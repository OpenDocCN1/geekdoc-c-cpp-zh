Qt applications that need to interface with other toolkits or libraries frequently need to access the low-level events (XEvent on X11, MSGs on Windows, EventRef on Mac OS X, QWEvents on QWS) before they are converted into QEvent. This can be useful for handling certain types of events that Qt ignores.

## Microsoft ActiveX on Windows

Microsoft's ActiveX technology allows applications to incorporate user interface components provided by other applications or libraries. It built on Microsoft COM and defines one set of interfaces for applications that use components and another set of interfaces for applications and libraries that provide components.

Qt/Windows Desktop Edition provides the ActiveQt framework to seamlessly combine ActiveX and Qt. ActiveQt consists of two modules:

- QAContainer module allows us to use COM objects and embed ActiveX controls in Qt.
- The QAServer module allows us to export custom COM objects and ActiveX controls using Qt.

Our first example will embed the Windows Media Player in a Qt application using the QAContainer module (see Figure 23.3). The Qt application adds a button, a Play/Pause button, a Stop button, and a slider to the Windows Media Player ActiveX control.

```cpp
class PlayerWindow : public QWidget
{
    Q_OBJECT
    Q_ENUM(ReadyState)

public:
    enum State { Stopped = 0, Paused = 1, Playing = 2 };
    enum ReadyState { Uninitialized = 0, Loading = 1, Interactive = 3, Complete = 4 };

    PlayerWindow();

protected:
    void timerEvent(QTimer *event);

private slots:
    void onStateChange(int oldState, int newState);
    void onReadyStateChange(ReadyState readyState);
    void onPositionChange(double oldPos, double newPos);
    void sliderValueChanged(int newValue);
    void openFile();

private:

    QPushButton *openButton;

    QPushButton *stopButton;

};
```

The PlayerWindow class is derived from QWidget. The Q_ENUM macro (just below Q_OBJECT) is necessary to tell moc the onStateChange slot is an enum type. In the private section, we declare a QAWidget * member variable.

```cpp
PlayerWindow::PlayerWindow()

    wmp = new QAWidget;
    wmp->setControl("{22D6F6-B0F6-11D0-94AB-0080C74CEE95}");

```

In the constructor, we are creating a QAWidget object to encapsulate the Windows Media Player ActiveX control. The QAContainer module consists of three classes: QObject encapsulates a COM object, QAWidget encapsulates an ActiveX control, and QABase implements the core COM functionality for QObject and QAWidget.
