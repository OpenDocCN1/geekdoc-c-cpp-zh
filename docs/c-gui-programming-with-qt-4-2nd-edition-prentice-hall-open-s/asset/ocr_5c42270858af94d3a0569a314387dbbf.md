QAXTYPE macros to declare and register the factory. This approach requires to specify the class and interface IDs using Q_CLASSINFO().

Back to the AddressBook class definition: The third occurrence of Q_CLASSINFO() may seem a bit mysterious. By default, ActiveX events control not only their properties, signals, and slots, but also those of their ancestors up to QWidget. The ToSuperClass attribute lets us specify the highest ancestor in the inheritance tree we want to expose. Here, we specify the class name of the component (AddressBook) as the highest to export, meaning that properties, signals, slots inherited from AddressBook's own ancestors will not be exported.
