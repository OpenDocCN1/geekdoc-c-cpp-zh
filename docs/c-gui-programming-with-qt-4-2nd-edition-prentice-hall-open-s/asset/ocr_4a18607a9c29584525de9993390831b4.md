horizontal header with QTableWidgetItem containing the column "A", "B", ..., "Z". We don't need to set the vertical header labels, because these are used to identify "1", "2", ..., "999". At the end, we move the cursor to cell A1.

QTableWidget is composed of several child widgets. It has a horizontal QHeaderView at the top, a vertical QHeaderView on the left, and two QScrollBars. The area is occupied by a special child widget, which handles the viewport, through functions inherited from QTableView and QAbstractScrollArea (Figure 4.2) provides a scrollable viewport and two scroll bars, which can be turned on and off. We cover the QScrollBar subclass in Chapter 6.

The cell() private function returns the Cell object for a given row and column. It is almost the same as QTableWidget::item(), except that it returns a Cell pointer instead of QTableWidgetItem pointer.

```
QString Spreadsheet::text(int row, int column) const
{
    Cell *c = cell(row, column);
    if (c) {
        return c->text();
    } else {
        return "";
    }
}
```
