Widget's palette consists of three color groups: active, inactive, and disabled.

+   * The Active group is used for widgets in the currently active window.

+   * The Inactive group is used for widgets in the other windows.

+   * The Disabled group is used for disabled widgets in any window.

The QWidget::palette() function returns the widget's palette as enums of type QPalette object. Color groups are specified as enums of type QPalette::ColorGroup.

When we want to get an appropriate brush or color for the drawing, the current approach is to use the current palette, obtained from QWidget::palette(), and the required role, for example, QPalette::foreground(). Each function returns a brush, which is normally what we want, but if we need the color we extract it from the brush, as we did in the paintEvent(). By default, the brushes returned are appropriate to the widget's state, so we don't need to specify a color group.

The paintEvent() function finishes by drawing the image itself. The call to QIconEditor::pixelRect() returns a QRect that defines the region to repaint. (Figure 5.4 illustrates how a rectangle is drawn.) As an easy optimization, we don't redraw pixels that fall outside this region.
