
We have written the book with the assumption that you have a basic knowledge of C++, Java, or C#. The code examples use a subset of C++, avoiding many C++ features that are rarely needed when programming Qt. In the places where a more advanced C++ construct is unviable, it is explained as it is used. If you already know Java or C# but have little or no experience with C++, we recommend that you begin by reading Appendix D, which provides sufficient introduction to C++ to be able to use this. For a more thorough introduction to object-oriented programming in C++, we recommend C++ How to Program by P. J. Deitel and H. M. Deitel (Pearson Hall, 2007), and C++ Primer by Stanley B. Lippman, Josée Lajoie, and Barbara E. Moo (Addison-Wesley, 2005).

Qt made its reputation as a cross-platform framework, but thanks to its intuitive and powerful API, many organizations use Qt for single-platform development. Adobe Photoshop Album is just one example of a mass-market Windows application written in Qt. Many sophisticated software systems in vertical markets, such as 3D animation tools, digital film processing, electronic device automation (for chip design), oil and gas exploration, financial services, and medical imaging, are built with Qt. If you are making a living with a successful Windows product written in Qt you can easily create new markets in the Mac OS and Linux worlds simply by recompiling.

Qt is available under various licenses. If you want to build commercial applications, you must buy a commercial Qt license from Trolltech; if you want to build open source programs, you may use the open source (GPL) edition. The K Desktop Environment (KDE) and most of the open source applications that go with it are built on Qt.

In addition to Qt's hundreds of classes, there are add-ons that extend Qt's scope and power. Some of these products, like the Qt Solutions components, are available from Trolltech, while others are supplied by other companies and by the open source community; see http://www.trolltech.com/products/qt/3rdparty/ for a list of available add-ons. Trolltech's developers also have their own web site, Trolltech Labs (http://labs.trolltech.com/), where they put unofficial code that they have written because it is free, interesting, or useful. Qt has a well-established and thriving user community that uses the qt-interest mailing list; see http://lists.trolltech.com/ for details.

# A Brief History of Qt

The Qt framework became publicly available in May 1995. It was initially developed by Haavar Nord (Trolltech's CEO) and Eirik Chambe-Eng (Trolltech's). Haavar and Eirik met at the Norwegian Institute of Technology in Trondheim, where both graduated with master's degrees in computer science. Haavar's interest in C++ GUI development began in 1988 when he was commissioned by a Swedish company to develop a C++ GUI framework. A couple of years later, in the summer of 1990, Haavar and Eirik were working together on a C++ database application system that needed to be able to run with a GUI on Unix, Macintosh, and Windows. One day that summer, Haavar and Eirik went out to enjoy the sunshine, and as they sat on a park bench, Haavar said, "We need an object-oriented display". The resulting discussion laid the intellectual foundation for the object-oriented cross-platform framework they would go on to build.

The year 1994 began with two young programmers wanting to establish a well-established market, with an unfinished product and no money. Frankly, they were employed and able to develop the product and start earning an income. In 1995, thanks to a contact made through one of Haavar's university professors, the Norwegian company gave them a contract to develop software based on Qt. Around this time, Trolltech hired Arnt Gulbrandsen, who during his six years at Trolltech developed and implemented an ingenious documentation system as well as contributing to Qt's code.

On May 20, 1995, Qt 0.90 was uploaded to site.unc.edu. Six days later, the release was announced on os.linux.announce. This was Qt's first release. Qt could be used for both Windows and Unix development, offering the Qt API on both platforms. Qt was available under two licenses from day one: a commercial license was required for commercial development, and a free software edition was available for open source development. The company kept Troll afloat, for ten months no one bought a commercial license.

In March 1996, the European Space Agency became the second Qt customer, with a purchase of ten commercial licenses. With unwavering faith, Eirik and Haavar hired another developer. Qt 0.97 was released at the end of May, and on September 24, 1996, Qt 1.0 came out. By the end of the year, Qt had reached version 1.1; eight customers, each in a different country, had bought 18 licenses between them. This year also saw the founding of the KDE project by Matthias Etritsch.

Qt 1.2 was released in April 1997. Matthias Etritsch's decision to use Qt to build KDE helped become the de facto standard for C++ GUI development on Linux. Qt 1.3 was released in September 1997.

Matthias Trolltech in 1998, and the last Qt 1 release, 1.40, was made in September of that year. Qt 2.0 was released in June 1999. Qt 2 had a new open source license, the Qt Public License (QPL), which complied with the Open Source Definition. In August 1999, Qt won the LinuxWorld award for best library/tool. Around this time, Trolltech Pty Ltd (Australia) was established.

Trolltech released Qt/Embedded Linux in 2000. It was designed to run on embedded devices and provided its own window system as a lightweight replacement for X11. Both Qt and Qt/Embedded were now offered under the widely used GNU General Public License (GPL) as well as commercial licenses. By the end of 2000, Trolltech had established Trolltech Inc. (USA) and had released the first version of Qtopia, an application platform for mobile phones and PDAs. Qt/Embedded Linux won the LinuxWorld "Best Embedded Linux Solution" in both 2001 and 2002, and Qtopia Phone achieved the same distinction in 2004.

Qt 3.0 was released in 2001. Qt was now available on Windows, Mac OS, Unix, and Linux (desktop and embedded). Qt 3 provided 42 new classes and its code exceeded 50000 lines. Qt 3 was a major step forward from Qt 2, including improved locale and Unicode support, a completely new text viewing and editing widget, and a feat won the Software Development Times "Jolt Productivity Award" in 2002.

In the summer of 2005, Qt 4.0 was released. With about 500 classes and more than 9000 functions, Qt 4 is larger and richer than any previous version, and it has been split into several libraries that developers only need to link against the parts of Qt that they need. Qt 4 is a huge advantage over previous versions with improvements that include a completely new set of features and easy-to-use template containers, advanced model/view functionality, and a fast and flexible 2D painting framework, and powerful Unicode text viewing and editing classes.
