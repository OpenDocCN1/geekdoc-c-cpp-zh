QTextStream for text. These classes take care of issues such as byte ordering and text encodings, which Qt applications running on different platforms or in different countries can read and write each other's files. This makes Qt's I/O classes more convenient than the corresponding Standard C++ classes, which leave these issues to the application programmer.

QFile makes it easy to access individual files, whether they are in the file system or embedded in the application's executable as resources. For applications that need to identify which sets of files to work on, Qt provides the QDir and QFileInfo classes, which handle directories and provide information about the files inside them.

QProcess allows us to launch external programs and communicate with them through their standard input, standard output, and error channels (cin, cout, cerr). We can set the environment variables and working directory that the external application will use. By default, communication with the process is asynchronous (non-blocking), but it is also possible to block on certain operations.

Networking and reading writing XML are such substantial topics that we cover separately in their own dedicated chapters (Chapter 15 and Chapter 16).

# Reading and Writing Binary Data

The simplest way to load and save binary data with Qt is to instantiate a QFile, open the file, and access it through a QDataStream object. QDataStream provides a platform-independent storage format that supports C++ types such as int and double, and many Qt data types, including QByteArray, QFont, QImage, QPixmap, QString, and QVariant, as well as Qt container classes as QList<T> and QMap<K, T>.

Here's how we store an integer, a QImage and a QMap<QString, QColor> in a QImage (phil.png)
