```
CC -DPI=3.1415926539 -c main.cpp
```

Macros were popular in the old days, typedefs, enums, constants, inline functions, and templates were introduced. Nowadays, their most important role is to protect header files against multiple inclusions.

+   Macros can be undefined at any point using #undef:

```
#undef PI
```

This is useful if we want to redefine a macro, since the preprocessor doesn't let us define the same macro twice. It is also useful to control conditional compilation.

+   Portions of code can be processed or skipped using #if, #elif, #else, #endif, based on the numeric value of macros. For example:

```cpp
#define NO_OPTIM 0
#define OPTIM_FOR_SPEED 1
#define OPTIM_FOR_MEMORY 2

#define OPTIMIZATION OPTIM_FOR_MEMORY
n...
```

```cpp
#if OPTIMIZATION == OPTIM_FOR_SPEED
typef int MyInt;
#elif OPTIMIZATION == OPTIM_FOR_MEMORY
typef short MyInt;
#else
typef long long MyInt;
#endif
```

In the preceding example, the second typedef declaration would be processed by the compiler, resulting in MyInt defined as a synonym for short. By changing the definition of the OPTIMIZATION macro, we get different programs. If a macro isn't defined, its value is taken to be 0.

Another approach to conditional compilation is to test whether a macro is defined. This can be done by using the defined() operator as follows:

```cpp
#define OPTIM_FOR_MEMORY
...
#if defined(OPTIM_FOR_SPEED)
```

```cpp
typedef int MyInt;
#elif defined(OPTIM_FOR_MEMORY)
typedef short MyInt;
#else
typedef long long MyInt;
#endif
```

+   * For convenience, the preprocessor recognizes #ifdef X and #ifndef X as synonyms for #if defined(X) and #if !defined(X). To protect a header file against multiple inclusions, we wrap its contents with the following idiom:

```cpp
#ifndef MYHEADER_FILE_H
#define MYHEADER_FILE_H
...
#endif
```

The first time the header file is included, the symbol MYHEADER_FILE_H is not defined, so the compiler processes the code between #ifndef and #endif. The second and any subsequent times the header file is included, MYHEADER_FILE_H is defined, so the #ifndef ... #endif block is skipped.

+   * #error directive emits a user-defined error message at compile time. This is often used in conjunction with conditional compilation to report an impossible case. For example:

```cpp
class UniChar{
public:
#if BYTE_ORDER == BIG_ENDIAN
uchar row;
uchar cell;
#elif BYTE_ORDER == LITTLE_ENDIAN
uchar cell;
uchar row;
#else
#error "BYTE_ORDER must be BIG_ENDIAN or LITTLE_ENDIAN"
#endif
};
```

Unlike other C++ constructs, where whitespace is irrelevant, preprocessor directives stand alone on a line and require no semicolon. Very long directives can be split across multiple lines by ending every line except the last with a backslash.

Since C++ is essentially a superset of the C language, C++ programmers also have the entire C library at their disposal. The C header files are available either with their traditional names (e.g., <stdio.h>) or with new-style names with a c- prefix and no .h (e.g., <cstdio>).
