
# Sequential Containers

A QVector<T> is an array-like data structure that stores its items at adjacent positions in memory, as Figure 11.1 illustrates. What distinguishes a vector from a plain C++ array is that a vector has its own size and can be resized. Appending extra items to the end of a vector is fairly efficient, whereas inserting items at the front or in the middle of a vector can be expensive.

> Figure 11.1. A vector of doubles

![](img/5a524abdf0b0d58fa99d30abb4463611_425_0.png)

If we know in advance how many items we are going to need, we can give the vector an initial size when we define it and use the [] operator to assign a value to the items; otherwise, we must either resize the vector later on or append items. Here's an example where we specify the initial size:

```cpp
QVector<double> vect(3);
vect[0] = 1.0;
vect[1] = 0.540302;
vect[2] = -0.416147;
```

Here's the same example, this time starting with an empty vector and using the append() function to append items at the end:

```cpp
QVector<double> vect;
vect.append(1.0);
vect.append(0.540302);
vect.append(-0.416147);
```

We can also use the << operator instead of append():

```cpp
vect << 1.0 << 0.540302 << -0.416147;
```

One way to iterate over the vector's items is to use [] and count():

```cpp
double sum = 0.0;
for (int i = 0; i < vect.count(); ++i)
    sum += vect[i];
```

Vector entries that were created without assigning an explicit value are initialized using the item class's default constructor. Basic types and pointer types are initialized to zero.

Inserting items at the beginning or in the middle of a QVector<T>, removing items from these positions, can be inefficient for large vectors. For this reason, QLinkedList<T>, a data structure that stores its items at non-adjacent locations, as illustrated by Figure 11.2. Unlike vectors, linked lists don't support random access, but they provide "constant time" insertions and removals.

# Figure 11.2. A linked list of doubles

![](img/5a524abdf0b0d58fa99d30abb4463611_426_0.png)

Linked lists do not provide the [] operator, so iterators must be used to traverse their items. Iterators are also used to specify the position of items. For example, the following code inserts the string "Tote Hosen" between "Clash" and "Ramones":

```cpp
QLinkedList<QString> list;
list.append("Clash");
list.append("Ramones");

QLinkedList<QString>::iterator i = list.find("Ramones");
list.insert(i, "Tote Hosen");
```

We will take a more detailed look at iterators later in this section. The List<T> sequential container is an "array-list" that combines the most important benefits of QVector<T> and QLinkedList<T> in a single class. It supports random access, and its interface is index-based like QVector<T>. Inserting or removing an item at either end of a List<T> is very fast, and inserting in the middle is fast for lists with up to one thousand items. Unless we want to perform insertions in the middle of huge lists or need the list's items to occupy consecutive addresses in memory, List<T> is usually the most appropriate general-purpose container to use.

The QStringList is a subclass of List<QString> that is widely used in Qt. In addition to the functions it inherits from its base class, it provides some extra that make the class more versatile for string handling. We discuss QStringList in the last section of this chapter (p. 290).

QStack<T> and QQueue<T> are two examples of convenience subclasses. Stack<T> provides push(), pop(), top(). QQueue<T> provides enqueue(), dequeue(), head().

For all the containers seen so far, the value type T can be a basic type like int or double, a pointer, or a class that has a default constructor (a constructor that takes no arguments), a copy constructor, and an assignment operator. Classes that qualify include ByteArray, QDateTime, QRegExp, QString, and QVariant; classes derived from QObject do not qualify, because they lack a copy constructor and an assignment operator. This is no problem in practice, since we can simply store pointers to QObject rather than the objects they represent.

The value type T can also be a container, in which case we must remember to separate consecutive angle brackets with spaces; otherwise, the compiler will choke on what it thinks is a >> operator. For example:

```cpp
QList<QVector<double> > list;
```

In addition to the types just mentioned, a container's value type can be any class that meets the criteria described earlier. Here is an example of such a class:

```cpp
class Movie
public:
    Movie(const QString &title = "", int duration = 0);
    void setTitle(const QString &title) { myTitle = title; }
    QString title() const { return myTitle; }

private:
    QString myTitle;
    int myDuration;
};
```

The first thing to keep in mind when using Java-style iterators is that they don't point directly at items. Instead, they can be located before the first item, after the last item, or between two items. A typical loop looks like this:

```cpp
ListIterator<double> i(list);
while (i.hasNext()) {
    do_something(i.next());
}
```

The hasNext() function returns true if there is an item to the right of the iterator. The next() function returns the item to the right and advances the iterator to the next position. Iterating backward is similar, except that we must first call toBack() to position the iterator after the last item:

```cpp
ListIterator<double> i(list);
i.toBack();
while (i.hasPrevious()) {
    do_something(i.previous());
}
```

Qt provides two categories of iterators: Java-style and STL-style. Java- iterators are easier to use, whereas STL-style iterators are more powerful. For each container, there are two Java-style iterators: read-only and read-write.

The read-only iterators are QConstListIterator<T> and QConstIterator<T>. The read-write iterators are QListIterator<T> and QListIterator<T>. Another way to think about the next() and previous() iterators is that they return the item that the iterator has just jumped over, as Figure 11.4 illustrates.

Mutable iterators provide functions to insert, modify, and remove items while iterating. The following loop removes all the negative numbers from a list:

```cpp
MutableListIterator<double> i(list);
while (i.hasNext()) {
  if (i.next() < 0.0)
    i.remove();
}
```

The remove() function always operates on the last item that was jumped over. It also works when iterating backward:

```cpp
MutableListIterator<double> i(list);
i.toBack();
while (i.hasPrevious()) {
  if (i.previous() < 0.0)
    i.remove();
}
```

Similarly, the mutable Java-style iterators provide a setValue() function that modifies the last item that was jumped over. Here's how we would replace negative numbers with their absolute value:

```cpp
MutableListIterator<double> i(list);
while (i.hasNext()) {
  int val = i.next();
  if (val < 0.0)
    i.setValue(-val);
}
```
