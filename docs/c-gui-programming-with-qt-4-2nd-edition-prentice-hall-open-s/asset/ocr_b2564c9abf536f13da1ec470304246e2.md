# Using the Reference Documentation

Qt's reference documentation is an essential tool for Qt developer, since it covers every class and function in Qt. This book makes use of many Qt classes and functions, but it does not cover all of them, nor does it provide detail of those are mentioned. To get the most benefit from Qt, you should familiarize yourself with the Qt reference documentation as quickly as possible.

The documentation is available in HTML format in Qt's doc/html directory and can be read using any web browser. You can also use Qt Assistant, the Qt help browser, which has powerful searching and indexing features that make it quicker and easier to use than a web browser.

To launch Qt Assistant, click Qt Trolltech v4.x.y|Assistant in the Start menu on Windows, type assistant on the command line, or double-click Assistant on the Mac OS X Finder. The links in the "API Reference" section on the home page provide different ways of navigating Qt classes. The "All Classes" page lists every those class in Qt's API. The "Main Classes" page lists only the most commonly used Qt classes. As an exercise, you might want to look up the classes and functions that we have used in this chapter.
