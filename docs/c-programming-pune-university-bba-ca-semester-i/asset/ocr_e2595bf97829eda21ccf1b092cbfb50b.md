# Tokens

Tokens are individual words and punctuation marks in passage of text. In C, program the smallest individual units are known as C Tokens. C has **Six types of Tokens**.

+   1. Keywords (eg: int, while),
+   2. Identifiers (eg: main, total),
+   3. Constants (eg: 10, 20),
+   4. Strings (eg: "total", "hello"),
+   5. Special symbols (eg: (), {}),
+   6. Operators (eg: +, /, -, *)
