# Global and Local Variables

A local variable is declared inside a function. A global variable is declared outside all functions. A local variable can only be used in the function where it is declared. A global variable can be used in all functions.

```
##include<stdio.h>
// Global variables
int x;
int y;
int add()
{
        return x + y;
}
int main()
{
        int answer; // Local variable
        x = 2;
        y = 5;
        answer = add();
        printf("%d\n",answer);
        return 0;
}
```

In example, global variables are declared, x and y. These variables can be used in main() and add(). The local variables answer can only be used in main().
