
## 7) Write a program on Sum of given N Numbers.

### Algorithm:

- Initialize: `sum = 0`
- Run a loop from `I = 1` to `N` and do following in loop.
  - Read `M`
  - `sum = sum + M`
- Display `sum`
- Stop

### Program:

```c
#include<stdio.h>
#include<stdlib.h>
int main()
{
        int N, M, i, sum;
        sum = 0; /* read the number */
        printf("Enter number to sum:");
        scanf("%d", &N);
        for(i=1; i<=N; i++)
        {
                printf("Enter number");
                scanf("%d", &M);
                sum = sum + M;
        }
        printf("sum of given numbers is %d\n", sum);
        getch();
        return 0;
}
```

## 9) Write a program to calculate nCr.

### Algorithm:

- Step 1: Start
- Step 2: Read n, r
- Step 3: Calculate factorial of n, r, and n-r.
- Step 4: Divide fact (n) by multiplication of fact (r) and fact (n-r) and store it to result.
- Step 5: Return result
- Step 6: Stop.

### Program:

```c
#include<stdio.h>
void main()
{
    int n, r, ncr;
    printf("Enter N and R values :");
    scanf("%d%d", &n, &r);
    ncr=fact(n)/(fact(r)*fact(n-r));
    printf("The NCR of %d and %d is %d", n , r ,ncr);
}

// p is a formal parameter or dummy parameter
// Calculate using n!/(n-r)!*r!
int fact(int p)
{
    int i=1;
    while(p!=0)
    {
        i=i*p;
        p--;
    }
    return i;
}
```

### Output:

```text
Enter N and R values: 6   3
The NCR of 6 and 3 is 20
```

## 12) Write a program to reverse digits of a number.

### Algorithm:

- Step 1: Start
- Step 2: Read N and initialize r_num=0
- Step 3: Iterate while N>0
  - 1) `r_num = r_num * 10 + N % 10`
  - 2) `N = N / 10`
- Step 4: Return r_num
- Step 5: Stop

### Program:

```c
#include<stdio.h>
/* Iterative function to reverse digits of num */
int reverseDigits (int N)
{
        int r_num = 0;
        while(N > 0)
        {
                r_num = r_num*10 + N%10;
                N = N/10;
        }
        return r_num;
}

/* Driver program to test reverseDigits */
int main()
{
        int N = 4562;
        printf("Reverse of no is %d", reverseDigits(N));
        getchar();
        return 0;
}
```
