# 4) Write a C program to check whether a given number is positive or negative.

# Algorithm :

+   - Step 1: Start
+   - Step 2: Declare variable N
+   - Step 3: Assign value to n
+   - Step 4: Check if N is greater than or equal to 0
+   - Step 5: If true print N is positive
+   - Step 6: If false print N is negative
+   - Step 7: Stop

# Program:

```
```c
#include<stdio.h>
Void main()
{
    Int N;
    Printf("Input a number:");
    Scanf("%d", &N);
    If(N>=0)
        Printf("%d is a positive number \n", N);
    else
        printf("%d is a negative number \n", N);
}
```
```

# Output:

Input a number : 7
7 is a positive number.
