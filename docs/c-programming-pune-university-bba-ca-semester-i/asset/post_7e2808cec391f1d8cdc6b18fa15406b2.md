## Run time error

If any error is generated at run time, it is known as a runtime error. In general, these are raised because of writing wrong logic in the program.

### Example

Calling function without existence, divide by zero.

```c
int a=10,b;
b=a/0; // infinite
```

Here out of range of int data type.

In general, it is very difficult to identify logical error in C language; to overcome this problem, exception handling was introduced in object-oriented programming language.

## Warning

Warning is also an abnormal condition but whenever it occurs execution of the program will never be stopped.

Note: In C language warning can be neglected but error cannot be neglected.

## Declare Constant

const keyword is used to declare a constant.

### Syntax

```c
const int height = 100;
```

### Example

```c
#include<stdio.h>
#include<conio.h>

void main()
{
    const int a=10;
    printf("%d",a);
    a=20; // gives error you can't modify const
    getch();
}
```

- 12A. Program to accept an Empcode, Emp name, basic salary from user

  - Calculate DA (Dearness Allowances) = 10% of basic
  - Calculate HRA (House Rent Allowances) = 5% of basic
  - Calculate CLA (City Allowances) = 12% of basic
  - TA is fixed 200 for all employees
  - Calculate Gross = Basic + DA + HRA + CLA + TA
  - Calculate Ptax (Professional Tax) = 5% of basic
  - Calculate IT (Income Tax) = 10% of basic
  - Calculate Total Deduction as ded = Ptax + IT
  - Calculate Net salary as Gross – ded.
  - Print Emp code, Emp name, Basic, Gross & Net sal.

```c
#include<stdio.h>
#include<conio.h>
void main()
{
    float basic,da,hra,cla,gross,ded,pt,it,net;
    clrscr();
    printf("please enter the value of basic");
    scanf("%f",&basic);
    da=(10.0/100.0)*basic;
    hra=(5.0/100.0)*basic;
    cla=(12.0/100.0)*basic;
    gross=basic+da+hra+cla;
    gross=basic+da+hra+cla;
    it=(10.0/100.0)*basic;
    ded=pt+it;
    net=gross-ded;
    printf("Basic is %3.2f\n",basic);
    printf("Da is %3.2f\n",da);
    printf("Hra is %3.2f\n",hra);
    printf("Cla is %3.2f\n",cla);
    printf("Gross is %3.2f\n",gross);
    printf("Ptax is %3.2f\n",pt);
    printf("Itax is %3.2f\n",it);
    printf("Deduction is %3.2f\n",ded);
    printf("Net salary is %3.2f\n",net);
    getch();
}
```
