# 15) Write a program for Table Generation.

**Algorithm:**

+   Step 1: Define table value N
+   Step 2: Initialize I=1
+   Step 3: T= I*N
+   Step 4: Display T
+   Step 5: Increment I by 1
+   Step 6: Check whether I<=N if True goto Step 2
+   Step 5: Stop

**Program:**

```
```c
#include<stdio.h>
int main()
{
        int N, T;
        printf("Enter an integer : ");
        scanf("%d", &N);
        for(i = 1; i<=10 ; ++i)
        {
                printf("%d * %d = %d\n", N, i, N*i);
        }
        return 0;
}
