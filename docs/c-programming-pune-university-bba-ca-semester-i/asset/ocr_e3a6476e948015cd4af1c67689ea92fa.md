# # Declare Constant

const keywords are used to declare a constant.

# ### Syntax

```
```c
const int height = 100;
```
```

# ### Example

```
```c
#include<stdio.h>
#include<conio.h>

void main()
{
    const int a=10;
    printf("%d",a);
    a=20; // gives error you can't modify const
    getch();
}
```
