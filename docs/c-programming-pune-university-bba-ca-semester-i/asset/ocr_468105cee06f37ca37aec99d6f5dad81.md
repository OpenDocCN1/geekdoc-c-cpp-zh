# 9) Write a program to calculate nCr.

# Algorithm:

+   - Step 1: Start
+   - Step 2: Read n, r
+   - Step 3: Calculate factorial of n, r, and n-r.
+   - Step 4: Divide fact (n) by multiplication of fact (r) and fact (n-r) and store it to result.
+   - Step 5: Return result
+   - Step 6: Stop.

# Program:

```
```c
#include<stdio.h>
void main()
{
    int n, r, ncr;
    printf("Enter N and R values :");
    scanf("%d%d", &n, &r);
    ncr=fact(n)/(fact(r)*fact(n-r));
    printf("The NCR of %d and %d is %d", n , r ,ncr);
}
