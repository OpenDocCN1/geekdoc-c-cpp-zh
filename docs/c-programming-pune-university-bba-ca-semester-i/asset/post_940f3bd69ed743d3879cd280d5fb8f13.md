
### Example:

```c

{
    static int marks[5] = {90,80,76,89, -90};
    int i, total = 0;
```

## 3.4.3 goto

A goto statement in C programming provides an unconditional jump from the 'goto' to a labeled statement in the same function.

### Syntax:

The syntax for a **goto** statement in C is as follows:

```c
goto label;
```

Here **label** can be any plain text except C keyword and it can be set anywhere in the C program above or below to **goto** statement. The label is an identifier. When **goto** statement is encountered, control of the program jumps to **label:** and starts executing the code.

## 3.4.4 exit

In C exit() is a predefined/library function used to terminate the currently running program(process) immediately.

### Syntax:

```c
void exit(int status);
```

**status** - The status is an integer value returned to the parent process.

Here 0 usually means program completed successfully, and nonzero values are used as error codes. **e.g. exit(0);**

There are also predefined macros EXIT_SUCCESS and EXIT_FAILURE, **e.g. exit(EXIT_SUCCESS);**

In the C Language, the required header for the exit() function is **stdlib.h.**

### Example:

```c
#include <stdio.h>
#include <stdlib.h>
int main ()
{
    printf("Start of the program....\n");
    printf("Exiting the program....\n");
    exit(0);
    printf("End of the program....\n");
    return(0);
}
```

### Output:

```
Start of the program....
Exiting the program....
```
