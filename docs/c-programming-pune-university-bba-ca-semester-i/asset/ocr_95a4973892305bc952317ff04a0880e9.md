# ## 2.1.2 getch(), getchar()

+   1. **getch( )**: getch() is **used** to get a character from console but does not echo to the screen.
+      - **Library:** `<CONIO.H>`
+      - **Declaration:** `int getch(void);`
+      - **Example:** Declaration:
+        `char ch;`
+        `ch = getch(); (or ) getch();`
+      - **Remarks:** getch reads a single character directly from the keyboard, without echoing to the screen.
+      - **Return Value:** This function return the character read from the keyboard.
