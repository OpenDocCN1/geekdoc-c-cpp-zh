# 2) Write a program to perform multiplication of two integers.

Algorithm:

+   Step 1: Start
+   Step 2: Declare variables no1, no2 and product.
+   Step 3: Read values for no1, no2.
+   Step 4: Multiply no1 and no2 and assign the result to a variable product.
+   Step 5: Display product
+   Step 6: Stop

Program:

```
```c
#include<stdio.h>
int main()
{
    int no1, no2, product;
    printf("Enter two numbers to multiply \n");
    scanf("%d%d", &no1, &no2);
    product = no1*no2;
    printf("Product of the numbers = %d\n", product);
    return 0;
}
```
```

Output:

Enter two numbers to multiply
2
4
Product of the numbers = 8
