# # For Loop Flow Diagram

![](bbox=[0.34, 0.172, 0.612, 0.54])

*Example:*

```
~~~c
...
int i;
for(i=1; i<=4; i++)
{
    printf("hello, World");
}
...
~~~
```

**Output:**

hello,World
hello,World
hello,World
hello, World

**Step 1:** First the counter variable gets initialized; here variable is I, which has been assigned by value 1.
