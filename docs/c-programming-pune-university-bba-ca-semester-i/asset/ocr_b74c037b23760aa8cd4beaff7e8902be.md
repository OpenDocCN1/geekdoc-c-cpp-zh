# ### C Programming Language Timeline

| Year |  | Developed by |
| --- | --- | --- |
| 1960 | ALGOL | International Group |
| 1967 | BCPL | Martin Richard |
| 1970 | B | Ken Thompson |
| 1973 | Traditional C | Dennis Ritchie |

C language has evolved from three different structured languages ALGOL, BCPL and B Language. It uses many concepts from these languages and introduced many new concepts such as data types, structure pointer.

In 1988, the language was formalized by American National Standard Institute (ANSI).

In 1990, a version of C language was approved by the International Standard Organization (ISO) and that version of C is also referred to as C89.
