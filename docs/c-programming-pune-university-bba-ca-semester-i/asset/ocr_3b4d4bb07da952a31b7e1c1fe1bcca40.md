# 1) Write a program to perform addition of two integers.

# Algorithm:

+   1. Step 1: Start
+   2. Step 2: Declare variables n1, n2 and sum.
+   3. Step 3: Read values for n1, n2.
+   4. Step 4: Add n1 and n2 and assign the result to a variable sum.
+   5. Step 5: Display sum
+   6. Step 6: Stop

# Program:

```
```c
#include<stdio.h>
int main()
{
        int n1, n2, sum;
        printf("Enter two numbers to add \n");
        scanf("%d%d", &n1, &n2);
        sum = n1+n2;
        printf("Sum of the numbers = %d\n", sum);
        return 0;
}
```
```
