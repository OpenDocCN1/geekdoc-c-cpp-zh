# # Preface

We take an opportunity to present this book on “C-Programming” to the first year students of BBA (CA) Semester – I as per the new syllabus of SPPU, June 2019. This book covers the C-Programming fundamentals which will help in clearing students basic programming concepts.

The main intention of presenting this book to student community is to equip them the practical orientation of programming skills. The book has 8 chapters which focuses on C fundamental concepts, I/O operations, Decision making and Looping, Arrays and Strings, Functions, Pointers and Structures. Each chapter supported with solved exercises and practicing questions.

We have given our best inputs for this book. Any suggestions and comments are always welcome towards the improvement of this book.
