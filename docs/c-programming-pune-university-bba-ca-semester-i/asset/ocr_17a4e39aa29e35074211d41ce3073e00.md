```
# strrchr() function

strrchr( ) function in C returns pointer to the last occurrence of the character in a given string. Syntax for strrchr( ) function is given below.

```
```c
char *strrchr(const char *str, int character);
```
```

In this program, strrchr( ) function is used to locate last occurrence of the character ‘i’ in the string ”Shrutkirti”. Last occurrence of character ‘i’ is located at position 10 and pointer is returned at last occurrence of the character ‘i’.
```
