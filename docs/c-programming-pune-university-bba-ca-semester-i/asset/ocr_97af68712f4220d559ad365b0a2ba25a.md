# *Example post-decrement*

```
~~~c
#include<stdio.h>
#include<conio.h>
void main()
{
    int x,i;
    i=10;
    x=i--;
    printf("x: %d",x);
    printf("i: %d",i);
    getch();
}
~~~
```

**Output:**

x: 10  
i: 9

In above program first used the value of x in expression then decrease value of i by 1.
