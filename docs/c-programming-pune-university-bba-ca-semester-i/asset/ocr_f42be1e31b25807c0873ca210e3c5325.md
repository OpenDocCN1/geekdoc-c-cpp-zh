# 12) Write a program to reverse digits of a number.

# Algorithm:

+   Step 1: Start
+   Step 2: Read N and initialize r_num=0
+   Step 3: Iterate while N>0
+   &nbsp;&nbsp;&nbsp;&nbsp;1) r_num=r_num*10+N%10
+   &nbsp;&nbsp;&nbsp;&nbsp;2) N=N/10
+   Step 4: Return r_num
+   Step 4: Stop

# Program:

```
#include<stdio.h>
/* Iterative function to reverse digits of num */
int reverseDigits (int N)
{
        int r_num = 0;
        while(N > 0)
        {
                r_num = r_num*10 + N%10;
                N = N/10;
        }
        return r_num;
}

/* Driver program to test reverseDigits */
int main()
{
        int N = 4562;
        printf("Reverse of no is %d", reverseDigits(N));
        getchar();
        return 0;
}
```

# Output:

Reverse of no is 2654
