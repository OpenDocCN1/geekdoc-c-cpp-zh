
## 2. Definition section

It is a constant defining section; this section is prefixed by `#` sign.

```c
#define pi 3.1415
```

`#` is a preprocessor directive which gives direction to the compiler that defines pi as a constant value for the program.

It is also called a macro definition.

### Macro: #define

This macro defines a constant value and can be any of the basic data types. These constants are usually defined at the beginning of a program. They may then appear later in the program in place of the numeric constants, character constants, etc., that the macro may represent. The syntax to use the define macro is as follows:

```c
#define name value
```

Where name represents a symbolic name, typically written in uppercase letters, and text represents the sequence of characters that is associated with the symbolic name. Note that text does not end with a semicolon, since a symbolic constant definition is not a true C statement.

Let’s see an example:

```c
#define PI 3.14
void main()
{
    float radius=1.2;
    float area_of_circle = PI * radius * radius;
    float circumference_of_circle = 2 * PI * radius;
    printf("\n Details of circle");
    printf("\n Area = %f", area_of_circle);
    printf("\n Circumference = %f", circumference_of_circle);
}
```

In the above program, instead of writing the value 3.14 for calculating the area and circumference of a circle, a constant PI, which is defined before the main() function, is used.

```c
#define PI 3.14
```

This statement is called ‘macro definition’ or more commonly, just a ‘macro’. The preprocessor replaces every occurrence of PI in the program with 3.14.

## 3. Link Section / Include Section

### File Inclusion: #include

The second preprocessor directive causes one file to be included in another. The preprocessor command for file inclusion looks like this:

```c
#include <file_name>
```

The source code of the file “file_name” is included in the C program’s main() function where “#include <file_name>” is mentioned. Of course, this assumes that the file being included exists.

This directive is normally used for very large programs which can be divided into several different files each containing related functions. These files are included with **#include** at the beginning of the main() function program file. Secondly, the commonly needed functions and macro definitions can be stored in a file, and that file can be included in every program later.

The prototypes of all the library functions are grouped into different categories and then stored in different header files. For example, prototypes of all mathematics related functions are stored in the header file “math.h” which can be included as shown below:

```c
#include<math.h>
```

The #include directive can be used in two ways as discussed below:

- `#include "filename"`
- `#include <filename>`
- `#include "sum.c"`
- `#include "c:\employee.c"`

It is the link section, also called the include section; this section is prefixed by `#` sign.

- `# include<stdio.h>`
- `# include<conio.h>`
- `# include<math.h>`
- `# include<stdlib.h>`

`#` is a preprocessor directive which gives direction to the compiler to include the specified header file from the library in the main() function program.

| Header File | Description |
|---|---|
| `#include<stdio.h>` | It is the standard input output header file; it consists of standard input function scanf() and standard output function printf(). |
| `#include<conio.h>` | It is the console input output header file; it consists of clrscr() function to clear screen and getch() function to get character to see the output on screen. |
| `#include<math.h>` | It is the Math Header File; it consists of all mathematical functions, sin(), cos(), tan(), sqrt(). |
| `#include<stdlib.h>` | It is the Standard Library File; it consists of exit() function. |
| `#include<string.h>` | It is the String Header File; it consists of string functions, strcmp(), strlen(), strcpy(), strrev(), strcat(). |
| `#include<ctype.h>` | All character handling functions are defined in this header file. It consists of islower(), isupper(), isdigit(). |

## 4. Global Declaration Section

The variables used in more than one function can be declared in the global section; hence, publicly all these variables can be used in all the functions of the program as well as can be included in other programs also.

User-defined functions can be declared in this section with the signature of the function in a single line terminated by a semicolon.

## Body Section

```c
void main() function section
{
    Local declaration part
    Executable part
}
```

**main() function section:** Every C program must have one main() function section. The main() function is a startup function from where the execution of the program starts. This section contains two parts: declaration part and executable part.

- 1. **Local declaration part:** The declaration part declares all the variables used in the executable part as well as user-defined functions can be declared locally in this section.
- 2. **Executable part:** There is at least one statement in the executable part. These two parts must appear between the opening and closing braces. The program execution begins at the opening brace and ends at the closing brace. The closing brace of the main() function is the logical end of the program. All statements in the declaration and executable part end with a semicolon, leaving keyword statements.

## 1.3 Language Fundamentals

### 1.3.1 Character Set, Tokens

### Character Set

C uses the uppercase letters A to Z, the lowercase letters a to z, the digits 0 to 9, and certain special characters as building blocks to form basic program elements (e.g., constants, variables, operators, expressions, etc.).

The special characters are listed below.

**Table 1.1: Character Set**

|   |   |   |   |   |
|---|---|---|---|---|
| + | - | * | \\ | / |
| = | % | & | ~ | # |
| ! | ? | ^ | . | " |
| \| | < | > | ( | ) |
| { | } | [ | ] | : |
| ; | . | , | _ | Blank space |

Most versions of the language also allow certain other characters, such as @ and $, to be included within strings and comments.

C uses certain combinations of these characters, such as `\b`, `\n` and `\t`, to represent special conditions such as backspace, newline and horizontal tab, respectively.

These character combinations are known as escape sequences. For now we simply mention that each escape sequence represents a single character, even though it is written as two or more characters.

### Tokens

Tokens are individual words and punctuation marks in a passage of text. In a C program, the smallest individual units are known as C tokens. C has six types of tokens.

- 1. Keywords (eg: int, while)
- 2. Identifiers (eg: main, total)
- 3. Constants (eg: 10, 20)
- 4. Strings (eg: "total", "hello")
- 5. Special symbols (eg: (), {})
- 6. Operators (eg: +, /, -, *)
