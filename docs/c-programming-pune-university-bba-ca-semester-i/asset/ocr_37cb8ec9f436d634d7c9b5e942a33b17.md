# ### 3) Write a C program to check whether a given number is even or odd.

# ### Algorithm :

+   - Step 1: Start
+   - Step 2: Read num
+   - Step 3: Check If num%2==0 Then Print: num is an Even Number.
+     Else
+     Print: num is an odd Number.
+   - Step 4: Stop

# ### Program:

```
    #include<stdio.h>
    int main()
    {
        int num;
        printf("Enter an integer: ");
        scanf("%d", &num);
        if(num%2==0)
            printf("%d is even", num);
        else
            printf("%d is odd", num);
        return 0;
    }
```

# ### Output :

Enter an integer :- 11
11 is odd.
