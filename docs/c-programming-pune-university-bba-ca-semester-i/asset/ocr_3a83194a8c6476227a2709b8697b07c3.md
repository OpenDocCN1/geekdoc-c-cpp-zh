# ### 14) Write a program to find maximum of two numbers.

# #### Algorithm:

```
```text
Step 1:  Start
Step 2:  Read N1, N2.
Step 3:  If N1>N2 then
             Display “N1 is the largest number”.
         Otherwise
             Display “N2 is the largest number”.
Step 4:  Stop.
```
```

# #### Program:

```
```c
#include<stdio.h>
#include<conio.h>
void main()
{
    int N1, N2 ;
    clrscr();
    printf(“enter the values of N1, N2”);
    scanf(“%d%d”, &N1, &N2);
    if (N1>N2)
    {
        printf(“%d is larger number”, N1);

    else
    {

}
