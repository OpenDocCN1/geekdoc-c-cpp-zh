# Unary Arithmetic Operators

The unary operators are unary minus(-), increment operator (++) and decrement operator (--).

# Unary Minus(-)

The symbol is the same as used for binary subtraction. Unary minus is used to indicate or change the algebraic sign of a value. For example:

```
```
a=-75;
b=-a;
```
```

assign the value -75 to a and the value 75(-(-75)) to b. The minus sign used in this way is called the unary operator because it takes just one operand.

Strictly speaking, there is no unary + in C.
