```
# Example:-

```
```c
main( )
{
    increment( );
    increment( );
    increment ( );
}
increment( )
{
    auto int x=1;
    printf("%d\n",x);
    x++;
}
```
```

# Output:-

```
```text
1
1
1
```
```

In above example , when variable x is auto , each time increment( ) is called, it is re-initialized to 1. When the function terminates, x vanishes and its new value of 2 is lost. No matter how many times we call increment( ), x is initialized to1 every time.
```
