### 6.1.1 Purpose of Function

- 1. C functions are used to avoid rewriting the same block of statements, which are to be executed again and again.
- 2. Functions can be called as many times as required. No limitation on calling of a function.
- 3. Defining function specifies modularization which divides large C programs into functions, i.e., dividing big task into small parts to achieve functionality.
- 4. The core concept of modularization that means dividing program into functions is reusability.
- 5. Modification can easily be done because of modularization. Updation does not affect whole program only respective module will be affected.

### 6.1.2 Function Definition

- 1. Function Definition is a body of the function written outside the main function.
- 2. The function Definition has a function header statement with a body of statements enclosed within { and }
- 3. Function definition has two main components (1) First Line Function Header (2) Body of function enclosed with { }
- 4. The first header statement consists of type specification of the value returned by the function followed by function name and followed by ( )
- 5. Within ( ) round brackets, it can either be empty or it can have parameters or arguments with data type of each argument

**The Syntax of function definition is:**

```
return_type function name (no. of parameters/arguments with data types)
{
    c statement;   // Block code of statements //
    c statement;
    return statement;
}
```

**Return_type:** Every function returns a value after execution of block of statements, Return type can be of any data type such as int, double, char, void, short, etc. Normally, function return type is any datatype but if function does not return any value then we have to specify with void keyword to indicate function returns null value.

**Function_name:** Function name should be a valid identifier and function name should be a meaningful name so that it can be easy to understand the purpose of function just by seeing its name.

**Argument list/parameter list (type arg1, type arg2):** Arguments are also called parameters, parameter list contains variables names along with their data types. These arguments are positional formal/dummy parameters whose value can be replaced with actual parameter during function call. For example – A function which is used to add three integer variables, will have three integer arguments. All arguments are to be specified along with data type and are separated by commas.

**Block of code:** It is a Set or Block of C statements, which will be executed during function call. Function definition execution will be performed in a stack.

If function has return type, then return statement will be the last statement of a block and if function has no return type, i.e., void then this function will have no return statement.

*Let us assume an example to solve the problem of function*

**Problem 1: Write a Function for addition of two numbers**

**Solution:**

- 1. First decide a meaningful name for the function like sum or addition, etc…
- 2. Now decide function Header statement, I am considering function name as sum, return_type as integer, and number of arguments and their respective data type.

```
return_type sum(argument list)
```

sum function is going to add two integer variables, which means I need two integer variables as input. My function header/signature statement would be

```c
return_type sum(int num1, int num2)
```

The result of the sum of two integers would be integer only. Hence function should return an integer value

```c
int sum(int num1, int num2);
```

So you got your function prototype or signature. Since function header statement is the same as function prototype statement, only function prototype statement is terminated by a semicolon (;) sign.

### Function Definition of sum of two numbers with Return type:

```c
int sum (int a, int b)
{
    int c;
    c = a + b;
    return c;
}
```

### Problem 2: Write a Function to print entered number in even or odd

### Solution:

- 1. First decide a meaningful function name like even or evenno
- 2. Now decide function Header statement, I am considering function name as even, return_type and number of arguments and their respective data type.

```
return_type even(argument list)
```

even function is going to check single number hence one integer variable, which means I need one integer variable as input. My function header/signature statement would be

```c
return_type even(int a)
```

Since this function will not return any value. It returns msg whether number is even or odd, hence it will return null value or void.

```c
void even(int a);
```

So you got your function prototype or signature. Since function header statement is the same as function prototype statement, only function prototype statement is terminated by a semicolon (;) sign.

### Function definition of even number checking with No return type hence void:

```c
void even (int a)
{
    if (a%2 == 0)
        printf("a is even");
    else
        printf("a is odd");
}
```

### 6.1.3 Function Declaration

General syntax of function declaration (also known as function prototype) is,

**return-type function-name ( parameter-list ) ;**

Like a variable and an array, a function must also be declared before it is called. A function declaration tells the compiler about a function name and how to call the function. The actual body of the function can be defined separately. A function declaration consists of 4 parts.

- return-type
- function name
- parameter list
- terminating semicolon

**return-type**

return type specifies the type of value (int, float, char, double) that function is expected to return to the program calling the function. The return type must be void if no value is returned.

**function-name**

function name specifies the name of the function. The function name is any valid C identifier and therefore must follow the same rule of formation as other variables in C.

**parameter-list**

The parameter list declares the variables that will receive the data sent by calling program. They are often referred to as formal parameters. These parameters are also used to send values to a calling program.

Number of parameters of function declaration is the same as number of parameters in function call, i.e., formal parameters of function declaration should be same as actual arguments of function call statement.

**terminating semicolon**

Function declaration is a single line terminated by semicolon (;) sign.

### Examples of function prototype statement or function declaration

Function with three integer arguments and integer as return type is represented using below syntax

- `int sum(int,int, int);` OR
- `int sum( int a, int b, int c);`

Function with integer argument and integer as return type is represented using below syntax

- `int cube(int);`

In the below example we have written function with no argument and no return type

- `void display(void);`

In the below example we have declared function with no argument and integer as return type

- `int get(void);`

### 6.1.4 Function Call

- 1. It is a single statement which is to be written within a main function with actual parameters
- 2. Function can be accessed or called by specifying its name followed by list of arguments enclosed in parenthesis separated by a comma, if function doesn't require arguments then function name followed by empty parenthesis.
- 3. The arguments within a function are actual parameters or arguments. Exactly same number of parameters with same data type should be passed as a formal parameter to function prototype and function definition.
- 4. These actual parameters are linked with formal parameters in function definition to copy value of actual parameter to formal parameter.
- 5. The syntax of function call statement is if functions have return type:
  - `return variable = function name (parameters);`
  - Example: `s = sum(x, y);`
- 6. The syntax of function call statement is if function does not have return type, i.e., returning null value:
  - `function name (parameters);`
  - Example: `even(x);`
