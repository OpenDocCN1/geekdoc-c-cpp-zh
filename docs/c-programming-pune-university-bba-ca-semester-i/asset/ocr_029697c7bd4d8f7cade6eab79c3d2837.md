# ## 8.6 Nested Structure (Structures within Structures)

Nested structure in C is nothing but structure within structure. One structure can be declared inside other structure as we declare structure members inside a structure.

As the complexity of real world data items increases, it may happen that a structure variable would be defined as a member of another structure. In such situations, the declaration of the embedded structure must appear before the declaration of the outer structure. This is also called nested structure.

Let’s consider an example

```
```c
struct author{
    char first_name[15];
    char last_name[15];
};
struct book {
    char title[20];
    struct author book_author;
    int no_of_pages;
    float cost;
} cprog, basicprog;
