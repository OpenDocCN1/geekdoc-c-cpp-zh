# 8) Write a C program to perform Addition/Subtraction/Multiplication/Division operations using switch case statement.

# Algorithm:

+   Step 1: Start  
+   Step 2: Read variable n1 and n2  
+   Step 3: Display menu  
+   Step 4: Enter the option code  
+   Step 5: Evaluate option code with case statements  
+   &nbsp;&nbsp;&nbsp;&nbsp;5.1: case1 ans1 = n1 + n2, print ans1 . go to step7  
+   &nbsp;&nbsp;&nbsp;&nbsp;5.2: case2 ans1 = n1 − n2, print ans1 . go to step7  
+   &nbsp;&nbsp;&nbsp;&nbsp;5.3: case3 ans1 = n1 * n2, print ans1 . go to step7  
+   &nbsp;&nbsp;&nbsp;&nbsp;5.4: case4 ans2 = (float)n1/n2, print ans2 . go to step7  
+   Step 6: Entered case option is invalid code the print “Incorrect Choice”  
+   Step 7: Stop the program
