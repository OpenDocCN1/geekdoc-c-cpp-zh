The project has five steps:

+   1. Initiate the project in SAS Enterprise Guide 6.1.
+   2. Import and view the data.
+   3. Explore the data.
+   4. Segment and profile the data.
+   5. Perform correlation analysis.

# Project Initiation

Open the project (Figure 5.1) by double-clicking the SAS Enterprise Guide icon. Click **New Project**. You will see an area on the left called the **Project Tree**. The Project Tree is where you can track each process and output in the project. The **Process Flow** area on the right is where you will build your process, in the form of a flowchart.
