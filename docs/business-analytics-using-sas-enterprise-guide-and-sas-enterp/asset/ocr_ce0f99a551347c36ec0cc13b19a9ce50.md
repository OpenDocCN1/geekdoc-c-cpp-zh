# Segmentation and Profile Analysis

The next step is to partition the customer base by CUSTOMER_REVENUE to compare the characteristics of the customers with the highest revenue to the rest of the customers.

Highlight the DRM Customer Base data set and select **Task ▸ Describe ▸ Distribution Analysis**. A window will open in which you can select the variables. Click CUSTOMER_REVENUE and move it to the area below Analysis Variables (Figure 5.5). In the left-hand column, select **Tables**. Check the box next to **Quantiles**. Click **Run**.
