# Transform the Variables

In this section, you transform the distribution of the variables to create a better fit for the neural network and regression models. From the **Modify** tab, drag the **Transform Variables** icon (far right) onto the diagram and connect it to the Filter icon. Highlight the **Transform Variables** icon to unveil the Property window.

As shown in the **Property** window in Figure 9.12, change the default methods as follows: For **Interval Inputs**, select **Best**. This method tries several transformations and selects the best fit. For the **Class Inputs**, select **Dummy Indicators**. This option gives each level of the class variables values of 0 and 1.
