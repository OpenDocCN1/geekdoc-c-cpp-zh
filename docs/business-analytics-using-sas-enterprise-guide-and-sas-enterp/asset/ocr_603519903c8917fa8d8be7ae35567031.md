# Input the Data Source

Next, click on the **Create Data Source** node (upper left menu right under the word ‘Actions.’). The Data Source Wizard will open and ask you to locate a SAS Table. Click **Next ▶** and browse in the SASUSER library for the **DRL_CUSTOMER_DATA** data set. Once you locate the data, select the data and click **OK** (Figure 8.4).
