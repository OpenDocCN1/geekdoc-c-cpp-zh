Often, you have many functions that perform specific tasks. In such cases, it is often good to organize them into regions so that they can be collapsed and expanded as and when needed. Using this example, you can group all the methods — Method1(), Method2(), and Method3() — into a region using the #region and #endregion preprocessor directives:

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace TestDefine
{
    class Program
    {
        static void Main(string[] args)
        {
        }

        #region "Helper functions"

        private void Method1()
        {
            //---implementions here---
        }

        private void Method2()
        {
            //---implementions here---
        }

        private void Method3()
        {
            //---implementions here---
        }

        #endregion
    }
}
```
