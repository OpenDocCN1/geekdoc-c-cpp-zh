# Summary

This chapter has demonstrated how you can use Silverlight to build Rich Interactive Applications (RIAs).
At the time of writing, there are two versions of Silverlight — 1.0 and 2 — the key difference being the integration of the .NET Framework in Silverlight 2. To build the user interface of a Silverlight application, you can use the Microsoft Expression suite of applications, while the coding can be done using Visual Studio 2008.
