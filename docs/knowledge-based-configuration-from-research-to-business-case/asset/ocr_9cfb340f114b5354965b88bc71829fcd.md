# FIGURE 7.5

Breadth-first based search for conflicts on the basis of the minimal diagnoses Δ₁ = {c₁}, Δ₂ = {c₅}, and Δ₃ = {c₂, c₄}. The resulting minimal conflict sets are CS₁ = {c₁, c₂, c₅}, CS₂ = {c₁, c₄, c₅}.

![](bbox=[0.42, 0.37, 0.62, 0.585])

Due to the minimality of CS₁ we have exactly three different alternatives to resolve the conflict (by deleting one of its elements). The HSDAG algorithm is complete—all different alternatives to resolve the given conflicts are analyzed. For example, if we delete c₁ from CS₁, we have already determined our first diagnosis, Δ₁ = {c₁}. The second minimal cardinality diagnosis that can be derived from the HSDAG is Δ₂ = {c₅}. There is a third minimal diagnosis (which is not a minimal cardinality one): Δ₃ = {c₂, c₄}.

The HSDAG algorithm (Reiter, 1987) not only supports the determination of hitting sets in terms of diagnoses—given a predefined set of diagnoses we are also able to derive all corresponding minimal conflicts (see, e.g., Figure 7.5). Typical HSDAG implementations are based on a number of additional concepts that help to improve the performance of diagnosis (conflict set) detection.
