Definition (Configuration Task). A configuration task can be defined as a triple (C_KB, REQ, CLANG) where C_KB and REQ are sets of logical sentences and CLANG is a set of predicate symbols. C_KB represents the configuration model and REQ specifies particular system (customer) requirements.
