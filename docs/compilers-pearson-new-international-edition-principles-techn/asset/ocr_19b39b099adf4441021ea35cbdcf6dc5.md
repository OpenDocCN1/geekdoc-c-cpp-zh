# 9.8. SYMBOLIC ANALYSIS

The expression c₀ + c₁m(y) + c₂m(z) is intended to represent all the possible forms of expression involving arbitrary variables y and z that may appear on the right side of an assignment to x and that give x a value that is an affine transformation on prior values of variables. These expressions are: c₀, c₀ + y, c₀ − y, y + x, x − y, c₁ * y, and y/(1/c₁). Note that in many cases, one or more of c₀, c₁, and c₂ are 0.

**Example 9.60:** If the assignment is y=x+z, then c₀ = 0 and c₁ = c₂ = 1. If the assignment is x=y/5, then c₀ = c₂ = 0, and c₁ = 1/5.
