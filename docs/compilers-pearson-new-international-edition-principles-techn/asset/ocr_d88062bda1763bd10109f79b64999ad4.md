# 9.5. PARTIAL-REDUNDANCY ELIMINATION

|  | (a) Anticipated Expressions | (b) Available Expressions |
|---|---|---|
| Domain | Sets of expressions | Sets of expressions |
| Direction | Backwards | Forwards |
| Transfer function | $f_B(x)=e_{aseB}\cup(x-e_{killB})$ | $f_B(x)=(anticipated[B].in\cup x)-e_{killB}$ |
| Boundary | $IN[EXIT]=\varnothing$ | $OUT[ENTRY]=\varnothing$ |
| Meet ($\wedge$) | $\cap$ | $\cap$ |
| Equations | $IN[B]=f_B(OUT[B])$<br>$OUT[B]=\Lambda_{S,succ(B)}IN[S]$ | $OUT[B]=f_B(IN[B])$<br>$IN[B]=\Lambda_{P,pred(B)}OUT[P]$ |
| Initialization | $IN[B]=U$ | $OUT[B]=U$ |

|  | (c) Postponable Expressions | (d) Used Expressions |
|---|---|---|
| Domain | Sets of expressions | Sets of expressions |
| Direction | Forwards | Backwards |
| Transfer function | $f_B(x)=(earliest[B]\cup x)-e_{useB}$ | $f_B(x)=(e_{useB}\cup x)-latest[B]$ |
| Boundary | $OUT[ENTRY]=\varnothing$ | $IN[EXIT]=\varnothing$ |
| Meet ($\wedge$) | $\cup$ | $\cup$ |
| Equations | $OUT[B]=f_B(IN[B])$<br>$IN[B]=\Lambda_{P,pred(B)}OUT[P]$ | $IN[B]=f_B(OUT[B])$<br>$OUT[B]=\Lambda_{S,succ(B)}IN[S]$ |
| Initialization | $OUT[B]=U$ | $IN[B]=\varnothing$ |

$earliest[B]=anticipated[B].in-available[B].in$

$latest[B]=(earliest[B]\cup postponable[B].in)\cap$
