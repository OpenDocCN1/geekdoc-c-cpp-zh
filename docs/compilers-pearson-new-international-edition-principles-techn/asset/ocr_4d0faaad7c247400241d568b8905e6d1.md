# 3.4. RECOGNITION OF TOKENS

Fig. 3.19. The objective is that *b₁b₂···b<sub>f(s)</sub>* is the longest proper prefix of *b₁b₂···bₙ* that is also a suffix of *b₁b₂···bₙ*. The reason *f(s)* is important is that if we are trying to match a text string for *b₁b₂···bₙ*, and we have matched the first *s* positions, but then fail (i.e., the next position of the text string does not hold *b<sub>s+1</sub>*), then *f(s)* is the longest proper prefix of *b₁b₂···bₙ* that could possibly match the text string up to the point we are at. Of course, the next character of the text string must be *b<sub>f(s)+1</sub>*, or else we still have problems and must consider a yet shorter prefix, which will be *b<sub>f(f(s))</sub>*.

```
```text
1)  t = 0;
2)  f(1) = 0;
3)  for (s = 1; s < n; s++) {
4)      while (t > 0 && b₍s+1₎ != b₍t+1₎) t = f(t);
5)      if (b₍s+1₎ == b₍t+1₎) {
6)          t = t + 1;
7)          f(s + 1) = t;
        }
8)      else f(s + 1) = 0;
    }
```

Figure 3.19: Algorithm to compute the failure function for keyword *b₁b₂···bₙ*

As an example, the failure function for the trie constructed above for *ababaa* is:

|  | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---:|---:|---:|---:|---:|---:|
| *s* |  |  |  |  |  |  |
| *f(s)* | 0 | 0 | 1 | 2 | 3 | 1 |

For instance, states 3 and 1 represent prefixes *aba* and *a*, respectively. *f(3) = 1* because *a* is the longest proper prefix of *aba* that is also a suffix of *aba*. Also, *f(2) = 0*, because the longest proper prefix of *ab* that is also a suffix is the empty string.
