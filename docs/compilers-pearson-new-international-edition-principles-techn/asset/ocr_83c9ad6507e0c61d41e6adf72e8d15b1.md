```

| ```text
for (i=1; i<=N; i++)
    for (j=0; j<=M; j++)
        Z[i,j] =
            Z[i-1,j];
```
[示意图] | Permutation  
$\begin{bmatrix}p\\q\end{bmatrix}=\begin{bmatrix}0&1\\1&0\end{bmatrix}\begin{bmatrix}i\\j\end{bmatrix}$ | ```text
for (p=0; p<=M; p++)
    for (q=1; q<=N; q++)
        Z[q,p] = Z[q-1,p];
```
[示意图] |
| ```text
for (i=1; i<=N+M-1; i++)
    for (j=max(1,i-M); j<=min(i,M); j++)
        Z[i,j] =
            Z[i-1,j-1];
```
[示意图] | Skewing  
$\begin{bmatrix}p\\q\end{bmatrix}=\begin{bmatrix}1&-1\\0&1\end{bmatrix}\begin{bmatrix}i\\j\end{bmatrix}+\begin{bmatrix}0\\1\end{bmatrix}$ | ```text
for (p=1; p<=N; p++)
    for (q=1; q<=M; q++)
        Z[p,q-p] =
            Z[p-1,q-p-1];
```
