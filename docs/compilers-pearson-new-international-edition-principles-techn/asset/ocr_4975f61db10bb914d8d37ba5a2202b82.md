Intuitively, \(A \to \alpha\cdot B\beta\) in \(\mathrm{CLOSURE}(I)\) indicates that, at some point in the parsing process, we might next see a substring derivable from \(B\beta\) as input. The substring derivable from \(B\beta\) will have a prefix derivable from \(B\) by applying one of the \(B\)-productions. We therefore add items for all the \(B\)-productions; that is, if \(B \to \gamma\) is a production, we also include \(B \to \cdot\gamma\) in \(\mathrm{CLOSURE}(I)\).

**Example 4.40:** Consider the augmented expression grammar:

```
E' → E
E  → E + T | T
T  → T * F | F
F  → (E) | id
```

If \(I\) is the set of one item \(\{[E' \to \cdot E]\}\), then \(\mathrm{CLOSURE}(I)\) contains the set of items \(I_0\) in Fig. 4.31.
