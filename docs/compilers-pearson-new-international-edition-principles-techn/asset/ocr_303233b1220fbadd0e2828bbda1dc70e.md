# CHAPTER 8. CODE GENERATION

```
```text
LD  R1, y        // R1 = y
LD  R2, z        // R2 = z
SUB R1, R1, R2   // R1 = R1 - R2
ST  x, R1        // x = R1
```
```

We can do better, perhaps. One of the goals of a good code-generation algorithm is to avoid using all four of these instructions, whenever possible. For example, y and z may have been computed in a register, and if so we can avoid the LD step(s). Likewise, we might be able to avoid ever storing x if its value is used within the register set and is not subsequently needed.

Suppose a is an array whose elements are 8-byte values, perhaps real numbers. Also assume elements of a are indexed starting at 0. We may execute the three-address instruction b = a[i] by the machine instructions:

```
```text
LD  R1, i        // R1 = i
MUL R1, R1, 8    // R1 = R1 * 8
LD  R2, a(R1)    // R2 = contents(a + contents(R1))
ST  b, R2        // b = R2
```
```

That is, the second step computes 8i, and the third step places in register R2 the value in the ith element of a, the one found in the location that is 8i bytes past the base address of the array a.

Similarly, the assignment into the array a represented by three-address instruction a[j] = c is implemented by:

```
```text
LD  R1, c        // R1 = c
LD  R2, j        // R2 = j
MUL R2, R2, 8    // R2 = R2 * 8
ST  a(R2), R1    // contents(a + contents(R2)) = R1
```
```

To implement a simple pointer indirection, such as the three-address statement x = *p, we can use machine instructions like:

```
```text
LD  R1, p        // R1 = p
LD  R2, 0(R1)    // R2 = contents(0 + contents(R1))
ST  x, R2        // x = R2
```
```

The assignment through a pointer *p = y is similarly implemented in machine code by:

```
```text
LD  R1, p        // R1 = p
LD  R2, y        // R2 = y
ST  0(R1), R2    // contents(0 + contents(R1)) = R2
```
