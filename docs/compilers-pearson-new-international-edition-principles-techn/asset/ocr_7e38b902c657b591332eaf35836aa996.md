```
stmt  →  id = expression ;
        |  if ( expression ) stmt
        |  if ( expression ) stmt else stmt
        |  while ( expression ) stmt
        |  do stmt while ( expression );
        |  { stmts }

stmts →  stmts stmt
        |  ε
```
