Upon entry to block $B_2$, $a$ has value 0 in the first iteration and increments by one in each subsequent iteration of the outer loop. Thus $a$ has value $i-1$ at the entry of the $i$th iteration and value $i$ at the end. The symbolic map at the entry of $B_2$ maps variables $b$, $c$, $d$ to NAA, because the variables have unknown values on entry to the outer loop. Their values depend on the number of iterations of the outer loop, so far. The symbolic map on exit from $B_2$ reflects the assignments to $a$, $b$, and $c$ in that block.
