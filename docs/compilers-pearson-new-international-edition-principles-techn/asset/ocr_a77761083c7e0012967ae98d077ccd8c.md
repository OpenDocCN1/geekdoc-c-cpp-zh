First, $R_2$ has no predecessors within $R_6$; remember that the edge $B_4 \rightarrow B_2$ goes outside $R_6$. Thus, $f_{R_6,\mathrm{IN}[B_2]}$ is the identity function,¹¹ and $f_{R_6,\mathrm{OUT}[B_2]}$ is the transfer function for block $B_2$ itself.

The header of region $B_3$ has one predecessor within $R_6$, namely $R_2$. The transfer function to its entry is simply the transfer function to the exit of $B_2$, $f_{R_6,\mathrm{OUT}[B_2]}$, which has already been computed. We compose this function with the transfer function of $B_3$ within its own region to compute the transfer function to the exit of $B_3$.

Last, for the transfer function to the entry of $R_4$, we must compute

$$f_{R_6,\mathrm{OUT}[B_2]} \wedge f_{R_6,\mathrm{OUT}[B_3]}$$

because both $B_2$ and $B_3$ are predecessors of $B_4$, the header of $R_4$. This transfer function is composed with the transfer function $f_{R_4,\mathrm{OUT}[B_4]}$ to get the desired function $f_{R_6,\mathrm{OUT}[B_4]}$. Notice, for example, that $d_3$ is not killed in this transfer function, because the path $B_2 \rightarrow B_4$ does not redefine variable $a$.

Now, consider loop region $R_7$. It contains only one region $R_6$ which represents its loop body. Since there is only one back edge, $B_4 \rightarrow B_2$, to the header of $R_6$, the transfer function representing the execution of the loop body 0 or more times is just $f_{R_6,\mathrm{OUT}[B_4]}$: the gen set is ${d_4, d_5, d_6}$ and the kill set is $\emptyset$. There are two exits out of region $R_7$, blocks $B_3$ and $B_4$. Thus, this transfer function is composed with each of the transfer functions of $R_6$ to get the corresponding transfer functions of $R_7$. Notice, for instance, how $d_6$ is in the gen set for $f_{R_7,\mathrm{OUT}[B_3]}$ because of paths like $B_2 \rightarrow B_4 \rightarrow B_2 \rightarrow B_3$, or even $B_2 \rightarrow B_3 \rightarrow B_4 \rightarrow B_2 \rightarrow B_3$.

Finally, consider $R_8$, the entire flow graph. Its subregions are $R_1$, $R_7$, and $R_5$, which we shall consider in that topological order. As before, the transfer function $f_{R_8,\mathrm{IN}[B_1]}$ is simply the identity function, and the transfer function $f_{R_8,\mathrm{OUT}[B_1]}$ is just $f_{R_1,\mathrm{OUT}[B_1]}$, which in turn is $f_{B_1}$.

The header of $R_7$, which is $B_2$, has only one predecessor, $B_1$, so the transfer function to its entry is simply the transfer function out of $B_1$ in region $R_8$. We compose $f_{R_8,\mathrm{OUT}[B_1]}$ with the transfer functions to the exits of $B_2$ and $B_4$ within $R_7$ to obtain their corresponding transfer functions within $R_8$. Lastly, we consider $R_5$. Its header, $B_5$, has two predecessors within $R_8$, namely $B_3$ and $B_4$. Therefore, we compute $f_{R_8,\mathrm{OUT}[B_3]} \wedge f_{R_8,\mathrm{OUT}[B_4]}$ to get $f_{R_8,\mathrm{IN}[B_5]}$. Since the transfer function of block $B_5$ is the identity function, $f_{R_8,\mathrm{OUT}[B_5]} = f_{R_8,\mathrm{IN}[B_5]}$.
