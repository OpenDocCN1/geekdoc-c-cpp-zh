Layer 2: Aggregation of the truth values of the conditions of Rule $i$,

$$\tau_{A_i}(a_i)=\sup\{\tau_{A_i}(a_{i1})\land\cdots\land\tau_{A_i}(a_{in})\}$$

Layer 3: Deduction of the conclusion from Rule $i$,

$$\mu_{B_j}^{3}(y)=\sup\{\tau_{A_i}(a_i)\land I_i(a_i,\mu_{B_j}(y))\}$$

Layer 4: Combination of the conclusions derived from all the rules,

$$\mu_{B_j}^{4}(y)=\operatorname{comb}\{\mu_{B_1}(y)\land\cdots\land\mu_{B_m}(y)\}$$

In the above equations $\tau_{A_{ij}}(x_i)$, $\tau_{A_i}(a_i)$, and $\mu_{B_j}(y)$, respectively represent the truth value of the condition “$x_i$ is $A_{ij}$” of rule $i$, the truth value of the condition part of rule $i$, and the conclusion derived from rule $i$. Besides, the functions $I_i$ and $comb$ respectively represent the function characterizing the implication function of rule $i$, and the global combination function.
