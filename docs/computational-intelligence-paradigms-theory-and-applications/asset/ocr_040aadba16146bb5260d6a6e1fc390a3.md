+   - GAs are well suited for complex, discontinuous, noisy fitness functions.
+   - GAs do not require computation of partial derivatives and they also do not require a problem to be linearised.
+   - Since GAs efficiently search the global space, they are capable of converging to the local minima effectively.

**Solution:**
The basic genetic algorithm is used to maximize the given function. To refresh, the algorithm is as follows:

+   1. Step 1. Create an initial population (usually a randomly generated string).
+   2. Step 2. Evaluate all of the individuals (apply some function or formula to the individuals).
+   3. Step 3. Select a new population from the old population based on the fitness of the individuals as given by the evaluation function.
+   4. Step 4. Apply genetic operators (mutation and crossover) to members of the population to create new solutions.
+   5. Step 5. Evaluate these newly created individuals.
+   6. Step 6. Repeat steps 3-6 (one generation) until the termination criteria has been satisfied (usually perform for a certain fixed number of generations).
