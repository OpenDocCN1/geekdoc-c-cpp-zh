以下为两种情况描述，请在符合企业情况描述的括号中填写该项目利润率为低或高(填写低或高即可)。

A. 若该项目的窗口期或排他期在3个月以内，与客户的合作期3年以上、且金额≥1000万元，项目利润可观。( )

B. 若该项目的实施周期在3个月以上，与客户的合作期3年以下、且金额＜1000万元，项目利润可能有限。( )
