# ### 3.2 Layered Architectures

Before dealing with the architecture and algorithms of the types of neural networks, let us understand the basic architecture based on the number of layers in the network. The network is classified into single layer and multi layer based on the layers in the architecture.

# ### 3.2.1 Single-Layer Networks
