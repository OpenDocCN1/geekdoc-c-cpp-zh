Construction of the Distance Matrix by using Distance measurement formula

```
```matlab
distmatx = zeros(num_cities);
for ii = 2:num_cities
    for jj = 1:ii-1
        distmatx(ii, jj) =
            sqrt(sum((cities(ii, :) - cities(jj, :)).^2));
        distmatx(jj, ii) = distmatx(ii, jj);
    end
end
```

end
