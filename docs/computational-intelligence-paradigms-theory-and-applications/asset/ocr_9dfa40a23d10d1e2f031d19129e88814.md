# Illustrations on Search Space, hypercubes, schemata and Gray Codes

Illustration 5:
Suppose we deal with a 'Simple GA' which uses bit-strings of
length L for chromosomes.

+   1. Why is the representation of the search space of size 2L by
+   a hypercube more appropriate than a 'linear representation'.

```
Linear Representation

00 ... 00|00 ... 01|00 ... 10| ... |01 ... 10| ... |11|10 ... 00| ...
```

Solution:

Properties of hypercube:

+   (i) d-dimensional hypercube: 2 (d-1)-dimensional hypercubes

+   (ii) every node is connected to or has as neighbors all other nodes for
+   which the bit-representation differs at only 1 position. (Hamming
+   distance 1)
