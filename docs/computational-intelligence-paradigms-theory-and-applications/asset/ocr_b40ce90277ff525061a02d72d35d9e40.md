# Incremental Rule Learning

In this learning process the rule base is developed from scratch by adding rule after rule. The rule bases developed by classifying an input vector initially, i.e., finding the membership function corresponding to each variable that generates the highest membership value for the respective input value, thus forming a rule antecedent.
