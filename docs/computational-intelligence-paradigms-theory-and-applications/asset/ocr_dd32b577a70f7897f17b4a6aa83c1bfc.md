While constructing trees the first issue that has to be considered is to determine the binary splits of the parent node. The node splitting criteria is used to determine the binary splits.

# 9.5.2 Node Splitting Criteria

The algorithm of finding splits of nodes to produce a purer descendant is shown in Figure 9.12:

+   - Let p denote the proportions of the class.
+   - Let t be the root node.

+   1. Step 1: The node proportions are defines as p(j→t), where the proportions are belonging to a class j.
+   2. Step 2: The node impurity measure of node t is defined as i(t) as a nonnegative function φ.
+   
+      Let Δ denote the candidate split of a node t, such that the split divides node t into t_left and t_right. The measure of split is now defined as Δi(t) = i(t) - p_left i(t_left) - p_right i(t_right).
+   
+   3. Step 3: Define the set of binary splits such that the candidate split sends all values in t having a “true value” to t_left and all values in t having a “false value” to t_right.

At each node CART solves the maximization problem given as max{i(t) - p_left i(t_left) - p_right i(t_right)}.
