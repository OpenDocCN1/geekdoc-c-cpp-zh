# Application Procedure

The parameters used are,

+   - n – number of input nodes (input vectors)
+   - m – number of output nodes (exemplar vectors)
+   - e(j) – jth exemplar vector

The pseudocode of the application procedure is as follows:

```
Initialize weights for storing m exemplar vectors
wᵢⱼ = eᵢ(j)/2, (i=1..n, j=1..m)
Initializing the bias
bⱼ = n/2 (j=1..m)
For each vector x
    Compute the net input to each unit yⱼ
    Y_inⱼ = bⱼ + ∑ᵢ₌₁ⁿ xᵢwᵢⱼ
    Initialize activations for Max Net
yⱼ(0) = y_inⱼ (j=1,..m)
Max net iterates to find the best match exemplar
End For
```

The Hamming network is more advantageous when compared with the Hopfield network. Hamming applies the optimum minimum error classifier to classify the input vectors when input bit errors are stochastic.
