# Architecture

The architecture of Boltzmann machine is shown in Figure 4.8.

The architecture of the Boltzmann machine looks like a two-dimensional array. It consists of a set of units and a set of bidirectional connections between a pair of units. The units in each row and column are fully interconnected. The weights on each connection are p and there is also a self-connection with weight b. The units are labeled as V+i,j.
