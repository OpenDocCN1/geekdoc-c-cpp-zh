For bipolar vector, the activation function for Y-layer is

$$y_j = \begin{cases} 1, & \text{if } y_{inj} > \theta_j \\ y_j, & \text{if } y_{inj} = \theta_j \\ 1, & \text{if } y_{inj} < \theta_j \end{cases}$$

and the activation layer for the X-layer is

$$x_i = \begin{cases} 1, & \text{if } x_{inj} > \theta_i \\ x_i, & \text{if } x_{inj} = \theta_i \\ 1, & \text{if } x_{inj} < \theta_i \end{cases}$$

If the net input is equal to the threshold value, the activation function decides to leave the activation of that unit at its previous value. In the above $\theta_i$, indicates the threshold value.

# Continuous BAM

The continuous BAM was introduced by Kosko in 1988. A continuous bidirectional associative memory has the capability to transfer the input smoothly and continuously into the respective output range between [0,1]. The continuous BAM uses logistic sigmoid function as the activation function for all units.

For binary input vectors $(s(p),t(p)), p=1,2,\ldots,P$, the weights are determined by the formula.

$$w_{ij}=\sum_p (2s_i(p)-1)(2t_j(p)-1)$$
