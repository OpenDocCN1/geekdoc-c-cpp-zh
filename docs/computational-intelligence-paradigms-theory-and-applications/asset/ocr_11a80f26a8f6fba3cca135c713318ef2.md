A continuous t-norm that satisfies subidempotency is called an “Archimedean t-norm”; if it also satisfies strict monotonicity, it is called a “strict Archimedean t-norm”.

*Theorem 6.9:* The Standard Fuzzy Intersection is the only idempotent t-norm.

The following are examples of some t-norms that are frequently used as fuzzy intersections (each defined for all a,b in [0,1]).

+   - Standard intersection: i(a,b) = min(a,b)
+   - Algebraic product: i(a,b) = ab
+   - Bounded difference: i(a,b) = max(0,a+b-1)
+   - Drastic intersection: i(a,b) =
+     - a when b=1
+     - b when a=1
+     - 0 otherwise

The drastic intersection is also denoted Imin(a,b). The full range of all fuzzy intersections, i(a,b) is specified in the next theorem.

*Theorem 6.10:* for all a,b in [0,1],

I_min(a,b) ≤ i(a,b) ≤ min(a,b)
