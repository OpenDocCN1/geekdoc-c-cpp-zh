# D.36  ART*Enterprise

ART*Enterprise is the latest of the family of rule-based development environments originating with ART in the mid-1980s. It is a development environment for enterprise-wide applications, incorporating rules, a full object system which includes features currently not present in C++ or Smalltalk, and a large collection of object classes for UI development across platforms (from Windows to OS/2 to Unix), access to databases (SQL-based and ODBC-based), and multi-person development. The ART*Enterprise environment provides a forward chaining engine where backward chaining can be implemented, though it is not supported directly. ART*Enterprise also provides a CBR kernel for those who are interested in incorporating it into their applications.

Available at: http://www.brightware.com/
