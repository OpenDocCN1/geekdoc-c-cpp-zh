## 6.6.3 MATLAB Code to Simulate Membership Functions

### Triangular Membership Function

```matlab
y = trimf(x,params)
y = trimf(x,[a b c])
```

The triangular curve is a function of a vector, x, and depends on three scalar parameters a, b, and c, as given in Eq. (6.3) and more compactly, by

$$f(x; a,b,c)=\max\left(\min\left(\frac{x-a}{b-a},\frac{c-x}{c-b}\right),0\right)$$

The parameters a and b locate the “feet” of the triangle and the parameter c locates the peak.

**Code**

```matlab
% Triangular membership function
x=0:0.1:10;
y=trimf(x,[3 6 8]);
plot(x,y)
xlabel('trimf, P=[3 6 8]');
title('Triangular Membership Function');
```

**Output**

### Trapezoidal Membership Function

**Syntax**

```matlab
y = trapmf(x,[a b c d])
```

The trapezoidal curve is a function of a vector, x, and depends on four scalar parameters a, b, c, and d, as given by Eq. (6.7) or, more compactly, by

$$f(x;a,b,c,d)=\max\left(\min\left(\frac{x-a}{b-a},1,\frac{d-x}{d-c}\right),0\right)$$

The parameters a and d locate the “feet” of the trapezoid and the parameters b and c locate the “shoulders.”

**Code**

```matlab
% Trapezoidal membership function
x=0:0.1:10;
y=trapmf(x,[1 3 5 9]);
plot(x,y)
xlabel('trapmf, P=[1 3 5 9]')
```

## 6.6.4 Translation of Parameters between Membership Functions Using MATLAB

To translate parameters between membership functions a function “mf2mf” is available in MATLAB Fuzzy Logic Toolbox. The general syntax of this function is

```matlab
outParams = mf2mf (inParams, inType, outType)
```

where

- `inParams` - the parameters of the membership function to be transformed
- `inType` - a string name for the type of membership function to be transformed
- `outType` - a string name for the new membership function

The following code translates the polynomial Z curve membership function into triangular membership function.

```matlab
x=0:0.1:5;
mfp1 = [1 2 3];
mfp2 = mf2mf(mfp1,'zmf','trimf');
plot(x,zmf(x,mfp1),x,trimf(x,mfp2))
```

## 6.7 Singletons

Strictly speaking, a fuzzy set D is a collection of ordered pairs

$$A=\{(x,\mu(x))\} \tag{6.11}$$

Item x belongs to the universe and μ(x) is its grade of membership in A. A single pair (x,μ(x)) is called a fuzzy singleton; therefore the entire set can be considered as the union of its constituent singletons. It is often convenient to think of a set A just as a vector

$$a = (\mu(x_1), \mu(x_2), \mu(x_3), \ldots, \mu(x_n)) \tag{6.12}$$

It is understood then, that each position i (1,2,3,...,n) corresponds to a point in the universe of n points.

## 6.8 Linguistic Variables

Just like an algebraic variable takes numbers as values, a linguistic variable takes words or sentences as values. The set of values that it can take is called its term set. Each value in the term set is a fuzzy variable defined over a base variable. The base variable defines the universe of discourse for all the fuzzy variables in the term set. In short, the hierarchy is as follows: linguistic variable → fuzzy variable → base variable.

### Illustration 4 (term set)

Let x be a linguistic variable with the label “Age”. Terms of this linguistic variable, which are fuzzy sets, could be “old”, “young”, “very young” from the term set.

$$T = \{Old, Very Old, Not So Old, More or Less Young, Quite Young, Very Young\}$$

Each term is a fuzzy variable defined on the base variable, which might be the scale from 0 to 100 years.
