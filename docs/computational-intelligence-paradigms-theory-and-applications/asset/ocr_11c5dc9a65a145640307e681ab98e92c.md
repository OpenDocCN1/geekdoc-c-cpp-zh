# Operation

The network starts by clamping the input at F1. Because the output of F2 is zero, G1 and G2 are both on and the output of F1 matches its input. The pattern sent to F2, and in F2 one or more neurons become active. This signal is then sent back over the backward LTM, which reproduces a binary pattern at F1. G1 is inhibited, and only the neurons in F1 which receive a ‘one’ from both x and F2 remain active. If there is a substantial mismatch between the two patterns, the reset signal will inhibit the neuron in F2 and the process is repeated.

# Training Algorithm

The parameters used in the training algorithm are

+   - **n:** Number of components in the input vector
+   - **m:** Maximum number of clusters that can be formed
+   - **bᵢⱼ:** bottom-up weights (from F1 (b) to F2 unit)
+   - **tᵢⱼ:** top-bottom weights (from F2 to F1 (b) units)
+   - **ρ:** vigilance parameter
+   - **s:** binary input vector
+   - **x:** activation vector for interface layer (F1 (b) layer (binary))
+   - **‖x‖:** norm of vector x (sum of the components xᵢ)
