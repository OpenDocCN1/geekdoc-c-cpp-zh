# % MATLAB code to compute R³ using max product composition

```
R=[0.1 0.8 0.5 0.6 0.7; 0.8 1 0.4 0 0.2; 0.1 0.5 0.3 1 0.5; 0.7 0.5 0.2 1 0.3; 0.2 0.9 0.5 0.3 1]
[x,y]=size(R);
R2=zeros(x,y); R3=zeros(x,y);
for i=1:x, % for each row of R matrix
for j=1:y, % for each column of R matrix
R2(i,j)=max(R(i,:).*R(:,j)');
End
end
for i=1:x, % for each row of R matrix
for i=1:x, % for each row of R matrix
for j=1:y, % for each column of R matrix
R3(i,j)=max(R2(i,:).*R(:,j)');
end
end
```
