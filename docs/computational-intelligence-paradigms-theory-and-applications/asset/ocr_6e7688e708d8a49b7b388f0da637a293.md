A nonlinear multilayer network is capable of providing more computational potential compared to a single layer network. For example, the difficulties found in the perceptron network can be overcome with the addition of hidden layers; Figure 3.3 demonstrates a multilayer network that symbolizes the XOR function. The threshold is set to zero, and therefore a unit responds if its activation is greater than zero. The weight matrices for the two layers are

W₁ = ( 1  -1 ; -1  1 ), W₂ = ( 1 ; 1 ).

We thus get

W₁ᵀ(1, 0) = (1, 0), W₂ᵀ(1, 0) = 1,<br>W₁ᵀ(0, 1) = (0, 1), W₂ᵀ(0, 1) = 1,<br>W₁ᵀ(1, 1) = (0, 0), W₂ᵀ(1, 1) = 0,<br>W₁ᵀ(0, 0) = (0, 0), W₂ᵀ(0, 0) = 0.

With input vector (1,0) or (0,1), the output produced at the outer layer is 1; otherwise it is 0.
