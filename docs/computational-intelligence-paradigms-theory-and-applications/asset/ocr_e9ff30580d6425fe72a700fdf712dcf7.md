# Cart and Pole Simulation

The cart and pole simulation is an example of an FIS model auto-generated by the Fuzzy Logic Controller block. Type slc at the MATLAB prompt to open the simulation. The model in Figure 8.12 appears. Right-click on the Fuzzy Logic Controller block and select Look under mask from the right-click menu. The subsystem shown in Figure 8.13 opens.

Follow the same procedure to look under the mask of the FIS Wizard subsystem to see the implementation of the FIS. The Fuzzy Logic Controller block uses built-in Simulink blocks to implement the FIS. Although the models can grow complex, this representation is better suited than the S-function sfis for efficient code generation.
