```
    If y_j ≠ t_j,
        w_ij(new) = w_ij(old) + αt_jx_i
        b_j(new) = b_j(old) + αt_j
    else
        w_i(new) = w_i(old)
        b(new) = b(old)

    End If
End For
End While
```

# Perceptron Testing Algorithm for several output classes

The pseudocode of the testing algorithm for the single layer perceptron with several output classes is given as follows

```
Set the weights from the training algorithm
For each input vector x
    Compute the response of output unit:
        y-in_j = Σ_i x_i w_i
        y = f(y-in_j) = {
            1,   if y-in_j > θ
            0,   if -θ ≤ y-in_j ≤ θ
            -1,  if y-in_j < -θ
        }
End For
End
```
