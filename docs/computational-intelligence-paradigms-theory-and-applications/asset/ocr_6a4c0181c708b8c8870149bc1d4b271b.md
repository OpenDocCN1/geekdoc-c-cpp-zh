# Γ Function

The membership definition for a -function is given as:

$$A(x) = \begin{cases} 0, & if x \le a \\ 1 - e^{-k(x-a)^2} & if x < a \end{cases} \quad (6.5)$$

or

$$A(x) = \begin{cases} 0, & if x \le a \\ \frac{k(x-a)^2}{1+k(x-a)^2}, & if x > a \end{cases}$$

where k>0.

# S-Function

The membership definition for a S-function is given as:

$$A(x) = \begin{cases} 0, & if x \le a \\ 2(\frac{x-a}{b-a})^2, & if x \in [a, m] \\ 1-2(\frac{x-b}{b-a})^2, & if x \in [m, b] \\ 1, & if x > b \end{cases} \quad (6.6)$$

The point m=a+b/2 is known as the crossover of the S-function.

# Trapezoidal function

The membership definition for a trapezoidal function is given as:

$$A(x) = \begin{cases} 0, & if x \le a \\ \frac{x-a}{b-a}, & if x \in [a, b] \\ 1, & if x \in [b, c] \\ \frac{d-x}{d-c}, & if x \in [c, d] \\ 0, & if x \ge b \end{cases} \quad (6.7)$$

Using equivalent notation, we obtain

$$A(x;a,m,n,b)max\{min[(x-a)/(m-a),1,(b-x)/(b-m)],0\} \quad (6.8)$$

# Gaussian Function

The membership definition for a Gaussian function is given as:

$$A(x) = -e^{\frac{(x-c)^2}{2\sigma^2}}, \text{where } 2\sigma^2 > 0. \quad (6.9)$$
