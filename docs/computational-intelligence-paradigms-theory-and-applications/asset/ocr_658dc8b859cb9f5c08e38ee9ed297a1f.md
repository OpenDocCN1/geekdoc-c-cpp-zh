where,
x is the vector activation of input units.
y_{in} is the net input to output unit, −Σ x.w_1
t is the target vector, α is the learning rate

The derivation is as follows,
The mean square error of a particular training pattern is $E=\Sigma_j(t_j- y_{inj})^2$
The gradient of $E$ is a vector consisting of the partial derivatives of $E$ with respect to each of the weights. The error can be reduced rapidly by adjusting weight $W_{IJ}$.

Taking partial derivation of $E$ w.r.t. $W_{IJ}$

$$\frac{\partial E}{\partial W_{IJ}} = \frac{\partial \Sigma_i(t_j - y_{inj})^2}{\partial W_{IJ}}$$
$$= \frac{\partial (t_j - y_{inj})^2}{\partial W_{IJ}}$$

Since the weight $W_{IJ}$ influences the error only at the input unit $y_J$. Also,

$$y_{inJ} = \Sigma_{i=1}^{n}(t_j - y_{inj})^2$$

we get,

$$\frac{\partial E}{\partial W_{IJ}} = \frac{\partial E(t_j - y_{inj})^2}{\partial W_{IJ}}$$
$$= 2(t_j - y_{inj})(-1)\frac{\partial(y_{inj})}{\partial W_{IJ}}$$
$$\frac{\partial E}{\partial W_{IJ}} = -2(t_j - y_{inj})\frac{\partial(y_{inj})}{\partial W_{IJ}}$$
$$\frac{\partial E}{\partial W_{IJ}} = -2(t_j - y_{inj})x_I$$

Thus the error will be reduced rapidly depending upon the given learning by adjusting the weights according to the Delta rule given by,

$$\Delta W_{IJ} = \alpha(t_j - y_{inj})x_I$$

# **Delta Rule for Several Output Units**

The derivation of Delta Rule of several output units is similar to that in the previous section. The weights are changed to reduce the difference between net input and target.
The weight correction involving Delta Rule for adjusting the weight from the Ith input unit to the Jth output unit is,

$$\Delta W_{IJ} = \alpha(t_j - y_{inj})x_I$$

# **Extended Delta Rule**

This also can be called a generalized Delta Rule. The update for the weight from the Ith input unit to the Jth output unit is,

$$\Delta W_{IJ} = \alpha(t_j - y_{inj})x_I x_I f'(y_{in} - J)$$
