# ## 21.10 Pointer-Based String Manipulation Functions

The string-handling library provides many useful functions for manipulating string data, comparing strings, searching strings for characters and other strings, tokenizing strings (separating strings into logical pieces such as the separate words in a sentence) and determining the length of strings. This section presents some common string-manipulation functions of the string-handling library (from the C++ standard library). | Function prototype | Function description |
| --- | --- |
| `char *strcpy( char *s1, const char *s2 );` | Copies the string s2 into the character array s1. The value of s1 is returned. |
| `char *strncpy( char *s1, const char *s2, size_t n );` | Copies at most n characters of the string s2 into the character array s1. The value of s1 is returned. |
