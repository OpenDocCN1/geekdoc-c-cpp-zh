## Section 4.11 Assignment Operators

- The arithmetic operators `+=`, `-=`, `*=`, `/=`, and `%=` abbreviate assignment expressions.

## Section 4.12 Increment and Decrement Operators

- The increment operator, `++`, and the decrement operator, `--`, increment or decrement a variable by 1, respectively. If the operator is prefixed to the variable, the variable is incremented or decremented by 1 first, then its new value is used in the expression in which it appears. If the operator is postfixed to the variable, the variable is first used in the expression in which it appears, then the variable’s value is incremented or decremented by 1.

## 4.5

See the following code:

```cpp
// Exercise 4.5 Solution: ex04.05.cpp
// Calculate the sum of the integers from 1 to 10.
#include <iostream>
using namespace std;

int main()
{
    int sum; // stores sum of integers 1 to 10
    int x; // counter

    x = 1; // count from 1
    sum = 0; // initialize sum

    while ( x <= 10 ) // loop 10 times
    {
        sum += x; // add x to sum
        ++x; // increment x
    } // end while

    cout << "The sum is: " << sum << endl;
} // end main
```

The sum is: 55
