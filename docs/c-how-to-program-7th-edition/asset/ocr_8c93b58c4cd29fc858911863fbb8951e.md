# ### 5.3  for Repetition Statement

In addition to `while`, C++ provides the `for` repetition statement, which specifies the counter-controlled repetition details in a single line of code. To illustrate the power of `for`, let’s rewrite the program of Fig. 5.1. The result is shown in Fig. 5.2.

```
```cpp
// Fig. 5.2: fig05_02.cpp
// Counter-controlled repetition with the for statement.
#include <iostream>
using namespace std;

int main()
{
   // for statement header includes initialization,
   // loop-continuation condition and increment.
   for (int counter = 1; counter <= 10; counter++)
      cout << counter << " ";

   cout << endl; // output a newline
} // end main
```

When the `for` statement (lines 10–11) begins executing, the control variable `counter` is declared and initialized to 1. Then, the loop-continuation condition (line 10 between the semicolons) `counter <= 10` is checked. The initial value of `counter` is 1, so the condition is satisfied and the body statement (line 11) prints the value of `counter`, namely 1. Then, the expression `counter++` increments control variable `counter` and the loop begins again with the loop-continuation test.
