# 1.2 Line Widths

Rules:

+   a. The width of all lines in a program shall be limited to a maximum of 80 characters.

Reasoning: From time-to-time, peer reviews and other code examinations are conducted on printed pages. To be useful, such print-outs must be free of distracting line wraps as well as missing (i.e., past the right margin) characters. Line width rules also ease on-screen side-by-side code differing.

Enforcement: Violations of this rule shall be detected by an automated scan during each build.
