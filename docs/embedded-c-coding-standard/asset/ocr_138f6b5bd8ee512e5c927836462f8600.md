# Example:

```
int
state_change (int event)
{
    int result = ERROR;

    if (EVENT_A == event)
    {
        result = STATE_A;
    }
    else
    {
        result = STATE_B;
        return (result);
    }
}
```

**Reasoning:** Code reviews take place at the function level and often on paper. Each function should ideally be visible on a single printed page, so that flipping papers back and forth does not distract the reviewers.

Multiple return statements should be used only when it improves the readability of the code.

**Enforcement:** Compliance with these rules shall be checked during code reviews.
