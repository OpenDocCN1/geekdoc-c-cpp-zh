Besides adding a WHERE clause, the next program also shows how to distinguish between two columns both having a heading of Subj. Finally, this next program uses a simpler method of naming the two Subj variables in the SELECT clause. Here is it:

# Program 26.6: Using Simplifying Naming Variables

```
title "Matching Subj Numbers from Both Tables";nproc sql;
    select H.Subj as Subj_Health,
         D.Subj as Subj_Demog,
         Height,
         Name,
         Gender
    from Learn.Health as H,
         Learn.Demographic as D
    where H.Subj eq D.Subj;
;
```

First take a look at THE FROM clause. To make it to name variables with the same name from different tables, you use aliases for each of them, H and D, in this program. You can use these aliases as a prefix in the SELECT clause (H.Subj) and D.Subj).
