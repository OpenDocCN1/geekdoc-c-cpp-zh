proc format;
  invalue ReadGrade (upscase)
    'A' = 95
    'B' = 85
    'C' = 75
    'F' = 65
    other = same_;

run;

# 22.6 Using Formats (and Inormats) to Perform Table Lookup

Table lookup is a process where one or more data values are used to retrieve a value for another variable. For example, given an item number from catalog, you might want to retrieve a product name and a price.

SAS provides you with a variety of ways to perform a table lookup, such as a data merge, a key value from an index, an array, a format hash, or an informat.
