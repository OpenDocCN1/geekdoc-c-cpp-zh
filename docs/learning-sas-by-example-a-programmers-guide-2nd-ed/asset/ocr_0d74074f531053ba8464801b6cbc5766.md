The OUTPUT option AUTNAME is quite useful, and it creates consistent and easy-to-understand variable names. Be aware that the suffix used for standard deviation is StdDev and not the abbreviation Std that is commonly used. Also remember that variable names cannot be longer than 32 characters—this includes the suffix that PROC MEANS adds. Although it is unlikely, adding the suffix causes the variable name to exceed 32 characters, the original variable name will be truncated.

# 16.10 Outputting a Summary Data Set: Including a BY Statement

Although there are many uses for a summary data set containing summary statistics on an entire data set, there are times when you would like to output statistics for each level of or more classifications. For example, you might want to see n's and many of RBC and WBC down by gender. Remember to use a BY statement, the data must be sorted in the same order. Program 16.9 creates a summary data set containing the mean of RBC and WBC for males and females.

Program 16.9: Adding a BY Statement to PROC MEANS

```
proc sort data=Learn.Blood out=Blood;
  by Gender;
run;

proc means data=Blood noprint;
  by Gender;
  var RBC WBC;
  output out = By_Gender
    mean = / autoname;
run;
```
