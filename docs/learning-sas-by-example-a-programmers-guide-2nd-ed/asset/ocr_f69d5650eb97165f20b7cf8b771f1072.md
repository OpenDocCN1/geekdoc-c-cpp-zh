Using the Sales data set, you want to see totals for Quantity and TotalSales at the bottom of the report. The following program produces this report:

# Program 15.14: Requesting a Report Break (REBREAK)

```
title "Producing Report Breaks";
proc report data=Learn.Sales;
column Region Quantity order width=6;
define Region / order width=8 format=comma;
define TotalSales / sum "Total Sales" width=9
format=dollar9;
break after / summarize;
run;
```

Following the keyword REBREAK is a location, either BEFORE or AFTER. BEFORE places the summary statistics at the beginning of the report, AFTER places them at the end. The option DEFINE prints a statistic (the one requested in the DEFINE statements) at the top or bottom of the SUMMARY (depending on whether you request the break before or after).
