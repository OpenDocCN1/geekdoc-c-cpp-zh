Here is a program to read this data file and create a temporary SAS data set called Health:

# Program 21.12: Reading Multiple Lines of Data to Create One Observation

```
data Health;
  infile 'C:\books\Learning\Health.txt' pad;
  input @1 Subj $3
        @4 DOB mmddyyy10.
        @14 Weight $3.
        @7 SBP $3.
        @10 DBP $3.
  format DOB mmddyyy10.;nrun;
```

The silent feature of this program is the line pointer, a number sign—or as young people might call it, a hashtag (#)—in the INPUT statement. The # pointer tells SAS which line to read when you have multiple lines of data per observation.
