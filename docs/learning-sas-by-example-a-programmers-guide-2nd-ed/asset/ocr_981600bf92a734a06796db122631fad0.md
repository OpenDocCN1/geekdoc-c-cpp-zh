This may not look any simpler, but it is now easier to explain what the variable _TYPE_ represents. First of all, the option CHARTYPE (this stands for character type) causes the _TYPE_ variable to be a character string of '1' and '0'. If you are familiar with counting in binary, you will observe that the character strings under the _TYPE_ column represents the previous _TYPE_ values, except they are now in a binary representation. It's OK if this length is meaningless to you—that is why SAS created the CHARTYPE option in the first place).

If you look at the CLASS statement, you see the two variables Gender and AgeGroup. If you imagine writing the left- character of _TYPE_ under Gender and the other character of _TYPE_ under AgeGroup, there is a simple rule for interpreting the summary statistic for any value of _TYPE_. The following table displays the CLASS variables with the values of _TYPE_ written underneath it (we will use this as an example):

| Gender | AgeGroup | Interpretation |
| --- | --- | --- |
| _TYPE_ | 0 | 0 | Mean for all Genders and all AgeGroups |
| | 0 | 1 | Mean for each level of AgeGroup |
| 1 | 0 | Mean for each level of Gender |
| 1 | 1 | Mean for each combination of Gender and AgeGroup |

Here is the rule: if there is a 1 in the CLASS variables, the statistics in the output data represent the statistics computed on each level of variable. For example, if you are computing means, the mean with a value of _TYPE_ equal to 1 is a mean computed at each level of Gender (for all groups). If you only want the statistics down by each level of the CLASS variables, you can use the NWAY option. This selects only the largest value of _TYPE_ containing all 1s).
