10. The raw data file Mixed_Recs.txt contains two types of records. Records with a 1 in Column 16 sales records with Date (in mmddyy format) starting in Column 1 and Columns 11–15 (in standard numeric form). Records with a 2 in Column 16 are inventory records and they contain two values, a part number (character, 5 bytes) starting in column 1 and quantity. A listing of this file is shown below:

```
10/21/2005 1001
11/15/2005 2001
A13688 250 2
B11112 300 2
01/03/2005 5001
A88778 19 2
```

Write a DATA step to read this file and create SAS data sets, called Sales and other Inventory. The two data sets should look like this:

| Obs | Date | Amount | Obs | Part Number | Quantity |
|---|---|---|---|---||
| 1 | 10/21/2005 | 100 | 1 | A13688 | 250 |
| 2 | 11/15/2005 | 200 | 2 | B11112 | 300 |
| 3 | 01/03/2005 | 5000 | 3 | A88778 | 19 |

11. Each record in the text file Three_Line.txt contains three sets of vital signs: start with heart rate (HR), systolic blood pressure (SBP), diastolic blood pressure (DBP). Values in Column 1 and each value takes three columns. Write an INPUT statement that uses a format list and relative column pointers so that you can read the three HRs, the three SBPPs, and the three DBPs together. Call the three HR HR1, HR2, and HR3; the three SPB SBP1, SBP2, and SBP3; and the three DBP DBP1, DBP2, and DBP3. Some sample data lines are shown here:

```
068120 80 72130 80 69122 78
072180110 76178102 70178100
054118 70 56118 72 50114 78
```
