# 22.7 Using a SAS Data Set to Create a Format

The example in the last section used only a small number of item codes. If you have a large number of values, writing a format statement by hand is tedious. Luckily, SAS allows you to use a specially constructed SAS data set to create a SAS format. The PROC FORMAT option CNTLIN=(control) allows you to use the SAS data set (or data view) that you want to use.

Control input sets require a minimum of three variables, FMTNAME, START, and LABEL. FMTNAME is a variable that specifies the format or informat name; START is either a single value to be formatted or, if END is also, the beginning of a range. You should include a $ as the first character of FMTNAME if you are creating a character format. Optionally, you can include a variable TYPE that is either c for character formats or an N for numeric formats.

> Note: There are other values of TYPE for informats and picture formats: I specifies a numeric informat;; J a a character informat; P specifies a picture format.

If you have data values and labels already stored in a SAS data set, you can use that data set as input to a DATA step (with variables renamed needed) to create your control data set.

This sounds complicated, but an example will make it clear. If you have a permanent SAS data set (Codes) that contains ICD-10 code values (International Classification of Diseases, Version 10) and descriptions. You want to create a format that provides labels for each of the ICD-10 codes. So that you can try this yourself, you create a permanent SAS data set called Codes.

# Program 22.9: Creating a Test Data Set That Will be Used to Make a CNTLIN Data Set

```
data Learn.Codes;
  input ICD10 : $5. Description & $21;
datalines;
020 Plague
022 Anthrax
390 Rheumatic fever
410 Myocardial infarction
493 Asthma
540 Appendicitis
;
```

Program 22.10: Creating a CNTLIN Data Set from an Existing SAS Data Set

```
data Control;
  set Learn.Codes(rename=
    (ICD10 = Start
    Description = Label));
  retain Fmtname=$ICDFMT'
  Type = 'C');

run;

title "Demonstrating an Input Control Data Set";
proc format cntlin=Control fmtlib;
run;
```
