# 13.1 Introduction

C's rule of SAS programming: if you are writing a SAS program and it is becoming tedious, stop. There is a good chance that there is a SAS tool, perhaps arrays, functions, or macros, that will make your task less tedious.

To the beginning programmer, arrays can be a bit frightening—to an experienced programmer, arrays can be a huge time saver. So, let's get over the fright into saving time.

First of all, what is an array? SAS arrays are a collection of elements (usually SAS variables) that allow you to write SAS statements referencing this group of variables.

> Note: SAS arrays are different from arrays in many programming languages. They do not hold values, and they allow you to refer to a collection of SAS variables in a convenient manner.

It is much easier to understand what an array is by a few examples. So, here goes.

# 13.2 Setting Values of 999 to a SAS Missing Value for Numeric Variables

Typically, arrays are used to perform a similar operation on a group of variables. In this example, you have a SAS data set called SPSS that contains several numeric variables. The folks that created this data set used a value of 999 whenever there was a missing value (Some statistical packages such as SPSS allow you to substitute a missing value for a specific value using 999 or 9999 to represent this missing value).

The following is a program that solves this problem without using arrays:

# Program 13.1: Converting Values of 999 to a SAS Missing Value—Without Using Arrays

```
data New;
  set Learn.SPSS;
  if Height = 999 then Height = .
  if Weight = 999 then Weight = .;
  if Age = 999 then Age = .;
;
```

Notice that you are writing the same SAS statement several—the only thing that is changing the name of the variable. You would like to be able to write something like this:

```
if Height, Weight, or Age = 999
  Height, Weight or Age = .;
```

This is pretty much how an array works. Let's first see the program using arrays, and then we'll go through the explanation:

# Program 13.2: Converting Values of 999 to a SAS Missing Value—Using Arrays

```
data New;
  set Learn.SPSS;
  array Myvars{3} Height Weight Age;
  do i = 1 to 3
    if Myvars(i) = 999 then Myvars(i) = .;
  end;
  drop i;
```

The first thing you may notice is that the program with arrays is longer than the one without arrays! However, if you had 50 or 100 variables, the program using arrays would be the same length as this program.

The ARRAY statement is used to create an array. Following the keyword ARRAY is the name you choose for your array. Array names follow the same rules you use for SAS variables. In this example, you choose the name MYVARS as the array name. Following the name, you place the number of elements (in this example, the three variables) in brackets. Finally, you list the variables you want to include in the array.
