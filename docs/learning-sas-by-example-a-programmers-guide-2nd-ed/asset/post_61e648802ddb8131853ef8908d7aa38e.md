## Program 21.18: Creating Several Observations from One Line of Data

```sas
data Pairs;
  input X Y @@;
datalines;
1 2 3 4 5 7 8 9 11 14 13 18 21 27
30 40
;
```

The double @@ prevent SAS from moving to a new line, even when you reach the bottom of the DATA step (unless there is another INPUT statement in the DATA step without a trailing @@). In other words, the double trailing @@ allows SAS to read a stream of data, eating through all the values on a line and then going to the next line. **Use this with great care.** If you are missing a data value in the file, everything gets out of whack.

Without the double trailing @@ signs in Program 21.18, there would be only two observations (X=1, Y=2 and X=30, Y=40).

## 21.14 Using Informats and Format Lists

You can supply a simple informat to a list of variables and some typing. To do this, place a list of variables in parentheses and follow this with a list of one or more informats, all in parentheses. For example, you could write the following line to read three numeric values (each with an informat of 2) and five character values (each with an informat of $1).

```sas
input @1 (X Y Z Char-Char(5))(3*2. 5*$1);
```

Notice that each of the informats in this statement is preceded by a multiplier, written as a number followed by an asterisk. In this example, there are as many informats as there are variables as variables. If there are more variables than there are informats, SAS cycles back to the beginning of the informat list to obtain informats for the remaining variables.

You can take advantage of this feature to read a list of variables that share the same informat. For example, to read 50 one-digit character values, starting in Column 10, you could use the following code:

```sas
input @10 (Ques-Ques50) ($1);
```

## 21.15 Using Relative Column Pointers to Read a Complex Data Structure Efficiently

Besides the absolute column pointer (@), SAS has a relative column pointer, plus sign (+). You can use this to move the current pointer left or right of its current position. Let's look at a few examples:

You have readers of the variables Time and Temperature aligned in pairs—Time values are in seconds and occupy 2 columns; Temperature values are in degrees and occupy 4 columns. The data pairs start in Column 5. Here are a few lines of data:

```
1 2 3 4 5
1234567890123456789012345678901234567890
1020.1120.2132.61525.01728.72031.42533.8
1021.71322.81528.01728.92129.92430.4
```

The tedious way to read this line is:

@5 Time1 2. @7 T1 4. @11 Time2 2. @13 T2 4. @17 Time3 2. @19 T3 4. @23 Time4 2. @25 T4 4. @29 Time5 2. @31 Time5 4. @35 Time6 2. @37 T6 4. @41 Time7 2. @43 T7 4;

If you use a relative column pointer, along with a variable list, this simplifies to:

```sas
input @5 (Time1-Time7)(2. +4)
