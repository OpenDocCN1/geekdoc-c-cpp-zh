Suppose you want to add these new members to the Demographic data set and call the new data set Complete_List. Here's how to do it using PROC SQL. (Notice that the columns are not in the same order as the Demographic data set.)

# Program 26.10: Concatenating Two Tables

```
proc sql;
create table Complete_List as
select *
from Learn.Demographic union all corresponding
select *
from Learn.New_Members
quit;
```

The resulting table contains all the rows from Demographic followed by all the rows from New_Members.
