
This method looks tedious than simply listing the parameters with the commas. However, here are some of the advantages of keyword parameters:

+   - It provides better documentation. Someone reading your calling routine can see what values are associated with each macro variable.
- You can list your parameters in any order. When you call positional parameters, they have to be listed in the same order they were listed in the macro definition.
- You can supply default values when you write your macro. If you call the macro and leave out a parameter that you defined with a default value that value will be used—if you include a value for that parameter, it will override the default value.

As an example, suppose you want to write a macro that prints the n observations of a data set. This macro also prints a title stating how many observations were printed. Finally, you want to set a default value of 10 observations if you call the Program without specifying the value of n.

Such a macro is shown below in Program 25.6:

# Program 25.6: Macro Demonstrating Keyword Parameters and Default Values

```
%macro Print (Dsn= /* Name of the data set to print */
n=10, /* Number of obs set to print, default
is 10 */);\ntitle "Listing of Data Set &Dsn"
title2 "First &n Observations"
proc print data=\&Dsn (Obs=\&n) noobs;
run;
%mend Print;
```
