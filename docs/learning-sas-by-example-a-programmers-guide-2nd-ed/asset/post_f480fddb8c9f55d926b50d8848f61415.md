# Program 5.2: Using PROC FORMAT to Create User-Defined Formats

```
proc format;
value $Gender 'M' = 'Male'
'F' = 'Female'
' ' = 'Not entered'
other = 'Miscoded';

value Age low-29 = 'Less than 30'
30-50 = '30 to 50'
51-high = '51+';

value $Likert '1' = 'Str Disagree'
'2' = 'Disagree'
'3' = 'No Opinion'
'4' = 'Agree'
'5' = 'Str Agree';

run;
```

You should notice several things about this procedure. First, you use a VALUE statement to create each user-defined format. Next that when you are creating the format in a VALUE statement, you do not include a period following the format name.

Next, formats used with character variables start with a dollar sign. Following the format name are either unique values or ranges of values, an equal sign, and then the text you want to associate with each value or range of values. Rules format names are the similar to those for SAS variables with the exception that format names cannot end in a digit and the maximum length of a format is 31 characters. To those curious readers, the length of 31 instead of 32 comes from the fact that you add a period at the end of a format name when you use it in a FORMAT statement in a DATA or PROC step. (SAS versions prior to SAS allowed only 8 format names.)

The first format to be defined is $GENDER. Format names do not need to be related to a variable name—calling this format $GENDER makes it easier to remember that you will use it later to alter how the Gender values will be printed in SAS output.

Values for Gender are stored as M and F. Associating the $GENDER format with the variable Gender results in M displaying as Male, F displaying as Female, and missing values displayed as Not entered. The keyword other in the VALUE statement causes the text Miscoded to be printed for any characters beside M, F, or a missing value.

The format AGE is used to group ages into three categories. Notice that it is OK to use the same name for a format and a variable, (SAS knows that a name containing a period is.) If you apply this to the variable AGE, the ages are printed instead of the age remains. The internal values of SAS variables are not changed because they have been associated with a format. The format only affects how values print out, in some cases, how SAS procedures process a variable. (For example, PROC FRE computes frequencies of formatted values rather than raw values; PROC MEANS formatted variables listed in the CLASS statement, and so forth.)

In the AGE format, the keywords LOW and HIGH refer to the lowest nonmissing value and the highest value, respectively.

> Note: The keyword LOW when used with character formats includes missing values.

The last format, $LIKERT, is used to substitute the appropriate text for the digits 1 (**strongly disagree**) to 5 (**strongly agree**).

> Note: The name Likert was chosen because that is the name that psychometricians use for responses that range from strongly disagree to strongly agree.

Let’s see what happens when you place a format statement in PROC PRINT, as follows:

# Program 5.3: Adding a FORMAT Statement in PROC PRINT

```
title "Data Set SURVEY with Formatted Values"
proc print data=Learn.Survey;
id ID;
var Gender Age Salary Ques1-Ques;
format Gender $Gender.
Age $Age.
Ques1-Ques $Likert.
Salary $dollar11.2;
run;
```

Here forts the format $GENDER and AGE are used to format the variables Gender and Age, respectively. The format $LIKERT formats the five variables Ques through Ques5. Note that each format is followed by a period, just as the built-in SAS formats.

The format for Salary, DOLLAR11.2, is a SAS format. The name dollar indicates that you want to use the dollar format (which adds a dollar sign and commas to the value); the 11 tells SAS to print a value using 11 columns; the 2 following SAS you want to print two digits to the right of the decimal point. Note that the 11 columns include the dollar sign, the commas, and the decimal point. The largest value for Salary using the DOLLAR11.2 format would be:

$999,999.99

## 5.3 Regrouping Values Using Formats

You can use formats to group various values. For example, suppose you want to see the survey results, but instead of looking at the five possible responses for Questions, you want to group the values 1 and 2 (strongly disagree and disagree) together and the values 4 and 5 (agree and strongly agree) to make three categories. You can accomplish this by creating a new format, as shown in Program 5.4:

# Program 5.4: Regrouping Values Using a Format

```
proc format;
    value $Three 1,2 = 'Disagreement'
                  3 = 'No opinion'
                  4,5 = 'Agreement';
run;
```

# Program 5.5: Applying the New Format to Several Variables with PROC FREQ

```
title "Question Frequencies Using the Three Format";
proc freq data=Learn.Survey;
tables Ques1-Ques5;
format Ques1-Ques $Three;
run;
```

PROC FREQ, as you saw in Chapter 2, is used to count frequencies for the variables listed in the TABLES statement (Ques1-Ques5 in this case). Because of the FORMAT statement in this procedure, the tables have only three categories rather than the original five. Here is a partial listing of the output:
