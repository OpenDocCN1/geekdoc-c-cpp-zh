# **20.6 Generating Time Series Plots**

This example starts with a short DATA step to create a moving average. The two functions, LAG and LAG2, return the stock price from the previous day and one day before and then averages the three values (the current price and the price on the two previous days). You use a SERIES statement along with X= and Y= options to specify the x and y variables for the plot. Each plot produced by PROC SGPLOT is additive—that is, each plot appears in the same graph. Later in this chapter, you will see that you can set a value for transparency if one plot covers a previous plot. In this case, overlapping is not a problem.
