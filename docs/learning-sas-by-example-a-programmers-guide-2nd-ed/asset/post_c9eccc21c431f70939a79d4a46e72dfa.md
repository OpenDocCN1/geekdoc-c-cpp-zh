## 12.11 Searching for Character Classes

A group of functions that some call the ANY functions (ANYNUMAL, ANYALPHA, ANYDIGIT, ANYPUNCT, and ANYSPACE) allow you to search for alphanumeric values (upper- and lowercase letters and digits), alphas (all letters), digits, punctuation characters, and space characters (blank, tab, line feeds), respectively.

As an example, suppose you have some ID values, some contain digits and some do not. You want to search each ID and create a list of all the IDs that contain one or more digits. The IDs are stored in a text file called ID.txt.

A listing of the ID.txt file is as follows:

```
abcABC
NJ1234
987654
123XYZ
TX78010
```

# Chapter 12: Working with Character Functions 193

Here is the program:

# Program 12.10: Demonstrating the ANYDIGIT Function

```sas
data Any_Digit;
infile 'C:\books\learning\ID.txt';
input ID : $10;
Position = anydigit(ID);
if Position then output;
```

If the argument of ANYDIGIT contains any digits, the function returns the position of the first one. If not, ANYDIGIT returns a 0. This program added an extra line creating only so that you can see clearly how the ANYDIGIT function works. Remember that the value of Position will be nonzero for any ID that contains a digit. Because all values that are not 0 or missing are considered true in logical expressions, these IDs are written out to the data set Any_Digit. Here are the listings:

# Figure 12.11: Listing of Data Set Any_Digit

| ID | Position |
|---|---|
| NJ1234 | 3 |
| 987654 | 1 |
| 123XYZ | 1 |

There is an optional second argument for all of the ANY functions. This argument indicates the starting position of the character to start looking for the specified characters. If the start value is negative, the search proceeds from right to left, starting at the absolute value of this parameter.

## 12.12 Using the NOT Functions for Data Cleaning

Another collection of functions, the NOT functions, are similar to the ANY functions. The difference is that these functions return the position of the first character in a string that does **not** belong to the specified class.

That makes this collection of functions especially useful for checking a character value for characters that don't belong. For example, if you expect a string to contain only digits, you can see the NOTDIGIT function returns any value greater than 0. Let's see some examples.

You have a SAS data set (Cleaning) that contains three variables: Letters, Digits, and Both. As you probably tell from these variable names, Letters should contain only upper- and lowercase letters; Digits should contain only digits, and Both can contain either letters or digits. You want to write a program to produce an error report. Here is a listing of the Cleaning data set:

# 194 Learning SAS by Example: A Programmer's Guide, Second Edition

## 12.12: Listing of Data Set Cleaning

| Subject | Letters | Digits | Both |
| 1 | Apple | 12345 | XYZ12 |
| 2 | Ice9 | 123X | Abc.23 |

And here is a program that produces the error report:

# Program 12.11: Demonstrating the NOT Functions for Data Cleaning

```sas
data Cleaning _null;
  file print;
  set Cleaning;
  if notalpha(trim(Letters)) then put Subject=Letters;
  if notdigit(trim(Digits)) then put Subject=Digits;
  if notalnum(trim(Both)) then put Subject=Both;
run;
```

It is important to understand why you need to use the TRIM function in this program. Without the TRIM function, each of the three NOT functions used would return the position of the trailing blank in each of the character values. Here is the output for the first two variables:

## 12.13 Extracting Part of a String

It is useful to extract one or more characters from a character variable. For example, an ID like NJ12M99 might contain a state abbreviation of the first two digits and a gender code in the 5th position. You might even want to extract the digits between the state code and the gender as well. The SUBSTR (substring) function allows you to accomplish these tasks.

# Program 12.12: Using the SUBSTR Function to Extract Substrings

```sas
data Extract;
input ID : $10 @@
length State $2 Gender $1 Last $5;
State = substr(ID,1,2);
Gender = substr(ID,5,1);
Last = substr(ID,6);
datalines;
NJ12M99 NY764512
```

The first argument to this function is the string you are searching. The second and third arguments of the SUBSTR function specify the starting position and the length of the substring. For example, the variable Gender is extracted from ID starting in the fifth position for a length of 1. The variable Name is bit more complicated. The SUBSTR function extracts two digits starting at position 3, and then uses the INPUT function to perform a character-to-numeric conversion. Notice that the SUBSTR function used to create the variable Last does not use an argument; the SUBSTR function extracts characters until the last non-blank character in the string.

Wait! What about State? Why wasn't the SUBSTR function used in the assignment statement? Notice that the variable State is declared as a character with a length of 2 in the LENGTH statement. When you set State to ID, because the storage length of State is 2, it contains the first two characters of the variable ID. This is a nice "trick" used by many SAS programmers. The reason it is preferred to using SUBSTR function is that functions use computer resources (CPU time) and this trick avoids using functions. (Once again, the author's compulsive programming personality shows through.)

Here is a list of the resulting data set:

# Figure 12.14: Listing of Data Set Extract

| ID | State | Gender | Last | Number |
|---|---|---|---|---|
| NJ12M99 | NJ | M | 99 | 12 |
| NJ764512 | NY | F | 4512 | 76 |
| TX91M5 | TX | M | 5 | 91 |

In this program, a LENGTH statement is used to define the lengths of State, Gender, and Last. Without this statement, the lengths of these three character variables would be equal to 10, that is the length of ID. Understanding why is very important.

SAS assigns a length to all character variables in the compile stage before any data values are read. In general, the starting position and the length of a substring could be read from data or computed in the DATA step. So, without a LENGTH statement, what length should SAS assign to the variables State, Gender, and Last? The longest substring you can extract from a string of length n is a string of length n, so if you don't define a length, that's exactly SAS does.

## 12.14 Dividing Strings into Words

The SCAN function is typically used to extract words from a string. However, as you will see in a later example, it can also be used to parse (separate) substrings separated by delimiters other than blanks. Let's start with a common example—separating the first and last names to a variable that contains both:

# Program 12.13: Demonstrating the SCAN Function

```sas
data Original;
  input Name $ 30;
  datalines;
  Jeffrey Smith
  Ron Cody
  Alan Wilson
  Alfred E. Newman

data First_Last;
  set Original Last $ 15;
  First = scan(Name,1, ' ');
  Last = scan(Name,2, ' ');
run;
```

The SCAN function extracts the nth word from a string with blanks and non-punctuation characters as the default delimiters. The delimiters differ in the ASCII and EBCDIC character sets. They are (<+!*$); ^,/ % (+&*);~/% | respectively.) It is usually a good idea to specify the delimiters you want to use as the argument to the SCAN function. In this program, a blank is specified as the delimiter.
