You can use MULTILABEL formats with PROC TABULATE to create interesting tables. Here is a program to compute frequencies in a table of Age by Gender:

# Program 22.19: Demonstrating a Multilabel Format

```
title "Demonstrating a Multilabel Format";ntitle2 "PROC TABULATE Example";nproc tabulate data-Learn.Survey;
  Class Age / MLF;
  table Age *
    Gender;
    format AgeGroup;
run;
```

This produces the following output:
