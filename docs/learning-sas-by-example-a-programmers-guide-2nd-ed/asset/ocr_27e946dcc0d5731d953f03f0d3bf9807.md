# 17.3 Selecting Variables for PROC FREQ

Because you rarely want to count frequencies on every variable in a data set, you need to include a TABLES statement to list the variables you want to count frequencies. You may also want to eliminate the cumulative columns because they are not usually needed. The following program selects Gender and Ques1–Ques3 and eliminates the cumulative statistics as well.

# Program 17.2: Adding a TABLES Statement to PROC FREQ

```
title "Adding a TABLES Statement and the NOCUM Option";
proc freq data=learn.survey;
  tables Gender Ques1-Ques3 / nocum;
```
