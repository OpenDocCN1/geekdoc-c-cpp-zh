Notice that the 5 random numbers are different from the ones produced by the first run. The reason is that you did not include the call to streaminit. Let’s run Program 11.9 twice more, but specify a stream value with a call to streaminit:

**Figure 11.10: Including a Call to Streaminit**

```
data Uniform;
call streaminit(1234567);
do i = 1 to 5;
  X = rand('uniform');
  output;
end;
run;
```
