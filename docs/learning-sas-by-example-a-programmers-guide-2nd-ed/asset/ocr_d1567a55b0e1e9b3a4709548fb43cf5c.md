title "Eliminating the 'N' Row from the Table";
proc tabulate data=Learn.Blood format=6;

# 18.8 Demonstrating a More Complex Table

As a final example of combining CLASS and analysis variables in a table and customizing the table, we present the following program:

# Program 18.13: Demonstrating a More Complex Table

```
title "Combining CLASS and Analysis Variables";
proc tabulate data=Learn.Blood format=comma9.2;
class AgeGroup;
var RBC WBC;
table (Gender=' ', ALL)* (AgeGroup=' ', All),
nRBC*(n=f=3. mean=f=5.1)
WBC*(n=f=3. mean=f=7.7)
Chol*(n=f=3. mean=f=7.1);
keylabel ALL = 'Total';
run;
```

Program 18.13 demonstrates several PROC TABULATE features. First, a label is attached to the variables Gender and AgeGroup. This is accomplished, followed by the label. Because a null label is used, the row normally used to display these variable names is eliminated altogether.(Try running this program without it to see the difference).
