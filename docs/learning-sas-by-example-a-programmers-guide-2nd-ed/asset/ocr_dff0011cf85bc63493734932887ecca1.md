# 6.4 Using an Engine to Read an Excel Spreadsheet

You can have SAS treat an Excel spreadsheet as if it were a SAS data set by the XLS or XLSX engine. As an example, suppose you want to run a SAS procedure with the data in a spreadsheet called Wages.xls in your C:\books\learning folder. The following LIBNAME statement enables you to access this spreadsheet directly:

```
libname Read 'C:\books\learning\Wages.xls';
```

You can now access any of the worksheets within this file. This particular spreadsheet contains two worksheets, Temporary and Permanent. Suppose you want to compute the mean of Wage and Hours Worked in the Permanent worksheet. Here are the SAS statements to do that:

# Program 6.3: Reading a Spreadsheet Using an XLSX Spreadsheet

```
title "Statistics from Sales Spreadsheet"
libname Read 'C:\books\learning\Wages.xls';

proc means data=Read.'Permanent$n' mean;
    var Hours_Worked;
run;
```

There are several important points to notice in this program.

First, because SAS requires you to follow the worksheet name with a dollar sign and because dollar signs are not normally allowed in SAS data set names, you need to use a name literal to do this. In Program 6.3, you place the worksheet name (Permanent$) in single quotes and follow this with an n. This notation allows you to use invalid characters as any part of SAS names.

> Note: In order for this name literal to work, you must have the option VALIDVARNAME set to ANY. To do this, submit the following statement:options validvarname=any;
