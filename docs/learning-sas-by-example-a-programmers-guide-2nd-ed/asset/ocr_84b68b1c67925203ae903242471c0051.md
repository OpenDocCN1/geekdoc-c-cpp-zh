# **20.3 Displaying Statistics for a Response Variable**

The same plot statements, VBAR and HBAR, can be used to display means or sums for each level of a categorical variable. Instead of the height of each bar representing frequencies, it can represent a mean or sum of a response variable. You accomplish this by including the option RESPONSE= in the VBAR or HBAR statement. In the example, you want to see the mean cholesterol levels for each blood type.

# **Program 20.4: Vertical Bar Chart Displaying a Response Variable**

```
title "Vertical Bar Chart Displaying a Response Variable";nproc sgplot data=Learn.Blood;
 vbar BloodType / response=Chol stat=mean barwidth=.5 nofill;
run;
```
