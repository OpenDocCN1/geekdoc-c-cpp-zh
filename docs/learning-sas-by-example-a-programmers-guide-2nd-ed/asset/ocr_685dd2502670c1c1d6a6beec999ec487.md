# Program 14.17: Listing the First Observations of Your Data Set

```
title "First Five Observations from Sales"
proc print data=Learn.Sales (obs=5);
run;
```

OBS=n is a data set option. You can tell this because it is placed in parentheses following the data set name. There are many other data set options that we will discuss later in this book. Notice that the listing here stops at Observation 5:

You can combine another data option, FIRSTSTBS=, to print observations starting from any point in the data set. For example, if you write the following, PROC PRINT would list Observations 4 through 7:

```
proc data=learn.sales (firstobs=4 obs=7);
```

Keep in mind that OBS= is not the number of observations you want to print—it is the last observation to be processed. When you use FIRSTSTBS= and OBS= together, the result is as LASTOBS.

Even though PROC PRINT is one of the simplest procedures in Base SAS, there are a few options that allow you more control over the appearance of the output. If you have more control over the appearance of a listing, you should consider PROC REPORT. This procedure takes more programming effort than the PRINT procedure, but provides much more control over the output.
