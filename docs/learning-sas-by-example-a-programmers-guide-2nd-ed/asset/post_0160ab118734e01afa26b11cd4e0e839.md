
## 18.13 Understanding How Missing Values Affect PROC TABULATE Output

Although this is the last topic in this chapter, it is a very important one.

**Note:** If you have missing values for one or more variables listed in a CLASS statement, any observation with one or more missing values will be eliminated from the table!

This is true even for a variable that is listed in a CLASS statement and is not referenced in a TABLE statement.

To help understand how this works (and later to see how to fix it), look at the small data set (Missing):

**Figure 18.20:** Listing of Data Set Missing

| A | B | C |
|---|---|---|
| X | Y | Z |
| X | Y | Y |
| Z | Z | Z |
| X | | |
| Y | Z | | |
| X | | |

Now, see what happens when you request some simple tables:

**Program 18.10:** Demonstrating the Effect of Missing Values on CLASS Variables

```sas
title "The Effect of Missing Values on CLASS variables";
proc tabulate data=Learn.Missing format=4;
class A B;
table A ALL, B ALL;
run;
```

**Figure 18.21:** Output from Program 18.19

# The Effect of Missing Values on CLASS variables

| B | All |
|---|---|---|
| X Y Z | | |
| N N N | | |
| A | | |
| X | 1 2 | |
| Y | | 1 |
| Z | | 1 |
| All | 1 2 | 5 |

Notice that although there are six observations in the data set, the total shown in the table is five. Now, what happens if you include the variable C in the CLASS statement, shown like this:

**Program 18.20:** Missing Values on a CLASS Variable That Is Not Used in the Table

```sas
"The Effect of Missing Values on CLASS variables"
proc tabulate data=Learn.Missing format=4;
  class A B C;
table A ALL, B ALL;
run;
```

Here is the table:

**Figure 18.22:** Output from Program 18.20

# The Effect of Missing Values on CLASS variables

| B | All |
|---|---|---|
| X Y Z | | |
| N N N | | |
| A | | |
| X | 2 | 2 |
| Z | | 1 |
| All | 2 1 | 3 |

Notice that the total number of observations is now three, even though variable C was not used to generate the table. PROC TABULATE chooses the observations to exclude from the table based on any missing values in any of the variables listed in the CLASS statement.

Let’s rerun Program 18.19 but include the procedure option MISSING, like this:

**Program 18.21:** Adding the PROC TABULATE Procedure Option MISSING

```sas
title "The Effect of Missing Values on CLASS variables";
proc tabulate data=Learn.Missing format=4. missing;
class A B;
table A ALL,B ALL;
run;
```

The MISSING option includes missing values as a category in the table. Take a look:

**Figure 18.23:** Output from Program 18.21

# The Effect of Missing Values on CLASS variables

| | | B | All |
|---|---|---|---|
| | X Y Z | | |
| A | | N N N | | |
| X | | 1 1 2 | 4 |
| Y | | | | 1 |
| Z | | | 1 | 1 |
| All | 1 1 2 2 | 6 |

Notice that variable B now has a column representing missing values and the total number of observations in the table is six.

By the way, if you would prefer to see something other than a period representing missing values in the table, THE TABLES option MISSTEXT= can be used to substitute any text you want. For example:

**Program 18.22:** Demonstrating the MISSTEXT= TABLES Option

```sas
title "Demonstrating the MISSTEXT TABLES Option";
proc tabulate data=Learn.Missing format=7. missing;
class A B;
table A ALL,B ALL / misstext='No Data';
run;
```

The text No Data now appears instead of the period in each cell that contains a missing value.

Note: The format width increased to 7 to accommodate the text.

Here is the listing:

**Figure 18.24:** Output from Program 18.22

| | B | All |
|---|---|---|---|---|
| | X | Y | Z |
| | N | N | N |
| A | | | | |
| X | 1 | 1 | 2 No Data 4 |
| Y | No Data No Data No Data | 1 1 |
| Z | No Data No Data No Data | 1 1 |
| All | 1 | 1 | 2 6 |

We hope that this introduction to PROC TABULATE gives you the courage to give this useful and powerful procedure to try. Author was TABULATE-phobic for a long time until forced to use the procedure for a project that requires nice-looking tables. Now, it tries to get others to use this procedure.

Make this format available to SAS (see Chapter 5), run the FORMAT statements here, or use the system option NOFORMAT that allows you to access data sets that have permanent-defined formats without any error.

```sas
proc format;
value$Yes '1' = 'Yes'

      'L' = 'Large';
```
