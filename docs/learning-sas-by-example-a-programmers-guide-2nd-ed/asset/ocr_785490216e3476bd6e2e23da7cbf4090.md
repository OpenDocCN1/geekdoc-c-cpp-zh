It should be pretty clear that these two variables represent: First.ID is true (1) for the first visit for each patient and false (0) otherwise. Last.ID is true for the last visit for each patient and false otherwise. For Number 303, First.ID and Last.ID are true (it is both the first and the last visit for this patient).

To create a data consisting of the last visit for each patient, the program uses a subsetting IF statement to check when the value of Last.ID is equal to 1. Here is a listing of data set:

A common data processing requirement is to perform such operations as setting counters equal to 0, when you are processing the first observation in a BY group and grouping counts when you are processing the last observation in a BY group.

Program 24.2 uses a DATA step to count the number of visits for each patient. (We will demonstrate later how to do this using PROC FREQ).
