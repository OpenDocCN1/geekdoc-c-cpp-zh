# 25.6 Describing Positional and Keyword Macro Parameters

The macro shown in Program 25.4, used what are called positional parameters. That is, of the macro variables in parentheses following the macro name are separated by commas. When you call this macro, you also list the variables that you want to substitute for each macro variable, in order, separated by commas.

There is an alternate (and superior way, at least the belief of this) to specify the macro parameters. It is called keyword parameters. You follow each macro variable in the list of parameters with an equal sign. When you call the macro, you list the name of the parameter, followed by an equal sign, followed by the value you want to substitute for the macro variable.

What follows is repeat of Program 25.4, rewritten to use keyword parameters. A recommended way to document these parameters is also included in the program.
