# ## 20.7 Describing Two Methods of Generating Smooth Curves

In addition to providing the capability of connecting data points by straight lines, PROC SGPLOT also provides two non-linear methods of curve fitting. Both of these methods use local regression models to generate smooth curves.

The first method in use local points to fit portions of the curve. To control how closely the smooth curve follows the data points, specify the SMOOTH option=numeric value in the PBSPLINE
