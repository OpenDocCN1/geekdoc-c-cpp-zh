# 18.5 Producing Descriptive Statistics

PROC TABULATE can also produce descriptive statistics such as sums and means. To specify that you want to generate descriptive statistics rather than frequency counts, you list all of your analysis variables (that is, the ones for which you want statistics) in a VAR statement. 

> Note: Descriptive statistics may appear on any dimension of a table, but you may only define statistics on a single dimension of a table.

Program 18.6 computes descriptive statistics for the RBC (red blood cell) and WBC (white blood cell) counts:

Program 18.6: Using PROC TABULATE to Produce Descriptive Statistics

```
title "Demonstrating Analysis Variables";
proc tabulate data=Learn.Blood;
var RBC WBC;
table RBC WBC;
run;
```
