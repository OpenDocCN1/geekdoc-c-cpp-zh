# Program 12.15: Using the SPEDIS Function to Perform a Fuzzy Match

```
data Fuzzy;
  input Name = $20;
  Value = spedis(Name, 'Friedman');
datalines;
Friedman
Freedman
Xriedman
Friedman
Friedmann
Alfred
FRIEDMAN
;
```

The SPEDIS function returns a 0 if the two arguments match exactly. The function assigns penalty points for each type of spelling error. For example, getting the first letter wrong is assigned more points than misspelling other letters. Interchanging two letters is a relatively small error, as is adding an extra letter to a word.

Once the total number of penalty points has been computed, the resulting value is as a percentage of the length of the first argument. This makes sense getting one letter wrong in a 3-letter word would be a more severe error than getting one letter in a 10-letter word.

Notice that the two character values evaluated by the SPEDIS function are case-sensitive (look at the observation in the listing). If case may be a problem, use the UPPERCASE, or PROPCASE or VALUE function before testing the name with SPEDIS.

To identify any name that is similar to Friedman, you could extract all names where the value returned by the SPEDIS function is less than some predetermined value. In the program here, values less than 15 or 20 would identify some reasonable misspellings of the name.
