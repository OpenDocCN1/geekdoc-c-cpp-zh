# ### Program 12.5: Demonstrating the TRIMN, LEFT, and STRIP Functions

```
data Blanks;
String = ' ABC '
**There are 3 leading and 2 trailing blanks in String; || '';
JoinLeft = ':' || left(String) || ';';
JoinTrim = ':' || trimn(String) || ';';
JoinStrip = ':' || strip(String) | ';';
run;
```

Here is the output:

# ### Listing 12.5: Output from Data Set Blanks

| Listing of Data Set Blanks
| String | JoinLeft | JoinTrim | Join Strip |
|---|---|---|---|
| ABC | :ABC | : ABC: | :ABC: |

The variable String has three leading and two trailing blanks. A good way to know if a value has leading and/or trailing blanks is to concatenate a character (a colon, for example) to the beginning and end of a character value.

> Note: It is very hard to see trailing blanks on printed output—only experienced SAS programmers can do this!

The colons in the three Join variables, we have JoinLeft - ABC followed by five blanks, JoinTrim - three blanks followed by ABC, and JoinStrip - no trailing blanks.

When you assign the result of any of these functions to a variable, the length of that variable does not change. So, if you create three variables in the following examples, the storage length of each of the three variables Left, Trim, Strip is equal to 8 (the length of String):

```
Left = left(String);
Trim = trimn(String);
Strip = strip(String);
```

Left is ABC followed by five blanks. Trim is three blanks followed by ABC followed by two. Even though the TRIM function returns a value with no trailing blanks, this value is assigned to a variable with a length of 8, the trailing blanks reappearing. This same logic, Strip is to ABC followed by five blanks.
