You can create more complex bar charts by displaying the distribution of one variable at each level of a second variable. This is accomplished by adding a GROUP= option to either the VBAR or HBAR statement. Suppose you want to look at frequencies of blood types for males and females. The program below does just like that:

# Program 20.3: Vertical Bar Chart Example (Two Variables)

```
title "Vertical Bar Chart Example (two variables)";nproc sgplot data=Learn.Blood;
vbar Gender / group=BloodType;
run;
```
