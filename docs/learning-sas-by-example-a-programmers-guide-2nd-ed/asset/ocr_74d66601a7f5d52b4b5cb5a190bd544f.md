If you use this query to create a SAS data set, there will only be one variable called Subj. If you would like to keep values of Subj from each data set, you can rename the columns, like this:

# Program 26.5: Renaming the Two Sub Variables

```
title "Renaming the Two Sub Variables";nproc sql;
  select Health.Subj as Health_Subj,
       Demographic.Subj as Demog_Subj,
       Height,
       Weight,
       Name,
       Gender
from Learn.Health,
     Learn.Demographic;
quit;
```
