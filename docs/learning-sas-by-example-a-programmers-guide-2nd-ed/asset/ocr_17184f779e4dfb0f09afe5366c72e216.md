# Program 20.7: Time Series Plot

```
data Moving_Average;
  set Learn.Stocks;
  Previous = lag(Price);
  Two_Back = lag2(Price);
  if n ge 3 then Moving=mean(Price, Previous, Two_Back);
run;
\ntitle "Series Plot";
proc sgplot data=Moving_Average;
  series x=Date y=Price;
  series x=Date y=Moving;
run;
```

The Price versus Day plot starts on January 1, 2017—the moving average plot starts on day3.
