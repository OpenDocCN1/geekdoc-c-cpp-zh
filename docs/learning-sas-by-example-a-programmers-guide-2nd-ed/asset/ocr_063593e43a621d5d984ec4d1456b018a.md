# 12.14 Dividing Strings into Words

The SCAN function is typically used to extract words from a string. However, as you will see in a later example, it can also be used to parse (separate) substrings separated by delimiters other than blanks. Let's start with a common example—separating the first and last names to a variable that contains both:

# Program 12.13: Demonstrating the SCAN Function

```
data Original;
  input Name $ 30;
  datalines;
  Jeffrey Smith
Ron Cody
  Alan Wilson
  Alfred E. Newman

data First_Last;
  set Original Last $ 15;
  First = scan(Name,1, ' ');
  Last = scan(Name,2, ' ');
run;
```

The SCAN function extracts the nth word from a string with blanks and non punctuation characters as the default delimiters. The delimiters differ in the ASCII and EBCDIC character sets. They are (<+!*$); ^,/ % and (+&*);~/% |é respectively.) It is usually a good idea to specify the delimiters you want to use as the argument to the SCAN function. In this program, a blank is specified as the delimiter.

A LENGTH statement is used to define the length of First and Last. If you don't include this statement, both First and Last will have a length equal to the length of Name (which you cannot extract a substring longer than the length of the first argument). This function was first introduced to SAS, a default length of 200 was used. It was changed later to the present value. Here is a listing of data First_Last:
