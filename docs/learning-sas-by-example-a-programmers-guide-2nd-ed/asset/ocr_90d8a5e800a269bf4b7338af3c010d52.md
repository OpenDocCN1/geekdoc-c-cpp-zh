# Program 22.11: Using the CNTLNIN= Created Data Set

```
data Disease;
input ICD10 : $5. @@;
datalines
020 410 500 493
;

title "Listing of Disease"
proc print data=Disease noobs;
format ICD10 $ICDFMT;
run;
```

Note that there is no format for the ICD-10 code of 500. If you were writing your OWN PROC FORMAT statements, you could use the keyword OTHER to provide a label for non-matching codes. If you want to accomplish this using a CNTLN data set, you need a way to assign a value to OTHER. CNTLN data sets use the variable for *High, Low, Other* to indicate that you want to use one of these keywords and not an explicit range value.

If you want to assign a label **Found** for all ICD-10 codes not in the list, you proceed as follows:

# Program 22.12: Adding another Category to Your Format

```
data Control;
set Learn.Codes (rename=
(ICD10 = Start
Description = Label))
End = Last;)
retain Fmtname '$ICDFMT'
type 'C';
output;

if last then do;
Start = ' ';
Hlo = 'o';
Label = 'Not Found';
output;
end;
```
