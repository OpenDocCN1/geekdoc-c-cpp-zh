# 1.1 Introduction

You may have thought of PROC MEANS (or PROC SUMMARY) primarily as a way to generate summary
reporting, the sums and means of your numeric variables. However, these procedures are much
more versatile and can be used to create summary data sets that can then be analyzed with more DATA OR
PROC steps.

All the examples in this chapter use PROC MEANS rather than PROC SUMMARY, even when all you
want an output data set. The reason for this is that using PROC MEANS with a NOPRINT option is
identical to using PROC SUMMARY when you are creating an output data set.
