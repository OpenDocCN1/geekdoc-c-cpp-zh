Notice that AgeGroup is getting more complicated. Even though there are only two levels of Gender and two levels of _TYPE_, there are nine observations in the data set. The _TYPE = 0 observation is the same as you saw earlier—it represents the grand mean, the mean of all nonmissing values in the data set. To understand the other observations in this data set, you have to know either how to count in binary or how to use another PROC MEANS—CHARTYPE. Let's take the easy way out and rerun this program with the CHARTYPE procedure option as follows:

Program 16.13: Adding the CHARTYPE Procedure Option to PROC MEANS

```
proc means data=Learn.Blood noprint charts;
class Gender AgeGroup;
var RBC WBC;
output out = Summary
mean = / autoname;
run;
```
