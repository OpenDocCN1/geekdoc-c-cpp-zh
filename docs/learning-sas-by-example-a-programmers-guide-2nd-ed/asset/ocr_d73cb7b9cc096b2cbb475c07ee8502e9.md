It is important to remember that the original character data values are not part of this data set. If you wanted both the original letter grade and its corresponding numeric value, you could read the letter grade as a character variable and use an INPUT function (with the CONVERT informat) to create the numeric grade.

There are some useful options you can use when you create your formats. UPCASE and JUST are two such options. UPCASE converts the data values to uppercase before checking on the informat ranges. JUST left-aligns character values. Let's use these two options to enhance Program 22.3.

# Program 22.4: Demonstrating Informat Options UPCASE and JUST

```
proc format;
invalid Convert (upcase just)
  'A+' = 100
  'A' = 96
  'A-' = 92
  'B+' = 88
  'B' = 80
  'B-' = 76
  'C+' = 72
  'C' = 65
  'F' = ;
;run;

data Grades;
  input @1 ID $;
  @4 Grade convert2;
datalines;
001A-
002b+
003F
004c+
005 A
006X
;
title "Listing of Grades";
proc print data=Grades noobs;
run;
```
