
# Chapter 4: Creating Permanent SAS Sets

A more useful way to list variable information is to list them in the order the variables are stored in the SAS data set, rather than alphabetically. To create such a list, use the VARNUM option of PROC CONTENTS, like this:

## Program 4.3: Demonstrating the VARNUM option of PROC CONTENTS

```sas
title "The Descriptor Portion of Data Set Test_Scores";
proc contents data=Mozart.Test_Scores varnum;
run;
```

Output from this program is identical to the previous output except that the variable list is in the same order as the variables in the data set. This portion of the output is shown below to demonstrate the effect of this option:

## Figure 4.2: Demonstrating the VARNUM Option of PROC CONTENTS

| | Variable | Type | Len |
|---|---|---|---|
| 1 | ID | Char | 3 |
| 2 | Name | Char | 15 |
| 3 | Score1 | Num | 8 |
| 4 | Score2 | Num | 8 |
| 5 | Score3 | Num | 8 |

It is important to remember that if you have just opened a new SAS session, you must reissue a LIBNAME statement if you want to access a previously created SAS data set or to create a new one. You may use any library name (libref) each time you open a SAS session, although in practice you usually use the same library reference each time.

For example, if you open a new SAS session, you can submit the following statements to obtain information on the Test_Scores data set:

## Program 4.4: Using a LIBNAME in a New SAS Session

```sas
library Proj99 'C:\books\learning';

title "The Descriptor Portion of Data Set Test_Scores";
proc contents data=Proj99.Test_Scores varnum;
run;
```

> Note: One useful PROC CONTENTS option is POSITION. This option produces both an alphabetical and ordered list of the variables in your SAS data set, which is this author’s favorite option.

## 4.5 Listing All the SAS Data Sets in a SAS Library Using PROC CONTENTS

You can use PROC CONTENTS to list the names of all the SAS data sets in a SAS library (folder). You can use the following:

## Program 4.5: Using PROC CONTENTS to List the Names of all the SAS Data Sets in a SAS Library

```sas
title "Listing All the SAS Data Sets in a Library";
proc contents data=Mozart_all nods;
run;
```

The keyword _ALL_ is used in place of a data set name. The NODS option gives you the name of the data sets only, omitting the detail listing for each data set. A partial listing is shown next:

## 4.6 Viewing the Descriptor Portion of a SAS Data Set Using a Point-and-Click Approach

If you are running SAS using any of the three windowing environments, you can use simple point-and-click methods to view the descriptor or data portion of a SAS data set. The screen shots that are displayed below were made using the SAS windowing environment on a Windows platform. Similar techniques can be used with Enterprise Guide or SAS Studio.

First, click the Explorer tab on the bottom left of your editor window:

Right-click on the data set icon brings up a menu that includes a choice to see the variables (columns) of the data set and their attributes. A left-click opens the SAS Viewer, showing the data portion of your set. If you right-click and select View Columns, you will see the following:

|---|---|---|---|---|---|

| W Score1 | Num... | 8 | | | |
| W Score2 | Num... | 8 | | | |
| W Score3 | Num... | 8 | | | |

This shows the same information that you can obtain by running PROC CONTENTS. The order of the variables in the list is the same as the order you will see when using the VARNUM option.

If you left-click the data icon, you will see your data set in the SAS Viewer. It looks like this:
