# 14.6 Adding Titles and Footnotes to Your Listing

You can make your output more meaningful by adding additional title lines and by adding one or more footnotes to your listing. The TITLEn statement (where n is a number from 1 to 10) allows you to specify multiple title lines. TITLE1 and TITLE2 are equivalent. The FOOTNOTEn statement allows you to specify from 1 to 10 footnotes, that appear at the bottom of the page. It is important to remember that once you issue a TITLE or FOOTNOTE statement, the title or footnotes print on every page of your output until you change or cancel them.

The short program lists variables from the Sales data and adds several title and footnote lines:

Program 14.7: Adding Titles and Footnotes to Your Listing

```sas
title1 "The XYZ Company";
title3 "Sales Figures for Fiscal 2017";
title4 "Prepared by Roger Rabbit";
title5 "------------------------------------";
footnote5 "All sales Figures are Confidential";

proc data=Learn;
id EmpID;
var Customer Quantity TotalSales;
format TotalSales dollar10.2 Quantity comma7;
;
```

```sas
footnote;
```

# 14.7 Changing the Order of Your Listing

If you want to see your list in a particular sorted order, you can precede PROC PRINT with a PROC SORT step. If you want to see your listing in order of TotalSales, the following program could be used:

Program 14.8: Using PROC SORT to Change the Order of Your Observations

```sas
proc sort data=Learn.Sales;
by TotalSales;
run;

title "Listing of Sales - Sorted by Total Sales";
proc print data=Learn.Sales;
id EmpID;
var Customer Quantity TotalSales;
format TotalSales dollar10.2 Quantity comma7;
run;
```

To see your listing from highest to lowest, precede the variable name (TotalSales) with the keyword DESCENDING, like this:

Program 14.9: Demonstrating the DESCENDING Option of SORT

```sas
proc sort data=Learn;
by descending TotalSales;
run;
```

In Program 14.8, you replaced the original data set with one sorted in order of TotalSales. In some cases, this is fine. However, if you do not want the original data set changed, add an OUT= option to your sort to specify an output data set. This is especially important if you subset the data you are performing your sort. As an example, the following program creates a temporary data set in descending order of TotalSales:

# Program 14.10: Sorting the Permanent Data Set and Creating a Temporary Output Data

```sas
proc sort data=Learn, out=Sales;
by descending TotalSales;
run;
```

Note that SAS is reading your permanent data set (Learn) and creating a temporary data set (Sales). It is fine (and sometimes convenient) to use the same name for each of the two data sets, as long as they are in different libraries.

# 14.8 Sorting by More One Variable

You can sort your data set by more than one variable. This is called a multi-level sort. As an example, the following PROC SORT statements sort your data by employee ID and within each ID, in decreasing value of total sales:

# Program 14.11: Sorting by More One Variable

```sas
proc sort data=Learn.Sales out=Sales;
by EmpID descending TotalSales;
run;
```

```sas
title "Sorting by More One Variable";
proc print data=sales;
id EmpID;
var TotalSales Quantity;
format TotalSales dollar10.2 comma7;
run;
```

# 14.9 Labeling Your Column Headings

If you want to make your listing a bit more readable, at least for non-programmer types, you might want to use labels instead of column headings. To make this happen you need to do two things. First, you need to use a LABEL statement, either in the DATA step or as a statement following your PROC PRINT. (LABEL statement act somewhat like FORMAT statements—if you place a LABEL statement in the DATA step, it remains associated with the variable—if you place the LABEL statement in the PROC step, it is associated only for procedure.) Next, you need to add a LABEL option to your PROC PRINT statement. We add labels to the listing to demonstrate this.

# Program 14.12: Using Labels as Headings with PROC PRINT

```sas
title "Using Labels as Headings";
proc print data=Sales label;
id EmpID;
var TotalSales Quantity;
label EmpID = "Employee ID"
     TotalSales = "Total Sales"
     Quantity = "Number Sold";
format TotalSales dollar10.2 comma7;
run;
```
