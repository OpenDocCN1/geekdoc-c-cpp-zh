# 15.13 Using a Nonprintable Variable to Order a Report

PROC REPORT can use a variable to order the rows of a report without including the variable in the report. For example, in data Sets, the Name variable stores as first name followed by last name. Now, if you want a report showing this variable you want to arrange the rows alphabetically by last name, you can run the following program:

Program 15.16: Using a Nonprintable Variable to Order the Rows of a Report

```
data Temp;
set Learn.Sales;
length LastName $ 10;
LastName = scan(Name,-1, ' ');
run;
title "Listing Ordered by Last Name";
proc report data=Temp;
column LastName EmpID TotSales;
define LastName / group noprint width=15;
define EmpID / "Employee ID" group width=11;
define TotSales sum "Total Sales" format=dollar9;
run;
```

In the host DATA step, the SCAN function extracts the last from the Name variable. The second argument to the SCAN function tells the system which "word" to extract from the first argument. A negative value says to start scanning from the right; the third argument defines the word delimiters—in this case, a space.
