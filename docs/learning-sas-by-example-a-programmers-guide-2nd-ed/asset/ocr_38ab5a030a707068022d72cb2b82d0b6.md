+   1. Using the SAS data set College, compute the mean, median, minimum, and maximum of number of both missing and nonmissing values for the variables ClassRank and GPA. Report the statistics to two decimal places.
Repeat 1, except the desired statistics for each combination of Gender and SchoolSize. Do this twice, once using a BY statement, and once using a CLASS statement. Note: that data College has permanent formats for Gender, SchoolSize, and Scholarship. Either make this format available to SAS (see Chapter 5), run the PROC FORMAT statements that follow, or use the system option NOFORMATM (no format error) that allows to access SAS data sets that have permanent user-defined formats without causing an error.

```
proc format;
value YSno 'Y', '1' = 'Yes'
               'N', '0' = 'No'
               '' = 'Not Given'
value SSize 'S' = 'Small'
               'M' = 'Medium'
               'L' = 'Large'
               '' = 'Missing'
value Gender 'F' = 'Female'
               'M' = 'Male'
               '' = 'Not Given';
```
