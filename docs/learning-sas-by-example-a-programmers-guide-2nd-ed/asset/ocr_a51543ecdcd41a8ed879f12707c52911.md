# 22.3 Using Formats with a PUT Function to Create New Variables

There are times when you want to create a new variable consisting of formatted values. Program 22.2 demonstrates how this is done.

Program 22.2: Using a Format and a PUT Function to Create a New Variable

```
proc format;
  0 - <20 = '< 20'
  20 - <40 = '20 to 39'
  40 - <60 = '40 to 59'
  60 - high = '60+';

run;

data Survey;
  set Survey;
  AgeGroup = put(Age,Agefmt.);

run;

title "Using a Format to Create a Character Variable"
proc print data=Survey;
  id ID;
  var AgeGroup;

run;
```

The key to this is the PUT function. This function takes the value of its first argument, formats this value with the format listed as the second argument, and returns the formatted value. Remember that the PUT function always returns a character value. In this example, AgeGroup is a character variable with a length of 8 bytes (the length of the longest formatted value).
