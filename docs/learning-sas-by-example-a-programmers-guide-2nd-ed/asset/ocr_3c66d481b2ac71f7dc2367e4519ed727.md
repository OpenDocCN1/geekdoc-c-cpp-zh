As you can, the heights are in feet and inches. Assume that these units can be in lowercase and may or may not be a period following the units. Create a temporary SAS set (Height) that contains a numeric variable (HInches) that is the height in inches.

> Note: The Height values is missing an inches value. Be sure that there are no character-to-numeric notes in the SAS log.

> Hints: Use the KD modifiers to keep the digits and use a single blank in the second argument to keep blanks. You can then use the SCAN function to extract the feet and inches values.

+   5. Data set Names_And contains a character variable Mixed that is either an integer or a mixed number (such as 50 1/8). Using this data set, create a new, temporary SAS set with a numeric variable (Price) that has decimal values. This number should be rounded to the nearest .1.

> Hint: Use the SCAN (character shown) function with forward slashes (/) as delimiters.
