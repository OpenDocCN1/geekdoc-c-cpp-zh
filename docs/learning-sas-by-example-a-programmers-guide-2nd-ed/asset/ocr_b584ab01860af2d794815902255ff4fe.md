# 26.8 An Example of Fuzzy Matching

One of the strengths of PROC SQL is its ability to create a Cartesian product. As mentioned earlier in this chapter, a Cartesian product is a pairing of every row in one table with every row in another table. Here are two tables: Demographic (used in many of the other examples in this chapter) and Insurance.

You want to join (merge) these tables by Name, allowing for slight misspellings of the names. Here is an SQL query that does just that:

Program 26.13: Using PROC SQL to Perform a Fuzzy Match

```
title "Example of a Fuzzy Match";nproc sql;
select Subj,
Demographic.Name,
Insurance.Name
from Demographic,
Learn.Insurance
where sperdis(Demographic.Name,Insurance.Name) le 25;
quit;
```

The SPEDI (spelling distance) function allows for misspellings (see Chapter 12). The WHERE clause operates on every combination of names from the two tables and selects names that are within a spelling distance of 25. In practice, you would want to compare other variables such as Gender and DOB between two files to increase the likelihood that a valid match is being made.
