#  9.1 Introduction

Most data sets contain date information, such as a date of birth or a transaction date. SAS can read dates in almost any used format. It can calculate intervals between dates and much, much more. Read on.

#  9.2 How SAS Stores Dates

SAS can read dates in almost any form, such as the following:

| Date | Description |
| 10/21/1950 | Month – Day – Year |
| 21/10/1950 | Day – Month – Year |
| 21Oct1950 | Day – Month – Abbreviation – Year |
| 50294 | Julian Date |

However, SAS does not store date in any of these forms—it converts all of these dates into a single number—the number of days from January 1, 1960. Dates after January 1, 1960 are positive
