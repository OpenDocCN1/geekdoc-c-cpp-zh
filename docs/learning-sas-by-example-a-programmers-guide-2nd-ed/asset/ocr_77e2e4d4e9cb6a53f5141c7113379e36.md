# 14.3 Changing the Appearance of Your Listing

You can control which variables appear in your listing, as well as the order of these variables, by a VAR statement. You place the variables you would like to see, following the keyword VAR. The order of this list also controls the order variables appear in the listing.

# Program 14.2: Controlling Which Variables Appear in the Listing

```
title "Listing of Sales"
proc print data=Learn.Sales;
var EmpID Customer TotalSales;
run;
```
