Because the two data sets use the same name for the BY variable, first you have to rename this variable and then create a new character variable with the name of SS. The PUT function takes the variable named in the first argument, applies the format in the second argument, and returns the formatted value (see Chapter 11 for details on this function). SSN11 is a built-in SAS format that prints leading zeros and adds dashes as required for Social Security numbers. Thus, the variable in data set Division1 is identical to SS in variable Division2. You can now proceed with the merge in the standard manner. Here is a listing of the resulting data set:
