For the first edition of this book, this chapter was devoted to SAS/GRAPH procedures such a PROC
GCHART and PROC GPLOT. Although SAS/GRAPH is still available, you can produce charts and graphs
more easily by using PROC SGPLOT (the SG stands for "Statistical Graphics"—although this author
inks it should stand for SAS Graphics instead). Unlike SAS/GRAPH, which requires a separate license,
PROC SGPLOT is included in Base SAS.

Three other SG procedures, SGSCATTER, SGPANEL, and SGRENDER, are also included in Base SAS
but PROC SGPLOT be all you need.
