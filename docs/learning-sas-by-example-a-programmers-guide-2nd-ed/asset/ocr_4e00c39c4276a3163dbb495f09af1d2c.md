+   1. You are given a SAS data set (BloodPressure) with variables SBP and DBP (systolic pressure and diastolic blood pressure). Want to see frequencies for SBP and DBP grouped as follows: pressures below 140 to be called Normal and frequencies of 140 and above are to be called High. For DBP, pressures below 90 to be called Normal and frequencies of 90 and above to be called High. Create an appropriate format and use PROC FREQ to produce these frequencies. Do not use a DATA step. Use the appropriate options to omit the cumulative frequencies and percentages from the PROC FREQ output.
2. Given the SAS data set Grades, grades (a numeric variable) grouped as follows:

```
Less than 65 = F
65 to less than 75 = C
75 to less than 85 = B
85 to 100 = A
```

Create a format and use PROC FREQ to list these frequencies. Do not use a DATA step.

+   3. Using the same definitions for high and low SBP and DBP from Problem 1, create a new, temporary SAS data set with two new variables (SBPGroup DBPGroup).
4. Using the same definitions for letters from Problem 2, create a new, SAS data set (Grades) with a new variable (LetterGrade) created using a PUT function with a user-defined format.
5. Using the same definitions for letters from Problem 2, create a new, temporary SAS data set (Grades) with a new variable LetterGrade (with values of A, B, C, and F). By doing this to read the raw scores from the text file NumGrades.txt.
6. You want to read the following line of data:

```
A 6.7 X b c a 10.9 11.6 C
```

The numbers represent blood leads and the letters A, B, and C represent default values from three labs (A=4, B=5, and C=3.5). An X represents a numeric value. Use an enhanced numeric to read this line of data with the letters converted to the appropriate values (notice that the letters are in mixed case).

+   7. Use the SAS data set DxCodes to create a control data set to create a character format (DXCODES). This data set contains variables Dx (character diagnosis codes) and Description. The Description variable contains the labels you want to use for each of the Dx codes. Use a SELECT statement to display this format.
