## 19.1 Introduction

The Output Delivery System (abbreviated ODS) allows you to send SAS output to a variety of destinations, such as HTML, PDF, RTF, and SAS data sets.

Not only can you send your SAS output to all of these formats, you can, if you are brave enough, customize the output's fonts, colors, size, and layout. Finally, you can now capture virtually every piece of SAS output to a SAS data set for further processing.

## 19.2 Sending SAS Output to an HTML File

Beginning in SAS 9.3 the default ODS Destination for SAS output is HTML. If you don't need your output in a file, you don't need to submit any ODS statements unless you want to capture procedure output to a SAS data set.

As an example, suppose you want to send the output of PROC PRINT and PROC MEANS to an HTML file. It takes only two SAS statement to do this, as shown next:

Program 19.1: Sending SAS Output to an HTML File

```
ods htmlpath='C:\books\learning\nfile='Sample.html';
title "Listing of Test_Scores";
proc print data=Learn.Test_Scores -
title2 "Sample of HTML Output - all defaults";
id;
var Score-Score3;
run;

title "Descriptive Statistics";
proc means data=Learn.Test_Scores nmiss min mean max maxdec=2;
var Score-Score3;
run;
```

All that is required to place an ODS HTML statement before the procedures that output you want to capture an ODS HTML CLOSE statement at the end. You specify a PATH= and a FILE= option on the HTML statement. The HTML extension (or HT for some environments) is not needed by SAS, but it allows the operating system to recognize that the file contains HTML tags and to open it with the appropriate browser.

## 19.3 Creating a Table of Contents

If your HTML output is large, you may elect to produce table of contents along with the normal HTML output. Remember that HTML is primarily intended to be viewed with web browser, not printed. A table of contents embeds links to each separate part of the output, allowing users to click on a link and go directly to different parts. To create a table of contents, you need to specify three files:

- A main file that contains procedure output
- A table of contents
- A frame file to display the other

Program 19.1: Program 19.2: Creating Table of Contents for HTML Output

```
ods body = 'Body_Sample.html'
contents = 'Contents_Sample.html'
frame = 'Frame_Sample.html'
path = 'c:\books\learning';
title "Using ODS to Create Table of Contents"
proc print data=Learn.Test_Scores n mean max
id;
var Name-Score3;
run;
title "Descriptive Statistics"
proc means data=Learn.Test_Scores n mean max
var Score-Score3;
run;
ods close;
```

The four keywords are BODY= CONTENTS= FRAME= and PATH=. You can name the files anything—the names do not need to include body, contents, or frame as example. If you are creating a web page from these files, you need to provide a link to FRAME file. A display of Contents_Sample.html is shown next.

## 19.4 Selecting a Different HTML Style

Although you can customize every aspect of the HTML output, it takes time and effort. There are a number of built-in styles that change the appearance of the output without any work on your part. The default style is called HTMLBLUE.

One way to select a list of styles, if you are in a windowing environment, is to select Tools ► Options ► then select the Tabs. You will see a long list of built-in styles you can choose from. For example, if you want black and white output, you could choose the Journal style, like this:

Program 19.3: Choosing a Style for HTML Output

```
ods html path = 'c:\books\learning'
             file = 'Journal_Example.html'
             style=Journal;

title "Listing of Test_Scores";
proc print data=Learn.Test_Scores;
    id
    var Name-Score3;
run;
ods html close;
```

## 19.5 Choosing Other ODS Destinations

You can create RTF (rich text format) or PDF (portable document format) files, which are both readable with Adobe Reader, in the same manner as HTML output. Besides providing a better appearance, using RTF or PDF allows users to see well-formatted SAS output without having to install SAS fonts on their machines. RTF is a somewhat universal format that can be incorporated into a Microsoft Office document directly.
