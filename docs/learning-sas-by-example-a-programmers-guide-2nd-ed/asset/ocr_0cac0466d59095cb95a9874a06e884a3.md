# Program 10.5: Using a SET Statement on Two Data Sets Containing Different Variables

```
data One_Three;
    set One Three;
run;
```

Looking at this output helps you understand what is going on. At compile, SAS looks at every data set listed in the SET statement. First comes data set One. This brings ID, Name, and Weight into the PDV (and all their attributes). Next SAS looks at data set Three. Are there variables in data set Three that are not already in the PDV? Yes, Therefore, Gender is added to the PDV.

Let's follow what goes on as Program 10.5 executes. First, all the variables in the PDV are set to missing. Then, each observation from data set One is read and written to the output data set. The PDV is not set back to missing as each observation in data set One is processed, but this doesn't matter because each new observation replaces the values in the PDV. (This would be true if one of the values in the current observation was missing.)

After all the observations in data set One are read and written out to data set One, SAS prepares to read observations from data set Three, all variables in the PDV are again set to missing. This is important because data set Three does not contain the variable Weight. If this initialization (setting values in the PDV to missing) did not take place, every coming from data set Three would wind up to 90 pounds (the last Weight value in data set One). SAS continues reading observations from data set Three until it reaches the end of that data set.

If the length of a variable is different in any of the input data sets, the length of the variable in the output data set is equal to the length that has in the first set encountered in the data step. It is a good idea to check lengths of character variables when you are combining several datasets to be sure you will not truncate any values. If necessary, place a LENGTH statement before the SET statement to be sure the resulting length is adequate to hold all of your values.
