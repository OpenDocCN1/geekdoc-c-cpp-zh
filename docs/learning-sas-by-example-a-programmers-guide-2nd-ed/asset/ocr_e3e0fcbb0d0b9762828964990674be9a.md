# 18.3.2 Table Dimensions (Page, Row, and Column)

The command in a TABLE statement controls the table's dimensions. If you do not include any commas in the TABLE statement, all of your table information is displayed as columns. If you include a single comma, the specification following the comma generates columns in the table; the specification before the comma generates rows. To demonstrate, Program 18.3 represents pages, the second, rows, and the for blood type frequencies to be displayed as columns and gender values to be displayed as rows.

Program 18.3: Demonstrating Table Dimensions with PROC TABULATE

```
title "Demonstrating Table Dimensions";nproc tabulate data=Learn.Blood format=6;
class Gender BloodType;
table Gender,
    BloodType;
run;
```

The resulting table is shown next:

If you use two commas in a table request, the first specification 1 * represents pages, the second, rows, and the last, columns.

# 18.3.3 Nesting

The third TABLE operator uses the asterisk (*). If you specify variable 1 * variable 2, variable 2 is nested within variable 1. To demonstrate, here is a request to nest BloodType within Gender:

Program 18.4: Demonstrating the Nesting Operator with PROC TABULATE

```
title "Demonstrating Nesting";nproc tabulate data=Learn.Blood format=6;
class Gender BloodType;
table Gender * BloodType;
run;
```
