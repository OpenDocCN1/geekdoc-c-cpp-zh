# Program 10.9: Demonstrating the IN= Data Set Option

```
Data New;
merge Employee(in=In Employee)
    Hours (in=In Hours);
  by ID;
    file print;
    put ID=In_Employee In_Hours Name=JobClass=Hours;
run;
```

An IN= data set option follows each data set name. Following the keyword IN= is a variable that you make up. In this example, the names Employee and In Hours were chosen. These variables are temporary variables (SAS will not add them to the output data set). They have a value of 1 (true) if the data set refer to is making a contribution to the current observation and 0 (false) otherwise. Because these variables are not in the output data set, Program 10.9 uses a PUT statement to list the values of these variables, along other variables in the data set. Here is the output:

Because Employee 1 is in both sets, In and Hours are both equal to 1 in the first observation. Employee 2 is in the data set but not in the other data set, so the second observation Employee is equal to 1 and In. Hours is equal to 0. Finally, in the last observation (ID=9), there is no corresponding ID in the data set, so In_Employee is equal to 0.

You can use IN= to control which observations are written to the output data set. For example, if you only want those who are in both data sets, you can adding a IF statement to the DATA step, like this:

# Program 10.10: Using IN= Variables to Select IDs That Are In Both Data Sets

```
Data Combine;
merge Employee(in=In Employee)
    Hours(in=In Hours);
  by ID;
    if In_Employee and In_Hours;
run;
```

You can, alternatively, write the subset IF statement like this:

```
if In_Employee = 1 and In_Hours = 1;
```
