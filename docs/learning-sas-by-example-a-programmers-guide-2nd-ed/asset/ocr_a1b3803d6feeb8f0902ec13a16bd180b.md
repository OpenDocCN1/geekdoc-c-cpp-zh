This is a detail report, showing all the observations in the data set. You may wonder why this is, because the default usage for numeric variables is ANALYSIS (with SUM as the default statistic). Because patient (Patno) is a character variable (with a usage of DISPLAY) and it is included in the report, the usage for numeric variables in the report also has to be DISPLAY. Having one DISPLAY variable in the report forces the usage to DISPLAY for the other variables. Some programmers prefer to explicitly code the usage for every variable in a report. title "Demonstrating the FLOW Option"
proc report data=Learn:Medical headline
