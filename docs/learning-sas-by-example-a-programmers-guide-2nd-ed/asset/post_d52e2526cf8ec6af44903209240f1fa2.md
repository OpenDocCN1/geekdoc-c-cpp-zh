### 21.2 Handling Missing Values at the End of a Line

Suppose you have a data file where some lines contain fewer values than you expect. For example, look at the file `Missing.txt`:

```
1 2 3
4 5
6 9 10 11
```

If you use the following SAS code:

```sas
data Missing;
  infile 'Missing.txt';
  x y z;
run;
```

You will notice in the SAS log that something is wrong. The second line only has two values (4 and 5), but the program expects three for x, y, and z. The log will state:

`NOTE: SAS went to a new line when INPUT statement reached the end of a line.`

This means SAS moved to the next line to find the value for `z`, resulting in `x=4, y=5, z=6`.

To fix this, you can use the `MISSOVER` option:

```sas
data Missing;
  infile 'Missing.txt' missover;
  x y z;
run;
```

With `MISSOVER`, SAS will set the remaining variable (z) to missing if the line ends before all variables are assigned.
