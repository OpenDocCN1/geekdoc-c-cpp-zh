Values for Gender are stored as M and F. Associating the SGENDER format with the variable Gender results in M displaying as Male, F displaying as Female, and missing values displayed as Not entered. The keyword other in the VALUE statement causes the text Miscoded to be printed for any characters beside M, F, or a missing value.

The format AGE is used to group ages into three categories. Notice that it is OK to use the same name for a format and a variable, (SAS knows that a name containing a period is.) If you apply this to the variable AGE, the ages are printed instead of the age remains. The internal values of SAS variables are not changed because they have been associated with a format. The format only affects how values print out, in some cases, how SAS procedures process a variable. (For example, PROC FRE computes frequencies of formatted values rather than raw values; PROC MEANS formatted variables listed in the CLASS statement, and so forth.)

In the AGE format, the keywords LOW and HIGH refer to the lowest nonmissing value and the highest value, respectively.

> Note: The keyword LOW when used with character formats includes missing values.

The last format, $LIKERT, is used to substitute the appropriate text for the digits 1 (**strongly disagree**) to 5 (**strongly agree**).

> Note: The name Likert was chosen because that is the name that psychometricians use for responses that range from strongly disagree to strongly agree.

Let’s see what happens when you place a format statement in PROC PRINT, as follows:

# Program 5.3: Adding a FORMAT Statement in PROC PRINT

```
title "Data Set SURVEY with Formatted Values"
proc print data=Learn.Survey;
id ID;
var Gender Age Salary Ques1-Ques;
format Gender $Gender.
Age $Age.
Ques1-Ques $Likert.
Salary $dollar11.2;
run;
```

Here forts the format SGENDER and AGE are used to format the variables Gender and Age, respectively. The format SLIKERT formats the five variables Ques through Ques5. Note that each format is followed by a period, just as the built-in SAS formats.

The format for Salary, DOLLAR11.2, is a SAS format. The name dollar indicates that you want to use the dollar format (which adds a dollar sign and commas to the value); the 11 tells SAS to print a value using 11 columns; the 2 following SAS you want to print two digits to the right of the decimal point. Note that the 11 columns include the dollar sign, the commas, and the decimal point. The largest value for Salary using the DOLLAR11.2 format would be:

$999,999.99
