##12.11: Demonstrating the NOT Functions for Data Cleaning

```
data "Data Cleaning Application"
  _null;
  file print;
  set Learn.Cleaning;
  if notalpha(trim(Letters)) then put Subject=Letters;
  if notdigit(trim(Digits)) then put Subject=Digits;
  if notalnum(trim(Both)) then put Subject=Both;
run;
```

It is important to understand why you need to use the TRIM function in this program. The TRIM function, each of the three NOT functions used would return the position of the first trailing blank in each of the character values. The three NOT functions are used to check for any invalid character type in each of the three variables. Here is the output:
