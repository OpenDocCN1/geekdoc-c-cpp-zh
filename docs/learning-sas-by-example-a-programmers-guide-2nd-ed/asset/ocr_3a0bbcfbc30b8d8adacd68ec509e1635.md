SELECT, FROM, and WHERE form a single query, which you end with a semicolon. In your example, you are not creating an output data set, so, by default, the result of this query is sent as a listing in the Output window (or whatever output location you have specified). Finally, the query ends with a QUIT statement. You do not need a RUN statement because PROC SQL executes as soon as a complete query has been specified. If you don't include a QUIT statement, PROC SQL remains in memory for another query.
