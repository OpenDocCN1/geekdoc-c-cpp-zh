# 12.2 Determining the Length of a Character Value

The LENGTH function returns the length of a character value, not counting trailing blanks. An older function, LENGTH, performed exactly as the LENGTH function with one exception—when the argument is a missing value. The LENGTH function returns 1 in this situation—the LENGTH function returns 0 (the preferred anch).

For those curious readers, the ‘N’ at the end of the LENGTH function stands for ‘null string,’ that is, a string of zero length. This concept was added with SAS9. You will see other functions in this chapter that are familiar to you except for that they now use an ‘N’. In most cases, use the ‘N’ version. Here is an example of the LENGTH function:

You have a SAS data set (Sales) that includes a variable called Name. You want to see all the names that are longer than 12 characters. Here is the program:

# Program 12.1: Determining the Length of a Character Value

```
data Long_Names;
set Learn.Sales;
if length (Name) gt 12;
run;
```

The subset IF statement is true when the number of characters in Name exceeds 12 (not counting trailing blanks including any blanks within the string).

Another function, LENTC, returns the storage length of a string. You may want to test storage lengths when you are combining data from multiple files.
