The following program demonstrates some uses of the PUT function:

# Program 11.14: Demonstrating the PUT Function

```
proc format;
    Agefmt low-<20 = 'Group One'
    20-<40 = 'Group Two'
    40-high = 'Group Three';

data Convert;
    set Learn.Numeric;
    Char_Date = put(Date,date9);
    AgeGroup = put(Age,Agefmt);
    Char_Cost = put(Cost,dollar10);
    drop Date Cost;
```

Data set Numeric contains three numeric variables: Date, Age, and Cost. In data set Convert, the three variables Char_Date, AgeGroup, and Cost are all character variables. The second argument of the PUT function specifies the format to apply to the first argument. Therefore, Char_date is a date in the DATE9, and Char_Cost is a value written using the DOLLAR10 format. Finally, AgeGroup applies a user-written format to place the age values into one of three groups. Here is a listing of the resulting data set.
