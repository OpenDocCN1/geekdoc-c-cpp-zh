# 15.17 Using an ACROSS Usage to Display Statistics

You can use an ACROSS usage to create a report showing a summary statistic for each level of the ACROSS variable. Here is an example.

You want to see the average age and red blood cell counts for each combination of gender, blood type, and age group in the Blood data set. You also want the age group variable to be displayed in separate columns of the report. Here is the program:

Program 15.20: Using ACROSS Usage to Display Statistics

```
title "Average Blood Counts by Age Group"
proc report data=Learn.Blood;
column Gender BloodType AgeGroup, WBC AgeGroup, RBC;
def Gender / group width=8 "Age Group"
def BloodType / group width=8 "Blood Group"
def AgeGroup / group width=8 "Age Group"
def WBC / analysis mean format=comma8;
def RBC / analysis mean format=8.2;
run;
```
