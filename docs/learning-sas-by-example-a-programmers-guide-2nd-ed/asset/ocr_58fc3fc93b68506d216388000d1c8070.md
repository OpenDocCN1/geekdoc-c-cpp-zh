# 25.3 Some Built-In Macro Variables

There are several built-in macro variables available to you as soon as you begin a SAS session. Two useful ones are &SYDATE9 and &SYSTIME. As you may guess, the former stores the date you started your SAS session (in DATE9 format) and the latter stores the time you started. As an example, you could use these automatic variable to include a date and time in a TITLE statement, like this:

# Program 25.1: Using an Automatic Macro Variable to Include a Date and Time in a Title

```
title "The Date is &Sysdate9 - The Time is &Sstime";
proc print data=Learn.Test_Scores noobs;
```

If you started your session at 10:02 on December 10, 2017, the macro processor would first resolve the macro variables (substitute text for the macro variable) before running the program. The listing would look like this:

Figure 25.1: Output from Program 25.1

| ID | Score1 | Score2 | Score3 |
|---|---|---|--|
| 1 | 90 | 95 | 98 |
| 2 | 78 | 77 | 75 |
| 3 | 88 | 91 | 92 |

This is a good thing to tell that if you place a macro variable inside quotation marks, SAS resolves macro variables that are inside double quotation marks. If you used single quotation marks in Program 25.1, the title would read:
