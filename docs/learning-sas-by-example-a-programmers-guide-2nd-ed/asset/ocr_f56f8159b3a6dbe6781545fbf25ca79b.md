The note that SAS went to a new line is important! It tells you exactly what happened and that you need to modify your program.

When you list input and you have some lines of data with fewer values than you need, you can use the INFILE option MISOVER to fix things. MISOVER tells SAS to set all the remaining variables if you have more variables than there are data values in one line of raw data. Here is the program with the MISOVER option added:

# Program 21.2: Using the MISOVER

```
data Missing;
infile 'c:\books\Learning\Missing.txt' missover;
input x y z;
```
