# Chapter 8: Performing Iterative Processing: Looping 111

This program demonstrates two things: first, you can use character values in a DO loop, second, you can nest one DO loop inside another. Let’s “play computer” and follow the execution of this program.

The outer loop first sets Group equal to Placebo. Next, the inner loop iterates five times, reading score values and outputting an observation each time (remember that Group is equal to Placebo for each of these five observations). When the inner loop is finished, control returns to the top of the outer loop where five more values of Score are read and five observations are written to the SAS data set.
