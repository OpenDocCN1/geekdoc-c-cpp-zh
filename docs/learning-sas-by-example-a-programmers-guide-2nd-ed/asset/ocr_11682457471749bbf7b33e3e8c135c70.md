Program 19.1: Sending SAS Output to an HTML File

```
ods htmlpath='C:\books\learning\nfile='Sample.html';
title "Listing of Test_Scores";
proc print data=Learn.Test_Scores -
title2 "Sample of HTML Output - all defaults";
id;
var Score-Score3;
run;

title "Descriptive Statistics";
proc means data=Learn.Test_Scores nmiss min mean max maxdec=2;
var Score-Score3;
run;
```

All that is required to place an ODS HTML statement before the procedures that output you want to
capture an ODS HTML CLOSE statement at the end. You specify a PATH= and a FILE= option on the
HTML statement. The HTML extension (or HT for some environments) is not needed by SAS, but it\allows the operating system to recognize that the file contains HTML tags and to open it with the
appropriate browser.
