# Chapter 2: Writing Your First SAS Program

In all the output displayed in this book, the global option NOPROTITLE was in effect. Without this option, all output from every procedure would contain text such as "The MEANS Procedure" before it prints your own title statements. The way to set this option is to use the line:

ODS NoProcTitle;

PROC FREQ is one of the built-in SAS procedures. As the name implies, this procedure counts frequencies of data values.

To tell this procedure variables you want to include in your frequency counts, you can add an additional statement—the TABLES (or TABLE) statement. Following the word TABLES, you list those for which you want frequency counts. You could actually omit A TABLES statement but, if you did, PROC FREQ would compute frequencies for every variable in your data set (including the numeric variables).

PROC MEANS is another built-in SAS procedure that computes means (averages) as well as some other statistics such as the minimum and maximum value of each variable. A VAR (short for variables) statement supplies PROC MEANS with a list of analysis variables (which must be numeric) for which you want to compute these statistics. Without a VAR statement, PROC MEANS computes statistics on every variable in your data set.
