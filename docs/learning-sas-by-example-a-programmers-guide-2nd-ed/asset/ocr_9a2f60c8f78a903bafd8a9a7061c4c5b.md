# 21.15 Using Relative Column Pointers to Read a Complex Data Structure Efficiently

Besides the absolute column pointer (@), SAS has a relative column pointer, plus sign (+). You can use this to move the current pointer left or right of its current position. Let's look at a few examples:

You have readers of the variables Time and Temperature aligned in pairs—Time values are in seconds and occupy 2 columns; Temperature values are in degrees and occupy 4 columns. The data pairs start in Column 5. Here are a few lines of data:

```
1 2 3 4 5
1234567890123456789012345678901234567890
1020.1120.21321.61525.01728.72031.42533.8
1021.71322.81528.01728.92129.92430.42833.7
```

The tedious way to read this line of file is:

```
input @5 Time1 2. @7 T1 4. @11 Time2 2. @13 T2 4.
@17 Time3 2. @19 T3 4. @23 Time4 2. @25 T4 4.
@29 Time5 2. @31 T5 4. @35 Time6 2. @37 T6 4.
@41 Time7 2. @43 T7 4;
```

If you use a relative column pointer, along with a variable informat list, this simplifies to following:

```
input @5 (Time1-Time7)(2. + 4)
@7 (T1-T7) (4. + 2);
```

THIS INPUT statement moves the pointer to Column 5. Then SAS reads a value for Time using a 2. informat and skips spaces. Because there are still variables in the variable list, this informat (read two spaces and skip four) keeps for the remaining values of Time. Next, the pointer moves back to Column 7. Here you read a value of Temperature using a 4. informat and skip two spaces. This informat is repeated until all the values of Temperature have been read.

If you use either of these INPUT statements in a DATA step, the resulting data sets are identical (except for the order of the variables).

As you saw in this chapter and Chapter 3, the INPUT statement is one of the most powerful statements in SAS and allows you to read almost any data file.
