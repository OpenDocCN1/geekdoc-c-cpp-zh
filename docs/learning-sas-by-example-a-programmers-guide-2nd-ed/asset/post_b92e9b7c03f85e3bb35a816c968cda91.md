## Program 22.22: Creating Several Informats with a Single CNTLN Data Set

```sas
data Exposure;
retain 'I' 'Hlo ' 'U';
length Fmtname $ 10;
do Year = 1944 to 1949;
 Fmtname = cats('Exp',Year,'fmt');
do Start = 'A','B','C','D','E';
  End Label : $3. @;
  output;
end;
end;
drop Year;
datalines;
220 180 210 110 90
202 170 200 100 85
150 110 150 60 50
105 56 88 40 30
60 30 40 20 10
45 22 22 10 8;
;
```

```sas
title "Creating the Exposure Format";
proc format cntlin=inform;
run;
```

**Type=u** tells PROC FORMAT that you want to create a numeric informat. The value of u for the HLO variable tells you the procedure to use the UPCASE option in the INVALUE statement. You want informat of the following form:

**yyyyfmt**

Here, **yyyy** is a year value from 1944 to 1949. The CATS function concatenates (joins) each of the arguments after first stripping off any leading or trailing blanks. This function allows numeric arguments and performs the numeric-to-character conversion as well. Here are the first few observations in the Exposure data set:

By the way, if you want to select informats using the SELECT statement of PROC FORMAT, you need to include an @ sign as the first character in the informat name. For example, to list the contents of EXP1944FMT and EXP1945FMT, you would use Program 22.23:

## Program 22.23: Using a SELECT Statement to Display the Contents of Two Informats

```sas
proc format;

run;
```

When you use SELECT statement with PROC FORMAT, it is not necessary to include the FMTLIB option as well.

Let's continue with our program. Now that you have an informat for each of the six years, all you have to use the year and job code to create an informat name and that name with INPUTN function to retrieve the error. Here is the program:

## Program 22.24: Using User-Defined Informats to Perform a Table Lookup Using the INPUTN Function

```sas
data ReadExp;
    input Worker Year JobCode;
    Exposure = input(JobCode,cats('Exp',Year,'fmt8.'));
    datalines;
001 1944 B
    002 1948 E
    003 1947 C
    005 1945 A
    006 1948 D
    ;
;
```

You cannot use the INPUT function in this program because that function the informat name must be a constant. The INPUTN function allows you to create the informat name in the DATA step. By the way, the 'N' in informat name tells SAS ahead of time if the informat you are going to be character or numeric (it can't tell if the name starts with a $ until it is created). There are two corresponding functions, PUT and UTC, which allow you to create character or numeric format names in the DATA step.

When this program runs, the informats are created with the CATS function. Each year creates a different informat name to be used in the INPUTN function. Here is a listing of the resulting data set:

## 23.1 Introduction

The data restructuring, also called transposing, means to take a data set with one observation per subject and convert it to a data set with many observations per subject, or vice versa. Why would you want or need to do this There are some operations that are most easily performed when all the information per subject (or other unit of analysis) is contained in a single observation. Other operations are more convenient when there are several observations per subject.

Several of the statistical procedures require data to be stored one way or the other, depending on what type of analysis is required.

This chapter demonstrates how to restructure data sets using DATA step approaches and PROC TRANSPOSE.
