# 10.12 Merging Data Sets with Different BY Variable Names

In a perfect world, multiple data sets would use the same name for the variable needed to put them together. You will sometimes find yourself trying to merge two data sets where the name of the variable you want to join has a different name in each data set. For example, one data set may call a variable ID and the other EmpID. Luckily, this is an easy problem to solve; you can use a RENAME= data option to rename the variable in one data set to be consistent with the name in the other. Also be sure that if you have character variables, the lengths of these variables is the same in each of the data sets.

Here is an example:

Data Bert has two variables: ID (a character variable) and X (a numeric variable). Data set Ernie has two variables: EmpNo (a character variable) and Y (a numeric variable). You want to merge these two data sets on the ID (or EmpNo) variable. Listings of these two data sets are shown here:

Figure 10.16: Listing of Data Sets Bert and Ernie

| Listing of Data Sets Bert | Listing of Data Set Ernie |
|---|---|---||
| ID | X | EmpNo | Y |
| 123 | 90 | 123 | 200 |
| 222 | 95 | 222 | 205 |
| 333 | 100 | 333 | 317 |

You can use the RENAME= data option to rename either ID to EmpNo or vice versa. Here’s one solution:

Program 10.13: Merging Two Data Sets by Renaming a Variable in One Data Set

```
data Sesame;
  merge Bert
  Ernie (rename=(EmpNo = ID));
  by ID;
run;
```
