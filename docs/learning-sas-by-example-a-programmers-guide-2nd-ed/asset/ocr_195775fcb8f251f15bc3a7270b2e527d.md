# 12 Learning SAS by Example: A Programmer’s Guide, Second Edition

When you use the SAS windowing environment, you write your program in the Enhanced EDITOR window (shown in Figure 2.1). Other windows that you will see later are the LOG window (where you see a listing of your program, possible error messages, and information about data files that were written) and the OUTPUT window where you see results.

To run this program, click the SUBMIT icon (see Figure 2.2).
