# Program 8.5: Creating a Cumulative Total with RETAIN and IF Statements (Third Attempt)

```
data Revenue:
  retain Total 0;
  input Day : $3;
    Revenue : dollar6;
  if not missing (Revenue) then Total = Total + Revenue;
  format Revenue Total dollar8;
datalines
Mon $1,000
Tue $1,500
Wed
Thu $2,000
Fri $3,000
;
```

```
title "Listing of Revenue"
proc print data=Revenue noobs;
run;
```

This time program worked correctly. But, there is an easier way: use a SUM statement. A SUM statement takes the following form:

```
variable + expression;
```

Notice there is no sign in this statement. That's what identifies this as a SUM statement to SAS. This statement does the following:

+   - Variable is retained
- Variable is initialized at 0
- Missing values (of increment) are ignored
