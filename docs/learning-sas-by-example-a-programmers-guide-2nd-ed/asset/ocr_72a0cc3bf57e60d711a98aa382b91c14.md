# 16.5 Applying a Format to a CLASS Variable

One nice feature of using a CLASS statement (besides not having to sort your data) is that SAS formatted values of the CLASS variable(s). You can use this to your advantage by adding a FORMAT statement to the procedure and changing how the CLASS variable groups your data, all without having to modify your data set.

Suppose you want to see some statistics (mean and median) for the two blood count variables (RBC and WBC), broken down by subjects with cholesterol levels below 200 versus subjects with cholesterol levels at or above 200. See how easy this is to do with a CLASS statement and a FORMAT statement:

Program 16.5: Demonstrating the Effect of a Formatted CLASS Variable

```
proc format;
    value Chol Group
    low - 200 = 'Low'
    200 - high = 'High';
run;
```

```
title "Using a CLASS Statement with PROC MEANS;\";
proc means data=Learn.Blood n miss mean median maxdec=1;
    class Chol;
    format Chol Chol Group;
    var RBC WBC;
run;"
```
