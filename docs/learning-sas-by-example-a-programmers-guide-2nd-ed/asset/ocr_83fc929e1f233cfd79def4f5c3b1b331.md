# 24.4 Computing Differences between Observations

Suppose you want to see changes in heart rate (HR), systolic blood pressure (SBP), and diastolic blood pressure (DBP) from visit to visit. The LAG function provides an easy way to compare values from the present observation to one in a previous observation. Here is a program to output changes from one visit to the next:

# Program 24.5: Computing Differences between Observations

```
data Difference;
  set Clinic;
  by ID;
  *Delete patients with only one visit;
  if first.ID and last.ID then delete;
  Diff HR = HR - lag(HR);
  Diff_SBP = SBP - lag(SBP);
  Diff_DBP = DBP - lag(DBP);
  if not first.ID then output;
run;
```

There are a few important points to notice about this program. First, you delete patients with only one visit (when both First.ID and Last.ID are true).
