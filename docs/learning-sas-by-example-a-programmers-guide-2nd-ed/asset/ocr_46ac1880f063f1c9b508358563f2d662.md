# Program 12.4: Demonstrating the Concatenation Functions

```
title "Demonstrating the Concatenation Functions"
data_null_ =
Length Join Name1 - Name4 $ 15;
First = 'Ron';
Last = 'Cody';
Join = ':' || First || ';';
Name1 = First || Last;
Name2 = cat(First,Last);
Name3 = catx(',',First,Last);
file print;
put Join=/nName1=/nName2=/nName3=/nName4=;
run;
```

Once again, monospaced output was used instead of HTML so that you can see multiple blanks easily. The variable Join is created by concatenation of colon to the front and back of the variable First. Notice that there are three blanks between Ron and the final colon. Name1 joins the variables First and Last, but because there are trailing blanks in First, there are three blanks between the names. The CAT function gives you the same result as the || operator. Notice that the variable Name3 has no blanks between the names the CATS function strips leading and trailing blanks before joining the strings. Finally, Name4 has a single blank between the first and last names because a blank was entered as the separator value.
