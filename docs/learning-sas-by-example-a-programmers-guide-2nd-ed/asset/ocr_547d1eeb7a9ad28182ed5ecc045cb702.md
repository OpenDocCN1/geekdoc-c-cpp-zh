# 12.1 Introduction

This chapter covers some of the basic functions that work with character values. These functions enable you to search for characters, strings apart and put them back again, and remove selected characters from a string. With SAS 9, you can search for or remove classes of characters, such as digits, punctuation marks, or space characters. You can even perform fuzzy matches between two character values—useful in matching names that may be misspelled. For more information, see SAS Functions by Example, 2nd edition by this author and SAS Help Center at http://go.documentation.sas.com.
