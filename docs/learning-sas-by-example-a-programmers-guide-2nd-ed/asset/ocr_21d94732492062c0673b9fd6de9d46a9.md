The following program converts all the character variable to propercase:

# Program 13.4: Converting All Character Values in a SAS Data Set to Propercase

```
data Proper;
  set Learn.Careless; _character_
  array AllChars{*} _character;

  do i = 1 to dim(AllChars);
    AllChars{i} = propercase(AllChars{i});
  end;

  drop i;
run;
```

The logic of this program is similar to the previous program. You use the keyword _CHARACTER_ to reference all the character variables in data set Careless, and then use a DO loop to convert all the values to Propercase.

# 13.5 Using an Array to Create New Variables

You can include variables in an ARRAY statement that do not exist in your SAS data set. For example, if your SAS data set had variables Fahrenheit1-Fahrenheit24 containing 24-Fahrenheit temperatures, you can use an array to create 24 new variables (say Celsius1-Celsius24 for the Celsius equivalents). Here is a program that accomplishes this:

# Program 13.5: Using an Array to Create New Variables

```
data Temp;
  input Fahrenheit24 @@;
  array Fahrenheit[24];
  array Celsius[24];
  do Hour = 1 to 24;
    Celsius{Hour} = (Fahrenheit{Hour} - 32)/1.8;
  end;
  drop Hour;
datalines;
```
