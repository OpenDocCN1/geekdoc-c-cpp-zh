# Program 12.10: Demonstrating the ANYDIGIT Function

```
data Any_Digit;
infile 'C:\books\learning\ID.txt';
input ID : $10;
Position = anydigit(ID);
if Position then output;
```

If the argument of ANYDIGIT contains any digits, the function returns the position of the first one. If not, ANYDIGIT returns a 0. This program added an extra line creating only so that you can see clearly how the ANYDIGIT function works. Remember that the value of Position will be nonzero for any ID that contains a digit. Because all values that are not 0 or missing are considered true in logical expressions, these IDs are written out to the data set Any_Digit. Here are the listings:

There is an optional second argument for all of the ANY functions. This argument indicates the starting position of the character to start looking for the specified characters. If the start value is negative, the search proceeds from right to left, starting at the absolute value of this parameter.

# 12.12 Using the NOT Functions for Data Cleaning

Another collection of functions, the NOT functions, are similar to the ANY functions. The difference is that these functions return the position of the first character in a string that does **not** belong to the specified class.

That makes this collection of functions especially useful for checking a character value for characters that don't belong. For example, if you expect a string to contain only digits, you can see the NOTDIGIT function returns any value greater than 0. Let's see some examples.
