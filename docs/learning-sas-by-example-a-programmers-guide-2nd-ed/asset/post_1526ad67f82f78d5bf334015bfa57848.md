## 22.1 Introduction

User-defined formats can do much more than make output from SAS procedures more readable. You will see how to use formats to create new variables and perform table lookups. You can even create your own informats to alter data values as they are being read into a SAS data set. Finally, certain SAS procedures support multi-label formats—that is, the ability to have a single value correspond to more than one format range.

## 22.2 Using Formats to Recode Variables

Many SAS procedures use formatted values of variables in their processing. For example, PROC FREQ uses formatted values when it computes frequencies; PROC MEANS uses formatted values of CLASS variables in its calculations.

As an example, suppose you want to compute frequencies on age groups (say, 20-year intervals), but your SAS data contains the variable Age. Rather than create a new variable representing age groups, you can simply write a format and use PROC FREQ, for this:

### Program 22.1: Using a Format to Recode a Variable

```
proc format;
  value Agefmt 0 - <20 = '0 to 19'
                    20 - <40 = '20 to 39'
                    40 - <60 = '40 to 59'
                    60 - high = '60+';
run;

title "Using a Format to Recode a Variable";
proc freq data=Learn.Survey;
  tables Age / nocum noperent;
  format Age Agefmt;
run;
```

When you run this program, the frequencies are computed for the age groups, not Age, as you can see in this listing:

### Program 22.1: Output from Program 22.1

| Using a Format to Recode a Variable |
| Age | Frequency |
|---|---|
| 20 to 39 | 3 |
| 40 to 59 | 2 |
| 60+ | 2 |

This same technique works for CLASS variables in MEANS, PROC SUMMARY, PROC TABULATE, PROC ANOVA, PROC GLM, and several other procedures.

## 22.3 Using Formats with a PUT Function to Create New Variables

There are times when you want to create a new variable consisting of formatted values. Program 22.2 demonstrates how this is done.

### Program 22.2: Using a Format and a PUT Function to Create a New Variable

```
proc format;
  0 - <20 = '< 20'
  20 - <40 = '20 to 39'
  40 - <60 = '40 to 59'
  60 - high = '60+';
run;

data Survey;
  set Survey;
  AgeGroup = put(Age,Agefmt.);
run;

title "Using a Format to Create a Character Variable";
proc print data=Survey;
  id ID;
  var AgeGroup;
run;
```

The key to this is the PUT function. This function takes the value of its first argument, formats this value with the format listed as the second argument, and returns the formatted value. Remember that the PUT function always returns a character value. In this example, AgeGroup is a character variable with a length of 8 bytes (the length of the longest formatted value). Here is a listing of data set Survey:

### 22.2: Output from Program 22.2

### Using a Format to Create a Character Variable |
| ID | Age | AgeGroup |
|---|---|---|
| 001 | 23 | 20 to 39 |
| 002 | 55 | 40 to 59 |
| 003 | 38 | 20 to 39 |
| 004 | 67 | 60+ |
| 005 | 22 | 20 to 39 |
| 006 | 63 | 60+ |
| 007 | 45 | 40 to 59 |

## 22.4 Creating User-Defined Informats

Although you are probably familiar with using PROC FORMAT to create user-written formats, you may not have this procedure to create your own informats. You can use user-written informats to alter values as they are read from a raw data file or with INPUT function to perform a table lookup. Let's look at an example.

Your raw data consists of IDs and letter grades (A+, A-, and so on). You want to convert these letter grades into numbers according to a predefined table. Program 22.3 creates an informat CONVERT and uses that to read the letter grades.

### Program 22.3: Demonstrating a User-Written Informat

```
proc format;
value Convert 'A+' = 100
               'A' = 96
               'A-' = 92
               'B' = 88
               'B-' = 84
               'C+' = 76
               'C' = 72
               'C-' = 65;
run;
data Grades;
    input @1 ID $3;
    @4 Grade Convert2;
datalines;
001A-
002B+
003F
004C*+
005AA
;
```

You use an INVALUE statement to create an informat. The rules are similar to the ones you use in creating formats. One tiny difference is that informat names can only be 31 characters in length (including the dollar sign ($) if it will be used to read character data). For curious minds, SAS uses 1 byte in the format catalog (@) to differentiate between informats and formats. If you look at the entries in your catalog with the FMTLIB option or PROC CATALOG, you will see the @ added to the informat names.

Following the keyword INVALUE, the type of the informat you want to create. Just as with formats, you must start the name with a dollar sign if it is used to create character data. In the previous program, even though you are reading character values (for example, A+, A– A–), the resulting variable (Grade) is a numeric variable. If you use the name SCON instead of CONVERT in this program, the Grade would be character.

Next, you specify ranges and labels. Again, use the same rules as formats. Use your informat just as you would a built-in SAS informat. Notice that you can add a width to it to specify how many columns of data to read. Here is a listing of data set Grades:

### Figure 22.3: Listing of Data Grades

### Listing of Data Grades

| 001 | 92 |

It is important to remember that the character data values are not part of this data set. If you wanted both the letter grade and its corresponding numeric value, you could read the letter grade as a character variable and use an INPUT function (with the CONVERT informat) to create the numeric grade.

There are some useful options you can use when you create your formats. UPCASE and JUST are two such options. UPCASE converts the data values to uppercase before checking on the informat ranges. JUST left-aligns character values. Let's use these two options to enhance Program 22.3.

### Program 22.4: Demonstrating Informat Options UPCASE and JUST

```
proc format;
invalid Convert (upcase just)
  'A+' = 100
  'A' = 96
  'A-' = 92
  'B+' = 88
  'B' = 80
  'B-' = 76
  'C+' = 72
  'C' = 65
  'F' = ;
;run;

data Grades;
  input @1 ID $;
  @4 Grade convert2;
datalines;
001A-
002b+
003F
004c+
005 A
006X
;
title "Listing of Grades";
proc print data=Grades noobs;
run;
```
