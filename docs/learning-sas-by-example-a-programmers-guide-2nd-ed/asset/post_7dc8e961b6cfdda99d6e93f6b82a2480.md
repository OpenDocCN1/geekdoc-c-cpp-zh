## Program 10.1: Subsetting a SAS Data Set Using a WHERE statement

```sas
data Females;
  set Learn.Survey;
  where Gender = 'F';
```

Remember that the variables used in a WHERE statement must all come from a SAS data set. Variables that are created by reading raw data or from an assignment statement may not be used in this fashion. In Program 10.1, the data set Females contains all the observations in the data set Survey where Gender has a value of F. Here is a listing of this data set:

Notice that the data set Females contains all the variables found in the data set Survey. If you do not need all the variables from the input data set (the data on the SET statement), you can use a KEEP= or DROP= data set option. For example, to keep ID, Gender, Age, and Ques1-Ques5, you can use the following method:

## Program 10.2: Demonstrating a KEEP= Data Set Option

```sas
data Females;
  set Learn.Survey(keep= ID Gender Age Ques1-Ques5);
  where Gender = 'F';
```

There is an important difference between using a KEEP= data set option on the input data set and placing a KEEP statement somewhere in the DATA statement. In this example, the variable Salary is not present in the Program Data Vector (PDV) because it was not included in the list of variables to keep. An alternative to listing eight variables with the KEEP= data set option would be to use DROP= data set. While this would save some typing, a KEEP= data set option instead of a DROP= data set allows someone reading your program to know what variables you are bringing in from the Survey data set. If you use DROP=Salary, you do not know what variables are being brought in from the Survey data set unless you already have a list of variables in that data set. See Chapter 2, "How SAS Works (a Look Inside the "Black Box")."

## Chapter 10: Subsetting and Combining SAS Data Sets

> **Note:** If you use a KEEP statement listing the eight variables instead of the KEEP= data set option, all of the variables, including Salary, would be in the PDV but not written out to the Females data set. If the input data set contains a large number of variables and you want only a few of these in the new data set, using the KEEP= data set option is more efficient than a KEEP statement.

You must remember when you use the KEEP= data set option, the variables not in the keep list are also not available in the DATA step.

## 10.3 Creating More Than One Subset Set in One DATA Step

You can create multiple SAS data sets from one input data set (something SQL cannot). Following the previous example, you can create a data set containing only females and one containing only males, in one step like:

## Program 10.3: Creating Two Data sets in One DATA Step

```sas
data Males;
  set Learn.Survey;
  if Gender = 'F' then output Females;
  else if Gender = 'M' then output Males;
run;
```

Notice that you must name the data set following the OUTPUT statement. If you do not, SAS outputs the observation to all the data sets listed in the DATA statement.

## 10.4 Adding Observations to a SAS Data Set

Suppose you want to create a single data set from several similar data sets. For example, your company may collect data each month into separate data sets and you want to analyze a year's worth of data. You can list as many data sets as you want on a SET statement and SAS will add all the observations together to form a single data set. For example, look at the listings of data sets One and Two here:

Each of the data sets contains the same variables. Also, the storage length for Name is the same in each of the two data sets. One way to combine these data sets is like this:

## Program 10.4: Using a SET Statement to Combine Observations from Two Data Sets

```sas
data One_Two;
  set One Two;
run;
```
