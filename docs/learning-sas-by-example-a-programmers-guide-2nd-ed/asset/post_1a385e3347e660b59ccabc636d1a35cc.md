## 18.5 Producing Descriptive Statistics

PROC TABULATE can also produce descriptive statistics such as sums and means. To specify that you want to generate descriptive statistics rather than frequency counts, you list all of your analysis variables (that is, the ones for which you want statistics) in a VAR statement. 

> Note: Descriptive statistics may appear on any dimension of a table, but you may only define statistics on a single dimension of a table.

Program 18.6 computes descriptive statistics for the RBC (red blood cell) and WBC (white blood cell) counts:

Program 18.6: Using PROC TABULATE to Produce Descriptive Statistics

```sas
title "Demonstrating Analysis Variables";
proc tabulate data=Learn.Blood;
var RBC WBC;
table RBC WBC;
run;
```

The resulting output follows:

### Figure 18.7: Output from Program 18.6

| RBC | WBC |
| Sum | Sum |
| 5022.91 | 6395020.00 |

The operator between RBC and WBC was a space, the analysis columns are concatenated. The default descriptive statistic is the sum (not a very useful statistic for blood counts). To specify one or more analyses for each variable, you use keywords (sum, mean, min, max, std, and so on) to specify which statistics you want and associate these statistics with a variable using the nesting (asterisk) operator. For example, to specify the mean rather than a sum for RBC and WBC, you would use the code in Program 18.7.

### Program 18.7: Specifying Statistics on an Analysis Variable with PROC TABULATE

```sas
title "Specifying Statistics";
proc tabulate data=Learn.Blood;
var WBC;
table RBC*mean WBC=mean;
run;
```

To save typing, you can also write the TABLE statement like this:

```sas
table (RBC WBC)*mean;
```

Either way, you now have a table showing the mean (average) blood counts:

### Figure 18.8: Output from Program 18.7

| RBC | WBC |
| Mean | Mean |
| 5.48 | 7042.97 |

The output now shows instead of the default statistic of sums. You can specify several statistics for each variable as well. For example, if you would like the mean, minimum, and maximum values for the blood counts, you could write Program 18.8:

### Program 18.8: Specifying More than One Descriptive Statistic with PROC TABULATE

```sas
title "Specifying More than One Statistic";
proc tabulate data=Learn.Blood format=comma9.2;
var RBC WBC;
table (RBC WBC) * (mean min max);
run;
```

Each statistic is now listed for each of the two variables, this:

### Figure 18.9: Output from Program 18.8

Specifying More than One Statistic

| RBC | | WBC |
| Mean Min Max | Min Max |
| 5.48 1.71 8.75 | 4.07.00 10.5500 |

This program uses the PROC TABULATE option FORMAT=COMMA9.2 to improve the readability of the output. Now you have the mean, minimum, and maximum value for RBC and WBC counts, each displayed with a 9.2 numeric format.

## 18.6 Combining CLASS and Analysis Variables in a Table

What if you want to see the mean value for RBC and WBC broken down by one or more of the CLASS variables (such as Gender or BloodType). You can combine frequencies and descriptive statistics in a single table. Here is where some people complain that PROC TABULATE is very difficult to use, Actually, the problem is more likely that the user did not decide what the table should look like before starting to write the TABULATE statements. It also takes some practice to arrange a table so that columns are not split between pages (making it very hard to read).

The next program is a request for the mean RBC, WBC, and Chol (cholesterol), broken down by Gender and AgeGroup.

### Program 18.9: Combining CLASS and Analysis Variables in the Table

```sas
title "Combining CLASS and Analysis Variables";
proc tabulate data=Learn.Blood format=comma1.2;
class Gender AgeGroup;
var RBC WBC Chol;
table (Gender ALL) * (AgeGroup All);
(RBC WBC Chol) *mean;
run;
```

This request nests AgeGroup and ALL within each value of Gender and ALL. The means of RBC, WBC, and Chol are displayed as columns of the table, like this:

## 18.7 Customizing Your Table

PROC TABULATE allows you to customize your table in several ways. You can associate a format with the table or rename any of the keywords, such as ALL or MEAN. If you look back at the output produced by Program 18.7, you see that the default format is useful for values of RBC but not for WBC (where you would rather see any decimal). The program follows a different format with each of these variables:

### Program 18.10: Associating a Different Format with Each Variable in the Table

```sas
title "Specifying Format";
proc table data=Learn.Blood;
var RBC WBC;
table RBC*mean=f=7.2 WBC*mean=f=comma7;
run;
```

You see another use of the asterisk. It is used to associate a format with a specific value. You can nest the formatting within the statistic.

### Figure 18.11: Output from Program 18.10

Specifying Formats

| RBC | WBC |
| Mean | Mean |
| 5.48 | 7.043 |

To demonstrate how to rename PROC TABULATE keywords, take a look at Program 18.11.

### Program 18.11: Renaming Keywords with PROC TABULATE

```sas
title "Specifying Formats and Renaming Keywords";
proc tabulate data=Learn.Blood;
class Gender;
var RBC WBC;
table Gender: ALL,
RBC*(mean*f=9.1 std*f=comma.2);
WBC*(mean*f=comma.9 std*f=comma.1);
keylabel ALL = 'Total'
mean = 'Average'
std = 'Standard Deviation';
```

The KEYLABEL statement allows you to provide a label for any of the keywords used by the procedure. In this program, ALL is replaced with Total, Mean by Average, and std by Standard Deviation. In addition, different formats are associated with the mean and the standard deviation. This is particularly useful when you are computing statistics like N (the number of nonmissing observations) or NMISS (the number of missing values), where you want integer values, along with means or statistics, where you may want to see the digits to the right of the decimal point. While we are on the topic of improving the appearance of your tables, look back at the output table from Program 18.1. The row of Ns across the table is not necessary. You can eliminate them by providing a null label (a blank) within the TABLE statement, request, like:

### Program 18.12: Eliminating the N Column in a PROC TABULATE Table

```sas
title "Eliminating the 'N' Row from the Table";
proc tabulate data=Learn.Blood format=6;
class Gender;
table Gender=n=' ';
run;
```
