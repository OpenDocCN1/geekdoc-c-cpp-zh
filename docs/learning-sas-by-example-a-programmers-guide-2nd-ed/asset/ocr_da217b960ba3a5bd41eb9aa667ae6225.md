To demonstrate how to rename PROC TABULATE keywords, take a look at Program 18.11.

# Program 18.11: Renaming Keywords with PROC TABULATE

```
title "Specifying Formats and Renaming Keywords";
proc tab data=Learn.Blood;
 class Gender;
 var RBC WBC;
table Gender: ALL,
RBC* (mean*f=9.1 std*f=comma.2);
WBC* (mean*f=comma.9. std*f=comma.1);
keylabel ALL = 'Total'
mean = 'Average'
std = 'Standard Deviation';
```

The KEYLABEL statement allows you to provide a label for any of the keywords used by the procedure. In this program, ALL is replaced with Total, Mean by Average, and Sid by Standard Deviation. In addition, different formats are associated with the mean and the standard deviation. This is particularly useful when you are computing statistics like N (the number of nonmissing observations) or NMISS (the number of missing values), where you want integer values, along with means or statistics, where you may want to see the digits to the right of the decimal point.
