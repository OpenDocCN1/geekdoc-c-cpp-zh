You can select variables from two tables by listing all the variables of interest in the SELECT clause and listing the two data sets in the FROM clause. If a variable has the same name in both data sets, you need a way to distinguish which data set to use. Here's how it's done:

# Program 26.4: Joining Two Tables (Cartesian Product)

```
title "Demonstrating a Cartesian Product";
proc sql;
select Health.Subj,
      Demographic.Subj,
      Height,
      Weight,
      Name,
      Gender,
from Learn.Health,
     Learn.Demographic;
quit;
```

Because the column Subj is in both tables, you prefix the variable name with the table name. You will see in a minute that you can simplify this bit. The result from this query is called a Cartesian product and it represents all possible combinations of rows from the first table with rows from the second table. The listing shows two columns, both with the heading of Subj.
