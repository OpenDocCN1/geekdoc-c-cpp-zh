### 多项式表示

请注意将多项式表示为线性链表的以下三个前提条件：

- 多项式项必须在线性链表中按指数递减顺序存储。
- 不能有两个项具有相同的指数。
- 不能有任何项的系数为零。

线性链表的每个节点将表示多项式的一项，是一个包含以下信息的结构体：

- 系数
- 指数
- 指向多项式下一项的指针

```c
typedef struct poly {
   float coeff;
   int expo;
   struct poly *next;
} *POLYPTR;
```

### 相加两个多项式

要将两个多项式相加，我们只需各扫描一次：

- 如果在两个多项式中找到指数相同的项，则相加系数并将新项复制到和多项式的末尾；否则，将指数较大的项复制到和多项式中并继续。
- 当到达其中一个多项式的末尾时，将另一个多项式的剩余部分复制到和多项式中。

我们必须小心不要在和中包含系数为 0 的项。例如：

6X^5 + 2X^4 + 3X^3 + 2X
+
3X^5 - 2X^4 - 5X^2 - 8X + 7
9X^5       + 3X^3 - 5X^2 - 6X + 7

```c
// poly.c

#include <stdio.h>

typedef struct poly {
    float coeff;
    int expo;
    struct poly *next;
} *POLYPTR;

POLYPTR sum(POLYPTR p, POLYPTR q) {
    float coeff;
    POLYPTR add = NULL;

    while (p != NULL && q != NULL) {
        if (p->expo == q->expo) {
            coeff = p->coeff + q->coeff;
            if (coeff) {
                makeTerm(add, coeff, p->expo);
                p = p->next;
                q = q->next;
            }
        } else if (p->expo > q->expo) {
            makeTerm(add, p->coeff, p->expo);
            p = p->next;
        } else {
            makeTerm(add, q->coeff, q->expo);
            q = q->next;
        }
    }

    while (p) {
        makeTerm(add, p->coeff, p->expo);
        p = p->next;
    }

    while (q) {
        makeTerm(add, q->coeff, q->expo);
        q = q->next;
    }

    return add;
}
```

在算法的多个位置，我们必须使用给定的系数和指数创建一个新项，并将其放在和多项式的末尾，即位于 `last` 指向的项之后。请注意，指针 `add` 将始终指向创建的第一个项，而指针 `last` 将始终指向和多项式的最后一个项。

```c
void makeTerm(POLYPTR *add, float coeff, int expo) {
    POLYPTR t;
    POLYPTR last = NULL;

    t = (POLYPTR) malloc(sizeof(struct poly));
    t->coeff = coeff;
    t->expo = expo;
    t->next = NULL;
    if (*last == NULL) {
        *add = t;
    } else {
        last->next = t;
    }
    last = t;
}
```
