# Combining Logical and Relational Operators

We can combine logical and relational operators to test whether a character is a:

+   - digit
+   - uppercase letter
+   - lowercase letter
+   - printable character

Note that it is typical to place 0x in front of a hexadecimal (base 16) digit:

```
// ascii1.c

#include <stdio.h>

int main(void) {
    unsigned char c;

    for (c = 0; c <= 127; ++c) {
        printf("%3d 0x%03x', c, c);

        // check for printable character
        if (c >= ' ' && c <= '~') {
            printf(" '%c'", c);
        }

        // check for digit
        if (c >= '0' && c <= '9') {
            printf("digit");
        }

        // check for uppercase
        if (c >= 'A' && c <= 'Z') {
            printf("uppercase");
        }

        // check for lowercase
        if (c >= 'a' && c <= 'z') {
            printf("lowercase");
        }

        printf("\n");
    }

    return 0;
}
```
