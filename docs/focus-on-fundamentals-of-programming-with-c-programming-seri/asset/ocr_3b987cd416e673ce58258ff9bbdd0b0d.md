```c
// swap1.c

void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}
```
```

The swap() function will swap any pair of int data items, even if those items are array elements.

Our relevant code in main() looks like this:

```
```c
// swap2.c

small = getMinIndex(num, 10);
swap(&num[0], &num[small]);
```
```

Note that although arrays are automatically passed to functions by reference, individual array elements are passed by value unless preceded by the ampersand in the function call. Thus, num[0] and num[small] are just single elements of type int of array num and must be explicitly passed by reference.
