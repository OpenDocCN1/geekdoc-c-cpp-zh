# Function Motivation

Suppose we wished to generate a table of powers with the following format:

| Number | Square | Cube |
| :--- | :--- | :--- |
| 1 | 1 | 1 |
| 2 | 4 | 8 |
| 3 | 9 | 27 |
| 4 | 16 | 64 |
| 5 | 25 | 125 |
| 6 | 36 | 216 |
| 7 | 49 | 343 |
| 8 | 64 | 512 |
| 9 | 81 | 729 |
| 10 | 100 | 1000 |

Our code might look like this:

```
// funct1.c
// Generate tables of powers

#include <stdio.h>

int main(void) {
    int i;

    for (i = 1; i <= 60; i++) {
        printf("%c", '-');
    }

    printf("\n");
    printf("%15s%15s%15s\n", "Number", "Square", "Cube");
    for (i = 1; i <= 60; i++) {
        printf("%c", '-');
    }

    printf("\n");
    for (i = 1; i <= 10; i++) {
        printf("%15d%15d%15d\n", i, i*i, i*i*i);
    }

    for (i = 1; i <= 60; i++) {
        printf("%c", '-');
    }

    printf("\n");
    return 0;
}
```
