We can write this more concisely:

```
// strcpy2.c
void strcpy(char s1[], char s2[]) {
    int i = 0;
    while ((s1[i] = s2[i]) != '\0') {
        ++i;
    }
}
```

+   • strcpy(s1, s2 )

Copies string s2 to onto the end of string s1.

Its function prototype is:

```
void strcpy(char *s1, char *s2);
```

For example:

```
char buf[32] = "Hello,";
strcpy(buf, " world.");
printf("%s\n", buf);
```

outputs the string:

```
Hello, world.
```
