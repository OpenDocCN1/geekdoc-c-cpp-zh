Here's an example of the use of the `strcmp()` function:

```
// compareStrings.c

#include <stdio.h>
#include <string.h>

int main(void) {
    int num;

    char s1[] = "red";
    char s2[] = "blue";
    num = strcmp(s1, s2);
    if(num < 0) {
        printf("%s is smaller.\n", s1);
    }
    else if (num > 0) {
        printf("%s is smaller.\n", s2);
    }
    else {
        printf("The strings are the same.");
    }
    return 0;
}
```

The output produced looks like this:

```
blue is smaller.
```

Note that C does not allow us to directly compare two strings for equality using the equality operator:

```
if (s1 == s2)
```

This is due to the fact that the equality operator can only be applied to simple variable types such as int, float, char, etc., but not to arrays, strings, or structures.
