We can add two integers and display the result:

```
// add.c
#include <stdio.h>
int main(void) {
   int num1, num2, sum;
   num1 = 50;
   num2 = 75;
   sum = num1 + num2;
   printf("The sum of %d and %d is %d.\n", num1, num2, sum);
   return 0;
}
```

The output is:

```
The sum of 50 and 75 is 125.
```

Shown below is a table of control string formats:

| %d | integer or decimal (base 10) format | %u | unsigned decimal |
| %ld | long decimal format | %lu | unsigned long decimal format |
| %f | floating point format | %e | scientific notation format |
| %lf | double format | %o | octal format |
| %c | character format | %x | hexadecimal format |
| %s | character string format | | |
