# if-else statement: Double Alternative Decision Statement

The pseudo-code example below:

```
if x is not equal to zero then
    divide y by x and assign the requly to num
else // otherwise
    display an error message
```

can be read as follows:

If the condition "x is not equal to zero" is true, divide the value of y by
the value of x and assign the result to variable num. Otherwise, the condition "x
is not equal to zero" is false. In this case, display an error message.

Note that the conditions shown above are logical expressions. When you
evaluate them, you get either true or false. These are the only two possible
values for a logical expression!

The syntax for the if-else statement is as follows:

```
if (expression) {
    statement1;
} else {
    statement2;
}
```

Here's what the C code might look like for the above pseudo-code example:

```
if (x != 0) {
    num = y / x;
} else {
    printf ("Divide by zero error condition.");
}
```
