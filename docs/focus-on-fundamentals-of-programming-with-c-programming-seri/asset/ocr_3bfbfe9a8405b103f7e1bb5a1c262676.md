For example, we can convert the decimal integer 147 into binary:

```
147 / 2 = 73 remainder = 1
73 / 2 = 36 remainder = 1
36 / 2 = 18 remainder = 0
18 / 2 = 9 remainder = 0
9 / 2 = 4 remainder = 1
4 / 2 = 2 remainder = 0
2 / 2 = 1 remainder = 0
1 / 2 = 0 remainder = 1
```

So 147 decimal is equivalent to 10010011 binary.
