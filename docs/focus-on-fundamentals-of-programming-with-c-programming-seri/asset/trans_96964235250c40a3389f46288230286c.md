

## 运算符作业

- 1. 编写一条 C 语句来完成以下每项任务：
  - a) 将 `x` 和 `y` 的和赋给 `z`，并在计算后将 `y` 的值减 1。
  - b) 使用 `*=` 运算符将 `num` 乘以 3。
  - c) 将变量 `x` 加 1，然后从变量 `value` 中减去它。
  - d) 将变量 `x` 加到变量 `total` 中，然后将 `x` 加 1。

- 2. 显示以下每个程序片段产生的输出。假设 `i`、`j`、`k` 是 `int` 变量。
  - a)
    ```c
    i = 7; j = 2;
    printf("%d %d", i / j, i % j);
    ```
  - b)
    ```c
    i = 4; j = 3;
    printf("%d%d", (i + 10) % j);
    ```
  - c)
    ```c
    i = 7; j = 8; k = 9;
    printf("%d", (i + 10) % k / j);
    ```

- 3. 显示以下每个程序片段产生的输出。假设 `i`、`j`、`k` 是 `int` 变量。
  - a)
    ```c
    i = 7; j = 8;
    i *= j + 3;
    printf("%d %d", i, j);
    ```
  - b)
    ```c
    i = j = k = 1;
    i *= j *= k;
    printf("%d %d %d", i, j, k);
    ```

- 4. 显示以下每个程序片段产生的输出。假设 `i`、`j`、`k` 是 `int` 变量。
  - a)
    ```c
    i = 4;
    j = ++i * 3 - 2;
    printf("%d %d", i, j);
    ```
  - b)
    ```c
    i = 3;
    j = 3 - 2 * i++;
    printf("%d %d", i, j);
    ```
  - c)
    ```c
    i = 2; j = 5;
    printf("%d ", i++ - ++j);
    printf("%d %d", i, j);
    ```

- 5. 添加括号以显示 C 编译器将如何解释以下每个表达式。
  - a) a * b - c * d + e
  - b) a / b % c / d

- 6. 执行以下每个表达式语句后，给出 i 和 j 的值。假设 i 初始值为 1，j 初始值为 2。
  - a) i += j;
  - b) i--;
  - c) i *= j / i;
  - d) i % ++j;

- 7. 使用德·摩根定律为以下每个表达式编写等价表达式：
  - a) ! ( x < 8 ) && ! ( y >= 3 )
  - b) ! ( x == y ) || ! ( z != 2 )
  - c) ! ( ( x <= 3 ) && ( y > 7 ) )
  - d) ! ( ( x > 2 ) || ( y <= 4 ) )
