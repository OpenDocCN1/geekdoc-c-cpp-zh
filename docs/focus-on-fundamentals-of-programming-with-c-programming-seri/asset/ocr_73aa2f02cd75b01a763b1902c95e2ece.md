actually is interpreted as;

```
x = (y = (z = 0));
```

which assigns 0 to z, then y, then x.

The assignment operator is even more flexible. For example:

```
x = x + 2
```

can be written as:

```
x += 2;
```

The assignment += is a combination of the add (+) and assignment (=) operators. All arithmetic operators have combined forms like this:

```
x += n;     // add n to x
x -= n;     // subtract n from x
x *= n;     // multiplyly x by n
x /= n;     // divide x by n
x %= n;     // x gets the remainder of dividing x by n
```

Note that:

```
x *= y + 1;
```

is equivalent to:

```
x = x * (y + 1);
```

and not:

```
x = x * y + 1;
```
