Here's a short program that prints the absolute value of a number:

```
```c
//absoluteValue.c
#include <stdio.h>
int main(void) {
    int num;
    printf("Enter a value: ");
    scanf_s("%d", &num);
    if (num < 0)
        num = -num;
    printf("The absolute value is %d\n", num);
    return 0;
}
```
```

Side effects are allowed inside the expression. It's good C style to use them to avoid creating otherwise useless "temporary" variables. Thus,

```
```c
if (scanf_s("%d", &num) != 1) {
    printf("Bad value.\n");
}
```
```

is better than

```
```c
temp = scanf_s("%d", &num);
if (temp != 1) {
    printf("Bad value.\n");
}
```
```

Due to the fact that an expression will result in a zero (false) or a non-zero value, we would use:

```
```c
if (expression)
```
```

instead of

```
```c
if (expression != 0)
```
