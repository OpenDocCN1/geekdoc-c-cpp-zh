# Two-Dimensional Arrays

We can declare a two-dimensional array consisting of both rows and columns:

```
```c
// 2dim1.c
int num [3][4];
```
```

This statement declares an array consisting of three rows and four columns:

| | Col 0 | Col 1 | Col 2 | Col 3 |
|---|---|---|---|---|
| Row 0 | | | | |
| Row 1 | | | | |
| Row 2 | | | | |

The elements of the two-dimensional array are identified as follows:

| | Col 0 | Col 1 | Col 2 | Col 3 |
|---|---|---|---|---|
| Row 0 | num[0][0] | num[0][1] | num[0][2] | num[0][3] |
| Row 1 | num[1][0] | num[1][1] | num[1][2] | num[1][3] |
| Row 2 | num[2][0] | num[2][1] | num[2][2] | num[2][3] |
