
如前所述，在逻辑表达式求值中，一旦结果（真或假）已知，求值过程就会停止（短路。）

例如，如果 `expr1` 为假（0），那么在语句中：

```
expr1 && expr2
```

`expr2` 不会被求值，因为逻辑表达式的值已经确定为零。

同样，如果 `expr1` 为真（非零），那么在语句中：

```
expr1 || expr2
```

`expr2` 不会被求值，因为逻辑表达式的值已经确定为 1。

## 德摩根定律

德摩根定律有时可以让我们更方便地表达逻辑表达式。德摩根定律可以用数学表达如下：

```
~(P or Q) = ~P and ~Q
~(P and Q) = ~P or ~Q
```

在 C 语言中，这些定律表明表达式：

```
! (condition1 && condition2)
```

在逻辑上等价于表达式：

```
(!condition1 || !condition2)
```

另外，表达式：

```
! (condition1 || condition2)
```

在逻辑上等价于表达式：

```
(!condition1 && !condition2)
```

总结：

```
!(condition1 && condition2) = (!condition1 || !condition2)
!(condition1 || condition2) = (!condition1 && !condition2)
```

看看你能否将德摩根定律应用到以下表达式：

```
!(x > 5) || !(y > 7)
```

## 组合逻辑运算符和关系运算符

我们可以组合逻辑运算符和关系运算符来测试字符是否为：

- 数字
- 大写字母
- 小写字母
- 可打印字符

注意，通常在十六进制（基数 16）数字前放置 0x：

```
// ascii1.c

#include <stdio.h>

int main(void) {
    unsigned char c;

    for (c = 0; c <= 127; ++c) {
        printf("%3d 0x%03x", c, c);

        // check for printable character
        if (c >= ' ' && c <= '~') {
            printf(" '%c'", c);
        }

        // check for digit
        if (c >= '0' && c <= '9') {
            printf("digit");
        }

        // check for uppercase
        if (c >= 'A' && c <= 'Z') {
            printf("uppercase");
        }

        // check for lowercase
        if (c >= 'a' && c <= 'z') {
            printf("lowercase");
        }

        printf("\n");
    }

    return 0;
}
```

## 字符类型测试

字符类型测试在编程中出现得足够频繁，以至于它们已被纳入名为 ctype.h 的标准 C 库头文件中。使用此文件，我们可以这样写：

```
if(isdigit(c))
```

而不是

```
if (c >= '0' && c <= '9')
```

或

```
if (isupper(c))
```

而不是

```
if (c >= 'A' && c <= 'Z')
```

要使用允许我们访问此库的 ctype.h 头文件，我们发出以下预处理器命令：

```
#include <ctype.h>
```

这一行是对 C 预处理器的命令，用于将一些标准定义包含到我们的编译中，以便识别 isdigit() 和 isupper() 等名称。

以下是可用库函数的列表：

```c
int isalnum(int c);
```
c 是字母数字字符
如果 c 是字母（A-Z 或 a-z）或数字（0-9），则返回非零值

```c
int isalpha(int c);
```
c 是字母
如果 c 是字母（A-Z 或 a-z），则返回非零值

```c
int isascii(int c);
```
c 是 ASCII 字符（代码小于 0200 或 128）
如果 c 的低序字节在范围 0-127（0x00-0x7F）内，则返回非零值

```c
int iscntrl(int c);
```
c 是不可打印字符（小于 ' '）
如果 c 是删除字符或普通控制字符（0x7F 或 0x00-0x1F），则返回非零值

```c
int isdigit(int c);
```
c 是数字
如果 c 是数字（0-9），则返回非零值

```c
int isgraph(int c);
```
c 是图形字符
如果 c 是打印字符（类似于 isprint()，但不包括空格字符），则返回非零值

```c
int islower(int c);
```
c 是小写字母
如果 c 是小写字母，则返回非零值

```c
int isprint(int c);
```
c 是可打印字符（包括空格）
如果 c 是打印字符（0x20-0x7E），则返回非零值

```c
int ispunct(int c);
```
c 是标点字符
如果 c 是标点字符（iscntrl() 或 isspace()），则返回非零值

```c
int isspace(int c);
```
c 是空白字符（空格、制表符、回车换行或换页符）
如果 c 是空格、制表符、回车、换行、垂直制表符或换页符（0x09-0x0D, 0x20），则返回非零值

```c
int isupper(int c);
```
c 是大写字母
如果 c 是大写字母，则返回非零值

```c
int isxdigit(int c);
```
c 是十六进制数字
如果 c 是十六进制数字（0-9, A-F, a-f），则返回非零值

```c
int toascii(int c);
```
通过清除除低 7 位（0-127）外的所有位，将整数 c 转换为 ASCII
返回转换后的 c 值

```c
int tolower(int c);
```
将 c 转换为小写
如果 c 是大写字母，则返回转换后的值；其他所有字符保持不变

```c
int toupper(int c);
```
将 c 转换为大写
如果 c 是小写字母，则返回转换后的值；其他所有字符保持不变

我们可以使用 ctype.h 库重写前面的程序：

```
// ascii2.c

#include <stdio.h>
#include <ctype.h>

int main(void) {
    unsigned char c;
    for (c = 0; c <= 127; ++c) {
        printf("%3d 0x%03x", c, c);
        if (isprint(c)) {
            printf(" '%c'", c);
        }
        if (isdigit(c)) {
            printf("%d", c);
        }
        if (isupper(c)) {
            printf("UC");
        }
        if (islower(c)) {
            printf("lc");
        }
        if (isalpha(c)) {
            printf("L");
        }
        if (isalnum(c)) {
            printf("AN");
        }
        if (isspace(c)) {
            printf("S");
        }
        if (ispunct(c)) {
            printf("P");
        }
        if (iscntrl(c)) {
            printf("C");
        }
        printf("\n");
    }
    return 0;
}
```
