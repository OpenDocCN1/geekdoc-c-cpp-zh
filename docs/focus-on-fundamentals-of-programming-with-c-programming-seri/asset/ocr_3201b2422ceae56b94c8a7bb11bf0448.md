# Functions, Arrays and Pointers

Given the following declarations:

```
int main(void) {
    int num[100];
    foo(num);
    return 0;
}

void foo(int list[]) {
    :
    :
}
```

Array num is an array containing 100 elements. How many elements are contained within array list? The answer is that there is no array list!! The formal parameter declaration:

```
int list[]
```

creates not an array, but a pointer. Why? Note our function call:

```
foo(num);
```

The argument is num and the name num is not only the name of the array, but is also a pointer to the first element of the 100 element array. So the function call passes a pointer, the address of the array, to the function foo(). This means that the argument of foo() is a pointer, and we could have written:

```
void foo(int *list) {
    :
    :
}
```
