# Operations on Linear Linked Lists

If p is a pointer to a node:

+   • p = getNode()

Obtains an empty node and sets the contents of a pointer variable named p to the address of that node. This means that p is a pointer to this newly allocated node.

![](bbox=[0.12, 0.25, 0.35, 0.3])

+   • freeNode(p)

Returns the node pointed to by p to the source of unused nodes and makes the node available for reuse.

![](bbox=[0.12, 0.43, 0.25, 0.46])

+   • info(p)

Refers to the information portion of the node that is pointed to by p.

x = info(p) assigns the contents of the info field of the node pointed to by p to x.
