As an OS, the IOS is designed to be regularly updated via an always-on Internet connection called WiiConnect24. Games for the Wii on discs are often distributed with the software updates included, however, because a given console may or may not be connected to the Internet, or may not have WiiConnect24 enabled. Each disc-transmitted update is applied when the game is started, if it hasn’t been applied previously. (This also allows Nintendo to apply new security patches and disable illegal homebrew software.) Individual games and system software such as Wii Channels run as applications on top of the IOS—an architecture that is reminiscent of dedicated application scheduling found in the earliest of computer OSs. In a game system, this makes sense because the game really is “in charge” of the system at any given time while it’s running, until the user quits or switches to another application. Like Apple’s apps on the iPhone, iPod Touch, and iPad, Channels works by simplifying the user’s relation to the system, and then representing it through GUI conventions in terms of discrete functions, services, and games, one at a time.
