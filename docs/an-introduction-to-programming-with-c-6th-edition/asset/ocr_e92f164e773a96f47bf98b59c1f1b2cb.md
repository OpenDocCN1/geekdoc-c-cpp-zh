Compare the decimal number system illustrated in Figure 3-7 with the binary number system illustrated in Figure 3-8. Like the decimal number system, the position of each digit in the binary number system is also associated with the system's base number raised to a power. However, in the binary number system, the base is 2 rather than 10. Starting with the rightmost position, the positions represent 2 raised to a power of 0, 1, 2, 3, and so on. In the binary number 110, the 0 is in the 2', the middle 1 is in the 2', and the leftmost 1 is in the 2'. Therefore, the binary number 110 means one 1s, two (2s), and one 4 (2'). The decimal equivalent of the binary number 110 is 6, which is calculated by adding together 0 + 2 + 4 (zero one). In other words, the decimal number 6 is stored in a memory location using the binary number. The binary number 11010 means one 1s, two (2s), zero 4s (2'), one 8 (2'), and one 16 (2'). The decimal equivalent of the binary number 11010 is 26, which is calculated by adding together 0 + 2 + 0 + 8 + 16. The decimal equivalent of the last number shown in Figure 3-8 is 9 (one 1 2s + zero 4s + one 8s + 8).

Unlike numeric, data character (which is assigned to memory locations that can store characters) are represented in internal memory using ASCII codes. ASCII (pronounced ASCII-ee) stands for American Standard Code for Interchange. The ASCII coding scheme assigns a specific code to each character on your keyboard. Shows a partial listing of ASCII codes along with their binary representations. The ASCII chart is contained in Appendix C in this book. As Figure 3-9 indicates, the uppercase letter A is assigned the ASCII code 65, which is stored in internal memory using the bits (“binary digits”) 01000001 (64 and 1). Note that the lowercase version of each letter is assigned a different ASCII code than the letter's version. The lowercase letter a, for example, is assigned the ASCII code 97, which is stored in internal memory using the bits 01100001. This fact indicates that the computer does not consider both cases of a letter to be equivalent. In other words, the uppercase letter A is not the same as the lowercase letter a. This concept will become important when you compare characters in later chapters.
