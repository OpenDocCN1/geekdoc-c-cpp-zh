You locate the errors in an algorithm by desk-checking. First, choose a set of sample data for the input. In this case, you will use the numbers 25, 63, and 14. Now use the values to manually compute the expected—in this case, the average. The average of the three numbers is 34. Next, create a desk-table that contains a column for each input, processing, and output item. This desk-table will contain five columns. Finally, walk through each of the instructions in the algorithm, recording the appropriate values in the desk-table. The first instruction in the algorithm is to enter the three input values.
