### Object-Oriented Terminology

The term *encapsulated* means to enclose in *capsule*. In the context of OOP, *capsule* is a class.

### Defining a Class in C++

The attributes and behaviors that are hidden are said to be protected. The attributes and behaviors that are exposed to the user are public. Inheritance, inheritance refers to the fact that one class can inherit the attributes and behaviors of another class. For example, a class can inherit from a base class. The attributes and behaviors of the derived class are inherited from the base class. Polymorphism is a feature that allows an object to respond in different ways. For example, a method can be overloaded in a class.

The methods in a class are called member functions.
