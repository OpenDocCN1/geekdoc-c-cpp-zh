A counter is always updated by a constant value—typically 1—whereas an accumulator is updated by a value that varies. The assignment that updates a counter or an accumulator is placed in the body of a loop, the update task must be performed each time the loop body executes. The accumulator (double variable totalSales) keeps track of the total sales and is initialized to 0.0.

# Problem specification

Sales Express wants a program that displays the average amount company sold during the prior year. The sales manager will enter each salesperson's sales. The program will use a counter to keep track of the number of sales amounts entered and an accumulator to total the sales amounts. When the sales manager has finished entering the amounts, the program will calculate the average sales amount by dividing the value stored in the accumulator by the value sales amount on the screen. The manager will indicate that she is finished with the program by entering a negative number for the sales amount. If the sales manager does not enter any sales amounts, the program will display the "No sales entered" message.
