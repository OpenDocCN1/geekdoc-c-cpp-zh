## 算法

+ 1. 输入销售数据
2. 如果（销售额小于 0）
   佣金 = -1
   否则如果（销售额属于以下范围之一：
   至 100,000）
   佣金 = 销售额 * .02
   否则如果（销售额 <= 400000）
   佣金 = (销售额 - 100000) * .05 + 2000
   否则
   400001 及以上
   佣金 = (销售额 - 400000) * .1 + 1700
   结束如果
3. 如果（佣金不为 -1）
   显示佣金
   否则
   显示错误信息
   结束如果

```cpp
cout << "Sales: ";
cin >> sales;

if (sales < 0)
  commission = -1;
else if (sales <= 100000)
  commission = sales * .02;
else if (sales <= 400000)
  commission = (sales - 100000) * .05 + 2000;
else
  commission = (sales - 400000) * .1 + 1700;
end if

if (commission != -1)
  cout << "Commission: $" << commission << endl;
else
  cout << "The sales cannot be less than 0." << endl;
end if
```
