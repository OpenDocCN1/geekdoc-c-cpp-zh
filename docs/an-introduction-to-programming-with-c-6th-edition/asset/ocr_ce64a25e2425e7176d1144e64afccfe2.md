Unary binary refer to the number of operands required by the operator. Unary operators require one operand, whereas binary operators require two operands. For example, the expression -7 uses the negation operator to turn the positive number 7 into a negative number. The expression 9 - 4, on the other hand, uses the subtraction operator to subtract the 4 from the number 9.

One of the arithmetic operators listed in Figure 4-7, the modulus operator (%), is less famous than you. The modulus operator is used to divide two integers and return the remainder of the division. For example, the expression 211 % 4 (read 211 mod 4) equals 3, which is the remainder of 211 by 4. A common use for the modulus operator is to determine whether a number is even or odd. If you divide a number by 2 and the remainder is 0, the number is even; however, the number is odd.

Some of the operators listed in Figure 4-7 have the same precedence. For example, both the addition and subtraction operators have a precedence of 4. When an expression contains more than one operator having the same priority, those operators are evaluated from left to right. In the expression 5 + 12 / 3 - 1, the division (/) is performed first, then the addition (+), and the subtraction (-). The result of the expression is 8, as shown in Figure 4-8. You can use parentheses to change the order in which the operators are evaluated. For example, as Figure 4-8 shows, the expression 5 + 12 / (3-1) evaluates to 11 rather than 8. This is because the parentheses tell the computer to perform the subtraction operation.

# Type Conversions in Arithmetic Expressions

In Chapter 3, you learned implicit type conversions in statements that declare memory locations. Recall that, if necessary, the computer will either promote or demote the value in a declaration statement to match the memory location data type. The computer also makes implicit conversions when performing arithmetic operations. More specifically, when performing an arithmetic operation with two values having different data types, the value with the lower-ranking data type is always promoted, to the higher-ranking data type. A value returns higher than data type if it can store larger numbers. The value returns to its original data type after the operation is performed.
