12. A concert has three seating categories: Orchestra, Main floor, and Balcony. Orchestra seats are $25. Main floor seats are $30, and Balcony seats are $15. The manager wants a program that allows him to enter the number of tickets sold in each seating category. The program should calculate and display the amount of revenue generated by each seating category, as well as the total revenue.

+   a. Create an IPO chart for the problem, and then desk-check the algorithm twice. For the first desk-check, use 50, 100, and 75 as the number of Orchestra, Main floor, and Balcony seats. For the second desk-check, use 30, 25, and 99.

+   b. List the input, processing, and output items, as well as the algorithm, in a chart similar to the one shown in Figure 4-12 in the chapter. Then code the algorithm into a program.

+   c. Desk-check the program using the same data used to desk-check the algorithm.

+   d. Enter C++ instructions into a source file named Introductory12.cpp. Also enter appropriate comments and any additional instructions required by the compiler.

+   e. Save and run the program. Test the program using the same data used to desk-check the program.
