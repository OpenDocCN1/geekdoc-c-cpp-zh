# The Selection Structure

As with the sequence structure, you are already familiar with the selection structure, also the selection indicates that a decision (based on some condition) needs to be made, followed by an appropriate action derived from that decision. Use the selection structure every time you drive your car and a railroad crossing. Your decision, as well as the appropriate action, is based on whether the crossing signals (flashing lights and ringing bells) are on or off. If the crossing signals are on, you stop your car before crossing the railroad tracks; otherwise, you proceed with caution over the railroad. When used in a computer program, the selection structure alerts the computer that a decision needs to be made, and it provides the appropriate action to take based on result of that decision.

To observe the selection structure works, we make a slight change to the problem specification shown in Figure 1-1. Robin’s bedroom door may or not be closed. What needs to be made to the original algorithm from result of this minor modification? The first two instructions in the original algorithm position Robin in her bedroom door; Robin still need to follow those. The third instruction tells Robin to open the bedroom door. That instruction was correct for the original problem specification, which states that the bedroom door is closed. However, in the modified problem specification, which states the status of the door unknown, it could be closed or it could be open. As a result, Robin will need to make a decision and then take the appropriate action based on the result. More specifically, Robin will need to determine whether the bedroom door is closed and open the door only if it needs to be opened. To write an algorithm to accomplish the current task, you need use two additional instructions from Robin’s instruction set: if (the bedroom door is closed) and end it.
