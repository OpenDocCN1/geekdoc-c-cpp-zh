# The static_cast Operator

C++ uses the `static_cast` operator for explicitly converting data from one type to another. This type of conversion is called an **explicit conversion** or a **type cast**. Figure 4-10 shows the `static_cast` operator's syntax and includes examples of using the operator. In the syntax, `dataType` is the type to which you want to convert the data. In the example, `firstNum` and `secondNum` are `int` variables that contain the numbers 5 and 2, respectively. You can want the data converted. You can use any of the expressions shown in Examples 1 to 3 to divide the integer stored in the firstNum variable and then return the quotient as a real number data type. The expression in Example 4 uses the `static_cast` operator to explicitly promote the integer stored in the firstNum to the `double` data type before it is multiplied by the `double` number 10.65. The same answer would be achieved with implicit conversion, the type cast; the statement in Example 5 uses the `static_cast` operator to explicitly convert, or type cast, the `double` number 3.99 to the `float` data type. In this case, the `double` number will be demoted to the `float` data type, because it can store larger numbers.

# HOW TO Use the static_cast Operator

Syntax
`static_cast<dataType>(expression)``

Example 1 `static_cast<double>(firstNum) / static_cast<double>(secondNum)`

+   1. The value stored in the firstNum variable (the integer 5) is explicitly promoted to the double number 5.0.
2. The value stored in the secondNum variable (the integer 2) is explicitly promoted to the double number 2.0.
3. The double number 5.0 (the result of Step 1) is divided by the double number 2.0 (the result of Step 2). The result of the division is the double number 2.5.

Example 2 `static_cast<double>(firstNum) / secondNum`

+   1. The value stored in the firstNum variable (the integer 5) is explicitly promoted to the double number 5.0.
2. The value stored in the secondNum variable (the integer 2) is implicitly promoted to the double number 2.0.
3. The double number 5.0 (the result of Step 1) is divided by the double number 2.0 (the result of Step 2). The result of the division is the double number 2.5.
