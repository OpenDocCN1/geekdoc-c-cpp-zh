# The Selection Structure

When expression contains more than one comparison operator with the same precedence number, the computer evaluates the comparison operators from left to right in the expression, similar to what is done with arithmetic operators. Comparison operators are evaluated after any arithmetic operators in an expression. For example, when processing the expression 5 - 2 > 1 + 2, the computer will evaluate the two arithmetic operators before it evaluates the comparison operator. The result of the expression is the Boolean false, as shown in Figure 5.

| Original expression | 5 - 2 > 1 + 2 |
| The subtraction is performed first | 3 > 1 + 2 |
| The addition is performed next | 3 > 3 |
| The comparison is performed last | false |

It is easy to confuse the equality operator (=) with the assignment operator (=). You use the equality operator to compare two values to determine whether they are equal, as in the condition if (num == 1). Use the assignment operator, on the other hand, to assign a value to a memory location. An example of this is the statement num = 1; in the next sentences, you will view programs that contain a comparison operator in an if statement condition.

# Swapping Numeric Values

Figure-10 shows the IPO chart information and C++ code for a program that displays the lowest and highest of two integers entered by the user. (The flowchart for this program is contained in Ch5Flowcharts.pdf file, which is located in Cpp6/Chap5 folder) The program contains a single-alternative selection structure. The firstNum > secondNum condition compares the contents of the firstNum variable. If the value in the firstNum is greater than the secondNum, the condition evaluates to true and the four instructions in the if statement true path values. Swapping the values places the smaller number in the firstNum variable and the larger number in the secondNum variable. Notice that the four instructions in the true path are enclosed in braces. Because more than one instruction needs to be processed when the if statement's condition is true, the C++ syntax requires those instructions to be entered as a statement block. If the condition in the if clause evaluates to false, the instructions in the true path are skipped because the firstNum variable already contains a number that is smaller than (possibly equal to) the number stored in the secondNum variable.
