# 关键术语

- **ASCII**：一种编码方案
- **二进制制**：仅使用 0 和 1 的系统
- **驼峰命名法 (Camel case)**：单词首字母大写的命名约定
- **字符**：一个符号
- **字符字面量常量**：使用单引号的字符
- **十进制**：使用 0 到 9 的系统
- **降级 (Demoted)**：将数字从一种类型转换
- **空字符串**：双引号之间没有内容
- **基础数据类型**：C 语言使用的基本类型，也称为内置类型
- **隐式类型转换**：计算机遵循内存内存位置的过程
- **初始化**：为内存位置分配初始值
- **整数**：没有小数点的数字
- **关键字**：在语言中具有特殊含义的单词
- **字面量常量**：出现在程序中的数据项
- **命名常量**：程序运行时无法更改的内存位置
- **实数**：带有小数点的数字
- **运行时**：在程序运行期间
- **语句**：执行后导致计算机操作的 C++ 指令
- **字符串字面量常量**：双引号内的零或多个字符
- **语法**：使用编程语言时遵循的规则
- **文本**：被视为整体的字符组
- **用户定义数据类型**：通过类添加到 C++ 语言的数据类型
- **变量**：程序运行时值可以变化的内存位置
