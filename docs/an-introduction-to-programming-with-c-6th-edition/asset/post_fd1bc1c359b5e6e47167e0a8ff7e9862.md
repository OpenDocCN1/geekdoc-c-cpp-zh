# CHAPTER 5 The Selection Structure

# Making Decisions

As you learned in Chapter 1, all computer programs are written using one or more of three basic control structures: sequence, selection, and repetition. You used the sequence structure in the programs you coded in Chapter 4. Recalling that during runtime, the computer processed the instructions in those programs sequentially—in other words, the instructions appeared in the order. Many times, however, a program will need the computer to make a decision before selecting the next instruction: A payroll program, for example, has the computer determine the number of hours an employee worked is greater than 40. The computer then would select either an instruction that pay overtime. Programs that need the computer to make a decision require the use of the selection structure (also called the decision structure). As you learned in Chapter 1, the selection structure indicates that a decision (based on some condition) needs to be made, followed by an appropriate action derived from that. But how does a programmer determine whether a problem's solution requires a selection structure? The answer to this question is by studying the problem specification. The first problem you will examine in chapter involves Robot, the mechanical woman from Chapter 1. The problem specification and an illustration of the problem are shown in Figure 5-1 with the solution from Chapter 1, which is written in pseudocode, requires only the selection structure. It does not need a selection structure because no decisions need to be made to get Robot from her initial location in the hallway ending in the bedroom.

Figure 5-4 shows a modified version of the previous problem specification. In the modified version, the contents of the bag Robin is holding are not certain: the bag might contain trash or it might contain recyclables. You can solve this using either of the solutions shown in Figure 5-4. The condition in Solution 1's selection determines whether Robin is holding a bag of trash. If she is, follow the original algorithm from Figure 5-3. If she's not, it means the bag contains recyclables. In that case, Robin should lift the Recycle lid before dropping the bag into the container. The condition in Solution 2's selection structure, on the other hand, determines whether Robin is holding a bag of either. Unlike the selection structure in Figure 5-2, which provides a special action for Robin to take only when the condition is true, the selection in Figure 5-4 require Robin to perform one or the other, but a different set of instructions when the condition is false. The instructions are to follow when the condition evaluates to the true path. The path begins with the if and ends with either the else (if it is) or the end if. The instructions to follow when the condition evaluates to false are called the false path. The path begins with the else and ends with the end if. For clarity, the instructions in each path should be denoted as in Figure 5-4. Selection structures that contain instructions in both paths, like the ones in Figure 5-4, are referred to as dual-alternative selection structures.

Robin holding either a bag of trash or a bag of recyclables in her right hand. She is directly in front of two containers: one marked Trash and the other marked Recycle. Each is on each container.
