In line 7 of the program, main is the name of a function and must be typed using lowercase letters. A function is a block of code that performs a task. Functions have parentheses after their names, like main(). Some functions require you to enter information between the parentheses; other functions, like main, do not. Every C++ program must have a main function, because that is where the execution of a C++ program begins. A C++ program can contain many functions; one being the main function. Some functions, like main, return a value of completing their assigned task. If it returns a value, the type of the value it appears to the left of the function name; otherwise, the keyword void appears to the left of the name. The int in line 7 indicates int main(), is referred to as a function header, because it marks the beginning of the function. After the function header, you enter the code that directs the function to perform its task. Examples of such code include statements that declare variables, as well as enclose the code within a set of braces {}. The braces mark the beginning and end of the code that blocks the function. And you enter the closing brace } at the end of the function. In Figure 4-20, the opening brace appears on line 8, immediately below the int main() function header. The closing brace appears on line 33. Everything between the opening and closing braces in Figure 4-20 is in the main function and is referred to as the function body.
