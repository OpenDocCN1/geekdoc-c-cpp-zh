# Arrays

All of the variables used so far have been simple. A simple variable, also called a scalar variable, is one that is unrelated to any variable. At times, however, you will encounter situations in which some of the variables are related to each other. In those cases, it is easier and more efficient to treat the variables as a group. You are already familiar with the concept of grouping. The clothes in your closet are separated into groups, such as coats, shirts, and so on. Grouping them in this manner allows you to locate your favorite rather than the entire closet. When you group together variables that have the same type, the group is referred to as an array or, more simply, an array. You might use an array of variables to store the population of each U.S. state. Or you might use an array of variables to store the sales in each of your regions. Storing data in an array increases the efficiency of a program, because data can be retrieved from computer's internal memory much faster than it can be written and read from a disk. Additionally, after the data is entered into an array which is typically done at the beginning of a program, you can use the data as many times as you want without having to enter the data again. Your company's program, for example, can use the amounts stored in an array to calculate the total company sales and the percentage that each region contributed to the total. It can also use the sales in an array to display the sales in a specific region.

The most commonly used arrays in business applications are one-dimensional and two-dimensional. You will learn about one-dimensional arrays in this chapter. Two-dimensional arrays are covered in Chapter 12. Arrays having more than two dimensions are used more in scientific and engineering programs and are beyond the scope of this book. As is true of functions, which you learned in Chapters 9 and 10, arrays are one of the more challenging topics for beginning programmers. Therefore, it is important for you to read and study each section in this chapter thoroughly before moving on to the next section. For example, be sure you understand the concept of one-dimensional arrays before you continue to the sections pertaining to the bubble sort and parallel arrays. By the end of the chapter, try reading the chapter again, paying particular attention to the examples and programs shown in the figures.
