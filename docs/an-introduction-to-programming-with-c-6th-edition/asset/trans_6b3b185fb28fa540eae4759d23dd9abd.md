# 格/通过程序

当用户输入字母 P（无论大写或小写）时，程序需要显示“Pass”；当用户输入其他任何内容时，显示“Fail”。你可以使用图 5-20 中的任一示例来编写程序。两个示例都包含一个双分支选择结构。示例 1 中的复合条件使用“或”（Or）运算符来确定字母是否包含大写的 P 或小写的 p。当字母包含其中之一时，复合条件求值为真，选择结构就会在屏幕上显示单词“Pass”；否则，显示“Fail”。你可能会奇怪，为什么在许多编程语言中，你需要将字母变量的内容与字母的大写和小写形式进行比较。在 C++ 中，字符比较是区分大小写的，这意味着字母的大写版本与其小写对应并不相同。尽管我们认为是同一个键，但计算机并不认为；对计算机来说，P 和 p 是不同的。这种差异的原因在第 3 章中提到。请记住，键盘上的每个字符都分配有一个唯一的 ASCII 代码，该代码使用一组 0 和 1 存储在计算机的内部内存中。大写 P 的 ASCII 代码是 80，而 p 则是 112，并使用位 01110000 存储。使用“或”运算符来确定字母变量是否包含 P 或 p，你也可以像图 5-20 所示使用“与”（And）运算符。第二个示例中的复合条件确定字母变量是否不等于大写字母 P且（同时）不等于小写字母 p。当变量不包含其中任何一个时，复合条件求值为真，选择结构就会在屏幕上显示单词“Fail”；否则，显示单词“Pass”。图 5-21 和 5-22 显示了包含图 5-20 中每个示例代码的程序的示例运行。

> 正如你在第 3 章中学到的，字符字面量包含在单引号中，例如 'P'。字符串字面量包含在双引号中，例如 "Pass"。

# 第 5 章 选择结构

示例 1
```cpp
//declare variable
char letter = ' ';
//enter input item, then display message
cout << "Enter a letter: ";
cin >> letter;

if (letter == 'P' || letter == 'p')
    cout << "Pass" << endl;
else
    cout << "Fail" << endl;
```

示例 2
```cpp
//declare variable
char letter = ' ';
//enter input item, then display message
cout << "Enter a letter: ";
cin >> letter;

if (letter != 'P' && letter != 'p')
    cout << "Fail" << endl;
else
    cout << "Pass" << endl;
```

# 将字符转换为大写或小写

在早前的图 5-20 中，你查看了格/通过程序的两个 C++ 函数示例。在这两个示例中，if 语句包含一个复合条件，将变量与字母的大写和小写形式进行比较。这并不是比较变量两个版本的唯一方法；你也可以使用以下内置函数：`toupper` 或 `tolower`。`toupper` 函数将字符转换为大写，而 `tolower` 函数将其转换为小写。图 5-24 显示了这一点。函数语法中括号内的表达式称为参数，它代表函数执行任务所需的信息。在这里，`toupper` 和 `tolower` 函数需要 `char` 类型变量名。两个函数都会字符转换为适当的大小（如有必要）并返回临时字符。记住，`toupper` 和 `tolower` 函数不会改变变量的内容，只更改临时位置的内容。此外，`toupper` 和 `tolower` 函数仅影响代表字母的字符，因为只有这些字符有大写和小写形式。同样，在比较中使用 `toupper` 函数时，请确保你比较的是大写；否则比较将无法正确计算。例如，`toupper(letter) == 'p'` 语句是不正确的：该条件将始终失败，因为字母的大写版本永远等于其小写对应版本。同样，在比较中使用 `tolower` 时，请确保你比较的是

# 如何使用 toupper 和 tolower 函数

语法
toupper(charVariable)
tolower(charVariable)

示例 1
```cpp
if (toupper(letter) == 'P')
```
该条件将 `toupper` 函数返回的大写字符与大写字母 P 进行比较。当 `letter` 变量存储的字符为 P 或 p 时，条件求值为真。

示例 2
```cpp
if (tolower(letter) == 'p')
```
该条件将 `tolower` 函数返回的小写字符与小写字母 p 进行比较。当 `letter` 变量存储的字符为 P 或 p 时，条件求值为真。

示例 3
```cpp
initial = topper(initial);
```
赋值语句将 `initial` 变量的内容转换为大写。

# 格式化数值输出

在 C++ 中，带有小数的数字以定点（fixed-point）或 e（指数）法显示，取决于数字的大小。请记住，带有小数的数字被称为小数。大数字——即小数点左侧有六或五位数字的数字——以定点法显示。例如，数字 1,234.56 以定点法显示为 1234.560000。小数点左侧超过六位数字的更大数字——通常以 e 法显示。例如，数字 1,225,000.0 以 e 法显示为 1.25e+006。你创建的数字类型决定了显示带小数数字时使用的适当格式。业务程序通常以定点法显示数字，而许多科学程序使用流操作器，允许你控制显示数字的格式。你使用 `fixed` 流操作器以定点法显示实数。要用 e 法显示实数，请使用 `scientific` 流操作器。适当的操作器必须出现在 `cout` 语句中，并且必须在格式格式的数字显示之前被处理。在处理之后，该操作器将保持有效，直到程序结束或遇到另一个改变它的操作器。图 5-25 显示了使用这两种操作器的示例。
