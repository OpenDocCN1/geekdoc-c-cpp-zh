Desk-checking the inefficient algorithm in Figure 6-19 will help you understand why the last selection is unnecessary. The first instruction in the inefficient algorithm is to enter the code and sales—in this case, X and 1500. The second instruction is to calculate the bonus by multiplying the sales by 8; the answer is 1200. The condition in the first selection structure determines whether the salesperson's code is X, so the condition in the second selection structure checks whether the sales are greater than or equal to 10000. They are, so the second selection structure's true path adds 150 to the bonus, 1350. The last instruction in the inefficient algorithm displays 1350 as the bonus, which is correct.

Using the second set of data, the user enters X as the code and 9000 as the sales. The second instruction in the inefficient algorithm calculates the bonus by multiplying the sales by 8; 720. The condition in the first selection structure determines whether the salesperson's code is X. It is, so the condition in the second selection structure checks whether the sales are greater than or equal to 10000. They aren't, so the condition in the third selection structure determines whether the sales are less than 10000—unnecessary. In this case, the sales are less than 10000, so the third selection structure's true path adds 125 to the bonus, 845. The last instruction in the inefficient algorithm displays 845 as the bonus, which is correct.

Using the third set of data, the user enters A as the code and 13000 as the sales. The second instruction in the inefficient algorithm multiplies the sales by 8, resulting in 1040 as the bonus. The condition in the first selection structure determines whether the salesperson's code is X. It's not, so the first selection structure ends. Notice that the two nested selection structures not processed when the first selection structure's condition evaluates to false. ## Multiple-Alternative Selection Structures

Figure 6-21 shows the problem specification and IPO chart for the Kindle High School problem. The problem's solution requires a selection structure that can choose from several alternatives; in this case, it can choose from several letter grades. As the figure indicates, when the letter grade is A, the selection structure should display the message "Excellent". When the letter grade is B, the selection structure should display the message "Above Average", and so on. Selection containing several alternatives are referred to as multiple-alternative selection structures or extended structures.

Mr. Jacoby teaches at Kindle High School. He wants a program that displays a message based on a letter grade he enters. The valid letter grades and their corresponding messages are shown below. If the letter grade is not valid, the program should display the "Invalid grade" message.

| Letter grade | Message |
|---|---|
| A | Excellent |
| B | Above Average |
| C | Average |
| D | Below Average |

## Multiple-Alternative Structures

| Input | Output |
|---|---|
| grade | message |

Algorithm:
1. enter the grade
2. If (grade is one of the following:)
   A display "Excellent"
   B display "Above Average"
   C display "Average"
   D display "Below Average"
   else
     display "Invalid grade"
end if

Figure 6-22 shows the flowchart. The diamond in the flowchart represents the multiple-alternative structure. Recall that the diamond is used in single-alternative and dual-alternative structures. However, the diamond in both of those structures has several flowlines (rather than only two). Each flowline represents a possible path and must be marked appropriately, indicating the value or values necessary for the path to be chosen.

Figure 6-23 shows two versions of the C++ code for the Kindle School program. Both versions use the multiple-alternative structure. The multiple-alternative form contains several `if else` clauses. Although both versions produce the same result, the second version provides a more convenient way of coding a multiple-alternative structure.

```
Version 1
int main()
{
    char grade = ' ';

    //enter grade
    cout << "Letter grade: ";
    cin >> grade;
    grade = toupper(grade);

    if (grade == 'A')
        cout << "Excellent";
    else
        if (grade == 'B')
            cout << "Above Average";
        else
            if (grade == 'C')
                cout << "Average";
            else
                if (grade == 'D' || grade == 'F')
                    cout << "Below Average";
                else
                    cout << "Invalid grade";
    //end grade
    cout << endl;
    system("pause");
    return 0;
} //end of main function

Version 2
```
