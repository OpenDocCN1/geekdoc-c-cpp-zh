# Summary

+   * All functions fall into one of two categories: value-returning or void. A value-returning function returns precisely one value to the statement that called the function. A void function, on the other hand, does not return a value.
* Like a value-returning function, a void function is composed of a function header and body. However, unlike a value-returning function, the function header for a void function begins with the keyword void rather than a data type. Also unlike a value-returning function, the body for a void function does not contain a return statement.
* As you do calling a value-returning function, you call a function by including its name and actual arguments (if any) in a statement. Unlike a call to a value-returning function, a call to a void function appears as a statement by itself rather than as part of other statements. When the computer finishes processing a void function's code, it continues program execution with the statement immediately below the one that called the function.
