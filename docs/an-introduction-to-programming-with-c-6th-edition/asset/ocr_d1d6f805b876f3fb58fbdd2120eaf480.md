# Coding a Nested-2 Selection Structure

In Chapter 5's Lab 5-2, you created a program for the manager of Willow Springs Health Club. The program allows the manager to enter the number of calories and grams of fat contained in a specific food. The program calculates and displays two values: the food's calories and its fat percentage. The club's manager now wants the program to display the message "High in fat" when the food's fat percentage is greater than 30%; otherwise, the program should display the message "Not high in fat". To accomplish this task, you will need to add a nested dual-alternative selection structure to the program. You will code the nested selection structure using the dual-alternative form of the if statement. The dual-alternative form is simply an if else clause.
