# LAB 11-2 Plan and Create

In this lab, you will plan and create an algorithm for Lab11-2 Helvetica. The problem specification, IPO chart information, and C++ instructions are shown in Figure 11-5. According to the figure, the main function will get the 12 rainfall amounts from the user. It will display a menu that allows the user to select from three different options. If the user chooses to display the monthly rainfall amounts, the main function will call the displayMonthly function, passing the rainfall array and number of array elements. The displayMonthly function uses a for loop to display the 12 monthly rainfall amounts on the screen. However, if the user chooses to display the total rainfall, the main function will call the displayTotal function, passing the rainfall array and number of array elements. The displayTotal function uses a for loop to accumulate the 12 monthly rainfall amounts. It then displays the total rainfall amount on the screen. The program ends when the user enters any number other than 1 or 2 in response to the “Enter your choice:” prompt.
