## Void Functions

As discussed in Chapter 9, all built-in and program-defined functions are categorized as either value-returning or void functions. Recall that a value-returning function performs a task and returns precisely one value to the statement that called it. You learned how to create and invoke value-returning functions in Chapter 9. Like value-returning functions, **void functions** do not return a value after completing their task. Unlike value-returning functions, you are already familiar with one void function: `srand`. Recall from Chapter 9 that the `srand` function is a built-in void function which serves to initialize the C++ random number generator. In this chapter, you will learn how to create program-defined void functions and use a program-defined void function to display information (such as a title and column headings) at the top of each page in a report. Rather than duplicating the required code several times in the program, the code can be encoded once a void function. The program can call the void function whenever and wherever it is needed. A void function is appropriate in this situation because the function does not return a value after completing its task. Figure 10-1 shows the syntax you used with the syntax for creating a value-returning function (shown in Figure 9-14 in Chapter 9), you will notice two differences. First, at the void function's header, the return type is `void` rather than a data type. The **void** keyword indicates that the function does not return a `return` statement. Second, the `return` statement is not necessary in a void function body because a void function does not return a value. Also included in Figure 10-1 are examples of program-defined void functions.

## HOW TO Create a Program-Defined Void Function Syntax

```cpp
void functionName(parameterList) {
    one or more statements
    //end of functionName
}

Example
void displayLine() {
    cout << "--------------------------------" << endl;
    //end of displayLine function
}
```

Figure 10-3 shows the program's code, with the function prototypes and calls showed. With a void-returning function, you can call a function by its name and actual arguments (if any) in statement. However, unlike a call to a value-returning function, a call to a void function appears as a statement by itself rather than part of another statement. Each call to the void functions in Figure 10-3, for example, is a self-contained statement. When the computer processes a statement that calls a function, the compiler first locates the function in the program. If the call contains an argumentList, the compiler passes the values of the actual arguments (in the argumentList) to the called function. The function receives the values and stores them in the formal parameters in its parameterList. Then, the computer processes the function's code. When the function ends, the computer continues execution with the statement immediately below the call. In the program shown in Figure 10-3, for the displayLine(); statement on Line 28 calls the displayLine function. After processing the displayLine function, the computer returns to the main function on Line 29; that statement calls displayCompanyInfo. When the computer finishes processing the function, it returns to the main function processes the statement on Line 30; that statement calls displayTotalSales(). After processing the code in displayTotalSales function, the computer returns to the main function to process the displayLine(); statement on Line 31. After the displayLine function completes its task, the computer returns to the main function to process the system("pause"); statement on Line 33. Figure 10-4 shows a sample run of the program. The sample run contains output from each of the four functions in the program.

As learned in Chapter 9, returning functions are typically called from statements that do one of the following: display the function's return value, use the return value in a calculation or comparison, or assign the return value to a variable.
