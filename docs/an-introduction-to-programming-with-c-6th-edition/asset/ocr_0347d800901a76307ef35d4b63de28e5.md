# Function Prototypes

Most C++ programmers use the function definitions below the main function in a program. When a function definition appears below the main function, you must define a function prototype above the main function; otherwise, the compiler will not recognize the function's name when it is used in the main function. A function prototype is a statement that specifies the function's name, the data type of its return value, and the data type of each of its formal parameters (if any). You may also include the name of each of its parameters; however, that is not a requirement. A program will have one function prototype for each function defined before the beginning of the program, after the #include directives and using namespace std;. A function prototype alerts the C++ compiler that the function will be defined later in the program. The function prototypes are similar to the table of contents in a book. As each entry in a table of contents, each prototype is a preview of what will be expanded later in the program (or in the book). Keep in mind that a function prototype is necessary only when the function is defined below the main function in the program. It is not needed for a function whose definition appears above the main function. In this book, the function definitions below the main function are used because that format is used by most C++ programmers. This means that each program-defined function will need a corresponding function prototype above the main function.
