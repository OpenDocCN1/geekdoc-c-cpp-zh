Figure-82 Current status updates the value in the numAsterisks variable by adding the number 1 to it; the result is 2. The computer then checks whether the variable's value is less than 6, so the nested loop's cout << '*'; state-ments another asterisk on the current line on the computer screen. The computer adds the number 1 to the value stored in the numAsterisks variable, giving 3. It then checks whether the variable's value is less than 6. It is, the cout << '*'; statement displays the third asterisk on the current line on the computer screen. Once again, the computer adds the number 1 to the value stored in the numAsterisks variable and checks whether the value is 4, so the cout << '*'; statement displays the fourth asterisk on the current line on the computer screen. The computer adds the number 1 to the value stored in the numAsterisks variable and checks whether the value (which is now 5) is less than 6. It is, so the cout << '*'; statement displays the fifth asterisk on the current line on the computer screen. Once again, the computer updates the value stored in the numAsterisks variable by adding the number 1 to it; the result is 6. The computer then checks whether the variable's value is less than 6. It's not, so the nested loop ends and the numAsterisks variable is removed from the computer's internal memory.
