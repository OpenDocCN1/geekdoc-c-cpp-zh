After the instruction to enter the input items, you usually record instructions to process items, typically including the items in one or more calculations. In this case, you will use the number of nights and per-night rate to calculate an intermediate value: the room charge. After completing the IPO chart, you move on to the third step in the problem-solving process, which is to de-check the algorithm. You begin by choosing a set of sample data for the inputs. You then use the values to manually calculate the expected output. You will de-check the algorithm twice: using 4, $100, $12, and $5 as the number of nights, per-night rate, room service charge, and telephone charge, respectively, and then using 2, $55, $20, and $0.
