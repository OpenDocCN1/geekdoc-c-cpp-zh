After planning the algorithm, you review it (in your mind) to verify that it will work as intended. When you are satisfied that the algorithm is correct, you implement the algorithm by following each of its instructions in the order. After implementing the algorithm, you evaluate it and, if necessary, you modify it. In this case, for example, you may decide to use the selection structure shown in Figure 2-2.
