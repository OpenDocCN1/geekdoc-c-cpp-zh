At this point, it is important to highlight what happens when one is divided by another in C++ because the result may not be what you expect. When both the divisor and dividend are integers, the quotient is always an integer in C+. For example, the result of the expression 24 / 5 is the integer 4 rather than the real number 4.8. So do you get the quotient as a real number? You do by converting at least one of the integers involved in the division operation to a real. If one of the integers is a numeric literal, you can convert the literal to a real by adding .0 to it. In this case, you can change the expression 24 / 5 to 24 / 5.0. When the computer evaluates the 24.0 / 5, it will implicitly convert the 5 to the double number 5.0 so the result will be the double number 4.8. You can also use the expression 24.0 / 5.0; both expressions evaluate to 4.8. Similarly, if the firstNum variable also contains the 5, the result of the expression 24.0 / firstNum will also be promoted to the double data type because this is because the value stored in the first variable is implicitly promoted before the division is performed. But what if neither of the integers involved in the division operation is a literal constant? For example, if both the divisor and dividend are int variables? In that case, you need to explicitly convert at least one of the int variables in the expression to either the double or float data type.
