# More on the Repetition Structure

The fourth step in the problem-solving process is to code the algorithm into a program. You begin by declaring memory locations that will store the values of the input, processing, and output items. The multiplication table will need three memory locations to store the multiplicand, multiplier, and product. You will store the multiplicand in a variable, because the user should be allowed to change its value during runtime. The multiplier will also be stored in a variable to allow its value to change from 1 to 9 in increments of 1. Finally, you will store the product in a variable, because its value will change based on the current values of the multiplicand and multiplier. The multiplicand, multiplier, and product will always be integers, so you will store them in int variables. Figure 8-38 shows the IPO chart information and corresponding C++ instructions.
