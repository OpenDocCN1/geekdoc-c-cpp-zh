You do this by including the endl manipulator at the end of the statement that writes the record. The outSales << custName << endl; statement in Example 3, for instance, writes a record that contains one field (the name stored in the custName variable) to the file associated with the outSales object. The endl stream manipulator writes a newline character at the end of the record. As learned in Chapter 4, the newline character represents the Enter key. In this case, the newline character advances the file pointer to the next line in the file. When writing a record that contains more than one field, programmers typically separate each field with a character literal. The character literal '\*' which is enclosed in single quotation marks, is commonly used as the separator. The '\*' character appears in the outEmploy << name << '\*' salary << endl; statement in Example 4. It writes a record that contains two fields: the name stored in the name variable and the salary amount stored in the salary variable. The statement writes the record on a separate line in the file, with the name separating the data field from the salary field.

# HOW TO Write Data to a Sequential Access File

Syntax
fileObject << data;

Example 1
outFile << "XYZ Corporation" << endl;
writes the string "XYZ Corporation" to the file associated with the outFile object and advances the file pointer to the next line in the file

Example 2
outFile << "Gross pay: " << endl;
writes the string "Gross pay:" and the contents of the gross variable to the file associated with the outFile object and advances the file pointer to the next line in the file

Example 3
outSales << custName << endl;
writes the contents of the custName to the file associated with the outSales object and advances the file pointer to the next line in the file

Example 4
outEmploy << name << '\*' salary << endl;
writes the contents of the name variable, the number sign (#), and the contents of the salary variable to the file associated with the outEmploy object and advances the file pointer to the next line in the file
