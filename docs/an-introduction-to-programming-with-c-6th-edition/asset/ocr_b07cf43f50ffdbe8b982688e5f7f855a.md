# Declaring and Initializing a One-Dimensional Array

Before you use an array in a program, you must first declare (create) it. It is also a good programming practice to initialize the array variables to ensure they do not contain garbage when the program is run. As you learned in Chapter 3, the garbage found in uninitialized variables is the remains of what was stored at the memory location that the variable now occupies. Figure 11-2 shows how to declare a one-dimensional array in C++. In the syntax, dataType is the type of the array variables, referred to as elements. Recall that each of the (elements) in an array has the same data type. ArrayName is you for naming a variable. NumberOfElements is an integer that specifies the size of the array. In other words, it specifies the number of elements you want to declare. To declare an array that contains 10 elements, you enter the 10 as the NumberOfElements. Notice that you enclose the NumberElements in square brackets []. You can initialize the array at the same time you declare it by entering more values, separated by commas, in the initialValues section of the syntax. You enclose the initialValues in braces {}. Assigning initial values to an array is referred to as populating the array. The values used to populate an array should have the same data type as the array variables. If the data types are not the same, the computer uses implicit type conversion to fit the array variables. However, recall from Chapter 3 that the implicit devotion of values can adversely affect a program's output.
