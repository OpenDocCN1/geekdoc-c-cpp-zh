# Closing a Sequential Access File

> The **close function** is a class member function in the **ifstream** and **ofstream** classes.

To prevent the loss of data, you should use the **close function** to close a sequential access file as soon as the program is finished it. The function's syntax is in Figure 14-10 along with examples of using the function. In the syntax, `fileObject` is the name of either an existing `ifstream` or existing `ofstream` object in the program. That `close` function does not require the name of the file you want to close because the computer automatically closes the file whose name is associated with the `fileObject`. (Recall that the **open** function associates the file's name when the file is opened.) The **close** function in Example 1 shows the input file associated with the **inFile** object. The **close** function in Example 2 shows the output file associated with the **outFile** object. Because it is so easy to forget the files used in a program, you should enter the statement to close the file as soon as possible after entering the one that opens.
