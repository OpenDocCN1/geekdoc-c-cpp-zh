#  Searching a Two-Dimensional Array

Figure 12-14 shows the problem specification, IPO chart information, and C++ instructions use a four-row, two-column array to store the company's four pay codes and their corresponding rates. The pays are stored in the first column of each row in the array. The pay associated with each code is stored in the same row as its pay code in the second column. The program gets a code from the user and then searches for the code in the array first column. If it finds the pay code, the program displays the corresponding pay rate from the second column; otherwise, it displays the "Invalid pay" message. For example, when the user enters a code of 6, the program displays a pay rate of 14, as shown in Figure 12-15. This is because the number 6 is contained in the codesAndRates[2][0] element. Notice that the pay code and its associated pay rate are contained in the same row but in different columns. However, as Figure 12-16, the program displays the "Invalid pay" message when the user enters 5 as the pay code. This is because the number 5 does not appear in the first column in the array.
