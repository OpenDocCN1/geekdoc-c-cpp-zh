# Selecting a Name for a Memory Location

A programmer can reserve memory locations in a program. As mentioned earlier, the memory locations will store the values of the input, processing, and output items as the program is running. Reserving a memory location is also referred to as declaring the memory location. You declare a memory location using a C++ instruction that assigns a name, data type, and (optionally) an initial value to the location. The name allows the programmer to refer to the memory location using one or more descriptive names, rather than a cryptic numeric, in code. The data type indicates the type of—example, or textual—the memory location will store. There are two types of memory locations that a programmer can reserve: variables and named constants. A variable is a memory location whose value can change (vary) during runtime, which is when a program is running. Most of the memory locations declared in a program are variables. A named constant, on the other hand, is a program that inputs the radius of any circle and calculates the area; a programmer would declare variables to store the value of the radius and area; however, he or she would declare a named constant to store the value of pi (π), which is used in the formula for calculating the area of a circle. A named constant is appropriate in this case because the value of pi will be the same.

The formula for calculating the area of a circle is π². The value of pi rounded to six decimal places is 3.141593.

# Selecting a Name for a Memory Location

Every memory location that a programmer declares must be assigned a name. The name, called the identifier, should be descriptive in that it helps you remember the memory location's purpose. In other words, it should describe the contents of the memory location. A good name for a memory location is one that is meaningful after you finish a program and many months later (or perhaps a coworker) you need to modify the program. Besides being in C++, the name must begin with a letter and contain only letters, numbers, and the underscore. No punctuation marks, spaces, or other characters (such as $ or %) are allowed in the name. In addition, the name cannot be a keyword, which is a word that has a special meaning in the programming language you are using. Keywords are also referred to as reserved words. Appendix B in this book contains a list of the C++ keywords. Names are case sensitive. This means that, in addition, if you use the exact spell when referring to a memory location in a program, you must use the exact case. In other words, if you declare a memory location named disc at the beginning of a program, you must use the name disc, rather than Disc or disc, to refer to the memory location throughout the program.

> All C++ keywords are entered using lowercase letters.

Many programmers use uppercase letters when naming variables and use lowercase letters when naming variables. This allows them to easily distinguish between the named constants and variables in a program. If a named constant contains more than one word, an underscore can be used to separate the words, like this: TAX_RATE. However, if a variable's name contains two or more words, C++ programmers capitalize the first letter in camel case and subsequent words in the name, like this: grossPay. Camel case refers to the fact that the uppercase letters appear as 'hump' in the name because they are taller than the lowercase letters.
