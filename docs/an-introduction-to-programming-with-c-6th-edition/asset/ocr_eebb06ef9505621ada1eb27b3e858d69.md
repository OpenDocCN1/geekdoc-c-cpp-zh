# Multiple-Alternative Selection Structures

# switch Statement

Instead of using the multiple-alternative selection of the if statement to code a multiple-alternative selection in C++ (but not always) you can use the switch statement. Figure 6-24 shows the switch statement's syntax and includes an example of using the statement (rather than the if statement) in the Kindle High School code from Figure 6-23. The switch begins with the switch clause, which contains a selectorExpression enclosed in braces. The selectorExpression can contain any combination of variables, constants, functions, and operators; however, the comparison must result in a value whose type is bool. For example, in Figure 6-24, the selectorExpression is a char, int, or long. Following the switch clause is a statement block. Recall from Chapter 5 that a statement block is one or more statements enclosed in braces. Between the switch statement's opening and closing braces are one or more case clauses; you can include as many case clauses as each represent a different alternative. Note that each case clause contains a value followed by a colon. The value can be a literal, a named constant, or an expression of literal and named constants. The data type of the value should be compatible with the data type of the selection. When the expression is numeric, the values in the case clauses must be numeric. Likewise, when the selectorExpression is character, the values should be characters. In the example in Figure 6-24, the data type of the selectorExpression is char, and so is the data type of the values in the case clauses ('A', 'B', 'C', 'D', and 'F'). Following the colon in each case clause is one or more statements that are processed when the selectorExpression matches that case's value. After the computer processes the instructions in a case clause, you typically want to leave the switch without processing the remaining instructions in the statement. You can do this by including a break statement as the last statement in the case clause. The break statement tells the computer to leave ('break out of') the switch statement. If you do not use the break in a case clause, the computer continues processing the remaining instructions in the switch statement; this may or not be what you intended. After processing the break statement, the computer processes the instructions that follow the switch statement's closing brace. For clarity, it is good programming practice to document the end of the switch statement with a comment, such as /end switch. In addition to case clauses, you can also include a default clause which can appear anywhere within the switch statement, except the last clause. If it is in that position, it does not need a break statement; however, some programmers include the break statement for clarity. If the default clause is not the last clause, a break statement is required in order to stop the computer from processing the instructions in the next case clause.
