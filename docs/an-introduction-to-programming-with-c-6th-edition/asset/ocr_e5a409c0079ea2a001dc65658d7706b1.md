# CHAPTER 14 Sequential Access Files

You can verify that the information was written correctly to a sequential access file by opening the file in a text editor, such as the text editor in Visual C++, or Notepad. The instructions for opening a sequential access file depend on the text editor you use. However, in many cases, if you are using Microsoft Visual C++ or DevC++, you display the Open dialog box by going to Open and clicking Filing (Visual C+) or clicking Open Project (Dev-C++). If you are using Notepad, you display the Open dialog box by clicking on File menu. Next, select the name of the appropriate file in the Open (or Open) dialog box and then click the button. You can use Notepad to create a file. However, when saving the file, be sure to enclose the file in quotation marks, like "employees.txt". You can also use Notepad to create a .cpp file, as long as you enclose the filename in quotation marks.

# Reading Information from a Sequential Access File

Figure 14-8 shows the syntax for reading numeric and char data from a sequential access file in C++, as well as the syntax for reading string data. The figure also includes examples of using each syntax. In each syntax, fileObject is the name of an ifstream object in the project. The variableName and stringVariableName represent the name of the variable that will store the information read from the file. As Figure 14-8 indicates, you use the extraction operator (>>) to read char and numeric data from a file. The inFile >> salary statement, for instance, stores numbers from the file and salary variables. The inAlphabet >> letter; statement in Example 2 reads a character from the file associated with the alphabet object and stores the character in the letter variable. To read data from a sequential access file, you use the getline function, which you learned in Chapter 13. The getline function will read characters from the file associated with the fileObject until it encounters the delimiterChar, which occurs. When a function consumes a character, it means that the function reads and discards the character. If you omit the delimiterChar argument the newline character remains.
