
# One-Dimensional Arrays

You access one variable in a one-dimensional array from another variable in the same array using a unique number. The unique number, which is an integer, is called a subscript. The subscript indicates the variable's position in the array and is assigned by the computer when the array is created in memory. The first variable in a one-dimensional array is assigned a subscript of 0, the second a subscript of 1, and so on. You refer to each variable in an array by its name and the variable's subscript, which is specified in a set of square brackets in one-dimensional array named sales. To refer to the first variable in a one-dimensional array named sales, you use `sales[0]`—read `sales sub zero`. Similarly, to refer to the second variable in the array, you use `sales[1]`. If the sales array contains four variables, you refer to the fourth (and last) variable using `sales[3]`. Notice that the last subscript in an array is always one less than the total number of variables in the array; this is because array subscripts start at 0. ## Declaring and Initializing a One-Dimensional Array

Before you use an array in a program, you must first declare (create) it. It is also a good programming practice to initialize the array variables to ensure they do not contain garbage when the program runs. As you learned in Chapter 3, the garbage found in uninitialized variables is the remains of what was stored at the memory location that the variable occupies. Figure 11-2 shows how to declare a one-dimensional array in C++. In the syntax, dataType is the type of the array variables, referred to as elements. ArrayName is naming a variable. NumberOfElements is an integer that specifies the size of the array. In other words, it specifies the number of elements you want to declare. To declare an array that contains 10 elements, you enter 10 as the NumberOfElements. Notice that you enclose NumberOfElements in square brackets []. You can initialize the array at the same time you declare it by entering more values, separated by commas, in the initialValues section of the syntax. You enclose initialValues in braces {}. Assigning values to an array is referred to as populating the array. The values used to populate an array should have the same data type as array variables. If data types are not the same, the computer uses implicit conversion to fit the array. However, recall from Chapter 3 that implicit conversion can adversely affect program's output. Therefore, you should be sure to populate an array using values that have the appropriate type. Also included in Figure 11-3 are examples of declaring and initializing one-dimensional arrays.

### HOW to Declare and Initialize a One-Dimensional Array

```cpp
dataType[numberElements] = {initialValues};
```

Example 1
```cpp
char letters[3] = {'A', 'B', 'C'};
```
declares and initializes a three-element char array named letters

Example 2
```cpp
double sales[4] = {0.0, 0.0, 0.0, 0.0};
```
declares and initializes a four-element double array named sales; each element is initialized to 0.0

```cpp
double sales[4] = {0.0};
```
declares and initializes a four-element double array named sales; each element is initialized to 0.0

Example 3
```cpp
int numbers[6] = {12, 0, 0, 0, 0, 0}
int numbers[6] = {12}
```
declares and initializes a six-element int array named numbers; the first element is initialized to 12, while the others are initialized to 0

Figure 11-3 How to declare and initialize a one-dimensional array

Keep in mind that if you inadvertently provide more values in the initialValues section than the number of array elements, C++ compilers will display the error message "too many initializers" when you attempt to compile the program. However, not all C++ compilers display a message when this error occurs. Rather, some compilers store the extra values in memory locations adjacent to, but not reserved for, the array. Therefore, you should be careful to provide no more than the appropriate number of initialValues.

## Entering Data into a One-Dimensional Array

As you can with a scalar variable, you can use either an assignment statement or the extraction operator to enter data into an array element. Figure 11-4 shows the syntax of such an assignment. In the syntax, `arrayName[subscript]` is the name and subscript of the array to which you want the `expression` assigned. The expression can include any combination of constants, variables, and operators. The data type of the `expression` must match the data type of the array element to which it is assigned; otherwise, an implicit conversion will occur, which could result in incorrect output.
