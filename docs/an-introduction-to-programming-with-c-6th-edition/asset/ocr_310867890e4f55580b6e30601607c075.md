# Using Two-Dimensional Arrays

As discussed in Chapter 11, an array is a group of related variables that have the same data type. Recall that the most commonly used arrays in business applications are one-dimensional and two-dimensional. You can visualize a one-dimensional array as a column of variables in memory, similar to the column of storage bins shown in Figure 11-1 in Chapter 11. A two-dimensional array, on the other hand, handles a number of variables in the two-dimensional array by multiplying the number of rows by the number of columns. An array with four rows and three columns, for example, contains 12 variables. Each variable is identified by a unique combination of two subscripts. The subscripts specify the variable's row and column position in the array. Variables located in the first row of the two-dimensional array are assigned a row subscript of 0. Variables located in the first column in the two-dimensional array are assigned a column subscript of 0. Similarly, variables in the second row are assigned a row subscript of 1, and so on. You refer to each variable in a two-dimensional array by the array's name and the row and column subscripts, with the row subscript listed first and the column subscript listed second. The row subscript is enclosed in a set of brackets [] and so is the column subscript. For example, to refer to the variable located in the first row, first column in a two-dimensional array named orders, you use orders [0]—orders sub zero. Similarly, to refer to the variable in the third row, third column, you use orders [1] [2]. Notice that the subscripts are one number less than the row and column in which the variable are located; this is because the row and column start at 0 rather than 1. You will find that the last row in a two-dimensional array is always one less than the number of rows in the array. Similarly, the last column subscript is always one less than the number of columns in the array.
