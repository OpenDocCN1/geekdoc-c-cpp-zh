## The Selection Structure

When an expression contains more than one comparison operator with the same precedence number, the computer evaluates the comparison operators from left to right in the expression, similar to what is done with arithmetic operators. Comparison operators are evaluated after any arithmetic operators in an expression. For example, when processing the expression 5 - 2 > 1 + 2, the computer will evaluate the two arithmetic operators before it evaluates the comparison operator. The result of the expression is the Boolean false, as shown in Figure 5.

| Original expression | 5 - 2 > 1 + 2 |
| :--- | :--- |
| The subtraction is performed first | 3 > 1 + 2 |
| The addition is performed next | 3 > 3 |
| The comparison is performed last | false |

Figure 5-9 Evaluation steps for an expression containing arithmetic and comparison operators

It is easy to confuse the equality operator (=) with the assignment operator (=). You use the equality operator to compare two values to determine whether they are equal, as in the condition `if (num == 1)`. Use the assignment operator, on the other hand, to assign a value to a memory location. An example of this is the statement `num = 1;`; in the next sentences, you will view programs that contain a comparison operator in an if statement condition.

## Swapping Numeric Values

Figure-10 shows the IPO chart information and C++ code for a program that displays the lowest and highest of two integers entered by the user. (The flowchart for this program is contained in Ch5Flowcharts.pdf file, which is located in Cpp6/Chap5 folder) The program program contains a single-alternative selection structure. The `firstNum > secondNum` condition compares the contents of the `firstNum` variable. If the value in the `firstNum` is greater than the `secondNum`, the condition evaluates to true and the four instructions in the if statement true path assign values. Swapping the values places the smaller number in the `firstNum` variable and the larger number in the `secondNum` variable. Notice that the four instructions in the true path are enclosed in braces. Because more than one instruction needs to be processed when the if statement's condition is true, the C++ syntax requires those instructions to be entered as a statement block. If the condition in the if clause evaluates to false, the instructions in the true path are skipped because the `firstNum` variable already contains a number that is smaller than (possibly equal to) the number stored in the `secondNum` variable.

Study closely the instructions used to swap the values stored in the `firstNum` and `secondNum` variables. The instructions are shaded in Figure 5-10. The instruction `int temp = 0;` declares and initializes a named `temp`. Because the variable can be used in the if statement's truth value, more specifically, it can be used only by the instructions within that path, or by the instructions that follow the declaration statement within the truth. A variable that can be used only within the statement block in which it is referred to is a local variable. In this case, the `temp` variable is local to the statement's truth value. You may be wondering why the `temp` variable was not declared at the beginning of the main function, with the `firstNum` and `secondNum` variables. There is nothing wrong with declaring the `temp` variable in that location, which is needed, when a swap is necessary. The second instruction in the if statement's truth value, `temp = firstNum;`, assigns the value of the `firstNum` to the `temp` variable. If you do not store the `firstNum`'s value in the next statement, `firstNum = secondNum;` which replaces the contents of the `firstNum` with the contents of the `secondNum`. Finally, `secondNum = temp;` assigns the value to the `secondNum` variable completes the swap. Figure 5-11 illustrates the concept of swapping, assuming the user enters the numbers 10 and 3. ## Logical Operators

You can use logical operators in an if statement's condition. Logical operators allow you to combine two or more conditions, referred to as subconditions into one compound condition. Logical operators sometimes are referred to as Boolean operators, the compound function in which they are contained always evaluates to either true or false. Figure 5-15 lists the most commonly used logical operators: And and Or. When the And operator is used to create a compound condition, all of the subconditions must be true for the compound condition to be. However, when the Or operator is used, only one of the subconditions must be true for the compound condition to be. C++ uses special symbols to represent the And and Or logical operators in a program. The operator in C++ is ampersands (&&); the Or operator is a type pipes (||).
