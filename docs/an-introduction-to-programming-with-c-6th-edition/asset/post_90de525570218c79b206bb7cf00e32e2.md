# Summary

- A repetition structure can be either a preprocess loop or a posttest loop. In a preprocess loop, the loop condition is evaluated *before* the instructions within the loop are processed. In a posttest loop, the evaluation occurs *after* the instructions within the loop are processed.

- The conditions at the end of a posttest loop determines whether the instructions within the loop body be processed more than once. The loop's condition must result in a true or false answer. When the condition evaluates to true, the instructions listed in the loop body are processed again; otherwise, the loop is exited.

- You use the `do while` statement to code a posttest loop in C++. You can use either the `while` statement or the `for` statement to code a preprocess loop in C++.

- Repetition structures can be nested, which means one loop (called the inner or nested loop) can be placed inside another (called the outer loop). For nested repetition structures to work correctly, the entire loop must be contained within the outer loop.
