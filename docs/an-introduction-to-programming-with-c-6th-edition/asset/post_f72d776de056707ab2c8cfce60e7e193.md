# Counter-Controlled Pretest Loops

In both Miller Incorporated and Sales Express programs, the termination of the loop is determined by a sentinel value that is entered by the user at the keyboard. Other loops are controlled using a counter rather than a sentinel value; such loops are referred to as **counter-controlled loops**. The

Jasper Music Company program provides an example of a counter-controlled loop. The program's problem specification, IPO chart information, and C++ instructions are shown in 7-22. The program flowchart is contained in the Cpp6(Chap07)ChFlowcharts.pdf. The input is the quarterly sales for each of the regions, and the output is the quarterly sales. The program uses one counter: that will keep track of the number of times loops are repeated. In this case, loop instructions need to be repeated three times, once for each sales region. Notice in the C++ instructions that the numRegions counter variable is initialized to the number 1, which corresponds to the first sales region. It's updated by each time the loop instructions are processed.

> The initialization and update of the counter variable in counter-controlled loops are comparable to the priming and updating reads in loops controlled by a sentinel value.

# Problem specification

The sales manager at Jasper Music Company wants a program that allows him to enter the quarterly sales made in each of three regions: Region 1, Region 2, and Region 3. The program should calculate the total sales and display the result on the screen. The program will use a counter to ensure the sales manager enters exactly three sales. It will use an accumulator to calculate the total sales.

> The loop will stop when the number of regions is equal to 4, because "greater than or equal to" "less than".
