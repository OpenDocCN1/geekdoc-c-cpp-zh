The getPayment function uses the periodic payment formula to calculate the payments. To use the formula, the function needs to know three items of information: the principal, monthly rate, and number of months. These items will be passed to the getPayment function when it is invoked by a statement in the main function. When calling the getPayment function to calculate the credit union payment, the statement will pass the difference between the car price and the rebate.
