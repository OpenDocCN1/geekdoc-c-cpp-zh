# The for Statement

Besides using the while, you can also use the for statement to code any preset loop in C++. However, the most common use of the for statement is to create loops whose processing is controlled by a counter--in other words, to code counter-controlled preset loops. This is because the for statement provides a compact way of writing that loop. The for statement's syntax is shown in Figure 7-28. The statement begins with the for clause, which contains three arguments separated by semicolons. The first and third arguments are optional. In the for clause, the initialization creates a counter that the computer uses to keep track of the number of loop body iterations processed. The variable is local to the for statement, which means it can be used only until the loop ends. It will be removed from the computer's memory when the loop ends. The condition argument specifies the condition that must be true for the loop body instructions to be processed. The condition must be a Boolean expression, which evaluates to true or false. The expression can contain variables, constants, arithmetic operators, comparison operators, and logical operators. The loop stops when the condition is false. The update clause contains an expression that updates the counter specified in the initialization. Following the for clause is the loop body. The loop body contains one or more statements that the want to repeat. If the loop body contains more than one statement, the statements must be represented as a statement block enclosing them in a set of braces {}. However, you can also include the braces when the loop body contains only one statement. Although it is not required by the C++ syntax, it is helpful to use a comment such as //for to document the end of the for statement. The comment will make your program easier to read and understand. Also shown in Figure 7-28 are examples of using the for statement. Example 1 displays the numbers 1, 2, and 3 on separate lines; while the condition is true.

- The condition argument in the for clause is a looping condition, because it specifies the requirements for repeating the loop instructions.
- The condition in Example 1 Figure 7-28 could be written as x < 3; Example 2 could also be written as x <= 1.

# HOW TO Use the for Statement

Syntax
`for (initialization); condition; [update])`

either one statement or a statement block to be processed as long as the condition is true

```cpp
//end for
```

Example 1: displays the numbers 1, 2, and 3 on separate lines the
```cpp
for (int x = 1; x < 4; x += 1)
cout << x << endl;
//end for
```
```cpp
you can also use x = x + 1
```

Example 2: displays the numbers 3, 2, and 1 on separate lines the
```cpp
for (int x = 3; x > 0; x = x - 1)

```
```cpp
you can also use x -= 1
```

- A common error made when typing the for clause is to use commas rather than semicolons.
