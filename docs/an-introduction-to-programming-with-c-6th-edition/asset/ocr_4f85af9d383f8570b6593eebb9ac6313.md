# Calling a Function

For a function to perform its task, it must be called (or invoked). The main function in a C++ program is invoked automatically when the program is executed. Functions other than main, however, must be called by a statement within the program. You do this by including the function's name and actual arguments (if any) in the statement, as indicated in the syntax and examples in Figure 9-15. The actual arguments are listed in the optional argumentList. Value-returning functions are typically called from statements that do one of the: assign the return value to a variable, use the return value in a calculation or comparison, or display the return value. The count statement in Example 1, for instance, calls the built-in value-returning rand function and then displays the function's return value on the screen. The statement in Example 2 calls the built-in value-returning sqrt function. The sqrt function calculates the square root of 10.0 and then returns the answer 3.16 to the statement which assigns the answer to the sqrt variable. Unlike a call to a value-returning function, a void function is an independent statement. In other words, it's not part of a statement that either assigns or displays the return value, because a void function does not return a value. Example 3 shows a statement that a built-in function returns: srand. The rand(5) statement sets the function to 5, which to initialize the random number generator. The function generates a random integer from one through ten and then returns the integer to the assignment statement, which assigns it to the num variable.
