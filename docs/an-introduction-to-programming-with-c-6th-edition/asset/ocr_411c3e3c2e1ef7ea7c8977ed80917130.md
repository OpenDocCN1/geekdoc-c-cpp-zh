# Displaying Messages on the Computer Screen

As you learned, you use objects to perform standard input and output in C++. In this section, you will learn about the standard output stream, cout (pronounced see out). The cout object used with the insertion operator << to display information “out” to the computer screen—in other words, to inform any combination of literals, named constants, or variables. Figure 4-5 shows several examples of statements that use cout and the insertion operator. Notice the semicolon that appears at the end of the syntax. Also notice that you can include more than one insertion operator in a statement. The cout << "Enter the price"; statement in the figure tells the computer to display a message that prompts the user to enter an item's price. Similarly, the message displayed by cout << "What is your middle initial?"; prompts the cout and insertion operator are not limited to displaying only messages that prompt the user to enter; you can also use them to display informational messages. The cout << "End of program"; statement, for instance, alerts the user that the program has ended. The cout << "Bonus: $$ bonusAmt << end1; on the other hand, displays a message along with the contents of the bonusAmt. The end1 in the statement is one of the stream manipulators that allows you to manage (or change) the characters in either the input or output stream. When used with the cout object, the end1 manipulator advances the cursor to the next line on the computer screen, which is equivalent to pressing the Enter key. When typing end1(which stands for end of line) in a statement, be sure to type the lowercase l rather than the number 1.
