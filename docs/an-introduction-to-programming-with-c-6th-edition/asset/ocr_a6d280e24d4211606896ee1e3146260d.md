# HOW TO Display the Contents of a One-Dimensional Array

Example 1
int x = 0;
while (x < 3)
    cout << letters[x] << endl;
    x += 1;
// end while
dis the contents of the three-element array

Example 2
for (int sub = 0; sub < 4; sub += 1)
{
    cout << "Sales for Region" << sub + 1 << ":";
    cout << sales[sub] << endl;
}// end for
displays the contents of the four-element sales array

Example 3
int x = 0;
do
{
    cout << numbers[x] << endl;
    x += 1;
} while (x < 6);
displays the contents of the six-element numbers array

> Note that the valid subscripts for the sales array in Example 2 are 0 through 3, whereas the valid region numbers are 1 through 4.
