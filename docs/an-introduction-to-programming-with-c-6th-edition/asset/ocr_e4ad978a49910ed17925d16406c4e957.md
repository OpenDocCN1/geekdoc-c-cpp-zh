Robin is sitting at a table in a bookstore, attending her book signing. Customers are standing in line waiting for Robin to sign their copy of their bestselling book on Robotics. Robin needs to sign each customer's book.

```
repeat (there are customers in line)
  accept the book from the customer
    place the book on the table
    open the front cover of the book
    sign your name on the first page
    close the book
  return the book to the customer
  thank the customer
end repeat
```

Now consider a *probelm* that a customer may have more than one book for Robin to sign. It's also possible that a customer, not knowing about the book signing in advance, has left his book at home and is standing in line for the sole purpose of meeting Robin. What changes will need to be made in the line, the first six instructions in the loop body—the instructions that begin with `*accept the book from the customer*` and end with `*return the book to the customer*`—must now be repeated for an unknown number of books for each customer. Therefore, in addition to require the current loop, which determines whether there is a customer in line, the modified algorithm would require a nested loop to determine whether the customer has any books need signing. Robin will tell the customer only after all of the customer's books have been signed, so the last instruction in the loop (the *thank the customer instruction*) needs to be repeated only for each loop. It does not need to be repeated for each book. Therefore, it should be included in the outer loop, but not in the nested loop. Figure 8-1 shows the modified specification and algorithm. The outer loop begins with *repeat (there are customers in line)* and ends with the last *repeat*. The nested loop begins with *repeat (there are books need signing)* and ends with the first *repeat*. The outer loop' instructions will be followed for each customer in line; the outer loop ends when there are no more customers. The nested loop's instructions will be followed for each book the current customer wants signed. The nested loop ends when the customer has no more books to sign. Note that the nested loop is contained within the outer loop. This must be true for the loop to be worked correctly.
