## Determining Whether a File Was Opened Successfully

Keep in mind that it is possible for the open function to fail when attempting to open a file. For example, the open function will not be able to create an output file either the path specified in the fileName argument does not exist or the disk is full. It will also not if you don't have permission to open. After using the open function on a file, you should use the is_open function to determine whether the file opened successfully. The is_open function returns the Boolean value true if the open function was able to open the file; otherwise, it returns the Boolean value false. Figure 1-4 shows the is_open function's syntax. In the syntax, file is the name of an existing object in the project. Most times, you will use the is_open function in an if statement's condition, as shown in the examples in Figure 1-4. For clarity, you can use either of the conditions shown in Example 1 to determine whether the file was able to be opened with the inFile object. The first condition in Example 1, inputFile.is_open() == true compares the is_open function's return value to the Boolean value true. If the condition evaluates to true, it means the open function was successful in opening the file. If the condition evaluates to false, it means the open function was not able to open the file. As you can omit the == true from the condition in Example 1, inputFile.is_open() is enough. Unlike the conditions in Example 2 which determine whether the open function failed to open the file associated with the fileObject. The outputFile.is_open() == false compares the is_open function's return value to the Boolean value false. In this case, you can use ! false preceding the condition with an exclamation point (!), as shown in the second condition in Example 2. The ! is not a logical operator in C++, and its purpose is to reverse the truth value of the condition. In other words, if the value of outputFile.is_open() is true, then the value of !outputFile.is_open() is false. Likewise, if the value of outputFile.is_open() is false, then the value of !outputFile.is_open() is true.

> The is_open function is a class member function in ifstream classes.

## Writing Data to a Sequential Access File

Figure 14-6 shows the syntax for writing to a sequential file in C++. In the syntax, outFile is the name of an existing ofstream object in the program, and data is the information you want to write to the file. The figure also includes examples of using the syntax. In Example 1 we writes the string "XYZ Corporation" to the file associated with the outFile object and then advances the pointer to the next line in the file. The first statement in Example 2 writes the string "Gross pay" to the file associated with the outFile object, but it leaves the pointer after the last character—in that line, after the space. The second statement in Example 2 writes the contents of the variable to the file and then advances the pointer to the next line in the file. If the variable contains the number 450, Example 2 writes "Gross pay:450", a sequential access file is used to store fields and records. A field is a single item of information about a person, place, or thing—such as a name, salary, a Social Security number, or prize. A record is a collection of one or more fields that contain all of the necessary data for a specific person, place, or time.
