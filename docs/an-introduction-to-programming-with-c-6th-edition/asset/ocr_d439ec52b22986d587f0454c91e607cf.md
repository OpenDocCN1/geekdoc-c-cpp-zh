# Calling a Function

Unless you specify otherwise, variables in C++ are automatically passed by value. For now, you do not need to concern yourself with passing by reference, because all functions in this chapter are passed by value. You will learn how to pass variables by reference in Chapter 10. The number of actual arguments passed to a function should match the number of formal parameters and position of each actual argument must agree with the data type and position of its corresponding formal parameter. This is because, when the function is called, the computer stores the value of the first actual argument in its first formal parameter, and the value of the second actual argument in its second formal parameter, and so on. The function in Example 5, for instance, passes double numbers to the rectangleArea function. This function shown earlier in Figure 2-8 contains two formal parameters, both of which have the double data type. The function uses the values stored in its formal parameters to calculate the area. It then returns the area to the statement that called it. In this case, it returns the area to the count << rectangleArea(7.25, 21.0); statement, which displays the area on the computer screen. The if clause in Example 6 invokes the bonus function. The function header (shown earlier in Figure 9-14) indicates that the function is expecting to receive two values, one integer that represents the amount sold and a double that represents the bonus rate. Because of this, the function call in Example 6 passes actual arguments in the correct data type and order: the int sales variable and the double rate variable. The computer stores the values of the actual arguments in the bonus function's formal parameters, which are named sold and bonusRate. Note that the names of the actual arguments do not have to be identical to the names of their corresponding formal parameters. In fact, to avoid confusion, it is better to use different names for the actual arguments and formal parameters. The bonus function uses the values in its formal parameters to calculate the salesperson's bonus. It then returns the bonus as a double number to the if clause, which compares return value to the double number 999.99. The condition will evaluate to true when the return value is greater than 999.99. It will evaluate to false when the return value is less than or equal to 999.99. In other words, it will fail when the computer encounters a statement that calls a function, it temporarily leaves the calling function to process the code contained in the called function. It returns to the calling function only after the called function ends.
