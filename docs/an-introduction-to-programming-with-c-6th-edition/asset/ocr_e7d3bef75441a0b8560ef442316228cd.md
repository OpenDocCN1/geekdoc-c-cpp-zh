# Arithmetic Operators in C++

Instructions 2 and 3 in the algorithm show in Figure 4-6 involve arithmetic calculations by writing an arithmetic expression that contains one or more arithmetic operators. Figure 4-7 lists the standard arithmetic operators available in C++, along with their precedence numbers. The precedence numbers indicate the order in which the computer performs the operation in an expression. Operations with a precedence of 1 are performed before operations with a precedence of 2, which are performed before operations with a precedence of 3, and so on. You can use parentheses to override the order of precedence, because operations within parentheses are always performed before operations of precedence.

> C++ also provides arithmetic assignment operators, which you will learn about in this chapter.

| --- | --- | --- |

| *, % | multiplication, division, and modulus arithmetic | 2 |
