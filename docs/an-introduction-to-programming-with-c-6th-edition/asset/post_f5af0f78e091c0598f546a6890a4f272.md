    // last names

# Removing Characters from a string Variable

At times, you may need to remove one or more characters from an item of data entered by the user, such as a digit sign from the beginning of a sales amount or a percent sign from the tax rate. In C++, you can use the string class's erase function to remove one or more characters located within a string variable. Figure 13-25 shows the function's syntax. In the syntax, the name of a string variable, and the subscript argument is the subscript of the first character you want to remove (erase) the variable's contents. Returns The first character in a string has a subscript of 0. The count argument is an integer that specifies the number of characters you want to remove. If you omit the count argument, the erase function removes all characters from the subscript position to the end of the string. Figure 13-25 also shows examples of using the erase(0, 7); statement in Example 1 tells the computer to remove the first seven characters from the string stored in the place variable. In this case, the computer removes the letters S, a, l, e, and space characters. After the string is processed, the place variable contains "Oregon". The place.erase(5); statement in Example 2 tells the computer to remove all of characters from the place variable, beginning with the character whose subscript is 5. In this case, the statement removes the "Oregon" portion of the string variable.

After the statement is processed, the place contains the string 'Salem'. The name.erase(2, 1); statement in Example 3 removes one character, beginning with the character whose subscript is 2, from the string stored in the name variable. In other words, it removes the h. After the statement is processed, the name variable contains the string 'Jon'. The code in Example 4 contains a loop that looks at each character in the salary variable, one at a time. The condition in the if statement within the loop compares the current character to both comma and space. If the character is either of those, the salary.erase(script, 1); statement in the if statement's true removes the character from the variable. Otherwise, the subscript += 1; statement increments the subscript by 1, which allows the loop to look at the next character in the salary variable.

# HOW TO Use the erase Function

string.erase(subscript, count);

Example 1
string place = "Salem, Oregon";
place.erase(0, 7);

removes the first seven characters from the place variable, changing the variable's contents to "Oregon"

Example 2
string place = "Salem, Oregon";
place.erase(5);
removes all characters from the place variable, beginning with the character whose subscript is 5, changing the variable's contents to "Salem"

Example 3
string name = "John";
name.erase(2, 1);
