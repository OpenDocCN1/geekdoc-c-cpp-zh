You will desk-check the area calculator program in Figure 9-22 using double numbers 7.0 and 10.0 as the rectangle's length and width, respectively. Desk-checking the program will help you understand how the computer processes a program-defined value-returning function when it is invoked. The statements on Lines 12 through 14 in the program create and initialize three double variables named length, width, and area. The statements on Lines 16 through 19 prompt the user to enter the length and width of the rectangle and store the user's responses in the length and width variables, respectively. The assignment on Line 21 calls the getRectangleArea function, passing it two arguments: the double length variable and the double width variable. Unless specified otherwise, variables in C++ are passed by value, which means that only the contents of the variables are passed to the function. In this case, the computer passes the numbers 7.0 and 10.0 to the getRectangleArea function. At this point the computer leaves the main function to access the getRectangleArea code with the function header on Line 29 in the program. The function header contains two parameters. The formal parameters tell the computer to reserve two memory locations: a double variable named len and a double variable named wid. After reserving the len and wid variables, the computer stores the values passed to the function—in this case, the numbers 7.0 and 10.0–in the variables.
