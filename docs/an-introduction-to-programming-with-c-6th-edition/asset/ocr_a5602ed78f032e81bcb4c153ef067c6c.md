F-13 shows a program that uses a MonthDay object to display a date. The code pertaining to use the MonthDay object is shaded in the figure. The **#include "MonthDay.h"** directive in Line 6 calls the compiler to include the contents of MonthDay.h file (shown in Figure-12). The **MonthDay** object named **myDate** is instantiated, the parameterized constructor **MonthDay myDate("04", "28"); is called, automatically, to initialize the private data members. In this case, the parameterized constructor initializes the **month** and **day** variables to the strings "04" and "28". The **cout** statement in Lines 18 and 19 calls the MonthDay object's **getMonthDay** method. The method retrieves the values stored in the **month** and **day** variables and returns the values (separated by a slash) to the **cout** statement—on the computer screen. The **myDate.getMonthDay(month, day);** statement in Line 27 calls the getMonthDay method, passing the values stored in the private **month** and **day** variables. The **cout** statement in Lines 30 and 31 calls the **getMonthDay** method again. As before, the method retrieves the values stored in the **month** and **day** variables and returns the values (separated by a slash) to the **cout** statement. The statement displays the return value on the computer screen. A sample of the display date program is shown in Figure-14.
