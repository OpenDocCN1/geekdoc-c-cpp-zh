为了理解为什么图 6-15 中的错误算法无法正常工作，你将使用与检查正确算法时相同的测试数据进行人工跟踪检查（desk-check）。错误算法的第一条指令是输入代码和销售额。在第一次检查中，代码和销售额分别为 X 和 15000。第二条指令是将销售额乘以 .08 来计算奖金；答案是 1200。第三条指令中的条件判断销售人员的代码是否为 X，同时销售额是否大于或等于 10000。在这种情况下，选择结构的真路径给奖金增加了 150，得到 1350，然后选择结构结束。错误算法的最后一条指令在屏幕上显示奖金（1350）。尽管其选择逻辑逻辑表述不正确，但在使用第一组测试数据时，错误算法产生的结果与正确算法相同。

使用第二组测试数据，用户输入 X 作为代码，输入 9000 作为销售额。错误算法的第二条指令将销售额乘以 .08，得到 720 的奖金。第三条指令中的条件判断销售人员的代码是否为 X，同时销售额是否大于或等于 10000。在这种情况下，复合条件评估为失败，因为销售额不满足指定标准。结果，选择结构的假路径给奖金增加了 125，得到 845，然后选择结构结束。错误算法的最后一条指令在屏幕上显示奖金（845）。在这里，使用第二组测试数据，错误算法产生的结果与正确算法一致。

使用第三组测试数据，用户输入 A 作为代码，输入 13000 作为销售额。错误算法的第二条指令将销售额乘以 .08，得到 1040 的奖金。第三条指令中的条件判断销售人员的代码是否为 X，同时销售额是否大于或等于 10000。在这种情况下，复合条件评估为失败，因为销售人员的代码不是 X。结果，选择结构的假路径给奖金增加了 125，得到 1165，然后选择结构结束。错误算法的最后一条指令在屏幕上显示奖金（1165）。注意，错误算法在使用第三组测试数据时产生了错误结果：根据图 6-10，

## 第二个逻辑错误：反转外层和嵌套决策

编写选择结构时常见的另一个错误是反转外层结构和嵌套结构所做的决策。图 6-17 显示了奖金算法中这种错误的示例。图中包含了正确的算法以供比较。正确算法中的选择结构在确定销售额之前先确定销售人员的代码，而错误算法中的选择结构在确定代码之前确定了销售额。考虑这如何改变了算法。选择结构只让代码为 X 的销售人员获得额外奖金。相反，错误算法中的选择结构表明，所有销售额大于等于 10000 的销售人员都会获得错误的奖金。

| 正确算法 | 错误算法 |
|---|---|
| 1. 输入代码和销售额 | 1. 输入代码和销售额 |
| 2. 将销售额乘以 .08 计算奖金 | 2. 将销售额乘以 .08 计算奖金 |
| 3. if (代码为 X) | 3. if (销售额大于或等于 10000) |
| (if 销售额大于等于 10000) | if (代码为 X) |
| 给奖金增加 150 | 给奖金增加 150 |
| else | else |
| 给奖金增加 135 | 给奖金增加 125 |
| end | end |
| end | end |
| 4. 显示奖金 | 4. 显示奖金 |

|图 6-17 正确算法与包含第二个逻辑错误的错误算法

对图 6-17 中的错误算法进行人工跟踪检查将告诉你为什么该算法无法正常工作。正确算法的第一条指令是输入代码和销售额——在这种情况下，为 X 和 1500。第二条指令是将销售额乘以 .08；这样做得到 1200 的奖金。第三条指令中外层选择结构的条件判断销售额是否大于或等于 10000。它们是，因此嵌套选择结构判断销售人员的代码是否为 X。是，所以嵌套结构的真路径给奖金增加了 150，得到 1350，然后选择结构结束。最后一条指令在屏幕上显示奖金（1350）。尽管其选择逻辑表述不正确，但在使用第一组测试数据时，错误算法产生的结果与正确算法相同。

使用第二组测试数据，用户输入 X 作为代码，9000 作为销售额。错误算法的第二条指令将销售额乘以 .08，得到 720 的奖金。第三条指令中外层选择结构的条件判断销售额是否大于或等于 10000。它们不是，所以外层选择结构结束。注意，当外层选择结构评估为假时，嵌套选择结构不会执行。最后一条指令显示奖金（720），这是错误的。

使用第三组测试数据，用户输入 A 作为代码，13000 作为销售额。错误算法的第二条指令将销售额乘以 .08，得到 1040 的奖金。第三条指令中外层选择结构的条件判断销售额是否大于或等于 10000。它们是，因此嵌套选择结构判断销售人员的代码是否为 X。它不是，所以嵌套结构的假路径给奖金增加了 125，得到 1165，然后选择结构结束。最后一条指令显示奖金（1165），这是错误的。图 6-8 显示了错误算法的人工跟踪表。在图中，只有第一次检查的结果是正确的。

| 代码 | 销售额 | 奖金 |
|---|---|---|
| X | 15000 | 1200（第一次检查的正确结果） |
| X | 9000 | 720（第二次检查的错误结果） |
| A | 13000 | 1165（第三次检查的错误结果） |
