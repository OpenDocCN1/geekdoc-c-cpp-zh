# Summary

+   * A two-dimensional array resembles a table that the elements are in rows\sand columns. Each element has the same data type.
* You can determine the number of elements in a two-dimensional array by
multlying the number of rows by the number of its columns.
* Each element in a two-dimensional array is identified by a unique
of subscripts. The first subscript represents the element's row
location in the array, and the second subscript represents its location.
You refer to each element in a two-dimensional array by the array's
name and the element's subscripts, which are specified in two sets of
square brackets immediately following.
* The first row subscript in a two-dimensional array is 0; the first column
script is also 0. The last row subscript is always one less than
t number of rows in the array. The last column subscript is always one
less than the number of columns in the array.
* You must declare a two-dimensional array before you can use it. When
dearing a two-dimensional array, you must provide the number of rows
as well as the number of columns.
* After declaring a two-dimensional array, you can use an assignment\statement or the extraction operator to enter data into the array.
* You need two loops to access every element in a two-dimensional
array. One of the loops keeps track of row subscript. The other loop
keeps track of column subscript.
* To pass a two-dimensional array to a function, you include the array's
name in the statement that calls the function. The array's corresponding
formal parameter in the function header must specify the formal param-
eter's data type and name, followed by two sets of square brackets. The
first bracket contains the number of rows, and the second bracket contains
t number of columns.
