# The Rearranged Name Program

To Use the find Function
Syntax
string.find(searchString, subscript)

```
Example 1
int location = 0;
phone = "(312) 999-9999";
location = phone.find("312", 0);\searches the phone variable, starting with the first character (subscript 0),
to determine the location of the string("312"); stores the result (0) in the
location variable
```
