
## Example 4—A Class that Contains Overloaded Methods

The calcGross method calculates and returns the gross pay for a salaried employee, requires a program to pass one item of information: the employee's annual salary. The second calcGross method, on the other hand, handles and returns the gross pay for an hourly employee and requires two items of information: the number of hours the employee worked and his her rate of pay. Rather than using two overloaded calcPay class, for example, you could use a method named calcSalariedGross to calculate and return the gross pay for a salaried employee and use a method named calcHourlyGross to calculate and return the gross pay for an hourly employee. The advantage of overloading the calcGross method is that you need to remember the name of only one method.

![](img/d64a28a6f49d61137bf2f3170ac40ad.png)

```cpp
// GrossPay.h
// Created by <name> on <date>

// declaration section
class GrossPay {
public:
    double calcGross(double);
    double calcGross(double, double);
};

// implementation section
double GrossPay::calcGross(double yearSalary) {
    return yearSalary / 24;
}

double GrossPay::calcGross(double h, double r) {
    return h * r;
}
```

GrossPay; statement in Line 14 instantiates employee. Notice that the calcGross method appears in two statements in Figure F-16. The computer uses the signature of the method in each statement to determine which calcGross to call. In this case, the gross = employee.calcGross(salary); statement in Line 32 tells the computer to process the calcGross method that contains one double parameter and in the GrossPay class, the calcGross method that contains one double variable calculates and returns the gross pay for a salaried worker. The worker = employee.calcGross(hours, hrPay); in Lines 41 and 42, on the other hand, tells the computer to process the calc method that contains two double parameters and then assign the return value to the program's gross variable. In the GrossPay class, the calcGross method that contains two double parameters calculates and returns the gross pay for an hourly worker. Before the program ends, it displays the contents of its gross variable on the computer screen. Sample runs of the gross pay program are shown in Figures F-17 and F-18.

```cpp
// GrossPay.cpp
// Displays the gross pay for salaried and hourly employees
// Created by <your name> on <date>

#include <iostream>
#include <iomanip>
#include "GrossPay.h"
using namespace std;

int main() {
    // create GrossPay object
    GrossPay employee;
    // declare variables
    int employeeType = 0;
    double salary = 0.0;
    double hours = 0.0;
    double hrPay = 0.0;
    double gross = 0.0;

    cout << fixed << setprecision(2);

    // determine employee's type
    cout << "Salaried (1) or Hourly (2): ";
    cin >> employeeType;

    if (employeeType == 1) {
        cout << "Annual salary: ";
        cin >> salary;
        gross = employee.calcGross(salary);
    } else if (employeeType == 2) {
        cout << "Hours worked: ";
        cin >> hours;
        cout << "Hourly pay: ";
        cin >> hrPay;
        gross = employee.calcGross(hours, hrPay);
    } else {
        cout << "Incorrect employee type." << endl;
    }
    // end if
    // end if

    // display gross pay
    cout << "Gross pay: $" << gross << endl;

    system("pause");
    return 0;
} // end of main function
```

## Summary

- A class is a blueprint or pattern for creating an object.
- A class encapsulates the attributes and behaviors of an object.
- The OOP concept of abstraction refers to the hiding of internal details from the user.
- The class definition specifies the attributes and behaviors of an object.
- The class consists of two sections: declaration and implementation.
- The declaration section contains the class statement.
- The implementation section contains the method definitions.
- You can instantiate an object from a class.
- Overloading methods allows you to use the same name for methods that require different information.
- The computer uses the method's signature to determine which overloaded method to process.
