# Repeating Program Instructions

Recall that all computer programs are written using one or more of three structures: sequence, selection, and repetition. You learned about the sequence and selection structures in previous chapters. This chapter provides an introduction to the repetition structure. Programs use the repetition structure, referred to simply as a loop, when they need the computer to repeatedly process one or more program instructions. The loop contains a condition that controls which instructions are repeated. In programming languages, the condition can be phrased in one of two ways: it either specify the requirement for repeating the instructions or the requirement for not repeating them. The requirement for repeating is referred to as the loop condition, which indicates when the computer should continue 'looping' through the instructions. The requirement for not repeating the instructions is referred to as the loop exit condition which tells the computer when to exit (or stop) the loop. An example may help illustrate the difference between the looping condition and loop exit condition. "Make hay while the sun shines" "While the sun is the looping condition, because it tells you when to continue making hay. The adage can be phrased as "Make hay until the sun is no longer shining." In this case, the sun is no longer shining is the loop exit condition, which indicates when you should stop making hay. Every loop has a loop exit condition; in other words, it is the opposite of the other. In the C++ programming language, the repetition structure is always phrased as a looping condition, which means it always contains the requirement for repeating instructions within the loop.

A repetition structure can be either a pretest loop or posttest loop. In both types of loop, the condition is evaluated with each repetition (iteration) of the loop. In a pretest loop, the condition is evaluated before the instructions within the loop are processed. In a posttest loop, the evaluation occurs after the instructions within the loop are processed. Depending on the result of the evaluation, the instructions in a posttest loop may never be processed. The instructions in a posttest loop, however, will be processed at least once. Of the two types of loop, the pretest loop is the most commonly used. You will learn about pretest loops in chapter 8.
