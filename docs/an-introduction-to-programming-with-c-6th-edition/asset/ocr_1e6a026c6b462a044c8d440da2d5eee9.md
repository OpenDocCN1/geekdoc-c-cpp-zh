# CHAPTER 13 Strings

# HOW TO Use the ignore Function

Syntax
cin.ignore([numberOfCharacters] [, delimiterCharacter]);

Example 1
cin.ignore();
reads and consumes one character; also can be written as cin.ignore(1);

Example 2
cin.ignore(5);
reads and consumes five characters

Example 3
cin.ignore(100, '\n');
reads and consumes characters until 100 characters are consumed
or the newline character is consumed, whichever occurs first

Example 4
cin.ignore(25, '#');
reads and consumes characters until 25 characters are consumed
or the # character is consumed, whichever occurs first
