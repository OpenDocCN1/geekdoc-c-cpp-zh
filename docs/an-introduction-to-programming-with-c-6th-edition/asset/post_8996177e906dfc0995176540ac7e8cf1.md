
# CHAPTER 9 Value-Returning Functions

## HOW TO Call a Function
Syntax
```cpp
functionName({argumentList})
```

Example 1
```cpp
cout << rand();
```
The statement calls the built-in value-returning rand function and displays the function's return value on the computer screen.

Example 2
```cpp
double squareRoot = 0.0;
squareRoot = sqrt(100.0);
```
The assignment statement calls the built-in value-returning sqrt function, passing the double number 100.0. It displays the function's return value on the computer screen.

Example 3
```cpp
rand(5);
```
The statement calls the void function, passing the integer 5. The function uses the integer to initialize the random number generator.

Example 4
```cpp
int num1 = 0;
num1 = getRandomNumber();
```
The assignment statement calls the getRandom function and assigns the function's return value to the num1 variable.

Example 5
```cpp
cout << getRectangleArea(7.25, 21.0);
```
The statement calls the getRectangleArea function, passing the double number 72.25 and 21.0. It displays the function's return value on the computer screen.

Example 6
```cpp
int sales = 0;
double rate = 0.0;
cin >> sales;
cin >> rate;
if (getBonus(sales, rate) > 999.999)
```
The clause calls the getBonus function, passing the integer stored in the sales variable and the double number stored in the rate variable. It compares the function's return value to the double number 999.999.

## Function Prototypes

Most C++ programmers use the function definitions below the main function in a program. When a function definition appears below the main function, you must define a function prototype above the main function; otherwise, the compiler will not recognize the function's name when it is used in the main function. A function prototype is a statement that specifies the function's name, the data type of its return value, and the data type of each of its formal parameters (if any).
