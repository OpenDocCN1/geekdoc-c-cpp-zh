# CHAPTER 2 Beginning the Problem-Solving Process

Problem specification
The manager of the Lakeview Hotel wants a program that calculates and displays a guest's total bill. Each guest pays a room charge that is based on a per-night rate. For example, if the per-night rate is $100 and the guest stays two nights, the room charge is $200. Customers may also incur one-time room service charge and a one-time telephone charge.

| Input | Processing | Output |
| --- | --- | --- |
| number of nights | Processing items: none | total bill |
| per-night rate | | |
| room service charge | | |

+   Algorithm:
1. enter the number of nights, per-night rate, room service charge, and telephone charge
2. calculate the total bill by multiplying the number of nights by the per-night rate and then adding the result to the room service charge and telephone charge
3. display the total bill
