The definition of the Salesperson class appears in Lines 11 through 17 in Figure F-4 The class contains three data members. Each data member is represented by a variable declaration, which specifies the variable's type and but not its initial value. This is because you cannot initialize variables within the Class statement. Notice that the variable declarations in Lines through 16 appear below the keyword public. When a variable is declared below the public keyword in a class definition, any program that instantiates an instance of the class can access the value. In any case, any program that instantiates a Salesperson object can use the variables included in the Salesperson class. Notice the Salesperson class definition contains the declaration section only.
