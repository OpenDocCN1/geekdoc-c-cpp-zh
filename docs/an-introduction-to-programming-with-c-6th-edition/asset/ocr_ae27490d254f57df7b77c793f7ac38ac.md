# Pass/Fail Program

A program needs to display the word "Pass" when the user enters the letter P (in either uppercase or lowercase) and display the word "Fail" when the user enters anything else. You can use either of the examples in Figure 5-20 to code the program. Both examples contain a dual-alternative selection structure. The compound condition in Example 1 uses the Or operator to determine whether the letter contains the uppercase P or the lowercase p. When the letter contains one of the two, the compound evaluates to true and the selection structure displays the word "Pass" on the screen; otherwise, it displays "Fail". You may be wondering why you need to compare the contents of the letter variable with both the uppercase and lowercase forms of the letter P is true in many programming languages, character comparisons in C++ are case-sensitive, meaning the uppercase version of a letter is not the same as its lowercase counterpart. Despite us them being the same key, a computer does not; to a computer, a P is different from p. The reason for this difference in Chapter 3. Recall that each character on a keyboard is assigned a unique ASCII code, which is stored in the computer's internal memory using a group of 0s and 1s. The ASCII code for uppercase P is 80 and p, on the other hand, is 112 and is stored using the bits 01110000. Using the Or operator to determine whether the letter variable contains either P or p, you could also use the And operator as shown in Figure 5-20. The compound condition in the second example determines whether the letter variable is not equal to the uppercase letter P and (at the same time) not equal to the lowercase letter p. When the variable does not contain either of them, the compound condition evaluates to true and the selection structure displays the word "Fail" on the screen; otherwise, it displays the word "Pass". Figures 5-21 and 5-22 show sample runs of a program that contains the code shown in each of the examples in Figure 5-20.
