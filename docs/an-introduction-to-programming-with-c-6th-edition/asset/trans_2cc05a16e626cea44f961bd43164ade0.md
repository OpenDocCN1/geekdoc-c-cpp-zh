## 第2章 开始解决问题

### 问题规范
Lakeview 酒店的经理希望有一个程序可以计算并显示客人的总账单。每个客人都要支付基于每晚费用的客房费。例如，如果每晚费用为 $100 且入住了两晚，客房费为 $200。客户还会产生一次性的客房服务费和一次性的电话费。

| 输入 | 处理 | 输出 |
| --- | --- | --- |
| 住宿晚数 | 处理项目：无 | 总账单 |
| 每晚费用 | | |
| 客房服务费 | | |

- 算法：1. 输入住宿晚数、每晚费用、客房服务费和电话费
2. 用住宿晚数乘以每晚费用，然后将结果加上客房服务费和电话费以计算总账单
3. 显示总账单
