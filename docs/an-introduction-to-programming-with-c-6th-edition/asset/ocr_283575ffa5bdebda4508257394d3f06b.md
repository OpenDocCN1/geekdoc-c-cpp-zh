# Replacing Characters in a string Variable

Rather than using the erase function to code the annual income program from the previous section, you can also use the string class's replace function. The replace function replaces a sequence of characters in a string with another variable of that number. For example, you can use the replace function to replace area code "800" with "877" in a phone number. Or, you can use it to replace the dashes in a Social Security number with the empty string. You can use it to replace a character, such as a comma or space, with the empty string. Figure 13-28 shows the replace function, string is a string variable, and the subscript argument specifies where to begin replacing characters in the string. The count argument indicates the number of characters to replace, and the replacement argument contains the pattern. The phone.replace(2, 3, "877"); statement in Example 1 tells the compiler to replace the "800" with "877". After the statement is processed, the phone variable contains "877-111-0000". The item.replace(3, 1, "D"); statement in Example 2 replaces the letter X, whose subscript is 3 in the item variable, with the letter "D". In other words, the statement changes the value stored in the item variable from "ABCX34" to "ABCD34". The name.replace(7, 6, "Farley"); statement in Example 3 replaces the string "Wilson" in the name variable with the string "Farley"; during this changes the variable's contents to "Karen Farley". Example 4 replaces with the empty string any commas and spaces contained in the salary variable. In other words, it removes commas and spaces from the variable.
