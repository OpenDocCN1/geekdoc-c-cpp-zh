# Pass/Fail Program

A program needs to display the word "Pass" when the user enters the letter P (in either uppercase or lowercase) and display the word "Fail" when the user enters anything else. You can use either of the examples in Figure 5-20 to code the program. Both examples contain a dual-alternative selection structure. The compound condition in Example 1 uses the Or operator to determine whether the letter contains the uppercase P or the lowercase p. When the letter contains one of the two, the compound evaluates to true and the selection structure displays the word "Pass" on the screen; otherwise, it displays "Fail". You may be wondering why you need to compare the contents of the letter variable with both the uppercase and lowercase forms of the letter is true in many programming languages, character comparisons in C++ are case-sensitive, meaning the uppercase version of a letter is not the same as its lowercase counterpart. Despite us them being the same key, a computer does not; to a computer, a P is different from p. The reason for this difference in Chapter 3. Recall that each character on a keyboard is assigned a unique ASCII code, which is stored in the computer's internal memory using a group of 0s and 1s. The ASCII code for uppercase P is 80 and p, on the other hand, is 112 and is stored using the bits 01110000. Using the Or operator to determine whether the letter variable contains either P or p, you could also use the And operator as shown in Figure 5-20. The compound condition in the second example determines whether the letter variable is not equal to the uppercase letter P and (at the same time) not equal to the lowercase letter p. When the variable does not contain either of them, the compound condition evaluates to true and the selection structure displays the word "Fail" on the screen; otherwise, it displays the word "Pass". Figures 5-21 and 5-22 show sample runs of a program that contains the code shown in each of the examples in Figure 5-20.

Recall that operators with the same precedence number are evaluated from left to right in an expression. Notice that logical operators are evaluated after any arithmetic operators or comparison operators in an expression. As a result, when the computer processes the arithmetic 30 / 75 / 3 & 5 < 10 * 2, it evaluates the arithmetic operators first, followed by the comparison operators, followed by the logical operator. The expression evaluates to true, as shown in the example included in Figure 5-23.

| Operator | Operation | Precedence number |
| --- | --- | --- |
| () | override normal precedence rules | 1 |
| - | negation (reverses the sign of a number) | 2 |
| *, /, % | multiplication, division, and modulus arithmetic | 3 |
| +, - | addition and subtraction | 4 |
| <, <=, >= | less than, less than or equal to, greater than or equal to | 5 |
| ==, != | equal to, not equal to | 6 |
| And (&&) | all sub-conditions must be true for the compound condition to evaluate | 7 |
| Or (|) | only one of the sub-conditions needs to be true for the compound condition to evaluate | 8 |

# Converting a Character to Uppercase or Lowercase

Earlier, in Figure 5-20, you viewed two examples of C++ functions for the Pass/Fail program. In both examples, the if clause contains a compound condition that compares the character stored in the letter variable with the uppercase and lowercase forms of the letter. That is not the only way of comparing a variable's contents to both versions of it; you can also use either the following built-in functions: toupper or tolower. The toupper function converts a character to uppercase, while the tolower function converts it to lowercase. Figure 5-24 shows this. An expression enclosed in parentheses in a function's syntax is called an argument, and it represents information that the function needs to perform its task. In this case, the toupper and tolower functions need the name of a variable data type that char. Both functions convert the character to the appropriate case (if necessary) and return the temporary character. Keep in mind that the toupper and tolower functions do not change the contents of the variable they change the contents of the temporary location only. In addition, the toupper and tolower functions affect only characters that represent letters of the alphabet, as these are the only characters that have uppercase and lowercase forms. Also included in Figure 5-24 are examples of using the toupper and tolower functions. When using the toupper function in comparison, be sure that everything you comparing is uppercase; otherwise, the comparison will not evaluate correctly. For instance, the clause if tou(letter) == 'p' is not correct: the condition will always fail to evaluate, because the uppercase version of a letter will never equal its lowercase counterpart. # HOW TO Use the topper and tolower Functions

Syntax
topper(charVariable)
tolower(charVariable)

Example 1
```cpp
if (topper(letter) == 'P')
```
The condition compares the uppercase character returned by the topper function with the uppercase letter P. The condition evaluates to true when the character stored in the letter variable is either P or p.

Example 2
```cpp
if (tolower(letter) == 'p')
```
The condition compares the lowercase character returned by the topper function with the lowercase letter p. The condition evaluates to true when the character stored in the letter variable is either P or p.

Example 3
```cpp
initial = topper(initial);
```
The assignment statement changes the contents of the initial variable to uppercase.

# Formatting Numeric Output

In C++, numbers with a decimal place are displayed in either fixed-point or e (exponential) notation, depending on the size of the number. Recall that a number with a decimal place is called a small number. Large numbers—those containing six or five digits to the left of the decimal point—are displayed in fixed-point notation. For example, the number 1,234.56 is displayed in fixed-point notation as 1234.560000. Larger numbers containing more than six digits to the left of the decimal point—typically are displayed in e notation. The number 1,225,000.0, for example, is displayed in e notation as 1.25e+006. The type of number you create determines the appropriate format to use when displaying numbers with a decimal place. Business programs usually display numbers in fixed-point notation, while many scientific programs use stream manipulators that allow you to control the format used to display numbers. You use the fixed stream manipulator to display real numbers in fixed-point notation. To display real numbers in e notation, use the scientific stream manipulator. The appropriate manipulator must appear in a cout statement, and it must be processed before the number you formatted are displayed. After being processed, the manipulator remains in effect until either the end of the program or until it encounters another manipulator that changes it.
