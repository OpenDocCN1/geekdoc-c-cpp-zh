# CHAPTER 9 Value-Returning Functions

When the computer encounters the `sales = getSales();` statement on Line 19, it temporarily leaves the `main` function to process the `getSales` function's code, beginning with the function header on Line 31. The function header does not contain any function parameters, which indicates that the function will not receive any information when it is called. The first statement in the `getSales` function body creates an `int` variable named `salesAmt`. The variable is local to the `getSales` function, which means it can be used only within that function. The `salesAmt` variable will remain in the computer's internal memory until the `getSales` function ends. The next two statements in the `getSales` function prompt the user to enter a sales amount and then store the user's response—in this case, 1575—in the `salesAmt` variable. Figure 9-33 shows the sales amount entered in the desk-table.

Next, the computer processes the `getSales` function's return statement, which returns the `salesAmt` variable's value to the statement called the function. In fact, it returns the value to the assignment statement on Line 19 in the `main` function. The statement assigns the return value to the `sales` variable, as shown in Figure 9-34.
