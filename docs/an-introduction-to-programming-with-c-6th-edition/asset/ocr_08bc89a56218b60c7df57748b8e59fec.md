Figure 8-16 shows a modified version of the previous problem specification, along with the corresponding IPO chart information and C++ instructions. In the modified version, the program will display five asterisks on each of three separate lines on the computer screen. The modified algorithm will use two loops to accomplish this task: an outer loop to keep track of the number of lines and a nested loop to keep track of the number of asterisks. The changes made to the IPO chart information and C++ instructions are shown in Figure 8-16. In the code, the outer loop begins with the first for clause, which directs the computer to repeat the loop instructions. The outer loop ends with the //end for. Braces are required in the nested loop which begins with the second for clause, which directs the computer to repeat the cout << '* five times. The nested loop ends with //end for. Because are not needed in the nested loop because its body contains only one statement. Here again, notice that the entire nested loop is contained within the outer loop. Both loops in Figure 8-16 are coded using the `for` statement, or both could be coded using the `while` statement. In addition, the algorithm could have been written using one or more posttest loops. Recall that you use the `do while` statement to create a posttest loop in C++.
