To reveal the concept of passing by value, you will desk-check the program shown in Figure 10-5, using the number 34 as the age. The first statement in the main function creates and initializes an int variable age. The variable is local to the main function and will remain in memory until the main function ends. The next two statements prompt the user to enter an age and store the user's response (34) in the age variable. Next, the displayAge(age); statement on Line 17 calls the displayAge function, passing a copy of the value stored in the age variable. In this case, the statement passes 34. At this point, the computer leaves the main function to process the code contained in the displayAge function, beginning with the function header. The displayAge header indicates that the computer should create one local int variable named years. The computer stores the value passed to the function in years variable, as shown in Figure 10-7.

Next, the computer processes the cout contained in the displayAge function body. The statement displays string literals along with the function's local years variable. In this case, the statement will display the message "You are 34 years old." on the computer screen. The displayAge function ends when the computer encounters the years variable's closing brace. At that point, it returns to the main function to process the statement immediately following the one that called the displayAge function. In this case, the next system("pause"); returns on Line 19 is the first statement immediately following the function call. Figure 10-8 shows the desk-check table after the displayAge function ends. Only the main function's local age variable remains in the computer's memory.

Recall that the variables listed in a function header are local to the function and can be used only within the function. The variables remain in memory until the function ends.
