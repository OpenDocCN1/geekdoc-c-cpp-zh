# HOW TO Use the switch Statement

```
Syntax
witch (selectorExpression)
{
  case value1:
    one or more statements
    [break];
  case value2:
    one or more statements
    [break];
  case valueN:
    one or more statements
    [break];
  default:
    one or more statements to be processed when the selector-Expression does not match any of the values in the case clauses
    [break];
}
//end switch
```

Example

```
int main()
{
  char grade = ' ';

  //enter grade
  cout << "Letter grade: ";
  cin >> grade;
  grade = toupper(grade);

  switch (grade)
  {
    case 'A':
      cout << "Excellent";
      break;
    case 'B':
      cout << "Above Average";
      break;
    case 'C':
      cout << "Average";
      break;
    case 'D':
      cout << "Below Average";
      break;
    case 'F':
      cout << "Invalid grade"; //end switch
    default:
      cout << endl;
  }

  cout << endl;
  system("pause");
  return 0;
} //end main function
```
