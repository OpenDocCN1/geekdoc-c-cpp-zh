# HOW TO Use the replace Function

Syntax
string.replace(substring, count, replacementString);

Example 1
string phone = "1-800-111-0000";
phone.replace(2, 3, "877");
replaces three characters in the phone variable, beginning with the
character whose subscript is 2, with "877"; changes the contents of the
phone variable to "1-877-111-0000"

Example 2
string item = "ABC34";
item.replace(3, 1, "D");
replaces one character in the item variable, beginning with the character
whose subscript is 3, with "D", changes the contents of the item variable to
"ABCD34"

Example 3
string name = "Karen Wilson";
name.replace(7, 6, "Farley");
replaces six characters in the name variable, beginning with the character
whose subscript is 7, with "Farley", changes the contents of the
variable to "Karen Farley"

# Inserting Characters Within a string variable

In addition to removing and replacing characters in a string variable, you can also insert characters within a string variable. For example, you can insert an employee's middle initial between his first and last names. Or, you can insert parentheses around the area code in a phone number. You can also insert hyphens in a Social Security number. The string insert function for inserting characters within a string variable's syntax is shown in Figure 13-31. In the syntax, the name of the string variable and subscripts specify where in the string you are using to insert. To insert at the beginning of the string, use the number 0 as the subscript. To insert starting with the second character in the string, use the number 1 as the subscript and so on. Also shown in Figure 13-31 are examples of using the insert function: name.insert(7, "G ") tells the computer to insert—G. (the letter G, a period, and a space)—in the name variable. The letter G is inserted. The period and space are inserted in subscripts 8 and 9, making them the ninth and tenth characters in the variable. After the statement, the name variable contains the string "Karen Guthers". In Example 2, phone.insert(0, "(") changes the contents of the phone variable from "312 050-1111" to "(312)050-1111". The phone.insert(4, ")") statement then changes the variable's contents to "(312)050-1111". The ssn.insert(3, "-") statement changes the contents of the ssn variable from "11122000" to "111-22000". The ssn.insert(6, "-") statement changes the variable's contents to "111-22-0000".

# HOW TO Use the insert Function

Syntax
string.insert(subscript, insertString);

Example 1
string name = "Karen Wilson";
name.insert(7, " G.");
inserts the letter G, followed by a period and a space, between the first and last names stored in the name variable; changes the contents of the name variable to "Karen G. Wilson"

Example 2
string phone = "312 050-1111";
phone.insert(0, "(");
phone.insert(4, ")");
inserts the opening and closing parentheses at the end, respectively, of the area code; changes the contents of the phone variable to "(312)050-1111"

Example 3
string ssn = "111220000";
ssn.insert(3, "-");
ssn.insert(6, "-");
inserts two hyphens in the Social Security number, after the third number and after the fifth number; changes the contents of the ssn variable to "111-22-0000"

# Duplicating a Character Within a string Variable

You can use the string class assign function to duplicate one character specified number of times and then assigning the result to a string variable. Figure 13-35 shows the function's syntax and examples of using the function. In the syntax, string is the name of a string variable that will store the characters. The count argument is an integer that indicates the number of times you want to duplicate the character. The character argument can be either a literal constant enclosed in single quotes or the name of a char memory location. The asterisks.assign(10, '*') in Example 1 duplicates the asterisk 10 times and then assigns the resulting string to the asterisks variable. The underline.assign(companyName.length(), '-') in Example 2 duplicates the hyphen character zero or more times, depending on the number of characters in the companyName variable.
