# CHAPTER 14 Sequential Access Files

displayTotal function
IPO chart information | C++ instructions
Input
sales.txt (sequential access) | ifstream inFile;
Processing
salesperson's name and sales amount | string name = "";
int sales = 0;
Output
total sales amount (accumulator) | int total = 0;
Algorithm
1. open the sales.txt file for input | inFile.open("sales.txt");
2. if (the sales.txt file was opened successfully) | if (inFile.is_open()) {
   read the salesperson's name and sales amount from the sales.txt |   getline(inFile, name, '#');
   inFile >> sales;
   inFile.ignore();
   repeat (while it is not the end of the sales.txt) |   while (!inFile.eof()) {
      add the sales amount to the total sales amount |   total += sales;
      read the salesperson's name and sales amount from the sales.txt |   getline(inFile, name, '#');
      inFile >> sales;
      inFile.ignore();
   } //end while
   close the sales.txt file |   inFile.close();
   display the total sales amount |   cout << "Total sales $" << endl;
else
   display the "File could not be opened." message |   else {
      cout << "File could not be opened." << endl;
end if | //end if
