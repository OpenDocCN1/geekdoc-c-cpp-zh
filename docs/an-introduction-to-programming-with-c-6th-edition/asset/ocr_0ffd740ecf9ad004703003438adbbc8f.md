# The Creative Sales Program

Because many strings entered the keyboard contain one or more block characters (such as "Bowling Green, Kentucky" and "Gerald R. Jones"), the string class provides a member function for accepting that type of input. The function is called getline. You will need to use the getline function to get the salesperson's name in the Creative Sales Program.

# The getline Function

Figure 13-4 shows the syntax for using the getline function to get string input from the keyboard. The semicolon that appears as the last character in the syntax indicates that the getline function is a self-contained statement. The function has three arguments, two of which are required. The required cin argument refers to the computer keyboard, and the requiredVariableName is a string variable to store the input. You can use the delimiterArgument to indicate the character that immediately follows the string. The getline function will continue to read the characters entered at the keyboard until it encounters the delimiter character. If you omit the delimiterArgument, the default character is the newline character. For example, if the user types the words "Good night" and presses the Enter key, the string will end with the letter t, which is the last character used before pressing the Enter key. When the getline function encounters the delimiter character in the input, it discards it—a process C++ programmers refer to as consuming character. Also included in Figure 13-4 are examples of using the function. The statement in Example 1 tells the computer to read characters entered at the keyboard and then store them in the name variable. The computer will stop reading and storing when it encounters the newline character, which is when the user presses the Enter key. (Recall that the default character in the getline function is newline.) At that point, the computer will consume (discard) the newline character. The statement in Example 2 also tells the computer to read characters entered at the keyboard and store them in the name variable. Again, the computer will stop reading when it encounters the newline character. The newline character is designated in C++ by a backslash and the letter \n. Although the newline character consists of two characters, it is treated as one character by the computer. The backslash in the newline character is an escape character, and it indicates that the character that follows it—in this case, the letter n—has a special meaning. The meaning of the backslash and the character that follows it is an escape sequence. The statement in Example 3 in Figure 13-4 tells the computer to read the characters entered at the keyboard and store them in the city variable. In this case, the computer will stop reading and storing characters when it encounters the # character, which will be consumed.
