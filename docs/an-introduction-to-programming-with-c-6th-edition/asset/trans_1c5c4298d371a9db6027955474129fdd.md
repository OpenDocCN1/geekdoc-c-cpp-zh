图 F-1 如何定义类

如图 F-1 所示，类可以包含公共和私有成员。你在类语句中 `public` 关键字下方记录公共成员。私有成员记录在 `private` 关键字下方。当你使用类在程序中实例化（创建）对象时，只有类的公共成员是对程序公开的（可用的），而私有成员是 隐藏的。在大多数情况下，你将可能希望公开成员方法并隐藏数据成员。因此，在大多数类定义中，你会在类语句的 `public` 下方列出方法原型，并在 `private` 关键字下方列出变量声明，如图 F-1 中的 `FormattedDate` 类定义所示。你公开方法是为了允许程序调用它所提供的每个方法。你隐藏变量（数据成员）是为了保护其内容不被程序无意中更改。当程序需要向私有变量赋值数据时，它必须使用公共成员来执行此操作。例如，当使用图 F-1 中的 `FormattedDate` 类时，程序需要使用 `setState` 方法为 `month`、`day` 和 `year` 变量赋值数据。公共成员的责任是在必要时对数据进行验证，然后将数据赋值给私有数据成员（如果数据有效）或拒绝该数据（如果数据无效）。请记住，程序无法直接访问类的私有成员。相反，它必须通过公共成员方法直接访问私有成员。
