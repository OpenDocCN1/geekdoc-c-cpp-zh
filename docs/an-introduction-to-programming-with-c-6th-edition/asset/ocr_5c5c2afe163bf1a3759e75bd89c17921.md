# CHAPTER 8 More on the Repetition Structure

loop body prompt the user to enter the next sales amount and store the user's response in the sales variable. Notice that the loop instructions are processed before the condition in the while clause is evaluated. After the loop body instructions are processed, the condition in the while clause compares the value stored in the sales variable with the sentinel value. If the sales variable does not contain the sentinel value, the condition evaluates to true and the loop instructions are processed again. Those instructions calculate the bonus, then display the bonus and two blank lines, then prompt the user to enter the next sales amount, and store the user's response in the sales variable. From now, each time the user enters a sales amount, the condition in the while clause compares the amount with the sentinel value. When the user enters the sentinel value—in this case,—as the sales amount, the loop instructions are not processed again. Instead, the loop is kept repeating and continues with the instruction located immediately below the loop. A sample run of the Miller Incorporated program is shown in 8-9. (The program used the fixed and setprecision stream manipulation to display the bonus amounts in fixed-point notation with two decimal places.)
