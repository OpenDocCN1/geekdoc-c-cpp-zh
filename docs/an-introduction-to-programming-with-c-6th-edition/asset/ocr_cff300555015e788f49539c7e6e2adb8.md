# CHAPTER 4 Completing the Problem-Solving Process

In order for the user to know what to enter when your program is run on the computer, you will display a prompt—one that clearly indicates the information to be entered—for each item. In this case, you will need three prompts. Each prompt should be entered above its corresponding cin statement, as you want the prompt to appear before the user is to enter the information. The three prompts are shaded in Figure 4-6. Also shaded is the statement that displays the tip amount on the computer screen; the statement corresponds to the last instruction in the algorithm. Although it is customary to code algorithm's instructions in the order they appear in the algorithm, the statement to display the tip amount is included now since this section covers displaying messages on the computer.

You can also display the tip amount using the following three lines of code:

```
cout << "Tip: $";
cout << tip;
cout << endl;
```
