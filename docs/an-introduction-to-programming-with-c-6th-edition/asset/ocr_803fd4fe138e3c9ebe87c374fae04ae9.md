# The Ignore Function

You can use the C++ ignore function to instruct the computer to read first and ignore characters by discarding them in the cin object. The ignore function ignores the characters by consuming (discarding) them. Figure 13-9 shows the function's syntax. Unlike getline, the ignore function is a self-contained statement, with the semicolon at the end of its syntax. The function has two arguments, both of which are optional. The numberOfCharacters argument is represents the maximum number of characters the function should consume. If you omit the numberOfCharacters argument, the default is 1. The delimiter is a character that, when consumed, stops the ignore function from reading and discarding any additional characters. The ignore function stops discarding characters either when it consumes the number of characters specified in the numberOfCharacters argument or when it consumes the delimiter, whichever occurs first. Figure 13-9 also shows examples of using the ignore function. As indicated in Example 1, you can use the statement cin.ignore(); or the statement cin.ignore(1); to have the computer read and discard (consume) one character. The statement in Example 2 tells the computer to read and consume five characters. The statement in Example 3 tells the computer to read and consume characters until either 100 characters are consumed or the newline character is consumed, whichever occurs first. When the computer processes the statement in Example 4, it will read and discard characters until either 25 characters are consumed or the # character is consumed, whichever occurs first.
