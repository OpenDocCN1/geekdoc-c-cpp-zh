# Selecting an Initial Value for a Memory Location

you typically initialize a memory by assigning a literal constant to it. Unlike variables and named constants, literal constants are not memory locations. A literal constant is an item of data that can appear in a program instruction and be stored in a memory location. The data type of the literal should match the data type of the memory location to which it is assigned. Integers are stored using short or int type. Memory locations using the float or double data type should be initialized using real numbers. Integer and real numbers are called numeric constants; examples include the numbers 146, 0.0, and -2.5. Numeric constants can contain numbers, the plus, minus and decimal point. They cannot contain a space, a comma, or a special character, such as the dollar sign ($) or percent sign (%). A numeric literal with no decimal is considered an int type, whereas a numeric literal with a decimal is considered a double type. A character literal consists of one character enclosed in single quotes, such as the 'X', the dollar sign '$', and a space ' ' (two quotes with a space character). A string memory is initialized using a string constant, or more characters enclosed in double quotes. The word "Hello," "Enter your pet's age," and the empty string "" are examples of string constants.

When a program instructs the computer to assign a value to a memory location, the computer first compares the value's type with the memory location's data type. The comparison is made to verify that the value is appropriate for the memory. If the value's type does not match the memory location's data type, the computer uses an implicit type conversion to convert the value to fit the memory. For example, if a program initializes a double with the integer 9, the computer converts the integer to a real before storing the value in the variable. The computer does this by adding a decimal point and the number 0 to the end of the integer, like 9.0. The computer then stores the real value 9.0 in the price variable. When a value is converted from one data type to another that can store larger numbers, the value is said to be promoted. In this case, the int value 9 is promoted to the double because the double value can store larger numbers than the int type. In most cases, the promotion of values does not affect a program's output. However, consider a program that defines an int named called MIN_WAGE. If you use a real number to initialize it (such as 7.25), the computer converts the real number to an integer before storing the value in the memory location. This conversion works by truncating (dropping off) the decimal portion of the number. In this case, the computer converts the real 7.25 to the integer 7. As a result, the number 7 rather than 7.25 is assigned to the MIN_WAGE named constant. When a value is converted from one data type to another that can store smaller numbers, the value is said to be demoted. In this case, the double value 7.25 is demoted to the int value 7. The implicit demotion of values can affect a program's output. Therefore, it's important to initialize memory locations using values that have the same data type as the memory location.
