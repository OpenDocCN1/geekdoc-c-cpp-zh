# The Scope and Lifetime of a Variable

A variable's scope indicates where the program variable can be used, and its lifetime indicates how long the variable remains in the computer's internal memory. Although variables can have either local or global scope, most of the variables used in a program will have local because fewer unintentional errors occur in programs when the variables are declared using the minimum scope, which is usually local. A variable's scope and lifetime are determined by where you declare the variable. Programs declared within a function, and that appear as variables. Local variables are used only by the function in which they are declared or in whose parameterList. Local variables remain in the computer's internal memory until the function ends, which is when the computer encounters the function's closing brace. Global variables are declared outside of any function in the program, and they remain in memory until the program ends. Unlike a local variable, a global variable is accessible accessible. Declaring a variable that should not have access to the local variables may inadvertently change the variable's contents. Because of this, you should avoid using global variables in your programs. If more than one function needs access to a variable, it is better to use a local variable in one of the functions and pass that to the other that need it.

In the area calculator shown in Figure 9-22, the length, width and area variables are declared on Lines 12 through 14 in the main function. As a result, the variables are local to the main function and can be used only by statements below Line 14 within the main function. The getRectangleArea function is not aware of the existence of these variables in memory. If you use the getRectangleArea function to use the values stored in length and width variables, you will need to pass each variable's value to the function. The len and wid variables, however, are local to the getRectangleArea function because they appear in the parameterList. Therefore, only statements within the getRectangleArea function can use the len and wid variables. Local variables remain in the computer's internal memory until the function in which they are declared. This explains why len and wid variables are removed from memory after the getRectangleArea function ends. It also explains why the computer waits until the main function ends before it removes the length, width, and area variables from memory.
