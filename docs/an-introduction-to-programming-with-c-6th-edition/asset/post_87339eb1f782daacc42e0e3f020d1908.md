# Processing steps

- 1. The computer creates the RATE constant and initializes it to .05.
2. The computer creates the sales and bonus variables and initializes them to 0 and 0.0, respectively.
3. The computer prompts the user to enter the first sales amount and stores the user's response (in this case, 1000) in the sales variable.
4. The computer processes the for clause condition (sales != -1), which checks whether the sales variable's value is equal to -1. The condition evaluates to true, so the computer processes the statements in the loop body. They prompt the user to enter the next sales amount and store the user's response (in this case, 2500) in the sales variable.
5. The computer processes the for clause condition, which checks the sales variable's value is not equal to -1. The condition evaluates to true, so the computer processes the statements in the loop body. These statements calculate and display the bonus (1250). They also prompt the user to enter the next sales amount and store the user's response (in this case, -1) in the sales variable.
6. The computer processes the for clause condition, which checks whether the sales variable's value is not equal to -1. In this case, the condition evaluates to false, so the computer stops processing the loop. Processing continues with the statement following the end of the loop.
