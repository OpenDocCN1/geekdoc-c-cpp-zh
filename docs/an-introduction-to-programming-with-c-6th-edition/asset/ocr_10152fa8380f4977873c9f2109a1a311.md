+   32. If necessary, create a new project named Advanced32Project. Also create a new source file named Advanced32.cpp. Create a program that allows the user to enter a word. The program should display the word in pig latin. The rules for converting a word into pig latin form are Use a sentinel value to end the program.

+   1. When the word begins with a vowel (A, E, I, O, or U), add the string “way” (a dash followed by the w, a, and y) to the end of the word. For example, the pig latin form of the word “ant” is “ant-way”.
2. When the word does not begin with a vowel, add a dash to the end of the word. Then continue moving the first character in the word to the end of the word until the first character is A, E, I, O, or Y. Then add the string “pig” to the end of the word. For example, the pig latin form of the word “Chair” is “air-Ch”.
3. When the word does not contain the letter A, E, I, O, U, or Y, add the string “way” to the end of the word. For example, “56” is “56-way”.
