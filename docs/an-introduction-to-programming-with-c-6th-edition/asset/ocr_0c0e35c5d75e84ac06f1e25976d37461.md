# Declaring and Initializing a Two-Dimensional Array

Before you use a two-dimensional array in a program, you must first declare (create) it. It is also a good programming practice to initialize the array variables to ensure they not contain garbage when the program runs. Recall assigning initial values to an array is referred to pop the array. You should populate an array using values that have the same data type as the array. Figure 12-3 shows the syntax for declaring and initializing a two-dimensional array in C++. In the syntax, `arrayName` is the name of the array and `dataType` is the type of data the array variables (elements) will store. Recall that each of the elements in an array has the same type. The `NumberOf` and `NumberColumns` integers specify the number of rows and columns, respectively, in the array. You can initialize the elements in a two-dimensional array by entering a `initialValues` section, excluded in braces, for each row in the array. If the array has two rows, then a maximum of two `initialValues` sections. If the array has five rows, then the declaration statement can have a maximum of five `initialValues` sections.
