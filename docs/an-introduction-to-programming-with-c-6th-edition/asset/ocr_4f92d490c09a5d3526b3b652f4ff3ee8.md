You may be wondering why the modified program in Figure 13-10 uses the cin.ignore(100, '\
') statement rather than the simpler cin.ignore(); statement. both statements consume the newline character in the cin object after the amount is entered, there is an advantage to using the cin.ignore(100, '\
') statement in the program. To illustrate, assume that when entering the sales, the user types the numbers 3, 0, 2, and 5, followed by the letter L and then presses the Enter key. The computer stores the four numbers, along with the L and the newline character, in the cin object. This alerts the extraction operation. The extractor removes the four numbers from the cin object and stores them in the sales variable. However, it leaves the L (which cannot be stored in an int variable) and the newline character at this point; the cin object contains two characters.
