# Functions

As learned in Chapter 4, a function is a block of code that performs a task. Every C++ program contains at least one function, which is named main; however, most C++ programs contain many functions. Some of the functions used in a program are built into the C++ language. The code for built-in functions resides in C++ libraries, which are special files that come with the C++ language. Examples of built-in functions with which you are already familiar are main and pow. Other functions are often referred to as program-defined functions, because the function are contained in the program itself rather than a different file. Why would a programmer use more than one function? The reason is to avoid the duplication of code. In instance, as the same task needs to be performed in more than one section of code, it is more efficient for the programmer to write the appropriate code in each of those sections, any section in the program can then call (or invoke) the function to perform the required task. Program-defined functions also allow large and complex programs, which are typically written by a team of programmers, to be broken into small and manageable tasks. Each member of the team is assigned one or more tasks to code as a function.

When each programmer completes his function, all of the functions gather together into one. In other words, program-defined functions allow more than one programmer to work on the program at the same time. Typically, a program's main function is responsible for calling (or invoking) each of the other program-defined functions. Any program-defined function can call any other program-defined or built-in function. All program-defined and built-in functions are categorized as either value-returning or functions that do not return a value. Value-returning functions return a value, whereas void functions do not return a value. You will learn all about value-returning functions in this chapter. Void functions are covered in Chapter 10.

All value-returning functions, whether built-in or program-defined, perform a task and then return precisely one value after the task is completed. The built-in value-returning toupper, for example, temporarily converts characters to uppercase and returns the result. The built-in value-returning pow, on the other hand, returns the result of raising a number to a specified power. In almost all cases, a value-returning function returns its value to the statement from which it was called (invoked). One exception is the main function, which returns its value to the operating system. Typically, the statement that invokes a function assigns its to a variable. However, it may also use the value in a calculation or comparison; In the first part of this chapter, you will learn how to use built-in value-returning functions. In the later part of the chapter, you will learn how to create program-defined value-returning functions. At this point, it is important to point out that functions are one of the more difficult topics for beginning programmers. Therefore, don't be concerned if you don' understand everything right away.
