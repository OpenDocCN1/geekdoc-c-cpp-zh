Some programmers pronounce char as "char" because it is short for character, while others pronounce char as the first syllable of the word character.

As Figure 3-5 shows, bool memory locations can store either the Boolean value true or false. The Boolean values are named in honor of the mathematician George Bool (1815-1864), who invented Boolean algebra. You could use a bool variable in a program to keep track of whether a customer's bill is paid (true) or not paid (false). Memory locations assigned the char data type store one character while string memory locations can store zero or more characters. A character is a letter, a symbol, or a number that will not be used in a calculator. Memory locations assigned either the short or int data type can store integers. An integer is a whole number, which is a number that does not contain a decimal point. Examples of integers include the numbers 0, 45, and -678. The differences between short and int types are the range of numbers needed to store and the amount of memory needed to store the number. Memory locations assigned the float or double data type can store real numbers, which include the numbers 75.67, -345, and 783.569. The differences between the float and double data types are the range of numbers each type can store, the memory needed to store the number. In most of the programs you create in this book, you will use the int data type for memory locations that will store integers and the double data type for memory locations that will store numbers with a decimal point.
