# Logic Errors in Selection Structures

In the next sections, you will observe some of the common logic errors when writing selection structures. Being aware of these errors will help prevent you from making them. In most cases, logic errors in selection structures are a result of the following mistakes: using a compound condition rather than a nested selection structure, reversing the decisions in the outer and nested selection structures, or using an unnecessary nested selection structure. The XYZ Bonus program will be used to demonstrate these logic errors. The company pays each salesperson 8% bonus on his or her sales. However, salespeople having a sales of X receive an additional $150 bonus when sales are greater than or equal to $10,000; otherwise they receive an additional $125 bonus. Notice that the salesperson code determines whether the salesperson receives an additional bonus. If the salesperson is entitled to the additional bonus, the amount of his or her sales determines the appropriate amount. In this case, the decision regarding the salesperson's code is the primary decision, while the decision regarding the sales is the secondary decision. The pseudocode in Figure 6-9 a correct algorithm for the bonus program.

```
1. enter the code and sales
2. calculate the bonus by multiplying the sales by .08
3. if (the code is X)
   if (the sales are greater than or equal to 10000)
      add 150 to the bonus
   else
      add 125 to the bonus
   end if
4. display the bonus
```

> You can also write the selection structure's condition as follows: if (sales are less than 10000). You should reverse the instructions in the true and false paths.
