3
#include <iostream>
using namespace std;
6
int main() {
    //声明变量和命名常量
    int cupsPurchased = 0;
    int platesPurchased = 0;
    double cupPrice = 0.0;
    double platePrice = 0.0;
    double totalCupCost = 0.0;
    double totalPlateCost = 0.0;
    double subtotal = 0.0;
    double totalCost = 0.0;
    const double TAX_RATE = .055;

    //输入项
    cout << "Cup price: ";
    cin >> cupPrice;
    cout << "Plate price: ";
    cin >> platePrice;
    cout << "Cups purchased: ";
    cin >> cupsPurchased;
    cout << "Plates purchased: ";
    cin >> platesPurchased;

    //计算总成本、小计和总费用
    totalCupCost = cupsPurchased * cupPrice;
    totalPlateCost = platesPurchased * platePrice;
    subtotal = totalCupCost + totalPlateCost;
    totalCost = subtotal * TAX_RATE + subtotal;

    //显示总费用
    cout << "Total cost: $" << totalCost << endl;

    system("pause");
    return 0;
} //main 函数结束

# 做出决策

正如你在第 1 章中学到的，所有的计算机程序都是使用三种基本控制结构之一或多种编写的：顺序、选择和重复。你在第 4 章编写的代码中使用了顺序结构。回想一下，在运行时，计算机是顺序处理这些程序中的指令的——换句话说，指令是按顺序出现的。然而，许多情况下，程序需要计算机在选择下一条指令之前做出决策：例如，一个工资程序需要计算机判断员工工作的小时是否大于 40 小时。然后，计算机将选择一条支付加班费的指令。需要计算机做出决策的程序需要使用选择结构（也称为决策结构）。正如你在第 1 章中学到的，选择结构表示需要根据（某些条件）做出一个决策，然后是根据该决策推导出的适当操作。但程序员如何确定一个问题的解决方案是否需要选择结构呢？这个问题的答案是通过研究问题规范。在本章中你将的第一个问题涉及第 1 章中的机械妇女 Robot。问题规范和问题的插图如图 5-1 所示，其中包含了第 1 章的解决方案（伪代码编写），它只需要选择结构。它不需要选择结构，因为将 Robot 从她走廊的初始位置移动到卧室结束不需要做出任何决策。

正如你在第 2 章中学到的，伪代码是程序员在规划解决方案时使用的工具。
