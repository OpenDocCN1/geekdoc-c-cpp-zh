You expose the methods to allow the program to service each method it provides. You hide the variables (data members) to protect their contents from being changed inadvertently by the program. When a program needs to assign data to a private variable, it must use a public member to do so. For example, when using the FormattedDate class in Figure-1, the program would need to use the setState method to assign data to the month, day, and year variables. It is the public member's responsibility to validate the data, if necessary, and then assign data to the private data member (if the data is valid) or reject the data (if the data is not valid). Keep in mind that a program does not have direct access to the private members of a class. Rather, it must access the private members directly, through a public member method.
