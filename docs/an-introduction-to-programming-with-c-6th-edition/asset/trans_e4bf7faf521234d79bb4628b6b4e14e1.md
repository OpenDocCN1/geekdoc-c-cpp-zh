# 控制结构

所有的计算机程序，无论简单还是复杂，都是使用三种基本结构中的一种或多种编写而成的：顺序、选择和重复。这些结构被称为控制结构或逻辑结构，因为它们控制着程序逻辑的流。你写的每一个程序中都会使用顺序结构。在大多数程序中，你将使用选择和重复结构。本章将介绍这三种控制结构。它还向你介绍了一个机器人 Robin，它将说明这些控制结构。此外介绍了关于每个结构的更详细信息，以及如何使用 C++ 语言实现这些结构。

# 顺序结构

你对顺序结构很熟悉，因为每当你按照一组从开始到结束的顺序指令时，你都会使用它。例如，一个饼干配方就是顺序结构的一个很好的例子。为了获得成品（可吃的饼干），你需要按照顺序遵循每条配方，从第一条指令开始，到最后一条指令结束。同样，计算机中的顺序结构引导计算机按照程序中列出的顺序一个接一个处理指令。你将在每个程序中发现顺序结构。

你可以通过为机器人 Robin 编程来观察顺序结构是如何工作的。像计算机一样，Robin 有有限的指令集。换句话说，Robin 只理解特定数量的指令，也称为命令。现在，你将只使用 Robin 指令集中的两个命令：向前走和打开卧室门。当被要求向前走时，Robin 向迈出完整的一步。换句话说，她移动右脚走一步，然后移动左脚与右脚会合。在第一个例子中，Robin 站在走廊里，面对两步之远的门。你的任务是仅使用 Robin 能理解的命令来编写指令，引导 Robin 进入她的卧室。1-1 显示了问题规范以及该问题的插图。它还显示了让 Robin 进入卧室的指令。图中显示的四条指令被称为算法，它是一组完成任务的逐步步进的指令。为了让 Robin 进入卧室，她必须按照顺序遵循指令——换句话说，即顺序。

# 选择结构

与顺序结构一样，你已经对选择结构非常熟悉，选择表示需要根据（某些条件）做出决定，然后根据该决定采取适当的行动。每当你开车经过路道平口时，你都会使用选择结构。你的决定以及适当的行动取决于平口信号（闪烁的灯光和铃声）是开启还是关闭。如果平口信号开启，你在跨越铁路轨道之前停止；否则，你谨慎地通过铁路。当用于计算机程序时，选择结构会提醒计算机需要做出决定，并根据该决定的结果采取适当的行动。

为了观察选择结构是如何工作的，我们对图 1-1 所示的问题规范进行了微调。Robin 的卧室门可能是关着的，也可能是开着的。根据这一微调的结果，原始算法需要做什么调整？原始算法的前两条指令将 Robin 定位于卧室门；Robin 仍然需要遵循这些指令。第三条指令告诉 Robin 打开卧室门。这条指令对于原始问题规范是正确的，规范说明卧室门是关着的。但在修改后的问题规范中，门的状态未知，它可能是关的也可能是开的。因此，Robin 需要做出决定，然后根据结果采取适当的行动。具体来说，Robin 需要确定卧室门是否关闭，并且仅在需要打开时才打开。要编写完成当前任务的算法，你需要使用 Robin 指令集中的两个额外指令：如果（卧室门是关着的）并结束。`if (the bedroom door is closed)` 指令允许 Robin 对卧室门的状态做出决定，它代表了一个选择结构。括号部分是条件，规定了 Robin 必须做出的决定。注意该条件会导致真或假的答案：要么卧室是关着的（真），要么没关（假）。`end if` 指令表示选择结构的结束。原始算法中的最后一条指令让 Robin 进入卧室内部的一步处；Robin 仍然需要遵循指令。1-2 显示了修改后的问题规范和修改后的算法。注意，“打开卧室门”指令在选择结构内部缩进了。这种缩进表示该指令仅在卧室关闭时才被遵循——换句话说，只有当条件的结果评估为真时，被称为该结构的路径。虽然 1-2 中的真路径只包含一条指令，但它可以包含许多条指令。
