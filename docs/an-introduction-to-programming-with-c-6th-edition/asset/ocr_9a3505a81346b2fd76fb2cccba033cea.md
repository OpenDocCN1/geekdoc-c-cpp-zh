# Multiple-Alternative Selection Structures

De-checking the code in Figure 6-2 will help you understand how the switch statement is processed by the computer. You will de-check the code using the following three letters: B, D, and x. First, the code declares a char variable named grade. It prompts the user to enter a grade and assigns it to the user's response—in this case, the letter—to the grade variable. Next, the grade = toupper(grade); statement assigns the letter B to the grade variable. The switch statement is processed next; now the grade variable is used as the statement's selector. When the switch statement, the computer compares the value of the selectorExpression with the value listed in the first. If a match is found, the computer processes the instructions in that case clause; unless a break or the switch statement's closing brace; the computer then skips the instruction following the closing brace. In this case, the first case compares the selectorExpression ('B') with the value listed in the first case ('A'). 'B' does not match 'A', so the computer compares the selectorExpression ('B') with the value listed in the second case ('B'). In this case, 'B' matches 'B', so the computer processes the instructions in the second case clause. The first statement in the second case displays the message "Above Average" on the screen. Next, the statement, break; tells the computer to skip the remaining instructions in the switch statement and continue processing with instruction following the switch statement's closing brace.

Now use the letter to de-check the code. The code declares a named variable grade. It prompts the user to enter a grade and assigns the user's response—in this case, the letter—D to the variable. The grade = toupper(grade); statement also assigns the letter D to the variable. The switch statement is processed next. When the switch statement, the computer compares the value of the selectorExpression ('D') with the value listed in the first case ('A'). 'D' does not match 'A', so the computer compares the selectorExpression ('D') with the value listed in the second case ('B'). 'D' does not match 'B', so the computer compares the selectorExpression ('D') with the value listed in the third case ('C'). 'D' does not match 'C', so the computer compares the selectorExpression ('D') with the value listed in the fourth case ('D'); however, notice that there is no statement immediately below the 'D': clause. So, what if anything happens when grade is D? When the value of the selectorExpression matches in a case clause, the computer processes the instructions contained in that clause until it encounters a break or the switch statement's closing brace. In this case, finding any instructions in the case 'D': clause; the computer continues processing with the instructions in the next clause, which is the case 'F': clause. The first instruction in the case 'F': displays the message "Below Average" which is the correct message to display. The second instruction tells the computer to break out of the switch statement. In other words, the cout << "Below Average"; and break; statements are processed when the grade is either D or F. Then the computer skips to instruction following the switch statement's closing brace.
