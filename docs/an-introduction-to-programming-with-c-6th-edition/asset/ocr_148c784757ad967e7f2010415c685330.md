# Exercises

+   26. In this exercise, you modify the program from Computer Exercise 25. If necessary, create a new project named Intermediate26 Project. Create a new source file named Intermediate26.cpp. Copy the C++ instructions from the Intermediate25.cpp file into Intermediate26.cpp. Change the filename in the first comment to Intermediate26.cpp. Modify the program so that it asks the user to enter a number from 1 to 10. When the user enters number 1, the program should update only the first price in the array. When the user enters the number 2, the program should update only the second price in the array, and so on. Use a loop that prompting the user when he or she enters a number that is either less than equal to 0 or greater than 10. Save and run the program. Increase the price by 10%. Next, increase the tenth price by 2%. Finally, decrease the first price by 10%.
