Figure 9-18 shows the complete code for the random numbers addition program. Changes made to the original program's code (shown earlier in Figure 9-11) are shaded. The program contains a function prototype on Line 32. The prototype alerts the computer that the getRandomNumber function is defined somewhere below the main function. In addition, the function definition appears on Lines 55 through 61. Some programmers use a comment (such as /** definition**) to separate the function from the main function as shown on Line 54; however, this is not a requirement. The statement claims that when the computer processes the num1 = getRandomNumber(); it temporarily lays the main function in order to process the getRandomNumber function. The code's header marks the beginning of the function. The statements in the function body are processed first. The first statement creates and initializes the randInteger variable. The second statement generates a random integer from 0 to 10 and then adds the random integer to the variable. The third (and last) statement returns the value stored in the randInteger variable to the statement called.
