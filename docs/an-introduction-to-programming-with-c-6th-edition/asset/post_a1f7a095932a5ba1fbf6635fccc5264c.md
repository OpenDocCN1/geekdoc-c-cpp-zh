The assignment on Line 21 calls the getRectangleArea function, passing it two arguments: the double length variable and the double width variable. Unless specified otherwise, variables in C++ are passed by value, which means that only the contents of the variables are passed to the function. In this case, the computer passes the numbers 7.0 and 10.0 to the getRectangleArea function. At this point the computer leaves the main function to access the getRectangleArea code with the function header on Line 29 in the program. The function header contains two parameters. The formal parameters tell the computer to reserve two memory locations: a double variable named len and a double variable named wid. After reserving the len and wid variables, the computer stores the values passed to the function—in this case, the numbers 7.0 and 10.0–in the variables. ## The Scope and Lifetime of a Variable

A variable's scope indicates where the program variable can be used, and its lifetime indicates how long the variable remains in the computer's internal memory. Although variables can have either local or global scope, most of the variables used in a program will have local because fewer unintentional errors occur in programs when the variables are declared using the minimum scope, which is usually local. A variable's scope and lifetime are determined by where you declare the variable. Programs declared within a function, and that appear as variables. Local variables are used only by the function in which they are declared or in whose parameterList. Local variables remain in the computer's internal memory until the function ends, which is when the closing brace. Global variables are declared outside any function, and they remain in memory until the program ends. Unlike a local variable, a global variable is accessible by all functions. It is better to avoid using global variables. In the area calculator shown in Figure 9-22, the length, width and area variables are declared on Lines 12 through 14 in the main function. The getRectangleArea function is not aware of the existence of these variables. Therefore, you will need to pass the values to the function. This explains why len and wid variables are removed from memory after the function ends. The computer waits until the main function ends before it removes the length, width, and area variables.
