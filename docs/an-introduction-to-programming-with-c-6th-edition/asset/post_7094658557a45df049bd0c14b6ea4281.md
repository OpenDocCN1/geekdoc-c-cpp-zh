# Creating File Objects

In previous chapters, you used stream objects to perform standard input and output operations in a program. The standard input stream object (cin) refers to the computer keyboard, and the standard output stream object (cout) refers to the computer screen. As you already know, a program that uses the cin and cout objects must contain the #include <iostream> directive, which tells the compiler to include the contents of the iostream file in the program. The ifstream and ofstream define the classes, respectively. You do not have to create the cin and cout objects in a program, because C++ creates the file object in the stream file for you. Objects are also used to perform input and output operations in C++. However, unlike the standard cin and cout objects, the input and output file objects must be created by the programmer. To create a file object in a program, the program must contain the #include <fstream> directive, which tells the compiler to include the contents of the fstream file in the program. The fstream file contains the definitions of the ifstream (input file) and ofstream (output file stream) classes, which allow you to create input and output file objects. Figure 14-2 shows the syntax for creating file objects. In each syntax, fileObject is the name of the file object you want to create. Examples 1 and 2 create input file objects named inputFile and inFile. Examples 3 and 4 create output file objects Notice the names of the input file objects in the examples begin with the two letters in, whereas the names of the output file objects begin with the three letters out. The C++ syntax does not require you to begin file objects with either in or out, using this naming convention helps to distinguish your input file objects from your output file objects.

# HOW TO Create Input and Output File Objects

To create an input file object: ifstream fileObject;
To create an output file object: ofstream fileObject;

-   Example 2

-   Example 3

# Opening a Sequential Access File

Use a program's input and output files, with the C++ open function, to open access files on your computer's disk. Figure 14-3 shows the open function syntax and describes the modes most commonly used to open a sequential file. In the syntax, fileObject is the name of either an ifstream file object or an ofstream file object, and fileName is the name of the file you want to open. Although it is not a requirement, many programs use "txt" (short for "text") extension when naming sequential access files. The open function opens the file name specified in the fileName argument and associates the file with the fileObject. When a subsequent statement in the program needs to read from or write to the file, the fileObject is used. The open function's argument can be either a string constant or a string value. In addition to the file, the fileName argument can also contain an optional path. If the fileName argument does not contain a path, the computer assumes that the file is located in the same folder as the program file. (See the second TIP on this page.) The optional mode indicates how the file is opened. Figure 14-3 uses the ios::in mode to open a file for input, which allows the computer to read the data stored in the file. The ios::out and ios::app modes are used to open output files. Both of these modes allow the computer to open output files.

# HOW TO Open a Sequential Access File

Syntax

fileObject.open(fileName, mode);

| mode | Description |
| --- | --- |
| ios:: | Used with an ifstream object. Opens the file for input, which allows the computer to read the file. This is the default mode for input files. |
| ios:: | Used with an ofstream object. Opens the file for output, which creates a new, empty file to which data can be written. If the file already exists, the computer erases the file's contents. This is the default mode for output files. |
| ios::app | Used with an ofstream object. Opens the file for append, which allows the computer to write data to the end of the file. If the file does not exist, the computer creates the file. |

Example 1
infile.open("payroll.txt", ios::);
or
finfile.open("payroll.txt");
opens the payroll.txt file for input

Example 2
outfile.open("employ.txt", ios::);
for
outfile.open("employ.txt");
opens the employ.txt file for output

Example 3
soutales.open("F:\Cpp6\Chap1\sales.txt", ios::app);
opens the sales.txt file for append

The computer uses a file pointer to keep track of the next character either to read from or write to a file. When you open a file for input, the computer positions the file pointer at the beginning of the file, immediately before the first character. When you open a file for output, the computer also positions the file pointer at the beginning of the file, but recall that the file is empty. (As you learned earlier, when you open a file for output, the computer creates a new, empty file or erases the contents of an existing file). However, when you open a file for append, the computer positions the file pointer immediately after the last character in the file.
