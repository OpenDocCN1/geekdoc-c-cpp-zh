# Problem specification

Create a program that allows the user to enter a rectangle's length and width (in feet). The program should calculate and display the rectangle's area in square feet.

```
main function
Input               Processing               Output
length (feet)      Processing items: none    area (square feet)
width (feet)

Algorithm:
1. enter the length and width
2. call the getArea function to
   calculate the area; pass the length and width
3. display the area
```

```
getRectangleArea function
Input               Processing               Output
length (feet)      Processing items: none    area (square feet)
width (feet)

Algorithm:
1. return the area, which is the result of
   multiplying the length by the width
```
