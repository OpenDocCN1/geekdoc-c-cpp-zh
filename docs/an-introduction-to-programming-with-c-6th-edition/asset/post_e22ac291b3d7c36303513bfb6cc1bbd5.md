# Control Structures

All computer programs, no matter how simple or complex, are written using one or more of three basic structures: sequence, selection, and repetition. These structures are called control structures or logic structures, because they control the flow of a program's logic. You will use the sequence in every program you write. In most programs, you will use the selection and repetition structures. This chapter gives an introduction to the three control structures. It also introduces you to a robot Robin, who will illustrate the control structures. More detailed information about each structure, as well as how to implement these structures using C++ language.

# The Sequence Structure

You are familiar with the sequence structure, because you use it each time you follow a set of directions, in order, from beginning to end. A cookie recipe, for instance, provides a good example of the sequence structure. To get the finished product (edible cookies), you need to follow each recipe in order, beginning with the first instruction and ending with the last. Likewise, the sequence structure in a computer directs the computer to process instructions, one after another, in the order listed in the program. You will find the sequence structure in every program.

You can observe how the sequence structure works by programming Robin, the robot. Like a computer, Robin has a limited instruction set. In other words, Robin understands only a specific number of instructions, also called commands. For now, you will use only two of the commands from Robin's instruction: walk forward and open the bedroom door. When told to walk forward, Robin takes one complete step forward. In other words, she moves her right foot one step and then moves her left foot to meet her right foot. For the first example, Robin is standing in her hallway facing the door two steps away. Your task is to write the instructions, using only the commands that Robin understands, direct Robin to enter her bedroom. 1-1 shows the problem specification along with an illustration of the problem. It also shows the instructions that will get Robin inside her bedroom. The four instructions shown in the figure are called an algorithm, which is a set of step-by-step instructions that accomplish a task. For Robin to enter her bedroom, she must follow the instructions in order—in other words, sequence.

# The Selection Structure

As with the sequence structure, you are already familiar with the selection structure, the selection indicates that a decision (based on some condition) needs to be made, followed by an appropriate action derived from that decision. Use the selection structure every time you drive your car and a railroad crossing. Your decision, as well as the appropriate action, is based on whether the crossing signals (flashing lights and ringing bells) are on or off. If the crossing signals are on, you stop your car before crossing the railroad tracks; otherwise, you proceed with caution over the railroad. When used in a computer program, the selection structure alerts the computer that a decision needs to be made, and it provides the appropriate action to take based on result of that decision.

To observe how the selection structure works, we make a slight change to the problem specification shown in Figure 1-1. Robin’s bedroom door may or not be closed. What needs to be made to the original algorithm from result of this minor modification? The first two instructions in the original algorithm position Robin in her bedroom door; Robin still need to follow those. The third instruction tells Robin to open the bedroom door. That instruction was correct for the original problem specification, which states that the bedroom door is closed. However, in the modified problem specification, which states the status of the door unknown, it could be closed or it could be open. As a result, Robin will need to make a decision and then take the appropriate action based on the result. More specifically, Robin will need to determine whether the bedroom door is closed and open the door only if it needs to be opened. To write an algorithm to accomplish the current task, you need use two additional instructions from Robin’s instruction set: if (the bedroom door is closed) and end it. If (the bedroom door is closed) instruction allows Robin to make a decision about the status of the bedroom door, and it representing a selection structure. The portion within the parentheses is the condition and specifies the decision that Robin must make. Notice that the condition results in a true or false answer: either the bedroom is closed (true) or it's not closed (false). The end if instruction denotes the end of a selection structure. The last instruction in the original algorithm positions Robin one step inside bedroom; Robin will still need to follow instruction. 1-2 shows the modified problem specification with the modified algorithm. Notice that the open bedroom door instruction is indented within the selection structure. Indenting in this manner indicates that the instruction should be followed only when the bedroom is closed—in other words, only when the condition results in answer condition evaluates to true are referred to as the structure’s path. Although the true path in 1-2 includes only one instruction, it can include many instructions.

1-3 shows another example of the selection structure. In this example, Robin is holding either a red or yellow balloon, and she is facing two boxes that are located five steps away from her. One of the boxes is yellow, and the other is red. Your task is to instruct Robin to drop the balloon into the appropriate box: the yellow balloon in the yellow box, and the red balloon in the red box. To write an algorithm to accomplish the task, you need to use four additional instructions from Robin’s instruction set: if (the balloon is red), else, drop the balloon in the red box, and drop the balloon in the yellow box. The additional instructions allow Robin to make a decision about the color of the balloon she is holding and take the appropriate action based on that. 1-3 shows the problem specification along with an illustration of the problem. It also shows an algorithm that solves the problem. Unlike the structure from 1-2, which requires Robin to take a specific action when the structure’s condition evaluates to true, the selection structure 1-3 requires her to take one action when the condition evaluates to true, a different action when it evaluates to false. In other words, the selection structure in 1-3 has both a true path and a false path. The else instruction marks the beginning of the false path instructions.
