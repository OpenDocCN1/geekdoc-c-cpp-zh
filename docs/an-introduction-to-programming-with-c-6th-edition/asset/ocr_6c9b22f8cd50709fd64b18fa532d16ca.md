You initialize the random number generator in each program that it is used. Otherwise, it will generate the same series of numbers each time the program is executed. Typically, the initialization task is performed at the beginning of the program. You initialize the random number generator using the **srand** function. *Like* the **rand** function, the **srand** function is a built-in C++ function. *However*, unlike the **rand** function is a void function, which means it does not return a value. You will learn more about functions in Chapter 10. Figure 9-9 shows the syntax of the **srand** function and includes examples of using the function. The *actual argument* in the syntax represents the starting point for the random number generator. The computer uses the starting point (or seed) in the mathematical algorithm it employs when selecting the random numbers. If you use the same seed, as shown in Example 1 Figure 9-7. *However*, a more common way to initialize the random number generator is to use the C++ **time function**; this is shown in Examples 2 and 3. The **time function** returns the current time (according to your computer system's clock) as elapsed seconds since midnight on January 1, 1970. However, you will need to use a type cast to convert the function's return value to an integer, as shown in Examples 2 and 3. In both examples, the **time function** is passed as one argument: the **srand** function ensures the random generator is initialized with a unique integer each time the program is executed. This unique integer will produce a sequence of random numbers. By using the **time function** in program, the program must contain the **#include <ctime>** directive.
