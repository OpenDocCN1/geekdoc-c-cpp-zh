The programmer uses a #include directive to include the contents of the header file in the program. In the modified Sweets Unlimited, the #include "Salesperson.h" directive (which is stated in Figure-8) tells the compiler to merge the contents of the Salesperson.h file with the contents of the current program. In other words, it calls the compiler to include the Salesperson class definition in the current program. Notice that the header filename is enclosed in quotation marks. The quotation indicates that the header file is located in the same folder as the program file.

The angle bracket-(<>) in the other directives in Figure-8 indicates that those are defined in the folder that contains the C++ Standard header files.

```
// Salesperson.h
//Created/revised by <name> on <current date>

#include <string>
using namespace std;

//declaration section
class Salesperson
{
public:
    string name;
    double sales;
    double bonus;
};
```
