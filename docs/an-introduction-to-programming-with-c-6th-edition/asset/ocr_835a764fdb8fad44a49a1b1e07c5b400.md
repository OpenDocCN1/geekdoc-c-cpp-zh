# CHAPTER 6 More on the Selection Structure

To verify your accuracy, you will desk-check the algorithm from Figure 6-9 three times. Figure 6-10 shows the values you will use for the desk-checks and includes the manually calculated results.

| Code | Sales | Bonus |
| X | $15000 | $1350 |
| X | $9000 | $845 |
| A | $13000 | $1040 |

Figure 6-10 Test data and manually calculated results

The first instruction in the algorithm shown in Figure 6-9 is to enter the code and sales. For the first desk-check, the code and sales are X and 15000, respectively. The second instruction is to calculate the bonus by multiplying the sales by .08; the answer is 1200. Figure 6-11 shows the current status of the desk-check.

| sales | bonus |
| X | 15000 | 1200 |

Figure 6-11 Current status of the desk-check table

Next, the outer selection structure in the algorithm determines whether the salesperson's code is X. It is, so the nested selection structure checks whether the sales are greater than or equal to 10000. The sales are greater than 10000, so the nested structure's true path adds 125 to the bonus; the answer is 1350. After the bonus is calculated, both selection structure end. The last instruction in the algorithm displays the bonus on the screen. Figure 6-12 shows the desk-check table after completing the first desk-check. The 1350 in the bonus column agrees with the manual calculation shown earlier in Figure 6-10.

Using the second set of test data, the user enters X and 9000 as the sales. The second instruction in the algorithm calculates the bonus by multiplying the sales by .08; the answer is 720. The outer selection structure determines whether the salesperson's code is X. It is, so the nested selection structure checks whether the sales are greater than or equal to 10000. The sales are not greater or equal to 10000, so the nested structure's false path adds 125 to the bonus; the answer is 845. After the bonus is calculated, both selection structure end. The last instruction in the algorithm displays the bonus on the screen. Figure 6-13 shows the desk-check table after completing the second desk-check. The 845 in the bonus column agrees with the manual calculation shown earlier in Figure 6-10.
