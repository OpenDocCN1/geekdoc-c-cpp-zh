# Parallel One-Dimensional Arrays

11-52 shows the problem specification, IPO chart information, and C++ instructions for the motorcycle club program. The program displays the annual fee with the membership type entered by the user. Note that the program uses two-dimensional arrays: a char array named type and an int named fees. The types array stores the membership types, and the fees array stores the annual fees. The two arrays are referred to as parallel because their elements are related by their position.

The members of a motorcycle club are required to pay an annual fee based on their membership type. Create a program that displays a member's annual fee, as well as their type.

| Membership type | fee |
| --- | --- |
| A | 100 |
| B | 110 |
| C | 125 |
| D | 150 |
| E | 200 |

# Algorithm

1. enter the membership type (A, B, C, D or E):
```
cout << "Membership type A, B, C, D or E: ";
cin >> memberType;
memberType = toupper(memberType);
```
2. repeat while (the subscript counter is less than 5 and the membership type has not been located in the array):
```
while (sub < 5 && types[sub] != memberType)
sub += 1;
```
3. if (the subscript counter is less than 5)
```
if (sub < 5)
    cout << "Annual fee for membership type " << types[sub]
    << "$" << fees[sub] << endl;
else
    cout << "Invalid membership type" << endl;
```
