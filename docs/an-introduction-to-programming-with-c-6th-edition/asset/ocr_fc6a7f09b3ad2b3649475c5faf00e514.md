Figure-21 Desk-check table and output after the nested loop cout statement is processed the fifth time

The value stored in the numAsterisks variable is updated once again; this time, the result is 6. The computer checks whether the variable's value is less than 6. It is not, so the nested loop ends and the numAsterisks variable is removed from the computer's internal memory. Continuing with the first statement following the end of the nested loop. In this case, the cout << end; statement positions the cursor on the next line on the computer screen. The cout << end; statement is the last statement in the body of the outer loop. Therefore, after processing the statement, the computer returns to the condition argument. This update (line += 1) tells the computer to add the number 1 to the value stored in the line; the result is 2. The condition (line < 4) directs the computer to check whether the variable's value is less than 4. It is, so the instructions in the body of the outer loop are processed again. The first instruction is the nested loop for clause, while initialization and condition arguments tell the computer to create the numAsterisks variable and initialize it to the number 1, and then check whether its value is less than 6. At this point, the variable's value is less than 6, so the cout << '*'; in the nested loop is processed. That statement displays an asterisk on the second line on the computer screen.
