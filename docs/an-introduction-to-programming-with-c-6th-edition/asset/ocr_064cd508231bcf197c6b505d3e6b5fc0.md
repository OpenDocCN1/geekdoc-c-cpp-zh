Some programmers use the hexagon to represent any counter-loop, even those coded with the while statement.

Many programmers use a hexagon, which is a six-sided figure, to represent the for clause in a flowchart. The hexagon contains four items, as shown in Figure 7-39. The four items are the name of the counter (rate), the variable's initial value (1), the value used to update the variable (.05), and the last value for which the condition will evaluate to .25. Notice that a less or equal sign (<=) precedes the .25 in the hexagon in Figure 7-39. The <= indicates that the loop body instructions will be processed as long as the rate variable's value is less than equal to .25.
