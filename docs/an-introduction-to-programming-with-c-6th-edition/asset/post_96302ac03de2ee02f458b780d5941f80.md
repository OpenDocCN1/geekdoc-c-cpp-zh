# The Moonbucks Coffee Program—Calculating a Total and Average

11-21 shows the problem specification, IPO chart information, and C++ instructions for the Moonbucks Coffee program. (The flowchart for this program is contained in the Ch1Flowcharts.pdf file, which is located in C6Chap1 folder). The program displays the total and average of pounds used in a 12-month period. Notice that the program stores the monthly usage in an 12-element double array named pounds. It also uses a program-defined value-returning function to calculate the total usage for the year. The getTotal function does this by adding together each monthly value stored in the pounds array, which is passed to the function when it is invoked. The getTotal function returns the sum to the main function, where it is used to calculate the average usage.

### Problem specification

The store manager at Moonbucks Coffee wants a program that displays both the total and average of pounds used during a 12-month period. Last year, the pounds of coffee used each month were as follows: 400.5, 475.5, 336.5, 457, 325, 220.5, 276, 320.5, 400.5, 415. The program will use two value-returning functions: main and getTotal. The getTotal function will calculate the total number of pounds used.

```

double pounds[12] = {400.5, 450.0, 475.5, 336.5, 457.0, 325.0, 220.5, 276.0, 300.0, 325.0, 415.0};
```

Processing

Output

```

double total = 0.0;
double average = 0.0;
```

Algorithm

- 1. call the getTotal function to calculate the total pounds, pass the function the pounds and the number of elements in the array
- 2. calculate the average pounds by dividing the total pounds by the number of elements
- 3. display the total pounds and average pounds

```
total = getTotal(pounds, 12);
average = total / 12;
```

```cpp
cout << "Total pounds: " << total << endl;
cout << "Average pounds: " << average << endl;
```

11-22 shows the Moonbucks Coffee program. The statement on Lines 15 through 17 in the **main** function declares the 12-double pounds array. It uses the values provided in the problem specification to initialize the array. The statement on Lines 19 and 20 declare two **double** variables named **total** and **average**. Next, the assignment statement on Line 23 calls the **getTotal** function, passing the pounds array and the number of elements in the array. Recall that when an array is passed to a function, the computer passes only the address of the first element. At this point, the computer temporarily leaves the main function to process the getTotal function code, beginning with the function header; the computer locates the array in memory and assigns the formal parameter's name—in this case, poundsUsed—to each element. As a result, each array element has two numbers. The first element, for example, is pounds[0] in the **main** function poundsUsed[0] in the **getTotal** function. After processing the getTotal function's header, the computer processes the statements within the function body. Those statements use a **for** loop, along with an accumulator named **total**, to add each value contained in the poundsUsed array. The sum of these values represents the total number of pounds of coffee. The **getTotal** function's return statement returns the total number of pounds to the assignment statement on Line 23 in the **main** function. At that point, the getTotal function ends and the computer removes the poundsUsed array from the elements memory. It removes the numElements and totalUsed variables from internal memory. The assignment statement on Line 23 assigns the total number of pounds to the main's total variable. Next, the assignment statement on Line 24 calculates the average number
