Rather than using two overloaded calcPay class, for example, you could use a method named calcSalariedGross to calculate and return the gross pay for a salaried employee and use a method named calcHourlyGross to calculate and return the gross pay for an hourly employee. The advantage of overloading the calcGross method is that you need to remember the name of only one method.

```
double GrossPay::calcGross(double yearSalary)
{
    return yearSalary / 24;
}//end of calcGross method

double GrossPay::calcGross(double h, double r)
{
    return h * r;
}//end of calcGross method
```
