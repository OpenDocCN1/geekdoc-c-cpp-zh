# CHAPTER 5 The Selection Structure

# Making Decisions

As you learned in Chapter 1, all computer programs are written using one or more of three basic control structures: sequence, selection, and repetition. You used the sequence structure in the programs you coded in Chapter 4. Recalling that during runtime, the computer processed the instructions in those programs sequentially—in other words, the instructions appeared in the order. Many times, however, a program will need the computer to make a decision before selecting the next instruction: A payroll program, for example, has the computer determine the number of hours an employee worked is greater than 40. The computer then would select either an instruction that pay overtime. Programs that need the computer to make a decision require the use of the selection structure (also called the decision structure). As you learned in Chapter 1, the selection structure indicates that a decision (based on some condition) needs to be made, followed by an appropriate action derived from that. But how does a programmer determine whether a problem's solution requires a selection structure? The answer to this question is by studying the problem specification. The first problem you will examine in chapter involves Robot, the mechanical woman from Chapter 1. The problem specification and an illustration of the problem are shown in Figure 5-1 with the solution from Chapter 1, which is written in pseudocode, requires only the selection structure. It does not need a selection structure because no decisions need to be made to get Robot from her initial location in the hallway ending in the bedroom.
