In this lab, you will plan and create an algorithm that displays the total amount a student owes for a semester. The problem specification is shown in Figure 4-24.

The number of semester hours will be entered by the user, whereas the problem specification indicates that the fee per semester hour is $100, and the room and board is $2000. # CHAPTER 4 Completing the Problem-Solving Process

As you know, most algorithms begin with an instruction to enter the input items into the computer, followed by instructions that process the input items, typically including the items in one or more calculations. Most algorithms end with one or more instructions that display, print, or store the output items. Figure 4-26 shows the completed IPO chart for the Hoover College.

| Input | Processing | Output |
|---|---|---|
| hours enrolled | Processing items: none | total owed |
| fee per hour (100) | | |
| room 5 board fee (2000) | | |

- Algorithm: 
  1. enter the hours enrolled
  2. calculate the total owed by multiplying the hours enrolled by the fee hour and adding the room & board fee to the result
  3. display the total owed

Figure 4-26 Completed IPO chart for the Hoover College problem

After completing the IPO chart, you move on to the third step in the problem-solving process, which is to desk-check the algorithm. You will desk-check the Hoover College twice, using 9 and 11 as the number of hours enrolled. Manually calculating the total owed results in $2900 for the first desk-check and $3100 for the second desk-check. Figure 4-27 shows the completed desk-check table. Notice that the amounts in the total column agree with the results of manual calculations.

| hours enrolled | fee per hour | room 5 board fee | total owed |
|---|---|---|---|
| 9 | 100 | 2000 | 2900 |
| 11 | 100 | 2000 | 3100 |

Figure 4-27 Completed desk-check table for the Hoover College algorithm

The fourth step in the problem-solving process is to code the algorithm into a program. By declaring memory locations that will store the values of the input, processing (if any), and output items. The Hoover College program will need four memory locations to store the values of the hours enrolled, fee per hour, room board fee, and total owed. The hours enrolled and total owed values should be stored in variables, because the user should be allowed to change the hours enrolled, which will change the total value, while the program is running. The fee per hour and board fee, however, will be stored in named constants, because those values should not change during runtime. The variables and named constants will store integers, so you will use the int data type for each.
