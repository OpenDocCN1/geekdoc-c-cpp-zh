```cpp
 //Lab12-1.cpp calculates the total sales

#include <iostream>
using namespace std;

int main() {
    //declare arrays and variable
    int company[2][6] = {{12000, 45000, 32000,
                          67000, 24000, 55000},
                          10000, 56000, 42000,
                          23000, 12000, 34000}};
    int companySales = 0; //accumulator

    //accumulate sales
    for (int location = 0; location < 2; location += 1) {
        for (int month = 0; month < 6; month += 1) {
            companySales += company[location][month];
        }
    }
    //display total sales
    cout << "Company sales: $" << companySales << endl;
    system("pause");
    return 0;
}
```

# LAB 12-2 Plan and Create

In this lab, you will plan and create an algorithm for Falcon Incorporated. The problem specification, IPO chart information, and C++ instructions are shown in Figure 12-24. The program displays a shipping charge based on the number of items ordered, which is entered by the user. The problem specification shows three shipping charges along with their minimum and maximum orders. Notice that the maximum order amounts are stored in the first column of the two-dimensional shipcharges array, while their corresponding shipping charges are stored in the second column. To find the appropriate shipping charge, you search the first column for the number of items ordered, beginning with the first row. You continue searching the first column as long as there are left to search and the number of items ordered is greater than the value in the first column. You stop either when there are no more rows to search or when the number of items ordered is less or equal to the value in the first column. For example, if the number of items ordered is 75, the value you would look at in the array is 50. The number of items ordered (75) is greater than 50, so you continue searching the value in the second row (100). The number 100 is greater than the number of items ordered (75). The appropriate shipping charge is located in the same row—in this, the second row—but in the second column. The appropriate shipping charge is $10.

```cpp
// Passing a Two-Dimensional Array to a Function
//Lab12-2.cpp displays the shipping charge
// #Created/revised by <your name> on <current date>

#include <iostream>
using namespace std;

int main() {
    //declare arrays and variables
    int shipCharges[3][2] = {{50, 20}, {100}, {999999, 0}};
    int numOrdered = 0;
    int rowSub = 0;

    //enter the number ordered
    cout << "Number ordered ";
    cout << "negative number or 0 to end":
    cin >> numOrdered;

    while (numOrdered > 0 && numOrdered <= 999999) {
        assign = 0 to the row subscript counter to ensure the search begins in the first row
        rowSub = 0;
        //search array
        while (rowSub < 3 && numOrdered > shipCharges[rowSub][0]) {
            // add 1 to the row subscript counter to continue the search in the next row
            rowSub += 1;
        }
        //end while
        //display the shipping charge
        cout << "Shipping charge for a quantity of $" << shipCharges[rowSub][1] << endl;

        //enter the number ordered
        cout << "Number ordered ";
        cout << "negative number or 0 to end":
        cin >> numOrdered;
    } //end while

    system("pause"); //tool may not require this statement
    return 0;
} //end of main
```
