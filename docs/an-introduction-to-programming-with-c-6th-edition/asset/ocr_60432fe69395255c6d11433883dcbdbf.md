Note that the program uses two-dimensional arrays: a char array named type and an int named fees. The types array stores the five membership types, and the fees array stores the annual fees associated with those types. The first element in each array pertains to membership type A; the types array contains the letter A, and the fees array contains the corresponding fee (100).
