# Instantiating an Object and Referring to a Public Member

# HOW TO Refer to a Public Member of an Object's Class

Syntax
objectName.publicMember; semicolon

Example 1
reportDate.getFormattedDate();
refers to the reportDate's getFormattedDate method, which is a public method of the FormattedDate class (shown earlier in Figure F-1)

Example 2
reportDate.setDate(monthNum, dayNum, yearNum);
refers to the reportDate's setDate, which is a public method of the FormattedDate class (shown earlier in Figure F-1)
