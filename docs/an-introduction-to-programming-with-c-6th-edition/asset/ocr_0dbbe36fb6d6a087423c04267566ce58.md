The ideal abstraction is to expose using only those attributes and behaviors that are necessary to use the object and to hide everything.

Another OOP term, inheritance, refers to the fact that you can create one class from another. The new class, the derived class, inherits the attributes and behaviors of the original class, which the base class. For example, the Valenti company might create a blueprint of the Model VI watch from the blueprint of the Model VI watch (the derived class) will inherit all of the attributes and behaviors of the Model VI blueprint (the base class), but then it can be modified to include an additional feature, such as an alarm.

Finally, you will also hear the term "polymorphism" in OOP discussions. Polymorphism is the object-oriented feature that allows the same instruction to be carried out depending on the object. For example, you open a door, you an envelope, a jar, and your eyes. Similarly, you can set the time, date, and an alarm on a Valenti watch. While the meaning of the verbs "open" and "set" are different in each case, you can understand instruction because the combination of the verb and the object makes the instruction class.
