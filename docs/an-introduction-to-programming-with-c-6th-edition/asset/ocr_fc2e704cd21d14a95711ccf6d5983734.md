Figure 11-28 shows the entire hourly rate program. The declaration statement on Lines 12 and 13 creates the six-element hourlyRates array and initializes it with the hourly rates in the provided specification. The rate associated with pay code 1 is stored in the first array element (hourlyRates[0]). The rate associated with pay code 2 is stored in the second array element (hourlyRates[1]), and so on. Notice that the pay code is one more than the index of its corresponding hourly rate in the array. The statement on Line 14 declares and initializes an int variable named code. The code variable will store the pay code entered by the user. It will be used to access the corresponding hourly rate in the array. The statement on Line 17 is next next in fixed-point notation with two decimal places. The cout on Line 20 prompts the user to enter the pay code, and the cin on Line 21 stores the user's response in the code variable. Next, the if clause on Line 12 determines whether the pay code stored in the code variable is valid. If the pay code is valid, the instruction in the if true path displays the appropriate hourly rate from the array; otherwise, the instruction in the if false path displays the message "Invalid pay code". Carefully study the instruction on Lines 23 and 24 in the program. Note that the instruction uses the code variable, which contains the pay code entered by the user, to access the appropriate element in the hourlyRates array. Also, to access the correct element, the number 1 must be subtracted from the contents of the code variable. This is because the pay code stored in the variable is one more than the subscript of its hourly rate. Figure 11-29 shows a sample run of the hourly rate program.

Before accessing an array, you should always verify that the subscript is valid for the array. If the compiler encounters an invalid subscript, it will display an error message and the program will end abruptly.
