# Coding a Selection Structure in C++

In C++ programs, you use the if statement to code a selection structure. The structure's syntax is shown in Figure 5-7. The square brackets in the syntax indicate that the else, referred to as the else clause, is optional. Recall, that bolded items in a statement's syntax are required. In this case, the if keyword and parentheses that surround the condition are required. The else clause is necessary only in a dual-alternative selection structure. Italic items in the syntax indicate where the programmer must supply information. In the if statement, the programmer must supply the condition that the computer needs to evaluate before processing it. The condition must be a Boolean expression, which is an expression that results in a Boolean value (true or false). Besides providing the statements to be processed in the true path, the programmer must provide the statements (optionally) in the false path. If a path contains more than one statement, the statements must be entered as a block, which means they must be enclosed in braces (). Although not a requirement, it is a good practice to use braces (such as /end if) to mark the end of an if statement. Using a block for an if statement will make your program easier to read and understand. It will also help you keep track of the if and else clauses when you nest if-else statements—in other words, when you include one if statement inside another if statement. You will learn how to nest if statements in Chapter 6. The six examples in Figure 5-7 show various ways of using the if statement to code selection structures. The remaining four examples 1 and 2 are dual-alternative selection structures. Notice that when a path contains multiple statements, the statements are entered as a block in braces. Although shown in Figure 5-7, you can also use braces even when a path contains only one statement. By doing this, you will not need to enter the braces when statements are added subsequently to the path. Forgetting to enter the braces is a common error made when using the if statement in a program.

C++ also provides the switch statement for coding a multiple-alternative selection structure. The switch statement is covered in Chapter 6.

In an if statement, you cannot have an else clause without matching if.
