Keep in mind that the parameterList is optional; the parentheses are a required part of the syntax. The parameterList contains the data type and name of one or more locations. The memory locations in a function's parameterList are called formal parameters. Each formal parameter will store an item of information passed to the function when it is called. In Example 1 in 9-4, the empty set of parentheses in the function header indicates that the randomNumber will not be passed any information by the statement that calls it. The function header in Example 2, contains two parameters and indicates that the getArea function will pass two items of information when it is invoked.

It is invoked with the double data type. The bonus function in Example 3 will receive an int item followed by a double item that it invokes. You will learn more about the parameterList later in Chapter 10.

In addition to the header, a function also contains a function body. The function body contains the instructions for performing the function's assigned task. The function begins with the opening brace { and ends with the closing brace }. In most cases, the last statement in the function body of a value-returning function is return expression; in which expression represents the function's one and only return value. The data type of the expression must agree with the dataType specified in the function header. The return statement returns the expression's value to the statement that called the function. After the function ends and execution continues in the calling function. Although not a requirement, it is a good programming practice to use a comment (such as //end of getRandomNumber function) to mark the end of a program-defined function. The comment will make your program easier to read and understand.

> Rather than using an empty set of parentheses when a function is not passed any information, programmers enter the keyword void within the parentheses.
