The algorithm in Figure 2-9 is composed of short English sentences, referred to as pseudocode. The word pseudocode means false code. It's called false code because although it represents programming language instructions, pseudocode cannot be understood by a computer.mers use pseudocode to help them while they are planning an algorithm. It allows them to jot down ideas using a human-readable language without worrying about the syntax of the programming language. The pseudocode is used as a guide when the programmer codes the algorithm. Coding the algorithm is the fourth step in the problem-solving process and is covered in Chapters 3 and 4. Pseudocode is standardized; every programmer has his own version, but you will find similarities among the various versions. Although the word pseudocode may be unfamiliar to you, think about the last time you gave directions to someone. You wrote down each direction on paper, in your words. Your directions were a form of pseudocode.

Besides pseudocode, programmers use flowcharts when planning algorithms. Unlike pseudocode, a flowchart uses standardized symbols to visually depict an algorithm. You can draw the flowchart by hand; or use the drawing and features in a word processor. You can use a flowchart program, such as SmartDraw or Visio.
