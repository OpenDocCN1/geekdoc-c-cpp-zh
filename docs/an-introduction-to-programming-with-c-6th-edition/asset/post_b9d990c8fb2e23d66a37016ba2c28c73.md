## The while Statement

C++ provides the while statement for coding a postfix loop. The statement's syntax is in Figure 8-7. As the bolded text in the syntax indicates, essential components of the statement include the do and while keywords, the parentheses that surround the condition, the braces, and the semicolon. The italicized items indicate where the programmer must supply information. In this case, the programmer must supply the condition, which must be phrased as a loop condition. As the while statement, the condition in the while statement must evaluate to true or false. The condition can contain variables, constants, functions, arithmetic operators, comparison operators, and logical operators. Besides it provides the statements to be processed when the condition evaluates to true. Although not required, some programmers use a comment (such as //begin loop) to mark the beginning of the while statement, because it makes easier to read and understand. Also included in Figure 8-7 are examples of using the while statement. The while clause in Example 1 tells the computer to repeat the loop body instructions as long as the age variable is greater than zero. The loop will stop when the second number entered by the user is zero or a negative number. The while clause in Example 2 indicates that the loop instructions should be repeated as long as the value in the makeEntry variable is either the uppercase Y or the lowercase y. In this case, the loop will stop when the user's second entry is anything other than the letter Y entered in either uppercase or lowercase. You could also write the last line in the loop as } while (toupper(makeEntry)) == 'Y'; or while (tolower(makeEntry)) == 'y';

> Recall that a looping condition specifies the requirement for processing the loop body.

## The do while Statement

### HOW TO Use the do while Statement

### Syntax

```
{
  //begin loop
  one or more statements to be processed one time, and thereafter
  as long as the condition is true
  while (condition);
} // the statement ends with a semicolon
```

### Example 1

```cpp
int age = 0;

cout << "Enter an age greater than 0: ";
cin >> age;
do {
  //begin loop
  cout << "You entered " << age << endl;
  cout << "Enter an age greater than 0: ";
  cin >> age;
} while (age > 0); // semicolon
```

### Example 2

```cpp
char makeEntry = ' ';
double sales = 0.0;

cout << "Enter a sales amount? (Y/N) ";
cin >> makeEntry;
do {
  cout << sales;
  cout << "You entered " << sales << endl;
  cout << "Enter a sales amount? (Y/N) ";
  cin >> makeEntry;
} while (makeEntry == 'Y' || makeEntry == 'y');
```

## Nested Repetition Structures

Like selection structures, repetition structures can be nested. In other words, you can place one loop (called the nested or inner loop) within another loop (called the outer loop). Both loops can be preset loops, or both can be postloops. Or, one can be a preset and the other a postloop. A programmer determines whether a problem requires a nested loop by studying the problem. ## CHAPTER 8 More on the Repetition Structure

Because the instructions for signing a book need to be repeated for every customer, the algorithm does not require a nested loop. This is because all the instructions within the loop should be followed only per customer.

```
repeat (there are customers in line)
  accept the book from the customer
    place the book on the table
    open the front cover of the book
    sign your name on the first page
    close the book
  return the book to the customer
  thank the customer
end repeat
```

Now consider a problem that a customer may have more than one book for Robin. It's also possible that a customer, not knowing about the book signing in advance, has left his book at home and is standing in line for the sole purpose of meeting Robin. What changes will need to be made in the line, the first six instructions in the loop body—the instructions that begin with "accept the book from the customer" and end with "return the book to the customer"—must now be repeated for an unknown number of books for each customer. Therefore, in addition to require the current loop, which determines whether there is a customer in line, the modified algorithm would require a nested loop to determine whether the customer has any books need signing. Robin will tell the customer only after all of the customer's books have been signed, so the last instruction in the loop (the thank the customer instruction) needs to be repeated only for each loop. It does not need to be repeated for each book. Therefore, it should be included in the outer loop, but not in the nested loop. Figure 8-1 shows the modified specification and algorithm. The outer loop begins with *repeat (there are customers in line)* and ends with the last *repeat*. The nested loop begins with *repeat (there are books need signing)* and ends with the first *repeat*. The outer loop' instructions will be followed for each customer in line; the outer loop ends when there are no more customers. The nested loop's instructions will be followed for each book the current customer wants signed. Note that the nested loop is contained within the outer loop. This must be true for the loop to be worked correctly.
