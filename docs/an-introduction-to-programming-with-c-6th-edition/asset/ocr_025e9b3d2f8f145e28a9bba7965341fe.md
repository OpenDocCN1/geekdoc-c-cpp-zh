# CHAPTER 12 Two-Dimensional Arrays

> HOW TO Use an Assignment Statement to Assign Data to a Two-Dimensional Array
Syntax
arrayName[rowSubscript][columnSubscript] = expression;

Example 1
grades[1][0] = 'F';
assigns the letter F to the element located in the four-row, first column in the grades array

Example 2
for (int row = 0; row < 4; row += 1) {
  for (int column = 0; column < 3; column += 1) {
    orders[row][column] = 0;
  }
}
assigns the integer 0 to each element in the four-row, three-column orders

You can use the C++ increment operator (++) to add 1 to a variable. For instance, you use row++ and column++ in Example 3, row++ and column++;

Be sure to always use row and column subscripts when referring to an element in a two-dimensional array. If the compiler encounters an invalid subscript, it will display an error message and the program will end abruptly.
