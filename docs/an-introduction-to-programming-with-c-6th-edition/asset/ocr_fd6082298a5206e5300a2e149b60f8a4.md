In the Square class definition the first method prototype and the first method definition pertain to the default constructor. A constructor is a method that automatically executes time an object is instantiated from the class. The sole purpose of a constructor is to initialize the private variables. Every class has at least one constructor. Each of a class's constructors must have the same name as the class, but its formal parameters (if any) must be different from any other constructor in the class. A constructor with no parameters is called the default constructor. A class can have only one default constructor. Because a constructor does not return a value, its prototype and definition do not begin with a data type. Notice that its definition begins with the name of the class followed by the scope resolution operator (::), the name of the constructor, and a set of parentheses—in case, Square::Square(). The scope operator indicates that the Square is a method of (or in) Square class. The Square method's definition in Figure F-9 contains the Square class's private side variable to number.

As learned earlier, a programmer does not have direct access to a private variable in a class. Rather, it must access the private variable indirectly through a public method. A program that instantiates a Square object can use the setSide method to assign a value to the private side variable. In this case, the setSide method receives the value from the program that invokes it and stores the value in its formal parameter: an int named sideValue. The code contained in the method definition verifies that the value received from the program is greater than zero. If it is, the code assigns the value to the private side variable; otherwise, it assigns the number to 0. Notice that the setSide method's prototype and definition begin with the keyword void, which indicates that the method does not return a value.
