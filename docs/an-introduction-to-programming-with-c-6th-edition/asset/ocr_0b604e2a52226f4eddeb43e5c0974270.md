# Example 4—A Class that Contains Overloaded Methods

In this example, you view the code for a class named GrossPay object has two behaviors: it can calculate and return the gross pay for a salaried employee, and it can calculate and return the gross pay for an hourly employee. The pay for a salaried employee is calculated by dividing the employee's annual salary by 24, because salaried employees are paid twice per month. The pay for an hourly employee is calculated by multiplying the number of hours worked during the week by his or her pay rate. Figure 15 shows the GrossPay class definition in the GrossPay header file. The GrossPay class contains two public member methods; both are overloaded calGross. Both methods have the same name, notice that their parameterLists differ. The parameter in the first calGross contains one parameter, whereas the parameterList in the second calGross contains two parameters. When two or more methods have the same name but different parameterLists, the methods are referred to as overloaded methods. Overloading is when two or more methods require different parameters to perform essentially the same task.
