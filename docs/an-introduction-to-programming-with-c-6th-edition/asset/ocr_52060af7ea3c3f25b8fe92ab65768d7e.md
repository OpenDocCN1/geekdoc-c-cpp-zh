Figure 6-22 shows the Kindlon High School flowchart. The diamond in the flowchart represents the multiple-alternative selection structure's condition. Recall that the diamond is used to represent the condition in single-alternative and dual-alternative selection structures. However, the diamond in both of those selection structures has several flowlines (rather than only two flowlines) leading out of the symbol. Each flowline represents a possible path and must be marked appropriately, indicating the value or values necessary for the path to be chosen.
