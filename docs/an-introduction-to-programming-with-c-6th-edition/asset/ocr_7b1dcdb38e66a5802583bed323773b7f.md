You desk-check the program in Figure 9-30 using 1575 as the sales amount. The statements on Lines 14 and 15 initialize an int variable sales and a double variable bonus. Both variables are local to the main function, which means they can be used only within that function. Both variables remain in the computer's internal memory until the main function ends.
