Problem specification

The game requires two people to play. Currently, Mr. Coleman thinks of a word that has five letters. He draws five dashes on the board—one for each letter the word. One student then chooses to guess the word, letter by letter. When the student guesses a correct letter, Mr. Coleman replaces the appropriate dash or dashes with the letter.
