# Displaying the Sum or Difference

Figure 5-13 shows the IPO chart information and C++ code for a program that displays either the sum or difference between two numbers entered by the user. The program contains a dual-selection structure. (The flowchart for this program is contained in the Ch5Flowcharts.pdf file, which is located in the Cpp6Chap05 folder or on the device designated by your instructor.) The program uses an int variable named operation and double variables named JanSales, febSales, and answer. The program prompts the user to enter either the number 1 (for addition) or the number 2 (for subtraction); it stores the result in the operation variable. The program then prompts the user to enter two amounts, which it stores in the JanSales and febSales variables. The operation == 1 in the if clause compares the contents of the operation variable with the number 1. The condition evaluates to true only when the user enters number 1; and false when the user enters anything other than the number 1. If the condition evaluates to true, the instructions in the selection structure's true path calculate and display the sum of the amounts stored in the JanSales and febSales variables. If the condition evaluates to false, the instructions in the selection structure's false path calculate and display the difference between the two amounts. Notice that the instructions in each path are entered as a statement block. Figure 5-14 shows a sample run of the sum or difference program.
