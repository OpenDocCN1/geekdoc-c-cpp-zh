# One-Dimensional Arrays

in Figure 11-3 are examples of declaring and initializing one-dimensional arrays. The declaration statement in Example 1 creates a three-element char named letters. It initializes the letters[0] element to A, the letters[1] element to B, and the letters[2] element to C. Example 2 shows statements you can use to declare a four-double array, initializing each element to a double number 0.0. The statement double sales[4] = {0.0, 0.0, 0.0, 0.0}; provides an initial value for each of the four array elements, or sales[4] = {0.0}; provides only one value. When the array declaration does not provide an initial value for each of the elements in a numeric array, C++ compilers will initialize the uninitialized array elements to 0 or 0 (depending on the data type of array). This is done only if you provide at least one value in the initialValues section. If you use the declaration statement without an initializer, the compiler does not automatically initialize the elements; the array elements may contain garbage. Example 3 shows two statements you can use to declare a six-element int array named int numbers[6] = {12, 0, 0, 0, 0, 0}; initializes the first element to the integer 12 and initializes the remaining elements to 0. The same result can be accomplished using the int numbers[6] = {12}; statement shown in the example.

> Most C++ compilers initialize array elements to a space, string empty string, and bool array elements to the keyword false.

> The = [initialValues] portion of the syntax in Figure 11-3 is optional; however items are enclosed in square brackets when in the syntax. In this case, the square brackets are omitted to conform with the square brackets that are required by the syntax.

# HOW to Declare and Initialize a One-Dimensional Array

```
dataTypeName[numberElements] = {initialValues};
```

Example 1

```
char letters[3] = {'A', 'B', 'C};
declares and initializes a three-element char array named letters
```

Example 2

```
double sales[4] = {0.0, 0.0, 0.0, 0.0};
declares and initializes a four-element double array named sales; each
element is initialized to 0.0
```

```
double sales[4] = {0.0};
declares and initializes a four-element double array named sales; each
element is initialized to 0.0
```

Example 3

```
int numbers[6] = {12, 0, 0, 0, 0, 0}
int numbers[6] = {12}
declares and initializes a six-element int array named numbers; the first
element is initialized to 12, while the others are initialized to 0
```
