# CHAPTER 7 The Repetition Structure

You can observe the way a counter is used to stop a loop by desk-checking the code in Figure 7-22. You will do this using the following three sales amounts: 2500, 2600, and 2000. The first three statements in the code create and initialize three variables. Figure 7-23 shows the desk-check table after these statements are processed.

| regionSales | numRegions | totalSales |
|--- | --- | --- |
| | 1 | 0 |

Figure 7-23 Desk-check table after the variable declaration statements are processed

The **while (numRegions < 4)** begins a loop that repeats its instructions as long as (or while) the value in **numRegions** counter variable is less than 4. According to the desk-check table in Figure 7-23, the value stored in **numRegions** is less than 4. As a result, the loop evaluates and the statements in the loop body are processed. The first statement prompts the user to enter 25 quarterly sales. The second statement stores the user's response (in this case, 2500) in the **totalSales** variable. The third statement adds the value stored in the **regionSales** variable to the **totalSales** accumulator variable; sum of both is 2500. The last statement in the loop body adds the number 1 to the value stored in **numRegions** counter variable; the result is 2. You can write the two instructions in the loop body as **totalSales = totalSales + regionSales;** and **numRegions = numRegions + 1;** Figure 7-24 shows the desk-check after the loop instructions are processed the first time.

| regionSales | numRegions | totalSales |
|--- | --- | --- |
| 2500 | 2 | 2500 |

Figure 7-24 Results of processing the loop instructions the first time

Next, in the **while (numRegions < 4)** clause evaluated to determine whether the loop instructions should be processed (a true condition) or skipped over (a false condition). According to the desk-check table in Figure 7-24, the value stored in the **numRegions** variable is less than 4. As a result, the loop evaluates and the statements in the loop body are processed. The first two statements prompt the user to enter 2nd quarterly sales and store the user's response (in this case, 6000) in the **regionSales** variable. The next statement adds the value stored in the **regionSales** variable to the value stored in the **totalSales** accumulator variable; sum of both is 8500. The last statement in the loop body adds the number 1 to the value stored in the **numRegions** counter variable; the result is 3. Figure 7-25 shows the desk-check table after the loop instructions are processed the second time.

| regionSales | numRegions | totalSales |
|--- | --- | --- |
| 6000 | 3 | 8500 |

Figure 7-25 Results of processing the loop instructions the second time
