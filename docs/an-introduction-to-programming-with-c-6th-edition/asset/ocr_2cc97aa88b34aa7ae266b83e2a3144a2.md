# LAB 7-2 Plan and Create

In this lab, you will plan and create an algorithm for Professor Chang. The problem specification and example calculations are shown in Figure 7-43.

Problem specification
Professor Chang wants a program that allows him to enter a student's project and test scores. The professor assigns three projects and two tests. Each project is 50 points, and each test is 100 points. The program should calculate and display the total points the student earned on the projects and tests. It should also display the student's grade, which is based on the points earned that Professor Chang uses when assigning grades.

| Total points earned | Grade |
| 315–350 | A |
| 280–314 | B |
| 245–279 | C |
| 210–244 | D |
| below 210 | F |

Example 1
Project and test scores: 45, 40, 41, 96, 68
Total points earned and grade: 31, B

Example 2
Project and test scores: 40, 35, 37, 73, 68
Total points earned and grade: 253, C

First, analyze the problem, looking for the output first and then for the input. In this case, Professor Chang wants the program to display the total points a student earned and his her grade. To calculate the total points earned, the computer will need to know the student's project and test scores. The scores are the problem items and will be entered by Professor Chang. To determine the grade, the computer will need to know Professor's grading scale. Next, plan the algorithm. Recall that most algorithms begin with an instruction to enter the items into the computer, followed by instructions that process the input items, typically including the items in one or more calculations.
