HOW TO Use the Extraction Operator to Store Data in a Two-Dimensional Array

```
Syntax
cin >> arrayName[subscript];
```

Example 1
cin >> grades[2][1];
stores the user's entry in the element located in the third row, column in the grades array

```

  << region + 1 << ",", Month "
  << month + 1 << ":": ";
  cin >> orders[region][month];
```
