# LAB 7-5 Debug

Follow the instructions for starting C++ and opening the Lab7-5.cpp file. The file is contained in the Cpp6Chap07\Lab7-5 Project folder or the Cpp6Chap07 folder. Run the program. When you are prompted to enter a value, type 15 and press Enter. The "Next" prompt appears over and again in the Prompt window, as shown in Figure 7-50. This is the result of the computer redoing the cout "Next: "; statement, which is contained in the body of the while loop, and it indicates that the program contains an endless (or infinite) loop. You can stop an endless loop by pressing Ctrl+c and hold down the Ctrl key as you tap the letter c, and then release keys. (If you are using Microsoft C++, you may need to click the Continue button after pressing Ctrl+c). Or, you can use the Close button on the Command Prompt window's title bar. Use either method to stop the endless loop, and then debug the program.

If you are using Microsoft Visual C++, you can stop end-less loop by Debugging on the menu bar in the IDE, and then clicking Stop Debugging.
