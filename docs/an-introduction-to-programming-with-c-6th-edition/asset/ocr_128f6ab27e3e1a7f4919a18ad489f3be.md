Study closely the instructions used to swap the values stored in the firstNum and secondNum variables. The instructions are shaded in Figure 5-10. The instruction, int temp = 0; declares and initializes a named temp. Because the variable can be used in the if statement's truth value, more specifically, it can be used only by the instructions within that path. or by the instructions that follow the declaration statement within the truth. A variable that can be used only within the statement block in which it is referred to as a local variable. In this case, the temp variable is local to the statement's truth value. You may be wondering why the temp variable was not declared at the beginning of the main function, with the firstNum and secondNum variables. There is nothing wrong with declaring the temp variable in that location, which is needed, when a swap is necessary. The second instruction in the if statement's truth value, temp = firstNum; assigns the value of the firstNum to the temp variable. If you do not store the firstNum's value in the next statement, firstNum = secondNum; which replaces the contents of the firstNum with the contents of the secondNum. Finally, secondNum = temp; assigns the value to the secondNum variable completes the swap. Figure 5-11 illustrates the concept of swapping, assuming the user enters the numbers 10 and 3.
