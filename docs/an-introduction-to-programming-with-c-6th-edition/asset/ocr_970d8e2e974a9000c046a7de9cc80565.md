**Figure 8-5** Second sales amount recorded in the desk-check table

The next symbol in the flowchart is the decision diamond. The diamond contains the posttest loop condition, which always marks the end of a posttest loop. The condition, which is phrased as a looping condition, compares the current sales amount with the sentinel value to determine whether the loop should be processed again (a true condition) or end (a false condition). Note that is the first time the loop condition is evaluated. In this case, the condition evaluates to true (25000 is not equal to -1). When the condition evaluates to true, the computer processes the instructions in the loop body. Those instructions calculate and display the bonus for the second salesperson and then get another amount (in this case, the sentinel value) for the user. Next, the condition is reevaluated whether the loop should be processed again (a true condition) or end (a false condition). In this case, the condition evaluates to false because the current sales amount is equal to the sentinel value. When the condition evaluates to true, the loop ends and continues again with the instruction immediately following the loop. In Algorithm 2's flowchart in 8-3, the loop is followed by the stop oval, which marks the end of the flowchart.
