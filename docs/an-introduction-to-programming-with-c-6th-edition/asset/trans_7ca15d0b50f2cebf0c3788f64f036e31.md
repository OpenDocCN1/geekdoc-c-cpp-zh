

## 选择结构中的逻辑错误

选择结构。注意第三个选择结构中的条件判断销售额是否小于 10000，并且它仅在第二个选择结构的条件为假时才被处理。换句话说，它只在销售额不大于等于10000时被处理。然而，如果销售额不大于等于10000，那么它们必然小于 10000；因此，第三个选择结构是不必要的。

| 正确的算法 | 错误的算法 |
|---|---|
| 1. 输入代码和销售额 | 1. 输入代码和销售额 |
| 2. 将销售额乘以 sb 计算奖金 | 2. 将销售额乘以 sb 计算奖金 |
| 3. if (代码是 X) | 3. if (代码是 X) |
| if (销售额大于或等于 10000) | if (销售额大于或等于 10000) |
| 奖金加上 150 | 奖金加上 150 |
| else | else |
| 奖金加上 125 | if (销售额小于 10000) |
| end if | 奖金加上 125 |
| end if | end if |
| 4. 显示奖金 | 4. 显示奖金 |

图 6-19 包含第三个逻辑错误的正确算法和低效算法

对图 6-19 中的低效算法进行人工检查将帮助你理解为什么最后一个选择是不必要的。低效算法的第一条指令是输入代码和销售额——在这种情况下为 X 和 1500。第二条指令是将销售额乘以 8 计算奖金；答案是 1200。第一个选择结构中的条件判断销售人员的代码是否为 X，因此第二个选择结构的条件检查销售额是否大于或等于 10000。确实如此，因此第二个选择结构的真路径将奖金增加了 150，得到 1350。低效算法的最后一条指令显示 1350 为奖金，这是正确的。

使用第二组数据，用户输入 X 作为代码，输入 9000 作为销售额。低效算法的第二条指令是将销售额乘以 8 计算奖金；得到 720。第一个选择结构中的条件判断销售人员的代码是否为 X。是，因此第二个选择结构的条件检查销售额是否大于或等于 10000。并不是，因此第三个选择结构的条件判断销售额是否小于 10000——这是多的。在这种情况下，销售额小于 10000，因此第三个选择结构的真路径将奖金增加了 125，得到 845。低效算法的最后一条指令显示 845 为奖金，这是正确的。

使用第三组数据，用户输入 A 作为代码， 13000 作为销售额。低效算法的第二条指令将销售额乘以 8，导致奖金为 1040。第一个选择结构中的条件判断销售人员的代码是否为 X。不是，因此第一个选择结构结束。注意当第一个选择结构的条件求值为假时，两个嵌套的选择结构都不会被处理。低效算法的最后一条指令显示 1040 为奖金，这是正确的。图 6-20 显示了低效算法的人工检查表。虽然三次人工检查的结果都是正确的，但第三次人工检查的结果是以效率较低的方式获得的。

| * | 9000 | 720 | (第二次检查的正确但低效的结果) |

## 多分支选择结构

图 6-21 显示了 Kindle 高中问题的规格说明和 IPO 图。该问题的解决方案需要一个从多个备选项中选择的选择结构；在这种情况下，它可以从几个字母等级中选择。如图所示，当字母等级为 A 时，选择结构应该显示消息“Excellent”（优秀）。当字母等级为 B 时，选择结构应该显示消息“Above Average”（平均以上），依此类推。包含多个备选项的选择被称为多分支选择结构或扩展结构。

Jacoby 先生在 Kindle 高中教学。他希望有一个程序，能根据他输入的字母等级显示消息。有效的字母等级及其对应的消息如下所示。如果字母等级无效，程序应该显示“Invalid grade”（无效等级）消息。

| 字母等级 | 消息 |
|---|---|
| A | Excellent |
| B | Above Average |
| C | Average |
| D | Below Average |

## 多分支结构

| 输入 | 输出 |
|---|---|
| grade | message |

算法：
1. 输入等级
2. If (grade 是以下之一：)
   A 显示 "Excellent"
   B 显示 "Above Average"
   C 显示 "Average"
   D 显示 "Below Average"
   else
     显示 "Invalid grade"
end if

图 6-23 显示了 Kindle 程序的两个 C++ 版本。这两个版本都使用了多分支结构。多分支形式包含多个 `if else` 子句。虽然两个版本的结果相同，但第二个版本提供了一种更方便的多分支编码方式。

```
Version 1
int main()
{
    char grade = ' ';

    //enter grade
    cout << "Letter grade: ";
    cin >> grade;
    grade = toupper(grade);

    if (grade == 'A')
        cout << "Excellent";
    else
        if (grade == 'B')
            cout << "Above Average";
        else
            if (grade == 'C')
                cout << "Average";
            else
                if (grade == 'D' || grade == 'F')
                    cout << "Below Average";
                else
                    cout << "Invalid grade";
    //end grade
    cout << endl;
    system("pause");
    return 0;
} //end of main function

Version 2
int main()
{
    char grade = ' ';

    //enter grade
    cout << "Letter grade: ";
    cin >> grade;
    grade = toupper(grade);

    if (grade == 'A')
        cout << "Excellent";
    else if (grade == 'B')
        cout << "Above Average";
    else if (grade == 'C')
        cout << "Average";
    else if (grade == 'D' || grade == 'F')
        cout << "Below Average";
    else
        cout << "Invalid grade";

    cout << endl;
    system("pause");
    return 0;
} //end of main function
```
