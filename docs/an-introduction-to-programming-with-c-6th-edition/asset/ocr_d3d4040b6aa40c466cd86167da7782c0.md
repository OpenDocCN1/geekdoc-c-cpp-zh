After de-checking an algorithm to ensure it works correctly, you can begin coding. You begin by declaring memory locations that will store the values of the input, processing (if any), and output items. The circle area problem will need to store the values of the radius, pi, and area. The radius and area values should be stored in variables, because the user should be allowed to change the radius value, while the program is running. The value of pi, however, will be stored in a named constant, because its value will not change during runtime. The variables and named constant will store real numbers, so you will use the double data type for each.
