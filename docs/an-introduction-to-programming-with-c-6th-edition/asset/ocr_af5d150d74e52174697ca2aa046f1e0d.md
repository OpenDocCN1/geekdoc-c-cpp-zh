# The Random Numbers Program

11-30 shows the problem specification, IPO chart information, and C++ instructions for the random numbers program. The flowchart for this program is contained in the Ch11flowcharts.pdf file, which is located in the Cpp6Chap11 folder. The main function assigns random numbers from 1 through 100 to a five-element int array named randNums. It then calls a program-defined value function to display the contents of the array. Next, it calls a program-defined value-returning function to determine the highest number in the array. The main function displays the function's return value on the screen.
