The statement

```
vector<int>::iterator iter = begin(vec);
```

declares and initializes an iterator object, iter. The type of iter is vector<int>::iterator. This complicated expiration that iterator is a type defined within the vector<int> type. A shorter way to express this statement takes advantage of the compiler's ability to infer the variable's type from its context:

```
auto iter = begin(vec);
```

(Section 3.9 C++s type inference capabilities.) The compiler can deduce the type of iter based on the return type of the begin function.

While the begin function returns an iterator pointing to the first element in a data structure, the end function returns an iterator pointing to the element just the last element in the data structure. The code fragment

```
vector<int> vec {10, 20, 30, 40, 50};
auto iter = end(vec);
```

the iterator object does not represent a viable element in the vector. As we never attempt to dereference the iterator, the expression +iter in this case is undefined. We normally use the iterator returned by the end function to see if we are part of our data structure, Listing 18.12 (iteratorloop.cpp) demonstrates.

Listing 18.12: iteratorloop.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Make a simple integer vector
    vector<int> vec {10, 20, 30, 40, 50};
    // Print the contents of the vector
    for (auto iter = begin(vec); iter != end(vec); iter++) {
        cout << +iter << ' ';
    }
}
