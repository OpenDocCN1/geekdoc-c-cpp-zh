# 2.1. GENERAL STRUCTURE OF A SIMPLE C++ PROGRAM

+   * #include <iostream>

This line is a preprocessor directive. All preprocessor directives within C++ source code begin with a # symbol. This one directs the preprocessor to add some predefined code to our source code before the compiler begins to process it. This process is automatic and invisible to us.

Here we want to use parts of the istream library, a collection precompiled C++ code that C++ programs (like ours) use. The istream library contains routines that handle input and output (I/O) that include functions such as printing to the display, getting user input from the keyboard, and dealing with files.

Two items used in Listing 2.1 (simple.cpp), cout and endl, are not part of the C++ language itself. These items along along many others related to input and output, were developed in C++, compiled, and stored in the iostream library. The compiler needs to be aware of these items. The #include directive specifies a file, called a header, that contains the specifications for the library code. The compiler checks how we use cout and endl within our code against the specifications in the <iostream> header to ensure that we are using the library correctly.

Most of the programs we use with this #include <iostream> directive, and some programs we will in the future using #include other headers as we.

+   * namespace std;

The two programs needs to display a message on the screen, cout and endl, have names: std::cout and std::endl. This using namespace std allows us to omit the std:: prefix and use their shorter names. This directive is optional, but if we omit it, we must use the longer names. Listing 2.2 (simple.cpp) shows how the longer names are used. The name std stands for “standard”, and using the namespace std line indicates that some of the names we use in our program are part of the so-called “namespace.”

+   * int main() {

This specifies the beginning of our program. Here we declaring a function named main. C++ programs must contain this function to be executable. Details about the meaning of int and the parentheses appear in later chapters. More general information about functions appear in Chapter 8 and Chapter 9.

The opening curly brace at the end of the line marking the beginning of the body of the function. The body of the function contains the statement to execute.

> cout << "This is a C++ program!" << endl;

The body of our main function contains only one statement. This statement executes the program to print the message C++ program! on the screen. A statement is the fundamental unit of execution in a C++ program. Functions contain statements that the compiler translates into machine language instructions. C++ has a variety of different kinds of statements, and the chapters follow explore these various kinds of statements. All statements in C++ end with a semicolon (;). A more detailed explanation of statement appears below.

+   * }

The closing curly brace marks the end of the body of the function. Both the opening curly brace and close curly brace are required for every function definition.
