Listing 6.20 (startree.cpp) uses sequential while loops nested within a while loop. The outer while loop is responsible for drawing one row of the tree each time its body is executed:

When a group of statements is enclosed within curly braces a block is formed. ### 6.5.2 Printing Prime Numbers

A prime number is an integer greater than one whose factors (also called divisors) are one and. For example, 29 is a prime number (only 1 and 29 divide it with no remainder), but 28 is not (2, 4, and 14 are factors). Prime numbers were once an intellectual curiosity of mathematicians, but now they play an important role in cryptography and computer security.

The task is to write a program that displays all the prime numbers up to a value entered by the user. Listing 6.21 (printprimes.cpp) provides one solution.

> Listing 6.21: printprimes.cpp

```cpp
#include <iostream>

using namespace std;

int main() {
	int max_value;
	cout << "Display primes up to what value? ";
	cin >> max_value;
	int value = 2; // Smallest prime number
	while (value <= max_value) {
		// See if value is prime
		// bool prime = true; // Provisionally, prime is prime
		// Try all possible factors from 2 to value - 1
		int trial_factor = 2;
		bool is_prime = true;
		while (trial_factor < value) {
			if (value % trial_factor == 0) {
				is_prime = false; // Found a factor
				break;
			}
			// No need to continue; it is NOT prime
			trial_factor++;
		}
		if (is_prime) {
			cout << value << " "; // Display the prime number
		}
		value++; // Try the next potential prime number
	}
	cout << endl; // Move cursor down to next line
}
```

The logic of 6.21 (print_primes.cpp) is a little more complex than that of 6.20 (startree.cpp). The user provides a value for max_value. The main loop (outer while iterates over all the values from two to max_value:

- Two new variables, local to the body of the outer loop, are introduced: trial_factor and is_prime is initialized to true, meaning value is prime unless our tests prove otherwise. trial_factor counts all the values from two to value - 1 in the inner loop:

```cpp
int trial_factor = 2;
while (trial_factor < value) {
    if (value % trial_factor == 0) {
        is_prime = false; // Found a factor
        break; // No need to continue; it is NOT prime
    }
    trial_factor++;
}
```

The expression value % trial_factor is zero when trial_factor divides value into no remainder—exactly when trial_factor is a factor of value. If is_prime becomes false, the loop cannot continue, and if is_prime never becomes false, the loop ends when trial_factor equals value.

```cpp
if (is_prime) {
    cout << value << " "; // Display the prime number
}
```

Some important questions we can ask:

- 1. If the user enters 2, will it be prime?
In this case max_value = 2, so the condition of the outer

```cpp
value <= max_value
```

is not true.

- 2. If the user enters a number less than 2, is anything printed?
The while ensures that values less than two are not considered. The body of the while will never be entered. Only the newline is printed. This behavior is correct.

- 3. Is the inner loop guaranteed to terminate?
In order to enter the body of the inner loop, trial_factor must be less than value. value does not change anywhere in the loop immediately after the if-statement, but trial_factor is, therefore, incremented during each iteration. Eventually, trial_factor equals value, the loop terminates.

- 4. Is the outer loop guaranteed to terminate?
In order to enter the body of the outer loop, value must be less than or equal to max_value, max_value does not change anywhere in the loop. it is increased in the last statement within the body of the outer loop, and value is not modified anywhere else. Since the inner loop is guaranteed to terminate as shown in the previous answer, eventually value will exceed max_value and the loop will end.

We rearrange the logic of the inner to use the break statement. The current version is:

```cpp
while (trial_factor < value) {
    if (value % trial_factor == 0) {
        is_prime = false; // Found a factor
        break; // No need to continue; it is NOT prime
    }
    trial_factor++;
}
```

We can rewrite it:

```cpp
while (is_prime == (value % trial_factor != 0)) {
    trial_factor++; // Try next factor
}
```

Each time the loop is restarted, trial_factor becomes false if any value % trial_factor is zero. This is exactly when trial_factor is a value. If is_prime becomes false, the loop cannot continue, and if is_prime never becomes false, the loop ends when trial_factor equals value. Due to operator precedence, the parentheses are not necessary.
