# 10.7 Reference Variables

C++ supports another kind of variable that is many ways similar to a pointer. When the & symbol is used as part of the type name during a variable declaration, as in

```
int x;
int& r = x;
```

we r is a reference variable. This declaration creates a r that refers to the same memory location as the variable x. We say r aliases x. Unlike a pointer variable, we may treat r as if it were an int variable—dereferencing is necessary. Listing 10.15 (referencevar.cpp) demonstrates how reference variables can alias other variables.

Listing 10.15: referencevar.cpp
#include <iostream>

using namespace std;

int main() {
int x = 5;
int y = x;
int& r = x;
cout << "x = " << x << endl;
cout << "y = " << y << endl;
cout << "r = " << r << endl;
cout << "Assign 7 to x" << endl;
x = 7;
cout << "x = " << x << endl;
cout << "y = " << y << endl;
cout << "r = " << r << endl;
cout << "Assign 8 to y" << endl;
