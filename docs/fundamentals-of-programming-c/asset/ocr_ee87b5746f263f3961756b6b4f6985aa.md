Like a constructor, a destructor has the same name as its class, except that the destructor's name begins with a tilde~) symbol. This symbol distinguishes a destructor from a constructor. Also unlike a constructor, a destructor may not be overloaded, and a destructor may not accept any parameters.

The constructor prints the first line when the main initializes the acct object. The acct variable's display method prints the second line. The destructor prints the last line at the end of main's execution when the acct goes out of scope.
