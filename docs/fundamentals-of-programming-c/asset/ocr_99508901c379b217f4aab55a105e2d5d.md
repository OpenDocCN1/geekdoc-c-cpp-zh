If bit 2 in e is 0, then bit 2 in the result is 1; otherwise, bit 2 in the result is 0.

If bit 31 in e is 0, then bit 31 in the result is 1; otherwise, bit 31 in the result is 0.

For example, the expression ~ 13 evaluates to -14, since:

$13_{10} = 0000000000000000000000001101_{2}$
$-14_{10} = 111111111111111111111010_{2}$

The shift operators moves all the bits in one left or to the right:

+   * Shift left (<<). Expression x << shifts all the bits in x to the left places. Zeros filled vacant positions. The bits shifted off the left side are discarded. x << 2 evaluates to 20, since $5_{10} = 101_{2}$ shifted two places to the left yields $10100_{2} = 20$. Observe that x is equal to $x \times 2^{2}$.
* Shift right (>>). Expression x >> shifts all the bits in x to the right places. The vacant bits on the left depends on whether the integer is signed or unsigned (for, int vs unsigned);

+   - For signed values the vacant bit positions are filled with the sign bit (the original leftmost bit).
* For unsigned values the vacant bit positions are filled with zeros.

The bits shifted off the right side are discarded. The expression 5 >> 2 evaluates to 1, since $5_{10} = 101_{2}$ shifted two places to the left $001_{2} = 20$ (the original bits in positions 1 and 0 are shifted off the end). Observe that x is equal to $x \div 2^{2}$.
