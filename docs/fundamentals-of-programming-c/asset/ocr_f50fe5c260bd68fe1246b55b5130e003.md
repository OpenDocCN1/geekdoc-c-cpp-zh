# 10.10. SUMMARY

+   - Local variables are not automatically initialized, but global numeric variables are automatically initialized to zero.

+   - A global variable exists for the life of the program, but local variables are created during a function call and discarded when the function's execution has completed.

+   - A local variable with the same name as a global variable hides the global from the code within the function. The scope resolution operator (:) can be used to access the hidden global.

+   - Modifying a global variable directly affects the behavior of any function that uses global variables. A function that uses a global variable cannot be tested in isolation since its behavior will depend on how code outside modifies the global variable.

+   - The behavior of an independent function is determined strictly by the parameters passed into it. An independent function will not use global variables.

+   - Local variables are preferred to global variables, since the indiscriminate use of global variables leads to functions that are less flexible, less reusable, and more difficult to understand.

+   - Unlike normal local variables, static local variables exist throughout the life of the program.

+   - Unlike normal local variables, a static local variable retains its value between function invocations.

+   - All static variables are initialized once, at the beginning of the program's execution.

+   - A function's signature contains its name along with the parameters it accepts.

+   - A C++ program may have multiple functions with the same names as long as their signatures differ.

+   - A recursive function must call itself or not determined by a conditional statement. The base case of the recursive is recursive, and the base case does not make the recursive. Each recursive call should move the computation closer to the base case.

+   - Function prototypes can be placed in a .h header file which is #included by calling code. The functions are then placed in a .cpp file which can be compiled separately from the calling code.

+   - A pointer is a variable representing a memory address.

+   - The address of a variable can be determined by the address-of (&amp). This address can be assigned to a pointer variable.

+   - The symbol * used during a declaration, the unary * is to signify a pointer variable.

+   - When not used in declaration, the unary * is the pointer dereferencing operator. The pointer dereferencing operator in conjunction with a pointer variable is used to examine or modify the contents of the memory referenced by the pointer.

+   - The pointer dereferencing operator (*) and address-of (&amp;) perform the inverse operations of each other. The &amp; operator yields the address of an object, while the * operator provides the object at a given address.

+   - In-by-reference parameter passing, an actual value is not copied into the formal parameter. Instead, the address of an actual value is passed as the formal parameter. The code within the function can manipulate the actual parameter through its reference.
