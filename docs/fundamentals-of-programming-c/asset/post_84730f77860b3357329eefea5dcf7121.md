## 3.3 Identifiers

While mathematicians are content with giving their one-letter names like x, programmers often use longer, more descriptive variable names. Names such as altitude, sum, and user_name are much better than the equally permissible, s, and u. A variable's name should be related to its purpose within the program. Good variable names make programs more readable by humans. Since programs often contain many variables, well-chosen variable names can render an otherwise obscure collection of symbols more understandable.

C++ has strict rules for variables. A variable name is one example of an identifier. An identifier is a word used to name things. One of the identifiers can name a variable. We will see in later chapters that identifiers name other things such as functions and classes. Identifiers have the following form:

- Identifiers must contain at least one character.
- The first character must be an alphabetic letter (upper or lower case) or the underscore `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz_`
- The remaining characters (any) may be alphabetic characters (upper or lower case), or a digit `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefdefghjklnopqrstuvwxyz_0123456789`
- No other characters (including spaces) are permitted in identifiers.
- A reserved word cannot be used as an identifier (see Table 3.1).

Here are some examples of valid and invalid identifiers:

- All of the following words are valid identifiers and so qualify as variable: **x, x2, total, port_22**, and **FLAG**.
- None of the following words are valid identifiers: **sub-total** (dash is not a legal symbol in an identifier), **first entry** (space is not a legal symbol in an identifier), **4all** (begins with a digit), **#** (pound is not a legal symbol in an identifier), and **class** (class is a reserved word).

C++ has many reserved words for which could otherwise be used as identifiers. Reserved words are special and are used to define the structure of C++ programs. Table 3.1 lists all the C++ reserved words.

The purposes of these reserved words are revealed throughout this book.
You may not use them but if you accidentally attempt to use one of the reserved words in a program as a variable name, the compiler will issue an error (see Section 4.6 for more compiler errors).

In Listing 2.1 (simple.cpp) we used reserved words: **using, namespace**, and **int**. Note that **include, endl,** and **main** are reserved words.

In a statically-typed language, the type of a variable must be explicitly specified before it is used in a program. ## 3.4 Floating-point Types

Many computational tasks require numbers that have fractional parts. For example, to compute the area of a circle around the circle's radius, the value $\pi$, or approximately 3.14159 is used. C++ supports non-integers, and they are floating-point numbers. The name implies that mathematical calculations the decimal point move or "float" to various positions to maintain the number of significant digits. The type float and double represent different types of floating-point numbers. The type double is used more often, since it is used for "double-precision floating-point", and it can represent a wider range of values with more digits of precision. The float type represents less precision. Floating-point numbers can be positive and negative.

As you can see from 3.2, doubles provide more precision at the cost of using more memory.

Listing 3.8 (pi-print.cpp) prints an approximation of the mathematical value $\pi$.
