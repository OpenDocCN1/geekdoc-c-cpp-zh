and a keyboard. One event might be a mouse button over a particular graphical element (like a button) within a window. Information about this event can be stored in an integer. For example, it may indicate whether or not the Shift key was held down when the mouse button was clicked. 1 may be responsible for the Alt key, but 3 for the Ctrl key. value 5, which in binary is

```
00000000000000000000000000000101
```

means that the mouse button was clicked by the Shift and Alt keys were held down. This might require a different action on the part of the program if some other combination of keys (or none) were being pressed. For example, suppose the int variable key_status holds information about which keys the user was depressing during the most recent mouse click. If the user presses the Shift key during mouse click, you can display some warning dialog box. The following code fragment uses a bitwise and to accomplish the tasks:

```
if (key_status & 1)
    show_dialog("Warning: Operation not supported.");
```

If the expression key_status & 1 is zero, then the bit 0 is zero in mouseEvent, and, therefore, the Shift key was not pressed. If the expression is nonzero, the condition is interpreted as false and the running program will not display the dialog box. On the other hand the expression evaluates to non-zero, the Shift key is depressed and the expression is non-zero. Recall from Section 5.1 that any non-zero condition is considered true, and so the dialog box appears

Using the GUI library with defined constants that you can use to enhance or modify particular for example the following constants:

```
const int SHIFT_DOWN = 1;          // This is 0...0001
const int CTRL_DOWN = SHIFT_DOWN << 1;  // This is 0...0010
const int ALT_DOWN = CTRL_DOWN << 1;    // This is 0...0100
```

The above code could be written:

```
if (key_status & SHIFT_DOWN)
    show_dialog("Warning: Operation not supported.");
```

If you wanted to check if the user was holding down the Shift and Alt keys during the mouse event, you could write

```
if (key_status & (SHIFT_DOWN | ALT_DOWN))
    show_dialog("Warning: Operation not supported.");
```

Do you see how SHIFT_DOWN | ALT_DOWN means both keys are down simultaneously?

Since we concentrate on applications programming systems in this book, we will have little use bitwise operators except for a few isolated situations. It is good to be aware of their presence, though their accidental use may lead to debug compiler messages and logic errors. For example, suppose you mean to use & (logical AND) in a conditional expression instead of &&. Because C++ allows integers to be treated as Boolean operators and anything else is true, the mistake might affect the compiler's detection. The resulting logic error may be difficult to track.
