Listing 7.4 (forcounttoffive.cpp) uses a for statement to count to five.

Listing 7.4: forcounttoffive.cpp
#include <iostream>
using namespace std;
int main() {
    for (int count = 1; count <= 5; count++)
    cout << count << endl; // Display counter
}

With a while loop, the four counting variables (variable declaration, initialization, condition, and modification) can be scattered throughout the code. With a for loop, a programmer should be able to determine all the important information about the loop's control by looking at one statement.
