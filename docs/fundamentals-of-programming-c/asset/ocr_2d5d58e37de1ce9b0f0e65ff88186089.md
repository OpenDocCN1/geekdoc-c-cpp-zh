With only two digits to work with, the binary number system distinguishes place values by powers of two.

In the decimal system, it is easy to add 3 + 8:

| 3 |
+ 5 |
- 8 |

The sum 3 + 9 is a little more complicated, as early elementary students soon discover:

| 3 |
+ 9 |
- 12 |

The answer, of course, is 12, but there is no single *digit* that means it takes digits, 1 and 2. The sum is

| 1 |
03 |
+ 09 |
\n 12 |

We can say 3 + 9 is 2, *carry*. The rules for adding binary numbers are shorter and simpler than decimal numbricks:

| $O_2 + O_1 = O_3 |
| $O_2 + L_2 = L_2 |
| $L_2 + O_2 = L_2 |
| $L_2 + L_2 = O_2$ |

Within the sum $l_2 + l_2$ is 0, *carry*. A typical large sum would be

| 11 |
10112 |
+ $3_{10}$ |
112_2 |
1100_{10} |

Integers are whole numbers (no fractional parts), both positive and negative. The range of C++ integer types include **int, long, long, short**. These are distinguished by the number of bits required to store the type, the range of values that can be represented. Mathematical integers are infinite, but all C++s integer types correspond to finite subsets of mathematical integers.
