## 8.6 RANDOM NUMBERS

Some applications require behavior that appears random. Random numbers are useful particularly in games and simulations. For example, many board games use a die (one or pair of dice) to determine how many places a player is to advance. (See Figure 8.5). A die or pair of dice are used in other games of chance. A die is a cube showing spots on each of its faces. The number of spots ranges from one to six. A player rolls a die or sometimes a pair of dice, and the side(s) that face have meaning in the game being played. The value of a face after a roll is determined by random the complex tumbling of the die. A software adaptation of a game that involves dice would need a way to simulate the random roll of a die.

![](img/e326304bd50fbc4f7d5a64c1487eb635_192_0.png)

All algorithmic random number generators actually produce pseudorandom numbers, not true random numbers. A pseudorandom generator has a particular period, based on the nature of the algorithm used. If the generator is long enough, the patterns of numbers produced repeats itself. The good news is that all practical algorithmic pseudorandom number generators have periods that are large enough for most applications.

C programmers can use two standard C functions for generating pseudorandom numbers: rand and rand().

```cpp
void srand(unsigned int);
int rand();
```

srand establishes the first value in the sequence of pseudorandom integer values. Each call to rand returns the next value in the sequence of pseudorandom values. Listing 8.10 (simplerandom.cpp) shows how a sequence of 100 pseudorandom numbers can be printed.

Listing 8.10: simplerandom.cpp
```cpp
#include <iostream>
#include <cstdlib>

using namespace std;

int main() {
  srand(23);
  for (int i = 0; i < 100; i++) {
    int r = rand();
    cout << r << " ";
  }
  cout << endl;
}
```

The numbers printed by the program appear to be random. The algorithm is given a seed value to begin, and a formula is used to produce the next value. The seed value determines the sequence of numbers generated; identical seed values generate identical sequences. If you run the program again, the same sequence is displayed because the seed value, 23, is used. In order to allow each program to run a different sequence to display different sequences, the seed value must be different for each run. How can we establish a different seed value for each run? The best way to make up a "random" seed at run is to use the time function which is found in the ctime library. The call to time() returns the number of seconds since midnight January 1, 1970. This value differs between different programs, so each execution will use a different seed value, and the generated pseudorandom will be different. Listing 8.11 (betterrandom.cpp) incorporates the time function to improve its randomness over multiple executions.

Listing 8.11:betterrandom.cpp
```cpp
#include <iostream>
#include <cstdlib>
#include <time>

using namespace std;

int main() {
    srand(static_cast<unsigned>(time(0)));
    for (int i = 0; i < 100; i++) {
        int r = rand();
        cout << r << " ";
    }
    cout << endl;
}
```

- When faced with the choice of using a standard library function or writing your own code to solve the same problem, choose the library function. The standard function will be tested thoroughly, well, and likely more efficient than the code you would write.
