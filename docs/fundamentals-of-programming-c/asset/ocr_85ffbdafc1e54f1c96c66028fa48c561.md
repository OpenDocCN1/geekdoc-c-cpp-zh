# 5.7. NESTED CONDITIONALS

```
if (value >= 64) {
  cout << 1;
  value %= 64;
} else {
  cout << 0;
  if (value >= 32) {
    cout << 1;
    value %= 32;
  } else {
    cout << 0;
    if (value >= 16) {
      cout << 1;
      value %= 16;
    } else {
      cout << 0;
      if (value >= 8) {
        cout << 1;
        value %= 8;
      } else {
        cout << 0;
        if (value >= 4) {
          cout << 1;
          value %= 4;
        } else {
          cout << 0;
          if (value >= 2) {
            cout << 1;
            value %= 2;
          } else {
            cout << 0;
            cout << value << endl;
          }
        }
      }
    }
  }
}
```

In Listing 5.9 (binaryconversion.cpp): outer if checks if the value is in the proper range. The program works only for non-negative integer less than 1,024, so the range is 0-1023.

+   - Each inner if compares the user-supplied entered integer against decreasing powers of two. If the number is large, the program:
  - prints the 1 to the console, and
  - removes the remainder operator that power of two’s contribution to the value.

If the number is not at least as big as the power of two, the program prints 0 instead and moves on without modifying the input value.
- For the ones at least the end no check is necessary—the remaining value will be 0 or 1 and so the program prints whatever remains.
