# 15.7. STATIC MEMBERS

```
// act accordingly
int TrafficSignal::get_color() const {
  return color;
}
```

Within the methods of the TrafficSignal class we can use the simple names RED, GREEN, and YELLOW. Code outside of the TrafficSignal class can access the colors because they are public but must use the fully-qualified names TrafficSignal::RED, TrafficSignal::GREEN, and TrafficSignal::YELLOW.

A client can create a traffic light object

```
TrafficLight(TrafficSignal::YELLOW);
```

Since the code is outside of the TrafficSignal class must use the full TrafficSignal::YELLOW name. This makes an initially yellow traffic light. The RED, GREEN, and YELLOW fields are constants, clients cannot access them directly to control the state of a traffic light. To see why, consider a minor change to TrafficSignal in the class we will call TrafficSignalAlt:

```
TrafficSignalAlt {
  int color; // The light's current color: RED, GREEN, or YELLOW
public:
  // Constant instance fields available to clients
  const int RED;
  const int GREEN;
  const int YELLOW;

```

```
TrafficSignalAlt(int initial_color);
  void change();
  int get_color() const;
}
```

TrafficSignalAlt is identical to TrafficSignal, except that the constants are instance fields instead of class (static) fields. Observe that like the TrafficSignal class, the TrafficSignalAlt has no default constructor. Recall from Section 14.4 that a default constructor accepts no arguments, and if a programmer provides any constructor for a class, the compiler will not automatically provide a default constructor. This client cannot write code such as

TrafficSignal light;

or

TrafficSignalAlt light;

During the object's construction the client must create an integer argument representing a traffic light color. If RED, GREEN, and YELLOW are constant instance variables (that is, non-static fields), every TrafficSignalAlt object has its own copy of the fields, and the RED, GREEN, and YELLOW fields cannot exist outside of any traffic light. This leads to a chicken-and-egg problem—how can we create the first TrafficSignalAlt object using the symbolic constants RED, GREEN, or YELLOW? These do not exist unless we have a traffic light object, yet we need a traffic light to have any of these constants!
