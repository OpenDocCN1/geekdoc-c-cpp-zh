+   g++ -Wall -std=c++11 -o simple.simple.cpp

The -std=c++11 option directs the compiler to process the C++ source code according to the rules of the C++11 standard which the International Standards Organization (ISO) adopted in 2011. This standard is relatively new, if you omit this part of the command, g++ assumes the programmer is writing the source code under the rules of the older, 1998 ISO C++ standard, usually referred to as C98.

The code in this book is based on the C++11 standard.

+   g++ -Wall -std=c++11 -o simple simple.cpp

The -o part of the command specifies the name of the executable program. The desired name appears after the -o part, so our executable program will be named simple.exe on Windows systems. On Mac and Linux platforms the name of the executable produced will be just simple (no .exe extension). If the C++ source code contains no errors, the compiler will produce the executable file named simple.exe (or simple). On a Windows Machine we can run the compiled program from the command line by typing

# simple

(We can also use the full name, simple.exe). On a Unix-like system (OS X or Linux), we instead would

# .simple

to execute the program.

+   g++ -Wall -std=c++11 -o simple simple.cpp

simple.cpp specifies the name of the C++ source file we wish to compile. Here the file simple.cpp must reside in your current working directory for the compiler to process it.

The general form of the command to compile a C++ source file, therefore, is

```
g++ -Wall -std=c++11 -o executable source
```

where source is the name of the file containing the C++ source code, and executable is the name of the executable program the build process generates.

When you are finished with the executable file simple.exe, you can delete it with the following command:

```
simple.exe
```

We can reconstruct the executable file whenever we like by recompiling the source file. Be careful not to delete the accident source file, or you will have no choice but to type it in again.
