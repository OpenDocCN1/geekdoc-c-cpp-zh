
## 10.7 Reference Variables

C++ supports another kind of variable that is many ways similar to a pointer. When the & symbol is used as part of the type name during a variable declaration, as in

```
int x;
int& r = x;
```

we r is a reference variable. This declaration creates a r that refers to the same memory location as the variable x. We say r aliases x. Unlike a pointer variable, we may treat r as if it were an int variable—dereferencing is necessary. Listing 10.15 (referencevar.cpp) demonstrates how reference variables can alias other variables.

Listing 10.15: referencevar.cpp
```cpp
#include <iostream>

using namespace std;

int main() {
int x = 5;
int y = x;
int& r = x;
cout << "x = " << x << endl;
cout << "y = " << y << endl;
cout << "r = " << r << endl;
cout << "Assign 7 to x" << endl;
x = 7;
cout << "x = " << x << endl;
cout << "y = " << y << endl;
cout << "r = " << r << endl;
cout << "Assign 8 to y" << endl;
y = 8;
cout << "x = " << x << endl;
cout << "y = " << y << endl;
cout << "r = " << r << endl;
cout << "Assign 2 to r" << endl;
r = 2;
cout << "x = " << x << endl;
cout << "y = " << y << endl;
cout << "r = " << r << endl;
return 0;
}
```

The output Listing 10.15 (referencevar.cpp):

```
x = 5
y = 5
r = 5
Assign 7 to x
x = 7
y = 5
r = 7
Assign 8 to y
x = 7
y = 8
r = 7
Assign 2 to r
x = 2
y = 8
r = 2
```

clearly demonstrates that the variables x and r represent the same quantity. Reassigning x in the same way, and reassigning r changes x exactly the same way. The variable y, on the other hand, is independent from both x and r. Reassigning x or r does not affect y, and reassigning affects x nor r.

Reference variables are similar to pointer variables, but there are some important differences. Reference syntax is similar to pointer syntax because it is not necessary to dereference a variable in order to assign the memory location to it it refers. If num is an int, ptr is a pointer to an int, and ref is a reference to an int, consider the following statements:

```
num = ref; // Assign num from ref, no need to dereference
num = *ptr; // Assign num from ptr, must dereference *
```

A reference has two limitations over a pointer variable: A pointer variable may be declared without an initial value and reassigned later. Consider the following statements:

- a reference variable must be initialized with an initial value when it is declared. 
```cpp
int *p; // Legal, we will assign p later
int &r; // Illegal, we must initialize r when declaring
```

Attempting to compile this code under Visual C++ prompts the compiler to issue the error
error C2535: 'r': references must be initialized

- there is no way to bind a reference to a variable during its lifetime. Consider the following fragment:
```cpp
int x = 5, y = 7;
int *p = &x; // Binds p to point to x
int &r = x; // Binds r to x
p = &y; // Reassign p to point to y
r = y; // Assign y's value to x (var r)
```

## 10.8 Pass by Reference

r = y;

Does not bind r to the y variable. The declaration of r binds r to the x variable for the life of r. This statement simply assigns y's value to x via the reference r. In contrast, we may freely bind pointer variables to any variables we choose at any time.

A reference variable, therefore, in the examples provided here works like pointer that may be bound to a variable and may not be redirected to point anywhere else. Also, unlike pointers, nullptr may not be assigned to a reference variable. There are some other differences between references and pointers that we will not explore. Reference variables provide a simpler syntax than pointers that we do not need to use the pointer dereferencing operator (*) when working with references.

There is one other major difference between pointers and references—C++ adopted pointers as is in the C programming language, but C does not have references. C++ programmers often use library functions written in C, so it is important not to mix references with C code.

Section 10.8 reveals a very important practical application of pointers and references in their role of enabling pass by reference.

The default technique for passing parameters to functions is pass by value (see Section 9.3). C++ also supports pass by reference, also known as call by reference, which allows functions to alter the values of formal parameters passed by callers.

Consider Listing 10.16 (faultyswap.cpp), which uses a function that attempts to interchange the values of its parameters.

Listing 10.16: faultyswap.cpp
```cpp
#include <iostream>

using namespace std;

/*
* swap(a, b)
* Attempts to interchange the values of
* its parameters a and b. That it does, but
* unfortunately it affects local
* copies.
*/
void swap(int a, int b) {
int temp = a;
a = b;
b = temp;
}

/*
* main
* Attempts to interchange the values of
* two variables using faulty swap function.
*/
int main() {
int var1 = 5, var2 = 19;
cout << "var1 = " << var1 << ", var2 = " << var2 << endl;
}
```

The output of Listing 10.16 (faultyswap.cpp) is
```
var1 = 5
 var2 = 19
```

Unfortunately, the swap function interchanges copies of actual parameters, not actual parameters themselves. We really would like to write a function that interchanges the caller's variables. Pass by reference is necessary to achieve the desired effect. C++ can pass by reference in two ways: pointer parameters and reference parameters.

### 10.8.1 Pass by Reference via Pointers

Pointers (see Section 10.6) allow us to access the memory locations of variables. We can use this ability to modify the values of variables that are owned by its caller. Listing 10.17 (swapwithpointers.cpp) provides a correct version of variable interchange program.

Listing 10.17: swapwithpointers.cpp
```cpp
#include <iostream>

using namespace std;

/*
* swap(a, b
*/
void swap(int *a, int *b) {
int temp = *a;
*a = *b;
*b = temp;
}

int main() {
int var1 = 5, var2 = 19;
cout << "var1 = " << var1 << ", var2 = " << var2 << endl;
}
```

The output of Listing 10.17 (swapwithpointers.cpp) is
```
var1 = 5, var2 = 19
```
which is the result we were trying to achieve. The swap function can manipulate main's variables directly since we passed pointers to those variables. In Listing 10.17 (swapwithpointers.cpp):

- The formal parameters to swap, a and b, are pointers to integers; they are not integers. In order to access the integer value to the pointer refers, it must be dereferenced. That is why any use of a in swap's body is prefixed with the pointer dereferencing operator, *.
```cpp
int temp = *a;
```
assigns to the local variable temp the value to which a points. Since main passes the address of var1 as the first parameter in call to swap, in this case points to var, so *a is effectively another way to access the memory location of var in main. The function assigns main's var1 to temp.

- In swap's statement
```cpp
*a = *b;
```
since *a is effectively main's var1 variable and *b is effectively main's var2 variable, this statement assigns the value of main's var2 to its var1 variable.

- The swap function's
```cpp
*b = temp;
```
statement assigns the local temp value to main's var2 variable, since swap's b parameter points to main's var2.

- Within main, the call
```cpp
swap(&var1, &var2);
```
passes the addresses of its local variables to swap.

In reality, pass by reference is still using pass by value. Instead of passing copies of values, we are passing copies of addresses. In Listing 10.17 (swapwithpointers.cpp), for example, the values of addresses of var1 and var2 are copied to the formal parameters a and b. The difference is we are not attempting to reassign a or b, but are reassigning memory to which a and b point. Whether we use the original address or a copy of the address, it is still the address—the same number location in memory.

## 10.8.2 Pass by Reference via References

Both C and C++ support pass by reference with pointers (see Section 10.8.1). Since C++ programmers often use C libraries, C++ programmers must be familiar with the pointer technique for pass by reference. C++, however, provides a simpler way of implementing pass by reference using reference parameters. (See Section 10.7 for an introduction to reference variables.) Listing 10.18 (swapwithreferences.cpp) uses reference parameters in our variable interchange program.

### Listing 10.18: swapwithreferences.cpp
```cpp
#include <iostream>

using namespace std;

/*
* swap(a, b)
* Interchanges the values of memory
* referenced by its parameters a and b.
* It effectively interchanges the values
* of variables in the caller's context.
*/
void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

/*
* main
* Interchanges the values of two variables
* using the swap function.
*/
int main() {
    int var1 = 5, var2 = 19;
    cout << "var1 = " << var1 << "," var2 = " << var2 << endl;
    swap(var1, var2);
    cout << "var1 = " << var1 << "," var2 = " << var2 << endl;
}
```

The syntax of Listing 10.18 (swapwithreferences.cpp) is a bit cleaner than that of Listing 10.17 (swapwithpointers.cpp).
