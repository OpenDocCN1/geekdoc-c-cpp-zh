# 12.5 Randomly Permuting a Vector

Section 12.4 showed how we generate all the permutations of a vector in an orderly fashion. Often, however, we need to produce one of these permutations chosen at random. For example, we may need to randomly rearrange the contents of an ordered vector so we can test a function to see if it will produce the original sequence. We could generate all the permutations, each one in a vector of vectors, and select a permutation from that vector of vectors. This approach is very inefficient, especially as the length of the vector to perm grows. Fortunately, we can randomly permute the contents of a vector easily and quickly. Listing 12.8 (randompermute.cpp) contains a function named permute that randomly permutes the elements of the vector.

