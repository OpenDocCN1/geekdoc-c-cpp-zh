The "assignment to zero" of the virtual methods in the Shape class make them special; they are called pure virtual methods or pure virtual functions. This special syntax signifies that these methods have no implementations. It is not possible to provide a body for these methods. A class that contains at least one pure virtual method is an abstract class. It is not possible to create an instance of an abstract class.
