As these examples show, you may use vector objects instead of arrays without risking bugs or not being able to use libraries that only deal with arrays.

If you are to be using an array and need to use a function that expects a vector instead, it is easy to make a vector out of an existing array. If arr is a raw integer array containing n elements, the statement

```
vector<int> vec(arr, arr + n);
```

creates a new vector object with elements that are identical to arr. One disadvantage of this technique is that it copies all the elements in arr to a new dynamic memory managed by the vector.

We will see in Chapter 18 that it is relatively easy to write a function in a generic way so that it can accept either a vector or an array with equal efficiency.

Programmers manage arrays and associated pointers very carefully because array and pointer misuse is a common source of difficulty to find and repair bugs in programs. Vectors effectively take care of the memory management problems that plague arrays. As have seen, it is easy to adapt to a context that requires an array. For these reasons, additional information about arrays is restricted to Appendix F, and the remainder of this chapter continues on C++ vectors rather than arrays.

# 11.3 Prime Generation with a Vector

Listing 11.12 (fasterprimes.cpp) uses an algorithm developed by the Greek mathematician Eratosthenes who lived from 274 B.C. to 195 B.C. The principle behind the algorithm is simple: Make a list of all the integers and two. Two is a prime, but any multiple of two cannot be a prime (since it has two as a factor). Go through the list and mark out all multiples of two (4, 6, 8, ...). Move to the next number in the list (in this case, three). If it is not marked out, it must be prime, so go through the rest of the list and mark out all multiples of that number (6, 9, 12, ...). Continue this process until you have listed all the primes you want.

# 11.3. PRIME GENERATION WITH A VECTOR

```cpp
// Initially all numbers are prime until proven otherwise
vector<bool> nonprimes(MAX); // Global vector initialized to all false

int main() {
    clock_t start_time = clock(); // Record start time

    // First number is 2; 0 and 1 are not prime
    nonprimes[0] = nonprimes[1] = true;

    // Start at the first prime, 2.
    for (int i = 2; i < MAX; i++) {
        // See if i is prime
        if (!nonprimes[i]) {
            cout << i << " ";
            // It is prime, so eliminate all of its
            // multiples that cannot be prime
            for (int j = i * 2; j < MAX; j += i)
                nonprimes[j] = true;
        }
    }
    cout << endl; // Move cursor to next line
    // Print the elapsed time
    cout << "Elapsed time: " << static_cast<double>(clock() - start_time) / CLOCKS_PER_SEC << " seconds" << endl;
}
```

# Listing 11.13: fasterprimes.cpp

```cpp
#include <iostream>
#include <vector>
#include <ctime>
#include <cmath>

using namespace std;

// Display the prime numbers between 2 and 500,000 and time it takes
// Largest potential prime considered
const int MAX = 2000000;

// Each position in the vector indicates if the number is not prime:
// false means "prime", and true means "composite".
// Initially all numbers are prime until proven otherwise
vector<bool> nonprimes(MAX); // Global vector initialized to all false

void countprimes() {
    int count = 0;
    clock_t start_time = clock(); // Record start time
    for (int value = 2; value <= MAX; value++) {
        // See if value is prime
        bool is_prime = true; // Provisionally, value is prime
        // Try all possible factors from 2 to the square root
        int root = sqrt(value);
        for (int trial_factor = 2; trial_factor <= root; trial_factor++) {
            if (value % trial_factor == 0) {
                is_prime = false;
                break;
            }
        }
        if (is_prime)
            count++; // Count the prime number
    }
    cout << "Count = " << count << " ";
    cout << "Elapsed time: " << static_cast<double>(clock() - start_time) / CLOCKS_PER_SEC << " seconds" << endl;
}

void primes2() {
    int count = 0;
    clock_t start_time = clock(); // Record start time
    // First number is 2; 0 and 1 are not prime
    nonprimes[0] = nonprimes[1] = true;

    for (int i = 2; i < MAX; i++) {
        // See if i is prime
        if (!nonprimes[i]) {
            count++; // It's prime, so count it
            // It is prime, so eliminate all of its
            // multiples that cannot be prime
            for (int j = i * 2; j < MAX; j += i)
                nonprimes[j] = true;
        }
    }
    cout << "Count = " << count << " ";
    cout << "Elapsed time: " << static_cast<double>(clock() - start_time) / CLOCKS_PER_SEC << " seconds" << endl;
}

void primes3() {
    int count = 0;
    clock_t start_time = clock(); // Record start time
    for (int value = 2; value <= MAX; value++) {
        // See if value is prime
        bool is_prime = true; // Provisionally, value is prime
        // Try all possible factors from 2 to the value - 1
        for (int trial_factor = 2; trial_factor < value; trial_factor++) {
            if (value % trial_factor == 0) {
                is_prime = false;
                break;
            }
        }
        if (is_prime)
            count++; // Count the prime number
    }
    cout << "Count = " << count << " ";
    cout << "Elapsed time: " << static_cast<double>(clock() - start_time) / CLOCKS_PER_SEC << " seconds" << endl;
}

int main() {
    countprimes();
    primes2();
    primes3();
}
```
