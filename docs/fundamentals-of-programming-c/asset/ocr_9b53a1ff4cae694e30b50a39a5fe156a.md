# 5.5. THE IF/ELSE STATEMENT

```
// Get two integers from the user
cout << "Please enter two integers to divide:";
cin >> dividend >> divisor;
// If possible, divide them and report the result
if (divisor != 0) {
    cout << dividend << "/" << divisor << " = "
         << dividend/divisor << endl;
} else {
    cout << "Division by zero is not allowed" << endl;
}
```

A program run will execute exactly one of either the if body or the else body. Unlike Listing 5.2 (betterdivision.cpp), a message is always displayed.
