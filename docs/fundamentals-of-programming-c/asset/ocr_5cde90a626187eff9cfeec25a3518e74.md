The compiler will instantiate two scale functions:

```
// Instantiated by the compiler due to scale<double, 3>:
double scale(const double& value) {
  return value * 3;
}
```

and

```
// Instantiated by the compiler due to scale<int, 4>:
int scale(const int& value) {
  return value * 4;
}
```

The types of non-type parameters permitted by C++ are very limited. Integral types (int, unsigned_long, etc.) are acceptable, as pointers and references. Other types such as floating-point and programmer-defined types may not be non-type parameters.

The C++ Standard Library contains many generic functions, some of which we have seen already (all in the std namespace):

+   * max—computes the maximum of two values
* min—computes the minimum of two values
* swap—interchanges the values of two variables

# 18.2 Class Templates

Function templates (Section 18.1) enable us to build generic functions. C++ supports class templates as well. With class templates we can specify the pattern or structure of a class of objects in a type-independent way. The template mechanism is a key tool for creating generic types.

As a simple example, consider a basic Point class that represents two-dimensional point objects. We can approximate with double-precision floating-point values. A point on a graphical display, the other uses integer coordinates because screen pixels are discrete, have number locations.
