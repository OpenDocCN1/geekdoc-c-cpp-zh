Realistic decomposition of Listing 9.17 (timetable.cpp) is extreme. The relative simplicity of the program does not really justify eight separate functions each with a narrow focus; however, more complex systems are used in this manner. Not only does Listing 9.17 (timetable.cpp) give us insight into how we can handle a complicated problem and break it down into simpler, more manageable pieces, we can use the program to understand how the function invocation process works.
