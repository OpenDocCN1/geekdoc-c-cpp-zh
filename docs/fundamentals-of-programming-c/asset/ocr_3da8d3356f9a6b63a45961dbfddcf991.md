# 9.8 Exercises

1. Is the following a legal C++ program?

```
int proc(int x) {
    return x + 2;
}
int proc(int n) {
    return 2*n + 1;
}
int main() {
    int x = proc(5);
}
```

2. Is the following a legal C++ program?

```
int proc(int x) {
    return x + 2;
}
int main() {
    int x = proc(5),
    y = proc(4);
}
```

3. Is the following a legal C++ program?

```
#include <iostream>
void proc(int x) {
    std::cout << x + 2 << std::endl;
}
int main() {
    int x = proc(5);
}
```
