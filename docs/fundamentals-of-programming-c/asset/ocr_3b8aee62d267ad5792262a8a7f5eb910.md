# 5.7. NESTED CONDITIONALS

```
using namespace std;

int main() {
    int value;
    cout << "Please enter an integer value in the range 0..10: ";
    cin >> value;
    if (value >= 0) // First check
        if (value <= 10) // Second check
            cout << "In range";
    cout << "Done" << endl;
}
```

Listing 5.6 (checkrange.cpp) behaves as follows:

+   * The program checks the value >= 0 condition. If value is less than zero, the executing program does not evaluate the second condition and does not print In range, it immediately executes the outer statement if which prints Done.
* If the executing finds value to be greater than or equal to zero, it checks the second condition. If the condition is met, it displays the In range message; otherwise, it is not. Regardless, the program Done before it terminates.

For the program to display the In range both of this nested if must be met. Said another way, the first condition and the second condition must be met for the In range message to be printed. From this perspective, we can rewrite the program to behave with way only one if statement, as Listing 5.7 (newcheck.cpp) shows.

# Listing 5.7:newcheck.cpp

```
#include <iostream>

using namespace std;

int main() {
    int value;
    cout << "Please enter an integer value in the range 0..10: ";
    cin >> value;
    if (value >= 0 && value <= 10)
        cout << "In range";
    cout << "Done" << endl;
}
```

Listing 5.7 (newcheck.cpp) uses a logical && to check both conditions at the same time. Its logic is simpler, using only one if statement, at the expense of a slightly more complex Boolean expression in its condition. The second version is preferable here because simple logic is a desirable goal.

Sometimes a program's logic cannot be simplified in Listing 5.7 (newcheck.cpp). In Listing 5.8 (enhancedcheck.cpp) if statement alone is insufficient to implement the necessary behavior.
