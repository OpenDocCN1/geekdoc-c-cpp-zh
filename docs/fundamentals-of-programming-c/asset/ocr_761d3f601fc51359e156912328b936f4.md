Figure 11.7: Pointer arithmetic. Incrementing pointer p moves it to the next element in the array.

Going back to the print function that uses pointers:
void print(int *begin, int *end) {
    for (int *elem = begin; elem != end; elem++)
        cout << *elem << ' ';
    cout << endl;
}

the pointer elem points to the same element as begin points, and within the loop it moves to the next element repeatedly until it the last element. A caller could invoke the function as

```
int list[25]; // Allocate a static array
for (int i = 0; i < 25; i++)
    list[i] = rand() % 1000; // Fill with pseudandom values
print(list, list + 25); // Print the elements of list
```

The advantage of the begin/end pointer approach is that it allows a programmer to parse a slice of the array. If we want to print the elements of the array from index 3 to 7, call the function as
print(list + 3, list + 8); // Print elements at indices 3, 4, 5, 6, 7
