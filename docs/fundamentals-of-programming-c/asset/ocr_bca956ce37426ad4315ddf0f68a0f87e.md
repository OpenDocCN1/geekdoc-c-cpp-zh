Listing 19.3 (callchainexception.cpp) is specially crafted to provide insight into the program's exact execution. Each function prints a message at its beginning and end so we can see when the code within a function is active. Each function also declares a local Tracker object which is identified by the name of function and automatically destroys the object when the function returns to caller. These local objects, however, have a lifetime that mirrors the lifetime of the function they manage. Listing 19.3 (callchainexception.cpp) declares a global Tracker. An executing function creates global objects before it calls main and automatically destroys them after main completes.

Listing 19.3 (callchainexception.cpp) covers the vector nums, declared in main. During this call, the main function has no control over the process function's attempt to access an element outside of the range. The process function, however, does not attempt to access any elements within the vector that main supplies. Instead, process passes the vector to the find function. It is in find that calls the at method at an out-of-bounds index, which will throw an exception. Unlike in 19.2 (vectorexception.cpp), the method that calls vector<int>::at does not so within a try/catch block. This means find cannot catch any exceptions that vector<int>::at might
