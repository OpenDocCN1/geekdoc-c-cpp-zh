The following function will print the contents of a vector of any:

```
/*
* print
* Prints the contents of a vector
* a is the vector to print.
* a is not modified.
 */
template <typename T>
void print(const vector<T>& a) {
    int n = a.size();
    cout << '<';
    if (n > 0) {
        cout << a[0]; // Print the first element
        for (int i = 1; i < n; i++)
            cout << ', ' << a[i]; // Print the rest
    }
    cout << '>';
```

The restriction is here that the elements in the vector must be printed by the cout object out <<.
