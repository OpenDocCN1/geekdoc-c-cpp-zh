List 12.5 (searchcompare.cpp) applies linear and binary search to vectors of various sizes and displays the results. The vector sizes range from 0 to 5000. The program uses the **time_execution** function to compute the running times of linear search and binary search. The **main** function directs which search_time_execution should perform by passing the first argument a pointer to the appropriate function. The second parameter to **time_execution** specifies the number of runs the function should execute to compute the average. Notice that in this program we run linear search over five runs and binary search over 25 runs. We subject the binary search to more runs since it executes so quickly, and 5 runs are not an adequate sample to evaluate its performance, especially for smaller vectors where the binary search execution time is close to the resolution of the timer. Besides, since binary search executes so quickly, we can easily afford to let **time_execution** run more tests and compute a more accurate average.
