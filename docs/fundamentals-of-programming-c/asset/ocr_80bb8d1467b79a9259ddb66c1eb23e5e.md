# F.9. THE SIZEEOF OPERATOR

```
// Allocate a modest-sized array to begin with
numbers = new double[capacity];

cout << "Please enter any number of non-negative values"
cout << "(negative value ends the list): ";
cin >> input;

while (input > 0) { // Continue until negative number entered
    if (size < capacity) { // Room left to add an element?
        capacity += CHUNK; // Expand array
        double temp = new double[capacity]; // Allocate space
        for (int i = 0; i < size; i++) { // Copy existing values
            temp[i] = numbers[i];
        }
        delete [] numbers; // Free up space
        numbers = temp; // Update numbers to new location
        cout << "Expanding by " << CHUNK << endl;
    }
    numbers[size] = input; // Add number to array at last position
    size++;
    sum += input; // Add to running sum
    cin >> input; // Get next number
}

if (size > 0) { // Can't average less than one number
    cout << "The average of ";
    for (int i = 0; i < size - 1; i++) {
        cout << numbers[i] << ", ";
    } // No comma following last element
    cout << numbers[size - 1] << " is ";
    cout << sum/size << endl;
} else {
    cout << "No numbers to average" << endl;
}
delete [] numbers; // Free up the space held by numbers
```

# F.9 The sizeof Operator

The size of an array is fixed at compile time. The C++ sizeof operator computes the amount of memory in bytes that a static array occupies.

```
int list[100];
set[] = { 1, 2, 3, 4, 5 };
cout << "list: " << (sizeof list) << ", set: " << (sizeof set) << endl;
```

prints

```
list: 400, set: 20
```
