Next, we consider binary search:

```
int binary_search(const vector<int> &a, int seek) {
    int n = a.size();              // Number of elements
    first = 0;                     // Initially the first element in vector
    last = n - 1;                  // Initially the last element in vector
    mid;                            // The middle of the vector
    while (first <= last) {
        mid = first + (last - first + 1)/2;
        if (a[mid] == seek)             // Found it
            return mid;
        else if (a[mid] > seek) {
            last = mid - 1;             // continue with 1st half
        } else { // a[mid] < seek
            mid = mid + 1;             // continue with 2nd half
        }
    }
    return -1;                     // Not there
}
```

We determined that in the worst case the binary_search iterates log2n times the vector contains n elements. These two initializations are performed once per call. Most of the actions within the loop log2n times, except that only return statement can be executed by call, and in the if/else statement only one path can be chosen per iteration.
