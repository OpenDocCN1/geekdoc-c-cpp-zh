Importantly, the statement

```
a = b;
```

does not mean a and b refer to the same box (memory location). After this statement a and b still refer to separate boxes (memory locations). It simply means the value stored in b's box (memory location) has been copied to a's box (memory location), and a b remain distinct boxes (memory locations). The original value found in a's box is overwritten when the contents of b's box are copied into a. After the assignment of b to a, the reassignment of b to 4 does not affect a.
