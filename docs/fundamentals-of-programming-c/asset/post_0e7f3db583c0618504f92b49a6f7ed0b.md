## Chapter 5

### Conditional Execution
All the programs in the preceding chapters execute the same statements regardless of the input, if provided to them. They follow a linear sequence: Statement 1, Statement 2, etc., until the last statement is executed. Linear programs like these are very limited in the problems they can solve. This introduces constructs that allow statements to optionally execute depending on the context.

### 5.1 Type bool
Arithmetic expressions evaluate to numeric values; a Boolean expression, sometimes called predicate, evaluates to true or false. While Boolean expressions appear limited on the surface, they are essential for building useful programs. C++ supports the non-numeric data bool, which stands for Boolean. The term Boolean comes from the name of George Boole, a branch of discrete mathematics dedicated to the study and manipulation of logical expressions. Compared to numeric types, the bool type is very simple in that it can represent only two values: true or false.

Listing 5.1: boolvars.cpp
```
#include <iostream>

using namespace std;

int main() {
    // Declare some Boolean variables
    bool a = true, b = false;
    cout << "a = " << " " << b << endl;
    // Reassignment
    a = false;
    cout << "a = " << " " << b << endl;
    // Mix integers and Booleans
    a = 1;
    b = 1;
}
```

It is important to note that Visual C++ issues warnings for the assignment statements in Listing 5.1 (boolvars.cpp). The simplest Boolean expressions are false and true, the bool literals. A Boolean variable is also a Boolean expression. An expression comparing numeric for equality or inequality is also a Boolean expression. The simplest kinds of Boolean expressions use relational operators to compare two values.
