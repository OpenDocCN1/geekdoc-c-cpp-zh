# Generic Programming

The flexible sorting examples in Listing 12.2 (flexibleint.cpp), Listing 16.5 (loggingflexiblesort.cpp), and Listing 17.20 (polymorphsort.cpp) allow us to arrange the elements in integers in creative ways and perform other interesting activities such as logging. These examples demonstrate the power of function pointers, inheritance, and polymorphism. As flexible and powerful as these techniques are, they all contain one major limitation: they deal with vectors of integers only. Consider the Compar class from Listing 17.23 (compar.h) and Listing 17.19 (compar.cpp), and the "flexible" selection_sort function from Listing 17.23 (loggingsort.cpp). The selection_sort function accepts a vector of integers and a Compar reference. What if we need to sort a vector of double-precision floating-numbers or a vector of string objects? Unfortunately, all of this "flexible" code cannot handle this seemingly minor variation.

In this chapter we show C++ template mechanism enables programmers to develop truly generic algorithms and data structures. We will see how the standard C++ library has embraced the template technology to provide a wealth of generic algorithms and data structures that greatly assist developers in the construction of quality software.

# 18.1 Function Templates

Consider the following comparison function found in Listings 12.2, 16.5, and 17.23:

```
/*
* less_than(a, b)
* Returns true if a < b; otherwise, returns
* false.
 */
bool less_than(int a, int b) {
    return a < b;
}
```
