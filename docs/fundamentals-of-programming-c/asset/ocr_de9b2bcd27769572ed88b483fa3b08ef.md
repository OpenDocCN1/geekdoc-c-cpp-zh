What is the nature of the machine code generated by the execution t1.get()? The compiler translates this higher-level expression into the machine language instruction that causes the execution to jump to another part of the code. Where does the program's execution jump? The variable t1's declared type is Text, the program's execution jumps to the compiled Text::get method (also the address of t1 is passed as the implicit parameter to the method so that the compiled code can access t1's text field).

For the expression t2.get(), the program's execution jumps FancyText's compiled get method, passing the address of t2 as the implicit parameter.

When the compiler can determine which method to execute based on the declared type of object, the process is known as static binding or early binding. Static binding is used in all cases for non-virtual methods and in the cases we have seen so far virtual methods.

The situation is different if we use pointers to access the objects of themselves. Consider the following code:

```
Text t1("ABC");
FancyText t2("XYZ", "[", "]", ");
cout << t1.get() << " " << t2.get() << endl;
```
