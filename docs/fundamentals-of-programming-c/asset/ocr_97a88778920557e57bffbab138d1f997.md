+   * A function that uses local variables can be tested correctly in isolation from other functions, since others do not affect the behavior of this function. This function's behavior is only influenced by its parameters, if it has.

The exclusion of global variables from a function leads to functional independence. A function that depends on information outside of its scope to perform its task is a dependent function. When a function operates on a global variable it depends on that global variable being in the correct state for the function to complete its task correctly. Nonprofit programs that contain many functions are more difficult to extend. A truly independent function that uses no global variables and uses no programmer-defined functions to help it be tested correctly in isolation. Additionally, an independent function can be copied from one program, pasted into another program, and without modification. Functional independence is a desirable quality.
