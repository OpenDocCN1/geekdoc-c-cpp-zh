As previously mentioned, however, for loop control should be restricted to its header, and the use of break, continue, and goto within for loops should be avoided.

Any for loop can be rewritten with a while loop and behaveally identical. For example, consider the for loop

```
for (int i = 1; i < 10; i++)
cout << i << endl;
```

and consider the while loop behaves exactly the same way:

```
int i = 1;
while (i <= 10) {
  cout << i << endl;
  i++;
}
```

Which is better? The for loop conveniently packages the loop control information in its header, but in the while loop information is distributed throughout the small section of code. The for loop provides a better organization of the loop control. Does one outperform the other? No, most compilers produce essentially the same code for both constructs. Thus, the for loop is preferred in example.

# 7.5 Summary

+   - The switch statement is an alternative to some multi-way if/else statements.

+   - Not all multi-way if/else statements can be converted directly to a switch statement.

+   - The expression to evaluate within the switch statement must evaluate to an integer value (int, short, long, char, or bool).

+   - The cases within a switch statement must be integral literals or constants (int, short, long, char, or bool). Specifically, case labels may not be variables or other expressions.

+   - Program execution jumps to the case with the value that matches the switch expression.

+   - Once a case is matched, program execution continues within the switch statement until a break is encountered.

+   - If no case labels match the switch expression, the program execution jumps to the default label, if it is present. If no case labels and no default label is present, no part of the switch body is executed.

+   - The conditional operator is an expression that evaluates to one of two values depending on a condition.

+   - The do/while loop is a bottom-checking loop, unlike the while loop, which is a top-checking loop.

+   - The body of a do/while loop is always executed at least once, regardless of the condition. The body of a while loop is not executed if the condition is initially false.
