# 19.3 Custom Exceptions

> **CAUTION! SECTION UNDER CONSTRUCTION**

The standard C++ library has a limited number of standard exceptions. We can create our custom exceptions for specialized error handling that our applications may require. Using 19.6 (customfilereadexcept.cpp) defines a custom class, `FileNotException`, derived from the standard exception class.

# Listing 19.6: customfilereadexcept.cpp

```
#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;
// Exception object to thrown when a client attempts to
// open a file via a name that does not correspond to a
// file in the current working directory.
class FileNotFoundException : public exception {
    string message; // Identifies the exception and filename
public:
    // Constructor establishes the exception object's message
    FileNotFoundException(const string& fname):
        message("\"" + fname + "\ not found") {}

    // Reveal message to clients
    const char *what() const {
        return message.c_str();
    }
};
// Creates and returns a vector of integers from data stored
// in a text file.
// filename: the name of the text file containing the data
// Returns a vector containing the data in the file, if possible
vector<int> load(const string& filename) {
    ifstream file(filename);
    if (file.good()) { // Open the file for reading
// Did the file open successfully?
        // Initially empty vector
        vector<int> result;
        int n;
        file >> n; // Size of data set
        for (int i = 0; i < n; i++) {
            int value;
            file >> value; // Read in a data value
            result.push_back(value); // Append it to the vector
        }
        file.close(); // Close the file
        return result; // Return the populated vector
    }else // Could not open the text file
    throw FileNotFoundException(filename);
}
```
