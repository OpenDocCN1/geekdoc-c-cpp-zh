All C++ standard exception classes have std::exception as their direct or indirect base class. C++ does not require exception objects to be derived from exception: in fact, primitive types such as int and char can be thrown and caught. Because of this, the "catch all" exception clause is

```
catch (...) {
    // Catches any exceptions caught by more specific
    // catch blocks in this try/catch block
}
```

The ellipses (...) stand for any exception of type.
Any function or method can throw an exception. Given an exception of type E, the statement to do is:

```
throw E();
```

# 19.6 Using Exceptions

Exceptions should be reserved for uncommon errors. For example, the following code adds up all the elements in an integer vector named vec:

```
int sum = 0, n = vec.size();
for (int i = 0; i < n; i++) {
    sum += vec[i];
}
cout << "Sum = " << sum << endl;
```

This loop is fairly typical. Another approach uses exceptions:

```

int i = 0;

    cout << "Sum = " << sum << endl;
```
