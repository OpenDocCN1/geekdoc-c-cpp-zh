# F.10: COPYING AN ARRAY

```
int a[10], *b;      // Declare two arrays, one dynamic
for (int i = 0; i < 10; i++) // Populate one of them
    a[i] = i;                // a is filled with increasing values
b = a;                      // Make a copy of array a?
```

but b is not a copy of a b aliases, so changing the contents of a will also change the contents of b identically, since b refers to the exact memory to which a refers. Figure F.7 illustrates the aliasing.

![](bbox=[0.363, 0.305, 0.686, 0.545])

Figure F.7: Faulty array copy

The following code shows the proper way to make a copy of a:

```
int a[10], *b;      // Declare two arrays, one dynamic
for (int i = 0; i < 10; i++) // Populate one of them
    a[i] = i;                // a is filled with increasing values
// Really make a copy of array a
b = new int[10];         // Allocate b
for (int i = 0; i < 10; i++)
    b[i] = a[i];
```

Separate data for the dynamic array must be allocated, and then each from the original array must be copied into the new array. Figure F.8 shows how this process works.

It is important to note that since the code allocates b dynamically with new, elsewhere within the program should eventually use delete to free b's space when it is no longer used. Failure to properly allocate b constitutes a memory leak.
