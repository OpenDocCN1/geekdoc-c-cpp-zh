# 19.2. EXCEPTION EXAMPLES

What makes the exception code

```
try {
    cout << nums.at(input) << endl;
}
catch (exception& e) {
    cout << e.what() << endl;
}
```

better than the conditional code

```
if (0 < input && input < nums.size()) {
    cout << nums.at(input) << endl;
} else {
    cout << "Vector out of bounds exception" << endl;
}
```

is not immediately obvious from this simple example. To see the real capabilities of exceptions, consider Listing 19.3 (callchainexception.cpp)

# ### Listing 19.3: callchainexception.cpp

```
#include <iostream>
#include <vector>
#include <string>

using namespace std;

// Used to keep track of object creation and destruction
class Tracker {
    string name;
public:
    Tracker(const string& s) : name(s) {
        cout << "Creating Tracker " << name << endl;
    }
    ~Tracker() {
        cout << "Destroying Tracker " << name << endl;
    }
};

bool find(const vector<int>& vec, int lower, int upper) {
    cout << "---Finding finding------" << endl;
    Tracker obj("find"); // Local tracking object
    bool result = false; // Not by default
    int seek;
    // What to look for
    cout << "Enter item to locate: ";
    cin >> seek;
    for (int i = lower; i < upper; i++) {
        if (vec.at(i) == seek) {
            result = true;
            break;
        }
    }
    cout << "---Leaving find------" << endl;
    return result;
}
```
