# ## Arrays

An array in C++ is a variable that refers to a block of memory that can hold multiple values simultaneously: an array, therefore, represents a collection of values. An array has a name, and the values it contains are accessed via their position within the block of memory designated for the array. An array stores a sequence of values, and the values must all be of the same type. A collection of values all of the same type is said to be homogeneous.

# ### F.1 Declaring and Using Arrays

Like any other variable, an array can be local or global, and must be declared before it is used. The following code fragment declares an array variable **list** that is assigned to a block of memory that can hold 25 integer values:

```
int list[25];
```

At the point of an array declaration the square brackets indicate the amount of space reserved for the array's elements. The compiler generates machine code that ensure space for 25 integers will be reserved at time. On many systems integers are four bytes each, in which case an array of 25 integers would occupy 100 bytes of memory when the program executes. The exact amount of memory depends on the size of an integer for a particular system.

**If list** is declared within a function, the array's contents are undetermined. This means that even space is set aside for 25 elements, the values of those individual elements are unspecified. If the array is declared as a global variable, **list** will initially contain 25 zeros.

Once we declare an array, we can access its elements using the square operator:

```
int list[3];      // Declare an array of three ints
list[0] = 5      // Make the first element 5
list[1] = -3     // Make the second element -3
list[2] = 12     // Make the last element 12
```

This code fragment shows that the square brackets used after the point of declaration allow us to access an individual element based on element's position within the block of memory assigned to the array. The number within the square brackets indicates the distance from the beginning of the array.
