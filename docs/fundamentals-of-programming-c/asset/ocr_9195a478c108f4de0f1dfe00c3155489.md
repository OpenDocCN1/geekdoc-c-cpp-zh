The typedef keyword changes the meaning of the statement that instead of declaring a variable defines a simpler name for the type. typedef statements usually appear near the top of a source file and often have global scope. It is uncommon to see a local typedef statement within a function body.

Given the typedef statement defining the new type Matrix, we may express the parameter for the print function simply:

```
void print(const Matrix& m) {
    for (const vector<double>& row : m) ( // For each row
        for (int elem : row) // For each element in row
            cout << setw(5) << elem;
        }
    return sum;
}
```

We can take advantage of the type inference of C++11 to simplify the print function further (see Section 3.9):

```
void print(const Matrix& m) {
    for (auto row : m) { // For each row
        for (int elem : row) // For each element in row
            cout << setw(5) << elem;
    }
    return sum;
}
```

Here we replace the explicit const vector<double>& with the word auto. The compiler is able to infer the type of the variable from the context: m is a Matrix (that is, a vector<vector<double>>), so row must be an element of the 2D vector (which is itself a 1D vector).

#include <iomanip>
#include <vector>

// Allow the user to enter the elements of a matrix
void populate(Matrix& m) {
    cout << "Enter " << m.size() << " rows of the matrix: " << endl;
    for (unsigned row = 0; row < m.size(); row++) {
        cout << "Row " << row << " enter " << m[row].size() << " values:";
        for (double& elem : m[row])
            cin >> elem;
    }
