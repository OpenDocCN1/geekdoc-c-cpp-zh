We rewrite Listing 2.4 (arrow.cpp) to achieve the same effect with one long print statement as Listing 2.5: arrow2.cpp

Listing 2.5: arrow2.cpp

```
#include <iostream>

using namespace std;

int main() {
    cout << " * " << endl;
    cout << " ***** " << endl;
    cout << " * " << endl;
    cout << "  *  " << endl;
    cout << " * " << endl;
}
```

At first, Listing 2.4 (arrow.cpp) and Listing 2.5 (arrow2.cpp) may appear to be identical, but upon closer inspection of the new program we see that cout appears only once within main, and only one statement.
