# 6.7. EXERCISES

7. How many asterisks does the following code fragment print?

```
int a = 0;
while (a < 100) {
    cout << "*";
    a++;
}
cout << endl;
```

8. How many asterisks does the following code fragment print?

```
int a = 0;
while (a < 100) {
    int b = 0;
    while (b < 55) {
        cout << "*";
        b++;
    }
}
cout << endl;
```

9. How many asterisks does the following code fragment print?

```
int a = 0;
while (a < 100) {
    if (a % 5 == 0) {
        cout << "*";
    }
    a++;
}
cout << endl;
```
