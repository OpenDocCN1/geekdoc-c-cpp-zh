The following code defines a function that computes the greatest common divisor of two integers.
It determines a definite factor (divisor) common to its parameters:

```
int qcd(int num1, int num2) {
  // Determine the smaller of num1 and num2
  int min = (num1 < num2) ? num1 : num2;
  // 1 is definitely a common factor to all ints
  int largestFactor = 1;
  for (int i = 1; i <= min; i++) {
    if (num1 % i == 0 && num2 % i == 0)
      largestFactor = i; // Found larger factor
  }
  return largestFactor;
}
```
