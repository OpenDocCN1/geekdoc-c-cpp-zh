# 3.1 Integer Values

The number (4) is an example of a numeric value. In mathematics, 4 is an integer value. Integers are whole numbers, which means they have no fractional parts, and an integer can be positive, negative, or zero. Examples of integers include 4, -19, and -1005. In contrast, 4.5 is not an integer, since it is not a whole number.

C++ supports a number of numeric and non-numeric values. In particular, C++ programs can use integer values. It is easy to write a C++ program that presents the number four, as Listing 3.1 (number4.cpp) shows.

```
Listing 3.1: number4.cpp
#include <iostream>
using namespace std;

int main() {
 cout << 4 << endl;
}
```
