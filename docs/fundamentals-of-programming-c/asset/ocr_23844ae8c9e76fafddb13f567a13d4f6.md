During this particular run we see that in 1,000,000 attempts the program generates the value 5 on average 99889.9 times and 9995 on 100033 times. Both of these amounts nearly equal the expected 100000 target. Averaging the 10 trials, we see that neither the count for 5 nor 9995 is biased to be greater than less than the other. In some trials the program generates 5 slightly less than 100000 times, and in others it appears slightly greater than 100,000 times. This is true for 9995. These multiple trials show that in 1,000,000 iterations the program consistently generates 5 approximately 100,000 times and 9995 approximately 100,000 times showing that the pseudorandom numbers generated by the Mersister object in conjunction with the distribution object are much better uniformly distributed than those produced by rand with the modulus operation.

In Notice 13.10 (highqualityrandom.cpp) how the three objects work together:

+   - The uniform_int_distribution object produces a pseudorandom number by the mt19937 generator object. The mt19937 object generates a pseudorandom number, and the uniform_int_distribution constrains this pseudorandom number to the desired range.
- Programmers create an mt19937 with a random_device object. The random_device object provides the seed, potentially from a hardware source, to the mt19937 generator object. We can also pass a fixed integer value to mt19937 constructor if we want the generator to produce a perfectly reproducible sequence of values; for example, the following code fragment

