# 5.7. NESTED CONDITIONALS

```
int main() {
    int value;
    cout << "Please enter an integer value in the range 0...10": ";
    cin >> value;
    if (value >= 0) // First check
        if (value <= 10) // Second check
            cout << " is acceptable";
        else
            cout << " is too large";
    else
        cout << " is too small";
    cout << endl;
}
```

Listing 5.8 (enhancedchecker.cpp) provides a more specific message instead of a simple notification of acceptance. The program prints exactly one message based on the value of the variable. A single if or if/else statement cannot choose from more than two execution paths.

Listing 5.9 (binaryconversion.cpp) uses a series of statements to print a 10-bit binary representation the binary equivalent of a decimal integer supplied by the user. (Chapter D provides some background information about the binary number.) We use if/else statements to print the individual digits left to right, essentially assembling the sequence of bits that represents the binary number.

# Listing 5.9: binaryconversion.cpp

```
#include <iostream>
using namespace std;

int main() {
    int value;
    // Get number from the user
    cout << "Please enter an integer value in the range 0...1023": ";
    cin >> value;
    // Integer must be less than 1024
    if (0 <= value && value < 1024) {
        if (value >= 512) {
            cout << 1;
            value %= 512;
        }
        else
            cout << 0;
        if (value >= 256) {
            cout << 1;
            value %= 256;
        }
        else
            cout << 0;
            if (value >= 128) {
                cout << 1;
                value %= 128;
            }
            else
                cout << 0;
    }
    cout << 0;
}
```
