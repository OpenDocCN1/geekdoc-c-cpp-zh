Observe that in order to use setw the compiler needs to be aware of it. The needed information about setw is not found in the iomanip header file, so an additional preprocessor include directive is required:

```
#include <iomanip>
```

The setw manipulator "conditions" the output stream for the next item to be printed. The values passed to the "conditioned" stream are all right justified within the number of spaces specified by setw.
