Section 10.8 indicates that call-by-value parameter passing is preferred to call-by-reference parameter passing. Because using a function passing by value cannot modify the actual variable passed to the caller. Observe that our new print function declares the formal parameter v to be a const reference. This means the function cannot modify the actual parameter by the caller. A vector object with a const reference allows to achieve the efficiency of passing with the safety of pass by value

Like the print function, the sum function in List 11.7 (vector.cpp) does not intend to modify the contents of its vector parameter. The sum function only looks at the vector's contents, vector parameter should be declared as a const reference. If a function's purpose is to modify a vector, the reference should not const.
