## More Arithmetic Operators

As Listing 4.12 (enhancedint.cpp) demonstrates, an executing program can change a variable's value by performing some arithmetic on its current value. A variable may increase one or decrease by five. The statement

```cpp
x = x + 1;
```

increments x by one, making it one bigger than it was before this statement was executed. C++ has a shorter statement that accomplishes the same effect:

```cpp
x++;
```

This is the increment statement. A similar decrement statement is available:

```cpp
x--; // Same as x = x - 1;
```

These statements are more precisely post-increment and post-decrement operators. There are also pre-increment and pre-decrement forms, as in

```cpp
--x; // Same as x = x - 1;
++y; // Same as y = y + 1;
```

When they apply a value in a statement, the pre- and post-versions work identically. Their behavior is different when they are embedded within a more complex statement. Listing 4.13 (prepost.cpp) demonstrates how the pre- and post-increment operators work slightly.

## 4.9 Algorithms

An algorithm is a finite sequence of steps, each step taking a finite length of time, that solves a problem or computes a result. A computer program is one example of an algorithm, as is a recipe to make lasagna. In both of these, the order of steps matters. In the case of lasagna, the noodles must be cooked in boiling water before they are layered into the filling to be baked. It would be inappropriate to place the raw noodles into the pan with all the other ingredients, bake it, and then remove the already baked noodles to cook them in boiling water separately. In the same way, the ordering of steps is very important in a computer program. While this point may be obvious, consider the following sound argument:

Another example, suppose x and y are integer variables in some program. How would we interchange the values of the two variables? We want x to have y's original value and y to have x's original value. This code may seem reasonable:

```cpp
x = y;
y = x;
```

The problem with this code is that the first statement is executed, x and y both have the same value (y's original value). The second assignment is superfluous and does nothing to change the values of x or y. The solution requires a third variable to remember the original value of one the variables before it is reassigned. The correct code to swap the values is

```cpp
temp = x;
y = y;
x = temp;
```
