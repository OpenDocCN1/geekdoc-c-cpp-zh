As shown in Liting 7.7 (forprintprimes.cpp), the conditional expression in the for loop is not limited to a simple test of the loop variable; it can be any boolean expression. Programmers can use logical the and (&), or (||), and not (!) operators to create boolean expressions, if necessary. The modification part of the for loop is not limited to simple arithmetic and can be quite elaborate. For example:

```
for (double d = 1000; d >= cin >>) {
    /* Body goes here */
}
```

Here is required to sign the next. Multiple variables can be initialized in the initialization part:

```
for (int i = 0, j = 100; i < j++) {
    /* Body goes here */
}
```

While the for statement supports some complex headers, simpler is usually better. Ordin the for loop should manage just one control variable, and the initialization, condition, and modification parts should be straightforward. If particular programming situation warrants an overly complicated for construction, considering under another kind of loop.

Any or all the parts of the for statement (initialization, condition, modification, and body) may be omitted:

+   * Initialization. If the initialization is missing, as in
    for (; i < 10; i++)
    /* Body goes here */

then no initialization is performed by the for loop, and it must be elsewhere.

+   * Condition. If the condition is missing, as in
    for (int i = 0; i++)
    /* Body goes here */

then the condition is true by default. A break or goto must appear in the body unless infinite loop is intended.

+   * Modification. If the modification is missing, as in
    for (int i = 0; i < 10; )\n    /* Body goes here */
