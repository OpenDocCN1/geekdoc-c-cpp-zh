25. In mathematics, the midpoint between the points $(x1, y1)$ and $(x2, y2)$ is computed by the formula

```
$$\frac{x1+x2}{2}, \frac{y1+y2}{2}$
```

Write a C++ program that receives two mathematical points from the user and computes prints
A sample run of the program produces

```
Please enter the first point: (0,0)
Please enter the second point: (1,1)
The midpoint of (0,0) and (1,1) is (0.5,0.5)
```

The user enters "0" and "1,1" with the parens and commas as shown. See how
to do this, suppose you want to allow a user to enter the point (2,3), assigning the x component
to a variable named x and the y component to a variable named y. You can use
following code in your program to achieve the desired:

```
double x, y;
char left_paren, comma, right_paren;
cin >> left_paren >> x >> comma >> y >> right_paren;
```

If the user enters (2,3), the cin statement will assign the ( character to the variable
left_paren. It will then assign 2 to the variable x. It assigns the , character to the variable
comma, the value 3 to the variable y and the ) character to the right_paren variable.
The left_paren, comma, and right_paren variables are placeholders for the user's input
 are not used elsewhere in the program. In reality, the user can use other types of characters
in place of the parens and as long as the numbers are in the proper location relative to the
characters; for example, the user can type 2*:3, and the program will interpret the input as the
(2.3).
