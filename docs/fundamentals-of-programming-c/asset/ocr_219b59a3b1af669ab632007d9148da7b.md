# 16.4. LINKED LISTS

Armed with this view of lists we can now examine the behavior of the linked list methods in more detail:

+   - To understand how the recursive private insert method works we must think recursively. A list is either empty or non-empty. Inserting a new item into a list is as simple:

+   - If the list is empty, make a new list with one element in it. The single element in the resulting list is the item you want. Symbolically (not in C++) we can let ∅ stand for the list containing the element x. We therefore can represent the insertion into empty list as:

```
insert(∅, x) = x → ∅;
```

+   - If the list is not, merely insert the new item into the rest of the list. Notice the recursive description. We can express this as

```
insert(x→rest-of-list, a) = x→insert(rest-of-list, a)
```

To see how we build a list with three elements. First we will insert l. The list variable in main is initialized to null, so the first time main calls insert passes nullptr as the first parameter, and as the second parameter. Let ∅ represent the empty list, so we are in effect making the

```
list = insert(∅, 1);
```

Within insert, since the parameter p is non-null,

```
if (p) // Is p non-null?
```

is not met, so the else body is executed. Those reassign p to a newly created node 1. The node's pointer is null, so p points to a list holding just one element. We can represent this as 1→∅ p returned, and main assigns the result to list, so list now points to a list containing the single element 1. Now list is the 1→∅. Observe this first call to insert results in no recursive call.

We can symbolize this insertion of 1 into a list as

```
list = insert(∅, 1) = 1→∅
```

The second call to insert, produces a list holding two elements, is more interesting. We will insert 2 into our list. Again, list is passed as the first parameter and 2 is passed as the second, but this list is non-null. In the method, the condition

```
if (p) // Is p non-null?
```

is satisfied, so the recursive calls takes:

```
p->next = insert(p->next, n)
```

Note that p->next is assigned, not put. The p->next field represents the rest of the list, so we have a new problem to solve: insert 2 into the remainder of the list. After the rest of the list is empty the recursive call simply creates a new list 2 (that is, 2→∅) and returns it to be assigned to p->next. p itself is not reassigned, so it is pointing to the node as before, but that node's next was assigned to 2→∅ p then makes 1→2→∅ and is returned and assigned to main. List is now 1→2→∅.

We can symbolize this insertion of 2 into the list 1→∅

```
list = insert(1→∅, 2) = 1→insert(∅, 2) = 1→2→∅
```
