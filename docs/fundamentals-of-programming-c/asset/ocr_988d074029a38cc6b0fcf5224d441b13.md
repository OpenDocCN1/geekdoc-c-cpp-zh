# 8.1. INTRODUCTION to USING FUNCTIONS

The sqrt function has no access to main's original input variable; it has only a copy of input, as if "written on a piece of paper". (Similarly, if the sqrt function uses any variables to do its work, main is oblivious to them and has no way to access them). After sqrt is finished and returns to main its computed answer, sqrt discards its copy of input (by analogy, the function "throws away" the paper with the copy of input that main gave). Thus, during a function call main is a temporary, transient variable used only to communicate information to the function. The parameter lives only as long as the function is executing.
