# Chapter 1
## The Context of Software Development

A computer program, from one perspective, is a sequence of instructions that dictate the flow of electrical impulses within a computer system. These impulses affect the computer's memory and interact with the display screen, keyboard, mouse, and perhaps other computers across a network in such a way as to produce the "magic" that permits humans to perform useful tasks, solve high-level problems, and play games. One program allows a computer to assume the role of a financial calculator, while another transforms the machine into a worthy chess opponent. Note the two extremes here:

- at the lower, more concrete level electrical impulses alter the internal state of the computer, while
- at the higher, more abstract level computer users accomplish real-world work or derive pleasure.

So well is the higher-level illusion achieved that most computer users are oblivious to the lower-level activity (the machinery under the hood, so to speak). Surprisingly, perhaps, most programmers write software at this higher, more abstract level also. An accomplished programmer can develop sophisticated software with little or no knowledge of the actual computer system upon it runs. Powerful software construction tools hide the lower-level details from programmers, allowing them to solve problems in higher-level terms.

The concepts of computer programming are logical and mathematical. In theory, computer programs can be developed without the use of a computer. Programmers can discuss the visibility of a program and reason about its correctness and efficiency by examining abstract symbols that correspond to the features of real-world programming languages but appear in no real-world programming language. While such exercises can be very valuable, in practice computer programmers are not isolated from their machines. Software is written to be used on computer systems. Professionals known as software engineers develop software to drive particular systems. These systems are defined by their underlying hardware and operating system. Developers use concrete tools like compilers, debuggers, and profilers. This chapter examines the context of software development, including computer systems and tools.

## 1.1 Software

A computer program is an example of computer software. Software makes a computer truly universal, transforming it into the tool for the task at hand. One can refer to a program as a piece of software if it were a tangible object, but software is quite intangible. It is stored on a medium. A hard drive, a CD, a DVD, and a USB pen drive are examples of media upon which software can reside. The CD is not the software; software is a pattern on the CD. In order to be used, software must be stored in the computer's memory. Typically computer programs are loaded into memory from a medium like the computer's disk. An electromagnetic pattern representing the program is stored on the computer's memory before the program can be executed. The program has been installed on the hard disk from a CD or from the Internet. In any case, the essence that is transferred from medium to medium is a pattern of electronic symbols that directs the work of the computer system.

These patterns of electronic symbols are best represented as a sequence of zeros and ones, digits of binary (base 2) number. A binary program sequence is:

```
10001010110000100000101001110
```

To understand computing hardware, a zero here and three ones might mean that electronic signals should be sent to the graphics device so that it makes a certain part of the display screen real. Unfortunately, only a minuscule people in the world would be able to produce, by hand, the complete sequence of zeros and ones that represent Microsoft Word for an Intel-based computer running the Windows 8 operating system. Further, almost none of those could produce the binary sequence would claim to enjoy the task.

The Word program for Mac OS computers using a PowerPC processor works similarly to the Windows version and produced by the same company, but the program is expressed in a completely different sequence of zeros and ones! The Intel Core i7 processor in the Windows machine accepts a completely different binary language than the PowerPC processor. We say the processors have their own machine language.

## 1.2 Development Tools

If few can (or want) to speak the machine language of the computers' processors and software is expressed in this language, how has so much software been developed over the years?

Software can be represented by written words and symbols that are easier for humans to manage than binary sequences. Every tool can automatically convert a higher-level description of what is to be in the required-level code. Higher-level programming languages like C++ allow programmers to express solutions to programming problems in terms that are closer to a natural language like English. Some of the more popular of the higher-level programming languages that have been devised over the past 60 years include FORTRAN, COBOL, Haskell, C, Python, Java, and C#.

One might think that such a convention would accept a description in a natural language, such as English, and produce the desired executable code.
