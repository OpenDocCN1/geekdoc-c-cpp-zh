```
/*
* primes(begin, end)
* Returns a vector containing the prime
* numbers in the range begin..end.
* begin is the first number in the range
* end is the last number in the range
*/
vector<int> primes(int begin, int end) {
    vector<int> result;
    for (int i = begin; i <= end; i++) {
        if (is_prime(i)) {
            result.push_back(i);
        }
    }
    return result;
}

int main() {
    int low, high;
    cout << "Please enter lowest and highest values in ";
    cout << "the range: ";
    cin >> low >> high;
    vector<int> prime_list = primes(low, high);
    print(prime_list);
}
```

The primes function declares a local variable named result. The function examines every value in the range begin..end. The primes function uses is_prime as a helper function. The is_prime classifies values as a prime, which code within the primes adds to the result vector. After primes has considered all the values in the provided range, result will contain all the prime numbers in that range. primes returns the vector containing all the primes in the specified range.

When returning a value that is a built-in scalar like int, double, char, etc., a C++ function normally makes a copy of the local value to return to the caller. Making a copy is necessary because local variables exist only while the function is executing and when the function finishes executing, the run-time environment reclaims the memory used by the function's local variables and parameters can be used by other functions.

The return value in primes is not a simple scalar type—it is an object that can be quite large, especially if it passes a range. Modern C++ compilers generate machine code that eliminates the need to copy the local result. The technique is known as return value optimization, and it comes into play when a function returns an object declared within the function. With value optimization, the compiler knows that the variable will disappear and the variable is to be returned to the caller; therefore, it generates machine code that makes the space for the result in the caller's memory space, not the local function. Because caller is maintaining the space for the object, it persists after the function returns. Because of return value optimization you can return vectors by value without fear of a time-consuming copy operation.
