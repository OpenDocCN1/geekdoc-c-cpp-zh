Listing 2.6: empty.cpp
int main() {
}

Since Listing 2.6 (empty.cpp) uses neither the cout object nor endl, it does not need the #include and using directives. It is legal and sometimes even in C++ to write functions with empty bodies, such functions will do nothing when they execute. Listing 2.6 (empty.cpp) with its empty main function is, therefore, to truly the simplest C++ program we can write, but it does nothing when we runs it!
