```cpp
cout << hours;
// Decide between singular and plural form of hours
if (hours == 1) {
    cout << " hour";
} else
    cout << " hours";
}
if (minutes > 0) { // Print minutes at all?
    cout << minutes;
    // Decide between singular and plural form of minutes
    if (minutes == 1) {
        cout << " minute";
    } else
        cout << " minutes";
    }
}
// Print seconds at all!
if (seconds > 0 || (hours == 0 && minutes == 0 && seconds == 0)) {
    cout << seconds;
    // Decide between singular and plural form of seconds
    if (seconds == 1) {
        cout << "second";
    } else
        cout << " seconds";
    }
}
cout << endl;
```

In Listing 5.13 (timecond2.cpp) each segment responsible for printing a time value and its unit is produced by an if statement that only allows the code to execute if the value is greater than zero. The exception is in the processing of seconds: if all time values are zero, the program will print 0 seconds. Note that each of the if/else statements responsible for determining the singular or plural form is nested within the if statement that determines whether or not the value will be printed at all.

## 5.8 Multi-way if/else Statements

A simple if/else statement can select from between two execution paths. Suppose we wish to choose one execution path from among several possible paths, as shown in Figure 5.5? Listing 5.8 (enhancedcheck.cpp)

![](img/e326304bd50fbc4f7d5a64c1487eb635_107_0.png)

Figure 5.5: Flowchart with multiple optional execution pathways

showed how to select from among three options. What if exactly one of many actions should be taken?

Nested if/else statements are required, and the form of these nested if/else statements is shown in Listing 5.14 (digitittoword.cpp).

### Listing 5.14: digitittoword.cpp

```cpp
#include <iostream>

using namespace std;

int main() {
    int value;
    cout << "Please enter an integer in the range 0..5: ";
    cin >> value;
    if (value < 0)
        cout << "Too small";
    else
        if (value == 0)
            cout << "zero";
        else
            if (value == 1)
                cout << "one";
            else
                if (value == 2)
                    cout << "two";
                else
                    if (value == 3)
                        cout << "three";
                        else
                            if (value == 4)
                                cout << "Four";
                            else
                                if (value == 5)
                                    cout << "five";
                                else
                                    cout << "Too large";
    cout << endl;
}
```

Observe the following Listing 5.14 (digitittoword.cpp):

- It prints one of each message depending on the user's input.
- Notice that each if body contains a single printing statement and each else body, except the last one, contains an if statement. Control logic forces program execution to check each condition in turn. The first condition that matches, and its corresponding body will be executed. If none of the conditions are true, the last else is printed.
- No curly braces are necessary to delimit the if or else bodies since each body contains only single statement (although a deeply nested if/else statement is a mighty thing).

Listing 5.14 (digitittoword.cpp) is formatted according to the conventions used in earlier examples. As a consequence, text drifts as more conditions are added. A commonly used alternative style, shown in Listing 5.15 (digitittoword.cpp), avoids this drift.

## 5.9 Errors in Conditional Statements

Consider Listing 5.17 (badequality.cpp).

### Listing 5.17: badequality.cpp

```cpp
#include <iostream>

using namespace std;

int main() {
    int input;
    cout << "Please enter an integer";
    cin >> input;
    if (input = 2)
        cout << "two" << endl;
    cout << "You entered " << input << endl;
}
```

Listing 5.7 (badquality.cpp) demonstrates a common mistake—using the assignment operator where the equality operator is intended. When run, it always prints the message "two" and insists that the user entered 2 regardless of the actual input. Recall from Section 4.3 that the assignment expression has a value. The value of an assignment expression is the same as the value that is assigned; thus, the expression

input = 2

has the value. You also consider that any integer can be treated as a Boolean value (See 5.1) and any non-zero value is interpreted as true, you can see that the condition of if statement

```
if (input = 2)
    cout << "two" << endl;
```

is always true.
