The program has acct_ptr points to memory that was allocated with new, and this memory is not freed until the function returns. The pointer acct_ptr is the only way to get to memory, so when the function is finished, memory is lost for the life of the program. If the program runs to completion, the leak may go undetected. In a longer running program such as a web server, memory leaks occurs repeatedly and eventually all of available memory becomes used.
