# 5.6. COMPOUND BOOLEAN EXPRESSIONS

The relational operators such as < compare two operands. The result of the comparison is a Boolean value, which is freely convertible to an integer. The application of relational operators can lead to surprising results; consider, for example, the expression

```
1 <= x <= 10
```

This expression is always true, regardless of the value of x! If the programmer's intent is to represent the mathematical notion of x falling within the range 1...10 inclusive, as in 1 <= x <= 10, the above C++ expression is not equivalent.

The expression

```
1 <= <= 10
```

is evaluated as

```
(1 <= x) <= 10
```

If x is greater than or equal to one, the subexpression 1 ~ <= x evaluates to true, or integer. Integer 1, however, is always less than 10, so the overall expression is true. If x is less than one, the subexpression 1 ~ <= x evaluates to false, or integer 0. Integer 0 is always less than 10, so the overall expression is true. The problem is due to the fact that C++ does not strictly distinguish between Boolean and integers.

A correct way to represent the mathematical notion of 1 <= x <= 10 is

```
1 <= x <= 10
```

In this case x must simultaneously be greater than or equal to 1 and less or equal to 10. Revised Boolean expression is a little more verbose than the mathematical representation, but it is the correct formulation for C++.

The following sequence of code assigns the indicated values to bool:

```
bool b;
int x = 10;\int y = 20;
b = (x == 10);      // assigns true to b
b = (x != 10);      // assigns false to b
b = (10 && y == 20); // assigns true to b
b = (x != 10 && y == 20); // assigns false to b
b = (10 && y != 20); // assigns false to b
b = (x != 10 && y != 20); // assigns false to b
b = (10 || y == 20); // assigns true to b
b = (x == 10 || y == 20); // assigns true to b
b = (10 || y != 20); // assigns true to b
b = (x != 10 || y != 20); // assigns false to b
```

Convince yourself the following expressions are equivalent:

```
(x != y)
```
