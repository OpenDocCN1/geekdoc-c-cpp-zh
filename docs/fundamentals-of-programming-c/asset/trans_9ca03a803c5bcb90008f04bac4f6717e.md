

## 16.3. 带有日志记录的排序

（比较和交换）因为函数只能返回一个值，而不能返回两个。此外，如果我们这样做，可能会显著地改变排序算法本身的代码。我们更倾向于让排序算法专注于它的排序任务，并且不被这些额外的日志代码所干扰。

相反，如果我们不是向我们的排序函数传递一个函数指针，而是传递一个经过特殊构造的对象。我们可以设计这个对象来执行我们想要做的任何操作；具体来说，我们可以设计这个特殊对象来执行必要的比较，并跟踪它执行操作的次数。我们可以让该对象执行交换，而代码将记录它所执行的操作。

列表 16.5 (loggingflexiblesort.cpp) 是列表 12.2 (flexibleinsert.cpp) 的一个变体，它使用比较对象而不是比较函数。

# 列表 16.5: loggingflexiblesort.cpp

```cpp
#include <iostream>
#include <vector>

using namespace std;

/*
 * 比较对象管理下面选择排序函数中的
 * 比较和元素交换。
 */
class Comparator {
    // 跟踪执行的比较次数
    int compare_count;
    // 跟踪执行的交换次数
    int swap_count;
    // 指向执行比较的函数的函数指针
    bool (*comp)(int, int);
public:
    // 客户端必须用一个合适的比较函数 
    // 初始化一个 Comparator 对象。
    Comparator(bool (*f)(int, int))
        : compare_count(0), swap_count(0), comp(f) {}
    void reset() {
        // 重置计数器以为新排序做好准备
        compare_count = swap_count = 0;
    }
    // 执行比较的方法。它将实际工作
    // 委托给 comp 指向的函数。
    // 此方法记录每次调用。
    bool compare(int m, int n) {
        compare_count++;
        return comp(m, n);
    }

    // 执行交换的方法。
    // 交换通过引用传递的参数
    // 参数 a 和 b 的值。
    // 此方法记录每次调用。
    void swap(int& m, int& n) {
        swap_count++;
        int temp = m;
        m = n;
        n = temp;
    }

    // 返回此对象自创建以来 
    // 执行的比较次数。
    int comparisons() const {
        return compare_count;
    }

    // 返回此对象自创建以来 
    // 执行的交换次数。
    int swaps() const {
        return swap_count;
    }
};

/*
* selection_sort(a, compare)
* 根据比较对象确定的顺序排列 
* vector a 中的元素。
* a 是一个 int 类型的 vector。
* compare 是一个比较两个整数
* 的函数。
* a 的内容被物理地重排。
*/
void selection_sort(vector<int>& a, Comparator& compare) {
    int n = a.size();
    for (int i = 0; i < n; i++) {
        // 注意：i, small, 和 j 代表 a 内部的索引
        // a[i] 和 a[j] 代表位置上的元素。
        // small 是到目前为止的最小值的位置，
        // 我们用它来找到小于 a[i] 的最小值。
        int small = i;
        // 查看在数组后面是否可以找到更小的值
        for (int j = i + 1; j < n; j++) {
            if (compare.compare(a[j], a[small]))
                small = j; // 找到了更小的值
            // 如果找到了更小的值，则交换 a[i] 和 a[small]
            if (i != small)
                compare.swap(a[i], a[small]);
        }
    }
}

/*
* print
* 打印整数 vector 的内容
* a 是要打印的 vector。
* a 不被修改。
*/
void print (const vector<int>& a) {
    int n = a.size();
    cout << '{';
    if (n > 0) {
        cout << a[0]; // 打印第一个元素
        for (int i = 1; i < n; i++)
            cout << ', ' << a[i]; // 打印其余元素
    }
    cout << '}';
}
```
