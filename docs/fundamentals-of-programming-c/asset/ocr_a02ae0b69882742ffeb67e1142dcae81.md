An ofstream object writes data to file. We can use the open method to associate the object with the file to be created. The open method accepts a string that represents a name. The save_vector function in Listing 13.6 (list.cpp) passes a string object to open, but the open method can work with string literals (quoted strings) as. Consider the following code fragment:

```
ofstream fout;
int x = 10;
fout.open("myfile.dat");
if (fout.good()) { // Make sure the file was opened properly
fout << "x = " << x << endl;
fout.close();}
```

```
else
cout << "Unable to write to the file \myfile.dat\" << endl;
```

After the call, programmers should verify that the method correctly opened the file by calling the file stream's good method. An output file may fail for various reasons, including the disk being full or insufficient permissions to create a file in a folder.

Once we have opened file, we can use an ofstream object like the cout stream object, except the data recorded in a file instead of being printed on the screen. With cout, we can use the << operator and an ofstream object stream manipulators like endl and setw.

After executing the program has written to the file and needs no more to use it the method to properly close the file. Failure to do so may mean some or all of the data written to the file is not saved to the disk. The close method accepts no parameters.

An ifstream object reads data from files. We can use the open method to associate the ifstream object with a particular file to be read. As ofstream objects, the open method accepts a string name to identify the file to read.

After calling, the program should call good to ensure the file was successfully opened. An input stream often fails to open because the file does not exist; the file is misspelled, or the path to the file is incorrect. An input stream can also fail because of insufficient permissions or of bad sectors on the disk.

Once its file is opened, an input file stream behaves like the cout object, except its data comes from a file instead of the keyboard. The same family >> operator and getline function are completely compatible with ifstream objects.

As with output stream, your program should close the file using the close method when the program has finished reading the file.
