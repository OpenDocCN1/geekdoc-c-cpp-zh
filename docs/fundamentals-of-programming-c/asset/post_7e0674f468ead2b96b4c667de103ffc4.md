## Other Conditional and Iterative Statements

The if/else and while statements are sufficient to implement algorithms that involve conditional execution and looping. The break and continue statements are convenient but are not necessary. C++ provides some additional conditional and iterative statements that are more convenient to use in some circumstances. These additional statements include

- switch: an alternative to multi-way if/else statements
- the conditional operator: an expression that exhibits the behavior of an if/else
- do/while: a loop that checks its condition after its body is executed
- for: a loop convenient for counting

These alternate contain certain parts of algorithms to be expressed more clearly and succinctly. This chapter explores these others of expressing conditional execution and iteration.

## 7.1 The Switch Statement

The switch provides a convenient alternative for multi-way if/else statements like the one in Listing 5.15(restlydigittow.cpp). Listing 7.1 (switchdigittow.cpp) uses a switch statement instead of a multi-way if/else statement.

### Listing 7.1: switchdigittow.cpp
```cpp
#include <iostream>

using namespace std;

int main() {
    int value;
    cout << "Please enter an integer in the range 0...5: ";
```

```
cin >> value;
switch (value) {
    case 0:
        cout << "zero";
        break;
    case 1:
        cout << "one";
        break;
    case 2:
        cout << "two";
        break;
    case 3:
        cout << "three";
        break;
    case 4:
        cout << "four";
        break;
    case 5:
        cout << "five";
        break;
    default:
        if (value < 0)
            cout << "Too small";
        else
            cout << "Too large";
        break;
}
cout << endl;
```

The general form of a switch is:

```
switch ( integral expression ) {
    case integral constant 1 :
        statement sequence 1
        break;
    case integral constant 2 :
        statement sequence 2
        break;
    case integral constant 3 :
        statement sequence 3
        break;
    ...
    case integral constant n :
        statement sequence n
        break;
    default:
        default statement sequence
}
```

In a switch statement

- The reserved word switch identifies a switch statement.
- The required parentheses expression that follows the word switch must evaluate to an integral value. Any integer type, characters, and Boolean expressions are acceptable. Floating point expressions and other non-integer types are forbidden.
- The body of the switch is enclosed by required curly braces.
- Each occurrence of the word case is followed by an integral constant and a colon (:). We call the integral constant a case label. This label can be either a literal value or a const symbolic value (Section 3.5). In particular, non-const variables and other expressions are expressly forbidden.

The case label defines a position within the code; it is not an executable statement. A case label represents a target to which the switch's execution flow can jump.

If the case matches the switch's expression, then the statements that label are executed until a break statement is encountered. The statements and break statement that follow each case label are optional. One may execute one set of statements for more than one case label or provide empty statements for one or more of the labels, as in:

```
cin >> key; // get key from user
switch (key) {
    case 'p':
    case 'q':
        cout << "You choose" << endl;
        break;
    case 'q':
    case 'Q':
        done = true;
        break;
}
```

Here a user enters upper- or lowercase P, resulting in the same action—You chose P is printed. The done Boolean variable is set to true. If the user enters neither P nor Q, none of the statements in the switch are executed.

The break statement is optional. If a case is labeled, the statements that follow are executed until a break statement is encountered. The control flow then transfers to the body of the switch. In this way, the break within a switch works until a break within a loop: the rest of the body of the switch is skipped and program execution returns to the next statement following the body. A missing break statement, a common error, when its omission is not intentional, causes the statements of the succeeding case label to be executed. The process continues until a break is encountered or the end of the switch is reached.

- The default is labeled if none of the case labels match. It serves as all option like the else in a multi-way if/else statement. The default label is optional. If it is missing and none of the case labels match the expression, no statement within the switch is executed.

The switch statement has two restrictions that make it less than the multi-way if/else:

- The switch argument must be an integral expression.
- Case labels must be constant integral values. Integral literals and constants are acceptable. Variables or expressions are not allowed.

To illustrate these restrictions, consider the following if/else statement that translates easily to equivalent switch statement:

```
if (x == 1) {
    // Do 1
} else if (x == 2) {
    // Do 2
} else {
    // Do 3
}
```

The corresponding switch statement is:

```
switch (x) {
    case 1:
        // Do 1
        break;
    case 2:
        // Do 2
        break;
    default:
        // Do 3
        break;
}
```

## 7.2 The Conditional Operator

As purely syntactical, C++ provides an alternative to the if/else construct called the conditional operator. It has limited application but is convenient nonetheless. The following code fragment assigns one of two to x:

- the result of y/z, if z is nonzero, or
- zero, if z is zero; we wish to avoid the runtime error of division by zero.

```cpp
// Assign a value to x:
if (z != 0)
    x = y/z; // Division is possible
else
    x = 0; // Assign a default value
```

This code has two assignments, but only one is executed at any given time. The conditional operator makes for a more compact statement:

```cpp
// Assign a value to x:
x = (z != 0) ? y/z : 0;
```

The general form of a conditional expression is:

![](img/e326304bd50fbc4f7d5a64c1487eb635_162_0.png)

- condition is a normal Boolean expression that might appear in an if statement. Parentheses around the condition are not required but should be used to improve the readability.
- expression 1 is the overall value of the conditional expression if condition is true.
- expression 2 is the overall value of the conditional expression if condition is false.

The conditional operator uses two symbols (? and :) and three operands. Since it has three operands it is classified as a ternary operator (C++s only one). The overall type of a conditional expression is the more dominant of exp1 and exp2 The conditional expression can be used anywhere an expression can be. It is not a statement; it is used within a statement.

As another example, the absolute value of a number is defined in mathematics by the following formula:

```
|n| = { n, when n >= 0; -n, when n < 0 }
```

In other words, the absolute value of a positive number or zero number is the same as the number; the additive inverse (negative) of that number. The following C++ expression represents the absolute value of the variable n:

```cpp
abs_n = (n >= 0) ? n : -n;
```
