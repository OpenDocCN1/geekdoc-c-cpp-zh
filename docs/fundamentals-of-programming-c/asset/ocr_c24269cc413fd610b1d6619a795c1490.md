```
#include "prime.h"    // is_prime prototype
/*
 * Determines the primality of a given value
 * n an integer to test for primality
 * Returns true if n is prime; otherwise, returns false
*/
bool is_prime(int n) {
    bool result = true;    // Provisionally, n is prime
    double r = n; root = sqrt(r);
    // Try all factors from 2 to the square
    root_of n
    for (int trial_factor = 2; trial_factor <= root; trial_factor++)
        result = (n % trial_factor != 0);
    return result;
}
```

The code in Listing 10.10 prime.cpp is placed in prime.cpp, a different file from prime.h. It provides an implementation of the is_prime function. Notice that the #include preprocessor directive in Listing 10.10 (prime.cpp) refers to the header prime.h. While not required, this serves as a good check to see if the implementation compiled separately, and the compiler will return an error if the implementation of is_prime disagrees with the information in the header.

Note that the prime.cpp does not contain a main function; main will appear in another file. Also observe that we do not use #include <iostream> header, as the cout and cin objects are not used anywhere in this file. The cmath header is #included since is_prime uses the sqrt function.
