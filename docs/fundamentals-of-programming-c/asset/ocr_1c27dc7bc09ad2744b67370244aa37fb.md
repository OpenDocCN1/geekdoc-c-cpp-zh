The expression iter != end(vec)

checks each time through the loop to ensure the iterator object has not run off the back of the vector. The begin and end functions are overloaded to work with vector objects, arrays, and other classes in the standard library. Listing 18.13 (iteratoropararray.cpp) is the array version of Listing 18.12 (iteratorloop.cpp).

# Listing 18.13: iteratoropararray.cpp

```
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Make a static integer array
    int arr[] = {10, 20, 30, 40, 50};
    // Print the contents of the array
    for (auto iter = begin(arr); iter != end(arr); iter++) {
        cout << +iter << ' ';
    }
n}
```

The output of Listing 18.13 (iteratoropararray.cpp) is identical to Listing 18.12 (iteratorloop.cpp):

```
10 20 30 40 50
```

Any type for the begin and end functions has been overloaded and may participate in a range-based for statement. In fact, the compiler internally transforms a range-based for into its equivalent begin/end form during the compilation process. The following code

```
for (auto i : vec)
    cout << +i << ' ';
```

```
for (auto i = begin(vec); _i != end(vec); _i++)
    cout << *i << ' ';
```

We can treat an iterator as a pointer. Recall from Section 11.2 that we can manipulate pointers with pointer arithmetic. If p points to the first element of an array, p+5 points to the sixth element in the array (because p+0 is the same as p). The expression p++ makes the p point to the next element in the array, while p moves backwards one position. We can use similar arithmetic with iterators as Listing 18.14 (iterarith.cpp) illustrates.
