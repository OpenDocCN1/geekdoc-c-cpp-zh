The user to retry without clearing the bad characters entered before results in the same problem—the stream object re-enters the error state and the bad characters remain in the keyboard buffer. The solution is to fix by clearing the keyboard buffer all of the characters since the user entered valid data.

```cpp
cin.ignore(numeric_limits<streamsize>::max(), '\n');
```

removes from the buffer all the characters, up to and including the newline character '\n'.

```cpp
numeric_limits<streamsize>::max()
```

returns the maximum number of characters that the buffer can hold, so the ignore method discards all characters until it reads the newline '\n' or reaches the end of the buffer, whichever comes first.

Once the stream object has been reset from its error state and the keyboard buffer is empty, user input can proceed as usual.

## 13.3 File Streams

Many applications allow users to create and manipulate data. True useful applications allow users to store data: for example, word processors can save and load documents.

Vectors would be more useful if they were persistent. Data is persistent when it exists between program executions. During one execution of a particular program the user may create and populate a vector. The user saves the contents of the vector to disk and quits the program. Later, the user can run the program and reload the vector from the disk and restore it.

C++ fstream objects allow programmers to build persistence in their applications. Listing 13.6 (numberlist.cpp) is a simple example of a program that allows the user to save the contents of a vector to a text file and load a vector from a text file.

## 13.3. FILE STREAMS

```cpp
/* v is a vector holding integers.
 */
void print_vector(const vector<int>& vec) {
    cout << "[";
    int len = vec.size();
    if (len > 0) {
        for (int i = 0; i < len - 1; i++) {
            cout << vec[i] << ", "; // Comma between elements
        }
        cout << vec[len - 1]; // No comma after last element
    }
    cout << "]" << endl;
}
```

```cpp
/* save_vector(filename, v)
* Writes the contents of vector v.
* filename is name of text file created. Any file by name is overwritten.
* v is a vector holding integers. v is unchanged by function.
 */
void save_vector(const string& filename, const vector<int>& vec) {
    ofstream out;
    out.open(filename);
    if (out.good()) { // Make sure the file was opened properly
        int n = vec.size();
        for (int i = 0; i < n; i++) {
            out << vec[i] << " "; // Space delimited
        }
        out << endl;
        out.close();
    } else
        cout << "Unable to save the file" << endl;
}
```

```cpp
/* load_vector(filename, v)
* Reads the contents of vector v from text file
* filename. v's contents are replaced by the file's.
* If the file cannot be found, the vector is empty.
* v is a vector holding integers.
 */
void load_vector(const string& filename, vector<int>& vec) {
    ifstream in;
    in.open(filename);
    if (in.good()) { // Make sure the file was opened properly
        vec.clear(); // Start with empty vector
        int value;
        while (in >> value) // Read until end of file
            vec.push_back(value);
        }
        in.close();
    } else
        cout << "Unable to load the file" << endl;
}
```

```cpp
int main() {

    while (!done) {
```

An ofstream object writes data to file. We can use the open method to associate the object with the file to be created. The open method accepts a string that represents a name. The save_vector function in Listing 13.6 (list.cpp) passes a string object to open, but the open method can work with string literals (quoted strings) as. Consider the following code fragment:

```cpp
ofstream fout;
int x = 10;
fout.open("myfile.dat");
if (fout.good()) { // Make sure the file was opened properly
    cout << "x = " << x << endl;
    fout.close();
}
else
    cout << "Unable to write to the file myfile.dat" << endl;
```

After the call, programmers should verify that the method correctly opened the file by calling the file stream's good method. An output file may fail for various reasons, including the disk being full or insufficient permissions to create a file in a folder.

Once we have opened file, we can use an ofstream object like the cout stream object, except the data recorded in a file instead of being printed on the screen. With cout, we can use the << operator and an ofstream object stream manipulators like endl and setw.

After executing the program has written to the file and needs no more to use it the method to properly close the file. Failure to do so may mean some or all of the data written to the file is not saved to the disk. The close method accepts no parameters.

An ifstream object reads data from files. We can use the open method to associate the ifstream object with a particular file to be read. As ofstream objects, the open method accepts a string name to identify the file to read. After calling, the program should call good to ensure the file was successfully opened. An input stream often fails to open because the file does not exist; the file is misspelled, or the path to the file is incorrect.
