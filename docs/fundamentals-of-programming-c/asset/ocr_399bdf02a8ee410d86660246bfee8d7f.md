# 17.4. POLYMORPHISM

```
virtual void set(int d) { data = d; }
virtual int get() { return data; }

int main() {
NoVTable no_vtable;
HasVTable has_vtable;
no_vtable.set(10);
has_vtable.set(10);
cout << "no_vtable size = " << sizeof(no_vtable) << endl;
cout << "has_vtable size = " << sizeof(has_vtable) << endl;
}
```

The output of Listing 17.3 (vtables.cpp) is

```
no_vtable size = 4
has_vtable size = 8
```

A NoTable requires four bytes for its integer field, and a HasVTable object occupies eight bytes—four for its integer field and four bytes for its secret pointer.

Dynamic binding enables a powerful technique in object-oriented programming called polymorphism. A polymorphic behavior behaves differently depending on the actual type of object upon which it is invoked. Consider Listing 17.4 (polymorphicvector.cpp).
