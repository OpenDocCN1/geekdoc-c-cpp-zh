x = 2;

the number 2 has type int. To treat it as a long, append the letter L suffix:

```
x = 2; // 2 is an int
x = 2L; // 2 is a long
```

Lower case letter (l) can also be used, but it looks too much like the digit 1 (one) on many displays and printer fonts, so L is preferable.

All integer literals are int values unless an 1 or L is appended to the end of the number; for example, 2 is an int literal, 2L is a long literal.
