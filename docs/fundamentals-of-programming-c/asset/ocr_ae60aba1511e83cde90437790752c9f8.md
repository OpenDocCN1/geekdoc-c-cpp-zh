The square bracket notation used with arrays does not represent a special operator. The square bracket array notation is part of the C language since its beginning, but vectors (added by C++) of the C++ library were designed to behave as much like possible primitive C arrays. Arrays have been part of the C++ have adopted the syntactic features of arrays. Both arrays and vectors use square brackets for element access, and locate their first element at index zero. Provide access to a block of memory that can hold multiple elements. A vector object adds additional capabilities and conveniences that make the vectors better choice for C++ developers. Vectors have a close association with arrays—a vector object is a thinner wrapper around a dynamic array. A vector object simply manages its dynamic by providing convenient methods for adding elements and resizing the array it manages. A vector keeps track of its own size. Arrays provide none of methods that vectors do. The overhead that a vector imposes over a raw array is negligible. You should prefer vectors over arrays when writing C++ code.

If you want to "unwrap" the array that the vector manages, you need to use a C library that accepts only arrays? Fortunately it is easy to use "unwrap"; If vec is a vector, the expression &vec[0] is the address of the first element within the vector. Given a function such as

```
void print(int a[], int n) {
    for (int i = 0; i < n; i++) {
        cout << a[i] << ' ';
    }
    cout << endl;
}
```

that expects &vec[0], vec.size()), can invoke it with your vec vector object

```
print(&vec[0], vec.size());
```

Note that the first parameter is the starting address of the wrapped array, and the second parameter is the number of elements. If you have a function that uses your pointer:

```
void print(int *begin, int *end) {
    for (int *elem = begin; elem != end; elem++) {
        cout << *elem << ' ';
    }
    cout << endl;
}
```

you can invoke it with your vec vector object

```
print(&vec[0], &vec[0] + vec.size());
```
