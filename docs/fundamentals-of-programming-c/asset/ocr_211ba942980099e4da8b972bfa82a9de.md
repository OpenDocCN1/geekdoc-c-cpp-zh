# F.11 Memory Management

Memory issues with new and delete frequently are the source of difficult to find and fix logic errors. Programmers must adhere to the following tenets:

+   * Every call to new should have an associated call to delete when the allocated memory is no longer needed. It sounds simple enough, but it is not clear when delete should be used. The following function exhibits a memory leak:

```

    // /

    // /
    // Do some stuff with p
    // /
    // /
    // Exit function without deleting p's memory
}
```
