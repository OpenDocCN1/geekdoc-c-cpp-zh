# 18. FUNCTION TEMPLATES

```
// The compiler automatically generates this from the template:
int sum(const vector<int>& v) {
    int result = 0;
    for (int elem : v) {
        result += elem;
    }
    return result;
}
```

Notice how the compiler substitutes int for every occurrence of the type parameter T. If the compiler sees code like

```
vector<double> v(10, 2, 30);
cout << sum(v) << endl;
```

it uses the template to instantiate the following function:

```
// The compiler automatically generates this:
double sum(const vector<double>& v) {
    double result = 0;
    for (double elem : v) {
        result += elem;
    }
    return result;
}
```

In a program that has code like

```
vector<double> v(10, 20, 30);
vector<int> w(10, 20, 30);
cout << sum(v) << endl;
cout << sum(w) << endl;
```

the compiler will instantiate both versions of the sum function. The compiler generates these automatically and secretly because they do not appear in any source code. The programmer never sees these instantiated template functions but the preprocessor that sees a modified version of the source code to the compiler (see Section 1.2 to review the preprocessor's role in the programmer's build process), a C++ compiler generates the machine versions of these instantiated functions directly from the programmer's source code.

Recall our swap function from List 10.18. Callers can use it to interchange the values of two integer variables. With our knowledge of C++ templates, we can write a version that interchanges the values of two variables of any type:

```
/*
* swap(a, b)
* Interchanges the values of memory
* referenced by its parameters a and b.
* It effectively interchanges the values
* variables in the caller's context.
*/ntemplate <typename ElemType>
void swap(ElemType& a, ElemType& b) {
    ElemType temp = a;
    a = b;
}
```
