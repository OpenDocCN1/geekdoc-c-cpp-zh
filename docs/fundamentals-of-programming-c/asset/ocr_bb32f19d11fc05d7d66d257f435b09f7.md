Once the loop is gone, we have many series of recursive calls to permute sandwiched by calls to swap. The first call to swap interchanges an element in the vector with the first element. The third call to swap reverses the effects of the first swap. This series of swap-permute operations allows each element in the vector to turn into the permuted vector. The permute recursive call generates all the permutations of the vector. Figure 12.4 traces the process of generating all the permutations of the vector {0,1,2}. The leftmost third contains the original contents of the vector and the initial call to permute. The three branches represent the three iterations of the for loop: varying from begin (0) to end (2). The vectors indicate the state of the vector after the first swap before the recursive call to permute.

The middle third of Figure 12.4 shows the state of the vector during the first recursive call to permute. The two branches represent the iterations of the for loop: varying from begin (1) to end (2). The vectors indicate the state of the vector after the first swap before the next recursive call to permute. At this level the element at index zero is fixed, and the remainder of the processing this chain of recursion is restricted to indices greater than zero.

The right third of Figure 12.4 shows the state of the vector during the second recursive call to permute. At this level the elements at indices zero and one are fixed, and the remainder of the processing this chain of recursion is restricted to indices greater than one. This leaves the element at index two, represents the base case of the recursion because begin (2) equals end (2). The function makes no recursive calls to itself. The function presents the current contents of the vector.

The arrows in Figure 12.4 represent a call to, or return from, permute. They illustrate the recursive call. The arrows pointing to left represent a call, and the arrows pointing to right represent a return from the function. The numbers with arrow indicate the order in which the calls and returns occur during the execution of permute.

The second column from the left shows the original contents of the vector after the first swap but before the first recursive call to permute. The swapped elements appear in red. The third column shows the contents of the vector at each level of recursion. The elements at index zero are fixed, as this level uses a value of one instead of zero. The for loop in this recursive call swaps the elements highlighted in red. The rightmost column is the point where begin equals end, and the permute function does not call itself terminating the recursion.
