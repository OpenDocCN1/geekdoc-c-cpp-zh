
## 17.6. FINE TUNING INHERITANCE

for "implementation", protected compare_impl represents the implementation details of the compare method and swap_impl represents the implementation details of the swap method.

- The public compare and swap methods both depart part of the work to the protected compare_impl and swap_impl.
- The compare and swap methods are not declared virtual, so derived classes cannot override them.
- The compare and swap methods manage the compare_count and swap_count counter fields. Since derived classes cannot see these fields, there is nothing that a designer of a derived class can do when overriding compare_impl or swap_impl to disturb the correct accounting of the number of times a client calls compare or swap.
- The comparisons and swaps methods report the results to the client are non-virtual, so derived classes may not override their behavior.

Observe that the nature of the Comparer class allows the comparisons and derived classes to be flexible, but it is rigid on the enforcement of how the accounting is performed and reported. The proper use of protected and private specifiers in a base class as shown in Compar affords designers general control over what derived class can do. Derived classes may adapt some behaviors, but other behaviors are non-virtual.

What kind of customization would a programmer want to do to the Compar class beyond how the comparison is performed? Consider the LogComparator class declared in Listing 17.21 (logcomparer.h).

The implementation of the LogComparer methods can be found in Listing 17.22 (logcomparer.cpp).

# Listing 17.22: logcomparer.cpp

```cpp
#include "logcomparer.h"
#include <cstdlib>
#include <iostream>

using namespace std;

// Method that actually performs the comparison
// Derived classes may override this method
bool LogComparer::compare_impl(int m, int n) {
    f << "Comparing " << m << " to " << n << endl;
    // Base class method does the comparison
    return LogComparer::compare_impl(m, n);
}

// Method that actually performs the swap
// Derived classes may override this method
void LogComparer::swap_impl(int& m, int& n) {
    f << "Swapping " << m << " and " << n << endl;
    int temp = m;
    m = n;
    n = temp;
}

// The client must initialize a LogComparer object with a
// suitable function and the file name of the
// text file to receive logging messages.
LogComparer::LogComparer(bool (*f) (int, int), const std::string& filename)
    : f(f) {
    f.open(filename);
    if (!f.good()) {
        f.close();
        cout << "Could not open file " << filename << " for writing" << endl;
        exit(1);
    }
}

// Destructor closes the log file
LogComparator::~LogComparator() {
    f.close();
}
```

The constructor attempts to open an output stream to write logging information to a text file. If the constructor cannot for reason open the file, it terminates the program's execution. The two overridden methods, `compare_impl` and `swap_impl`, write to the log file. Notice that the `override` keyword appears after the method declarations in `comparer.h`, it does not appear after the method implementations in `comparer.cpp`. The client code in Listing 17.23 (loggingsort.cpp) uses a LogComparator object to create a text file named sort.log.

# Listing 17.23: loggingsort.cpp

```cpp
#include <iostream>
#include <vector>
#include "comparer.h"

using namespace std;

/*
 * selection_sort(vector<int>& a, Comparator& compare)
 * Arranges the elements of vector a in an order
 * determined by the compare object.
 * a is a vector of ints.
 * The contents of a are physically rearranged.
 */
void selection_sort(vector<int>& a, Comparator& compare) {
    int n = a.size();
    for (int i = 0; i < n - 1; i++) {
        // i and j represent positions within
        // a[i], a[small], and a[j] represents the elements at
        // positions.
        // small is the smallest value we've seen
        // so far; we use it to find the smallest value
        // than a[i];
        int small = i;
        // See if a smaller value can be found later in the array
        for (int j = i + 1; j < n; j++) {
            if (compare(a[j], a[small])) {
                small = j; // Found a smaller value
            }
        }
        // Swap a[i] and a[small], if a smaller value was found
        if (i != small)
            compare.swap(a[i], a[small]);
    }
}

/*
 * print the contents of an integer vector
 * a is the vector to print.
 * a is not modified.
 */
void print(const vector<int>& a) {
    int n = a.size();
    cout << '{';
    cout << a[0]; // Print the first element
    for (int i = 1; i < n; i++)
        cout << ', ' << a[i]; // Print the rest
    cout << '}';
}

/*
 * less_than(a, b)
 * Returns true if a < b; otherwise,
 * false.
 */
bool less_than(int a, int b) {
    return a < b;
}

int main() {
    // Make a working copy of integers from an array
    int a[] = { 23, -3, 4, 215, 0, -3, 2 };
    int len = sizeof(a)/sizeof(a[0]);
    vector<int> vec(a, a + len);

    // Make a working copy of the original vector
    cout << "Before: ";
    print(vec);
    cout << endl;
    LogComparator lt(less_than, "sort.log");
    selection_sort(vec, lt);
    cout << "Ascending: ";
    print(vec);
    cout << " (" << lt.comparisons() << " comparisons, "
        << lt.swaps() << " swaps") << endl;
}
```

Listing 17.23 (loggingsort.cpp) prints to the console:

| Before | Ascending |
| :--- | :--- |
| (23,-3,4,215,0,-3,2) | (-3,0,2,4,23,215 (21 comparisons, 4 swaps)) |

and writes the file sort.log the text:

Comparing -3 to 23
Comparing 4 to -3
Comparing 215 to -3
Comparing 0 to -3
