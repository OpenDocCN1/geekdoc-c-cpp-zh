# 17.6. FINE TUNING INHERITANCE

The constructor attempts to open a file output stream to write logging information to a text file. If the constructor cannot for any reason open the text file for writing, it terminates the program's execution. The destructor closes the file object when the LogComparator object's life is over.

The two overridden methods, `compare_impl` and `swap_impl`, write to the log file. Both methods use the LogComparator object's fout field rather than the count output stream object.

Notice that the override keyword appears after the method declarations in logcomparator.h, it does not appear after the method implementations in logcomparator.cpp.

The client code in Listing 17.23 (loggingsort.cpp) uses a LogComparator object to create a text file named sort.log.

```cpp
#include <iostream>
#include <vector>
#include "logcompar.h"

using namespace std;

/*
* selection_sort(vector<int>& a, Comparator compare)
* Arranges the elements of vector a in an order determined
* by the compare object.
* a is a vector of ints.
* compare is a function that compares the ordering of
* two integers.
* The contents of a are physically rearranged.
*/
void selection_sort(vector<int>& a, Comparator& compare) {
    int n = a.size();
    for (int i = 0; i < n - 1; i++) {
        // Note i, j and j represent positions within
        // a[i], a[small], and a[j] represents the elements at
        // those positions.
        // small is the smallest of smallest value we've seen
        // so far; we use it to find the smallest value less
        // than a[i];
        int small = i;
        // See if a smaller value can be found later in the array
        for (int j = i + 1; j < n; j++) {
            if (compare(a[j], a[small])) {
                small = j; // Found a smaller value
            }
        }
        // Swap a[i] and a[small], if a smaller value was found
        if (i != small)
            compare.swap(a[i], a[small]);
    }
}

* Prints the contents of an integer vector
* a is the vector to print.
