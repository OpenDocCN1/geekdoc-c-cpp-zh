# 6.3. ABNORMAL LOOP TERMINATION

```
int input, sum = 0;
done done = false;
while (!done) {
    cout << "Enter positive integer (999 quits): ";
    cin >> input;
    if (input < 0) {
        cout << "Negative value " << " ignored"
        << endl;
        continue; // Skip rest of body for this iteration
    }
    if (input != 999) {
        cout << "Tallying " << endl;
        sum += input;
    } else {
        done = (input == 999); // 999 entry exits loop
    }
}
cout << "sum = " << sum << endl;
```

Programmers do not use the continue statement as frequently as the break statement since it is easy to transform the code use continue into an equivalent that does not. Listing 6.18 (noccontinueexample.cpp) works exactly like Listing 6.17 (continueexample.cpp), but it avoids the continue statement.

# Listing 6.18: nocontinueexample.cpp

```
#include <iostream>
using namespace std;
int main() {
    int input, sum = 0;
done done = false;
while (!done) {
        cout << "Enter positive integer (999 quits): ";
        cin >> input;
        if (input < 0) {
            cout << "Negative value " << " ignored"
            << endl;
        } else {
            if (input != 999) {
                cout << "Tallying " << endl;
                sum += input;
            } else {
                done = (input == 999); // 999 entry exits loop
            }
        }
    }
cout << "sum = " << sum << endl;}
```

6.5 shows how we can rewrite any program that uses a continue statement into an equivalent form that does not use continue. The transformation is simpler than break elimination (see Figure 6.4), since the loop's condition remains the same, and no additional variable is introduced.
