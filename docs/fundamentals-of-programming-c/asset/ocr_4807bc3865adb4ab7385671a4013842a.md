# 3.2. VARIABLES AND ASSIGNMENT

```
int main() {
    int x = 10;
    cout << x << endl;
}
```

Notice that in Listing 3.6 (variable-init.cpp) the declaration and assignment of the variable x is performed in one statement of two. This combined declaration and immediate assignment is called Initialization.

C++ supports another syntax for initializing variables in Listing 3.7 (alt-variable-init.cpp).

# Listing 3.7: alt-variable-init.cpp

```
#include <iostream>

using namespace std;

int main() {
    int x{10};
    cout << x << endl;
}
```

This alternate form is not commonly used for simple variables, but it necessary for initializing more complicated kinds of variables called objects. We introduce objects in Chapter 13 and Chapter 14.

Multiple variables of the same type can be declared and, if desired, initialized in a single statement. The following statements declare three variables in one declaration statement:

```
int x, y, z;
```

The following statement declares three integers and initializes two of them:

```
int x = 0, y, z = 5;
```

Here y's value is undefined. The declarations may be split up into multiple declaration statements:

```
int x = 0;
int y;
int z = 5;
```

In the case of multiple declaration the type name (here int) must appear in each statement.
