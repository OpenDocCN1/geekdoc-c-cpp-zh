clearly demonstrates that the variables x and r represent the same quantity. Reassigning x in the same way, and reassigning r changes x exactly the same way. The variable y, on the other hand, is independent from both x and r. Reassigning x or r does not affect y, and reassigning affects x nor r.

Reference variables are similar to pointer variables, but there are some important differences. Reference syntax is similar to pointer syntax because it is not necessary to deference a variable in order to assign the memory location to it refers. If num is an int, ptr is a pointer to an int, and ref is a reference to an int, consider the following statements:

```
num = ref; // Assign num from ref, no need to deference
num = *ptr; // Assign num from ptr, must dereference *
```

A reference has two limitations over a pointer variable: A pointer variable may be declared without an initial value and reassigned later. Consider the following statements:

+   * a reference variable must be initialized with an initial value when it is declared. A pointer variable may be declared without an initial value and reassigned later. Consider the following statements:
```
int *p; // Legal, we will assign p later
int &r; // Illegal, we must initialize r when declaring
```

Attempting to compile this code under Visual C++ prompts the compiler to issue the error
error C2535: 'r': references must be initialized
