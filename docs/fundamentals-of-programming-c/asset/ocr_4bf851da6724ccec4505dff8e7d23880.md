In Listing 6.19(factors.cpp) the outer loop condition is

```
n <= MAX
```

If n is 3 and MAX is 20, then the condition is false, so this is not a tautology. Checking the inner loop condition:

```
factor <= n
```

we see that if factor is 3 and n is 2, the expression is false; therefore, it is also not a tautology.

+   The condition of a while must be true to initially gain access to its body. The code within the body must modify the state of factor in some way so as to influence the outcome of the condition that is checked at each iteration. Usually means code within the body of the loop modifies one of the variables assigns a value that makes the condition false, and the loop terminates.

In Listing 6.19(factors.cpp) the outer loop condition involves the variables n and constant MAX. MAX cannot change, so to avoid an infinite loop it is essential that n be modified within the loop. Latest, in the body of the outer loop n. is initially 1 and MAX is 20, unless the circumstances arise to make the inner loop infinite, the outer loop should eventually terminate.

The inner loop involves the variables n and factor. Statement in the inner loop modifies n, so it is important that factor be modified in the loop. The good news is that factor is incremented by the if statement. The inner loop contains one statement, the if statement. That if statement has two statements in its body:

```
while (factor < n)
    if (n % factor == 0) {
        cout << factor << " ";
        factor++;
    }
```

If the condition is ever false, the state of the program will not change when the body of the inner loop is executed. This effectively moves the if statement factor:

```
while (factor <= n)
    if (n % factor == 0)
        cout << factor << " ";
        factor++;
```

This new version runs correctly.
