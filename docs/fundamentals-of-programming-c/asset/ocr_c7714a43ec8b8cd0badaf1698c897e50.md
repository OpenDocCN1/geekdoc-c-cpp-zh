> After Assignment

Figure 17.1: Object slicing during assignment of a derived class to a base class

is not possible; even though FancyText object is a Text object, we cannot say any Text object is a FancyText object (it could be a FixedText object or just a Text object without any special decoration). Figure 17.2 shows how an attempted assignment was meaningless because the base class instance has missing information needed by the derived class. Failure to properly assign all the fields in the derived class instance produce an object that is not well defined, as C++ does not allow the assignment.

FixedText instances do not contain any additional data that plain Text instances do not have, but the assignment rules remain the same:

```
Text t1("ABC");
FixedText t3;
cout << t1.get() << " " << t3.get() << endl;
t1 = t3;
cout << t1.get() << " " << t3.get() << endl;
```

is legal and produces

```
ABC FIXED
FIXED FIXED
```
