In Listing 6.3 (countup.cpp) the expression

```
input != 'Y' && input == 'y' && input != 'N' && input != 'n'
```

is true if the variable input is not equal to one of the listed character literals. The Boolean
variable controls the loop's execution. It is important to note that the expression

```
!done
```

inside the while evaluates to the opposite truth of the variable done: the expression
does not affect the value of done. In other words, the operator assigned to a variable does not modify the
variable's value. In order to change the variable done, you would need to reassign it, as

```
done = !done // Invert the truth value
```

For Listing 6.3 (countup.cpp) we have no need to insert its value. We ensure that its value is false initially
 then make it true when the user enters a capital or lower-case N.
