Interestingly, the toupper function returns an int, not a char. At the enhanced level 4 for Visual C++ a cast is required to assign the result to the variable upper:

```
char upper = static_cast<char>(toupper(lower));
```

Some of the more useful functions are described in Table 8.2.

| charfunctions Module |
| int toupper (int ch) | Returns the uppercase version of the given character; returns the original character if no uppercase version exists (such as punctuation or digits) |
| int tolower (int ch) | Returns the lowercase version of the given character; returns the original character if no lowercase version exists (such as for punctuation or digits) |
| int isupper (int ch) | Returns a nonzero value (true) if ch is an uppercase letter ('A'-'Z'); otherwise, returns 0 (false) |
| int islower (int ch) | Returns a nonzero value (true) if ch is a lowercase letter ('a'-'z'); otherwise, returns 0 (false) |
| int isalpha (int ch) | Returns a nonzero value (true) if ch is a letter from the alphabet ('A'-'Z' or 'a'-'z'); otherwise, returns 0 (false) |
| int isdigit (int ch) | Returns a nonzero value (true) if ch is a digit ('0'-'9'); otherwise, returns 0 (false) |

Table 8.2: A few of the functions from the cctype library

Other functions exist to define if a character is a punctuation character like a comma or semicolon (ispunct), a space, tab, or newline character (isspace).

To use the Standard character functions in your C++ program, you must include the <cctype> header file.
