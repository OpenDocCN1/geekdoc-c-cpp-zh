As in the case of the **int** type, the range of floating-point numbers is limited, each value requires a fixed amount of memory. In some ways, **ints** are very different from **doubles**. Any integer within the range of int type can be represented exactly. This is not true for the floating-point types. The real $\pi$ contains an infinite number of digits, its value can only be approximated. The number of digits is limited, so a finite number of digits can only be approximated; for example, the number 3.141592653589793 contains too many digits for the **double** type and must be approximated as 3.230249863404. We can express floating-point numbers in scientific notation. Most programming editors do not use superscript and special symbols like $\times$, C++ shifts the normal scientific notation. The number $6.022 \times 10^{23}$ is written as **6.022e23**. The number to the left of the **e** to the right is the exponent of 10. Another example, $-5.1 \times 10^4$ is expressed in C++ as **-5.1e-4**. Listing 3.9 (scientificnotation.cpp) prints some scientific constants using scientific notation.

#include <iostream>

## 3.5 CONSTANTS

In Listing 3.9 (scientificnotation.cpp), Avogadro's number and the speed of light are scientific constants; that is, the degree of precision to which they have been measured and/or calculated, do not vary. C++ supports many constants. Constants are declared as variables with the addition of the const keyword:

```cpp
const double PI = 3.14159;
```

Once declared and initialized, a constant can be used like a variable in all one way—a constant may not be reassigned. It is illegal for a constant to appear on the left side of the assignment operator (=) outside its declaration. A consequent statement like

```cpp
PI = 2.5;
```

would cause the compiler to issue an error message:

```
error C3892: 'PI': you cannot assign to a variable that is const
```

and fail to compile the program. Since the scientific constants do not change, Listing 3.10 (const.cpp) is a better version of Listing 3.9 (scientificnotation.cpp).

Listing 3.10: iostream
```cpp
#include <iostream>

using namespace std;

int main() {
    const double avogadro_number = 6.022e23, c = 2.998e8;
    cout << "Avogadro's number = " << avogadro_number << endl;
    cout << "Speed of light = " << c << endl;
}
```

Since it is illegal to assign a constant outside of its declaration statement, all constants must be initialized where they are declared.

By convention, C++ programmers generally express constant names in all capital letters; in this way, from the source code a human reader can distinguish a constant quickly from a variable.

## 3.6 Other Numeric Types

C++ supports several numeric data types:

- long int—typically provides integers with a greater range than the int type; its name is long. It is guaranteed to provide a range of integer values at least as large as the int type. An integer with a L suffix, as in 1L, has type long. A lower case (l) is allowed as a suffix, but do not use it because it is difficult for human readers to distinguish between 1 (lower case ell) and 1 (digit one). The L suffix is used with literal values only; you cannot change an int variable into a long by appending an L. Attempting to do so would change the name of the variable!

## 3.7 Characters

The char type is used to represent single characters: letters of the alphabet (both upper and lower), digits, punctuation, and control characters (like newline and tab). Most systems support the American Standard Code for Information Interchange (ASCII) character set. Standard ASCII can represent 128 different characters.

In C++ source code, characters are enclosed by single quotes (''), as in

Standard (double) quotes "" are reserved for strings, which are composed of characters, but strings and chars are very different. C++ strings are covered in Section F.7. The following statement would produce a compiler error:

```cpp
ch = "A"
```

since a string cannot be assigned to a character variable.

Internally, char are stored as integer values, and C++ permits assigning numeric values to char variables and assigning characters to numeric values. The statement

```cpp
ch = 65;
```

assigns a number to a char to show that this is perfectly legal. The value 65 is the ASCII code for the character A. If ch is printed, as in

```cpp
ch = 65;
cout << ch;
```

the corresponding character, A, would be printed ch's declared type is char, not int or some other numeric type.

Listing 31.1: charexample.cpp shows how characters can be used within a program.

```cpp
Listing 31.1: charexample.cpp
#include <iostream>

using namespace std;

int main() {
    char ch1, ch2;
    ch1 = 65;
    ch2 = 'A';
    cout << ch1 << " " << ch2 << " " << 'A' << endl;
}
```

The program displays

A, A, A

The first A is printed because the statement

```cpp
ch1 = 65;
```

assigns the ASCII code for A to ch1. The second A is printed because the statement

```cpp
ch2 = 'A';
```

assigns the literal character A to ch2. The third A is printed because the literal 'A' is sent directly to the output stream.

Integers can be freely assigned to each other, but the range of chars is much smaller than the range of ints, so care must be taken when assigning an int value to a char variable.

Some characters are non-printable characters. The ASCII chart lists several common non-printable characters:

- '\n'—the newline character
- '\r'—the carriage return character
- '\b'—the backspace character
