## 3.1 Integer Values

The number (4) is an example of a numeric value. In mathematics, 4 is an integer value. Integers are whole numbers, which means they have no fractional parts, and an integer can be positive, negative, or zero. Examples of integers include 4, -19, and -1005. In contrast, 4.5 is not an integer, since it is not a whole number.

C++ supports a number of numeric and non-numeric values. In particular, C++ programs can use integer values. It is easy to write a C++ program that presents the number four, as Listing 3.1 (number4.cpp) shows.

```cpp
Listing 3.1: number4.cpp
#include <iostream>
using namespace std;

int main() {
    cout << 4 << endl;
}
```

Notice that unlike the programs we saw earlier, Listing 3.1 (number4.cpp) does not use quotation marks (""). Compare Listing 3.1 (number4.cpp) to Listing 3.2 (number4-alt.cpp).

```cpp
Listing 3.2: number4-alt.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "4" << endl;
}
```

Both programs behave identically, but Listing 3.1 (number4.cpp) prints the value of the number four, while Listing 3.2 (number4-alt.cpp) prints a message containing the digit. The distinction here is unimportant, but we will see in Section 3.2 that the presence or absence of the quotes can make a big difference in the output.

In C++ source, integers may not contain commas. This means we must write the number two-thousand, four hundred sixty-eight as 2468, not 2,468. In mathematics, integers are unbounded; another way, the set of mathematical integers is infinite. In C++, the range of integers is limited because all computers have a finite amount of memory. The exact range of integers supported depends on the system and particular compiler. C++ on most 32-bit systems can represent integers in the range -2,147,483,648 to +2,147,483,647.

What happens if you exceed the range of C++ integers? Try Listing 3.3 (exceed.cpp) on your system.

```cpp
Listing 3.3: exceed.cpp
#include <iostream>

using namespace std;

int main() {
    cout << -30000000000 << endl;
}
```

Negative billion is too large for 32-bit integers, however, and the program’s output is wrong:

```
1294967296
```

The printed value was not negative! Most C++ compilers will issue a warning about this statement. expression::expressionarithmetic explores errors vs. warnings in more detail. If the compiler finds an error in the source, it will not generate the code. A warning indicates a potential problem and does not stop the compiler from producing an executable. Here we see that the programmer should heed this warning because the program's execution produces meaningless output.

This limited range of values is common among programming languages since each integer is stored in a fixed amount of memory. Larger numbers require more memory in memory. To model the infinite set of mathematical integers an infinite amount of memory would be needed! As we see later, C++ supports an integer type with a greater range.

## 3.2 Variables and Assignment

In algebra, variables are used to represent numbers. The same is true in C++, except C++ variables also can represent values other than numbers. Listing 3.4 (variable.cpp) uses a variable to store an integer value and then prints the value of the variable.

```cpp
Listing 3.4: variable.cpp
#include <iostream>

using namespace std;

int main() {
    int x;
    x = 10;
    cout << x << endl;
}
```

The main function in Listing 3.4 (variable.cpp) contains three statements:

- int x;

This is a declaration statement. All variables in a C++ program must be declared. A declaration specifies the type of a variable. The word int indicates that the variable is the integer. The name of the integer is x. We variable x has type int. C++ supports types other than integer, and some types require more or less space in the computer's memory. The compiler uses the declaration to reserve the proper amount of memory to store the variable's value. Due to the compiler it can also check if the variable is being used properly; for example, we see that it can be added together like in mathematics. For some other types, however, addition is not possible and so is not allowed. The compiler can ensure that a variable in an addition is compatible with declaration. It can return an error if it is not.

The compiler will issue an error if a programmer attempts to use a variable.

- x = 10;

This is an assignment statement. An assignment associates the value on the right with the variable on the left. The symbol used is =. A variable can be reassigned multiple times during its lifetime. Listing 3.5 (multipleassignment.cpp) shows this.

```cpp
Listing 3.5: multipleassignment.cpp
#include <iostream>

using namespace std;

int main() {
    int x;
    x = 10;
    cout << x << endl;
    x = 20;
    cout << x << endl;
    x = 30;
    cout << x << endl;
}
```

A variable may be given a value at the time of its declaration; for example, Listing 3.6 (variable-init.cpp) is a variation of 3.4 (variable.cpp).

```cpp
Listing 3.6: variable-init.cpp
#include <iostream>

using namespace std;

int main() {
    int x = 10;
    cout << x << endl;
}
```

Notice that in Listing 3.6 (variable-init.cpp) the declaration and assignment of the variable is performed in one statement. This combined declaration and immediate assignment is called Initialization. C++ supports another syntax for initializing variables in Listing 3.7 (alt-variable-init.cpp).

```cpp
Listing 3.7: alt-variable-init.cpp
#include <iostream>

using namespace std;

int main() {
    int x{10};
    cout << x << endl;
}
```

This alternate form is not commonly used for simple variables, but it necessary initializing more complicated kinds of variables called objects. We introduce objects in Chapter 13 and Chapter 14.
