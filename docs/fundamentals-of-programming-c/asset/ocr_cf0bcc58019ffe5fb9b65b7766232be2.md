# 8.1. INTRODUCTION TO USING FUNCTIONS

```
// Compute the square root
double root = sqrt(input);

// Report result
cout << "Square root of " << input << " = " << root << endl;
```

The line

```
#include <cmath>
```

directs the preprocessor to augment our source code with the declarations of a collection of mathematical functions in the cmath library. The sqrt function is among them. Table 8.1 lists some of the other commonly used mathematical functions available in the cmath library. The compiler needs this augmented code so it can check if we are using the sqrt function properly.

The expression

```
sqrt(input)
```

is a function invocation, also known as the function call. A function provides a service to the code that uses it. Here, our main function is the caller that uses the service provided by the sqrt function. We may main calls, or invoke sqrt passing the value of input. The expression sqrt(input) evaluates to the square root of the variable input. Behind the scenes—inside the black box as it were—special about this precompiled C uses the value of input to compute its square root. There is nothing special about this precompiled C that constitutes the sqrt function; it was written by a programmer or team of programmers for the library using the same tools we have at our disposal. In Chapter 9 we will write our own functions, but for now we enjoy the functions provided for us.

When calling a function, a pair of parentheses follows the function's name. Information that the function requires to perform its task must appear within these parentheses. In the expression

```
sqrt(input)
```

While we say "passing input to the sqrt function", the program is really not giving the function access to main's input variable. The sqrt function itself cannot change the value of main's input variable, it simply uses the value to perform the computation.

The following example may help explain how the communication works between main and sqrt. The main function has to do, but instead of doing all the work, it delegates some of the work (in this case the hard part to sqrt). When main needs to compute the square root of input, it writes down the value of input on a piece of paper and hands it to sqrt. main then sits until sqrt finishes its work. The sqrt function accepts main's note and begins working on the input main gave. When it is finished the task, sqrt returns back to main a different piece of paper with the answer, and sqrt throws away the piece of paper main originally passed to it. main receives the note from sqrt it uses the information on the note and discards the note. The main function can then continue with its other business.

> The term call can be used as well, otherwise to reserve the term call for code that interacts with objects (see Chapter 13).
