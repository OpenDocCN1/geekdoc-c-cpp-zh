# ### 12.1 Sorting

We will use the generic term *sequence* to refer to either a vector or an array. Sorting—arranging the elements within a sequence into a particular order—is a common activity. For example, a sequence of integers may be arranged in ascending order (that is, from smallest to largest) or arranged in lexicographical (commonly called alphabetic) order. Many sorting algorithms exist, some perform much better than others. We will consider one sorting algorithm that is relatively easy to implement.

The selection sort algorithm is relatively easy to implement, and it performs acceptably for smaller sequences. If A is a sequence, and i represents an index with the sequence, selection sort works as follows:

+   1. Set $i = 0$.

+   2. Examine all elements $A[j]$, where $j > i$. If any of these elements is less than $A[i]$, exchange $A[i]$ with the smallest of these elements. (This ensures that all elements after position $i$ are greater or equal to $A[i]$).

+   3. If $i$ is less than the length of $A$, increase $i$ by 1 and go Step 2.

If the condition in Step 3 is not met, the algorithm terminates with a sorted sequence. The command to "goto Step 2" in Step 3 represents a loop. We can begin to translate away description into C++ as follows:

```
// n is A's length
for (int i = 0; i < n - 1; i++) {
// Examine all the elements
// A[j], where j > i;
// If any of these A[j] is less than A[i],
// then exchange A[i] with the smallest of these elements.
}
```
