# 18. FUNCTION TEMPLATES

As another example, consider the following function that computes the sum of the elements in a vector of integers:

```
int sum(const vector<int>& v) {
    int result = 0;
    for (int elem : v) {
        result += elem;
    }
    return result;
}
```

The following client code works:

```
vector<int> v {10, 20, 30};
cout << sum(v) << endl;
```

and 60. The following code does not compile:

```
vector<double> v {10, 20, 30};
cout << sum(v) << endl;
```

The second code fragment attempts to pass a vector of double-precision floating-point values to the sum function. Unfortunately, the sum accepts only types that contain integers. Precisely, sum accepts only arguments of type vector<int>, and a vector<double> object is not a vector<int>. The solution is: just copy and paste the original function and change all the occurrences of "int" to "double", creating an overloaded function:

```
double sum(const vector<double>& v) {
    double result = 0;
    for (double elem : v) {
        result += elem;
    }
    return result;
}
```

This work, if duplicated effort is unsatisfactory. These two overloaded functions are identical except for the types. The actions of the two functions—initialization, vector traversal and arithmetic—are essentially the same. In general, code duplication is undesirable. A programmer who discovers an error in one of the functions must remember to apply the corresponding correction to the function's overloaded counterpart.

Both the less_than functions share a common shortcut: they are tied in some way to a particular type. It would be convenient to specify the type and let the compiler fill in the fields. In the case of less_than we would be able to write a function that uses the < operator for parameters of any type which is compatible. For sum, we would like to create a generic function that works for vectors containing any numeric type.

C++ enables us to write generic functions via templates. A template function specifies a pattern of code, and either the programmer or the compiler supplies the exact type as needed. Listing 18.2 (templateslesthan.cpp) uses C++s template mechanism to create a generic less_than function.
