# 11.1. VECTORS

```
vector<int> list;
vector<double> collection{ 1.0, 3.5, 0.5, 7.2 };
vector<char> letters{ 'a', 'b', 'c' };
```

| collection | letters |
|--- |--- |
| 1.0 3.5 0.5 7.2 | 'a' 'b' 'c' |
| 0 1 2 3 | 0 1 2 |

Figure 11.3: Vectors containing different types of elements. While two different vector objects may contain different types of elements, the elements within a particular vector object must all have the same type.

the expression between the square brackets, in this case 3, is called an index or subscript. The subscript terminology comes from mathematics where subscripts reference elements in a mathematical sequence (for example, $v_2$ represents the second element in the mathematical sequence). Unlike the convention used in mathematics, however, the first element of a vector is at position zero, not one. The expression list[2] can be read as "list two". As a consequence of a zero beginning, if a vector holds n elements, the element in is $a[n-1]$, not $a[n].

An element of a vector accessed via its index behaves like a variable of that type; for example, suppose nums has been declared

```
vector<double> nums(10);
```

This declaration specifies a collection of 10 double-precision-floating elements. The following code shows how we can manipulate some of these elements:

```
// The fourth element
cout << nums[3] << endl;
// The third element is the average of the first and last elements
nums[2] = (nums[0] + nums[4])/2;
// Assign elements at indices 1 and 4 from user input
cin >> nums[1] >> nums[4];
```

Note that the << operator with the cout output stream is not designed to work with vector objects as:

```
cout << nums << endl;           //--- Will not compile!
```

The expression within the [] operator must be compatible with an int. Suppose a is a vector, x is a numeric variable that returns a numeric value, and b is a vector that holds numeric indices. The following examples illustrate the variety of expressions that legal vector indices:

+   * an numeric literal: a[34]
* an numeric variable: a[x]
