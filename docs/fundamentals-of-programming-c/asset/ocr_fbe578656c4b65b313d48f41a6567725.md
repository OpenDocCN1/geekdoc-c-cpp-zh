Notice that a Comparison object wraps a function pointer, contains a swap method, and maintains two integer counters. The comparison object passed to the sort routine customizes the sort's behavior (via its function pointer) and keeps track of the number of comparisons and swaps performs (via its integer counters). In Listing 12.2 (flexibleintort.cpp), the basic structure of the sorting algorithm remains the same regardless of the ordering determined by the comparison object.

| Before: | (23,3,4,215,0,-3,23,100,88,-10) |

| Descending: | (215,100,88,23,4,2,0,-3,-10) (55 comparisons, 0 swaps) |

We see from the results that the number of comparisons is dictated by the algorithm used, but the number of element swaps depends on the ordering of the elements and the nature of the comparison. Sorting an already sorted array with selection sort does not reduce the number of comparisons function must perform, but as we can see, it requires no swaps.
