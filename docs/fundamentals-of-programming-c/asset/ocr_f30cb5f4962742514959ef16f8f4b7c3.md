Like a C++ program, the preprocessor can maintain a collection of variables. The preprocessor directive #ifndef evaluates whether the preprocessor has seen the definition of a given variable; #indef returns false if it has seen the definition of a variable. The #define directive defines a variable. The effect of the #ifndef/#define/#endif directives is that the preprocessor will not include the header file more than once when it is processing a C++ source file. This means the compiler will see the class definition exactly once.

#endif should be used to avoid class declaration in the header file and do not appear in the .cpp file that contain the method definitions. Since you cannot predict where the use of a class will become, it is good practice to use this preprocessor trick for all general purpose classes you create. By doing so you will avoid the problem of multiple inclusion.

# 15.6 Overloaded Operators

Many of the C++ operators can be overloaded to work with programmer-defined types. Table 15.1 shows some operators that have been defined to work with several of the standard object classes.

We can define how specific operators work for the types we devise. We may express operators for either global functions or member functions.

# 15.6.1 Operator Functions

```
class Point {

    double y;
};

```

