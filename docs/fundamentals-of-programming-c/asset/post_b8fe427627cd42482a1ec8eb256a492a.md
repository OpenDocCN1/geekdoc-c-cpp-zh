
## 3.8. ENUMERATED TYPES

- '\a'—the "alert" character (causes a "beep" sound on many systems)
- '\t'—the tab character
- '\f'—the formfeed character
- '\0'—the null character (used in C strings, see Section F.7)

These special non-printable characters begin with a backslash (\) symbol. The backslash is called an escape symbol, and it signifies that the statement follows has a special meaning and should not be interpreted literally. This means the literal backslash character must be represented as two backslashes: '\\\'

These special non-printable escape codes can be embedded within strings. To embed a backslash within a string, use the statement

```cpp
cout << "C:\Dev\cppcode" << endl;
```

would print

```
C:\Dev\cppcode
```

See what this statement prints:

```cpp
cout << "ABCD\aEF" << endl;
```

The following two statements behave identically on most computer systems:

```cpp
cout << "End of line" << endl;
cout << "End of line\n";
```

On the Windows platform, the character sequence "\n" (carriage return, line feed) appears at the end of lines in text files. Under Unix and Linux, text lines end with '\r' (carriage return) character. The compilers on Apple Macintosh adhere to the C++ standard will ensure that the "\n" character in a C++ program sent to the output will produce the same results as the endl manipulator.

## 3.8 Enumerated Types

C++ allows a programmer to create a new, very type and list all the possible values of that type. A type is called an enumerated type, or an enumeration type. The enum keyword introduces an enumerated type

```cpp
enum Color { Red, Orange, Yellow, Green, Blue, Violet };
```

Here, the new type is named Color, and a variable of Color may assume any of the values that appears in the line within the curly braces. The semicolon follows the close curly brace is required. The enumerated type definition is formatted as

```cpp
enum Color {
  Red,
  Orange,
  Yellow,
  Green,
  Blue,
  Violet
};
```

but the formatting moves no different to the compiler.
The values with the curly braces constrain all the values that a variable of an enumerated type can obtain. The name of each of an enumerated type is a valid C++ identifier (see Section 3.3).

Given the Color type defined as above, we can declare and use variables of the enum type as shown by the following code fragment:

```cpp
Color myColor;
myColor = Orange;
```

Here the variable myColor has our custom type Color, and its value is Orange.
It is illegal to reuse an enumerated value within another enumerated type within the same program. In the following code, the enumerated value Light is used in Shade and Weight:

```cpp
enum Shade { Dark, Dim, Light, Bright };
enum Weight { Light, Medium, Heavy };
```

These two enumerated are incompatible because they share the value Light, and so the compiler will issue an error.
The value within an enum type must be unique. Convention in C++ is to capitalize the first letter of an enum and its associated values, although the language does not enforce this convention.

An enum type is handy for representing a small number of discrete, non-numeric options. For example, a program that controls the movements made by a robot. The allowed orientations are forward, backward, left, right, and down. The program can encode these movements as integers, where 0 means forward, 1 means backward, etc. While implementation works, it is not ideal. Integers may assume more values than just the six values. The compiler cannot ensure that an integer representing a move will stay in the range 0... If the programmer makes a mistake and under certain circumstances assigns a value outside of the range 0... then the program may result in erratic behavior with the robot. With enum types, if the programmer uses only the named values of the enum, the compiler will ensure that such a mistake cannot happen.

A particular enumerated type necessarily has fewer values than a type such as int. Imagine making an integer enum type and having to list all of its values! (The 32-bit int represents over four billion values.) Enumerated types, therefore, are practical for types that have a relatively small range of values.

## 3.9 Type Inference with auto

C++ requires that a variable be declared before it is used. Or this means specifying the variable's type, as in

```cpp
int count;
char ch;
double limit;
```

A variable may be initialized when it is declared:

```cpp
int count = 0;
char ch = 'Z';
double limit = 100.0;
```

Each of the values has a value: 0 is an int, 'Z' is a char, and 0.0 is a double. The auto keyword allows the compiler to automatically deduce the type of a variable if it is initialized when it is declared:

```cpp
auto count = 0;
auto ch = 'Z';
auto limit = 100.0;
```

The auto keyword may not be used without an accompanying initialization; for example, the following declaration is illegal:

```cpp
auto x;
```

because the compiler cannot deduce x's type.

> Automatic type deduction is supported by compilers that comply with the latest C++11 standard. Programmers using older compilers must specify a variable's exact type during the variable's declaration.

## 3.10. SUMMARY

- C++ supports kinds of variables.
- In C++ we express scientific notation literals of the form 1.0 × 10^¹ as 1.0e1.
- The qualifier const renders a "variable" unchangeable; it signifies a constant.
- On systems longs have extended range compared to normal ints.
- On systems shorts have reduced range compared to normal ints.
- The unsigned type represents non-negative integers.
- On systems long double have extended precision compared to double.
- The char type represents 8-bit integers.

* A variable can be reassigned.
* A variable can be given an initial value at the time of its declaration.
* Multiple variables can be declared in one declaration statement.
* A variable represents a location in memory capable of storing a value.
* The statement a = b; copies the value stored in b into variable a. a and b still refer to those memory locations.
* A variable name is an identifier. The name of a variable must consist of at least one character. The first symbol must be an alphabetic letter or the underscore. Remaining symbols (if any) must be alphabetic letters, the underscore, or digits.
* Reserved words have special meaning within a C++ program and cannot be used as identifiers.
* Descriptive variable names are preferred over one-letter names.
* C++ is case sensitive; the name X is not the same as the x.
* Floating types represent single-precision floating-numbers, and the double type represents double-precision floating-numbers.
* There are many values f or F can be assigned to a floating-point to signal that it is a float value instead of a double.

Characters are ordered as 8-bit integers. Their values correspond to the ASCII code.
* A char can be assigned to an int variable, and an int value can be assigned to a char variable. char and ints are readily interchangeable in C++.
* Character literals appear within single quote marks ('\'), unlike literal strings that appear within double quote marks ("").
* Special non-printable control codes use newline and are prefixed with the backslash escape character (\).
* The '\n' character is an alternative to using endl to end a printed line.
