First, notice that in the recursive call the argument begin is one larger, and end remains the same.
This means as recursion progresses the ending index never changes, and the beginning index keeps
increasing until it reaches the ending index. The recursion terminates when begin becomes equal to end.

In its simplest form the function looks like this:

```
void permute(int *a, int begin, int end) {
    if (begin == end)
        // Print the whole vector
    else
        // Do the interesting part of the algorithm
}
```

Let us zoom in on the interesting part of the algorithm (all the comments):

```
for (int i = begin; i <= end; i++) {
    swap(a[begin], a[i]);
    permute(a, begin + 1, end);
    swap(a[begin], a[i]);
}
```

If the mixture of iteration and recursion is confusing, imagine you replace the loop with the statements in its
duplicated that many times; for example, we can rewrite the code

```
for (int i = 0; i < 5; i++)
    cout << i << i << endl;
```

as

```
cout << 0 << endl;
cout << 1 << endl;
cout << 2 << endl;
cout << 3 << endl;
cout << 4 << endl;
```

Notice that the loop is gone. Process of transforming a loop into a series of statements that the
loop would perform is known as loop unrolling. Compilers unroll loops to make the code's
execution faster. After unrolling the loop control variable (in this case i) is gone, so there is no
t to initialize it (it done once), and, importantly, no need to check its value and update it during each
iteration of the loop.

Our purpose for unrolling the loop in perform is not to optimize it. We are trying to understand
better how the algorithm works. In order to unroll perform's loop, we will consider the case for vectors
containing exactly three elements. In this case for the perform function would be hardcoded as

```
for (int i = 0; i <= 2; i++) {
    swap(a[begin], a[i]);
    permute(a, begin + 1, end);
    swap(a[begin], a[i]);
}
```
