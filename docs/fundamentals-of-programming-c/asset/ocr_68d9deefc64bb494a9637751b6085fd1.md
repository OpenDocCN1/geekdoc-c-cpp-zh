Nested if/else statements are required, and the form of these nested if/else statements is shown in Listing 5.14(digitittoword.cpp).

# Listing 5.14: digitittoword.cpp

```
#include <iostream>

using namespace std;

int main() {
    int value;
    cout << "Please enter an integer in the range 0..5: ";
    cin >> value;
    if (value < 0)
        cout << "Too small";
    else
        if (value == 0)
            cout << "zero";
        else
            if (value == 1)
                cout << "one";
            else
                if (value == 2)
                    cout << "two";
                else
                    if (value == 3)
                        cout << "three";
                        else
                            if (value == 4)
                                cout << "Four";
                            else
                                if (value == 5)
                                    cout << "five";
                                else
                                    cout << "Too large";
    cout << endl;
}
```

Observe the following Listing 5.14(digitittoword.cpp):

+   * It prints one of each message depending on the user's input.
* Notice that each if body contains a single printing statement and each else body, except the last one, contains an if statement. The control logic forces program execution to check each condition in turn. The first condition that matches wins, and its corresponding body will be executed. If none of the conditions are true, the last else is printed.
* No curly braces are necessary to delimit the if or else bodies since each body contains only a single statement (although a deeply nested if/else statement is a mighty thing).

Listing 5.14(digitittoword.cpp) is formatted according to the conventions used in earlier examples. As a consequence, the mass of text drifts as more conditions are added. A commonly used alternative style, shown in Listing 5.15(restledigitittoword.cpp), avoids this right drift.
