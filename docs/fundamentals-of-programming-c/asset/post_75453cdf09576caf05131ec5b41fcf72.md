Like the vector class (Section 11.1.3), the string class provides a number of methods. Some string methods include:

- **operator[]** provides the value stored at a given index within the vector
- **operator=** assigns one string to another
- **operator+=** appends a string or single character to the end of a string object
- **at** provides bounds-checking access to the character stored at a given index
- **length** returns the number of characters that make up the string
- **size** returns the number of characters that make up the string (same as length)
- **find** locates the index of a substring within a string object
- **substr** returns a new string object made of substring of an existing string
- **empty** returns true if the string contains no characters; returns false if the string contains one or more characters
- **clear** makes the vector empty.

The following code fragment

```
string word = "computer";
cout << "\"" << word << " contains " << word.length()
<< " letters." << endl;
```

prints

```
"computer" contains 8 letters.
```

The expression:

```
word.length()
```

invokes the length method on behalf of the word object. The string class provides a method size that behaves exactly like the length method.

The string class defines a method named operator[] that allows a programmer to access a character within a string, as

```
cout << "The letter at index 3 is " << word.operator[] (3) << endl;
```

Here the operator[] method uses the same syntax as the length method, but the operator[] method expects a single integer parameter. The above code fragment is written as

```
cout << "The letter at index 3 is " << word[3] << endl;
```

## 13.2 Input/Output Streams

We have used iostream stream object from the beginning. cout is the output stream object that prints to the screen. cin is the input stream that receives values from the keyboard. The precise type of cout is ostream, and cin's type is istream.

Like others, cout and cin have methods. The << and >> operators are the methods operator<< and operator>>. (The operators << and >> are normally used on integers to perform left and right bitwise operations; see Appendix E for more information.) The following code fragment

```
cin >> x;
cout << x;
```

can be written in the explicit method call as:

```
cin.operator>>(x);
cout.operator<<(x);
```

The first statement calls the operator>> method on behalf of the cin object passing in variable x by the reference. The second statement calls the operator<< method on behalf of the cout object passing the value of variable x. A statement such as

```
cout << x << endl;
```

is a pleasant way of expressing

```
cout.operator<<(x).operator<<(endl);
```

Reading the left to right, the expression cout.operator<<(x) prints x's value on the screen and returns the cout object itself. The return value (simple cout) is then used to invoke the operator<< method with endl as its argument.

A statement such as

```
cin >> x >> y;
```

can be written

```
cin.operator>>(x)(y);
```

As is the case of operator<< with cout, reading left to right, the expression cin.operator>>(x) calls the operator>> passing variable x by reference. It reads the value from the keyboard and assigns it to x. The method call returns cin itself, and the return value is used immediately to invoke operator>> passing y by reference.

Listing 13.3 (betterintinput.cpp) detects illegal input and continues to receive input until the user provides an acceptable value.

### Listing 13.3: betterintinput.cpp

```cpp
#include <iostream>
#include <limits>
using namespace std;
int main() {
    // I hope the user does the right thing!
    cout << "Please enter an integer";
    // Enter and remain in the loop as long as the user provides
    // bad input
    while (!(cin >> x)) {
        // Report error and re-prompt
        cout << "Bad entry, please try again";
        // Clean up the input stream
        cin.clear(); // Clear the error state of the stream
        // Empty the keyboard buffer
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
    }
    cout << "You entered " << x << endl;
}
```

We learned in Section 6.1 that the expression cin >> x has a Boolean value that we may use in a conditional or iterative statement. If the user enters a value with a type compatible with the declared type of the variable, the expression evaluates to true; otherwise, it is interpreted as false. The negation ! (cin >> x) is true if the input is bad, so the only way to execute the body of the loop is provide illegal input. As long as the user provides bad input, the program's execution stays inside the loop.
