# 18. ITERATOR RANGES

```

```

Observe that the selection_sort function in List 18.15 (genericogflexiblesort) does not restrict the sequence to be a vector or an array. The first two parameters of selection_sort are generic, and the code within the function treats these parameters as if they are pointers. Since objects behave like pointers to the elements within selection_sort, the compiler can instantiate the template to accept either pointer or iterator ranges. Similarly, the print function works equally well with pointer ranges for arrays and for vectors. The main function demonstrates the flexibility of print and selection_sort functions by sending both array ranges and vector ranges. This means the compiler will automatically instantiate two overloaded print functions and works.
