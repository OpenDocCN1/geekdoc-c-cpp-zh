
## 11.1. VECTORS

The general form of this range-based for statement is

```cpp
for ( type elementvariable : vectorvariable ) statement using elementvariable
```

If the element variable within the range-based for loop is declared to be a reference, the code within the body of the loop may modify the vector's elements. Listing 11.5 (foreachexample.cpp) allows a user to populate a vector with 10 numbers and then prints the vector's contents.

# Listing 11.5: foreachexample.cpp

```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
    // Declare a vector of ten numbers
    vector<double> vec(10);

    // Allow the user to populate the vector
    cout << "Please enter 10 numbers: ";
    for (double& elem : vec) {
        cin >> elem;
    }

    // Print the vector's contents
    for (double& elem : vec) {
        cout << elem << endl;
    }
}
```

Note that the range-based for statement in Listing 11.5 (foreachexample.cpp) uses a reference to assign each element to the vector. The second range-based for statement does not need to use a reference variable because it is not possible to change any of the contents of vector variable. The range-based for statement iterates forward through the vector elements and cannot move backwards. The range-based statement is not convenient if you want to consider only a portion of the elements in the vector. Examples include visiting every element in the vector or considering only the first third of the elements. In these specialized cases a standard for loop with an integer counter is the better choice.

### 11.1.3 Vector Methods

A vector is, and objects differ from the simple types like int, double, and bool, in a number of ways. Most objects have access to special functions called methods. C++ programmers often offer methods as member functions. A method is a function associated with a class of objects. A method invocation involves a slightly different syntax than a function; for example, if obj is an object that supports a method named f that accepts no parameters, you can invoke f on obj with the statement:

```cpp
obj.f();
```

The dot operator connects an object to a method to invoke. Other than this special invocation syntax, methods work very much like the global functions introduced in Chapter 8. A method may accept parameters and return a value.

Vectors support a number of methods, but we will focus on seven of them:

- push_back—inserts a new element onto the back of a vector
- pop_back—removes the last element from a vector
- operator[]—provides the value stored at a given index within the vector
- at—provides bounds-checking access to the value stored at a given position within the vector
- size—returns the number of values currently stored in the vector
- empty—returns true if the vector contains no elements; false if the vector contains one or more elements
- clear—makes the vector empty.

We have seen how to declare a vector of a particular size and use the space provided; however, we are not limited by a vector's initial size. In order to add an element to a vector, we use the push_back method as follows:

```cpp
vector<int> list;           // Make an empty vector that can hold integers
list.push_back(5);              // Add 5 to the end of list
list.push_back(-3);             // Add -3 to the end of list
list.push_back(12);             // Add 12 to the end of list
```

After executing the three pop_back calls above, the list conceptually looks just like Figure 11.2. The size of the vector increases automatically as new elements are inserted onto the back of Each. Each push_back call increases the number of elements in a vector by one.

The pop_back method performs the opposite action of push_back. Each pop_back removes the last element from a vector, effectively reducing the number of elements in the vector by one. The following code fragment removes a vector named list that contains only the element 5.

```cpp
vector<int> list;      // Declare list to be a vector
list.push_back(5);              // Add 5 to the end of list
list.push_back(-3);             // Add -3 to the end of list
list.push_back(12);             // Add 12 to the end of list
list.pop_back();                // Removes 12 from the list
list.pop_back();                // Removes -3 from the list
```

We have been using the operator[] method to access an element in the vector. The word operator is reserved in C++, that makes this method even more interesting. The expression

```cpp
vec.operator[][](2)
```

is the long way to write

```cpp
vec[2]
```

Programmers use the shorter syntax exactly, but the longer expression illustrates the fact that the square bracket `}` operator is really a class method.

As we have seen, a programmer must be vigilant about avoiding an out-of-bounds index with the `operator[]` method. The vector class provides an additional method, `at`, that provides bounds checking. Checking expression `vec[x]` in and itself provides no bounds checking and so may prevent undefined behavior. The functionally equivalent `vec.at(x)` will ensure that the index `x` is within the bounds of the vector.
