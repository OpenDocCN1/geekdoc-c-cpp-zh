## 13.1 String Objects

C++ is object-oriented. It was not the first OO programming language, but it was the first OO language that gained widespread use in a variety of application areas. An OO programming language allows the programmer to define, create, and manipulate objects. Variables representing objects can have considerable functionality than the primitive variables like ints and doubles. Like a normal variable, every C++ object has a type. An object is an instance of a particular class, and class means the same as type. An object's type is its class. We have used cout and cin for objects some time. cout is an instance of the ostream—which is to say type ostream. cin is an instance of istream.

Code that uses an object is a client of that object; for example, the following code fragment `cout << "Hello" << endl;`

```cpp
cout << "Hello" << endl;
```

uses the cout and, therefore, is a client of cout. Many of the functions we have seen so far are clients of cout and/or cin objects. Objects provide services to their clients.

A string is a sequence of characters, most often used to represent words and names. The C++ standard library provides the class string. In order to use string objects, you must provide the preprocessor directive:

```cpp
#include <string>
```

The string class is part of the namespace, which means its full name is std::string. If you use the

```cpp
using namespace std;
```

or

```cpp
using std::string;
```

statements in your code, you can use the abbreviated name string.

You declare a string object like any variable:

```cpp
string name;
```

You may assign a literal sequence to a string via the familiar string quotation syntax:

```cpp
string name = "joe";
cout << name << endl;
name = "jane";
cout << name << endl;
```

You may assign one object to another using the simple assignment operator:

```cpp
string name1 = "joe", name2;
name2 = name1;
cout << name1 << " " << name2 << endl;
```

In this case, the assignment statement copies the characters making up name1 to name2. After the assignment both name1 and name2 have their own copies of the characters that make up string;
