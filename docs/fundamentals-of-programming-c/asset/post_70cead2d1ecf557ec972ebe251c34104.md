shows that vector formal parameter is declared like a non-vector formal parameter. In this case, the print function uses by value, so during the program's execution invocation of **print** will copy the data in the actual parameter (**list**) to the formal parameter (v). Once a vector parameter can be quite large, it is generally inefficient to pass by value as shown above. Pass by value requires a function invocation to create a new vector object for the formal parameter and copy all the elements of the actual parameter into the new vector which is local to the function. A better approach uses by reference, with a twist:

The **&** symbol indicates that a caller invoking **print** will pass by reference (see Section 10.8). This copies the address of the actual parameter (owned by the caller) to the formal parameter v instead of making a copy of all the data in the caller's vector. Passing the address is much more efficient because most systems are the same size as a single int, whereas a vector could, for example, 1,000,000 ints. With value function invocation would have to copy all 1,000,000 integers from the caller's actual parameter into the function's formal parameter.

Section 10.8 indicates that call-by-value parameter passing is preferred to call-by-reference parameter passing. Because using a function passing by value cannot modify the actual variable passed to the caller. Observe that our new print function declares the formal parameter v to be a const reference. This means the function cannot modify the actual parameter by the caller. A vector object with a const reference allows to achieve the efficiency of passing with the safety of pass by value

Like the print function, the sum function in List 11.7 (vector.cpp) does not intend to modify the contents of its vector parameter. The sum function only looks at the vector's contents, vector parameter should be declared as a const reference. If a function's purpose is to modify a vector, the reference should not be const. // List 11.8: makerandomvector.cpp
```cpp
#include <iostream>
#include <vector>
#include <cstdlib> // For rand

using namespace std;

/*
* print(v)
* Prints the contents of an int vector
* v is the vector to print; v is not modified
 */
void print(const vector<int>& v) {
    for (int elem : v) {
        cout << elem << " ";
    }
    cout << endl;
}

/*
* make_random(v)
* Fills an int vector with pseudorandom integers
* v is the vector to fill; v is modified
* size is the maximum size of the vector
 */
void make_random(vector<int>& v, int size) {
    v.clear(); // Empties the contents of vector
    int n = rand() % size; // Random size for v
    for (int i = 0; i < n; i++) {
        v.push_back(rand()); // Populate with random values
    }
}

int main() {
    srand(2); // Set pseudorandom number generator
    vector<int> list;
    // Print the contents of the vector
    cout << "Vector initially: ";
    print(list);
    make_random(list, 20);
    cout << "1st random vector: ";
    print(list);
    make_random(list, 5);
    cout << "2nd random vector: ";
    print(list);
    make_random(list, 10);
    cout << "3rd random vector: ";
    print(list);
}
```

The make_random function in Listing 11.8 (makerandomvector.cpp) calls the vector method clear which makes a vector empty. We call clear first to ensure the vector is empty before we add elements. The function proceeds to add random number of integers to the empty vector. A function may return a vector. Listing 11.9 (primelist.cpp) is a practical example of a function that returns a vector.

```cpp
// Listing 11.9: primelist.cpp
#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

/*
* print(v)
* Prints the contents of an int vector
* v is the vector to print; v is not modified
*/
void print(const vector<int>& v) {
    for (int elem : v) {
        cout << elem << " ";
    }
    cout << endl;
}

/*
* is_prime(n)
* Determines the primality of a given value
* an integer to test for primality
* Returns true if n is prime; otherwise, false
*/
bool is_prime(int n) {
    if (n < 2)
        return false;
    else {
        bool result = true; // Provisionally, n is prime
        double root = sqrt(n);
        // Try all possible factors from 2 to root
        for (int trial_factor = 2; trial_factor <= root; trial_factor++) {
            if (n % trial_factor != 0) {
                result = false;
            }
        }
        return result;
    }
}

/*
* primes(begin, end)
* Returns a vector containing the prime
* numbers in the range begin..end.
* begin is the first number in the range
* end is the last number in the range
*/
vector<int> primes(int begin, int end) {
    vector<int> result;
    for (int i = begin; i <= end; i++) {
        if (is_prime(i)) {
            result.push_back(i);
        }
    }
    return result;
}

int main() {
    int low, high;
    cout << "Please enter lowest and highest values in the range: ";
    cin >> low >> high;
    vector<int> prime_list = primes(low, high);
    print(prime_list);
}
```

The primes function declares a local variable named result. The function examines every value in the range begin..end. The primes function uses is_prime as a helper function, which classifies values as a prime, code within primes adds to the result. After primes has considered all the values in the provided range, result will contain all the prime numbers in that range.

When returning a value that is a built-in scalar like int, double, char, etc., a C++ function normally makes a copy of the local value to return to the caller. Making a copy is necessary because local variables exist only while the function is executing and when the function finishes, the run-time environment reclaims the memory used by the function's local variables and parameters can be used by other functions. The return value in primes is not a simple scalar—it is an object that can be quite large, especially if passes a range. Modern C++ compilers generate machine code that eliminates the need to copy the local result. The technique is known as return value optimization, and it comes into play when a function returns an object declared within the function. With value optimization, the compiler knows that the variable will disappear and the variable is to be returned to the caller; therefore, it generates machine code that makes the space for the result in the caller's memory space, not the local function. Because caller is maintaining the space for the object, it persists after the function returns. Because of return value optimization you can return vectors by value without fear of a time-consuming copy operation. Due to the fact that vectors may contain a large number of elements, you should pass vectors to functions as reference parameters rather than value parameters:

- If the function is meant to modify the contents of the vector, declare the vector as a non-const reference (that is, omit the const keyword when declaring the parameter).
- If the function is not meant to modify the contents of the vector, declare the vector as a const reference.

It is generally safe to return a vector by value from a function if that vector is declared local to the function. Modern C++ compilers generate optimized code that avoids the overhead of copying the result back to the caller.

## 11.1.5 Multidimensional Vectors

The vectors have so far been one dimensional—simple sequences of values. C++ supports higher-dimensional vectors. A two-dimensional vector is best visualized as a table with rows and columns.

The statement

`vector<vector<int>> a(2, vector<int>(3));`

effectively declares a to be a two-dimensional (2D) vector of integers. It literally creates a vector with two elements, and each element is itself a vector containing three integers. Note that the type of a is a vector of integers. A 2D vector is sometimes called a matrix. In this case, the declaration specifies that 2-D contains two rows and three columns. Figure 11.5 shows the logical structure of the vector created by the following sequence of code:

```cpp
vector<vector<int>> a(2, vector<int>(3));
a[0][0] = 5;
a[0][1] = 19;
a[0][2] = 3;
a[1][0] = 22;
a[1][1] = -8;
a[1][2] = 10;
```

The two-dimensional vector a is said to be a 2×3 matrix, meaning it has two rows and columns (as shown in Figure 11.5). Rows are arranged horizontally, and the values in columns are arranged vertically. In each of the assignment statements above, for example

```
a[1][0] = 22;
```

the first index (here 1) signifies the second index (here 0) denotes the column of the element within the vector. The expression a[1][0] means (a[1]) [0]; that is, the element at index 0 of the vector at index 1 within a.

Using a syntax similar to the initialization lists of one-dimensional vectors, we can declare and initialize the 2D vector from above:

```cpp
vector<vector<int>> a{{5, 19, 3}, {22, -8, 10}};
```
