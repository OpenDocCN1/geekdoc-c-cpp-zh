In order to determine if any of the elements is less than A[i], we introduce a new variable named
small. The purpose of small is to keep track of the smallest element found so far. We
will set small equal to i initially because we wish to locate any element less than the element at
position i.

```
// n is A's length
for (int i = 0; i < n - 1; i++) {
    // small is the position of the smallest value we've seen
    // so far; we use it to find the smallest value less than A[i]
    int
    small = i;
    for (int j = i + 1; j < n; j++) {
        if (A[j] < A[i])
            small = j; // Found a smaller element, update
    }
    // If small changed, we found an element smaller than A[i]
    if (small != i)
        exchange A[i] and A[i]
}
```
