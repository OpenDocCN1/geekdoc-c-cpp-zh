## Convenient-quality Pseudandom Numbers

In Section 13 we used classes from the standard library to generate high-quality pseudorandom numbers. Listing 16.10 (highqualityrandom.cpp) used three kinds of objects—random_device, mt19937, and uniform_int_distribution—to produce good sequences. The C++ class allows us to combine multiple sources of randomness into one convenient package.

Listing 16.12: uniformrandom.h

```cpp
#ifndef UNIFORM_RANDOM_DEFINED
#define UNIFORM_RANDOM_DEFINED

#include <random>

using std::random_device;
using std::mt19937;
using std::uniform_int_distribution;

class UniformRandomGenerator {
    // A uniform distribution
    uniform_int_distribution<int> dist;
    // A Mersenne Twister random generator with the seed
    mt19937 mt;

public:
    // The smallest pseudorandom number generator can produce
    int MIN;

    // The largest pseudorandom number generator can produce
    int MAX;

    // Create a pseudorandom generator that produces values in low...high
    UniformRandomGenerator(int low, int high) : dist(low, high), mt(random_device{}()) {}

    // Return a pseudorandom number in MIN...MAX
    int operator() {
        return dist(mt);
    }
};

#endif


The UniformGenerator class provides a simplified interface to programmers who need access to high-quality pseudorandom numbers. Every UniformGenerator object contains its mt19937 field and a uniform_int_distribution. The constructor accepts the range of pseudorandom numbers and initializes the mt19937 field with a seed. To accumulate the results of 10 trials, with each trial generating 1,000,000,000 pseudorandom numbers, the UniformGenerator uses the random_device only for creating its mt19937 field. The UniformGenerator also provides an operator() method. This allows a client to "call" an object as if it were a function. Given a UniformGenerator object named gen, we can assign a pseudorandom number to an integer x with the statement

```cpp
int x = gen();
```

This statement may appear to be calling a global function named gen; in fact, it is calling the operator() method of the UniformGenerator class on behalf of gen. The expression gen() is syntactic sugar for gen.operator(), but it is simply invoking the UniformGenerator::operator() method on behalf of gen passing no arguments in the empty part of parentheses.

Listing 16.13 (testorandom.cpp) is a simple rename of Listing 16.10 (highqualityrandom). In Listing 16.13 (testorandom.cpp) we see that our UniformGenerator class can generate high-quality pseudorandom numbers with a single object that is simple to use.

# Listing 16.13: testorandom.cpp

```cpp
#include <iostream>
#include "uniformorandom.h"

using namespace std;

int main() {
    // Pseudorandom number generator with range 0...9,999
    UniformRandomGenerator rand(0, 9999);

    // Total counts over all the runs.
    // Make these double-precision floating-point numbers
    // so the average computation at the end will use floating-point
    // arithmetic.
    double total = 0.0, total9995 = 0.0;

    // Accumulate the results of 10 trials, with each trial
    // generating 1,000,000,000 pseudorandom numbers = 10;
    const int NUMBER_OF_TRIALS = 10;

    for (int trial = 1; trial < NUMBER_OF_TRIALS; trial++) {
        // Initialize counts for this run of a billion trials
        int count = 0, count9995 = 0;
        for (int i = 0; i < 1000000000; i++) {
            // Generate a billion pseudorandom numbers in the range
            // 0...9,999 and count the number of 5 and 9,995 appear
            int r = rand();
            if (r == 5) count++; // Number 5 generated, so count it
            if (r == 9995) count9995++;
        }
        cout << "Trial " << trial << ": " << count << " fives, " << count9995 << " nine-995s" << endl;
        total += count;
        total9995 += count9995;
    }

    cout << "Average fives: " << total / NUMBER_OF_TRIALS << endl;
    cout << "Average nine-995s: " << total9995 / NUMBER_OF_TRIALS << endl;

    return 0;
}
```
