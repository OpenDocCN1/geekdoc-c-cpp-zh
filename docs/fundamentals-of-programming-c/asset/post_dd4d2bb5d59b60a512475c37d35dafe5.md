
## 13.5. BETTER PSEUDORAND NUMBER GENERATION

The rand function cannot return a value greater than 32,767; specifically, in our program above, **rand** cannot produce 39,995. Listing 13.8 (badrand.cpp), therefore, using **rand** and modulus we can produce 9,995 in three different ways: 9,995, 19,995, and 29,995. Based on our analysis, Listing 13.8 (badrand.cpp) can generate the number 5 different ways and 9,995 different ways. This 3:4 ratio agrees with our empirical observations of the Behavior of Listing 13.8 (badrand.cpp). The consequences of this bias means that values in the relatively small range 0...2,767 will appear disproportionately more frequently than numbers in the range 2,766...9,999. Such bias is undesirable in a pseudorandom number generator.

We must use more sophisticated methods to produce pseudorandom numbers. Unfortunately C++11 provides standard classes that provide high-quality pseudorandom generators worthy of scientific and mathematical applications.

The **rand** function has another weakness that makes it unsuitable for scientific, engineering, and mathematical applications. **rand uses** a linear congruential generator algorithm (see https://en.wikipedia.org/wiki/linear_congruential_generator) **rand has** a relatively small period. This means that the pattern of the sequence of numbers it generates will repeat itself if you call rand enough times. For Visual C++, rand's period is 2,147,483,648. Listing 13.9 (randperiod.cpp) verifies...

```
Listing 13.9: randperiod.cpp
```cpp
#include <iostream>
#include <cmath>
#include <cstdlib>
#include <ctime>

using namespace std;

int main() {
    // Set random number seed value
    srand(rand());

    // To use numbers larger than regular integers; use long long
    for (long long i = 1; i <= 4294967400LL; i++) {
        int r = rand();
        if (i <= 1 && i <= 0)
            cout << i << ": " << r << endl;
        else if (i <= 2147483645 && i <= 2147483656)
            cout << i << ": " << r << endl;
        else if (i <= 429467293LL && i <= 4294673099LL)
            cout << i << ": " << r << endl;
    }
}
```

Notice that after 2,147,483,648 iterations the program begins to print the same numbers in the same order as it began. 2,147,483,648 iterations later (after 4,294,967,296 total iterations) the sequence repeats. A careful observer could detect this repetition and thus some time might be to predict the next pseudorandom value that the program would produce. A predictable pseudorandom number generator is not a good number generator. Such a generator used in a game of chance would render the game perfectly predictable by clever players. A better pseudorandom number generator would have a much longer period. The Mersenne twister (https://en.wikipedia.org/wiki/Mersenne_twister) is widely used, high-quality pseudorandom number generator. It has a very long period, $2^{19937}-1$, which is approximately $4.311 \times 10^{6002}$. If an implementation of the Mersenne twister could generate 1,000,000,000 (one billion) numbers every second, a program would run for about $1.368 \times 10^{85}$ years before it begins to repeat. It is safe to assume that an observer will not be able to wait long enough to witness a pattern in the sequence. The standard C++ library contains class which can instantiate objects to generate numbers using the Mersenne twister algorithm. Generating pseudorandom numbers is one thing, ensuring that the numbers are fully distributed within a specified range of values is another concern. Fortunately, the standard C++ library provides a multitude of classes that allow us to shape the production of mt19937 object into a mathematically sound distribution. Our pseudorandom generator consists of three pieces:

- an object that produces a random seed value
- a pseudorandom number generator that we construct with the random seed object,
- a distribution object that uses the pseudorandom number generator to produce a sequence of pseudorandom numbers that are uniformly distributed.

The C++ classes for these objects are:

- The seed object is an instance of random_device class.
- The pseudorandom number generator is an instance of mt19937 class.
- The distribution object is an instance of uniform_int_distribution class.

We use the random_device object in place of rand. The mt19937 object performs the role of the random function, but with much better characteristics. The uniform_int_distribution object constrains the pseudorandom values to a particular range, replacing the simple but problematic modulo operator. Listing 13.10 (highquality.cpp) upgrades Listing 13.8 (badrand.cpp) with improved random number generation based on these classes.

```
Listing 13.10:highquality.cpp
```cpp
#include <iostream>
#include <iomanip>
#include <random>

using namespace std;

int main() {
    random_device rdev; // Used to establish a seed value
    // Create a Mersenne twister random number generator with a seed
    // value derived from rdev
    mt19937 mt(rdev());

    // Create a uniform distribution object. Given a random
    // number generator, dist will produce a value in the range
    // 0..9999.
    uniform_int_distribution<int> dist(0, 9999);

    // Total counts over all runs.
    // Make these double-precision floating-point numbers
    // so the average computation at the end will use floating-point
    // arithmetic.
    double totals = 0.0, total9995 = 0.0;

    // Accumulate the results of 10 trials, with each trial
    // generating 1,000,000,000 pseudorandom numbers
    const int NUMBER_OF_TRIALS = 10;

    for (int trial = 1; trial < NUMBER_OF_TRIALS; trial++) {
        // Initialize counts for this run of a billion trials
        int count5 = 0, count9995 = 0;
        // Generate billion pseudorandom numbers in the range
        // 0..9999 and count the number of times 5 and 9,995 appear
        for (int i = 0; i < 1000000000; i++) {
            // Generate a pseudorandom number in the range 0..9,999
            int r = dist(mt);
            if (r == 5)
                // Number 5 generated, so count it
                count5++;
            } else if (r == 9995)
                // Number 9,995 generated, so count it
                count9995++;
            }
        }
        // Display the number of times the program generated 5 and 9,995
        cout << "Trial #" << set(2) << trial << " 5: " << set(6) << count5
             << " 9995: " << set(6) << count9995 << endl;
        // Accumulate the counts to:
        totals += count5;
        total9995 += count9995;
    }
    cout << "------------------------------------------------" << endl;
    cout << "Averages for " << NUMBER_OF_TRIALS << " trials: 5: "
         << set(6) << totals / NUMBER_OF_TRIALS << " 9995: "
         << set(6) << total9995 / NUMBER_OF_TRIALS << endl;
}
```
