# Listing F.3: cleararray.cpp

```
#include <iostream>

using namespace std;

/*
* print(a, n)
* Prints the contents of an int array
* a is the array to print
* n is the size of the array
*/
void print(int a[], int n) {
    for (int i = 0; i < n; i++)
        cout << a[i] << " \;
}

/*
* clear(a, n)
* Makes all the elements of array a
* a is the array to zero out
* n is the size of the array
*/
void clear(int a[], int n) {
    for (int i = 0; i < n; i++)
        a[i] = 0;
}

int main() {
    int list[] = { 2, 4, 6, 8 };
    // Print the contents of the array
    print(list, 4);
    // Zero out the array
    clear(list, 4);
    // Reprint the contents of the array
    print(list, 4);
}
```

The clear function actually modifies the contents of main's list array. The function works on the array's actual elements, not copies of them.
