### Listing 18.6: genericpoint.h
```cpp
#ifndef GENERICPOINT_H
#define GENERICPOINT_H_

template <typename T>
class Point {
public:
    T x;
    T y;
    Point(T x, T y) : x(x), y(y) {}
};

#endif
```
```

If a client declares a Point object as
Point<int> pixel(10, 10);

the compiler will instantiate a Point<int> class that looks like

```
```cpp
class Point {
public:
    int x;
    int y;
    Point(int x, int y) : x(x), y(y) {}
};
```
```

If a client declares a Point object as
Point<float> pixel(10.0, 20.0);

the compiler will instantiate a Point<double> class that looks like

```
```cpp
class Point {
public:
    double x;
    double y;
    Point(double x, double y) : x(x), y(y) {}
};
```
```

Neither of these instantiations in any source code, a programmer will not see them. The compiler substitutes actual types (int or double) for the parameterized type (T).
```
