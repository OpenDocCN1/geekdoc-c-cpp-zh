+   * dir

When the command line interface starts locates you in a particular folder, or directory, in the file system managed by the operating system. Your location is known as the current working directory. The command dir prints a list of the files in your current working directory. On Unix-like machine the ls -l command performs similar. The command dir /w displays a wide listing of files with fewer details; the ls command is equivalent on Unix-like systems.

+   * mkdir name

Creates a new directory (folder) named name in the current directory. Subdirectories allow you to better organize your files.

+   * cd name

Changes your current directory to be specified by name. Some examples of its include

+   - cd Code
Changes the current working directory to be the subdirectory named Code. Here the name is relative to the current directory. It is an error to provide a name that does not correspond to a subdirectory of the current directory'
- cd
Changes the current working directory to its parent directory. Said another way, the current working directory is itself a subdirectory of some other directory. This command makes this other (parent) directory the current working directory. .. means "parent directory" or "parent folder."
- cd C:\Users\rick\Documents\Code
Changes the current working directory to the completely specified one. The name is known as a full-path name. The name is an absolute location; it is not relative to the current directory. Unix-like systems do not have a drive letter (C:), and the backslashes (\ would be forward slashes (/).
- cd .
Changes the current working directory to itself, which effectively does nothing! This command does not use work. The dot (.) in this context means "current working directory."

+   * del name

Deletes the file named name. Use this command carefully. Unix-like systems use the rm command in its place.

+   * rename name2

Renames the file to name2. The move command does the same thing, and Unix-like systems use the mv command to rename files.

In preparation for our programming, we can create a new directory for our code and make that new directory current working directory with the commands:

```
mkdir Code
cd Code
```
