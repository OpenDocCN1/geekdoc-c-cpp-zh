Listing 6.6 (powersof10.cpp) prints the powers of 1 to 1,000,000,000 (the next power of, 10,000,000,000, is outside the range of the int type).

Listing 6.6: powersof10.cpp

```
#include <iostream>
using namespace std;
int main() {
  int power = 1;
  while (power <= 1000000000) {
    cout << power << endl;
    power *= 10;
  }
}
```
