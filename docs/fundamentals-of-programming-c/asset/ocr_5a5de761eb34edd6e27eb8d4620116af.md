This, object-oriented version is simpler and more readable.
The design of the Stopwatch class allows to create multiple Stopwatch instances, and each instance keep track of its own time. In practicing optimizing programs, performance guarantees is usually unnecessary. Rarely do developers need to overlap code, so one object per project is enough. Multiple sections of code can be checked with the same Stopwatch; just start it, check the time, and reset it start again when any other section of code is to be timed.
