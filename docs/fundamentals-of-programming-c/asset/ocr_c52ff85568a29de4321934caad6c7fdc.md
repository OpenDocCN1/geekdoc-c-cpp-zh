We can easily write a non-recursive factorial function, as Listing 10.6 (nonrecursfact.cpp) shows.

# Listing 10.6: nonrecursfact.cpp

```
#include <iostream>

using namespace std;

/*
 * factorial(n)
 * Computes n!
 * Returns the factorial of n.
 */
int factorial(int n) {
    int product = 1;
    for (int i = n; i > 0; i--) {
        product *= i;
    }
    return product;
}

int main() {
    // Try out the factorial function
    cout << "0! = " << factorial(0) << endl;
    cout << "1! = " << factorial(1) << endl;
    cout << "6! = " << factorial(6) << endl;
    cout << "10! = " << factorial(10) << endl;
}
```

Which factorial function is better, the recursive or non-recursive version? Generally, if the same algorithm is being used by both recursive and non-recursive functions, the non-recursive version will be more efficient. A function call is a relatively expensive operation compared to a variable assignment or comparison. The body of the non-recursive factorial function invokes no functions, but the recursive version calls itself—during all but the last recursive invocation. The iterative version of factorial is much more efficient than the recursive version.

Even though the iterative version of the factorial is technically more efficient than the recursive version, on many systems you could not tell the difference. The factorial function "grows" fast, meaning it returns fairly large results for small arguments. For example, 32-bit integers, 13! is the largest integer value that can be computed. The execution difference between the two is negligible on most systems.
