What we really would like to print the value of a variable (call count), then increment the variable (count++), and repeat this process until the variable is large enough (count == 5 or perhaps count == 10000). This process of executing the same code over and over is known as iteration, or looping, and in C++ we can implement loops in several ways.

Listing 6.2: (iterativecountoftive.cpp) uses a while statement to count to five:

# Listing 6.2: iterativecountoftive.cpp

```
#include <iostream>

using namespace std;

int main() {
    int count = 1;           // Initialize counter
    while (count <= 5) {   // Display counter, then
        cout << count << endl;
        count++;
    }
}
```

Listing 6.2 (iterativecountoftive.cpp) uses a while statement to display that counting is counting up to five. Unlike the approach taken in Listing 6.1 (countoftive.cpp), it is trivial to modify Listing 6.2 (iterativecountoftive.cpp) to count up to 10,000—just change the literal 5 to 10000.

The line

```
while (count <= 5)
```

begins the while statement. The expression within the parentheses must be a Boolean expression. If the Boolean expression is true the program's execution reaches the while statement, the program executes the body of the while statement and then checks the condition again. The program repeatedly executes the statement within the body of the while as the Boolean expression remains true.

If the Boolean expression is true when the while statement is executed, the body of the while statement is executed, and the body is executed repeatedly as long as the Boolean expression remains true.

The statements

```
cout << count << endl;
count++;
```

constitute the body of the while statement. The curly braces are necessary since more than one statement makes up the body.
