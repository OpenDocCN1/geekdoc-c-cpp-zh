
## 5.3 The Simple if Statement

The Boolean expressions described in Section 5.2 at first may seem arcane and of little use in practical programs. In reality, Boolean expressions are essential for a program to be able to adapt its behavior at run time. Most useful and practical programs would be impossible without the availability of Boolean expressions.

The run-exceptions mentioned in Section 4.6 arise from logic errors. One way is that Listing 4.7 (division.cpp) can fail when the user enters a zero for the divisor. Fortunately, programmers can take steps to ensure that division by zero does not occur. Listing 5.2 (betterdivision.cpp) shows how it might be done.

### Listing 5.2: betterdivision.cpp

```cpp
#include <iostream>

using namespace std;

int main() {
    int dividend, divisor;

    // Get two integers from the user
    cout << "Please enter two integers to divide:";
    cin >> dividend >> divisor;
    // divide them and report the result
    if (divisor != 0)
        cout << dividend << " /" << divisor << " = "
             << dividend/divisor << endl;
}
```

The second cout statement may not always be executed. In the following

![](img/e326304bd50fbc4f7d5a64c1487eb635_84_0.png)

it is executed, but if the user enters a zero as the second number:

![](img/e326304bd50fbc4f7d5a64c1487eb635_84_1.png)

the program prints nothing after the user enters the values.

The last statement in Listing 5.2 (betterdivision.cpp) begins with the reserved word if. The statement allows code to be optionally executed. In this case, the printing statement is executed only if the variable divisor's value is not zero.

The Boolean expression

`divisor != 0`

determines if the simple statement that follows the right parenthesis is executed. If divisor is not zero, the message must be printed; otherwise, the program prints nothing.

Figure 5.1 shows how program execution flows through the *if* statement of Listing 5.2 (betterdivision.cpp).

![](img/e326304bd50fbc4f7d5a64c1487eb635_85_0.png)

The general form of a simple *if* statement is

```cpp
if ( condition )
    statement
```

- The reserved word *if* begins the *if* statement.
- The Boolean expression determines whether or not the body will be executed. The Boolean expression must be enclosed within parentheses as shown.
- The statement is the statement to be executed if the Boolean expression is true. The statement makes up the body of the *if* statement. Section 5.4 shows how the body can be composed of multiple statements.

## 5.3. THE SIMPLE IF STATEMENT

Good coding dictates the body should be indented to emphasize the optional execution and improve the program's readability. The indenting is not required by the compiler. Sometimes programmers will place a short body on the same line as the if; for example, the following if statement optionally assigns y:

```cpp
if (x < 10)
  y = x;
```

and could be written as

```cpp
if (x < 10)  y = x;
```

but not be written as

```cpp
if (x < 10)
  y = x;
```

because the lack of indentation hides the fact that the program optionally executes the assignment statement. The compiler will accept it, but it is misleading to human readers accustomed to the indentation convention. The compiler, of course, will accept the code written as

```cpp
if (x<10)y=x;
```

but the lack of spaces makes it difficult for humans to read.

> When the if statement is written the preferred way using two lines of source code, it is important not to put a semicolon at the end of the first line:
> `if (x < 10); // No! Don't do this!`
> `  y = x;`

> Here, the semicolon terminates the if statement, but the indentation implies that the second line is intended to be the body of the if statement. The compiler, however, interprets the badly formatted if as it were written as:
> ```cpp
> if (x < 10)
>   // This is what is really going on.
>   y = x;
> ```

This is legal in C++; it means the if statement has an empty body. In which case the assignment is not part of the body. The assignment statement is after the body and always will be executed regardless of the truth value of the Boolean expression.

## 5.4. COMPOUND STATEMENTS

When checking for equality, as
```cpp
if (x == 10)
    cout << "ten";
```

be sure to use the equality operator (==), not the assignment operator (=). Since an assignment statement has a value (see Section 4.3), C++ allows = within the conditional expression. It is, however, almost always makes sense when beginning programmers use = in this context. Visual++ at rating Level 4 checks for the use of assignment within a conditional expression; the default Level 3 does not.

Sometimes you need to execute more than one statement based on a particular condition. Listing 5.3 (alternateddivision.cpp) shows how you must use curly braces to group multiple statements together into one compound statement.

### Listing 5.3: alternateddivision.cpp

```cpp
#include <iostream>

using namespace std;

int main() {
    int dividend, divisor, quotient;

    // Get two integers from the user
    cout << "Please enter two integers to divide:";
    cin >> dividend >> divisor;
    // If possible, divide them and report the result
    if (divisor != 0) {
        quotient = dividend / divisor;
        cout << dividend << " divided by " << divisor << " is "
             << quotient << endl;
    }
}
```

The assignment statement and printing statement are both part of the body of the if statement. Given the true value of the Boolean expression divisor != 0 during a particular program run, either both statements will be executed or neither will be executed.

A compound statement consists of zero or more statements grouped within curly braces. We say the curly braces define a block of statements. As a matter of style many programmers use curly braces to delimit the body of an if statement if the body contains only one statement:

```cpp
if (x < 10) {
    y = x;
}
```

They do this because it is easy to introduce a logic error if additional statements are added later and the programmer forgets to add required curly braces.

An empty pair of curly braces represents an empty block. An empty block is a valid compound statement.

// Get two integers from the user

    cout << dividend << "/" << divisor << " = "
