# 9.6. CUSTOM FUNCTIONS VS. STANDARD FUNCTIONS

+   - Standard routines are typically tuned to be very efficient; it takes a great deal of effort to make custom
code efficient.

+   - Standard routines are well-documented; extra work is required to document custom code, and writing
good documentation is hard work.

Listing 19: squarootcomparison.cpp tests our custom square root function over a range of 1,000,000,000
floating-point values.

Listing 19: squarootcomparison.cpp

```
#include <iostream>
#include <cmath>

using namespace std;

// Compare two floating-point numbers equal when
// the difference between them is very small.
bool equals(double a, double b, double tolerance) {
    return a == b || fabs(a - b) < tolerance;
}

double square_root(double x) {
    // Compute a provisional square root
    double root = 1.0;
    do {
        // Loop until the provisional root
        // is close enough to the actual root
        root = (root + x /root) / 2.0;
    } while (!equals(root+root, x, 0.0001));
    return root;
}

int main() {
    for (double d = 0.0; d < 100000.0; d += 0.001) {
        if (equals(square(d), sqrt(d), 0.001)) {
            cout << d << " Expected: " << sqrt(d) << " , but computed "
                 << square_root(d) << endl;
        }
    }
}
```

Listing 19.9 (squarootcomparison.cpp) uses our equals function from Listing 9.16 (floatequals.cpp).
The third parameter specifies a tolerance; if the difference between the two parameters is less than
the tolerance, the first two parameters are considered equal. Our custom square_root
function uses the equals function. The main function uses the equals function as well. Observe,
hover, that the tolerance used within the square root is smaller than the tolerance main
uses to check the result. The main function, therefore, uses a less strict notion of equality.
