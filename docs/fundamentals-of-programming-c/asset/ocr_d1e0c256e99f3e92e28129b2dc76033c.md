# 19.4. CATCHING MULTIPLE EXCEPTIONS

```
throw FileNotFoundException(filename);

int main() {
  try {
    vector<int> numbers = load_vector("values.data");
    for (int value : numbers) {
      cout << value << ' ';
    }
    cout << endl;
  } catch (exception& e) {
    cout << e.what() << endl;
  }
}
```

The text file containing the integers to load into the vector has a specific format. The first integer read from the file is not a data element; instead, it specifies the number of integers that follow. This gives us two options for creating and populating the vector:

+   1. Create the vector with sufficient size up front and then use a loop to place individual elements in their proper places.
2. Create an empty vector and then use a loop to push_back the individual elements.

Option 1 is more efficient than Option 2. Successive calls to vector<int>:push_back must reallocate and copy elements every time. Option 2 is safer than Option 1 because the number of elements specified at the start may not agree with the actual number of data elements in the file. If the specified number is too small, the function will attempt to overrun the bounds of the vector.

Listing 19.7 (filreadmultitext1.cpp) opts for efficiency at the expense of safety. This means that on a correctly created file. If the file does not exist, load_vector will throw our FileNotFoundException custom exception:

```
File "values.data" not found
```

If the file exists and contains

```
3
10
20
30
40
50
```

the load_vector function will throw the standard out_of_range exception.

Listing 19.8 (filreadmultitext2.cpp) uses two catch blocks to print different messages depending on the exact type of exception thrown by a load_vector.
