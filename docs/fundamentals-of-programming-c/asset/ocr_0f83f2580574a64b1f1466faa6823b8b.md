Listing 6.20 (startree.cpp) uses sequential while loops nested within a while loop. The outer while loop is responsible for drawing one row of the tree each time its body is executed:

+   * The program will execute the outer loop's body as the user enters a value greater than zero; if the user enters zero or less, the program terminates and does nothing. This is the expected behavior.

+   * The last statement in the body of the outer while:
rowrow++;

ensures that the row increases by each time through the loop; therefore, it eventually will equal height (since it initially to be less than height to enter the loop), and the loop will terminate. There is no possibility of an infinite loop.

+   * The body of the outer loop consists of more than one statement; therefore, the body must be enclosed within curly braces. When a group of statements is enclosed within curly braces a block is formed. A variable's scope (the section of the source code in which the variable is declared and can be used) is from its point of declaration to the end of the block, in which it is declared. For example the variables height and row are declared in the block that is main's body; thus, the body of the outer while statement is main; therefore, count is declared in the outer while statement. An attempt to use count outside of the outer while statement would be an error.
