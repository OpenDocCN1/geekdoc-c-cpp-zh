# 18.3 Iterators

11.2 and the extended information in Appendix F demonstrate how we can use a pointer to access the elements within an array. A vector is an object that manages a primitive array, and the developers of the class designed vectors to look and feel as much as possible as arrays. They adopted the square bracket {} operator to access elements. They also devised for programmers to use pointer-like objects to access the elements within a vector. These pointer-like objects are called *iterators*.

An iterator is an object that allows to traverse and access elements of a data structure in implementation independent way. C++ provides two global functions, **begin** and **end**, that produce iterators to move forward and back. Functions in the standard library that accept iterators as arguments rather than vectors work equally well with both vectors and arrays. Since they accept arguments, these standard functions are able to work with other, more sophisticated data structures. We will examine some of these standard functions later in this chapter.

In order to behave like a pointer, an iterator object provides the following methods:

+   * 	exttt{operator*}: to access the element at the iterator's current position. The syntax is exactly like pointer dereferencing (Section 10.6).

+   * 	exttt{operator++}: to move to the next element within the data structure. The syntax is exactly like pointer increment (See Section 11.2).

+   * 	exttt{operator==}: to determine whether two iterator objects currently refer to different elements within the data structure.

Listing 18.11 (simpleiterator.cpp) shows how to use these methods to manipulate an iterator.

Listing 18.11: simpleiterator.cpp
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Make a simple integer vector
    vector<int> vec = {10, 20, 30, 40, 50};
    // Direct an iterator to the vector's first element
    vector<int>::iterator iter = begin(vec);
    // Print the element referenced by the iterator
    cout << *iter << endl;
}
```
