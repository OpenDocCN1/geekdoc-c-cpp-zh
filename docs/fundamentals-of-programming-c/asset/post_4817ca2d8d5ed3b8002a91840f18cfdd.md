Consider the following program fragment in the C++ programming language:

```cpp
subtotal = 25;
tax = 3;
total = subtotal + tax;
```

These lines do not make up a C++ program; they are merely a piece of a program. The statements in this program fragment look similar to expressions in algebra. We see no sequence of binary digits. Here subtotal, tax and total variables are used to hold information. Mathematicians have used variables for hundreds of years before the first digital computer was built. In programming, a variable represents a value stored in the memory. Familiar operators (= and +) are instead of some cryptic binary digit sequence that instructs the processor to perform the operation. Since this program is expressed in the C++ language, not machine language, it cannot be executed directly on any processor. A C++ compiler is used to translate the C++ code into machine language

The higher-level code is source code. The compiled machine language code is the target code. The compiler translates the source code into the target machine language.

The beauty of higher-level languages is this: the C++ source code can be compiled to different target platforms. The target platform may require changes in the source code because of architectural differences in the platforms, but the work to move from one platform to another is far less than would be necessary if the program for the new platform had to be rewritten by hand in the new language. Just importantly, when writing the program the human programmer is free to think about writing the solution to the problem in C++, not in a specific machine language.

Programmers have a variety of tools available to enhance the software development. Some common tools include:

- Editors. An editor allows the user to enter the program source code and save it to files. Most programming editors increase programmer productivity by using colors to highlight features. The syntax of a language refers to how we pieces of the language are arranged to make well-formed sentences. To illustrate, the sentence

The tall boy runs quickly to the door.

uses proper syntax. By comparison, the sentence

Boy the tall runs door to the is incorrect. It uses the same words as the original sentence, but their arrangement does not follow the rules of English.

Similarly, programmers must follow strict syntax rules to create well-formed computer programs. Only well-formed programs are acceptable and can be compiled and executed. Syntax aware editors can use colors or special annotations to alert programmers of syntax errors before the program is compiled.

- Compilers. A compiler translates the source code to target code. The target code may be the machine language for a particular platform or embedded device. The target code could be another source language; for example, the earliest C++ compiler translated C++ into C, another higher-level language. The resulting C code was then processed by a C compiler to produce an executable program. C++ compilers translate directly into machine language.

The complete set of built tools for C++ includes a preprocessor, compiler, and linker:

- Preprocessor adds or modifies the contents of the source file before the compiler processes the code. We use the services of the preprocessor mainly to #include information about library routines our programs use.

- Compiler translates C++ source code to machine code.

- Linker combines the compiler-generated machine code with precompiled library code or compiled from other sources to make a complete executable program. Most compiled C++ code is incapable of running by itself and needs some additional code to make a complete executable program. The missing code has been preprocessed and stored in a repository of code called a library. A program called a linker combines the programmer's compiled code and the library code to make a complete program.

## 1.3. LEARNING PROGRAMMING WITH C++

We generally do not think about the preprocessor, compiler, and linker as three separate programs (although we do); the tools we make appear as only one process is taking place: translating our source code to create an executable program.

- Debuggers. A *debugger* allows a programmer to more easily trace a program's execution to locate and correct errors in the program's implementation. With a debugger, a developer can simultaneously run a program and see which line in the source code is responsible for the program's current actions. The debugger can watch the values of variables and other program elements to see if their values change as expected. Debuggers are valuable for locating errors (also called bugs) and repairing programs that contain errors. (See Section 4.6 for more information about programming errors).

- Profilers. A *profiler* collects statistics about a program's execution to tune appropriate parts of the program to improve its overall performance. A profiler indicates how many times a program is executed during a particular run, and how long that portion takes to execute. Profilers also can be used for testing purposes to ensure all the code in a program is actually being used during testing. This is known as *coverage*. It is common for software to fail after its release because users exercise some of the program that was not executed during testing. The main purpose of profiling is to find the parts of a program that can be improved to make the program run faster.

Despite the plethora of tools (and tool vendors), the programming process is for all but true programming is not. Good tools are valuable and certainly can increase the productivity of developers, but they cannot write software. There are no substitutes for logical thinking, creativity, common sense, and of, programming experience.

1.3 Learning Programming with C++ 

Bjarne Stroustrup of AT&T Bell Labs created C++ in the mid 1980s. C++ is an extension of the programming language C, a product of AT&T Bell Labs from the early 1970s. C was developed to use the Unix operating system, and is widely used for systems-level software and embedded systems development. C initially introduced object-oriented programming features (see Chapter 13 and Chapter 14) that added generic programming capabilities. C++'s relationship to C allows C programs to utilize a large collection of code developed in C.

C++ is widely used in industrial software development. It is an industrial strength programming language used for developing complex systems in business, science, and engineering. Examples of software written in C++ include Windows 8, Microsoft Office, Mac OS X, and Adobe Creative.

In order to meet the needs of commercial software development and accomplish all that, C++ itself is complex. While experienced programmers can accomplish great things with C++, beginners sometimes have a difficult time with it. Professional developers enjoy the flexible design options that C++ permits, but beginners need more structure and fewer options so they can master simpler concepts before moving on more complex ones.
