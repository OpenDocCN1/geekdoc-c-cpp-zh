# F.8. DYNAMIC ARRAYS

Listing F10: largearrayaverage.cpp

```
#include <iostream>

using namespace std;

// Maximum number of expected values is 1,000,000
const int MAX_NUMBER_OF_ENTRIES = 1000000;
double numbers[MAX_NUMBER_OF_ENTRIES];

int main() {
    double sum = 0.0;
    int size; // Actual number of entries

    // Get effective size of the array
    cout << "Please enter number of values to process: ";
    cin >> size;

    if (size > 0) { // Nothing to do with no entries
        cout << "Please enter " << size << " numbers: ";
        // Allow the user to enter in the values.
        for (int i = 0; i < size; i++) {
            cin >> numbers[i];
            sum += numbers[i];
        }

        cout << "The average of: ";
        for (int i = 0; i < size; i++) {
            cout << numbers[i] << ",";
        }
        // No comma following last element
        cout << numbers[size - 1] << " is " << sum / size << endl;
    }

    return 0;
}
```

Listing F10(largearrayaverage.cpp) creates an array that can handle any size needed by the user. The variable size keeps track of the part of the array actually used during a execution may be much smaller.
Notice that the array numbers is a global variable and is not local to main. This is because systems limit the amount of storage available to local functions. Local variables are stored in an area of memory called the stack. Local variables exist in memory only when the function using them is invoked; the stack grows and shrinks as functions execute and return. Global variables, on the other hand, are stored in the computer's memory for the life of the program's execution. Global variables are stored in what is known as static memory. There is a limit to the amount of storage available for global variables (the amount of RAM or virtual memory on disk, if nothing else), but the global limit is much higher than the local limit. One million double-precision numbers consume 8,000,000 bytes (8 megabytes) in C++ and on many other systems. The default stack size for local variables under C is only one megabyte, although the stack size can be increased by adjusting the compiler and linker options.
While the approach taken in F10(largearrayaverage.cpp) works, it wastes memory resources. In modern computing, a user may have multiple programs open at the same time.
