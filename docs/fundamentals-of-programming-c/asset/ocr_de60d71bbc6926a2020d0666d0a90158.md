# 6.1. THE WHILE STATEMENT

```
/*
#include <iostream>
using namespace std;

int main() {
    int input = 0,        // Ensure the loop is entered
    sum = 0;               // Initialize sum

    // Request input from the user
    cout << "Enter numbers to sum, negative number ends list:";

    while (input >= 0) { // A negative number exits the loop
        cin >> input;       // Get the value
        if (input >= 0)    // Only add if it is non-negative
            sum += input;
        }
        cout << "Sum = " << sum << endl; // Display the sum
    }
}
```

The initialization of input to zero coupled with the condition input >= 0 of the while loop guarantees that program will execute the body of the while loop at least once. If the if statement then a negative entry will not be added to sum. (Could the results results?) When the user enters a negative integer the program will not update sum, and the condition of while will no longer be true. The program's execution then loops and executes the statement at the end.

Listing 6.4 (addnegative.cpp) shows that a while loop can be used for simple counting. The program does not keep track of the number of values entered. The program simply accumulates the values in a named variable sum.

It is a little awkward in Listing 6.4 (addnegative.cpp) that the same condition appears twice, in the while and in the if. Furthermore, if the user wishes to enter negative values with non-negative values? The code can be simplified with a C++ idiom that uses cin and the extraction operator as a condition within while statement.

If x is an integer,
cin >> x

evaluate false if the user does not enter a valid integer. Armed with this knowledge we can simplify and enhance Listing 6.4 (addnegative.cpp) as shown in Listing 6.5 (addnumbers.cpp).

# Listing 6.5: addnumbers.cpp

```
#include <iostream>
using namespace std;

int main() {
    int input, sum = 0;
    cout << "Enter numbers to sum, type 'q' to end the list:";
    while (cin >> input) {
        sum += input;
    }
    cout << "Sum = " << sum << endl;
}
```
