Observe that the client code does not use pointers at all. All the pointer manipulations are hidden within the IntClass. Pointer programming can be tricky, and it is easy to debug, find bugs; encapsulation once gains results and more robust application development.

As shown in the IntList methods, a pointer variable by be used as a condition within a conditional statement or loop. A null pointer is interpreted as false, and any non-null pointer is true. This means if p is a pointer, the statement

```
if (p)
    /* Do something */
```

is a shorthand for

```
if (p != nullptr)
    /* Do something */
```

and the statement

```
if (!p)
    /* Do something */
```

is a shorthand for

```
if (p == nullptr)
    /* Do something */
```

Most C and C++ programmers use the shorter syntax.
In order to understand how the recursive methods work, think about the structure of a Node object with this interpretation: A Node object holds a data item and a pointer to the rest of the list that follows. A pointer to a Node is either null or non-null. A null pointer represents the empty list. A non-null pointer represents a non-empty list consisting of two parts: the first element in the list and the rest of the list. If the next field of a Node object is null, the rest of the list is empty.
