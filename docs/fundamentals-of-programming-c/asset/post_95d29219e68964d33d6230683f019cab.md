Listing 12.3: linearsearch.cpp

```cpp
#include <iostream>
#include <vector>
#include <cstdio>
#include <iomanip>

using namespace std;

/**
 * locate(a, seek)
 * Returns the index of element seek in vector a
 * Returns -1 if seek is not an element of a
 * a is the vector to search.
 * seek is the element to find.
 */
int locate(const vector<int>& a, int seek) {
    int n = a.size();
    for (int i = 0; i < n; i++) {
        if (a[i] == seek)
            return i; // Return position immediately
    }
    return -1; // Element not found
}

/**
 * format(i)
 * Prints integer right justified in a 4-space
 * field. Prints """" if i > 9999.
 */
void format(int i) {
    if (i > 9999)
        cout << """" << endl; // Too big!
    else
        cout << setw(4) << i;
}

/**
 * print(v)
 * Prints the contents of an int vector.
 * v is the vector to print.
 */
void print(const vector<int>& v) {
    for (int i : v) {
        format(i);
    }
}

/**
 * display(a, value)
 * Draws an ASCII art arrow showing
 * the given value is within the vector.
 * a is the vector.
 * value is the element to locate.
 */
void display(const vector<int>& a, int value) {
    int position = locate(a, value);
    if (position >= 0) {
        print(a);    // Print contents of the vector
        cout << endl;
        position = 4+position + 7;    // Compute spacing for arrow
        cout << setw(position);
        cout << "   " << endl;
        cout << setw(position);
        cout << " | " << endl;
        cout << setw(position);
        cout << " +-" << value << endl;
    } else {
        cout << value << " not in ";
        print(a);
        cout << endl;
    }
    cout << "======" << endl;
}

int main() {
    vector<int> list = { 100, 44, 2, 80, 5, 13, 11, 2, 110 };
    display(list, 13);
    display(list, 2);
    display(list, 7);
    display(list, 100);
    display(list, 110);
}
```

The key function in Listing 12.3 (linearsearch.cpp) is **locate**: all the other functions lead to a more interesting story of **locate**'s results. If **locate** finds a match, it immediately returns the position of the matching element; otherwise, if **locate** finds all elements of the vector and finds no match, it returns -1. -1 is a good indication of failure, since -1 is not a valid index in a C++ vector.

The other functions are:

- **format** prints an integer right justified within a four-field space. Extra spaces pad the beginning of the number if necessary.
- **print** prints the elements in any vector using the **format** function to properly format the values. This alignment simplifies the **display** function.
- **display** uses **locate**, **print**, and **setw** to provide a graphical display of the operation of the **locate** function.

The kind of search performed by **locate** is known as *linear search*, as the process takes a straight line path from the beginning to the end of the vector, and it considers each element in order. 12.1 illustrates linear search.

## 12.3.2 Binary Search

Linear search is acceptable for relatively small vectors, but the process of examining each element in a large vector is time consuming. An alternative to linear search is *binary search*. In order to perform binary search a vector's elements must be ordered. Binary search exploits this sorted structure of the vector using a simple binary strategy that quickly zeros in on the element to:

Figure 12.1: Linear search. The grayed out elements are not considered during the search. This approach is analogous to looking for a telephone number in a phone book in this manner:

1. Open the book at its center. If the name is on one of two visible pages, look at the phone number.
2. If not, and the person's last name is alphabetically less than the name on the visible pages, apply the search to the left half of the open book; otherwise, apply the search to the right half of the open book.
3. Continue the search if the person's name should be on one of the visible pages but is not present.

Listing 12.4 (binarysearch.cpp) contains a C++ function that implements the binary search.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

/**
 * binary_search(a, seek)
 * Returns the index of element seek in vector
 * returns -1 if seek is not an element of a
 * a is the element to search; a's contents must be
 * sorted in ascending order.
 * seek is the element to find.
 */
int binary_search(const vector<int>& a, int seek) {
    int first = 0,               // Initially the first position
    int last = a.size() - 1,     // Initially the last position
    int mid;                    // middle of the vector
    while (first <= last) {
        mid = first + (last - first) / 2;
        if (a[mid] == seek)
            return mid;               // Found it
        else if (a[mid] > seek)
            last = mid - 1;           // continue with 1st half
        else
            first = mid + 1;         // continue with 2nd half
    }
    return -1;                   // Not there
}

/**
 * format(i)
 * Prints integer right justified in a 4-space
 * field. Prints """" if i > 9999.
 */
void format(int i) {
    if (i > 9999)
        cout << """" << endl; // Too big!
    else
        cout << setw(4) << i;
}

/**
 * print(v)
 * Prints the contents of an int vector.
 * v is the vector to print.
 */
void print(const vector<int>& v) {
    for (int i : v) {
        format(i);
    }
}

/**
 * display(a, value)
 * Draws an ASCII arrow showing where
 * the given value is within the vector.
 * a is the element to locate.
 * value is the element.
 */
void display(const vector<int>& a, int value) {
    int position = binary_search(a, value);
    if (position >= 0) {
        print(a);                   // Print contents of the vector
        cout << endl;
        position = 4*position + 7;     // Compute spacing for arrow
        cout << setw(position);
        cout << "";
        cout << setw(position) << endl;
        cout << " | " << endl;
        cout << setw(position);
        cout << " +- " << value << endl;
    } else {
        cout << value << " not in";
        print(a);
        cout << endl;
    }
    cout << "======" << endl;
}

int main() {
    // Check binary search on even- and odd-length vectors and
    // an empty vector
    vector<int> even_list={1, 2, 3, 4, 5, 6, 7, 8},
                       odd_list={1, 2, 3, 4, 5, 6, 7, 8, 9},
                       empty_list;

    for (int i = -1; i <= 10; i++)
        display(even_list, i);
    for (int i = -1; i <= 10; i++)
        display(odd_list, i);
    for (int i = -1; i <= 10; i++)
        display(empty_list, i);
}
```

In the binary_search function:

- The initializations of first and last:
```cpp
int first = 0,               // Initially the first position
last = a.size() - 1,     // Initially the last position
```
ensure that first is less than or equal to last for a nonempty vector. If the vector is empty, first is zero, and last is n-1 which equals -1. In the case of an empty vector binary_search will skip the loop and immediately return -1. This is correct behavior because an empty vector cannot contain any item.

- The variable mid represents the midpoint between first and last, and it is computed in the statement:
```cpp
mid = first + (last - first) / 2;
```
This arithmetic might look a bit complex. The more straightforward way to compute the average of two values would be
```cpp
mid = (first + last) / 2;      // Alternate calculation
```
The problem with computing the midpoint is fails to produce the correct results more times than the version found in Listing 12 (binary_search.cpp). The problem arises if the vector is large, and first and last both have relatively large values. The expression first+last can overflow the range of integers producing a meaningless result.
