It is customary to justify a column of numbers, but Listing 6.6 (powersof10.cpp) prints the powers of ten with their most-significant digit aligned. We can right align the numbers using a stream object called a stream manipulator. The specific stream manipulator we need is named setw. setw means "set width." It can be used as

```
cout << setw(3) << x << endl;
```

This statement prints the value of x right justified within a three character horizontal space on the screen. Listing 6.7 (powersof10justified.cpp) shows the effects of setw.

Listing 6.7: powersof10justified.cpp
#include <iostream>
#include <iomanip>

using namespace std;

// Print the powers of 10 from 1 to 1,000,000,000
int main() {
    int power = 1;
    while (power <= 1000000000) {
        // right justify each number in a field 10 wide
        cout << setw(10) << power << endl;
        power *= 10;
    }
}
