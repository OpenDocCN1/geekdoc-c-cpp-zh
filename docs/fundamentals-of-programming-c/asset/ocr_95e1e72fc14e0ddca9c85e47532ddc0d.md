# 1.1 Software

A computer program is an example of computer software. Software makes a computer truly universal transforming it into the tool for the task at hand disk. One can refer to a program as a piece of software if it were a tangible object, but software is quite intangible. It is stored on a medium. A hard drive, a CD, a DVD, and a USB pen drive are examples of media upon which software can reside. The CD is not the software; software is a pattern on the CD. In order to be used, software must be stored in the computer's memory. Typically computer programs are loaded into memory from a medium like the computer's disk. An electromagnetic pattern representing the program is stored on the computer's memory before the program can be executed. The program has been installed on the hard disk from a CD or from the Internet. In any case, the essence that is transferred from medium to medium is a pattern of electronic symbols that directs the work of the computer system.

These patterns of electronic symbols are best represented as a sequence of zeros and ones, digits of binary (base 2) number. A binary program sequence is

```
10001010110000100000101001110
```

To understand computing hardware, a zero here and three ones might mean that electronic signals should be sent to the graphics device so that it makes a certain part of the display screen real. Unfortunately, only a minuscule people in the world would be able to produce, by hand, the complete sequence of zeros and ones that represent the Microsoft Word for an Intel-based computer running the Windows 8 operating system. Further, almost none of those could produce the binary sequence would claim to enjoy the task.

The Word program for Mac OS X computers using a PowerPC processor works similarly to the Windows version and produced by the same company, but the program is expressed in a completely different sequence of zeros and ones! The Intel Core i7 processor in the Windows machine accepts a completely different binary language than the PowerPC processor in the Mac. We say the processors have their own machine language.

# 1.2 Development Tools

If few can (or want) to speak the machine language of the computers' processors and software is expressed in this language, how has so much software been developed over the years?

Software can be represented by written words and symbols that are easier for humans to manage than binary sequences. Every tool can automatically convert a higher-level description of what is to be in the required-level code. Higher-level programming languages like C++ allow programmers to express solutions to programming problems in terms that are closer to a natural language like English. Some of the more popular of the higher-level programming languages that have been devised over the past 60 years include FORTRAN, COBOL, Haskell, C, Python, Java, and C#. Most programmers today, especially those concerned with high-level applications, do not worry about the details of underlying platform and its machine language.
