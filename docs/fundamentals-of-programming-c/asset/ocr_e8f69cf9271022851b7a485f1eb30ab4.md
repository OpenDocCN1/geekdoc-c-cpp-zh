What if we wanted the evaluate function to perform arithmetic operations at different times during a program's execution? Unfortunately, evaluate as it is currently written cannot adapt to a different arithmetic operation. The good news is that we can rewrite evaluate so that it can flexibly adapt to a caller's changing needs.

C++ allows programmers to pass functions as parameters to other functions. A function that accepts one or more functions as parameters or returns a function is known as a higher-order function. As we will see, higher-order functions enable us new programming possibilities to customize the behavior of a function by plugging into it different functions to achieve different effects.

C++ achieves higher-order functions via pointers. During a program's execution, the compiled machine code for a function must reside the computer's memory for the program to be able to invoke it. Every function has a memory address as each variable has its own memory address. A pointer to a function holds the starting address for the compiled code of a particular function.

Listing 10.19 (arithmeticeval.cpp) provides an example of a higher-order function in action.

```
#include <iostream>

using namespace std;

int add(int x, int y) {
    return x + y;
}

int multiply(int x, int y) {
    return x * y;
}

int evaluate (*f)(int, int), int x, int y) {
    return f(x, y);
}

int main() {
    cout << add(2, 3) << endl;
    cout << multiply(2, 3) << endl;
    cout << evaluate(&add, 2, 3) << endl;
    cout << evaluate(&multiply, 2, 3) << endl;
}
```
