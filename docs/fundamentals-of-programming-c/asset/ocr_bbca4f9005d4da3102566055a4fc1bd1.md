The output of Listing 6.9 (timetable-1st-try.cpp) is somewhat overwhelming:

![](bbox=[0.138, 0.587, 0.782, 0.807])

Listing 6.9 (timetable-1st-try.cpp) does print each row in its proper place—it just does not supply the needed detail for each row. Our next step is to refine the way the program prints each row. Each row should contain size numbers. Each number within each row represents the product of the current row and current column; for example, in row 2, column 5 should be 2 × 5 = 10. In each row, therefore, we must vary the column number from 1 to size. Listing 6.10 (timetable-2nd-try.cpp) contains the needed refinement.
