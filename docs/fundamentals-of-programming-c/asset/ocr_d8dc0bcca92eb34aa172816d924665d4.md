# 16. CONVENIENT HIGH-QUALITY PSEUDORAND NUMBERS

a UniformRandomGenerator object uses the random_device only for creating its mt19937 field and does not need it later. UniformRandomGenerator objects do not contain a random_device field.

To create a UniformRandomGenerator object produces pseudorandom integers in the range -100... 100, a client needs only write

UniformRandomGenerator gen (-100, 100);

The UniformRandomGenerator class also provides an operator() method. This allows a client to "call" an object as if it were a function. Given a UniformRandomGenerator object named gen, we can assign a pseudorandom number to an integer x with the statement

```
int x = gen();
```

This statement may appear to be calling a global function named gen; in fact, it is calling the operator() method of the UniformRandomGenerator class on behalf of gen. The expression gen() is syntactic sugar for gen.operator()(), but it is simply invoking the UniformRandomGenerator::operator() method on behalf of gen passing no arguments in the empty part of parentheses.

Listing 16.13 (testuniformorandom.cpp) is a simple rename of Listing 16.10 (highqualityrandom). In Listing 16.13(testuniformorandom.cpp) we see that our UniformRandomGenerator class can generate high-quality pseudorandom numbers with a single object that is simple to use.

# Listing 16.13: testuniformorandom.cpp

```
#include <iostream>
#include "uniformorandom.h"

using namespace std;

int main() {
    // Pseudorandom number generator with range 0...9,999
    UniformRandomGenerator rand(0, 9999);

    // Total counts over all the runs.
    // Make these double-precision floating-point numbers
    // so the average computation at the end will use floating-point
    // arithmetic.
    double total = 0.0, total19995 = 0.0;

    // Accumulate the results of 10 trials, with each trial
    // generating 1,000,000,000 pseudorandom numbers = 10;
    const int NUMBER_OF_TRIALS = 10;

    for (int trial = 1; trial < NUMBER_OF_TRIALS; trial++) {
        // Initialize counts for this run of a billion trials
        int count = 0, count9995 = 0;
        for (int i = 0; i < 1000000000; i++) {
            // Generate a billion pseudorandom numbers in the range
            // 0...9,999 and count the number of 5 and 9,995 appear
            int r = rand();
            if (r == 5) count++; // Number 5 generated, so count it
            if (r == 9995) count9995++;
        }
```
