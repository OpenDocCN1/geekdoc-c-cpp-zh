# Appendix A

# Using Visual Studio 2013 to Develop C++ Programs

This appendix describes the task of C++ software development under Visual Studio:

+   - To begin creating a C++ program, you must first launch Visual Studio 2013 from the Windows 8 start screen or other relevant shortcut. Figure A.1 shows the appropriate application tile to activate.

![](bbox=[0.271, 0.497, 0.733, 0.613])

Figure A.1: Launching Visual Studio from the Windows 8 start screen and the ensuing splash screen that Visual Studio displays it is launching.

soon you should see a splash screen to the one shown on the right of Figure A.1.
If you have never used the Visual Studio application, you must wait a few moments while it configures the development environment for you. At this point you will indicate that Visual C++ is your preferred development language (not necessary if you are using the Visual C++ Express Edition). You may also select a color scheme. The schemes shown reflect the blue color scheme.
Figure.2 shows how Visual Studio looks when it is fully loaded and ready to use.

+   - After Visual Studio has started, you begin the process of developing a C++ program by creating a new project. Figure A.3 shows you can create a new project by following the menu sequence: File→New→Project
- In the dialog that follows, shown on the right of Figure A.3, you should choose the project type to be C++ in the left pane, and use the Win32 Console Application option in the center pane. In the name field next to the bottom of the dialog, enter a name for the project; we will use the name *simple*. You may change the location to a different folder if you like, or even a different drive (such as USB drive). In this example, we chose not to change the default location by Visual Studio.
