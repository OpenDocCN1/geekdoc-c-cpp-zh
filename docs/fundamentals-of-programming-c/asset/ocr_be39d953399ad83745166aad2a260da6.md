+   * cin >> value1 >> value2;
This statement causes the program's execution to stop until the user types two numbers on the keybord and presses enter. The first number entered will be assigned to value1, and the second number entered will be assigned to value2. Once the user presses the enter key, the value is assigned to the variable. The user may choose to type one number, press enter, type, the second number, and press enter again. The user may enter both numbers separated by one of spaces and then enter only once. The program will not proceed until the user enters two numbers.

The cin input stream can assign values to multiple variables in one statement,
as as shown here:

```
int num1, num2, num3;
cin >> num1 >> num2 >> num3;
```

A common beginner's mistake is to use commas to separate the variables, as in

```
int num1, num2, num3;
cin >> num1, num2, num3;
```

The compiler will not generate an error message, because it is legal C++ code.
The statement, however, will not assign three variables from user input as desired.
The comma in C++ has different meanings in different contexts, and here
it is treated like a statement separator; thus, the variables num2 and num3 are
not involved with the cin input stream. We will have no need to use the
comma operator in this, but you should be aware of this potential pitfall.

cin is a fact that can be used to read input from the user. The >> operator—used here in
the context of the cin object—is known as the extraction operator. Notice that it is "backwards"
the << operator used with the cout operator. The cin object represents the input stream—information\flowing into the program from user input from the keyboard. The >> operator extracts the data from
the cin stream and assigns the pieces of the data, in order, to the various variables on it.

+   * sum = value1 + value2;
This an assignment statement because it contains the assignment operator (=). The variable sum\appears to the left of the assignment operator, sum will receive a value when this statement execute
to the right. The right of assignment operator is an arithmetic expression involving two variables and
t addition operator. The expression is evaluated by adding together the values of the two variables.
Once the expression's value has been determined, that value can be assigned to the sum variable.

All expressions have a value. The process of determining the expression's value is called evaluation.
Evaluating simple expressions is easy. The literal value 54 evaluates to 54. The value of a variable named
x is stored in the memory reserved for x. The value of a more complex expression is
by evaluating the smaller expressions that make it and combining them with operators to form
potentially new values.
