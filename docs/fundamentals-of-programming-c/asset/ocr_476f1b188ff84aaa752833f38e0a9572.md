> It is legal to assign a derived class instance to a variable of a base class type. This is because a derived class instance is a specific kind of base class instance. In contrast, it is not legal to assign a base class instance to a variable of a derived type. This is because the a relationship is only one direction, from a derived class to its base class.

The **FancyText**, and **FixedText** classes form a small class hierarchy. The relationships in this class hierarchy can be represented in a graphical form using the Unified Modeling Language (UML). Figure 17.3 shows the UML diagram for our specific class hierarchy. A rectangle represents a class. **Text**, the base class, appears at the top of Figure 17.3. The derived classes appear below **Text**. The inheritance arrow points from the derived classes to the base class. The arrow represents a relationship which flows upward. This layout and level of detail provided by the UML diagram more succinctly communicates the relationships amongst the classes than does the C++ source code.
