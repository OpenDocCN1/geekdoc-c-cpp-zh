When a client calls a virtual method via a pointer to an object, the runtime environment executes the correct method by following the vtable pointer stored in the object itself. Observe that the FixedText class does not override the inherited method, its vtable remains the same code as of Text's vtable.

One exists for each class, but all instances of that class store a pointer to that shared vtable. The compiler assigns an index to each virtual method in a class. For example, the Text class contains two virtual methods, so the index of get might be 0, and the index of append might be 1.

Figure 17.4 illustrates a typical scenario with vtables. In this case the compiler translates the expression p1->get() to the machine language p1->vtable[0(), which invokes the correct method for the instance pointed to by p1. Similarly for the append method, p1->append("suffix") internally becomes p1->vtable[1]("suffix"). If p1 points to a Text instance, p1->vtable points to the vtable array of the Text class.
