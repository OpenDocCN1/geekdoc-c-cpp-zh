# 3.1. INTEGER VALUES

Notice that unlike the programs we saw earlier, Listing 3.1 (number4.cpp) does not use quotation marks
(""). Compare Listing 3.1 (number4.cpp) to Listing 3.2 (number4-alt.cpp).

```
Listing 3.2: number4-alt.cpp
```cpp
#include <iostream>
nusing namespace std;

int main() {
    cout << "4" << endl;
}
```
```

Both programs behave identically, but Listing 3.1 (number4.cpp) prints the value of the number four, while
Listing 3.2 (number4-alt.cpp) prints a message containing the digit. The distinction here is unim-important, but we will see in Section 3.2 that the presence or absence of the quotes can make a big difference
in the output.

In C++ source, integers may not contain commas. This means we must write the number two-thousand, four hundred sixty-eight as 2468, not 2,468. In mathematics, integers are unbounded; another way, the set of mathematical integers is infinite. In C++, the range of integers is limited because all
computers have a finite amount of memory. The exact range of integers supported depends on the system\and particular compiler. C++ on most 32-bit systems can represent integers in the
range -2,147,483,648 to +2,147,483,647.

What happens if you exceed the range of C++ integers? Try Listing 3.3 (exceed.cpp) on your system.

```
Listing 3.3: exceed.cpp
```cpp
#include <iostream>

using namespace std;

int main() {
    cout << -30000000000 << endl;
}
```
```

Negative billion is too large for 32-bit integers, however, and the program’s output is wrong:

```
1294967296
```

The printed value was not negative! Most C++ compilers will issue a warning about this statement.
secrease::expressionarithmetic explores errors vs. warnings in more detail. If the compiler finds
an error in the source, it will not generate the code. A warning indicates a potential problem and
does not stop the compiler from producing an executable. Here we see that the programmer should
heed this warning because the program's execution produces meaningless output.

This limited range of values is common among programming languages since each integer is stored in
a fixed amount of memory. Larger numbers require more memory in memory. To model the infinite
set of mathematical integers an infinite amount of memory would be needed! As we see later, C++
supports an integer type with a greater range.
