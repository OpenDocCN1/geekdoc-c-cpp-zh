# F2. ARRAYS AND FUNCTIONS

```
Segmentation fault
```

If your program is using an array, and it terminates with such a message, you should check its source code carefully for places where out-of-bounds array accesses are possible.

The following code fragment shows some proper and improper array accesses:

```
int numbers[10];      // Declare the array
numbers[0] = 5;      // Put value 5 first
numbers[9] = 2;      // Put value 2 last
numbers[-1] = 5;     // Out of bounds; first valid index is 0
numbers[10] = 5;     // Out of bounds; last valid index is 9
numbers[1.3] = 5;    // Out of bounds; 1.3 is not an int
```

Notice the comment does check that the type of the index is a valid expression.

In an array with a for loop such as

```
for (int i = 0; i < SIZE; i++)
    cout << a[i] << endl;
```

it is easy to ensure that x falls out the bounds of an array, but arbitrary values should be checked before their use:

```
int x;
int a[10];            // Make an array with 10 spaces available
cin >> x;             // User enters x at run time
if (0 < x && x < 10) // Ensure x is within the bounds of the array
    a[x] = 1;         // This is safe now
else
    cout << "Index provided is out of range" << endl;
```

Here, if it statement ensures the array access is within the array's bounds.
