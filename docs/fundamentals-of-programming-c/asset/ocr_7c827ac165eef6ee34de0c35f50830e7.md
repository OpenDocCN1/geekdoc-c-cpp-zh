Since we derived the FileNotFoundException class from exception, any FileNotException object is also a exception object (see Section 17.1). This enables the main function to catch a FileNotFoundException object in its catch block though it is declared to catch exception objects.

The C++ standard library provides a number of exception classes, all derived from exception. The vector-of-bounds exception objects thrown by the at method are instances of the standard out_of_range class. The out_of_range class is derived from the standard logic_error class which is derived from the standard exception class. Figure 19.3 shows the relationship between these exception classes.
