If the executable is named primes.exe, you can redirect its output at the command line by issuing the command

```
primes > run.out
```

This creates a file named run.out that can be viewed with any text editor. Its contents are exactly what would have been printed to the screen if the redirection is not used.

# 8.5 Character Functions

The C library provides a number of character functions that are useful to C++ programmers. Listing 8.9 (toupper.cpp) converts lowercase letters to uppercase letters.

```
Listing 8.9: toupper.cpp
#include <iostream>
#include <cctype>

using namespace std;

int main() {
    for (char lower = 'a'; lower <= 'z'; lower++) {
        char upper = toupper(lower);
        cout << lower << " " << upper << endl;
    }
```
