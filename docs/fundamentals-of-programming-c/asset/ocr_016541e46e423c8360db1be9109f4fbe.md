+   - When you select **OK** on the project creation dialog, a Win32 Application Wizard as shown on the left of Figure A.4 appears. At this point, the instructions in the dialog say “Click Finish” from any window to accept the current settings. **Do not select Finish**; instead, select *Next* to continue. We have one more key step to complete our project is set up correctly.

+   - In the subsequent **Application Settings** dialog (as shown the right image in Figure A.4), select the **Empty project** checkbox. The dialog should look like the image in Figure A.4 before you proceed. Choose **Finish** when you are ready to continue.

+   - At this point, the **Solution Explorer** panel showed the structure of the newly created, albeit empty, project. The left image in Figure A.5 shows the newly populated **Solution Explorer**.

+   - Right click on the **simple element** in the **Solution Explorer**. As shown on the right of Figure A.5, select **Add** and **New Item** from the popping-up menu.

+   - In the **New Item** dialog box, shown on the left in Figure A.6, select C++ File (.cpp) and enter a name for the C+ file in the text field at the top. You need not add .cpp to the end of the name, as Visual Studio will do that for you. The file will be named simple.cpp. Press Add when done.

+   - As shown on the right of Figure A.6, the **Solution Explorer** panel now shows the file **simple.cpp**, and the large editor pane is ready for you to type the source code for the program. The new source file is initially empty.
