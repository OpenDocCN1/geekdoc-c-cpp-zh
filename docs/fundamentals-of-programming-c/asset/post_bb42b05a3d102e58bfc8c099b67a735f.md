## 6.2 Nested Loops

Just like if statements, while bodies can contain arbitrary C++ statements, including other while statements. A loop can be nested within another loop. To see how nested loops work, consider a program that produces a multiplication table. Elementary students use multiplication tables, or times, to learn the products of integers up to 10 or 12. Figure 6.5 shows a 10 x 10 multiplication table. We want our multiplication table to be flexible and allow the user to specify the table's size. We will begin our development with a simple program and add features as we go. First, we will not worry about printing the table's row and column titles, we will print the lines separating the titles from the contents of the table. Initially we will only print the contents of the table. We will need a nested loop to print the table's contents, but that is still too much to manage in our first attempt. In our first attempt we will print the rows in a very rudimentary manner. We are satisfied that our simple program can add more features. Listing 6.9 (timetable-1st-try.cpp) does print each row in its proper place—it does not supply the detail for each row. Our next step is to refine the way the program prints each row. Each row should contain size numbers. Each number within each row represents the product of the current row and current column; for example, in row 2, column 5 should be 2 × 5 = 10. In each row, therefore, we must vary the column number from 1 to size. Listing 6.10 (timetable-2nd-try.cpp) contains the needed refinement.

Listing 6.10: timetable-2nd-try.cpp

```cpp
#include <iostream>

using namespace std;

int main() {
    int size;    // The number of rows and columns in the table
    cout << "Please enter the table size: ";
    cin >> size; // Print a size x multiplication table
    int row = 1;  // Table has rows.
    while (row <= size) { // Reset column for each row
        int column = 1;
        while (column <= size) { // Table has columns.
            int product = row*column; // Compute product
            cout << product << " "; // Display product
            column++; // Next element
        }
        cout << endl; // Move to next row
        row++; // Next row
    }
}
```

We use a loop to print the contents of each row. The outer loop controls how many rows the program prints, and the inner loop, executed each time the program rows, prints the individual elements that make up a row. The Result of Listing 6.10 (timetable-2nd-try.cpp) is the numbers within each column are not lined up nicely, but the numbers are in their correct positions relative to each other. We can use the setw manipulator introduced in Listing 6.7 (power10justified.cpp) to right justify the numbers within a four-digit area. Listing 6.11 (timetable-3rd-try.cpp) contains this adjustment.

Listing 6.11: timetable-3rd-try.cpp

```cpp
#include <iostream>
#include <iomanip>

using namespace std;

int main() {
    int size;      // The number of rows and columns in the table
    cout << "Please enter the table size:";
    cin >> size;
    // Print a size x multiplication table
    int row = 1;
    while (row <= size) { // Table has size rows.
        int column = 1; // Reset column for each row.
        while (column <= size) { // Table has size columns.
            int product = row*column; // Compute product
            cout << setw(4) << product << " "; // Display product
            column++; // Next element
        }
        cout << endl; // Move to next row
        row++; // Next row
    }
}
```
