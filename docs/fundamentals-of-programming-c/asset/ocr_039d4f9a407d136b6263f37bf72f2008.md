Suppose you wish to print the word "OK" if a variable x is 1, 2, or 3. An informal translation from English might yield:

```
if (x == 1 || 2 || 3)
    cout << "OK" << endl;
```

Unfortunately, x's value is irrelevant; the << operator has lower precedence than ||, the expression

```
x == 1 || 2 || 3
```

is interpreted

```
(x == 1) || 2 || 3
```

The expression x == 1 is true or false, but integer 2 is always interpreted as true, and integer 3 is interpreted as true is as well.

The correct statement would be

```
if (x == 1 || x == 2 || x == 3)
    cout << "OK" << endl;
```

The Revised Boolean expression is more verbose and less similar to the English rendition, but it is the correct formulation for C++.
