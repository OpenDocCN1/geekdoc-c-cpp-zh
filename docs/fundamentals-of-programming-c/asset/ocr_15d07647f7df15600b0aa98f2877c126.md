# 2.2 Editing, Compiling, and Running the Program

C++ programmers have two options for C++ development environments. One involves a command-line environment with a collection of independent tools. The other option is to use an IDE (see Section 1.2) which combines all the tools into a convenient package. Visual Studio is the dominant IDE on the Microsoft Windows platform, Linux and Apple Mac developers often use the Xcode IDE. Appendix A provides an overview of how to use the Visual Studio 2013 IDE to develop a simple C++.

The myriad of features and options in these powerful IDE can be bewildering to learn. In a command-line environment the programmer needs only a few simple commands into a window to edit, compile, and execute programs. Some developers prefer the simplicity and flexibility of command-line environments, such as less complex projects.

One prominent command-line build system is the GCC Compiler Collector (http://gcc.gnu.org/) or GCC for short. The GCC C++ compiler, g++, is one of most C++ standards conforming compilers. The GCC C++ compiler is available for the Microsoft Windows, Apple Mac, and Linux platforms. It is a free, open-source project with a world-wide development team. Appendix C provides an overview of how to use the GCC C++ compiler.

Visual Studio and Xcode offer command line development options. Appendix B provides an overview of the Visual Studio command line development process.

# 2.3 Variations of our program

The two Items 2.1 (simple.cpp) needed to display a message on the screen, count and endl, have longer names: std::cout and std::endl. The using namespace std allows us to omit the std:: prefixes and use shorter names. This directive is optional, but if it is used, the longer names are required. For example, Listing 2.2 (simple2.cpp) shows an alternative of writing Listing 2.1 (simple.cpp).

Listing 2.2:simple2.cpp

```
#include <iostream>

int main() {
    std::cout << "This is a simple C++ program!" << std::endl;
}
```
