If p points to an array, the element at index i is accessed as p[i] or *(p + i).
The expression *(p + i) dereferences the address that is positions away from the address referenced
by p.

Sometimes pointer notation is used to represent an array parameter to a function. The array print
function begins

```
void print(const int a[], int n)
```

could instead be written

```
void print(const int *a, int n)
```

where a is a pointer to an array. The compiler treats the two identically in the machine language it
produces.
Both use the pointer when declaring their array parameters.
