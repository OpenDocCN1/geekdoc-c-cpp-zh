If you are using the GCC tools instead of Visual Studio, in order to make the executable program primetest (or primetest.exe under the Microsoft Windows version of the gcc tools), you would issue the command

```
g++ -o primetest -Wall -O1 -std=c++11 prime.cpp primetest.cpp
```

The GNU C++ compiler will separately compile the two source files producing two machine object files. The linker will use those object files to create the executable. When the linker has created it, executable automatically deletes the object files.

The is_prime function is now readily available to other programs. If it becomes an often used function in many programs, it can be compiled and placed into a special file that requires it. If our is_prime is placed in a dynamic library, its code can be linked at run time and be shared by many executing programs. We do not cover library creation in this test.
