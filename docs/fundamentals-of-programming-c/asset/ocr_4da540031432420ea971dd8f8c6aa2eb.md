# 8.7 Summary

+   - The C and C++ standard library provides a collection of routines that can be incorporated into code that you write.
- When faced with the choice of using a standard library function or writing your own code to solve the same problem, choose the library function. The standard function will be tested thoroughly, well, and likely more efficient than the code you would write.
- The function is a standard unit of reuse in C++.
