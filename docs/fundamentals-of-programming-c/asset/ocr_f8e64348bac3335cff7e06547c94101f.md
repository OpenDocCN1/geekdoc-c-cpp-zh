# 10.8. PASS BY REFERENCE

```
cout << "var1 = " << var1 << ", var2 = " << var2 << endl;
```

The output of Listing 10.17 (swapwithpointers.cpp) is

```
var1 = 5, var2 = 19
var1 = 19, var2 = 5
```

which is the result we were trying to achieve. The swap function can manipulate main's variables directly since we passed pointers to those variables.

In Listing 10.17 (swapwithpointers.cpp):

+   - The formal parameters to swap, a and b, are pointers to integers; they are not integers themselves. In order to access the integer to the pointer refers, it must be dereferenced. That is why any use of a in swap's body is prefixed with the pointer dereferencing operator, *.
  int temp = *a;

assigns to the local variable temp value of the variable to which a points. Since main passes the address of var1 as the first parameter in call to swap, in this case points to var, so *a is effectively another way to access the memory location of var in main. The function assigns the value of main's var1 to temp.

+   - In swap's statement
  *a = *b;

since *a is effectively main's var1 variable and *b is effectively main's var2 variable, this statement assigns the value of main's var2 to its var1 variable.

+   - The swap function's
  *b = temp;

statement assigns the local temp value to main's var2 variable, since swap's b parameter points to main's var2.

+   - Within main, the call
  swap(&var1, &var2);

passes the addresses of its local variables to swap.

In reality, pass by reference is still using pass by value. Instead of passing copies of values, we are passing copies of addresses. In Listing 10.17 (swapwithpointers.cpp), for example, the values of the addresses of var1 and var2 are copied to the formal parameters a and b. The difference is we are not attempting to reassign a or b, but are reassigning memory to which a and b point. Whether we use the original address or a copy of the address, it is still the address—the same number location in memory.
