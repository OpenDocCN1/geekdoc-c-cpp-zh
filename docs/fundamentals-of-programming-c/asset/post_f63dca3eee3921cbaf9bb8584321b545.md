
## 11.1. VECTORS

| | 5 | 19 | 3 |
|---|---|---|---|
| 1 | 22 | -8 | 10 |
| | 0 | 1 | 2 |

Figure 11.5: A $2 \times 3$ two-dimensional vector

Note that each row appears within its set of curly braces, and each row looks like 1D vector initialization list.

To access an element of a 2D vector, use two subscripts:

```cpp
a[r][c] = 4; // Assign element at row r, column c
cout << a[m][n] << endl; // Display element at row m, column n
```

The following function prints the contents of a 2D vector of doubles:

```cpp
void print(const vector<vector<double>>& m) {
  for (unsigned row = 0; row < m.size(); row++) {
    for (unsigned col = 0; col < m[row].size(); col++) {
      cout << setw(5) << m[row][col];
    }
    cout << endl;
  }
}
```

We can use range-based statements to simplify the code:

```cpp
void print(const vector<vector<double>>& m) {
  for (const vector<double>& row : m) { // For each row
    for (int elem : row) // For each element in row
      cout << setw(5) << elem;
    }
    cout << endl;
  }
}
```

The declaration of the parameter m is somewhat complicated. We can simplify the syntax by using C++ typedef statement:

```cpp
typedef vector<vector<double>> Matrix;
```

creates a new name Matrix for the existing type of 2D vector containing doubles. If you omit the word typedef from the above statement, it becomes a declaration of 2D vector. The typedef keyword changes the meaning of the statement instead defines a simpler name for the type. typedef statements usually appear near the top of a source file and have global scope. It is uncommon to see a local typedef statement within a function body.

Given the typedef statement defining the type Matrix, we may express the parameter for the print function simply:

```cpp
void print(const Matrix& m) {
    for (const vector<double>& row : m) { // For each row
        for (int elem : row) // For each element in row
            cout << setw(5) << elem;
        }
    return;
}
```

We can take advantage of the type inference of C++11 to simplify the print function further (see Section 3.9):

```cpp
void print(const Matrix& m) {
    for (auto row : m) { // For each row
        for (int elem : row) // For each element in row
            cout << setw(5) << elem;
    }
    return;
}
```

Here we replace the explicit vector<double>& with the word auto. The compiler is able to infer the type of the variable from context: m is a Matrix (that is, a vector<vector<double>>), so row must be an element of the 2D vector (which is itself a 1D vector). Listing 11.10 (twodimvector.cpp) experiments with 2D vectors and takes advantage of the typedef to simplify the code.

Listing 11.10: todimvector.cpp
```cpp
#include <iostream>
#include <iomanip>
#include <vector>

using namespace std;

typedef vector<vector<double>> Matrix;

// Allow the user to enter the elements of a matrix
void populate(Matrix& m) {
    cout << "Enter " << m.size() << " rows of the matrix: " << endl;
    for (unsigned row = 0; row < m.size(); row++) {
        cout << "Row " << row << " enter " << m[row].size() << " values:";
        for (double& elem : m[row])
            cin >> elem;
    }
}
```

## 11.2. ARRAYS

```cpp
void print_matrix(const Matrix m) {
  for (auto row : m) {
    for (double elem : row)
      cout << setw(5) << elem;
    }
    cout << endl;
  }
}

int main() {
  int rows, columns;
  cout << "How many rows ?";
  cin >> rows;
  cout << "How many columns ?";
  cin >> columns;
  // Declare the 2D vector
  Matrix mat(rows, vector<double>(columns));
  // Populate the vector
  populate_matrix(mat);
  // Print the vector
  print_matrix(mat);
}
```

An expression that uses just index with a 2D vector represents a single row within the 2D vector. This row is itself a 1D vector. If a is a 2D vector and i is an integer, then the expression

```cpp
a[i]
```

We can build vectors with dimensions higher than two. Each “slice” of a 3D vector is simply a 2D vector, a vector of 3D vectors. For example, the statement

```cpp
matrix[x][y][z] = 1.0034;
```

assigns 1.0034 to an element in a 4D vector of doubles. In practice, vectors with more than two dimensions are rare, but advanced scientific and engineering applications sometimes require higher-dimensional vectors.

## 11.2 Arrays

C++ is an object-oriented programming language, and a vector is an example of a software object. The C programming language does not directly support object-oriented programming, and therefore does not have vectors to represent aggregate types. The C language uses a more primitive construct called an array. C++, as an extension of C, supports arrays as well as vectors. Arrays come in two varieties, static and dynamic. Arrays may be local or global. Programmers need not worry about managing the memory used by static arrays. The compiler and runtime environment automatically ensure the array has enough space to hold all of its elements. The space held by local arrays is automatically freed when the local array goes out of the scope of its declaration. Global arrays live for the lifetime of the executing program. Memory management for static arrays, works just like scalar variables.
