```
# The Inverse Power Method.

We assume a known approximation $\mu$ of an eigenvalue $\lambda_j$ (with $\mu,\lambda_j\in\mathbb{C}$). How can we determine an eigenvector associated to $\lambda_j$?

We assume that $\forall k\ne j$, $0<|\mu-\lambda_j|<|\mu-\lambda_k|$, and thus, $\lambda_j$ is a simple eigenvalue. We then consider $(A-\mu I)^{-1}$, whose largest eigenvalue is $(\lambda_j-\mu)^{-1}$, and we apply the power method to this matrix.

Let us take for example:

```
```python
sage: A = matrix(RDF, [[1,3,2], [1,2,3], [0,5,2]])
```
```

By calling the method `A.eigenvalues()`, we find the eigenvalues (rounded to 5 significant digits) `6.3929, 0.56052, -1.9535`. We will search the eigenvector associated to the second eigenvalue, starting from an approximation:
```
