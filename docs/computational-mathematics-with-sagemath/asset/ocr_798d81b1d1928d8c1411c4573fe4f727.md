**Eigenvalues, Eigenvectors.** Considering the factorisation of the minimal polynomial into irreducible factors, φ1 = ψ1^{m1} ... ψs^{ms}, then every invariant factor can be written in the form φi = ψ1^{m_i1} ... ψs^{m_is}, with multiplicities m_{i,j} ≤ m_j. One can show that there is a similarity transformation, replacing each companion block C_{φi} in the Frobenius normal form by a diagonal block Diag(C_{ψ1^{m_i1}}, ..., C_{ψs^{m_is}}). This variant of the Frobenius normal form, called intermediate form, is still composed of companion blocks but each of which now corresponds to an irreducible polynomial raised to some power.
