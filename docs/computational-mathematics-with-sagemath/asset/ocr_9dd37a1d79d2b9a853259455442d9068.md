**Elimination Ideals.** In the context of polynomial systems, the “consequences” of equations \(p_1(x)=\cdots=p_s(x)=0\) are elements of the ideal \(\langle p_1,\ldots,p_s\rangle\). If \(J\) is an ideal of \(K[x_1,\ldots,x_n]\), we call the \(k\)-th *elimination ideal* of \(J\) the set

$$
J_k = J \cap K[x_{k+1},\ldots,x_n] \tag{9.5}
$$

of elements of \(J\) which only contain the \(n-k\) last variables. This is an ideal of \(K[x_{k+1},\ldots,x_n]\).
