If we consider the set $P$ of bijections from $V$ to $\{1,\ldots,|V|\}$, we notice that

$$
\begin{aligned}
\sum_{n\in P}|S_n| &= \sum_{n\in P}\sum_{v\in G} \text{1 if }v\text{ is minimal for }n\text{, 0 otherwise}\\
&= \sum_{v\in G}\left(\sum_{n\in P} \text{1 if }v\text{ is minimal for }n\text{, 0 otherwise}\right)\\
&= \sum_{v\in G}\frac{|P|}{d(v)+1} = |P|\sum_{v\in G}\frac{1}{d(v)+1}.
\end{aligned}
$$

As a consequence, such a function corresponds on average to an independent set of size $\sum_{v\in G} \frac{1}{d(v)+1}$. To obtain a set of this size with Sage, we will use random bijections using the Permutations class, until we obtain the size promised by the theorem:
