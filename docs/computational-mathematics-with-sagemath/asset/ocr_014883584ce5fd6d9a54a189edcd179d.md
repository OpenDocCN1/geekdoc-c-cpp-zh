# ### 7.3.2 Root Finding

The computation of the roots of a polynomial may be performed in several ways: Do we want real or complex roots? Roots in another domain? Do we want exact or approximate roots? With or without multiplicities? In a guaranteed or heuristic way? The _roots_ method of a polynomial returns by default the roots in its base ring, in the form of a list of pairs (root, multiplicity):

```
    sage: R.<x> = ZZ[]; p = (2*x^2-5*x+2)^2 * (x^4-7); p.roots()
    [(2, 2)]
```

With a parameter, $roots(D)$ returns the roots in the domain $D$, here the rational roots, and approximations of the $\ell$-adic roots for $\ell = 19$:

```
    sage: p.roots(QQ)
    [(2, 2), (1/2, 2)]
```

```
    sage: p.roots(Zp(19, print_max_terms=3))
    [(7 + 16*19 + 17*19^2 + ... + O(19^20), 1),
     (12 + 2*19 + 19^2 + ... + O(19^20), 1),
     (10 + 9*19 + 9*19^2 + ... + O(19^20), 2),
     (2 + O(19^20), 2)]
```
