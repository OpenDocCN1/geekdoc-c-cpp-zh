The minimum is thus attained by taking $\lambda_i = (u_i^H b)/\sigma_i$ for $1 \le i \le p$ if $\lambda_i \ne 0$, and $\lambda_i = 0$ otherwise. We finally obtain the solution $x = V\lambda$.

Naturally, the measures $A$ and $B$ contain some noise, whence the problem has no solution in general. $$\|A - BQ\|_F^2.$$
