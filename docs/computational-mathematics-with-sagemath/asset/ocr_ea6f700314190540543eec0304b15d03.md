# Errors and Condition Number: an Example, with Exact and Approximate Computations.

Let us use the capability of Sage to perform exact computations when the coefficients are rational. We consider the Hilbert matrix

$$a_{ij}=1/(i+j-1),\ i,j=1,\ldots,n.$$

The following program computes¹ exactly the condition number of Hilbert matrices, using the norm $\|\cdot\|_\infty$:

```
```python
sage: def cond_hilbert(n):
.....:     A = matrix(QQ, [[1/(i+j-1) for j in [1..n]] for i in [1..n]])
.....:     return A.norm(Infinity) * (A^-1).norm(Infinity)
```
```

Here are the results for a few $n$:

| $n$ | condition number |
|---:|---:|
| 2 | 27 |
| 4 | 28375 |
| 8 | 33872791095 |
| 16 | 5.06277e+22 |
| 32 | 1.35711e+47 |

We see the extremely fast growth of the condition number with respect to $n$. We can prove that $\kappa(A)\ge e^{7n/2}$, which indeed grows very quickly. Still computing in the rational field, we take $x=[1,\ldots,1]^t$, $y=Ax$ and we solve the system $\tilde{A}s=y$ where $\tilde{A}$ is a slight modification of the matrix $A$; then we compare the solution $s$ and $x=A^{-1}y$, thus measuring the error introduced by the modification of $A$:

```
```python
sage: def diff_hilbert(n):
.....:     x = vector(QQ, [1 for i in range(0,n)])
.....:     A = matrix(QQ, [[1/(i+j-1) for j in [1..n]] for i in [1..n]])
.....:     y = A*x
.....:     A[n-1,n-1] = (1/(2*n-1))*(1+(1/10^5))  # modifies the matrix
.....:     s = A\\y
.....:     return max(abs(float(s[i]-x[i])) for i in range(0,n))
```
```

We obtain:

| $n$ | error (diff_hilbert) |
|---:|---:|
| 2 | 3.99984e-05 |
| 4 | 5.97610e-3 |
| 8 | 4.80536 |
| 16 | 67.9885 |
| 32 | 20034.3 |

The error very rapidly becomes too large with respect to $x_i=1$.
