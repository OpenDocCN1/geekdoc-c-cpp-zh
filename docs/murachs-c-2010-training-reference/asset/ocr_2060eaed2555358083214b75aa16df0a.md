# What you will learn in this book

+   * Section 1 tours the .NET Framework and teaches the basics of working with Microsoft's development environment, Visual Studio 2010. Here, you'll learn how to develop a simple Windows application. To do that, you'll use the Form Designer to design a Windows form, and you'll use the Code Editor to add and edit the C# code for the form.
* Section 2 presents the data types, control structures, and other essential elements of the C# language as well as the core .NET classes that you'llll use to develop Windows applications. Along the way, you'll also learn how to do the tasks that are required by professional business applications. In chapter 7, for example, you'll learn data validation techniques that you won't find in competing books, even though everyone should know them.
* Section 3 teaches the powerful object-oriented programming features of the C# language. Here, you'll learn how to create your own business and database classes, and you'll learn how to use the database classes to populate the business objects with data from files or a database. That, of course, is how applications work in the real world, even though most C# books don't show you that. You'll also learn how to use inheritance, polymorphism, interfaces, and much more.
* Section 4 teaches you the basic skills for developing database applications. To start, you'll learn how to use data sources to build database applications quickly, with minimal code and without using any ADO.NET code. This is particularly useful for developing small, relatively simple applications and for prototyping larger applications. Then, you'll learn how to write ADO.net code that directly accesses the database. You'll use these skills as your applications get more complicated.
