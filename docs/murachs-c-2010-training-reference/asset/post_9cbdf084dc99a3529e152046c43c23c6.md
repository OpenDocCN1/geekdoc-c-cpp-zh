
# How to use the Form Designer

When you open an existing C# project, you'll see a screen like the one in Figure 1-8. Here, one or more tabbed windows are displayed in the main part of the Visual Studio window. In this example, the first tab is for a form named `frmDepreciation.cs`, and the second tab is selected, its form is displayed in the Form Designer window (or just Form Designer). You use the Form Designer to develop the user interface for a form, and you'll learn more about working with the Form Designer in chapter 2.

This figure also shows some of the windows that you use as you develop C# applications. To add controls to a form, for example, you use the Toolbox. To set the properties of a form or control, you use the Properties window. To manage the files that make up a solution you can use the Solution Explorer. If all three of these windows aren't shown when you open a project, you can use the techniques in figure 1-11 to open and arrange them.

This figure also points out two of the toolbars that are available from Visual Studio. You can use these toolbars to perform a variety of operations, and the toolbars change depending on what you're doing. In course, you can also perform any operation by using the menus at the top of Visual Studio. And you can perform some operations by using the context-sensitive shortcut menu that's displayed when you right-click on an object within Visual Studio.

# Description

- The main Visual Studio workspace contains one or more tabbed windows. To develop a form, you use the Form Designer window (or just Form Designer). To develop code, you use the Code Editor window that's shown in figure 1-9.
- To add controls and other items to a form, you use the Toolbox. The Toolbox contains a variety of items organized into categories as Common Controls, Containers, Menus & Toolbars, Data, and so on.
- To change the way a form or control looks or operates, use the Properties window. This window displays the properties of the item that's selected in the Form Designer.
- You use the Solution Explorer to manage project files. You'll learn more about the Solution Explorer in figure 1-10.
- Several toolbars are available from Visual Studio. The Standard toolbar includes Windows toolbar buttons such as Open, Save, Cut, Copy, and Paste, plus other buttons that you'll learn about as you progress through this book.
- As you work with Visual Studio, you'll find that other toolbars are displayed, depending on what you're doing.

# How to use the Code Editor

If you want to work with the source code for an application, you can use the Code Editor window (or just Code Editor) shown in figure 1-9. The Code Editor lets you enter and edit the source code for a C# application.

After you have designed the user interface for a project by using the Form Designer to place controls you can use the Code Editor to enter and edit the C# code that makes the controls work the way you want them to. The easiest way you can begin typing the C# statements that will be executed when the user performs the most common action on that control. For example, you can enter the statements that will be executed when the user clicks on that button.

The Code Editor works much like any other text editor. However, the Code Editor has a number of special features that simplify the editing C# code. For example, color is used to distinguish C# keywords from variables, comments, and other language elements. The improved IntelliSense feature can help you enter code correctly. You'll learn more about working with the Code Editor in chapter 3.

# How to use the Solution Explorer

- The Solution Explorer lists all of the projects in the solution.
- The Solution Explorer shows the files that make up each project.
