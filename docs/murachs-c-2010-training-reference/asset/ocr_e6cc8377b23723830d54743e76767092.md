# An introduction to the System.IO classes

The System.IO namespace provides a variety of Classes for working with files and for managing directories, files, and paths. You will be introduced to those classes in the topics that follow. In addition, you'll learn about the types of files and streams supported by the System.IO classes and how they're used to perform I/O.

# The classes for managing directories, files, and paths

And you can use the methods of the File class to create, delete, or move a file, or to determine if a file exists. Since the methods for both of these classes are static methods, you call them directly from the class.
