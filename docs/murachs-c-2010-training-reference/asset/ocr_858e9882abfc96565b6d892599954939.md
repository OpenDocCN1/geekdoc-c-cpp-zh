# How to work with files and data streams

In section 4, you learned how to develop applications that store and retrieve data from a database. Because databases provide powerful features for working with data, databases are typically used for the data in most business applications. For some applications, though, you may need to save data in a file on disk and then read data whenever it's needed. In this chapter, you'll learn how to do that with two different types of files: text and binary.
