# How to refer to properties, methods, and events

As you enter the code for a form in the Code Editor window, you often need refer to the properties, methods, and events of the form's objects. To do that, you type the name of the object, a period (also known as a dot operator, or dot), and the name of the member. This is summarized in figure 3-2.

In addition to referring to the properties, methods, and events of objects, you can also refer to some of the properties and methods of a class directly from that class. The code shown in the Code Editor in this figure, for example, refer to the ToDecimal of the Convert class. A property or method that you can refer directly from a class this is called a static member. You'll learn more about static members in Chapter 4. For now, you just need to refer to static properties and methods using the same techniques that you use to refer to the properties and methods of an object.

To make it easier for you refer to the members of an object or class, Visual Studio's IntelliSense feature displays a list of the members that are available for object or class after you type the object or class name and a period. Then, you can highlight the entry you want by clicking on, typing one or more letters of its name, or using the arrow keys to scroll through the list. In most cases, you can then complete the entry by pressing the Tab or Enter key or entering a space. If the member name is followed by another character, such as a parenthesis, you can also complete the entry by typing that character.
