# How to work with XML

The .NET Framework provides nearly 150 different classes for working XML documents. Fortunately, you don't need to know how to use them all. In this topic, I'll get you started with XML programming by showing you how to use two classes: the Xml class and the XmlReader class. These are the classes that provide the basic services you need to write and read XML files.

Note that both of these classes reside in the System.XML namespace. As a result, you should include a using statement for the System.XML namespace at the beginning of any class that uses either of them. Otherwise, you have to qualify the class names each you refer to them.

# How to use the XmlWriter class

Figure 22-5 shows the methods of the XmlWriter class that you can use to write data to an XML file. These methods make it easy to generate the tags for the XML document. As a result, you can concentrate on the document's structure and content.

Since the XmlWriter class is an abstract class, you can't construct an object from this class. However, you can create an XmlWriter object using one of the static Create methods of the XmlWriter class. To do that, you typically use a string variable that holds the path and name of the file. If you specify a file that already exists, it's deleted and recreated. You cannot use this to add XML to an existing file.

Before you code any statements that write XML to a file, you typically want to change some settings for the XmlWriter object so it uses spaces to indent elements. This will make your XML files easier to read if they're opened in the XML Editor. To do that, you need to use XmlSettings object and set its Indent and IndentChars properties. Then, you pass this object to the Create method when you create an XmlWriter object.

To write XML data, you use one of the Write methods of the XmlWriter class. Although this class has 28 Write methods, you can create basic XML documents using just the six Write methods in this figure.

When you use these methods, you need to use the WriteStartElement and WriteEndElement methods for elements that have children, such as the Products element. However, you don't need to use a WriteStartElement or WriteElement method to create an element that only contains content, such as the Description and Price elements. In this case, you can use the WriteElementString method to automatically write the start tag, and the end tag.
