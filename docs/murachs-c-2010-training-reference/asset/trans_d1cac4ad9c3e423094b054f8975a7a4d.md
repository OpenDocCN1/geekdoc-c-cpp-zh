一旦设置好所有set，只需点击“立即发布”（Publish Now）按钮即可发布应用程序。作为发布过程的一部分，会创建一个用于安装应用程序的网页。该页面将显示，以便你可以在自己的计算机上安装并测试应用程序。

## 如何选择发布的文件

如果你点击项目设计器（Project Designer）发布页上的“应用程序文件”（Application Files）按钮，将显示图 25-4 所示的“应用程序文件”对话框。此对话框列出了项目的输出文件，并指示哪些文件将被发布。默认情况下，只会发布 exe 和 .manifest 文件。如果你也想发布 pdb 文件，可以从“发布状态”（Publish Status）下拉列表中选择“包含”（Include）选项。

## 如何选择前提条件

如果你点击发布页上的“前提条件”（Prerequisites）按钮，将显示图 25-4 所示的“前提条件”对话框。此对话框允许你选择应用程序正常运行必须安装的组件。默认选择了 Windows Installer 3.1 和目标框架（通常是 .NET Framework 4 Client Profile），这通常是你所需要的。

在某些情况下，需要额外的组件。例如，如果应用程序使用了安装在用户计算机上的 SQL Server 2008 数据库，则用户必须安装 SQL Server 2008 Express。你将在本章中学习更多相关内容。

默认情况下，你选择的组件将从供应商网站下载，然后由 ClickOnce 安装。例如，如果需要 .NET Framework 或 SQL Server Express，它们将从微软网站下载。如果开发应用程序的计算机上已有这些组件，你可以将它们发布到与应用程序相同的位置。这时，如果你在“前提条件”对话框中选择第二个选项，组件将从与应用程序相同的位置下载。如果你从其他位置提供组件，也可以使用第三个选项来指定该位置。

## 如何设置更新选项

默认情况下，应用程序不会检查更新，这通常不是你想要的。要更改此工作方式，你需要使用图 25-5 所示的“应用程序更新”（Application Updates）对话框。要显示此对话框，点击项目属性窗口发布页上的“更新”（Updates）按钮。

首先，你选择对话框顶部的复选框，表示应用程序在用户每次运行时都检查更新。当你勾选它时，随后的两个选项将变为可用，且第二个选项默认被选中。此选项会导致应用程序在用户每次运行时都检查更新。然后，如果有可用更新，将显示一个对话框允许用户安装更新。你将在一分钟后看到那个对话框。

你还可以通过选择“在应用程序启动后”（After the Application Starts）选项，指定应用程序在下次运行之前不安装更新。如果你选择此选项，还可以指定应用程序检查更新的频率。默认情况下，它会在每次运行时检查更新，但你也可以让它按指定的天数间隔检查。

你还可以使用“应用程序更新”对话框指定必须安装的应用程序最低版本号。然后，当用户运行应用程序时，如果没有安装该版本或更高版本，将自动安装。

最后，“应用程序更新”对话框允许你指定应用程序更新的位置。大多数情况下，你会将更新发布到与原始应用程序相同的位置，因此你可以留空此选项。

## 如何设置选项

点击项目属性窗口发布页上的按钮时，会显示“发布选项”（Publish Options）对话框，允许你设置各种选项。这些选项分为四个选项卡，如图 25-6 所示。在大多数情况下，你会将“发布选项”对话框中的其余选项保持为默认设置。然而，如果你将应用程序发布到 CD，你可能希望选择“部署”（Deployment）选项卡上的倒数第二个选项。这样，当插入 CD 时，安装将自动开始。此外，如果你在安装应用程序时在用户的桌面上创建快捷方式，可以选择“清单”（Manifests）选项卡上的最后一个选项。
