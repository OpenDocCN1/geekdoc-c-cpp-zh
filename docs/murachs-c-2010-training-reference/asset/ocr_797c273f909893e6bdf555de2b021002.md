# The Application Files dialog box for a project that contains a database file

![](bbox=[0.105, 0.085, 0.693, 0.403])

# The connection string for a database that's on a network server

Data Source=DBSERVER\SqlExpress;Initial Catalog=KMMAbooks;Integrated Security=True

# The connection string for a database that's included in the project

DataSource=\SQLEXPRESS;AttachDbFilename=|DataDirectory\KMMAbooks.mdf;Integrated Security=True;UserInstance=True

# Description

+   - To use a database that's available via a LAN, then you need to make sure that the connection string is set correctly and all users have proper permissions to access the database. To do that, you may need to make the application a full trust edition.
- To deploy a database to the client along with the other files for the application, add the database file to the project. Then, that file and all related files are listed in the Application-Files dialog box, and those are published by default.
- If you store the connection string for an application in the app.config file, the configuration file is created when the application is published by default.
- If you add a SQL Server database file to a project, SQL Server 2008 Express is automatically included as a prerequisite.
- When you add a database file to project, the connection string is set as shown in the second example above. Then, when application is deployed, the DataDirectory in this string points to a special directory that's created to hold the database file.
- When you add a database file to a project, the Data Source Configuration Wizard starts. If you've already created the data sources for the application, you will want to cancel out of this wizard and then change the connection string so it looks like the second one above.
