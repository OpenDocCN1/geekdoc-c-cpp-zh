# # Concepts

+   * A relational database uses tables to store and manipulate data. Each table consists of one or more records, rows, or columns, that contain the data for a single entry. Each row contains one or more fields, or columns, with each column representing a single item of data.
* Most tables contain a primary key that uniquely identifies each row in the table. The primary key often consists of a single column, but it can also consist of two or more columns. If a primary key uses two or more columns, it is a composite primary key.
* In addition to primary keys, some database management systems let you define one or more non-primary keys. In SQL Server, these are called unique keys, and they are implemented using unique constraints. Like a primary key, a non-primary key uniquely identifies each row in the table.
* A table can also be defined based on one or more indexes. An index provides an efficient way to access data from a table based on the specific values in columns. An index is automatically created for a table's primary and non-primary keys.
