# Description

+   - The Customer Maintenance project contains the classes that define the business objects used by the Customer Maintenance application and the database classes that are used to work with the MMBooks database.

+   - The business objects are defined by the Customer and State classes. These objects hold data from the associated tables in the MMBooks database.

+   - The classes that end with DB, including CustomerDB, StateDB, and MMBooksDB, are the database classes. These classes provide shared methods for working with the MMBooks database.

+   - The StateDB class provides a public method for getting a list of states from the States table. The CustomerDB class provides public methods for getting the data for a customer and for adding, updating, and deleting a customer. And the MMBooksDB class provides a public method for getting a connection to the MMBooks database.
