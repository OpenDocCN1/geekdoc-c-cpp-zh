product1
Code=CS10

product2

# Code that creates these two object instances

```
product1, product2;
product1 = new Product("CS10","Murach's C# 2010", 54.50m);
product2 = new Product("VB10","Murach's Visual Basic 2010", 54.50m);
```

# Another way to create the object instances

```
product1 = new Product {"CS10",
Description = "Murach's C# 2010", Price = 54.50m};
product2 = new Product {"VB10",
Description = "Murach's Visual Basic 2010", Price = 54.50m};
```

# Description

+   - When an object is instantiated, a constructor is executed to initialize the data that makes up the object. If a class doesn't provide a constructor, a default constructor is executed. The default constructor initializes all the data to default values.
- The data that makes up an object is sometimes referred to as the object's state. Once an object has been instantiated, its state can change.
- The state of an object changes whenever you change the value of one of the object's properties or public fields. The state can also change when you call a method that affects the data stored within an object.
- An application can create two or more instances of the same class. Each instance is a separate entity with its own state. If you change the state of one object, the state of objects created from the same class is not affected.
- Object initializers let you create an instance of an object and assign values to that object in a single statement without explicitly calling a constructor.
- A class defines a reference type. That means the variable that's used to access an object instantiated from a class contains the address of the object, not the actual object.
