# How to set options and create a new project

Before you start your first Windows Forms application with Visual Studio 2010, you probably should change a few of the Visual options. That will make it easier for you to create a new project. You may also want to change the import and export settings.

# How to set the Visual Studio options

To set the options for Visual Studio, you the Options dialog box shown in figure 2-1. This dialog box is open, you can expand the Projects and Solutions group by clicking on the ▷ symbol to the left of that group, and you can click on the General group to display the options shown in this figure.
You can set the default project location by typing a path directly into the text box, or you can click the button to the right of the text box to display a dialog box lets lets navigate to the folder you want to use. This will set the default location for new projects, but you can always override it when you create a new project.
By default, most of the options available from this dialog box are set the way you want. However, if you want Visual Studio to work the way it's described in this book, you should check the Always Show and Save New Projects when Created options. Beyond that, it's worth taking a few minutes to review the other options that are available. Then, you can change if Visual Studio isn't working the way you want to. For instance, you may want to use the Startup group within the Environment group to change what's displayed when Visual Studio starts.

# How to change the import and export settings

The first time you start Visual Studio 2010, you're asked what Default Environment Settings you want to use. You can choose from several options including Visual Basic, Visual C#, Visual C++, and Web. Among others, your choice affects what items are available from some menus and what buttons are available from the Standard toolbar. For example, you choose the Visual C# settings, you open a project with the File→OpenProject/Solution command. But if you choose the Visual Basic settings, you open a project with the File→Open Project command.
To change these settings, you use the Import and Export Settings Wizard as described in this figure. In the first step of the wizard, choose the Reset All Settings option. In the second step, choose the Save, My Current Settings option. And in the last step, if you want yours to work as described in this book, choose the Visual C# Development Settings option. Later, if you switch to Visual Basic, C++, or web development, you can change the settings.
