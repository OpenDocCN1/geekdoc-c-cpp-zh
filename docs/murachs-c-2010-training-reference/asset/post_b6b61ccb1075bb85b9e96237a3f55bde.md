
# How to code conditional statements

Now that you know how to code Boolean expressions, you're ready to learn how to code conditional statements. These statements include the if-else statement and the switch statement.

## How to code if-else statements

5-3 shows how to use the if-else statement (or just if statement) to control the logic of your programs. This type of statement is the primary logical statement of all programming languages. It is the C# implementation of a control structure known as the selection structure because it lets you select different actions based on the results of Boolean expressions.

In the syntax of this, the brackets [] and the ellipsis (...) indicate that a clause is optional, and that the preceding element can be repeated as many times as needed. In other words, this syntax shows that you can code an if with or without else if clauses or an else clause. It also shows that you can code an if clause as many else clauses as you need. 

When an if statement is executed, C# begins by evaluating the Boolean expression in the if clause. If it's true, the statements within this clause are executed and the rest of the clauses in the if-else statement are skipped. If it's false, C# executes the first if clause (if there is one). If its Boolean expression is true, the statements within this else clause are executed and the rest of the if-else statement. Otherwise, C# executes the next else clause. This continues with any remaining else clauses. Finally, if none of the clauses contains a Boolean expression that evaluates to true, C# executes the statements in the else clause. The statement doesn't include an else clause, C# doesn't execute any statements.

When coding if-else statements, it's often good practice to code a set of braces for each clause. However, if a clause only contains a single statement, you can omit the braces. Although omitting the braces saves you typing and takes up less vertical space, coding the braces makes it easier to identify the statements for each clause, and it makes it easier for you to add more statements.

In C#, whenever you use braces, you define a block of code. If you declare a variable within a block, that is available only to the other statements in the block. This can be referred to as block scope. As a result, if you need to access a variable outside of an if statement, you should declare it before the statement.

When coding statements, it's a common practice to code one statement within another statement. This is known as nested statements. When you code nested statements, it's a good practice to indent the nested statements and their clauses. This clearly identifies where the nested statement begins and ends. In the last example of this figure, you can see that C# will execute the nested if statement only if the customer type is R. Otherwise, it executes the outer else clause.

## The syntax of the if-expression statement

```csharp
if (booleanExpression) { statements }
[else if (booleanExpression) { statements }] ...
[else { statements }]
```

## Statements without else if or else clauses

With a single statement

```csharp
if (subtotal >= 100)
  discountPercent = .2m;
```

With a block of statements

```csharp
if (subtotal >= 100)
{
  discountPercent = .2m;
  status = "Bulk rate"
}
```

## An if statement with an else clause

```csharp
if (subtotal >= 100)
  discountPercent = .2m
else
  discountPercent = .1m;
```

## An if statement with else if and else clauses

```csharp
if (subtotal >= 100 && subtotal < 200)
  discountPercent = .2m
else if (subtotal >= 200 && subtotal < 300)
  discountPercent = .3m
else if (subtotal >= 300)
  discountPercent = .4m
else
  discountPercent = .1m;
```

## Nested if statements

```csharp
if (customerType == "R")
{
  if (subtotal >= 100)
    discountPercent = .2m
  else
    discountPercent = .1m
}
else
  customerType isn't "R"
{
  discountPercent = .4m
}
```

## Description

- An if-else statement, or just statement, always contains an if clause. In addition, it can contain one or more else clauses and a final else clause.
- If a clause requires just one statement, you don't have to enclose the statement in braces. You can just end the clause with a semicolon.
- If a clause requires more than one statement, you enclose the block of statements in braces.

When you use a switch statement, you can code statements within the cases. You can also code switch statements within the cases of another switch statement. That can make switch statements more useful. Generally, programmers prefer to use if-else statements instead of switch statements because if-else statements aren't limited.

## The syntax of the switch statement

```csharp
switch (switchExpression) {
  case constantExpression:
    statements
    break;
  [case constantExpression:
    statements
    break];...
  default:
    statements
    break;
}
```

## A switch statement with a default label

```csharp
switch (customerType) {
  case "R":
    discountPercent = .1m;
    break;
  case "C":
    discountPercent = .2m;
    break;
  default:
    discountPercent = .0m;
    break;
}
```

## A switch statement that falls through the first label

```csharp
switch (customerType) {
  case "R":
  case "C":
    discountPercent = .2m;
    break;
  case "T":
    discountPercent = .4m;
    break;
}
```

## Description

- A switch statement begins evaluating its switch expression. This expression must evaluate to a string, char, byte, sbyte, short, ushort, int, uint, long, long, or bool type.
- After evaluating the switch expression, the switch statement transfers control to the appropriate case label. If control isn't transferred to one of the case labels, the optional default label is executed.
- The break statement exits the switch statement. If a label contains one or more statements, the label must end with a break statement.
