## An introduction to the System.IO classes

The System.IO namespace provides a variety of classes for working with files and for managing directories, files, and paths. You will be introduced to those classes in the topics that follow. In addition, you'll learn about the types of files and streams supported by the System.IO classes and how they're used to perform I/O.

## System.IO classes used to work with drives and directories

| Class | Description |
| --- | --- |
| Directory | Used to create, edit, delete, or get information on directories (folders). |
| File | Used to create, edit, delete, or get information on files. |
| Path | Used to create, edit, delete, or get information on files. |

### Common methods of Directory class

| Method | Description |
| --- | --- |
| Exists(path) | Returns a boolean indicating whether the directory exists. |
| CreateDirectory(path) | Creates the directory. |
| Delete(path) | Deletes the directory. |
| Delete(path, recursive) | Deletes the directory, if specified. |

### Common methods of File class

| Method | Description |
| --- | --- |
| Exists(path) | Returns a boolean indicating whether the file exists. |
| Delete(path) | Deletes the file. |
| Copy(source, dest) | Copies the file from source to destination. |
| Move(source, dest) | Moves the file from source to destination. |

### A statement that works with a text file

```csharp
using System.IO;

string path = @"C:\Products.txt";
if (File.Exists(path))
{
    File.Delete(path);
}
```

### Code that uses some of the Directory methods

```csharp
string path = @"C:\Products";
if (!Directory.Exists(path))
{
    Directory.CreateDirectory(path);
}
```

### Code that uses some of the File methods

```csharp
string path = @"C:\Products.txt";
if (File.Exists(path))
{
    File.Delete(path);
}
```

## How files and streams work

When you use the System.IO classes to do I/O, you can use two different kinds of files: text files or binary files. To illustrate, figure 21-2 shows the contents of a text file and a binary file as they look in a text editor. Although both of files contain the same data, they look quite different.

In a text file, all of the data is stored as characters. Often, the fields in this type of file are separated by tabs or pipe characters, and the records are separated by line characters. Although you can't see the line characters in this file, you know record starts at a new line.

In contrast, a binary file can include text characters as well as data types. Because of that, the data isn't always displayed properly within a text editor. For example, you can't tell what the value of Price is in each of these records because Price has a decimal data type. Also, since the records in a binary file do not end with line characters, record isn't displayed on line.

To handle I/O operations with text and binary files, the .NET Framework uses streams. You can think of a stream as the flow of data from one location to another. For instance, an output stream can flow from the internal memory of an application to a disk file, and an input stream can flow from a disk to internal memory. When you work with a text file, you use a text stream. When you work with a binary file, you use a binary stream.

To work with streams and files using the System.IO namespace, you use the classes summarized in this figure. To create a stream that connects to a file, for example, use the FileStream class. Then, to read data from a text stream, you use the StreamReader class. And to read data from a binary stream, you use the BinaryReader class. You'll learn how to use all of these classes later in this chapter.
