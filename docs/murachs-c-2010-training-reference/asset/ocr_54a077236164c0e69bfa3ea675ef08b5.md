# # How to implement the IEnumerable<> interface

The foreach loop only works on generic collections that implement the IEnumerable<> interface. As a result, if you want to use the foreach loop on a generic collection that you've defined, you must implement the IEnumerable<> interface. For example, to be able to use a foreach loop on the generic collection defined by the CustomList<> class presented in this chapter, you must implement the IEnumerable<> interface for this class as shown in figure 15-11.

In C# 2002 and 2003, allowing a foreach loop to iterate a custom collection was a confusing undertaking that involved writing a fair amount of code at the end of it to implement both the Enumerator and IEnumerable interfaces. Frankly, C# 2005 introduced a simpler way to implement an enumerator that only involves writing a few lines of code.

To start, you can generate the method stubs for the GetEnumerator method for both the regular IEnumerable interface and the generic IEnumerable<> interface. This generates method stubs for both. However, you only need to implement the GetEnumerator method for the generic IEnumerable<> interface.

The easiest way to do that is to code a foreach loop that loops through each item in the list. Then, you can use the yield keyword together with the return keyword to return the current item to the enumerator object and yield control.

In this figure, the enumerator object is the CustomList<Product> object named list. At the end of the figure, the enumerator object (the list) returns a Product object and yields control to the foreach loop. This allows the foreach loop to call the ToString method of the Product object before yielding control back to the enumerator object. In short, this allows the two loops shown in this figure to be synchronized.
