# Combo box properties for binding

| Property | Description |
| --- | --- |
| DataSource | The name of the data table that contains the data displayed in the list. |
| DisplayMember | The name of the data column whose is displayed in the list. |
| ValueMember | The name of the column value is stored in the list. This is returned by the SelectValue property of the control. |
| SelectedValue | Gets the value of the currently selected item. You can use this property to bind the ValueMember property to a column in another data source. |

# Description

+   - To access the most common properties for a combo box, you can display the smart tag for the combo box and use the Use Data Bound Items check box. This will display the properties above.
- To set the DataSource property, display the drop-down list; expand the Data Sources node, the Project Data Sources node, and the node for the dataset; and select the table you want to use as the data source. This adds DataSource and Table objects to the form. Then, you can use the DisplayMember and ValueMember properties to this table.
- The SelectedValue property is typically bound to a column in the main table. That way, if you select a different item from the combo box, the value of this column is set to the value of the ValueMember property for the selected item.
- When you bind a combo box to a data source, you'll typically use the DropStyle property of the combo box to DropList so the user can only select a value from the list. You'll also want to change the (DataBindings)- Text property to None to remove the binding from the text portion of the combo box.
