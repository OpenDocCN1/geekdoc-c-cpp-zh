# What the downloadable files for this book contain

+   - All of the applications presented in this book
- The starting points for all of the exercises in this book
- The solutions for all of the exercises in this book
- The data files and database for the applications and exercises

# How to download and install the files for this book C# 2010.

+   - Go to www.murach.com, and go to the page for Murach's C#
- Click the link for "FREE download of the book applications.\ Then, select the "All book files" and respond to the resulting pages and dialog boxes. This will download a setup file named cs10_allfiles.exe onto your hard drive.
- Use Windows Explorer to find the setup file on your hard drive. Then, double-click this file and respond to the dialog boxes that follow. This installs the files in directories that start with C:\Murach\C#2010

# How your system is prepared for doing the exercises

+   - Some of the exercises you have start from existing projects. The source code for these projects is in the C:\Murach\C#2010Exercise Starts directory. After the setup file installs the files in the downloads, it runs a batch file exercise_starts_setup.bat that copies all of the subdirectories of the Exercise Starts directory to the C:\C# 2010 directory. Then, you can find all of the starting points for the exercises in directories like C:\C# 2010Chapter 01 and C:\C# 2010Chapter 04.

# How to view the source code for the applications

+   - The source code for the applications presented in this book can be found in the C:\Murach\C#2010Book Applications directory. You can view this source code by opening the project or solution in the appropriate directory.

# How to view the solutions to the exercises

+   - The exercise solutions can be found in the C:\Murach\C#2010Exercise Solutions directory. You can view these applications by opening the project or solution in the appropriate directory.

# How to prepare your system for using the database

+   - To use the database that comes with this on your PC, you need to make sure that SQL Server 2008 Express is installed as described in figure A-3. Then, you need to run the batch file to create the database and attach it to SQL Server Express as described in figure A-4.
