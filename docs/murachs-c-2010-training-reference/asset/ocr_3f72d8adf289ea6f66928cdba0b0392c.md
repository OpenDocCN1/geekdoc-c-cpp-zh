# # How to get started with Visual Studio

This chapter gets you started with Visual Studio 2010 by introducing the .NET Framework, the languages that work with the .NET Framework, and the Visual Studio development environment. It also provides a quick tour of this development environment environment. Along the way, you'll learn all of the concepts and terms that you need for developing .NET applications.
