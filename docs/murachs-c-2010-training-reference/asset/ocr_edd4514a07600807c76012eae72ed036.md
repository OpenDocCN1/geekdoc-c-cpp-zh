# syntax for creating a structure

```
public struct StructureName {
    structure members...
}
```

# A Product structure

```
public struct Product {
    public string Code;
    public string Description;
    public decimal Price;

public Product(string code, string description, decimal price) {
        this.Code = code; // If you code a constructor
        this.Description = description; // you must initialize
        this.Price = price; // all instance variables
}

public string GetDisplayText(string sep) {
    return Code + sep + Price.ToString("c") + sep + Description;
}
```

Code declares a variable as a structure type and assigns values to it

```
Product p;
p.Code = "CS10"; // Create an instance of the Product
p.Description = "Murach's C# 2010"; // Assign values to each instance variable
p.Price = 54.50m;
string msg = p.GetDisplayText("\n"); // Call method
```

# Code that uses the structure's constructor

```
Product p = new Product("CS10", "Murach's C# 2010", 54.50m);
```

# Description

+   - A structure is similar to a class, but it represents a value type, not a reference.
- A structure can contain the same types of members as a class, including fields, properties, methods, and events. You can't use auto-implemented properties with structures.
- When you declare a structure, you can't code an empty constructor. When you declare a structure, automatically uses this constructor to initialize itself. As a result, you only need to use the new keyword to create an instance of a structure when you're passing values to a constructor that accepts parameters.
- You can not call any of the properties or methods of a structure until you initialize all of the instance variables of the structure.
- Unlike classes, structures cannot be inherited by other classes. For more information about how inheritance works, please see chapter 14.
