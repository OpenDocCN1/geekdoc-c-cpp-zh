# Visual Studio and the .NET programming languages

In this book, you're going to learn how to use Visual Studio 2010 to develop Windows Forms applications. In the first table in figure 1-2, you can see that Visual Studio 2010 is available in four different editions, ranging from the free Express Edition to the expensive Ultimate.

With the last three editions in this table, you get all four of the .NET programming languages shown in the second table. In this book, of course, you'll learn how to use C# 2010 (pronounced “Visual C sharp”) to develop your applications. This version of C# builds on the versions that were included with Visual Studio .NET 2002, 2003, 2005, and 2008.

In contrast, each Express Edition of Visual Studio provides only one language. To develop applications with C#, then, you need to get the Visual C# 2010 Express Edition. As you will see, you can use this edition to do almost everything that's presented in in this book, and we'll point out any limitations whenever they occur.

The three other languages that come with Visual Studio 2010 are Visual Basic, C++, and F#. Visual C# is a language that can be used for rapid application development. In contrast, Visual C++ is Microsoft's version of the C++ language. Visual F# is a new language that provides functional programming in addition to object-oriented and procedural programming.

Although the four languages shown in this figure are the only languages that come with Visual Studio, it's possible for other vendors to develop languages for the .NET Framework. For example, Micro Focus has developed a version of COBOL for the .NET Framework.

Regardless of the language that's used, Visual Studio 2010 provides an Integrated Development Environment (IDE) that can be used for application development. Visual Studio also includes the .NET Framework (pronounced “dot net framework”) that defines the environment that executes Visual C# applications. You'll learn more about both you as you progress through this chapter.

All the Express editions of Visual Studio also include SQL Server 2008 Express. Otherwise, you can download SQL Server Express from the Microsoft web site for free. SQL Server Express is a lightweight version of the Microsoft SQL Server 2008 database management system, and it's ideal for testing database applications on your own PC.
