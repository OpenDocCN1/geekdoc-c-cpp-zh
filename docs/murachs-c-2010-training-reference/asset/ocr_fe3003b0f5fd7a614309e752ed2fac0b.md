# How to save a connection string in the app.config file

After you select or create a data connection, the fourth step of the Data Source Configuration Wizard is displayed. This step, shown in figure 18-5, asks whether you want to save the connection string in the application configuration file (app.config). In most cases, that's what you'll want to do. Then, any table adapter that uses the connection can refer to the connection string by name. That way, if the connection information changes, you you only need to change it in the app.config file. Otherwise, the connection string is stored in each table adapter that uses the connection, and you'll have to change each table adapter if the connection information changes.

This figure also shows how the connection string is stored in the app.config file. Although this file contains XML data, you should be able to understand it even if you don't know XML. Here, for example, you can see that the connectionStrings element contains an add element that contains three attributes. The first attribute, name, specifies the name of the connection string, in this case, MMABooksConnectionString. The second attribute, connectionString, contains the actual connection string. And the third attribute, providerName, identifies the data provider, in this case, SqlClient.
