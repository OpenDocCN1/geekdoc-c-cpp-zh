

## 第 25 章 如何部署应用程序

### 在 Visual Studio 中显示的 Setup 项目

![](img/3148667e42d4db35b3d08576aaa1fa01_792_0.png)

## 描述

- 当我们首次创建 Setup 项目时，会显示“文件系统编辑器”（File System Editor）。你可以使用此编辑器向 Setup 项目中添加文件。
- 若要将项目输出（作为应用程序的 exe 文件）添加到 Setup 项目中，请在文件系统窗口中右键点击相应的文件夹，选择“添加→项目输出”（Add→Project Output）命令显示“添加项目输出”对话框。然后，选择你想要添加的输出并点击确定。
- 若要向 Setup 项目添加其他文件（例如 Read 文件或数据库文件），请在文件系统窗口中右键点击文件夹，选择“添加→文件”（Add→File）命令，然后定位并选择该文件。
- 若要在应用程序安装时向用户的桌面或开始菜单添加应用程序快捷方式，请右键点击“主输出”（Primary Output）项并选择“创建快捷方式”（Create Shortcut）命令。然后，为快捷方式命名并将其移动到“用户桌面”或“用户程序”文件夹。
- 除了文件系统编辑器外，Visual Studio 还提供了五个编辑器供你自定义 Setup 项目。要显示这些编辑器，请在解决方案管理器中选择 Setup 项目，然后使用解决方案顶部的按钮。有关这些编辑器的更多信息，请参见图 25-10。

## 完成 Setup 项目

除了文件系统编辑器外，还有五个编辑器可用于处理 Setup 项目。当你在解决方案管理器中选择 Setup 项目时，可以使用顶部的按钮显示这些编辑器。这些编辑器提供了多种自定义 Setup 项目的功能，详见第 25-10。例如，你可以使用“注册表编辑器”（Registry Editor）指定要添加到用户计算机的键和值。你可以使用“文件类型编辑器”（File Types Editor）建立应用程序与文件之间的关联。

用户界面编辑器（User Interface Editor）允许你自定义运行 Setup 项目时显示的对话框。例如，你可以更改任何对话框的 Banner 属性，以便在对话框中显示公司标志。你还可以更改对话框中显示的文本，并在 Setup 项目的对话框中添加自己的对话框。

自定义操作编辑器（Custom Actions Editor）允许你指定在安装、提交或卸载阶段在计算机上执行的操作。Visual Studio 提供了五个定义的操作：事件日志（Event Log）、消息队列（Message Queue）、性能计数器（Performance Counter）和服务（Service）。此外，你可以通过开发程序或组件来创建自定义操作。注意，自定义操作可能很难开发。最后，“启动条件”（Launch Conditions）允许你在安装应用程序之前设置必须条件。例如，你可以使用启动条件检查操作系统版本或计算机上是否存在特定文件。如果不符合条件，Setup 程序将终止安装。

除了编辑器外，你还可以设置 Setup 项目的属性。在这些属性中，制造商（Manufacturer）和产品名称（ProductName）是最重要的，因为它们用于构建默认安装文件夹。如果你想安装应用程序的另一个版本，还需要更改要安装的应用程序的版本。为此，请显示项目属性并输入新版本。

当你完成 Setup 项目时，它会生成用于安装应用程序的文件。这一个包含应用程序及所需文件和信息的 Setup.msi 文件，以及用户可以执行的 Setup.exe 文件。默认情况下，Setup 项目的 msi 和 exe 文件存储在项目目录下的 Release 目录。如果你需要，可以从项目的属性对话框更改路径。

## 用于自定义 Setup 项目的编辑器

| 编辑器 | 描述 |
| :--- | :--- |
| 文件系统编辑器 | 允许指定要包含在 Setup 项目中的输出、文件和其他项目，以及它们在目标计算机上的安装位置。更多信息见图 25-9。 |
| 注册表编辑器 | 允许指定添加到目标计算机注册表的键和值。 |
| 文件类型编辑器 | 允许指定应用程序安装到目标计算机时关联的文件类型和文件扩展名。 |
| 用户界面编辑器 | 允许自定义运行 Setup 程序时显示的对话框。 |
| 自定义操作编辑器 | 允许指定在安装各个阶段结束后目标计算机上执行的附加操作。 |
| 启动条件编辑器 | 允许指定安装应用程序之前必须满足的条件。 |

## Setup 项目的常用属性

| 属性 | 描述 |
| :--- | :--- |
| Manufacturer | 应用程序制造商名称。该属性作为默认安装路径的一部分。 |
| ProductName | 产品名称。该属性用于 Setup 程序显示的对话框以及作为默认安装路径的一部分。 |
| ProductCode | 应用程序的唯一标识符，应用程序的每个版本都应有所不同。 |
| Version | Setup 程序的版本号。如果你更改此属性，也应更改 ProductCode 属性。 |
| RemovePreviousVersions | 决定在安装当前版本之前移除哪些之前的应用程序。 |

## 描述

- Manufacturer 和 ProductName 属性也会显示在“卸载”或“更改程序”窗口（Windows 7 和 Windows Vista）或“添加或删除程序”窗口提供的“支持信息”对话框中（Windows XP）。上述其他属性为此窗口和对话框提供了信息。
- 要生成 Setup 项目，在标准工具栏的配置组合框中选择 Release ，在解决方案管理器中选择项目，并选择“生成项目”命令。这将创建一个 Windows 安装程序（Setup.msi），其中包含任何部署文件、应用程序信息和安装说明，以及一个可用于运行安装程序的 Setup.exe 文件。
- 默认情况下，Setup 项目的 msi 和 exe 文件存储在项目目录的 Release 目录中。要将这些文件存储在另一个目录，请在解决方案管理器中选择项目，选择“项目→属性”命令，并在“输出文件名”中设置路径。

## 如何使用 Setup 程序安装应用程序

当用户双击 Setup 程序的 exe 文件时，会显示一个如图 25-11 所示的标准 Setup 设置向导。如果你以前安装过 Windows 应用程序，你应该已经熟悉这种向导了。虽然此图只显示了设置的前两个步骤，但这两个是最重要的步骤。

第一步显示默认的欢迎消息和默认的版权警告。如果你想更改其中任何一个的文本，可以使用用户界面编辑器。此外，Setup 项目的 ProductName 属性显示在向导的标题栏中。如果你想更改它，可以更改 Setup 项目的 ProductName 属性。

第二步显示应用程序的默认安装文件夹。正如我之前提到的，这只是建议的文件夹，因此用户可以选择另一个文件夹。

在用户完成这些步骤后，接下来的三个步骤允许用户确认安装、显示安装进度并在安装完成后显示消息。虽然此图中没有显示这些步骤，但你曾在安装其他 Windows 应用程序时可能见过这些步骤。如有必要，你可以使用用户界面编辑器控制这些步骤的外观。或者，你可以使用此编辑器添加步骤，例如显示许可协议的步骤或注册用户的步骤。
