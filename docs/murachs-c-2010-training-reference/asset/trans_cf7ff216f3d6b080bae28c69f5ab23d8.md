# 如何从网页安装应用程序

一旦发布了应用程序，用户就可以通过在浏览器中生成的网页来安装它。例如，图 25-7 显示了为之前几个图中看到的应用程序生成的网页。要从该网页安装应用程序，用户只需点击“安装 (Install)”按钮即可。

取决于您在发布应用程序之前选择的选项，生成的网页外观可能与此处显示的不同。例如，如果应用程序仅在线可用，则页面将包含一个“运行 (Run)”按钮而不是“安装”按钮。如果需要 .NET Framework 和 Windows 安装程序之外的先决条件，页面将列出所有先决条件。此外，它还会包含一个链接，如果用户确定所需的组件已安装在计算机上，可以让用户跳过先决条件。

当用户安装或运行应用程序时，会显示启动应用程序 (Launching Application)对话框。然后，如果应用程序不是来自受信任源，会显示带有安全警告的对话框。在发布应用程序的最终版本之前，您可能希望为应用程序的发布者安装有效证书来消除此警告。如果应用程序发布到内网上的服务器，您可能可以使用 Windows Server 2008 自带的 Microsoft 证书服务创建自己的证书。如果应用程序发布到互联网上的服务器，您将需要从 VeriSign 等认证机构获取证书。有关认证机构的更多信息，您可以在互联网上搜索“认证机构 (certification authorities)”和“签名证书 (code signing certificate)”。

# 如何更新应用程序

图 25-7 还显示了用户运行使用 ClickOnce 部署的应用程序且可用更新时显示的对话框。通过此对话框，用户可以点击“确定 (OK)”按钮安装更新，或点击“跳过 (Skip)”按钮跳过安装。注意，如果应用程序的更新选项指定了最低所需版本，而用户未安装该版本，则不会显示可用更新 (Update Available)对话框。相反，更新将自动安装。

# 如何创建和使用 Setup 程序

如果 XCopy 或 ClickOnce 部署对于您的应用程序并不足够，您可以创建一个 Setup 项目，该项目会创建一个用户可以运行以安装应用程序的 Setup 程序。这种方法可以用于安装除最复杂应用程序以外的所有应用程序。然而，创建 Setup 程序本身可能是一个复杂的过程，且不同应用程序之间差异很大。因此，接下来的主题旨在让您对如何创建 Setup 程序有一个大致的了解。然后，如果有必要，您可以在创建自己的 Setup 程序之前进行一些额外的研究。

# 如何创建 Setup 项目

图 25-8 显示了如何为 Windows 应用程序创建 Setup 项目。要做到这一点，首先要打开包含您想要部署的 Windows 应用程序的项目解决方案。然后使用如图所示的“添加新项目 (Add New Project)”对话框为该解决方案添加应用程序的 Setup 项目。在示例中，我正在向包含第 7 章 FutureValueSetup 项目的解决方案中添加一个名为 FutureValueSetup 的 Setup 项目。

# Setup 项目的“添加新项目”对话框

![](img/3148667e42d4db35b3d08576aaa1fa01_790_0.png)

## 描述

- 您使用 Setup 项目来创建一个安装 Windows 应用程序的 Setup 程序。Setup 程序是一种用于安装其他 Windows 应用程序的 Windows 应用程序。
- 要创建 Setup 项目，请打开包含要部署的 Windows 应用程序的解决方案，并选择文件 (File)→添加 (Add)→新建项目 (New Project)。然后展开其他项目类型 (Other Project Types)，选择部署 (Deployment)，选择 Setup 模板，为 Setup 输入名称并点击确定。
- 当您创建 Setup 项目时，它会被添加到您想要创建的解决方案中。

## Express 限制

- Visual Studio 2010 Express 版不提供 Setup 项目。

# 如何向 Setup 项目添加输出文件

一旦创建了 Setup 项目，您就可以使用它提供的设置编辑器来自定义项目。首先，您将想要添加任何希望 Setup 程序部署的输出文件。图 25-9 显示了如何进行操作。

要向 Setup 项目添加输出文件，您可以使用如图所示的文件系统编辑器 (File System Editor)。在您创建 Setup 项目时，此编辑器会默认显示。在此编辑器的左窗格中，您可以看到三个文件夹，它们代表应用程序在用户系统上安装的文件夹、包含在用户桌面上显示的项目的文件夹，以及在用户“程序”菜单中显示的项目的文件夹。对于复杂的应用程序，您可以包含特殊文件夹和自定义文件夹。但对于简单的应用程序，您将只使用默认文件夹和您创建的任何子文件夹。

Setup 项目必须包含项目的主要输出，即 Windows 应用程序的 exe 文件。在大多数情况下，您会将此文件添加到应用程序文件夹 (Application Folder)。然后，当您选择此文件夹时，该文件将出现在文件系统编辑器的右窗格中，如图所示。为了将应用程序使用的 Read 文件或数据库文件添加到应用程序文件夹，请右键点击文件夹，选择添加 (Add)→项目输出 (Project Output) 命令并使用项目输出对话框。

您还可以使用添加 (Add) 菜单向 Setup 项目添加文件。例如，您可能想为应用程序添加 Read 文件或数据库文件。要执行操作，请选择文件命令并标识文件。

另一个您将包含 Setup 项目的常用文件是应用程序的快捷方式。当安装应用程序时（例如），您可能希望将快捷方式添加到用户的桌面或程序菜单。要创建快捷方式，请右键点击想要创建快捷方式的文件并选择创建快捷方式 (Create Shortcut) 命令。然后，快捷方式将创建在与其文件相同的文件夹中。此时，您可以为快捷方式赋予适当名称并将其移动到您希望其出现在用户计算机上的文件夹。

例如，假设您希望 Future Value 应用程序的快捷方式出现在用户的“所有程序→Murach”菜单中。要实现这一点，您首先要使用添加 (Add)→文件夹 (Folder) 命令向用户程序菜单文件夹中添加一个名为 Murach 的子文件夹。然后，按照上述说明创建并命名快捷方式，然后将其移动到 Murach 子文件夹中。
