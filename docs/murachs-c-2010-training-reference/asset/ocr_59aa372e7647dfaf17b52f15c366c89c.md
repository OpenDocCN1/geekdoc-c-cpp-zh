# Description

+   - The main Visual Studio workspace contains one or more tabbed windows. To develop a form, you use the Form Designer window (or just Form Designer). To develop code, you use the Code Editor window that's shown in figure 1-9.

+   - To add controls and other items to a form, you use the Toolbox. The Toolbox contains a variety of items organized into categories as Common Controls, Containers, Menus & Toolbars, Data, and so on.

+   - To change the way a form or control looks or operates, use the Properties window. This window displays the properties of the item that's selected in the Form Designer.

+   - You use the Solution Explorer to manage project files. You'll learn more about the Solution Explorer in figure 1-10.

+   - Several toolbars are available from Visual Studio. The Standard toolbar includes Windows toolbar buttons such as Open, Save, Cut, Copy, and Paste, plus other buttons that you'll learn about as you progress through this book.

+   - As you work with Visual Studio, you'll find that other toolbars are displayed, depending on what you're doing.
