# How to set the publish options

The Publish Options dialog box, which is displayed when you click the Options button on the Publish page of the Project Properties window, lets you set a variety of options. These options are divided into four tabs, as you can see in figure 25-6.

In most cases, you'll specify at least a publisher name and the product name on the Description tab. Then, the values you specify determine how the application appears in the user's Start menu. The application shown in this figure, for example, will appear in the Start→All Programs→Mike Murach &amp; Associates, Inc. menu with the name Calculate Future Value. You can also specify a suite name. Then, a subfolder with that name will be created within the folder for the publisher, and the application will appear in that subfolder.

You may also want to specify a support URL and an error URL. If you specify an error occurs during the installation of the application, the URL will be included in the dialog box that displays. If you specify a support URL, it will be installed from the window that works with you the programs that are installed on your system. The window depends on your operating system.

If you're using Windows 7 or Windows Vista, for example, you can access the support information from the Uninstall or Change a Program window. To do that, just select the program from the list's displayed and the URL is displayed at the bottom of the window. If you're using Windows XP, you can access the support information from the Add or Remove Programs window. To do that, select the program and click the link that becomes available to display the Support Info dialog box.

The options on the Deployment tab affect the web page that is generated when you publish an application and that users access to install the application. To start, you must enter the name you want to use in the text box. The name can be anything you want, but it must have an extension of htm or html. You can also specify whether this page is generated each time the application is published or whether it's displayed after the application is published. At the least, you'll want to select these options the first time you publish an application so the initial web page is generated and you can make sure it looks the way you want it to.

By the way, you can modify the web page after it's generated. To do that, just open the page in an HTML editor such as Visual Web Designer and make the appropriate changes. In that case, you'll want to be sure not to regenerate the web page next time the application is published or you'll overwrite your changes.

In most cases, you'll leave the remaining options in the Publish Options dialog box at their default settings. If you publish your application to a CD, however, you may want to select the second last option on the Deployment tab. Then, the installation will start automatically when the CD is inserted. And if you want to create a shortcut on the user's desktop when the application is installed, you can select the last option on the Manifests tab.
