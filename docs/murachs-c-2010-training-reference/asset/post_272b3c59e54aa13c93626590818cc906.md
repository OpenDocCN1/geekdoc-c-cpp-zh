# How to add toolbars to a form

Earlier in this chapter, you learned how to add menu to a form to provide access to the functions of an application. Now, you'll learn how to add a toolbar.
Most of the time, the buttons on a toolbar duplicate the functions provided by the menu system. However, toolbar buttons let users access these functions with a single click.

# How to create a toolbar

To create a toolbar, you add a ToolStrip control to a form. Like the MenuStrip control, this control appears in the Component Designer tray. Then, by default, it is docked at the top of the form below any menus on the form and extends the full width of the form.
Figure 24-8 presents two examples of toolbars. Here, the first toolbar includes the standard toolbar buttons for functions like Save, Print, Cut, and Paste. You can create a toolbar like this using the Insert Items command in the ToolStrip's smart menu. The second toolbar has two custom buttons that let the user display Future Value. To add custom buttons, you can use the Items Collection Editor that is shown in this figure. By default, each button you add to a toolbar displays a graphic. To specify the image for the button, you can use the Image property of the button to display a dialog box that lets you select the image. In this figure, the two buttons in the second toolbar use images that are stored in bmp files, and these bmp files are stored in the same directory. If you are working with graphics, you can create your own. Or you may be able to find images you can use on the Internet.

After you've specified an appropriate image for a button, you need to set the Text property for the button. When you set this property, it automatically sets the ToolTip property which specifies the text displayed when the user places the pointer over the button. This text is known as a tooltip, and it's important because it's often hard for a user to determine the function of a button from the button's image alone. However, if the user points at the first button, it will display a tooltip that says, "Open Future Value," which gives the user a clear idea of what the button does.

By default, the items you add to a toolbar are displayed as push buttons. You can create other types of toolbar items by selecting a different type of item from the combo box at the top of the Items Collection dialog. For example, if you select DropDown from this combo box, you can create a menu that drops down from the button. With a little experimentation, you should be able to use this dialog box to add a variety of controls to a toolbar.

# Description

- To create a toolbar, add a ToolStrip to a form. By default, the toolbar is docked at the top of the form below the menus and reaches across the width of the form.
- To insert the items shown above, select the Insert Items command from the ToolStrip control's smart tag menu.
- To display the Items Collection dialog box for a ToolStrip, select the Edit Items command from the smart tag menu for the ToolStrip. You can use this dialog box to add buttons to the toolbar and set the properties for these buttons.
- To include an image on a button, you can use the Image property for the button to display a dialog box that lets you specify an image file for the button. This dialog box works with modern image files including gif, jpg, bmp, wmf, and png.
- To specify the text that is displayed when the user points to the button with the mouse (called a tooltip), you can enter the text in the Text property for the button. This automatically sets the ToolTip property for the button.

# How to write code that works with toolbars

After you create the toolbars for a form, you need to add the code that makes them work. To do that, you can code event handlers like this in figure 24-9.

The first example handles the Click event of the Future Value button on the toolbar. This event handler uses the PerformClick method of the Future Value menu item. That way, you don't have to duplicate the code that creates and displays the form.

The second example shows or hides a toolbar. In this case, a View menu has been added to the main menu, and this menu contains a single menu item named mnuToolbar. Each time you click on a menu item like this, a checked item is displayed. Each uses a check mark to indicate whether the toolbar should be unchecked and vice versa, and the toolbar, which is named lblMain, should be hidden or displayed accordingly.

The code for the Click event of this menu item uses the Checked property of the menu item to determine if the toolbar is currently displayed. If it is, this sets the Visible property of the toolbar to false so it's hidden. Conversely, if the Checked property of the menu item is false, it's set to true so a check mark is displayed, and the Visible property of the toolbar is true so the toolbar is displayed.

Another way to code this handler is like this:

```csharp
mnuToolbar.Checked = !mnuToolbar.Checked;
lblMain.Visible = !lblMain.Visible;
```

Here, the Not operator (!) is used to reverse the values of the menu item's Checked property and the toolbar's Visible property. Although this code isn't as easy to follow as the code in this figure, this type of code is commonly used.

# Code that shows or hides a toolbar depending on a menu selection

```csharp
private void mnuToolbar_Click(object sender, System.EventArgs e)
{
    if (mnuToolbar.Checked == true)
    {
        mnuToolbar.Checked = false;
        lblMain.Visible = false;
    }
    else if (mnuToolbar.Checked == false)
    {
        mnuToolbar.Checked = true;
        lblMain.Visible = true;
    }
}
```

# Description

- You use the Click event of a button in a toolbar to respond to the user clicking on that button.
- You can use the Checked property of a menu item to work with the check mark that's displayed to the left of the item.
- You can use the Visible property of a control to show or hide the control.
