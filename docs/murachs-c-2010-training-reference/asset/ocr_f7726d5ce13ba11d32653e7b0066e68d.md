# Description

+   - The Customer Name combo box in the Customer form lets the user select a customer.
- The Select Payment button in the Customer form displays the Payment dialog box, which lets the user specify payment information for the customers.
- If the Credit Card option is selected, the user must select a credit card type, enter a card number, and select an expiration month and year.
- If the Bill Customer option is selected, the Credit Card Type, Card Number, and Expiration Date controls are disabled.
- When the user clicks the OK button on the Payment form, control returns to the Customer form and the payment information is displayed in the Payment Method label.

# Note

+   - This application doesn't actually save the data enters. In a production application, however, the data would be saved to a database or file.
