# Introduction

C# is elegant, object-oriented language that uses syntax that's similar to C++ and Java. As a result, it provides an easy migration path for C++ and Java developers who want to leverage the power of the .NET Framework. In addition, C# provides an opportunity for Visual Basic developers to learn a powerful language that's in the C# family without leaving the comfort of the Visual Studio environment.

Murach's C# 2010 is an updated edition of Murach's C# 2008, a book that helped thousands of programmers learn the C# language. This 2010 edition carefully integrates new features like optional parameters, named arguments, and code stubs with the features presented in the 2008 edition of the book. The result is a book that helps you learn as quickly and as easily as possible.

# Who this book is for

This book is for anyone who wants to learn how to use C# 2010 for developing Windows Forms applications using Visual Studio 2010 and the .NET Framework. It includes the entire range of developers from beginners to experienced Java, C++, and Visual Basic programmers.

To make that possible, this book uses a unique, topic-based approach that lets you set your own pace. For example, section 1 guides you through the basics of using the Visual Studio IDE and C# 2010. Whether you're a Java or C++ programmer or a complete beginner, you can get up speed quickly with this development environment by reading this section and doing the exercises at the end of each chapter. If you're a Visual Basic programmer who is already comfortable with Visual Studio, you can skim this section to learn just the new VS 2010 features that it presents.

Sections 2 and 3 use the same approach to teach the skills that you need to be productive with the C# language. If you're familiar with the language in the C# family, such as Java, you should be able to move through this section quickly, focusing on the classes and methods that are available from the .NET Framework. Conversely, if you're already familiar with .NET, you can focus on the details of the C# syntax. Either way, you're going to learn C# at a pace that's right for you.
