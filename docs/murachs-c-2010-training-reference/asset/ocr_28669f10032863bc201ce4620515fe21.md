# The beginning of the script for creating the MMABooks database

# Description

+   - To create the MMABooks database, you can use Windows Explorer to navigate to the C:\Murach\2010\folder and double-click the create_database.bat file. This runs the create_database.sql file that creates the database objects and inserts the rows into each table.

+   - The create_database.sql file starts deleting the MMABooks database if it already exists. That, you can use it to recreate the database and restore the original data if you ever need to do that.

+   - When you create the MMABooks database, two files named MMABooks.mdf and MMABooks_log.ldf are created and stored in the default data directory for your instance of SQL Server. For SQL Server 2008, for example, that directory is C:\Program files\Microsoft SQL Server\MSSQL2\MSSQL\DATA.
