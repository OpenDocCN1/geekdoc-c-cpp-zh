# Description

+   - The Code Editor window (or just Code Editor) is where you create and edit the C# code that your application requires. The Code Editor works like any other text editor, so you shouldn't have much trouble learning how to use it.
- You can display the Code Editor by double-clicking the form or any of the controls in the Form Designer window. Or, you can select the form in the Solution Explorer and click the View Code button.
- Once you've opened the Code Editor, you can return to the Form Designer by clicking the [Design] tab or the View Designer button in the Solution Explorer (to the right of the View Code button). You can also move among these windows by pressing Ctrl+Tab or Shift+Ctrl+Tab, by selecting the form from the Active Files dropdown list that's available to the right of the tabs.
- It's important to realize that the Form Designer and the Code Editor give you two views of the form. The Form Designer gives you a visual representation of the form. The Code Editor shows the C# code that makes the form work the way you want it to.
