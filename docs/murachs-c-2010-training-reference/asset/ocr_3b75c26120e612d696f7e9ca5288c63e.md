# How to read a binary file

Figure 21-9 shows how to use the BinaryReader class to read data from a binary file. Like the BinaryWriter class, the argument that you pass to the BinaryReader is the name of the FileStream object that connects the stream to a file.

In a binary file, there's no termination character to indicate where one record ends and another begins. Because of that, you can't read an entire record at once. Instead, you have to read one character or one field at a time. To do that, you use the methods of the BinaryReader class that are shown in this figure. When you do, you must use the appropriate method for the data type of the field that you want to read. To read a Boolean field, for example, you use the ReadBoolean method. To read a Decimal field, you use the ReadDecimal method.

The BinaryReader class provides methods to read most of the data types provided by the .NET Framework. However, this figure shows only the most common of these methods. For a complete list of methods, see the online help information for the BinaryReader class.

Before you read the next character or field, you want to be sure that you are not at the end of the file. To do that, you use the PeekChar method. Then, if there's at least one character to read, this method returns that character without advancing the cursor to the next position. If there isn't another character, the PeekChar method returns a value of -1. Then you can use the Close method to close the binary reader and the associated file stream.

The example shows how you can use some of these methods. Here, a FileStream argument for the file stream specifies OpenOrCreate, this opens an existing file if one exists or creates a new file that is empty and opens it. Then, a new BinaryReader object is created for file stream. Finally, the while loop is executed until the PeekChar method returns a value of -1, which means the end of the file has been reached.

Within the while loop, the three fields in each record are read and assigned to the properties of the Product object. Because the first two fields in each record contain string data, the ReadString method is used to retrieve their contents. The third field contains decimal data, the ReadDecimal method is used to retrieve its contents. Then, the Product object is added to the List< > collection. When the loop ends, the Close method of the BinaryReader object is used to close both the BinaryReader and the FileStream objects.
