# Description

+   - You can display a list of the open child forms in a menu by setting the MdiWindowListListItem property of the menu strip to the name of the menu. A list like this is typically displayed in the Window menu.

+   - In this example, the Action menu is stored in the child form. This menu appears in the parent form when a child form that contains it is the active form.
