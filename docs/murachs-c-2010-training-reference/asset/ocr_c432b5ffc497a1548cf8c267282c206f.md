# Chapter 14  How to work with inheritance  441

# The code for the Software class

```
public class Software : Product
{
    private string version;

    public Software()
    {
    }

    public Software(string code, string description, string version,
        decimal price) : base(code, description, price)
    {
        this.Version = version;
    }

    public string Version
    {
        get
        {
            return version;
        }
        set
        {
            version = value;
        }
    }

    public override string GetDisplayText(string sep)
    {
        return base.GetDisplayText(sep) + " " + Version + " " + Version;
    }
}
```

# Description

+   - The Software class inherits the Product class. It adds a property named Version and overrides the GetDisplayText method.
