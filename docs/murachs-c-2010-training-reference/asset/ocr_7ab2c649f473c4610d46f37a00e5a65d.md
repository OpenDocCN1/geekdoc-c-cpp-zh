# How to get help information

As you develop applications in C#, it's likely that you'll need some additional information about the IDE, the C# language, an object, property, method, or event, or some other aspect of C# programming. Figure 3-14 shows how to use the Microsoft Help Viewer to get that information.

When you're in the Code Editor or the Form Designer, the quickest way to get help information is to press F1 while the insertion point is in a keyword or an object is selected. Then, Visual Studio opens the Help Viewer in your default browser and displays the available information about the selected keyword or object. Another way to display the Help Viewer is to select the Help command from Visual Studio's Help menu. Then, you can use the full-text search feature or the table of contents that is available from the left pane of the Help Viewer to locate and display the information you need.

To display the topic shown in this figure, for example, entered "code editor" into the Search text box and then pressed the Enter key. When I did that, a list of topics that the search text was displayed in the Help Viewer. Then, I clicked on the link for the "Code and Text Editor" to display the information shown here.

The table of contents that's displayed in the left pane of the Help Viewer includes ancestors of the current topic and the current topic and its peers. In addition, the peers of the current topic's parent are displayed under Related Links. You can click on any of these topics to display the information for that topic in the right pane.

Note that because the help information is displayed in your web browser, you can work with it just as you would any other web page. For example, you can click on a hyperlink in the current topic. To move forward and backward through previously displayed topics, you can use the Forward and Back buttons. As a result, with a little practice, you shouldn't have much trouble using the Help Viewer.

In addition to the Help Viewer, you can use the Help Library Manager to manage your help content. For example, if you initially choose to use online help and then decide you want to use local help, you can use the Help Library Manager to install help locally and change the setting to use local help. In contrast, if you initially install help locally, you can use the Help Library Manager to remove local help and change the setting to use online help. To display the help you want to use online help, you can use the Help Library Manager, you choose the Manage Help Settings command from Visual Studio's Help menu.

One advantage of using local help is that it's always available even if you don't have access to the Internet. On the other hand, local help may not always be up-to-date like online help. Because of that, you may want to occasionally update your local help. The Help Library Manager lets you do that too.
