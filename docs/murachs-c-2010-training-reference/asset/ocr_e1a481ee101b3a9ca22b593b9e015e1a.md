arrayName.Length

# Code that computes the average of an array of totals

```
decimal[] totals = [14.95m, 12.95m, 11.95m, 9.95m];ndecimal sum = totals[0] + totals[1] + totals[2] + totals[3];ndecimal average = sum/4;
```

# Code that puts the numbers 0 through 9 into an array

```
int[] numbers = new int[10];nfor (int i = 0; i < numbers.Length; i++)
numbers[i] = i;
```


# Code that uses a for loop to compute the average of the totals array

```
decimal sum = 0.0m;nfor (int i = 0; i < totals.Length; i++)
sum += totals[i];ndecimal average = sum/totals.Length;
```
