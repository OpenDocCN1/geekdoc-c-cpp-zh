# ADO.NET objects created using use code

```
string connectionString = "Data Source=localhost\\SqlServer;Initial Catalog=MMABooks;" + "Integrated Security=True";
SqlConnection connection = new SqlConnection(connection);

string selectStatement = "SELECT * FROM Products ORDER BY ProductCode";
SqlCommand selectCommand = new SqlCommand(selectStatement, connection);

SqlDataAdapter productsDataAdapter = new SqlDataAdapter(selectCommand);
DataSet productsDataSet = new DataSet();
```

# Description

+   - You can use the Data Sources window to create a data source. Then, you can drag the data source onto it to automatically generate a table adapter object and a dataset. A table adapter is similar to a data adapter, but it can only be generated by the designer, it has a built-in connection object, and it can contain more than one query. You'll learn how to work with data sources and table adapters in chapter 18.
- To create ADO.NET objects in code, you write a declaration that identifies the class each object is created from. You'll learn how to write code like this in chapter 20.
