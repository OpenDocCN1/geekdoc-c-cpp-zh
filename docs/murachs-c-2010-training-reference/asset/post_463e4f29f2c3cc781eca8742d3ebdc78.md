### The syntax for overloading unary operators

```csharp
public static returnType operator unary-operator(type operand)
```

### The syntax for overloading binary operators

```csharp
public static returnType operator binary-operator(type-1 operand-1, type-2 operand-2)
```

### Common operators you can overload

Unary operators

- + - ! ++ true false

Binary operators

- + - += * % & == == != >= =

### The Equals method of the Object class

| Method | Description |
| :--- | :--- |
| Equals(object) | Returns a Boolean that indicates whether the current object refers to the same instance as the specified object. If that's not what you want, you can override this method as shown in figure 13-9. |
| Equals(object1, object2) | A static version of the Equals method that compares two objects to determine if they refer to the same instance. |

### The GetHashCode method of the Object class

| Method | Description |
| :--- | :--- |
| GetHashCode() | Returns an integer value that's used to identify objects in a hash table. If you override the Equals method, you must also override the GetHashCode method. |

### Description

- You use the operator keyword to overload an operator within a class. For example, you might overload the + operator in the ProductList class so that it can be used to add products to the list. You might also overload the == and != operators in the Product class so you can compare Product objects to see if they contain identical data rather than whether they refer to the same instance.

- You can overload all of the unary and binary operators shown above, as well as others that aren't presented in this book. When you overload a binary operator, operand-1 is the operand that appears to the left of the operator, and operand-2 is the operand that appears to the right of the operator.

- Overloaded operators are always static so they deal with null operands properly.

- When you overload relational operators like == and !=, you need to provide your own versions of the Equals and GetHashCode methods. See figure 13-9 for details.

### Part of a ProductList class that overloads the + operator

```csharp
public class ProductList
{
    private List<Product> products;
    public void Add(Product p)
    {
        products.Add(p);
    }
    public static ProductList operator + (ProductList pl1, Product p)
    {
        pl1.Add(p);
        return pl1;
    }
}
```

### Code that uses the + operator

```csharp
ProductList products = new ProductList();
Product p = new Product(1, "Apple", 0.50);
products = products + p;
```

### How to overload relational operators

Figure 13-9 shows that relational operators are often difficult to overload. Here, the first example shows how to implement the == operator for the Product class so you can compare objects based on values rather than references. The == operator starts by testing the object passed to it, in this case, the second operand of the == operator, for a null. If both operands are null, the == operator returns true. If the first is null but the second isn't, it returns false. If the first operand isn't null, the == operator calls the Equals method of the first operand to compare it with the second operand, and returns the result of the comparison.

```csharp
public override bool Equals(object obj)
{
    if (this == null && obj == null)
        return true;
    if (obj == null)
        return false;
    Product p = (Product)obj;
    return Code == p.Code && Description == p.Description && Price == p.Price;
}
```

Notice that the declaration for the Equals method includes the override keyword. That means it overrides the Equals method defined by the Object class that each class inherits. In the next chapter, you'll learn how to work with inheritance. Then, you'll be able to understand how this works.

When you overload a comparison, you must also overload the operator that performs the opposite operator. If, for example, you overload the == operator, you must also overload the != operator. Similarly, if you overload the < operator, you must also overload the > operator. The code that's used to implement the != operator in the Product class is also shown in this figure. You can see, that operator defines itself in terms of the == operator.

```csharp
public static bool operator != (Product p1, Product p)
{
    return !(p1 == p);
}
```

The last method that's required when you overload the == operator is the GetHashCode method. Like the Equals method, this overrides the GetHashCode method defined by the Object class. The main requirement for the GetHashCode method is that it must always return the same value for any two objects that are considered equal by the Equals method. The easiest way to accomplish this is to combine the values that are used for comparison in the Equals method to create a string, and return the hash code of string.

```csharp
public override int GetHashCode()
{
    return (Code + Description + Price).GetHashCode();
}
```
