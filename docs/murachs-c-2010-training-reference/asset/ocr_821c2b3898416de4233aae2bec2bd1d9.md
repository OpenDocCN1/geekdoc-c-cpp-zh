# Description

+   - The Visual Studio IDE is referred to as Visual Studio, even though that name is also used to refer the entire suite of products, including the .NET Framework.
- Visual Studio supports all four languages presented in figure 1-2.
- Visual Studio includes designers that can be used to develop Windows Forms applications and Web Forms applications.
- Visual Studio includes a code editor that can be used with any of the four languages presented in figure 1-2 as well as HTML and XML.
