# Description

+   - To change the version of the .NET Framework that's used by a project that you convert from an earlier version of C#, select the version you want to use from the Application tab of the Project Properties window for the project.
- To display the Project Properties window, use the Project->Properties command.
- The .NET Framework version you choose determines the features you can use in the project.
