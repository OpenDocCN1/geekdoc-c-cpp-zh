# Chapter 8 How to work with arrays and collections

# The syntax of a foreach loop

```
foreach (type elementName in arrayName)
{
    statements
}
```

# Code that displays the numbers array in a message box

```
string numbersString = ""
foreach (int number in numbers)
{
    numbersString += number + " ";
}\MessageBox.Show(numbersString, "Numbers Test");
```

# Code that computes the average of the totals array

```
decimal sum = 0.0m;
foreach (decimal total in totals)
    sum += total;
decimal average = sum/totals.Length;
```

# Code that displays the totals array in a message box

```
string totalsString = ""
foreach (decimal total in totals)
    totalsString += total + "\n";
MessageBox.Show("The totals are:\n" + 
    totalsString + "\n" + 
    "Sum: " + sum + "\n" + 
    "Average: " + average + "\n" + 
    "Totals Test:*\*");
```
