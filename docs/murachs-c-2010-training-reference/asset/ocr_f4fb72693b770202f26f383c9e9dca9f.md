# Description

+   - To create a toolbar, add a ToolStrip to control a form. By default, the toolbar is docked at the top of the form below the menus and reaches across the width of the form.
- To insert the items shown above, select the Insert Items command from the ToolStrip control's smart tag menu.
- To display the Items Collection Editor dialog box for a ToolStrip, select the Edit Items command from the smart tag menu for the ToolStrip. You can use this dialog box to add buttons to the toolbar and set the properties for these buttons.
- To include an image on a button, you can use the Image property for the button to display a dialog box that lets you specify an image file for the button. This dialog box works with most modern image files including gif, jpg, bmp, wmf, and png.
- To specify the text that is displayed when the user points to the button with the mouse (called a tool tip), you can enter the text in the Text property for the button. This automatically sets the ToolTipText property for the button.
