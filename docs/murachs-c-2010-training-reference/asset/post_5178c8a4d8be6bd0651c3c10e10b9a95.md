
## What software you need for this book

- Any edition of Microsoft Visual Studio 2010 or the Express Edition of Microsoft Visual C# 2010.
- If you want to store databases on your PC, you need to install SQL Server 2008 Express Edition, which is available for free.
- For information about downloading and installing these products, please see appendix A.

## The downloadable files for this book

- All of the applications presented in this book including source code and data.
- Starting points and data for the exercises in this book so you can get more practice in less time.
- Solutions for all of the exercises in this book so you can check your work on the exercises.
- Files for creating the MMABooks database that's used by this book.

## How to download the files for this book

- Go to www.murach.com, and go to the page for Murach's C# 2010.
- Click the link for “FREE download of the book applications.” Then, select the “All book files” link and respond to the resulting pages and dialog boxes. This will download a setup file named cs10_allfiles.exe onto your hard drive.
- Use Windows Explorer to find this exe file on your hard drive. Then, double-click this and respond to the dialog boxes that follow. This installs the files in directories that start with C:\Murach\C# 2010, and runs a batch file that copies the subdirectories to the C:\Murach\C# 2010 directory.

## How to prepare your system for this book

- If you want to use the MMABooks database for this book with a SQL Server 2008 Express database server that's running on your PC, use Windows Explorer to navigate to the C:\Murach\C# 2010\Database directory and double-click on the create_database.bat file.
- For more detailed instructions about preparing your system for this book, please see appendix A.

## Murach's C# 2010 contents

## Get going fast with the C# elements

- Create your first Windows Forms applications using C# 2010, Visual Studio 2010, and .NET Framework 4
- Master C# programming skills, including exception handling, string handling, and every other aspect
- Learn how to write data validation routines to create bulletproof applications
- Discover .NET classes, such as Array, String, StringBuilder, and the typed collections
- Gain the benefits of tracking down elusive coding errors

## Object-oriented programming made clear

- Create fully object-oriented programs, complete with business and data access classes
- Add features to your classes, such as delegates, events, and overloaded operators
- Cut through the mystery of inheritance and polymorphism as you build more sophisticated classes
- Understand and use interfaces, structures, and class libraries
