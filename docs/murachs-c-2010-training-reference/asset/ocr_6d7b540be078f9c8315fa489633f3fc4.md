# Change the way the application gets the invoice data

+   6. Review the code for the Load event handler for the form. Then, you can see that all the rows in the Invoices table are loaded into the dataset when the form is loaded. Then, the rows for a specific CustomerID are displayed in the DataGridView control each time the CustomerID changes. For some applications, that may be okay, but if there are thousands of invoice rows in the dataset that may be inefficient.
