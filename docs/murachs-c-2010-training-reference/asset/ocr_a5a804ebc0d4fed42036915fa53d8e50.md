# Standard DateTime formatting codes

| d | f | Long date, short time |
| D | F | Long date, long time |
| t | g | Short date, short time |
| T | G | Short date, long time |

# Custom DateTime formatting codes

| d | h | Day of the month without leading zeros |
| dd | hh | Day of the month with leading zeros |
| ddd | H | Abbreviated day name / Hour on a 24-hour clock without leading zeros |
| dddd | HH | Full name / Hour on a 24-hour clock with leading zeros |
| M | m | Month without leading zeros |
| MM | mm | Month with leading zeros |
| MMM | s | Abbreviated month name / Seconds without leading zeros |
| MMMM | ss | Seconds leading zeros |
| y | f | Two-digit year without leading zero / Fractions of seconds (one for each decimal place) |
| yy | t | Two-digit year with leading zeros / First character of AM/PM designator |
| yyyy | tt | Four-digit year / Full AM/PM designator |
| / | | Date separator / Time separator |

# Statements that format date and times

```
DateTime currentDate = DateTime.Now; // 1/30/2010 10:37:32 PM
String.Format("{{0:d}", currentDate) // 1/30/2010
String.Format("{{0:D}", currentDate) // Saturday, January 30, 2010
String.Format("{{0:t}", currentDate) // 10:37 PM
String.Format("{{0:T}", currentDate) // 10:37:32 PM
String.Format("{{0:ddd, mmm d, yyyy}", currentDate) // Sat, Jan 30, 2010
String.Format("{{0:M/d/yy}", currentDate) // 1/30/10
String.Format("{{0:HH:mm:ss}", currentDate) // 22:37:32
```
