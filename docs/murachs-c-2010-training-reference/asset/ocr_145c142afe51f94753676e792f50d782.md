# Perspective

Now that you've completed this chapter, you should be able to use the DateTime structure to work with dates and times and the String and StringBuilder classes to work with strings. You should also be able to use the Format method of the String class to provide custom formatting for numbers, dates, and times, although most of the applications that you develop won't require that.
