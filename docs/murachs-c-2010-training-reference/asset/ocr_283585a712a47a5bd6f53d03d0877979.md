# Two versions of the Invoice Total application

To give you a better idea of how you can use data, arithmetic, data conversion, and scope, this chapter concludes by presenting two illustrative applications.

# The basic Invoice Total application

Figure 4–16 presents a simple version of the Invoice Total application that's similar to the one presented in chapter 3. Now that you have learned how to work with data, you should be able to understand all of the code in this application.

To start, this figure shows the user interface for this application, which is the same as it was in the last chapter. Then, this figure lists the six controls that the code refers to so you can see how the code relates to those controls.

This figure also presents the code for the two event handlers of the Invoice Total application. If you study the Click event of the Calculate button, you'll see that it begins by converting the string value that entered by the user to a decimal value. Then, it sets the discount percent to .25, or 25%. The discount is then used to calculate the discount for the invoice, and finally, the calculated values are formatted and displayed on the form.

If rounding is necessary when the values are displayed, the formatting statements will do the rounding. Note, however, that the values stored in discountAmount and invoiceTotal are not rounded. To round these values, you would need to use the Round method of the Math class. You often need to do that when you work with values that are going to be stored in a file or database.

You should also realize that this application will work only if the user enters a numeric value into the Subtotal text box. If the user enters any non-numeric characters, an exception will occur when the application tries to convert that value to a decimal value. In chapter 7, you'll learn how to prevent this type of error.
