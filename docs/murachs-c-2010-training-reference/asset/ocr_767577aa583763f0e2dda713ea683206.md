# Perspective

In this chapter, you learned the basics of reading and writing XML documents using the XmlReader and XmlWriter classes. With these skills, you should be able to incorporate simple XML documents into your applications. You should also have a better appreciation for the way XML is used internally by the database applications that you learned about in section 4.

However, this chapter is only an introduction to XML that omits important features. For example, you can use XML schemas to define the layout for an XML document. Then, you can use .NET classes to make sure an XML document conforms to its schema. You can also use DOM, which stands for Document Object Model, to treat an entire XML document as a single XmlDocument object with property collections that represent the XML document's nodes. In short, there's a lot more to learn before you master XML.
