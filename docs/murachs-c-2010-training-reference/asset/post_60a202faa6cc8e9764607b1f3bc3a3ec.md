
# Two ways to code the select clause

```csharp
select columnExpression
select new [type] { [PropertyName1] = columnExpression1
, [PropertyName2] = columnExpression2]... 
```

# An example that selects keys values from a sorted list

- The employee sorted list
SortedList<string, decimal> employeeSales = new SortedList<string, decimal>();
employeeSales.Add("Anderson", 1286.45m);
employeeSales.Add("Mendezz", 2433.43m);
employeeSales.Add("Thompson", 2893.85m);
employeeSales.Add("Wilkinson", 2094.53m);

# A query expression that selects the employees from the list

```csharp
var employeeList = from sales in employeeSales
where sales.Value > 2000
orderby sales.Value descending
select sales.Key;
```

# Code that executes the query

```csharp
string employeeDisplay = "";
foreach (var employee in employeeList)
    employeeDisplay += employee + "\t\t\n";
MessageBox.Show(employeeDisplay, "Sorted Employees With Sales Over 2000");
```

# A query expression that creates an anonymous type from the list of invoices

```csharp
var invoices = from invoice in invoiceList
where invoice.InvoiceTotal > 150
orderby invoice.CustomerID, invoice.InvoiceTotal descending
select new { invoice.CustomerID, invoice.InvoiceTotal };
```

# Description

- The select clause indicates the data you want to return from each element of the query results.
- A query that returns anything other than that source elements is called a *projection*. Both examples above illustrate projections.
- To return two or more fields from each element, you can code an object initializer within the select clause, an *anonymous type* that contains the specified fields as its properties is created.

# How to join data from two or more data sources

Figure 23-7 shows how you can include data from two or more data sources in a query. To do that, you use the join variable name shown at the top of this figure. To start, this clause declares a reader variable and names a data source just like the clause does. Then, it indicates how the two data sources are related.

To illustrate, the clause in this figure joins data from the list of Invoice objects you've seen in the previous figures with a list of Customer objects. You can see the definition of the Customer class at the beginning of this example, along with the statements that declare and load the two lists. Like the invoice list, the customer list is loaded by calling a method of a database class.

The query expression that follows joins data in these two lists. To do that, it names the invoice list from the clause, and names the customer list on the join clause. Then, on the condition indicates that only customers in the customer list with customer IDs match customer IDs in the invoice list should be included in the results.

Because both the invoice and customer lists are included as data sources in this query expression, the rest of the query can refer to fields in either data source. For example, the orderby clause in this query expression sorts the results by the InvoiceTotal field in the invoice list within the Name field from the customer list. Similarly, the select clause selects the Name field from the customer list and the InvoiceTotal field from the invoice list.

The remaining code in this example executes the query and creates a list that includes the customer names and invoice totals. This is similar to the list you saw in figure 23-5. Because the list in figure 23-7 includes the customer names instead of the customer IDs, however provides more useful information.

Although this figure only shows how to join data from two data sources, for example, suppose you have three data sources named invoiceList, itemItemList, and productList. Then, you could join the data in these lists using code like this:

```csharp
from invoice in invoiceList
  join item in itemItemList
    on invoice.InvoiceID equals item.InvoiceID
  join product in productList
    on item.ProductCode equals product.ProductCode
```

Once the three tables are joined, you can refer to fields from any of these tables in the query expression.

# The basic syntax of the join clause

```csharp
join elementName in collectionName on keyName equals keyName
```

# An example that joins data from two generic lists

The Customer class
```csharp
public class Customer
{
    public int CustomerID { get; set; }
    public string Name { get; set; }
}
```

# Code that gets the two data sources

```csharp
List<Invoice> invoiceList = InvoiceDB.GetInvoices();
List<Customer> customerList = CustomerDB.GetCustomers();
```

# A query expression that joins data from the two data sources

```csharp
var invoices = from invoice in invoiceList
    join customer in customerList
    on invoice.CustomerID equals customer.CustomerID
    where invoice.InvoiceTotal > 150
    orderby customer.Name, invoice.InvoiceTotal descending
    select new { customer.Name, invoice.InvoiceTotal };
```

# Code that executes the query

```csharp
string invoiceDisplay = "Customer Name\tInvoice amount\n";
foreach (var invoice in invoices)
{
    invoiceDisplay += invoice.Name + "\t" + "\t" + "\n";
    invoiceDisplay += invoice.InvoiceTotal.ToString("c") + "\n";
}
MessageBox.Show(invoiceDisplay, "Joined Customer and Invoice Data");
```
