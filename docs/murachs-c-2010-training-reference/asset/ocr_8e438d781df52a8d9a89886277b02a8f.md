# Description

+   - The Call Hierarchy window displays calls to and from methods, properties, and constructors using this. To display this window, use the View→Call Hierarchy command. You can display this window at design-time and at runtime.

+   - To add a method, property, or constructor to the Call Hierarchy, right-click on that member and then choose the View Call Hierarchy command from the menu’s displayed. This also opens the Call Hierarchy window if it isn’t already open.

+   - To display the calls to or from a member, click the ▷ in the tree view pane. To hide the calls click the ◁.

+   - To display the locations of the calls to or from a member in the details pane on the right side of the Call Hierarchy window, click the member in the tree view pane.

+   - To jump to the location of a member in the Code Editor, double-click on it in the tree view pane of the Call Hierarchy window. To jump to the location of a call, double-click on it in the details pane.

+   - To remove a member from the Call Hierarchy, select the root node for that member and then click the Remove Root button at the top of the window.

+   - You use the drop-down list at the top of the Call Hierarchy window to select whether calls in the current document, the current project, or the solution are displayed.
