# How to create a new project

To create a new project, you use the New Project dialog box shown in figure 2-2. This dialog box lets you select the type of project you want to create by choosing one of several templates. To create a Windows Forms application, for example, you select the Windows Forms Application template. Among other things, this template includes references to all of the assemblies that contain the namespaces you're most likely to use as you develop a Windows application.

Note that you can select a template from the Installed Templates category as shown here. You can select a template from the Recent Templates and Online Templates categories. Or you can search for an installed template using the search text box in the right corner of the dialog box.

The New Project dialog box also lets you specify the name for the project, and it lets you identify the folder in which it will be stored. By default, projects are stored in the Visual Studio 2010Projects folder under the My Documents folder, but you can change as shown in the figure.

If you want to change the location that's shown in the New Project dialog box, you can click the Browse button to select a different location; display the Location drop-down list to select a location've used recently; or type a path directly. If you specify a path that doesn't exist, Visual Studio will create the necessary folders for you.

When you click the OK button, Visual Studio automatically creates a new folder for the project using the project name you specify. In the dialog box in this figure, for example, InvoiceTotal is the project name and C:\Project#2010 is the location. By default, Visual Studio creates a new folder for the solution, using the same name as the project. As a result, Visual Studio will create one folder for the solution, and a subfolder for the project. Then, you can add another drop-down list to the same solution by selecting Add To from the Solution drop-down (This list is displayed only if a drop-down is open).

If a project will contain a single solution, you may want to store the project and solution in the same folder. To do that, you can select the Create Directory For check box. Then, the solution is given the same name as the project. In the applications for this book, the project and solution files are typically stored in separate folders when most solutions contain a single project.

Incidentally, the terms folder and directory are used as synonyms throughout this book. With the introduction of Windows 95, Microsoft started referring to directories as folders. But most of the Visual Studio documentation still uses the term directory. That why this book uses whichever seems more appropriate at the time.

By default, the new projects you create .NET Framework 4 so you can use the features it provides. If you use any of these features, however, any computer that you want to run the application on must also have .NET Framework 4. If that's not the case, you can change the target framework using the top of the New Project dialog box. the drop-down list. Then, only the features of the framework you choose will be available from Visual Studio.
