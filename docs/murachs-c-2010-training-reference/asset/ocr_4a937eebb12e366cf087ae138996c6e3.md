# Methods of the Console class that write data to the Output window

| Method | Description |
| --- | --- |
| Write(string) | Displays the value of the specified string. |
| WriteLine(string) | Displays the value of the specified string, followed by a line break. |

# Three statements that write data to the Output window

```
Console.WriteLine("Entering CalculateFuture method...");
Console.WriteLine("month: " + (i+1));
Console.WriteLine("futureValue: " + futureValue);
```

# Code that uses an if statement to control when data is written

```
if ((i+1)%12 == 0) // every 12 months
Console.WriteLine("futureValue: " + futureValue);
```

# Description

+   - You can use the methods of the Console class to write data to the Output window.
This can be useful for tracing execution or for detecting changes in the values of variables.
