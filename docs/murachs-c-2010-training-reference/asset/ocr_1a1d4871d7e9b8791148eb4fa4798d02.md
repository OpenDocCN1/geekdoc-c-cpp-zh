# A Watch window (Debugging) - Microsoft Studio

![](bbox=[0.063, 0.085, 0.903, 0.467])

# Description

+   - The Watch windows let you view the values of watch expressions while an application is in break mode. To display a Watch window, click on its Watch tab. Or, select Debug>Windows>Watch and choose Watch 1, Watch 2, Watch 3, or Watch 4.

+   - To add an expression to a Watch window, click on an empty row in the Name column, type the expression. You can also highlight an expression in the Code Editor and drag it into a watch window.

+   - If an expression is out of scope, it will be dimmed in the Watch window along with a message that says the expression is not valid in the current context.

+   - If you enter the name of an object or an array in the Watch window, a tree control will appear next to its name. Then, you can use this to expand or collapse it.

+   - To change the value of a watch expression, double-click on its value in the Value column, enter the new value, and press the Enter.

+   - To delete a watch expression, right-click on the expression and select the Delete Watch command from the shortcut menu. Delete all watch expressions, right-click on the Watch window, select the Select All command, and select the Delete Watch command.

# Express Edition difference

+   - The Visual C# 2010 Express Edition offers just one Watch window named Watch.
