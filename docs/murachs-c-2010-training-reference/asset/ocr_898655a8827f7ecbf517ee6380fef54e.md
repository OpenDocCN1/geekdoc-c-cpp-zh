# How to view the XML documentation

Once you add XML documentation, Visual Studio will use the XML documentation when it displays the screen tips that appear in the Visual Studio Code Editor window as shown in figure 16-5.
in the first example, when I typed the Validator class and a period, the IntelliSense feature displayed a list of the members of the Validator class. Then, I used the arrow keys to select the IsPresent method. When I did, Visual Studio displayed a screen tip that included the signature of the IsPresent method along with the summary tip that provided by the XML documentation that's shown in the previous figure.
In the second example, when I typed the opening parenthesis for the IsPresent method, Visual Studio displayed a screen tip that included the description of the TextBox parameter that's provided by the XML documentation that's shown in the previous figure.
