# Add Connection and Change Data Source dialog boxes

![](bbox=[0.058, 0.093, 0.822, 0.513])

# Description

+   - The first time you create a connection, the Change Data Source dialog box is displayed so you can select the data source and provider you want to use. If you check the Always Use This Selection option, your selections will be used each time you create a connection. To change these options, click the Change button in the Add Connection dialog box.

+   - To create a connection, specify the name of the server that contains the database, enter the information that it's required to log on the server, and specify the name of the database you want to connect to.

+   - To be sure that the connection is configured properly, you can click the Test Connection button in the Add Connection dialog box.

# Express Edition differences

+   - The Change Data Source dialog box provides only three options: Microsoft Access Database File, Microsoft SQL Server Compact 4, and Microsoft SQL Server Database File. The default is Microsoft SQL Server Compact 4, which probably isn't what you want.

+   - The Add Connection box is simpler, and it includes a Database Name text box that you use to specify the database. To do that, you click the Browse button to the right of the text box and use the resulting dialog box to point to the data file for the database.
