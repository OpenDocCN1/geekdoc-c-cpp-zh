# How to use the Code Editor

If you want to work with the source code for an application, you can use the Code Editor window (or just Code Editor) shown in figure 1-9. The Code Editor lets you enter and edit the source code for a C# application.

After you have designed the user interface for a project by using the Form Designer to place controls you can use the Code Editor to enter and edit the C# code that makes the controls work the way you want them to. The easiest way you can begin typing the C# statements that will be executed when the user performs the most common action on that control. For example, you can enter the statements that will be executed when the user clicks on that button.

The Code Editor works much like any other text editor. However, the Code Editor has a number of special features that simplify the editing C# code. For example, color is used to distinguish C# keywords from variables, comments, and other language elements. The improved IntelliSense feature can help you enter code correctly. You'll learn more about working with the Code Editor in chapter 3.
