# The Publish page of the Project Properties window

![](bbox=[0.098, 0.091, 0.843, 0.473])

# Description

+   - To publish an application, display the Project Properties window and then display the Publish page. Enter the location where you want to publish the application, set the other options the way you want them, and click the Publish button.
- If the application will be installed from a location other than the location where it's published, you'll need to enter that location for the Installation Folder URL option.
- By default, the application is available offline, which means that it's installed on the user's hard drive. If that's not what you want, you can select the Online Only option. Then, the user will only be able to run the application from the web server.
- By default, the version of an application is increased automatically each time you publish it, and the initial version is to 1.0.0.0. If that's not what you want, you can select the options in the Publish version of the Publish page.
- You can use the buttons in the Install Mode and Settings sections of this page to set additional options. See 25-4, 25-5, and 25-6 for details.
- You can also use the Publish Wizard to publish an application. This wizard lets you specify where the application will be published and whether the application will be available offline. To start this, select the Build->Publish command or click the Publish Wizard button on the Publish page.
- To publish an application to a remote web site, FrontPage Server Extensions must be installed on the web server.
