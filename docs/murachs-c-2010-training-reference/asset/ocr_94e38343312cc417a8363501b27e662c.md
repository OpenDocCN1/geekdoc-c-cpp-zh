# Perspective

Now that you've completed this chapter, you should be able to use a data source to create simple applications that let you view and maintain the data in one table of a database. That should give you some idea of how quickly and easily you can create applications when you use the data source feature. And in the next chapter, you'll learn how you can use data sources to build more complex applications.
