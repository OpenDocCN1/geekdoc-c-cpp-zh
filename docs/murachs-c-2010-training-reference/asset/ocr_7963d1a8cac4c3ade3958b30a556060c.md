# Perspective

When you've read this chapter, you should have a general idea of what the .NET Framework, the Visual Studio development environment, and C# are and how they're related. You should also know how to use Visual Studio's IDE to work with the files in projects and solutions. Now, to get more comfortable with the IDE, you can step through the exercise that follows.

When you're done with this exercise, you should be ready for the next chapter. There, you'll learn more about using the IDE as you develop your first C# application.
