# Perspective

You'll probably spend a surprising amount of time developing procedures for deploying even relatively small applications. So for a large application, I recommend that you develop a procedure early in the application's development cycle. Then, you can use this procedure to install the application during testing, and you can use that experience to fine-tune the procedure as you go along. As a side benefit, you may discover installation issues that affect the application's design.
