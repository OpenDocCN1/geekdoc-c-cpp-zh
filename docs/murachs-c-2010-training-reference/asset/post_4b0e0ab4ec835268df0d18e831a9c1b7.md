## How to set options and create a new project

Before you start your first Windows Forms application with Visual Studio 2010, you probably should change a few of the Visual options. That will make it easier for you to create a new project. You may also want to change the import and export settings.

## How to set the Visual Studio options

To set the options for Visual Studio, use the Options dialog box shown in figure 2-1. This dialog box is open, you can expand the Projects and Solutions group by clicking on the ▷ symbol to the left of that group, and you can click on the General group to display the options shown in this figure.

You can set the default project location by typing a path directly into the text box, or you can click the button to the right of the text box to display a dialog box lets lets navigate to the folder you want to use. This will set the default location for new projects, but you can always override it when you create a new project.

By default, most of the options available from this dialog box are set the way you want. However, if you want Visual Studio to work the way it's described in this book, you should check the Always Show and Save New Projects when Created options. Beyond that, it's worth taking a few minutes to review the other options that are available. Then, you can change if Visual Studio isn't working the way you want to. For instance, you may want to use the Startup group within the Environment group to change what's displayed when Visual Studio starts.

## How to change the import and export settings

The first time you start Visual Studio 2010, you're asked what Default Environment Settings you want to use. You can choose from several options including Visual Basic, Visual C#, Visual C++, and Web. Among others, your choice affects what items are available from some menus and what buttons are available from the Standard toolbar. For example, you choose the Visual C# settings, you open a project with the File→Open Project/Solution command. But if you choose the Visual Basic settings, you open a project with the File→Open Project command.

To change these settings, you use the Import and Export Settings Wizard as described in this figure. In the first step of the wizard, choose the Reset All Settings option. In the second step, choose the Save, My Current Settings option. And in the last step, if you want yours to work as described in this book, choose the Visual C# Development Settings option. Later, if you switch to Visual Basic, C++, or web development, you can change the settings.

## How to use the Options dialog box

- To display the Options dialog box, use the Tools→Options command.
- To expand and collapse group of options, you can use the ▷ and ▷ symbols to the left of each group. To display the options for a group, click on the group.
- To set the default location for all projects that you start from Visual Studio, you can change the Projects Location as shown above.
- Although most of the options should be the way you want them, you may want to familiarize yourself with the options in each category so you know what's available.

## How to set the Import and Export Settings

- The first time you start Visual Studio 2010, you are asked to choose the default environment settings. These settings affect how the menus work and what buttons are displayed on the Standard toolbar.
- To change the settings to the ones used for this book, use the Tools→Import and Export command to start the Settings Wizard. Then, choose the Reset All Settings option, the Save My Current Settings option, and the Visual C# Development Settings option as you step through the wizard.

## Express Edition notes

- If you want the Visual C# 2010 Express Edition to work as described in the next figure, be sure to check the Save New Projects When Created box in the Options dialog box.
- With the Express Edition, there is no third step to the Import and Export Settings Wizard because this wizard assumes that you want to use the Visual C# development settings.

## How to create a new project

To create a new project, you use the New Project dialog box shown in figure 2-2. This dialog box lets you select the type of project you want to create by choosing one of several templates. To create a Windows Forms application, for example, you select the Windows Forms Application template. Among other things, this template includes references to all of the assemblies that contain the namespaces you're most likely to use as you develop a Windows application.

Note that you can select a template from the Installed Templates category as shown here. You can select a template from the Recent Templates and Online Templates categories. Or you can search for an installed template using the search text box in the right corner of the dialog box.

The New Project dialog box also lets you specify the name for the project, and it lets you identify the folder in which it will be stored. By default, projects are stored in the Visual Studio 2010 Projects folder under the My Documents folder, but you can change as shown in the figure.

If you want to change the location that's shown in the New Project dialog box, you can click the Browse button to select a different location; display the Location drop-down list to select a location've used recently; or type a path directly. If you specify a path that doesn't exist, Visual Studio will create the necessary folders for you.

When you click the OK button, Visual Studio automatically creates a new folder for the project using the project name you specify. In the dialog box in this figure, for example, InvoiceTotal is the project name and C:\Projects2010 is the location. By default, Visual Studio creates a new folder for the solution, using the same name as the project. As a result, Visual Studio will create one folder for the solution, and a subfolder for the project. Then, you can add another drop-down list to the same solution by selecting Add To from the Solution drop-down (This list is displayed only if a drop-down is open).

If a project will contain a single solution, you may want to store the project and solution in the same folder. To do that, you can select the Create Directory For check box. Then, the solution is given the same name as the project. In the applications for this book, the project and solution files are typically stored in separate folders when most solutions contain a single project.

Incidentally, the terms folder and directory are used as synonyms throughout this book. With the introduction of Windows 95, Microsoft started referring to directories as folders. But most of the Visual Studio documentation still uses the term directory. That why this book uses whichever seems more appropriate at the time.

By default, the new projects you create .NET Framework 4 so you can use the features it provides. If you use any of these features, however, any computer that you want to run the application on must also have .NET Framework 4. If that's not the case, you can change the target framework using the top of the New Project dialog box. the drop-down list. Then, only the features of the framework you choose will be available from Visual Studio.
