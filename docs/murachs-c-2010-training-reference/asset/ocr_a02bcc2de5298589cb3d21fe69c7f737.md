# # How to test a project

+   1. Test the user interface. Visually check all the controls to make sure they are displayed properly with the correct text. Use the Tab key to make sure the tab order is correct, verify that the access keys work, and make sure that the Enter and Esc keys work properly.
2. Test valid input data. For example, enter data that you would expect a user to enter.
3. Test invalid data or unexpected user actions. For example, leave required fields blank, enter data into numeric input fields, and use negative numbers where they are not appropriate. Everything you can think of to make the application fail.

# # Description

+   * To test a project, run the project to make sure it works no matter what combination of valid or invalid data you enter or what sequence of controls you use.
* If a statement in your application can't be executed, a runtime error, or exception, occurs. Then, if the exception isn't handled by your application, the statement that caused the exception is highlighted and an Exception Assistant window like the one above is displayed. At that point, you need to debug the application.
