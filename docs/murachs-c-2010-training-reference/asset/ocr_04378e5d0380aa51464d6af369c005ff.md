# Using a Setup program

If you use a Setup program to deploy a database application, you need to be sure that the connection string is properly set and the users have access to the database if it's stored on a network server just as you do with ClickOnce deployment. The database will be stored on the user's computer, however, you can use the technique described in figure 25-13 to deploy the database with the application.

To start, you need to add the database file to the Setup project. In this figure, for example, the database file has been added to a folder name Data within the applications uses for the database so it points to this folder. This is illustrated added following the connection string in this folder. Here, a directory named Data has been added the DataDirectory specification. When the application is deployed, DataDirectory will point to the directory that contains the executable file for the application. Although you can't see it here, the executable file is included in the Application Folder, so the database file will be stored in the Data folder that's subordinate

Unlike ClickOnce deployment, SQL Server 2008 Express isn't automatically selected as a prerequisite if you deploy a database file with an application. Because of that, you'll need to set this prerequisite manually. To set the prerequisites for a Setup project, display the Property Pages dialog box for the project as described in this figure. Then, click the Prerequisites button and select the appropriate option from the dialog box that's displayed.
