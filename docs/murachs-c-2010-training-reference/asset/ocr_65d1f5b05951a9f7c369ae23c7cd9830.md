# The dataset schema

![](bbox=[0.071, 0.098, 0.858, 0.53])

Description

* The dataset for this application includes all the columns from the Customers and In-voices tables in the MMABooks database.
* Because the Customer Invoice application doesn't use all the columns in these tables, the data source could have been defined so that it includes only the required columns. It could also have been so that the data is joined into a single table. However, this would give an application that performed additional functions less flexibility.
* The dataset used by this application was generated using the Data Source Configuration Wizard. For information on this wizard, please see chapter 18.
