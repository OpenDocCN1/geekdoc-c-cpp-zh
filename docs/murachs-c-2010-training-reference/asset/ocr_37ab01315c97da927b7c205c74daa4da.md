# How to work with
interfaces and generics

This chapter starts by showing you how to use interfaces. Interfaces are similar
ab abstract classes, but they have several advantages that make them easier to
create and more flexible to use. Then, this chapter shows you how to use
generics so you can code your own collections that work like the generic
collections from the .NET Framework presented in chapter 8. Along the way,
you'll learn how to work with the generic interfaces that are used with generic
collections.
