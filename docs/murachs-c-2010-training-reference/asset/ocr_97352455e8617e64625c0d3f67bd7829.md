# Section 5 Other skills for C# developers

The ReadStartElement method starts by confirming the current node is a start tag. If it is, the method checks to make sure that the name of the start tag matches the name you supply as an argument. If both of these conditions are met, the method then reads the next element. Otherwise, an Exception is thrown.

The ReadEndElement method is similar, but it checks to make sure the current node is an end tag rather than a start tag, and it doesn't check the element name. If the current node is an end tag, the ReadEndElement method reads the next element. Otherwise, it throws an XmlException.

The ReadContentAsString method reads a simple content element (an element that has no child elements) and returns its content node as a string. However, if the element contains child elements rather than simple content, an XmlException is thrown. After the reader moves past the end element tag it's positioned to read the next element.

The ReadContentAsDecimal method works similarly. However, this method also converts the content's stored in the element to a decimal value and returns that value. If this method isn't able to convert the content to a decimal value, it throws an XmlException.

To read attributes, you can use the indexer of the XmlReader. To do that, you use the name of the attribute as a string argument within brackets. Of course, this only works if the current node has an attribute with the specified name.
