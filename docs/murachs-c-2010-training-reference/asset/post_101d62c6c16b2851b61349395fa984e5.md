# How to code multiple classes in a single file

In most cases, you'll code each class that's required by an application in a separate file. If two or more classes are closely related, however, you might want to consider storing them in the same file. Figure 16-1 shows two ways you can do that.

First, you can simplify the class declarations one after another as shown in the first example. The advantage of doing that is that it makes easier to manage the files that make up the application. If the classes are large, however, you should place them in separate files even if they are closely related.

You can also code two or more classes in a single file by nesting one class within another. Nested classes are useful when one class only makes sense within the context of another class. The second example in this figure illustrates how to nest two classes. Here, the class name InnerClass is nested within a class named OuterClass.

If you want to refer to the inner class from another class than the outer class, you have to qualify it with the name of the outer class like this:

```csharp
OuterClass.InnerClass ic = new OuterClass.InnerClass();
```

However, you typically only need to refer to the inner class from the outer class, and you can do that without qualifying the name of the inner class.

# A file with two classes coded one after another

```csharp
public class Class1 {
    // Body of Class1
}
public class Class2 {
    // Body of Class2
}
```

# A file with nested classes

```csharp
public class OuterClass {
    InnerClass ic = new InnerClass(); // code that uses the inner class
    public class InnerClass {
        // Body of InnerClass
    }
}
```

# Description

- When two classes are closely related, it sometimes makes sense to code them in the same file, especially if the classes are relatively small. That way, the project consists of fewer files.
- One way to code two classes in a single file is to code them one after the other as shown in the first example.
- Another way to code two classes in a single file is to nest one class within another. This is useful when one class is only used within the context of another class.
- To refer to a nested class from another class than the outer class, you must qualify it with the name of the class it's nested within: `OuterClass.InnerClass`
