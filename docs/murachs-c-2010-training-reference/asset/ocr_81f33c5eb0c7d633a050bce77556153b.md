# Common .NET structures define value types

| Structure | C# keyword | What the value type holds |
|---|---||
| Byte | byte | An 8-bit unsigned integer |
| Int16 | short | A 16-bit signed integer |
| Int32 | int | A 32-bit signed integer |
| Int64 | long | A 64-bit signed integer |
| Single | float | A single-precision floating-point number |
| Double | double | A double-precision floating-point number |
| Decimal | decimal | A 96-bit decimal value |
| Boolean | bool | A true or false value |
| Char | char | A single character |

# Common .NET classes that define reference types

| Class name | C# keyword | What the reference type holds |
|---|---||
| String | string | A reference to a String object |
| Object | object | A reference to any type of object |

# Description

+   * Each built-in data type is supported by a structure or a class within the .NET Framework. When you use a C# keyword to refer to a data type, you're actually using an alias for the associated structure or class.
* A structure defines a reference type. A reference type doesn't store the data itself. Instead, it stores a reference to the area of memory where the data is stored.
* All of the structures and classes shown in this figure are in the System namespace of the .NET Framework.
