# How to use a class library

+   - Add a reference to the class library to your project by right-clicking the References folder in the Solution Explorer and selecting the Add Reference command. In the Add Reference dialog box, click the Browse button, locate the DLL for the class library, select it, and click the OK.

+   - If the class library project is included in the same solution as the client project, your project will appear in the list at the top of the Projects tab. Then, you can add a reference to the class library by double-clicking the project name.

+   - Once you have added a reference to the class library, you can include a using statement for the class library's namespace in any class that uses it. You can then use the classes in the class library without qualification. Alternatively, you can qualify the class names with the namespace name you assigned to the library.
