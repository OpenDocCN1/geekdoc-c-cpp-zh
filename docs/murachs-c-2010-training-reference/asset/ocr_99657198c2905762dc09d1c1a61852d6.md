# How to code properties

12-7 presents the syntax for coding a property. As you can see, a property declaration specifies both the type and name of the property. In addition, a property is typically declared with the public access modifier so that it can be accessed by other classes.

Within the block that defines a property, you can include blocks called accessors because they provide access to the property values. The getter is executed when a request to retrieve the property value is made, and the setter is executed when a request to set the property value is made. If both get and setter accessors are included, the property is called a read/write property. If only a getter is included, the property is called a read-only property. In most cases, each property has a corresponding instance variable that holds the property's value. In that case, the property should be declared with the same data type as the instance variable. It's also common to use the same name for the property and the instance variable, but use Camel notation (first word starts with a lowercase character, all words after that start with uppercase characters) and use Pascal notation for the property name. The set accessor uses an implicit parameter named value to be assigned to the property.
