# Common properties of a column

| Property | Description |
| --- | --- |
| HeaderText | The text that's displayed in the column header. |
| Width | The number of pixels that are used for the width of the column. |
| DefaultCellStyle | The style that's applied to the cell. You can use dialog boxes to set style elements as color, format, and alignment. |
| ReadOnly | Determines if the data in the column can be modified. |
| SortMode | Determines if the data in the grid is sorted by the values in the column and how the sorting is performed. The default option is Automatic, which uses the built-in sorting mechanism. To provide custom sorting, select the Programmatic option. To turn off sorting, select the NotSortable option. |

# Description

+   * You can use the Edit Columns dialog box to control which columns are displayed in the grid and edit the properties of those columns. To display this dialog box, choose the Edit Columns command from the smart tag menu for the control
* To remove columns from the grid, select the column and click the Remove button.
* To add a column to the grid, select the Add button and complete the dialog box that's displayed. This dialog lets you both bound and unbound columns.
* To change the order of the columns, select the column you want to move and click the up or down arrow to the right of the list of columns.
* To edit the properties for a column, select the column and use the Bound Column window to edit the properties.
