# Description

+   * To install an application, open a web browser and navigate to the installation page that's created when you publish an application. Then, click the Install button to install the application.
* If an application doesn't come from a trusted source, a security warning will be displayed when you install the application. You can click the Install button in this dialog box to install the application.
* If you run an application that's set to check for updates, the Update Available dialog box is displayed if a new version of the application is available. Then, you can click the OK button to update the application, or you can click the Skip button to skip the update.
