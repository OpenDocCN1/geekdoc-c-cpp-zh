# How to generate detail controls from a data source

If you change the control type that's associated with a table from DataGridView to Details and drag that table from the Data Sources window onto a form, Visual Studio will add the appropriate controls to the form as shown in figure-18-11. It will bind controls to the appropriate columns in the table, and it will add a Label control for each column to identify it. In this, for example, you can see that Visual Studio added a TextBox control and a Label control for each of the six columns in the Customers table. In addition, it added DataSet, BindingSource, TableAdapter, and TableAdapter objects and a binding navigator toolbar just as it does when you generate a DataGridView control.

When you use text boxes to work with the data in a table, only one row of the table is displayed at a time. Then Visual Studio uses simple data binding to tie each text box to a single column value. To do that, it sets the Text property in the DataBindings collection to the name of the data column that control is bound to. In this figure, for example, you can see the drop-down list for the Text property of the DataBindings collection. It shows that the Customer ID box is bound to the CustomerID column of the customersSource object.

Once the labels and text boxes are displayed on the form, you can use standard skills for editing labels and text boxes to get the form to work correctly. For example, if you want to change the text that's displayed in a label, you can select the label and edit its Text property. If you don't want the user to be able to enter data for a particular column, you can change the ReadOnly property of the text to True. Or, if you don't want to display a column, you can delete the label and text box for that column.

Alternatively, instead of dragging the entire table onto the form, you can drag the columns you want. In addition, if you want to create a read-only form, you can edit the BindingNavigator toolbar to remove its Add, Delete, and Save buttons. You'll learn how to do that in the next chapter.
