# How to write code that works with parent and child forms

24-76 shows coding techniques that you can use to work with parent and child forms. To start, the first example shows how to create and display a new instance of a child form. You create a new instance using the new keyword as you do for any class. Then, you set the MdiParent property of the form to the parent form. To do that, you can use this keyword to identify the parent form. Finally, you use the Show method to display the form.

Because there may be more than one instance of a child form displayed at the same time, you can't refer to an individual form by name. Instead, you need to use the ActiveMdiChild property of the parent form to refer to the child form that currently has the focus. You can see how this works in the second example in this figure. Here, the first statement uses the ActiveMdiChild property to return a reference to the active child form. Then, it uses the Close method to close that form.

The next code example shows how you can use the LayoutMdi method of the parent form to arrange the child forms. To do that, you the members of the MdiLayout enumeration. These members let you the windows vertically or horizontally or arrange them in a cascaded layout.

All of the code in this figure is executed in response to the Click event of a item menu, when the user selects the item. For example, the code that creates and displays a new instance of a child form is executed in response to the user selecting the New Value item from the File menu. The code that closes the active child form is executed in response to the user selecting the Close item from the File menu. And the code that arranges the child forms is executed in response to the user selecting the Vertical item from the Window menu.

Whenever you need to display and organize the child forms of an MDI application, you can use menus in the parent form to do that. For example, it's common for a parent form to contain a File menu that allows you to display child forms, close the active child form, and exit the application, which closes all open child forms. Similarly, it's common for a parent form to contain a Window menu that allows you to cascade or tile all child forms. If you set the MdiWindowListItem property of the MenuStrip this menu will also display a list of all the open child forms as shown in this figure.

However, when you want to use menus that work directly with a child form, you can add menus to that child form. For example, if you want to add a Clear menu item that clears all the text boxes on a child form, you can add that to a menu on the child form. Then, the menu for the active child form will be displayed to the right of the menus for the parent form.
