# Chapter 14 How to work with inheritance

# Two methods that display product information

```
public void DisplayProduct(Product p)
{
    MessageBox.Show(p.GetDisplayText());
}
public void DisplayBook(Book b)
{
    MessageBox.Show(b.GetDisplayText());
}
```

# Code that doesn't require casting

```
Book b = new Book("CS10", "Murach's C# 2010", "Joel Murach", 54.50m\);
// Casting is not required because Book
DisplayProduct(b);
// is a subclass of Product.
```

# Code that requires casting

```
Product p = new Book("CS10", "Murach's C# 2010", "Joel Murach", 54.50m);
DisplayBook((Book)p);
// Casting is required because DisplayBook
// accepts a Book object.
```

# Code that throws an exception

```
Product p = new Software("NPFX", .NET Programmer's Toolkit",
"4.0", 179.99m);
DisplayBook((Book)p);
// Will throw a casting exception because p is
// Software object, not a Book object.
```

# Code that uses the as operator

```
Product p = new Book("CS10", "Murach's C# 2010", "Joel Murach", 54.50m);
DisplaySoftware(p as Software); // Passes null because p isn't a Software object
```

# Description

+   * C# cannot implicitly cast a subclass to its base class as is called for. For example, you can specify a Book object whenever a Product object is expected because Book is a subclass of Product.

+   * You must explicitly cast a base class object when a reference to one of its subclasses is required. For example, you explicitly cast a Product object to Book if a Book object is expected.

+   * If you attempt to cast a base class object to a subclass, InvalidCastException will be thrown if the object is not of the correct type. For example, if you store a Software object in a variable of type Product and try to cast the variable to a Book, a casting exception will be thrown.

+   * You can use the as operator to cast an object to another type without throwing a casting exception if the cast is invalid. The as operator simply returns null if the cast is invalid.
