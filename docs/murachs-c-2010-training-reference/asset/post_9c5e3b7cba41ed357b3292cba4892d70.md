## An introduction to coding

Before you learn the mechanics of adding code to a form, it's important to understand some of the concepts behind object-oriented programming.

## Introduction to object-oriented programming

Whether you know it or not, you are using object-oriented programming as you design a Windows form with Visual Studio's Form Designer. That's because each control on a form is an object, and the form itself is an object. These objects are derived from classes that are part of the .NET Class Library.

When you start a new project from the Forms Application template, you are actually creating a new class that inherits the characteristics of the Form class's part of the .NET Class Library. Later, when you run your form, you are actually creating an instance of your form class, and this instance is known as an object.

Similarly, when you add a control to a form, you are actually adding a control to the form. Each control is an instance of a specific class. For example, a text box control is an object that is an instance of the TextBox class. Similarly, a label control is an object that is an instance of the Label class. Process of creating an object from a class can be called instantiation.

As you progress through this book, you will learn more about classes and objects because C# is an object-oriented language. In chapter 12, you will learn how to use the C# language to create your own classes. At point, you'll start to understand what's actually happening as you work with classes and objects. For now, though, you just need to get comfortable with the terms and the fact that a lot is going behind the scenes as you design a form and its controls.

Figure 3-1 summarizes what I've just said about classes and objects. It introduces you to the properties, methods, and events that are defined by classes and used by objects. As you've already seen, the properties of an object's characteristics and data. For instance, the Name property gives a name to a control, and the Text property determines what is displayed within the control. In contrast, the methods of an object determine the operations that can be performed by the object.

An object's events are sent by the object to your application that something has happened can be responded to. For example, a Button control object generates an event Click if the user clicks the button. Then, your application can respond by running a C# method to handle the Click event.

### Class and object

- An object is a self-contained unit that combines characteristics and data
- A class is a template for creating objects
- The process of creating an object from a class is called instantiation

### Property, method, and event

- Properties define the characteristics and data of an object
- Methods are the operations that can be performed by the object
- Events are signals sent by the object to your application that something has happened

### Objects and forms

- When you add a control to a form, you are actually adding a control to the form
- Each control is an instance of a specific class
- The form itself is an object

### How to refer to properties, methods, and events

- IntelliSense displays a list of members that are available after you type the object name and period
- You can highlight the entry you want by clicking on, typing one or more letters of its name, or using the arrow keys to scroll through the list
- You can complete the entry by pressing the Tab or Enter key
- If the member name is followed by another character, such as a parenthesis, you can also complete the entry by typing that character
