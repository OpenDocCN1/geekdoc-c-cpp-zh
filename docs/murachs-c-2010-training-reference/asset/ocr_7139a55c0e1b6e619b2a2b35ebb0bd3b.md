# Code that reads an XML document

```
// create the list
List<Product> products = new List<Product>();

// create the path variable
string path = "C:\Data\Products.xml";

// create the XmlReaderSettings object
XmlReaderSettings settings = new XmlReaderSettings();
settings.IgnoreWhitespace = true;
settings.IgnoreComments = true;

// create the XmlReader object
Reader xmlIn = XmlReader.Create(path, settings);

// read past nodes to the first Product node
if (xmlIn.ReadToDescendant("Product"))
{
    // create one Product object for each Product node
    do
{
        Product product = new Product();
        product.Code = xmlIn["Code"];
        xmlIn.ReadStartElement("Product");
        product.Description =
            xmlIn.ReadElementContentAsString();
        product.Price =
            xmlIn.ReadElementContentAsDecimal();
        products.Add(product);
    } while (xmlIn.ReadToNextSibling("Product"));
}

// close the XmlReader object
xmlIn.Close();
```

# Description

+   
- This example loads the XML document in figure 22-1 into a List<> collection of objects.
- To focus on the code that's used to read an XML file, this code doesn't include any exception handling. However, it's common to use a try-catch block that catches and handles any exceptions that this might throw. In addition, it's common to include a finally block that frees the resources being used by this code.
