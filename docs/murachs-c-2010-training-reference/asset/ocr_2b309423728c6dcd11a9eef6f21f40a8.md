# Description

+   - The new Generate From Usage feature lets you generate code stubs for any undefined class, constructor, property, method, field, enumeration, structure, or interface from the current location in your code.
- To generate a code stub for a class, property, method, or field, click in the class or member name and select the appropriate Generate command from the smart tag menu that becomes available.
- To generate a code stub for an enumeration, structure, or interface, or to specify additional information for a class, select the Generate New Type... command from the smart menu and complete the dialog box that is displayed.
- When you enter a class or member that hasn't been defined, you should use suggestion mode for statement completion instead of completion mode. With suggestion mode, the name you type is inserted into your code rather than the highlighted entry in the completion list.
- To switch or from suggestion mode, use the Edit→IntelliSense→Toggle Completion Mode command, or press Ctrl+Alt+Spacebar.
