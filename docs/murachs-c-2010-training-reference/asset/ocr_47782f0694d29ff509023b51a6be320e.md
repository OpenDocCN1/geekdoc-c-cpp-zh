# An introduction to ADO.NET

ADO.NET (ActiveX Data Objects .NET) is the primary access API for the .NET Framework. It provides the classes that you use to develop database applications with C# as other .NET languages. These classes can be divided into two categories: the .NET data providers, which provide the classes that you use to access the data in a database, and datasets, which provide the classes that you use to store and work with data in your applications.

# The .NET data providers

A .NET data provider is a set of classes that enable you to access data's managed by a particular database server. The second table in this figure lists the four data providers that come with the .NET Framework. The SQL Server provider is designed to provide efficient access to a Microsoft SQL Server database. The OLE DB data provider is a generic data provider that can access any database that supports the industry standard OLE DB interface. Although you can use the OLE DB data provider to access a SQL Server database, you shouldn't do that unless you are on migrating the data to another database since the SQL Server database is optimized for accessing SQL Server data. The ODBC provider lets you access any database that can work with ODBC, another industry standard database interface. The Oracle provider lets you access any data stored in Oracle databases.

Note that the Oracle provider has deprecated and will be dropped from a future release of the .NET Framework. Because of that, you'll want to avoid using this provider for new application development. Instead, you can use the .NET data provider is available from Oracle.

Also note that the .NET data provider isn't available if you set the target framework for a project to: .NET Framework 4 Client Profile. If you want to use this, you'll need to set the target framework to: .NET Framework 4.

In addition to the .NET data provider developed by Oracle, several other database vendors have developed .NET data providers that are optimized for use with their databases. For example, .NET data providers are available for the popular MySQL database and for SQL Anywhere. Before you develop an application using the OLE DB or ODBC providers, you should check with your database vendor to see if a .NET data provider is available.
