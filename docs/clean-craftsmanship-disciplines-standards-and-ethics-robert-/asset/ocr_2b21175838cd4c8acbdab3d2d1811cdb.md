The software industry is wildly dynamic. We can debate whether this *should* be so, but we cannot debate whether it *is* so. It is. And therefore, we must all be continuous aggressive learners.

The language you are using today will likely not be the language you’ll be using in 5 years. The framework you are using today will probably not be the framework you’ll be using next year. Be prepared for these changes by being aware of what is changing all around you.

Programmers have often been advised¹ to learn a new language every year. This is good advice. Moreover, pick a language that has a style you are unfamiliar with. If you’ve never written code in a dynamically typed language, learn one. If you’ve never written code in a declarative language, learn one. If you’ve never written Lisp or Prolog or Forth, learn them.

¹. David Thomas and Andrew Hunt, *The Pragmatic Programmer: From Journeyman to Mastery* (Addison-Wesley, 2020).
