

## 初始化静态数据成员

由于类的所有对象都可以访问静态成员，那么谁负责为其预留存储并进行初始化呢？你不能在每个构造函数中这样做，因为每创建一个对象就会重新初始化静态成员。有一种特殊的方法可以创建和初始化静态数据成员。你必须在所有函数之外创建一个定义：

```cpp
// word4.h

#ifndef _WORD4_H
#define _WORD4_H

class Word {
private:
    char *buf;
    static int wordCount;
public:
    Word(char *s);
};

#endif

// word4.cpp
#include <string.h>
#include "word4.h"

int Word::wordCount = 0;

Word::Word(char *s) {
    buf = strdup(s);
    wordCount++;
}
```

这看起来有些不同寻常，因为你不仅要给出变量名，还要使用作用域解析运算符指明其所属类。因此，静态数据成员的初始化是在类定义之外进行的，方式与使用作用域解析运算符的非成员变量相同。需要注意的是，在一个程序中，静态数据成员只能初始化一次。

初始化静态成员时，请勿再次包含关键字 static。如果这样做，会遇到编译器错误。通常，静态成员的分配放在与类实现相同的源文件（.cpp 源文件）中。请记住，类声明通常放在头文件中。如果在类中包含静态成员声明也会分配该成员，那么实际上我们就在头文件中分配数据，这是绝对不应该做的。

## 访问静态数据成员

现在假设你想读取或修改一个 `static` 数据成员。你可以像访问其他任何数据成员一样访问 `static` 数据成员：

```cpp
// word5.h

#ifndef WORD5_H
#define _WORD5_H

class Word {
private:
    char *buf;
    static int wordCount;
public:
    Word(char *s);
    int getCount();
};
#endif

// word5.cpp

#include <string.h>
#include "word5.h"

int Word::wordCount = 0;

Word::Word(char *s) {
    buf = strdup(s);
    wordCount++;
}

int Word::getCount() {
    return wordCount;
}
```

```cpp
// word5drv.cpp

#include <iostream>
#include "word5.h"

using namespace std;

int main() {
    Word w1("Red");
    Word w2("White");
    Word w3("Blue");

    cout << w1.getCount() << endl;
    cout << w2.getCount() << endl;
    cout << w3.getCount() << endl;
    return 0;
}
```

// word5 output

3
3
3

如果 wordCount 是普通自动变量或局部变量，而不是静态数据成员，那么每个构造函数只会递增其自身私有副本中的 wordCount 一次，输出对所有三个对象都将是 1，而不是 3。

## 另一个示例

假设一个对象需要知道程序中其类有多少其他对象。例如，在一场公路赛车游戏中，一辆赛车可能想知道还有多少辆车正在比赛。在这种情况下，可以将一个静态变量 count 作为类的成员包含进来：

- 所有对象都可以访问此变量
- 它是所有对象共享的同一个变量
- 每个对象都会看到相同的 count 变量

每个对象都可以访问静态数据成员中的信息，因此你可以使用静态数据成员让对象之间相互通信。因此，静态数据成员可以被视为类中对象之间通信的一种方式。

## 静态成员函数

假设你想读取或修改一个 `static` 数据成员。你可以像访问其他任何成员一样，通过普通成员函数来访问 `static` 数据成员，如下所示：

```cpp
// word6.h

#ifndef _WORD6_H
#define _WORD6_H

class Word {
 private:
   char *buf;
   static int wordCount;
 public:
   Word(char *s);
   int getCount();
};

#endif

// word6.cpp

#include <string.h>
#include "word6.h"

int Word::wordCount = 0;

Word::Word(char *s) {
  buf = strdup(s);
  wordCount++;
}

int Word::getCount() {
  return wordCount;
}
```

```cpp
// word6drv.cpp
#include <iostream>
#include "word6.h"

using namespace std;

int main() {
    Word w1("Red");
    cout << w1.getCount() << endl;
    return 0;
}

// word6 output
1
```

但是，当你调用 getCount() 时，必须针对一个对象来调用，即向特定对象发送 getCount() 消息，而 this（对象的地址）会被秘密地传递给成员函数。

虽然 this 指针带来的额外开销可能不是问题，但在某些情况下，效率的降低是不可接受的。这不仅适用于仅访问静态数据成员的函数，也适用于任何代表整个类执行操作且不需要访问特定对象成员的操作。

我们可以通过将 getCount() 函数设为友元函数来消除传递 this 指针的额外开销：

```cpp
// word7.h

#ifndef _WORD7_H
#define _WORD7_H

class Word {
    private:
        char *buf;
        static int wordCount;
    public:
        Word(char *s);
        friend int getCount();
};

#endif
```

```cpp
// word7.cpp
#include <string.h>
#include "word7.h"

int Word::wordCount = 0;

Word::Word(char *s) {
    buf = strdup(s);
    wordCount++;
}

int getCount() {
    return Word::wordCount;
}
```

```cpp
// word7drv.cpp
#include <iostream>
#include "word7.h"

using namespace std;

int main() {
    Word w1("Red");
    Word w2("White");
    Word w3("Blue");
    return 0;

    cout << getCount() << endl;
}

// word7 output
3
```

我们现在在类之外定义了 getCount()，如下所示：

```cpp
int getCount() {
    return Word::wordCount;
}
```

现在 getCount() 是一个全局函数，可以访问静态私有数据，但没有额外开销。然而，该函数不再位于类 Word 的作用域内。因此，如果有人通过引入另一个库（例如）来引入 getCount() 名称，就会发生名称冲突。

C++ 允许你以优雅的方式解决这些问题。你可以将成员函数定义为 `static`！这与 `static` 数据成员的含义相近，即该函数是为整个类服务的，而不仅仅是类的一个对象。

关键在于，`this` 指针不会被秘密地传递给 `static` 成员函数。因此，你不会产生额外开销。但是，你也只能访问 `static` 数据成员和 `static` 成员函数，不能访问其他内容。

由于函数是类的成员，其名称隐藏在类的作用域内，不会与全局名称冲突。此外，你可以将函数名与类名关联，这在记法上很方便，因此函数的用途更加明显，并且可能受到类更改的影响。

```cpp
// word8.h

#ifndef WORD8_H
#define WORD8_H

class Word {
   private:
      char *buf;
      static int wordCount;

   public:
      Word(char *s);
      static int getCount();
};

#endif

// word8.cpp

#include <string.h>
#include "word8.h"

int Word::wordCount = 0;

Word::Word(char *s) {
   buf = strdup(s);
   wordCount++;
}

int Word::getCount() {
   return wordCount;
}
```

## 调用静态成员函数

你可以用两种方式调用静态成员函数：

```cpp
// word9.h

#ifndef _WORD9_H
#define _WORD9_H

class Word {
    private:
        char *buf;
        static int wordCount;
    public:
        Word(char *s);
        static int getCount();
};

#endif
```

```cpp
// word9.cpp

#include <string.h>
#include "word9.h"

int Word::wordCount = 0;

Word::Word(char *s) {
    buf = strdup(s);
    wordCount++;
}

int Word::getCount() {
    return wordCount;
}
```

```cpp
// word9drv.cpp

#include <iostream>
#include "word9.h"

int main() {
    Word w1("Red");
    Word w2("White");
    Word w3("Blue");

    cout << w1.getCount() << endl;
    cout << Word::getCount() << endl;
    return 0;
}
```

// word9 output

3
3

示例 1 与其他任何成员函数一样。示例 2 是静态成员函数特有的，通过使用作用域解析运算符指定类。这是调用静态函数的重要方式，因为它不需要对象引用。当静态成员函数实际上并不使用或修改该特定对象时，却为对象调用静态成员函数，这可能会让代码阅读者感到困惑。

请记住，对象的地址 this 不会传递给静态成员函数；因此静态成员函数不能访问非静态数据成员，即它不能访问用于调用静态函数的对象的成员数据。静态成员函数只能访问静态数据成员。

如果静态成员函数需要访问类的成员数据，则需要显式传递 this 指针：

```cpp
// word10.h

#ifndef WORD10_H
#define _WORD10_H

class Word {
    private:
        char *buf;
        static int wordCount;
    public:
        Word(char *s);
        static int getCount(Word *w);
};

#endif
```
