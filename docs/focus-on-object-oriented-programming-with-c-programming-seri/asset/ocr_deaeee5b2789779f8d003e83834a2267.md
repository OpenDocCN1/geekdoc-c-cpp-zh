class, we can use the scope resolution operator to refer to the member of the base class.

```
// base.cpp
class Base {
protected:
    int num;
public:
    Base (int n = 0) : num(n) ()
    int getNum() { return num; }
};
class Derived : public Base {
private:
    int num;
public:
    Derived(int n = 1) : num(n) ()
    int getNum() { return num + 1; }
};
int main() {
    Derived d;
    cout << d.getNum() << endl;
    cout << d.Base::getNum() << endl;
    return 0;
}
```

# Overriding Member Functions

We can also override base class member functions. We can use member functions in a derived class that have the same name as those in the base class. You might want to do this so that calls in your program work the same way for objects of both base and derived classes.
