We can solve this problem by overloading the assignment operator, =. We use a declaration of the form:

```
Alpha& operator=(const Alpha&);
```

So let's now add an overloaded assignment operator function to the Alpha class:

```
class Alpha {
private:
    char *buf;
    int i;
    double d;
public:
    // appropriate constructors etc.
    Alpha& operator=(const Alpha&);
};
```

The overloaded assignment operator specifies a constant reference parameter of type Alpha. The parameter refers to the object being copied.

Returning a reference to the assigned-to object allows users to write code like:

```
Alpha x, y;
x = y = Alpha(num);    // note that assignment is right associative
```
