# # Default Arguments

In C, if a function requires two arguments, both arguments must be passed when the function is called. For example, suppose we have a function to position the cursor (which has an x and y location on the screen), within a window:

```
```cpp
void move(int a, int b) {
    int x, y;
    x = a;
    y = b;
    :
}
```
```

Whenever you want to position the cursor at the home position (0, 0), you would call the move() function and pass it the zero values:

```
```cpp
move(0, 0);
```
```

Because it is common to reposition the cursor to the home position, which is always (0, 0), C++ allows us to provide default argument values as follows:

```
```cpp
void move(int a = 0, int b = 0) {
    int x, y;
    x = a;
    y = b;
    :
}
```
```

This function can be called in 3 ways:

```
```cpp
move(35, 70);    // position cursor at (35, 70)
move(10);        // position cursor at (10, 0)
move();          // position cursor at (0, 0)
```
