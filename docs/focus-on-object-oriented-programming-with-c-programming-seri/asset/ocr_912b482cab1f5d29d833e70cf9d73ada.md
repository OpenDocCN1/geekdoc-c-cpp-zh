It's up to you to define the `IntArray` class, but it should fulfill the following requirements:

+   • An `IntArray` object may be declared in any of four ways:

+   1) With a single integer giving the number of elements, in which case the indices will run from 0 to one less than the number of elements.

+   2) With two integers, which will be taken as the lower and upper indices. It is an error for the first index to be greater than the second index, but having both indices the same specifies a valid, single element array.

+   3) With no integers, which creates a ten-element array whose indices run from 0 to 9.

+   4) With another object of type `IntArray`. The new object will be a copy of the old one, with each entry and the index range duplicated.
