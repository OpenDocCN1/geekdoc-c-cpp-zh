# C Structs

Conventional C programming techniques often make programmers work harder than necessary. For instance, consider how you might represent the date and time, a typical task that most programs need to do.

In C, you could declare a struct like:

```
struct Time {
    int month;
    int day;
    int year;
    int hour;
    int min;
    int sec;
};
```

The members of the Time struct store the component values of a single date and time.

Given this struct, you can declare a Time variable such as:

```
struct Time appt;
```

and you can assign values to appt's members with statements such as:

```
appt.month = 9;
appt.day = 23;
appt.year = 2012;
appt.hour = 8;
appt.min = 30;
appt.sec = 0;
```
