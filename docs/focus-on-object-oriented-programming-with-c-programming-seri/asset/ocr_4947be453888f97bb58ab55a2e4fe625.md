# Member Function Declarations

In C++, all member functions must be declared with full prototypes, i.e., all the argument types must be declared before the function can be called.

+   - Functions are declared inside a `struct`.

+   - The scope of these member functions is the scope of the `struct`.

+   - These are not global names.

# Scope Resolution Operator

When defining member functions, we must tell the compiler that the function is associated with a particular type using the scope resolution operator (::).

```
void Elevator::initialize() {
    floorSelected = 0;
    floorNumber = 0;
};
```

Since the member function is in the scope of a `struct`, it has access to the other members of the `struct`. Therefore, no pointers are necessary to access and modify the data members of the `struct`!
