For example:

```
#include <cstdio>

int main() {
    int num1;
    int num2 = num1;
    printf("%p %p", &num1, &num2); // FFFFFFFF FFFFFFFF
    return 0;
}
```

Therefore a reference variable does not have its own unique address.

# Reference Variables are Useless!

Finally, reference variables are generally useless!!!

If you already have a variable, all a reference to the variable will provide is complexity. Now you'll have two ways of changing the same variable. You'll gain nothing from reference variables. It's as messy as it sounds and you should think hard before you decide you must use a reference variable.

References were really designed for argument passing and return values and reference variables were only included for syntactic completeness, not necessarily because they were a good idea. References are usually necessary only in the context of a user-defined class type.
