is now an invalid statement. The compiler will generate an error message. The data member floorSelected is now a private data member and can only be accessed within the scope of the Elevator struct.

# # Restricted Access to Member Functions

Member functions can also have restricted access as shown below:

```
```cpp
struct Coordinates {
    private:
        int c1, c2, c3;
        void translate(int, int, int);
    public:
        void move (int, int, int);
};
```
```

Here we can assume that the member function move() calls the translate() member function, since programmers using the objects cannot.

So we've seen why we need to protect the data and functions within types and how the keywords public, private and protected can help us do that. This will lead us into a discussion of the class.
