To make it possible to use our `operator++()` in expressions, we must provide
a way for it to return a value:

```
class Counter {
   private:
      int count;
   public:
      Counter()
         { count = 0; }
      int getCount()
         { return count; }
      Counter operator++()
      {
         ++count;
         Counter temp;
         temp.count = count;
         return temp;
      }
};
```

In this version of the class, our `operator++()` function returns a value of class
Counter.

+   - it increments the count data in its own object as before.
+   - the function creates a new object of type `Counter`, called `temp`, to use
+     as a return value
+   - it assigns `count` in the temporary object the same value as in itself
+   - it returns the `temp` object

These changes now allow for the following style of expression in `main()`:

```
c2 = ++ c1;       // displays itself using the
++c1.getCount()   // getCount() member function.
```
