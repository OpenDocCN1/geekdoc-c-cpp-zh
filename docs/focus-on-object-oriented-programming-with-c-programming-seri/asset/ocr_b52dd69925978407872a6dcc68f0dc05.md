# Passing const Parameters to a Function

C++ allows you to declare a function parameter to be a `const`:

```
void foo(const int num);
```

Why would you want to declare a function in this manner? Because the function receives a copy of the actual parameter, the caller of the function really doesn't care whether the function modifies its copy. This is called pass by value.

But what if you pass a pointer to something solely for efficiency purposes? You may want to ensure that the called function doesn't use the pointer to modify the entity referenced. By declaring a pointer argument `const`, a function is prohibited from modifying the parameter pointed to.

For example:

```
void foo(const int *num);
void foo(const char *buf);
void foo(const bigStruct *bs);
char *strcpy(char *p, const char *q);
void foo(const int & num);
```

It is also legal to declare a function that returns a `const`:

```
const int foo();
```
