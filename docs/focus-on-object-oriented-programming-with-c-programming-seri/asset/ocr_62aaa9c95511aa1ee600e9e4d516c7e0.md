Defining and initializing variables where they are used can make the source listing easier to understand, since you don't need to refer to the beginning of a block. However, use with discretion. Variables that are used in many places in a function are probably better defined at the start of the function.

# Data Types

Traditional C data types are also available in C++:

```
char (the signedness of a char is machine dependent)
unsigned char
short
unsigned short
int
unsigned int
long
unsigned long
float
double
long double
```

C++ adds the logical boolean data type:

```
bool flag = true;
bool test = false;
```

The syntax for C casting looks like this:

```
(long)num
```

while the syntax for C++ casting looks like this:

```
long(num)
```

This looks a lot like a function call although it isn't really.
