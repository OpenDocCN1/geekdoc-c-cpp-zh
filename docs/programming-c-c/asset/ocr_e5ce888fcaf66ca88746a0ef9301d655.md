In this type of a construct, if the value of test-expression is true, then the true block of statements will be executed. If the value of test-expression if false, then the false block of statements will be executed. In any case, after the execution, the control will be automatically transferred to the statements appearing outside the block of If.

# Syntax of if-else statements:

```
if (test-expression)
{
    True block of statements
}
else
{
    False block of statements
}
Statements;
```
