# Functioning of switch case statement

First, the integer expression specified in the switch statement is evaluated. The value is then matched by one with the constant values given in the different cases. If a match is found, then all the statements specified in that case are executed along with all the cases present after that case including the default statement. No two cases can have similar values. If the matched case contains a break statement, then all the cases present after that will be skipped, and the control comes out of the switch. Otherwise, all the cases following the matched case will be executed.
