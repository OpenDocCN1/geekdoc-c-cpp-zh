## Functions

- One of the strengths of C is that functions can be divided into smaller parts.
- The type-specifier is the type of the data that the function is expected to return. In the absence of any data type, the type integer is assumed.
- The type specifier is followed by a function-name. The arguments of the function, if any, are given within parentheses. If the function takes no arguments, the parentheses must still be included. The function header is not terminated by a semicolon.

## Defining a Function

A function consists of three parts:
1. Function header
2. Declaration list
3. Function body

The general form of function definition is:

```
Type specifier function-name (argument list):
{
argument declarations;
Body of the function;
return(expression);
}
```

## Benefits of Using Functions

- 1. **Work:** One of the main reasons to use functions is that they work.
- 2. **The functions are modularity:** The use of functions provides modularity and allows for decomposition.
- 3. **It saves development time:** Using functions saves considerable time in development.
- 4. **The functions are portable:** Functions can be used across different programs and platforms.

## Function Header

The function header contains a type, the function name and an argument list. The type specifier is the type of the data that the function is expected to return.

## Declaration List

The function header is followed by a declaration list, which declares the types of the arguments (formal parameters). No other variables can be declared at this point. Recent compilers permit including the argument declaration with parentheses like type-specifier function-name(data-type argument1, data-type argument2...).

Examples:
1 float average (int a, b, c);
or float average (a,b,c);

The data type void may be used for the return type of the function where the function does not return any value.

## Function Body

After declaring the type of function, function-name, formal arguments, a statement or block of statements is placed between the beginning and end braces. The declaration of local variables is required only when any local variables are used in functions.

Example:

```c
/* function definition */
Factorial (x); /* Function header */
int x; /* argument declaration */
{
int i; fact = 1; /* local declaration */
for ( i = 1; i<= n; i++ ) /* Function body */
fact = fact * i;
printf(" Factorial of %d = %d\n", fact);
}
```

## Return Statement

The keyword return is used to terminate function and return a value to its caller. The return statement may also be used to exit a function with out returning a value. The return statement may or may not include an expression.

The general form of the return statement is:

```
return;
or
return( expression );
```
