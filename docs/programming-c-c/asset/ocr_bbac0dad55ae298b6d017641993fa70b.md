Here, we have used sizeof() function to read a string from the user.
fgets(name, sizeof(name), stddin); // read string

The sizeof(name) results to 30. Hence, we can take a maximum of 30 characters
input which is the size of the name string.

To print the string, we have used puts(name);

Note: The gets(s) function can also be take input from the user. However,
it is removed from the C standard.

It's because gets(s) allows you to input any length of characters. Hence, there
might be a buffer overflow.
