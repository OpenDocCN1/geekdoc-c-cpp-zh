# void type

The void type specifies that no value is available. This is usually used to specify the type of functions which returns nothing. It is used in three kinds of situations.

| S.No. | Types and Description |
| --- | --- |
| 1 | Function returns as void: There are various functions in C which do not return any value or you can return void. A function with no return value as void. For example, exit (int status); |
| 2 | Function arguments as void: There are various functions in C which do not accept any parameter. A function with no parameter can accept a void. For example, int rand(void); |
| 3 | Pointers to void: A pointer of void * represents the address of an object, but not its type. For example, a memory allocation function void *malloc(size_t size); returns a pointer to void which can be casted to any type.

# TYPE CONVERSION IN C

The type conversion process in C is basically converting one type of data type to other perform operation. The conversion is done only between those types where the conversion is possible, e.g., char to int and vice versa. There are two types of conversion:

# 1. Implicit Type Conversion

This type of conversion is usually performed by the compiler when necessary without any commands by the user. Thus, it is also called "Automatic Type Conversion".

The compiler usually performs this type of conversion when a particular expression contains more than one data type. In such cases, either promotion or demotion takes place.
