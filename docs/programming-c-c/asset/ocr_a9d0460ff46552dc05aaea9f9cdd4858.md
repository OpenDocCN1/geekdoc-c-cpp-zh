# Multiple Choice Questions

+   1. Which of the following cannot be a variable name in C?
(a) Volatile (b) True (c) friend (d) export

+   2. All kinds of C are in
(a) Lower Case letters (b) Upper Case letters

+   3. Which of the following is a User-defined type?
(a) typedef
(b) typedef[Mon, Tue, Wed, Thu, Fri] Workdays;
(c) struct [char name[10], int];
(d) All of the mentioned

+   4. Which is correct with respect to size of the data types?
(a) char < float (b) char > float
(c) char << double (d) double > char

+   5. Which of the following is not an arithmetic operation?
(a) a *= 20; (b) a /= 30; (c) a %= 40; (d) a != 50;

+   6. The format identifier "%s" is also used for data type.
(a) char (b) double (c) float (d) int

+   7. How many keywords are there in C?
(a) 31 (b) 32 (c) 64 (d) 63

+   8. Result of a logical or relational expression in C is
(a) True or False
(b) 0 or 1

+   9. Which of the following is not a logical operator?
(a) ! (b) && (c) || (d)

+   10. The precedence of arithmetic operators is (from highest to lowest)
(a) %, *, /, +, - (b) %, *, /, +, - (c) %, *, /, +, - (d) +, -, *, /

**Answers:** 1. (a), 2. (a), 3. (d), 4. (c), 5. (d), 6. (d), 7. (a), 8. (b), 9. (d), 10. (a)
