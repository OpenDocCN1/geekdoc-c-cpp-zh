### 2. Static Member Functions in C++

Static functions have class scope. They cannot modify any non-static data members or call non-static member functions. Static members functions do not have implicit this argument. That is why they can work only with static members of class. Static functions can be declared using the following format:

```cpp
static ReturnType FunctionName(ParameterList);
```

Static is something that holds its position. Static is a keyword which can be used with data members as well as the member functions. We will discuss this in details later. As of now, we will discuss its usage with member functions only.

A function is made by using static keyword with function name. These functions work for the class as a whole rather than for a particular object of a class.
It can be called using the object and the direct member access . operator. But, its more typical to call a static member function by itself, using class name and scope resolution :: operator.

Example:

```cpp
class Raman
{
    public:
        static void f()
        {
            // statement
        }
};
int main()
{
    Raman::f(); // calling member function directly with class name
}
```

### 3. Const Member Functions in C++

Const keyword makes variables constant, that once defined, their values cannot be changed.

Const function is used to specify a "read-only" function. This type of function cannot modify any non-static data members or call other non-const member functions. If you want to modify a constant function, you have to add const keyword after parenthesis of parameter list:

```cpp
ReturnType FunctionName(ParamList) const;
// basic syntax of const Member Function

void func() const
{
    // statement
}
```

When used with member function, such member functions can never modify the object or its related data members.

### 4. Inline Functions in C++

All member functions defined inside the class definition are by default declared as Inline.

Inline functions are actual functions, which are copied everywhere during compilation, like preprocessor macro, the overhead of function calling is reduced. All the functions defined inside class definition are by default inline, but you can also make any non-class function inline by using keyword **inline** with them.

For an inline function, declaration and definition must be done together.

```cpp
inline void fun(int a)
{
    return a++;
}
```

#### Some Important Points about Inline Functions

- 1. We must keep inline functions small, inline functions have better efficiency.
- 2. Inline functions increase efficiency, but we should not make large functions inline.
- 3. Hence, it is advised to define large functions outside class using scope resolution :: operator, because if we define such functions inside class, they become inline automatically.
- 4. Inline functions are kept in Symbol Table by the compiler.

#### Limitations of Inline Functions

- 1. Large Inline functions causes Cache misses and affect performance.
- 2. Compilation overhead of copying the function everywhere is negligible for small programs but makes a difference in code bases.
- 3. Also, if we require address of the function, compiler cannot perform inlining on such functions. Because for providing address to a function, compiler will have to allocate storage to it.

## Friend Functions in C++

Friend function is a function that is not member function of a class, but it has access to private and protected members of a class. Friend function is declared and implemented outside of class as a simple function. But the class has to grant "friend" privileges by declaring this function with friend keyword inside the class declaration. Here is an example of creating a friend function for class:

Example:

```cpp
bool checkSalary(Raman v)
{
    if (v.salary > 40000) //salary is protected data member
        return true;
    else
        return false;
}
```

This is a function with a global scope. Inside the class, we have to add its declaration with friend keyword:

```cpp
friend bool checkSalary(Raman v);
```

Now, you can call check Salary from main as a simple function:

```cpp
bool result = checkSalary(raman);
```

Hence, friend functions can access private data members by creating object of the class. Similarly, we can also make function of some other class as friend, or we can also make an entire class as friend class.

When we make a class as friend, all its member functions automatically become friend functions.

Friend Functions is a reason, because C++ is not as a pure Object Oriented language. Because it violates the concept of Encapsulation.
