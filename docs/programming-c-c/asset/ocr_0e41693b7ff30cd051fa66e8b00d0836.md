# Calling a function

A function gets called when the function name is followed by a semicolon. When the function is called, the formal parameters are automatically initialized to the actual parameters used in the function. The number of actual parameters and formal parameters must be equal. Next, the function body is executed. If a return statement is encountered during the execution of the function body, the function terminates execution, returning the value specified in the return statement (if any), as the value of the function.
