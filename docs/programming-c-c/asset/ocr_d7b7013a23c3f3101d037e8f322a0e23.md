# Width Specifier Program:

```
#include <stdio.h> //header file section
int main() {
    printf("\n%2s", "abcdef");
    printf("\n%3s", "abcdef");
    printf("\n%4s", "abcdef");
    printf("\n%5s", "abcdef");
    printf("\n%6s", "abcdef");
    return 0;
}
```

+   * ab
* abc
* abcd
* abcde
* abcdef

Note: Output itself shows the process done by %.2s, %.3s, etc.

scanf to Get Input:

```
#include <stdio.h> //header file section
int main() {
    float a, b, c, d;
    printf("Enter three float numbers:\\n ");
    scanf("\n%f %f %f", "&a,&b,&c");
    d = (a + b + c)/3;
}
```
