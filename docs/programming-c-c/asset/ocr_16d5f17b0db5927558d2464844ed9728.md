# 2. post-increment (variable ++)

In post-increment, first value of variable is used in the expression (initialize another variable) and then increment the value of variable.

Syntax: ++;

Example:

```
#include <stdio.h>
#include <conio.h>
void main() {
  intx,i;
  i=10;
  x=i++;
  printf(":x: %d",x);
  printf(":i: %d",i);
  getch();
}
```

Output:
x: 10
i: 11

In above program, first use the value of i into expression and then increase value of i by 1.
