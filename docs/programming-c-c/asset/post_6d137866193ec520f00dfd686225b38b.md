## DATA TYPES IN C LANGUAGE

Data types specify how we enter data into our programs and what type of
data enter. C language has some predefined set of data types to handle various
kinds of data that we can use in our program. These data types have different
storage capacities.

C language supports two different type of data types:

- 1. Primary data types

These are fundamental data types in C namely integer(int), floating point(float),
character(char) and void.

- 2. Derived data types

Derived data types are nothing but primary data types but a little twisted or
group together like array, structure, union and pointer. These are discussed in
details later.

Data type determines the type of data a variable will hold. If a variable x is declared as int it means x can hold only integer values. Every variable which is used in the program must be declared as what data type it is.

## TYPE CONVERSION IN C

The type conversion process in C is basically converting one type of data type to other perform perform operation. The conversion is done only between those types where the conversion is possible, e.g., char to int and vice versa. There are two types of conversion:

## 1. Implicit Type Conversion

This type of conversion is usually performed by the compiler when necessary without any commands by the user. Thus, it is also called "Automatic Type Conversion".

The compiler usually performs this when an expression contains more than one type. In such cases, either promotion or demotion takes place.

## Rules:

- 1. char or short type operands will be converted to int during an operation and the outcome data type will be int.
- 2. If an operand of long double is present in the expression, then the corresponding operand will also be converted to long double.
- 3. If an operand of float type is present, then the corresponding operand in the expression will also be converted to float type.
- 4. If an operand of unsigned int is present, then the other operand will be converted to unsigned int for the data type.
- 5. If an operand of long int is present, then the other operand will be converted to long int and the final result will be long int.
- 6. If an operand of unsigned int is present, then the other operand will be converted to unsigned int. (Note: OCR repetition)

Now, let's focus on some examples to further understand about type conversions in.

## Example 1:

```
int a = 20;
double b = 20.5;
a + b;
```

Here, first operand is unsigned int and other is of double. So, as per rule 2, the variable will be converted to double. Therefore, the final answer a + b = 40.50000.

## Example 2:

```
char ch='a';
int a = 13;
a + c;
```

Here, first operand is char type and other is of int. So, as per rule 1, the char variable will be converted to int type during the operation and the final answer will be of type int. We know the ASCII value for ch is 97. Therefore, final answer is a + c = 97 + 13 = 110.

## Example 3:

```
char ch='A';
signed int a =60;
a * b;
```

Here, the first operand is char type and the other is of unsigned int. So, as per rule 6, char data type will be converted to unsigned int during the operation. Therefore, the final result will be an unsigned int variable, 65 + 60 = 125.

Thus, all these above illustrations suggest that whenever the compiler deals with different data types in an expression, the operand which is present at the lower rank will be converted to the corresponding data type of the operand with the higher rank.
