```
static datatype var_name1 [= value];
```

示例：

```
static int x = 101;
```

4. 寄存器存储类（Register）
寄存器存储将变量分配在 CPU 寄存器而非主内存中。它的生命周期和可见性与自动变量相同。创建寄存器变量目的是提高访问速度并使程序运行更快。如果寄存器中没有空间，这些变量将存储在主内存中，作用类似于自动存储类变量。因此，只有需要快速访问的变量才应该设为寄存器。

## 寄存器存储类声明语法：

```
register datatype var_name [= value];
```

示例：

```cpp
register int id;
register char a;
```

存储类示例

示例 2：创建自动、全局、静态和寄存器变量的 C++ 程序。

```cpp
#include<iostream>
using namespace std;
int g; //全局变量，初始值为 0
void test_function()
{
    static int s; //静态变量，初始值为 0
    register int r; //寄存器变量
    r=5;
    s=s+r*2;

cout<<"Inside test_function"<<endl;
cout<<"g = <<g<<endl;
cout<<"s = <<s<<endl;
cout<<"r = <<r<<endl;
}
int main() {
	int a; //自动变量
g=25;
a=17;
test_function();
	cout<<"Inside main"<<endl;
	cout<<"a = <<a<<endl;
	cout<<"g = <<g<<endl;
test_function();
	return 0;
}
```

在上述程序中，g 是全局变量，s 是静态变量，r 是寄存器变量，a 是自动变量。我们定义了两个函数，第一个是 main()另一个是 test_function()。由于 g 是全局变量，因此可以在两个函数中使用它。变量 r 和 s 定义在 test_function() 内部，因此只能在该函数内部使用。然而，s 是静态的，在程序结束之前不会被销毁。第一次调用 test_function() 时，r 初始化为 5，s 的值为 10，这是通过语句计算出来的：

```
s=s+2;
```

第一次执行 test_function() 之后，r 被销毁，但 s 仍然保持 10。第二次调用时，r 被创建并初始化为 5。由于 s 初始值为 10，现在 s 的值变为 20。变量 a 定义在 main() 内部，只能在 main() 内部使用。

## 输出：

```
Inside test_function
g = 25
s = 10
r = 5
Inside main
a = 17
g = 25
Inside test_function
g = 25
s = 20
r = 5
```

## 5. 可变（Mutable）存储类

在 C++ 中，可以使用关键字 const 将类对象保持为常量。这不允许在程序执行期间修改类对象的数据成员。但在某些情况下，该常量对象的某些数据成员必须更改。例如，在银行转账期间，必须锁定交易以确保没有信息被更改，但即使如此，它的状态已从“开始”变为了“处理中”再到“已完成”。在这些情况下，我们可以使用 mutable 存储类使这些成员可变。

## mutable 存储类声明语法：

```
mutable datatype var_name1;
```

示例：

```
mutable int x;
mutable char y;
```

mutable 存储类示例

示例 3：创建可变变量的 C++ 程序。

```cpp
#include<iostream>
using namespace std;

class test
{
    mutable int a;
    int b;
public:
    test(int x,int y)
    {
        a=x;
        b=y;
    }
    void square_a() const
    {
        a=a*a;
    }
    void display() const
    {
        cout<<"a = "<<a<<endl;
        cout<<"b = <<b<<endl;
    }
};

int main()
{
    const test x(2,3);
    cout<<"Initial value"<<endl;
    x.display();
    x.square_a();
    cout<<"Final value"<<endl;
    x.display();
    return 0;
}
```

程序定义了一个类 test。它包含一个可变数据成员 a。创建了类 test 的常量对象 x，并使用自定义构造函数初始化数据成员的值。由于 b 是普通数据成员，其值在初始化后无法更改。然而由于 a 是可变的，其值可以被更改，这通过调用 square_a() 方法实现。display() 方法用于显示数据成员的值。

```
Initial value
a = 2
b = 3
Final value
a = 4
b = 3
```

## C 和 C++ 之间的相似之处

- 两种语言都具有相似的语法。
- 两种语言的代码结构相似。
- 两种语言的编译方式相似。
- 它们共享相同的基本语法。几乎所有 C 的运算符和关键字在 C++ 中都存在，且功能相同。
- C++ 的语法比 C 略有扩展，但基础语法是相同的。
- 两者的基本内存模型都非常接近硬件。
- 两种语言都存在栈、堆、文件作用域和静态变量的概念。

示例 3：创建可变变量的 C++ 程序。

```cpp
#include<iostream>
using namespace std;

class test
{
    mutable int a;
    int b;
public:
    test(int x,int y)
    {
        a=x;
        b=y;
    }
    void square_a() const
    {
        a=a*a;
    }
    void display() const
    {
        cout<<"a = "<<a<<endl;
        cout<<"b = <<b<<endl;
    }
};

int main()
{
    const test x(2,3);
    cout<<"Initial value"<<endl;
    x.display();
    x.square_a();
    cout<<"Final value"<<endl;
    x.display();
    return 0;
}
```

程序中定义了一个类 test。它包含一个可变数据成员 a。创建了类 test 的常量对象 x，并使用用户定义的构造函数初始化数据成员的值。由于 b 是普通数据成员，其值在初始化后无法更改。然而由于 a 是可变的，其值可以被更改，这通过调用 square_a() 方法实现。display() 方法用于显示数据成员的值。

```
Initial value
a = 2
b = 3
Final value
a = 4
b = 3
```

4. 寄存器存储类（Register）
寄存器存储将变量分配在 CPU 寄存器而非主内存中。它的生命周期和可见性与自动变量相同。创建寄存器变量目的是提高访问速度并使程序运行更快。如果寄存器中没有空间，这些变量将存储在主内存中，作用类似于自动存储类变量。因此，只有需要快速访问的变量才应该设为寄存器。

## 寄存器存储类声明语法：

```
register datatype var_name [= value];
```

示例：

```cpp
register int id;
register char a;
```

存储类示例

示例 2：创建自动、全局、静态和寄存器变量的 C++ 程序。

```cpp
#include<iostream>
using namespace std;
int g; //全局变量，初始值为 0
void test_function()
{
    static int s; //静态变量，初始值为 0
    register int r; //寄存器变量
    r=5;
    s=s+r*2;

cout<<"Inside test_function"<<endl;
cout<<"g = <<g<<endl;
cout<<"s = <<s<<endl;
cout<<"r = <<r<<endl;
}
int main() {
	int a; //自动变量
g=25;
a=17;
test_function();
	cout<<"Inside main"<<endl;
	cout<<"a = <<a<<endl;
	cout<<"g = <<g<<endl;
test_function();
	return 0;
}
```

在上述程序中，g 是全局变量，s 是静态变量，r 是寄存器变量，a 是自动变量。我们定义了两个函数，第一个是 main() 另一个是 test_function()。由于 g 是全局变量，因此可以在两个函数中使用它。变量 r 和 s 定义在 test_function() 内部，因此只能在该函数内部使用。然而，s 是静态的，在程序结束之前不会被销毁。第一次调用 test_function() 时，r 初始化为 5，s 的值为 10，这是通过语句计算出来的：

```
s=s+2;
```

第一次执行 test_function() 之后，r 被销毁，但 s 仍然保持 10。第二次调用时，r 被创建并初始化为 5。由于 s 初始值为 10，现在 s 的值变为 20。变量 a 定义在 main() 内部，只能在 main() 内部使用。

## 输出：

```
Inside test_function
g = 25
s = 10
r = 5
Inside main
a = 17
g = 25
Inside test_function
g = 25
s = 20
r = 5
```

## 5. 可变（Mutable）存储类

在 C++ 中，可以使用关键字 const 将类对象保持为常量。这不允许在程序执行期间修改类对象的数据成员。但在某些情况下，该常量对象的某些数据成员必须更改。例如，在银行转账期间，必须锁定交易以确保没有信息被更改，但即使如此，它的状态已从“开始”变为了“处理中”再到“已完成”。在这些情况下，我们可以使用 mutable 存储类使这些成员可变。

## mutable 存储类声明语法：

```
mutable datatype var_name1;
```

示例：

```
mutable int x;
mutable char y;
```

mutable 存储类示例

示例 3：创建可变变量的 C++ 程序。

```cpp
#include<iostream>
using namespace std;

class test
{
    mutable int a;
    int b;
public:
    test(int x,int y)
    {
        a=x;
        b=y;
    }
    void square_a() const
    {
        a=a*a;
    }
    void display() const
    {
        cout<<"a = "<<a<<endl;
        cout<<"b = <<b<<endl;
    }
};

int main()
{
    const test x(2,3);
    cout<<"Initial value"<<endl;
    x.display();
    x.square_a();
    cout<<"Final value"<<endl;
    x.display();
    return 0;
}
```

程序中定义了一个类 test。它包含一个可变数据成员 a。创建了类 test 的常量对象 x，并使用用户定义的构造函数初始化数据成员的值。由于 b 是普通数据成员，其值在初始化后无法更改。然而由于 a 是可变的，其值可以被更改，这通过调用 square_a() 方法实现。display() 方法用于显示数据成员的值。

```
Initial value
a = 2
b = 3
Final value
a = 4
b = 3
```
