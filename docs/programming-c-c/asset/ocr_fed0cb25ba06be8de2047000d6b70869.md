# **Call by Value**

**Call by value** method of passing arguments to a function copies the actual value of an argument into the formal parameter of the function. In this case, changes made to the parameter inside the function have no effect on the argument.

By default, C programming uses *call by value* to pass arguments. In general, it means the code within a function cannot alter the arguments used to call the function. Consider the function `swap()` definition as follows.

```
/*definitionintwapvalues*/
void swap(int x,int y)
{
    int temp;
    temp=x;/*savevalueofx*/
    x=y;
    /*putintx*/
    y=temp;/*putinty*/
    return;
}
```
