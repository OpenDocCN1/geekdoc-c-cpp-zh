\n is used for formatting purposes which means the value will be printed on
a new line.

# break Statement with while loop

The break statement is used mainly in the switch statement. It is also useful
for immediately stopping a loop.

We consider the following program which introduces a break to exit a while

```
#include <stdio.h>
int main()
{
    int num = 5;
    while (num > 0)
{
        if (num == 3)
            break;
        printf("%d\n", num);
        num--;
    }
}
```

**Output: 5 4**

# continue Statement with while loop

When you want to skip to the next iteration but remain in the loop, you should
use the continue statement.

**Example:**

```
#include <stdio.h>
int main() {
    int nb = 7;
    while (nb > 0)
{
    nb--;
}
```
