# Description of All Keywords in C

auto

The auto keyword declares automatic variables.

Example:

```
auto int var1;
```

This statement suggests that var1 is a variable of ANSI storage class auto and type int.

Introduction to C Language, Variables, Data Types and Operators

Variables declared within function bodies are automatic by default. They are recreated each time a function is executed.

Since automatic variables are local to a function, they are also called local variables.

# break and continue

The break statement makes program jump out of the innermost enclosing loop (while, do, or for switch statements) explicitly.

The continue statement skips the certain statements inside the loop.

```c
for (i=1;i<=10;++i)
{
    if (i=3)
        continue;
    if (i=7)
        break;
    printf("%d ",i);
}
```

Output
1 2 4 5 6

When i is equal to 3, continue statement comes into effect and skips 3. When i is equal to 7, break statement comes into effect and terminates the for loop.

# switch, case and default

The switch and case statement is used when a block of statements has to be executed among many blocks.

# Example:

```c
switch(expression)
{
    case '1':
        //some statements to execute when 1
        break;
    case '5':
        //some statements to execute when 5
        break;
    default:
        //some statements to execute when default;
}
```

# enum

Enumeration types are declared in C programming using keyword enum.

Example:

```c

{
    hearts;
    spades;
    clubs;

```

Here, an enumerated variable suit is created having tags: hearts, spades, clubs and diamonds.

# goto

The goto statement is used for unconditional jump to a labeled part of the program.

Example:
```c
int main() {
    int i = 0;
    start:
    printf("%d ", i);
    i++;
    if (i < 5)
        goto start;
    return 0;
}
```

# if

The if statement is used to make decisions based on a condition.

```c

    printf("i is 1.");
}
```

# else

The else statement is used when the if condition is false.

```c
if (i == 1) {
    printf("i is 1.");
} else {
    printf("i is not 1.");
}
```

# else if

The else if statement is used to check multiple conditions.

```c

    printf("one");
} else if (i == 2) {
    printf("two");
}
```

The ternary operator (?: ) is a shorthand for if-else statement.

```c

```

# variables

Variables are memory locations used to store data that can be changed during program execution.

```c

float y = 5.5;
```

# types

Types define the type of data a variable can hold.

- int: integer numbers
- float: floating point numbers
- double: double precision floating point numbers
- char: single characters
- void: no return value

# functions

Functions are blocks of code that perform a specific task.

```c
int add(int a, int b) {
    return a + b;
}
```

# arrays

Arrays are collections of elements of the same type stored in contiguous memory locations.

```c
int arr[5] = {1, 2, 3, 4, 5};
```

# pointers

Pointers are variables that store the address of another variable.

```c
int x = 5;
int *ptr = &x;
```

# structures

Structures are user-defined types that group different types of variables together.

```c
struct Student {
    int id;
    char name[50];
};
```

# unions

Similar to structures, but members share the same memory location.

```c
union Data {
    int i;
    float f;
};
```
