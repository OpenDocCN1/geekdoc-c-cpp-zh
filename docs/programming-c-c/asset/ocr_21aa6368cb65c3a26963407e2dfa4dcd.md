Unformatted input/output functions are used to read a single input from the user at console and it allows us to display the value in the output from the user at console. Reads a single character from the user at the console, without echoing it.

# C Unformatted Functions

Unformatted input and output functions are only work with character data type. Unformatted input and output functions do not require any format specifiers because they work with character data type.
