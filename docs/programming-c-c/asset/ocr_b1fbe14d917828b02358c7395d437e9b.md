# 23. Write a C Program to make a simple calculator using switch case.

```
#include <stdio.h>

int main() {
    int num1,num2;
    float result;
    char ch;//to store operator choice

    printf("Enter first number: ");
    scanf("%d",&num1);
    printf("Enter second number: ");
    scanf("%d",&num2);

    printf("Choose operation to perform (+,-,*,/%,@): ");
    scanf("%c",&ch);

    result=0;
    switch(ch) {
        case '+':
            result=num1+num2;
            break;
        case '-':
            result=num1-num2;
            break;
        case '*':
            result=num1*num2;
    }
```
