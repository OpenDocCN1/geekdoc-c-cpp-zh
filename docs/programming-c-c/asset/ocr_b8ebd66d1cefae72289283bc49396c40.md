# Introduction to C Language, Variables, Data Types and Operators

```
int x,i;
i=10; x=i--;
x=i--;
printf("x: %d",x);
printf("i: %d",i);
getch();
}
Output:
x: 10
i: 9
```

In above program, first use the value of x in expression and then decrease the value of i by 1.
