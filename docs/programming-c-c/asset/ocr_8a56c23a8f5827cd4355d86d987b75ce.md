Let's see an example of #define to define a constant.

```
#include <stdio.h>
#define PI 3.14
main() {
    printf("%f",PI);
}
**Output:
3.140000
```

# #undef

The #undef preprocessor directive is used to undefine the constant or macro defined by #define.

Syntax:

Let's see a simple example to define and undefine a constant.

```
#include <stdio.h>
#define PI 3.14
#undef PI
main() { printf("%f",PI); }
**Output:** Compile Time Error: 'PI' undeclared
```

The #undef directive is used to undefine the preprocessor constant to a limited scope so that you can declare constant again.

# #ifdef

The #ifdef preprocessor directive checks if macro is defined by #define. If yes, it executes the code.

Syntax:

```
#ifdef MACRO
//code
#endif
```
