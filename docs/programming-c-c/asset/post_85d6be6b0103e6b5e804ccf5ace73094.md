- *Function Overloading*: Function overloading is using a single function name to perform different types of tasks.
- When there are multiple functions with the same name but different parameters, then these functions are said to be overloaded. Functions can be overloaded by change in number of arguments and/or change in type of arguments.

// C++ Program for Function Overloading

```cpp
#include <bits/stdc++.h>
using namespace std;
class Commerce {
    public:
    // function with 1 int parameter
    void hello(int x) {
        cout << "value of x is " << x << endl;
    }

    // function with same name but 1 double parameter
    void hello(double x) {
        cout << "value of x is " << x << endl;
    }
};
```

```cpp
// function with same name and 2 int parameters
void hello(int x, int y)
{
    cout << "value of x and y is " << x << ", " << y << endl;
}
```

```cpp
int main() {
    Commerce obj1;

// Which function is called will depend on the parameters passed
// The first 'hello' is called
obj1.hello(7);
// The second 'hello' is called
obj1.hello(9,132);
// The third 'hello' is called
obj1.hello(85,64);
return 0;
}
```

# Output:

value of x is 7
value of x is 9.132
value of x and y is 85, 64

In the above example, a single function named hello acts differently in three different situations which is the property of polymorphism.

## Compile-time Polymorphism Example:

In this example, we have two functions with same name but different number of arguments. Based on how many parameters we pass during function call determines which function is to be called, it is considered as an example of polymorphism because in different conditions the output is different. Since, the call is determined during compile time thats why it is called compile-time polymorphism.

```cpp
#include <iostream>
using namespace std;
class Add {
public:
    int sum(int num1, int num2){
        return num1+num2;
    }
    int sum(int num1, int num2, int num3){
        return num1+num2+num3;
    }
};
int main() {
    Add obj;
    //This will call the first function
    cout<<"Output: "<<obj.sum(10, 20)<<endl;
    //This will call the second function
    cout<<"Output: "<<obj.sum(11, 22, 33); << endl;
    return 0;
}
```

## 2. Runtime Polymorphism
Function ordering is an example of Runtime polymorphism.

*Function Overriding*: When child class declares a method, which is already present in the parent class, then this is called function overriding. Here, the child class overrides the parent class.

In case of function overriding, we have two definitions of the same function, one is parent class and one in child class. The call to the function is determined at runtime to decide which definition of the function is to be called. That is the reason, it is called runtime polymorphism.

# Example of Runtime Polymorphism

// C++ Program for Function Overriding

```cpp
#include <bits/stdc++.h>
using namespace std;

class base {
public:
    virtual void print ()
    { cout<< "print base class" <<endl; }

    void show ()
    { cout<< "show base class" << endl; }
};

class derived:public base {
public:
    void print ()             //print () is already virtual function in derived class,
    // we could also declared as virtual print () explicitly
    { cout<< "print derived class" << endl; }

    void show ()
    { cout<< "show derived class" << endl; }
};

//main function
int main() {
    base *bptr;
    derived d;
    bptr = &d;
    //virtual function, binded at runtime (Runtime polymorphism)
    bptr->print();

// Non-virtual function, bindeat at compile time
    bptr->show();

    return 0;
}
```
Output:
print derived class
show base class

# Inheritance

The capability of a class to derive properties and characteristics from another class is Inheritance. Inheritance is an important feature of object oriented programming used for code reusability. Inheritance allows us to inherit all the code (except declared as private) of one class to another class.

- **Derived Class:** The class that inherits properties from another class is called Derived Class or Sub Class.
- **Base Class:** The class whose properties are inherited by derived class is called Base Class or Super Class.

![](img/967bcdbdba6f2e1f56642982e8b39e66_244_0.png)

Hierarchical Inheritance with Class Shape

- *Reusability*: Inheritance supports the concept of "reusability", i.e., when we want to create a new class we want and there is already a class that includes some of the code that we want, we can derive our new class from the existing class. By doing this, we are reusing the fields and methods of the existing class.

# Modes of Inheritance

1. **Public Mode**: If we derive a sub class from a public base class, then the public member of the base class will become public in the derived class and protected members of the base class will become protected in derived class.
2. **Protected Mode**: If we derive a sub class from a protected base class, then both public member and protected members of the base class will become protected in derived class.
3. **Private Mode**: If we derive a sub class from a private base class, then both public member and protected members of the base class will become private in derived class.

# TYPES OF INHERITANCE

Different languages offer different types of inheritance. However, the basic idea remains that derived class gets access to the (non-private) members of the base class. C++ is very flexible in inheritance and provides the following types.

## Single Inheritance

This is the basic type of inheritance where the parent class has exactly one child and the child class has exactly one parent, then this kind of inheritance is called inheritance.

Syntax:

```cpp
class subclass_name : access_mode base_class
{
    //body of subclass
};
```

Example:

# C++ Program to Explain Single Inheritance

```cpp

        cout << "This is a Vehicle" << endl;
    }

// sub class derived from two classes

// main function
```

## Multiple Inheritances

In this type of inheritance, a child class has more than one parent classes and hence inheriting more than one base class. Advantage of this kind of inheritance is that one class accesses the members of more than one classes thus taking full advantage of inheritance. This is a complex type of inheritance and some computer languages (like Java, C#, C#, VB.Net, etc.) do not support this kind of inheritance but as C++ is very flexible in inheritance, so supports multiple inheritances as well. };
