In the above example, the operator '+' is overloaded. The operator '+' is an addition operator and can add two numbers (integers or floating point) but here the operator is made to perform addition of two imaginary or complex numbers.

+   * Function Overloading: Function overloading is using a single function name to perform different types of tasks.
* When there are multiple functions with the same name but different parameters, then these functions are said to be overloaded. Functions can be overloaded by change in number of arguments and/or change in type of arguments.

// C++ Program for Function Overloading

```
#include <bits/stdc++.h>
using namespace std;
class Commerce {
    public:
    // function with 1 int parameter
    void hello(int x) {
        cout << "value of x is " << x << endl;
    }

    // function with same name but 1 double parameter
    void hello(double x) {
        cout << "value of x is " << x << endl;
    }
}
```
