# Some Commonly Used Library Functions in C Language

Standard Library Functions are basically the inbuilt functions in the C compiler that makes things easy for the programmer.

Every C program has at least one function, i.e., the main() function. The main() function is also a standard library function in C since it is inbuilt and conveys specific meaning to the C compiler.

# <stdio.h>

This is the basic header file used in almost every program written in the C language.

It stands for standard input and standard output to perform input-output functions, some of which:

+   - printf() To display output on the screen.
- scanf() To take input from the user.
- getchar() To return characters on the screen.
- putchar() To display output as a single character on the screen.
- fgets() To take a line as an input.
- puts() To display a line as an input.
- fopen() To open a file.
- fclose() To close a file.

# <conio.h> with

It is used to perform console input and console output operations like clscr() to clear the screen (works in Turbo C) and get() to get the character from the keyboard.

# SIGNIFICANCE OF STANDARD LIBRARY FUNCTIONS IN C

# Usability

Standard library functions allow the programmer to use the pre-existing codes available in the C compiler without the need to define his own code by deriving the logic to perform certain basic functions.

# Flexibility

A wide variety of programs can be made by the programmer by making slight modifications while using the standard library functions in C.
