# Calling a function

A function gets called when the function name is followed by a semicolon. When the function is called, the formal parameters are automatically initialized to the actual parameters used in the function. The number of actual parameters and formal parameters must be equal. Next, the function body is executed. If a return statement is encountered during the execution of the function body, the function terminates execution, returning the value specified in the return statement (if any), as the value of the function.

# Formatted and Unformatted Functions:

## Formatted Functions

- They require formatted string to produce formatted results.
- They can be used for both reading and writing of all data values.
- The formatted functions return values after execution.

### C Formatted IO Functions

Input data or output results are formatted as per requirement. Formatted function improves the readability of the input and output. Formatted functions can be used to read and write data of all data type (char, int, float, double). Formatted input and output functions require format specifiers (%c, %d, %f, %lf) to identify the type of data.

### scanf() Function

scanf() reads all types of data value from input devices (or) from a file. The address operator '&' is to indicate the memory location of the variable. This memory location is used to store the data which is read through keyboard.
