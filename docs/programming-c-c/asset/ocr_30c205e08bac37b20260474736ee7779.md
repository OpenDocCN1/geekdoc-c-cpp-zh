History of C language is interesting to know. Here, we are going to discuss a brief history of the C language. C programming language was developed in 1972 by Dennis Ritchie and Brian Kernighan at bell laboratories of AT&T (American Telephone & Telegraph), located in the USA. Dennis Ritchie is the founder of C language. It was developed to overcome the problems of previous languages such as B, BCPL, etc. Initially, C was developed to be used in UNIX operating system inherits many features of previous languages such as B and BCPL.

Let's see the programming languages that were developed before C language.
