# Difference between Flowchart and Algorithm

Difference between flowchart and algorithm is the same as the difference between movie and its story, or the difference between a fiction novel and the story, or the difference between a comics or the story.

Algorithms and flowcharts are two different tools used for creating new programs, especially while a computer programming. An algorithm is a step-by-step analysis of the process, while a flowchart explains the steps of a program in a graphical way.

| Flowchart | Algorithm |
|---|---|n| Block by block information diagram representing the data flow. | Step-by-step instruction representing the process of any solution |
| It is a pictorial representation of a process. | It is step-wise analysis of the work to be done. |
