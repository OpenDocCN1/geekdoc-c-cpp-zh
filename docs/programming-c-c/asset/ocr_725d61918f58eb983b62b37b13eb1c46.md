printf("Global inside func1 is %d",global); // Would print the global variable successfully.

printf("Local inside func1 is %d", local); /* It would produce an error,
because local is a local variable and it can be accessed
only inside main function. */

Clearly, as mentioned in the comment, the printing of global variable would be
done, but that of local variable would produce an error, as the variable named local
actually local to the main function() and hence can be accessed only through that
function not from any other function, but for global variable, it can be accessed by
all functions/blocks program is using.

Here, our variable named global has scope and lifetime, hence it outlines
im until the program execution is completed and can be accessed by any
function/block too. But in case of our local variable, it may outlives in memory
till program execution is completed but it can be accessed from within the
function or block it is defined.

The basic problem here can be, we can have variable with same name defined
as a global as well as local variable, and hence, it would be ambiguous as to which
variable we want to actually refer to. We can resolve this issue in C++ (Advancement
of C language) by the use of a special operator known as scope resolution operator.

# DATA TYPES IN C LANGUAGE

Data types specify how we enter data into our programs and what type of
data enter. C language has some predefined set of data types to handle various
kinds of data that we can use in our program. These data types have different
storage capacities.

C language supports two different type of data types:

+   1. Primary data types

These are fundamental data types in C namely integer(int), floating point(float),
character(char) and void.

+   2. Derived data types

Derived data types are nothing but primary data types but a little twisted or
group together like array, structure, union and pointer. These are discussed in
details later.
