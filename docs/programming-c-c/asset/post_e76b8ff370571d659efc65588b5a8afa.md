strlen()

This function returns the length of the string, i.e., the number of characters in the string excluding the terminating NULL character.

It accepts a single argument which is pointer to the first character of the string.

For example: strlen("uresh")

It returns the value 6.

In array version to calculate length:

```c
int strlen(char str[])
{
    int i=0;
    while(str[i]='\0')
    {
        i++;
    }
    return i;
}
```

Example:
#include<stdio.h>
#include<string.h>
void main()

}
```

# strcpy()

This function is used to copying one string to another string. The strcpy(str1,str2) copies str2 to str1 including the NULL character. Here, str2 is the source string str1 is the destination string.

The old content of the destination string str1 are lost. The function returns a pointer to destination string str1.

Example:

```c
#include <stdio.h>
#include <string.h>
void main()
{
    char str1[50], str2[50];
    printf("Enter a string:");
    gets(str2);
    strcpy(str1,str2);
    printf("strcpy(str1,str2): %s\n",str1);
}
```

# strcat()

This function is used to append one string to the end of another string. The strcat(str1,str2) appends str2 to the end of str1 including the NULL character. Here, str1 is the destination string str2 is the source string.

**Example:**

```c
#include <stdio.h>
#include <string.h>
void main()
{
    char str1[50], str2[50];
    printf("Enter first string:");
    gets(str1);
    printf("Enter second string:");
    gets(str2);
    strcat(str1,str2);
    printf("strcat(str1,str2): %s\n",str1);
}
```
