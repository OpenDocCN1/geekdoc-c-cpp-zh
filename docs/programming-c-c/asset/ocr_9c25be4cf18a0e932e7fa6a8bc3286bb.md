# Syntax:

+   - variable;

# Example:

```
#include<stdio.h>
#include<conio.h>
void main() {
  intx,i;
  i=10;x= -i;
  x= --i;
  printf("x: %d",x);
  printf(":i: %d",i);
  getch();
}
```

# Output

x: 9
i: 9

In above program, first decrease the value of i and then value of i used in expression.

# 2. post-decrement (variable --)
