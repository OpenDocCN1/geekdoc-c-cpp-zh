# 层次级继承

在这一类型的继承中，一个父类可以有多个子类。它允许在多个派生类中访问同一个类的代码。几乎所有支持面向对象编程的计算机语言都支持层级继承。下图描述了这种继承方式。

![](img/967bcdbdba6f2e1f56642982e8b39e66_249_0.png)

# 实现层次级继承的 C++ 程序

```cpp
#include <iostream>
using namespace std;

// base class
class Vehicle
{
public:
    Vehicle()
    {
        cout << "This is a Vehicle" << endl;
    }
}

// first sub class
class Car: public Vehicle
{
}

// second sub class
class Bus: public Vehicle
{
};
```

```cpp
// main function
int main() {
    // creating object of sub class will
    // invoke the constructor of base class
    Car obj1;
    Bus obj2;
    return 0;
}
```

Output:

This is a Vehicle
This is a Vehicle

# 多级继承

正如名称所示，继承可以扩展到两个以上的级别。在这种类的继承中，同一个类可能既是父类的子类，又是其子类的父类。在图中，Class2 是 Class1 的子类，同时也是 Class3 的父类。

![](img/967bcdbdba6f2e1f56642982e8b39e66_250_0.png)

# 实现多级继承的 C++ 程序

```cpp
#include <iostream>
using namespace std;

// base class
class Vehicle
{
public:
    Vehicle()
    {
        cout << "This is a Vehicle" << endl;
    }
}
class fourWheeler: public Vehicle
{
public:
    fourWheeler()
    {
        cout<<"Objects with 4 wheels are vehicles"<<endl;
    }
}
// sub class derived from two base classes
class Car: public fourWheeler{
public:
    car()
    {
        cout<<"Car has 4 Wheels"<<endl;
    }
}
// main function
int main()
{
    //creating object of sub class will
    //invoke the constructor of base classes
    Car obj;
    return 0;
}
```

Output:
This is a Vehicle
Objects with 4 wheels are vehicles
Car has 4 Wheels

# 混合（虚）继承

这种继承是上述讨论的不同类型继承的集合。例如，在下图所示的，一个子类可能有多个父类，且在多级继承中，一个类可能有多个子类。

![](img/967bcdbdba6f2e1f56642982e8b39e66_252_0.png)

如上图所示，Class1 有多个子类，Class5 有多个父类。这里也存在多级继承。你可以组合之前讨论的任何类型的继承来形成混合继承。

#include <iostream>

# 消息传递

对象通过相互发送和接收信息进行通信。一个对象的消息是执行某个过程的请求，并将调用接收对象中的函数以生成所需的结果。消息传递涉及指定对象的名称、函数的名称以及要发送的信息。
