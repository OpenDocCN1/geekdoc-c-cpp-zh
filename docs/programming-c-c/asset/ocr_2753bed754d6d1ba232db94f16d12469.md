# Inheritance

The capability of a class to derive properties and characteristics from another class is Inheritance. Inheritance is an important feature of object oriented programming used for code reusability. Inheritance allows us to inherit all the code (except declared as private) of one class to another class.

+   - **Derived Class:** The class that inherits properties from another class is called Derived Class or Sub Class.
- **Base Class:** The class whose properties are inherited by derived class is called Base Class or Super Class.
