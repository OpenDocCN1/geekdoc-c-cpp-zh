# 控制语句

在 'C' 程序中，语句是按顺序执行的。当语句周围没有条件时，就会发生这种情况。如果你为一个语句块设置某些条件，执行流可能会根据条件评估的结果而改变。这个过程在 'C'语言中被称为决策。决策语句也称为控制语句。

在 'C' 编程中，可以通过以下结构实现条件语句：

- 1. if 语句
- 2. if-else 语句
- 3. if-else 阶梯
- 4. 嵌套 if-else 语句

它也被称为分支，因为程序根据评估的条件的结果来决定执行哪条语句。

# if 语句

它是强大的条件语句之一。if 语句负责修改程序的执行流。if 语句始终与条件一起使用。在执行 If 体内的任何语句之前，会先评估条件。

![](img/967bcdbdba6f2e1f56642982e8b39e66_64_0.png)

if 语句的语法如下：

| if (condition) |
| :--- |
| instruction; |

条件评估结果为真或假。真始终是一个非零值，而假是一个包含零的值。指令可以是单条指令，也可以是受花大括号 `()` 包围的代码块。

下面的程序说明了 'C' 编程中 if 结构的使用：

```c
#include<stdio.h>
int main()
{
    int num1=1;
    int num2=2;
    if(num1<num2) //test-condition
        printf("num1 is smaller than num2");
    }
    return 0;
}
```

输出：
num1 is smaller than num2

上面的程序说明了使用 if 结构来检查数字的相等性。

![](img/967bcdbdba6f2e1f56642982e8b39e66_65_0.png)

- 1. 在上面的程序中，我们初始化两个变量 num1 和 num2，值分别为 1 和 2。
- 2. 然后，我们使用 if 配合测试表达式来检查哪个数字最小，哪个数字最大。我们在 if 结构中使用了一个关系表达式。由于 num1 的值小于 num2，该条件将评估为真。
- 3. 因此，它将打印 If 块内部的语句。之后，控制将移动到块外部，程序将以成功的结果终止。

# 嵌套 if

有时，我们编写不带任何 else 部分的嵌套 if-else 结构。有时，这些结构通常被称为嵌套-if 结构。

语法：

```c
if(cond1) {
    if(cond2) {
        if(cond3) {
        }
    }
}
```

# if-else 语句

if-else 语句是 if 的扩展版本。if-else 的流程图如下：

![](img/967bcdbdba6f2e1f56642982e8b39e66_66_0.png)

在这种类型的结构中，如果测试表达式的值为真，则执行真语句块。如果测试表达式的值为假，则执行假语句块。在任何情况下，执行后，控制都将自动转移到出现在 If 块之外的语句。

# if-else 语句的语法：

```c
if (test-expression)
{
    True block of statements
}
else
{
    False block of statements
}
Statements;
```

下面的程序说明了 if-else 结构的使用：

```c
    {
        printf("The value is less than 10");

```

# 多重条件

if-else 阶梯用于在有多个条件需要检查时。每个条件按顺序评估。如果某个条件为真，则执行相应的块，并跳过阶梯剩余。

# 条件表达式

三元运算符是 if-else 语句的简写。

语法：

```c
condition ? expression_if_true : expression_if_false;
```

示例：

```c
int max = (a > b) ? a : b;
```

# 多重条件

上面的程序使用三元运算符找到两个数字的最大值。

```cpp
#include <stdio.h>
int main() {
    int a = 10, b = 20;
    int max = (a > b) ? a : b;
    printf("The maximum is %d", max);
    return 0;
}
```

输出：
The maximum is 20

if-else 阶梯用于在有多个条件需要检查时。每个条件按顺序评估。如果某个条件为真，则执行相应的块，并跳过阶梯剩余。

# Else-if 阶梯

if-else 阶梯是检查多个条件的方法。

语法：

```c
if (condition1) {
    // block 1
} else if (condition2) {
    // block 2
} else if (condition3) {
    // block 3
} else {
    // default block
}
```

根据分数确定等级的示例程序：

```c
#include <stdio.h>
int main() {
    int marks;
    printf("Enter marks: ");
    scanf("%d", &marks);
    if (marks >= 90) {
        printf("Grade: A");
    } else if (marks >= 80) {
        printf("Grade: B");
    } else if (marks >= 70) {
        printf("Grade: C");
    } else {
        printf("Grade: D");
    }
    return 0;
}
```

# 循环

循环用于多次执行一个代码块。C 语言中有三种循环：while、do-while 和 for。

# while 循环

while 循环在执行块之前检查条件。如果条件为真，则执行该块。

语法：

```c
while (condition) {
    // block
}
```

# do-while 循环

do-while 循环执行一次块，然后检查条件。这意味着该块至少执行一次。

语法：

```c
do {
    // block
} while (condition);
```

# for 循环

for 循环用于预先知道迭代次数。

语法：

```c
for (initialization; condition; increment) {
    // block
}
```

# 嵌套循环

嵌套循环是指将一个循环放在另一个循环中。

```c
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        printf("%d %d\n", i, j);
    }
}
```
