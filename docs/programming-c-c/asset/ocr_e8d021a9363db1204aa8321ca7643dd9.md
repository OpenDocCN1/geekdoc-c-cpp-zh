# 24. Write a C Programming Code to create pyramid and pattern.

```
#include <stdio.h>
int main() {
    int i, j, rows;
    printf("Enter number of rows: ");
    scanf("%d", &rows);
    for (i=1; i<=rows; i++) {
        for (j=1; j<=i; j++) {
            printf("* ");
        }
        printf("\n");
    }
    return(0);
}
```

Output
1
1 2
1 2 3
