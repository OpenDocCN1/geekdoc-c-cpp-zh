- 3. 下述C代码的输出是什么？
```c

    int x = 5;
    if(x < 5)
        printf("hello");
    if(x ==5)
        printf("hi");
    else
        printf("no");
}
```
(a) hi (b) hello (c) no (d) 错误

- 4. 下述C代码的输出是什么？
```c

void main() {
    int x = 5;
    if(x < 1)
        printf("Hello");
}
```
(a) 无 (b) 运行时错误 (c) Hello (d) 变化

- 5. 下述C代码的输出是什么？

```c
        a++;
        continue;

```
