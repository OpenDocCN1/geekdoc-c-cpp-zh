+   4. The value assigned to enum names must be some ingeral constant, i.e., the value must be in range from minimum possible integer value to maximum possible integer value.

+   5. All enum constants must be unique in their scope. For example, the following program fails in compilation.

```
enum state {working, failed};
enum result {failed, passed};
int main() { return 0; }
```

Output:
Compile Error: 'failed' has a previous declaration as 'state failed'

# ## UNIONS

A union is a special data type available in C that allows to store different data types in the same memory location. You can define a union with many members, but only one member can contain a value at any given time. Unions provide an efficient way of using the same memory location for multiple purpose.

A union is a user-defined type similar to structures in C programming. Unions are conceptually similar to structures. The syntax to declare/define a union is also similar to that of a structure. The only difference is in terms of storage. In structure, each member has its own storage location, whereas all members of union uses a single shared memory location which is equal to the size of its largest data member.

```
Structure
struct Emp {
    charX; //size 1 byte
    floatY; //size of 4 byte
};
```

```
Unions
union Emp {
    charX;
    floatY;
};
```

```
Memory Sharing
[X | Y]
e (union variable)
allocates storage
equal to largest one
```
