# Conditional Expressions

There is another way to express an if-else statement is by introducing the ?: In a conditional expression, the ?: operator has only one statement associated with the if and the else.

Example:

```
#include <stdio.h>
int main() {
int y;
int x = 2;
y = (x >= 6) ? 6 : x/*This is equivalent to: if (x >= 5)
y = 5; else y = x; */
printf("y =%d",y);
return 0;
}
```

Output :
y = 2

# if-else Ladder

Sometimes, we keep write if-else constructions inside the else parts only. These constructions are known as if-else ladder (or) else-if ladder (or) if-else-if ladder.

The if...else statement executes two different codes depending upon whether the test expression is true or false. Sometimes, a choice has to be made more than two possibilities.

The if...else ladder allows you to check between multiple test expressions and execute different statements.
