# Only one union member can be accessed at a time.

We can access all members of a structure at once as sufficient memory is allocated for all members. However, it's not the case in unions. We can only access a single member of a union at one time. Let's see an example.

```
#include <stdio.h>
unionJob
{
float salary;
int workerNo;
j} j;
int main()
{
tj.salary = 12.3;
j.workerNo = 100;
printf("Salary = %f\n", j.salary);
printf("Number of workers = %d", j.workerNo);
return0;
}
```
