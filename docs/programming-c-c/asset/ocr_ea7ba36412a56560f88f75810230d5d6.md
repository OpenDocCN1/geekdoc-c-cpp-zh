# Pointers, Structures and Unions

| Variables | Memory | Address |
|---|---|--|
| a | 5 | 4214000 |
| b | 6 | 4214004 |
| ptr | 4214000 | 4214008 |

Whenever a variable is declared in a program, system allocates a location, i.e., an address to that variable in the memory, to hold the assigned value. This location has its own address number, which we just saw above.

Let us assume that system has allocated memory location 80F for a variable a.

```
int a = 10;
```

![](bbox=[0.345, 0.518, 0.655, 0.593])

We can access the value 10 either by using the variable a or by using its address 80F.

The question is how we can access a variable using its address? Since the memory addresses are just numbers, they can also be assigned to some other variable. The variables which are used to hold memory addresses are called Pointer variables.

A pointer is therefore nothing but a variable which holds an address of some other variable. And the value of a pointer variable gets stored in another memory location.
