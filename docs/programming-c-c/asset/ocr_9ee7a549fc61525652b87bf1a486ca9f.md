# Overview of Compiler and Interpreter

# Compiler

A compiler takes entire program and converts it into object code which is typically stored in a file. The object code is also refered as binary code and can be directly executed by the machine after linking. Examples of compiled programming languages are C and C++.

# Interpreter

An Interpreter directly executes instructions in a programming or scripting language without previously converting to an object code or machine code. Interpreter reads only one line of source program at a time. Examples of interpreted languages are Perl, Python and Matlab.

# Comparison between Compiler and Interpreter

| Basis for Comparison | Compiler | Interpreter |
| --- | --- | --- |
| Input | It takes an entire program at a time. | It takes a single line of code or instruction at a time. |
| Output | It generates intermediate object code. | It does not produce any intermediate object code. |
| Working mechanism | The compilation is done before execution. | Compilation and execution take place simultaneously. |
