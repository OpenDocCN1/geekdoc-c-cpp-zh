# Preface

We have enormous fulfillment in presenting the first edition book titled
“Programming with C & C++”.

The related matter had been written in simple and lucid style, for an easy understanding by the readers, with sufficient support from real business information. We consider that this book will be of a great help to the beginners.

This book covers Variables, Data Types and Operators, Working with Control Statements, Loops, Functions, Arrays and Strings, Pointers, Structures and Unions, and Object Oriented Concepts Using C++, etc. with suitable programs.
