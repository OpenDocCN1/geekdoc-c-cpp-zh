# Example 1: Program with nested for loop:

```
#include<stdio.h>
int main()
{
    for(int i=0; i<2; i++)
    {
        for(int j=0; j<4; j++)
        {
            printf("%d, %d\n",i, j);
        }
    }
    return 0;
}
```

# Output:

0,0
0,1
0,2
0,3
1,0
1,1
1,2
1,3
