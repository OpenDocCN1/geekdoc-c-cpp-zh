# goto

The goto keyword is used for unconditional jump to a labeled statement inside a function.

Example:

```
for(i=1; i<5; ++i)
{
    if (i==10)
    goto error;
}
printf("i is not 10");
error:
printf("Error, count cannot be 10.");
```

# Output

Error, count cannot be 10

# int

The int keyword declares integer variable.

For example:

int count;

Here, count is a integer variable.

# short, long, signed and unsigned

The short, long, signed and unsigned keywords are type modifiers that alters the meaning of a base data type to yield a new type.

```
short intInteger;
long intInteger;
signed intnormalInteger;
unsigned intpositiveInteger;
```
