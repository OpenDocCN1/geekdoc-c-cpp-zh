We can also limit the number of digits or characters that can be input or output, by adding a numeric string specifier, like "%1d" or "%3s", the first one means a single numeric digit and the second one means 3 characters, hence if you try to input 42, scanf(f) has "%1d", it will take 4 as input. Same is the case for output.

In C language, computer monitor, printer, etc. output devices are treated as files and the process is followed to write output to these devices as would have been followed to output to a file.

Note: The printf() function returns the number of characters printed by it, and scanf() returns the number of characters read by it.
