3. **Multiple Inheritance:** In this type of inheritance, this can be achieved with the help of multiple interfaces, not with a class. In simple words, C# does not support multiple inheritances, but if you want to achieve it, then it can be achieved with the help of interfaces only. For example:

+   - Interface A {}
+   - Interface B {}
+   - Class C: A, B {}

4. **Hierarchical Inheritance:** In this type of inheritance, there is one parent class, and the other derived classes inherit the same parent class to achieve this inheritance. To illustrate:[^16]

```
class BaseClass
{
    public void hello()
    {
        Console.WriteLine("Parent’s Hello Method");
    }
}
class ChildClass : BaseClass
{
    public void World()
    {
        Console.WriteLine("Child’s World Method");
    }
}
```
