or other function variables. Also, you can pass them to other functions as standard variables. If you want to assign a value to a function, you have the following possibilities:

+   - Point the function object to reference some existing method by name.
+   - Create an anonymous function using the lambda expression or delegate and assign it to the function object.
+   - Create a function expression where you are able to add or subtract a function and assign that kind of multicast delegate to the function object

Some examples of assigning values to functions are elaborated in the following listing:

```
Func<double, double> f1 = Math.Sin;
Func<double, double> f2 = Math.Exp;
double y = f1(4) + f2(5); // y=sin(3) + exp(5)
f2 = f1;
y = f2(9);               // y=sin(9)
```

In this case, methods are referred to as ClassName.MethodName. Instead of existing functions, you can dynamically create functions and assign them to variables. In this case, you can use either anonymous delegates or lambda expressions. An example is shown in the following listing:

```
Func<double, double> f = delegate(double x) { return 3*x+1; }
double y = f(4); // y=13
```
