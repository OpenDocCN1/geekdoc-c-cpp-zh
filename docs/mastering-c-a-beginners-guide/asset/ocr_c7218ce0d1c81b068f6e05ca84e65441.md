# Nested Structs

We can declare nested structures, as default structs are placed inside other structs. The following code snippet explains this:

```
```csharp
/* Nested Structure */
using System;
struct student
{
    public String name, last;
}
struct Marks      //Nested Structure
{
    public student s;
    public int math, sci;
}

class nest
{
    public static void Main()
    {
        Marks m;
        m.s.name = "Pardeep";
        m.s.last = "Kumar";
