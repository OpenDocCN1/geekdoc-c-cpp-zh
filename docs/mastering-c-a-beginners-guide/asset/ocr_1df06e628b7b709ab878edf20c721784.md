# What Languages Do Developers Have Access to While Working with .NET?

The .NET Framework is a multi-language framework that allows for interoperability between supported programming languages. The framework supports these programming languages:

+   - **C#:** This is an advanced, OOPs language that gives garbage collection, versioning type-safety, scalability support, and other productivity-increasing features. It’s easy to use and can help you save time while developing apps.
+   
+   - **F#:** This is a cross-platform, open-source language with excellent OOPs features. It is a primary functional programming language .NET.
+   
+   - **Visual Basic:** It is a simple language used to develop object-oriented apps. It provides type safety and uses simple syntax.

Developers can use managed C++, IronPython, Visual COBOL, IronRuby, and many other languages found in the Visual Studio Languages to code in .NET.

To create .NET apps or components, follow these steps:

+   - Install the .NET Framework version that will be used to execute your application.
+   
+   - Select the .NET Framework language that you’ll use to build your project. C#, F#, C++, Visual Basic, and IronRuby are all options.
