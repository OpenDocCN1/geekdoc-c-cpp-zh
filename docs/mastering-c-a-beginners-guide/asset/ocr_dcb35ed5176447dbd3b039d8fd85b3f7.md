```
int result
    = fn.EndInvoke(async);

Console.WriteLine("f({0}) = {1}",
    arguments, result);

"5,3"
);
```

The callback function (or lambda expression in this example) takes a parameter async that has information about the asynchronous call. And when you cast the parameter of the lambda expression to AsyncResults, you can find the original function and call its EndInvoke method. As a result, you can print it on the console window.

Moreover, there is no need to explicitly check in the main code if the function has finished – just let it know what should be done when it is completed.

# Tuples

Tuples are great way to dynamically form a required data structure. You can create tuples by passing a set of fields that belong to the tuple to the Tuple. An illustration of a function that uses tuples is shown below:

```
Random rnd = new Random();
Tuple<double, double> CreateRandomPoint()
{
    var x = rnd.NextDouble() * 10;
    var y = rnd.NextDouble() * 10;
    return Tuple.Create(x, y);
}
```

This function creates a random 2D point within area 10x10.
