```
f = x => 3*x+1;
Y = f(5);
//y=16
```

In this code, we have allocated a delegate that accepts a double argument x and returns a double value 3*x+1. As this dynamically created function matches, Func<double, double>, it can be allocated to the function variable. In the third line, an equivalent lambda expression is allocated. As you can see, the lambda expression is identical to the function: it is just a function representation in the format parameters => return-expression. In the following table, some lambda expressions and equivalent delegates are shown:

| Lambda expression | Delegate |
|---|---|
| () => 3 | delegate(){ return 3; } |
| () => DateTime.Now | delegate(){ return DateTime.Now; }; |
| (x) => x+1 | delegate(int x){ return x+1; } |
| x => Math.Log(x+1)-1 | delegate(int x){ return Math.Log(x+1)-1; } |
| (x, y) => x+y | delegate(int x, int y){ return x+y;} |
| (x, y) => x+y | delegate(string x, string y){ return x+y;} |

Lambda expression must have part for definition of argument names – if lambda expression does not have parameters, empty brackets () should be placed. If there is only one parameter in the list, brackets are not needed. After => sign, you need to put an expression that will be returned.
