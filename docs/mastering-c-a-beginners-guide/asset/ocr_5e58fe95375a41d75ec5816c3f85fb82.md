The Async feature establishes two keywords, async and await, which allows you to write asynchronous code more quickly and intuitively like synchronous code. Before C# 5.0, for writing an asynchronous code, you have to define callbacks (also known as continuations) to capture what happens after an asynchronous process completes. This makes your code and another routine task such as exception handling complicated. Caller information can help you out in tracing, debugging, and creating diagnosis tools. It will help you avoid duplicate codes that are generally invoked in many methods for the same purpose, such as logging and tracing.
