+   - Name of operator.
+   - Index initializers.
+   - Await in catch/finally blocks.
+   - Default values for getter-only properties.

Each of these features is quite interesting in its own right. But if you gaze at them all together, you see an interesting pattern. In this version, C# eliminated language boilerplate to make code more terse and readable. So for fans of clean, simple code, this language version was a huge win.
