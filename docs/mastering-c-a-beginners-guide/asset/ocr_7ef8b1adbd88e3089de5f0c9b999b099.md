2. **Multilevel Inheritance:** In this type of inheritance, there is only one base class, and multiple derived classes are available. If a class is created by using another derived class is known as multilevel inheritance. Example:

```
class BaseClass
{
public void hello()
{
Console.WriteLine("Parent’s Hello
Method");
}
}
class ChildClass : BaseClass
{
public void World()
{
Console.WriteLine("Child’s World
Method");
}
}
class SecondChildClass : ChildClass
{
public void Hi()
{
}
}
```
