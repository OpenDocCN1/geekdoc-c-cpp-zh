having the class in multiple files can be helpful. The partial keywords let a class span multiple source files. When compiled, the elements of the partial types are collected into a single assembly.

There are certain rules for defining a partial class as in the following:

+   - A partial type must have the same accessibility.
+   - The “partial” keyword precedes each partial type.
+   - If the partial type is sealed or omitted, then the entire class will be abstract.

In the following example, we include two files, partial-Part1.cs and partialPart2.cs, and declare a partial class, partialclassDemo, in both classes.

```
partialPart1.cs
using System;
namespace oops
{
    public partial class partialclassDemo
    {
        public void method1()
        {
            Console.WriteLine("method from
part1 class");
        }
    }
}
```
