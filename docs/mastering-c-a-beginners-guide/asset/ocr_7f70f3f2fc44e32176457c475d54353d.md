# Type Constraints

You can constrain the argument for a type parameter to match a particular type. For instance, you could use this to demand that the argument type runs a certain interface. Let’s take a look at this syntax:

```
using System;
using System.Collections.Generic;

public class GenericComparer<T> : IComparer<T>
    where T : IComparable<T>
{
    public int Compare(T x, T y)
    {
        return x.CompareTo(y);
    }
}
```

Let’s briefly explain the purpose of this example before describing how it takes advantage of a type constraint. This class acts as a link between two styles of value comparison that you’ll find in .NET.
