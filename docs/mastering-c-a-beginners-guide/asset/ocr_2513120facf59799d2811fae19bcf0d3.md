# ENUMERATION

Enumeration (or enum) is another value data type in C# that is mainly applied to give the names or string values to integral constants, making the code easy to read and operate with. The main objective of enum is to define our data types (Enumerated Data Types). Enumeration is declared using enum keyword directly inside a namespace, class, or structure.
