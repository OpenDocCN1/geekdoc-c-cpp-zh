# CLASSES AND OBJECTS

A class in C# is explained by the keyword class, followed by an identifier (name) of the class and data members and methods in a different code block.

Classes in C# can include the following elements:

+   - **Fields:** member-variables from a particular type.
+   - **Properties:** These are particular types of elements that extend the functionality of the fields by giving extra data management when extracting and recording it in the class fields.
+   - **Methods:** They devise the manipulation of the data.
