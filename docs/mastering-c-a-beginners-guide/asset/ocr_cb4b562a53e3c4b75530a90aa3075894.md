# Intersection

An intersection is the group of objects that appear in both two lists:

```
var intersectionList1 = new List<int> {1,
2, 3, 4, 5, 6, 7, 8, 9};
var intersectionList2 = new List<int> {2,
4, 6, 8, 10, 12, 14};
var intersection = intersectionList1.
Intersect(intersectionList2);
//{2, 4, 6, 8}
```

# Union

A union is the combined list of unique objects from two separate lists. An item which appears in both lists will only be listed in the union object once:

```
var unionList1 = new List<int> {5, 7, 3,
2, 9, 8};
var unionList2 = new List<int> {9, 4, 6,
1, 5};
var union = unionList1.Union(unionList2);
//{5, 7, 3, 2, 9, 8, 4, 6, 1}
```

# Except

There is also the LINQ method Except(), which produces the elements that are in the first set, but not in the second set:

```
var exceptList1 = new List<int> {1, 2, 3,
4, 5, 6, 7, 8, 9};
var exceptList2 = new List<int> {7, 2, 8,
5, 0, 10, 3};
var except = exceptList1.
Except(exceptList2); //{ 1, 4, 6, 9}
```
