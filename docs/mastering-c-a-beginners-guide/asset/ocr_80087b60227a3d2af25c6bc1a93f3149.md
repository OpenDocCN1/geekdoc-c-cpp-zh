# C# Version 7.1

C# 7.1 was released in August 2017 as part of the 15.3 updates for Visual Studio 2017. The most notable new feature in C# 7.1 is the ability to have an async Main method. With C# 7.0, we started seeing point releases on C#, starting with version 7.1. This marked an increased release cadence for C#. New language features for this release were:

+   - Async Main method,
+   - Default literal expressions,
+   - Inferred tuple element names, and
+   - Pattern matching on generic type parameters.

C# 7.1 also added the language version selection configuration element, as well as new compiler behavior.
