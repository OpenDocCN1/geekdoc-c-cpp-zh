# 2.9 Adding the User Interface

The game is all there, but it needs the following user interfaces:

+   1. A get ready message
+   2. An in-game UI to tell players the current score and high score
+   3. A game over message
+   4. A main menu to return to, after the game is over

There is a little more cheating going on here with the user interface – remember at the start of the chapter when we hid it all? Yeah, the user interface is already there but it needs some additional code to be shown and hidden as needed.

Choose New Script and type RunMan_UIManager as the name of the script. Click Create and Add to make the new template Component.
