# 14.4 The Core Scene Overview

The main parts of the game are split into two Scenes. The first contains the level – that is, an environment (track) with waypoints, starting points, and so forth – and the second core Scene contains just game logic.

When the game starts, the Game Manager in the core Scene looks to BaseUserManager (the same one from Chapter 4, Section 4.3) to find out which types of racers to add to the game. It adds the racers to the Scene, instantiating their prefabs, and then we have a countdown before the race starts.
