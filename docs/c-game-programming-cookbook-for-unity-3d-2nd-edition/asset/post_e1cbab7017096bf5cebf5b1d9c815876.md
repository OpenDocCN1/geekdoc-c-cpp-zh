This part of the code is going to spawn all the vehicles for the race. Most of what happens in this function takes place inside the loop above, which goes from 0 to however many players we need to spawn – representing the variable numberOfRacers.

A function named Spawn() is used to deal with the instantiation of our prefabs, rather than calling out to Instantiate here. If you need to improve performance, I would recommend replacing the Instantiate call inside the Spawn() function with some kind of pool management, whereby objects are recycled rather than destroyed and replaced with new ones.
