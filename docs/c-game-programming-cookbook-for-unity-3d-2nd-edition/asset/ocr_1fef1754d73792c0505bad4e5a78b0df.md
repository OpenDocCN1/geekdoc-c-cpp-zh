Above, there is nothing particularly unusual about the variables or class declarations for this script until we reach the groundLayerMask declaration. groundLayerMask is a LayerMask type variable that is used by this class to decide which collision layers to look for when trying to find ground underneath the player. When you see this Component attached to a GameObject, and the GameObject is selected, as the Component appears in the Inspector, this variable will appear as a dropdown menu. The dropdown contains all the defined collision layers in your project, and you can choose one or multiple, if required. Layers in Unity are represented as bitmasks. A bitmask is used to access specific bits in a byte of data – you can think of a bitmask as a binary number that represents something else. Layers can be difficult to work with, but when you use a LayerMask, you avoid having to mess around with bit shifting. To help out, the class that this class derives from, ExtendedCustomMonoBehaviour, has a function in it called IsInLayerMask() that simplifies working with layers even more.
