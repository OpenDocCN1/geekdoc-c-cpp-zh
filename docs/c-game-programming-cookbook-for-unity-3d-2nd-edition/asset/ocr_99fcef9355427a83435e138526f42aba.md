# 4.4 The BasePlayerStatsController Class

You can find this class in the folder GPC_Framework/Scripts/BASE/PLAYER.

My player controllers derive from several other classes, one of which is BasePlayerStatsController, a class which gives the player controller access to a host of functions dealing with the user data. Okay, that is not the only function of BasePlayerStatsController. It is also there just to hold any variables that may be relevant to dealing with the players in the games, but BasePlayerStatsController mostly acts as a friendly interface between my player scripts and the user data. For example, I can call SetHealth(an amount) from my player controller without having to worry about identifying my player with the correct ID or anything like that. The functions I use to set UserData in BasePlayerStatsController already takes care of the ID and how the UserDataManager needs to be called.
