We use Unity's JsonUtility class and its ToJson() function to convert our profile data into a JSON formatted string. Wait, what? This requires a little more explanation. Right now, all the profile data is held in the SerializableObject profileObject. All we do to get this converted into JSON is to pass in the instance of the class containing the data. Just as long as the data is serializable, JsonUtility.ToJson() will iterate through the class and all of its variables and format it into a string for us. Pretty neat, right?
