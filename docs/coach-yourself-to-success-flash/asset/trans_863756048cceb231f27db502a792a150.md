## 你的个人成功计划

无论你在生活中想要什么，都有简单的策略可以确保你的梦想成真。你可以遵循的一个快速方法是每天写日记，专门记录每天发生在你生活中的具体事情。生活是忙碌的，当你从一个项目匆匆赶往另一个项目时，你的判断很容易被蒙蔽，也很容易歪曲某一天实际发生的事情——你一心想着完成任务，反而忽略了自己真正取得的成就。

如果你想在生活中做出改变，你会想确保自己做出正确的改变。要想做出最有效的改变，你必须准确地了解自己目前的生活状况。通过写日记，你可以监测当前的行为和所得到的结果，从而追踪自己的进展。然后，如果需要调整方法，你就能非常清楚地看到哪些方面最需要进行有效的改变。写一份简短的个人日记，是监测什么对你有效、什么对你无效的好方法。通过完成今天的日记条目，看看生活目前是如何对待你的。

### 每日日记

| --- |

| 我希望少做哪些事情？ |
| 今天我学到了什么？ |
| 明天我会做出哪些不同的事？ |
| 今日思考 |

### 为什么要写每日日记？

要在生活中做出最有效的改变，你必须了解当前正在发生什么。你需要意识到自己当前的想法和行为，因为正是这些想法和行为给你带来了当前所经历的结果。一旦你有意识地注意到每天的高峰和低谷，你就能具体决定想要做出哪些改变，从而增加积极因素，减少消极因素，并提升你对接下来每一个 24 小时的享受程度。每日日记中的问题将帮助你准确定位自己需要做的事情，并迅速采取行动。

### 一次改变还是多次改变？

一旦你开始做出积极的改变，生活会变得更好，你可能会感到有动力尽可能多、尽快地去改变。人们彻底重整生活时经常出现的一个问题是：“我应该同时尝试改变多少件事？”答案很简单，取决于你希望以多快的速度走向新生活，以及你对改变节奏的适应程度。你越早开始按照你想要的生活去行动，这种行动就越快成为现实。通常，人们有能力同时进行多项自己选择的改变，所以不要害怕设定更高的改变目标。只要确保用日记记录你的进展，然后根据当前生活环境的需要调整你的方法，以纳入或多或少的改变。

### 改变需要多长时间？

另一个常见的问题是：“改变我生活的某个方面需要多长时间？”对于许多改变来说，答案类似于“一根绳子有多长？”这个问题。改变可以是立竿见影的，因为你通常可以立即采取某种行动来改变你所经历的结果。你越早采取这些行动，观察结果并相应调整方法，就越早实现完整的改变。

确保改变立即发生的一个方法是改变你对某个特定问题或生活领域的思考方式。即使你无法立即采取针对期望改变的行动，改变你对某一情境的想法和感受也始终是确保改变发生的第一步。

### 你改变的最大资产

现在是正式向你介绍你在追求自我实现的道路上最宝贵资产的绝佳时机。你拥有的最强大盟友是一个永远不会让你失望的灵感来源——你的潜意识或下意识思维。这是你身上神秘的部分，有些人称之为“直觉”、“内心感受”或“第六感”。

当你忙于某项任务或项目，甚至是在思考午餐吃什么时，正是你的潜意识在关注手头的问题。你决定思考什么，然后专注于它。你可能当场想出解决方案，也可能想不出来。

当你选择专注于某些想法时，你的潜意识会照顾所有其他需要考虑的事情，以保你安全、健康和快乐。当你在想午餐时，你的潜意识控制着你的呼吸，让你保持直立，并防止你在去餐厅的路上撞到墙。你的潜意识是你个人的自动驾驶仪。它是你大脑中一直在处理信息的部分，即使你并未意识到它。

你可以训练你的潜意识以特定方式运作，而且你必须谨慎选择如何编程这部分大脑。潜意识的强大力量在驾驶或通勤上班等熟悉旅程的任务中展现得淋漓尽致。当你学习驾驶时，你真的必须集中注意力，因为有太多任务需要记住，而且一旦犯错可能会付出高昂代价。当你刚开始一份工作时，你必须仔细规划去办公室的路线，确保使用最高效的路线、时间安排正确，并且始终安全。刚开始时，这两项任务都需要完全有意识地进行，并且需要高度集中注意力。

随着你重复这些任务，它们变得更加熟悉，你可以减少对所做之事的专注，直到最终你可以在完全专注于其他事情的同时完成它们。此时，你的潜意识已经接管了这些任务，让你的有意识思维得以自由地专注于当时可能更重要的事情。令人惊讶的是，潜意识的力量如此强大，以至于你可以信任它去处理像安全地将你从A地送到B地这样复杂而重要的事情。如果在你某次旅途中遇到一些小问题——比如道路绕行或车站关闭——你可以肯定，你的潜意识会发出警报，并发送信号让你的有意识思维来思考如何应对这次对日常行程的干扰。

你的潜意识是一种强大的资源，不容浪费。当你忙于思考更有趣的事情时，它运行着你的身体；当你睡觉时，它过滤和归档信息。它解读每天学到的最重要的东西，并将它们存入你最容易获取的记忆部分。正是你的潜意识给了你那些“尤里卡”时刻：当你正忙于处理一个主题时，某个完全不同的问题的答案——也许是困扰了你几天的问题——突然像凭空出现一样闯入你的脑海。
