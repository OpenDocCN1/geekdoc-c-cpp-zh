# # C++
## Fundamentals

Within this section you can begin to understand the structure of C++ code and how to compile and execute that code. These are the fundamentals of C++, which teach you the basics such as using comments, variables, data types, strings and how to use C++ mathematics. These are the building blocks of a C++ program. With them, you can form your own code, produce an output to the screen and store and retrieve data.
