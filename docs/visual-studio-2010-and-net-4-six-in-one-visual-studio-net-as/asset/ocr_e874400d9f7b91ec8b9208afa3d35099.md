+   - The itemRendering and itemRendered events are raised before and after each item is rendered.

+   - The rendering and rendered events are raised before and after the whole dataset is rendered in the control.

# # External Templates

By default, the template engine replaces the first child of the HTML element to which the DataView is attached. For most cases, this is a very convenient behavior. However sometimes you may want to add a non-bound first item, or a header, or even footer manually.

On the server side, this problem is solved with the itemplaceholder and the itememplate properties of the ListView control, and you can find similar concepts on the client side. You can mark an HTML element within your DataView as an item placeholder, and you can mark an external element as an item template. The DataView will repeat the external element as many times as required by the data source, and will substitute the placeholder with it.

The following example generates an unordered list with manual header and footer items. Figure 19-8 shows the rendered.

![](bbox=[0.125, 0.453, 0.148, 0.513])

```
<ul>
  <div sys:attach="div"
    data="{{ children }}"
    div:itemplaceholder="#itemPlaceholder">
    div:itemtemplate="#itemTemplate">
      <li><a href="Add.aspx">Click here to add a new item to the list</a></li>
      <li><li id="itemPlaceholder"></a></li>
      <li><a href="More.aspx">More...</a></li>
    </li>
  <div id="itemTemplate" class="sys-template">
    <li>
      {{ Name }} ({{ Capital }})
    </li>
  </div>
</ul>
```

Code file [3-AjaxLibrary/10-ExternalTemplates.htm] available for download at Wrox.com

The template is defined in an external div container, the child item is repeated (when the DataView is rendered), and finally, ever overwrites the placeholder in the DataView. It is worth pointing out that if you use templates, the sys-template class should not be attached to the host element of the DataView rather to the external container.

In this example, the DataView is attached to the ul element, and the itemplaceholder and itemtemplate properties are used to point to the placeholder and the template. You can utilize the selector for properties by using the sign (+) to point to an HTML element.
