# # Anchoring Annotations

Annotations can belong to the anchor point of the chart area, or be anchored with one of the data points. There are two ways to use values when you specify the position and size of an annotation:

+   - Set the AxisX, AxisY, or both of these annotation properties to the AxisX and AxisY property of a ChartArea object.

+   - Use the AnchorDataPoint property to anchor the annotation to a data point. In this case, its positioning is automatically calculated. At design time, the Property grid lets you select the data point from you have already added to the chart series.

Table 14-10 describes some of properties starting with the Anchor prefix that define how the annotation will be anchored.

**TABLE 14-10: Anchor Properties**

| PROPERTY | DESCRIPTION |
|---|---|
| Anchorage | Gets or sets the alignment of an annotation to the anchor point. The annotation must be anchored by either using the AnchorDataPoint property, or by setting the AnchorX and AnchorY properties. Its X and Y properties must be NaN [NotSet in design mode]. |
| AnchorDataPoint | Gets or sets the data point to which an annotation is anchored. The annotation is anchored to the X and Y values of the specified data point, and automatically uses the same axes as the data point. To automatically position the annotation relative to the anchor point, ensure that its X and Y properties are set to NaN. The AnchorAlignment property can be used to change the automatic position alignment of the annotation to the anchor point. The Offset and OffsetY properties may be used to add extra spacing. When you use this property, the AnchorX and AnchorY properties are set to Double.NaN, because they have precedence. Set this value to a reference value (Nothing in Visual Basic) to disable anchoring to a data point. |
| AnchorOffsetX | Gets or sets the offset from the anchor point for the X position of an annotation. |
| AnchorOffsetY | Gets or sets the offset from the anchor point for the Y position of an annotation. |
| AnchorX | Gets or sets the X coordinate to which the annotation is anchored. Automatically position an annotation relative to an anchor point, ensure that its X property is set to NaN. The AnchorAlignment property can be used to change the automatic position alignment of the annotation to the anchor point. The AnchorOffsetX and AnchorOffsetY properties may be used to add extra spacing. This property has a higher priority than the AnchorDataPoint property. |
| AnchorY | Gets or sets the Y coordinate to which the annotation is anchored. |
