For example, you can split MyClass into two parts, as shown in the following example:

```
// --- MyClass1.cs
[Serializable]
public partial class MyClass
{
    private bool _IsDisposed;
}

// -- MyClass2.cs
partial class MyClass : IDisposable
{
    public bool IsDisposed
    {
        get { return _IsDisposed; }
    }
    public void Dispose()
    {
        // Implement the logic here
        _IsDisposed = true;
    }
}
```

The result of the partitions is a public class MyClass implementing the IDisposable interface and decorated with the Serializable attribute.

# # Static Classes

Static classes are classes that cannot be instantiated, you cannot use the new keyword to create a variable of the class type. By C# 2.0, you could only use the singleton pattern to have types with exactly one instance.

By definition, static classes can contain only static members and no instance members, so they do not have instance constructors. The only base type allowed for static classes is System.Object, and the class is sealed.

The Math class is an example of a simple static class, as shown here:

```
public static class MyMath
    private static double _LastResult;

    static MyMath() { _LastResult = 0.0; }
    public static double Add(double a, double b) { return _LastResult = a + b; }
    public static double Subtract(double a, double b) { return _LastResult = a - b; }
    public static double LastResult
    {
        get { return _LastResult; }
    }
}
```
