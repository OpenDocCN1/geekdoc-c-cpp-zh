Visual Studio can read all the settings from here to register the COM information of the add-in. Table 6-4 summarizes the meaning of information nested inside the <HostApplication> and <AddIn> nodes. The schema defining the structure of .AddIn files contains other nodes, but they are not addressed here.

# TABLE 6-4: Information Nodes in the AddIn File

| NODE | DESCRIPTION |
|---|---|
| <Name> | Specifies the name of the application hosting the add-in. Microsoft Visual Studio means the main Visual Studio IDE, "Microsoft Visual Studio Macros" stands for the Macros IDE. |
| <Version> | Sets the version of the host application. Visual Studio 2010 uses the value 10.0, while Visual Studio 2008 uses 9.0. |
| <FriendlyName> | This name is displayed in the Add-Manager. |
| <Description> | This description appears in the Add-In Manager for the add-in. |
| <Assembly> | The name and full path of assembly encapsulating the add-in. |
