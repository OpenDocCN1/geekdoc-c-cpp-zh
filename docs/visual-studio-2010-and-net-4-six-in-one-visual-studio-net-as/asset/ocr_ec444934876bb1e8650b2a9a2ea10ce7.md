The Solution Explorer and Properties window are docked at the right edge of the IDE's main window. The Toolbox is docked at the left edge of the IDE and is also auto-hidden.

The Output window is docked at the bottom edge of the main window, and Error List is tabbed with it — they share the same visual frame with a single title bar. When they are moved by dragging the title bar, both tool windows move together. When they are dragged by their tabs at the bottom, the captured tool window moves.

# Document Windows

The other type of windows supported by the IDE is called a document window. In contrast to tool windows, document windows are always multi-instanced. They can occupy only the middle area of the main window, optionally surrounded by docked tool windows. Although, document windows cannot be docked, they can float, and can also be split into horizontal and vertical groups, as shown in Figure 5-5.
