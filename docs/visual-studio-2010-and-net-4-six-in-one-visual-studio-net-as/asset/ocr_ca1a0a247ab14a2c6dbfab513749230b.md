# DEVELOPERS FROM VULCAN, DESIGNERS
ARE FROM VENUS

If you have been to any developer conferences, or seen video recordings of sessions, you probably
listened to one or more speaker showing off the latest and greatest tools for creating a website or
desktop application — and apologizing by saying, “As you can see, I am not a designer.” Most
developers probably admit that they are not good with design. It is very rare that someone is a
great developer and designer at the same time. This is not only because both take
years to master, but also because they require diametrically opposite skills and ways of thinking.

If you are reading this book, you are probably a developer, as well. So, let's see what kindnof thinking and skills make a developer great:

+   - Developers think in extremes. This usually means yes or no, 0 or 1, true or false, pass
or fail.

+   - Designers value logic above else (in their work). — An application must behave in
ogical manner. It must be built from logical components that operate logically. A
software developer prefers code to always behave in a predictable way.

+   - Developers strive to write code that always behaves the same under the
circumstances. — Consistency is good. Surprises are almost always bad.

+   - Designers are usually good at mathematics. — Even if their areas of work do not require
svolving n-dimensional equations, they have received properly good math
grades in school.

To sum up, developers think like a Vulcan from Star Trek (at least, when they develop). Writing code
is an engineering science, and it is very creative, developers learned long ago that there are
ultimate laws that they should not deviate.

Interestingly, these skills are attributed to the left side of the brain. People with left-brain
thinking are rational, analytical, logical, objective, and interested in the ways things work, and
how the parts are working together. Right-brain people, on the other hand, are intuitive, holistic,
creative and are looking at the whole instead of the part. Yes, designers are usually right-brainer
people.
