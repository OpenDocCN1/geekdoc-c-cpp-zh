The RetroGamesConnectionString parameter is defined in the following Web.config XML lines:

```
<xml version="1.0"?>
<configuration>

<connectionStrings>
<add name="RetroGamesConnectionString" connectionString=
"Data Source=\SQLEXPRESS;AttachDbFilename=|DataDirectory\RetroGames.mdf;Integrated Security=
User;=True;Instance=True"
providerName="System.Data.SqlClient" />
</connectionStrings>
```

Additionally, the RetroGames.designer.cs file contains the definition of the entity classes (that in this case, it is just one entity class, Game, which is an implementation of INotifyPropertyChanging and INotifyPropertyChanged)

```
[global::System.Data.Linq.TableAttribute(Name="dbo.Game")
public partial class Game : INotifyPropertyChanging, INotifyPropertyChanged
```
