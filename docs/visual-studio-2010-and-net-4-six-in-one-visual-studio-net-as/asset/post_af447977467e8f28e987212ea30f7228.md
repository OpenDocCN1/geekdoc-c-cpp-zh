## Customizing Validations

It is very important to master data model validations in order to take full advantage of Dynamic Data capabilities. The previously shown example is just a simple case of a range validation. You will usually need to combine many different kinds of validations in complex models.

To create a range validation for the Score field in PlayerScore table, follow these steps:

- 1. Create a new class ScoreMetadata.cs.
- 2. Add the following declarations:

```cs
using System.ComponentModel;
using System.ComponentModel.DataAnnotations;
```

- 3. Add the partial keyword to ScoreMetadata.
- 4. Use the following code to define the metadata class:

```cs
[Metadata(typeof(ScoreMetadata))]
public partial class ScoreScore
{
}

public class ScoreMetadata
{
    [Range(1, 10000000, ErrorMessage = "Value for {0} must be between {1} and {2}.")]
    public object Score { get; set; }
}
```

# LISTING 17-8: The Code for Score Property with Range Validation

```cs
using System;
using System.Collections.Generic;
using System.Linq;
using System.Web;
```

You can also apply a RangeAttribute with the RangeAttribute(Type, String, String, String) constructor, as shown in the following line for a Decimal field:

```cs
[Range(typeof(Decimal), "200", "15000")]
```
