Commands with shortcut combinations that are part of the Global scope can be supersed by commands in other scopes, depending on the current context of the IDE. For example, if you are editing a file, commands that are part of the Text Editor scope have precedence over commands in the Global scope that start with the same key combination. For example, if several commands have key combinations that start with Ctrl + K and the Text Editor also has several key combinations that start with Ctrl + K, when you are editing the Text Editor key combinations will work, and the Global key combinations will be ignored.
