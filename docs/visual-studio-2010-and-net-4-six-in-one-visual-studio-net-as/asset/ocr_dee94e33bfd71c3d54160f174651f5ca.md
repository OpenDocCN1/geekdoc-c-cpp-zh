What is happening behind the scenes?
NET MVC 2 ships with a default set of code-only templates for different data types. Template rendering is that of MVC the metadata associated with model controls the HTML output.

Each property is rendered with two parts: a label and a field. The default templates assign predefined CSS classes to the HTML tags, and it makes much easier to put together a website with great design. Listing 18-19 shows the HTML content rendered from Edit.aspx.
