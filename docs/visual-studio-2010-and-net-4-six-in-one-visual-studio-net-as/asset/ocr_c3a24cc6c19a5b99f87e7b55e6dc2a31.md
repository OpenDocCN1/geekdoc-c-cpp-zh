The DataView control, you can solve the previously described task to display the countries and its flags in an unordered list in the following way:

```
<body xmlns="javascript:Sys" dv="javascript:Sys.Ui.DataView">
  <ul class="sys-template" sys:attach="dv" dv:data="{{ countries }}">
    <li>
      {{ Name }} ({{ Capital }})
n      <img src="'../images/' + Code + '.gif'" />
    </li>
  </ul>
</body>
```

This code may seem a bit familiar but also a strange to start. You can recognize the standard XHTML tags (body, ul, li, img) and their attributes (class, src). However, you probably have not seen the sys: and dv prefixes before which is essentially XML, so you can add new prefixes with their namespace declarations just when they are needed. In this code, the sys and the dv namespaces are declared at the *body* level—and this is the recommended practice.

The sys:attach attribute is recognized by the templating engine, and means that an instance of the DataView class (referenced with the dv alias) is attached to the current XHTML element. DataView will automatically repeat the child element of the current element (in this case, the li tag) and its content as many times as required by the data. Therefore, in some scenarios, you do not have to explicitly make an item holder or an item template.

Because the DataView will take care of rendering the HTML markup, the elements that the DataView is attached to should not be displayed by the browser. This is specified by hiding the element with the sys-template CSS class that contains only the following setting:

```
<style type="text/css">
.sys-template {
  display: none;
}
</style>
```
