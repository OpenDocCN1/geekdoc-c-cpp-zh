
Having so many separate languages and tools, the architect teams recognized that the whole visual aspect could be separated from the languages. Why separate IDEs for all the languages and tools if they could fit into the same environment? When was the name of Visual Studio born?

## Visual Studio 97 and 6.0

In 1997, Microsoft built a single environment to integrate multiple languages into one application surface. This was released as Visual Studio 97, bundling Microsoft development tools for the first time. This package contained Visual Basic 5.0, Visual C++ 5.0, Visual FPro 5.0, and Visual J++ 1.1 from the set of existing tools. The bundle was also extended with InterDev, a new tool for developing dynamic Web sites using the Active Server (ASP) technology. A snapshot of the Microsoft Developer Network Library was part of the package.

At this time, the IDE named Developer Studio integrated only C++, J++, InterDev, and MSD. The name "Visual Studio" was rather the name of the bundle (Visual Basic and Visual FPro had their own IDEs)

The famous and long-lived loops of Visual Studio that resembles the strip of infinity (or the Moebius strip) was introduced with the first version. You can recognize it from the package cover in Version 1-1.

Shortly after the 1997 version, in June 1998, Visual Studio 6.0 was released. It did not contain many new things, but fixed early integration issues to make the product more robust. The version numbers of all its constituent parts also moved to 6.0 to suggest a higher level of integrity among the individual tools. However, instead of three IDEs in Visual Studio 97, version 6.0 had four, because C++ got its own IDE.

Microsoft understood the challenge of the Java phenomenon. Not only the language, but also the managed nature of the Java platform inspired the company to make a huge leap in regard to a development platform shift. The huge amount of research and development work done between 1998 and 2002 led to the introduction of the .NET Framework. This new platform entirely changed the future of Visual Studio.

## VISUAL STUDIO.NET 2002 AND 2003

At PDC, Microsoft also demonstrated C#, and announced ASP+ (which was later renamed to ASP) and Visual Studio.NET. It took more than a year and a half, in February 2002, .NET Framework 1.0 was released as part of a pair with Visual Studio.NET (the latter of which is often referred as as Visual Studio .NET 2002).

- Visual C# — This new language was developed by a team led by Anders Heijberg and enormously used by Microsoft itself to develop the Base Class Library of the framework. This new language attracted a lot of developers from the former Visual Basic and C++ camps, and became very popular. - Visual Basic .NET — The former Visual Basic versions scratched the surface of object-oriented programming (OOP), but the real innovations were missing from the language for long time. The clear object-oriented nature of .NET required a new Visual Basic. Microsoft recognized the popularity of the language and created Visual Basic .NET with full .NET and OOP support.

Visual C++ provided this capability. - Visual J# — This language was considered as a replacement for J+. This language had Java syntax. A bit more than a year after Visual Studio.NET was released, a new version, Visual Studio .NET 2003, was shipped with .NET Framework 1.1. Microsoft had to work to stabilize the framework, and of course, critical bugs were fixed. A few things (such as the security model) were also added to the framework (such as built-in support for building mobile applications, built-in data access from ODBC). Also, the CLR became more stable from version 1.0 to 1.1. Visual Studio.NET (the one released with .NET 1.0) was not able to compile applications for the new CLR, so the 2003 version was to undertake this task. Thanks to the robustness and stability of Visual Studio .NET 2003, it became very popular and is in use because of the large number of business applications developed for .NET.

## VISUAL STUDIO 2005

Released in November 2005, Visual Studio 2005, together with .NET Framework 2.0, brought fundamental changes to the tool as well as to the languages. The Common Type System (CTS) of the framework introduced generic types. The shift of CTS also enabled ASP.NET and ADO.NET. Web application development had some pain in the former Visual Studio versions. Developers had to install and use Internet Information Server (IIS) locally on their machines, and it meant confrontation with system administrators who did not want IIS on desktops for security reasons. Visual Studio 2005 installed a local Web server on desktops and resolved this situation.

With this release, Microsoft widened the camp of programmers using Visual Studio with two new editions:

- Express Editions — These editions (which are free) targeted students, hobbyists, and other developers coding for fun. Instead of giving a "free" version of Visual Studio for free, Microsoft created language-related kits with the names Visual C# 2005, Visual Basic 2005, Visual Web Developer, and Visual C++ 2005, equipped with the full language feature but with limited tool support.

- Team Systems Editions — Microsoft wanted to move Visual Studio out of the box of development tools and into high-end enterprise development tools. Team Systems provided out-of-the-box integration with Microsoft’s Team Foundation Server 2005, and added powerful productivity tools for specific development projects. There are four editions for Developers, Testers, Architects, Database Designers, and a single package, Visual Studio Team Suite, which includes all of the features of these four in one.

Compare the list of installed products in the splash screen of Visual Studio 2005 Team Edition for Software Developers (in Figure 1-3) with the list in Figure 1-2. The eye-catching tells you how many tools were added to the new edition.

Following the initial release, few special-purpose products were also shipped and integrated into the IDE (such as Visual Studio Tools for Office and Visual Studio Tools for Applications).

An unusual thing happened in November 2006: .NET Framework 3.0 was released without any accompanying Visual Studio. This major .NET version kept the CL untouched and added infrastructure components to the framework — Windows Workflow Foundations (WF), Windows Communications Foundations (WCF), Windows Presentation Foundation (WPF), and CardSpace. Developers could download Visual Studio extensions to use these new .NET 3.0 technologies.
