Here, you would like to know how much time steps in the computation take, and log this
timing information to the console (or file, the database, and so on).

You can start by defining a computation builder as follows:

```
type LoggerBuilder() =
  let mutable lastTime = None
  member self.Return e =
    lastTime <- None
    e
  member self.Bind(value, cont) =
    match lastTime with
    | None ->
      printf("Time at! = 0 sec")
    | Some (last) ->
      let time = System.DateTime.Now - last
      printf("Time at! = %f sec")
    lastTime <- System.DateTime.Now
    cont value
  cont value

let logger = new LoggerBuilder()
```

Here, your logger computation builder has special treatment for let! expressions. First, you
keep a lastTime in the builder that stores the timestamp of the latest invocation of a let
expression. Initially, this is not available, and you store that as a None value. When a let!
isencountered inside this builder, the Bind method will be invoked. You first check if you have
the last timestamp available, and report the elapsed time accordingly. As a last step, you update the
lastTime counter, and invoke the continuation.

When this will elapsed time the step let! for each let! One tiny bit is resetting the
timestamp when exiting from the logger block. This is useful if you are reusing the same logger
instance across multiple sessions/blocks.

Now you can wrap your earlier code in a logger computation:

```
logger {
  let a = ComputeA()
  let b = ComputeB a
  let c = ComputeC (a, b)
  let d = ComputeD c
  return d
}
```

This has no effect; everything executes like before. However, if you switch some of the instances
let to let!, you will see time information:

Time at let! = 0 sec
Time at let! = 0.104006 sec
