# Filtering Data

DataManipulator supports the following three kinds of filtering:

+   - You can filter for the top N values in a series.
- You can filter data points matching a very simple condition.
- You can create your own data filter class to apply more complex criteria.

You can use the FilterTop method for getting the top N values from a series, as the following code snippet shows:

```
private void FilterTop10MenuItem_Click(object sender, EventArgs e)
{
    chart1.DataManipulator.FilterEmptyPoints = true;
    chart1.DataManipulator.FilterTopN(10,"Series1","Series2");
}
```

The first argument of FilterTop is the number of data points to filter. The other two string parameters are the input and output series, respectively. Setting the FilterEmptyPoints to true causes the DataManipulator to create empty points for data points that are left from Series1 as a result of filtering.
