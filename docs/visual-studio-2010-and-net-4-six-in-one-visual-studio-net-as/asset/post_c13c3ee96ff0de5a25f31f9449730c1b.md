
The <Reference> element has two nested elements:

- <Assembly> — This is mandatory, and it contains the name of the assembly to be referenced. The name can be either the short name of the assembly (such as System.Data.dll shown in the previous example) or its strong name (such as MyCompany.Widgets.dll).
- <Url> — This is an optional element that can be set to a link providing more information about the assembly and types de-encapsulated.

## Code Snippet Functions

The <literal> and <Object> elements may contain a child element named <Function>, which is processed only by the C# code editor. <Function> contains a name with arguments, and it is executed when a literal or object placeholder receives the focus in the editor.

Table 3-3 summarizes the function names that can be processed by the C# code editor:

| FUNCTION | DESCRIPTION |
| --- | --- |
| ClassName() | Retrieves the name of the class that contains the snippet being inserted. This function is very useful when creating constructor or declaration code or instantiation statements. |
| GenerateSwitchCases(EnumLiteral) | Generates a switch with the related case statements according to the type defined by EnumLiteral. The EnumParameter can be either an enumeration type or a reference to a <Literal> with an enumeration type. |
| SimpleTypeName(TypeName) | Reduces the name in the TypeName parameter to the simplest form in the context where the snippet is inserted. This function helps you make your code readable by removing unnecessary namespace tags in type references. |


### Code Snippet Manager

By now, you should realize that, at the lowest level, code snippets are stored in XML files with the .snippet extension. The Snippet Manager works with a set of folders containing .snippet files. Actually, it only paths to those folders, and discovers subfolders dynamically. There are two kinds of folders:

- **System folders** — These are added to the Code Snippet Manager’s list at Visual Studio setup time.
- **User folders** — These can be added by users at any time. One user folder in your profile is added for each language at Visual Studio setup time.

Table 3-4 summarizes the root of the system folders and default custom folders for each language supported by Visual Studio 2010.

| LANGUAGE | SYSTEM FOLDER | USER FOLDER |
| --- | --- | --- |
| HTML | %InstallRoot%\Web\Snippets\HTML | Visual Web Developer\My HTML Snippets |
| JavaScript | %InstallRoot%\Web\Snippets\JavaScript | Visual Web Developer\My JavaScript Snippets |
| Visual Basic | %InstallRoot%\VB\Snippets | Visual Basic\My Code Snippets |
| Visual C# | %InstallRoot%\VC#\Snippets | Visual C#\My Code Snippets |
| XML | %InstallRoot%\xml\Snippets | XML\My Xml Snippets |
| SQL | %InstallRoot%\VSTDB\Snippets | SQL\My Code Snippets |
