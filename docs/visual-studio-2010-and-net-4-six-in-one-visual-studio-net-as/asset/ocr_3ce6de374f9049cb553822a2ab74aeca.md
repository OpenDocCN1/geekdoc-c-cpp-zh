+   - Edit — A view to edit the details (attributes) of an item.

+   - Empty — An view that you must manually edit after its skeleton has been generated.

+   - List — A view listing the model items in a collection.

Select List, because you are going to create a view that lists books in the database.

The "Select master page" checkbox allows you to define the master page attributes (that is, which master page to use, and the identifier of the content placeholder view will be nested). Leave the checkbox checked, and also leave the master page attributes with their default values.

You can check the "Create a partial view (.ascx)" checkbox to create a view as an ASP.NET user control, but for now, unless uncheck this.
