When you comment out this line and run the sample, because postback happens,
PostBackValue triggers rendering postback scripts.

So, when the user clicks a data point, the Chart1 Click event handler is invoked as a result
of the asynchronous postback. It obtains the PostBackValue sent by Chart1 as a property of its
ImageEventArgs parameter. Chart1 Click splits this value into two parts that will be used as
input parameters for the query being carried out as the data source of Chart2. Binding to the
query results to Chart2, the foreach cycle sets the series' properties.

This kind of master-detail chart selection is very powerful. If it takes a few seconds (let's say few)
while the second chart gets updated, you can use an Ajax UpdateProgress control. While the
chart is being updated, the user is not prevented from examining the first chart. Or, you can
use any controls instead of the second chart, and with this mechanism, you can also cascade
controls in a master-detail scenario.
