Multi-project templates cannot be created with the Export Template Wizard. You must manually establish the multi-project structure and the required manifest files. Actually, you are able to export templates for the individual projects into .zip files, but you must write the root .vtemplate file by hand, and also repackage the .zip archives manually.

# # CUSTOMIZING TEMPLATES

The New Project and Add Item dialogs provide very limited customization for project templates. You can use placeholders in the content of template files to replace them with the project or item names specified in the dialog. In many scenarios, however, these simple replacements do not provide an appropriate solution.

In this section, you will learn about the following two customization techniques:

+   * *Using custom parameters* — You can add custom parameters to the template manifest by specifying placeholders and their current replacement values.
* *Custom template wizards* — You can develop a wizard that can be run when the template is used. Your wizard can collect information from the user and initiate actions according to this information.

Both techniques are very useful, especially template wizards that provide sophisticated customization opportunities.

# # Template Parameters

In the samples presented thus far, you have already used the $safeprojectname$ and $safeitemname$ templates. There are a few more predefined ones, as shown in Table 4-6.

### TABLE 4-6: Template Parameters
| PARAMETER | DESCRIPTION |
|---|---|
| clrversion | Current version of the common language run-time (CLR). |
| guid[1-10] | A GUID value to be used in the project file, or in any other source files. You can specify up to ten GUIDs (for example, guid). Visual Studio generates the GUID values and replaces them consistently (for example, the same value replaces guid at every occurrence). |
| itemname | The name provided by the user in the Add New Item dialog box. The default extension is automatically cut from the name. |
| machinename | The current computer name. |
