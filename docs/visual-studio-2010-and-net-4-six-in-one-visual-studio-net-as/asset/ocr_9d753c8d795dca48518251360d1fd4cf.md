# Touch

Touch and multitouch are supported via the manipulation API. Any UElement has its ManipulationEnabled property set to True. This UElement will receive manipulation events, such as ManipulationStarted, ManipulationStarting, ManipulationDelta, ManipulationCompleted, and ManipulationInertiaStarting. Handling effectively and for changing the manipulated element's transform, scale, and rotation transforms moving, rotating, and scaling. In fact, the most complex control in the Surface SDK, the ScatterView control encapsulates the "classic" element rotation, as well as touching functionality, is also available in the Microsoft Software Toolkit for touch-enabled WPF applications.
