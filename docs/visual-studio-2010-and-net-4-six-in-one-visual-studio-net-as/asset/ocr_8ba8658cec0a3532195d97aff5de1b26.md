# The DataManipulator

The chart has a property named DataManipulator that exposes an instance of a class called DataManipulator. You can use this to perform data-manipulation operations at runtime. These operations include copying values, filtering, grouping and sorting data, exporting data to a DataSet object, and applying a formula to data.

You can download the source code for the DataManipulatorSample application to check out how the manipulations treated in this section can be implemented. This implementation contains a simple chart with two chart areas. The primary area is the input the DataManipulator class works with, while the secondary area displays the results.
