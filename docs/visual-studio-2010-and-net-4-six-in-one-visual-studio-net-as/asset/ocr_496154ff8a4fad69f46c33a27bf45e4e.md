is used to project model.Author. The value of this expression is retrieved as a LINQ Expression (defined in the System.Linq.Expressions namespace) and not as a simple reference to the property value. The Expression class is a special class (it is beyond the scope of this book to explain why), and it provides access to the metadata of properties.

So, the LabelFor method can access the metadata of properties and render the HTML output according to it.

# # Display and Edit Templates

There are two template types within MVC: display templates and edit templates. HtmlHelper provides a set of methods available at model and property levels to help the rendering of these templates.

These methods for model properties are available in two flavors. One accepts a string literal that contains the name of the property, and another one accepts an expression, as you have already seen with the LabelFor method. The following code snippet shows the different versions of the Display method rendering the Title property:

```
<%= Html.Display("Title") %>
<%= Html.LabelFor(model = model.Title) %>
```

When you're using the string literal Display method, it looks for the generic property in your model class, and in the ViewData property belonging to the view instance.

If you want to output the editor for the same property, you can use the Editor method as follows:

```
<%= Html.Editor("Title") %>
<%= Html.EditorFor(model = model.Title) %>
```

You have helper methods to display a read-only representation view or an editor view for the entire model. These are the DisplayForModel and EditorForModel methods:

```
<%= Html.DisplayForModel() %>
<%= Html.EditorForModel() %>
```
