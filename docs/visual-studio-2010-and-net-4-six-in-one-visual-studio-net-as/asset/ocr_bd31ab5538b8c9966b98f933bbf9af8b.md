private void Button_Click(object sender, EventArgs e) {
  if (!DeviceConfiguration.RequestDeviceAccess()) {
    MessageBox.Show("In that case, I won't show anything for you");
    return;
  }

  var videoDevice = DeviceConfiguration.GetDefaultVideoCapture();
  var cs = new CaptureSource();
  cs.VideoCaptureDevice = videoDevice;
  webcamBrush = new VideoBrush();
  webcamBrush.SetSource(cs);
  ellipse.Fill = webcamBrush;
  cs.Start();
}

To start using the webcam, the user must allow access to the capture devices. For privacy reasons, access can only be requested from a user-initiated action. Thus, you need a button and have its Click event enabled. If the request is successful, the default VideoSource object is set up. Finally, a VideoBrush is created with the CaptureSource object and is capturing.

Silverlight can also enumerate all the video and audio devices on the system with the DeviceConfiguration.GetAvailableVideoCaptureDevices and GetAvailableAudioDevices methods. The result of these calls can be presented to the user, who can choose the video or audio capture.
