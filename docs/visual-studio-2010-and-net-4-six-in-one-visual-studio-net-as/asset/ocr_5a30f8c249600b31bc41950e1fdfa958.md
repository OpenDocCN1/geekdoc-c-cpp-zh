{
if (oHttpRequest.readyState == 4) // 4 = READYSTATE_COMPLETE
if (oHttpRequest.status == 200) // 200 = HTTP_OK

> Code file [1-XMLHttpRequest/Default.html] available for download at Wrox.com

When the user clicks on the "Get time" button, the getServer function is called, which initializes the XMLHttpRequest object and sends an asynchronous GET request to time.aspx. The readyState property of the XMLHttpRequest object continuously monitors the current state of the round-trip, and when it changes, the onStateChanged method is called. In this event handler, the response is displayed only if the response is received without error.

This sample does not seem to be complicated, but it is not cross-browser. If you code the same functionality cross-browser in JavaScript, the result is at least three times longer (or More). In practice, it is not uncommon for multiple pages to use AJAX in more complex scenarios and implement them with raw JavaScript, and this would be very time-consuming work. The need for productivity brought AJAX libraries into life.

# ASP.NET and Ajax

The calendar showed June 2003, and most of the ASP.NET team was focused on delivering ASP.NET 2.0 and Visual Studio 2005. A small group was founded to work on a new project named "Atlas". The goal of Atlas was to add the AJAX functionality to the ASP.NET architecture, and support asynchronous UI programming over the server, as well as the client side.
