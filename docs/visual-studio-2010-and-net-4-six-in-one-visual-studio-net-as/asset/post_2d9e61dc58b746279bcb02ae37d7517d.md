To build this code, you will need the following:

- Define your Abstract Syntax Tree (AST) representation for the mathematical expressions you want to plot. This will go into your Ast module.
- Implement a parser to parse formulas into this AST. This will go into your Language module.
- Implement a function that evaluates AST terms. This will go into your Evaluator module.
- Implement a function that creates a new window and plots your formulas in it. This will go into your FunctionPlotter module.

## The Ast Module

The Ast module defines the abstract syntax tree (AST) type for your arithmetic expressions. These consist of the following:

- Numbers, represented as floats
- Binary operations, such as addition or multiplication
- Variables, which will be the single variable used in the formulas you are going to be plotting
- Function calls, a couple of primitives of which you will support, such as sine and cosine

```fsharp
module Ast =

  type var = string

type Expr =
    | Number of float
    | BinOp of (float -> float -> float) * Expr * Expr
    | Var of var
    | FunApply of var * Expr

  static member Sum (el1, e2) = BinOp (( + ), el1, e2)
  static member Diff (el1, e2) = BinOp (( - ), el1, e2)
  static member Prod (el1, e2) = BinOp (( * ), el1, e2)
  static member Ratio (el1, e2) = BinOp (( / ), el1, e2)
```

The static members you added to the type will make it easier to create expressions that use the four arithmetic operations.

## The Language Module

The Language module contains functions to parse strings into the AST representation you defined earlier. The helper of parser is matchToken, which takes a regex pattern and an input string and returns a Value of a pair of strings (for the match, and for the remaining string), or a None (if the regex pattern can be matched).

This function is used to build partial active patterns that can match different types of tokens (terminal symbols) and non-terminals. (These correspond to grammar productions that consist of various symbols that must be parsed before the production can “reduce.”)

You build expressions from sums that, in turn, can be products of that, in turn, can be various factors such as numbers, variables, or function calls.

```fsharp
module Language =
  open System
  open System.Text.RegularExpression

let matchToken pattern s =
  Regex.Match(s, "\A(*" + pattern + "*)((?s.*)*",
  RegexOptions.Multiline)
  | fun m ->
  if m.Success then
    (m.Groups.[1].Value, m.Groups.[2].Value) |> Some
  else
    None
```

```fsharp
let ([WHITESPACE|_]) = matchToken @"[\ \t|\n|\r]*"
let rec MatchTokenNoWS s pattern =
    match ([WHITESPACE|_]) with s
    | Some (_, rest) ->
        rest
        |> matchToken pattern
    | None ->
        s
        |> matchToken pattern

let MatchTokenS f pattern =
    pattern
    |> MatchTokenNoWS s
    |> Option.bind f

let MatchSymbol s pattern =
    pattern
    |> MatchToken s (fun (_, rest) -> rest |> Some)
let rec ([Star|_]) f acc s =
    match f s
    | Some (_, rest) ->
        ([Star|_]) f (rest :: acc)
    | None ->
        (acc |> List.rev, s) |> Some

let ([NUMBER|_]) s =
    @"[0-9]+\\.?[0-9]*"
    |> MatchToken s
    (fun (n, rest) -> (n |> Double.Parse, rest) |> Some)

let ([ID|_]) s =
    @"[a-zA-Z]*"
    |> MatchToken s (fun rest -> rest |> Some)

let ([PLUS|_]) s = @"+\*" |> MatchSymbol s
let ([MINUS|_]) s = @"-\*" |> MatchSymbol s
let ([MUD|_]) s = @"\*" |> MatchSymbol s
let ([DIV|_]) s = @"/*" |> MatchSymbol s
let ([LPAREN|_]) s = @"\(*" |> MatchSymbol s
let ([RPAREN|_]) s = @"\)*" |> MatchSymbol s

let rec ([Factor|_]) = function
    NUMBER (n, rest) ->
        (Ast.Expr.Number n, rest) |> Some
    ID (v, rest) ->
        match rest with
        |> LPAREN (Expression (arg, RPAREN rest)) |>
          (Ast.Expr.FunApply (v, arg, rest)) | Some
        | _ ->
          (Ast.Expr.Var v, rest) | Some
        | LPAREN (Expression (e, RPAREN rest)) ->
          (e, rest) | Some
        | _ ->
          None

and (|Term|_|) = function
| Factor (el, rest) ->
  match rest with
    MUL (Term (e1, e2), rest) ->
      (Ast.Expr.Prod (e1, e2), rest) | Some
    DIV (Term (e2, rest)) ->
      (Ast.Expr.Ratio (e1, e2), rest) | Some
    | _ ->
      (el, rest) | Some
| _ ->
  None

and (|Sum|_|) = function
| Term (el, rest) ->
  match rest with
    PLUS (Sum (e2, rest)) ->
      (Ast.Expr.Sum (el, e2), rest) | Some
    | _ ->
      (el, rest) | Some
| _ ->
  None

and (|Expression|_|) = s
  if String.IsNullOrEmpty s then
    () | Some
  else
    None
```

## The Evaluator Module

The Evaluator module evaluates AST terms with respect to a given variable. It works as follows:

- For numbers, it returns the number.
- For binary operations, it evaluates the two operands.
- For variables, it finds the value in the environment.
- For function calls, it calls the function with the evaluated argument.

```fsharp
module Evaluator =
  open System
  open Ast

let rec Eval (env: (string * float) list) (e: Expr) =
    match e with
    | Number n -> Some n
    | BinOp (f, e1, e2) ->
        match Eval env e1, Eval env e2 with
        | Some v1, Some v2 -> Some (f v1 v2)
        | _ -> None
    | Var v ->
        match List.find (fun (name, _) -> name = v) env with
        | Some (_, val) -> Some val
        | None -> None
    | FunApply (v, arg) ->
        match Eval env arg with
        | Some val ->
            // Implementation of function lookup here
            None
        | None -> None
```

## The FunctionPlotter Module

The FunctionPlotter module implements the plotting capabilities. It defines a record type, which you can use to specify the domain and range of the functions. The entry point to this module is the Plot member that takes a PlotInfo value, creates a new window with a PictureBox, and plots the function.

More refinements could do several optimizations, but use more efficient drawing techniques, and implement further choices, such as the zooming.

```fsharp
module PlotterClient =
  open System
open System.Drawing
open System.Windows.Forms
open Microsoft.FSharp.Control

let WIDTH = 500
let HEIGHT = 500
let POINTS = 500

type PlotInfo =
{ Variable : string
 From : float
 To : float
 FromY : float
 ToY : float
 Formula : string }

// A utility function to evaluate a formula with respect to the given
// variable assigned with the given value.
let Eval v formula x =
Evaluator.Eval [(v, x)] formula

// The function that plots a list of values with respect to a global
// minimum and maximum. It needs the graphics context of the canvas
// to draw on.
let draw min (ctx: Graphics) =
let pen = New Pen(Color.White)
// Increase range if min=max then 0..(max*2)
let min = if min=max then 0. else min
let max = if min=max then max*2. else max

// Scale values into the box available (with height HEIGHT).
let scaleY y = float32 HEIGHT / float32 ( (max-min) /(y-min)
// Break the computed values into segments (continuous lines)
| List.fold ((segments, current), x) ->
    match y with
    | None ->
        (current :: segments, []), x+1
    | Some y ->
        let sy = scaleY y
        if sy > 0.f && sy <= float32 HEIGHT then
            (segments, Point(float32 x * float32 WIDTH / float32 POINTS, sy) :: current), x+1
        else
            (segments, current), x+1
```
