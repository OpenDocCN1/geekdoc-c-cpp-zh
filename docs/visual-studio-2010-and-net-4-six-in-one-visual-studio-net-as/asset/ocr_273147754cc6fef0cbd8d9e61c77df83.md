Based on these goals, .NET Framework 1.0 was born in 2002. Since then, many new versions have been released, with more and more new capabilities answering the newer and newer developer needs. This chapter took a brief look at all of the .NET Framework versions from 1.0 to the current 4.0, and discussed the main capabilities of each of them.
