Use the Window Shift Split to divide the document window area into two vertical panes. You can scroll within the upper and lower panes independently, or resize them by dragging the split bar between them to a new position. The two panes cannot be separated to tab groups; they always move with the document window. You can unite the two panes with the Window Remove Split command, or by resizing one of the panes to a zero height.

It is times very to use separate document windows for the same document. That is when the Window New Window command comes into the picture. It creates an additional document window by cloning the active one, and indicates that by adding "index 1" to "index 2" to the window title. You can use the New Window command for the same window several times, so you can create more document window instances as well. The great thing about this approach is that you can have moved the windows separately from the original one, even though you cannot do this operation with the panes of a split window.

When you split a document window or duplicate it, it changes in one window (or window pane) will instantly appear in the other windows (other window pane).
