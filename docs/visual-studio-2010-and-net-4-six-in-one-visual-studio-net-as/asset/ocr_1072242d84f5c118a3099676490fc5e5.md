The classifier's constructor initializes the classification types and the dictionary of file associations. The _fileAssociations stores file extensions with their content type. This container is initialized with a LINQ expression that looks up the registry and collects the interesting file extensions. Here you also store the maximum length of registered extensions, because it plays an important role in the algorithm recognizing the extensions in the text.

The lion's share of work is in the GetClassificationSpans method. First, it gets the text of the snapshot span, and then looks up all extensions.

There are many ways to do that. The algorithm used here seems a bit complicated; you may create a simpler solution. However, there are two important things to keep in mind when programming the GetClassificationSpan method:

+   - The spans returned be ordered by their starting position and non-overlapping, in order to be displayed correctly in the editor.

+   - The algorithm must be efficient, because keystroke triggers running it.

You may think efficiency is not critical in this case, but that may not be the case. For one sample run, the test machine had 690 file extensions, and the first one was not quick enough. When the tester kept a key pressed, the editor started to clog up.

A better algorithm would start searching for the dot if it does not find the dot in the span, the work is done. If it is found, the algorithm extracts the maximum number of available characters the dot — keeping in mind the length of file extension. It then extracts the extra characters in the _fileAssociations dictionary. If that is not found, a shorter string is searched, unless the file extension to search becomes empty. This is important, because, if you type something like .file.csfg and .cs are valid extensions, and in this case, you would have to highlight the longer one, namely, .cs.

After finding an extension, a new element is added to the classification list with the appropriate type, depending on the content type of the _fileAssociations dictionary, and the search goes on as long as there is new extension to find.
