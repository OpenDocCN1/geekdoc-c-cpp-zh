The Solution Explorer on the right contains a pane with the tree view of the solution structure. The frame hosting is docked at the right side of the main IDE window, and so it provides a different border than the floating window. The frame also contains a pane button to turn on or off the auto-hide property of the window.

The Output window at the bottom is docked exactly at the same location as the Error List window, but the latter is sent to the back. The window uses small tabs for each pane in order to allow clicking it to bring the pane to the front. Just as with the other windows, the toolbar is here as part of the frame window.

The Toolbox window at the left is an example of how a window is hidden at the moment. The small rectangle is the frame, indicating the pane is automatically hidden. When you hover over the mouse the frame, the window pane flies.

The largest part of the screen behind the "Find and Replace" window is covered by two windows representing the MyControl.xaml.cs and source.extension.vismanifest files. These are so-called tab document windows. The frame provides the tabs with the names of the files and all other parts of the editor window below the pane. The MyControl.xaml window to the left of the "Find and Replace" window is a floating document window.
