## CREATING CHARTS

Chapter 14 examined many details surrounding the creation and use of Windows Forms Chart controls, and discussed how to use them to create simple applications. Although the ASP.NET Chart shares the same concepts as the Windows Forms control, you must follow different guidelines when creating charts in web applications — because of the distributed nature of the web. In this section, you create a few samples to learn how to start charts in ASP.NET.

## Adding a Chart to a Page

Create a new ASP.NET Empty Web Application and name it SimpleAspNetChart. Add a new Form item with the name Default.aspx. It becomes the default startup page of the application. Use the Source view of Default.aspx by clicking the Chart tab at the bottom of the document window — unless you are not already in this view. On the Toolbox, expand the Data tab, drag a Chart control, and drop it between the <div> and </div> HTML tags. The Chart automatically creates Series and ChartArea elements, as you can see in Listing 16-1.

### LISTING 16-1: Default.aspx after Adding the Chart Control

```csharp
<@ Language="C*" AutoEventWireup="true" CodeBehind="Default.aspx.cs" Inherits="SimpleAspNetChart.Default" %>

<%@ Register assembly="System.Web.Visualization, Version=4.0.0.0, Culture=neutral, PublicKeyToken=31bf3856d364e35" namespace="System.Web.DataVisualization.Charting" tagprefix="asp" %>

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

<html xmlns="http://www.w3.org/1999/xhtml">
<head runat="server">
<title>title</title>
</head>
<body>
<form id="form">
    <div>
        <asp:Chart ID="Chart1" runat="server">
            <Series>
                <asp:Series Name="Series1">
                </asp:Series>
            </Series>
            <ChartAreas>
                <asp:ChartArea Name="ChartArea1">
                </asp:ChartArea>
            </ChartAreas>
        </asp:Chart>

</body>
</html>
```

The <Register> directive shows the Chart control can be found in the System.Web.DataVisualization assembly.

When to turn to Design view, you can see the charts sample data. But when you run the application, an empty chart is displayed. You can add data points to the chart in the Design view by editing the Points property of Series1 in the Series Collection Editor or manually typing data points in the Source view.

```csharp
<asp:Chart ID="Chart1" runat="server" Width="490px">
    <Series>
        <asp:Series Name="Series1">

                <asp:DataPoint XValue="2" YValues="28" />
                <asp:DataPoint XValue="3" YValues="13" />
                <asp:DataPoint XValue="4" YValues="7" />
            </Points>
        </asp:Series>
    </Series>
    <ChartAreas>
        <asp:ChartArea Name="ChartArea1" />

```

Of course, you can set up a Chart from code. You can carry out the initialization in the Page_Load event, as Listing 16-2 shows.

### LISTING 16-2: Default.aspx.cs with Simple Chart Initialization Code

```csharp
using System;
using System.Drawing;
using System.Web.UI.DataVisualization.Charting;

namespace SimpleAspNetChart
{
    public partial class Default : System.Web.UI.Page
    {
        protected override void Page_Load(object sender, EventArgs e)
        {
            // Set up chart title
            var title = new Title("This is an ASP.NET Chart control");
            title.Font = new Font("Calibri", 24, FontStyle.Bold);
            Chart1.Titles.Add(title);

            // Set up chart type
            var series1 = Chart1.Series[0];
            series1.Points.Clear();
            series1.ChartType = ChartType.Spline;

            // Create data points
            for (int i = 0; i <= 10; i++)
            {
                series1.Points.Add(new DataPoint(i, Math.Pow(i, 2)));
            }
        }
    }
}
```

The ASP.NET Chart and all related types can be found in the System.UI.DataVisualization.Charting namespace. The Page_Load event sets up the chart title and the Series chart type to Spline and creates points programmatically in Default.aspx.
