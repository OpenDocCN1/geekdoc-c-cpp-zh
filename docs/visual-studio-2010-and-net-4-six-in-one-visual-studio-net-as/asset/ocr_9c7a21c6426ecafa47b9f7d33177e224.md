| PATTERN CASE | EXAMPLE | DESCRIPTION |
| --- | --- | --- |
| [ patt; ... ] | [ elem ] | Matches a list with its elements |
| id :: patt | hd :: tail | |
| hd1 :: hd2 :: [ last ] | Deconstructs a list into a head and a tail. | |
| [ ] | [ ] | Matches an empty array |
| [ patt; ... ] | [ ell; _; el3 ] | Matches an array with its elements |
| { id=patt; } | { FirstName=fn; LastName=ln } | Matches a record by matching against fields |
| patt | patt | [] | [ elem ] | OR pattern |
| patt & patt | | AND pattern |

Pattern matching is a fundamental technique in functional programming and is absolutely ubiquitous in F# code. All bindings use pattern matching to bind the right-hand of the left-hand side. Consider the following:

```
let (a, b, c) = 1, "my string", 2
let (x, y, _) = Compute3()[2]
let (myList, Some x) = [1; 2], CustomerById 12
```

In addition, pattern matching is also a control-flow device. The match with ... construct allows you to pattern match an expression with various patterns, and return a value from the first pattern that matches. The various cases are checked in the order of their definition, so the first list you list in your match expression will be the first to consulted.

```
let result =
  match myList with
  | [] ->
      printf ""
      1
  | [ _ ] ->
      printf "single element"
      1
  | :: [ _ ] ->
      printf "two elements"
      2
  | ->
      printf "more elements"
      3
```

A fundamental property of pattern matching is whether or not it is exhaustive — that is, whether it covers all possible cases or shapes of the value matched. For example, a pattern match on a discriminated union with three possible shapes will handle all three of these shapes to be exhaustive.
