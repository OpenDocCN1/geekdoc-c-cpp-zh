As mentioned earlier in this chapter, MVC 2 was designed and implemented with TDD in mind. This chapter would not be complete if you could not see how great MVC is when combined with TDD.

Of course, it is beyond the scope of this book to thoroughly examine TDD. However, you can learn how to create unit tests in conjunction with MVC, and this is the most important step if you want to deal with TDD.
