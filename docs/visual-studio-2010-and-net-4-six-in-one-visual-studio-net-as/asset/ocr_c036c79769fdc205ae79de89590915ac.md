# Visual Studio Package Development

For those who want to develop packages in the native way, the *Visual Studio Library* (VSL) provides the foundation which to build. The VSL is a set of template-based C++ classes to simplify the creation of packages in C++. It relies on the *Active Template Library* (ATL) for its support of COM objects.

Developers using managed code cannot directly use COM-based APIs. The bridge between the two worlds is the set of interoperability (interop) assemblies. Interop assemblies help in the physical communication between COM and .NET. So, managed developers can use the Automation API and the Package API, but this does not add value to the managed world.
