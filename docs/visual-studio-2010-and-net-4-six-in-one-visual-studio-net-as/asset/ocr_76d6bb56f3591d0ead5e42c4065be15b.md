Code file [ButtonExtendersSample.aspx] available for download at Wrox.com.

As you see, you can define images for CheckBox state. Unfortunately, when you want to declare more ToggleButtonExtender instances, you must set all the image-related properties for each extender. With ImageHeight and ImageWidth, you define the height and width, of the image that will be displayed.

The definition of the ConfirmButtonExtender is much shorter. You can initialize the ConfirmText property to extend the text to show in the confirmation message.
