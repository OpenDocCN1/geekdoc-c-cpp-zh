# The Code Snippet Manager

Use the ✎ Code Snippets command, or press the Ctrl+K and then Ctrl+B key combination, to display the dialog to help you in managing code snippets integrated with Visual Studio. Figure 3-18 shows this dialog in action, where a concrete snippet is selected.

![](bbox=[0.095, 0.222, 0.663, 0.606])

Figure 3-18: Code Snippets Manager

At the top of the dialog, you see the Language drop-down box that you can use to filter all code snippets by a language. The largest part of the dialog screen is occupied by the tree view on the left displaying the hierarchy of code snippets belonging to the specified language. The details on the right display the most relevant properties of the snippet selected in the tree view.

Above the panes, you see the Location field that defines the path of a folder or snippet selected in the tree view. You can see the content of the Location field when you need it for use—for example, to open the snippet folder in Windows Explorer.

Below the panes, you find the Add and Remove buttons that let you add a new snippet folder to the list of existing ones and remove a folder from the list. You can also import a snippet file or search for more information online.
