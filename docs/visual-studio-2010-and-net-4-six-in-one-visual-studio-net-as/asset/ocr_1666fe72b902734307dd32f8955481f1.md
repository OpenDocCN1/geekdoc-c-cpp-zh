You are going to use a few interoperability types that can be found in the Microsoft.VisualStudio .Shell.Interop.10.0 assembly (it's deployed with Visual Studio 2010 SDK), so add a reference to it from the ContextStartPage project. Instead of displaying a simple text, the Text control will display information about the data properties.

Rename the MyControl.xaml file to VSContextControl.xaml and the MyControl control to VSContextControl. Change the body of the user control to encapsulate a ListBox, as shown in 5-7.
