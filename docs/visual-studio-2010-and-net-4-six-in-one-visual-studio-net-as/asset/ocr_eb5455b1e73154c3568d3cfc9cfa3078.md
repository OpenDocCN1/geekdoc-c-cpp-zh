# Null Values

Generally, in F# programming, you will rarely (if ever) encounter null values. In other .NET languages, null is used as an indication that a particular value is not initialized or available, and some of the .NET APIs rely on passing and/ returning `null` values to indicate certain conditions. In F#, a common pattern for this is to return `None` option values, as you will see later in this chapter, which are similar to `Nullables`, but they are truly generic and can be used with any type.

To accommodate .NET APIs returning or expecting nulls, F# also has a null value. When working with .NET APIs, you often need to check whether or not there is a null. You can do so by using pattern matching against the `null` pattern:

```
match SomeDotNetAPIFunction() with
| null ->
    ...
```
