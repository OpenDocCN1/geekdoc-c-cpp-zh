# CREATING FLOWCHARTS AND CODED WORKFLOWS

With previous WF, you could create basic lists of workflows:

+   **Sequential workflows** — The control of a workflow starts from the first activity and executes other activities in the defined sequence. Activities can include control flow such as IfElse, Parallel, While, and so on, but there is no way to use something like a Goto to change the sequence order. When the last activity in the sequence is finished, the workflow completes.
**State-machine workflows** — The control follows the transitions of a state-machine. As the current state changes, the activities assigned to the specific transition are executed. When a final state is reached, the workflow completes.

WF 4.0 does not make such a separation among workflows. It provides a composite activity called Sequence. With nested activities, it uses the same model as a sequential workflow in versions prior to WF 4.0. However, it does not provide an activity like "StateMachine" to support the other. Instead, you can use a composite activity named Flowchart. You can nest activities into Flowchart and connect them to form a flow.
