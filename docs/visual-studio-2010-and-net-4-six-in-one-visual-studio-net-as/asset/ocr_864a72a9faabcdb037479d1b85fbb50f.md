# .NET Compact Framework

In some circumstances, we are forced to use resource-constrained computing devices such as smart phones, PDAs, and so on.. .NET Compact Framework (CF) is a hardware-independent environment for running .NET applications on mobile devices. CF has the same architecture as the full CLR and managed code execution of the .NET Framework, but supports only a subset of the .NET classes, and contains a set of classes created specially for the CF.

# .NET Micro Framework

The .NET Micro Framework is designed for devices with very limited resources. It's very special because it can run with or without an operating system on the device. It has the following layers directly on the hardware:

+   - Hardware Abstraction Layer (HAL) that hides the hardware with an abstraction system.

+   - Platform Abstraction Layer (PAL) that gives the basic functionality of the missing operating system.

+   - CLR, Libraries, and User Applications

The typical memory requirement of MF is 200-500 KB (the next .NET implementation, .NET CF, needs around 12 MB), so it's very effective on remote controllers and other small devices.

Following is a short summary of .NET Micro Framework features:

+   - It has a very small memory footprint.

+   - It runs on the “metal!” or on an existing operating system.

+   - It supports embedded peripherals and interconnects.

+   - It is optimized for low power consumption.

+   - It has multithreading support.

+   - Drivers can be written in C#.
