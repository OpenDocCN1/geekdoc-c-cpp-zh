# Code Snippet Storage

By now, you should realize that, at the lowest level, code snippets are stored in XML files with the .snippet extension. The Code Snippets Manager works with a set of folders containing .snippet files. Actually, it only paths to those folders, and discovers subfolders and code snippet files dynamically. There are two kinds of folders:

+   - System folders — These are added to the Code Snippets Manager’s list of folders at Visual Studio setup time.

+   - User folders — These can be added by users at any time. One user folder in your user profile is added for each language at Visual Studio setup time.

Table 3-4 summarizes the root of the system folders and default custom folders for each language supported by Visual Studio 2010 out-of-the-box.

| LANGUAGE | SYSTEM FOLDER | USER FOLDER |
| --- | --- | --- |
| HTML | %InstallRoot%\Web\Snippets\HTML | Visual Web Developer\My HTML Snippets |
| JavaScript | %InstallRoot%\Web\Snippets\JavaScript | Visual Web Developer\My JavaScript Snippets |
| Visual Basic | %InstallRoot%\VB\Snippets | Visual Basic\My Code Snippets |
| Visual C# | %InstallRoot%\VC#\Snippets | Visual C#\My Code Snippets |
| XML | %InstallRoot%\xml\Snippets | XML\My Xml Snippets |
| SQL | %InstallRoot%\VSTDB\Snippets | SQL\My Code Snippets |

Visual Studio puts the code snippet folders in your My Documents folder under the Visual Studio 2010\Code Snippets folder. Depending on your user name, profile, and operating system, for example, in a notebook computer using Windows 7, the Visual C# custom snippets would be located in the C:\Users\<username>\Documents\Visual Studio 2010\Code Snippets\Visual C#\My Codeppets folder.

System folders are under the Visual Studio installation folder %InstallRoot% shown in the Table 3-4. Each folder contains a subfolder depending on the language of Visual Studio, and snippets are under the language folder. For example, if you installed Visual Studio 2010 with English language, Visual C# snippets can be found at %InstallRoot%\VC#\Sni\1033 folder.
