# Updating Data on the Server

If you want to implement a read-write scenario, you must delegate all data management to the new `Sys.DataContext` class. This class encapsulates everything required to retrieve the data from the server, changes on the client, and then modify the data back to the server. The `DataContext` implements an `IDataProvider` interface, which means you can use a `DataContext` instance directly as a source for your DataView:

```
<ul
class="sys-template"
sys:attach="dv"
dv:atafetch="true"
dv:dataProvider={executionContext}
dv:fetchoperation="GetCountriesByName"
<li
  {{ Name }} {{ Capital }}}
</li>
</ul>
```
