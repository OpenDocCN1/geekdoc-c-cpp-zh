With this release, Microsoft widened the camp of programmers using Visual Studio with two new editions:

+   - Express Editions — These editions (which are free) targeted students, hobbyists, and other developers coding for fun. Instead of giving a "geese" version of Visual Studio for free, Microsoft created language-related kits with the names of Visual C# 2005, Visual Basic 2005, Visual Web Developer, and Visual C++ 2005, equipped with the full language feature set, but with limited tool support.
- Team Systems Editions — Microsoft wanted to move Visual Studio out of the box of development tools and into the high-end enterprise development tools. Team Systems provided out-of-the-box integration with Microsoft’s Team Foundation Server 2005, and added powerful productivity tools for specific development projects. There are four editions for Developers, Testers, Architects, Database Designers, and a single package, Visual Studio Team Suite, which includes all of the features of these four in one.

Compare the list of installed products in the splash screen of Visual Studio 2005 Team Edition for Software Developers (in Figure 1-3) with the list in Figure 1-2. The eye-catching tells you how many tools were added to the new edition.

Following the initial release, few special-purpose products were also shipped and integrated into the IDE (such as Visual Studio Tools for Office and Visual Studio Tools for Applications).

An unusual thing happened in November 2006: .NET Framework 3.0 was released without any accompanying Visual Studio. This major .NET version kept the CL untouched and added infrastructure components to the framework — Windows Workflow Foundations (WF), Windows Communications Foundations (WCF), Windows Presentation Foundation (WPF), and CardSpace. Developers could download Visual Studio extensions to use these new .NET 3.0 technologies.
