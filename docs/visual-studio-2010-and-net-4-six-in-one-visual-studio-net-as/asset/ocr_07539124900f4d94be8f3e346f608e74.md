# Customizing Validations

The default Dynamic Data validation considers the metadata and includes the following three rules:

+   - Required fields

+   - Maximum field length

+   - Type enforcement

You can include additional validation information in the data model by creating validation methods and by using System.ComponentModel.DataAnnotations attributes. You can also create your own customized attributes.
