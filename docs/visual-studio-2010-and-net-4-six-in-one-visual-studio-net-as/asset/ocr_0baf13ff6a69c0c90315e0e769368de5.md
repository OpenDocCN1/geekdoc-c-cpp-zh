> You will find this folder directly under your operating system's Program Files folder (64-bit systems, under the Program Files (x86) folder) in a folder with an IronPython prefix.

Add a new text file and name it Calculate.py where .py is the standard extension for IronPython files. This file should be in the same folder from where the console application is started, set the Build Action property of Calculate.py to Content, and the “Copy to Output Directory” property to Copy Always.

Enter the following short program into the Calculate.py file:

```
def Add(A, B):
    return A + B
```

This small code snippet adds A and B and retrieves the result of this operation. What is less obvious if you are not familiar with Python that A and B can be any objects, and the operation will be successful when the “+ operator” is defined on their types.

Copy the code in Listing 10-1 to the Program.cs file to invoke the Python snippet.

# LISTING 10-1 Program.cs File of IronPythonRunner

```
using System;
using IronPython.Hosting;

namespace IronPythonRunner
{
    class Program
    {
        static void Main(string[] args)
        {
            var ip = Python.CreateRuntime();
            dynamic calculator = ip.UseFile("Calculate.py");
            Console.WriteLine(calculator.Add("Welcome to IronPython on ", DateTime.Now.ToShortDateString()));
            for (int i = 1; i < 4; i++)
            {
                for (int j = 5; j < 8; j++)
                {
                    Console.WriteLine("(" + (i) + \ + \ " + (j) + ") = ");
                    calculator.Add(i, j);
                }
            }
        }
    }
}
```
