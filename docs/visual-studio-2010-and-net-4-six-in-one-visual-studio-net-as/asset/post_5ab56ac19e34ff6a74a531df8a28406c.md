
# Writing the Code Snippet Definition

You can now type in the definition of the snippet. List 3-1 shows the text you should type in. IntelliSense and code completion will help you accelerate the typing.

LISTING 3-1: ConsoleSnippet.snippet

```xml
<xml version="1.0" encoding="utf-8"?>
<CodeSnippets xmlns="http://schemas.microsoft.com/VisualStudio/2005/CodeSnippets">
  <CodeSnippet Format="1.0">
    <Header>
      <Title>Write a message to the console</Title>
      <Shortcut>mvc</Shortcut>
      <Author>Insert (DiveDeeper) Novak</Author>
      <Description>This snippet inserts a "Console.WriteLine" invocation into the code.</Description>
      <SnippetTypes>
        <SnippetType>Expansion</SnippetType>
      </SnippetTypes>
    </Header>
    <Code Language="Csharp">
      <![CDATA[
        Console.WriteLine("This is a message");
      ]]>
    </Code>
  </CodeSnippet>
</CodeSnippets>
```

Save the file in one of your folders.

# Importing the Code Snippet

To make the snippet available in Visual Studio, go to the Code Snippets Manager dialog. In the Language drop-down, select Visual C#. You will see a few folders. Select the Code Snippets folder and click on the Import button.

A Code Snippets directory-selection dialog pops up on the screen to enable you to select a .snippet file. Select the ConsoleSnippet snippet from the folder where you saved it. Click Open. The Import Code Snippet dialog then opens to enable you to select the location of the snippet file. Click Finish to signify that you accept the location.

The new code snippet file is imported. You can see it in the Code Snippets manager, when you expand My Code Snippets folder, as shown in Figure 3-11.

# The Code Snippet File Structure

The structure of a code snippet file is simple. It doesn't have too many XML nodes, and its structure can be reflected with the following skeleton:

```xml
<?xml version="1.0" encoding="utf-8"?>
<CodeSnippet xmlns="http://schemas.microsoft.com/VisualStudio/2005/CodeSnippet>
<CodeSnippet Format="1.0">
  <Header>
    <!-- General information goes here -->
  </Header>
  <Snippet>
    <!-- Here goes the code template -->
  </Snippet>
</CodeSnippet>
</CodeSnippet>
```

FIGURE 3-14: The snippet selected

All elements in the file should be in the http://schemas.microsoft.com/VisualStudio/2005/CodeSnippet section, as indicated in the <Codeppets section. A single .snippet file may contain one or more snippets, each of which is represented by <CodeSnippet> element. This element is valid only with Format set to the version of the code. For Version numbers, the number is 1.

Each <CodeSnippet> must have two mandatory sections:

- <Header> This section defines general information about the snippet. The Code Snippets Manager leverages information from this section.
- <Snippet> This section defines the body, or the code template.

The schema definition requires that the <Header> be specified before <Snippet>. However, you can import the snippet if this condition is not satisfied.

# The <Header> Element

Child nodes of the <Header> element contain general information about the code snippet — such as its title, a detailed description, the shortcut to activate it, and on. Table 3-1 summarizes the available children of <Header>.

**TABLE 3-1:** Child Elements of <Header>

| ELEMENT | DESCRIPTION |
| <Author> | This element is a placeholder to specify the author of the snippet and any other related information (such as trademarks, copyright symbols, and so on). |
| <Title> | This is a short title or name of the snippet. This name is indicated in the folder list of Code Snippets Manager. You should keep it short but expressive. |
| <Description> | The name often does not tell enough about the snippet. This element allows you to add a more verbose description to the snippet, and this description is displayed in the Code Snippets Manager when the snippet is selected in the folder list. |
| <Shortcut> | This element defines the shortcut text to use typing. Typing this shortcut and pressing the Tab key will activate the snippet, and the related code template is processed. When completion is finished, this shortcut also appears on the completion list with an icon indicating that this is going to invoke a code snippet. |
| <Keywords> | This element acts as a container for the <Keyword> child elements. Each <Keyword> child contains a custom keyword for the snippet. Although this is currently not used by Visual Studio, it represents a standard way of keycoding code snippets for online content providers. |
