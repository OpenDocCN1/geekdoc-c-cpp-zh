## The AsyncFileUploadControl

The standard .NET FileUpload control does not work within an Ajax UpdatePanel. If you want to place it in an update panel, then a postback is also required to upload the file. The Toolkit's AsyncFileUploadcontrol allows you to upload the file in an asynchronous manner, and it works with UpdatePanel. A great advantage of this control is that it uploads the file without postback, and provides client-side and server-side events.

The control provides different coloring for file uploads. It can have a green background when the file is uploaded successfully and a red one when upload fails. You can also show a "progress" image while file uploading is in progress.

You can find the AsyncFileUploadSample.aspx in the project to examine how this control works. Listing 20-14: AsyncFileUploadSample.aspx

```aspor
<%@ Language="C#" AutoEventWireUp="true"
CodeBehind="AsyncFileUploadSample.aspx.cs"
Inherits="ActControlsSamples.AccordionSample" %>

<%@ Register Assembly="AjaxControlToolkit" Namespace="AjaxControlToolkit" %>
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0//EN"
"http://www.w3.org/TR/html/html-transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
<head>
  <meta charset="utf-8" />
  <title>AsyncFileUpload sample</title>
  <script type="text/javascript">
    function onStart(sender, args) {
      document.getElementById('StatusLabel').innerText = 'File being uploaded.';
    }

    function onError(sender, args) {
      var fileName = args.getFileName();
      var errorMessage = args.getErrorMessage();
      document.getElementById('StatusLabel').innerHTML = fileName + "<span style='color:red;'>*</span>" + errorMessage;
    }

    function onComplete(sender, args) {
      var fileName = args.getFileName();
      var contentType = args.getContentType();
      var text = fileName + " uploaded, Size: " + args.length() + " bytes";
      if (contentType.length > 0) {
        text += ", content type: " + contentType;
      }
      document.getElementById('StatusLabel').innerHTML = text;
    }
  </script>
</head>
<body style="font-family:verdana;font-size:12px">
<form id="form1" runat="server">
    <asp:ToolkitScriptManager Id="ToolkitScriptManager1" runat="server" />
    <div>
      <p>Select a file to upload</p>
      <asp:UpdatePanel Id="UpdatePanel" runat="server">
        <ContentTemplate>
          <asp:AsyncFileUpload ID="AsyncFileUpload1" runat="server"
            width="400px"
            OnClientUploadStarted="onStart"
            OnClientUploadError="onError"
            OnClientUploadComplete="onComplete"
            CompleteBackgroundColor="Lime"
            ErrorBackgroundColor="#FF5050"
            ThrobberID="robber"
            UploadingBackgroundColor="LightBlue" />
        </ContentTemplate>
      </asp:UpdatePanel>
    </div>
</form>
</body>
</html>
```
