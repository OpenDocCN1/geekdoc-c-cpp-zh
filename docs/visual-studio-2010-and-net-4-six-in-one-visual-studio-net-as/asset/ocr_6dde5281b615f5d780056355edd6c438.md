```
public static IEnumerable<Pet> TransformMacawTo(
    IEnumerable<Macaw> pets,
    Func<Macaw, Pet> transformation)
{
    foreach (var pet in pets)
        yield return transformation(pet);
}

public static IEnumerable<Pet> TransformDog(
    IEnumerable<Dog> pets,
    Func<Dog, Pet> transformation)
{
    foreach (var pet in pets)
        yield return transformation(pet);
}
nstatic Dog TransformToDog(Macaw macaw)
{
    return new Dog { Name = macaw.Name, Age = macaw.Age };
}

static Eagle TransformToEagle(Pet pet)
{
    return new Eagle { Name = pet.Name, Age = pet.Age };
}
```

In the TransformMacawTo function, the Func<Macaw, Pet> delegate is used, while in the TransformDog function, a Func<Dog, Pet> argument is passed.

Two functions, TransformToDog and TransformToEagle, are responsible for performing the "magical change" of pets. The following lines of code utilize TransformTo:

```
var macawsToDogs = TransformMacawTo(macaws, TransformToDog);
var macawsToEagles = TransformMacawToEagle(macaws, TransformToEagle);
```
