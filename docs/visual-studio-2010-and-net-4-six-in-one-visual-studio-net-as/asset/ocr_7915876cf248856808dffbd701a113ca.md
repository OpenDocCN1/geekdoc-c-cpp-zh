# Styles

You have already seen how you can change the look of controls via the Background, Stroke, and other properties. For example, you can change how a TextBlock looks and behaves with the following XAML:

```
<TextBlock Text="I am stylish, I am not?" HorizontalAlignment="Center"
Family="Comic Sans MS"
VerticalAlignment="Center" FontSize="20" Style="Italic"
FontWeight="Bold" TextTrimming="WordEllipsis" Width="199">
<TextBlock.Foreground>
<LinearGradientBrush EndPoint="0.5,1" StartPoint="0.5,0">
<GradientStop Color="Black" Offset="0" />
<GradientStop Color="Gray" Offset="1" />
</LinearGradientBrush>
</TextBlock.Foreground>
<TextBlock.Effect>
<BlurEffect Radius="2" />
</TextBlock.Effect>
</TextBlock>
```

When the styles are defined within the element, they are even inline styles. There are several problems with inline styles. The first problem is that they are verbose, and it is difficult to read the XAML and concentrate on the actual control tree. The second is that they cannot be reused easily — you must repeat the styles for every control. The third problem is that if you want to change the look and feel of the entire application, there is one central place where you can do it.

Luckily, the Silverlight styling features go beyond inline styles or property setters. You can create resources that define styles for objects. Resources can be local to a control, or they can be placed into an external file. Listing 18-10 extracts some of the styles to a resource within the parentControl.

LISTING 18-10: Font, Blur, and Foreground Brush Extracted to a UserControl Resource

```
<UserControl x:Class="Styles. MainPage"
xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
xmlns:mc="http://schemas.microsoft.openxmlformats.org/markup-compatibility/2006"
mc:Ignorable="d"
d:Height="300" d:Width="400" Font="Normal">
<UserControl.Resources>
<FontFamily x:Key="Family1">Comic Sans MS</FontFamily>
<BlurEffect x:Key="Effect1">Radius="2" />
<LinearGradientBrush x:Key="ForegroundBrush" EndPoint="0.5,1"
StartPoint="0.5,0">
<GradientStop Color="Black" Offset="0" />
</LinearGradientBrush>
</UserControl>
```
