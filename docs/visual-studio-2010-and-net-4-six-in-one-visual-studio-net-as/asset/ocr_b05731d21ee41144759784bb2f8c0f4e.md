# TABLE 8-2: Viewbox.Stretch Property

| STRETCH VALUE | VIEWBOX ACTION |
|---|---|
| None | The content does not get resized. Viewbox behaves like a Border with BorderThickness = 0. |
| Fill | The content fills the Viewbox. If the aspect ratio (the width divided by the height) of the content is not the same as the aspect ratio of the Viewbox, the content may get distorted. |
| Uniform | The content is enlarged or reduced to as much of the Viewbox as possible while maintaining the aspect ratio. |
| UniformToFill | The content is enlarged or reduced to fill the entire Viewbox, while maintaining the aspect ratio. If the aspect ratio of the content and the Viewbox are not equal, some clipping will occur.

# Data Binding

Data binding is used to connect elements of the UI to, or other UI elements. Silver's data binding works in cooperation with styles, templates, layouts, and animation. Data binding allows for two-way synchronization and validation, and automatically ensures that the UI and the underlying data are synchronized. You can use data binding techniques for display and data entry. Data binding is a key element in making the separation between the UI and the logic possible.
