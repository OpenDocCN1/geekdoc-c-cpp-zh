+   View — This layer displays the application's UI.

+   Controller — This layer controls user interaction, works with the Model, and selects the appropriate View to render and display the UI.

The first MVC version in ASP.NET was released as an add-on framework for ASP.NET 3.5 SP1. The second release of ASP.NET MVC was shipped with Visual Studio 2010. It focuses on better developer productivity, and providing the framework for handling large, enterprise web developers projects.

MVC 2 is included in ASP.NET 4 Beta 2 and includes the following features and capabilities:

+   Areas — With the help of areas, controllers and views can be grouped to building subsets of a large application. You can implement each area as a separate ASP.NET MVC project so that the complexity of the application can be easily maintained.

+   Data Annotation Attribute validation support — This lets you add validation logic to a model by adding metadata attributes to a class property. This metadata-driven validation of inputs.

+   Templated helpers — These help you associate and display data with data types. With the help of them, you can reduce the amount of typing of HTML code.

+   Dynamic data — Dynamic data simplifies the creation of data-driven web applications using the LINQ-to-SQL or Entity Framework model, and determining the appropriate rendering method of the UI.

Following are the main benefits of the MVC architecture:

+   It's capable of building strongly layered applications so that business functions can be separated from data accessing and displaying.

+   Web applications with MVC architecture are easy to maintain.

+   Creating unit tests for the application is easy.

One more important benefit of ASP.NET 4.0 is particularly liked by many professional developers is the capability in ASP.NET 4.0 to create pages optimized for search engines. Search Engine Optimization (SEO) is the process of site and page optimization for search engines that result in higher relevance and ranking.

ASP.NET 4.0 provides new capabilities to improve your sites and pages for SEO. The most relevant new capabilities are the support of manipulating the metadata headers and search engine friendly routing.
