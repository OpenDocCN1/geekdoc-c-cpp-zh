You can also use member expressions to access elements and attributes in the hierarchy represented by an XML document or. The following example shows how to access the hierarchy represented by Customers using the XMLNamespaces module:

```
Dim thirdCustomer As XElement = Customers..(2)

Dim thirdCustomerID As Integer = thirdCustomer.<db:ID>
Dim order As XElement = thirdCustomer.<db:Order>
```

The ...descendants> member operator allows you to go down to the descendants collection of the element from which it is applied. The ..qualifiedname element operator navigates down to a single element. The .name and ..<qualified> operators access element attributes.

# Nullable Value Modifier

.NET 2.0 introduced the Nullable(Of T) to represent nullable values. Because of Nullable(Of T) type is supported by the CLR, you can use it like any other generic types:

```
Dim firstName As Nullable(Of Integer) = 4
Dim secondValue As Nullable(Of Integer) = 5
Dim sumValue As Nullable(Of Integer) = firstValue + SecondValue

Public Function Square(ByVal n As Nullable(Of Integer)) As Nullable(Of Integer)
  Return Iif(n.HasValue, n.Value * n.Value, Nothing)
End Function
```

Visual Basic 2008 introduced the ? modifier for value types. It can be added to a type name to represent the nullable value of that type. The previous code can be shortened with the ? modifier:

```
Dim firstName As Integer? = 4
Dim secondValue As Integer? = 5
Dim sumValue As Integer? = firstValue + secondValue

Public Function Square(ByVal n As Integer?)
  Return Iif(n.HasValue, n.Value * n.Value, Nothing)
End Function
```
