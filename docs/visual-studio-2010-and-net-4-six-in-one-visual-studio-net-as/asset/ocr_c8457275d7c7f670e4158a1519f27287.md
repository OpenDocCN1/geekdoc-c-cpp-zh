The Filter box under the list helps you to display only the components that match the filter string you type in. For example, if you type Button where you are on the WPF tabs, the list will contain every component having "Button" in its name, as Button, ButtonChrome, DialogButton, RadioButton, and so on.

The Group box under the Filter text box displays some helpful information about the component. It shows you icon representing the component and its language.

# # Selecting a Component to Add

Use the Browse button to select a binary file representing a component that fits into the selected category. For example, in the COM Components, you will see a list that contains a COM component. If you want to add a file that does not fit in the selected category (for example, you will select an Silverlight components in the System.Workflows Components), and that will be refused.

Let's look at an example. Select the WPF Components, and click Browse. If you download the source code from your companion website (www.wrox.com), under the samples belonging to this chapter you will find a folder named Fluent.dll After you select the file, the IDE checks to see if it fits into the WPF category. # # Blocked Components

Today, a majority of components are downloaded from the web. Because these components can arrive from untrusted sources, Visual Studio IDE does not allow loading them into its process by default. If you try to add the FluentBlock.dll (it is in the same folder as Fluent.dll) to WPF components, you will get a message, similar to, 'The assembly 'Fluent, Version=...' not be loaded. This assembly may have been downloaded from the web.
