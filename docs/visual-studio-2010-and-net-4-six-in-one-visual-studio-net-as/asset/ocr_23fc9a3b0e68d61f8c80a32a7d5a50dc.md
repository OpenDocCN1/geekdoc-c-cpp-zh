# # Source Code Structure

Nothing tells more about VSPackage from its source code, so let's look at how the VSPackage generated the code according to the parameters you specified, and it performed a lot of work in the background:

+   * It generated a class library project in C#.
* It added references to this project for the interoperability assemblies required to access Visual Studio functionality.
* It created resources used by the package and other resources used by the registration process.
* It added new MSBuild targets to the project to support the build and registration process of the package.
* It generated generic types for implementing the package functionality.
* It set up the debug properties of the project to start Visual Studio Experimental Hive.
