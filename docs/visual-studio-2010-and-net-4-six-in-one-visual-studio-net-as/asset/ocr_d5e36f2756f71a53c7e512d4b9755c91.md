# A BRIEF functional HISTORY of F#

F# is a functional programming language that grew out of the work of Don Symme and his team at Microsoft Research (MSR) in Cambridge, United Kingdom. Symme and his team set out to implement a NET front for a functional programming language similar to OCaml. In fact, the initial goal of F# was to port OCaml to .NET, which, in turn, had identified many of the weaknesses of the early .NET 1.1 Common Type System (CTS).

One of the key features that OCaml and the .NET languages at the time lacked was OCaml's mature type system. In particular, the type system of .NET 1.1 was unable to express what is called parametric polymorphism, a key feature of many functional programming languages. This was eventually added to .NET 2.0 as Generics by, others, Don Symme and Andrew Kennedy, making it possible to implement the first port of a functional programming language of .NET.

Although F# had some beginnings around 2002, crowds didn't start building around 2004–2005. These were silent but very productive releases from Don Symme's team (which included original member James Marsden) some impressive batches of new features drawing more and more people's attention to F#. The community started to shape, and many initiatives took off, including the HubF# (https://cs.hubsfs.net), a community site that aimed to be the primary place for F# enthusiasts — now numbering more than 16,000 members as of January 2010.

The first books on F# appeared in 2007 — Robert Pickering's Foundations of F# (New York: Apprentice) and Don Symme's Expert F# (New York: Apprentice). These books helped introduce F# to a multitude of developers, and the language gradually became well known in professional .NET programming camps.

Undoubtedly, the growing interest in the functional paradigm, and the expressive coding coding that F# delivers, helped F# make up to the strategic plans of Microsoft. Microsoft quickly realized the potential behind the language, and the project was promptly transferred from MSR Cambridge to Redmond, where it now resides with the other Visual Studio and programming languages teams.

This was followed by public announcements at the end of 2007 — the most notable one being that by Microsoft Division Division Chief Som Somaraj, spoke the one on his blog emphasizing the company's strength to continue the flow of good ideas from functional programming world into mainstream development, and the importance of technology transfer from research to products to “productize” great ideas.

As time has since 2007, F# is much more than a simple product glued together from a set of ideas from functional programming. It is a unique and amazingly effective combination of brevity and productivity, of imperative, object-oriented and mainly functional paradigms, and a mind-changer that offers a truly unveloped developer experience.

A long time had pass before F# reached its well-deserved membership in the Visual Studio standard languages, and this has made F# a robust and fully mature language that not only fills in where .NET languages fall short, but also defines new approaches for many of the traditionally difficult problems developers face — including the advent of multi-core
