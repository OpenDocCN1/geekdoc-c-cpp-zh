# Adding a Three-Dimensional Effect to the Chart

In many cases, a three-dimensional effect may offer a trendier look to your charts. With the Chart control, it's very easy to change your chart to have this modern look.

Launch the ChartArea Collection editor and select ChartArea. At the top of the property grid, find the Area3DStyle property, and extend it to access its sub-properties. Change the (Enable3D) property to True, set PointDepth to 40, PointGap to 10 and WallWidth to 0. When you build and run your application, you can check it, as shown in Figure 14-10.

The first chart displays the data in a three-dimensional fashion.

Now, your chart gives more information to the user than its first version, when only data points could be seen. There are many other customization opportunities for the chart. You can change how axes look, or you can add labels and annotations to the chart element. Of alignment, fonts, colors, and gradients can be adjusted for each element. Later in this chapter, you will learn more about these customization options.

# Adding Data to the Chart Programmatically

By now, in the sample application, all data points have been set up manually. In real applications, data is generated at run-time; and data points are set up according to results of calculations or reports.

The Chart control supports two methods to set up data points at run-time:

+   - You can use the appropriate chart properties to add data points one-by-one in a program. This is the traditional imperative approach.
- You can bind a data source to the chart, and declare how series and data points should be extracted from the data source. This approach is the declarative approach. You can easily bind data from databases, LINQ expressions, or in-memory objects without having to program any cycle to create and set data points.
