# # CREATING CHARTS

.NET Framework 4.0 has a great charting solution for Windows Forms applications. Types related to charting components can be found in the System.Windows.Forms.DataVisualization assembly in the System.Windows.Forms.DataVisualization.namespace. The most important type is the Chart control shown in Figure 14-1, which can be dragged from the Toolbox to your form. As you can see, this control is located under the Data tab in the Toolbox.
Adding a chart to your application generally entails the following three steps:

+   1. Prepare the data you want to visualize with the chart.
2. Design and set the visual properties of the chart.
3. Bind your data to the chart.

Let's start this discussion by jumping ahead to Step 2 so that you can manually enter data to get a better overview of the chart's visual elements. After you are familiar with how to set chart properties, the discussion will take you back to Step 1 to add programmatically computed data to the chart.

# # Creating a Simple Chart

Working with a Windows Forms chart is easy, because most of the design can be done visually by setting up chart properties. To see this in action, create a C# Windows Forms application and name it ProcessInfoChart.cs. Rename Form1.cs to MainForm.cs. Click OK on the dialog that appears when you have changed the files. Set the Text property of MainWindow to "Process Information Chart."

# # Adding a Chart to a Form

Drag a Chart control to the design surface of MainWindow and set its Dock property to Fill. The chart is immediately shown with sample data info so that you can immediately check its visual properties. If you run the application at that point, the chart will be empty.
