# # Chaining and Utility Functions

One of the best of jQuery is its chainability, which is possible because the jQuery object itself (as with most of the functions and filters) returns a jQuery object. The returned object contains the original wrapped set modified by the function used. In the previous sample, you saw example of chained expressions—for example, the .attr method has been used to set the specific attributes of elements in a wrapped set.

You can use chaining to make complex queries readable by cascading them. For example, consider the following expressions:

```
$$(td:not(:contains('Bells')))
// ...
$$(li:nth-child(3n))
```

This is how they would appear in chained form:

```
$$(td).not(:contains('Bells'))
// ...
$$(li).filter(:nth-child(3n))
```

You can access the DOM items in wrapped sets, and you can process them easily with the help of a few utility functions summarized in Table 20-15.
