Macro Explorer is not just a simple hierarchy view of macro projects and their items. You can also initiate actions from the context menus of items. Right-click on an item to reach its context menu, and select the action you would like to take.

Table 6-1 provides an overview of actions you can access from the quick menus.

# TABLE 6-1: Actions Available in Macro Explorer

| ACTION | ITEM TYPE | DESCRIPTION |
| --- | --- | --- |
| Load Macro Project... | Root | Adds a macro project to the macro system. You can select a .vmacros file representing the project. The selected project will be added to the macro system, and remains after closing and restarting Visual Studio, until you unload it. |
| Unload Macro Project | Project | Removes the project from the macro system. The operation does not delete the corresponding .vmacros file, so later you'll be able to load it again. |
| New Macro Project | Root | While the Load Macro Project adds an existing .vmacros to the system, with this function you can create a new project with its own .vmacros file. You must first select a macro template and set the name and path of the project, as illustrated in Figure 6-7. You should accept the default path unless you have a good reason to put the project in another location. |
| Macros IDE | Root | Opens the Macros IDE, allowing you to edit macros in the project. |
| New Module | Project | Creates a new module and adds it to the selected project. You can select a module template and name your module, as shown in Figure 6-8. Remember that modules are not separate files. They are logical parts of the project file, so you cannot set a physical path to store them. |
| Set Recording Project | Project | Sets the project to the one into which to save recorded macros. The project is displayed with bold typeface in the Macro Explorer window. |
| Edit | Module/Macro | Opens the Macros IDE and navigates to the selected module or macro so that you can start editing its content immediately. |
