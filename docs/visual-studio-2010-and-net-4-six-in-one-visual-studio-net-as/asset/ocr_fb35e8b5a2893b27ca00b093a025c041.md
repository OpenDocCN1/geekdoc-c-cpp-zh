Isolated storage can be thought of as a virtual file system, a complete tree of directories and files. It also allows for storing settings in a key-value combination via the application-scoped IsolatedStorageSettings.ApplicationSettings or the site-scoped IsolatedStorageSettings.SiteSettings.

# Navigation and Search Engine Optimization

As Silverlight (and other RIA technologies) merge the web with the desktop experience, some usability questions arise. The way you use web and desktop applications is different. Do you want to enable the back and forward buttons in the browser for Silverlight? How can you bookmark the current status of an application (as the currently displayed item in a web shop) or send the link to a friend? What about search engines? How will they index the content and drive traffic to the site?

Whether to choose a desktop-like or a web-like experience (or merge the two) is, of course, up to the UX designer. But, if deep linking and back button support is needed, Silverlight's built-in Navigation Framework can help.

Visual Studio 2010 includes an template called Silverlight Navigation Application. Creating a project based on this template results in an application with a few pages (Home and About). Clicking on the navigation links behaves just like clicking on a browser — the program switches to “page,” and the URL changes (for, the About page's URL adds a # to the end).

The important difference between this and the conventional browser navigation is that the page does not reload — the Silverlight keeps running, and no intermediate page is shown, as is with two HTML pages. Back and forward buttons in the navigation, just like bookmarking and deep linking. The key to the navigation API is the System.Windows.Controls.Frame class. Frame loads hosts Pages, handles navigation, and can integrate with the browser. There are also facilities to extract information from the query string (NavigationContext), and URL mapping (UMaMapper).

What about Search Engine Optimization (SEO)? It is not practical to build up a full website using Silverlight if search engines cannot read the information and, therefore, visitors won’t come to the site. The two-sentence version of the SEO trick is to build a “mirror” in ASP.NET that feeds from the same data, and outputs the relevant content and navigation within the fallback part of the Silverlight’s <object> tag in the hosting page. The ASP.NET application can also dynamically generate the robots.txt sitemap XML to direct the search engines' spider to the right content. This approach also helps when the user does (or cannot) have Silverlight installed, but needs to access the content of the site.
