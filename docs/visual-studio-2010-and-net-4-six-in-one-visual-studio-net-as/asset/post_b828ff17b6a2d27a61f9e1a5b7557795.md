```cs
namespace FindAnExpertDemo
{
    [ScriptService]
    public class ExpertiseService : WebService
    {
        [Method]
        public CascadingDropDownNameValue[] GetDropDownContent(
            string knownCategoryValues,
            string category)
        {
            var result = new List<CascadingDropDownNameValue>();
            var da = new DataAccess(Server);
            if (category.Equals("Expertise"))
            {
                foreach (var item in da.GetExpertiseList())
                {
                    result.Add(new CascadingDropDownNameValue(item.Name, item.ToString()));
                }
            } else if (category.Equals("Expert"))
            {
                var values = CascadingDropDown;
                ParseCategoryValuesString(knownCategoryValues);
                foreach (var item in da.GetExpertList(values["Expertise"]))
                {
                    result.Add(new CascadingDropDownNameValue(item.Name,
                        String.Format("{0}${1}${2}", item.Id, item.Photo, item.Description)));
                }
            }
            return result.ToArray();
        }
    }
}
```

The web service is decorated with the ScriptService attribute, indicating that ExpertiseService can be invoked by scripts. The interesting thing is that both CascadingDropDown controls use the GetDropDownContent service. The category argument is used to branch which control to be populated. Both controls use the DataAccess component introduced in List 20-2.

When the ExpertList is populated, you must query the experts possessing the expertise represented by the selected value of the ExpertiseList drop-down. ParseCategoryValuesString method helps in creating the StringDictionary by the values. When you select "Visual Basic" in ExpertiseList, Expertise;1 is put into this dictionary so you can address it with Expertise to retrieve the value 1.

The CascadingDropDown attached to the ExpertList initiates a postback as soon as you select an item. For security purposes, it validates that arguments post-back or callback events originate from the server control that originally rendered them. In the case of CascadingDropDown control, this validation would fail if you turn off event validation:

```asp
<@ Page Language="C#" AutoEventWire="true" CodeBehind="Default.aspx" Inherits="Default.Default" EnableValidation="false" %>
```

> Setting the EnableValidation property to false is not recommended because of security reasons. However, to be able to use the CascadingDropDown extender in Ajax Control Toolkit Beta 0911, hopefully this issue will be solved in one of the next releases.

## Using UpdatePanel

There is a <table> in Default.aspx that holds a Label and an Image to show the description and photo of the selected expert, respectively. You can wrap this table into an UpdatePanel and define a trigger for it that is related to the ExpertList control will be handled asynchronously. These event will also refresh the content within the UpdatePanel. Listing 20-6 shows the full source of the Default.aspx file after adding UpdatePanel.

## LISTING 20-6: Default.aspx with UpdatePanel Control
