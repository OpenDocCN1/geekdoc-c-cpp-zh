listing decorates this class with a MetadataType attribute telling that BookMetadata contains data annotation attributes for Book. BookMetadata defines placeholder properties having the same name and type as the ones in Book. As a result of this definition, decorating the BookMetadata properties are considered by the MVC framework as if those attributes were added directly to Book.

# Preparing the Controller for Validation

The current implementations of controller actions execute the related database transactions and let the database operation raise an exception. This approach is not correct for the following reasons:

+   There is no using clause on database operations if the properties are invalid. This can be done before talking to the database.

+   It might be that the database transactions are alert, because the action does not hurt the consistency of data. However, the current state of the model — the set of its properties may hurt business rules.

You can check the validity of the model before executing the action valid data. The key is the ModelState property of controller that is a ModelDictionary instance. Using the IsValid property of ModelState, you can avoid starting an operation with invalid data. For example, you can use the Create action to avoid creating a new book with wrong data:

```
[HttpPost]
public ActionResult Create(Book newbook)
{
    if (ModelState.IsValid)
    {
        try
        {
            using (var context = new AcmeLibraryDataEntities())
            {
                context.AddToBooks(newbook);
                context.SaveChanges();
            }
            return RedirectToAction("Index");
        }
        catch (Exception)
        {
            return View(newbook);
        }
    }
    return View(newbook);
}
```

The ModelState property contains a detailed state describing model properties and related validation errors based on the data annotations and implicit metadata belonging to the model class. If your controller has more business rules to check, you can do further validation checks.
