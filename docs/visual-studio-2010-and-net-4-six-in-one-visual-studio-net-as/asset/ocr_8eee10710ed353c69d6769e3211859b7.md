Code file [source.extension.vsmanifest] available for download at Wrox.com

As you can see, the manifest is an XML file just like a template manifest, but it has a different schema. Use the View Code command (accessible from the context menu of extension .vsmanifest) and use the XML editor to take a look at the content of the file. Without going deep into the details of this schema, let's note a few things about it.

The ID of the <Identifier> and <Version> elements identify your installation. These values are also used to recognize updates for an extension already installed. The <SupportedEdition> element enumerates all Visual Studio versions supporting the extension, which, in this case, is the Professional edition and all Team Systems editions.

The <Content> element is the one where you can put the payload information for the installer. The child elements determine what actions to carry out during the installation. To add your artifacts to the payload, modify the manifest as shown in Listing 4-13.
