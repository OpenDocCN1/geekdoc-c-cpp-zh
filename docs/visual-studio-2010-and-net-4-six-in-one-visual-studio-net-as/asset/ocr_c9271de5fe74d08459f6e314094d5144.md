# Using the DataView Control

The nightmare of client-side data binding is solved adding template functionality to the Microsoft AJAX Library in the Sys.DataView class. The DataView control acts as a client control, and behaves similarly to the server-side ListView control — it can have a data source, multiple templates, rendering, and user action events, and is capable of displaying either a single record or multiple records. Because you are to use it on the server side, this can be configured in declarative markup on the client, and can also be instantiated in JavaScript code.
