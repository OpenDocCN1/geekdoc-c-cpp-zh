mixing different active patterns in the same match expression will cause the active patterns to execute,
possibly more than once (depending on the order of the match cases and the value being matched).

# Exceptions

Exceptions are a way to signal an error to a calling site, breaking the normal flow of execution and
exiting without a return value .NET exceptions are relatively expensive to create, so you should
ot use exceptions as a control-flow device. Instead, you might try to return option values, and signal
an error with a None value. However, there are situations where exceptions come hard, some even
when they are inevitable.

F# provides a shorthand of notations for dealing with exceptions. All F# exceptions are
subtypes of the System.Exception class, the general .NET exception base class. Table 25-18
summarizes the practices to raise and catch exceptions.
