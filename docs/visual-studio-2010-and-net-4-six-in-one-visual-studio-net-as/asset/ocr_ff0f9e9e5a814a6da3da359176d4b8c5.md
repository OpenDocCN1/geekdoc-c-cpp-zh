# # Image URL Rendering

By default, the RenderType property of a Chart control is set to ImageTag (as Figure 16-5 shows). The ImageLocation and ImageStorageMode properties determine how images are stored and retrieved when the HTML page is to display them. ImageStorageMode is set to UseHttpPost by default, but you can use UseImageLocation to specify a folder where the generated chart images should be.

You can also define the type of image used for the chart by setting the ImageType property to one of Bmp, JPEG, P (the default), or Emf. When you select the Jpeg format, you can also set the Compression property to a value between 0 and 100, where 0 provides the best picture quality and 100 the worst.

# # Changing Image Location

When you render a chart picture as an image, it is automatically saved to a file. The ImageLocation property determines the absolute or relative location and name of this file, and the file extension is automatically added, depending on the image type specified.

Open the SimpleAspNetChart project to play with the image rendering options. Create a new folder under the root project in Solution Explorer and name it ChartImages. Changing the ImageStorageMode to UseImageLocation will cause the image to be stored in a well-defined folder where we. Set the ImageLocation property to /ChartImages/ChartPic#. This value tells the location control of where the rendered chart pictures should be stored. The #SEQ(4,3) formatter instructs the chart to create a sequential number as part of the chart filename, where 4 is the sequential number and 3 is the image time live in (seconds).

Start the application by pressing Ctrl+F5 and click "Draw the Chart" three times with different parameters. Without closing, go back to Visual Studio. In the Solution Explorer, right-click on the ChartImages folder and then click the Open Folder command in Windows Explorer. You can see all chart images rendered since the application was launched, as a title was shown in Figure 16-6.

You can recognize the four pictures already rendered. The first one holds only a chart type.
