The list in the middle of the page enumerates all Visual Studio commands available for keyboard shortcut assignment. The list is very long, finding commands will be laborious. # Determine the Shortcut Key Assigned to a Command

The main menu of the Visual Studio IDE displays the keyboard shortcuts to the right of the menu items names, you can easily find shortcut to use for a specific command. However, there are commands that are not visible in the main menu, or it is difficult to locate them. With the Keyboard page you can find the associated shortcut for any commands.

Type a part of the command name into the textbox above the command list to help you locate a command in the list. Figure 5-23 shows how “Comment” word helps to locate the `Edit.Comment` command.

Directly below the list, you can see the box showing the keyboard shortcuts associated with the command. You can associate zero, one, or more shortcuts with each command. If there is no shortcut assigned to the command, the box is disabled. You can drop down the combo box to display all shortcuts when command. When you select the `Edit.Paste` command, the list contains two items, Ctrl+V and Shift+Ins, both defined in the Global scope.

The list shows the keys you must press to invoke the command, and shows the name of the shortcut is associated with. Figure 5-23 shows how the `Edit.CommentSelection` command has a keyboard shortcut in the Text Editor scope (Ctrl+K, Ctrl+C). You can use up to two keystrokes for shortcut.

# Removing a Shortcut

You can remove a shortcut easily. Select the one you want to delete from the combo box of shortcuts, and click the Remove button. The selected item will be removed from the list without confirmation question. When you remove every item, the combo box and the Remove button are disabled, indicating that no more shortcuts are associated with the command.

# Creating a New Keyboard Shortcut

In most cases, you would like to assign a new keyboard shortcut to a command because of the following reasons:

+   - The command does not have any shortcuts yet.

+   - You would like to change an existing shortcut, or add another shortcut for the same command.

+   - You would like to override the shortcut defined in the Global scope.
