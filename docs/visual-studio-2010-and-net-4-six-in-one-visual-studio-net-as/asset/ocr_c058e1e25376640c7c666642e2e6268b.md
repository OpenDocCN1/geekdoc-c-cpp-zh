UserControl. The constructor has only one instruction — it calls the InitializeComponent method, which builds up the control tree described in the XAML, and creates and assigns the fields for the named elements (such as the LayoutRoot grid).

Let's put some logic inside the Click event handler of the button:

```
private void Button_Click(object sender, RoutedEventArgs e)
{
    LayoutRoot.Background = new SolidColorBrush(Colors.Yellow);
}
```

Notice that you have not a field or property called LayoutRoot — Visual Studio care of that. The InitializeComponent method could found the element within the view created from the XAML file, and assigned it to the LayoutRoot field.

If you run the application, clicking the button should change the background of the entire application to yellow. If you come from an ASP.NET backend, it is important to realize that there has no postback — the event handler on the client, within the Silverlight plug-in itself.
