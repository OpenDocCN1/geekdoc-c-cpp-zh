# The Ast Module

The Ast module defines the abstract syntax tree (AST) type for your arithmetic expressions. These consist of the following:

+   - Numbers, represented as floats
- Binary operations, such as addition or multiplication
- Variables, which will be the single variable used in the formulas you are going to be plotting
- Function calls, a couple of primitives of which you will support, such as sine and cosine

```
module Ast =

  type var = string

type Expr =
    | Number of float
    | BinOp of (float -> float -> float) * Expr * Expr
    | Var of var
    | FunApply of var * Expr

  static member Sum (el1, e2) = BinOp (( + ), el1, e2)
  static member Diff (el1, e2) = BinOp (( - ), el1, e2)
  static member Prod (el1, e2) = BinOp (( * ), el1, e2)
  static member Ratio (el1, e2) = BinOp (( / ), el1, e2)
```

The static members you added to the type will make it easier to create expressions that use the four arithmetic operations.

# The Language Module

The Language module contains functions to parse strings into the AST representation you defined earlier. The helper of parser is matchToken, which takes a regex pattern and an input string and returns a Value of a pair of strings (for the match, and for the remaining string), or a None (if the regex pattern can be matched).
