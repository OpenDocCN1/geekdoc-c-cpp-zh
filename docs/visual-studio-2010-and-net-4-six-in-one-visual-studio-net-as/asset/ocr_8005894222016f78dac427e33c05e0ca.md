You can use the following options:

+   - Export all environment settings or a selected subset of them into a .vssettings file.
- Import all settings from a saved .vssettings file, or a subset of settings saved into that file.
- Reset all settings by selecting one from the default collections of settings shipped with Visual Studio.

# Export Settings

To save the current settings, choose the "Export selected settings" option in the Welcome page and click Next. The wizard moves you to the "Choose Settings to Export" page, where you can define the subset of settings to export. By default, all settings except "Import and Export Settings" are selected, but you can change this definition by checking and unchecking items in the tree view.

You can expand the nodes in the tree and select or unselect settings under any folder. Figure 5-20 shows a configuration where only the "Fonts and Colors" are chosen to export.

Once you have defined the settings to export, click Next to move to the "Name Your Settings file" page. Specify the name of your settings file and the folder where you want to save that file. Click Finish. The Wizard exports the file. It creates a default filename for you that contains the data, but you can overwrite it. Default extension of the file is .vssettings. If you omit the extension, the Wizard appends it to the filename.

# Import Settings

You can import the settings by choosing the "Import selected environment settings" option on the Welcome page. Click Next, and go to the Save Current Settings page, where you can specify a folder and a file to save a backup of the current settings.

Although this page allows you to skip creating a backup (as Figure 5-21 shows), it is always recommended to create a backup. Once you have imported a .vssettings file, the only rollback option is to re-import the backup file. Otherwise, you must manually configure each setting that does not meet your expectations—and this reconfiguration can be laborious and painful.
