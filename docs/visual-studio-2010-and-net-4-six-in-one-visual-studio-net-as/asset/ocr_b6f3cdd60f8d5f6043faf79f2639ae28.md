If you want to manage, it is important to know the order of the client-life events. The full page life cycle is out of the scope of this book. However, let's touch on this topic because there are minor (important) changes in this area.

The first event that is fired is the init event that is raised after all scripts have been loaded, before any objects are created. This event is raised only once when the page is first rendered, and gives you a point in the life cycle to add your custom component to the page. To handle this, you must subscribe to it with the Sys.Application.add_init method.

If you are not a developer, you should use the load event that is raised after all scripts have been loaded, and all objects are created initialized. You do not have to implement a handler to this event. Instead, you can create a function with the reserved name pageLoad. ASP.NET 4, you can also use the Sys.onload to register a function that is called when the DOM is ready and when all required resources have been loaded.

In earlier versions of the Ajax library, if you used the pageLoad method to be called before the window.onload event was, you had to manually call the Sys.Application.initialize method of the page. From ASP.NET 4.0, this is no longer required, because the pageLoad method is called immediately after the DOM content is finished loading and before the window.onload event.

# Working with DOM Elements

Earlier in this, you can see examples of how to use the get function to get a reference to a DOM element by its ID. While the get function is very useful, modern Web 2.0 applications need more flexibility over how DOM elements are selected. The Microsoft Ajax Library 4 introduces a new function (Sys.get) that allows selecting elements not only by their IDs, but by their names or CSS classes. Sys.get is also capable of returning references to Ajax Library components.

The Sys.get function expects two parameters:

+   - selector — This is to define what you are looking for.
- context — This is essentially the scope of the search.

If you omit the second parameter, the function searches the entire DOM.
