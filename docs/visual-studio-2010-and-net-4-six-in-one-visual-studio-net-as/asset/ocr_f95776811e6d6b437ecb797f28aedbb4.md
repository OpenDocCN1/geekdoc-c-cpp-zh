# TABLE 11-4 (continued)

| ACTIVITY | DESCRIPTION |
|---|---|
| PickBranch | This activity is a potential path of execution within a Pick activity. A PickBranch contains a Trigger and an Action. At the beginning of a Pick element's execution, all the triggers from Pick elements are scheduled. When the first trigger activity completes, the corresponding action activity is scheduled, and all other triggers are canceled. |
| Sequence | This activity executes a set of child activities to a single, defined order. The Activities defines the activities to be executed. They are carried out in the order they are in the collection. When the last activity in the collection completes, the Sequence activity completes. In WF 3.5 the Sequence activity has the same semantics as WF 4.0. |
| Switch<T> | This activity selects one from a number of activities to execute, based on the value of a generic type specified in this object's type. Each case in the Cases dictionary consists of a value (serving as the key for the dictionary) and an activity (serving as the value for the dictionary). The expression of Switch is evaluated and compared against the keys in the Cases dictionary. If a match is found, the corresponding activity is executed. |
| While | This activity executes a workflow element where a condition evaluates to true. First, the Condition property is evaluated, and if it's true, the Body of the activity is executed. This cycle goes on while the condition is met. The While activity in WF 3.5 has the same semantics as WF 4.0.
