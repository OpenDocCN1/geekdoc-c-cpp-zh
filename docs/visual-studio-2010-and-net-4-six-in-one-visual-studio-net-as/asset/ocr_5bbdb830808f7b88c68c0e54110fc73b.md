# Upgrading to a New Version

If you have already installed an older version of the Toolkit, or you have downloaded a new one and you want to change your projects using this latter version, you can avoid annoying versioning issues with a few recommended steps:

+   1. Open the ASP.NET web project (solution) you intend to upgrade and remove all references to the AjaxControlToolkit.dll assembly.

+   2. Right-click on the project in Solution Explorer, and run the Open Folder command from Windows Explorer. When the Explorer opens, go into the bin folder and delete AjaxControlType.dll.

+   3. Add a new Dummy.aspx file to your project. Go to the Toolbox and right-click the Ajax Control Toolkit tab. Remove the Delete tab to remove all Toolkit controls previously added.

+   4. Follow the steps described earlier to add the controls of the New Toolkit version to the Toolbox again.

+   5. Temporarily drag a control (for example, ComboBox) from the Ajax Control Toolkit to Dummy.aspx. Visual Studio will add the reference to the AjaxControlToolkit assembly (of course, to the new version you have just installed).

+   6. Delete Dummy.aspx.

If you have more than one ASP.NET Web Application in your solution, repeat these steps for each project. Of course, you must remove the Ajax Control tab from the Toolbox and add the new controls only once.

# Creating a Simple Web Application with the Toolkit

The best way to get started with the Toolkit is to create a application. In this section, you will change the FindExpertDemo sample project that you can download from your book's companion website (www.wrox.com).

# The FindExpertDemo Project

FindExpertDemo is a very simple ASP.NET application that displays information about selected experts. You have two drop-down lists on the page. The first one allows you to select an expertise. The second drop-down list is filled with names of people who have selected the expertise. As you select one of them, a photo and a short description of the expert is displayed.
