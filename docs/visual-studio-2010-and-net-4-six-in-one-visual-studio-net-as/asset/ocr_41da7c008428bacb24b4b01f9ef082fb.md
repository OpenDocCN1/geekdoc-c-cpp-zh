The event handler looks this:

```
private void AddAuthor_Click(object sender, RoutedEventArgs e)
{
    authors.Add(new Author {
        Name = "New Author",
        Chapters = "New Author Chapters"
    });
}
```

However, clicking the Button does not update the DataGrid. Setting the ItemsSource property of the DataGrid to null, and then back to the authors field, but this is a downright ugly solution. Surely must be a better way.

The better way is the INotifyCollectionChanged interface. If INotifyPropertyChanged get your property changes to show up in the UI, the INotifyCollectionChanged interface helps with automatically propagating changes to a list in the UI. The simplest way to take advantage of the INotifyCollectionChanged interface is to use the built-in ObservableCollection<Author> instead of List<Author>. Now, pressing Button adds a new item to the list, which immediately shows up in the DataGrid. 8-8 shows the entire BindingList.cs file.

# LISTING 8-8: DatabindingList.cs

```
using System;
using System.Windows.Controls;
using System.Collections.ObjectModel;

namespace DataBindingDemo
{
    public class ListDataBinding : UserControl
    {
        public ObservableCollection<Author> ListBinding()
        {
            InitializeComponent();
            authors = new ObservableCollection<Author>
            {
                new Author { Name = "Andras Valvart", Chapters = "Modern UI Frameworks" },
                new Author { Name = "Agnes Molnar",
                    Chapters = "History of Visual Studio and Current Editions,
.NET Framework Version History,
ASP.NET Version History"" },
                new Author { Name = "Istvan Novak",
                    Chapters = "Visual Studio Snippets, Visual Studio Templates,
.NET Core Framework, C# History,
C# Language Improvements" }
            });
        }
    }
}
```
