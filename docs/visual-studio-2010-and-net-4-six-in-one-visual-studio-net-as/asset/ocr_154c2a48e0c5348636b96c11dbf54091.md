The ASP.NET Ajax Extensions contain a set of server-side controls that contain not only server code, but also script code that runs. However, you probably do not even notice, as the scripts are “automatically” managed by the run-time and the controls — you use these controls just like any other control in the design and code behind.

The flagship is the ScriptManager which is responsible for managing script resources for client components, partial page rendering, web services, and can even manage your custom scripts. You must drop the ScriptManager control onto the page in order to use Ajax features on the page.

The most notable control in the set is the UpdatePanel that enables you to refresh selected parts of the page. You can take any existing ASP.NET control, embed it into an UpdatePanel, and it will work asynchronously. As a server-side developer, you do not have to worry about client side scripts; it works well for most scenarios.

If you want to notify that an asynchronous request is currently running in the background, you can use the UpdateProgress control. The UpdateProgress contains a placeholder that you can fill with a static message or a progress bar, and it will be automatically displayed when the associated UpdatePanel control executes a request in the background.

Sometimes you want to send the whole page or content of an UpdatePanel to the server at intervals. You can use the Timer control to trigger an event on the client that you can process on server.

To see a simple scenario with these controls, create an ASP page with a GridView and a SqlDataSource that retrieves data from the Customer table of the Northwind database. Enable the sorting and paging for the GridView and set the PageSize to 30 to display many items on the page the user must scroll down to access the page and go to the next page.

```
<GridView runat="server"
DataSourceID="NorthwindDS"
AllowPaging="True" PageSize="30"
AllowSorting="True" />

<SqlDataSource ID="NorthwindDS" runat="server"
ConnectionString="<%% ConnectionStrings:Northwind %>"
SelectCommand="SELECT [CompanyName] FROM [Customers]" />
```

If you try this in a browser, it works as it expects — the records are displayed on pages and you can sort them. Every time you click on a column header or a page number, the page is refreshed. You will notice the quicker flicker and that you lose your scroll content.
