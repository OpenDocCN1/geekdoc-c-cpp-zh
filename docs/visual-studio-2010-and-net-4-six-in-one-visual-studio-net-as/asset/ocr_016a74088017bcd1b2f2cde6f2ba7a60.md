+   * Microsoft Visual Studio 2010 Professional with MSDN — This version is intended to be the essential tool for basic development tasks to assist developers in easily implementing their ideas.

+   * Microsoft Visual Studio 2010 Premium with MSDN — This provides a complete skillset to help developers deliver scalable, high-quality applications.

+   * Microsoft Visual Studio 2010 Ultimate with MSDN — This version (as its name suggests) is a comprehensive suite of application life-cycle management tools for software teams to ensure quality results from design to deployment.

The feature sets of these editions are formed so that each contain every feature the lower editions have, plus their own functionality on top.

Microsoft's intention with Visual Studio 2010 is clear from the features all editions have in common:

+   * Development platform support — All important platforms (Windows, Web, Office, SharePoint, and cloud development) are available with a common tool.

+   * Team Foundation Server integration — There is no difference between the Visual Studio editions in the Team Foundation Server they have! All of them are shipped with the Visual Studio Team Explorer 2010 to instantly access Team Foundation Server with the entire feature set, including source control and work item management, build automation and test case management, Team Portal, Business Intelligence (BI), and reporting.

+   * Debugging and Diagnostics — The efficient debugging and diagnostics tools (with a number of Visual Studio 2010 innovations) help developers to become more productive than ever before. Post-mortem debugging, multi-threaded application debugging through the Parallel Stack and Tasks windows, and 64-bit support for mode debugging are available for every developer independently of the he she uses.

These editions are built with MSDN subscriptions. This is a great benefit — especially for Premium and Ultimate users who receive additional software for production use (such as Expression Studio 3, Office Plus 2010, Visual Premium 2010, and Professional Project 2010). All users get the standard MSDN subscription benefits, such as priority support on MSDN Forums, technical support incidents, MSDN magazine, and so on.

As a result of setting up the editions, small development teams with the Professional edition can now work together in a way that was possible only with one of the Team systems from the previous versions. The Premium edition adds new tools for database development, testing, and advanced functions for debugging and diagnostics. Users of the Ultimate edition have architecture, modeling, and test lab management tools shipped with the product, a benefit they never got before with Visual Studio.
