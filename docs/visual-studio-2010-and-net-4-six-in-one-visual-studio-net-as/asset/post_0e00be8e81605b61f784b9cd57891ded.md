# List Extenders

There are three extenders in the Ajax Control Toolkit that can be attached to ASP.NET list controls:

- CascadingDropDown can be attached to an ASP.NET DropDownList to modify the automatic population of a set DropList controls. When you modify the FindExpertDemo sample application, you learned a lot about using this extender.

- ListSearchExtender lets you search for items in a ListBox or DropList by typing. It performs an incremental search within the ListBox based on what has been typed so far.

- PagingListExtender can be attached to a BulletedList and provide client-side paging. It is very flexible, if you specify either the number of characters used in the heading indices, or the maximum number of items to display per page.
