By default, the control does not assign any specific
styles to the elements of the control. And, without styles, the
control works, but when you see it in a web page, you would not
ink it is interactive. At Figure-20 shows how the control
looks with its default style.

You can set the HeaderCssClass, HeaderSelectedCssClass,
 ContentCssClass properties to provide a more attractive (and
intuitive) look for the control, as seen in Figure 20-12.

When you click one of the controls, the control provides a
animation to show the content behind the clicked header. The
TransitionDuration property allows setting the length of time
to use between Accord panes in milliseconds
def value is 250. You can use the FramesPerSecond
property to define the number of steps per second in the transition
ananimations; the default value is 30. With the FadeTransitions
lag, you can influence whether to fade the accordion panes when
transitioning.
