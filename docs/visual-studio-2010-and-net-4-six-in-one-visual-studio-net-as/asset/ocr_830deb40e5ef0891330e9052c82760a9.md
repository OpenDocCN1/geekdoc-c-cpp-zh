The Sys.create.dataView attaches a new DataView instance to the specified element.
To specify an element, you use a selector that can point to an HTML element (in this case, the single ul tag), ID, or a CSS class. To refer to an ID, use the "# prefix (for example, "#mydid").To select by their CSS class, use the ".prefix (for example, ".class") in the selector.
Furthermore, if you loaded the jQuery Library into the page, you could use the full jQuery selector syntax. In the present, this method allows you to configure the DataView — in this case, only the data property is set.

# Using Pseudo-Columns in a Template

In addition to the properties of the records in the source, the template engine provides two additional pseudo-columns you can access in your data-binding experiences. The first one is $index that contains the zero-based numerical index of your current record, and the second one is $data which is the currently bound record.
