# RequireHttpsAttribute

This attribute checks the current HTTP IsSecureConnection property, and only allows the action to execute when the request was done through a secure connection (such as the HTTPS protocol).

```
[RequireHttpsAttribute]
public ActionResult LoginUser(string username, string clearTextPassword)
{}
```

# ValidateAntiForgeryTokenAttribute

This attribute checks the presence of a specially formatted cookie and hidden form field's value. if all the required data is valid, the action can be executed.

This attribute tries to prevent an action from getting executed during a cross-site scripting (XSS) attack. ValidateAntiForgeryTokenAttribute should be only applied to an action that is allowed to execute during an HTTP POST request. As a prerequisite, a call must be made to the HtmlHelper class's AntiForgery method, which puts the required data into the action's result.

```
[HttpPost]
[ValidateAntiForgeryToken]
public ActionResult XSSProtectedAction ()
{}
```

The related view should look like this:

```
<% using (Html.BeginForm()) { %>
<%= Html.AntiForgeryToken() %>
<!-- Form field definitions -->
<% } %>
```

This view will be rendered something like the following HTML fragment:

```
<form action="/View/Edit" method="post">
<input name="__RequestVerificationToken" type="hidden" value="Ac/BHD5D4K/as67G..." />
<!-- Form field definitions -->
</form>
```

# ValidateInputAttribute

If you want to disable validation for a specific action method or across a specific controller, you can use the ValidateInputAttribute:

```
[ValidateInput(EnableValidation=false)]
public ActionResult ThisMethodCanContainDangerousRequestData()
{}
```
