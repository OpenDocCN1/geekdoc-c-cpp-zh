The metadata code applied the RangeAttribute(System.ComponentModel.DataAnnotations.RangeAttribute) to the Score property. This specifies a minimum, 1, and maximum value, 100000000. If the value of the property is not within the minimum and maximum values, the code raises a validation exception considering the ErrorMessage string.

You can also apply a RangeAttribute with the RangeAttribute(Type, String, String, String) constructor, as shown in the following line for a Decimal field:
