When you move the mouse over the Start point, four handles will appear on each side of this activity. Move the mouse to handle the Start point, click the mouse, and drag the line over the FlowDecision activity. When the handles belong to FlowDecision appear, release the button over one of these handles. An arrow will be drawn connecting the Start point with FlowDecision. This is how you can draw the connection among activities dropped to the design surface of a Flowchart.

When you move the mouse over the FlowDecision, the handles display their labels (you set them through the FalseLabel and TrueLabel properties earlier). Connect the big to test label with the first Assign activity, and then the Testable label with the second Assign activity.
