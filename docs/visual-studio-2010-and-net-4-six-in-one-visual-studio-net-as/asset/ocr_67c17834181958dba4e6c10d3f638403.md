# Nullable Types

In CLR 1.0, one of the weaknesses of value types was the lack of value type's "nullability." To eliminate this, the CLR 2.0 designers added the concept of nullable types to the runtime. A new generic, the System.Nullable(Of T) structure, was introduced, where T should be a value.

The Visual Basic 2005 syntax allowed assigning Nothing to a System.Nullable(Of T) instance, and to compare an instance value with Nothing. The HasValue property tells if a nullable instance has a value, and if it has, it can be obtained through the Value property.

Using these properties, you could define the Nothing-aware Square method, as shown in the following example:

```
Public Function Square(ByVal n As Nullable(Of Integer)) As Nullable(Of Integer)
    Return IIf(n.HasValue, n.Value * n.Value, Nothing)
End Function
```

The Nullable(T) also defines a Narrowing cast operator from Nullable(Of T) to T, and a Widening cast operator from T to Nullable(Of T), so the following declarations are correct when using Option Strict:

```
Dim firstValue As Nullable(Of Integer) = 4
Dim secondValue As Nullable(Of Integer) = 5
Dim sumValue As Nullable(Of Integer) = firstValue + SecondValue
Dim squareValue As Integer = CType(Square(sumValue), Integer)
```
