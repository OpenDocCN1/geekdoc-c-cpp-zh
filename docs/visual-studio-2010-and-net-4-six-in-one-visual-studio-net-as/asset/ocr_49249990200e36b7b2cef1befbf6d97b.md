The DropShadowExtender has a few properties to specify how the shadow should be applied to the panel. Width lets you set the size of the shadow, which can be Rounded with the specified Radius. Shadow Opacity also can be set. When your panel is movable or resizable, setting the TrackPosition to True will follow the shadow to the panel.

DragPanelExtender requires only specifying the DragHandleID property that points to the control that serves as the handle to the panel.

# PopupExtenders

Two controls help you to display pop-up panels (or other pop-up controls) on the page:

+   - PopupControlExtender can be attached to any control to open a pop-up window that displays additional content. This pop-up window will be interactive and will work within an Ajax UpdatePanel, so it will be capable of performing server-side processing (including postbacks) without affecting the rest of the page.
- ModalPopupExtender allows you to display content in an element that mimics a dialog box, which prevents the user from interacting with the rest of the page.

When you use the AjaxControls project, the PopupExtenderSample.aspx page shows you how you can use these controls. Use a PopupControlExtender to display a ListBox filled with expert names.
