```
Chart1.Serializer.Content = content;
Chart1.Serializer.Save(sw);
Chart1.ViewData = sw.ToString();
```

The Serializer provides you with additional properties and methods to create the view state data. The Save method serializes all chart content with non-default property values (as a result of setting the Content property to SerializationContents.Default through the variable). Setting the ViewData property tells the chart that all important state information has been already created. The chart does not serialize its state information, but accepts the content of ViewData as it is persisted.

At this time, the default series has data points, and no other data points get serialized.

When the Page_Load method is called as a result of a postback, view state data of the base series is deserialized from the ViewData property of the chart:

```
var sr = new StringReader(Chart1.ViewData);
Chart1.Serializer.Content = content;
Chart1.Serializer.Load(sr);
```

The last section of Page_Load creates the additional series from the base series data that either was just generated or reloaded from the view state.

As a result of this tuning, the size of the generated HTML page decreases from 13 KB to 8 KB.

# Playing with the Serialization Content

Listing 16-12 sets the Content property of the chart's Serializer to SerializationContents.Default, and not only the data, but also the appearance is saved for the default series generated in the Page_Load method.

Change the first line of the method to follow that only series data would be saved:

```
var content = SerializationContents.Data;
```

When you run the page and set any of the additional series to displayed, the result will not be exactly what you expect, Figure 16-12.

The base series is shown as a column chart instead of a line chart. The cause of this behavior is simple. The ChartType property of base series was not serialized because the content was set to Data, and so no appearance information was saved in the state. When the base series is deserialized, the ChartType property is set to Column, because this is its default value.
