The PopupControlExtender's TargetControl property points to MessageTextBox — the control that controls the panel when receiving the focus. PopupControlID property refers to the control to be popped up. CommitScript property specifies the property on the control being extended that should be set with the result of the popup. After setting the result of the popup, CommitScript specifies additional script to run after these properties result in the TextBox being set to the "Your Expert is..." text when you select an item from the PopupBox.

The ModalPopupExtender control binds the panel to show up with its PopupControlID property. It specifies the controls representing the OK and Cancel buttons with the OkControlID and CancelControlID properties, respectively.
