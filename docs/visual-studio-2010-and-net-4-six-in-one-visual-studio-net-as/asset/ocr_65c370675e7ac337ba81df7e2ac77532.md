The main difference between the two representations is not about using ASP.NET controls or plain HTML, but the way the user is directed to the link. When you look after the HTML code fragment the navigation menu renders, you will see. The following HTML snippet is rendered by the ASP.NET page:

```
<ul class="level1">
  <li><a class="level1" href="Default.aspx">Home</a></li>
  <li><a class="level1" href="About.aspx">About</a></li>
</ul>
```

The HTML snippet for the MVC master page is different:

```
<ul id="menu">
  <li><a href="/Home">Home</a></li>
  <li><a href="/Home/About">About</a></li>
</ul>
```

While the ASP.NET master page uses filenames in the requests belonging to the link, the MVC master page uses folder names.
