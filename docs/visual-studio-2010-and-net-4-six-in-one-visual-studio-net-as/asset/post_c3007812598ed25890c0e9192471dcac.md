## Setting Up Titles and Legends

Adding a title to a chart can help the user understand what data he or she sees. The Chart control allows you to add one or more titles to the chart that can be assigned to either the chart, or one of its chart areas. Setting up chart titles is very simple.

Launch the Title Collection Editor by clicking the ellipsis belonging to the Titles property under the Chart category. Use the Add button to create a new title, and then set its Text property — you'll find it with name “(Text)” right under the Appearance category — to My Secret Data. Expand the Font property and set Size to 12. You can immediately see the newly created title in the design view, located at the top of the chart.

Now, add two more titles and set their Text properties to Increasing Trend and Decreasing Trend. Select Title2, and scroll down to the Docking property in the property grid. Here you find five properties that determine the title is displayed and how it is aligned.

Set the DockedToChartArea to ChartArea. The "Increasing Trend" is displayed within the first chart area. Set the IsDockedInsideChartArea to False and the title moves outside of the chart area, docked at the top. Change the Docking property to Bottom, and the title moves below the chart area.

Change Title3 similarly as Title2, but set DockedToChartArea to Chart2 in this case. When you run the application, you will see all three titles in the chart, as shown in Figure 14-8.

When you create a chart, a legend is automatically added to it. You can see this in Figure 14-8 at the top-right of the window containing Series and Series2. The default legend is docked to the chart, but you can attach legends to charts.

Start the Legend Collection Editor by clicking the ellipsis belonging to the Legends property under the Chart category, and click the Add button to create a new legend. The new Legend2 is also docked to the chart, and is associated with the legend, so it is empty, as its placeholder indicates on the design surface. Close the Legend Collection Editor, and go to Edit Charts.

Select Series1, scroll down to the Chart category, and set the Name property to Revenue. Changing the series name immediately updates the legend using the new name of Series1. Similarly, rename Series2 to Cost. You can attach a series to a legend to be displayed. By default, all series are attached to Legend. Scroll down to the Legend property of Cost (you'll find it under the Legend category) and attach it to Legend2. Now, the Cost series is moved from the first legend to the new one, as the designer surface immediately reflects.

Now, go back to edit Legends. A legend has a set of properties under the Docking category that determine how those are displayed in the chart. Select Legend1 and scroll down to the Docking property. Set the DockedToChartArea to ChartArea. Change the same property for Legend2 to ChartArea2, and also set the IsDockedInsideChartArea to False. ## Adding Data Programmatically

The data you've added manually can also be created programmatically. Start the Series Editor to clear the data points you've added. Select the Revenue series. Go to the Points property and click the ellipsis to display the DataPoints Editor. Select all data points (click the firstPoint, and then the lastPoint while pressing Shift Key), and click Remove. Repeat the same action for the Cost series.

In the design surface, select the MainForm and click the Events button in the Properties window. Double-click on Load to create an event handler method to run when the form is loaded. You will use this method to set up data. 14-1 shows the full source code of MainForm.cs (the unused clauses have been removed).

```
using System;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;

namespace ProcessInfoChart
{
    public partial class MainForm : Form

            for (int i = 0; i < 5; i++)
```
