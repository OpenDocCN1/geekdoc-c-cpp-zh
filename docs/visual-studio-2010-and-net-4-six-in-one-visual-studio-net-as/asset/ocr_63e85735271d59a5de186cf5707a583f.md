# # Handling Click Events

With Ajax, you can post-back a message to the web page in a separate asynchronous communication channel using an XMLHttpRequest object at the background. When the page processes the request, it sends back the results, and a well-defined part of the page is refreshed after the results returned. This communication is asynchronous, so it does not prevent the user from interacting with the page.

The PetShopCharts project contains a page named AjaxClickEvent that allows you to click any point on the chart and refresh the chart's subtitle with information about what has been clicked. Figure 16-15 shows how the subtitle changes when you click on the third data point in the second series.

To allow using Ajax communication on your page, you must add an <asp:ScriptManager> and an <asp:UpdatePanel> to control your page:

```
<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="AjaxClickEvent.aspx.cs"
Inherits="PetShopCharts.AjaxClickEvent" %>
<!DOCTYPE html PUBLIC "//W3C//DTD HTML 1.0 Transitional//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml11-transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
<head runat="server">
<title>Ajax click event sample</title>
</head>
<body>
```
