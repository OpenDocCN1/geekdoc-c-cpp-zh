```
with get idx =
    if Seq.length <= idx then
        failwith "Index out of bound"
    else
        Seq.nth idx coords
```

# Named and Optional Arguments to Constructors

You can make your code more readable by naming arguments and setting properties in your constructor calls. For example, you can construct a new rectangle like this:

```
> let r2 = Rectangle(height=100., width=100., ColorCode=5)
```

You can verify that this indeed initialized the object properly:

```
> r2.ColorCode;
val it : int = 5
> r2.Area;
val it : float = 10000.0
> r2.Diagonal;
val it : float = 141.423562
```

You can also add optional arguments to your constructors:

```
type Circle(radius, x, y, ?color: int) =
    let setColor =
        match color with
        | None -> 128
        | Some c -> c
    member self.Everything = (radius, x, y, setColor)
```

Here, ?color defines an optional argument to the Circle class constructor. This is modeled as receiving an option value, which you can check as part of the object initialization sequence, and assign the local setColor variable appropriately (in this case, defaulting to 128 if no color code is given). You can test this in F# Interactive:

```
> let c1 = new Circle(radius=10, x=5, y=5);
val c1 : Circle
> let c2 = new Circle(10, 5, 5, 100);
```
