The parameter of the Export attribute defines the contract it satisfies. When the MEF composes the parts of the application, it uses this attribute to recognize that SimpleGreeting satisfies the IGreeting contract. When any other component or the host application queries the composition container for parts supporting the IGreeting contract, SimpleGreeting is also retrieved. Later in this chapter, you will see complete examples of how to use Export to proper parts implementing custom editor extensions.

# Accessing Services with Import Attribute

Generally, compos parts not only offer functions to other parts, but also intend to use services provided by other parts. This intention is expressed with the Import attribute.

Let's assume you want to modify the SimpleGreeting component so that it can work together with an IContextInfo-aware component, like UserInfo in the following declaration:

```
[typeof(IContextInfo)]
class UserInfo: IContextInfo
{
    public IDictionary<string, string> GetContextInfo()
    {
        return new Dictionary<string, string>
        {{\Username", Environment.UserName };
    }
}
```

The IContextInfo is a service from SimpleGreeting's point of view, and this is expressed like this:

```
[typeof(IGreeting)]
class SimpleGreeting : IGreeting
{
    [Import(typeof(IContextInfo))]
    IContextInfo ContextInfo { get; set; }

    public string SayHello()
    {
        string userName;
        var props = ContextInfo.GetContextInfo();
        props.TryGetValue("Username", out userName);
        return "Hello " + (userName ?? "<null>") + " " from Visual Studio 2010";
    }
}
```

The Import attribute here applied on the ContextInfo property, which is used in the SayHello method. The MEF takes care during the composition phase that ContextInfo will be set up and not remain uninitialized.

The Visual Studio editor offers about three dozen services that can be accessed using the pattern just described. Later in this chapter, you will see a sample to learn how the editor's classification type registry service is consumed.
