Double-click the AcmeLibraryData.mdf file in Solution Editor to display the Explorer tool window. Then, right-click the Tables node and select the Add New Table command. Add the fields shown in 18-12 to the table. Set the Id field as the primary key of the table and set its (Is Identity) property in the Columns Properties tab to Yes.

When you are finished, press Ctrl+S to save the table, and name it Book.

# Create a Model

Now, you must add a model for the Book table. Select the Models folder in Solution Explorer, and with the + New Item command in its context menu, add a new ADO.NET Entity Model item with AcmeLibraryModel.edmx to the folder. When you click OK in the Add Item dialog, the Entity Data Model Wizard starts with the "Choose Contents" page. Select the Generate from database option and click Next.

In the "Choose your data" page, select AcmeLibraryData.mdf from the connection combo box. Set the "Save entity connection settings in Web.config" checkbox and check AcmeLibraryDataEntities in the text below the checkbox. Click Next to move to the next wizard.

In the Choose Database Objects page (shown in Figure 18-13), select the Book table and check checkboxes for the database objects list. Set the Model Namespace to AcmeLibraryDataModel and click Finish.

The ADO.NET entity model is created for you. Build your project so that the ASP.NET MVC 2 tools can observe the new classes in the model.
