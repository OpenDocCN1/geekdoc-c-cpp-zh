# THE VISUAL STUDIO SHELL AND PACKAGES

Visual Studio was designed with extensibility in mind. To develop great extensions, it is very helpful to become familiar with the basic architecture that makes it possible to add your own functionality to the IDE.

Like all developers, you know that when you launch Visual Studio, devenv.exe application is started. So, you might think that devenv.exe is actually Visual Studio. If you take a look at the properties of this file (you can find it under the Common\IDE folder under the Visual Studio installation), you will discover that the file size is about 1 MB. Can the functionality of Visual Studio fit in one megabyte? Get editors, designers, compilers, debuggers (and many tools) for C#, VB, and C++ all in this executable?

Of course, this file cannot be the whole Visual Studio package, because so many functions can hardly fit into one file.
