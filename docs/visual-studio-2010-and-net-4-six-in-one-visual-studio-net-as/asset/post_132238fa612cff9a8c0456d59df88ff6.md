## A NEW GENERATION OF PRESENTATION FRAMEWORKS

In 2001, Microsoft founder Bill Gates created a new team tasked with researching and developing a new presentation layer. .NET 1.0 wasn't released at this point. At that time, there were at least four different, but overlapping, UI technologies within Microsoft: Windows Forms, GDI32, Visual Basic, and Internet Explorer’s Trident engine. The technology to be created by the new group was named "Avalon".

> You can learn more about the history and goals of Avalon in Chris Anderson’s book, Essential Windows Presentation Foundation (Reading, MA: Addison-Wesley, 2007).

The Avalon team aimed to merge the best of the web and the desktop, to integrate first-class multimedia with documents and UI, to streamline the designer-developer workflow, and to create a rich presentation platform that could easily increase the power of graphics hardware.

The first appearance of Avalon was in 2003, at the Professional Developers Conference (PDC). Later, Avalon was renamed Windows Presentation Foundation (WPF), and it appeared in version 3.0 of the .NET Framework. WPF was still a novelty at the time. With limited and (buggy) support in Visual Studio 2005, and a nonexistent designer tool, many were reluctant to climb the steep learning curve. Still, the most important thing was already there: a solid, well-thought architecture and foundation that could be built upon. The pillars of WPF are the Extensible Application Markup Language (XAML), graphics processing (GPU) rendering, a layout system, data binding, styling, templating, media, and document handling. Together, they formed an amazing toolset for building the applications most developers wouldn't even think they could.

With the release of .NET Framework 3.5 and Visual Studio 2008, WPF gained some new features and performance enhancements, as improved internationalization support and the capability to map two-dimensional elements onto a three-dimensional surface in an interactive manner.

However, the big feature push came with .NET Framework 3.5 SP1. Despite the Service Pack name, for WPF, this was more like a whole version up. Client profile introduced the isolation footprint to 25 MB for computers that didn't need the full .NET Framework. GPU-accelerated shaders allowing for include. DirectX integration allowed CAD software to have the context presented with Direct3D, as well as the controls and data display with WPF. An office ribbon was also added. Finally, Visual Studio 2008 could be used with WPF, as well as with Windows Forms.

In April 2007, Expression Blend 1.0 was released. Expression Blend (or simply "Blend") was designed to be the tool for the intermediary — the integrator who gets data, behavior, and presentation thread. Blend aligned a lot of developers with "designer-ish" look and feel, but with versions 2 and 3, it became an intuitive tool for anyone seriously working with WPF or Silverlight. Blend was the first "big" Microsoft application created in WPF. The largest is probably Visual Studio 2010. The entire UI of Visual Studio 2010 is created in WPF. Many of the performance and feature enhancements in WPF 4 were driven by the need of the Visual Studio team.

In the meantime, WPF's cousin, Silverlight (originally called WPF Everywhere, or WPF/) began to take shape. The goal was to create a trimmed-down version of the Windows-only WPF, taking the same key principles over the web, other operating systems, and devices.

Silverlight 1.0 was released in September 2007, and focused on media playback, utilizing some of the WPF XAML syntax, programmable via the browser's JavaScript engine. The real revolution came with Silverlight 2.0, which launched one year later, in October 2008. A 4 MB download, Silverlight 2.0 included a trimmed-down version of the .NET Framework, dozens of controls, XAML and media support, deep zoom, and most of the WPF pillars mentioned previously.

Silverlight 3 came only nine months later, in July 2009, with H.264 video codec and pixel shaders, limited GPU acceleration, perspective transform, out-of-browser support, touch support, and a brand new navigation framework, just to mention a few enhancements. Silverlight is officially supported on Windows and Intel-based Mac OS X computers, Firefox, Internet Explorer, and Safari.

Silverlight 4 launched in April 2010 (3 years after Silverlight 1 was introduced), and focuses on line-of-business (LOB) applications, media and out-of-browser scenarios. A Linux version of Silverlight is also in the works. Novel's Mono project is developing Moonlight, an Open Source version of Silverlight. However, Moonlight was lagging behind in its writing, still not having released Moonlight 3, which promises Silverlight 3 compatibility.

WPF 4 brings a handful of enhancements to the table. The text stack has been replaced to make text faster to render, sharper, and more legible. New controls (such as a Silverlight-compatible DataGrid, Calendar, and DatePicker) have been added. Silverlight's touch support is now officially part of WPF.
