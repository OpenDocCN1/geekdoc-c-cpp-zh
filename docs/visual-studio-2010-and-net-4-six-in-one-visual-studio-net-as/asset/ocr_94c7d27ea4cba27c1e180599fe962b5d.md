# # The XMLHttpRequest Object

The interface created by the engineers of the Outlook web Access for Microsoft Exchange Server 2000 faced the same challenge, and the engineers decided to create a new object called XMLHttpRequest that could be accessed via ActiveX from Internet Explorer 5.0. The Gecko engine implemented a new JavaScript object called XMLHttpRequest that followed the original implementation. However, neither the name nor the syntax was 100 percent the same, which resulted in a incompatibility problem among various browser versions that still persists today. The solution to the problem was discovered in many Ajax wrapper libraries over the years.

The XMLHttpRequest acts as a mini-browser in the browser. It can send HTTP requests to the server and asynchronously receive the responses, and all can be driven and handled in JavaScript.

The following code example shows the use of the XMLHttpRequest object on a page that displays the current time of the server, while other parts of the page are not updated. First, the server-side component of an ASPX page that returns the current time in a HTML fragment:

```
<@ Page Language="C# %>
<script runat="server">
    protected void Page_Load(object sender, EventArgs e)
{
        // Server-side processing.
        System.Threading.Thread.Sleep(1500);

        this.Response.Clear();
        this.Response.Write(
            "<b>Server time is " + DateTime.Now.ToLongTimeString() + "</b>");
            this.Response.Expires = -1; // Disable client cache.
        this.Response.End();
    }
</script>
```
