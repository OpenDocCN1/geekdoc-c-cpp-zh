      }

The control does not need any initialization, the Page_Load method is empty. Both the SubmitButton_Click and Editor_ContentChanged methods are fired when the page is posted back as a result of clicking the Submit button. First, Editor_ContentChanged runs then SubmitButton_Click. The HTML content of the editor is accessed through the Content property. Because it is an HTML string, you can directly assign it to the Text property of the EditorLiteral control.
