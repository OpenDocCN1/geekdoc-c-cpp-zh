+   > The Exec method is called by the IDE when a command is about and whether QueryStatus previously added that the add-in supports that command.

In the previous implementation, QueryStatus responds to the event only when the IDE is asking for the status (not for command text). It checks if the only command known by the add-in is called, and, in this case, returns a status saying, “I’m supporting the command, so you can execute it when the user clicks on the menu item, and also it is enabled on the UI.

Exec checks again if the only supported command is called. It shows the message box and signals that the command has been handled. The handle flag is important. Visual Studio can see the command to one or more add-ins (all to support command). If one command does not set the handle flag (it can leave false!), the next add-in also has the chance to handle it.
