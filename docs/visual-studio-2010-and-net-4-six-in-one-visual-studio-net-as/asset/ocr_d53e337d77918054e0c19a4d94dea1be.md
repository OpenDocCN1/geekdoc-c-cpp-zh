# # Syntactic Sugar

The design team added use “syntactic sugar” to the language right at the beginning in C# 1.0 (and they keep adding this from version by version).

**Enumeration members** in C# have their own scope, and can be used only by specifying the scope name. For example, consider the following enumeration type members:

```
enum MyPrimeNumbers
{
    Three = 3,
    Five = 5,
    Seven = 7
}
```

```
MyPrimeNumbers pickFirst = MyPrimeNumbers.Three;
MyPrimeNumbers pickThird = MyPrimeNumbers.Seven;
```

C# includes the concept of **properties**, which are special members with **accessors** (getter and setter methods) that syntactically behave like fields. This concept was not new with the development of C#; it existed before Delphi and Visual Basic 6. However, C# binds the一个个 to the scope of a property declaration, as shown in the following example:

```
class MyClass
{
    private int _CountOfMembers;

    public int CountOfMembers
    {
        get { return _CountOfMembers; }
        set { _CountOfMembers = value; }
    }
}
```
