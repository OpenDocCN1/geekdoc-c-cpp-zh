In .NET 2.0, reflection was extended to support generic type parameters. The system.Type could now represent generic types with specific type arguments (closed), or unspecified (open) types.

Also, many types in .NET 2.0 — especially collections — had been changed or added to support generics. For example, Array now has a dozen new generic methods, and there were many generic collection classes to provide a new and performance-boosted experience related to the old .NET 1.1 collection types.
