# TEMPLATE STORAGE STRUCTURE

As you just learned, project and item templates are stored as .zip archives. This archive stores files that will be artifacts when the template is transformed into a concrete project or item, and some other files with "accessory" information. When you created the project and item templates earlier, the Export Template wizard added two files to the archives:

+   - __TemplateIcon.ico — This file is used by Visual Studio as the icon representing the project or item template.
