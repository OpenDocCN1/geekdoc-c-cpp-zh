Of course, you can set up a Chart from code. You can carry out the initialization in the Page_Load event, as Listing 16-2 shows.

# LISTING 16-2: Default.aspx. cs with Simple Chart Initialization Codeusing System;

```
using System.Drawing;
using System.Web.UI.DataVisualization.Charting;

namespace SimpleAspNetChart
{
    public partial class Default : System.Web.UI.Page
    {
        protected override void Page_Load(object sender, EventArgs e)
        {
            // Set up chart title
            var title = new Title("This is an ASP.NET Chart control");
            title.Font = new System.Drawing.Font("Calibri", 24, FontStyle.Bold);
            Chart1.Titles.Add(title);

            // Set up chart type
            var series1 = Chart.Series[0];
            series1.Points.Clear();
            series1.ChartType = ChartType.SplineRange;

            // Create data points
            for (int i = 0; i <= 10; i++)
{
                Chart1.Series[0].Points.Add(new DataPoint(i, Math.Pow(Math.Abs(5 - i), 2.5)));
            }
        }
    }
}
```

The ASP.NET Chart and all related types can be found in the System.Web.UI.DataVisualization.Charting namespace. The Page_Load event handler method sets up the chart title and the Series chart type to SplineRange and creates data points using a simple formula.

Because you create data programmatically in the Page_Load event, you should remove the previously added points from Default.aspx. You can also change the size of the chart.
