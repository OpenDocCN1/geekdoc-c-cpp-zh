The System.Web.DynamicData namespace and assembly contains classes that provide the core functionality for the Dynamic Data framework, extensibility features, and customization capabilities. The tag prefix asp is registered for this namespace. For example, the following lines define a System.Web.DynamicData.DynamicDataManager as asp:DynamicDataManager:

```
<asp:DynamicDataManager Id="DynamicDataManager1" runat="server">
  AutoLoadForeignKeys="true">
  <DataControls>
    <asp:DataControlReference ID="FormView1" />
    <asp:DataControlReference ID="GridView1" />
  </DataControls>
</asp:DynamicDataManager>
```

To possible to work with the Dynamic Data framework, both the DetailView and GridView controls have been extended to display fields using templates instead of hard-coded-rules. The FormView and ListView controls implement a similar behavior by using a DynamicControl object (System.Web.DynamicData.DynamicControl) in their templates and specifying which field to display. The Dynamic Data framework builds the UI for all controls considering the specified templates.

The default validation checks the metadata in the data model (including the data types and their limitations) as the number of characters for a char-style column and null acceptance.

# Customizing the Look and Feel

The Site.css file contains the definitions for the styles used by the Dynamic Data page template and controls. Thus, you can choose to change the look and feel for the pages and control when a style is invoked.

For example, the default style for a row selected in a grid (using the combined-page mode) is the following:

```
.DDSelected {
  background-color: #ffdffb;
}
```

The following new version applies a black border color with a double style and uses a bold font to emphasize the selected row:

```
.DDSelected {
  background-color: #ffdffb;
  border: Black;
  border-style: double;
  font-weight: bold;
}
```
