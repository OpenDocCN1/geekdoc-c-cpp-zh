## Context Sensitivity

Earlier, when you added the new menu item to the main menu, you could see that the Controls list in the Commands tab of the Customize dialog contained items that cannot be seen when you load Visual Studio (a look at Figure 5-10). Also, when you use Visual Studio, several toolbars are automatically displayed or hidden, depending on your activity. For example, when you start debugging an application, the Debug toolbar is automatically shown, and when you leave the debug mode, the toolbar is hidden.

## Visual Experience Options

As you have learned, Visual Studio 2010 changed how windows are handled. The General page contains new options:

- Automatically adjust visual experience based on client performance — WPF is a technology that allows a rich user experience. This option specifies which Visual Studio sets the experience automatically, or you set the adjustment explicitly.
