For Visual Studio 2010, Microsoft has enhanced window management. This new version unifies the concept of windows, and the differentiation between the two kinds of windows has disappeared from the UI interface. Now you can dock these windows as you like. The visual feedback about the result of a window-docking operation is also much improved, so the user will know where the currently dragged window will be exactly positioned after releasing the left mouse button.

As development tasks become more complex, every developer needs more than just a code editor. One display surface, regardless of its size and resolution, cannot fulfill all of the developer's requirements. That is why the Visual Studio team added the multi-monitor support to Visual Studio 2010. Now, any window from the IDE can be dragged and aligned onto a second, third, and so on, monitor, and the IDE will remember your settings correctly. It will even reuse them for future Visual Studio starts. This feature is extended in such a way that you can have your own multi-monitor setup for, development and debug modes.

Another useful feature is that when you hold down the Ctrl key and double-click the header of a dragged-out window, the window is docked in its original position.
