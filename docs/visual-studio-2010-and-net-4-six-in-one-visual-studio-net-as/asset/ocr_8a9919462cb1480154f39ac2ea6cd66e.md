# Using Code Snippets

There are several ways to invoke code snippets. To use them, you must have at least one code editor open. The expansion and surrounding type of code snippets can be activated with separate shortcuts. The reason behind this is that a certain snippet can be an expansion and surrounding snippet at the same time. If you have selected text in the code editor, the type snippet should replace the selection with the inserted code template, while the surrounding type snippet should embed the selection into the editor.

With a C# file open, you can invoke the snippets from the Edit · IntelliSense menu, as shown in Figure 3-1.

As you can see, pressing the Ctrl+K, and then the X, is a shortcut to the Insert Snippet function, and S represents the shortcut combination to the Surround With function. The same functions presented on the Edit menu are also available on code editor context menu (accessed by using a mouse-click), as shown in Figure 3-2.
