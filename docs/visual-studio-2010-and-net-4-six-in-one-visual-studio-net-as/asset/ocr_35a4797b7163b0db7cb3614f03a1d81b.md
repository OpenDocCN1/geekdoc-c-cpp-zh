Clicking on Install immediately integrates the template with Visual Studio. Generally, after installing components, Extension Manager asks you to restart Visual Studio and provides a button to do this. however, template installation does not require a restart, and so can instantly work with the new template.

Online templates do not require an explicit installation by Extension Manager. You can also access published templates in the Gallery through the New Project and Add New Item items (you will notice that their user interface is very similar to Extension Manager).
