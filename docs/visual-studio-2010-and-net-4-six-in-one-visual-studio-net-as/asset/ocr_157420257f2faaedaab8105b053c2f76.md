This small Python code solves the quadratic equation defined in the form of Ax² + Bx + c = 0 and retrieves the results in a tuple of a Boolean (is there a solution, anyway?), and in numbers (the two possible solutions).

Copy the code in Listing 22-5 using the Module1.vb file to invoke the Python snippet.

# LISTING 22-5: Module1.vb File of IronPythonRunner

```
Option Stric Off

Imports IronPython.Hosting

Module Module

Sub Main()
Dim ipy As Object = Python.CreateRuntime()
Dim calculator As Object = ipy.UseFile("Quadratic.py")
SolveQuadratic(calculator, 1.0, 2.0)
SolveQuadratic(calculator, 2.0, 15.0, 6.0)
End Sub

Sub SolveQuadratic(ByVal Calculator Object,
ByVal A As Double,
ByVal B As Double,
ByVal C As Double)
Dim result As Object = calculator.SolveQuadratic(A, B, C)
Console.WriteLine("The quadratic equation (0)*x + (1)*x + (2) = 0*",
A, B, C)

If result(0) Then
Console.WriteLine(" has the following solutions:")
Console.WriteLine("#1: (0), result(1))")
Console.WriteLine("#2: (0), result(2))")
Else
Console.WriteLine(" has no solution.")
End If
Console.WriteLine()
End Sub
```
