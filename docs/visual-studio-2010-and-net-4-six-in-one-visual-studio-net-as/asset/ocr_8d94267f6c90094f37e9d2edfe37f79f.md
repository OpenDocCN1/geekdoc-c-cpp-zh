# ## Filtering Data from Many Related Tables

As happened with the previous database, you just made very small changes to the code provided by the template. However, in this case, there are many complex relationships that the Dynamic Data must decode to provide really useful CRUD operations and scaffolding behavior.

Follow these steps to display data from the different related tables and test the default filters offered by a more complex Dynamic Data database:

+   1. Display the `Default.aspx` page in your default browser. It will display a page with the list of tables available in the data model — in this case, the five tables, as shown in Figure 17-17.
2. Now, click the `Games` hyperlink under “My tables” (Games for the Game). The web browser will display the `Games/List.aspx` page with the data from the selected table. In this case, it also shows the Name for the GameCategoryCategory and a “View PlayerScores” button for each row. Because the Played field is of the Boolean type (`bit` in SQL Server), it uses a checkbox to display its value. Also, it displays two combo boxes, `Played` and `GameCategory`, as shown in Figure 17-18.
