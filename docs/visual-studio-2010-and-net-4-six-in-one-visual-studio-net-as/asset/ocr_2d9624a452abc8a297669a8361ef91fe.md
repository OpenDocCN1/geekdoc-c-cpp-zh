# Discovering the Effect of CascadingDropDown

You are almost ready to try the effect of CascadingDropDown extenders. Because you do not need to make an explicit postback when the ExpertiseList is populated with values or its selection is changed, the code-behind of Default.aspx gets very simple. This time, the code is not ready when you select a control expert, so the body of the ExpertList_SelectedIndexChanged method should be commented out.
