As you can see, there are a few minor modifications in the <TemplateData> section — now the name ends with Wizard. The real change is the insertion of the <WizardExtension> section that contains two child elements:

+   - <Assembly> — This names the assembly where the class implementing the wizard logic is implemented. Here, an assembly name must be specified in the GAC. Use the name put when inserting your assembly into the GAC. With simple copying, the name out from the listing prevents your wizard from working, because it probably has a different public key.

+   - <ClassName> — This specifies the full name of the class implementing the wizard logic to be used in the template. This class must be the part of the assembly and implement the IWizard interface. As you might guess, one assembly can hold not one but more wizard classes.
