# The First Breakthrough: Visual Basic

The first tool that dramatically changed Windows development was Visual Basic 1.0, released in 1991. Visual Basic introduced (or, perhaps, invented) concepts as forms, controls, code-behind files—all of which are still used in contemporary tools. Instead of writing routine files and addressing UI elements in 16-bit constants, you could drag-and-drop predefined UI controls to create your forms and program them.

# Other Languages and Tools

The whole conceptual aspect of Visual Basic was something that could be applied for C++ and other languages as well. In the few years following the release of Visual Basic, a plethora of tools was created by Microsoft:

- Visual C++1.0 was released in February 1993 with Microsoft Foundation Classes (MFC) 2.0 and proved that C++ programming for Windows could be more productive—still keeping the feel and granular control over the operating system.
- In 1992, Fox Technologies (the creator of FoxBASE and FoxPro) merged with Microsoft, and at the end of 1995, Visual FoxPro 3.0 was used.
- The emergence of the Java language in 1995 motivated Microsoft to create its own Java implementation. It was Java++1.0 that conformed to the Sun specification and used Microsoft's Java Virtual Machine (JVM).
