This page has two validator controls, for the Full Name and another for the Confirm Password field. Listing 20-26 shows an extract of the page definition.

# LISTING 20-26: ValidatorCallOutExtender.aspx (Code Extract)

![](bbox=[0.045, 0.195, 0.125, 0.235])

```
<table>
  <tr>
    <td>Full Name:</td>
    <td>
      <asp:TextBox ID="FullName" run="server" />
      <asp:TextBoxWatermarkExtender ID="WmExt" TargetControlID="FullName"
        WatermarkText="&lt;name&gt;"
        WatermarkCssClass="watermarked"
        run="server" />
      <asp:RequiredFieldValidator ID="RequiredFieldValidator" run="server"
        ErrorMessage="Full name is required."
        ControlToValidate="FullName" Display="Dynamic" />
      <asp:ValidatorCallOutExtender run="Server" TargetControlID="RequiredFieldValidator"
        HighlightCssClass="validatorCallOutHighlight" />
        CloseImageUrl="~/Images/Warning.png"
        WarningImageUrl="~/Images/Warning.png">
    </td>
  </tr>
  <tr>
    <!-- Password field omitted --
  </tr>
    <td>Confirm Password:</td>
    <td>
      <asp:TextBox ID="Password2" runat="server" TextMode="Password" />
      <!-- Passwordstrength control omitted --
      <asp:CompareValidator ID="CompareValidator1" run="server"
        ErrorMessage="The two passwords must be equal!"
        ControlToCompare="Password"
        ControlToValidate="Password2" Display="Dynamic" />
      <asp:ValidatorCallOutExtender run="Server" TargetControlID="CompareValidator1"
        HighlightCssClass="validatorCallOutHighlight"
        CloseImageUrl="~/Images/Warning.png"
        WarningImageUrl="~/Images/Warning.png">\n    </td>
  </tr>
</table>
```

Code file [ValidatorCallOutExtenderSample.aspx] available for download at W3.com.

You must specify the ControlID of the ValidatorCallOutExtender - and not the control to which the validator is attached. With HighlightCssClass property, you can set the style to apply to the callout when it is shown. You can also change the images used to display the warning sign and the glyph of the callout with the WarningImageUrl and CloseImageUrl properties, respectively.
