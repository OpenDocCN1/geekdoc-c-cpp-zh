WCF 4.0 also allows you to configure services to announce their endpoints as soon as they are started. Here is how you can configure your service to announce endpoints at start time:

```
<configuration>
  <system.serviceModel>
    <services>
      <service name="TestService">
        <endpoint binding="httpBinding" contract="ITestService"/>
        <endpoint kind="udpDiscoveryEndpoint"/>
      </service>
    </services>
    <behaviors>
      <serviceBehaviors>
        <behavior>
          <serviceDiscovery>
            <announceEndpoints>
              <endpoint kind="udpAnnouncementEndpoint"/>
            </announceEndpoints>
          </serviceDiscovery>
        </behavior>
      </serviceBehaviors>
    </behaviors>
  </system.serviceModel>
</configuration>
```

# REST Improvements

WCF 4.0 comes with improved support for REST-based features. You now have support for an automatic Help page that describes the REST-based services available for the service consumers or clients. This feature is turned on by default, yet you can also manually configure the property, as shown in the following code list:

```
<configuration>
  <system.serviceModel>
    <serviceHostingEnvironment aspCompatibilityEnabled="true" />
    <behaviors>
      <endpointBehaviors>
        <behavior name="WroxTestHelpBehavior">
          <webhttp helpEnabled="true" />
        </behavior>
      </endpointBehaviors>
    </behaviors>
  </system.serviceModel>
</configuration>
```
