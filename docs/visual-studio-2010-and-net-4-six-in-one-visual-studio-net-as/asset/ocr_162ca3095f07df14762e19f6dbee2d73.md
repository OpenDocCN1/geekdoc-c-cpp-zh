+   b. Set the current folder with the cd command to the one into which the SimpleCommentWizard.dll was compiled.

+   c. Add the assembly to the GAC gacutil -i SimpleCommentWizard.dll command.

+   2. Put down the full name of the SimpleCommentWizard.dll assembly, because you need to integrate the wizard with the project template. The easiest way is to use the gacutil -l SimpleCommentWizard command line that writes out the full name of the assembly.

+   3. Modify the Program.cs file and the template manifest within the Basic Command Console.zip to integrate the wizard and the new project template.

The last step requires some workaround, because it is not easy to modify files within a .zip archive.

The easiest way is to extract the content of Basic Command Console.zip into a temporary folder. When you are ready with the modifications, modify the template again and override the original Basic Command Console.zip file with it. Keep in mind the following things:

+   When zipping the temporary folder, select all the files in the folder, and not (the folder itself). If you zip the folder, the system will not find the manifest file and ignore your template.

+   The Basic Command Console.zip file you should override is in My Documents folder under Visual Studio 10\ProjectTemplates.

So, modify the Program.cs by adding the following lines to the top:

```
// ====================================================
// headercomment$
// ====================================================
```

The headercomment$ is the placeholder for the file header comment. The RunStarted method of the wizard will provide the value for headercomment$.
