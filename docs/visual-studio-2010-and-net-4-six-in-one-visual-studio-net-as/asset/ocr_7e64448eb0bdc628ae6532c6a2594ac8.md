After you select one or more .snippet files, click the Import button to start importing snippets. The Import Code Snippet dialog shown in Figure 3-19 is displayed to let you select the import folder for each file.

![](bbox=[0.147, 0.175, 0.712, 0.608])

**FIGURE 3-19:** Using the Import Code Snippet dialog

The left pane of the window displays the code snippet folders, while the right pane lists the user folders into which to import. When a snippet file is imported, the file is physically copied into the selected folder. As you can see from Figure 3-19, you can set the import folder for each individual file. One file can be copied into one or more than one folder. Figure 3-19 illustrates a situation when both the selected snippets are to be imported into the My Code Snippets folders, and only one of them is about to be put into the My Special Snippets.

The Code Snippet Manager allows you to import snippets only to the top-level user folders.

You can select code snippet folders supporting different languages. The Import Code Snippet dialog groups them according to their host languages. You can click the Previous and Next buttons to page among the languages and select the appropriate folder. The label above the snippet pane on the left of the dialog tells you the host language of the files listed in the pane.

When you click the Finish button, the snippet files will be instantly imported into the selected folders and are ready to use.
