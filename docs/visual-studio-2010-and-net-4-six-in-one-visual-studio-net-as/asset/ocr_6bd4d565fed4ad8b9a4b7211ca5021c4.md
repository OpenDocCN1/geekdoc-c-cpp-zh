Using a multi-project template creates more projects in the same solution. When a multi-project template is created from the New Project dialog box, every project in the template is added to the solution.

A multi-project template includes the following items, compressed into a .zip file:

+   A root .vtemplate file for the entire multi-project template — This root file contains the metadata that the New Project dialog box displays, and where to find the .vtemplate files for the projects in this template. This file must be located at the root of the .zip file.

+   One or more folders that contain the files required for a complete project template — This includes all code for the project, and a .vtemplate file for the template.

The root of the .zip archive can contain only the .vtemplate file, and all other .vtemplate files should be in subfolders within the archive. For example, a multi-project template .zip file that has two projects (WinFormsApp and FormLibrary) could have the following directories:

+   Application.vtemplate: root .vtemplate file
WinFormsApp\WinFormsApp.vtemplate: .vtemplate file for the WinFormsApp project
WinFormsApp\WinFormsApp.csproj
WinFormsApp\Properties\AssemblyInfo.cs
WinFormsApp\MainForm.cs
WinFormsApp\MainForm.Designer.cs
FormLibrary\FormLibrary.vtemplate: .vtemplate file for the FormLibrary project
FormLibrary\FormLibrary.csproj
FormLibrary\Properties\AssemblyInfo.cs
FormLibrary\UserEntities.cs
FormLibrary\SystemEntities.cs

To describe this multi-project template, you can use the <ProjectCollection> element nested inside <TemplateContent>. You can nest the following elements in <ProjectCollection>:

+   <ProjectTemplateLink> — This element represents a project in a multi-project template. It contains a required ProjectName attribute that specifies the name of the project. The value of this element is the path to the .vtemplate file describing the specific project template within the .zip archive.
