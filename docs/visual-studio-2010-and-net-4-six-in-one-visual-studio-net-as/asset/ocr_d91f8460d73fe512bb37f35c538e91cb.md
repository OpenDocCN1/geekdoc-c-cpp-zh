# WINDOW MANAGEMENT

The Visual Studio IDE was designed to provide an ergonomic workbench for its users. During application development, many types of information are displayed on the surface of this workbench. Visual Studio provides great window management to help developers establish and manage their workspace. The IDE contains two basic types of windows: tool windows and document windows. These two windows behave in slightly different ways.
