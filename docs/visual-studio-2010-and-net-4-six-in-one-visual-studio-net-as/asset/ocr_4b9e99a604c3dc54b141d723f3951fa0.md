You can also define a JavaScript function with the OnCancel property to run when the user cancels the confirmation. Setting the ConfirmSubmit to true can be useful if the page contains ASP.NET validators, and the confirm dialog box should be displayed only after all validation checks. You can also set the DisplayPopupID so that the ConfirmButtonExtender works together with a ModalPopupExtender control. You will learn about this in this chapter.
