The richness of functionality that the Editor control provides may be an issue when you want to constrain the available formatting options. You have no properties to enable or disable specific editor features. However does not mean you cannot solve this You can derive a custom ASP.NET control from Editor, customize it, and use this edited version in your pages.

The ActControlSamples project contains an example of this customization. There is a page named CustomEditorSample.aspx which is an exact copy of EditorSample.aspx you've seen earlier — it uses an Editor-derived class instead. Listing 20-18 shows how easy it is to carry out the customization.
