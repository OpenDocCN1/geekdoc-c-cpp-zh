Each command is defined by a vs:Image type (which is implemented in the Microsoft.VisualStudio.Shell.11.0 assembly) and has a few properties influencing its appearance and behavior. The ImageNormal, ImageHover, and ImagePressed properties allow the image resources to be defined for the specific states of command buttons. In 5-3, only partial parts are indicated. In the original StartPage.xaml file for the full resources.

The x:Uid defines the unique identifiers of commands that can be used to access them programmatically. Theoretically Command is defined so that they execute the Visual Studio IDE Shell identified with the name in the CommandParameter. The names used here are exactly the same as you use in the Command Window (View > Other Windows).

As you see, the context of the Start Page contains properties to check the availability of Visual Studio features. For example, the Team Foundation Server button contains the following binding for its Visibility:

```
Visibility="Binding Path=TeamFoundationClientSupported,
Converter=(StaticResource BoolVisibilityConverter)"
```

Here, the TeamFoundationClientSupported binding allows showing or hiding this command button, depending on whether the loaded Visual Studio edition supports Team Foundation integration
