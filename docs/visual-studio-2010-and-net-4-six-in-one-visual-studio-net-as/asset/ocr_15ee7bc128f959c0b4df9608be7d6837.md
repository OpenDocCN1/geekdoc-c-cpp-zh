There are a few points to remember about lists:

+   - **Lists are immutable** — As you saw at the beginning of this chapter, immutability plays an important role in functional programming, and is especially true for one of its fundamental data structures — lists. For example, when you cons (add to the front) a new element to a list, or concatenate two lists, you get a new list.
- **Lists are eager** — One way to ensure that a collection of values is fully computed is to convert it to a list. This is a typical pattern, and you will see it often when you work with lazy sequences (see later in this chapter) and the kind of objects they wrap (LINQ query results).
- **Lists are generic** — Because the standard .NET collection type (of which the F# list type is a sub type) is generic, F# lists can store values of arbitrary types.
