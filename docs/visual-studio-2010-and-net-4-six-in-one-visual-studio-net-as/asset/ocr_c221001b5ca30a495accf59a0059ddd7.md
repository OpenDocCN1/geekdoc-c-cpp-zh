The MyControl tab item uses the StartPage.TabStyle dynamic resource just like the other tabs to define the preferred appearance. The content of this tab is to set up an instance of the MyControl WPF user control defined in the SimpleStartControl project.

The MyControl.xml file defines the control's appearance, as shown in Listing 5-5.

# LISTING 5-5: MyControl.xml

```
<UserControl x:Class="SimpleStartPageControl.MyControl"
xmlns="http://schemas.microsoft.com/winfx/2006/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xml"
xmlns:mc="http://schemas.microsoft.com/markup-compatibility/2006"
xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
xmlns:vs="http://schemas.microsoft.com/visualstudio/shell"
assembly:Name="Microsoft.VisualStudio.Shell,10.0"
mc:Ignorable="d"
d:DesignHeight="300" d:DesignWidth="300">
  <Grid Backgrounds="x:Static Resource=VsBrushes.StartPageBackgroundKey">
    <Border Margin="0" CornerRadius="10" BorderThickness="3"
            Brush="x:Static Resource=VsBrushes.StartPageSeparatorKey">
      <StackPanel VerticalAlignment="Center">
        <TextBlock Foreground="x:Static Resource=VsBrushes.StartPageTextBodyKey">
          <TextBlock Text="My Start Page Control" FontSize="18"
                     HorizontalAlignment="Center"/>
          <TextBlock Text="{Binding Path=DTE.Name}" FontSize="12"
                     HorizontalAlignment="Center"/>
        </TextBlock>
      </StackPanel>
    </Border>
  </Grid>
</UserControl>
```

As seen from the line, the control definition utilizes the resource keys defined by the VsBrushes class. The control encapsulates two TextBlock elements; the second displays the name of the application (Microsoft Visual Studio). The tool window displaying the Start page creates a data context where a DTE object (the root object of the Visual Studio run-time object that can be used from extensions such as, add-ins, or Packages) is packaged through the DTE property. The DTE.Name binding path retrieves the application name.
