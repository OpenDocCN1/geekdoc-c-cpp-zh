## The DataManipulator

The chart has a property named DataManipulator that exposes an instance of a class called DataManipulator. You can use this to perform data-manipulation operations at runtime. These operations include copying values, filtering, grouping and sorting data, exporting data to a DataSet object, and applying a formula to data.

You can download the source code for the DataManipulatorSample application to check out how the manipulations treated in this section can be implemented. This implementation contains a simple chart with two chart areas. The primary area is the input the DataManipulator class works with, while the secondary area displays the results. The code snippets shown in this section are extracted from the MainForm.cs file of the source code; most of them are simple menu item event handler methods.

In this section, you will find an overview of DataManipulator features. There are a few features not treated here. For more details, see the DataManipulator documentation in MSDN at http://msdn.microsoft.com/en-us/library/dd456766(VS.100).aspx.

## Filtering

The DataManipulator supports three kinds of filtering:

- You can filter the top N values.
- You can filter data points matching simple criteria.
- You can create your own filter.

You can use the FilterTop method for top values, as shown in the following code:

```csharp
private void FilterTop_Click(object sender, EventArgs e)
{
    chart1.DataManipulator.FilterEmptyPoints = true;
    chart1.DataManipulator.Filter(10, "Series1", "Series2");
}
```

The first argument of FilterTop is the number of points, the other two parameters are input and output, respectively. The result is shown in:

When you need to filter data points within a range, you must implement the IDataPoint interface, as shown below:

```csharp
public class BetweenFilter : IDataPoint
{
    private double lowerValue;
    private double upperValue;

    public BetweenFilter(double lower, double upper)
    {
        lowerValue = lower;
        upperValue = upper;
    }

    public bool FilterPoint(DataPoint point, Series series, int pointIndex)
    {
        return point.YValues[0] > upperValue || point.YValues[0] < lowerValue;
    }
}
```

You can use the customFilter class as follows:

```csharp
private void CustomFilter_Click(object sender, EventArgs e)
{
    chart1.DataManipulator.FilterEmptyPoints = true;
    chart1.DataManipulator.Filter(new BetweenFilter(10.0, 60.0), "Series1", "Series2");
}
```

## Sorting Data

The DataManipulator provides a Sort method that orders your data points in ascending or descending order. Using the Y value data of the specified series by default, orders the Series.Points collection accurately. However, ordering your data points does not change the X values. For most chart types, you will not see that the data points are ordered! The chart output remains unchanged because using only the X and Y value properties of a data point, ignores their physical order within the Series.Points collection.

To cope with this situation, you may align the data points so that their X values reflect the sort position. The following code extract shows how you can implement it:

```csharp
private void SortDataMouseClicked(object sender, EventArgs e)
{
    var series2 = chart1.Series[1];
    chart1.DataManipulator.Sort(PointSortOrder.Descending, series2);
    AlignSeries(series2);
}
// ...
private void AlignSeries(Series series)
{
    for (int i = 0; i < series.Points.Count; i++)
    {
        series.Points[i].XValue = i;
        series.Points[i].IsEmpty = false;
    }
}
```

After calling the Sort method, the AlignSeries method resets the X values of the series. Because Series.Points contains data points in descending order, aligning the X values will cause the secondary chart to be displayed correctly, as shown in Figure 14-50.
