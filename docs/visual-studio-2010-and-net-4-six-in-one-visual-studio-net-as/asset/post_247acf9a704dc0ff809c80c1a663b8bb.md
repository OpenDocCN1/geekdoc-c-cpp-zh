
# Binding a Data Source to the Chart

A natural (and simpler method) is to bind the chart to a data source. Let's bind the chart to the result of a LINQ expression that retrieves the top ten processes by means of consumed memory. Add a new code file to the ProcessInfoChart project with ProcessInfo.cs. Listing 14-2 shows the content you should copy into this file.

```cs
using System.Collections.Generic;
using System.Diagnostics;
using System.Linq;

namespace ProcessInfoChart
{
    public class ProcessInfo
    {
        public string Name { get; set; }
        public long WorkingSet { get; set; }
        public long PeakWorkingSet { get; set; }
    }

    public class ProcessList
    {
        public static IEnumerable<ProcessInfo> GetTopWorkingSet(int topN)
        {
            return (from process in Process.GetProcesses()
                    orderby process.WorkingSet64 descending
                    select new ProcessInfo
                    {
                        Name = process.ProcessName,
                        WorkingSet = process.WorkingSet64,
                        PeakWorkingSet = process.PeakWorkingSet64
                    }).Take(topN);
        }
    }
}
```

One instance of the ProcessInfo class describes a data point in the chart. The ProcessList static class encapsulates the GetTopWorkingSet method that returns a collection of data points representing the processes.

The next step is creating a data source with Visual Studio. Build the project so that you can select ProcessInfo as the type of data source.

Select chart in the design surface of MainForm and scroll down to the Data category in the Properties window. Click the DataSource property. Click the arrow to the right of the property value. In the drop-down list, click the Add Project Data Source link to start setting up a data source.

When the Data Source Configuration Wizard appears, choose the Object data source type and click Next. Expand ProcessInfoChart. Mark the ProcessInfo class as shown in Figure 14-11.

![](img/b5597c749e848b27b0d305153ae16106_642_0.png)

**FIGURE 14-11:** Selecting the data source object type

Click Finish. The wizard generates the processInfoBindingSource for you, and sets it as the data source of chart. Of course, this object does not know the real data, but knows the "shape" of the data that is represented by the ProcessInfo type. In order to display chart, you must declare how to extract series from the data source.

Start the Collection Editor to set up data source binding information for each series. Select Revenue and rename it by changing the Name property to WorkingSet. Scroll down to the DataSource category and set the XMember property to Name, and set Ymembers to WorkingSet. You can select these values from the drop-down list, as shown in Figure 14-12.

![](img/b5597c749e848b27b0d305153ae16106_642_1.png)

**FIGURE 14-12:** You can drop-down list to select value members

Change the Cost name to Top Working Set. Set XValueMember to Name and YValueMembers to PeakWorkingSet.

The chart application contains false titles, so to fix them is to Start the Title Collection editor and change the (Text) properties of Title1, Title2, and Title3 to Process Information Charts, Top 10 Processes by Working Set, and Top 10 by Peak Working Set, respectively.

At this point, the chart's visual properties are set up. The only thing that remains is to bind the data coming from the ProcessList.GetTopWorkingSet() method to the chart. It's simple. In the MainForm_Load event, you can set this binding as shown in Listing 14-3.

# LISTING 14-3: MainForm.cs Modified for Data Binding

```cs
using System;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;

namespace ProcessInfoChart
{
    public partial class MainForm : Form
    {
        public MainForm()
        {
            InitializeComponent();
        }

        private void MainForm_Load(object sender, EventArgs e)
        {
            processInfoBindingSource.DataSource = ProcessList.GetTopWorkingSet(10);
        }
    }
}
```

# Adding Charts to WPF Applications

Unfortunately, Microsoft did not package a Windows Presentation Foundation (WPF) chart control with .NET Framework 4.0. However, that does not mean you must surrender the Chart control in WPF applications. Let's create a simple WPF application using a Windows Forms chart.

Start a new WPF project and name it WpfSimpleChart. Add a reference to the WindowsForms assembly. The main windows of this application will have Windows Forms control, so change the MainWindow.xml file as shown in Listing 14-4.

```xml
<Window x="WpfSimpleChart.MainWindow" xmlns="http://schemas.microsoft.com/winfx/2006/xml/presentation" xmlns:x="http://schemas.microsoft.com/winfx/2006/xml" Title="MainWindow" Height="350" Width="525" Loaded="Window_Loaded">
  <WindowsFormsHost HorizontalAlignment="Stretch" Name="ChartHost" VerticalAlignment="Stretch" />
</Window>
```

![](img/b5597c749e848b27b0d305153ae16106_644_0.png)

Code file [MainWindow.xml] available for download at Wrox.com

The WindowsFormsHost control will embed the chart. This user control is assigned to the Window_Loaded event.

Create a new Windows Forms Control and name it SimpleChart. Draw a chart from the Toolbox to the design surface, and set the Dock property of chart1 to Fill. This user control will show the chart in Figure 14-14.

![](img/b5597c749e848b27b0d305153ae16106_644_1.png)

# LISTING 14-5: SimpleChart.cs

```cs
using System.Drawing;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;
using System;

namespace WpfChart
{
    public partial class SimpleChart : UserControl
    {
        public SimpleChart()
        {
            InitializeComponent();
            SetupChart();
        }

        private void SetupChart()
        {
            var title = new Title("This is a Windows Forms chart in WPF");
            title.Font = new System.Drawing.Font("Calibri", 18F, FontStyle.Bold);
            chart1.Titles.Add(title);
            var datapoints = chart1.Series[0].Points;
            for (int i = 0; i <= 0; i++)
                datapoints.Add(new DataPoint(i, Math.Pow(Math.Abs(5-i), 2)));
        }
    }
}
```

# LISTING 14-6: MainWindow.cs

```cs
using System.Windows;

namespace WpfSimpleChart
{
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
        }

        private void Window_Loaded(object sender, RoutedEventArgs e)
        {
            ChartHost.Child = new SimpleChart();
        }
    }
}
```
