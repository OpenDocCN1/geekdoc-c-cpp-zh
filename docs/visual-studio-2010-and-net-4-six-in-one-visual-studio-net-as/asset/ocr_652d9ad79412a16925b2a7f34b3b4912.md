In April 2007, Expression Blend 1.0 was released. Expression Blend (or simply "Blend") was designed to be the tool for the intermediary — the integrator who gets data, behavior, and presentation thread. Blend aligned a lot of developers with "designer-ish" look and feel, but with versions 2 and 3, it became an intuitive tool for anyone seriously working with WPF or Silverlight. Blend was the first "big" Microsoft application created in WPF. The largest is probably Visual Studio 2010. The entire UI of Visual Studio 2010 is created in WPF. Many of the performance and feature enhancements in WPF 4 were driven by the need of the Visual Studio team.

In the meantime, WPF's cousin, Silverlight (originally called WPF Everywhere, or WPF/) began to take shape. The goal was to create a trimmed-down version of the Windows-only WPF, taking the same key principles over the web, other operating systems, and devices.

Silverlight 1.0 was released in September 2007, and focused on media playback, utilizing some of the WPF XAML syntax, programmable via the browser's JavaScript engine. The real revolution came with Silverlight 2.0, which launched one year later, in October 2008. A 4 MB download, Silverlight 2.0 included a trimmed-down version of the .NET Framework, dozens of controls, XAML and media support, deep zoom, and most of the WPF pillars mentioned previously.

Silverlight 3 came only nine months later, in July 2009, with H.264 video codec and pixel shaders, limited GPU acceleration, perspective transform, out-of-browser support, touch support, and a brand new navigation framework, just to mention a few enhancements. Silverlight is officially supported on Windows and Intel-based Mac OS X computers, Firefox, Internet Explorer, and Safari.

Silverlight 4 launched in April 2010 (3 years after Silverlight 1 was introduced), and focuses on line-of-business (LOB) applications, media and out-of-browser scenarios. A Linux version of Silverlight is also in the works. Novel's Mono project is developing Moonlight, an Open Source version of Silverlight. However, Moonlight was lagging behind in its writing, still not having released Moonlight 3, which promises Silverlight 3 compatibility.

WPF 4 brings a handful of enhancements to the table. The text stack has been replaced to make text faster to render, sharper, and more legible. New controls (such as a Silverlight-compatible Datag, Calendar, and DatePicker) have been added. Silverlight's Visual Manager is now officially part of WPF. Touch and manipulation APIs to handle Windows 7's multitouch capabilities are borrowed from the Surface Desktop SDK. WPF also borrowed Silverlight 3's GPU caching and layout rendering features, and added Pixel Shader 3 support.
