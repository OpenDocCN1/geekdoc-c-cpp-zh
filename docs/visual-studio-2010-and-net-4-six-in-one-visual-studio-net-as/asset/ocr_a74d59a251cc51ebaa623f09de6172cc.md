You can combine selectors and filters. For example, you can set the background of table cells that do not have any albums with "Bells" in the album name with the following code:

```
function backTo() {
  $(td:not(contains('Bells'))).attr("class", "yellowBack");
}
```

Here, the td selects all table cells. The :contains('Bells') filter selects those that have "Bells" in their text, and the :not filters out those that match with :contains('Bells'). expression The affected table cells have a yellow background.

Another query expression is implemented behind the "Second paragraphs to Green" button. It sets the color of the paragraphs in the table cells (the paragraphs containing the years) only when there is "19" in the query text. The code behind the function is very simple:

```
function secondParagraph() {
  $(p-p:contains('19')).attr("class", "green");
}
```

The first p in the query selects all paragraphs <p> elements. The +p selection selects the next siblings. The :contains('19') expression filters out those that contain 19 in their text. Let's say that you insert non-paragraph text between the <p> elements, like this:

```
<td valign="top">
  <p>Early albums</p>
  <h3> early</h3>
  <p>(1973-1979)</p>
  <ul id="earlyAlbums" class="list">
    <li class="item">Tubular Cells</li>
    <li class="item">Herget Ridge</li>
    <li class="item">Ommadaw</li>
    <li class="item">Incantations</li>
    <li class="item">Exposed</li>
  </ul>
</td>
```

The p-p expression will not match the "1973-1979" paragraph because it is not subsequent with "Early albums". However, it would match with it.

# TABLE 20-13: Attribute Filters Supported by jQuery

| ATTRIBUTE FILTER | DESCRIPTION |
|---|---|
| [attribute] | Returns all elements that have the specified attribute. |
| [attribute = value] | Returns all elements that have the specified attribute set to the specified value. |
| [attribute != value] | Returns all elements whose specified attribute (if present) has a value different from the given one. |
