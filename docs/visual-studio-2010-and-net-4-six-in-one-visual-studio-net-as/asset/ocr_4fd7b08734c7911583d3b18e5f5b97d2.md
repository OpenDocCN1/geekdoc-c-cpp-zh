# # Base Class Library

For the reasonable and efficient use of the functions of the CLR and Win32 APIs, developers need a lot of base objects wrapping the functions into usable-objects by .NET languages. The main goal of the Base Class Library is to provide infrastructure services to the developers — services that provide a good and safe layer over the system's Win31 API.

The folder of base classes contains a lot of assemblies. The most important is the mscorlib.dll file, which contains the most-used types and useful functions for general programming. .NET component you develop, in whatever architecture, you always use the mscorlib.dll assembly.
