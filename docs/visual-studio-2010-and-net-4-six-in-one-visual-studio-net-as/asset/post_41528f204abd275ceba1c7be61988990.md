## Support for HTTP Pipelining and Syndication Feeds

After caching an ASP.NET request by IIS, a web server assigns a unique token based on the authentication model (Windows, Basic or Digest). This token is alive during the session and is tied with the whole worker process.

The account used in the request depends on the impersonation configured in the ASP.NET application. The default setting is that impersonation is disabled, but in this case, the thread runs under the default account of the worker process, which is not good, because it opens up a lot of attack capabilities.

The ASP.NET worker process has one main task. It handles the request over to the HTTP pipeline, which is a chain of managed objects activated by creating a new instance of the HttpRuntime class.

# 16 # ASP.NET Charting Controls

For a long time, no Chart controls were shipped with Visual Studio. If you wanted to use them, you had to buy one from user interface (UI) component vendor, or download Open Source charting components with the appropriate license. With Visual Studio 2010 and .NET Framework 4.0, Microsoft ships two Chart controls — one for Windows Forms applications, and another for ASP.NET applications. In Chapter 14, you learned about one of them, the features of the Windows Forms Chart.

Although ASP.NET and Windows Forms are very different in their UI principles, the two Chart controls share the same concepts. After you have learned one of them, you can start using the other one in a few minutes.

With Visual Studio 2010, you can drag a Chart control directly from the Toolbox to your design surface. You can easily set up both Chart controls through the dozens of properties they exploit. Charts have great design-time support. When you change a property, the design-view changes immediately.

You can choose from more than 30 chart types and customize them through general and chart type-specific properties. The Chart control supports data binding and many manipulations, including filtering, sorting values, and applying financial formulas.

Most concepts of the Windows Forms Chart control treated in Chapter 14 are the same for the ASP.NET Chart control, including the chart elements and their structure, most property and method names, chart types, three-dimensional chart handling, customization, data manipulations, and many more.
