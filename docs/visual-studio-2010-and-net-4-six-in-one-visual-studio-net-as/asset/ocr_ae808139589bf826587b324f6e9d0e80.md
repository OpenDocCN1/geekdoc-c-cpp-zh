Keep in mind, however, that redefining functions or types will not have any effect on what you have already entered unless you redefine the consuming functions also. In other words, anything you enter is parsed and interpreted using lexical scoping. You can think of redefinitions as creating a new definition with a name that just happens to be the same as that existed already, which is now unreachable.

If you want to restart your interactive session, type `exit 1;`.

F# is a script-language, with very light, concise, and almost math-like syntax. It lends itself to exploratory programming, enabling you to quickly prototype short (but powerful) functional programs that are easy to maintain.

```
// Compute number based on a list of integers.
// Returns Nan and reports an error if any of the
// numbers are prime or on division by zero.
let lillyComputation numbers = // Global function
  let translate x =
    let isEven n = n%2 = 0 // Local, nested function
    let isPrime n =
      if n > 1 then // If-then-else
        (2 .. n/2) // Sequence
        |> Seq.exists (fun i -> n%i = 0) // Piping into a HOF
      else false
    if isPrime x then // If-then-elif-else
    failwith "Can't compute XYZ" // Raising a failure
  elif isEven x then
    -1./float x
  else
    1./float x
try
  numbers // try-with
    |> List.map translate
    |> List.reduce (+)
    |> fun res -> -res // Anonymous function
with
  |> Failure msg -> // Pattern matching
```
