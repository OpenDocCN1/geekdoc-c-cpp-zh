“A colleague of mine (Anders) and I spent about two months brainstorming ideas how we could build a programming model that delivered all of this. Eventually, we decided to put together a prototype to try out the concepts, and I ended up coding it over the Christmas and New Year's holiday in 1997/1998 (I was a hardcore geek then). We showed the prototype to a lot of people within the company, built a lot of excitement, and got the go-ahead to build a team it.

The name of the initial prototype was “XSP”. Guthrie explained in a 2007 interview, “People would always ask what the ‘X’ stood for. it really didn’t stand for anything. XML started with XSLT; Everything cool seemed to start with an ‘X’, so that is what we named it.

The initial prototype of XSP used Java, but it was soon decided to try to build it on top of the .NET Common Language Run-time (CLR) of its benefits. Guthrie said in the New York Times that this decision was an extremely huge risk, the success of the new XSP platform would be dependent on the success of the CLR that was in its infancy. So first real test of CLR was the XSP team in Microsoft.

With this decision, the XSP prototype was re-developed in C# (known internally as “Project Cool”) that was also secret from the public. At the same time, it was renamed to “ASP+ because this new platform was the successor of ASP, and the easy migration from ASP was announced on May 2, goal of the project.

The first demonstration of ASP+ was at the ASP Connections in Phoenix on May 2, 2000, by Anders. The first public demonstration was made at the Professional Developer Conference (PDC) on July 11, 2000, in Orlando, Florida. In Bill Gates’ keynote presentation, ASP+ was demonstrated with COBOL, but support of other languages (Visual Basic .NET and C#) was also announced. Python and Perl support was announced as third-party interoperability tools.

The final name of ASP.NET was decided when the “.NET branding was introduced by Microsoft in the second half of 2000. Anders explained:

> “The .NET initiative is reality about a number of factors. It’s about delivering software as a service; it’s about XML and web services and really enhancing the Internet in terms of what it can do ... we really wanted to bring its name in line with the rest of the platform pieces that make up the .NET framework.”

According to Microsoft’s official ASP.NET website, “Microsoft ASP.NET is a free technology that allows programmers to create dynamic web applications. ASP.NET can be used to create anything from small, personal websites to to large, enterprise-class web applications. All you need to get started with ASP.NET is the free .NET Framework and the free Visual Web Developer.

One of ASP.NET’s main goals was to simplify the learning path of developers from Windows application development to web development.
