+   1. Open the Site.css file.

+   2. Add a new style to add a background color for the control, DDText:

```
.DTextBoxEdit
{
  background-color: #0000FF;
  color: #FFFFFF;
  font-weight: bold;
}
```

+   3. Now, add the DateTime_Edit.ascx field template and replace CssClass="DTextBox" with CssClass="DTextBoxEdit", as shown in Listing 17-4. This, the textbox displayed when editing the DataType data type will apply the previously defined style to use a different background.
