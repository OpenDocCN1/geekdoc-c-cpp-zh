The wizard added several assemblies to the class library project in addition the ones belonging to a class library by default. Their names start with the Microsoft.VisualStudio prefix, and most of them are interoperability assemblies having Interop in their names. These contain only proxy type definitions to access the core Visual Studio COM service interface and objects.
