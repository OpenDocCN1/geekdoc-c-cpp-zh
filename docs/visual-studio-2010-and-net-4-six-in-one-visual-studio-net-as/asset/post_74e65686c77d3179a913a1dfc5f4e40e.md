
# ASP.NET Ajax Control Toolkit and jQuery

In Chapter 19, you learned anew about the Ajax improvements and saw several examples of using the ASP.NET Ajax Library. You also read about jQuery library and used jQuery in a few samples.

If you do not have any server-side technologies, but rather just a simple web server with standard HTTP/HTTPS protocol, you can still use both of them. However, most applications work with information, and the nature of these applications is that they store and handle data at the server side — somewhere in the Internet cloud — and not at the client.

This chapter dives deeper into the ASP.NET Ajax Control Toolkit and the jQuery technology. These are two important pieces of the fullIPSETSET that you can use together with your ASP.NET applications to improve the user experience.

# FIRST LOOK AT THE AJAX CONTROL TOOLKIT

The ASP.NET Ajax Control Toolkit contains a rich set of ASP.NET-server-side controls that you can use to build highly responsive and interactive Ajax-enabled Web applications. It is often referred to as simply the Ajax Control Toolkit, and this chapter refers to it as the "Toolkit".

The Toolkit contains more than 40 frequently used controls, including the AutoCompleteExtender, ComboBox, CollapsiblePanelExtender, Accordion, and many more. Most of them simple, add power, functionality to your websites, and improve the user experience. Although, at the end of the day, JavaScript is used at the client side, the controls in the Toolkit remove the majority of JavaScript-related programming challenges from your task list.

Using the Ajax Control Toolkit, you can build Ajax-enabled ASP.NET Web Forms by dragging and dropping controls from the Visual Studio Toolbox onto a Web page and then using them like any other ASP.NET server-side controls.

The ASP.Net Ajax Control Toolkit started its life as an Open Source project in May 2006, and it is still a very active project. You can find it on Codeplex (http://www.codeplex.com/AjaxControlToolkit). It is a joint effort between Microsoft and the ASP.NET community. Controls provided by the project are built on top of the Microsoft ASP.NET framework. The Toolkit was designed to support not only Internet Explorer, but also Firefox, Safari, Opera, and Chrome. Most controls work seamlessly and independently of the browser you use. However, there are a few compatibility issues. The project tracks them and provides service releases on a regular basis.

# Installing the Ajax Control Toolkit

You can download the latest version of the ASP.NET Ajax Control Toolkit from its home on Codeplex by clicking on the Downloads tab. As of writing, the freshest version was the ASP.NET Ajax Library Beta 0911 (released on November 18, 2009). As the name of download indicates, this is not only the Ajax Toolkit, but also the ASP.NET Ajax Library now includes all the ASP.NET Web Forms controls that were in the original Ajax Control Toolkit.

When you download and extract the library, you can find the Ajax Control Toolkit in the AjaxNetLibrary\WebForms subfolder under the root where you extracted the downloaded file. You will also find there the ReleaseToolkit.dll file, as shown in

**20-1. The Debug folder also contains the Debug build of this assembly.**

You can integrate the Toolkit with Visual Studio by adding the controls to the Toolbox. Open an ASP.NET Web Application in Visual Studio 2010, or create an ASP.NET Web Application project. Add a New Form to name it, for example, Default.aspx.

Open an .aspx file (for example, Default.aspx) so that you display Visual Studio Toolbox. Right-click on any toolbox item (the Extensions tab) and add the Add tab. A new empty tab appears. Name it “Ajax Toolkit”. This tab is just a placeholder for controls, since it does not contain any controls. Right-click on this tab and run the Choose Items.

When the Choose Toolbox Items dialog appears, select the .NET Frameworks Components tab. Click the Browse button and select the AjaxControlToolkit.dll from the Release folder shown in Figure 20-1. Visual Studio will warn you that you are adding a file downloaded from a network location, which could potentially harm your computer. Confirm you really want to. The new controls found in AjaxControlToolkit.dll will be selected in the dialog, and marked to be added to the tab. Close the dialog by clicking the OK button, and Visual Studio adds all the controls in the assembly to the tab, as shown in Figure 20-2.

Of course, Figure 20-2 you can see only part of the controls added. The Ajax Control Toolkit provides more than 40 controls you can add to your pages.

# Controls installed with the Toolkit

When you look at the names of controls you find:

- Standard controls — These have a simple name, such as Rating, Accordion, TabContainer, and so. These are simple controls that work like any other ASP.NET.
- Control extenders — These are easily recognized because their names end “Extender” by convention (with a few exceptions). As the names suggest, a extender extends the functionality of an existing control.

# Upgrading to a New Version

If you have already installed an older version of the Toolkit, or you have downloaded a new one and you want to change your projects using this latter, you can avoid annoying versioning issues with a few recommended steps:

1. Open the ASP.NET web project (solution) you intend to upgrade and remove all references to AjaxControlToolkit.dll.
2. Right-click on the project in Solution Explorer, and run the Open Folder command from Windows Explorer. When the Explorer opens, go into the bin folder and delete AjaxToolkit.dll.
3. Add a new Dummy.aspx file to your project. Go to the Toolbox and right-click the Ajax Control tab. Remove the tab to remove all controls previously added.
4. Follow the steps described earlier to add the controls of the New version to the Toolbox.
5. Temporarily drag a control (for example, ComboBox) from the Ajax Control Toolkit to Dummy.aspx. Visual Studio will add the reference to AjaxControlToolkit assembly (of course, to the new version you have just installed).
6. Delete Dummy.aspx.

If you have more than one ASP.NET Web Application in your solution, repeat these steps for each project. Of course, you must remove the Ajax Control tab from the Toolbox and add the new controls only once.
