When the action method retrieves the ActionResult instance, the controller interprets the result and decides what activity to take. In the case of the Index and About actions, the result is a View, so the controller navigates to the view implicitly or explicitly named by this result.

# # The View

The Index and About views defined in the Index.aspx and About.aspx pages in the Views/ folder are simple, as shown in Listing 18-8 and Listing 18-9.

LISTING 18-8: Index.aspx

```
<%@ Page Language="#C" MasterFilePath="~/Views/Shared/Site.Master"
Inherits="System.Web.Mvc.Page" %>
<asp:Content ID="Content1" ContentHolderID="TitleContent" runat="server">
  Home Page
</asp:Content>
<asp:Content ID="Content2" ContentHolderID="MainContent" runat="server">
<h2><%: ViewData["Message"] %></h2>
<p>
  To learn more about ASP.NET MVC visit
  <a href="http://asp.net/mvc" title="ASP.NET MVC Website">http://asp.net/mvc</a>
</p>
</asp:Content>
```

LISTING 18-9: About.aspx

```
<%@ Page Language="#C" MasterFilePath="~/Views/Shared/Site.Master"
Inherits="System.Web.Mvc.Page" %>
<asp:Content ID="aboutTitle" ContentHolderID="TitleContent" runat="server">
  About Us
</asp:Content>
<asp:Content ID="aboutContent" ContentHolderID="MainContent" runat="server">
<h2>About</h2>
<p>
  Put content here.
</p>
</asp:Content>
```

*Code file [About.aspx] available for download at Wrox.com*

As you can see, both pages provide the <asp:Content> tags that match the attribute <asp:ContentPlaceHolder> tags in the main page (Site.Master). Index.aspx in Listing 18-8 uses the ViewData to extract the "Message" property encapsulated in the view.
