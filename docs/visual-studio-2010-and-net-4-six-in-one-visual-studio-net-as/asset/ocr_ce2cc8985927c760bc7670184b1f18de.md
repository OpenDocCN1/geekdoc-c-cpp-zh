Set the name of the project to MySimpleAddIn and click the OK button. The Visual Studio Add-In Wizard starts and displays a welcome page. Click Next to get the first information page, where you can select the programming language to use. As you see in Figure 6-17, you can select from four alternatives - C#, VB, managed C++, and native C++/ATL.

Select the "Create an Add-in using C#" option and click Next. second page of the wizard allows you to select a host application which to embed your add-in. As shown in Figure 6-18, the add-in can be hosted by the Visual Studio 2010 IDE or the Macros IDE. You can select both options on this page. In that case, your add-in will be integrated into both applications. For right now, check only Microsoft Studio 2010.
