# TABLE 17-3: Root Level Files in an ASP.NET Dynamic Data Website

| FILE | DESCRIPTION |
| --- | --- |
| Default.aspx | ASP.NET page displays the tables and views registered in the associated meta-model. As previously explained, each table or view rendered as a HyperLink control, and when the user clicks on, the selected table lists its contents. |
| Global.asax | This registers an instance of the MetaModel class (System.Web.DynamicData.MetaModel), representing one or multiple databases, and adds routes to the RouteCollection object as previously described. |
| Site.css | This is the cascading stylesheet (CSS) used by all the Data page templates and controls. |
| Site.master | This is the master page for the website. Both Default.aspx and all the Dynamic Data pages use this master page. |
| Web.config | This is the XML-based configuration file for the website. |

# TABLE 17-4: Folders Found Inside the DynamicData Folder in an ASP.NET Dynamic Data Website

| FOLDER | DESCRIPTION |
| --- | --- |
| Content | This contains the Images sub-folder and the GridView control. The Images sub-folder contains all the GIF images as icons in the control responsible for allowing the user to switch between multiple pages. |
| CustomPages | This folder is empty by default. It allows defining custom page templates to override the default page templates in the PageTemplates folder for a specific table. |
| EntityTemplates | This contains the entity templates that are responsible for creating the UI to view, edit, and insert data. |
| FieldTemplates | This contains the controls used to create the UI to view and edit the data for each different field type. |
| Filters | This contains the controls used to create the UI to filter the data rows being displayed. As previously explained, there are three filter templates. |
| PageTemplates | This contains the page templates that create the UI for all orders supported by Dynamic Data. This folder contains the page templates that you were using during the different examples: Details.aspx; Edit.aspx; Insert.aspx; List.aspx; and ListDetails.aspx. As previously discussed, the URL routing defined in the Global.asax file defines which page to call for each action. |
