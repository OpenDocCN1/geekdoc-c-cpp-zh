# Additional Layout Containers and Controls

While WrapPanel made its way into the Silverlight Toolkit, Viewbox is now in the core WPF runtime with few layout containers — ListView, DockPanel, and UniformGrid.

ListView allows listing its items in a list or grid (or custom) list, displaying its items similarly to Windows Explorer.

DockPanel's children have a DockPanel.Dock attached property instructs DockPanel where to dock the specified child. Order is important, because docking the next child hangs in the remaining area of the DockPanel. For example, if the first child is docked to the top, and the next to one of the left, the second can only occupy the entire height of the remaining area of the DockPanel. The DockPanel's LastChildFill property indicates whether the last child should fill the remaining area. Figure 8-42 shows DockPanel within the Visual Studio 2010 Designer.
