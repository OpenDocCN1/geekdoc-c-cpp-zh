Because of the distributed nature of the web, you have several options to render charts. You can use them as images (with a number of format and storage options) or as binary streams. Chart controls can be easily integrated with legacy websites.

The Chart control has a smart state management implementation that lets you fine-tune which chart properties (and how) to save into the view state. With a few lines of code, you can balance among performance, used processing capacity, and network bandwidth, and establish solutions that are frugal with resources.

The Chart control has great user interactivity support, starting with handling tooltips, to using sophisticated asynchronous and real-time charting solutions with Ajax.
