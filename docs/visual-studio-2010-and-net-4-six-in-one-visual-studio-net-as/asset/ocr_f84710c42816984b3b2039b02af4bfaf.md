# Generic Types

Generic types allow you to define type-safe data structures, without committing to actual data types. This results in higher-quality code, because you can reuse data processing algorithms without duplicating type-specific code.

There is a similar concept in C++, called “templates”, while templates in C++ are supported by a compiler, .NET generics are implemented at the CLR level. Although there are entire books dedicated to generics, this section provides a brief overview without deeper explanations.

The C# world before generics never offered a type-safe way to encapsulate behavior into a type. If you wanted to create a behavior describing how a queue works and intended to use it with both int and Order type, you had to create a workaround. Either you implemented two separate typesQueue and OrderQueue created a single Queue type that accepted System.Objects. The first implementation has code maintenance, while the second has issues providing type safety and performance.

C# generics allow you to use type parameters and method definitions. These definitions are open type definitions, as shown in the following example:

```
public class Queue<T>
{
    public Enqueue(T item) { ... }
    public T Dequeue() { ... }
    public bool IsEmpty { get ( ... ) }
}
```
