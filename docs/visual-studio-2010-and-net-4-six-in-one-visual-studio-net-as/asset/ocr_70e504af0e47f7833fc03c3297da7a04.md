```
<GradientStop Color="Gray" Offset="1" />
</LinearGradientBrush>
<UserControl.Resources>

</TextBlock>

```

Now, you can use the resources in any other control. For example, the resource with the key ForegroundBrush can be used in another TextBlock, or to specify the stroke brush of a Rectangle:

```
<Rectangle Fill="White" Height="63" Width="121"
Stroke="(StaticResource ForegroundBrush)" StrokeThickness="5"/>
```

Of course, the Rectangle can only refer to the resource — if it is within the same UserControl. If you want to reuse the resource throughout your entire project, you can create a new resource dictionary and move it, or make it truly global by putting it into the App.xml resource dictionary.

Still, with resources, if you want all your TextBlocks to look the same, you must set all the important properties to the proper resources. Styles to rule! A style is nothing more than a set of properties. For example, you can collect the properties of the TextBlock into a style:

```
<Style x:Key="TextBlockStyle" TargetType="TextBlock">
<Setter Property="Foreground" Value="(StaticResource ForegroundBrush)"/>
<Setter Property="Effect" Value="(StaticResource Effect1)"/>
<Setter Property="FontFamily" Value="(StaticResource FontFamily1)"/>
<Setter Property="TextTrimming" Value="WordEllipsis"/>
<Setter Property="FontSize" Value="20"/>
<Setter Property="FontStyle" Value="Italic"/>
<Setter Property="FontWeight" Value="Bold"/>
</Style>
```

The style is defined inside a resource dictionary — either within the UserControl, or an external one (such as App.xml). Using the previous example, the TextBlock definition is reduced to the following:

```
<TextBlock Text="I am stylish, am I not? HorizontalAlignment="Center"
VerticalAlignment="Center" Width="199"
Style="(StaticResource TextBlockStyle)" />
```
