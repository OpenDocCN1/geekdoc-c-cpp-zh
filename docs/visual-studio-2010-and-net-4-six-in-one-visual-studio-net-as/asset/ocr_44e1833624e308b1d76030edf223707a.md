As you may have noticed, the method always returns a single element (the first match), or an element set. Another thing to note is that the different types of searches (by component name, by ID, by class, or by element name) are not combined in a single selector. Both may seem to be a very strict limitation of the Sys.get method, especially if you are familiar with the capabilities of the jQuery Library. The good news is that, if the jQuery Library is loaded into the page, and the selector is not one of the previously mentioned formats, the call will be automatically forwarded to jQuery. That means you do not have to know how Microsoft Ajax Library or the jQuery Library resolves the query; you just use any syntax you want, and you work with the results.
