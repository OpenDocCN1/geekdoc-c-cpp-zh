# Setting Up the Domain Model

The AcmeLibrary application works with Book as the most important entity. BookController defines the interaction logic and also invokes the persistence services provided by the AcmeDataEntities generated from the entity model. To separate the BookController from the class services — using the Repository Pattern — the IBookRepository interface has been extracted, as shown in Listing 18-23.

LISTING 18-23: IBookRepository.cs

```
using System;

namespace AcmeDomain
{
    public interface IBookRepository
{
        IQueryable<IBook> GetBooks();
        IBook GetBookById(int id);
        void CreateBook(IBook book);
        void InsertBook(IBook book);
        void SaveBook(IBook book);
        void DeleteBook(int id);
    }\}
```
