When you plan to create some functional editor enhancement, it often cannot be accomplished by creating a custom component for only one of the extensions outlined previously. You may have to create more small components together. For example, if you are programming a library of your own, you may want to add functions to your editor that recognizes types and members of this library. Then you can add UI elements representing functions accelerating your coding tasks to those members. This kind of enhancement may require adding custom components for the following extensions:

+   - Content type dedefinitions representing the types and members of your programming library
- Classifiers for the types and members (probably a few separate classifiers, depending on how you group them functionally or visually)
- Adornments to represent types, members, and related actions
- Optional statement completions, smart tags, and mouse processors

To create full solutions, you may also have to use your editor extensions together with your own custom packages (for example, if you want to provide custom options pages or tool windows).
