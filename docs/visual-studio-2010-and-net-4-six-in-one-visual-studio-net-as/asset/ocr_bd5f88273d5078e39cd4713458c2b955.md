SqlWorkflowStore instance, which is immediately stored in the InstanceStore field.
The next statement registers the application as a workflow service host, which acts as a lock owner
in the persistence database.

The OnButtonClick event handler creates a new workflow instance and\passes the workflow parameters. before calling the Run method that synchronously
utes the workflow, it calls the ConfigureWorkflow method to pass the prepared
InstanceStore extension to this workflow instance:

```
wf.InstanceStore = InstanceStore;
wf.PersistableId = e => PersistableIdleAction.Unload;
```

The PersistableIdle event property is called by the workflow when it is about to
persisted. You can any custom persistence actions here. The simple deftly returns
a PersistableIdleAction.Unload. It causes the workflow to be unloaded from memory (and
release resources) after its state has been persisted.
