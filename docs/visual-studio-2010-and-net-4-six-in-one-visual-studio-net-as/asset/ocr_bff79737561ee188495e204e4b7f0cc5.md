This will check that the lazy value has been evaluated already, if not, it will evaluate it. Subsequent calls to the Value property will simply serve the value already calculated, so "caching" is automatically provided and can be of great value. You can accomplish the same effect by using `Force()`.

# Quotations

Language Integrated Queries (LINQ) in C# and VB have received quite a bit of attention since their introduction and incorporation into those languages. The general idea of LINQ is to give you typed query access to data sources using the same (language integrated) query language. SQL-like constructs were added to C# and VB to utilize LINQ, including *from*, *select*, *where*, and so on.

Underneath the covers, when you use LINQ queries in C# or VB, the LINQ extensions are defined by the compiler to take care of translating those queries to *expression trees*, which are then evaluated at runtime and converted to alternate representations and executed.

Quotations are the F# way of converting F# code into expression trees. These expression trees are different than those used by LINQ. They are defined in the Microsoft.CSharp.Quotations.Expr type. You will rarely use this type directly (if ever), but instead create quotations using the convenient operators `< ... >.

```
> let q1 = < 1 @;
val q1 : Expr<int> = Value (1)
> let q2 = <= 1+2 @;
val q2 : Expr<int> =
Call (None, Int32 op_Addition[Int32,Int32,Int32](Int32, Int32), [Value (1), Value (2)])
> let q1 =
<@ add x y = x+y
add 10 20 @>;nval q1 : Expr<int> =
Let (add, Lambda (x,
Lambda (y,
Call (None, Int32 op_Addition[Int32,Int32,Int32](Int32, Int32), [x, y]),
Application (Application (add, Value (10)), Value (20))))
```

As these examples show, you can enclose any block of code inside quotations. They will be parsed and converted to quoted expressions. Furthermore, these quotations are typed, meaning they preserve type information. If you need, there is also an untyped expression representation. You can use `<@@ ... @@` to wrap code and translate it to this untyped representation, or you can go directly from a typed quotation by invoking the `Raw` property on it.
