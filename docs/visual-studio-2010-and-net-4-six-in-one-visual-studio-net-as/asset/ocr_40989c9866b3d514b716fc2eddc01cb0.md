# The TabContainer Control

You can use the TabContainer control to organize a page into several panels. A TabContainer is a host for a number of TabPanel controls. The ActControlSamples project contains a TabContainerSample page that provides a similar view of experts, as you've built in the FindAnExpertDemo project. Figure 20-9 and Figure 20-10 show the two tabs of the TabContainer used by the page.
