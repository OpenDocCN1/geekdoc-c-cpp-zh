# Panel Extenders

Following are examples in the Ajax Control Toolkit that can be attached to panels to provide visual effects:

+   CollapsiblePanelExtender adds collapsible sections to a web page. This extender targets any ASP.NET control. You specify which control or controls on the page should be the open and close controls for the panel.

+   The DragPanelExtender targets any ASP.NET Panel and takes an additional parameter that signifies the control to use as the drag handle". Once initialized, the user can freely drag the panel around the web page using the drag handle.

+   DropShadowExtender applies a shadow to any ASP.NET control. The extender allows you to specify how wide the shadow is, how opaque it is, and whether the shadow should have rounded corners. For pages that the user move or resize the panel, the DropShadowExtender has a mode that will resize and reposition the shadow to match the panel at run-time.
