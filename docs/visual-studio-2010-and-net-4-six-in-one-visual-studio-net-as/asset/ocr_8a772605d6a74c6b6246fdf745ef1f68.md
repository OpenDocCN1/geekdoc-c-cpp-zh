This query definition is almost the same as the PLINQ solution in Listing 10-8. This simple extension causes the Parallel LINQ provider to plan the execution so that the whole query is divided into independent chunks of running concurrently, and merges the partial results forming the final result. Behind the scenes, PLINQ has many strategies to execute the query. Sometimes it requires more than one pass to produce the results.
