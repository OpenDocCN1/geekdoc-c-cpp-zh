When you import the snippet file, you will see all the snippets displayed in the Snippets Manager, as shown in Figure 3-20.

Having multiple snippets in a file makes it easy for you to manage and deploy the snippets — if you put a reasonable number of <codesnippet> elements into a file. A good rule of thumb is if you put two snippets sharing some common behavior into a file, this should be pretty easy to handle. However, if you put more into one file, or have snippets with separate behavior in one file, manageability becomes difficult, and moreover, can lead to complications.
