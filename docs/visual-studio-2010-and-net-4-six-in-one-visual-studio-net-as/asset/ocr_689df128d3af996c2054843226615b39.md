Each method retrieves a ParallelLoopResult instance that provides a completion status on the execution of the loop. The IsCompleted property of the structure tells you whether the loop has finished, or interrupted before all iterations could run. The LowestBreakIteration property tells you the index of the lowest iteration from which Break was called.
