# XAML

To fully appreciate the relationship between XAML and Silverlight, a sample application would be most helpful.

> Visual Studio 2010 allows you to create out-of-the-box, Silverlight 3 and Silverlight 4 applications. However, only Silverlight 3 support is provided. To enable Silverlight 4 development, you must download and install "Silverlight 4 Tools for Visual Studio 2010" from http://www.silverlight.net/getstarted. If you plan to follow the samples on your own computer, it is recommended that you perform this installation now.
