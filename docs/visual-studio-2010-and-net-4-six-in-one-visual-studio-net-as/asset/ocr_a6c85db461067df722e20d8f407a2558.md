+   Next-generation experience — WPF provides a unified method for building rich applications with UIs. WPF offers support for two-dimensional and three-dimensional graphics, hardware accelerated effects, scalability, interactive visualization, and excellent content readability. Moreover, designers can be the active part of the development process with the help of the file format, XAML.

+   Cross-browser, cross-platform, cross-device — Another tool for a UI in .NET Silverlight, which helps developers with a cross-browser, cross-platform, cross-device plug-in for creating the next generation of rich, interactive applications.

+   Advanced web development — .NET offers a free, advanced technology for web development. ASP.NET can be the best tool in a developer's hand from small, personal websites to large, enterprise web applications. Moreover, ASP.NET Asynchronous JavaScript and XML (Ajax) enables developers to create more efficient, and rich web UIs on all of the popular browsers.

+   Secure and powerful web services — WCF provides many capabilities for developing real distributed systems with extensible architecture, secure communication, messaging patterns, and so on.

+   Business processes — As part of the .NET Framework, WF can be used for developing business processes in a more efficient way, thus improving productivity of both developers and end users.

+   Flexible data access options — ADO.NET with Entity Framework and ADO.NET Data Services provide a rich set of components for developing distributed, data-centric applications. ADO.NET supports a lot of general development needs, including the creation of multi-tier applications over databases. Entity Framework simplifies data access by providing a unified model for any database, and enables this model to reflect business requirements. ADO.NET Data Services provides a first-class infrastructure for the next wave of dynamic Internet applications by enabling web applications to expose data as REST-based data services that can be consumed by client applications in corporate networks and over the Internet.
