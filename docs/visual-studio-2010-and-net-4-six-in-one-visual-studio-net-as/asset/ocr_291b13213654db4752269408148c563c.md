Accept the default project name and click OK. Visual Studio creates the project from the Basic Command Console, and when you run it, you can see that it behaves exactly as the original BaseConsole application from which you created the template.

# Adding a Small Customization

As you see, in a few steps, you have created a New Visual Studio project template. Now let's take this step further. Let's add a small customization to the template. The first project you created from the template wrote the same message "Welcome to the BaseConsole application" to the console as the template. Let's modify the template so that the current project name given by the user in the New Project dialog is now

Open the BaseConsole project again, and change the DisplayWelcomeMessage method in the Project.cs file to the following:

```
static void DisplayWelcomeMessage()
{
    Console.WriteLine("Welcome to $safeprojectname!");
    Console.WriteLine("");
}
```

$safeprojectname$ placeholder is a template parameter. When a new template is created, this parameter is replaced with the name of the current project transformed to a name conforming to the identifier syntax, so "unsafe" characters and spaces are removed.

Export the BaseConsole project to project template exactly as you did before. The Export Template Wizard will warn you that the output file already exists. Confirm that you want to delete the existing file, and the original Basic Command Console.zip template will be replaced.

Now, create a new project using the refreshed template, and give the My Customized Console name to the application. Build and start the application. The welcome message now shows the effect of $safeprojectname$ template parameter, as illustrated in Figure 4-10.
