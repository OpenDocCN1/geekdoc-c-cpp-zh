# SUMMARY

This chapter discussed the new UI-related features and functions of Visual Studio 2010. You learned about changes to the Shell itself, including the new window management and multi-monitor support. You learned about the new code editor features and the extensibility possibilities. The new visual designers and their features were also introduced. Finally, you got a glimpse of the functions available for architects in the new IDE.

Chapter 3 provides an in-depth exploration of Visual Studio code snippets and some features that can help you become more productive in your daily work.
