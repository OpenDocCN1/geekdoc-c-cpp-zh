# Downloading and Installing Components

Component authors and vendors can decide how you can download and install components. You can either download components directly from the Visual Studio Gallery (as illustrated by the Download button in Figure 5-42), or you are redirected to the vendor's (author's) site for further instructions. In the latter case, you will find a Get button instead of Download.

The Visual Studio Gallery supports the VSIX kit format that was established for Visual Studio Extensions. When the selected component is available for direct installation, you can click the Download button to run or save the VSIX file representing the setup kit.

Visual Studio 2010 installs the Visual Extension Installer utility that is associated with the .vsix extension. So, if you have the VSIX file downloaded from the Gallery, this utility starts and lets you go on, or abort the installation, as shown in Figure 5-43.

When the installation is complete, the utility warns you to restart all Visual Studio instances in order for the component to be successfully integrated into the IDE.

Later, if you want to remove the component, you can use the Extension Manager dialog (Tools -> Extension Manager) to uninstall or disable it.
