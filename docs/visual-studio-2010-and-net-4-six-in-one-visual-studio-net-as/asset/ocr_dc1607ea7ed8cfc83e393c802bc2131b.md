# Call Hierarchy

A new function called Call Hierarchy can also be used to navigate code. This function can be invoked by positioning the caret in a method's name and pressing Ctrl+K, followed by the T key. The function is also available from the context menu.

Call Hierarchy shows what methods the selected function is calling, or who is calling the selected method. This helps you understand code execution and code flow in more complex solutions. Call Hierarchy display can go to any depth in function calls. A caveat of this function is when someone is using user interfaces, this function cannot resolve a "default implementation" class for a given interface.
