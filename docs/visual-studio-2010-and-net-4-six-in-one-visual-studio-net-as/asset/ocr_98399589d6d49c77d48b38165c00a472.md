# Advanced Chart State Management

The BasicChartStateManagement.aspx page saves more information than required, because it saves the state of the additional series that can be calculated (and it's) from the data generated for the base series. If there were a way to tell the chart to only save the base series, you could save resources reserved by a hundred data points. This is especially important when your chart contains more—let's say a few hundred or thousand—data points.
