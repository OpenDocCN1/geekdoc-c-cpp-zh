# ENTITY FRAMEWORK

The Entity Framework is an extended ORM from Microsoft that is used to reduce the impedance mismatch between the relational and the object model in an application. It makes this possible through the Entity Data Model (EDM), an extended Entity Relational Model allows you to work with domain-specific properties, rather than being concerned about how the data is represented and stored in the database.

The Entity Framework is called an extended ORM because it provides the following additional features over and above an ORM:

+   - Change tracking
- Entity inheritance

# Entity Framework Architecture

Following are the architectural components of the Entity Framework:

+   - The Entity Data Model (EDM)
- LINQ to Entities
- Entity Client
- Object Services
- Entity SQL
