to the Sys.Binding instance. You do not have to register these additional properties. Just configure them in the binding expression, and the converter will receive their values. Be careful, because a typo (even in casing) can create additional properties, and your converter will fail to work.

If you convert a value when it is transferred from the data source to the UI element, you can write a simple function (the signature is the same), but you must change the binding expression to use the convert keyword instead of the convertBack.

The templating engine provides strong support for converters. However, there is currently no built-in in the Microsoft Ajax Library.

# Master-Detail Binding

The DataView control and the live binding feature of the Microsoft Ajax Library supports master-detail scenarios. In a master-detail scenario, you define two DataViews and connect them to each other. When a user selects a record in the master DataView that shows only some top-level fields from the record, the details DataView is automatically updated to display the additional fields. As you may know, this feature relies heavily on the select command in the master view, and the trick is how you define the data source of the details view.

The following example displays lists of controls, and when the user selects a country, the name, capital, and the flag of the country is displayed below the list.

```
<ul
  id="template"
  class="sys-template"
  sys:attr="dv"
  dv="{ countries }}"
  dv:selecteditemclass="selected">
  <li sys:command="Select" style="cursor: pointer;">
    {{ Name }}
    <span>{{ binding Capital }}</span>
  </li>
</ul>
<div
  class="sys-template"
  sys:attr="dv"
  dv="{ binding selectedData,
    source={ { $find('master') } }"
  <img
    sys:src="{ binding Code,
    convert=stringConverter,
    format=../images/flag(0).gif"
    style="float: left; margin-right: 10px;" />
  <h2 id="txtCapital">Capital:</h2>
  <label for="txtCapital">Capital:</label>
  <input type="text" id="txtCapital"
    sys:value="{ binding Capital }" />
</div>
```
