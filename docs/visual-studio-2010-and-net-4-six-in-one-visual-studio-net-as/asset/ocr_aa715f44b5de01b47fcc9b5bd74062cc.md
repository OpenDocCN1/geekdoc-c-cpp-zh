As you work through the examples in this book, you may choose either to type in all the code manually, or to use the source code files that accompany the book. Some of the code used in this book is available for download at www.wrox.com. When at the site, simply locate the book's title (use the Search box or one of the lists) and click the Download Code Link on the book's detail page to obtain the source code for the book.
