While an ASP.NET web master page inherits from the class that derives from the System.Web.UI.MasterPage type, this page (as you see here in the %@ Master tag) inherits from the System.Web.Mvc.ViewPage class that derives from System.Web .MasterPage. The structure of the master page is very similar to master pages in ASP.NET web projects.

The Site.Master page contains a <div> tag with the menucontainer identifier, which seems:

```
<div id="menucontainer">
<ul id="menu">
  <li>@Html.ActionLink("Home", "Index", "Home")</li></li>
  <li>@Html.ActionLink("About", "About", "Home")</li></li>
</ul>
</div>
```

These lines represent the rectangular Home and About menu items shown in Figure 18-6. ASP.NET master page uses controls to represent the menu, like this:

```
<asp:Menu Id="NavigationMenu" runat="server" CssClass="menu"
EnableViewState="false" Orientation="Horizontal">
<Items>
  <asp:MenuItem NavigateUrl="/Default.aspx" Text="Home"/>
  <asp:MenuItem NavigateUrl="/About.aspx" Text="About"/>
</Items>
</asp:Menu>
```
