All components in the framework derive from abstract base classes or implement interfaces. You can replace the original components to create your own ones deriving from the appropriate abstract classes or implementing the interfaces.

You have many extension points in MVC. Instead of discussing them separately, you will meet them later in this chapter in the context where they are used.
