Start with a C# sample application, and name it DynamicObjectDemo. Add a new class item file with the name DynamicEnvironment.cs to the project. Listing 10-3 shows the code you should copy to this file.

# LISTING 10-3: DynamicEnvironment.cs

```
using System;
using System.Dynamic;

namespace DynamicObjectDemo
{
    public class DynamicEnvironment: DynamicObject
    {
        private EnvironmentVariableTarget _TargetEnv;
        private bool _ignoreMissingProperty;

        public DynamicEnvironment(
            EnvironmentVariableTarget targetEnv,
            bool ignoreMissingProperty = false)
        {
            _TargetEnv = targetEnv;
            _ignoreMissingProperty = ignoreMissingProperty;
        }

        public override bool TryGet(MemberBinder binder, out object result)
        {
            result = Environment.GetEnvironmentVariable(binder.Name, _TargetEnv);
            return result != null || _ignoreMissingProperty;
        }
    }
}
```

> Code file [DynamicEnvironment.cs] available for download at Wrox.com

The constructor allows you to pass an optional EnvironmentVariableTarget to set if you want to bind the object to the machine or to the user environment. The ignoreMissingProperty parameter's true value allows you to retrieve a null value for non-existing environment variables instead of raising run-time exception.

The property name resolution is handled by the overridden TryGet method. It accepts two parameters. The binder receives the operation message from the DLR. In this case, it handles the name of the property to resolve. The result should be set to the object to be retrieved from the operation, and in this case, it will be the value of the property. The return value of the method is set true if the operation message can be handled by this method; otherwise it is false.

The logic of the method is simple. If the property name refers to an existing environment variable, the resolution is successful, and it retrieves the value; otherwise returns null, or fails, depending on the value of _ignoreMissingProperty.
