Although the CompareOther method takes an IComparable(Of Elephant) instance as its first parameter, it still works in Visual Basic 2010 an despite the fact that Elephant does not implement IComparable(Of Elephant). Elephant directly (through Animal) implements IComparable(Of Animal) which can substitute IComparable(Of Elephant). This is the definition of IComparable(Of T):

```
Public Interface IComparable(Of T)
    Function CompareTo(ByVal other As T) As Integer
End Interface
```

The type T uses the In variant modifier, restricting T to only occur in input positions, and just as the Out modifier, the compiler will check the appropriate usage of T. This restriction provides (and, of course, it also ensures that the interface becomes contravariant in T, which means that an IComparable(Of X) is considered an IComparable(Of Y) if X has a reference conversion to Y.

In the example, Elephant has a reference conversion to Animal, and so IComparable(Of Elephant) can be substituted by IComparable(Of Animal).

# Variance with Multiple Type Parameters

At first sight, many developers may think that covariant or contravariant is a property of a generic type. This is not true! Variance is a property of types in generic types. When you have a generic type — let’s say MyType(Of T) — you cannot say "MyType is invariant, covariant, or contravariant." What can you say "MyType is invariant, covariant, or contravariant in T."
