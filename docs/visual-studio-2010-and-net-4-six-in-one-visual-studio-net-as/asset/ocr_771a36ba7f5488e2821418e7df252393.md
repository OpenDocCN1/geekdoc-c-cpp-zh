Installing VS SDK is very simple, so when you download the setup kit, you can immediately run the setup file. Follow the instructions on the screen, and in a few minutes, VS SDK is ready to work with.

Start a new VSIX by selecting the appropriate template from the Extensibility subcategory under Visual C#, as shown in Figure 4-22. Name it BasicDBObjectConsoleInstaller.

The project template contains a few files, as shown in Figure 4-23, viewed in Solution Explorer.

You will not need the VSIXProject.cs file, so you can remove it. There are two image files in the project. You can think of them as the icon and preview images of the template definitions. These images are used similarly for the installation kit when browsing in the Studio Gallery. The most important part of the project is extension .vsixmanifest. As its name suggests, this is the file that tells everything about the installation.
