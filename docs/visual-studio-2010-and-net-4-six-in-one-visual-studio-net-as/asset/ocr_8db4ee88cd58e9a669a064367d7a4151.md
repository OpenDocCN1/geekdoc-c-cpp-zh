# TABLE 4-4 (continued)

| CHILD ELEMENT | DESCRIPTION |
|--- |--- |
| <PromptForSaveOnCreation> | This specifies whether the user is prompted for a save location using the New Project dialog box when creating the project. If this element is set to true, then the user is prompted for a save location. If false, then the user is not prompted, and in this case, a temporary project is created. |
| <EnableLocationBrowseButton> | In New Project dialog box, the Location text box specifies the directory where a new project is saved. The Browse button helps you find this directory by displaying the Project Location dialog box, which enables you to easily navigate to a different directory from your computer, and then choose it as the directory where the new project is saved. The text must be either true or false, indicating whether or not to display the Browse button on the New Project dialog box. The default value is true. |
| <LocationField> | The Location text box in the New Project dialog enables users to change the default directory in which new projects are saved. This element specifies if this text box should be enabled, disabled, or hidden. Thus, the element values are Enabled, Disabled, and Hidden. |

Now that you are familiar with the <TemplateData> element, you can understand what the following definition in the Basic Console project template stands for:

```
<TemplateData>
<Name>Basic Console</Name>
<Description>This console processes simple commands</Description>
<ProjectType>CSharp</ProjectType>
<ProjectSubType></ProjectSubType>
<Order>1000</Order>
<CreateNewFolder>true</CreateNewFolder>
<DefaultName>Basic Console</DefaultName>
<ProvideDefaultName>true</ProvideDefaultName>
<LocationField>Enabled</LocationField>
<EnableLocationBrowseButton>true</EnableLocationBrowseButton>
<Icon>Template.ico</Icon>
</TemplateData>
```

Not all elements are described here, but rather, lets on what the result is. The project template is for the Visual C# language and the project template will be placed at the end of the project template list. New Project dialog will provide a default for the project that is to be created in new folder, and the user is allowed to select this folder.
