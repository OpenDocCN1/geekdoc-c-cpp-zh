Add the following using clause to the existing using clauses in the file header:

```
using AcmeLibrary.Models;
```

Integrate the Index action with the model by changing its body to the following code:

```
public ActionResult Index()
{
    var context = new AcmeLibraryDataEntities();
    var books = context.Books;
    return View(books);
}
```

This code retrieves all books and passes data to the View method that interprets the books as a collection from the model.

# Creating the Index View

Although the Index action accesses the model, there is no view yet that displays the list of books. The MVC 2 tools integrated with Visual Studio 2010 makes it very simple to create a new view.

Open the UserController.cs file if it's loaded, and click into the body of the Index method to place the caret there. Right-click the code editor and select the Add View command from the context menu.

> There is a small bug in the RTM version of Visual Studio 2010. In some cases, it pops up context menus that you must scroll (even if there is enough space on the screen). To access the Add View command, you must scroll up to the top of the context menu.

The View dialog pops up, allowing you to specify parameters for the new view to create. Figure 18-15 shows this in action.

Set the Name to Index. Check the "Create a strongly-typed view" option and select AcmeLibrary.Models. From the "View data" combo box. The "View content" combo box allows you to select the type of view you want to generate. You can choose from the following items:

+   - Create — A view to enter data for a new item.
- Delete — A view to confirm the deletion of an item.
- Details — A view to browse the details (attributes) of an item.
