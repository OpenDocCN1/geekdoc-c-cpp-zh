# Range Charts

As their names suggest, range charts can display data points representing ranges ("from" and "to" values). If you change a chart type the YValuePerPoints property of the corresponding Series instance changes to 2 numbers for the YValues property of data points in the series.

You can use different types of range charts. You can use range column charts and range bar charts (as shown in Figure 14-31) that are very similar to column and bar charts, except that columns and bars are not drawn from the zero point of the Y axis to the data point's Y value, but between the two YValues provided.

You can also display range charts based on line charts (the name "range chart" covers this idea) or spline charts (as shown in Figure 14-32), which are called spline charts.
