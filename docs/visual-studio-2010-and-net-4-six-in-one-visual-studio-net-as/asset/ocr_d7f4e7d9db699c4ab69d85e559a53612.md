The central area displays the artboard on the top, and the XAML on the bottom. This split view is an excellent learning tool. Any change to the area (like moving the button, changing colors, adding new controls, and so on) is immediately reflected on the bottom, and vice versa. When the XAML is changed, the end result can be seen on the top in a second. On the right bottom, the Property Browser is a very useful feature—the properties can be searched, as shown in Figure 8-7.

There is also a handy developer outline window. Because XAML trees can get pretty huge, this helps finding the right element in the document.
