The Employee ID field demonstrates the use of the MaskedEditExtender control. The following code sets up this extender to allow typing only employee IDs with LLL-99-99 format, where L stands for letters and 9 for numbers: 

```
<tr>
  <td>Employee ID:</td>
  <td>
    <asp:TextBox ID="EmpID" runat="server" />
    <asp:MaskedEditExtender ID="MeExt" TargetControlID="EmpID"
      Mask="LLL-99-99"
      TooltipEnabled="True"
      runat="server" />
  </td>
</tr>
```

This extender has many properties you can use for culture-specific format settings. Look at the reference of this extender to discover the large set of properties you can use to customize.

# List Extenders

There are three extenders in the Ajax Control Toolkit that can be attached to ASP.NET list controls:

+   - CascadingDropDown can be attached to an ASP.NET DropDownList to modify the automatic population of a set DropList controls. When you modify the FindExpertDemo sample application, you learned lot about using this extender.

+   - ListSearchExtender lets you search for items in a ListBox or DropList by typing. The performs an incremental search within the ListBox based on what has been typed so far.

+   - PagingListExtender can be attached to a BulletedList and provide client-side paging. It is very flexible, if you specify either the number of characters used in the heading indices, or the maximum number of items to display per.
