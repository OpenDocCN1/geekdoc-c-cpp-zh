# # Collection-Handling Activities

WF 4.0 provides some defined activities that you can use to manipulate collections in your workflow. You can declare the following declarations:

```
Variable<ICollection<Customer>> customerList =
new Variable<ICollection<Customer>>();
// ...
Argument<ICollection<Order>> Orders { get; set; }
```

There are several primitive activities allowing you to work with collections. All of them have a type parameter defining the elements of the collection, and a Collection property containing a reference to the collection argument or variable that is the subject of the operation. The Item property — where the operation has this argument — specifies the collection item used by the operation.
