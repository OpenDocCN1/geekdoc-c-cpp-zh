
# TABLE 20-9: Animations

| ANIMATION | DESCRIPTION |
| --- | --- |
| Condition | This is used as a control structure to play a specific child animation, depending on the result of executing the conditionScript. If the conditionScript evaluated to true, the first child animation is played. If it evaluates to false, the second child animation is played (although nothing is played if the second animation is not present). |
| Case | This animation is used as a control structure to play a specific child animation, depending on the result of executing the selectScript, which should evaluate the index of the child animation to play. If the provided index is outside the bounds of the child animations (or if nothing is returned), it will not play anything. |
| FadeIn | This animation performs a fade from the current opacity to the maximumOpacity. |
| FadeOut | This animation performs a fade out from the current opacity to the minimumOpacity. |
| Pulse | This animation fades in and out repeatedly to create a pulsing effect. The iterations determine how many pulses will be. The duration defines the length of each fade in or out, not the length of an animation. |
| Interpolated | This animation assigns a range of values between startValue and endValue to the designated property. |
| Color | This animation transitions the value of a property between two colors (although it ignores the alpha channel). The colors must be seven-character strings such as #A3AA44 |
| Length | This is identical to Interpolated, except that it adds a unit to the property. |
| Move | This animation is used to move the target element. If the relative flag is set to true, then it treats the horizontal and vertical properties as offsets to move the element. If the relative flag is false, then it will treat the horizontal and vertical properties as coordinates on the page where the target element should be moved. |
| Resize | This animation changes the size of the target from current values to the specified width and height. |
| Scale | This animation scales the size of the target element by the given scaleFactor. If scaleFactor is true, the size of font will also scale the element. If center is true, the element's center will not move as it is scaled. |

You can use actions over animation primitives. For example, with the EnableAction primitive, you can disable or enable animation actions (events) while an animation is in progress. For example, the fifth image (the first in the second row) does not allow you to carry out any other actions on it while animations are not played;

```xml
<asp:Image ID="Image5" runat="server" Width="128" Height="128"
    ImageUrl="~/Photos/Ebeneizer.png" />
<!-- --
<asp:AnimationExtender ID="AnimExt5" runat="server"
TargetControlID="Image5"
<Animations>
  <OnHoverOver>
    <Sequence>
      <EnableAction Enabled="false" />
      <ResizeAction Width="256" Height="256" />
      <EnableAction Enabled="true" />
    </Sequence>
  </OnHoverOver>
  <OnHoverOut>
    <Sequence>
      <EnableAction Enabled="false" />
      <ResizeAction Width="128" Height="128" />
      <EnableAction Enabled="true" />
    </Sequence>
  </OnHoverOut>
</Animations>
</asp:AnimationExtender>
```
```

# TABLE 20-10: Animation Actions

| ANIMATION | DESCRIPTION |
|---|---|
| EnableAction | This action changes whether or not the target is disabled. |
| HideAction | This action simply hides the target from view (by setting its style's display attribute to "none"). |
| StyleAction | This action is used to set a particular attribute of the target's style. |
| OpacityAction | This action will set the opacity of the target. |
| ScriptAction | The action is used to execute arbitrary JavaScript code. |

The AnimationExtender can describe actions that can be executed on other targets than the control attached to the extender through the TargetControlID property. You can set the AnimationTarget property of primitives to involve other controls into the animation.

For example, the sixth image carries out operations on the first image with the following declarations:

```xml
<asp:Image ID="Image6" runat="server" Width="128" Height="128"
  ImageUrl="/Photos/Omar.png" />
<!-- ... -- -->
<asp:AnimationExtender ID="AnimExt6" runat="server"
  ControlID="Image6">
  <Animations>
    <OnMouseOver>
      <FadeOut AnimationTarget="Image" Duration=".5s" Fps="20" />
    </OnMouseOver>
    <OnMouseOut>
      <FadeIn AnimationTarget="Image" Duration=".5s" Fps="20" />
    </OnMouseOut>
  </Animations>
</asp:AnimationExtender>
```

In addition to the AnimationExtender control, you can use the UpdatePanelAnimation control. This latter one is a non-visual control, so it has events that trigger animations. The OnUpdating event starts when the UpdatePanel begins updating; OnUpdated plays the animation after the UpdatePanel has finished updating (but only if the UpdatePanel changed).
