However, because IEnumerable(Of T) is covariant in T, the compiler accepts it. With Visual Basic 2008 — assuming that you would transform it in this source to the old syntax — this code would not compile with Strict If To make it work with Visual Basic 2009, you must use a workaround. One possible solution is to cast Dogs and Macaws as IEnumerable(Of Pet):

```
Dim DogsAsPet As IEnumerable(Of Pet) = Dogs.Cast(Of Pet)
Dim MacawsAsPet As IEnumerable(Of Pet) = Macaws.Cast(Of Pet())

Dim Youngsters =
From pet in Pet.ShackUpWith(DogsAsPet, MacawsAsPet)
where pet.Age < 5
Select pet
```

It is much simpler with Visual Basic 2010, isn't it?
