You can just add the `udpDiscoveryEndpoint` endpoint and also enable the `<serviceDiscovery>` behavior to enable service discovery in the ad-hoc mode. Here is an example:

```
<configuration>\system.serviceModel>
    <services>
      <service name="TestService">
        <endpoint binding="wsHttpBinding" contract="ITestService" />
        <!-- add a UDP discovery endpoint -->
        <endpoint name="udpDiscovery" kind="udpDiscoveryEndpoint"//>
      </service>
    </services>
    <behaviors>
      <behavior name="TestService.MyServiceBehavior">
        <!-- To avoid disclosing metadata information, set the value to false and remove the metadata endpoint before deployment -->
        <serviceMetadata HttpEnabled="true"/>
        <!-- To receive exception in faults for debugging purposes, set the value to true. Set to false before deployment to avoid disclosing exception -->
        <serviceDebug includeExceptionDetailInFaults="false"/>
        <serviceDiscovery />
      </behavior>
    </behaviors>
</system.serviceModel>
</configuration>
```
