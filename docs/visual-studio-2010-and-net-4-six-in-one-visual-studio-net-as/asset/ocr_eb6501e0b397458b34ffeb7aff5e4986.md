Code snippets can be grouped into a hierarchical folder structure. For example, Visual C# snippets have the following folders:

+   - NetFX3 — These are snippets for .NET 3.0 new features.

+   - OfficeDevelopment — These are code snippets helping in Microsoft Office development tasks.

+   - other — This is the folder for other code snippets. Currently, a few WF snippets can be found here.

+   - Refactoring — These are snippets used by the C# language service for refactoring functions.

+   - Visual C# — These are general-purpose snippets related to the C# language (properties, events, classes, and so on).

System folders have so-called index files to enumerate snippets. This is the existence and the name of these files is SnippetIndex.xml for Visual Basic, and SnippetsIndex.xml for the other languages. The format of these index files is beyond the scope of this book, but free to open and examine them.

# Adding and Removing Snippets

The Code Snippets Manager allows you to add your custom folders with snippets. As mentioned previously, Code Snippets Manager stores only paths to folders. By using the Add button, you can add only top-level folders to the selected language. When you click the Add button, a folder-selection dialog with Code Snippets directory is popped to let you specify the folder to add. After you added the folder to the directory, it is displayed in the folder list. You can immediately browse its content.

When you select a folder in the list and click the Remove button, you can draw it off from the library. Of course, this operation does not delete the content of the folder; it omits it from the list handled by Code Snippets Manager. You can remove only top-level folders. The Remove button is disabled when you select a subfolder or snippet.

Be careful about removing system folders. The Code Snippets Manager allows you to remove them, and not even ask for confirmation. If you accidentally removed a system folder, you can add it later by selecting the physical folder you drew off. After adding it again, Visual Studio recognizes it as a system folder and handles it correctly.

# Importing Snippets

If you have a lot of snippets organized in a folder, you can add the folder to the appropriate language with Code Snippets Manager. However, if you have .snippet files that have not been organized in any folder, you can import them, and make the snippets within them a part of your library.
