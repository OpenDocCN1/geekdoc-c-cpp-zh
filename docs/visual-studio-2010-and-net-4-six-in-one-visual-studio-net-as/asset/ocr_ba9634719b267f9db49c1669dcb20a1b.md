ECMA-334 (December 2001), Microsoft also started the standardization at International Organization for Standardization (ISO), with C# becoming an ISO standard in 2003 with the moniker ISO/IEC 23270:2003.

In 2002, the big leap reached the developer community. Visual Studio .NET (also known as VS 2002) was released with C# 1.0 (and Visual Basic .NET). The C# 1.0 compiler was the part of the .NET SDK, and Visual Studio included "only" developer's workbench for the language. Although the .NET framework had been fixed and polished in 2003 and a new Visual Studio Version (VS 2003) was released in April 2003, the C# language used was the C# 1.0 specification.

The next roaring success of the language was C# 2.0 with its most appreciated feature: generics. In later iterations, Heijsberg added this feature to its list from the beginning, but had not enough experience to implement it in .NET 0.1 or 1.1.

The implementation of generics was very important from the C# point of view. It was not only a feature that enabled better code reusability, but also an important part in the move towards functional programming paradigm. This new language version was released with Visual Studio 2005 in October 2005.

The related ECMA and ISO standards were also updated to match the new C# 2.0 features.

Released with Visual Studio 2008, C# 3 made another huge leap with the introduction of Language Integrated Query (LINQ) and query expressions. LINQ is a .NET Framework component that adds data querying capabilities to .NET languages. Query expressions represent a new form of data query syntax that resembles the SQL language. With LINQ involved in C#, the language took a new programming paradigm shift from the imperative approach to the direction of declarative and functional programming. Parallel with the query expressions, the language included small (but significant) "synthetic syntax" features intended to make the bed for LINQ, but these features were also well used.

Microsoft has not updated C# 3.0. The most current versions of the standards for the C# programming language are ISO/IEC 23270:2006 and ECMA-334 edition.

The newest version of the language is 4.0, released with Visual Studio 2010. The step from C# 3.0 to 4.0 signals that it has become a multi-paradigm language. This new version introduces new features as support for dynamic types, which introduces a great way to interoperate with dynamic languages. C# now has named and optional parameters, that mean other things, using COM object hierarchies from C# with the same ease as in Visual Basic and scripts.

What will be C# 5.0? Right now, there is no official information from Microsoft about what the team is working on. But, because a new Visual Studio release is scheduled for every two years, you can be that the team is definitely working on and exciting features to be encapsulated into C#.
