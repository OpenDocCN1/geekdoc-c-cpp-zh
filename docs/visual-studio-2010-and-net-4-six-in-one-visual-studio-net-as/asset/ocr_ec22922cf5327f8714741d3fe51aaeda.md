Returning true from this method tells the template system to add the file in the project and add any

or an item. In both cases, the automation object representing the project or the
item is passed to the appropriate method.

+   4. For each file the OpenInEditor was set to true in the template manifest

+   5. At the very end, the RunFinished method is called.
