| CountdownEvent | This class represents a synchronization primitive that is signaled when its count reaches zero.
You can use this in fork-and-join scenarios, because it provides an easy rendezvous mechanism.\ CountdownEvent allows to wait until one or more threads finish some other operation. An instance of this class is initialized with an integral count, typically greater than 0. Threads block waiting on the event until the count reaches 0, at which the count is decremented by CountdownEvent's Decrement method, which is typically called by a worker thread completing a unit of work being tracked by the event.| ManualResetEventSlim | This type is a slimmed down and lightweight version of its predecessor, ManualResetEvent, and can be used to notify one or more waiting threads that an event has occurred.

They improve performance when the wait time is expected to be short, by avoiding expensive switching and blocking operations.\ SpinLock is a mutual-exclusion lock that causes the thread that is acquiring the lock to wait in a loop (or spin) for a period of time before yielding its quantum. SpinLock is a value type, that for performance reasons, so you need to pass a SpinLock instance around, it should be passed by reference, rather than by value.\ SpinWait is a small, lightweight type that will spin for a specified time and eventually put the thread into a wait state if the count is exceeded.\ SpinWait is a value type; its members are not thread-safe.
