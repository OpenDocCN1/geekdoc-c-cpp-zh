# Appendix B = Solutions to Exercises 505

13. The following code for multiplying two matrices was shown in the chapter's text:

```
MultiplyArrays(Integer: array1[], Integer: array2[], Integer: result[])
For i = 0 To <Upper bound for dimension 1>
  For j = 0 To <Upper bound for dimension 2>
    // Calculate the [i, j] result.
    result[i, j] = 0
    For k = 0 To <Upper bound for dimension 2>
      result[i, j] = result[i, j] + array1[i, k] * array2[k, j]
    Next
  Next
MultiplyArrays
```

Now consider the inner For loop. If i < k, array1[i, k] is 0. Similarly, if k < j, array2[k, j] is 0. If either of these two values is 0, their product is 0.

The following code shows how you can modify the array assignment statement so that an entry's value is only assigned if multiplying entries are present in both arrays:

```
If (i >= k) And (k > j) Then
  result[i, j] = result[i, j] + array1[i, k] * array2[k, j]
End If
```

You can make this a bit simpler if you think about the values of k to access entries that exist in both arrays. Those values exist if k <= i and k >= j. You can use these bounds for k in its For loop, as shown in the following pseudocode:

```
For k = j To i
  total += this[i, k] * other[k, j];
Next
```

14. The following code shows a CopyEntries method that copies the items in the ArrayEntry linked list starting from from_entry to the end of the list that currently ends to:

```
// Copy the entries starting from from_entry into
// the destination list after to_entry.
CopyEntries(ArrayEntry: from_entry, ArrayEntry: to_entry)
While (from_entry != null)
  to_entry.NextEntry = new ArrayEntry
  to_entry = to_entry.NextEntry
  to_entry.ColumnNumber = from_entry.ColumnNumber
  to_entry.Value = from_entry.Value
  to_entry.NextEntry = null

  // Move to the next entry.
  from_entry = from_entry.NextEntry
End While
CopyEntries
```

As long as the "from" list isn't empty, this adds a new ArrayEntry object to the "to" list.
