# Summary

Some network algorithms model real-world situations in a fairly straightforward way. For example, a shortest-path algorithm can help you find the quickest way to drive through a street network. Other network algorithms have less-obvious uses. For example, the maximal flow algorithm not only lets you determine the greatest amount of flow that it can carry, but it also lets you assign jobs to employees.

The edit distance algorithm described in the next chapter also uses a network in a non-obvious way. It uses a network to decide how different one string is from another. For example, the edit algorithm can determine that the strings “peach” and “peace” are more similar than the strings “olive” and “pickle.”

The next chapter discusses algorithms such as the edit distance algorithm that let you study and manipulate strings.
