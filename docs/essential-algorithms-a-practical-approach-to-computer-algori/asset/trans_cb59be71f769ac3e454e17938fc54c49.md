10. 下面的伪代码绘制谢尔宾斯基分形。该代码假设有一个具有 X 和 Y 属性的 `Point` 数据类型。

```
// 绘制分形
SierpinskiGasket(Integer: depth,
Point:point1, Point:point2, Point:point3)
// 如果深度为 0，填充剩余的三角形。
If (depth == 0) Then
    Point:points[] = {point1, point2, point3 }
    FillPolygon(points)
Else
    // 找到三角形左侧、右侧和底部的点。
    lpoint = new Point(
    (point1.X + point2.X) / 2,
    (point1.Y + point2.Y) / 2)
    bpoint = new Point(
    (point2.X + point3.X) / 2,
    (point2.Y + point3.Y) / 2)
    rpoint = new Point(
    (point3.X + point1.X) / 2,
    (point3.Y + point1.Y) / 2)
    // 递归调用。
    SierpinskiGasket(depth - 1, point1, lpoint, rpoint)
    SierpinskiGasket(depth - 1, lpoint, point2, bpoint)
    SierpinskiGasket(depth - 1, rpoint, bpoint, point3)
End If
SierpinskiGasket
```

11. 下面的伪代码绘制谢尔宾斯基地毯。该代码假设有一个具有 X, Y, Width 和 Height 属性的 `Rectangle` 数据类型。

```
// 绘制地毯
SierpinskiCarpet(Integer: depth, Rectangle:rect)
// 如果深度为 0，填充矩形。
If (depth == 0) Then
    FillRectangle(rect)
Else
    // 计算子矩形的长宽宽。
    Float: width = rect.Width / 3
    Float: height = rect.Height / 3
    For row = 0 To 2
        For col = 0 To 2
            // 跳过中间矩形。
            If (row != 1) || (col != 1) Then
                SierpinskiCarpet(depth - 1, new Rectangle(
                rect.X + col * width,
                rect.Y + row * height,
                width, height))
            End If
        Next col
    Next row
End If
SierpinskiCarpet
```
