# A Fairly Random Array

One other important consideration of this algorithm is whether it produces a fair arrangement. In other words, is the probability that an item ends up in any given position the same for all positions? For example, it would be bad if the item that started in the first position finished in the first half of the time.

I said in the Introduction that this book doesn't include long mathematical proofs. So if you want, you can skip the following discussion and take my word for it that the randomness is fair. If you know some probability, however, you may find the discussion of interest.

For a particular item, consider the probability of its being placed in position k. To be placed in position k, it must not have been placed in positions 1, 2, 3,..., k-1 and then placed in position k.

Define $P_i$ to be the probability of the item not being placed in position i that it was not placed in positions 1, 2, ..., i-1. Also define $P_k$ to be the probability of the item being placed in position k that it was not placed in positions 1, 2, ..., k-1. The total probability that the item is placed in position k is $P_{-1} 	imes P_{-2} 	imes \dots 	imes P_{k-1} 	imes P_k$, $P_i$ is $1/N$, so $P_{-1} = (N-1)/N$ and $P_k$ is $1/N$.

After the first item is assigned, $N-1$ items be assigned to position 2, so $P_2$ is $1/(N-1)$, and $P_3$ is $1/(N-1) 	imes 1/(N-2) = (N-2)/(N-1).

More generally, $P_i = (N-i)/(N-i+1)$ and $P_j = 1/(N-j)$, $P_{i-1} = (N-i)/(N-(i-1)) = (N-i)/(N-i+1)$.

If you multiply the probabilities, $P_{-1} 	imes P_{-2} 	imes \dots 	imes P_{k-1} 	imes P_k$ gives the following equation:

```
$\frac{N-1}{N} 	imes \frac{N-2}{N-1} 	imes \frac{N-3}{N-2} 	imes \dots 	imes \frac{N-(k-1)}{N-(k-2)} 	imes \frac{N-1}{N-(k-1)}$
```

If you look at the equation, you'll see that the numerator of each term cancels out the denominator of the following term. When you make the cancellations, the equation simplifies to 1/N.

This means that the probability of the item's being placed in position k is $1/N$ no matter what k is, so the arrangement is fair.
