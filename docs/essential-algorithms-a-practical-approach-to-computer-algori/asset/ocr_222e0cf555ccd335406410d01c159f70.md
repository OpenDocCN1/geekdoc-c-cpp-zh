This approach works in this instance, but it has a serious drawback under some conditions. What happens to the operator if the two subexpressions start with the same input transitions? For example, suppose the two subexpressions are A + A and A + B. In that case, blindly following the previous discussion leads to the transition diagram on the left in Figure 15-9. It has two links labeled A that leave state 0. If the DFA is in state 0 and encounters input character A, which link should it follow?
