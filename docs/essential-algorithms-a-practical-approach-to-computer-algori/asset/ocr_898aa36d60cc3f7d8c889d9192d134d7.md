# Chapter 11: Balanced Trees

+   1. Figure B-12 shows the right-left rotation.
2. Figure B-13 shows AVL tree as the values 1 through 8 are added in numeric order.
3. Figure B-14 shows the process of removing node 33 and rebalancing the tree. First you need to replace node 33 with the rightmost node to its left, which in this case is 17. After replacement, the tree is unbalanced at node 12, because its left subtree has height 2, and its right subtree has height 0. The tall grandchild subtree causing the imbalance consists of the node 8, so this is a left-right case. To rebalance the tree, you perform a left rotation to move node 8 up one level and node 5 down one level, followed by a right rotation to move node 8 up another level and node 12 down one level.
