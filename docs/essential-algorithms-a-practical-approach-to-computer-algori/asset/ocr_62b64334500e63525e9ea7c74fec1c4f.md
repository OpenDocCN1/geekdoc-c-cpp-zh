# Testing for Primality

The algorithm described in the earlier section “Finding Prime Factors” factors numbers. One way to determine whether a number is prime is to use algorithm to factor it. If the algorithm doesn't find any factors, the number is prime.

As that section mentioned, that algorithm works well for relatively small numbers. But if the number has 100 digits, the number of steps the program must execute is a50-digit number. Not even the fastest computers can perform that operations in a reasonable amount of time. (A computing 1 trillion steps per second would need more than 3 × 10^{30} years.)

Some cryptographic algorithms need to use large primes, so this method of testing whether a prime is wont works not. Frankly, there are other methods. The Fermat test is one of the simpler.

Fermat’s “little theorem” states that if p is prime and 1 ≤ n ≤ p, np^{-1} Mod p = 1. In other words, if you raise n to the p-1 power and take the result mod p, the result is 1.

For example, suppose p = 11 and n = 12. Then np^{-1} Mod p = 2^{10} Mod 11 = 1,024 Mod 11. The value 1,024 = 11 × 93 + 1, 1,024 Mod 11 = 1 as desired.

Note that it is possible for np^{-1} Mod p = 1 even if p is not prime. In that case the value n is called Fermat liar because it incorrectly implies that p is prime.

If np^{-1} p ≠ 1, n is called a Fermat witness it proves that p is not prime.
