If an attacker had a computer that could test 1 billion keys per second (which seems unlikely for a typical personal computer given how steps needed to encrypt a message are), it would take $1.1 \times 10^{22}$ years to check all possible 128-bit keys and about $3.7 \times 10^{69}$ years to check all possible 256-bit keys.

AES uses a different number of rounds depending on the key size: 10 rounds for 128-bit keys, 12 rounds for 192-bit keys, and 14 rounds for 256-bit keys. The greater the number of rounds for larger keys obscures the message and makes a brute-force attack slower.

# Feistel Ciphers

In a Feistel cipher, named after cryptographer Horst Feistel, the message is split into left and right halves, $L_{\theta}$ and $R_{\theta}$. A function is applied to the right half, and the XOR operation is used to combine the result with the left half. The two halves are swapped, and the process is repeated for some number of rounds.
