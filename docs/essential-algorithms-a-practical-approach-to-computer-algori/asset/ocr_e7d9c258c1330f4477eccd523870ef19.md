After initializing the arrays, the algorithm looks for improvements. First it looks for paths it can improve by using node A as an intermediate point. Node A is on the end of the network, so it cannot improve any paths.

Next the algorithm tries to improve paths by using node B and finds improvements. For example, looking at the second Distance array, you can see that Distance [A, C] is infinity, so Distance [A, B] is 4 and Distance [B, C] is 10, so the path A → C can be improved. To make that, the algorithm sets Distance [A, C] to 4 + 10 = 14 and Via [A, C] to the intermediate node B.

If you look at the Via network, you can find the changes. The initial path A → C had distance set to infinity. You can see in the network that the total distance for that path is 14.

Similarly you can work through the changes in the paths A → D, C → A, and D → A.

Next the algorithm tries to improve paths by using node C as an intermediate node. That node doesn't allow any improvements (because it's at the edge of the network).

Finally, the algorithm tries to improve paths by using node D as an intermediate node. It can use node D to improve the four paths A → C, B → C, C → A, and C → B.

For an example of finding a path through the Via array, consider the array on the right in Figure 13-12. Suppose you want to find the path from node A to C. The following steps describe how to find the path A → C:

+   - Via [A, C] is D, so A → C = A → D + D → C.
- Via [A, D] is B, so A → D = A → B + B → D.
- Via [D, C] is C, so there is a link from node D to node C.
- Via [A, B] is B, so there is a link from node A to node B.
- Finally, Via [B, D] is D, so there is a link from node B to node D.

The final path travels through nodes B, D, and C so the full path is A → D → C.

After you create the Distance and Via arrays, you can quickly find the shortest between any two points in a network. The downside is that arrays can take up a lot of room.

For example, a street network for a moderately large city might contain 30,000 nodes, so the arrays are 4-byte integers, the arrays would occupy 7 gigabytes of memory.
