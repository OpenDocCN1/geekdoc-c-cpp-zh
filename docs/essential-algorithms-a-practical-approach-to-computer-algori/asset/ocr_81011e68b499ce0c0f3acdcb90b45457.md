   - Make a Disk class to represent disks. It gives properties to represent its size and position, a list of points representing it should shift, we a Draw method that draws the disk, and a Move method that moves the some distance toward the next point in its list.
   - Make stacks to represent the pegs. Initially put Disk objects on the first peg's stack to represent the initial tower of disks.
   - Make a Move class to represent moves. It should record the peg number from which and to which disk should move. Give it a MakeMovePoints method that gets the top disk from the Move object's start peg, builds the Disk's movement points, and moves the Disk to the destination stack.
