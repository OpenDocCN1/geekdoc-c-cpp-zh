15. To multiply matrices, you need to multiply the rows of the first by the columns of the second. To do efficiently, you must be able to iterate over the entries in the second array's columns. The sparse arrays described in the text let you iterate the entries in their rows but not the entries in the columns.

You can make it easier to iterate the entries in a column by using a linked list of columns, each holding a linked list of entries, just as the text using linked lists of rows.

Instead of building a new class, however, you can reuse the existing SparseArray class. If you reverse the roles of the rows and columns, you get an equivalent array that lets you traverse the fields in a column. Of course, the class will treat the rows as columns and vice versa, which can be confusing.
