# Delete a Value

The algorithm to delete a value follows the same general approach used to set a value:

```
DeleteEntry(Integer: row, Integer column)
// Find the row before the target row.
ArrayRow: array_row = FindRowBefore(row)

// If the row is missing, we don't need to delete it.
If (array_row.NextRow == null) or
    (array_row.NextRow.RowNumber > row)
    Return

// Find the entry before the column in the next row.
ArrayEntry: target_row = array_row.NextRow
ArrayEntry: array_entry =
FindColumnBefore(column, target_row.RowSentinel)

// If the target entry is missing, we don't need to delete it.
If (array_entry.NextRow == null) Or
    (array_entry.NextRow.ColumnNumber > column)
    Return

// Delete the target column.
array_entry.NextColumn = array_entry.NextColumn.NextColumn

// If the row has any columns left, we're done.
If (target_row.RowSentinel.NextColumn != null) Return

// Delete the empty target row.
array_row.NextRow = array_row.NextRow.NextRow
EndDeleteEntry
```

This algorithm FindRowBefore to find the row before the target row. If the target row doesn't exist, the algorithm doesn't need to delete anything, so it returns.

The next algorithm FindColumnBefore to find the column before the target column in the target row. If the target column doesn't exist, the algorithm doesn't need to delete anything, so it returns.

At this point, the algorithm has found the ArrayEntry object in the row's linked list of entries. It removes the entry from the list by setting the NextColumn reference of the previous entry to or the object after the target entry.
