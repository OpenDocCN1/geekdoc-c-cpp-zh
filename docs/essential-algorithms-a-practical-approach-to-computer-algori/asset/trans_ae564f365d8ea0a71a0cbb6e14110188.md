
# 术语表 565

**哈 (hashing)** — 将键映射到哈希表位置的过程。

**哈希表 (hash table)** — 将数据映射到数据结构中位置的数据结构和算法。

**堆 (heap)** — 一种完全二树，其中每个节点的值至少大于所有子节点的值。

**高度 (height)** — 对于树中的节点，从该节点向下到叶子节点的最长路径长度。对于树而言，这等于根节点的高度。

**启发式算法 (heuristic)** — 一种通常产生良好结果但不保证产生最优结果的算法。

**希尔伯特曲线 (Hilbert curve)** — 一种填充空间的分形曲线，从初始化曲线开始，递归地将初始化曲线的部分替换为经过适当缩放、旋转和平移的曲线。

**爬山算法 (hill climbing)** — 一种启发式策略，在每一步都采取最接近可能解决方案的行动。这类似于登山者试图通过始终向上来寻找山顶。

**入度 (in-degree)** — 在有向网络中，进入节点的数量。

**间接递归 (indirect recursion)** — 当一个方法通过调用另一个方法，再由该方法调用第一个方法来间接调用自身时发生。

**初始化器 (initiator)** — 一种为特定分形设定基础形状的曲线。在每个递归层级，初始化器的一部分或全部被替换为生成曲线。

**中序遍历 (inorder traversal)** — 在树中，一种先访问节点的左子节点、然后访问节点、最后访问其右子节点的遍历方式。

**内部节点 (internal node)** — 至少有一个子节点的树节点。

**密钥 (key)** — 在密码学中，允许加密消息的接收者解码消息的信息。在现代密码学中，假设攻击者知道加密方法，因此拥有密钥的攻击者可以解密消息。

**骑士游问题 (knight's tour problem)** — 骑士访问棋盘上的每个位置且不访问任何方格两次。在闭合路径中，终点与起始位置仅一步之遥。不闭合的路径称为开放式路径。

**科科曲线 (Koch curve)** — 一种自相似的分形，从初始化器开始，递归地将初始化器的部分替换为经过适当缩放、旋转和平移的曲线。

**叶子节点 (leaf node)** — 没有子节点的树节点。

**最小公共祖先 (least common ancestor)** — 参见最近公共祖先。

**层级 (level)** — 树节点的层级与其根节点之间的距离。

**LIFO (后进先出)** — 参见栈 (stack)。

**LIFO 列表** — 参见栈 (stack)。

**线性数组 (linear array)** — 一维数组。

**线性同余生成器 (linear congruential generator)** — 一种使用简单递归关系生成数字的伪随机数生成器。

**线性探测 (linear probing)** — 一种构建哈希表的技术，其冲突解决策略向每个已占据的位置增加一个常数（通常为 1）以生成探测序列。

**线性查找 (linear search)** — 在线性数组或任何其他线性结构中线性地搜索某个值。

**链接 (link)** — 从一个链表单元到另一个单元，或从树或网络中的一个节点到引用或指针。

**链表 (linked list)** — 由一个或多个链接连接的单元列表。

**活锁 (livelock)** — 在分布式处理中，一种类似于死锁的情况，进程没有被阻塞，但由于它们处理冲突的方式，无法完成任何工作。

**循环 (loop)** — 重复执行执行直到满足某些条件的指令序列。

**可达节点 (reachable node)** — 在网络中，如果存在从节点 A 到节点 B 的路径，则节点 B 对于节点 A 是可达的。
