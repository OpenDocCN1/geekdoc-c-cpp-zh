| Bucketsort | O(N + M) | Buckets | Large arrays with reasonably uniform value distribution

These algorithms demonstrate an assortment of useful techniques and provide good performance for a wide variety of problems, but they're far from the end of the story. There are dozens of other sorting algorithms. Some are minor modifications different approaches. Chapter 10 discusses trees, which are also extremely useful for sorting data. Search the Internet for other algorithms.

This chapter explained several ways to sort data but didn't explain why you want to do that. Simply having data sorted often makes it more useful to a user. Viewing accounts sorted by balance makes it much easier to determine which accounts need special attention.

Another good reason to sort data is that you can later find specific items within it. For example, if you sort customers by their names, it's easier to locate a specific customer. The next chapter explains methods you can search for a sorted set of data to find a specific value.
