- The number of branches B in a binary tree containing N nodes is $B=N-1$.
- The number of nodes N in a perfect binary tree of height H is $N=2^{H+1}-1$.
- Conversely, if a perfect binary tree contains N nodes, it has a height of $\log(N+1)-1$.
- The number of leaves L in a perfect binary tree of height H is $L=2^H$. Because the total number of nodes in a perfect binary tree of height H is $2^{H+1}-1$, the internal nodes $I=N-L=(2^{H+1}-1)-2^H=2^H-1=2(X-1)-1$.
- This means in a perfect binary tree, almost half of the nodes are leaves and almost half are internal. More precisely, $I=L$.
- The number of missing branches (places where a child could be added) M in a binary tree that contains N nodes is $M=N+1$.
- If a binary tree has $N_0$ leaf nodes and $N_2$ nodes with degree 2, $N_0=N_2+1$. In other words, there is one more leaf node than nodes with degree 2.

## LEAF AND FULL NODES

The last fact is not very intuitive, so here's a proof.

- 1. Let $N$ be the total number of nodes; $B$ be the total number of branches; and $N_0$, and $N_2$ the number of nodes of degree 0, 1, and 2, respectively.
- 2. Consider the branches leading into nodes. Every node has a single branch leading into its parent, $B=N-1$.
- 3. Next, consider the branches out of nodes. The $N_0$ nodes have no branches leading out of them, the $N_1$ nodes have one branch leading out of them, and the $N_2$ nodes have two branches leading out of them, so the total number of branches $B=N_1+2*N_2$.
- 4. Setting these two equations for $B$ to each other gives $N-1=N_1+2*N_2$. Adding 1 to both sides of the equation changes this $N=N_1+2*N_2$.
- 5. Adding up the three kinds of nodes, you know that $N=N_0+N_1+N_2$.
- 6. Setting these two equations for $N$ to each other gives $N_1+2*N_2=N_0+N_1+N_2$. Subtracting $N_1+N_2$ from both sides makes this $N_2+1=N_0$.

These facts make it easier to calculate the run time for algorithms that work with trees. For example, if an algorithm must search a perfect binary tree containing nodes from the root to a leaf, you know that the algorithm needs only $O(\log(N))$ steps.

## INDUIVE REASONING

You can prove many of these properties of binary trees inductively. In an inductive proof, you first establish a base case for a small problem. Then you make an inductive step in which you prove that the property being true for some value $K$ that it must be true for the value $K+1$. Those two steps show that the property holds for all $K$.

For example, consider the first property described a moment ago: The number of nodes $N$ in a perfect binary tree of height $H$ is $2^{H+1}-1$. The following shows an inductive proof. [Here $H$ plays the role of $K$ in the general description of a proof.]

### BASE CASE:

Consider a perfect tree of height $H=0$. It has a single root node and no branches. In this case the number of nodes $N$ is 1. Note that $2^{H+1}-1 = 2^{0+1}-1 = 2^1-1 = 1$ so $N=1$ as desired.

### INDUIVE STEP:

Suppose the property true for perfect binary trees of height $H$. A perfect binary tree of height $H+1$ consists of a root node connected to two perfect subtrees of height $H$. Because we assume the property is true for trees of height $H$, the total number of nodes in each subtree is $2^{H+1}-1$. Adding the root node, means the total number of nodes in the tree of height $H+1$ is $2 \times (2^{H+1}-1)+1$. Rearranging this bit gives $2^{H+2}-2+1=2^{H+2}-1$. This means in a perfect binary tree, almost half of the nodes are leaves and almost half are internal. More precisely, $I=L$.
