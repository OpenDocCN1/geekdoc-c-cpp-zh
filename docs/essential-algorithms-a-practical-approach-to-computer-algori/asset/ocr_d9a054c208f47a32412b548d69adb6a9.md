# XML AND TREES

XML [ensible Markup Language] is a markup language for representing data. XML documents are hierarchical. You define tokens nested within other tokens.
XML's hierarchical structure makes a natural choice for storing trees persistently and for transferring trees from one program to another. For example, you could build a large tree representing your company's organizational chart, save in an XML file, and share that with other programs throughout your company.
For more information on XML, see http://en.wikipedia.org/wiki/XML or http://www.w3schools.com/xml/whatis.asp, or get a book about XML such as Beginning XML, 5th Edition by Joe Fawcett, at [Wrox, 2012].
