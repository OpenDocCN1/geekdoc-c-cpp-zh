# Branch and Bound

Branch and bound is a technique for searching trees more effectively than an exhaustive search. After it moves down a branch in the tree, the algorithm calculates the best possible outcome it achieve that branch. If the best possible outcome won't be an improvement over the best solution that has already been found, the algorithm abandons branch and doesn't continue its subtree. Depending on the specific data values, this can save a huge amount of time.

For example, suppose a partition problem algorithm keeps track of the current total weight in each of the two groups it is building and the total weight of the items that have not yet assigned to a group. Now suppose the algorithm has reached a point where group 0 has a weight of 100, group 1 has a total weight of 50, and the unassigned items have a total weight of 20. Suppose also that the algorithm has already found a solution in which the two groups have weights by 20.

If we were to assign all the remaining items to group 1, group 0 would have a total of 100, and group 1 would have a total weight of 70, a difference of 30. But the algorithm has already found a solution in which the difference is only 20. The current test solution cannot be improved to make it better than the current best solution. In that case, the algorithm can stop working on its current solution without assigning the rest of the items.

The following pseudocode shows a high-level branch and bound algorithm for the optimization of the partition problem:

```
StartBranchAndBound()\  <Initialize best solution so it is replaced by the first test solution>
  BranchAndBound(0)
End StartBranchAndBound()

BranchAndBound(Integer: next_index)
  // See if <next_index > max_index>
  // We have assigned all items, so we are at a leaf node.
    <If the test solution is better than the best solution, save it>
  Else
    // We have not assigned all items, so we are not at a leaf node.

  If <test solution cannot be improved enough
    to beat the current best solution>
    Then Return

  <Assign item next_index to group 0>
  BranchAndBound(next_index + 1)
  <Unassign item next_index to group 0>
```
