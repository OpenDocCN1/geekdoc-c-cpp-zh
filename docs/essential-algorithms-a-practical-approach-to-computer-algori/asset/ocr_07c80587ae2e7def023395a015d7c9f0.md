This algorithm has a few flaws. For example, it doesn't handle the case in which multiple items have the same value, as in 1, 2, 3, 4. It also doesn't handle arrays with an even number of items, which has no item in the middle. (If an array has an even number of items, median is defined as the average of the two middle items. For example, the median of 1, 4, 6, 9 is 4 + 6 / 2 = 5).

If the array contains N values, the outer For loop executes N times. For every one of those, the inner For j loop executes N times. That means the steps inside the inner loop execute N × N = N² times, giving the algorithm a run time of O(N²).

A much faster algorithm is to first sort the array and then find the median directly by looking at the values in the sorted array. Chapter 6 describes several algorithms for sorting an array containing N items in O(N log N) time. That's a lot faster than O(N²).

# Inserting Items

Inserting an item at the end of a linear array is easy, assuming that the programming language can extend the array by one item. Simply extend the array and insert the new item at the end

Inserting an item anywhere else in the array is more difficult. The following algorithm inserts a new item at location position in a linear array:

```
InsertItem(array[], Integer: value, Integer: position)
// Resize the array to add 1 item at the end

// Move the items after the target position
// to make room for the new item.
For i = array.Length - 1 To position + 1 Step -1
  array[i] = array[i - 1]
Next i

// Insert the new item.
array[position] = value
InsertItem
```
