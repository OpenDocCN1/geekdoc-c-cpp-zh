+   7. Add “c” to get “descent.”

This requires seven steps, so the edit distance is no more than 7, but how can you tell if it is the most efficient way to convert “assent” to “descent”? For longer words or strings (as you will see later in this section, for files), it can be hard to be sure you found the best solution.
