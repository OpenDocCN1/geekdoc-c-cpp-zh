- 9. A B-tree of order K would occupy $1024 \times (2 \times K) + 8 \times (2 \times K + 1) = 2048 \times K + 16 \times K + 8 = 2064 \times K$ bytes. To fit in four blocks of 2 KB, this must be less than or equal to $4 \times 2 \times 1024 = 8192$ bytes, so $2064 \times K + 8 \leq 8192$. Solving for $K$: $K \leq (8192-8) / 2064$, or $K \leq 3.97$. $K$ must be an integer, so you must round this down to 3.

A B+-tree of order K would occupy $100 \times (2 \times K) + 8 \times (2 \times K + 1) = 200 \times K + 16 \times K + 8 = 216 \times K + 8$ bytes. To fit in four blocks of 2 KB, this must be less than or equal to $4 \times 2 \times 1024 = 8192$ bytes, so $216 \times K + 8 \leq 8192$. Solving for $K$: $K \leq (8192-8) / 216$, or $K \leq 37.9$. $K$ must be an integer, so you must round this down to 37.

Each tree would have a height of $\log_{(K+1)}(10000)$ while holding 10,000 items. For the B-tree, value is $\log_K(10000) = 6.6$, so the tree could be seven levels tall. For the B+-tree, value is $\log_{2K}(10000) = 2.5$, so the tree could be three levels tall.
