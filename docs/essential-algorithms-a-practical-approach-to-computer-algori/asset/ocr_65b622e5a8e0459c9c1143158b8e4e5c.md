# Hilbert Curve

Like the Koch curve, the Hilbert curve starts with a simple initiator curve. To move to a deeper level of recursion, the algorithm breaks the initiator into pieces and uses an appropriately rotated smaller version of the Hilbert curve to draw pieces of the initiator.

Figure 9-8 shows level 0, 1, and 2 Hilbert curves. In the level 1 and 2, the lines connecting the lower-level curves are gray so that you can see how the pieces are connected to build the higher-level curves.

![](bbox=[0.131, 0.283, 0.816, 0.458])

The following pseudocode shows the Hilbert curve algorithm:

```
// Draw the Hilbert initially moving in the direction <dx, dy>
Hilbert(Integer: depth, Float: dx, Float: dy)
If (depth > 0) Then Hilbert (depth - 1, dx, dy)
DrawRelative(dx, dy)
If (depth > 0) Then Hilbert (depth - 1, dx, dy)
DrawRelative(dx, dy)
If (depth > 0) Then Hilbert (depth - 1, dx, dy)
DrawRelative(-dx, -dy)
If (depth > 0) Then Hilbert (depth - 1, -dy, -dx)
```

The algorithm assumes the program has defined a current location. The DrawRelative method draws from current position to point and updates the current position. For example, if the position is (10, 20), the statement DrawRelative(0, 10) would draw the line segment (10, 20) (10, 30) and leave the new current position at (10, 30).

If the recursion is greater than 0, the algorithm calls itself recursively to draw a version of the curve with one lower level of recursion and with the dx and dy parameters switched so that the smaller curve is rotated 90 degrees. If you compare the level 0 and 1 curves shown in Figure 9-8, you can see that the level 0 curve that is drawn at the beginning of the level 1 curve is rotated. Next the program draws a line segment to connect the first lower-level curve to the next one.
