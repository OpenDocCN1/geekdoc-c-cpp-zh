# Stack Algorithms

Many algorithms use stacks. For example, some of the shortest path algorithms described in Chapter 13 can use stacks. The following sections describe a few other algorithms that you can implement using stacks.

# Reversing an Array

Reversing an array is simple with a stack. Just push each item onto the stack and pop it back off. Because of the stack's LIFO nature, the items come back in reverse order.

The following pseudocode shows this algorithm:

```
ReverseArray(Data: values[])
  // Push the values from the array onto the stack.
  Stack: stack = New Stack
  For i = 0 To <length of values> - 1
    stack.Push(values[i])
Next i
```

```
// Pop the items off the stack into the array.
  For i = 0 To <length of values> - 1
    values[i] = stack.Pop()
Next i
EndReverseArray
```

If the array contains N items, this algorithm takes 2 × N steps, so it has run O(N).

# Train Sorting

Suppose a train contains cars bound for several different destinations, and it enters a yard. Before the train leaves the yard, you need to use tracks to sort the cars so that the cars going to the same destination are grouped.

Figure 5-5 shows a train with cars bound for cities 3, 2, 1, 3, and 2 entering from the left on the input track. The train can move onto a holding track and move its rightmost car to the left end of any cars on that holding track. Later the train can go back to the holding track and move a car from the holding track's left end back onto the train's right end. The goal is to sort the cars.

![](img/fefa42765c0b410af6705110aea7c0cb_141_0.png)

**Figure 5-5**: You can use stacks to model a real yard sorting a train's cars.

You can directly model this situation by using stacks. One stack represents the incoming train. Its Pop method removes a car from the right of the train, and its Push method moves a car back onto the right end of the train.
Other stacks represent the holding tracks and the output track. Their Push methods represent moving a car onto the left end of the track, and the Pop method represents moving a car off the left end of the track.
The following pseudocode shows how a program could use stacks to sort the train shown in Figure 5-5. Here *train* is on the input track, *track1* and *track2* are the top and bottom holding tracks, and *output* is the output track on:

```
holding1.Push(train.Pop()) // Step 1: Car 2 to holding 1.
holding2.Push(train.Pop()) // Step 2: Car 3 to holding 2.
output.Push(train.Pop()) // Step 3: Car 1 to output.
holding1.Push(train.Pop()) // Step 4: Car 2 to holding 1.
train.Push(holding2.Pop()) // Step 5: Car 3 to train.
train.Push(holding1.Pop()) // Step 6: Car 2 to train.
train.Push(holding1.Pop()) // Step 7: Car 2 to train.
train.Push(output.Pop()) // Step 8: Car 1 to train.
```

Figure 5-6 shows this process. The car being moved in each step has a border outline. Arrow shows where each car moves.

Of course, in a real yard, each move requires shuffling train cars and can take several minutes. Therefore, finding a solution with the fewest possible moves is very important.

![](img/fefa42765c0b410af6705110aea7c0cb_142_0.png)

**Figure 5-6:** You can sort this train in eight moves by using two holding tracks and an output track.

# Tower of Hanoi

The Tower of Hanoi puzzle, shown in Figure 5-7, has three pegs. One peg holds a stack of disks of different sizes, ordered from smallest to largest. You move the disks from one peg to another, one at a time, with the goal of restacking all the disks, ordered by size, on a different peg. You cannot place a disk on top of another disk that has a smaller radius.

![](img/fefa42765c0b410af6705110aea7c0cb_142_1.png)

**Figure 5-7:** The goal in the Tower of Hanoi puzzle is to restack disks from one peg to another without placing a disk on top of a smaller disk.

You can model this puzzle using three stacks in a fairly obvious way. Each stack represents a peg. You can use numbers giving the disks’ radii for objects in the stacks.

The following pseudocode shows how a program could use stacks to model moving the disks from the left peg to the middle peg:

```
peg2.Push(peg1.Pop())
peg3.Push(peg1.Pop())
peg2.Push(peg3.Pop())
peg1.Push(peg2.Pop())
peg3.Push(peg2.Pop())
peg2.Push(peg3.Pop())
peg1.Push(peg2.Pop())
```
