# Pseudandom Probing

Pseudandom probing is similar to linear probing, except that the stride is given by a pseudandom function of the initially mapped location. In words, if a value initially maps to position K, its probe sequence is K, K + p, K + 2 * p ..., where p is determined by a pseudandom function of K.
Like quadratic probing, pseudandom probing prevents primary clustering. Also like quadratic probing, pseudandom probing is subject to secondary clustering, because values that map to the same initial position follow the same probe sequences.
Pseudandom probing may skip over some unused entries and fail to insert an entry even though the table isn't completely full.

# Double Hashing

The reason quadratic probing and pseudandom probing suffer from secondary clustering is that values that map to the same initial location follow the same probe sequence. You can reduce that effect if you make values that map to the same location different probe sequences.
Double hashing is similar to pseudandom probing. Instead of using a pseudandom function of the initial location to create a stride value, it uses a second hashing function to map the original value to a stride.
