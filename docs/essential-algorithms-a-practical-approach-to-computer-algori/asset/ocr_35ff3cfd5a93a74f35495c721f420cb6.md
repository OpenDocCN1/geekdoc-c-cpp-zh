The following algorithms find the minimum, maximum, and average values for a one-dimensional array of integers:

```
Integer: FindMinimum(Integer: array[])
Integer: minimum = array[0]
For i = 1 To Array.Length - 1
  If (array[i] < minimum) Then minimum = array[i]
Next i
Return minimum
FindMinimum
```

```
Integer: FindMaximum(Integer: array[])
Integer: maximum = array[0]
For i = 1 To Array.Length - 1
  If (array[i] > maximum) Then maximum = array[i]
Next i
Return maximum
FindMaximum
```

```
Float: FindAverage(Integer: array[])
Integer: total = 0
For i = 0 To Array.Length - 1
  total = total + array[i]
Next i
Return total / array.Length
FindAverage
```

As for the case to find a specific item in the array, these algorithms must visit every item in the array, so they run time O(N).

One value is as easy to calculate as the median, the value that lies in the middle of the values when they are sorted. For example, the median of 1, 3, 4, 7, 8, 9 is 7 because there are three smaller values (1, 3, 4) and three larger values (8, 8, 9).
