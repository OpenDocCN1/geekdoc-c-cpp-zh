# Chapter 9 = Recursion

One other factor determines which groups of items are included in a particular kind of selection or permutation: whether duplicates are allowed. For example, the two-item selections for the set [A, B, C] allowing duplicates [A, A], [B, B], and (C, C) in addition to the other selections listed earlier.

The special case of permutation that takes all the items in the set and doesn't allow duplicates all the possible arrangements of the items. For the set [A, B, C], all the arrangements are (A, B, C), (A, C, B), (B, A, C), (B, C, A), (C, A, B), and (C, B, A). Many people think of the permutations of a set to be this collection of arrangements, rather than the more general case, in which you may not be taking all the items from the set and you may allow duplicates.

The following sections describe algorithms you can use to generate selections and permutations without duplicates:

# Selections with Loops

If you know how many items you want to select from a set when you are writing a program, you can use a series of For to easily generate combinations. For example, the following pseudocode generates all selections of three items from a set of five items allowing duplicates:

```
// Generate selections of 3 items allowing duplicates.
List<string>: SelectWithDuplicates(List<string> items)
List<string>: results = New List<string>
For i = 0 To <Maximum index in items>
  For j = i To <Maximum index in items>
    For k = j To <Maximum index in items> + items[i]
      results.Add(items[i] + items[j] + items[k])
    Next k
  Next j
Next i
Return results
End SelectWithDuplicates
```

This algorithm takes as a parameter list of Strings. It then uses For loops to select the three letters that make each selection.

Each loop starts with the current value of the previous loop's counter. For example, the second loop starts with j equal to i. That means the second letter chosen for the selection will comes before the first letter in the items. For example, if the items are the letters A, B, C, D, and E, and the first letter in the selection is C, the second letter will be A or B. That keeps the letters in the selection in alphabetical order and prevents the algorithm from selecting both [A, B, C] and [A, C, B], which are the same set.

Within the innermost loop, the algorithm combines the items selected by each loop variable to produce an output that includes all selections.
