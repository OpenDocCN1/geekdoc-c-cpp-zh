To simplify the network, find such K, N, and M, and require that nodes M and N have the same color. We know that they aren't neighbors, so that this is allowed. Because node K has exactly five neighbors and nodes M and N use the same color, K's neighbors are not using all five of the available colors. That means at least one is left over for node K use.

The simplification is to remove nodes K, M, and N from the network and create a new node M/N to represent the color that nodes M and N will give. The new node has the same color that nodes M and N had previously. Call this Rule 2.

When you restore the nodes K, M, and N that were removed using Rule 2, give nodes M and N whatever color was assigned to node M/N. Pick a color that isn't used by one of its neighbors for node K.

You can use techniques similar to those described in the previous section for three-coloring. The following steps describe the algorithm:

+   1. Repeat while the network has more than one node:
   a. if there is a node with degree less than 5, remove it from the network, keeping track of where it was so you can restore it.
   b. If the network contains no node of degree less than 5, find a node K with degree exactly 5 and two children M and N, as described earlier. Remove nodes K, M, and N, and create the new node M/N as described in Rule 1.
2. When the network contains a single node, assign it a color.
3. Restore the previously removed nodes, coloring them appropriately.

If the network is not completely connected, you can use the algorithm for each of its connected components.
