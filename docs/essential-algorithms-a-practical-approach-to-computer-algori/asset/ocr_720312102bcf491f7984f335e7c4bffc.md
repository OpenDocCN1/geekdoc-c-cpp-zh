# Chapter 2 Numerical Algorithms

For example, suppose you want to calculate $7^6$. First the algorithm calculates $7^1$, $7^2$, and $7^4$. It stops because the next power, 8, is greater than the desired power, 6:

$7^1 = 7$

$7^2 = (7^1)^2 = 7^2 = 49$

$7^4 = (7^2)^2 = 49^2 = 2401$

Next the algorithm uses the second fact to build 6 from a sum of powers of 2 that are already created. If you think of 6 as being because of $2 = 2 + 4$. Using the second fact, you know that $7^6 = 7^2 	imes 7^4 = 49 	imes 2401 = 117,649$.

Performing this calculation took two multiplications to calculate $7^2$ and $7^4$ plus one more multiplication to find the final result, for a total of three multiplications. That's fewer multiplications than multiplying $7 	imes 7 	imes 7 	imes 7 	imes 7$, but it's a small difference in this example.

More generally, for the exponent P, the algorithm calculates log(P) powers of A. It then searches because the binary digits of A to see which of those powers it must multiply to get the final result. (If a binary digit of P is 1, then the result should include the corresponding power of 2. For the previous example, the binary representation of 6 is 110 so the second and third powers of 2 are included: $2^2$ and $2^1$).

In binary, the value P has log(P) digits, so the total time is O(log P) + O(log P). If P is 100, log(P) is about 20, so this algorithm uses about 20 steps (up to 40 multiplications), which is a less than 1 million.

One limitation of this algorithm is that values raised to large powers grow extremely large. Even a "small" value as $7^{300}$ has 254 decimal digits. This means that multiplying the huge numbers needed to calculate large powers grows slow and takes up quite a bit of space.

Fortunately, the most common applications for these kinds of huge powers are cryptographic algorithms that perform all operations in modulus. The modulus is large, but it still limits the numbers' size. For example, if the modulus has 100 digits, the product of two 100-digit numbers can have more than 200 digits. You then reduce the result with the modulus to again get a number with no more 100 digits. Reducing each number with the modulus each step slightly smaller, but it means you can calculate values of practically unlimited size.

# Working with Prime Numbers

As you probably know, a prime number is a counting number (an integer greater than 1) whose only factors are 1 and itself. A composite number is a counting number greater than 1 that is not prime.
