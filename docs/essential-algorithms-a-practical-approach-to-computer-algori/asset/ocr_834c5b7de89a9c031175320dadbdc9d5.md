The code iterates through the linked list until it finds the last cell. It makes the last cell’s link point to the new cell and sets the new cell’s link point to to null.

This code would be messier if the list didn't have a sentinel. In that case you would have to use special code to handle the case when the list is empty top points to null.

# Inserting Cells After Other Cells

The preceding sections explained how you can add cells to the beginning or end of a linked list, but sometimes you may want to insert an item in the middle of the list. Assuming that you have a variable named after_me that points to the cell after you want to insert the item, the following pseudocode shows an algorithm for inserting a cell after after_me:

```
InsertCell(Cell: after_me, Cell: new_cell)
    new_cell.Next = after_me.Next
    after_me.Next = new_cell
```
