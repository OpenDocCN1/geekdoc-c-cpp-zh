The number of cells in a full tetrahedral arrangement is harder to calculate. If you make some drawings and count the cells, you can follow the approach used in the chapter. If you assume the number of cells in the tetrahedral arrangement involves the number of rows cubed, you will find that the exact number is (N³ + 3×N² + 2×N) / 6. The following pseudocode uses that formula:

```
Integer: NumCellsForTetrahedralRows(Integer: rows)
  Return (rows * rows + 3 * rows + 2 * rows) / 6
End NumCellsForTetrahedralRows
```
