When you move a new value up to the parent node, that node may now be too full. In that case you must repeat the process with the parent node, either rearranging values among that node's siblings or splitting that node and moving a value to its parent.

In the worst case, the split travels all the way up to the tree to the root, where it causes a root split. This is the only way a B-tree grows taller.

# # Deleting Values

To remove a value from an internal node, swap it with the rightmost value to the left in the tree, as you normally do for sorted trees. Then treat the case as you were removing the value from a leaf node.

After you remove the value, if the leaf node contains at least K values, you're done. If the leaf node contains fewer than K values, you must rebalance the tree.

If any of the node's siblings holds more than K values, you can redistribute the values to give the target node K values.
