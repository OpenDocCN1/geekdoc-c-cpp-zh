```
$T_{BI} = (T_{A1} + E) + D_{AB}$
```

Now, if you subtract the second equation from the first, you get this:

```
$T_{BI} - T_{A2} = (T_{A1} + E + D_{AB}) - (T_{BI} + E + D_{BA})$
$= T_{A1} - T_{BI} + D_{BA} - 2 \times E$
```
