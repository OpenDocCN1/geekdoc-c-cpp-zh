# Chapter 13 = Basic Network Algorithms 333

```
// Push the node onto the stack.
stack.Push(link.Nodes[1])
End If
Next link
Loop // Continue processing the stack until empty
EndFirstTraverse
```

This algorithm visits the start node and pushes it onto a stack. Then, as the stack isn't empty, it pushes the next node off the stack and processes it.
To process it, the algorithm examines the node's links. If a link's destination node has not been visited, the algorithm marks it as visited and adds it to the stack for later processing.
Because of how it pushes nodes onto a stack, it traverses the network in a depth-first order. To see why, suppose the algorithm starts at node A and that A has neighbors B1, B2, and so on. Later, when it processes node A, it pushes node's neighbors C1, C2, and so onto the stack. Because the stack returns items in last-in-first order, the algorithm processes the C nodes. As it continues, the algorithm moves quickly through the network, traveling long distances from the start node A before it gets back to processing node's closer neighbors.
Because the traversal visits nodes far from the root node before it visits all the ones that are closer to the root, this is called a depth-first traversal.
