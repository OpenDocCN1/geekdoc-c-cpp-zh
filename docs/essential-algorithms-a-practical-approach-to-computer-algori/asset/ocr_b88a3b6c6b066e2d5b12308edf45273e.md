# Network Representations

It's fairly easy to use objects to represent a network. You can represent nodes with a node class.

How you represent links depends on how you will use them. For example, if you are building a directed network, you can make the links references stored inside the node class. If the links have costs or other data, you can also add that to the node class. The following pseudocode shows a simple node class for this situation:

```
Class Node
  String: Name
  List-Node: Neighbors
```
