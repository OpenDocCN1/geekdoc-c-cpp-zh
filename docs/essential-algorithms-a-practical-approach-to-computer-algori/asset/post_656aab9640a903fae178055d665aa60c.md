- 9. $LCM(A, B) = A \times B / GCD(A, B)$. Suppose $g = GCD(A, B)$, so $A = g \times m$ and $B = g \times n$ for some integers $m$ and $n$. Then $A \times B / GCD(A, B) = m \times n$. The values $m$ and $n$ have no common factors, so this is LCM.

- 10. The following pseudocode shows the algorithm used by the FastExponentiation example program that is available for download on the book's website. (The bold lines are used for Exercise 11.)

```
// Perform the exponentiation.
Integer: Exponentiate(Integer: value, Integer: exponent)
```

```
// Make lists of powers and the value to that power.
List Of Integer: powers
List Of Integer: value_to_powers

// Start with the power 1 and value^1
Integer: last_power = 1
Integer: last_value = value
powers.Add(last_power)
value_to_powers.Add(last_value)

// Calculate other powers until we get one bigger than exponent.
While (last_power < exponent)
    last_power = last_power * 2
    last_value = last_value * last_value
    powers.Add(last_power)
    value_to_powers.Add(last_value)
End While

// Combine values to make the required power.
Integer: result = 1

// Get the index of the largest power that is smaller than exponent.
For power_index = powers.Count - 1 Step -1
    // See if this power fits within exponent.
    If (powers[power_index] <= exponent)
        // Use this power.
        exponent = exponent - powers[power_index]
        result = result * value_to_powers[power_index]
Next power_index

// Return the result.
Return result
End Exponentiate
```

- 13. You already know that next\_prime \times 2 has been crossed out, because it is a multiple of 2. If next\_prime \times 3, you know that next\_prime \times 3 has already been crossed out, because 3 has already been considered. For every prime $p$ where $p < next\_prime$, the $p$ has already been considered, so next\_prime $\times p$ has already been crossed out. The first prime that is not less than next\_prime is next\_prime, the first multiple of next\_prime that has not been considered is next\_prime \times next\_prime. That means you can change the loop to the:

- 17. The following pseudocode shows a high-level algorithm for performing Monte Carlo integration in three dimensions:

```
Float: EstimateVolume(Boolean: PointIsInShape(..), Integer: num_trials,
Float: xmin, Float: xmax, Float: ymin, Float: ymax,
Float: zmin, Float: zmax)
Integer: num_hits = 0
For I = 1 To num_trials
Float: x = <pseudandom number between xmin and xmax>
Float: y = <pseudandom number between ymin and ymax>
Float: z = <pseudandom number between zmin and zmax>
If (PointIsInShape(x, y, z)) Then num_hits = num_hits + 1
Next I
```

```
Float: total_volume = (xmax - xmin) * (ymax - ymin) * (zmax - zmin)
Float: hit_fraction = num_hits / num_trials
Return total_volume * hit_fraction
End EstimateVolume
```
