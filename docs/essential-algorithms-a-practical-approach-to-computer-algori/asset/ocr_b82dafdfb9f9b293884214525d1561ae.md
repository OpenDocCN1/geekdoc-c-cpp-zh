# Glossary

+   AVL tree — A sorted binary tree in which the heights of two subtrees at
given node differ by at most 1.

+   B-tree — A balanced tree in which internal nodes (called buckets) can hold several
values and corresponding branches.

+   B+tree — Similar to a B-tree, except that the tree's nodes store only key values
 pointers to the rest of each record's data instead of holding the data itself.

+   backtracking — A recursive algorithm that considers partial solutions. If it finds
a partial solution that cannot be extended to a full solution, the algorithm discards
t partial solution, backtracks to the previous feasible test, and continues
searching for them.

+   balanced tree — A tree that rearranges its nodes as necessary to guarantee that it
does't become too tall and thin. That allows algorithms that travel through
tree in O(log N) time

+   Big Omega notation — An algorithm's run time is Ω(g(N)) if the func-
gion(N) is a lower bound for the algorithm's runtime function.

+   Big O notation — An algorithm's O run time is O(g(N)) if the function
g(N) is an upper bound for the algorithm's runtime function.

+   Big Theta notation — An algorithm's big theta run is Θ(g(N)) if the func-
gion(N) is both lower and upper bound for the algorithm's runtime function.

+   binary search — A strategy that repeatedly divides the search space into
two halves and searches the halves that contain the target item.

+   binary tree — A tree with degree 2.

+   bipartite matching — The process of matching the nodes in one group of a bipar-network with the nodes in the other group.

+   bipartite network — A network in which the nodes can be divided into two
groups, A and B, and every link connects a node in group A with a node in
group B.

+   block cipher — A cipher in which the plaintext is broken into blocks of the same
size, each encrypted, and the blocks are combined to give the ciphertext.

+   bottom-up B-tree — A B-tree that performs burst splits as recursive calls end
and move up to the root.

+   branch — Connects a parent and child node in the tree.

+   branch and bound — A tree search algorithm in which the program moves down
a branch then decides whether it is possible to improve its current solution
enough to be better than the best solution so far. If the current solution
innot improve on the best solution so far, the algorithm stops exploring that
part of the tree.

+   breadth-first traversal — In a tree or network, a traversal that visits all of a node's
children visiting any other nodes. This makes the traversal visit nodes close
to the starting node before visiting nodes farther away.
