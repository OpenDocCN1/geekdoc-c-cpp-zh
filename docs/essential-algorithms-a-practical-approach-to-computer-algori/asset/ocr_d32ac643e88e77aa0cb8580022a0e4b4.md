One type of game heuristic is to look for patterns in the board position. For example, one heuristic that chess players use is “When ahead, trade mercilessly.” When you have the advantage and you can trade one of your pieces for a piece of equal value, you should do so. That can make your relative advantage greater and makes the game tree so that it's easier to search in the future.
Other patterns that a chess program may look include long sequences of trades, casting, moves that threaten multiple pieces, discovered check, moves that threaten the king or queen, promotion, and so forth.
When a program recognizes one of these patterns, it can alter the strategy it uses to search the game tree. For example, if the program sees it exceed its maximum depth of recursion to follow the exchange to the end and see if it will come ahead.
Another kind of heuristic assigns numeric values to locations on the board and modifies a board's total value based on the locations occupied or threatened by a player's pieces. For example, in tic-tac-toe you might assign each square a number the number of wins that include. For example, the upper-left corner would have the value 3, because there are three ways to win by that square. Figure 12-2 shows the square values for this heuristic.

In chess, the center four squares occupy a critical location, where you might give those squares more value. You might also assign different values for squares occupied by a piece and threatened by a piece.
In most cases, the values of the board locations change over time. For the early stages of a chess game the central four squares are important. At the very end of the game, however, it is whether a player can achieve a checkmate that is important, not whether the player controls those squares.
