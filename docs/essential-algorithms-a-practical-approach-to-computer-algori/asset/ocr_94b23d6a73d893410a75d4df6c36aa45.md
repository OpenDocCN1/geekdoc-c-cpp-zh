# Chapter 5 Stacks and Queues

The following pseudocode shows how a program could use stacks to model moving the disks from the left peg to the middle peg:

```
peg2.Push(peg1.Pop ())
peg3.Push(peg1.Pop ())
peg3.Push(peg2.Pop ())
peg2.Push(peg1.Pop ())
peg1.Push(peg3.Pop ())
peg2.Push(peg3.Pop ())
peg2.Push(peg1.Pop ())
```
