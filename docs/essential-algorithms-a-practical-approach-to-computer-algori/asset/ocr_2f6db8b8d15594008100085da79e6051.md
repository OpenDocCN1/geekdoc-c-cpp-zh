# **INDUCTIVE REASONING**

You can prove many of these properties of binary trees inductively. In an inductive proof, you first establish a base case for a small problem. Then you make an inductive step in which you prove that the property being true for some value K that it must be true for the value K+1. Those two steps show that the property holds for all K.

For example, consider the first property described a moment ago: The number of nodes N in a perfect binary tree of height H is $2^{H+1}-1$. The following shows an inductive proof. [Here H plays the role of K in the general description of an proof.]

# **BASE CASE:**

Consider a perfect tree of height H=0. It has a single root node and no branches. In this case the number of nodes N is 1. Note that $2^{H+1}-1 = 2^{0+1}-1 = 2^1-1 = 1$ so N=1 as desired.

# **INDUCTIVE STEP:**

Suppose the property true for perfect binary trees of height H. A perfect binary tree of height H+1 consists of a root node connected to two perfect subtrees of height H. Because we assume the property is true for trees of height H, the total number of nodes in each subtree is $2^{H+1}-1$. Adding the root node, means the total number of nodes in the tree of height H+1 is $2	imes(2^{H+1}-1)+1$. Rearranging this bit gives $2^{H+2}-2+1=2^{H+2}-1$. This is the formula for the number of nodes for a perfect binary tree of height H+1 (just plug H+1 into the formula), so the property is true for a tree of height H+1.

This proves that the number of nodes in a perfect binary tree of height H $2^{H+1}-1$ for all H.

If a binary tree containing N nodes is fat (isn't too tall and skinny), as if it's a complete tree, its statistics are similar to those of a perfect binary tree in terms of Big O notation. if a fat binary tree contains N nodes, it has O(log N) height, O(N+2)=O(N) leaves, O(N) internal nodes, and O(N) missing branches.

These properties are also true for fat trees of higher degrees but with different log bases. For example, a fat degree 10 tree containing N nodes has height O($\log₁₀ N). Because all log bases are the same in Big O notation, this is the same as O(log N), although in practice the constants ignored by Big O notation may make a big difference.
