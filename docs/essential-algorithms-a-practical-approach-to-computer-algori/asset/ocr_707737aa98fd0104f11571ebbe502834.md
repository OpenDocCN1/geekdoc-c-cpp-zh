Linked lists are often frequently represented graphically, with boxes representing cells and arrows representing links.

To indicate a link that does not point to anything, this book uses a small box with an X in. (In a programming language, the value of the pointer corresponding to the link would be nothing, null, or some other language-specific value indicating that the pointer does not point to.)

In addition to the list itself, a program needs a variable that points to the list so that the code can find. This variable is named top to indicate that it represents the top of the list. The top variable could be a variable of the cell's class, or it may be a pointer to the first cell in the list.

Figure 3-1 shows two linked lists holding the numbers 31, 72, 47, and 9. In the list on the top, the program has a variable named top that is a pointer to the first cell. In the list on the bottom, the program's top variable is the first cell in the list. Both lists end with a box containing an X to represent a null pointer.

Linked lists are a good way to store a list of items that can grow or shrink over time. To add a new cell, you just add it at the beginning or end of linked list. In contrast, an array has a fixed size, so it may be hard to enlarge if you need to add more items.

The following sections explain some of the algorithms you can use to manipulate linked lists. Many of them are most easily described with figures that show the list before and after an operation has been performed.
