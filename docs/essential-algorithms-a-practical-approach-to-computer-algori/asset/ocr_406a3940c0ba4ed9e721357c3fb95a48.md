**Phase 2, Round 2**—the majority value for the phase king $P_5$ is seen (three times), it tells all the other processes that the tiebreaker value is attack. All valid processes (including the phase king) see the majority value less than 3.5 times, so they all go with the tiebreaker value, which is attack.

At this point, all the value processes have attack as their current guess.
The reason this algorithm is that it works for $F+1$ phases. If there are at most $F$ failures, at least one of the processes has honest phase king.
During phase, suppose value process $P_i$ doesn't see its majority value more than $N/2+F$ times, it uses the phase king's tiebreaker value.
All valid processes $P_i$ that don't see a value more than $N/2+F$ times end up using the same value. But what if some valid process $P_i$ sees a value more than $N/2$ times? Because there are at most $F$ invalid processes, those more than $N/2+F$ occurrences include more than $N/2$ occurrences.\ That means there is a true value for that, so every process that sees a majority value more than $N/2+F$ times must be seeing the same majority value. In this situation there is a true value, the current phase king must see as its majority value (even if the phase king doesn't necessarily see it than $N/2+F$ times).

This means after the honest phase king's reign, all the valid processes vote for the same.
After that, it doesn't matter what an invalid phase king tries to do. At this point, the $N-F$ valid processes all agree on a value. This means all the valid processes keep their values, no matter what an invalid phase king tries to confuse them.

# Leader Election

Sometimes a collection of processes needs a central leader to coordinate actions. The leader crashes or the network connection to the leader fails, the group must elect a new leader.
The *bully algorithm* uses the processes' IDs to elect a new leader. The process with the largest ID wins.
