Notice that paths between nodes may not be unique. For example, A-E-F and A-B-C-F are both paths from A to F.

Table 13-1 summarizes these key terms to make remembering them a bit easier. 

| TERM | MEANING |
| --- | --- |
| adjacent | If two nodes are connected by a link, they are adjacent. |
| capacity | The maximum amount of something that can move through a node or link, such as the maximum current that can flow through a wire in an electrical network or the maximum number of cars that can move through a street network per unit of time. |
| connected | In an undirected network, nodes A and B are connected if node B is reachable from node A and vice versa. An undirected network is connected if every node is reachable from every other node. |
| connected component | A set of nodes that are mutually connected. |
| cost | A link may have an associated cost. Less commonly, a node may have a cost. |
| cycle | A path that returns to its starting point. |
| degree | In an undirected network, the number of links leaving a node. In a directed network, a node has an in-degree and an out-degree. |
| directed | A link is directed if you can traverse it in only one direction. A network is directed if it contains directed links. |
| edge | Link. |
