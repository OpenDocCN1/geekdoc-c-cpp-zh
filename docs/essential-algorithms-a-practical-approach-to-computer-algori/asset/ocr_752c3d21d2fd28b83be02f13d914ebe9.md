**Figure B-1:** The Fibonacci function increases more quickly than x^2 but less quickly than 2*.

It turns out that you can calculate the Fibonacci numbers directly using the following formula:

$Fibonacci (n) = \frac{w^n}{\sqrt{5}}$

where:

$w = \frac{1+\sqrt{5}}{2}$

So the Fibonacci function is exponential in $\phi$. The value $\phi=1.618$, so the function doesn't grow as quickly as $2^n$, but it is still exponential and does grow faster than polynomial functions.
