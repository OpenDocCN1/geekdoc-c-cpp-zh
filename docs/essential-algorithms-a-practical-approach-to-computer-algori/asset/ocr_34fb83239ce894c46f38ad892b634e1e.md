Finally, you need to add 1 for each item that comes before this one in its column. If the item has column c, this is simply c:

```
index = index + c
```

You can extend this technique to work in even higher dimensions. To make calculating indices in the values array easier, you can make a slice_size array that holds the size of the “slice” at each of the dimensions. In the three-dimensional case, these values are <row size> x <column size>, <Column size>, and 1.

To move to higher dimensions, you can find a slice by multiplying the next slice by the size of the current dimension. For example, four dimensional array, the next slice size would be <height size> x <row size> x <column size>.

With all this background, you are ready to see the complete algorithm. Suppose the bounds array alternates lower and upper bounds for the N-dimensional array. The following pseudocode initializes the array:

```
// Initialize LowerBound and Slice.
Integer: slice_size = 1
For i = NumDimensions - 1 To 0 Step -1
SliceSize[i] = slice_size
```

```
LowerBound[i] = bounds[2 * i]
Integer: upper_bound = bounds[2 * i + 1]
Integer: bound_size = upper_bound - LowerBound[i]
slice_size *= bound_size
```

```
// Allocate room for all of the items.
Double: Values[slice_size]
InitializeArray
```

This code calculates the number of dimensions by dividing the values in the bounds array by 2. It creates a LowerBound array to hold the lower bounds and a SliceSize array to hold the sizes of slices at different dimensions.
The next code sets slice_size to 1. This is the size of the slice at the highest dimension

The code loops through the dimensions, starting at the highest and looping toward 0. (This corresponds to looping from column to row to height in the preceding example). It sets the current slice size to slice_size and saves the dimension's lower bound. It multiplies slice_size by the current dimension to get the slice size for the next-smaller dimension.
