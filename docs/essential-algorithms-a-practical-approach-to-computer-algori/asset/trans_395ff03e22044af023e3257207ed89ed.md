*拓扑排序*是将网络上的偏序扩展为全序的过程。

一种扩展偏序的算法非常简单。如果任务可以按有效顺序完成，那么至少有一个没有先置条件的任务可以让你先执行。找到该任务，将其添加到扩展的全序中，并将其从网络中移除。然后重复这些步骤，找到另一个没有先置条件的任务，将其添加到扩展的全序中，并将其从网络中移除，直到所有任务都完成。

如果你到了每个剩余任务都是先置条件的程度，那么任务就存在循环依赖，因此偏序无法扩展为全序。

# 循环检测

循环检测是确定网络是否包含循环的过程。换句话说，它是确定通过网络的路径是否返回起点的过程。

如果你将此问题视为拓扑排序问题，那么循环检测就很简单。网络只有在无法进行拓扑排序时才包含循环。换句话说，如果你将网络视为拓扑排序问题，如果一系列任务 A、B、C、... 形成了一个依赖循环，则网络就包含循环。

在得出这一观察后，检测循环就很容易了。以下伪代码显示了算法：

```
// 如果网络包含循环，返回 True。
Boolean: ContainsCycle()
// 尝试拓扑排序 ordering()
If (ExtendPartialOrdering() == null) Then Return True
Return False
```

该算法假设网络是完全连通的。如果不是，则对每个连通分量重复使用该算法。

# 地图染色

在地图染色中，目标是为地图中的区域染色，使得没有共享边的区域不会具有相同的颜色。显然，如果你给每个区域一个不同的颜色，你就可以这样做。真正的问题是：“为特定地图染色最少需要的颜色种数是多少？”相关问题是：“为任何地图染色最少需要的颜色种数是多少？”

为了用网络算法研究地图染色，你需要将问题从区域染色转换为节点染色。简单地为每个区域创建一个节点，并在共享边界的区域之间建立无向连接。

取决于地图的情况，你可能可以使用两种、三种或四种颜色进行染色。以下章节将介绍这些地图以及你可以使用的算法。

# 二色

某些地图（如图 14-2 所示）可以用两种颜色染色。选取任意区域，给它两种颜色中的一种。然后给它的所有邻居另一种颜色，递归地访问它们，直到你发现某个节点的邻居与该节点颜色相同，此时该地图就无法二色。

以下伪代码显示该算法：

```
// 创建一个已染色的节点队列。
Queue (Of Node): colored

// 为第一个节点染色并将其添加到列表。
Node: first_node = <Any node>
first_node.Color = color1
colored.Enqueue(first_node)

// 遍历网络，为节点染色。
While (colored contains nodes)
    // 从颜色列表中获取节点。
    Node: node = colored.Dequeue()

    // 计算节点的邻居颜色。
    Color: neighbor_color = color1
    If (node.Color == color1) then neighbor_color = color2

    // 为节点的邻居染色。
    For Each link in node.Links
        Node: neighbor = link.Nodes[1]

        // 检查邻居是否已经染色。
        If (neighbor.Color == node.Color) Then
            <该地图无法二色>

            // 邻居已经正确染色。
            // 什么都不做。
        Else
            // 邻居尚未染色。现在给它染色。
            neighbor.Color = neighbor_color
            colored.Enqueue(neighbor)
