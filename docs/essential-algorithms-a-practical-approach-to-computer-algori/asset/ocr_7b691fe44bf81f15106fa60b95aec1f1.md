> Figure 13-12: The shortest paths between all pairs of nodes in a network are represented by a Distance array (top arrays) and a Via array (bottom arrays).

The upper-layer array shows the initial values in a Distance array. The distance from each node to itself is 0. The distance between two nodes connected by a link is set to the link's cost. For example, the link between node A and node B has cost 4, so Distance [A, B] is 4. (To make the example easier to follow, the names of the nodes are used as if they were array indices.) The remaining entries are set to infinity.
