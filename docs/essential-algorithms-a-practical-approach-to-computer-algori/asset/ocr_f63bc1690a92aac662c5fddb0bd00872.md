If the current node is a leaf node and adding one more item would give it too many items, the algorithm splits the node. It creates the four nodes and loops through the items, recursively calling the child nodes’ AddItem methods to move the item into the appropriate subtree. It sets the Items list to null to indicate that this is an internal node.

Next, if the Items property is not null, this is a leaf node, so the algorithm adds the new item to the Items list.

If the Items property is null, this is an internal node. In that case, the algorithm performs a series of If-Then tests to see which subtree should contain the item, and it recursively calls the corresponding’s AddItem method.
