Suppose the algorithm gives nodes the colors red, green, blue, yellow, and orange, in that order. For example, if a node's neighbors are red, green, and orange, the algorithm gives the node the first color—in this case, blue.

Starting at the final network shown in Figure 14-4, the algorithm gives these steps:

+   1. The algorithm restores node J red.
2. The algorithm restores the node that was removed last, node I. Node's neighbor J is red, so the algorithm makes node I.
3. The algorithm restores the node that was removed next-to-last, node E. Node E's neighbors J and I are red, green, so the algorithm makes node E blue.
4. The algorithm restores node F. Node F's neighbors J and E are red and blue, so the algorithm makes node F.
5. The algorithm restores node K. Node K's neighbors J and F are red and green, so the algorithm makes node blue.
6. The algorithm restores node B/H. Node B/H's neighbors K, F, and I are blue, red, and green, so the algorithm makes node B/H.
7. The algorithm restores node L. Node L's neighbors K, B/H, and I are blue, red, and green, so the algorithm makes node L yellow. (At this point the network looks like the bottom network in Figure 14-4, but with the nodes.)
8. The algorithm restores node D. Node D's neighbors B/H, E, and I are red, blue, and green, so the algorithm makes node D yellow.
9. The algorithm restores node A. Node A's neighbors B/H, F, E, and D are red, green, blue, and yellow, so the algorithm makes node A orange.
10. The algorithm restores node G. Node G's neighbors L, B/H, and K are yellow, red, and blue, so the algorithm makes node green. (At this point the network looks like the middle network in Figure 14-4, but with the nodes.)

+   11. Now the algorithm undoes the Rule 2 step. It restores node B and H gives them the same color as node B/H, which is red. Finally, it restores node C. Its neighbors G, H, D, A, and B have colors green, red, yellow, and orange, so the algorithm makes node C blue. (At this point the network looks like the top of Figure 14-4, but with the nodes.)
