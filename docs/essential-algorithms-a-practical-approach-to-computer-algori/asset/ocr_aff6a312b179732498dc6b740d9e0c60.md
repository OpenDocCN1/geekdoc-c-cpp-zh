Here $K_i$ is a subkey for round $i$. This is a series of values generated using the message's key. For example, a simple approach would be to split the key pieces and then use the keys in order, repeating them as necessary. (You can think of a Vigenère cipher as doing this because it uses each letter in the key to encrypt a single message and then repeats the key letters as needed.)

After you have finished the desired number of rounds, the ciphertext is $L_{i+1}$ plus $R_{i+1}$.

To decrypt a message, you split the ciphertext into two halves to get the final values $L_i'$ and $R_i'$. If you look at the preceding steps, you'll see that $R_i$ is $L_{i+1}'$. Therefore, if you already know $L_{i+1}$, you already know $R_i$.

To recover $L_i'$, substitute $L_{i+1}'$ for $R_i$ in the equation used in step 2b to get:

R_i = L_i$ XOR $F(R_i, K_i) = L_i$ XOR $F(L_{i+1}', K_i)$.

At this point you know $L_{i+1}$ so you can calculate $F(L_i', K_i)$. If you combine with $R_i'$ the $F(L_i', K_i)$ terms, leaving only $L_i'$, so you have recovered $L_i'$. The following steps describe the decryption algorithm:

+   1. Split the ciphertext into two halves, $L_{i+1}$ and $R_{i+1}$.
2. Repeat:
   a. Set $R_i' = L_{i+1}'
   b. Set $L_i' = R_{i+1}'$ XOR $F(R_i', K_i)$.

One advantage of Feistel ciphers is that decryption does not require to invert the function $F$. That means you can use any function for $F$, even functions that are not easily invertible.

Another advantage of Feistel ciphers is that the code for encryption and decryption is basically the same. The only real difference is that you use the subkeys in reverse to decrypt the ciphertext. That means you need only one piece of code for encryption and decryption.

> NOTE The Data Encryption Standard (DES), until recently was one of the most commonly used encryption methods, is a Feistel cipher. It is generally no longer secure enough for high-security applications, largely due to its relatively short 56-bit key.

A variation of this method called Triple DES simply applies DES three times to each block. Triple DES is believed to be in practice, although most secure applications now use AES.

For more information on DES, see: http://en.wikipedia.org/wiki/Data_Encryption_Standard.
