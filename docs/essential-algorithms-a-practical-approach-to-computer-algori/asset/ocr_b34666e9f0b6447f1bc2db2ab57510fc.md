This algorithm sorts the items in the original array (aside from a few variables to control loops and move items). so it doesn't need any additional storage. If the array contains N items, the algorithm considers each of the N positions in the array. For each position $i$, it must search the previously sorted items in the array to find the $i$th item's new position. It must then move the items between location and index one to the right. If the item should be moved to position $j$, it takes $j$ steps to find the new location $j$ and $i - j$ steps to move items over, resulting in a total of $i$ steps. That means in total it takes $i$ steps to move item into its new position.

Adding up the steps required to position all items, the total run time is

$1 + 2 + 3 + \dots + N = (N^2 + N) / 2$

This means the algorithm has run time $O(N^2)$. This isn't a very fast run time, but it's fast enough for reasonably small arrays (fewer than 10,000 or so items).
