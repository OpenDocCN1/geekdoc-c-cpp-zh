For each item, this algorithm moves the unsorted items to the temporary stack. Then it moves all the items back to the original stack. At different steps the number of unsorted items that must be moved is N, N-1, N-2, ..., 2, 1, so the total number of items moved is N + (N-1) + (N-2) + ... + 1 = N × (N+1) / 2 = O(N^2). Then the algorithm has a run time of O(N^2).

# StackSelectorsort

In addition to describing a linked-insertion sort, Chapter 3 explains how to implement selectsort with linked lists. The basic idea behind selectsort is to search through the unsorted items to find the smallest item and move it to the end of the sorted output list. Chapter 3 explains how to implement selectsort with linked lists, but you can also implement it with stacks.

As in the insertionsort algorithm, the original stack holds items in two sections. The farthest down in the stack are sorted, and those near the top of the stack are not. Initially, no items are sorted, and all the items are in the “sorted” section of the stack.

The algorithm makes a second temporary stack. For each position in the stack, the algorithm moves all the unsorted items to the temporary stack, keeping track of the last item.

After it has moved all the unsorted items to the temporary stack, the program pushes the item it found onto the original stack. It then moves all the unsorted items from the temporary stack back to the original stack.

The algorithm repeats this process until all the items have been added to the sorted section of the stack.
