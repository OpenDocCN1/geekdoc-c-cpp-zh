14. If the network contains a cycle with a negative total weight, the label-correcting algorithm enters an infinite loop following the cycle and lowering the distances to the nodes it.

This cannot happen to the label-setting algorithm, because each node's distance is exactly once and never changed.

15. After a node is labeled by a label-setting algorithm, its distance is never changed, so you can make the algorithm stop when it has labeled the destination donut shop. If the network is large and the start and destination are close together, this will gladly save time.

16. When a label-correcting algorithm labels a node, that doesn't mean it will not change that distance, so you cannot immediately conclude that the path to node is the shortest, the way you can with a label-setting algorithm.

However, the algorithm cannot improve a distance that is shorter than the distances provided by the links in the candidate list. This means you can periodically check the links in list. If none of them leads to a distance less than the donut shop's distance, the donut shop's shortest path is final.

This change is complicated and slow enough that it probably won't speed up the algorithm unless the network is very large and the start and destination nodes are very close together. You may be better off using a label-setting algorithm.
