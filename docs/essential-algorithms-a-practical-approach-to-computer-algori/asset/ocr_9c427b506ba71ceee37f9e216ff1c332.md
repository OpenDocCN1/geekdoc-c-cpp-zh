# Algorithm Basics

Next i

```
// If we get to this point, there are no duplicates
Return False
EndContainsDuplicates
```

This algorithm contains two nested loops. The outer loop iterates over all the array's N items, it takes O(N) steps.
For each trip through the outer loop, the inner loop also iterates over the N items in the array, it also takes O(N) steps.
Because one loop is nested inside the other, the combined performance is O(N × N) = O(N²).

# Rule 5

Ignore constant multiples. If C is a constant, O(C × f(N)) is the same as O(f(N)), and O(C × N) is the same as O(N).
If you look at the ContainsDuplicates algorithm shown in the preceding, you will see that the inner loop actually performs one or two steps. It performs an If to see if the indices and j are the same. If they differ, it compares array[i] and array[j]. It may also return the value True.
If you ignore the extra step for the Return statement that the algorithm performs both the If statements (as it does most of the time), and you assume that, the inner loop takes O(2 × N) steps. Therefore, the algorithm’s total performance is O(N × 2 × N) = O(2 × N²).
Rule 5 lets you ignore the factor of 2, so the runtime is O(N²).
This rule really goes back to the purpose of Big O. The idea is to get a feeling for the algorithm’s behavior as N increases. In this case, suppose you increase N by a factor of 2.

If you plug the value 2 × N into the equation 2 × N², you get the following:

```
2 × (2 N)² = 2 × 4 × N² = 8 × N²
```

This is 4 times the original value 2 × N², so the runtime has increased by a factor of 4.
Now try the same thing with the runtime simplified by Rule 5 to O(N²).
Plugging 2 × N into this equation gives you the following:

```
(2 × N)² = 4 × N²
```

This is 4 times the original value N², so this also means that the runtime has increased by a factor of 4.
Whether you use the formula 2 × N² or just N², the result is the same: Increasing the size of the problem by a factor of 2 increases the runtime by a factor of 4. The important thing here isn’t the constant; it’s fact that the runtime increases as the square of the number of inputs N.
