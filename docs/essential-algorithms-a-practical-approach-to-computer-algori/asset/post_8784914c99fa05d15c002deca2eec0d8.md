The following steps describe the basic Boyer-Moore algorithm at a high level:

- 1. Align the target and text on the left.
- 2. Repeat until the target's last character is aligned beyond the end of the text:
  a. Compare the characters in the target with the corresponding characters in the text, starting from the end of the text and moving backwards towards the beginning.
  b. If all characters match, you've found a match.
  c. Suppose character x in the text doesn't match the corresponding character in the target. Slide the target to the right until the x aligns with the next character with the same value x in the target to the left of the current position. If no such character x exists to the left of the position, slide the target to the right by its full length.

One of the more time-consuming pieces of this algorithm is Step 2c, which calculates the amount by which the algorithm slides the target to the right.

> NOTE Variations on the Boyer-Moore algorithm use other, more complicated rules for shifting the target string efficiently. For example, suppose the algorithm considers the following

```
what shall we draw today ...
ababracadabra
```

The algorithm scans the target abracadabra backwards. The first two characters, a and r, match. Then the text's d doesn't match the target's b. The previous algorithm would shift the text to align the text like this:

```
what shall we draw today ...
ababracadabra
```

But know that the text matched the following two characters, ra, so you know the text's characters dra cannot match the text's characters dab at this point.

Instead of shifting to align the mismatched d, you can shift the entire suffix that has been matched so far—in this case, ra—to an earlier occurrence of those characters in the target. In other words, you can move the text to place an earlier occurrence of the characters ra where the matched suffix is right now, as in the following.

```
what shall we draw today ...
ababracadabra
```

This lets the algorithm shift the text further, so it can make the search run faster.

For more information on variations on the Boyer-Moore algorithm, see http://en.wikipedia.org/wiki/Boyer-Moore_string_search_algorithm.

The Boyer-Moore algorithm has the unusual property that it tends to be faster when it finds a nonmatching character, it can shift the text further.
