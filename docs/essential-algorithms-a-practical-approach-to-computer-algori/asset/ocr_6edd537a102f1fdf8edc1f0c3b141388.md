Some PRNG algorithms use linear congruential generators with different constants and then select from among the values generated at each step to make the numbers more random and to increase the sequence's repeat period. That can make programs produce random-looking results, but those methods are not truly random.

> NOTE Most programming languages have built-in PRNG methods that you can use instead of writing your own. These methods are generally fast and produce long sequences of numbers before they repeat, so for most programs you can simply use them instead of writing your.

One feature of PRNGs is an advantage that you can use a particular seed to generate the same sequence of "random" values repeatedly. That may also be a disadvantage, because it means that the numbers are more predictable, being able to use the same numbers repeatedly can make some programs much easier to debug.

Being able to repeat sequences of numbers also lets some applications store complex data in a very compact format. For example, suppose a program needs to perform a long and complicated pseudorandom walk on a map. The program could generate and save all its coordinates so that it can redraw the route. Alternatively, it could just save the seed. Then, whenever it needs to draw the route, it can use the seed to reinitialize a PRNG so that produces the same walk each time.
