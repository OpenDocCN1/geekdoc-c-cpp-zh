13. You already know that next_prime x 2 has been crossed out, because it is a multiple of 2. If next_prime x 3, you know that next_prime x 3 has already been crossed out, because 3 has already been considered. For every prime p where p < next_prime, the p has already been considered, so next_prime x p has already been crossed out. The first prime that is not less than next_prime is next_prime, the first multiple of next_prime that has not been considered is next_prime * next_prime. That means you can change the loop to the:

```
// Crossout * multiples of this prime.\nFor i = next_prime * next_prime To max_number Step next_prime Then\nis_composite[i] = true\nNext i
```
