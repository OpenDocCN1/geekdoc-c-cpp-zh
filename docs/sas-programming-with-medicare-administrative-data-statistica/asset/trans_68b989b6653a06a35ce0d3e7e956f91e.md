* STEP 10.14: MERGE CONTINUOUS ENROLLMENT AND DIABETIC EYE EXAM INFORMATION */
data fnl.present_eyedia(keep=bene_id eye_svc state county);

cnd.dia_copd_cond(in=k) bene_id dia_flag=;

if a and dia_flag=1;

# 批量生产执行

如下所示，所有程序都应该在批量模式下执行，以便日志和列表的文件与其主程序相同（当然文件扩展名不同）。此外，对代码进行“生产性”执行是有帮助的，这意味着按顺序运行每个程序而不中断，这样文件上的日期和时间戳就是顺序的。根据你的操作系统，在批量中执行代码可以简单地通过对文件“右键点击”并选择“批量执行”选项来实现。完成后，会自动生成日志和列表文件。读者应仔细检查日志中的错误、警告和未初始化的变量（这可以通过搜索“error”、“warning”和“uninitialized”来轻松完成）。如果读者在 UNIX 环境下操作，他或她可以在 UNIX 中执行脚本来批量执行代码。在执行之前，我建议读者要么删除代码开发和测试过程中创建的数据集，要么在不包含开发和测试过程中创建的数据集的系统分区中工作。强烈建议执行此步，以避免在生产运行中使用开发集（其中可能包含错误信息）。只要你的代码指向一个存在的数据集，SAS 就会输入并使用代码指向的数据集，无论你是否意图这样做。
