## 按医疗人员展示评估和管理服务的医疗保险支付

之前章节创建的汇总分析文件的另一种展示方式是与医疗保险评估就诊相关的费用汇总统计列表。在本示例中，我们在分析中使用包含医疗人员及其关联受益人的文件（在第 5 章中描述为我们的“查找文件”或“归属文件”）。我们在示例研究项目开始时回此文件，并用它指导项目的数据提取过程。现在，我们使用此归属文件来检查研究中医疗人员的费用。

我们使用第 8 章步骤 8.2 中提供的代码测量了医疗保险的总 E&M 费用，输出了一个数据集 `CST_EM.BENE`，其中包含每个受益人的记录，以及一个变量 `EM_TOTCOST_BENE`，它是每个受益人总 E&M 费用的样本。现在，在步骤 10.3 中，我们将 `CST_EM_BENE` 集合与我们的归属文件（称为 `SRC_FINDER_ATTRIB`）合并，以便将 E&M 汇总数据集中的每个受益人“归属”到一个医疗人员。两个数据集已按 `BENE_ID` 排序，因此不需要预合并。我们只保留 `CST_EM_BENE` 集合中的记录（即，我们执行 `if b` 合并，因为这些是我们拥有 E&M 费用信息的受益人）。我们输出一个名为 `PRESENT_EMCOST` 的数据集，包含每个至少一次 E&M 服务连续入保受益人的 E&M 费用信息（`EM_TOTCOST`），以及该受益人相关的医疗人员标识符（`PRPI`）。

```sas
* STEP 10.3: 与医疗人员归属文件合并 E&M 费用信息 */
data  present_emcost(keep=bene_id prfnpi em_totcost_bene);
  merge src_finder_attrib(in=a) cst_em_cost_bene(in=b)
  by bene_id;
  if b then output present_emcost;
```

最后，在步骤 10-4 中，我们使用 `PROC SQL` 汇总 `FNL.PRESENT_EMCOST` 数据集中按医疗人员分组的 E&M 费用信息（`EM_TOTCOST`）。我们将汇总后的费用命名为 `EM_TOTCOST_PRO`。我们将相关的受益人汇总到一个名为 `EM_TOTBENE_PRO` 的变量。我们输出一个名为 `FNL_PRESENT_EMCOST` 的文件。

```sas
* STEP 10.4: 按医疗人员展示 E&M 费用的测量 */
proc sql;
  create table fnl.present_emcost as
    select prfnpi, count(distinct bene_id) as em_totbene_pro,
    sum(em_totcost_bene) as em_totcost_pro
    from present_emcost
    group by prfnpi;
quit;
```
