## Presenting Medicare Payments for Evaluation and Management Services by Provider

Another interesting presentation of the summary analytic files created in previous chapters is a listing of summary statistics related to costs to Medicare for evaluation and management visits. In this example, we use the file that contains providers and their associated beneficiaries (described in Chapter 5 as our “finder file” or “attribution file”) in our analysis. We recall this file at the beginning of our example research programming project, and we used it to guide our project's data extraction process. Now, we use this attribution file to examine costs for the sample of providers in our study.

We measured total E&M costs to Medicare using the code presented in Step 8.2 of Chapter 8, outputting a data set CST_EM. CST_BENE that contains one record for each beneficiary, along with a variable EM_TOTCOST_BENE that is a sample of each beneficiary's total E&M costs. Now, in Step 10.3, we merge the CST_EM_BENE set with our attribution file (called SRC_FINDER_ATTRIB) in order to "attribute" a provider to each beneficiary in the E&M summary data set. Both data sets are already sorted by BENE_ID, so pre-merging is not necessary. We keep only the records in the CST_EM_BENE set (i.e., we perform an "if b" merge because those are the beneficiaries for whom we have E&M cost information. We output a data set called PRESENT_EMCOST that contains the E&M cost information (EM_TOTCOST_BENE) for each continuously enrolled beneficiary with at least one E&M service, as well as the identifier of the provider associated with that beneficiary (PRFNPI).

```sas
* STEP 10.3: MERGE E&M COST INFORMATION WITH PROVIDER ATTRIB FILE /
data  present_emcost(keep=bene_id prfnpi em_totcost_bene);
  merge src_finder_attrib(in=a) cst_em_cost_bene(in=b)
  by bene_id;
  if b then output present_emcost;
```

Finally, in Step 10-4, we use PROC SQL to summarize the E&M cost information (EM_TOTCOST_BENE) contained in the FNL.PRESENT_EMCOST data set by provider (PRFNPI). We call our summarized cost EM_TOTCOST_PRO. We also summarize the relevant beneficiaries into a variable called EM_TOTBENE_PRO. We output a file called FNL_PRESENT_EMCOST.

```sas
* STEP 10.4: PRESENT MEASUREMENT OF E&M COSTS TO MEDICARE BY PROVIDER */
proc sql;
  create table fnl.present_emcost as
    select prfnpi, count(distinct bene_id) as em_totbene_pro,
    sum(em_totcost_bene) as em_totcost_pro
    from present_emcost
    group by prfnpi;
quit;
```
