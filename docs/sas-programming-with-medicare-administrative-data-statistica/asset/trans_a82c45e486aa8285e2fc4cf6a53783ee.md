

# 算法：衡量评估与管理支付

我们在第 7 章中识别了评估与管理（E&M）服务，但我们没有在输出中保留支付变量。此外，我们还在承运公司的理赔记录中搜索了每位受益人在医生诊所环境中单次 E&M 服务的证据。现在，我们想要针对在医生诊所环境中至少接受过一次 E&M 服务的受益人群，识别其 E&M 服务的支付情况。我们编写的代码将非常简单。我们将首先在第 7 章中开发的 E&M 算法中添加支付信息。然后，我们将使用 PROC SQL 汇总金额，并使用 DATA 步骤计算每位受益人的金额。

在步骤 8.1 中

```sas
* STEP 8.1: DEFINE EM CODES */
%let emcodes='99201','99202','99203','99204','99205','99211',
'99212','99213','99214','99215';
data em_cost (keep=bene_id expnsdt; prvnpi; linepmt; hcpcs_cd; em_svc em_cost);
  set util.carr_2010_fnl;
  array hcpcscd(13) hcpcs_cd-hcpcs_cd13;
  array prvpmt(13) linepmt1-linepmt3;
  retain em_svc em_cost;
  em_svc=0;
  em_cost=0;
  do i=1 to 13;
    if substr(hcpcscd(i),1,5) in (&emcodes) then do;
      em_svc=em_svc+1;
      em_cost=em_cost+prvpmt(i);
    end;
  end;
run;
```

# 使用 Medicare 行政数据进行 SAS 编程

在步骤 8.2 中，我们按受益人对步骤 8.1 得到的 E&M 支付和服务进行汇总。具体而言，我们使用 PROC SQL 创建名为 CST.EM_COST_BENE 的数据集，以创建两个汇总变量：EM_TOTCOST_BENE（汇总每位受益人的 E&M 服务总支付金额）和 EM_TOTVC_BENE（汇总每位受益人的 E&M 服务总计数）。这种汇总通过按 Bene ID 对数据分组来实现。注意，在创建这两个变量后，我们将 EM_TOTCOST_BENE 变量格式化为货币金额格式。

```sas
/* STEP 8.2; CALCULATE TOTAL E&M COSTS AND TOTAL E&M SERVICES BY
BENEFICIARY */
proc sql;
    create table cst.em_cost as
    select bene_id, sum(em_cost) as em_totcost_bene format=dollar15.2
    label='TOTAL E&M COST FOR THE BENE',
    sum(em_svc) as em_totsvc_bene label='TOTAL E&M SERVICES FOR';
quit;
```

输出 8.1 显示了步骤 8.2 的结果，为了显示仅打印了前 10 条观测值。

最后，在步骤 8.3 中，我们对 E&M 支付和服务信息进行汇总，但仅针对在医生诊所环境中至少接受过一次 E&M 服务的受益人群，输出名为 CST.EM_COST 的数据集以创建名为 EM_TOTBENE 的唯一受益人，以及名为 EM_TOTCOST 的总支付汇总。此外，我们使用创建的两个变量（EM_TOTBENE 和 EM_TOTCOST）进行计算，以得出至少接受过一次 E&M 服务的受益人群的平均 E&M 支付金额 EM_AVGCOST。我们使用 'where' 子句确保我们的输出考虑了那些在医生诊所环境中接受过一次 E&M 服务的受益人。我们还为创建的变量添加了标签，并将支付和平均支付格式化为货币格式。

```sas
* STEP 8.3: CALCULATE TOTAL AND AVERAGE E&M COSTS FOR ALL BENEFICIARIES WITH LEAST ONE E&M SERVICE */
proc sql;
    create table cst.em_cost_all as
    select count(distinct bene_id) as em_totbene,
    sum(em_totcost_bene) as em_totcost format=dollar15.2 label='TOTAL E&M COST',
    (em_totcost/em_totbene) as em_avgcost format=dollar10.2 label='AVG E&M COST'
    from cst.em_cost_bene
    where em_totbene > 0;
quit;
```

输出 8.2 显示了步骤 8.3 的结果。

虽然步骤 8.1 和步骤 8.2 为我们提供了每位受益人的 E&M 总支付金额，但可以通过不同的方式获得相同的信息。在第 7 章中，我们创建了包含单条记录头部和行信息的理赔文件。可以使用行文件来搜索 E&M 代码并按受益人进行汇总。当然！在步骤 8.4 中，我们只需在承运数据中搜索 E&M 程序代码，然后使用 LINEPMT 变量汇总每行的支付。注意，可以使用代表 E&M 服务的 HCP 代码来限制我们的计算。

```sas
* STEP 8.4: CALCULATE TOTAL E&M COSTS BY BENEFICIARY USING THE CLAIM FILE */
proc sql;
    create table cst.em_cost_bene_line as
    select bene_id, sum(linepmt) as em_totcost_bene format=dollar15.2
    label='TOTAL E&M COST FOR THE BENE'
    from src.carrier_cd2010
    where hcpcs_cd in (&emcodes)
    group by bene_id
    order by bene_id;
quit;
```

# 算法：衡量住院支付

在第 7 章，我们决定将住院理赔数据中的理赔视为住院，并针对短期急性护理医院。为了挖掘级别的汇总统计数据（如平均住院时长 ALOS），我们使用理赔文件头部的支付金额来计算 Medicare 为在急性护理设施或关键医院住院支付的的金额。这是通过对用于计算步骤 8.2 和步骤 8.3 E&M 支付的代码进行微调实现的。

在步骤 8.5 中，我们使用住院理赔数据集中的 PMT_AMT 变量汇总每位受益人的总住院支付，输出一个名为 IP_TOTCOST_BENE 的变量（类似于我们在步骤 8.2 中计算每位受益人总 E&M 支付的方式）。我们输出数据集 CST_IP_COST_BENE。注意，PMT_AMT 变量是 Medicare 付给提供者的金额。

# 第 8 章：衡量成本

有时读者可能会注意到住院理赔中存在负支付。回想我们在步骤 7.5 中的工作从住院数据集中排除了负金额。

```sas
* STEP 8.5: CALCULATE TOTAL INPATIENT COSTS BY BENEFICIARY FOR
BENEFICIARIES AT LEAST ONE INPATIENT CLAIM */
proc sql;
    create table cst_ip_cost_bene_as
    select bene_id, sum(pmt_amt) as ip_tocost_bene format=dollar15.2
    label='TOTAL COST FOR THE BENE'
    from util.ip_2010
    group by bene_id;
quit;
```
