## Algorithms: Measuring Emergency Utilization

As discussed in Chapter 3, the identification of emergency department is an interesting and challenging task. Proper identification of emergency services involved the use of three claims sets: inpatient data, outpatient data, and Part B carrier data. Specifically:

- If a beneficiary is admitted to the hospital following the ED visit, the information pertaining to the ED visit can be found in the inpatient data. These ED services are identified using revenue codes 0450-0459.
- If a beneficiary is seen in an ED but not subsequently admitted to the hospital, the claim for the ED visit can be found in the outpatient data. These claims can be identified using the same revenue codes used for identification of ED visits in the inpatient data (revenue codes 0450-0459).
- The professional component for ED services may be identified in the Part B carrier data. This professional component can be identified using certain procedure values (such as 99281, 99282, 99283, 99284, and 99285).

If we were measuring total ED costs, or counting ED visits, we would identify ED using three claims sets. However, because we are conducting a study of patients, we will focus on identifying the professional component of ED services. In Step 7, we use the file created in Step 1 (UT_CARR_2010_FNL) to identify the professional component of ED services. Our code is similar to the code used in Step 7, creating an array for the 13 HCPCS codes (HCPCS_CD1-HCPCS_CD13) on carrier claims, and a flag representing an ED service (ED SVC). We search for these codes equal 99281, 99282, 99283, 99284, and 99285. These procedure values indicate emergency department services (a procedure code value of 99285 may be considered because it indicates direction by a physician of emergency care systems during the transportation of the patient to the emergency department, but Medicare does not pay it). We output a file called UT_CARR_UTIL.

```
* STEP 7.9 IDENTIFY THE PROFESSIONAL COMPONENT OF ED SERVICES */
data util.carr_util(keep=bene_id ed_svc);
    set util.carr_2010_fnl;
    array hcpsccd(13) hcpsccd_cd1-hcpsccd_cd13;
    ed_svc=0;
    do i=1 to 13;
        if substr(hcpsccd(i),1,5) in('99281','99282','99283','99284','99285') then do
            ed_svc=1;
        end;
run;
```

## Algorithms: Measuring of Ambulance Services

Let's further explore the carrier file by studying the utilization of ambulance services. Checking with a subject matter expert in identifying services using billing codes reveals that we can identify these services using procedure values of A0021, A0080, A0090, A0100, A0110, A0120, A0130, A0140, A0160, A0170, A0180, A0190, A0200, A0210, A0225, A0380, A0382, A0384, A0390, A0392, A0394, A0396, A0398, A0420, A0422, A0424, A0426, A0427, A0428, A0429, A0430, A0431, A0432, A0433, A0434, A0435, A0436, A0800, A0888, and A0999.

Because it is possible for more than one service to appear on a claim, we use a variant of the code developed in Step 7.3 to identify the occurrence of an E&M visit. Specifically, we must change the code to count the total number of occurrences of a relevant code, instead of using a leave statement to end the processing after a single occurrence of a relevant code.

In Step 7.10, we create a macro amcodes that identifies the procedure values we are looking for. Then use the Part B data set created in Step 7.1 (UT_CARR_2010_FNL) to search for the procedure codes by the amcodes variable. We create an array for 13 procedure codes (HCPCS_CD1-HCPCS_CD13) on the carrier claims, as well as a variable called AMB_CARR_SVC to count the number of relevant procedure codes on the claim. Note the absence of a leave statement that ends the processing when a value of the procedure code is found. In place of a leave statement, we include a loop that iterates the value of AMB_CARR_SVC on a record by each time a relevant code (i.e., one of the codes represented by amcodes) is found. We output a file called AMB_UTIL, using only the BENE_ID procedure code, and the AMB_CARR_SVC variables.

```
* STEP 7.10: IDENTIFY AMBULANCE SERVICES IN CARRIER CLAIMS */
* DEFINE AMBULANCE PROCEDURE CODES */
let amcodes="A0021','A0080','A0100','A0190','A0110','A0120','A0130','A0140','A0170','A0180','A0190','A0200','A0210','A0225','A0380','A0382','A0384','A0390','A0392','A0394','A0396','A0398','A0420','A0422','A0424','A0426','A0427','A0428','A0429','A0430','A0431','A0432','A0433','A0435','A0436','A0800','A0888','A0999';

data amb_util(ben_id=hcpscd, amb_carr_svc);
  set utl_carr_2010_fnl;
  array hcpscd(13) hcpscd_cd1-hcpscd_cd13;
  retain amb_carr_svc;
  amb_carr_svc=0;
  do i=1 to 13;
    if substr(hcpscd(i),1,5) in (&amcodes) then do
      amb_carr_svc=amb_carr_svc+1;
    end;
  end;
  if amb_carr_svc=1;
run;
```
