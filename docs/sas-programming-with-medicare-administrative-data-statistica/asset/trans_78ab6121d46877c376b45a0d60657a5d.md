在步骤 71 中，我们统计每个受益人的救护车服务总数。具体而言，我们按受益人累加 AMB_CARR_SVC 的值。此求和结果存储在变量 `TOT_AMB` 中。我们输出一个名为 `UTIL_CNT_SVCS_UTIL` 的永久文件，每个不同的 `BENE_ID` 值只保留一条记录。

```sas
/* STEP 71: 统计每个受益人的救护车数量 */
proc sql;
  create table util.amb_util as
  select distinct bene_id, sum(amb_carr_svc) as tot_amb_svc
  from util
  group by bene_id;
quit;
```

## 算法：衡量门诊就诊信息

```sas
/* STEP 7.12: 计算每个受益人的门诊服务次数 */
proc sql;
  create table util.amb_util as
  select distinct bene_id, sum(amb_carr_svc) as tot_amb_svc
  from util
  group by bene_id;
```
