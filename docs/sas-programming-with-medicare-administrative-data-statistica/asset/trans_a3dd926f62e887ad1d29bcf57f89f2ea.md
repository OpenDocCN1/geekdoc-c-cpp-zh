# 关于我们索赔数据来源和结构的说明

在详细介绍我们将要使用的医疗补助保险行政索赔和注册数据内容之前，让我们通过确定数据来源以及我们假设请求并处理以完成项目的文件结构，来设定讨论的框架。³ 现在引入这一话题是重要的，因为医疗补助保险数据可能来自不同的来源，且每个来源存储数据的方式也不相同。

我们将在第 5 章中详细探讨这一主题，但现在重要的是知道，取决于我们的资金来源和项目的性质，我们可以从至少四个数据源中选择：

- CMS 的数据分发商（有时被称为研究数据分发中心）
- CMS 的数据提取系统 (DESY)
- CMS 的虚拟研究数据中心 (VRDC) 系统
- CMS 的集成数据仓库 (IDR)

出于我们的目的，我们假设将与 CMS 的研究数据协助中心 (ResDAC) 和 CMS 的数据分发商合作请求并获取数据。⁴

医疗补助保险索赔数据由 CMS 数据分发商按索赔类型单独提供。其他系列文件为最终的非机构服务（Part B 承保商和耐用医疗设备）以及机构服务（门诊、住院、护理设施、健康和安宁疗）提供。CMS 进一步将每种索赔类型的数据拆分为单独的文件，分为基础索赔明细和索赔行明细（针对非机构数据文件）或收入中心明细（针对机构数据文件集），从而产生多组文件。⁵

**基础索赔明细**（也称为标题级信息）基本上是汇总信息，包括识别索赔的信息、接受护理的受益人、服务提供者、索赔中计费服务的起始和结束日期、索赔中的诊断结果，以及支付给提供者作为所执行服务报酬的总金额。**索赔行明细**（有时泛指行级信息）是一组关于执行的特定服务的深度信息。例如，某行将包含服务的起始和结束日期、患者的诊断结果（由诊断代码表示）、执行的服务（由程序代码表示）、服务的支付金额以及执行每项服务的提供者标识符。在 SAS 数据集中，一个索赔分布在多个记录中，每项提供的服务对应一条记录。

在第 5 章中，我们将转换这些序列，使其将所有索赔级和行级信息包含在单条记录中。换句话说，我们将处理每个索赔对应多个记录的文件，并在单条记录上构建数组来表示每个行项目。这种操作不是你在自己的研究编程中通常会做的，但正如我们将讨论的，它的优势在于我们可以使用来自这三个源的任一数据创建的数据集结构进行工作。因此，这种“扁平化字段”（the leveling field）的转换使得书的剩余部分对更广泛的读者可见。此外，这种结构恰好是我处理索赔数据的首选方法，因为它提供了在一个记录中查看整个索赔的机会！由于这种转换可能会消耗宝贵的资源，更高级的读者应该自己决定构建其索赔的最有效方法。

# Part B 索赔数据

承保索赔（Carrier claims）包含非机构提供者使用 CMS-1500 索赔表提交的索赔信息。当医疗补助保险受益人去医生处检查时，提供者会使用 ANSI 837 5010 电子格式（或 CMS-1500 纸质表）向医疗补助 Part B 提交账单。CMS-1500 表格详细列出了受益人和提供者标识符、服务日期、执行的操作以及患者的医学诊断。提交的索赔将发送至提供者的医疗补助行政承包商 (MAC) 进行裁决、处理和支付。随后，医疗补助保险索赔的最终结果作为承保索赔数据提供给研究社区。

根据我的经验，用户大多数将这些文件与个人内科专家或心脏病专家联系起来。换句话说，绝大多数用户将承保数据集与医生诊所提供的服务（如检查）的索赔联系起来。然而，承保数据集也包含了你可能不会轻易考虑的提供者提交的索赔，如社工、推骨师、救护车、护理医师和医生助理。此外，文件还包括在医生诊所外执行服务的索赔，如流动手术中心、医院门诊部和医院急诊科。

# 耐用医疗设备 (DME) 数据

该文件包含非机构 DME 提供者使用 CMS-1500 索赔表提交的最终结果索赔信息。⁶ 这些索赔由提供者的医疗补助行政承包商 (MAC) 进行裁决和支付。随后，医疗补助保险索赔的最终结果作为 DME 索赔数据提供给研究社区。耐用医疗设备包括轮椅和助行器、医院床、血糖仪及相关用品、拐杖、拐、夹板、假肢、矫形器、呼吸设备（如氧设备设备用品）以及透析设备和用品。

只要在医学上有必要，DME 就会提供给任何拥有 Part B 保险的受益人。医疗 B 的受益人必须由其“治疗从业者”（例如医生助理或护理医师）开具处方使用的设备。长期设施可以作为受益人的住所，但如果设备在医院或专业护理设施中使用，则不予涵盖。例如，住院设施的医院床已包含住院数据中的设施费用中。

# 门诊索赔数据

门诊索赔数据是关于由机构提供者提交的最终结果索赔的信息。该数据还包括其他类型机构提供者的索赔，如流动手术中心、门诊康复设施、农村健康诊所甚至是社区健康中心。

医疗补助 Part B 支付受益人在医院接受的许多门诊服务，例如医院急诊科服务的费用（正如我们在下文所示，这不包括医生的费用）、缝合或打石膏、实验室和 X 射线服务、门诊手术、为了确定受益人是否应入院接受住院治疗而进行的观察，甚至在受益人无法自行给药时对药物进行给药。这些索赔即为“机构 Part B”（institutional Part B）索赔。展望第 8 章，当我们加总 Part A 费用且未使用住院数据集时，我们将看到这一实际应用。

如果受益人的医生下达了住院医，则该受益人被视为住院。这些服务受医疗补助 Part B 覆盖，并使用门诊预付支付系统 (OPPS) 进行支付。OPPS 向医院支付预定的费率（费率因地区而异）以提供这些服务。

# 住院索赔数据

住院索赔数据包含由长期和短期住院医院提交的最终结果索赔信息，用于报销这些设施费用。这些索赔通过医疗补助 Part A 支付。医院使用 UB-92 表格（也称为 CMS-1450 索赔）或电子 837i 格式对这些服务进行申请。区分设施费用和医院内提供的其他费用是关重要的（再次，这一点请见下文示例）。设施费用包括房费，甚至是受益人住院期间提供的某些药物。正如我们在下文中讨论的，医生的诊治甚至在设施内执行的手术是使用 CMS1500 表计费的，因此位于承保数据中。
