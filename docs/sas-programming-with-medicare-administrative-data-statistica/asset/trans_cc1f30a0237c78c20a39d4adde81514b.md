接下来在步骤 9.9 中，我们展示了通过查找住院理赔记录来识别在之前住院出院 30 天内发生的医院入院的代码¹具体而言，我们使用 PROC SQL 代码创建一个数据集 CND.READ_COPD_COND，该数据集包含受益人标识符 (BENE_ID)、出院日期 (DISCHRGDT) 和入院日期 (ADMSN_DT)，代表在初始住院 30 天后再次入院医院的 COPD 理赔。请注意，我们只从别名为为 "a" 的数据集中选择 BENE_ID，以避免日志中出现变量 BENE_ID 已在输出数据集 CND.READ_COPD_COND 中存在的的警告。

```sas
* STEP 9.9: IDENTIFY READMISSIONS WITHIN 30 DAYS OF ANY DISCHARGE */
proc sql;
    create table cnd.readm_copd_cond as
    select a.*, b.readm
    from copd_ip(keep=bene_id dschrgdt) a, copd_ip(keep=readm) b
    admsn_dt rename=(admsn_dt=bene_id)
    where a.bene_id=b.bene_id
    having ((readm-dschrgdt+1)<=30));
quit;
```

## 章总结

在本章中，我们使用了理赔和注册数据研究慢性病。具体：
- 讨论了研究慢性病的重要性。许多 Medicare 受益人患慢性病；治疗慢性病需要高水平的护理，从衡量结果的角度观察慢性病的治疗。
- 编写了识别糖尿病或 COPD 受益人的算法，通过定义识别这些慢性病的诊断代码（包括“排除”诊断）、搜索这些诊断代码的理赔项目并按理赔类型计算出现次数。
- 编写了识别糖尿病或 COPD 受益人评估与管理服务（E&M）的算法，通过将这些情况的人与我们在第 7 章创建的文件合并。
- 编写了简单的算法识别糖尿病受益人的眼科检查次数，通过搜索 Part B 理赔数据中的视网膜检查代码。
- 编写了简单的算法识别 COPD 受益人在任何住院 30 天内的医院再入院。
