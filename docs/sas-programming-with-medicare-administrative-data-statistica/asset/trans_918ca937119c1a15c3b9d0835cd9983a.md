

```
/* STEP 7.14: IDENTIFY CLAIMS WITH DATE RANGES TO BE COLLAPSED USING
CLAIM_SEGMENT_ID */
data &clmtyp.2010_stay(drop=bene_id2 thru_dt rename=(from_dt=begin_dos
end2=end_dos));
  set &clmtyp.2010_fnl;
  retain end2;
  bene_id=iag1 (bene id);
  if bene_id2=bene_id and from_dt le (end2+1) then do;
    from_dt=end2;
    end2=max(thru_dt,end2);
  end;
  else do;
    claim_segment_id+1;
    end2=thru_dt;
  end;
  format end2_dt mmddyy10.;
run;
```

Step 7.15 根据 CLAIM_SEGMENT_ID 收集在步骤 7.14 中输出的记录。具体而言，对于具有相同 CLAIM_SEGMENT_ID 值的记录，代码会输出一条记录，其中包含的 FROM_DT 值等于该索赔集中最早的 FROM_DT，而 THRU_DT 值等于该索赔集中中最晚的 THRU_DT。如果记录属于情景 #4，代码将为该受益人输出多条记录。最后，代码通过计算每条输出记录中 THRU_DT 与 FROM_DT 之间的差值来计算住院时长（称为 LOS）。输出的分析文件 UTL.SN_2010 STAY 和 UTL.HH_2010 STAY 将保存为永久数据集，以备后之用。

```
/* STEP 7.15: COMBINE CLAIMS WITH OVERLAPPING SEGMENTS */
data util.&clmtyp.2010_stay_fnl(drop=begin_dos end_dos
claim_segment_id);
  retain thru_dt;
  set &clmtyp.2010_stay;
  by bene_id claim_segment_id;
  format from_dt thru_dt mmddyy10;
  if first.claim_segment_id then do;
    from_dt=begin_dos;
  end;
  if last.claim_segment_id then do;
    thru_dt=end_dos;
    los=thru_dt-from_dt;
    output;
  end;
run;
%mend;
%clm_loop2(&clmtyp=sn);
%clm_loop2(&clmtyp=hh);
%clm_loop2(&clmtyp=hs);
```

# 章节总结

在本章中，我们利用索赔和注册数据编写了利用率指标，并输出了包含我们人群利用数据的分析文件。具体而言，我们：

- 通过第 6 章创建的受益人人群，界定了书中剩余部分将要使用的索赔数据。
- 编写了一个算法来衡量医生诊所评估与管理（E&M）服务的利用率，方法是定义用于描述 E&M 就诊的程序代码，并在 Part B 承保人的行级程序代码变量数组中搜索是否存在这些程序代码。
- 编写了一个算法来计算住院时长，讨论了住院数据集中大多数记录如何代表一次住院，学习了如何定义急性短期留，并编写了确定住院时长的算法。
- 编写了一个算法来衡量急诊室（ED）服务的专业部分利用率，方法是定义如何在索赔数据中查找 ED 服务，并学习搜索其中某些服务的程序代码。
- 编写了一个算法来衡量救护车的利用率，方法是定义描述救护车的程序代码，并统计这些代码在特定索赔中的总出现次数。
- 编写了针对门诊访问、专业护理机构（SNFs）、家庭医疗机构和临终关怀服务的利用率指标算法。

通常情况下，虽然受益人去急诊室有很多原因（这可能涵盖广泛的 E&M 代码），但我们关注 HCPCS 手册中定义的 ED 和 E&M 代码。
