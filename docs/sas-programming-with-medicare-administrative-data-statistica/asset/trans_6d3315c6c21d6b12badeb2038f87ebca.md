# 关于慢性病数据仓库 (CCW) 的说明

拥有 Medicare（联邦医疗保险）管理数据的读者可能试图调和两个事实：

- 我们正在编写算法，利用理赔数据识别患有两种慢性疾病（糖尿病和慢性阻塞性肺疾病 COPD）的受益人。
- CMS 通过慢性病数据仓库 (CCW) 向研究社区提供包含此类信息的文件。CCW “是一个研究数据库，旨在使 Medicare、评估和 Part D 药物事件数据更易于获取，以支持旨在提高护理质量并降低成本和利用率的研究。”这些数据可以通过 ResData 和 CMS 的数据分发承包商获得。

经过某些简化，我们将利用 CCW 对糖尿病和 COPD 的定义，编写识别我们受益人群中糖尿病和 COPD 的代码。既然 CMS 已经提供了对慢性病受益人的标记，为什么我们还要自己编写这些代码呢？编码慢性疾病具有工具性目的，可以为理解 CCW 中未提供的可能修正的慢性疾病提供背景。此外，一些研究人员选择自己定义疾病是因为他们希望修改 CCW 中的定义。例如，CCW 对糖尿病的定义包含了继发性糖尿病，这对于你的特定研究可能不是正确的选择。不而喻，鼓励读者充分利用 CCW 提供的数据。

# 算法：识别患有糖尿病或 COPD 的受益人

我们的首要任务是识别人群中患有糖尿病或 COPD 的受益人。尽管可能会有些重复，但在开始之前，非常重要的一点是：我们使用的诊断代码会随年份而变化。我们在书中使用的所有代码也是如此。例如，手术代码和诊断代码每年更新一次（创建新代码并废弃某些旧代码）。因此，定期检查您用于识别诊断或服务（或者说，任何内容）的代码是一个良好的习惯，以确保它们是正确的。这在 2014 年 10 月之后尤为如此，因为随着新的诊断编码系统 ICD-10-CM 的实施，所有代码将发生变化。

识别糖尿病受益人的算法改编自 CCW 提供的说明，并经过了一些简化（例如，我们识别糖尿病时不需要跨越两年的数据）。我们的 SAS 代码涉及搜索特定的诊断代码（特定诊断代码列表请参阅下文算法）。代码可能出现在理赔单的任何位置（即它们不必非是主诊断）。这些诊断代码出现的设置至关重要。

# 第 9 章：识别慢性疾病的编程

具体而言，如果我们发现证据表明某位受益人在住院或熟练护理机构环境中仅有一次被确诊为糖尿病，我们将将其计为患有糖尿病。在这些环境中，真正的编码专家会审阅病历、咨询医生，并且仅在患者确实患有该疾病时才记录诊断。然而，在搜索保险公司理赔和医院住院理赔单时，我们需要独立的糖尿病诊断事件。为什么呢？因为在这些环境中，单次糖尿病诊断出现可能被称为“排除性”（rule out）诊断，即医生安排实验室检查以检查糖尿病。第二次诊断确认受益人确实患有糖尿病。在所有情况下，诊断都可以发生在两年期内的任何时候（但在我们的示例中，我们将搜索一年的数据）。最后，我们要指出，在识别糖尿病或 COPD 受益人时，我们使用的是家庭健康理赔数据，而不是临终关怀（hospice）或医疗设备（DME）数据。尽管研究人员认为查看家庭健康理赔单上的诊断代码是不智的，我们仍然使用了家庭健康数据。由于临终关怀环境提供的护理性质，我们不使用临终理赔单。最后，由于明显原因，DME 文件无法可靠地识别患有糖尿病或 COPD 的受益人。

识别 COPD 受益人的算法构建方式与糖尿病类似（同样改编自 CCW 提供的信息），但使用了不同的诊断代码（且搜索通常发生在一年的理赔数据上）。因此，我们将使用单一算法搜索住院、SNF（熟练护理机构）、门诊和 Part B 保险公司的这些诊断代码证据，并在适当的地方设置标记。然后，我们将统计生成的标记，并使用这些计数来识别患有糖尿病或 COPD 的受益人。

在步骤 9.1 中，我们展示了一种算法，用于识别住院、SNF、家庭健康和门诊理赔数据集中用于识别糖尿病或 COPD 的诊断代码。该算法与之前章节中用于识别数据中诊断代码的代码相似。我们使用一个名为 `CLM LOOP` 的宏和数组逻辑，在每份理赔单存在糖尿病（`DIA_IA`、`DIA_SN`、`DIA_OP` 和 `DIA_HH`）和 COPD（`COPD_IP`、`COPD_SN`、`COPD_OP` 和 `COPD_HH`）时创建设置为 1 的独立标记。这些数据集每个包含 25 个诊断变量（`ICD_1_DGNS_CD25`）。此外，我们首先对住院数据集进行条件处理，因为我们只搜索 `PMT_AMT` 为非负值的住院短期和关键准入医院的理赔单。我们使用 `%if` 子句在 `UTIL_IP_2010_FNL` 中创建住院患者。我们只输出标记变量等于 1 的记录。在步骤 9.3 和步骤 9.4 中，我们将使用这些记录作为受益人患有糖尿病或 COPD 的确定证明（来自住院数据集的标记除外）。

```sas
* STEP 9.1: SEARCH INPATIENT, SNF, HOME HEALTH, AND OUTPATIENT CLAIMS
FOR DIABETES AND COPD DIAGNOS
* NOTE THIS MACRO WILL NOT ERROR IF CLMTYP IS NOT CREATE */
%macro clm_loop(&clmtyp);
data cc_&clmtyp._search(keep=bene_id dia_&clmtyp copd_&clmtyp);
  if &clmtyp=sn or &clmtyp=op or &clmtyp=hh then do
    set utl_&clmtyp_2010_fnl;
  else if &clmtyp=ip then do
    set utl_ip_2010_fnl;
  end;
  array dgnsc(25) icd_dgns_cd1-icd_dgns_cd25;
  do i=1 to 25;
    /* diabetes */
    if substn(dgnsc(i),1,4)='3572'
    or substn(dgnsc(i),1,5)
    in('24900','24901','24910','24911','24920','24921','24930','24931',
    '24940','24950','24951','24960','24961','24970','24971',
    '24980','24990','24991',
    '25000','25001','25002','25003','25010','25011','25012',
    '25020','25021','25022','25023',
    '25030','25031','25032','25033','25040','25041','25042','25043',
    '25050','25051','25052','25053',
    '25060','25061','25062','25063','25070','25071','25072','25073',
    '25080','25081','25082','25083',
    '25090','25091','25092','25093','36201','36202','36641') then dia_&clmtyp=1;
    /* copd */
    if substn(dgnsc(i),1,3)='496'
    or substn(dgnsc(i),1,4)
    in('4910','4911','4918','4919','4920','4928','4940','4941') then copd_&clmtyp=1;
    or substn(dgnsc(i),1,5) in('49120','49121','49122') then copd_&clmtyp=1;
  end;
  if dia_&clmtyp= drop dia_&clmtyp=-1;
run;
%mend clm_loop;
%clm_loop(clmtyp=ip);
%clm_loop(clmtyp=sn);
%clm_loop(clmtyp=op);
%clm_loop(clmtyp=hh);
```

在步骤 9.2 中，我们继续识别用于识别糖尿病或 COPD 的诊断代码的过程，这次使用我们的保险公司数据集。同样，我们搜索每份理赔单以寻找存在糖尿病或 COPD 代码的诊断代码，如果在保险公司的 13 个行级诊断代码（LINE_IC_DGNS_1-LINE_IC_DGNS_CD13）中，我们将相关标记（`DIA_CARR`、`COPD_CARR` 或两者）设置为 1。我们只输出标记变量等于 1 的记录。在步骤 9.3 和 9.4 中，我们将使用这些记录证明受益人患有糖尿病或 COPD。

```sas

data cc_carr_search(keep=bene_id dia_carr copd_carr);
  set udln_2010_fnl;
  array indgns(13) line_ic_dgns_1-line_ic_dgns_cd13;
  do i=1 to 13;
    /* diabetes */
    if substr(indgns(i),1,4)='3572'
    or substr(indgns(i),1,5)
    in('24900','24901','24910','24911','24920','24921','24930','24931',
    '24940','24950','24951','24960','24961','24970','24971',
    '24980','24990','24991',
    '25000','25001','25002','25003','25010','25011','25012',
    '25020','25021','25022','25023',
    '25030','25031','25032','25033','25040','25041','25042','25043',
    '25050','25051','25052','25053',
    '25060','25061','25062','25063','25070','25071','25072','25073',
    '25080','25081','25082','25083',
    '25090','25091','25092','25093','36201','36202','36641') then dia_carr=1;
    /* copd */
    if substr(indgns(i),1,3)='496'
    or substr(indgns(i),1,4)
    in('4910','4911','4918','4919','4920','4928','4940','4941') then copd_carr=1;
    or substr(indgns(i),1,5) in('49120','49121','49122') then copd_carr=1;

  if dia_carr=1 or copd_carr=1;

```
