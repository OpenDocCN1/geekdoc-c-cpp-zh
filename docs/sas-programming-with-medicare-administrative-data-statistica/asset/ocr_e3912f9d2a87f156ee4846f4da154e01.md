The information presented in this chapter is derived from resources like the Medicare coverage publications available at www.medicare.gov (see, for example, http://www.medicare.gov/publications/pubs/pdf/10153.pdf). These manuals are wonderful sources of information. It also draws on information available at www.ccwdata.org, www.resdac.org, and www.medpac.gov.

We will not write SAS code in this chapter because we want to stay focused on learning about the Medicare program and Medicare data. In Chapter 7, we will construct SAS code for identifying emergency department services. Writing SAS code for identifying services can be further advanced, and is outside the scope of this chapter.

The discussion of acquisition of source data is for illustrative purposes. The data we use in this book are fake, and subject to the disclaimer provided in Chapter 1. In other words, we pretend to go through the process of requesting data from CMS, and we did not actually produce the data used in this book through process.

Although we are pretending we are receiving data from CMS's data distribution contractor, we are actually using CMS's Data Entrepreneurs' Synthetic Public Use File (DE-SynPUF), which is available in the public domain. Please see the disclaimer in Chapter 1 for more information.

Data from DESY are not received in this fashion, however we utilize the output of a query of the IDR.

See CMS's booklet called You are a Hospital Patient or Outpatient, available at http://www.medicare.gov/Pubs/pdf/11435.pdf, for more information on Medicare's outpatient benefits.

It is important to note that the MedPAR file also provides information related to inpatient and (SNF) claims. This file is summarized at the state level and may provide the right level of detail for many research exercises.

See CMS's booklet called Medicare Coverage of Skilled Nursing Facility Care, available at http://www.medicare.gov/Pubs/pdf/10153.pdf, for a more comprehensive treatment of the information provided in this section.
