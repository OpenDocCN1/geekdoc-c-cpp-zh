# Production Execution in Batch

As stated below, all programs should be executed in batch mode so that the logs and lists have the same name as their parent program (a different file extension, of course). In addition, it is helpful to undertake a "production" execution of the code entails running each program in sequence without breaks so that the date and time stamps on the files are sequential. Depending on your operating system, executing code in batch can be as simple as "right clicking" on the file to execute and selecting the option to execute in batch. Upon completion, log and list files are generated automatically. The reader should carefully review the logs for errors, warnings, and uninitialized variables (this can be accomplished quite easily by performing a find on "error," "warning," and "uninitialized."). If the reader is operating in a UNIX environment, he or she can execute a script in UNIX to execute the code in batch. Prior to execution I recommend that the reader either delete data sets created during code development and testing process, or work in a partition of the system that does not contain data sets created during the development and testing process. This step is strongly recommended to avoid a development set (that may contain incorrect information) in your production run. As long as your code is pointing to an existing data set, SAS will input and use the set that the code points regardless of whether or not intend for it to do so.

# Data Destruction

Most UAS require the destruction of all Personally Identifiable Information (PII) data and additional materials derived from PII data, even if those materials do not contain PII data themselves. Therefore, the first step in destroying the data is to become clear on exactly what data must be destroyed. The must destroy all files containing PII. For our example programming project, we will destroy all SAS data sets. The reader should check the details of his or her Dua. Common methods of destruction include shredding CDs or DVDs, erasure via degaussing of magnetic storage such as hard drives, and deleting data from hard drives, followed by overwriting the deleted files many times to ensure they cannot be recovered.
