Now that we have summarized payments by claim, we can summarize beneficiaries’ total payments for all Medicare Part A services performed the year. To complete this task, we must sum all of the payment amounts calculated in Step 8.7. Step 8.8 utilizes the output of Step 8.7, concatenating each data set from the macro used in Step 8.7. The concatenation is performed by BENE_ID so that the data is sorted by beneficiary. Next, we leverage the concatenation by beneficiary by "group" processing. Simply, for each beneficiary identifier (BENE_ID), we set the total Part A payment variable (PA_TOTCOST_BENE) equal to 0. Then, we add the payment summary for each beneficiary created in Step 8.7 (the variable TOTCOST_BENE) to the PA_TOTCOST_BENE variable. In this way, the PA_TOTCOST_BENE variable becomes the summary of each beneficiary’s Part A payments.
