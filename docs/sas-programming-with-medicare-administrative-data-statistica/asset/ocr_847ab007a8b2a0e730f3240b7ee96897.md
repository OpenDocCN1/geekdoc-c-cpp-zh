# 134 SAS Programming with Medicare Administrative Data

In Step 10.11, we add beneficiary state and county information to our data set of total Part A costs to Medicare. This data set containing summary information on costs, called CST_PA_TOTCOST_BENE, was created in Chapter 8. Our merge to add state and county information to this data set looks the same as the merge in Step 10.8, except that we retain all in the ENR_CONTENT_2010_FNL data set, we perform an "if" merge. In addition, we add a line of code to set the value of the variable matching to Medicare (PA_TOTCOST_BENE) equal to 0 for beneficiaries without a benefit in the ENR_CONTENT_2010 FNL data set because it is possible (though unlikely) to have an enrollment without any corresponding claims. The output of this merge, a data set FNL_PRESENT_PACOST, contains for each continuously enrolled beneficiary, along with each beneficiary's total Part A cost summary information, and information on the beneficiary's state and county.

```
* MERGE TOTAL PART A COST WITH BENEFICIARY SSA STATE AND COUNTY INFORMATION */
data fnl_present_pacost(keep=bene_id pa_totcost_bene state county);
  merge enr.conter_2010_fnl(in=a) cst.pa_totcost_bene(in=b);
  by bene_id;
  if a;
    if and not b then pa_totcost_bene=0;
```

In Step 10.12, sort the output of Step 10.11 BY STATE AND COUNTY in preparation for displaying Part A costs to Medicare BY STATE AND COUNTY in the PROC MEANS in the next step.

```
* STEP 10.12: SORT DATA BY SSA STATE AND COUNTY IN PREPARATION FOR PRESENTATION OF COST BY SSA STATE AND COUNTY */
proc sort data=fnl.present_pacost;
  by state county;
```

Finally, in Step 10.13, we perform a PROC MEANS ON our summaries of total Part A costs to Medicare in order to present mean payments per beneficiary by state and county name. In the prior example, we used ODS to output the results to the same folder where our permanent data is stored for work in this chapter, and we limit the output to those beneficiaries who reside in a single county in Michigan. We also ask for the minimum and maximum values for each state and county combination.

```
* STEP 10.13: PRESENT TOTAL PART A COST BY BENEFICIARY SSA STATE AND COUNTY */
ods html file="C:\Users\Gillingham\Desktop\SAS
Book\FINALDATAVOD_OUTPUT\Gillingham_fig10.html"
image_dpi=300 type=GrayscalePrinter;
ods graphics on / imagefmt=png;
title="PROC MEANS OF TOTAL PART A COST TO MEDICARE BY SSA STATE AND COUNTY";
proc means data=fnl.present_pacost(where=(state='MI' and
county='WASHTENAW'))
```
