In Step 71 we count the total number of ambulance services per beneficiary. Specifically, we sum the values of AMB_CARR_SVC by beneficiary. Output of this summation is stored in a variable called TOT_AMB. We output a permanent file called UTIL_CNT_SVCS_AMB_UTIL, keeping only one record per distinct value of BENE_ID

```
* STEP 71: COUNT AMBULANCE SERVICES PER BENEFICIARY */
proc sql;
  create table util.amb_util as
  select distinct(bene_id), sum(amb_carr_svc) as tot_amb_svc
  from util
  group by bene_id;
quit;
```
