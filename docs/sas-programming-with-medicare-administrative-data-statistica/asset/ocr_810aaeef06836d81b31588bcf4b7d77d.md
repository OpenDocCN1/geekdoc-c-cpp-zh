Because it is possible for more than one service to appear on a claim, we use a variant of the code developed in Step 7.3 to identify the occurrence of an E&M visit. Specifically, we must change the code to count the total number of occurrences of a relevant procedure code, instead of using a leave statement to end the processing after a single occurrence of a relevant procedure code.

In Step 7.10, we create a macro variable amcodes that identifies the procedure code values we are looking for. Then use the Part B carrier data set created in Step 7.1 (UTL_CARR_2010_FNL) to search for the procedure codes by the amcodes variable. We create an array for 13 procedure codes (HCPCS, CD1-HCPCS, CD13) on the carrier claims, as well as a variable called AMB_CARR_SVC to count the total number of relevant procedure codes on the claim. Note the absence of a leave statement that ends the processing when a value of the procedure code is found. In place of the leave statement, we include a loop that iterates the value of AMB_CARR_SVC on a record by each time a relevant procedure code (i.e., one of the codes represented by amcodes) is found. We output a file called AMB_UTIL, using only the BEN_ID procedure code, and the AMB_CARR_SVC variables.

* STEP 7.10: IDENTIFY AMBULANCE SERVICES IN CARRIER CLAIMS */
* DEFINE AMBULANCE PROCEDURE CODES */
let amcodes="A0021', 'A0080', 'A0100', 'A0190', 'A0110',
A0120', 'A0130', 'A0140', 'A0170', 'A0180', 'A0190', 'A0200', 'A0210',
A0225', 'A0380', 'A0382', 'A0384', 'A0390', 'A0392', 'A0394', 'A0396', 'A0398',
A0420', 'A0422', 'A0424', 'A0426', 'A0427', 'A0428', 'A0429', 'A0430',
A0431', 'A0432', 'A0433', 'A0435', 'A0436', 'A0800', 'A0888', 'A0999';

data amb_util(ben_id=hcpscd, amb_carr_svc);
  set utl_carr_2010_fnl;
  array hcpscd(13) hcpscd_cd1-hcpscd_cd13;
  retain amb_carr_svc;
  amb_carr_svc=0;
  do i=1 to 13;
    if substr(hcpscd(i),1,5) in (&amcodes) then do
      amb_carr_svc=amb_carr_svc+1;
    end;
  end;
  if amb_carr_svc=1;
run;
