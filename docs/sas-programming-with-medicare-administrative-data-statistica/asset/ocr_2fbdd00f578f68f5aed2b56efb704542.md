# Age Groups

Next, let's define and group the age category to which a beneficiary belongs. Suppose for illustrative purposes we wish to calculate each beneficiary's age as the beginning of the reference year (in our case, January 1, 2010). In Step 6.5, we use ENR.CONTENTR_2010_FNL data to calculate this variable and call it STUDY_AGE. Suppose further that we wish to create a variable that describes a beneficiary's inclusion in one of four age groups: 65, 65-74, 75-84, 85-95 and older. Also in Step 6.5, we create a variable AGE_CATS that groups beneficiaries by their value of STUDY_AGE. Note that we use PROC FORMAT to create a format AGE_CATS_FMT that we apply to the display of AGE_CATS below.

```
* STEP 6.5: CREATE VARIABLE STUDY_AGE CATEGAS AS OF
01.01.2010 /*
* STEP 6.5 (CONT): CREATE VARIABLE AGE_CATS THAT GROUPS STUDY_AGE INTO
AGE CATEGORIES */
proc format;
value age_cats_fmt
0='AGE LESS THAN 65'
1='AGE BETWEEN 65 AND 74, INCLUSIVE'
2='AGE BETWEEN 75 AND 84, INCLUSIVE'
3='AGE BETWEEN 85 AND 94, INCLUSIVE'
4='AGE GREATER THAN OR EQUAL TO 95';
run;

data enr.contentr_2010_fnl;
set enr.contentr_age_cats_fmt;
study_age=floor((intk('month', bene_dob, '01jan2010'd) - day(bene_dob)) / 12);
select;
when (study_age<65) age_cats=0;
when (65<=study_age<=74) age_cats=1;
when (75<=study_age<=84) age_cats=2;
when (85<=study_age<=94) age_cats=3;
when (study_age>=95) age_cats=4;
end;
label age_cats='Beneficiary age category at beginning of reference
year (January 1, 2010)';
run;
```

Finally, in Step 6.6, Output 6.4 shows the results of Step 6.5 (still using the file
ENR.CONTENTR_2010_FNL) using a cross-tabulation of STUDY_AGE (the variable we calculated
as January 1, 2010), and AGE_CATS (the groupings of STUDY_AGE). The output of this frequency
 be used to check that our calculations of STUDY_AGE and AGE_CATS were performed
correctly. Note that we limited our input data to retain only those beneficiaries 65 through 70,
inclusive for display purposes below. You can remove the 'where' clause and perform a frequency
distribution for all values of STUDY_AGE at your discretion.
