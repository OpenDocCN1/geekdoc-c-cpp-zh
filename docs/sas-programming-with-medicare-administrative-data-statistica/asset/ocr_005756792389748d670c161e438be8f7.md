# Algorithms: Create Final Enrollment Data for Remainder of Programming

The last step in our programming with FBS data is to create a final file that we will carry forward and use the remainder of our programming. In Step 6.12, we merely need to carry the file for ENR.CONTER_2010 FNL through the remainder of our processing. Since we will be doing much of our work at the beneficiary level, the last programming step in this chapter is to sort the ENR.CONTER_2010_FNL data set by the beneficiary identifier BENE_ID.

```
* STEP 6.12: CREATE FINAL ENROLLMENT FILE */
proc sort data=enr.contenr_2010_fnl;
  by bene_id;

run;
```
