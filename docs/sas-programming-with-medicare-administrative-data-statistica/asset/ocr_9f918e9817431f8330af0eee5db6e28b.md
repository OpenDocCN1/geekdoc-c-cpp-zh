To this end, we merge the CND.DIA COPD_COND data set with the same ENR.CONTENTR_2010 FNL data set used above, keeping all records in the ENR.CONTENTR_2010 FNL data set to create the data set FNL.PRESENT_DIACOPD. The values of the variables identifying beneficiaries with diabetes or COPD in the set CND.DIA_COPD_COND are set to zero for beneficiaries in ENR.CONTENTR_2010 FNL who are not in CND.DIA_COPD_COND (indicating that these beneficiaries were not having diabetes or COPD).

```
* STEP 10.5: MERGE CONTINUOUS ENROLLED BENEFICIARIES WITH POPULATION OF DIABETES AND BENGES WITH COPD */
data fnl.present_diacopd(keep=bene_id dia_flag copd_flag);
  merge enr.contentr_2010_fnl(in=a) cnd.dia_copd_cond(in=b);
  by bene_id;
  if a;
    if dia_flag=. then dia_flag=0; if copd_flag=. then copd_flag=0;
;
```

In Step 10.6, we present a simple frequency distribution of beneficiaries with diabetes or COPD (or both diabetes and COPD) of the data set FNL.PRESENT_DIACOPD that we created in Step 10.5. We perform frequency distribution on the variable that identifies beneficiaries with diabetes (DIA_FLAG) and the variable that identifies beneficiaries with COPD (COPD_FLAG). In addition, we perform a cross-tabulation of these variables. As in previous examples in this chapter, we use ODS to output the PROC FREQ results to the same folder where our permanent data is stored for our work in this chapter.

```
* 10.6: PRESENT RATES OF DIABETES, COPD, AND BOTH DIABETES AND COPD */
ods html="C:\Users\mgilling\Desktop\SASBook\FINAL_DATA\OUTPUT\mgilling_fig10_6.html"
```
