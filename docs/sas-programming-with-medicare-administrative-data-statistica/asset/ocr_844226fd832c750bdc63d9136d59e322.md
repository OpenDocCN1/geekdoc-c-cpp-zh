# 60 SAS Programming with Medicare Administrative Data

SEX and RACE variables using frequency distributions. Note that we use PROC FORMAT so the definitions of the variables of SEX and RACE are displayed in our output. We use SAS' Output Delivery System to create our output.

```
* STEP 6.4: INITIAL INVESTIGATION OF SEX AND RACE IN THE 2010 DATA * /
proc format;
  value $sex_cats_fmt
    '0'='UNKNOWN'
    '1'='MALE'
    '2'='FEMALE';

run;
ods html file="C:\Users\mgillingham\Desktop\SAS Book\FINAL_DATA_ODS_OUTPUT\mgillingham_fig6_4_RACE.html"
image_dpi=300 style=GrayscalePrinter;
ods graphics on /
title "FREQUENCY OF SEX IN 2010 DATA";
proc freq data=enr.contr_2010_fnl;
  tables sex / missing;
  format sex $sex_cats_fmt.;

run;
ods html close;

proc format;
  value $race_cats_fmt
    '0'='UNKNOWN'
    '1'='WHITE'
    '2'='BLACK'
    '3'='OTHER'
    '4'='ASIAN'
    '5'='HISPANIC'
    '6'='NORTH AMERICAN NATIVE';

run;
ods html file="C:\Users\mgillingham\Desktop\SAS Book\FINAL_DATA_ODS_OUTPUT\mgillingham_fig6_4_RACE.html"
image_dpi=300 style=GrayscalePrinter;
ods graphics on /
title "FREQUENCY OF RACE IN 2010 DATA";
proc freq data=enr.contr_2010_fnl;
  tables race / missing;
  format race $race_cats_fmt.;

run;
ods html close;
```
