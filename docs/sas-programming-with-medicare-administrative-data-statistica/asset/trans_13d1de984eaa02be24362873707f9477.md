```sas
/* STEP 8.6: CALCULATE TOTAL AND AVERAGE INPATIENT COSTS FOR ALL
BENEFICIARIES WITH AT LEAST ONE INPATIENT CLAIM */
proc sql;
    create table cst_ip_cost_all as
    select count(distinct bene_id) as ip_totbene,
    sum(ip_totcost_bene) as ip_tocost=Dollar15.2 label='TOTAL IP COST',
    (calculated ip_tocost/calculated ip_totbene) as ip_avgcost
    format=dollar10.2 label='AVERAGE BENE IP COST'
    from cst.ip_cost_bene;
quit;
```

## ## 算法：衡量 Part A 支付款额

在上述工作中，我们衡量了特定服务（如 E&M）或特定环境（如医生诊所或急性入住医院）的费用。我们必须继续这项工作，使用 `PMT_AMT` 变量来汇总 Medicare Part A 的总支付。为此，我们将分别汇总住院、专业护理机构（SNF）、家庭健康和临终关怀数据集中的总费用，然后对一个整体进行汇总。我们没有包含门诊数据集，尽管门诊数据集包含在住院设置环境中进行的服务，但这些理赔是通过 Medicare Part B 支付的。考虑到我们正在使用每个数据集中存在的相同 `PMT_AMT` 变量来汇总支付款，我们可以利用宏循环以标准化的方式执行这些支付汇总。

首先，在步骤 8.7 中，我们利用宏来计算受益人支付的 Medicare 总额，为每种理赔类型输出一个单独的文件。我们的宏 `CLM_LOOP` 让人想起第 7 章（步骤 7.1）中使用的宏，该宏通过注册数据中的受益人来划分每种理赔类型的数据，但我们编写的代码是根据条件处理住院数据。具体而言，我们的 `CLM_LOOP` 宏包含一个 `PROC SQL` 语句，它看起来应该非常熟悉；它是我们在本章中定义其他支付汇总时使用的相同代码。

# 第 8 章：衡量 Medicare 成本 101

然而，存在一个主要区别：我们必须弄清楚如何处理命名与 SNF、某些健康和临终关怀文件不同的住院理赔，这种处理在宏中需要特殊编码。事实上，我们正在使用的住院文件已经过处理，排除了支付金额。该文件的命名没有遵循我们在宏中处理的其它部分部分（Part A）文件的相同模式。为了在宏中包含对住院文件的处理，我们在宏内部使用 `%if` 逻辑来识别正在处理的数据类型。除此之外，该代码使用了第 7 章中创建的数据（通过我们的注册数据划分，在住院理赔的情况下，通过医院类型和支付金额价值划分），并为每种理赔输出单独的文件，包含受益人标识符（`BENE_ID`）和与受益人相关的总费用（`TOTCOST_BENE`）。到此时，我们已经为每种 Part A 理赔类型创建了支付汇总。

```sas
/* STEP 8.7: CALCULATE TOTAL BENEFICIARY INSTITUTIONAL COSTS USING MACRO LOOP */
%macro clm_loop(clmtype=);
  create table totcost_clmtyp as
  select distinct (bene_id), sum(pmt_amt) as totcost_bene
  if %clmtype=sn or %clmtype=hh or %clmtype=hs then do
    from utl.part_cost_bene
  else if %clmtype=ip then do
    from utl.ip_cost_bene
  end;
  group by bene_id;
  quit;
%mend clm_loop;

%clm_loop(clmtype=ip);
%clm_loop(clmtype=sn);
%clm_loop(clmtype_hh);
%clm_loop(clmtype=hs);
```

对于至少有一次住院理赔的所有受益人的 Medicare Part A 总支付款额，我们现在通过这种方式，分别处理住院、专业护理机构、家庭健康和临终关怀数据集中的总支付。由于我们在处理住院理赔时 `%if` 逻辑来识别正在处理的数据类型。除此之外，该代码使用了第 7 章中创建的数据（通过我们的注册数据划分，在住院理赔的情况下，通过医院类型和支付金额价值划分）。

为了完成这项任务，我们需要按受益人汇总 Medicare Part A 支付款额。现在，我们利用步骤 8.7 的输出支付汇总。

```sas
/* STEP 8.8: CALCULATE TOTAL PART A PAYMENTS FOR ALL BENEFICIARIES */
data cst.part_cost_all(keep=bene_id total_parta_cost);
  set totcost_clmtyp;
  by bene_id;
  if first.bene_id then total_parta_cost = 0;
  total_parta_cost + totcost_bene;
  if last.bene_id then output;
run;
```
