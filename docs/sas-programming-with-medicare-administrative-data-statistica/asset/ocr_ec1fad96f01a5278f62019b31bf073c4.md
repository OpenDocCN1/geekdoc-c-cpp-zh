In, Step 7.3, we search the claims data set (the "physician office setting" part of criteria) UTL_CARR_2010 FNL for the procedure codes contained in our macro variables. The carrier claims has 13 line items, so our data set has 13 procedure codes to search on per-claim (or per-record). We perform this search by creating an array HPCSCD that represents the procedure code variables (HPCS_CD1-HPCS_CD13). Then, we create a flag called EM_SVC that is set to a value of 1 if one of the procedure code variables in the array is in the set of procedure codes defined by the macro variables. If such evidence is found, the leave statement ends the processing, and the next record is searched (in other words, we not counting all E&M services that could be on the claim, but searching for evidence of a single E&M service). The output (EM_UTIL) contains the claims in the carrier data set, with a reduced set of variables that define the beneficiary, dates of service, provider, and flag indicating an E&M service was discovered. This output file contains only records where EM_SVC is equal to 1.

```
* STEP 7.3: PULL RECORDS FROM CARRIER FILE BASED ON EMCODES LIST */
data em_util (keep=bene_id em_svc);
  set utl.carr_2010 fnl (keep=bene_id expnsdt=prfnpi; hcpcs_cd:);
  array hcpcscd(13) hcpcs_cd1-hcpcs_cd13;
  em_svc=0;
  do i=1 to 13;
    if substr(hcpcscd(i),1,5) in (&emcodes) then;
      em_svc=1;
      leave;
  end;
  if em_svc=1;
```

In Step 7.4, we duplicate the EM_UTIL by beneficiary identifier, keeping only one record per beneficiary, where there is evidence of an E&M service. We output a permanent file called UTL_EM_UTIL. In other words, this is a list of beneficiaries for whom found evidence of an E&M service in our carrier data claims.

```
* STEP 7.4: DE-DUPLICATE TO CREATE LIST OF BENEFARIES WITH AT LEAST ONE E&M SERVICE */
proc sort data=em_util out=util.em_util nodupkey;
  by bene_id;
```
