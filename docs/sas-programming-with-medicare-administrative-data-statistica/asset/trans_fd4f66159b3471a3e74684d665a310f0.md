

## 使用 Medicare 行政数据进行 SAS 编程

如上所述，我们将基础索赔（base claim）和收入中心（revenue center）合并为每个每个索赔类型的单一文件，每个索赔及其关联行对应一条记录。请注意，我们不会提供为每个索赔类型执行此任务的代码，也不会提供使用这些数据集中所有变量的代码。相反，我们将提供一组用于保险人（Carrier）索赔数据集转换的代码，并使用一组有限的变量。通过这些示例，读者可以轻松创建针对其他索赔类型和额外变量执行此过程的代码。

## 将基础索赔和行级保险人数据转换为索赔级文件

让我们将基础索赔 SAS 数据集和行人 SAS 数据集合并为一个单一的保险人 SAS 数据集，每个索赔及其关联行对应一条记录。在第 5.1 步中，我们根据变量 `BENE_ID`、`CLM_ID` 和 `CLM_LN` 对保险人行文件（SRC.CARRIER2010LINE）进行排序。

```sas
* STEP 5.1: SORT CARRIER LINE FILE IN PREPARATION FOR TRANSFORMATION */
proc sort data=src.carrier2010line out=carrier2010line;
  by bene_id clm_id clm_ln;
run;
```

在第 5.2 步中，我们将已排序的保险人行文件（CARRIER2010LINE）从每行一条记录（使用 `CLM_LN` 识别）转换为每个索赔一条记录，并在该记录中包含行变量数组。由于保险人索赔最多有 13 条索赔行，我们将创建 13 个新变量。如你所见，我们对保险人行中的其他变量也执行了相同的操作。这些变量将在我们后续章节工作中使用。

```sas
* STEP 5.2: TRANSFORM CARRIER LINE FILE */
data carrier2010line_wide (drop=expnsdt1 expnsdt2 hcpcs_cd
line_icd_dgns_cd clm_id linepmpt1-13 mmddyy10);
  format expnsdt1_1-expnsdt2_13 mmddyy10;
  line_icd_dgns_cd1-line_icd_dgns_cd3 $5
  hcpcs_cd-hcpcs_cd3 $7
  linepmpt1-linepmpt13 12.
  prfnpipl1-prfnpipl13 $12.
  tax_num1-tax_num13 $10;
  set carrier2010line;
  by bene_id clm_id ln;
  retain
  expnsdt1_1-expnsdt113
  expnsdt2_1-expnsdt213
  line_icd_dgns_cd1-line_icd_dgns_cd3
  hcpcs_cd1-hcpcs_cd13
  linepmpt1-linepmpt13
  prfnpipl1-prfnpipl13
  tax_num1-tax_num13;
  array xline_icd_dgns_cd(13) line_icd_dgns_cd-
line_icd_dgns_cd3;
  array xexpnsdt1(13) expnsdt1_1-expnsdt13;
  array xexpnsdt2_(13) xexpnsdt2_1-expnsdt2_13;
  array hcpcs_cd(13) hcpcs_cd1-hcpcs_cd13;
  array xlinepmt(13) linepmt1-linepmt13;
  array xprfnpi(13) prfnnpil1-prfnnpil13;
  array xtax_num(13) tax_num1-tax_num13;
  if first.clm_id then
    do i=1 to 13
        xline_icd_dgns_cd(clm_ln)='';
        xexpnsdt1_(clm_ln)=.;
        xexpnsdt2_(clm_ln)=.;
        hcpcs_cd(clm_ln)='';
        xlinepmt(clm_ln)=.;
        xprfnpi(clm_ln)='';
        xtax_num(clm_ln)='';
    end;

  xline_icd_dgns_cd(clm_ln)=clm_id_dgns_cd;
  xexpnsdt1_(clm_ln)=xexpnsdt1;
  xexpnsdt2_(clm_ln)=xexpnsdt2;
  hcpcs_cd(clm_ln)=hcpcs_cd;
  xlinepmt(clm_ln)=linepmt;
  xprfnpi(clm_ln)=prfnpi;
  xtax_num(clm_ln)=tax_num;

  if last.clm_id then output;
run;
```

## 第 5 章：请求、接收、加载和转换数据

在第 5.4 步中，我们使用“a 和 b”合并，根据唯一的受益人标识（`BENE_ID`）和唯一的索赔标识（`CLM_ID`）合并 `CARRIER2010CLAIM` 和 `CARRIER2010LINE_WIDE` 文件。我们使用名为 `ETL_2010` 的 SAS 数据集。这个根据 `BENE_ID` 输出的数据集将在书中剩余部分中使用。注意，名为 `CARR_MATCH` 的输出文件包含 `BENE_ID` 和 `CLM_ID` 不匹配的记录，用于质量保证（不匹配表示数据存在问题）。

```sas
* STEP 5.4: MERGE BASE CLAIM AND TRANSFORMED LINE FILES */
data etl2010 carr_nomatch;
  merge carrier2010claim(in=a) carrier2010line_wide(in=b);
  by bene_id clm_id;
  if a and b then output;
  else output;
```

图 5.4 是上述相同受益人的输出 ETL2010 数据集的单记录。我们可以看到索赔文件和行文件已经合并，使得每个索赔存在一条记录，而以前存储在行文件单独行中的程序代码和诊断代码变量现在排列在同一行中，带有索赔上的日期基础细节（`FROM_DT` 和 `THRU_DT`）。

## 章节总结

在本章中，我们学习了如何接收、加载和转换用于完成研究编程项目的行政索赔和注册数据。为了这一目标，我们讨论了以下信息：

- 申请数据可能花费大量的时间和资金，因此在启动数据请求之前尽可能做好计划。
- 根据资金来源，获取 Medicare 数据有多种途径。我们讨论了 CMS 的集成数据仓库（IDR）、数据提取系统（DES）和研究数据中心（VRDC）。此外，我们讨论了研究协助中心（ResDAC）以及数据分发机构。
- ResDAC 和 CMS 数据分发机构是研究社区获取数据的门径。
