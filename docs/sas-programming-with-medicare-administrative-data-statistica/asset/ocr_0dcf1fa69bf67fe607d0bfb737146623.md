# 136 SAS Programming with Medicare Administrative Data

+   * Using the dataset CND_DIA_COPD_COND, we set the population of our output file to be only those continuously enrolled beneficiaries who were identified as diabetes.
* We use the data CND_EYE_DIA_COND to add the EYE_SVC flag to the output data set.
* We use the data ENR_CONTENR_2010_FNL to add HRR information for each beneficiary in the output data set.
* We output a data set FNL_PRESENT_EYEDIA, keeping the state and county name variables (STATE AND COUNTY), as well as the EYE_SVC variable. Note that the missing values of EYE_SVC for continuously enrolled beneficiaries with diabetes who did not receive a diabetic eye exam are set to zero.

```
* STEP 10.14: MERGE CONTINUOUS ENROLLMENT AND DIABETIC EYE EXAM
INFORMATION */
data fnl.present_eyedia(keep=bene_id eye_svc state county);
merge enr.contenr_2010_fnl (in=a) cnd.eye_dia_cond (in=b)
cnd.dia_copd_cond(in=k=bene_id dia_flag=);
by bene_id;
if c and dia_flag=1;
set eye_svc=0;
```

In Step 10.15, we sort the output of Step 10.14 by STATE AND COUNTY in preparation for displaying the number of diabetic eye exams by STATE AND COUNTY in the PROC FREQ presented in the next step.

```
* STEP 10.15: SORT DATA BY SSA STATE AND COUNTY IN PREPARATION FOR
PRESENTATION BY SSA STATE AND COUNTY */
proc sort data=fnl.present_eyedia;
by state county;
```

Finally, in Step 10.16, we perform two separate FREQs on the EYE_SVC variable. First, we create a frequency distribution of the rates of diabetic eye exams in the overall population of STATE and COUNTY, continuously enrolled beneficiaries with diabetes. Next, we perform the same frequency distribution by a single county in Michigan. You can see that there are few beneficiaries in Washenaw County Michigan who did not receive a diabetic eye exam. We use ODS to output the results to the folder where our present data is stored for this chapter.

```
* STEP 10.16: PRESENT MEASUREMENT OF DIABETIC EYE EXAM SERVICES BY
OVERALL AND BY SSA STATE AND COUNTY */
ods html file='C:\Users\gillingham\Desktop\SAS
Book\FINAL_DATA\ODS_OUTPUT\Gillingham\fig1_16.html'
image_300 style=printer;
ods graphics on / imagefmt=png;
title "RATES OF DIABETIC EYE EXAMS";
proc freq data=fnl.present_eyedia;
```
