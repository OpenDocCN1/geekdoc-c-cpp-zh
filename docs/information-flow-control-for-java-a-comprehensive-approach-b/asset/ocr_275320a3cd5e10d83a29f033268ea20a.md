# The Unfolding Constructor

Liang and Lloyd [LL98] already pointed out that in the presence of recursive
data structures the object cannot be unfolded until all are primitive types.
as mentioned in section 2.5, their solution, to limit the depth to a
fixed level, is unsatisfactory. In our approach we unfold the tree until we reach
a fixed point with respect to the aliasing of the containing object. Thus
we obtain a safe criterion for whether unfolding can be stopped
l losing dependencies. We define a reflexive, symmetric relation $R \subseteq loc$ loc.
