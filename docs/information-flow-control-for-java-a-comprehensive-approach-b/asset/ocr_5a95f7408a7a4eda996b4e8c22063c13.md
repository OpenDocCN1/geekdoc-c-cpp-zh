# 7.3.6 Future Work

While we presented evidence for precision, scalability, and practicability, there is still room for further improvements. In particular, we expect that optimizations for slicing, e.g. as presented by Binkley et al. [BHK07], apply to our information flows as well. These techniques produce up to 71% reduction in runtime and thus significantly improve scalability. Further research must evaluate, which of these techniques are applicable to information flow control.
