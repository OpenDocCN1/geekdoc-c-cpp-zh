# 定理 3.4. 如果

$\forall a \in \text{dom}(\mathcal{R}) : \forall x \in BS(a) \cap \text{dom}(P) : P(x) \leq R(a)$ (4.15)

则对于所有 $x \in N$ 保持机密性。

也就是说，从需求安全级别 $R(a)$ 的节点的后向切片不能包含具有更高安全级别 $P(x)$ 的节点 $x$。

**证明。** $x \in N$。我们需要证明 (4.7) 和 (4.8) 对 $x$ 有效。根据前提，我们知道 $\forall x \in BS(a) : P'(x) \leq R(a)$，因为对于 $x \in \text{dom}(P)$ 有 $P'(x) \leq P(x)$。因此 $R(a) \geq \text{fix}_{BS(a)}(P')$，根据定理 4.2 有 $R(a) \geq S(x)$。这里满足了 (4.8)。此外，根据 $S$ 的不动点的定义，$S$ 满足 (4.13)，从而满足 (4.11) 和 (4.7)。$\square$

该定理可以很容易转换为一个检查机密性的算法。

**基于 PDG 的机密性检查。** 对于依赖图中每个指定需求安全级别的节点，计算后向切片，并检查切片中所有节点的安全级别是否低于或等于指定的级别。
