# 2.4 Slicing Object-Oriented Languages

The slicing techniques presented in the previous sections and other research in
program slicing produced systems like CodeSurfer [AT01] or VALSOFT
[Kri03a,RS02], which can slice realistic programs in the full C language
with precision and performance.

# 2.4.1 Dynamic Dispatch

Special extensions of the SDG to object-oriented features have been proposed,
of all of them are capable of handling dynamic dispatch and inheritance
[LH96, KMG96, Zha00, LH98, WRW03, MMKM94, HDZ000]. Usually,
dynamic dispatch is treated similar to functions in C [GH96]. Today,
approximation of dynamic dispatch in slicers for object-oriented languages is
reasonable precision and efficient, enough to support call-graph and points-to-
anysis algorithms supporting the SDG construction. For every method-
to the call graph (see Definition 2.14) might be called at runtime,
a adds an edge to the entry of this method [TAFM97]. Each c→m in Gc
uces a edge c→Entry_m in the SDG. As the number and type
ofparameters must be identified for redefined methods, the parameter nodes at
t site can be taken from any appropriate method definition. However,
global variables and fields of parameters that are used or modified may differ
for redefinitions. This problem will be discussed in section 2.5.
