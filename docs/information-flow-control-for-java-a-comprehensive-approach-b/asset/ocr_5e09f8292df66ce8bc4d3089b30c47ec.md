# 5.2. FOUNDATIONS OF PATH CONDITIONS

$PC(x, y)$ is a necessary condition for flow from $x$ to $y$, and $E(z)$ is a necessary condition for the execution of $z$. A control path is a path that consists of control dependence edges only. $E(x)$ is computed along all control paths from the $Start$ node of function $x$ based on the conditions $c(
u 	o \mu)$ associated with dependence edge $
u 	o \mu$. For control dependences, $c(
u 	o \mu)$ is typically a condition from a *while-* or *if-statement*. Program variables in a path condition are (implicitly) existentially quantified, which are necessary conditions for potential information flow.

Because the path between the criterion nodes are based on the chops, we will be interested in the set of paths $P_1, P_2, \dots \in CH(x, y)$ and a slightly relaxed relation for path conditions is:

```
$PC(x, y) = \bigwedge_{z \in PC(x,y)} E(z)$
```

In [[SRK06**] Selting et al. explain why this formula is correct and precise, and why it clearly simplifies computation. They also show that cycles in $CH(x, y)$ can be safely ignored for computation of $PC(x, y)$, such that the formula is always finite. For the example in Figure 5.1, the following equation and path conditions are computed:

```
$c(2 \to 3) \equiv c(2 \to 4) \equiv (n > 0), \quad c(4 \to 5) \equiv (x > 0)$,$
c(4 \to 7) \equiv (x \le 0)$,$
E(1) = \text{true}, \quad E(3) \equiv (n > 0) \wedge E(5) \equiv (n > 0) \wedge (x > 0)$,$
PC(1, 5) \equiv E(1) \wedge E(5) \equiv (n > 0) \wedge (x > 0)$
```

In the presence of data structures like arrays or pointers, additional constraints will be generated. For data dependences, $\Phi(\nu \to \mu)$ is a condition constraining information flow through data types. As an example we consider arrays (a full presentation can be found in [[SRK06**]) A data dependence $
u \to \mu$ between array element $a[E_1] = \dots$ and a usage $a[E_2]$ generates $\Phi(\nu \to \mu) = E_1 \wedge E_2$; all other dependences will generate $\Phi(\nu \to \mu) = \text{true}$. The equation to compute a path condition becomes:

```
$PC(x, y) = \bigwedge_{z \in PC(x,y)} (\bigwedge_{z \in P} E(z) \wedge \bigwedge_{u \in P} \Phi(u \to v)) \quad (5.2)$
```
