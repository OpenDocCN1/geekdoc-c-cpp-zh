# 2.5.1 Intraprocedural IRef and IMod Computation

Before getting into the details of the algorithm, the notation used in this is presented: For a method m, the Param(m) denotes all formal parameters of m. We use Sub(x) for the set of locations that are transitively reachable by dereferencing fields of x. This can be easily determined by Class Hierarchy Analysis [DGC95], which provides results of class analysis generally allow much more refined sets, as only fields of points-to-set x (and transitively reachable locations) need to be considered. The base(y,f) refers to the base object of a composite location y and is defined as base(y,f) = y.

The locations that may be referenced or modified by the method alone, without taking effects of method into account, are computed according to the following recursive definitions. Therefore, we are interested in their minimal fixed point:

```
IRef(m) = {loc.y | y ∈ Param(m) ⊉ IRef(m) : ∃ statement r ∈ m
loc.x ∈ Mod(m) ⊉ Ref(r): alias(x,y)} ⊉ IMod(m) ⊉ Subobject(x)
{loc.y | y ∈ IRef(m) : ∃ statement r ∈ m ⊉ Ref(r): alias(x,y)} (2.3)
```
