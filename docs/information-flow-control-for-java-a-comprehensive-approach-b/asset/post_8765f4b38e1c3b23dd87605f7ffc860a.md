# Zusammenfassung

Trotz der derzeit Diskussion über Sicherheit in der Informatik können aktuelle Sicherheitstechniken zwar nur die Herkunft und Identität eines Software-Artefakte überprüfen. Die Semantik eines Artefakts wird nicht berücksichtigt, wodurch Trojanische Pferde, Würmer und andere Formen von bösartiger Software begünstigt. Doch die gegenwärtigen Netzwerke unserer Zeit werden diese Probleme umso gravierender.

Informationskontrolle ist eine Technik, die die Sicherheit eines gegebenen Programms hinsichtlich einer Sicherheitspolitik überprüft. Im Gegensatz zu traditionellen Sicherheitstechnik berücksichtigt sie auch die Programmsemantik. Ein bekanntes Beispiel für eine Sicherheitspolitik, Nichtinterferenz, verlangt zum Beispiel, dass kleine Eingaben in öffentliche Ausgaben nicht einmal von geheimen Datenbank beeinflusst dürfen. Obwohl Informationsflüsse fließen, verwenden die eingesetzten Techniken einen sehr begrenzten Bereich der Forschung. Die Programanalyse nutzt hauptsächlich Typsysteme. Typsysteme öffnen die Tür für Programmanalyse als Form der Informationskontrolle, aber andere Techniken bieten höhere Präzision oder benötigen einen geringeren Annotationsaufwand, um die Sicherheitspolitik zu spezifizieren.

Das sogenannte Program Slicing hat sich erwiesenmaßen stark mit Informationskontrolle und bietet mehrere Dimensionen, die Analysemöglichkeit erhöhen. Diese Arbeit implementiert ein präzises Modell von objektorientiertem Programmieren in einer klassischen Datenstruktur für Program Slicing, Systemhängigkeitsgraphen. Die Slicingalgorithmus wird dahingehend erweitert, dass sie präzise Informationskontrolle und, falls nötig, eine Möglichkeit zur Aufinhaltung der Information bietet. Pfadbindungen geben tiefere Einsicht, wie eine Anweisung eine andere beeinflussen kann. Sie ergeben somit Bedingungen für einen unstrukturierten Informationsfluss oder zeigen, dass ein vermuteter Fluss in Wirklichkeit möglich ist.

Ob die präsentierte Analyse im Allgemeinen ist als ein Typsystem, zeigt eine Evaluation, die für die Sicherheit skaliert, deren Analyse wir beabsichtigen. Gleichzeitig reduziert dies der Aufwand deutlich, die Sicherheitspolitik zu spezifizieren. Das wichtigste Ergebnis dieser Arbeit ist allerdings, dass wir die erste Analyse bieten, die eine reale Programmiersprache zertifizieren kann: Unser System analysiert Java Bytecode in vollem Umfang.

# Abstract

Despite the current discussion on security in computer science, current security mechanisms can only validate origin and identity of a software artifact. The semantics of an artifact are not taken into account, giving rise to all forms of trojan horses, worms and other malware. With the ubiquity of networks in modern life, these problems become all the more serious.

Information flow control is a technique to assert the security of a given program with respect to a security policy. In contrast to traditional security, it also takes the program semantics into account. The most prominent example is from secret input. While output of a program may not flow to public output; in fact, public output may not be influenced from secret input. Techniques for checking security policies only intensively researched in the last decade, leverage a very restricted part of program analysis technology, mostly type systems. While type systems were a successful door opener for program analysis as a means of information flow control, other techniques offer higher precision or lower annotation burden for specifying the security policy.

A technique called program slicing has been shown closely connected to information flow control and offers many dimensions for improving analysis precision. This thesis presents a precise model for object-oriented programs in a classic data structure for slicing; the system dependence graph. It extends the algorithms for program slicing to allow for precise information control and provides a means to downgrade secure information, if necessary.

While the presented analysis is clearly more expensive than type systems, an evaluation shows that our techniques scale well to the security kernels we have in mind. At the same time, the burden for specifying the security policy is reduced significantly. But most importantly, we offer the first security analysis that can certify programs written in a realistic programming language: Our system can analyze full Java bytecode.
