## 4.7 去分类

如所述的 IFC 过于简单，因为在某些情况下，人们可能接受将更高安全级别的信息传递到“更低”通道。例如，信息在统计匿名化后可能被发布，秘密数据可能通过加密在互联网上传输，而在电子商务中需要在购买后释放秘密数据。去分类允许降低传入信息的 security level 作为放松安全策略的一种手段。前面介绍的密码检查方法就是另一个例子：由于密码是加密的，因此密码表的信息流向可见结果并不重要，因此在节点 14 处进行去分类到 public 是合适的（在第 4.5 节中发现了非法流）——基于密码的身份验证机制必然会泄露有关秘密密码的信息。$^{17}$

在允许对基本安全策略的此类例外时，一个主要关注点是例外可能会引入不可预见的信息泄露。提出了几种去分类语义的方法，每种方法都侧重于“安全”去分类的某些方面。当前最先进的研究描述了根据何处、谁、何时和什么可以去分类的去分类的四个维度 [SS05]，由此提出了一些基本原则，可作为允许去分类的语义安全策略的“合理性检查”。这些原则是 1. 语义一致性，即基本是在不改变语义的变换下保持不变；2. 保守性，即在没有去分类的情况下，安全性归结为非干扰；3. 释放的单调性，即添加去分类不应使安全程序变得不安全；4. 非遮蔽，要求去分类操作不能掩盖其他信息释放。

### 4.7.1 SDG 中的去分类

我们通过指定某些 SDG 节点为去分类节点来建模去分类。设 $D \subseteq N$ 为去分类节点集合。去分类节点 $x \in D$ 必须具有所需和提供的 security level：

```
$x \in D \Rightarrow (x \in dom(P) \cap dom(R)) \wedge (R(x) \geq P(x)) \quad (4.18)$
```

泄露 $x$ 的最大 security level $R(x)$ 的信息被降低（去分类）到 $P(x)$（请注意 $R(x) \not\geq P(x)$ 没有任何意义，

因为去分类应该降低级别，而不是提高它）。现在，从节点 $y$ 到 $a$ 的路径上 $P(y) > R(a)$ 并不是违规，如果路径上存在去分类节点 $x \in D$ 且 $P(y) \leq R(x)$ 且 $P(x) \leq R(a)$（假设路径上没有其他去分类节点）。实际 security level $S(x)$ 将在 $P(x)$ 和 $R(x)$ 之间。在密码示例中，$D=\{14\}, R(14)=secret, P(14)=public$；并且前面描述的非法流消失了。

根据 Sabelfeld 和 Sands [SS05]，为了表达信息释放，需要描述释放了哪些信息：去分类节点集合 D 对应于代码位置——此外，在已实现的系统中，我们必须指定代码位置，它们由系统映射到去分类节点。

就传播而言，去分类只是改变了方程 (4.11) 的计算方式，必须按如下方式扩展：

```
$S(x) \geq \begin{cases} P(x) & \text{if } x \in D \ P(x) \sqcup S(y) & \text{otherwise} \end{cases} \quad (4.19)$
```

因此包含的 security level 被忽略并被去分类 security level 替换。

当然，(4.8) 对非去分类节点有效，但对于 $x \in D$ 它必须通过 $S(x)$ 作为去分类进行修改：

```
$\forall x \in dom(R) \setminus D : R(x) \geq S(x) \\forall x \in D : R(x) \geq \bigcup_{y \in pred(x)} S(y) \quad (4.20)$
```

这表达了 $S$ 的正常流在 $x \in D$ 处被中断。

**定义 4.3.** 给定程序的 SDG。如果对于所有 $a \in dom(R)$ 方程 (4.19) 和 (4.20) 都得到满足，则该程序监控保密性。

**定理 4.6.** 对于任何 $a \notin D$，算法 7 生成的约束集是正确且完备的，因此根据定义 4.3 强制执行保密性。

**证明.** 我们已经论证过（定理 4.4 的证明）对于非去分类节点，生成的约束与方程 (4.8) 和 (4.7) 完全对应，并且与方程 (4.19) 和 (4.20) 中的非去分类情况相对应。对于去分类节点 $d \in D$，算法 7 不再生成约束 $S(w) \leq S(d)$，这确实由 (4.19) 的情况 $x \in D$ 要求。相反它生成 $R(d) \geq S(w)$ 对于 $w \in pred(d)$，这等价于 (4.20) 中情况 $x \in D$ 的约束。此外，它生成 $S(d) \geq P(d)$，这正是 (4.19) 中情况 $x \in D$ 所要求的。

因此算法 7 生成了 (4.19) 和 (4.20) 所要求的约束。因为它们具有相同的最小不动点，满足定义 4.3 的要求。

在 $D = \varnothing$ 的情况下，算法 7 根据定理 4.4 检查没有去分类的非干扰。因此我们得到免费的

**推论 4.7**（去分类的保守性）。算法 7 是保守的，即在没有去分类的情况下它归结为标准的非干扰。

最后让我们指出一些特殊情况。显式允许在一条特定路径上存在两个或多个去分类，例如 $x 	o^* d_1 	o^* d_2 	o^* y$。但这只有在 $P(d_1) \leq R(d_2)$ 时才有意义，否则路径上不可能有合法流，并且 $P(d_2) \leq P(d_1)$，因为第二次去分类是多余的。

如果从 $x$ 到 $y$ 的路径上有多个去分类，例如 $x 	o^* d_1 	o^* y 	o^* d_2 	o^* y, x 	o^* d_3 	o^* y,\dots$，则可以通过引入新的去分类 $R(d) = \bigsqcup R(d)$ 和 $P(d)$ 来保守地近似所有这些去分类。通过 $d$ 合法的任何流也通过（其中一个）$d_i$ 合法，因此近似不会引入新的（非法）流。这一观察似乎没有动机，但将成为第 4.8 节中描述的更精确 IFC 的来源。

## 4.7 释放的单调性

另一个有用的属性是释放的单调性，它指出引入额外的去分类不应使以前安全的不安全（即产生非法流）。形式上，可以定义如下：

**定义 4.4.** 设程序根据定义 4.3 满足保密性，并且设 $d \in N$ 其中 $d \in Dom(R) \cup Dom(P)$。用 $d' \in D$ 替换 $d$，其中 $d'$ 具有与 $d$ 相同的连接边，但 $d'$ 被 $R$ 和 $P$ 注释。根据 (4.19) 重新计算实际 security level，$S'(x)$ 对于 $x \in N$。如果方程 (4.20) 对所有 $S'(x)$ 仍然成立，则 $d'$ 的去分类尊重释放的单调性。

**定理 4.8.** 如果 $R'(d') \geq \bigsqcup_{y \in pred(d)} S(y)$，并且 $P(d') \leq \bigsqcup_{y \in pred(d)} S(y)$，则对于 $x \in N, S'(x) \leq S(x)$。

第一个前提避免了防止非法流（其中 $R'(d') = \mathcal{T}$ 因为 $d \notin Dom(R)$ 被任意过低的 $R(d)$ 阻止）。请注意 $P(d) \leq R(d)$ 在方程 (4.18) 中无论如何都是必需的。上述前提更精确，避免去分类产生新的非法流，因为传出的去分类过高，或传入限制过低。在实践中，两个要求是等价的并且不限制去分类。

**证明.** 在最优 SDG 中，$\bigsqcup_{y \in pred(d)} S(y) \leq S(d) \leq S'(d) = \bigsqcup_{y \in pred(d)} S(y)$，在新的 SDG 中 $P'(d) \leq P(d) \leq S'(d) = \bigsqcup_{y \in pred(d)} S(y)$ 根据假设和方程 4.19。此外，$S'(d) \leq S(d) \leq \bigsqcup_{y \in pred(d)} S(y) \geq S'(y) = S(y)$ 对于所有 $y \in succ(d)$。这里 $S(y) \geq \bigsqcup_{y \in pred(y)} S(y) \geq S'(y)$ 对 $y$ 的后继有效。通过归纳 $^{18}$ $S'(x) \leq S(x)$ 对于所有 $x$。
