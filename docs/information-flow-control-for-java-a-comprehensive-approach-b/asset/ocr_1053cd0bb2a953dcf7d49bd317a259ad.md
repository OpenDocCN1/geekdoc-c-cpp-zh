Comparing our results with Ranganath's, aliasing clearly excels over es-

a rather cheap but context-sensitive escape analysis as presented in [RH04].

context-sensitive aliasing information gives a significant gain in precision over
escape information. Benchmarks with array access are clearly not modeled
in [RH04], so a fair comparison for this is impossible.

# 7.3 Information Flow Control

This section presents empirical studies about precision, scalability, and pract-\icability of our new information flow analysis developed in chapter 4. It starts
 an elaboration on the current state of the art in language-based informa-
flow control. The language Jit is the only implementation of a Java-like
language with built-in information flow control. We will show that the applic-
ability diminishes significantly, as the language design is centered around the
information flow type system. Traditional Java programs need sign
sificant refactoring for complying with Jit's constraints (see e.g. [AS05]).
The later parts of this section connect on empirical evaluations of accuracy
and scalability.
