Let us finally point out a few special situations. It is explicitly allowed to have two or more declassification on one specific path, e. g. $x 	o^* d_1 	o^* d_2 	o^* y$. But this only makes sense if $P(d_1) \leq R(d_2)$, otherwise no legal flow is possible on the path, and $P(d_2) \leq P(d_1)$, as the second declassification is redundant.

In case there are several declassifications on paths from $x$ to $y$, by example $x 	o^* d_1 	o^* y 	o^* d_2 	o^* y, x 	o^* d_3 	o^* y,\dots$, it is possible to approximate all these declassifications conservatively by introducing a new declassification $R(d) = igsqcup R(d)$ and $P(d)$. Any flow legal through $d$ is also legal through (one of) the $d_i$, hence the approximation will not introduce new (illegal) flows. This observation seems unmotivated, but will be the source for some more precise IFC, as described in section 4.8.

# 4.7 Monotonicity of Release

Another useful property is monotonicity of release, which states that introduction of an additional declassification should not make previously secure insecure (i.e. generate illegal flow). Formally, this can be defined as follows:

**Definition 4.4.** Let a program satisfy confidentiality according to Definition 4.3 and let $d \in N$ where $d \in Dom(R) \cup Dom(P)$. Replace $d$ by $d' \in D$ where $d'$ has the same connecting edges as $d$, but $d'$ is annotated with $R$ and $P$. Recompute the actual security levels according to (4.19), $S'(x)$ for $x \in N$. Declassification of $d'$ respects monotonicity of release, if equation (4.20) still holds for all $S'(x)$.

**Theorem 4.8.** If $R'(d') \geq igsqcup_{y \in pred(d)} S(y)$, and $P(d') \leq igsqcup_{y \in pred(d)} S(y)$, then for $x \in N, S'(x) \leq S(x)$.

The first premise avoids that prevents illegal flow (where $R'(d') = \mathcal{T}$ as $d 
otin Dom(R)$ is blocked by a too low arbitrary $R(d)$). Note that $P(d) \leq R(d)$ is required anyway in equation (4.18). The above premise is more precise and avoids that a declassification generates new illegal flows as the outgoing declassification is too high, or the incoming limit too low. In practice, both requirements are equal and do not restrict declassification.

**Proof.** In the optimal SDG, $igsqcup_{y \in pred(d)} S(y) \leq S(d) \leq S'(d) = igsqcup_{y \in pred(d)} S(y)$, in the new SDG $P'(d) \leq P(d) \leq S'(d) = igsqcup_{y \in pred(d)} S(y)$ by assumption and equation 4.19. Furthermore, $S'(d) \leq S(d) \leq igsqcup_{y \in pred(d)} S(y) \geq S'(y) = S(y)$ for all $y \in succ(d)$. Here $S(y) \geq igsqcup_{y \in pred(y)} S(y) \geq S'(y)$ works for the successors of $y$. By induction $^{18}$ $S'(x) \leq S(x)$ for all $x$.
