# 2.1. INTROPROCEDURAL DATAFLOW ANALYSIS

Since the nodes and their corresponding statements are bijectively mapped, we will use both meanings interchangeably in the sequel.

**Reachability** One of the most fundamental properties of a program is the question if an execution of the program exists, where a given node is traversed and later in this execution another node is reached, i.e. whether a given statement is reachable in a program execution from another given statement. A path $p = (n_1, \dots, n_k)$ is called *realizable* if an execution exists, where the nodes are executed in the order induced by the path. This question, however, is undecidable in general and so conservatively assumes that all paths in the CFG correspond to a valid execution. This corresponds to treating conditionals like non-deterministic choice operators.

# 2.1.1 Monotone Dataflow Analysis Framework

Monotone dataflow analysis frameworks (MDFAF) are the most important class of dataflow analysis. Under a certain condition, they can compute the most precise solution in a finite number of steps, if no loops in the CFG may infinitely long paths. The basic structure of a MDFAF is a lattice of values:

**Definition 2.2** (Semi Lattice). A *join* semi lattice $\mathcal{L} = (L, \leq, \bot, \sqcup)$ consists of a set of values $L$ with a partial order $\leq$, and a binary operator supremum $(\sqcup)$ where the least element $\bot := \sqcup L$ in $L$ is called and the following properties hold:

+   1. $a \leq b := a \sqcup b = b$
2. $(a \sqcup b) \sqcup c = (a \sqcup c) \sqcup b$ (commutativity)
3. $a \sqcup b = b \sqcup a$ (commutativity)
4. $a \sqcup a = a$ (idempotence)

A *semi lattice* $\mathcal{L} = (L, \leq, \top, \sqcap)$ consists of a set of values $L$ with a partial order $\leq$, and a binary operator infimum $(\sqcap)$ where the greatest element $\top := \sqcap L$ in $L$ is called top and the following properties hold:

+   1. $a \geq b := a \sqcap b = a$
2. $(a \sqcap b) \sqcap c = (a \sqcap c) \sqcap b$ (associativity)
3. $a \sqcap b = b \sqcap a$ (commutativity)
4. $a \sqcap a = a$ (idempotence)

**Definition 2.3** (Complete Lattice). A complete lattice $\mathcal{L} = (L, \leq, \bot, \top, \sqcup, \sqcap)$ consists of a set of values $L$ with a partial order such that $\mathcal{L} = (L, \leq, \sqcup)$ is a join semi lattice and $\mathcal{L} = (L, \leq, \top, \sqcap)$ is a meet semi lattice.
