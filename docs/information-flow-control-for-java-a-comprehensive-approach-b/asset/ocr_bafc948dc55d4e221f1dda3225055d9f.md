This thesis presents several precise techniques that analyze object-oriented
languages for security vulnerabilities, together with evaluations on Java benchmarks.
The key question that will be targeted throughout this work is “Can a given
statement directly or indirectly influence another statement, and if this is poss-
ible, how can this influence happen during program execution?” Several branches
of computer science ask slight variations of this question, but the basic ideas re-
mains the same for all their targeted problems. A seminal technique to answer
t first part of the question has been presented by Weiser [Wei84] which has
been coined program slicing. Program slicing as presented by Weiser and many
other authors, determines the set of statements that potentially affect the exe-
cution of a given statement.

Program slicing has been extended to procedural languages like C and implement-\ed in frameworks like CodeSurfer [ATO1] or ValSoft [SRK06]. But for the
dominant programming paradigm of our time, object-oriented programming
(OOP), no clear and sound model was available when this thesis started. After
from that, whereas support for multi-threading is integrated into contemporary
languages like Java, and precise flow analysis for slicing multi-threaded applica-
tions had been proposed, no, seems imperative for precise slicing algorithms. As a remedy, this thesis
presents novel models for modeling key features of languages like Java – ob-
jects, dynamic binding, exception handling and concurrency – for the purpose
of program slicing. A precise analysis for computation of inter-thread dependencies
prunes most of the false positives that crude implementations do
include.
