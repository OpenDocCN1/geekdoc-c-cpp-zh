This PDG is still incomplete, as it does not include exceptions. Dynamic runtime exceptions can alter the control flow of a program and thus may lead to implicit flow, in case the exception is caught by some handler on the stack, or represent a control channel in case the exception is propagated to the top of the stack yielding program with stack trace. This is why type-based approaches disallow (or ignore) implicit exceptions. Our analysis conservatively adds control edges from bytecode injections which might throw unchecked exceptions to an appropriate exception handler (CPS+99), or propagates the exception to the callee in which receives a conservative control flow edge. Thus, our analysis does miss implicit flow caused by these exceptions, even the covert of uncaught exceptions is checked. The resulting PDG is shown in Figure 4.5.
