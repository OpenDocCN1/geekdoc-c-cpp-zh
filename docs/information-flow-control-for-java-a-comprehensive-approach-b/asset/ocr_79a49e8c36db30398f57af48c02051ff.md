# Definition 2.4 (Monotone Function Space). A set of functions F defined on a
join-lattice L = (L, �subseteq, �cap) is a monotone function space, if

+   1. idL ∈ F : idL(x) = x (identity function)

+   2. ∀ F ∈ F : ∀x, y : x ≤ y ⇒ F(x) ≤ F(y) (monotonicity)

+   3. ∀F, G ∈ F : F �∘ G ∈ F (closed under composition)

+   4. ∀F, G ∈ F : F ∩ G ∈ F (pointwise infimum)

# Definition 2.5 (Dataflow Analysis Framework). A monotone data-
flow analysis framework (MDFAF) A = (L, F) consists of

+   1. a complete semi-lattice L = (L, �subseteq, �cap) with a supremum operator for the
abstract values of the dataflow analysis, and

+   2. a monotone function space F defined on L.

If all functions in F are distributive over ∩, i.e. (∀ F ∈ F : ∀x, y ∈ L :
F(x ∩ y) = F(x) ∩ F(y)), the desired
solution of a monotone dataflow analysis framework is the meet-over-all-paths
(MOP) solution of a monotone in the control flow graph.
transfer for a path p = (n1, ..., nk) can be constructed with the
recursive definition:

```
F_(n1,...,nk) : L → L : F_(n1,...,nk)(x) = F_nk (F_(n1,...,n_{k-1})(x))
```

Since there are infinitely many paths in a control flow graph, there
is no general algorithm to compute the MOP, which is F_p, directly.
However, an efficient solution can be found using a different definition, which is
equivalent or conservative to the MFP for monotone functions.

# Definition 2.6 (Fixed point). A fixed point of an operator f on a semi-lattice
L is an element x in L such that f(x) = x. A fixed point for x is called
minimal (MFP) if y ≤ x : f(y) = y ≤ x.
