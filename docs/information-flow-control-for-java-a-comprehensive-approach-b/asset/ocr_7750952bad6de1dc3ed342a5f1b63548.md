The lattices have been designed such that they cover different characteristics equally: Lattice A is a traditional chain, lattice B is more flat and contains an impure node. Lattice F has been automatically generated by randomly removing edges from a complete subset of 9 elements. Conversion to bit representation is only possible for the transitive reduction order, which is not guaranteed by random removal of order edges. We included a reduction phase before bit conversion. Interestingly, Table 7.3 illustrates that the bit conversion usually results in a representation with size linear in the number of lattice nodes.
