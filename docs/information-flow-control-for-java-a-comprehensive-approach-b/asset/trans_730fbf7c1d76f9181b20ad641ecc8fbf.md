# 定理 3.4. 若

$\forall a \in \text{dom}(\mathcal{R}) : \forall x \in BS(a) \cap \text{dom}(P) : P(x) \leq R(a)$ (4.15)

则对所有 $x \in N$ 保密性得以维持。

也就是说，从具有所需安全级别 $R(a)$ 的节点向后切片不得包含具有更高安全级别 $P(x)$ 的节点 $x$。

**证明.** $x \in N$。我们需要证明 (4.7) 和 (4.8) 对 $x$ 有效。从前提我们知道 $\forall x \in BS(a) : P'(x) \leq R(a)$，因为对 $x \in \text{dom}(P)$ 有 $P'(x) \leq P(x)$。因此 $R(a) \geq \text{fix}_{BS(a)}(P')$，其中 $R(a) \geq S(x)$ 由定理 4.2 给出。这里 (4.8) 得到满足。此外，根据不动点 $S$ 的定义，$S$ 满足 (4.13) 从而满足 (4.11) 和 (4.7)。$\square$

该定理可以很容易地转化为检查保密性的算法。

**基于 PDG 的保密性检查。** 对依赖图中的每个具有指定所需安全级别的节点，计算向后切片，并检查切片中的所有节点具有较低或相等的安全级别指定。

一旦 PDG 已被计算，每个向后切片和保密性检查的最坏复杂度为 $O(|N|)$。通常，具有特定安全级别 $R(a)$ 的节点数量是有界的且与 $|N|$ 无关：通常只有少数输出具有语句 $R(a)$。因此总体复杂度也预期为 $O(|N|)$。

逐节点检查允许在出现安全违规时进行简单的强大洞察：如果向后切片 $BS(a)$ 具有过大或不可比较的提供安全级别（$P(x) \ngeq R(a)$），则负责的节点可以通过所谓的 $CH(x,a) = FS(x) \cap BS(a)$ 计算。chop 计算从 $x$ 到 $a$ 路径上的所有节点，因此它包含可能参与从 $x$ 的安全级别传播到 $a$ 的所有节点。
