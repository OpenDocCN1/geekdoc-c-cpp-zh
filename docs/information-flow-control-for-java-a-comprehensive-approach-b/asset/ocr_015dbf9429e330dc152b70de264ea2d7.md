# 4.2.1 The Lattice Model of Information Flow

Usually, data is classified into a finite set of security domains (also called security levels) $\mathcal{L} = \{l_1, \dots, l_n\}$. A transitive, reflexive and antisymmetric metric interference relation (a partial order): $\preceq$ denotes $x \preceq y$ if information in class $x$ is permitted to flow to class $y$. The completion relation, called noninterference, defined by $x \perp y$ means that information flow between security levels must be prevented. Frequently, the security levels are arranged in a lattice $\mathcal{L}$ in which $\preceq$ is equivalent to $\le$. If the interference relation does not form a lattice, we assume a complete bounded lattice $\mathcal{L} = $(\mathcal{L}, \le, \top, \bot)$ of security levels in the sequel for convenience. The most trivial lattices are given by linear priorities that can be represented as a sequence $0 \dots, n$, like LOW $(\text{L}) \le$ HIGH $(	ext{HIGH})$ which can also be represented as $0 \le 1$, or like the well-known classification levels Unclassified (0), Confidential (1), Secret (2) and Top (3). Many complex lattices contain incomparable elements where neither $x \preceq y$ nor $y \preceq x$ as shown in Figure 4.1. Lattices have been found to naturally represent the semantics of information flow [Den76]. When information is composed of pieces with different security levels, the supremum operator $\sqcup$ signifies security class for the combined information. The 'operands' security levels are joined using the supremum operator, e.g. if information of the security levels Confidential and Secret is merged, the result must at least be Secret.
