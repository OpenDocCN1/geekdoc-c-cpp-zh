# **Algorithm 1** Kildall's algorithm to compute the MFP

```
**Input:** CFG a control flow graph
$F_s$ transfer functions of a monotone dataflow analysis framework
**Output:** $A$ an array of lattice elements computing the MFP of the MDFAF
**foreach** $n \in$ CFG **do**
  $A[n] = \perp$
  **od**
  **foreach** $n \in$ CFG **do**
    $temp = \bigcap_{q} F_q(A[q])$
    **if** $temp \neq A[n]$
      $change = \text true$
      $A[n] = temp$
  **fi**
  **od**
**until** $\neg$ $change$
```

**Theorem 2.1** (Coincidence Theorem [KU77]). Let $P_1, P_2, \dots$ be all (maybe infinitely many) paths from START to the program $s$; let the transfer functions $F_B$ be distributive; let $A[s] = fix(s) \in L$ be the value computed by the fixed point iteration. Then follows:

> $fix(s) = \bigcap_{\text{Path } P \text{ ending in } s} F_{P}(\perp)$

In the general case of non-distributive transfer functions, the MFP is only less or equal to the MOP.

# **2.1.2 Reaching Definitions**

*Reaching definitions* is a traditional dataflow problem of optimizing compilers but is also a prerequisite for computing the program dependence graph. It answers the question, whether a definition of a variable at a given statement can reach the use of that variable without statement being redefined on the way. A definition that assigns value to a variable, while a use that takes a variable as parameter. A definition can reach another statement, if there is a path from the definition to that statement in the CFG without any definition of the same variable on that path:

**Definition 2.7** (Reaching Definitions). Let $Def(n)$ be the set of variables defined at a node $n$ in the CFG, then a definition $d$ of a variable $var(d) := v$, where $v \in Def(n)$, reaches a (not necessarily different) node $n'$, if there is a path $P = (n = n_0, \dots, n_k = n')$ in $G$ with $k > 0$ such that $\forall i \in 1, \dots, k-1 : v \notin Def(n_i)$.
