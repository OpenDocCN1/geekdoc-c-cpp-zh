The constraint solver checks the satisfiability of the condition and, if possible, generates program input that trigger the influence in question, thus acting as a digital “witness”. However, we found that naively extending path conditions to object-oriented constructs results in conditions that solvers cannot reduce to input. As part of this work, paths are extended to object-oriented language features. Furthermore, we present here refine the terms generated by naive extension, such that a constraint solver can handle these terms and generates. Complementary, this thesis proposes an approach to increase precision of path conditions by dynamic profiling data.

All analyses form the foundation for our main application, information flow control (IFC). Information flow control basically as proving that (almost) no sensitive data can lead to untrusted users or other uncontrolled channels like the Internet. While it was forklore that only one mechanism and implementation of this program slicing was known, and none for object-oriented languages; research was exclusively concerned with type systems that guarantee correct information [SM03]. Unfortunately type systems are either coarse means, allow no flow-, or restrict the programming language and require elaborate annotations, both of which may be prohibitive for realistic applications. These type systems are too restrictive for practical use in realistic security-sensitive applications. As an alternative, this thesis develops an information flow control mechanism based on dependence graphs and program slicing. It allows a more precise analysis in all dimensions presented in the sequel. As intuitively secure programs contain a negligible information flow from secret input data to public output, which is prohibited by standard noninterference, we introduce an extension for classification, and present a technique to determine context-sensitive results in spite of cla's intransitive nature.

All the approaches presented in this thesis have been implemented. This implementation will be described, together with a presentation of the Eclipse integration. Finally, the scalability and precision of the presented approaches will be evaluated.
