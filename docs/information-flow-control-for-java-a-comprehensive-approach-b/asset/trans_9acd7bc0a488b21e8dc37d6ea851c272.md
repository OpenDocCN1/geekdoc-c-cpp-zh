

## 2.1. 过程内数据流分析

由于节点与其对应的语句之间存在双射映射，在后文中我们将交替使用这两种含义。

**可达性**（Reachability）程序最基础的属性之一是：是否存在一次程序的执行，在该次执行中，一个给定的节点被遍历，并在随后的执行中到达另一个节点，即在程序执行过程中，一个给定的语句是否从另一个给定的语句可达。如果一条路径 $p = (n_1, \dots, n_k)$ 存在一次执行，按照路径诱导的顺序执行节点，则该路径被称为*可实现的*（realizable）。然而，这个问题在一般情况下是不可判定的，因此保守地假设控制流图（CFG）中的所有路径都对应于一次有效的执行。这相当于将条件语句视为非确定性选择操作符。

### 2.1.1 单调数据流分析框架

单调数据流分析框架（MDFAF）是数据流分析最重要的类型。在某些条件下，如果 CFG 中不存在具有无限路径的循环，它们可以在有限步数内计算出最精确的解。MDFAF 的基本结构是一个值格：

**定义 2.2**（半格）。一个上半格（join semi lattice $\mathcal{L} = (L, \leq, \bot, \sqcup)$ 包含一个值集 $L$、一个偏序 $\leq$ 以及一个二元算符上界 $(\sqcup$，其中 $L$ 中的最小元素 $\bot := \sqcup L$ 称为底，并满足以下性质：

- 1. $a \leq b := a \sqcup b = b$
- 2. $(a \sqcup b) \sqcup c = (a \sqcup c) \sqcup b$ （结合律）
- 3. $a \sqcup b = b \sqcup a$ （交换律）
- 4. $a \sqcup a = a$ （幂等）

一个半格 $\mathcal{L} = (L, \leq, \top, \sqcap)$ 包含一个值集 $L$、一个偏序 $\leq$ 以及一个二元算符下界 $(\sqcap$，其中 $L$ 中的最大元素 $\top := \sqcap L$ 称为顶，并满足以下性质：

- 1. $a \geq b := a \sqcap b = a$
- 2. $(a \sqcap b) \sqcap c = (a \sqcap c) \sqcap b$ （结合律）
- 3. $a \sqcap b = b \sqcap a$ （交换律）
- 4. $a \sqcap a = a$ （幂等）

**定义 2.3**（完全格）。一个完全格 $\mathcal{L} = (L, \leq, \bot, \top, \sqcup, \sqcap)$ 包含一个值集 $L$ 及其偏序，使得 $\mathcal{L} = (L, \leq, \sqcup)$ 是上半格且 $\mathcal{L} = (L, \leq, \top, \sqcap)$ 是下半格。$L$ 中的最小元素是 $\bot$（底），最大元素是 $\top$（顶）。二元算符下界 $(\sqcap)$ 和上界 $(\sqcup)$ 具有附加性质：

> $^1$ 偏序是一种自反性、反对性和传递性关系

- 1. $a \cap (a \cup b) = a$
- 2. $a \cup (a \cap b) = a$ （吸收律）
- 3. 任何子集 $X \subseteq L$ 在 $L$ 中都有一个上界 $\sqcup X$。

很容易证明有限格始终是完全格，这对于本文的论文来说足够了。

**定义 2.4**（单调函数空间）。定义在上半格 $L = (L, \subseteq, \cap)$ 上的函数集 $F$ 是单调函数空间，当仅满足：

- 1. $id_L \in F : id_L(x) = x$ （恒等函数）
- 2. $\forall F \in F : \forall x, y : x \leq y \Rightarrow F(x) \leq F(y)$ （单调性）
- 3. $\forall F, G \in F : F \circ G \in F$ （对复合封闭）
- 4. $\forall F, G \in F : F \cap G \in F$ （逐点下界）

**定义 2.5**（数据流分析框架）。单调数据流分析框架 $A = (L, F)$ 包含：

- 1. 一个完全半格 $L = (L, \subseteq, \cap)$，其对于数据流分析的抽象值具有上界算符，以及
- 2. 一个定义在 $L$ 上的单调函数空间 $F$。

如果 $F$ 中的所有函数都是关于 $\cap$ 分配的，即 $(\forall F \in F : \forall x, y \in L : F(x \cap y) = F(x) \cap F(y))$，则单调数据流分析框架所需的解是控制流图中单调函数的全路径下界（MOP）解。对于路径 $p = (n_1, \dots, n_k)$ 的传递函数可以通过递归定义构建：

```
F_{n1,...,nk} : L → L : F_{n1,...,nk}(x) = F_nk (F_{n1,...,n_{k-1}}(x))
```

由于控制流图中无限多路径，因此没有通用的算法来计算 MOP。

**定义 2.6**（不动点）。在半格 $L$ 上的算符 $f$ 的不动点是 $L$ 中的一个元素 $x$，使得 $f(x) = x$。如果存在一次执行使得节点按照路径诱导的顺序执行，则该不动点被称为*可实现的*（realizable point）。

如果 $F$ 中的所有函数都是关于 $\cap$ 分配的，那么单调数据流分析框架的期望解是控制流图中单调函数的 MOP 解。
