The theorem can be easily transformed into an algorithm that checks for confidentiality.

**PDG-Based Confidentiality Check.** For every node in the dependency graph that has a required security level specified, compute the backward slice, and check all nodes in the slice have lower or equal security levels specified.

Once the PDG has been computed, each backward slice and confidentiality check has worst complexity $O(|N|)$. Usually, the number of nodes that have a specific security level $R(a)$ is bounded and not related to $|N|$: typically just a few outputs have statements $R(a)$. Thus overall complexity can be expected to be $O(|N|)$ as well.

Checking each node allows a simple powerful insight in the case of a security violation: if the backward slice $BS(a)$ has a provided security level that is too large or incomparable ($P(x) \ngeq R(a)$), the responsible nodes can be computed by a so-called $CH(x,a) = FS(x) \cap BS(a)$. The chop computes all nodes that are on a path from $x$ to $a$, thus it contains all nodes that may be involved in the propagation from $x$'s security level to $a$.
