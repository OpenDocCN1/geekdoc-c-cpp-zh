

## 算法 4 虚拟线程编号

```
**Input:** The call graph
**Output:** A map $\theta : method \rightarrow set$ of numbers and the maximal number of virtual threads $maxThreads$
$maxThreads = 0$
assign $\{\}$ to all root methods of the call graph
add all methods to cSDG into the worklist $changed$
**while** changed $m$ from worklist **do**
remove $m$ from worklist
**for** all $c \in caller(m)$ **do**
  **if** $m$ is redefinition of $Thread.run()$ and
    $c \in Thread.start()$ **then**
    **if** $m$'s thread may be started more than once **then**
      $\theta(m) \cup= \{maxThreads + 1, maxThreads + 2\}$
      $maxThreads += 2$
    **else**
      $\theta(m) \cup= \{maxThreads + 1\}$
      $maxThreads += 1$
    **end if**
  **else**
    $\theta(m) \cup= method(\theta(c))$
  **end if**
  **if** $\theta(m)$ has changed **then**
    add all callees of $m$ to worklist
  **end if**
**end for**
**end while**
```

public class FacThreads extends Thread {
    static int i;
    static final Int[] fac = new Int[10];

    public static void main(String[] args) {
        new FacThreads().start();
        for (int i = 0; i < fac.length; i++) {
            fac(i);

    static void fac(int n) {
        if (n <= 1)
            return setValue(n, n * fac(n - 1));
    }

    static int setValue(int n, int i) {
        synchronized (fac) {
            if (fac[n] == null) {
                fac[n] = new Int(i);
                fac.notify();
            }
            return i;
        }
    }

    public void run() {
        for (int i = 0; i < fac.length; i++) {
            synchronized (fac) {
                while (fac[i] == null) {
                    try {
                        fac.wait();
                    } catch (InterruptedException e) {}
                }
                System.out.println(fac[i].value);
            }
        }
    }

    static class Int {
        int value;
        public Int(int i) {
            value = i;
        }

> Definition 3.2. A node $r$ is interference dependent on node $d$, if $\theta(d) \neq \theta(r)$ ($d$ and $r$ may potentially be executed in parallel)
