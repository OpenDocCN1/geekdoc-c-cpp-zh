The SDG makes all side-effects visible, the actual parameters of any
call-site can be (transitively) dependent on actual-in parameters of the same
call-site. This inspiration of so-called summary edges [HRB90]\enrich the SDG. Summary edges are inserted between actual-in and actual-out
nodes of the call-site, if there exists a path in the callee between
corresponding formal parameters. These edges represent interprocedural
summary information of dependences between procedure parameters and thus
allow preservation of the calling context.

In our example in Figure 2.5, there are four summary edges in red
and dashed: from a and b of call site 4 to v, and from v and b of call site 5 to v.
These correspond to the transitive dependences between the formal parameters
x y and the statement in node 8.

With summary edges, context-sensitive slicing becomes a two-phase algo-ith is still in O(SDG). The first phase traverses all edges (including
summary edges) except for formal-out edges. Thus all dependences of
slicing's procedure and its transitive closures are included. The second
phase starts at all formal-out nodes and traverses all edges but call and
parameter-in edges, thus omitting all callers (whose effects have already been
included because of the summary edges). The context-sensitive slice is the union
of nodes encountered in both phases.

Figure 2.5 is shown in Figure 2.6. It traverses the summary edges to a

edge to v and includes the nodes x y and the entry of add (depicted in

# Computing Summary Information

Summary edges have been proposed by Horwitz et al. [HRB90] as a means
to allow context-sensitive slicing in linear time in the size of the dependence
graph. Their algorithm to compute these edges based on attribute graphs,
however, is asymptotically slower than an alternative algorithm presented by
Reps et al. [HRSR94]. An optimization of this latter algorithm, which trades
space for time in the map fragmentPath, is presented in Algorithm 2. Its worst
case complexity is in O(n⁵) where n is the size of the dependence graph. After
summary edges have been computed, each slice can be determined in linear
time.
