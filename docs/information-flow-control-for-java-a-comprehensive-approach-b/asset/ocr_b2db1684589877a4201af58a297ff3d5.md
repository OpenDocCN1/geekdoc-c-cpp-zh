# # Dependence Graphs and Slicing for Object-Oriented Languages

This chapter gives an overview of dataflow analysis, dependence graphs and program slicing, as a prerequisite for the development of the author's contributions. It does, however, not try to give a complete survey of program slicing literature, as the number of publications in this area has exploded in the last decade. A little outdated but still valuable is Tip's survey on program slicing, applications and variations can be found in [Tip95], [BG96, Dl01, HH01, BH04]. Krike [Kr03a, Kr05] gives another incomplete, but more recent picture of the slicing literature. The most recent overview probably be We will first consider procedure-less programs (the intra-procedural case) and then move to inter-procedural programs. Section 2.1 will therefore present intraprocedural dataflow analysis starting from the control flow graph and reaching definitions that allow to transform a program into static assignment format. From intermediate representation, section 2.2 describes program slicing as a program transformation technique and how to compute slices on a data structure called the dependence graph. In the second part, techniques to extend dependence graphs to programs that contain multiple procedures are discussed and how this impacts program slicing. The next section defines points to analysis and aligning, prerequisites for precise analysis of all object-oriented languages. This analysis is leveraged in section 2.4, which extends dependence graphs to features like dynamic dispatch, exception handling, and most importantly, object oriented fields. A precise analysis of interprocedural side-effects is presented in section 2.5, together with a correctness proof. This allows computation of precise data dependencies between instance fields in the presence of method calls.

A preliminary exposition of the analysis presented in this chapter was published under the title “An Improved Slicer for Java” - Christian Hammer and Gregor Sneling [HS04] at the 5th ACM SIGPLAN-SIGSOFT workshop on Program Analysis for Software Tools and Engineering 2004.
