# Constructor Definition:

```
Car :: Car ( int displacement )
{
    cout << endl << endl
         << "Object Created! Setting Displacement as"
         << displacement ;
    Displacement = displacement ;
    cout << endl << endl
         << "Displacement Set: " << Displacement ;
}
```

# Object creation in main function:

```
Car c1 (1000), c2 (2000), c3 (3000);
```

As seen, 1000, 2000, 3000 are passed as arguments to the constructor.
