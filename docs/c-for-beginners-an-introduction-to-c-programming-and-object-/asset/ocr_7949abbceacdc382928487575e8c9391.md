Let us derive the Student Class from the Person Class:

```
class Student : public Person
{
    public:

    char School [20];

    int Grade;
};
```

As seen from the above code snippet, *public* inheritance is used and hence the public members of *Person class* will be inherited into the *Student class*. The Student class now has *FirstName, LastName, City, School and Grade*. This process will internally look like the one shown in the diagram below:
