# 5. Variables and Constants

```
```cpp
#define shape "circle"
#define PI 3.14
using namespace std;
int main ( )
{
    cout << shape << endl << PI << endl;
    return 0;
}
```
```

When this code is sent for compilation, during pre-processing the values of *shape* and *PI* will be substituted wherever *shape* and *PI* appear in the code. After pre-processing, the above code will look like the following to the compiler (and not the user):

```
```cpp
using namespace std;
int main ( )
{
    cout << "circle" << endl << 3.14 << endl;
    return 0;
}
```
```
