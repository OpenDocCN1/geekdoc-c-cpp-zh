Here is a snippet to display numbers from 1 to 10 on the screen using a *for loop*:

```
```cpp
//Declare an integer variable
int number;
for ( number = 1 ; number <= 10 ; number ++)
{
    //Display number
    cout << number << " ";
}
```
```
