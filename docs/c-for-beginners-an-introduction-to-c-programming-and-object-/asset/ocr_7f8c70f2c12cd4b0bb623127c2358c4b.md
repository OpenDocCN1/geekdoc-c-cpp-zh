# 9. Functions

A function is a block of code that performs a specific task. Functions, synonymously called methods are used where a piece of code needs to be re-used. C++ standard library provides built-in functions and we can also define our own functions. There are two things to know when dealing with user defined functions – function definition and function call.

# 9.1 Function Definition

A function should be defined outside the main method. The general syntax is:

```
```cpp
<return data type> <function name> ( <parameters> )
{
    //Function Body
    //Statements...
    return <value>; //Only if the function returns a value.
}
```
```

These are the important parts of a function definition – Return Data Type, Function Name, Parameters, Function Body.
