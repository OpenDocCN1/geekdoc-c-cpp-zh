You cannot assign a string value to a string using the assignment operator after declaration. The following method is incorrect:

```
```cpp
char str [ 10 ];
```
```

If you want to assign a value to a string after declaration, you can very well set each element using the access operator ([]) as explained in Section 10 or you can use the strcpy function from the cstring header. You will need to include the cstring header in your code. strcpy is a function used to copy a string. The syntax is:

```
```cpp
strcpy    (<destination    string>    ,    <source
string/constant string>);
```
```

Refer to the following example:

```
```cpp
#include <cstring>
...
...
char str [10];
strcpy ( str, “Hello” );
```
```

This code snippet declares a character array of size 10. The strcpy function sets the value of str to “Hello”.
