# Non-Overload-able Operators:

There are only a handful of operators which cannot be overloaded. They are `-`, `*`, `::`, `?:`.

*Fun Fact:* You may have not noticed, but we have been taking advantage of operator overloading all this while. The *left shift* (`<<`) and *right shift* (`>>`) operators are overloaded to work with *cout* and *cin* as *insertion* (`<<`) and *extraction* (`>>`) operators.
