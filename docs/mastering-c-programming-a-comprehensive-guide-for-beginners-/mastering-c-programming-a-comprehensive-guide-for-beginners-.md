## 1. C 编程简介

C 语言是由 Dennis Ritchie 在 20 世纪 70 年代在贝尔实验室（Bell Labs）开发的。 它的创建是为了实现 UNIX 操作系统，从此以后成为最流行、最有影响力的编程语言之一。

**C 的主要特征：**

- 高效性：由于其低级特性，C 允许直接操作硬件。
- 可移植性：用 C 编写的程序可以轻松在不同平台之间迁移。
- 模块化：C 支持使用函数和库创建模块化程序。
- 灵活性：它提供了广泛的数据类型和运算符。

# C 递归：理解C语言编程中的递归函数

递归是一种编程技术，函数通过调用自身来解决问题。它涉及将复杂问题分解为更小、更容易管理的子问题。本指南涵盖了C语言编程中递归的原理、实现、基本情况和实际示例。

## 1 . 递归简介：

什么是递归？

递归是一个函数直接或间接调用自身的过程，通过将问题分解为相同问题的更小实例来解决。

示例：使用递归计算阶乘

```c
c code
#include <stdio.h>

// 计算阶角的递归函数
int factorial(int n){
  if(n == 0 || n == 1) {
    return 1;
} else {
    return n * factorial (n - 1); // Recursive call
}

int main() {
    int num = 5;
    int result = factorial (num);
    printf(" Factorial of %d is : %d\n", num, result);

    return 0;
}
```

-**解释**：`factorial()` 函数带有较小的值调用自身，直到达到基本情况（`n == 0` 或 `n == 1`），返回阶乘值。

## 2. 递归原理：

**递归函数的原理：**

-   **基本情况 (Base Case)**：定义停止递归调用的终止条件。
-   **问题分解**：将问题分解为更小的子问题。
-   **递归调用**：使用减少或简化的输入参数调用自身。

**示例：递归原理图解**

```c
c code
#include <stdio.h>

// 从 n 到 t 倒数的递归函数
void countdown (int n) {
  if (n <= 0) {
    return;
  } else {
    printf("%d ", n);
    countdown(n - 1); // Recursive call
  }
}

int main() {
  int startingNumber = 5;
  countdown(startingNumber);
  printf("\n");
  return 0;
}
```

-解释：`countdown()` 函数通过从给定值倒数演示了递归原理。

## 3 . 递归中的基本情况

递归中基本情况的意义：

递归中的基本情况定义了函数停止的条件。它防止了无限递归。

示例：带有基本情况的递归函数

```c
#include <stdio.h>

// 计算数字幂的递归函数
int power ( int base, int exponent ) {
    if (exponent == 0) {
        return 1; // Base case
    } else {
        return base * power ( base, exponent - 1 ); // Recursive call
    }
}

int main(){
    int baseNum = 2, exp = 5;
    int result = power(baseNum, exp);
    printf("%d raised to the power %d is : %d\n", baseNum, exp, result);
}
```

解释：`power()` 函数使用递归计算幂，在指数达到0时停止。

## 4. 递归与迭代：

递归与迭代：

递归和迭代（循环）是实现重复任务的两种方法。递归使用函数调用，而迭代使用循环结构。

示例：递归与迭代的阶乘计算

```c
#include <stdio.h>

// 计算阶乘的递归函数
int factorialRecursive(int n) {
    if (n == 0 || n == 1) {
        return 1;
    } else {
        return n * factorialRecursive(n - 1); // Recursive call
    }
}

// 计算阶乘的迭代函数
int factorialIterative(int n) {
    int result = 1;
    while (n > 1) {
        result *= n;
        n--;
    }
    return result;
}

int main() {
    int num = 5;
    int resultRecursive = factorialRecursive ( num );
    int resultIterative = factorialIterative ( num );

    printf(' Factorial using recursion : %d\n ', resultRecursive);
    printf(" Factorial using iteration : %d\n", resultIterative);

    return 0;
}
```

-解释：`factorialRecursive()` 函数使用递归，而 `factorialIterative()` 使用 while 循环计算数字的阶乘。

## 5 . 尾递归：

**尾递归：**

尾递归中，递归调用是函数执行的最后一个操作。尾递归函数可以被编译器优化以使用更少的内存。

示例：尾递归函数

```c
#include <stdio.h>

// 计算阶乘的尾递归函数

    if (n == 0 || n == 1) {
        return result; // Base case
    }
    return factorialTailRecursive(n - 1, n * result); // Tail recursive call
}
```



```c
else {
    return factorialTailRecursive (n - 1, n * result); // 尾递归
}
```

```c

    int num = 5;
    int result = factorialTailRecursive (num, 1);
    printf('Factorial of %d is : %d\n', num, result);

    return 0;
}
```

**解释**：`factorialTailRecursive()` 函数通过使用累加器（result）计算阶乘，演示了尾递归。

## 6 . 间接递归：

**间接递归：**

当函数 A 调用函数 B，而函数 B 又调用函数 A（或调用函数 C 再调用函数 A）时，就会发生间接递归。

**示例：间接递归函数**

```c

```

```c

  if (n > 0) {
    printf("%d ", n);
    functionA (n - 1 ); // 调用 functionA
  }
}
```

```c

  if (n > 1) {
    printf("%d ", n);
    functionB (n / 2 ); // 调用 functionB
  }
```

# 理解 C 结构体：全面指南

C 结构体是用户定义的数据类型，允许你将不同类型的变量组合到一个名称下。它们在组织相关数据项和在 C 语言编程中创建复杂数据结构方面非常重要。本指南将涵盖结构体的基础、语法、用法、示例和实际应用。

## 1 . C 结构体简介：

什么是结构体？

在 C 语言编程中，结构体用于在一个名称下定义一组不同数据类型的变量集合。结构体中的每个变量被称为“成员”或“字段”。结构体能够创建自定义数据类型来表示复杂的真实世界实体。

结构体的语法：

# 5 . 枚举作为标志：**

将枚举作为标志：

枚举可以作为位标志，通过位运算表示多个选项或状态。

# 示例：枚举作为标志

```c
#include <stdio.h>

enum Permissions {
  READ = 1,
  WRITE = 2,
  EXECUTE = 4
};

int main() {
  enum Permissions userPermissions = READ | WRITE;

  if (userPermissions & READ ) {
    printf(" User has read permission . \n ");
  }
  if (userPermissions & WRITE ) {
    printf(" User has write permission . \n ");
  }
  if (userPermissions & EXECUTE ) {
    printf(" User has execute permission . \n ");
  } else {
    printf(" User doesn't have execute permission . \n ");
  }

  return 0;
}
```

解释：枚举 Permissions 定义了读、写、执行权限。userPermissions 使用位或运算组合了读和写权限，并使用位与运算检查了单个权限。

```c
int binarySearch(int arr [], int l, int r, int x) {
  while (l <= r) {
    int mid = 1 + (r - l) / 2;
    if (arr[mid] == x) {
      return mid;
    }
    if (arr[mid] < x) {
      l = mid + 1;
    } else {
      r = mid - 1;
    }
  }
  return -1;
}
```

```c
#define MAX_SIZE 100
```

```c code
#include <math.h>

int isArmstrong(int num) {
    int originalNum = num, remainder, result = 0, n = 0;

    while (originalNum != 0) {
        originalNum /= 10;
        ++ n;
    }

    originalNum = num;
```

```c
void bubbleSortStrings(char arr[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        for (int j = 0; j < n - i - 1; ++j) {
            if (strcmp(arr[j], arr[j + 1]) > 0) {

                arr[j] = arr[j + 1];

            }

    }
}
```
