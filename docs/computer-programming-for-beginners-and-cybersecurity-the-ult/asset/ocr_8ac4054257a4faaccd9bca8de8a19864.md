An internal iteration is a form of declarative programming that is
fundamental to functional programming. It relieves the developer
from having to describe the “how” to do it and focuses instead on the
“what” to do.

Split iterators are designed for parallel iteration over collections. Data
is partitioned, and each chunk is handed to different threads for
parallel processing.
