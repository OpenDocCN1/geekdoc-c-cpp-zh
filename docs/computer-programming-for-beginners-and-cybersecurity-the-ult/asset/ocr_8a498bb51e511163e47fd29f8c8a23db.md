The node can store values as a simple integer, key_value, and has
two child trees —p_left, and p_right.

There are some common functions that you want on your binary
tree: inserting, searching, removing, and destroying.

```
node* insert (node* p_tree, int key);
node *search (node* p_tree, int key);
void destroyTree (node* p_tree);
node *remove (node* p_tree, int key);
```
