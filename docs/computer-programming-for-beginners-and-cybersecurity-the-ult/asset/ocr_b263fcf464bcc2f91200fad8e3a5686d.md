# ## Data Types in Python

When writing codes, we need to store data into memory. These data cannot be stored in the same memory because a number will be different from a letter. For instance, a person's name is alphabetic; address can be alphanumeric characters, whereas age can be stored as a numerical value. Python has data types to define various operations and methods of storing these data types. There are five data types in Python; these are:

+   - String
+   - Numbers
+   - Tuple
+   - List
+   - Dictionary
