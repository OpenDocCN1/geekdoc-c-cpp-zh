You can achieve this by typing two slashes and then the comment. Here is a sample.

```
```
//Place your single line comment here
```
```

You can have more than one comment line by doing either of the following:

```
```
//We are going to
//spread the comments into two
```
```

Or

```
```
/*
This comment spreads over two lines
*/
```
```

If you look at the comment above, you will notice that it starts with /* but ends with */

Additionally, if you look at the previous image (figure 8, you will notice that there are comments that begin with a single forward slash and two asterisks (/**), but end with one asterisk and one forwards slash; this is called a Javadoc comment.
