```
~~~java
public class MyRunnable implements Runnable {
    private volatile boolean active;

    public void run() {
        active = true;
        while (active) { // line 1
            // code here
        }
    }

    public void stop() {
        active = false; // line 2
    }
}
~~~
```

# # Transient

The keyword transient is used to tell the compiler to skip an instance variable when it is serializing the object that contains the marked variable.

Example:

```
~~~java
public transient int limit = 50; // will not persist
~~~
```
