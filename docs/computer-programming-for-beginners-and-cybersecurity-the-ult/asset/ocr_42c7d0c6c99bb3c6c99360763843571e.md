# How to Access Methods and Instance Variables

The created objects are used to access methods and instance variables. To access instance variables, you will use these steps:

First, you must create an object:

`ObjectName = New Constructor();`

Next, call a variable like:

`ObjectName.variableName;`

To call a class method:

`ObjectName.MethodName();`
