# ## Function pointers

Much like you can do with variables, you can also do the same with
functions; below is a snippet of code that shows a function pointer
being defined. Key sections will be highlighted:

```
~~~c
void printAddition(int value1, int value2)
{
int result = value1 + value2;
printf("The result is: %d", result);
}
int main()
{
//Function pointer definition
//<retrunType>(*<Name>)(<Parameters>)
void(*functionPtr)(int, int);
functionPtr = &printAddition;
//Invoking call to pointer function
(*functionPtr)(100, 200);
return 0;
}
~~~
```
