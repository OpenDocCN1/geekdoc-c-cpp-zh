# ## Enhanced For Loop

Java also supports an enhanced loop structure, which can be used for array elements. The syntax for this loop construct is—

```
~~~java
for(declaration : expression) {
/*Body*/
}
~~~
```

The declaration part of the Enhanced for loop is used to declare a variable. This variable shall be local to the 'for loop' and must have the same type as the type of the array elements. The current value of the variable is always equal to the array element that is being traversed in the loop. The expression is an array or a method call that returns an array.
