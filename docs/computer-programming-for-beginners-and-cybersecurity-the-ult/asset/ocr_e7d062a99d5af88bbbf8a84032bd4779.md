# # Lesson 2—Classes, Superclasses, and Programs

Java programs are made from one or more classes. Classes contain the actual program code: the instructions that, when run in sequence, perform the desired task.

Every class must name some other class as its superclass. For example, programs intended to run in a window must name some type of window class as its superclass.

In this lesson, you'll create your first class: a program that runs in a DIYWindow.
