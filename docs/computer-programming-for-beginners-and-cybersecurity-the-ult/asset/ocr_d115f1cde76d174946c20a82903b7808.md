This is the world-famous example of recursion that is used to find a factorial of a number (3 factorial is 3x2x1). It works by the recursive return statement above; it stops by hitting a return statement without a recursive definition, i.e. when x = 1, the function just returns 1; this means the stack can unwind and find an answer.
