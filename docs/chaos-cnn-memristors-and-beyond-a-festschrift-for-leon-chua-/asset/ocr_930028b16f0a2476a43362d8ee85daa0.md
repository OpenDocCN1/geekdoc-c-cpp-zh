With a single plane projection — or a first-order Poincaré map — (Fig. 23(a)), it is rather difficult to figure out that it corresponds to a toroidal chaos. But the toroidal structure characterized by an annular shape becomes obvious with a second-order Poincaré map computed by selecting points x_k ∈ [−ε; +ε]. The limit set is approached as ε → 0.

The advantage of a higher-order Poincaré map is that it allows easier identification of torus T^k. But, as mentioned by Parker and Chua, “the main drawback of the higher-order Poincaré map is that it requires an enormous amount of input data to produce a reasonable amount of output. [...] Another disadvantage is that, owing to the ε-neighborhood, the limit sets are fuzzy — a point becomes a segment and a circle becomes an annulus. This effect can be lessened by chosing a smaller value of ε, but this will increase the simulation time since more data points are required.” Such a technique was recently used to investigate non trivial toroidal chaos in a laser system [90].
