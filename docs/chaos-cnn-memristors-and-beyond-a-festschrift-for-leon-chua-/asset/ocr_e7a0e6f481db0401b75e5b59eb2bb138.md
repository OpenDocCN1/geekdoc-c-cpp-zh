# 2. The Memristor

The memristor is a 1-port described by the constitutive relations [1].

```
dq/dt = i, dφ/dt = v, φ = h(q) (charge controlled) or q = g(φ) (flux controlled) (2)
```

Setting q = q1 and φ = R1 q2 yields indeed the constitutive relations of a charge-controlled memristor:

```
dq/dt = i1, dφ/dt = v1,
φ = f(q), with f(x) = C2 R1 R2 g(x/C1) (5)
```

A similar equivalent circuit can be given for the flux controlled memristor.

The drawback of these equivalent circuits is that they use two capacitors which would suggest two state variables, namely the two charges. But by the very nature of the memristor, the charge and the flux, and therefore in the equivalent circuit the two charges are dependent and therefore there can be only one state variable. For this reason, we prefer to view the memristor as a charge or flux controlled resistor and use the constitutive relations

```
dq/dt = i, v = R(q)·i or i = G(φ)·v (6)
```

where R and G are the derivatives of the functions h and g in (2), respectively. Here only a single state variable candidate q or φ appears.
