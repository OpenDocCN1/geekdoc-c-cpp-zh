Although the application of the multilinear theory leads to accurate approximations in several cases, it is desirable to describe circuits with memristors on a more general basis. # 4.1. The Volterra series approach

Let’s assume a nonlinear system with an input function $x(t)$ and the corresponding output function $y(t)$. The Volterra series relates the input to the output function according to

$$y(t)=\sum_{n=1}^{\infty}\int_{-\infty}^{\infty}\cdots\int_{-\infty}^{\infty}h_n(\tau_1,\ldots,\tau_n)x(t-\tau_1)\cdots x(t-\tau_n)d\tau_1\cdots d\tau_n. \tag{12}$$

The index $n$ defines the so-called Volterra order and hence (12) can be imagined as a decomposition of $y$ into the output $y_n$ of homogeneous systems of order $n$. The functions $h_n(\tau_1,\ldots,\tau_n)$ denote each the Volterra kernel of order $n$.
