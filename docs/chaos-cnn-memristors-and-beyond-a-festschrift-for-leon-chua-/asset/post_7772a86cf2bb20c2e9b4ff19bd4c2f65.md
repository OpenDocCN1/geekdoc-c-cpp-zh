Globally-equivalent transformations are defined independently from the rule to which they are applied. Nevertheless, there is a weaker equivalence between rules, performed by a quasi-global transformation [19], that can be applied only to rules with a specific form. ## 3. Local Dynamics of Elementary CA Cells

### 3.1. The discrete-time dynamics of single CA cell can be described by a continuous-time nonlinear dynamical system

Cellular Automata are described as discrete-time dynamical systems; however, any computer used to simulate them is a continuous-time system with a very small, though non-zero, time scale. Therefore, it is meaningful to consider a single cell of the elementary Cellular Automaton as a continuous-time dynamical system with three binary ±1 inputs (denoted by u_{i-1}, u_i, and u_{i+1}) which are the current state of the cell itself and its two nearest neighbors, and one binary ±1 output (denoted by y_i) which is the next state of the cell. The inputs are not dependent on the continuous time t as we are analyzing what happens in the single iteration n. The internal state of the continuous-time system is denoted by x_i(t) and it is a real-valued variable of time; even though the notation is very similar, it should not be confused with the discrete-time state of the cell x_i^n at the iteration n. The initial condition is set to be x_i(0)=0. Our goal is proving that the discrete-time evolution from iteration n to iteration n+1 of the cell in position i, x_i^n -> x_i^{n+1}, which is usually considered instantaneous, can be described by a dynamical system with the form

```
dx_i/dt = f(x_i(t), u_{i-1}, u_i, u_{i+1})  (5a)
y_i(t) = g(x_i)  (5b)
```

where f and g are nonlinear functions, such that its attractors (ie, y_i(+∞)) for all possible combinations of the input encode the truth table of any elementary CA rule. In other words, given a generic rule N = (β7 β6 β5 β4 β3 β2 β1 β0)2, we desire that:

+   (u_{i-1}, u_i, u_{i+1}) = (000) => y_i = β0  (6a)
+   (u_{i-1}, u_i, u_{i+1}) = (001) => y_i = β1  (6b)
+   (u_{i-1}, u_i, u_{i+1}) = (010) => y_i = β2  (6c)
+   (u_{i-1}, u_i, u_{i+1}) = (011) => y_i = β3  (6d)
+   (u_{i-1}, u_i, u_{i+1}) = (100) => y_i = β4  (6e)
+   (u_{i-1}, u_i, u_{i+1}) = (101) => y_i = β5  (6f)
+   (u_{i-1}, u_i, u_{i+1}) = (110) => y_i = β6  (6g)
+   (u_{i-1}, u_i, u_{i+1}) = (111) => y_i = β7  (6h)

There are several choices for the functions f and g: Chua suggests the following scalar differential equation:

```
dx_i/dt = -x_i(t) + 2y_i(t) + (z2 + c1·|z1 + c0·|z0 + b0 u_{i-1} + b1 u_i + b2 u_{i+1}||)  (7a)
y_i(t) = 1/2 (|x_i(t)+1| - |x_i(t)-1|)  (7b)
```

where the parameter vector P = {b0, b1, b2, c0, c1, z0, z1, z2} ∈ R^8; it has been proved that similar results can be achieved when f is a polynomial function [20]. Each realization of P defines one elementary CA rule; however, there are infinite realizations of P implementing a specific rule N. It can be found experimentally that the choice of the values of the parameters is fairly robust for all 256 elementary CA rules. Even though we only discussed the case of elementary CA, in [4] it is proved that any rule of a binary Cellular Automaton, regardless of the spatial dimension and the neighborhood size, can be mapped into a nonlinear dynamical system whose attractors encode the associated truth table. The same paper conjectures that this result holds for Cellular Automata with an arbitrary number of states.

### 3.2. A rigorous definition of the complexity index of elementary CA rules

The attractors of the continuous-time dynamical system of Eqs. (7a) and (7b) can be written as:

```
y_i(+∞) = sgn (z2 + c1·|(z1 + c0·|z0 + b0 u_{i-1} + b1 u_i + b2 u_{i+1}|)|)  (8)
```

and, as already mentioned above, there exists a combination of the eight parameters to implement each of the 256 elementary CA rules. However, for some rules this equation can be simplified by removing one of the nested nonlinear functions, thus obtaining:

```
y_i(+∞) = sgn (z1 + c0·|z0 + b0 u_{i-1} + b1 u_i + b2 u_{i+1}|)  (9)
```
