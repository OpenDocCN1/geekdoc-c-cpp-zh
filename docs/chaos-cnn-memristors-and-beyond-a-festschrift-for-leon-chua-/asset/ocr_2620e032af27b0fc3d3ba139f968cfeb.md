# 2.1.1. Van der Pol oscillation relaxations

We point out that this generic equation describes for example the transition from slow to fast motion in the van der Pol oscillator, as shown by Dorodnitsyn [3] and recalled here briefly. The van der Pol dynamical system

```
ẍ + η(x² − 1)ẋ + x = 0,  (6)
```

is a prototype for relaxation oscillations (RO) with slow drift and fast jumps in saddle folding systems, in the limit of large non linearities (large positive η values). Using the Liénard transform y = −ẋ/η − ∫₀ˣ (x² − 1), then setting t ↦ t/η, equation (6) writes

```
⎧ ẏ = x
⎨
⎩ ẋ = −η² [ y + (x³/3 − x) ] .  (7)
```

which shows that the dominant component of the velocity field is ẋ in the limit η large. As well known the trajectory in the plane (x, y) follows in the slow phases the cubic y = x − x³/3, but becomes unstable at x = ±1, where it jumps along a line at y almost constant toward x = ±2 on the cubic. Close to the transition point (x = −1, y = −2/3), the equations of motion for δx = x + 1 small compared to one and δy = y + 2/3 write

```
⎧ δẏ = −1
⎨
⎩ δẋ = −η²(δy − δx²).  (8)
```

which have the obvious solution δy = −t + t₀, t₀ constant, taken as zero, and δẋ = η²(t + δx²). The constant η can be eliminated by taking as new time scale t ↦ η⁴/³t and new variable x ↦ δx η²/³, which gives exactly the equation (5) introduced above to describe the dynamics near a saddle node bifurcation with a drifting parameter.

# 2.1.2. Solution of the “universal” model

We look for a solution of equation (5) transiting from the “stable” fixed point at “large” negative times to the rolling down one towards positive value of x at positive times. This solution behaves like x(t) ≈ −√(−t) at large negative times. The equation (5) is of the Riccatti type and can be integrated by introducing the function y(t) such that x(t) = −y′/y where y′ = dy/dt and y(t) is a solution of Airy’s equation,

```
y'' + t y = 0.  (9)
```

The solution relevant with the given condition for x(t) at t → −∞, is Airy’s function Ai(−t) which writes

```
Y(t) = Ai(−t) = ∫₀^{+∞} cos( u³/3 − u t ) du,  (10)
```

and leads to the blue curve x(t) drawn on Fig. 2(a). The transition ends up when t becomes equal to the first zero of Airy’s function Ai(−t), corresponding to a divergence of the original function x(t).
