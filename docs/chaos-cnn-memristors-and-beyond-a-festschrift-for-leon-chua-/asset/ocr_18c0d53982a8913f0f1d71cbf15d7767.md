relationships used for normalization are

```
x = v, y = i/G, z = Gφ/C, G = 1/R, β = C/(LG²),
ω = ΩC/G = 2πνC/G, τ = Gt/C, f = Fβ. (26)
```

The bistability nature of the memristor makes the memristive MLC circuit a first order piecewise-smooth continuous system of the Filippov type [1,2], due to the discontinuity is in W(z) at z ± 1. Referring to the memductance characteristic of the memristor in Fig. 9(b), we find that the memristor switches states at z = +1 and at z = −1 either from a more conductive ON state to a less conductive OFF state or vice versa depending on how we proceed across the discontinuity boundary. Consequently the phase space can be divided into three subspaces S1, S2 and S3 due to the presence of two switching manifolds Σ1,2 and Σ2,3 defined by the zero set of the smooth functions H1(x, μ) = (1 − z), z = +1 and H2(x, μ) = (1 + z), z = −1. The memristive MLC circuit can be written as a set of smooth ODE’s

```
ẋ(t) = { F1(x, μ), H1(x, μ) ≥ 0, F2(x, μ), H1(x, μ) < 0, F2′(x, μ), H2(x, μ) ≥ 0, F3(x, μ), H2(x, μ) < 0, }.
```

with the conditions that

```
F1(x, μ) = F3(x, μ),
F2(x, μ) = F2′(x, μ). (27)
```

Here

```
F1(x, μ) = F3(x, μ) = { y − W1(z)x, −β(x + y) − f sin(ωt), x } . (28)
```

and

```
F2(x, μ) = F2′(x, μ) = { y − W2(z)x, −β(x + y) − f sin(ωt), x, } (29)
```

where W1(z) = b and W2(z) = a.
