Fig. 5. (a) Photo of the multi-chip CNN architecture for monocular orientation selective filtering. Each “Gabor Chip” board is identical, but tuned to different orientations via different biasing voltages applied to the chip. Since implementation constraints restrict the range of tune to between 0° (vertical) and 90° (horizontal), we use a flip image board, which flips the output and input images of the fourth chip horizontally using address remapping. This enables us to implement neurons tuned to 135. The chip select board pass only spikes originating from a desired chip for display. The display board connects to a VGA monitor (not shown) for visualizing the chip outputs. The logic analyzer collects spikes for analysis. (b) Measured responses of the system to a black ring presented to the silicon retina. Image on the left shows the output of the silicon retina. The image intensity encodes the difference between the spike rates of the ON and OFF neurons at each position. The eight remaining images show the outputs of the neurons on the Gabor chips. The top row shows the difference between the responses of ON and OFF neurons with even symmetric receptive fields. The bottom row shows the difference between the responses of ON and OFF neurons with odd symmetric receptive fields. White corresponds to positive differential spike rates. Black corresponds to negative differential spike rates.

This implementation contains 35,648 model neurons spread across five chips. Neurons on different chips interact with each other in continuous time and communicate their activity via spikes transmitted via AER. Within each chip, neurons interact with each other in continuous time but via graded activity encoded as currents.

Because of the continuous time operation of the CNN arrays and the asynchronous communication protocol, we have been able to implement feedback interactions between neurons serving the

same retinal location, but with different orientation tunings, even though these neurons reside on different chips [7]. These feedback interactions sharpen the orientation selectivity of the neurons.
