Using the Chua circuit (13), Chua and co-workers [74] obtained a quasi-periodic regime [Fig. 19(a)] whose Poincaré section is a regular closed loop [Fig. 19(b)] as expected. More surprisingly, they observed a folded torus, that is, a toroidal chaotic attractor (Figs. 20). Toroidal chaos produced by three-dimensional autonomous system is quite rare, and only very few examples are known [83–85]. Varying the value of the capacitance C1 allows to developed the toroidal chaotic regime [Figs. 20(b) and 20(c)]. Just before a boundary crisis leaving a single fixed point for attractor, the toroidal attractor [Fig. 20(d)] has a structure reminiscent of the double scroll attractor. When the capacitance C1 is increased, another very strange toroidal structure is obtained [Fig. 20(a)] just before a second boundary crisis. These types of toroidal chaos are not yet fully understood and remain to be more carefully investigated. Let us note that it is possible to recover parameter values reported in Table 1 from the characteristics of the electronic components as follows: α = C2/C1, β = R²C2/L, γ = RR0C2/L, a = RG_a, b = RG_b and κ = ±1 if RC2 ≥ 0. The equivalent electronic circuit is explicited in [74].

Another toroidal chaotic attractor was also found by Chua and co-workers [74]. It is shown in Fig. 21(a). It is interesting in the sense that it has a single folding (bottom right of the Poincaré section as shown in Fig. 21(b)) as the attractor solution to

the rather complicated model proposed by Bo Deng [83]. This attractor is therefore a good benchmark attractor to develop a topological analysis for three-dimensional toroidal chaotic attractors.

A “torus circuit” was investigated by Matsumoto and co-workers [86] using the governing equations

```
⎧ ẋ = −α f(y − x)
⎨ ẏ = −z − f(y − x)      (15)
⎩ ż = β z
```

where the piecewise-linear function reads as

```
f(u) = −a u + (a + b)/2 (|u + 1| − |u − 1|).      (16)
```

For some parameter values, a toroidal chaotic attractor was obtained (Fig. 22). It was shown that three mechanisms responsible for the breakdown of a torus T² are realized in the torus circuit. They are [87]

+   (i) a transition via a cascade of period-doubling bifurcation;

+   (ii) an abrupt transition to chaos in the homoclinic region via saddle-node bifurcation of a limit cycle;

+   (iii) a soft transition to chaos due to the loss of torus smoothness.
