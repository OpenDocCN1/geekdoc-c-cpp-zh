If the segments associated with eventual passivity are so far away from the inner breakpoints that the trajectory never reaches them, then the practical implementation is correctly modeled by the original Chua’s circuit equations with a symmetric three-segment nonlinearity. If the attractor is too large, it may enter the outermost regions associated with eventual passivity; this distorts the attractor [28]. Negative resistance may be produced by using a Negative Impedance Converter (NIC) terminated in a resistor [5,13]. This turns a positive resistance into a negative resistance over the linear region of operation of the NIC. The NIC itself is eventually passive and therefore exhibits breakpoints associated with the extremities of the linear region of operation of the active element. The breakpoints in the Chua diode characteristic can be implemented in a number of ways including exploiting the eventual passivity of the NIC itself or by using resistor-diode networks.

# 3.2.1. Op amp-based negative impedance converters

In the first experimental implementation of Chua’s circuit [27], the piecewise-linear nonlinear resistor was realized by connecting two NICs in parallel. One NIC provides the inner pair of breakpoints ±E, while the other provides the outer pair ±E'. The two-NIC implementation of Chua’s circuit is shown in Fig. 9.

Op amp A1 and resistors R1–R3 implement one negative resistor, op amp A2 and resistor R4–R6 implement the other one. The slopes and breakpoints of the Chua diode are defined by:

```
G_a = - R2/(R1 R3) - R5/(R4 R6)   (5)
G_b = 1/R3 - R5/(R4 R6)   (6)
G_c = 1/R3 + 1/R6   (7)
E = R1/(R1+R2) E_sat   (8)
E' = R4/(R4+R5) E_sat   (9)
```
