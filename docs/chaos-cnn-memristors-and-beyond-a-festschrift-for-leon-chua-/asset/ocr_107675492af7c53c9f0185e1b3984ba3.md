by a series of the form (6), the “charge” of the memristor can be expressed as

```
Q(t) = Q(t0) + ∫_{t0}^{t} Σ_{n=1}^{∞} α^n I_n(t') dt'
= Q(t0) + Σ_{n=1}^{∞} α^n ∫_{t0}^{t} I_n(t') dt'   (7)
= Q(t0) + Σ_{n=1}^{∞} α^n Q_n(t),
```

where Q_n(t) is the time integral over the n-th order current. For now, Q(t0) is assumed to be zero.

The incremental memristance has to be represented approximately as a Taylor series (or a suitable polynomial)

```
M(Q) = M0 + Σ_{k=1}^{∞} M_k Q^k.   (8)
```

For instance, the simple model of the memristor implementation in [13] has a memristance of this form.

By inserting (7) and (8) into V(t) = M(Q(t)) · I(t), we get

```
V(t) = M0 Σ_{n=1}^{∞} α^n I_n(t) + Σ_{k=1}^{∞} M_k ( Σ_{n=1}^{∞} α^n Q_n(t) )^k · Σ_{r=1}^{∞} α^r I_r(t) = M0 Σ_{n=1}^{∞} α^n I_n(t) + Σ_{k,r=1}^{∞} Σ_{n1=1}^{∞} ... Σ_{nk=1}^{∞} × (M_k Q_{n1}(t)···Q_{nk}(t) α^{n1+...+nk+r} I_r(t)).
```

Sorting the summands according to the exponent of α, the n-th order voltage can be obtained

```
V_n(t) = M0 I_n(t) + Σ_{r=1}^{n-1} Σ_{k=1}^{n-r} Σ_{n1,...,nk ∈ N\{0}, n1+...+nk = n−r} × (M_k Q_{n1}(t)···Q_{nk}(t) I_r(t)).   (9)
```
