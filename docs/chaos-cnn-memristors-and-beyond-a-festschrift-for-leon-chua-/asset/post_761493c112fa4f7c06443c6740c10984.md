## 1. Introduction

27 years have passed since the first observations of chaos in electronic circuits. This first chaotic attractor was discovered in Chua’s circuit [19] — very simple circuit containing two linear capacitors, one linear inductor, one linear resistor and an active nonlinear (piecewise-linear) resistor called Chua’s diode. Since then numerous theoretical and experimental studies were carried out by researchers in many laboratories around the world — chaos in electronic circuits became an independent area of research. Hundreds of publications have been published exploring various aspects of nonlinear dynamics and chaos in Chua’s circuit and its variants [5–11,16–18]. A new impact on this area of research is linked with the real implementation of the memristor concept. Last three years have brought a wide-spread interest in applications of circuits containing memristors.

This is due to the fact that after a long period since this kind of elements have been proposed by L.O. Chua [12] there has been a breakthrough in technology permitting the fabrication of microelectronic memristive devices [21,22]. In this paper we study and compare bifurcation phenomena observed in the original Chua's circuit, its variant called Chua's oscillator (with a series resistor added in series with the inductor) and three types of memristor oscillators derived from the original Chua's circuit by replacement of some elements by a suitable memristive element proposed by Itoh and Chua [15]. The circuit configurations considered are shown in Fig. 1.

## 2. Comparison of Circuit Equations

The dimension-less equations governing the prototype Chua's circuit read

```
dx/dt = α(y − f(x)),
 dy/dt = x − y + z,
 dz/dt = −βy,
```

while for the Chua's oscillator we add one term in the RHS of the first equation

```
dx/dt = α(y − x − f(x)),
 dy/dt = x − y + z,
 dz/dt = −βy,
```

In both equations the nonlinear element is a three-segment piecewise linear function

```
i_R = f(v_R)
= { m1 v_R + m1 - m0   for v_R ≤ -1
    m0 v_R            for -1 ≤ v_R ≤ 1
    m1 v_R + m0 - m1   for v_R ≥ 1 }  (3)
```

Adding to the canonical Chua’s circuit a memristive element we introduce an additional variable in the state equations describing the dynamics of the circuit — thus we have a system of four nonlinear differential equations. It should be noted however that because of the fact that one of the state variables (voltage across the capacitor) is also the voltage across the memristor, one of the equations constitutes a constraining equation for system dynamics. A thorough discussion of the state equations of memristive oscillators can be found in [4]. The state equation for the first type of memristor oscillator circuit reads

```
dv1/dt = 1/C1 (i3 - W(φ) v1),
 di3/dt = 1/L (v2 - v1),
 dv2/dt = 1/C2 (-i3 + G v2),
 dφ/dt = v1.  (4)
```

The parameters are chosen:

L = 1, C2 = 1, G = 0.65, only C1 can be varied in the interval C1 ∈ ⟨0, 0.22⟩, and in normalized form

```
x = v1,   y = i3,   z = v2,   w = φ,
α = 1/C1,   β = 1/C2,   γ = G/C2,   L = 1
```

```
dx/dt = α(y - W(w)x),
 dy/dt = z - x,
 dz/dt = -β y + γ z,
 dw/dt = x.  (5)
```

The second configuration in normal conditions is not able to generate chaotic solutions, but can behave as an oscillator when an active memristor is introduced. The circuit equations are given by

```
dv1/dt = 1/C1 (i3 - W(φ) v1),
 di3/dt = 1/L (v2 - v1),
 dv2/dt = -1/C2 i3,
 dφ/dt = v1.  (6)
```

The parameters are chosen:

L = -1 and C2 = -0.05, only C1 can be varied in the interval C1 ∈ ⟨0, 0.16⟩. In this type of configuration, many nonlinear phenomena including different types of periodic orbits, period-adding bifurcations leading to chaos can be observed. Introducing new variables

```
x = v1,   y = i3,   z = v2,   w = φ,
α = 1/C1,   β = 1/C2,   ξ = 1/L,
```

the equation can be rewritten as follows:

```
dx/dt = α(y - W(w)x),
 dy/dt = ξ(x + z),
 dz/dt = -β y,
 dw/dt = x.  (7)
```

The dynamics of the third configuration are governed by the set of equations:

```
dv1/dt = 1/C1 ( (v2 - v1)/R + G v1 = W(φ) v1 ),
 dv2/dt = 1/C2 ( (v1 - v2)/R - i ),
 di/dt = 1/L (v2 - r i),
 dφ/dt = v1.  (8)
```

This circuit will be considered with the following values of parameters:

L = 1, r = 0.35, G = 1.5 and C1 = 0.1, only C1 can be varied in the interval C1 ∈ ⟨0.06, 0.08⟩.
