The configuration that results in the fastest propagating wave is more stable than others because the wave is in the neighbourhood of the initiating grid points for the least amount of time.

The configuration in which three grid points are activated in a row (as is shown in the first example) is more stable than other configurations as it gives rise to more rapidly propagating wave fronts than other configurations. Other configurations activate grid points in the center of the neighbourhood before the wave is able to advance outward. # 5. Bursting in CAs with Heterogeneity in Cell Spacing

The bursting Greenberg-Hastings CA has several limitations when compared to real cardiac tissue. First, the CA displays artefacts associated with the underlying grid. These artefacts are apparent at neighbourhood sizes close to the base lattice spacing: simulations with small Moore neighbourhoods have planar wave fronts with sharp corners instead of smoothly curved waves. Although the use of larger neighbourhood sizes alleviate this problem, larger neighbourhoods average out asymmetries due to random activation, and therefore do not display unidirectional propagation and bursting. Second, the Greenberg-Hasting formalism doesn’t simulate local changes in cell connectivity correctly. For example, unidirectional propagation caused by asymmetries in cell loading, which is observed in real cardiac tissue [36], cannot be replicated in a CA in which an excitable cell determines activity based only on the number of neighbouring active cells. Finally, experiments in which a control parameter is continuously varied are difficult to simulate: we observed subtle dynamic changes when continuously lowering connectivity of cardiac cell networks using pharmacological agents, but connectivity in the Greenberg-Hastings CA can only be changed by integer values. We incorporated several modifications to the original formulation that address these issues.

In the original Greenberg-Hastings model all cells were on a square lattice. We employ a method first used by Marcus and Hess [30] and introduce spatial heterogeneity in the cell density by perturbing the location of each cell.
