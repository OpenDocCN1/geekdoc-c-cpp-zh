Using only nearest neighbor connections, a two layer linear CNN can implement filters that are similar to Gabor filters with $\phi=0$, except that the modulating function is not Gaussian, but decays like a Laplacian distribution. In one dimension, the filter kernel is given by

$$g(x)=\frac{\lambda}{2\alpha}\exp\left(-\frac{\lambda}{\alpha}|x|\right)\exp(j\Omega_xx)$$ (15)

While Gaussian functions are attractive theoretically, as they minimize the uncertainty relation, several studies have shown that the exact shape of the modulating function is not critical in real applications. It is possible to obtain closer approximations to Gaussian envelopes by using larger template radii.

A significant advantage of the two layer architecture is that it enables us to establish the spatially oscillatory RF profiles with a recurrent architecture with purely nearest neighbor connections between neurons. Similar RF profiles can be obtained with single layer architectures, but require second nearest neighbor connections, and would only represent one member of the pair [18].

More recent network designs execute the same filtering operation, but contain four layers, where pairs of layers represent the positive and negative half wave rectified filter outputs, which we refer to as the ON and OFF components [6]. Although the four layer network requires twice as much hardware as the two layer network, this ON-OFF representation has the same advantages in our designs as it has in biology. In biology, the ON-OFF representation is energy efficient because quiescent signals correspond to small spike rates on both ON and OFF neurons. In our analog circuits, quiescent signals correspond to small currents in the ON and OFF circuits. Thus, this architecture automatically allocates power to active neurons, while neurons with little activity dissipate little power. Another advantage is that the ON-OFF signal representation includes the half-wave rectification operation that is part of the simple cell model.

Hardware implementations of retinotopic arrays of monocular neurons tuned to different orientations, as illustrated in the left and right columns of Fig. 2, have been reported [7]. Retinotopic arrays of neurons tuned to different orientations are obtained by fanning out the output of the silicon retina to different chips. Each chip is identical, containing a four layer network with arrays of 32 × 64 neurons in a 0.25 um CMOS process [6]. They are tuned to different orientations by different values of external bias voltages applied to each chip. The analog processing components of this network are implemented using transistors operating in weak inversion for maximum energy efficiency.

In this implementation, neuronal activity within the chips is spike-encoded using arrays of silicon integrate and fire neurons, and is communicated between chips using the Address Event Representation Protocol (AER), which is an asynchronous digital protocol that signals a spike within the neuron array on the chip by placing the address of the neuron that spiked on a digital bus [14]. The time the address appears on the bus directly encodes the spike time. Simultaneous spikes are handled by an arbiter that grants sequential access to the bus. Although this will introduce some jitter into the spike times, the magnitude of this jitter is on the order of tens of nanoseconds due to the high speed of modern electronic circuits, and is therefore negligible in comparison with the time constants of biological neurons. At the input side, an address appearing on the digital bus causes a spike (current pulse) to be delivered to input of the corresponding neuron in the array. The ON-OFF signal representation is advantageous when we use this spike-based communication scheme, since neurons will have low quiescent spike rates, which reduces the traffic on the digital bus. Fan-out of spikes from the silicon retina to the different chips is implemented using routing circuit contained on each Gabor-type filtering chip [16].
