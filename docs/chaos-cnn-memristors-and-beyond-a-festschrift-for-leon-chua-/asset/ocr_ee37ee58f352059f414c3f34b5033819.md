Selecting $q_i = y^{(i-1)}(S_{i-1})$, $2 \le i \le N$, and let $\dot{\psi}(t)$ be the piecewise continuous function defined by

```
$\dot{\psi}(t) = \begin{cases} \dot{\psi}_i(t), & t \in [S_i,T_i], \ 1 \le i \le N, \\ 0, & \text{otherwise.} \end{cases} \quad (40)$
```

Then we have

```
$S(t,\dot{\psi})q_0 \in B(p_i,\epsilon/2),$ $t \in [T_i,S_{i+1}], \quad 1 \le i \le N,$
```

By Lemma 4, the set

```
$\left\{\omega : \sup_{t\in[0,T]} |S(t,\dot{\psi})q_0 - \phi(t,\omega)q_0| < \epsilon/2 \right\}, \quad (41)$
```

has positive probability, which implies the set

```
$\Omega' := \{\omega : \phi(t,\omega)q_0 \in B(p_i,\epsilon_i), \ t \in [T_i,S_{i+1}], \ 1 \le i \le N\}, \quad (42)$
```

has $\mathbb{P}(\Omega') > 0$. The proof is complete.
