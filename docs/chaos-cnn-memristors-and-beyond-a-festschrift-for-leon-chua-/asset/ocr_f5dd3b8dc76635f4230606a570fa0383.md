Bergson’s view on time can find analogies in the dynamical behavior occurring in chaotic systems. In the definition of strange attractors [4, 5], one of the key elements beyond the topologically transitivity and sensitive dependence on initial conditions, is the fact that points in the attractor are dense. This concept seems to find an analogy in the idea of Bergson that the consciousness cannot pass two times through the same identical state. Starting from these considerations and taking into account the importance of recurrences and related methods [6, 7] for investigating chaotic systems, we study the recurrence times of the Chua’s circuit and introduce a characteristic index showing the matching between Bergson’s conception and uniqueness of states in the chaotic Chua’s circuit.

This Chapter is organized as follows. In Sec. 2 the definition of the characteristic index for recurrence is discussed. In Sec. 3 the experimental setup is briefly described. In Sec. 4 the results of the calculation of this index on the Chua’s circuit are reported. In Sec. 5 conclusions are drawn.

# 2. The Average Recurrence Time

Let us consider a chaotic dynamical system defined by

```
ẋ = f(x)
```

with x ∈ ℝⁿ and f : ℝⁿ → ℝⁿ. Let us consider a time series x(tᵢ) (i = 1, …, N) extracted by the solution of system (1) with initial conditions x(t₀). Let us then take into account a general point x̄ᵢ = x(tᵢ) of the trajectory. We start from this point and look when the trajectory comes sufficiently close to x̄ᵢ. More rigorously, let us consider the following condition:

```
‖x(tⱼ) − x̄ᵢ‖ < r
```

where ‖·‖ is the Euclidean norm and r > 0. This relationship will be in general satisfied for some j = 1, …, M, from which recurrence times can be defined as:

```
τᵢⱼ(r) = { tⱼ − tᵢ   if j = 1
           tⱼ − tⱼ₋₁ if j = 2, …, M }
```

We then define the average recurrence time as a function of the radius r as follows:

```
τ(r) = 1/N Σᵢ₌₁ᴺ 1/M Σⱼ₌₁ᴹ τᵢⱼ(r)
```

This parameter is characteristic for each given chaotic attractor. We calculated it, numerically and experimentally, for the Chua’s circuit [8, 9] with respect to different values of the parameter α.

# 3. Experimental Setup

The Chua’s circuit represents one of the first examples of an autonomous physical system exhibiting chaos [8]. The circuit was deliberately designed to exhibit aperiodic irregular waveforms. The circuit can be described by the following dimensionless equations:

```
⎧ ẋ = α[y − x − h(x)]
   ẏ = x − y + z
   ż = −βy − γz
```

with h(x) = m₁x + 0.5(m₀ − m₁)(|x + 1| − |x − 1|). For α = 9, β = 14.286, γ = 0, m₀ = −1/7, m₁ = 2/7 the so-called double scroll chaotic attractor is obtained. By varying the parameter α different behaviors can be obtained. In particular, in the following we have considered a single scroll attractor obtained for α = 8.6, two different limit cycles obtained for α = 7.2 and α = 8.1 and another double scroll attractor obtained for α = 10.

The analysis carried out in this Chapter is based on numerical integration of Eqs. (5), but also on real experiments conducted on a Chua’s circuit.
