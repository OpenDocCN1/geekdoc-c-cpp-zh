# 3. Mutators

The mutator is another highly original and fundamental creation of Chua [3] for synthesizing and building any 2-terminal nonlinear inductor and nonlinear capacitor from 2-terminal nonlinear resistors [3]. It has since been generalized to synthesize any memristor [4] as well as any α − β circuit elements [12]. The basic concept of the mutator is first presented in Section II of [2], which we reproduce below:

The mutator is an active, two-port linear network for transforming one type of nonlinear network element into another type. There are three classes of mutators-an L-R mutator, a C-R mutator, and an L-C mutator. An L − R mutator is characterized by the property that if a nonlinear resistor with a v − i curve Γ is connected across port two of this element, the resulting one-port network (seen across port one) becomes a nonlinear inductor in the sense that it can be characterized by a φ − i curve, or by an i − φ curve, which is identical to the original v − i curve Γ. In the case where the φ − i curve is identical to Γ, the element is called a type 1 L-R mutator. If the i − φ curve is identical to Γ, the element is called a type 2 L − R mutator.e Conversely, if a nonlinear inductor with a φ − i curve Γ (or i − φ curve Γ), is connected across port one of a type 1 (or type 2) L − R mutator, the resulting one-port network (seen across port two) becomes a nonlinear resistor whose v − i curve is identical to Γ. In view of this two-way mutation property, the mutator is said to be a reversible two-port.
