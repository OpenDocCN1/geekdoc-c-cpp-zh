The value of β in the output feedback cloning template and the filter center frequency Ω_t in Eq. (5) are related by Ω_t = β/τ.

This cell circuit has been implemented in a 1.5μm CMOS process as described in [22]. The time constant τ and spatial frequency tuning Ω_t are adjustable via externally applied bias voltages. Internally, the spike trains are integrated to produce continuously varying currents, which are filtered using log-domain filter circuits constructed from CMOS transistors operating in weak inversion, where the low current levels enable us to obtain tunings and time constants on the order of tens of hertz, consistent with the temporal frequency tuning of real cortical cells.

The final step in the CNN architecture shown in Fig. 2 is to combine the monocular responses to create neurons selective to binocular disparity. According to (12), this can be done at each spatial location separately. Thus, the CNN array implementing disparity selective cells consists of a four layer array of cells which are decoupled both spatially and across layers. The CNN dynamics reduce to leaky integration at each layer and spatial position.

The disparity selectivity of the cells is not adjusted by altering the dynamics of the CNN array, but by altering which outputs from the two eyes are combined. According to (13), the disparity tuning can be changed by introducing either a position shift or a phase shift between the two monocular receptive fields. Because neuron outputs from different positions and different phases are all encoded on a single AER bus, we can use address remapping circuits to select different combinations of monocular outputs, and thus alter the disparity tuning. A position shift can be implemented by adding a horizontal offset to the address of spikes coming from the left or right eye orientation selective filter chips. A phase shift can be implemented by changing the way in which the four filter outputs at each pixel from the left and right eye orientation selective chips are combined. To implement a zero phase shift, corresponding outputs from the left and right eye are combined at each layer, i.e. left eye e+ outputs are combined with right eye e+ outputs and so on. ## 4. Summary

We have described a unified CNN architecture that can be used to build silicon neurons that mimic the multi-dimensional selectivity of visual cortical neurons along six stimulus dimensions. The feasibility of this CNN architecture has been validated through working hardware prototypes built using full custom mixed analog digital circuits. In order to support fully continuous time interactions between neurons and allow the possibility for real-time feedback, the architecture can be implemented by distributing computation across multiple chips, each containing a multi-layer CNN array and communicating via voltage pulses analogous to neural action potentials (spikes).
