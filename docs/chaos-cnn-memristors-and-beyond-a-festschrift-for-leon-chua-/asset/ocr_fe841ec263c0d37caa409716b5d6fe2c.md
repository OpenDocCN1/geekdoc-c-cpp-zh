# Definition 7. Suppose $S \in st_0(\Gamma_{\mathcal{F}})$. Let

$\mathcal{X}_S\mathcal{F} = \left(\bigoplus_{j\in\mathcal{I}_S} \mathcal{X}_S\mathcal{F}_j\right) \oplus \left(\bigoplus_{\substack{\underline{\gamma}\in\mathcal{A}_S(\mathcal{F})\\1<i<|\underline{\gamma}|}} \mathcal{X}_S\mathcal{F}_{i:\underline{\gamma}}\right)$.
and
$X_S = \left(\bigoplus_{j\in\mathcal{I}_S} X_j\right) \oplus \left(\bigoplus_{\substack{\underline{\gamma}\in\mathcal{A}_S(\mathcal{F})\\1<i<|\underline{\gamma}|}} X_{i:\underline{\gamma}}\right)$.

For the function $\mathcal{X}_S\mathcal{F}: X_S \to X_S$ the dynamical network $(\mathcal{X}_S\mathcal{F}, X)$ is called the dynamical network expansion of $(\mathcal{F}, X)$ with respect to $S$.

# Example 3. Consider the dynamical network $(\mathcal{F}, X)$ where

$\mathcal{F}(\mathbf{x}) = \begin{bmatrix} \mathcal{F}_1(x_1,x_2) \\ \mathcal{F}_2(x_1,x_3) \\ \mathcal{F}_3(x_2,x_3) \end{bmatrix}$.

The network has the graph of interactions $\Gamma_{\mathcal{F}} = (V,E)$ shown in Fig. 1 (left). Moreover, the set $S = \{v_1, v_3\}$ is a complete structural set of $\Gamma_{\mathcal{F}}$. To see this note that the cycles of $\Gamma_{\mathcal{F}}$ form the set $\{v_1,v_1;v_3,v_3;v_1,v_2,v_1;v_1,v_2,v_3;v_3,v_2,v_1;v_3,v_2,v_3\}$ As (i) each cycle of $\Gamma_{\mathcal{F}}$ contains either $v_1$ or $v_3$ and (ii) each vertex in $V$ belongs to the path $v_1,v_2,v_3$ then $S \in st_0(\Gamma_{\mathcal{F}})$. Hence, the expansion $(\mathcal{X}_S\mathcal{F}, X)$ is well defined.

To construct this expansion we first consider the components of $\mathcal{F}$ indexed by $\mathcal{I}_S = \{1,3\}$. For $\mathcal{F}_1 = \mathcal{F}_1(x_1,x_2)$ note that the variable $x_2$ is indexed by an element not in $\mathcal{I}_S$. Hence, $\mathcal{F}_{\langle1,1\rangle} = \mathcal{F}_1(x_1,x_{21})$. Replacing $x_{21}$ by the function $\mathcal{F}_{2;21} = \mathcal{F}_2(x_{121},x_{321})$ yields $\mathcal{F}_{\langle1,2\rangle} = \mathcal{F}_1(x_1,\mathcal{F}_2(x_{121},x_{321}))$. Since each variable of $\mathcal{F}_{\langle1,2\rangle}$ is indexed by a sequence beginning with an element of $\mathcal{I}_S$ then $\mathcal{X}_S\mathcal{F}_1 = \mathcal{F}_1(x_1,\mathcal{F}_2(x_{121},x_{321}))$. Similarly, the function $\mathcal{X}_S\mathcal{F}_3$ can be shown to be $\mathcal{X}_S\mathcal{F}_3 = \mathcal{F}_3(\mathcal{F}_2(x_{123},x_{323}),x_3)$.

Note that the set $\mathcal{B}_S(\Gamma_{\mathcal{F}}) = \{v_i,v_i;v_i,v_2,v_i;v_i,v_2,v_j : i,j \in \mathcal{I}_S\}$ implying $\mathcal{A}_S(\mathcal{F}) = \{121,123,321,323\}$. Then for any $\underline{\gamma} \in \mathcal{A}_S(\mathcal{F})$ there is a single function $\mathcal{X}_S(\mathcal{F}_{2:\underline{\gamma}})$ corresponding to $\underline{\gamma}$ given by $\mathcal{X}_S\mathcal{F}_{\underline{\gamma}}(x_i) = x_i \quad \text{for}\quad \underline{\gamma}=i,2,j.$

By Definition 7 the expansion $\mathcal{X}_S\mathcal{F}$ is given by $\mathcal{X}_S\mathcal{F}(\mathbf{x}) = \begin{bmatrix} \mathcal{X}_S\mathcal{F}_1(x_1,x_{121},x_{321}) \\ \mathcal{X}_S\mathcal{F}_3(x_{123},x_{323},x_3) \\ \mathcal{X}_S\mathcal{F}_{121}(x_1) \\ \mathcal{X}_S\mathcal{F}_{123}(x_1) \\ \mathcal{X}_S\mathcal{F}_{321}(x_3) \\ \mathcal{X}_S\mathcal{F}_{323}(x_3) \end{bmatrix} = \begin{bmatrix} \mathcal{F}_1(x_1,\mathcal{F}_2(x_{121},x_{321})) \\ \mathcal{F}_3(\mathcal{F}_2(x_{123},x_{323}),x_3) \\ x_1 \\ x_1 \\ x_3 \\ x_3 \end{bmatrix}$ (6)

where $X_S = (X_1 \oplus X_3) \oplus (X_{121} \oplus X_{321} \oplus X_{123} \oplus X_{323})$ The graph of interactions $\Gamma_{\mathcal{X}_S\mathcal{F}}$ is shown in Fig. 1 (right).

A natural question to ask is whether the expansion $(\mathcal{X}_S\mathcal{F}, X_S)$ and the initial (real) dynamical network $(\mathcal{F}, X)$ have similar dynamics.

# Theorem 2. Suppose $(\mathcal{X}_S\mathcal{F}, X_S)$ is a dynamical network expansion of $(\mathcal{F}, X)$. If $(\mathcal{X}_S\mathcal{F}, X_S)$ has a globally attracting fixed point then $(\mathcal{F}, X)$ also has a globally attracting fixed point.

In particular, suppose $\mathbf{y}_S \in X_S$ is a globally attracting fixed point of $(\mathcal{X}_S\mathcal{F}, X_S)$. Then the globally attracting fixed point $\mathbf{y} \in X$ of $(\mathcal{F}, X)$ has the property $y_j = (\mathbf{y}_S)_j \quad \text{for}\quad j \in \mathcal{I}_S$ from which the other coordinates of $\mathbf{y}$ can be easily deduced.
