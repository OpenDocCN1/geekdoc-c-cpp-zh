## 1. Introduction

There is no formal “nonlinear circuit theory” until 1969 when Chua published what many researchers now regarded as a classic book entitled “Introduction to Nonlinear Network Theory” in 1969 [3]. This 949-page monumental book formally defines what is a nonlinear resistor, a nonlinear inductor, and a nonlinear capacitor, and develops the fundamental concepts, tools, and even symbols for developing a consistent, rigorous, yet elementary axiomatic theory of nonlinear circuits. For example, prior to Chua’s book, standard textbooks on linear circuit analysis routinely treated the “controlled sources” just like independent voltage

and current sources, thereby propagating numerous misconceptions. In [3], Chua showed that controlled sources are 2-ports that behave quite differently from independent sources, and should be distinguished by a symbol different from the traditional “small circles”. The “diamond” symbol Chua proposed for controlled sources has since been adopted worldwide in elementary circuit theory textbooks. Several fundamental concepts and tools first introduced and carefully illustrated in [3] have now been routinely applied. They include the concept of driving-point characteristic (DP plot), transfer characteristic (TC plot), and piecewise-linear analysis. The graphical method for deriving the DP and

TC plots of any l-port made of an arbitrary series and parallel interconnection of 2-terminal nonlinear resistors have now been widely taught and exploited for its pedagogical and intuitive appeals. For example, the fundamental theorem in CNN which allows one to understand how a CNN template could give rise to a prescribed binary CNN cell is based entirely on the DP plot and piecewise-linear method developed in [3].

The above cited nonlinear circuit concepts and tools are all of original Chua vintage.

Another truly original and extremely powerful concept first developed in [3] is the concept of the “dynamic route”, which has been exploited in numerous areas, including the CNN, and l-dimensional cellular automata [16–20]. This powerful tool allows one to determine the dynamic behavior of any nonlinear circuit or system described by a first-order nonlinear differential equation. All nonlinear circuits containing one capacitor, or one inductor, and any interconnection of nonlinear resistors belong to this class. For example, both the CNN “cell” [15], and the basic “cell” for executing Wolfram’s 1D cellular automata [16–20] belong to this class.

Another original and powerful contribution of the Chua’s classic work [3] is the design and synthesis of nonlinear circuits with prescribed characteristics, using off-the-shelf circuit components. For example, it includes designing a 1-port with a prescribed DP plot, or a 2-port with a prescribed TC plot. Many practical large-signal electronic circuits can be understood, and designed via the principles developed in [3]. They include rectifiers, limiters, voltage compensating circuits, voltage regulators, flip flops, multivibrators, harmonic generators, frequency converters, wave-shaping circuits, etc. Indeed, virtually all practical nonlinear electronic circuits, circa 1969, were unified and explained via the concepts, techniques and tools developed in [3]. What is truly amazing about this seminal book on nonlinear circuit theory is that it has not aged, since the concepts treated are fundamentals, and fundamental concepts never die.

where x is an n-dimensional “state vector”, u is an m dimensional “input vector”, many nonlinear circuits do not have a system of continuously-differentiable state equations

# Example 1. Consider the nonlinear RC network Π shown in Fig. 1(a). Let the element constitutive relations be described as follows:

```
Resistor R : i_R = h(v_R),  v_R ∈ R  (3)
```

```
Capacitor C : v_R = g(q_C),  q_C ∈ R.  (4)
```

If we choose the capacitor charge q_C as state variable, the state equation is given by

```
q̇_C = −h(g(q_C)) ≜ f(q_C),  q_C ∈ R.  (5)
```

Now suppose g(.) in (4) is bijective so that its inverse

```
q_C = q̂_C(v_C),  v_C ∈ R  (6)
```

exists. Then applying KCL and the chain rule, we obtain

```
C(v_C) v̇_C = −h(v_C),  v_C ∈ R  (7)
```

where C(v_C) ≜ d q̂_C(v_C)/dv_C is the incremental capacitance. Assuming that C(v_C) ≠ 0 for all v_C, then (5) can be rewritten as

```
v̇_C = −C⁻¹(v_C) h(v_C) ≜ f(v_C),  v_C ∈ R.  (8)
```

Note that $C$ is not voltage-controlled. In particular, its incremental capacitance $C(v_C)$ is multivalued over the interval $[5\frac{1}{3},6\frac{2}{3}]$. If we choose $v_C$ as state variable as in (6), then the state equation is defined only over 2 disjoint intervals $(-\infty,5\frac{1}{3})$ and $(6\frac{2}{3},\infty)$:

$\dot v_C=-\dfrac{v_C}{C(v_C)},$

$-\infty<v_C<5\frac{1}{3}\quad\text{and}\quad6\frac{2}{3}<v_C<\infty.$$

Since $\dot q_C=-v_C$ implies $\dot q_C>0$ whenever $v_C<0$, and $\dot q_C<0$ whenever $v_C>0$, it follows that all solutions must tend toward the equilibrium point $q_C=0$, as depicted by the “dynamic route” in Fig. 2(b) [3]. Hence, as a well-defined solution $\dot q_C(t)$ satisfying (14), in spite of the fact that the state equation (20) does not exist globally (i.e., in $\mathbb{R}$).

Since $v_C(t)=\hat v_C(q_C(t))$ is well defined, one might argue that (20) is also well defined so long as one picks the appropriate branch of the curve when numerically solving the state equation: the initial point specifies which branch applies at any time. This is in fact the way circuit simulation programs are designed, where the computation is carried out in a small neighborhood of an initial point [6]. Mathematically, $v_C$ is called a local coordinate about the initial point $v_C(t_0)$. This argument is valid at all points in the curve in Fig. 2 except at $Q_1$ and $Q_2$. Note that given any neighborhood of either point, no matter how small, the $q_C-v_C$ curve remains a multivalued function of $v_C$. This difficulty is reflected in (20) in the value of $C(v_C)$ which tends to $\infty$ at precisely these 2 points. We conclude that $v_C$ does not qualify even as a local coordinate at $Q_1$ and $Q_2$.
