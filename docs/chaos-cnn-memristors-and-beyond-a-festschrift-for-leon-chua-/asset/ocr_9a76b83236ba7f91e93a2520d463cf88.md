# 5. A Quaternionic-valued Chaotic Neuron Model

Traditional neuron models using discrete and real-valued numbers have been extended to those that use complex-valued numbers [36–39]. Generally speaking, it is also possible to use quaternions and others.

A quaternionic-valued version of the chaotic neuron model in Eq. (2) is described as follows:

```
x(t + 1) = Kx(t) − α f{ x(t) } + a,    (17)
```

where x, K, a ∈ H and α ∈ R. Referring to Georgiou and Koutsougeras [37], we define the output function f(x) as follows:

```
f(x) = x / (β + |x|),    (18)
```

where x, β ∈ H.
