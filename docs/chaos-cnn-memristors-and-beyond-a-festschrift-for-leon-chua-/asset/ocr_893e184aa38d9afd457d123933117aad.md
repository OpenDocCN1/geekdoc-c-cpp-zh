The computational cost associated with large-scale simulations can be reduced through the use of parallel computing and sparse connectivity; it then becomes possible to simulate networks composed of more than one million chaotic neurons, which become more than two millions-dimensional chaotic systems. Furthermore, we have also developed several methods for converting color images into binary codes so that the chaotic neural networks can memorize them. These methods can be used to visualize the network states by mapping them to their corresponding color images.

Such a large-scale chaotic neural network also has a large memory capacity. Thus, many patterns can be memorized by the network. The memory patterns we have analysed had associative relations among them, and formed complex network structure [24, 25]. Here, each memory pattern is considered a node in the network, and the associative relations among these patterns correspond to edges.

To introduce this kind of memory relation network (MRN) structure into the chaotic neural network model, we use hetero-associative connections [26–29]. The original auto-associative connections represent memory patterns themselves, whereas the hetero-associative connections specify the relations among these memory patterns. In addition, signal propagation through hetero-associative connections can involve some delay, as described in the Kleinfeld model [27].

The model equations are modified as follows [30]:

```
$$\eta_i(t+1)=k_f\,\eta_i(t)+\sum_{j=1}^{N}w_{ij}y_j(t)$$

$$\qquad +\beta\sum_{j=1}^{N}u_{ij}y_j(t-\tau), \tag{9}$$

$$\zeta_i(t+1)=k_r\,\zeta_i(t)-\alpha y_i(t)+a_i, \tag{10}$$

$$y_i(t+1)=f\{\eta_i(t+1)+\zeta_i(t+1)\}. \tag{11}$$
```

where $u_{ij}$ denotes the synaptic weight of the hetero-associative connection from the $j$th neuron to the $i$th one, $\beta>0$ denotes the scaling parameter of these connections, $\tau\in N$ denotes the synaptic delay, and $a_i$ denotes the sum of the threshold and the temporally constant external inputs to the $i$th neuron.

In the present model, the memory patterns used are binary ones $\{s^k_1,\ldots,s^k_N\}$ $(k=1,\ldots,K,\ s_i^k\in\{-1,1\})$. For simplicity, let us assume that each memory pattern contains an equal number of 1’s and −1’s. Then, the synaptic weights $w_{ij}$ and $u_{ij}$ are determined as follows:

```
$$w_{ij}=\frac{1}{K}\sum_{k=1}^{K}s_i^k s_j^k, \tag{12}$$

$$u_{ij}=\frac{1}{|S|}\sum_{e_{kl}\in S}s_i^k s_j^l. \tag{13}$$
```

where $S$ is the edge set of the MRN and $e_{kl}$ is the edge from node $l$ to node $k$. To reduce the computational cost, we remove some connections such that each neuron receives inputs from only $L$ neurons at random.

To visualize the network state, we use the color images shown in Fig. 5(a) as the memory patterns. The MRN of these patterns includes “one-to-many associations” [31], i.e., a node in the MRN has multiple outgoing edges.

Figure 5(b) shows the actual transition frequencies among the memory patterns. The observed transitions are divided into two types based on whether or not the transition is consistent with the structure of the MRN. We can see that most of the observed transitions are consistent with the given MRN. Furthermore, most of the edges in the MRN are realized at least once; only a small number of edges are unrealized.

Figure 6 shows a typical time series for the decoded chaotic neural network output; many stored images appear successively. The mechanism of chaotic transitions can be explained as follows. Note that the strength of the hetero-associative connections $\beta$ is small; therefore, the auto-associative connections dominate the dynamics, especially when a particular memory pattern is almost accurately retrieved. However, the network state becomes disordered again due to the accumulated refractoriness, where the influence of the auto-associative connections may be canceled out. At that point, the hetero-associative connections are effective because of the synaptic delay; therefore, they can lead the network dynamics to the next memory pattern. Thus, the hetero-associative connections induce nearly equal biases to all the candidate memory patterns for the next transition, and the chaotic dynamics chooses one memory pattern among them.
