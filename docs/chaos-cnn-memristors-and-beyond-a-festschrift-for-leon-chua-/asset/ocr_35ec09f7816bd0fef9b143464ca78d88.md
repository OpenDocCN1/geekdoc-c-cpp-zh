where β = C/LG², ν = GRₛ and f = Fβ/Bₚ. Here

h(x) = { bx + a - b,  x ≥ 1

# 2.1. Explicit analytic solutions and period doubling route to chaos

The dynamical equations (5) can be equivalently written as a second order linear differential equation with discontinuous right hand side:

```
ẍ + β(1 + ν)ẋ + βx - f sin ωt = Δᵢ(t, x, ẋ), i = 1, 2, 3,  (7)
```

where Δ₁ = -bẋ - βb(1 + ν)x - β(1 + ν)(a - b), in D₀{x > +1}  (8a)

given as x(t) = C₀,±¹ exp(α₁t) + C₀,±² exp(α₂t) + E₁ + E₂ sin ωt + E₃ cos ωt,  (10)

where C₀,± are arbitrary constants in the corresponding regions D₀, D±₁. The other parameters are given by α₁ = [-A + √(A² - 4B)]/2, α₂ = [-A - √(A² - 4B)]/2,  (11a)

where A = β(1 + ν) + μ, B = β(1 + μ(1 + ν)), μ = a in D₀ and μ = b in D±₁  (11b)

and E₁ = 0 in D₀, E₁ = ∓β(1 + ν)(a - b)/B in D±₁, E₂ = [f(B + ω²)/(α₁² + ω²)(α₂² + ω²)], E₃ = [fAω/(α₁² + ω²)(α₂² + ω²)].  (11c)

Knowing x(t), y(t) can be evaluated from Eq. (5) as y(t) = ẋ + h(x).  (12)

Starting from the given initial conditions x(0) and y(0) in a given region, say D₀, the arbitrary constants C₀¹ and C₀² can be fixed. Then as the system evolves, the variable x(t) may cross one of the boundaries, say x = +1 and enter into the region D₊₁ at a time t = T₁, provided ẋ(T₁) > 0.
