f is a nonlinear vector function, τ is a delay time, and K is a coupling matrix. It is easy to see that the anticipatory synchronization manifold r2(t) = r1(t + τ) is a solution of Eqs. (10). For appropriate choice of τ and K, this solution can be stable, i.e., the slave anticipates by an amount τ the output of the master. This phenomenon has been studied numerically for a variety of systems and justified experimentally in electronic circuits [55] and lasers [51].

Implementation of anticipating synchronization as a strategy for real-time forecasting of a given dynamics requires a design of coupling schemes with a possibly large anticipation time. The analysis performed in [53] shows that the scheme (10) with a diagonal matrix K is ineffective. Its maximum stably anticipation time is much shorter than the characteristic time scales of the system’s dynamics. In order to enlarge the prediction time it was proposed to extend Eq. (10b) with a chain of N unidirectionally coupled slave systems [54]:

```
ṙ_i = f(r_i) + K[r_{i-1} - r_i(t - τ)],   i = 2, ..., N + 1. (11)
```

Formally, the prediction time of this scheme is N times larger as compared to the scheme (10b). However, it was shown that the chain (11) is unstable to propagating perturbations, and this convective-like instability limits the number of slaves in the chain which can operate in a stable regime [25].

Recently, we addressed the question, whether it is possible to considerably prolong the prediction time via a suitable choice of the coupling matrix K and for typical low-dimensional chaotic systems, we gave a positive answer [39,42]. In the next two sections, we briefly outline our ideas. We describe two algorithms of design K based on the scheme (10) with the single slave system. In Sec. 3.2, we show that using the idea of phase-lag compensating coupling (PLCC), the prediction time can be enlarged several times in comparison to the diagonal coupling. In the Sec. 3.3, we describe an extended PLCC (EPLCC) algorithm that allows us to prolong the anticipating time to the characteristic period of chaotic oscillations.

# 3.2. Phase-lag compensating coupling

First, we demonstrate a heuristic idea of the PLCC algorithm with the Rössler system [45], which is given by a three-dimensional (3D) vector variable

r = [x, y, z] and vector field

```
f(r) = [-y - z, x + ay, b + z(x - c)]. (12)
```

In the following, we set a = 0.15, b = 0.2, c = 10 and suppose that both r and f are the vectors columns. Although the Rössler system has two fixed points, the strange attractor originates from one of them, r0 = [(c - s)/2, (s - c)/2a, (c - s)/2a], located close to the origin, where s = (c² - 4ab)^{1/2}. The fixed point is a saddle-focus with an unstable 2D manifold (an unstable spiral) almost coinciding with the (x, y) plane and a stable 1D manifold almost coinciding with the z axis. The phase point of the system spends most time in the (x, y) plane moving along the unstable spiral according to approximate equations ẋ = -y, ẏ = x + ay. Whenever x approaches a value x ≈ c, the z variable comes into play. The phase point leaves for a short time the (x, y) plane and then returns to the origin via a stable z-axis manifold.

Taking into account such a topology of the strange attractor, we choose the coupling matrix as K = kQ, where k is a scalar parameter defining the coupling strength and

```
Q = ( cos α  -sin α  0 ; sin α  cos α  0 ; 0  0  0 ) (13)
```

is a 3 × 3 matrix that projects the vector field onto the unstable (x, y) plane and rotates this projection by the angle α = ωτ. Here ω is a frequency of the unstable spiral, which for the Rössler system is ≈ 1. The main advantage of such a choice consists in phase-lag compensation of the time-delay feedback term in Eq. (10b). When the system moves along the unstable spiral in the (x, y) plane, the vector Qr2(t - τ) is in-phase with the vector r2(t) [cf. Fig. 5], and thus the term Kr2(t - τ) provides a correct negative feedback. We refer to this coupling law as a phase-lag compensating coupling (PLCC).
