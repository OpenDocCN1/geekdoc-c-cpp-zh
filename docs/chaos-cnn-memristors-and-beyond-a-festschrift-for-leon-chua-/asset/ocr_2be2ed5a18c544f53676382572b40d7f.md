The cellular locally connected character is the basis for many neuromorphic models, literally converting real neural anatomy, their receptive fields, into cloning templates (local interaction patterns) [16,17]. This neuromorphic property can be used to generate CNN models for many sensory organs for vision, hearing, touching, etc. The key step is to convert the receptive field organization into a local interaction pattern defined by the cloning template of CNN, an obvious strength of this prototype architecture.

During the first few years of the 1990s, about a hundred various templates had been developed for different purposes, including visual, logic, PDE operators, as well as mathematical morphology, etc. [18].

Non-standard CNNs became important soon, by introducing nonlinear and delay templates, as well as space varying and adaptive templates [19].

Stability studies were important right from the beginning. Moreover, it turned out soon that analytic properties of CNN dynamics, depending on the templates, will be a vital condition to design stored programmable spatial-temporal computers. The issue is that under various initial and boundary conditions the feedback template defines the analytic properties, including stability and the maximal value of state variables.

The first challenge was to study various non-reciprocal CNN Templates, in particular when the feedback template (A template) is not centrally symmetric. The first result [14] showed that sign symmetry and positivity of the off diagonal elements in the template or the system matrix might lead to completely stable systems. This result was later generalized to many equivalent conditions [22]. Several other important results and analytic tools were published in [23–28].

A few non-stationary state patterns were soon discovered by some other template classes. A two cell chaotic behavior, and more general chaotic attractors were identified [29, 30]. An oscillating behavior was used to detect some patterns (e.g. edges) by the onset of oscillating cells [31], and an array of Chua’s circuits were formed by a special template [32] and elementary spatial/temporal interaction, inspired by ant colonies was generated [33].

# 4. Inventing the Stored Programmable Spatial-temporal Computer: The CNN Universal Machine (CNN-UM) and the Cellular Wave Computer

The lesson learned from the practical limitations of any fixed program array processors with well defined cells and interconnections, as well as the need of the precedence of locality to make the architecture silicon-friendly, became soon clear. The role of stored programmability or algorithmic programmability in the digital computer was also clear from John von Neumann. To overcome the lack of stored programmability, another way of thinking was applied [5], combing analog/arithmetic array dynamics and logic. The new stored programmable spatial-temporal Machine, the CNN Universal Machine [6] became a fruitful paradigm. The basic idea is independent of technology, though silicon technology was considered as the main target platform.

The core of the cell array is a CNN architecture, each cell is extended by local analog/arithmetic and logic memories and a local communication and control unit connected to a Global Analog-and-logic Control Unit of the Global Analog-and-logic Program Unit. The latter contains also 3 registers for storing (and sending) the templates, the local logic operators, and the switch configurations defining and changing the local extended cell configuration (operating mode). Herewith, elementary instructions defined by spatial-temporal CNN dynamics can be used in a stored program algorithm. The optional local logic unit and local analog/arithmetic unit takes the values from the local memories, and places the results to them, respectively.

This architecture is a minimal architecture to make universal machine, universal in the logic universe, as a Turing Machine, and also as a nonlinear operator on topographic image flows. The algorithms running on this cellular wave computer can be defined formally as the so called alfa-recursive functions, as a counterpart of the mu-recursive functions for digital computers.
