| Circuit element | Replacement by *n*-th order model | Details |

| Independent current source, $I(t)$ is given [10] | $n=1$: $I(t)$; $n>1$: open circuit | first order: no change; higher orders: open circuit |

| Nonlinear capacitor, $V(t)=\sum_{k=1}^{\infty}S_k Q^k(t)$ [10] | $n=1$: $C=1/S_1$; $n>1$: voltage source $V_{En}(t)$ in series with $C$ | $V_{E1}(t)=0$; $V_{E2}(t)=S_2 Q_1^2(t)$; $V_{E3}(t)=2S_2 Q_1(t)Q_2(t)+S_3 Q_1^3(t)$ |
| Nonlinear inductor, $V(t)=\dot{\Phi}(t)$, $\Phi(t)=\sum_{k=1}^{\infty}L_k I^k(t)$ [10] | $n=1$: $L_1$; $n>1$: voltage source $V_{En}(t)$ in series with $L_1$ | $V_{E1}(t)=0$; $V_{E2}(t)=\frac{d}{dt}L_2 I_1^2(t)$; $V_{E3}(t)=\frac{d}{dt}\left(2L_2 I_1(t)I_2(t)+L_3 I_1^3(t)\right)$ |
| Memristor, $V(t)=M(Q(t))I(t)$, $M(Q)=\sum_{k=0}^{\infty}M_k Q^k$ (Section 3.2) | $n=1$: $M_0$; $n>1$: voltage source $V_{En}(t)$ in series with $M_0$ | $V_{E1}(t)=0$; $V_{E2}(t)=M_1 Q_1(t)I_1(t)$; $V_{E3}(t)=M_1 Q_2(t)I_1(t)+M_2 Q_1^2(t)I_1(t)+M_1 Q_1(t)I_2(t)$ |

For the first three orders $n$, we get

\[
V_1(t)=M_0I_1(t),
\]

\[
V_2(t)=M_0I_2(t)+\left(M_1Q_1(t)I_1(t)\right),
\]

\[
V_3(t)=M_0I_3(t)+\left(M_1Q_2(t)I_1(t)+M_2Q_1^2(t)I_1(t)+M_1Q_1(t)I_2(t)\right).
\]

It can be seen that $V_n(t)$ is the sum of $M_0$ times the *n*-th order current and a term in parentheses, which does not depend on any quantity of order $\ge n$. The *n*-th order memristor model therefore is a linear resistor $M_0$, connected in series with a time-dependent voltage source (see Table 1).

## 3.3. *CM-circuit*

For the sake of simplicity it is assumed that the capacitor in the CM-circuit (Fig. 6) is linear, and that the memristance is given as

\[
M(Q)=M_0+M_1Q\quad\text{with }M_0C>0.
\]

![img/039e7d3c23390584a66737067db8b75b_545_0.png](img/039e7d3c23390584a66737067db8b75b_545_0.png)

*Fig. 6.* Schematic diagram of a CM-circuit.

The circuit shall be excited by an independent sinusoidal voltage source

\[
V_S(t)=\hat V_S\cos(\omega_0t+\varphi_{V_S}), \tag{10}
\]

and we want to calculate the current $I(t)$ through the memristor.

Furthermore, $Q(t)=Q_C(t)$ is assumed where $Q_C(t)$ denotes the charge of the capacitor. Then,

![img/039e7d3c23390584a66737067db8b75b_546_0.png](img/039e7d3c23390584a66737067db8b75b_546_0.png)

the resulting system has an attractive fixed point $Q_{\mathrm{FP}}=0$ for $V_S(t)\equiv0$. Thus, for sufficiently small $Q(0)$, the circuit with $Q_C(t)=Q(t)$ and no excitation has unique asymptotic behavior. We assume that is true for the excited circuit. Consequently, we disregard the transient response, and calculate the steady state current only. (However, if $Q(0)-Q_C(0)$ was nonzero, $Q(t)$ would follow $Q_C(t)$ with a constant offset, i.e. it would act as a “shadow state”. The analysis of the system therefore would be slightly different.)

#### First order circuit

First, the circuit elements in the above mentioned circuit have to be replaced by their individual first order models, which can be taken from Table 1. The resulting first order circuit is shown in Fig. 7.

As the first order circuit is linear, the first order current $I_1(t)$ can be determined directly. For a sinusoidal excitation $V_S(t)$ with the angular frequency $\omega_0$, the current $I_1(t)=\hat{I}_{1,\omega_0}\cos(\omega_0t+\varphi_{I_1,\omega_0})$ must be sinusoidal, too. Employing the transfer function

\[
G_1(j\omega)=\frac{I_1}{V_S}=\frac{1}{M_0-j/(\omega C)},
\]

the amplitude $\hat{I}_{1,\omega_0}$ and the phase $\varphi_{I_1,\omega_0}$ of the first order current follow as

\[
\hat{I}_{1,\omega_0}=\hat{V}_S\,|G_1(j\omega_0)|=\frac{\hat{V}_S}{\sqrt{M_0^2+\left(1/(\omega_0C)\right)^2}}
\]

and

\[
\varphi_{I_1,\omega_0}=\varphi_{V_S}+\arg G_1(j\omega_0)=\varphi_{V_S}+\arctan\frac{1}{\omega_0M_0C}.
\]

Integrating $I_1(t)$ with respect to time, we get

\[
Q_1(t)=\frac{\hat{I}_{1,\omega_0}}{\omega_0}\cos\left(\omega_0t+\varphi_{I_1,\omega_0}-\frac{\pi}{2}\right).
\]

#### Second order circuit

The second order circuit contains a new independent voltage source, which is a part of the memristor model (Fig. 8). The voltage $V_{E2}(t)$ of this source has to be determined by using the results for the first order circuit.

![img/039e7d3c23390584a66737067db8b75b_546_1.png](img/039e7d3c23390584a66737067db8b75b_546_1.png)

With the abbreviation $A=\omega_0t+\varphi_{I_1,\omega_0}$, $V_{E2}(t)$ can be written as

\[
V_{E2}(t)=M_1Q_1(t)I_1(t)=\frac{M_1\hat{I}_{1,\omega_0}^2}{\omega_0}\cos(A)\cos\left(A-\frac{\pi}{2}\right)=\frac{M_1\hat{I}_{1,\omega_0}^2}{2\omega_0}\left[\cos\left(2A-\frac{\pi}{2}\right)+\cos\left(\frac{\pi}{2}\right)\right]=\hat{V}_{E2,2\omega_0}\cos(2\omega_0t+\varphi_{V_{E2},2\omega_0}).
\]

The sole excitation of the second order circuit therefore is a sinusoidal voltage with the angular frequency $2\omega_0$, and the amplitude/phase

\[
\hat{V}_{E2,2\omega_0}=\frac{M_1\hat{I}_{1,\omega_0}^2}{2\omega_0},\qquad
\varphi_{V_{E2},2\omega_0}=2\varphi_{I_1,\omega_0}-\frac{\pi}{2}.
\]

Again, a transfer function $G_2(j\omega)=-G_1(j\omega)$ is used to calculate the current $I_2(t)$. The amplitude of the second order current is

\[
\hat{I}_{2,2\omega_0}=\frac{\hat{V}_{E2,2\omega_0}}{\sqrt{M_0^2+\left(1/(2\omega_0C)\right)^2}};
\]

and it has a phase of

\[
\varphi_{I_2,2\omega_0}=\varphi_{V_{E2},2\omega_0}+\arctan\frac{1}{2\omega_0M_0C}+\pi.
\]

$Q_2(t)$ can be obtained by integrating $I_2(t)$.

#### Third order circuit

The only difference between the second and the third order circuit is the time dependent voltage source that belongs to the memristor model. Both $V_{E3}(t)$ and $I_3(t)$ can be written as the sum of two sinusoidal components with the angular frequencies $\omega_0$ and $3\omega_0$ respectively.

#### Results

To get an approximation of the current $I(t)$ in the original circuit, we just add the current of first, second, and third order leading to

\[
\begin{aligned}
I(t)&\approx\hat{I}_{1,\omega_0}\cos(\omega_0t+\varphi_{I_1,\omega_0})\\
&\quad+\hat{I}_{2,2\omega_0}\cos(2\omega_0t+\varphi_{I_2,2\omega_0})\\
&\quad+\hat{I}_{3,\omega_0}\cos(\omega_0t+\varphi_{I_3,\omega_0})\\
&\quad+\hat{I}_{3,3\omega_0}\cos(3\omega_0t+\varphi_{I_3,3\omega_0}). \tag{11}
\end{aligned}
\]

A numerical simulation was carried out using $C=1\,\mu\mathrm{F}$, $M_0=100\,\Omega$, $M_1=0.1\,\mathrm{G}\Omega\,(\mathrm{As})^{-1}$, $\omega_0=20000\,\mathrm{s}^{-1}$, $\hat{V}_S=1\,\mathrm{V}$, $\varphi_{V_S}=0.166667\,\pi$ and $Q(0)=2.5\,\mu\mathrm{As}$. In Fig. 9 it can be seen, that (after decay of the transient) the approximation obtained by using (11) is very close to a numerical simulation of the example circuit.

## 4. A General Description of Single Memristor Circuits by Means of the Volterra Series Approach

Although the application of the multilinear theory leads to accurate approximations in several cases, it is desirable to describe circuits with memristors on a more general basis. This can be achieved by introducing the so called single memristor circuits shown in Fig. 10. A general linear two-port which might be represented by its impedance matrix is coupled to a memristor and a given current source. Please note that this specific form is defined without loss of generality, i.e. a voltage source instead of the current source can be described similarly.

In the following, the Volterra series are introduced and applied to the SMC.

![img/039e7d3c23390584a66737067db8b75b_547_2.png](img/039e7d3c23390584a66737067db8b75b_547_2.png)

*Fig. 10.* The general structure of a single memristor circuit consisting of a linear two-port connected to a source and a memristor.

### 4.1. The Volterra series approach

Let's assume a nonlinear system with an input function $x(t)$ and the corresponding output function $y(t)$. The Volterra series relates the input to the output function according to

\[
y(t)=\sum_{n=1}^{\infty}\int_{-\infty}^{\infty}\cdots\int_{-\infty}^{\infty}h_n(\tau_1,\ldots,\tau_n)x(t-\tau_1)\cdots x(t-\tau_n)\,d\tau_1\cdots d\tau_n. \tag{12}
\]

The index $n$ defines the so-called Volterra order and hence (12) can be imagined as a decomposition of $y$ into the output $y_n$ of homogeneous systems of order $n$. The functions $h_n(\tau_1,\ldots,\tau_n)$ denote the Volterra kernel of order $n$. Once the kernels $h_n$ are known, it is possible to determine the correct output function corresponding to a given input. The kernels in the complex frequency domain are the Laplace transforms of the kernels in the time domain.
