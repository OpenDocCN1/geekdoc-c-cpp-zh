A four layer CNN cell can be used to implement a complex-valued temporal filter with kernel given by Eq. (11) where α = 1 [22]. To facilitate integration into the multi-chip network, this cell circuit accepts and produces four spike encoded signals, which represent the ON and OFF components of the real and imaginary parts of the inputs and outputs. The four outputs of the spatial filtering chip at each pixel can be connected directly to the corresponding inputs of the array of CNN temporal filtering cells to implement the spatio-temporal filter with spatio-temporal receptive field given by Eq. (6).

Figure 4 shows the relationship between the inputs, states and outputs of the four layer temporal filtering cell. The relationship between inputs and outputs in this cell is identical to that used in the cells of the four layer orientation selective filtering array, as given by Eqs. (28)-(31). The non-zero cloning templates for the temporal filtering array are given by

```
A_{o+e+} = A_{e-o+} = A_{o-e-} = A_{e+o-} = [β]  (32)
B_{e+e+} = B_{e-e-} = B_{o+o+} = B_{o-o-} = [1]  (33)
C_{e+e+} = C_{e-e-} = C_{o+o+}
      = C_{o-o-} = [-1]  (34)
```

The value of β in the output feedback cloning template and the filter center frequency Ω_t in Eq. (5) are related by Ω_t = β/τ.

This cell circuit has been implemented in a 1.5μm CMOS process as described in [22]. The time constant τ and spatial frequency tuning Ω_t are adjustable via externally applied bias voltages. Internally, the spike trains are integrated to produce continuously varying currents, which are filtered using log-domain filter circuits constructed from CMOS transistors operating in weak inversion, where the low current levels enable us to obtain tunings and time constants on the order of tens of hertz, consistent with the temporal frequency tuning of real cortical cells.

The final step in the CNN architecture shown in Fig. 2 is to combine the monocular responses to create neurons selective to binocular disparity. According to (12), this can be done at each spatial location separately. Thus, the CNN array implementing disparity selective cells consists of a four layer array of cells which are decoupled both spatially and across layers. The CNN dynamics reduce to leaky integration at each layer and spatial position.

The disparity selectivity of the cells is not adjusted by altering the dynamics of the CNN array, but by altering which outputs from the two eyes are combined. According to (13), the disparity tuning can be changed by introducing either a position shift or a phase shift between the two monocular receptive fields. Because neuron outputs from different positions and different phases are all encoded on a single AER bus, we can use address remapping circuits to select different combinations of monocular outputs, and thus alter the disparity tuning. A position shift can be implemented by adding a horizontal offset to the address of spikes coming from the left or right eye orientation selective filter chips. A phase shift can be implemented by changing the way in which the four filter outputs at each pixel from the left and right eye orientation selective chips are combined. To implement a zero phase shift, corresponding outputs from the left and right eye are combined at each layer, i.e. left eye e+ outputs are combined with right eye e+ outputs and so on.
