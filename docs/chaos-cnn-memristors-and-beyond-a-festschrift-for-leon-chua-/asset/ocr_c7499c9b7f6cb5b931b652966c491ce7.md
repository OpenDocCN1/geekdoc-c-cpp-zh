A practical realization of the circuit in Fig. 30 is shown in Fig. 32. Note that this implementation uses the same basic components as the original Chua’s circuit shown in Fig. 9. Negative values of resistance, capacitance, and inductance are obtained by using a negative impedance converter consisting of the op amp A1 and resistors R1 and R2. This subcircuit realizes:

```
κ = R1 / R2. (28)
```

The op amp A2 and resistors R3–R6 implement the Chua diode, whose slopes and breakpoints are defined by:

```
G_a = - R4 / (R3 R5) + 1 / R6 (29)
```

```
G_b = 1 / R3 + 1 / R6 (30)
```

```
E = R5 / (R4 + R5) E_sat, (31)
```

respectively. In the case of an LF351 op amp with ± 15 V power supplies, E_sat ≈ 13.5 V.

A remarkable property of this circuit is that it can produce chaos even when R = 0. Thus, Chua’s circuit is reduced to its simplest form, corresponding to a lossless LC network connected to a Chua diode, as shown in Fig. 33.
