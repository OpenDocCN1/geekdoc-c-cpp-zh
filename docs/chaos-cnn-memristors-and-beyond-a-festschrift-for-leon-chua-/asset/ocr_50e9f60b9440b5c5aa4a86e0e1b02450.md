Ω′ ⊂ Ω with P(Ω′) > 0 such that for ω ∈ Ω′ the trajectory of the ID process visiting each B(p_i, ε) within [0, T].

For convenience of following discussion, we denote f := −∇g, and (Ω, F, P) the Wiener space generated by Brownian motion W(t). To prove this theorem, we need some lemmas for the counterpart equation of (2):

dx = f(x)dt + σ dW,    x(0) = x0,    (24)
where σ is a constant. Denoted by φ(t, ω)x0, ω ∈ Ω the solution of (24).

# Lemma 1. Assume (H3)–(H4) hold. The solution of (24) is a global solution for all ω ∈ Ω (i.e., φ(t, ω)x0 is defined for t ∈ [0, ∞)).

Proof. Let v := x − σW, we have

dv/dt = f(v + σW).    (25)
Then, the time-derivative of g along trajectories v(t) is given by

dg(v(t))/dt = −f(v)·f(x)    (26)
= −(f(v)−f(x)+f(x))·f(x)    (27)
≤ −|f(x)|² + |f(x)||f(x)−f(v)|    (28)
≤ −|f(x)|² + L|f(x)||σW|    (29)
≤ (L|σW(t)|)²/4,    (30)
which implies
g(v(t)) ≤ g(v(0)) + ∫₀ᵗ (L|σW(s)|)²/4 ds := M(t).
Therefore v(t) is bounded by K_{M(t)} which is a bounded set. It follows that v(t) is defined for t ∈ [0, ∞), and so is x(t).

Let ψ̇(t) be a piecewise continuous function. We consider the following nonautonomous equation:

dy = f(y)dt + σ ψ̇ dt,    y(0) = x0.    (31)
Denoted by S(t, ψ̇)x0 the solution of (31).

# Lemma 2. Assume (H3)–(H4) hold. For any piecewise continuous ψ̇, the solution of (31) is a global solution (i.e., S(t, ψ̇)x0 is defined for t [0, ∞)).

# Lemma 3. Assume (H3)–(H4) hold. Given T > 0, ε > 0, x0 and q ∈ Rⁿ, there exists a piecewise continuous ψ̇(t) such that solution of (31) satisfies the boundary condition S(T, ψ̇)x0 ∈ B(q, ε).

Proof. We may assume σ = 1 for simplicity and ε < 1. Let N ∈ N and

0 := t0 < t1 < ⋯ < tN := T,
 t_i − t_{i−1} = h := T/N    (32)
q_i := x0 + i((p − x0)/N),    1 ≤ i ≤ N.    (33)
Let V be the tube centered at the line segment from x0 to q and with radius one, i.e.,

V := ⋃_{t∈[0,1]} B((1−t)x0 + t q, 1)
Let C := sup_{x∈V} |f(x)| < ∞. We are going to construct ψ(t) on each (t_i, t_i +1). According to Lemma 2 the solution are defined for t ∈ (t_i, t_i +1). For simplicity we set ψ(t_i)=0 at each t_i.

(i) On (t0, t1):
Denote q0 := x0. Let
ψ(t) := (q1 − q0)t/h, t ∈ (t0, t1)
then q0 + ψ(t) ∈ V, t ∈ (t0, t1). Therefore,
sup_{s∈(t0,t1)} |f(q0 + ψ(s))| ≤ C.
From (31) we have
y(t) − (q0 + ψ(t)) = ∫_{t0}^t f(y(s)) − f(q0 + ψ(s)) ds
+ ∫_{t0}^t f(q0 + ψ(s)) ds,
which implies
|y(t) − (q0 + ψ(t))|
≤ ∫_{t0}^t |f(y(s)) − f(q0 + ψ(s))| ds
+ ∫_{t0}^t |f(q0 + ψ(s))| ds,
≤ ∫_{t0}^t L|y(s) − (q0 + ψ(s))| ds + hC.
By Gronwall inequality, we have
|y(t1) − (q0 + ψ(t1))| ≤ hC e^{Lh} < ε/2,
provided h small. Denote by q̃1 := y(t1) ∈ V.
