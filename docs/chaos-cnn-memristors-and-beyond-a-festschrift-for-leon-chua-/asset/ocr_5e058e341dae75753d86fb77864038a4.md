We can use CNNs to compute each of the required filter outputs. Thus, the architecture can be considered to be a network of CNNs. The outputs of the binocular stages are simultaneously selective along all six stimulus dimensions. The first step of monocular processing is spatial frequency and orientation selective filtering. As discussed in the previous section, we must compute phase quadrature pairs of filter responses, which can be considered as the real and imaginary parts of a complex valued filter output. The spatial phase parameters is a free parameter, but it is only necessary to compute the pair of filter responses with φ = 0, since quadrature pairs at other phase shifts can be computed by linear combinations of these two filter responses. In addition, different values of phase parameters only alter the phase properties of the simple cell responses. There is no difference between the responses of complex cells computed from the outputs of simple cells with different phase parameters, since the complex cell outputs are combined in such a way as to make their responses phase invariant. Since the responses of complex cells are much more robust to changes in the stimulus

structure, it is likely that these complex cell outputs are what are used in further processing stages. Indeed, many biologically inspired algorithms for extracting disparity and motion information use complex cell outputs exclusively. The requirement for phase quadrature responses motivated the development of two layer linear CNN architectures for Gabor-type filtering, where each layer represents one filter output at different spatial locations [20, 21]. A multi-layer CNN array for image filtering consists of a number of two-dimensional layers of discrete cells [8]. Each cell corresponds to one pixel in the image to be filtered, and has an associated state variable, input and output.
