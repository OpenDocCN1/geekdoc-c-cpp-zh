# 4. Summary

We have described a unified CNN architecture that can be used to build silicon neurons that mimic the multi-dimensional selectivity of visual cortical neurons along six stimulus dimensions. The feasibility of this CNN architecture has been validated through working hardware prototypes built using full custom mixed analog digital circuits. In order to support fully continuous time interactions between neurons and allow the possibility for real-time feedback, the architecture can be implemented by distributing computation across multiple chips, each containing a multi-layer CNN array and communicating via voltage pulses analogous to neural action potentials (spikes).
