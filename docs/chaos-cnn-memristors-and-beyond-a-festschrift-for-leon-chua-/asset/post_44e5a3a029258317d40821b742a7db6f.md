## Theorem 1

Consider a gradient flow

ẋ(t) = −∇g(x(t)),

and its ID process generated by

dx(t,ω) = −∇g(x(t,ω))dt + σ(t)dW(t),

where σ(t) = \sum_{j=1}^N σ_j I_{[S_j,T_j]}(t). Let Q be the set of global minimizers, U a small neighborhood of Q, and X_opt the optimal solution obtained by the ID process. Then for any given ε > 0, there exist τ > 0, σ0 > 0 and N0 > 0 such that if T_i − S_i > τ, σ_i < σ0 (for i = 1,…,N), and N > N0, 𝔼(X_opt ∈ U) ≥ 1 − ε. (9)

### Proof

There are two different cases for the global minimum set Q: it has (1) Lebesgue measure 0, or (2) a positive Lebesgue measure. For instance, if Q contains one global minimum point, or finite number of global minimum points, then its measure is 0. If the global minima form a region in the space, its measure is positive. We give the proof for a simple case assuming there is one global minimum point {x*} of hyperbolic type. Since the Hessian matrix of x* is negative definite, we can always take U = B(x*,γ), a ball centered at x* with radius γ for small enough γ. For other situations including multiple global minima, a similar proof can be given with minor modifications and we will omit it in this paper.

Let us consider one segment for t ∈ [S_i, S_{i+1}] of the ID method first. Since the trajectory rests on a small neighborhood of a local minimizer at the end of each gradient descent period, we may assume x(S_i) ∈ B(q_i,γ_i), where q_i is a minimizer, and B(q_i,γ_i) a small neighborhood (ball) centered at q_i with radius γ_i. The location of x(S_i) is a random variable for different realizations, and we denote the distribution of x(S_i) as p_0^i(x), which is a continuous function compactly supported in B(q_i,γ_i). This is because p_0^i(x) is the solution at t = S_i of p_t = ∇·(∇g(x)p), with a smooth initial condition (given by the final distribution of previous segment).

For t ∈ [S_i,T_i], (7) is a diffusion process. We denote the probability density function of the trajectory x(t,ω) visiting x at time t ∈ [S_i,T_i] by p_{σ_i}(t − S_i; x; q_i), which depends on perturbation strength σ_i. It is well known that p_{σ_i} satisfies the Fokker-Planck equation given by

(p_{σ_i})_t = ∇·(∇g(x)p_{σ_i}) + ½ σ_i^2 Δ p_{σ_i}, (10)

with initial data p_0^i(x). As the solution of this linear convection-diffusion equation, p_{σ_i} ∈ C^\infty continuously depends on t > 0 and σ_i > 0.

In the classical diffusion theory, it is straightforward to verify that (10) has an equilibrium solution which is given by the famous Gibbs distribution,

\bar{p}_{σ_i}(x) = A e^{−2g(x)/σ_i^2}, (11)

where A is a constant defined by

A = (∫_{ℝ^n} e^{−2g(x)/σ_i^2} dx)^{−1}. (12)

It is used to normalize p_{σ_i} to be a probability density function. According to [17] and the references cited therein, \bar{p}_{σ_i}(x) weakly converges to a point distribution concentrated at x* as σ_i → 0. This implies that

lim_{σ_i→0} ∫_U \bar{p}_{σ_i}(x)dx = 1. (13)

We remark here that if Q has positive Lebesgue measure, then \bar{p}_{σ_i}(x) weakly converges to a uniform distribution on Q as σ_i goes to zero. In the past two decades, there are intensive studies on the convergence of p_{σ_i} to its steady state \bar{p}_{σ_i} [2,33,38]. By Holley-Stroock perturbation lemma [23], it can be shown that with conditions (H2), p_{σ_i} converges to the equilibrium solution \bar{p}_{σ_i} exponentially in the relative entropy sense, i.e.

H(p_{σ_i}|\bar{p}_{σ_i}) ≤ e^{−2λt} H(p_0^i|\bar{p}_{σ_i}),

where λ is a constant, depending on the structure of g, in the logarithmic Sobolev inequality for \bar{p}_{σ_i}, and H is the relative entropy defined as

H(p|q) = ∫ p log(p/q) dx,

for any two probability density functions p and q.

Using the Csiszar-Kullback inequality, which states ‖p − q‖_{L^1}^2 ≤ 2 H(p|q), we obtain

‖p_{σ_i} − \bar{p}_{σ_i}‖_{L^1}^2 ≤ 2 e^{−2λt} H(p_0^i|\bar{p}_{σ_i}). (14)

Because the initial distribution p_0^i on the right-hand side has compact support depending only on g(x) in a bounded region, this estimate is uniform. That is

‖p_{σ_i} − \bar{p}_{σ_i}‖_{L^1}^2 ≤ C e^{−2λt}, (15)

where C is a constant independent of the initial data p_0^i.

Let us define the attraction set of q_i as

K(q_i) = {x : (8) with x as the initial state converges to a point in B(q_i, γ)}.

Since the Hessian matrix of g(x) has negative eigenvalues near q_i, we find B(q_i, γ) ⊆ K(q_i) provided γ is small enough. Thus, for any given α ∈ (0,1) there exists σ0 such that for σ_i < σ0, (13) implies

∫_U \bar{p}_{σ_i}(x)dx > α + (1 − α)/2. (16)

Also, there exists a τ(α) such that for T_i − S_i > τ(α), (15) gives us

‖p_{σ_i}(T_i − S_i, x) − \bar{p}_{σ_i}(x)‖_{L^1} < (1 − α)/2. (17)

Therefore, by (16) and (17), we have

∫_U p_{σ_i}(T_i − S_i, x)dx ≥ ∫_U \bar{p}_{σ_i}(x)dx − ∫_U |p_{σ_i}(T_i − S_i, x) − \bar{p}_{σ_i}(x)| dx > α. (18)

This implies that

P(x(S_{i+1}) ∈ U | x(S_i) ∈ B(q_i, γ_i)) = P(x(T_i) ∈ K(x*) | x(S_i) ∈ B(q_i, γ_i)) > α, (19)

due to the fact that the ID method is deterministic on [T_i, S_{i+1}].

Let Θ be the set consisting of local minimizers of g, then

P(x(S_{i+1}) ∈ U^c) = \sum_{q_i∈Θ} P(x(S_{i+1}) ∈ U^c | x(S_i) ∈ B(q_i, γ_i)) × P(x(S_i) ∈ B(q_i, γ_i)), (20)

where U^c is the complement of U. By estimate (19), we have

P(x(S_{i+1}) ∈ U^c | x(S_i) ∈ B(q_i, γ_i)) < (1 − α) for all q_i ∈ Θ, (21)

provided (T_i − S_i) > τ and σ_i < σ0. This implies

P(x(S_{i+1}) ∈ U^c) < (1 − α) \sum_{q_i∈Θ} P(x(S_i) ∈ B(q_i, γ_i)) < (1 − α). (22)

The estimate (22) can be made for all segments i = 1,2,…,N uniformly. We remark that the estimate (22) is independent of which neighborhood B(q_i, γ_i) the x(S_i) will lie in. Since x(S_i) must lie in some B(q_i, γ_i), if we repeat it for all intervals [S_j, S_{j+1}], j = 1,…,N, with the same fixed α, then the probability that the solution X_opt of the ID method does not belong to U satisfies,

P(X_opt ∈ U^c) = P(\bigcap_{i=0}^N \{x(S_i) ∈ U^c\}) < (1 − α)^N.

For any given ε ∈ (0,1), there exists N0 > 0, such that for N ≥ N0, P(X_opt ∈ U^c) < (1 − α)^N < ε, which is equivalent to (9).

It is easy to obtain the following statement from the proof.

## Corollary 37.1

Assume the probability of attaining an approximation in U, a small neighborhood of the global minimizer x*, in one segment of the ID process is α ∈ (0,1), and there are N segments, then the best approximation X_opt obtained by the ID method satisfies

P(X_opt ∈ U) ≥ 1 − (1 − α)^N. (23)

Furthermore, if we pick α ≥ 1/2 in the proof, it implies that x(S_{i+1}) has larger probability in U than in the neighborhoods of other local minimizers.

We summarize this extension in the following theorem.

## Theorem 2

Consider the ID process for the gradient flow stated in Theorem 1. If 0 < γ ≪ 1, then

P(x(S_{i+1}, ω) ∈ U) ≥ P(x(S_{i+1}, ω) ∈ B(q_j, γ)),

where q_j is any local minimizer, provided T_i − S_i is large and σ_i small enough.

We remark that the ID method indicates the convergence is monotone with respect to the number of segments N. And the convergence rate is a geometric series based on the factor α. The following theorem reveals more properties of the ID method.

## Theorem 3

Consider the ID method for the randomly perturbed gradient flow (2) and suppose that g ∈ C^2 satisfies (H2) and the following conditions:

- (H3) \lim_{|x|\rightarrow\infty} g(x) = ∞.
- (H4) ∇g has a Lipschitz constant L on ℝ^n.

Given 0 < ε, T > 0 and any finite sequence {p_i}_{i=1…N} of local minimizers of g, there exists Ω′ ⊂ Ω with P(Ω′) > 0 such that for ω ∈ Ω′ the trajectory of the ID process visits each B(p_i, ε) within [0, T].

For convenience of the following discussion, we denote f := −∇g, and let (Ω, F, P) be the Wiener space generated by Brownian motion W(t). To prove this theorem, we need some lemmas for the counterpart equation of (2):

dx = f(x)dt + σ dW,    x(0) = x0,    (24)

where σ is a constant. Denote by φ(t,ω)x0 the solution of (24) for ω ∈ Ω.

Let \dot{\psi}(t) be a piecewise continuous function. We consider the following nonautonomous equation:

dy = f(y)dt + σ \dot{\psi} dt,    y(0) = x0,    (31)

Denote by S(t, \dot{\psi})x0 the solution of (31).

## Lemma 1

Assume (H3)–(H4) hold. The solution of (24) is a global solution for all ω ∈ Ω (i.e., φ(t, ω)x0 is defined for t ∈ [0, ∞)).

### Proof

Let v := x − σW. We have

dv/dt = f(v + σW). (25)

Then, the time-derivative of g along trajectories v(t) is given by

dg(v(t))/dt = −f(v)·f(x) (26)

= −(f(v)−f(x)+f(x))·f(x) (27)

≤ −|f(x)|^2 + |f(x)||f(x)−f(v)| (28)

≤ −|f(x)|^2 + L|f(x)||σW| (29)

≤ (L|σW(t)|)^2 / 4, (30)

which implies

g(v(t)) ≤ g(v(0)) + ∫_0^t (L|σW(s)|)^2 / 4 ds := M(t).

Therefore v(t) is contained in K_{M(t)}, which is a bounded set. It follows that v(t) is defined for t ∈ [0, ∞), and so is x(t).

## Lemma 2

Assume (H3)–(H4) hold. For any piecewise continuous \dot{\psi}, the solution of (31) is a global solution (i.e., S(t, \dot{\psi})x0 is defined for t ∈ [0, ∞)).

## Lemma 3

Assume (H3)–(H4) hold. Given T > 0, ε > 0, x0 and q ∈ ℝ^n, there exists a piecewise continuous \dot{\psi}(t) such that the solution of (31) satisfies the boundary condition S(T, \dot{\psi})x0 ∈ B(q, ε).

### Proof

We may assume σ = 1 for simplicity and ε < 1. Let N ∈ \mathbb{N} and

0 := t0 < t1 < ⋯ < tN := T,    t_i − t_{i−1} = h := T/N,    (32)

q_i := x0 + i((q − x0)/N),    1 ≤ i ≤ N.    (33)

Let V be the tube centered at the line segment from x0 to q and with radius one, i.e.,

V := \bigcup_{t∈[0,1]} B((1−t)x0 + t q, 1).

Let C := sup_{x∈V} |f(x)| < ∞. We are going to construct \dot{\psi}(t) on each (t_i, t_{i+1}). According to Lemma 2, the solutions are defined for t ∈ (t_i, t_{i+1}). For simplicity we set \dot{\psi}(t_i) = 0 at each t_i.

- (i) On (t0, t1): Denote q0 := x0. Let \dot{\psi}(t) := (q1 − q0)t/h, t ∈ (t0, t1). Then q0 + \dot{\psi}(t) ∈ V for t ∈ (t0, t1). Therefore,
  sup_{s∈(t0,t1)} |f(q0 + \dot{\psi}(s))| ≤ C.

  From (31) we have

  y(t) − (q0 + \dot{\psi}(t)) = ∫_{t0}^t (f(y(s)) − f(q0 + \dot{\psi}(s))) ds + ∫_{t0}^t f(q0 + \dot{\psi}(s)) ds,

  which implies

  |y(t) − (q0 + \dot{\psi}(t))| ≤ ∫_{t0}^t |f(y(s)) − f(q0 + \dot{\psi}(s))| ds + ∫_{t0}^t |f(q0 + \dot{\psi}(s))| ds ≤ ∫_{t0}^t L|y(s) − (q0 + \dot{\psi}(s))| ds + hC.

  By the Gronwall inequality, we have

  |y(t1) − (q0 + \dot{\psi}(t1))| ≤ hC e^{Lh} < ε/2,

  provided h is small. Denote q̃1 := y(t1) ∈ V.
