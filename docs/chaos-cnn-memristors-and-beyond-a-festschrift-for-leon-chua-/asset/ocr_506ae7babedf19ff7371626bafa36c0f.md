Rapid activity overwhelms the cells ability to restore the ions concentration to steady state levels. The resulting imbalances are indirectly responsible for secondary effects such as hyperpolarisation or reduced cell coupling, which alter functional characteristics (such as period and conduction velocity) of the tissue. These long term effects are referred to as fatigue in conductive tissue [2] and overdrive suppression in pacemaking tissue [28]. Fatigue is simulated in the cellular automata models by decreasing a cell’s ability to be stimulated by its neighbours as a function of its recent activity.

# 4. Bursting in a Greenberg-Hastings Model with Spontaneous Activity and Fatigue

We study a very simple cellular automaton modified from early proposals by Greenberg-Hastings [21] that we believe captures the effects of a heterogeneous cellular structure. The Greenberg-Hastings model is formulated as follows. Each site at time t is assigned a state, u_j(t), where the subscript j refers to the cell number. The neighbourhood of a given site is determined using a square (Moore) metric of diameter r. The state is an integer: 0 is a rest state; states 1,2,...,E are excited states; states E+1,E+2,...,E+R are refractory states; state (E+R+1) is identified with the rest state 0. The update rule for the state of a site is as follows: If (1 <= u_i(t) <= E+R) then u_i(t+1)=u_i(t)+1; and if (u_i(t)=0) then u_i(t+1)=0 unless u_i is excited by its neighbours, or becomes spontaneously active with probability p_s.

A cell becomes excited if it is not refractory a sufficient number of excited cells is present in a defined neighbourhood around the cell. These models display bursting if each cell is given a probability of firing when u_i(t)=0, and if excitability is modified by a fatigue term which increments for each cell every time it fires, and decays away exponentially at other times. The fatigue term in this formulation is added to the threshold for excitation.

The model shows initiation and annihilation of spirals similar to experimental observations. Impulses are initiated by the chance simultaneous firing of several sites in close proximity to each other, so that additional sites in the neighbourhood fire. Local heterogeneity prevents spread of excitation in all directions, resulting in unidirectional propagation. Two wave free ends double back to form doubled armed spiral waves. The build-up of fatigue eventually makes propagation impossible and the rotor is annihilated.

Spiral wave initiation in cellular automata depends on asymmetric initiation of a wave. Initiation of a wave occurs when a number of grid points greater than or equal to threshold K_exci are active within a neighbourhood. As the probability of initiation is low, we assume that at any initiation site only K_exci grid points are active, and that there are no grid points close to the initiation site that are refractory. If this is the case, unidirectional propagation can only occur if one or more of the initiating grid points become refractory before the target wave advances past the immediate neighbourhood of the initiation site. Consider a GH model with a Moore neighbourhood of size 1, K_exci=3, E=5, and R=6. There are 56 ((8·7·6)/6!) different positions that three active grid points can have in a given 3×3 neighbourhood. Cells can have activation states ranging from 1 to 5 in each of these configurations. At least one grid point has a value of 1 at the moment of initiation. There are three possible locations for this grid point, giving 3×5×5−14=61 different permutations (where 14 is the number of identical repeats) for the 56 spatial configurations at the initiation site. Of this 3416(56×61) different configurations, a certain portion give rise to unidirectional propagation and rotor waves, while the rest result in target patterns.

The probability that wave initiation results in a spiral can be determined by iterating the model for each of the 3416 possible configurations. As this is impractical, one spatial configuration (with 61 different configurations of activation state) is analysed in detail. The representative spatial configuration is chosen so that the results can be generalized to the remaining 55.
