Conversely, any composition $\mathcal{F}=F\circ T$ can be considered to be an interaction. Writing $\mathcal{F}=(F\circ T)\circ id$ the dynamical network $(\mathcal{F},X)$ is simply the interaction $\mathcal{F}=F\circ T$ with no local dynamics.

**Remark 2.** If $(\mathcal{F},X)$ is considered as a dynamical network with no local dynamics then $\mathcal{M}_{\mathcal{F}}=\Lambda$ for any constants $\Lambda_{ij}$ satisfying (2) for $\mathcal{F}$. Hence, $(\mathcal{F},X)$ has a globally attracting fixed point if $\rho(\Lambda)<1$.

Suppose $(\mathcal{F},X)$ is a dynamical network where $(\mathcal{F},X)$ is considered as a dynamical network with no local dynamics. That is, the component

$$\mathcal{F}_j:\bigoplus_{i\in I_j}X_i\to X\qquad\text{for }1\le j\le n.$$

Alternatively we write

$$\mathcal{F}_j(\mathbf{x}|_{I_j})=\mathcal{F}_j(x_{j_1},\ldots,x_{j_m}),\qquad\text{where }I_j=\{j_1,\ldots,j_m\}.$$

Note that if we replace the variable $x_{j_i}$ of $\mathcal{F}_j$ by the function $f(y_1,\ldots,y_k)$ the result is the function

$$\mathcal{F}_j(x_{j_1},\ldots,x_{j_{i-1}},f(y_1,\ldots,y_k),x_{j_{i+1}},\ldots,x_{j_m})$$

having variables $x_{j_1},\ldots,x_{j_{i-1}},y_1,\ldots,y_k,x_{j_{i+1}},\ldots,x_{j_m}$. Additionally, if the sequence $\gamma=\ell_1,\ldots,\ell_N$, let

$$\mathcal{F}_{j;\gamma}(x_{j_1},\ldots,x_{j_m})=\mathcal{F}_j(x_{j_1,\gamma},\ldots,x_{j_m,\gamma}).$$

That is, the variables of the function $\mathcal{F}_{j;\gamma}$ are indexed by the sequences $j_1,\ell_1,\ldots,\ell_N$ for $1\le i\le m$.

As $\mathcal{F}$ is an interaction the graph $\Gamma_F=(V,E)$ where $e_{ij}\in E$ if $x_i$ is a variable of $\mathcal{F}_j$. A path $P$ in the graph $\Gamma_F$ is an ordered sequence of distinct vertices $v_1,\ldots,v_m\in V$ such that $e_{i,i+1}\in E$ for $1\le i\le m-1$. We call the vertices $v_2,\ldots,v_{m-1}$ of $P$ the interior vertices of $P$. If the vertices $v_1$ and $v_m$ are the same then $P$ is a cycle.

**Definition 5.** For $\Gamma_F=(V,E)$ let $S\subset V$. The set $S$ is a *complete structural set* of $\Gamma_F$ if

(i) each cycle of $\Gamma_F$ contains a vertex in $S$; and

(ii) each vertex $v_k\in V$ belongs to a path $v_i,\ldots,v_j$ where $v_i,v_j\in S$.

Let $st_0(\Gamma_F)$ denote the set of all complete structural sets of the graph $\Gamma_F$. Moreover, if the complete structural set $S=\{v_1,\ldots,v_m\}$ let $I_S=\{1,\ldots,m\}$ denote the *index set* of $S$.

Let $(\mathcal{F},X)$ be a dynamical network with graph of interactions $\Gamma_F=(V,E)$ and suppose $S\in st_0(\Gamma_F)$. For $j\in I_S$ let $\mathcal{F}_{j,1}$ be the function

$$\mathcal{F}_j=\mathcal{F}_j(x_{j_1},\ldots,x_{j_m})$$

in which each variable $x_{j_\ell}$ is replaced by $x_{j_\ell,j}$ if $j\notin I_S$.

For $i>1$ let $\mathcal{F}_{j,i}$ be the function

$$\mathcal{F}_{j,i-1}=\mathcal{F}_{j,i-1}(x_{\gamma_1},\ldots,x_{\gamma_t})$$

in which each $x_{\gamma_\ell}=x_{\ell_1,\ldots,\ell_N}$ is replaced by the function $\mathcal{F}_{\ell_1;\gamma_\ell}$ if $\ell_1\notin I_S$. If $\ell_1\in I_S$ for each $1\le\ell\le t$ then define $\mathcal{X}_S\mathcal{F}_j=\mathcal{F}_{j,i-1}$.

**Definition 6.** For $S\in st_0(\Gamma_F)$ let $\mathcal{B}_S(\Gamma_F)$ be the set of paths and cycles of $\Gamma_F$ that begin and end with a vertex of $S$ having no interior vertices in $S$. We say

$$\mathcal{A}_S(\mathcal{F})=\{\ell_1,\ldots,\ell_N:v_{\ell_1},\ldots,v_{\ell_N}\in\mathcal{B}_S(\Gamma_F),\ N>2\} \tag{5}$$
is the set of *admissible sequences* of $\mathcal{F}$ with respect to $S$.

Let $\gamma=\ell_1,\ldots,\ell_N\in\mathcal{A}_S(\mathcal{F})$. For $1<i<|\gamma|=N$ define the $N-2$ spaces

$$X_{i;\gamma}=X_{\ell_1}.$$

Additionally, define the functions

$$\mathcal{X}_S\mathcal{F}_{i;\gamma}(x_{i-1,\gamma})=x_{i-1,\gamma}.$$

By way of notation we let

$$X_{N-1,\gamma}=X_\gamma,\quad \mathcal{X}_S\mathcal{F}_{N-1,\gamma}=\mathcal{X}_S\mathcal{F}_\gamma,\quad\text{and}\quad x_{1,\gamma}=x_{\ell_1}.$$
