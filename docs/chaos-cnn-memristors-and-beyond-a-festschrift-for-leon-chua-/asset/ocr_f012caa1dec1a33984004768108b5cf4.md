can then insert (11) into (8) to obtain an equation describing the memductance of the MMC, i.e.,

```
W(t) = 0.3(0 − v7(t)) + 0.11. (12)
```

Using a sinusoidal signal at the input gives

```
v1(t) = V sin(ωt), (13)
```

thus allowing v7(t) to be determined as

```
v7(t) = (R8 R3 V)/(R2 R4 R6 C1) cos(ωt) − (R8/R7) v5. (14)
```

For V = 1 V, ω = 2π rad/s, offset voltage V5 = 5.5 V and the component values given for the schematic in Table 1, Eqs. (12) and (14) can be used to determine that the memductance of the MMC varies between 1.45 mS and 2.07 mS. This gives a memristance range of 483.1 Ω to 689.7 Ω.

This range can be adjusted by a number of methods. The gain of the first operational amplifier stage at U1 can be altered to give a corresponding change in the value of v7(t). This can also be adjusted at the summing stage U3 by changing the values of components R8 or R6.

The circuit can be simply modified to operate as a two-terminal (non-grounded) MMC as shown in Fig. 10. The block diagram shows a feedback path to the non-inverting input of the first operational amplifier stage. To configure this stage as a difference circuit, the feedback path is in series with a 100 kΩ resistor and another 100 kΩ resistor is connected to ground at the non-inverting input.
