Each cell is assigned a random weight, $S_i$, uniformly distributed in the range $(0.5 < S_i < 1.5)$. The results are qualitatively the same for constant $S_i$. However, if each weight $S_i$ is a whole number, the values of neighbourhood size where propagation fails cluster around the square root of whole numbers. Incorporating random values for $S_i$ is a simple way to introduce a continuously varying number of neighbours with varying neighbourhood size. This approach allows analytic determination of wave speed as a continuous function of neighbourhood size, as well as an estimate of parameters that give rise to blocked wave propagation [4, 5]. The model generates smooth wavefronts for large neighbourhoods while displaying irregular fronts with local asymmetries for small neighbourhood sizes. Wave propagation in the revised model more closely mimic what is thought to occur in real tissue, where conduction is irregular at cellular space scales but is continuous at larger space scales [40].

The condition for a cell ‘i’ to become excited is as follows. If $u_i(t)=0$, then $u_i(t+1)=1$ if the sum of all excited cells divided by the sum of all nonexcited cells in a neighbourhood is over a threshold $\theta$. The use of the ratio allows the model to simulate the effects of current sinks that are known to modulate propagation in cardiac systems [3]. The model can be used to simulate a classic cardiac experiment that demonstrates the interplay between local geometry and cell-cell connectivity. Figure 2 demonstrates the effect of a sudden expansion on propagation. Due to asymmetric cell loading at the expansion point, waves can propagate into the narrow channel from the expanse, but cannot propagate in the reverse direction. The wave can propagate in both directions if coupling is decreased by changing the neighbourhood size from 3 to 1.8. This behaviour cannot be simulated using a standard Greenberg-Hastings CA as the effects of asymmetric cell loading on an excitable cell are not accounted for.

In order to terminate bursting activity, we add a fatigue term similar to that used in the original formulation: the fatigue term of cell ‘i’ at time $(t+1)$ is $\gamma_i(t+1)=\gamma_i(t)+F_{add}$ if $u_i(t+1)=1$ and $\gamma_i(t+1)=g\gamma_i(t)\times F_{sub}$ if $u_i(t+1)\neq 1$. The fatigue term is added to the threshold $\theta$. The model bursts as a function of network connectivity. The model displays target patterns for large neighbourhood sizes.
