periodic orbits may not reveal some important features [23,24] and sometimes it can be even misleading [25]. For this reason, an accurate classification can be done only when non-robust periodic orbits are also taken into account.

How to define ‘interesting’ non-robust periodic orbits? We propose to look for orbits with period τ = 3. The rational behind this choice is that the presence period-3 orbits in continuous real functions is an evidence of a very complex dynamical behavior, as proved in a classical work [26] of nonlinear dynamics. This result does not apply directly to elementary CA with a finite state space Σ (ie, in which the states are binary arrays with finite length L) since in this case Σ can be put into a one-to-one correspondence with rational numbers but not with real numbers, as explained in Sec. 5.1. Nevertheless, there are experimental evidences [27] that rules with periodic orbits with τ = 3 exhibit considerably rich dynamics. Therefore, even though there is no rigorous result yet, it is meaningful looking for rules having non-robust periodic rules with τ = 3. There are six such rules in the first four groups of Chua’s classification; namely, rule 9, 25, 37, 74, 94, and 164. For instance, for L = 14 both rule 164 and rule 37 (belonging to C1 and C2, respectively) have a non-robust periodic orbit with τ = 3 and σ = 1, as displayed in Table 12 (a) and (b), respectively. Similarly, also for L = 14 rule 9 and rule 25 (both belonging to C4) have non-robust periodic orbits with σ = 2 and σ = 3, respectively, and τ = 3 (see Table 12 (c) and (d)).

These observations on the period of the non-robust periodic orbits suggest a new classification of the elementary CA rules of the first four Chua’s groups. This classification contains only three classes: i) rules with robust periodic orbits only; ii) rules whose non-robust orbits have τ = 1 and/or τ = 2; iii) rules whose non-robust orbits have τ ≥ 3. Remarkably, this last class contains at least one rule from each of the first four Chua’s groups.

# 5. Nonlinear Dynamics in Elementary Cellular Automata

# 5.1. The states of elementary CA can be represented through rational numbers

As already explained in Sec. 2.1, the states of an elementary Cellular Automaton are binary arrays with L cells; if L is finite, then the state space Σ is

composed of 2^L states. In this case, to each state x^n = (x_0^n x_1^n ... x_{L-1}) of the Cellular Automaton we can associate a rational number q_n by using the function Q : Σ → [0,1) where:

```
q_n = Q(x^n) = sum_{i=0}^{L-1} ( (x_i^n + 1)/2 . 2^{-(i+1)} )    (12)
```

It is possible to prove [28] that if L → ∞ then Q(x) tends to assume all rational values belonging to the interval [0,1) which are a dense subset of the real numbers. The mapping performed by an elementary CA rule N, defined as M_N : Σ → Σ, can be then associated to a function f_N : [0,1) → [0,1), if ∀x^n ∈ Σ, x^{n+1} = M_N(x^n) ⇔ q_{n+1} = f_N(q_n), where q_{n+1} = Q(x^{n+1}) and q_n = Q(x^n). This formula establishes a one-to-one correspondence between elementary CA rules and functions defined of the set of rational numbers, and it is first fundamental step to link Nonlinear Dynamics and Cellular Automata.

# 5.2. Time-τ characteristic function, time-τ return plot, and cobweb diagrams

The time-τ characteristic function χ_N^τ : [0,1) → [0,1) of rule N is a function defined as:

```
Q(M_N^τ(x)) = χ_N^τ(Q(x)),
∀ binary array x with length L    (13)
```

The function χ_N^τ can be conveniently represented on a Cartesian coordinate system. For example, the time-1 characteristic function χ_{74}^1 and time-2 characteristic function χ_{74}^2 of rule 74 are shown in Fig. 2(a) and (b), respectively. Observe that if x = M_N^τ(x), then Q(x) is a fixed point for χ_N^τ. This implies that the graph of the time-τ characteristic function of a period-τ, ie, a rule in which the robust periodic orbits have period τ, will have most of the points lying on the diagonal line.

The special case in which τ = 1 is particularly significant because it is an alternative way to define an elementary CA rule if the length L of the binary arrays is L ≥ 8. In fact, when L ≥ 8 at least one binary array, say x' among the 2^L possible contains all eight triplets of the truth table, from (-1,-1,-1) to (1,1,1), and hence χ_N^1(x') is a complete representation of the local rule N because it contains the information needed to derive the dynamic evolutions from any initial state.
