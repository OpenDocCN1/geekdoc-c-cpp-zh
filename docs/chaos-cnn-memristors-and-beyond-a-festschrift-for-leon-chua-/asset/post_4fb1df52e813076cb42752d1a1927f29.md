Itoh and Chua had proposed theoretically a three segment piecewise linear memristor with characteristic curves similar to those of Chua’s diode [17], albeit with a difference. While the characteristic curve of the Chua’s diode lies in the (v − i) plane, that of the proposed memristor falls in the (φ − q) plane. The piecewise linear relationship for a Chua type flux controlled memristor is given as

```
q(φ) = bφ + 0.5(a − b)[(|φ + 1|) − (|φ − 1|)], (20)
```

where a and b are the slopes in the inner and outer segments of the characteristic curve. This characteristic curve of the memristor in the (φ − q) plane is shown in Fig. 9(a). The current through the memristor is given by

```
i(t) = W(φ)v(t), (21)
```

where W(φ) is the memductance of the memristor. It is so called because it has the units of conductance (℧) and is given by

```
W(φ) = dq(φ)/dφ = { a, |φ| ≤ 1; b, |φ| > 1 } (22)
```

where a, b are as defined earlier. From Eq. (22) we find that the memristor has a bistable nature (ie) it switches from a high conductance ON state to a low conductance OFF state as shown in Fig. 9(b). This bistable nature causes the current and voltage to vary with time as shown in Fig. 9(c).

Here W(z) is the normalized value of the memductance of the memristor, given as

```

```

where a, b are now the normalized values of the quantities mentioned earlier. The rescaling relationships used for normalization are

```
x = v, y = i/G, z = Gφ/C, G = 1/R, β = C/(LG²),

```

The bistability nature of the memristor makes the memristive MLC circuit a first order piecewise-smooth continuous system of the Filippov type [1,2], due to the discontinuity in W(z) at z = ±1. Referring to the memductance characteristic of the memristor in Fig. 9(b), we find that the memristor switches states at z = +1 and at z = −1 either from a more conductive ON state to a less conductive OFF state or vice versa depending on how we proceed across the discontinuity boundary. Consequently the phase space can be divided into three subspaces S1, S2 and S3 due to the presence of two switching manifolds Σ1,2 and Σ2,3 defined by the zero set of the smooth functions H1(x, μ) = (1 − z), z = +1 and H2(x, μ) = (1 + z), z = −1. The memristive MLC circuit can be written as a set of smooth ODEs

```
ẋ(t) = { F1(x, μ), H1(x, μ) ≥ 0, F2(x, μ), H1(x, μ) < 0, F2′(x, μ), H2(x, μ) ≥ 0, F3(x, μ), H2(x, μ) < 0, }.
```

with the conditions that

```
F1(x, μ) = F3(x, μ),
F2(x, μ) = F2′(x, μ). (27)
```

Here

```
F1(x, μ) = F3(x, μ) = { y − W1(z)x, −β(x + y) − f sin(ωt), x } . (28)
```

and

```
F2(x, μ) = F2′(x, μ) = { y − W2(z)x, −β(x + y) − f sin(ωt), x, } (29)
```

where W1(z) = b and W2(z) = a.

## 6. Piecewise Linear Circuits and Strange Nonchaotic Attractors

In recent years, much attention has been given to a class of quasiperiodically forced dissipative dynamical systems which typically exhibits an interesting class of attractors which are not chaotic but yet display strange geometric properties. These are called strange nonchaotic attractors (SNAs), and were reported for the first time by Grebogi, Ott, Pelikan and Yorke [9, 11]. SNAs, although somewhat exotic, are not at all rare. They are regarded as structures in between regularity and chaos. They are geometrically strange as evidenced by their fractal nature, which is common to all chaotic systems. However, they are nonchaotic in a dynamical sense because they do not show sensitivity with respect to changes in initial conditions (as evidenced by negative or zero Lyapunov exponents) just like regular systems.

There are several mechanisms and routes by which SNAs can arise which have all been realized in a variety of dynamical systems [9, 32, 50]. These are included in Table 1.

Table 1. Routes and mechanisms for the onset of various SNAs.

| Type of route | Mechanism |
|---|---|
| Heavy-Hammel | Collision of period-doubled torus with its unstable parent |
| Gradual fractalization | Increased wrinkling of torus without any interaction with nearby periodic orbits |
| On-off intermittency | Loss of transverse stability of torus |
| Type-I intermittency | Due to saddle-node bifurcation, a torus is replaced by SNA |
| Type-III intermittency | Subharmonic instability |
| Homoclinic collision | Homoclinic collisions of the quasiperiodic orbits |
