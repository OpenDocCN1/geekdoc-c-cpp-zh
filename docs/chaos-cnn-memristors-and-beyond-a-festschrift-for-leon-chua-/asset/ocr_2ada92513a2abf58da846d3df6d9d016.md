Despite the limited number of globally-independent rules, elementary CA can display an extraordinary variety of behaviors: from the ‘dull’ rules 0 and 255 (these globally-equivalent rules map the whole state space Σ onto a single point) to the ‘mythical’ rule 110 which is capable of universal computation.

Globally-equivalent transformations are defined independently from the rule to which they are applied. Nevertheless, there is a weaker equivalence between rules, performed by a quasi-global transformation [19], that can be applied only to rules with a specific form. An example of quasi-global equivalent transformation is the alternating-row complementation T̃ which complements the states of all cells only every other iteration, leaving them unchanged in the rest of the iterations. Therefore, rule 𝒩̃ = T̃(𝒩) can be defined as:

```
ℳ_{𝒩̃}^n(x) = ℳ_{𝒩}^n(x) ⇒ ℳ_{𝒩̃}^{n+1}(x) = overline{ℳ_{𝒩}^{n+1}(x)}  (3)
```

This formula implies that:

```
ℳ_{𝒩̃}(x) = ℳ_{𝒩}(overline{x})  (4)
```

for a generic Cellular Automaton state x. Nevertheless, only the elementary CA rules with the form 𝒩 = (β̅0 β̅1 β̅2 β3β3β2β1β0)2 have a quasi-global equivalent rule 𝒩̃, which has the form 𝒩̃ = (β0β1β2β3β̅3 β̅2 β̅1 β̅0); this implies that 𝒩̃ = 255 − 𝒩.
