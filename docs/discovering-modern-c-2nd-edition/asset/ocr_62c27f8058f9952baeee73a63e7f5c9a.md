```
inline double my_root(double x, double eps= 1e-12)
{
    double sq= 1.0, sqo;
    do {
    sqo= sq;
    sq= 0.5 * (sqo + x / sqo);
    } while (abs(sq - sqo) > eps);
    return sq;
}
```

On the one hand, it contains an expensive operation: the division (which usually flushes the floating-point pipeline). On the other hand, the algorithm has quadratic convergence. So, we need precise measurement:
