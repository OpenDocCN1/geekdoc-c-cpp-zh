To avoid an ambiguity, we have to remove the member function with the complex argument.

Even if we keep all three overloads, it is more symmetric to implement them all as free functions. For many applications it does not make a big difference whether a certain binary operator is implemented as a free function or as a method. However, there can be subtle differences: free functions are selected by overload resolution with potential implicit conversion on both arguments while methods are subject to overriding and name hiding when classes are derived (Chapter 6).
