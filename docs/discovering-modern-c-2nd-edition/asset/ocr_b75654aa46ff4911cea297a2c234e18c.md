focus on the memcheck. We apply it to the vector example used, for instance, in Section 2.4.2:

```
valgrind --tool=memcheck vector_test
```

memcheck detects memory-management problems like leaks. It also reports read access of uninitialized memory and partly out-of-bounds access. If we omitted the copy constructor and the destructor of our vector class (so that the compiler would generate one with aliasing effects), we would see the following output:
