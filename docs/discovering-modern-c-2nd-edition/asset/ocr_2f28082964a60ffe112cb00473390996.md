# Figure B-2: ddd control panel

**Next:** Go to the next line in our source code. If we are located on a function call, do not jump into it unless there is a break point set inside.

**Stepi and Nexti:** These are the equivalents on the instruction level. They are only needed for debugging assembler code.

**Until:** When we position our cursor in our source, the program runs until it reaches this line. If our program flow does not pass this line, the execution will continue until the end of the program is reached or until the next break point or bug. Possibly, the program might run eternally in an infinite loop.
