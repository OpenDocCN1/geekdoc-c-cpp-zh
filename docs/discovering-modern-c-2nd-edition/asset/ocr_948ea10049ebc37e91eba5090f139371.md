The approximate points \(\vec{x}_n\) are obtained sequentially using a numerical algorithm that can be written in its most general form as:

```
\(\vec{x}_{n+1} = \vec{F}_{\Delta t} \left( \vec{x}_n \right). \quad (7.7)\)
```

The mapping \(\vec{F}_{\Delta t}\) here represents the numerical algorithm, i.e., famous _RK4_ scheme, sometimes called the Runge-Kutta scheme, that performs one iteration from \(\vec{x}_n\) to \(\vec{x}_{n+1}\) with the time step \(\Delta t\). The numerical scheme is said to have the order _m_ if the solution it generates is exact up to some error of order _m_ + 1:

```
\(\vec{x}_1 = \vec{x}(t_1) + O \left( \Delta t^{m+1} \right), \quad (7.8)\)
```

where \(\vec{x}(t_1)\) is the exact solution of the ODE at _t_<sub>1</sub> starting from the initial condition \(\vec{x}(t_0) = \vec{x}_0\). Hence, _m_ denotes the order of accuracy of a _single step_ of the scheme.
