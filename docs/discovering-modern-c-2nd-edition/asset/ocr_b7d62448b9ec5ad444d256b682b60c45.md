The benefit of this design is that the data is mostly sequential in memory and access is almost as fast as for vector [60]. At the same time, deque entries are only relocated when something is inserted or deleted in the middle. This doesn’t only save the cost of copy or move, it also allows us to store types that are neither copyable nor movable as we will show in the following.
