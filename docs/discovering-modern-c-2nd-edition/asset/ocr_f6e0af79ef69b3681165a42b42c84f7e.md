These lambdas are overloaded with the following variadic template:

```
template <typename ...Functors>
struct overloaded : Functors... {
    using Functors::operator()...;
};
template <typename ...Functors>
overloaded(Functors... ) -> overloaded<Functors...>;
```

It derives from all lambdas and imports their implicitly generated operator(). As this charming little template is quite popular among standard committee members (Bjarne being one of them) there are grounds to fear that it will make it into the next standard.
