# Listing 5-4: Naïve addition operator

![](bbox=[0.15, 0.28, 0.4, 0.29])

```
template <typename T>
inline vector<T> operator+(const vector<T>& x, const
vector<T>& y)
{
    x.check_size(size(y));
    vector<T> sum(size(x));
    for (int i= 0; i < size(x); ++i)
        sum[i] = x[i] + y[i];
    return sum;
}
```
