is not declared `explicit`. Needless to say, the usage of implicit conversions should not be overdone and we can control this for our own classes with `explicit` constructors and conversion operators. Which conversion should be expressed explicitly and where we can rely on the implicit rules is an important design decision for which no general rule exists.

# ### 6.6.1 CRTP

This section describes the _Curiously Recurring Template Pattern_ (CRTP). It combines template programming very efficiently with inheritance. The term is sometimes confused with the _Barton-Nackman Trick_ that is based on CRTP and was introduced by John Barton and Lee Nackman [6].
