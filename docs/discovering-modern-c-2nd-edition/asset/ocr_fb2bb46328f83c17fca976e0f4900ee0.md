This technique is thoroughly discussed in the design patterns book [16] as the Factory pattern. The factory can also be implemented with raw pointers in C++03.

C++14 The construction of the unique_ptr is somewhat cumbersome. C++14 introduces the convenience function make_unique that makes this situation really more convenient:

```
unique_ptr<solver> my_solver;
switch (solver_choice) {
    case 0: my_solver= make_unique<cg_solver>(); break;
    case 1: my_solver= make_unique<bicg_solver>(); break;
}
```

It is a good exercise to implement your own make_unique as suggested in Exercise 3.12.14. Once our polymorphic pointer is initialized, it is straightforward to call our dynamically selected solver:
