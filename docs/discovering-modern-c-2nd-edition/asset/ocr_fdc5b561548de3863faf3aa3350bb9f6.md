# 3.12 Exercises

# 3.12.1 String Representation

Write a generic function `to_string` that takes an argument of an arbitrary type (as `const&`) and generates a string by piping it to a `std::stringstream` and returning the resultant string.

# 3.12.2 String Representation of Tuples

Write a variadic template function that represents an arbitrary number of arguments as a tuple in a string. That is, the function call `to_tuple_string(x, y, z)` returns a string of the form `(x, y, z)` by printing each element to a string stream.

Hint: There are several ways to achieve this. For most programmers it is probably the simplest approach to have an outer function for the parentheses and a helper function `to_tuple_string_aux` that recursively outputs the arguments. More challenging is a non-recursive approach with a fake initializer list. Using a fold expression is also relatively simple as long as the separating commas are ignored but with them it’s more fun.

# 3.12.3 Generic Stack

Write a stack implementation for a generic value type. The maximal size of the stack is defined in the class (hard-wired). Provide the following functions:

+   • Constructor;
+   • Destructor if necessary;
+   • top: show last element;
+   • pop: remove last element (without returning it);
+   • push: insert new element;
+   • clear: delete all entries;
+   • size: number of elements;
