However, in practice the number of a function's instances will not be that large, and it only matters for large functions not inlined. # C++14 3.1.6 Automatic Return Type

Since C++14, we can let the compiler deduce the `return` type of functions:

Click here to view code image

```
template <typename T, typename U>
auto max (T a, U b)
{
    return a > b ? a : b;
}
```

The `return` type is deduced from the expression in the `return` statement in the same fashion as parameters of function templates are deduced from the arguments. If the function contains multiple `return` statements, their deduced types must all be equal. In template libraries, sometimes simple functions have rather lengthy `return` type declarations—possibly even longer than the function body—and it is then a great relief for the programmer not being obliged to spell them out.
