# 3.6 Non-Type Parameters for Templates

So far, we have used template parameters only for types. Values can be template arguments as well. Before C++20, this was essentially limited to integral types—i.e., integer numbers and bool—and pointers. Since C++20, floating-point numbers and classes under certain conditions are allowed as well. In this section we will, however, focus on integers.
