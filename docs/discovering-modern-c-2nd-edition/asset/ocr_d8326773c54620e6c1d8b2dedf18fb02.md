For these, introduced with the p character. The exponent is mandatory— thus we needed p0 in the first example. Due to the suffix f, f1 is a float storing the value 16^1+16^-1 = 16.0625. These literals involve three bases: the pseudo-mantissa is a hexadecimal scaled with powers of 2 whereby the exponent is given as a decimal number. Thus, d2 is 511 × 2^10 = 523264. Hexadecimal literals seem, admittedly, a little nerdy at the beginning but they allow us to declare binary floating-point values without rounding errors.
