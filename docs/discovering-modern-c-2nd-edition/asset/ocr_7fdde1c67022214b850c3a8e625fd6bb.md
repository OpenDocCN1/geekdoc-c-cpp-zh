There are shortcuts for capturing all variables:

+   - [=]: capture all by copy;
+   - [&]: capture all by reference;
+   - [=, &a, &b, &c]: capture all by copy but a, b, c by reference; and
+   - [&, a, b, c]: capture all by reference but a, b, c by copy.

Scott Meyers advises not using the capture-all feature as it increases the danger of stale references and of ignoring static or member variables; see [46, Item 31].

Lambdas in methods must capture the `this` pointer when they access class members:

Click here to view code image

```
struct s
{
    int f(int x) const { return 2 * x; }
    int g(int y) const
    {
        auto l= [this](int z){ return f(z + i); };
        return l(y);
    }
    int i= 3;
};
```

f and i would be considered unknown in the lambda if we hadn't captured this.
