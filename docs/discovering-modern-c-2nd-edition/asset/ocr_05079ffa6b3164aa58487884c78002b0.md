decomposition with or without pivoting. Let's say we prefer LU factorization with column pivoting so that we have:

LU=PA,

with a unit lower triangular matrix L, an upper triangular matrix U, and a permutation matrix P. Thus it is:

A = P⁻¹LU.

This means for the inverse:

A⁻¹ = U⁻¹L⁻¹P. (A.1)
