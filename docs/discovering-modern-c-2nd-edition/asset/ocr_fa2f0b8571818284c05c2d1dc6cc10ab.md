# ## 4.1.2 Iterators

The central abstraction of the STL is *Iterators*. Simply put, iterators are generalized pointers: one can dereference and compare them, and change the referred location as we have already demonstrated with our own `list_iterator` in Section 3.3.2.5. However, this simplification does not do justice to the iterators given their importance. Iterators are a **Fundamental Methodology to Decouple the Implementation of Data Structures and Algorithms**.
