default-constructible, we need still the derivation. As an example we create again a scaling view but this time with an explicit type:

```
struct scale_functor
{
    scale_functor(int factor) : factor(factor) {}
    int operator()(int x) const { return factor * x; }
    int factor;
};
```

```
template <typename Matrix>
struct scale_view
    : map_view<Matrix, scale_functor>
{
    scale_view(const Matrix& A, int factor) : A(A), f(factor)
    {
        const Matrix& A;
        scale_functor f;
    };
};
```

We admit that for the sake of shortness the implementation is simplified by omitting the (different) template parameters for `factor` and `x`.

With this implementation, `map_view` requires an explicit declaration of `is_matrix`. The idea to overcome this is to overload a function and use its return type as the type trait. As before, any type we don't know is not considered to be a matrix:

Click here to view code image

```
template <typename T>
std::false_type is_a_matrix(const T&);        // #1

template <typename T>
using is_matrix = decltype(is_a_matrix(std::declval<T>()));
```

Since we are only interested in the return type and couldn't call the function anyway with `declval` as argument, we only declare the function without any definition.
