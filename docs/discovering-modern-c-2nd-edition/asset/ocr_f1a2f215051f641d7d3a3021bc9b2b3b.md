```
set<int> s = {1, 3, 4, 7, 9};
s.insert(5);
for (int i = 0; i < 6; ++i)
	cout << i << " appears " << s.count(i) << " time(s).\n";
```

yielding the expected output:

```
0 appears 0 time(s).
1 appears 1 time(s).
2 appears 0 time(s).
3 appears 1 time(s).
4 appears 1 time(s).
5 appears 1 time(s).
```

C++20 added the method contains to test the presence of a value:

Click here to view code image

```
for (int i = 0; i < 6; ++i)
	cout << i << "is" << (s.contains(i) ? "" : "n't")
	<< " contained in s.\n";
```

Repeated insertions of the same value have no impact; i.e., count always returns 0 or 1. The container multiset allows for additionally counts how often values were inserted:

Click here to view code image

```
multiset<int> s = {1, 3, 4, 7, 9, 1, 1, 4};
s.insert(4);
for (int i = 0; i < 6; ++i)
	cout << i << " appears " << s.count(i) << " time(s).\n";
```

yielding:

```
0 appears 0 time(s).
1 appears 3 time(s).
2 appears 0 time(s).
3 appears 1 time(s).
4 appears 3 time(s).
5 appears 0 time(s).
```

For only checking whether a certain value is present in the multiset, find is more efficient as it doesn't need to traverse replicated values. In C++20, contains is even more efficient and it is also more convenient than find.
