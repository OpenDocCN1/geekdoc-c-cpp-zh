C++ 深度系列是一套简洁而专注的书籍集合，为现实世界的程序员提供关于 C++ 编程语言的可靠信息。

该系列由 C++ 的设计者和最初实现者伯雅尼·斯特劳斯特鲁普精选，并由该领域经过精心挑选的专家撰写，系列中的每本书要么针对某个单一主题，以适合该主题的技术水平进行阐述，要么提供快节奏的概述，以便快速理解更广泛的语言特性。无论哪种情况，该系列的实用方法旨在将专业人士（以及有志成为专业人士的人）提升到下一级的编程技能或知识水平。
