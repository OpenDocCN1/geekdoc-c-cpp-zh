Lambdas returning lambdas are scary at first but are not so rare in software that tries to squeeze out all the expressiveness of modern C++.

C++17 Using compile-time if from C++17 relieves us from the specialization to terminate the recursion and we only need one definition (that slightly exceeded our guideline limit). On the other hand, we get an extremely expressive formulation for our approximated derivatives:

Click here to view code image

```
template <size_t N>
auto derive = [] (auto f, auto h) {
if constexpr (N == 0) {
return [f] (auto x) { return f(x); };
} else {
auto prev = derive<N-1>(f, h);
return [=](auto x) { return (prev(x+h) - prev(x)) / h;
};
};
};
```

With our new definition we can define functions for the derivative as before:

```
auto f = [] (double x) { return 2.0 * std::cos(x) + x*x; };
auto d2f = derive<2>(f, 1e-3);
auto d5f = derive<5>(f, 1e-3);
cout << "f'(1) = " << d2f(1.0) << endl;
cout << "f(5) (1) = " << d5f(1.0) << endl;
```
