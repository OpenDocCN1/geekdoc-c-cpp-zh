Since C++14 we can express imaginary numbers with user-defined literals. For instance, `3i` is shorthand for `complex<double>{0, 3}`. Suffixes for `float` and `long double` literals were added as well. A function `f` for instances of `complex` can now be called in a more concise manner with different types representing `3.2 + 4.3i`:

+   5. The feature is called user-defined literals although we use a suffix in the literal that is not defined by the user but by the standard library.

```
f(3.2f + 4.3if) // As float
f(3.2 + 4.3i)   // As double
f(3.21 + 4.3il) // As long double
```

This notation is not so much shorter than a constructor call but it is definitely closer to the mathematical original.
