Regarding the visibility of names, the derived class is similar to an inner scope: in addition to the class's members, we see those of its base class (and their base classes as well). When a derived class contains a variable or function with the same name, those of the base class are hidden, similarly again to a scope. In contrast, we can still access the hidden members of the base class by name qualification like person::all_info.
