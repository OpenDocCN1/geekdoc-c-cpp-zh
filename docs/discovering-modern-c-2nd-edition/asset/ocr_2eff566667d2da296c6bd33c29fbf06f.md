Here the variable stores a lambda to compute the n<sup>th</sup> derivative of a function f on the fly by defining internally another lambda that computes the (n-1)<sup>th</sup> derivative, for instance:

Click here to view code image

```
auto f = [] (double x) { return 2.0 * std::cos(x) + x*x; };
cout << "f''(1) = " << derive<2>(f, 1.0, 1e-3) << endl;
cout << "f(5) (1) = " << derive<5>(f, 1.0, 1e-3) << endl;
```

In contrast to this, the derivatives with functors first generated from a unary function another unary function that approximates their n<sup>th</sup> derivative. Thus we could use this function in the same manner as the original one. To achieve this with lambdas and variable templates, we must refrain from immediate calculation and instead create some sort of factory that returns the function which can perform the computation later:

Click here to view code image

```
template <size_t N>
auto derive = [] (auto f, auto h) {
    auto prev = derive<N-1>(f, h);
    return [prev,h](auto x) { return (prev(x+h) - prev(x)) /
    h; };
};
```
