# Advice

The correct way to use free functions such as `std::begin` in a generic library is by locally lifting them into the current namespace with `using std::begin` and then accessing them without a namespace qualifier, i.e., `begin(x)`, as is done in Listing 7-4. This way, the compiler can also utilize `begin` functions defined in the same namespace as the type of `x` via argument-dependent name lookup (ADL) if necessary.

Listing 7-4 shows such a `container_algebra`. The iterations are performed within `for_each` functions that are part of the `struct` called `container_algebra`. Those functions expect a number of container objects as well as an operation object and then simply perform an iteration over all containers and execute the given operation element-wise.
