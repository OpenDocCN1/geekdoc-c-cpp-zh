```
tmp.3+= A[1] [3] * B[3] [1]
C[1] [0]= tmp.4
C[1] [1]= tmp.3
tmp.4+= A[3] [0] * B[0] [0]
tmp.3+= A[3] [0] * B[0] [1]
tmp.4+= A[3] [1] * B[1] [0]
tmp.3+= A[3] [1] * B[1] [1]
tmp.4+= A[3] [2] * B[2] [0]
tmp.3+= A[3] [2] * B[2] [1]
tmp.4+= A[3] [3] * B[3] [0]
tmp.3+= A[3] [3] * B[3] [1]
C[3] [0]= tmp.4
C[3] [1]= tmp.3
```

In temporary number 4, we accumulate \(A_1 \cdot B^0\) and store the result to \(c_{1,0}\). This is interleaved with the accumulation of \(A_1 \cdot B^1\) in temporary 3, allowed for using multiple pipelines of super-scalar processors. We can also see that:

\(c_{ik} = \sum_{j=0}^3 a_{ij} b_{jk} \forall i, k.\)
