```
First we differentiate the constructor by reducing the numerator and denominator in the canonical form:

[Click here to view code image](#)

```
```cpp
rational(int p, unsigned q) : p{p}, q{q}
{
    if (q == 0)
        throw zero_denominator();
    if constexpr (Canonical) {
        auto g = gcd(abs(p), q);
        p /= g;
        q /= g;
    }
}
```
