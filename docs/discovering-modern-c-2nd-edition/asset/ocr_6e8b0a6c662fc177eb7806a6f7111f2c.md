If you see an error message with `STATIC ASSERTION` in it, don't think about the message itself—it is meaningless—but look at the source code line that caused this error and hope that the author of the assertion provided more information in a comment. With a recent Boost version and a C++11-compliant compiler, the macro is expanded to `static_assert` and at least the condition is printed as an error message. Note that `BOOST_STATIC_ASSERT` is a macro and doesn't understand C++. This manifests itself in particular when the argument contains one or more commas. Then the preprocessor will interpret this as multiple arguments of the macro and get confused. This confusion can be avoided by enclosing the argument of `BOOST_STATIC_ASSERT` in double parentheses as we did in the example (although it was not necessary here).
