# 6.3.2.2 Virtual Base Classes

=> c++11/oop_multi3.cpp

Virtual Base Classes allow us to store members in common super-classes only once and thus help to overcome related problems. However, it requires a basic understanding of the internal implementation to not introduce new problems. In the following example, we just denote person as a virtual base class:

![](bbox=[0.133, 0.413, 0.373, 0.426])

```
class person { ... };

class student
: public virtual person
{ ... };

class mathematician
: public virtual person
{ ... };

class math_student
: public student, public mathematician
{
public:
    math_student(const string& name, const string& passed,
                 const string& proved)
    : student(name, passed), mathematician(name, proved) {}
    ...
};
```

and get the following output that might surprise some of us:

![](bbox=[0.133, 0.813, 0.373, 0.826])

```
[student] My name is
    I passed the following grades: Algebra
    I proved: Fermat's Last Theorem
```
