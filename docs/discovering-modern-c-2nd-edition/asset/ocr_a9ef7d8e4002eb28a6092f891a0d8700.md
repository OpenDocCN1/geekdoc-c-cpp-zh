In the context of parallelization, seven new algorithms were added:

+   - `for_each_n` applies a functor to the first `n` entries;
+   - `reduce` performs a reduction like `accumulate` except that the order is allowed to change;
+   - `transform_reduce` applies a functor before reduction (in general known as map-reduce);
+   - `inclusive_scan` computes a partial sum like the existing sequential function `partial_sum`;
+   - `exclusive_scan` computes a partial sum as well where the i-th entry is excluded from the i-th partial sum; and
+   - `transform_inclusive_scan` and `transform_exclusive_scan` compute the according partial sums after applying a functor to each entry.
