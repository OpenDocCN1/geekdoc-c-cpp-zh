The value in each Case statement is then compared to the expression's value and, if there is a match, any statements between the matching Case statement and the next Case statement (or the End Select statement) are executed.

Using the Case Else statement is optional, but it's always a good idea. The Case Else clause is always the last Case statement of Select Case and is executed when none of the Case values matches the expression at the top of the Select Case statement.

The Case statement can be inequality comparisons by incorporating the Is keyword:

```
Select Case dTaxRate
    Case Is < 0.03
        MsgBox "Low taxes"
    Case Is > 0.07
        MsgBox "High taxes"
    Case Else
        MsgBox "Average taxes"
End Select
```
