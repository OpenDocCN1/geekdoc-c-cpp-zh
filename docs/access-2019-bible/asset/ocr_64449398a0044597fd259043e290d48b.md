+   - **Comma-separated values (CSV):** CSV files are somewhat more difficult to understand than fixed-width. Each field is separated from the other fields by a comma character (,), and each field occupies as much space as necessary to contain the data. Generally, there is no blank space between fields in a CSV file. The advantage of CSV files is that the data can be contained in a smaller file because each field occupies only as much disk space as necessary to contain the data. The difficult part is that sometimes there are commas within a field, requiring text qualifiers, like double quotes, around the field.
+   - CSV files can be difficult to read when opened in Notepad. Figure 7.12 shows a typical CSV text file.

Text files are used as intermediate data-transfer vehicles between dissimilar applications. For example, there might be an obsolete data management system in your environment that’s incompatible with any of the link or import data types in Access. If you’re lucky, the obsolete system is able to output either fixed-width or CSV files. Linking to or importing the fixed-width or CSV files might be the best option for sharing data with the obsolete system. At the very least, much less time is required to link or import the data than would be involved in re-keying all the information from the obsolete system into Access.
