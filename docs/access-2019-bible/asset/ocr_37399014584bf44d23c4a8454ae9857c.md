Let's assume you want to refine the rptSalesJanuaryAlpha1 report by labeling the groups with the letters of the alphabet. That is, all customers beginning with A (Antonio Moreno Taqueria and Around the Horn) are in one group, all customers beginning with B (Blondel père et fils, Bon app', and Bottom-Dollar Markets) are in another group, and so on. Within each group, the company names are sorted in alphabetical order. The sales to each customer are further sorted by order date.

To emphasize the alphabetical grouping, a text box containing the first character for each group has been added to the report (see rptSalesJanuaryAlpha2 in Figure 21.5). Although the data set in this example is rather small, in large reports such headings can be useful.
