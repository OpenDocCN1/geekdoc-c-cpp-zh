# Removing duplicate records

If you’re working with a small data set, removing the duplicates can be as easy as manually deleting records from your Find Duplicates query. However, if you’re working with a large data set, your Find Duplicates query may result in more records than you care to manually delete. Believe it when someone tells you that manually deleting records from a 5,000-row Find Duplicates query is an eyeball-burning experience.
