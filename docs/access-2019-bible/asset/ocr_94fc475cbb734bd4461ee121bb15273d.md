Most of the time, you use the String, Date, Long, and Currency or Double data types. The Integer data type is no longer used by VBA. It’s still in the language for backward compatibility, but behind the scenes VBA converts all Integer variables to Long variables. You don’t save any memory using Integer, and you might experience a very small performance hit, because VBA actually has to do the conversion. On top of that, you limit yourself to a smaller range of numbers with no memory savings. In short, never use the Integer data type.

When you want to assign the value of an Access field to a variable, you need to make sure that the type of the variable can hold the data type of the field. Table 25.2 shows the corresponding VBA data types for Access field types. Some Access data types can’t be stored in a VBA variable.
