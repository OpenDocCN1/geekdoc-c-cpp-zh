The thing to notice in cmdBackward_Click is that the arguments are not passed to PrepareOutput() in the order specified by the procedure's argument list. As long as the name used for an argument matches an argument in the PrepareOutput argument list, Access VBA correctly uses the arguments in PrepareOutput().
