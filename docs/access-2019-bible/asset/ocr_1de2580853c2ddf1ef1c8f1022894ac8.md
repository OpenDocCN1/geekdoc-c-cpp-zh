> NOTE
> When you run a macro with submacros from the Navigation pane, only the first submacro executes.

If you're careful in planning your macros, you can create one top-level macro object for each form or report and use submacros for each action you want to perform in the form or report. Submacros let you limit the number of macros that appear in the Navigation pane and make managing numerous macros much easier.

# Conditions

Submacros let you put multiple groups of actions in a single macro object, but a condition specifies certain criteria that must be met before the macro performs the action. The IF macro action also takes a Boolean expression. If the expression evaluates to False, No, or 0, the action will not execute. If the expression evaluates to any other value, the action is performed.
