When you first display text in the Zoom window, all the text is selected. You can deselect the text by clicking anywhere in the window. If you accidentally delete all the text or change something you didn't want to change, click Cancel to exit back to the datasheet with the field's original data.

> Tip
> Use the Zoom window (Shift+F2) when designing Access objects (tables, forms, reports, and queries) to see text that normally scrolls out of view.
