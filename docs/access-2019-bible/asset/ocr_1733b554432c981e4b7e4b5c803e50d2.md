[Revenue]*0.33 will be preformed against the resulting sum of LineTotal for each individual Period group. Running this query will return the total Revenue and Cost for each Period group.

# NOTE

Here is one final note about the Where clause. Notice in Figure 10.9 that the check box in the Show row has no check in it for the Period.
