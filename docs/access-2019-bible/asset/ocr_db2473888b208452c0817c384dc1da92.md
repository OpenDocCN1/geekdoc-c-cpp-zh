Using ADO to update a table.

Variables are declared in the top portion of the code using Dim statements. You can declare a variable anywhere as long as it’s declared before you use it. It’s good practice to declare all your variables together at the top. The variables for the database and the recordset use the library as the prefix (DAO in this case). This file contains both DAO and ADO code, so it’s necessary to specify which library to use. If only DAO were used, you could just use, for example, Dim db As Database and most programmers omit the library in that case.

The next line of code uses On Error to tell VBA to jump to the ErrHandler label if it encounters any errors. Without error handling, the user would be thrust into the VBE if an error occurred. The two labels near the bottom, ErrExit and ErrHandler, complete the error handling. This is very common method of indicating error handling in your code.
