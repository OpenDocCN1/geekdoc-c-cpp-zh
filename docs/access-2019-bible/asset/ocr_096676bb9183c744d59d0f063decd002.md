# FIGURE 6.1

The External Data tab of the Ribbon hints at the variety of external data sources available to Access.

![](bbox=[0.13, 0.24, 0.9, 0.38])

The Import & Link group includes the following options:

+   - New Data Source
+   - Saved Imports
+   - Linked Table Manager

The New Data Source drop-down includes four categories containing several data formats each:

+   - From File
+     - Excel
+     - HTML Document
+     - XML File
+     - Text File
+   - From Database
+     - Access
+     - From SQL Server
+     - From Azure Database
+     - dBASE File
+   - From Online Services
+     - SharePoint List
+     - From Dynamics 365 (online)
+     - From Salesforce
+     - Data Services
+   - From Other Sources
+     - ODBC Database
+     - Outlook Folder

The Export group includes the following options:

+   - Saved Exports
+   - Excel
