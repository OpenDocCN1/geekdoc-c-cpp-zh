As you might guess, the Tab control is fairly complex. It includes its own properties, events, methods, and object collections. You have to know and understand these items before you can effectively use the Tab control in your applications.

> NOTE
> Developers often use the term tab when referring to the pages of a tabbed dialog box. In this chapter, the terms page and tab are used interchangeably.

A Tab control consists of a number of tabs. From the user interface, the quickest and easiest way to add or delete a page is to right-click the control and select the appropriate command from the shortcut menu (see Figure 19.16).

The Tab control contains some unique properties, some of which are described in Table 19.1. Use these properties to tailor the Tab controls in your applications to suit the needs of your users.
