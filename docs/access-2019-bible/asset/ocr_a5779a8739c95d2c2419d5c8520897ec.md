# Adjusting the report's layout

There are a few small issues with the report shown in Figure 20.10. The Access Report Wizard has chosen the fonts and overall color scheme, which may not be what you had in mind. Also, the column headings on the right side overlap, and the Cost column was made very narrow.

The Report Wizard displays the new report in Print Preview. Right-click the report's title bar and select Layout View from the shortcut menu. The new report in Layout view is shown in Figure 20.11.
