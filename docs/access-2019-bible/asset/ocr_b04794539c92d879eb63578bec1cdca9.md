+   3. **Add tblBookOrders5 and tblBookOrderDetails to the Relationships window** (double-click each table in the Show Table dialog box, or select each table and click the Add button).

+   4. **Create a relationship by dragging the primary key field in the "one" table and dropping it on the foreign key in the "many" table.** Alternatively, drag the foreign key field and drop it on the primary key field.
+   
+   For this example, drag OrderID from tblBookOrders5 and drop it on OrderID in tblBookOrderDetails. Access immediately opens the Edit Relationships dialog box (shown in Figure 4.16) to enable you to specify the details about the relationship you intend to form between the tables. Notice that Access recognizes the relationship between tblBookOrders5 and tblBookOrderDetails as a one-to-many.

+   5. **Check the Enforce Referential Integrity checkbox.** In Figure 4.16, notice the Cascade Delete Related Records check box. If this check box is left unchecked, Access won't permit you to delete records in tblBookOrders5 (the "one" table) until all the corresponding records in tblBookOrderDetails (the "many" table) are first deleted. With this box checked, deletions across the relationship "cascade" automatically. Cascading deletes can be a dangerous operation because the deletions in the "many" table occur without confirmation.
