+   - Select the control and use the arrow keys on the keyboard to move the control. Using this technique, a control changes by only 1 pixel at a time (or moves to the nearest gridline or grid point if Snap to Grid is selected in the Size/Space gallery on the Arrange tab of the Ribbon).
+   - Click and drag the move handle in the upper-left corner of the control. This differs from the other methods in that it will move the control or its label independently. The other methods move the control and label together.
