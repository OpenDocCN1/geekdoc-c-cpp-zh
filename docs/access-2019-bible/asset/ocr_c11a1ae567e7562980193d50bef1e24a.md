The If macro action lets you selectively run actions based on other values in your application. Use the If macro action to reference controls on forms or reports and other objects and determine which actions to execute.

# Temporary Variables

In previous versions of Access, you could use variables only in VBA code. Macros were limited to performing a series of actions without carrying anything forward from a previous action. Beginning with Access 2007, three new macro actions—SetTempVar, RemoveTempVar, and RemoveAllTempVars—let you create and use temporary variables in your macros. You can use these variables in conditional expressions to control which actions execute, or to pass data to and from forms or reports. You can even access these variables in VBA to communicate data to and from modules.
