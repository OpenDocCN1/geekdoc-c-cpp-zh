Use these steps to turn a check box into a toggle button:

+   1. **Open frmControlMorphing in Design view.**
+   2. **Select the Before label control (just select the label control, not the check box).**
+   3. **Press Delete to delete the label control because it isn’t needed.**
+   4. **Right-click the check box, and choose Change To → Toggle Button from the shortcut menu.**
+   5. **Resize the toggle button and click inside it to get the blinking cursor; then type After on the button as its caption (shown on the right of Figure 17.24).**
