# An Easy Way to Query Only Workdays

Suppose you’ve been asked to provide the total amount of revenue generated by product, but only revenue generated during workdays in calendar year 2013. Workdays are defined as days that are not weekends or holidays.

The first thing you need to accomplish this task is a table that lists all the company holidays in 2013. The following figure shows that a holidays table can be nothing more than one field listing all the dates that constitute a holiday.

| Holidays |
|---|
| 1/1/2013 |
| 1/18/2013 |
| 5/31/2013 |
| 7/4/2013 |
| 9/6/2013 |
| 11/25/2013 |
| 11/26/2013 |
| 12/24/2013 |
| 12/25/2013 |
| 12/31/2013 |
