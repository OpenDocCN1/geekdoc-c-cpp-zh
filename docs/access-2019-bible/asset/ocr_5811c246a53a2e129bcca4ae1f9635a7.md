The process of linking HTML data is similar to linking to Excel spreadsheets:

+   1. Click Import & Link > New Data Source > From File > HTML Document on the External Data tab of the Ribbon. The Get External Data – HTML Document dialog box appears.
+   2. Select the Link to the Data Source by Creating a Linked Table option, and click Browse. The File Open dialog box appears, enabling you to search for the HTML file you want to link.

From this point on, the process of linking to HTML data is similar to linking to other types of data files, including providing field names and other details of the linked data. Figure 7.9 shows the first screen of the Link HTML Wizard. Click the Advanced button to get to the Link Specification dialog box (shown in Figure 7.10), where you can provide the field names and other details.
