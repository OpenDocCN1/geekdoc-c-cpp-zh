# Using Dates in Your Analyses

In Access, every possible date starting from December 31, 1899, is stored as a positive serial number. For example, December 31, 1899, is stored as 1; January 1, 1900, is stored as 2; and so on. This system of storing dates as serial numbers, commonly called the 1900 system, is the default date system for all Office applications. You can take advantage of this system to perform calculations with dates.

# CAUTION

To be calculated correctly, dates must reside in a field that is formatted as a Date/Time field. If you enter a date into a Short Text field, the date will continue to look like a date, but Access will treat it like a string. The end result is that any calculation done on dates in this Text-formatted field will fail. Ensure that all dates are stored in fields that are formatted as Date/Time.
