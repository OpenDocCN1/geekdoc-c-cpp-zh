# Datasheet forms

Click the More Forms button in the Forms group of the Create Ribbon and then click the Datasheet button to create a form that looks like a table or query’s datasheet. A datasheet form is useful when you want to see the data in a row and column format but you want to limit which fields are displayed and editable.
