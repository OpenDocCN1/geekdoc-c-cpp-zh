The Ribbon is the primary way that users interact with Office applications. All Office applications have a Ribbon and support customizing the Ribbon, including Access.

Access is a unique application compared to other Office applications. The main difference is that you use Access to create applications, but you use Word and Excel to create documents. Ribbon customization is different in Access too. While most Office documents are compressed XML documents, Access files don’t follow that model. If you’ve customized the Ribbon in other Office applications, you’ll have a head start in Access because you’ll already be familiar with the XML. Don’t worry if you’re new to Ribbon customization. We’ll show you everything you need to know.

# The Ribbon Hierarchy

The Ribbon is a fairly complex structure and is hierarchical in nature. At the top level are the tabs you see along the top of the Ribbon. Each tab contains one or more groups, each containing one or more controls. The Ribbon is highly adaptable to your current tasks, so the description that follows may not be exactly the same as you see on your screen:

+   - **Tabs:** The top object in the Ribbon hierarchy. You use tabs to separate the most fundamental operations into logical groups. For instance, the default Ribbon contains five tabs: Home, Create, External Data, Database Tools, and Help. The File tab acts differently from the other tabs. It opens a Backstage area with typical file operations.
