# Part VI: Microsoft Access Programming Fundamentals

# ON THE WEB

If you haven't done so already, open the database for this walkthrough, `Chapter23.accdb`, which can be downloaded from this book's website.

+   1. Open the `tblProducts` table in Datasheet view.
+   2. Select the Table tab on the Ribbon, and choose the BeforeChange event. At this point, Access will activate the macro builder.
+   3. Double-click or drag the Group program flow action onto the macro’s design surface. Here, you’re creating a new macro group. Give the macro group a name as shown in Figure 23.7.

**FIGURE 23.7**
Add a Group to the macro and give it a name.

![](bbox=[0.169, 0.407, 0.759, 0.562])

+   4. While in the newly created group, double-click the Comment program flow action to place a comment onto the macro’s design surface. With this comment, enter some friendly text describing what you’re doing here (see Figure 23.8).
