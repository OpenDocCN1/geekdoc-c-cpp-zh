Some of the examples in this chapter use Visual Basic for Applications (VBA). VBA is discussed more fully in Chapters 24–29.

To hide the header after the first page, add an unbound Text Box control to the report with its Control Source property set to the expression =HideHeader(). Delete the text box's label. The HideHeader() function returns a null string, making the text box invisible.

# NOTE

You can't actually set the control's Visible property to No; if you did, the control wouldn't be able to respond to events.

The HideHeader() function is as follows:

```
Function HideHeader() As String

'Set the visible property of the header
Me.Section("PageHeader0").Visible = False
HideHeader = vbNullString

End Function
```
