6. Select the delimiter that separates your fields; if an uncommon delimiter is used, select Other and enter the delimiter in the Other box.

# CAUTION

There can be a problem with the separator used if any of the fields in the text file contains the separator character as data. For example, if you use a comma to delimit fields and one of the fields is Acme Widgets, Inc., Access will have a problem importing the file. The solution is to wrap text fields in double quotes ("Acme Widgets, Inc.") so that the comma is not misinterpreted as a field separator. This use of double quotes is referred to as the text qualifier. Most often single- or double-quote marks are used for this purpose and usually resolve issues with special characters contained within data fields.
