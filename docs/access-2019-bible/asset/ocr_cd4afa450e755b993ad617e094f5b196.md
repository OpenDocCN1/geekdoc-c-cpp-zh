# Printing or viewing the report

The final step in the process of creating a report is printing or viewing it.

# Printing the report

There are several ways to print your report:

+   - Choose File ➔ Print in the main Access window (with a report highlighted in the Navigation pane). The Backstage area appears with the following options:
+     - Quick Print. This sends the report to the default printer immediately.
+     - Print. This shows the print dialog box allowing you to make certain changes prior to printing.
+     - Print Preview. This displays the report in print preview mode.
+   - Click the Print button on the Print Preview tab of the Ribbon. The print dialog is shown.
