# Part V: Working with Access Forms and Reports

You can move around the page by using the horizontal and vertical scroll bars or use the Page controls (at the bottom-left corner of the window) to move from page to page. The Page controls include navigation buttons to move from page to page or to the first or last page of the report. You can also go to a specific page of the report by entering a value in the text box between the Previous Page and Next Page controls.

Right-clicking the report and selecting the Multiple Pages option, or using the controls in the Zoom group on the Print Preview tab of the Ribbon, lets you view more than one page of the report in a single view. Figure 20.17 shows a view of the report in the Print Preview’s two-page mode. Use the navigation buttons (in the lower-left section of the Print Preview window) to move between pages, just as you would to move between records in a datasheet.

If, after examining the preview, you’re satisfied with the report, click the Print button on the Ribbon to print the report. If you’re dissatisfied with the design, click the Close Print Preview button to switch to the Report Layout window and make further changes.

# Publishing in alternate formats

An important feature of the Print Preview tab is the ability to output the Access report in a number of common formats, including PDF, XPS (XML Paper Specification), HTML, and other formats.
