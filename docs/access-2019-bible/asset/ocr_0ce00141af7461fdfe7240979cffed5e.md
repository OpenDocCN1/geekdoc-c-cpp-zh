# Basic Descriptive Statistics

This section discusses some of the basic tasks you can perform using descriptive statistics.

# Running descriptive statistics with aggregate queries

At this point in the book, you have run many Access queries, some of which have been aggregate queries. Little did you know that when you ran those aggregate queries, you were actually creating descriptive statistics. It’s true. The simplest descriptive statistics can be generated using an aggregate query. For instance, the query in Figure 16.1 will output descriptive statistics around revenue generated by all sales reps.

![](bbox=[0.169, 0.384, 0.829, 0.561])

Running this aggregate query will provide a useful set of descriptive statistics.

Similar to the descriptive statistics functionality found in Excel, the result of this query, shown in Figure 16.2, provides key statistical metrics for the entire data set.

![](bbox=[0.169, 0.697, 0.661, 0.726])

You can easily add layers to your descriptive statistics. In Figure 16.3, you’re adding the Branch_Number field to your query. This will give you key statistical metrics for each branch.

As you can see in Figure 16.4, you can now compare the descriptive statistics across branches to measure how they perform against each other.
