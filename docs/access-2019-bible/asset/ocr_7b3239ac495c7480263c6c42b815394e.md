# Opening the report design

The final Report Wizard screen contains a text box for you to enter a title for the report. This title appears only once, at the very beginning of the report, not at the top of each page. The report title also serves as the new report's name. The default title is the name of the table or query you initially specified as the report's data source. The report just created in the Chapter20.accdb example is named rptProducts_Wizard.

> NOTE
> The Chapter20.accdb file contains all of the reports described in this chapter. If you follow along to create your own reports, simply choose a different name in the last step so you don't overwrite the examples.

Next, choose one of the option buttons at the bottom of the dialog box:

+   - Preview the report
+   - Modify the report's design

For this example, leave the default selection intact to preview the report. Click Finish and the report displays in Print Preview (see Figure 20.10).
