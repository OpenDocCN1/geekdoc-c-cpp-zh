6. Adjust field widths as needed. Access guesses at the best breaks to use for fields, based on the most consistent spacing across rows. In this case, the field breaks are very consistent. If necessary, however, use the mouse to grab a dividing line and move it left or right to change the width of fields in the file.

TIP
To add a new dividing line, single click the mouse within the data area and then move the line to the desired position.
To delete an existing line, double-click the line.
