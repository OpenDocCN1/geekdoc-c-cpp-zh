The Page Footer Format event procedure adjusts the Text Align property of txtPageNumber to shift the page number all the way to the left or right side of the text box depending on whether the page is even or odd:

```
Private Sub PageFooter1_Format(Cancel As Integer, _
    FormatCount As Integer)

    Const byALIGN_LEFT As Byte = 1
    Const byALIGN_RIGHT As Byte = 3

    If Me.Page Mod 2 = 0 Then
        Me.txtPageNumber.TextAlign = byALIGN_LEFT
    Else
        Me.txtPageNumber.TextAlign = byALIGN_RIGHT
    End If

End Sub
```

In this event procedure, any time the expression Me.Page Mod 2 is zero (meaning the page number is even), the Text Align property is set to Left. On odd-numbered pages, Text Align is set to Right.

Figure 21.28 shows that Page 1, an odd numbered page, is shown on the right side, and Page 2, an even numbered page, is shown on the left.
