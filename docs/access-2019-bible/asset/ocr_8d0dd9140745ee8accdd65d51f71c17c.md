# Turning Aggregate Query Results into Hard Data

The results of aggregate queries are inherently not updatable. This means you won't be able to edit any of the records returned from an aggregate query because there is no relationship between the aggregated data and the underlying data.

However, you can change your aggregate query into a Make Table query and create a hard table with your aggregate query's results. With your new hard table, you'll be able to edit to your heart's content.
