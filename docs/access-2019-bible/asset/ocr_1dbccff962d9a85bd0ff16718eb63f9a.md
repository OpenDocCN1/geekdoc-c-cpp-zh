If you run this query, Access will display the message shown in the following figure. This message is asking you to specify which table contains the records you want to delete.

![](bbox=[0.13, 0.53, 0.55, 0.67])

This message stumps many Access users. Unfortunately, this message doesn't clearly state what you need in order to remedy the mistake. Nevertheless, the remedy is a simple one: First, clear the query grid by deleting the CustomerName field. Next, double-click the asterisk (*) in the Customer_ListA table. This explicitly tells Access that the Customer_ListA table contains the records you want to delete. The following figure demonstrates the correct way to build this query.
