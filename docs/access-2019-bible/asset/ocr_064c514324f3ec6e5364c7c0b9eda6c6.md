The Tab Order dialog has several buttons at the bottom. Auto Order places the controls in order from left to right and from top to bottom, according to their position in the form. This button is a good starting place when the tab order is very disorganized. The OK button applies the changes to the form, while the Cancel button closes the dialog box without changing the tab order.

Each control has two properties related to the Tab Order dialog box. The Tab Stop property determines whether the cursor stops at the control when you press the Tab key. The default is Yes. Changing the Tab Stop property to No does not remove the control from the tab order, but the control is skipped when you reach its position by tabbing through the form. When you set the tab order in the Tab Order dialog box, you’re setting each control’s Tab Index property. Moving the fields around in the Tab Order dialog box changes the Tab Index properties of those (and other) controls.

> **CAUTION**
> 
> Setting a control’s Tab Stop property to No does not make the control read-only. The user can still select the control and change its value.
