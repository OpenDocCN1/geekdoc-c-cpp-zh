> TIP
> The Select Behavior option (choose File ◄ Options ◄ Object Designers ◄ Form/Report design view ◄ Selection Behavior) determines how controls are selected with the mouse. You can enclose them fully (the rectangle must completely surround the selection) or partially (the rectangle must touch only the control), which is the default.

Make sure you also resize all the controls as shown in the figure. Change the size and shape of the Features Long Text field and the OLE picture field Picture. The OLE picture field displays as a rectangle with no field name in Design view. (It's the bottommost control above the footer in Figure 20.32.)
