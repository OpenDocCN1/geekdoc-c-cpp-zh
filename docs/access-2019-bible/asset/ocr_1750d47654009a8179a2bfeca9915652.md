These spaces can cause some abnormal results, especially when you're appending values with leading and trailing spaces to other values that are clean. To demonstrate this, look at the data set in Figure 11.20.

This is intended to be an aggregate query that displays the sum of the dollar potential for California, New York, and Texas. However, the leading spaces are causing Access to group each state into two sets, preventing you from discerning the accurate totals.

# FIGURE 11.20

The leading spaces are preventing an accurate aggregation.

| State | SumOfDollarPotential |
| --- | --- |
| ca | $26,561,554.00 |
| ny | $7,483,960.00 |
| tx | $13,722,782.00 |
| ca | $12,475,489.00 |
| ny | $827,563.00 |
| tx | $7,669,208.00 |

You can easily remove leading and trailing spaces by using the Trim function. Figure 11.21 demonstrates how you would update a field to remove the leading and trailing spaces by using an update query.
