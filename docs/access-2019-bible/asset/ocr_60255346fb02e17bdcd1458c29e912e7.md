The subquery runs first, giving you the average purchase for all customers. This is a single value that Access then uses to compare the outer query's resulting data set. In other words, the maximum purchase for each customer is compared to the company average. If a customer's maximum purchase is greater than the company average, it's included in the final output; otherwise, it's excluded.

> NOTE
> A subquery that is used with a comparison operator must return a single value.
