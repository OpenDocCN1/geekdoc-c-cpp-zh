# Managing Macro Objects

At this point, you should have a solid sense of how the macro builder works. In this section, let’s dig deeper and explore some of the options for managing macro objects once they’re added to a macro’s design.

# Collapsing and expanding macro items

Notice in Figure 23.11 that each macro item is accompanied by a collapse/expand button to the left of its name in the designer. These buttons allow you to view or hide parts of the macro. In Figure 23.13, you see the same macro with the Group level collapsed.

Collapsing items helps when you need to review large macros and want to see only a subset of the macro at one time. Note that you can also use the Collapse/Expand commands found in the Ribbon.
