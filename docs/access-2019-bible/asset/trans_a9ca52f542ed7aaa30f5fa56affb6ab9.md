警告
请注意，Access 不会进行模糊逻辑判断来检查记录是否可能重复。它会按字面意思处理你的请求。例如，如果地址或电话号码稍有输入错误，那么实际上是重复的行也可能被允许保留。这一点你一定要记住，尤其是在处理手动输入数据的文本字段时。

## 填充空白字段

在数据集中填充 null 值只需运行一个更新查询。在图 11.12 所示的示例中，你将 DollarPotential 字段中的 null 值更新为零。
