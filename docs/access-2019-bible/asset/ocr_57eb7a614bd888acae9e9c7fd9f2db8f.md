> Tip
> If you already know the name of the form you want to add to the navigation form, you can type it in a new tab. # Multiple-items forms

Click the More Forms button in the Forms group of the Create Ribbon and then click the Multiple Items button to create a tabular form based on a table or query selected in the Navigation pane. A tabular form is much like a datasheet, but it's much more attractive than a plain datasheet.
