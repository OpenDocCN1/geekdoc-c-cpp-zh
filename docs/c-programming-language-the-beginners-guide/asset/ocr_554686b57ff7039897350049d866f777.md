# Chapter 11: C language Arrays

An array is simply a collection of more than one of the same type of variable. For example, a list of high scores is a type of array, as would be how many miles you run per day, even if that list contains lots of zeros. Of course, strings in the C language are an array of single character variables.

In this section, we introduce the concept of an array. You’ll see how to create an array, how to fill it with data, how to access that data, and we’ll also divulge some secrets about character arrays also known as strings.
