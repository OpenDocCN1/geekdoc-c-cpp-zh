# Puts Function

Each function is designed to send one or more characters to the standard output device, which is the screen or terminal window. The puts function puts, or sends a string of text to standard output. “Puts” is put string, and a string is a collection of characters enclosed in double quotes. This function is defined in the STDIO.IO header file, which is included at line one of your dummy program.

In the source code below, we’ve specified the puts function, but omitted the string. Your job is to type this source code in your editor, and supply the string.

```
```c
1  #include 2
3  int main()
4  {
5  puts();
6
7  return(0);
8  }
9
10
```
```

Click inside side the parenthesis and type the string argument for the “puts” function. Type a double quote. The editor automatically supplies the closing quote. Type the text of your choice. If the editor does not supply the closing quote, you must type it. Otherwise, the compiler will not see the end of the string, and an ugly error will be generated.
