# ***Else if Statements***

When three or more conditions are present, you can evaluate them using an *else if* structure. Take a look at the code below:

```
```c
#include <stdio.h>
int main()
{
    int a;

    printf("Type an integer: ");
    scanf("%d", &a);
    printf("You typed %d.\n", a);
    if(a > 10)
    {
        printf("%d is greater than 10.\n", a);
    }
    else if(a < 10)
    {
        printf("%d is less than or equal to 10.\n", a);
    }
    else
    {
        printf("%d is 10.\n", a);
    }
    return(0);
}
```
