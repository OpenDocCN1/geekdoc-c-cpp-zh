# If Statements

Before you can use the *if* keyword, you must understand how comparisons work in C. Two values or expressions are evaluated. To make that evaluation, you use one of the C language’s comparison operators. Here are the most common comparison operators:

+   - == “Equal to”
+   - > “Greater than”
+   - < “Lesser than”
+   - <= “Less than or equal to”
+   - >= “Greater than or equal to”
+   - != “Does not equal”
+   
+   Take a look at the code below:

```
```c
#include <stdio.h>

int main();
{
    int a;

    printf("Type an integer: ");
    scanf("%d", &a);
    printf("You typed %d.\n", a);
    if (a > 10)
        printf("%d is greater than 10.\n", a);

    return(0);
}
