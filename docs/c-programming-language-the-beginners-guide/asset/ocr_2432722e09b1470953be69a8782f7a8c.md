2 to the 8th power is 256. Generally speaking, all C language math functions require the inclusion of the math.h header file. They all work with real numbers. We used floating point numbers in our previous example, but officially they should be double-type variables. The double carries twice the precisions of a float. That means, it is more accurate. But it should really be used only when a greater degree of precision is required.
