# Functions

The real workhorses of the C language are functions. What the keywords do is really basic. To do more in C, you rely upon a function. The functions are held in libraries. The linker's job is to combine the library with your program's object code; knitting the two together to make a program.

To use a function in a program, you must incorporate a header file, which defines the function. You will see how that's done in the later chapters.
