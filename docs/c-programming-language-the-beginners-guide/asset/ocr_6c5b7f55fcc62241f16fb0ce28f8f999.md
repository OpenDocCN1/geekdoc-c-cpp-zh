# Chapter 13: C Language Time Functions

We’ve yet to encounter a programmable device that didn’t have some sort of internal clock. The computer has a clock, and thanks to the Internet, modern computers keep accurate track of the time. When your code needs to access that information, you dip into the C language library's assortment of time functions.

In this chapter, you'll see how time functions work in the C language. You'll learn how to check the time, read time values, and how to gather information about the current date. The code below uses the direct value generated by the time function, as shown by the second argument in the printf function at line 6:

