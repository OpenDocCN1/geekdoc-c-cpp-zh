In the terminal window that appears, type your name and press the Enter key. As you can see, the string is read and displayed. Now, for the peculiarities. Run the program again. This time, assume that your name is Jerry Bob, which are two words. The `scanf()` function stops reading characters at the first white space character—a space, tab, or new line. There’s no way you can force `scanf()` to read in those characters. It is just the way it works. Basically, `scanf()` is really a string input function where the strings are just one word long.

A better function to use for reading strings is *fgets*. Fgets is a file input function that can also be used to read standard input. Take a look at the code below:

```
```c
#include <stdio.h>
int main()
{
char input[64];

printf("Instructions: ");
fgets(input,64,stdin);
puts("Thank you! Here are your instructions:");
puts(input);

return(0);
}
