The terms "Interoperability" and "Coexistence" are sometimes used in place of 
migration but are different concepts:

Interoperability is the ability of two systems to understand each other and, therefore, be 
able to exchange information. For example, two different e-mail servers may be able to 
exchange mail messages thanks to Simple Mail Transfer Protocol (SMTP).

Coexistence is the ability of two systems to operate on the same resource. For example, 
two different file systems can both be installed on the same computer, but they cannot read 
each other's files. A system that can read from or write to both file systems provides a 
migration path.

A migration strategy should consider:

+   - Data Migration
+   - Application Migration
+   - User Migration

Migration should not be confused with new development. And other concepts and 
principles should also be considered in a migration roadmap:

+   - Keep it simple
+   - Methodology
+   - Simplicity, Openness, Scalability (SOS)
