# ***Character Manipulation Functions***

So much goes on with characters that the C library offers a host of character manipulation functions. In this section, we introduce a few of those functions and show you how to use them in your code. As a bonus, we offer an introduction to logical expressions, which can also come into play when working with characters.

In your C code, characters appear either individually, or marching along in an array called a string. You can manipulate characters one at a time or, more commonly, in the string. The code below includes a ctype.h header file, which prototypes the character testing and manipulation functions:

```
```c
#include <ctype.h>

int main()
{
    int ch = 'a';

    printf("Big %c\n", toupper(ch));
    printf("Little %c\n", tolower(ch));

    printf("What begins with %c?\n", ch);
    return(0);
}
