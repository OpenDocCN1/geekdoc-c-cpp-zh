# **Chapter 12: C Language Structures**

Another variable type in the C language is the structure. It is actually a combination of existing variable types all tied together into a single unit. A structure variable simply has many parts like a record in a database. This chapter presents the concept of the structure. You’ll see how to set up a structure, create structure variables, and how to access structure members.
