An if statement is traditionally formatted differently from other statements. It is split between two or more lines. The first line sets the if condition in parenthesis. If that condition is evaluated as true, the next line is executed. Actually, it is just one statement split between two lines. See how the semi-colon is at the end of line 11 and not at line 10.
