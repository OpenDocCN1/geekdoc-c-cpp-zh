```
~~~c
(b) int main()
{
    int a = -2;
    printf("%d", -a);
    return 0;
}
~~~
```

Output: 2
Explanation: In example (b) unary minus (for negation) operator is used twice. Here, math-rule "minus * minus = plus" is to be applied. However, one cannot give -a instead of --2 because the -- operator can only be applied to variables as a decrement operator (e.g., i--). 2 is a constant and not a variable.

```
~~~c
(c) int main()
{
    int a=5;
    printf("%d", !a);
    return 0;
}
~~~
```

Output: 0
Explanation: In the expression !a?5:0 the NOT (!) operator has more precedence than the ?: symbol. ! is a unary logical operator. !a is 0 (NOT of true is false). 5?0 is false (zero).

```
~~~c
(d) int main()
{
    printf("abc\rdef");
    printf("ghi");
    return 0;
}
~~~
```

Output: defghi
Explanation: The escape sequences \n, \b and \r stand for newline, backspace, and carriage return respectively.

```
~~~c
(e) int main()
{
    printf("abc\b\b\bhai");
    return 0;
}
~~~
```

Output: hai
Explanation: The escape sequences \n, \b and \r stand for newline, backspace, and 'carriage return' respectively. At first, 'abc' is printed on console. The \b deletes the character 'c' of 'abc' and appends 'd'? Therefore, 'ab' is printed. Then, \r causes to position the cursor at 'a' of

'as' and replace 'as' with 'ha'. As a result, finally 'hai' is printed on the screen.

```
~~~c
(i) int main()
{
    int i;
    printf("%d", !scanf("%d",&i));
    return 0;
}
~~~
```

Output 0
Explanation: ! is a logical operator. In C, the value 0 is considered to be FALSE, and any non-zero value including negative value, is considered to be the Boolean value TRUE. Here, 2 is a non-zero value, so TRUE. !TRUE is FALSE (0); so it prints 0.
