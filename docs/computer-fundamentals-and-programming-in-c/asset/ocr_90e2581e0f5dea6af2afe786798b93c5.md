7. **If a computer contains RAM, why does it need ROM too?**

Normally, the instructions and data are stored in a secondary storage devices permanently. In addition to data and program instructions currently being processed, RAM also holds operating system instructions that control the basic functions of a computer system. These instructions are loaded into RAM every time when the computer is booted, and they remain resident until the computer is turned off. But RAM is a volatile memory i.e. its content will be lost when the power is turned off. Now ROM plays the important role: ROM contains a small set of instructions called the BIOS (Basic Input Output System). These instructions access the hard disk, find the operating system, and load it into RAM. After the operating system is loaded, the system is ready to be used.
