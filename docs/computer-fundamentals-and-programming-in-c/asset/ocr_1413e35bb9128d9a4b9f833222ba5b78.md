# ### DATA STRUCTURES USING C [9780198065449]

Reema Thareja,  
Assistant Professor, Shyama Prasad  
Mukherjee College for Women, Uni-versity of Delhi

The book starts off with an overview of the concepts of C programming followed by pointers and functions, and then connects these concepts and applies them to the study of various data structures such as arrays, strings, linked lists, stacks, queues, trees, and graphs.

# #### Key Features

+   - Provides a brush-up of C programming basics before delving into the analysis of data structures
+   - Includes a chapter on AVL trees, M-way search trees, B and B+ trees, red-black trees, and splay trees
+   - Makes use of numerous algorithms, programs, and illustrations to explain the concepts

# ### DISCRETE MATHEMATICS [9780198065432]

S.K. Chakraborty, Associate Professor, Department of Applied Mathematics, BIT Ranchi;  
B.K. Sarkar, Assistant Professor, Department of Information Technology and MCA, BIT, Ranchi

The book begins with a detailed analysis of modern mathematical concepts like sets, relation and functions, and matrices, and then delves into core concepts of discrete mathematics like logic and truth tables, groups, order relation and lattices, Boolean algebra, trees, and graphs.

+   - Lays emphasis on the applicability of mathematical structures to computer science
+   - Includes separate chapters on combinatorics and automata theory
