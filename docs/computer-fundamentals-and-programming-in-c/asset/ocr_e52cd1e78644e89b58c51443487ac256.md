```
    int i, j;

    }
```

The array’s contents can be kept contiguous with the explicit pointer arithmetic.

```
int **arr = (int **)malloc(nrows * sizeof(int *));
arr[0] = (int *)malloc(nrows * ncolumns * sizeof(int));
for(i = 1; i < nrows; i++)
    arr[i] = arr[0] + i * ncolumns;
```

One way of dealing with the problem is through the use of the typedef keyword. Consider the following program.

```
#include <stdio.h>
#include <stdlib.h>
#define COLS 5
typedef int RowArray[COLS];
RowArray *rptr;
int main(void)
{
    int nrows = 10;
    int r, c;
    rptr = malloc(nrows * COLS * sizeof(int));
    for(r = 0; r < nrows; r++)
    {
        for(c = 0; c < COLS; c++)
        {
            rptr[r][c] = 0;
        }
    }
    return 0;
}
```

Here, it has been assumed that an ANSI compiler has been used, so a cast on the void pointer returned by malloc() is not required. If an older K&R compiler is being used, it will have to cast using

```
rptr = (RowArray *)malloc(...);
```
