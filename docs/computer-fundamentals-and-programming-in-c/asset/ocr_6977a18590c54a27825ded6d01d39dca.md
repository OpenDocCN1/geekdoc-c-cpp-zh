A semicolon before the printf statement implies that the loop only increments the value of c. No executable statement is included in this for loop, i.e., there is no statement in the statement block. The output will be 6, as the loop continues up to c=5. When the value of c is 6, the loop terminates as the test expression evaluates false.

# ### Some variations of for loop

From a syntactic standpoint, all the three expressions initialization, test expression, and updating need not be present in a for statement, though semicolon must be present. However, the criteria and consequences of an omission should be clearly understood.

Any initialization statement can be used in the first part of the for loop. Multiple initializations should be separated with a comma operator.
