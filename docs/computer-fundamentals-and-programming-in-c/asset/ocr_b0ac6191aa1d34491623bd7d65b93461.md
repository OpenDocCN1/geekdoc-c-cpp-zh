The use of the conditional expression frequently shortens the amount of source code that must be written. For example, a lengthy function call which has several argument expressions, one of which is conditional, needs to be written only once.

The conditional expression is not only a shorthand; it may also result in less object code than would be generated by other alternative means, e.g., by the use of one or more if statements.

Observe that parentheses are normally not needed around the expressions that are separated by the characters '?' and ':' because, as the operator precedence table shows, the '?' operator has a very low precedence, i.e., it is usually applied last.
