be accessed outside the loop. The ANSI/ISO Standard restricts the variable to the scope of the for loop.

# ## Note

+   - If the test expression is omitted, however, it will be assumed to have a permanent value of true; thus the loop will continue indefinitely unless it is terminated by some other means, such as a break or a return statement (see Section 10.8).
+   - Multiple initializations should be separated with a comma operator.
+   - Multiple relational expressions in the test expression must be connected using logical operators && or ||.
+   - A floating-point variable should not be used as the control variable because floating-point values are sometimes approximated and may result in imprecise counter values and inaccurate test for termination.
