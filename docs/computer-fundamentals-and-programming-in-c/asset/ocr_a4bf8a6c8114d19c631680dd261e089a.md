Just as the decimal system with its ten digit symbols is a number system with base 10, the octal number system with its 8 digit symbols, ‘0’, ‘1’, ‘2’, ‘3’, ‘4’, ‘5’, ‘6’ and ‘7’, has eight as its base. Table 2.7 shows the weights for an octal number that has three decimal places before and two digit places after the octal point (.).

To express a given octal number as its decimal equivalent, each bit is multiplied by its associated weight and the summation of these gives the decimal number.
