```
The following program checks whether a string given by the user is a palindrome or not. In this program, the first character s[0] and the last character s[n-1] are compared. Then the second character s[1] and the last but one character s[n-2] are compared, and so on. This process will be continued up to half the length of the string. If characters are found to be different during any comparison, then the string is not a palindrome. Else it is a palindrome.

```
```c
#include <stdio.h>
#include <string.h>
int main()
{
    int n,i,j,chk=1;
    char s[30];
    printf("\n Enter the string:");
    scanf("%[^\n]s",s);
    n=strlen(s)-1;
    for(i=0,j=n;i<n/2;i++,j--)
        if(s[i]!=s[j])
        {
            chk=0;
            break;
        }
    if(chk==1)
        printf("String is Palindrome");
    else
        printf("String is not Palindrome");
    return 0;
}
```
