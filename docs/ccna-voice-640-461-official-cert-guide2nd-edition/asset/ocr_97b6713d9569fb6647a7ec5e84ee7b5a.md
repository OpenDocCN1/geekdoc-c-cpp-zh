# Figure 13-9 User Template: Phone Menus

+   - **For New Messages, Play:** Check each box as desired to hear message counts for Totals (all new messages), E-mails, Faxes, and Receipts.
- **For Saved Messages, Play:** Check this box to CUC announce the number of saved messages.
- **Before Playing Messages, Play:** Check the Message Type Menu to hear a list of key options for each type of message.
- **New Message Play Order and Saved Message Play:** Use this set of preferences to set the order in which CUC plays messages to the users. To hear e-mails and faxes, you must ensure a CoS that allows the Access to E-mail Message Stores and Fax features enabled. If there are fax messages, CUC announces the sender, date, and time (it does not read the fax).
- **Before Playing Each Message, Play:** Check each box as desired to hear any (or all) of the following:
- **Sender's Information:** Recorded name or ANI for internal callers; ANI for outsiders is not called.
- **Include Extension:** In conjunction with the Sender's Information checkbox, selecting this checkbox allows CUC to play the extension of an internal caller and the recorded name (if available).
- **Message Number:** CUC announces the sequential number of messages in the mailbox as it plays them.
