+   Managing CME Using the Command Line:

+   Managing CME Using a Graphic User Interface:
Over the last few years, Cisco has released many different GUI-based utilities for configuring and interacting with Cisco routers and switches. Cisco Configuration Professional (CCP) has evolved to become the most fully functional all-in-one graphic interface for managing your CME router. This section discusses the CCP interface and common configuration areas.
