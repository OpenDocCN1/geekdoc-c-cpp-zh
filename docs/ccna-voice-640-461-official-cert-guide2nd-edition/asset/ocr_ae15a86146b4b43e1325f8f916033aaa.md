# Enabling Call Coverage

This section describes the configuration steps to enable the following Call Coverage features:

+   - Shared Lines
- Barge and CBarge
- Call Pickup
- Call Park and Directed Call Park
- Call Hunting

# Configuring Shared Lines

When two or more devices are configured with the same DN, it is called a shared line. The configuration is straightforward: Simply add the DN to multiple phones, either from the DN Configuration page or the Phone Configuration page via the Phone Button configuration.
