## Cisco Unified Serviceability: Serviceability Reports Archive

CUC includes a built-in reporting system to monitor server health and performance. These reports are accessed through the Unified Serviceability web application (not to be confused with the CUC Serviceability application). To access these reports, you must first activate the Serviceability Reporter.

The Serviceability Reporter collects data from logs and populates the Serviceability Archive, which stores report information and makes it available on a daily basis. It is a CPU-intensive service, so consider activating it will impact server performance. In Unified Serviceability, navigate to Tools > Reports to the following:

- Enable Audit Log: Unchecking this box stops the recording of stored procedures. The default setting is Enabled.

## Key Topic

- Maximum Entries Allowed in Audit Log: This setting limits the number of entries in the Audit Log. When the defined number is exceeded, the oldest entries are overwritten. Values are between 1 and 100,000. The default is 100,000.
- Enable Security Log: Unchecking this box stops the logging of stored procedures.
- Maximum Entries Allowed in Security Log: This setting limits the number of entries in the Security Log. When the defined number is exceeded, the oldest entries are overwritten. Values are between 1 and 100,000. The default is 100,000.
- Minutes Between Data Cycles: This value controls how frequently data is gathered. The default is 30.
- Days to Keep Data: Determines how many days of historical data should be kept in the reports database. The default is 90 days. Note that if the report specifies a date range of more than 90 days, the report will still be limited to this setting's value.
- Reports Database Size (as a Percentage of Capacity) After Which the Reports Harvest Is Disabled: Sets the maximum percentage of disk space the reports database may take up. When the value is reached, the CUC Report Harvest service is stopped, preventing the database size from growing. The default value is 80%.
- Maximum Records in Output: Limits the number of records presented in the report. The allowed range is from 5,000 to 30,000; the default is 25,000. Some reports impose their own restrictions due to the size of the report (for example, User Message Activity is limited to 25,000).
- Minimum Records Needed to Display Progress Indicator: This value determines whether running a report will cause a message to pop up before the report is generated, and a progress bar to be shown as it. The idea is to provide a warning that the selected report is large and may impact server performance. The allowed range is from 1 to 10,000. The default is 2,500.
