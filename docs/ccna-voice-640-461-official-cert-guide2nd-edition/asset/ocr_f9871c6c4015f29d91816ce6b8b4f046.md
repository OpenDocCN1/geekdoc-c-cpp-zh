conference bridge (available on most IP Phone models) must be activated. The privacy feature removes the call information from all phones that share lines and blocks other shared lines from barging in its calls. The following steps describe how to configure Barge

+   1. In CM Administration, navigate to System > Service Parameters. Select the server you want to configure from the Server drop-down.
2. Select the Cisco CallManager service from the Service drop-down.
3. Scroll down to the Clusterwise Parameters (Device-Phone) section. Built-in Bridge Enable On.
4. Set the Privacy Setting to True (the default).

**Note:** The Built-in Bridge, Privacy, Privacy, and Single Button settings can be overridden at the Device Pool or the individual phone if desired.

+   5. Scroll down to Clusterwise Parameters (Feature-Join Across Lines And Single Barge Feature Set) and set the Single Barge/CBarge Policy. Your choices are Off, Barge, CBarge. This setting allows pressing the shared line button to cause a Barge onto the shared line when it is in use (instead of using the softkey). Setting the value to Barge uses the built-in bridge on the target phone, while setting it to CBarge forces the Barge operation to use an external conference resource.
