Because you will be accessing the GUI through a web interface, you need to turn the CME router into a mini-web server to serve up the CME pages. The configuration in Example 7-17 completes this.

**Example 7-17** Configuring the CME Router as a Web Server

```
CME_Voice(config)# ip http server
CME_Voice(config)# ip http secure-server
% Generating 1024 bit RSA keys, keys will be non-exportable...[OK]

ME_Voice(config)# ip http path:/flash/
CME_Voice(config)# ip http authentication location
```

![](img/e4ad7862dc47b4e5de0cde3b4550ad65_240_0.png)

Example 7-17 enables both the HTTP (ip http server) and HTTPS (ip secure-server) services on the router. Of course, HTTPS is the preferred method of accessing the CME GUI because the CME router encrypts all communication. The ip path flash/command sets the HTTP server to use files from the GUI subdirectory of flash memory of the CME router for HTTP requests. Finally, the CME router uses its local user database to authenticate users accessing to the web interface.

**Note:** You might need to change the argument of the ip path flash command based on where the HTML files are located for the CME GUI. Earlier versions of CME placed CME files directly into flash without any directory structure. In this case, the command should be entered as **ip path flash**.

The next step in enabling the CME GUI is to create a user account with permission to access and manage the CME router. Example 7-18 configures this.

# Example 7-18 Creating a CME Web Administrator Account and Adding Permissions

```
CME_Voice(config)# telephony-service
CME_Voice(config-telephony)# web admin ?
  customer admin
  system admin
CME_Voice(config-telephony)# web admin system ?
  name admin username
  password admin password
  secret secret password
CME_Voice(config-telephony)# web admin name ?
  username for admin
CME_Voice(config-telephony)# web admin name NinjaAdmin ?
  password admin password
  secret secret password
CME_Voice(config-telephony)# web admin name NinjaAdmin secret ?
  ENCRYPTED password will follow
  ENCRYPTED password will follow
CME_Voice(config-telephony)# web admin name NinjaAdmin secret @
  Admin password
CME_Voice(config-telephony)# web admin name NinjaAdmin secret @isco
  dn-service
CME_Voice(config-telephony)# time-service
```

![](img/e4ad7862dc47b4e5de0cde3b4550ad65_241_0.png)

By default, the CME GUI is not able to add phone-dns to the CME configuration or modify the time on the CME router. The dn-service and time-service commands unlock these functions.

Note: If you are synchronizing your router's clock via NTP, do not enter the time-command, to ensure that the time remains the more accurate NTP server.

The CME router's web interface is now ready to go. The final step is to connect to the CME router using a supported web-browser. From the supported web browser, enter http://<CME_IP_Address>/ccme.html to access the CME GUI. After authenticating your web account, the CME management console is displayed, as shown in Figure 7-24.
