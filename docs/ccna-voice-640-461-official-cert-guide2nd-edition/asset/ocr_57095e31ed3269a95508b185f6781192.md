Technically, the intercom deplments is through a speed-dial and auto-answer speed-dial configuration. If the administrative assistant presses the button configured as an intercom, it dials the executive's phone, which auto-answers the call on muted speakerphone. To establish two-way communication, the executive deactivates mute (by pressing the M button). Understanding this helps the intercom configuration much clearer.

To configure intercom functionality, you must configure two ephone-dns, one for each side of the intercom connection. These intercom lines should be assigned a number, just like any other ephone-dns. However, to prevent others from accidentally (or purposely) dialing the intercom and ending up on muted speakerphone for a random IP phone, the number should be something users cannot dial from other IP phones. The configuration in Example 7-8 achieves this objective.

# 7-8 Configuring Intercom

| Key Topic | CME_Voice(config)# ephone-dn 60 |
| | CME_Voice(config-ephone-dn)# number A100 |
| | CME_Voice(config-ephone-dn)# intercom A101 label "Manager" |
| CME_Voice(config-ephone-dn)# exit |
| | CME_Voice(config-ephone-dn)# number A101 |
| | CME_Voice(config-ephone-dn)# intercom A100 label "Assistant" |
| | CME_Voice(config-ephone-dn)# exit |
| | CME_Voice(config-ephone-dn)# ephone 1 |
| | CME_Voice(config-ephone-dn)# button 2:60 |
| | CME_Voice(config-ephone-dn)# restart |
| | restarting 0014.C149.E71A |
| | CME_Voice(config-ephone-dn)# exit |
| | CME_Voice(config-ephone-dn)# ephone 2 |
| | CME_Voice(config-ephone-dn)# button 2:61 |
| | CME_Voice(config-ephone-dn)# restart |
| | restarting 0019.D122.DCF3 |

Notice the assignment to ephone-dn 60 is A100. You cannot dial this number from a Cisco IP Keypad, but you can assign it to a speed-dial. The intercom acts like a speed-dial button on the ephone-dn. In the case of ephone-dn 60, the command intercom A101 dials the number A101, which is assigned to ephone-dn 61. Because ephone-dn 61 is also configured with the intercom command, it auto-answers the incoming call on muted speakerphone. The label syntax allows you to assign a logical name to the speed-dial; the A101 or A100 label will show up next the line button on the phone. There are three other arguments you can use with the intercom to tune the functionality:

+   - **arge-in**: Automatically places an existing call on hold and holds the intercom to immediately answer.
- **no-auto-answer**: Causes the phone to ring rather than auto-answer on speakerphone.
