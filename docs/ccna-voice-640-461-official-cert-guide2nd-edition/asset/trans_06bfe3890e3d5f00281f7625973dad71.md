

# 激活并下载模拟考试

安装考试引擎后，您应该按照以下步骤激活与本书相关的考试（如果您在安装过程中尚未操作）：

- **步骤 1**。从 Windows 开始菜单或桌面快捷图标启动 Pearson 认证实践测试 (PCPT) 软件。
- **步骤 2**。若要激活并下载与本书相关的考试，请从“我的产品”（My Products）或“工具”（Tools）选项卡中选择“激活”（Activate）按钮。
- **步骤 3**。在下一个屏幕上，输入书后纸板 CD 盒内的激活密钥（Activation Key）。输入完成后，点击“激活”按钮。
- **步骤 4**。激活过程将下载模拟考试。点击“下页”（Next），然后点击“完成”（Finish）。

激活过程完成后，“我的产品”选项卡上将列出您的新考试。如果您没有看到该考试，请确保您已选择了菜单上的“我的产品”选项卡。此时，软件和模拟考试已准备就绪。只需选择考试并点击“使用”（Use）按钮即可。

若要更新已激活并下载的特定考试，只需选择“工具”选项卡和“更新产品”（Update Products）按钮。更新考试可确保您获得考试数据的最新更改和更新。

如果您想检查 PCPT 考试引擎软件的更新，只需选择“工具”选项卡并选择“更新应用程序”（Update Application）按钮。这可以确保您运行的是最新版本的软件引擎。

# 激活其他考试

考试安装过程和注册过程只需一次。之后，对于每项新考试，仅需几个步骤。例如，如果您购买了另一本新的 Cisco Press 官方认证指南或 Pearson IT 认证指南，请从该书后的 CD 封中提取激活代码——此时您甚至不需要 CD。您只需要启动考试引擎并执行上版列表中的步骤 2 到 4 即可。

# 最终复习/学习建议计划

本节列出了从您读完第 17 章到参加 640-461 ICCOMM 考试之间的建议学习计划。当然，您可以忽略此计划、按计划执行，或仅参考其中的建议。

该计划分为六个步骤：

- **步骤 1**。复习关键主题和 DIK 问题：
    - 您可以使用列每章关键主题的表格，或直接翻阅页面寻找关键主题。此外，复习章节开头的“我已经知道这些吗”（Do I Know This Already）问题对复习很有帮助。
- **步骤 2**。使用 PCPT 引擎进行练习：
    - CD 上的 PCPT 引擎可以使用本书专有的独特真实考试题库进行学习。
- **步骤 3**。复习薄弱环节：
    - 完成模拟考试将揭示您可能想要复习和学习的主题。花时间填补知识漏洞并尝试再次模拟考试。然而，注意不要过度进行模拟考试，因为您可能仅仅因为开始记忆模拟测试的答案而产生虚假的自信。在尝试正式考试之前，请确保您真正理解了内容。
- **步骤 4**。安排并参加 640-461 ICOMM 考试：
    - 在真实的认证考试环境中测试您的知识！虽然我们祝您好运，但请记住，Cisco 认证考试是行业内难度最大的之一，除了技术知识外，还有许多因素影响最终考试结果。
- **步骤 5**。根据结果进行学习：
    - 离开认证中心时，您将知道考试结果。如果通过了，恭喜您！如果没有，写下您在考试中感到困难的领域或主题。在学习中，将 90% 的时间放在这些内容领域，10% 的时间复习其他领域。
- **步骤 6**。重复步骤 4 和 5 直到获得认证！
