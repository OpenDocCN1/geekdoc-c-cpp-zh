# Example 6-10 Configuring a POTS Dial Peer for a T1 Interface

```
ROUTER_B(config)# dial-peer 2000 pots
ROUTER_B(config-dial-peer)# destination-pattern 2...
ROUTER_B(config-dial-peer)# no digit-strip
ROUTER_B(config-dial-peer)# port 1/0:23
```

It's simple. Notice that you can use the “.” wildcard to represent any dialed digit. This instructs the router to send all XXXXX extensions out port 1/0/23 (the T1 PRI interface). One additional command in this example brings a big point of discussion: no digit-strip. This command prevents the router from automatically stripping dialed digits from this dial peer.
