# Glossary

- **802.1Q**: A trunking protocol that allows traffic between VLANs.
- **802.3af**: Power over Ethernet (PoE) which supplies power to devices.
- **Administrative**: A subscriber that is a member of the administrators group.
- **Automatic attendant**: A feature that answers incoming calls to the appropriate person.
- **Automatic Number Identification (ANI)**: Describes caller ID.
- **Call Detail Record (CDR)**: A log of specific information about a call.
- **Cisco Unified Communications Manager**: A multiserver platform capable of supporting up to 30,000 users.
- **Cisco Unified Communications Manager Business Edition**: A single-server platform capable of up to 500 users.
- **Cisco Unified Communications Manager Express (CME)**: A platform capable of supporting up to 250 users.
- **Cisco Unified Contact Center**: A call center application capable of supporting up to 300 agents.
- **Cisco Unified MeetingPlace**: A conference solution for voice, video, and data.
- **Cisco Unified Mobility**: Allows users to have a single contact number linked to multiple devices.
- **Cisco Unified Presence**: Provides status and reachability information for users.
- **Cisco Unified Serviceability**: Reports on alerts and server statistics.
- **Cisco Unity**: A unified messaging platform capable of supporting up to 7,500 users per server.
- **Cisco Unity Connection**: A single-server platform capable of supporting up to 7,500 users.
- **Cisco Unity Express**: A messaging platform integrated into a CME router, supporting up to 250 users.
- **Cisco Unity Express administrator**: A subscriber in the administrators group.
- **Cisco Unity Express Advanced Integration Module (AIM-CUE)**: A hardware platform for Cisco Unity Express providing up to 50 mailboxes and 12 ports.
- **Cisco Unity Express automated-attendant (AA) script**: A collection of software steps defining actions on a received call.
- **Cisco Unity Express CLI**: The command-line interface for configuring and administering Cisco Unity Express.
- **Cisco Unity Express custom scripting**: The act of modifying the default Cisco Unity Express AA script.
