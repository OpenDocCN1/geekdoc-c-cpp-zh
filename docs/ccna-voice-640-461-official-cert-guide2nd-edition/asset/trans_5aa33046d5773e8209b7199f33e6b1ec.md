CUCM 拨号计划的构建模块简单且一致。当实现多条分级路径并启用不同的功能和能力时，复杂性的可能性将会增加。本节识别了核心元素并解释了它们的相互作用。

# CUCM 中的呼叫路由源

呼叫路由请求（包括但不限于简单的电话）可以源于以下任何位置：

- IP 电话：使用其配置的线路之一下发路由请求。这可能是手动拨号的号码、快捷拨号、功能按钮或软键。
- 中继 (Trunk)：指示来自另一个 CUCM 集群、CUEME 或或其他呼叫代理的入站呼叫。
- 网关 (Gateway)：指示来自 PSTN 或另一个呼叫代理（如主分支交换机 PBX）的入站呼叫。
- 翻译模式 (Translation pattern)：匹配原始被叫数字并立即将其转换为新的拨号数字。新字符串将重新提交给数字分析进行路由。
- 语音信箱端口 (Voicemail port)：如果应用程序代表用户信箱尝试进行呼叫、转移或消息通知，则它可以作为呼叫路由请求的源。

呼叫路由请求仅仅是上述条目之一通过一组拨号数字指示 CUCM。这些数字可以由用户在电话上手动拨号，由 Cisco Unified Connection 等应用程序自动拨号，或通过中继或网关由另一个系统拨。

# CUCM 中的呼叫路由目的地

以下是 CUCM 中可能的呼叫路由目的地：

- 目录号码 (DN)：IP 电话上的每个按钮都可以分配一个唯一的分机号。
- 翻译模式 (Translation Pattern)：匹配拨号数字字符串并将其转换为新的拨号字符串，然后将其重新提交给数字分析并路由到不同的目标。
- 路由路模式 (Route Pattern)：匹配拨号数字字符串并触发呼叫路由过程，该过程可以包含一个或多个潜在路径，提供分级的呼叫路由选项。
- 寻号主 (Hunt Pilot)：一种特定的数字模式，匹配时会触发可自定义的呼叫覆盖系统。
- 呼叫等待号码 (Call Park Number)：CUCM 可用于临时保留呼叫的模式或模式范围，直到用户拨打呼叫号码从任何 IP 电话接听。
- 会议号码 (Meet-Me Number)：会议发起者拨入会会号码以开始会议，一个或多个用户拨入同一个号码加入会议。

上述目的地由可拨号数字字符串表示。拨号计划必须为所有这些目标分配数字范围，并且配置 CUCM 适当路由到它们（如有必要，不路由到它们）。

# 呼叫路由配置元素

CUCM 呼叫路由系统的主要组件是：

- 路由路模式 (Route Patterns)
- 路由列表 (Route Lists)
- 路由组 (Route Groups)
- 网关/中继 (Gateways/Trunks)

# 路由路模式 (Route Pattern)

路由路模式 (Route Pattern) 匹配拨号数字字符串。模式可以是特定的（匹配单个拨号号码），也可以是通性的（匹配数十万可能的号码）。这种变精度通过模式中的通配符数字进行配置。路由路模式允许管理员指定任何拨号数字字符串的目标。

路由路模式对于提供 PSTN 拨号访问是必要的。它们还可以用于将 CUCM 拨号计划与现有 PBX 拨号计划集成；在这种情况下，路由路模式将匹配由 PBX 控制的所有 DNS（分机）。事实上，路由路模式可以自定义以允许所有用户拨号并到达任何所需的终端。

路由路模式与路由列表 (Route List) 或特定网关 (Specific Gateway) 关联。

> 注意：如果路由路模式直接关联网关（而不是路由列表），则选定的网关将不再被路由组引用；该网关被“锁定”在路由路模式中。在小型部署中，这可能不是问题，但在大型部署中，这样做会限制系统的灵活性。

# 路由列表 (Route List)

路由列表是路由组的有序列表。列表中的第一个项目是首选路径；如果该路径不可用（由于故障或无通道），则尝试第二个选择。路由列表的层次允许管理员提供覆盖深度。例如，如果路由路模式匹配的远距离号码关联到一个将首选项列为中继交换机运营商 (IXC) 的路由列表，那么只要有可用通道，呼叫就会路由到 IXC。

此时，IXC 被拒绝，并尝试路由列表的第二个选择。如果第二个选择是本地交换机运营商 (LEC) PSTN 电路，则通过 LEC 链路拨号号码。

# 路由组 (Route Group)

路由组是设备（网关或中继）列表，这些设备支持通往 PSTN 或远程集群的电路。路由组通常配置为包含具有共同特征的设备（例如，一组 PSTN 网关和另一组通往远程集群的 WAN IP）。

路由组的分配算法是配置的；选择“自顶 (Top-Down)”会导致每次新呼叫按自顶顺序使用组内的设备，而“循环 (Circular)”则按轮询顺序使用设备。系统的特定上下文和需求决定了哪种算法是合适的。

> **注意：** 本地路由组 (Local Route Group) 功能允许管理员在路由池中定义路由组，并在路由列表中引用该本地路由。这样做有效地将 PSTN 网关的位置与目标网关的路由路模式解耦。此功能大大减少了多站点拨号计划设计的复杂性。

# 网关与中继 (Gateways and Trunks)

网关和平继是物理终止并支持到 PSTN、数字或模拟 PBX 以及到远程集群 IP WAN 电路或运营商 IP-TSP 电路的设备。

CUCM 支持各种网关设备和接口，使用对等网关协议（H.323 和 SIP）或网关控制协议（MGCP 和 SCCP）控制它们。
