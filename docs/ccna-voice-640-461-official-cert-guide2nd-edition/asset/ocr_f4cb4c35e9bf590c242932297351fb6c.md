If you have not already connected the IP phone to the network, doing so now causes it to appear as a completely configured device.

Because nearly any verification and troubleshooting is typically a command-line realm, CCP provides a template of show commands you are able to perform using a drop-down box. In addition, CCP enables you to use the drop-down box as a "free form" field where you are able to type any custom show command you want. To access this area in CCP, navigate to Configure > IOS Show Commands. The view section is apart from the normal configuration categories under the Utilities section of CCP.
