Notice the options given by the context-sensitive help when the auto qos voip command was entered. Entering the command auto qos voip cisco-phone or auto qos voip cisco-softphone only enables the trust boundary if CDP detects Cisco IP phone or Cisco IP Communicator (or equivalent IP Softphone device) attached to the port. If a user removes this device, the trust boundary is broken and is not restored until the device is reattached. If you enter the command auto qos voip trust, the switch switches the markings from the attached device regardless of what it is. You need to use this command if you purchase non-Cisco IP phones. Keep in mind that if you use this the network becomes susceptible to users removing the non-Cisco IP phone and attaching rogue devices.

**Note:** The auto qos voip command is entered under the FastEthernet 0/3 interface in Example 6-28, a show run command was performed so that you could see the current syntax entered under the interface. Notice how many commands are generated when entering the auto qos voip command. It is beneficial that the Cisco switch (and router) shows you all the individual commands so that you can optionally tune the settings to exactly fit your environment.

If the configuration generated by the auto qos voip command is not desired, you can remove this configuration simply by entering no auto qos voip.
