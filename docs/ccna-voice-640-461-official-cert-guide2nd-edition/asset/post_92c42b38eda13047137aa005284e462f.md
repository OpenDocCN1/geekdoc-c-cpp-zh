
# Configuring Cisco Unified CME Voice Productivity Features

After implementing the ephone, ephone-dn, and dial-peer concepts, you now have an IP Telephony network that is able to make and place internal and external calls. If only voice networks stayed this simple! Organizations expect modern telephony systems to support a whole host of features, such as call transfer, Music on Hold, conference calling, and so on. This chapter is dedicated to adding these features to the voice network.

## Configuring a Voice Network Directory

When most people think of a corporate directory, visions of Excel spreadsheets emailed come to mind. Isn't there a better way? Sure there is! Cisco IP Phones support a local directory that you can update from Cisco Communication Manager Express (CME) as you configure devices.

You can enter names under ephone-dn configuration either as you are configuring new lines or separately. Example 7-1 shows names being added to individual ephone-dn.

### Example 7-1 Configuring Local Directory and Caller ID Information

```
CME_Voice(config)#ephone-dn 20
ME_Voice(config-ephone-dn)#name Joshua Bellman
ME_Voice(config-ephone-dn)#exit
CME_Voice(config)#ephone-dn 21
ME_Voice(config-ephone-dn)#name Ruth Hopper
ME_Voice(config-ephone-dn)#exit
CME_Voice(config)#ephone-dn 22
ME_Voice(config-ephone-dn)#name Esther Billford
ME_Voice(config-ephone-dn)#exit
CME_Voice(config)#ephone-dn 23
ME_Voice(config-ephone-dn)#name Job Smith
ME_Voice(config-ephone-dn)#exit
CME_Voice(config)#ephone-dn 24
ME_Voice(config-ephone-dn)#name Samuel Oldham
ME_Voice(config-ephone-dn)#exit
```

When you enter these names in ephone-dn configuration mode, they immediately take effect. If ephone-dn 24 to call ephone-dn 21, Ruth would see “Samuel Oldham” appear on her caller ID information, as shown in Figure 7-1.

In addition, all Cisco IP Phone models allow you to browse the corporate directory by pressing the Directory button on the phone itself. Some low-end IP phones may not have a dedicated Directory button, but instead have a menu-driven process to get there. After you press the Directory button, you are able to browse categories including Missed Calls, Received Calls, and so on. Move down to the option showing the Local Directory, as shown in Figure 7-2.
