# Managing CME Using a Graphic User Interface

Managing CME using a Graphic User Interface (GUI) offers a number of advantages, some of which can be seen on the surface, others may not be evident. First, many small offices use an all-in-one administrator whose knowledge is spread across many different technologies. To force this level of administrator to learn a complete command-line operating system to interact with CME is unrealistic. Similarly, some offices consult or contract network administrators to manage their network. Providing an easy-to-use GUI allows one of the more technically inclined users at the office to take care of the day administration (changing directory numbers, adding phones, and so on) without the involvement of IT staff. Finally, the point-and-click of a graphic interface can be more efficient than times typing configuration commands.

Cisco has released multiple GUI management tools to configure CME over the years, two primary are used today: the integrated CME GUI and Cisco Professional (CCP). The integrated CME GUI is powered by HTML and JAR (Java) files loaded into the router. Typically, the CME router ships with these files preloaded into Cisco for; however, you can also download a TAR package from the Cisco website (assuming you have a valid support contract) and extract the files into the router. With minimal command-line configuration (assigning an IP address and enabling the HTTP server), you can have the integrated CME GUI up and running in no time, as shown Figure 4-1.

Although the integrated CME GUI is not "pretty" by today's standards, it is functional, which enables you to handle more core functions of CME: adding/changing phone configurations, modifying the dial-plan, configuring hunt groups, and so on. Keep in mind that this, too, runs from the CME router, so conserving space is more important in Cisco's mind when adding "gloss" to the utility.

Cisco focused the integrated CME GUI on configuring only the telephony aspects of the CME router. It created the CCP to configure all aspects of the CME router. It enables simple (often with wizard-based) configuration of the router, firewall, Intrusion Prevention System (IPS), Virtual Private Network (VPN), Unified Communications, and common WAN LAN features and configurations. You can download the latest version of the CCP software from the Cisco website free of charge. CCP is roughly a 200 MB installation on a local PC. After you install it on your local PC, you can manage any supported Cisco platform using the utility. (You do not need to install anything on the managed devices).
