# QoS Issues

Troubleshooting QoS is a different skill set and strategy for troubleshooting dial-plan issues. Instead of working with the routing table for you, you're working with the traffic itself.

You might have heard the saying before, "If you have no goal, you'll hit it every time." Before we troubleshoot voice quality issues, we need to have a goal we're shooting for. Table 15-2 shows the Cisco recommended parameters for high-quality voice calls.

# Table 15-2 Requirements for High-Quality VoIP Calls

| Parameter | Requirement |
| --- | --- |
| End-to-end (one-way) delay | 150 ms or less |
| Jitter | 30 ms or less |
| Packet loss | 1% or less |
