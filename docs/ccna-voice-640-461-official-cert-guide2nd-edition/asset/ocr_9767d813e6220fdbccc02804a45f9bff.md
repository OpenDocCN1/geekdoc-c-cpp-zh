+   3. Enter a Hunt Pilot number. This behaves the same way as a Route Pattern; you can specify any string you like, including a valid PSTN or DID number.

+   4. Set a Partition, if desired, to control access to the Hunt Pilot.

+   5. In the Hunt List field, select the Hunt List that should be accessed by dialing the Hunt Pilot number.

+   6. Specify an Alerting Name, which displays on phones receiving calls as part of the hunting system.

+   7. Set Hunt Forwarding options to control calls that cannot be handled by the hunting system are sent. Use the Personal Preferences checkbox ignores the configured settings, instead using the CFNC setting of the station that forwarded the call to the Hunt Pilot.

+   8. Click Save.
