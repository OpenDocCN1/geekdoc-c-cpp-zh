In a larger organization, employees sometimes leave the company, and the voicemail administrators may not be aware of. The Unused Voice Mail Accounts Report makes it simple to spot accounts that have not been used recently, allowing the administrator to take the appropriate action. Figure 17-12 shows the Unused Voice Mail Accounts Report.

It is common to track the number of calls that CUC makes, either for statistical purposes or for actual cost billing purposes. Remember that CUC can place calls on the user's request (assuming Co allows allows), and these calls can incur charges. Likewise, CUC performs Message Notification, it is possible that some of those calls may incur charges as well. There are three Billing reports to allow administrators to easily correlate the number and time of these kinds of calls with the user account that caused them to be placed:

+   * Transfer Calling Billing Report lists:

+   * Name, extension, and billing ID of the user

+   * Date/time stamp for the call

+   * Called number

+   * Transfer result (Connected, Ring No Answer, Busy, or Unknown)
