**Note:** If you want to use a Call Park system in which each department has its own Call Park slot, it may be beneficial to configure multiple e-dns assigned to each department designated for Call Park. Otherwise, you will be able to park only one call for each department.

You can answer parked calls in one of three ways:

+   - Dial directly into the call park slot. For example, lifting a phone handset and dialing 3001 answers whatever call is parked at 3001.
- Press the PickUp softkey and dial the call park number that you want to answer.
- From the phone which the call was parked, press the PickUp softkey followed by an asterisk (*) to recall the most recently parked call back to the phone.

Using CCG to configure call park features automates the process quite a bit. First, navigate to the call park configuration window (Unified Communications > Telephony Features > Call Park). Once you arrive there, you can click the Create button to bring up the Create Call Park Entry configuration window. Entering a name creates a description label in the IOS for the call park entry. CCG gives you the option to select the number of slots (call park numbers) as well as the starting number for slots. For example, applying the configuration shown in Figure 7-12 creates ten park slots numbered from 1300 through 1309.
