Cisco Unity Express 增强功能网络模块 (NME-CUE-EC) Cisco Unity Express 的中高端硬件平台，提供最多 250 个邮箱箱、300 小时存储以及 16 个可用于并发语音会话的端口。

Cisco Unity Express 密码 用于通过 GUI 验证订阅者。

Cisco Unity Express PIN 用于通过 TUI 验证订阅者。

Cisco Unity Express 订阅者 在 Cisco Unity Express 中配置的用户账户。

Cisco Unity Express 电话用户界面 (TUI) 为订阅者和管理员提供电话界面，用于使用和管理 Cisco Unity Express 的功能和特性。

限制类别 (COR) 在 CME 环境中实现呼叫限制的方法。入站 COR 列表分配权限，而出站 COR 列表则限制呼叫。

服务类别 (CoS) 一组设置，用于提供或限制对许可功能、高级功能或用户能力的访问。

客户端服务框架 (CSF) CUPC 以及其他 CUC 集成应用程序（如 Microsoft Outlook）的客户端基础架构。

公共信道信令 (CCS) 一种信令方法，通过独立的专用信令信道提交信息。

社区 由 Cisco Configuration Assistant 管理的一组带有 IP 地址的设备。

合规性 对于 CUPC 而言，合规性是指在外部 PostgreSQL 数据库或合规性服务器上保留即时消息 (IM)。

计算机电话接口快速缓冲区编码 (CTTIQBE) 用于 CUPC 电话控制的协议。

拨号对 (dial-peer) 用于在 Cisco 路由器上定义拨号计划信息的逻辑配置。

被叫号码识别服务 (DNIS) 向语音处理设备描述拨号号码信息。与自动号码识别 (ANI) 密切相关，后者识别呼叫者 ID 信息。

## 术语表

**直接内入拨 (DID)** 一种语音配置，允许用户从公共交换网 (PSTN) 直接拨入组织内的个人电话，而无需经过接线员或自动语音应用程序。

**定向摘机 (directed pickup)** 一种与摘机配合的方法，通过拨打响铃电话的分机号直接接听电话。

**灾难恢复系统 (DRS)** 内置的统一平台备份和恢复实用。

**双音多频 (DTMF)** 一种寻号信令类型，电话键盘上的按钮使用一对高低电频，在呼叫者每次按下数字时产生一个信号。

**动态中干协议 (DTP)** 允许交换机动态协商中干链路。

**E.164** 由国际电信联盟 (ITU) 创建并被 PSTN 采用的国际编号计划。

**口和嘴 (E&M)** 作为 PBX 系统中干的模拟接口类型。

**ephone** CME 路由器中的一种配置，代表单个 IP 电话（或 IP 电话设备）。

**ephone-dn** CME 路由器中的一种配置，代表单个目录号码 (DN)。

**扩展超级帧 (ESF)** 一种现代 T1 信令方法，一次发送 24 个 T1 帧。

**可扩展消息和存在协议 (XMPP)** 用于与 CUPS 进行即时消息通信。

**功能许可 (feature license)** 规定 Cisco Unified CME 路由器能够支持的 IP 电话数量的许可。

**功能铃 (feature ring)** 导致 IP 电话连续三次脉冲响铃；通过使用 f 按钮分隔符配置。

**外线局 (FXO)** 连接到电话局 ( (CO) 或 PBX 系统的模拟接口类型：FXO 端口从接入设备接收拨号音。

**外线局 (FXO) 端口** 将 VoIP 网络连接到传统电话网络（如 PSTN 或 PBX 系统）的模拟接口。

**分机 (FXS)** 连接到模拟设备的模拟接口类型；为接入设备提供拨号音。

**分机 (FXS) 端口** 将传统模拟设备连接到 VoIP 网络的模拟接口。

**G.711** 占用 64 kbps 带宽的未压缩音频编码。

**G.726** 占用 32 kbps 带宽的压缩音频编码。

**G.728** 占用 16 kbps 带宽的压缩音频编码。

**G.729** 占用 8 kbps 带宽的压缩音频编码。

**通用邮箱 (GDM)** 一组订阅者共享的邮箱。

**冲突 (glare)** 用户拿起电话并意外连接到入入呼叫的实例。

**接地信令 (ground start signaling)** 一种依赖于连接到设备的接地线建立新呼叫的信令方法；通常用于 PBX 系统以避免冲突。

**H.323** 由 ITU-T 创建的协议族，用于在基于网络的环境中进行媒体通信。

**H.450.2** 不产生回路的呼叫转移行业标准方法。

**H.450.3** 不产生回路的呼叫转发行业标准方法。

**回路现象 (hairpinning)** 当呼叫从一个 IP 电话转移或转发到另一个 IP 电话时出现的问题，该过程保持了音频路径的建立（established）。

**交互式语音响应 (IVR)** 一种通过语音用户界面促进人类交互的自动化系统。

**消息等待指示 (MWI)** 提供一种机制，提醒订阅者其邮箱中有了新消息。这通常通过开启订阅者 IP 电话上的灯来实现。

**网络时间协议 (NTP)** 将网络设备的时钟与更准确的 NTP 服务器同步。

**奈奎斯特定理 (Nyquist theorem)** 描述了通过以最高频率的两倍进行采样，将模拟音频信号转换为数字格式的方法。
