+   4. Navigate to System > Service Parameters. Select the user you want to configure, and the Cisco CallManager Service. Scroll down to Clusterwide Parameters (System-Presence).

+   5. Set the default Inter-Presence Group Subscription policy to either Allow or Disallow, as desired (The Use Default setting referenced mentions this parameter).

+   6. Assign Presence Groups to DNs and Phones. Remember that Phones watch DNs. The Presence Groups assigned to the phone and the DN, the Inter-Presence Group Subscription Setting, the Subscribe CSS of the watcher, and the Partition of the DN all determine whether Presence information is available to the watcher.

Note: Phones are watchers that monitor the status of Presence entities (such as DNs and SIP trunks). A SIP trunk, is both a watcher and a Presence entity, but only one Presence Group can be assigned to a SIP trunk.
