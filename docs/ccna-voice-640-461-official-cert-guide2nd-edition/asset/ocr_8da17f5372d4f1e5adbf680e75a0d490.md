CUC can import users from a number of different vendors' implementations of LDAP. These user accounts are held and maintained in the LDAP system, with certain fields (attributes) copied as read-only entries to the CUC database. User authentication can be oppositionally redirected from the local CUC database to the LDAP system as well.

To enable LDAP synchronization, follow these steps:

+   1. In the C Cisco Unified Serviceability interface, navigate to Tools > Services.
2. Select the DirSync service and click Save.
3. In the CUC Administration interface, navigate to System Settings > LDAP > LDAP Setup.
4. Check the Enable Synchronizing From LDAP Server checkbox.
5. Choose the LDAP Server Type from the drop-down.
6. In the LDAP Attribute for User ID drop-down, select the LDAP attribute that will be mapped to the CUC Alias attribute. The selected attribute must contain data, and the data must be unique. User accounts without data in the selected attribute will not be imported.
7. Navigate to LDAP > Directory Configuration.
8. Enter the LDAP Configuration Name. It is recommended to use a name that identifies the users being imported, especially if multiple Search Bases are configured.
9. Enter the LDAP Manager Distinguished Name and LDAP Password: This is the LDAP account and password that CUC uses to read and import the LDAP database.
10. Enter the LDAP User Search Base: This entry defines the point where CUC will begin reading the LDAP database. Most LDAP designs are hierarchical tree structures; CUC starts the LDAP search at the point specified by the User Search Base and can read all branches of the tree. It cannot move up the tree from that point, nor can it cross to other branches. CUC can only integrate with a single LDAP database. If the administrator does not know the LDAP design or the correct syntax for the Search Base, he should contact the LDAP administrator to confirm what should be entered. An example search base may be cn=users, dc=isco, dc=com.

+   11. In the LDAP Directory Synchronization schedule, choose to Perform Once if you do not want to have CUC perform a regular sync. Refresh update current user information; it will not import any new users created since the agreement was synchronized. A new User Import must be performed to create these users in CUC.
12. To have CUC synchronize on a regular scheduled basis, set the Perform a Re-sync Every as desired.
13. To configure the mappings between LDAP attributes and CUC user database attributes, set the desired values in the User Fields to Be Synchronized section. Different fields will be changeable, with different field names listed depending on the LDAP type/vendor selected.
