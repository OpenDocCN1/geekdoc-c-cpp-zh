# Configuring After-Hours Call Blocking

In the traditional telephony realm, there have been many recorded incidents of unauthorized calls being placed after-hours, when most, if not all, staff has left for the evening. To prevent this, you can implement after-hours call blocking on CME.

After-hours call blocking allows you to define ranges of times specified as after-hours intervals. You can then list number patterns that are disallowed during those intervals. If a user places a call during the after-hours time range that matches one of the defined patterns, CME will play a reorder tone and disconnect the call.

Of course, there are exceptions to every rule. You may want to have some phones completely exempt from the policy, or give users a "back door" around the restrictions if they are working late and need to make business-related calls that CME would typically restrict. After-hours call blocking configuration on CME provides for both of these scenarios. You have the option to completely exempt certain IP phones from the after-hours restrictions or provide users with a PIN they can enter into the IP phone. If they enter the PIN correctly, CME exempt the IP phone from the after-hours policy for a configurable amount of time.
