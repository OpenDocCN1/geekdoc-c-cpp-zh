This chapter discusses the methods of CME configuration: command line and GUI.

## Managing CME Using the Command Line

As you read this paragraph, you identify yourself as one of two types of people. The first type of person sees the “Managing CME Using the Command Line” title and thinks, "Fantastic! I love working in the command line—it’s so flexible and customizable. Let’s get started! The second type of person sees the same title and thinks, "I thought we moved away Microsoft DOS years ago. If you want to edit an autoexec.bat file, be my guest. I’ll opt for the point-and-click GUI." If these types of people meet, they would probably not enjoy each other's company and would most likely end up throwing computer at each other.

> Note: In most cases, the GUI-based administrator would win the initial confrontation; however, the command-line administrator would later unleash a Denial of Service (DoS) attack on the GUI administrator that would make up for any initial loss.

Thankfully, with the modern configuration tools supported by CME, both administrators can peacefully coexist. Command-line administration still remains the most flexible and supports all CME features. The GUI-based utilities, specifically the Cisco Configuration Protocol (CCP), have evolved to support simple configuration and troubleshooting for the vast majority of CME features. In some cases, the configuration performed using CCP is much more efficient than using the command-line administration. With that said, troubleshooting typically lives in the command-line domain and each section presents a variety of show or debug commands that you can use to verify or troubleshoot the operation of your CME router. To access the command-line interface (CLI) of the CME router, use one of three methods:

- **Console port:** How you initially configure the Cisco router before anyone has assigned a management IP address to the device. You can access the console port using a serial interface on a desktop or laptop PC and a Cisco rollover cable with the appropriate adapters.
- **Telnet access:** Since the 1970s, people have used Telnet to manage a variety of command-line systems. The industry now considers Telnet to be an insecure protocol because it transmits data in clear text.
- **SSH access:** Secure Shell (SSH) performs the same function as Telnet but secures communication with every heavy dose of encryption. All modern Cisco equipment supports SSH out of the box, whereas older Cisco equipment might need an IOS upgrade to a security feature set.

> Note: The foundation IOS commands, such as enable, configure terminal, and show, are covered in the CCENT and CCNA certification guides, which are a prerequisite for the CCNA Voice certification. They are not covered here.

## Managing CME Using the Graphic User Interface

Managing CME using a Graphic Interface (GUI) offers a number of advantages, some of which can be seen on the surface, others may not be. First, many small offices use- or contract network administrators. Providing an easy-to-use GUI allows the more technically inclined users at the office to take care of day without the involvement of IT staff. Finally, the point-and-click of interface can be more efficient than times typing commands.

Cisco has released multiple GUI tools to configure CME over the years, two primary are used today: the integrated CME GUI and CCP. The integrated CME GUI is powered by HTML and JAR (Java) files loaded into the router. Typically, the CME router ships with these files preloaded; however, you can also download a TAR package from the Cisco website (assuming you have a valid support contract) and extract the files into the router. With minimal CLI configuration

Cisco focused the integrated CME GUI on configuring only the telephony aspects of the CME router. It created the CCP to configure all aspects of the CME router. It enables simple (often with wizard-based) configuration of the router, firewall, Intrusion Prevention System (IPS), Virtual Private Network (VPN), Unified Communications, and common WAN LAN features and configurations. You can download the latest version of the CCP software from the Cisco website free of charge. CCP is roughly a 200 MB installation on a local PC. After you install it on your local PC, you can manage any supported Cisco platform. (You do not need to install anything on the managed devices).
