# 理解思科统一通信的组成部分

你是否听过这样一句话：“你不知道你所不知道的？”随着技术发展速度不断加快，这种情况对你来说发生的概率也随之增加。遗憾的是，这可能会导致错过实施某些非常棒的功能（最乐观的情况下），或者无法增加贵公司的生产力和效率（最坏的情况下）。本章解决了这个问题（至少在涉及核心思科统一产品方面）。所有这些服务器和软件是什么？它们是做什么的？它们如何为我的公司带来收益？在阅读本章时，我们将逐一解答这些问题。
