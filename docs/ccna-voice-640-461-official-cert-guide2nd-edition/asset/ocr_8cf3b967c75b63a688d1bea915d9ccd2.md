Configuring Directed Call Park is similar. Follow these steps:

+   1. In CM Administration, navigate to Call Routing > Directed Call Park.
2. Click Add New.
3. Enter a unique number or range and specify a Partition if desired.
4. Specify the Reversion Number (the DN to which a call will be forwarded if not picked up from the park slot before the Call Park Reversion timer [60 seconds by de-fault] expires).
5. Specify the Reversion Calling Search Space to allow the phone to find the reversion number specified above, if it is not in the normal CSS of the phone or line.
6. Specify the Retrieval Prefix, which is the code the person picking up the parked call must dial in order to retrieve it.
7. Click Save.
