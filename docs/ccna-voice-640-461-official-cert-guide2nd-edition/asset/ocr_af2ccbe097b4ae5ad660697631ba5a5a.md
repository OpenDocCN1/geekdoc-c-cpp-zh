# Understanding the CME Dial-Plan

Connecting a voice gateway to another voice network is similar to connecting a router to a data network: Plugging in the cable is the smallest part of the configuration! After the physical connections are in place, the configuration begins. Instead of routing tables, voice gateways build the logical dial-plan through a system of dial peers. This chapter explores the configuration and testing of dial peers in a voice environment.
