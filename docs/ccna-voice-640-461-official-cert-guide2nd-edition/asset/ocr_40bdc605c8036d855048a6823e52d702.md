Figure-21 CDR Records Logging to a Cisco Syslog Server

The output on the syslog server is the message received in the buffer at bottom of the phone. Although it is easy to read when scrolling through wrapped terminal output, for this reason, many third-party vendors create CDR interpreters that format the syslog data into easy-to-understand spreadsheets and HTML pages.

Tip: Cisco offers a web-based utility that can help many third-party software applications around CDR interpretation. You can find it at https://tinyurl.com/5ocklk.

It is common for an organization to use these CDR for billing purposes. Businesses track the long-distance and international calls to the department level to help in budget accounting. Although it is easy to keep track of the extension numbers that are in each department and the calls they make, call data is easier to manage if CME can flag the CDR with an account code.

Businesses can distribute account codes to each department in the organization. For example, the East Coast sales group get account code 1850, the West Coast sales group 1851, management 1852, and so on. You can then train the users in each department to enter this account code when they make a long distance or international call by pressing the Acctsoft key on the phone. This soft appears in the ring out or connected state, as shown in Figure 7-22.
