**Key Point:** CUC Calling Rules only apply if the call has been answered by CUC; for example, a PSTN call to a user's phone DID did not be answered by CUC unless the IP phone forwards it because of a Busy or No Answer condition.



Distribution Lists (DL) provide a simple way to send a voice message to a group of users. Two types of DL can be configured: System DIs are managed by the administrator and be made available to all users or a subset of users as required. Private DLs are managed and maintained by an individual user and usable only by the user who made them. The administrator can limit how many private lists a user can create and how many members can be in each.



To set the security level for access to the CUC system, authentication rules for Voicemail (for TUI access via PIN) and Web Application (access to the User Web Pages) can be customized. Authentication rules specify how many failed login attempts can occur before the account is locked out, how long the account is locked, the minimum number of characters in a password, how often the password must be changed, and so on. The default Authentication Rules apply to all users. You can create new Authentication Rules with customized settings, and apply them to User Templates or even individual users. CUC incorporates the concepts of Partitions and Search Spaces in a similar way to CUCM. Objects that can receive calls, such as a user mailbox or call handler, are assigned a Partition; objects that can place or transfer calls are assigned a Search Space. The object being called must be one of the Partitions listed in the Search Partition of the object calling. A default Search Space, containing the default Partition, allows all objects to reach all other objects until the administrator customizes the system as needed.
