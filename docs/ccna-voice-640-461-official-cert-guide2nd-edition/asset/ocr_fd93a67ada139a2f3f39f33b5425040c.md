| 7-24 block pattern works for 7 * 24 |
| <cr>
| CME_Voice(config-telephony)# after-hours block pattern 3 91900....... 7-24 |

You might have noticed on the context-sensitive help output in Example 7-12 that the CME router allows you to configure up 32 indexes of block patterns. The initial block pattern 1 matches and blocks long distance numbers; block pattern 2 matches and international numbers; block pattern 3 matches and 1-900 toll calls. Notice that block pattern 3 is followed by the 7-24 keyword. This additional syntax tells the CME router to block calls with this pattern at all times. If you enter block patterns with this keyword, exempted from other after-hours blocked numbers are not exempt these patterns.

**Note:** If you need more flexibility than after-hours blocking, you can also use Class of Restriction (COR) features with CME. Cisco Voice over IP (CVOICE) Authorized Self-Study Guide, Third Edition, (Cisco Press, 2008), has more information on the configuration of COR on Cisco routers. For more information on the web, go to http://tinyurl.com/64256f.

The final step in the configuration of after-hours blocking is to allow any necessary exemptions to the policy, as shown in Example 7-13. You can add exemptions on a per-IP phone basis or by using one or more PIN numbers to allow on-demand access to block patterns (with the exception of patterns defined with the 7-24 keyword) from any IP phone. Example 7-13 configures phone 1 to be exempt from the after-hours blocking policy. Phones 2 and 3 are configured with PIN numbers. In order to become exempt from the after-hours call blocking policy, the user using the phone must enter the necessary PIN number.
