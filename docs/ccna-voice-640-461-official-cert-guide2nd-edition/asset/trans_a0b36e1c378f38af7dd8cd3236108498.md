# 术语表

- **802.1Q**：允许 VLAN 之间流量的链路干协议。
- **802.3af**：以太网供 (PoE)，为设备供电。
- **Administrative**：管理员组的成员。
- **Automatic attendant**：将入入电话接到相应人员的功能。
- **Automatic Number Identification (ANI)**：主叫显示。
- **Call Detail Record (CDR)**：关于通话特定信息的日志。
- **Cisco Unified Communications Manager**：支持 30,000 个用户的多服务器平台。
- **Cisco Unified Communications Manager Business Edition**：支持 500 个用户的单服务器平台。
- **Cisco Unified Communications Manager Express (CME)**：支持 250 个用户的平台。
- **Cisco Unified Contact Center**：支持 300 个座席的呼叫中心应用。
- **Cisco Unified MeetingPlace**：用于语音、视频和数据的会议解决方案。
- **Cisco Unified Mobility**：允许用户拥有连接多个设备的单一联系号码。
- **Cisco Unified Presence**：提供用户的状态和可达性信息。
- **Cisco Unified Serviceability**：报告警报和服务器统计。
- **Cisco Unity**：每台服务器支持最多 7,500 个用户的消息平台。
- **Cisco Unity Connection**：支持最多 7,500 个用户的单服务器平台。
- **Cisco Unity Express**：集成在 CME 路由器中的消息平台，支持 250 个用户。
- **Cisco Unity Express administrator**：管理员组的订阅。
- **Cisco Unity Express Advanced Integration Module (AIM-CUE)**：提供最多 50 个邮箱和 12 个端口的 Cisco Unity Express 硬件平台。
- **Cisco Unity Express automated-attendant (AA) script**：定义接收电话后动作的软件步骤集合。
- **Cisco Unity Express CLI**：用于配置和管理 Cisco Unity Express 的命令行界面。
- **Cisco Unity Express custom scripting**：修改默认 Cisco Unity Express AA 脚本的行为。
