

other group pickup 其他组摘听：一种用于通过 pickup 回应来自另一个号码铃声的方法，必须由 GPickUp 软键指定。

overlay line 覆盖线路：通过将多个线路实例分配到 Cisco IP 电话物理线路按钮（覆盖）上，允许的线路配置；通过使用 o、c 或 x 分隔符配置。

packetization interval 分组间隔：放入每个数据包的数据量（通常为音频）。Cisco 默认对所有编码器的分组间隔为 20 ms。

persistent chat 持久聊天：用户离开后重新加入聊天室时保留的群聊。

phone user license 用户许可：每个 Cisco IP 电话拥有的许可，允许其与 Cisco Unified CME 路由器或 Cisco Communications Manager 服务器通信；大多数购买了用户许可的 IP 电话。

power failure (PFO) 停电：允许 UC520 在停电情况下通过指定的模拟电话向 PSTN 完成外呼的特性功能。

private branch exchange (PBX) 程部交换：允许公司运行内部私有语音网络的系统；PBX 系统用于较大的公司，并为所有设备提供唯一的分机号。

private distribution lists 私有发布列表：由单个订阅者创建并供该订阅者专门使用的订阅者集合。Private Line Automatic Ringdown (PLAR) 线路自动接入：用于启用“立即拨号”应用的配置，例如当用户拿起听筒时立即拨打紧急号码的电话。

public distribution list 公共发布列表：所有 Cisco Unity Express 订阅者可作为发布列表使用的订阅者集合。

pulse-amplitude modulation (PAM) 脉冲幅度调制：对模拟波形多次采样以确定用于数字转换的数值幅度的过程；PAM 与脉冲编码 (PCM) 结合。

pulse-code modulation (PCM) 脉冲编码：将脉冲幅度调制 (PAM) 值转换为语音设备可通过数字电路传输的二进制等效值的过程。

pulse dialing 脉冲拨号：一种地址信号类型，旋转拨号在围绕特定数字旋转时连接和断开本地环路电路。

Q.931 用于 ISDN CCS 实现的信号协议。

quantization 量化：将模拟信号分配为可以在数字网络上传输的数值的过程。

Real-Time Transport Control Protocol (RTCP) 实时传输控制协议：基于 UDP 的协议，负责传输音频统计数据；使用 16,384 到 32,767 随机奇数 UDP 端口通信。

Real-Time Transport Protocol (RTP) 实时传输协议：基于 UDP 的协议，负责传输音频数据包；使用 16,384 到 32,767 随机偶数 UDP 端口通信。

resource 资源：可以是管理网页、网页的一部分，或应用程序内的工具或接口。

robbed bit signaling (RBS) 窃位阻塞：一种通道关联业务 (CAS) 的实现，通过提取数字 T1 电路每六帧中的一个位作为信号信息。

role (CUCM) 角色：定义应用程序资源的一组权限。权限可以定义为无访问、读取或更新。

router-on-a-stick 单路单路路由器：一种跨 VLAN 路由配置，允许单个路由器通过划分为连接到交换机中干端口子接口的 FastEthernet 或更高级接口在 VLAN 之间路由数据。

service engine 服务引擎：在安装了 Cisco Unity Express 硬件并被路由器识别的 Cisco CME 上创建的接口。CME 通过此接口将通话路由到服务模块供 Cisco Unity Express 处理。

service module 服务模块：Cisco Unity Express 的内部接口。Cisco Unity Express 通过此接口将通话路由到服务引擎供 Cisco CME 处理。

Session Initiation Protocol (SIP) 会话发起协议：IETF 创建的语音协议，作为 H.323 的轻量级替代方案。

Signaling System 7 (SS7) 七号信令：用于电信提供商网络内部提供局间通信和通话路由的协议。

Single Number Reach 单号可接：允许用户在定义的时间限制后让入电在另一个预配置号码上响的特性。单号可接还允许移动性，允许将活动通话传输至或来自同一预配置号码。

SIP for Instant Messaging and Presence Leveraging (SIMPLE) 用于与第三方系统进行即时消息 (IM)。

Skinny Client Control Protocol (SCCP) Skinny 客户端控制协议：Cisco 专用语音协议，用于控制 Cisco IP 电话。

smartports 智能端口：一种辅助配置单个端口路由的 CCA 方法。

Spanning Tree Protocol (STP) 生成树协议：旨在防止由于冗余交换机间连接导致交换网络环路的方法。

super frame (SF) 超帧：一种早期的 T1 信令方法，一次发送 12 个 T1 帧。

Survivable Remote Site Telephony (SRST) 远程站点生存性电话：允许路由器在 IP 电话无法到达 Cisco Unified Communications Manager 时作为备份设备的配置。

switched virtual interface (SVI) 交换虚拟接口：交换机上的路由接口。

time-division multiplexing (TDM) 时分复用：一种通过在特定时隙中发送数据，在单个数字连接上传输多个语音或数据通道的方法。

troubleshooting 故障排除：确定并执行问题可能原因及可能修正步骤的序列。

trunk port 干道端口：Cisco 交换机上专门配置用于传输多个 VLAN 的端口。干道通常用于交换机设备之间以及单路路由器配置中。

user group (CUCM) 用户组：与一个或多个角色关联。组的成员继承与组相关的角色的权限。属于多个组的成员可能会创建冲突的权限分配；企业参数“重叠用户组和角色的有效权限”定义了有效权限是最大还是最小。

virtual LAN (VLAN) 虚拟局域网：用于将交换机划分为多个广播域和 IP 子网的配置。

VLAN Trunking Protocol (VTP) VLAN 隧道协议：一种 Cisco 专用协议，将 VLANset信息复制到所有参与同一 VTP 域的交换机。voice expansion port 语音扩展端口：UC520 所有型号中的集成语音/WAN 接口 (VWIC) 端口，允许 PSTN 语音扩展。此端口不支持 WAN 连接。Voice Profile for Internet Mail (VPIM) 互联网邮件语音配置：允许一个语音箱系统与其他语音箱系统交换消息的特性。VoiceView Express 一种 XML 应用，通过 IP 电话上的 Services 按钮为订阅者提供其消息的 GUI 访问。
