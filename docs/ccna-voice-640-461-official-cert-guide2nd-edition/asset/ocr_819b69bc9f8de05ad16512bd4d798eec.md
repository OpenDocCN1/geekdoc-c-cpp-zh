# Step 6: Associate Users with Device Profiles

6.1 Navigate to User Management > End User.

6.2 Select the user for whom you want to create a profile association, or, if necessary, create a new user (see Chapter 9, “Managing Endpoints and End Users in CUCM”).

6.3 In the user configuration, choose the Device Profile(s) that should be associated with the user. If more than one is assigned, the user must select the one she wants to use after she logs into EM. The Default Profile option puts the selected profile at the top of the list of choices.
