# Describe Telephony Features in CUCM

CUCM supports a wide range of telephony features. This section reviews some of the widely used features, including several Call Coverage Options, Intercom, and Presence.

# Call Coverage

Call Coverage is a general term that references several features and mechanisms used to ensure calls are answered under almost any unforeseen circumstances. CUCM supports the following Call Coverage features:

+   - Call Forward
- Shared Lines
- Call Pickup
- Call Hunting
