# Voice Messaging with SRST and AAR

In the event the IP WAN fails, calls can be rerouted over the PSTN using Automated Routing (AAR) or Survivable Remote Site Telephony (SRST). If the CUC server is reached over the WAN from branch user, in the event of an outage, these systems reroute the call to CUC over the PSTN, too. When the call arrives at CUC, the ten-digit PSTN caller ID will not be recognized as a mailbox owner unless it is added as an alternate extension for the user (the same goes for each other user over the system as well).

# Voicemail Box

When creating the user mailbox, the administrator can choose whether to list the user in the directory or not, record the voice name (the spoken version of the username); CUC speaks the name in the configuration page if the name is not recorded), and record a greeting. The administrator can also require the user to go through these steps at his next login.

# Private Distribution Lists

Each user is permitted to create up to 99 DLs, each with a maximum of 999 members. Lower limits can be set in the COS or individually per user. Private DLs are visible only to the user who created them (and administrators).

# Notification Devices

In addition to the MWI lamp on the IP phone, users can be notified of new messages by way of up to three PSTN numbers (mobile phone, home phone, and pager) and e-mail. Toll control is handled by restriction tables that define what numbers CUC can call for message notification. When CUC calls the configured number, it informs the user that there is a new voice message and prompts the user to authenticate before playing the message.

# User Creation Options

There are several ways to create or import user accounts into CUC:

+   - **Manual creation:** Creates users one at a time. All data is maintained locally in the CUC database.

+   - **Bulk administration:** Creates many users at once from data in a .csv file. All user data is maintained locally in the CUC database.

+   - **Migration from Cisco Unity:** Users can be migrated and imported using the Consolidated Object Backup and Restore Application Suite (COBRAS) tool, helps administrators migrate users from a Cisco Unity system to a Cisco Unity Connection system. The users can be imported with or without their mailboxes.

+   - **Import from CUCM:** Synchronizes the CUC user database with an existing CUCM database. Some user data is maintained in CUC and copied to CUC, but CUC-specific data is locally maintained in the CUC database.
