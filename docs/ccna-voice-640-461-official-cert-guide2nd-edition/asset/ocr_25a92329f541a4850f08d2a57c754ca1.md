# Configuring a Voice Network Directory

When most people think of a corporate phone directory, visions of Microsoft Excel spreadsheets e-mailed monthly come to mind. Isn't there a better way? Sure there is! Cisco IP Phones support a local directory that you can update from the Cisco Unified Communication Manager Express (CME) router as you are configuring devices.

You can enter names under ephone-dn configuration mode either as you are configuring new lines for the organization or separately, after you configure the lines. These names are used for building the internal corporate phone directory (often called the local directory) and for caller ID information. Example 7-1 shows names being added to individual ephone-dn currently use in the organization.

# Example 7-1 Configuring Local Directory and Internal Caller ID Information

```
CME_Voice(config)# ephone-dn 20
ME_Voice(config-ephone-dn)# name Joshua Bellman
ME_Voice(config-ephone-dn)# exit
ME_Voice(config)# ephone-dn 21
ME_Voice(config-ephone-dn)# name Ruth Hopper
ME_Voice(config-ephone-dn)# exit
ME_Voice(config)# ephone-dn 22
ME_Voice(config-ephone-dn)# name Esther Billford
ME_Voice(config-ephone-dn)# exit
ME_Voice(config)# ephone-dn 23
ME_Voice(config-ephone-dn)# name Job Smith
ME_Voice(config-ephone-dn)# exit
ME_Voice(config)# ephone-dn 24
ME_Voice(config-ephone-dn)# name Samuel Oldham
ME_Voice(config-ephone-dn)# exit
```

When you enter these names in ephone-dn configuration mode, they immediately take effect. If ephone-dn 24 to call ephone-dn 21, Ruth would see “Samuel Oldham” appear on her caller ID information, as shown in Figure 7-1.

In addition, all Cisco IP Phone models allow you to browse the corporate directory by pressing the Directory button on the phone itself. Some low-end IP phones may not have a dedicated Directory button, but instead have a menu-driven process to get there. After you press the Directory button, you are able to browse categories including Missed Calls, Received Calls, and so on. Move down to the option showing the Local Directory, as shown in Figure 7-2.
