# Configuring Cisco Unified CME Voice Productivity Features

After implementing the ephone, ephone-dn, and dial-peer concepts, you now have an IP Telephony network that is able to make and place internal and external calls. If only voice networks stayed this simple! Organizations expect modern telephony systems to support a whole host of features, such as call transfer, Music on Hold, conference calling, and so on. This chapter is dedicated to adding these features to the voice network.
