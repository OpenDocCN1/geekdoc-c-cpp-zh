# Enabling Telephony Features with CUCM

Getting Cisco Unified Communications Manager (CUCM) to the point where it will ring phones is only part of the fun. Users of a contemporary business phone system expect it to have a comprehensive feature set. This chapter explores just a few of the features available in CUCM 8.x and the basics of implementing them.
