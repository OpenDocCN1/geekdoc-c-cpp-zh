# Understanding and Configuring Dial Peers

When you initially entered the Cisco world, you probably learned about the concept of static routing. This method of routing allows you to manually enter destinations the router is able to reach on the data network. Dial peers use a similar concept to this; think of dial peers as static routes for your voice network. By default, the CME router only knows how to reach the iphone-dns you configure for the Cisco IP phones. You can connect the CME router to any number of FXS, FXO, or digital T1/E1 connections, but until you create dial peers for these connections, the router will not use them.
