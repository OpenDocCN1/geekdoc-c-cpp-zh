# Cisco Unified Personal Communicator

You'll hardly find any documentation about Cisco Unified Presence without mentioning Cisco Unified Personal Communicator. Once you understand the purpose of Cisco Personal Communicator, you'll understand why. This single-software application brings together used services in a single location: soft phone, presence, instant messaging, visual voicemail, employee directory, communication history, video, and web conferencing. When you initially see Cisco Unified Personal Communicator, it looks like another IM client (shown in Figure 2-8); under the hood, it's so much more.

At its core, Personal Communicator serves as an IM client, supporting peer-to-peer chat, multi-user chat, and persistent chat. Persistent chats use the idea of "rooms," which allow users to join chat sessions and see the conversation history (rather than simply the new messages appearing after they have joined). Personal Communicator uses LDAP authentication to log into the IM client, for user searches, and to add contacts. Because Personal Computer uses the Cisco Unified Presence server, you are able to see not only the status of the user as it relates to IM conversations, but you can also see the status of their phone (off hook, on hook, and so on).

From Personal Communicator, you can start both voice and video calls to reach High Definition (HD) quality. Personal Communicator also acts as a full software, allowing audio calls from other audio devices (IP phones, smartphones, and so on) in the network. If you combine Personal Computer with the multipoint video conference solutions offered by Cisco (such as Cisco Unified MeetingPlace or Cisco Unified Video Conferencing), you are even able to run video-based conference calls with multiple video sources!
