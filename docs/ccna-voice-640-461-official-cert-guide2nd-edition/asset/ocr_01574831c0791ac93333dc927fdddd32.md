# Managing Endpoints and End Users with CME

Up to this point, you have seen the key concepts of traditional voice and VoIP, understood the core pieces that make up the Cisco Unified Communications suite of products, and correctly implemented the underlying network foundation for VoIP. Now, we've reached our moment of glory: It's time to make some phones ring! This chapter focuses on the most common tasks performed by a Cisco Unified Communication Manager Express (CME) administrator: IP phone provisioning and maintenance. The topics covered will take you all the way from the initial installation of a new IP phone to the day-to-day maintenance of IP phones and end users on the VoIP network.
