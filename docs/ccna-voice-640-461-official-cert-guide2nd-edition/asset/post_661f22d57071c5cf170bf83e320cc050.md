CME_Voice# dir flash:/phone/7940-7960

CME_Voice# configure terminal
Enter configuration commands, one per line. With CNTL/

```
CME_Voice()# tftp-server flash:/phone/7940-7960/P0308000500.bin alias
P0308000500.bin
CME_Voice()# tftp-server flash:/phone/7940-7960/P0308000500.loads alias
P0308000500.loads
CME_Voice()# tftp-server flash:/phone/7940-7960/P0308000500.sb2 alias
P0308000500.sb2
CME_Voice()# tftp-server flash:/phone/7940-7960/P0308000500.sbn alias
P0308000500.sbn
```

The alias syntax that follows the tftp-server command enables the firmware file to be requested by aliased filename. This is necessary in newer CME versions, which organize firmware files into subdirectories.

**Note:** Be sure to make all firmware files in each subdirectory available via TFTP. The firmware files for 7940 and 7960 IP Phones are now available through TFTP from the CME router. You can repeat this process as many times as necessary to make firmware files available for models you have on your network.

**Note:** You can download the latest firmware files from Cisco website assuming you have a valid contract. These files come in TAR archive, which you can extract to flash with a single command.

## Base CME Configuration

For CME router to support IP Phones, you must configure some telephony service information. The key items you must configure include:

- IP Source Address
- Max-DN
- Ephones

![](img/e47862dc47e5de0c3b45500)

Although you can configure many features, these three are necessary to get the phone system up. Example 5-4 illustrates this configuration.

## Example 5-4 Provisioning CME Phone and Directory Support

```
CME_Voice(config)# telephony-service
CME_Voice(config-telephony)# ip source-address 172.168.1.1
CME_Voice(config-telephony)# max-phones ?
<1-30> Maximum phones to support
CME_Voice(config-telephony)# max-phones 24
CME_Voice(config-telephony)# max-dn ?
<1-150> Maximum directory numbers
CME_Voice(config-telephony)# max-dn 48
```

The max-phones parameter configures the maximum number of IP phones the router will support, whereas the max-dn parameter specifies the maximum number of directory numbers. The ip source-address command enables the router to know which IP address will receive registration requests from IP phones.

Note: The max-phones and max-dn parameters directly affect how much memory the router reserves to support CME. Setting the value much higher than you actually need requires excessive resources on your router and impacts other services. In addition, the max-phones parameter should not be any higher than the number of ephones you have purchased for your CME system.

## Understanding and Configuring Ephone-DNs

An ephone-dn in its simplest form is a directory number that can be assigned to one or more buttons on one or more Cisco IP Phones. You can configure each ephone-dn you create as a single- or dual-line mode ephone-dn. Here's the difference:

- **Single-line ephone-dn:** In single-line mode, the ephone is able to make or receive one call at a time. If a call arrives on an ephone-dn where there is already an active call, the caller receives a busy signal.
- **Dual-line ephone-dn:** In dual-line mode, the ephone is able to handle two simultaneous calls.

## Example 5-5 Configuring ephone-dn

```
CME_Voice# configure terminal
Enter configuration commands, one per line. With CNTL/
CME_Voice())# telephony-service
CME_Voice(config-telephony)# ephone-dn ?
<1-150> ephone-dn
CME_Voice(config-telephony)# ephone-dn 1
CME_Voice(config-ephone-dn)# number ?
  A sequence of digits
CME_Voice(config-ephone-dn)# number 1000
CME_Voice(config-ephone-dn)# exit
CME_Voice(config-telephony)# ephone-dn 2 ?
```

```
dual-line (2 calls per line)
<cr>
CME_Voice(config-telephony)# ephone-dn 2 dual-line
CME_Voice(config-ephone-dn)# number 1001 secondary 4805551001
```

The ephone-dn tag is a logical number, which is used when assigning the ephone-dn to an ephone. You can choose any ephone-dn tag from the range as long as the total number of ephone-dns does not exceed the max-dn command.

**Note:** Creating more ephone-dns than you have specified using the max-dn command results in the following error:

```
CME_Voice(config)# ephone-dn 49
dn 49 exceeds legal range 1 to max-dn 48
```

To correct this error, increase the max-dn value from telephony service mode.

The number syntax (which is used to assign a directory number to an ephone-dn) also supports a secondary number value. For example, you can enter the following:

```
CME_Voice(config-telephony)# ephone-dn 2 dual-line
CME_Voice(config-ephone-dn)# number 1001 secondary 4805551001
```

This enables the ephone-dn to answer for multiple numbers. This can be used if you want an internal extension to be reachable by someone on the internal network dialed a four-digit extension or the full Publicitched Telephone Network (PSTN) Direct Inward Dial (DID) number.

**DID:** A feature is supported by PSTN carriers that enable internal extensions to be reached by PSTN callers directly without the need to route calls through a receptionist.

## Example 5-6 Creating an Ephone

When you configure an ephone in CME, it represents the configuration applied directly to a single Cisco IP Phone or SoftPhone managed by the CME router. Just as with the ephones, the max-ephone parameter directly impacts the number of ephones you are able to create and manage on a CME router. Example 5-6 adds an ephone to the CME router.

```
CME_Voice(config)# ephone ?
<1-24> Ethernet phone tag
CME_Voice(config)# ephone 1
CME_Voice(config-ephone)#
```
