A number of Properties were set. The Text property for the TextBlock labels were set. Button and RadioButton objects did not have a Text property, instead the Control property was used to provide identifying information on the form. For the TextBox objects, Text was set to " ". The controls that are used in the program statements were named in the Properties Window. The size and color of several controls were set. An Image control was placed on the grid on the phone. The Source property was used to identify a .jpg image. The image was resized and moved.

The final design is shown in Figure 15-37. As illustrated in that figure, you have great control over the canvas. You can zoom in/out as you work with controls placed on the form.
