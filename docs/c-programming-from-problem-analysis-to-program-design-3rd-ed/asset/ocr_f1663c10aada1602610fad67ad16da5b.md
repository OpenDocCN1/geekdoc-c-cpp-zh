The WebControls application that is being developed in this chapter includes a DataGrid or GridView control, which displays data from an Access database. **OleDB Data Provider** You learned in Chapter 14 that .NET organizes ADO.NET classes into different provider namespaces. This enables you to work with data from different databases such as Oracle and Access using a consistent object-oriented approach. Each of these namespaces has its own classes prefixed with the provider type, one of which is OleDB for working with Access databases.
