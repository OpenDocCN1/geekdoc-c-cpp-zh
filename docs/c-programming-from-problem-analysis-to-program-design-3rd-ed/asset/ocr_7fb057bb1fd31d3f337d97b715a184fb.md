The Program.cs file contains the Main( ) method, where execution always begins. One of the three lines of code found in the Main( ) method is a call to Application.Run( ), which makes the form visible and ready to receive input from the user. The code shown in Example 9-2 is completely generated by Visual Studio. The only changes made to Example 9-2 were made to the comments. The XML comments inserted by Visual Studio were deleted and new inline comments added.
