# ## Handling ComboBox Events

Another difference between the `ComboBox` and `ListBox` is that the `ComboBox` allows only a single selection to be made. Unlike the `ListBox` , the `ComboBox` object does not have a `SelectionMode` property. Selections from `ComboBox` objects can be either a new typed value or one of the choices displayed from the drop-down selection. As with the `ListBox` control object, `SelectedIndexChanged( )` is the default event-handler method. When a value such as "Sunflower" is typed into the `ComboBox`, the `SelectedIndexChanged( )` event-handler method is not triggered or raised. A new event must be registered to respond to values being typed into the text portion. One way to deal with this is to have a `KeyPress( )` event-handler method executed when new values are entered.
