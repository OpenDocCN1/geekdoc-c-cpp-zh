Figure 10–5 shows the form allowing the user to enter another activity to the list of events. A new Button and TextBox object is added to the form. The text from the TextBox object is added as a selection to the ListBox. Two events were fired before the output being displayed in Figure 10–5 was produced. The first event that was fired was the button click. This event-handler method added the user-entered string to the ListBox. The second event was fired when the user clicked a selection from the list box. The selections are displayed in the Result text box. Notice the new selection that was typed, Picnic now appears as an option. It was also selected from the list box.
