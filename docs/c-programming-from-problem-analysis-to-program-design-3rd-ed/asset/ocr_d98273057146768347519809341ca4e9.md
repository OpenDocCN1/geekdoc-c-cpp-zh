The DataGrid is a less sophisticated control. The DataGridView has added functionality. You can specify how data is formatted and displayed using the DataGridView. It provides a customizable table that allows you to modify columns, rows, and borders. You can freeze rows and columns to prevent them from scrolling with a DataGridView. You can hide rows or columns and provide ToolTips and shortcut menus for individual cells, rows, and columns in the grid.

# Placing a DataGridView Control on the Form

The easiest way to add a DataGridView control to your application is to drag a table from the Data Sources window onto your form. When you do this, an object of the DataGridView class is instantiated. You get the added benefit of another control, BindingNavigator object, being automatically instantiated. In Figure 14–15, notice the strip of buttons below the title bar. These were all placed when the table from the Data Sources window was dragged onto your form; no additional coding was needed. No other objects (other than the DataGridView) were dragged onto the form.
