# Example 5-17

```
if (average > 89)
    grade = 'A';
else
    if (average > 79)
        grade = 'B';
    else
        if (average > 69)
            grade = 'C';
        else
            if (average > 59)
                grade = 'D';
            else
                grade = 'F';
```

Pay particular attention to the conditional expressions in Example 5-17. It is not necessary for the second expression to be a compound expression using &&. You do not have to write if (average > 79 && average <= 89). Make sure you understand that execution would never have reached the expression of (average > 79) unless the first expression was false. If the average is not greater than 89, it must be either equal to 89 or less than 89.

As you reviewed Example 5-15 and 5-17, you probably wondered what happens when you keep indenting. Your statements soon start to go off to the right, out of sight. A solution to this problem used by many programmers is to write a series of else...if statements when they have a long, nested, multiway statement.

The lines in Example 5-17 could be written with a series of else...if statements, as shown in Example 5-18. This prevents the indentation problem.

# Example 5-18

```
if (average > 89)
    grade = 'A';
else if (average > 79)
    grade = 'B';
else if (average > 69)
    grade = 'C';
else if (average > 59)
    grade = 'D';
else
    grade = 'F';
```

Examples 5-17 and 5-18 are multiway if statements. A single variable is tested using a relational operator.
