One of the special properties in the `Array` class is `Length`. It returns an `int` representing the total number of elements in an array. For *Example 7-5*, `Length` returned 14. The loop control variable, `i`, is evaluated before each iteration through the loop to determine whether it is less than 14 (`score.Length`).

> > Notice that the conditional expression that was used with the `for` statement used less than (`<`) instead of less than or equal to (`<=`). Because `Length` returns a number representing the size of the array, the last valid index should always be one less than `Length`. Therefore, as soon as the index is equal to `Length`, the loop will terminate.
