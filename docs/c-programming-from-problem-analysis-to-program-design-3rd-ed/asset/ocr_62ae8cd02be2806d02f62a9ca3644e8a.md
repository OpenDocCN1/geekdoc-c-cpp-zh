As highlighted in Figure 14-14, the app.config file, which stores the connection string, is now part of the application. A new set of files defining the dataset object is also included with the application when the configuration wizard terminates normally. These files, independent of the data source, are named using the database identifier (e.g., StudentDataBaseDataSet.xxx) with “DataSet” appended onto the end of the name.

# Data Sources Window

Figure 14-14 also shows the new Data Sources window to the left of the form. This window enables you to view the data available to your project. It greatly reduces the complexity of binding data from a database to controls on your forms by allowing you to drag complete tables or selectively drag columns from the tables onto forms to create data-bound controls.

# DataGridView Control

Data was placed in rows and columns in an earlier example using the DataGrid. Another option, the DataGridView, adds enhanced functionality. The DataGrid is still available and can be used, but no longer appears as a control in the Toolbox window. If you want to use the DataGrid, you add it to your Toolbox window by right-clicking anywhere in the Toolbox window and selecting Choose Items.

You use the right-click and Choose Items menu option to customize your Toolbox window. You can deselect any controls you do not want displayed and can also add any of the .NET Framework components or your own .dlls that you create.
