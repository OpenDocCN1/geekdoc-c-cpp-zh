# Master Pages

When you have more than one page associated with a Web site, you may want to consider beginning with a master page. You can lay out the design you want to see and indicate on the page where content will change from one page to the next. For example, on a master page you might place an HTML table for the layout and include an image element for a logo. You might also include special controls for page navigation for your site. The concept of a master page allows you to create and maintain a consistent theme across several pages for a Web site. As you look back at Figures 15-5 and 15-6, notice one of the nodes listed in the **Solution Explorer** window is **Site.master**; this is a master page. It is automatically created when you create a New Web Site in Visual Studio 2010. A master page ends with an extension of .master.

Figure 15-7 shows most of the **Site.master** file. You will notice it contains formatting HTML tags. A master page can include static text, HTML elements, and server controls. If you look at the Site.master file in Figure 15-7, you will find html, head, body, form, and div elements on the page. There are a few subtle differences between a master page and other pages, like the Default.aspx page. First, it has a special **@ Master** directive instead of the **@ Page** directive.
