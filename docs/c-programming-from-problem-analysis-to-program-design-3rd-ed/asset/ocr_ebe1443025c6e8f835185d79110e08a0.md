# Web Page

You will recall that two files are created for each page when you build Web applications. Selecting **File, New, Web Site** with the **File System** option selection enables you to specify where the Web site files should be stored on your local machine. The Source code file for the .aspx markup file is automatically opened when you first create a Web site as illustrated in Figure 15-5.

Figure 15-5  Source code for HTML file

In Figure 15-5, the `Default.aspx` file for the `DynamicPage` site is shown in source code. This file (ending in .aspx) holds the HTML tags. You can view and directly edit the HTML source code here. The tags automatically generated by Visual Studio are actually XHTML tags. They are referred to as HTML tags for the remainder of the chapter. Tags are automatically inserted for head, title, body, form, and div. The first two lines in the .aspx markup file are called page directives. Page directives are delimited with `<%@` and `%>`. They provide information needed by ASP.NET to process the file.

The first attribute, `Page Title="Home Page"`, identifies the text title that will be associated with the page. This name appears in the title bar or tab for the browser.
