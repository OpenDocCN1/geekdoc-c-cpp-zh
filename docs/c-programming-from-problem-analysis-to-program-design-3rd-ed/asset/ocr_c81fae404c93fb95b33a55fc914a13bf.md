During design, it is important to develop an algorithm showing the systematic process to solve the problem. This can be done using any of the design tools presented in previous chapters. Pseudocode for the `SetFine()` method, which contains a nested `if`, is shown in Figure 5–12.

![](bbox=[0.19, 0.197, 0.703, 0.557])

```
SetFine()

speed = ticketedSpeed - speedLimit

fine = (speed / 5 * 87.50) + 75.00
if senior
    if speed > 20
        fine = fine + 200
    else
        fine = fine + 50
else
    if freshmen
        if speed < 21
            fine = fine - 50
        else
            fine = fine + 100
    else
        if speed > 20
            fine = fine + 100
```

Figure 5–12  Pseudocode for the `SetFine()` method

The problem definition indicates that for every 5 miles over the speed limit the additional fine is $87.50. A whole number value representing the overage is needed. For example, if the speedLimit is 42, and the ticketedSpeed is 42, only the additional fee of $87.50 is added to the fine. If the ticketedSpeed is 45, two additional $87.50 fees are added. This value is determined by doing integer division. An assumption for the pseudocode is that all variables, except fine, are of type int. This forces the division to be integer division.

42 − 35 = 7 miles over the limit

7 / 5 = 1

Notice that the result is not 1.40, because integer division produces an integer result.
