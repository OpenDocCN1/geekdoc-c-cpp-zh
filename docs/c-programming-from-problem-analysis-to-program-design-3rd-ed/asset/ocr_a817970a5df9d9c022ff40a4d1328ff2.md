There are a number of ways to document collaboration between objects using an object-oriented approach. They include sequence, collaboration, state transition, and activity diagrams. Systems analysts often use these diagrams to design an application. Development of these types of models is beyond the scope of this book; however, you are encouraged to research and learn about them.
