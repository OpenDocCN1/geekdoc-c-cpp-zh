If you are simply returning values for display, you would select the first option, **SELECT which return rows**, as shown in Figure 14–27. The next window lets you type the SQL statements or click a button that takes you to the **Query Builder**. When you have completed the SQL statement, a dialog box similar to the one shown in Figure 14–28 opens. Notice that two methods are automatically generated.

For the `ConfigToolsExampleWithQuery`, a WHERE clause was typed onto the end of the autogenerated SQL statement. The SQL statement reads:

