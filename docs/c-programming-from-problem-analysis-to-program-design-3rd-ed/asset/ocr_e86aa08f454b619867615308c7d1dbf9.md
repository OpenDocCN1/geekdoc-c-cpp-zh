Now that you know what elements make up a C# program, you are almost ready to begin developing your own programs. Figure 1-17 shows how namespace, class, method, and statements are related. Notice that the Framework class library (FCL) includes a number of different namespaces, such as System. Defined within a namespace are a number of classes, such as Console. Defined within a class are a number of methods, such as WriteLine( ) and Read( ). You did not see the statements that made up the WriteLine( ) method, you saw the WriteLine( ) method being called. A method can have one or more statements. One of those statements can be a call to another method, such as the case of calling on the WriteLine( ) method from within the Main( ) method.
