## 二维数组

一维数组对于存储数据列表非常有用。由于数据存储在连续的内存位置中，元素通过表示相对于数组起始元素位置的索引来引用。二维数组和其他多维数组遵循你在一维数组中学到的相同准则。使用 C# 可以创建两种二维数组。第一种是矩形数组，大多数语言都支持这种类型。第二种称为交错数组或不规则数组。二维数组的引用方式与引用矩阵的方式非常相似。
