# Figure 5-5 Two-way if statement

When the expression evaluates to true, the true statements are executed. As the figure shows, execution continues at the same location for both, whether the true statements are executed or the false statements are executed. Consider Example 5-10.

# Example 5-10

```
if (hoursWorked > 40)
{
    payAmount = (hoursWorked - 40) * payRate * 1.5 + payRate * 40;
    Console.WriteLine("You worked {0} hours overtime.",
        hoursWorked - 40);
}
else
    payAmount = hoursWorked * payRate;
    Console.WriteLine("I am displayed, whether the expression "
        + "evaluates true or false");
```

As shown in Example 5-10, it is permissible to have a block of statements with the true portion and a single statement for the false portion. No curly braces are required for the false statement in this example; however, adding the curly braces can improve readability.
