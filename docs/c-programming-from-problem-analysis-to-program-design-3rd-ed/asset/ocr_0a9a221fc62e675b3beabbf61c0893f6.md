As you saw from the previous example, when you create a **New Web site**, a number of files including a master page, style sheet, and content pages for Default, About, and Login are automatically added to the project. If you do not want these files, you have another option. You can select **ASP.NET Empty Web Site** from the list of templates available for Web sites. Selecting this option does not create any files—not even the **Default.aspx** file. However, it also does not add lots of overhead to the project. This option was used for the remaining examples in the chapter.

# ASP.NET Empty Web Site

When you take the selection **File, New, Web Site, ASP.NET Empty Web Site**, no .aspx files are created. No extra folders are created. A Web site named HtmlExample was created.

A file named **Default.aspx** is added to the project by right-clicking on the project name in the **Solution Explorer** window and selecting **Add New Item, Web Form**. It is this file that is automatically opened in Source view when you first start building a Web site. Clicking on the arrow beside **Default.aspx** expands to reveal the **Default.aspx.cs** file. This code-behind file was automatically created when you added the new **Web Form** item to the project. You will read more about this shortly; however, the xxx.aspx.cs file is where your program logic, including your event handlers, is stored.

As with a Windows application, you can debug and execute a Web application from within the IDE. It is a fully functioning application from the beginning. When you run the application, the default Web browser is launched and the file is opened inside the browser.
