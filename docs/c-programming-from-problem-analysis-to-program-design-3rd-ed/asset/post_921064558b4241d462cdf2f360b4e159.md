## DATA SOURCE CONFIGURATION TOOLS

The **Data Source Configuration Wizard** simplifies connecting your application to a data source by guiding you through the process, automatically generating the connection string, creating dataset and table adapter objects, and bringing the data into your application. Figure 14-5 shows one way to begin this process.

![](img/e33ae760e23d89eac66541252ad65de8_891_0.png)

**Figure 14-6**  Connect to a database

As shown in Figure 14–6, selecting **Database** enables you to create a typed dataset object or an entity data model for the application. The typed dataset object corresponds directly to the underlying database table(s). A typed dataset defines a schema that exposes the tables and their columns as object properties. This makes manipulating the dataset much easier because you can reference the tables and columns directly by name.

When a dataset object is available for the application, the **DataSet Designer** tool is available to you. The **Dataset Designer** provides another visual representation of the objects contained in the dataset object. It enables you to set relationships between the tables and add additional queries to your application. You will explore the **Dataset Designer** later in this chapter.

### SQL Server

If you are connecting to a SQL Server Express database, you would type `(local)\SqlExpress` in the Server name box shown in Figure 14-8. This assumes the default name, SqlExpress, was retained during Visual Studio or SQL Server installation. You might also enter the server name as `(local)\SQLEXPRESS` or `.\SQLEXPRESS`. Selecting the **Refresh** button populates the interface with available connections.

SQL Server Express is a free download and can be used to create and manipulate a SQL Server database. At the time this chapter was written, the download was available at *http://microsoft.com/express*.

If you have Visual Studio 2005 or later, you already have SQL Server. It is installed as part of the Visual Studio install and can be used within the Visual Studio IDE to design and manipulate databases. SQL Server 2008 Edition is bundled with Visual Studio 2010 Professional and Team editions.

### Creating SQL Server Databases

To create a new SQL Server database from within Visual Studio, display the **Server Explorer** window (from the View menu). Right-clicking the **Data Connection** icon displays a shortcut menu option named **Create New SQL Server Database**, as shown in Figure 14-9.

![](img/e33ae760e23d89eac66541252ad65de8_894_0.png)

Figure 14-9  Server Explorer window

After selecting the option shown in Figure 14-9, you are again asked to enter the server name and the name of your new database. After the database is created, you add tables by first clicking the plus sign to the left of the database name. This expands or reveals a number of database features, including **Database Diagrams**, **Tables**, **Views**, and **Stored Procedures**. To create a new table, right-click the **Tables** node in the **Server Explorer** window and select **Add New Table** from the shortcut menu. You enter field names and data types next. For strings, the SQL **varchar(50)** data type works well. The SQL **bit** data type works well for Boolean data types.
