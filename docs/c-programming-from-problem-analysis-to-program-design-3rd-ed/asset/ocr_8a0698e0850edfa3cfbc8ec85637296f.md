# PROGRAMMING EXERCISES

+   1. Write a program that reads data into an array of type `int`. Valid values are from 0 to 10. Your program should determine how many values were inputted. Output a list of distinct entries and a count of how many times that entry occurred.
+   
+      Use the following test data:
+   
+      `1  7  2  4  2  3  8  4  6  4  4  7`
+   
+   2. Write a program that accepts any number of integer input values. Total the values. Display a report showing the original value input and the percentage it contributes to the total. You may prompt the user for the number of values to be inputted.
+   
+   3. Write an array class application that has a one-dimensional array as a data member. The array stores temperatures for any given week. Provide constructors for instantiating the class and methods to return the highest temperature, lowest temperature, average temperature, and the average temperature excluding the lowest temperature. Provide a method that accepts as an argument a temperature and returns the number of days the temperatures were below that value. Override the `ToString()` method to return the temperature range for the given week. Write a second class to test your class.
