# Other Code Editor Tips

**Zoom** is one of the more interesting features added with Visual Studio 2010. You can press the **Ctrl+Mouse** wheel to increase and decrease the font size. There is also zoom capability available in the extreme left corner, near the status line, in code view as was illustrated in **Appendix A**.

**Box Selector** is a code editor tool that enables you to select a rectangular region, type a line, and have that line repeated for every line part of the region. To do this, hold the **Alt** key while using the mouse to make a vertical section. Then start typing. Whatever is typed appears on every line that is part of the region. This could be a useful tool for adding comments to blocks of text or change all data members from **public** to **private** by typing a single **private** keyword once the region has been selected.
