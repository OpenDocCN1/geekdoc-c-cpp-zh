The messages from Figures 12–9 through 12–11 were generated during run-time, and the entire application halted. No error had been detected when the program was compiled. It was only when the application ran that the program crashed and the message was displayed.

Remember that during the compilation stage, the errors that are detected are those in which specific statements violate the syntax or grammar of the language, such as omission of a semicolon at the end of a statement.
