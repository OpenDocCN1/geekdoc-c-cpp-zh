After a Web application is created, saved, and closed, it is reopened differently from a Windows application. To reopen a Web application, select **File, Open, Web Site** instead of **File, Open, Project**. By doing this, you are given five options, as shown on the right in Figure 15–4. If you select **Local IIS**, you are shown the list of all Web applications (sites) stored at localhost (C:\Inetpub\wwwroot).

**Figure 15–4** Opening an existing Web site

As shown in Figure 15–4, the first option listed on the **Open Web Site** dialog box is **File System**. When you select this option, you are able to browse to the location where the Web application is stored. All of the Web sites created for the rest of the chapter will be saved using the **File System** option.

As with Windows applications you still have the option of creating new Web sites from the **Start Page** when you launch Visual Studio. Select the **New Project** button. The Web Templates are available on the next screen. The same holds true for opening existing Web sites. You use the **Open Project** or **Recent Project** selection. This assumes the **Show Start page on startup** check box is selected on the **Start page**.
