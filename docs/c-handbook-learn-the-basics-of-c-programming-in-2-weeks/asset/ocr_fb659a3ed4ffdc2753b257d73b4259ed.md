Remember, if you lose a lot of weight quickly, you will put it back on just as quickly.

# ### If you want to do the plan again

I recommend that you don't partake in the Ketogenic diet for more than two weeks at a time. This is because you will need to consume fruits and vegetables and other nutrients that this diet may lack.

If you really would like to do the plan again, then please do the plan for two weeks, have two weeks off, and then start the plan again for another two weeks.
