# Writing Your First Program

C# programs are composed of these parts:

+   - Classes
+   - Comments
+   - Expressions and Statements
+   - Namespace Declarations
+   - Class Attributes
+   - Main Methods

Analyze the screenshot below. It is an easy code that prints this phrase: “ Hello World ”
