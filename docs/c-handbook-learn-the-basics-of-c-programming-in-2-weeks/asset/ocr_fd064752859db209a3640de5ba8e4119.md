# Recipe 5: Crock Pot Choco-Nut Candy

This is probably the best and easiest crockpot dessert you will ever make.

You will need:

+   - 500 grams roasted nuts – walnuts/peanuts/cashew
+   - 400 grams chocolate chips
+   - 4 chocolate bars

How to Prepare:

+   - Place all the ingredients into the crock pot.
+   - Cook for 3 hours under low heat. Allow to rest for at least 30 minutes.
+   - Stir well and pour over wax sheets or cookie trays. Divide evenly using a spoon.
+   - Lift them up using a wooden spatula. Enjoy!
