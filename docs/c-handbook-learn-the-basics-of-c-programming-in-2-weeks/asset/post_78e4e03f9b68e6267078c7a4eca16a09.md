If you are looking for a general-purpose, high-level programming language with code readability as its main focal point, you should consider Python. ### A Brief History of the Python Programming Language

Python was developed by Guido van Rossum in the late 1980s. It was initially just a Christmas project. Van Rossum wanted an interpreter for a scripting language that C and UNIX hackers would use. His little project eventually upgraded to Python 2.0, which was released in October 2000. This new version had a complete garbage collector and Unicode support. Python 3.0, also called Python 3000 and py3k, was released in December 2008 and had features that were backported to versions 2.6 and 2.7.
