Another way to execute scripts is to modify the .py file, such as:

```
#! /usr /bin /python

print “Monty Python’s Flying Circus”;
```

If you run it as

```
$ chmod + x test.py
$ ./test.py
```

you get the following output:

```
Monty Python’s Flying Circus
```
