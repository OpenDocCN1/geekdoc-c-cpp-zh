# Exercise

This plan also involves exercise, you don’t have to do a lot more exercise than you currently do, just try to be a bit more active. Think about walking or cycling to work or the shops, instead of using the car. Go for a walk when you have some free time, take an exercise class, or do anything that makes you sweat a little. The more active you are, the more calories you will burn, which means you will start to lose weight.

Important: If you do a lot more exercise, you will need to up your intake of fluids. Make sure that you don’t leave yourself dehydrated, get those fluids into your body, and feel better for it.
