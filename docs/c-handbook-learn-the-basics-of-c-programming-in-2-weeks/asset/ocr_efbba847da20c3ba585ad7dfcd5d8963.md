# Hide the Charms Bar

Then, you can proceed to hide the Charms Bar.

Basically, you can just choose *Settings* on its own, instead of having it appear in the Charms Menu. By clicking *Settings*, you’re already able to turn off the Charms Bar.

In order to access full Settings without the Charms Bar, here’s what you have to do:

+   1. Click *Charms* Bar.
+   2. Click *Change PC Settings*.
+   3. Then, access the first screen that you’d see on Windows 10.
+   4. Click the Start Button so that the new Start Menu would be displayed.
+   5. Click the *Settings* link.
+   6. Voilà! You’re all set!
