# Steam Inhalation

This is one of the more popular aromatherapy methods for improving respiratory and immune function. Simply boil water and add 3 to 7 drops of essential oils. Some of the best ones to use for this include tea tree oil, eucalyptus oil, lemon oil, and thyme essential oil.

Steam inhalation is used for:

+   - Congestion in upper respiratory tract (cold or flu)
+   - Sinus infection or sinusitis
+   - Enhancing respiratory function
