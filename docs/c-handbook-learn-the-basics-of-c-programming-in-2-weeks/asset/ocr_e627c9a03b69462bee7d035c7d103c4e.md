# How to Change the Font

+   1. Highlight the cell/s you wish to work on.
+   2. Click on the drop-down arrow right beside the current font’s name. Excel will display all of the available fonts in alphabetical order.
+   3. Choose the font that you want to use and click on it. The letters and numbers within the highlighted cells will reflect the change.

# How to Change the Font Size

+   1. Highlight the cell\s you need to format.
+   2. Click on the text box for Font Size.
+   3. Enter your preferred font size.

Important Note: You may click on the drop-down arrow of the Font Size menu. Then, choose the correct font size from the list.
