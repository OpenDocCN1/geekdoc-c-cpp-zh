# 8.3.2 Spatial deformation

S-patches can be used for applications other than filling multi-sided holes on surfaces as well. Though rarely thought of in this way, S-patches can be used for image and surface deformation as well. In fact, free-form deformations [353] (FFDs) as well as cage-based deformations [215, 217] are all special cases of deformation using S-patches.

To perform such spatial deformation, we use S-patches to construct a map $F: \mathbb{R}^d \rightarrow \mathbb{R}^d$ where $d = 2$ for images and $d = 3$ for surfaces and volumes. $F$ is then given by

```
$F(\boldsymbol{x}) = \sum_{|\boldsymbol{l}|=m} B_{\boldsymbol{l}}^m(\boldsymbol{x}) \boldsymbol{p}_{\boldsymbol{l}}.$
```

Hence, we control the deformation by manipulating the control points $\boldsymbol{p}_{\boldsymbol{l}} \in \mathbb{R}^d$.
