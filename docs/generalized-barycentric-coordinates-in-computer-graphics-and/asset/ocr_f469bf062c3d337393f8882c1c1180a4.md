Replacing the right-hand side component \( y_i \) with the expression \( -\sum_{j=n_b+1}^{n_v} w_{ij} x_j \) and \( w_{ii} \) with \( -1 \), we get the update

```
\( x_i \leftarrow - \left( - \sum_{j=n_b+1}^{n_v} w_{ij} x_j - \sum_{j=1}^{n_i-n_b} w_{ij} x_j \right) \)
```

or simply

```
\( x_i \leftarrow \sum_{j \in N_i} w_{ij} x_j \).
```

To summarize, applying Gauss-Seidel relaxation to Tutte's equation simply means iteratively moving each interior vertex to the weighted barycenter of its neighbors. This method is very simple to implement, and gives results in a reasonable time for small meshes (with a few thousand elements). If larger meshes need to be processed, then one can consider using more efficient iterative methods such as the bi-conjugate gradient method, as suggested in [143]. If memory consumption is not an issue, sparse direct solvers such as SuperLU [246] can be an even more efficient alternative. See also the chapter on numerical aspects in [66].
