As a consequence, starting from a sphere that has genus zero and Euler-Poincaré characteristic $\chi = 2$ (see Figure 6.5), each time one creates a handle, $g$ is increased by one (by the definition of $g$) and $\chi$ is decreased by two. To summarize, for a connected surface without any boundary, we have

$\chi = n_v - n_e + n_t = 2 - 2g.$

For example, for double torus (see Figure 6.5E), we have $g = 2$, thus $\chi = 2 - 2g = -4$.

Let us now turn to surfaces with multiple connected components and boundaries. It is easy to see what the formula becomes: since for a topological sphere, $\chi = 2$, each connected component adds two to the Euler-Poincaré characteristic. Consider now the "topological surgery" operation that creates a boundary by deleting a facet. It decreases $n_t$, thus it also decreases $\chi$. To summarize, for a surface with multiple connected components and multiple boundary components, we have

$\chi = n_v - n_e + n_t = 2n_{cc} - 2g - n_{bc}.$

where $n_{cc}$ denotes the number of connected components and $n_{bc}$ the number of boundary components.
In what follows, we consider topological disks, that is, surfaces with genus zero, a single connected component, and a single boundary component. They are characterized by

$g = 0, n_{cc} = 1, n_{bc} = 1.$
