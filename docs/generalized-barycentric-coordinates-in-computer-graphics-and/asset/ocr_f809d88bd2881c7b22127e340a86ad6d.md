where the derivatives are taken with respect to the arc-length $s$ and $k$ denotes the curvature of $\partial \Omega$.

It is easy to show [307] that the polar reciprocal curve $\Sigma_x$ is given by the radius vector $n/h$. Then a tangent vector for $\Sigma_x$ can be obtained by

\(\binom{n}{h}' = \frac{n'h - nh'}{h^2} = \frac{-kth + nkg}{h^2} = \frac{gn - ht}{\sqrt{g^2 + h^2}} \frac{k\rho}{h^2}.\) (3.17)

where the simple observations that

$h' = (r \cdot n)' = r' \cdot n + r \cdot n' = r \cdot n' = -kr \cdot t = -kg \quad \text{and} \quad \sqrt{g^2 + h^2} = |r| = \rho$

are used. Normalizing the tangent vector given by the right-hand side of (3.17) gives

$dl/ds = k\rho/h^2,$

Now $l$ is the arc-length of $\Sigma_x$. The unit normal for $\Sigma_x$ is given by $\mathbf{n}_\Sigma = r/\rho$. Now we can find the curvature $k_\Sigma$ of $\Sigma_x$ by differentiating its unit normal $\mathbf{n}_\Sigma$ with respect to $l$,

\(\frac{d}{dl}\mathbf{n}_\Sigma = -k_\Sigma \mathbf{t}_\Sigma \text{ with } \mathbf{n}_\Sigma = \frac{r}{\rho} = \frac{gt + hn}{\sqrt{g^2 + h^2}} \text{ and } \mathbf{t}_\Sigma = -\mathbf{n}_\Sigma^\perp = \frac{ht - gn}{\sqrt{g^2 + h^2}}.\)

where $\perp$ denotes the $\pi/2$ rotation in a clockwise direction. Further,

\(\frac{d}{dl} = \frac{ds}{dl} \frac{d}{ds}, \quad \frac{d}{ds} \left[ \frac{r}{\rho} \right] = \frac{r'\rho - r\rho'}{\rho^2} = \frac{t\rho - r\rho g}{\rho^2} = \frac{h^2t - ghn}{\rho^3} = \frac{h}{\rho^2} \frac{ht - gn}{\sqrt{g^2 + h^2}},\)

\(\frac{d}{dl}\mathbf{n}_\Sigma = \frac{ds}{dl} \frac{d}{ds} \left[ \frac{r}{\rho} \right] = \frac{h^2}{k\rho^3} \frac{d}{ds} \left[ \frac{r}{\rho} \right] = \frac{h^3}{k\rho^3} \mathbf{t}_\Sigma = -k_\Sigma \mathbf{t}_\Sigma.\)

Thus the curvature $k_\Sigma$ of $\Sigma_x$ is given by
