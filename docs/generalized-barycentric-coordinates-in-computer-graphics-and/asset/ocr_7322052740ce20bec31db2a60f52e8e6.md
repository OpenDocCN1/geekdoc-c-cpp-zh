Combining (3.26) with

```
\frac{4}{3\pi} \int_0^{2\pi} \left( \frac{\partial^4 u}{\partial e_\theta^4} \right) d\theta = \Delta^2 u \qquad (3.27)
```

and mimicking biharmonic interpolation then leads to a modified version of the cubic Gordon-Wixon interpolation scheme,

```
u(x) = \int_0^{2\pi} \left[ \frac{(\rho_1 + \rho_2)\rho_2^3}{(\rho_1 + \rho_2)^3} u(y_1) + \frac{(\rho_1 + 3\rho_2)\rho_1^3}{(\rho_1 + \rho_2)^3} u(y_2) \right. \left. - \frac{\rho_1 \rho_2^2}{(\rho_1 + \rho_2)^2} \frac{\partial u}{\partial e_\theta}(y_1) + \frac{\rho_1^2 \rho_2}{(\rho_1 + \rho_2)^2} \frac{\partial u}{\partial e_\theta}(y_2) \right] \frac{d\theta}{\rho_1^2 \rho_2^2} \bigg/ \int_0^{2\pi} \frac{d\theta}{\rho_1^2 \rho_2^2} \qquad (3.28)
```

Similar to the cubic Gordon-Wixon scheme, (3.28) has cubic precision and reproduces biharmonic functions on a disk.
