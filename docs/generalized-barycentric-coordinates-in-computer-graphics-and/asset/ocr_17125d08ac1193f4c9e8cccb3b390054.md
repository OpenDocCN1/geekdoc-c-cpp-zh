# 8.1.2 Evaluation

While we can evaluate Bézier curves by evaluating the polynomial expressions in the Bernstein basis functions, a more elegant solution exists via de Casteljau's algorithm. To do so, we introduce a graphical notation for a linear combination of two control points. Figure 8.2 shows a simple pyramid diagram. The arrows denote taking the product of the value at the base of the arrow with the scalar value listed along the arrow. The result of this product is then added to the sum at the end of the arrow. Hence, this figure denotes taking f_0 and f_1 and multiplying these values by a, b, respectively, to form the result af_0 + bf_1. Using this notation, de Casteljau's algorithm can be written in a very elegant fashion as a pyramid diagram shown in Figure 8.3 [167]. Note that each level of the pyramid produces lower order Bézier functions with the value of the curve appearing at the apex of the pyramid.
