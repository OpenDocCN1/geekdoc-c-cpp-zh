```
u_i = \sum_{j \in N_i} w_{ij} u_j \qquad i = 1, \dots, n_v - n_{bw},
v_i = \sum_{j \in N_i} w_{ij} v_j \qquad i = 1, \dots, n_v - n_{bw}.
```

Note that the right-hand side contains a mixture of unknowns (the \(u_i\)’s and \(v_j\)’s associated to interior vertices) and fixed values (the \(u_i\)’s and \(v_j\)’s associated to boundary vertices). To re-organize the equation in a form that gathers the fixed values on the right-hand side, one can extend the definition of \(w_{ij}\) with the following conventions: \(w_{ii} = -1\) and \(w_{ij} = 0\) if \(j \notin N_i\). We have

```
\sum_{j=1}^{n_v - n_{bw}} w_{ij} u_j = - \sum_{j=n_v - b_w + 1}^{n_v} w_{ij} u_j \qquad i = 1, \dots, n_v - n_{bw},
\sum_{j=1}^{n_v - n_{bw}} w_{ij} v_j = - \sum_{j=n_v - b_w + 1}^{n_v} w_{ij} v_j \qquad i = 1, \dots, n_v - n_{bw}.
```

In matrix form, the two linear systems can be written as

```
W \mathbf{X}^u = \mathbf{Y}^u,
W \mathbf{X}^v = \mathbf{Y}^v,
```

where \(W\) is an \((n_v - n_{bw}) \times (n_v - n_{bw})\) matrix, and \(\mathbf{X}^u, \mathbf{X}^v, \mathbf{Y}^u, \mathbf{Y}^v\) are \((n_v - n_{bw})\)-dimensional vectors.

We now outline several methods to solve such linear systems. Considering a system in the form \(W \mathbf{X} = \mathbf{Y}\), with \(n = n_v - n_{bw}\), Gauss-Seidel relaxation is a method that is very simple to implement. Intuitively, it can be understood by considering the equation in the form of the linear system

```
w_{i,1}x_1 + w_{i,2}x_2 + \dots + w_{i,n}w_n = y_1,
\vdots
w_{i,1}x_1 + w_{i,2}x + \dots + w_{i,i}x_i + \dots + w_{i,n}w_n = y_i,
\vdots
w_{n,1}x_1 + w_{n,2}x_2 + \dots + w_{n,n}w_n = y_n.
```

The algorithm iterates over and over through the n equations. For each equation \(i\), it "pretends" that all the variables \(x_j\) for \(j \neq i\) are known and updates \(x_i\) accordingly as

```
x_i \leftarrow \frac{1}{w_{ii}} \left( y_i - \sum_{j=1}^{n_v - n_{bw}} w_{ij} x_j \right).
```
