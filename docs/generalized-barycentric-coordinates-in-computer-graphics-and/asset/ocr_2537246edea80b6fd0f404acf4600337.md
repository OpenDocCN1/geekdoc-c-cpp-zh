Averaging (3.24) with respect to \(\theta\) leads to the Hermite-type Gordon-Wixom interpolation scheme

```
\(u(\boldsymbol{x}) = \frac{1}{2\pi} \int_0^{2\pi} u(\boldsymbol{x}, \theta) \, d\theta.\) (3.25)
```

The transfinite interpolation scheme (3.25) has cubic precision and reproduces biharmonic functions if \(\Omega\) is a disk. The biharmonic property was conjectured in [171] and rigorously proved in [145].
