# 3.2.5 Transfinite Laplace and Wachspress coordinates coincide for a disk

As shown in [149], discrete harmonic and Wachspress coordinates are the same for a circumscribable polygon. The continuous or transfinite version of this remarkable result is established in [93]. Below we give a different and elementary proof that transfinite Laplace and Wachspress coordinates coincide if \(\Omega\) is a disk.

Using the notations of Figure 3.3 we have

```
\(\cos \theta = \frac{\rho^2 + r^2 - R^2}{2\rho r} = A\rho - B\frac{1}{ho}\)
```

for some values of \(A\) and \(B\), which do not depend on \(\theta\). Thus,

```
\(0 = (\cos \theta)'' + \cos \theta = A[\rho''_{\theta\theta} + \rho] - B[(1/\rho)''_{\theta\theta} + 1/\rho].\)
```

It remains to note that the kernels \(\rho''_{\theta\theta} + \rho\) and \((1/\rho)''_{\theta\theta} + 1/\rho\) correspond to the transfinite Laplace and Wachspress coordinates, respectively.
