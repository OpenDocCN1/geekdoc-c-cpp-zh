# TABLES OF SQUARES

Table of squares from 1 to 10. Program stops after 5 iterations

Author: Dogan Ibrahim
File  : squares2.c
Date  : December 2020

```
/*-------------------------------------------------
        TABLES OF SQUARES
        ================
Table of squares from 1 to 10. Program stops after 5 iterations

Author: Dogan Ibrahim
File  : squares2.c
Date  : December 2020
---------------------------------------------------*/

#include <stdio.h>

int main(void)
{
    int k;

    printf("\nTABLE OF SQUARES");
    printf("\n===============\n");

    for(k = 1; k <= 10; k++)
    {
        printf("%3d\t%3d\n", k, k*k);
        if(k == 5)break;
    }

    return 0;
}
```
