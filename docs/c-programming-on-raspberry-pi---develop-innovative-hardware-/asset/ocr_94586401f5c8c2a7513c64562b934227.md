# GENERATING SQUARE WAVE SIGNAL USING DAC

In this project an analogue-to-digital converter is used to generate square wave signal. The peak value of the signal is set to 2V. The ON and OFF times are 1ms each, so the period is 2ms (freq = 500Hz)

This is the pigpio version of the program

Author: Dogan Ibrahim
File : squaredac2.c
Date : December 2020
