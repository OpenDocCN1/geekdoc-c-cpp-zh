
导通和关断时间的持续时间设置为1ms。实验发现，DAC例程大约耗时0.2ms（0.0002秒），而且树莓派的延时函数不是很准确。因此，输出波形的周期及相应频率不是很准确。导通和关断时间略大于1ms。如有需要，读者可以通过实验调整延时以获得精确的1ms。
