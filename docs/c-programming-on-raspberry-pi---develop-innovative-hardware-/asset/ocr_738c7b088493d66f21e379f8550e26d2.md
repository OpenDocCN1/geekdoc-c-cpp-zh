# ## 13.12 • pigpiod

pigpio supports a utility called **pigpiod** which launches the **pigpio** library as a daemon. After launching the library, it runs in the background and accepts commands from pipe and socket interfaces (for details see: [http://abyz.me.uk/rpi/pigpio/pigpiod.html](http://abyz.me.uk/rpi/pigpio/pigpiod.html)).
