# pigpio

The pigpio version of the program is shown in Figure 9.7 (Program: **tmp36-2.c**). This version of the program is very similar to the wiringPi version. Function **get_adc_data** receives temperature data from the chip as in the previous program. Two buffers are used: **bufftx** and **buffrx**. bufftx is filled with the start bit, SGL/DIFF, ODD/SIGN, and MSBF. The data returned by the chip is stored in buffer **buffrx**. Temperature is extracted and returned to the calling program.
