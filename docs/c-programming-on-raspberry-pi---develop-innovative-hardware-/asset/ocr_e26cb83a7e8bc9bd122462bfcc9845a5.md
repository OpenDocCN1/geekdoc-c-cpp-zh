The MCP23017 chip has 8 internal registers that can be configured for its operation. The device can be operated either in 16-bit mode or two 8-bit mode by configuring bit IOCON. BANK. On power-up, this bit is cleared which selects the two 8-bit mode by default.

The I/O direction of the port pins are controlled with registers IODIRA (at address 0x00) and IODIRB (at address 0x01). Clearing a bit to 0 in these registers makes the corresponding port pin(s) as output(s). Similarly, setting a bit to 1 in these registers makes the corresponding port pin(s) inputs(s). GPIOA and GPIOB register addresses are 0x12 and 0x13 respectively. This is shown in Figure 7.4.
