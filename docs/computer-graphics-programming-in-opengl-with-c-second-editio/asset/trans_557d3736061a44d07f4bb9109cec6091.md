
在 C++ 的 `display()` 函数中，紧接在 `glBindTexture()` 命令之后调用 `glUniform1i(glGetUniformLocation(renderingProgram, "samp"), 0);`，其中 "samp" 是 uniform 采样器变量的名称，而前一个示例中的 "0" 是先前已删除的绑定命令中指定的纹理单元。
