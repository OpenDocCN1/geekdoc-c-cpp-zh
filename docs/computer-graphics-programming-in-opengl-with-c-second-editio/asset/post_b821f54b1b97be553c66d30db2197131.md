
`glUniform1i(glGetUniformLocation(renderingProgram, "samp"), 0);` immediately after the `glBindTexture()` command in the C++ `display()` function, where "samp" is the name of the uniform sampler variable, and the "0" in the previous example is the texture unit specified in the binding command that was removed earlier.

### B.2.6 Additional Notes
