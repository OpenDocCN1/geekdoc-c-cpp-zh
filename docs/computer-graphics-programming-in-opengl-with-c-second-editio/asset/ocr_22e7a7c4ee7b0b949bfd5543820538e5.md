+   - Finding whether the angle between vectors lies in the range (-90°..+90°): \(\vec{V} \cdot \vec{W} > 0\)
+   - Finding the minimum signed distance from point \(P=(x,y,z)\) to plane \(S=(a,b,c,d)\). First, find unit vector normal to \(S\):
+     \(\hat{n}=(\frac{a}{\sqrt{a^2+b^2+c^2}},\frac{b}{\sqrt{a^2+b^2+c^2}},\frac{c}{\sqrt{a^2+b^2+c^2}})\), and shortest distance
+     \(D=\frac{d}{\sqrt{a^2+b^2+c^2}}\) from the origin to the plane. Then, the minimum signed distance from \(P\) to \(S\) is: \((\hat{n} \cdot \vec{P})+D\) and the sign of this distance determines on which side of the plane S point P lies.
