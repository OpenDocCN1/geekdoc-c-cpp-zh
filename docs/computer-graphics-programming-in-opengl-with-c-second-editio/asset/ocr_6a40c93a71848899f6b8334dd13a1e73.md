# ### 3.7 EYE SPACE AND THE SYNTHETIC CAMERA

So far, the transform matrices we have seen all operate in 3D space. Ultimately, however, we will want to display our 3D space—or a portion of it—on a 2D monitor. In order to do this, we will need to decide on a vantage point. Just as we see our real world through our eyes from a particular point in a particular direction, so too must we establish a position and orientation as the window into our virtual world. This vantage point is called “view” or “eye” space, or the “synthetic camera.”

As shown in Figures 3.10 and 3.12, viewing involves: (a) placing the camera at some world location; (b) orienting the camera, which usually requires maintaining its own set of orthogonal axes *U/V/N*; (c) defining a *view volume*; and (d) projecting objects within the volume onto a *projection plane*.
