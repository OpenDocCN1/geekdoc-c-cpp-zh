# ## 17.5 A SIMPLE TESTING HARDWARE CONFIGURATION

There are many ways available today for viewing side-by-side scenes such as the one rendered by Program 17.3. While modern headsets can be pricey, a simple method that the authors have used for preparing the examples in this chapter is to utilize the following set of technologies:

+   - a reasonably modern cell phone (such as Android or iPhone) connected to a computer
+   - WiredXDisplay [WX20] (cell phone app), which duplicates the computer screen to the cell phone
+   - Google Cardboard [GC20] for viewing the cell phone display in split screen format

For readers who already own a smart phone, the total cost for the above solution is under $20. The phone can be connected to a computer using a USB cable. The WiredXDisplay application then transmits the contents of the computer screen to the cell phone, essentially turning the phone into a computer monitor. The phone is then placed inside the Google Cardboard headset, which assumes the left half of the display screen is for the left eye, and the right half is for the right eye.
