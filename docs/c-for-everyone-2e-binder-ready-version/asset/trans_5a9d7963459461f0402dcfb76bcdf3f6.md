## 在 C++ 中制定类的公共接口。

- 修改器成员函数会改变其操作的对象。
- 访问器成员函数不会改变其操作的对象。访问器请使用 `const`。

## 选择数据成员来表示对象的状态。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_454_0.png)

- 对象持有由成员函数访问的数据成员。
- 每个对象都有自己的一组数据成员。
- 私有数据成员只能由同一个类的成员函数访问。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_454_1.png)

## 实现类的成员函数。

- 定义成员函数时使用 `ClassName::` 前缀。
- 隐式参数是成员函数所作用对象的引用。
- 成员函数的显式参数在函数定义中列出。
- 在同一对象上调用另一个成员函数时，不要使用点号表示法。

## 设计并实现构造函数。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_454_2.png)

- 每当创建对象时，构造函数会自动被调用。
- 构造函数的名称与类名相同。
- 默认构造函数没有参数。
- 一个类可以有多个构造函数。
- 编译器会选择与构造参数匹配的构造函数。
- 请务必在构造函数中初始化所有数值和指针数据成员。

## 使用对象追踪技术来可视化对象行为。

- 将成员函数写在卡片正面，数据成员的值写在背面。
- 当调用修改器成员函数时，更新数据成员的值。
