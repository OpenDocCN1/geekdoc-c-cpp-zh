If you omit the length, you get all characters from the given position to the end of the string. For example,

```
greeting.substr(7)
```

is the string "World!" (including the exclamation mark).

Here is a simple program that puts these concepts to work. The program asks for your name and that of your significant other. It then prints out your initials.

The operation first.substr(0, 1) makes a string consisting of one character, taken from the start of first. The program does the same for the second. Then it concatenates the resulting one-character strings with the string literal "&" to get a string of length 3, the initials string. (See Figure 4.)

![](bbox=[0.28, 0.34, 0.56, 0.48])

Figure 4 Building the initials String

![](bbox=[0.68, 0.22, 0.9, 0.44])

Initials are formed from the first letter of each name.

# ch02/initials.cpp

```

3
4  using namespace std;
5
6  int main()
7  {
8      cout << "Enter your first name: ";

10     cin >> first;

12     string second;
13     cin >> second;
14     string initials = first.substr(0, 1)
```
