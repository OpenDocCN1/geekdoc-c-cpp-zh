```cpp

```

用于测试某一年是否为闰年：即一年有 366 天。闰年是使日历与太阳保持同步所必需的，因为地球每 365.25 天绕太阳一周。实际上，这个数字并不完全精确，对于 1582 年之后的所有日期，适用格里高利历修正。通常能被 4 整除的年份是闰年，例如 1996 年。然而，能被 100 整除的年份（例如 1900 年）不是闰年，但能被 400 整除的年份是闰年（例如 2000 年）。
