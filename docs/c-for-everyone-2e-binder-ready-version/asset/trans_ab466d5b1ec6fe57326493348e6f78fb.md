- 数组元素可以像任何变量一样使用。
- 数组索引必须至少为零且小于数组大小。
- 如果提供了无效的数组索引，就会发生越界错误，它可能破坏数据或导致程序终止。
- 对于未填满的数组，要用一个伴随变量来记录当前大小。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_318_1.png)

## 能够使用常见的数组算法。

- 要复制数组，请使用循环将其元素复制到新数组中。
- 分隔元素时，不要在第一个元素前放置分隔符。
- 线性搜索按顺序检查元素，直到找到匹配项。
- 在插入元素之前，*从最后一个元素开始*将元素向数组末尾移动。
- 交换两个元素时使用临时变量。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_318_2.png)

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_318_3.png)

## 实现处理数组的函数。

- 将数组传递给函数时，也要传递数组的大小。
- 数组参数始终是引用参数。
- 函数的返回类型不能是数组。
- 当函数修改数组大小时，它需要告知调用者。
- 向数组添加元素的函数需要知道数组的容量。

## 能够组合并调整算法来解决编程问题。

- 通过组合基本算法，你可以解决复杂的编程任务。
- 你应该熟悉基本算法的实现，以便能够调整它们。

## 通过操作实物来发现算法。

- 使用一系列硬币、扑克牌或玩具来可视化值数组。
- 你可以使用回形针作为位置标记或计数器。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_318_4.png)

## 使用二维数组存储按行和列排列的数据。

- 使用二维数组存储表格数据。
- 二维数组中的单个元素通过两个下标 `array[i][j]` 访问。
- 二维数组参数必须具有固定的列数。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_318_5.png)

## 使用向量管理大小可变的集合。

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_319_0.png)

- 向量存储大小可变的值序列。
- 使用 `size` 成员函数获取向量的当前大小。
- 使用 `push_back` 成员函数向向量添加更多元素。使用 `pop_back` 减小大小。
- 向量可以作为函数参数和返回值。
- 使用引用参数修改向量的内容。
- 函数可以返回向量。
