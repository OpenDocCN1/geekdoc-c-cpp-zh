**Figure 3 Parameter Passing**

| Stage | Code | State |
| --- | --- | --- |
| Function call | `double result = cube_volume(2);` | `result = ?` |
| Entering function `cube_volume` | `double result = cube_volume(2);` | `side = 2` |
| Executing function body | `double volume = side * side * side;` | `side = 2` |
| Executing return statement | `return volume;` | `volume = 8` |
| Return to function call | `double result = cube_volume(2);` | `result = 8` |

- The parameter variable `side` (length of cube) is created.
- The parameter variable is initialized with the value of the argument that was passed in the call to `cube_volume`.
- The variable `volume` is assigned the value of `side * side * side`, which is stored in the variable `volume`.
- The return statement returns the value of `volume`, so `cube_volume` returns `8`.

## Common Error 2.1

### Using Undefined Variables

You must declare a variable before using it for the first time. For example, the following sequence of statements would not be legal:

```
    double can_volume = 4 / 3 * 3.14 * can_radius * can_radius * 1.75;
    double can_radius = 12 * 3.14 * 1.75 * 1.75;
```

In your program, the statements are compiled in order. When the compiler reaches the first statement, it does not know that later can_radius will be defined in the next line, and it reports an error.

## Programming Tip 3.6

### Hand-Tracing

A very useful technique for understanding whether a program works correctly is called hand-tracing. You simulate the program’s activity on a sheet of paper. You can use this method with pseudocode or Java code.

![](img/6ec8c4bdbdda7d4ab1f2166b5332154c_12_0.png)

Hand-tracing helps you understand whether a program works correctly.

Get an index card, or some other kind of paper, and make a table with one column for each variable in the program. Add rows for lines in the program, if you like. Make sure that every time a variable is updated, you cross out the old value and write the new value below it.

You need to know how to execute a loop. In a loop, you repeatedly execute the statements inside it until the loop condition is false.

| input | count | max |
| --- | --- | --- |
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 3 | 3 |

| input | count | max |
| --- | --- | --- |
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 3 | 3 |
| -1 | 3 | 3 |

For example, let’s trace the program with the data from the preceding section. Suppose we use the input values 1, 2, 3, and -1, and the code from Worked Example 3.1.

```
    Line 14: int input = in.nextInt();
    Line 15: int count = 0;
    Line 16: int max = 0;
    Line 17: while (input >= 0) {
    Line 18:    count++;
    Line 19:    if (input > max) { max = input; }
    Line 20:    input = in.nextInt();
    Line 21: }
    Line 22: double average = 0;
    Line 23: if (count > 0) { average = (double) max / count; }
    Line 24: System.out.println(average);
```

Because max starts at 0, it is replaced by 1; it is later replaced by 2; then it is replaced by 3; it is not replaced by -1 because -1 is not greater than 3. On the next input, the loop condition is false. Then the average is computed as (double) max / count. If count is 0, the average is 0.

## Special Topic 6.2

### A Sorting Algorithm

Sorting is the process of rearranging the elements of a sequence so that they are stored in sorted order. Here is a simple sorting algorithm, called selection sort. Consider sorting the following array values:

`11 9 17 12 5 10`

An obvious first step is to find the smallest element. In this case, the smallest element is 5, stored in slots[4]. You should move the 5 to the beginning of the array. Of course, there is already an element stored in slots[0], namely 11. Therefore the 11 needs to be copied to slots[4], the position previously occupied by 5. The following shows the array after the first step is completed.

`5 9 17 12 11 10`

Now the first element is in the correct position. In the next step, the second element is in the correct position. In the next step, the third element is in the correct position. In the next step, the fourth element is in the correct position. The remaining array values are 9, 17, 12, 11, 10. The next step is to find the smallest element in the remaining array. The smallest element is 9, stored in slots[1]. You should move the 9 to the beginning of the remaining array. Of course, there is already an element stored in slots[1], namely 9. Therefore no action is needed. The following shows the array after the second step is completed.

`5 9 17 12 11 10`

Now the first two elements are in the correct positions. In the next step, the remaining array values are 17, 12, 11, 10. The smallest element is 10, stored in slots[5]. You should move the 10 to the beginning of the remaining array. Of course, there is already an element stored in slots[2], namely 17. Therefore the 17 needs to be copied to slots[5], the position previously occupied by 10. The following shows the array after the third step is completed.

`5 9 10 12 11 17`

Now the first three elements are in the correct positions. In the next step, the remaining array values are 12, 11, 17. The smallest element is 11, stored in slots[4]. You should move the 11 to the beginning of the remaining array. Of course, there is already an element stored in slots[3], namely 12. Therefore the 12 needs to be copied to slots[4], the position previously occupied by 11. The following shows the array after the fourth step is completed.

`5 9 10 11 12 17`

Now the first four elements are in the correct positions. In the next step, the remaining array values are 12 and 17. The smallest element is 12, stored in slots[4]. You should move the 12 to the beginning of the remaining array. Of course, there is already an element stored in slots[4], namely 12. Therefore no action is needed. The following shows the array after the fifth step is completed.

`5 9 10 11 12 17`

Now the first five elements are in the correct positions. In the next step, the remaining array value is 17. The smallest element is 17, stored in slots[5]. You should move the 17 to the beginning of the remaining array. Of course, there is already an element stored in slots[5], namely 17. Therefore no action is needed. The following shows the array after the sixth step is completed.

`5 9 10 11 12 17`

Now the first six elements are in the correct positions. The array is now sorted.

## Random Fact 4.1

### The First Bug

According to legend, the first computer bug was a real insect. The computer scientist Grace Murray Hopper, a pioneer in the field of computers, was working on an early computer, the Mark II, at Harvard University. One day, the machine stopped working. She and her coworkers discovered that a moth was trapped in a relay switch. The operators taped the moth to the logbook. The logbook entry, shown below, reads “First actual case of bug being found.” The moth itself has disappeared, but the logbook page is preserved at the Smithsonian Institution.
