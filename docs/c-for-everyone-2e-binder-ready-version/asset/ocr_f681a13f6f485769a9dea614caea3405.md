# Programming Tip 3.1

# Brace Layout

Programmers vary in how they align braces in their code. In this book, we follow the simple rule of making { and } line up.

```
~~~
if (floor > 13)
{
   floor--;
}
~~~
```

This style makes it easy to spot matching braces.
