# Expressions

With string interpolation, expressions within curly braces {} can also be evaluated. The result will be inserted at the corresponding location within the string. For example, to calculate the maximum of foo and bar and insert it, use Math.Max within the curly braces:Console.WriteLine($"And the greater one is: {th.Max(foo, bar)}");

Output:

> And the greater one is: 42
