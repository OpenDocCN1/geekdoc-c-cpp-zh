# Adapting layout for mobile, tablet, and desktop

On smaller screens Bootstrap will automatically stack the columns you create for your site. However, you can exercise more control than just relying on the default behavior over how these columns appear. There are four device screen sizes you can target – phones, tablets, desktops, and large desktops. As shown in Table 8-1, Bootstrap uses a different class prefix to target each device.

| Table 8-1 | Bootstrap Code for Various Screen Sizes | | | | |
|---|---|---|---|---|---|
|  | Phones (<768 px) | Tablets (≥768px) | Desktops (≥992px) | Large desktops (≥1200 px) |  |
| Class prefix | `col-xs-` | `col-sm-` | `col-md-` | `col-lg-` |  |
| Max container width | None (auto) | 750px | 970px | 1170px |  |
| Max column width | Auto | ~62px | ~81px | ~97px |  |
