Stretching a cell across columns or rows is called *spanning*.

The colspan attribute spans a column over subsequent vertical columns. The value of the colspan attribute is set equal to the number of columns you want to span. You always span a column from left to right. Similarly, the rowspan attribute spans a row over subsequent horizontal rows. Set rowspan equal to the number of rows you want to span.

The following code generates a part of the table shown in Figure 5-8. You can see the colspan attribute spans the Total Revenue cell across two columns. As described in Chapter 4, the <strong> tag is used to mark important text, and is shown as bold by the browser.
