# Navigating with toolbars

Web pages with multiple pages or views usually have one or more toolbars to help users with navigation. Some toolbar options are shown in Table 8-3.

| Attribute | Class Prefix | Description |
|---|---|---|
| Toolbar type | `nav-tabs` | Tabbed navigation toolbar |
|  | `nav-pills` | Pill, or solid button navigation toolbar |
| Toolbar button type | `dropdown` | Marks button or tab as dropdown menu |
|  | `caret` | Down-arrow dropdown menu icon |
|  | `dropdown-menu` | Dropdown menu items |

To create a pill or solid button navigation toolbar, write the following HTML:

+   - Begin an unordered list using the `<ul>` element.
+   - In the opening `<ul>` tag, include `class="nav nav-pills"`.
+   - Create buttons using the `<li>` tag. Include `class="active"` in one opening `<li>` tag to designate which tab on the main toolbar should appear as visually highlighted when the mouse hovers over the button.
