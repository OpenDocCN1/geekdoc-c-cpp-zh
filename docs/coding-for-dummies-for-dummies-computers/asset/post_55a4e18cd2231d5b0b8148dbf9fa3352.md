
```css
a:link {
    color: rgb(6,69,173);
    text-decoration: none;
}
a:visited {
    color: rgb(11,0,128);
}
a:hover {
    text-decoration: underline;
}
a:active {
    color: rgb(250,167,0);
}
```

![](img/5a907eb39993e80f28c82efc2e4632b3_100_0.png)

Remember to include the colon between the a selector and the link state.

![](img/5a907eb39993e80f28c82efc2e4632b3_100_1.png)

Although explaining why is out of the scope of this book, CSS specifications insist that you define the various link states in the order shown here — link, visited, hover, and then active. However, it is acceptable to not define a link state, as long as this order is preserved.

The various link states are known as *pseudo-class selectors*. Pseudo-class selectors add a keyword to CSS selectors and allow you to style a special state of the selected element.

## Adding background images and styling foreground images

You can use CSS to add background images behind HTML elements. Most commonly, the background-image property is used to add background images to individual HTML elements such as div, table, and p, or (when applied to the body element) to entire web pages.

![](img/5a907eb39993e80f28c82efc2e4632b3_101_0.png)

Background images with smaller file sizes load more quickly than larger images. This is especially important if your visitors commonly browse your website using a mobile phone, which typically has a slower data connection.

The properties and values in Table 6-3 show the options for adding background images.

| Property name | Possible values | Description |
|---|---|---|
| `background-image` | `url("URL")` | Adds a background image from the image link specified at URL. |
| `background-size` | `auto`<br>`contain`<br>`cover`<br>`width`<br>`height`<br>`(#px, %)` | Sets background size according to the value:<br><br>`auto` (default value) displays the image as originally sized.<br><br>`contain` scales the image's width and height so that it fits inside element.<br><br>`cover` scales the image so entire background is not visible.<br><br>Background size can also be set by specifying width and height in pixels or as a percentage. |
| `background-position` | `keywords`<br><br>`position`<br>(#px, %) | Positions the background in the element using keywords or exact position. `Keywords` are comprised of horizontal keywords (`left`, `right`, `center`), and vertical keywords (`top`, `center`, and `bottom`). The placement of the background can also be exactly defined using pixels or a percentage to describe the horizontal and vertical position relative to the element. |
| `background-repeat` | `repeat`<br>`repeat-x`<br>`repeat-y`<br>`no-repeat` | Sets the background image to tile, or repeat, as follows:<br>horizontally (repeat-x)<br>vertically (repeat-y)<br>horizontally and vertically (repeat)<br>don't repeat at all (no-repeat). |
| `background-attachment` | `scroll`<br>`fixed` | Sets the background to scroll with other content (scroll), or to remain fixed (fixed). |

### Setting the background-image

As shown in the following example, the background-image property can set the background image for the entire web page or a specific element.

```css
body {
    background-image:
        url("http://upload.wikimedia.org/wikipedia/commons/e/e5/Chrysler_Building_Midtown_Manhattan_New_York_City_1932.jpg");
}
```

![](img/5a907eb39993e80f28c82efc2e4632b3_102_0.png)

You can find background images at sites such as images.google.com, www.flickr.com, or publicdomainarchive.com.

![](img/5a907eb39993e80f28c82efc2e4632b3_102_1.png)

Check image copyright information to see if you have permission to use the image, and comply with image’s licensing terms, which can include attributing or identifying the author. Additionally, directly linking to images on other servers is called hotlinking. It is preferable to download the image, and host and link to the image on your own server.

![](img/5a907eb39993e80f28c82efc2e4632b3_102_2.png)

If you’d prefer a single-color background instead of an image, use the background-color property. This property is defined in much the same way as the background-image property. Just set it equal to a color name, RGB value, or hex code, as I describe earlier in this chapter in the section “Setting the color.”

### Setting the background-size

By specifying exact dimensions using pixels or percentages, the background-size property can scale background images to smaller or larger, as needed. In addition, this property has three dimensions commonly used on web pages, as follows (see Figure 6-7):

- **auto:** This value maintains the original dimensions of an image.
- **cover:** This value scales an image so all dimensions are greater than or equal to the size of the container or HTML element.
- **contain:** This value scales an image so all dimensions are less than or equal to the size of the container or HTML element.

![](img/5a907eb39993e80f28c82efc2e4632b3_103_0.png)

**Figure 6-7:** Setting the background size to three different values.

### Setting the background-position

The background-position sets the initial position of the background image. The default initial position is in the top left corner of the web page or specific element. You can change the default position by specifying a pair of keyword or position values, as follows:

- **Keywords:** The first keyword *(left, center, or right)* represents the horizontal position, and the second keyword *(top, center, or bottom)* represents the vertical position.
- **Position:** The first position value represents the horizontal position, and the second value represents the vertical position. Each value is defined using pixels or percentages, representing the distance from the top-left of the browser or the specified element. For example, `background-position: center center` is equal to `background-position: 50% 50%`. (See Figure 6-8.)

### Setting the background-repeat

The background-repeat property sets the direction the background will tile as follows:

- **repeat:** This value (the default) repeats the background image both horizontally and vertically.
- **repeat-x:** This value repeats the background image only horizontally.
- **repeat-y:** This value repeats the background image only vertically.
- **no-repeat:** This value prevents the background from repeating at all.

![](img/5a907eb39993e80f28c82efc2e4632b3_104_0.png)

**Figure 6-8:** The initial background image positions specified using keywords or position.

### Setting the background-attachment

The background-attachment property sets the background image to move (or not) when the user scrolls through content on the page. The property can be set to:

- **scroll:** The background image moves when the user scrolls.
- **fixed:** The background image does not move when the user scrolls.

The following code segment uses several of the properties discussed earlier to add a background image that stretches across the entire web page, is aligned in the center, does not repeat, and does not move when the user scrolls. (See Figure 6-9.)

```css
body {
    background-image: url("http://upload.wikimedia.org/wikipedia/commons/thumb/a/a0/USMC-090807-M-8097K-022.jpg/640px-USMC-090807-M-8097K-022.jpg");
    background-size: cover;
    background-position: center center;
    background-repeat: no-repeat;
    background-attachment: fixed;
}
```

![](img/5a907eb39993e80f28c82efc2e4632b3_105_0.png)

**Figure 6-9:** An image set as the background for entire page.

## Styling Me Pretty

The CSS rules discussed in this chapter give you a taste of a few common styling properties and values. Although you aren’t likely to remember every property and value, with practice the property and value names will come to you naturally. After you understand the basic syntax, the next step is to actually incorporate CSS into your web page and try your hand at styling HTML elements.

### Adding CSS to your HTML

There are three ways to apply CSS to a website to style HTML elements:

- **In-line CSS:** CSS can be specified within an HTML file on the same line as the HTML element it styles. This method requires placing the `style` attribute inside the opening HTML tag. Generally, in-line CSS is the least preferred way of styling a website because the style rules are frequently repeated. Here’s an example of in-line CSS:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Record IPOs</title>
</head>
<body>
```
