Given a threshold ρ, FCBC first selects a set of features S that is highly correlated to the class with $SU \geq \rho$, where $SU$ is symmetrical uncertainty defined as

$$SU(f_i,C)=2\frac{IG(f_i,C)}{H(f_i)+H(C)}. \tag{2.7}$$

A feature $f_i$ is called predominant iff $SU(f_i,c_k) \geq \rho$ and there is no $f_j(f_j \in S,j \neq i)$ such as $SU(j,i) \geq SU(i,c_k)$. $f_j$ is a redundant feature to $f_i$ if $SU(j,i) \geq SU(i,c_k)$. Then the set of redundant features is denoted as $S_{(P_i)}$, which is further split into $S^+_{p_i}$ and $S^-_{p_i}$. $S^+_{p_i}$ and $S^-_{p_i}$ contain redundant features to $f_i$ with $SU(j,c_k)>SU(i,c_k)$ and $SU(j,c_k)\leq SU(i,c_k)$, respectively. Finally FCBC applied three heuristics on $S_{(P_i)}$, $S^+_{p_i}$ and $S^-_{p_i}$ to remove the redundant features and keep the features that are most relevant to the class. FCBC provides an effective way to handle feature redundancy in feature selection.

Minimum-Redundancy-Maximum-Relevance (mRmR) is also a mutual information based method and it selects features according to the maximal statistical dependency criterion [52]. Due to the difficulty in directly implementing the maximal dependency condition, mRmR is an approximation to maximizing the dependency between the joint distribution of the selected features and the classification variable. *Minimize Redundancy* for discrete features and continuous features is defined as:

For Discrete Features: $\min W_I,\quad W_I=\frac{1}{|S|^2}\sum_{i,j\in S}I(i,j)$  
For Continuous Features: $\min W_c,\quad W_c=\frac{1}{|S|^2}\sum_{i,j\in S}|C(i,j)|$  \tag{2.8}

where $I(i,j)$ and $C(i,j)$ are mutual information and the correlation between $f_i$ and $f_j$, respectively. Meanwhile, *Maximize Relevance* for discrete features and continuous features is defined as:

For Discrete Features: $\max V_I,\quad V_I=\frac{1}{|S|}\sum_{i\in S}I(h,i)$  
For Continuous Features: $\max V_c,\quad V_c=\frac{1}{|S|}\sum_iF(i,h)$  \tag{2.9}

where $h$ is the target class and $F(i,h)$ is the F-statistic.

**ReliefF [34,56]:** Relief and its multi-class extension ReliefF select features to separate instances from different classes. Assume that $\ell$ instances are randomly sampled from the data and then the score of the $i$-th feature $S_i$ is defined by Relief as,

$$S_i=\frac{1}{2}\sum_{k=1}^{\ell}\left(d(\mathbf{X}_{ik}-\mathbf{X}_{iM_k})-d(\mathbf{X}_{ik}-\mathbf{X}_{iH_k})\right). \tag{2.10}$$

where $M_k$ denotes the values on the $i$-th feature of the nearest instances to $\mathbf{x}_k$ with the same class label, while $H_k$ denotes the values on the $i$-th feature of the nearest instances to $\mathbf{x}_k$ with different class labels. $d(\cdot)$ is a distance measure. To handle multi-class problem, Equation (2.10) is extended as,

$$S_i=\frac{1}{K}\sum_{k=1}^{\ell}\left(-\frac{1}{m_k}\sum_{x_j\in M_k}d(\mathbf{X}_{ik}-\mathbf{X}_{ij})+\sum_{y\ne y_k}\frac{1}{h_{ky}}\frac{p(y)}{1-p(y)}\sum_{x_j\in H_k}d(\mathbf{X}_{ik}-\mathbf{X}_{ij})\right). \tag{2.11}$$

where $M_k$ and $H_{ky}$ denotes the sets of nearest points to $\mathbf{x}_k$ with the same class and the class $y$ with sizes of $m_k$ and $h_{ky}$ respectively, and $p(y)$ is the probability of an instance from the class $y$. In [56], the authors related the relevance evaluation criterion of ReliefF to the hypothesis of margin maximization, which explains why the algorithm provides superior performance in many applications.
