The dual problem only has $l$ variables, and the calculation of $Q_{ij}$ may not even require expanding $\phi(x_i)$ and $\phi(x_j)$. For example, suppose that we carefully scale the feature mapping of (7.10) as follows:

$$\phi(x)=\left[1\quad \sqrt{2}x_1\quad \sqrt{2}x_2\quad x_1x_1\quad \sqrt{2}x_1x_2\quad x_2x_2\right]^\mathsf{T},$$

In this case, $\phi(x_i)^\mathsf{T}\phi(x_j)$ could be obtained as follows:

$$\phi(x_i)^\mathsf{T}\phi(x_j)=(1+x_i^\mathsf{T}x_j)^2.$$

As a result, it is not necessary to explicitly expand the feature mapping. In the same manner, one could apply such a scaling to the $d$th order Taylor expansion, and the dot product $\phi(x_i)^\mathsf{T}\phi(x_j)$ could be simplified as follows:

$$\phi(x_i)^\mathsf{T}\phi(x_j)=(1+x_i^\mathsf{T}x_j)^d.$$

In fact, such a method can even handle infinite dimensional expansions. Consider the following feature mapping of a one-dimensional instance $x$,

$$\phi(x)=\exp(-x^2)\left[1\quad \sqrt{\frac{2}{1!}}x\quad \sqrt{\frac{2^2}{2!}}x^2\quad \sqrt{\frac{2^3}{3!}}x^3\quad \cdots\right]^\mathsf{T}. \tag{7.11}$$

The transformation is constructed by all degrees of polynomials of $x$, and $\mathbf{w}^\mathsf{T}\phi(x)$ can be seen as a scaled Taylor expansion with respect to the scalar $x$. Such a feature transformation could not even be performed *explicitly*, because of the infinite dimensionality. However, the dot product of the transformed feature vectors has a closed form, as follows:

$$\begin{aligned}\phi(x)^\mathsf{T}\phi(z)&=\exp(-x^2)\exp(-z^2)\sum_{i=0}^{\infty}\frac{1}{i!}(2xz)^i\\&=\exp(-x^2)\exp(-z^2)\exp(2xz)\\&=\exp\left(-(x-z)^2\right).\end{aligned}$$

As a result, we could implicitly apply this infinite dimensional feature mapping in the dual formulation, which is expressed only in terms of the dot product. This means that the transformation does not need to be performed explicitly, because the dot products in the dual formulation can be substituted with the kernel function. Such a method is referred to as the kernel trick, and the product is referred to as the **Kernel Function**, $k(x,z)\equiv\phi(x)^\mathsf{T}\phi(z)$. Similar to (7.8), we can predict an input $x$ via

$$h(x)=\sum_{i=1}^{l}\bar{\alpha}_iy_i\phi(x_i)^\mathsf{T}\phi(x)+\bar{b}=\sum_{i=1}^{l}\bar{\alpha}_iy_ik(x_i,x)+\bar{b}. \tag{7.12}$$

The matrix $K$, in which $K_{ij}=k(x_i,x_j)=\phi(x_i)^\mathsf{T}\phi(x_j)$, is called the **Kernel Matrix**. With the kernel matrix, the dual SVM could be written as the following form in [9].

$$\min_{\boldsymbol{\alpha}}\ \frac{1}{2}\boldsymbol{\alpha}^{\mathsf{T}}Q\boldsymbol{\alpha}-\mathbf{e}^{\mathsf{T}}\boldsymbol{\alpha},\quad \text{s.t.}\quad 0=\mathbf{y}^{\mathsf{T}}\boldsymbol{\alpha},\ 0\leq\boldsymbol{\alpha}\leq C\mathbf{e},\ Q_{ij}=y_iy_jK_{ij}.$$

As the definition shows, the kernel matrix is simply a dot map between transformed instances. Solving dual SVMs would only require the kernel matrix $K$, and we do not even need to know the mapping function $\phi(\cdot)$. In other words, classification could be done in an unknown high dimensional space, if the labels and a kernel matrix of training instances are given.
