

尽管存在一些不足，决策树在分类方法中仍然是一个极具吸引力的选择。改进工作仍在持续进行：更准确、更稳健的划分准则、用于获得更高精度的集成方法、处理数据流和概念漂移的增量方法，以及处理更大规模和分布式数据集的可扩展性功能。一个早在计算机发明之前就已出现的简单概念，决策树仍然是机器学习工具箱中的有价值工具。
