```
$$\bar{f}(x)=\frac{1}{n}\sum_{i=1}^{n}K'_h(x-x_i)$$ \tag{16.3}
```

A Gaussian kernel with width $h$ can be defined as Equation (16.4).

```
$$K'_h(x-x_i)=\left(\frac{1}{\sqrt{2\pi}\cdot h}\right)\cdot e^{-\frac{(x-x_i)^2}{2h^2}}$$ \tag{16.4}
```

The overall effect of kernel density estimation is to replace each discrete point $x_i$ by a continuous function $K'_h(x-x_i)$, which peaks at $\hat{x}_i$ and has a variance that is determined by the smoothing parameter $h$.

The presence of attribute-specific errors may change the density estimates. In order to take these errors into account, we need to define error-based kernels. The error-backed kernel can be defined as:

```
$$Q'_h(x-\hat{x}_i,\varphi(x_i))=\left(\frac{1}{\sqrt{2\pi}\cdot(h+\varphi(x_i))}\right)\cdot e^{-\frac{(x-\hat{x}_i)^2}{2\cdot(h+\varphi(x_i))^2}}$$ \tag{16.5}
```

where $\varphi(x_i)$ denotes the estimated error associated with data point $x_i$.

As in the previous case, the error-based density at a given data point is defined as the sum of the error-based kernels over different data points. Consequently, the error-based density $\bar{f}^{Q}(x,\varphi(x_i))$ at point $x_i$ is defined as:

```
$$\bar{f}^{Q}(x,\varphi(x_i))=\left(1/N\right)\cdot\sum_{i=1}^{N}Q'_h(x-x_i,\varphi(x_i))$$ \tag{16.6}
```

This method can be generalized for very large data sets and data streams by condensing the data into micro-clusters; specifically, here we need to adapt the concept of micro-cluster by incorporating the error information. In the following we will define an error-based micro-cluster as follows:

**Definition 1:** An error-based micro-cluster for a set of $d$-dimensional points $MC=\{x_1,x_2,\cdots x_m\}$ with order $1,2,\cdots,m$ is defined as a $(3\cdot d+1)$ tuple $(CF2^x(MC),EF2^x(MC),CF1^x(MC),n(MC))$, wherein $CF2^x(MC)$, $EF2^x(MC)$, and $CF1^x(MC)$ each correspond to a vector of $d$ entries. The definition of each of these entries is as follows.

+   - For each dimension, the sum of the squares of the data values is maintained in $CF2^x(MC)$. Thus, $CF2^x(MC)$ contains $d$ values. The $p$-th entry of $CF2^x(MC)$ is equal to $\sum_{i=1}^{m}(x_i^p)^2$.
