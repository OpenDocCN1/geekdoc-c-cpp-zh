# 17.1 Introduction

The problem of rare class detection is closely related to outlier analysis [2]. In *unsupervised* outlier analysis, no supervision is used for the anomaly detection process. In such scenarios, many of the anomalies found correspond to noise, and may not be of any interest to an analyst. It has been observed [35,42,61] in diverse applications such as system anomaly detection, financial fraud, and Web robot detection that *the nature of the anomalies is often highly specific to particular kinds*
