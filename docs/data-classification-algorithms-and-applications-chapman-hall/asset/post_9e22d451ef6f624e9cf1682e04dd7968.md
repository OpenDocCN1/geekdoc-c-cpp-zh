
problem, a Lagrangian relaxation approach may be used to derive the optimality condition. The Lagrangian is defined to be the sum of the objective function, and a constraint-based penalty term with non-negative Lagrange multipliers α ≥ 0 and β ≥ 0,

L(w, b, ξ, α, β) ≡ ½ wᵀ w + C Σᵢ₌₁ˡ ξᵢ − Σᵢ₌₁ˡ αᵢ (yᵢ (wᵀ xᵢ + b) − 1 + ξᵢ) − Σᵢ₌₁ˡ βᵢ ξᵢ.

Consider the problem min_{w,b,ξ} P(w, b, ξ) and max_{α ≥ 0, β ≥ 0} D(α, β), in which

P(w, b, ξ) ≡ max_{α ≥ 0, β ≥ 0} L(w, b, ξ, α, β) and D(α, β) ≡ min_{w,b,ξ} L(w, b, ξ, α, β).

We point out the following property of the function P. When (w, b, ξ) is a feasible solution of (7.2), P(w, b, ξ) equals the objective of (7.2) by setting the Lagrangian multipliers to zero. Otherwise,

P(w, b, ξ) → ∞ when (w, b, ξ) is not feasible.

As a result, the problem min_{w,b,ξ} P(w, b, ξ) is equivalent to (7.2). Furthermore, because L(w, b, ξ, α, β) is convex in (w, b, ξ), and concave in (α, β), we have the following equality from the saddle point property of concave-convex functions,

min_{w,b,ξ} max_{α ≥ 0, β ≥ 0} L(w, b, ξ, α, β) = max_{α ≥ 0, β ≥ 0} min_{w,b,ξ} L(w, b, ξ, α, β).

This property is popularly referred to as the Minimax Theorem [32] of concave-convex functions. The left-hand side, min_{w,b,ξ} P(w, b, ξ), is called the Primal Problem of SVM, and the right-hand side, max_{α ≥ 0, β ≥ 0} D(α, β), is the Dual Problem of SVM. Similar to the primal objective function,

D(α, β) → −∞ when Σᵢ₌₁ˡ αᵢ yᵢ ≠ 0 or C e − α + β ≠ 0,

where e is the vector of ones. However, such an (α, β) does not need to be considered, because the dual problem maximizes its objective function. Under any given (α, β) with D(α, β) ≠ −∞, the minimum (ŵ, b̂, ξ̂) is achieved in the unconstrained problem min_{w,b,ξ} L(w, b, ξ, α, β), if and only if ∇_{w,b,ξ} L(w, b, ξ, α, β) = 0. In other words,

∂L/∂w = 0 ⇒ ŵ − Σᵢ₌₁ˡ αᵢ yᵢ xᵢ = 0, ∂L/∂b = 0 ⇒ Σᵢ₌₁ˡ yᵢ αᵢ = 0, ∂L/∂ξ = 0 ⇒ C e − α + β = 0. (7.3)

Thus, the dual objective, D(α, β) ≡ min_{w,b,ξ} L(w, b, ξ, α, β), could be expressed as follows:

D(α, β) = L(ŵ, b̂, ξ̂, α, β) = −½ Σᵢ₌₁ˡ Σⱼ₌₁ˡ αᵢ αⱼ yᵢ yⱼ xᵢᵀ xⱼ + Σᵢ₌₁ˡ αᵢ.

As a result, the corresponding dual problem is as follows:

max_{α,β} −½ Σᵢ₌₁ˡ Σⱼ₌₁ˡ αᵢ αⱼ yᵢ yⱼ xᵢᵀ xⱼ + Σᵢ₌₁ˡ αᵢ, s.t. Σᵢ₌₁ˡ yᵢ αᵢ = 0, C − αᵢ − βᵢ = 0, αᵢ ≥ 0, βᵢ ≥ 0, ∀i = 1…l.

Moreover, by $C - \alpha_i = \beta_i \ge 0$, we can remove $\beta_i$ by imposing an additional inequality constraint on $\alpha_i$. The dual problem could be simplified as follows:

$$\min_{\alpha} \frac{1}{2} \boldsymbol{\alpha}^\top Q \boldsymbol{\alpha} - \boldsymbol{e}^\top \boldsymbol{\alpha}, \quad \text{s.t.} \quad 0 = \boldsymbol{y}^\top \boldsymbol{\alpha}, \; 0 \le \boldsymbol{\alpha} \le C\boldsymbol{e}, \; Q_{ij} = y_i y_j \boldsymbol{x}_i^\top \boldsymbol{x}_j. \tag{7.4}$$

Consider the solutions $(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}})$ and $(\bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}})$ for the primal and dual problems, respectively. By the minimax theorem and the definition of $P$ and $D$, we have the following:

$$L(\boldsymbol{w}, \bar{b}, \bar{\boldsymbol{\xi}}, \bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}}) \le \overbrace{\max_{\boldsymbol{\alpha}, \boldsymbol{\beta}} L(\boldsymbol{w}, \bar{b}, \bar{\boldsymbol{\xi}}, \boldsymbol{\alpha}, \boldsymbol{\beta})}^{P(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}})} = \overbrace{\min_{\boldsymbol{w}, b, \boldsymbol{\xi}} L(\boldsymbol{w}, b, \boldsymbol{\xi}, \bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}})}^{D(\bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}})} \le L(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}}, \bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}}).$$

That is, $P(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}}) = D(\bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}}) = L(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}}, \bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}})$. As a result, (7.3) should also hold for $(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}}, \bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}})$.

$$\bar{\boldsymbol{w}} - \sum_{i=1}^{l} \bar{\alpha}_i y_i \boldsymbol{x}_i = \boldsymbol{0}, \quad \sum_{i=1}^{l} y_i \bar{\alpha}_i = 0, \quad C\boldsymbol{e} - \bar{\boldsymbol{\alpha}} + \bar{\boldsymbol{\beta}} = \boldsymbol{0}. \tag{7.5}$$

Further, by $P(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}}) = L(\bar{\boldsymbol{w}}, \bar{b}, \bar{\boldsymbol{\xi}}, \bar{\boldsymbol{\alpha}}, \bar{\boldsymbol{\beta}})$,
$$0 = \sum_{i=1}^{l} \bar{\alpha}_i (y_i (\bar{\boldsymbol{w}}^\top \boldsymbol{x}_i + \bar{b}) - 1 + \bar{\xi}_i) + \sum_{i=1}^{l} \bar{\beta}_i \bar{\xi}_i.$$

With the feasibility constraints on solutions,
$$0 \le \bar{\alpha}_i, \quad 0 \le \bar{\beta}_i, \quad 0 \le \bar{\xi}_i, \quad y_i (\bar{\boldsymbol{w}}^\top \boldsymbol{x}_i + \bar{b}) \ge 1 - \bar{\xi}_i, \quad \forall i = 1 \dots l, \tag{7.6}$$

we have
$$\bar{\alpha}_i (y_i (\bar{\boldsymbol{w}}^\top \boldsymbol{x}_i + \bar{b}) - 1 + \bar{\xi}_i) = 0, \quad \bar{\beta}_i \bar{\xi}_i = 0, \quad \forall i = 1 \dots l. \tag{7.7}$$

The conditions (7.5), (7.6), and (7.7) are referred to as the Karush-Kuhn-Tucker (KKT) optimality conditions [4]. We have shown that the optimal solution should satisfy the KKT conditions. In fact, for a convex optimization problem with linear constraints, the KKT conditions are both necessary and sufficient for optimality.

Further, the KKT conditions link the primal and dual solutions. We have $\bar{\boldsymbol{w}} = \sum_{i=1}^{l} \bar{\alpha}_i y_i \boldsymbol{x}_i$ from (7.5), and $\bar{b}$ could be inferred from (7.7). Once $(\bar{\boldsymbol{\alpha}}, \bar{b})$ has been calculated, we could evaluate the decision value as follows:
$$h(\boldsymbol{x}) = \bar{\boldsymbol{w}}^\top \boldsymbol{x} + \bar{b} = \sum_{i=1}^{l} \bar{\alpha}_i y_i \boldsymbol{x}_i^\top \boldsymbol{x} + \bar{b}. \tag{7.8}$$

One can observe that only non-zero $\bar{\alpha}_i$'s affect the decision value. We call instances with non-zero $\bar{\alpha}_i$ as the support vectors. Further, from the KKT condition,
$$y_i (\bar{\boldsymbol{w}}^\top \boldsymbol{x}_i + \bar{b}) \begin{cases} < 1 \implies \bar{\alpha}_i = C, \\ > 1 \implies \bar{\alpha}_i = 0, \\ = 1 \implies 0 \le \bar{\alpha}_i \le C. \end{cases}$$

The result shows that all the misclassified instances have $\bar{\alpha}_i = C$, and all correctly classified instances off the margin have $\bar{\alpha}_i = 0$. Under the separable scenario, only a few instances are mis-classified or fall within the margin, while all other $\bar{\alpha}_i$ are zero. This means that the set of support vectors should be sparse.

## 7.5 Kernel Tricks

A linear model may not always be appropriate for every kind of data. For example, consider the scenario in Figure 7.5(a). For any linear model, one can obtain only about 50% accuracy. This is not satisfactory, because it is only as good as random guesses. However, if we apply a feature transformation $\phi(\mathbf{x})$ to all the data by the following:

$$\phi(\mathbf{x}) = [x_1x_1\quad x_2x_2]^{\mathsf T}.$$

In this case, the data set becomes linearly separable in the mapped space, as in Figure 7.5(b). In general, when the decision surface is decided by a smooth function $h(\mathbf{x})$, it could be expressed and approximated by Taylor expansions. For example, the second-order Taylor expansion of $h(\mathbf{x})$ is as follows:

$$h(\mathbf{x}) \approx w_1 + [w_2\quad w_3]\begin{bmatrix}x_1\\x_2\end{bmatrix} + \frac{1}{2}[x_1\quad x_2]\begin{bmatrix}w_4&w_5\\w_5&w_6\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix}.$$ (7.9)

It should be pointed out that although $h(\mathbf{x})$ is nonlinear in $\mathbf{x}$, it is linear in $\mathbf{w}$. Consequently, it could be rewritten as $h(\mathbf{x})=\mathbf{w}^{\mathsf T}\phi(\mathbf{x})$, in which

$$\phi(\mathbf{x}) = [1\quad x_1\quad x_2\quad \frac{1}{2}x_1x_1\quad x_1x_2\quad \frac{1}{2}x_2x_2]^{\mathsf T}.$$ (7.10)

The primal problem with transformed instances is quite similar to the original one, as the change is to replace $x_i$ with $\phi(x_i)$.

$$\min_{\mathbf{w},b,\boldsymbol{\xi}} \frac{1}{2}\mathbf{w}^{\mathsf T}\mathbf{w}+C\sum_{i=1}^{l}\xi_i,\quad \text{s.t.}\quad y_i(\mathbf{w}^{\mathsf T}\phi(\mathbf{x}_i)+b)\ge 1-\xi_i,\ \xi_i\ge 0,\ \forall i=1\ldots l.$$

However, the transformation has a serious problem. It is known that the $d$th-order Taylor expansion for an $n$-dimensional input has $\frac{(d+n)!}{d!n!}$ coefficients, because of all the combinations of coordinates of $\mathbf{x}$ less than or equal to order $d$. Thus, when the dimensionality of features and the degree of the Taylor expansion grow, the dimension of $\mathbf{w}$, which is identical to the number of coefficients in the Taylor expansion, may become very large. By replacing each $x_i$ in (7.4) with the mapped vector $\phi(x_i)$, the dual formulation with transformed instances is as follows:

$$\min_{\boldsymbol{\alpha}} \frac{1}{2}\boldsymbol{\alpha}^{\mathsf T}Q\boldsymbol{\alpha}-\mathbf{e}^{\mathsf T}\boldsymbol{\alpha},\quad \text{s.t.}\quad 0=\mathbf{y}^{\mathsf T}\boldsymbol{\alpha},\ 0\le\boldsymbol{\alpha}\le C\mathbf{e},\ Q_{ij}=y_i y_j\phi(\mathbf{x}_i)^{\mathsf T}\phi(\mathbf{x}_j).$$
