# 20.1 Introduction

Consider an input space \(\mathcal{X}\) and an output space \(\mathcal{Y}\), where one would like to see an example from input space \(\mathcal{X}\) and automatically predict its output. In traditional supervised learning, a learning algorithm is typically given a training set of the form \(\{(x_i,y_i)\}_{i=1}^{l}\), where each pair \((x_i,y_i)\in\mathcal{X}\times\mathcal{Y}\) is drawn independently at random according to an unknown joint probability distribution \(P_{\mathcal{X}\times\mathcal{Y}}\).
