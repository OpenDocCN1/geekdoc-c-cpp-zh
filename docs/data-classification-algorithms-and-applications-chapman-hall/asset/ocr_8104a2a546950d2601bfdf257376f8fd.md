Suppose the projection matrix we want to get is **W**^φ in the feature space, then with the representer theorem

$$\mathbf{W}^{\phi}=\Phi\alpha$$  (18.10)

where $\Phi=[\phi(\mathbf{x}_1),\phi(\mathbf{x}_2),\cdots,\phi(\mathbf{x}_n)]$ and $\alpha$ is the coefficient vector over all $\phi(\mathbf{x}_i)$ for $1\leq i\leq n$. We define $\mathbf{K}=\Phi^\mathrm{T}\Phi$ as the kernel matrix.

Then

$$(\mathbf{W}^{\phi})^\mathrm{T}\Sigma_C^{\phi}\mathbf{W}^{\phi}=\alpha^\mathrm{T}\left[\frac{1}{C}\sum_{c=1}^{C}\frac{1}{n_c}\sum_{\mathbf{x}_i\in c}\Phi^\mathrm{T}(\phi(\mathbf{x}_i)-\bar{\phi}_c)(\phi(\mathbf{x}_i)-\bar{\phi}_c)^\mathrm{T}\Phi\right]\alpha$$

$$=\alpha^\mathrm{T}\left[\frac{1}{C}\sum_{c=1}^{C}\frac{1}{n_c}\sum_{\mathbf{x}_i\in c}(\mathbf{K}_{\cdot i}-\bar{\mathbf{K}}_{\cdot c})(\mathbf{K}_{\cdot i}-\bar{\mathbf{K}}_{\cdot c})^\mathrm{T}\right]\alpha$$

$$=\alpha^\mathrm{T}\mathbf{M}_C\alpha$$  (18.11)

where $\mathbf{K}_{\cdot i}=\ $ and $\bar{\mathbf{K}}_{\cdot c}=\frac{1}{n_c}\sum_{\mathbf{x}_i\in c}\mathbf{K}_{\cdot i}$.

$$(\mathbf{W}^{\phi})^\mathrm{T}\Sigma_S^{\phi}\mathbf{W}^{\phi}=\alpha^\mathrm{T}\left[\frac{1}{C}\sum_c(\bar{\mathbf{K}}_{\cdot c}-\bar{\mathbf{K}}_{\cdot *})(\bar{\mathbf{K}}_{\cdot c}-\bar{\mathbf{K}}_{\cdot *})^\mathrm{T}\right]\alpha$$

$$=\alpha^\mathrm{T}\mathbf{M}_S\alpha$$  (18.12)

where $\mathbf{K}_{\cdot *}=\frac{1}{n}\sum_{i=1}^{n}\mathbf{K}_{\cdot i}$. Therefore we can get $\alpha$ by solving

$$\min_{\alpha^\mathrm{T}\alpha=1}\frac{\operatorname{tr}(\alpha^\mathrm{T}\mathbf{M}_C\alpha)}{\operatorname{tr}(\alpha^\mathrm{T}\mathbf{M}_S\alpha)}.$$  (18.13)

# ### 18.3.2 Margin Maximizing Discriminant Analysis (MMDA)

MMDA can be viewed as an extension of the *Support Vector Machine* (SVM) algorithm [21]. Supposing data points $\mathbf{X}=[\mathbf{x}_1,\mathbf{x}_2,\cdots,\mathbf{x}_n]$ come from two classes, the label of $\mathbf{x}_i$ is $l_i\in\{-1,+1\}$. As a recap, the goal of SVM is to find the maximum-margin hyperplane that divides the points with $l_i=1$ from those with $l_i=-1$ (thus it is a supervised method). Any hyperplane can be written as a point $\mathbf{x}$ satisfying

$$\mathbf{w}^{\mathrm{T}}\mathbf{x}-b=0$$  (18.14)

where $b/\|\mathbf{w}\|$ corresponds to the distance of the hyperplane from the origin. SVM aims to choose the $\mathbf{w}$ and $b$ to maximize the distance between the parallel hyperplanes that are as far apart as possible while still separating the data, which is usually referred to as the margin of the two classes. These hyperplanes can be described by the equations

$$\mathbf{w}^{\mathrm{T}}\mathbf{x}-b=1\quad\text{or}\quad\mathbf{w}^{\mathrm{T}}\mathbf{x}-b=-1.$$  (18.15)

The distance between the two parallel hyperplanes is $2/\|\mathbf{w}\|$. Then if the data from two classes are clearly separated, the goal of SVM is to solve the following optimization problem to find the hyperplane that maximizes the margin between two classes

$$\min_{\mathbf{w},b}\quad \frac{1}{2}\|\mathbf{w}\|^2$$

$$s.t.\quad l_i(\mathbf{w}^{\mathrm{T}}\mathbf{x}_i-b)\geq 1\quad(\forall i=1,2,\cdots,n).$$  (18.16)
