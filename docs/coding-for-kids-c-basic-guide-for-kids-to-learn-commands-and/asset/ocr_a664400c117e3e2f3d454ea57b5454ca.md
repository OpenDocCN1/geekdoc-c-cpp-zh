# Definition of a Function

A function definition contains everything that a function declaration does, plus the body of the function, which is surrounded in braces ().

Furthermore, it should contain named parameters. When a function is called, the program's control is passed to the function definition, executing the function code. When the function's execution is complete, control returns to the place where the function was called.

The following is the definition of the swap function for the above declaration:

```
void swap(int a, int b){
    b = a + b;
    a = b - a;
    b = b - a;
}
```

It is worth noting that a function's declaration and definition can occur at the same time. There is no need for a separate declaration if we declare a function before referencing it.

We can see that there is a function swap in the preceding example that takes two int parameters and returns nothing. It has a void return type. We have not declared this function individually because it was defined before main as a calling function.

We read two integers in the primary function and then call the swap function by giving them two integers. The two integers are switched using conventional logic in the swap function, and the swapped values are reported.
