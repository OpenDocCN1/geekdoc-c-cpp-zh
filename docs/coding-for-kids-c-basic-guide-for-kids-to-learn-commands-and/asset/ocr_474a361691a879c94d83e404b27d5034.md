# ## 7.1 C++ Function

In C++, a function is a collection of statements that receives input, processes it, and returns a result. The purpose of a function is to consolidate common tasks that are performed regularly. You will not write the same code twice if the inputs are different. Simply put, you will call the function with a different set of parameters.

The main() function is one of the functions found in every C++ application. Your code can be divided into distinct functions. Every function should perform a specific task as a result of this division.

The C++ standard library includes a large number of built-in functions. These functions can be called within your program.

# ### What Does It Mean to Define a Function?

A function is a collection of statements that work together to accomplish a specific goal. It could be phrases that conduct routine operations or statements that perform specialized jobs like printing.

Functions can be used to simplify code by splitting it down into smaller components called functions. Another advantage of using functions is that it saves us from writing the same code again and over and over. We only need to write one function and then call it as needed, rather than writing the same set of lines over and over.

# ### Calling a Function

When we have a function in our software, we need to call or invoke it based on the requirement. The function will only execute its set of statements to give the required results when it is called or invoked.

It is possible to call the function from anywhere in the program. If the software uses more than one function, it can be called from the primary function or any other function. The "Calling Function" is the function that calls another function.
