# **Local Variables**

Local variables are the variables that are declared within a function or block. They can only be utilized by statements that are included within that function or code block. Functions outside of their own are unaware of local variables. The following is an example of how to use local variables.

```
```cpp
#include <iostream>
using namespace std;

int main () {
    // Local variable declaration:
    int a, b;
    int c;

    // actual initialization
    a = 10;
    b = 20;
    c = a + b;

    cout << c;

    return 0;
}
```
