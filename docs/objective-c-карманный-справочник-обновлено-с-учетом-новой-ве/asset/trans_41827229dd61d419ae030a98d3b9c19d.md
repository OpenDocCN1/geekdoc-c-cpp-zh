

## 关于作者

David Chisnall 是一位自由撰稿兼顾问。在攻读博士期间，他共同创立了 Étoile 项目，该项目旨在基于 GNUstep 制作一个开源桌面环境，而 GNUstep 是 OpenStep 和 Cocoa API 的开源实现。他是 GNUstep 的活跃贡献者，也是 GNUstep Objective-C 2 运行时库以及 Clang 编译器中相关编译器支持的原始作者和维护者。在完成博士学位后，David 曾在学术界“隐居”了一段时间，研究编程语言的历史。当他意识到校园外也有同样优美的海景，且不需要完成如此大量的文书工作时，他终于逃离了那里。他偶尔会回来参与涉及动态语言语义建模的项目协作。

David 对 Objective-C 非常熟悉，他不仅参与过使用该语言的项目，还参与过该语言本身的实现。他还曾致力于过其他语言，包括 Smalltalk 的方言和 JavaScript，这些语言都运行在 Objective-C 运行时之上，允许在无需桥接的情况下混合使用这些语言的代码。

在不写作或不编程时，David 喜欢跳阿根廷探戈和古巴萨尔舞、打羽毛球和终极飞盘，以及烹饪。

## 引言

布莱·帕斯卡（Blaise Pascal）曾写道：“我没有时间写一封短信，所以我写了一封长信。”这本短语集是我写过的最短的书，试图将我想说的一切都塞进这本短小的卷册中是一项挑战。

当 Mark Taber 最初建议我写一本 Objective-C 短语集时，我不确定它会是什么样子的。自然语言的短语集是一系列简短习语列表，供那些发现自己急需一两句话的人使用。编程语言的短语集应该承担类似的角色。

这本书并不是语言参考书。Apple 在 http://developer.apple.com 网站提供了 Objective-C 语言的一份胜任的参考。这不是一个详尽的教程；与我的另一本 Objective-C 书《Cocoa 编程开发手册》（Cocoa Programming Developer’s Handbook）不同，你找不到完整的程序代码示例。相反，你会发现非常短的 Objective-C 习语示例，希望你可以在很多地方使用它们。

生活中最令人沮丧的事情之一是发现书中的代码示例实际上无法运行。书中有两类代码列表。白色背景上的代码旨在说明一个简单的观点。这些代码可能取决于某些隐含的教程上下文，不应被视为可运行、可用的示例。

你在书中发现的大部分代码都在灰色背景上。在每个示例的底部，你会找到该列表取自的文件名。你可以从 InformIT 网站上的书籍页面下载这些内容：http://www.informit.com/title/0321743628

当我写这本书的第一版时，我在 OS X 上编写并测试了所有的示例。在将草稿发送去编辑后，我在 GNUstep 上对它们进行了测试，并惊喜地发现几乎所有的示例都能正常运行。到书籍出版时，它们都运行良好。第二版涵盖了许多 Apple 仅在 OS X 10.7 或 iOS 5 上支持的功能。和以前一样，我在 OS X 上编写了所有示例，除了在 GNUstep 上进行测试外，没有对其做任何妥协。

### 关于排版的说明

这本书使用 Vim 编写，并使用了语义标记。通过 pdflatex 生成了三个不同的版本。如果你阅读的是打印版或 PDF 版本，就可以看到其中之一。两者唯一的区别在于打印版包含了裁剪标记。

第三个版本是 XHTML，用于电子版。它是通过 EileText 框架生成的，该框架首先将 LaTeX 风格的标记解析为树结构，然后进行处理交叉引用和索引的转换，最后生成 XHTML。实现此功能的代码全部用 Objective-C 编写。

如果你能接触两个版本，可能会注意到电子版的代码列表看起来更好。这是因为 EileText 使用了另一个 Apple 框架 SourceKit 进行语法高亮。这使用了 Clang（一种现代 Objective-C 编译器）对代码列表进行标记。这意味着代码的范围被标记了编译器看到的相同语义类型。例如，它可以区分函数调用和宏实例化。

你可以在 Étoilé 子版本仓库中找到实现此功能的所有代码：http://svn.gna.org/viewcvs/etoile/trunk/

## Objective-C 哲学

要理解 Objective-C，你需要理解其创建背后的哲学。与 C++、D 或 Java 等被设计为新的 C 类语言不同，Objective-C 是一种混合语言。它是 C 语言的纯超集，意味着有效的 C 程序也是有效的 Objective-C 程序，但它也允许一些类似 Smalltalk 的语法和语义。

Objective-C 的设计者之一 Tom Love 将方括号语法描述为路路标，提醒你正在离开 C 语言进入“对象世界”。
