Both NSArray and NSSet implement the -containsObject: method, which returns YES if the collection contains an object that is equal to the argument. This uses the same notion of equality we\u29ve already covered in relation to collection classes: Two objects are equal if sending one an -isEqual: message with the other as the argument returns YES.
In an array, you probably want to know exactly where the object is, rather than simply whether it is present. There are two methods for telling you this: -indexOfObject: and -indexOfObjectIdenticalTo:. The second of these uses pointer comparison to determine equality.
