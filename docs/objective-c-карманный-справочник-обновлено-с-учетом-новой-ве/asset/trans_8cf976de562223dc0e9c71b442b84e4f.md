

## 用于显示的日期转换

如果你的用户所在的地区是一个在该日期之后才采用格里哥利历的国家，会发生什么呢？

一个具体的例子是俄罗斯的十月革命，它发生在1917年11月7日。如果你向俄罗斯用户用户展示这个日期，它将是不正确的，因为那时俄罗斯仍使用儒略历，这就是为什么他们将发生在 11 月的事件称为“十月革命”。

其他地区可能根本不使用格里哥利历。大多数拥有电脑的人可能对格里哥利历有所了解，但强制你的用户自己进行转换并不是一个好主意。

**注意：** NSCalendar 是旧的 OpenStep 表示显示日期的方法。该类现在已废弃。与 NSDate 不同，NSCalendar 在格里哥利历格式中存储日期。

在转换用于用于显示的日期时，你可能需要使用两个类之一。如果你需要获取特定日历中日期的各个组件，则需要使用 `NSCalendar` 类。如果你想生成一个字符串值，应该使用 `NSDateFormatter`。

`NSCalendar` 类封装了一个日历，以及一种在绝对时间与包含编号年份、月份等的分段时间段之间映射的方法。你使用该类从 `NSDate` 创建 `DateComponents` 对象。`DateComponents` 对象封装了相对于特定日历的日期组件。

`DateComponents` 对象不存储它所所属的日历，而且没有定义的方法来比较两个 `DateComponents` 对象。这是刻意为之。如果你在比较日期，应该使用 `NSDate` 对象比较绝对时间，仅在显示时对其进行本地化。这是相对于 `NSCalendarDate` 的重大变化，后者曾是 `NSDate` 的子类，并定义了比较方法。

如果你有一个 `DateComponents` 对象，随后可以使用 `NSString` 的 `+stringWithFormat:` 构建一个用于显示的日期。这是一个坏主意。如果你生成了诸如 1/2/2012 这样的日期，使用中端序（middle-endian）格式日期的美国人将其解释为1 月 2 日，而使用小端序（little-endian）日期的世界其他地区将其读取为 2 月 1 日。

`DateFormatter` 类为你解决了这个问题。它有一个方便的类方法 `+localizedStringFromDate:dateStyle:timeStyle:`，返回一个包含本地化日期和时间的字符串。第二个和第三个参数分别描述了日期时间和组件所需的详细程度。其范围可以从不显示任何内容到极短的数字描述，再到写出完整月份和日期名称的长描述。

## 计算已时间

```c
NSDate *start = [NSDate date];
sleep(1);
NSTimeInterval elapsed = 0 - [start timeIntervalSinceNow];
```
源自：elapsed.m

你可以通过发送 `-timeIntervalSinceDate` 作为参数来找到两个日期对象之间的差异。或者，为了找到某个日期是多久之前的，你可以向它发送一个 `-timeIntervalSinceNow` 消息。如果日期在过去，这将给出一个负数，因此，要找出自通过 `+date` 或 `+new` 创建日期以来已经过了多少时间，你应该从零中减去这个值。

这不是计算已时间的最快方法。`gettimeofday()` 系统调用会在结构体内返回系统时间。这避免了创建对象和发送消息的开销，但工作量大一些，因为你需要自己处理该结构体。该结构在不同的字段中存储秒和微秒，因此减法操作比仅比较两个标量值要费力。

## 从字符串解析日期

```objc
NSDate *isoDate = [NSDate dateWithString:@"1982-06-15 06:10:00 +0000"];
NSLocale *gb = [[NSLocale alloc] initWithLocaleIdentifier:@"en_GB"];
NSDateFormatter *formatter = [NSDateFormatter new];
[formatter setLocale:gb];
[formatter setDateStyle:NSDateFormatterShortStyle];
[formatter timeStyle:NSDateFormatterNoStyle];
NSDate *britishDate = [formatter dateFormat:@"15/06/1982"];
```
源自：stringdate.m

`Date` 类有一个构造函数，可以从 ISO 8601 格式的字符串构建日期。当你在你解析用于交换的文件时非常有用，但在处理用户提供的数据时并不十分有用。

如果你想从本地化字符串创建日期，你需要回到 `NSDateFormatter` 类。该类封装了一些日期格式的描述，并可以在日期对象和字符串对象之间进行双向转换。

当你创建一个日期格式化器时，可以将区域设置为显式区域，或者将其设置为用户当前的区域。然后你可以使用该区域的标准时间和和日期格式之一，或者通过 `-setDateFormat:` 方法显式指定。该方法接受一个模板字符串作为参数，但在大多数代码中都不建议使用它，因为它没有考虑到区域设置。

读取日期你还有最后一种选择。如果你想从某些自定义格式读取日期，可以使用 `NSScanner` 从字符串中读取组件，然后构建一个 `DateComponents` 对象并将其传递给 `NSCalendar` 来创建日期。`NSScanner` 在第 5 章介绍。

## 接收定时器事件

```objc
(void)periodic:(NSTimer*)theTimer {
    NSLog("Timer fired");
}
(void)start {
    SEL sel = @selector(periodic:);
    [NSTimer scheduledTimerWithTimeInterval:1
                               target:self
                               selector:sel
                               userInfo:nil
                               repeats:YES];
    [[NSRunLoop currentRunLoop] run];
}
```
源自：timer.m

`NSTimer` 类封装了一个在特定时间产生事件的事件源。这在原理上与 `alarm()` 系统调用相似，尽管你可以同时拥有多个定时器。

你几乎总是使用本节开头的方法来构建定时器。定义此消息最简单的方法是在创建定时器时传递选择器（selector）、目标（target）和一个字典。选择器必须是一个接收一个参数的方法：一个 `NSTimer` 实例。你可以通过向定时器发送 `-userInfo` 消息来获取字典。

当时间间隔过去，定时器将触发。它随后会向一个对象发送消息。当你像这样创建定时器时，它会被自动释放，但它会被运行循环（run loop）对象保留。你只有在使用 `NSRunLoop` 时才能使用定时器。运行循环等待事件——例如定时器或文件描述符上的数据变得可用——然后响应这些事件发送消息。

如果你在使用 AppKit 或 UIKit，你将自动使用运行循环。`NSApplication` 和 `UIApplication` 类都会在内部创建一个运行循环。这些类在运行循环中注册，以接收来自显示服务器的用户界面事件通知，然后将它们传递给窗口等。

如果你正在编写命令行应用程序或服务器，你仍然可以使用 `NSRunLoop`。它是 Foundation 框架的一部分，但你必须手动创建它并告诉它运行。这非常简单，在上一个示例的 `-start` 方法的最后一行完成。

## 使用属性列表（Property Lists）
