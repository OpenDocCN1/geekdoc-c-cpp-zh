You have one final option for reading dates. If you want to read dates from some custom format, you can use NSScanner to read the components from the string, then construct an DateComponents object and pass this to NSCalendar to create the date. NSScanner is covered in Chapter 5.

# Receiving Timer Events

```
(void)periodic:(NSTimer*)theTimer {
    NSLog("Timer fired");
}
(void)start {
    SEL sel = @selector(periodic:);
    [NSTimer scheduledTimerWithTimeInterval:1
        target: self
        selector: sel
        userInfo: nil
        repeats:YES];
    [[NSRunLoop currentRunLoop] run];
}
```
