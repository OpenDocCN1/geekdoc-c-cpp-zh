It’s also important to remember to call the implementation of both of these superclass methods if, and only if, the superclass conforms to the NSCoding protocol. If it doesn’t, but does have some state that you wish to persist, you are responsible for archiving this as well as your subclass’s instance variables.

# Creating Designated Initializers

```
(id)initWithName:(NSString*)aSel arguments:(NSArray*)args {
    if (nil == (self = [super init])) {
        return nil;
    }
    selector = [aSel copy];
    arguments = [args mutableCopy];
    return self;
}
(id)initWithName:(NSString*)aSel {
    return [self initWithName:aSel arguments:nil];
}
(id)init {
    return [self initWithName:nil];
}
```
