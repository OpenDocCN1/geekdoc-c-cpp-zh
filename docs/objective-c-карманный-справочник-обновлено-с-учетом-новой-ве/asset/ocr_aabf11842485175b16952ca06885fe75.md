Arrays are indexed by integers. Often, you want to do some operation on a group of values in an array. A special class, called NSSet, is used for storing groups of indexes. Internally, this stores a set of ranges, so can be quite dense. A very common use for index sets is to collect a group of indexes while enumerating an array and then remove them at the end. Removing objects from a collection while enumerating it is a bad idea, and will throw an exception in most cases. If you add each index that you want to remove to an index set, you can remove them all at once when you finish the enumeration.
