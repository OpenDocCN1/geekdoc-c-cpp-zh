

## 第 6 章：操作字符串

### 在字符串中匹配模式

```objc
NSRegularExpression *regex = [NSRegularExpression expressionWithPattern:@"abcd"
options: 0
error:NULL];
MutableString *str = [@"abcddd fish, wobble abcd, abc, foo" mutableCopy];
NRange all = NSMakeRange(0, [str length]);
[regex enumerateMatchesInString:str
options: 0
range: all
usingBlock:^(NSTextCheckingResult *result, NSMatchingFlags flags, BOOL *stop)
{
    NSLog("Matched range: %@", NSStringFromRange([result range]));
}];
NSLog("Copy with replacement: %@",
[regex stringByReplacingMatchesInString:str
options: 0
range: all
withTemplate:@"foo"]);
```
源自：regex.m

使用过 Perl 或 JavaScript 等语言，那么你可能已经习惯了使用正则表达式进行字符串模式匹配。Foundation 框架的最新版本包含了 `NSRegularExpression` 类，它是对 Unicode国际组件（ICU）正则表达式代码的薄封装封装。

## 存储富文本

```objc
NSDictionary *keyword = [[NSDictionary dictionaryWithObject:@"keyword" forKey:@"type"] retain];
NSMutableAttributedString *program = [NSMutableAttributedString new];

NSAttributedString *fragment = [[NSAttributedString alloc]
initWithString:@"int"
attributes:keyword];
[program appendAttributedString:fragment];
```
源自：richText.m

字符串仅仅是字符列表。在显示字符串之前，你通常需要一些属性。这些属性描述了字体、大小、对齐方式和下划线样式等。

如果你正在编写处理结构化文本的内容——例如 HTML 或另一种形式的语义标记（如 DocBook），那么这些属性可能是 1 级标题或有序列表。

Foundation 提供了一个类，用于为字符串分配任意属性。`NSAttributedString` 类允许你附加属性。需要注意的是，`NSAttributedString` 是通用的。你可以使用它将任何想要定义的属性附加到字符串的特定范围上。

## 操作集合

与我们看过的其他内容一样，Objective-C 中有两种集合：面向对象的版本和原始 C 类型。前者一如既往地是构建在后者之上的。

在 C 语言中，有两种复合数据类型：数组和结构体。数组只是包含相同类型数据的内存块。结构体具有固定的布局，并可能包含不同类型的元素。

C 复合类型是指针运算上层非常薄的语法糖。当你访问数组中的元素时，编译器会将数组索引乘以单个元素的大小，并将结果加到数组的起始指针上。当你访问结构体中的元素时，编译器会向结构体的起始指针添加一个固定偏移量。

## 第 7 章：操作集合

Objective-C 集合是更高级的构造。每个 Objective-C 集合与 Objective-C 添加的大多数其他功能一样，都是对象。你通过向它们发送消息来与其通信。

Foundation 框架包含了许多集合类，用于存储有序和无序数据，以及映射或索引集。Objective-C 中的大多数集合类都存储对象。与 C++ STL 集合（需要根据其可能包含的类型进行细化）不同，Objective-C 集合是异质的。它们可以存储任何类型的 Objective-C 对象。

大多数 Objective-C 集合（如字符串）使用*可变子类模式*，即基类实现不可变集合的行为，而子类提供一个可变版本。

所有遵循此模式的类都实现了 `NSMutableCopying` 协议，这意味着你可以向集合发送 `-mutableCopy` 消息并获得一个可变的副本，即使原始对象不可变。

大多数集合也是*类簇（clusters）*。当你创建一个集合时，你将得到一些私有的抽象子类。公共类通常是抽象的。用户友型方法都是基于少数几个原始方法实现的。如果你创建自己的子类，将需要自己实现这些方法。

### 使用数组

```objc
NSArray *array = [NSArray arrayWithObjects:
"array", @containing, "string", @objects,
nil];
MutableArray *mutable = [array mutableCopy];
[mutable sorting:@selector(localizedCompare:)];
[mutable addObject:[NSNumber initWithInteger:12]];
[mutable removeAllObjects];
```
源自：nsarray.m

除了 C 数组外，Foundation 还提供了 `NSArray` 类及其可变子类 `NSMutableArray`。它们实现了一种抽象数据类型，将从 0 开始的连续范围内的整数映射到对象。在内部，它可能由 C 数组、跳表列表或其他数据结构实现，取决于它是如何创建的。

例如，如果你通过追加两个不可变数组来创建一个数组，你可能会得到一个内部不存储任何内容的复合数组，它只是访问另外两个数组。或者你可能会得到一个全新的数组，取决于实现相关 `NSArray` 子类的开发者认为在该特定情况下哪种更高效。

创建 Objective-C 数组简单的方法是使用 `+arrayWithObjects:` 方法，`NSArray` 和 `NSMutableArray` 都实现了该方法。这是另一个可变方法的示例，它接受对象列表作为参数，并使用 `nil` 表示列表的结束。当你使用变量作为此方法的参数时，必须确保没有变量是 `nil`，否则数组将将其视为列表的结束并忽略后面的值。

**注意：** 大多数 Objective-C 集合不允许你将 `nil` 作为值存储。如果你需要表示空值而不是值的缺失，可以使用 `NSNull` 类。它提供了一个可以通过 `[NSNull null]` 访问的单例对象。

数组是类簇。`NSArray` 中的两个原始方法是 `-objectAtIndex` 和 `-count`。所有其他方法都是基于这两个方法实现的。当然，某些具体的子类会实现更高效的版本，但如果你想创建一个新的 `NSArray` 子类，你必须实现这两个方法，以便基类的其他方法能够正常工作。

子类 `NSMutableArray` 稍微困难一点；它增加了另外六个原始方法。但在大多数情况下，你会使用数组而不是对其进行子类化。你可以通过两种方式向可变数组插入对象：`-addObject:` 将其添加到末尾，或者 `-insertObject:atIndex:` 将其插入到
