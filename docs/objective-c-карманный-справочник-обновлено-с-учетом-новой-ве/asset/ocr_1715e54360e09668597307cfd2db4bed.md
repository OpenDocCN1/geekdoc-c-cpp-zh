# Converting Property List Formats

```
NSString *file =
[NSNSString stringWithUTF8String:argv[1]];
NSData *data = [NSData dataWithContentsOfFile:file];
PropertyListFormat fmt;
id plist = [NSPropertyListSerialization propertyWithData:data
options: 0
format: &fmt
error: NULL];
if (fmt == NSPropertyListListBinaryFormat_v1_0) {
return 0;
}
data = [NSSerialization dataWithPropertyList:plist
format: NSPropertyListListBinaryFormat_v1
options: 0
error: NULL];
[data writeToFile:file atomically:NO];
```

From: makebinaryplist.m

On OS X, you cannot write property lists in the OpenStep format, but you can still use the two other forms. In general, you should use the binary format for storing private data and the XML format for anything that the user might want to edit with other tools.
