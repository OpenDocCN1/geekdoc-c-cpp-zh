The migration tool will try to insert __bridge
casts where required, but these are worth
checking. These casts are used to move objects in
out of ARC-managed code. In non-
ARC Objective-C, you are free to do things like
(void*)someObject, because object pointers are
just C pointers that can send messages to.
In ARC mode, this cast doesn't know what the
ownership semantics of void* are supposed to
be, so it is rejected.

The migration tool will rewrite this as
(__bridge void*)someObject, but that may
not be what you want. We'll look at these casts
in more detail in the “Interoperating with C"
section.
