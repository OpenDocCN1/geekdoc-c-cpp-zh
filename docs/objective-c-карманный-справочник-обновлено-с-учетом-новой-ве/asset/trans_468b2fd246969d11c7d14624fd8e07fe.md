**注意：** 在 C++ 中，通常使用 `const` 关键字来描述对象为不可变。在 Objective-C 中，**const** 实际上是毫无用处的。它规定了对象的实例变量可能被直接修改，但这种情况很少发生。它不会改变可以发送给对象的消息，因此声明为 **const** 的对象仍然是可变的。
在大多数需要区分可变和不可变实例的情况下，Objective-C 程序员使用*可变子类模式*（*mutable subclass pattern*），即一个不可变类有一个可变的子类。你可以隐式地将可变版本转换为不可变版本，但你不能将一个不可变实例变为可变。

Objective-C 为 C 语言带来的的最重要的改进是发送消息。正如我在上一章中提到的，消息是一种高层流控制结构。

这是 Objective-C 中往往让那些来自 C++ 和 Java 等语言的人士感到畏畏的部分，因为它的语法直接取自 Smalltalk，对于更熟悉 C 语法的人来说看起来非常陌生。这是刻意为之。C 语言中没有任何东西的行为与 Objective-C 消息发送相同，因此引入新语法突出了你同时也拥有了新语义的事实。记住 Tom Love 曾将其描述为一种混合语言，在纯 C 部分和“对象世界”之间有清晰的语法分离，后者具有类 Smalltalk 的语法，用以伴随类 Smalltalk 的语义。

最简单的消息发送不接受任何参数。这方面的一个例子可能是发送给数组的 `-count` 消息。注意消息名称前的减号。这是 Objective-C 文档中使用的惯例，用于表示发送给实例的消息。加号用于表示发送给类的消息，例如 `+new` 或 `+arrayWithObject:`。

```
size = [anArray count];
```

这段代码段获取数组中的元素个数并将其存储在变量 `size` 中。在 C++ 或 Java 等语言中，等效的操作类似于这样：

```
size = anArray.size();
```

如果 `anArray` 是一个 C 结构体且 `size` 字段是一个函数指针，那么 Objective-C 中将使用相同的语法。由于这与向对象发送消息意味着完全不同的，设计者认为使用相同的语法会引起混淆。

接收一个参数的消息看起来非常相似。如果你想向 Objective-C 数组添加一个对象，你会使用类似这样的代码：`[anArray addObject:anObject];`

当消息有多个参数时，情况开始变得有点不同。和小 Smalltalk 一样，每个参数都有独立的名称，因此你可以在特定索引处插入对象：

```
[anArray insertObject:anObject atIndex:anIndex];
```

当你理解了基本语法，这会让 Objective-C 代码非常易读，因为每个消息都会告诉你每个参数的用途。如果你在文档中遇到这个消息，它的写法是这样的：`-insertObject:atIndex:`。你可以从两个冒号看出它接受两个参数，并从两个冒号之前的文本看出这些参数是什么。和之前一样，减号表示这是发送给实例的消息。

如果你向一个没有实现该方法的对象发送消息，那么将会使用若干回退方法。在默认实现中，这些方法中的最后一个将抛出一个异常（你可以在运行时捕获并绕过它）。在发送消息之前，你也可以询问对象是否知道如何处理它。我们将在第 19 章查看如何这样做。

29 理解选择器

Objective-C 的流控制更加动态化。你可以获取方法的指针，但大多数情况下，你希望向对象发送特定的消息，而不是调用一个特定的方法。如果你调用一个特定的方法，你必须绝对确保接收者确实是你所预期的类。
