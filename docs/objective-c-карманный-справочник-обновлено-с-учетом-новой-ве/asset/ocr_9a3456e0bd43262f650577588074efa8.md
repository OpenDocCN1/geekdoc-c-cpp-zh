@interface KeyFallback : KeyPublic

    NSMutableDictionary *dict;
}
@end
@implementation KeyFallback
-(id)valueForUndefinedKey:(NSString*)akey

}

forUndefinedKey:(NSString*)akey
{
    [dict setValue:aValue forKey:akey];

From: kvc.m

The methods are the last chance to support KVC. If you implement them, you should call the superclass implementation for all keys you don't support directly. This will throw an exception if called on the root class, indicating that you don't properly handle the key.

If you use declared properties to synthesize accessor methods, you will get KVC compliance for free. The kvc.m example shows all of the different ways in which you can implement the same KVC property.
