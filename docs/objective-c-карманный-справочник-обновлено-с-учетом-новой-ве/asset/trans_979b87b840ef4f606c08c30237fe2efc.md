## 操作索引

```
NSMutableIndexSet *indexSet =
[NSMutableIndexSet indexSetWithIndex:1];
[indexSet addIndexesInRange:(5, 20)];
[array removeObjectsAtIndex:indexSet];
```

源自：indexset.m

数组通过整数进行索引。通常，你希望对数组中的一组值执行某些操作。一个名为 NSSet 的特殊类用于存储索引组。在内部，它存储的是一组范围集合，因此可能非常密集。索引集的一个非常常见的用途是在枚举数组时收集一组索引，然后在最后将它们删除。在枚举集合时从集合中删除对象是一个坏主意，并且在大多数情况下它会抛出异常。如果你将想要删除的每个索引都添加到索引集中，那么你就可以在完成枚举后一次性地删除它们。

涉及索引集的操作通常比涉及单个索引对应的操作更高效。即使在相对原始的消息发送中也是如此，因为你需要的范围检查更少。你还可以避免一些范围检查。Objective-C 数组上的每个操作都会进行边界检查，以确保它不会引用数组末尾之外索引。使用索引集，接收者只需要比较 -lastIndex 的结果与数组的最后一个索引，然后就可以在不进行范围检查的情况下对索引集中的每个元素进行操作。

像其他集合一样，索引集也有可变和不可变两种版本。大多数时候，你将使用可变版本。你通过添加和删除单个索引（NSIntegers）或范围来操作它。你可以使用索引集来存储任何内容的索引，但它们与 NSArrays 结合使用时最有用，数组有几个方法设计用于接收索引集作为参数。如果你只是想对数组中的某些任意子元素进行操作，通常可以使用它们作为创建子数组的替代方案。

## 存储无序的对象组

```
NSArray *array = [NSArray arrayWithObjects:
"set", @"object", @"containing"
"seven", @"objects", @"not"
"eight", @"objects", nil];
NSSet *set = [NSSet initWithArray:array];
MutableSet *mSet = [set mutableCopy];
NSSet *cSet =
[NSCountedSet initWithArray:array];
```

源自：nsset.m
如果你想存储一个没有顺序的对象集合，可以使用 NSSet 及其可变子类。这模型了数学中的集合，因此插入两次相同的对象也不会存储它的两个副本。

NSSet 如何确定对象之间的相等性是非常复杂的。相等性不等同于同一性（identity）；它不会存储相同对象的副本，但也会存储两个值相同的对象。它通过向其中一个对象发送 -isEqual: 消息并将另一个对象作为参数来判断两个对象是否相等。

实现 NSSet 最简单的方法是将每个新对象与每个现有对象进行比较。然而，这将非常缓慢，所以 NSSet 并不是这样工作的。相反，它使用 -hash 方法。每个对象都应该实现此方法并返回一个整数哈希值。

如果两个对象相等，它们必须具有相同的哈希。像 NSSet 这样的集合根据哈希值将对象放入桶中。在测试对象是否已在集合中时，它只需要测试具有相同哈希值的对象。

因此，良好的哈希对于这些集合类的良好性能至关重要。幸运的是，此类集合中最常用的对象 NSString 已经有了良好的哈希实现。

这种方法的一个细微问题是，对象在集合中时不能更改其哈希值。对于可变对象，在不破坏其他一些规则的情况下无法强制执行这一点。因此，在对象存储在集合期间不要修改它们很重要。

另一种类型的集合是 NSCountedSet，它是 NSMutableSet 的子类，支持多次添加相同对象。这为 NSMutableSet 增加了一个方法 -countForObject:，它返回特定对象被添加到集合的次数。

> 注意：在 Java 和其他其他语言中，计数集合被称为 bag（袋集合）。

值得注意的是，因为 NSCountedSet 是 NSSet 的子类，它的某些方法被设计为允许 NSCountedSet 实例替代 NSSet 实例。如果你向本节开头示例中创建的任何集合发送 -count 消息，你将获得相同的值。如果你遍历任何一个集合，你将得到七个对象。你只有通过向集合发送 -countForObject: 消息，才能判断一个对象是否在计数集合中出现了多次。

## 创建字典

```
NSMutableDictionary *dict = [NSMutableDictionary dictionaryWithObjectsAndKeys:"One", @"1", @"two", @"2", nil];
[dict setObject:@"three" forKey:@"3"];
```

源自：dictionary.m

字典（通常称为 map 或关联数组）提供了一个通过其他对象索引的对象集合。最常见的是字典通过字符串进行索引。这并不是唯一的选择，但对可以用作字典键的类有一些限制。

字典与集合相似，相同的约束也适用。用作键的对象必须实现 -hash 和 -isEqual 方法，在比较时返回 YES，且如果它们相等则返回相同的哈希值。只要它们在集合中，哈希值就不能更改。

此外，键必须实现 NSCopying 协议。当你将一个键添加到字典时，该值将被保留（retain）。如果你传递一个不可变对象（例如 NSString），这种效果等同于释放内存（dealloc）。

最后，值得记住，只有使用字符串作为键的字典才能配合键值编码（key-value coding，见第 11 章）。你将在字典上最常用的方法是 -objectForKey:，它返回与键关联的对象，如果没有对象则返回 nil。对于可变字典，你通常会使用 -setObject:forKey: 方法来设置键值对。

你对集合执行的最常见任务之一是遍历集合中的每个元素并进行某些处理。在 Objective-C 中有很多方法可以实现这一点。因为这是一项如此常见的任务，新的实现方法不断被添加。

对于数组，你可以遍历从 0 到 [array count] 的每个索引并发送 -objectAtIndex: 消息。这是非常无效的。遍历集合的传统方法是使用枚举（enumeration）；即 NSEnumerator 子类的实例。

**注意：** 如果你是从 Java 转过来的，在脑海中将 enumerator（枚举器）替换为 iterator（迭代器），你会发现你熟悉的模式仍然有效。

你可以通过向集合发送 -objectEnumerator 消息来获取枚举器。这个对象非常简单。它只响应两个消息，而你可能会使用其中一个：-nextObject。它返回集合中的下一个对象，如果你遍历了集合包含的所有对象，则返回 nil。

在 Objective-C 2 中，Apple 引入了快速枚举（fast enumeration）。你可以将其用于任何实现 NSFastEnumeration 协议的集合。该协议定义了一个通过单个消息获取多个对象的方法。具体数量由调用者和接收者定义。编译器分配一个缓冲区并将指针传递给接收者。接收者可以将某些对象复制到此缓冲区中，或者如果它内部作为 C 数组（或一组数组）存储数据，则返回其内部存储的指针。
