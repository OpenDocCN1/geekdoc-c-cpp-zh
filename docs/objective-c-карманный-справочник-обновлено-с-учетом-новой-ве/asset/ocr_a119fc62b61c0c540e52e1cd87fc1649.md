On OS X, you will probably use the XCode IDE. This lets you create projects with a number of different template types. If you need to compile these on other platforms, you can find a tool in the GNUSstep repository called pbxbuild, which will compile them.

If you are working on some other platform, you can use GNustep Make to build. This also works on OS X, so whichever option you choose, you should not have portability problems caused by your build system.
