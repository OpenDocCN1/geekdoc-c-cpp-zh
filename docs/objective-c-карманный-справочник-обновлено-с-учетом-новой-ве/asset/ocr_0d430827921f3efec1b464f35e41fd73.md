# Converting Between Strings and Numbers

```
int answer = [@"42" intValue];
NSString *answerString =
    [NSString stringWithFormat:@"%d", answer];
NSNumber *boxedAnswer =
    [NSNumber numberWithInt:answer];
NSAscert([answerString isEqualToString:
    [boxedAnswer stringValue];
    @"Both strings should be the same"]);
```

From: stratum.m

There are several ways of converting between a number and a string. A lot of objects that represent simple data have methods like -intValue, for returning an integer representation of the receiver.

NSString has several methods in this family. If you have a string that contains a numerical value, you can send it a -doubleValue, -floatValue, -intValue, or -longLongValue message to convert it to any of these types. In 64-bit safe versions of Foundation, you can also send it an -integerValue message. This will return NSInteger.
