Objective-C 2 added a few bits of syntactic sugar. It provided a new way of doing enumeration, a way of synthesizing accessor methods, and introduced garbage collection. Objective-C 2 is more of a marketing buzzword than a real language. You won't find a compiler switch for selecting it. Some of the features, such as non-fragile instance variables, are only available on some runtimes. Others, such as garbage collection, are not available on the iPhone. Declared properties are the only Objective-C 2 features that work everywhere, including non-Apple platforms. With iOS 5 and Mac OS X 10.7, Apple moved away from version numbers and started using compiler versions to describe features. Prior to release, the new features were known as Objective-C 2.1, but Apple's marketing division decided not to use this name publicly. These new features included some better support for data hiding, making it easier to move implementation details out of public headers, and automatic reference counting, which combines most—but not quite all—of the benefits of garbage collection and manual reference counting, without most of the disadvantages of either.
