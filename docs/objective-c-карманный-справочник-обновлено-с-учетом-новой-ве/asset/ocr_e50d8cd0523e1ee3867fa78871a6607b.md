The variable is moved from the stack into a reference counted bit of code in heap memory. This means that every reference to it will refer to the same variable. The blockCapture.m example demonstrates this, with a function that creates two, linked, counters.

```
typedef int (^counter_t)(void);
void linkedCounters(counter_t *a, counter_t *b)
{
  _block int c = 0;
  *a = ^(void) { return c++; };
  *b = ^(void) { return c++; };
  *a = Block_copy(*a);
  *b = Block_copy(*b);
  c++;
}

int main(void)
{
  counter_t pre, post;
  linkedCounters(&post, &pre);
  printf("%d %d, %d, %d\n",
  pre(), post(), pre(), post());
  return 0;
}
```
