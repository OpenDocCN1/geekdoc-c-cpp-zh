# Creating Strings from Templates

```
int a = 12;
float b = 42.0;
const char *cString = "words";
id object = [NSDictionary new];
NSString *string = [NSString stringWithFormat:"%d, %f, %s, %@", a, b, cString, object];
```

From: formatstring.m

If you come from a C background, one of the first functions you learned about was probably printf(). This is a variadic function that takes a format string as the first argument. The contents of the format string then define the types of the other arguments.

Objective-C, as a descendant of C, inherits the idea of a format string. Objective-C format strings are almost exactly like C format strings, but with one addition. The %@ indicates that the matching argument is an object.
