Unfortunately, there is no second argument, so it will read a random value from a register. If it’s interpreting this as some kind of number, it’s not a big problem. If it’s interpreting it as a pointer (to a C string or Objective-C object), it will almost certainly crash. By passing @"%@@" we tell NSLog() that there is only one real argument, and that it’s an object.
