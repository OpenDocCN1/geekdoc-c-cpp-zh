# Setting Up the Variables

After this, a few locals require setting up (whether or not a zoom is currently running),
using this code:

```
var maxw = Math.max(fromw, tow)
var maxh = Math.max(fromh, toch)
var stepw = (tow - fromw) / (msecs / INTERVAL)
var steph = (toh - fromh) / (msecs / INTERVAL)

```

The first two sentences use the Math() function to determine the maximum
width and height will be either at the start or end of the zoom, and places these
values in maxw and maxh. The horizontal and vertical distance between each frame of
t zoom is calculated and placed in stepw and steph.

The last four statements of the initial setup process are as follows:

```
S(id).overflow = HID
(id).ZO_Flag = true
(id).ZO_Int = interruptible
(id).ZO_IID = setInterval(DoZoom, INTERVAL)

```

The first one ensures that the overflow will not out its boundaries if it is made
smaller than the contents. This isn't applicable to images but must be done for objects
d divs and spans that can contain many different elements. The overflowing is prevented
by setting id's style.overflow property to HID, which is 'hidden'.

Next, the ZO_Flag property is set to true to indicate and other plug-ins that a zoom
is progress on. The ZO_Int property is also assigned the value in interruptible, which
will be true if this zoom can be interrupted.

Finally, the setInterval() function is called in such a way that the DoZoom() function
will called every interval milliseconds. The result returned by the function is placed in
ZO_ID so that it can used later to cancel the interrupts by a call to clearInterval().

# The DoZoom() Function

The job of the DoZoom() function is to perform the resize by changing the
object's dimensions a little each time it called. The first three lines calculate the new
width and height for the resizing as follows:

```
if (w)ZO_W = Math.max(fromw + stepw * O(id).ZO_Count)
if (h)ZO_H = Math.max(fromh + steph * O(id).ZO_Count)
Resize(id, ZO_W, ZO_H),

```

In the first line, if the argument w is true, horizontal resizing is allowed so the ZO_W
property is assigned the new value required for the object's width. This value is
calculated by multiplying stepw (the amount of change for each animation) by
ZO_Count (the original width of the object). If the zoom is reducing, then a negative value
is added to fromw, otherwise a positive value is added. 

The second line does exactly the same, for the object's height and places the result in
id's ZO_H property. If either w or h is not true, then dimension is not to be resized
during the zoom, the value previously assigned to either the ZO_W or ZO_H property
