PopDown(contents.slice(1)).type, w, h, 1, 0
O(contents[0]).PO_IsUp = true

for (var j = 0 ; j < headings.length ; ++j)
{
  O(headings[j]).PO_C = contents[j]

  if (action == '.hover') O(headings[j]).onmouseover = DoFoldingMenu

function DoFoldingMenu()
{
  if (multi) PopToggle(this.FO_C, type, w, h, msecsl, interruptible)
  else
    for (j = 0 ; j < headings.length ; ++j)
      if (O(O(headings[j]).PO_C.PO_IsUp && O(headings[j]) != this)
        PopDown(O(headings[j]).PO_C, type, w, h,

  if (!O(this.FO_C).PO_IsUp)
    Popup(this.FO_C, type, w, h, msecs2)

## ContextMenu()

With this plug-in, you can replace the standard right-click menu with your own. Much more than a way to block casual users from viewing the source of page, the ContextMenu plug-in lets you create entire entities of HTML and pop them up at the cursor position when user clicks right button. In Figure 8-7, a simple menu has been popped up.

## About the Plug-In

This plug-in requires an object that, when right-clicked, should pop up a menu, which you also pass to. It takes the following arguments:

- Id: An object to which the right-click should be attached—generally, you will attach to the document object but can be more specific and attach different menus to objects (arrays of objects are not supported)
- contents: An object containing the menu to be displayed
- type: The type of effect for popping the menu up and out, 'fade', 'inflate', 'zoom', or 'instant'
- w: If applicable and this argument is true or 1, the object's width will be modified during transition
- h: If applicable and this argument is true or 1, the object's height will be modified during transition
- msecs: The number of milliseconds the pop-up transition should take

## Variables, Arrays, and Functions

| | |
| :--- | :--- |
| x, y | Local variables containing the current and top edges of location |
| MOUSE_X, MOUSE_Y | Global variables containing the current mouse x and y coordinates |
| PO_IsUp | Property of id that is false if popped down, otherwise popped up |
| FA_Flag | Property of id set by Fade() plugin when fade is in progress on id |
| DF_Flag | Property of id set by Deflate or Inflate() plugin when deflate or inflate is in progress on id |
| zIndex | Style property of contents containing its depth from front (highest) to lowest |

| SetInterval() | Function to start interrupts |
| clearInterval() | Function to stop interrupts |

| PopUp() | Plug-in to pop up a previously down object |
| PopDown() | Plug-in to pop down an object |
| W(), H() | Plug-ins to return the width and height of an object |
| ContextUp() | Subfunction to pop up when the mouse is right-clicked |
| ContextDown() | Subfunction of ContextUp to check whether the mouse moved out of the space occupied by contents and if so to remove it |

## How It Works

This plug-in releases the contents object from its position in the HTML document by using Locate() plugin to give it style position of ABS (a global variable with the value 'absolute'). Next, it moves off screen to a location thousands of pixels away, removing it from the browser as quickly as possible so not to appear within your page. Next, contents are popped down, to be popped up when required, and the oncontext event of id is attached to the ContextUp() function, which will pop up contents when id is right-clicked.

```
Locate(contents, ABS, -10000, -10000)
PopDown(contents, type, 1, 1, 1, 0)
O(id).oncontext = ContextUp
```

### The ContextUp() Subfunction

The purpose of this subsection is to react to a rightclick event on id. The first thing it does, though, is check whether it can go ahead by examining the state of flags created by the Popup(), PopDown(), Fade(), and Relate() plug-ins, like this:

```
if (O(contents).PO_IsUp ||
    O(contents).FA_Flag ||
    O(contents).DF_Flag) return false
```

If any of these flags are true, then contents are popped up, or one of the transition types is already active in contents, so the plug-in returns.

If the plug-in proceed, it sets the local x and y to the current coordinates of the mouse cursor and moves the popped down contents to that location with a call to Goto(). It calls Popup() to pop it up, like this:

```
var x = MOUSE_X
var y = MOUSE_Y
Goto(contents, x, y)
Popup(contents, type, w, h, msecs, 1)
```

Next, it's necessary to ensure that any objects that have been created or had their zIndex changed since the contents div will not appear in front of it, so the object's zIndex property is set to the value in ZINDEX plus one. ZINDEX is the global variable that tracks the highest zIndex used by an object, adding 1 to this value ensures that contents will appear on top of every other object in the browser. Here's the statement that does:

```
contents.zIndex = ZINDEX + 1
```

The plug-in needs a way to determine whether the mouse has moved out of the area occupied by contents, and therefore it needs to be popped down. You might think that attaching to the mousemove event of contents would do the trick, but sadly, it won't do so reliably and in all. The reason for this is if you include a form input or other elements within contents, when the mouse passes over the browser it thinks it has passed out of the contents object and prematurely trigger the mousemove event.
Therefore, it is necessary to track the position of the mouse and pop the object down if it moves out of the object's bounds. To do this, a repeating interrupt is created to call up the subsection ContextDown() every INTERVAL milliseconds to see whether the mouse is still inside the object:

```
O(id).zIndex = setInterval(ContextDown, INTERVAL)
```

Finally, the return statement returns a value of false to tell the browser pulling up the standard right-click menu:

```
return false
```
