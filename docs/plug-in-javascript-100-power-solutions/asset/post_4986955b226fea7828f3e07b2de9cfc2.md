# How It Works

This plug-in begins by populating the associative array types with the eight types of chart names used by the plug-in and their corresponding keywords, as passed on to Google Charts, like this:

```javascript
var types = {
  'line' : 'lc',
  'vbar' : 'bvg',
  'hbar' : 'bhg',
  'gometer' : 'gom',
  'pie' : 'p',
  'pie3d' : 'p3',
  'venn' : 'v',
  'radar' : 'r'
}
```
