# O()

The O() function is the most functional of the plug-ins provided in this book and is used by almost all the others. In its simplest form it replaces the long-winded JavaScript function getElementById which takes the string argument to it and returns the HTML DOM (Document Object Model) object that has been assigned that ID. The letter O short for the word Object since the main purpose of this function is to retrieve an object or modify its properties.

# About the Plug-in

This plug-in takes one required and two optional arguments follows:

+   - id This can be a string containing the ID of an object, an object, or even an array containing several objects and/or IDs. If none of the optional arguments are also provided the function returns the object or objects represented by id. If there are optional arguments then the purpose of the function changes to assign the value in value to the property in property of the object (or objects) in id.
- property This optional string argument can contain the name of a property belonging to the object (or objects) in id that requires modifying
- value If this optional argument is set it represents the value to be assigned to the property in property of the object (or objects) in id. Both the property and value arguments must have values, otherwise O() will simply return the object (or objects) in id.
