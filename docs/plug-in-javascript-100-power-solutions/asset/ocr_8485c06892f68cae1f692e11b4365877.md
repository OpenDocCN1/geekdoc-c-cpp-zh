# Setting Up the Repeating Interrupts

The last four lines of the setup portion of the plug-in set the local variable count to zero; it will count each step, and inform the plug-in when it's to stop. The new SL_Int property of id is set to the value interruptible. This causes any call that attempts to interrupt the slide to be prevented unless the value true or the new SL_Flag property of id is set to true to tell this and any other plug-ins are currently running on the object id.

Finally, setInterval() is called, passing the DoSlide function name and the value in INTERVAL. If the brackets are left off the end of the function, the function itself is passed to setInterval(). If brackets were placed after the result of calling the DoSlide() function would be set to setInterval(), which is another value altogether.

This statement has initiating an interrupt call to the DoSlide() function every INTERVAL (by default) milliseconds. The value returned by the function is stored in SL_ID (id) so it can be used as an argument to clearInterval() when the slide has completed (or if it is interrupted). The code to do all of this is follows:

```
var count = 0
O(id).SL_Int = interruptible
O(id).SL_Flag = true
O(id).SL_ID = setInterval(DoSlide, INTERVAL)
```

# Performing the Slide

The portion of code that performs the animation is the DoSlide subfunction. Subfunctions retain the main function's local variables and, therefore, a neat way to create a repeating interrupt without having to keep the arguments required.

```
Go(id, frx + stepx * count, fry + stepy * count)
```
