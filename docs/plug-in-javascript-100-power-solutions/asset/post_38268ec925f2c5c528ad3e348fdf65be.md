```javascript
window.onload = function() {
  width = GetWindowWidth()
  height = GetWindowHeight()
  x = width - 200
  y = height - 150

  Locate('sea', ABS, 0, height - 50)
  Resize('sea', width, 50)

    Array(

      InsVars('Slide('ship', #1, #2, #3, #4, 5000)', 0, y, x, y),
      FadeOut('ship', 500, 0),
      InsVars(Callback('GoTo('\\', #1, #2)'), 0, y)
    )
  }
}</script>
```

The two lines of HTML <script> section starts off by obtaining a div to represent the sea and display an image of a sailing ship. Next, the set width and height of the browser and setting x and y to values for the sailing ship to use in a call to the Slide() plug-in.

After this, the set style property of 'absolute' so that it can be placed in an exact location, and is then resized to take up the bottom 50 pixels of the browser. The represent the 'sea' object also has its background color changed. Finally, the ship is located at its start position of 0, y.

The final part of this example is the While() function, which passes the following expression:

```
KEY_PRESS != ' '
```

KEY_PRESS is a global variable that is automatically set to whatever the value of the last key pressed happens to be, so this expression will return true until the space bar is pressed.

The first three statements in the chain of calls are pretty obvious; they fade the ship in, move it across the browser, and then fade it out. However, the final call is a little more interesting because it's an example of using Callback() plug-in to turn a nonchangeable plug-in (in this case GoTo()) into a chainable, for just this single call.

Use InsVars() plug-in to insert the variables and values into the string containing the Goto() call. This string is then placed within a call to Callback() and becomes chainable.

Therefore, the fourth statement moves the ship back to the start position ready for its next voyage—if the space bar hasn't been pressed.

function While(expr, calls) {
  if (eval(expr)) {
    var temp = ''
    for (var j = 0; j < calls.length; ++j)
      temp += '' + calls[j].replace(/"\\/g, '\\\\') + '\';
    temp = temp.substr(0, temp.length)
    calls.push("While\#(InsVars('#\', Array(#2))", expr, temp))
  }
  Chain(calls)
}

# About the Plug-in

This plug-in pauses between commands in a chain for the length of time specified. It takes the following argument:

- wait Length to time in milliseconds

# Variables, Arrays, and Functions

| | |
| :--- | :--- |
| setTimeout() | Function to create a single interrupt |
| NextChain() | Plug-in to run the next command in a chain (if there is one) |

# How It Works

This plug-in is quite straightforward. It simply makes a call to the setTimeout function to make it call the NextChain() plug-in after wait milliseconds. Because commands within a chain are linked together via the NextChain() plug-in, this is the only way that the next command in a chain can be run. By setting the timeout to occur at a future time, the chain will not continue until timeout occurs and NextChain() is called.

Unlike the setInterval function, setTimeout sets up a single interrupt and forgets about it once it has occurred, so there is no need to clear it.

# How To Use It

To use this plug-in, insert a string as the following, which will create an event 1.5 seconds in the future to resume the execution, into an array of chain commands:

```
"Pause(1500)"
```

Here's a fun example that illustrates the use of Pause() by zooming down the ship in the previous plug-in, While(), when it reaches the center of the browser, then pausing for a few second before coming back in again, letting the ship continue on its course:

# WaitKey()

This plug-in is useful for inserting a pause in a chain that waits until a key is pressed. In Figure 7-5, the chain has been paused and is using this plug-in for a keypress.

# About the Plug-in

This plug-in halts execution of a chain until a key is pressed. It requires no arguments.

# Variables, Arrays, and Functions

| | |
| :--- | :--- |
| KEY_PRESS | Global variable containing the value of the last key pressed |
| INTERVAL | Global variable containing 30 |
| GetLastKey() | Plug-in to return the value of the last key pressed |
| NextChain() | Plug-in to run the next command in a chain |
| DoWaitKey() | Subfunction to wait for keypress before allowing a chain to continue |
| SetTimeout() | Function to create a single call to another function at a future time |

# How It Works

This calls the GetLastKey() function, which removes any key that has been pressed and leaves the global variable KEY_PRESS containing the empty string. Next, the setTimeout() function is called to create an interrupt call to the DoWaitKey() function in INTERVAL milliseconds. Here is the code for these two statements:

```
GetLastKey()
setTimeout(DoWaitKey, INTERVAL)
```

When the DoWaitKey() function is called, it checks the value of KEY_PRESS and, if it is no longer the empty string, the NextChain() plug-in is allowed to allow the command in a chain to run (if there is one). Otherwise, if no key has been pressed, another call to setTimeout() is made, to see if a key has been pressed, DoWaitKey() after INTERVAL milliseconds using this code:

```
if (KEY_PRESS != '')
NextInChain()
else setTimeout(DoWaitKey, INTERVAL)
```

Therefore, if there is a key, after calling NextChain() the function returns and will not be called unless a new call is made to WaitKey(), otherwise DoWaitKey() will be repeatedly called every INTERVAL milliseconds until a key is pressed.
