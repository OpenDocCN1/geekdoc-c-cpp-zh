Finally, in the tooltip section, the DoToolTip() and ToolTipHide() functions are attached to the mouseover and mouseout events of id, and the Hidden property of id is set to false to indicate that the tooltip is not currently visible:

```
O(id).mouseover    = DoToolTip
O(id).mouseout     = ToolTipHide
O(tt).Hidden       = false
```

### TheDoToolTip() Function
This function moves the div referred by tt to a location 15 pixels to the right and 15 down from the mouse position, sets its zIndex property to the highest value used so far plus 1 (to ensure displays above all other elements), fades the tooltip, and sets the tooltip's Hidden attribute to false to indicate that it is now visible:

```
Goto(tt, MOUSE_X + 15, MOUSE_Y + 15)
O(tt).zindex = 1
FadeIn(tt, msecs)
(tt).Hidden = false
```

With the tooltip displayed, if a timeout has been specified then setTimeout() is called to create an interrupt call to the ToolTipHide() function in timeout milliseconds, to fade it away (after first cancelling any timeout that may be in place), like this:

```
O(tt).IID = clearTimeout(O(tt).IID)
O(tt).IID = setTimeout(ToolTipHide, timeout)
```

### TheToolTipHide() Function
This function simply checks whether the tooltip is hidden. If it is, it has nothing to do and returns; otherwise, it fades the tooltip and sets its Hidden attribute to true to indicate the new setting:

```
FadeOut(tt, msecs)
O(tt).Hidden = true
```
