# How It Works

This plug-in begins by finding the farthest possible position along or an edge that id can be placed, using the browser width, subtracting the width of id from it, and placing the result into w. The variable h is also calculated for vertical edges, as follows:

```
var w = GetWindowWidth() - W(id)
var h = GetWindowHeight() - H(id)
```

Next, the variable o is set to zero if offset is a number, or if offset is a string beginning with the % character, o gives the value resulting from dividing the numeric part of the argument by id. In the first instance, the value of zero will indicate that an exact offset in pixels has been passed in offset, in the second case, a percentage distance along the edge has been specified for where id should be located, and that is value in w. Here is how the code does:

```
var o = offset[0] != '%' ? 0 : offset.substr(1) / 100
```

# If the Left or Right Edge Has Been Chosen

Next, the plug-in needs to determine which edge is going to be used, so first tests the value against the global variables LT and ET (which contain 'left' and 'right'). If it is one of these, the following code is executed:

```
var t = W(id)
var u = Math.min(t, msecs / INTERVAL)
var x = where == LT ? t : w + t
var y = o ? h * o : offset
var s = t / u
```

This assigns the amount of id that's not shown by default to t, then u is assigned the number of steps the animation needs to complete in msecs milliseconds. After this, the x and y coordinates again to see if they 'left' (the value of LT). If it does, means the left edge is used, so x is set to -t, which places id sufficiently off scroll so that showing pixels of the object are visible. Otherwise, x is set to move the object off the right hand of the screen in a s of a similar fashion.

The variable y is similarly calculated, being set to the value in offset if o is zero (in other words, an absolute offset if the edge was requested), or set to h * o because o is a fractional value representing the percentage along the edge the object should be, and h is the maximum distance that the edge may appear near.

Finally, s is the distance by which id should be moved for each frame of a slide, is calculated by dividing t (the amount of id that's not shown by default) by u (the number of steps required to make the animation last msecs milliseconds). These variables will be be used during the animation stages of the plug-in.
