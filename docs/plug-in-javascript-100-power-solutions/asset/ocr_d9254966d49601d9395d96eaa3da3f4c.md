# 34 Opacity()

Being able to switch from invisible to visible is great, but sometimes you need
finer control over an object's visibility. This is referred to in JavaScript by the inverse term:
it opacity. With this plug-in, you can set the opacity of any object to a value between 0 and 20 percent
(totally transparent, or invisible) and 100 percent (fully opaque, nothing being behind
through.)

Figure 5-5 shows three buttons displayed using the default opacity of 100 percent.
In Figure 5-6 each has been clicked to change its value to 25 percent, 50 percent, or
75 percent, respectively.

# About the Plug-in

This plug-in applies the opacity setting supplied to the object or objects it is. It requires
the following arguments:

+   - id An object, an object ID, or an array of objects and/or object IDs
- percent The amount of opacity to apply to the object or objects, from 0 percent,
which is fully transparent, to 100 percent, which is fully opaque.
