# Choosing a Program Editor

Long gone are the days of relying on a simple Notepad program for coding. Software for writing program code has progressed in leaps and bounds in recent years, with text editors being replaced by powerful program editors that highlight your syntax using different colors and can quickly locate things for you like (matching) brackets and braces and so on.
Table 1-2 lists number of free program editors that will do a great job of helping you write JavaScript code quickly and efficiently.
