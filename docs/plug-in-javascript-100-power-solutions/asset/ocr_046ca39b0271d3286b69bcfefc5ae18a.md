# 81 PlaySound()

This plug-in lets you play a sound as a result of a mouse or button event, a keyboard event, or any other reason. Figure 10-6 reintroduces the avatars in previous chapters, but this time their onmouseover events are attached to this plug-in.

# The Plug-in

This plug-in takes an empty container such as a div or span and embeds an audio player in play a sound. It requires the following arguments:

+   * id Object or ID—this cannot be an error
* file URL of an audio file, generally a WAV or similar file
* loop If 'true', the sound will loop continuously; if 'stop', it will stop a previously playing sound; any other value will play the sound
