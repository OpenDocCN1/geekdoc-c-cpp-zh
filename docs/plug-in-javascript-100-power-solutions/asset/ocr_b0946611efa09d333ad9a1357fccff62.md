# If a Zoom Is Not Currently in Progress

Next, the plug-in checks whether a zoom is currently in progress id by looking at itsnZO_Flag property. If a zoom is not in progress, three variables require initializing prior
starting the zoom, as follows:

```
if (!O(id).ZO_Flag) {
  O(id).ZO_W = Math.max(fromw, tow)
  O(id).ZO_H = Math.max(from, toh)
  O(id).ZO_Count = 0
}
```

The first two statements assign whichever value is larger than the start and destinationnwidths and heights to the ZO_W and ZO_H properties of id.
fromw, tow, and toh this sets default value for the width and height of a zoom should only one of the dimensions
be to change (the nonchanging dimension will retain this value). The ZO_Count
property is also initialized to zero

# If a Zoom Is In Progress

If a zoom is in, the ZO_Int property is inspected. If it is not, the plug-in may
be interrupted, it returns. The repeating intervals are stopped by calling the
clearInterval() function. also the only useful action an interrupt can do to
zoom in progress is to reverse the direction of zooming, the ZO_Count property of is set
to inverse. Here is the section of code that does this:

```
else {
  if (O(id).ZO_Int) return
  else clearInterval(O(id).ZO_IID)

O(id).ZO_Count = (msecs / INTERVAL) - O(id).ZO_Count
}
```

If the zoom can't interrupted then the msecs / INTERVAL being the number of
steps required to make the zoom last for msecs milliseconds. Therefore, if the ZO_Count
property has a value of 10 out of 34 (for example), then for the zoom to reverse there will be
only 10 steps remaining to return to the starting zoom level.
