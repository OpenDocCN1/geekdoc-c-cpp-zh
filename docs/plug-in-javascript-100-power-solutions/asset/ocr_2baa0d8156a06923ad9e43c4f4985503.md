# How It Works

The first thing this plug-in does move the pop-up to its correct location and initiate the pop-up process, like this:

```
GoTo(id, x, y)
PopUp(id, type, w, h, msecs, interruptible)
```

Next, some local variables are assigned to keep track of the browser's dimensions, the borders (if any) of the pop-up, and its width and height, as follows:

```
var browser = GetWindowWidth()
var browser = GetWindowHeight()
var borderw = Nox(S, .borderLeftWidth) +
Nox(S, .borderRightWidth)
var border = Nox(S, .borderTopWidth) +
Nox(S, .borderBottomWidth)
var popw = W(id)
var poph = H(id)
```

The mouse cursor is then to show a pointer when it passes over closed object, which is using the close button. After that, the BWToFront() function is assigned to the onclick event of the pop-up so that whenever you click on the pop-up, if it is partially obscured or, it is brought to the front.

In addition, the closed object is assigned to the BWCloseWindow() function so that clicking the close button will pop the window down, and the BWMove() function is assigned to the header so that you can click and drag the header to move the pop-up about, like this:

```
(closed).cursor = 'pointer'
O(id).onclick = BWToFront
(closed).onclick = BWCloseWindow
(header).onmousedown = BWMove
```

The last couple of lines in the main section of code use the PreventionAction() plug-in to disable the 'select' event on the header and closed objects. If this is not done, dragging the pop-up quickly may highlight parts of the header text because the pop-up will drag behind behavior is prevented like this:

```
PreventionAction(header, 'select', true)
PreventionAction(closed, 'select', true)
```
