# Variables, Arrays, and Functions

| opacity | The style.opacity property used as most browsers |
| MozOpacity | The version of the opacity property used by Mozilla-based browsers as Firefox |
| KhtmlOpacity | The version of the opacity property used on older versions of the Apple Safari browser |
| filter | Used to implement Microsoft's version of the opacity property (and many others properties too) |

# How It Works

This plug-in makes four calls in turn because various browsers approach the subject of opacity in different ways. Fortunately, none of the methods clash with each other, so a lot of if...then code is not necessary.
The first line for most browsers (as Opera, Google Chrome, and recent versions of Apple Safari) looks like this:

```
S(id, 'opacity', percent / 100)
```
