# Erasing a Cookie

The code to erase a cookie makes use of a recursive call by passing the cookie name and a value of an empty string, along with one minute in the past, back to itself with an action of 'save':

```
ProcessCookie('save', name, '', -60)
```

# To Use It

To use this plug-in, put the action in the action argument, which should be a value of 'save', 'read', or 'erase', and pass the cookie's name and any other values needed.

For example, set the cookie 'password' to the value 'mypass' with an expiry date of one hour from now, you would use the following:

```
ProcessCookie('save', 'password', 'mypass', 60 * 60, '/')
```

Once a cookie has been set, you can read it back like this:

```
value = ProcessCookie('read', 'password', '', '', '/')
```

Or, you can delete a cookie like this:

```
ProcessCookie('erase', 'password', '', '', '/')
```
