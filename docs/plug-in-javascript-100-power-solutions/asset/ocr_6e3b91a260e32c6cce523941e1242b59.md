# The StarttE() Subfunction

This function checks the flag variable to see whether touch control has already been enabled. If it has, false is returned; otherwise, copies of the mouse cursor position are placed in temporary variables to compare later or if the document body should be scrolled, like this:

```
var oldmouse = MOUSE_X
var oldmouse = MOUSE_Y
var tempmousex = MOUSE_X
var tempmouse = MOUSE_Y
```

Next, flag is set to true to indicate that touch control has been enabled, and setInterval() is called to set up repeating interrupts to DoTE:

```
flag = true
iid = setInterval(DoTE, 10)
```

# The DoTEv() Sub-subfunction

This function checks whether the mouse button is currently held down and is within the bounds of the browser, like this:

```
if (MOUSE_DOWN && MOUSE_IN)
```

If the mouse is either not down or not within the browser’s bounds, the StopTE subfunction is called to release the current scroll. Otherwise, a test is made to see whether the mouse has moved from the position that was stored in the variables tempmousex and tempmouse when StartTE() was first called:

```
if (MOUSE_X != tempmousex || MOUSE_Y != tempmousey)
```

If the mouse has moved, tempmousex and tempmousey are updated to the new mouse location, like this:

```
tempmousex = MOUSE_X
tempmousey = MOUSE_Y
```

Next, the window is scrolled by the difference between the current mouse location and the one that was stored in oldmouse and oldmouse when StartTE() was first called, like this:

```
window.scrollBy(oldmouse - MOUSE_X, oldmouse - MOUSE_Y)
```
