# How To Use It

To use this function, you pass an object (or array of objects) that have already been zoomed and specify the type of zoom you want (whether to zoom the horizontal or vertical axis, or both), with the number of milliseconds it should take, whether to use padding, and whether the zoom should be interruptible, like this:

```
ZoomRestore(myobject, 1, 1, 100, 0)
```

This restores the dimensions of myfile over a period of 1000 milliseconds from zero width, back to its original values. The final two values specify that no padding should be used, and the zoom should not be interruptible.
