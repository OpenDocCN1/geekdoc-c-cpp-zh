# The Companion Website

To save the effort of typing all plugin-ins in this book, you can download them from this book's companion website at pluginjavascript.com (see Figure 1-4).

Click the "Download Plug-ins" link to download the file plug-ins.zip, which is an archive file (easily extractable on all operating systems) containing all the plugin-ins. Once extracted, in the root of the plug-ins.zip you will find files P1.js and P1.js, which contain the plugin-ins in a ready-to-use form. Also in the root is a file ReadMe.txt, which contains the latest details about the plugin-ins, including any improvements or updates that have been made since this book was published.

There are also examples from 3 to 13, corresponding to chapters in this book. Within each folder you will find example HTML and JavaScript files showing the use of each function that you can load into a browser to try out for. Some plugin-ins also make use of Ajax techniques and may include other associated files (such as those with .php extensions), in case they will be documented in the associated chapter.

# CONTENTS

JavaScript is the free language built into all modern browsers including Internet Explorer, Firefox, Safari, and Chrome. It is the power behind dynamic web applications, the technology used for Web 2.0 websites such as Facebook, Flickr, Gmail and many others. Plug-In JavaScript is aimed at people who have learned basic HTML, and provides a Little Ajax that they may wish to create dynamic menu systems, provide mouse hover effects, support Ajax functionality and more. They will be shown how to do all these things and make more using simple JavaScript.
