# The Remaining Assignments
In the final lines of the setup portion of this plug-in, a few other properties of id have to be assigned, as follows:

```
O(id).FA_Flag = true
O(id).FA_End = end
O(id).FA_Int = interruptible
```

The first line sets the object's FA_Flag to true, and this is used in other parts of the code to decide whether or the plug-in can be entered (reentered). The second line makes a copy of the end value in the new property FA_End, and the last assigns the value in interruptible to the property FA_Int.

Next, the amount by which change the opacity has to stored in FA_Step. This is either step if the opacity is to increase, or -step if it will be decreasing, as determined by this line:

```
O(id).FA_Step = end > O(id).FA_Start ? stepval : -stepval
```

# Initiating the Interrupts
The last line of the setup section of the plug-in sets up the interrupts in the following way:

```
O(id).FA_IID = setInterval(DoFade, INTERVAL)
```

This starts off a repeating interrupt that will call the DoFade() function every INTERVAL milliseconds. The value returned by calling setInterval() is saved in the new property FA_IID, as is needed later when time comes to cancel the interrupts.
