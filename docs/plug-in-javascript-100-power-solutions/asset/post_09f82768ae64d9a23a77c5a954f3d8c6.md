## How It Works
This plug-in works in almost the same fashion as the MatrixToText() plug-in except that the string is loosely scrambled over time and using the id to display it—a full explanation can be found in the section "Plug-in 72: MatrixToText()."

## How To Use It

To use this, pass it an object, such as a div or span that contains some text, and tell it how long the scramble transition should take, as with this example:

```html
<font face='Courier New' size='6'>
<b>
<div id='text'>Welcome to the best science fiction and fantasy fan website in the world!</div>
</body>
</font>
```

```javascript
<script>
window.onload = function() {
TextToMatrix('text', 3000)
FadeOut('text', 3000)
}
</script>
```

Note that I sniff in a call to the FadeOut() plug-in in this example as it makes for an interesting combined effect of the scrambling text slowly fading away—this is just one example of how you can combine these plug-in to produce more complex and interesting results.

You may also notice that I omitted the interruptible argument to FadeOut(). Therefore, this passes a value of 'undefined' for argument to the function, which will be treated as if the value was false and so it saves on typing.

## The Plug-In

```javascript
function TextToMatrix(id, msecs)
  if (id instanceof Array)
  {
    for (var j = 0 ; j < id.length ; ++j)
      TextToMatrix(id[j], msecs)
  }

  if (O(id).TM_Flag) return
  else O(id).TM_Flag = true

  var text = Html(id)
  var len = text.length
  var freq = Math.round(msecs / INTERVAL)
  var count = 0
  var chars = 'ABCDEFGHIKLMNOPQRSTUVWXYZ' + \
    'abcdefghijklmnopqrstuvwxyz' + \
    '0123456789'
  var id = setInterval(TextToMatrix, freq)

  function TextToMatrix() {
    for (var j = 0 ; j < len / 20 ; ++j)
    {
      var k = Math.floor(Math.random() * len)
      var l = Math.floor(Math.random() * chars.length)

      if (text[k] == '\n' || text[k] == 'r' || text[k] == ' ')
        text = text.substr(0, k) + chars[l] + text.substr(k + 1)
    }

    if (O(id).innerText) O(id).innerText = text
    O(id).textContent = text

    if (++count == INTERVAL) {
      O(id).TM_Flag = false
      clearInterval(iid)
    }
  }
```

## 74 ColorFade()

This plug-in provides a very smooth transition effect between two different colors, and you can use it with either object's text or its background colors. Figure 9-5 shows two elements that have been set to fade colors. The first continuously alternates between yellow and blue text and background colors, while the second fades from black to light blue when the mouse is passed over it.

## The Plug-in

This plug-in changes the text or background color of the contents of an object over a specified period of time. It requires the following arguments:

- An object or object ID or an array of objects and/or object IDs
- color1: The start color expressed as a six-digit hexadecimal number
- color2: The end color expressed as a six-digit hexadecimal number
- what: The property to change, 'text' for the text color, or 'back' (or other than 'text') for the background color
- msecs: The number of milliseconds the transition should take
- number: The number of times the transition should repeat, with 0 meaning infinite repeats

This function starts by iterating through if it is an array, recursively calling itself to process each element individually, like this:

```javascript
if (id instanceof Array) {
  for (var j = 0; j < id.length; ++j) {
    ColorFade(id[j], color1, color2, what, msecs, number);
  }
  return;
}
```
