# How It Works

This plug-in makes a call to the set() plug-in using the assignment version of the call so that id can be an object, an object ID, or an array of objects and object IDs. Each object has its style.display property set to 'block', which restores its full width and height. Additionally, a call to id() is made with the arguments HI and false, which sets the new property HI_Flag to false, so that plugins can tell the object is not hidden. call also supports arrays.

Finally, any callback function is evaluated by the eval() function, but only if the argument CB (in Chapter 7) has a value.
