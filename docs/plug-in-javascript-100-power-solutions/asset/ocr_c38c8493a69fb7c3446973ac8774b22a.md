+   - offset the amount by which the object should be offset from the left or top of the edge—if offset is a number, the amount is an exact offset in pixels, but if it is a string fetched with a % symbol (such as "%50”), then the object is to be placed along the edge
- showing The number of pixels by which the object must poke into the browser
- msecs The number of milliseconds it should take for the object to slide in or out
