Let's look at another example that responds to mouse events and allows interruption adding a couple of commands to the <script> section of the previous example:

```
O('globe').onmouseover = function() {
  Slide(this, 450, 0, 450, 50, 500, 1) }
O('globe').onmouseout = function() {
  Slide(this, 450, 0, 450, 0, 500, 1) }
```

Now when you pass the mouse over the slide it will move from the position 450.0 to 450.0. When you move the mouse away, it will slide back to 450.0. As you'll see, it doesn't matter where you interrupt the slide, it always maintains the correct speed. Notice that the keyword tells Slide() object to slide.

However, if you interrupt one slide with another that has a different distance to go or a different length of time specified, the interrupting and interrupted speeds will not match. I recommend you to generally dissu interrupting a slide with a dissimilar one. as with the first Slide() call in the example, where you cannot interrupt.
