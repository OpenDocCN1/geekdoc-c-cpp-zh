# 93 ValidatePassword()

To help users pick more secure passwords, you may wish to require them to be of a certain format, such as including upper- and lowercase characters, as well as digits and punctuation. With this plugin-in, you can choose any or all of these and the plugin-in will return true or false, depending on whether the user has satisfied your requirements. In Figure 12-5 the password that has been entered has not verified.

# About the Plugin-in

This plug-in takes a password string and returns either true or false, depending on whether it satisfies the conditions also passed as arguments. It requires the following arguments:

+   * pass The password to validate
* min The minimum password length
* max The maximum password length
* upper If true or 1, at least one uppercase character must be in pass
* lower If true or 1, at least one lowercase character must be in pass
* dig If true or 1, at least one digit must be in pass
* punct If true or 1, at least one nonalphanumeric character must be in pass
