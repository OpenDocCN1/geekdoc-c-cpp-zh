Next, the overflow property of the document.body is set to 'hidden' to disable scrolling

they can be moved about or modified without these actions being seen by the
user.

After that, the frame is moved to the top left of the browser and resized to fill the
window, and its zIndex property is set to the highest value used for (held in ZINDEX),
like this:

```

Having set the frame, id is processed by setting its opacity to 0, which releases
it from the HTML by calling Position() to set its style attribute to 'absolute'.
Next, its zIndex is set to a value that is  higher than the frame's, and the ZINDEX global
variable is also increased to contain this higher value:

```
