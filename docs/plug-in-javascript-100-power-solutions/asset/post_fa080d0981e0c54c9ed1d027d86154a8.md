## About the Plug-In

This plug-in fades smoothly between two images. It requires the following arguments:

- id1: An object, an object ID, or an array of objects and/or object IDs
- id2: An object, an object ID, or an array of objects and/or object IDs
- msecs: The number of milliseconds the transition should take
- interruptible: If set, the fade can be interrupted; otherwise, it cannot

## Variables, Arrays, and Functions

| FadeOut () | Plug-in to fade an object out |
| FadeIn () | Plug-in to fade an object in |

## How It Works

This plug-in calls the FadeOut () plug-in for id1 and the FadeIn () plug-in for id2. It is also possible to supply an object, an object ID, or an array of objects and/or object IDs to both plug-ins.

## How To Use It

To use plug-in, pass two IDs, objects, or arrays of objects and/or object IDs, and they will fade from the first to the second. For the best results, you will probably want to overlay the objects on top of each other so that you can get smooth transitions. The plug-in still works to fade between objects in different locations.

The example illustrates the setting up of your objects and then fading

```
<center<br />
<span id='id1'>Crossover</span>
<img id='id1' src='id3.gif' />
<img id='id2' src='id4.gif' />
</center>
```

```html
<script>
window.onload = function() {
  LocateArray('id1', 'id2'), 0, 0
  FadeToggle('id2', 1);
  O('id1').onmouseover = function() { FadeBetween('id1', 'id2', 500, 1) };
  O('id1').onmouseout = function() { FadeBetween('id2', 'id1', 500, 1) };
}
</script>
```

In the HTML section a span is created to mouse events will be attached and two GIF images are loaded.

In the <script> section the two images are lifted up of the layout by making their position setting 'absolute', the second image is speedily faded (over a period of 1 millisecond) so that only the first image is visible.

## Chapter 5: Visibility

The mouse events are attached to the FadeBetween() plug-in so that passing your mouse over the span smoothly fades between the images over a period of half a second. The first FadeBetween() call fades from the first image to the second, while the second call fades back again.

## The Plug-in

```javascript
function FadeBetween(id1, id2, msecs, interruptible, CB)
{
  FadeOut(id1, msecs, interruptible, CB)
  FadeIn(id2, msecs, interruptible, CB)
}
```

## Hide()

This plug-in is different from Plug-in 31, Invisible(), in that when called it completely collapses the object down to 0 by 0 pixel. The object is still there that it can be unhidden, but it is not visible. Because it occupies no space, other elements will move to occupy the free space. This makes it perfect for menuing and similar features.

In Figure 5-12, a row of three buttons has been created, each of which is attached by its onclick event to a call to the Hide() plug-in. In Figure 5-13, the middle button is hidden after being clicked, and the other buttons have moved in to take up the vacant space.

## About the Plug-in

This plug-in will hide an object, effectively removing it from a web page. It requires the following argument:

- An object, an object ID, or an array of objects/or object IDs

## Variables, Arrays, and Functions

| HI_Flag | New property assigned to id and set to true when id is hidden |
| display | The style.display property of id |

## How It Works

This plug-in makes a call to the S() plug-in using the assignment version of the call, so that it can be an object, object ID, or an array of objects and/or object IDs. Each object has its style.display property set to 'none', Additionally, a call to O() is made with the arguments Hi_Flag and true, which sets the new object property Hi_Flag to true so that other plug-ins can tell the object has been hidden. This also supports arrays.

Finally, any callback function in CB is evaluated with the ev() function, but only if the event CB (explained in Chapter 7) has a value.

## How To Use

To hide an object, pass it to the Hide() plug-in, from inside a side of JavaScript code, or from within HTML. In the following example, three buttons can be hidden:

```html
<center>
<input id='a' type="button" onclick="Hide('a')" value="A" />
<input id='b' type="button" onclick="Hide('b')" value="B" />
<input id='c' type="button" onclick="Hide('c')" value="C" />
</center>
```
