
# Introduction

JavaScript is the free language built into all modern browsers including Internet Explorer, Firefox, Safari, Opera, and Chrome. It is the power behind dynamic HTML and the Ajax environment used for Web 2.0 websites as Facebook, Flickr, Gmail, and many others. Plug-in JavaScript is aimed squarely at people who learned basic HTML (and perhaps a little CSS (and JavaScript) and are interested in doing more. For example, you may wish to create more dynamic menu systems, provide mouse hover effects, or support Ajax functionality. In this book you will be shown how to do all these things and much more using simple JavaScript, and it is never assumed that you know anything about a solution. Instead, you are taken through each step by step with the explanations included, so there is no need to look up anything elsewhere; every solution is complete and applicable immediately.

Where possible, the book purposefully ignores advanced JavaScript techniques such as object programming (even though they may sometimes be more powerful) to make it easy for you to understand all the plug-ins. Not using these advanced techniques does not mean the plug-ins are any less useful; rather, they may simply take a few extra lines of code to achieve the same result, which will generally run as fast as most complete code.

The book can be dipped into required because each chapter is contained—when you have a particular problem to solve, you can refer to the relevant chapter and it will be all that you need.

# About JavaScript

The JavaScript programming language is already over 15 years old and is more popular than ever. Written by Brendan Eich at Netscape and previously known as Mocha and LiveScript, JavaScript was first incorporated into the Netscape Navigator browser in 1995, the same time that Netscape added support for Sun's Java technology.

JavaScript is a quite different language from Java, as part of a marketing deal between Netscape and Sun Microsystems, it given its name to benefit from the general buzz surrounding the Java language. To justify this naming, all Java keywords are reserved in JavaScript, its standard library follows Java's naming conventions, and its Math and Date objects are based on Java 1 classes. the trademark "JavaScript" now belongs to Oracle Corporation—but the similarities end there.

# Plug-in JavaScript: 100 Solutions

Microsoft's version, called JScript, was released year later as a component of Internet Explorer 3, as you might expect, it differed in several important respects, making it less 100 percent compatible with JavaScript. Unfortunately, remains true to this day, as you will see some of these plug-ins that work differently depending on which browser they find themselves running in.

Unlike languages used for creating websites, such as Perl, PHP, and Ruby, JavaScript runs within the web browser, not on a server. This makes it the perfect tool for creating dynamic web pages which it can modify HTML elements in real time. It is also the technology behind Web 2.0 Ajax functionality, in which data is transferred between a web server and web browser scenes without the user being aware of it.

As you will learn in Chapter 2, JavaScript's great power lies in its ability to access the HTML Document Object Model (DOM), in which every element a web page can be individually addressed (either reading or modifying its value), and elements can also be created and deleted on the fly, as layered over each other and moved. You can go so far as treat a web browser as a blank canvas and build applications and games from scratch using JavaScript and the DOM (although doing so takes some quite advanced programming skills).

Because Oracle the trademark to its name, JavaScript has officially been known as ECMAScript since the language was submitted to ECMA, the European Computer Manufacturers Association (a nonprofit standards organization).

# JavaScript Frameworks

With recent steps towards standardization, different browser developers implement JavaScript in slightly different ways, giving rise to the plethora of JavaScript frameworks now available such as jQuery, Yii, Moo, and so on. These technologies handle all the inconsistencies for you, providing a set of functions you can call without worrying about browser differences.

The plug-ins in this book provide much of the functionality of these frameworks without actually this framework. Procedural programming techniques make it easy to use and understand their workings. And although, plug-ins are also interconnected and draw on each other's features, it's possible to just use a plug-in and its dependencies to a web page. On the other hand, with the major frameworks it's quite difficult to extract the functions you need.

Although at around 25Kb for the compressed file containing all the plug-ins, the tiny amount of bandwidth used means you probably never want or need to extract just a few functions: you can simply drop the link to any web page to access all the plug-ins.
