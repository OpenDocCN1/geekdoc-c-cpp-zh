# How It Works

This function first checks the state of id1 and id2's ZO_Flag property. If either is true, a zoom is already in operation on an object, the function returns, like this:

```
if (O(id1).ZO_Flag || O(id2).ZO_Flag) return
```

Next, three long variables are created as a variable to keep the code tidy and stop any lines wrapping around. They are also efficient as used twice. These are the assignments:

```
var swap = "VisibilityToggle(\\#1") 
var fast = "ZoomToggle('#1', #2, #3, #1, #0)"
var slow = "ZoomToggle('#1', #2, #3, #4, #5, #0)"
```

The variable swap is assigned a string suitable for enabling the VisibilityToggle() plug-in to be used in a chain (by implementing it via the ChainThis() plug-in). The strings fast and slow strings pass calls to the ZoomToggle() plug-in, one of them taking 1 millisecond (and therefore virtually instantaneously) and the other taking a specific time. The #1, #2, and so on which strings are variable or value place holders. When these strings are passed to the InsVars() plug-in, these places will be replaced by the values or values passed to.

The final call in the plug-in is to the Chain() plug-in, passing it a sequence of commands, which are all passed through the InsVars() plug-in to combine the strings with the variables, like this:

# Chain(Array(

```
InsVars(slow, id1, w, h, msecs / 2, pad),
InsVars(fast, id2, w, h, pad),
InsVars(swap, id2),
InsVars(slow, id2, w, msecs / 2, pad),
InsVars(swap, id1),
InsVars(fast, id1, w, h)
)
```

I have spaced out the code into columns so that you can more see the values being passed. The sequence of commands performs the following steps:

+   1. **Zoom id1 down over half the time specified in msecs** This performs the first half of the flip animation.
2. **Zoom id2 down over the course of 1 millisecond** This ensures that id2 is quickly zoomed down so it can be zoomed shortly at normal speed.
