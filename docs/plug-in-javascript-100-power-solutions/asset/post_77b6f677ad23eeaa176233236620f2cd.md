## 25 GetWindowWidth()

There are many reasons to need to know the width of the browser, the most obvious of which is that you can determine where in Figure 4-7. This plug-in also takes into account scroll bars the available width.

## Variables, Arrays, and Functions

| Variable | Description |
| :--- | :--- |
| de | Local object of document.documentElement |
| BROWSER | Global variable containing the browser name |
| barwidth | Local integer set if scroll bar exists |
| scrollHeight | The.scrollHeight property |
| clientHeight | The.clientHeight property |
| innerWidth | The window.innerWidth property |

## How It Works

This plug-in first copies the document.documentElement to provide a much shorter name, Next, if the browser is not Internet Explorer by the value in global variable BROWSER, then the local integer barwidth is set to 17 if de.scrollHeight is greater than de.clientHeight. This value is subtracted from the full window width and the result is returned.

Otherwise, as is often the case if the browser is Internet Explorer, the code simply returns the value of whichever has a value, either de.clientWidth or document.body.clientWidth (allowing for strict or quirks mode).

## How To Use It

To use this plug-in, simply call it and use the value returned, as in the following example, which passes the returned value to an alert statement, where it is displayed:

```html
<script>

  alert('This browser has a window width of: ' + GetWindowWidth())
}
</script>
```

## The Plug-in

```javascript
function GetWindowWidth() {
  var de = document.documentElement

if (BROWSER != 'IE') {
    var barwidth = de.scrollHeight > de.clientHeight ? 17 : 0
    return window.innerWidth - barwidth
  }

return de.clientWidth || document.body.clientWidth
}
```
