For this example I set the horizontal w argument of the calls to 0 so that only the height of the objects is allowed to be resized. This has effect of making the icons appear to spin around their horizontal axes if you let them all down and back up. You could alternatively set the vertical h argument to zero instead (but not both), and then the icons would appear to spin around their vertical axes.
