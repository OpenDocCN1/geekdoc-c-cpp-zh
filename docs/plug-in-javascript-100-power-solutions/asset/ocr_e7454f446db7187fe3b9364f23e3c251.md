```
<script>
window.onload = function() {
  headings = Array('h1', 'h2', 'h3', 'h4');
  contents = Array('c1', 'c2', 'c3', 'c4');

  FoldingMenu(headings, contents, 'click', 'inflate', 0,1,200,300,1);
}
</script>
```

I designed this and other plug-ins in such a way that they do not rely on using CSS other than what you want. Of course, CSS can be used to apply different styles when the mouse passes over, but the goal of this is to enable you to set up objects in standard HTML with a small section of JavaScript.

Therefore, the HTML in this example creates four headings, each of which has a section of links underneath, although contents could be any HTML or objects, such as images and on. In addition to the four sections, there are four contents sections.

I have specifically chosen spans here because browsers automatically know their dimensions based on content. Div are different in that their width is infinite (at least to the browser edge), you cannot define a div's width unless you use it, for example, using the plug-in.

After this, msec1 and msec2 are 200 and 300 so that popping down will take 200 milliseconds and popping up will take 300. This provides a more interesting effect than if they are the same values. I recommend you altering them yourself, giving first msec1 the larger value and then msec2. You will find you can create a wide range of interests.
