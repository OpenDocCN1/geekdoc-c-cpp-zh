Finally, Microsoft chose a more complicated approach and includes opacity as part of theirstandard and transparency group of features. The object's filter property is set in the following manner (for a setting of 25 percent, example):

```
S(id).filter = 'alpha (opacity = 25)'
```

However, because you need to take into account the fact that id could be an array, the following version of it is made, with both the property and setting values passed to the S() plug-in:

```
S(id, 'filter', 'alpha (opacity = 25)'
```

Also, rather than a numeric value, a string has to be assigned to the filter property which requires construction. So, in order to place the value in percent in the string, the following code is used (employing the InsVars plug-in from Chapter 3):

```
S(id, 'filter', InsVars("alpha (opacity = '#1#')", percent))
```

# How To Use It

To change an object, opacity just it with the object or its ID (or an array of objects and/or ids). You can use a JavaScript command like this:

```
Opacity('faded', 64)
```

Or, you can embed the call within HTML, as in the following example, which creates three clickable buttons:

```
<center>
<input type='submit' value='25 percent' onclick='Opacity(this, 25)' />
<input type='submit' value='50 percent' onclick='Opacity(this, 50)' />
<input type='submit' value='75 percent' onclick='Opacity(this, 75)' />
</center>
```

When clicked, the different buttons will change the opacity of the assigned amount (25 percent, 50 percent, or 75 percent, respectively). Notice that none of these HTML elements have been assigned IDs because the keyword this has been passed to the Opacity() plug-in, thus taking advantage of the fact that this plug-in (like most of them) will accept either an object ID or an object. This keyword directly passes the calling object to the function, which is why no ID is required.
