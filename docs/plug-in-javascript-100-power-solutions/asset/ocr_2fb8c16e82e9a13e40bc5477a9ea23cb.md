The final path argument specifies which part of the server the cookie applies to. The value of '/' means everywhere, from the document upward, you can access the cookie. However, you can restrict the scope by, for example, changing the path to a subfolder such as '/chat'. You can simply omit the same scope as if it had the value '/'. If you do so, you can also shorten the cookies used to read and erase the cookie, like this:

```
value = ProcessCookie('read', 'password')
ProcessCookie('erase', 'password')
```

Remember that the path (or no path) you must be the same for all accesses to the cookie, otherwise you will not be able to read and write it. You will probably not need to use the domain and secure arguments, is why I omitted from the preceding examples, but if you do they are available.
's an example that lets you test that cookies are being reliably transferred:

```
<script>
window.onload = function() {
  value = ProcessCookie('read', 'username')
  if (value) alert('The returned for username is: ' + value + ')')
  else alert('The username has no value.')

  alert('Click OK to store cookie 'username' with the value 'fred')
  ProcessCookie('save', 'username', 'fred', 60 * 24)

  alert('Click OK to retrieve the cookie')
  value = ProcessCookie('read', 'username')

  if (confirm('The returned for :username is: ' + value + '\n\nNow, either [OK] to delete the cookie, and then' + +
  'reload the page to see if the cookie has been erased.\nnOr ' + +
  'click [Cancel] to do nothing, and then reload the page to ' + +
  'see if it has retained its value.\n')) {
    ProcessCookie('erase', 'username')
  }
}</script>
```

This JavaScript fetches the cookie 'username' and if it has a value, it is displayed.
The first time you load this page, it won't exist so you will see an alert pop up and tell you so.

Next, the cookie is created and assigned the value 'fred', with alert messages before and after so you can see the result of each action.
Finally, a confirm dialog is called up in which you can either the OK button to erase the cookie or the Cancel button to leave it alone. I suggest you click OK and then reload the page to see that the cookie has been erased. Then follow through the alerts again, but this time click the Cancel button and reload the page, and see that the cookie's value has been retained.
