# How It Works

This plug-in creates a new div for each tooltip, or an id comprising the string TT_ and the ID name, and then creates a local variable to hold this ID, like:

```
var tt = 'TT_' + O(id).id
```

Next, if the div for the tooltip hasn't been created, this is done using the following code:

```
var newdiv = document.createElement('div')
newdiv.setAttribute('id', tt)
document.body.appendChild(newdiv)
```

The opacity of the new div is set to 0 to hide it, and it is released by giving it a style position attribute of 'absolute', using the global ABS:

```
Opacity(tt, 0)
Position(tt, ABS)
```

Next, all the arguments are default values for any that have not been given value:

| font = font ? font : 'Arial' |
| size = size ? size : 'small' |
| textc = textc ? textc : '#884444' |
| backc = backc ? backc : '#ffff88' |
| bordc = bordc ? bordc : '#aaaaaa' |
| bstyle = bstyle ? bstyle : 'dotted' |
| width = width ? width : 1 |
| msecs = msecs ? msecs : 250 |
