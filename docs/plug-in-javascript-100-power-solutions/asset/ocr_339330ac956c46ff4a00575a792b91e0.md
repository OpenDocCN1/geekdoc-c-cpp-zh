# The Plug-in

```
function Invisible(id)
{
  S(id, 'visibility', HID)
}
```

# Visible()

This is the partner plug-in to Invisible(). It makes a previously invisible object visible. Figure 5-3 expands the example in the previous plug-in. Now, when the alert message's OK button is clicked, the invisible text will reappear and the browser will look like Figure 5-1 again (but without the alert window).

# About the Plug-in

This plug-in makes an object visible after it has been made invisible. It requires the following:

+   - id object, an object ID, or an array of objects/or object IDs

# Variables, Arrays, and Functions

| visibility | The style.visibility property of the object(s) |
| VIS | Global variable with the value 'visible' |

# How It Works

This plug-in makes a call to the S() plug-in in such a way that you can pass an array of objects/or object IDs, a single object, or an object ID. The style.visibility property of the object (or objects) is set to the global variable VIS, which is 'visible'.
