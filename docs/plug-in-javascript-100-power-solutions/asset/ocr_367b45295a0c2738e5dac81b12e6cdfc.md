# About the Plug-in

This plug-in creates an Ajax object ready for making background calls to the web server. It requires the following arguments:

+   * id An object or id—this may not be an array
* callback The function to pass the returned data to once it has been retrieved

# Variables, Arrays, and Functions

| | Local Ajax object |
| readyState | Property of ajax containing its state |
| status | Property of ajax containing its status |
| responseText | Property of ajax containing the text returned by the Ajax call |
| XMLHttpRequest | Function used by non-Microsoft browsers to create an Ajax object |
| ActiveXObject() | Function used by Microsoft browsers to create an Ajax object |
