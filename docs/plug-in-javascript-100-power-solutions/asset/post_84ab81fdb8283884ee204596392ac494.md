# DeflateToggle()

If you use this plug-in, you don't need to keep track of which objects have or haven't been deflated, and it saves on extra code, too. In Figure 6-5 the example in the Relate() plug-in in section has been updated to use this plug-in.

# About the plug-in

This plug-in toggles an object between deflated or inflated. It takes the following arguments:

- An object, an object ID, or an array of objects and/or object IDs
- If true or 1, the object's width will deflate or replate own- If true or 1, the object's height will deflate or replate
- The number of milliseconds the animation should show
- interruptible If true (or 1), this plug-in can be interrupted by a new call on the same object; otherwise, if false (or 0), the call is uninterrupted

# How It Works

This-plugin uses the standard recursive techniques of the others to determine whether id is an array and if it is, to pass each element of the array recursively back to the same function to be dealt with individually, as follows:

```javascript
if (id instanceof Array)
{
  for (var j = 0; j < id.length; ++++)
    DeflateToggle(id[j], w, h, msecs, interruptible, CB)
  return
}
```

After there are two cases, the first of which tests the Deflate property of id. If it is true, the object has (or is in the process of being) deflated, so the Reflate () plug-in is called. Otherwise, the object is inflated (or in the process of being reinfl), so the Deflate () plug-in is called, like this:

```javascript
if (O(id).Deflated) Reflate(id, w, h, msecs, interruptible, CB)
else Deflate(id, w, h, msecs, interruptible, CB)
```
