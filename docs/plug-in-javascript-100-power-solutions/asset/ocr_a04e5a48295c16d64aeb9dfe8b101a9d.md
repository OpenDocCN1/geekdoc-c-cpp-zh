# Deflate()

With this plug-in you can make an object shrink down over time until it is no longer visible. You can also specify whether to deflate (or shrink) the width, height, or both. Figure 6-3 shows three images, each of which is in the process of being deflate with this plug-in. The first is shrinking horizontally, the last vertically, and the middle one is deflating both dimensions.

# About the Plug-in

This plug-in takes an object and over a specified time period shrinks down until it is no longer visible. The following are the required arguments:

+   * id An object, an object ID, or an array of objects and/or object IDs
* w If true or 1, the object's width will shrink
* h If true or 1, the object's height will shrink
