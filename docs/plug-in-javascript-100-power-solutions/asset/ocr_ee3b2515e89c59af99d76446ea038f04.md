After these first ten global variables, a further ten string variables are defined. These are UND, HID, VIS, ABS, FIX, REL, STA, INH, TP, BM, LT and RT, and in order they for the strings 'undefined', 'hidden', 'visible', 'absolute', 'fixed', 'relative', 'static', 'top', 'bottom', 'left' and 'right'.

They are not essential, but I created these variables because the strings to which they are referred frequently by the plug-ins, and this helps to keep the code more compact. It also serves to make the listings in this book narrower, so that lines that might have wrapped around now on a single line. Additionally, they help to make the code more readable, as long you refer back to this section if you forget the values of any of them.

# Determining the Current Browser

Because JavaScript varies in its implementation between different developers, you sometimes need to know which browser you are dealing with. So, in conjunction with the subfunction NavCheck(), the next ten lines of code will set the global BROWSER to one of the following strings, depending on the browser used: 'IE', 'Opera', 'Chrome', 'iPod', 'iPhone', 'iPad', 'Safari', 'Firefox', and 'UNKNOWN'. You can then refer to this variable in some way that the plug-ins do in order to offer different browsers. When 'Firefox' is returned it means a browser running on the Gecko rendering engine is in use, which includes other browsers than Firefox.

# Attaching Functions to Events

Much of the functionality of these plug-ins rests on the capturing of built-in browser events, as is done by the remaining seven lines of code. The first three CaptureMouse() function to the document.onmousevent, and the CaptureKeyboard() function to the document.onkeydown and document.onkeypress events. These plug-ins are documented in their own sections, but it suffices to say that they are called each time of these events occurs and they keep the global variable KEY_PRESS updated.

The final four lines attach functions that are so small that I have created them as anonymous, inline functions. All they do is capture the document.onmouseover, document.onmouseover, document.onmouseup and document.onmousedown events, keeping the global variables MOUSE_IN and MOUSE_DOWN updated.
