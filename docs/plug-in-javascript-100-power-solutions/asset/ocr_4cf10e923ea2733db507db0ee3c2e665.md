First, the array temp is assigned a copy of calls, then the concat() function merges the contents of temp with calls, until there are number copies altogether. Finally, the Chain() plug-in is called to start the first call running.

# How To Use It

Using this plug-in is the same as calling Chain() except that you also pass an additional parameter to specify the number of times the chain should repeat.
The following example slightly modifies the one in the Chain() and NextInChain() plug-ins section to make the bounce around the browser 10 times:

```
<img id='ball' src='ball.png' />

<script>
window.onload = function() {
  Position('ball', ABS)
  width = GetWindowWidth()
  height = GetWindowHeight()
  r = width - 100
  b = height - 100
  x = width / 20
  y = height / 50

  ch1 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', 0, y, x, 0)
  ch2 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', x, 0, r, y)
  ch3 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', r, y, x, b)
  ch4 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', x, b, 0, y)

  Repeat(10, Array(ch1, ch2, ch3, ch4))
}
</script>
```

# The Plug-in

```
function Repeat(number, calls) {
  var temp = calls

  for (var j = 1; j < number ; ++j)
    calls = calls.concat(temp)

  Chain(calls)
}
```

# While()

Sometimes you might find it convenient for a chain of plug-ins to keep repeating while a certain condition is true; for example, if no key has been pressed or the mouse hasn't been clicked. With this plug-in you can supply a test condition along with a chain, and as long as the condition returns true, the chain will keep repeating.
