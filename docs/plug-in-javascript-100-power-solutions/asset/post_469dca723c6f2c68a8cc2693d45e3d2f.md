## Objects as well as images

Although to give best results, you can pass any kind of object such as a div or table to the Flip() plug-in. This means you can, for example, an e-mail button that flips when the mouse passes over it to reveal a small form for entering your e-mail address to subscribe to newsletters. If you do this, text will flow out of the object that rotates away so you get a slightly different effect.

You can use Flip() to swap sections of HTML according to the selection of radio button and don't forget that you can flip objects horizontally and vertically, or you can even do both at the same time to create a zoom-back-and-again effect. By changing the values in Flip() calls of the last two lines see what different results you get.

Note using objects that have odd value for one or more dimensions may see a slight jitter occur horizontally or vertically during flip. This happens because there are differences between the way different browsers handle fractional numbers and is fixed by the flip-in the object's positions before restoring afterwards. Even though it's almost imperceptible, if you wish to avoid this disturbance you should only work with dimensions that have even values. It's easy to ensure this with a call to Resize() prior to using Flip().

## HoverSlide()

This plug-in places an object on one edge of the browser with a small portion of it revealed and remained hidden. When you pass your mouse over it, the object slides out into the window to reveal itself and then slides back when you move the mouse. ## The Plug-in

This plug-in places an object across one edge of a browser boundary with most of it unseen, outside the browser, and a small area showing that you can pass the mouse to move the object slide and out. It requires the following arguments:

- Either an or an object ID—this cannot be an array of objects
- The edge to which the object should be attached ‘top’, ‘left’, ‘right’, and ‘bottom’

- offset the amount by which the object should be offset from the left or top of the edge—if offset is a number, the amount is an exact offset in pixels, but if it is a string fetched with a % symbol (such as "%50"), then the object is to be placed along the edge showing the number of pixels by which the object must poke into the browser
- msecs The number of milliseconds it should take for the object to slide in or out

## How It Works

This plug-in begins by finding the farthest position along an edge that id can be placed, using the browser width, subtracting it, and the variable h. Here is how the code does:

```javascript
var w = GetWindowWidth()
var h = GetWindowHeight()
```

Next, the variable o is set to zero if offset is a number (in other words, an absolute offset if the edge was requested), or if offset is a string beginning with % character, o gives the percentage along the edge the object should be.

```javascript
var o = offset[0] != '%' ? 0 : offset.substr(1) / 100
```

## If the Left or Right Edge Has Been Chosen

Next, the plug-in needs to determine which edge is going to be used, so first tests the value against the global variables LT and RT. If it is one of these, the following code is executed:

```javascript
var t = W(id)
var u = Math.min(t, msecs / INTERVAL)
var x = where == LT ? -t : w + t
var y = o ? h * o : offset
var s = t / u
```

This assigns the amount of id that's not shown by default to t, then u is assigned the number of steps required to make the animation last msecs milliseconds. After this, the x and y coordinates again to see if they 'left'. If it does, means the left edge is used, so x is set to -t, which places id sufficiently off scroll so that showing pixels of the object are visible. Otherwise, x is set to move the object off the right hand of the screen in a s of similar fashion.

The variable y is similarly calculated, being set to the value in offset if o is zero (in other words, an absolute offset if the edge was requested), or set to h * o because o is a fractional value representing the percentage along the edge the object should be, and h is the maximum distance that the edge may appear near.

Finally, s is the distance by which id should be moved for each frame of a slide, is calculated by dividing t (the amount of id that's not shown by default) by u (the number of steps required to make the animation last msecs milliseconds).
