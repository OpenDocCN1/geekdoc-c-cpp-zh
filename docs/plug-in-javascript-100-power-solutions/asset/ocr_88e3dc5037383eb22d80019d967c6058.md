# 71 TextType()

This plug-in emulates an old-fashioned typewriter or a teletype machine by outputting the text contents of one character at a time, over a period of time specified by you. Figure 9-2 shows a phrase being displayed with this plug-in.

About the Plug-in
This plug-in takes an object that contains text and displays it one character at a time. It requires the following arguments:

+   - An object, object ID, or array of objects and/ object IDs
- number The number of times to repeat, with 0 indicating infinite repeats
- msecs The number of milliseconds that it should take to type out the text
