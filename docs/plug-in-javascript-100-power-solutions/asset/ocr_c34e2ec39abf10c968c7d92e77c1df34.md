BWToFront() and BWCloseWindow() Subfunctions
BWToFront() function simply changes the zIndex property of the pop-up so that it is brought to the front, like this:

```
S(id).zIndex = ++ZINDEX
```

Every time an in-browser window as id is clicked, this function is called, moving it to the front, and updating the value in ZINDEX.
BWCloseWindow() function pops the pop-up down, like this:

```
PopDown(id, type, w, h, msecs, interruptible)
```

# The BWMove Subfunction

The job of this function is to prepare the pop-up for being dragged around. First, the pop-up is brought to the front with a call to BWToFront() and the cursor is changed to the operating system's icon for moving a window, like this:

```
BWToFront().cursor = 'move'
```

Next, it makes copies of the difference between the top left corner of the pop-up and the current mouse position, placing them in xoffset and offset, and setInterval is called to keep repeating interrupts to the BWMove() sub-function every 10 milliseconds to allow the object to be dragged around, as follows:

```
var xoffset = MOUSE_X - X(id)
var offset = MOUSE_Y - Y(id)
var id = setInterval(BWMove, 10)
```

# The BWMove() Sub-function

This function actually moves the pop-up about. It starts by giving the local variables x and y the difference between the current mouse location and the location that was stored in xoffset and offset when BWMove() was initially called, like this:

```
var x = MOUSE_X - xoffset
var y = MOUSE_Y - yoffset
```

Then the arguments is tested. If it is true or 1, the pop-up must stay within the main browser window, and the farthest horizontal and vertical locations the pop-up may go to be placed in the local variables x and y (for right and bottom). These values are used to calculate the pop-up stays in bounds, like this:

```
var r = browserWidth - border + SCROLL_X
var b = browserHeight - border + SCROLL_Y
x = Math.max(0, Math.min(x, r))
y = Math.max(0, Math.min(y, b))
```
