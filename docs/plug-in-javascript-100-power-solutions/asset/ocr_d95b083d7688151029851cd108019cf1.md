The main benefit of using this plug-in with FadeOut () is that they require
fewer arguments than the Fade (), in are easier to remember, and are shorter. They are
also used by the next two plug-ins, which toggle an object between faded out or
and fade smoothly between two objects, respectively.

# The Plug-in

```
function FadeIn(id, msecs, interruptible, CB)
{
  Fade(id, 0, 100, msecs, interruptible, CB)
}
```
