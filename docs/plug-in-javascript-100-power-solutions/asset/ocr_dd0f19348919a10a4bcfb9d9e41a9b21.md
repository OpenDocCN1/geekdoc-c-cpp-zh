By setting the multi argument, each onmouseover or onclick event of a heading will toggle the pop-up or pop-down state of the associated contents object with the PopToggle() plug-in, like this:

```
if (multi) PopToggle(this.FO_C, type, w, msecsl, interruptible)
```

If multi is not set, then one contents object can be popped up at a time, when a new one is to be popped the previously popped up object must be popped. This is worked out by iterating through the headings in a for() loop, like this:

```
for ( j = 0; j < headings.length; ++j)
if (O(headings[j]).FO_C.PO_IsUp && O(headings[j]) != true)
PopDown(headings[j]).FO_C, type, w, msecsl, interruptible)
```

The variable j iterates through each element in the headings array and checks one's contents object popped up, so the heading is compared with this, which refers to the current heading if PO_IsUp is true or 1, the contents object is currently popped up, so the heading was either clicked or the mouse passed over it. If they match, they are the same and nothing happens the currently selected contents object will be set to a popped state a couple of lines later in the code.

However, if the contents object that has been found to be popped up is different from the current heading's contents object, it is the one that was previously popped up, so it is popped down with a call to PopDown(). The timing used here is from the argument msecsl.

Finally, the currently selected contents is set to a popped state (if it isn't already popped up), like this:

```
if (!this.FO_C.PO_IsUp)
PopUp(this.FO_C, type, w, msecsl, interruptible)
```

This pop-up action has its own time setting in msec2 so that different effects can be achieved by using different values for msec1 and msec2.

# How To Use It

There are two ways to use this plug-in. The first is within an accordion or folding menu, and the other is to separate the headings from the contents to control the objects in a different place from the displayed contents. The first is most suited to being operated by mouse clicks, as the transitions occur, new elements could pass under the mouse cursor, or if onclick were used, unwanted selections can be made.

Here's an example of an accordion-style menu driven by mouse clicks:

```
<span id='hl1'>&lt;b&gt;News&lt;/b&gt;&lt;br&gt;/div id='cl1'>
&amp;nbsp; <a href='local.html'>Local News&lt;/a&gt;&lt;br /gt;
&amp;nbsp; <a href='world.html'>World News&lt;/a&gt;&lt;br /gt;
```
