# The Document Object Model (DOM)

The Document Object Model (DOM) separates the different parts of an HTML document into a hierarchy of discrete objects, each having its own properties and methods. Methods are functions that can do something with an object, while properties are attributes of an object such as the value it holds in the case of a text object, or width and height in case of an image, and so on.

The outermost object is the window object, which is the current window, tab, or popped up. Underneath is the document object, of which can be more than one (such as several documents loaded into different frames within a page). Inside a document there are other objects such as the head and body of a page.
