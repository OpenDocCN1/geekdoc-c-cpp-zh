```
<script>
window.onload = function() {
  Locate(Array(['b1', 'b2', 'b3', 'b4', 'b5'], 'absolute', 2, 50));
  Locate('p1', ABS, 330, 50);
  Locate('p2', ABS, 330, 55);
  Locate('p3', ABS, 340, 60);
  Locate('p4', ABS, 345, 65);
  Locate('p5', ABS, 350, 70);

  swap('m1', 'b1');
  swap('m2', 'p2', 'b2');
  swap('m3', 'p3', 'b3');
  swap('m4', 'p4', 'b4');
  swap('m5', 'p5', 'b5');

  function swap(o1, o2, o3) {
    o1.onmouseover = function() { SlideBetween(o2, o3, 200, 1) };
    o1.onmouseout = function() { SlideBetween(o2, o3, 200, 1) };
  }
}
</script>
```

The HTML section of this example displays some text and five headings that describe five photographs. Each heading is given an ID and placed in its own span. Underneath, five div objects are created with these IDs. These are used as objects with to swap the photographs. Finally, the photographs are displayed, with each having a unique ID assigned to it.

In the <script> section, the first statement sets all the blank divs to have a position property of 'absolute' and places them all at the location 250. The photos are also made 'absolute' and placed in their locations. I chose slightly different coordinates to show them as a stack of images.

After this call, a new function swap () is added to attach the image's mouse events. The swap function takes three arguments, o1, o2, and o3, for the three objects to pass. It o1 is one of the headings, which has its onun and onmouseout attached by inline, anonymous functions that call the SlideBetween() plugin-in, passing o2 (the two objects to swap) and, a time of 200 milliseconds that the swap should take.

All this has the effect of swapping a photo with its blank div when the mouse passes over it. It swaps back when the mouse passes over of the heading. The final argument passed to SlideBetween() is a 1, the animations are interruptible, so if you move the mouse away before a picture has finished sliding, it will simply slide back to its position in the stack of images.

I have deliberately given you the guts of how this works so you can see how to easily create your own functions. With suitable CSS and graphics, you can use these techniques to create very impressive dynamic effects.
