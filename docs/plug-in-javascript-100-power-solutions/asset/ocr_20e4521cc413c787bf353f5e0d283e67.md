How It Works
plug-in has the usual code at the start that iterates through id if it is an array and
cursively passes each element back to itself to be dealt with individually, as follows:

```
if (id instanceof Array {
  for (var j = 0 ; j < id.length ; ++j)
    PopUp(id[j], type, w, h, msecs, interruptible)
  return
}
```

Next, the object will previously have been hidden using the Hide() plug-in, it is
shown by calling Show():

Show(id)
This is all that needs to be done at this point if it is 'instant'. If it isn't, a group of
if() else statements call the FadeIn(), Reflate(), or ZoomRestore()
plug-ins, depending on the value in this time, as:

```
if (type == 'fade')
  FadeIn(id, msecs, interruptible)
else if (type == 'inflate')
  Reflate(id, w, h, msecs, interruptible)
else if (type == 'zoom')
  ZoomRestore(id, w, h, msecs, l, interruptible)
```

Finally, the PO_IsUp property of id is set to true to indicate to other plug-ins that the
object is (or in the process of being) popped up.

O(id).PO_IsUp = true

How To Use It
Use this plug-in in the same manner as PopDown() to restore an object to its original
state. Following is an example that shows how the PopDown() plug-in to make the image
pop down and up again:

```

<span id='14'>Image 4</span> |

```
