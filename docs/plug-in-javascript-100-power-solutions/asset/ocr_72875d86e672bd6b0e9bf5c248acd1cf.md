# Chapter 10: Audio and Visual Effects 307

**FIGURE 10-4**
This plug-in makes it easy to create charts from collections of data.

![](bbox=[0.303, 0.103, 0.843, 0.396])

+   - **tsize** The title size
- **type** The chart of any, of 'line', 'vbar', 'hbar', 'gometer', 'pie', 'pie3d', 'venn', or 'radar'—see Table 10-1 for more details (and see Figure 10-5 for some example chart types)
- **b** The bar width if the chart is a bar chart
- **labels** A string of data labels, separated by |
- **legends** A string of data legends, separated by |
- **colors** A string of colors, for each item of data, in six digit hex values, separated by commas
- **bgfill** The background color as a six-digit hex string
- **data** The data, as a string of numeric values, separated by commas

TABLE 10-1
| Type value | Chart type |
| --- | --- |
| 'line' | Standard line chart |
| 'vbar' | Vertical bar chart |
| 'hbar' | Horizontal bar chart |
| 'gometer' | Google Go Meter |
| 'pie' | Standard pie chart |
| 'pie3d' | 3D pie chart |
| 'venn' | Venn diagram |
| 'radar' | Radar chart |
