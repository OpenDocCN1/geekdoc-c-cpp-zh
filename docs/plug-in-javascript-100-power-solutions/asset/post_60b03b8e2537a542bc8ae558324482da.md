
## Repeat()

As well as chaining plug-ins together, you can make one or more plug-ins repeat a specified number of times using the Repeat() plug-in. In a medium such as it's not possible to capture the motion in these examples, so Figure 7-2 shows the ball (slightly grayed out) as it was captured on different repetitions of an animation created using this plug-in.

## About the Plug-in

This plug-in allows you to repeat a chain of actions as many times as you like. It requires the following arguments:

- *number*: The number of times the chain should be repeated
- *calls*: An array of strings containing a sequence of plug-ins to call

## Variables, Arrays, and Functions

| Variable | Description |
|---| j | Local variable used for counting the repeats |
| temp | Local copy of the calls array |
| concat() | Function to merge two or more arrays |
| Chain() | Plug-in used to chain a group of plug-ins together |

## How It Works

This plug-in takes the calls array and duplicates it enough times so that there are number copies of the calls, like this:

```
var temp = calls
for (var j = 1 ; j < number ; ++j)
  calls = calls.concat(temp)
Chain(calls)
```

![](img/95e4c43b430487125c342550cc090977_202_0.png)

First, the array temp is assigned a copy of calls, then the concat() function merges the contents of temp with calls, until there are number copies altogether. Finally, the Chain() plug-in is called to start the first call running.

## How To Use It

Using this plug-in is the same as calling Chain() except that you also pass an additional parameter to specify the number of times the chain should repeat. The following example slightly modifies the one in the Chain() and NextInChain() plug-ins section to make the bounce around the browser 10 times:

```html
<img id='ball' src='ball.png' />

<script>
window.onload = function() {
  Position('ball', ABS)
  width = GetWindowWidth()
  height = GetWindowHeight()
  r = width - 100
  b = height - 100
  x = width / 20
  y = height / 50

  ch1 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', 0, y, x, 0)
  ch2 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', x, 0, r, y)
  ch3 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', r, y, x, b)
  ch4 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)*', x, b, 0, y)

  Repeat(10, Array(ch1, ch2, ch3, ch4))
}
</script>
```

## The Plug-in

```javascript
function Repeat(number, calls) {
  var temp = calls

  for (var j = 1; j < number ; ++j)
    calls = calls.concat(temp)

  Chain(calls)
}
```

## While()

Sometimes you might find it convenient for a chain of plug-ins to keep repeating while a certain condition is true; for example, if no key has been pressed or the mouse hasn't been clicked. With this plug-in you can supply a test condition along with a chain, and as long as the condition returns true, the chain will keep repeating.

## About the Plug-in

This plug takes an expression and an array of statements to chain if the expression evaluates to true. It requires the following parameters:

- *expr*: A string containing an expression that can be evaluated to true or false
- *calls*: An array of strings containing a sequence of plug-ins to place in the chain

## Variables, Arrays, and Functions

| Variable | Description |
|---|---|
| temp | Local string variable used for reconstructing a string from the array in calls |
| j | Local variable for iterating through the calls array |
| eval() | Function to evaluate a JavaScript expression |
| replace() | Function to replace parts of a string |
| substr() | Function to return part of a string |
| push() | Function to push a value onto an array |
| InsVars() | Plug-in for inserting values into a string |
| Chain() | Plug-in for chaining sequences of plug-ins together |

## How It Works

This plug resides within an if statement and completes only if the string passed in expr evaluates to true, like this:

```javascript
if (eval(expr))
```

What is the logic of the While() plug-in? Let's look at the code. The plug-in takes an expression and an array of statements to chain if the expression evaluates to true. It requires the following parameters:

- *expr*: A string containing an expression that can be evaluated to true or false
- *calls*: An array of strings containing a sequence of plug-ins to place in the chain

This plug-in resides within an if statement and completes only if the string passed in expr evaluates to true, like this:

```javascript
if (eval(expr))
```

The logic of the While() plug-in is to check the expression, and if it is true, it executes the chain of calls. Then it checks the expression again. This continues until the expression evaluates to false.

Here is the code for the While() plug-in:

```javascript
function While(expr, calls) {
  while (eval(expr)) {
    Chain(calls)
  }
}
```

In the example below, the expression is `KEY_PRESS == 0`. As long as the user has not pressed any key, the animation will continue.

```javascript
While("KEY_PRESS == 0", Array(Slide('ship', 1, 2, 3, 4, 500, 0), FadeOut('ship', 1, 2, 3, 4, 500, 0)))
```

This shows how the While() plug-in can be used to create a loop that continues until a certain condition is met.
