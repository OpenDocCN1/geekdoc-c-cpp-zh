Usually, if the first argument is an array the second argument, a single object, is assigned to all elements of the array, but this plug-in requires either two object or two arrays.
In the former case, the first object is rolled over with the second. In the latter case, each element of the first array will roll over with each matching element in the second array.
The few lines of code facilitate recursively passing on the elements of both arrays to be processed as individual items (there is no error checking, make sure you pass two matching arrays or objects):

```
if (rol instanceof Array)
{
    for (var j = 0; j < id.length; ++j)
        RollOver(rol[j], ro2[j])
    return
}
```

Next, the local array is assigned elements rol1 and ro2 to make them easier for later to access them. The width and height and vertical locations of the objects are saved in the local variables w, h, x, and y, like this:

```
var a = Array(rol, ro2)
var w = W(rol) + 1
var h = H(rol) + 1
var x = X(rol)
var y = Y(rol)
```
