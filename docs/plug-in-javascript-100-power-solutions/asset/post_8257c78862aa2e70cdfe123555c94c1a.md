## The ChainThis() plug-in

This plug-in allows you to take a plug-in or function that is not chainable (which you can determine by checking Table 7-2) and use it within a chain. The code is simple like this:

```
eval(expr)
NextChain()
```

For example, suppose that for one of the instructions in a chain you want to move using the following statement:

```
Goto('myobject', x / 2, y + 100)
```

You can also chain this by turning it into a string, using the InsVars() plug-in and ChainThis(), as follows:

```
string = InsVars("ChainThis(\"myobject\", #1, #2)", x / 2, y + 100)
```

The InsVars() plug-in makes it easy to insert variables into a string using tokens such as #1 and #2 as placeholders for them and passing the variables or expressions after the main string.

If you pass the string string to Chain() or Repeat or While() as one of the elements in a chain, the Goto() call will be executed when its turn comes up, and the program flow will pass onto the next item in the chain (if any).

## How To Use Them

To use the Chain() plug-in, you need to create an array of plug-in chains to be chained together, and each call must be assembled into a string before it is placed into the array. For example, assume you want to add the following to a chain to:

```
FadeOut(myobject, 1000, 0)
```

To do, you must first convert it to a string, like this:

```
string1 = 'FadeOut(' + myobject + ', ' + 1000, 0)'
```

Or, if you have a more complicated call, like this:

```
Slide('a', width / 2, height / 2 - 50, width / 2 -20, height / 2, 500, 0)
```

then it would need to be turned into a string, like:

```
string2 = "Slide(' + a + \', ' + width / 2 + \', + height / 2 - 50 + \', ' + width / 2 - 29 + \', ' + height / 2 - 500, 0) + "
```

Obviously this quite gets very messy, it's almost much easier to make use of Plug-in 15, InsVars(), in these two versions of the preceding statements:

```
string1 = InsVars('FadeOut('#1, 1000, myobject)')
string2 = InsVars('Slide('#1, #2, #3, #4, #5, 500, 0', width / 2 - 50, width / 2 -20, height / 2)
```

In these two lines the argument list has been placed at the end of the main string, with each value replaced with a #1, #2, and so on, for each value to be inserted. The two strings can be placed in a chain, and the first one in the chain started, using the following:

```
Chain(Array(string1, string2))
```

The first statement places the strings in an array which then chains to the Chain() plug-in. Here's an example that uses these techniques to make a ball bounce around the browser:

```
<img id='ball' src='ball.png' />
<script>
window.onload = function() {
  Position('ball', 'absolute')
  width = GetWindowWidth()
  height = GetWindowHeight()
  r = width - 100
  b = height - 100
  x = width / 2 - 50
  y = height / 2 - 50

  ch1 = InsVars('Slide(#1, #2, #3, #4, 500, 0)', x, y, x)
  ch2 = InsVars('Slide(#1, #2, #3, #4, 500, 0)', x, 0, r)
  ch3 = InsVars('Slide(#1, #2, #3, #4, 500, 0)', r, y, b)
  ch4 = InsVars('Slide(#1, #2, #3, #4, 500, 0)', b, 0, y)

  Chain(Array(ch1, ch2, ch3, ch4))
</script>
```

The HTML section displays an image of a ball, then the first line of the <script> section sets the ball's property to 'absolute' so that it can be moved. After this the width and height of the browser are calculated and stored in width and height, then the right and bottom positions are required to place the ball against these edges which are placed in r and b. The variables x and y are also calculated to set them to coordinates that place the ball exactly in the center of the browser. Next, Slide() plug-ins are assembled into strings using InsVars() plug-in. Then calls the ball from center left to top middle, then to center right, then to bottom middle, and finally back to center left. These calls are then placed in an array and passed to the Chain() plug-in.

> NOTE Because of the way chaining has been implemented with a single array, you can have only one chain of plug-ins running at a time. You can carefully create a chain that interleaves two or more sets of plug-ins so that animations appear to be running concurrently. However, you will need to use trial and error to get the best results with this technique.

## Using Callback() Function Directly

The Callback() function achieves its execution by adding the name of a function to call back after the current one has finished. You can also do this if the plug-in you call supports chaining, as detailed in Table 7-2.

For example, if you would like to use Hide() plug-in called immediately after Deflate(), you can use code such as:

```
Deflate(myobject, 1, 1, 500, 0, 'Hide(myobject)')
```

This calls the Deflate() plug-in, passing it myobject, with the required parameters to deflate it over 500 milliseconds and without the possibility of the plug-in being interrupted. However, there is a final argument, which is a call to Hide(), placed within a string so that the string, not the result of executing the function, is passed.

 will need to tweak the syntax slightly if you are passing object IDs rather than objects within a callback, like:

```
Deflate('myobject', 1, 1, 500, 0, "Hide('myobject')")
```

This way, the double quotes are stripped off by the eval() function that will eventually execute this callback string, the string quotes will indicate that myobject is a string that is an object ID, and not the name of an object.

This procedure is a quick and easy to create a two-part chain without having to assemble a chain. Remember, however, that it works only on plug-ins that can be inserted into a chain.
