# How To Use Them

To use the Chain() plug-in, you need to create an array of plug-in chains to be chained together, and each call must be assembled into a string before it is placed into the array. For example, assume you want to add the following to a chain to:

```
FadeOut(myobject, 1000, 0)
```

To do, you must first convert it to a string, like this:

```
string1 = 'FadeOut(' + myobject + ', ' + 1000, 0)'
```

Or, if you have a more complicated call, like this:

```
Slide('a', width / 2, height / 2 - 50, width / 2 -20, height / 2, 500, 0)
```

then it would need to be turned into a string, like:

```
string2 = "Slide(' + a + \', ' + width / 2 + \', ' + height / 2 - 50 + \', ' + width / 2 - 29 + \', ' + height / 2 - 500, 0) + "
```

Obviously this quite gets very messy, it's almost much easier to make use of Plug-in 15, InsVars(), in these two versions of the preceding statements:

```
string1 = InsVars('FadeOut('#1, 1000, myobject)')
string2 = InsVars('Slide('#1, #2, #3, #4, #5, 500, 0', width / 2 - 50, width / 2 -20, height / 2)
```

In these two lines the argument list has been placed at the end of the main string, with each value replaced with a #1, #2, and so on, for each value to be inserted. The two strings can be placed in a chain, and the first one in the chain started, using the following statement:

```
Chain(Array(string1, string2))
```
