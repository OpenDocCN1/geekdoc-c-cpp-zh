# 25 GetWindowWidth()

There are many reasons to need to know the width of the browser window, the most obvious of which is that you can determine which objects you can display where in a dynamically generated website. This plug-in gives you that exact information, as shown by the alert box in Figure 4-7. It also takes into account scroll bars that might reduce the available width.

# About the Plug-In

This function will tell you the width of the browser window to the nearest pixel. It doesn’t require any arguments and returns the width as an integer.

# Variables, Arrays, and Functions

| | |
|---|---|
| de | Local object copy of document.documentElement |
| BROWSER | Global variable containing the browser name |
| barwidth | Local integer variable set if a vertical scroll bar exists |
| scrollHeight | The.scrollHeight property |
| clientHeight | The.clientHeight property |
| innerWidth | The window.innerWidth property |
| clientWidth | The.clientWidth and document.body.clientWidth properties |

# How It Works

This plug-in first copies the document.documentElement object into to provide a much shorter name, reducing the amount of code to edit. Next, if the browser is not Internet Explorer by the value in the global variable BROWSER, then the local integer barwidth is set to 17 if the value in de.scrollHeight is greater than that in de.clientHeight.
