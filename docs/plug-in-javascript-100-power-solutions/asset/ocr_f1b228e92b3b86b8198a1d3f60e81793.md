# About the Plug-in

This plug-in can take a key as an argument and return a string representing the special key that was pressed, or the code if no key was pressed.

# Variables, Arrays, and Functions

| c | Key code passed to the function and returned if it does represent a special key |

# How It Works

This function uses a switch() statement to test the value of c and return various strings if it matches value. If none of the values match, then c is returned.

# To Use It

Generally this plug-in will be called for you by the CaptureKeyboard() plug-in. However, you may have an application for which you'd rather return the strings, or rather different names. In these cases, feel free to modify the plug-in to your requirements.

For example, if you don't want the keyspress created by pressing the SHIFT key, you might prefer to return an empty string for value instead of string 'SHIFT'. That way, when the user presses the SHIFT key followed by the M key, for example, you will only see the value 'M' and not followed by 'M'.

The reason I've to to bother of trapping these special keys is, although there are already useful input features built into JavaScript, these plug-ins allow you to, for example, set up various special keys to move objects around the screen or perform particular functions the moment a key is pressed.
