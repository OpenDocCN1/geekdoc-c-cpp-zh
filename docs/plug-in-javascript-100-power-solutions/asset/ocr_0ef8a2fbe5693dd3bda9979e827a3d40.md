After this, the values used to center the object are placed in midx and midy, like this:

```
var midx = O(id).ZO_X + Math.round((maxx - O(id).ZO_W) / 2)
```

properties of it.

# When the Argument Is True

If the argument is greater than zero, the calling of this plug-in will pad out as it is
changes so that it will retain the overall size, and therefore, elements
resting against it will all aligned where they are. Without this setting, and the
height and id changes, any objects surrounding move about to make the new
dims into account. The following line of code calls the ZoomPad() function to
to create the padding:

```
if (pad > 0) ZoomPad(Math.max(fromw, tow),
Math.max(fromh, toh, O(id).ZO_W, O(id).ZO_H)
```

This finds the maximum width and height of the object that will be out of its start and
values of fromw, tow, fromh, and toh, by using the Math.max() function. The object will
ten having added its padding so that it is growing to larger, padding is placed
around it, in which case the resizing can grow. Or, if it is reducing, then no
padding is added, but as the object reduces, more and padding are added to make up
the reduction in size. The overall result is when pad is greater than zero, id will
always have the overall dimensions (when you add its width and height to its
padding).

Otherwise, if pad doesn't have a value of -1, id is moved to keep it centered (if pad
is-1, no padding is required and no moving of id is wanted).

which case the best way to keep the object centered is to set pad to true).
