# How To Use It

To make invisible objects reappear, just pass them to this plug-in. The following extends the previous plug-in to make the hidden span reappear:

```
<span id='ghost'>Now you see me...</span> and soon you won't
<script>
  window.onload = function() {
    S('ghost').backgroundColor = 'lightblue'
    Resize('ghost', 128, 32)
    alert('Click OK to see the object disappear')
    Invisible('ghost')
    alert('Click OK to see the object reappear')
    Visible('ghost')
  }
</script>
```

Just the final two lines of code in this example are new: an alert, so that you can verify the span was made invisible, and a call to Visible() that is executed after clicking OK, which makes the object reappear.

# The Plug-in

```
function Visible(id)
{
  S(id, 'visibility', VIS)
}
```
