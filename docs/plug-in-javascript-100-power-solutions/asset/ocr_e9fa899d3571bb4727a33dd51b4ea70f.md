# 66 DockBar()

This plug-in adds a dock bar to the browser similar to the one used by Mac OS X. It's easily configurable and can be attached to any of the browser's four edges. Figure 8-8 dock icons attached to the bottom edge of a browser using this plug-in, with one in the process of zooming up.

# About the Plug-in

This plug-in takes a containing object and list of elements within the object and turns them into a dock bar that you can affix to any edge of the browser. It requires the following arguments:

+   - id A containing object such as a div or span that holds the individual dock bar elements—this cannot be an error
- items An array of objects located within id, usually comprising images
- where The edge to which the bar should be attached, out of 'top', 'bottom', 'left', 'right'
- increase The percentage by which an item should enlarge when the mouse passes over it
- msecs The number of milliseconds the transition should take
