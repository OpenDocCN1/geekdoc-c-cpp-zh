## ContextDown Sub-function
This function monitors the position of the mouse by checking the MOUSE_X and MOUSE_Y global variables:

```
if (MOUSE_X < x || MOUSE_X > (x + W(contents)) ||
    MOUSE_Y < y || MOUSE_Y > (y + H(contents))) {
```

If the mouse pointer is not within the bounds of contents, the object is popped down and the repeating interrupts are stopped with a clearInterval(), passing the value in the property Context_ID that was saved when setInterval was called. Also, the property PO_IsUp is set to false because contents have now been popped down:

```
PopDown(contents, type, w, h, msecs, 1)
clearInterval(O(id).Context_ID)
O(contents).PO_IsUp = false
```

If the mouse is within the bounds of contents, the function returns to be called again in another INTERVAL milliseconds.

> Note: With a little tweak, this plug-in could be easily adapted to create a slight buffer around the context menu so the menu won't disappear when the mouse goes slightly outside the boundary.

## 66 DockBar()

This plug-in adds a dock bar to the browser similar to the one used by Mac OS X. It's easily configurable and can be attached to any of the browser's four edges. Figure 8-8 dock icons attached to the bottom edge of a browser using this plug-in, with one in the process of zooming up.

## About the Plug-in

This plug-in takes a containing object and list of elements within the object and turns them into a dock bar that you can affix to any edge of the browser. It requires the following arguments:

- id: A containing object such as a div or span that holds the individual dock elements
- items: An array of objects located within id
- where: The edge to which the bar should be attached, of 'top', 'bottom', 'left', 'right'
- increase: The percentage by which an item should enlarge when the mouse passes over it
- msecs: The number of milliseconds the transition should take

Figure 8-8 Use this plug-in to create impressive dock bars.

| DockDown() | Subfunction to zoom down an object

## How It Works

This plug-in starts by releasing the object in id from the browser and giving it a style of 'fixed' to ensure that the dock bar will stay in place if the browser is scrolled, as follows (FIX being a global variable with the value 'fixed'):

```
Position(id, FIX)
```

Then all the elements in the items array are iterated through a for loop with the local variable j as the index, and the first statements within the loop set the alignment of each element, like this:

```
for (var j = 0 ; j < items.length; ++j) {
  if (where == TP || where == BM)
    O(items[j]).verticalAlign = where
  else
    O(items[j]).align = where
}
```

If the argument has either of the values 'top' or 'bottom' (tested by the global variables TP and BM), then the verticalAlign style property of the element is set to the value in where. Otherwise, it must have a value of 'left' or 'right' to set the align property of the element given that value.

Next, element's original width and height is extracted from the W() and H() plug-ins and placed in the local variables oldw and oldh, like this:

```
oldw = W(items[j])
oldh = H(items[j])
```

After that, the cursor to display when the mouse is over an element is set to 'pointer' and several properties are created, as follows:

```
O(items[j]).cursor = 'pointer'
O(items[j]).DB_Parent = id
O(items[j]).DB_Where = where
O(items[j]).DB_OldW = oldw
O(items[j]).DB_OldH = oldh
O(items[j]).DB_NewW = Math.round(oldw + increase) * increase / 100
O(items[j]).DB_NewH = Math.round(oldh + increase) * increase / 100
```

This causes information about the element and the containing it is located within to be stored as new properties of the elements. These properties can be referenced by the following DockUp() and DockDown() subfunctions and also referenced from within the Zoom() plug-in which relies on.

First, the object is copied to the DB_Parent property. The value in where is copied so that Zoom() will know where to place the element as it zooms, and oldw and oldh are added as properties to tell Zoom() where to zoom up from. The width and height of that element are zoomed up to by increasing the original width and height by the percentage value in increase and placed in the DB_NewW and DB_New properties.

The final statements in this loop attach the DockUp() and DockDown() subfunctions to the element's mousemouseover and mouseout events, respectively, as follows:

```
O(items[j]).onmouseover = DockUp()
O(items[j]).onmouseout = DockDown
```

Finally, in the setup section of code, the object id is moved to the edge indicated by the value in where, like this:

```
GotoEdge(id, 50)
```

## The DockUp() and DockDown() Subfunctions

These functions trigger the popping up or the popping down of an element by passing the previous properties of the pseudo object to the Zoom() plug-in; this being a keyword that represents the object that triggered the event that called the function.
