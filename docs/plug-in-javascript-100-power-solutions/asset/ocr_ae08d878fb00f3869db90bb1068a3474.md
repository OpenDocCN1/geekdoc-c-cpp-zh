# About the Plug-In

This plug-in requires a hexadecimal string to be passed to it, and then returns that number in decimal. It requires this argument:

+   - n A string containing a hexadecimal number

# Variables, Arrays, and Functions

| parseInt() | JavaScript function to convert a string to a number |

# How It Works

This plug-in uses the JavaScript function parseInt() to convert a hexadecimal string to a decimal number. It does because the second parameter passed to it is 16. If the decimal number were 8, for example, it would try to convert from an octal number, and so on.

# How To Use It

Pass the HexDec() function string containing a hexadecimal number and it will return decimal number, like this:

```
alert('The hexadecimal number FFFF in decimal is ' + 
HexDec('FFFF'));
```

In this instance the hexadecimal number FFFF is converted to 65,535 in decimal, and the result is displayed using a call to the JavaScript alert function().

# The Plug-in

```
function HexDec(n)
{
  return(parseInt(n, 16))
}
```
