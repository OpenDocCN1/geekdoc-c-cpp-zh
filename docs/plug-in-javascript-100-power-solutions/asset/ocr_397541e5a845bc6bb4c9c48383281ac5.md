# About the Plug-ins

These plug-ins require an object's property to be passed to them. If NoPx() is passed a value, the value returned will be that of the value any ‘px’ suffix. If Fx() is called, then the value returned is that of the value passed to the plug-in, combined with the suffix ‘px’. No case is property actually changed by these plug-ins, as values are derived from the properties and it is up to you to use them as required. The plug-ins require the following argument:

+   - value The property to be modified

# How They Work

NoPx() uses the JavaScript() function to replace any occurrences of ‘px’ in the string it is passed, and then returns the result, multiplying by 1 to ensure it is turning a string into a number.
Fx() function adds the suffix ‘px’ to any value it is passed and then returns the result.

# How To Use Them

NoPx() is very simple in that all it does is replace the ‘px’ (if found) with the empty string in any string it is. Thus it can strip the trailing ‘px’ suffix that many object properties have. For example, the style.marginLeft property is just one of many that ends in ‘px’, so the following will call it out:

```
value = NoPx(S(id).marginLeft)
```

In this example the object referred to by id is passed to the S() function, which returns the style subjet. The marginLeft property is then passed to and the resulting string value, which might look like ‘10px’, for example, is then passed to the NoPx() function. In this case, it would return the number 10, which is then assigned to the variable value.
