# About the Plug-in

This plug-in fades an object in out, depending on its previous state. It requires the following arguments:

+   - id An object, an object ID, or an array of objects and/or object IDs
- msecs The number of milliseconds the transition should take
- interruptible If set, the fade can be interrupted; otherwise, it cannot

# Variables, Arrays, and Functions

| | Local variable that iterates through the elements in id if it is an array |
|---|---|
| Fadeout | New property given to id and set to true if it has been faded out |
| FadeIn() | Plug-in to fade an object in |
| FadeOut() | Plug-in to fade an object out |

# How It Works

This plug-in has to use its own code to iterate through id if it is an array because of the need to individually check the Fadeout property for each object. It uses the standard form of many prior plug-ins to call the same function with single array elements.

The second half of the plug-in is where the Fadeout property is checked. If it is set to true, that value will have been assigned from within the Fade() plug-in, discussed earlier in this chapter. When set to, it means the object has been faded out. The Fadeout property doesn't exist or is set to false, then the object has not been faded out.
Therefore, based on the value of Fadeout, a decision is made by the FadeToggle() plug-in to call either the FadeIn() plug-in to fade the object or the FadeOut() plug-in to be attached.

# How To Use It

You can attach this plug-in to an event using HTML, or you can call it from a sample of JavaScript code. In the following example, the same call to FadeToggle() is attached to both the mouseover and mouseout events of the span:

```
<center><br />
<img id='il1' src='id3.gif /><br />
<span id='spl'>Mouseover</span>

<script>
window.onload = function () {
  FadeToggle('il1', 1, 1);
  O('spl').mouseover = function() { FadeToggle('il1', 500, 1) }
  O('spl').mouseout = function() { FadeToggle('il1', 500, 1) }
}
</script>
```
