If the event is not recognized, the mousedown event for the object in id is caught and return false. This is not a great solution because it prevents other mousedown events from being attached, but it does have the effect of preventing the event from occurring.

In case of Mozilla-based browsers as Firefox, the special property MozUserSelect is to set either 'none' to prevent text from being selected, or 'text' to re-enable it. It is necessary because these browsers will not use the onselectstart event, and using this property is less intrusive than capturing the mousedown event.

# How To Use It

To prevent copying and pasting the contents of a div, for example, you can attach this function to its onselectstart event, like this:

```
PreventAction('mydiv', 'select', true)
```

If a user tries to select any text, this plug-in stops the event before it can get going. This is not merely an easy way to prevent copying text from your web pages, but it also prevents text from being inadvertently highlighted when you are using the mouse to drag items about.

You can also use it to prevent any element from being dragged in the browser or dragged and dropped elsewhere, like this:

```
PreventAction('mygif', 'drag', true)
```

Here's some code that illustrates both of these:

```
<img id='gif' src='il.gif' />
The image cannot be dragged.
<span id='text'>And this text is unselectable</span>
```

```
<script>
window.onload = function() {
  PreventAction('gif', 'drag', true);
  PreventAction('text', 'select', true);
}
</script>
```

In the HTML section of the example, a GIF with the name il.gif is displayed and the ID of 'gif'. It is followed by some regular text and the ID of 'text'.

Below that, in the <script> section, the GIF image has its drag property disabled, and the span text is unselectable. If you try either of these actions they will fail. However, Internet Explorer will allow you to continue the selection within the span if you commence a selection from outside the span. You can work around this bug by setting the document as unselectable, like this:

```
PreventAction(document.body, 'select', true)
```
