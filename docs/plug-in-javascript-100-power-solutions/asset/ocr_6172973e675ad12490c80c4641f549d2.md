# 43 Slide()

This plug-in allows you to slide an object from one place to another over time, making it useful for sliding elements on demand, hiding and revealing objects, or creating animation effects. Figure 6-1 shows an image in the process of sliding from the bottom to the top right of the browser.

# About the Plug-in

This plug-in moves an object from one location to another over a period of time. It supports single objects only (not arrays) if there were more than one object, only the topmost would be seen. Therefore, you can pass only an object or an object ID to this plug-in. It requires the following arguments:

+   * Either an object or an object ID cannot be an array of objects
* frx The top left corner of the initial position for id
* toy The top left corner of the final position for id
* msecs The number of milliseconds the animation should hold
* interruptible If true (or 1), this plug-in can be interrupted by a new call on the same object; if false (or 0), the call is uninterruptible
