```
if (O(id).PO_IsUp) PopDown(id, type, w, h, msecs, interruptible)
else Popup(id, type, w, h, msecs, interruptible)
```

# How To Use It

To use this plug-in, pass an object and the type of pop-up and down to effect use, out of 'fade', 'inflate', 'zoom', or 'instant'. Then decide the width, height, or dimensions resizable (if applicable), how the transition should take, and whether it can be interrupted, like

```
PopToggle('object', 'inflate', 0, 1, 500, 0)
```
