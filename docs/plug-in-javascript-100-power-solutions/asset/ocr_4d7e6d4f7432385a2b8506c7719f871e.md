# 73 TextToMatrix()

This plug-in provides the inverse functionality to the MatrixText() plug-in. It takes some text and randomly scrambles it over a period of time specified by you. Figure 9-4 shows some text that has been fully scrambled with this plug-in.

# About the Plug-in

This plug-in takes an object containing some text and replaces it with random characters over a period of time you specify. It requires the following arguments:

+   - id An object, object ID, or array of and/or object IDs
- msecs The number of milliseconds it takes to scramble the text
