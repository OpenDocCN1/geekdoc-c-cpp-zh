## ToolTip()

With this plug-in, you can add tooltips that fade in and out over a period to any object, with a range of configurable display options. Figure 13-5 shows a tooltip that has been attached to the Home link of a web page.

## About the Plug-in

This plug-in displays a tooltip when the mouse passes over an attached object. It requires the following arguments:

- id: An object or object ID—this cannot be an array
- tip: The tip message to display, which may contain HTML
- font: The font to use

## How It Works

This plug-in creates a new div for each tooltip, or id comprising the string TT_ and the ID, then creates a local variable to hold this ID, like:

```javascript
var tt = 'TT_' + O(id).id
```

Next, if the div for the tooltip hasn't been created, this is done using the following:

```javascript
var newdiv = document.createElement('div')
newdiv.setAttribute('id', tt)
document.body.appendChild(newdiv)
```

The opacity of the new div is set to 0 to hide it, and is released by giving it style attribute of 'absolute', using ABS:

```javascript
Opacity(tt, 0)
Position(tt, ABS)
```

Next, all the arguments are default values for any that have not been given:

| Argument | Default Value |
| :--- | :--- |
| font | font ? : 'Arial' |
| size | size ? : 'small' |
| textc | textc ? : '#884444' |
| backc | backc ? : '#ffff88' |
| bordc | bordc ? : '#aaaaaa' |
| bstyle | bstyle ? : 'dotted' |
| width | width ? : 1 |
| msecs | msecs ? : 250 |

After that, various styles based on these values are applied to the new div, and the contents of tip argument are placed in its innerHTML, as follows:

```javascript
S(tt).fontFamily = font
S(tt).fontSize = size
S(tt).padding = 'px 5px 5px'
S(tt).color = text
S(tt).backgroundColor = backc
S(tt).borderColor = bordc
S(tt).borderStyle = bstyle
S(tt).borderWidth = Px(width)
```

```javascript
Html(tt, tip)
```

Finally, in the tooltip section, DoToolTip() and ToolHide() functions are attached to the mouseover and mouseout events of id, and the Hidden property of id is set to false to indicate that the tooltip is currently visible:

```javascript
O(id).mouseover = DoToolTip
O(id).mouseout = ToolHide
O(tt).Hidden = false
```

### TheToolTip() Function

This function moves the div referred by tt to a location 15 pixels to the right and 15 down from the mouse position, sets its zIndex property to the highest value so far plus 1 (to ensure displays above all other elements), fades the tooltip, and sets the tooltip's Hidden attribute to false to indicate it is now visible:

```javascript
Goto(tt, MOUSE_X + 15, MOUSE_Y + 15)
O(tt).zIndex = 1
FadeIn(tt, msecs)
O(tt).Hidden = false
```

With the tooltip displayed, if a timeout has been specified then setTimeout() is called to create an interrupt to the ToolHide() function in timeout milliseconds, to fade it away (after first cancelling any timeout that may be in place), like this:

```javascript
O(tt).IID = clearTimeout(O(tt).IID)
O(tt).IID = setTimeout(ToolTipHide, timeout)
```

### TheToolTipHide() Function

This function simply checks whether the tooltip is hidden. If it is, it has nothing to do and returns; otherwise, it fades the tooltip and sets its Hidden attribute to true to indicate the setting:

```javascript
FadeOut(tt, msecs)
O(tt).Hidden = true
```

## How To Use It

To use this plug-in, all you need to do is pass an object and the tip message to display, like:

ToolTip('home', 'Visit the Home page')

You can also pass all of the other supported arguments to tailor the output. The following example illustrates attaching a tooltip to a link using all the available options:

```html
<h2>
  <a id='home' href='/'Home</a>
  <a id='news' href='/news'>News</a>
  <a id='blog' href='/blog'>Blog</a>
  <a id='links' href='/links'>Links</a>
</h2>
```

```javascript
<script>
  window.onload = function () {
    tip = 'Click this link to return<br />to the main home page'
    ToolTip('home', 'Verdana', '12px', '#444444', '#ffff', '#088888', 'solid', 1, 500)
    O('links').title = tip
  }
</script>
```

The HTML section sets up four links and gives them IDs. The <script> section attaches a tooltip to the first link. As you can see by the <br /> included in the string assigned to tip, HTML is supported, enabling you to configure the tooltip any way you like.

There is also a standard tag attached to the link so that you can compare the way it displays with this plug-in by passing the mouse over that link.
