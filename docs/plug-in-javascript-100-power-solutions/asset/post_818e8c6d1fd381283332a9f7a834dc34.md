## About the Plug-In

This plug-in takes an object containing some and replaces it with random characters, then slowly changes them to reveal the original text. It requires the following arguments:

- id An object, object or array of objects and/or object IDs
- msecs The number of milliseconds it should take to reveal the text

## How It Works

This plug-in begins by iterating through id if it is an array, recursively calling itself to individually process each element, like this:

```javascript
if (id instanceof Array) {
  for (var j = 0 ; j < id.length; j++) {
    MatrixToText(id[j], msecs)
  }
}
```

The MT_Flag property of id is tested. If it's true, a call to this plug-in is operating on the object, Otherwise, the property is set to true to indicate that a progress is in the id, as follows:

```javascript
if (O(id).MT_Flag) return
else O(id).MT_Flag = true
```

Next, html is the HTML contents of id, len length, and freq frequency with which the DoMatrixToText function needs to be called for the transition to make msecs. In addition, the string variable matrix is created, which will hold the random text as it is slowly revealed; count, the counter for each step, is initialized to 0; and chars, the string containing all possible characters for scrambling the text, a-z, A-Z and 0-9, as follows:

```javascript
var html = Html(id)
var len = html.length
var freq = Math.round(msecs / INTERVAL)
var matrix = ''
var count = 0
var chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ' + 'abcdefghijklmnopqrstuvwxyz' + '0123456789'
```

## MatrixToText() Function

This function does the revealing using a for() loop each time it is called to replace characters in the string with random characters. This is sufficient to change only each step, so that the transition will take msecs, as follows:

```javascript
for (j = 0; j < len; j++) {
  var k = Math.floor(Math.random() * len)
  matrix = matrix.substr(0, k) + html[k] + matrix.substr(k + 1)
}
```

The value of k was determined by performing tests with strings of different sizes and timing. It's not an exact value, so you might find to tweak it. The value in matrix is then assigned to the correct property of id to display it:

```javascript
if (O(id).innerText) O(id).innerText = matrix
else O(id).textContent = matrix
```

Finally, the count variable is incremented until the interval has completed. If the value is the same as INTERVAL, the MT_Flag property of id is set to false to indicate the transition is over. Its inner property is restored to its original value, and the repeating intervals are cancelled, like this:

```javascript
if (++count == INTERVAL) {
  O(id).MT_Flag = false
  O(id).innerHTML = html
  clearInterval(id)
}
```

The function then returns, and if there are still characters to be revealed, it is called again in freq milliseconds, and so on, until the transition is finished.

## How To Use It

To use this plug-in, pass it an object, such as a div or span that contains some text, and tell it how long the reveal transition should take, with this example:

