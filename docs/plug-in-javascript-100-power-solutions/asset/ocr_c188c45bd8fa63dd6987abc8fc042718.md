How It Works
To start with this, plug-in sets the width and height of the browser in w and h and sets c to the string 'CT_', a prefix that will be used when assigning IDs to the image objects that were created:

```
var w = GetWidth()
var h = GetHeight()
var c = 'CT_'
```

Next, if it is not 1 or true, any repeating interrupts are cancelled, and the plug-in returns, turns off the mouse trails:

```
if (!state) return clearInterval(CT_IID)
```

At the next line of code, if no object has the ID 'TT_0', it means the first time the plug-in has been called, so all the objects are created and set style positions of 'absolute' (so that they can be moved about). In addition, their opacity is set to different levels so that the farthest away from the mouse cursor are the most faded, the images are loaded from the URL supplied in image, and the X and Y properties of each image are assigned starting values of -9999 to place them well off screen, as follows:
