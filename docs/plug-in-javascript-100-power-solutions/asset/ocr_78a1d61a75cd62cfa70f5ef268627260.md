| de | Local object copy of document.documentElement |
| BROWSER | Global variable containing the browser name |
| scrollWidth | Local integer variable set if a vertical scrollbar exists |
| scrollWidth | The.de.scrollWidth property |
| clientWidth | The.de.clientWidth property |
| innerHeight | The window.innerHeight property |
| clientHeight | The.de.clientHeight and document.body.clientHeight properties |

How It Works
This plug-in works almost the same as GetWindow() except that it returns the available height in the current browser window, taking any scroll bars into account. Please refer to GetWindow() for further details.

How To Use It
To use this plug-in, simply call it and use the value returned in the following example, which passes the returned value to an alert() statement where it is displayed:

```
<script>
window.onload = function() {
  alert('This browser has a window height of: ' + GetWindowHeight())
}
</script>
```
