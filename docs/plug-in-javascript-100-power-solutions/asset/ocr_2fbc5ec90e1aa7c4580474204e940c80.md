DismissLB() Subfunction
This function is called whenever id is clicked. The first thing it does is fade the frame's opacity back down to 0 and its background color from col2 back to coll1, like this:

```
Fade('LB_DIV', opacity, 0, msecs)
ColorFade('LB_DIV', col2, coll, 'back', msecs, 1)
```

At the same time, a chain is created to perform three actions in sequence: first, fade out id; second, hide id and third, restore scrollbars to document.body, as follows:

```
Chain(Array(
InsVars('FadeOut Array('#1', 'LB_DIV'), 2', id, msecs),
InsVars('Hide Array('#1', 'LB_DIV'))', id),
'(document.body, 'overflow', 'auto')
)
```

How To Use
To use this plug-in, you need to have an image (or any other object) already prepared. Most likely you will have set its style.display attribute to 'none' so that it is not visible in the web page, like this:

```
<img id='photo' src='photo6.jpg' border='1' style='display:none'>
```

Next you can attach the plug-in to an event such as an onclick or mouseover to pop the object in a light box. Here's an example that uses an onclick:

```
<button id='link' type='button'>Click Me</button>
<img id='photo' src='photo6.jpg' border='1' style='display:none'>
```

```
<script>
window.onload = function () {
O('link').onclick = function () {
Lightbox('photo', '#888888', '0000000', 80, 500, 1)
}
}
n</script>
```

The HTML example of this section creates a link to the anonymous inline function, along with an image object with the ID 'photo'. The <script> section simply contains the function that can call the Lightbox() plug-in.
When a light box is in use, none of the elements underneath are clickable (or have mouseover events attached) will work until the light box is removed. This is because the div object it covers the entire browser window and has a zIndex value that everything except the light box contents, which makes it especially useful when you wish to force the user to focus on only one thing, such as entering log-in details or accepting a notification of an error, and so on.
