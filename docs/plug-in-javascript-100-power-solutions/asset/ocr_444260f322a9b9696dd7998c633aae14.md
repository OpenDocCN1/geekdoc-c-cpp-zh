# The Plug-in

```
function SaveState(id)
O(id).Save_left = S(id).left
O(id).Save_top = S(id).top
O(id).Save_visibility = S(id).visibility
O(id).Save_color = S(id).color
O(id).Save_backgroundColor = S(id).backgroundColor
O(id).Save_display = S(id).display
O(id).Save_opacity = S(id).opacity
O(id).Save_MozOpacity = S(id).MozOpacity
O(id).Save_MhtmlOpacity = S(id).MhtmlOpacity
O(id).Save_filter = S(id).filter
O(id).Save_zindex = S(id).zindex
}
```

# RestoreState()

This is the partner plug-in for SaveState(). It will restore an object's major style settings to the way they were saved. Figure 3-14 shows that the div we created in the previous plug-in has been modified; its colors are different and it has been moved to the right. An alert box has popped up to let you see this before the RestoreState() plug-in is called to restore the div to its original state.
