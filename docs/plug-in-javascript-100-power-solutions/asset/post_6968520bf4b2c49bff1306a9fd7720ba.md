# When the Animation Has Completed

To check whether the zoom has completed, the following if() statement is used:

```
if (++o(id)).ZO_Count >= (msecs / INTERVAL)
```

This statement increments the ZO_Count property of id and then checks whether it is greater or equal to the result of msecs / INTERVAL (which gives the number of steps in the animation). If it isn't, the contents of the if() statement are ignored and the subfunction returns will be called up in INTERVAL milliseconds time.

Otherwise, the zoom finished and with the following statements are executed:

```
var end = O(id).ZO_X + Math.round(maxx - tow) / 2
var windy = O(id).ZO_Y + Math.round(maxh - toh) / 2
O(id).ZO_Flag = false
Resize(id, tow, toh)
clearInterval(O(id).ZO_IID)
```

The first two lines calculate the final x and y locations for object and place them in end and windy. The next line sets the ZO_Flag property of id to false to indicate that no zoom is running on id. Next, the object is resized to its final width and height in tow and toh, and the repeating interrupts are stopped by calling clearInterval(), passing it the property ZO_IID that was stored when setInterval() was called.
