# How to Use It

To use this plug-in, you need to ensure that the second object has already been deflated. Ideally, you will have also released each object from its position in the HTML by giving it a position style of 'absolute' or 'relative'. You will probably also have overlaid the objects on each other.

The following example does all of this and a span that you can pass your mouse over to initiate the swaps:

```
<span id='d'>Mouse Me</</span>

<img id='p1' src='photo1.jpg' />
<img id='p2' src='photo2.jpg' />

<script>
window.onload = function() {
  Locate(Array(['p1', 'p2']), 0, 30)
  Deflate('p2', 1, 1, 0)
}

O('d').onmouseover = swap1
O('d').onmouseout = swap2

function swap1() {
  DeflateBetween('p1', 'p2', 1, 1, 1000, 1)
}

function swap2() {
  DeflateBetween('p2', 'p1', 1, 1, 1000, 1)
}
</script>
```

The HTML section creates a span with the text "Mouse Me" and also displays two images. All three are given a position style setting of 'absolute' and located at 0 pixels, and 30 down using calls to the Locate() plug-in. In the <script> section, both of the images are deflated the second image using the Deflate() plug-in, over the shortest time possible (1 millisecond), which is virtually instantaneous.

Finally, the mouseover and mouseout events of the div are attached, in order, to the swap1() and swap2() functions, which call the DeflateBetween() plug-in to either swap from image 1 to image 2, or from image 2 to image 1.

The transitions are given 1000 milliseconds (or 1 second) to complete. Because the interruptible parameter is set to 1, you can pass your mouse in and out of the Mouse text to instantly change between displaying one or the other.

You may want to try changing the w and h arguments to see the various different you can achieve.
