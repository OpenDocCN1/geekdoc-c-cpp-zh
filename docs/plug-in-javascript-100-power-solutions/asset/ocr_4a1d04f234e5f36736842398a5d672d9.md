# # To Use It

To use this plug-in, you will need to insert it as a string within an array of chain commands, as follows:

"WaitKey()"

You can then choose the key that was pressed or have a later command in the chain use the GetLastKey() plug-in to return the key and use it.

The following example replaces the same zooming in and back of the previous example in the Pause() plug-section, with a "Press any key" message that fades in, waits for a keypress, and then fades out again—allowing the ship to sail on its way:

```
<div id='sea'></div>
<img id='sea' src='ship.png'>
<span id='note'><font size='5'>Press any key</font></span>

<script>
window.onload = function() {
  width = GetWindowWidth()
  height = GetWindowHeight()
  x = width - 200
  y = height - 150
  mid = width / 2 - 100

  Locate('sea', ABS, 0, height - 50)
  Resize('sea', width, 50)
  S(document.body).backgroundColor = '#b7d4dc'
  S('sea').backgroundColor = '#90a5a6'
  Locate('ship', ABS, 0, y)
  Locate('note', ABS, 0, y + 115)
  CenterX('note')
  Opacity('note', 0)

  While('KEY_PRESS ! != ' ', {
    FadeIn('ship', 'slide', 0, y)
    InsVars('Slide('ship', 0, #1, #2, #1, 2500, 0)', mid, y)
    FadeIn('note', 1000, 0)
    WaitKey()
    FadeOut('note', 1000, 0)
    InsVars('Slide('ship', #1, #2, #3, 2500, 0)', mid, y, x)
    FadeOut('ship', 500, 0)
    InsVars(Callback('Goto("ship", 0, #1)'))
  })
}
</script>
```

The differences between this and the last example are highlighted in bold. In the HTML section, a new span has been added with the message text. In the <script> section, the span is moved to the location where it will be displayed, and its opacity is set to zero to make it invisible.
