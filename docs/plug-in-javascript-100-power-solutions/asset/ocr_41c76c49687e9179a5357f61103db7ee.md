Next, if the ID 'ALERT_DIV' doesn't exist, it means this time is for the plug-in has been called, the two main divs are created, like this:

```
var newdiv = document.createElement('div')
newdiv.setAttribute('id', 'SHADOW_DIV')
dbody.body.appendChild(newdiv)
newdiv = document.createElement('div')
newdiv.setAttribute('id', 'ALERT_DIV')
dbody.body.appendChild(newdiv)
```

These statements create new divs with the IDs 'ALERT_DIV' and 'SHADOW_DIV', attaching them to the document body. The divs are released from their location in the HTML, resized, and centered, and the shadow div has its opacity set to 50 percent, as follows:

```
Position(div, ABS)
Resize('ALERT_DIV', 350, 140)
Resize('SHADOW_DIV', 350, 146)
Center('ALERT_DIV')
Goto('SHADOW_DIV', 4, Y('ALERT_DIV')) + 6
Opacity('SHADOW_DIV', 50)
```

Next, the divs are hidden with a callback to AlertHide(), and the innerHTML property is assigned the value of html, which contains the HTML to create the two subdivs, both of which are resized:

```
AlertHide()
Html('ALERT_DIV', html)
Resize('ALERT_TITLE', 350, 22)
Resize('ALERT_MESSAGE', 330, 98)
```
