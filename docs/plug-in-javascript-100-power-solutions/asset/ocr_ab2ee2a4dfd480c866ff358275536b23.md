The simpleInterrupt() function calls GetLastKey() each time it is called. If the value is 'Enter', it means the user has pressed the Enter key and k is assigned the value '. (a period), and the input is disabled using clearInterval(), with the interrupt ID appended to it. If the value is the empty string, then nothing is appended.

All your code to do then is to look at the end of the string to see if it is the period character to indicate that the user has pressed Enter. Your code removes that character and uses the remainder of the string. Alternatively, you can use a different kind of input marker.
