## About the Plug-In
The plug-in requires a pair of arrays of heading and contents and then displays a folding menu based on the styles and actions you supply. It takes the following arguments:

- **headings** An array of objects and/or object IDs
- **contents** An array of objects and/or object IDs
- **action** The menu action type, either 'hover' or 'click'
- **type** The type of transitions to use, out of 'fade', 'inflate', 'zoom', or 'instant'
- **multi** If true or 1, more than one section can be open at a time
- **w, h** If type is 'inflate' or 'zoom', these arguments specify the width, height, or dimensions be modified during transitions
- **mssec1** The transition in milliseconds of popping down
- **mssec2** The transition in milliseconds of popping up
- **interruptible** If true or 1, the PopUp() and PopDown() plug-in is interrupted by another on the same id

## How It Works

The first thing this plug-in does is pop down all the objects in the contents array except for the first one

```
PopDown(contents.slice(1), type, w, h, 1, 0)
O(contents[]).PO_IsUp = true
```

slice() is used with a value of 1 to PopDown() all elements from the second element onward (because the first element of an array is 0). The msec argument to PopDown() is so that the transition is set to take only 1 millisecond and is, therefore, virtually instantaneous.

Next, the contents and arrays are iterated through a for () loop, using j as an index, like these:

```
for (var j = 0; j < contents.length; ++j)
{
  O(headings[j]).PO_C = contents[j]
  S(headings[j]).cursor = 'pointer'

  if (action == 'hover') O(contents[j]).onmouseover = DoFoldingMenu
  else O(contents[j]).onclick = DoFoldingMenu
}
```

Each heading has its PO_C property assigned the object in the associated contents array. Each heading will pop up and down the contents associated with it. When each heading its cursor property set to 'pointer', the mouse pointer will change when it passes over the heading.

After that action argument is tested. If it is 'hover', the DoFoldingMenu() subfunction is attached to the current heading's on event so that it will be called by passing the mouse over it.
Otherwise, the subfunction is attached to the current heading's onclick event so that it will only be called when the heading is clicked.

## The DoFoldingMenu Subfunction

Once all the various properties and events are set up for the plug-in, the DoFoldingMenu() subfunction will be called whenever a change to the menus is required.

When this happens, the first statement in the function checks the markup. If it is true or 1, it means that more than one set of contents can be popped up at a time; in fact, all of them can be up (or down) at the same time.

By setting multi argument, each onmouseover or onclick event of a heading will toggle the pop-up or pop-down state of the associated contents with PopToggle(), like this:

```
if (multi) PopToggle(this.PO_C, w, msec1, interruptible)
```

If multi is not set, then one contents can be popped up at a time; when a new one is to be popped the previously up object must be popped. This is worked out by iterating through the headings in a for loop, like this:

```
for (j = 0; j < headings.length; ++j)
if (O(headings[j]).PO_IsUp && O(headings[j]) != true)
PopDown(headings[j]).PO_C, w, msec1, interruptible)
```

The variable j iterates through each element in the headings array and checks one's contents popped up so the heading is compared with this, which refers to the current heading; if PO_IsUp is true, the contents object is currently popped up so the heading was either clicked or mouse passed over. If they match nothing happens the currently selected contents object will be set to popped state a couple of lines later.

However, if the contents object that has been found to be up is different from the current heading's contents, it is the one that was previously up so it is popped down with a call to PopDown(). Timing used here is from the msec argument.

Finally, the currently selected contents is set to popped state if it isn't already popped up, like this:

```
if (!this.PO_C.IsUp)
PopUp(this.PO_C, w, msec1, interruptible)
```

This pop-up action has its own setting in msec2 so that different effects can be achieved by using different values for.

## How To Use It

There are two ways to use this plug-in. The first is within an accordion or folding menu, and the other is to separate the headings from the contents to control the objects in a different place. The first is most suited to being operated by mouse clicks, as transitions occur new elements could pass under the mouse cursor, or if onclick were used unwanted selections can be made.

Here's an example of an accordion-style menu driven by mouse clicks:

```html
<span id='h1'><b>News</b><
<div id='c1'>
  <a href='local.html'>Local News</a><br>
  <a href='world.html'>World News</a><br>
  <a href='business.htm'>Business News</a><br>
  <a href='technology.htm'>Technology News</a>
</div>
```
