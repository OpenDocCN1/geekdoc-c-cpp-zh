# How To Use It

To create set of backup properties for an object, pass its ID to the SaveState() plug-in, like this:

```
SaveState('myobject')
```

The following code shows a few style settings made to an object and then its state being saved:

```
<div id='mydiv'>Example Text</</div>

<script>
window.onload = function() {
  S('mydiv').width = Px(200)
  S('mydiv').height = Px(100)
  S('mydiv').backgroundColor = 'green'
  S('mydiv').color = 'white'
  S('mydiv').position = 'absolute'

  SaveState('mydiv')
}
</script>
```
