Interest in touch devices really picked up momentum with Apple's release of the iPad in the spring of 2010, I couldn't resist adding a bonus 101st plug-in to this collection. Here's the final plug-in, which allows you to touch-enable a web page. Example 13-8 shows a copy of the web page for Plug-in PHP, a companion to this one, in which a small frame has been attached to the top of the browser window with links to touch-enabling on and off.

## About the Plug-in

This plug-in changes the mouse click so that a click and drag operation becomes a scroll up, down, left and right simply by touching the screen and moving your finger (or a stylus), also, in the same manner as you would using an iPhone, iPad, Android phone, or other touch device. It requires the following argument:

- * If or true, touch enabling is turned on; otherwise, it is turned off

## How It Works

This plug-in starts by making a copy of document.body in the local variable db, thus creating a shorthand reference to shorten the code:

```
var db = document.body
```

The argument is when tested, and if it is 1 or true, touch enabling is turned on, the variables iid and flag are initialized, PreventAction() is called to disable the default actions for drag and select operations on the document body, and the onmousedown and onmouseup events of the document body are attached to the StartTE() and StopTE() subfunctions, as follows:

```
var iid = null
var flag = false
PreventAction(db, 'both', true)
db.onmousedown = StartTE
db.onmouseup = StopTE
```

If state is 0 or false, then touch enabling is be turned off, so PreventAction() is called to restore the default actions for drag and select operations on the document body, onmousedown and onmouseup event hooks are removed, and the plug-in returns:

```
PreventAction(db, 'both', false)
db.onmousedown = ''
db.onmouseup = ''
```

## The StartTE() Subfunction

This function checks the flag variable to see whether touch control has already been enabled. If it has, false is returned; otherwise, copies of the mouse cursor position are placed in temporary variables to compare later or if the document body should be scrolled, like this:

```
var oldmouse = MOUSE_X
var oldmousey = MOUSE_Y
var tempmousex = MOUSE_X
var tempmouse = MOUSE_Y
```

Next, flag is set to true to indicate that touch control has been enabled, and setInterval() is called to set up repeating interrupts to DoTE:

```
flag = true
iid = setInterval(DoTE, 10)
```
