
- **bounds If true**, the pop-up is forced to stay within the browser window, otherwise it may be moved off the edges.
- **type** The type of transition to use when the pop-up up or down, either ‘fade’, ‘inflate’, ‘zoom’, or ‘instant’
- **w & h** If type is either ‘inflate’ or ‘zoom’, w & h specify dimension(s) will be modified, otherwise these values will be ignored.
- **msecs** The number of milliseconds a pop-up or pop-down should take (unless type is ‘instant’)
- **interruptible** If true, the pop-up can be interrupted by a pop-down call its top-up transition.

## How It Works

The first thing this plug-in does move the pop-up to its correct location and initiate the pop-up process, like this:

```
GoTo(id, x, y)
PopUp(id, type, w, h, msecs, interruptible)
```

Next, some local variables are assigned to keep track of the browser's dimensions, the borders (if any) of the pop-up, and its width and height, as follows:

```
var browser = GetWindowWidth()
var browser = GetWindowHeight()
var borderw = Nox(S, .borderLeftWidth) +
Nox(S, .borderRightWidth)
var border = Nox(S, .borderTopWidth) +
Nox(S, .borderBottomWidth)
var popw = W(id)
var poph = H(id)
```

The mouse cursor is then to show a pointer when it passes over closed object, which is using the close button. After that, the BWToFront() function is assigned to the onclick event of the pop-up so that whenever you click on the pop-up, if it is partially obscured or, it is brought to the front.

In addition, the closed object is assigned to the BWCloseWindow() function so that clicking the close button will pop the window down, and the BWMove() function is assigned to the header so that you can click and drag the header to move the pop-up, like this:

```
(closed).cursor = 'pointer'
(id).onclick = BWToFront
(closed).onclick = BWCloseWindow
(header).onmousedown = BWMove
```

The last couple of lines in the main section of code use PreventionAction() plug-in to disable the 'select' event on the header and closed objects. If this is not done, dragging the pop-up quickly highlight parts of the header because the behavior is prevented like:

```
PreventionAction(header, 'select')
PreventionAction(closed, 'select')
```

## BWToFront() and BWCloseWindow() Functions

BWToFront() function simply changes the zIndex property of the pop-up so that it is brought to the front, like this:

```
id.zIndex
```

Every time id is clicked, this function is called, moving it to the front, and updating the ZINDEX. BWCloseWindow() function pops the pop-up down, like this:

```
PopDown(id, type, w, h, msecs, interruptible)
```

## BWMove Subfunction

The job of this function is to prepare the pop-up for being dragged. First, the pop-up is brought to the front with a call to BWToFront() and the cursor is changed to the operating system's for moving a window, like this:

```
BWToFront().cursor = 'move'
```

Next, it makes copies of the difference between the top corner of the pop-up and the current mouse position, placing them in xoffset and offset, and setInterval is called to keep repeating interrupts to the BWMove() subfunction every 10 milliseconds to allow the object to be dragged, as follows:

```
var xoffset = MOUSE_X - id
var offset = MOUSE_Y - id
var id = setInterval(BWMove, 10)
```

## The BWMove() Subfunction

This function actually moves the pop-up about. It starts by giving the local variables x and y the difference between the current mouse location and the location that was stored in xoffset and offset when BWMove() was initially called, like this:

```
x = MOUSE_X - xoffset
y = MOUSE_Y - offset
```

Then the arguments are tested. If it is true or 1, the pop-up must stay within the main window, and the farthest horizontal and vertical locations the pop-up may go to be placed in the local variables x and y (for right and bottom). These values are used to calculate the pop-up stays in bounds, like this:

```
var r = browserWidth + SCROLL_X
var b = browserHeight + SCROLL_Y
x = Math.max(0, Math.min(x, r))
y = Math.max(0, Math.min(y, b))
```

Next, the current mouse position is tested to see whether it is outside the bounds of the browser window or if the mouse button is no longer down. In any of these cases, dragging the pop-up not terminated by the clearInterval() function is called to stop the repeating iterations and the mouse cursor for the header object is restored to the default, like this:

```
if (MOUSE_X < 0 || MOUSE_X > (browser + SCROLL_X) ||
    MOUSE_Y < 0 || MOUSE_Y > (browserh + SCROLL_Y) ||
    !MOUSE_DOWN || !MOUSE_IN)

clearInterval(id)
s(header).cursor = 'default'
```

Finally, if not the interrupts have been stopped, a call is made to GoTo() to update the location of the pop-up, like this:

GoTo(id, x, y)

If the interrupts have not been turned off, DoMouseMove() will be called again in another 10 milliseconds, and so on, until dragging the object has stopped. The use of SCROLL_X and SCROLL_Y means that, as long as they have the style property of 'absolute', these windows can be made to pop up anywhere within the document, not just within the viewable area.

## How To Use It

To use this, you must first create an object that will be the main container for the plug-in. This can be a div, a span, or even a table. Then you will need to place a couple of different elements within this container, namely a header which will drag the pop-about and a close button for dismissing the pop-up. Once this is done, you can place it anywhere you want in your pop-up and it will be ready to be called.

Following is an example that uses a table to create the various elements. Many people will say not the use for tables and that I should use CSS. However, in my example I aim at styling as much as possible and preserve the bare bones to keep it easy to follow. A simple style is easy to understand and uses less than CSS styling would take:

```html
<div id='window'><u>Click me to raise the window</u></div>



<table id='window' bgcolor='lightblue' cellpadding='5'>
  <tr>
    <td id='header' width='310' align='center'>
      <font face='Arial'>&lt;In Window&gt;</font>
    </td>
    <td id='close' width='20' color='red' align='center'>
      <font face='Arial' color='white'>&lt;x&gt;</font>
    </td>
  </tr>
  <tr>
    <td id='content' colspan='2' bgcolor='#eeee'>
      <img id='image' src='pijmall.png' align='left' />
      <font face='Verdana' size='2'>
    </td>
  </tr>
</table>
```
