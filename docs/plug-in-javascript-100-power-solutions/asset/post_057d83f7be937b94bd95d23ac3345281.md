How It Works
This plug-in begins by checking id is an array. If it is, it iterates through it and recursively calls itself, separately passing each element of the array to be processed individually, like this:

```javascript
if (id instanceof Array) {
  for (var j = 0; j < id.length; ++j)
    PulsateOnmouseover(id[j], opl, op2, msecs)
  return
}
```

Next, the variable finish is set to false—it will later be set to true whenever mouse passes out of a stop and the pulsating has to stop. The id variable is also declared, which will be used to store the value returned by the setInterval() function:

After this, the opacity of id is set to the level in the argument opl, to which the FA_Level property of id is also set. This property is used by the Fade() plug-in, but this plug-in needs to access it in order to know when an object has faded in or out by the correct amount:


Finally, in the stop section, events of id are attached to the PulsateOn() subfunction for stopping the pulsations, and to an inline, anonymous function that sets the variable finish to true when the mouse moves away from an object, like this:

```javascript
O(id).onmouseover = PulsateOn
(id).onmouseout = function() { finish = true }
```

### PulsateOn() Subfunction
This function's job is to set the variables required before calling the DoPulsate() subfunction. It first declares the variable faded and assigns the value of false, indicating that the object is faded—it will be true when it is faded out. The finish variable is also set to false in the plug-in when restarted after having been previously stopped:

```javascript
var faded = false
finish = false
```

If the variable iid has a value, a previous call has been made to the plug-in, so it is passed to the clearInterval() function to stop any repeating interrupts that may currently be in place. After that, setInterval() is called to set up repeating interrupts to the DoPulsate() plug-in every INTERVAL milliseconds, like this:

```javascript
if (iid) clearInterval(iid)
iid = setInterval(DoPulsate, INTERVAL)
```

## How To Use It

The plug-in is written so that it will always fade back to the default opacity for an object when the mouse is moved away. To use it, attach it to any objects that you would like to pulsate when the mouse passes over them. These can be images, divs, spans, or anything that has opacity property that can be changed.
