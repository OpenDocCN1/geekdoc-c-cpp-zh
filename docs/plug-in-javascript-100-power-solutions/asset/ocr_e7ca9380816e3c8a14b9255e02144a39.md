# 98 ReplaceAlert()

If you like the Alert plug-in, you can use this one to replace the default JavaScript alert() with it and use it all the time. Figure 13-4 shows the alert() function being called to display the mouse's current coordinates in but the Alert () plug-in is handling the message display, as it has replaced the default function.

# About the Plug-in

This is probably the shortest plug-in in the book, and it requires no arguments to change the default action of alert() to use the new Alert () plug-in.
