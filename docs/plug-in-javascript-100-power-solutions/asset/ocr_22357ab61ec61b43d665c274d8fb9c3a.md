# How It Works

This plug-makes a call to the S() plug-in in such a way that you can pass it an array of objects and/or IDs, a single object, or an object ID. The style.visibility property of the object (or objects) is set to the value of a hidden HID, which is 'hidden'.

# How To Use It

To use this plug-in, pass the object or objects to make invisible. The following example shows one way you might incorporate it:

```
<span id='ghost'>Now you see me...</span> and soon as you won't

<script>
window.onload = function() {
  S('ghost').backgroundColor = 'lightblue'
  Resize('ghost', 128, 32)
  alert('Click OK to see the object disappear')
  Invisible('ghost')
}
</script>
```

This example first creates a span in the HTML section and gives it some text. Following is more text than what is inside the span. Then, in the <script> section, the span's background color is set to light blue and resized to make it stand out.

Next, an alert is raised to give you the chance to see the initial display before the call to the Invisible() plug-in is made. After clicking the alert OK button, the call is made, and the contents of the span becomes invisible.

+   * Tip If you want to keep your layout unchanged when hiding an object, you should use this plug-in in preference to Plug-in 40, Hide(). Plug-in 35 preserves an object's dimensions, while Plug-in 40 fully collapses an object, causing elements surrounding it to move in and occupy newly space.
