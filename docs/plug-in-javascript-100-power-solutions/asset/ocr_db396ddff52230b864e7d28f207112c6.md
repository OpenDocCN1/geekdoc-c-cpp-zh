# Plug-In JavaScript: 100 Power Solutions

In this chapter I'll show you how you can chain many of the plug-ins in this book to form sequences of actions or animations. These are animations you write to create stunning opening effects, or they can be small chains to perform simple actions as moving menu elements.

Chaining is also useful for ensuring that one action follow another. This can be hard to do in JavaScript because it is event driven, and therefore plug-ins called at the same time will normally run in parallel with each other. However, by adding what is known as a callback function at the end of the many of plug-ins, one plug-in can be set to call another when it completes—the term chaining.

You'll also learn how to use callbacks (like a mini, two-part chain) on those functions that support chaining.

# 53 Chain(), NextChain(), and Callback()

These plug-ins are a suite of functions that enable you to link up a sequence of plug-in calls to run in sequence, with each one calling the next when it has finished. This is a great way to create animation effects in JavaScript that you might think can be only done in programs as Java or Flash.
