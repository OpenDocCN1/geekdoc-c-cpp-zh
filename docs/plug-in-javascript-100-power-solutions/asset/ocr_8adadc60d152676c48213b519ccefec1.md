Figure 3-1 shows a group of three divs that all had their innerHTML properties set to the same value, using the code in the following example page:

```
<!DOCTYPE HTML PUBLIC "//W3C//DTD HTML 4.01 Transitional//EN"
"http://www.w3.org/TR/html4/loose.dtd">
<html><head><title>Plug-in JavaScript</title>

<script src="PJ.js"></script>
<script>Initialize();</script>

</head><body>

Fred: <span id="Fred"></span><br />
Mary: <span id="Mary"></span><br />
Bill: <span id="Bill"></span>

<script>
ids = Array('Fred', 'Mary', 'Bill');
O(ids, 'innerHTML', 'New contents...');
</script>

</body></html>
```

This is the first time you have seen a complete example of using the plug-ins. It begins with the <!DOCTYPE ...> setting, then adds both the <title> and the two <script> tags- lines required to include and set up the plug-ins. After that the <head> and <body> of the page is opened. Then three lines of HTML create simple <span> sections that don't contain any content.

Finally, there is another <script> section in the contents of these spans is changed so that each displays the string 'New contents...' This is the format that standard web pages will follow when using the plug-ins. The result of loading this page in a browser is shown in Figure 3-1.

Now you've seen how easy it is to use the plug-ins and how the different parts fit within a web page, throughout the rest of this book's examples I will omit everything before (and including) the <body> tag (except where a plug-in affects that particular section) and concentrate only on the relevant HTML and JavaScript to explain the usage of a plug-in.
