## 212 Plug-In JavaScript: 100 Solutions

As websites try to offer a better look and feel than their competitors, new ways of navigating through large numbers of pages are being devised all the time. Menus and navigation are probably the areas that make the most use of JavaScript for this purpose.

In the early days of JavaScript, the interaction was mainly limited to instant changes of location and color as the mouse passed over a menu, but nowadays savvy web users expect more fluid and appealing designs with fades, transitions, and more.

The plug-ins in this chapter give you a variety of solutions that you can use as-is, or you can build them into even more sophisticated systems. They range from sliding menus to pop-up and down menus, folding and context menus, and even a dock bar to the one used in Mac OS X.

## 60 HoverSliderMenu()

This plug-in expands on the final one in Chapter 7, HoverSlider(), to build a complete menu system, rather than just a single mobile. With it you can select a group of objects that will be attached to one of the edges of the browser and will slide into view when the mouse passes over the part showing. In Figure 8-1, two almost identical sets of objects containing links have been attached to the top and bottom of the browser.

### About the Plug-in

This plug-in takes an array of objects and lines them all along one of the browser edges where they become a collection of slide menus. The following arguments are required:

- ids: Array of objects and/or object IDs
- where: The edge should be attached to, either ‘top’, ‘left’, ‘right’, or ‘bottom’
- offset: How far along to locate the objects—if offset begins with a % symbol, the position will be that percent from the start, otherwise it will be offset pixels from the start
- showing: The number of pixels to leave of each object the mouse will pass over to cause the menu to slide

### How It Works

The first thing this-plugin assigns values to some local variables, like this:

```javascript
var len = ids.length
var total = gap * (len - 1)
var start = (offset[0] != '%') ? 0 : offset.substr(1) / 100
var a = []
var jump = 0
```

The variable len is assigned the number of items in the ids array, and total is assigned the width of all the gaps. Next, start is set to 0 or the value of offset / 100 if it begins with the character %. Later, if start is 0, the value of offset will be used to align the objects in their required positions at exact positions. Otherwise, start contains a percentage value for the start.

After this, the array is created to hold the widths of the objects and jump is initialized to 0; it will store the current widths and gaps so far, as each object is given its location.
Next, there are two sections of code, the first of which is executed either the top or bottom of the browser is used for the menu:

```javascript
if (where == TP || where == BM) {
  for (var j = 0; j < len; ++j)
```

```javascript
{
  a[j] = W(ids[j])
  total += a[j]
}

start = start ? (GetWindowWidth() - total) * start : offset * 1
```

The first line compares the argument with TP and BM (global variables containing the values 'top' and 'bottom'). If one of these values, the menu will be laid horizontally, the for () loop places all of the objects in the array by fetching them with the W() plug-in. The total variable is also increased by this value so that when the loop has finished it counts the sum of all object widths and all the gaps (the latter having been assigned earlier).

Then, if start is not zero, it calculates the percentage value that was previously assigned, so the width of the browser, as returned by GetWindowWidth() less the value in total, is multiplied by start. This value represents the percent offset from the start of the edge. However if start is 0, then offset contains the number of pixels the menus should be located from the edge. because this value may be a string, it is multiplied by 1 to turn it into an integer. The result is then placed in start.

The second part of the if () statement repeats the procedure, substituting values for the left or right edge of the screen, like this:

```javascript
{
  for (var j = 0 ; j < len; ++j)
    a[j] = H(ids[j])
    total += a[j]
}

start = start ? (GetWindowHeight() - total) * start : offset * 1
```

Finally, another for loop iterates through the array and calls the HoverSlide() plug-on for each object, placing them in all their correct positions based on the value of start, plus that jump. Initially, jump is zero so there is no additional offset, but each object is added to the menu, jump is incremented by the previous object width and the size of the gap, so that each object is located at the correct distance from the previous one.

### How To Use It

To use this plug-in, you need to create an object for each of the sliding menu parts. A div is perfect for the job. Fill each with the images, links, and any other contents you need, and make sure the edge of the div is a suitable tab that will make people want to pass their mouse over it. Now you will need to call the plug-in, like this:

```javascript
HoverSlideMenu(ids, 'top', '%50', 20)
```

In this example, the objects ids are passed to the plug-in, telling it to place the menus at the browser top, 50 percent along the edge, with 20 pixels.
