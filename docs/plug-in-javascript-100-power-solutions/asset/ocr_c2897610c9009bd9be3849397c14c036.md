CT_IID = setInterval(DoCurTrail, length)

# The DoCurTrail() Subfunction

This function performs the moving of all the trail images, which it manages with a for() loop, which with the first command moves the current iteration to its new position:

```
for (var j = 0; j < 10; ++j)
Goto(c + j, O(c + j).X, O(c + j).Y + 2)
```

For example, when j has the value 5, the image ID calculated with the expression c + j is manipulated, which is 'CT_5'. The number 2 in the code places the images down and to the right by two pixels.

Next, the zIndex of the image is set to the maximum zIndex so far plus 1, to ensure that it will display on top of all other elements:

```
S(c + j).zIndex = ZINDEX + 1
```

If it is set to display directly under the mouse pointer, the image is hidden. If it wouldn't, the user could not click a link because a trail image would be between the mouse pointer and the clickable object underneath:

```
if (c + j).X == MOUSE_X && O(c + j).Y == MOUSE_Y) Hide(c + j)
```

Otherwise, if the image is away from the mouse pointer, it is shown:

```
else Show(c + j)
```

+   Next, as long as j has a value greater than 0 (and therefore is indexing the nine trail images above the first), the image location of the image behind the current one is set to that of the current image:

```
if (j > 0)
{
O(c + (j - 1)).X = O(c + j).X
O(c + (j - 1)).Y = O(c + j).Y
}
```

Finally, the highest numbered image (with the ID 'CT_9') is either set to the current mouse location, or if the mouse is off screen, to a position well off the start of the screen (with the values 12 and 20 representing the width and height of the mouse pointer):

```
O(c + 9).X = MOUSE_X < (w - 12) ? MOUSE_X : -9999
O(c + 9).Y = MOUSE_Y < (h - 20) ? MOUSE_Y : -9999
```
