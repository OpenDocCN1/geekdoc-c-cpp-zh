# 290 Plug-In JavaScript: 100 Power Solutions

In this chapter, there are a number of plug-ins you can use for creating light boxes and slide shows (or combining the two), making rotating billboards for placing advertising news updates, or making objects pulsate as you pass the mouse over them.

There are also plug-ins to help create professional looking charts with the help of Google Charts, present YouTube videos in a variety of ways with a single function call, and play sounds in response to events or for any other reason.

# 77 Lightbox()

With this plug-in you can display an image or any object in the center of the browser with the outside darkened and made transparent by amounts you can specify. Your users can then view objects with minimum duration and simply click them to dismiss the light box. Figure 10-1 shows a photograph displayed using this plug-in.

# About the Plug-In

This plug-in displays a photo (or other object) centered in the browser, with a darkened frame over the web page below. It requires the following arguments:

+   * id An object or object—this may not be an array
* coll1 A starting color for the frame
* coll2 An ending color for the frame
* opacity The final opacity of the frame
* meecs The time in milliseconds the should take
