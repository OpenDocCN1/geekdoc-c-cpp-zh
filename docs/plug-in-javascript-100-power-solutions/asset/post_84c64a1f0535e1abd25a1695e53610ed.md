## 2 S()

Probably the most common use to which JavaScript is put is modifying CSS properties in HTML documents. These include colors, dimensions, location, opacity, and much more. Generally this is done using code such as the following, which changes the foreground text color of a div:

```javascript
document.getElementById('element').style.color = 'red'
```

Or, using the previous plug-in, this can be shortened to:

```javascript
O('element').style.color = 'red'
```

This is a common action that I have created a companion plug-in to O() called S (for Style), with handling an object's style subobject. Using it, the preceding commands can be reduced to the following:

```javascript
S('element').color = 'red'
```

### About the Plug-In
The S() is similar to O() with the exception that instead of referencing an object, object's style subobject is accessed. Also, since events are not used by it there is no need to check for this function. It accepts the following arguments:

- id This can be a string containing the ID of an object, or even an array containing several objects and/or IDs. If none of the optional arguments also provided then the function returns the style subobject of the object (or objects) represented by id. If there are optional arguments, the purpose of the function changes to assign the value to the property in property of the style subobject of the object (or objects) in.
- property This optional string argument can contain the name of a property belonging to the style subobject of the object (or objects) in id that requires modifying.
- value If this optional argument is set it represents the value to be assigned to property in property of the style subobject of the object (or objects) in id. Both the property and value arguments must have values, otherwise S() will simply return the style subobject of the object (or objects) in id.

## How It Works

Now that you understand how the O() plug-in works, you will have an idea how this one functions. Because it is similar, I'll just outline the basics.

As with O(), this function has three main parts. The first processes id if it happens to be an array. It does this by recursively calling itself with each element within the array as to deal with each one separately. The code that it does is as follows, with the final line returning an array of all the values returned during the process:

```javascript
if (id instanceof Array)
{
  var tmp = []
  for (var j = 0 ; j < id.length ; ++j)
    tmp.push(S(id[j], property, value))
  return tmp
}
```

The second section handles the case when you use the plug-in in its property assigning mode. It determines this by checking both the arguments property and value has. If you do, then property in property of the style subobject of the object represented by id is assigned the value in value.

Otherwise the object fetching mode is entered, and so the subobject of id is returned within try() statements that any errors can be caught and displayed via a call to alert(), using the matching catch() statements:

```javascript
if (typeof property != UNDEF && typeof value != UNDEF)
  try { return O(id).style[property] = value }
  catch(e) { alert('PJ - Unknown ID: ' + id) }
else if (typeof id == 'object') return id.style
else
{
  try { return O(id).style }
  catch(e) { alert('PJ - Unknown ID: ' + id) }
```

During development you will find this error catching very useful, mistyping ID names or accessing them before they have been declared are common errors.

> Note: I refer to the style subobject, could also call the style property, because it is both: it's a properly styled style, which is itself an object that has properties. Therefore I tend to refer to properties that are also objects as subobjects.

## How To Use It

You use the plug-in in much the same way as you use the O() function. With it you can fetch the style subobject of an object, or modify one of the style properties of object. Here's one way you could use the plug-in to first fetch and then use an object's style subplot:

```javascript
var _styleobject = S('mydiv')
styleobject.color = 'red'
```

Or, you can access the style directly, like this:

```javascript
S('mydiv').color = 'red'
```

If you wish, you can also set the value of a property like this:

```javascript
S('mydiv', 'color', 'red')
```

In this case, all the objects in the array will have their innerHTML set to:

```javascript
ids = Array('div1', 'div2', 'div3')
S(ids, 'innerHTML', 'red')
```
