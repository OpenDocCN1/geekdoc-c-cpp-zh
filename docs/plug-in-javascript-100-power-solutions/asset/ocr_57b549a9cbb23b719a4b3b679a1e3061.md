About the Plug-In
The S() is similar to O() with the exception that instead of referencing an object,
object's style subobject is accessed. Also, since events are not used by it there is no
need to check for this function. It accepts the following arguments:

+   - id This can be a string containing the ID of an object, or even an array
containing several objects and/or IDs. If none of the optional arguments
also provided then the function returns the style subobject of the object (or objects)
represented by id. If there are optional arguments, the purpose of the function
changes to assign the value to the property in property of the style
subobject of the object (or objects) in.
- property This optional string argument can contain the name of a property
belonging to the style subobject of the object (or objects) in id that requires
modifying.
- value If this optional argument is set it represents the value to be assigned to
property in property of the style subobject of the object (or objects) in id. Both
t property and value arguments must have values, otherwise S() will simply
return the style subobject of the object (or objects) in id.
