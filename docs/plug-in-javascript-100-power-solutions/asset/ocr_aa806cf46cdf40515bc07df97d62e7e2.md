# # How It Works

The first thing this plug-in does pop down all the objects in the contents array except for the first one

```
PopDown(contents.slice(1), type, w, h, 1, 0)
O(contents[]).PO_IsUp = true
```

slice() is used with a value of 1 to PopDown() all elements from the second element onward (because the first element of an array is 0). The msec argument to PopDown() is so that the transition is set to take only 1 millisecond and is, therefore, virtually instantaneous.

Next, the contents and arrays are iterated through a for () loop, using j as an index, like these:

```
for (var j = 0; j < contents.length; ++j)
{
  O(headings[j]).FO_C = contents[j]
  S(headings[j]).cursor = 'pointer'

  if (action == 'hover') O(contents[j]).onmouseover = DoFoldingMenu
  else O(contents[j]).onclick = DoFoldingMenu
}
```

Each heading has its FO_C property assigned the object in the associated contents array. Each heading will pop up and down the contents associated with it. When each heading its cursor property set to 'pointer', the mouse pointer will change when it passes over the heading.
After that action argument is tested. If it is 'hover', the DoFoldingMenu() subfunction is attached to the current heading's on event so that it will be called by passing the mouse over it.
Otherwise, the subfunction is attached to the current heading's onclick event so that it will only be called when the heading is clicked.

# # The DoFoldingMenu Subfunction

Once all the various properties and events are set up for the plug-in, the DoFoldingMenu() subfunction will be called whenever a change to the menus is required.
