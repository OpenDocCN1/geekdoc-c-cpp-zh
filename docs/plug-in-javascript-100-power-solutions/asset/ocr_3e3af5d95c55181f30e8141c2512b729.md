Table 1-3 details the default locations of root document that Zend Server CE creates on different operating systems. If you keep your various HTML, JavaScript, and PHP files in that folder (or subfolders), then they can all be served by the Apache web server.
Unfortunately there is no room to go into detail about Zend Server CE in this book, although there is one thing I should mention: you may find the Zend Server CE document root folder doesn't allow you to copy files into it by default. If you find this to be the case, you should change the folder permissions to grant access.

| TABLE 1-3 Server CE Document Root on Various Platforms |
| Operating System | Document Root |
|---|---|
| Windows | C:/Program Files/Zend/Apache2/htdocs |
| Mac OS X | /usr/local/zend/apache2/htdocs |
| Debian/Ubuntu Linux | /var/www |
| Fedora Linux | /var/www/html |
| Generic Linux | /usr/local/zend/apache2/htdocs |
