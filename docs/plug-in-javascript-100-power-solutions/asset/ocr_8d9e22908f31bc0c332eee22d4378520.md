# About the Plug-in

This plug-in takes an object and attaches to its mouseover and mouseout events to create a pulsating effect. It requires the following arguments:

+   - id An object or ID or an array of objects and/or object IDs
- opl The default opacity for the object, between 0 and 100
- opl The opacity to which the object should be faded, between 0 and 100
- msecs The number of milliseconds each full cycle should last

# Variables, Arrays, and Functions

| | Local variable used to index id if it is an array |
|---||
| j finish | Local variable used to set true if the pulsating stops |
| faded | Local variable set to true when the object is faded (or fading), otherwise false |
| iid | Local variable assigned the result of calling setInterval() to be used later when clearInterval() is called |
| FA_Level | Property of used by the Fade() plug-in to set its opacity |
| FA_Flag | Property of used by the Fade() plug-in and set to true to indicate that a fade transition is in progress, otherwise it is false or 'undefined' |
| onmouseover | Event attached to triggered when the mouse passes over |
| mouseout | Event attached to triggered when the mouse passes out |
| PulseateOn() | Subfunction that sets up the main variables |
| DoPulsate() | Subfunction that performs the transitions |
| Fade() | Plug-in to fade an object from one opacity level to another |
| setInterval() | Function to set up repeating interrupts to another function |
| clearInterval() | Function to stop the repeating interrupts |
