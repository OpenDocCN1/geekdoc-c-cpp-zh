```
O('link').onclick = function() {
  Slideshow('show', photos, 500, 2000)
  Lightbox('show', '#888888', '000000', 80, 50, 1)
}
</script>
```

In the HTML section, a div is created that will call the anonymous function when clicked, underneath there's an empty div. In the <script> section, the div is resized (with a call to Resize()) to the dimensions so that the Slideshow() function can center correctly—without these dimensions, the content of the div is not ready when the Center() call is made, the object may appear off center.
The div is also hidden with a call to Hide because now that it has dimensions will push any content below out of the way. The array photos is populated with URLs of five photos, and the function calls Slideshow() and Lightbox() to merge the two plug-ins.
Because Lightbox() pull-dimms itself when you click it, the slide will not stop, even when it's not visible. If you click the button again, the Slideshow() plugin will that still running and simply continue the slide.
If you want to turn the slide off, you need to set the SS_Stop property of 'show' to 1 or true, and the next time a slide change it will stop:

```
O('show').SS_Stop = true
```

This plug-in is designed so that you can place the content object anywhere you like and the slide show will occur at that position; you don't have to use it in a light box if you don't want to.
