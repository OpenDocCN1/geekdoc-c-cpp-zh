
# Plug-In JavaScript: 100 Power Solutions

```javascript
<script>
window.onload = function() {
  Locate('p1', ABS, 0, 0)
  Locate('p2', ABS, 160, 0)
  Locate('p3', ABS, 320, 0)
  Deflate('p1', 1, 2000, 0)
  Deflate('p2', 1, 2000, 0)
  Deflate('p3', 0, 1, 2000)
}
</script>
```

The HTML section of this example places three images on the screen and assigns them unique IDs. The <script> section then uses the Locate() plugin to give them a position of 'absolute' and places them overlapping each other, along the top of the browser.

The final three lines call a different Deflate() effect on each, which is achieved by passing different values of the second and third parameters. The first image shrinks only in a horizontal direction the width and height parameters are 1 and 0. The middle image has width and height parameters of 1 and 1, and it shrinks in both directions. The last image has width and height parameters of 0 and 1 and it shrinks only in a vertical.

The final two parameters of 2000 and 0 cause the animations to take 2000 milliseconds (each although they run concurrently), and the 0 specifies that they are not interruptible.

## The Plug-in

```javascript
function Deflate(id, w, h, msecs, interruptible, CB) {
  if (id instanceof Array) {
    for (var j = 0; j < id.length; ++j)
      Deflate(id[j], w, h, msecs, interruptible, CB)
    return
  }

  if (!w) ResizeWidth(id, W(id))
  if (!h) ResizeHeight(id, H(id))

  if (O(id).DF_Flag) {
    if (!O(id).DF_Int) return
    else clearInterval(O(id).DF_IID)
  } else {
    if (w) O(id).DF_OldW = W(id)
    if (h) O(id).DF_OldH = H(id)
    O(id).DF_Count = msecs / INTERVAL
  }

  var stepw = O(id).DF_OldW / (msecs / INTERVAL)
  var steph = O(id).DF_OldH / (msecs / INTERVAL)

  S(id).overflow = HID
  (id).Deflated = true
  (id).DF_Flag = true
  (id).DF_Int = interruptible
  (id).DF_ID = setInterval(DoDeflate, INTERVAL)
}

function DoDeflate() {
    if (w) ResizeWidth(id, stepw * O(id).DF_Count)
    if (h) ResizeHeight(id, step * O(id).DF_Count)
  }

  if (O(id).DF_Count < 1) {
    O(id).DF_Flag = false
    if (w) ResizeWidth(id, 0)
    if (h) ResizeHeight(id, 0)
    clearInterval(O(id).DF_ID)
    if (typeof CB != UNDEF) eval(CB)
  }
}
```

## Reflate()

This is the companion plug-in to Deflate(). With it, you can expand a deflated object back to its original dimensions over a specified period of time, with a choice of three different animation types. ## About the Plug-In

This plug-in takes an object (or an array of objects) and reinflates it to its original dimensions after it has been deflated using the Deflate() plug-in. You can call this plug-in only on objects that have been previously deflated, otherwise the call will be ignored. It takes the following arguments:

- id: An object, object ID, or array of objects and object IDs
- w: If true or 1, the object's width will expand to its original value
- h: If true or 1, the object's height will expand to original value
- msecs: The number of milliseconds the animation should take
- interruptible: If true (or 1), this plug-in can be interrupted by a new call on the same object; otherwise, if false (or 0), the call is uninterible

## Variables, Arrays, and Functions

| Variable | Description |
| :--- | :--- |
| j | Local variable containing index if it is an array |
| stepw | Local variable containing the amount of horizontal change per frame |
| steph | Local variable containing the amount of vertical change per frame |
| width | Local variable containing the width to which id should be changed at each step |
| height | Local variable containing the height to which id should be changed at each step |
| DF_Flag | Property of id that is true if a Deflate() call is in progress |
| DF_Int | Property of id containing true if deflation is interruptible |
| DF_ID | Property of id that clears with clearInterval() |
| DF_OldW | Property of id containing the unshrunk width of id |
| DF_OldH | Property of id containing the unshrunk height of id |
| DF_Count | Property of id that counts the number of frames in the animation |
| Deflated | Property of set to true if it has been deflated—used by Deflate() plug-in |
| INTERVAL | Global variable with the value 30 |
| setInterval() | Function to set repeating |
| clearInterval() | Function to stop repeating |
| DoRelate() | Subfunction to perform the animation |
| Resize() | Plug-in to resize an object |

## How It Works

This plugin works in a very similar way to the Deflate() plug-in with two main differences. First, if Deflated property of id is not true, the plug-in returns because the object cannot be reinstated. Here is the piece of code that does that:

```javascript
if (O(id).Deflated) return
```

Second, instead of DF_Count counting down from the maximum step to zero, it counts upward from 0 and is initialized to a value in this plug-in (as opposed to the value it is assigned with msecs / INTERVAL in the Deflate() plug-in). The DoRelate() function uses the following statement to increment the Count property each frame of the animation (decrementing, as in the Deflate() function):

```javascript
if (O(id).DF_Count >= msecs / INTERVAL
```

The Deflated property of id indicates whether an object is deflated or set to false by this plug-in (rather than true, with Deflate()), and the rest of the code is virtually meaningless, so please read the details on Deflate() for further details.

## How To Use It

You should call this plug-in on an object after the object has been defeated using the Deflate() plug-in. If you try to use it on an object that hasn't been deflated, the plug-in will simply return.

The following example is expanded from the one in the Deflate()-section. It has a div inserted before the images that you can pass the mouse over to either deflate or inflate the images:

```html
<span id='d'>Mouse Me</span>

<img id='p1' src='photo1.jpg' />
<img id='p2' src='photo2.jpg' />
<img id='p3' src='photo3.jpg' />

<script>
window.onload = function() {
  Locate('p1', ABS, 0, 30)
  Locate('p2', ABS, 160, 30)
  Locate('p3', ABS, 320, 30)

  O('d').onmouseover = down
  O('d').onmouseout = up

  function down() {
    Deflate('p1', 1, 0, 2000, 1)
    Deflate('p2', 1, 1, 2000, 1)
    Deflate('p3', 0, 1, 2000, 1)
  }
}
</script>
```

```javascript
function up()
{
  Reflate('p1', 1, 2000, 1)
  Reflate('p2', 1, 2000, 1)
  Reflate('p3', 0, 2000, 1)
}
</script>
```

This example replaces the direct calls to the Deflate() plug-in with a pair of new functions, down() and up(). These are attached to the onmouseover and mousmouseout events of the span displaying the text "Mouseover Me", so that when you move the mouse over the text objects deflate, and when you move out, they inflate.

The calls to the two plug have their final parameter set to 1. This is the interruptible argument, and therefore, interrupting of the plug-ins has been enabled. This means that the example is very responsive and the animations occur immediately upon moving the mouse in or out of the span, taking into account the current amount of deflation or reflation to smoothly inverse the previous animation.
