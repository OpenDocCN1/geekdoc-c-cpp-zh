```
<script>
window.onload = function() {
  setInterval(simpleInterrupt, INTERVAL);

  function simpleInterrupt() {
    O('output').innerHTML =
      ' Mouse_X = ' + MOUSE_X + ',' + MOUSE_Y +
      ' Scroll_X,Y = ' + SCROLL_X + ',' + SCROLL_Y
  }
}
</script>
```

The first section is within the HTML body of a web page and is used to create a div into which the output will be. Underneath this div's a line of text made up of repeating the word Padding. This is used to make the text overflow (since there are no spaces in it), causing the scrollbar to appear so you can move the offset value in real time. If your browser is set very wide, you should resize it until the scrollbar appears.
In the <script> section there is a single main line of code that sets up a regular interrupt using the setInterval() function, passing the name of the function to call (which is simpleInterrupt) and the frequency at which it should be called in INTERVAL (which is 30 by default). This function simpleInterrupt() will be called every 30 milliseconds.

> Tip In JavaScript, whenever you want to reference a function by its name without actually calling the function, you omit the opening and closing brackets. In this instance, the setInterval() knows that you are passing only the name of the function. If you used opening and closing brackets, the function would be called first and the value returned would be passed to the setInterval() function, which is probably not you want.

The simpleInterrupt() function uses the O() plug-in you have to select the div 'output' object by name. It assigns the string to that object's innerHTML. This has the effect of inserting the string as if it were entered between the opening and closing tags. The value is some text and the values in global variables.
To try for yourself, enter the example code (as well as the required pair of script>) commands to load the Pl.js file and calling Initialize( plug-in), or select example04.html from the plug-ins zip file, which you can download from the companion website at pluginjavascript.com.
Resize your browser so that it is fairly small and the bottom scrollbar is visible.
Move the mouse about within the browser and move the scrollbar to see the values displayed change in real time. By the way the scrolling event works, you will only see its values change when you release the mouse button after moving one of the scrollbars.
