# The Plug-ins

```
function W(id) {
    var width = O(id).offsetWidth +
    NoPx(id).marginLeft +
    NoPx(id).marginRight

    var bord = O(id).borderLeftWidth +
    NoPx(id).borderRightWidth

    if (bord > 0) width = bord
    else if (O(id).border) width = O(id).border *

    return width
}
```
