# 71 TextType()

This plug-in emulates an old-fashioned typewriter or a teletype machine by outputting the text contents of one character at a time, over a period of time specified by you. Figure 9-2 shows a phrase being displayed with this plug-in.

## About Plug-in
This plug-in takes an object that contains text and displays it one character at a time. It requires the following arguments:
- An object, object ID, or array of objects
- number The number of times to repeat
- msecs The number of milliseconds it should take to type out the text

## Variables, Arrays, and Functions

## How It Works

The plug-in begins iterating through id if it is an array, recursively calling itself to individually process each element, like this:

```
if (id instanceof Array) {
  for (var j = 0; j < id.length; ++j)
    TextType(id[j], number, msecs)
}
```

The TT_Flag property of id is then tested. If it's true, a call to this plug-in is already operating on the object, it returns. Otherwise, the property is set to true to indicate a call is in progress on the id, as follows:

```
if (O(id).TT_Flag) return
else O(id).TT_Flag = true
```

Next, some variables are used to hold the content of id, the length of the text, the frequency at which the DoTypeText() function must be called in order for typing msecs milliseconds, a couple of counters and, finally, the repeating interrupts are set up with a call to setInterval(), with these statements:

var freq = Math.round(msecs / len)
