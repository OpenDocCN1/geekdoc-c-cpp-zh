About the Plug-in
Each time this plug-in is called, the object or objects passed to change their visibility to the opposite side. It requires the following argument:

+   - id An object, an ID, or an array of objects and/or object IDs

# Variables, Arrays, and Functions

| j | Local integer for indexing it if it is an array |
| visibility | The object's style.visibility property |
| HID | Global variable with the value 'hidden' |
| VIS | Global variable with the value 'visible' |

# How It Works

This plug-in uses the recursive trick that many others employ to handle arrays of and/ object IDs, as well as single objects and object IDs. It does this using the instanceof operator to test whether it is an array. If it is, the array is iterated through the local variable j in a for loop, individually calling the function recursively for each element of the array. Once done, the function returns.
If it is not an array, the S() plug is called, with the inverse of the object's style.visibility property. This is achieved using the following ternary expression, along with the global variables HID and VIS, which stand for the 'hidden' and 'visible':

```
S(id).visibility = (S(id).visibility == HID) ? VIS : HID
```

In plain English, this statement means 'If the current value of the object's style.visibility is 'hidden', return the value 'visible'; otherwise return the value 'hidden'. Everything after the first equals and before the question mark is the test. The value immediately following it is the one to return if the result is true, and the final value is to be returned if the result is false.
All this has the effect of applying the opposite side of the visibility property to the object.

# How To Use It

You can call this plug-in directly from JavaScript, like this:

```
VisibilityToggle('myobject')
```

Or you pass an array of objects, like this:

```
ids = Array('firstobj', 'secondobj', 'thirdobj')nVisibilityToggle(ids)
```
