```
Hide(Array('11', '12', '13'))
O('h1').onmouseover = function() { Show('11') }
O('h1').onmouseout = function() { Hide('11') }
O('h2').onmouseover = function() { Show('12') }
O('h2').onmouseout = function() { Hide('12') }
O('h3').onmouseover = function() { Show('13') }
O('h3').onmouseout = function() { Hide('13') }
}
<script>
```

This is all straightforward. The HTML section is in two parts. The first displays a header with the three spans containing subheadings, and the second displays three divs, each containing a different limerick.

The <script> section then hides all three of the divs with a single call to Hide () which an array of IDs is passed. This follows six statements that attach either the Hide () or Show () plug-in to themouseover and mouseout events of the subheadings via use of anonymous inline functions.
Whenever the mouse is passed over any subheading, the matching div will be displayed using a call to Show(). As the mouse passes out of the subheadings, a matching call to Hide () is made to remove it again.

# Placing the JavaScript within HTML

As you have noticed, my preference when choosing such interactive sections of a web page is to prefer using strong separation between HTML and JavaScript. I find that it makes the HTML more readable and faster to update. However, if you prefer to embed JavaScript within HTML:

```
<span id='h1' onmouseover="Show('11')" mouseout="Hide('11')">Beard
Limerick/</span>
<span id='h2' onmouseover="Show('12')" mouseout="Hide('12')">Bee
Limerick/</span>
<span id='h3' onmouseover="Show('13')" mouseout="Hide('13')">Chin
Limerick/</span></span></p>
```

If you do this method of attaching to the mouse events, you can remove the final six statements in the <script> section, but you will still need to keep the initial Hide () statement in order to hide all divs on page load.
