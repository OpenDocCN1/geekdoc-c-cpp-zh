# Variables, Arrays, and Functions

| x, y | Local variables containing the current and top edges of the location of content |
| MOUSE_X, MOUSE_Y | Global variables containing the current mouse x and y coordinates |
| PO_IsUp | Property of id that is false if it is popped down, otherwise it is popped up |
| FA_Flag | Property of id set by the Fade() plugin when a fade is in progress on id |
| DF_Flag | Property of id set by the Deflate or Inflate() plugin when a deflate or inflate is in progress on id |
| zIndex | Style property of contents containing its depth location from front (highest) to lowest |
| Context_IID | Property of id returned by calling setInterval() to later be used by clearInterval() |
| SetInterval() | Function to start repeating interrupts |
| clearInterval() | Function to stop repeating interrupts |
| Locate() | Plug-in to set an object's style position and coordinates |
| PopUp() | Plug-in to pop up a previously popped down object |
| PopDown() | Plug-in to pop down an object |
| W(),H() | Plug-ins to return the width and height of an object |
| ContextUp() | Subfunction to pop up when the mouse is right-clicked |
| ContextDown() | Subfunction of ContextUp() to check whether the mouse moved out of the space occupied by contents and if so to remove it |

# How It Works

This plug-in releases the contents object from its position in the HTML document by using the Locate() plugin to give it a style position of ABS (a global variable with the value 'absolute'). Next, it moves off screen to a location thousands of pixels away, removing it from the browser as quickly as possible so not to appear within your page.
Next, contents are popped down, to be popped up when required, and the oncontext event of id is attached to the ContextUp() function, which will pop up contents when id is right-clicked.

```
Locate(contents, ABS, -10000, -10000)
PopDown(contents, type, 1, 1, 1, 0)
O(id).oncontextmenu = ContextUp
```
