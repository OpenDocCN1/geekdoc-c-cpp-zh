To prevent the text from moving on the page as the larger characters in a ripple increase its height, each line on which a ripple can be triggered has the html <font size='+4'>&nbsp;</font> immediately preceding it. This ensures that the height of the line is always set to the maximum +4 size of font used by the plug-in. You can also use CSS styling, and other methods to enclose lines that are wrapped and prevent them moving themselves or other elements

The <script> section passes an array of the objects to the O() plug-in, along with the 'mouseover' event name as a string, and the name of the function ripple below it. The ripple function then uses this keyword, which acts as a pseudo object representing the object that triggered the event. This saves having pass arguments to the function, keeping the code short and simple.
