If the argument has either of the values 'top' or 'bottom' (tested by the global variables TP and BM), then the verticalAlign style property of the element is set to the value in where. Otherwise, there must have a value of 'left' or 'right' to set the align property of the element given that value.

Next, element's original width and height is extracted from the W() and H() plug-ins and placed in the local variables oldw and oldh, like this:

```
oldw = W(items[j])
oldh = H(items[j])
```

After that, the cursor to display when the mouse is over an element is set to 'pointer' and several properties are created, as follows:

```
S(items[j]).cursor = 'pointer'
O(items[j]).DB_Parent = id
O(items[j]).DB_Where = where
O(items[j]).DB_OldW = oldw
O(items[j]).DB_OldH = oldh
O(items[j]).DB_NewW = Math.round(oldw + oldw) * increase / 100
O(items[j]).DB_NewH = Math.round(oldh + oldh) * increase / 100
```

This causes information about the element and the containing it is located within to be stored as new properties of the elements. These properties can be referenced by the following DockUp() and DockDown() subfunctions and also referenced from within the Zoom() plug-in which one relies on.

First, the object is copied to the DB_Parent property. The value in where is copied so that Zoom() will know where to place the element as it zooms, and oldw and oldh are added as properties to tell Zoom() where to zoom up from. The width and height of that element are zoomed up to are by increasing the original width and height by the percentage value in increase and placed in the DB_NewW and DB_New properties.

The final statements in this loop attach the DockUp() and DockDown() subfunctions to the element's mousemouseover and mouseout events, respectively, as follows:

```
O(items[j]).onmouseover = DockUp()
O(items[j]).onmouseout = DockDown
```

Finally, in the setup section of code, the object id is moved to the edge indicated by the value in where, like this:

```
GotoEdge(id, 50)
```

# The DockUp() and DockDown() Subfunctions

These functions trigger the popping up or the popping down of an element by passing the previous properties of the pseudo object to the Zoom() plug-in; this being a keyword that represents the object that triggered the event that called the function.
