# Chapter 5: Visibility

```
O('il1').mouseover = function () { Fade('il1', 0, 100, 1000, 0) }
O('il1').mouseout = function () { Fade('il1', 0, 100, 1000, 0) }
O('id2').mouseover = function () { Fade('id2', 100, 0, 1000, 1) }
O('id2').mouseout = function () { Fade('id2', 0, 100, 1000, 1) }
</script>
```

The HTML section sets up two images with the IDs of 'il' and 'id2'. In the <script> section the mouseover and mouseout events of each are attached so that the objects will fade when the mouse passes over them and fade again when the mouse leaves. For the sake of brevity, I will use anonymous functions instead of named functions.

The calls to Fade for the first image, 'il', have the interruptible set to 0, which means they cannot be interrupted and will always continue to completion. The second image has the interruptible set to 1, which allows interruptions.

# The Difference between Interruptible and Noninterruptible Calls

Try moving over the pair of images and note what happens. You will see that the second image smoothly fades in and out as the mouse enters or leaves, always picking up from the opacity level of the fade that was interrupted.

On the other hand, the first is harder to control because you can only make it out or in from a fully opaque or a fully transparent state; you cannot interrupt it partly. This means if you move the mouse away from the first image before the transition has complete, the mouse will be out, so there will be no mouseout event to trigger until you move back in again and wait for the transition to complete, and then move the mouse out.

You'll see what I mean when you experiment with the example, and it will become clear how the noninterruptible method is ideal for animations and transitions that you want to always complete, while interruptible ones are best used when user interaction with the mouse is required.

# The Plugin-in

```
Fade(id, start, end, msecs, interruptible, CB)
{
  if (instanceof Array) {
    for (var j = 0 ; j < length ; ++j)
      Fade(id[j], start, end, msecs, interruptible, CB)
  }
  return
}

var stepval = Math.abs(start - end) / (msecs / INTERVAL)

if (O(id).FA_Flag)
{
  if (!O(id).FA_Int) return

  clearInterval(O(id).FA_IID)
  O(id).FA_Start = O(id).FA_Level
}
```
