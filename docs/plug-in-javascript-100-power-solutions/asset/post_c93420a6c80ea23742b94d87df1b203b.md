# How It Works

This plug-in makes a call to the S() plug-in in such a way that you can pass it an array of objects and/or IDs, a single object, or an object ID. The style.visibility property of the object (or objects) is set to the value of a HID, which is 'hidden'.

This example first creates a span in the HTML section and gives it some text. Following is more text than what is inside the span.
