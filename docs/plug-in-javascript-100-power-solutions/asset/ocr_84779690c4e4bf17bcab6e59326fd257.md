Note As already mentioned, using objects that have an odd value for one or more dimensions you may see a slight pixel jitter occur either horizontally or vertically during a flip. This happens because there are differences between the way different browsers round fractional numbers and is fixed by the flip-in the object's positions before a flip and restoring them afterwards. Even though it's almost imperceptible, if you wish to avoid this disturbance, you should only work with dimensions that have even values. It's easy to ensure this with a call to the Resize() link prior to using Flip().

# 59 HoverSlide()

This plug-in places an object on one edge of the browser with a small portion of it revealed and remained hidden. When you pass your mouse over it, the object slides out into the window to reveal itself and then slides back when you move the mouse.
Figure 7-8 shows an object that has been attached to the top of a browser, showing only the keys of a piano. In Figure 7-9, the mouse has passed over the keyboard and slid the object into the browser to reveal itself.

# The Plug-in

This plug-in places an object across one edge of a browser boundary with most of it unseen, outside the browser, and a small area showing that you can pass the mouse to move the object slide in and out. It requires the following arguments:

+   * Either an or an object ID—this cannot be an array of objects
* where The edge to which the object should be attached out of ‘top’, ‘left’, ‘right’, and ‘bottom’
