```
url = 'http://pluginjavascript.com/plug-ins/ajaxget.php'
args = 'http://wikipedia.org/''
GetAjaxRequest('a', todiv, args)

function todiv() {
  Html('a', this)
}
</script>
```

The `ajaxget.php` program is a very simple, one-liner that looks like this:

```
`<?php if (isset($_GET['url'])) echo file_get_contents($_GET['url']); ?>
```

If your server supports PHP (and most do), you can use the same script on to check whether the server has a server query string looking like `url=http://example.com?args=vals`. (In the case of the preceding example, the `args=vals` section is specified in the page that assigns the string `url=http://wikipedia.org/` to the args variable).

The `ajaxget.php` script then uses the `file_get_contents()` PHP function to fetch the requested data (in this case the Wikipedia page), which is then returned using the PHP echo command, which puts the data it fetched.

The `todiv()` callback function, which was passed to `GetAjaxRequest()`, is then called back and returns the retrieved data, which then inserts into the `innerHTML` property of the div.

# The Plug-in

```
function GetAjaxRequest(id, type, args) {
  var nocache = Math.random() * 1000000
  var ajax = new CreateAjaxObject(id, type)
  if (!ajax) return false

  ajax.open('GET', url + '?' + args + nocache, true)
  ajax.send(null)
}
```
