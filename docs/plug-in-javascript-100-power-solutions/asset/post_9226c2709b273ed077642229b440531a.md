## Visible()

This is the partner plug-in to Invisible(). It makes a previously invisible object visible. Figure 5-3 expands the example in the previous plug-in. This plug-in makes an object visible after it has been made invisible. It requires the following:

## How To Use It

To make invisible objects reappear, just pass them to this plug-in. The following extends the previous plug-in to make the hidden span reappear:

```html
<span id='ghost'>Now you see me...</span> and soon you won't
<script>
  window.onload = function() {
    S('ghost').backgroundColor = 'lightblue'
    Resize('ghost', 128, 32)
    alert('Click OK to see the object disappear')
    Invisible('ghost')
    alert('Click OK to see the object reappear')
    Visible('ghost')
  }
</script>
```

Just the final two lines of code in this example are new: an alert, so that you can verify the span was made invisible, and a call to Visible() that is executed after clicking OK, which makes the object reappear.

## 33 VisibilityToggle()

This plug-in inverts the visibility of an object. If it is visible it becomes invisible, or if it is invisible becomes visible. In Figure 5-4, each time the button is clicked, the text to the right toggles between visible and invisible.

### About the Plug-in

Each time this plug-in is called, the object or objects passed to change their visibility to the opposite side. It requires the following argument:

- id An object, an ID, or an array of objects and/or object IDs

## Variables, Arrays, and Functions

| variable | description |
| :--- | :--- |
| j | Local integer for indexing it if it is an array |
| visibility | The object's style.visibility property |
| HID | Global variable with the value 'hidden' |
| VIS | Global variable with the value 'visible' |

## How It Works

This plug-in uses the recursive trick that many others employ to handle arrays of and/ object IDs, as well as single objects and object IDs. It does this using the instanceof operator to test whether it is an array. If it is, the array is iterated through the local variable j in a for loop, individually calling the function recursively for each element of the array. Once done, the function returns.

If it is not an array, the S() plug-in is called, with the inverse of the object's style.visibility property. This is achieved using the following ternary expression, along with the global variables HID and VIS, which stand for the 'hidden' and 'visible':

```javascript
S(id).visibility = (S(id).visibility == HID) ? VIS : HID
```

In plain English, this statement means 'If the current value of the object's style.visibility is 'hidden', return the value 'visible'; otherwise return the value 'hidden'. Everything after the first equals and before the question mark is the test. The value immediately following it is the one to return if the result is true, and the final value is to be returned if the result is false.
All this has the effect of applying the opposite side of the visibility property to the object.

## How To Use It

You can call this plug-in directly from JavaScript, like this:

```javascript
VisibilityToggle('myobject')
```

Or pass an array of objects, like this:

```javascript
ids = Array('firstobj', 'secondobj', 'thirdobj');
VisibilityToggle(ids)
```

Alternatively, you can incorporate the call within HTML, as in the two lines of HTML that contain the text in span called 'toggle' to switch between invisible or invisible each time the button is clicked (you could equally attach it to onmouseover or other event): you will see this plug-in used in a number of the other plug-ins, in various ways.

Note calling this plug-in from HTML illustrates the main reason why nearly all these plug-ins allow you to pass either an ID or an object. In the preceding example, the object ID of 'toggle' is passed to the plug-in, but this object (which is an object, not the ID of an object) also be passed, telling the plug-in that the HTML object in which the call is embedded is one to manipulate. This is how rollover and other effects are achieved—on this next plug-in, and in Chapter 8, "Menus and Navigation."

## The Plug-in

```javascript
function VisibilityToggle(id)
{
  if (id instanceof Array)
  {
    for (var j = 0; j < id.length; ++j)
      VisibilityToggle(id[j])
  }
}
}
```

## 34 Opacity()

Being able to switch from invisible to visible is great, but sometimes you need finer control over an object's visibility. This is referred in JavaScript by the term opacity. With this plug-in, you can set the opacity of any object to a value between 0 and 100 percent (totally transparent, or invisible through.) 5-5 shows three buttons displayed using the default opacity of 100 percent. In Figure 5-6 each has been clicked to change its value to 25 percent, 50 percent, or 75 percent, respectively.

## About the Plug-in

This plug-in applies the opacity setting supplied to the object or objects. It requires the following arguments:

- id An object, an object ID, or an array of objects and/or IDs
- percent The amount of opacity to apply to the object or objects, from 0 percent, which is fully transparent, to 100 percent, which is fully opaque.

## Variables, Arrays, and Functions

| variable | description |
| :--- | :--- |
| opacity | The style.opacity property used by most browsers |
| MozOpacity | The version of the opacity property used by Mozilla-based browsers as Firefox |
| HtmlOpacity | The version of the opacity property used on older versions of the Apple browser |
| filter | Used to implement Microsoft's version of the opacity property (and many others too) |

## How It Works

This plug-in makes four calls in turn because various browsers approach the subject of opacity in different ways. Frankly, none of the methods clash with each other, so a lot of if...then code is not necessary. The first line for most browsers (as Opera, Google Chrome, and recent versions of Apple Safari) looks like this:

```javascript
S(id, 'opacity', percent / 100)
```

This simply takes the value in percent, divides it by 100, and applies it to the style opacity of id. Of course, if id is an array, all its elements will have that property updated.

However, Mozilla-based browsers such as Firefox have their own property for this function, the following line of code performs the equivalent by changing the style.MozOpacity. Likewise, the third line is for Safari browsers that use the old rendering engine (before Webkit was introduced) and therefore require the style HtmlOpacity property to be changed.

Finally, Microsoft chose a more complicated approach and includes opacity as part of their standard and transparency group of features. The object's filter property is set in the following manner (for a setting of 25 percent, example):

```javascript
S(id).filter = 'alpha (opacity = 25)'
```

However, because you need to take into account the fact that id could be an array, the following version of it is made, with both the property and setting values passed to the S() plug-in:

```javascript
S(id, 'filter', 'alpha (opacity = 25)')
```

Also, rather than a numeric value, a string has to be assigned to the filter property which requires construction. So, in order to place the value in percent in the string, the following code is used (employing the InsVars plug-in):

```javascript
S(id, 'filter', InsVars("alpha (opacity = #1#)", percent))
```
