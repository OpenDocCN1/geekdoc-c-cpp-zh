# About the Plug-ins

These plug-ins return the absolute horizontal or vertical offsets of an object from the left
top of the browser window. They take this argument:

+   * id The object whose offset is to be returned

# Variables, Arrays, and Functions

| obj | Local object copy of the id object |
| offset | Local integer used to hold the horizontal or vertical offset |
| offsetParent | The parent offset object |
| offsetLeft | The object's left offset |
| offsetTop | The object's top offset |

# How They Work

These plug-ins make a copy of the object represented by id in obj and the local
variable offset to either the offsetLeft or offsetTop property of the object. This is the
amount by which the object is from its parent.

Then, in case the parent object is also a subobject, the if() and while() statements
recurse through all parent objects, adding their offsets in turn to offset, until there
are no more parent objects. This point offset contains the absolute distance in pixels
from the left side or top edge of the browser window to the left or top of the object. This is
value is then returned.

# How To Use Them

To use these plug-ins, pass the ID of an object to them and they will return either the\absolute horizontal or absolute vertical position of its left side or top edge in pixels. Here's
some code to illustrate their use:
