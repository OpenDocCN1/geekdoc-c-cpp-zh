# The StopTE() Subfunction
This function simply sets the flag variable to false to indicate that a scroll is not currently in operation and clears the repeating intervals. The document will not scroll until the mouse button is held down once—the same action as a touch screen.

# How To Use It

To use this plug-in, call it up with a value of 1 or true, like this:

TouchEnable(1)

To turn it off, call it with a value of 0 or false, like this:

TouchEnable(0)

The following example shows how you can enable and turn off controls for this feature in a web page, in a similar way to the one shown in Figure 13-8:

```
<div id='enabled'><font size='1' face='Verdana'>
This webpage has been <TouchEnable(1)>;&nbsp;
<a href="javascript:TouchEnable(1)"
target&#38;
title="ontouchscreen control">Activate/</a>&#38;
<a href="javascript:TouchEnable(0)"
title="Turn off touchscreen control">Deactivate/</a>&#38;
<a href="javascript:FadeOut('enabled', 1, 1000)"
title="Remove this panel">\x201d;Remove this panel/</a></font>
<br /><font size='1' face='Verdana'>
```

When activated you can touch anything to scroll this page using a touchscreen/</div>
