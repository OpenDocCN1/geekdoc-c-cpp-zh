# **Variables, Arrays, and Functions**

| | |
|---||
| j | Local variable to index id if it is an array |
| stepw | Local variable containing the amount of horizontal change per frame |
| steph | Local variable containing the amount of vertical change per frame |
| width | Local variable containing the width to which id should be changed at each step |
| height | Local variable containing the height to which id should be changed at each step |
| overflow | The object's `style.overflow` object, which is set to HID ('hidden') to prevent an object's contents overflowing as it shrinks |
| DF_Flag | Property of id containing true if a `Deflate()` is in progress |
| DF_Int | Property of id containing true if the deflation is interruptible |
| DF_ID | Property of used to clear an interrupt with `clearInterval()` |
| DF_OldW | Property of id containing the unshrunken width of id |
| DF_OldH | Property of id containing the unshrunken height of id |
| DF_Count | Property of id that contains the number of frames in the animation |
| Deflated | Property of id set to true if it has been deflated—used by the `DeflateToggle()` `plugin` |
