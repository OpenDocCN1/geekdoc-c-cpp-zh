# About the Plug-in

This-plugin returns the HTML code required to embed a YouTube video. It requires the following arguments:

+   - **video** A YouTube video identifier like 'apEpZpynN_1lg'
- **width, height** The width and height at which to display the video
- **hq** If 'true' (and it is available), the video is played in high quality
- **full** If 'true', the video is allowed to be viewed in full screen
- **auto** If 1, the video starts playing automatically

# Variables, Arrays, and Functions

| temp | Local variable containing the HTML to display the video |
| InsVar() | Plug-in to insert values into a string |

# How It Works

This-plugin begins by assigning hq the query string to display a video in high quality (if the argument is l or true); otherwise, it is the empty string:

```
if (hq) hq = '&amp;ap=%2526fmt%3D18'
else hq = ''
```

The next lines of code account for when one or both of the width or height arguments are omitted, assigning default values to them that will display a video in a 4:3 aspect ratio, if required:

```
if (width && height) height = width * 0.7500
if (!width && height) width = height * 1.3333
if (!width) width = 425
if (!height) height = 324
```
