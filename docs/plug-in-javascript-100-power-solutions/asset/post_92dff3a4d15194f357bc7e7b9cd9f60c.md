# 15 InsVars()

In JavaScript, when you want to create a string that also includes the values of different variables, you have to keep the string, then use a + sign followed by the variable name, follow it with another +, and then re-open the string—and you have to do this for every single variable. However, this plug-in lets you easily drop the values of variables into any string. Figure 3-15 shows three values inserted in this manner.

# About the Plug-in

This plug-in requires at least two arguments. The first is the string in which to insert values and the second, third, and so on, are the values to be inserted as follows:

- string: The string in which to insert values
- value1: A value to insert in string
- value2: As value1 (etc...)

# Variables, Arrays, and Functions

| Name | Description |
| :--- | :--- |
| tmp | Local variable containing the string to process |
| arguments | Array of arguments passed to the plug-in |
| replace() | JavaScript function to replace substrings in a string |
| regExp() | JavaScript function to create a regular expression |

# How It Works

This plug-in uses the handy fact that JavaScript passes an array to every function that is called. This array is called arguments, and each element of it is one of the values that has been passed to the function.

Therefore, the first element is extracted and placed in tmp, a local variable. This is the string to make the variable substitutions, like this:

```javascript
var tmp = arguments[0]
```

Then a for() loop is used to iterate through each remaining element. If there is a substring with the value '#1' within the string tmp, the first is inserted in its place. The same happens for '#2', '#3', and any number of similar substrings, each being replaced by the next line of the values passed to the plug-in, like this:

```javascript
tmp = tmp.replace(new RegExp('#' + j, 'g'), arguments[j])
```

To allow one value to be inserted in many places in a string, a global replace is enabled by using the RegExp() object to create a new regular expression with the value 'g' supplied to indicate a global search and/or.

Finally, the modified tmp string is returned.

# How To Use It

To insert values into a string using InsVars(), you call it in the following manner:

```javascript
string = InsVars("The product of #1 and #2 is #3", 6, 7, 6 * 7)
```

This statement will assign the value "The product of 6 and 7 is 42" to string. All you have to remember is to use the same number of tags as there are values to be inserted.

# The Plug-in

```javascript
function InsVars()
{
  var tmp = arguments[0]

  for (var j = 1; j < arguments.length; ++j)
    tmp = tmp.replace(new RegExp('#' + j, 'g'), arguments[j])
  return tmp
}
```

# How To Use It

To use this function, pass it a string and a number, like this:

```javascript
string = StrRepeat('Hip, Hooray!', 3)
```

# The Plug-in

```javascript
function StrRepeat(str, num)
{
  var tmp = ''
  for (var j = 0; j < num; ++j)
    tmp += str
  return tmp
}
```

# Dec()

This plug-in converts a decimal number to hexadecimal string.

# About the Plug-in

This plug-in requires a decimal number to be converted.

- n: The decimal number

# Variables, Arrays, and Functions

| Name | Description |
| :--- | :--- |
| toString() | JavaScript function for converting to string |

# How It Works

This plug-in uses a ternary expression to check if the number is less than 16.

```javascript
n < 16 ? '0' : ''
```

If the result is true, it returns '0', otherwise, it returns an empty string. This ensures that the hexadecimal number always has two digits. Having padded the number with a 0 (if necessary), the number n is then passed to the JavaScript toString() function with an argument of 16, like this code segment:

```javascript
n.toString(16)
```

This tells it to convert the number to base 16, which is hexadecimal.

# The Plug-in

```javascript
function Dec(n)
{
return (n < 16 ? '0' : '') + n.toString(16)
}
```

The results of the two segments are concatenated and returned. When you put both pieces of code together they like this:

```javascript
return (n < 16 ? '0' : '') + n.toString(16)
```

# How To Use It

To convert a decimal number to hexadecimal, pass it to the Dec() plug-in, like this:

```javascript
alert('The decimal number 173 in hexadecimal is ' + Dec(173))
```
