# 80 GoogleChart()

在许多其他产品中，Google 提供了一个用于创建和显示图表的出色程序。然而，为了充分利用它，有许多选项需要设置，并且需要大量的文档。此插件将该服务的主要功能提炼为一组可以传递给它的基本参数，使得该服务变得极易使用。图 10-4 显示了如何使用该插件显示 3D 饼图。

# 关于插件

此插件取一个 `div` 或 `span` 作为容器，并向其中插入从 Google Charts 服务获取的图像。它需要以下参数：

- id: 一个对象或 ID——这不能是数组
- title: 图表标题
- tcolor: 标题颜色
