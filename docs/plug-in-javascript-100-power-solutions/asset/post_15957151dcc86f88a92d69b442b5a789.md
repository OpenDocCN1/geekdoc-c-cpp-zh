### The ZeroTo Subfunction
This function takes the value passed to `num` and uses the `Math.max()` function to ensure it is not greater than 0, the `Math.min()` function to ensure it isn't greater than 255, and the `Math.round()` function to turn it into an integer, like:

### Chapter 9: Text Effects
Here's an example that uses the plug-in in two ways. One highlights text by constantly transitioning it between the two colors, and the other reacts to `mouseover` and `mouseout` events to fade the two colors:

```html
<center>
  <b>
    <font face='Verdana' size='6'>
      <span id='t'>New - See our latest offers!</span><br />
      <span id='m'>Mouseover Me</span>
    </font>
  </b>
</center>
```

```javascript
<script>
window.onload = function () {
  ColorFade('t', '#ffff', '#0000ff', 'text', 2000, 0)
  ColorFade('t', '#ff0000', '#ffff', 'back', 2000, 0)
}
O('m').mouseover = function () { fade('#00000', '#008ff') };
O('m').mouseout = function () { fade('#008ff', '#00000') };

ColorFade('m', 'text', 200, 1)
</script>
```

The section creates two spans with the IDs 't' and 'm'. In the `<script>` section, the first two commands set both the background and text colors of 't' to transition between yellow (#ffff00) and blue (#000ff). Because a number argument of 0 is passed, the transitions continue infinitely.

Below this, the 'm' span has its `mouseover` and `mouseout` events attached to a small function called `fade()` that calls `ColorFade()` with a number argument of 1, so that each transition happens only once. This means that when the mouse passes over, the color fades to light blue (#008ff), and when the mouse moves away it fades back to black (#00000).

Pass your mouse over the second span to see the smooth mouseover effect you can achieve for links and other elements.

Note Odd transitions change the color of an object from the first to the second color, while even ones change it back. This means that number argument values of 1, 3, 5, and so on will leave the second color on display, while 2, 4, 6, and so on will restore the first color after all transitions are over.

    if (id instanceof Array) {
