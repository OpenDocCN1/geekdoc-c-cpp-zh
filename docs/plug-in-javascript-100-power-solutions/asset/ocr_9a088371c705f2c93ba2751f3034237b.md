Here's an example that places sets of menus at the top of the screen:

```
<div id='ml'>
&nbsp;&rsquo; uWorld News</u<br />
&nbsp;&rsquo; uEntertainment News</u<br />
&nbsp;&rsquo; uTech News</u<br />
&nbsp;&rsquo; uBusiness News</u<br />
<center>b<font color='yellow'>&u;NEWS</u</font>b</center></div>

<div id='m2'>
&nbsp;&rsquo; uHurricane News</u<br />
&nbsp;&rsquo; uLong Term Forecast</u<br />
&nbsp;&rsquo; uNational Weather</u<br />
&nbsp;&rsquo; uLocal Weather</u<br />
<center>b<font color='yellow'>&u;WEATHER</u</font>b</center></div>
```

```
<script>
window.onload = function() {
ids = Array(['m1', 'm2', 'm3'])
Hide(ids)
Resize(ids, 150, 100)
Position(ids, FIX)
S(ids, 'backgroundColor', 'red')
S(ids, 'color', 'cyan')
Show(ids)
HoverSlideMenu(ids, 'top', '$50', 21, 10, 200)
}
</script>
```

This example creates three divs and places links in them using <u><a href...> tags in the real world you might use. Each object has a unique ID. Also the &amp; HTML entity creates pairs of pointing brackets.
Then, in the <em><section> section, the Ida is populated with the object names and the Hide() function makes them invisible so they will display nearly when the menus have been created—and you shouldn't see them jump around. It also helps to hide any content that might make some value for a potential horizontal scroll bar, ensuring that everything centers correctly.

After resizing the objects, setting style positions, and assigning their colors, it's safe to show the objects again with Show(). In fact, you must do so in order for the plug-in to be able to look up their dimensions. Finally, the HoverSlideMenu() plug-in is called and the menus are displayed.
