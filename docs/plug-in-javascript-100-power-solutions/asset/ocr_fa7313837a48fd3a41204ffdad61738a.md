## The FP_Off() Subfunction
This function is called when the field gains focus. It first checks the value property of id to see whether it contains the prompt string. If it does, then the prompt needs to be removed ready for the user to type some input, like this:

```
O(id).FP_Empty = true
(id).value = ''
(id).fontStyle = ''
(id).color = inputcolor
```

Here, the FP_Empty property of id is set to true to indicate that the field is empty, the field's value is set to the empty string, any font style is turned off, and the field text color is set to the input argument;
If the field doesn't contain the value in prompt, then the FP_Empty property is set to false.
