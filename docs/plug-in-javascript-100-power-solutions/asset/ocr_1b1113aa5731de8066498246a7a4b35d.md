# 44 SlideBetween()

The plug-in swaps the positions of two objects by sliding them past each other. This is a great effect for swapping requested objects into a chosen location. For example, Figure 6-2 shows a collection of photos that can be individually displayed by passing the mouse over the associated title. When you do this, the previous photograph is swapped with the new one and the old one returning to the stack of pictures and the new one moving to the main viewing area.

# About the Plug-in

The plug-in takes the positions of two objects and swaps the two by sliding the objects past each other. It takes the following arguments:

+   * Either an, or an object ID—it cannot be an array of objects
* msecs The number of milliseconds the animation should take
* interruptible If true (or 1), this plug-in can be interrupted by a new call on the same objects; otherwise, if false (or 0), the call is uninterruptible
