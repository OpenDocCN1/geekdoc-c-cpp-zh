# About the Plug-in

This plug-in takes three arguments, and depending on their values, it prevents events to occur. The arguments are as follows:

- *id* The ID of an object, such as a div or span of HTML, or any other object
- *type* This argument can have one of three string values: 'drag', 'select', or 'both'. If the value is 'drag', then the object referred to by id will either be prevented from being dragged or allowed to be dragged, depending on the value of onoff. If it is 'select', then the selection of text will be prevented or allowed, depending on the value of onoff. If it is 'both', then these events will be prevented or allowed.
- *onoff* This argument should be true or false; alternatively, the values 1 or 0 are acceptable. The values true or 1 mean the event (events) in the variable type are prevented. If onoff is false or 0 then the event (events) are allowed.

# How It Works

The plug-in is divided into two main sections. In the first, the drag event of the object referenced by id is managed, while the second half is for handling the id select event.
