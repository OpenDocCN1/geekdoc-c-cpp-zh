# JavaScript Frameworks

With recent steps towards standardization, different browser developers implement JavaScript in slightly different ways, giving rise to the plethora of JavaScript frameworks now available such as jQuery, Yii, Moo, and so on. These technologies handle all the inconsistencies for you, providing a set of functions you can call without worrying about browser differences.

The plug-ins in this book provide much of the functionality of these frameworks without actually this framework. Procedural programming techniques make it easy to use and understand their workings. And although, plug-ins are also interconnected and draw on each other's features, it's possible to just use a plug-in and its dependencies to a web page. On the other hand, with the major frameworks it's quite difficult to extract the functions you need.

Although at around 25Kb for the compressed file containing all the plug-ins, the tiny amount of bandwidth used means you probably never want or need to extract just a few functions: you can simply drop the link to any web page to access all the plug-ins.
