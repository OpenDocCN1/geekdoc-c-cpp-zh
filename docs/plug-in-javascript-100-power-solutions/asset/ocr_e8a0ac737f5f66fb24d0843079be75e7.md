The HTML section is unchanged, but the <script> uses a technique I haven't shown you yet, which is to assign both the mouseover and mouseout events to the same function, using a single statement, like this:

```
O('l1').mouseover = O('l1').mouseout = fade
```

This works because events are readable as well as writable, the mouseover event is first assigned to the fade() function, and the mouseout event is assigned to the value in the mouseout event.
This means only four statements are used in place like this, because PopToggle() can replace both the PopDown() and PopUp() plug-ins, of only four functions are required to manage eight actions.
In fact, the functions can be attached to the events using inline, anonymous functions, and the line lengths would become quite long and less easy to edit.

# The Plug-in

```
function PopToggle(id, type, w, h, msecs, interruptible)
{
  if (instanceof Array)
    for (var j = 0; j < id.length; ++j)
      PopToggle(id[j], type, w, h, msecs, interruptible)
  return

  if (typeof id.PO_IsUp == UNDEF)
    id.PO_IsUp = true

  if (O.PO_IsUp) PopDown(id, type, w, h, msecs, interruptible)
  else PopUp(id, type, w, h, msecs, interruptible)
}
```
