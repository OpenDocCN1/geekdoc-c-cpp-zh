# 84 ProcessCookie()

With this plug-in, you can save cookies to a user's computer and read back again later. This lets you keep user names, shopping carts, or any data you need to keep current as you browse your site and changes pages. Figure 11-1 shows the cookie 'username' being read and its value displayed using an alert() message.

# About the Plug-in

This plug-in can save a cookie, read it from the computer, or delete it. It requires the following arguments:

+   - action The action to take with the cookie, out of 'save', 'read', or 'erase'
- name The cookie's name
- value The value to be stored in the cookie
- seconds The number of seconds after which the cookie should expire
- path The domain and path to which the cookie applies
- domain The domain name of the website, as mydomain.com
- secure If this has the value 1, the browser should use SSL when sending the cookie
