# Chapter 7: Chaining and Interaction 183

```
{
  Position('ball', ABS)
width = GetWindowWidth()
height = GetWindowHeight()
r = width - 100
b = height - 100
x = width / 2 - 50
y = height / 2 - 50

ch1 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0)', x, y, x)
ch2 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0", x, 0, r, y)
ch3 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0", r, y, x, b)
ch4 = InVars('Slide('ball', #1, #2, #3, #4, 500, 0", x, b, 0, y)

Chain(Array(ch1, ch2, ch3, ch4))
</script>
```

The HTML section displays a 10x100 pixel image of a ball, then the first line of the <script> section sets the ball's property to 'absolute' so that it can be moved.

After this the width and height of the browser are calculated and stored in width and height, then the right and bottom positions are required to place the ball against these edges which are placed in r and b. These values are similar to the width and height of the browser less the ball's width and height of 100 pixels.

The variables x and y are also calculated to set them to coordinates that place the ball exactly in the center of the browser (bearing in its width and height of 100 pixels).

Next, Slide() plug-ins are assembled into strings using the InsVars() plug-in. Then calls the ball from the center left of the browser to the top middle, then to the center right, then to the bottom middle, and finally back to the center left of the browser.

These calls are then placed in an array and passed to the Chain() plug-in to get the ball rolling (so) to speak.

> NOTE Because of the way chaining has been implemented with a single global array, you can have only one chain of plug-ins running at a time. You can carefully create a chain that interleaves two or more sets of plug-ins so that number of different animations appear to be running concurrently. However, you will need to use trial and error to get the best results with this technique.

# Using the Callback() Function Directly

The Callback() function achieves its execution by adding the name of a function to call back after the current one has finished execution. You can also do this, as the plug-in you calls supports chaining, as detailed in Table 7-2.

For example, if you would like to use the Hide() plug-in called immediately after Deflate(), you can use code such as:

```
Deflate(myobject, 1, 1, 500, 0, 'Hide(myobject)')
```
