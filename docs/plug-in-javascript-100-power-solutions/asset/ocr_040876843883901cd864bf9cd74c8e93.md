# How To Use It

Thankfully, using this plug-in is a great simpler than describing it. To zoom an object either up or down all you need to do is pass the object to Zoom(), along with start and end dimensions, like this:

Zoom(myobject, 1, 1, 100, 100, 20, 20, 1000, 0, 0)

This statement will zoom myobject from a width and height of 100 pixels each to just 20. You can also get fancy and turn a horizontal rectangle into a vertical one, like this:

Zoom(myobject, 1, 1, 100, 10, 10, 1000, 0, 0)

This will change myobject from being 100 by 10 pixels to 100 pixels over the course of 1000 milliseconds.

The following example displays 4 by 86 pixels at a width and height of 70 pixels. You can pass your mouse over them to zoom up to their original size and back down again:

```
<img id='il1' src='il1.gif' />
<img id='il2' src='il2.gif' />
<img id='il3' src='il3.gif' />
<img id='il4' src='il4.gif' />

<script>
window.onload = function () {
  ids = Array(['il1', 'il2', 'il3', 'il4']);
  Zoom(ids, 1, 1, 86, 70, 70, 1, 1, 0);
  O(ids, 'mouseover', 'up');
  O(ids, 'mouseout', 'down');
}

function up() {
  Zoom(this, 1, 1, 70, 86, 86, 200, 1, 1);
}

function down() {
  Zoom(this, 1, 1, 86, 70, 70, 200, 1, 1);
}
</script>
```

The first four lines of HTML display the IDs and give them unique IDs. The <script> section then creates the array ids out of these IDs, which is used in the following line to zoom all the icons from 86 by 86 pixels to 70 by 70. It passes a value of 1 millisecond so that the change is virtually instantaneous.
