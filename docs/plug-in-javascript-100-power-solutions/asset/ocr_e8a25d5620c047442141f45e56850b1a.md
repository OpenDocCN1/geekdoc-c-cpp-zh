The HTML displays the two images with a div containing the article text. The <section> then hides the text with a call to Hide because it is going to be resized; if it didn't do this, the Internet browser would return the wrong width in the next count as it would prepare for possibly requiring a scroll bar. After resizing the article text, the Show() plug-in is called to display it again, and now that it has been reduced to fit within the current window, Internet will not try to leave a gap for a scroll bar in case it needs it.

Now the ids array is populated with the image IDs and is passed to the Locate() plug-in at the top right corner of the border. The Resize() plug-in is also called because, unfortunately, odd widths and heights sometimes cause a slight disturbance to animations depending on the browser used (something to do with the way they handling), ensuring that both dimensions of objects to Flip() is the easiest way to get the best results. It also ensures that both images have the same dimensions and will flip neatly.

Next, the second object is set visible before setting the mouse events to Flip(). This must be because the two images are overlaid on each other and could have varying zindex values, you must ensure the one is on the front by making the other invisible.

In the two lines, the onmouseover event of object 'a' is attached to a flip from object 'a' to 'b', while the onmouseout event of object 'b' is attached to a flip from object 'b' to 'a'.

Before flips, object 'b' will be visible, so the mouse over it will start the flip. After the flip has finished, object 'b' will still be over it (unless the user quickly moved away), while the onmouseout event of object 'b' is attached: so the animation will flip back again when the mouse moves away.

# Objects as well as images

Although the give flip best results, you can pass any kind of object such as a div or table and so, to the Flip() plug-in. This means you can, for example, an e-mail button that flips when the mouse passes over it to reveal a small form for entering your e-mail address to subscribe to newsletters. If you do this, text will flow in out of the object that rotate the away image does, so you get a slightly differentbut still interesting—effect.

You can use Flip() to swap sections of HTML according to the selection of radio button or clicking of links. And don't forget that you can flip objects horizontally and vertically, or you can even do both at the same time to create a zoom-and-back-and-again effect.
