# CursorTrail()

This plug-in can provide a great visual aid for your users, or you can use it as a special effect. It leaves a trail of images behind the mouse cursor, with each image a little more faded than the one in front of it, so that it gives a smoother flowing appearance, for each, the built-in Windows cursor trail utility. It also allows you to select your images for the trail. FIGURE 13-6
Add cursor trails to the mouse pointer by calling this plug-in.

![](img/95e4c43b430487125c342550cc090977_391_0.png)

Figure 13-6 shows a cursor trail created using the mouse pointer image supplied with this plug-in on the pluginjavascript.com website.

# About the Plug-In

This plug-in creates a trail of images that follow the mouse pointer. It requires the following arguments:

- image The URL of an image to use for the trail
- length The length of the trail, with smaller numbers being shorter
- state If 1 or true the trails are turned on; a value of 0 or false turns them off

# Variables, Arrays, Functions

| Variable/Function | Description |
| :--- | :--- |
| j | Local variable for iterating through the ten images |
| w | Local variable containing the width of the browser |
| h | Local variable containing the height of browser |
| c | Local variable containing the string 'CT_' |
| newimg | Local variable containing each new image as it is created |
| zIndex | Property of each image set to bring in front of all other elements |
| ABS | Global variable with the value 'absolute' |
| MOUSE_X & MOUSE_Y | Global variables containing the horizontal and vertical mouse coordinates |
| ZINDEX | Global variable containing the highest zIndex property so far used |
| Goto() | Plug-in to move an object to a new location |
| Hide() | Plug-in to hide an object |
| Show() | Plug-in to show an object that has been hidden |
| Position() | Plug-in to set the style position property of an object |
| Opacity() | Plug-in to set the opacity of an object |

# How It Works

To start with this, plug-in sets the width and height of the browser in w and h and sets c to the string 'CT_', a prefix that will be used when assigning IDs to the image objects that were created:

```javascript
var w = GetWidth()
var h = GetHeight()
var c = 'CT_'
```

Next, if it is not 1 or true, any repeating interrupts are cancelled, and the plug-in returns, turns off the mouse trails:

```javascript
if (!state) return clearInterval(CT_IID)
```

At the next line of code, if no object has the ID 'TT_0', it means the first time the plug-in has been called, so all the objects are created and set style positions of 'absolute' (so that they can be moved about). In addition, their opacity is set to different levels so that the farthest away from the mouse cursor are the most faded, the images are loaded from the URL supplied in image, and the X and Y properties of each image are assigned starting values of -9999 to place them well off screen, as follows:

```javascript
if (!O('TT_0'))
{
  for (var j = 0; j < 10; ++j) {
    var newimg = document.createElement('img')
    newimg.setAttribute('id', c + j)
    document.body.appendChild(newimg)
    Position(newimg, ABS)
    Opacity(newimg, (j + 1) * 9)
    newimg.src = image
    O(c + j).X = -9999
    O(c + j).Y = -9999
  }
}
```

With everything prepared, the final command in setup starts the repeating interrupts to the DoCurTrail() function:

```javascript
CT_IID = setInterval(DoCurTrail, length)
```

# The DoCurTrail() Subfunction

This function performs the moving of all the trail images, which it manages with for() loop, which with the first command moves the current iteration to its new position:

```javascript
for (var j = 0; j < 10; ++j)
Goto(c + j, O(c + j).X, O(c + j).Y + 2)
```

For example, when j has the value 5, the image ID calculated with expression c + j is manipulated, which is 'CT_5'. The number 2 in the code places the images down and to the right by two pixels. Next, the zIndex of the image is set to the maximum zIndex so far plus 1, to ensure it will display on top of all other elements:

```javascript
S(c + j).zIndex = ZINDEX + 1
```

If it is set to display directly under the mouse pointer, the image is hidden. If it wouldn't, the user could not click link because a trail image would be between mouse pointer and clickable object:

```javascript
if (c + j).X == MOUSE_X && O(c + j).Y == MOUSE_Y) Hide(c + j)
```

Otherwise, if the image is away from the mouse pointer, it is shown:

```javascript
else Show(c + j)
```

Next, as long as j has a value greater than 0 (and therefore indexing the trail images above the first), the location of the image behind the current one is set to that of current image:

```javascript
if (j > 0)
{
  O(c + j - 1).X = O(c + j).X
  O(c + j - 1).Y = O(c + j).Y
}
```

Finally, the highest numbered image (with the ID 'CT_9') is either set to the current location, or if the mouse is off screen, to a position well off start of screen (with the values 12 and 20 representing width and height of mouse pointer):

```javascript
O(c + 9).X = MOUSE_X < (w - 12) ? MOUSE_X : -9999
O(c + 9).Y = MOUSE_Y < (h - 20) ? MOUSE_Y : -9999
```

Only this highest numbered image needs to be given the mouse coordinates, because each time loop the coordinates of each item are copied to the one behind it. For example, the next image with ID 'CT_8' will be passed the values in image with ID 'CT_9', and so on.

# How To Use It

To use this plug-in, pass the URL of an image to display as the trail, for long the trail should be (with 1 being the smallest), and a value of true or 1 for state argument, like this:

```javascript
CursorTrail('mousepointer.gif', 20, 1)
```

To turn the effect off, just change the state argument to 0 or false, like this:

```javascript
CursorTrail('mousepointer.gif', 20, 0)
```

For example, Figure 13-7 shows the file snowflake.gif being used in place of mousepointer.gif, with the following code:

```html
<script>
window.onload = function() {
  CursorTrail('snowflake.gif', 20, 1)
}
</script>
```

> TIP: For an more interesting effect, try displaying GIFs in the cursor trail instead of static ones.

# The Plug-in

```javascript
function CursorTrail(image, length, state)
{
  var w = GetWindowWidth()
  var h = GetWindowHeight()
  var c = 'CT_'

  if (!state) return clearInterval(CT_IID)

  if (!O('TT_0'))
{
    for (var j = 0; j < 10; ++j)
    {
      var newimg = document.createElement('img')
      newimg.setAttribute('id', c + j)
      document.body.appendChild(newimg)
      Position(newimg, ABS)
      Opacity(newimg, j + 1) * 9)
      newimg.src = image
      O(c + j).X = -9999
      O(c + j).Y = -9999
    }
  }

  CT_IID = setInterval(DoCurTrail, length)

  function DoCurTrail()
  {
    for (var j = 0 ; j < 10; ++j)
    {
      GoTo(c + j, O(c + j).X + 2, O(c + j).Y + 2)
      S(c + j).zIndex = ZINDEX + 1
    }

  if (O(c + j).X == MOUSE_X && O(c + j).Y == MOUSE_Y) Hide(c + j)
  else Show(c + j)

    if (j > 0)
    {
      O(c + j - 1).X = O(c + j).X
      O(c + j - 1).Y = O(c + j).Y
    }

    O(c + 9).X = MOUSE_X < (w - 12) ? MOUSE_X : -9999
  O(c + 9).Y = MOUSE_Y < (h - 20) ? MOUSE_Y : -9999
}
```
