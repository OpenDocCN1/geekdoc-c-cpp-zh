#  How It Works

This plug-in makes a call to the S() plug-in using the assignment version of the call, so that it can be an object, object ID, or an array of objects and/or object IDs. Each object has its style.display property set to 'none', Additionally, a call to O() is made with the arguments Hi_Flag and true, which sets the new object property Hi_Flag to true so that other plug-ins can tell the object has been hidden. This also supports arrays.

Finally, any callback function in CB is evaluated with the ev() function, but only if the event CB (explained in Chapter 7) has a value.

#  How To Use

To hide an object, pass it to the Hide() plug-in, from inside a side of JavaScript code, or from within HTML. The following example creates three buttons, of which each can be clicked to hide it

```
<center>
<input id='a' type='submit' value=' Button A />
<input id='b' type='submit' value=' Button B />
<input id='c' type='submit' value=' Button C />

<script>
window.onload = function () {
  O('a').onclick = function () { Hide('a') }
  O('b').onclick = function () { Hide('b') }
  O('c').onclick = function () { Hide('c') }
}
</script>
```

Alternatively, the input tags can be written as follows, and no <script> section is necessary:

```
<input type='submit' value=' Button A ' onclick='Hide(this)' />
<input type='submit' value=' Button B ' onclick='Hide(this)' />
<input type='submit' value=' Button C ' onclick='Hide(this)' />
```
