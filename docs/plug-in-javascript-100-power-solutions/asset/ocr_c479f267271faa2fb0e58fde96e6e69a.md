# How To Use It

To create a flip animation, you need to have two objects of equal dimensions. They must be overlaid on each other the second object's visibility property turned off, using code such as this:

```
ids = Array('a', 'b')
Locate(ids, ABS, 10, 10)
VisibilityToggle('b')
Flip('a', 1, 0, 1000)
```

This code takes two objects that have the IDs of 'a' and 'b', places the names in the array ids, and then locates them at the absolute position 10,10 with a call to the Locate() plugin-in. VisibilityToggle() plugin-in. Finally, the Flip() is called with the two objects and set to flip only the width (so that the flip will twist around the vertical axis). A time of 1000 milliseconds is specified and padding is not used.
