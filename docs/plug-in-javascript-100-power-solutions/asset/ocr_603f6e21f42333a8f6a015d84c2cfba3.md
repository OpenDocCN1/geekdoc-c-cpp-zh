# About the Plug-in

This plug-in takes two objects and animates them so they appear to flip over if they are attached to back. It returns these arguments:

+   - id1 An object or object ID—may not be an array
- id2 An object or object ID—may not be an array
- w If true or 1, the width will be flipped
- h If true or 1, the height will be flipped
- msecs The number of milliseconds the flip should take

+   - pad If set, the objects will be padded to retain their overall dimensions during the flip

# Variables, Arrays, and Functions

| swap | Local string variable containing a command suitable for InsVars() to add a call to VisibilityToggle() to a chain |
| fast | Local string variable containing a command suitable for InsVars() to add a 1 millisecond call to ZoomToggle() to a chain |
| slow | Local string variable containing a command suitable for InsVars() to add a call of msecs / 2 to ZoomToggle() to a chain |
