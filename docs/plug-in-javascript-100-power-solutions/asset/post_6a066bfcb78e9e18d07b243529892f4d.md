function GetWindowHeight ()
{

| GetWindowWidth() | Plug-in to return the browser width |
| GetWindowHeight() | Plug-in to return the browser height |
| W() | Plug-in to return the width of an object |
| H() | Plug-in to return the height of an object |
| GoTo() | Plug-in to move an object to a new location |

### How It Works

Like many others, this plug-in supports the passing of an object, an object ID, or an array of objects/or object IDs. This is managed by the if() section, which determines whether id is an array using the `instanceof` operator. If is, then each element of the array is recursively passed to the same function, along with the values of width and percent. Once all have been processed, the function returns.

After this local variables are assigned values representing the amount of width and height taken into account. This is done by fetching the width and height of the browser using the GetWindowWidth() and GetWindowHeight() and subtracting the width of one and its height from the other, as determined by calls to W() and H().

The variable amount is set to percent/100 so that it can be used as a multiplier. For example, if percent has a value of 40, dividing it by 100 gives the value of 0.40, which can then be multiplied by any number to reduce it to 40 percent of its original value. In this case, the multiplier determines how far the object should edge.

Next, a switch() statement tests for the four argument values for, which are 'top', 'bottom', 'left', or 'right'. The shorthand global variables of TP, BM, LT, and RT are used in place of these values to make the code shorter and clearer. A break command ends each subsection of the switch() statement except for the final, where it is not required because program flow will continue to the next line down anyway.

Depending on which of the four values has been passed in where, the local variables x and y are set to align the object in right between 0 and 100 percent above (or down), according to the percent. Finally, a call to GoTo() is made to move the object to the new location.

There are many uses for this plug-in; particular is a dock bar, similar to the one used at the bottom of the screen on Apple OS system, with a row of expanding and collapsing icons. DockBar() provides exactly this functionality for any web page.

### How To Use It

To use this plug-in, pass an object to it along with details on where to display it, as in the following example, which displays four icons, one per edge:

```html
<img id='i1' src='i1.gif' />
<img id='i2' src='i2.gif' />
<img id='i3' src='i3.gif' />
<img id='i4' src='i4.gif' />

<script>
window.onload = function() {
  ids = Array('i1', 'i2', 'i3', 'i4');
  Position(ids);
  GotoEdge('i1', TP, 50);
  GotoEdge('i2', BM, 10);
  GotoEdge('i3', LT, 30);
  GotoEdge('i4', RT, 60);
}
</script>
```

In the first section of HTML, GIF images are loaded with each a different ID. Then, in the <script> section the array ids is populated with these IDs so that the Position() command can set all of them to have style='fixed'. This means they will stay where they put, even if the browser scrolls.

Finally, each image is attached to a different edge using four calls to GotoEdge(). The top is 50 percent in, the bottom 10 percent in, the left 30 percent down, and the right 66 percent down. As all of this book's examples, you can download this plug-in and all associated content (such as the images used) from companion website at javascript.com.

### The Plug-in

```javascript
function GotoEdge(id, where, percent) {
  if (id instanceof Array) {
    for (var j = 0; j < id.length; j++) {
      GotoEdge(id[j], where, percent)
    }
    return
  }

  var width = GetWindowWidth() - W(id)
  var height = GetWindowHeight() - H(id)
  var amount = percent / 100

  switch (where) {
    case TP: x = width * amount; y = 0; break;
    case BM: x = width * amount; y = height; break;
    case LT: x = 0; y = height * amount; break;
    case RT: x = width; y = height * amount;
  }
  GotoTo(id, x, y)
}
```

## CenterX()

Another very useful function is to center an object, which is what this plug-in does. By using the browser width and object width it moves an object horizontally to exactly the center of the browser. Figure 4-10 shows a div that has been centered using this plug-in.

### About the Plug-in

The plug-in centers an object (or objects) on a horizontal axis. It requires the following argument:

- id An object, object ID, or an array of objects or object IDs

## Variables, Arrays, and Functions

| Variable | Description |
| :--- | :--- |
| j | Local integer variable for indexing id if it is an array |
| left | The style.left property of object |
| SCROLL_X | Global variable containing the number of pixels by which the browser is scrolled horizontally |
| GetWindowWidth() | The available width of the browser window, taking into account any scroll bars |
| W() | Plug-in to fetch an object's width |
| Px() | Plug-in to add the suffix 'px' |

### How It Works

This plug-in allows arrays of objects andor object IDs, as well as single objects or object IDs. It does this by using the instanceof operator to tell whether id is an array, and if it is, it iterates the array using the local variable as an index, recursively calling itself with the single element values. Upon completion, the if() section of code returns.

In the second part of the plug-in, the Px() sets the object's style.left property to the correct value (using a 'px' suffix) to center the object horizontally. The correct value is determined by looking up the width of the window (17 if there's a scroll bar), minus the width of id. If the window is 600 pixels and the width is 100 (and there is no scroll bar), the value is determined by subtracting 100 from 600, which equals 500; then the value is divided by 2 to get a final result of 250. Therefore, an offset of 250 pixels from the left will exactly center an object of 100 pixels in a 600-pixel wider browser. If there is a scroll bar, the values become 583 - 100 / 2, which equals 241.5. The Math.round() call deals with a fractional result, in which this is rounded up to 342.

If the browser has no scroll, this is all the calculation that needed. However, because the horizontal offset is from the left edge of the document (not the window), if there has been a horizontal scroll the object will be displayed left of center by the amount of the scrolling. Therefore, the global variable SCROLL_X is added to the calculated value in order to place the object exactly between the left and right hands of the window.

### How To Use It

To center an object, as long as it is capable of moving, just call CenterX() in the following manner, which creates a simple div and centers it:

```html
<div id='test'>&nbsp;Test div</div>

<script>
window.onload = function() {
  Locate('test', ABS, 20, 20);
  Resize('test', 100, 100);
  S('test').border = 'solid ' + Px(1);
  Center('test')
}
</script>
```
