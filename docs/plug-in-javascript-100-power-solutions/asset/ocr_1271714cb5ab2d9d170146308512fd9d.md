Make sure to look at the first call in the <script> section. Notice how it sets a transition time of just 1 millisecond for the fade. This is the recommended way to set up toggleable elements to start up in their inverse state because it causes the transition to occur, but only a single frame of animation.

This technique is useful if you want the house to start faded out: the call to FadeToggle() executes the first fade out as quickly as possible—faster than the eye can see. When you run the example, you would hardly notice the image until you pass the mouse over the text.

With the image faded out, remaining the two lines of code to attach the mouse events. The house will smoothly fade in and as you pass your mouse over the text because the interruptible argument is set to 1 and allows smooth interrupts to the transitions.

# The Plug-in

```
function FadeToggle(id, msecs, interruptible, CB)
  if (id instanceof Array)
  {
    for (var j = 0; j < id.length; ++j)
      FadeToggle(id[j], msecs, interruptible, CB)
    return
  }
```
