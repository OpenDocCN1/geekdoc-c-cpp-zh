# How It Works

This plug-in starts by creating an array of the main two divs, then four strings are created to hold the warning triangle HTML, the OK button, the alert message itself, and two new divs that will contain the alert's title and message header:

```
var divs = Array('ALERT_DIV', 'SHADOW_DIV')
var warn = "<font color=red size=6 style='vertical-align:middle;'>" + 
"&#916;</font>&nbsp;"
var ok = "<center><input id='ALERT_OK' type='submit' /></center>"
```

```
var mess = warn + value + '<br /> <br>' + ok
var html = `<div id='ALERT_TITLE'>${mess}</div>
           <div id='ALERT_MESSAGE'></</div>>`
```

Next, if the ID 'ALERT_DIV' doesn't exist, it means this time is for the plug-in has been called, the two main divs are created, like this:

```
var newdiv = document.createElement('div')
newdiv.setAttribute('id', 'SHADOW_DIV')
document.body.appendChild(newdiv)
newdiv = document.createElement('div')
newdiv.setAttribute('id', 'ALERT_DIV')
document.body.appendChild(newdiv)
```

These statements create new divs with the IDs 'ALERT_DIV' and 'SHADOW_DIV', attaching them to the document body. The divs are released from their location in the HTML, resized, and centered, and the shadow div has its opacity set to 50 percent, as follows:

```
Position(div, ABS)
Resize('ALERT_DIV', 350, 140)
Resize('SHADOW_DIV', 350, 146)
Center('ALERT_DIV')
Goto('SHADOW_DIV', 4, Y('ALERT_DIV')) + 6
Opacity('SHADOW_DIV', 50)
```

Next, the divs are hidden with a callback to AlertHide(), and the innerHTML property is assigned the value of html, which contains the HTML to create the two divs, both of which are resized:

```
AlertHide()
Html('ALERT_DIV', html)
Resize('ALERT_TITLE', 350, 22)
Resize('ALERT_MESSAGE', 330, 98)
```

After this, a number of style elements are set, the innerHTML of the title and message divs are assigned, like this:

```
Html('ALERT_TITLE', 'Message from the webpage')
Html('ALERT_MESSAGE', mess)
S('ALERT_TITLE').backgroundColor = '#acc5e0'
S('ALERT_TITLE').fontFamily = 'Arial'
S('ALERT_TITLE').paddingTop = '2px'
S('ALERT_TITLE').textAlign = 'center'
S('ALERT_TITLE').fontSize = '14px'
S('ALERT_MESSAGE').innerHTML = mess
S('ALERT_MESSAGE').fontFamily = 'Arial'
S('ALERT_MESSAGE').fontSize = '12px'
S('ALERT_MESSAGE').padding = '10px'
S('ALERT_MESSAGE').overflow = 'auto'
S('ALERT_DIV').backgroundColor = '#f0f0f0'
S('ALERT_DIV').border = 'solid #444 1px'
S('SHADOW_DIV').backgroundColor = '#444444'
S('ALERT_OK').value = OK
```

These statements set the color, fonts, and borders for the elements, and the message has its overflow property set to 'auto', so that larger messages will have scrollbars if necessary.

Finally, the onclick event of the OK button is attached to AlertHide() function, and the divs are visible, like this:

```
S('ALERT_OK').onclick = AlertHide
Visible(divs)
```

The plug-in ends with the AlertHide() function, which is called when the OK button is clicked:

```
function AlertHide() {
  Invisible(divs)
}
```

# How Use It

You use this plug-in in the same manner as the built-in alert() function: by simply passing a value or expression to display, like this:

```
Alert("You must log-in")
```

Or, here's an example that combines a string and an expression:

```
Alert("The product of 6 and 7 is " + 6 * 7)
```

One of the best things about this plug-in is that you can watch values changing in real time without having to click OK after the message. Here's an example that can create repeating interrupts to call the plug-in and display the current coordinates, which change as you move the mouse:

```
window.onload = function() {
  setInterval(mousecoords, INTERVAL)
}
```

```
function mousecoords() {
  Alert("Mouse X = " + MOUSE_X + " | Mouse Y = " + MOUSE_Y)
}
```

In this particular example, because the calls to Alert() repeat continuously, nothing will happen if you click the OK button to dismiss the message, as another Alert() call is made milliseconds later. If you want to use the plug-in with a single call you just try a command as:

```
Alert("This is a test alert message")
```

Note Don't confuse the two functions because they use the same letters. The original JavaScript function starts with a lowercase 'a', and is alert(), while the new plug-in begins with an upper 'A' and is called Alert().
