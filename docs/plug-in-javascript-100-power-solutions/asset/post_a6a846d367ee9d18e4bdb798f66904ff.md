## The DoSlideshow() Subfunction

The job of this function is to transition between two images and then initiate an interrupt to call itself when the next transition is due (unless it is cancelled).

The first thing this function does load the first image with the current value in the images array, as indexed by index. The first time it calls this, nothing happens since the same has already been loaded. However, on all future transitions it has the effect of taking the picture that is being displayed in the second image and duplicating it in the first, so that they are showing the same picture:

```
O('SS_IMG1').src = images[index]
```

Since both images are the same picture, it is safe to set the first one to be fully visible and the second one to invisible, like:

```
Opacity('SS_IMG1', 100)
Opacity('SS_IMG2', 0)
```

Having made this swap, the index variable is incremented to point to the next picture in the slide show, and if it becomes larger than the number of images in the images array, it is reset to 0 (using the % operator) to start again at the beginning, as follows:

```
index = ++index % len
```

Next, it's time to load the next picture listed in the images array into the second image, because the first image is the currently being displayed, and the second has been made invisible to do:

```
O('SS_IMG2').src = images[index]
```

## About the Plug-In

This plug-in takes a containing object such as a div or span and an array of objects held within it, which it rotates like an automated billboard. It requires the following arguments:

- id: An object or object ID—this cannot be an array
- objects An array of objects or object IDs
- random: If true, the objects will be displayed in random order
