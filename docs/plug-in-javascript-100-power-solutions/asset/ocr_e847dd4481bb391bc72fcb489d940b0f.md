# Chapter 13: Solutions to Common Problems

FIGURE 13-5
Use this plugin-in to attach smoothly fading tooltips to objects.

![](bbox=[0.311, 0.114, 0.833, 0.296])

+   - size The font size to use
- textc The text color to use
- backc The background color to use
- bordc The border color to use
- bstyle The border width to use, in pixels
- bwidth The time each fade out or should take in milliseconds
- timeout The time after the tooltip will automatically fade out in milliseconds; if 0 or not, the tooltip will not automatically fade out

# Variables, Arrays, and Functions

| tt | Local variable containing the string 'TT_' concatenated with the ID of id |
| newdiv | Local variable containing the new div object |
| MOUSE_X | Global variable containing the current horizontal location of the cursor |
| MOUSE_Y | Global variable containing the vertical location of the cursor |
| ZINDEX | Global variable containing the highest zIndex value far used |
| Hidden | Property of the new div: true when the tooltip is hidden, otherwise false |
| IID | Property of the new div set to cancel any pending interrupt using setTimeout() |
| zIndex | Property of the new div set to bring it to the font of all objects |
| fontFamily | Property of the new div containing its font family |
| fontSize | Property of the new div containing its font size |
| padding | Property of the new div containing its padding |
