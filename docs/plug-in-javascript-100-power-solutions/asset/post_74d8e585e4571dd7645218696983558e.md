# 4 SlideBetween()

The plug-in swaps the positions of two objects by sliding them past each other. This is a great effect for swapping requested objects into a chosen location. For example, Figure 6-2 shows a collection of photos that can be individually displayed by passing the mouse over the associated title. When you do this, the previous photograph is swapped with the new one and the old one returning to the stack of pictures and the new one moving to the main viewing area.

## About the Plug-in

The plug-in takes the positions of two objects and swaps the two by sliding the objects past each other. It takes the following arguments:

- Either an, or an object ID—it cannot be an array of objects
- msecs The number of milliseconds the animation should take
- interruptible If true (or 1), this plug-in can be interrupted by a new call on the same objects; otherwise, if false (or 0), the call is uninterruptible

## How It Works

This plug-in first checks whether the objects passed to it is currently being used in a slide animation by testing their SL_Flag properties. If so, both objects have their SL_Int properties. If neither has a value of true or 1, the slide may not be interrupted and the function returns. The code to do this is as follows:

```javascript
if (O(id1).SL_Flag || O(id2).SL_Flag)
  if (!O(id1).SL_Int || !O(id2).SL_Int)
    return
```

If the function is interruptible, the locations of each object require swapping so that they can return to their start locations. This behavior has been chosen because the details passed to the plug-in are the object IDs. Therefore, if an interrupting call to SlideBetween() is requested on an object, the only action it can take is to reverse the current slide.

To do this, the temporary variables t1 and t2 are the current horizontal and vertical locations of object. id1 is given the position of id2. Finally, id2 is given the position stored in t1, using the following assignments:

```javascript
var t1 = O(id1).SB_X
var t2 = O(id1).SB_Y

O(id1).SB_Y = O(id2).SB_Y
O(id2).SB_X = t1
O(id2).SB_Y = t2
```

Next, although not necessary, temporary copies are made of the locations of any object in the short named variables x1, x2, y1 and y2. This is so that the final two statements are easier to read and can fit on single lines. The four lines that do look like this:
