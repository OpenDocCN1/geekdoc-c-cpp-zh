```
<script>
window.onload = function() {
S('menu').backgroundColor = '#aebecb'
S('menu').border = 'solid 1px'
ContextMenu(document, 'menu', 'fade', 0, 300)
}
</script>
```

The HTML section displays a heading and instructional sentence, followed by a span with the ID 'menu', which contains a few links. Of course, the links go nowhere because they only contain a # symbol, but they display as so. The <script> sets the background color of the menu, gives it a solid border, and then calls ContextMenu() to prepare the browser for handling right-clicks.

You might want to play this example by trying different style arguments such as 'inflate', 'zoom', and 'instant'. You can also play with the w and h arguments as well as the timing in msecs.

Something else you can try is create an object and attach it to that rather than the entire document. Or, try making a couple of menus for different objects—once you have your plug-in in your web toolkit, you are on your way to creating some highly dynamic and interactive websites.
