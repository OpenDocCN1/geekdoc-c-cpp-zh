# How It Works

This plug-in begins by iterating through id if it is an array, recursively calling itself to individually process each element, like this:

```
if (id instanceof Array) {
  for (var j = 0 ; j < id.length; ++++) {
    MatrixToText(id[j], msecs)
  }
}
```

The MT_Flag property of id is tested. If it's true, a call to this plug-in is operating on the object, Otherwise, the property is set to true to indicate that a progress is in the id, as follows:

```
if (O(id).MT_Flag) return
else O(id).MT_Flag = true
```

Next, html is the HTML contents of id, len length, and freq frequency with which the DoMatrixToText function needs to be called for the transition to make msecs. In addition, the string variable matrix is created, which will hold the random text as it is slowly revealed; count, the counter for each step, is initialized to 0; and chars, the string containing all possible characters for scrambling the text, a-z, A-Z and 0-9, as follows:

```
var html = Html(id)
var len = html.length
var freq = Math.round(msecs / INTERVAL)
var matrix = ''
var count = 0
var chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ' + 'abcdefghijklmnopqrstuvwxyzuvwxyz' + '0123456789'
```
