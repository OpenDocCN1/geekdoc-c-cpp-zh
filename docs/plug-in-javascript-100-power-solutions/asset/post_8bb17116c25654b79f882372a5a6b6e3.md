## 50 ZoomDown()

This plug-in zooms an object down over time from its current size to zero dimensions. It does this in such a way that the object can be zoomed back again with the following plug-in, ZoomRestore(). Figure 6-8 shows four icons that had their mouseover events attached to this plug-in and are in varying states of zooming.

### About the Plug-in

This plug-in takes an object and zooms it down until it has zero dimensions. It requires the following arguments:

- id: An object, an object ID, or an array of objects/object IDs
- w: If true or 1, the object's width will be zoomed down
- h: If true or 1, the object's height will be zoomed down
- msecs: The number of milliseconds the animation should take
- pad: If 0, the object will be moved during resizing so to remain centered. If greater than 0, the object will be padded with CSS to retain its original dimensions as it zooms down. If -1, no padding will be applied and the object will not be moved during resizing.
- interrupt: If true (or 1), this plug-in can be interrupted by a new call on the same object; otherwise, if false (or 0), the call is uninterruptible

### How It Works

This plug-in starts by iterating through id if it is an array and recursively calls itself with each element individually, as follows:

```javascript
if (id instanceof Array)
  for (var j = 0; j < id.length; ++j)
    ZoomDown(id[j], w, h, msecs, pad, interruptible, CB);
return
```

Next, the plug-in checks whether a zoom is already present on id and, if so it checks whether that zoom is interruptible, like:

```javascript
if (O(id).ZO_Flag && O(id).ZO_Int) return
```

If there is a zoom (determined by the ZO_Flag property of id) and it cannot be interrupted (determined by thes ZO_Int content) then the plug-in returns. Otherwise the following code is executed:

```javascript
else if (!O(id).ZO_OldW)
  O(id).ZO_OldW = W(id)
  O(id).ZO_OldH = H(id)
  O(id).ZO_X = X(id)
  O(id).ZO_Y = Y(id)
```

This checks whether the ZO_OldW property exists. If it doesn't, it zooms down so its current width and height are stored in the ZO_OldW and ZO_OldH properties. These values are obtained using the W() and H() plug-ins. Also, the coordinates of the object are read from X(id) and Y(id) and stored in the ZO_X and ZO_Y properties.

The first of the three statements sets the Zoomdown property of id to true to indicate that the object is (or in the process of being) zoomed. Then the location is reset to the stored values in ZO_X and ZO_Y (to handle the case where an object has an odd dimension and sometimes gets disturbed by a pixel), and the Zoom plug-in is called, passing the original width and height of id, the new zero width and height values, and the value of pad and interruptible, as follows:

```javascript
O(id).Zoomdown = true
ToGo(id, O(id).ZO_X, O(id).ZO_Y)
Zoom(id, w, h, O(id).ZO_OldW, 0, 0, msecs, pad, interruptible, CB)
```

### How To Use It

To use this function, you pass an object (or array of objects) and specify the type of zoom you want down (whether to zoom down the horizontal or vertical axis, or both), along with the number of milliseconds it should take, whether to use padding and whether the zoom should be interruptible, like this:

```javascript
ZoomDown(object, 1, 1, 1000, 0, 0)
```

This zooms down object from whatever its current dimensions are over a period of 1000 milliseconds. The final two values specify that no padding should be used and that the zoom should not be interruptible.
