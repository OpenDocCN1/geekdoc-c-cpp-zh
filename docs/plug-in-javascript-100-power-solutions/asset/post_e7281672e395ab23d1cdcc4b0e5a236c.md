## Setting Up the Events

The final lines of code in the setup section move id to the location x,y; store a copy of each the HS_X and HS_Y properties; and set up the mouseover and mouseout events to call the SlideIn() and SlideOut() functions, respectively:

```javascript
GoTo(id, x, y)
O(id).HS_X = x
O(id).HS_Y = y
O(id).mouseover = SlideIn
O(id).mouseout = SlideOut
```

## The SlideIn()

The job of this function is to slide the object into view when the mouse passes over any part of it. The first it cancels any previously running interrupts (for instance, if the object was in the process of sliding out) with a call to clearInterval(), and then it sets up a new interrupt to the DoSlideIn() sub-function, like this:

```javascript
O(id).HS_ID = clearInterval(O(id).HS_ID)
O(id).HS_ID = setInterval(DoSlideIn, INTERVAL)
```

This sub-function is where all the animation takes place. First, though to make use of smaller, more manageable variables ox and oy are the values in the HS_X and HS_Y properties of id. These are the location of the top left of id:

```javascript
var ox = O(id).HS_X
var oy = O(id).HS_Y
```

A next, of if... else statements test for whether the edge being used is top, bottom, left, or right by checking the argument against the global variables TP, BM, LT, and RT. Then, as long as it has further to move, the value of either ox or oy is incremented or decremented by the step value in s. Otherwise, if there is no movement to make, the clearInterval() function is called to stop the interrupts, like this:

```javascript
if (where == TP && oy < 0) oy = Math.min(0, oy + s)
else if (where == BM && oy > h) oy = Math.max(h, oy - s)
else if (where == LT && ox < 0) ox = Math.min(0, ox + s)
else if (where == RT && ox > w) ox = Math.max(w, ox - s)
else clearInterval(O(id).HS_ID)
```

Finally, the object is moved to the new location in ox and oy, and the HS_X and HS_Y properties are assigned these values, as follows:

```javascript
GoTo(id, ox, oy)
O(id).HS_X = ox
O(id).HS_Y = oy
```

## Subfunction

The job of this function is to slide the object away again when the mouse passes out of it. The first thing it does is cancel any previously running regular interrupts (for instance, if the object was in the process of sliding in) with a call clearInterval(). Then it sets up a new interrupt to the DoSlideOut() sub-function, like this:

```javascript
if (id).HS_HID = clearInterval(O(id).HS_HID)
O(id).HS_HID = setInterval(DoSlideOut, INTERVAL)
```

As with the similar DoSlideIn(), copies of the properties used are first placed into shorter variable names, like this:

```javascript
var ox = O(id).HS_X
var oy = O(id).HS_Y
```

Then, if the movement hasn't completed, the values of ox and oy are modified as depending upon which edge is being used; otherwise the repeating interrupt is cancelled, as follows:

```javascript
if (where == TP && oy > y) oy = Math.Max(y, oy - s)
else if (where == LT && oy < y) oy = Math.min(y, oy + s)
else if (where == LT && ox > x) ox = Math.Max(x, ox - s)
else if (where == RT && ox < x) ox = Math.Max(x, ox + s)
clearInterval(O(id).HS_HID)
```

Finally, the object is moved to the new location in ox and oy, and the HS_X and HS_Y properties are assigned these values, as follows:

```javascript
GoTo(id, ox, oy)
O(id).HS_X = ox
O(id).HS_Y = oy
```

> Note: HoverSlide() is one of the more complicated plug-ins, but it does create great effects, so it is worth reading the preceding explanation a few times if any parts are not clear first.

## How Use It

To use the HoverSlide() plug-in, you pass an object and tell it where the object should be placed (out of the 'top', 'bottom', 'left', or 'right' edges), wherever on the edge to place it, how of the object to allow showing, and the speed of the sliding animation in milliseconds, as in these examples:

```javascript
HoverSlide('myobject', 'top', '$50', 60, 1000)
HoverSlide('myobject2', 'right', 15, 20, 1000)
```

The first statement places an object at the top edge of the browser, exactly 50 percent along, with 60 pixels showing, and with a sliding window of 1. The second one does the same for another object, but it is attached to the right edge starting 15 pixels down and has only 20 pixels showing.

```javascript
Position(object, FIX)
Position('mydiv', ABS)
```

The first of these has a fixed position (FIX) and places the object in the browser so that even if you scroll through the web page, the object will remain screen exactly where it was placed. The second has an absolute position (ABS) and places the object absolutely within a web page so it will start off looking exactly like a fixed object but move with the page you scroll it.

Here's a fun example using fixed position to create a dynamic menu for a music store:

```html
<table id='a' width='375' height='160' padding='0' bgcolor='black'>
  <tr height='20'>
    <td colspan='3'>
      <font color='white'>
    </td>
  </tr>
</table>
```
