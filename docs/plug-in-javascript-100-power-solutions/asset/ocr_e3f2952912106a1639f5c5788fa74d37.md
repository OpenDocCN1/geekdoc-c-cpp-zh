# Chapter 7: Chaining and Interaction 181

This code works by passing the name of a plug-in to be called in the CB argument for a function that supports it. It does this by using the expression to it and then inserting the next call in the chain into this expression as its final argument.

To do this the string variables left, right and middle are first created, with left containing all the expression up to the insertion point, middle a string containing a reference to the 'NextChain()' plug-in, and right the remainder of the expression after the insertion point. The reference to 'NextChain()' uses single quotes within double quotes to ensure that the string is evaluated, the single quoted string will be processed as and not the result of calling the function name in the string.

If the character immediately following is not '(' (this means that the expression passed to Callback()) includes arguments, the variable middle has a comma and space preceding it, to act as a variable separator. Otherwise it is kept as the assigned value of 'NextChain()'. Finally the three values of left, middle, and right are concatenated and passed to the eval().

When a plug-in is called it will notify the CB is not empty and will therefore evaluate it. In this instance the NextChain() plug-in will be called.

> Note For passing the name of a function (or expression) in CB this way, rather than simply having the plug-in just call NextChain(), is to let you pass expressions of yours to be executed as a callback. To do you pass an expression (or function call) in a string and pass it in CB any plug-in that accepts it (listed in Table 7-1). Your expression will be evaluated when the plug-in executes.

# TheChainThis() plug-in

This plug-in allows you to take a plug-in or function that is not chainable (which you can determine by checking Table 7-2) and use it within a chain. The code is simple like this:

```
eval(expr)
NextChain()
```

For example, suppose that for one of the instructions in a chain you want to move using the following statement:

```
Goto('myobject', x / 2, y + 100)
```

You can also chain this by turning it into a string, using the InsVars() plug-in and ChainThis(), as follows:

```
string = InsVars("ChainThis(\"myobject\", #1, #2)", x / 2, y + 100)
```

The InsVars() plug-in makes it easy to insert variables into a string using tokens such as #1 and #2 as placeholders for them and passing the variables or expressions after the main string.

If you pass the string string to Chain() or Repeat or While() as one of the elements in a chain, the Goto() call will be executed when its turn comes up, and the program flow will pass onto the next item in the chain (if any).
