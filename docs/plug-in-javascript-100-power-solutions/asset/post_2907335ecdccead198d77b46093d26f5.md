## Zoom()

This plug-in is similar in some ways to the Deflate() and Relate() plug-ins but can do much more, including zooming in and out the center of an object as the focus, padding margins during zooms to retain the same width and height (ensuring other objects don't get disturbed by the resizing), and specifying end widths and heights.

In Figure 6-7, four icons are displayed, each of which is attached by its mouse events and when the Zoom() plug-in so when the mouse passes over them they enlarge, and when it moves away they shrink back down. In the figure the second icon is currently zoomed up.

## About the Plug-in

This plug-in will zoom an object over a period of time between supplied sets of width and height. It can also pad the object to retain its overall dimensions and supports three styles of zoom. It requires the following arguments:

- id An object, object ID, or an array of objects and/or object IDs
- w If true or 1, the object's width will be zoomed
- h If true or 1, the object's height will be zoomed
- fromw The width from which the object should be zoomed
- fromh The height from which the object should be zoomed
- tow The width to which the object should be zoomed

## How It Works

This plug-in is quite long because it has to achieve a number of different objectives, but if you follow this explanation you'll see how it breaks down into easily digestible chunks. However, you don't need to understand how this function works if you just want to use it, please don't be put off by this extended commentary.

## If a Zoom Is Not Progress

Next, the plug-in checks whether a zoom is currently progress by looking at its ZO_Flag. If it is not, the variables require this:

```
if (!O(id).ZOFlag) {
  O(id).ZOW = Math.max(fromw, tow)
  O(id).ZOH = Math.max(fromh, toh)
}
```

The first two sentences use the Math() function to determine the maximum width and height will be either the start or end of the zoom. The horizontal and vertical distance between each frame is calculated in stepw and steph.

## Setting Up the Variables

After this, a few locals require setting up:

```
var maxw = Math.max(fromw, tow)
var maxh = Math.max(fromh, toh)
var stepw = (tow - fromw) / INTERVAL
var steph = (toh - fromh) / INTERVAL
```

The first one ensures that the overflow will not out its boundaries if it is made smaller. This isn't applicable to images but must be done for divs and spans that can contain many elements. The overflow is prevented by setting id's style.overflow to HID, which is 'hidden'.

```
(id).overflow = HID
(id).ZOFlag = true
(id).ZOInt = interruptible
(id).ZOIID = setInterval(DoZoom, INTERVAL)
```

## The DoZoom() Function

The job of the DoZoom() function is to perform the resize by changing the object's dimensions each time it called. The first three lines calculate the new width and height for the resizing as follows:

```
if (w)ZOW = Math.max(fromw + stepw * O(id).ZOCount)
if (h)ZOH = Math.max(fromh + steph * O(id).ZOCount)
Resize(id, ZOW, ZOH),
```

In the first line, if the argument w is true, horizontal resizing is allowed so the ZO_W property is assigned the new value required for the object's width. This value is calculated by multiplying stepw (the amount of change for each animation) by ZO_Count (the original width of the object). If the zoom is reducing, then a negative value is added to fromw, otherwise a positive value is added.
