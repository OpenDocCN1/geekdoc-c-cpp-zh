Because JavaScript is supported by all major browsers, you might think that setting yourself as a JavaScript programmer is as easy as having a text editor and a web browser. Well, you could get by with those, but there's actually a lot more to it if you want to produce code efficiently, quickly, and with the minimum of bugs.

First of all, although JavaScript is available on all web browsers it varies slightly between them in the way it implements certain features. This means that you need to be able to test your code on all the main browsers to ensure that it works correctly in all cases. So you really need to have access to a Windows computer, because recent versions of Internet Explorer (IE) are available only for that operating system.

## Downloading and Installing Web Browsers

Table 1-1 lists the few major browsers and their Internet download locations. While all of them can be installed on a Windows PC, some are not available for Mac OS or Linux. The web pages at these URLs are smart and often offer the correct version to download according to your operating system, if available.

Before proceeding with this book I recommend that you ensure you have installed all of these browsers on your computer as you can.

If you're running any version of Windows from XP onward, you will be able to install all of them, but on other operating systems it's not quite so. For example, because development of IE for the Mac was made many years ago at IE version 5, you can install all browsers on Mac OS X except for Microsoft Explorer. And although it is possible to use the Wine windows applications interface on a Mac and run Internet Explorer using it, I found it to be a tedious process with inconsistent results, and therefore wouldn't take screenshots of a web page in different browsers, because they can't tell you whether the mouse, keyboard, and other features are working well, or even at all.

Instead, your best option is to either perform a dual install of Windows alongside Mac OS X, or you have access to a Windows PC. After all, unless you intend to develop only for Mac computers, people using a Windows operating system will represent by far the majority of your users.

As for Linux, it does not have access to Internet Explorer, there is no version of Safari either, although all the other browsers do in Linux flavors. And, as with OS X, while various solutions exist that incorporate Wine running for Internet Explorer, they seem to work with some distributions and not others, can be a bit of a minefield to find a foolproof way to run Windows browsers on Linux.

## Managing Ajax

Ajax stands for Asynchronous JavaScript and XML, but the name is really a misnomer because Ajax is far more than XML handling technology. It is, in fact, at the heart of all modern Web 2.0 websites that exchange information between the web browser and server in the background without the user being aware.

To do this, a server side language is required, and the most popular one is PHP scripting language. So although this isn't about Ajax, inevitably some of these technologies and if you wish to use them on your development computer, you'll need to install a server and PHP processor. You don't have to do this if you don't intend to use any Ajax plugins, but if you do, it is quite simple.

The developers have released an all-in-one application called Zend Community Edition (CE) that includes an Apache web server and a MySQL database. You can download Zend from the following URL:

http://zend.com/products/server-ce

Versions are available for three main operating systems (Windows, Mac OS X, and Linux), and the installation process is reasonably straightforward, although you'll need to carefully read the prompts and make the responses. Figure 1-2 shows how you can control Zend Server CE directly from within your web browser.
