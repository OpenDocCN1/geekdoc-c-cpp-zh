# How It Works

This plug-starts by creating an array of the main two divs, then four strings are created to hold the warning triangle HTML, the OK button, the alert message itself, and two new divs that will contain the alert's title and message header:

```
var divs = Array('ALERT_DIV', 'SHADOW_DIV') +
var warn = "<font color=red size=6 style='vertical-align:middle;'>" + 
"&#916;</font>&nbsp;"
var ok = "<center>input id='ALERT_OK' type='submit' /></center>"
```
