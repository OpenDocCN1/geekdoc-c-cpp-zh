# Center()

More than not, when you center an object you usually want to do so in both horizontal and vertical directions, so this plug-in brings the previous ones together into a single function, as shown in Figure 4-12.

# About the Plug-in

This plug-in centers an object (or objects) on both its vertical and horizontal axes. It requires the following argument:

+   * An object, an object ID, or an array of object or object IDs

# Variables, Arrays, and Functions

| CenterX() | Plug-in to center an object horizontally |
|---|--|
| CenterY() | Plug-in to center an object vertically |

# How It Works

Since both CenterX() and CenterY() have been written to take arguments that can be an array of objects and/or object IDs, an object, an object ID, there is little work for this plug-in to do, so it simply calls each one in turn, passing id (whether or not it's an array) to each.
