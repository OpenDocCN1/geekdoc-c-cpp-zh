The variable `m` is defined in the subexpression after the `?`, but not in the subexpression after the `:`.

# **NOTE:**

The variable-declaring `instanceof` form is called “pattern-matching” because it is similar to type patterns in switch, a “preview” feature of Java 17. I don’t discuss preview features in detail, but here is an example of the syntax:
