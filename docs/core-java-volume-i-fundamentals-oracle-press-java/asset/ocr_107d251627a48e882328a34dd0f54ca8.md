In the example program, the user can choose a font style from a list of styles
(Serif, SansSerif, Monospaced, etc.). The user can also type in another font.

Add the choice items with the addItem method. In our program, addItem is
called only in the constructor, but you can call it any time.

```
```java
var faceCombo = new JComboBox<String>();
faceCombo.addItem("Serif");
faceCombo.addItem("SansSerif");
. . .
```
```

This method adds the string to the end of the list. You can add new items
anywhere in the list with the insertItemAt method:

```
```java
faceCombo.insertItemAt("Monospaced", 0); // add at the
beginning
```
```

You can add items of any type—the combo box invokes each item’s
toString method to display it.

If you need to remove items at runtime, use the removeItem or removeItemAt
method, depending on whether you supply the item to be removed or its
position.

```
```java
faceCombo.removeItem("Monospaced");
faceCombo.removeItemAt(0); // remove first item
```
