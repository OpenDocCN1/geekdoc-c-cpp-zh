# NOTE:

You can use the `s` conversion to format arbitrary objects. If an arbitrary object implements the `Formattable` interface, the object’s `formatTo` method is invoked. Otherwise, the `toString` method is invoked to turn the object into a string. The `toString` method is discussed in [Chapter 5](#) and interfaces in [Chapter 6](#).
