Of course, to find the maximum of an array list, you would write the code
slightly differently.

```
```java
if (v.size() == 0) throw new NoSuchElementException();
T largest = v.get(0);
for (int i = 1; i < v.size(); i++)
    if (largest.compareTo(v.get(i)) < 0)
        largest = v.get(i);
```
```

What about a linked list? You don’t have efficient random access in a linked
list, but you can use an iterator.

```
```java
if (l.isEmpty()) throw new NoSuchElementException();
Iterator<T> iter = l.iterator();
T largest = iter.next();
while (iter.hasNext())
{
    T next = iter.next();
    if (largest.compareTo(next) < 0)
        largest = next;
}
```

These loops are tedious to write, and just a bit error-prone. Is there an offby-
one error? Do the loops work correctly for empty containers? For containers
with only one element? You don’t want to test and debug this code every
time, but you also don’t want to implement a whole slew of methods, such as
these:

```
```java
