# 25.5.2 Constant-time get()

The `get<T>` operation is extremely common when working with tuples, but it requires implementations that require a linear number of template instantiations that can affect compile time. Fortunately, the EBO optimizations introduced in the previous section have enabled a more efficient implementation of the tuple and will reduce the number of template instantiations.

The key insight is that template argument deduction (Chapter 15) deduces template arguments for a base class when matching a parameter of the base class type to an argument of the derived class type. Thus, if we can compute the height `h` of the element we wish to extract, we can rely on the expression from the `Tuple` specialization to `TupleElement`, to retrieve the element.

Because `get<T>` receives the index `I` of the desired element (which accounts from the beginning of the tuple) while the tuple's actual storage is in terms of height `H` (which counts from the end of the tuple), we compute `H` from `I`. Template argument deduction for the call to `getHeight<I>` permits the actual search: the height `I` is fixed because it is explicitly provided in the call, so only one `TupleLike` base class will match, from which the type `T` will be deduced.
