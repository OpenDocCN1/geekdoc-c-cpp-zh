# Type Traits Stuff?

Since C++14+, the standard library uses this technique to define shortcuts for all the types in the standard library that yield a type. For example, to be able to write

![](bbox=[0.08, 0.108, 0.63, 0.122])

```
std::add_const_t<T>                 // since C++14
```

instead of

![](bbox=[0.08, 0.168, 0.63, 0.182])

```
typename std::add_const<T>::type       // since C++11
```

the standard library defines:

![](bbox=[0.08, 0.228, 0.63, 0.242])

```
namespace std {
    template <typename T> using add_const_t = typename
    add_const<T>::type;
}
```

# 2.9 CLASS TEMPLATE ARGUMENT DEDUCTION

Until C++17, you always had to pass all template parameter types to class templates (unless they have default values). Since C++17+, the construction that you always have to specify the template arguments explicitly was relaxed. Instead, you can skip to define the templates arguments explicitly, if the constructor is able to deduce all template parameters (that don't have a default value).

For example, in all previous code examples, you can use a copy constructor without specifying the template arguments:

![](bbox=[0.08, 0.447, 0.63, 0.461])

```
template <typename T>
class Stack {
private:
    Stack() = default;                 // elements
    Stack (const T& elem);              // initialize stack
                                        // with one element
    ...
};
```

By providing constructors that pass some initial arguments, you can specify deduction of the element type of a stack. For example, we could provide a stack that is initialized by a single element:

![](bbox=[0.08, 0.611, 0.63, 0.625])

```
template<typename T>
class Stack {
private:
    std::vector<T> elems;              // elements
public:
    Stack() = default;
    Stack(T const& elem)                // initialize stack
      : elems{elem} { }
    ...
};
```

This allows you to declare a stack as follows:

![](bbox=[0.08, 0.762, 0.63, 0.776])

```
Stack<int> stack1;                 // Stack<int> deduced
since C++17
```

By initializing stack with the integer 0, the template parameter T is deduced to int, so that a Stack<int> is instantiated.

Note the following:

+   - Due to the definition of the init constructor, you have to request the default constructors to be available with its default behavior, because the default constructor is available only if no other constructor is available:
+   
+     `Stack() = default;`
+   
+   - The argument `elem` is passed to `elems` with braces around to initialize the vector `elems` with an initializer list with `elems` as the only argument:
+   
+     `: elems{elem}`

There is no constructor for a vector that is able to take a single parameter as initial element directly.

Note that, unlike for function templates, class template arguments may not be deduced only partially (they explicitly specify only some of the template arguments). See Section 15.12 on page 934 for details.
