# 1.3.3 Return Type as Common Type

Since C++11, the C++ standard library provides a means to specify changing the return type. std::common_type<> is a type trait that defines the “common type” of two (or more) different types passed as template arguments. For example:

}
```
```

The way std::common_type<> is implemented uses some tricky template programming, which is discussed in Section 5.2 on page 622.
