$\mathrm{Sqrt}<16,5,5>$ has a value of 5, as shown below:

```text
value = 5
```

$\mathrm{Sqrt}<16,5,5>$ value is decomposed as follows.

![](bbox=[0.08, 0.11, 0.88, 0.14])

mid = (1+4)/2
= 3
value = $\mathrm{Sqrt}<16,3,4>$ value
= $\mathrm{Sqrt}<16,3,3>$ value
= $\mathrm{Sqrt}<16,4,4>$ value
= $\mathrm{Sqrt}<16,4,4>$ value

Finally, $\mathrm{Sqrt}<16,3,4>$ value results in the following:

![](bbox=[0.08, 0.31, 0.88, 0.34])

mid = (3+4)/2
= 4
value = $\mathrm{Sqrt}<16,3,4>$ value
= $\mathrm{Sqrt}<16,4,4>$ value
= $\mathrm{Sqrt}<16,4,4>$ value

and $\mathrm{Sqrt}<16,4,4>$ value ends the recursive process because it matches the explicit specialization that catches equal high and low bounds. The final result is therefore

```text
value = 4
```

# 23.3.1 Tracking All Instantiations

Our analysis above followed the significant instantiations that comprise the square root of 16. However, when a compiler evaluates the expression

![](bbox=[0.08, 0.7, 0.88, 0.73])

it instantiates not only the templates in the positive branch but also those in the negative branch ($\mathrm{Sqrt}<16,9,16>$). Furthermore, because the code attempts to access a member of the subscript class using the `::` operator, all the members inside that class are also instantiated. This means that the full instantiation of $\mathrm{Sqrt}<16,9,16>$ results in the full instantiation of $\mathrm{Sqrt}<16,9,32>$. When the whole process is examined in detail, we find that dozens of instantiations end up being generated. The total number is almost twice the value of 5.

Fortunately, there are techniques to reduce this explosion in the number of instantiations. To illustrate one such important technique, we rewrite our `Sqrt` metaprogram as follows:

![](bbox=[0.08, 0.89, 0.88, 0.92])

```
```cpp
#include "ifthenelse.hpp"

// primary template for odd recursive step
template<int N, int Low, int High>
struct Sqrt {
  // compute the midpoint, rounded up
  static constexpr auto mid = (Low+High+1)/2;

  // search at too large value in a half interval
  using Sqrt = Sqrt<N, Low, mid-1>;
  static constexpr auto value = Sqrt<N, Low, mid-1>::value;

  // search at too small value
  using Sqrt = Sqrt<N, mid, High>;
  static constexpr auto value = Sqrt<N, mid, High>::value;
};

// partial specialization for end of recursion criteria
template<int N, int Low>
struct Sqrt<N, Low, Low> {
  static constexpr auto value = 5;
};
```
```

The key change here is the use of the `ifThenElse` template, which was introduced in Section 9.1, on page 49. Remember, the `ifThenElse` template is a class that selects between two types based on a given Boolean constant. If the constant is true, the first type is instantiated; otherwise, the second type is instantiated.
