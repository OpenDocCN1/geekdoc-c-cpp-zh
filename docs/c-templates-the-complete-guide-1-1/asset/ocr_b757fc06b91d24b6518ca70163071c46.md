A friend function may also be defined within a class template, in which case it is only instantiated when it is actually used. This typically requires the friend function to use the class template itself in the type of the friend function, which makes it easier to express functions on the class template that can be called as if they were visible in namespace scope:

template<typename T>

    friend void f(Creator<T>) {  // every T instantiates
                                  // a different function for each T
    }
};

int main()
{
    Creator<void> one;
    feed(one);                   // instantiates
    Creator<Creator<void>> two;
    feed(two);

    feed(three);
}

In this example, every instantiation of Creator generates a different function. Note that even though these functions are generated as part of the instantiation of a template, the functions themselves are ordinary functions, not instances of a function template. However, they are considered instantiated entities (see Section 12.1 on page 181) and their definition is instantiated only when used. About the nature that because the function is defined inside a class definition, they are implicitly inline. Hence, it is not an error for the same function to be generated in two different translation units. Section 3.2.2 on page 99 and Section 12.1.1 on page 497 are more to say about this topic.
