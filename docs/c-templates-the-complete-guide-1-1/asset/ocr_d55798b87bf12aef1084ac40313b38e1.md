![](bbox=[0.08, 0.013, 0.83, 0.027])

```
print<double, char const*, std::string>(7.5, "hello", "world");
```

+   - `firstArg` having the value `7.5` so that the type `T` is a `double` and
+   - `args` being a variadic template argument having the values `"hello"` of type `char const*` and `"world"` of type `std::string`.

After printing `T`, `print()` is called again for the remaining arguments, which then expands to:

![](bbox=[0.08, 0.141, 0.83, 0.155])

```
print<char const*, std::string>("hello", "world");
```

+   - `firstArg` having the value `"hello"` so that type `T` is a `char const&` here and
+   - `args` being a variadic template argument having the value of type `std::string`.

After printing `"hello"` as `firstArg`, it calls `print()` again for the remaining arguments, which then expands to:

![](bbox=[0.08, 0.276, 0.83, 0.29])

```
print<std::string>("world");
```

+   - `firstArg` having the value `"world"` so that type `T` is a `std::string` now and
+   - `args` being an empty variadic template argument having no value.

Thus, after printing `"world"` as `firstArg`, we call `print()` with no arguments, which results in calling the non-templated overload of `print()`.

# 4.1.2 Overloading Variadic and Nonvariadic Templates

Note that you can also implement the example above as follows.

![](bbox=[0.08, 0.469, 0.83, 0.483])

```
#include <iostream>

template<typename T>
void print (T arg)
{
    std::cout << arg << '\n';  //print passed argument
}

template<typename T, typename... Types>
void print (T firstArg, Types... args)
{
    print(firstArg);          // call print() for first argument
    print(args...);           // call print() for remaining arguments
}
```

That is, if two function templates only differ by a trailing parameter pack, the function template without the trailing parameter pack is preferred. The section 3.1, page 688 explains the more general overload resolution rule that applies here.
