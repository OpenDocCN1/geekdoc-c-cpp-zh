The following examples show which template is used by which delegation:

**Click here to view code image**

```
MyClass<int, float> x;          // error: MyClass<T1,T2>
MyClass<int, float> a;          // error: MyClass<T>
MyClass<int, float, int> b;     // error: MyClass<T,T>
```

If more than one partial specialization matches equally well, the delegation is ambiguous:

**Click here to view code image**

```
MyClass<int, int> x;            // ERROR: matches
MyClass<T, T>                    // and
MyClass<T, int>                  // ERROR: matches
MyClass<T, T>                    // and
MyClass<T, T*>
```

To resolve the second ambiguity, you could provide an additional partial specialization for pointers of the same type:

**Click here to view code image**

```
template<typename T>
class MyClass<T*, T*> {
    ...
};
```

For details of partial specialization, see Section 16.4 on page 347.

# 2.7 DEFAULT CLASS TEMPLATE ARGUMENTS

As for function templates, you can define default values for class template parameters. For example, in Listing 16.2 you can define the container that is used to manage the elements as a second template parameter, using its default value as the default value:

**Click here to view code image**

```
#include <vector>
#include <cassert>

template<typename T, typename Cont = std::vector<T> >
class Stack {
  private:
    Cont elems;                 // elements

  public:
    void push(T const& elem);   // push element
    void pop();                 // pop element
    T const& top() const;       // return top element
    bool empty() const {
      return elems.empty();
    }
};

template<typename T, typename Cont>
void Stack<T, Cont>::push(T const& elem)
{
  elems.push_back(elem);        // append copy of elem
}

template<typename T, typename Cont>
void Stack<T, Cont>::pop()
{
  assert(!elems.empty());
  elems.pop_back();             // remove last element
}
```
