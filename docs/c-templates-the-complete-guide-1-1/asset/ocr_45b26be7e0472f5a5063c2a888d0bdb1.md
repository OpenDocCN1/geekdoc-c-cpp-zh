Given a variant v, v.is<T>() will determine whether v's active value is of type T. The check is straightforward, comparing the discriminator in the variant's storage against the Discriminator value of the corresponding VariantChoice base class.

If the type we're looking for (T) is not found in the list, the implementation's base class will fail to instantiate because findIndexOfT will not contain a value member, causing an (intentional) compilation failure in is<T>(). This prevents user errors where the user is asking for a type that cannot possibly be stored in the variant.

The get() member function extracts a reference to the stored value. It must be provided with the type to extract (e.g., v.get<int>()) and is only valid when the variant's active value is of that type.
