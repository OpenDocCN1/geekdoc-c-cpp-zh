```
A_Mult<double, A_Scalar<double>, $Array<double>>
```

Hence, the type of the expression to the right of the assignment token is

```
Array<double>
    A_Mult<double,
      A_Mult<double, A_Scalar<double>, $Array<double>>>
```

This type is matched to the assignment operator template of the Array template:

```
template<typename T, typename Rep = $Array<T>>
class Array
{
public:

    // assignment operator for arrays of different type
    template<typename T2, typename Rep2>
    Array& operator= (const Array<T2, Rep2>& x)
    {
        for (int i=0; i<size; ++i)
            rep_[i] = x[i];

        return *this;
    }
};
```

The assignment operator computes each element of the destination x by applying the subscript operator to the representation of the right side, the type of which is

```
A_Mult<double,
   A_Mult<double, A_Scalar<double>, $Array<double>>,
   $Array<double>>
```

Carefully noting this subscript operator shows that for a given subscript i, it computes

```
(1.2*x[i]) + (x[i][y][idx])
```

which is exactly what you want.

# 27.2.5 Expression Template Assignments

It is not possible to instantiate write operations for an array with a 3-argument that is built on our example A_Mult and A_S expression templates. (Indeed, it makes no sense to write to A_ expression; it is entirely reasonable to write other expression templates for which assignment-right semantics are possible. For example, indexing with an array of integer values would intuitively correspond to subset selection. In other words, the expression

```
x[i] = 2*y[i]
```

should mean the same as

Click here to view code image

```
for (int i=0; i < D; i++)
    x[i] = 2*y[i];
```

Enabling this implies that an array built on an expression template becomes an lvalue (i.e., writable). The expression template component for this is not fundamentally different from, say, a_Mult, except that both const and non-const versions of the subscript operators are provided, and they may return lvalue references.

Click here to view code image

```
template<typename T, typename A1, typename A2>

class A_Subscript
{
public:

    // constructor initializes references to operands
    A_Subscript (A1 const& a, A2 const& b)
        : a1(a), a2(b) { }

    // process subscript in rhs via repeated
    decltype(auto) operator() (int id) const
    {
        return a1[id][a2[id]];
    }
```
