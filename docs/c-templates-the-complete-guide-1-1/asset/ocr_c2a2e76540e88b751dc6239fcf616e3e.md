In the recursive case, each Tuple instance contains a data member head that stores the first element in the list, along with a data member tail that stores the remaining elements in the list. The basic case is simply the empty tuple, which has no associated storage.

The get function template allows this recursive structure to extract the requested element:

template<unsigned I>
struct TupleGet {
    template<typename Head, typename... Tail>
    static auto apply(Tuple<Head, Tail...> const& t)
        -> decltype(TupleGet<I-1>::apply(t.getTail())) {
        return TupleGet<I-1>::apply(t.getTail());
    }
};
