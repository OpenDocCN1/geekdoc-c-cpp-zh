# 24.2.6 Accumulating Typelists

`Transform` is a useful algorithm for transforming each of the elements of the sequence. It is often used in conjunction with `Accumulate`, which combines all of the elements of a sequence into a single resulting value.

The `Accumulate` algorithm takes a typelist `T` with elements `T₁, T₂, ..., Tₙ`, an initial typelist `I`, and a metafunction `F` which expects two types and returns a type. If `F(I, T₁) = T'₁`, `F(T'₁, T₂) = T'₂`, ..., then the *i*th step in the accumulation is applied to the result of the previous *i − 1* steps and `Tᵢ`.

Depending on the typelist, choice of `F`, and initial type, we can use `Accumulate` to produce a number of different outcomes. For example, if `F` selects the largest of two types, `Accumulate` will behave like the `type` algorithm. On the other hand, if `F` accepts a typelist and a type and pushes the type on the back of the typelist, `Accumulate` will behave like the reverse algorithm.

The implementation of `Accumulate` follows our standard recursive-metaprogram breakdown:

```
```cpp
template<typename List,
         template<typename X, typename Y> class F,
         typename I>
class Accumulate;

// recursive case:
template<typename T, typename U,
         template<typename X, typename Y> class F,
         typename I>
class Accumulate<Typelist<T, U>, F, I>
{
public:
    typedef typename Accumulate<U, F,
        typename F<I, T>::type>::type type;
};

// base case:
template<template<typename X, typename Y> class F,
         typename I>
class Accumulate<NullType, F, I>
{
public:
    using Type = I;
};
```
```

Here, the initial type `I` is also used as the accumulator, ensuring the current result. Therefore, the basic case returns this result when it reaches the end of the typelist. In the recursive case, the algorithm applies `F` to the previous result (`I`) and the front of the list, passing the result of applying `F` as the initial typelist for the accumulation of the remainder of the typelist.
