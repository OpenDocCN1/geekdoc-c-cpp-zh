The design and optimisation approach of introducing non-specialised versions of general algorithms is called algorithm specialisation. The previous sections detailed the general algorithm, describing which subset the task is a special case of, types or properties, and typically more efficient than the most general implementation of that general algorithm.

Central to the implementation of algorithm specialisation is the property that the more specialised variants are automatically selected when they are applicable, rather than the caller having to ensure that these variants are called. In our simple example, this was accomplished by overloading the function's (or generally a function template's) function template with a most general function template (the first one), and ensuring that the more specialised function template was also more specialised based on C++ partial ordering rules.

```
# ## 20.2 TAG DISPATCHING

One approach to algorithm specialisation is to “tag” different implementations of an algorithm with a unique type that describes that variant and allows the compiler to automatically select the best implementation for the task at hand. We can use the standard library’s iterator category tags (defined below) to simplify the two implementation variants of the advanceIter() algorithm:

Click here to view code image

```
```cpp
template<typename InputIterator, typename Distance>
void advanceIter(InputIterator& i, Distance n, std::input_iterator_tag) {
    while (n > 0) {    // linear time
        ++i;
        --n;
    }
}

template<typename RandomAccessIterator, typename Distance>
void advanceIter(RandomAccessIterator& i, Distance n,
                 std::random_access_iterator_tag) {
    i += n;    // constant time
}
```
```

Then, the advanceIter() function template itself simply forwards its arguments on using the appropriate tag:
```

```cpp
template<typename Iterator, typename Distance>
void advanceIter(Iterator& i, Distance n)
{
    advanceIter(i, n,
                std::iterator_traits<Iterator>::iterator_category());
}
```
