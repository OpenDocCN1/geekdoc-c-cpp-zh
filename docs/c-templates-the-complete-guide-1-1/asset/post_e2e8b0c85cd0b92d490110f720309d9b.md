Again, you could change the implementation to parameterize the internal container type:

```cpp
template<typename T, typename Cont = std::deque<T>>
class Stack {
private:
    Cont elems;                 // elements

public:
    void push(T const&);        // push element
    void pop();                 // pop element
    T const& top() const;       // return top element
    bool empty() const {        // return whether stack is empty
        return elems.empty();
    }

    // assign stack of elements of type T2
    template<typename T2, typename Cont2>
    Stack(Stack<T2, Cont2> const&);

    // to get access to private members of Stack<T2>
    template<typename T2, typename Cont2>
    friend class Stack;
};
```

Thus, the template assignment operator is implemented like this:

```cpp
template<typename T, typename Cont>
template<typename T2, typename Cont2>
Stack<T, Cont>&
Stack<T, Cont>::operator=(Stack<T2, Cont2> const& op2)
{
    elems.clear();                    // remove all
    elems.insert(elems.begin(),       // insert at beginning
                 op2.elems.begin(),
                 op2.elems.end());

    return *this;
}
```

Remember, for class templates, only those member functions that are called are instantiated. Thus, if you avoid assigning a stack with elements of a different type, you could even use a vector as the internal container:

```cpp
// stack for ints using a vector as internal container
Stack<int, std::vector<int> > vStack;

vStack.push(42); vStack.push(7);
std::cout << vStack.top() << '\n';
```

Because the assignment operator template isn't necessary, no error message of a missing member function push_front() occurs and the program is fine.

## Special Member Function Templates

Template member functions can be used whenever special member functions allow copying or moving objects. Similar to assignment operators as defined above, they can also be constructor templates. However, note that template constructors or template assignment operators don’t replace predefined constructors or assignment operators. Member templates don’t count as the special member functions that copy or move objects. For example, for assignments of stacks of the same type, the default assignment operator is still called.

**This effect can be good and bad:**

- It can happen that a template constructor or assignment operator is a better match than the predefined copy/move constructor or assignment operator, although a template version is provided for initialization of other types only. See Section 6.2 on page 59 for details.
- It is not easy to “employ” a copy/move constructor, for example, to be able to constrain its existence. See Section 6.4 on page 102 for details.

### 5.5.1 The Template Keyword

Sometimes, it is necessary to explicitly qualify template arguments when calling a member template. In that case, you have to use the template keyword to ensure that < is the beginning of the template argument list. Consider the following example using the standard library type std::bitset:

**Click here to view code image**

```cpp
template<int N>
void printBitset (std::bitset<N> const& bs)
{
    std::cout << bs.template to_string<char,
                                       std::char_traits<char>,
                                       std::allocator<char>>();
}
```

For the bitset we call the member function template to_string() while explicitly specifying the string type details. Without that extra use of the template keyword, the compiler would interpret the less-than sign as the beginning of a comparison.

The type of the object depends on a template parameter. In our example, the parameter is dependent on the template parameter `T`.

The `.` notation (and similar notations such as `->template` and `::template`) should be used only inside templates and only if they follow something that depends on a template parameter. See Section 13.3.3 on page 39 for details.

### 5.5.2 Generic Lambdas and Member Templates

Note that generic lambdas, introduced with C++14, are shortcuts for member templates. A simple lambda containing the “sum” of two arguments of arbitrary types

Click here to view code image

```cpp
[](auto x, auto y) {
  return x + y;
}
```

is a shortcut for a default-constructed object of the following class:

```cpp
class SomeCompilerSpecificName {
public:
  SomeCompilerSpecificName() { }  // constructor only
  template<typename T1, typename T2>
  auto operator() (T1 x, T2 y) const {
    return x + y;
  }
};
```

See Section 15.10.6 on page 39 for details.

## 5.6 VARIABLE TEMPLATES

Since C++14, variables also can be parameterized by a specific type. Such a variable is called a variable template.

For example, you can use the following code to define the value of `pi` while still defining the type of the value:

Click here to view code image

```cpp
template<typename T>
constexpr T pi = 3.1415926535897932385;
```

Note that, as for all templates, this declaration may not occur inside functions or block scope.

To use a variable template, you have to specify its type. For example, the following code uses two different variants of the variable template `pi` declared:

Click here to view code image

```cpp
std::cout << pi<double> << '\n';
std::cout << pi<float> << '\n';
```

You can also declare variable templates that are used in different translation units.

Click here to view code image

```cpp
// header.hpp

template<typename T> T val;  // zero initialized

// translation unit 1:
#include "header.hpp"

int main() {
  val<long> = 42;
  print();
}

// translation unit 2:
#include "header.hpp"

void print() {
  std::cout << val<long> << '\n';  // prints 42
}
```

Variable templates can also have default template arguments.

Click here to view code image

```cpp

```
