As we've seen with the insertion sort, const-style typelists can express all of the same algorithms as the variadic typelists described throughout this chapter. Indeed, many of the algorithms described are written in precisely the same style used to manipulate cons-style typelists. However, they have a few downsides that lead us to prefer the variadic versions. First, the nesting makes long const-style typelists very hard to both write and, in source code and in compiler diagnostics. Second, several algorithms (including PushBack and Trace) can be specialized for variadic typelists to provide more efficient implementations (as measured by the number of instantiations). Finally, the use of variadic templates for typelists fits well with the use of variadic templates for heterogeneous containers, discussed in Chapter 2 and Chapter 25.
