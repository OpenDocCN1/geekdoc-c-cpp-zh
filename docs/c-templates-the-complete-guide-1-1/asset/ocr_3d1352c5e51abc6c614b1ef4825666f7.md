The template AccumulatorTraits is called a traits template because it holds a trait of its parameter type. (In general, there could be more than one trait and more than one parameter.) We chose not to provide a generic definition of this template because there isn’t a great way to select a good association type when we don’t know what the type is. However, an argument could be made that it “isn’t” often a good candidate for such a type (although nearly not in our earlier example).
