```
Thus, the result is only allowing instantiation for those template arguments that meet the requirements of the implementations of the template (`T2`, `T3`, and `T5`), so we never get an error from the body of `min()`. Moreover, if we had some other overload of `min()` that might work for these types, overload resolution could have selected one of those instead of throwing an error.

The last type in our example, `X7`, illustrates some of the subtleties of implementing instantiation-safe templates. In particular, if `X7` is passed to the non-instantiation-safe `min()` function, instantiation will succeed. However, the instantiation-safe `min()` rejects it because no `NULL` is set implicitly convertible to `bool`. The distinction here is particularly subtle: An explicit conversion to `bool` can be used implicitly in certain contexts, including in Boolean conditions for control-flow statements (`if`, `while`, `for`, and `do`), the built-in `!=`, `==`, and `!` operators, and therefore the value is said to be contextually converted to `bool`.

However, our insistence on having a general, implicit conversion to `bool` has the effect that our instantiation-safe templates are overconstrained; that is, we specified requirements that the template needs to instantiate properly. (It is, on the other hand, underconstrained if we had entirely forgotten the conversion-to-`bool` requirement, and it would have allowed some template arguments that could cause an instantiation failure for such as `X6`.)

To fix the instantiation-safe `min()`, I need a trait to determine whether a type is contextually convertible to `bool`. The control-flow statements are not a helpful way of defining this trait, because statements cannot occur within a SFINAE context, nor are the logical operators, which can be overloaded for an arbitrary type. Fortunately, the ternary operator `?:` is an expression and is not overloadable, so it can be exploited to test whether a type is contextually convertible to `bool`:

Click here to view code image

```
```cpp
#include <utility>      // for declval()
#include <type_traits>   // for true_type and false_type

template<typename T>
class IsContextualBool {
  private:
    template<typename U> static auto test(int)
      -> decltype(std::declval<U>() ? 1 : 0);

    template<typename> static auto test(...) -> false_type;

    test(0);

  public:
    static constexpr bool value = decltype(test<T>(nullptr))::value;
};
```
