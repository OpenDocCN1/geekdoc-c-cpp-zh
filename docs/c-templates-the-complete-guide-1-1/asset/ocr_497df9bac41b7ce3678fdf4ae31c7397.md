```
# 4.4.4 Variadic Deduction Guides

Even deduction guides (see Section 2.9 on page 62) can be variadic. For example, the C++ standard library defines the following deduction guide for `std::array`:

Click here to view code image

```
```cpp
namespace std {
template<typename T, typename... U>
array(T, U...) -> array<std::common_type_t<T, U...>,
                       1 + sizeof...(U)>;
}
```
```

An instantiation such as

```
```cpp
std::array arr{42, 45, 77};
```
```

deduces `T` in the guide to the type of the element, and the various `_U` types to the types of the subsequent elements. The total number of elements is therefore `1 + sizeof...(U)`:

Click here to view code image

```
```cpp
std::array{42, 45, 77};
```
```

The `std::enable_if_t<>` expression for the first array parameter is a fold expression that (as introduced as a homogeneous constraint in Section 4.4.1 on page 63) expands to:

Click here to view code image

```
```cpp
is_same_v<T, U> && is_same_v<U, U> && is_same_v<U, U>
```
```

If the result is true for (i.e., and all the element types are the same), the deduction guide is discarded and the overall deduction fails. This way, the standard library ensures that all elements must have the same type for the deduction guide to succeed.
```
