# 21.2.1 The Barton–Nackman Trick

In 1994, John J. Barton and Lee R. Nackman presented a template technique that they called restricted template expansion (see [BartonNackman]). The technique was motivated in part by the fact that—at the time—function template overloading was severely limited and namespaces were not available in most compilers.

To illustrate this, suppose we have a class template A for which we want to define the equality operator ==. One possibility is to declare the operator as a member of the class template, but this is not good practice because the first argument (binding to the this pointer) is subject to conversion rules that differ from the second argument. Because operator == is meant to be symmetrical with respect to its arguments, it is preferable to declare it as a namespace scope function.
