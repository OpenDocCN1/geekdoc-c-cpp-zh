# std::decay<T>

+   - Defined in header `<type_traits>`
+   - Yields an "object" or function of any type without calling any constructor or initialization
+   - If `T` is a reference, the return type is `T`.
+   - This can be used to deal with objects or functions of any type in unevaluated expressions.
+   - It is simply defined as follows:

# Then

+   - If `T` is a plain type or an rvalue reference, it yields `T`.
+   - If `T` is an lvalue reference, it yields `T&`.
+   - If `T` is a function, it yields `T*`.
+   - See Section 5.3.3 on page 171 for details and Section 11.3.3 on page 596 for more details; `type<>` type trait in Section D.3.3 on page 733 for example using it.

# std::addressof<T>

+   - Defined in header `<memory>`
+   - Yields the address of an object or function `x` even if `operator&` is overloaded for its type.
+   - See Section 12.5 on page 676 for details.
