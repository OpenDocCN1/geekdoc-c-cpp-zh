```
std::cout << int20Stack.top() << '\n';
int20Stack.pop();

// manipulate stack of up to 40 strings

stringStack.push("hello");
std::cout << stringStack.top() << '\n';
stringStack.pop();
}
```

Note that each template instantiation is its own type. Thus, int20Stack and int40Stack are two different types, and no implicit or explicit type conversion between them is defined. Thus, one cannot be used instead of the other, and you cannot assign one to the other.

Again, default arguments for the template parameters can be specified:

Click here to view code image:

```
template<typename T = int, std::size_t MaxSize = 100>
class Stack {
};
```

However, from a perspective of good design, this may not be appropriate in this example. Default arguments should be intuitively correct. But neither type int nor a maximum size of 100 seems intuitive for a general stack type. Thus, it is better when the programmer has to specify both values explicitly so that these two attributes are always documented during a declaration.

# 3.2 NONTYPE FUNCTION TEMPLATE PARAMETERS

You can also define non-type parameters for function templates. For example, the following function template defines a group of functions for which a certain value can be added:

Click here to view code image:

```
template<int Val, typename T>
T addValue (T x)
{
    return x + Val;
}
```

These kinds of functions can be useful if functions or operations are used as parameters. For example, if you use the C++ standard library you can pass an instantiation of this function template to add a value to each element of a collection:

Click here to view code image:

```
std::transform(source.begin(), source.end(),  // source
               dest.begin(),                    // dest
               addValue<5, int>);               // operation
```

The last argument instantiates the function template addValue<5> to add 5 to a value. The resulting function is called for each element in the source collection source, while it is translated into the destination collection dest.

Notice that you have to specify the argument list for the template parameter of addValue<5,int>. Deduction only works for immediate calls and not for a transfer to a function template. It cannot be completed by the type of the function parameter. There is no support to substitute or deduce only some template parameters and let the rest be deduced from the remaining parameters.

Again, you can also specify a default template parameter as deduced from the previous parameter. For example, to derive the return type from the passed non-type:

Click here to view code image:

```
template<typename Val, typename T = decltype(Val)>
T foo();
```

or ensure that the passed value has the same type as the passed type:

Click here to view code image:

```
template<typename T, T Val = T()>
T foo();
```
