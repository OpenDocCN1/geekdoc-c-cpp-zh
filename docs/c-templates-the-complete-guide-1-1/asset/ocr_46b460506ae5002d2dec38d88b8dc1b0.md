```
is_convertible_v<...>                 // yields false
```

+   - Requires that the given types are either complete (see Section [basic.types]), or arrays of unknown bound.
+   - Note that a const pointer is a const-qualified type, whereas a non-const pointer or reference to a const type is not const-qualified. For example, `is_assignable<...>` has a different order for the three modes of instantiation.
+   - Section [..] on page 425 for implementation details.

# D.4 TYPE CONSTRUCTION

The traits listed in Table D.6 allow us to construct types from other types.

|---|---|
