# ## 5.10.2 Expressing the Type of an Expression with decltype

While auto and decltype work in a way that is often the same, the type that is deduced for auto is not always the same as the type that is deduced for decltype. The type that is deduced for auto may differ from the type that is deduced for decltype due to a different treatment of the value category of an expression. For example, decltype produces the type of the expression; that is, the type of the expression including the value category of the expression. The type that is deduced for auto is a different type, because auto deduces the type of the expression without the value category. The type that is deduced for decltype is a different type, because decltype deduces the type of the expression including the value category.

```
```
auto x = 2;
auto y = x + 1;
decltype(x) y2 = x + 1;
```
```

Depending on the initializer for x, y2 may or may not have the same type as x. If derived on decltype, y2 has the same type as x. If derived on auto, y2 has the same type as x. The type of decltype(x) is int&, while the type of decltype(x) is int.

+   - If e is an lvalue of type T, decltype(e) produces T.
+   - If e is an lvalue of type T, decltype(e) produces T&.
+   - If e is an lvalue of type T, decltype(e) produces T&&.

See Appendix A for a detailed discussion about value categories. The difference can be demonstrated by the following example:
