```
```cpp
void someFunc(int i) const {
    std::cout << "MyClass::someFunc() called for: " << i;
}

int main()
{
    std::vector<int> primes = { 2, 3, 5, 7, 11, 13, 17 };

    // pass lambda as callable and an additional argument
    foreach(primes.begin(), primes.end(),        // elements
        [](std::string const& prefix, int i) {   // lambda
            std::cout << prefix << i << '\n';
        },
        "value:");                              // argument

    // call obj.someFunc() for each element to print it
    MyClass obj;
    foreach(primes.begin(), primes.end(),        // elements
        &MyClass::someFunc,                      // member function
        obj);                                     // object to call
}
```
```

The first call of `foreach()` passes its fourth argument (the string literal `"value:"`) to the first parameter of the lambda, while the current element in the vector binds to the second parameter of the lambda. The second call passes the member function reference `&MyClass::someFunc` that is called for `obj` as passed as the fourth argument.

See Section 3.D.3 on page 716 for type traits that yield whether a callable can be used by `std::invoke()`.

# 11.1.3 Wrapping Function Calls

A common application of `std::invoke` is to wrap single function calls (e.g., to log them, measure their duration, or prepare some context such as starting a new thread for them). Now, we can support more semantics by perfect forwarding both the callable and all passed arguments:

Click here to view code image

```
```cpp
template<typename Callable, typename... Args>
decltype(auto) call(Callable&& op, Args&&... args)
{
    return std::invoke(std::forward<Callable>(op),
                       std::forward<Args>(args)...);
}
```
```

The other interesting aspect is how to deal with the return value of a called function to “perfectly forward” it back to the caller. To support returning references (such as `std::string&`) from it, we use `decltype(auto)` instead of just `auto`.

Click here to view code image

```
```cpp
template<typename Callable, typename... Args>
decltype(auto) call(Callable&& op, Args&&... args)
{
    decltype(auto) value = std::invoke(std::forward<Callable>(op),
                                       std::forward<Args>(args)...);
    return value;
}
```
```

If you want to temporarily store the value returned by `std::invoke()` in a variable to return it after doing something else (e.g., do a little work before returning the value or log the end of the call), you also have to declare the temporary variable with `decltype(auto)`:

```cpp
