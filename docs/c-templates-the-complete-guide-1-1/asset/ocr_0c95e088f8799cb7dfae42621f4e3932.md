`std::is_member_pointer<T>::value`  
- Yields true if type `T` is any pointer-to-member type.  
- Same as: `is_member_object_pointer<T> || is_member_function_pointer<T>`

`std::is_arithmetic<T>::value`  
- Yields true if type `T` is an arithmetic type (bool, character type, integer type, or floating-point type).  
- Same as: `is_integral<T> || is_floating_point<T>`

`std::is_fundamental<T>::value`  
- Yields true if type `T` is a fundamental type (arithmetic type or void or `std::nullptr_t`).  
- Same as: `is_arithmetic<T> || is_void<T> || is_null_pointer<T>`  
- See `std::is_fundamental` in Section 19.8.1 on page 448 for implementation details.

`std::is_scalar<T>::value`  
- Yields true if type `T` is a “scalar” type.  
- Same as: `is_arithmetic<T> || is_enum<T> || is_pointer<T> || is_member_pointer<T> || is_null_pointer<T>`

`std::is_object<T>::value`  
- Yields true if type `T` describes the type of an object.  
- Same as: `is_scalar<T> || is_array<T> || is_class<T> || is_union<T>`

`std::is_compound<T>::value`  
- Yields true if type `T` is a type compound of all other types.  
- Same as: `!is_fundamental<T>`  
  or an array, class, union, enum, reference, pointer, or member-pointer type.

# ### D.3 TYPE PROPERTIES AND OPERATIONS

The next group of traits offer properties of single types as well as certain operations (e.g., value swapping) that may apply to them.

# #### D.3.1 Other Types

`std::is_signed<T>::value`  
- Yields true if `T` is a signed arithmetic type (i.e., an arithmetic type that includes negative value representations); this includes types like `(signed) int`, `float`.  
- For type `bool`, it yields false.  
- For type `char`, it is implementation defined whether it yields true or false.  
- For all nonarithmetic types (including enumeration types) `is_signed` yields false.

`std::is_unsigned<T>::value`  
- Yields true if `T` is an unsigned arithmetic type (i.e., an arithmetic type that does not include negative value representations); this includes types like `unsigned int` and `bool`.  
- For type `char`, it is implementation defined whether it yields true or false.  
- For all nonarithmetic types (including enumeration types) `is_unsigned` yields false.

`std::is_const<T>::value`  
- Yields true if the type is const-qualified.  
- Note that a const pointer has a const-qualified element type, whereas a const pointer or a reference to a const type is not const-qualified. For example:

```
```cpp
std::is_const<int>::value        // false
std::is_const<const int>::value  // true
std::is_const<int const*>::value // false
```
```

The language defines arrays to be const-qualified if the element type is const-qualified.⁵ For example:

```
```cpp
std::is_const<int[3]>::value        // false
std::is_const<const int[3]>::value  // true
```
```
