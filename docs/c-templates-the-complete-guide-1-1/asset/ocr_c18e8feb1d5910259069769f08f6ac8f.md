# Glossary

This glossary is a compilation of the most important technical terms that we use in the book. See [StroustrupGlossary] for a comprehensive, general glossary of terms used by C++ programmers.

# abstract class

A class for which the creation of objects (instances) is impossible. Abstract classes are used to model common properties of different classes in a class hierarchy. The opposite of abstract class is concrete class. Abstract classes are used in base classes; the acronym ABC is sometimes used for abstract base class.

# ADL

An acronym for argument-dependent lookup. ADL is a process that looks for a function name (or operator name) in the namespaces of each of its arguments (or in the namespaces associated with the arguments of the function call in which that function (or operator name) appears). For historical reasons, it is sometimes called Koenig lookup (the latter is also used for ADL applied to operators).

# alias template

A construct that represents a family of type aliases. It specifies a pattern from which actual type aliases can be generated by substituting the template parameters by specific entities. An alias template can be a class member.

# angle bracket hack

A C++ feature that requires a compiler to accept two consecutive `>` characters as closing two template argument lists, even though the two characters would otherwise be interpreted as an int shift operator (`>>`). It's called a hack because it doesn't fit well in the C++ formal specification (the grammar, in particular) or in the general architecture of C++ compilers. Another similar hack deals with alternative digraph notations (see digraph).

# angle brackets

The characters `<` and `>` when they are used as delimiters rather than as less-than and greater-than operators.

# ANSI

An acronym for American National Standards Institute, a private, non-profit organization that coordinates efforts to produce standard specifications of the U.S. (See ISO.) Note ANSI.

# argument

A value (in a broad sense) that substantiates a parameter of a parametric entity. For example, in a function call `f(1)`, the argument is 1. In some programming communities, arguments are called actual parameters whereas parameters are called formal parameters. See also default argument.

# argument-dependent lookup

See ADL.

# class

The description of a set of objects. The class defines a set of characteristics for any object of that type. This includes data (attributes), data members, and operations (methods, member functions). In C++, classes are structures with members that can be functions and are subject to access limitations. They are declared using the keyword `class` or `struct`.

# class template

A construct that represents a family of classes. It represents a pattern from which actual classes can be generated by substituting the template parameters by specific entities. Class templates are sometimes called parameterized classes.

# class type

A C++ type declared with `class`, `struct`, or `union`.
