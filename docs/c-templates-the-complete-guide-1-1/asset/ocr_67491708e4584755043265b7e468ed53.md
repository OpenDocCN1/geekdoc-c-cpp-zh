All standard type traits yielding a value are derived from an instance of the helper class template `std::integral_constant`:

Click here to view code image

```
```cpp
template<typename T, T val>
struct integral_constant {
    static constexpr T value = val;          //
    using value_type = T;                    //
    using type = integral_constant<T, val>;

    constexpr operator value_type () const noexcept
    {
        return value;
    }
};
```
```

That is:

+   - We can use the `value_type` member to query the type of the result. Since many traits yielding a value are predicates, `value_type` is often just `int`.
+   
+   - Objects of traits types have an implicit conversion to the type of the value produced by the type trait.
+   
+   - In C++14 (and later), objects of type traits are also function objects (functors), where a “function call” yields their value.
+   
+   - The `type` member just aliases the underlying `integral_constant` instance.

If traits yield Boolean values, then can also use

Click here to view code image

```
```cpp
template<bool T>
struct is_bool
{
    using bool_constant = integral_constant<bool, T>;  // since C++17
    using true_type = bool_constant<true>;
    using false_type = bool_constant<false>;
};
```
```

so that these Boolean traits inherit from `std::true_type` if a specific property applies and from `std::false_type` if not. That also means that their corresponding `value` members equal `true` or `false`. Having distinct types for the resulting values turned false allows us to tag-dispatch based on the results of type traits (see Section 9.3.3 on page 467).

For example:

```cpp
#include <type_traits>
#include <iostream>

int main()
{
    using namespace std;

    cout << boolalpha;

    using MyType = int;

    cout << is_const<MyType>::value << '\n';

    using VT = is_const<MyType>::value_type;  // bool

    using T = is_const<MyType>::type;         // integral_constant<bool, false>

    cout << is_same<VT, bool>::value << '\n';

    cout << is_same<T, integral_constant<bool, false>>::value
         << '\n';

    cout << is_same_v<T, integral_constant<bool, false>>;
```
