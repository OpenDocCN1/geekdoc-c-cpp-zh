```
```cpp
intStack.push(7);
std::cout << intStack.top() << '\n';

// manipulate string stack
stringStack.push("hello");
std::cout << stringStack.top() << '\n';
stringStack.pop();
```
```

By declaring `typedef Stack<int> IntStack`, `int` is used as type inside the class template. Thus, `IntStack` is created as an object that uses `int` as elements and, for all member functions that are called, code for this type is instantiated. Similarly, by declaring and using `StringStack`, an object that uses strings as elements is created, and for all member functions that are called, code for this type is instantiated.

Note that code is instantiated only for template (member) functions that are called. For class templates, member functions are instantiated only if they are used. Thus, of course, members and space are allocated only if they are used. This example illustrates how class templates are instantiated only partially, which we will discuss in Section 2.3 on page 32.

In this example, the default constructor, `push()`, and `top()` are instantiated for both `IntStack` and `StringStack`. However, `pop()` is instantiated only for `IntStack`. If a class template has static members, these are also instantiated for each type for which the class template is used.

An instantiated class template's type can be used just like any other type. You can qualify it with `const` or `volatile` or define array and reference types from it. You can also use it as a type definition within a `typedef` or `using` (see Section 2.8 on page 38 for details about type definitions) or use it as a parameter between building another template type. For example:

Click here to view code image

```
```cpp
void foo(Stack<int> const& s)   // parameter s is int stack
{
    using IntStack = Stack<int>; // IntStack is another name for Stack<int>
    Stack<int> intStack[10];     // intStack is an array of 10 int stacks
    IntStack stack2[10];         // stack2 is also an array of 10 int stacks (same type)
}
```
```

Template arguments may be any type, such as pointers to floats or even stacks of ints:

```cpp
Stack<float*> floatStack;       // stack of float pointers
Stack<Stack<int>> intStackStack; // stack of Stack<int>
```
```

The only requirement is that any operation that is called is possible according to this type.

Note that before C++11 you had to put whitespace between the two closing template brackets:

Click here to view code image

```
```cpp
Stack<Stack<int> > intStackStack; // OK with all C++ versions
```
```

If you didn't do this, you were using operator `>>`, which resulted in a syntax error.

Click here to view code image

```
```cpp
Stack<Stack<int>> intStackStack; // ERROR before C++11
```
```

The reason for double-brackets was that it had been the first case of a compiler to tokenize the source code independent of the semantics of the code. However, because the missing space was a typical bug, which required corresponding error messages, the semantics of the code were not made to get taken into account anyway. So, with C++11 the rule to put a space between two closing template brackets was removed.
