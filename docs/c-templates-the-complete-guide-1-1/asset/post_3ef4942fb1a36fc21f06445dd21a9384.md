
```cpp
template<typename List>
using PopBack = typename PopBackT<List>::Type;
```

The algorithm reverses the list, removes the first element from the reversed list (using `PopBack`), and then reverses the resulting list again.

## 24.2.5 Transforming a Typelist

Our previous typelist algorithms have allowed us to extract arbitrary elements from a typelist, such as the nth element, construct a new typelist, and reverse lists. However, we have yet to perform any operations on the elements within the typelist. For example, we may want to "transform" all of the types in the typelist in some way, such as by adding each type into its own const-qualified variant using the `AddConstT` declaration:

Click here to view code image

```cpp
template<typename T>
struct AddConstT
{
    using Type = T const;
};

template<typename T>
using AddConst = typename AddConstT<T>::Type;
```

To that end, we will implement a `Transform` algorithm that takes a typelist and a metafunction and produces another typelist containing the result of applying the metafunction to each type. For example, the type
`Transform<Typelist<int, short, long>, AddConst>`
will be a typelist containing `int const`, `short const`, and `long const`. The metafunction is provided through a template template parameter, which maps an input type to an output type. The `Transform` algorithm itself is, as we might expect, a recursive algorithm.

Click here to view code image

```cpp
template<typename List, template<typename T> class MetaFun,
         bool Empty = IsEmpty<List>::value>
class TransformT;

// recursive case:
template<typename List, template<typename T> class MetaFun>
class TransformT<List, MetaFun, false>
  : public PushFrontT<
      typename TransformT<typename PopFront<List>::Type, MetaFun>::Type,
      typename MetaFun<typename Front<List>::Type>::Type>
{
};

// basis case:
template<typename List, template<typename T> class MetaFun>
class TransformT<List, MetaFun, true>
{
  public:
    using Type = List;
};

template<typename List, template<typename T> class MetaFun>
using Transform = typename TransformT<List, MetaFun>::Type;
```

The recursive case applies `MetaFun` to the front element of the typelist (second argument to `PushFront`) and adds it to the beginning of the sequence produced by recursively transforming the rest of the elements in the typelist (first argument to `PushFront`).

See also Section 24.1.9 on page 508 which shows how a more efficient implementation of transforms can be developed.

## 24.2.6 Accumulating Typelists

`Transform` is a useful algorithm for transforming each of the elements of the sequence. It is often used in conjunction with `Accumulate`, which combines all of the elements of a sequence into a single resulting value.

The `Accumulate` algorithm takes a typelist `T` with elements `T₁, T₂, ..., Tₙ`, an initial type `I`, and a metafunction `F` which expects two types and returns a type. If `F(I, T₁) = T'₁`, `F(T'₁, T₂) = T'₂`, ..., then the *i*th step in the accumulation is applied to the result of the previous *i − 1* steps and `Tᵢ`.

Depending on the typelist, choice of `F`, and initial type, we can use `Accumulate` to produce a number of different outcomes. For example, if `F` selects the largest of two types, `Accumulate` will behave like the `LargestType` algorithm. On the other hand, if `F` accepts a typelist and a type and pushes the type on the back of the typelist, `Accumulate` will behave like the reverse algorithm.

The implementation of `Accumulate` follows our standard recursive-metaprogram breakdown:

[Click here to view code image](typelist/accumulate.hpp)

```cpp
template<typename List,
         template<typename X, typename Y> class F,
         typename I>
class Accumulate;

// recursive case:
template<typename T, typename U,
         template<typename X, typename Y> class F,
         typename I>
class Accumulate<Typelist<T, U>, F, I>
{
  public:
    using Type = typename Accumulate<U, F,
        typename F<I, T>::Type>::Type;
};

// basis case:
template<template<typename X, typename Y> class F,
         typename I>
class Accumulate<NullType, F, I>
{
  public:
    using Type = I;
};
```

Here, the initial type `I` is also used as the accumulator, carrying the current result. Therefore, the basis case returns this result when it reaches the end of the typelist. In the recursive case, the algorithm applies `F` to the previous result (`I`) and the front of the list, passing the result of applying `F` as the initial type for the accumulation of the remainder of the typelist.

```cpp
using Result = Accumulate<SignedIntegerTypes,
                          PushBack, NullType>::Type;
// produces Typelist<signed char, short, int, long>
```

Implementing an Accumulate-based version of `LargestType` requires slightly more effort, because we need to provide the metafunction that returns the larger of two types.

Click here to view code image

`typelist/largestTypeAcc.cpp`

```cpp
template<typename T, typename U>
class LargerTypeT
{
  public:
    using Type = IfThenElse<(sizeof(T) >= sizeof(U)), T, U>;
};

template<typename Typelist>
class LargestTypeT
{
  public:
    using Type = typename Accumulate<Typelist, LargerTypeT,
                                     Front<Typelist>::Type>::Type;
};

template<typename Typelist>
using LargestType = typename LargestTypeT<Typelist>::Type;
```

Note that this formulation of `LargestType` requires a nonempty typelist, because it provides the first element of the typelist as the initial type. We could handle the empty-list case explicitly, either by returning some sentinel type (`char` or `void`) or by making the algorithm itself SFINAE-friendly, as discussed in Section 19.4.4 on page 492.

Click here to view code image

`typelist/largestTypeAcc.cpp`

```cpp
template<typename T, typename U>
class LargerTypeT
{
  public:
    using Type = IfThenElse<(sizeof(T) >= sizeof(U)), T, U>;
};

template<typename Typelist, bool = IsEmpty<Typelist>::value>
class LargestTypeT;

template<typename Typelist>
class LargestTypeT<Typelist, false>
{
  public:
    using Type = typename Accumulate<Typelist, LargerTypeT,
                                     Front<Typelist>::Type>::Type;
};

template<typename Typelist>
class LargestTypeT<Typelist, true>
{
};

template<typename Typelist>
using LargestType = typename LargestTypeT<Typelist>::Type;
```

Accumulate is a powerful typelist algorithm because it allows us to express many different operations, and therefore can be considered one of the fundamental algorithms for typelist manipulation.

## 24.2.7 Insertion Sort

For our final typelist, we will implement an insertion sort. As with other algorithms, the recursive step splits the list into its first element (the head) and the remaining elements (the tail). The tail is then sorted (recursively), and the head is inserted into the correct position within the sorted list. The shell of this algorithm is expressed as a typelist algorithm:

**Click here to view code image**

`typelist/insertion-sort.hpp`

```cpp
template<typename List,
         template<typename T, typename U> class Compare,
         bool = IsEmpty<List>::value>
class InsertionSortT;

template<typename List,
         template<typename T, typename U> class Compare>
using InsertionSort = typename InsertionSortT<List, Compare>::Type;

// recursive case (insert first element into sorted tail)
template<typename List,
         template<typename T, typename U> class Compare>
class InsertionSortT<List, Compare, false>
  : public InsertSortedT<InsertionSort<List, Compare>,
                         Front<List>::Type, Compare>
{
};

// basis case (an empty list is sorted):
template<typename List,
         template<typename T, typename U> class Compare>
class InsertionSortT<List, Compare, true>
{
  public:
    using Type = List;
};
```

The `Compare` parameter is the comparison used to order elements in the typelist. It accepts two types and evaluates to a Boolean via its `value` member. The basis case, an empty typelist, is trivial.

The core of insertion sort is the `InsertSorted` metafunction, which inserts a value into an already-sorted list at the first point that will keep the list sorted:

`typelist/insertion-sort.hpp`

```cpp

         bool = IsEmpty<List>::value>

// recursive case:
template<typename List, typename Element,
         template<typename T, typename U> class Compare>
class InsertSortedT<List, Element, Compare, false>
```
