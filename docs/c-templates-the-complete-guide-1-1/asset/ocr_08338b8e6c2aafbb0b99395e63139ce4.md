# 9.8.4 Determining Class Types

Unlike the other compound types we have handled so far, we have no partial specialization patterns that match class types specifically. Nor is it feasible to enumerate all class types, as it is for fundamental types. Instead, we need to use an indirect method to identify class types, by coming up with some trait that can be used to represent the kind of type in question. (and not other type). With that type or expression, we can apply the SFINAE trick techniques discussed in Section 9.0 on page 411.

The most convenient property of class types to utilize in this case is that class types can be used as the basis of pointer-to-member types. That is, in a type construct of the form `X Y::*`, if `X` can also be a class type. The following formulation of `IsClass<T>` exploits this property (and picks an arbitrarily for type `X`):

```
```cpp
trait/isclass.hpp

template<typename T>
struct IsClassT {
  static constexpr bool value = std::false_type::value;
};

template<typename T>
struct IsClassT<T, std::void_t<T T::*>> { // primary template
};

template<typename T>
struct IsClassT<T, std::void_t<T T::*>> { // classes
  static constexpr bool value = true;
};
```

The C++ standard library provides the trait `std::is_class<T>` and `std::is_union<T>`, which are described in Section D.2.2 on page 705. However, these traits require special compiler support because distinguishing a class type from a union type cannot currently be done using any standard class language technique.

# 9.8.5 Determining Enumeration Types

The only types not classified by our trait are enumeration types. Testing for enumeration types can be performed directly by writing a SFINAE-based trait that checks for an explicit conversion to an integral type (say, `int`) and explicitly excluding fundamental types, class types, reference types, pointer types, and pointer-to-member types, all of which can be converted to an integral type but are not enumeration types. Instead, we simply note that any type that does not fall into any of the other categories must be an enumeration type, which we can implement as follows:

```
```cpp
trait/isenum.hpp

template<typename T>
struct IsEnumT {
  static constexpr bool value = !std::isfundamental<T>::value
                          && !IsPointer<T>::value;
};
