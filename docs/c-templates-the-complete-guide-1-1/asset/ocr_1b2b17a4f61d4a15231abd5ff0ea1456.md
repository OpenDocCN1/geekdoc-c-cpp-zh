```
condition<...> ? 21 : // ambiguous?
```

In this example, the call to construct is ambiguous between the first constructor that matches the first argument (the string literal) and the second constructor that matches the second argument (the double). We would again need an explicit cast to force the call to match the constructor that accepts the second argument, but C++ does not attempt to resolve a call to a function or constructor that has multiple possible matches.

Given this principle, we are left with specifying how well a given argument matches the corresponding parameter of a viable candidate. As a first approximation, we can rank the possible matches as follows (from best to worst):

+   1. A perfect match. The parameter has the type of the expression, or it has a type that is a reference to the type of the expression (possibly with added `const` and/or `volatile` qualifiers).
+   2. Match with minor adjustments. This includes, for example, the decay of an array variable to a pointer to its first element, or the addition of `const` to match an argument of type `int**` to a parameter of type `int const* const*`.
+   3. Match with promotion. Promotion is a kind of implicit conversion that converts a small integral type to an `int` (or larger), and the conversion of `float` to `double`, `bool` to `int`, and the conversion of a scoped enum to its underlying type.
+   4. Match with standard conversions only. This includes any sort of standard conversion (such as `int` to `double`) but does not include a conversion to another user-defined type. A conversion to `bool` from a type that has an explicit conversion to `bool` is allowed.
+   5. Match with user-defined conversions. This allows any kind of implicit conversion.
+   6. Match with ellipsis. An ellipsis parameter can match almost any type (but non-POD class types may not be allowed through an ellipsis; a constructor or conversion operator may or may not be used).

The following contrived example illustrates some of these matches:

List<double> l2;
List<Int> l3;

       // a standard conversion)

f(l3); // ok: f(List<int>) match with promotion
