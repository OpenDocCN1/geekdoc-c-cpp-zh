The following program shows how to use the `max()` function template:

Click here to view code image

```
```cpp
#include "max1.hpp"
#include <iostream>
#include <string>

int main()
{
    int i = 42;

    std::cout << max(7,i) << " " << max(7,i) << '\n';

    double f1 = 3.4; double f2 = -6.7;

    std::cout << max(f1,f2) << " " << max(f1,f2) << '\n';

    std::string s1 = "mathematics"; std::string s2 = "math";

    std::cout << max(s1,s2) << " " << max(s1,s2) << '\n';
}
```
```

Inside the program, `max()` is called three times: once for two ints, once for two doubles, and once for two `std::strings`. Each time, the maximum is computed. As a result, the program has the following output:

```
```text
max(7,i): 42
max(f1,f2): 3.4
max(s1,s2): mathematics
```
```

Note that each call of the `max()` template is qualified with `::`. This is to ensure that our `max()` template is found in the global namespace. There is a `max()` in the `std` namespace in the standard library, which has been found by argument-dependent lookup. Under some circumstances they may be called or may lead to ambiguity.

Templates are compiled into single entities that can handle any type. Instead, different entities are generated from the template for every type for which that template is used. Thus, `max()` is compiled for each of the types in our example, the first call of `max()`

```
```cpp
int i = 42;
max(7,i);
```
```

uses the function template with `int` as template parameter `T`. Thus, it has the semantics of calling the following code:

```
```cpp
int max (int a, int b)
{
    return b > a ? b : a;
}
```
```

The process of replacing template parameters by concrete types is called instantiation. It results in an instance of a template.

Notice that the same use of a function template can trigger such an instantiation process. There is no need for the programmer to request the instantiation separately.

Similarly, the other calls of `max()` instantiate the two templates for `double` and `std::string` as if they were declared and implemented individually.

Click here to view code image

```
```cpp
double max (double, double);
std::string max (std::string, std::string);
```
```
