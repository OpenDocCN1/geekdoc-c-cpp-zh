Because the template parameter of the template template parameter is not used, it is customary to omit its name (unless it provides useful documentation):

[Click here to view code image](#)

```
```cpp
template<template<typename> class Cont = std::deque>
class Stack {
    // ...
};
```
```

Member functions must be modified accordingly. Thus, you have to specify the second template parameter at the template template parameter. The same applies to the implementation of the member function. The `push()` member function, for example, is implemented as follows:

[Click here to view code image](#)

```
```cpp
template<template<typename> class Cont>
void Stack<T, Cont>::push (const T& elem)
{
    elems.push_back(elem);    // append copy of passed
}
```
```

Notice that while template template parameters are placeholders for class or alias templates, there is no corresponding placeholder for function or variable templates.

# Template Template Argument Matching

If you try to use the new version of Stack, you may get an error message saying that the default value `std::deque` is not compatible with the template parameter `Cont`. The problem is that prior to C++17 a template argument had to be a template with parameters that exactly match the parameters of the template template parameter it substitutes, with some exceptions related to variable template parameters (see Section 12.3.4 on page 107). Default template arguments of template template arguments are not considered, so that a match couldn't be achieved by leaving out arguments that have default values (in C++17, default arguments are considered).

The pre-C++17 problem in this example is that the `std::deque` of the `std::deque` library has more than one parameter. The second library has more than one parameter. The second parameter of `std::deque` allows an allocator (as a default value), but prior to C++17 this was not considered when matching `std::deque` to the `Cont` parameter.

There is a workaround, however. We can rewrite the class declaration so that the `Cont` parameter expects containers with two template parameters:

[Click here to view code image](#)

```
```cpp
template<typename T,
         template<typename, typename> class Cont = std::deque>
class Stack {
private:
    Cont<T> elems;        // elements

public:
    void push (T const&); // push element
    void pop ();          // pop element
    T const& top() const; // return top element
};
```
```

The final version of our `Stack` template (including member templates for assignments of stacks of different element types) now looks as follows:

[Click here to view code image](#)

```
```cpp
#include <deque>
#include <cassert>
#include <memory>

template<typename T,
         template<typename T, typename = std::allocator<T>>
                   class Cont = std::deque>
class Stack {
private:
    Cont<T> elems;        // elements

public:
    void push (T const&); // push element
    void pop ();          // pop element
    T const& top() const; // return top element
    // ...
};
```
