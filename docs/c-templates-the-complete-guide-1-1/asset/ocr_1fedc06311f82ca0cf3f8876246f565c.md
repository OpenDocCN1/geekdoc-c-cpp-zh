Each instance of `specificFunctionBridge` stores a copy of the function object (whose type is `Functor`), which can be invoked, copied by cloning the `specificFunctionBridge`, or destroyed (implicitly in the destructor). `specificFunction` instances are created whenever a `Function` is initialized to a new function object, completing the `FunctionPtr` example:

**Click here to view code image**

*bridge/FunctionPtr-list.hpp*

```
template<typename R, typename... Args>

template<typename R>

FunctionPtr<R(Args...)>::FunctionPtr(F f)
  : bridge(nullptr)
{
  using Functor = std::decay_t<F>;
  using Bridge = specificFunctionBridge<Functor, R, Args...>;
  bridge = new Bridge(std::forward<F>(f));
}
```

Notice that while the `FunctionPtr` constructor itself is templated on the function object type `F`, that type is known only to the particular specialization of `specificFunctionPtr<R(Args...)>` defined by the `bridge` type alias. Once the newly allocated `bridge` instance is assigned to the data member `bridge`, the extra information about the specific type is lost due to the derived-to-base conversion from `Bridge *` to `FunctionBridge<R, Args...> *`. This loss of type information explains why the `dump` type erasure is often used to describe the technique of bridging between static and dynamic polymorphism.

One peculiarity of the implementation is the use of `std::decay` (see Section 6.1 on page 73) to produce the `Functor` type, which makes the inferred type `volatile` storage, for example, by turning references to function types into function pointer types and removing top-level `const`, `volatile`, and reference types.

# 22.5 OPTIONAL BRIDGING

Our `FunctionPtr` template is rarely a drop-in replacement for a function pointer. However, it does not support one operation provided by function pointers: testing whether two `FunctionPtr` objects will invoke the same function. Adding such an operation requires updating the `FunctionPtr` class with an `equals` operation:

```
virtual bool equals(const FunctionBridge<R, Args...> const& fb)
{
  const override {
    if (typeid(*this) != typeid(SpecificFunctionBridge<Functor, R, Args...>))
      return false;
    return functor == static_cast<SpecificFunctionBridge<Functor, R, Args...>&>(fb).functor;
  }
}
```

```
friend bool
operator==(const FunctionPtr const& f1, FunctionPtr const& f2)
{
  if (f1 == f2) {
    return f1.bridge->equals(f2.bridge);
  }
}

friend bool
operator!=(const FunctionPtr const& f1, FunctionPtr const& f2)
{
  return !(f1 == f2);
}
```

This implementation is correct.
