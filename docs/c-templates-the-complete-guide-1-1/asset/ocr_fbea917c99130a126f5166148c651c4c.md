```
```cpp
private:

  // test() trying substitute call of a default constructor
  template<typename T, typename = decltype(T())>
    static std::true_type test(void*);

  // test() fallback:
  template<typename>
    static std::false_type test(...);

public:
  using Type = decltype(test<T>(nullptr));
};

template<typename T>
struct IsDefaultConstructible : IsDefaultConstructible<T>;
```
```

Now, if the first `()` function template is valid, it is the preferred overload, so that the member `IsDefaultConstructible::Type` is initialized by its return type `std::true_type`. As a consequence, `IsConstructible<T>` derives from `std::true_type`.

If the first `()` function template is not valid, it becomes disabled due to SFINAE, and `IsDefaultConstructible<T>` is initialized by the return type of the `test()` fallback, that is, `std::false_type`. The result is a `IsDefaultConstructible<T>` that derives from `std::false_type`.
