# Expression Templates

In this chapter we explore a template programming technique called expression templates. It was originally invented in support of numeric array classes, and that is also their context in which we introduce it here.

A numeric array class supports numeric operations on whole array objects. For example, it is possible to add two arrays, and the result contains elements that are the sums of the corresponding values in the argument arrays. Similarly, a whole array can be multiplied by a scalar, meaning that each element of the array is scaled. Naturally, it is desirable to keep the operator notation that is so familiar for built-in scalar types.

**Click here to view code image**

```
Array2d<double> x(10, 10);
x = 1.2*x + y*y;
```

For the serious number cruncher, it is crucial that such expressions be evaluated as efficiently as can be expected from the platform on which the code is run. Achieving this with the compact operator notation of this example is no trivial task, but expression templates will come to our rescue.

Expression templates are reminiscent of template metaprogramming, in that because expression templates rely on sometimes deeply nested template instantiations, which are not unlike the recursive instantiations encountered in template metaprograms. The fact that both techniques were originally developed to tackle problems that are encountered in our example using templates to unroll loops in Section 23.1–3 on page 533) probably also contributes to a sense that they are related. Certainly the techniques are complementary. For example, metaprogramming is convenient for small fixed-size arrays, whereas expression templates are very effective for operations on medium to large arrays sized at run time.

# 27.1 TEMPORARIES AND SPLIT LOOPS

To motivate expression templates, let's start with a straightforward (or maybe naive) approach to implement templates that enable numeric array operations. A basic array template might look as follows (Array stands for the type of array):

**Click here to view code image**

exprarray/numarr.cpp

```
#include <cstddef>

#include <cassert>


template<typename T>

class Array {

public:

  // create array with initial size

  explicit Array (std::size_t n)

    : storage(new T[n]), storage_size(n)

  { init(); }


  // copy constructor

  Array (Array<T> const& orig)

    : storage(new T[orig.size()]), storage_size(orig.size())

      copy(orig);
```
