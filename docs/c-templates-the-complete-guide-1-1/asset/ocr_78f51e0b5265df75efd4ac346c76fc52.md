```
```cpp
template<typename T>
struct IsSame<T, T> : TrueType
{
};
```
```

Now, the resulting type of `IsSame<T, T>` is implicitly convertible to its base class `TrueType`, which not only provides the corresponding `value` member but also allows us to dispatch to a different function implementations or partial class template specializations at compile time. For example:

`traits/2.3/isame.cpp`

```
```cpp
#include <iostream>
#include <ostream>

template<typename T>
void fooImpl(T, TrueType)
{
    std::cout << "fooImpl,true) for int called\n";
}

template<typename T>
void fooImpl(T, FalseType)
{
    std::cout << "fooImpl,false) for other type called\n";
}

template<typename T>
void foo(T t)
{
    fooImpl(t, IsSame<T,int>{});  // choose impl, depending on type
}

int main()
{
    foo(42);  // calls fooImpl(42, TrueType)
    foo(7);   // calls fooImpl(42, FalseType)
}
```
```

This technique is called tag dispatching and is introduced in Section 20.2.3 on page 467.

Note that our `IsSame` implementation includes a `Type` member, which allows us to reintroduce an alias template for `IsSame<T>`.

```
```cpp
template<typename T>
using IsSameT = typename IsSame<T>::Type;
```
```

That alias template can coexist with the variable template `IsSame`.

In general, traits yielding Boolean values should support tag dispatching by deriving from types such as `TrueType` and `FalseType`. However, to be as generic as possible, there should be only one type representing `true` and one type representing `false` in Boolean traits of any kind (and should therefore be defining its own types for Boolean constants).

Fortunately, the C++ standard library provides corresponding types in `<type_traits>` since C++11: `std::true_type` and `std::false_type`. In C++11 and C++14, they are defined as follows:

```
```cpp
namespace std {
    using true_type = integral_constant<bool, true>;
    using false_type = integral_constant<bool, false>;
```
