A full specialization is a replacement for the instantiation of a certain generic template, and it is not valid to have both the explicit and the generated versions of a template present in the same program. An attempt to use both in the same file is usually caught by a compiler:

Click here to view code image

```
```cpp
template<typename T>
class Invalid {
};

Invalid<void> x1;       // causes the instantiation of
Invalid<void>

template<>
class Invalid<void> {  // ERROR: Invalid<void> already
                        // instantiated
};
```
```

Unfortunately, if this occurs in different translation units, this problem may not be caught by a compiler. The following invalid C++ example contains two files which use templates and invokes many implementations, but it is invalid and dangerous:

Click here to view code image

```
```cpp
// Translation unit 1:
template<typename T>
class Danger {
public:
    enum {
        max = 100
    };
};

char buffer[Danger<void>::max]; // use generic value

extern void clear(char*);

int main()
{
    clear(buffer);
}

// Translation unit 2:
template<typename T>
class Danger {
};

template<>
class Danger<void> {
public:
    enum { max = 100 };
};

void clear(char* buf)
{
    // mismatch in array bounds?
    for (int i = 0; i < Danger<void>::max; ++i) {
        buf[i] = 0;
    }
}
```
```

This example is clearly destined to keep its shirt, but it illustrates that care must be taken to ensure that the declaration of the specialization is visible to all the users of the generic template. In practical terms, this means that a declaration of the specialization should follow the declaration of the template in its header file. When the generic implementation comes from an external source, such that the corresponding header files should not be modified, this is not necessarily practical, but it may be worth creating a header including the generic template followed by declarations of the specializations to avoid these hard-to-find errors. We find that, in general, it is better to avoid specializing templates coming from an external source unless it is clearly marked as being designed for that purpose.
