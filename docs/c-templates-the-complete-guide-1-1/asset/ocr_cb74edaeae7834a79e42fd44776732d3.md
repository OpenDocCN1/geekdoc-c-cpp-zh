The variadic proposal came late in the C++ standardization process and practically overwrote all the text regarding the standard. It was rejected as a result, and instead, a few tokens were added to the existing text to allow implementations based on expansion templates. However, the exploitation of this allowance remains much more cumbersome than what was discussed here. At the time of this writing, no such implementation is known, and standard arrays are, generally speaking, quite inefficient at performing the operations for which they were designed.

Finally, it is worth observing here that many of the pioneering techniques presented in this chapter, as well as what later became known as the STL, were all originally implemented on the same compiler: version 4.4 of the Borland C++ compiler. This was perhaps the first compiler that made complete programming broadly popular in the C++ programming community.

Expression templates were first applied primarily for operations on array-like types. However, after a few years, new applications were found. Among the most ground-breaking were Jaakko Järvi's and Gary Powell's Boost.Lambda library (Lambda?), which provided a usable lambda expression facility years before lambda expressions became a core language feature — and Eric Niebler's Boost.Proto library, which is a library to meta-program expression templates, with the goal of creating extended domain-specific languages (DSLs). Other Boost libraries, like Boost.Fusion and Boost.Hana, also make advanced use of expression templates.
