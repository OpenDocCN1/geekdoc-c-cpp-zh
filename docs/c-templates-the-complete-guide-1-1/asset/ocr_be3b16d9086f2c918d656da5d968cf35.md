auto template parameters are also useful to parameterize template parameters of a class. For example:

Click here to view code image

```
```
template<typename T, typename M = std::pair<T,T>>
class MyClass {
public:
    using Pair = M;
    MyClass(Pair& p) : p(p) {}
    MyClass(MyClass const&) = default;
    MyClass(MyClass&&) = default;
    MyClass& operator=(MyClass const&) = default;
    MyClass& operator=(MyClass&&) = default;
    ~MyClass() = default;
    void swap(MyClass& other) noexcept {
        std::swap(p, other.p);
    }
private:
    Pair p;
};
void swap(MyClass& a, MyClass& b) noexcept {
    a.swap(b);
}
```
```

Here we used a helper class template `MyClass` to retrieve from a pointer to member type `Ptr` a class type, using class template partial specialization. (described in Section 16.4 on page 347). With an `auto` template parameter, you don't have to specify the type of the class template. The compiler will deduce it for you. For example:

template<typename T>
struct MyClass<T, std::pair<T,T>> {
    using Type = T;
};
