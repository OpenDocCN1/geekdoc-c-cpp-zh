void printTupleElements(Tuple<Types...> const& t) {

        std::cout << t.getHead(),

# ## 25.3 TUPLE ALGORITHMS

A tuple is a container that provides the ability to access and modify each of its elements (through get()) as well as to create new tuples (directly or by concatenating, splitting, or applying some transformation to one or more existing tuples).
