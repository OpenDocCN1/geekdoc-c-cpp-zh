# 2.1.2 Implementation of Member Functions

To define a member function of a class template, you have to specify that it is a template, and you have to use the full type qualification of the class template. Thus, the implementation of the member function push_back() of Stack<T> looks like this:

Click here to view code image

```
template<typename T>
void Stack<T>::push_back (T const& elem)
{
    elems.push_back(elem);        // append copy of passed elem
}
```

In this case, push_back() of the element vector is called, which appends the element at the end of the vector.

Note that pop_back() of a vector removes the last element but doesn't return it. The reason for this behavior is exception safety. It is impossible to implement a pop_back() function with semantics of "pop() that returns the removed element (this topic was first discussed by Tom Cargill in [Cargill91] and is discussed in [Josuttis99] and [Alexandrescu01]). However, removing this from a pop() that returns the just removed element. To do this, we simply use T to declare a local variable of the element type:

Click here to view code image

```
template<typename T>
T Stack<T>::pop()
{
    assert(!elems.empty());     // error if stack is empty
    T elem = elems.back();       // save copy of last elem
    elems.pop_back();            // remove last element
    return elem;                 // return copy of saved
}
```

Because back() (which returns the last element) and pop_back() (which removes the last element) have undefined behavior when there is no element in the vector, we should check whether the stack is empty. If it is empty, we assert because it is a huge error to call pop() on an empty stack. This is also done in top(), which returns a reference to the top element:

Click here to view code image

```
template<typename T>
class Stack {
public:
    void push (T const& elem)        // append copy of
                                     // passed elem
    {
        elems.push_back(elem);
    }
};
```

Of course, as for any member function, you can also implement member functions of class templates as an inline function inside the class declaration. For example:

```
template<typename T>
class Stack {
public:
    void push (T const& elem)        // append copy of
                                     // passed elem
    {
        elems.push_back(elem);
    }
};
```
