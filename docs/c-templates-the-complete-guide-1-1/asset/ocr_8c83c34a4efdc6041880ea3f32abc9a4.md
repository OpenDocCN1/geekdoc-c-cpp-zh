# Nontype Template Parameters

For function and class templates, template parameters don't have to be types. They can also be ordinary values. As with type parameters using type parameters, you define code for which a certain detail remains open until the code is used. However, the detail that is open is a value instead of a type. When using such a template, you have to specify this value explicitly. Thus changing code then instantiated. This chapter illustrates this feature. In addition, we show an example of non-type function template parameters and discuss some restrictions to this technique.

# 3.1 NONTYPE CLASS TEMPLATE PARAMETERS

In contrast to the example implementations of a stack in previous chapters, you can also implement a stack by using a fixed-size array for the elements. An advantage of this method is that the memory management is removed, whether performed by you or by a standard container, is avoided. However, determining the best size for such a stack is not challenging. The smaller the size you specify, the more likely it is that you will get full. The larger the size you specify, the more likely it is that memory will be squandered. Implementing such a fixed-size stack is a good solution if the size of the stack specifies the size of the array as the maximum size needed for stack elements.

To do this, define the size as a template parameter:

#include <array>
#include <cassert>

template<typename T, std::size_t Maxsize>
class Stack {
  private:
    std::array<T, Maxsize> elems; // elements
    std::size_t numElems;         // current number of
                                  // elements

  public:
    Stack()                    // constructor
      : numElems(0) { }

    void push(T const& elem)   // push element
    {
      assert(numElems < Maxsize);
      elems[numElems] = elem;
      ++numElems;
    }

    void pop()                 // pop element
    {
      assert(!empty());        // ensure whether the
      --numElems;
    }

    T const& top() const       // return top element
    {
      assert(!empty());        // ensure whether the
      return elems[numElems - 1];
    }

    std::size_t size() const   // return current num
    {
      return numElems;
    }
};

template<typename T, std::size_t Maxsize>
Stack<T, Maxsize>::Stack() : numElems(0)
