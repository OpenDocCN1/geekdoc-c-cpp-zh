```
# Copy/Move Initialization

Copy and move initialization are more interesting. To copy a source variant, we need to determine which type it is currently storing, copy-construct that value into the buffer, and test that discriminator. Fortunately, visit() handles decoding the active value of the source variant, and the copy-assignment operator inherited from Variant<int, double> will copy-construct a value into the buffer, leading to a compact implementation:

Click here to view code image

variant/variantcopyctor.hpp

```
```cpp
template<typename... Types>

Variant<Types...>::Variant(Variant const& source) {

    if (!source.empty()) {

        source.visit([&](auto const& value) {
            this->value = value;
        });
    }
}
```
```

The move constructor is similar, differing only in its use of std::move when visiting the source variant and move-assigning from the source value:

variant/variantmovector.hpp

```
```cpp
template<typename... Types>

Variant<Types...>::Variant(Variant&& source) {

    if (!source.empty()) {

        std::move(source).visit([&](auto&& value) {
            this->value = std::move(value);
        });
    }
}
```
