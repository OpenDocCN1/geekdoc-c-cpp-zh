# 26.2 DESIGN

Now that we have a solution to the storage problem for variants, we design the Variant type itself. As with the Tuple type, we use inheritance to provide behavior for each type in the list of Types. Unlike with Tuple, however, these classes do not have storage. Rather, each of the base classes uses the Union to provide the actual storage.
