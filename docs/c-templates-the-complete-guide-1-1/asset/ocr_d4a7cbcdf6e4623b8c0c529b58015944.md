# 5.12.1 Deduction Guides

Consider first a small change to our earlier example from Section 15.8.2 on page 288:

**Click here to view code image**

```
```cpp
template<typename T>
class S {
private:
  T a;
public:
  S(T b = a) { }
};

template<typename T> S(T) -> S<T>; // deduction guide

S x(12);       // S<int>
S y(12);       // S<int>
S z(12);       // or, since C++17, same as S<int>
S w = S(12);   // or, since C++17, same as S<int>
S<int> z{12};
```
```

Notice in particular the addition of a new template-like line constructed called a *deduction guide*. It looks a little like a function template, but it differs syntactically from a function template in a few ways:

+   - The part that looks like a trailing return type cannot be written as a traditional return type. We call the type it designates (`S<T>` in our example) as the guided type.
+   - There is no leading `auto` keyword to indicate that a trailing return type follows.
+   - The “name” of a deduction guide must be the unqualified name of a class template declared earlier in the same scope.
+   - The guided type of the guide must be a template-id whose template name corresponds to the guide name.
+   - It can be declared with the `explicit` specifier.

In the declaration `S x(12);`, the specifier `S` is called a *placeholder class type*. When such a placeholder is used, the name of the variable being declared must follow immediately and that in turn must be followed by an initializer. The following is therefore invalid:

**Click here to view code image**

```
```cpp
S* p = ...; // ERROR: syntax not permitted
```
```

With the guide as written in the example, the declaration `S x(12);` deduces the type of the variable by treating the deduction guides associated with class `S` as an overload set and attempting overload resolution with the initializer arguments. At this point, note that the only one guide in it, and is successfully deduces `T` to `int` and the guide's guided type to be `S<int>`. That guided type is therefore selected as the type of the variable `x`.
