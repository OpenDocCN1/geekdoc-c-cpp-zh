# 13.2 LOOKING UP NAMES

There are many details in looking up names in C++, but we will focus on only a few major concepts. The details are necessary to ensure that only the names that are actually intended are found; that is, name lookup doesn't confuse names from unrelated scopes.

Qualified names are looked up in the scope implied by the qualifying construct. If that scope is a class, then classes and their base classes are also searched. However, before qualified lookup, unqualified lookup is performed on the name following the `::`. The following illustrates this principle:

```
int x;
class B {
public:
    int i;
};

int B::* p; // OK
void f(int* p)
{
    p->i = 1; // Error: B::i
    x = 2; // Error: x does not find B::i in the
           // enclosing scope
}
```

In contrast, unqualified names are typically looked up in successively nested enclosing scopes (though the member function definitions, the scope of the class and its base classes are searched before any other enclosing scopes).
