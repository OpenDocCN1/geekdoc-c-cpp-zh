# 8.1 Introduction

In previous chapters, we assumed that all observations are independent—that is, the outcome for each observation is completely unrelated to the outcome for every other observation. While that assumption is quite appropriate for most data sets, there are many applications where the data can be grouped into natural or imposed clusters with observations in the same cluster tending to be more alike than observations in different clusters.
