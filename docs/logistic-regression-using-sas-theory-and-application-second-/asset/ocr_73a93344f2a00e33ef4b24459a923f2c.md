Discrete choice analysis is usually based on the *conditional logit model*, a name that—unfortunately—has also been used for quite different models. This model is very easily estimated using the STRATA statement in PROC LOGISTIC. But I’ll also show how to estimate more general models using PROC PHREG and PROC MDC.
