Neither the deviance nor the Pearson chi-square will have true chi-square distributions. To remedy this deficiency, Hosmer and Lemeshow (2000) proposed a test that has rapidly gained widespread use. It may be implemented in LOGISTIC with the LACKFIT option in the MODEL statement. Let’s apply it to the model we’ve just been evaluating.

```
PROC LOGISTIC DATA=penalty;
    MODEL death(EVENT='1') = blackd whitvic culp / LACKFIT;
RUN;
```

The resulting p-value of .82, shown in Output 3.14, suggests that the model fits very well.
