Now we’re ready for PROC LOGISTIC:

```
PROC LOGISTIC DATA=wisc;
    CLASS iq ses / PARAM=REF;
    MODEL coll/total=iq ses parent / SCALE=NONE;
RUN;
```

IQ and SES are listed as CLASS variables so that they will be treated as categorical rather than quantitative variables. As explained in Chapter 2, the PARAM=REF option overrides the default method for coding CLASS variables. Specifically, the REF option tells LOGISTIC to create a set of dummy (indicator) variables, with the reference category being the highest value of the CLASS variable.
