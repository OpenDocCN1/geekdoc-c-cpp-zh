At this point we take the logarithm of both sides of the equation to get

```
$$\log L = \sum_{i} y_i \log\left(\frac{p_i}{1-p_i}\right) + \sum_{i} \log(1-p_i). \tag{3.4}$$
```

It is generally easier to work with the logarithm of the likelihood function because products get converted into sums and exponents become coefficients. Because the logarithm is an increasing function, whatever maximizes the logarithm of a function will also maximize the original function.

Substituting our expression for the logit model (equation 3.1) into equation (3.4), we get

```
$$\log L = \sum_{i} \mathbf{\beta x}_i y_i - \sum_{i} \log(1 + e^{\mathbf{\beta x}_i}) , \tag{3.5}$$
```

which is about as far as we can go in simplifying the likelihood function.

This brings us to step 2, choosing values of $\mathbf{\beta}$ that make the log-likelihood in equation (3.5) as large as possible. There are many different methods for maximizing functions like this. One well-known approach is to find the derivative of the function with respect to $\mathbf{\beta}$, set the derivative equal to 0, and then solve for $\mathbf{\beta}$. Taking the derivative of equation (3.5) and setting it equal to 0 gives us:

```
$$\frac{\partial \log L}{\partial \mathbf{\beta}} = \sum_{i} \mathbf{x}_i y_i - \sum_{i} \mathbf{x}_i (1 + e^{-\mathbf{\beta x}_i})^{-1}
= \sum_{i} \mathbf{x}_i y_i - \sum_{i} \mathbf{x}_i \hat{y}_i = 0 \tag{3.6}$$
```

where

```
$$\hat{y}_i = \frac{1}{1 + e^{-\mathbf{\beta x}_i}},$$
```

the predicted probability of $y$ for a given value of $\mathbf{x}_i$. Because $\mathbf{x}_i$ is a vector, equation (3.6) is actually a system of $k+1$ equations, one for each element of $\mathbf{\beta}$.

Those familiar with OLS theory may recognize the second line of equation (3.6) as identical to the *normal equations* for the linear model. The difference is that $\hat{y}$ is a linear function of $\mathbf{\beta}$ in the linear model but a nonlinear function of $\mathbf{\beta}$ in the logit model.
