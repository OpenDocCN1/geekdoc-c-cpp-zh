# Adding a menu

In addition to the pop-up button, giving a user menu access to the different mathematical computations would be handy. It's a cinch to add keyboard shortcuts to menus, which in turn can give your users keyboard access to the mathematical choices in the pop-up button. To create a new menu item, follow these steps:

+   1. Open the Menu editor for MainActivity from the project window.
2. Drag a menu item from the Library window and drop it onto the new menu bar.
3. Rename the new menu Calculate and press Return to accept the new name.
4. Drag a menu item from the Library window to the new Calculate menu item.
5. Select the last of the three menu items, Item 3, and press Ctrl+D to duplicate the item and add it to the menu.
6. Select the first menu item, Item 1, and press Ctrl+I to open the inspector window.
7. Alter the attributes of the menu item to match Figure 4-18. Change the Title attribute to Add, click the Key Equiv. field, and press + on your keyboard to assign the shortcut for that menu item.

A new menu appears with three items by default.
