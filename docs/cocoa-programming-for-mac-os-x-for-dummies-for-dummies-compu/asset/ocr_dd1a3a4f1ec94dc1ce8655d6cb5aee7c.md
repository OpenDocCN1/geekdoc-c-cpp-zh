You can view and navigate the documentation with Xcode in much the same way as you would a Web browser. Figure 1-4 shows what the screen looks like when documentation is loaded into Xcode.

When you complete your Cocoa project, you use Xcode to compile, link, and build a final application. You can then distribute the application to friends, co-workers, and even the world (as long as they use Mac OS X).

Xcode wears many hats. If you're accustomed to other environments, you might be surprised to discover that Xcode performs tasks that require multiple tools in other environments. For example, Xcode functions as a

+   - Project organizer, managing files and resources in your Cocoa projects

+   - Code editor, allowing you to write and edit Xcode code

+   - Browser, displaying built-in documentation or other kinds of resources in your Cocoa projects

+   - Compiler and linker, spitting out a complete Cocoa application at the end of the development process
