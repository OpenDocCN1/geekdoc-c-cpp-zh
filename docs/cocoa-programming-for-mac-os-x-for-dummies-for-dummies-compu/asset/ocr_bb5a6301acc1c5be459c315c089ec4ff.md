7. With the disk image in the foreground and eject the volume by pressing Cmd+E.

8. Return to Disk Utility and open the disk image via File:Open Disk Image.

Disk Utility opens and mounts the image, as shown in Figure 5-18.

9. Choose Images:Convert to convert the disk image to a compressed format. Name the new disk image and select Compressed from the Image Format drop-down, as shown in Figure 5-19.

10. Click Save to create the new disk image. When Disk Utility is finished, you can upload the resulting disk image to a Web server or send it to others via e-mail.
