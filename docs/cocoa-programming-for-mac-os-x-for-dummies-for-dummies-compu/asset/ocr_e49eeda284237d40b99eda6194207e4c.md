# Class models

Class models are your next stop on the Xcode tool (see Chapter 2 for more classes). Xcode can provide you with a visual representation of the classes in your project. This can be helpful for design and debugging purposes. To view a class model, select the desired class and choose Design->Quick Model. Xcode displays a graphical model of your class.

The calculator has only one class: the Fusebox class and choose Design->Quick Model to view the Fusebox model. In this class, you implemented one function (calculateAnswer) and three outlets for the three text fields, as shown in Figure 3-6. NSObject also appears in the Quick Model because it is the superclass of the Fusebox class. All classes, except NSObject, are based on some other class in a class hierarchy. The Fusebox class is based on the NSObject class, so NSObject is to be its superclass.

As your project grows, the class models help you with the big picture. The graphs show how they interact in the project interconnect.
