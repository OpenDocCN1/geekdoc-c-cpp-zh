# Making connections

Now you've created a Fusebox class and added three outlets and an, it's time to make connections between Fusebox and your interface.

You've just created a new Fusebox object based on the Fusebox class. You'll make connections between this instance and your interface with the outlets and action you added earlier. For starters, connect the three outlets to the three corresponding text fields in the interface. To get you started, here's how to connect the numberField1 outlet to the interface:

+   1. Select the Fusebox instance in MainMenu.x.
2. Control+drag from the Fusebox instance to the leftmost text field in the interface.
