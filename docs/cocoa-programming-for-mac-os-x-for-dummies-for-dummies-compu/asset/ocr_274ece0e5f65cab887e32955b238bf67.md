# Chapter 6: The Basics of Objective-C

- (void)doSomething;
- (void)doSomethingElse:(NSString *)aString;
@end

The method name is followed by a colon and then the parameter's data type in parentheses. The parameter's name appears in the declaration, which is slightly different than what you might be accustomed to C function declarations, but so far it's not too strange.

When you begin adding additional parameters to a method, however, things start looking really weird to a C programmer. Besides having a name, every parameter after the first one also has a label. In the following example, drawString has two parameters: aString and an int. The second parameter has atThisXPosition.

```
@interface MyClass : NSObject {
UIButton *aButton;
int age;
float percent;
BOOL collapsed;
}
- (void)doSomething;
- (void)doSomethingElse:(NSString *)aString;
- (void)drawString:(NSString *)aString
atThisXPosition:(int)xPos;
@end
```

This can look very peculiar to C developers, but you'll quickly adjust to it. In you find that you prefer it because each parameter is documented in the declaration itself. As you add additional parameters, simply append a label, colon, a data type in parentheses, and the parameter name. For example, here is the drawString method with three parameters instead of:

```
@interface MyClass : NSObject {
UIButton *aButton;
int age;
float percent;
BOOL collapsed;
}
- (void)doSomething;
- (void)doSomethingElse:(NSString *)aString;
- (void)drawString:(NSString *)aString
atThisXPosition:(int)xPos atThisYPosition:(int)yPos;
@end
```
