# Menu editor window

The last window to discuss is the Menu editor. The Menu editor window displays a miniature version of your application's menu bar. You can click a menu to display its menu items. It's easy to change the text or keyboard shortcut for a menu item or to add a new menu item altogether.

To prepare the menu for your application, follow these steps:

+   1. In the XIB project window, double-click the MainMenu icon.
   The Menu editor appears.

+   2. Open the New Application menu.

+   3. Double-click the About MyFirstProject menu item and rename it.
   For example, rename it to AboutSimpleCalculator.
   You can also rename the About (or any other menu, for that matter) by single-clicking it and making the change in the Info window.

+   4. Change the Hide NewApplication and Quit NewApplication menus.
   For example, change them to HideSimpleCalculator and Quit SimpleCalculator, respectively. Figure 4-12 shows all three menus; About, Hide, and Quit changed in the Menu editor.
