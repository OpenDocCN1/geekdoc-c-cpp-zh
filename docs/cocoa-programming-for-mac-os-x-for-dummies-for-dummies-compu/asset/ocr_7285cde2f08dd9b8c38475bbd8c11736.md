# Creating a Controller class

When you have the interface in place, you need to create a Controller class. Perform the following steps:

+   1. Drag an NSobject from the Library window to the XIB project window to add a new controller. 
2. Press ⌘+6 to open the Identity Inspector and change the class name to File Info Controller, as shown in Figure 13-4.
