# Getting started with your Cocoa project

Now that you have an idea in mind, you can begin the Cocoa development process:

+   1. Launch Xcode by double-clicking its icon.
The icon is on your hard drive at the following location:
/Developer/Applications/Xcode
When you launch Xcode, a happy window may be welcoming you to Xcode, as in Figure 2-2. This window also offers convenient one-click access to documentation and tutorials for you. If it opens, close the Welcome to Xcode window to reduce clutter. It opens again the next time you launch Xcode, unless you deselect the Show at Launch check box.
2. Choose File::New Project.
The New Project window appears, asking what kind of project you want to create, as shown in Figure 2-3.
