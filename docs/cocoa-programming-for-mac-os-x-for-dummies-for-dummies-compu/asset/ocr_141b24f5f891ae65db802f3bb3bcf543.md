# # Working with Boolean Data Types

A Boolean data type represents information that can occur in two, and only two, states. For example, an On/Off switch acts in a Boolean fashion because you have only two options. A Yes/No question works similarly. Objective-C has its own Boolean data type: **BOOL**. Instead of the usual **TRUE** and **FALSE** values, Objective-C uses **YES** and **NO**.
