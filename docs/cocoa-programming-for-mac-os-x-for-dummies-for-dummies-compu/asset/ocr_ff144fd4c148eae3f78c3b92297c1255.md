# Chapter 4: Interface Builder

Incidently, the XIB file extension in MainMenu.xib indicates that it is a newer Interface Builder project file format, introduced in Xcode 3. Previously, the file had a NIB extension, which is short for Next Interface Builder. Why NeXT? NeXT is the name of the company Steve Jobs headed before his return to Apple. Apple produced the Next operating system, which became the core of Mac OS X. The XIB file is a carryover from those days. Cocoa geeks still use these NIB files—old habits die besides. Have you ever tried to pronounce "NeXT”? Furthermore, the AS that appears at the beginning of class names in Cocoa stands for NextStep, another historical tidbit in Cocoa left over from NeXT.

When you first launch Interface Builder, you may see as many as five windows. Figure 4-2 shows the various windows as they appear in Interface Builder. Although it is not one of the five main windows, the Strings window might make an appearance, too. The Strings window is less likely to be present than the others but if you use it, feel free to choose it. You dont use it in this chapter.
