Figure 5-9 Add the Copyright (Human-Readable) key to info.plist to display the copyright at the bottom of the About Panel.

You can display all sorts of interesting and useful credits in a scrolling text field in the mode of the About Panel. All you have to do is add a Credits file to your Resource folder. The Credits file can be either a rich file (.rtf or .rtfd) or an HTML (HyperText Markup Language) file. Both can display stylized text and images HTML can display clickable links, which can be useful for adding your company's URL or an email address for support. Be forewarned, HTML files don't contain images; instead they reference separate image files. So, if you want to plan using HTML, use just the HTML to display graphics.
