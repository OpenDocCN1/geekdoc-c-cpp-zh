    if ([[applyCheckbox state]) {

        range:[textView selectedRange]];
    }

    }

Setting the background and text colors is as easy as using the set-BackgroundColor and setTextColor methods of the NSTextView view. If the state of applyCheckbox is YES, the setTextColor method sets the color of the text of the currently selected text, passing the range as one of its parameters. This allows you to choose which portion of the text you want to colorize.
