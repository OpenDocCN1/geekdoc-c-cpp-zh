# Displaying a version number, a copyright date, and credits

Besides using a title to identify your application, it's also a good idea to provide a version number, a copyright, and credits in the About Panel:

+   The version number helps users know at a quick glance what version of the application they are using, in case they want to know when it comes to download a new version of the application.
