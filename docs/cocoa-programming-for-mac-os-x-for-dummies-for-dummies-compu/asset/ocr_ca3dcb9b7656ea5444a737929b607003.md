# # Manual editing

Sometimes you may want to alter the text in an `NSTextView` without using the Pasteboard. Perhaps the most common editing task that you'll want to perform is to change the text that appears in an `NSTextView`. You can accomplish this task by using the `setString` method of the `NSSring` class. Create an `NSSring` and assign a string to it:

```
```objective-c
NSSring* someString = @"Cocoa says Hello!";
```
```

![](bbox=[0.11, 0.66, 0.19, 0.74])

Note the @ character preceding the string. The @ character is an Objective-C operator that tells the compiler to allocate a constant `NSSring` object with the stated value.

After you have an `NSSring`, it's a simple matter to display it in an `NSTextView`:

```
```objective-c
[extView setString:someString];
```
```
