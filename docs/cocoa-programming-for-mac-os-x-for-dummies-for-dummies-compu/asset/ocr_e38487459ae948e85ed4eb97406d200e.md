Because sliders represent a range of values, they have minimum and maximum values. They also have a current value, which represents the position of the slider button in the range of minimum and maximum values. You can set these values in the Inspector window.

If you want to find out what the current value of the slider is in code, do something like this:

```
```float x = [theSlider floatValue];```
```

You can also set the current position of the slider by using the setFloatValue method:

```
```[theSlider setFloatValue:3.14];```
```

You aren’t restricted to the setFloatValue method, however. Because NSSlider inherits from NSControl, among other classes, you can use the methods of NSControl to work with the slider. The setFloatValue method is just one method of NSControl. There are others, which you can view in the built-in documentation. For example, if you don’t care about slider values that contain decimal points, you can use the setValue method of the NSControl:

```
```[theSlider setIntValue:5];```
```
