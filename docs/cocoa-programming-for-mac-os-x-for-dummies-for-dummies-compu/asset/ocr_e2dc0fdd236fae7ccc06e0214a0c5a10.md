# Where to go for Help

At some point, you'll want more information about how Xcode operates. Frankly, Apple has covered you with its built-in documentation. Choose Help>Xcode Workspace Guide to view the built-in documentation about Xcode.

The built-in Help offers documentation on each aspect of Mac OS X development. It also includes a helpful tutorials for getting started with programming Cocoa in Xcode.
