**4. Find out what the user did with the OpenPanel.**

To find out whether the user clicked OK or Cancel in the OpenPanel, you must examine the value that `runModal` returns. If the user clicked OK, the return value is `NSOKButton`, a constant that Cocoa provides for you. If the user cancels the open operation instead, the return value is `NSCancelButton`.

```
```objc
NSInteger i = [openPanel runModal];
if (i == NSOKButton)
{
    NSLog(@"The user clicked OK!");
}
```
```

Rather than create a new variable just to check the return value, wrapping the `runModal` command into the `if` statement is easier:

```
```objc
if ([openPanel runModal] == NSOKButton)
{
    NSLog(@"The user clicked OK!");
}
```
