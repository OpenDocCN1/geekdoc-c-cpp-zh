```
You can also use a combination of fill and stroke for different effects. When you do, make sure to perform the stroke functions after the fill function so that the outline draws on top of the filled path. For example, suppose you wanted to draw a black ring around one of the traffic lights. Your code might look like this:

```
```OBJECTIVE-C
//stroke oval in black
theColor = [NSColor blackColor];
[theColor set];
[thePath stroke];
```

```OBJECTIVE-C
[thePath setLineWidth: 5];
```
