# Program Notes

First, note how each function in Listing 8.4 is called:

```
swap(wallet1, wallet2);       // pass variables
swap(&wallet1, &wallet2);     // pass addresses of variables
swap(wallet1, wallet2);       // pass values of variables
```

Passing by reference (swap(wallet1, wallet2)) and passing by value (swap(wallet1, wallet2)) look identical. The only way you can tell that swap() passes by reference is by looking at the prototype or the function definition. However, the presence of the address operator (&) makes it obvious when a function passes by address ((swap(&wallet1, &wallet2)). (Recall that the type declaration int *p means that p is a pointer to an int and therefore the argument corresponding to p should be an address, such as &wallet1.)

Next, compare the code for the functions swap() (passing by reference) and swap() (passing by value). The only outward difference between the two is how the function parameters are declared:

```
void swap(int & a, int & b)
void swap(int & a, int b)
```

The internal difference, of course, is that in swap() the variables a and b serve as aliases for wallet1 and wallet2, so swapping a and b swaps wallet1 and wallet2. But in swap(), the variables a and b are new variables that copy the values of wallet1 and wallet2, so swapping a and b has no effect on wallet1 and wallet2.

Finally, compare the functions swap() (passing a reference) and swap() (passing a pointer). The first difference is in how the function parameters are declared:

```
void swap(int & a, int & b)
void swap(int * p, int * q)
```

The second difference is that the pointer version requires using the * dereferencing operator throughout when the function uses p and q.
