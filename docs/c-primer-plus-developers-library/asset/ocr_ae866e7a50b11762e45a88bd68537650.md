# **Table G.13 Nonmodifying Sequence Operations**

| Function | Description |
|---|---|
| `mismatch()` | Finds the first element in one range that does not match the corresponding element in a second range and returns iterators to both. Matching may be by equality or may be evaluated with a binary predicate. |
| `equal()` | Returns `true` if each element in one range matches the corresponding element in a second range. Matching may be by equality or may be evaluated with a binary predicate. |
| `is_permutation()` | Returns `true` if each element in one range matches the corresponding element in some permutation of a second range. Matching may be by equality or may be evaluated with a binary predicate. (C++11) |
| `search()` | Finds the first occurrence of a subsequence whose values match the values of a second sequence. Matching may be by equality or by applying a binary predicate. |
| `search_n()` | Finds the first subsequence of `n` elements that each match a given value. Matching may be by equality or by applying a binary predicate. |

# **all_of() (C++11)**

```
```cpp
template<class InputIterator, class Predicate>
bool all_of(InputIterator first, InputIterator last,
            Predicate pred);
```
```

The `all_of()` function returns `true` if `pred(*i)` is `true` for every iterator in the range `[first,last)` or if the range is empty. Otherwise the function returns `false`.

# **any_of() (C++11)**

```
```cpp
template<class InputIterator, class Predicate>
bool any_of(InputIterator first, InputIterator last,
            Predicate pred);
```
```

The `any_of()` function returns `false` if `pred(*i)` is `false` for every iterator in the range `[first,last)` or if the range is empty. Otherwise the function returns `true`.

# **none_of() (C++11)**

```
```cpp
template<class InputIterator, class Predicate>
bool none_of(InputIterator first, InputIterator last,
             Predicate pred);
```
```

The `none_of()` function returns `true` if `pred(*i)` is `false` for every iterator in the range `[first,last)` or if the range is empty. Otherwise the function returns `false`.
