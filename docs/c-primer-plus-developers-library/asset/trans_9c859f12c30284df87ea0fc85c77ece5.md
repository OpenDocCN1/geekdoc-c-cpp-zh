### 作者简介

**斯蒂芬·普拉塔**曾在加利福尼亚州肯特菲尔德的马林学院教授天文学、物理学和计算机科学。他在加州理工学院获得理学学士学位，在加州大学伯克利分校获得博士学位。他撰写或合著了十余本编程主题书籍，包括*New C Primer Plus*，该书获得计算机出版社协会1990年最佳计算机操作指南图书奖；以及*C++ Primer Plus*，该书于1991年获得计算机出版社协会最佳计算机操作指南图书奖提名。
