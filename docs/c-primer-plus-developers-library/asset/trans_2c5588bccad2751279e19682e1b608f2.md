
当进入包含它的块（通常是函数定义）时，它开始存在；当离开该块时，它失效。静态变量在程序的整个运行期间持续存在。由 C++98 标准加入的标准模板库（STL）提供了一个 vector 模板类，为自行实现的动态数组提供了一种替代方案。C++11 提供了一个 array 模板类，为固定大小的内置数组提供了一种替代方案。
