# **Table G.12 Additional Operations Defined for Unordered Sets, Multisets, Maps, and Multimaps**

| Operation | Description |
|---|---|
| `X(i,j,n,hf,eq)` | Constructs an empty container with at least `n` buckets, using `hf` as the hash function and `eq` as the key equality predicate, and inserts the elements from `[i,j)`. If `eq` is omitted, `key_equal()` is used as the key equality predicate. If `hf` also is omitted, `hasher()` is used as the hash function. If `n` also is omitted, an unspecified number of buckets is used. |
| `X a(i,j,n,hf,eq)` | Constructs an empty container `a` with at least `n` buckets, using `hf` as the hash function and `eq` as the key equality predicate and inserts the elements from `[i,j)`. If `eq` is omitted, `key_equal()` is used as the key equality predicate. If `hf` also is omitted, `hasher()` is used as the hash function. If `n` also is omitted, an unspecified number of buckets is used. |
| `b.hash_function()` | Returns the hash function used by `b`. |
| `b.key_eq()` | Returns the key equality predicate used in constructing `b`. |
| `b.bucket_count()` | Returns the number of buckets in `b`. |
| `b.max_bucket_count()` | Returns an upper bound for the number of buckets `b` might contain. |
| `b.bucket(k)` | Returns the index of the bucket that would contain an item with a key equivalent to `k`. |
| `b.bucket_size(n)` | Returns the number of elements in the bucket having index `n`. |
| `b.begin(n)` | Returns an iterator to the first element of the bucket having index `n`. |
| `b.end(n)` | Returns an iterator to the past-the-end element of the bucket having index `n`. |
| `b.cbegin(n)` | Returns a constant iterator to the first element of the bucket having index `n`. |
| `b.cend(n)` | Returns a constant iterator to the past-the-end element of the bucket having index `n`. |
| `b.load_factor()` | Returns the average number of elements per bucket. |
| `b.max_load_factor()` | Returns the value used as an upper limit for the load factor; the container increases the number of buckets if the load factor exceeds this value. |
| `b.max_load_factor(z)` | May change the maximum load factor, using `z` as a hint. |
