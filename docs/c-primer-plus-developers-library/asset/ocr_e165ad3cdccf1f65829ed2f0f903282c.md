# Table D.1 C++ Operator Precedence and Associativity

| Operator | Assoc. | Meaning |
| --- | --- | --- |
| *Precedence Group 3 (All Unary)* | | |
| `!` | R-L | Logical negation |
| `~` | R-L | Bitwise negation |
| `+` | R-L | Unary plus (positive sign) |
| `-` | R-L | Unary minus (negative sign) |
| `++` | R-L | Increment operator, prefix |
| `--` | R-L | Decrement operator, prefix |
| `&` | R-L | Address |
| `*` | R-L | Dereference (indirect value) |
| `()` | R-L | Type cast—that is, (type) expr |
| `sizeof` | R-L | Size in bytes |
| `alignof` | R-L | Alignment requirement |
| `new` | R-L | Dynamically allocate storage |
| `new []` | R-L | Dynamically allocate array |
| `delete` | R-L | Dynamically free storage |
| `delete []` | R-L | Dynamically free array |
| `noexcept` | R-L | False if operand might throw an exception |
| *Precedence Group 4* | | |
| `.*` | L-R | Member dereference |
| `->*` | L-R | Indirect member dereference |
| *Precedence Group 5 (All Binary)* | | |
| `*` | L-R | Multiply |
| `/` | L-R | Divide |
| `%` | L-R | Modulus (remainder) |
| *Precedence Group 6 (All Binary)* | | |
| `+` | L-R | Addition |
| `-` | L-R | Subtraction |
| *Precedence Group 7* | | |
| `<<` | L-R | Left shift |
| `>>` | L-R | Right shift |
| *Precedence Group 8* | | |
| `<` | L-R | Less than |
| `<=` | L-R | Less than or equal to |
| `>=` | L-R | Greater than or equal to |
| `>` | L-R | Greater than |
