Table 16.1  **string Class Constructors**

| Constructor | Description |
|---|---|
| `string()` | Creates a default string object of 0 size (default constructor). |
| `string(const char * s,`<br>`size_type n)` | Initializes a string object to the NBTS pointed to by `s` and continues for `n` characters, even if that exceeds the size of the NBTS. |
| `template<class Iter>`<br>`string(Iter begin,`<br>`Iter end)` | Initializes a string object to the values in the range `[begin, end)`, where `begin` and `end` act like pointers and specify locations; the range includes `begin` and is up to but not including `end`. |
| `string(const string & str,`<br>`size_type pos,`<br>`size_type n = npos)` | Initializes a string object to the object `str`, starting at position `pos` in `str` and going to the end of `str` or using `n` characters, whichever comes first. |
| `string(string && str) noexcept`<br>`(C++11)` | Initializes a string object to the string object `str`; `str` may be altered (move constructor). |
| `string(initializer_list<char> il)`<br>`(C++11)` | Initializes a string object to the characters in the initializer list `il`. |
