

# 4.1.1 Windows

1. 打开开始菜单。
2. 点击“运行...”。
3. 在文本框中输入“cmd”（不带引号）并回车。
4. 此时你应该看到一个黑底白字的窗口。这就是命令提示符。
5. 如果在提示符处输入“python”，你应该会进入 Python 解释器提示符。

# 4.1.2 Mac

1. 打开应用程序。
2. 打开实用工具。
3. 向下滚动并打开终端。
4. 你应该看到与上述 Windows 用户类似的窗口。
5. 在提示符处输入“python”，你将进入 Python 解释器。

此时你的终端应该显示如下内容：

**列表 4.1：Python 解释器示例**

```
Python 2.5.1 (r251:54863, Jan 17 2008, 19:35:17)
[GCC 4.0.1 (Apple Inc. build 5465)] on darwin
Type "help", "copyright", "credits" or "license"
for more information.
>>>
```

你可能会注意到，上述示例中使用的 Python 版本是 2.5.1；而当前版本是 3.2。别惊慌。你将要学习的绝大多数内容，无论使用哪个版本都能正常工作。我最喜欢的一本 Python 书，*Python How to Program*，是基于 2.2 版本的，但我现在每天编码时仍然几乎都把它当作参考书使用。

在大多数情况下，你甚至不会察觉到使用的是哪个版本，除非你正在使用针对特定版本的库、函数或方法。在这种情况下，你只需在代码中添加一个检查器，以识别用户使用的版本，并通知用户升级，或者修改你的代码使其具备向后兼容性。

（本书稍后的章节将详细介绍使用 Python 3.x 时需要了解的主要区别。目前你只需学习那些无论最终使用哪种语言版本都会用到的基础知识。）

列表 4.1 中的 >>> 是 Python 命令提示符；你的代码在这里输入，结果会在下一行打印，而不带提示符。例如，列表 4.2 展示了 Python 2.5 中的一个简单打印语句：

**列表 4.2：Python 命令提示符**

```
>>> print "We are the knights who say, 'Ni'."
We are the knights who say, 'Ni'.
```

## 4.2 Python 版本

顺带一提，Python 3.x 已将 print 从一个简单的语句（如列表 4.2 所示）变成了一个正式函数（列表 4.3 所示）。由于我们还没有讲到函数，你只需要知道 Python 3.x 简单地要求你以略微不同的方式使用 print 语句：引号内的单词需要用括号包围。只是让你知晓这一点。

**列表 4.3：Print 函数（Python 3.x）**

```
>>> print ("We are the knights who say, 'Ni' .")
We are the knights who say, 'Ni'.
```

本书中绝大多数的代码是针对 Python 2.6 或更早版本编写的，因为许多 *nix 系统默认安装的是这些版本，因此它们仍然非常流行；此外，市面上还有许多旧代码，尤其是开源程序，并没有（可能永远不会）升级到 Python 3.x。如果你决定使用其他 Python 程序来学习或使用，你需要了解“传统”的 Python 编程方式；许多开源程序仍然是为 Python 2.4 编写的。

如果你使用的是 Python 3.x，并且希望随着阅读过程将每个示例输入到你的计算机中，请注意，按照原文写法的 print 语句将无法正常工作。它们必须修改为像列表 4.3 中那样使用 print() 函数。

# 4.3 使用 Python 命令提示符

如果你写入一个不需要 Python 进行任何“处理”的语句，它只会将你返回到提示符，等待你的下一条指令。下一个代码示例展示了用户将值“spam”赋值给变量 can。Python 不需要对此进行任何计算或其他操作，因此它接受该语句，然后等待新的语句。

**列表 4.4：Python 语句**

```
>>> can = "spam"
>>> 
```

（顺便说一下，Python 的名字来源于 Monty Python，而不是蛇。因此，你在互联网上、教程和书籍中找到的很多代码都会包含对 Monty Python 小品的引用。）

标准的 Python 解释器可以在你将想法放入代码之前用来测试。这是一种整理逻辑的好方法，以确定使特定函数正确工作所需的逻辑，或者查看条件循环将如何工作。你还可以将解释器用作简单的计算器。这可能听起来极客，但我经常启动一个 Python 会话用作计算器，因为通常比点击 Windows 菜单使用其计算器更快。

以下是“计算器”功能的示例：

**列表 4.5：Python 作为计算器**

```
>>> 2+2
4
>>> 4*4
16
>>> 5**2  # 五的平方
25
```

Python 还有一个 math 库，你可以导入它来进行三角函数和许多其他高等数学计算。导入库将在本书后续章节中介绍。

## 4.4 Python 注释

最后要讨论的一点是，Python 中的注释使用“#”符号标记。注释用于添加注释或其他信息，而无需让 Python 尝试对其执行操作。例如，

**列表 4.6：Python 注释**

```
dict = {"First phonetic": "Able", "Second phonetic": "Baker"}  # 创建一个字典
print dict.keys()              # 字典中的值不是有序的
['Second phonetic', 'First phonetic']
print dict["First phonetic"]    # 打印键的值
Able
```

你稍后会看到，尽管 Python 是一种非常可读的语言，但在代码中添加注释仍然很有帮助。有时是为了明确说明代码在做什么，解释你使用的巧妙捷径，或者只是为了在你编码时提醒自己某些事情，比如一个“待办事项”列表。

## 4.5 启动 Python 程序

如果你想运行一个 Python 程序，只需在 shell 命令提示符处（而不是 IDE 或交互解释器）输入 `python`，后跟程序名称。

**列表 4.7：启动 Python 程序**

```
$ python foo.py
```

以 .py 扩展名保存的文件称为模块，可以像其他语言中的头文件一样在命令行或程序内部单独调用。如果你的程序将导入其他模块，你需要确保它们都保存在计算机上的同一目录中。有关处理模块的更多信息，可以在本书的后续章节或 Python 文档中找到。

根据程序的不同，在启动程序时可以在命令行添加某些参数。这类似于在 Windows DOS 提示符命令中添加开关。参数告诉程序具体应该做什么。例如，假设你有一个 Python 程序，它可以将其处理后的数据输出到文件而不是屏幕。要调用程序中的此功能，你只需如此启动该程序：

**列表 4.8：带参数启动 Python 程序**

```python
$ python foo.py -f
```

“-f”参数由程序接收，并调用一个函数，该函数将数据打印到计算机文件系统中的指定位置，而不是打印到屏幕。

如果你的计算机上安装了多个 Python 版本，例如系统默认版本是 2.5，但你想尝试 Python 3.x，你只需告诉操作系统使用哪个版本（见列表 4.9）。这一点很重要，因为许多旧的 Python 程序不能直接兼容 Python 3.x。在许多情况下，必须在计算机上保留旧版本的 Python 才能启用某些程序的正确运行；你并不希望完全覆盖旧版本的 Python。

**列表 4.9：选择 Python 版本**

```python
$ python2.5 sample.py    # 强制使用 Python 2.5
$ python3.0 sample.py    # 强制使用 Python 3.0
```

# 4.6 集成开发环境

我应该花点时间更多地解释一下编程环境。贯穿全书，大多数示例都涉及使用 Python 交互解释器，它是通过在操作系统命令提示符处输入“python”来使用的。这种环境实际上更多地用于测试想法或简单的“一次性”任务。由于信息不会存储在任何地方，当 Python 会话结束时，你处理的所有数据都会消失。

要制作可重用的程序，你需要使用某种源代码编辑器。这些编辑器可以是实际的编程环境应用程序，即 IDE（集成开发环境），也可以是像 Windows 记事本这样的简单文本编辑器。源代码没有什么特别的；无论使用哪种编程语言，它都只是文本。IDE 基本上是增强型的文本编辑器，提供特殊的工具使编程更容易、更快捷。

Python 有许多可用的 IDE，几乎全都是免费的。通常，一个 IDE 包含一个源代码编辑器、一个调试器、一个编译器（对于 Python 并非必要），以及通常还有一个图形用户界面构建器；不同的 IDE 可能包含或移除某些功能。以下是一些常见的 Python IDE 列表：

- *Eric* - 一个免费的应用程序，作为其他程序的前端，并使用插件
- *IDLE* - 一个包含在基础 Python 安装中的免费应用程序；包含集成的调试器
- *Komodo* - 一个功能齐全的专有应用程序，可用于其他编程语言
- *PyDev* - *Eclipse* 开发环境的插件
- *Stani’s Python Editor (SPE)* - 一个包含许多开发辅助工具的免费应用程序
