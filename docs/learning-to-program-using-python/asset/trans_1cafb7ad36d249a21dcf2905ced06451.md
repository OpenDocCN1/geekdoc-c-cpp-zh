

# 第 5 章

## 类型与运算符

Python 基于 C 编程语言并是用 C 语言编写的，因此 Python 使用的许多格式对于 C 和 C++ 程序员来说都很熟悉。然而，它让开发过程变得稍微轻松一些，因为它不是被设计为低级语言（很难与硬件进行深度交互或执行内存分配），并且它具有内置的“垃圾回收”机制（它会跟踪对象的引用，并在不再被引用时自动从内存中移除对象），这使得程序员可以更多地关注程序如何工作，而不是处理计算机底层细节。

### 5.1 Python 语法

#### 5.1.1 缩进

Python 强制用户以结构化的格式进行编程。代码块由使用的缩进量决定。正如你在编程语言比较章节中所记得的，其他语言使用括号和分号来显示代码分组或行结束。Python 不需要这些；缩进被用来标识每个代码块的开始和结束。这里有一个示例（行号已添加以便说明）：

```python
1   x = 1
2   if x:  #if x is true
3       y = 2
4       if y:  #if y is true
5           print "block 2"
6       print "block 1"
7   print "block 0"
```

每个缩进的行标记了一个新的代码块。让我们梳理上面的代码片段：第 1 行是主代码块的开始。第 2 行是一个新的代码段；如果“x”的值不等于 0，则其下方的缩进行将被评估。因此，第 3 行和第 4 行属于另一个代码段，如果第 2 行为真，它们将被评估。第 5 行是另一个代码段，只有当“y”不等于 0 时才被评估。第 6 行属于与第 3 行和第 4 行相同的代码块；它也将在那几行所在的同一块中被评估。第 7 行与第 1 行在同一部分，无论任何缩进行做什么，它都会被评估。

你会注意到，复合语句，比如 if 比较语句，是通过在头行后跟一个冒号 (":") 来创建的。语句的其余部分在其下方缩进。最需要记住的一点是，缩进决定分组；如果你的代码因某种原因不起作用，请仔细检查哪些语句被缩进了。

快速提示：说 “x = 1” 这个动作是将一个值赋给一个变量。在这种情况下，“x” 是变量；根据定义，它的值是变化的。这意味着你可以赋予它任何你想要的值；在这种情况下，值是“1”。变量是你将经常处理的最常见的编程项目之一，因为它们存储值并用于数据操作。

#### 5.1.2 跨多行

如果语句被收集在大括号内（圆括号 "()"、方括号 "[]" 或花括号 "{}"），它们可以跨越多行。通常使用圆括号。当在大括号内跨行时，缩进并不重要；初始括号用于确定整个语句属于哪个代码部分。如果使用三重引号，字符串语句也可以是跨行的。例如：

**列表 5.2：三重引号的使用**

```python
>>> big = """This is
... a multi-line block
... of text; Python puts
... an end-of-line marker
... after each line. """
>>>
>>> big
'This is\012a multi-line block\012of text; Python
puts\012an end-of-line marker \012after each
line.'
```

请注意，\012 是 \n 的八进制形式，即“换行”指示符。上面的省略号 (…) 是交互式 Python 提示符中的空白行，用于表示解释器正在等待更多信息。

### 5.2 Python 对象类型

与其他许多编程语言一样，Python 具有内置的数据类型，程序员使用它们来创建程序。这些数据类型是程序的构建块。根据语言的不同，可用的数据类型也不同。一些语言，特别是 C 和 C++，拥有非常原始的类型；大量的编程时间仅仅用于将这些原始类型组合成有用的数据结构。Python 消除大量这种繁琐的工作。它已经实现了一系列广泛的类型和结构，为开发人员留下了更多时间来实际创建程序。相信我；这是我在学习 C/C++ 时讨厌的事情之一。不得不为每个程序不断重新创建相同的数据结构，不是一件令人期待的事。

Python 拥有以下内置类型：数字、字符串、列表、字典、元组和文件。当然，如果需要，你可以构建自己的类型，但 Python 的创建使得你很少需要“自己动手”。内置类型足够强大，可以覆盖你代码的大多数部分，并且易于增强。我们将在讨论完数字后结束这一节；我们稍后会在其他章节中涵盖其他类型。

在我忘记之前，我应该提到 Python 没有强类型编码；也就是说，一个变量可以作为整数、浮点数、字符串或任何其他类型使用。Python 在运行时将确定需要什么。参见下方：

**列表 5.3：弱类型编码**

```python
>>> x = 12
>>> y = "lumberjack"
>>> x
12
>>> y
'lumberjack'
```

其他语言通常要求程序员在初始创建变量时决定变量必须是什么类型。例如，C 语言要求你在上面的程序中声明 "x" 为 *int* 类型，"y" 为 *string* 类型。从那时起，这些变量只能作为这些类型，即使你后来决定它们应该是不同的类型。

这意味着当你开始你的程序时，你必须决定每个变量将是什么，即决定是否应将数字变量设为整数或浮点数。显然，你以后可以回去修改它们，但这只是你又得思考和记住的一件事。此外，任何时候你忘记某个变量是什么类型并尝试给它分配错误的值，你就会得到编译错误。

### 5.3 Python 数字

Python 可以处理普通的长整数（最大长度根据操作系统确定，就像 C 语言一样）、Python 长整数（最大长度取决于可用内存）、浮点数（就像 C 语言的双精度浮点数）、八进制和十六进制数，以及复数（具有虚部数字）。以下是这些数字的一些示例：

- 整数：12345, -32
- Python 整数：999999999L (在 Python 3.x 中，所有整数都是 Python 整数)
- 浮点数：1.23, 4e5, 3e-4
- 八进制：012, 0456
- 十六进制：0xf34, 0X12FA
- 复数：3+4j, 2J, 5.0+2.5j

Python 具有你预期的常规内置数值工具：表达式运算符 (*, >>, +, <, 等)、数学函数 (pow, abs, 等) 和实用工具 (rand, math, 等)。对于大量的数值计算，Python 有 Numeric Python (NumPy) 扩展，它包含矩阵数据类型等。如果需要，必须单独安装。由于它的强大功能和易用性相当于 Mathematica、Maple 和 MatLab，它在科学和数学环境中被广泛使用。

虽然这对非程序员可能没有太大意义，C 语言中的表达式运算符已被包含在 Python 中，但其中一些略有不同。逻辑运算符在 Python 中是用单词拼写出来的，而不是使用符号，例如，逻辑 AND 由 "and" 表示，而不是 "&&"；逻辑 OR 由 "or" 表示，而不是 "||"；逻辑 NOT 使用 "not" 而不是 "!"。更多信息可以在 Python 文档中找到。

运算符优先级与 C 语言相同，但强烈建议使用括号以确保表达式正确评估并增强可读性。混合类型（浮点值与整数值结合）在评估前会向上转换为最高类型，即将浮点数与整数相加会导致整数在求和评估前变为浮点值。

继我之前所说，变量赋值是在首次使用时创建的，不需要像 C 语言那样预先声明。

**列表 5.4：通用 C++ 示例**

```cpp
int a = 3; //inline initialization of integer
float b; //sequential initialization of floating point number
b = 4.0f;
```
