

### 常见列表操作

```python
>>> print L  # show that the last item was removed
[1, 2, 3, 4]
```

以下是一些常见的列表操作：

- `L1 = []`：空列表
- `L2 = [0, 1, 2, 3]`：包含四个元素的列表
- `L3 = ['abc', ['def', 'ghi']]`：嵌套子列表
- `L2[n]`, `L3[n][j]`, `L2[n:j]`, `len(L2)`：索引、切片、获取长度
- `L1 + L2`, `L2 * 3`：拼接、重复
- `for x in L2`, `3 in L2`：迭代、成员资格测试
- `L2.append(4)`, `L2.sort()`, `L2.index(1)`, `L2.reverse()`：方法调用：添加、排序、查找、反转等
- `del L2[k]`, `L2[n:j] = []`：缩小列表（删除元素）
- `L2[n] = 1`, `L2[n:j] = [4,5,6]`：索引赋值、切片赋值
- `range(4)`, `xrange(0, 4)`：创建整数列表或生成器（注：`xrange` 在 Python 2 中返回序列，Python 3 中合并为 `range`）

需要记住的最重要的一点是，列表是由方括号包裹、以逗号分隔的一系列对象。字典和元组在语法上与列表相似，只是使用的括号类型不同。

## 7.1 列表的用法

列表通常用于存储同构值，即列表通常存储名称、数字或其他所有属于同一数据类型的序列。列表没有类型限制；你可以混合使用任何你想要的数据类型。只是通常更容易将列表想象为持有一个“标准”项目序列。

列表最常见的用途是遍历列表并对列表中的每个对象执行相同操作，因此常用相似的数据类型。举个例子：

### 列表 7.2：遍历列表

```python
>>> mylist = ["one", "two", "three"]
>>> for x in mylist:
...      print "number " + x

number one
number two
number three
```

在上面的例子中，创建了一个文本字符串列表。接下来，一个简单的 *for* 循环被用来遍历列表，在每个列表对象前加上单词 "number" 并打印出来。我们稍后会讨论 *for* 循环，但这是一个常见的用途。

现在需要注意的一点是，你可以使用任何值作为 "x"，即你可以使用任何你喜欢的名称代替 "x"。我之所以提到这一点，是因为我在 Python 中第一次遇到这种循环时有点困惑。在其他语言中，像这样的循环要么是语言内置的、必须使用其格式，要么必须显式地在循环前创建 "x" 值以便在循环中调用。Python 的方式更容易，因为你可以使用任何意义最合理的名称，或者像我一样使用“通用变量”。例如，我可以使用 "for num in mylist:" 或任何其他变体来遍历列表。完全由你决定。

我不会深入讨论列表的简单操作，因为它们的工作原理与字符串操作相同。你可以像操作字符串一样对列表进行索引、切片和操作。实际上，字符串更像是一种只处理字母数字字符的修改版列表。

如果你有疑问，请查看关于字符串的章节（第 6 章）；如果仍有疑问，请查阅官方 Python 文档。请记住，生成的对象将是一个新列表（由方括号包围），而不是字符串、整数等。

## 7.2 添加列表元素

向列表添加新项非常容易。你只需告诉列表添加它即可。对列表进行排序也是同样的情况。

### 列表 7.3：向列表添加项目

```python
>>> newlist = [1, 2, 3]
>>> newlist.append(54)
>>> newlist
[1, 2, 3, 54]
>>> a_list = ["eat", "ham", "spam", "eggs", "and"]
>>> a_list.sort() # 对列表项进行排序（大写字母优先）
>>> a_list
['spam', 'and', 'eat', 'eggs', 'ham']
```

**append()** 方法简单地将单个项目添加到列表末尾；它与连接不同，因为它接受单个对象而不是列表。**append()** 和 **sort()** 都是就地更改列表，不会创建全新的列表对象，也不返回修改后的列表。要查看更改，必须显式地再次调用列表对象，如列表 7.3 所示。因此，如果你困惑更改是否实际发生，请留意这一点。

如果你想将新项目放入列表中的特定位置，你需要告诉列表它应该放在哪个位置，即使用位置的索引。记住，索引从 0 开始，而不是 1，如列表 7.4 所示。

### 列表 7.4：通过索引添加项目

```python
>>> newlist.insert(1, 69)    # 在索引 '1' 处插入 '69'
>>> newlist
[1, 69, 2, 3, 54]
```

你可以使用 **extend()** 方法将第二个列表添加到现有列表中。本质上，这两个列表被连接（链接）在一起，如下所示：

### 列表 7.5：组合列表

```python
>>> newerlist = [" Mary", "had", "a", "little", "spam ."]
>>> newlist.extend(newerlist) # 使用命名列表进行扩展
>>> newlist
[1, 69, 2, 3, 54, 'Mary', 'had', 'a', 'little', 'spam.']
>>> newerlist.extend(["It's", "grease", "was", "white", "as", "snow."])  # 内联扩展
>>> newerlist
['Mary', 'had', 'a', 'little', 'spam.', "It's", 'grease', 'was', 'white', 'as', 'snow.']
```

请注意，extend 和 append 之间存在明显区别。extend() 接受一个参数，始终是一个列表，并将该列表的每个元素添加到原始列表；两个列表合并为一个。append() 接受一个参数，可以是任何数据类型，并简单地将其添加到列表末尾；最终得到一个包含一个元素的列表，该元素是被追加的对象。以下是来自“Dive into Python”的一个例子：

### 列表 7.6：extend 与 append

```python
>>> li = ['a', 'b', 'c']
>>> li.extend(['d', 'e', 'f'])
>>> li
['a', 'b', 'c', 'd', 'e', 'f']  # 合并列表
>>> len(li)     # 列表长度
6
>>> li[-1]  # 反向索引
'f'
>>> li = ['a', 'b', 'c']
>>> li.append(['d', 'e', 'f'])  # 将列表对象用作元素
>>> li
['a', 'b', 'c', ['d', 'e', 'f']]
>>> len(li)
4
>>> li[-1]  # 单个列表对象
['d', 'e', 'f']
```

## 7.3 可变性

列表的特殊之处在于它们是可变的，即它们可以被就地修改，而不会创建新对象。对此的主要顾虑是记住，如果你这样做，可能会影响对它的其他引用。然而，这通常不是大问题，所以只要你得到程序错误，就要记住这一点。

以下是使用偏移量和切片更改列表的示例：

### 列表 7.7：更改列表

```python
>>> L = [ 'spam', 'Spam', 'SPAM!' ]
>>> L[1] = 'eggs'     # 索引赋值
>>> L
[ 'spam', 'eggs', 'SPAM!' ]
>>> L[0:2] = [ 'eat', 'more']  # 切片赋值：删除+插入
>>> L    # 替换索引为 0 和 1 的项
[ 'eat', 'more', 'SPAM!' ]
```

由于列表是可变的，你还可以使用 del 语句删除项目或节。以下是一个例子：

### 列表 7.8：删除列表项

```python
>>> L
[ 'SPAM!', 'eat', 'more', 'please' ]
>>> del L[0]       # 删除一个项目
>>> L
[ 'eat', 'more', 'please' ]
>>> del L[1:]      # 删除整个节
>>> L   # 等同于 L[1:] = []
[ 'eat' ]
```

## 7.4 方法

我之前提到过方法，我会在面向对象编程章节中进一步讨论方法，但对于好奇者，方法的作用类似于函数，即你有方法名后跟括号内的参数。主要区别是，

方法通过点号标点符号限定于特定对象。在上面的某些示例中，列表对象通过使用“.”（点）符号受方法影响。“.” 告诉 Python 解释器查找点后的方法名并对相关的列表对象执行方法中的操作。

由于 Python 中的一切都是对象，几乎所有对象都有某种方法。你可能无法记住每种对象类型的所有方法，但记住最常见和有用的方法会加快开发速度。拥有一种对象类型的方法列表非常方便。你会在这本书的附录中找到每种对象类型的最常见方法列表。

最后，你需要记住只有可变对象才能就地更改；字符串、元组和其他对象在更改时始终必须创建新对象。你还需要记住，就地修改对象可能会影响引用它的其他对象。
