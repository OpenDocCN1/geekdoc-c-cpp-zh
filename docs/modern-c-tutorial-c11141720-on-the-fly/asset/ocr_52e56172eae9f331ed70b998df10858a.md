This is because the length of the array in the C++ standard must be a constant expression, and for len_2, this is a const constant, not a constant expression, even if this is supported by most compilers, but it is an illegal behavior, we need to use the constexpr feature introduced in C++11, which will be introduced next, to solve this problem; for arr_5 before C++98 The compiler cannot know that len_foo() actually returns a constant at runtime, which causes illegal production.
