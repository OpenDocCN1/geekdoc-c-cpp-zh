Perfect forwarding is based on the above rules. The so-called forwarding is to let us pass the parameters, keep the original parameter type (value reference keeps lvalue, rvalue reference keeps rvalue reference). To solve this problem, we should use std::forward (pass) the parameters:

```
#include <iostream>
#include <utility>
void reference(int& v) {
    std::cout << "lvalue reference" << std::endl;
}
void reference(int&& v) {
    std::cout << "rvalue reference" << std::endl;
}
template <typename T>
void pass(T v) {
    std::cout << " normal param passing: " <<
    reference(v);
    std::cout << " std::move param passing: " <<
    reference(std::move(v));
    std::cout << " std::forward param passing: " <<
    reference(std::forward<T>&>(v));
    std::cout << " _static_cast<T&> param passing: " <<
    reference(static_cast<T&&>(v));
}
int main() {
    std::cout << "rvalue pass:" << std::endl;
    pass(1);
    int l = 1;
    std::cout << "lvalue pass:" << std::endl;
    pass(l);
    return 0;
}
```

The outputs are

rvalue pass:
normal param passing: lvalue reference
std::move param passing: rvalue reference
