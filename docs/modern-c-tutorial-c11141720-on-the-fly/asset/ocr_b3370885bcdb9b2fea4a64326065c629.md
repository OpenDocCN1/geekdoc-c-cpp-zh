# Type alias templates

Before you understand the type alias template, you need to understand the difference “template” and “type”. Carefully understand this sentence: Templates are used to generate types. In traditional C++, typedef can define a new name for the type, but there is no way to define a new name for the template. Because the template is not a type. E.g:

```
template<typename T, typename U>
class MagicType {
public:
    T dark;
    U magic;
};
```
