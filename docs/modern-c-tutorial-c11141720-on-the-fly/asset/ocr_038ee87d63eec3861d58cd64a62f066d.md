# Default template parameters

We may have defined an addition function:

```
template<typename T, typename U, typename V>
auto add(T x, U y) -> decltype(x+y) {
    return x+y;
}
```

When, used, it is found that to add, you must specify the type of its template parameters each time.

A convenience is in C++11 to specify the default parameters of the template:

```
template<typename T = int, typename U = int>
auto add(T x, U y) -> decltype(x+y) {
    return x+y;
}
```

# Variadic templates

The template has always been one of C++’s unique Black Magic. In traditional C++, both a class template and a function template could only accept a fixed set of template parameters as specified; C++11 added a new representation, allowing any number, template parameters of any category, and there is no need to fix the number of parameters when defining.:

```
template<typename... Ts> class Magic;
```

The class Magic object can accept unrestricted number of typename as a formal parameter of the template, such as the following definition:

```
class Magic<int>
    std::vector<int>,
    std::map<int, std::string>,
    std::vector<std::vector<int>>> darkMagic;
```
