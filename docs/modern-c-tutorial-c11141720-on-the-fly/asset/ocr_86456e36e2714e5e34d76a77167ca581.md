std::get in using constants to get type objects, C++14 adds usage to get objects in tuples:

```
std::tuple<std::string, double, double, int> t("123", 4.5, 6.7, 8);
std::cout << std::get<std::string>(t) << std::endl;
std::cout << std::get<double>(t) << std::endl; // illegal, runtime error
std::cout << std::get<3>(t) << std::endl;
```

# Runtime Index

If you think about it, you might find the problem with the above code. std::get<T> depends on a compile-time constant, so the following is not legal:

```
int index = 1;
std::get<int>(index);
```
