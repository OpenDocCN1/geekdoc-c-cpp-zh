dummy or meaningless byte of data. If you only want to send then the byte you receive is not used.

Example:

```
/*** Read a byte of data from an EEPROM function ****
char RD_BYTE ( char EE_address )
{
    char dummy;
    char spi_received = 0;
    CS = 0;     // Set chip select low
    dummy = SPI_OUTPUT (0x03);        // Send read command
    dummy = SPI_OUTPUT( EE_address ); // Send Address
    spi_received = SPI_OUTPUT( 0x00 ); // Receive Stored Value
    CS = 1;                         // Bring chip select high to terminate
                                    // the read command
    return spi_received;
}
```

# WR_BYTE (address, databtye)

The WR_BYTE function uses the spi_output function to write a byte of data to a SPI based EEPROM chip. The byte can be written to a specific memory location. The address is a value from 0 to 255 so this function is limited to a 2k bit EEPROM memory chip. A Microchip 25LC020A or 25AA020A are 2k bit parts that work well with this command.

Special Note: Notice the function name is all capitals. This is because this function is a SPI specific routine for a particular component.
