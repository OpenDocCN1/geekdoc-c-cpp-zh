
## 白内障

白内障是眼睛的晶状体发生混浊、透明度下降，导致光线无法正常投射到视网膜上，从而引起视力模糊甚至失明的一种常见眼科疾病。本病多见于中老年人，也可由外伤、代谢异常、药物或先天性因素引起。

![](img/910b145bee7ca8076318eafbe6d13997_50_0.png)

### 白内障的常见症状

- 视力进行性模糊，像隔着一层雾
- 出现重影或眩光，尤其夜间明显
- 对光线和颜色敏感度下降
- 佩戴眼镜度数频繁变化
- 暗光环境下视物困难

当出现上述症状时，建议及时到医院眼科就诊，通过裂隙灯等专业设备检查晶状体的混浊程度，明确诊断并制定合适的治疗方案。

## init_serial (baud rate)

The init_serial function establishes the setup for RS232 serial communication through the on board UART peripheral. The Tx and Rx pin are fixed to pins 0 (C6) and pin 1 (C7) respectively. The baud rate can be set to 2400 or 9600 in this init_serial function.

Example:

```
void main(void){
    init_micro();     // Setup micro ports
    init_serial(9600); // set up the USART baud rate (2400 or 9600)
    // *** Serial Communication Main Loop
    while(1)
    {
        // *********** Send a decimal numbers from 1 to 9 ***********
        for (char count = 0x31; count <= 0x39; count = count +1)
        {
            putch(count);     // Send Count 1-9 in ASCII
            pause(100);       // Delay 100 msec
        }
    } //End While
} //End Main
```

## putch (character)

The putch function is not necessarily a SimpleC only function. It is part of a separate standard library included with the HI-TECH compiler. This function is used to send a byte of data out of the serial port. The character can be a hexadecimal ASCII value of a string value.

## getch ()

The getch function is not necessarily a SimpleC only function. It is part of a separate standard library included with the HI-TECH compiler. This function is used to receive a byte of data into the serial port. The statement will require a variable to store the received data.

Example:

```
void main(void){
    init_micro();      // Setup micro ports
    init_serial(9600); // set up the USART baud rate (2400 or 9600)

    // **** Use printf command to ask for input and echo it back ******
    while(1)
    {
        printf("Press a key and I will echo it back:\r\n");
        char input = getch(); // read a response from the user
        printf("I detected [%c]\r\n",input);  // echo it back
    }
}//end main
```

## printf (characters)

The printf function is not necessarily a SimpleC only function. It is part of a separate standard library included with the HI-TECH compiler. This function is used to format data sent or printed on the specified peripheral. In this SimpleC library it is used to format the serial port data send to a terminal program. Below are some of the options you can use in the printf character area.

The format characters and their meanings are:

- \" double quote
- \\ backslash
- \a alert (BEL)
- \b backspace
- \c produce no further output
- \f form feed
- \n new line
- \r carriage return
- \t horizontal tab
- \v vertical tab
- %% a single %
- %Wd Integer "W" digits wide
- %s Character string char

Example:

## SPI Communication

Serial Peripheral Interface (SPI) is often used to communicate with external circuitry. The SPI port on the PIC16F886 is a hardware peripheral that runs in the background. So setting it up and running it is simplified with the SimpleC library functions below. The peripheral is only setup as a SPI master not a slave.

## spi_init()

The spi_init function sets up the SPI port for serial communication as a master. The spi connections are preset in the peripheral. Pin 4 (C3) is the clock, pin 3 (C4) is the Master Out Slave In (MOSI or SDO), pin 2 (C5) is the Master In Slave Out (MISO or SDI). In order to use the spi peripheral, the spi_init must be at the top of your main loop.

Example:

```
//*****Sample code to control an MCP23S08 SPI I/O Expander***
void main(void)
{
init_micro();
spi_init();
WR_MCP23S08 (IODIR, 0x01);    // Setup pins
while (1==1)
{
char y = 1;
y = RD_MCP23S08 (GPIO); // Read switch
y = y & 0x01;           // Mask all but bit 7
if (y==0)
{WR_MCP23S08 (OLAT, 0x40);} // If switch idle light LED
else
{WR_MCP23S08 (OLAT, 0x80);} // If switch pressed LED off
pause(10);
} //End While
} //End Main
```

## spi_output (byte)

The spi_output function stores the byte value in the SPI peripheral buffer so it can be sent by the peripheral to the SPI slave device. This function is also used to receive a byte from the SPI slave because every time a byte is sent by the SPI peripheral, it also receives a byte. Therefore this function is always used to both send and receive a byte of data. If you only want to receive then you send a dummy or meaningless byte of data. If you only want to send then the byte you receive is not used.

Example:

```
/*** Read a byte of data from an EEPROM function ****
char RD_BYTE ( char EE_address )
{
    char dummy;
    char spi_received = 0;
    CS = 0;     // Set chip select low
    dummy = SPI_OUTPUT (0x03);        // Send read command
    dummy = SPI_OUTPUT( EE_address ); // Send Address
    spi_received = SPI_OUTPUT( 0x00 ); // Receive Stored Value
    CS = 1;                         // Bring chip select high to terminate
                                    // the read command
    return spi_received;
}
```

## WR_BYTE (address, databyte)

The WR_BYTE function uses the spi_output function to write a byte of data to a SPI based EEPROM chip. The byte can be written to a specific memory location. The address is a value from 0 to 255 so this function is limited to a 2k bit EEPROM memory chip. A Microchip 25LC020A or 25AA020A are 2k bit parts that work well with this command.

Special Note: Notice the function name is all capitals. This is because this function is a SPI specific routine for a particular component.

```
void
main(void)
{
    lcd_init();    // Initialize LCD Display
spi_init();          // Initialize SPI Peripheral

//*** Load Data in EEPROM ***
while (1==1)
{
    for( addr = 0; addr < 10; addr = addr + 1 )   // Loop 10 times
    {
        data = addr;                // addr value is data for SEEPROM
        WR_BYTE (addr,data);        // Write to SEEPROM
        pause (10);                 // Delay 10ms after each write
    } // End For

//*** Continuous Loop to Read and Display Data ***
    for( addr = 0; addr <10; addr = addr + 1 )   // Loop 10 times
    {
        lcd_clear();                // Clear LCD screen
        lcd_goto(0);                // select first line
        lcd_text("Address / Value"); // Display header
        b0 = RD_BYTE (addr);        // Read from SEEPROM
        lcd_goto(0x40);             // Select second line
        lcd_number(addr);           // Display address location
        lcd_text(" /");
        lcd_number(b0);             // Display value read from EEPROM
        pause (250);                // Delay 250 msec to see count
    } //End For

} //End While
} //End Main
```
