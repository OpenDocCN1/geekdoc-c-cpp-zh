# TABLE 1-2: REGISTER ADDRESSES

| Address | Access to: |
|---|---|
| 00h | IODIR |
| 01h | IPOL |
| 02h | GPINTEN |
| 03h | DEFVAL |
| 04h | INTCON |
| 05h | IOCON |
| 06h | GPPU |
| 07h | INTF |
| 08h | INTCAP (Read-only) |
| 09h | GPIO |
| 0Ah | OLAT |

The value entered in the register location is written in hex form (i.e. 0x04 for the INTCON register). The RD_MCP23508 function also offers a few nicknames for the most common three registers so you can use these names in place of the actual address value:

+   - IODIR // Data Direction Register Address 0x00
+   - OLAT // Output Latch Register Address 0x0A
+   - GPIO // Port Register Register Address 0x09
