# WR_MCP23S08 (register, databyte)

The WR_MCP23S08 function uses the spi_output function to write a byte of data to a SPI based Microchip I/O expander part number MCP23S08. The databyte can be written to a specific register location. The register value is based on the data sheet for the MCP23S08. The main registers are below:

**TABLE 1-2: REGISTER ADDRESSES**

| Address | Access to: |
|---|---|
| 00h | IODIR |
| 01h | IPOL |
| 02h | GPINTEN |
| 03h | DEFVAL |
| 04h | INTCON |
| 05h | IOCON |
| 06h | GPPU |
| 07h | INTF |
| 09h | INTCAP (Read-only) |
| 09h | GPIO |
| 0Ah | OLAT |

The value entered in the register location is written in hex form (i.e. 0x04 for the INTCON register). The WR_MCP23S08 function also offers a few nicknames for the most common three registers so you can use these names in place of the actual address value:

+   - IODIR // Data Direction Register Address 0x00
+   - OLAT // Output Latch Register Address 0x0A
+   - GPIO // Port Register Register Address 0x09
