```
spi_init();          // Initialize SPI Peripheral

//*** Load Data in EEPROM ***
while (1==1)
{
    for( addr = 0; addr < 10; addr = addr + 1 )   // Loop 10 times
    {
        data = addr;                // addr value is data for SEEPROM
        WR_BYTE (addr,data);        // Write to SEEPROM
        pause (10);                 // Delay 10ms after each write
    } // End For

//*** Continuous Loop to Read and Display Data ***
    for( addr = 0; addr <10; addr = addr + 1 )   // Loop 10 times
    {
        lcd_clear();                // Clear LCD screen
        lcd_goto(0);                // select first line
        lcd_text("Address / Value"); // Display header
        b0 = RD_BYTE (addr);        // Read from SEEPROM
        lcd_goto(0x40);             // Select second line
        lcd_number(addr);           // Display address location
        lcd_text(" /");
        lcd_number(b0);             // Display value read from EEPROM
        pause (250);                // Delay 250 msec to see count
    } //End For

} //End While
} //End Main
```

# RD_BYTE (address, databyte)

The RD_BYTE function uses the spi_output function to read a byte of data from a SPI based EEPROM chip. The byte can be read from a specific memory location. The address is a value from 0 to 255 so this function is limited to a 2k bit EEPROM memory chip. A Microchip 25LC020A or 25AA020A are 2k bit parts that work well with this command.

Special Note: Notice the function name is all capitals. This is because this function is a SPI specific routine for a particular component.
