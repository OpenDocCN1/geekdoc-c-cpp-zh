# Chapter 9 – SimpleC Pulse Width Modulation

In this chapter I’ll show you how SimpleC makes using the hardware PWM peripheral extremely easy to use. You’ll be able to set the frequency and duty cycle in one command line. Because SimpleC was written for a fixed 16Mhz oscillator I was able to do all the calculations and preset all the registers within the SimpleC PWM function. Thus the only thing left for the SimpleC user to do is decide the frequency and the duty cycle. If you want more detail on the inner workings of the peripheral I cover this in my Volume 2 book and showed the formula used to calculate the register settings. Here we’ll take the easy route and use SimpleC.

This project will drive two PWM outputs with a 5 Khz frequency signal. The micro will read a potentiometer using an analog pin and then adjust the duty cycle of PWM1 accordingly. The project will also drive the PWM2 pin at the same frequency as PWM 1 but at a constant 50% duty cycle signal on PWM2. The outputs will drive LEDs for visual feedback. I also captured the signal on an oscilloscope to show the signal (Figure 9-3).

# Hardware

The hardware for this project is quite simple to build. The schematic in Figure 9-1 shows the connections. PWM 1 is on CHIPINO pin 5 (C2) and PWM 2 is on CHIPINO pin 6 (C1) with LEDs connected. The potentiometer creates a variable voltage on its wiper pin between V+ and V- which is somewhere between 5v and ground. The analog pin AN0 will monitor the potentiometer. The CHIPINO has a 16 Mhz crystal, which will drive the micro and the internal PWM signals.
