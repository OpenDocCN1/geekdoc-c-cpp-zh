void msecbase(void)
{
        OPTION = 0b00000011;       //Set prescaler to TMR0 1:16
        TMR0 = 0xD;                 //Preset TMR0 to overflow on 243 counts
        while(!T0IF);               //Stay until TMR0 overflow flag equals 1
        T0IF = 0;                   //Clear the TMR0 overflow flag
}

The high ( ) function and low ( ) are really a way of setting a port pin high or low for the true beginner. If you don’t want to learn or haven’t learned about setting the TRIS register and then the PORT register, this command handles it for you. It sets the individual bits for the pin you want to use. It also simplified the definition of the port pin to numbers that match the numbers on the CHIPINO board. These are handy but probably a bad habit for when you try to control ports outside of the CHIPINO world. Controlling the port directly is a preferred programming method.
