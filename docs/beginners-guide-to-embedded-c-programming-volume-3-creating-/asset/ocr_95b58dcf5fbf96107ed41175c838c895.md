Once the build is successful we want to load the code into the PIC16F886 and we do that with either the CHIPAXE PK2 clone programmer or a Microchip PICkit 2 Programmer. Click on the Programmer>Select Programmer>PICkit 2 menu selection to enable the PICkit 2 as shown in Figure 4-14. You can also use a PICkit 3 or ICD3 if you have one of those. Just select them from the drop down menu rather than the PICkit 2.
