# Hardware

The schematic for this project is shown in Figure 2-3. The schematic shows all the CHIPINO module connections and then the I2C EEPROM 24LC01B along with the four LEDs. The LEDs have 1k ohm resistors to limit the current. The A0, A1 and A2 pins are grounded on the 24LC01B to make the address 000 of the control byte for this EEPROM. If we had more than one, we could tie one of the pins, such as A0, to 5v to make the address 001. This is how you could have more than one EEPROM on the same I2C bus.
