# Project 3 – Outputs from MCP23S08

This project is just a variation of the previous project as it only drives outputs of the MCP23S08. We did that is the previous project based on the state of a switch. This project uses the same LED connections to create a quick two-bit binary counter with the LEDs as indicators.

# Hardware

The hardware is just a reduced version of the previous project. You can use the same breadboard setup as before so this is a quick addition to the SPI examples. The MCP23S08 can drive LEDs directly as it has a high output current drive for each pin. This can be handy since the LEDs could be replaced with a transistor driving a relay coil.
