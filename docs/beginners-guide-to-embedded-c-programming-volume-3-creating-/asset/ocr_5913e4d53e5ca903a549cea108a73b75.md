```
pause(255);      // Delay 255 milliseconds
}

cnt=0;
```

The same variable “cnt” is used as a counter so 10 data values can be read from the EEPROM in a while loop. The value read is displayed in binary on the LEDs.

```
while(cnt<=10)
{
PORTB = I2C_EEIN(cnt); // Display data read from EEPROM on LEDs in binary
pause(1000);           // Delay for 1 second to read LEDs
cnt=cnt + 1;           // Increment cnt variable
}
```

All those functions created were used to run that main loop of code that is only about 16 lines of code. Putting all those functions in a library file is how SimpleC makes C programming easier.
