# SimpleC Software Description

Two files make up the Simple C library; simplec1.1.h and simplec1.1.c. The number 1.1 is the version level so as I add new functions in the future the version number will increase from 1.1, to 1.2, to 1.3, etc. These have been opened sourced and can be found as part of the books software download and at the chipino.cc download page so adding to this library can be a community project where anyone can improve upon the capability.

In this section I wanted to briefly cover how each function works so you can reference this chapter if you have issues in using the library or need to modify it for your specific application. Later on I’ll go deep into the actual code for each function for those that want to modify it.

*Note: All SimpleC functions are case sensitive meaning if they are written as lower case in the simplec.c file then you need to write lower case in your program. Some specific functions are written in upper case so please be aware of this.*
