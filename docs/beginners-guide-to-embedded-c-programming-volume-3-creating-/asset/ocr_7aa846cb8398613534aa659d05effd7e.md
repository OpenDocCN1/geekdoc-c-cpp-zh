# Chapter 4 – SimpleC Digital Output

This may seem like we are retracing our steps if you have read through Volume 1 of this book series but we have to start with the basics to make sure everything is working correctly. The best way to do that is with a flash LED project. You can easily replace the LED with a transistor driving a relay or any item that can be digitally controlled. The point is to show how to drive a port pin with the SimpleC library function high(). For those new to MPLAB I’ll step through creating a software project in this chapter. You can use this for a reference in future project chapters since I won’t bore you with this for every project. Once you learn it for one project, it will work for all.
