The HI-TECH compiler already has some pre-built functions included in the stdio library which is automatically included during the compile time if the stdio.h file is included. One of those is the printf() function. This is described in the HI-TECH manual and can be used for all USART communication but I wanted a couple specific byte control functions for the SimpleC library as well. The first is putch() which is used to send an ASCII character out of the USART. The function makes sure the transmit buffer is empty and then fills it with the ASCII byte in the parameter section of the function header.

```
// ****************************************
// Send ASCII Character from Hardware USART
// ****************************************

void
putch(unsigned char byte)
{
    /* output one byte */
    while(!TXIF); /* set when register is empty */
    continue;
    TXREG = byte;
}
```

The second is the receive byte getch() function that tests for data in the receive register and then returns the byte received from the function call. These make serial communication very easy.

```
// ****************************************
// Receive ASCII Character from Hardware USART
// ****************************************

unsigned char
getch()
{
    /* retrieve one byte */
    while(!RCIF); /* set when register is not empty */
    continue;
    return RCREG;
}
```
