The main loop of code starts off with an init_micro function. This function sets the analog pins to digital and turns off any comparators. This was standard code added to every project in my previous books so I reduced it down to one function in the SimpleC library. Needless to say, this should also be part of every SimpleC project file.

```
void
main(void)
{
    init_micro();    // Initialize I/O
}
```

The main loop of code contains the high and low functions along with two pause functions that delay for 1000 milliseconds creating the one second on, one second off blink. The nice feature of the high and low is they control the bit defined by the parameter. These were written to match the numbered pins of the CHIPINO modules. A value of 1 to 13 is allowed, as those are the pin numbers of the CHIPINO. You cannot put pin name such as RB0 in place of the number. You have to stick with the numbering system.

```
while (1==1)
{
    high(8);
    pause(1000);    // Delay for 1 second (1.0000 sec)
    low(8);
    pause (1000);   // Delay for 1 second
}
```

# Next Steps

The options you have for this simple project is really up to your imagination. The high and low functions work on one pin at a time so controlling multiple pins can make a program very easy to write but also very long. I find these functions work best when you just need a simple way to control a pin. With that in mind maybe change the hardware to control a relay or maybe use this simple blink program to create a pulse that controls a servo motor. It can be a great way to demonstrate how controlling a digital pin is at the heart of everything a micro does.
