Now that we have the state of the switch stored we can test it to perform different operations. If the value is 1 or switch is idle, then using the high and low functions we turn on one LED and turn off the other. If the switch is pressed then the reverse lighting of the LEDs occurs. This runs continuous so we can see any press or release of the switch quickly.

```
if (value == 1)
{
    //*** Switch is idle ***
    high(11);     // Pin 11 LED on
    low(10);      // Pin 10 LED off
}
else
{
    //*** Switch is Pressed ***
    low(11);      // Pin 11 LED off
    high(10);     // Pin 10 LED on
}
}
```
