This book will show you how I created what I call the “SimpleC library” of useful functions and then show several projects that demonstrate how to use the library. I found this library so useful I now use it for most of my HI-TECH C projects. I won’t claim this is the best C code out there but I think you’ll see that these functions will save you a lot of time and effort when you are developing a quick prototype or development project. They form a great library of functions that are all open source so you can change them to fit your needs. Using the library doesn’t take away from you using the core features of the HI-TECH compiler either. All the code I taught you in the first two books can be applied to this setup as well.

This book also covers a topic left out of the previous two and that is I2C communication. The PIC16F886 has an improved communication peripheral port that makes I2C much easier to control. Chapter 2 will cover this prior to the book diving deep into the SimpleC library.
