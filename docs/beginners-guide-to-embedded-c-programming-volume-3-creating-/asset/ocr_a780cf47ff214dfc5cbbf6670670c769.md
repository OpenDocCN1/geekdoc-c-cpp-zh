# How it Works

The top of the program has a title block that the compiler recognizes as comments. The title block starts with a "/*" and much later ends with a "*/". This indicates that everything in-between is just comments and not code.

The program will send 10 data bytes to external EEPROM at a fast rate and display each value stored on four LEDs as a binary value. It will then read each byte back from the EEPROM and display the value in binary on the four LEDs. The write section will count up in binary from 1 to 9 quickly and then the read section will go slower and count down from 9 to 1 in binary format.

```
/*
 * I2C External EEPROM example using SimpleC
 * This code will write 10 bytes to the EEPROM and
 * then read them back and display binary value on LEDs.
 *
 * Connections:
 * Pin 8(B0) - LED Anode - LED Cathode - 1k ohm - Ground
 * Pin 9(B1) - LED Anode - LED Cathode - 1k ohm - Ground
 * Pin 10(B2) - LED Anode - LED Cathode - 1k ohm - Ground
 * Pin 11(B3) - LED Anode - LED Cathode - 1k ohm - Ground
 *
 * Pin 3(C4) - 24LC01B SDA - 10k pullup - 5v
 * Pin 4(C3) - 24LC01B SCL - 10k pullup - 5v
 * 24LC01B Vss - Ground
 * 24LC01B Vdd - 5v
 */
```

The next section includes the header file htc.h required by the HI-TECH compiler. The stdio.h file is optional for this project but used for some library functions built into the HI-TECH compiler. The configuration settings for the CHIPINO's PIC16F886 are included next. These include:

+   - HS – High Speed Oscillator Setting
+   - WDTDIS – Watchdog Timer Disabled
+   - MCLREN – Master Clear Pin Enabled as a Reset Pin
+   - UNPROTECT – Allow the program to be read from the chip
+   - LVPDIS – Disable low voltage programming

```
#include <htc.h>
#include <stdio.h>
__CONFIG (HS & WDTDIS & MCLREN & UNPROTECT & LVPDIS);
```
