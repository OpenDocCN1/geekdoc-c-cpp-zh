## Software Project 1

The first project demonstrates how to use the `lcd_symbol()` function. This SimpleC function is designed to display ASCII characters on the LCD. Any character can be created as long as you know the ASCII value. This project will create a count from 0 to 9 on the LCD by rotating through the ASCII values for the characters 0 to 9. The “How It Works” section of this chapter will describe how it’s done.

```c
/*
This project displays a zero to nine count on the LCD using
the lcd_symbol() function.

LCD
PIN 1 - Gnd
PIN 2 - 5v
PIN 3 - Gnd
PIN 4 - RB4/CHIPINO Pin 12 (RS)
PIN 5 - Gnd
PIN 6 - RB5/CHIPINO Pin 13 (EN)
PIN 7 - NC
PIN 8 - NC
PIN 9 - NC
PIN 10 - NC
PIN 11 - RB0/CHIPINO Pin 8 (DB4)
PIN 12 - RB1/CHIPINO Pin 9 (DB5)
PIN 13 - RB2/CHIPINO Pin 10 (DB6)
PIN 14 - RB3/CHIPINO Pin 11 (DB7)
*/

#include "simplec1.1.h"

void
main(void)
{
init_micro();   // Initialize I/O
lcd_init();     // Initialize LCD Display
lcd_clear();    // Clear LCD screen

while (1==1)
{
for (char x=0;x<10;x=x+1)    // Create count of 0 thru 9
{
lcd_goto(0);        // Select first line
lcd_symbol(0x30+x); // Display decimal value
pause(1000);        // Delay to read display
}
} //End While
} //End Main
```

The screen of the LCD is cleared with the `lcd_clear` function. This clears the screen and positions the cursor at the home or first character block position.

```c
lcd_clear();    // Clear LCD screen
```

Now we enter the main while loop that actually displays the count on the LCD. The while-loop contains a for-loop that creates and increments an 8-bit variable. When the variable equals 10, the for-loop ends.

```c
while (1==1)
{
    for (char x=0;x<10;x=x+1)    // Create count of 0 thru 9
    {
```

The first SimpleC function in the for-loop is the `lcd_goto` function. This function has the parameter 0, so it positions the cursor at the first position of the LCD. This was already done when we cleared the screen, but in the loop we need to reposition it each time.

```c
lcd_goto(0);    // Select first line
```

The next SimpleC function we use is the `lcd_symbol` function. This sends the ASCII value in the parameter section to the LCD. In this case, we send the loop variable value (0–9) to the LCD but first add the hex value 30 to create the proper ASCII value to send. The number 1 has the ASCII value 31 hex, 32 hex is for 2, etc.

```c
lcd_symbol(0x30+x);    // Display decimal value
```

The program then uses the SimpleC `pause` function to delay 1000 milliseconds, or 1 second, before incrementing the variable. This makes the numbers change at a one-second rate. From there, the while-loop ends and so does the main loop, so this code runs over and over again.

```c
pause(1000);    // Delay to read display
} //End While
} //End Main
```

## Software Project 2

Writing ASCII characters to the LCD is useful, but more often you'll probably want to display a full message of text. Sending each individual ASCII character could do this, or you could use the `lcd_text` function in SimpleC. This next project uses that function to display a message on the first and second line of the 2x16 LCD.

```c
/*
This project creates a message on a 2x16 LCD module
using the lcd_text() function.

LCD
PIN 1 - Gnd
PIN 2 - 5v
PIN 3 - Gnd
PIN 4 - RB4/CHIPINO Pin 12 (RS)
PIN 5 - Gnd
PIN 6 - RB5/CHIPINO Pin 13 (EN)
PIN 7 - NC
PIN 8 - NC
PIN 9 - NC
PIN 10 - NC
PIN 11 - RB0/CHIPINO Pin 8 (DB4)
PIN 12 - RB1/CHIPINO Pin 9 (DB5)
PIN 13 - RB2/CHIPINO Pin 10 (DB6)
PIN 14 - RB3/CHIPINO Pin 11 (DB7)

*/

#include "simplec1.1.h"

void main(void)
{
    init_micro();    // Initialize I/O
    lcd_init();      // Initialize LCD Display
    lcd_clear();     // Clear LCD screen

    while (1==1)
    {
        lcd_goto(0);                 // Select first line
        lcd_text("Simple C Makes");  // Display Hello World

        lcd_goto(0x40);              // Select second line
        lcd_text("Programming Easy");

        pause (10000);               // Delay for 1 second to read display
    } //End While
} //End Main
```

The SimpleC `lcd_text` function does the work for us. The parameters of this function are placed between quotes so it knows this is a string. Each letter is then sent as an ASCII value to the LCD module. This displays the message “Simple C Makes” on the first line of the LCD.

```c
lcd_text("Simple C Makes");    // Display Hello World
```

Now the LCD cursor is positioned on the second line with a hex value 40 as the parameter. This is the value for the beginning of the second line. The `lcd_goto` handles the code that indicates this is a command character. After this function runs, the cursor will be at the beginning of the second line.

```c
lcd_goto(0x40);                 // Select second line
```

Now the `lcd_text` function is used to write the second message, which is “Programming Easy”.

```c
lcd_text("Programming Easy");
```

We pause a second and then loop back to write the message again.

```c
pause (10000);           // Delay for 1 second to read display
```

## Next Steps

You could replace the LCD with LEDs to create a bar graph display of light that changes with the turning of the potentiometer. You could also add some other functions, such as the PWM library function, so the potentiometer controls a motor’s speed or an LED’s brightness and still shows the value on the LCD. You could also replace the potentiometer with a light sensor to let the light change the resistance and thus the voltage. This would make a crude light meter. This project is easily adapted to many different analog sensors. Having the LCD readout makes it easy to see the sensor results.
