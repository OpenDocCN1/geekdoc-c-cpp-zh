# i2c_restart()

The i2c_restart() function is used to send a new start bit in the i2c signal. This is used at the beginning of a new i2c communication message. This is commonly used when the first start bit is used to send a message requesting data to be sent back. The example below shows this function used in one of the SimpleC library functions.

Example:

```
```c
unsigned char I2C_EEIN(unsigned char address)
{
unsigned char data;
i2c_start();
i2c_write(0xa0);
i2c_write(address);
i2c_repStart();
i2c_write(0xa1);
data=i2c_read(0);
i2c_stop();
return(data);
}
```

# i2c_stop()

The i2c_stop() function is used to send a stop bit at the end of the i2c signal. This is used to indicate the end of the i2c communication message. The example below shows this function used in one of the SimpleC library functions.

Example:

```
```c
unsigned char I2C_EEIN(unsigned char address)
{
unsigned char data;
i2c_start();
i2c_write(0xa0);
i2c_write(address);
i2c_repStart();
i2c_write(0xa1);
data=i2c_read(0);
i2c_stop();
return(data);
}
```
