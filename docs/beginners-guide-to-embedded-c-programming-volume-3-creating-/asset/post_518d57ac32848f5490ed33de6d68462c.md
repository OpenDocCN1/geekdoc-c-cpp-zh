### Software

The software is easy to follow and understand. If you have ever used a BASIC compiler for PICs it will look very familiar. The SimpleC library has a high and low function for setting pins. The functions set the TRIS register and then write a 1 to the port register pin if using high and writes a 0 if using a low function. The pause function I’ve used in previous books is now part of the SimpleC library so the delay portion is easy to implement. The program just loops through setting and clearing the LED port pin.

```
/*********************************
Flash an LED example using SimpleC
This code will drive an LED on pin 8(RB0)
and flash it on and off at a 1 second rate.
Connections:
PIN 8(RB0) to LED Anode
LED Cathode to 1k ohm
1k ohm to Ground
*********************************/
```

```
#include "simplec1.1.h"
```

```
void
main(void)
{
    init_micro();    // Initialize I/O
    while (1==1)
    {
        high(8);
        pause (1000);    // Delay for 1 second (1.0000 sec)
        low(8);
        pause (1000);    // Delay for 1 second
    }
}
```

### How it Works

The first part of the program just contains a description header indicating what the code does and then describes the electrical connections.

```
/*********************************
Flash an LED example using SimpleC
This code will drive an LED on pin 8(RB0)
and flash it on and off at a 1 second rate.
Connections:
PIN 8(RB0) to LED Anode
LED Cathode to 1k ohm
1k ohm to Ground
*********************************/
```

The SimpleC library is setup with the inclusion of the simplec1.1.h file. All the configuration settings and some of the defines used by the SimpleC library are setup in this header file so all SimpleC files need to include it.

```
#include "simplec1.1.h"
```

The main loop of code starts off with an init_micro function. This function sets the analog pins to digital and turns off any comparators. This was standard code added to every project in my previous books so I reduced it down to one function in the SimpleC library. Needless to say, this should also be part of every SimpleC project file.

```
void
main(void)
{
    init_micro();    // Initialize I/O
}
```

The main loop of code contains the high and low functions along with two pause functions that delay for 1000 milliseconds creating the one second on, one second off blink. The nice feature of the high and low is they control the bit defined by the parameter. These were written to match the numbered pins of the CHIPINO modules. A value of 1 to 13 is allowed, as those are the pin numbers of the CHIPINO. You cannot put pin name such as RB0 in place of the number. You have to stick with the numbering system.

```
while (1==1)
{
    high(8);
    pause(1000);    // Delay for 1 second (1.0000 sec)
    low(8);
    pause (1000);   // Delay for 1 second
}
```

### Next Steps

The options you have for this simple project is really up to your imagination. The high and low functions work on one pin at a time so controlling multiple pins can make a program very easy to write but also very long. I find these functions work best when you just need a simple way to control a pin. With that in mind maybe change the hardware to control a relay or maybe use this simple blink program to create a pulse that controls a servo motor. It can be a great way to demonstrate how controlling a digital pin is at the heart of everything a micro does.

## Chapter 5 – SimpleC Digital Input

Reading an input is not difficult to do in C as I’ve shown in my previous books but I still decided to make a function that could read a port pin easily by setting the TRIS or direction register and then reading the port state for a particular port pin. This project shows how to do that by monitoring a momentary switch and then lighting one LED when the switch is pressed and the other when the switch is idle.

### Hardware

The circuitry for this project is shown in Figure 5-1 and has all the connections to the PIC16F886 shown. The port pin names are on the schematic image of the chip but the CHIPINO Mini numbered pin names are shown on the tabs. The switch is tied to pin 8, which is also RB0. The switch is pulled high to V+ during its normally open idle state. When the switch is pressed, the RB0/8 pin will see a low or ground value. The LEDs are tied to pin 9 and 10 of the CHIPINO Mini module.

![](img/910b145bee7ca8076318eafbe6d13997_116_0.png)

### Figure 5-1: SimpleC Input Schematic

The breadboard setup, in Figure 5-2A, shows the connections that you can match with your own breadboard setup. The module is offset to the bottom of the breadboard so all the port wires can run across the top. The power comes in through the programmer connected to the CHIPINO Mini module that supplies power to the rails through two jumpers. The upper rail has the negative on the outer row while the inner row is the positive. On the bottom of the breadboard the inner row is negative via the long jumper from top to bottom. Figure 5-2B shows the same setup using the CHIPINO module.

![](img/910b145bee7ca8076318eafbe6d13997_117_0.png)

### Figure 5-2A: Breadboard Setup

Now that we have the state of the switch stored we can test it to perform different operations. If the value is 1 or switch is idle, then using the high and low functions we turn on one LED and turn off the other. If the switch is pressed then the reverse lighting of the LEDs occurs. This runs continuous so we can see any press or release of the switch quickly.

```
if (value == 1)
{
    //*** Switch is idle ***
    high(11);     // Pin 11 LED on
    low(10);      // Pin 10 LED off
}
else
{
    //*** Switch is Pressed ***
    low(11);      // Pin 11 LED off
    high(10);     // Pin 10 LED on
}
}
```

### Next Steps

An obvious next step is to change what happens when the switch is pressed. As you get more knowledgeable of the SimpleC library you will find it very easy to display something on an LCD or to send a SPI or I2C signal when the switch is pressed.
