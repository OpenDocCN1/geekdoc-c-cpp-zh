The library function to control a Microchip MCP23S08 I/O expander uses some predefined names for registers the micro will control. This set of defines is for that section of code.

```
// ****************************************
// External MSP23S08 I/O Expander Write
// ****************************************

#define IODIR 0x00  // Data Direction Register
#define OLAT  0x0A  // Output Latch Register
#define GPIO  0x09  // Port Register
```
