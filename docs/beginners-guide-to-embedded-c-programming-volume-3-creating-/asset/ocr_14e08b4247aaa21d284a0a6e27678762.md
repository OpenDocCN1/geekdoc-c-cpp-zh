# Next Steps

These projects demonstrate how easy SimpleC makes using the hardware SPI peripheral can be. I will be using this often and I've often wanted to use the MCP23S08 and its 16 I/O cousin the MCP23S16 in many projects but really didn't feel like reading over the data sheet and working through all the registers when I could just use a larger PIC to get more I/O. But now that I've taken the time to create a function for the MCP23S08 I will use them more.

As a next step you could expand the projects to control more I/O on the MCP23S08 and create a whole string of LEDs or multiple switches. This can easily be accomplished with small modifications to these projects. Now if you really want to go further then maybe tie in the EEPROM with a separate chip select (CS) control line for each. This will require you to make modifications to the SimpleC files but should not be difficult. Then you can control more than one SPI device from the PIC.
