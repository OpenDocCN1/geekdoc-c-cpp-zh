```
// ****************************************
// Hardware SPI Setup
// ****************************************

/* SPI Peripheral Setup */
void spi_init(void)
{
// *** 16F886 Settings ***
TRISC5 = 0; // SDO pin set to output
TRISC3 = 0; // SCK pin set to output (Master Mode)
TRISA5 = 0; // CS pin set to output

/* SSPCON Settings */
// *** FOSC = 4Mhz ***
// SSPCON = 0b000000001; // SPI Clock Frequency set to FOSC/16 = 250khz

// *** FOSC = 16Mhz ***
SSPCON = 0b00000010; // SPI Clock Frequency set to FOSC/64 = 250khz
CKP = 0; // Idle state of clock is low

/* SSPSTAT Settings */
SMP = 1; // Sampled at end of data pulse
CKE = 1; // Data Transfered on rising edge of clock

/* SPI Peripheral on */
SSPEN = 1; // Enable SPI peripheral
pause(1); // Allow SPI to Stabilize
}
```

The SPI peripheral will send a bit out the SDO pin (Master Out Slave In) while it clocks in data at the SDI pin (Master In Slave Out). Therefore one function can handle it all. SPI_OUTPUT() is that function and first stores the byte defined in the parameter section of the function inside the internal SPI buffer register. The SPI hardware will then automatically send out that byte and then receive a byte in the receive buffer. The function returns the byte received to the routine that called this function.

```
// ****************************************
// Hardware SPI Output
// ****************************************

char SPI_OUTPUT ( char spi_byte )
{
SSPBUF = spi_byte;
do {
}
while(!IBF);
return SSPBUF;
}
```
