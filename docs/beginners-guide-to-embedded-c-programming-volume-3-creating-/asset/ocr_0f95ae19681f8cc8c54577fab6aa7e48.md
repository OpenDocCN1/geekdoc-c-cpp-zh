# I2C Communication

As I showed in the previous chapter, I2C communication is useful for communicating with external circuitry. The I2C peripheral shares many of its communication I/O with the SPI peripheral on the PIC16F886. Therefore you will use either SPI or I2C but not both at the same time. These SimpleC functions make it easier to use the I2C peripheral.

# i2c_init()

The i2c_init function sets up the i2c port for serial communication as a master. The i2c connections are preset in the peripheral. Pin 4 (C3) is the clock, pin 3 (C4) is the data line. In order to use the i2c peripheral, the i2c_init must be at the top of your main loop.

Example:
