Step four of the project setup process is where you add any pre-written C files. Typically you will modify an existing file to save time rather than start from scratch. In the left window you scroll to find the flash LED file. Highlight that file by clicking on it and then click on the “Add >>” button. It should appear on the right side of the screen. If you cannot find the LED file then download the files from my website and store them at a known location on your computer.

Next to the selected file you’ll see a big “A”. If you click on this several times you will see a “C” appear next to it. The “C” will force a copy of the file to be saved in the directory you created back at screen three. I like to do this so I keep all my changes in one directory and leave the original files intact.
