The SimpleC include file is added and then the main loop with the init functions for this project.

```
#include "simplec1.1.h"

void
main(void)
{
init_micro();
spi_init();
}
```

The WR_MCP23S08 function is used to set all pins to outputs by writing all zeros to the IODIR register.

```
WR_MCP23S08 (IODIR, 0x00);  // Setup pins as outputs
```

The while loop contains a for loop that counts through 4 cycles. Each cycle increments the variable x by one. This variable is then multiplied by 64 to shift the bits to the GP6 and GP7 pins of the MCP23S08. The WR_MCP23S08 function can handle the math within its parameter section prior to writing the value to the OLAT register. A one second delay is added to create a one second binary counter.
