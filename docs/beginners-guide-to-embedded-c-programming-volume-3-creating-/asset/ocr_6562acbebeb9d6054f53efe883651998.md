CHIPINO/Arduino style pin numbers and built in fixed speed oscillator. The CHIPINO-mini module shown in Figure 1-4 was the compromise and available at chipaxe.com. It's a CHIPAXE style board with the pin numbers to match the CHIPINO module. The board has a 16 Mhz resonator built in along with a 10k reset pin pull-up resistor. This board plugs into a large breadboard and gives me the opportunity to build my circuits on independent breadboards.

Despite the fact I chose the CHIPINO-mini doesn't mean you are locked into any of these choices. Any board that uses the 28 pin PIC16F886 can work with the projects in this book.

No matter which one you choose, one thing they all have in common is a need for a set of simple pre-written functions to make them easier to use. So I decided to create a library of functions based on the code developed for Volume 1 and Volume 2 of this series plus some new useful functions. It also gave me a reason to improve the code to be a bit more universal.

Creating the SimpleC library is the focus of this book. I covered the hardware, compiler and programming software setup in the first two books but realized a few people may be reading this Volume 3 book first. For those readers, I'll cover the hardware programmer topic again with a little more detail so you understand how to use these modules with the projects in this book.
