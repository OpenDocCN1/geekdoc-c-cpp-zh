# Figure 11-6: UART Screen Capture

The last thing shown is the CHIPINO asking the user to either press a keyboard key or to enter a character in the Send box in the lower middle of the screen. That character will be read by the CHIPINO and then sent back demonstrating two-way communications. Figure 11-7 shows the results when a capital A is sent to the CHIPINO from the Send window.

This operation will continue until the Disconnect button is pressed in the upper left corner of the screen. You can also see in the lower left the connections to the PICkit 2, which is helpful if you are using this tool in the future and forget the connection scheme.
