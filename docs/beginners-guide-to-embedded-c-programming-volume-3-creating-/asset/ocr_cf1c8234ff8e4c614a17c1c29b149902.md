The RD_MCP23S08 function from the SimpleC library is used to test the state of the switch. It actually reads the state of all the pins so we have to use a binary AND function to only see the GP0 bit. After this the y variable will contain the state of the switch.

```
y = RD_MCP23S08 (GPIO); // Read switch
y = y & 0x01;           // Mask all but bit 7
```

We test the y variable to see if it’s zero indicating the switch was pressed. If the switch is pressed we use the WR_MCP23S08 function to write to the latch register OLAT which was defined in the simplec1.1h file. We set the GP6 bit to a one to light that LED if the switch is pressed. If the y variable in one meaning the switch is idle then the OLAT register is set to make the GP7 bit a one and light that LED instead.

```
if (y==0)
    {WR_MCP23S08 (OLAT, 0x40);}  // If switch idle light LED
else
    {WR_MCP23S08 (OLAT, 0x80);}  // If switch pressed LED off
```

We delay for 10 milliseconds using the pause function from the SimpleC library and then loop back to the beginning of the while loop.

```
    pause(10);
} //End While
```

Finally we end this short program with a bracket for the main loop.
