# Software

The software is easy to follow and understand. If you have ever used a BASIC compiler for PICs it will look very familiar. The SimpleC library has a high and low function for setting pins. The functions set the TRIS register and then write a 1 to the port register pin if using high and writes a 0 if using a low function. The pause function I’ve used in previous books is now part of the SimpleC library so the delay portion is easy to implement. The program just loops through setting and clearing the LED port pin.
