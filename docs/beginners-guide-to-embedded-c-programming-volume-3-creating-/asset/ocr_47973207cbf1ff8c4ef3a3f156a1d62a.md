# Next Steps

The most logical next step is to expand this code to control two servomotors and actually drive a servo robot with them. If you are not that familiar with servomotors, driving the servo with a 1.5 millisecond pulse should pause the servomotors or make the robot stop.

Another advantage the pulseout function offers is the ability to drive any of the digital CHIPINO pins. With a little extra code, you can create a PWM signal on any digital pin. The snippet of code below creates a slow 100 hz signal with a duty cycle that sweeps from 20% to 80% and then back from 80% down to 20%. Just replace the for-loops in the servo code with these and you should get what I describe.

```
/*
Create a slow PWM signal on CHIPINO pin 2 using the pulseout function
*/

for(int dc=200; dc<800; dc++)
{
    pulseout(2,dc);      //Send increasing Duty Cycle
    pauseus(1000-dc); //Send low delay to create 100hz
}

for(int dc=800; dc>200; dc--)
{
    pulseout(2,dc);      //Send decreasing duty cycle
    pauseus(1000-dc); //Send low delay to create 100hz
}
```
