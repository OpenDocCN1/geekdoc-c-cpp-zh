# high(pin)

Make the specified pin high. pin is automatically made an output. pin may be a constant, 0-13, or a variable that contains a number 0-13.

Examples:

```
while()
{
  high(5); // Make pin5 (C2) an output and set it high (~5 volts)
}
```

or

```
#define led 8 // Define Pin 8 (RB0) as connected to LED

while()
{
  high(led);  //Make LED pin an output and set it high (~5 volts)
}
```

# low(pin)

Make the specified pin low. pin is automatically made an output. pin may be a constant, 0-13, or a variable that contains a number 0-13.

Examples:

```
while()
{
  low(5); // Make pin5 (C2) an output and set it low (~0 volts)
}
```

or

```
#define led 8 // Define Pin 8 (RB0) as connected to LED

while()
{
  low(led);  //Make LED pin an output and set it low (~0 volts)
}
```
