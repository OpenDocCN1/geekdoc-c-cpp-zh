I was introduced to an early prototype of the CHIPINO module that matched the footprint of the popular Arduino module (Figure 1-3). This setup offered a plug in board that contains a small breadboard on top so you can again build your circuit and then unplug it for reference later. I was able to be part of the team that improved this module to the present form shown at the chipaxe.com site. This board has a power port with built in 5v and 3v regulator so I can easily connect a 9v power adapter or 9v battery to this setup. The I/O is all brought out to the headers on the edges so custom boards can be easily plugged in on top of the main board. There are already many plug-in boards, or shields as they are called, for the similarly styled Arduino module. Many of the Arduino shields can plug into this CHIPINO board. This will make future books and projects much easier to setup since the hardware is already created.
