# LCD Character Module Control

A 2x16 LCD is a common way to display messages from the microcontroller. The setup and control of a 2x16 LCD is simplified with the functions in the SimpleC library.

# lcd_init()

The lcd_init function establishes the connections for a 2x16 LCD character module controlled by PORTB (pins 8-13). The DB0-DB3 pins of the LCD are connected to B0 thru B3 (pins 8-11) respectively. The RS pin is connected to B4 (pin 12) and the EN pin is connected to B5 (pin13).

Before using any of the LCD commands, the lcd_init() must be issued. It's best to put it at the top of a program.

Example:

```
void
main(void)
{
init_micro();    // Initialize I/O
lcd_init();      // Initialize LCD Display
lcd_clear();     // Clear LCD screen

while (1==1)
{
lcd_goto(0);            // Select first line
lcd_text("Simple C Make");  // Display Hello World
lcd_goto(0x40);         // Select second line
lcd_text("Programming Easy");// Display message between quotes
pause(1000);            // Delay for 1 second to read display
}
}
```

# lcd_clear()

The lcd_clear function will clear the screen of a 2x16 LCD character module. The cursor will also be located to the upper left corner of the display which is typically called location zero.

The lcd_clear() function is typically placed at the top of the program to start but can be used throughout the program to clear the screen before writing a new message.
