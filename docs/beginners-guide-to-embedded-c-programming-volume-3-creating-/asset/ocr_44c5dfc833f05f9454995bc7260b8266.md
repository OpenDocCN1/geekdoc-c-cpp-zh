# getch ()

The getch function is not necessarily a SimpleC only function. It is part of a separate standard library included with the HI-TECH compiler. This function is used to receive a byte of data into the serial port. The statement will require a variable to store the received data.

Example:

```
void main(void){
    init_micro();      // Setup micro ports
    init_serial(9600); // set up the USART baud rate (2400 or 9600)

    // **** Use printf command to ask for input and echo it back ******
    while(1)
    {
        printf("Press a key and I will echo it back:\r\n");
        char input = getch(); // read a response from the user
        printf("I detected [%c]\r\n",input);  // echo it back
    }
}//end main
```

# printf (characters)

The printf function is not necessarily a SimpleC only function. It is part of a separate standard library included with the HI-TECH compiler. This function is used to format data sent or printed on the specified peripheral. In this SimpleC library it is used to format the serial port data send to a terminal program. Below are some of the options you can use in the printf character area.

The format characters and their meanings are:

+   - \" double quote
+   - \\ backslash
+   - \a alert (BEL)
+   - \b backspace
