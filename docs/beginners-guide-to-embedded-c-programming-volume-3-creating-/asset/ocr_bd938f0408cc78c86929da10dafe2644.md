# SPI Communication

Serial Peripheral Interface (SPI) is often used to communicate with external circuitry. The SPI port on the PIC16F886 is a hardware peripheral that runs in the background. So setting it up and running it is simplified with the SimpleC library functions below. The peripheral is only setup as a SPI master not a slave.

# spi_init()

The spi_init function sets up the SPI port for serial communication as a master. The spi connections are preset in the peripheral. Pin 4 (C3) is the clock, pin 3 (C4) is the Master Out Slave In (MOSI or SDO), pin 2 (C5) is the Master In Slave Out (MISO or SDI). In order to use the spi peripheral, the spi_init must be at the top of your main loop.

Example:

```
//*****Sample code to control an MCP23S08 SPI I/O Expander***
void main(void)
{
init_micro();
spi_init();
WR_MCP23S08 (IODIR, 0x01);    // Setup pins
while (1==1)
{
char y = 1;
y = RD_MCP23S08 (GPIO); // Read switch
y = y & 0x01;           // Mask all but bit 7
if (y==0)
{WR_MCP23S08 (OLAT, 0x40);} // If switch idle light LED
else
{WR_MCP23S08 (OLAT, 0x80);} // If switch pressed LED off
pause(10);
} //End While
} //End Main
```

# spi_output (byte)

The spi_output function stores the byte value in the SPI peripheral buffer so it can be sent by the peripheral to the SPI slave device.
