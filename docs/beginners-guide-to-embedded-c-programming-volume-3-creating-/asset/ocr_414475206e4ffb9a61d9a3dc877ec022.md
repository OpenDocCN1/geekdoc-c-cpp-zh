```
// External I/O Expander Write
// ****************************************
void WR_MCP23S08 ( char regist, char data )
{
    char dummy;
    CS = 0;                     // Select MCP23S08 by pulling CS low
    dummy = SPI_OUTPUT ( 0x40 ); // Send Device Opcode, select Write mode
    dummy = SPI_OUTPUT ( regist ); // Send Register Address location
    dummy = SPI_OUTPUT ( data ); // Send Data byte
    CS = 1;                     // Release EEPROM to allow byte to be written
}
```

Reading from the MCP23S08 is completed with the RD_MCP23S08 () function.

```
// ****************************************
// External I/O Expander Read
// ****************************************

char RD_MCP23S08 ( char regist )
{
    char dummy;
    CS = 0;                     // Set chip select low
    dummy = SPI_OUTPUT (0x41); // Send Device Opcode, select Read mode
    dummy = SPI_OUTPUT (regist); // Send Address
    char data = SPI_OUTPUT ( 0x00 ); // Receive data byte
    CS = 1;                     // Bring chip select high to terminate
    return data;
}
```

*Special Note: Notice that I used all capital letters for the special SPI functions. I did this to separate part specific functions from the generic library functions. When you use these, make sure you use capital letters.*

One of the more popular requests I received from the previous books was a simpler way to control the hardware PWM port. The PIC16F886 has two of them so I created two PWM functions; pwmout1 () and pwmout2 (). The parameters of the function define the duty cycle and the frequency. Since both PWM’s must use the same clock source on the PIC16F886, they have to have the same frequency. All the register settings are handled in the function so you don’t need to issue a pwm_init function. Once turned on though, the PWMs continue to run. If you want to shut them off you place a CCP1CON == 0 to shut off PWM 1 and CCP2CON to shut off PWM 2.
