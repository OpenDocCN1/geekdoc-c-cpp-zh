# # 白内障

白内障是眼睛的晶状体发生混浊、透明度下降，导致光线无法正常投射到视网膜上，从而引起视力模糊甚至失明的一种常见眼科疾病。本病多见于中老年人，也可由外伤、代谢异常、药物或先天性因素引起。

# ## 白内障的常见症状

+   - 视力进行性模糊，像隔着一层雾
+   - 出现重影或眩光，尤其夜间明显
+   - 对光线和颜色敏感度下降
+   - 佩戴眼镜度数频繁变化
+   - 暗光环境下视物困难

当出现上述症状时，建议及时到医院眼科就诊，通过裂隙灯等专业设备检查晶状体的混浊程度，明确诊断并制定合适的治疗方案。
