# simplec1.1.c – How it Works

I've covered the basics of the SimpleC library and the guts of the SimpleC.h file. For those that want to understand the guts of this library I'll now get into the heart of the code. This is where all the functions created in Volume I and Volume 2 of this series comes together along with some new ones I wrote for this book. I'll take each block and try to explain what I'm doing.

The first part of the simplec1.1.c file is to include the header file.

```
#include "simplec1.1.h"
// Library Functions
```

The first function is the init_micro (). The registers are set to make the analog pins digital and turn off the comparators. I also included the settings for using the internal oscillator but commented that out for now. This would require everything adjusted for the slower internal clock. The final uncommented step is to disable any interrupts.

```
//*******************************
// Initialize Microcontroller Setup
//*******************************

void init_micro(void)
{
    ANSEL = 0;        //Analog ports set to digital
    ANSELH = 0;
    CM1CON0 = 0;      //Comparators Shut off
    CM2CON0 = 0;
    // IRCPF0 = 0;      // Set internal Oscillator to 4 Mhz
    // IRCPF1 = 1;
    // IRCPF2 = 1;
    // SCS = 1;         // Config bits define clock
    INTCON=0;          // purpose of disabling the interrupts
}
```
