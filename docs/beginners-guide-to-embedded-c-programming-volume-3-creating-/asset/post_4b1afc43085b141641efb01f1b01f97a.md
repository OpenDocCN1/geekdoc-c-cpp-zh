// *******************************************
// I2C_EEIN function to read from an 8-bit address Microchip
// EEPROM part (i.e. 24LC01) with 8 byte address (2k bit max)
// *******************************************
unsigned char I2C_EEIN(unsigned char address)
{
    unsigned char data;

    i2c_start();
    i2c_write(0xA0);
    i2c_write(address);
    i2c_repStart();
    i2c_write(0xA1);
    data=i2c_read(0);
    i2c_stop();
    return(data);
}

## Initialization and Time Delays

The first set of functions in the SimpleC library address the microcontroller initialization, time base and basic I/O control. The configuration settings and some I/O definitions are in the simplec1.1.h file which I’ll cover later. The rest of the initializations are handled by these functions so let me summarize them here.

### high(pin)

Make the specified pin high. pin is automatically made an output. pin may be a constant, 0-13, or a variable that contains a number 0-13.

Examples:

```
while()
{
  high(5); // Make pin5 (C2) an output and set it high (~5 volts)
}
```

or

```
#define led 8 // Define Pin 8 (RB0) as connected to LED

while()
{
  high(led);  //Make LED pin an output and set it high (~5 volts)
}
```

### low(pin)

Make the specified pin low. pin is automatically made an output. pin may be a constant, 0-13, or a variable that contains a number 0-13.

Examples:

```
while()
{
  low(5); // Make pin5 (C2) an output and set it low (~0 volts)
}
```

or

```
#define led 8 // Define Pin 8 (RB0) as connected to LED

while()
{
  low(led);  //Make LED pin an output and set it low (~0 volts)
}
```

### input(pin)

Make the specified *pin* an input and return the state of the pin. The function must be preceded by a variable to receive the state. *pin* may be a constant; 0–13, or a variable that contains a number 0–13.

**Example:**

```
while()
{
char var = input(8);  // Store a 1 (high) or 0 (low) in the variable per pin 8 level
}
```

### pulseout(pin,period)

pulseout generates a pulse on *pin* of specified *period*. The pulse is generated by toggling the pin high, delaying and then low. *pin* is automatically made an output. *pin* and *period* may be a constant; 0–13, or a variable that contains a number 0–13.

The resolution of pulseout is 10usec increments. So a *period* value of 25 creates a pulse of 250 microseconds long.

```
while()
{
pulseout(5,100); // Send a pulse 1000 microseconds long (1 msec) on pin5
}
```

### adcin(pin)

The adcin function converts a voltage sensed on an analog pin to a digital value from 0 to 255 (8-bit resolution). The parameter *pin* designates which analog pin to sense and convert. SimpleC supports 5 analog pins numbered 0 thru 4. This correlates to the AN0 thru AN4 pins of the Microchip PIC. The function is actually used in an equation that puts the result in a variable. The voltage can range from 0v to 5v but never exceed this range.

Example

```
while()
{
char var = adcin(1)    // Convert voltage on AN1 pin and store in variable var
}
```

## LCD Character Module Control

A 2x16 LCD is a common way to display messages from the microcontroller. The setup and control of a 2x16 LCD is simplified with the functions in the SimpleC library.

### lcd_init()

The lcd_init function establishes the connections for a 2x16 LCD character module controlled by PORTB (pins 8-13). The DB0-DB3 pins of the LCD are connected to B0 thru B3 (pins 8-11) respectively. The RS pin is connected to B4 (pin 12) and the EN pin is connected to B5 (pin13).

Before using any of the LCD commands, the lcd_init() must be issued. It's best to put it at the top of a program.

Example:

```
void
main(void)
{
init_micro();    // Initialize I/O
lcd_init();      // Initialize LCD Display
lcd_clear();     // Clear LCD screen

while (1==1)
{
lcd_goto(0);            // Select first line
lcd_text("Simple C Make");  // Display Hello World
lcd_goto(0x40);         // Select second line
lcd_text("Programming Easy");// Display message between quotes
pause(1000);            // Delay for 1 second to read display
}
}
```
