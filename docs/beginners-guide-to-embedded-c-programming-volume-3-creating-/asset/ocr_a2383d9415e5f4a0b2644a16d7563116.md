One of the features of the standalone software is the built-in UART tool. This is a terminal program that uses the PICkit 2 programmer as a PIC to USB communication channel. You launch the software from the tools menu as shown in Figure 11-5.

# Figure 11-5: UART Tool Selection

As you can see in Figure 11-5, I ran the standalone software with the MPLAB software in place. You could deselect the PICkit 2 from the MPLAB programmer menu to be safe but it worked fine for me with it still selected.

When the UART tool is run you’ll see the screen in Figure 11-6. The upper right hand corner shows the baud rate as 9600. The screen shows the software was running in the CHIPINO when this was captured as it shows the text sent by the CHIPINO to the UART screen through the PICkit 2 connection.
