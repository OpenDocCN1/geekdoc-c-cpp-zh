
在派生类中声明的成员，以及失去对派生类成员函数的访问。

问：如果无法从抽象类实例化任何对象，那抽象类有什么用？

答：抽象类可能非常有用。它们可以包含许多其他类将继承的公共类成员，这省去了你一遍又一遍定义这些成员的麻烦。
