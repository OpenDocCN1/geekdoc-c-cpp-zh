    }

    const int ROWS = 5;
    const int COLUMNS = 3;
    for (int i = 0; i < ROWS; ++i)

## 嵌套for循环

你可以通过将一个for循环放入另一个for循环中来嵌套它们。这就是我在下面的代码部分中所做的，它计算了一个网格的元素。外部循环从以下代码开始：

```
for (int i = 0; i < ROWS; ++i)
```

它简单地执行其循环体ROWS（五）次。但恰好这个循环内部还有另一个for循环，它从以下代码开始：

```
for (int j = 0; j < COLUMNS; ++j)
```

因此，内部循环在外部循环的每次迭代中都会完整执行。在这种情况下，这意味着内部循环执行COLUMNS（三）次，而外部循环迭代ROWS（五）次，总共执行15次。具体来说，发生的情况如下：

- 1. 外部for循环声明i并将其初始化为0。由于i小于ROWS（5），程序进入外部循环体。
- 2. 内部循环声明j并将其初始化为0。由于j小于COLUMNS（3），程序进入其循环体，将i和j的值发送给cout，显示0, 0。
- 3. 程序到达内部循环体的末尾，将j增加到1。由于j仍小于COLUMNS（3），程序再次执行内部循环体，显示0, 1。
- 4. 程序到达内部循环体的末尾，将j增加到2。由于j仍小于COLUMNS（3），程序再次执行内部循环体，显示0, 2。
- 5. 程序到达内部循环体的末尾，将j增加到3。然而这次，j不小于COLUMNS（3），内部循环结束。
- 6. 程序通过向cout发送endl来完成外部循环的第一次迭代，结束第一行。
- 7. 程序到达外部循环体的末尾，将i增加到1。由于i小于ROWS（5），程序再次进入外部循环体。
8. 程序到达内部循环，该循环再次从头开始，声明并将j初始化为0。程序重复我在步骤2到7中描述的过程，显示网格的第二行。这个过程持续进行，直到所有五行都被显示出来。

再次强调，要记住的重要一点是，内部循环在外部循环的每次迭代中都会完整执行。

## 理解对象

到目前为止，你已经了解了如何在变量中存储单个信息片段，以及如何使用运算符和函数操作这些变量。但你在游戏中想要表示的大多数东西——例如，一艘外星飞船——都是对象。它们是封装的、内聚的事物，结合了各种属性（如能量级别）和能力（例如，发射武器）。通常，单独讨论这些属性和能力是没有意义的。

幸运的是，大多数现代编程语言允许你使用将数据和函数结合在一起的软件对象（通常简称为对象）。对象的数据元素称为数据成员，对象的函数称为成员函数。作为一个具体例子，考虑那艘外星飞船。一个外星飞船对象可能是一种名为Spacecraft的新类型，由游戏程序员定义，并且可能有一个用于其能量级别的数据成员和一个用于发射武器的成员函数。实际上，对象的能量级别可能存储在其int类型的数据成员energy中，而其发射武器的能力可能定义在名为fireWeapons()的成员函数中。

同一类型的每个对象都有相同的基本结构，因此每个对象将具有相同的数据成员和成员函数集。然而，作为个体，每个对象的数据成员都有自己的值。如果你有一个由五艘外星飞船组成的飞行中队，每艘飞船都会有自己的能量级别。一艘可能有75的能量级别，而另一艘可能只有10，等等。即使两艘飞船具有相同的能量级别，它们也各自属于一个独特的飞船。每艘飞船还可以通过调用其成员函数fireWeapons()来发射自己的武器。

对象的一个酷之处在于，你不需要知道实现细节就可以使用它们——就像你不需要知道如何制造汽车就可以驾驶汽车一样。你只需要知道对象的数据成员和成员函数——就像你只需要知道汽车的转向盘、油门踏板和制动踏板在哪里一样。

你可以像使用内置类型一样将对象存储在变量中。因此，你可以将外星飞船对象存储在Spacecraft类型的变量中。你可以使用成员选择运算符（.）访问数据成员和成员函数，方法是将该运算符放在对象的变量名之后。因此，如果你希望你的外星飞船ship仅在其能量级别大于10时发射武器，你可以编写：

```
// ship is an object of Spacecraft type
if (ship.energy > 10)
{
    ship.fireWeapons()
}
```

## 索引string对象

string对象存储一系列char值。你可以通过使用下标运算符（[]）提供索引号来访问任何单独的char值。这就是我接下来要做的：

```
cout << "The character at position 0 is: " << phrase[0] << "\n\n";
```

序列中的第一个元素位于位置0。在前面的语句中，phrase[0]是字符G。由于计数从0开始，所以字符串对象中的最后一个字符是phrase[11]，即使该字符串对象有12个字符。

### 陷阱

> 一个常见的错误是忘记索引从位置0开始。记住，一个有n个字符的string对象可以从位置0到位置n−1进行索引。

你不仅可以使用下标运算符访问string对象中的字符，还可以重新赋值。这就是我接下来要做的：

```
phrase[0] = 'L';
```

我将phrase的第一个字符改为字符L，这意味着phrase变为"Lame Over!!!"。

### 陷阱

> C++编译器在处理string对象和下标运算符时不会执行边界检查。这意味着编译器不会检查你是否试图访问不存在的元素。访问无效的序列元素可能会导致灾难性后果，因为可能会覆盖计算机内存中的关键数据。这样做可能会使程序崩溃，因此在使用下标运算符时要小心。

## 遍历string对象

鉴于你对for循环和string对象的新知识，遍历string对象的各个字符是一件轻而易举的事。这就是我接下来要做的：

```
for (unsigned int i = 0; i < phrase.size(); ++i)
{
    cout << "Character at position " << i << " is: " << phrase[i] << endl;
}
```

该循环遍历`phrase`的所有有效位置。它从0开始，一直到11。在每次迭代中，`string`对象的一个字符通过`phrase[i]`显示。请注意，我将循环变量`i`设为unsigned int，因为`size()`返回的值是unsigned整型。

## 现实世界

遍历序列是游戏中强大且经常使用的技术。例如，你可能在策略游戏中遍历数百个独立单位，更新它们的状态和命令。或者你可能遍历3D模型的顶点列表以应用一些几何变换。

## 使用find()成员函数

接下来，我使用成员函数`find()`来检查两个字符串字面量中的任何一个是否包含在`phrase`中。首先，我检查字符串字面量"Over"：

```
cout << "\nThe sequence 'Over' begins at location ";
cout << phrase.find("Over") << endl;
```

`find()`成员函数在调用它的字符串对象中搜索作为参数提供的字符串。该成员函数返回你搜索的字符串对象在调用它的字符串对象中首次出现的位置编号。这意味着`phrase.find("Over")`返回"Over"在`phrase`中首次出现的位置编号。由于`phrase`是"Lame Over!!!"，`find()`返回5。（记住，位置编号从0开始，所以5意味着第六个字符。）

但如果你搜索的字符串在调用它的字符串中不存在怎么办？接下来我处理这种情况：

```
if (phrase.find("eggplant") == string::npos)
{
    cout << "'eggplant' is not in the phrase.\n\n";
}
```

由于`phrase`中不存在"eggplant"，`find()`返回一个定义在文件`string`中的特殊常量，我通过`string::npos`访问它。因此，屏幕显示消息：“'eggplant' is not in the phrase.”
