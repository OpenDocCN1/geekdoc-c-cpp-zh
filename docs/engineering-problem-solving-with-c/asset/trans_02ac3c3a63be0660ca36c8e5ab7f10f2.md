## C++ 语句摘要

文件流对象的声明：

```
ifstream sensor1;
ofstream balloon;
```

文件打开函数：

```
//filename is a string object
sensor1.open(filename);
balloon.open(filename);
```

文件失败函数：

```
if(sensor1.fail())
```

文件输入：

```
sensor1 >> t >> motion;
```

文件输出：

```
balloon << setw(8) << time << setw(8) << height << setw(8) << velocity;
```

标准错误输出：

```
cerr << "Error encountered on input";
```

文件关闭函数：

```
sensor1.close();
```

流清除函数

```
sensor1.clear()
```
