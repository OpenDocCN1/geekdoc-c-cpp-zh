# 2.3 C++ Classes

C++ supports the use of classes to define new data types, often referred to as programmer defined data types. Programmer defined data types are useful for defining new data types that model real world objects. In the previous section, we looked at examples using built-in data types including int, double and char, and we discussed the predefined data type, string. Suppose we are working on an application that manipulates points in a plane. There is no built-in data type for defining a point, but we can define a new data type to model a point using the C++ keyword class. In this section, we will introduce the basic syntax for defining a C++ class, and define a new data type to model a point in a plane.

A point in a plane is an object defined by a (x, y) coordinate. The coordinate is a physical attribute and can be represented by data. For this example, we will use the built-in data type double to represent the values of the (x, y) coordinate. In addition to the physical attributes of a point, we have to consider what operations we want to perform on a point. Of course, we have to be able to create new points. We may also want to move an existing point or determine the distance between two existing points or print the coordinate of an existing point. Physical attributes and operations are defined for a new data type within a C++ class.

The definition of a C++ class consists of two parts: a class declaration and a class implementation. In general, the class declaration and the class implementation are contained in separate files. The convention is to name the class declaration file with a .h extension and class implementation file with a .cpp extension.
