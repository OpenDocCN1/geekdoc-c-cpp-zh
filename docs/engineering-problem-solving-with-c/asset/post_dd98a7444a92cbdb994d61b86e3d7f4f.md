## 10.2 Building C++ Solutions with IDEs: Xcode Image Files

Digital images can be stored in a variety of file formats, including CGM and SVG formats when working with vector graphics and JPEG, GIF, TIFF and PPM formats when working with raster graphics. Numerous software packages are available for viewing, converting, and modifying digital images.

Raster graphics is commonly used for storing digital images on the Internet. Raster images are defined as a rectangular grid of picture elements, or pixels. The grid is referred to as a bitmap or pixel map. The size of the bitmap is defined by a width and height, in pixels. In the case of color images, each pixel represents a color value defined as a red, green, and blue triple (R, G, B). The values of R, G, and B range from zero to a maximum color value, specified within the image file.

The PPM (Portable Pixel Map) format is one of a collection of file formats developed to represent raster images. The PPM images provided in Figure 10.3 were generated by a C++ program. The output files generated by the C++ program were named `YellowCircle.ppm` and `YellowBox.ppm`. A PPM file requires a header that must be preserved in order to view or convert the image. The header contains a “magic number” (P3 for PPM files), possible comment lines (comment lines begin with a # and end with a newline), the width and height of the image, and the maximum color value.
