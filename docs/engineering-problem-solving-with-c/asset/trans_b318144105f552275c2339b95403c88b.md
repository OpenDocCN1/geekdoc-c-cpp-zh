## C++ 语句摘要

指针声明：

一般形式：

数据类型 *标识符 [,*标识符];

示例：

int *ptr_1;
double a, *ptr_2=&a;

动态内存分配：

一般形式：

指针对象 = new 数据类型;

示例：

ptr = new double;

动态内存释放：

一般形式：

delete 指针对象;

动态数组内存分配：

arr_ptr = new double[100];

动态数组释放：

一般形式：

delete []指针对象;

- 注意
- 1. 为指针选择的标识符应清楚地指示该标识符与指针对象相关联。
- 2. 如果指针最初未分配给内存位置，则将其赋为字面值 nullptr，以指示它不指向任何对象。

- 注意
- 1. 确保程序在其他语句中使用对象的值之前对其进行初始化。
- 2. 确保指针对象在用于引用值之前已初始化。
- 3. 函数中与指针参数对应的实际参数必须是地址或指针。
