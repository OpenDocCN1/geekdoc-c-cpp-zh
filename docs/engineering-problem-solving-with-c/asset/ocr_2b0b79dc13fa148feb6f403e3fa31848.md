Logarithms to the base $b$. To compute the logarithm of $x$ to base $b$, we can use the following relationship

$$\log_b x = \frac{\log_2 x}{\log_2 b}$$

+   41. Write a program that reads a positive number and then computes and prints the logarithm of the value to base 2. For example, the logarithm of 8 to base 2 is 3 because $2^3 = 8$.

+   42. Write a program that reads a positive number and then computes and prints the logarithm of the value to base 8. For example, the logarithm of 64 to base 8 is 2 because $8^2 = 64$.
