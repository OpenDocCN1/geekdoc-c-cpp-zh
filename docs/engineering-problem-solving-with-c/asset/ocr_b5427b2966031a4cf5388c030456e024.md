binary search tree

A binary search tree is an example of an ordered binary tree. A binary search tree is defined as a binary tree where:

+   1. each node has a value,
+   2. the left subtree of a node contains only nodes with values less than the node's value,
+   3. the right subtree of a node contains only nodes with values greater than or equal to the node's value.

A binary search tree with six nodes is displayed in Figure 10.10.

Binary search trees are popular data structures for storing large amounts of ordered data because of the speed with which a binary search tree can be traversed and modified. Notice in the diagram in Figure 10.10 that there is a unique path from the root of the tree to every other node in the tree. Notice also that each right child of a node and each left child of a node is the root of a smaller subtree. These two features allow for the development of efficient recursive algorithms for tree traversal.

tree traversal

Traversing a tree refers to the process of visiting each node in a tree structure, exactly once, in a systematic way. Traversal algorithms are classified by the order in which the nodes are visited. For example, if we want to print() method to print the ordered data stored in the binary search tree represented in Figure 10.10, we would perform an in order traversal of the tree, printing the value of a node when it is visited. The recursive algorithm for an in order traversal of a tree is given below:

```
inOrder traverse:
if(root == null)
    return
inOrder traverse left child
visit node
inOrder traverse right child
```
