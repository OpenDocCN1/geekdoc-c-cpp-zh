| empty() | Returns true if the queue is empty and false otherwise. |
|---|---|
| pop() | Removes front element from the queue. Does not return a value. |
| push(value) | Adds value to front of queue. |
| size() | Returns the number of elements in the queue. |
| top() | Returns the value of the element at the front of the queue. The element is not removed from the queue. |
