Notice that we use the const modifier twice in each of the operator declarations. The use of the const modifier prevents an overloaded operator from modifying the data members of its operands. The const modifier inside the parentheses protects the data members of the right-hand side operand, and the const modifier at the end of the declaration protects the data members of the left-hand side operand. Any attempt to modify the data members either object from within these methods will result in a compilation error.
