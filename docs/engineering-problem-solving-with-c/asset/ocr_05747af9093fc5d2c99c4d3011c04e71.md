# Test getHeader Window

The Utilities window needs to be visible on the right hand side to display the complete path of the utility file. Viewing of the Utilities window is controlled by the icon on the upper right hand corner of the menu bar. Select Run from the Xcode Product menu. If the build is successful, the program will prompt for the name of the input file. Select the input file and copy the Full Path as provided in the Utilities window. Paste this into the standard input window and hit return as shown below.
