clear(Node* root):
if(root == null)
    return
else
    clear(root->left)
    clear(root->right)
    delete root

Notice in the declaration of the BinaryTree class that the methods print(), insert(), and clear() are overloaded. The public versions of these methods are not recursive. The private versions of these methods are recursive, and each has a formal parameter of type Node*.

The public versions of these methods must be called by a BinaryTree object, thus the root of the tree is provided by the calling object. The private versions of these methods calls themselves recursively, on the right and left subtree of the calling object, to traverse the tree.
