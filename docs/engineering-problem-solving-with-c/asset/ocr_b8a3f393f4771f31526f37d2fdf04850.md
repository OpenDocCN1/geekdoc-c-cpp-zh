/* This function converts each character in
/* the string pointed to by ptr_strg to uppercase.

void stringupper(char* ptr_strg)
{
    // While not end of string (while character is not null).
    while(*ptr_strg)
    {
        // Convert character to uppercase
        *ptr_strg = toupper(*ptr_strg);

        // Mover pointer to next character
        ptr_strg++;
    }
}

In this example, the pointer ptr_strg1 is passed to the function stringupper(), and the string pointed to by ptr_str1 is converted to uppercase. The formal parameter ptr_strg is incremented in the function to traverse the string, but no change is made to the argument in main because ptr_strg1 was passed by value.
