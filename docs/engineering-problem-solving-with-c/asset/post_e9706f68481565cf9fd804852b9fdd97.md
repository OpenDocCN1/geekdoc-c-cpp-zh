

```cpp
/*-----------------------------------------*/
/* Program chapter10_3                     */
/* This program demonstrates binary file I/O */
/*-----------------------------------------*/

#include <iostream>    //Required for cout
#include <fstream>     //Required for ifstream
using namespace std;

const int MAXLEN(100);

int main()
{
   //Define file filestream
   ifstream fin("YellowBox.jpg", ios::binary);
   ofstream fout("BinaryOutput.bin", ios::binary);

   //Define character array for storing input
   char bData[MAXLEN];
   int count(0);

   //Read and write MAXLEN characters
   fin.read(bData,MAXLEN);
   fout.write(bData,MAXLEN);

   cout << fin.gcount() << " characters read..."
        << endl;

   //Read and write MAXLEN characters
   for(char ch : bData)
   {
      fin.read(&ch,1);   //read one byte...
      fout.write(&ch,1);
      ++count;
   }
   cout << count << " byte(s) read" << endl;
   cout << fin.gcount() << " character(s) read"
        << endl;
   fin.close();
   fout.close();
   return 0;
}
```

The first call to the function read() extracts the first 100 characters from the input file YellowBox.jpg. The variable bData is an array of type char, thus the name of the array provides the address of the first element. The function write() is called to stream the characters in bData to the file BinaryOutput.bin. The second call to the member function read() is inside a range-based for statement. The range-based for statement will execute 100 times and 1 character per iteration will be read. The variable ch is a single variable of type char, thus the address operator is required to pass the address of ch to both read() and the write() functions. The member function gcount() returns the number of characters that were successfully extracted by the most recent call to read(). The output from a sample run of program chapter10_3 is provided below.

```
100 characters were read...
100 byte(s) read
1 character(s) read
```

This image was downloaded as a JPEG from the nasa.gov Image Gallery and saved as a PPM file named Pluto.ppm, using ToyViewer. To save an image as a PPM file in ToyViewer, select Export-> Save As PNM, then select the ppm Extension and select Save. When we view this PPM file with a text editor, we see the following header information, and no viewable pixel data.

```
P6
# : by ToyViewer
1042 1042 255
```

Recall that a PPM file contains a header that must be preserved in order to view the image. The header contains a magic number, optional comment, and the width, height and maximum color value of the image. In Section 10.2, we created an ASCII PPM file named YellowBox.ppm that required a magic number of P3 for viewing. The magic number provided for viewing the file Pluto.ppm is P6. P6 indicates that the pixel data is stored in a compressed binary format following the header. The header provides the width, height, and maximum color as ASCII decimal values. The pixel data is stored in a compressed binary format, three bytes per pixel, with no whitespace. Write a C++ solution to convert a binary PPM image with a magic number of P6 to an ASCII PPM image with a magic number of P3. Modify the converted image by performing a smoothing operation as discussed in Section 10.1.

## 3. HAND EXAMPLE

The header information in Pluto.ppm is read as character data and converted to decimal using the function atoi(), defined in the standard C++ library cstdlib. The function prototype is int atoi(const char *s); For our hand example, we will input and convert the value of width from the file Pluto.ppm. The value for width is input one character at a time. While the input character is a digit, it is stored in an array. When whitespace is encountered, the null character is added to the array to terminate the string as illustrated in the memory snapshot given below:

| '1' | '0' | '4' | '2' | '\0' |
|---|---|---|---|---|
| [0] | [1] | [2] | [3] | [4] |

The function call, shown below, converts the character string width to the integer value 1042 and the result is assigned to the variable w:

```
w = atoi(width);
```

A memory snapshot of w after the call to atoi() is given below:

```
int w = 1042;
```

To convert the pixel data, we will read the data one byte at a time and convert each unformatted character to an unsigned integer. We will perform this conversion in two steps. First, we will convert the unformatted character to an unsigned character so that all 8 bits of the character are used as data. Then, we will convert the unsigned character to an unsigned integer and store it as one color value of an (R, G, B) triple. Recall that a pixel is defined by an (R, G, B) triple, where each color value in the triple is an unsigned integer in the range of zero to the maximum color.
