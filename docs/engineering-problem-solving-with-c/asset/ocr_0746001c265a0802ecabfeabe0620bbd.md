Recall from Chapter 2.4 that we can compile our program by selecting Build from the Xcode Product menu. To run our program successfully we must provide a data file for input, so next we will add a data file to the project. From the Xcode File menu, select New > File... then select Other and Empty as shown below in the new file window:

![](bbox=[0.23, 0.17, 0.8, 0.43])

# New File Window

After choosing Next from the new file window and providing a name for the data file, a new empty file will be added to the project. We can then select the file and insert our sample data set. The completed data file is shown in the project window below. Note that the name of the data file is WeatherData.txt.
