Recall that a PPM file contains a header that must be preserved in order to view the image. The header contains a magic number, optional comment, and the width, height and maximum color value of the image. In Section 10.2, we created an ASCII PPM file named YellowBox.ppm that required a magic number of P3 for viewing. The magic number provided for viewing the file Pluto.ppm is P6. P6 indicates that the pixel data is stored in a compressed binary format following the header. The header provides the width, height, and maximum color as ASCII decimal values. The pixel data is stored in a compressed binary format, three bytes per pixel, with no whitespace.
