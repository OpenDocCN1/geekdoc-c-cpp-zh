```
#include <iostream> //Required for cout
#include "Point.h" //Required for Point
using namespace std;

int main()
{
    //Declare and initialize objects.
    Point p1;
    Point p2(1.5, -4.7);

    //Test operators
    if( p1 == p2)
    {
        cout << "p1 is equal to p2" << endl;
    }
    else
    {
        cout << "Distance between p1 and p2 is" << p1 - p2
            << endl;
    }

    return 0;
}
/*--------------------------------------*/
```

In the expression
p1 == p2

p1 is the calling object. The calling object is the object that calls the method. For overloaded binary operators, the left operand is always the calling object. When the operator == (const Point& rhs) method is called, we see from the memory snapshot that rhs is defined and references the same object that p2 references. The data type of rhs is the type
