# 8.3 Two-Dimensional Arrays and the vector class

The vector class can be used to implement the concept of a two-dimensional array and has many advantages over built-in arrays. The vector class allows variables to be used to define the desired row and column size, thus eliminating the need for symbolic constants. The vector class also includes a set of useful methods for determining and modifying the size and capacity of a vector, dynamically.

To define a two-dimensional vector, we define a vector of vectors of a specified data type. The row size of a two-dimensional vector can be specified in the declaration statement, but is optional, as illustrated in the type declaration statements provided below.

```
vector<vector<double>> arr; //rowSize and colSize are 0
vector<vector<double>> arr(10); //rowSize is 10, colSize is 0
```

Notice the space between the last two > > characters in each of the type declaration statements. This space is required for successful compilation in older compilers. This space is not required in C++11.

The column size of a two-dimensional vector can be defined for each row using the resize() method as shown in the example program below.

```
#include<iostream>
#include <vector>
using namespace std;

int main()
{
 int rowSize(10), colSize(25);

 vector< vector<int> > table(rowSize);
 for(int i=0; i<table.size(); ++i) table[i].resize(colSize);

 cout << "rowSize is " << table.size() << endl;
 cout << "colSize is " << table[0].size() << endl;
```
