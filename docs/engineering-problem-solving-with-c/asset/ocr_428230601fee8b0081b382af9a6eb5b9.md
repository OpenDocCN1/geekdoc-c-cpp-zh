# Figure 4.8 End-of-data loop.

flowchart of this looping structure is given in Figure 4.8. The end-of-data loop is easily implemented using a while loop, as illustrated in the following example, which calculates the average of a set of exam scores, entered from the keyboard:

```
/* Program chapter4_7 */
/* This programs finds the average of a set of exam scores. */
#include<iostream>//Required for cin, cout
using namespace std;
int main()
{
    // Declare and initialize objects.
    double exam_score, sum(0), average;
    int count(0);
    // Prompt user for input.
    cout << "Enter exam scores separated by whitespace. ";
    // Input exam scores using end-of-data loop.
    cin >> exam_score;
    while (!cin.eof())
    {
        sum = sum + exam_score;
        ++count;
        cin >> exam_score;
    }
```
