## String Data

A literal string constant is a sequence of characters enclosed within double quotes, as in "sensor", "F18", or "Jane Doe". String variables can be represented as C-style strings using arrays of type char, or as string objects using the string class. Both representations will be discussed in detail in Chapter 7. In this section, we give a brief introduction to the string class.

The C++ compiler does not have a built-in data type named string, but a string class definition is provided in the standard C++ library file string. To use the string class, a program must include the following preprocessor directive:

```
#include<string>
```

The following program illustrates the use of the predefined C++ string class:


## Symbolic Constants

A symbolic constant is defined using the const modifier. Engineering constants such as pi or the acceleration of gravity are good candidates for symbolic constants. For example, consider the following declaration statement to assign a value to the symbolic constant PI:

```
const double PI = acos(-1.0);
```

The acos function, when evaluated at -1, will return an approximation for pi that includes 15 digits of precision. Statements that need to use the value of pi would then use the symbolic constant PI as illustrated in this statement:

```
area = PI*radius*radius;
```

which computes the area of a circle.

Symbolic constants are usually defined with uppercase identifiers (as in PI instead of pi) to indicate that they are symbolic constants, and, of course, the identifiers should be selected so that they are easy to remember. Once an identifier has been declared and initialized using the const modifier, its value cannot be changed within the program.

## Auto Type Specifier

The C++11 keyword auto supports the declaration of an object without specifying a data type, as long as an initializer is provided. The data type of the initializer defines the data type of the identifier. When using the keyword auto, it is preferred to use the = notation for initialization. Consider the following type declaration statements:

```
auto x1 = 0;        //x1 is type integer
auto comma = ',',   //comma is type char
auto y1 = 0.5;      //y1 is type double
auto count{0};      //count is type initializer_list<int>
```

The keyword auto acts like a placeholder for the data type of the initializer. In the case of auto count{0}; the initializer {0} is interpreted as an initializer list of type integer, not an integer. There is no advantage to using auto for the simple declaration of built-in types, but it can be useful as data types become more complex, and harder to determine.

## 2.3 C++ Classes

C++ supports the use of classes to define new data types, often referred to as programmer defined data types. Programmer defined data types are useful for defining new data types that model real world objects. In the previous section, we looked at examples using built-in data types including int, double and char, and we discussed the predefined data type, string. Suppose we are working on an application that manipulates points in a plane. There is no built-in data type for defining a point, but we can define a new data type to model a point using the C++ keyword class. In this section, we will introduce the basic syntax for defining a C++ class, and define a new data type to model a point in a plane.

A point in a plane is an object defined by a (x, y) coordinate. The coordinate is a physical attribute and can be represented by data. For this example, we will use the built-in data type double to represent the values of the (x, y) coordinate. In addition to the physical attributes of a point, we have to consider what operations we want to perform on a point. Of course, we have to be able to create new points. We may also want to move an existing point or determine the distance between two existing points or print the coordinate of an existing point. Physical attributes and operations are defined for a new data type within a C++ class.

The definition of a C++ class consists of two parts: a class declaration and a class implementation. In general, the class declaration and the class implementation are contained in separate files. The convention is to name the class declaration file with a .h extension and class implementation file with a .cpp extension.

## Class Declaration

A class declaration begins with the keyword class, followed by an identifier that specifies the name of the new class and the body of the

- data members
- member functions
- class methods

class declaration is a block of code, terminated with a semicolon. This block of code includes declaration statements for the physical attributes of the class, often referred to as the data members and declaration statements for the definition of the desired operations, often referred to as the member functions or class methods. The keywords public, private, and protected are used to control access to the data members and class methods. Controlling access to data members and methods is a powerful feature of classes and will be discussed in more detail in later chapters. To illustrate the syntax of a class declaration, we begin by writing the initial declaration of a new class named Point. Consider the class declaration given below.

```
/*
 * Point class
 * Initial Declaration
 * Filename: Point.h
 */
class Point
{
    // Type declaration statements
    // for data members.
    private:
    double xCoord, yCoord; //Class attributes

    public:
    //Declaration statements for class methods
    //Constructors for Point class
    Point(); //default constructor
    Point(double x, double y); //parameterized constructor
};
/*------------------------------------------------*/
```

Note that a semicolon is required to terminate the declaration block.

The first four lines of the class declaration are comments, and include the name of the source file. On the next line the identifier, Point, and a block of code that defines the body of the class declaration follow the keyword class. It is important to note that a semicolon is required to terminate the declaration block. Within the declaration block, the data members and methods are declared. The data members, xCoord and yCoord, are declared under the keyword private to limit access to these data members. The class methods are declared under the keyword public to allow access to these methods. Note that only two public methods are listed in the initial declaration. The first method listed is the default constructor, Point(). The second method is the parameterized constructor, Point(double x, double y). A constructor is a special method that performs the operation of a type declaration statement, thus the name of the constructor is always the same as the name of the class. Constructors allow applications to create objects of the new type. The default constructor for the Point class includes only the name of the class and a set of parentheses. The parameterized constructor for the Point class includes a set of parameters within the parentheses. These parameters allow the application to specify the initial values to be

- default constructor
- parameterized constructor
- constructor
