class declaration is a block of code, terminated with a semicolon. This block of code includes declaration statements for the physical attributes of the class, often referred to as the data members and declaration statements for the definition of the desired operations, often referred to as the member functions or class methods. The keywords public, private, and protected are used to control access to the data members and class methods. Controlling access to data members and methods is a powerful feature of classes and will be discussed in more detail in later chapters. To illustrate the syntax of a class declaration, we begin by writing the initial declaration of a new class named Point. Consider the class declaration given below.

```
/*
 * Point class
 * Initial Declaration
 * Filename: Point.h
 */
class Point
{
    // Type declaration statements
    // for data members.
    private:
    double xCoord, yCoord; //Class attributes

    public:
    //Declaration statements for class methods
    //Constructors for Point class
    Point(); //default constructor
    Point(double x, double y); //parameterized constructor
};
/*------------------------------------------------*/
```

Note that a semicolon is required to terminate the declaration block.

The first four lines of the class declaration are comments, and include the name of the source file. On the next line the identifier, Point, and a block of code that defines the body of the class declaration follow the keyword class. It is important to note that a semicolon is required to terminate the declaration block. Within the declaration block, the data members and methods are declared. The data members, xCoord and yCoord, are declared under the keyword private to limit access to these data members. The class methods are declared under the keyword public to allow access to these methods. Note that only two public methods are listed in the initial declaration. The first method listed is the default constructor, Point(). The second method is the parameterized constructor, Point(double x, double y). A constructor is a special method that performs the operation of a type declaration statement, thus the name of the constructor is always the same as the name of the class. Constructors allow applications to create objects of the new type. The default constructor for the Point class includes only the name of the class and a set of parentheses.
