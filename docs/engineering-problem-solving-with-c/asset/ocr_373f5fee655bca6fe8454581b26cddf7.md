The algorithm for our solution is quite simple. We will define a two-dimensional vector of type Pixel to represent our grid. A color of either red (255 0 0) or yellow (255 255 0) will be assigned to each pixel in the grid, depending on the position of the pixel. If the pixel is “inside” the box, it will be assigned a color value of yellow, otherwise it will be assigned a color value of red. For example, a pixel may be considered inside the box when the row position of the pixel is greater than (height*0.25) and less than (height*0.75) and the column position of the pixel is greater than (width*0.25) and less than (width*0.75).
