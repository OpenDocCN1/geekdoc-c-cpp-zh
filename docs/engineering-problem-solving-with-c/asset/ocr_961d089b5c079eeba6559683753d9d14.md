# The BinaryTree class

In this section, we will implement a new programmer-defined type to represent the concept of a binary tree. Our implementation will include the use of class composition, and the definition of several recursive methods. In Section 10.7, we will use the BinaryTree class to develop a class template.

+   root
+   left child
+   right child
+   leaf node

A binary tree is a dynamic, linked, data structure that represents a collection of nodes that extend from a single root. The root of a binary tree references the first node. Each node in a binary tree consists of a data value and at most two links to other nodes. The links to other nodes are referred to as the left child and the right child. The left child is the root of the left subtree, and the right child is the root of the right subtree. If both the left child and the right child of a node are null, the node is referred to as a leaf node. A diagram of a binary tree with five nodes is provided in Figure 10.7.
