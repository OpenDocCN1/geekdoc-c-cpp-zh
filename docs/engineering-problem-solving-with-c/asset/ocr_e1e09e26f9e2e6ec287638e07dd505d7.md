# 4.1 Algorithm Development

In Chapter 3, we developed algorithms that used selection structures to provide alternative paths during program execution. In this chapter, we develop algorithms and write C++ programs that use repetition structures. The repetition structure allows us to repeat (or loop through) a set of steps as long as a condition is true. For example, we might want to compute a set of velocity values that correspond to time values of 0, 1, 2, ..., 10 seconds. Although this structure would require only eleven statements in this case, it could require hundreds of statements if we wanted to compute the velocity values over a long period.
