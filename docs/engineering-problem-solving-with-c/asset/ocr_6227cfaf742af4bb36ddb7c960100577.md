However, the input operator does not do any checking on the maximum size of the array. If the input data has more characters than the maximum size of the character array, the input operator will recall values beyond the bounds of the array, and an error will occur.

Recall that the input operator ignores all whitespace. If whitespace is desired as part of a string, the function getline() can be used to read strings, as illustrated in the next example that reads comment lines from the header of an ASCII image file and prints the comment lines on the screen. Our example uses the peek() function to look at the next character on the input stream. The function peek() is a member function of the istream class and can be called by any istream object. The function peek() returns the value of the next character on the input stream but does not remove the character from the input stream:
