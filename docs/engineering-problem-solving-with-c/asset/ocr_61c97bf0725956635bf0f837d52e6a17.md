# Pointers as Function Arguments

When a pointer is passed as an argument to a function, the pointer can be passed by value or passed by reference. If a pointer is passed by value, the pointer can be used to modify the object it points to, but the value of the pointer cannot be modified by the function. If a pointer is passed by reference, the pointer can be used to modify the object it points to, and the value of the pointer can also be modified.
