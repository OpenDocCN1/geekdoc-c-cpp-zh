At this point, it is a good idea to create an instance of VegetationSample in main.cpp and test all methods in the VegetationSample class. Once all methods have been tested and are working correctly the new data type can be used in the final solution.

The structure chart for our solution has four functions that are referenced by main.

Create a custom header file named Functions.h as discussed in Section 7.3 for the function prototypes and a separate .cpp file for the function definitions. To do this, select New > File... from the Xcode File menu. Choose C++ Source file and select the Also create a header file box, and select Next, as we did when defining VegetationMap.h and VegetationMap.cpp. Two files, Functions.h and Functions.cpp, will be added to the project. Select Functions.h and add the required function headers, then select Functions.cpp and add the statements necessary to implement the pseudocode for each of our four functions.
