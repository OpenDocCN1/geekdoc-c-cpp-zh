A PPM file can be viewed as an ASCII text file using a basic text editor such as TextEdit Emacs or vi. The header information and image data for a very small version of Yellow-Box.ppm is shown in Figure 10.4.

The first five lines of the image file hold the header data. The magic number P3 identifies the file as a PPM file. The comment line begins with a # and in this example the comment provides the name of the image file. The next two integers, 8 and 8 in this example, provide the width and height of the image and the next integer, 255, defines the maximum color value. The image data follows. The image data consist of an 8 by 8 grid of pixels values. The first pixel is represented by the triple 255 0 0, or the color red. The pixel value in the forth row, four column is represented by the triple 255 255 0, or the color yellow.
