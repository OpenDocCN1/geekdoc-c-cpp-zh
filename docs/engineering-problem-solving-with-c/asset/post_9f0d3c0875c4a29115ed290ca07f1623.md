## 7.8 The string Class

The string class provides an object-based alternative to the C-style string. The following are a few of the commonly used member functions included in the string class:

| Function | Description |
| :--- | :--- |
| `size()` | // Returns the length of the calling string. |
| `empty()` | // Returns true if the calling string contains no characters. |
| `substr(int start, int len)` | // Returns the substring of length len, beginning at start of the calling string. |
| `c_str()` | // Returns the equivalent C-style string. |

Numerous operators have been overloaded in the string class to support the use of string objects. The assignment operator, as well as the relational operators, <, >, <=, >=, ==, and the operators + and +=, can be used with string objects. The binary operator + concatenates two strings, and the binary operator += appends one string to the end of the other. ## 7.9 Building C++ Solutions with IDEs: Xcode Vegetation Maps

### vegetation map

A vegetation map shows the distribution of plant life over a defined geographical region. Vegetation maps can be constructed from satellite images by examining the different wavelengths of light reflected off a landmass. These maps are useful for monitoring the health of our forests and global changes in plant distribution. Vegetation maps may also record vegetation samples for specific plants within a geographical region, such as endangered species, species known to attract bees, or species that have a significant impact on the carbon cycle. In this section, we will develop a C++ solution, using Xcode, to analyze a vegetation map. The map is constructed of vegetation samples of five bee-friendly wildflowers taken in a region of Colorado. Each vegetation sample includes the following:

- geographical location defined as the
  - latitude (decimal degrees)
  - longitude (decimal degrees)
  - elevation (meters)
- number of Blueflax (*Linum lewisii*)
- number of Colorado Columbine (*Aquilegia coerulea var. coerulea*)
- number of Penstemon (*Penstemon glaber*)
- number of Alpine Sunflower (*Hymenoxys grandiflora*)
- number of Avalanche Lily (*Erythronium grandiflorum*)
