# 2.4 Building C++ Solutions with IDEs: Xcode

Integrated Development Environment (IDE)

Xcode

We have discussed the general structure of a C++ program and written several small programs to illustrate the use of data types. In this section, we will illustrate how to develop a C++ solution using an Integrated Development Environment (IDE). An IDE is a software package designed to facilitate the development of software solutions. The IDEs include an editor, a compiler, a debugger, and many additional tools to aide in the design and development of large software solutions. There are many good IDEs available for a variety of platforms. In this section, we will develop a C++ solution for program chapter2_3 using the IDE Xcode.

# Xcode
