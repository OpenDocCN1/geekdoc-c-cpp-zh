```
ave_power(x, n):
set sum to zero
set k to zero
while k <= n - 1
add x[k]'2 to sum
increment k by 1
return sum/n
ave_magn(x, n):
set sum to zero
set k to zero
while k <= n - 1
add | x[k] | to sum
increment k by 1
return sum/n
crossings(x, n):
set count to zero
set k to zero
while k <= n-2
if x[k]*x[k + 1] < 0
increment count by 1
return count
```

Note that the number of potential zero crossings for a set of n data points is n - 1 crossings, because each crossing is determined by a pair of values. Thus, the last pair of values tested will be at offsets n - 2 and n - 1. The steps in the pseudocode are detailed enough to convert to C++:
