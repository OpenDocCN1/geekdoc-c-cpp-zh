# C++ Statement Summary

Preprocessor directives to include information from the files in the Standard C++ library:

General Form:

```
#include<filename>
```

Example:

```
#include <iostream>
#include <cmath>
#include <string>
```

Type Declaration Statement

General Form:

```
datatype identifier [,identifier];
```

Examples: Declarations for integers:

```
short sum(0);
int year_1, year_2;
long k;
```

Declarations for floating-point values:

```
float height_1, height_2;
double length(10), side1, side2;
long double distance, velocity;
```

Declarations using the keyword auto:

```
auto i = 0;   //i is declared as an int
auto r = 0.5; //r is declared as a double
```

Declarations for characters and strings:

```
char ch;
string name; //Requires #include<string>
```

Declarations for symbolic constants: General Form:

```
const datatype identifier = expression;
```

Example:

```
const double PI = acos(-1.0);
const int MAX_SIZE = 100;
```
