In the program developed in Section 6.10, we searched for subintervals for which the function values at the endpoints had different signs; then we estimated the root location to be the midpoint of the subinterval. A more accurate estimate of the root location is usually the intersection of a straight line through the function values with the x-axis, as shown in Figure 6.23.

Using similar triangles, it can be shown that the intersection point c can be computed using the following equation:

$c = \frac{a * f(b) - b * f(a)}{f(b) - f(a)}.$
