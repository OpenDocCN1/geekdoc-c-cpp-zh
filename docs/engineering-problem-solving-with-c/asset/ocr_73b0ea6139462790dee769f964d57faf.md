# Manipulators

In program chapter2_4 we used stream functions to control the formatting of output printed to the screen. The formatting of output can also be controlled with the use of manipulators. A manipulator is a predefined object that can affect the state of an output stream. Program chapter2_5 illustrates the use of manipulators instead of stream functions to control the formatting of the standard output stream. To use manipulators, a program must include the header file <iomanip>
