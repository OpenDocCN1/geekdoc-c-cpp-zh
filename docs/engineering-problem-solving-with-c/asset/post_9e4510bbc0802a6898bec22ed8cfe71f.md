void createYellowBox(vector<vector<Pixel>> &image, int w, int h)
{
    cout << " inside createYellowBox" << endl;
    const Pixel RED(maxPixelVal,0,0);
    const Pixel YELLOW(maxPixelVal,maxPixelVal,0);
    const double P25(0.25), P75(0.75);

    image.resize(h);
    for(int i=0; i<h; ++i)
    {
        image[i].resize(w);
        for(int j=0; j<w; ++j)
        {
            if((i > h*P25&&i < h*P75)&&(j > w*P25&&j < w*P75))
                image[i][j] = YELLOW;
            else
                image[i][j] = RED;
        }
    }
}

void writeImage(vector<vector<Pixel>> &image, string filename)
{
    ofstream fout;
    fout.open(filename);
    const int TEN(10); //write 10 pixels per line
    if(fout.fail())
    {
        cout << "error opening output file" << endl;
        exit(1);
    }

    int h,w;
    h = (int)image.size();
    w = (int)image[0].size();
    writeHeader(fout,h,w,filename);

    for(int i=0; i<h; ++i)
    {
        for(int j=0;j<w; ++j)
        {
            fout << image[i][j] << " ";
            if((j+1)%TEN == 0) fout << endl;
        }
    }
    fout.close();
}
void writeHeader(ofstream& out, int h, int w, string comment)
{
    out << magicNumber << endl;
    // MagicNumber defined in header file
    out << comment << endl;
    out << h << " " << w << endl;
    out << maxPixelVal << endl;
    // maxPixelVal defined in header file
}

## 10.3 Binary File Input and Output

**Big data**

Engineering problem solving often requires manipulating large amounts of data. Data can represent anything from simple text, to images, speech samples, weather maps, or social media sharing. **Big data** is a term that refers to data sets that are so large and so complex that they are not easily defined. Big data can arrive from a variety of devices and it arrives in very large volumes and at very high rates of speed. New fields of study in data science and new career opportunities are arising globally to capitalize on information that can be harnessed from big data.

**binary files**

In the preceding chapters of this text, we have developed C++ solutions that open data files for input and output. Our solutions thus far have worked with American Standard Code for Information Interchange (ASCII) text files. ASCII is a seven-bit character code discussed briefly in Chapter 2. Each byte of an ASCII text file is interpreted as one ASCII character. An ASCII text file can be created, viewed, and edited with a basic text editor. ASCII text files are convenient for storing text files and source code, but they are not efficient for storing large amounts of data. For large data sets, **binary files** are preferred. Binary files store data in a compressed format that views all eight bits of each byte. Binary files are not easily read by humans and cannot be viewed and edited using a basic text editor. However, large amounts of data can be stored more efficiently in a binary format, and since binary data is not interpreted as formatted data, it can be accessed at a faster rate of speed.

Consider the ASCII text file YellowBox.ppm, created in Section 10.2, with a width and height of 200. The size of the file YellowBox.ppm is 343,632 bytes. We can save the image as a binary file by selecting **Export** from the **ToyViewer** menu and then selecting from one of the file formats in the **Save As** menu. Selecting the file format JPEG from the **Save As** menu results in the creation of the new file **YellowBox.jpg**. The size of the new file **YellowBox.jpg** is 5,615 bytes. In this section, we discuss the C++ statements required for interacting with binary data files and give examples that read and process information from binary files.

### Opening Binary Files

The C++ Standard Library provides file stream classes to support file input and file output. The member function **open()** is used to associate a data file with a file stream object. Recall that both the **ifstream** and the **ofstream** class are derived from the **ios_base** class as illustrated in Figure 5.1. The **ios_base** class includes a member constant named **binary** that is defined to specify a binary mode when associating a data file with a stream object. The **binary** mode is system dependent but in general it means that data will be stored in the file as a sequence of characters with no expected format. The following statements define input and output file stream objects and associate these stream objects with binary files.

```cpp
ifstream binaryInstream;
binaryInstream.open("YellowBox.jpg", ios::binary);
if (binaryInstream.fail()) exit(1);
```

```cpp
ofstream binaryOutstream("modifiedImage.bin", ios::binary);
```

As we see in the above statements, the **ios::binary** mode can be provided as a parameter to the member function **open()** or to the constructor of an **istream** or **ostream** object.

The data in a binary file is unformatted implying that whitespace is not used as a delimiter between bytes, thus the input operator (**>>**) cannot be used to extract data from a binary file. The **istream** class defines a member function named **read()** to read data from a binary file and the **ostream** class defines a member function named **write()** to write data to a binary file. Additional member functions defined in **istream** and **ostream** are listed in Appendix A.

### Reading and Writing Binary Files

The **istream** class defines a member function with the following prototype for reading unformatted data from a binary file:

```cpp
istream& read(char* data, streamsize n);
```

The input parameter **data** is the starting address of a range of memory where the character data will be stored, and **n** is an integral value that specifies the number of characters to be extracted from the input stream. Characters are read from the input stream, until **n** characters have been extracted or an end of file is encountered.

The **ostream** class defines a member function with the following prototype for writing unformatted data to a binary file:

```cpp
ostream& write(const char* data, streamsize n);
```

The input parameter **data** is the starting address of the source of the character data, and **n** is an integral value that specifies the number of characters to be streamed from the source. The following example reads characters from the binary file **YellowBox.jpg** and writes binary data to the file **binaryOutput.bin**.
