Note that we can also use the C++II syntax to initialize a member that is object. For example, let's
change the declaration of the c object:

```
class B
{
public:
    C c{10}; /* We can also write C c = {10}; Notice that it is not\allowed to use parentheses, that is, it is illegal to write C c(10). */
    ...
};
```

To create the c second constructor will be called, the value 10 is passed, so the value of
b.c.p becomes 10.
C++ll supports the assignment of value to the members of a class. For example:

A a; // x is 10 and a v is 20.
A a(1); // a x is 1 and a v is 20.
A (1, 2); // a x is 1 and a v is 2.

When the default constructor is used to create an object of class A, its members are initialized to the
sified values, that is, 10 and 20.

# Non-Public Constructors

In the question, a constructor can be private, the answer is yes. For example, we can have many public
constructors, which all call a private constructor that undertakes to create the object. We will see that tech-
nique with the delegating constructor in Chapter 19. One reason to use a private constructor is when we
dont want to expose it to the outside world.

In the similar, a constructor can be protected, the answer is again yes. For example, in inher-\itance, a constructor can be declared protected in the base class to prevent the direct creation of base
objects and only derived classes to use it. For example, as we'll see in Chapter 20, we can write:

A a; // Error.
A b; // OK.
