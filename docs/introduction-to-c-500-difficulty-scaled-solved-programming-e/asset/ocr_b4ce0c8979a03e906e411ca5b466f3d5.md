To make clear, both header files and library files are supplied with the compiler; a header file contains information about the components of the program (e.g., function declarations), while a library file contains the implementation code (e.g., function definitions) in machine language. although, in some cases the necessary libraries must be explicitly loaded. for, if you are using the g++ compiler and your program (e.g., test.cpp) with a math function (e.g., sqrt()), you might need to load the library by using a command with the name Build or Make which is typically found, g++ performs compilation and linking in one step.

If the linking is successful, an executable file is generated. For example, the default name of the executable produced by the g++ compiler is a.out, while a Microsoft compiler produces an executable file with the same name as the source file and extension.exe.

An executable file is generated for a specific system, that is, an executable created on a Windows system cannot be executed on a Mac. What about the source code? If the code can be successfully compiled on a variety of systems without any modifications, we say that the program is portable.

# RUN THE PROGRAM

There are several ways to run a program. For example, if the executable file was generated by the g++ compiler, type in the command line:

```
$ a.out
```

If an error message like No such file or directory or command not found is displayed,

```
./a.out
```

so that the file is searched in the current folder. in an IDE, a command like Build->Execute is typically found to run the program.

# ERRORS

Errors may appear in all stages of the program development. Errors reported by the compiler are compile-time errors, errors reported by the linker are linker errors, and errors that emerge when the program runs are runtime or logical errors. As you guess, the latter is the worst type of errors.

The most common errors are syntactic. For example, if you write in the cout instead of << omit the double quotes or you don't add ; at the end, the compilation and the compiler will display error messages. Spelling errors are very common, for example. if you mean the compilation failures. C++ is a case-sensitive language, meaning that distinguishes between uppercase and lowercase letters. for you use Cout instead of cout, the compilation fails.

If the compiler displays many fixes, a single error can cause the compiler to display more than actually exists. The new compilation may show less errors, even once. Notice, that an error detected by the compiler may not occur in the indicated line, but in some previous line, the immediately preceding one.

Apart from errors, the compiler may display warning messages. If there are only messages, the program will be compiled. don't ignore them; it may warn you the potential malfunction of your program. in fact, for better control of your program it is safer to set the warning level at the maximum level supported by your compiler in order to catch all of them.
