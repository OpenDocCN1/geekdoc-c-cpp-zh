The code displays the characters of the string beginning from the character the pointer points to until it encounters the null character. If we want to display a certain number of characters we can use the write() function, which is a member of the ostream class. For example, if we write: cout.write(str, 3); it displays the first three characters, that is, Pri. If we don't want to display the string from where we make the pointer to the desired position. For example, if we write: cout << str+8; or equivalent: cout << &str[8]; it displays the part beginning from the ninth character, that is, message. If the null character is encountered, no more characters are printed. For example, if we add the statement str[5] = '\n'; before the output, the code displays Print.

If we want to split the string in one line we can use the \ character. Note that the string will be displayed in the same line.

```
cout << "This text is displayed \
nin the same line\n";
```

Alternatively, because the compiler allows the merging of two or more adjacent literal strings into a single string we can:

```
cout << "This text is displayed "
in the same line\n";
```

If the string contains the ", we use the escape sequence \" to print it. For example:

```
cout << "Start\"; and the code displays: "Start"
```

If cout does not encounter the null character, it continues the end of the string until it finds a null somewhere in the memory. For example:

```
#include <iostream> // Example 10.1
int main() {
    char str[10];
    str[0] = 'a';
    str[1] = 'b';
    std::cout << str << '\n';
    return 0;
}
```

The program displays 'a' and 'b' and then garbage characters until it finds the null character or an illegal memory access. If we write char str[10] = {};; then, the elements are initialized to 0, the program would display ab.

As we know, to represent special characters in a literal string, such as " or \, we must first add \. If the string contains many such characters, the result becomes more complex to write and read. To facilitate the output of such strings, C++11 provides the form of raw processing where each character, \ has no special treatment but is displayed as it. For example, the \n is not interpreted as the new line character, but as two characters the backslash and the n. To represent the character sequence (e.g., abc) the character R is used with the following syntax R"(abc). The "( )" is the default pair to delimit the sequence and identify it as a raw string.
