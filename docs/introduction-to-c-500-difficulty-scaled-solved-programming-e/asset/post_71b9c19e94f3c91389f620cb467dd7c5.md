# ~ Operator

The complement operation is unary and performs the Boolean NOT on all bits of its operand. In particular, it reverses the 1s to 0s and vice versa. For example, the result of -23 in a 32-bit system is:

# Shift Operators

The shift operators shift the bits of an integer variable or constant left or right. The >> operator shifts the bits to the right, while the << operator shifts the bits to the left. Both operators take a right operand, which indicates how many places the bits will be shifted. If i is negative or it has a value equal to or greater than the number of bits of the type left the result is undefined. It is the programmer's responsibility to make sure that the right operand has a valid value. For example, if the int type has 32 bits and a is int, it is valid to write a << 31, but not a << 32 or a << -1.

The expression i >> n shifts the bits i by n places to the right. If i is positive or its type is unsigned, then the n high-order bits inserted on the left are set to 0. If i is negative, it depends on the implementation whether ones or zeros are added. For example, what would be the value of a in the following code?

```cpp
unsigned int a, b = 23;
a = b >> 2;
```

Let's write the number in binary to explain the shifting operation. For simplicity, use 8 bits. Since 23 is 00100111 in binary, the result of 00100111 >> 2 is 00001001, and that will be the value of a (i.e., 9). In particular, the two rightmost bits 1 and 1 of the original number are "shifted off" and two zero bits are entered in positions 7 and 8. Notice that the value of b remains 23.

> Since a bit corresponds to a power of 2, shifting a positive integer n places to the right divides its value by 2ⁿ.

The expression i << n shifts the bits i by n places to the left. The low-order bits inserted on the right are set to 0. For example, what would be the value of a in the following code?

```cpp
unsigned int a, b = 23;
a = b << 3;
```

# Introduction to C++

Since the number 23 is 00010111 in binary, the shifting result of 00010111 << 3 is 001011100, and that will be the value of a. In particular, the original number are shifted three places to the left and three zeros are added in positions 1, 2, and 3. Therefore, a becomes 184, while it remains 23.

> If no overflow occurs, shifting a positive number n places to the left multiplies its value by 2n.

When you use the << operator to store the shifting result into a variable, make sure the type of the variable is large enough to hold the value. For example, what would be the value of a in the following code?

```cpp
unsigned char a = 32;
a <<= 3; // Equivalent to a = a << 3;
```

The statement << 3 shifts the value of three places to the left and inserts three zeros at the right. Therefore, the shifting result is 10000000. However, if a is declared as unsigned char, it can hold only the value of eight low-order bits. Therefore, a becomes 0 and not 256, as you might expect. If it were declared as int, its value would be 256. Here's another example:

```cpp
char a = 4;
a <<= 5;
```

the value of a is shifted four places to the left and becomes 10000000. If the char type is signed, the leftmost bit is reserved for the sign and a becomes -128. If a were declared as unsigned char, its value would be 128.

Remember, it is safer to perform bitwise operations on unsigned types.

Now you've learned about the << and >> operators, you may wonder how are they used with the cout and cin objects? The answer is that when used like they do not operate as shift operators. As we'll learn in Chapter 18, the ostream overloads them and changes their behaviour. As far as the compiler is concerned, the way they are used is clear from the context.

# ALTERNATIVE REPRESENTATIONS

The language provides a set of reserved words for the alternative representation of the operators:

```
&&    &=    &      |    ~    ! !=    ||      ^     ^=
and  and_eq bitand bitor compl not not_eq or or_eq xor x_eq
```

For example, the expressions:

```cpp
bool a = (b & c) || !d;
int a = (b & c) | d;
```

are equivalent to:

```cpp
bool a = (b and c) or d;
int a = (b bitand c) bitor d;
```

C.4.4 Write a program that reads an integer and displays a message to indicate whether it is even or odd. Use the & operator.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    int num;
    cout << "Enter number: ";
    cin >> num;

    if(num & 1) // could also write if(num & 1) == 1
        cout << "The number " << num << " is odd\n";
    else
        cout << "The number " << num << " is even\n";
    return 0;
}
```

Comments: To determine whether a number is even or odd we check its last digit. If it is 0, it is even; otherwise, it is odd. Suppose the variable num is coded in binary as:

xxxxxxxx xxxxx

where each '&' represents a bit of 0 or 1. Then, the result of num & 1 is:

```
xxxxxxxx xxxxx
00000000 00000000
00000000 00000001
00000000 00000000
```

Therefore, the result is equal to the value of the last bit. If it is 1, the condition in the if statement is true and the program displays a message that the number is odd. If it is 0, the condition is false and the program displays a message that the number is even. Notice that this solution is based on the assumption we've made in Chapter 2 that the system uses the most common method to represent negative numbers, is the two's complement. For a more generic and portable solution, you should use the % operator.
