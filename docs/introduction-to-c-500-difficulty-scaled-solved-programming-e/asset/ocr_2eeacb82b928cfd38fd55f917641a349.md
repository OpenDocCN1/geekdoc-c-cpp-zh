# Rethrow Exceptions

When a catch catches an exception it may not be able to handle or decide that it is better a higher level to deal with. In this case you can rethink the exception so that it is forwarded to a higher level, relevant with the type of exception, to take over its handling. This is what we just wrote throw, without any argument. The throw must be within a catch block or within a function called (directly or indirectly in a call chain) from a catch block. Otherwise the throw causes the program to terminate. The rethrown exception is the original exception that was caught. For example, in the following program, the initial exception of throw is passed all the way to the catch block that will eventually handle the exception:

```
#include <iostream> // Example 22.5
void f();
void g();

int main() {
    try
    {
        f();
    } catch (int a)
    {
        std::cout << "int exception is caught: " << a << '\
';
    }
    return 0;
}

void f() {
    try
    {
        g();
    } catch(int indirect) /* Since the catch block does not use the argument I don't use a parameter name. */
    {
        std::cout << "int exception is rethrown\n";
        // Rethrow the exception.
    }
    std::cout << "f() terminates\n"; /* Since throw rethrows the exception, this statement won't be executed. */
}

void g() {
    throw 10;
}
```

The int exception thrown by g() is caught by the catch block in f(). The f() rethrows it and is caught in main(). The original argument of throw is also passed to main(). Therefore, the program displays:

int exception is rethrown
int exception is caught: 10
