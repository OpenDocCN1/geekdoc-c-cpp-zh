# Container Adaptors

Container adaptors are implemented on top of containers and adapt their functionality to their own requirements. A container adaptor provides a limited set of the services of the encapsulated container, tailored to a specific use. For example, the stack container, although is based on deque, it allows the insertion and deletion of elements only at the top of the stack. They have no iterators and do not support access with index notation. The standard container adapters are the queue, priority_queue, and stack template classes. Let's see them briefly.

# The queue template class

The queue template class implements a FIFO (First In Out) queue, where elements are inserted into the end of the queue and extracted from its front. The implementation supports the basic functionality of a queue. We can add an element at the end of the queue, remove the first element, find the values of the first and last element, check if the queue is empty, and find the number of stored elements. Access to elements is not supported nor we traverse the queue. To use queue we must include the queue header file. Let's look at an example:

```cpp
#include <iostream> // Example 26.10
#include <queue>
int main() {
    std::queue<int> q;

    q.push(1);
    q.push(2);
    std::cout << " Front: " << q.front();
    std::cout << " End: " << q.back();
    q.pop();
    std::cout << " Size: " << q.size();
    return 0;
}
```

`push` adds the element at the end of the queue. front() returns the value of the first element and back() returns the value of the last one. pop() returns the first element and size() returns the number of the elements in the queue. Therefore, the program displays: Front: 1 End: 3 Size: 2

# The priority_queue template class

The priority_queue template class is similar to queue. Their main difference is that in priority_queue the elements are sorted according to some priority. The default priority is based on comparing elements using the < operator. The element stored at the front of the queue is the largest. For example:

```cpp
priority_queue<int> q;
q.push(20);
q.push(10);
q.push(30);
int i = q.top();
```

`top()` returns the first element of the queue, which is 30. If we want to change the ordering, we add the desired method as the third argument. The second argument indicates the type of the underlying container used to store the elements. example, if we write:

```cpp
priority_queue<int, vector<int>, greater<int>> q;
```

the sorting will be descending in order. Thus, the first element will be 10. We'll discuss later about the greater<.

# The stack template class

The stack class implements a LIFO (Last In First Out) stack, where elements are inserted and extracted from only one end of the container. The implementation supports the basic functionality of a stack, we can add an element at the top of the stack, remove the element from the top, find the value of the element at the top. To use stack we must include the stack header file. Let's look at an example:

```cpp
#include <iostream> // Example 26.11
#include <stack>
int main() {
    std::stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);
    std::cout << "Top: " << s.top() << endl;
    s.pop();
    std::cout << "Top: " << s.top() << endl;
    std::cout << "Size: " << s.size() << endl;
    return 0;
}
```

`push` adds the element at the top of the stack. top() returns the value of the element at the top. pop() removes the element from the top. size() returns the number of the elements in the stack. Therefore, the program displays: Top: 30 Top: 20 Size: 2

# Associative Containers

Associative containers are designed to store elements in a sorted order. They are useful when we need to search quickly. They are typically implemented using balanced binary search trees. The set container stores elements, where each element is unique. Similarly, the map container stores key-value pairs where each key is unique. The standard associative containers are set, multiset, map, and multimap.

# The set class

The set container stores elements, where each element is unique. The elements are stored in a sorted order. By default, the set uses the < operator to sort the elements. The set supports bidirectional iterators. Let's look at an example:

```cpp
#include <iostream>
#include <string>
#include <set>
#include <algorithm>
using namespace std;

void show(const string& s);

int main() {
    set<string> s = {"car", "the", "get", "sea", "sky"};
    set<string>::iterator it;

    cout << "Set after init: " << endl;
    for (it = s.begin(); it != s.end(); ++it)
        cout << *it << " ";

    s.insert("new");
    cout << "\nSet after insert: " << endl;
    for_each(s.begin(), s.end(), show);

    it = s.find("sky");
    s.erase(it);
    cout << "\nSet after erase: " << endl;
    for_each(s.begin(), s.end(), show);
    return 0;
}

void show(const string& s) {
    cout << s << endl;
}
```

When we create a set object we specify the type of the key it contains (e.g., string). insert() inserts the argument into the container. find() returns an iterator that points to the position where the argument is stored, if found. erase() removes the element indicated by the iterator.
