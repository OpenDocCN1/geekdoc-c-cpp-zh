**C.11.17** In math, the bisection method is used to find a root of a continuous function f(x) in a given interval [x0, x1] provided that f(x0)*f(x1) < 0. If this applies, the Bolzano’s theorem states that the function has one root at least in the interval (x0, x1). The method repeatedly bisects the interval and finds the subinterval in which the function changes sign, and therefore, must contain a root. Write a program that implements the bisection method according the following steps:

+   1. Read initial x0 and x1 values so that f(x0)*f(x1) < 0.
2. Read a positive number err for root tolerance error.
3. Read the maximum number of bisections (max_steps).
4. Calculate the approximate root middle = (x0+x1)/2.
5. If |f(middle)| <= err or x1-x0 becomes sufficiently small, then, x1 <= 2*err or the current number of bisections is greater than the input number (max_steps) then go to Step 7, otherwise go to Step 6.
