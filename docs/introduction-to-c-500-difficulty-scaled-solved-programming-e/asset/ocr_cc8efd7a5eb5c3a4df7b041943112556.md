C.2.7 Write a program that declares two floating-point variables (e.g., i, j), assigns to them two positive values (e.g., 3.45 and 6.78) and swaps their integer parts (i.e., i becomes 6.45 and j becomes 3.78). For casting, use the `static_cast<>` operator.

```
#include <iostream>
int main() {
    int k;
    float i = 3.45, j = 6.78, dec;
    dec = i - static_cast<int>(i); // Get the decimal part.
    k = static_cast<int>(i); /* Save the integer part, before changing its value. */
    i = static_cast<int>(j) + dec;

    dec = j - static_cast<int>(j);
    j = k + dec;
    std::cout << i << ' ' << j << '\n';
    return 0;
}
```
