Also, the attempt to release an already released memory or access the memory through a deleted pointer is wrong. For example:

```
int *p = new int;
...
delete p;
*p = 10; // Wrong.
delete p; // Wrong.
```

Notice the multiple use of delete to release the same memory is a serious error, which causes the undefined behavior of the program.

If the pointer is null, it is safe to delete delete. Since a null pointer does not point somewhere, the statement has no effect, nothing happens. For example:

```
int *p = nullptr;
delete p; // OK.
```

Thus, it is not necessary to use an if to check before releasing the memory:

```
if(p) // Not necessary.
{
    delete p;
}
```

To release memory that is allocated for many items with the new[] operator we use the delete[] operator. For example:

```
Student *p = new Student[100];
...
delete[] p;
```

The braces indicate to the compiler that it should release the whole memory, and not just the memory for the item that the pointer points to. If we forget the braces the behaviour is unpredictable. Unfortunately, the compiler most probably won't warn us about this error. Therefore, we need to be very careful not to forget the [].

> delete to release memory that is allocated with new and delete[] to release memory that is allocated with new[].

The released memory can be reused for new allocations. Note if we don't release the memory, it will be released automatically and returned back to the operating system when the program terminates.

Notice that releasing the memory it does not imply that the value of the pointer will become nullptr. For example, its value may still be equal to the address of the allocated memory. In general, to avoid disastrous situations it is considered a good practice to reset the value of the pointer to nullptr. For example, in large programs, where the same pointer may be used in different parts of the program, it would be better, for control and safety, to make nullptr nullptr when releasing the memory. For example:

```
delete[] p; // If it is null, there is no problem; delete has no effect.
p = nullptr;
```
