Notice the ; before exp2 must be present. In fact, the two ; must be present even if exp1 and exp2 expressions are omitted.

In a similar way, we can put exp3 in the loop body and remove it from the for statement. For example, in the following code, this expression a-- is inside the body.

```
for (a = 10; a >= 3; {
  cout << a << ' ';
  a--;
}
```

If the controlling expression exp2 is missing, the compiler treats it as always true, and becomes infinite, it is, never ends. For example, this for statement creates an infinite loop:

```
for (a = 0; a--);
```

Most programmers omit all three expressions in order to create an infinite loop. For example:

```
for();
```

Infinite loops are used in many applications, such as programs that receive data continuously or monitor the operational status of many systems. We will see later that if exp1 and exp3 are missing, the for statement is equivalent to the while statement.

```
for(; a >= 3); is equivalent to: while (a >= 3)
```

C++11 introduces another form of the for statement, which is called range-based for. We'll discuss it in Chapter 7.

# THE break STATEMENT

We've already discussed how a break statement terminates the execution of a switch statement. It can be used to terminate a for, while, or do-while loop and transfer control out of the loop. For example:

```
#include <iostream> // Example 6.4
int main() {
  int i, j = 3;
  for (i = 0; i < 10; i++) {
    if (i == j)
      break;
    std::cout << "Out: " << i << '\n';
  }
  return 0;
}
```
