# Use of const

For safety, if we do not want a function to be able to change the values of the array elements, we declare the parameter to be const. For example, with the declaration:

```
void test(const int arr[]); test() may access the elements of arr, but it cannot modify their values. For example, if we write:
```

```
void test(const int arr[])
{
  arr[0] = 10; // Compilation error.
```

the compiler will display an error message. const provides security, as we avoid the case of an unintended change, but also inform those who read or use our code that no change should be made. Note that this declaration does not oblige us to declare the passed array as const. It just says that test() can treat arr as read-only data. Also, if test() calls another function (e.g., f) and passes the array to it, the array parameter must be declared as const. For example:

```
void test(const int arr[])
{
  f(arr);
}
...
```

```
void f(const int p[])
{
}
```

If we omit const in f(), the compiler will display an error message similar to can convert from const int* to int*. And makes sense for the compiler to produce an error, since it wants to ensure that f() will not change the contents of the array. In general, declaring a pointer argument as const (remember, arr is treated as a pointer) indicates the programmer's intention that the value of the variable points to not change.

# Passing a Segment

When passing an array to a function, we can pass a part of it. For example, what does the following program display?

```
#include <iostream> // Example 11.23
```

```
void test(int ptr[]);
```

```
int main()
{
  int i, arr[6] = {1, 2, 3, 4, 5, 6};

  test(arr+3); // Alternatively, test(&arr[3]);
  for (i = 0; i < 6; i++)
    std::cout << arr[i] << ' ';
  return 0;
}
```
