
# Use of const

For safety, if we do not want a function to be able to change the values of the array elements, we declare the parameter to be const. For example, with the declaration:

```cpp
void test(const int arr[]); test() may access the elements of arr, but it cannot modify their values. For example, if we write:
```

```cpp
void test(const int arr[])
{
  arr[0] = 10; // Compilation error.
```

the compiler will display an error message. const provides security, as we avoid the case of an unintended change, but also inform those who read or use our code that no change should be demade. Note that this declaration does not oblige us to declare the passed array as const. It just says that test() can treat arr as read-only data. Also, if test() calls another function (e.g., f) and passes the array to it, the array parameter must be declared as const. For example:

```cpp
void test(const int arr[])
{
  f(arr);
}
...
```

```cpp
void f(const int p[])
{
}
```

If we omit const in f(), the compiler will display an error message similar to "can convert from const int* to int* And makes sense for the compiler to produce an error, since it wants to ensure that f() will not change the contents of the array. In general, declaring a pointer argument as const (remember, arr is treated as a pointer) indicates the programmer's intention that the value of the variable points to not change.

# Passing a Segment

When passing an array to a function, we can pass a part of it. For example, what does the following program display?

```cpp
#include <iostream> // Example 11.23
```

```cpp
void test(int ptr[]);
```

```cpp
int main()
{
  int i, arr[6] = {1, 2, 3, 4, 5, 6};

  test(arr+3); // Alternatively, test(&arr[3]);
  for (i = 0; i < 6; i++)
    std::cout << arr[i] << ' ';
  return 0;
}
```

```cpp
void test(int ptr[])
{
    int i, tmp[3] = {10, 20, 30};
    for(i = 0; i < 3; i++)
        ptr[i] = tmp[i];
    *ptr = *(ptr-1);
}
```

When (test()) is called, we have ptr = arr+3, that is, the part of arr from the fourth element and is passed. Since we use ptr as array, ptr[0] corresponds to arr[3], ptr[1] corresponds to arr[4], and ptr[2] to arr[5]. Therefore, the loop makes the values of arr[3], arr[4], and arr[5] equal to 10, 20, and 30, respectively. Since ptr points to arr[3], the statement *ptr = *(ptr-1) is equivalent to arr[3] = arr[2]. As a result, the program displays 1 2 3 20 30.

Let me ask a "weird" question. Could we write the following?

```cpp
void test(const int ptr[])
{
    std::cout << ptr[-1] << ' ';
}
```

Strange as it may seem, the answer is yes. As you already know from Chapter 8, ptr[-1] is equivalent to *(ptr-1) and since ptr is arr+3, it is equivalent to *(arr+2), that is, arr[2]. If it is certain that elements in the backward direction do exist, it is safe to use negative indexing and access them. Of course, if you're sure, please don't write code.

# Passing a vector Object

As said in Chapter 7, for greater safety and flexibility it is better to use the vector class instead of an ordinary array. And of course, we can pass a vector object in a function. For example, try the following exercise.

Write a function that takes parameters as a vector object that contains the grades in a test and returns the average. The program should take the number of students, create a vector, read the grades, and display the average.

```cpp
#include <iostream> // Example 11.25
#include <vector>
using namespace std;

void avg(const vector<int>& v)
{
    double sum = 0;
    for (int i = 0; i < v.size(); i++)
        sum += v[i];
    cout << "Average: " << sum / v.size() << endl;
}

int main()
{
    int num;
    cout << "Enter number of students: ";
    cin >> num;
    vector<int> grd(num);
    for (int i = 0; i < num; i++) {
        cout << "Enter grade " << i + 1 << ": ";
        cin >> grd[i];
    }
    avg(grd);
    return 0;
}
```

C.11.11 Write a function that takes two strings, uses them as pointers, and returns 0 if they are identical or the difference of the two non-matching characters. Write a program that reads two strings of less than 100 characters and uses the function to display the result of the comparison.

```cpp
#include <iostream>
using std::cout;
using std::cin;
```

```cpp
int str_cmp(const char *str1, const char *str2)
int main() {
    char str1[100], str2[100];
    cout << "Enter first text: ";
    cin.getline(str1, sizeof(str1));
    cout << "Enter second text: ";
    cin.getline(str2, sizeof(str2));
    int i = str_cmp(str1, str2);
    if(i == 0)
        cout << str1 << " = " << str2 << '\n';
    else if (i < 0)
        cout << str1 << " < " << str2 << '\n';
    else
        cout << str1 << " > " << str2 << '\n';
    return 0;
}
```

```cpp
int str_cmp(const char *s1, const char *s2) {
    while (*s1) {
        if (*s1 == '\0')
            return 0;
        s1++;
        s2++;
    }
    return *s1-*s2;
}
```
