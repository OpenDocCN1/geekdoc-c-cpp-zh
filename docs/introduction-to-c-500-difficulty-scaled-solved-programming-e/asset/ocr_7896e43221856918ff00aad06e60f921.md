When in doubt, a quick test to determine whether an expression is an lvalue or rvalue is to ask your-self if you can take use of its address (we'll learn how to do this with the & operator in Chapter 8). If you can, it is an lvalue. For example:

```
int f() {int c = 10; return c;
int a, b;

int* p1 = &a; // Yes you can, so a is an lvalue.
int* p2 = &(a+b); // No you can't, so a+b is an rvalue.
int* p3 = &10; // No you can't, so 10 is an rvalue.
int* p4 = &f(); // No you can't, f() returns an rvalue.
```

# ARITHMETIC OPERATORS

The arithmetic operators +, *, and / are used to perform addition, subtraction, multiplication, and division, respectively. If the operands have arithmetic type, the conversions discussed in Chapter 2 are applied, if necessary.

When both operands are integers, the / operator cuts off the decimal part. For example, suppose that a and b are values with 8 and 5, respectively. Then the result of a/b is 1, not 1.6. If both operands are negative the result is a positive number (e.g., -16/-3 is 5). If either of the operands is a floating point variable, the decimal part is not truncated. For example, the result of 16.0/5 is 0.5, because the decimal part maintains the constant floating-point.

The % operator is used to find the remainder of the division of two integers. Both operands must be integers, otherwise the % code won't compile. In example, the result of a%b is 3. If the operand of / % operator is 0, the result is undefined (the program may terminate abnormally).

Note that before C11, if one of the operands was negative and the other, the result of the division was implementation dependent. For example, the result of -9/5 could be -1 or -2, it depends on whether the implementation rounded up or down the result. C11 specifies that if one operand was negative, the result of the division has the sign of the divisor. Also, C11 specifies that the result of -9%5 could be either 4 or -4, it depends on whether the sign of the remainder matches the dividend.

These five operators are binary, they require two operands. Also, C11 provides the + and - unary operators which require one operand. The unary + has no effect. The unary - is the negation of its operand. When both binary and + - operators are mixed, the compiler figures out how to use them. For example:

```
int a = +30; // + has no effect.
a = -40; // - is interpreted as the unary operator.
int b = -(a-10); /* The inner - is interpreted as the binary operator and the
outer as the unary. */
a-; /* This statement does nothing. Careful, the value of a remains the
same. */
a = - // Now, the value of a changes.
```

The value of a becomes 40 and b equal to 50.
By convention, most programmers add a space before and after the operators. Most times I do the same; less often with the arithmetic operators though.
