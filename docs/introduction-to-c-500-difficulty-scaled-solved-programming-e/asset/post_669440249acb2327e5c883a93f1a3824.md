# COMPLEX DECLARATIONS

Now that we've learned to define functions, let's make a preface for deciphering complex declarations. Always decipher the declaration from inside out. Find the name of the variable and, if it is enclosed in parentheses (), deciphering from there. Then, continue with the next operator where the precedence order, from high to low is:

- a. the postfix operators. The parentheses () indicate a function, and the brackets indicate [] an array.
- b. the prefix operator * indicates "pointer to".

For example, the declaration of type: `int *p[5];`

Let's apply these precedence rules. The variable p is not enclosed in parentheses. Because [] take precedence over * we go right, so that p is "an array of five...", then left to * and have "an array of five pointers...", we add the type and end up with "an array of five pointers to integers".

Let's see another example: `int (*p)[5];`

Now, p is enclosed in parentheses. Deciphering starts inside, so we go left to * and we have p is "pointer to...", then go right, so we have "pointer to an array of five...", then left to add the type and end up with "pointer to an array of five integers". By the way, it is an example of how to initialize a pointer type. Suppose that arr is declared as `int arr[];`. To initialize p we write `p = &arr;` or with the declaration `int (*p)[5] = &arr;`

Another complex declaration: `int (*p)(int);`

Before that, we start that p is "function that takes an integer argument", then the precedence over *, we go right and have "pointer to a function with an integer argument...", then left to add the return type and end up with "pointer to a function that returns a pointer to an integer".

Leave the best for: `int (*p)[5](int);`

Like before, start deciphering inside the parentheses, p is "...", because [] take precedence over * we go right and have "an array of five pointers...", then left to *, and have "an array of five pointers to functions with argument...", then, because () take precedence over * we go right and have left to add the return type and end with the train "array of five pointers to functions with argument pointer to an pointer to an integer".

# THE return STATEMENT

The return statement is used to terminate immediately the execution of a function. A function can contain as many return statements as we need. In some programs, we've used the return statement to terminate the main() function, that is, the program itself when a condition is met. For example, the following program terminates if the user enters 2, otherwise it outputs the input value:

```cpp
#include <iostream> // Example 11.3
int main()
{
    int num;
    while (1)
    {
        std::cout << "Enter number: ";
        std::cin >> num;
        if (num == 2)
            return 0; // Terminate the program.
        else // else is not needed.
            std::cout << num << '\n';
    }
    return 0;
}
```

Notice that the last return will not be executed, as the first return terminates the program. The value returned by main() indicates the status of the program. The value 0 indicates normal termination, whereas a non-zero value typically indicates an abnormal termination.
If the function returns nothing, we just write `return`. Also, in this case, the return statement at the end of the function is unnecessary, since the function will return automatically. In the following example, the f() function compares the values of the two parameters, and if they are met, if they are different, it displays their average.

```cpp
void f(int a, int b)
{
    // Function body.
    if(a == b)
        return;
    cout << (a+b)/2.0;
    // It is not needed to add the return statement.
}
```

If the function is declared to return a value, each return statement should be followed by a value. As we see later, the value of the executed return is returned to the point at which the function was called. The calling function is free to use or discard the returned value. For example, I modified f() to return an integer value:

```cpp
int f(int a, int b)
{
    if(a == b)
        return 0;
    cout << (a+b)/2.0;
    return 1;
}
```

Notice that we are allowed to omit the second return statement at the end of the function. In that case, the compiler would, most probably, issue a warning message as 'f': not all control paths return a value or control end of non-void function. The standard says that leaving a value-returning function without a return statement causes undefined behaviour. The function returns an undefined value, which is undesirable and very dangerous if the calling function uses that value. So, we must be very careful to make a non-void function always return a value through all paths, otherwise unexpected problems may occur.

The type of the returned value should match the function's return type. If it does not match, the compiler will convert the return value, if possible, to the return type. For example:

```cpp
int test() {
    return 4.9;
}
```

Since test() is declared to return an int value, the returned value is implicitly converted to an int. Therefore, the function returns 4.

# FUNCTION CALL

A function can be called as many times as needed. When a function is called, the execution of the program continues with the execution of the function's code. In particular, the compiler allocates memory to store the function's parameters and the variables that are declared within its body. Typically, this memory is reserved from a specific part of the memory, called stack; it might not happen in all cases. For example, parameters are typically placed in system registers for faster access. For simplicity, we assume the memory is allocated on the stack. Moreover, the compiler allocates memory to store the address where the program returns once the function terminates. The allocated memory is automatically released when the function terminates. A more detailed discussion about the actions performed in the memory when a function is called is beyond the scope of this book.
