## C.5.6 A water supply company charges the water consumption, as follows:

- Fixed amount of $10.
- For the first 30 cubic metres, $0.6/m³.
- For the next 20 cubic metres, $0.8/m³.
- For the next 10 cubic metres, $1.1/m³.
- For every additional metre, $1.2/m³.

Write a program that reads the water consumption in cubic metres and displays the total cost. For example, if the consumption is 55 cm, the final cost is calculated as follows: cost = 10 + 30*0.6 + 20*0.8 + 5*1.1.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
  float meters, cost;

  cout << "Enter meters: ";
  cin >> meters;

  /* I don't do the fixed multiplications, to show in detail the method of the cost calculation. */
  if(meters <= 30)
    cost = 0.6*meters;
  else if (meters <= 50)
    cost = 0.6*30 + 0.8*(meters-30);
  else if (meters <= 60)
    cost = 0.6*30 + 0.8*20 + 1.1*(meters-50);
  else
    cost = 0.6*30 + 0.8*20 + 1.1*10 + (meters-60)*1.2;

  cost += 10;
  cout << "Cost: " << cost << '\n';
  return 0;
}
```

## C.5.7 Write a program that reads the grades of three students and displays them in ascending order.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    float i, j, k;

    cout << "Enter grades: ";
    cin >> i >> j >> k;

    if(i <= j && i <= k) {
        cout << i << ' ';
        if (j < k) {
            cout << j << ' ' << k << '\n';
        } else {
            cout << k << ' ' << j << '\n';
        }
    } else if(j < i && j < k) {
        cout << j << ' ';
        if(i < k) {
            cout << i << ' ' << k << '\n';
        } else {
            cout << k << ' ' << i << '\n';
        }
    } else {
        cout << k << ' ';
        if(j < i) {
            cout << j << ' ' << i << '\n';
        } else {
            cout << i << ' ' << j << '\n';
        }
    }
    return 0;
}
```

**Comments:** At first, we compare each grade with the other two, in order to find and display the lowest. Next, we compare the two remaining grades and display them in ascending order.

**C.5.8** The 13-digit International Standard Book Number (ISBN) is a unique code that identifies a book commercially. The last digit is a check digit to detect errors in the previous 12 digits. To calculate its value, each of the first 12 digits is multiplied, from right to left, by 1 or 3. The products are summed up and divided by 10. The check digit is the remainder of the subtraction from 10. If it is 10, it becomes 0. For example, assume the first 12 digits are: 978960931961.

- a. (9*1 + 7*3 + 8*1 + 9*3 + 6*1 + 0*3 + 9*1 + 3*3 + 1*1 + 9*3 + 6*1 + 1*3) = 126
- b. check_digit = 10 - (126 % 10) = 10 - 6 = 4

Write a program that reads a 13-digit ISBN code and checks the last digit to verify if it is valid or not.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    int dig1, dig2, dig3, dig4, dig5, dig6, dig7, dig8, dig9, dig10,
    dig11, dig12, dig13, chk_dig, sum;

    cout << "Enter ISBN's digits: ";
    cin >> dig1 >> dig2 >> dig3 >> dig4 >> dig5 >> dig6 >> dig7 >> dig8 >>
    dig9 >> dig10 >> dig11 >> dig13; /* A 13-digit number exceeds
    size of int type, we use a variable for each digit. */
    sum = dig1 + dig2*3 + dig3 + dig4*3 + dig5 + dig6*3 + dig7 + dig8*3 +
    dig9 + dig10*3 + dig11 + dig12*3;
    chk_dig = 10 - (sum%10);
    if(chk_dig == 10)
        chk_dig = 0;

    if(chk_dig == dig13)
        cout << "Valid ISBN\n";
    else
        cout << "Invalid ISBN\n";
    return 0;
}
```

**C.9** Suppose that two PCs reside in the same network. Write a program that reads their IP addresses (version 4) and displays if they are configured correctly. The user must enter each IP address in x.x.x.x form where x is an integer within [0, 255]. The value of the first octet of an IP address defines its class as follows:

- Class A: [0, 127]
- Class B: [128, 191]
- Class C: [192, 223]

If the two IP addresses indicate different classes, the PCs cannot communicate. If they belong to the same class, compare their network octet(s) to be compared according to their class. For example, the PCs with IP addresses 192.168.1.1 and 192.168.1.2 may communicate because they belong to the same class and the first three octets are the same. For your information, the method just described is referred to as class addressing. For more efficient management of IP addresses, classless addressing was introduced.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    char ch;
    int a1, a2, a3, a4, b1, b2, b3, b4;

    cout << "Enter first IP address: ";
    cin >> a1 >> ch >> a2 >> ch >> a3 >> a4;

    cout << "Enter second IP address: ";
    cin >> b1 >> ch >> b2 >> ch >> b3 >> b4;

    if(a1 < 128) {
        if(a1 == b1)
            cout << "Class A: Correct Configuration\n";
        else
            cout << "Class A: Wrong Configuration\n";
    } else if(a1 < 192) {
        if(a1 == b1 && a2 == b2)
            cout << "Class B: Correct Configuration\n";
        else
            cout << "Class B: Wrong Configuration\n";
    } else if(a1 < 224) {
        if(a1 == b1 && a2 == b2 && a3 == b3)
            cout << "Class C: Correct Configuration\n";
        else
            cout << "Class C: Wrong Configuration\n";
    } else
        cout << "Error: Wrong class\n";
    return 0;
}
```

**Comments:** Because the user enters the IP in x.x.x.x form I used the variable ch to get the dot.

**C.5.10** In a course, each test is graded by two graders. If the difference of their grades is less than diff, the final grade is their average. Otherwise, the test is reviewed by a third grader, as follows:

- a. If the difference of the third reviewer is equal to the average of the first two grades, that is the final grade.
- b. If it is less than the minimum (e.g., min) of the first two grades, the final grade is min.
- c. Otherwise, the final grade is the average of the third reviewer and the one of the first closest to it.

Write a program that reads the two grades, the difference and displays the final grade according to procedure.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    double g1, g2, g3, fin_grd, avg, min, max, diff;

    cout << "Enter grades: ";
    cin >> g1 >> g2;

    cout << "Enter difference: ";
    cin >> diff;
    if(g1 < g2) {
        min = g1;
        max = g2;
    }
    else {
        min = g2;
        max = g1;
    }
    avg = (g1+g2)/2;
    if((max-min) < diff) {
        fin_grd = avg;
    }
    else {
        cout << "Enter third grade: ";
        cin >> g3;
        if(g3 == avg) /* For simplicity, we make a simple comparison.
        However, this comparison is not safe as mentioned in Ch.2. */
        fin_grd = avg;
        else if(g3 < min) {
            fin_grd = min;
        }else {
            if(g3 > avg) // The max value is closer.
                fin_grd = (g3+max)/2;
            else
                fin_grd = (g3+min)/2;
        }
    }
    cout << fin_grd << '\n';
    return 0;
}
```
