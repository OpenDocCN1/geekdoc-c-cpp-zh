# TWO-DIMENSIONAL ARRAYS AND C-STYLE STRINGS

Two-dimensional arrays are often used to store multiple C-style strings. For example, the statement:

```
char str[10] [40];
```

declares the str[10] with ten rows. Each row can store a string of up to 40 characters. In case of shorter strings, there is a waste of memory.

We can store string literals in a two-dimensional array when it is declared. For example:

```
char str[3] [40] = "One", "Two", "Three";
```

the characters of "One" are stored in the first row of str, "Two" in the second row, and those of "Three" in the third row are not large enough to fill the null, characters are padded, as depicted here:

| str[0][0]str[0][2] | str[0][3] | ... | str[0][39] |
|---|---|---|---|
| O n | e | \0 \0 | ... | \0 \0 |
| str[1][0]str[1][1] | str[1][3] | ... | str[1][39] |
| T w | o | \0 \0 \0 | ... | \0 \0 |
| str[2][0]str[2][2] | str[2][3]str[2][5] | ... | str[2][39] |
| T h | r | e | \0 \0 ... | \0 \0 |
