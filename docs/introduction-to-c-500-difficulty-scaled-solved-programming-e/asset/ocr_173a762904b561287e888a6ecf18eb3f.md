```
#include <iostream> // Example 20.1
#include <string>
using std::cout;
using std::cin;
using std::string;

class Product {
public:
    string code;
    float prc;

    Product() { cout << "Base Constructor\n"; }
    ~Product() { cout << "Base Destructor\n"; }
    void show() const { cout << "\nC:" << code << " \n"; }
};

class Book : public Product {
public:
    string title;
    string auth;

    Book() { cout << "Derived Constructor\n"; }
    ~Book() { cout << "Derived Destructor\n"; }
    void display() const { cout << "T:" << title << " A:" << auth << " P:" << prc << "\n"; } // The function may access the members of the base class.
};

int main() {
    Book b;

    cout << "Product Details: ";
    cin >> b.code >> b.prc; // Access the members of the base class.

    cout << "Book Details: ";
    cin >> b.title >> b.auth;

    b.show(); // Call a function of the base class.
    b.display();
    return 0;
}
```

For simplicity, I used only public members. The main advantage of inheritance is that it allows us to use existing code without rewriting it. We all have to write the code that implements the derived class. In our example, Book inherited all Product members and functions. We do not have to add them again. Again, a Book object inherits the code and prc members and the show() function. Book contains its own members and functions.

When a derived object is created, the constructor of the derived class is called first. Then, it calls the constructor of the base class to create the object of the base class contained in the derived object. Thus, the derived object contains a base class sub-object. This relationship is also referred to as is-a relationship, in the sense that a derived class object is also a base class object. For example, a Book object is also a Product object.
