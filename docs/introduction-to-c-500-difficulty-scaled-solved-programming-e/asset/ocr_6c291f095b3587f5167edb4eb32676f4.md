```
Time mk_time(const int *ptr)
{
    Time tmp;

    tmp.hours = *ptr/3600;
    tmp.mins = (*ptr%3600)/60;
    tmp.secs = *ptr%60;
    return tmp;
}
```

**Comments:** To avoid copying the structure returned from mk_time() we could pass the address of a structure. For example, we could change the return type to void and pass the address of t to mk_time(). Thus, the function modifies the structure of the calling function instead of returning a new structure.

```
void mk_time(const int *ptr, struct time *tmp)
{
    tmp->hours = *ptr/3600;
    tmp->mins = (*ptr%3600)/60;
    tmp->secs = *ptr%60;
}
```
