All the containers of the STL library have iterators which use the != operator. However, some containers may not support comparisons by means of the < operator. In this case, the compilation will fail. And why? This was answered in Chapter 18, for better performance, in order to avoid the creation of a copy of the object. Thus, programmers prefer a common syntax for all cases rather to change it when it is used as iterators.

# The find() Function

The find() function works with each container and it is used to search for a value in a container. It takes three parameters. The first two are input iterators (e.g., first, last) that indicate the search range, which is [first, last]. The third is the value to be searched. If the value is found, find() returns an iterator that points to the position of its first occurrence. If not, it returns the value of the second argument (e.g., last). Because, as we'll see next, pointer also works as an iterator, let's look at an example of it using an array and vector:

```
#include <iostream> // Example 26.2
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int *p, arr[] = {10, 20, 30, 40, 50};

    p = find(arr, arr+5, 30);
    if(p != arr+5) cout << "Element " << *p << " found in position " << p-arr-1 << '\n';
    else cout << "Element not found\n";

    vector<int> v(arr, arr+5); /* Create a vector with the array elements. */
    vector<int>::iterator it;
    it = find(v.begin(), v.end(), 30);
    if(it != v.end()) cout << "Element " << *it << " found in position " << it-v.begin()+1 << '\n';
    else cout << "Element not found\n";

    return 0;
}
```

To give an idea how find() might be defined in STL, here is an implementation example:

```
template <typename Iterator, typename T>
Iterator find(Iterator start, Iterator end, const T& val) {
    for(Iterator p = start; p != end; ++p)
        if(*p == val)
            return p;
    return end;
}
```

In the first call of find() the Iterator is replaced with int*, while in the second call with the iterator member of the vector class.
