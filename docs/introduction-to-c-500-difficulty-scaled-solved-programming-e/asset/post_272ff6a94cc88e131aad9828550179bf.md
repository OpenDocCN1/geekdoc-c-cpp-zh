## Annex C: Hexadecimal System

This annex provides a brief description of the hexadecimal system. The base of the hexadecimal system is 16. The numbers 0-9 are the same as the decimal system. The numbers 10-15 are represented by the letters A to F. The correspondence of the hexadecimal system to binary and decimal systems is depicted in Table C.1.

Table C.1 Hexadecimal System

| HEX | BINARY | DECIMAL |
|---|---|---|
| 0 | 0000 | 0 |
| 1 | 0001 | 1 |
| 2 | 0010 | 2 |
| 3 | 0011 | 3 |
| 4 | 0100 | 4 |
| 5 | 0101 | 5 |
| 6 | 0110 | 6 |
| 7 | 0111 | 7 |
| 8 | 1000 | 8 |
| 9 | 1001 | 9 |
| A | 1010 | 10 |
| B | 1011 | 11 |
| C | 1100 | 12 |
| D | 1101 | 13 |
| E | 1110 | 14 |
| F | 1111 | 15 |

As shown, each hexadecimal digit (0 to F) is represented with four binary digits. For example, the hexadecimal number F4A4 is written in binary as: 1111 0100 1010.

To find the decimal value of a hexadecimal number that consists of $n$ digits (e.g., $d_{n-1}...d_2d_1d_0$), we apply the formula:

```
Decimal = \sum_{i=0}^{n-1} (d_i \times 16^i)
```

For example, the decimal value of F4A4 is: $(A \times 16^0) + (4 \times 16^1) + (F \times 16^2) = 10 + 64 + 3840 = 3914$.
