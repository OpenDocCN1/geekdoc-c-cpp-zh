the address of ptr, in hex. As you see, using pointers are very close to the hardware and the system’s memory. In the general case, if the type is T the type of &T is “pointer to T”.

The assignment of an integer value to a pointer variable will probably cause a compilation error. This is logical since a pointer is not an integer. For example:

```
int *ptr;
ptr = 10000; // Potential compilation error.
```

However, in applications that need direct access to hardware addresses (e.g., embedded systems), this cast can be used to allow the following assignment:

```
ptr = reinterpret_cast<int*>(10000); // Use a cast operator.
```

A pointer variable can be initialized when declared, providing the variable that it points has already been declared. For example:

```
int a, b, *ptr = &;
```

As a matter of style, I prefer to initialize the pointer variables in separate statements, not together with their declarations, in order to make it clearer. In some examples, I don’t want to save space.
The & operator cannot be applied to constants (e.g., &20), expressions (e.g., &(a+b)), and bits (we’ll discuss them in Chapter 13). It is only applied to memory, which are variables, array elements, and functions.

# NULL POINTERS

As with an ordinary, the initial value of a pointer variable is the content of its address, that is, the pointer points to “garbage” address. When we declare explicitly that the pointer points to nowhere, we assign the value 0. Many prefer to use the macro NULL, instead of O. The NULL is defined in several header files (e.g., stddef). A pointer assigned with NULL is called null pointer and points to nothing. For example, the following program outputs the initial value of the pointer and 0:

```
#include <iostream> // Example 8.2
int main() {
    int *ptr;
    std::cout << ptr << '\n';
    ptr = NULL;
    std::cout << ptr << '\n';
    return 0;
}
```

Although the value 0 can be used in a pointer context, using NULL makes the code easier to read. For example, the assignment p = 0 might confuse the reader. Is p a numeric variable or a pointer? In contrast, the assignment p = NULL; is more indicative that p is a pointer. The value of a pointer variable can be compared with NULL, as follows:

```
if(p != NULL) // Equivalent to if(p)
if(p == NULL) // Equivalent to if(!p)
```

As a matter of style, the syntax I do not prefer is if(!p).
