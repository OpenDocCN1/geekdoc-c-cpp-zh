# Properties of Nested Classes

To discuss the properties of a nested class, let's use the example of Mgt_Dpt. Before that, I'd like to make clear that the declaration of a nested class is not the same as containment, that is, to declare a class object as member of another class. For example:

```
class A
{
    ...
};
class B
{
    A a; // Containment.
};
```

Here, the creation of a B object invokes the creation of an A object. In our example, the creation of a Company object does not invoke the creation of the Mgt_Dpt object. To make it, the nested class just defines a type whose scope– restricted in the enclosing class.

One way to create a Mgt_Dpt object is to call the create_dpt() function. An object of the enclosing class contains only its own members. That is, it is to write:

```
Company cmp;
cmp.empl = 10; // Wrong, empl is not a member of Company.
```

As said, the Mgt_Dpt type is restricted within the Company. For example, if we were to define the constructor of the Mgt_Dpt outside the class we would use the scope operator and write:

```
Company::Mgt_Dpt::Mgt_Dpt(int c, int e) : code(c), empl(e) {
```

This syntax indicates that the Mgt_Dpt class is declared within the Company. For a similar reason I defined the show() method to show the syntax and there is no name conflict with the show() of Company. Each show() refers to its own class.

A nested class has special access privileges to the members of the enclosing class and vice versa, that is, the enclosing class has no special access privileges to the members of the nested class. That is, we follow the same rules to access the members of a nested class as we do with the public, protected, and private members of an ordinary class. For example, the code is a private member we are not allowed to write: m_ptr->code = 2;

Just as the enclosing class contains only its own members, an object of the nested class contains only its own members. That is, it is to write:

```
void Company::Mgt_Dpt::show()
{
    cout << tax_id; // Wrong.
};
```
