Note that it is not needed to declare m_ptr pointer to access the nested class. We could declare it as Mgt_Dpt object, which is, Mgt_Dpt m_ptr; and use the . operator instead of ->. I just wanted to show how to access the nested class using pointer. The program displays T:100 E:5 C:1.

With member functions, a nested class can be declared inside the enclosing class but defined outside it. For example:

```cpp
class Company {
public:
  class Mgt_Dpt;
  ...
};
```

To define the nested class we use the name of the enclosing class and the scope operator. For example:

```cpp
class Company::Mgt_Dpt {
  ...
};
```

# Properties of Nested Classes

To discuss the properties of a nested class, let's use the example of Mgt_Dpt. Before that, I'd like to make clear that the declaration of a nested class is not the same as containment, that is, to declare a class object as member of another class. For example:

```cpp
class A
{
    ...
};
class B
{
    A a; // Containment.
};
```

Here, the creation of a B object invokes the creation of an A object. In our example, the creation of a Company object does not invoke the creation of the Mgt_Dpt object. To make it, the nested class just defines a type whose scope– restricted in the enclosing class.

One way to create a Mgt_Dpt object is to call the create_dpt() function. An object of the enclosing class contains only its own members. That is, it is to write:

```cpp
Company cmp;
cmp.empl = 10; // Wrong, empl is not a member of Company.
```

As said, the Mgt_Dpt type is restricted within the Company. For example, if we were to define the constructor of the Mgt_Dpt outside the class we would use the scope operator and write:

```cpp
Company::Mgt_Dpt::Mgt_Dpt(int c, int e) : code(c), empl(e) {
```

This syntax indicates that the Mgt_Dpt class is declared within the Company. For a similar reason I defined the show() method to show the syntax and there is no name conflict with the show() of Company. Each show() refers to its own class.

A nested class has special access privileges to the members of the enclosing class and vice versa, that is, the enclosing class has no special access privileges to the members of the nested class. That is, we follow the same rules to access the members of a nested class as we do with the public, protected, and private members of an ordinary class. For example, the code is a private member we are not allowed to write: m_ptr->code = 2;

Just as the enclosing class contains only its own members, an object of the nested class contains only its own members. That is, it is to write:

```cpp
void Company::Mgt_Dpt::show()
{
    cout << tax_id; // Wrong.
};
```

Since tax_id is not a member of the Mgt_Dpt class, the compiler will display an error message. And how could the nested class have access to the members of the enclosing class? One way is to pass a pointer when an object of the nested class is created. For example, let's change the constructor of Mgt_Dpt and pass to it this pointer of the Company object:

```cpp
class Mgt_Dpt
{
    private:
        Company *c_ptr;
        ...
    public:
        Mgt_Dpt(Company *p, int c, int e) : c_ptr(p), code(c), empl(e) {}
};
```

and call the constructor like this:

```cpp
void Company::create_dpt(int c, int e) {
    m_ptr = new Mgt_Dpt(this, c, e);
}
```

in order to pass the pointer of the Company. This pointer is stored in c_ptr, so it can be used whenever we want to access the members of the enclosing class. For example, we can write:

```cpp
void Company::Mgt_Dpt::show() {
    cout << c_ptr->tax_id;
};
```

In this way, a function of the nested class may access the members of the enclosing class, even if private members (e.g., tax_id).

# Access to Nested Class

As said, a nested class defines a type within the enclosing class. This type can be used by all the members of the enclosing class, regardless of whether it is declared in the public, protected or private part of the enclosing class. However, any member, the point of its declaration determines if it can be used from outside the enclosing class. That is, if we want to create Mgt_Dpt object we can write:

```cpp
int main() {
    Company::Mgt_Dpt m(1, 5);
    m.show();
};
```

Because Mgt_Dpt has class scope, the scope operator and the name of the enclosing class must be used. However, if Mgt_Dpt had been declared in the private or protected part, this declaration would not be allowed and the compiler would issue an error message.

Regarding public inheritance, we'll discuss in Chapter 20, if the nested class is declared in the public or protected part it is available in the derived class, and therefore the derived class can create objects of the nested class, whereas if it is declared in the private part it is not.

C.19.1 What is the output of the following program?

```cpp
#include <iostream>

class T {
public:
    int a;
    T(int i) {a = i;}
    T(const T& t) {std::cout << t.a << ' ';}
};

void f(T p) {
    p.a = 10;
}

int main() {
    T *p1, *p2;
    p1 = new T(20);
    p2 = new T(30);
    T r(*p1);
    f(*p2);
    std::cout << r.a << ' ' << p1->a << ' ' << p2->a << std::endl;
    delete p1;
    delete p2;
    return 0;
}
```

Answer: When r is created, the copy constructor for r is called, the reference t refers to *p1. So, the program displays 20. Since r is not initialized it has a random value. For example, if we add a statement a=1; in the copy constructor, r.a will become 1. Because an object is passed to f() the copy constructor is called, and the reference t refers to *p2. So, the program displays 30 and because *p2 is passed by value through the statement p.a = 10; does not affect the value of a member of *p2. Then, the program displays the value of r.a, 20, and 30.

# Answer:

```cpp
#include <iostream>
#include <string>
#include <cstdlib> // For the exit() function

class T {
private:
    char *s;
public:
    explicit T(const char str[]);
    T() { s = nullptr };
    ~T();
    T(const T& t);
    T& operator+(const T& t);
    T& operator=(const T& t);
    char& operator[](int i);
};

T::T(const char str[]) {
    s = new char[strlen(str) + 1];
    strcpy(s, str);
}

T::~T() {
    delete[] s;
}

T::T(const T& t) {
    s = new char[strlen(t.s) + 1];
    strcpy(s, t.s);
}

T& T::operator=(const T& t) {
    if (this == &t) {
        return *this;
    }
    delete[] s;
    s = new char[strlen(t.s) + 1];
    strcpy(s, t.s);
    return *this;
}

T T::operator+(const T& t) {
    T tmp; 
    tmp.s = new char[strlen(s) + strlen(t.s) + 1];
    strcpy(tmp.s, s);
    strcat(tmp.s, t.s);
    return tmp; // Note: This is a simplified implementation for the exercise
}
// The actual implementation for operator+ needs proper memory management and return copy.

char& T::operator[](int i) {
    return s[i];
}
```
