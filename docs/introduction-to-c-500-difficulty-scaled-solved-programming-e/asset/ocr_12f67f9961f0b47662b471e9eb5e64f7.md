# OPERATOR PRECEDENCE

As shown in Annex A, each operator has a precedence that determines the order in which operators are evaluated. In an expression with several operators, the operators with higher precedence are evaluated first. For example, since the * has higher precedence than the + and - operators, the result of:10-2*4+1 is 3.

When operators of equal precedence appear in the same expression, the operators are evaluated according to their associativity. For example, since * and / have the same precedence and are left associative, the result: 6/2*4/3 is 4, because the division 6/2 = 3 is executed first, then the multiplication 3*4 = 12, and the division 12/3 = 4. In another example, do the following statements assign the value to a?

```
float a, b = 4, c = 3;
a = 2/3*b;
a = b*c/2;
```

Since the result of 2/3 is 0, the first statement assigns 0 to a. Since multiplications are performed first and the numerator is float, the second statement assigns 8 to a.
