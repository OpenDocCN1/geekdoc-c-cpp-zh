**C.10.15** Write a program that reads a string and stores it in a string object. Then, the program should display it after replacing all 'a' characters that may appear at the beginning and at the end of the string with the space character. For example, if the user enters "aabcdaaa", the program should display " bcd ", while the input string is "bcddaa", the program should display "bcd ",

```
#include <iostream>
#include <string>
using std::cout;
using std::cin;
using std::string;

int main() {
    string str;
    int i, len;

    cout << "Enter text: ";
    getline(cin, str);
    len = str.size();

    for(i = 0; i < len; i++) {
        if(str[i] == 'a')
            str[i] = ' ';
        else
            break;
    }
    for(i = len-1; i >= 0; i--) {
        if(str[i] == 'a')
            str[i] = ' ';
        else
            break;
    }
    cout << "New text: " << str << "\n";
    return 0;
}
```

**Comments: The first loop compares the characters in the beginning of the string with 'a'. If it is an 'a', it is replaced with the space character, otherwise the loop terminates. Similarly, the second loop replaces all 'a' characters at the end of the string with the space character.**

**C.10.16** is the output of the following program?

```
#include <iostream>
#include <string>
int main() {
    char str[] = "csf", *p = str;
    while(*p) {
        --p; /* To make it harder, I could merge the two statements */
        p++;
    }
    std::cout << strlen(str) << '\n';
    return 0;
}
```

Answer: The statement --p; decreases the content of the address that p points to. For example, in the first iteration, p points to the first character of the string, which is 'c'. Therefore, *p is equal to 'c' and the statement --p; changes the value of str[0] and makes it equal to the previous character. Next, p is increased and points to the next element of str. In the same way, the next iterations make str[1], str[2], str[3], and str[4] equal to 'e', 'a', and 'k', respectively. The loop terminates once p becomes equal to str+5, which is the null character. Since strlen() returns the length of the string, the program displays 5.

**C.10.18** Write a program that reads strings and stores it in a string object. Then, the program should display the number of appearances of lowercase letters and digits. Also, the program should display the lowercase letter which appears the most times and the number of its appearances. If the string contains more than one letter with the same maximum number of appearances, the program should display the one found.

```cpp
#include <iostream>
#include <string>
using std::cout;
using std::cin;
using std::string;

int main() {
    string str;
    char ch, max_ch;
    int i, max_times, low_let[26] = {0}; // The size of the array is equal to the number of lowercase letters. This array holds the number of appearances of each letter. For example, low_let[0] holds the appearances of 'a', and low_let[25] holds the appearances of 'z'.
    int dig[10] = {0}; // Similarly, dig[0] holds the appearances of digit 0, dig[9] the appearances of digit 9.

    cout << "Enter text: ";
    getline(cin, str);

    max_ch = max_times = 0;
    for(i = 0; i < str.size(); i++) {
        if(str[i] >= 'a' && (str[i] <= 'z')) {
            ch = str[i]-'a';
            low_let[ch]++; // For example, if the character is 'a', value of low_let['a'-'a'] = low_let[0], which holds the appearances of 'a', will be incremented by one.
            if(low_let[ch] > max_times) {
                max_times = low_let[ch];
                max_ch = str[i];
            }
        } else if(str[i] >= '0' && (str[i] <= '9') {
            dig[str[i]-'0']++;
        }
    }

    cout << "****** Lower case appearances\n";
    for(i = 0; i < 26; i++)
        if(low_let[i] != 0) /* Check if the letter appears once at least. */
            cout << "Letter " << (char)('a'+i) << " appeared " << low_let[i] << " times\n";

    cout << "****** Digits appearances\n";
    for(i = 0; i < 10; i++)
        if(dig[i] != 0)
            cout << "Digit " << i << " appeared " << dig[i] << " times\n";
    if(max_times != 0)
        cout << max_ch << " appears " << max_times << " times\n";
    return 0;
}
```

Comments: If the string contains more than one character, which appears the same most of times, for example, if the user enters exit!, the output would be: 'e' appears 1 times, because all characters appear once and the character 'e' is the first one.
