int a(5.2); // The compiler informs the programmer for the conversion of the float number to an integer. */
```

An empty list {} is used to assign a default value. For example, the default value for an integer or float type is 0, and for pointers we will see it in Chapter 8 the nullptr:

```cpp
int a(); // a becomes 0.
char *p{}; // p becomes nullptr.
```
