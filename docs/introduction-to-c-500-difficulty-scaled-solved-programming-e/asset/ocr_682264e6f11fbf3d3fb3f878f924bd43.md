```
#include <iostream>
#include <string>
using std::string;

class Person {
private:
    string name;
    int code;
public:
    Person(const string& n = "None", int c = -1) : name(n), code(c) {}
    virtual ~Person() {}{
    virtual float& operator[](int i) = 0;
};

class Student : public Person {
private:
    float grd[5];
public:
    virtual float& operator[](int i);
};

class Employee : public Person {
private:
    float fee[3];
public:
    virtual float& operator[](int i);
};

float& Student::operator[](int i) {
    return grd[i];
}

float& Employee::operator[](int i) {
    return fee[i];
}
```

**Comments:** We check main() to show how to implement the classes. At first, when we read the comments in the creation of the objects we understand that we define a default constructor in Person with predefined values. Then, we see that p points to s, *p corresponds to s. Therefore, the statement (*p)[3] = 5; is s[3] = 5. To allow this we conclude that the Student class must overload the [] operator. The operator[] overload function should take as an argument parameter and return a reference to the respective element in the array, so that its value can be modified. Similarly, with the (*p)[1] = 100; which is equal to e[1] we conclude that the [] operator must also be overloaded in the Employee class. In order for depending on the type of the object pointed by the p pointer, the function must be declared as virtual in the base class. Because the exercise requires the base class to abstract we declare the function as pure virtual.
