Once a variable is declared, as shown in Table 2.1, the char type receives one byte, while the double type receives eight bytes. the compiler saves the value of the variable and its memory address, whenever a variable is used within the program, the compiler uses the name to retrieve the corresponding address and content. For example, with the statement i = 10; the compiler stores the value 10 into the memory location corresponding to i. As we see in Chapter 8 we can use the & to retrieve the memory address of i. Note that the value, like any other value (e.g., float, character, ...), is stored in memory as a sequence of 0s and 1.

Next, we will see that specific properties change when declaring a variable, such as the type quality and storage class (we'll discuss it about in Chapter 11). Although they may appear in any order, the typical practice is to specify the storage class first, then the variable, and last the date. For example: static unsigned int a;

Until we reach Chapter 11, we declare all within main(). Those variables are automatic, in the sense that their lifespans end when the program terminates. Their initial value is indeterminate (i.e., garbage), that is, the initial value of a variable is whatever happened to be at its memory location. For example, the following program displays the initial value of i:

```
#include <iostream> // Example 2.2.
int main() {
    std::cout << i;
    return 0;
}
```

In general, using variables that have not been initialized is very dangerous and can cause the program to behave unpredictably. Most likely, the compiler will warn you of use, but you should also be careful.

A variable can be declared anywhere in the program. Many prefer to declare the variable when it is needed to be used. In most cases, I prefer to declare all the variables at the beginning of each function, so that some who reads the code can quickly get an idea of the complexity of the function and the type of variables it uses. I find it more convenient to have them all together in one place, so when you want to see the type of a variable you don't have to search for its declaration point. On the other hand, there are cases where it is more efficient to declare the variable after checking certain conditions. Here is an example to avoid an unnecessary memory allocation:

```

}
```
