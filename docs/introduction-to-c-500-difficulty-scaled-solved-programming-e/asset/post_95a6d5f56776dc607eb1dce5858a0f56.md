
## Class Templates

A template parameter can be mixed with ordinary parameters. For example, let's change the declaration of C:

```cpp
template <typename T> class Test, typename X, typename Y> class C
{
  ...
  Test<X> t1;
  Test<Y> t2;
};
```

Thus, those that are used for the t1 and t2 objects become generic. Of course, we should change the declaration of C to:

```cpp
C<A, int, double> c;
```

The Test will be replaced with A, X with int, and Y with double.

## Default Parameter Values

In a class template we can specify default values for its parameters. For example:

```cpp
template <typename T1, typename T2 = int> class Group {...}
```

It works similar to the default values for function parameters. If we omit the type of T2 and write Group<double> g; the type of T2 will be int. A class template provides default values for all parameters and we want to use all of them when we use empty <>. For example:

```cpp
template <typename T1, typename T2 = int> class Group {...}
```

If we write Group<int>; the type of T1 will be string and the type of T2 will be int. We can also specify default values for non-type parameters. For example:

```cpp
template <typename T, int s = 20> class Grades {...}
```

If we write Grades<int>; the type of T will be int and s equal to 20.

## Static Members

A class template can contain static members. Be careful though, each version of the class contains its static members. For example:

```cpp
#include <iostream> // Example 23.7

template <typename T> class A
public:
  A() {cnt++;}
  static inline int cnt = 0; // Since C++17.
  static int f() {return cnt;}
};

int main()
{
  A<int> a1, a2, a3;
  A<double> d1, d2;
  std::cout << A<int>::cnt << ' ' << d1.cnt << '\n';
  // A::cnt = 10; Wrong.
  std::cout << a.f() << ' ' << d2.f() << '\n';
  return 0;
}
```

Each version of the class has its own instances of static members. The A<int>::cnt is different from the A<double>::cnt. All the A<int> objects share the same A<int>::cnt variable and A<int>::f() function, while the A<double> objects share the same A<double>::cnt variable and A<double>::f() function. When the A<int> and A<double> classes are created, the respective counters are initialized to 0. Because three A<int> objects and two A<double> objects are created, the program displays 3 and 2. As static members of non-class templates, to access a static member we can use either of the class or the scope operator and the specific class. That is, it is wrong to write A::cnt = 10.

## Recursive Use

A class template can be used recursively. For example:

```cpp
#include <iostream> // Example 23.8

template <typename T, int n> class Array
{
public:
    T data[n];
};

int main()
{
    Array<Array<int, 10>, 20> arr;
    arr.data[0][8] = 3; // Example how to access an element.
    std::cout << sizeof(arr.data[0]) << '\n';
    return 0;
}
```

Initially, the compiler replaces T with int and n with 10 and defines the Array<int, 10> class. The data member of the Array<int, 10> is an array of 10 integers. Then, it replaces T with this, so that arr.data is an array of 20 elements, where each element is an object of the Array<int,10> class. So, the program displays 40 (assuming that the int type is 4 bytes). The equivalent ordinary array would be declared as: int arr[20][10];

## Templates as Members

A class template can be a member of a structure, or another class. For example the following class template contains a nested class and a function template:

```cpp
#include <iostream> // Example 23.9

template <typename T1> class A
{
private:
    T1 m;
    template <typename T2> class B {
    private:
        T2 p;
    public:
        B(T2 i) { p = i; }
        void show() const { std::cout << p << '\n'; }
    };
public:
    A(T1 i) { m = i; }
    template <typename T2>
    B getB() { return B<T2>(m); }
};

int main() {
    A<int> a(5);
    A::B<int> b = a.getB<int>();
    b.show();
    return 0;
}
```

## CLASS TEMPLATE AND FRIENDS

Like an ordinary class, a class template can also have friends. Its friends can be classes, functions, class templates, or function templates. If a class is a friend of a class template, then its member becomes friends to all instantiations of the class. A friend function can be:

- a. non-template.
- b. template, where an instantiation of the friend function is friend only to the respective instantiation of the class.
- c. template, where all instantiations of the friend function are friends to each instantiation of the class.

## Non-Template Friend Functions

When a class template contains a non-template friend function, the function becomes friend to all instantiations of the class template. For example:

```cpp
#include <iostream> // Example 23.10

template <typename T> class A
{
private:
    T p;
public:
    A(T i) {p = i;}
    friend void f(A& a);
    friend void g();
};

// Friend function of all A<int> classes.
void f(A<int>& a)
{
    std::cout << a.p << '\n';
}

// Friend function of all A<double> classes.
void f(A<double>& a)
{
    std::cout << a.p << '\n';
}

// Friend function of all A<T> classes.
void g()
{
    A<char> tmp('t');
    std::cout << tmp.p << '\n';
}

int main() {
  A<int> a(5);
  A<double> d(2);
  f(a);
  f(d);
  g();
  return 0;
}
```

The g() function becomes friend of all instantiations of the A class template. The reason I made f() to take a template function is to see how f() is associated with the A instances. When an object is defined, T is replaced with int and the prototype of f() becomes:

```cpp
class A<int> {
  friend void f(A<int>& a);
};
```

Thus, the f() with parameter A<int>& becomes a friend function of the A<int> class. Similarly, the f() with parameter A<double>& becomes a friend function of the A<double> class. Note that f() is not a function template; it takes a template function. This is why we need to define explicit specializations of f() for the types we want to use. If, the definition of f() with parameter A<double>& was missing, the compiler would display an error message in the statement f(d); To make it clear, g() has one-to-one friend relationship with class A, that is, it is friend to all instantiations of A, and f() has one-to-one relationship. The program displays 5, 2, and t.

## Friend Function Template Bound to Class Template

When a class template contains a friend template, each version of the class can be bound to a matching version of the friend function. Let's see an example, where a class template contains two friend templates:

```cpp
#include <iostream> // Example 23.11
template <typename T> void f();
template <typename T> void g(T& t);

template <typename T> class A {
private:
  T p;
  static inline int cnt = 0;
public:
  A(T i) {p=cnt++;}
  friend void f<T>();
  friend void g(A<T>& t); // We could also write g<A<T>>(A<T>& t);
};

template <typename T> void f() {
  std::cout << A<T>::cnt << '\n';
};

template <typename T> void g(A<T>& t) {
  std::cout << t.p << '\n';
}
```
