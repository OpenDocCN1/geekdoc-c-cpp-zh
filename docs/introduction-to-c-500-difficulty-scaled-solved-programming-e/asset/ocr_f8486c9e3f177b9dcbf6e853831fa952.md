The T(n) triangular number declares the number of the objects composing the equilateral triangle, and it is equal to the sum of the numbers from 1 to n. Therefore, T(n) is expressed as T(n)=1+2+3...+(n-1)+n

```
and in a recursive form: $T(n) = \begin{cases} n, & for=0 or n=1 \ n+T(n-1), & for>1 \end{cases}$
```

Write a program that reads a positive integer (e.g., n) up to 20 and uses a recursive function to display the T(n) triangular number.
