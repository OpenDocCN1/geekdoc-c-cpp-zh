# Constructor

The constructor is a special function of the class, which is called whenever an object of this class is created. The declaration of a constructor must follow some rules. In particular, it must have the same name as the class, it has no return type, it is not allowed to be declared as const, it can accept parameters, and it can be overloaded, that is, a class can have many constructors. With ordinary functions, the different versions of the constructors may differ in the number or type of parameters.
Typically, a constructor is used to assign values to the members of the class or to allocate memory. For example, in the C.17.1 example, because direct access to the code member is not allowed, we cannot write something like this:

```
s = {100, "Name", 5.5};
```

Of course, if all members were declared public, this declaration would be acceptable, but I refer to the general case where a class contains private members, data hiding is not the reason for using a class. The code is initialized after the creation of s by calling a member function, such as set(). Note that if a member variable of either basic type (e.g., int) or pointer (e.g., int*) is not initialized, it will have an arbitrary junk value.
If we want to initialize the members of an object when it is declared we use the constructor to do it. In fact, this is my preference, I prefer to define a constructor and initialize the members rather than calling initialization function, such as set(), after the creation of the object. Not only is it convenient, but it is also safer, especially when creating multiple objects, since we may forget to initialize some of them. When the constructor is used to assign the initial values there is no reason to worry about.
By the way, this kind of functions (e.g., set()) allow member values to be set from outside the class and respect functions that their values are often referred to as setters and getters.

Note that if a class contains a member which is an object of another class (e.g., string name), its constructor is called first to create the member and then the constructor of the class is executed. Exercise C.17.3 is such an example.
And if something goes wrong with the constructor, how can we handle such a situation? For example:

```
Test::Test(int size)
{
    p = new int[size];
}
```

What if a negative value is passed to size? What we certainly cannot do is to return a special value that indicates the error, as we said, a constructor does not return a value. We'll see in Chapter 22, an easy way is to create an exception that informs the programmer about error. For example, we can add something like this:

```
if(size < 0)
    throw Negative_Size();
```
