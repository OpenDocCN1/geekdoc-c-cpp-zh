# READING CHARACTERS

There are many ways to read a character from the input stream. The most common is to use the get() function, which is a member of the ist class. For those who have experience in C, get() works similar to getchar(). Note that getchar can also be used. get() starts reading characters when the user presses the Enter key. If it is executed successfully, it returns the character read as int. If no more characters are available in the stream, get() returns a special value defined as EOF (End Of File). This value is different from any character value, so it cannot be confused with a regular character. EOF is typically -1, but it is better to use EOF, so that your program does not depend on the numeric value.

For example, if the user types abc and presses Enter, the first call of get() returns 'a', the second returns 'b', the third 'c', and the fourth '\n'. If it is called, the program "stacks" until the user enters new character(s) and presses Enter. The next program displays and counts the input characters until the user presses Enter.

```cpp
#include <iostream> // Example 9.2
#include <cstdio>
using std::cin;
using std::cout;

int main()
{
    int ch, sum;

    cout << "Enter characters: ";
    sum = 0;
    while ((ch = cin.get()) != '\n' && ch != EOF) /* The inner parentheses
are necessary, because the != operator has greater precedence than =. */
    {
        sum++;
        cout << (char)ch; // Cast the type to display the character.
    }
    cout << '\n' << sum << " characters are read\n";
    return 0;
}
```

get() returns one by one input characters until the '\n' character is met. Each character is stored in ch and value is tested against EOF to determine if it is valid.

# 220 Introduction to C++

Notice the return type of get() should be stored into an int variable, not char. See why. Suppose that char is declared as char. the char type is signed and the character with value 255 is, it will be stored as -1 into char. As a result, the condition which tests that value EOF becomes false and the loop stops reading more readers. If the char type is unsigned and get() returns EOF, you won't be stored as -1; the loop will terminate.

In case you where we do not read characters with cin in the same way we read numeric values, the reason is that white characters (e.g., spaces, tabs) are skipped by default. For example:

```cpp
#include <iostream> // Example 9.3
int main()
{
    std::cout << "Enter character: ";
    std::cin >> ch;
    if(ch == ' ')
        std::cout << (int)ch;
    return 0;
}
```

Since the characters are skipped, if the user enters a space and presses Enter, the program neither displays something nor it terminates. To terminate, you must enter a non-white character. This behavior can change using the noskipws manipulator. That is, if we:

cin >> noskipws >> ch;

the white characters are not ignored. So, if the user enters a space the program displays the ASCII value of the space (i.e., 32) and in the general case the program is continuously reading characters until the user enters a specific character I prefer get(), because it does not skip the character (e.g., the program may require to count all the characters) and it is also easy to check with the EOF, the validity of the character.

An unexpected behaviour that makes many novice programmers wonder why their program is not working properly and make them crazy enough to crash the computer occurs when reading characters after reading numeric values. The following program is an example. Do you notice malfunction in the program when the user enters an integer and presses Enter?

```cpp
#include <iostream> // Example 9.4
using std::cout;
using std::cin;
int main()
{
    int i, ch;

    cout << "Enter number: ";
    cin >> i;

    cout << "Enter character: ";
    ch = cin.get();
    cout << i << ' ' << (char)ch << '\n';
    return 0;
}
```

In case the user enters an integer and presses Enter, the generated new line character is stored in the input queue. get() gets it from there and stores it into the ch variable, without leaving the user type

other character. The program displays the input integer. There are several methods to get rid of the '\n' character. One solution is to add another get() before the second cout, that is, cin.get(); Also, if we reverse the order, that is, first read the character then the integer, the program will behave normally, because white spaces, such as '\n', are ignored before a numeric value.

# EXERCISES

C.9.1 Write a program that reads three characters and checks if they are consecutive in the set.

```cpp
#include <iostream>
using namespace std;

int main() {
    char c1, c2, c3;
    cin >> c1 >> c2 >> c3;
    if (c2 == c1 + 1 && c3 == c2 + 1)
        cout << "Consecutive" << endl;
    else
        cout << "Not consecutive" << endl;
    return 0;
}
```

C.9.3 Write a program that reads a character and displays whether it is uppercase or lowercase.

```cpp
#include <iostream>
using namespace std;

int main() {
    char ch;
    cin >> ch;
    if (ch >= 'A' && ch <= 'Z')
        cout << "Uppercase" << endl;
    else if (ch >= 'a' && ch <= 'z')
        cout << "Lowercase" << endl;
    else
        cout << "Neither" << endl;
    return 0;
}
```
