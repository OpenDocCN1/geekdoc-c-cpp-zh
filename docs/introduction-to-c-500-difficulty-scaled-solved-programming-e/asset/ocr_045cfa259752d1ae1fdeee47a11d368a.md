Since the name of array can be used as a pointer to its first element, the content is equal to the value of its first element. Therefore, *arr is equal to arr[0]. In a similar way, so arr+1 is a pointer to the second element, *(arr+1) is equal to arr[1], and so on. In general, the following expressions are equivalent:

```
*arr = arr[0]
*(arr+1) == arr[1]
*(arr+2) == arr[2]
...
*(arr+n) == arr[n]
```

The parentheses are necessary because the * operator has higher precedence than the + operator. The expressions, *(arr+n) and *arr+n are evaluated in a different way. For example, consider the following:

```
#include <iostream> // Example 8.11
int main()
{
    int *ptr, arr[5] = {10, 20, 30, 40, 50};

    ptr = arr+1;
    std::cout << *ptr+2 << " '" << *(ptr+2) << '\n';
    return 0;
}
```

With the statement ptr = arr+1; ptr becomes the address of arr[1], so *ptr is equal to arr[1], that is, 20. Since the * operator has higher precedence than +, *ptr+2 is equal to 20+2 = 22. The value of *(ptr+2) is the content of the array ptr points to increment by two positions. Therefore, *(ptr+2) is equal to arr[3]. As a result, the program displays: 22 40

The following programs use array subscripting and pointer arithmetic to display the addresses and values of arr elements in two different ways:

```
#include <iostream> // Example 8.12
int main()
{
    int arr[5] = {10, 20, 30, 40, 50};

    std::cout << "***** Using array notation *****\n";
    for(int i = 0; i < 5; i++)
        std::cout << "Addr: " << &arr[i] << " Val: " << arr[i] << '\n';

    std::cout << "\nn***** Using pointer notation *****\n";
    for(int i = 0; i < 5; i++)
        std::cout << "Addr: " << arr+i << " Val: " << *(arr+i) << '\n';

    return 0;
}
```
