
# THE ++ AND -- OPERATORS

The ++ increment operator is used to increment the value of a variable by 1. It can be added before (prefix) or after (postfix) the variable's name. The operand must be a modifiable lvalue, such as an ordinary variable. For example:

```cpp
int a = 10;
a++; // Equivalent to a = a+1;
++a; // Equivalent to a = a+1;
(a+10)+; // Wrong.
```

The value of a is incremented twice and becomes 12.
If the ++ operator is used in postfix form, the increment is performed after the current value of the variable is used in an expression. For example:

```cpp
int a = 10, b;
b = a++;
```

the current value of a is first stored into b, and then a is incremented. Therefore, a becomes 11 and b becomes 10.
If used in the prefix form, the variable's value is first incremented and the new value is used in the evaluation of the expression. For example:

```cpp
int a = 10, b;
b = ++a;
```

a is first incremented, and then that is stored into b. Therefore, both becomes 11.
The -- operator is used to decrement the value of a variable by 1. For example:

```cpp
int a = 10;
a--; // Equivalent to a = a-1;
--a; // Equivalent to a = a-1;
```

The value of a is decremented twice and becomes 8. When the -- operator is used in an expression it behaves like the ++ operator. For example:

```cpp
#include <iostream> // Example 4.1
int main()
{
    int a = 10, b;

    b = --a;
    std::cout << a << ' ' << b << '\n';

    b = a--;
    std::cout << a << ' ' << b << '\n';
    return 0;
}
```

The current value of a is first incremented and the new value is stored into b. Thus, the program outputs: 9 9. Then, the value of a is first stored into b, and then it is decremented. Thus, the program outputs: 8 9.
Example:

```cpp
double a = 1.23;
cout << ++a << '\n';
cout << a-- << '\n';
```

The current value of a is first incremented and the code displays 2.23. Then, the code displays the value of a, which is 2.23, and then it is decremented. ++ and -- operators can be combined in the same expression. For example, what does the following program output?

```cpp
#include <iostream> // Example 4.2
int main() {
    int a = 0, b = 1, c = 2;
    std::cout << (b++)--(-a)*(c--) << '\n';
    return 0;
}
```

With the operation b++ the value of b is first stored and then increased. With --a, the value of a is first decremented and used in the expression. With --c, the value of c is first used and then decremented. Therefore, the program outputs 1-(1)*2 = 3 and the values of a, b and c become -1, 2, and 1, respectively.

> If you apply the ++ and -- operators to change the value of a variable in the same expression, please use the variable alone, otherwise the evaluation order is undefined.

For example, the result of a a++; is implementation defined. It depends on the compiler whether a is first incremented and then multiplied, or not. In most cases, as in this example, the compiler is free to evaluate the expression in any order. There are exceptions such as the &&, ||, ?: and the comma operator, generally the compiler can choose any order. Therefore, do not create expressions like the previous one, because their result is undefined.

# RELATIONAL OPERATORS

The relational operators >, >=, <=, != == are used to compare operands and determine their relationship. We'll see in the next chapters, the relational operators are mostly used in if statements and iteration loops. For example, with the statement:

- if(a > 5) check if a is greater than 5.
- if(a >= 5) check if a is greater than equal to 5.
- if(a < 5) check if a is less than 5.
- if(a <= 5) check if a is less than or equal to 5.
- if(a != 5) check if a is not equal to 5.
- if(a == 5) check if a is equal to 5.

An expression is considered true if it has a non-zero value. If it is zero, it is considered false.

# COMPOUND ASSIGNMENT OPERATORS

The compound assignment operators are used to shorten statements using the form: exp op= exp2; This statement is equivalent to exp1 = exp op (exp2). Notice that the compiler encloses the expression exp2 in parentheses for reason of priority. Typically, the op operator is one of the arithmetic

operators: +, -, *, %, it can also be any of the bit operators: ^, |, <<, as we'll describe later in this chapter. For, consider the following program:

```cpp
#include <iostream> // Example 4.3
int main() {
    int a = 1, b = 2;
    a -= 2;
    a *= 1-b;
    a += b+3;
    a /= b+2;
    a %= b;
    std::cout << a << '\n';
    return 0;
}
```

The statement a -= 2; is equivalent to: a = a-2 = -1.
The next statement is equivalent to: a = a*(1-b) = -1*(-1) = 1. Notice that the compiler encloses the expression 1-b in parentheses.
The statement a += b+3; is equivalent to: a = a+(b+3) = 1+5 = 6, while the next statement is equivalent to: a = a/(b+2) = 6/4 = 1.
Finally, the statement a %= b; is equivalent to: a = a%b = 1%2 = 1. Therefore, the program outputs 1 When the expression is long, the compound operator can make the code easier to read and safer to write as well. For example, it is more convenient and safer to write:

```cpp
publisher[i].book[j].prc += 10;
```

than to write this long expression on the right. Indeed, it is more convenient, but why is it safer? Because it is too easy to make a type error and write:


and use instead of j, in the book member in the right expression. As you'll learn in Chapter 7, this error may cause a crash!

> When using the compound assignment operators, be careful to write the op operator, and then the = If you switch the characters, you inserted a bug most likely.

# LOGICAL OPERATORS

The logical operators !, &&, and || are used to form logical expressions. The ! operator is unary, && and || are both binary. The logical operators produce either true or false, just like the relational operators. The logical operators are left associative, so the compiler evaluates the operands from left to right.
