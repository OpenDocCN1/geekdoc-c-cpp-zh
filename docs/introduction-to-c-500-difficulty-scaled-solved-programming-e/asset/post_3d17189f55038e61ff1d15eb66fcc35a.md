```cpp
// Second file.
int t;
void f();
```

there will be no conflict between the two t variables. Each t is different and accessible only in its own file. The same happens if we declare these names in another unnamed namespace. The unnamed namespaces in the two files are independent of each other. The names declared here are local to each file. To sum up, an unnamed namespace ensures the locality of the code and thus we avoid the possibility of name conflicts in different files.

# RUNTIME IDENTIFICATION

To determine the type of an object at runtime, C++ provides the dynamic_cast operator, the typeid operator, and the typeinfo structure.

The dynamic_cast operator is typically used for downcasting, that is to cast a base class to a derived class. It can also be used for upcasting, that is, to cast a derived class (or reference) to a base class (or reference). 

The dynamic cast operator only applies to pointers and references to polymorphic classes, that there must be at least one virtual function (declared or inherited) in the class to which the pointer points or the reference refers. It takes two operands, a pointer (or reference) to a class inside < and the pointer (or reference) to be cast (). The types we are casting must be pointers or the classes within the same class hierarchy.
