The data written to cout are not sent directly to the destination, but are stored in a buffer area in memory. When it becomes full, the program flushes the buffer and the data are sent to the destination. Use of memory is especially useful when the output stream is connected to a peripheral device, such as a file on the hard disk, since one large transfer is much more efficient and increases the performance than many individual transfers. When the output is directed to the screen, screens are improved since the program does not have to wait until the memory is full. Typically, writing a new line character or waiting for data causes the memory to be flushed. Also, as we'll see, the use of endl and flush manipulators has the same effect.

C++ provides several ways to format the output. We'll describe them briefly in a short. Before that, let's discuss escape sequences.

# Escape Sequences

In C++, there are characters that have a special meaning. The "" delimits a string, that is, a sequence of characters enclosed in double quotes, so you cannot add an extra " within it. Also, there are characters that you cannot enter directly from the Keyboard. For example, you cannot add the new line character in a string by pressing Enter. If you press Enter, you will start a new line in your source code.

For the representation of non-printable characters (e.g., backspace) and characters with special meaning (), called escape sequences. An escape sequence consists of a backslash (\ followed by a character. Although these sequences look like two characters, they represent only one. For example, when you write \ the compiler interprets it as a new line and not as the character n.

TABLE 3.1 ESCAPE SEQUENCE | MEANING
\a | Audible alert.
\b | Backspace.
\f | Form field.
\n | New line.
\r | Carriage return.
\t | Horizontal tab.
\v | Vertical tab.
\\\ | Backslash.
\' | Single quote.
\" | Double mark.
\? | Question mark.

Represents the character that corresponds to the octal number (one to three digits). For example, \143 corresponds to ',', where 143 = 99. The sequence ends if either three digits have been used or a character other than octal digit is met. For example, the string "142k" contains the characters \142, that is, 'b', and 'k'. The octal number does not have to begin with 0.

Represents the character that corresponds to the hexadecimal number (h is a hex digit or letter). For example, \x6d corresponds to 'm', because 6d16 = 109. The standard does not set a limit on the number of h. The sequence ends if a character other than hex digit is met.
