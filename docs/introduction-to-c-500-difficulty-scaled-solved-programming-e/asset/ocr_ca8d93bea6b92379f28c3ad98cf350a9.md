# C.10.24 What is the output of the following program?

```
#include <iostream>
int main()
{
    const char *arr[] = {"TEXT", "SHOW", "OPTIM", "DAY"};
    const char **ptr1;

    ptr1 = arr;
    std::cout << ***ptr1 << ' ';
    std::cout << **ptr1+2;
    std::cout << (char)(**ptr1+1) << '\n';
    return 0;
}
```

Answer: The array is declared as an array of pointers to strings. In particular, arr[0] points to
"TEXT", arr[1] points to "SHOW", and so. The statement ptr = arr; makes ptr0 to point to the
address of arr[0].

The expression ++ptr1 makes ptr1 to point to arr[1]. Since **ptr1 is equivalent to arr[1],
the cout statement is translated to cout << ptr1[2]; and the program skips the first two characters of
"OPTIM" and displays TIM.

Like before, the expression ++ptr1 makes ptr1 to point to arr[3]. However, **ptr1
is equivalent to *arr[3]. What is the value of *arr[3]? Since arr[3] points to the first character
of "DAY", *arr[3] is equal to 'D'. Therefore, the value of *arr[3]+1 is 'E' and the program dis-
plays.

As a result, the program displays SHOW TIME
