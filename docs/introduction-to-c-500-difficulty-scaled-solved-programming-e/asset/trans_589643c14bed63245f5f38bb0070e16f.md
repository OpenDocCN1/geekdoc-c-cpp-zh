**U.12.8** 编写一个程序，读取十门课程的名称（存储在 vector 对象中）以及 50 名学生这些课程的成绩。程序应显示课程名称及其对应的平均分，从平均分最高的课程开始。在平均分相同的情况下，程序应按字母顺序显示“并列”课程。使用冒泡排序算法对数组进行排序。重新复 C.12.6 查看如何使用 vector 对象。

**U.12.9** 在一场音乐比赛中，200 名评委对 50 首歌曲中的热门歌曲进行投票。编写一个程序读取歌曲名称（存储在 vector 对象中）并显示前五名的歌曲。如果第五名并列，程序应显示“并列”歌曲。为某歌曲投票时，评委输入其条目。每位评委最多投五首歌曲，并输入单词 end 作为标题。假设评委不会对同一首歌重复投票。使用选择排序算法对数组进行排序。
