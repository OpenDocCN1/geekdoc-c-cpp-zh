# Overloading the [] Operator

Although the [] operator is not a conventional unary operator such as ++, I'd like to add an example of its use, because it is a particularly useful operator that is often overloaded. As we saw in the overloading restrictions, the overloaded function of [] must be a class member. Let's look at a simple example of a class that returns an array:

```
class Array // Example 18.5
private:
    int arr[10];
public:
    int& operator[](int i);
};
int& Array::operator[](int i)
{
    return arr[i]; /* For simplicity, it is not checked if the value of i is within valid range. In exercise U.18.2 you'll be asked to do it. */
}
```

```
int main()
{
    Array a;
    a[0] = 5; /* Equivalent to a.operator[](0) = 5. The a.arr[0] becomes 5. */
    return 0;
}
```

Usually, the operator[] function is defined to return a reference to the element and not its value, in order work like l[i]. For example, if we have an array, we can write b[3] = i; and i = b[3]. Usually, we want the operator[] to support this. To achieve this, we declare the function to return a reference so that when the operator [] is used at the left of we can assign a value to a particular element. When the function is called, the value inside the brackets becomes its assignment. For example, the statement a[0] = 5 invokes the a.operator[](0), which returns a reference to arr[0]. Thus, the value of arr[0] becomes 5.

Note that if the type was just int the compiler would display an error message that the assignment of operand is not allowed. That is, we could only read the value of the element (e.g., int c = a[0]); and not write to it. Also, someone may ask, could we return a pointer and have the same result? Could we write?

```
int* Array::operator[](int i)
{
    return &arr[i];
}
```

Yes why not? But then you have to dereference the pointer to the element. That is, to write: *a[0] = 5; an ugly syntax which makes the code harder to read and write. It is much better to use the reference as return value.
If we don't want to change the element in the value we make the reference const. For example:

```
const int& Array::operator[](int i) { return arr[i]; };
a[0] = 5; // Wrong, it is not allowed to change the value.
int i = a[0]; // OK.
```
