Essentially, show_inorder() performs an in-order tree traversal. For each traversed node, it visits the nodes of its subtree, then the current node, and the nodes of its right subtree. As result, the function displays the keys in ascending order.

In the same sense, show_preorder() performs a pre-order tree traversal. In particular, for each traversed node, it visits the nodes of its subtree, and then the nodes of its right subtree.

```
void show_preorder(Node *p)
{
    if(p == nullptr)
        return;
    cout << p->key << ' ';
    show_preorder(p->left);
    show_preorder(p->right);
}
```

show_postorder() performs a post-order tree traversal. For each traversed node, it first visits its left subtree, the nodes of its right subtree, and then the current node.

```
void show_postorder(Node *p)
{
    if(p == nullptr)
        return;
    show_postorder(p->left);
    show_postorder(p->right);
    cout << p->key << ' ';
}
```

delete_tree() uses the post-order method to release the allocated memory. For each traversed node, the first memory of the nodes of its subtree is released, and then the memory of the node itself. In the previous example, the nodes are released in order: 4, 8, 6, 18, and 9.
