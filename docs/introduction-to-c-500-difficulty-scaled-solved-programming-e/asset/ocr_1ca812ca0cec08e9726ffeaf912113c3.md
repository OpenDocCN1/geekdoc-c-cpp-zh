To make it easier to write the pointer declaration and the type of the corresponding variables it is more convenient to use the typedef statement and create a synonym for the type of the pointer. Fine, but about the syntax of this declaration? It seems complex, it might seem, but it is not, as long as we follow the method that we've mentioned in Chapters 8 and 11.

As we said, an easy way to declare a pointer to a function is to first write the prototype of the function and then replace the function name with an expression of the form (*ptr). For example, we write the prototype of f(ptr), replace f with (*ptr) and because f(ptr) is contained in class T::. Then add the typedef word.

To remind you, the syntax with typedef remains that of variable declaration, just preceded by the word typedef. For example, we use the typedef to declare the declaration of fptr, and so we can use the fptr name in the program. Then, if fptr is a synonym of the type "pointer to function member of class T, which takes two integer parameters and returns nothing". Using this synonym makes the declaration of corresponding variables (e.g., p) simple.

Alternatively, as we know from Chapter II, we can use the using keyword to create a synonym. For example, we can use

```
using fptr = void (T::*) (int a, int b);
```

Without synonyms we can declare the p pointer as follows:

```
int main()\{
    void (T::*p)(int a, int b); // Pointer declaration.
    p = &T::f;
    ...
}
```

Alternatively, the declaration becomes very easy with C++11, because we can use auto to deduce the type of the variable for us. For example, we write

```
auto p = &T::f;
```

A static member is not associated with an object, so don't use its full name to declare it. For example:

```
class T {
public:
    static void f() {}
};
void (T::*p)() = &T::f; // Wrong.
void (*p)() = &T::f; // Correct.
auto p = &T::f;
```
