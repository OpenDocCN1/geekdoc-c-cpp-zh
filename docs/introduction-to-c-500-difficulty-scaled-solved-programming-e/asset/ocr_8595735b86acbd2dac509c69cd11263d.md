# Overloading the ++ and -- Operators

Let's overload the ++ operator, the is overloaded in a similar way, to increase the dimensions of the invoking object. As we know, the ++ operator can be applied in two ways. Therefore, we'll implement two versions of the function, one for the postfix and one for the prefix increment. For example, with the statement ++r; the function should return the object after increasing its dimensions, while with r++; return r before increasing its dimensions. Fine, but there is a problem. Since both functions have the same name operator and do not accept parameters, that is, they have the same signature, how will the compiler figure out which one to call? To solve this, an integer is added in the postfix version. For example:

```
Rect::operator++() /* Prefix version (e.g., ++r). The declaration is added in the class. */
{
    length++;
    height++;
    return *this;
}
```

```
Rect::operator++(int) /* Postfix version (e.g., r++). The declaration is added in the class. */
{
    Rect tmp;
    tmp = *this;
    length++;
    height++;
    return tmp;
}
```
