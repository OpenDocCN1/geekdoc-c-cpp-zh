# ## DATA OUTPUT with cout

In C++, data input and output is accomplished via streams. The stream term refers to a data source or destination. For example, an output stream may be associated with the screen, a file, or an output device (e.g. printer). C++ provides a set of classes declared in the iostream and fstream headers to support input/output operations. We will discuss classes and objects in Chapter 17. For now, it is enough to know that a class is a data type that the programmer defines and it represents a logical entity. An object is an instance of a particular class and it is created according to the description of class. A class variables and functions determine the operations that can be performed on objects of that class. For example, the ostream class contains functions that are responsible for output data.

cout is an object of the ostream class. By default, the cout object is associated with the predefined standard output (e.g. screen). For those who know C, cout corresponds to stdout. The cout is followed by the << operator and the expression we use to display. By default, the values written in cout are converted to a sequence of characters. For example, if we:

```
cout << 35;
```

the characters 3 and 5 are inserted into the output stream. Before we continue, a parenthesis for those who know from C that the << is the left operator, The same applies to C++. It's just that the ostream class overloads it and changes its behaviour. When used in this way, the << operator sends the data on right to left. The cout gets to Chapter 18 and discuss operator overloading, over you will see how we can change the behaviour of an operator.

If you are familiar with the C input/output system and the functions declared in stdio.h (e.g. printf()), you can also use them in C++ programs to display data. However, the format and syntax of printf() is more complex, since the type of each variable must be specified. Also, printf() is not scalable to user-defined types (e.g., there is no specific identifier for displaying the members of a class), nor is it secure in the sense that it checks the types and arguments passed to it. For example:

```
int i;
printf("%s", i); // Wrong, it should be %d instead of %s. The code is compiled successfully. However, this error may cause the program to behave unpredictably.*
```

C++ provides flexibility, security, and secures the data output, since the cout and the << operator know to handle each data type.
