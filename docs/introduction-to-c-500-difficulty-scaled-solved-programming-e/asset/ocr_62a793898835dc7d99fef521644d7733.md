# Introduction to C++

As we said in Chapter 2, if an overflow occurs in a computation with signed numbers, for example, if the outcome of an addition is too big to be stored in a variable, the result is undefined. If the numbers are unsigned, the result is defined as modulo 2^n, where n is the number of bits of the unsigned type. For example, if the size of the unsigned int type is 32 bits the result of 4000000000 + 1000000000 is 705032704.

When performing arithmetic operations, ensure that overflow won't occur in order to avoid unpleasant situations.

For example, if we use the new operator to allocate memory, we'll see in Chapter 14, and an overflow occurs in the computation of its size (e.g., we are using a short variable to hold the size), the size of the allocated memory won't be the one asked with unpredictable consequences on the program execution. For example, the basic idea to avoid overflow is to check that a, b, and c are integers and b is positive, before assigning the result of a+b into c, we could write:

```
if (a > INT_MAX) /* INT_MAX is defined in <climits>. It is a macro that specifies the maximum value that an integer variable can hold. */
cout << "Error: overflow case\n";
return;
c = a+b;
```

# Lvalues and Rvalues

The right operand is an expression that has a value, such as a constant value or a variable. The left operand must be an lvalue. An lvalue refers to an object stored in memory (e.g., a variable) which we can store something. That is, the object should be addressable, which means we can extract and value is memory address. It is not allowed to use a constant or the result of a computation. For example:

```
20 = a; // Wrong.
b-a = 30; // Wrong.
```

The compiler will produce an error message similar to error '=': left operand must be lvalue. Also, the lvalue may be modifiable. We'll see in Chapter 8 that an array is not a modifiable lvalue. The complement of the left is the rvalue. As rule of thumb, an rvalue is an expression that is not lvalue, such as a constant value (e.g., 10), or an expression (e.g., a+b) or function call that returns a non-reference type. In particular, an rvalue evaluates to a result that is stored temporarily in memory. If we write c = a+b; the result of the expression a+b is temporarily stored somewhere, only to be copied into c, and then that memory is discarded. Thus, the expression a+b is an rvalue. To sum up, an rvalue is an expression that evaluates to a temporary value, while an lvalue evaluates to a more persistent value which is addressable in memory.
