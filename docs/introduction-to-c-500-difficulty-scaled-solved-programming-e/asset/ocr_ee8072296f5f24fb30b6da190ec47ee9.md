Many programmers prefer to use the same names for the parameters as the names of the members. We can do that by using this pointer. For example, we have a class T with integer members a and b and an appropriate constructor that initializes them:

```
void T::T(int a, int b)
{
    this->a = a;   /* If we write a = a, the compiler considers the
    argument name. The constructor arguments don't represent the class
    members. */
    this->b = b;
}
```

Since this holds the address of the current object, we can have the same names for the parameters and the members and use this to access members of the object.
Notice that we can change the value of the this pointer. For example, it is wrong to write this->inside cmp(). The value of this is immutable, it always points to the current object. In particular, for a const function its type is const T, so the function cannot modify the members of the object.
Now you can understand why the statement grd = 2; in the section that we were discussing const functions is not allowed. It is translated as this->grd = 2; which cannot be compiled since the type of this is a pointer to const.
