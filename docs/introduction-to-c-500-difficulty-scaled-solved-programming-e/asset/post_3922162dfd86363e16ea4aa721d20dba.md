## Manipulators

A convenient way using setf() to format the output is to use manipulators. The manipulators are declared in the std namespace. Table 3.4 shows the most frequently used standard manipulators.
C++ has the defaultfloat manipulator, which sets the floating-point numbers in the default notation, and the hexfloat manipulator, to output the floating-point numbers in hex.

### TABLE 3.4 Manipulators

| MANIPULATOR | OPERATION |
|---|---|
| endl | Inserts a new line character into the output. The difference with \n is that endl guarantees that the buffer will be flushed and the output will be immediately displayed, you don't get that guarantee with \n. |
| ends | Inserts the null character '\037' into the output. |
| dec | setf(ios_base::dec, ios_base::basefield) |
| hex | setf(ios_base::hex, ios_base::basefield) |
| oct | setf(ios_base::oct, ios_base::basefield) |
| internal | setf(ios_base::internal, ios_base::adjustment) |
| left | setf(ios_base::left, ios_base::adjustment) |
| right | setf(ios_base::right, ios_base::adjustment) |
| fixed | setf(ios_base::fixed, ios_base::basefield) |
| scientific | setf(ios_base::scientific, ios_base::basefield) |
| boolalpha | setf(ios_base::boolalpha) |
| noboolalpha | unset(ios_base::boolalpha) |
| showcase | setf(ios_base::showcase) |
| noshowbase | unset(ios_base::showcase) |
| showpoint | setf(ios_base::showpoint) |
| noshowpoint | unset(ios_base::showpoint) |
| showpos | setf(ios_base::showpos) |
| noshowpos | unset(ios_base::showpos) |
| skipws | setf(ios_base::skipws) |
| nopws | unset(ios_base::skipws) |
| ws | Extracts and discards leading whitespace from an input stream. |
| uppercase | setf(ios_base::uppercase) |
| nouppercase | unset(ios_base::uppercase) |
| flush | Flushes the output buffer. |
| setfill(c) | Sets the fill character of the stream to c. If an output value does not fit in the width of the field, the remaining positions are filled with the character c. |
| setprecision(n) | Sets the precision to n. The precision remains in effect for subsequent operations. |
| setw(n) | Sets the width to n. If it is less than the characters required to display the field is ignored. The width remains in effect only for the next field. |
| setflags(n) | Sets the format flags specified by n. |
| resetflags(n) | Unsets the format flags specified by n. |
| setbase(n) | Sets the numeric base to n. |
| unitbuf | Sets the unitbuf flag. The associated buffer is flushed after each output operation. |
| nounitbuf | Unsets the unitbuf flag. |

As shown in Table 3.4, manipulators perform the operation as the format calls by the corresponding set() and unset() functions. For example, the noshow manipulator calls unset(ios_base::base), while the dec manipulator calls set(ios_base::dec, ios_base::basefield). Some of the manipulators (e.g., setw) are declared in the file iomanip. The following program displays integer and floating-point values in various formats:

```cpp
#include <iostream> // Example 3.4
#include <iomanip>
using namespace std;

int main() {
    int i = 100;
    double j = 100.536;

    cout << i << '\t' << hex << i << '\t' << endl;
    cout << scientific << j << '\t' << fixed << j << endl;
    cout << setprecision(2) << j << '\t' << setprecision(0) << '\t' << j << endl;
    cout << showcase << uppercase << i << '\t' << 1.4999 << '\t' << endl;
    return 0;
}
```

The endl flushes the output buffer and inserts a new line. Regarding my preference between \n and endl, I prefer to embed the \n within a string; this is more convenient than using endl. For example, I prefer to write cout << "\nCheck\n"; instead of cout << endl << "Check" << endl;. Also, note that endl may affect the performance in case of many flushing requests.

Note that it is not necessary to use one count for each print. cout is smart to concatenate output. We use the << operator before what we want to display. You'll understand the sequential use of << when we discuss overloading in Chapter 18. The program outputs:

- 100 144 64 (the number 100 is equivalent to 64 in octal and 64 in hex). The values are one tab away.
- 1.005360+002 100.53600
- 104.54 101 (the value is displayed with two precision digits. Because the cut-off digit is 6, that is, greater than the 4 is rounded up. Then, the precision becomes 0 and, because, the cut-off digit is 5 the program displays 101).
- 0X64 1 +100 (the hex manipulator is active the value is displayed in hex. Similarly, because the precision remains 0 and the cut-off digit is 4 the program outputs 1. The dec manipulator is activated and the + sign prefixes the value).

In essence, the manipulators are functions, while the format looks like integers. For example, we write:

hex(cout); instead of cout << hex. In view, the ostream overload looks easier and clearer to write. In practice, the overload clears the << operator so that the second syntax becomes equivalent to hex(cout); Note that most manipulators are sticky (e.g., hex), which means that they persist until we tell the stream otherwise.

Let's look at an example with different field widths and output alignment:

```cpp
#include <iostream> // Example 3.5
#include <iomanip>
using namespace std;

int main()
{
    int i = 200;
    double j = 123.456;

    cout << left << setw(10) << i << setw(10) << j << endl;
    cout << right << setw(10) << i << setw(10) << j << endl;
    cout << internal << setw(10) << i << setw(10) << j << endl;
    return 0;
}
```

The program outputs:
- 200       123.456
-      200 123.456
-      200      123.456

## Member Functions

| FUNCTION | MEANING |
|---|---|
| flags() | Returns the format flags. |
| fill() | Returns the fill character. |
| fill(c) | Sets the fill character to c. |
| precision() | Returns the precision digits. |
| precision(n) | Sets the precision digits to n. |
| width() | Returns the value of the field width. |
| width(n) | Sets the field width to n. |

Another way to format the output is using cout member functions, as shown in Table 3.5

```cpp
#include <iostream> // Example 3.6
using namespace std;

int main()
{
    double i = 12.428, j = 5.6731;

    cout.precision(2);
    cout.width(7);
    cout.fill('*');
    cout << fixed << i << '\t' << j << '\n';
    return 0;
}
```

The program outputs: **12.43    5.67**.

## DATA INPUT WITH cin

In this section we will learn how to get data from an input stream, the keyboard, to use data in variables, and use it in our programs. For example, an input stream may be associated with a file on the hard disk, or a peripheral device (e.g., modem). cin is an object of the istream class. By default, the cin object is associated with the standard input device (e.g., keyboard). For those who know C, cin corresponds to stdin. The type of the variable after the >> determines the type of input data that will be read and stored in that variable. Just as the ostream class overloads the << operator, the istream class overloads the >> shift operator to read the data. When used in this way, the >> operator extracts the data from the input stream and stores it in the indicated variable. The >> suggests that the direction of data flow is from left to right. The istream class provides several functions to get the input data. For now, we will read numeric values and other types of (e.g., pointer) in the next chapters. Here, we'll see in Chapter 18, that we can use cin to get data for user types (e.g., class) in the same way we use with basic types (e.g.). Let's see an example:

```cpp
#include <iostream> // Example 3.7
using std::cout;
using std::cin;
using std::fixed;

int main()
{
    int i;
    double j;

    cout << "Enter number: ";
    cin >> i; // Read an integer and store it into i.
    cout << "Enter number: ";
    cin >> j;

    cout << i << '  \t' << fixed << j << '\n';
    return 0;
}
```
