**U.8.3** Write a program that uses a pointer to read a double number and display its fractional part. If the user enters -7.21, the program should display 0.21.

**U.8.4** What is the output of the following program?

```
#include <iostream>
int main() {
    int i = 10, j = 20, k = 30, *p1 = &i, *p2 = &j, *p3 = &k;
    *p1 = *p2 = *p3;
    k = i+j;
    std::cout << *p3 << '\n';
    return 0;
}
```

**U.8.6** What is the output of the following program?

```
#include <iostream>
int main() {
    int *ptr, i, j=1, a[] = {j, j+1, j+2, j+3};
    for(i=0; i<3; i++) {
        ptr = a+i;
        std::cout << a[*ptr] << ' ';
    }
    return 0;
}
```
