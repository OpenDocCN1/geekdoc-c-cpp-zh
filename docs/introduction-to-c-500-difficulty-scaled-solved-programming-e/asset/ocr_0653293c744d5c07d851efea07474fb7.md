Answer: Once the memory is allocated, p1 and p2 point to the same memory. When f() is called, we have p=p2 and f() displays test. Then, if f() releases the memory pointed to by p (that's the same pointed to by p1 and p2). Therefore, the attempt to allocate this memory with the statement *p1='m'; is wrong. This also shows how we can manage the memory allocated in one function (e.g., main()) into another function (e.g., f()).
