
Explicit instantiations may improve the compilation and the linking time of the program, since no instantiations are repeated for the same type(s). Also, in large applications where the use of the same function template in multiple sources files may be required, we can avoid the delay caused by instantiating it explicitly and making it extern. For example, if abs<int> is defined in one file and we want to use it in such a file we write:

```
extern template int abs<int>(int a); // Second file.
```

With the extern declaration the compiler will not redefine the abs<int> version in this file. As with ordinary declarations of extern variables, the definition of abs<int> will be searched in another file. In the same sense, there can be many extern declarations for a given function, but only one definition for instantiation.

## Overloading Function Templates

As we said, we write a function template when we want to apply the same code to a variety of types. However, it may be a case that we want to write a function that performs a similar operation, not the same. In such a case we can overload the function, just as we've learned to do with ordinary functions. For example, we want to write a function template that returns the absolute value of the sum of its arguments and one that displays the absolute value of the sum of its arguments:

```cpp
#include <iostream> // Example 16.15
```

```cpp
template <typename T> T abs(T a);
template <typename T> void abs(T a, T b, int c = 3);
```

```cpp
int main()
{
    int a = 6, b = 3;
    double c = 1.2;

    abs(a, b, -10);
    std::cout << ' ' << abs(c) << '\n';
    return 0;
}
```

```cpp
template <typename T> T abs(T a)
{
    return a < 0 ? -a : a;
}
```

```cpp
template <typename T> void abs(T a, T b, int c)
{
    T sum;

    sum = a+b+c;
    if(sum < 0)
        std::cout << -sum;
    else
        std::cout << sum;
}
```

As with ordinary overloading, the signatures must be different. The first signature is (T), while the second is (T, T, int). ## Explicit Specialization

When writing a function template it might be a case that we want the function to work differently for a particular type. To achieve this we can declare an explicit specialization of the function template. For example, suppose we have declared the following structure:

```cpp
struct Student
{
    string name;
    float grd;
}
```

If we want to swap the contents of the two structures we can use the template do_swap() function we saw earlier in C.16.12. But if we want to swap only the grades and not the names it won't work. A solution is to supply an explicit specialization of the function template to handle the explicitly arguments. For example:

```cpp
#include <iostream> // Example 16.16
#include <string>
```

```cpp
struct Student
{
    std::string name;
    float grd;
}
```

```cpp
template <typename T> void do_swap(T& a, T& b);
template <> void do_swap<Student>(Student& a, Student& b); /* Explicit specialization. */
```

```cpp
int main()
{
    int a = 10, b = 20;
    Student s1 = {"N.Smith", 6.5}, s2 = {"P.Krow", 5.2};

    do_swap(a, b); // Call the function template.
    do_swap(s1, s2); // Call the specialized version.
    std::cout << a << ' ' << b << '\n' << s1.name << ' ' << s1.grd << '\n' 
    << s2.name << ' ' << s2.grd << '\n';
    return 0;
}
```

```cpp
template <typename T> void do_swap(T& a, T& b)
{
    T tmp;
    tmp = a;
    a = b;
    b = tmp;
}
```

```cpp
template <> void do_swap<Student>(Student& a, Student& b)
{
  float grd;
  grd = a.grd;
  a.grd = b.grd;
  b.grd = grd;
}
```
