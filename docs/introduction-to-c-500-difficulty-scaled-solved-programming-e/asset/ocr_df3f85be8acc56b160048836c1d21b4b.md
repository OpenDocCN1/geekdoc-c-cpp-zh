A popular usage of a conversion function is checking the state of a stream in a condition.
example:

```
while(cin >> i) {...}
```

As we know, with the >> operator a value will be read, stored in i and a reference to cin is returned.
The istream class uses an operator bool conversion function. Thus, to evaluate the condition, the conversion function is called, which, if the state of cin is valid, it returns true, otherwise, if an error occurs, it returns false.

As a constructor, if we do not want to allow implicit conversions we can use the word explicit. If the conversion function is made explicit we must use typecast explicitly to use it:

```
class A
{
    explicit operator int() const {return 10;}
}
int i;
i = a; // Wrong.
i = static_cast<int>(a); // Correct, use typecast for explicit conversion.
```

# POINTER TO A FUNCTION MEMBER

In Chapter 8, we discussed pointers to functions. For example, with void (*ptr)(int, int); ptr is declared as a pointer to a function, which takes two integer parameters and returns nothing. Now, let's see how we can declare pointers to functions that are members of a class. For example:

```
#include <iostream> // Example 19.4
class T
{
public:
    void f(int a, int b) {std::cout << a-b << '\n';}
}
typed void (T::*fptr)(int a, int b);

int main()
{
    T t;
    fptr p; // Pointer declaration.
p = &T::; /* This is the syntax to make the pointer point to the member function.*/
    (t.*)(8, 5); // Call the function through the. * operator.
    T *r = &;
    (r->p)(8, 5); // Call the function through the ->* operator.
    return 0;
}
```
