```
void insert_sort(int i, j, temp) {
    for(i = 1; i < SIZE; i++) {
        temp = arr[i];
        j = i;
        while(j > 0 && (arr[j-1] > temp)) {
            arr[j] = arr[j-1]; /* Shift this element one position to the right. */
            j--;
        }
        arr[j] = temp;
    }
}
```

The for loop compares the elements from the second. In each iteration, the while loop shifts one position to the right the elements on the left of the examined element and are greater than it. To see how the algorithm works, suppose that the array elements are: 7, 3, 1, 9, 4.

First for loop iteration (i = 1 and temp = arr[1] = 3)
(j = 1) First while loop iteration: 7 --> 1 9 4

So, the array is transformed to: 3 7 9 4

Second for loop iteration (i = 2 and temp = arr[2] = 1)
(j = 2) First while loop iteration: 3 --> 1 9 4
(j = 1) Second while loop iteration: 7 --> 1 9 4

So, the array is transformed to: 1 3 7 9 4

Third for loop iteration (i = 3 and temp = arr[3] = 9)
(j = 3) No shifting take place because the fourth element (i.e., arr[3] = 9) is greater than the "most element" (i.e., arr[2] = 7).
