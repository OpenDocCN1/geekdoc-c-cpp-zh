Ellipse& Ellipse::operator-(int n)

```
{
    float rad;
    rad = get()-n;
    if(rad < 0)
        throw 10;
    set(rad);
    axis -= n;
    if(axis < 0)
        throw 20;
    return *this;
}
```

void Ellipse::show() const

```
{
    std::cout << "R:" << rad << " A:" << axis << '\n';
}
```

void f(Circle& c, int n)

```
{
    Circle& tmp = c-n;
    tmp.show();
}
```

```

```

**Comments:** Because the rad is a private member and we want the Ellipse to be able to access it, add public set/get functions in Circle. Since we see in f() that an integer is subtracted from an object we understand that the - operator must be overloaded. In order for the operator-() to be called depending on the type of object referenced by c, the class must be declared as virtual in the base class. In f(i), the c is a reference to the base class, so that a reference to a derived class (e.g., r1, r2) can exploit the mechanism of the virtual functions.
