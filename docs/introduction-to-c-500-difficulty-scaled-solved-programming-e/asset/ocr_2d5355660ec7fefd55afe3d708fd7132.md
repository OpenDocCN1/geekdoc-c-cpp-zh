The & operator is often used to make zero a number of bits. For example, the statement: a = a & 15; sets to zero but the four lower bits of a.

> Don't confuse the && & operators. For example, if a=2 and b=4, the result of a && b is 1, while the result of a & b is 0.

# The Operator

The | performs the Boolean OR operation on all bits of its two operands. If both corresponding bits are 0, the result is 0. Otherwise, the bit is set to 1. For example, the result of 23 | 11 is 31:

```
00010111 (23)
00001011 (11)
-----------
00011111 (31)
```

The | operator is often used to set one a number of bits. For example, the statement: a = a | 15; sets to one the lower bits of a.

> Don't confuse the || and operators. For example, if a=2 and b=4, the result of a || b is 1, while the result of a | b is 6.

# ^ Operator

The ^ operator performs the Boolean XOR operation on all bits of its two operands. If the corresponding bits are different, the result bit is 1. Otherwise, the bit is set to 0. For example, the result of 23 ^ 11 is 28:

```
00010111 (23)
00001011 (11)
00011100 (28)
```
