C++17 provides the ability to define a static member variable within the class by making it inline. For example:

```cpp
class T
{
static inline int num = 5; // Since C++17.
}
```

Now, we don't have to define it outside the class; making it inline is much more convenient. Also, the fact that it is inline allows us to include header file in multiple source files without violating the definition rule.

To, just remember, when you want a variable to be shared by all objects you should declare it as static. For example, in one of my applications, where each object represented a tab of a browser, I had declared the members that stored the machine's network addresses (e.g., MAC and IP) as static, because these addresses are common to all the objects. With this chapter, let's go to the exercises.

In some of this book's exercises I use members of type char* to handle strings. The reason I do this is to gain more experience in using pointers but also to see dangerous situations. Also, a lot of code is written out that uses this type, so it is useful to know how to handle it. As we said, the best choice is the string type. Its use is simple, safe, and provides many capabilities.

C.17.1 Find the errors in the following code.

```cpp
class T
private:
int a;
public:
friend int f();
void r(const T& t) {t.a = a};
void g(int b) const {a = b};
}
```

```cpp
int f()
{
return a;
}
```

Answer: Because the function f() is not a member of the class, it cannot access a directly. So the statement return a is not acceptable. Because the reference passed to r() is const, it is not allowed to change the members of t. So the statement t.a = a is not acceptable. Because g() is declared as const it is not allowed to change the value of a. So, the statement a = b is not acceptable.

C.17.2 In communications, a network can be managed in an object-oriented way. In particular, every element of the network (e.g., router, computer, printer, ...) can be represented by an object.

Define the class that represents a connection. The class should contain three string members, in order to store the computer's IP address, the MAC address of its network card, and the IP address of the router to which it is connected. It should also contain two numerical members, in order to store the number of packets transmitted by the network card and the number of packets received. You should decide about the access type of the PC members so that the network administrator can safely configure three addresses as well as learn the packet values. A program that tests the functionality of the PC class.

Answer:

```cpp
#include <iostream>
#include <string>
using std::cout;
using std::string;
```

```cpp
class PC {
private:
    string MAC_addr;
    string IP_addr;
    string gateway_IP_addr;
    unsigned int send_pkts; /* In a real implementation, this value increases each time the network card sends a packet. */
    unsigned int rcvd_pkts; /* In a real implementation, this value increases each time the network card receives a packet. */
public:
    PC() {send_pkts = rcvd_pkts = 0};
    void set_MAC_addr(const string& MAC) {MAC_addr = MAC; }
    void set_IP_addr(const string& IP) {IP_addr = IP; }
    void set_gateway_IP_addr(const string& IP) {gateway_IP_addr = IP; }
    unsigned int get_send_pkts() const {return send_pkts;}
    unsigned int get_rcvd_pkts() const {return rcvd_pkts;}
    void show() const;
};
```

```cpp
void PC::show() const {
    cout << "MAC: " << MAC_addr << " IP: " << IP_addr << " Gateway: " << gateway_IP_addr << '\n';
}
```

```cpp
int main() {
    PC pc;
    string s = "1.2.3.4.5.";
    pc.set_MAC_addr(s);
    s = "200.1.2.3";
    pc.set_IP_addr(s);
    s = "200.1.2.1";
    pc.set_gateway_IP_addr(s);
    pc.show();
    cout << "Send: " << pc.get_send_pkts() << " ' Rcvd: " << pc.get_rcvd_pkts() << '\n';
    return 0;
}
```

Comments: We declare the members private, so that direct access to them is not allowed. For example, if the send_pkts member was public, its value could accidentally change, so the administrator would return an invalid value. Because the members are declared private, corresponding set/get functions must be declared to access them.

# C.17.5 Are there any errors in the following program? If so, fix them and find the output.

```cpp
#include <iostream>
#include <vector>

class A
{
public:
    ~A() {cout << "-A\n";}
}

class B
{
public:
    ~B() {cout << "-B\n";}
}

class C
{
public:
    vector<A> v;
    B *b;
    C& push(A *p) {v.push_back(*p); return *this};
}
```

```cpp
int main()
{
    C c;
    A *p = new A;
    cout << &c.push(p) << '\n';
    delete p;
    return 0;
}
```

Answer: Is it fine for a class to define only a destructor? Yes, why not? When p is declared, the default constructor creates an object. Is the call to push() correct? Yes, no. When push() is called push_back() saves a copy of the passed object in c.v. Then, push() returns c, the program displays its memory address. Then, for the p pointer released, the destructor of A is called and the program displays -A. Finally, the destructor of c is called. Will the destructor of b be? Of course not b was created, b is just a pointer. Beware now, when v is destroyed, the destructor will be called for every A object it contains. Since it contains only one, it displays -A. To sum up, the program has no errors and displays the first memory address of c.

# C17.6 Add appropriate functions in class T so that the following program works.

```cpp
#include <iostream>
#include <cstring>

class T
{
private:
    char *s;
    ...
};

int main()
{
    char str[100];
    cout << "Enter text: ";
    cin.getline(str, sizeof(str)); /* Assume that the user inputs a string with less than 100 characters. */
    T t1(str); // The string should be copied to member s.
    t1.show(); // show() should display the input string in reverse order.
    For example, if the input string is abcd, the program should display dcba.
    Also, there is a restriction that the only variable you are allowed to declare in show () is a pointer.
    return 0;
}
```

Answer:

```cpp
#include <iostream>
#include <cstring>
using std::cout;
using std::cin;

class T
{
private:
    char *s;
public:
    T(char str[]);
    T();
    ~T();
    void show() const;
};
```

```cpp
T::T()
{
    s = nullptr; /* Initialize the pointer so that there is no problem
when the memory is released. For example, no memory is reserved for t2. */
}
```

```cpp
T::T(char str[])
{
    s = new char[strlen(str)+1];
    strcpy(s, str);
}
```

```cpp
T::~T()
{
    delete[] s;
}
```

```cpp
void T::show() const
{
    for(char *p = s+strlen(s)-1; p >= s; p--)
        cout << *p;
}
```

**Answer:** Let's explain how we decided to add these functions. Since in main() the objects are created in two ways, we define two constructors. Since s is a pointer, the constructor must allocate memory to the string. Therefore, a destructor must be defined to release the memory.
