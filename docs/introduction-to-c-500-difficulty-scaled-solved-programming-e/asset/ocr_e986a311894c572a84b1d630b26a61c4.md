# C.4.5 What is the output of the following program?

```
#include <iostream>
using std::cout;

int main()
{
    unsigned int i = ~(0 << 3);

    if(i >> 3)
        cout << "One\n";
    else
        cout << "Two\n";

    if((i << 2) == 28)
        cout << "One\n";
    else
        cout << "Two\n";

    cout << i << '\n';
    return 0;
}
```

Answer: According to the precedence table in Annex A, the - operator has higher precedence than the << operator; therefore, the -0 is evaluated first, and then the result is shifted three places to the left. In a 32-bit system, the result of -0 is the number with all 32 bits set to 1. Therefore, the value of (-0 << 3) is the number: 11111111 11111111 11111111 11100000 << operator is applied, the value assigned to i is: 00000000 00000000 00000000 00000111, that is, 7.

Since the value of the expression (i >> 3) is 0, the first if statement displays Two. Notice that the if statement does not change the value of i to 0; it just tests whether i shifted three places to the right is 0 or not. The second if statement checks the value of (i << 2) is 28. Since it is true, the program displays One. As previously, i does not change, so the program displays 7.

# C.4.6 Applications that get data from the hardware often to retrieve the value of certain bits. For example, write a program that reads an integer and displays the value of the respective bits. Assume that the user enters a position within [1, 32].

```
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    unsigned int num, pos;

    cout << "Enter number: ";
    cin >> num;

    cout << "Enter position [1-32]: ";
    cin >> pos;

    cout << "bit" << pos << " is " << ((num >> (pos-1)) & 1) << '\n';
    return 0;
}
```
