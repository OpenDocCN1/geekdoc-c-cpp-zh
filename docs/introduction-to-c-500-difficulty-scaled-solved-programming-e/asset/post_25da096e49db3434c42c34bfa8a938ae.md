The data written to cout are not sent directly to the destination, but are stored in a buffer area in memory. When it becomes full, the program flushes the buffer and the data are sent to the destination. Use of memory is especially useful when the output stream is connected to a peripheral device, such as a file on the hard disk, since one large transfer is much more efficient and increases the performance than many individual transfers. When the output is directed to the screen, screens are improved since the program does not have to wait until the memory is full. Typically, writing a new line character or waiting for data causes the memory to be flushed. Also, as we'll see, the use of endl and flush manipulators has the same effect.

C++ provides several ways to format the output. We'll describe them briefly in a short. Before that, let's discuss escape sequences.

## Escape Sequences

In C++, there are characters that have a special meaning. The "" delimits a string, that is, a sequence of characters enclosed in double quotes, so you cannot add an extra " within it. Also, there are characters that you cannot enter directly from the Keyboard. For example, you cannot add the new line character in a string by pressing Enter. If you press Enter, you will start a new line in your source code.

For the representation of non-printable characters (e.g., backspace) and characters with special meaning (), called escape sequences. An escape sequence consists of a backslash (\ followed by a character. Although these sequences look like two characters, they represent only one. For example, when you write \n the compiler interprets it as a new line and not as the character n.

| TABLE 3.1 ESCAPE SEQUENCE | MEANING |
| :--- | :--- |
| \a | Audible alert. |
| \b | Backspace. |
| \f | Form field. |
| \n | New line. |
| \r | Carriage return. |
| \t | Horizontal tab. |
| \v | Vertical tab. |
| \\ | Backslash. |
| \' | Single quote. |
| \" | Double mark. |
| \? | Question mark. |

Represents the character that corresponds to the octal number (one to three digits). For example, \143 corresponds to ',', where 143 = 99. The sequence ends if either three digits have been used or a character other than octal digit is met. For example, the string "142k" contains the characters \142, that is, 'b', and 'k'. The octal number does not have to begin with 0.

Represents the character that corresponds to the hexadecimal number (h is a hex digit or letter). For example, \x6d corresponds to 'm', because 6d16 = 109. The standard does not set a limit on the number of h. The sequence ends if a character other than hex digit is met.

If the character after \ is not supported, the behaviour is undefined. The escape sequences are divided into character escapes and numeric escapes. The character escapes can represent ASCII characters (e.g., new line), while the numeric escapes, which are the latter in Table 3.1, can represent any character. Let's see the following:

```cpp
#include <iostream> // Example 3.1
using std::cout;

int main() {
    cout << '\a';
    cout << "Check\b\b back\";
    cout << "Test\rCR";
    cout << "\53\nx2d"; /* The octal number 53 (decimal 43) corresponds to the character + and the hexadecimal number 2d (decimal 45) to -. */
    cout << "T\ree\n";
    cout << "Check\t\tpoint\\\n";
    return 0;
}
```

As we will see, the \n we can use the endl manipulator to change the line. The first statement creates a beep, while the second one deletes the last three characters of the word Check, prints back the message and the \n moves the cursor to the beginning of the next line. On the third, the \r moves the cursor to the beginning of the line and the word CRst is displayed. The next one outputs + character, changes line and outputs -. The next one outputs T, then a, and then the word tree. The last one outputs the word Check, adds two tabs, and prints the word \point\. To sum up, the program outputs:

(Hear a beep)
Ch backspace
CRst
+
T"ree"
Check \point\

If we want to display a single character we can also use single apostrophes (e.g., cout << 'd'). If you want for better readability to expand the format string of cout to several lines, one way is to use the backslash\. For example, the following cout is written over three lines, the output will appear on one line:

```cpp
cout << "This statement extends in three lines, \
but the message is displayed \
in the same line";
```

## Format Flags

The flags are used to specify the output format. The flags are declared in the ios_base class and are divided into two categories: those that operate individually and those that belong to groups. Individual flags can be turned on or off independently of the other flags. These flags are shown in Table 3.2.

| :--- | :--- |

| showcase | Prefixes octal numbers with 0 and hex numbers with 0x. No prefix for decimal-base values. |
| showpoint | Displays the decimal point for floating-point values. |

The ios_base class provides the setf() function to activate flags. Because the o class derives from the ios_base we can use the use object to call setf(). For example, the statement:

```cpp
cout.setf(ios_base::showpos);
```

sets the showpos flag. because flags are declared in the ios_base class we must use the name (or a class that inherits it) and the scope operator ::. That is, we have to write ios_base::showpos, not just showpos. The expression ios_base::refers to the showpos constant declared in the ios_base class.
A flag remains active until it is disabled. To deactivate a flag we use the unsetf() function. For example:

```cpp
cout.unsetf(ios_base::showpos);
```

All flags correspond to integer values. C++ uses the fmtflags (usually, it is an alias of the long type) to store values. Specifically, each flag is an integer with only one bit set to. Thus, we have the ability to use the bit operator | (we will discuss it in Chapter 4) and enable more than one flag in the same setf() call.

The first setf() activates the showcase and uppercase flags, while the second de-activates the baseline group and activates the hex flag. Therefore, the values are displayed in hex and the program displays OX4.

In C++, for the floating-point values depends on the selected mode. If fixed or scientific mode is selected, the precision specifies the maximum number of digits after the decimal point. If no mode is selected, the precision specifies the maximum number of digits. The default precision for all modes is six digits. In the scientific mode the value is displayed with an exponent and one digit before the decimal point. To return to the default mode we can write:

```cpp
cout.setf(0, ios_base::floatfield) or cout.unsetf(ios_base::basefield);
```

If you know the conversion characters for C in printf(), it is helpful to know that the mode corresponds to %, the scientific mode to %e, and the default mode to %g. In case of a cut-off digit, if its value is greater than 4 the value is rounded up, otherwise down. Let's see the following program:

```cpp
#include <iostream> // Example 3.3
using namespace std;

int main() {
    double i = 12345.689;

    cout << "Default mode: " << i << '\\n';
    cout.setf(ios_base::fixed, ios_base::floatfield) << i << '\\n';
    cout << "Fixed mode: " << i << '\\n';

    cout.setf(ios_base::scientific, ios_base::floatfield) << "Scientific mode: " << i << '\\n';

    cout.unsetf(ios_base::floatfield);
    cout << "Default mode: " << i << '\\n';
    return 0;
}
```

The program outputs:

Default mode: 12345.7 (since the precision is six digits and the cut-off digit is 8, the value is rounded up).

Fixed mode: 12345.68900

Scientific mode: 1.234569E+04 (the letter E corresponds to base 10).

Default mode: 12345.7 (the mode is reset to the default mode).
