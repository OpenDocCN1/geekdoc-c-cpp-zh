# C.8.4 What is the output of the following program?

```
#include <iostream>
int main()
{
    int *ptr1, *ptr2, i = 10, j = 20;

    ptr1 = &i;
    ptr2 = &j;

    ptr2 = *ptr1 + *ptr2;
    *ptr2 *= 2;
    std::cout << *ptr1 + *ptr2 << '\nn';
    return 0;
}
```

Answer: The statement ptr2 = *ptr1; means ptr2 to point to the same address that ptr1 points to, that is, the address of i. Therefore, *ptr2 is equal to i. Since both pointers point to the address of i, the statement *ptr1 +ptr2; is equivalent to i+i=10+10=20. Similarly, the statement *ptr2 = 2; is equivalent to *ptr2 = 2*(ptr2); that is, 2i = 2*20 = 40. As a result, the program displays the value of *ptr1 +ptr2 = i = 40+40, that is, 80.
