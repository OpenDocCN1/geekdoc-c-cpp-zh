# C.14.12 What is the output of the following program?

```
#include <iostream>

struct Node
{
    int i;
    Node *next;
    Node *prev;
};

int main()
{
    Node a = {10}, b = {20}, c = {30}, d = {40};

    a.next = &b;
    a.prev = &d;

    b.next = &c;
    b.prev = &a;

    c.next = &d;
    c.prev = &b;

    d.next = &a;
    d.prev = &c;
    std::cout << a.next->prev->prev->next->i << '\n';
    return 0;
}
```

**Comments:** This program is a simple implementation example of another type of list, a circular double linked list, where each node, the pointer to the next node, contains another pointer to the previous node. Note that the next pointer of the last node points to the head, while head's prev pointer points to the last node.
