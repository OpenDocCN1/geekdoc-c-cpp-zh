First, the program outputs a and nonsense values for the s.i and s.d members. Next, the value 64 is assigned to i. Since this value is stored in the common space, the value of s.ch is overwritten. the program displays 64 and nonsense values for the s.ch and s.d. Next, the value 12.48 is assigned to d. The value of s.i is overwritten and the program outputs 12.48 and nonsense values for the s.ch and s.i.

> When a union member is assigned with a value, any value previously stored in the last assigned member is overwritten.

Let's have a look. What is the output of the following program?

```
#include <iostream> // Example 13.12

union Test {
    int a, b, c;
};

int main() {
    Test t;

    t.a = 100;
    t.b = 200;
    t.c = 300;
    std::cout << t.a << ' ' << t.b << ' ' << t.c << '\n';
    std::cout << &t.a << ' ' << &t.b << ' ' << &t.c << '\n';
    return 0;
}
```

Since the members are of the same type and they are stored in the same memory, once one becomes 300 that would be the value of the other members as well. Therefore, the program displays three times 300. Then, it displays three times memory address.
A typical use of unions is to save memory data in two or more forms but never simultaneously. For example, suppose we want to store in an array of 100 structures the preferences of men and women. The preferences of men concern favourite game and movie, while for women television show and book. We could use a structure Person like that:

```
struct Person {
    char game[SIZE];
    char movie[SIZE];

    char tv_show[SIZE];
    char book[SIZE];
}
```

For simplicity, using fixed size arrays to hold the texts. However, this structure wastes space, for each person only two members are used to store information. To save space, we can use a union with members structures. For example, consider the following program:
