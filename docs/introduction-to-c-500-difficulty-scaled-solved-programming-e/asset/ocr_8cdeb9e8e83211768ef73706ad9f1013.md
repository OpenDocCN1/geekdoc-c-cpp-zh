Notice that in an overloaded function the type of at least one operand must be a user defined, such as a class. You cannot define an overloaded function where all operands are basic types. For example, you cannot define an overloaded function of the == operator with two arguments char* or int.
 the previous program, an overloaded function of the > operator that takes a parameter Rect (e, r) and returns true if the area of the calling function is greater than the r, false otherwise. Use the area() function to calculate the area. Modify main() to test the operation of the function.

bool Rect::operator>(const Rect& r) /* The declaration is added in the class. */

```
if(area() > r.area())
    return true;
else
    return false;

```

```
int main()
{
    Rect r1(10, 20), r2(30, 40);

    if(r1 > r2)
        std::cout << "Bigger\n";
    else
        std::cout << "Not bigger\n";
    return 0;
}
```

The expression r1 > r2 is translated to r1.operator>(r2), so the function operator> of r1 is called with argument r2. That is, strange as it may see, the expression r1+r2 or r1 > r2 do not perform the math operations, but calling the operator functions. Because the function returns false the program displays Not bigger.
