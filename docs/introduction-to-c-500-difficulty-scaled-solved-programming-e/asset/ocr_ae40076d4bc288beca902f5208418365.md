And if we want to call the show() of the base class from the derived class could we do that? Yes, we just use the scope operator with the name of the base class. For example:

```
void Book::show() {
    cout << "T:" << title << " A:" << auth << '\n';
    Product::show(); /* Pay attention, if we only write show() an infinite recursion will be created. */
}
```

As the comment says, if we write Product::show() the compiler assumes that the show() of the Book class is called, resulting in the creation of an endless recursion. The scope operator also be applied when the object is used to call the function. For example:

```
Book b("B", 2 "Nice", "Many");
b.show(); // The Book::show() is called.
b.Product::show(); // The Product::show() is called.
```

Fine, that's clear when an object is used to call the function. But what happens when a pointer is used to call the function? For example:

```
Book b("B", 2 "Nice", "Many");
Product *p = &b;
p->show(); // Which show() will be called, that of Product or Book?
```

I will answer briefly now, however, I'll make the same question later on when we discuss virtual functions. Because the type of the pointer is Product*, although it points to a Book object, the show() will be called is that of the Product class.

# Function Redefinition with Different Signature

Let's now examine the case where the base class function is declared differently in the derived class. For example:

```
#include <iostream> // Example 20.8

class A {
public:
    void show() const {std::cout << "A\n";
};

class B : public A {
public:
    void show(int k) const {std::cout << k << '\n';
};
```
