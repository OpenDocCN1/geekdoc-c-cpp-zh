As with the if statement, C++17 provides a new version of switch that allows us to add an initialization clause inside switch and then test for the condition. This syntax is similar to:

```
switch(init; condition);
```

For example:

```
int f() {return 10;}
switch(int a = f(); a+1)
{
    case 11:
        cout << "One\n";n        break;
        ...
}
cout << a; // Error, a is out of scope..
```

Since it becomes 10, the code outputs One. The scope of a is limited in the switch block. As with the new if, this concise syntax may be used to initialize the tested variable and limit its scope inside the block.

# switch versus us if

The main disadvantage of the switch statement is that we can make tests only for equality, that is, test whether the value of an expression matches one of the case constants. On the contrary, we can use if to test any kind of condition. In addition, the case constants are restricted to integers and the expression must be an integer or expression only. Because characters are treated as small integers they may be used, floating-point numbers and strings are not permitted. On the other hand, if the number of conditions being tested is large, then the use of switch might be preferable in order to make the code easier to read and maintain. For example, a typical use of switch statement is to handle user choices from a large number of options. Also, switch might be faster than a list of if conditions because the compiler may produce at compile time a jump table indexed by the values of the cases, and find right away the matching case when the program runs. This may be faster compared to a list of if, where each if condition should be evaluated sequentially to reach the matching one.
