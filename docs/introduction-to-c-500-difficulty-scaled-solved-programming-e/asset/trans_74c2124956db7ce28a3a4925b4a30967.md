## 218 C++ 简介

代码显示：

```cpp
char c = 50, a = 70;
if('c' < 'a')
   std::cout << a+c;
```

加法困扰你了吗？'a' 的 ASCII 值小于 'c'，所以代码没有输出。

```cpp
char ch = 'c';
int i;
ch++; // ch 变为 'd'
ch = 68; // ch 变为 'D'
i = ch-3; // i 变为 'A'，即 65。
```

```cpp
#include <iostream>
int main() {
    int a(20) = 1, 20;
    std::cout << (a(0)) !! a(1));

}
```
