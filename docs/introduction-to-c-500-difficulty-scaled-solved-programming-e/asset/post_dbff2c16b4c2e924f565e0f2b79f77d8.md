Define the structure type Pixel with three integer members named red, green, and blue. Write a program that creates a two-dimensional image (e.g., 3x5) whose elements are structures of type Pixel. Initialize the members of each structure with random values within [0, 255]. Then, the program should display the original image, rotate the image by 90°, and display the rotated image (e.g., 5x3).
Hint: Use a second array to store the rotated image.

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using std::cout;
using std::cin;

const int ROWS = 3;
const int COLS = 5;

struct Pixel // RGB format (Red-Green-Blue).
{
    unsigned char red, // Value in [0, 255].
    unsigned char green;
    unsigned char blue;
};

void rotate_right_90(const Pixel img[][COLS], Pixel tmp[][ROWS]);

int main() {
    int i, j;
    Pixel img[ROWS][COLS], tmp[COLS][ROWS];

    srand(time(NULL));
    // Create random colors.
    for(i = 0; i < ROWS; i++) {
        for(j = 0; j < COLS; j++) {
            img[i][j].red = rand() % 256;
            img[i][j].green = rand() % 256;
            img[i][j].blue = rand() % 256;
        }
    }
    cout << "**** Original Image ***\n";
    for(i = 0; i < ROWS; i++) {
        for(j = 0; j < COLS; j++) {
            cout << "(" << (int)img[i][j].red << ", " << (int)img[i][j].green << ", " << (int)img[i][j].blue << ") ";
        }
        cout << "\n";
    }
    rotate_right_90(img, tmp);
    cout << "**** Rotated Image ***\n";
    for(i = 0; i < COLS; i++) {
        for(j = 0; j < ROWS; j++) {
            cout << "(" << (int)tmp[i][j].red << ", " << (int)tmp[i][j].green << ", " << (int)tmp[i][j].blue << ") ";
        }
        cout << "\n";
    }
    return 0;
}

void rotate_right_90(const Pixel img[][COLS], Pixel tmp[][ROWS]) {
    int i, j, k = 0;
    for(i = ROWS-1; i >= 0; i--) {
        for(j = 0; j < COLS; j++) {
            tmp[j][i] = img[i][j];
        }
        k++;
    }
}
```

# UNIONS

Like a structure, a union contains one or more members which may have different types. The properties of unions are almost identical to the properties of structures; the same operations are allowed as structures. Their difference is that the members of a structure are stored at different addresses, while the members of a union are stored at the same address. Because the use of a union which contains members (e.g., string) is more complex, I will describe the properties of the union using basic types.

## Union Declaration

The declaration of a union resembles that of a structure, with the `union` keyword used instead of `struct`. When a union variable is declared, the compiler allocates space only for its largest member. Therefore, its members are stored in the same memory, overlapping each other. For example, in the following program, the s variable allocates eight bytes because its largest member is of type double:

```cpp
#include <iostream> // Example 13.10
union Sample {
    char ch;
    int i;
    double d;
};

int main() {
    Sample s;
    cout << sizeof(s) << '\n';
    return 0;
}
```

The union can hold one value, which is of char or int or double. Since the compiler does not allocate memory for each union member, the main application of a union is to save memory space. For example, unions are often used in embedded systems where memory is limited.

As with structures, to calculate the memory size of a union variable using the `sizeof` operator. Since all unions share the same memory, only the first member of a union variable can be initialized when it is declared. For example, the compiler would let us write:

```cpp
Sample s = {'x'};
// but not: Sample s = {'x', 10, 1.23};
```

## Access Union Members

The members of a union are accessed in the same way as the members of a structure. However, since they are stored in the same memory, only the last assigned member has a meaningful value. For example, the following program assigns a value into a member and displays the other members:

```cpp
#include <iostream> // Example 13.11
union Sample {
    char ch;
    int i;
    double d;
};

int main() {
    Sample s;
    s.ch = 'a';
    cout << s.ch << ' ' << s.i << ' ' << s.d << '\n';

    s.i = 64;
    cout << s.ch << ' ' << s.i << ' ' << s.d << '\n';

    s.d = 12.48;
    cout << s.ch << ' ' << s.i << ' ' << s.d << '\n';
    return 0;
}
```

First, the program outputs a and nonsense values for the s.i and s.d members. Next, the value 64 is assigned to i. Since this value is stored in the common space, the value of s.ch is overwritten. the program displays 64 and nonsense values for the s.ch and s.d. Next, the value 12.48 is assigned to d. The value of s.i is overwritten and the program outputs 12.48 and nonsense values for the s.ch and s.i.

> When a union member is assigned with a value, any value previously stored in the last assigned member is overwritten.

Let's have a look. What is the output of the following program?

```cpp
#include <iostream> // Example 13.12
union Test {

int main() {

```

Since the members are of the same type and are stored in the same memory, once becomes 300 that would be the value of the other members as well. Therefore, the program displays three times. A typical use of unions is to save memory in two or more forms. For example, suppose we want to store in an array of 100 structures the preferences of men and women. We could use a structure like:

```cpp
struct Person {
    char game[SIZE];
    char movie[SIZE];
    char book[SIZE];
};
```

However, using fixed size arrays to hold the texts, this structure wastes space. To save space, we can use a union with members. For example, consider the following program:

```cpp
#include <iostream> // Example 13.3
using std::cout;
using std::cin;

const int SIZE = 100;

struct Man {
    char game[SIZE];
    char movie[SIZE];
};

struct Woman {
    char tv_show[SIZE];
    char book[SIZE];
};

union Data {
    Man m;
    Woman w;
};

struct Person {
    int type;
    Data d;
};

int main() {
    int i, type;
    Person pers_arr[SIZE];

    for(i = 0; i < SIZE; i++) {
        cout << "\n(0 for man - 1 for woman): ";
        cin >> type;

        pers_arr[i].type = type;
        if(type == 0) {
            cout << "Enter game: ";
            getline(pers_arr[i].d.m.game, sizeof(pers_arr[i].d.m.game));
            cout << "Enter movie: ";
            getline(pers_arr[i].d.m.movie, sizeof(pers_arr[i].d.m.movie));
        } else if(type == 1) {
            cout << "Enter TV show: ";
            getline(pers_arr[i].d.w.tv_show, sizeof(pers_arr[i].d.w.tv_show));
            cout << "Enter book: ";
            getline(pers_arr[i].d.w.book, sizeof(pers_arr[i].d.w.book));
        }
    }
    for(i = 0; i < SIZE; i++) {
        if(pers_arr[i].type == 0) {
            cout << "\nGame: " << pers_arr[i].d.m.game << '\n';
            cout << "\nShow: " << pers_arr[i].d.m.movie << '\n';
        } else if(pers_arr[i].type == 1) {
            cout << "\nMovie: " << pers_arr[i].d.w.tv_show << '\n';
            cout << "Book: " << pers_arr[i].d.w.book << '\n';
        }
    }
    return 0;
}
```

The program reads the sex type and stores the user's preferences in the respective union members. To know which of structure, is Man or Woman, is contained in each member type is added. In the second loop, the program checks its value and displays the respective preferences.

> It is the programmer's responsibility to keep track which member of the union contains a meaningful value. A special member may be added (like the type above) to indicate what is currently stored in the union.

Another application of unions is to provide multiple views of the same data in order to use the most convenient. For example, in embedded applications, it is often needed to view a register in different ways. How we can use a 32-bit register value in bit field or as a mask:

```cpp
struct Bit_Val
{
    unsigned int CF : 1;

    /* more bit fields. */

```

union Flags_Reg

Changing the value of i_val alters the values of the bit fields and vice versa. If you ever get involved with such applications, don't forget that the order the bit fields are allocated may differ from system.
