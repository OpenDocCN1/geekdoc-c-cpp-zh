The value assigned to a variable should be within the range of its type. For example, the statement

```
unsigned char a = 260;
```

does not make a equal to 260 (100000100 in binary), because the maximum value that can be stored in an unsigned char is 255. Only the 8 bits will be stored, is, 00000100, and a becomes 4. For unsigned types, the assigned value is the remainder of dividing the integer (e.g., 260) by 2^8. If an outofbounds value is assigned to a signed type, the result is undefined. Then the compiler will not display a message when you run it for overflow. So, pay attention to the ranges of your variables!

```
short int s = 32767; // The maximum value is assigned.
s = s+1; /* The new value of s is undefined. For example, it may be32768 in one system and something different in another system. */
```

C++11 supports initialization with value {}, without using the =. For example:

```
int a(5); // a becomes 5.
vector<int> v(1, 2, 3); // Initialization of a vector with integers. We'll talk about vectors later.*
```

An advantage of this format is that the compiler informs the programmer for conversions that may cause information loss. For example:

```
int a = 5.2; /* a becomes 5. The compiler may not inform the programmer for the information loss. */
int a(5.2); // The compiler informs the programmer for the conversion of the float number to an integer. */
```

An empty list {} is used to assign a default value. For example, the default value for an integer or float type is 0, and for pointers we will see it in Chapter 8 the nullptr:

```
int a(); // a becomes 0.
char *p{}; // p becomes nullptr.
```

# Type Specifiers

As we said, when a variable is declared, its type must be specified. C++11 provides alternative ways to specify the type using the auto and decltype identifiers.

When using the auto it is not needed to declare the type of the variable (e.g., int), as long as the compiler can deduce it from its initialization value. For example:

```
auto a = 5; // The type of a is int.
auto d = 1.2; // The type of d is double.
auto v = i+j; // The type of v is inferred from the type of the result i+j.
For example, if i and j are double, the type of v is double. */
auto k = f(); // The type of k is the return type of f().
```
