# Subtracting and Comparing Pointers

The result of pointer subtraction is valid only if both pointers point to elements of the same array or in the place right after the end of the array. The result is the number of elements between them. If the value of the subtracted pointer is greater, the result would be the same with a negative sign. For example, if p1 points to the second element and p2 points to the fifth element of the same array, the result of p2-p1 is -3. The type of the result is ptrdiff_t, which is defined in the cstddef file

The result of comparing two pointers with the == and != operators is reliable. Using the relational operators <, <= and >=, the result is valid only if both point to members of the same object (e.g., structure) or elements of the same array including the next past end, otherwise it is undefined. For example, the result of p2 > p1 is 1.
