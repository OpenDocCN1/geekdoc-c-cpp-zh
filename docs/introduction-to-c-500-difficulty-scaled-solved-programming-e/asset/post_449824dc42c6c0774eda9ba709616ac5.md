
## C.6.15 Write a program that reads an integer and displays the number of its digits and their sum. For example, if the user enters 1234, the program should display 4 and 10 (1+2+3+4=10).

```cpp
#include <iostream>
int main() {
    int num, sum, dig;

    sum = dig = 0;
    std::cout << "Enter number: ";
    std::cin >> num;

    if(num == 0)
        dig = 1;
    else
    {
        if(num < 0)
            num = -num;

        while (num != 0) {
            sum += num % 10;
            num /= 10; // Remove the last digit.
        }
    }
    std::cout << dig << " digits and their sum is " << sum << '\n';
    return 0;
}
```

## C.6.16 Write a program that reads an integer in [0, 255] continuously and displays it in binary. For example, if the user enters 32, the program should display 0100000. If the user enters a number out of [0, 255], the program should display the total number of times. It should also display the smallest and largest input number, as well as the average of input numbers in [0, 50]. Use while loops only.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    int i, num, times, cnt, min, sum;

    times = cnt = sum = 0;
    min = 255;
    max = -1;
    while(1) {
        cout << "\nEnter number: ";
        cin >> num;
        if(num < 0 || num > 255)
            break;

        i = 7;
        while (i >= 0) { // Check each bit.
            if((num >> i) & 1)
                cout << '1';
            else
                cout << '0';
            i--;
        }
        cout << "\n";

        i = 0;
        while (i < num) {
            cout << "\n";
            i++;
        }
        times++;
        if(num >= 0 && num <= 50) {
            sum += num;
            cnt++;
        }
        if (max < num)
            max = num;
        if (min > num)
            min = num;
    }

    cout << "Total number of times entered is: " << times << '\n';
    cout << "Min:" << min << " Max:" << max << '\n';
    if(cnt)
        cout << "Avg: " << (float)sum/cnt << '\n';
    else
        cout << "No integer in [0, 50] was entered\n";
    return 0;
}
```

## C.6.17 The sum of the series 1/1 - 1/3 + 1/5 - 1/7 ... converges to pi/4. Write a program that finds how many terms should be added until the result converges to pi/4 with an accuracy of 0.001. Consider pi equal to 3.14. Use the fabs() function to check for the convergence.

```cpp
#include <iostream>
#include <cmath>
int main() {
    int i, terms;
    double a, val, final, sum;
    const double pi = 3.14, accuracy = 0.001;

    terms = sum = 0;
    a = 1;
    i = 1;
    final = pi/4;
    while (1) {
        terms++;
        sum += a/i;
        if (fabs(sum-final) < accuracy)
            break;
        a = -a;
        i += 2;
    }
    std::cout << "Sum: " << sum << " Terms: " << terms << '\n';
    return 0;
}
```

## C.18 Write a program that continuously reads a month number (1=Jan, 12=Dec), the first day of the month (1=Mon, 7=Sun), and displays the calendar for that month. If the input month is February, the program should prompt the user to enter its days, that is 28 or 29. If the given month is out of [1, 12], the program should terminate.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    int i, mon, mon_days, day, rows;
    while(1) {
        cout << "\nter month: ";
        cin >> mon;
        if(mon < 1 || mon > 12) {
            break;
        }
        if(mon == 2) {
            cout << "Enter Feb days: ";
            cin >> mon_days;
        }
        else if(mon==4 || mon == 6 || mon == 9 || mon == 11) {
            mon_days = 30;
        }
        else {
            mon_days = 31;
        }

        cout << "Enter start day (1=Mon,7=Sun): \tTue\tWed\tThu\tFri\tSat\tSun\n";
        cin >> day;
        for(i = 1; i < day; i++) /* Add some spaces up to the first day
        of the month to format the output. */
        cout << '\t';

        rows = 0;
        for(i = 1; i <= mon_days; i++) {
            cout << i << '\t';
            if(i == 8-day+(rows*7)) {
                cout << '\n';
                rows++;
            }
        }
    }
    return 0;
}
```

# THE do-while statement

Unlike the for and while statements where the expression is tested *before* the execution of the body, the do-while statement tests the expression *after* each execution of the body. Therefore, a do-while loop is executed at least once. It has the form:

```cpp
do
{
    /* block of statements that is executed at least once
then repeatedly as long as the value of exp is true. */
} while (exp);
```

The loop body is executed first, exp is evaluated. If it is false, the loop terminates. If not, the loop body is executed again and exp is tested. This process is repeated until exp becomes false.

For example, the following program uses the do-while statement to display the integers from 1 to 10:

```cpp
#include <iostream> // Example 6.11
int main() {
    int i = 1;
    do {
        std::cout << i << '\n';
        i++;
    } while (i <= 10);
    return 0;
}
```

Although the braces around a single statement can be omitted I always use them, otherwise, the reader might be mistaken and consider the while part to be a separate while statement. For example:

```cpp
do
    std::cout << i << '\n';
while(+i <= 10);
```
