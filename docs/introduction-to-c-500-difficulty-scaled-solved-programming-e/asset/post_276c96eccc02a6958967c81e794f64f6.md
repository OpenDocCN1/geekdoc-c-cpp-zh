## 218 Introduction to C++

The code displays:

```cpp
char c = 50, a = 70;
if('c' < 'a')
   std::cout << a+c;
```

Did the addition confuse you? The ASCII value of 'a' is less than 'c', so the code displays nothing.

```cpp
char ch = 'c';
int i;
ch++; // ch becomes 'd'
ch = 68; // ch becomes 'D'
i = ch-3; // i becomes 'A', that is, 65.
```
