C.6.11 Write a program that reads a number which corresponds to a number of lines. The program should display the first line a number of '*' equal to the input number and one less in each line. For example, if the user enters 5 the program should display:

*****
****
***
**
*

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    int i, j, lines;

    cout << "Enter lines: ";
    cin >> lines;

    for(i = 0; i < lines; i++) {
        for(j = 0; j <= i; j++) {
            cout << '*';
        }
        cout << '\n';
    }
    return 0;
}
```

**Comments:** Suppose that the user enters 5. Let's explain the code by tracing the first two iterations of the outer loop.

- First iteration of the outer loop (i=0): Since the condition (i < 5) is true, the outer loop is executed.
- Execution of the first inner loop (j=0): Since j=0 and i=0, the condition (j <= i) is true and the loop displays *. This is repeated once. Then, a line change is made.

- **Second iteration of the outer loop (i=1):** Since the condition (i < 5) is true, the inner loop is executed.
- Execution of the first inner loop (j=0): Since j=0 and i=1, the condition (j <= i) is true, so the program displays *.
- Execution of the second inner loop (j=1): Since j=1 and i=1, the condition (j <= i) is true and the loop displays *. This is repeated twice in total. Then, a line change is made.

**C.12** Write a program that reads the grades of five students in three different courses and displays the average grade of each student in these three courses, as well as the average grade of all students.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    const int LESSONS = 3;
    const int STUDENTS = 5;
    int i, j;
    float grd, stud_grd, sum_grd = 0;
    for(i = 0; i < STUDENTS; i++) {
        cout << "****** Student " << i+1 << "\n";
        stud_grd = 0; /* This variable holds the sum of a student's grades in all courses. It is initialized to 0 for each one. */
        for(j=0; j < LESSONS; j++) {
            cout << "Enter grade for lesson " << j+1 << ": ";
            cin >> grd;
            stud_grd += grd; /* This variable holds the sum of all grades. */
        }
        cout << "Average grade for student_" << i+1 << " is " << stud_grd/LESSONS << "\n";
        sum_grd += stud_grd;
    }
    cout << "\nTotal average grade is " << sum_grd/(STUDENTS*LESSONS) << "\n";
    return 0;
}
```

# THE while STATEMENT

The while statement is the simplest way to create loops. Its syntax is:

```cpp
while(exp) {
  /* block of statements (loop body) that is repeatedly executed as long as the value of exp is true. */
}
```

With the for statement, if the loop body consists of a single statement, the braces are omitted. The value of the controlling expression is evaluated. If it is false, the loop is not executed. If it is true, the loop body is executed and evaluated again. If it is false, the loop terminates. If not, the loop body is executed again. This process is repeated until exp becomes false. For example, the following program uses the while statement to display the integers from 10 to 1:

```cpp
#include <iostream> // Example 6.9
int main() {
  int i = 10;
  while (i >= 0) {
    std::cout << i << '\n';
    i--;
  }
  return 0;
}
```

Note that we could write while(i) instead of while(i != 0). Similarly, while(!i) is equivalent to while(i == 0). The for and while statements are closely related. In fact, the for statement:

```cpp
for(exp1; exp2; exp3) {
  statements;
}
```

is equivalent to:

```cpp
exp1;
while(exp2) {
    statements;
    exp3;
```

To answer the question whether to use the while or for statement, given that both produce elegant code, I would say it is a matter of personal preference. Typically, the while statement is used when the number of iterations is unknown or directly tested without initializing a variable. When the number of iterations is known and used, it is preferable to use the for statement, because its compact form makes the loop easier to read. However, there are cases where the for statement, although it may seem the best option, can produce "inelegant". The code of for in C.7 is such an example. If the user enters a wrong value, the step changes inside the body (e.g., i--), which is something I consider "inelegant". If this for statement is replaced with a while statement, the code becomes elegant. Do it and see the difference.

If exp is true, the loop is executed forever unless its body contains an exit statement (e.g., break). For example, the following loop is infinite:

```cpp
while(1)
    cout << "One\n";
```

By convention, most programmers use the value 1 or true to create an infinite loop. However, any non-zero counter can be used. When a program continuously reads data until a condition becomes true, I prefer to use an infinite loop. For example, let's read:

```cpp
int i;
while(1) {
    cout << "Enter number: ";
    cin >> i;
    ...
}
```

Others prefer not to prompt the user to enter data and put the cin statement in the while condition:

```cpp
while(cin >> i) {
    ...
}
```

In this way not only the value is entered but the loop condition of cin is also checked. If something goes wrong, the condition becomes false and the message about what to enter then the loop ends. I prefer the first way, that is, guide the user with an appropriate message. If we want to check the state of the input, we can do it after the input. As I mentioned in Chapter 3, for the sake of brevity and simplicity, I omit such checks.

With the for statement, at the end of the while statement declares an empty body. For example, putting a after the parentheses:

C.6.14 What is the output of the following program?

```cpp
#include <iostream>
int main()
{
    int i = 4, j = 3;
    while (i >> 1)
    {
        i--;
        while (!j)
        {
            std::cout << "One ";
            j--;
            if (i == 1)
                break;
        }
        j += 2;
    }
    std::cout << j << '\n';
}
```

Answer: As the nested for loops, each iteration of the outer while loop triggers the execution of the nested loop. Note that while(i >> 1) is equivalent to while(i != 0), that is, it is checked whether the value of one bit shifted to the right is Not 0. Also, while(!j) is equivalent to while(j == 0). Let's trace the first iteration of the outer loop:

First iteration of the outer loop: Since i is 4, the condition is true, so the inner loop is executed.
First iteration of the inner loop: Since i and j are both 3 the condition (!j) is true, so the program displays One and j becomes 2. As we've, the break statement terminates the loop in which it is contained.

Second iteration of the inner loop: Since the condition is false, the loop terminates. Then, j becomes 4.

Eventually, the program outputs: One One One 6
