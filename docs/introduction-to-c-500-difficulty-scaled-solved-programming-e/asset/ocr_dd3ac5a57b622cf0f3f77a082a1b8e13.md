# INLINE FUNCTIONS

Inline function is a feature that C++ provides to improve performance. As we said in Chapter 14, when a function is called, the compiler stores the memory address of the next statement following the function call, it reserves memory from the stack, if needed, to copy the arguments, program control is transferred to the memory address where the code of the function is located, the function is executed, and when completed, program control returns to the address stored when the function was called.
