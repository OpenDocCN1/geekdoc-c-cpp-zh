The handle_up_msg() is called when a message from the upper layer is received. In our,
upper level connects to the application menu which provides some operations to perform.
example, if the user selects the call option, a new object is created to manage the call and the SETUP
message is supposed to be sent to the called user. In a real application, this message is created when
caller initiates communication with the called user (e.g., dials the number), the network card
tmits it to the physical medium (e.g., optical fiber), and the message traverses the ISDN network to
the destination.

The handle_low_msg() is called when a message from the lower layer is received. For example,
a a real application, the message is received from the network card, it is passed to the driver of the,
and the driver forwards it to the application. In our example, the message is contained in the
data array. In a real application, the handle_low_msg() and handle_up_msg() are called
asynchronously and access the resources, I put them in threads and use semaphores to synchro-
me. STL classes for multi-threading. Thinking of this as a separate program
executed in the main program. In this book we don't discuss about threads, I just give some\hints in case someone is involved using something similar in the future.

Next files are the fsm.cpp and fsm.h. These files implement the state machine of the protocol. For
example, when the SETUP message is received in the IDLE state, the state changes to CALL_INIT
 the message is forwarded to send.cpp for transmission. When the call is in CALL_INIT state and
the CONNECT message is received, the state changes to ACTIVE, which means that the call has been estab-
lished. To release the call, the state changes from ACTIVE to RELEASE_INIT and the RELEASE mes-
saged to send.cpp for transmission. The RELEASE_COMPLETE message is received, the
call is released and the respective object is deleted from the vector. For simplicity, I using the switch
statement. However, typical choice is to use an array of pointers to functions, as in the example of the
section in Chapter 8, in order to improve performance.
