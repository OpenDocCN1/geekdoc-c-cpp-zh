# CONVERSIONS TO CLASS TYPE

As we said in Chapter 17, when a constructor takes a single argument, a value of argument can be converted to the class type. That is, the constructor acts as a conversion function. For example, consider the T class:

```cpp
class T {
private:
    int a;
public:
    T() {}
    T(int i) { a = i; }
    void show() const { cout << a << '\n'; }
};
```

Now, we can write:

```cpp
T t;
t = 20;
t.show();
```

The integer 20 is implicitly converted to a T object. The compiler uses the T(int) constructor to create a temporary object with argument the value 20.

f() displays the value 20. Implicit conversion occurs when a function declared to return a T object returns an integer value. For example:

```cpp
T f()
{
    return 20;
}

T t = f();
t.show();
```

If we do not want the constructor to operate as a conversion function we precede its declaration with the keyword explicit. For example:

```cpp
explicit T(int a);
```

Now, we write t = 20, the compiler will display an error message. However, it is allowed to a conversion using an explicit type cast. For example:

```cpp
t = static_cast<T>(20);
```

Note that if the constructor is declared explicit and outside the class, the word explicit is not added to its definition. For example:

```cpp
explicit T::T(int a) {} // Wrong.
T::T(int a) {} // Correct.
```
