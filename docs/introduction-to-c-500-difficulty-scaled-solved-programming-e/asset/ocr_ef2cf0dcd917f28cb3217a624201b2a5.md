# The strcpy() and strncpy() Functions

A very common error is to use the = operator to copy strings. For example, see again the C.10.3 exercise
or that one:

```
char str[10];
str = "something"; // Wrong.
```

One way to copy C-style strings is to use the strcpy() function. It is declared in cstring

```
char *strcpy(char *dest, const char *src);
```

strcpy() copies the string pointed by src into the memory pointed to by dest. The null character is copied, strcpy() terminates and returns the dest pointer. Since src is declared as const,
strcpy() cannot modify the string. If the source and destination strings overlap the behaviour
of strcpy() and strcpy() is undefined. In the following example, strcpy() copies the string "some-
thing" into str.

```
char str[10];
strcpy(str, "something");
```

```
strcpy(str, "new");
cout << str[6];
```

Since strcpy() terminates once the null character is copied, the first four elements change and the
rest remain the same. Therefore, the code outputs i.
