# Bubble Sort Algorithm

The bubble sort algorithm is based on sequential comparisons between adjacent elements. Each element "bubbles" and is stored in the proper position. For example, suppose that we want to sort an array in ascending order.
At first, the last element is compared against the last one. If it is less, the elements are swapped, the smaller value keeps "bubbles" up. Then, by the last one is compared against the last two. Like before, if it is less, the elements are swapped, so "bubbling" The comparisons continue to the beginning of the array, and eventually the smallest value "bubbles" to the top of the array and it is stored at its first position.
This procedure is repeated from the second element and up to the last one, so the smallest value of the array "bubbles" to the top and in the second position. The same is repeated for the part of the array from its third element and up to the last one, and so forth. The algorithm terminates when none element "bubbles" to the top.
