

## C.6.15 编写一个程序，读取一个整数并显示它的位数以及这些数字之和。例如，如果用户输入 1234，程序应该显示 4 和 10 (1+2+3+4=10)。

```cpp
#include <iostream>
int main() {
    int num, sum, dig;

    sum = dig = 0;
    std::cout << "Enter number: ";
    std::cin >> num;

    if(num == 0)
        dig = 1;
    else
    {
        if(num < 0)
            num = -num;

        while (num != 0) {
            sum += num % 10;
            num /= 10; // Remove the last digit.
        }
    }
    std::cout << dig << " digits and their sum is " << sum << '\n';
    return 0;
}
```

## C.6.16 编写一个程序，连续读取 [0, 255] 之间的整数并以二进制形式显示。例如，如果用户输入 32，程序应该显示 0100000。如果用户输入的数字超出 [0, 255] 范围，程序应该显示输入的总次数。它还应该显示最小和最大的数字，以及 [0, 50] 之间输入数字的平均值。仅使用 while 循环。

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    int i, num, times, cnt, min, sum;

    times = cnt = sum = 0;
    min = 255;
    max = -1;
    while(1) {
        cout << "\nEnter number: ";
        cin >> num;
        if(num < 0 || num > 255)
            break;

        i = 7;
        while (i >= 0) { // Check each bit.
            if((num >> i) & 1)
                cout << '1';
            else
                cout << '0';
            i--;
        }
        cout << "\n";

        i = 0;
        while (i < num) {
            cout << "\n";
            i++;
        }
        times++;
        if(num >= 0 && num <= 50) {
            sum += num;
            cnt++;
        }
        if (max < num)
            max = num;
        if (min > num)
            min = num;
    }

    cout << "Total number of times entered is: " << times << '\n';
    cout << "Min:" << min << " Max:" << max << '\n';
    if(cnt)
        cout << "Avg: " << (float)sum/cnt << '\n';
    else
        cout << "No integer in [0, 50] was entered\n";
    return 0;
}
```

## C.6.17 级 1/1 - 1/3 + 1/5 - 1/7 ... 的和收敛于 pi/4。编写一个程序，找出需要加多少项，直到结果以 0.001 的精度收敛到 pi/4。考虑 pi 等于 3.14。使用 fabs() 函数来检查收敛性。

```cpp
#include <iostream>
#include <cmath>
int main() {
    int i, terms;
    double a, val, final, sum;
    const double pi = 3.14, accuracy = 0.001;

    terms = sum = 0;
    a = 1;
    i = 1;
    final = pi/4;
    while (1) {
        terms++;
        sum += a/i;
        if (fabs(sum-final) < accuracy)
            break;
        a = -a;
        i += 2;
    }
    std::cout << "Sum: " << sum << " Terms: " << terms << '\n';
    return 0;
}
```

## C.18 编写一个程序，连续读取月份数字（1=1月，12=12月）、每月的第一（1=周一，7=周日），并显示该月的日历。如果输入的月份是二月，程序应提示用户输入该月的天数，即 28 或 29。如果给月份超出 [1, 12] 范围，程序应终止。

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    int i, mon, mon_days, day, rows;
    while(1) {
        cout << "\nter month: ";
        cin >> mon;
        if(mon < 1 || mon > 12) {
            break;
        }
        if(mon == 2) {
            cout << "Enter Feb days: ";
            cin >> mon_days;
        }
        else if(mon==4 || mon == 6 || mon == 9 || mon == 11) {
            mon_days = 30;
        }
        else {
            mon_days = 31;
        }

        cout << "Enter start day (1=Mon,7=Sun): \tTue\tWed\tThu\tFri\tSat\tSun\n";
        cin >> day;
        for(i = 1; i < day; i++) /* 添加一些空格直到月份的第一天
        of the month to格式化输出. */
        cout << '\t';

        rows = 0;
        for(i = 1; i <= mon_days; i++) {
            cout << i << '\t';
            if(i == 8-day+(rows*7)) {

                rows++;
            }
        }
    }

}
```

# do-while 语句

与 for 和 while 语句（在执行体*之前*测试表达式）不同，do-while 语句在每次执行执行体*之后*测试表达式。因此，do-while 循环至少执行一次。它的形式如下：

```cpp
do
{
    /* 至少执行一次的语句块，
    只要 exp 的值为真，就会重复执行。 */
} while (exp);
```

首先执行循环体，然后求值 exp。如果为假，循环终止。如果为真，则再次执行循环体并测试 exp。这个过程一直重复，直到 exp 变为假。

例如，以下程序使用 do-while 语句显示从 1 到 10 的整数：

```cpp
#include <iostream> // Example 6.11
int main() {
    int i = 1;
    do {
        std::cout << i << '\n';
        i++;
    } while (i <= 10);
    return 0;
}
```

虽然单个语句周围的括号可以省略，但我总是使用它们，否则读者可能会误认为，将 while 部分视为一个独立的 while 语句。例如：

```cpp
do
    std::cout << i << '\n';
while(+i <= 10);
```
