The following program reads a number of students, creates a vector object that contains their grades and a second one with their names. It displays the names and the grades of the students with a grade greater than equal to the average grade.

```cpp
#include <iostream> // Example 7.4
#include <string>
#include <vector>
using namespace std;
```

```cpp
int main() {
    int i, num;
    float avg, sum;

    cout << "Enter number of students: ";
    cin >> num;

    vector<float> grd(num);
    vector<string> names(num);

    sum = 0;
    for(i = 0; i < num; i++) {
        cout << "Enter grade: ";
        cin >> grd[i];
        cin.get();

        cout << "Enter name: ";
        getline(cin, names[i]);
        sum += grd[i];
    }
    avg = sum/num;
    for(i = 0; i < num; i++)
        if(grd[i] >= avg)
            cout << names[i] << ": " << grd[i] << '\n';

    return 0;
}
```

We discuss the string class in Chapter 10. For now, consider that each name is stored in a string object. The vector contains elements of string type. We use the [] operator to access the elements, as we do with arrays. As we learn in Chapter 18, the vector class overloads the [] operator. Also, the vector class provides the at() function, which takes as an argument the index of the element.

```cpp
for(i = 0; i < num; i++)
    cout << names.at(i) << ": " << grd.at(i) << '\n';
```

The difference with the [] operator is that at() checks for exceeding the bounds of the vector and in such a case it creates the out_of_range exception (we discuss exceptions in Chapter 22). Therefore, if you care about safety, use at() and check for exceptions. On the other hand, if you are sure that your code never exceeds the limits, use [] for greater speed.

In addition to the dynamic definition of the vector size, it is very useful that the size of the initially allocated memory can dynamically increase by adding new elements. For example, the following program reads ten numbers and stores them in a vector that is initially empty:

```cpp
#include <iostream> // Example 7.5
#include <vector>
using namespace std;

int main() {
    int i, num;
    vector<int> vec;

    for(i = 0; i < 10; i++) {
        cout << "Enter number: ";
        cin >> num;
        vec.push_back(num);
    }
    cout << vec.size() << " << " << vec.capacity() << '\n';
    return 0;
}
```

push_back() adds the integer to the end of the vector. Exercise C.7.2 is a similar example.

Let's see how memory is managed. The compiler initially allocates more memory to avoid successive memory allocations each a new element is added. If the available memory runs out, the compiler allocates new memory to store new elements. Its size depends on the implementation, where a typical size is half the original. The allocation of memory may not be a simple extension to the adjacent memory, as this may be used for other purposes. In such a case, the compiler allocates new memory in another area and copies the contents of the original to the new memory. Remember that vector elements are always stored in consecutive memory locations. While the size() function returns the number of elements that are already stored. For example, the above program with the compiler I showed 10 and 16.

Besides the at(), another function begin() returns an iterator that refers to the first element of the object, while end() returns an iterator that refers to the next position after the last element. For now, consider that iterator behaves like a pointer. For pointers, we will discuss in Chapter 8. See the following example to get an idea and you may look it after reading Chapter 8:

```cpp
vector<int> vec(10);
vector<int>::iterator iter;

for(iter = vec.begin(); iter != vec.end(); ++iter) {
    *iter = 200;
}
```

Like any container, the vector class declares an iterator type. The iter variable is declared as iter. As shown, we use iter as a pointer and the value 200 is assigned to all elements of the vector object. The use of begin() and end() functions along with an iterator to traverse the vector is a safe practice, as it ensures that the limits of the vector will not be exceeded.

By using iterators we can delete or add elements into it. For example, the erase() function takes two iterators that specify the part to be deleted:

```cpp
vec.erase(vec.begin(), vec.begin()+3);
```

The iterator specifies the beginning of the part to be deleted, while the second one it does, without including this position. Therefore, this statement deletes the first three elements, from vec[0] to vec[2]. If we call size() to display the number of elements we see that it is 7. In another, if we write:

```cpp
vec.erase(vec.begin()+1, vec.end());
```
all the elements of the vec object are deleted, except the first. That is, size() returns 1. The vector class supports an overloaded version of erase(), which takes as argument an iterator and deletes the element it refers to. If we want to add a new element we use the insert() function:

```cpp
vec[3] = 20;
vec.insert(vec.begin()+3, 50);
```
inserts the value 50 just before the position indicated by the iterator, that is, before vec[3]. Therefore, the value of the new element vec[3] is 50, while the insertion, is 20. The vector class supports an overloaded version of insert() to add a number of elements. Its arguments are three iterators, let's say their names are pos, first, and last. The new elements are inserted before the element at pos but not the one pointed by last. That is, the range includes all elements in [first, last]. Usually this version of insert() is used to copy elements from one vector to another. For example:

```cpp
vector<int> v1(3, 20);
vector<int> v2(3, 10);
v1.insert(v1.begin()+1, v2.end());
```
The contents of v1 become: 20 10 20. The vector class provides the swap() function and overloads several operators, as = and ==. For example:

```cpp
vector<int> v1(3, 20);
vector<int> v2(5, 10), v3;
v1.swap(v2);
v3 = v1;
if(v3 == v2)
if(v3 != v2)
if(v3 < v2)
```
The swap() function exchanges the contents of two objects and if necessary, allocate more to store the elements. The elements of v1 become with a value of 10, while the elements of v2 become with a value of 20. The = operator assigns the elements of v1 to v3, while the == operator compares the two objects. If they are the same, that is, they have the same number of elements and their values are equal, the return value is true. On the other hand, if v1 and v2 were ordinary arrays it'd be illegal to write v3 = v1 to copy the elements we need to use an iteration loop or copy function. You'll also see in Chapter 8 that it is wrong to write if(v3 == v2) to check if the arrays have the same values.

One may ask, wouldn't be better to present the vector class later after we've learned classes and templates, so that we can better understand it? Before answering, let's discuss a bit some important differences between arrays and vector. The main weakness of an array is that it does not support out-of-bounds checks, and as we said, if that happens, the consequences for the program may be catastrophic. In contrast, the vector class supports secure access to its elements. Second, the size of the array remains fixed, which means we cannot add or delete elements from it. Instead, the size of a vector can dynamically change by adding or deleting elements want. Third, when using an array, we have to write the code to manage it and support various functions, such as to search for a value within it. With vector, the code is ready and we can call the appropriate functions. For example, we saw erase() and insert(); there are many more.

As you see, the vector class is easy to work with and provides greater security and flexibility than the array. This is why I decided to discuss vector in this chapter and not later. Either you will learn to use it better; you will use vector in several programming exercises in order to get familiar with it. # C.7.1 What is the output of the following program?

```cpp
#include <iostream>
int main ()
{
    int i, sum, a[] = {5, 6, 7, 8, 9};
    double b[] = {3.1, 1.9, 0.5, -4.1, -0.9};

    sum = 0;
    for (i = 0; a[i] = b[i]; i++) {
        sum += a[i];
    }
    std::cout << sum << '\n';
    return 0;
}
```

Answer: The condition a[i] = b[i] is equivalent to (a[i] = b[i]) != 0, which means that the elements of b are copied to the respective elements of a as long as a[i] does not become 0. If it does, the loop terminates. The value of a is an int, only the integer parts of the b elements will be stored into the respective elements. Therefore, when the value 0.5 is copied, a[2] becomes 0 and the loop terminates. The values of a[3] and a[4] remain the same. As a result, the program outputs the sum of a[0] and a[1], that is, sum=4.
