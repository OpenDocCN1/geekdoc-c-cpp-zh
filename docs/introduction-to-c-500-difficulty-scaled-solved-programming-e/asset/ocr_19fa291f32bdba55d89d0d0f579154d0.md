```
float avg_arr(const vector<float> &v, float min, float max)
{
    int i, cnt = 0;
    float sum = 0;

    for(i = 0; i < v.size(); i++)
    {
        if(v[i] >= min && v[i] <= max)
        {
            cnt++;
            sum += v[i];
        }
    }
    if (cnt == 0)
        return -1;
    else
        return sum/cnt;
}
```

I think the program is clear, except for the & in the vector parameter. When we discuss references in Chapter 16 you'll understand its role. To give you an idea, if we don't use it the vector will be passed by value and, its elements will be copied, which could be time expensive for a vector with many elements. I used const to show that we can prevent changes as we do with an ordinary array.
