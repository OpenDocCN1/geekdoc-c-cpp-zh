# SMART POINTERS

A smart pointer is an object that facilitates the management of dynamically allocated memory. It behaves like an ordinary pointer with the difference that it can release the memory that it manages by itself. Thus, we don't have to worry about not forget to release the allocated memory and create memory leaks. It will be released automatically when no longer needed. For example, with ordinary pointers the following code may create a memory leak

```
void f() {
    int *p = new int[100000];
    ...
    if (error_occurs)
        throw exception();
    
    delete [p];
}
```

If an error occurs, the exception will be created and let's add the delete[] and release the memory before the for- ing exception. Yes, but it might be needed to do the same in other places. For example, before each return statement which might exist in the ... part of the code or in catch blocks that handle thrown exceptions. Believe, it is not so hard to forget adding the delete[] or even worse delete instead of delete[].

We have another alternative besides to "remember" to release the memory, when is, is there a way to ensure we do so? Yes, by using smart pointers. If the pointer we use had a destructor, the destructor could release the memory when the object was destroyed. This is the idea behind smart pointers; to use an object to manage the memory in order to prevent memory leaks. Essentially, a smart pointer is an object of a standard template class which releases the allocated memory when it is destroyed. Thus, we don't have to release the memory; the smart pointer will do it for us. The definitions of the classes are included in the memory header file. C++11 introduces the unique_ptr, shared_ptr, and weak_ptr types. We'll describe them in brief.
