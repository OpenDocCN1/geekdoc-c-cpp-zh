## C.18 Define the class Rect with private members l and h, which denote the length and width of a rectangle, respectively. Also, define the class Circle with private member r, which denotes the radius of the circle. Each class must contain an appropriate constructor and a public function area(), which returns the area of the corresponding shape.

- Define a template function f() that accepts a generic parameter of type Rect or Circle and returns the area of the object. Write a program that tests the function.

**Answer:**

```cpp
#include <iostream>

class Rect {
private:
    float l;
    float h;
public:
    Rect(float a, float b) {l=a; h=b;};
    float area() const {return l*h};
};

class Circle {
private:
    float r;
public:
    Circle(float a) {r=a;};
    float area() const {return r*3.14};
};

template <typename T> float f(T t) {
    return t.area();
}

int main() {
    Rect r(1, 2);
    Circle c(3);

    std::cout << f(r) << ' ' << f(c) << '\n';
    return 0;
}
```

**Comments:** To initialize the private members we use the constructors.

## C.17 Complete the public section of the Lifo class and write a program to test the operation of the class. The purpose of Lifo is to implement a stack, similar to that of Exercise C.J4.8, with the difference that a vector object should be used to store the Node elements and not a linked list.

```cpp
struct Node
{
    string name;
    float grd;
};
```

```cpp
class Lifo
{
private:
    vector<Node> vec_n;
public:
    /* Add functions that implement the stack interface. Specifically, the
       push() function that adds an element (that is, a Node object) in the stack (that
       is, in vec_n), the pop() that uses an argument to return the last element added
       in the stack, displays its data and removes it from the stack, the show_all()
       that displays the data of all elements, and the get_nodes() that returns how
       many elements are stored in the stack. Choose which functions to make const. */
};
```

**Answer:**

```cpp
#include <iostream>
#include <vector>
#include <string>
using std::cout;
using std::string;
using std::vector;

struct Node
{
    string name;
    float grd;
};
```

```cpp
class Lifo
{
private:
    vector<Node> vec_n;
public:
    void push(const Node& n);
    void pop(Node& n);
    void show_all() const;
    int get_nodes() const;
};
```

```cpp
void Lifo::push(const Node& n)
{
    vec_n.push_back(n);
}
```

```cpp
void Lifo::pop(Node& n)
{
    int size = vec_n.size();
    if(size > 0) {
        n = vec_n[size-1];
        vec_n.erase(vec_n.end() - 1);
    }
    else
        cout << "Stack is empty\n";
}
```

```cpp
void Lifo::show_all() const
{
    int size = vec_n.size();
    if(size > 0) {
        for (int i = 0; i < size; i++)
            cout << "N:" << vec_n[i].name << " G:" << vec_n[i].grd << '\n';
    }
    else
        cout << "Stack is empty\n";
}
```

```cpp
int Lifo::get_nodes() const
{
    return vec_n.size();
}
```

```cpp
int main()
{
    int i;
    Node node[] = {{"Alpha", 1}, {"Beta", 2}, {"Epsilon", 3}};
    Lifo lifo;
    for(i = 0; i < 3; i++)
        lifo.push(node[i]);
    lifo.show_all();
    lifo.pop(node);
    cout << "\nname:" << node.name << " G:" << node.grd << '\n';
    cout << "\nNodes:" << lifo.get_nodes() << '\n';
    return 0;
}
```

**Comments:** See the difference of this approach with the solution of C.14. In C.14, we use external functions to manage the stack. With the object-oriented approach, the functions are contained within the class and the programmer specifies which data will be private and will be public. Thus, the vector that contains the elements of the class is declared private, in order to prevent access to it we could use a linked list as in C.14. The implementation only concerns the developer of the class and is not publicly exposed. The user of the class will communicate with it through the public functions that the developer provides. Yes, the object-oriented approach yields the stack more accurately, but it is also safer.

## C.17.10 Define the Time class with members hr, min, and sec, define the minutes, seconds, and respectively. The class should contain a constructor to initialize the members with zero values and the inc_hour(), inc_min() and inc_sec() public functions, which increase by one the values of hr, min, and sec, respectively. Also, the class should contain a public show() function to display the values of the members. Define the functions in such a way that the following program works:

```cpp
int main()
{
    Time t(23, 59, 59);

    t.inc_hour().inc_min().inc_sec();
    t.show(); // The program should display 24:0:0
    return 0;
}
```

**Answer:**

```cpp
#include <iostream>

class Time {
private:
    int hr;
    int min;
    int sec;
public:
    Time(int h = 0, int m = 0, int s = 0);
    Time& inc_hour();
    Time& inc_min();
    Time& inc_sec();
    void show() const;
};

Time::Time(int h, int m, int s)
{
    hr = h;
    min = m;
    sec = s;
}
```

```cpp
Time& Time::inc_hour()
{
    hr++;
    return *this;
}
```

```cpp
Time& Time::inc_min()
{
    min++;
    if(min == 60) {
        min = 0;
        hr++;
    }
    return *this;
}
```

```cpp
Time& Time::inc_sec()
{
    sec++;
    if(sec == 60) {
        sec = 0;
        inc_min();
    }
    return *this;
}
```

```cpp
void Time::show() const
{
    std::cout << hr << ': ' << min << ': ' << sec << '\n';
}
```

**Comments:** The successive use of . operator implies that an object must be to its left. Therefore, the functions must return an object and in particular a reference to it, since the changes in the members must be made to the object itself and not to a copy of it.
