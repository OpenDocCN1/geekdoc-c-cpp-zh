# READ STRINGS

There are many ways to read a string. For example, we can use cin to read it:

```
#include <iostream> // Example 10.4
int main() {
  char str[10];
  int i = 5;

  std::cout << "Enter text: ";
  std::cin >> str; // Danger, be careful.
  std::cout << str << ' ' << i << '\\n';
  return 0;
}
```

The program reads a string, stores it into the str and displays it. By default, cin reads characters until it encounters a white character (i.e., space, tab, or new line character). Then, it appends a null character at the end of the string. Notice that cin does not check if there is available memory to store all input characters. For example, if the user enters a string with more than ten characters, the first ten will be stored into str, but the rest will be stored outside the bounds of the array, which causes the unpredictable behaviour of the program. The value will change. Try it in your program system. To avoid a memory overflow, one way is to use the setw().

cin >> setw(10) >> str;

Now, the maximum number to be stored is limited to ten. In particular, if the user enters more characters, the first nine will be stored in the first nine positions and the null character in the tenth. Note that if the user enters many words (e.g., nice day), because cin stops reading when it encounters a white character such as the space, only the first word will be stored in the array (e.g., nice). The remaining characters are left in the input queue. To be read strings that contain spaces we can use the getline() function, which is a member of the istream class.
