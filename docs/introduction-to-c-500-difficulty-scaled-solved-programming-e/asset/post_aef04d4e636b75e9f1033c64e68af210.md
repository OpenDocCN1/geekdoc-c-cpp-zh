**C.13** Write a program that reads 6 integers and stores them in a 2x3 array (e.g., a). Then, it should read other 6 integers and store them in a 3x2 array (e.g., b). The program should display the elements of a 2x3 array (e.g., c), which is the result of c=a*b.

It is reminded from the linear algebra that the product of two matrices is produced by adding the products of the elements of each row of the first matrix with the corresponding elements of each column of the second matrix. Therefore, the outcome of an NxM matrix multiplied with an MxN matrix is an NxN matrix. For example, consider the following (2x3) and b (3x2) matrices:

```
a = \begin{bmatrix} 1 & -1 & 1 \\ 0 & 2 & 1 \end{bmatrix} b = \begin{bmatrix} 1 & 0 \\ 2 & -2 \\ 2 & 3 \end{bmatrix}
```

The dimension of c=a*b is 2x3, and its elements are:

```
c = \begin{bmatrix} 1*1+(-1)*2+1*2 & 1*0+(-1)*(-2)+1*3 \\ 0*1+2*2+1*2 & 0*0+2*(-2)+1*3 \end{bmatrix} = \begin{bmatrix} 1 & 5 \\ 6 & -1 \end{bmatrix}
```

In math, the value of its element is the outcome of $c_{ij} = \sum_{k=1}^M a_{ik}b_{kj}$. In programming, $k$ ranges from 0 to M-1.

**C.7.14** Write a program that assigns random values within [0, 20] to the elements of a 6x8 integer array. The program should read the user's choice, and if it is 1, it should read more integers which correspond to two rows and swap their elements. If it is not 1, the two input integers correspond to columns. The program should check the validity of the two input integers and display the original and final array.

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
#include <iomanip>
using std::cin;
using std::cout;
using std::setw;

int main()
{
    const int ROWS = 6;
    const int COLS = 8;
    int i, j, a, b, max, tmp, type, arr[ROWS][COLS];

    srand(time(NULL));
    for(i = 0; i < ROWS; i++)
    {
        for(j = 0; j < COLS; j++)
        {
            arr[i][j] = rand()%21;
            cout << setw(5) << arr[i][j];
        }
        cout << '\n';
    }
    cout << "Enter swap type (1:rows): ";
    cin >> type;
    if(type == 1)
        max = ROWS;
    else
        max = COLS;
    do{
        cout << "Enter dim_1[1-" << max << "]: ";
        cin >> a;
    } while (a < 1 || a > max);
    do{
        cout << "Enter dim_2[1-" << max << "]: ";
        cin >> b;
    } while (b < 1 || b > max);
    a--; // Subtract 1, since indexing starts from 0
    if(type == 1)
    {
        for(i = 0; i < COLS; i++)
        {
            tmp = arr[a][i];
            arr[a][i] = arr[b][i];
            arr[b][i] = tmp;
        }
    }
    else
    {
        for(i = 0; i < ROWS; i++)
        {
            tmp = arr[i][a];
            arr[i][a] = arr[i][b];
            arr[i][b] = tmp;
        }
    }
    for(i = 0; i < ROWS; i++)
    {
        for(j = 0; j < COLS; j++)
            cout << setw(5) << arr[i][j];
        cout << '\n';
    }
    return 0;
}
```

C.7.15 In linear algebra, a square matrix is called Toeplitz when the elements of each diagonal parallel to the main diagonal are equal. For example, consider the following 5x5 Toeplitz matrix:

| a | b | c | d | e |
|---|---|---|---|---|
| f | a | b | c | d |
| g | f | a | b | c |
| h | g | f | a | b |
| i | h | g | f | a |

Write a program that reads integers and stores them in a 5x5 array. Then, the program should check whether the array is Toeplitz.

```cpp
#include <iostream>
#include <iomanip>
using std::cin;
using std::cout;
using std::setw;

int main()
{
    const int N = 5;
    int i, j, arr[N][N];

    for(i = 0; i < N; i++)
    {
        for(j = 0; j < N; j++)
        {
            cout << "Enter element[" << i << "][" << j << "]: ";
            cin >> arr[i][j];
        }
    }

    // Logic to check Toeplitz property
    bool isToeplitz = true;
    for(i = 1; i < N; i++)
    {
        for(j = 1; j < N; j++)
        {
            if(arr[i][j] != arr[i-1][j-1])
            {
                isToeplitz = false;
                break;
            }
        }
        if(!isToeplitz) break;
    }

    if(isToeplitz)
        cout << "The matrix is Toeplitz." << std::endl;
    else
        cout << "The matrix is not Toeplitz." << std::endl;

    return 0;
}
```
