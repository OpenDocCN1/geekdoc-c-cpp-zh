Another one. Are there any errors in the following program? If not, what is the output?

```
#include <iostream> // Example 17.12

class T {
private:
    int a;
public:
    T(int i) {a = i;}
    const int* set(int a) const;
};

const int* T::set(int a) const
{
    this->a = a;
    return &(*this).a;
}

int main() {
    int* p;
    T t;
    p = t.set(10);
    std::cout << *p << '\n';
    return 0;
}
```

Yes, there are errors. The first, declaration of t. Since a non-default constructor is defined in T, the default constructor must be defined to make declaration valid. Let's go to set(). Since it is a const function, can set() change the value of a? Of course not. The statement this->a = a is wrong. We said that const makes the this pointer to const. The return statement is wrong? No, since *this corresponds to t, set() returns the address of a. Finally, in main(), the assignment to p is wrong because its type is not const* as the return type of set().
