C.19.1 What is the output of the following program?

```
#include <iostream>

class T {
public:
    int a;
    T(int i) {a = i;}
    T(const T& t) {std::cout << t.a << ' ';}
};

void f(T p) {
    p.a = 10;
}

int main() {
    T *p1, *p2;
    p1 = new T(20);
    p2 = new T(30);
    T r(*p1);
    f(*p2);
    std::cout << '\
' << r.a << ' ' << p1->a << ' ' << p2->a << '\
';
    delete p1;
    delete p2;
    return 0;
}
```

Answer: When r is the copy constructor for r is called, the reference t refers to *p1. So, the program displays 20. Since r is not initialized it has a random value. For example, if we add a statement a=1; in the copy constructor, r.a will become 1. Because an object is passed to f() the copy constructor is called, and the reference t refers to *p2. So, the program displays 30 and because *p2 is passed by value through the statement p.a = 10; does not affect the value of a the member of *p2. Then, the program displays the random value of r.a, 20, and 30.
