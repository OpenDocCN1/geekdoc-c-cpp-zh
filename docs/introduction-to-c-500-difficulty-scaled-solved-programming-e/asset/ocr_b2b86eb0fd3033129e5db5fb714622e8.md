```
class D : public A
{
public:
    D() { cout << "D"; };
};
```

```
class E : public A
{
public:
    E() { cout << "E"; };
};
```

```
class F : public B, public C, public D, public E
{
public:
    F() { cout << "F"; };
};
```

```
int main()
{\    F f;
    return 0;
}
```

How many sub-objects of the A class does the F object contain? It contains one sub-object of the B and C classes where the A class is virtual, one-object for the D class and one for the E class. The program displays:

A() B() C() D() A() E() F()

One more question, if in each class had destructors that display similar messages, what would the program display? Since we know that the destructors are called in the reverse order of that the constructors would display the output from right (e.g., F) to left.

To sum up, as you've seen, multiple inheritance can introduce programming complexities and be problem-prone to implement and control. If you can avoid it and use single inheritance instead, it is preferable. If not, you need to decide whether to use virtual classes or not.
