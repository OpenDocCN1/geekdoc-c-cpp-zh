The result that the relational operators produce is type bool, that is, true or false. For example, the value of the expression (a < 5) is true only if a is less than 5, otherwise, it is false. A more difficult example, tell me what is the result of the expression: -10 < a = -3; it depends on the value of a?

Because the < operator is associative (see Annex A), the first value of the -10 < a is evaluated. The result is either true or false. Remember from Chapter 2 bool values are promoted to int with a default value of 1 for true and 0 for false. So, the result of the comparison, is 1 or 0, compared with -3. Therefore, the value of the expression is always false, no matter what the value of a is. We will see next, to test whether a value is in a given set, we use the && operator.

> Common mistake is to confuse the == and operators. The == operator is used to check whether two expressions have the same value, while the = operator is used to assign a value.

For example, the value of the expression a = 5 is true, only if a is equal to 5, otherwise, it is false. The value of a remains the same. On the other hand, the expression a = 5; assigns the value 5 into a. We'll see more examples like this when presenting the if statement in the next chapter.

# EXERCISE

C.4.1 What is the output of the following program?

```
#include <iostream>
int main() {
    int a = 4, b = 6, c;

    a = (a <= (b-2)) + (b > (a+1));
    b = (a == 2) > ((b-3) < 3);
    c = (b != 0);
    std::cout << a << ' ' ' << b << ' ' ' << c << '\\n';
    return 0;
}
```

**Answer:** Since a is 4 and b is 6, the first expression (4 <= 4) + (6 > 5), so a becomes 2. Since a a is 2, the value of (a == 2) is true. Since b is 6, the value of ((b-3) < 3) is false. So, b = 1 > 0 is 1. Since b is 1, c becomes 1. As a result, the program displays: 2 1 1.
