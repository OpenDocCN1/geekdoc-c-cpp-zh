```
int main()
{
    T t1(1, 2);  // The default copy constructor is called.
    T t2(t1); // The default copy constructor is called.
    T t3 = t1; // The default copy constructor is called.

    t2.show();
    t3.show();
    return 0;
}
```

As the compiler defines the default constructor if no constructor is defined, the default destructor if no destructor is defined and the default copy function, it provides the default copy constructor if none is defined. Thus, to create the t2 and t3 objects, the copy constructor is called. And what this constructor does? As its name implies it copies one by one the non-static members of the existing object into the new one. For example, with the statement t2(t1); the compiler copies the t2 object and calls the copy constructor to copy the members of t1 to t2.

This also allows shallow copy. Each member will depend on its type. The basic types are copied directly, if its array elements are copied and if it is an object the copy constructor of its class is called to make the copy. Similarly, with the T3 = t1; statement, which is an alternative to T3(t1); the copy constructor is called and copies the members of t1 to t2. If the class contains members that are not affected since they belong to the class and not to an object. The program displays 1 twice.

Note that in one assignment, as t2 = t1; it is not the copy constructor that is called, but the default copy operator-function, which copies the members t1 to t2. To make it clear, the copy constructor is called when the object is created (e.g., T2 = t1); whereas the object already exists (e.g, t2 = t1); the copy function is called.

# Define Our Copy Constructor

There are some situations that we need to define our copy constructor. The typical situation is when the class contains pointer(s); we'll see each an example later. Fine, how do we declare it? The copy constructor has the same name as the class, it has no return type, and takes as a parameter reference to an object of the respective class. The usual convention is to declare the reference as const, in the sense that the copy constructor creates a copy of object without modifying it. If we make it-const, it would not be allowed to pass a const object, so we could not copy objects. A reference to const allows const and non-const objects to be copied. After all, the parameter should be a const reference, the job of the copy constructor, as its name indicates, is to make a copy, not to change the original object. In fact, the parameter type for a default copy constructor of any class is a const reference. For example, the prototype of the default copy constructor for the class T is:

```
T(const T&);
```

As an implementation example of our copy constructor, if we add the following in the class definition:

```
T(const T&) { std::cout << "In\n"; }
```

this copy constructor will be called. Then, the program will display 1 twice and junk values for the members of t2 and t3.

Of course, it is allowed our copy constructor to call another constructor or have initialization list as we saw earlier. For example:

```
T(const T& t) : T(t.a, t.b) {}
```
