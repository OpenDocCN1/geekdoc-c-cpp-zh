Suppose that the user enters the values 10, 20, and 30. The program should display:

```
Class A input: 10
Class_B input: 20
Class_C input: 30
Class_C output: 30
Class_B output: 20
Class_C output: 10
```

# U.20.2 Define the classes in such a way that the get() and show() functions.

```
class Circle
{
private:
    float rad;
    ...
};

class Sphere : public Circle
{
private:
    string col;
};

int main()
{
    Sphere sph("Blue", 2); /* Make appropriate calls to constructors, so Blue is stored in the col member of Sphere and 2 in the rad member of Circle. */
    Circle& c = sph;
    c.show(); /* The program should display the colour of the sph object and its volumes according to the type 4/3*pi*r^3. In this example, the program should display Blue and 33.49. */
    return 0;
}
```
