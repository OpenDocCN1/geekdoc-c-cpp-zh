# C.11.9 In math, the trapezoidal rule is a technique for approximating the definite integral of a function $f(x)$ within an interval $[a, b]$. The rule works by adding the areas of the trapezoids that are formed when approximating the function with a polyline, as depicted in the following figure:

![](bbox=[0.158, 0.166, 0.832, 0.438])

The procedure involves the following steps:

+   a. Split the interval $[a, b]$ into $N$ subintervals of the same width. Therefore, $x_i = x_0 + \frac{i(b-a)}{N}$ $i=0, \dots, N$. For larger values of $N$, the approximation is closer to the value of the integral.
b. Calculate the values $f(x_i)$ for $i = 0, \dots, N$.
c. Calculate the areas of the $N$ trapezoids formed under the polyline and add them. The integral is approximately:

> $f(x) = E_{tp1} + \dots + E_{tpN} = \frac{(x_1 - x_0) 	imes (f(x_0) + f(x_1))}{2} + \dots + (x_N - x_{N-1}) 	imes (f(x_{N-1}) + f(x_N))}{2}$
