## C.8.10 What is the output of the following program?

```cpp
#include <iostream>
int main()
{
    int i, *ptr1, *ptr2, arr[] = {10, 20, 30, 40, 50, 60, 70};
    ptr1 = &arr[2];
    ptr2 = &arr[4];
    for (i = ptr2-ptr1; i < 5; i+=2)
        std::cout << ptr1[i] << ' ';
    return 0;
}
```

Answer: As said, when two pointers point to the same array are subtracted, the result is the number of elements between them, not their distance in memory. Therefore, although the address of arr[4] is eight places higher than the address of arr[2], the result of ptr2-ptr1 is equal to the difference of their subscripts, that is, 4-2=2. Since ptr1 points to arr[2], ptr1[2] corresponds to arr[4] and ptr1[4] to arr[6]. Therefore, the program outputs 50 and 70.

Write a program that reads the grades of ten students, stores them in an array, and displays the best and worst grade the positions of their first occurrences in the array. The program should force the user to enter grades within [0, 10]. Use pointer arithmetic to process the array.

```cpp
#include <iostream>
int main()
{
    const int SIZE = 10;
    int i, max_pos, min_pos;
    float *p, max, min, arr[SIZE];

    max = -1;
    min = 11;
    for(i = 0; i < SIZE; i++)
    {
        p = arr+i;
        do {
            std::cout << "Enter grade: ";
            std::cin >> *p;
        } while(*p > 10 || *p < 0); /* Check if the grade is within [0, 10]. */
        if(*p > max)
        {
            max = *p;
            max_pos = i;
        }
        if(*p < min)
        {
            min = *p;
            min_pos = i;
        }
    }
    std::cout << "Max grade is " << max << " " << max_pos << "\nMin grade is " << min << " " << min_pos << '\n';
    return 0;
}
```

## C.8.12 Use the ptr pointer and complete the following program to read and store the grades of 50 students into arr and display the array's values in reverse. Use pointer arithmetic to process the array.

```cpp
#include <iostream>
int main()
{
    const int SIZE = 50;
    float *ptr, arr[SIZE];
    ...
```

Answer:

```cpp
#include <iostream>
int main()
{
    const int SIZE = 50;
    float *ptr, arr[SIZE];

    ptr = arr;
    while(ptr < arr+SIZE)
    {
        std::cout << "Enter grade: ";
        std::cin >> *ptr;
        ptr++;
    }
    while(ptr >= arr)
    {
        std::cout << *ptr << "\n";
        ptr--;
    }
    return 0;
}
```
