# Non-Type Parameters

Like a function template, a class template can take non-type parameters. It is written as a function parameter with the type name followed by the name of the parameter. The most common use of non-type parameters is integer parameters. Typically, they are used when we want to pass values related to numerical sizes and range limits. For example, a common use of an integer argument is when we want to specify the size of a memory. Here is a look at such example:

```
#include <iostream> // Example Grades
template <typename T, int size> class Grades
{
private:
    T lab[size];
    T theory[size];
public:
    Grades();
};

template <typename T, int size> Grades<T, size>::Grades() {
    for (int i = 0; i < size; i++)
        lab[i] = theory[i] = 0;
}

int main() {
    Grades<float, 5> g;
    return 0;
}
```

In the declaration of the class template, the use of typename means that T corresponds to some type, while the second parameter size is to an integer value. The compiler in order to define the Grades<float, 5> class replaces T with float and size to 5. Thus, the type of the two lab and theory arrays becomes float and their size equal to 5. It also calls the constructor of the class to create the g object.
Note that there are some restrictions for the non-type parameters. It is allowed to be an integer literal (e.g., 5), an enumeration type, a constant integer expression, a null pointer, a pointer to a class member or a pointer to an object or a function. For example, it is wrong to write:

```
int p = 10; // Wrong, p should be a constant.
ades<float, p> grd;
```

If we declare const, there will be no problem. Also, if we write float size& or float size* the compiler will display an error message. However, you can use the type name of the type parameter as the type of non-type parameter. For example:

```
template <typename T, T size> Grades {
```
