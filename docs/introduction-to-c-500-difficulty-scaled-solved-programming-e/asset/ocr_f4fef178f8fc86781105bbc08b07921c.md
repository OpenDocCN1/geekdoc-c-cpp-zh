Notice that although arr[i] and ptr[i] access the same element, the compiler gets there in a differ-way. For example, to access arr[2], it gets the address of arr, adds 8 (as we assume the size of int is 4 bytes), and goes to the resulting address to get the value. On the other hand, to access ptr[2], it retrieves the value that is stored there, adds 8, and goes to that address to get the value. In other words, arr[2] resides 8 places after the address of arr, while ptr[2] resides 8 places after the address that ptr points to.
