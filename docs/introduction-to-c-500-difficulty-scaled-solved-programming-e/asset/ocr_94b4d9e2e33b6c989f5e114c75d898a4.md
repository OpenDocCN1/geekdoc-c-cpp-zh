Also, it is very important for the proper operation and maintenance of the program to avoid code duplication as much as possible. Not only is it a waste of time to write the same code many times once, but it carries risks. For example, if the code snippets are duplicated in several places and you decide to change one of them (e.g., to fix a bug), you have to remember to make the same changes in each individual copy of the snippet. Even if it is you same person who duplicated the code it is very easy to make all the adjustments. Much worse if it is someone else with no clue about the code repetition; a bug may have been fixed in one place and still remain in another. If each piece of logic resides in a single place, we can avoid this inconsistency. The function is such mechanism that may encapsulate common parts and save us from dangerous situations.

# COMPLEX DECLARATIONS

Now that we've learned to define functions, let's make a preface for deciphering complex declarations. Always decipher the declaration from inside out. Find the name of the variable and, and if it is enclosed in parentheses (), deciphering from there. Then, continue with the next operator where the precedence order, from high to low is:

+   a. the postfix operators. The parentheses () indicate a function, and the brackets indicate [] an array.
.. the prefix operator * indicates "pointer to".

For example, the declaration of type: int *p[5];

Let's apply these precedence rules. The variable p is not enclosed in parentheses. Because [] take precedence over * we go right, so that p is "an array of five...", then left to * and have "an array of five pointers...", we add the type and end up with "an array of five pointers to integers".

Let's see another example: int (*p)[5];

Now, p is enclosed in parentheses. Deciphering starts inside, so we go left to * and we have p is "pointer to...", then go right, so we have "pointer to an array of five...", then left to add the type and end up with "pointer to an array of five integers". By the way, it is an example of how to initialize a pointer type. Suppose that arr is declared as int arr[]; To initialize p we write p = &arr; or with the declaration int (*p)[5] = &arr;

Another complex declaration: int (*p)(int);

Before we, we start that p is "function that takes an integer argument", then the precedence over *, so we go right and have "pointer to a function with an integer argument...", then left to add the return type and end up with "pointer to a function that returns a pointer to an integer".

Leave the best for: int (*p)[5](int);

Like before, start deciphering inside the parentheses, p is "...", because [] take precedence over * we go right and have "an array of five pointers...", then left to *, and have "an array of five pointers to functions with argument...", then, because () take precedence over * we go right and have left to add the return type and end with the train "array of five pointers to functions with argument pointer to an pointer to an integer".
