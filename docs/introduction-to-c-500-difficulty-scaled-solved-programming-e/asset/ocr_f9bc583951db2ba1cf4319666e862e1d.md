# Pass Arguments by rvalue References

As you guess, we can pass arguments by rvalue references to functions. Thus, a function can use the reference to move data. Typically, such a function is overloaded, we saw earlier with the move and copy constructors and assignment operators. That is, there is one version that accepts const lvalue reference and another with an rvalue reference. When the function is called, the compiler checks the type of the argument and selects the appropriate one. Let's see an example with class member overloads:

```
void T::f(const string& s)
{
    string sl = s; // Copy data.
    ...
}
```

```
void T::f(string& s)
{
    string sl = move(s); // Move data.
}
```

```
T t;
string s = "Text";
t.f(s); // Since s is lvalue the first version is called.
t.f(move(s)); // Since move() returns an rvalue reference, the second version is called.
t.f("Text"); // Because the string literal is an rvalue, the second version is called.
```

Someone may wonder, why in the second f(i) we are using again move()? That is, since the type of s is an rvalue reference we couldn't just write string sl = s; to move the data. Getting inside details, the answer is that the name of a variable is an lvalue, even if that type is an rvalue reference. That's why we have to use move().
