# MACROS WITH PARAMETERS

Besides its simple form, a macro can take parameters and behave like a function. For example, in the following program:

```cpp
#include <iostream> // Example 15.7

#define MIN(a, b) ((a) < (b) ? (a) : (b))

int main() {
    int i, j, min;

    std::cout << "Enter numbers: ";
    std::cin >> i >> j;
    min = MIN(i, j);
    std::cout << min << '\n';
    return 0;
}
```

the MIN takes two parameters. Once it is, the preprocessor replaces a with i, b with j, and expands this line to: min = ((i) < (j) ? (i) : (j)); Because a macro takes parameters of any data type, it can be more generic than a function. For example, we could use the MIN macro to find the minimum of int, char, double, ... and other data types. Using a parameterized macro, instead of a function that does the same job, may improve performance, as a function calls some runtime overhead due to the storage of context information (e.g., the memory address of function) and copy of the arguments. On the other hand, a macro invocation does not impose any delay because the preprocessor has expanded it and added it to the program at compile time. However, the general rule is not to use macros, as you'll see below, their use has many disadvantages and carries risks.

> Don't leave a whitespace after the name of a parameterized macro because the preprocessor will handle the left parenthesis as the beginning of a simple macro definition.

For example, if we write:

```cpp
#define MIN(a, b) ((a) < (b) ? (a) : (b)
```

the compilation will fail because the preprocessor replaces the MIN from the first left parenthesis.

# THE ## OPERATORS

The ## operator is used to merge identifiers together. It is not allowed to appear in the beginning or at the end of the sequence. If it identifies a macro parameter, the preprocessor replaces it with the value of the argument and then merges value with others.

# THE # OPERATOR

The # in front of a macro instructs the preprocessor to create a string literal having the name of the argument. For example:

```cpp
#include <iostream> // Example 15.8
#define f(s) std::cout << #s << " = " << s << '\n';

int main()
{
  const char *str = "text";
  f(str);
  return 0;
}
```
