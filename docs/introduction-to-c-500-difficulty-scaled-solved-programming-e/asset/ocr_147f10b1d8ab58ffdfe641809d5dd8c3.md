Let's continue, where will p point to? Applying pointer arithmetic and because its type is pointer to an array, it will incremented by the size of the pointer and point to the first element of the next row. Consider the following:

```
#include <iostream> // Example 8.21
int main() {
    int i, a[2][3] = {10, 20, 30, 40, 50, 60}, (*p)[3];
    for(p = a; p < a+2; p++) { // We could write the condition as p < &a[2]
        for(i = 0; i < 3; i++)
            std::cout << (*p)[i] << '\n';
    }
    return 0;
}
```

Notice that the case of p must be a pointer to an array. If it declared as int* or int** the program wouldn't compile. Each time p is incremented, it points to the first element of the next row and the inner loop displays the elements of that row. What should we change to make display the elements of a specific row (e.g., the second)?

We'd remove the outer loop and write: p = a+1; equivalently p = &a[1]. The inner loop remains as is.

What if we want to declare pointers to each row of the array? We could use an array of pointers. For example:

```
#include <iostream> // Example 8.22
int main() {
    int i, a[4][2] = {10, 20, 30, 40, 50, 60, 70, 80}, *p[4] = {a[0], a[1], a[2], a[3]};
    for(i = 0; i < 4; i++)
        std::cout << (*(p[i]+1) << '\n';
    return 0;
}
```

When initialized, each p[0] points to a[0] and p[0]+1 points to a[0][1]. Therefore, the program displays the values of the second column, that is, 20 40 60 80.

Before finishing a really tough section, the equivalent pointer expressions access an element of to a four-dimensional array:

```
arr[i] = *(arr+i)
arr[i][j] = *(*(arr+i)+j)
arr[i][j][k] = *(*((arr+i)+j)+k)
arr[i][j][k][l] = *(*(*(arr+i)+j)+k)+l)
```
