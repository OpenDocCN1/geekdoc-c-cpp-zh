Because in several programs we'll need to generate random numbers, let's make a parenthesis to
show you such an example:

```
#include <iostream> // Example 6.2
#include <cstdlib>
#include <ctime>
int main()
{
    int i, num;

    srand(time(NULL));
    for(i = 0; i < 5; i++)
    {
        num = rand();
        std::cout << num << '\\n';
    }
    return 0;
}
```

The rand() function with the srand() and time() functions is used to generate random
integers each time the program runs. rand() returns an integer between 0 and RAND_MAX. The value of
RAND_MAX is defined in cstdlib. The srand() function sets the seed for rand(). For example, if we\want to generate random floating-point numbers in [0, 1], we write double(rand()/RAND_MAX). To use
these in our program we must include the cstdlib and ctime files. In practice, random num-ers are often used, such as in gaming and applications that simulate experiments. Note that
the standard library provides in the <random> several functions that generate random numbers. If you
ever write an application that you should explore the <random> functions; rand() is not sufficiently random for demanding uses. For
sim, we use the ones we just described.

# Common Errors

Let's use same example:

```
for(i = 0; i < 10; i++)
    std::cout << i << '\\n';
```

A common error is to use = check if the final value is returned. That, it is an error to write
i = 10 instead of i < 10. Since this assignment makes the condition true, the loop becomes infinite and
displays continuously 10, significantly degrading the performance of the computer. It is also an error to
write i == 10. In the first step, since i is 0, the condition is false and the loop terminates; nothing is dis-
played on the screen.

statement, consider the following program:
