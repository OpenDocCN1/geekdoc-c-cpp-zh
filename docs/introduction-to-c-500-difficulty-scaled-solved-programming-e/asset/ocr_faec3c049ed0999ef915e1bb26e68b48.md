In general, as we'll see, in a hierarchy of classes (e.g., A, B, C, D), when an object of a derived class is created (e.g., D), the constructor of the most base class is called first (e.g., A), then the constructor of its derived class (e.g., B), and so on (e.g., C), until the constructor of the intended class is called (e.g., D). That is, first the A, B, C sub-objects that are created in the D object are created, and then the D completes the construction of D.
