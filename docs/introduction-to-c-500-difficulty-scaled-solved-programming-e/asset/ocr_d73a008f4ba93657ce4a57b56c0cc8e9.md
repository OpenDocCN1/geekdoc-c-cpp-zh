# OVERLOADING WITH NON-MEMBERS FUNCTIONS

As mentioned, most operators can be overloaded using functions that are not class members. In fact, there are cases where their use is necessary. For example, consider the class A of the previous exercise. As we've seen, the statement a+5 is acceptable, but not the 5+a. To achieve this we declare a member function. Such a function cannot be called by an object. Specifically, the values of the operands are passed as arguments to the function. The restriction is that at least one of the operands must have a class type. In our example, the prototype of the function is:

```
void operator+(int i, A& a);
```

Now, the expression a+5 is translated to operator+(5, a). Let's define it:

```
void operator+(int i, A& a)
{
    a.t += i;
}
```

Is it correct? No, because the t member is private. What did we learn in the previous chapter? How a non-member function access the private members of a class? We declare it as a friend. Let's see the program.

```
#include <iostream> // Example 18.6

class A
{
public:
    int t;
    A(int i) { t = i; }
    void operator+(int i) { t += i; }
    friend void operator+(int i, A& a);
    void show() const { std::cout << t << '\n'; }
};

void operator+(int i, A& a)
{
    a.t += i;
}

int main()
{
    A a(10);

    a+5; // Translated to a.operator+(5).
    a.show(); // The program outputs 15.
    5+a; // Translated to operator+(5, a).
    a.show(); // The program outputs 20.
    return 0;
}
```
