程序应该显示存储在每个 vector 中的分数的最低分、最高分和平均分。
程序应该强制用户输入 [0, 10] 之间的分数，或者值 -1。

```cpp
#include <iostream>
#include <vector>
using std::cout;
using std::cin;
using std::vector;

int main() {
    int size;
    float grd, sum_suc, sum_fail, min_fail, max_fail, min_suc, max_suc;
    vector<float> suc;
    vector<float> fail;

    sum_suc = sum_fail = 0;
    min_fail = min_suc = 11; // 初始化为大于 10 的值
    max_fail = max_suc = -1; // 初始化为小于 0 的值
    while (1) {
        cout << "Enter grade: ";
        cin >> grd;
        /* 有几种方法可以检查输入的分数是否
        有效。在接下来的练习中我使用了 do-while。 */
        if ((grd >= 0 && grd <= 10) || (grd == -1)) {
            break;
        }
        if (grd == -1) {
            break;
        }
        if (grd >= 5 && grd <= 10) {
            sum_suc += grd;
            suc.push_back(grd);
            if (grd > max_suc)
                max_suc = grd;
            if (grd < min_suc)
                min_suc = grd;
        } else {
            sum_fail += grd;
            fail.push_back(grd);
            if (grd > max_fail)
                max_fail = grd;
            if (grd < min_fail)
                min_fail = grd;
        }
    }
    size = suc.size();
    if (size != 0)
        cout << "\nSuccess_Avg: " << sum_suc/size << " Best: " << max_suc << " Worst: " << min_suc << '\n';
    else
        cout << "\nall students failed";
    return 0;
}
```

**注释：** 这是 vector 类提供的极大灵活性的一个示例。如果我们使用数组来存储分数（例如 suc 和 fail），我们就不知道它们的确切大小，因为考试及格和不及格的人数是未知的。因此，我们声明了两个空 vector，只有当分数存储在它们中时，才会分配内存。

## C.7.3 写一个程序，读取一个整数并显示出现超过一次的数字。例如，如果用户输入 1868，程序应该显示数字 8 出现了两次。如果没有数字出现超过一次，程序应该显示一条相关消息。

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    bool flag;
    int i, dig_times[10] = {0}; /* 此数组存储了每个
    数字出现的次数。例如，dig_times[0] 表示数字 0 出现了多少次。 */
    cout << "Enter number: ";
    cin >> i; // 检查是否输入了 i。
    if(i == 0)
        dig_times[0] = 1;
    else
        if(i < 0)
            i = -i;
        while(i != 0)
        {
            dig_times[i%10]++;
            i /= 10;
        }
    flag = 0;
    for(i = 0; i < 10; i++)
    {
        if(dig_times[i] > 1)
        {
            cout << "Digit " << i << " appears " << dig_times[i] << " times\n";
            flag = 1;
        }
    }
    if(flag == 0)
        cout << "No digit appears times\n";
    return 0;
}
```

## C.7.4 写一个程序，连续读取整数并将其存储在 vector 中。如果用户输入 -1，则停止。然后程序应该检查 vector 是否对称，即第一个元素的值等于最后一个元素，第二个元素的值等于倒数第二个，以此此类推。如果不对称，程序应该检查是否有重复的值，如果有，则终止。

```cpp
#include <iostream>
#include <vector>
using std::cout;
using std::cin;
using std::vector;

int main() {
    bool flag;
    int i, j, size;
    vector<int> v;

    while (1) {
        cout << "Enter number: ";
        cin >> i;
        if(i == -1) {
            break;
        }
        v.push_back(i);
    }
    size = v.size();
    flag = 1;
    for(i = 0; i < size/2; i++) {
        if(v[i] != v[size-1-i]) {
            flag = 0;
            break; /* 发现 vector 不对称。 */
        }
    }
    if(flag) {
        cout << "Symmetric\n";
    } else {
        cout << "Not symmetric with ";
        for(i = 0; i < size; i++) {
            for(j = i+1; j < size; j++) { /* 此循环检查是否存在另一个值为 v[i] 的元素。 */
                if(v[i] == v[j]) {
                    cout << "same values\n";
                    return 0; /* 发现有相同的值，程序终止。 */
                }
            }
        }
        cout << "different values\n";
    }
    return 0;
}
```

**注释：** 如果元素是奇数，代码仍然有效，因为中间元素没有与其他元素比较。

## C.7.5 写一个程序，读取整数并以二进制形式显示。使用数组存储数字的位。使用补码法显示负数，例如用户输入 -5：

- a. 将其转换为正数（例如 5）。
- b. 反转其位（例如 101 变为 11111111111111111111111010）。
- c. 加 1（例如数字变为 111111111111111111111111011，这应该是输出值）。

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    int i, j, bits[32]; /* 此数组存储数字的
    0 或 1 位。大小为 32，因为我们假设整数的大小
    是 32。 */
    unsigned int num;
    int tmp;

    cout << "Number: ";
    cin >> tmp;
    if(tmp < 0)
    {
        tmp = -tmp;
        tmp++;
    }
    num = tmp; // 存储为正数。
    i = 0;
    /* 连续除以 2 并每个位存储在相应的
    数组位置。 */
    while(num > 0)
    {
        bits[i] = num & 1;
        num >>= 1; // 等于 num /= 2;
        i++;
    }
    cout << "Binary form: ";
    // 从左到右显示位。
    for(j=i-1; j>=0; j--)
        cout << bits[j];
    return 0;
}
```

**注释：** 我使用移位运算符是为了提高性能。然而，这很可能没有必要，因为编译器会自动优化该操作。

## C.7.6 下面程序的输出是什么？

```cpp
#include <iostream>
int main()
{
    int i, a[] = {-1, 5, 7}, b[] = {5, 4, -1};
    for (i = 0; i < 3; i++)
        a[i]-b[2-i]++;
    for(--i; i >= 0; i--)
        std::cout << a[i] << '\n';

    return 0;
}
```

**答案：** 让我们追踪第一个循环的迭代：

- 第一次迭代（i=0），a[0]-b[2] = -1-(-1) = 0。
- 第二次迭代（i=1），a[1]-b[1] = 5-4 = 1。
- 第三次迭代（i=2），a[2]-b[0] = 7-5 = 2。

因此，a[0], a[1], 和 a[2] 分别变为 0, 6, 和 8。在第二个循环中，i 先减减 变为 2。条件是 a[i] != 0。由于 a[0] 是 0，循环终止。

## C.7.7 写一个程序，读取并将它们存储在 50 个位置的整数数组中。只有当代码不在数组中时才存储。如果数组满了或用户输入 -1，程序应该显示已存储的代码并终止。

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main() {
    const int SIZE = 50;
    bool found;
    int i, j, pos, num, code[SIZE];

    pos = 0;
    while (pos < SIZE) {
        cout << "Enter code: ";
        cin >> num;
        if (num == -1)
            break;

        found = 0;
        /* pos 变量检查输入代码是否已存储在数组中。
        如果是，found 变为 1 循环终止。 */
        for(j = 0; j < pos; j++) {
            if(code[j] == num) {
                cout << "Error: " << num << " exists.\n";
                found = 1;
                break;
            }
        }
        if (!found) {
            code[pos] = num;
            pos++;
        }
    }

    cout << "Stored codes: ";
    for (i = 0; i < pos; i++) {
        cout << code[i] << " ";
    }
    cout << "\n";

    return 0;
}
```
