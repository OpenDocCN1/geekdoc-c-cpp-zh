When the c object is created, the constructor of class c is called, calls the constructor of class B and passes to it the value 20. In turn, it calls the constructor of class A, passes to it the value 21 and the body of A constructor is executed. The program displays A:21, then, the body of B constructor is executed and the program displays B:20. Then, the first sub-object of class A is created and the sub-object of class B. The c contains two sub-objects, one of class A and one of class B. After the construction of these two sub-objects, the body of the C constructor is executed and the program displays C:10.
In general, a hierarchy of classes, a derived object contains a sub-object of its immediate base class and a sub-object for each of its indirect base classes. The destructors are called in the reverse order from which the constructors were called, throughout the hierarchy, from the last derived class to root. Finally, the program displays:

```
A:21      B:20      C:10
-C        -B        -A
```

As mentioned, the constructor of class C is not allowed to use the above syntax to call directly a class A constructor. What is allowed is call only from its direct base class, that is, from B, and B to call a constructor only from class A. For example, we are not allowed to write:

```
C(int p) : A(p) {} // Wrong.
```

The compiler will display an error message similar to A is not a direct base of C.
If we do not want to inherit use final introduced by C++11. For example:

```
class A {...}; // The class cannot be a base class.
class B {...};
class C : public A {...}; // Wrong.
class D final : public B {...};
class E : public D {...};
```

The attempt to inherit from class A or D causes a compilation error. We'll discuss more about the word final in a short.

# Conversions from Derived to Base Class

A special relationship between a base and a derived class is that a pointer or reference to a base class can point or refer to an object of a derived class. Note that type cast is not needed. This conversion is often derived-to-base conversion. For example, consider the examples of class C.20:3:

```
Book("AB25", 8.5, "Nice", "Many");
Product *p = &b; /* Converting a pointer from a derived class (e.g., &b) to a
pointer to a base class (e.g., p) is allowed. The p pointer points to the
Product sub-object of b.
Product &r = b; // The reference refers to the Product sub-object of b.
p->show();
```
