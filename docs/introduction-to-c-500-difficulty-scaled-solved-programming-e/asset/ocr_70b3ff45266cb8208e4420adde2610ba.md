```
if(j = 4)
    m++;

    m++;
if(k = 0)

if(i < m < k)
    m++;
```

**Answer:** This is another example of how the wrong use of the = operator instead of the == operator can produce unexpected results. In particular, the first four conditions don't test the variables for equality, but the variables are assigned the respective values instead. As a result, i becomes -1, j becomes 4, while k becomes 5, and then 0. Since non-zero values are assigned to the first three conditions they are true, while becomes 3.

According to the precedence rules the < operator is left associative. Since i is -1 and m is 3, the expression i < m is true. Then the expression < k is evaluated, which is false, because k is 0. As a result, the program displays 3. When we want to check if the value of a variable is within an interval we use the && operator, that is, if(i == m && m < k).

**C.5.3 To change the PIN code of a mobile phone, the user is asked to enter the PIN code and the device compares with the code stored in the SIM card. If they are the same, the user is asked to enter the new PIN code twice for verification, and if the number is entered twice, it is stored in the SIM card. Write a program that simulates this process. Assume that the current code stored in SIM is 1234.

```
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    int tmp, new_code;

    cout << "Enter code: ";
    cin >> tmp;

    if(tmp == "1234")
    {
        cout << "Enter new code: ";
        cin >> tmp;

        cout << "Enter new code once more: ";
        cin >> new_code;

        if(new_code == tmp)
        {
            cout << "New code is stored\n";
        }
        else
        {
            cout << "Different codes are entered\n";
        }
    }
    else
    {
        cout << "Wrong code\n";
    }
    return 0;
}
```
