# Call of operator Functions

Without going into details, the use of the new and new[] operators causes the call of respective operators. For example, let's look at their simple versions:

```
void* operator new(std::size_t count); // For new.
void* operator new(std::size_t count); // For new[].
```

The size_t is a synonym of an integer type defined by the implementation and the count indicates the number of bytes to be allocated. For example, the statement:

Student *p = new Student; is translated to:

```
Student *p = operator new(sizeof(Student));
```

that, the operator new() is called. When we discuss operator overloading in Chapter 18, you'll understand how the use of an operator triggers the call of an operator function. When new is executed, the compiler allocates memory to construct an object and returns a pointer to the allocated memory (e.g., Student). It then calls the appropriate constructor. In the case of new[] it allocates memory for a number of objects and, for each, its constructor is called. Note that C++ allows us to set our own functions to be called when the new operator is used. For example, if one of our classes, as we see, has special requirements for memory allocation, we can overload the new operator for that class and define our own function. Thus, when an object of that class is created with the new operator, our function will be called.
