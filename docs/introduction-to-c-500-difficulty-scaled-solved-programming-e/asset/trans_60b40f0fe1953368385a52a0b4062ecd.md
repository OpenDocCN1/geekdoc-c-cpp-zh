**C.6.21** 编写一个程序，供老师使用以测试学生是否掌握了乘法口表。程序应该在 [1, 10] 范围内生成两个随机值（例如 a 和 b），并显示 axb = （较小的数字排在前面）。程序应提示学生输入结果，并显示一条信息性消息以指示答案是否正确。如果学生输入 -1，程序应该显示正确答案的总数并退出。

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using std::cout;
using std::cin;

int main() {
    int i, j, num, fails, wins;

    fails = wins = 0;
    srand(time(NULL));
    do {
        i = rand()%10+1; /* rand() 返回一个随机正整数，运算符将其限制在 [0, 9] 内。我们加 1 将其限制在 [1, 10] 内。 */
        j = rand()%10+1;
        if (i < j) {
            cout << '\n' << i << ' x ' << j << ' = ';
        } else {
            cout << '\n' << j << ' x ' << i << ' = ';
        }

        cin >> num;
        if (num != -1) {
            if (num == i*j) {
                cout << "Correct\n";
                wins++;
            } else {
                cout << "Wrong. The answer is " << i*j << '\n';
                fails++;
            }
        }
    } while (num != -1);

    cout << "Fails: " << fails << " Wins: " << wins << '\n';
    return 0;
}
```

**C.22** 编写一个程序根据泰勒级数计算 sin(x)：sin(x) = x - x^3/3! + x^5/5! - x^7/7! ...。程序应以度读取 x，将其转换为弧度，并计算结果，直到连续项之间的绝对差小于 0.0001。不要计算阶乘或进行幂运算。具体来说，计算新项时应使用前一项并将其乘以一个适当的数字。例如，计算 x5/5! 时使用前一项 x3/3! 并乘以 x*x/4。将 pi 视为 3.14，使用 fabs() 函数求差，并使用 sin() 函数比较结果。

```cpp
#include <iostream>
#include <cmath>
int main() {
    int i, a;
    double x, sum, prev_term, cur_term;
    const double pi = 3.14, accuracy = 0.0001;
    std::cout << "Enter x in degrees: ";
    std::cin >> x;
    x = pi*x/180; // 将度转换为弧度。
    sum = x;
    a = 1;
    cur_term = x;
    i = 2;
    do {
        a = -a;
        prev_term = cur_term;
        cur_term = prev_term * x*x/(i*(i+1));
        sum += cur_term * a;
        i += 2;
    } while (fabs(cur_term-prev_term) >= accuracy);
    std::cout << "Sum: " << sum << " Sin: " << sin(x) << '\n';
    return 0;
}
```

# goto 语句

goto 语句用于将控制转移到同一函数内的另一个语句，前提是该语句有一个标签。其语法如下：

```cpp
goto label;
```

当执行 goto 语句时，程序将控制转移到标签后的语句。标签被命名为变量，并且在使用 goto 语句的函数中必须是唯一的。它的名字后面必须跟一个冒号 ：标签的作用范围是整个函数。例如，在以下程序中，如果用户输入 -1，goto 语句将执行转移到 START 标签并重复循环。

```cpp
#include <iostream> // 示例 6.12
int main() {
    int i, num;

START:
for(i = 0; i < 5; i++)
{
    std::cout << "Enter number: ";
    std::cin >> num;
    if(num == -1) goto START; /* 我们可以写 i=-1; 并得到相同的结果；这只是如何使用 goto 的一个示例。 */
    return 0;
}
```

通常，最好避免使用 goto，因为它会导致程序的执行从一个点跳转到另一个点，使得代码难以阅读、维护和修改。但在某些情况下 goto 有用，例如：

```cpp
if(error_1)
    goto ERROR;
if(error_2)
    goto ERROR;
ERROR:
```

另一个例子，goto 可以帮助从嵌套循环中退出，跳转到这里：

```cpp
for(i = 0; i < 10; i++)
    for(j = 0; j < 20; j++)
    {
        if(condition)
            goto NEXT;
    }

NEXT:
```
