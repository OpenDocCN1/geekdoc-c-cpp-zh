
## TWO-DIMENSIONAL ARRAY AS ARGUMENT

The most common way to declare a function that takes parameter a two-dimensional array is to write the name of the array followed by its dimensions. For example, test() takes parameter a two-dimensional integer array with 5 rows and 10 columns

```
void test(int arr[5][10]);
```

Because, as discussed in Chapter 7, the compiler is not necessary to know the number of rows to calculate the memory location of an element, the first dimension may be omitted. If you specify it, the compiler will ignore it. For example:

```
void test(int arr[][10]);
```

However, the number of columns must be specified. In the general, when a multidimensional array is passed to a function, the first dimension must be specified and match the declaration of the array. In this case, the compiler would have the necessary information to make the correct scaling for address arithmetic and access an element. In this example, any array with 10 as second dimension can be passed to the function, but not with dimensions other than 10. 

C++ treats a two-dimensional array as an array of one-dimensional arrays, the compiler actually translates the two-dimensional parameter to a pointer to an array. Therefore, we could equivalently write: void test(int (*arr)[10]); the brackets [] have greater precedence than *, as necessary, otherwise it would be interpreted as an array of 10 pointers to integers instead of pointer to an array of 10 integers. Although that declaration is more accurate, my preference is to use the first one and the first element in order to make that the parameter is a two-dimensional array.

Play some defence, a burst of questions is coming. Where does arr point? It points to the first row of the array. And if arr++ does does it point? In the next one, it is increased by the size of row. And what is (*arr)[1]? It is the second element of the row that arr points to. And does (*arr++) increases arr to the next row and access its first element. How do we know that the total row of the array is reached? Typically, we use either a counter or pass an argument to Two-Dimensional Arrays (*) in Chapter 8.

I write again, the compiler translates the two-dimensional array to a pointer to an array, not to a pointer as you might expect. Therefore it is illegal to write void test(int **arr); We'll discuss the new operator in Chapter 14, you'll see in example C14.5 how we can use a pointer to a variable to dynamically create a two-dimensional array and pass it to a function. Summarize how the compiler translates its arguments:

- One-dimensional: e.g., arr[10] is translated to *arr.
- Two-dimensional: e.g., arr[10][20] is translated to pointer (*arr)[20].
- Array of pointers: e.g., *arr[10] is translated to pointer **arr.

C.11.24 Write a function that takes parameters as array of names and another name. The function should check if name is contained in the array. If it is, the function should return a pointer to the position of name in the array, otherwise nullptr. A program that reads names of 20 students (less than 100 characters) and stores them in an array. Then, reads another name and uses the function to check if name is contained in the array.

```cpp
#include <iostream>
#include <cstring>
using std::cout;
using std::cin;

const int NUM = 20;
const int SIZE = 100;

char *find_name(char name[], char str[]);

int main()
{
    char *ptr, str[SIZE], name[NUM][SIZE]; /* The name array holds names of students. */
    int i;

    for(i = 0; i < NUM; i++)
    {
        cout << "Enter name: ";
        cin.getline(name[i], sizeof(name[i])); /* We use name[i] as a pointer to the respective row of characters. */
    }
    cout << "Enter name to search: ";
    cin.getline(str, sizeof(str));

    ptr = find_name(name, str);
    if(ptr == nullptr)
        cout << ptr << " is not contained\n";
    else
        cout << ptr << " is contained\n";
    return 0;
}

char *find_name(char name[],SIZE], char str[])
{
    int i;
    for(i = 0; i < NUM; i++)
        if(strcmp(name[i], str) == 0)
            return name[i]; /* name[i] points to the first character of the row that contains the name. */
    return nullptr; /* If this point is reached, the name is not found in the array. */
}
```
