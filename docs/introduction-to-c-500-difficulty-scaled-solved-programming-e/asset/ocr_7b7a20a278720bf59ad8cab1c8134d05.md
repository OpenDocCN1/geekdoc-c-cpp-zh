```
int main()
{
    fp var;
    var = g();
    cout << ({*var)(); // The code outputs 5.
}
```

If using the C++11 postfix form we can declare g() as follows:

```
auto g()->int*();
```

where it is shown that the return type is a pointer to a function that returns an integer value and does not accept parameters.

The postfix form is used in declarations of function templates when the return type depends on the type of arguments. For example:

```
template <typename T1, typename T2>
auto f(T1 a, T2 b)->decltype(a*b)
{
    return a*b;
}
```

```
int main()
{
    cout << f(10, 1.3); // The code outputs 13.
}
```

You'll understand this example after reading about function templates in Chapter 16. When f() is called, T1 is replaced by int, T2 by double, the return type of f() becomes of a*b, that is double, and the code outputs 13. This example shows, when we do not know the types of the arguments that will be passed to f(); and therefore, we cannot determine the return type, the use of auto and decltype proves to be particularly useful.

Fortunately, C++14 makes the syntax easier and allows us to write a function that uses auto and let the compiler deduce the return type from the return statements to some rules (e.g., if there are multiple return statements, they must deduce the same). Thus, we do not have to use the peculiar trailing return type of C++11. For example, we can write:

```
template <typename T1, typename T2>
auto f(T1 a, T2 b) // No need to use decltype.
{
    return a*b;
}
```

Another example:

```
auto f(int a)
{
    return a*2.5;
}
```

```
int main()
{
    cout << f(3); // The code outputs 7.5.
...}
```
