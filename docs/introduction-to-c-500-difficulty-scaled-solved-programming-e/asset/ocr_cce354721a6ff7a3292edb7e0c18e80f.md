Answer: When t1() is called only the A of the b object is passed to the function and copied to a. So, f() displays 1 and the program displays A.v(). To make it clear, the member k of A has nothing to do with k of B. When t2() is called, r refers to b which is an object of the derived class. Because f() is not virtual A.f() is called and the program displays 1. On the contrary, v() is virtual the B.v() is called. To sum up, the program displays 1 A.v() 1 B.v().
