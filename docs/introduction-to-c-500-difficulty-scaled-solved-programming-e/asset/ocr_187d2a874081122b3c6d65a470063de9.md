# Return Value

A function returns one value at most. The return type specifies the type of the returned value. A function may return any data type, such as char, double, struct, ... or a pointer to some type. The return type void that the function does not return any value.

The only restriction is that it is not allowed to return an array or a function. However, it is allowed to return a pointer to an array or a function. I know it is too early to see such examples, but I prefer to put them here so that you don't have to search for them elsewhere in this book. A convenient way to specify these return types is to create a synonym. We'll see how to create synonyms in the next section. For example, let's define a function that returns a pointer to an array of five integers:

```
typedef int arr[5]; /* arr is a synonym for the type array of integers. /
using arr = int[5]; // Here is an alternative way to declare arr.
arr* f(); // f returns a pointer to an array of five integers.
```

Here is an example of f():

```
int v[5]; // If the size is not 5 the compiler displays an error message.
f* f() {
    return v;
}
```

C++11 allows us to declare the return type after the list of parameters. For example, the following two statements are equivalent:

```
int f(int a); // Prefix return type.
auto f(int a) ->int; // Postfix return type.
```

The auto specifies that the return type is added with the -> after the parameter list. Thus, we can alternatively write:

```
auto f() ->int(*) [5];
```

where it is shown that the return type is a pointer to an array of five integers.
's see an example of returning a pointer to a function. As previously, we can use a synonym to declare the return type. For example:

```
typedef int (*fp)()(); /* fp is a synonym for a pointer to a function that
returns an integer value and does not accept parameters. */
using fp = int(*)(); // Here is an alternative way to declare fp.
fp g(); // g returns such a pointer type.
```

Here is an example of g():

```
int v() {return 5;}
g() {
return v;
}
```
