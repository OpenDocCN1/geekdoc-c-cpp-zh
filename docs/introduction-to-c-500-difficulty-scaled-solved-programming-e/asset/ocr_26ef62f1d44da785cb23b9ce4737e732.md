Storing data in a binary file can save space compared to a text file. For example, suppose that we are using the ASCII character set to write the number 47654 in a text file. In this system represent with five characters, the size of the file will be 5 bytes, as shown in the following figure:

| 0010100 | 0010111 | 0010110 | 0010101 | 0010100 |
| '4' | '7' | '6' | '5' | '4' |

On the other hand, if this number is stored in binary, the size of the file will be 2 bytes, as shown in the following figure:

```
00111110 00101010
47654 = =
```

Binary files might seem a better choice; they have some disadvantages, though. When a binary file is transferred from one system to another the data might not be represented the same, because different systems store them in different ways. For example, a system may store the high byte of a number, while some other system the lower byte. Furthermore, because the sizes of the data types may differ from system to system, number of bytes might be written. For example, a function using sizeof(int) to save an integer into a file may write four bytes in one system, eight in another.
