Another iterator is the reverse_iterator, which can be used to display the elements of a container in reverse order, from end to the beginning. For example, the vector class contains the rbegin() function which returns a reverse iterator to the last element and the rend() which returns a reverse iterator to the position right before the first element. For example:

```

#include <vector>
#include <algorithm>

using std::vector;

    cout << "Reverse order: " << v.rbegin() << "," << v.rend() << ", show"; show();

    cout << "\nReverse order - again: ";
    vector<int>::reverse_iterator it;
    for(it = v.rbegin()); it != v.rend(); ++it)

';
    return 0;
}
```

When using a function, such as copy(), we may want to add new elements to the container rather than overwriting the ones. The three iterators back_insert_iterator, insert_iterator, and insert_iterator provide this ability. Their type is output iterator.

The back_insert_iterator can be used with containers that support insertion of elements at the end. For example, the vector class qualifies, it provides the push_back() function. The front_insert_iterator can be used with containers that support insertion of elements at the beginning. For example, the list container qualifies, it provides the push_front() function. The insert_iterator is more general as it can be used with containers that support insertion of elements. It is, can be used to insert data at any position; the container just needs to support the insert operation.

To create the back_insert_iterator and front_insert_iterator iterators, the template parameter is the data type of the container and the argument of the constructor is the particular container.
