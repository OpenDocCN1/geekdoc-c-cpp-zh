# Set Types of Template Parameters

There are cases where we may want or we not explicitly specify the type of a template argument. Such a case is when a function returns a value whose type differs from the types of its parameters. For example:

```
template <typename T1, typename T2, typename T3> f(T2 a, T3 b);
```

When we call f() specify the T1 type in <>. The T2 and T3 types will be deduced from the values of its arguments. If we write:

```
int i;
double j;
f<int>(i, j); // int f(int, double);
```

The T1 will be replaced by int and the compiler will determine the T2 and T3 types from the types of the corresponding arguments. When template arguments are explicitly set, each argument (e.g., int) corresponds to the respective template parameter (e.g., T1) from left to right.

# Use of Non-Type Parameters

A function template can accept the following parameters:

+   a. Types.
b. Integer types (e.g., int).
c. Pointers and references to a function or an object type.
d. Pointer to a class member.
e. Enumeration type.

The number of parameters can be fixed or variable, as we'll see below. The most common parameter is the one we encountered so far, the template. Let's look at some examples again:

```
template <typename T> void f(T& a);
double d = 2.3;
f<double>(d); // T becomes double.
vector<int> v;
f(v); // T becomes vector<int>.
```

A non-type parameter represents a value instead of a type. The values of the non-type arguments should be determined at compile time. A typical use of integers is when we want to specify the size of a memory:

```
template <typename T, int size> void f(T& a)
{
  T arr[size]; // The size of the array is specified.
  arr[0] = a;
  size = 20; // Wrong.
}
```

```
int i = 5;
f<int, 10>(i); /* T becomes int, size becomes 10 and arr[0] becomes equal to i,
that is, 5. */
```
