Are the above casts safe? In the general case of type casts, depending on the class declarations, all may be safe, but those that are guaranteed to be safe when the pointer is being pointed to a derived object. The first cast is safe. And if it is safe a B object contains an A sub-object. In fact, as we know from Chapter 20, the casting is not needed. The second is not safe, because the pointer to a base class (e.g., b) is cast to a derived object (e.g., since a B object does not contain a c sub-object it is logical not to safe a c object may contain members that do not exist in b.

As we know, an easy way to find out if a type cast is safe is to check the relationship of the object on the right. For example, the first cast is safe because b object is an A object, and the second is not safe a b object is a c object.

So, while we know that the cast is not safe, the compiler allows it. This is the main reason C++ includes operators for cast. To set some discipline rules when performing casts that they are applied with more safety. That is, is there a way to make type casts and check if they are done safely? Yes, with the help of the dynamic cast operator. The dynamic cast operator only applies to pointers and references to polymorphic classes, that there must be at least one virtual function (declared or inherited in) the class to which the pointer points or the reference refers. It takes two operands, a pointer (or reference) to a class inside < and the pointer (or reference) to be cast inside (). The types we are casting must be pointers or the classes within the same class hierarchy. Let's see an example of its syntax with:

```
dynamic_cast<Type*>(p);
```

p is the pointer to be cast. The type to which p should be cast. The purpose of the dynamic_cast is to ensure that the result of the type casting points to a valid object of the target type (e.g. Type). If the conversion is successful, the operator returns a Type*. If it fails, it returns a null pointer. If p is the null pointer, the operator returns a null pointer. As we said, this type cast is done at runtime, not at compile time. In fact, the word dynamic implies the runtime behaviour. The dynamic_cast operator is primarily used for downcasting, that is to cast a base class (or reference) to a derived class (or reference). It can also be used for upcasting, that is, to cast a derived class (or reference) to a base class (or reference). Let's look at an example of its use with the following code we saw:

```
#include <iostream> // Example 25.3
class A {
```
