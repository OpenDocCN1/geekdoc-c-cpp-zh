The procedure to insert a key in the tree resembles the procedure to search for a key. U.14.16 to write a recursive search function. Alternatively, here is a non-recursive implementation. In fact, this is my preference; remember we've discussed about recursion performance issues in the respective section of Chapter 11.

```
Node find_node(Node *p, int key)
```

```
{
    if (p == nullptr) /* Check if the tree is empty. We could use the while
condition, I just prefer to make it clear. */
        return nullptr;

    while (p != nullptr)
    {
        if (key < p->key)
            p = p->left;
        else if (key > p->key)
            p = p->right;
        else
            return p;
    }
    return nullptr;
}
```

The code compares the key and the proper subtree is selected. If the lower level is reached, it means that the key is not found.
