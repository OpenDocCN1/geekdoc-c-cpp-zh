# Destructor and Memory Release

As weve, the destructor of an object with automatic storage duration (e.g., t in example C17.5) is called automatically when the program exits the block in which the object is defined. If the object has static storage, its destructor is called when the program terminates. If the object has been created with the new operator, its destructor will be called when the delete operator is used to free the reserved memory. Also, a program may create temporary objects to perform certain operations; the program calls their destructors when it no longer needs them. For example:

```
Test;
t = Test(3, 4);
```

First, the constructor is called and the t object is created. With the next, the compiler creates an unnamed object with values 3 and 4 and copies its contents to t, which is, ta becomes 3 and t becomes 4. Then, its destructor is called and this temporary object is destroyed.
Let's see an example that demonstrates the most common use of a destructor, which is to release the memory allocated by members-pointers.
