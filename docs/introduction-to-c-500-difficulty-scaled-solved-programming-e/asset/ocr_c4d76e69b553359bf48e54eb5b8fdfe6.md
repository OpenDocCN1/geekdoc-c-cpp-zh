If the character after \ is not supported, the behaviour is undefined. The escape sequences are divided into character escapes and numeric escapes. The character escapes can represent ASCII characters (e.g., new line), while the numeric escapes, which are the latter in Table 3.1, can represent any character. Let's see the following:

```
#include <iostream> // Example 3.1
using std::cout;

int main() {
    cout << '\a';
    cout << "Check\b\b back\";
    cout << "Test\rCR\";
    cout << "\53\nx2d\"; /* The octal number 53 (decimal 43) corresponds to the character + and the hexadecimal number 2d (decimal 45) to -. */
    cout << "T\ree\n";
    cout << "Check\t\tpoint\\\n";
    return 0;
}
```

As we will see, the \n we can use the endl manipulator to change the line. The first statement creates a beep, while the second one deletes the last three characters of the word Check, prints back the message and the \n moves the cursor to the beginning of the next line. On the third, the \r moves the cursor to the beginning of the line and the word CRst is displayed. The next one outputs + character, changes line and outputs -. The next one outputs T, then a, and then the word tree. The last one outputs the word Check, adds two tabs, and prints the word \point\. To sum up, the program outputs:

(Hear a beep)
Ch backspace
CRst
+
T"ree"
Check \point\

If we want to display a single character we can also use single apostrophes (e.g., cout << 'd'). If you want for better readability to expand the format string of cout to several lines, one way is to use the backslash\. For example, the following cout is written over three lines, the output will appear on one line:

```
cout << "This statement extends in three lines, \
but the message is displayed \
in the same line";
```
