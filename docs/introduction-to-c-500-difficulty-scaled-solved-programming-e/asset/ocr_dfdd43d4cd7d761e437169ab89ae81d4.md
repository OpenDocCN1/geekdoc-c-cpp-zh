# C.15.3 Suppose that the content of test.h is:

```
#include <iostream>

#define TEST

#ifdef TEST
#define f() std::cout << "One "
#undef TEST
#endif
```

What is the output of the following program?

```
#include "test.h"
int main()
{
    f();
    #ifdef TEST
    f();
    #endif

    f();
    return 0;
}
```

**Answer:** The preprocessor replaces the first occurrence of f() with cout and then cancels the definition of TEST. Since TEST is not defined, the preprocessor does not expand the second f() and continues with the third. Therefore, the program displays: One One

# C.15.4 A program that reads double numbers continuously and counts the positives or the negatives depending on the definition of a macro. For example, if the CNT_POS macro is defined, the program should count the positives, otherwise the negatives. If the user enters 0, the insertion of numbers should terminate.

```
#include <iostream>

#define CNT_POS
```

```
int main()
{
    int cnt = 0;
    double num = 1;
    while (num != 0)
    {
        std::cout << "Enter number: ";
        std::cin >> num;
        #ifdef CNT_POS
        if (num > 0)
            cnt++;
        #else
            if (num < 0)
                cnt++;
        #endif
    }
    std::cout << cnt << '\n';
    return 0;
}
```
