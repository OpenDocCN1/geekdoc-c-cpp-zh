```
Rect::Rect(float l, float h)
{
    length = l;
    height = h;
}
```

```
Rect::operator+(const Rect& r) const
{
    Rect tmp;
    tmp.length = length + r.length;
    tmp.height = height + r.height;
    return tmp;
}
```

```
float Rect::area() const
{
    return length * height;
}
```

```
void Rect::show() const
{
    std::cout << "L:" << length << " H:" << height << '\n';
}
```

```
int main()
{
    Rect r1(10, 20), r2(30, 40), r3;
    r3 = r1+r2; // Equivalent to r3 = r1.operator+(r2)
    r3.show();
    return 0;
}
```

Before discussing the operator overloading, let's answer that. Since the length and height members are private, the compilation does not fail when those members are accessed in the operator+ function (e.g., r1.length?). The answer is that C++ allows an object to access all the members of objects of the same class, including the private members.

When the compiler encounters the r1+r2 statement it examines the types of operands and realizes that it must call the operator+ function. Specifically, the r1+r2 statement is implemented as r1.operator+(r2), so the operator+ function of the r1 object is called with the argument r2. In general, when the overload of a binary operator is declared in the class, the left (e.g., r1) is the object that calls it, while the right operand (e.g., r2) is passed as an argument to the function. Note that if the operator function was not declared, the compiler would display an error message for an illegal action, since objects cannot be added. Alternatively, it could explicitly call the function and write r1.operator+(r2). Naturally, the usual of the operator is easier to read and write abbreviation of the explicit call. The function returns a new object with dimensions equal to the corresponding dimensions of the two objects. So, the program displays 40 and 60.
