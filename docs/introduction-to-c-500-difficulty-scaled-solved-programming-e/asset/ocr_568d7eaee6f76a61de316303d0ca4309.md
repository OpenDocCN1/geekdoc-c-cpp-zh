void Build_Pkt(const IP_src[], const int IP_dst[], int port)
{
    unsigned char pkt[40] = {0}; // Initialize all fields to 0.
    int i, j;
    pkt[0] = 0x45; // Version, IVL.
    pkt[8] = 255; // Time to Live.
    pkt[9] = 6; // Protocol: TCP.
    for(i = 12; j < 16; i++)
        pkt[i] = IP_src[j]; // IP Source.
    for(i = 16; j < 20; i++)
        pkt[i] = IP_dst[j]; // IP Destination.
    pkt[20] = 1500 >>; // TCP Source Port.
    pkt[21] = 1500 & 0xFF;
    pkt[22] = port >> 8; // TCP Dest Port.
    pkt[23] = port & 0xFF;
    pkt[33] = 2; // SYN bit.
    pkt[34] = 0xFF; /* The maximum value for the Window field is all 16
    pkt[35] = 0xFF;
    /* The Values of the CheckSum and Urgent Pointer are set in positions
where, the total length of the IP packet is 40 bytes. */
    pkt[2] = 0; // IP Total Length.
    pkt[3] = 40;

void Show_Frm(const unsigned char pkt[], int len)
{
    for(int i = 0; i < len; i++)
    {
        if(i%16 == 0)
            cout << setw(2) << setfill('0') << hex << (int)pkt[i] << ' '; /* Each
element is displayed with two digits. If the value has one digit, the
digit is 0 as default. */
    }
}

Comments: Do you have any idea about what this program really does? This program is an oversimplified version of a popular application, almost installed in your computer, the firewall. This program may prevent communication to specific IP addresses and specific applications (e.g., web servers to talk to TCP port 80). The main part of a firewall is nothing more than a sequence of if-else statements.

In a real networking, this IP packet is encapsulated in a MAC frame; the hardware of the network card encodes the bits of the frame signals (e.g., two voltage levels represent 0 and 1) and forwards the frame to the connected router. The router checks the IP destination address; it consult its routing table to determine the next router for the destination and forwards the frame. This process is repeated for the next router using its own routing table, until the frame eventually reaches the destination.
