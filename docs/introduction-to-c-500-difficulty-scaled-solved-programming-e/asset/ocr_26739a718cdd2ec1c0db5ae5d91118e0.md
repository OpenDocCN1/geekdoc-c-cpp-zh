```
class D : public C {
public:
    D() { cout << " D"; }
    ~D() { cout << " -D"; }
};

```

```
class E : public C {
public:
    E() { cout << " E"; }
    ~E() { cout << " -E"; }
};

```

```
class F : public D, public E {
public:
    F() { cout << " F"; }
    ~F() { cout << "\n-F"; }
};

```

```
int main() {
    F f;
    return 0;
}

```

**Comments:** As we know, the destructors are called in the reverse order from that of the constructors. The program displays:

A() B() C() D() C() E() F()
~F() ~E() ~C() ~D() ~C() ~B() ~A()
