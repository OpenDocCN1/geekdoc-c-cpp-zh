# READ STRINGS

There are many ways to read a string. For example, we can use cin to read it:

```cpp
#include <iostream> // Example 10.4
int main() {
  char str[10];
  int i = 5;

  std::cout << "Enter text: ";
  std::cin >> str; // Danger, be careful.
  std::cout << str << ' ' << i << '\n';
  return 0;
}
```

The program reads a string, stores it into the str and displays it. By default, cin reads characters until it encounters a white character (i.e., space, tab, or new line character). Then, it appends a null character at the end of the string. Notice that cin does not check if there is available memory to store all input characters. For example, if the user enters a string with more than ten characters, the first ten will be stored into str, but the rest will be stored outside the bounds of the array, which causes the unpredictable behaviour of the program. The value will change. Try it in your program system. To avoid a memory overflow, one way is to use the setw().

```cpp
cin >> setw(10) >> str;
```

Now, the maximum number to be stored is limited to ten. In particular, if the user enters more characters, the first nine will be stored in the first nine positions and the null character in the tenth. Note that if the user enters many words (e.g., nice day), because cin stops reading when it encounters a white character such as the space, only the first word will be stored in the array (e.g., nice). The remaining characters are left in the input queue. To be read strings that contain spaces we can use the getline() function, which is a member of the istream class. We will see in Chapter 17, to call a function that is a member of a class we write the name of the object (e.g., cin) and add the . operator.

The first argument of getline() is a pointer to the memory used to store the characters, the second specifies the maximum number of characters (e.g., size) to be read. This number should not be larger than the size of the allocated memory to prevent overflow. getline() stops reading when it reads the newline character or when it reads size-1 characters, whichever comes first. Then, it adds the null character. For example:

```cpp
char str[30];
cin.getline(str, sizeof(str));
```

getline() will read a maximum of 29 characters, leaving one place for the null character. The characters will be stored in the str array. If the new character is encountered early, getline() stops reading. getline() extracts the new line from the input stream and does not store it. If the user enters more characters, the redundant characters are left in the input queue. To read your program independent of the array size, use the sizeof operator instead of a fixed value (e.g., 30). Note that there is a version of getline() which allows us to specify the character to stop. For example:

```cpp
cin.getline(str, sizeof(str), '\n');
```

Now, if getline() encounters the line character it won't stop. This would allow multiple lines to be deleted. That overloaded version of get() we saw in Chapter 9 works similarly to getline(). Since we are going to use getline(), there is no need to describe it. If we want to find how many characters are read we can use gcount() function. For example:

```cpp
char str[30];
cin.getline(str, sizeof(str));
cout << cin.gcount() << "\n";
```

If the user enters test, the code outputs 5. The pointer that is passed to getline() must point to allocated memory. Example, is this following code correct?

```cpp
char *p, s[10];
p = s;
cin.getline(p, 10);
```

Yes, because p points to allocated memory. If the statement p = s; was missing, the code would be wrong. And, if in getline(), instead we use sizeof(p), would be the same? Not, the sizeof operator returns the size of the pointer, and not the size of memory it points to. An unexpected behavior that makes novice wonder why their program not correctly arises when the program reads a string after having read a numerical value. We saw something in C.9. Another example, suppose that the user enters an integer and presses Enter. What does the following program output?

```cpp
#include <iostream> // Example 10.5
using std::cout;
using std::cin;

int main()
{
    char str[100];
    int num;

    cout << "Enter number: ";
    cin >> num;

    cout << "Enter text: ";
    cin.getline(str, sizeof(str));

    cout << num << ' ' << str;
    return 0;
}
```

The program reads the integer and stores it in num. The new line character generated when Enter is pressed in the input queue. Since getline() terminates the line character is read, the user cannot enter more characters. Therefore, the program outputs only the input number. A solution is to use cin.get() before getline(), in order to read the line character.

## C.10.8 Complete the following program by using the p pointer and a while loop, so that the program reads a string of less than 100 characters and displays the number of the characters, the number of 'b' occurrences, and the input string after replacing the space character with the new line character and 'a' with 'p'.

```cpp
#include <iostream>
int main()
{
    char *p, str[100];
    int cnt;
    ...
}
```

**Answer:**

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    char *p, str[100];
    int cnt;

    p = str;
    cout << "Enter text: ";
    cin.getline(p, sizeof(str));

    cnt = 0;
    while (*p != '\0')
    {
        if (*p == ' ')
            *p = '\n';
        else if (*p == 'a')
            *p = 'p';
        else if (*p == 'b')
            *p = 'b';
        cnt++;
    }
    cout << "Len:" << p-str << " Times:" << cnt << "\nText:" << str << "\n";
    return 0;
}
```

Comments: When the loop ends, p points to the null character. Then, we use pointer arithmetic to calculate the length of the string.
