# The strlen() Function

The strlen() function is declared in cstring:

```cpp
size_t strlen(const char *str);
```

The size_t type is defined in the C++ library as an alias of some unsigned integer type (e.g., unsigned int). strlen() returns the number of characters in the string pointed to by str, not counting the null character.

```cpp
int len;
len = strlen("Test"); // len becomes 4.
const char *p = "";
len = strlen(p); // len becomes 0.
char s[] = {'a', 'b', 'c'};
len = strlen(s); /* The result is undefined, because the null character is not
stored in the array. */
```

The pointer is declared as const, so that strlen() cannot modify the string. Here is an example of how it might be implemented:

```cpp
unsigned int strlen(const char *str)
{
    unsigned int i = 0;

    while(str[i] != '\0') /* We count the characters of the string until
    we reach the '\0'. */
    i++;

    return i;
}
```

As an example of using strlen() tell me what the following code outputs:

```cpp
char str[] = "Text";
cout << strlen(str+4) << ' ' << strlen("Text"+1) << ' '\n';
```

Since the name of an array can be used as a pointer to its first element - I doubt I've written it times, I just want to be sure you've got it - str+4 is a pointer to the fifth character of str, that is, the null character. Therefore, the first strlen() returns 0. The string literal can be used as a pointer, the second strlen() returns the number of characters after the second one. As a result, the code outputs: 0 3.

# The strcpy() and strncpy() Functions

A very common error is to use the = operator to copy strings. For example, see again the C.10.3 exercise or that one:

```cpp
char str[10];
str = "something"; // Wrong.
```

One way to copy C-style strings is to use the strcpy() function. It is declared in cstring

```cpp
char *strcpy(char *dest, const char *src);
```

strcpy() copies the string pointed by src into the memory pointed to by dest. The null character is copied, strcpy() terminates and returns the dest pointer. Since src is declared as const, strcpy() cannot modify the string. If the source and destination strings overlap the behaviour of strcpy() and strcpy() is undefined. In the following example, strcpy() copies the string "something" into str.

```cpp
char str[10];
strcpy(str, "something");
```

If the null character is not found, the copy operation won't perform successfully. For example:

```cpp
char str1[] = "abcd", str2[] = {'e', 'f', 'g'};
strncpy(str1, str2);
```

Since str2 does not contain the null character, the copy operation won't perform successfully and a runtime error may occur.

> Because strcpy() does not check if the string pointed to by src fits into the memory pointed by dest, is the programmer's responsibility to ensure the destination memory is large enough to hold all characters. Otherwise, the memory past the end of the dest will be overwritten causing the unpredictable behaviour of the program.

For example, consider the following:

```cpp
#include <iostream> // Example 10.6
#include <cstring>
int main()
{
    char c = 'a', str[10];

    strcpy(str, "Longer text. The program may crash");
    std::cout << str << ' ' << c << '\n';
    return 0;
}
```

Since the size of str is not large enough to hold the characters of the string, the data past the end of str will be overwritten (e.g., c could be stored in that position). And yes, it is a serious error to pass an uninitialized pointer to strcpy(). For:

```cpp
char *str;
strcpy(str, "test"); // Wrong, str is not initialized.
```

The strncpy function is declared in cstring:

```cpp
char strncpy(char *dest, const char *src, size_t count);
```

strncpy is similar to strcpy(), with the difference that only the first count characters of the string pointed to src will be copied into dest. If the value of count is less or equal to the length of the string that str points to, a null character isn't appended to the memory pointed to dest. If it is greater, null characters are appended up to the value.

> strncpy() specifies the maximum number of copied characters is safer than strcpy().

Here is an example of strncpy():

```cpp
#include <iostream> // Example 10.6
#include <cstring>
int main() {
  char str1[] = "Old text", str2[] = "New", str3[] = "Get";

  strncpy(str1, str2, 3);
  std::cout << str1 << '\n';

  strncpy(str1, str3, 5);
  std::cout << str1 << '\n';
  return 0;
}
```

Since the number 3 is less than the length of the string stored in str2, the first strncpy copies the first three characters into str1 and does not append a null character. Therefore, the program displays New. Since the number 5 is greater than the length of the string stored in str3, the second strncpy copies three characters from str3 and appends null characters to reach the value 5. Therefore, the program displays Get.

# The strcpy() Function

The strcpy function is declared in cstring:

```cpp
char *strcpy(char *dest, const char *src);
```

strcpy() appends the string pointed by src to the end of the string pointed by dest. strcpy() appends the null character and returns dest, which points to the resulting string. For example, the following program reads two strings less than 100 characters and uses strcpy() to merge them into an array.

```cpp
#include <iostream> // Example 10.8
#include <cstring>
using std::cout;
using std::cin;

int main() {
  char str1[100], str2[100], str3[200] = {0}; /* Store the null character in str3 for the first strcpy(). */

  cout << "Enter first text: ";
  cin.getline(str1, sizeof(str1));

  cout << "Enter second text: ";
  cin.getline(str2, sizeof(str2));

  strcpy(str3, str1); // The string in str1 is added to str3.
  strcpy(str3, str2);
  cout << "The merged text is: " << str3 << '\n';
  return 0;
}
```

> It is the programmer's responsibility to ensure that there is enough room in the memory to append the string pointed by src. Otherwise, it is a potential cause of memory overrun with unpredictable results.

# The strcmp() Functions

The strcmp function is declared in cstring:

```cpp
int strcmp(const char *str1, const char *str2);
```

strcmp() compares the string pointed to by str1 with the string pointed by str2. If the strings are identical, strcmp() returns 0. If the first string is less than the second, strcmp() returns a negative value, if it is greater it returns a positive value. A string is considered less than either one of the following conditions is true:

- first n characters of the strings match, but the value of the n+1 character in the first string is less than the value of the n+1 character in the second string.
- All characters, but the first string is shorter than the second.

Let's see some examples. The statement strcmp("One", "one") returns a negative value because the ASCII code of the first non-matching character 'E' is less than the ASCII code of 'e'. The statement strcmp("one", "many") returns a positive value the ASCII code of the first non-matching character 'w' is greater than 'm'. The statement strcmp("some", "something") returns a negative value because the first four characters, but the first string is smaller than the second.
