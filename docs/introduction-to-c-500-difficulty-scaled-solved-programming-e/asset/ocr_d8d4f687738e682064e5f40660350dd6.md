**C.6.1** What is the output of the following program?

```
#include <iostream>
using std::cout;
int main()
{
    int i = 2;
    unsigned int j = 2;

    for (i > j && (i+j) == 4); i--, j++)
        cout << i << ' ';
        cout << j << ' ';

    for(j = i; j >= 0; j--)
        cout << "\n";
}

```

**Answer:** Since the for has no braces, the loop body contains only the first cout. Deliberately indented the second cout to make you think that it belongs to the loop body. No, it does not, it is executed only once, after the end of the loop. The value of i > j is 0; however, this does not affect the execution of the loop. Let's trace the iterations:

+   *First iteration.* The first term of the condition, that i is, it is equivalent to i!=0, which is true. i is 2 and j is 2, the second term is also true, the program outputs 2. Then, i and j become 1 and 3, respectively.
*Second iteration.* The condition is true again and the program outputs 1. Then, i and j become 0 and 4, respectively.
*Third iteration.* The condition is i>=0, the condition becomes false, the loop ends, and the second cout outputs the value of j. So far, the program has displayed 2 1 4

Let's go to the next trace. Once j has been declared as unsigned, its value will never become negative (-1). The -1 will be converted to an unsigned value (e.g., in a 32-bit system it is 4294967295). Therefore, the second loop is infinite and the program displays One continuously.
