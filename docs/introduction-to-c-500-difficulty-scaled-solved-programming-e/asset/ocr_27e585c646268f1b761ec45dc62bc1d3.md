C++17 provides the ability to define a static member variable within the class by making it inline. For example:

```
class T
{
static inline int num = 5; // Since C++17.
}
```

Now, we don't have to define it outside the class; making it inline is much more convenient. Also, the fact that it is inline allows us to include header file in multiple source files without violating the definition rule.

To up, just remember, when you want a variable to be shared by all objects you should declare it as static. For example, in one of my applications, where each object represented a tab of An browser, I had declared the members that stored the machine's network addresses (e.g., MAC and IP) as static, because these addresses are common to all the objects. C.17.1 Find the errors in the following code.

```
class T
private:
int a;
public:
friend int f();
void r(const T& t) {t.a = a};
void g(int b) const {a = b};
}
```

```
int f()
{
return a;
}
```

Answer: Because the function f() is not a member of the class, it cannot access a directly. So the statement return a is not acceptable. Because the reference passed to r() is const, it is not allowed to change the members of t. So the statement t.a = a is not acceptable. Because g() is declared as const it is not allowed to change the value of a. So, the statement a = b is not acceptable.
