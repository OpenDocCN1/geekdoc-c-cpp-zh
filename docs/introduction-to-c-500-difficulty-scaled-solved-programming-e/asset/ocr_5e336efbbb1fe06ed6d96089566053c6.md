Note that in test() we could use the name instead of arr, since you know that local variables of different functions are not related even if they are named the same. When test() is called, we have arr a = &a[0]. The statements arr[0] = 0; and arr[1] = 0; change the values of the first two elements and the program displays: 0 30 40 50
Array parameter can be declared as a pointer, as well. For example, the declarations:

```
void test(int arr[]); and void test (*int arr);
```

are equivalent. The compiler treats both and passes the pointer to the function. The second declaration is more accurate, since it clearly states that a pointer is passed, not a copy of the array. The second declaration is ambiguous; the reader cannot figure out whether the function accepts a number of values or a pointer to a single variable.
Alternatively, we could pointer arithmetic to access the array elements. For example:

```
void test(int arr[]) {
*arr = 0; // Equivalent to arr[0] = 0.
arr++;
*arr = 0;
}
```

What is really interesting is the statement arr++. Can we change the value of an array? Certainly not, you know from Chapter 8 that the name of arr is used as a pointer it is a const pointer. So, why the compiler allows this statement? Because, as although arr is declared as array, it is actually a pointer. Therefore, we can give it a new value. One more example: the following code will compile, and if, what is the output?

```
#include <iostream> // Example 11.21
void test(int arr[]);
int main() {
int a[3] = {5};
ntest(a);
std::cout << a[0] << '\n';
return 0;
}
test test(int arr[]) {
int i = 20, b[10];
arr = b;
*arr = 10;
arr = &i;
*arr = 30;
std::cout << b[0] << ' ' << i << ' '';
}
```

Of course, arr is treated as an ordinary pointer. test() outputs 10 and 30. Since test() did not access a[0], the program outputs 5.
And of course, we make sure, when using an ordinary array, that all the actions are within the limits of the array. Note that, if we want, we pass the whole array instead of the pointer to its first element. We'll see such an example with reference in Chapter 16.
