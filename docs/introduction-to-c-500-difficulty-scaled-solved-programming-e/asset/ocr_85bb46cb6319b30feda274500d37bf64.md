# 8 • Pointers 197

```
{
int *p, **pp, i = 20;

p = &i;
pp = &p;
std::cout << **pp << '\n';
return 0;
}
```

Since pp points to the address of p, *pp is equal to p. Since pp points to the address of i, **pp is equal to i and the program displays 20.
The most common use of pointer to a pointer variable is when we want a function to change the value of an argument which is pointer. We'll discuss such examples in Chapter 11. In general, it is allowed to declare a pointer to another pointer variable and so on (e.g., int ***p); but, in practice, it is rarely to exceed a depth of two. Let's see an example that combines all together; array, array of pointers and pointers to pointer

```
#include <iostream> // Example 8.18
int main() {
    int a[] = {10, 20, 30}, *p[] = {a, a+1, a+2}, **pp;
    for (pp = p; pp < p+3; pp++) {
        std::cout << **pp << ' '
    }
    return 0;
}
```

Initially, pp points to p[0] which points to the address of a[0]. Therefore, **pp is equal to a[0]. When increased, pp points to p[1] which points to a[1]. As a result, the program displays 10 20 30.

# EXERCISES

C.8.21 What is the output of the following program?

```
#include <iostream>
int main() {
    int *p, **pp, i = 10, j = 20;
    p = &i;
    pp = &p;
    **pp = j;
    p = &j;
    **pp += 10;
    std::cout << j << '\n';
    return 0;
}
```

Answer: Since pp points to p and p points to i, **pp is equal to i. Therefore, the statement **pp = j; is equivalent to i = j 20. The statement p = &j, makes pointer to j, so **pp is equal to j. Therefore, the statement **pp += 10; is equivalent to j = j+10 = 20+10 = 30. As a result, the program displays 30.
