C.10.27 Write a program that reads 20 names (less than 100 characters each), stores them in an array, and an array of pointers to display them in alphabetical order.

```
#include <iostream>
#include <string>
using std::cout;
using std::cin;

int main() {
    constconst int SIZE = 20;
    char *temp, *ptr[SIZE], str[100];
    int i, j;

    for(i = 0; i < SIZE; i++) {
        cout << "Name: ";
        cin.getline(str[i], sizeof(str[i]));
        ptr[i] = str[i]; /* The elements of the array point to the input strings. */
    }
    for(i = 0; i < SIZE-1; i++) {
        for(j = i+1; j < SIZE; j++) {
            /* If the string pointed to ptr[j] is less than the string pointed to ptr[i], swap the respective pointers. */
            if(strcmp(ptr[j], ptr[i]) < 0) {
                temp = ptr[j];
                ptr[j] = ptr[i];
                ptr[i] = temp;
            }
        }
        }
        cout << ptr[i] << '\n';
    }
    return 0;
}
```

Comments: The main reason I added this exercise is to show you how useful an array of pointers might be. When two strings are swapped, it is the pointers that are swapped, not the strings. As a result, we gain performance. The sorting algorithm we used is called selection sort and will be discussed in Chapter 12. The "negative" point in this solution is the waste of space. Each row of str allocates 100 characters, even if the string contains less. For a more efficient memory management, see the next exercise.
