{
    int r;
    while (1)
    {
        r = a&b;
        if (r == 0)
            return b;
        else /* According to the algorithm, we divide b by r, so we

        {
            a = b;
            b = r;

# C.11.14 What is the output of the following program?

```
#include <iostream>
int test(int *p1, int *p2);
int main()
{
    int arr[] = {1, 2, 3, 4};
    test(arr, arr+3) = 30;
    std::cout << arr[0] << ' ' << arr[2] << ' ' << arr[3] << '\n';
    return 0;
```

```
int test(int *p1, int *p2)
{
    *(p1+1) = 10;
    *(p2-1) = 20;
    return p1+3;
}
```

Answer: When test() is called, we have p1 = arr, so the pointer p1+1 points to arr[1]. Therefore, the statement *(p1+1) = 10 makes arr[1] equal to 10. Similarly, we have p2 = arr+3, so p2 points to arr[3]. Therefore, the statement *(p2-1) = 20 makes arr[2] equal to 20. Since p1 points to arr, the expression p1+3 returns a pointer to arr[3]. Therefore, arr[3] becomes 30. As a result, the program displays 1 10 20 30
