show() displays all the values. For for_each() is called with an object as argument, the first constructor of the class is called and lambda equals to the value of the argument, and then operator() displays the value of the elements that are less than them. That is, operator() is called for each element in the specified range. Thus, we use for_each with objects of different values (e.g., 6 and 3). We also use the same function to compare strings. We do not need to create another class. Therefore, the program displays:

+   Show all: 5 3 8 12 1
Show less than 6: 5 3 1
Show less than 3: 1
Show less strings: one

This example demonstrates that using a function object instead a plain function pointer as argument, it is much more flexible and powerful since we can use the members of the object to store and use any information we need.

STL provides several predefined function objects. They can be used to provide more flexibility to STL functions that take functions as arguments. For example, sort() by default sorts the elements of the container in ascending order. If we want to change the order to descending we can use the predefined object greater<int>. For example:

