As we said, the mode is an optional argument. If not specified, as in examples C24.1 and C24.2, the default mode applies. In particular, the default value for istream open() and the constructor is ios_base::in, for ofstream open() and the constructor is ios_base::out. The default value for fstream open() and the constructor is ios_base::in; Let's look at some examples:

```
ifstream fin("test.txt"); /* The file opens for reading with the default mode
ofstream out("test.txt", ios_base::app); /* The file opens for writing and
appending new data at its end. The existing data are preserved. */
fstream f("test.txt", ios_base::out | ios_base::trunc); /* The
file opens for reading and writing. The existing data are deleted. */
```

# OPEN MULTIPLE FILES

An application may need to open many files. If the files are opened simultaneously, then we must declare separate objects for each file. The number of the files that can be open simultaneously depends on the operating system.

+   In applications where many files are opened, it is advisable to close the files you need more, because the operating system sets a limit to the number of files that can be opened simultaneously.

When we close a may use the respect object for another file, and not declare a new object. Thus, we avoid the allocation of new memory. For example, if we have to open several files sequentially, we do not to declare separate objects. We can declare a single object and use open(), as shown in the following code:

```
ifstream fin;
fin.open(filename1);
/* Use fin to read the file. */
fin.close();
fin.open(filename2);
/* Use the same object to read a new file. */
fin.close();
```

# FILE PROCESSING

When a file is opened and associated with the respect object, information related to the file is stored in the members of the object. For example, an ofstream object contains a pointer member, which indicates the position in the file to write data. Similarly, an istream object contains a pointer member, which indicates the position in the file to read data.

When a file is opened for reading or writing, the respect pointer points to the beginning of the file. If it opens for appending, it points at the end. When a read or write operation is performed, the value is updated automatically. For example, if a file is opened for reading and 50 characters are read, the value of the pointer changes and points to the location of the file that is 50 bytes from the beginning. If it is opened for writing, the pointer advances a number of places equal to the number of the written bytes. The next write operation will be done at that position.
