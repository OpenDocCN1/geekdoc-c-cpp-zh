```
// first.h
int g;

That is, an inline variable can be defined in multiple source files, provided that all definitions are identical, and, second, it must be defined in every source file in which it is used. In case of inline functions, both are given by including the inline variable in a header file and include it whenever required. # REFERENCE VARIABLES

A reference variable is an alias for an existing variable. As we know, C++ uses the & operator to get the address of a variable. C++ adds a new property to the & & operator to declare reference variables. The compiler checks to figure out how it is used. Specifically, to declare a reference variable we must define it and initialize it with an existing variable. For example:

```
int i = 10;
int& r = i;
r = 20; // Equivalent to i = 20.
i = 30; // Equivalent to r = 30.
```

In the declaration of the reference variable, r & is not used as the address operator, but for the declaration of the type. That, the type of r is int& which refers to an integer. Essentially, the value of r is an alias, a second name for i; it will always refer to the value and memory location of i. It is permanently associated with i, it is not allowed to refer to another variable. The common practice is to add the & to the type (e.g., of int& r = i), to make it clear that the two variables have the same value, but to avoid confusion with the address expression.
