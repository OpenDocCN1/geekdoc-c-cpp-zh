# Introduction to C++

The most common use is when we want to define a function that accepts arguments objects of different classes and acts on their private data. We declare the function as friend to each class, so it acts as a link between the classes. Exercise C.17.4 is such an example. Also, we'll see examples in Chapter 18 where friend functions can be used when overloading operators. Also, we'll see in Chapter 19 that a function which is a member of one class or the whole class can be a friend to another class.

One last thing to say. A function template can also be friend to an ordinary class. In this case, all instantiations of the function template become friends of the class. For example:

```
#include <iostream>
class A {
private:
    int p;
public:
    A() {p = 20};
    template <typename T> friend void f(A& a);
};

template <typename T> void f(A& a)
{
    std::cout << a.p;
    a.p += 30;
}

int main() {
    A a;
    f<int>(a);
    f<double>(a);
    return 0;
}
```

Since the f function template is declared as a friend of the A class, every instance of it is a friend of the A class. Here, we have two instances and the program outputs first 20 and then 50.
Now that we've discussed friend functions, let's summarize the rules that apply to class members that you can find in one place:

+   - The private members are accessible only by class member functions and friend functions of the class.
- The protected members are accessible only by the member functions of the class and its friend functions, as well as the member functions and the friend functions of the derived classes.
- The public members are accessible by any function inside or outside the class.

# CONSTRUCTORS AND DESTRUCTORS

A class constructor and destructor are special member functions. In particular:

+   - Whenever an object is created, the constructor of the class is invoked.
- Whenever an object is destroyed, the destructor of the class is invoked.
