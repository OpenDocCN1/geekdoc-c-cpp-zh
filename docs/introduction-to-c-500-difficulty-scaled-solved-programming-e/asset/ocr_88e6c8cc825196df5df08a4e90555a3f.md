C.9.1 Write a program that reads three characters and checks if they are consecutive in the ASCII character set.

```
#include <iostream>
using namespace std;

int main() {
    char ch1, ch2, ch3;
    cout << "Enter characters: \ ";
    cin >> noskipws >> ch1 >> ch2 >> ch3;
    if((ch1+1 == ch2) && (ch2+1 == ch3))
        cout << "Consecutive\n";
    else
        cout << "Not Consecutive\n";
    return 0;
}
```

Comments: If you run the program, don't type a space between the input characters because the space a character as well (unless the space is among the characters you want to check).
