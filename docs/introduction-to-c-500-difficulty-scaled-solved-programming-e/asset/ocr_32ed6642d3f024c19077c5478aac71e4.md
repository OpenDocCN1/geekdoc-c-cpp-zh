In addition to the dynamic definition of the vector size, it is very useful that the size of the initially allocated memory can dynamically increase by adding new elements. For example, the following program reads ten numbers and stores them in a vector that is initially empty:

```
#include <iostream> // Example 7.5
#include <vector>
using namespace std;

int main() {
{
    int i, num;
    vector<int> vec;

    for(i = 0; i < 10; i++) {
        cout << "Enter number: ";
        cin >> num;
        vec.push_back(num);
    }
    cout << vec.size() << ' << ' << vec.capacity() << '\\n';
    return 0;
}
```

push_back() adds the integer to the end of the vector. Exercise C.7.2 is a similar example.
Let's see how memory is managed. The compiler initially allocates more memory to avoid successive memory allocations each a new element is added. If the available memory runs out, the compiler allocates new memory to store new elements. Its size depends on the implementation, where a typical size is half the original. The allocation of memory may not be a simple extension to the adjacent memory, as this may be used for other purposes. In such a case, the compiler allocates new memory in another area and copies the contents of the original to the new memory. Remember that vector elements are always stored in consecutive memory locations. While the size() function returns the number of elements that are already stored. For example, the above program with the compiler I showed 10 and 16.

Besides the alt(), another function begin() returns an iterator that refers to the first element of the object, while end() returns an iterator that refers to the next position after the last element. For now, consider that iterator behaves like a pointer. For pointers, we will discuss in Chapter 8. See the following example to get an idea and you may look it after reading Chapter 8:

```
vector<int> vec(10);
vector<int>::iterator iter;

for(iter iter = vec.begin(); iter != vec.end(); ++iter) {
    *iter = 200;
```

Like any container, the vector class declares an iterator type. The iter variable is declared as iter. As shown, we use iter as a pointer and the value 200 is assigned to all elements of the vector object. The use of begin() and end() functions along with an iterator to traverse the vector is a safe practice, as it ensures that the limits of the vector will not be exceeded.

By using iterators we can delete or add elements into it. For example, the erase() function takes two iterators that specify the part to be deleted:

```
vec.erase(vec.begin(), vec.begin()+3);
```
