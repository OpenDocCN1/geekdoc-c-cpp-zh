```cpp
void bubble_sort(int arr[])
{
    bool reorder;
    int i, j, temp;
    for(i = 1; i < SIZE; i++)
    {
        reorder = 0;
        for(j = SIZE-1; j >= i; j--)
        {
            if(arr[j] < arr[j-1])
            {
                // Swap values.
                temp = arr[j];
                arr[j] = arr[j-1];
                arr[j-1] = temp;
                reorder = 1;
            }
        }
        if(reorder == 0)
            return;
    }
}
```

**Comments:** The reorder variable checks if the sorting is completed in order to avoid unnecessary iterations. If two elements are swapped, it is set to 1. Otherwise, the value 0 means that the array is sorted and the function terminates. For see how the algorithm works, suppose that the array elements are: 10, 9, 4, 7, 6.

First iteration of the outer **for**(i = 1)

| First iteration of the inner **for**(j = 4): 10 | 9 | 4 | 6 <-> 7 |
| Second iteration of the inner **for**(j = 3): 10 | 9 | 4 | 6 | 7 |
| Third iteration of the inner **for**(j = 2): 10 | 4 <-> 9 | 6 | 7 |
| Fourth iteration of the inner **for**(j = 1): 10 | 6 <-> 10 | 9 | 7 |

So, the array is transformed to: 4 10 9 6 7

| Second iteration of the outer **for**(i = 2): 4 | 10 | 9 | 6 | 7 |
| Second iteration of the inner **for**(j = 3): 4 | 10 | 6 <-> 9 | 7 |
| Third iteration of the inner **for**(j = 2): 4 | 6 <-> 10 | 9 | 7 |

# Quick Sort Algorithm

The quick sort is a divide and conquer algorithm. Its idea is to pick an element as a pivot and partition the array into two subarrays, one with elements less than the pivot and the other with elements greater than the pivot. This process is repeated recursively for the two subarrays.

There are several ways to choose a pivot:
- The first element
- The last element
- The median element
- A random element

In this example, we use the last element as the pivot.

```cpp
int partition(int arr[], int low, int high)
{
    int pivot = arr[high];
    int i = (low - 1);

    for (int j = low; j <= high - 1; j++)
    {
        if (arr[j] < pivot)
        {
            i++;
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
    int temp = arr[i + 1];
    arr[i + 1] = arr[high];
    arr[high] = temp;
    return (i + 1);
}

void quickSort(int arr[], int low, int high)
{
    if (low < high)
    {
        int pi = partition(arr, low, high);

        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

int main()
{
    int arr[] = {10, 7, 8, 9, 1, 5};
    int n = sizeof(arr) / sizeof(arr[0]);
    quickSort(arr, 0, n - 1);
    std::cout << "Sorted array: ";
    for (int i = 0; i < n; i++)
        std::cout << arr[i] << " ";
    std::cout << std::endl;
    return 0;
}
```

**Tracing the algorithm:**
QuickSort(arr, 0, 5):
Pivot = arr[5] = 5
Partition(arr, 0, 5):
- j=0: arr[0]=10 > 5
- j=1: arr[1]=7 > 5
- j=2: arr[2]=8 > 5
- j=3: arr[3]=9 > 5
- j=4: arr[4]=1 < 5. i=0, swap arr[0] and arr[4]. arr = {1, 7, 8, 9, 10, 5}
- Swap arr[i+1] and arr[high]. arr = {1, 5, 8, 9, 10, 7}. Return i+1=1.

QuickSort(arr, 0, 0): returns
QuickSort(arr, 2, 5):
Pivot = arr[5] = 7
Partition(arr, 2, 5):
- j=2: arr[2]=8 > 7
- j=3: arr[3]=9 > 7
- j=4: arr[4]=10 > 7
- Swap arr[i+1] and arr[high]. arr = {1, 5, 7, 9, 10, 8}. Return i+1=2.

QuickSort(arr, 2, 1): returns
QuickSort(arr, 3, 5):
Pivot = arr[5] = 8
Partition(arr, 3, 5):
- j=3: arr[3]=9 > 8
- j=4: arr[4]=10 > 8
- Swap arr[i+1] and arr[high]. arr = {1, 5, 7, 8, 10, 9}. Return i+1=3.

... and so on. The final sorted array is 1 5 7 8 9 10.
