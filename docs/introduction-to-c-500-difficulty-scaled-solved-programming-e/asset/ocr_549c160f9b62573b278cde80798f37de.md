As we see in Chapter 18, the string overloads arithmetic operations, and with + and - to simplify the syntax of string functions. Memory management is done dynamically, as described for the vector class in Chapter 7. It is that the compiler allocates more memory in order to avoid consecutive allocations. For example, suppose that a character is added sequentially. It would be inefficient to reserve an extra place each time. Also, if this new memory place is in use, then a new block is allocated and the old content is put in the new string. If memory runs out, then the compiler allocates a block of memory larger than the initial size to store the new content and new characters. The capacity() function returns the size of the allocated memory.

Let's remind the common ways to read characters and store them in a C-style string.

```
char s[50];ncin >> s; /* Read characters and store them into s, until a white space character is met. As we said, this approach carries the risk of a buffer overflow; */
getline(s, 50); /* Read characters and store them into s, until either the extracted character is the new line character '\n' which is discarded and not stored in s or 50 characters are stored in s including the null character. */
getline(s, 50, '?'); /* As previously, with the difference that the delimiting character is the ?, and not the '\n'. */
```

Let's see how we can read and store them in a string object.

```
string s;
cin >> s; /* First, all the white characters that may exist in the input queue are extracted. Then, characters are read and stored in s until a white character is met. For example, if the user enters multiple words only the first word is stored in s. */
getline(cin, s); /* '\n' is met. The '\n' is discarded and not stored in s. */
getline(cin, s, '?'); /* As previously, with the difference that the delimiting character is ?, and not the '\n'. Since the '\n' does not signal the end of input, we can enter as many lines as they'll all merged into s. */
```
