```
int main()\{
    T t1("abc"), t2("def"), t3("gg");
    T t4 = std::move(t1); // Move constructor.
    t3 = std::move(t2); // Move function.
    return 0;
}
```

Comments: When moving data, t4.s points to the memory that abc is stored and the t3.s points to the memory. If we do not use move() the copy constructor and the copy function will be called, respectively.
