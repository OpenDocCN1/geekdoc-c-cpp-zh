# C.5.7 Write a program that reads the grades of three students and displays them in ascending order.

```
#include <iostream>
using std::cout;
using std::cin;

int main() {
    float i, j, k;

    cout << "Enter grades: ";
    cin >> i >> j >> k;

    if(i <= j && i <= k) {
        cout << i << ' ';
        if (j < k) {
            cout << j << ' ' << k << '\n';
        } else {
            cout << k << ' ' << j << '\n';
        }
    } else if(j < i && j < k) {
        cout << j << ' ';\n        if(i < k) {
            cout << i << ' ' << k << '\n';
        } else {
            cout << k << ' ' << i << '\n';
        }
    } else {
        cout << k << ' ';\n        if(j < i) {
            cout << j << ' ' << i << '\n';
        } else {
            cout << i << ' ' << j << '\n';
        }
    }
    return 0;
}
```

**Comments:** At first, we compare each grade with the other two, in order to find and display the lowest. Next, we compare the two remaining grades and display them in ascending order.

**C.5.8** The 13-digit International Standard Book Number (ISBN) is a unique code that identifies a book commercially. The last digit is a check digit to detect errors in the previous 12 digits. The check digit is the remainder of the subtraction from 10. If it is 10, it becomes 0. For example, assume the first 12 digits are: 978960931961.
