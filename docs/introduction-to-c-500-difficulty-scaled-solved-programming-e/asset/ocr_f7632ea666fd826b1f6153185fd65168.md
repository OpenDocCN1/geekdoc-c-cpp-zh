memcmp() is used to compare the data stored in one memory region with the data stored in another. It is
memcmp in cstring;

```
int memcmp(const void *ptr1, const void *ptr2, size_t size);
```

memcmp() compares size bytes of the memory regions pointed to ptr1 and ptr2. The return value
of memcmp() is that of strcmp(). Their main difference is that strcmp() compares when
entounters the null character in either string. memcmp(), on the other hand, stops only when one
size bytes are compared; does not look for the null character. For example:

```
#include <iostream> // Example 14.8
#include <cstring>
using std::cout;

int main()
{
    char str1[] = {'a', 'b', 'c', '\0', 'd', 'e'};
    char str2[] = {'a', 'b', 'c', '\0', 'd', 'f'};

    if(strcmp(str1, str2) == 0)
        cout << "Same\n";
    else
        cout << "Different\n";

    if(memcmp(str1, sizeof(str1)) == 0)
        cout << "Same\n";
    else
        cout << "Different\n";
    return 0;
}
```

Because strcmp() stops comparing when the null character is met, the program displays Same. On
the contrary, memcmp() compares all bytes, and the program displays Different.
