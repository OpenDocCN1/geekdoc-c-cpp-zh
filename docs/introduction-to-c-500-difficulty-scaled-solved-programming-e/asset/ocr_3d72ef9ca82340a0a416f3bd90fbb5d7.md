```
void end_prg()
{
    std::cout << "Unhandled exception. Program terminates\n";
    abort();
}
```

Since the exception is not caught, the program calls terminate(), which calls the end_prg(). The end_prg() displays the message and the abort() terminates the program.
Recall that we can capture exceptions of unknown types by using the catch(...) block. In case we prevent the program from terminating; however we still have to handle the exception.
