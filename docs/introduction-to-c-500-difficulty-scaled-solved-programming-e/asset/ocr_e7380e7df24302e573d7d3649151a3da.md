If the last statement were allowed we could use r2 to change the value referred by r1, that is,
value of a. A reference to const can refer to a non-const variable or constant expression. It is not
allowed to change the value of the non-const variable through the reference. For example:

```
int a = 10;
const int r1 = a; // Correct.
const int r2 = 20; // Correct.
const int& r3 = &a; // Correct.
a = 30; // Correct, the variable is not const.
r1 = 30; // Wrong, it is not allowed through the reference.
```

# References as Function Parameters

As we've learned, when we want a function to change the value of an argument we pass a pointer to thencorresponding variable. An alternative is to pass a reference to it. For example:

```
#include <iostream> // Example 16.5

void test(int& a, int& b);

int main()
{
    int i = 10, j = 50;

    test(i, j);
    std::cout << i << ' ' << j << '\n';
    return 0;
}

void test(int& a, int& b)
{
    a = 100;
    b = 200;
}
```

When a reference to a variable is passed to a function, it is the memory address of the variable that
is actually passed. The function can access the value of the calling function. For example, when
test() is called, the variable is passed by reference. In this method, of passing data is named
call by reference. The & operator is only added to the function, not called. When
test(), a refers to i, that is, a is used as if. In other words, a is an alias
of, not a copy of i. On the contrary, we acknowledge, the variable j is passed by value, that is, b is
copy of j. So, the value of j does not change and the program displays: 100 50

If we do not want the function to be able to change the original value we make the reference const.
For example, we write:

```
void test(const int& a, int& b);
```
