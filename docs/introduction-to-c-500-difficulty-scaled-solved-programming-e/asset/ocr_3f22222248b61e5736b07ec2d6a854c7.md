With virtual functions, the compiler checks the dynamic type of the pointer or reference and decides which function to call.

> When designing a base class, it is a common practice to declare as virtual the functions that may be overridden in derived classes, so that those functions are called based on the type of the object that the pointer or the reference refers to.

Let's see another example:

```
class A
{
    virtual void f();
}
class B : public A
{
    virtual void f();
}
```

B b;
A* p = &b;
p->f(); // Which f() will be called?

Since p points to the address of b, the f(b) of the B class will be called. Note that if f(f) was not declared as virtual, the f(f) of the A class would be called.

A class declared as virtual automatically becomes virtual in all classes declared directly or indirectly from it. That is, word virtual in the declaration of show() in the Book class is not needed. Although unnecessary, I prefer to add it in order to make it again clear to someone who reads the code. If the function is defined outside the class virtual is not added. It is only added in the declaration of the function. Note that when you override a virtual it is useful for the program consistency and readability, the new function to maintain the semantics of the overridden function. That is, a new draw() should provide "draw" services and not used for other purposes.

Any non-function, except the constructor, can be declared as virtual. Constructors, static functions, and function templates cannot be virtual. A friend function must be defined in the class in which it is declared for the first time, as we see in Chapter 21, it is declared as pure virtual function. That is not necessary to be redefined in a derived class that does not need its own version. If not defined, the version of the base class is used. If the derived class belongs to a long chain of derivations, the most recently defined version is used.

# Dynamic Polymorphism

That is, with virtual functions, polymorphism is achieved dynamically at runtime and not at compile.
