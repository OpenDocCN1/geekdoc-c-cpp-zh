```
if (exp1)

For example, the following code displays two values in increasing:

```
(i < j) ? (cout << i << ' ' << j) : (cout << j << ' ' << i);
```

The value of a conditional expression can be stored to a variable. For example, the following code reads a student's grade and if it is within [5, 10] Otherwise, it is set to 0.

```
float i; grd;
cin >> grd;
i = (grd >= 5 && grd <= 10) ? grd : 0;
```

Typically, the conditional operator is used in place of an if-else statement, when it has a simpler form. For example, the next if-else statement:

```
if (a < b)
  min = a;
else
  min = b;
```

can be replaced with: min = (a < b) ? a : b; The parentheses are not necessary, because the precedence of ? is very low. However, it is advisable to use them to make clearer the tested condition.

Conditional expressions can be merged by replacing the expression that follows the colon: with another conditional expression. In this example, exp3 is replaced with the add1 ? add2 : add3:

```
k = exp1 ? exp2 : add1 ? add2 : add3;
```

If exp1 is true, k will be equal to the value of exp2. If exp1 is false, the value of add1 is evaluated. If add1 is true, k will be equal to the value of add2. Otherwise, it will be equal to the value of add3. The equivalent chain of if-else statements is:

```
if (exp1)
  k = exp2;
else if (add1)
  k = add2;
else
  k = add3;
```

For example, the following code outputs 2.

```
int a = 10;
(a > 100) ? (cout << "1\n") : (a == 10) ? (cout << "2\n") : (cout << "3\n");
```

Note that because the ? operator has a low priority, when the conditional expression is used in a larger expression it is very likely that you should enclose it in parentheses, as unexpected results may occur:

```
int a = 10;
cout << (a > 20) ? "Yes\n" : "No\n";
```

Although we would expect this count to display No, it displays 0. Let's see why. The first, the count << (a > 20) is executed, displays 0. The << operator returns the count (we'll see how in Chapter 18), so the initial expression becomes equivalent to count ? "Yes\n" : "No\n"; This expression does not print anything. It checks the value of count, and because the expression yields Yes. To display the correct result we must use parentheses:

```
cout << ((a > 20) ? "Yes\n" : "No\n");
```

# EXERISES

C.5.11 What is the output of the following program?

```cpp
#include <iostream>
int main()
{
    int a = 1, b = !a;
    if((b ? a : -a) <= 10)
        std::cout << "One " << -a << '\n';
    else
        std::cout << "Two " << -a << '\n';
    return 0;
}
```

Answer: Since b is 0, the result of the conditional expression is -a, that is, -1. The value of a does not change, it remains 1. Therefore, if the condition is true, the program outputs: One -1

C.5.12 Write a program that reads the price of three products and uses the ?: operator to display the highest price.

```cpp
#include <iostream>
int main()
{
    float i, j, k;
    std::cout << "Enter prices: ";

    std::cout << "Max: " << ((i >= j && i >= k) ? i : (j > i && j > k) ? j : k) << '\n';
    return 0;
}
```

Comments: To display the lowest price we change the ? to <.

    return 0;
}
```

# THE SWITCH STATEMENT

The switch statement can be used as an alternative to an if-else-if series, when we want to test the value of an expression against a series of values and handle each case differently. In the most common case, or at least the one I prefer, the syntax of the switch statement is:

```cpp
switch(expression) {
    case constant_l:
        /* block of statements that will be executed if the value of the expression is equal to constant_l. */
        break;
        ...
    case constant_n:
        /* block of statements that will be executed if the value of the expression is equal to constant_n. */
        break;
    default:
        /* block of statements that will be executed if the expression is other than the previous constants. */
        break;
}
```

As a matter of style, there are several ways to write the switch statement. The most popular is to align the case with the switch. My preference is to align the case under the switch, or leave some space. The parentheses are not necessary, because the precedence of ? is very low. ```cpp
k = exp1 ? exp2 : add1 ? add2 : add3;

The << operator returns the count (we'll see how in Chapter 18), so the initial expression becomes equivalent to count ? "Yes\n" : "No\n"; This expression does not print anything. It checks the value of count, and because the expression yields Yes. To display the correct result we must use parentheses:

```cpp
cout << ((a > 20) ? "Yes\n" : "No\n");
```
