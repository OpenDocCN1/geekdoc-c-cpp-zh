- Add the digits in the odd positions and multiply the result by 3.
- Add the digits in the even positions to the previous result.
- Divide the result by 12. Subtract the remainder from 10, and that is the check digit. If the subtraction is 10 (meaning that the remainder is 0), use 0 as check digit.

For example, let the barcode 123456789015. The check digit is calculated as follows:

- a. 1+3+5+7+9+1 = 26. Multiplied by 3 26*3 = 78.
- b. 2+4+6+8+0 = 20. Added to the previous result 78+20 = 98.

Since the last digit is 5 and the calculated check digit is 2, the barcode is not correct.

# C.10.22 The data compression algorithm Run Length Encoding (RLE) is based on the assumption that a symbol within data stream may be repeated many times in a row. This repetitive sequence can be replaced by an integer that declares the number of repetitions and the symbol itself. Write a program that reads a string of less than 100 characters and uses RLE algorithm to compress it. If digits and characters appear once, for example, the string: aaa12bb should be compressed to: 3a122b

```cpp
#include <iostream>
#include <cstring>
using std::cout;
using std::cin;

int main()
{
    char str[100];
    int i, len, cnt;

    cout << "Original text: ";
    cin.getline(str, sizeof(str));
    len = strlen(str);

    cout << "Compressed text: ";
    i = 0;
    while(i < len)
    {
        cnt = 1;
        while(i + cnt < len && str[i+cnt] == str[i]) /* Check if the current character, that is str[i], is repeated in the next places. */
        {
            cnt++;
        }
        if(cnt == 1)
            cout << str[i];
        else
            cout << cnt << str[i];

        i += cnt;
    }
    cout << "\n"; // Added newline based on logic flow
    return 0;
}
```

# C.10.23 Write a program that reads a string and stores it in a string object. Then, the program should display the words it consists of and their number. Suppose that a word is a sequence of characters that does not contain space characters. For example, if the user enters how many words (notice that more than one space may be included between the words), the program should display: how many words The text contains 4 words

```cpp
#include <iostream>
#include <string>
using std::cout;
using std::cin;
using std::string;

int main()
{
    int i, words;
    string str;

    i = words = 0;
    cout << "Enter text: ";
    getline(cin, str);

    if(str[0] != ' ' && str[0] != '\t' && str[0] != '\0') /* If the first character is other than the space character, it means that a word begins, the value of words is incremented. */
    words++;

    while(str[i] != '\0')
    {
        if(str[i] == ' ' || str[i] == '\t')
        {
            /* Since more than one space character may be included between words, we check the next character, that is str[i+1], is also a space character. If it isn't, it means a new word begins, so the value of words is increased. */
            if(str[i+1] != ' ' && str[i+1] != '\t' && str[i+1] != '\0')
            {
                words++;
                cout << '\n';
            }
        }
        else
            cout << str[i];
        i++;
    }
    cout << "\nThe text contains " << words << "\n";
    return 0;
}
```

# C.10.24 What is the output of the following program?

```cpp
#include <iostream>
int main()
{
    const char *arr[] = {"TEXT", "SHOW", "OPTIM", "DAY"};
    const char **ptr1;

    ptr1 = arr;
    std::cout << ***ptr1 << ' ';
    std::cout << **ptr1+2;
    std::cout << (char)(**ptr1+1) << '\n';
    return 0;
}
```

Answer: The array is declared as an array of pointers to strings. In particular, arr[0] points to "TEXT", arr[1] points to "SHOW", and so. The statement ptr = arr; makes ptr0 to point to the address of arr[0].

The expression ++ptr1 makes ptr1 to point to arr[1]. Since **ptr1 is equivalent to arr[1], the cout statement is translated to cout << ptr1[2]; and the program skips the first two characters of "OPTIM" and displays TIM.

Like before, the expression ++ptr1 makes ptr1 to point to arr[3]. However, **ptr1 is equivalent to *arr[3]. What is the value of *arr[3]? Since arr[3] points to the first character of "DAY", *arr[3] is equal to 'D'. Therefore, the value of *arr[3]+1 is 'E' and the program displays.

As a result, the program displays SHOW TIME
