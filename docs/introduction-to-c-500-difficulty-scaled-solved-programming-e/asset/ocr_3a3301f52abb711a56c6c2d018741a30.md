C++11 restrictions and allows us to write compile-time functions using familiar language constructs. It just poses some few restrictions (e.g., when defining a variable to be initialized). Let's see an example of a `constexpr` function:

```
constexpr int f(int a) /* Not compiled with C++11, but compiled since C++14. */
{
    int i = 10;
    while (a > i)
    {
        a--;
        i++;
    }
    return (a < 50) ? i : 20;
}
```

When using the return value of a `constexpr` function for initialization the performance of the program is improved, since that value is computed at compile time and not at runtime. For example:

```
int k = 5;
constexpr int i = f(3); /* Since the argument is a constant expression, the value of i will be computed at compile time. */
int i = f(k); /* Since the argument (e.g., k) is not a constant expression, the value of i will be computed at runtime. */
constexpr int i = f(k); /* Compilation error. Because k is not constant, the value of i will not be computed at compile time. If it was constant there would be no problem. */
```

As you see, it is called with a constant argument the `constexpr` function produces a compile time. When called with a non-constant argument, it produces a value at runtime like an ordinary function.

A `constexpr` function can accept arguments and return a reference or a pointer. For example:

```
constexpr const int& f(const int& a)
{
    return &a; // Return a pointer.
}
static const int k = 5; /* The memory address of a variable with permanent lifetime, as a static or a global variable, is fixed. */
constexpr const int *p = f(k); /* Since the argument is a constant expression, the value of p will be computed at compile time. */
int i = *p; // i becomes 5.
```

# FUNCTION OVERLOADING

Unlike C, C++ allows different functions to have the same name. This feature is called function overloading or polymorphism in the sense that a function may have many forms. Function overloading is one of the essential parts of generic programming. An example of the overloading concept is the use of the + operator can be used to add integers or float numbers or both types. This idea was extended to functions.
