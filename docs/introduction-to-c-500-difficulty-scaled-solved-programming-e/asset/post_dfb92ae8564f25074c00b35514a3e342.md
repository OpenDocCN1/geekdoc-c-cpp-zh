**C.9.6 Every mobile phone in GSM (2G) and WCDMA (3G) wireless networks is characterized by a unique identifier of 15 digits, called International Mobile Equipment Identifier (IMEI).* A method to check if the device is really made by the official manufacturer is to compare the IMEI's last digit, called Luhn digit, with a check digit. If it is equal, the device is most authentic. Otherwise, it is not authentic. The check digit is calculated as follows: first, we calculate the sum of the first IMEI's 14 digits by adding:

- a. The digits in the odd positions.
- b. The double of the digits in the even positions. But, if a digit's doubling is a two-digit number, we add each digit separately. For example, suppose the value of the checked digit is 8. Its double is 16; therefore, we add it to the sum of 1+7, not 16.

If the last digit of calculated sum is 0, the check digit is 0. If not, we subtract the last digit from 10 and that is the check digit. For example, check the IMEI 357683036257378. The algorithm applied in the first 14 digits produces:

```
3 + (2*5) + 7 + (2*6) + 8 + (2*3) + 0 + (2*3) + 6 + (2*2) + 5 + (2*7) + 3+(2*7) =
3 + (1*0) + 7 + (1*2) + 8 + (6) + 0 + (6) + 6 + (4) + 5 + (1*4) + 3 + (1+4) =
3 + (1+0) + 7 + (1+2) + 8 + (6) + 0 + (6) + 6 + (4) + 5 + (1+4) + 3 + (1+4) = 62
```

The check digit is 10-2, which is equal to the Luhn digit. Therefore, this IMEI is valid. Write a program that reads the IMEI of a mobile phone (15 digits) and displays a message to indicate it is authentic or not.
