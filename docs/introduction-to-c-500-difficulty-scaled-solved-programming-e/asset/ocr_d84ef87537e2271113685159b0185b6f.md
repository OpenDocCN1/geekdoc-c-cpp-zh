Explicit instantiations may improve the compilation and the linking time of the program, since no instantiations are repeated for the same type(s). Also, in large applications where the use of the same function template in multiple sources files may be required, we can avoid the delay caused by instantiating it explicitly and making it extern. For example, if abs<int> is defined in one file and we want to use it in such file we write:

```
extern template int abs<int>(int a); // Second file.
```

With the extern declaration the compiler will not redefine the abs<int> version in this file. As with ordinary declarations of extern variables, the definition of abs<int> will be searched in another file. In the same sense, there can be many extern declarations for a given function, but only one definition for instantiation.

# Overloading Function Templates

As we said, we write a function template when we want to apply the same code to a variety of types. However, it may be a case that we want to write a function that performs a similar operation, not the same. In such a case we can overload the function, just as we've learned to do with ordinary functions. For example, we want to write a function template that returns the absolute value of the sum of its arguments and one that displays the absolute value of the sum of its arguments:

```
#include <iostream> // Example 16.15
```

```
template <typename T> T abs(T a);
template <typename T> void abs(T a, T b, int c = 3);
```

```
int main()
{
    int a = 6, b = 3;
    double c = 1.2;

    abs(a, b, -10);
    std::cout << ' ' << abs(c) << '\n';
    return 0;
}
```

```
template <typename T> T abs(T a)
{
    return a < 0 ? -a : a;
}
```

```
template <typename T> void abs(T a, T b, int c)
{
    T sum;

    sum = a+b+c;
    if(sum < 0)
        std::cout << -sum;
    else
        std::cout << sum;
}
```
