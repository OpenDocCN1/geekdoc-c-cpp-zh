To create a unique_ptr object we use the usual template syntax. As we say, smart pointers are templates. When we put <> the type that smart pointers point to. When we create a smart pointer we can initialize it with the pointer that the new operator returns. If b is 0, f() creates an exception. The unique_ptr overloads the * and -> operators, so that we can use it as an ordinary pointer. Notice that there is no need to delete memory. The allocated memory is released when the pointer is destroyed. This happens when p goes out of scope, in the function is returned, either due to an exception or not. Then, p is destroyed and its memory will be released if there is a forced exit from the block. Then, p is destroyed and its destructor will release the memory. Then C is called and the program ends in both cases, whether the exception is thrown or not.
C++14 introduces the std::make_unique<>() function template to create a unique_ptr object. In this, it is recommended to use the new operator. The arguments of the make_unique<T>(...) are the same as the ones used in the new T(...) form. To make the syntax simpler we can use the auto identifier. For example:
