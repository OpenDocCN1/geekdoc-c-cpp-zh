On the other hand, when the function returns a pointer and we intend to dereference it should check that it is not a null pointer, otherwise the program crash. This cannot happen with references, because a reference always refers to a variable; there is no null reference. Of course, I may prefer pointers I started programming with C and C does not support references. C uses pointers to access the original data. Had I started with C++, I might have preferred references, thus their use is simpler.

In the question when to use a pointer or a reference, what I usually do is use pointers when passing basic types (e.g., int), unions, and because C++ often requires references in class design, I use references when classes are passed to the function. Of course, this is just my preference, and there might be reasons to make different choices. Regardless of your choice, what is certain that you should know both ways, because both are quite popular.

And as you know from Chapter 13, when large entities are passed to the function, such as structures and classes, we choose to pass a reference or pointer even if the copy is not going to modify them. The reason is to save time and memory required to make a copy of the original entity. Thus, the performance of the program is improved. For simple variables, such as basic types, the typical choice is the call by value, as long as we do not intend to modify the original values.

Another example, let's pass a reference to pointer in order to change the value of the parameter. What is

```
#include <iostream> // Example 16.6

void test(int& r);

int main() {
    int int i = 10, *p = &i;

    test(p);
    std::cout << *p << '\\n';
    return 0;
}

void test(int& b) {
    static int b = 20;
    *r = &b;
}
```

The parameter r is declared as a reference to type int. In test(), r is equal to p, so p = &b. Since the value of p changes, the program displays 20. Alternatively, as we know from Chapter 11, to change the value of a pointer we could pass a pointer to pointer variable. In fact, this is my preference. For example:

```
void test(int **) {
    static int b = 20;
    *r = &b;
}
```

and write: test(&p); I think this syntax is simpler and also makes it clearer and easier for the reader to understand that the value of the passed pointer may change. Of course, as I mentioned, I may consider that I started programming with C. I guess that someone starting with C++ might prefer to use the reference syntax.
