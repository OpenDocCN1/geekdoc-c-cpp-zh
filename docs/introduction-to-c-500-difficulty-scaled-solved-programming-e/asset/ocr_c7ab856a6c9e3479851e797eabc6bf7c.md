Another example of using a reference to an array is in function templates. The size of the passed array may vary.

```
template <typename T, int size> void f(T (&r) [size]);
...
int a1[5];
float a2[10];
f(a1);
f(a2);
```

As we will see later, f() is a function template. When the first call of f() is made, T is replaced by int and size by 5, while in the second call, T is replaced by float and size by 10. And if you want to declare variables in an array here are two examples with one-dimensional and two-dimensional arrays.

```
int a[3];
int (&r) [3] = a; // r refers to an array of three integers.
r[0] = 5; // a[0] becomes 5.

int a[4];
int (&r) [4] = a[1]; /* r refers to an array of four integers, which is the second row of a. */
r[0] = 5; // a[1][0] becomes 5.
```

# rvalue References

C++11 introduces a new type of reference, the rvalue reference. An rvalue reference refers to a temporary object, which will not be used again after its use. Thus, an rvalue reference can refer the result of an rvalue expression, even though this value is generally temporary. Once an rvalue reference is bound to the result, the lifetime of the object is used to extend the result as long as the rvalue reference is in scope. Then declare an rvalue reference use two & following the type name. For example:

```
int a = 10, b = 10;
int&& r = a+b;
std::cout << r; // The code outputs 20.
```

The r is an alias for the result of the rvalue expression a+b. Note that this example has no real value; it is just to see the syntax of the rvalue reference.

The main purpose of an rvalue reference is because the object is temporary, to convert a copy operation into a move operation. For example, when copying elements that contain lot of data (e.g., vector) it would be more efficient, if the source is not used again, instead of copying the data, which is not only necessary but also costly, to move. But how do we tell the compiler to move data? Using an rvalue reference. For example, consider the following program:

```
#include <iostream> // Example 16.8
#include <string>
using std::cout;
using std::string;
```
