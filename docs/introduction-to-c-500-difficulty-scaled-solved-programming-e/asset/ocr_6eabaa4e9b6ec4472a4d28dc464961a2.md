As in the case of if, a common error is to add the ; at the end of else. For example:

```
int i = 20, j = 10, max;
if (i > j)
    max = i;
else    // Be careful, don't add ;
    max = j;
cout << max;
```

Initially, max becomes 20, but then, ; terminates the execution of else, it becomes 10.
The code displays 10.
Note that we can declare a variable within the code. For example:

```
if(int a = f()) /* Declaration of a. f() is assumed to return an integer
value. If a is not zero, the condition is true. */
{
...}
```

The scope of a extends to a end of the if statement. Then, as we will see in Chapter 11, a ceases to
ext. If there is an else branch, its scope extends to all. The common practice is to declare a before
t if statement. However, some programmers prefer to make the declaration inside the condition, so that
t code is more compact and the scope of the variable is limited to the block that it is.
C++17 provides a new version which allows us to utilize the variable inside if and then test for a condi-
tion.

```

```
