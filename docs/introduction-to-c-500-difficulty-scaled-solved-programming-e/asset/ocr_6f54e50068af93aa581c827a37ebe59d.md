# The strcpy() and strncmp() Functions

The strcmp() function is declared in cstring

```
int strcmp(const char *str1, const char *str2);
```

strcmp() compares the string pointed to by str with the string pointed to by str2. If the strings are identical, strcmp() returns 0. If the first string is less than the second, strcmp() returns a negative value, if it is greater it returns a positive value. A string is considered less than either one of the following conditions is true:

+   - first n characters of the strings match, but the value of the n+1 character in the first string is less than the value of the n+1 character in the second string.
- All characters, but the first string is shorter than the second.

Let's see some examples. The statement strcmp("One", "one") returns a negative value because the ASCII code of the first non-matching character 'E' is less than the ASCII code of 'e'. The statement strcmp("one", "many") returns a positive value the ASCII code of the first non-matching character 'w' is greater than 'm'. The statement strcmp("some", "something") returns a negative value because the first four characters, but the first string is smaller than the second.
