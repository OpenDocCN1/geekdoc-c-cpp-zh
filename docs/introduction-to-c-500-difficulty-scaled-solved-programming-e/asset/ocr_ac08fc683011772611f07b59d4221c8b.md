```
T::T()
{
    s = nullptr; /* Initialize the pointer so that there is no problem
when the memory is released. For example, no memory is reserved for t2. */
}
```

```
T::T(char str[])
{
    s = new char[strlen(str)+1];
    strcpy(s, str);
}
```

```
T::~T()
{
    delete[] s;
}
```

```
void T::show() const
{
    for(char *p = s+strlen(s)-1; p >= s; p--)
        cout << *p;
}
```

**Answer:** Let's explain how we decided to add these functions. Since in main() the objects are created in two ways, we define two constructors. Since s is a pointer, the constructor must allocate memory to the string. Therefore, a destructor must be defined to release the memory.
