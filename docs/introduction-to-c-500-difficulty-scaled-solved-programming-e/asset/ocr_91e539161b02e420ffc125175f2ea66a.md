```
int linear_search(const double arr[], int size, double num, int *t)
{
    int i, pos;
    pos = -1;
    *t = 0;
    for(i = 0; i < size; i++)
    {
        if(arr[i] == num)
        {
            (*t)++;
            if(pos == -1) /* Store the position of the occurrence. */
            pos = i;
        }
    }
    return pos;
```

Comments: Since a function cannot take as parameter an integer array, we use a pointer to return the second value.
