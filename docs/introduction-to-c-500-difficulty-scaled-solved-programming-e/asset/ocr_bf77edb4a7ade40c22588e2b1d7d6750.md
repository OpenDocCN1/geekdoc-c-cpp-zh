other 6 integers and store them in a 3x2 array (e.g., b). The program should display the elements
of a 2x3 array (e.g., c), which is the result of c=axb.

It is reminded from the linear algebra that the product of two matrices is produced by adding the
products of the elements of each row of the first matrix with the corresponding elements of each column
of the second matrix. Therefore, the outcome of an NxM matrix multiplied with an MxN matrix is an NxN
matrix. For example, consider the following (2x3) and b (3x2) matrices:

```
a = \begin{bmatrix} 1 & -1 & 1 \ 0 & 2 & 1 \end{bmatrix} b = \begin{bmatrix} 1 & 0 \ 2 & -2 \ 2 & 3 \end{bmatrix}
```

The dimension of c=axb is 2x3, and its elements are:

```
c = \begin{bmatrix} 1*1+(-1)*2+1*2 & 1*0+(-1)*(-2)+1*3 \ 0*1+2*2+1*2 & 0*0+2*(-2)+1*3 \end{bmatrix} = \begin{bmatrix} 1 & 5 \ 6 & -1 \end{bmatrix}
```

In math, the value of its element is the outcome of $c_{ij} = \sum_{k=1}^M a_{ik}b_{kj}$. In programming, $k$ ranges
from 0 to M-1.
