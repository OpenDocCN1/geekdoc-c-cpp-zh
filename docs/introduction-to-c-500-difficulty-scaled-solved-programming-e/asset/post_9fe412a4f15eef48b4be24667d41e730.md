#include <iostream> // Example 25.10

```cpp
unique_ptr<double> f() {
    auto p2 = make_unique<double>();
    *p2 = 1.2;
    return p2; /* We could avoid the declaration of p2 and write directly;
    return make_unique<double>(1.2); */
}
```

When f() returns, p1 takes ownership of the memory that p2 originally owned. And it is logical for the compiler to allow this action, because it knows that p2, it is a local variable, will be destroyed, there are no two objects pointing to the same memory. The memory will be released when p1 is destroyed. The program displays 1.2.

With the use of unique_ptr we don't need to worry about the release of the memory, since the memory will be released by the object that it is destroyed.

As said, we cannot copy a unique_ptr to another. However, if we want to transfer the ownership to unique_ptr object and use the object again to another location, we can do by using the move() function. For example:

```cpp
int main() {
    unique_ptr<double> p1, p2;
    auto p3 = make_unique<double>();

    *p3 = 3.4;
    p1 = move(p3); /* We use move() to transfer the ownership from p1 to p2.
    As said, if we write p2 = p1; we'll have a compilation error. */
    p2 = move(p1); // We transfer the ownership of p3 to p1.
    cout << *p3 << '\n'; // Wrong action
    cout << *p2 << '\n';
    return 0;
}
```

The program displays 3 and 1. Notice that when the ownership is transferred it is the responsibility of the programmer not to use the pointer (e.g., p3) to access the memory, otherwise a problem will occur in the execution. Let's see another example of unique_ptr to manage memory allocated for many elements. We'll compare it with an ordinary pointer:

```cpp
class T {
private:
  int *p;
public:
  T(int num) {p = new int[num];}
  ~T() {delete[] p;}
};
int main() {
  T t(100);
}
```

When using an ordinary pointer (e.g., p) we should not forget to release the memory, otherwise we'll have a memory leak. Also, if we use unique_ptr instead, we don't need to worry about such issues. Specifically, we change the class to:

```cpp
class T {
private:
  unique_ptr<int> p;
public:
  T(int num) : p(new int[num]) {} // Older syntax.
  T(int num) : p(make_unique<int>(num)) {} // C++14 syntax.
};
```

In the declaration of unique_ptr we put the data type with a pair of empty. As with ordinary pointer, to manage elements we can use the index notation (e.g., p[0]=10). When t is destroyed the p object will be destroyed. delete[] will be called to release the memory. We don't have to do it; the smart pointer will do it for us. It simplifies things and prevents memory leaks. Of course, never forget the use of vector as an alternative. ### The shared_ptr Type

Similar to unique_ptr, to create a shared_ptr object we put inside the type that the pointer points to. For example:

```cpp
shared_ptr<int> p1;
shared_ptr<vector<int>> p2; // p2 can point to a vector of integers.
shared_ptr<string> p3(new string("test"));
cout << *p3; // This code outputs test.
```

The shared_ptr type is used when we want to manage the ownership of memory among shared_ptr objects. That is, shared_ptr objects manage the same memory. In fact, it implies its role. For example:

```cpp
#include <iostream> // Example 25.11
#include <memory>
using std::shared_ptr;
using std::cout;

int main() {
    shared_ptr<int> p1(new int);
    shared_ptr<int> p2;
    shared_ptr<int> p3(new int[10]);

    *p1 = 10;
    p2 = p1;
    *p2 = 20;
    p3[0] = 100; // Indexing is supported since C++17.
    cout << *p1 << '\n';
    return 0;
}
```

With the statement p2 = p1, the p1 and p2 objects manage the same memory. Therefore, the program outputs 20. How the shared_ptr works? It has a reference counter which is increased by each time a shared_ptr object points to the same memory. For example, the counter increases when a shared_ptr object is used to initialize a new one (e.g., shared_ptr<int> p4(p1)); or when used in an assignment (e.g., p4 = p1). It also increases when passed to a function by value. For example:

```cpp
void f() {
    shared_ptr<int> p(new int);
    g(p);
}
```

```cpp
void g(shared_ptr<int> sp) {
    ...
}
```

Because the parameter is passed by value the counter becomes 2. When g() terminates, the local variable sp is destroyed and the counter becomes 1.

When a new value is assigned to the shared_ptr pointer or the shared_ptr is destroyed (e.g., out of scope), the counter decreases by one. When it becomes zero, that is, when the last shared_ptr object is destroyed, the memory it points to is released. For example:

```cpp
shared_ptr<string> p(new string);
shared_ptr<string> q(new string);
p = q; // Now that p points to the same memory
```

Note that if we write something with ordinary pointers, the original memory won't be released. For example:

```cpp
string *p = new string;
string *q = new string;
```

If we want to allocate and initialize memory in one step we can use make_shared<T>(). In fact, it is recommended for efficiency that the memory returns a shared_ptr, which points to the memory allocated. For example:

```cpp
shared_ptr<int> p1 = make_shared<int>(10);
shared_ptr<int> p2 = make_shared<int>(20);
shared_ptr<vector<int>> p3 = make_shared<vector<int>>(10);

p3[0] = 100; // Indexing is supported since C++17.
cout << *p1 << '\n';
return 0;
```

With the statement p2 = p1, the p1 and p2 objects manage the same memory. Therefore, the program outputs 20.

### The weak_ptr Type

The weak_ptr is a smart pointer that can refer to a memory managed by a shared_ptr object. The association of a weak_ptr to a shared_ptr does not increase the reference counter. That is, when the last shared_ptr object is destroyed, the memory it points to is released, no matter how associated weak_ptr objects exist. In fact, it implies its role. When this pointer could be used with weak_ptr we can first check if the memory is valid if it can still be managed, and then access it. Let's see an example:

```cpp
#include <iostream> // Example 25.13
#include <memory>
using namespace std;

int main() {
    shared_ptr<int> p1 = make_shared<int>(10);
    weak_ptr<int> w1 = p1;
    if (w1.lock()) {
        cout << *w1.lock() << '\n';
    }
    p1.reset();
    if (w1.lock()) {
        cout << *w1.lock() << '\n';
    } else {
        cout << "memory is released" << '\n';
    }
    return 0;
}
```
