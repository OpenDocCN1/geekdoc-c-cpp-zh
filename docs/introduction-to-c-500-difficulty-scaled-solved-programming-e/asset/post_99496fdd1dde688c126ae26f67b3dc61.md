# TWO-DIMENSIONAL ARRAYS AND C-STYLE STRINGS

Two-dimensional arrays are often used to store multiple C-style strings. For example, the statement:

```cpp
char str[10] [40];
```

declares the str[10] with ten rows. Each row can store a string of up to 40 characters. In case of shorter strings, there is a waste of memory.

We can store string literals in a two-dimensional array when it is declared. For example:

```cpp
char str[3] [40] = "One", "Two", "Three";
```

the characters of "One" are stored in the first row of str, "Two" in the second row, and those of "Three" in the third row are not large enough to fill the null, characters are padded, as depicted here:

| str[0][0]str[0][2] | str[0][3] | ... | str[0][39] |
|---|---|---|---|
| O n | e | \0 \0 | ... | \0 \0 |
| str[1][0]str[1][1] | str[1][3] | ... | str[1][39] |
| T w | o | \0 \0 \0 | ... | \0 \0 |
| str[2][0]str[2][2] | str[2][3]str[2][5] | ... | str[2][39] |
| T h | r | e | \0 \0 | ... | \0 \0 |

Recall from Chapter 8 and the section "Pointers and Two-Dimensional Arrays" that we can treat each of elements str[0], str[1], ..., str[N-1] of a two-dimensional array str[N][M] as a pointer to

M elements. For example, str[0] can be used as a pointer to an array of 40 characters, which holds the string "One".

Also remember from the section "Array of Pointers" that in order to save memory we could use an array of pointers instead of two-dimensional array. For example:

```cpp
const char *str[] = {"One", "Two", "Three"};
```

Although some memory is allocated for str, the first thing is that the memory allocated for the strings is exactly as needed. Thanks to the close relationship between pointers and arrays, we can subscript str as two-dimensional array to access a character. For example:

```cpp
for(i = 0; i < 3; i++)
  if(str[i][0] == 'T')
    cout << str[i] << '\n';
```

The loop displays the strings from T. C10.27 is another example, where the use of an array of pointers proves more efficient. Also do not forget that for more flexible and safer management of strings we can use the vector class. C10.28 is such an example. As I have mentioned, my intention is to show you all these approaches because they are popular.

C10.27 Write a program that reads 20 names (less than 100 characters each), stores them in an array, and an array of pointers to display them in alphabetical order.

```cpp
#include <iostream>
#include <string>
#include <cstring>
using std::cout;
using std::cin;

int main() {
    const int SIZE = 20;
    char *temp, *ptr[SIZE], str[100];
    int i, j;

    for(i = 0; i < SIZE; i++) {
        cout << "Name: ";
        cin.getline(str[i], sizeof(str[i]));
        ptr[i] = str[i]; /* The elements of the array point to the input strings. */
    }
    for(i = 0; i < SIZE-1; i++) {
        for(j = i+1; j < SIZE; j++) {
            /* If the string pointed to ptr[j] is less than the string pointed to ptr[i], swap the respective pointers. */
            if(strcmp(ptr[j], ptr[i]) < 0) {
                temp = ptr[j];
                ptr[j] = ptr[i];
                ptr[i] = temp;
            }
        }
        cout << ptr[i] << '\n';
    }
    return 0;
}
```

Comments: The main reason I added this exercise is to show you how useful an array of pointers might be. When two strings are swapped, it is the pointers that are swapped, not the strings. As a result, we gain performance. The sorting algorithm we used is called selection sort and will be discussed in Chapter 12. The "negative" point in this solution is the waste of space. Each row of str allocates 100 characters, even if the string contains less. For a more efficient memory management, see the next exercise. We'll use an alternative in Chapter 14 for the exercise C.14.6.

C.10.28 Write a program that reads continuously and stores strings in a vector of string elements that begin with 'a' and end with 's'. If the user enters end, the insertion of strings should terminate. The program should read and display how many times it is contained in the vector.

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main()
{
    int i, cnt, size;
    string s;
    vector<string> v_str;

    while (1)
    {
        cout << "Enter text: ";
        getline(cin, s);
        if(s == "end")
            break;
        v_str.push_back(s);
    }
    size = v_str.size();
    if(size == 0)
    {
        cout << "None string is stored\n";
        return 0;
    }

    cout << "Enter text: ";
    getline(cin, s);
    cnt = 0;
    for(i = 0; i < size; i++)
    {
        if(v_str[i] == s)
            cnt++;
    }
    cout << s << " is stored " << cnt << " times\n";
    return 0;
}
```
