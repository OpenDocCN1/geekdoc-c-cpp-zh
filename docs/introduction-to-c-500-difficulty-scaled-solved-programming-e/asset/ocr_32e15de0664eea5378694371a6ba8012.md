# Overloading the >> Operator

To read values, the cin is an object of the istream class, which contains overloaded operator>> functions for every basic type. Its prototype is similar to:

```
istream& operator>>(type&);
```

where type is the type of the input data. Then, the >> operator can be used sequentially in statements such as:

```
int a, b;
cin >> a >> b;
```

The expression cin >> triggers a call to cin.operator>>(int&), which returns an integer value, stores it into a, and returns a reference to the invoking object, that is, cin. Because the argument is reference, cin may change the value of the passed variable. Thus, the original statement contains cin >> b; and the next value will be read.

Let's see an overloading example of the >> operator to read and store values in a Rect object:

```
class Rect {
  ...
public:
    friend istream& operator>>(istream& in, Rect& r);
    ...
};
```

```
istream& operator>>(istream& in, Rect& r) {
  cout << "Enter length: ";
  in >> r.length;
  cout << "Enter height: ";
  in >> r.height;
  return in;
}
```

The first parameter is a reference to istream, while the second is a reference to the object that will be stored. Because the state of the object will change, the reference cannot be const. As in the case of <<, the function is typically defined to return reference to istream, so that in can be used sequentially in statements such as:

```
Rect r1, r2;
cin >> r1 >> r2;
```

As we said, when we overload an operator we should try to make it behave as much as close to its original purpose. Well, the << and >> are exceptions to this suggestion, as their original use as shift operators has no resemblance to the way they are used when overloaded.
