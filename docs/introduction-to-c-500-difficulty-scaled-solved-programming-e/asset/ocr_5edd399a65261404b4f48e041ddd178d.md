708 Introduction to C++

```
class B : public A
{
public:
    void f() {v = 20};
};

class C : public A
{
public:
    void g() {v = 30};
};

int main()
{
    B b;
    C c;

    b.f();
    c.g();
    std::cout << b.v << ' ' << c.v << '\n'; /* Alternatively, we can write
cout << B::v << ' ' << C::v; */
    return 0;
}
```

Since there is only one instance of v the f() and g() functions change its value sequentially. Thus, the program displays 30 30. If we do not declare v as static, the program will display 20 30, since b.v is a different variable from c.v.
