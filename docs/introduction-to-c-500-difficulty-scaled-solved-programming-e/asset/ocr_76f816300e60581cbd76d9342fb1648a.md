As when reading cin, the most common functions for reading a file are operator>>() functions,
getline() and get(). When using operator>>() functions to read from a file and assign the data to
appropriate variables, the programmer is supposed to know the type of the stored data and their order
in the file. For example, to read the file created in the previous program we need to know that each line
contains an integer, a string, and a float number, in order to assign the values to appropriate
variables. Also, space() are supposed to discriminate the values in the file.

```
#include <iostream> // Example 24.6
#include <fstream>
#include <cstdlib>
#include <string>
using namespace std;

int main()
{
    int code;
    string name;
    float grd;

    ifstream fin("test.txt");
    if(fin.is_open() == false)
{
        cout << "Error: is_open() failed\n";
        exit(EXIT_FAILURE);
    }
    while(1)
    {
        fin >> code >> name >> grd;
        if(!fin)
            break;
        cout << code << ' ' << name << ' ' << grd << ' '\n';
    }
    fin.close();
    return 0;
}
```

The program displays the data of the students stored in the file, that is, the data of s1, s2, and s3.
Specifically, in the loop we read the data of each line and store them in the respective variables. If we
read after the end of the file or if any error occurs, the state of the streams becomes false, so the
if condition becomes true and the loop ends. To determine which of the two happened, we can use
eof() function. For example, we can add the following code after the loop:

```
if(fin.eof())
    cout << "End of file\n";
else
    cout << "Failed for another reason\n";
```

The message informs us the read operation failed because we reached the end of the file or
s some other reason.
 simplicity, if something goes wrong during the reading process, I assume that this error is due
to the end of the file condition and not for some other reason. However, a robust program should check
the reason of failure.
