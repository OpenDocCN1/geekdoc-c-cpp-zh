Since a local variable is not visible outside the function in which it is declared, we can use the same name to declare variables in other functions. For example, in the following program, the local variable declared in main() is different from the local variable declared in test(), although they have the same name:

```
#include <iostream> // Example 11.10

void test();

int main() {
    int i = 10;

    test();
    std::cout << "I_main = " << i << '\\n';
    return 0;
}

void test() {
    int i = 200;
    std::cout << "I_test = " << i << '\\n';
}
```

Since the variables are different, each has its own value, and the program outputs: I_test = 200 and I_main = 10. What happens if we don't declare i as int test() and write i = 200?
Since the two variables are unrelated, the compiler will issue an error message that the variable in test() is undeclared.
Note that the parameters of the function are also considered local variables of the function. For example:

```
#include <iostream> // Example 11.11

void test(int i, int j);

int main() {
    int i = 100, j = 100;

    test(i, j);
    std::cout << i << ' ' << j << '\\n';
    return 0;
}

void test(int i, int j) {
    int a = 2000; // The local variables of the function are a, and j.
    i = j = a;
}
```

The parameters of the function are also local variables, the variables i and j of test() are not related with those of main().
