# C.9.4 Write a program that displays all lowercase letters in one line, all uppercase letters in a second line, and all characters that represent the digits 0-9 in a third line. Use one for loop.

```
#include <iostream>
int main() {
    char ch, end_ch;

    end_ch = 'z';
    for(ch = 'a'; ch <= end_ch; ch++) {
        std::cout << ch << ' ';
        if(ch == 'z') {
            ch = 'A'-1; /* Subtract 1, so that the ch++ statement on the next iteration it makes 'A'. */
            end_ch = 'Z'; /* Change the character, so that the loop displays the uppercase letters. */
            std::cout << ch << '\n';
        } else if(ch == 'Z') {
            ch = '0'-1;
            end_ch = '9';
            std::cout << ch << '\n';
        }
    }
    return 0;
}
```
