C.8.1 Use the p1 and p2 pointers and complete the following program to read two numbers first and to swap the values they point to. Then, use the same program to display the absolute result of the difference of these values. The variables i and j should be used only once.

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    float *p1, *p2, i, j, tmp;
    ...
}
```

Answer:

```cpp
#include <iostream>
using std::cout;
using std::cin;

int main()
{
    float *p1, *p2, i, j, tmp;
    /* The pointers must be initialized before used to store the input values. */
    p1 = &i;
    p2 = &j;

    cout << "Enter values: ";
    cin >> *p1 >> *p2;

    tmp = *p2;
    *p2 = *p1;
    *p1 = tmp;

    if((*p1-*p2) > 0)
        cout << *p1-*p2 << '\n';
    else
        cout << -(p1-*p2) << '\n';
    return 0;
}
```

# C.8.2 What is the output of the following program?

```cpp
#include <iostream>
int main() {
    int *ptr1, *ptr2, *ptr3, i = 0, j = 1, k = 2;

    ptr1 = &i;
    i = *ptr1 ? 3 : 4;

    ptr2 = &j;
    j = *ptr2 + *ptr1;

    ptr3 = &k;
    k = *ptr3 + *ptr2;
    std::cout << *ptr1 << ' ' << *ptr2 << ' ' << *ptr3 << ' '\n';
    return 0;
}
```

Answer: Since ptr1 points to the address of i: expression: *ptr1 = i ? 3 : 4; is equivalent to i = i ? 3 : 4. Since i is 0, it becomes 4. Since ptr2 points to the address of j, *ptr2 is equal to j, that is, 1. Therefore, j = *ptr2 + *ptr1 = 1+4 = 5. Similarly, since ptr3 points to the address of k, *ptr3 is equal to k, that is, 2. Therefore, k = *ptr3 + *ptr2 = 2+5 = 7. Since the values of *ptr1, *ptr2, and *ptr3 are equal to i, j, and k, respectively, the program displays: 4 5 7

# C.8.3 Use the pointer and a while loop, and complete the following program to display the integers from 1 to 10. The variable i used only once.

```cpp
#include <iostream>
int main() {
    int *p, i;
    ...
}
```

Answer:

```cpp
#include <iostream>
int main() {
    int *p, i;

    p = &i;
    *p = 1;
    while(*p <= 10) {
        std::cout << *p << '\n';
        (*p)++; /* As you see, we must use parentheses for reasons. */
    }
    return 0;
}
```

# THE VOID* POINTER

Sometimes we may need to store or pass pointer to a function the memory address of a variable whose we't know the type. In such cases, the type void is used. The void* pointer is a generic pointer in the sense that it can point to a pointer of any type. A void* pointer can be assigned to another void* pointer. Also, a non-void* pointer can be assigned to another void* pointer. For example:

```cpp
void *p1, *p2;
int i, j, *p3 = &i;
p1 = &j;
p1 = *p3;
p2 = p1;
```

Notice that, except for void*, in order to assign one type to a pointer of another type cast is necessary. For example:

```cpp
char *p1;
int *p2;
...
p2 = p1; // Wrong.
p2 = (int*)p1; // Compiled
```

In general, it is better to avoid using castings, as the different sizes of the data types, for example, dereferencing objects, may cause serious problems. If you make a cast, it is better to use a cast operator (e.g., reinterpret_cast) as we will see in Chapter 25.
To access a variable via void* pointer, cast is necessary in order to inform the compiler about the type of variable. For example:

```cpp
#include <iostream> // Example 8.47
int main()
{
  void *ptr;
  char s[] = "abcd";
  int i = 10;

  ptr = &i;
  *ptr += 20; // Wrong, cast is needed.
  *(int*)ptr += 20; // That's ok now.
  std::cout << i << '\n';
}

```cpp
ptr = s+2;
*(char*)ptr++;
std::cout << ptr << '\n';
return 0;
```

Typically, a void pointer is used as a function parameter in order to pass values of different types without loss of information. Note that any pointer can be cast to void* and back again.

# USE OF COST QUALIFIER

To prevent a pointer to change the value of it points to, we add the const keyword before its type. For example, the following code will not compile because ptr is not allowed to change the value of the same type. The variable does not have to be const.

```cpp
int j, i = 10;
const int *ptr;
ptr = &i; // OK, the variable does not have to be const.
i = 30; // OK, i is not const.
*ptr = 30; // Wrong, it is not allowed to change the value.
```

To prevent a pointer to another variable, we add the const keyword before its name. We create a const pointer. With ordinary const variables, the pointer must be initialized when declared. For example, the following code will not compile because ptr is not allowed to point to the address of j. However, it is allowed to change the value of i.

```cpp
int i, j;
int *const ptr = &i; // Initialize the pointer.
ptr = &j; // Wrong.
*ptr = 30; // OK, i becomes 30.
```

What is now ptr? From right to left, it is a const pointer to type int. Note that it is allowed to prevent back actions by using the const keyword twice. For example:

```cpp
int i, j;
const int *const ptr = &i; // Initialize pointer.
ptr = &j; // Wrong.
*ptr = 30; // Wrong.
```
