In short, the binary search algorithm divides the array into two parts. Then, the searched value is compared with the middle element and the search continues in the proper part. The algorithm terminates if the searched value is found or start becomes greater than end. The maximum number of searches in a sorted array of n elements with the binary search algorithm is log_n. In the following program, the binary_search() function implements the binary search algorithm.

';

int binary_search(const int arr[], int size, int num)
{
    int start, end, middle;

    start = 0;
    end = size-1;
    while(start <= end)
    {
        middle = (start+end)/2;
        if(num < arr[middle])
            end = middle-1;
        else if(num > arr[middle])
            start = middle+1;
        else
            return middle;
    }
    return -1; /* If the execution reaches this point it means that the number was not found and the function returns -1. */
