C11.30 What is the output of the following program?

```
#include <iostream>
```

```
int unknown(const int arr[], int num);

int main()
{
    int arr[] = {10, 20, 30, 40};
    std::cout << unknown(arr, 4) << '\n';
    return 0;
}
int unknown(const int arr[], int num)
{
    if(num == 1)
        return arr[0];
    else
        return arr[num-1] + unknown(arr, num-1);
}
```

Answer: When unknown() is called, it returns:

```
arr[4-1] = 3 + unknown(arr, 4-1) = 3
arr[3] + (arr[3-1] + unknown(arr, 3-1)) =
arr[3] + arr[2] + (arr[2-1] + unknown(arr, 2-1)) =
arr[3] + arr[1] + unknown(arr, 1)
```

The last call of unknown(arr, 1) returns arr[0], because num = 1. Therefore, the return value is arr[3]+arr[2]+arr[1]+arr[0], which the function calculates as the sum of the array's elements. The function outputs 100.

C11.31 Write a recursive function that takes as an integer n and returns its factorial, using the formula n!=n(n-1)!. The factorial of integer n, where n>=1, is the product of the integers from 1 to n, that is, 1*2*...*n. The factorial of 0 is (0!=1). Write a program that reads a positive integer and uses the function to display its factorial. Since factors grow rapidly and may exceed very fast the capacity of the larger type don't exceed a large integer

```
#include <iostream>
```

```
unsigned long int fact(int num);

int main()
{
    int num;
    do
    {
        std::cout << "Enter a positive integer: ";
        std::cin >> num;
    } while (num < 0);

    std::cout << "Factorial of " << num << " is " << fact(num) << '\n';
    return 0;
```
