**C10.26** What is the output of the following program?

```
#include <iostream>
#include <string>
int main()
n  char arr[7][10] = {"Monday", "Tuesday", "Wednesday", "Thursday",
  "Friday", "Saturday", "Sunday"};
  int i;
  for(i = 0; i < 7; i++)
    if(arr[i][2] == 'n' && *(arr[i]+3) == 'd' && *(arr+i+4) == 'a')
      cout << arr[i] << " is No." << i << " week day";
  return 0;
}
```

**Answer:** The characters of "Monday" are stored in the first row of arr, the characters of "Tuesday" are in the second row, and so on. Remember that *(arr+i+3) is equivalent to arr[i][3] and **(arr+i+4) is equivalent to *(arr+i)[4], that is, arr[i]. Therefore, the loop checks each row of arr and displays the strings third, fourth, and fifth characters are 'n', 'd', and 'a', respectively. Therefore, the program displays:

Monday is No.1 week day
Sunday is No.7 week day
