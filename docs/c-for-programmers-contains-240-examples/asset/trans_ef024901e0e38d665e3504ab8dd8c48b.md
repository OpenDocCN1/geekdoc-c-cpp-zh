让我们多次运行该程序并观察结果。注意，只要用户输入不同的种子，程序每次执行时都会产生不同的随机数序列。我们在第一和第三组示例输出中使用了相同的种子，因此这两组输出中显示了相同的10个数字序列。

```
// Fig. 6.9: fig06_09.cpp
// Randomizing die-rolling program.
#include <iostream>
using std::cout;
using std::cin;
using std::endl;

#include <iomanip>
using std::setw;

#include <cstdlib> // contains prototypes for functions srand and rand
using std::rand;
using std::srand;

int main()
{
    unsigned seed; // stores the seed entered by the user

    cout << "Enter seed: ";
    cin >> seed;
    srand( seed ); // seed random number generator

    // loop 10 times
    for ( int counter = 1; counter <= 10; counter++ )
    {
        // pick random number from 1 to 6 and output it
        cout << setw( 10 ) << ( 1 + rand() % 6 );

        // if counter is divisible by 5, start a new line of output
        if ( counter % 5 == 0 )
            cout << endl;
    } // end for

    return 0; // indicates successful termination
} // end main
```

为了无需每次输入种子即可实现随机化，我们可以使用如下语句：

```
srand( time( 0 ) );
```

这会使计算机读取其时钟以获取种子的值。函数`time`（如上一条语句中的参数0所示）返回自1970年1月1日格林尼治标准时间（GMT）午夜以来经过的秒数。该值被转换为无符号整数，并用作随机数生成器的种子。函数`time`的函数原型位于`<ctime>`中。

## 常见编程错误 6.7

> 在程序中多次调用函数srand会重新启动伪随机数序列，并可能影响rand所产生数字的随机性。

## 随机数的一般化缩放与平移

之前，我们演示了如何用一条语句模拟六面骰子的滚动：

```
face = 1 + rand() % 6;
```

该语句总是将一个大范围内的整数（随机地）赋给变量`face`，满足1 ≤ face ≤ 6。注意，该范围（即范围内连续整数的个数）的宽度为6，范围的起始数字为1。参考前面的语句，我们可以看到范围的宽度由用于缩放rand的取模数（即6）决定，而范围的起始数字等于加到表达式`rand % 6`上的数字（即1）。我们可以将此结果一般化为：

```
number = shiftingValue + rand() % scalingFactor;
```

其中，`shiftingValue`等于所需连续整数范围中的第一个数字，`scalingFactor`等于所需连续整数范围的宽度。

## 常见编程错误 6.8

> 使用srand代替rand来尝试生成随机数是编译错误——函数srand不返回值。

## 6.8 案例研究：机会游戏；引入enum

最流行的机会游戏之一是被称为“掷双骰”（craps）的骰子游戏，全球各地的赌场和后巷都在玩。游戏规则很简单：

> 玩家掷两颗骰子。每颗骰子有六个面。这些面上分别有1、2、3、4、5和6个点。骰子静止后，计算两个朝上的面上的点数之和。如果第一次掷出的和是7或11，玩家获胜。如果第一次掷出的和是2、3或12（称为“craps”），玩家失败（即“庄家”获胜）。如果第一次掷出的和是4、5、6、8、9或10，那么这个和就成为玩家的“点数”。要获胜，你必须继续掷骰子，直到“掷出你的点数”。如果玩家在掷出点数之前掷出7，则失败。

图6.10中的程序模拟了掷双骰游戏。

在游戏规则中，注意玩家在第一次掷骰及所有后续掷骰中都必须掷两颗骰子。我们定义了函数rollDice（第71–83行）来掷骰子、计算并打印它们的和。函数rollDice只定义了一次，但在程序中的两处（第27行和第51行）被调用。有趣的是，rollDice不带任何参数，因此我们在原型（第14行）和函数头（第71行）中标明了空参数列表。函数rollDice确实返回两颗骰子的和，因此返回类型`int`在函数原型和函数头中都已标明。

```
// Fig. 6.10: fig06_10.cpp
// Craps simulation.
#include <iostream>
using std::cout;
using std::endl;

#include <cstdlib> // contains prototypes for functions srand and rand
using std::rand;
using std::srand;

#include <ctime> // contains prototype for function time
using std::time;

int rollDice(); // rolls dice, calculates and displays sum

int main()
{
    // enumeration with constants that represent the game status
    enum Status { CONTINUE, WON, LOST }; // all caps in constants

    int myPoint; // point if no win or loss on first roll
    Status gameStatus; // can contain CONTINUE, WON or LOST

    // randomize random number generator using current time
    srand( time( 0 ) );

    int sumOfDice = rollDice(); // first roll of the dice

    // determine game status and point (if needed) based on first roll
    switch ( sumOfDice )
    {
        case 7: // win with 7 on first roll
        case 11: // win with 11 on first roll
            gameStatus = WON;
            break;
        case 2: // lose with 2 on first roll
        case 3: // lose with 3 on first roll
        case 12: // lose with 12 on first roll
            gameStatus = LOST;
            break;
        default: // did not win or lose, so remember point
            gameStatus = CONTINUE; // game is not over
            myPoint = sumOfDice; // remember the point
            cout << "Point is " << myPoint << endl;
            break; // optional at end of switch
    } // end switch

    // while game is not complete
    while ( gameStatus == CONTINUE ) // not WON or LOST
    {
        sumOfDice = rollDice(); // roll dice again

        // determine game status
        if ( sumOfDice == myPoint ) // win by making point
            gameStatus = WON;
        else
            if ( sumOfDice == 7 ) // lose by rolling 7 before point
                gameStatus = LOST;
    } // end while

    // display won or lost message
    if ( gameStatus == WON )
        cout << "Player wins" << endl;
    else
        cout << "Player loses" << endl;

    return 0; // indicates successful termination
} // end main

// roll dice, calculate sum and display results
int rollDice()
{
    // pick random die values
    int die1 = 1 + rand() % 6; // first die roll
    int die2 = 1 + rand() % 6; // second die roll

    int sum = die1 + die2; // compute sum of die values

    // display results of this roll
    cout << "Player rolled " << die1 << " + " << die2
         << " = " << sum << endl;

    return sum; // end function rollDice
} // end function rollDice
```

这个游戏相当复杂。玩家可能在第一次掷骰或任何后续掷骰中获胜或失败。程序使用变量gameStatus来跟踪这一点。变量gameStatus被声明为新的类型Status。第19行声明了一个用户自定义类型，称为枚举。枚举由关键字`enum`引入，后跟一个类型名（此处为Status），是一组由标识符表示的整数常量。除非另有指定，这些枚举常量的值从0开始，并逐个递增1。在前面的枚举中，常量CONTINUE的值为0，WON的值为1，LOST的值为2。枚举中的标识符必须是唯一的，但不同的枚举常量可以具有相同的整数值（我们稍后会演示如何实现这一点）。

在枚举常量的名称中只使用大写字母。这会使这些常量在程序中脱颖而出，并提醒你枚举常量不是变量。
