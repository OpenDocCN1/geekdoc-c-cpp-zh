## 3.7 使用构造函数初始化对象

如3.6节所述，当GradeBook类（图3.5）的对象被创建时，其数据成员courseName默认被初始化为空字符串。如果你希望在创建GradeBook对象时提供课程名称，该怎么办？你声明的每个类都可以提供一个构造函数，用于在创建对象时初始化该类的对象。构造函数是一种特殊的成员函数，必须定义为与类相同的名称，以便编译器能够将其与类的其他成员函数区分开来。构造函数与其他函数的一个重要区别是，构造函数不能返回值，因此它们不能指定返回类型（甚至不能是void）。通常，构造函数被声明为公有。在文献中，“构造函数”一词常被缩写为“ctor”——我们通常避免使用缩写。

C++要求为每个创建的对象调用构造函数，这有助于确保每个对象在程序中使用之前被初始化。构造函数调用在对象创建时隐式发生。如果类没有显式包含构造函数，编译器会提供一个默认构造函数——即没有参数的构造函数。例如，当图3.5中的第46行创建一个GradeBook对象时，会调用默认构造函数。编译器提供的默认构造函数创建一个GradeBook对象，但不会给对象的基本类型数据成员提供任何初始值。[注意：对于作为其他类对象的数据成员，默认构造函数会隐式调用每个数据成员的默认构造函数，以确保该数据成员被正确初始化。这就是为什么string数据成员courseName（在图3.5中）被初始化为空字符串——string类的默认构造函数将字符串的值设置为空字符串。你将在10.3节中了解更多关于初始化作为其他类对象的数据成员的内容。]

在图3.7的示例中，我们在创建GradeBook对象时为其指定课程名称（第49行）。在这种情况下，参数"CS101 Introduction to C++ Programming"被传递给GradeBook对象的构造函数（第17-20行），并用于初始化courseName。图3.7定义了一个修改后的GradeBook类，其中包含一个带string参数的构造函数，该参数接收初始课程名称。

## 定义构造函数

图3.7的第17-20行定义了GradeBook类的构造函数。注意，构造函数与其类GradeBook同名。构造函数在其参数列表中指定执行其任务所需的数据。创建新对象时，你将此数据放在对象名称后面的括号中（如我们在第49-50行所做的那样）。第17行表明GradeBook类的构造函数有一个名为name的string参数。注意，第17行没有指定返回类型，因为构造函数不能返回值（甚至不能是void）。

构造函数体中的第19行将构造函数的参数name传递给成员函数setCourseName，后者将值赋给数据成员courseName。setCourseName成员函数（第23-26行）只是将其参数name赋给数据成员courseName，因此你可能想知道为什么我们要在第19行调用setCourseName——构造函数当然可以执行赋值courseName = name。在3.10节中，我们将修改setCourseName以执行验证（确保在这种情况下courseName的长度不超过25个字符）。到那时，从构造函数调用setCourseName的好处将会变得清晰。注意，构造函数（第17行）和setCourseName函数（第23行）都使用名为name的参数。你可以在不同的函数中使用相同的参数名，因为参数对于每个函数是局部的；它们互不干扰。
