+   a) Vary the control variable from 1 to 100 in increments of 1.

+   
+       for ( int i = 100; i >= 1; i-- )

+   c) Vary the control variable from 7 to 77 in steps of 7.
+   
+       for ( int i = 7; i <= 77; i += 7 )

+   
+       for ( int i = 20; i >= 2; i -= 2 )

+   
+       for ( int i = 2; i <= 20; i += 3 )
