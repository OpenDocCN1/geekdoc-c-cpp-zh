## 3.10 使用set函数验证数据

## 使用GradeBook成员函数setCourseName验证课程名称

对类GradeBook的增强体现在setCourseName的定义中（图3.16，第18–31行）。第20–21行的if语句判断参数name是否包含有效的课程名称（即长度不超过25个字符的字符串）。如果课程名称有效，第21行将课程名称存储到数据成员courseName中。注意第20行中的表达式name.length()。这是一个成员函数调用，就像myGradeBook.displayMessage()一样。C++标准库的string类定义了一个成员函数length，它返回字符串对象中的字符数。参数name是一个string对象，

```
1  // Fig. 3.16: GradeBook.cpp
2  // Implementations of the GradeBook member-function definitions.
3  // The setCourseName function performs validation.
4  #include <iostream>
5  using std::cout;
6  using std::endl;
7
8  #include "GradeBook.h" // include definition of class GradeBook
9
10 // constructor initializes courseName with string supplied as argument
11 GradeBook::GradeBook( string name )
12 {
13     setCourseName( name ); // validate and store courseName
14 } // end GradeBook constructor
15
16 // function that sets the course name;
17 // ensures that the course name has at most 25 characters
18 void GradeBook::setCourseName( string name )
19 {
20     if ( name.length() <= 25 ) // if name has 25 or fewer characters
21         courseName = name; // store the course name in the object
22
23     if ( name.length() > 25 ) // if name has more than 25 characters
24     {
25         // set courseName to first 25 characters of parameter name
26         courseName = name.substr( 0, 25 ); // start at 0, length of 25
27
28         cout << "Name \"" << name << "\" exceeds maximum length (25).\n"
29             << "Limiting courseName to first 25 characters.\n" << endl;
30     } // end if
31 } // end function setCourseName
```

因此，调用name.length()返回name中的字符数。如果该值小于或等于25，则name有效，并执行第21行。

第23–30行的if语句处理setCourseName收到无效课程名称（即长度超过25个字符的名称）的情况。即使参数name太长，我们仍然希望使GradeBook对象保持一致性状态——即对象的数据成员courseName包含有效值（即不超过25个字符的字符串）的状态。因此，我们截断（即缩短）指定的课程名称，并将name的前25个字符赋给courseName数据成员（不幸的是，这可能会使课程名称被生硬地截断）。标准string类提供了成员函数substr（“substring”的缩写），它通过复制现有字符串对象的一部分来返回一个新的字符串对象。第26行中的调用（即name.substr( 0, 25 )）向name的成员函数substr传递两个整数（0和25）。这些参数指示substr应返回字符串name的哪个部分。第一个参数指定从原字符串中开始复制字符的起始位置——每个字符串的第一个字符被认为位于位置0。第二个参数指定要复制的字符数。因此，第26行中的调用返回从位置0开始的name的25个字符的子字符串（即name的前25个字符）。例如，如果name的值为"CS101 Introduction to Programming in C++"，则substr返回"CS101 Introduction to Pro"。调用substr后，第26行将substr返回的子字符串赋给数据成员courseName。这样，成员函数setCourseName确保courseName总是被赋值为包含25个或更少字符的字符串。如果成员函数必须截断课程名称以使其有效，则第28–29行显示警告消息。

请注意，第23–30行的if语句包含两个主体语句——一个用于将courseName设置为参数name的前25个字符，另一个用于向用户打印相应的消息。当name太长时，我们希望这两个语句都执行，因此将它们放在一对花括号{ }中。回顾第2章，这创建了一个块。你将在第4章中学习更多关于将多个语句放置在控制语句主体中的内容。
