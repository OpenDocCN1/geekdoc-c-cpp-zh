- 1. 如果类A是类B的泛化，那么类B派生自（并且是类A的特化）。例如，抽象基类Transaction是类Withdrawal的泛化。因此，类Withdrawal派生自（并且是）类Transaction的特化。图13.30包含了类Withdrawal的头文件的一部分，其中类定义表明了Withdrawal和Transaction之间的继承关系（第9行）。

```
#define WITHDRAWAL_H

#include "Transaction.h" // Transaction class definition

// class Withdrawal derives from base class Transaction
class Withdrawal : public Transaction
{
}; // end class Withdrawal

#endif // WITHDRAWAL_H
```

- 2. 如果类A是一个抽象类，而类B派生自类A，那么如果类B要成为具体类，它必须实现类A的纯虚函数。例如，类Transaction包含纯虚函数execute，因此如果我们要实例化Withdrawal对象，类Withdrawal必须实现这个成员函数。图13.31包含了来自图13.28和图13.29的类Withdrawal的C++头文件。类Withdrawal从基类Transaction继承了数据成员accountNumber，因此Withdrawal不再声明这个数据成员。类Withdrawal还继承了对其基类Transaction中Screen和BankDatabase的引用，因此我们在代码中不包含这些引用。图13.29为类Withdrawal指定了属性amount和操作execute。图13.31的第19行声明了属性amount的数据成员。第16行包含操作execute的函数原型。回顾一下，要成为具体类，派生类Withdrawal必须提供基类Transaction中纯虚函数execute的具体实现。第16行的原型表示你打算覆盖基类纯虚函数。如果你将在.cpp文件中提供实现，则必须提供此原型。我们在附录E中给出了这个实现。keypad和cashDispenser引用（第20–21行）是根据图13.28中Withdrawal的关联而得出的数据成员。在附录E中实现这个类时，构造函数将这些引用初始化为实际对象。同样，为了能够编译第20–21行的引用声明，我们在第8–9行包含了前置声明。

```
// Fig. 13.31: Withdrawal.h
// Definition of class Withdrawal that represents a withdrawal transaction
#ifndef WITHDRAWAL_H
#define WITHDRAWAL_H

#include "Transaction.h" // Transaction class definition

class Keypad; // forward declaration of class Keypad
class CashDispenser; // forward declaration of class CashDispenser

// class Withdrawal derives from base class Transaction
class Withdrawal : public Transaction
{
public:
    // member function overriding execute in base class Transaction
    virtual void execute(); // perform the transaction
private:
    // attributes
    double amount; // amount to withdraw
    Keypad &keypad; // reference to ATM's keypad
    CashDispenser &cashDispenser; // reference to ATM's cash dispenser
}; // end class Withdrawal

#endif // WITHDRAWAL_H
```
