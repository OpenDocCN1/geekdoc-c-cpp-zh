# E.2 Class ATM

Class ATM (Figs. E.1–E.2) represents the ATM as a whole. Figure E.1 contains the ATM class definition, enclosed in #ifndef, #define and #endif preprocessor directives to ensure that this definition gets included only once in a program. We discuss lines 6–11 shortly. Lines

// ATM.h

#ifndef ATM_H
#define ATM_H

#include "Screen.h" // Screen class definition
