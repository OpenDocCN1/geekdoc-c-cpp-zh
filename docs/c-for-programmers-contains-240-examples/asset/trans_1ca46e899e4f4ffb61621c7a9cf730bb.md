在此图中，两条语句涉及将成绩加到总分变量上，以及将计数器变量加1。此类语句可能出现在对学生若干成绩求平均值的程序中。要计算平均值，需要将成绩总和除以成绩个数。计数器变量用于跟踪被平均的数值个数。你将在4.6节的程序中看到类似的语句。

活动图是UML的一部分。活动图对软件系统某一部分的工作流（也称为活动）进行建模。此类工作流可能包含算法的某一部分，例如图4.1中的顺序结构。活动图由专用符号组成，如动作状态符号（左右两侧替换为向外弯曲弧线的矩形）、菱形和小圆圈；这些符号通过转换箭头连接，转换箭头表示活动的流向。活动图帮助你开发和表示算法。如你将看到的，活动图清晰地展示了控制结构如何运作。

考虑图4.1的顺序结构活动图。它包含两个表示要执行动作的动作状态。每个动作状态包含一个动作表达式——例如“将成绩加到总分”或“计数器加1”——该表达式指定要执行的特定动作。其他动作可能包括计算或输入/输出操作。活动图中的箭头称为转换箭头。这些箭头表示转换，指明动作状态所表示的动作发生的顺序——实现图4.1活动图所示活动的程序首先将成绩加到总分，然后将计数器加1。

位于活动图顶部的实心圆表示活动的初始状态——程序执行所建模活动之前工作流的起点。活动图底部出现的带空心圆环绕的实心圆表示最终状态——程序执行其活动之后工作流的终点。

图4.1还包括右上角折叠的矩形。在UML中这些称为注释。注释是描述图中符号用途的解释性说明。注释可用于任何UML图，而不仅是活动图。图4.1使用UML注释来显示与活动图中每个动作状态相关联的C++代码。虚线将每条注释与注释所描述的元素连接起来。活动图通常不显示实现活动的C++代码。我们在此使用注释是为了说明该图如何与C++代码相关联。有关UML的更多信息，请参阅我们可选的案例研究，该案例研究出现在第1–7章、第9章和第13章末尾的软件工程案例研究部分，或访问www.uml.org。

## C++中的选择语句

C++提供三种类型的选择语句（本章和第5章讨论）。if选择语句在条件（谓词）为真时执行（选择）一个动作，在条件为假时跳过该动作。if…else选择语句在条件为真时执行一个动作，在条件为假时执行另一个不同的动作。switch选择语句（第5章）根据整数表达式的值执行许多不同动作之一。

if选择语句是*单选择语句*，因为它选择或忽略单个动作（或者，我们很快会看到，单个动作组）。if…else语句被称为*双选择语句*，因为它在两个不同动作（或动作组）之间进行选择。switch选择语句被称为*多选择语句*，因为它在许多不同动作（或动作组）中进行选择。

## C++中的重复语句

C++提供三种类型的重复语句，使程序能够在条件保持为真时重复执行语句。重复语句是*while*、*do…while*和*for*语句。（第5章介绍do…while和for语句。）while和for语句执行其主体中的动作（或动作组）零次或多次——如果循环继续条件最初为假，则动作（或动作组）不会执行。do…while语句至少执行其主体中的动作（或动作组）一次。

if、else、switch、while、do和for每个词都是C++关键字。这些词被C++编程语言保留用于实现各种功能，例如C++的控制语句。关键字不得用作标识符，例如变量名。图4.2提供了C++关键字的完整列表。

### C++控制语句小结

C++只有三种控制结构，从现在起我们称之为控制语句：顺序语句、选择语句（三种类型——if、if...else和switch）和重复语句（三种类型——while、for和do...while）。与图4.1的顺序语句一样，我们可以将每个控制语句建模为活动图。每个图都包含一个初始状态和一个最终状态，分别表示控制语句的入口点和出口点。这些单入口/单出口的控制语句通过将一个的出口点连接到下一个的入口点来相互连接。我们称之为控制语句堆叠。连接控制语句只有另一种方式——称为控制语句嵌套，即一个控制语句包含在另一个控制语句内部。

> **软件工程观察4.1**
>
> 我们将构建的任何C++程序都可以仅由七种不同类型的控制语句（顺序、if、if...else、switch、while、do...while和for）以仅两种方式（控制语句堆叠和控制语句嵌套）组合而成。这就是简洁性的本质。

## 4.3 if选择语句

程序使用选择语句在备选行动方案中进行选择。例如，假设考试及格分数为60。语句

```cpp
if ( grade >= 60 )
    cout << "Passed";
```

确定条件 grade >= 60 为真还是为假。如果为真，则打印“Passed”，并执行顺序中的下一条语句。如果条件为假，则忽略打印，并执行顺序中的下一条语句。注意此选择语句的第二行是缩进的。这种缩进是可选的，但建议使用。
