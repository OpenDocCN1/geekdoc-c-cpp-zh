In Fig. 10.22, note the use of the new operator (lines 27 and 30) in the `Employee` constructor to dynamically allocate the correct amount of memory for members `firstName` and `lastName`. In Chapter 16, we’ll provide a better mechanism for dealing with cases in which new is unable to allocate memory.
