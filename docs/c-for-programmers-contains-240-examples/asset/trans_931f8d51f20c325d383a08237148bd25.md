```
// Fig. 17.4: Fig17_04.cpp
// Create a sequential file.
#include <iostream>
using std::cerr;
using std::cin;
using std::cout;
using std::endl;
using std::ios;

#include <fstream> // file stream
using std::ofstream; // output file stream

#include <cstdlib>
using std::exit; // exit function prototype

int main()
{
    // ofstream constructor opens file
    ofstream outClientFile( "clients.dat", ios::out );

    // exit program if unable to create file
    if ( !outClientFile ) // overloaded ! operator
    {
        cerr << "File could not be opened" << endl;
        exit( 1 );
    } // end if

    cout << "Enter the account, name, and balance." << endl
         << "Enter end-of-file to end input.\n?";

    int account;
    char name[ 30 ];
    double balance;

    // read account, name and balance from cin, then place in file
    while ( cin >> account >> name >> balance )
    {
        outClientFile << account << ' ' << name << ' ' << balance << endl;
        cout << "?";
    } // end while

    return 0; // ofstream destructor closes file
} // end main
```

第19行创建了一个名为outClientFile的ofstream对象，它与文件clients.dat关联，并以输出方式打开。参数`"clients.dat"`和`ios::out`被传递给ofstream构造函数，该构造函数打开文件——这建立了与文件的一条“通信线路”。默认情况下，ofstream对象以输出方式打开，因此第19行也可以使用替代语句

## 常见编程错误17.1

> 以输出方式（ios::out）打开现有文件时要格外小心，尤其是当您希望保留文件内容时，因为内容将被无警告地丢弃。

| 模式 | 描述 |
|------|-------------|
| ios::app | 将所有输出追加到文件末尾。 |
| ios::ate | 为输出打开文件并移动到文件末尾（通常用于向文件追加数据）。数据可以写入文件中的任何位置。 |
| ios::in | 为输入打开文件。 |
| ios::out | 为输出打开文件。 |
| ios::trunc | 如果文件内容存在则丢弃（这也是ios::out的默认操作）。 |
| ios::binary | 以二进制（即非文本）输入或输出方式打开文件。 |

## 常见编程错误17.2

> 在程序中尝试引用文件之前未打开文件会导致错误。

创建ofstream对象并尝试打开它之后，程序测试打开操作是否成功。第22–26行的if语句使用重载的ios运算符成员函数operator!来确定打开操作是否成功。如果打开操作时流的failbit或badbit被设置，则条件返回true值。一些可能的错误包括：尝试读取不存在的文件，尝试在没有权限的情况下读或写文件，以及在没有可用磁盘空间时打开文件进行写入。

如果条件指示打开文件未成功，第24行输出错误消息"File could not be opened"，第25行调用函数exit终止程序。传递给exit的参数被返回到调用程序的环境。参数0表示程序正常终止；任何其他值表示程序因错误而终止。调用环境（很可能是操作系统）使用exit返回的值来适当地响应错误。

另一个重载的ios运算符成员函数——operator void *——将流转换为指针，因此可以将其测试为0（即空指针）或非零（即任何其他指针值）。当指针值用作条件时，C++将空指针转换为bool值false，并将非空指针转换为bool值true。如果流的failbit或badbit（参见第15章）已被设置，则返回0（false）。第36–40行while语句中的条件隐式调用cin上的operator void *成员函数。只要cin的failbit和badbit都未被设置，该条件就保持为true。输入文件结束指示符会设置cin的failbit。operator void *函数可用于测试输入对象的文件结束状态，而不是在输入对象上显式调用eof成员函数。

如果第19行成功打开了文件，程序就开始处理数据。第28–29行提示用户输入每条记录的各字段，或在数据输入完成时输入文件结束指示符。图17.6列出了各种计算机系统输入文件结束的键盘组合。第36行提取每组数据并确定是否已输入文件结束。当遇到文件结束或输入了错误数据时，operator void *返回空指针（转换为bool值false），while语句终止。用户输入文件结束以告知程序不再处理更多数据。当用户输入文件结束键组合时，设置文件结束指示符。while语句循环直到文件结束指示符被设置。

| 计算机系统 | 键盘组合 |
|---|---|
| UNIX/Linux/Mac OS X | <Ctrl-d>（单独一行） |
| Microsoft Windows | <Ctrl-z>（有时后跟按Enter） |
| VAX (VMS) | <Ctrl-z> |
