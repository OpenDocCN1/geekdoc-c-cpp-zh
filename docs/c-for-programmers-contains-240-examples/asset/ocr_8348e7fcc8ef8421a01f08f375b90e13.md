Chapter 10 presents additional class features. We’ll demonstrate how const can be used to indicate that a member function does not modify an object of a class. You’ll see how to build classes with composition—the capability that allows a class to contain objects of other classes as members. We’ll show how a class can allow so-called “friend” functions to access the class’s non-public members. We’ll also show how a class’s non-static member functions can use a special pointer named this to access an object’s members. Next, we discuss how to use C++’s new and delete operators, which enable you to obtain and release memory as necessary during a program’s execution.
