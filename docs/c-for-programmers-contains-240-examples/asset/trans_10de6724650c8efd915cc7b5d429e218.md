`ifstream` 类的对象默认以输入方式打开。我们本可以使用语句

```cpp
ifstream inClientFile( "clients.dat" );
```

来打开 `clients.dat` 以进行输入。就像 `ofstream` 对象一样，`ifstream` 对象可以在不打开特定文件的情况下创建，因为文件可以稍后附加到它。

程序使用条件 `!inClientFile` 来确定在尝试从文件检索数据之前文件是否成功打开。第 48 行从文件中读取一组数据（即一条记录）。在前一行第一次执行后，account 的值为 100，name 的值为 "Jones"，balance 的值为 24.98。每次第 48 行执行时，它都会从文件中读取另一条记录到变量 account、name 和 balance 中。第 49 行使用函数 `outputLine`（第 55–59 行）显示记录，该函数使用参数化流操纵符来格式化数据显示。当到达文件末尾时，`while` 条件中对 `operator void *` 的隐式调用返回空指针（转换为布尔值 `false`），`ifstream` 析构函数关闭文件，程序终止。

要从文件中顺序检索数据，程序通常从文件开头开始读取，并连续读取所有数据，直到找到所需数据。在程序执行期间，可能需要多次（从文件开头）顺序处理文件。`istream` 和 `ostream` 都提供了用于重新定位 *文件位置指针*（即下一次要读或写的字节号）的成员函数。这些成员函数是 `seekg`（“seek get”）用于 `istream`，以及 `seekp`（“seek put”）用于 `ostream`。每个 `istream` 对象都有一个“get 指针”，它指示下一次输入应发生的字节号在文件中的位置，每个 `ostream` 对象都有一个“put 指针”，它指示下一次输出应放置在文件中的字节号。语句

```cpp
inClientFile.seekg( 0 );
```

将附加到 `inClientFile` 的文件位置指针重新定位到文件的开头（位置 0）。`seekg` 的参数通常是一个长整数。可以指定第二个参数来指示 *查找方向*，它可以是 `ios::beg`（默认值）表示相对于流开头定位，`ios::cur` 表示相对于当前位置定位。

流中的位置或 ios::end 表示相对于流末尾定位。文件位置指针是一个整数值，它指定文件中的位置为从文件起始位置开始的字节数（这也称为相对于文件开头的偏移量）。定位“get”文件位置指针的一些示例是

```
// 定位到 fileObject 的第 n 个字节（假设 ios::beg）
fileObject.seekg( n );

// 在 fileObject 中向前定位 n 个字节
fileObject.seekg( n, ios::cur );

// 从 fileObject 末尾向后定位 n 个字节
fileObject.seekg( n, ios::end );

// 定位到 fileObject 末尾
fileObject.seekg( 0, ios::end );
```

可以使用 ostream 成员函数 seekp 执行相同的操作。成员函数 tellg 和 tellp 用于分别返回“get”和“put”指针的当前位置。下面的语句将“get”文件位置指针值赋给类型为 long 的变量 location：

```
location = fileObject.tellg();
```
