# Predefined Function Objects of the Standard Template Library

Many predefined function objects can be found in the header <functional>. Figure 20.41 lists several of the STL function objects, which are all implemented as class templates. We used the function object less< T > in the set, multiset and priority_queue examples, to specify the sorting order for elements in a container.

# Using the STL Accumulate Algorithm

Figure 20.42 demonstrates the accumulate numeric algorithm (discussed in Fig. 20.30) to calculate the sum of the squares of the elements in a vector. The fourth argument to accumulate is a binary function object (that is, a function object for which operator() takes two arguments) or a function pointer to a binary function (that is, a function that takes two arguments). Function accumulate is demonstrated twice—once with a function pointer and once with a function object.
