# 8.1 What You Need

+   1. An Ethernet shield for the Arduino
+   2. An TMP36 temperature sensor
+   3. A PIR infrared motion sensor
+   4. A breadboard
+   5. Some wires
+   6. An Arduino board such as the Uno, Duemilanove, or Diecimila
+   7. A USB cable to connect the Arduino to your computer
