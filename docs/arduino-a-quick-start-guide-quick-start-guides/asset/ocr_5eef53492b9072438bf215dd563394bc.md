# Creating Games with the Arduino

You can use the Arduino to build more than your own cool game controllers. You can also use it to build some cool games. With the right extension shields, you can even turn an Arduino into a powerful gaming console.* It’s pricey, but suddenly your Arduino has a 320x200 pixel OLED touch screen, an analog stick, two buttons, and even an vibration motor for force feedback effects.

While looking for a cheaper solution, someone built a Super Mario Bros clone with minimal hardware requirements.† It’s a perfect example of the unbelievable creativity that the Arduino sets free.
