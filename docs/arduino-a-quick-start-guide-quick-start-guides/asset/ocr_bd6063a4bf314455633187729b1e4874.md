Now that you're familiar with the Arduino IDE, let's do some program- ming. We'll make the Arduino talk to the outside world.



Arduino makes many stand-alone applications possible—projects that do not involve any additional computers. In such cases you need to connect the Arduino to a computer once to upload the software, and after that, it needs only a power supply. More often, people use the Arduino to enhance the capabilities of a computer using sensors or by giving access to additional hardware. Usually, you control external hardware via a serial port, so it is a good idea to learn how to communicate serially with the Arduino.
