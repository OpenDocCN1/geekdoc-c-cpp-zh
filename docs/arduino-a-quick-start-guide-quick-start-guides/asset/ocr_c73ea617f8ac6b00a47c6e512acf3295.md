```
void drawPaddle() {
    int x = xpos - PADDLE_WIDTH / 2;
    int y = height - (PADDLE_HEIGHT + MARGIN);
    strokeWeight(1);
    fill(128);
    rect(x, y, PADDLE_WIDTH, PADDLE_HEIGHT);
}
```

As you can see, the ball is nothing but a circle, and the bricks and the paddle are simple rectangles. To make them look more appealing, we give them a nice border.

The update() function is very important, because it updates the game's state—it checks for collisions, moves the ball, and so on:

```
void updateGame() {
    if (ballDropped()) {
        initBall();
        paused = true;
    } else {
        checkBrickCollision();
        checkWallCollision();
        checkPaddleCollision();
        px += vx;
        py += vy;
    }
}
```
