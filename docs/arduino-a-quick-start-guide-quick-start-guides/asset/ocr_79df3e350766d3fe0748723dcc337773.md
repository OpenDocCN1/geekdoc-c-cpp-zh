Where available, you can also plug them into sockets as we have them on the Arduino or on breadboards (you'll learn more about breadboards in Section 3.2, Working with Breadboards, on page 64).

In Figure 1.12, on the following page, you can see how to attach an LED to an Arduino. Put the short connector of the LED to the ground pin (GND) and the longer one to pin 13. You can do that while the blink sketch is still running. Both the status LED and the external LED will start to blink.

Make absolutely sure that you're using pin 13! If you connect the LED to any other pin, it will probably be destroyed. The reason is that pin 13 has an internal resistor that the other pins don't have (you'll learn more about this in Chapter 3, Building Binary Dice, on page 63).
