The following parameters control a serial communication:

+   - A *start bit* indicates the beginning of a data word and is used to synchronize transmitter and receiver. It is always 0.
+   - A *stop bit* tells us when the last data bit has been sent and separates two consecutive data words. Depending on the particular protocol agreement, there can be more than one stop bit, but that happens rarely.
+   - Information is transferred as binary *data bits*; that is, if you'd like to transmit the letter M for example, you have to turn it into a number first. Several character set encodings are available, but when working with the Arduino, the ASCII encoding fits best. In ASCII, an uppercase M is encoded as the decimal number 77, which is 01001101 in binary. This is the bit sequence that eventually gets transmitted.
+   - The *parity bit* indicates whether the number of 1s in the data has been odd or even. This is a simple error checking algorithm that is rarely used and that stems from a time when network connections have been less reliable than they are today.
