# 8.9 Bringing It All Together

With our PassiveInfraredSensor and SmtpService classes, it’s a piece of cake to build an emailing burglar alarm. Connect the PIR sensor to the Ethernet shield, as shown in Figure 8.10, and upload the following code to your Arduino:

```
Download Ethernet/BurglarAlarm/burglar_alarm.h

Line 1 #ifndef __BURGLAR_ALARM_H__
#define __BURGLAR_ALARM_H__

#include "pir_sensor.h"
#include "smtp_service.h"

class BurglarAlarm {
  PassiveInfraredSensor _pir_sensor;
  SmtpService           _smtp_service;

  void send_alarm() {
    Email email(
      "arduino@example.com",
      "info@example.net",
      "Intruder Alert!",
      "Someone's moving in your living room!"
    );
    _smtp_service.send_email(email);
  }
}
```
