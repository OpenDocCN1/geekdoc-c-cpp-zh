Finally, there is another class of problems, between the two here given, for which the approximation ratio is about log n SET COVER is an example.

(A humbling reminder: All this is contingent on the assumption P ≠ NP. Failing this, this hierarchy collapses down to P, and all NP-complete optimization problems can be solved exactly in polynomial time.)

A final point on approximation algorithms: often these, or their variants, perform much better on typical instances than their worst-case approximation ratio would have you believe.

# 9.3 Local search heuristics

Our strategy for coping with NP-completeness is inspired by evolution (which is, after all, the world's best-tested optimization procedure)—by its incremental process of introducing small mutations, trying them out, and keeping them if they work well. This paradigm is called local search and can be applied to any optimization task. Here is how it looks for a minimization problem.

```
let s be any initial solution
while there is some solution s' in the neighborhood of s
  for which cost(s') < cost(s): replace s by s'
s s
```

On each iteration, the current solution is replaced by a better one to close, in its neighborhood. This neighborhood structure is something we impose upon the problem and is the central design decision in local search. As an illustration, let's revisit the traveling salesman problem.
