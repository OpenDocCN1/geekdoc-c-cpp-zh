+   65. Consider the 3-PARTITION problem. Given integers $a_1, \dots, a_n$, we want to determine whether it is possible to partition $\{1, \dots, n\}$ into three disjoint subsets $I, J, K$ such that

> $\sum_{i \in I} a_i = \sum_{j \in J} a_j = \sum_{k \in K} a_k = \frac{1}{3}$

For input (1, 2, 3, 4, 5, 8) the answer is yes, because there is the partition (1, 8), (4, 5), (2, 3, 4). On the other hand, for input (2, 3, 5) the answer is no.

Devise and analyze a dynamic programming algorithm for 3-PARTITION that runs in time polynomial in $n$ and $a_i$.
