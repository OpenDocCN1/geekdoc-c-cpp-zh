This loop takes a different amount of time for each vertex, let's consider all vertices together. The total work done in step 1 is O(|V|). In step 2, the course of the entire DFS, each edge (x, y) ∈ E is examined twice, once during exploring (x) and once exploring (y). The overall time for step 2 is therefore O(|E|) and the depth-first search has a running time of O(|V| + |E|), linear in the size of its input. This is as efficient as we possibly hope for, since it takes long enough just to read to the adjacency list.

# 3.2.3 Connectivity in undirected graphs

An undirected graph is connected if there is a path between any pair of vertices. The graph of Figure 3.6 is not connected because, for instance, there is no path from A to K. However, it has three disjoint connected regions, corresponding to the following sets of vertices:

> {A, B, E, I, J} {C, D, G, H, K, L} {F}.

These regions are called connected components: each of them is a subgraph that is internally connected but has no edges to the remaining vertices. When explore is started at a particular vertex, it identifies precisely the connected component containing that vertex. Each time the DFS outer loop calls explore, a new connected component is picked out.
