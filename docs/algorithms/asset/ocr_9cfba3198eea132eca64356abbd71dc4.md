# 7.6.1 Vertices and neighbors in $n$-dimensional space

Figure 7.12 recalls an earlier example. Looking at it closely, we see that each *vertex* is the unique point at which some subset of hyperplanes meet. Vertex A, for instance, the sole point at which constraints ②, ③ and ⑦ are satisfied with equality. On the other hand, the hyperplanes corresponding to inequalities ④ and ⑥ do not define a vertex, because their intersection is not just a simple point but an entire line.

Let's make this definition precise.

> Pick a subset of the inequalities. If there is a unique point that satisfies them with equality, and this point happens to be feasible, then it is a vertex.

How many equations are needed to uniquely identify a point? When there are $n$ variables, we need at least $n$ linear equations if we want a unique solution. On the other hand, having more than $n$ equations is redundant: at least one of them can be rewritten as a linear combination of the others and can therefore be disregarded. In short,

Each vertex is specified by a set of $n$ inequalities.³

A notion of *neighbor* now follows naturally.

Two vertices are *neighbors* if they have $n-1$ defining inequalities in common.
in Figure 7.12, for instance, vertices A and C share the two defining inequalities ③, ⑦ and are thus neighbors.

# 7.6.2 The algorithm

On each iteration, simplex has two tasks:

+   1. Check whether the current vertex is optimal (and if so, halt).
2. Determine where to move next.

As we will, both tasks are easy if the vertex happen to be at the origin. And if the vertex is elsewhere, we will transform the coordinate system to move it to the origin!
First's see why the origin is so convenient. Suppose we have generic LP

```
max cᵀx
Ax \le b
x \ge 0
```

where x is the vector of variables, x = $(x_1, \dots, x_n)$. The origin is feasible.
Then it is certainly a vertex, since it is the unique point at which the $n$ inequalities $\{x_i \ge 0, \dots, x_n \ge 0\}$ are tight. Now let's solve our two tasks. Task 1:

The origin is optimal if and only if all $c_i \le 0$.

> ³There is one tricky issue here. It is possible that the same vertex might be generated by different subsets of inequalities. In Figure 7.12, vertex B is generated by (②, ③, ④, ⑤), but also by (②, ⑤, ⑥). Such vertices are called *degenerate* and require special consideration. Let's assume for the time being that they exist, that they don't, and we will return to them later.
