Suppose that the two boys $b_0$ and $b_1$ and the two girls $g_0$ and $g_1$ are not involved in any other triples. (The four pets $p_0, \dots, p_3$ will of course belong to other triples as well; for otherwise the instance would trivially have no solution.) Then matching-must contain either the two triples $(b_0, g_0, p_1), (b_1, g_1, p_2)$ or the two triples $(b_0, g_0, p_1), (b_1, g_1, p_3)$, because these are the only ways in which these two boys and girls can find any match. Therefore, this "gadget" has two possible states: it behaves like a Boolean variable!

To transform an instance of $3	ext{sat}$ we start by creating a copy of the preceding gadget for *each* variable $x$. Call the resulting nodes $p_{x1}, b_{x0}, g_{x1}$, and so on. The intended interpretation is that $x$ is matched with girl $g_{x1}$ if $x = 	ext{true}$, and with girl $b_{x0}$ if $x = 	ext{false}$.

We next must create three clauses. For each clause, $c = (x \vee \overline{y} \vee 	ext{z})$, introduce a new boy $b_c$ and a new girl $g_c$. They will be involved in three triples, one for each literal. And the pets in these triples must reflect the three whereby the clause can be satisfied: (1) $x = 	ext{true}$, (2) $y = 	ext{false}$, (3) $z = 	ext{true}$. For (1), we have the triple $(b_c, g_x, p_{x1})$, where $p_{x1}$ is the pet in the gadget for $x$. Here is where we use $p_1$: if $x = 	ext{true}$, then $b_0$ is matched with $g_1$ and $g_0$, and so $p_0$ and $p_2$ are taken. In which case $b_c$ and $g_c$ can be matched with $p_1$. If $x = 	ext{false}$, then $p_1$ and $p_3$ cannot be accommodated this way. We do the same thing for the other two literals of the clause, which yields triples involving $b_c$ and $g_c$ with either $p_0$ or $p_2$ (for the negated variable $y$) and with $p_{23}$ (for variable $z$).

We have to make sure that for every occurrence of a literal in a clause $c$ there is a different pet to match with $b_c$ and $g_c$. This is by an earlier reduction we can assume that no literal appears more than twice, and so each variable gadget has enough pets, two, for negated occurrences and two for unnegated.
