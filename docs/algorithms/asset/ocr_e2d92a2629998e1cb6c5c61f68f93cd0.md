three smaller subproblems $E(i-1, j), E(i, j-1), E(i-1, j-1)$. We have no idea
which of them is the right, so need to try all and pick the best:

```
$E(i, j) = \min[1+E(i-1, j), 1+E(i, j-1), \text{diff}(i, j) + E(i-1, j-1)]$
```

where difference $\text{diff}(i, j)$ is defined to be 0 if $x[i]=y[j]$ and otherwise.

For instance, computing the edit distance between EXPONENTIAL and
YNOMIAL, $E(4,3)$ corresponds to the prefixes EXPO and POL. The rightmost column of their best alignment must be one of the following:

0 0 or 0

L L

Thus, $E(4,3) = \min[1+E(3,3), 1+E(4,2), 1+E(3,2)]$.

The answers to all the subproblems $E(i, j)$ form a two-dimensional table, as in
Figure 6.4. In what order should these subproblems be solved? Any order is fine,
as long as $E(i-1, j), E(i, j-1)$, and $E(i-1, j-1)$ are handled before $E(i, j)$.
For instance, we could fill the table row at a time, from top to bottom
row, and moving left to right across each row. Alternatively, we could fill it
by column. Both methods would ensure that by the time we get around
computing a particular table, all the entries we need are already filled
