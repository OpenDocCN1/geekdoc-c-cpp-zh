For instance, if x = 10110102 (the subscript 2 means “binary”) then x_L = 10112, x_s = 01102, and x = 10112 × 2⁴ + 01102. The product of x and y can then be written

> $xy = (2^{n/2}x_L + x_s)(2^{n/2}y_L + y_s) = 2^nx_Ly_L + 2^{n/2}(x_Ly_s + x_sy_L) + x_sy_s$.

We compute xy via the expression on the right. The additions take linear time, as do the multiplications by powers of2 (which are merely left-shifts). The significant operations are the four n/2-bit multiplications, x_L, x_s, y_L, y_s; we can handle this by four recursive calls. Our method for multiplying n-bit numbers starts by making recursive calls to multiply these pairs of n/2-bit numbers (four subproblems of half the size), and then evaluates the preceding expression in O(n) time. For the overall running time on n-bit inputs, we get the recurrence relation

$T(n) = 4T(n/2) + O(n).

We will see general strategies for solving such equations. In the meantime, this particular works out to O(n²), the same running as the traditional grade-school multiplication technique.
