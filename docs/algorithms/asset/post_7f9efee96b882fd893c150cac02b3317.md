- (a) Show that it is possible to move from any spanning tree $T$ to any other spanning tree $T'$ by performing a series of edge-swaps, that is, by from neighbor to neighbor. At how many edge-swaps are needed?

- (b) Show if $T'$ is an MST, then it is possible to choose these swaps so that the costs of the spanning trees encountered along the way are nonincreasing. In other words, if the sequence of spanning trees encountered

$T = T_0 \to T_1 \to T_2 \to \dots \to T_k = T'$

then $cost(T_{i+1}) \le cost(T_i)$ for all $i < k$.

- (c) Consider the following local search algorithm which is given as an input an undirected graph with distinct edge weights.

Let $T$ be any spanning tree of $G$
while there is an edge-swap $(e, e')$ that reduces
$cost(T)$:

$T \leftarrow T + e - e'$

return $T$

Show that this procedure always returns a minimum spanning tree. how many iterations does it take?

9.8. In the MAX SAT problem, we are given a set of clauses, and we want to find an assignment that satisfies as many of them as possible.

- (a) Show that this problem can be solved in polynomial time, then so can SAT.
- (b) Here's a very naive algorithm.
for each variable:
  set its value to either 0 or 1 by flipping a coin

Suppose the input has $m$ clauses, of which the $j$th has $k$ literals. Show that the expected number of clauses satisfied by this simple algorithm is

$\sum_{i=1}^m (1 - \frac{1}{2^k}) \geq \frac{m}{2}$.

In other words, this is a 2-approximation in expectation! And if the clauses all contain $k$ literals, then this approximation improves to $1 + 1/(2^k-1)$.

- (c) Can you make this algorithm deterministic? (Hint: Instead of flipping a coin for each variable, select the value that satisfies the most-as-unsatisfied clauses. What fraction of the clauses is satisfied?)

9. In the MAX CUT problem we are given an undirected graph $G=(V,E)$ with weight $w(e)$ on each edge, and we wish to separate the vertices into two sets $S$ and $V-S$ such that the total weight of the edges between the two sets is as large as possible.

For each $S \subseteq V$, define $w(S)$ to be the sum of $w_{uv}$ over all edges $[u,v]$ such that $|S \cap \{u,v\}|=1$. MAX CUT is about maximizing $w(S)$ over all subsets of $V$.

Consider the local search algorithm for MAX CUT:

start with $S \subseteq V$
while there is a subset $S' \subseteq V$ such that
$(S-S') \cup (S'-S)=1$ and $w(S') > w(S)$ do:
  set $S=S'$

- (a) Show that this is an approximation algorithm for MAX CUT with ratio 2.
- (b) But is it a polynomial-time algorithm?

# 10.1 Qubits, superposition, and measurement

## 10.1 Qubits, superposition, and measurement

The whole concept of a superposition suggests that the electron does not make up its mind about whether it is in the ground or excited state, and the amplitude α₀ is a measure of its inclination toward the ground state. Continuing along this line of thought, it is tempting to think of α₀ as the probability that the electron is in the ground state. But then how are we make sense of the fact that α₀ can be negative, or even imaginary?

This linear superposition of the electron’s state however is the private world of the electron. For to get a glimpse of its state we must make a *measurement*, and when we do, we get a silly bit of information—0 or 1. If the electron is α₀|0⟩ + α₁|1⟩, then the outcome of the measurement is 0 with probability |α₀|² and

The superposition principle states if a quantum system can be in one of two states, then it can also be in *any linear* of those states. For instance, the state of the electron could be ½|0⟩ + ½1⟩ or ½|0⟩ − ½1⟩ or an infinite number of combinations of the form α₀|0⟩ + α₁|1. The coefficient α₀ is called the *amplitude* of the state, and similarly with α₁. And—if things aren’t already enough—the α’s be complex numbers, as long as they are normalized so that |α₀|² + |α₁|² = 1. For example, ½|0⟩ + i|1⟩ (where i is the imaginary unit, √−1) is a perfectly valid quantum state! Such a superposition, α₀|0⟩ + α₁|1⟩ is a basic unit of encoded information in quantum computers (Figure 10.1). It is called a *qubit* (pronounced “cubit”).
