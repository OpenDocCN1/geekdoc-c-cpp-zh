# 9.2 Approximation algorithms

Let's understand this relation. Removing any edge from a traveling salesman tour leaves a path through all the vertices, which is a spanning tree. Therefore,

TSP cost ≥ cost of this path ≥ MST cost.

Now, we somehow need to use the MST to build a building salesman tour. If we use each edge twice, then by following the shape of the MST we end up with a tour that visits all the cities, some of them than once. Here's an example, with the MST on the left and the resulting tour on the right (the numbers show the order in which the edges are taken).

![](bbox=[0.045, 0.273, 0.715, 0.465])

There, this tour has a length at most twice the MST cost, which as we've already seen is at most twice the TSP cost.

This is the result we wanted, but we aren't quite done because our tour visits cities multiple times and is therefore not legal. To fix the problem, the tour should simply skip any city it is about to revisit, and move directly to the new city in its list:

![](bbox=[0.193, 0.638, 0.563, 0.866])

By the triangle inequality, these bypasses can only make the overall tour shorter.
