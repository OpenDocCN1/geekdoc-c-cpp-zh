## 8.3 The Reductions

We shall now see that the search problems of Section 8.1 can be reduced to one another as depicted in Figure 8.7. As a consequence, they are all NP-complete.

Before we tackle the specific reductions in the tree, let us warm up by mentioning two versions of the Rudrata problem.

Rudrarata (s, t)-Path $\longrightarrow$ Rudrata Cycle

Recall the RUDRATA CYCLE problem: given a graph, is there a cycle that passes through each vertex exactly once? We can also formulate the closely related RUDRATA (s, t)-PATH problem, in which two vertices $s$ and $t$ are specified, and we want a path starting at $s$ and ending at $t$ that goes through each vertex exactly once. It is possible that RUDRATA CYCLE is easier than RUDRATA (s, t)-PATH? We will show by a reduction that the answer is no.

## 8.3 The reductions

The reduction maps an instance $(G = (V, E), s, t)$ of RUDRATA $(s, t)$-PATH into an instance $G' = (V', E')$ of RUDRATA CYCLE as follows: $G'$ is simply $G$ with an additional vertex $x$ and two new edges $(s, x)$ and $(x, t)$. For instance:

![](img/3dd1f1364df8f87b80683fc32a15b999_258_0.png)

So $V' = V \cup \{x\}$ and $E' = E \cup \{s, x\}, \{x, t\}$. How do we recover a Rudrata $(s, t)$-path in $G$ given any Rudrata cycle in $G$? Easy, just delete the edges $\{s, x\}$ and $\{x, t\}$ from the cycle.

### RUDRATA $(s, t)$-PATH

| Instance $G = (V, E)$ nodes $s, t$ | $G' = (V', E')$ RUDRATA CYCLE | Solution: cycle Delete edges $\{s, x\}, \{x, t\}$ | Solution: path |
|---|---|---|---|
| | Add node $x$ and edges $\{s, x\}, \{x, t\}$ | | No solution | No solution |

To confirm the validity of this reduction, we have to show that it works in the case of either output being decided.

- 1. When the instance of RUDRATA CYCLE has a solution. Since the new vertex $x$ has two neighbors, $s$ and $t$, and any Rudrata cycle in $G'$ must consecutively traverse the edges $\{t, x\}$ and $\{x, s\}$. The rest of the cycle then traverses every other vertex from $s$ to $t$. Thus deleting the two edges $\{t, x\}$ and $\{x, s\}$ from the Rudrata cycle gives a Rudrata path from $s$ to $t$ in the original graph $G$.
- 2. When the instance of RudR CYCLE does not have a solution. In this case we show that the original instance of RUDRATA $(s, t)$-PATH cannot have a solution either. It is easier to prove the contrapositive, that is, to show that if there is a Rudrata $(s, t)$-path in $G$, then there is also a Rudrata cycle in $G'$. But this is easy: just add the two edges $\{t, x\}$ and $\{x, s\}$ to the Rudrata path to close the cycle.

One last detail, but crucially easy to check, that the pre- and postprocessing functions take polynomial in the size of the instance $(G, s, t)$.

It is also possible to go in the other direction and reduce RUDR CYCLE to RUDRATA $(s, t)$-PATH. Together, these reductions demonstrate that the two Rudrata variants are in the same problem—which is not too surprising, given that their descriptions are almost the same.

## 3SAT $\rightarrow$ INDEPENDENT SET

One can frankly think of two different problems. In 3SAT the input is a set of clauses, each with three or fewer literals, for example

```
$(x \vee y \vee z) (x \vee y \vee z) (x \vee y \vee z) (x \vee y \vee z)$
```

and the aim is to find a satisfying truth assignment. In INDEPENDENT SET the input is a graph and a number $g$, and the problem is to find a set of pairwise non-adjacent vertices. We must somehow relate Boolean logic with graphs!

Let us. To form a satisfying truth assignment we must pick one literal from each clause and give it the value true. But our choices must be: if we choose $x$ in one clause, we cannot choose $x$ another. Any consistent choice of literals, from each clause, specifies a truth assignment (variables for which neither literal has been chosen can take either value).

So, let us represent a clause, say $(x \vee y \vee z)$, by a triangle, with vertices labeled $x$, $y$, $z$. Why triangle? Because a triangle has three vertices maximally connected, and forces us to pick only one of them for the independent set. Repeat this construction for all clauses—a clause with two literals will be represented by an edge joining the literals. (A clause with one literal is silly and can be removed in a preprocessing step, since the value of the literal is determined.) In the resulting graph, an independent set has to pick at most one literal from each group (clause). To enforce exactly one from each clause, take the goal $g$ to be the number of clauses; in our example, $g = 4$.

All that is missing is now a way to prevent us from choosing opposite literals (that is, both $x$ and $\bar{x}$) in different clauses. This is easy: put an edge between two vertices that represent opposite literals. The resulting graph for our example is shown in Figure 8.8.

Let's recap the reconstruction. Given an instance $I$ of 3SAT, we create an instance $(G, g)$ of INDEPENDENT SET as follows.

- Graph G has a triangle for each clause (or just an edge, the clause has two literals), with vertices labeled by the clause's literals, and additional edges between any two vertices that represent opposite literals.
- The goal g is set to the number of clauses.

Clearly, this construction takes polynomial time. However, recall that for a reduction we do not need an efficient way to map instances of the first problem to instances of the second (the function $f$ in the diagram on page 245), but also a way to reconstruct a solution to the first instance from any solution of the second (the function $h$). As always, there are two things to show.

- 1. Given an independent set $S$ of $G$, it is possible to recover a satisfying assignment to $I$. For any clause, $S$ contains at most one vertex of its triangle; set the corresponding literal to true. If no vertex is in $S$, set the literal arbitrarily. Since $S$ is an independent set, it cannot contain both $x$ and $\bar{x}$, so the assignment is consistent.
- 2. If $G$ has no independent set of size $g$, then $I$ is unsatisfiable. If $I$ has a satisfying assignment, pick one true literal from each clause and select the corresponding vertices in $G$. Since the assignment is consistent, no two vertices are adjacent, so $S$ is an independent set of size $g$.
