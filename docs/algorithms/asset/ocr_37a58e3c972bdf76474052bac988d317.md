5.27. Graphs with prescribed degree sequences. Given a list of $n$ positive integers $d_1, d_2, \dots, d_n$, we want to efficiently determine whether there exists an undirected graph $G = \{V, E\}$ whose nodes have degrees precisely $d_1, d_2, \dots, d_n$. That is, if $V = \{v_1, \dots, v_n\}$, then the degree of $v_i$ is exactly $d_i$. We call $(d_1, \dots, d_n)$ the degree sequence of $G$. This graph should not contain self-loops (with endpoints to the same node) or edges between the same pair of nodes.

+   (a) Given an example of $d_1, d_2, d_3, d_4$ where all $d_i \leq 3$ and $d_1 + d_2 + d_3 + d_4$ is even, but for which no graph with degree sequence $(d_1, d_2, d_3, d_4)$ exists.
(b) Suppose that $d_1 \geq d_2 \geq \dots \geq d_n$ and there exists a graph $G = (V, E)$ with degree sequence $(d_1, \dots, d_n)$. We want to show that there must exist a graph that has this sequence and in addition the neighbors of $v_1$ are $v_2, v_3, \dots, v_{d_1+1}$. The idea is to transform $G$ into a graph with the desired additional property.

+   i. suppose the neighbors of $v_1$ in $G$ are not $v_2, v_3, \dots, v_{d_1+1}$. Show that there exists $i < j \leq n$ and $u, v \in V$ such that $[v_1, u], [v_1, v] \notin E$ and $[u, v] \in E$ and E'.
ii. Specify the changes you would make to obtain a new graph $G' = (V, E')$ with the same degree sequence as $G$ and $(v_1, v_1) \in E'$.
iii. Now there must be a graph with the given degree sequence in which $v_1$ has neighbors $v_2, v_3, \dots, v_{d_1+1}$.

+   (c) Using the result from part (b), describe an algorithm that on $d_1, \dots, d_n$ (not necessarily sorted) decides whether there exists a graph with this degree sequence. Your algorithm should run in polynomial time in $n$.
