More generally, if $A(x) = a_0 + a_1x + \dots + a_dx^d$ and $B(x) = b_0 + b_1x + \dots + b_dx^d$, their product $C(x) = A(x) \cdot B(x) = c_0 + c_1x + \dots + c_{2d}x^{2d}$ has coefficients

```
$c_k = a_0b_k + a_1b_{k-1} + \dots + a_kb_0 = \sum_{i=0}^k a_ib_{k-i}$
```

(for $i > d$, take $a_i$ and $b_i$ to be zero). Computing $c_k$ from this formula takes $O(d)$ steps, and finding $2d+1$ coefficients would therefore require $\Theta(d^2)$ time. Can we possibly multiply polynomials faster than this?

The solution we will develop, the fast Fourier transform, has revolutionized—indeed, defined—the field of signal processing (see the following box). Because of its importance, and its wealth of insights from different fields of study, we will approach it a little less leisurely than usual. The reader who wants just the core algorithm can skip directly to Section 2.6.4.

# 2.6.1 An alternative representation of polynomial multiplication

To arrive at a fast algorithm for polynomial multiplication we take inspiration from an important property of polynomials.

**Fact** A degree-$d$ polynomial is uniquely characterized by its values at any $d+1$ distinct points.

A familiar instance of this is that "any two points determine a line." We will later see why the general statement is true (page 64), but for the time being gives us an alternative representation of polynomials. Fix any distinct points $x_0, \dots, x_d$. We can specify a degree-$d$ polynomial $A(x) = a_0 + a_1x + \dots + a_dx^d$ by either one of the:

+   1. Its coefficients $a_0, a_1, \dots, a_d$
2. The values $A(x_0), A(x_1), \dots, A(x_d)$

Of these two representations, the second is more attractive for polynomial multiplication. Since the product $C(x)$ has degree $2d$, it is completely determined by its values at any $d+1$ points. And its value at any given point $z$ is easy enough to figure out, $A(z)$ times $B(z)$. Thus polynomial multiplication takes linear time in the value representation.

The problem is that we expect the input polynomials, and also their product, to be specified by coefficients. So we need to translate from coefficients to values—then multiply the polynomial at the chosen points—in the value representation, and finally translate back to coefficients, a process called *interpolation*.

| Coefficient representation | Evaluation | Value representation |
|---|---|--|
| $a_0, a_1, \dots, a_d$ | Interpolation | $A(x_0), A(x_1), \dots, A(x_d)$ |
