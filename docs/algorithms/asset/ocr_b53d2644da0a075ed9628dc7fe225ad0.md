# 7.2.3 A closer look at the algorithm

All we know so far of the simplex algorithm is the vague geometric intuition that it keeps making moves on the surface of a convex feasible region, successively improving the objective function until it reaches the optimal solution. Once we have studied it in more detail (Section 7.6), we will be in a position to understand exactly how it handles LPs, which is as useful as a source of inspiration for designing *direct* max-flow algorithms.

It turns out that the behavior of simplex is an elementary interpretation:

+   - Choose an appropriate path from s to t, and increase flow along the edges of this path as much as possible.

Figure 7.5(a) shows an example in which simplex halts after two iterations. The final flow has size 2, which is easily seen to be optimal.

There just one complication. What if we had initially chosen a different path, the one in 7.5(c) which gives only one unit of flow and sets to cancel all flow. Simplex gets around this problem by allowing paths to *cancel existing flow*. In this particular case, it would subsequently choose the path of Figure 7.5(f). Edge (b, a) of this path was not in the original network and has the effect of canceling flow previously assigned to edge (a, b).

To summarize, in each iteration simplex looks for an $s - t$ path whose edges $(u, v)$ can be of two types:

+   - $(u, v)$ is in the original network, and is not yet at full capacity.
- The reverse edge $(v, u)$ is in the original network, and there is some flow along it.

If the current flow is $f$, then it can handle up to $c_{uv} - f_{uv}$ additional units of flow, and in the second case, to $f_{vu}$ additional units (canceling all or part of the flow on $(u, v)$). These flow-increasing opportunities can be captured in a *residual network* $G^f = (V, E^f)$, which has exactly the two types of edges listed, with residual capacities $c^f$:

```
$\begin{cases} c_{uv} - f_{uv} & \text{if } (u, v) \in E \text{ and } f_{uv} < c_{uv} \ f_{vu} & \text{if } (u, v) \in E \text{ and } f_{vu} > 0 \end{cases}$
```

Thus we can equivalently think of simplex as choosing an $s - t$ path in the residual network.
