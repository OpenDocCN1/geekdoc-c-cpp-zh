# Is your social security number a prime?

The numbers 7, 17, 19, 71, and 79 are primes, but how about 717-19-7179? Telling whether a large number is a prime seems tedious because there are far many candidate factors to try. However, there are some clever tricks to speed up the process. instance, you can omit even-valued candidates after you have eliminated the number 2. You can actually omit all candidates except that are themselves prime.

In fact, a little further thought will convince you that you can proclaim N prime as soon as you have rejected all candidates up to √N, for if N can be factored as N = K·L, then it is impossible for both factors to exceed √N.

We seem to be making progress! Perhaps by omitting more and more candidate factors, a truly efficient primality test can be discovered.

We carry this example a bit further. From the picture, we can conclude

{1, 2, ..., 6} = {3·1 mod 7, 3·2 mod 7, ..., 3·6 mod 7}.

Multiplying all the numbers in each representation gives 6! ≡ 3⁶ · 6! (mod 7), and dividing by 6! we get 3⁶ ≡ 1 (mod 7), exactly the result we wanted in the case a=3, p=7.

Now let generalize this argument to other values of a and p, with S={1, 2, ..., p−1}. We'll prove that the elements of S are multiplied by a modulo p, the resulting numbers are all distinct and nonzero. And since they lie in the range [1, p−1], they must simply be a permutation of S.
