7.19. Suppose someone presents you with a solution to a max-flow problem on some network. Consider a *linear* time algorithm to determine whether the solution indeed gives a maximum flow.

7.20. Consider the following generalization of the maximum flow problem. You are given a directed network $G=(V,E)$ with capacities $\{c_e\}$. Instead of a single $(s,t)$ pair, you are given multiple pairs $(s_1, t_1), (s_2, t_2), \dots, (s_k, t_k)$, where $s_i$ and $t_i$ are nodes of $G$. You are also given $d_1, \dots, d_k$. The goal is to find flows $f^{(1)}, \dots, f^{(k)}$ with the following properties:

- $f^{(i)}$ is a valid flow from $s_i$ to $t_i$.
- For each edge $e$, the total flow $f^{(1)} + f^{(2)} + \dots + f^{(k)}$ does not exceed the capacity $c_e$.
- The size of each flow $f^{(i)}$ is at least $d_i$.
- The size of *total* flow (the sum of the flows) is as large as possible. How would you solve this?

7.21. An edge of a network is *critical* if increasing the capacity of that edge results in an increase in maximum flow. Give an efficient algorithm that finds all critical edges in a network.

7.22. In a particular network $G=(V,E)$ whose edges have integer capacities $c_e$, we have already found the maximum flow $f$ from node $s$ to node $t$. However, we now find that one of the capacity values was used wrong: for edge $(u,v)$ we used $c_{uv}$ whereas it should have been $c_{uv}-1$. This is because the flow $f$ uses that edge at full capacity: $f_{uv}=c_{uv}$. We could redo the flow computation from scratch, but there is a faster way. Show how a new optimal flow can be computed in $O(|V|+|E|)$.

7.26. In a satisfiable system of linear inequalities:
$a_{11}x_1 + \dots + a_{1n}x_n \le b_1$
$a_{m1}x_1 + \dots + a_{mn}x_n \le b_m$

we describe the $j$th inequality as forced-equal if it is forced-equal in all satisfiable solutions. Equivalently, $\sum a_{ij}x_j = b_i$ for all $i$ where the $i$th inequality is forced-equal. For example, in
$x_1 + x_2 \le 2$
$-x_1 + x_2 \le 0$
$x_1 - x_2 \le 0$
$-x_1 - x_2 \le -2$
the first two inequalities are forced-equal, but the third is not.

- (a) Show that the number of forced-equal inequalities in a system is at most $n$.
- (b) If a solution is forced-equal for all $m$ inequalities, is it unique?
- (c) Give an algorithm to determine which inequalities are forced-equal in polynomial time.
