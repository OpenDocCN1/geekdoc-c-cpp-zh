The numbers $a \cdot i \pmod p$ are distinct because $a \cdot i \equiv a \cdot j \pmod p$, dividing both sides by $a$ gives $i \equiv j \pmod p$. They are nonzero $a \cdot i \equiv 0$ similarly implies $i \equiv 0$. (And we can divide by $a$, because by assumption it is nonzero and relatively prime to $p$).

We now have two ways to write S:

$S = \{1, 2, \dots, p-1\} = \{a \cdot 1 \pmod p, a \cdot 2 \pmod p, \dots, a \cdot (p-1) \pmod p\}$.

We can multiply elements in each of these representations to get

$(p-1)! \equiv a^{p-1} \cdot (p-1)! \pmod p$.

Dividing by $(p-1)!$ (which we can do because it is relatively prime to $p$, since $p$ is assumed prime) gives us the theorem.

This theorem suggests a “factorless” test for determining whether a number $N$ is prime:

![](bbox=[0.333, 0.403, 0.952, 0.493])

The problem is that Fermat's theorem is not an if-and-only-if condition; it doesn't say what when $N$ is not prime, in these cases the preceding diagram is questionable. In fact, it is possible for a composite number $N$ to pass Fermat's test (that is, $a^{N-1} \equiv 1 \pmod N$) for certain choices of $a$. For instance, $34 = 11 \cdot 3$ is not prime, and $2^{34} \equiv 1 \pmod{34}$. Nonetheless, it might that for composite $N$, most values of $a$ will fail the test. It is indeed true, in a sense we will see many precise, and motivates the algorithm of Figure 1.7: rather than picking an arbitrary value of $i$ in advance, we should choose $\{1, \dots, N-1\}$.

# Figure 1.7 An algorithm for testing primality.

```
function primality(N)
Input: Positive integer N
Output: yes/no

Pick a positive integer a < N at random
  if a^{N-1} \equiv 1 \pmod N:
    return yes
  else:
    return no
```
