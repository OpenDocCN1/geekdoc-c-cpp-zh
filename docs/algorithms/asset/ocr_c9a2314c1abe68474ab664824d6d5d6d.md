**Figure 1.4** Modular exponentiation.

```
function modexp(x, y, N)
Input: Two $n$-bit integers $x$ and $N$, an integer exponent $y$
Output: $x^y \mod N$

if y = 0: return 1
z = modexp(x, y/2, N)
if y is even:
	return $z^2 \mod N$
else:
	return $x \cdot z \mod N$
```

We package this idea in a particularly simple form: the recursive algorithm of Figure 1.4, which works by executing, the self-evident rule

```
$x^y = \begin{cases} (x^{(y/2)})^2 & \text{if } y \text{ is even} \ x \cdot (x^{(y/2)})^2 & \text{if } y \text{ is odd.} \end{cases}$
```

In so, it closely parallels the recursive multiplication algorithm (Figure 1.1). For instance, that algorithm would compute the product $x \cdot 25$ by an analogous decomposition to the one we just saw: $x \cdot 25 = x \cdot 16 + x \cdot 8 + x \cdot 1$. Whereas for multiplication the terms $x \cdot 2'$ come from repeated doubling, for exponentiation the corresponding terms $x^2'$ are generated by repeated squaring.

Let $n$ be the size in bits of $x$, $y$, and $N$ (whichever is largest of them). As with multiplication, the algorithm will halt after $n$ recursive calls, and during each call it multiplies $n$-bit numbers (computing modulo $N$ saves us here), for a running time of $O(n^2)$.
