# 7.6 The simplex algorithm

The extraordinary power and expressiveness of linear programs would be little solution if we did not have a way to solve them efficiently. This is the role of the simplex algorithm.

At a high level, the simplex algorithm takes a set of linear inequalities and a linear objective function finds the optimal feasible point by the following strategy:

```
let $\nu$ be any vertex of the feasible region
while there is a neighbor $\nu$ of $\nu$ with better objective value:
```

```
set $\nu = \nu'$
```

In our 2D and 3D examples (Figure 7.1 and Figure 7.2), this was to visualize and make intuitive sense. But what if there are $n$ variables, $x_1, \dots, x_n$?

Any set of the $x_i$'s can be represented by an $n$-tuple of real numbers and plotted in $n$-dimensional space. A linear inequality involving the $x_i$ defines a *hyperplane* in this same space $\mathbb{R}^n$, and the corresponding linear inequality defines a *half-space*, of it. The feasible region of the linear program is specified by a set of inequalities and is therefore the intersection of the corresponding half-spaces, a convex polyhedron.
