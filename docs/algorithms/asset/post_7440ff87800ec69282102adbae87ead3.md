
## Reductions

Sometimes a computational task is sufficiently general that any subroutine for it can also be used to solve a variety of other tasks, which at glance might seem unrelated. For instance, we saw in Chapter 6 how an algorithm for finding the longest path in a dag, surprisingly, also be used for finding increasing subsequences. We describe this phenomenon by saying that the longest increasing subsequence problem reduces to the longest path in a dag. ## 7.1.4 Variants of linear programming

As evidenced in our examples, a general linear program has many degrees of freedom.

- It can be either a maximization or a minimization problem.
- Its constraints can be equations and/or inequalities.
- The variables are often restricted to be nonnegative, but they can also be unrestricted in sign.

We will now show that these various LP options can all be reduced to one another via simple transformations. Here's how.

- To turn a maximization problem into a minimization (or vice versa), multiply the coefficients of the objective function by -1.
- To turn an inequality constraint like $\sum_{i=1}^n a_ix_i \le b$ into an inequality, introduce a new variable $s$ and use

```
$$\sum_{i=1}^n a_ix_i + s = b$$
$$s \ge 0.
```

This $s$ is called the slack variable for the inequality. For justification, observe that a vector $(x_1, \dots, x_n)$ satisfies the original inequality constraint if and only if there is some $s \ge 0$ for which it satisfies the new equality constraint.

- To change an equality constraint into inequalities is easy: rewrite $ax = b$ as $ax \le b$ as the equivalent pair of constraints $ax \le b$ and $ax \ge b$.
- Finally, to deal with a variable $x$ that is unrestricted in sign, we do the following:
    - Introduce two nonnegative variables, $x^+, x^- \ge 0$.
    - Replace $x$, wherever it occurs in the constraints or the objective function, by $x^+ - x^-$.

This way, $x$ can take on any real value by appropriately adjusting the new variables. More precisely, any feasible solution to the original LP involving $x$ can be mapped to a feasible solution of the new LP involving $x^+, x^-$, and vice versa.

By applying these transformations we can reduce any LP (maximization or minimization, with both inequalities and equations, and with both nonnegative and unrestricted variables) into an LP of a much more constrained kind that we call the standard form, in which the variables are all nonnegative, the constraints are all equations, and the objective function is to be minimized.

## Matrix-vector notation

A linear function like $x_1 + 6x_2$ can be written as the dot product of two vectors

$c = (1/6)$ and $x = (x_1, x_2)$

denoted $c \cdot x$ or $c^T x$. Similarly, linear constraints can be compiled into matrix-vector form:

$$\begin{array}{rrc} x_1 & \le & 200 \\ x_2 & \le & 300 \\ x_1 + x_2 & \le & 400 \end{array} \Rightarrow \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} \le \begin{pmatrix} 200 \\ 300 \\ 400 \end{pmatrix}$$
$A \le b$

Here each row of matrix $A$ corresponds to one dot product with $x$ that is at most the value in the corresponding row of $b$. In other, if the rows of $A$ are the vectors $a_1, \dots, a_m$, then the statement $Ax \le b$ is equivalent to

$a_i x \le b_i$ for all $i = 1, \dots, m$.

With these conventions, a generic LP can be expressed as

$max \ c^T x$
$Ax \le b$
$x \ge 0$.

For example, our first linear program gets rewritten as follows:

$max \ x_1 + 6x_2$
$x_1 \le 200$
$x_2 \le 300$
$x_1 + x_2 \le 400$
$x_1, x_2 \ge 0 \quad \Rightarrow \quad min \ -x_1 - 6x_2$
$x_1 + s_1 \le 200$
$x_2 + s_2 \le 300$
$x_1 + x_2 + s_3 \le 400$
$x_1, x_2, s_1, s_2, s_3 \ge 0$
