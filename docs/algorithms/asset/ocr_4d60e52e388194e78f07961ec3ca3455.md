We claim that the values chosen are solution to the original instance of ZOE. If a variable xi has value 1, then the edge ei is not traversed, and thus all edges associated with xi on the edge must be traversed (since they are paired with C xi=0). So, in each equation exactly one of the variables appearing in it has value 1—which is the same as saying that all equations are satisfied. The other direction is straightforward well: from a solution to the instance of ZOE one easily obtains an appropriate cycle.
