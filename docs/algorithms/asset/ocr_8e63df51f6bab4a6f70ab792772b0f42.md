+   1. Given an independent set $S$ of $g$ vertices in $G$, it is possible to efficiently recover a satisfying assignment to $I$.

For any variable $x$, the set $S$ contains no vertices labeled $ar{x}$ and $x$, because any pair of vertices is connected by an edge. Assign $x$ to value $true$ if $S$ contains a vertex labeled $ar{x}$, and a value of $false$ if $S$ contains a vertex labeled $x$ (if $S$ contains neither, then assign value to $x$). Since $S$ has $g$ vertices, it must have one vertex per clause; this truth assignment satisfies those particular literals, and satisfies all clauses.

+   2. If graph $G$ has no independent set of size $g$, then the Boolean formula $I$ is unsatisfiable.

It is usually cleaner to prove the contrapositive, that if $I$ has a satisfying assignment then $G$ has an independent set of size $g$. This is easy: for each clause, pick any literal whose the satisfying assignment is $true$ (there must be at least one literal), and add the corresponding vertex to $S$. Do you see why $S$ must be independent?

$SAT \rightarrow 3SAT$

This is an interesting and common reduction, from a problem to a special case of itself. We want to show that the problem remains hard if its inputs are restricted somehow—the present case, even if all clauses are restricted to $\le 3$ literals. Such reductions modify the instance so as to get rid of the forbidden feature (clauses with $\ge 4$ literals) while keeping the instance essentially same, in that we can read off a solution to the original instance from any solution of the modified one.
