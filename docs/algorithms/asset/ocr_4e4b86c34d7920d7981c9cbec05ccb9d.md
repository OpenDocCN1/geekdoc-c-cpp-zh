In an instance of RUDRATA CYCLE WITH PAIRED EDGES we are given a graph $G = (V, E)$ and a set $C \subseteq E \times E$ of pairs of edges. We seek a cycle that (1) visits all vertices once, a Rudrata cycle, and (2) for every pair of edges, $(e, e') \in C$, traverses either $e$ or $e'$—exactly one of them. In the simple example of Figure 8.10 a solution is shown in bold. Notice that we have two or more parallel edges between two nodes—a feature that doesn't make sense in most graph problems—since the different copies of an edge can be paired with other edges in ways that do not make a difference.

Now for the reduction of ZOE to RUDRATA CYCLE. Given an instance of ZOE, $Ax=1$ where $A$ is an $m \times n$ matrix with $0-1$ entries, and thus describes $m$ equations in $n$ variables), the graph construct has the very structure shown in Figure 8.11: a cycle that connects $m+n$ collections of parallel edges. For each variable $x_i$ we have two parallel edges (corresponding to $x_i=1$ and $x_i=0$). For each equation $x_i + \dots + x_j=1$ involving $k$ variables we have $k$ parallel edges, for every variable appearing in the equation. This is the whole graph. Evidently, any Rudrata cycle in this graph must traverse the $m+n$ collections of parallel edges one by one, choosing one edge from each collection. This way, the cycle "chooses" for each variable value—0 or 1—and, for each equation, a variable appearing in it.
