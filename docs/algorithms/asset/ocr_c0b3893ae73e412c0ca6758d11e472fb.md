Let's make this more precise.

**Lemma** *Suppose independent samples are drawn uniformly from*

```
$\frac{M}{k}, \dots \frac{(k-1)M}{k}$
```

Then with probability at least $1-k/2^2$, the greatest common divisor of these samples is $M/k$.

*Proof.* The only way this can fail is if all samples are multiples of $j/k$, where $j$ is some integer greater than 1. So, fix any integer $j \ge 2$; the chance that a particular sample is a multiple of $j/k$ is at most $1/j \le 1/2$; and thus the chance that *all* the samples are multiples of $j/k$ is at most $1/2^j$.

So far we have been thinking about a particular number $j$; the probability that this bad event will happen for *some* $j \le k$ is at most equal to the *sum* of these probabilities over the different values of $j$, which is no more than $k/2^j$.

We can make the failure probability as small as we like by taking $s$ to be an appropriate multiple of $M$.

# 10.5 Quantum circuits

So quantum computers can carry out a Fourier transform exponentially faster than classical computers. But what do these computers actually look like? What is a *quantum* circuit made up of, and exactly how does it compute Fourier transforms so quickly?

10.5.1 Elementary quantum gates

An elementary quantum operation is analogous to an elementary gate either the AND or not gate in a classical circuit. It operates on either a single qubit or qubits. One of the most important examples is the Hadamard gate, denoted by H, which operates on a single qubit. On $|0\rangle$, it outputs $H(|0\rangle) = \frac{1}{\sqrt{2}}|0\rangle + \frac{1}{\sqrt{2}}|1\rangle$; and on input $|1\rangle$, $H(|1\rangle) = \frac{1}{\sqrt{2}}|0\rangle - \frac{1}{\sqrt{2}}|1\rangle$. In pictures:

```
$|0\rangle \rightarrow \mathbf{H} \rightarrow \frac{1}{\sqrt{2}}|0\rangle + \frac{1}{\sqrt{2}}|1\rangle \quad \quad |1\rangle \rightarrow \mathbf{H} \rightarrow \frac{1}{\sqrt{2}}|0\rangle - \frac{1}{\sqrt{2}}|1\rangle$
```
