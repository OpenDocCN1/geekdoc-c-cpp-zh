The correctness of Kruskal's method follows from a certain cut property, which is general enough to also justify a whole slew of other minimum spanning tree algorithms.

# 5.1.2 The cut property

Say that in the process of building a minimum spanning tree (MST), we have already chosen some edges and are so far on the right track. Which edge should we add next? The following lemma gives us lot of flexibility in our choice.

**Cut property** *Suppose edges $X$ are part of a minimum spanning tree of $G = (V, E)$. Pick any node of $S$ for which $X$ does not cross between $S$ and $V - S$, and let $e$ be the lightest edge across this partition. $X \cup \{e\}$ is part of some MST.*

A cut is any partition of the vertices into two groups, $S$ and $V - S$. What this property says is that it is always safe to add the lightest edge across any cut (that is, between a vertex in $S$ and one in $V - S$), provided $X$ has no edges across the cut.

Let's see why this holds. Edges $X$ are part of some MST; if the new edge $e$ also happens to be part of $T$, then there is nothing to prove. So assume $e$ is not in $T$. We will construct a different MST $T'$ containing $X \cup \{e\}$ by altering $T$ slightly, changing one of its edges.

Add $e$ to $T$. Since $T$ is connected, it already has a path to the endpoints of $e$, so adding $e$ creates a cycle. This cycle must also have some other edge $e'$ across the cut $(S, V - S)$ (Figure 5.2). If we now remove this edge, we are left with $T' = T \cup \{e\} - \{e'\}$, which we will show to be a tree. $T'$ is connected by Property 1, since $e'$ is a cycle edge. And it has the same number of edges as $T$; so Properties 2 and 3, it is also a tree.

$T'$ is a minimum spanning tree. Compare its weight to that of:

$$$weight(T') = weight(T) + w(e')$$
