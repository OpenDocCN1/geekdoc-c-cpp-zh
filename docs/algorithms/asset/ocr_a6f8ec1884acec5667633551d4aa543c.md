# 5.1.3 Kruskal's algorithm

We are ready to justify Kruskal's algorithm. At any moment, the edges it has already chosen form a partial solution, a collection of connected components each of which has a tree. The next edge $e$ is to be connects two of these components; call them $T_1$ and $T_2$. Since $e$ is the lightest edge that doesn't produce a cycle, it is certain to be the lightest edge between $T_1$ and $V - T_1$ and therefore satisfies the cut property.
