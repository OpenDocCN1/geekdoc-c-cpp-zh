Here's an instance of SAT looks like:

```
(x ∨ y) (x ∨ y) (y ∨ z) (z ∨ x) (x ∨ y ∨ z)
```

This is a Boolean formula in conjunctive normal form (CNF). It is a collection of
clauses (the parentheses), each consisting of the disjunction (or, or not)
of literals, where each literal is either a Boolean variable (such as x) or
t negation of one (such as X). A satisfying truth assignment is an assignment of
false or true to each variable so that every clause contains a literal whose value
is true. The sat is the following: given a Boolean formula in conjunctive
normal form, either find a satisfying truth assignment or report that none exists.

In the instance previously mentioned, setting variables to true, for example, satisfies
very clause except the last. Is there a truth assignment that satisfies all clauses?

SAT is a typical search problem. We are given an instance I (that is, some input
d specifying the problem at hand, in this case a Boolean formula in conjunctive
normal form), and we are asked to find a solution S (an object that meets a partic-
ular specification, in this case an assignment that satisfies each clause). If no such
solution exists, we must say so.

More specifically, a search problem has the property that any proposed solu-
to S an instance I can be quickly checked for correctness. Does this entail?
For one thing, S must be at least (quick to) read, with length polynomially
bounded by that of I. This is clearly true in the case of sat, for which S is an as-
signment to the variables. To formalize the notion of quick checking, we will say
that there is a polynomial-time algorithm that takes as input I and S decides
whether or not S is a solution of I. For sat, this is as easy as it involves checking
the whatever assignment specified by S satisfies every clause in I.
