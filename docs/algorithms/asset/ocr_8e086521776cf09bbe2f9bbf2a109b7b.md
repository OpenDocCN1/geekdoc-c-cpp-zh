# Matrix-vector notation

A linear function like $x_1 + 6x_2$ can be written as the dot product of two vectors

$c = \left(\frac{1}{6}\right) \text{ and } x = \left(\frac{x_1}{x_2}\right)$

denoted $c \cdot x$ or $c^T x$. Similarly, linear constraints can be compiled into matrix-vector form:

$$\begin{array}{rrc} x_1 & \le & 200 \ x_2 & \le & 300 \ x_1 + x_2 & \le & 400 \end{array} \Rightarrow \begin{pmatrix} 1 & 0 \ 0 & 1 \ 1 & 1 \end{pmatrix} \begin{pmatrix} x_1 \ x_2 \end{pmatrix} & \le \begin{pmatrix} 200 \ 300 \ 400 \end{pmatrix}$
$A \quad \le \ b$

Here each row of matrix $A$ corresponds to one dot product with $x$ is at most the value in the corresponding row of $b$. In other, if the rows of $A$ are the vectors $a_1, \dots, a_m$, then the statement $Ax \le b$ is equivalent to

$a_i x \le b_i$ for all $i = 1, \dots, m$.

With these not convenions, a generic LP can be expressed as

$max \ c^T x\nAx \le b\nx \gege 0$.

For example, our first linear program gets rewritten as follows:

$max \ x_1 + 6x_2\nx_1 \\le \ 200\nx_2 \lele \ 300\nx_1 + x_2 \lele \ 400\nx_1, x_2 \gege 0 \quad \Rightarrow \quad min \ -x_1 - 6x_2\nx_1 + s_1 \lele \ 200\nx_2 + s_2 \lele \ 300\nx_1 + x_2 + s_3 \lele \ 400\nx_1, x_2, s_1, s_2, s_3 \gege 0$

The original was also in a useful form: maximize an objective subject to certain inequalities. Any LP can likewise be recast in this way, using the reductions given earlier.
