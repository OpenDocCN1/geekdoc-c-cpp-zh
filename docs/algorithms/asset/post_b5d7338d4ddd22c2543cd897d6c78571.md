
# Setting up a periodic superposition

Let us now see how to use our periodic function $f(a) = x^a \mod N$ to set up a periodic superposition. Here is the procedure:

- We start with two quantum registers, both initially 0.
- Compute the quantum Fourier transform of the first register $M_0$, to get a superposition over all numbers between 0 and $M-1$: $\frac{1}{\sqrt{M}}\sum_{a=0}^{M-1} |a, 0\rangle$. This is because the initial superposition can be thought of as periodic with period $M$, so the transform is periodic with period 1.
- We now compute the function $f(a) = x^a \mod N$. The quantum circuit for doing this regards the contents of the first register $a$ as the input to $f$, and the second register (which is initially 0) as the answer register. After applying this quantum circuit, the state of the two registers is: $\sum_{a=0}^{N-1}|a, f(a)\rangle$.
- We measure the second register on the first register, with period $r$, the period of $f$. Here's why:

Since $f$ is a periodic function with period $r$, for every $r$th value in the first register, the contents of the second register are the same. The measurement of the second register yields $f(b)$ for some random $k$ between 0 and $r-1$. What is the state of the first register after this measurement? To answer this question, recall that the first register is a superposition of only values $a$ that are compatible with the outcome of the measurement on the second register. But these values of $a$ are exactly $k, k+r, k+2r,\dots,k+M-r$. The resulting state of the first register is a periodic superposition $|\alpha\rangle$ with period $r$, which is exactly the order of $x$ we wish to find!

- Choose $x$ uniformly in the range $1 \le x \le N-1$.
- Let $M$ be a power of 2 near $N$ (for reasons we cannot get into, it is best to choose $M \approx N^2$).
- Repeat $L=\log N$ times:
    (a) Start with two quantum registers, both initially 0, the first large enough to store a number $M$ and the second modulo $N$.
    (b) Use the function $f(a) = x^a \mod N$ to create a periodic superposition $|\alpha\rangle$ of length $M$ as follows (see box for details):
        i. Apply the QFT to the first register to obtain the superposition $\frac{1}{\sqrt{M}}\sum_{a=0}^{M-1}|a, 0\rangle$.
        ii. Compute $f(a) = x^a \mod N$ using a quantum circuit, to get the superposition $\frac{1}{\sqrt{M}}\sum_{a=0}^{M-1}|a, x^a \mod N\rangle$.
        iii. Measure the register. Now the first register contains the periodic superposition $|\alpha\rangle = \sum_{j=0}^{M/r-1} \sqrt{\frac{r}{M}} |jr+k\rangle$ where $k$ is a random offset between $0$ and $r-1$ (recall that $r$ is the order of $x$ mod $N$).
        i. Fourier sample the superposition $|\alpha\rangle$ to obtain an index between $0$ and $M-1$.
        Let $g$ be the gcd of the resulting indices $j_1, \dots, j_s$.
        l. If $M/g$ is even, compute $\gcd(N, x^{M/g}+1)$ and output it if it is a non-trivial factor of $N$; otherwise return to step 1.

From previous lemmas, we know that this method works for at least half the cases of $x$, and the entire procedure has to be repeated a couple of times before a factor is found.

But there is one aspect of this algorithm, having to do with the number $M$, that is still quite unclear: $M$, the size of our FFT, must be a power of 2. And for our period-detecting idea to work, the period must divide $M—hence it should also be a power of 2. But the period in our case is the order of $x$, definitely not a power of 2!

The reason it all works anyway is the following: the quantum Fourier transform can detect the period of a periodic vector if it does not divide $M$. But the division is not as clean as in the case when the period divide $M$, so we shall not go any further into this.

Let $n$ be the number of bits of the input $N$. The running time of the algorithm is dominated by $2 \log N = O(n)$ repetitions of step 3. Since modular exponentiation takes $O(n^3)$ steps (as we see in Section 1.2.2) and the quantum Fourier transform takes $O(n^2)$ steps, the total running time for the factoring algorithm is $O(n^3 \log n)$.

# Implications for computer science and quantum physics

In the early days of computer science, people wondered whether quantum computers were more powerful than those made of silicon. This question has been widely settled by the extended Church-Turing thesis. Can quantum computers be built? This is the challenge that stands before us. Quantum superpositions are fragile and need to be protected from any environment. There is progress in this direction, but the question of whether they can be scaled up remains. The next decade of quantum physics promises to be exciting, as it comes to the implementation of quantum algorithms. This is motivated by the need to clarify the fundamental nature of quantum mechanics.
