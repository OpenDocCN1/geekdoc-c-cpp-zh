3.8. Pour water. We have three containers whose sizes are 10 pints, 7 pints, and 4 pints, respectively. The 7-point and 4-point containers start full of water, but the 10-pint container is initially empty. We allow one type of operation: pouring the contents of one container into another, stopping when the source container is empty or the destination is full. We want to know if there is a sequence of pourings that leaves exactly 2 pints in the 7- or 4-point container.

+   (a) Model this as a graph problem: give a precise definition of the graph involved and state the specific question about this graph needs to be answered.
(b) What algorithm should be applied to solve the problem?
