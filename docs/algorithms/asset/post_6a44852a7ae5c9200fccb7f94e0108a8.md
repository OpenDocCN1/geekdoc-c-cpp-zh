The algorithm to factor a large integer N can be viewed as a sequence of reductions (and everything shown here in italics will be defined in good time):

- *FACTORING* is reduced to finding a nontrivial square root of 1 modulo N.
- Finding such a root is reduced to computing the order of a random integer modulo N.
- The order of an integer is precisely the period of a particular periodic superposition.
- Finally, periods of superpositions can be found by the quantum FFT.

We begin with the last step.

### 10.3 The quantum Fourier transform

Recall the fast Fourier transform (FFT) from Chapter 2. It takes as input an $M$-dimensional, complex-valued vector $\alpha$ (where M is a power of 2, so $M=2^m$), and outputs an M-dimensional complex-valued vector $\beta$:

![](img/3dd1f1364df8f87b80683fc32a15b999_313_0.png)

where $\omega$ is a complex Mth root of unity (the extra factor of $\sqrt{M}$ has the effect of ensuring that if $|\alpha_i|^2$ add up to 1, then so do $|\beta_i|^2$). The preceding equation suggests an $O(M^2)$ algorithm, the classical FFT is able to perform this much faster and has the profound effect of making digital signal processing practically feasible. We will now see that quantum computers can implement the FFT exponentially faster, in $O(\log M)$ time!

But wait, can any algorithm take time M, the length of the input? The point is that we can encode the input in a superposition of $m = \log M$ qubits: after all, this superposition consists of $2^m$ amplitude values. In the notation we introduced earlier, we wrote the superposition as $\alpha = \sum_{j=0}^{M-1} \alpha_j |j\rangle$ where $\alpha_j$ is the amplitude of the m-bit binary string corresponding to the number $j$ in the natural way. This brings us an important point: the $|j\rangle$ is just another way of writing a vector, where the index of each entry is written explicitly in the special bracket symbol.

Starting from this input superposition $|\alpha\rangle$, the quantum Fourier transform (QFT) manipulates it appropriately in $m=\log M$ stages. Each stage evolves so that it encodes the intermediate results at the same stage of the classical (whose finest circuit, with $m$ stages, is reproduced from Chapter 2 in Figure 10.4).

#### Figure 10.4 The classical FFT circuit from Chapter 2. Input vectors of M bits are processed in a sequence of m = \log M levels.

![](img/3dd1f1364df8f87b80683fc32a15b999_314_0.png)

As we will see in Section 10.5, this can be achieved with $m$ quantum operations per stage. Ultimately, after $m$ such systems and $m^2 = \log^2 M$ elementary operations, we obtain the superposition $|\beta\rangle$ that corresponds to the desired output of the QFT.

So far we have only considered the good news about the QFT: its amazing speed. Now it is time to read the first part. The classical FFT algorithm actually outputs the M complex numbers $\beta_0, \dots, \beta_{m-1}$. In contrast, the QFT only prepares a superposition $|\beta\rangle = \sum_{j=0}^{m-1} \beta_j |j\rangle$. And, as we saw earlier, these amplitudes are part of the "private world" of this quantum system.

The only way to get our hands on this result is by measuring it! And measuring the state of the system only yields $m = \log M$ classical bits: specifically, the output is index $j$ with probability $|\beta_j|^2$.

So, instead of QFT, it would be more accurate to call this algorithm quantum Fourier sampling. Moreover, even though we have confined our attention to the case $M = 2^m$ in this section, the algorithm can be implemented for arbitrary values of $M$, and can be summarized as follows:

#### Figure 10.5 Examples of periodic superpositions.

| period 3 | | | | ... |
|---|---|---|---|---|
| 0 | 3 | 6 | | M-3 |
| period 4 | | | | ... |
| 1 | 5 | 9 | | M-3 |

- **Input:** A superposition of $m = \log M$ qubits, $\alpha = \sum_{j=0}^{M-1} \alpha_j |j\rangle$.
- **Method:** Using $O(m^2) = O(\log M)$ quantum operations perform the quantum FFT to decompose the superposition $\beta = \sum_{j=0}^{M-1} \beta_j |j\rangle$.
- **Output:** A random $m$-bit number $j$ (that is, $0 \le j \le M-1$), from the distribution $Pr[j] = |\beta_j|^2$.

Quantum Fourier sampling is a quick way of getting a very rough idea about the output of the FFT, just detecting one of the larger components. In fact, we don't see the value of that component—we only see its index. How can we use meager information? In which applications is this enough? This is what we explore next.

### 10.4 Periodicity

Suppose that the input to QFT, $|\alpha\rangle = (\alpha_0, \alpha_1, \dots, \alpha_{M-1})$, is such that $\alpha_i = \alpha_j$ whenever $i \equiv j \pmod k$, where $k$ is a particular integer that divides $M$. That is the array $\alpha$ carries $M/k$ repetitions of some sequence $(\alpha_0, \alpha_1, \dots, \alpha_{k-1})$ of length $k$. Moreover, suppose that exactly one of the $k$ numbers $\alpha_j$ is nonzero, so we say $|\alpha\rangle$ is periodic with period $k$ and offset $j$ (Figure 10.5).

It turns out that if the input is periodic, we can use Quantum Fourier sampling to compute its period! This is based on the following fact, proved next:

> Suppose the input to quantum sampling is periodic with period $k$, for some $k$ that divides $M$. Then the output will be a multiple of $M/k$, and it is equally likely to be any of the $k$ multiples of $M/k$.

A little thought tells us that by repeating the sampling a few times (repeatedly preparing the periodic superposition and doing Fourier sampling), and then taking the greatest common divisor of all the indices returned, we will with very high probability get the number $M/k$—and from the period $k$ of the input!

#### The Fourier transform of a periodic vector

Suppose the vector $|\alpha\rangle = (\alpha_0, \alpha_1, \dots, \alpha_{M-1})$ is periodic with period $k$ and with no offset (that is, the nonzero terms are $\alpha_0, \dots, \alpha_{k-1}$). Thus,

$|\alpha\rangle = \sum_{j=0}^{M/k-1} \sqrt{k} |jk\rangle$

We will show that its Fourier transform $|\beta| = (\beta_0, \beta_1, \dots, \beta_{M-1})$ is also periodic, with period $M/k$ and no offset.

##### Claim

Proof. In the input vector, the coefficient $\alpha_i$ is $\sqrt{k}$ if $k$ divides $i$, and is otherwise zero. We can plug this into the formula for:

$\beta_j = \frac{1}{M} \sum_{j=0}^{M/k-1} \sqrt{k} \alpha_{jk} \sum_{i=0}^{k-1} \omega^{ijk}$

The summation is a geometric series, $1 + \omega^k + \omega^{2k} + \dots$, containing $M/k$ terms and with ratio $\omega^k$. There are two cases. If the ratio is 1, which happens if $jk = 0 \pmod M$, then the sum of the series is simply the number of terms. If the ratio isn't 1, we can apply the formula for geometric series to find that the sum is

$\beta_j$ is $1/\sqrt{k}$ if $M$ divides $jk$, and is zero otherwise.

More generally, we can consider the original superposition to be periodic with period $k$, and with some offset $l < k$:

$|\alpha\rangle = \sum_{j=0}^{M/k-1} \sqrt{k} |jk+l\rangle$

Then, as the Fourier transform $|\beta|$ will have amplitudes precisely at multiples of $M/k$:

##### Claim

$\beta = \frac{1}{\sqrt{k}}\sum_{j=0}^{M/k-1} \omega^{jlM/k} |j\rangle$

The proof of this claim is very similar to the preceding one (Exercise 10.5). We conclude that the QFT of any periodic superposition with period $k$ is an array that is everywhere zero except at multiples of $k$.

**Lemma** *Suppose independent samples are drawn uniformly from*

$\frac{M}{k}, \dots \frac{(k-1)M}{k}$

Then with probability at least $1-k/2^2$, the greatest common divisor of these samples is $M/k$.

*Proof.* The only way this can fail is if all samples are multiples of $j/k$, where $j$ is some integer greater than 1. So, fix any integer $j \ge 2$; the chance that a particular sample is a multiple of $j/k$ is at most $1/j \le 1/2$; and thus the chance that *all* the samples are multiples of $j/k$ is at most $1/2^j$.

So far we have been thinking about a particular number $j$; the probability that this bad event will happen for *some* $j \le k$ is at most equal to the *sum* of these probabilities over the different values of $j$, which is no more than $k/2^j$. We can make the failure probability as small as we like by taking $s$ to be an appropriate multiple of $M$.

### 10.5 Quantum circuits

So quantum computers can carry out a Fourier transform exponentially faster than classical computers. But what do these computers actually look like? What is a *quantum* circuit made up of, and exactly does it compute Fourier transforms so quickly?

#### 10.5.1 Elementary quantum gates

An elementary quantum operation is analogous to an elementary gate either the AND or not gate in a classical circuit. It operates on either a single qubit or qubits. One of the most important examples is the Hadamard gate, denoted by H, which operates on a single qubit. On $|0\rangle$, it outputs $H(|0\rangle) = \frac{1}{\sqrt{2}}|0\rangle + \frac{1}{\sqrt{2}}|1\rangle$; and on input $|1\rangle$, $H(|1\rangle) = \frac{1}{\sqrt{2}}|0\rangle - \frac{1}{\sqrt{2}}|1\rangle$. In pictures:

$|0\rangle \rightarrow \mathbf{H} \rightarrow \frac{1}{\sqrt{2}}|0\rangle + \frac{1}{\sqrt{2}}|1\rangle \quad \quad |1\rangle \rightarrow \mathbf{H} \rightarrow \frac{1}{\sqrt{2}}|0\rangle - \frac{1}{\sqrt{2}}|1\rangle$
