# The Fourier transform of a periodic vector

Suppose the vector $|\alpha| = (\alpha_0, \alpha_1, \dots, \alpha_{M-1})$ is periodic with period $k$ and with no offset (that is, the nonzero terms are $\alpha_0, \alpha_k, \dots$). Thus,

```
$|alpha| = \sum_{j=0}^{M/k-1} \sqrt{k} |jk|$$
```

We will show that its Fourier transform $|eta| = (eta_0, eta_1, \dots, eta_{M-1})$ is also periodic, with period $M/k$ and no offset.
