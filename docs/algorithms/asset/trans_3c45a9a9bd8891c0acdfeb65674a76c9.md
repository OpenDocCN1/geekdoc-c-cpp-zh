

# 威尔逊定理指出，一个数 $N$ 是素数当充分仅当：

$$(N-1)! \equiv -1 \pmod{N}$$

- 如果 $p$ 是素数，我们知道每个数字 $1 \leq x < p$ 在模 $p$ 下都是可逆的。
- 通过配对乘逆元，证明对于 $p$，有 $(p-1)! = -1 \pmod{p}$。
- 如果 $N$ 不是素数，那么 $(N-1)! \neq -1 \pmod{N}$。（提示：考虑 $d=\gcd(N, (N-1))$。）
- 与费尔马小定理不同，威尔逊定理是判定素数的充充分必要条件。为什么我们不能直接基于此建立素性测试呢？
