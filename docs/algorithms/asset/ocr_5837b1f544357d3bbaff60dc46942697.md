# Carmichael numbers

The smallest Carmichael number is 561. It is not a prime: $561 = 3 \cdot 11 \cdot 17$; yet it fools the Fermat test, as $a^{560} \equiv 1 \pmod{561}$ for all values of $a$ relatively prime to 561. For a long time it was thought that there might be finitely many numbers of this type; now we know they are, but exceedingly rarely.

There is a way around Carmichael numbers, using a slightly more refined primality test like Rabin and Miller. Write $N-1=2^s u$. If we choose a random base $a$ and check the value of $a^u \mod N$. We perform this computation by determining $a^*=\\mod N$ and then repeatedly squaring, to get the sequence:

```
$a^* \mod N, (a^*)^2 \mod N, \dots, (a^*)^{2^s} = a^{N-1} \mod N$
```

If $a^{N-1} \not\equiv 1 \mod N$, then $N$ is composite by Fermat's theorem, and we are done. If $a^{N-1} \equiv 1 \mod N$, we conduct a little follow-test: somewhere in the preceding sequence, we run into a for the first time. If this happened after the first position (that is, if $a^* \not\equiv 1 \mod N$), and the preceding value in the list is $-1 \mod N$, then we declare $N$ composite.

In the latter case, we have found a nontrivial square root of $1 \mod N$: a number that is not $\pm1 \mod N$ but when squared is equal to $1 \mod N$. Such a number can only exist if $N$ is composite (Exercise 1.40). It turns out that if we combine this square-root check with our earlier Fermat test, then at least three-fourths of the possible values between $1$ and $N-1$ will reveal a composite $N$, even if it is a Carmichael number.

# 1.3.1 Generating random primes

We are now close to having the tools we need for cryptographic applications. The final piece of the puzzle is a fast algorithm for choosing random primes that are a few hundred bits long. What random $n$-bit number has roughly a one-in-$n$ chance of being prime (about $1/(\ln 2^n) \approx 1/144$). For instance, in 20 social security numbers is prime!

Lagrange's prime number theorem $\pi(x)$ is the number of primes $\le x$. $\pi(x) \approx x/ln x$, or more precisely,

```
$\lim_{x\to\infty} \frac{\pi(x)}{x} = 1$.
```

Such abundance makes it simple to generate a random $n$-bit prime:
