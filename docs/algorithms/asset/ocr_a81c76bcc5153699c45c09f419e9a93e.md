# Why P and NP?

Okay, P must stand for "polynomial." But why use the initials NP (the common chatroom abbreviation abbreviation for "no problem") to describe the class of search problems, some of which are terribly hard?

NP stands for "nondeterministic polynomial," a term going back to the roots of complexity theory. Intuitively, that a solution to any search problem can be found and verified in polynomial time by a (quite unrealistic) sort of algorithm, called a nondeterministic algorithm. Such an algorithm has the power of guessing correct at every step.

Incidentally, the original definition of NP (and its most common usage to this day) was not a class of search problems, but as a class of decision problems: algorithmic questions that can be answered by yes or no. Example: "Is there a truth assignment that satisfies this Boolean formula?" But this reflects a historical reality; at the time of NP-completeness was being developed, researchers in the theory of computation were interested in formal languages, a domain which decision problems are of central importance.

We've seen many examples of NP search problems that are solvable in polynomial time. In some cases, there is an algorithm that takes as input an instance I and has a running time in polynomial [1]. If I has a solution, the algorithm correctly reports so. The class of all search problems that can be solved in polynomial time is denoted P. Hence, all search problems on the right-hand side of the table are in P.

Are there search problems that cannot be solved in polynomial time? In other words, P ≠ NP? Most researchers think so. It is hard to believe that a simple trick will crack all these hard problems, famously unoved for decades and centuries. And there is a good reason for mathematicians to believe that P ≠ NP-the task of proving a given for a mathematical assertion is a search problem and therefore in NP (after all, a formal proof of a mathematical statement is written out in excruciating detail, it can be checked mechanically, line by line, by an efficient algorithm). If P = NP, there would be an efficient way to prove theorems, eliminating the need for mathematicians! In all all, there are a variety of reasons why it is widely believed that P ≠ NP. However, proving this has turned out to be extremely difficult, one of the deepest and most important puzzles of mathematics.
