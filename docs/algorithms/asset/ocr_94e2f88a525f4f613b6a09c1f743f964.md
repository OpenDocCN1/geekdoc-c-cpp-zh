If there are $n$ elements, their rank value can range from 0 to $\log n$ by Property 3. Let's decide the nonzero part of this range to into carefully chosen ideals, for reasons that will soon become clear:

+   [1], [2], [3, 4], [5, 6, $\dots, 17, 18, $\dots, 2^{16} = 65536]$, [65537, 65538, $\dots, 2^{65536}]$, $\dots$

Each group is of the form $[k+1, k+2, \dots, 2^k]$, where $k$ is a power of 2. The number of groups is $\log^* n$, which is defined to be the number of successive log operations that need to be applied to $n$ to bring it to 1 (or below 1). For instance, $\log^* 100 = 4$ since $\log\log 100 \le 1$. In practice there will be just first five of the intervals; more needed only if $n \ge 2^{65536}$, in other words never.
