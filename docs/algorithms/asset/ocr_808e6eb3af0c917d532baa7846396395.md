# Two’s complement

Modular arithmetic is nicely illustrated in two’s complement, the most common format for storing integers. It uses $n$ bits to represent numbers in the range $[-2^{n-1}, 2^{n-1}-1]$ and is usually described as:

+   - Positive integers, in the range 0 to $2^{n-1}-1$, are stored in binary and have a leading bit of 0.
- Negative integers $-x$, with $1 \le x \le 2^{n-1}$, are stored by first constructing $x$ in binary, flipping all the bits, and finally adding 1.

(And the usual description of addition and multiplication in this format is ever more arcane!)

Here’s a much simpler way to think about it: any number in the range $-2^{n-1}$ to $2^{n-1}-1$ is stored modulo $2^n$. Negative numbers $-x$ therefore exist as $2^n-x$. Arithmetic operations like addition and subtraction can be performed directly in this format, ignoring any overflow bits.

# Substitution rule If $x \equiv x'$ (mod $N$) and $y \equiv y'$ (mod $N$), then:

```
$x+y \equiv x'+y'$ (mod N) and $xy \equiv x'y'$ (mod N).
```

(See Exercise 1.9.) For instance, suppose you have an entire season of your favorite television show in one sitting, starting at midnight. There are 25 episodes, each lasting 3 hours. At what time of day are you done? Answer: the hour of completion is $(25 \times 3)$ mod 24, which (since $25 \equiv 1$ mod 24) is $1 \times 3 = 3$ mod 24, or three o’clock in the morning.

It is not hard to check that in modular arithmetic

```
$x+(y+z) \equiv (x+y)+z$ (mod N) Associativity
$xy \equiv yx$ (mod N) Commutativity
$x(y+z) \equiv xy+yz$ (mod N) Distributivity
```

```
$2^{345} \equiv (2^5)^{69} \equiv 32^{69} \equiv 1^{69} = 1$ (mod 31).
```
