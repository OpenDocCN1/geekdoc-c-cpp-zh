# Hey, that was group theory!

For any integer $N$, the set of all numbers $N$ that are relatively prime to $N$ constitute what mathematicians call a *group*:

+   - There is a multiplication operation defined on this set.
- The set contains a neutral element (namely 1: any number multiplied by this remains unchanged).
- All elements have a well-defined inverse.

This particular group is called the *multiplicative group of $N$*, usually denoted $\mathbb{Z}_N^*$.
Group theory is a very well developed branch of mathematics. One of its key concepts is that a group can contain a *subgroup*—a subset that is in group and itself. An important fact about a subgroup is that its size must divide the size of the whole group.

Consider the set $B = \{b : b^{N-1} \equiv 1 \pmod N\}$. It is not hard to see that it is a subgroup of $\mathbb{Z}_N^*$ (just check that $B$ is closed under multiplication and inverses). The size of $B$ must divide that of $Z_N^*$. Which means if $B$ does not contain all of the next largest size it can have $|Z_N^*|/2$.

We can reduce this *one-sided error* by repeating the procedure many times, randomly picking several values of $a$ and testing them all (Figure 1.8).

> Pr(Algorithm 1.8 returns yes when $N$ is not prime) $\le \frac{1}{2^k}$

This probability of error drops exponentially, and can be driven arbitrarily low by choosing $k$ large enough. Testing $k=100$ values of $a$ makes the probability of failure at most $2^{-100}$, which is minuscule: for instance, the probability that a random cosmic ray will sabotage the computer during the computation!

**Figure 1.8** An algorithm for testing primality, with low error probability.

```
function primality2(N)
Input: Positive integer N
Output: yes/no
nPick positive integers $a_1, a_2, \dots, a_k < N$ at random
if $a_i^{N-1} = 1 (mod N)$ for all $i = 1, 2, \dots, k:
  return yes
else:
  return no
```
