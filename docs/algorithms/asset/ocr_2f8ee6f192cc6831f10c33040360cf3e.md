If $c_i \le 0$, then considering the constraints $x \ge 0$, we can't hope for a better objective value. Conversely, if some $c_i > 0$, the origin is not optimal, since we can increase the objective function by raising $x_i$.

Thus, for task 2, we can move by increasing some $x_i$ for which $c_i > 0$. How much can we increase it? Until we hit some other constraint. That is, we release the constraint $x_i \ge 0$ and increase $x_i$ until some other inequality, relatively loose, becomes tight. At that point, we again have exactly $n$ tight inequalities, so we are at a new vertex.

For instance, suppose we're dealing with the following linear program:

```
$2x_1 + 5x_2\n2x_1 - x_2 \le 4\nx_1 + 2x_2 \le 9\n$-x_1 + x_2 \le 3\nx_1 \ge 0\nx_2 \ge 0$
```

Simplex can be started at the origin, which is specified by constraints (④) and (⑤). To move, we release the tight constraint $x_2 \ge 0$. As $x_2$ is gradually increased, the first constraint runs into $-x_1 + x_2 \le 3$, and thus it has to stop at $x_2 = 3$, at which point this new inequality is tight. The new vertex is given by (③) and (④).

So we know what to do if we are at the origin. But if our current **u** is elsewhere? The trick is to transform **u** into the origin, by shifting the coordinate system from the usual $(x_1, \dots, x_n)$ to the “local view” from **u**. These local coordinates consist of (appropriately scaled) distances $y_1, \dots, y_n$ to the $n$ hyperplanes (inequalities) that define and enclose **u:**:

![](bbox=[0.498, 0.613, 0.702, 0.74])

Specifically, if one of these enclosing inequalities is $a_i \cdot x \le b_i$, then the distance from a point **x** to that particular “wall” is

```
$y_i = b_i - a_i \cdot x$.
```

The $n$ equations of this type, one per wall, and this relationship can be inverted to express the $x_i$'s as a linear function of the $y_i$'s. This doesn't fundamentally change it, we can rewrite the LP in terms of $y_i$ without totally change it (for instance, the optimal value stays the same), but it expresses it in a different coordinate frame.
