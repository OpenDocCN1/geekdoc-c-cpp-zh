For large values of $n$, there are two recursive invocations of $fib1$, taking time $T(n-1)$ and $T(n-2)$, respectively, plus three computer steps (checks on the value of $n$ and a final addition).

$T(n) = T(n-1) + T(n-2) + 3 \text{ for } n > 1.$

Compare this to the recurrence relation for $F_n$: we immediately see that $T(n) \geq F_n$.

This is bad news: the timing of the algorithm grows as fast as the Fibonacci numbers $T(n)$ is exponential in $n$, which implies that the algorithm is practically slow except for very small values of $n$.

Let's be a little more concrete about exponential time. To compute $F_{200}$, the $fib1$ algorithm executes $T(200) \geq F_{200} \geq 2^{138}$ elementary steps. How long this actually depends, of course, on the computer used. At this time, the fastest computer in the world is the NEC Earth Simulator, which clocks 40 trillion steps per second. Even on this, $fib1(200)$ would take at least $2^{92}$ seconds. This means that, if we start the computation today, it would still be long after the sun turns into a red giant.

But technology is rapidly improving—computer speeds be doubling every 18 months, a phenomenon called Moore's law. With this extraordinary growth, $fib1$ will run a lot faster on next year's machines. Let's see the time of $fib(n)$ is proportional to $\approx (1.6)^n$, so it takes 1.6 times longer to compute $F_{n+1}$ from $F_n$. Under Moore's law, computers get roughly 1.6 times faster each year. So if we can reasonably compute $F_{100}$ with this year's technology, next year we will manage $F_{101}$. And the year after, $F_{102}$. And the so on: just one more Fibonacci number every time.

In short, our recursive algorithm is correct but hopelessly inefficient. Can we do better?

# A polynomial algorithm

Let's try to understand why $fib1$ is so slow. Show the cascade of recursive invocations triggered by a single call to $fib1(n)$. Notice how many computations are repeated!

A more sensible scheme would store the intermediate results—values $F_0, F_1, \dots, F_{n-1}$—as soon as they become known.

```
function fib2(n)
  if n = 0:
    return 0
  create an array f[0...n]
  f[0] = 0, f[1] = 1
  for i = 2..n:
    f[i] = f[i-1] + f[i-2]
  return f[n]
```
