# Figure 7.13 Simplex in action.

Initial LP:

| Current vertex: ({4, 5}) (origin). |
| Objective value: 0. |
| max $2x_1 + 5x_2$ | Move: increase $x_2$. |
| $2x_1 - x_2 \le 4$ ① | ⑤ is released, ③ becomes tight. Stop at $x_2 = 3$. |
| $x_1 + 2x_2 \le 9$ ② | New vertex ({4, ③}) has local coordinates ($y_1, y_2$): |
| $-x_1 + x_2 \le 3$ ③ | $y_1 = x_1, y_2 = 3 + x_1 - x_2$ |
| $x_1 \ge 0$ ④ | |
| $x_2 \ge 0$ ⑤ | |

Rewritten LP:

| Current vertex: ({4, 3}). |
| Objective value: 15. |
| max $15 + 7y_1 - 5y_2$ | Move: increase $y_1$. |
| $y_1 + y_2 \le 7$ ① | ④ is released, ② becomes tight. Stop at $y_1 = 1$. |
| $3y_1 - 2y_2 \le 3$ ② | New vertex ({②, ③}) has local coordinates ($z_1, z_2$): |
| $y_2 \ge 0$ ③ | $z_1 = 3 - 3y_2, z_2 = y_2$ |
| $z_1 \ge 0$ ④ | | |
| $-y_1 + y_2 \le 3$ ⑤ | |

Rewritten LP:

| Current vertex: ({②, ③}). |
| Objective value: 22. |
| max $22 - \frac{1}{2}z_1 - \frac{1}{2}z_2$ | Optimal: all $v_i < 0$. |
| $-\frac{1}{2}z_1 + \frac{1}{2}z_2 \le 6$ ① | Solve ②, ③ (in original LP) to get optimal solution |
| $z_1 \ge 0$ ② | $(x_1, x_2) = (1, 4)$. |
| $z_2 \ge 0$ ③ | | |
| $\frac{1}{2}z_1 - \frac{1}{2}z_2 \le 1$ ④ | | |
| $z_1 + \frac{1}{2}z_2 \le 4$ ⑤ | |
