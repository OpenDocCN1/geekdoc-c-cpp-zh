# **Lemma** If a ≥ b, then a mod b < a/2.

Proof. Witness that either b ≤ a/2 or b > a/2. These cases are shown in the following figure. If b ≤ a/2, then we have a mod b < b ≤ a/2; and if b > a/2, then a mod b = a - b mod a/2.

| b | a | a/2 | b | a |
|---|---|---|---|---|
| a mod b | | | | mod b |

This means that any two consecutive rounds, arguments a and b, are at the very least halved in value—the length of each deat decreases by at least one. If they are initially n-bit integers, the base case will be reached within 2n calls. And each call invokes a quadratic-time division, the total time is O(n²).

# 1.2.4 An extension of Euclid's algorithm

To motivate it, suppose someone claims d is the greatest common divisor of a and b; how can we check this? It is not enough to verify that d divides both a and b, because this only shows d be a common factor, not necessarily the largest one. Here's a test that can be used if d is of a particular form.

> **Lemma** If d divides both a and b, and d = ax + by for some integers x and y, then necessarily d = gcd(a, b).

Proof. By the first two conditions, d is a common divisor of a and b so it cannot exceed the greatest common divisor; that is, d ≤ gcd(a, b). On the other hand, gcd(a, b) is a common divisor of a and b, and it must also divide ax + by = d, which implies gcd(a, b) ≤ d. Putting these together, d = gcd(a, b).

So, if we supply two numbers x and y such that d = ax + by, then we can be d = gcd(a, b). For instance, we know gcd(13, 4) = 1 because 13 − 1 ⋅ 4 − (−3) = 1. But when we find these numbers: under what circumstances can gcd(a, b) be expressed in this checkable form? It turns out that it can always be. What is even better, the coefficients x and y can be found by a small extension to Euclid's algorithm; see Figure 1.6.

# **Figure 1.6** A simple extension of Euclid's algorithm.

```
function extended-Euclid(a, b)
Input: Two positive integers a and b with a ≥ b ≥ 0
Output: integers x, y,d such that d = gcd(a, b) and ax + by = d

if b = 0: return (1, 0, a)
(x', y', d) = extended-Euclid(b, a mod b)
return (y', x' − {a/b}y', d)
```
