Notice how the function $\mu_2$ penalizes points that are far from $\mu_1$ much more heavily than the function for $\mu_1$. Thus $\mu_2$ tries much harder to be *all* the observations. This might sound like a good thing at some level, but it is statistically undesirable because a few outliers can severely throw off the estimate of $\mu_2$. It is therefore said that $\mu_1$ is a more robust estimator than $\mu_2$. Worse than either of them, however, is $\mu_{\infty}$, the value of $\mu$ minimizes the function

```
max |x - \mu|
```
