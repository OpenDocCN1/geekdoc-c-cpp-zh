Big-O notation lets us focus on the picture. When with a complicated function like 3n² + 4n + 5, we just replace it with O(n), where f(n) is as simple as possible. In this particular example use O(n²), because the quadratic portion of the sum dominates the rest. Here are some commons rules that help simplify functions by omitting dominated terms:

+   1. Multiplicative constants can be omitted: 14n² dominates n².
2. nᵃ dominatesᵇ if a > b: for instance n dominates n.
3. Any exponential dominates any polynomial: 3ⁿ dominates n² (even dominates 2ⁿ).
4. Likewise, any polynomial dominates any logarithmic: log n dominates (log n)³. This also means, for example, n² dominates n log n.

Don't misunderstand this variety attitude toward constants. Programmers and developers are very interested in what would gladly stay up nights in order to make an algorithm faster by a factor of 2. But understanding algorithms at the level of this book would be impossible without the simplicity afforded by big-O notation.
