# 2.6.4 A closer look at the fast Fourier transform

# The definitive FFT algorithm

The FFT takes as input vector $a = (	ilde{a}_0, \dots, \tilde{a}_{n-1})$ and a complex number $\omega$ whose powers $1, \\omega, \omega^2, \dots, \omega^{n-1}$ are the complex $n$th roots of unity. It multiplies vector $a$ by the $n \times n$ matrix $M_a(\omega)$, which has $(j, k)$ entry (starting row-column-count at zero) $\omega^{jk}$.
