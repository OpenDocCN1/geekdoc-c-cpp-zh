We will show that if we pick these coefficients $a$ at random, $h_a$ is very likely to be good in the following sense.

**Property** Consider any pair of distinct IP addresses $x = (x_1, \dots, x_4)$ and $y = (y_1, \dots, y_4)$. If the coefficients $a = (a_1, a_2, a_3, a_4)$ are chosen uniformly at random from $(0, 1, \dots, n-1)$,

```
$Pr [h_a(x_1, \dots, x_4) = h_a(y_1, \dots, y_4)] = \frac{1}{n}.$
```

In other words, the chance that $x$ and $y$ collide under $h_a$ is the same as if each were assigned randomly and independently. This condition guarantees that the expected lookup time for any item is small. Here's why: if we wish to look up $x$ in our hash table, the time required is determined by the size of its bucket, that is, the number of items that assigned the same name as $x$. But there are only 250 items in the hash table, and the probability that any item gets the same name as $x$ is $1/n=1/257$. Therefore the expected number of items that are assigned the same name as $x$ by a randomly chosen hash function $h_a$ is $250/257 \approx 1$, which makes the expected size of $x$'s bucket less than $2.$.

Let us now prove the property.

**Proof.** Since $x = (x_1, \dots, x_4)$ and $y = (y_1, \dots, y_4)$ are distinct, these quadruples must differ in some component; without loss of generality we assume that $x_4 \neq y_4$. We wish to compute the probability $Pr[h_a(x_1, \dots, x_4) = h_a(y_1, \dots, y_4)]$, that is, the probability that $\sum_{i=1}^4 a_i \cdot x_i = \sum_{i=1}^4 a_i \cdot y_i \pmod n$. This equation can be rewritten as

```
$$\sum_{i=1}^4 a_i \cdot (x_i - y_i) \equiv a_4 \cdot (y_4 - y_4) \pmod n$.
```

Suppose that we draw a random function $h_a$ by picking $a = (a_1, a_2, a_3, a_4)$ at random. We start by drawing the first number $a_1, a_2$, and $a_3$, and then think: What is the probability that the last number $a_4$ is such that equation (1) holds? Since the far left side of equation evaluates to some number, call it $c$. Since $n$ is prime and $x_4 \neq y_4$, $(y_4 - x_4)$ has a unique inverse modulo $n$. Thus for (1) to hold, the last number $a_4$ must be $c \cdot (y_4 - x_4)^{-1} \pmod n$, out of $n$ possible values. The probability of this happening is $1/n$, and it is complete.
