Unraveling the FFT circuit completely for $n=8$ elements, we get Figure 2.10. Notice the following.

- 1. For $n$ inputs there are $\log_2 n$ levels, with $n$ nodes, for a total of $n \log n$ operations.
- 2. The inputs are arranged in a peculiar order: 0, 4, 2, 6, 1, 5, 3, 7.

Why? Recall that at the top level of recursion, we first bring up the coefficients of the input and then on to the odd ones. At the next level, the even coefficients of this group (which therefore are multiples of 4, or equivalently, have zero as their least significant bits) are brought up, and so on. To put it otherwise, the inputs are arranged by increasing *last* of the binary representation of their index, resolving ties by looking at the next most significant bit(s). The resulting order in binary, 000, 100, 010, 110, 001, 101, 011, 111, except the bits are the same as the natural one, *mirrored*!

- 3. There is a unique path between each input $a_j$ and each output $A(\omega^k)$

This path is most easily described using the binary representations of $j$ and $k$ (shown in Figure 2.10). There are two edges out of each node, one going out (the 0-edge) and one going down (the 1-edge).

- 4. On the path between $a_j$ and $A(\omega^k)$, the labels add up to $jk \pmod 8$.

Since $\omega = 1$, this means the contribution of input $a_j$ to output $A(\omega^k)$ is $a_{j\omega^k}$, and therefore the circuit correctly computes the values of polynomial $A(x)$.

# The slow spread of a fast algorithm

Tukey was not keen to write a paper on the subject, Cooley took the initiative. This is one of the most famous and most cited scientific papers published in 1965, co-authored by Cooley and Tukey. The reason Tukey was reluctant to publish the FFT was not secretness or pursuit of profit via patents. He felt that this was a simple observation that was probably already known. This was typical of the period: back then (and for some time) algorithms were considered second-class mathematical objects, devoid of depth and length, and unworthy of serious attention.

But Tukey was right about one thing: it was later discovered that British engineers used the FFT for calculations during the late 1930s.—and to end this chapter with the same mathematician who started it—a paper by Gauss in the early 1800s (on what else?) interpolation essentially contained the same idea in it! Gauss's paper had remained a secret for so long because it was protected by an old-fashioned cryptographic technique: like most scientific papers of its era, it was written in Latin.

- 2.3. Section 2.2 describes a method for solving recurrence relations which is based on analyzing the recursion tree and deriving a formula for the work done at each level. Another (closely related) method is to expand the recurrence few times, until a pattern emerges. For instance, let's start with the familiar $T(n) = 2T(n/2) + O(n)$. Think of $O(n)$ as $\le cn$ for some constant $c$, so: $T(n) \le 2T(n/2) + cn$. By repeatedly applying this rule, we can bound $T(n)$ in terms of $T(n/2)$, $T(n/8)$, and so on, at each step getting closer to the value of $T(1)$ which we know, $T(1) = O(1)$.

```
$T(n) \le 2T(n/2) + cn
\le 2[T(n/4) + cn/2] + cn = 4T(n/4) + 2cn
\le 4[T(n/8) + cn/4] + 2cn = 8T(n/8) + 3cn
\le 8[T(n/16) + cn/8] + 3cn = 16T(n/16) + 4cn$
```
