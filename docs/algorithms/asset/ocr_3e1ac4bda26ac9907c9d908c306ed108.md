27.26. In a satisfiable system of linear inequalities

```
$a_{11}x_1 + \dots + a_{1n}x_n \le b_1\n:\n$a_{m1}x_1 + \dots + a_{mn}x_n \le b_m$
```

we describe the jth inequality as forced-equal if it is satisfied with every x = $(x_1, \dots, x_n)$ of the system. Equivalently, $\sum a_{ij}x_j \le b_i$ is not forced-equal if there exists an x that satisfies the whole system and that $\sum a_{ij}x_j < b_i$.
For example, in

```
$x_1 + x_2 \le 2\n$-x_1 - x_2 \le -2\n$x_1 \le 1\n$-x_2 \le 0$
```

the first two inequalities are forced-equal, but the third and fourth are not. A solution x to the system is called characteristic if, for every inequality I is not forced-equal, x satisfies I without equality. In the instance above, a solution is $(x_1, x_2) = (-1, 3)$, for which $x_1 < 1$ and $-x_2 < 0$ while $x_1 + x_2 = 2$ and $-x_1 - x_2 = -2$.

+   (a) That any satisfiable system has a characteristic solution.

+   (b) Given a satisfiable system of linear inequalities, how to use linear programming to determine which inequalities are forced-equal, and to find a characteristic solution.
