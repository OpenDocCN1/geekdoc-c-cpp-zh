(b) What is wrong with the following proof of NP-completeness? We know that the CLIQUE problem in general graphs is NP-complete, so it is enough to present a reduction from CLIQUE-3 to CLIQUE. Given a graph with vertices of degree $\le 3$, and a parameter $g$, the reduction leaves the graph and the parameter unchanged: clearly the output of the reduction is a possible input for the CLIQUE problem. Furthermore, the answer to both problems is identical. This proves the correctness of the reduction and, therefore, the NP-completeness of CLIQUE-3.

(c) It is true that the VERTEX cover problem remains NP-complete when restricted to graphs in which every vertex has degree at most 3. Call this problem VC-3. What is wrong with the following proof of NP-completeness for clique-3?

We present a reduction from vc-3 to clique-3. Given a graph $G = (V, E)$ with node degrees bounded by 3, and a parameter $b$, we create an instance of CLIQUE-3 by leaving the graph unchanged and switching the parameter to $|V|-b$. Now, a subset $C \subseteq V$ is a vertex cover in $G$ if and only if the complement set $V - C$ is a clique in $G$. Therefore $G$ has a vertex cover of size $\le b$ if and only if it has a clique of size $\ge |V|-b$. This proves the correctness of the reduction, and consequently, the NP-completeness of clique-3.
