# Entanglement

Suppose we have two qubits, the first in state $\alpha_0|0angle + \alpha_1|1angle$ and the second in the state $eta_0|0angle + eta_1|1angle$. What is the joint state of the two qubits? The answer is, the (tensor) product of the two: $\alpha_0eta_0|00angle + \alpha_0eta_1|01angle + \alpha_1eta_0|10angle + \alpha_1eta_1|11angle$.

An arbitrary state of two qubits, can we specify the state of each individual qubit in this way? No, in general the two qubits are *entangled* and cannot be decomposed into the states of the individual qubits. For example, consider the state $|\psiangle=\frac{1}{\sqrt{2}}|00angle+\frac{1}{\sqrt{2}}|11angle$, which is one of the Bell states. It cannot be decomposed into states of the individual qubits (see Exercise 10.1). Entanglement is one of the most mysterious aspects of quantum mechanics and is ultimately the source of power of quantum computation.

An interesting question comes up here: what if we make a *partial measurement*? For instance, if we measure the first qubit, what is the probability that the outcome is 0? This is simple. It is as same as it would be if we had measured both qubits, normally, $Pr[bit=0]+Pr[bit=1]=|\alpha_{00}|^2+|\alpha_{01}|^2$. Fine, how much does this partial measurement disturb the state of the system?

The answer is elegant. If the outcome of measuring the first qubit is 0, then the new superposition is obtained by crossing out all terms of $|\alphaangle$ that are inconsistent with that outcome (that which first bit is 1). Because the sum of the squares of the amplitudes is not 1, we must renormalize. In our example, this new state would be

$|alpha_{new}\rangle = \frac{\alpha_{00}}{\sqrt{|\alpha_{00}|^2+|\alpha_{01}|^2}}|00\rangle+\{\alpha_{01}}{\sqrt{|\alpha_{00}|^2+|\alpha_{01}|^2}}|01\rangle$.
