# Highlights

Many games have a need to execute tasks at regular intervals.
Threads are a possible solution, but they can be a poor choice due
to their nondeterministic nature, the complexities of their
interactions, and the high overhead of context switching. On the
other hand, a scheduler can be implemented to run in a single
thread and execute tasks at a specific point in the frame. Its tasks
will execute in a single context under full control of the application.

This gem presents a basic lightweight object-oriented scheduler
that implements limited cooperative multitasking between tasks in
a single thread. Possible applications of this scheduler include AI,
audio, and environmental effects. The complete code for the
scheduler described here is available on the accompanying CD.
