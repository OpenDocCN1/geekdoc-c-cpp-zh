# 27.2 Vectoring Mode Algorithm

A second related algorithm iteratively rotates a given point towards the x-axis. This is called the "vectoring" mode. In this algorithm, the point is rotated by successively smaller amounts until the value of the y-coordinate is zero. As in the rotation mode, the direction of rotation is represented by the value $d_i$, but this is instead determined by the sign of the y-coordinate, rather than the angle:

\( d_i = \begin{cases} -1, & \text{if } y_i \ge 0; \\ +1, & \text{if } y_i < 0. \end{cases} \)

Again, it is important to note that this algorithm requires the angle of the input vector to be in the range [-\(\pi\)/2,\(\pi\)/2]. For angles outside of this range, the point is first rotated by 2\(\pi\) and \(\pi\) as necessary until it is in the proper range.

After completion, the accumulated angle is the angle between the initial point and the x-axis, and the value of the x-coordinate is the distance to the point from the origin. In summary, the values of the last iteration of the vectoring mode algorithm are given by

\( x_n = \sqrt{x_0^2 + y_0^2} \quad y_n = 0 \quad \alpha_n = \tan^{-1}(y_0 / x_0). \)
