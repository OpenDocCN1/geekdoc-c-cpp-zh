where X, Y, and Z are the XYZ components of the scene's scattered light, which is the sum of the scattered light from the sun and the moon. The display luminosities $L_{daC}$ and $L_{daR}$ are set to 100 cd/m$^2$, but may be adjusted for brighter or darker scenes. The rod and cone thresholds from the scene are then mapped to rod and cone thresholds for the display, using a technique called *threshold mapping*. For both rods and cones, photopic, mesopic, and scotopic conditions are treated separately; the rod threshold is given by $\epsilon_R$ and the cone threshold by $\epsilon_c$:

```
\log \epsilon_R(L_{ad}) = \begin{cases} -2.86, & \text{if } \log L_{ad} \le -3.94; \\ \log L_{ad} - 0.395, & \text{if } \log L_{ad} \ge -1.44; \\ (0.405 \log L_{ad} + 1.6)^{2.18} - 2.86, & \text{otherwise.} \end{cases}
\log \epsilon_c(L_{ac}) = \begin{cases} -0.72, & \text{if } \log L_{ac} \le -2.6; \\ \log L_{ac} - 1.255, & \text{if } \log L_{ac} \ge 1.9; \\ (0.249 \log L_{ac} + 0.65)^{2.7} - 0.72, & \text{otherwise.} \end{cases}
```

What we really need is to compute two scaling values, one for rods ($m_R$) and one for cones ($m_C$):

```
m_R = \frac{\epsilon_C (L_{daC})}{\epsilon_R (L_{waR})}
m_C = \frac{\epsilon_C (L_{daC})}{\epsilon_C (L_{waC})}.
```

We also need a scaling value $k$ which is used to interpolate between full color perception from cones and blue-shifted monochromatic perception from rods in mesopic conditions. With the value $\sigma$ set to 100 cd/m$^2$,

```
k = \sqrt[3]{4} \frac{\sigma L_{waR}}{\sigma + L_{waR}}.
```
