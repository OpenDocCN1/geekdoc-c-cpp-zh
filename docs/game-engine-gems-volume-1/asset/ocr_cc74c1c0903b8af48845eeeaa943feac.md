# 27.3 Applications

The following table summarizes the computations that can be done by these two algorithms, given an initial vector(x₀,y₀) and an angle θ:

| Operation | Mode | Input | Results |
|---|---|---|---|
| Sine/cosine | rotation | (1,0), θ | cosθ = xₙ
sinθ = yₙ |
| Arctangent | vectoring | (x₀,y₀), θ | tan⁻¹(y₀/x₀)+θ = αₙ |
| 2D vector rotation | rotation | (x₀,y₀), θ | (x′,y′) = (xₙ,yₙ) |
| Vector length | vectoring | (x₀,y₀) | ||(x₀,y₀)||=xₙ |
