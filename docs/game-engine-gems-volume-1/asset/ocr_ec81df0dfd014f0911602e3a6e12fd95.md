this is to give each scalar component a weight that is applied
during the squared error analysis.

Even so, this technique is helpful because it affords greater control
over the fitting of data. Squared error strongly limits the deviation
per axis, so that you can control the importance of each scalar
within a sample by weighting the deviation on each individual with
a factor s_j. This can be used to more heavily weight the Y' luma
component rather than chrominance (CrCb), or to improve the z
component of normals at the expense of x and y. As you can see,
squared error is a little more expensive to compute as well:

\(\varepsilon = \sum_{i=1}^n \left[ \sum_{j=0}^2 (v_j - x_{ij})^2 s_j^2 \right] w_{x_i}.\)

(Here, x_ij is the component j of the sample i.)
