# Stringizing operator

So far have been using '#' for inclusion of files and macro definition. It can be
used as a stringizing operator, meaning whatever is appended after a '#', it will be
considered as string.

# Examples

```
#define print(var) #var -> macro definition
printf("%s",print(123)); -> prints "123"
printf("%s",print(C Programming)); prints "C Programming"
printf("%s",print(123.456)); prints "123.456"
```

# Token pasting operator

## is termed as token pasting operator. It takes 2 arguments. Its prime objective is
to concatenate the arguments together. For instance, sachin## tendulkar will become
sachintendulkar.
