**Important Note:** By value is the default argument passing mechanism. It prevents other modules changing the original values either intentionally or accidentally. But with one exception, when passing an array to a function, the base address of the array is passed to the function much like passing the reference. So, the function will be accessing the original array values and not the copy of it. So passing an array comes under passing by reference technique. Refer Program 5.8.

```c
#include<stdio.h>
#include<conio.h>
void inc(int [], int);
void main() {
    int a[10],n,i;
    printf("Enter the number of elements in the array..\n");
    scanf("%d", &n);
    printf("\nenter array values\n");
    for(i=0;i<n;i++)
        scanf("%d", &a[i]);
    printf("\noriginal array values...\n");
    for(i=0;i<n;i++)
        printf("%d->%d\n", a[i], a[i]);
    inc(a, n);
    printf("\nafter incrementing, from main()...\n");
    for(i=0;i<n;i++)
        printf("%d->%d\n", a[i], a[i]);
    getch();
}
void inc(int b[], int n) {
    int i;
    for(i=0;i<n;i++)
        b[i]=b[i]+1;
}
```

## 5.3. RECURSIVE FUNCTIONS

Refer to the Program 5.3 which is meant for calculating the factorial of a given number. The function factorial in the program makes use of 'iteration technique' to repeatedly calculate the value as follows.

```c
for (i=1;i<=num;i++)
    f=f*i;
```

Figure 5.4 Factorial using iteration

In each iteration, value of 'f' gets changed. When the termination condition is reached,(i.e.) when 'i' greater than 'num', the loop stops. And the recently updated value in 'f' is returned as the answer. The same job can be done using a concept called 'recursion' where we don't need a loop for iteration. Before going to the programmatic solution, let's understand the concept of recursion theoretically.

Let's do some maths work with factorial program.
Formula for factorial is as follows,

```
factorial(n) = n * (n-1) * (n-2) * (n-3) * ****** 1
factorial(1)=factorial(0)=1
```

Examples,
factorial(2)=2*1=[similar to factorial(1)]
factorial(3)=3*2*1=[similar to factorial(2)]
factorial(4)=4*3*2*1=[similar to factorial(3)]

Our focus henceforth will be with square bracket in the above examples. As it observed, factorial finding problem can be broken down into parts of lower complexity.

(i.e.) factorial(5)=5*factorial(4);
factorial(4)=4*factorial(3);
factorial(3)=3*factorial(2);
factorial(2)=2*factorial(1);
factorial(1)=1*factorial(0);
So, factorial(5)=5*4*3*2*1*factorial(0)=120

When we need to repeat an operation, we adopted iteration so far. Instead, when we call a function from itself each time with the value of variable changed, the process is called recursion So we learnt functions that called other functions and not themselves!! Recursive functions -> Functions that call themselves Program 5.9 explains the recursion.

One example would make recursion clearer. Program 5.8 explains the Fibonacci series using recursion. A quick glance of series problem goes here. Given an integer value, a series will be generated as follows. Let the number 7, Then the series would be 0 → 1 → 2 → 3 → 5 → 8. What is the logic behind the series generation? Every number in the series is the sum of its immediate predecessors from 3rd value. First two numbers are 0, 1 by default. Refer Program 5.10 Recursive solution to Fibonacci series.

```c
#include<stdio.h>
#include<conio.h>
void main() {
    void fibonacci(int, int, int);
    int n, fib;
    int a=1,b=1;
    printf("Enter the number:\n");
    scanf("%d",&n);
    fibonacci(a,b,n);
    getch();
}

void fibonacci(int a, int b, int n) {
    if(n>0) {
        printf("%d\t",a,a+b);
        fibonacci(b,a+b,n-1); //recursive call
    }
}
```

## 6.1. auto (automatic)

Their region of use is limited and it vanishes when the function gets complete! Most importantly, if not initialized, these are of no use and will hold garbage. Any variable which is declared in the body of a function is by default automatic. If someone wants to declare it explicitly as auto, then it can be done with a keyword auto.

> int meters;// Explicitly defined as auto.
int meters; // initialized as auto.

Since it is default, the keyword auto is used very rarely. Few interesting factors are there with auto. If keyword is used, then it has to be initialized with a value. It will be filled with garbage values, which is not expected behavior. A simple example is shown below with output to depict this behavior. In the program, there are 2 variables declared and one of them is initialized with integer value 10. When uninitialized variable will have some unwanted junk values which is in the execution result.

```c
#include <stdio.h>
main() {
    auto int ai;
    auto int bi1;
    printf("\nUn initialized(Garbage)%d",ai);
    printf("\ninitialized %d",bi1);
}
```

Execution Result:

initialized 10
