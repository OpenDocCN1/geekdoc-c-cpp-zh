# PRE-PROCESSOR DIRECTIVES

# Example

```
#include <stdio.h>
#define a(x, y) x##y
#define b(x) #x
#define c(x) b(x)
void main() {
    printf("%s\n", c(a(sachin, tendulkar)));
    printf("%s\n", b(a(22,55)));
    printf("%s\n", b(18*));
    getch();
}
```

After looking at the output, one can tell by themselves the following things.

+   1. The pre-processor directives clears the whitespaces before printing. So only, the space in front of tendulkar was ignored!
2. # simply prints the entire thing as it is provided to it considering them all to be strings. So only, it allows any type of values including, string (char array), int, float, etc.
3. Since # prints the arguments as it is, to experience the token pasting operator's work becomes tricky. Since, b(a(123,45)) will simply print “a(123,45)” and not 12345. c(x) is defined and called.

# 14.2.3 Conditional compilation

So far, the reader would have been provided with the basics about pre-processor directives. This section will go deeper into it by introducing conditional compilation constructs. If the reader has enough experience working with conditional constructs such as ‘if’, ‘else if’ ‘else’, then this section can be easily crossed.

Some of the pre-processor conditional constructs are,

+   * #if <identifier>
* #elif <identifier>
* #else
* #endif
* #ifdef <identifier>
* #ifndef <identifier>
* #defined <identifier>
* #!defined <identifier>
