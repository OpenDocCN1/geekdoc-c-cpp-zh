# Program 9.14 Strings and pointers

This example would have given a light on how strings can be accessed through the pointers.

Few more simple examples will be helpful for the reader. Here is program 9.15 presented for the readers. Stract operation is done and the result is stored in the pointer. The execution result is also presented for the reference.

Reader on through program 9.15, will get a better clarity of the concept.

```
#include <string.h>
#include <stdio.h>
int main() {
    char str1[] = "I";
    char str2[] = "LOVE INDIA.";
    char *string3;
    // character pointer which can hold address of
    // a character.
    string3 = strcat(str1, str2);
    // After strcat, the concatenated string is stored in a
    // Pointer string3, which will hold the address of first character of string.
    printf("%s\n", string3);
    getch();
}
```

Execution Result:
LOVE INDIA.
