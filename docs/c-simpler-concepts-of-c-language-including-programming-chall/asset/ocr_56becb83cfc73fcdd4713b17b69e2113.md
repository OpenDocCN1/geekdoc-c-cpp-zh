# CONDITIONAL CONSTRUCTS AND LOOPING

# 2.1.1. if condition.

Syntax:

if (condition to be evaluated)

----Action to be taken if the condition is evaluated to be TRUE------

Program 2.1 explains the condition is if condition.

```
#include<stdio.h>
#include<conio.h>
void main()
{
    int mark;
    printf("please enter the mark");
    scanf("%d",&mark);
    if(mark<35)
        printf("Sorry!!the user is not allowed to sit for the next level");
    else
        printf("Wow!!the user has passed, allowed to sit for the next level");
    getch();
}
```

# 2.1.2. if-else condition.

If the condition being evaluated in the if part happens to be FALSE, what to do, this
is answered by the else part.

Syntax:

if (condition to be evaluated)

{

----Action to be taken if the condition is evaluated to be TRUE------

}

else

{

----Action to be taken if the condition is evaluated to be FALSE------

}

Note: If there are more than one statement to be executed in the if part or in the
else part, they have to be enclosed in { } (Curly Braces).

Refer Program 2.2 for its usage.
