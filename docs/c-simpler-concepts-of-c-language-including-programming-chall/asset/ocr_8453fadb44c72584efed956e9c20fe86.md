# INTRODUCTION TO C PROGRAMMING

If the same variable name is used for global and local variable then local variable takes preference in its scope. Remember, it is a bad practise to use global variables and local variables with the same name.

A sample code is being used here to demonstrate the usage of Global variables. Reader can understand how 'functions' work when the read on the later part of the book. Now it is expected to just see the function as a subroutine. Program 1.2 is the program used to explain global's usage.

```
# include <stdio.h>
int i = 1; /* Global definition, before main declaration */
main() {
    i++; /* Global variable */
    function() { /* Function Call */
    printf("Value of i from Main = %d\n", i);
    }
function() {
    int i=100; /* Local definition */
    i++; /* Local variable */
    printf("Value of i from function\n%d", i);
n}
```

# Program 1.2 Global variables in C programming.

This will give the following result on execution.

Value of i = 101 from function
Value of i from Main = 2

i in main function is global and will be incremented to 2 because of i++. in function is internal and will be incremented to 101. When control returns to main the internal variable will die and any reference to i will be the global.

# 1.8 CONSTANTS

A constant is usually just the written version of a number. For an instance, 20, 35.743.The constants can be Octal, hexadecimal, and characters.

Octal constants are written with a leading zero - 012.
Hexadecimal constants are written with a leading 0x - 01bc.

Character constants are usually the character enclosed in single quotes; 'a', 'b', 'c'. Some characters can't be represented in this way.

They can be represented in the following way and will be called as escape sequences.

| Escape Sequences | Description |
|---|---|
| \a | Bell (alert) |
| \b | Backspace |
| \f | Formfeed |
| \n | New line |
