# 5.1.5. Library routines and functions

Referring to the benefits of functions in section 5.1, the third point speaks about the library functions. We can define some of the frequently used operations such as addition, subtraction, multiplication and put them all under one header file named arithmetic_operations.h, and, when needed, the header file should be included in the user program, so that the methods defined in the header files can be simply called without redefining them. Much like scanc() and printf() without defining them. Program 5.5 would explain it even better.

```
```int add(int a, int b) {
    return a+b;
}
int sub(int a, int b) {
    if(b>a)
        return b-a;
    else
        return a-b;
}
int mul(int a, int b) {
    return a*b;
}
int div(int a, int b) {
    return a/b;
}```
