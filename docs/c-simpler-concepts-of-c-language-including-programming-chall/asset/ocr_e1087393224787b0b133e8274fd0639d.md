# 5.1.2. The declaration

Similar to the variable declaration, one needs to declare the functions in 'C' before using it. Unless the compiler will flash an error. The declaration may go either inside the main() or outside the main.

Syntax:
<return function_name (types of parameters)>

+   * A function needs to return a value of any type.
If it is meant to return an integer value, for instance, sum of 'n' numbers, the return type would be int. It can return a char, a float, a char pointer. If it has nothing to return, then the function will be declared 'void'.
* Function_name is the name given by the user according to the logic of the function. For instance, sum, avg, sort, etc.

Note: The rules for naming the variables are applicable to functions also.
* Parameters are the arguments being passed.

It may take any number of variables of any type including a structure variable, array variable, etc.

```
Examples of function declarations
void sum(int,int);
int sum(int,int);
float avg(int []); -> passing an array variable.
char gender(struct student); -> passing a structure variable.
void swap(int,int);
sum(int,int)-> If no return value is mentioned, default data type- 'int' is used.
```

Note: Function declaration statement is also known as function prototype.!

# 5.1.3. Function call

Every person on the Earth has a name associated with. In order to refer a particular person, normally one would use the name of that person, for instance, his/her name would be used to call him/her. Similarly, when a function (already declared and defined) need to be used, we would generally call the function with its name.

While calling, return type and the type of the parameter are not used. Simply the name and the values are used to call.

Note: Maximum number of arguments that can be passed to a function is 256!
