# 7.4. POINTERS IN SHARING VARIABLES

As pointed out in the introduction section, pointers are useful when one or more entities want to use a same object. In this scenario, initializing the pointers would be preferable. Look into the Program 7.4, where the pointers p and p1 point to the same memory location, (i.e.) the memory location occupied by the variable. When both the contents are printed, answer will be the same. (Initially, var=10, so *p=*p1=10). At a later point, the value of the variable gets to 20. Since both the pointers to 'var', the change reflects when their contents are printed. Refer to Output 7.4.

Note: Unlike other type of variables, pointers cannot be subjected to so many operations. It can perform only a limited number of operations. One among them, pointer comparison. Two pointers can be compared only if both of them share an object! More on pointer operations will be discussed in Section 7.7.

```
#include<stdio.h>
void main()
{
    int var=10,*p,*p1;
    p=&var;
    p1=&var;
    printf("var=%d(using p)"
",var,p);
    printf("nvar=%d(using p1)"
",var,p1);
    var=20;
    printf("nafter changing,,\n");
    printf("nvar=%d(using p)"
",var,p);
    printf("nvar=%d(using p1)"
",var,p1);
    getch();
}
```
