# 1.4.1. Identifiers

As the name, it is used to refer every word of a C program. It is short used to refer each and every element of a C program like a variable, function or an array. Identifiers can have letters, digits and symbols. There are few rules to be remembered when naming an identifier. They are

+   a. First character must be an alphabet (be lower case or upper case) or an underscore
b. Upper case and lower case letters are different. X is not x.
c. Most importantly, keywords can never be used as identifier.
d. Two underscores cannot be used in succession.

Some of the sample identifiers are presented here in table 1.4.

| X_Identifier | y_123 | degree_celcius | _fahrenheit |
| Name_C | ProGRaM_c | name | sum |
