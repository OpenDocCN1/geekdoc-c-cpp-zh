# 2.1.4. The switch case

This construct is similar to if-else construct, but syntactically simpler and also easily understandable if-else. An example program is taken for reference and executed. The results are presented in Program 2.4.

Syntax:
switch (case label)

```
case <value1>: // similar to if (label==value1)
----Statements to be executed if case label is equal to value1----
break;
case <value2>:/ // similar to else if (label==value2)
----Statements to be executed if case label is equal to value2----
break;
```
