# INTRODUCTION TO C PROGRAMMING

# 1. Comment lines

The first line of the code starts with /* THIS IS MY FIRST C PROGRAM */. It is a comment given for the program. The only intention of having comment lines is to increase the readability and to help in better documentation. It is used fully for the benefit of programmers. If person 1 codes a program and person 2 wants to understand and understand it, these comment lines will be as helpful as a walking stick to an old man.

The comments will not increase burden to the processor. Performance will no be affected because of including the comment line. Also size of binary executable will not increase if there are more number of comment lines. Because compiler on seeing the /* */ will ignore those lines.

# Methods of commenting:

As shown in the code, one can start with the first line of commenting in a single line.

Or the last lines of the code starting with /* and it has lines from it. All the characters inside the /* to */ are considered by the compiler as comment lines only.

So based on the comfort of the program any style can be followed.

And few compilers allow //. Whatever written after // are treated as comments and they will not be executed by the compiler. But this is not supported in few compilers which users need to remember.

# 2. include <stdio.h> and header files.

#include <stdio.h> is the second line of the program. It starts with a pound sign, # which is followed by include.#include forms a pre-processor directive that tells the C pre-processor to look for a file and place the contents of the file in the location where the #include indicates.

It is actually a kind of work for the further processing. The pre-processor is a program that does some preparations for the C compiler before code is compiled.

And the reason for using < > is to tell the pre-processor to search for file stdio.h in a standard list of system directories.

# include "stdio.h" is also a correct option which indicates the pre-processor to look for file (stdio.h) in the same directory of the file that contains the #statement.

Based on the required programmer can select one of the above methods.

# 3. main () function

This is most important and special function in C. A program can have only one main function. Normally main () will be written in the top of the program after pre-processor
