# 15.6. SUMMARY

The experience of many projects leads to the conclusion that coding standards makes the project goes smoother. It makes the code readable, easily maintainable and makes it reusable. Since we can't expect all the developers of an application to remain in the project for its life time, the coding standards are a must for future enhancement and releases. Knowledge transfer to a new resource becomes an easy task with a more readable code. So the coding standard plays an important role in software application development.
