# 2.2.1.1. The do-while loop.

Syntax:
do
{"

A set of statements

What is the difference between a while and do-while loop?

The only difference between the two is, a while loop executes the statements only if the condition is satisfied, on the other hand, a do-while loop executes the statements first once, and at the end check for the condition; if the condition is satisfied, loop is continued, else terminated. In essence, a do-while executes the body of the loop at least once.

Program 2.9 shows a sample program for do-while loop.

```
#include <stdio.h>
#include <conio.h>
main()
{
    int i;
    printf("please enter the value of i:");
    do{
        scanf("%d",&i);
        printf("i=%d\n", i);
        i=i-10;
    }while(i>0);
getch();
}
```
