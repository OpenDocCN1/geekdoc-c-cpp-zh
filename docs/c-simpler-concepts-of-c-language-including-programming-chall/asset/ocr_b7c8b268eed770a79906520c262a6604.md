Structures do the very same job for us 😊

They act like a container which can hold different type of variables, which are in one way or the other related to each other.

# Properties of Structures:

+   → They are called ‘User – Defined Data types’.
→ They are given a unique name while declaration.
→ They do not contain any method declaration; they have only variables declared.
→ Variables inside the structure declaration are called, ‘the member variables’.
→ Structures can be passed as an argument to methods.
→ They can be partially initialized – Automatic Structures.
→ Structures can be declared inside another structure – Nested Structures.

# Syntax:

```
struct <name of the structure>
{
  //Member variable declarations
}[structure variables];
```

Example,
struct student
{
  char s_name[30];
  long int s_regno;
  int year_of_study;
  char branch[10];
};

# 8.1.1. Structure variable declaration

Now it is clear that structures are similar to the built-in data types. So, we can declare variables for them also.

Variables can be declared for the structures in two ways:

+   1. Inside the main function.
2. Before the semi colon at the end of structure declaration.
