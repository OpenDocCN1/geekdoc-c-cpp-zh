                        printf("%d->", i);

    scanf("%d",&option);

      printf("terminating...\n");

# POINTS TO REMEMBER

- A loop helps repeating a set of statements.
- for, while, do-while are the looping constructs in c.
- switch case is similar to if-else if-else construct.
- do executes the statements at least once.
- break statement takes the control out of the loop.
- continue skips present iteration and proceeds with the next.

Most of the time, the programs are supposed to deal with many values of same type. For instance, roll numbers of students of a class, their marks, their names, their average marks, etc.

## 3.1. DEFINITION

Grouping data items that have common name

### 3.1.1. Properties

- It comes under derived types.
- An array variable with size mentioned, roll_numbers[10]; type int
- The first element's address is called the base.
- Bytes for array are reserved consecutively from that base without any gap.
- Array's elements are accessed with an index, generally called 'subscripts'. For example, accessing the 3rd element is roll_numbers[2], and 4th by roll_numbers[3], where [2] and [3] are subscripts (Note that the index starts from 0).
- Subscripts and size of array should be positive integers.
- Compiler of C language will not check for 'out-of-bounds' error. So, trying to print an array whose index is larger than the maximum size would end up in printing 'junk' values instead of flashing an error. Hence, care should be taken by the programmer.

## 3.2. DECLARING AN ARRAY

Types of arrays
Generally,

- 1 dimensional array (1-D)
- 2 dimensional array (2-D)
- Multi-dimensional array (n-D)

are used. In this section, the syntax for declaring each of the above types of arrays will be discussed.
An array can be declared to any other variable, and declared before used by a program. But a ‘size’ of the array has to be mentioned during declaration so that, the compiler will make appropriate reservation of bytes in the memory. 1-D arrays 2-D arrays have 2 subscripts and n-D arrays have n subscripts.

Syntax
<data type>array_name[Size][size];
Examples for 1-D arrays

```c
int a[10];
float b[10];
char c[10];
```
