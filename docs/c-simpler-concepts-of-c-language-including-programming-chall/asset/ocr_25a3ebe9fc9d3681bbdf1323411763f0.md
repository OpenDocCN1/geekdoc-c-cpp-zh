# 7.7. OPERATIONS ON POINTERS

From the above programs, the reader would have come to a basic understanding of what can be done with pointers. This section briefs the do's and don'ts with pointers.

The following operations can be done with pointers.

+   1. Increment, Decrement
2. Addition, subtraction
3. Assignment
4. Comparison.

Of the 4, 1 and 3 have been extensively used in the programs illustrated above. Rest will be covered in this section.

# 7.7.1. Addition, subtraction on pointers.

++ and -- are a form of addition and subtraction we know. Only thing is they add or subtract 1*(No.of.bytes for the variable being incremented or decremented!). Unlike them, we can add or subtract an integer to or from a pointer variable, just like,

```
int i=10, *p;
p=&i;
printf("%d", *p);-- prints 10
printf("%d", *p+10)---- adds 10 to *p. prints 20.
printf("%d", *p-10)---- subtracts 10 from *p. so prints 10.
```
