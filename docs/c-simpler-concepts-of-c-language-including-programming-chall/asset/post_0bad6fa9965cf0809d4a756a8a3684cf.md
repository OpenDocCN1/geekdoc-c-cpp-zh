(I) initializes the pointer i with address of variable a.
(II) initializes the pointer f with the address of variable b.
(III) initializes the pointer c with the value NULL.

> Any type pointer can be assigned with the value NULL. Such a pointer is called NULL pointer.

## POINTERS

### Accessing the pointer variable's contents

A normal variable can be directly accessed with its name itself. Pointer variables are accessed with an asterisk in front. For instance, (considering the declaration int *p) printf("%u",p); -> this statement prints the contents of the pointer variable p, since p is a pointer variable, it is supposed to have an address in it. While printing addresses, the address specifier "%u" (for unsigned int) can be used.

Note: To print the contents of pointer variable, use '*'. To print the address of any variable, use '&'. '*' is also known as value of operator, and '&', the address of operator.

The following program demonstrates the above mentioned concept of pointers. Following the program is the output of the Program 7.1.

```
#include<stdio.h>
void main(){
    int var=20;
    int *p=NULL;//to nothing; the 'NULL' pointer
    char *c=0;
    float *f=NULL;//points to var
    p=&var;
    printf("%d (directly printing)",var);
    printf("\n%d (printing using pointer)",*p);
    printf("\naddress of var is %u",&var);
    printf("\naddress of pointer p is %u",&p);
    printf("\naddress of pointer c is %u",&c);
    printf("\naddress of pointer f is %u",&f);
    getch();}
```

## 7.2. MULTIPLE INDIRECTION

One can apply any operator number of times, based on the pointer type. If it is simply a pointer, then only one indirection operator can be used. There are some other types of pointers such as,

- * Pointer to a pointer (2 levels)
- ** Pointer to a pointer, which in turn a pointer to another pointer (3 levels)
- And so on.

In 2 level pointers, 2 '*' are used, in 3 level pointers, 3 asterisks are used. Program 7.2 makes use of these two types of pointers. Before looking into the program, glance the figure given below.

![](img/5bbdccabcf90cef7ee48b1b48eaa187d_113_0.png)

Figure 7.2 Multiple Indirections

```
#include<stdio.h>
void main()
{
    int var=20;
    int *p;
    p=&var;
    int **p1;
    p1=&p;
    int ***p2;
    p2=&p1;
    printf("\naddress of var : %u",&var);
    printf("\ncontent of p : %u",*p);
    printf("\naddress of p : %u",&p);
    printf("\ncontent of p1 : %u",*p1);
    printf("\nvar= %d (printing directly)",var);
    printf("\nvar= %d (printing using p1)",**(p1));
    printf("\nvar= %d (printing using p2)",*(*(p2)));
    getch();
}
```
