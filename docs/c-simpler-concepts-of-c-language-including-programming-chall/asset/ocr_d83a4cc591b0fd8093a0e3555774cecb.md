Note: Rules for naming an array are similar to those for naming a variable.

Examples for 2-D arrays
int a[3][3];
float b[10][2];
char c[10][30];

2-D arrays can be visualized as a matrix of elements. First example declares a 3*3 integer matrix, 2nd one declares a float matrix of size 10*2 where row size is 10 and column size is 2. But final example, c[10][30] declares 10 strings of size 30 characters. 3-D arrays will be dealt in Section 3.5.

# 3.3. INITIALIZING AN ARRAY

Like any other variable in 'C', an array can also be initialized with the help of assignment operator '=').

+   Initialization can be done during declaration or at a later point of time in the program.
For example, with respect to 1-D arrays,
1. While declaration,
int a[]={10,50,58,41,210,100}; // Note that size of the array is not mentioned.
2. At a later point in program (using a loop)
for(i=0;i<size;i++)
a[i]=0; // initializing all the values with '0'.
Or
Explicitly assigning values,
a[0]=10;
a[1]=20;
a[2]=30; and so on.
With respect to 2-D arrays,
int matrix[3][3]={1,2,3,4,5,6,7,8,9};
Or
int matrix[3][3]={{1,2,3},{4,5,6},{7,8,9]};
