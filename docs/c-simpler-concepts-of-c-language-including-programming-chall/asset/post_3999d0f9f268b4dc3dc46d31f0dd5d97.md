## 10.3.2 Reading from file

Reading from the file can reading a character from the file or reading a word from the file or it may be reading a number from the numeric file.

### 10.3.2.1. int fgetc(<file pointer>)

For reading a character from the file. If the reading is successful, this function returns the character (converted to int) that was read. Once the end of the file is reached, it returns EOF.

### 10.3.2.2. char *fgets(*word, int n, file pointer>)

This function reads 'n-1' characters into the 'word'. It stops reading when it encounters a newline. On successful execution, this function returns the word read, or NULL if end of file is reached or on some error in reading occurrences.

### 10.3.2.3. int getw(<file pointer>)

Sometimes there may arise to store only numeric values. In such situation, this function can be used, which writes the ASCII equivalent of the number being written to the file mentioned by the file pointer. (Performs automatic conversion to integer before writing to the file if the character being written is float or double.)

### 10.3.2.4. int fscanf(file pointer, control strings...), (variables...))

If there arises a need to read from the file which has a well defined structure, instance, a file with the following fields:

- 1. S.no $\rightarrow$ indicating serial number
- 2. Customer name
- 3. Date of purchase (In character array)
- 4. Total amount of purchase

fscanf() can be used to read the rows of the file as follows:
`fscanf(fp,"%d,%s,%s,%f",s.sno,s.cust_name,s.date,s.amt);` where s is the struct object.
This will return EOF on reaching end of file.

### 10.3.2. size_t fread (*ptr, size_t size, size_t n, file pointer)

This function reads 'n' objects of 'size' bytes from the file. It returns the number of objects read.

## 10.3.3. Writing to a file

10.3.2 dealt with reading data from the file. This section discusses library functions associated with writing to a file. The programmer can check the success of the function execution manually by locating the file in the drive from which the program is executed. After writing, the contents would have been changed.

### 10.3.3.1. int fputc(int c, file pointer)

This function writes the character c (int c will be converted automatically into char) to the file pointed by file pointer. Returns EOF on error condition.

### 10.3.3.2. int fputs(const char *s, file pointer)

Counterpart of fgets in 10.3.2.2. This function writes the character pointer s to the file pointed by the file pointer. On error condition, returns an EOF.

### 10.3.3.3. int putw(int n, file pointer)

This function writes the value n to the file. It doesn't return the value as it is. Instead, it stores the ASCII value of n. Returns EOF on encountering end of file.

### 10.3.3.4. int fprintf(file *ptr, control strings...), (variables...))

Writes the variables to the file. Returns the number of characters written or a negative value on occurrence.

### 10.3.3.5. size_t fwrite (*ptr, size_t s, size_t n, file pointer)

This function writes from array 'ptr' of size 's'. In case of error, it will be less than n which is the number of objects written.
