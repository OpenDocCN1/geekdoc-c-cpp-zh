- The data types are all dealt in detail int: This is a keyword used to refer to integer number. An integer is some sequence of numbers that has no decimal points in between. Based on word length of the computers the range of int can be defined. If an 8 bit computer is used the range can be calculated with the following formula:

```math
$$-2^{8-1}$ to $2^{8-1} - 1$$
```

This will give the range as -128 to +127. Same is the case with 16 bit computer. When used with the same scenario as one will get,

```
$$-2^{16-1}$ to $2^{16-1} - 1$$
```

This will now set the range as -32,768 to +32,767. Similarly one can calculate the range for a 32 or 64 bit computer.

## 1.7.2 Scope of a variable

To solve a complex problem the programmer normally breaks the problem into smaller pieces and deals with each piece by writing multiple functions. Then, all the functions are put together to form a complete program that can serve the purpose. In the complete program, there might be variables that have to be shared by all the functions. On the other hand, the use of some variables may be limited to only certain functions. That is, the visibility of those variables is limited, and values assigned to those variables are hidden from many functions.

Scope of the variable is the measure of lifetime of a variable. There are two types of scoping for variables to be introduced:

1. Local Scoping
2. Global Scoping

Reader is introduced with a small program on local scoping.

## Local Variables

Variable whose scope is limited within the block or function where it is defined called Local variables. Local variables must always be defined at the top of a block. There are a few things to remember when one goes on using a local variable. When a variable is defined, it has to be initialized by user. The variable will be alive only within the block. Once the execution is out of the block, the variable dies.

The following program 1.1 stands as a support for understanding the concept of local variables.

```c
#include <stdio.h>
main() {
    int i=10;
    int j=1;
    if(1){/*Always True, So loop will be executed*/
        printf("\n i is %d\n", i);
        /* i in main can be seen here */
        /* can be used for commenting */
    }
    if (1) {
        /* i is defined to this block */
        int i=100;
        printf("\n i is %d\n", i);
        /* Since this is local 100 will be printed*/
    }/* value 100 dies here*/
    printf("\n i is %d\n", i);/*value 10 is now visible.*/
}
```

## Global Variables

Global variable is defined at the top of the program file and it can be visible and modified by any function that may reference it. A global variable declaration looks normal, but is located outside of any of the program's functions. This is usually at the beginning of the program file, but after pre-processor directives. The variable is not declared in the body of the functions which access it. Modern programming practice recommends against the excessive use of global variables. They can lead to poor program structure, and tend to clog up the available name space.
