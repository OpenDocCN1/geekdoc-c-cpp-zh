# 3.7. POINTS TO REMEMBER

+   * Array is an ordered list of homogeneous elements.
* Array elements are accessed by their index position.
* C doesn't perform bounds check.
* Base address is the address of the first array element.
* 2-D arrays are visualized as matrices.
* 3-D arrays are visualized as ‘n’ 2-D arrays.
