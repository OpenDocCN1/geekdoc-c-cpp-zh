# 8.1.2. Initializing member variables

Member variables can be declared in two types:

+   1. Using dot (.) operator.
2. Using arrow (->) operator.

Initialization of member variables is done using the structure variable.
Syntax:

+   1. structure_variable.member_variable=value;
2. structure_variable->member_variable=value;

When to use dot operator and when to use arrow operator? If it is an ordinary variable, dot operator is used. (Refer the aforementioned Examples 1 and 2, the structure var1 has been declared as a non-pointer variable.) Else if it is a pointer holding the address of a structure variable, arrow operator is used. (Example is given next.)
