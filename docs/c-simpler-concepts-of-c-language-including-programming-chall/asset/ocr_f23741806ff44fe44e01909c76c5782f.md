# Program 14.5 Conditional compilation

In Program 14.5, the following directives are already present.

#define inc → already discussed in Section 14.2.2.

#ifdef inc → checks if the pre-processor directive has been defined in this.
#elif defined is elif nothing, but else if construct. This statement checks if inc has not been defined so far. In this case it's true. The statements followed by will get executed. This statement can also be written as #undef inc.
#if ((j1-i1)>0)→ #if defined can be used with constant expressions.
#else → it is must to close the #if block.
#endif
#undef <identifier>→#undef construct is used to define already defined directive. If no identifier is matched, it goes without ruffling the execution. (The line #undef PI has been commented in Program 14.5 since it is used inside the main())
#defined can be used just like !defined.
