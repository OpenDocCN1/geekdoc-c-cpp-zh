- 2. Addition, subtraction

Of the 4, 1 and 3 have been extensively used in the programs illustrated above. Rest will be covered in this section.

### 7.7.1. Addition, subtraction on pointers.

++ and -- are a form of addition and subtraction we know. Only thing is they add or subtract 1*(No.of.bytes for the variable being incremented or decremented!). Unlike them, we can add or subtract an integer to or from a pointer variable, just like,

```c
int i=10, *p;
p=&i;
printf("%d", *p); // prints 10
printf("%d", *p+10)---- adds 10 to *p. prints 20.
printf("%d", *p-10)---- subtracts 10 from *p. so prints 10.
```

But, one cannot add or subtract a pointer from another pointer, with two exceptions! One is, if we subtract two pointers which are of same type, then the result will always be 1. Second, with respect to arrays, if two pointers point to the same array, both pointers can be subtracted from one another, which will yield the number of elements between the two pointers. The effect is undefined for pointers pointing to different arrays. For example refer to the following figure.

# Pointers to functions

So far, the reader would have gone through programs where pointers to variables, arrays have been discussed. One can also have a pointer to functions; pass such pointer to another function, manipulations like any other pointer. Declaring a function pointer (pointer to a function) is simple.

Syntax:
`<return_type> (*function_name) (parameters);`

Example:
`void (*fp) (int, int);` declares a function pointer 'fp' which can point to a function that takes two arguments and returns nothing.

# Initializing function pointers

Suppose, there are function declarations as follows.

- void sum(int,int);
- void diff(int,int);

The function pointer previously can be made to point to the above declared functions as follows:
`fp=sum;` → fp points to function sum(). Afterwards instead of using `sum(10,20)`, one can alternatively use `fp(10,20);` (Note that the function should have been defined). After some time, the function pointer can be made to point some other function `diff()` in the same manner. Any number of function pointers can point to the same function, just like many pointers. Comparison is the only operation that can be done with function pointers. Complex function which is supposed to do a lot of works can outsource a portion of work to other function by receiving a pointer to that function.

# 7.8. DYNAMIC MEMORY ALLOCATION

Have you ever declared an array of size 20 or above and initialized it leaving the rest blank? If yes, there is loss of many bytes allocated for the array! Is there a way to allocate bytes according to necessity? The answer is YES! Where dynamic allocation enters the scene.

### 7.8.1. The Heap memory

If the reader had come across Random Access Memory (RAM), it will be simpler to move along. When system is booted for the first time, the OS occupies some memory leaving the rest for the user. Apart from the executable files, global variables declared in them will allotted some space while the programs execute. Do you think all memory space available will be occupied? Mostly not. There exists free space managed by the operating system called 'Heap' memory. What are the functions available to allocate and de-allocate memory dynamically?

- malloc()
- calloc()
- free()
- realloc()

Let's make use of each in detail in following.

### malloc():

Syntax:
`void * malloc(size_t size)` → allocates a block of size bytes. Returns NULL if failed.

Example:
`int *p;`
`p=(int *) malloc(sizeof(int));` → allocates 10 bytes of memory.
`p=(int *) malloc(sizeof(int)*20);` → allocates 20 bytes of memory.

Program 7.10 makes use of the function to dynamically allocate memory for array!

```c
#include<stdio.h>
void main() {
    int *p,i,size;
    printf("Enter the array size..\n");
    scanf("%d",&size);
    p=(int *)malloc(size*sizeof(int));
    if(p==NULL)
        printf("OUT OF MEMORY error!\n");
    else {
        printf("\nEnter array elements by one..\n");
        for(i=0;i<size;i++){
            scanf("%d",&p[i]);
        }
        printf("\narray elements are..\n");
        for(i=0;i<size;i++){
            printf("%d->",p[i]);
        }
        free(p);
        getch();
    }
```

It is a a good practice to always free the used memory to prevent any memory leak. The syntax to free up memory is simple, just use `free (pointer variable)`. After freeing the memory, it is illegal to operate the locations. The output for the above program is given below.

malloc() will be helpful to allocate memory for dynamically growing data structures including linked lists, trees, etc., allocate memory! The following program takes you through a concept called structures (discussed in detail in Chapter 11) where malloc() will be useful.

Structures are user defined types which can collectively hold any type of variable at a time. For example, there can be a structure 'student' which is defined to keep students details like name, age, degree, area_of_specialization, etc., declaring a structure is simple. Here it goes:

```c
struct student {
    long reg_no;
    char name[30];
    int age;
    int var;
};
```

In the above declaration, struct is the keyword to be used, student refers to the structure name, followed by a block of declarations. At the end, 'var' is declared, which serves as the variable for the just created student data type.(Yes, the structure hereafter serves as a data type, to which we can declare variables, assign values to the variables, just like we do for other built-in data types.)

Ok, how to allocate memory for a structure variable? It's simple. Just declare a pointer for the structure student, then follow the syntax mentioned above.

For example:

```c
struct student *s; // s is the pointer to a structure.
```

```c
s = (struct student *) malloc(sizeof(struct student)); // allocates memory based on the size of the structure.
```

### calloc()

There are two basic differences between malloc() and calloc().

- 1. malloc() is used to allocate a single block of memory. Whereas, calloc() can allocate n blocks of memory.
- Syntax:
`void *calloc(size_t n, size_t size)` → allocates n blocks of size bytes. Returns NULL if failed.
- 2. malloc() simply initializes all the requested memory. It doesn't initialize them. calloc() initializes all the bytes with zero.
