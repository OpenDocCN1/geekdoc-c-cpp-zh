# 10.3.4. Random access to files

### Table 10.2

| Constant | Meaning |
| :--- | :--- |
| SEEK_CUR | Denotes current position |
| SEEK_SET | Denotes the beginning |
| SEEK_END | Denotes the EOF. |

### Table 10.2 File constants

In order to move n bytes forward, fseek(fp, SEEK_SET) can be used. (Note that 'L' in second parameter denotes long value). To move n bytes backward, fseek(fp, -SEEK_CUR). (The minus sign before 'n'). this function will return a non zero value in case of any error.

### 10.3.4.2. ftell(file pointer)

This function tells the user, the current location of the file pointer. Returns -1 on error.

### 10.3.4.3. rewind(file pointer)

After moving forward or backward, the file pointer can be made to point to the original position where it was previously pointing to. This function helps so.
