# POINTERS

The advantage of using pointers in the above scenarios can be visualized when the reader tries to use the following code, where only one pointer is used, and a variable p1 copies with the value in. everything will be fine before the value of ‘var’ gets changed. Look at the Output 7.4.1.

```
#include<stdio.h>
void main() {
    int var=10,*p,p1;
    p=&var;
    p1=var;
    printf("var=%d(using p)",*p);
    printf("\nvar=%d(using p1)",p1);
    var=20;
    printf("\nafter changing,\n");
    printf("var=%d(using p)",*p);
    printf("\nvar=%d(using p1)",p1);
    getch();
}
```

# Output 7.4.1

From Output 7.4.1, it can be observed that the value of var is not changed when using p1. This is because, the statement “p1=var” assigns the current value of var to p1. The change thereafter won’t get reflected into the p1. So, everytime when the value of var is changed, we need to write a statement “p1=var” for the program to work perfectly. Pointers avoid this unnecessary doings. This concept is logically related to call by value/reference that was discussed in Chapter 5. The next section will detail with char and pointers.
