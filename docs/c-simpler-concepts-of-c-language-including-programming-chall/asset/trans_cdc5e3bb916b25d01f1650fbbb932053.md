# 8.1.6. 将结构体传递给函数

将普通变量或数组传递给方法是我们通常的操作。在讨论了强大的结构后，读者应该会产生疑问：“如何将整个结构体传递给方法以进行计算？”例如，将一个结构体数组传递给一个方法，该方法用于计算每个学生的总分和平均分。

将结构体传递给方法并不复杂。它很简单。

只需要在函数调用中提供结构体变量的名称。

假设我们有

- 一个名为 'Cricket' 的结构体
- 它的变量 `players[11]`（结构体数组）
- 以及一个处理球员记录的方法 `kriketers ()`
