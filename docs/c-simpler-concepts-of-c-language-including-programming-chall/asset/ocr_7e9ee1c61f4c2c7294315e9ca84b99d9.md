One might get a query on usage of linux in the code. It is a simple way to avoid usage of gcc in all those places and if there is need to use cc compiler it needs to be changed in only one place, which is at the top of the code.

How to run the file? Very simple. Just type make and press enter key. Compilation would have happened now. User will not have the pain of running all the steps. /main to be suited for execution. If someone wants to run the makefile again, if user issues make again, it would not remake it. unless there is a change in any of the files, the older object files will be used instead of regenerating the same. This is real intelligent act of saving time and resources.

But then, if the user is so particular in running the make file again and it can still be done with a clear make. This means, deleting the object files and regenerating it. As rm is the command used to remove the files, the last section is used to remove all the object files created and the executable file, main. And and now, user can go ahead and run the make file. It will generate the .o files and executable file as well which can be run.
