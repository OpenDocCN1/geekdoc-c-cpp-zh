# 4.2.7. Conditional operator

Consider the following code snippet.

```
int x,y,bigger;
x=10;
y=20;
if(x>y)
bigger=x;
else
bigger=y;
```

As it is clear from the above statements, 'bigger' stores the bigger value among variables x and y. the above statements can be reduced to a single statement with the help of conditional operator as follows.

bigger=(x>y)?x:y;
"?' is said to be the conditional operator. Expression before '?' is executed. Based on the result, either expression/value before ':' (colon) or after ':' is executed. In the previous case, value of y will be assigned to bigger. The parts of conditional operator are as follows.
