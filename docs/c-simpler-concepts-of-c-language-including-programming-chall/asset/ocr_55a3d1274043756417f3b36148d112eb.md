Character constants are rarely used, since string constants are more convenient. A string constant is surrounded by double quotes eg " PROGRAMMING". The string is stored as an array of characters. The null character '\0' is automatically placed at the end of such a string to act as a string terminator.

How to define constants?

A keyword has to be used to declare a constant. A couple of examples would help reader in getting this understanding.

```
int const a = 1;
const int a = 1;
```

Both the mentioned ways are correct and programmer can select any one of them.

# Defining constants with Pre-processors

# define is a pre-processor which can be used to define constants.

Following few lines show how to use # define

```
# define UP 1
# define DOWN 0
# define salary 2000
```

The pre-processor directives are discussed in Chapter 14.
