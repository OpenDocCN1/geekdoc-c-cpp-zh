# 4.2.8. Comma operator

Used in declaring, initializing variables, inside for loops, and in 'scanf' and 'printf' while dealing with many variables. Refer to the Program 4.9.
 operator in

```
#include<stdio.h>
main() {
    int i,j;
    for (i=0,j=10;i<=10;i++,j--)
    {
        printf("\ni=%d\tj=%d\n",i,j);
    }
    getch();
}
```
