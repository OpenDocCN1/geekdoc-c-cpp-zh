# 3.2. DECLARING AN ARRAY

Types of arrays
Generally,

+   - 1 dimensional array (1-D)
- 2 dimensional array (2-D)
- Multi-dimensional array (n-D)

are used. In this section, the syntax for declaring each of the above types of arrays will be discussed.
An array can be declared to any other variable, and declared before used by a program. But a ‘size’ of the array has to be mentioned during declaration so that, the compiler will make appropriate reservation of bytes in the memory. 1-D arrays 2-D arrays have 2 subscripts and n-D arrays have n subscripts.

Syntax
<data type>array_name[Size][size];
Examples for 1-D arrays

int a[10];
float b[10];
char c[10];
