# ## 7.1. INTRODUCTION

This chapter deals with a special kind of variable called pointer, which holds values which are not normal values, but the so called ‘addresses’.

# ### Why to use pointers?

It is the misunderstanding that prevails among many that pointers are difficult to understand. It is not. Pointers are very helpful and easy to use if learnt properly. It has got the benefits. The reader can substantiate them at the end of this chapter ©

+   - Pointers let many parts of the program to share variables and other objects. Without them, the programmer has to do so many copying works. Pointers reduce this burden.
- Pointers are used to create various useful data structures like linked lists, trees, etc. Data structures are discussed in Chapter 11.

# ### The definition

A pointer is a variable, which holds the address of the other variable of same type. A pointer variable is declared like any other variable, but with an asterisk (*) in front.

For example,

# #### Declaration of pointers

+   1. int *;
2. char *c;
3. float *f;

All the variables are declared as pointer variables. Declaring them with a '*' in front implies that these variables will store the addresses. This ‘*’ is called indirection operator.

So, the pointer variable is declared. How to initialize it?
