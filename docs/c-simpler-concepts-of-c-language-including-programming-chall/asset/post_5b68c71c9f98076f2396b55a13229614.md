
## 12 Command Line Arguments

## 12.1. INTRODUCTION

As previously mentioned, main() is the first function in any program to get executed. So far, main() was executed without any argument. This statement is quite arguable. The statement poses a question that, can main() take arguments? The answer is yes. The main() function can take arguments which cannot be passed from any other user defined function, when the program gets executed, main() will be the entry point in any program. So, from where to pass the arguments to main? The answer is Command Line Arguments. In this chapter, let's explore more about them.

## 12.2. THE ARGUMENTS

- main() takes two arguments generally.
- 1. argc - integer argument that indicates the argument count.
- 2. argv - character pointer array.

For example, refer to the following code snippet.

```c
void main(int argc, char *argv[])
{
    
}
```

Syntax - How to pass the values to argc, argv?
From the command prompt, the programmer needs to pass the values.
Assume the following call from the command prompt,

```
C:\turbo\prog cmdline_prog one two three
```

As it be observed from the previous line, C:\turbo\prog> is the path from where the C programs are executed. The following steps are followed to pass arguments to main().

- 1. go to Start->Run->cmd
- 2. in the command prompt, type the path from where the programs are executed using 'cd'. cd C:\turbo\prog.
- 3. From the prompt, first the name of the program is mentioned. In our case, cmdline_prog is the name of the program.
- 4. Followed by the program name, the parameters are passed to the main(). In our case, one two three are the parameters being passed.

Now, it's the time for us to explore more on argc, argv things.

argc

As previously mentioned, argc denotes the number of arguments being passed. In our example, argc will be 4. The count includes the file name (Program name) also!

- The first argument: the program name by default.
- Second argument: one (in our example)
- Third argument: two (in our example)
- Fourth argument: three (in our example)

It is mandatory for the programmers to at least mention the program name in the command prompt for execution, in case of using turboc Dev-Cpp platform, even if the programmer doesn't mention any argument, the program will be executed with the program name automatically. (Note: In Dev-Cpp, Execute Menu→parameters option is used to input command line arguments.

argv

The type of argc is integer. Type of argv is char pointer array. They can be accessed from inside the main( ) in the similar way one would access character pointer. So whatever value is passed is considered as a string (Character pointer array). Consider the following command line parameters.

```
C:\turboc\cmdline_prog 123
```

In the above line, 1, 2, 3 will be considered as "1", "2", and "3". (Note: If the programmer needs to work with integers they can use the library function atoi().

Let's work out simple arithmetic operations using command line arguments. Refer to Program 12.2.

```c
#include <stdio.h>
void main (int argc, char *argv[]) {
    if (argc != 3) {
        printf("Not enough arguments to perform arithmetic operations..");
    }
    else {
        printf("Argument 1 = %s, Argument2= %s\n", argv[1], argv[2]);
        printf("%s + %s = %d\n", argv[1], argv[2], atoi(argv[1])+atoi(argv[2]));
        printf("%s - %s = %d\n", argv[1], argv[2], atoi(argv[1])-atoi(argv[2]));
        printf("%s * %s = %d\n", argv[1], argv[2], atoi(argv[1])*atoi(argv[2]));
        printf("%s / %s = %d\n", argv[1], argv[2], atoi(argv[1])/atoi(argv[2]));
    }
    getch();
```

Having seen the program to work with integers, let's concentrate on String operations now. Program 12.3 explains string operations on command line arguments.

```c
#include <stdio.h>
#include <string.h>
void main(int argc, char *argv[])
{
    int i, choice;
    printf("\nargument count=%d",argc);
    for (i=0;i<argc;i++){
        printf("\narg[%d]=%s\n",i,argv[i]);
    }
    printf("\nWhat do you want to do now..\n1.Identity Check\n2.String Concatenation\n3.End\n");
    scanf("%d\n",&choice);
    do {
        switch (choice) {
            case 1:
                if (strcmp(argv[1], argv[2])==0) {
                    printf("\nStrings are identical..\n");
                } else {
                    printf("\nStrings are different..\n");
                }
                break;
            case 2:
                printf("\nThe concatenated string is %s\n",argv[1],argv[2]);
                break;
            case 3:
                break;
        }
        printf("\nWhat do you want to do now..\n1.Identity Check\n2.String Concatenation\n3.End\n");
        scanf("%d\n",&choice);
    } while (choice!=3);
    getch();
```

Note 1: It is possible for the programmer to change argc value from any part of the program and assign manually the argv array.
Note 2: argc is local to main(). It can't be accessed from functions defined outside main(). Referring to the following code for reference.

```c
#include<stdio.h>
#include<conio.h>
void fun();
void main(int argc, char *argv[])
{
    int i;
    printf("\nargument count=%d",argc);
    fun();
    getch();
}
void fun()
{
    printf("From inside the function, %d",argc);
}
```
**Program 12.4 Scope of argc**

On executing the program, an error will be flashed for using the function 'fun()' without declaring it. It is because, according to 'fun()' argc is a local variable which is used without declaring it. So, what is the remedy for it? How to make the other functions access command line arguments?

There are two ways in which one can achieve the process.

- 1. Pass argc, argv as arguments to functions, which will then have access to the copy of command line arguments. Refer to the following program.

| Actual parameters | Dummy parameters |
|---|---|

```c
#include<stdio.h>
void fun(int, char[]);
void main(int argc, char *argv[])
{
    int i;
    fun(argc, argv);
    getch();
}
void fun(int argc, char *argv[])
{
    int i;
    printf("%d",argc);
    for (i=0;i<argc;i++)
    printf("\n%s",argv[i]);
}
```
**Program 12.5 Passing command line arguments to functions**

Ok, what is the second way?

- 2. Assign the command line arguments to global variables, which can then be accessed by any function. Refer Program 12.6 for reference; but since global variables cause some problems in very large programs, it is generally not used!

```c
#include<stdio.h>
void func();
int argc;
char *argv[10];
void main(int argc, char *argv[])
{
    int i;
    for(i=0;i<argc;i++)
        argv[i]=argv[i];

}
```

### POINTS TO REMEMBER

- Parameters can be passed to the function main() from the operating system prompt as command line arguments.
- The command line arguments are accepted into special parameters to main( ), namely, argc and argv.
- argc decodes argument count which includes the program name also, and, argv, the argument vector.
- Parameters passed from command prompt are all of type character arrays.
- Minimum number of arguments that should be passed is one (The program name).
- argc and argv values are local to the main(). They cannot be accessed from outside!
