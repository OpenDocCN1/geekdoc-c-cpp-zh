# 13.3.5. Close system call ()

Close is used to close the file descriptor issued. It will close that one and fd number cannot be referred any more by process. A simple code will make life easier on close. The execution procedure remains same here too. After execution, run the code with ./ and check the monitor. It will be flashing a ‘0’ since fd has been closed. Reader can try with some available fd for close operation. After execution it shall flash a -1.

```
# include <stdio.h>
# include <fcntl.h>
# include <unistd.h>
# include <sys/stat.h>

int main ()
{
 int fdl,ret;

fd1 = open ("txt1.txt",0_RDONLY|0_CREAT,0777);
ret = close (fd1);

// Closing the file descriptor here. It cannot be referred after
// closing the same. Also if closing is done perfectly it will
// return a 0 else a -1.

printf("\n0 is Success \n -1 is failure");
printf("\n result %d", ret);
}
```
