# POINTERS

```
#include<stdio.h>
void main() {
    int *p,size;
    printf("Enter the array size...\n");
    scanf("%d",&size);
    p=(int *) calloc(size,sizeof(int));
    if(p==NULL) {
        printf("OUT OF MEMORY error!\n");
    } else {
        printf("nEnter the array elements one by one...\n");
        for(i=0;i<size;i++) {
            scanf("%d",&p[i]);
        }
        printf("\nThe array elements are...\n");
        for(i=0;i<size;i++) {
            printf("%d->",p[i]);
        }
        free(p);
        getch();
    }
}
```

# Program 7.11 calloc()

realloc()
There may be situations where you may feel for allocating the enough memory for arrays. During such circumstances, realloc() will be helpful to reallocate the already allocated memory while keeping the already initialized values.

Syntax
void *realloc(void *p, size_t new_size); -> reassigns the pointer p with new size.
Program 7.11 makes the perfect use of the realloc(0). This program initially allocates some memory for the arrays. If the user wants to insert more elements to the array, he/she can do so by realloc() the memory.
