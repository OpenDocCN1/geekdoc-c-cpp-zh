dup2:
syntax of the subroutine dup2() is as follows:

```
int dup2(int oldfd, int newfd);
```

Where, oldfd, newfd denote the old and new file
descriptors respectively.

This system call copies the oldfd to the newfd, which means that, both the file
descriptors point to the same file. For example:

```c
# include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main ()
{
 int fd1, fd2;
 fd1 = open("txt1.txt",O_RDONLY|O_CREATE, 0777);
 // here fd1 is duplicated to fd2.
dup2(fd1, fd2);
while(1)
{
}
n}
```

In this program, fd1 and fd2 hold the same reference. (i.e.) Both point to the text
document "txt1".

## 14.2.1. File inclusion

In 'C', if we want to print something or read something, we need simple I/O functions like printf() and scanf(). Almost all the programs would need these methods. If it was like, only the programmer has to define the functions every time by his/her own before using them, it would have no sense. The time is going to consume much larger than time taken to code logic

So, it was decided to put up some common methods in a 'file' and when the methods are needed, it is simply enough to just include the 'file' as pre-processor directives. Once the files are included, all the methods in that file can be used freely. So, how to include other files?

- 1. Using #include "filename"
- 2. Using #include<filename>

When the first type is used, the compiler searches for the particular file in two places. - 1. In the same directory/folder where the current file is present. For instance, suppose there is a file called ‘l.c’ is present in "B:/tc/Cprog/", and it includes the header file ‘stdio.h’. If the header file is present in the same path, (i.e) B:/tc/Cprog/stdio.h, the compiler won’t throw any error!
- 2. In the default path, where all header files will be saved. Else, it will flash the error. stdio.h: No such file or directory. When the files are included using angle brackets (<stdio.h>), the search is performed in default path alone. Even if the file is found current working directory, it will flash the error! What happens on successfully locating the file to included? If the file is located, all its contents will be pasted in currently working file before compilation. So that any reference to non-existing methods (that do not exist in current file but present in included file!) will perfectly work.

# Stringizing operator

So far have been using '#' for inclusion of files and macro definition. It can be used as a stringizing operator, meaning whatever is appended after a '#', it will be considered as string.

# Examples

```c
#define print(var) #var -> macro definition
printf("%s",print(123)); -> prints "123"
printf("%s",print(C Programming)); -> prints "C Programming"
printf("%s",print(123.456)); -> prints "123.456"
```

# Token pasting operator

## is termed as token pasting operator. It takes 2 arguments. Its prime objective is to concatenate the arguments together. For instance, sachin## tendulkar will become sachintendulkar.
