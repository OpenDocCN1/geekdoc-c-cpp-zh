# Program 8.14 Union Example

In the above program, integer value is assigned the value 1024. In the memory, the binary equivalent of 1024 (00000000 00000100 00000000 00000000) will be stored. The binary value won't be stored as such. They will be stored in Little Endian format, (i.e) in the reverse! As 00000000 00000000 00000100 00000000. It occupies 4 bytes totally. Each byte can be accessed individually.

myData.a[0] will be 00000000 (i.e) 0

myData.a[1] will be 00000010 (i.e) 4

myData.a[2] will be 00000000 (i.e) 0

myData.a[3] will be 00000000 (i.e) 0

If the user prints the x value, (i.e.) myData.x, it will print 1024!!

**Note:** Anonymous union is union without a tag or name. The member variables of such unions must be distinct from other variables within the scope in which union is declared.

# POINTS TO REMEMBER

- Structures and Unions are user defined data types.
- Structures hold variables of different types.
- Size occupied by the structure is the sum of sizes of its member variables.
- Bit fields allow variables to be stored into memory spaces smaller than the compiler would ordinarily allow.
- Unions and structures can be declared inside main().
- Structures can be declared inside another structure.
- A union declared inside a structure.
- Anonymous union doesn't have a tag.
- Members of partially initialized structures are automatically assigned default values of respective types.

# 9.1.1. What is a string?

A string is a collection of characters. A group of characters, stored in an array can be called as a string. There is no data type specifically meant for strings as available in C, or in few of the other programming languages. So char is the data type available for the programmers and array of characters forms string.

# 9.1.2. How to declare a string?

Simple. As conveyed the following syntax can be used to store a string C PROGRAMMING. The size of the string is not mentioned in this case, which will lead the compiler to do that task. Every string is terminated with a '\0' character, which is called as null terminator.

```c
char string[1] = "C PROGRAMMING";
```

One can also specify the size of string as follows

```c
char string[4] = "hello";
```

# (a) strlen ()

This is an inbuilt function which helps the programmers to find the length of the string passed as an argument. The null terminator '\0' would not be counted into account. A simple program is presented in program 9.4 with string().

```c
#include <stdio.h>
#include <string.h>
int main ()
{
    char string[18] = "PROGRAMMING";
    int i;
    i=strlen(string);
    printf("\nLength of the string is %d",i);
    return 0;
}
```

# Execution Result:

Length of the string is 12

# Program 9.4 strlen ()

This function returns the length of a string passed to it as an argument. The string terminator, i.e. the null character is not taken into consideration.

Well, most of interviewers ask this question. Can someone find the length of a string without using()? Solution is presented in program 9.5.

```c

int main ()
{
    char string[13] = "PROGRAMMING";

    for (i=0; string[i] != '\0'; i = i + 1);

    return 0;
}
```

# (b) strcpy()

This will help the programmer with copying one string to another. Syntax of strcpy is very simple.

Syntax: strcpy (destination_string, source_string);
A sample code using strcpy () is presented below in program 9.6.
