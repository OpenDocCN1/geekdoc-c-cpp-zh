# STORAGE QUALIFIERS

```
# include <stdio.h>
static int upper;
/*Defined as static, so initialized to 0*/
int lower;
/* Global, so by default static */
main()
{
    printf("Stored with value (defined as static) %%d\n", upper);
    printf("Stored with value (global)%%d\n", lower);
}
```

# Execution Result

Stored with value (defined as static) 0
Stored with value (global) 0

# Program 6.3 Default values for static variables.

To prove the static variables work, the program 6.2 is being taken again and static is used in place of auto (program 6.4). Execution is done and the result says it all. The value stored in static variable is retained for every time the function () is called and final result is shown as expected.

```
#include<stdio.h>
main()
{
    int i, ret;
    for (i=1; i<10; i++)
    {
        ret = add();
    }
}

int add()
{
    static int sum = 0;
    sum++;
    printf("\n Sum is %%d\n", sum);
}
```

# Program 6.4 Scope of auto variables.

Though global and static variables seem like the same, there is a difference between them. Global variables have file level scope, whereas in static, it is restricted to function leveling.
