# # CHAPTER 3 Arrays

Most of the time, the programs are supposed to deal with many values of same type. For instance, roll numbers of students of a class, their marks, their names, their average marks, etc. In such situations, it is undesirable to have a variable for each student.

For example, while dealing with roll numbers, having variables roll1, roll2, roll3, roll4......etc., would waste memory as well as it is a tedious process, and handling them is difficult too. So what's the remedy? It's an array which would overcome aforementioned pitfalls.

# ## 3.1. DEFINITION

Grouping the data items that have coinciding properties, characteristics under a common name.

In the above roll number example,

We can have an array named 'roll_numbers' of type int/long int.

# ### 3.1.1. Properties

+   * It comes under the derived data types family.
* An array variable is any other variable with its size mentioned during declaration as follows, int roll_numbers[10]; -> int is the storage class/data type of the array. Array name roll_numbers, size is 10. (Note that the size is mentioned in square brackets).
* If the array is initialized with values during declaration itself, (discussed in Section 3.2) size may be left unspecified.
* Declaring an integer array would reserve 2/4 bytes normally. Similarly, declaring an integer array would reserve 2/4*(size_of_array) number of bytes.
* The first element's (in array) address is called the base address.
* Bytes for array are reserved consecutively from that base without any gap.
* Array's elements are accessed with an index, generally called 'subscripts'. For example, accessing the 3rd element in roll_numbers is done as, roll_numbers[2], and 4th by, roll_numbers[3], where [2] and [3] are subscripts. (Note that the index generally starts from 0 and hence, 3rd element is accessed with the subscript[2] 4th with index[3] and so on).
* Subscripts and size of array should be positive integers.
* Compiler of C language will not check for 'out-of-bounds' error in arrays. So, trying to print an array whose index is larger than the maximum size of the array would end up in printing 'junk' values instead of flashing an error! Hence, care should be taken by the programmer.
