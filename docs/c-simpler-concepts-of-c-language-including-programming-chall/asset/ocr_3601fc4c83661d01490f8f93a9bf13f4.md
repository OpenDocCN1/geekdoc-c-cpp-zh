# 5.1.6. Function calls and stack.

Let's look into more intrinsic details about the working of functions.

As previously mentioned, main() is the entry point for any program. The compiler executes line by line until a user defined function call is encountered. The compiler needs to jump to the location of function definition outside the main() if it encounters a function call inside the main(). If it doesn't find an appropriate function definition, it flashes an error! OK, What if it finds one? It executes line by line in the function definition until the function is terminated by a ')'.

After the brace closure '}', the compiler jumps back to the previous position main()(i.e. back to the function call position in main()).

This is the mechanism followed for function executions. One probable question at this place would be, how can the compiler reclaim the place where it jumped off the main()? The answer to this question lies in a data structure called 'The Stack'. It is much like a container where we put something in and take off the same thing after some time. The basic operations in stack are:

+   1. Push – Putting the item to the stack.
2. Pop – Taking out the item from the stack.

> Note : Stack operates in LIFO fashion, when we pop the item that was recently pushed (Last In First Out). TOS is a pointer which points to the Top of the Stack.

During the function call, we push the local environment.
While returning from the function, we push and restore the local environment.
An example would make it simpler.

Assume a call is performed from main() to a user defined function fun(). The following steps are performed during the function call.

+   * The compiler saves local environment of main() in the stack.
* Jumps to first instruction of fun(), and executes function.
* Then returns from fun(), passing return value(if any) to main().
* Restores environment of main().
* Resumes execution in main just after the function call to g.

As another example, assume, f(1) calls f(2), f(2) in turn calls f(3).View this as f1(f2(f(3))). Where, f(3) is the innermost function, and gets executed first. After that, control returns to the function f2. Finally, it f1 gets executed and the control returns to the main function.
