# 4.3. PRECEDENCE OF OPERATORS

When the compiler encounters an expression like 'a+b*(c-d)+(e%f)-g', it will have to apply some rules based on the importance @ precedence of operators for evaluating the expression correctly. Following the rules will avoid conflicts in expression evaluation.

When talking about expression evaluation, 'associativity' comes into the picture. When a particular operator occurs more than once in an expression, the compiler will decide on which direction to execute the operators. Whether to proceed from left or right. The Table 4.5 describes the precedence associativity details.
