3. Find, how many times ‘hi’ gets printed.

```
#include <stdio.h>
#include <conio.h>
main()
{
    int i,j,k;
    for(i=0;i<2;i++)
    {
        for(j=0;j<2;j++)
        {
            for(k=0;k<2;k++)
            {
                printf("hi");
            }
        }
    }
}
```

+   a. 8 times
b. 2 times
c. 6 times
d. 4 times
