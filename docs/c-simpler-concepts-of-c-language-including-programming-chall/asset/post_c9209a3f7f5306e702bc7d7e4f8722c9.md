```c
#include<stdio.h>
void main() {
    int *p, size;
    printf("Enter the array size...\n");
    scanf("%d", &size);
    p = (int *) calloc(size, sizeof(int));
    if(p == NULL) {
        printf("OUT OF MEMORY error!\n");
    } else {
        printf("\nEnter the array elements one by one...\n");
        for(i = 0; i < size; i++) {
            scanf("%d", &p[i]);
        }
        printf("\nThe array elements are...\n");
        for(i = 0; i < size; i++) {
            printf("%d->", p[i]);
        }
        free(p);
        getch();
    }
}
```

# Program 7.11 calloc()

## realloc()
There may be situations where you may feel for allocating the enough memory for arrays. During such circumstances, realloc() will be helpful to reallocate the already allocated memory while keeping the already initialized values.

### Syntax
`void *realloc(void *p, size_t new_size);` -> reassigns the pointer p with new size.

Program 7.11 makes the perfect use of the realloc(0). This program initially allocates some memory for the arrays. If the user wants to insert more elements to the array, he/she can do so by realloc() the memory.

```c
#include<stdio.h>
void main() {
    int *p, oldsize, options, rem;
    printf("Enter the array size...\n");
    scanf("%d", &oldsize);
    p = (int *) calloc(oldsize, sizeof(int));
    if(p == NULL) {
        printf("OUT OF MEMORY error!\n");
    } else {
        printf("\nEnter the array elements one by one...\n");
        for(i = 0; i < oldsize; i++) {
            scanf("%d", &p[i]);
        }
        printf("\nThe array elements are...\n");
        for(i = 0; i < oldsize; i++) {
            printf("%d->", p[i]);
        }
        printf("\nDo you want to increase the size of the array? (0:NO ;1:YES)\n");
        scanf("%d", &options);
    }
}
```

# POINTS TO REMEMBER

- Pointers hold the address of another variable of same type.
- A pointer variable declared with a '*' in front; address of a variable is obtained by &variable; value of pointer can be obtained by *pointer variable.
- Pointers which are declared but left uninitialized are called bad pointers that point to a random memory locations.
- Any number of pointers can point to the same variable, meaning that, many pointers can share a single variable.

- Pointers are helpful in passing by reference.
- Increment, decrement, addition, subtraction, comparison can be performed on pointers.
- A pointer variable occupies 4 bytes. There are some other types of pointers called near and far pointers which occupy 16 bits (2 bytes) and 32 bits respectively. Near far pointers will not work with linux GCC and visual C++.
- Dynamic memory allocation constructs are malloc(), calloc(), realloc(), free().
- Dynamically allocated memory should be freed after usage.
- There is an inherent relationship between pointers and arrays. When an array is passed to a function as an argument, its base address will be passed to the function.
- Function pointers are those which can point to functions.
