# 2.2.2. The while loop

Syntax:
Initialization;
while(condition for termination)
{
---statements to be executed---
Increment/decrement statement;
}

When a while loop is preferred?

A while loop is preferred than a for loop, when the programmer, is not aware of the number of iterations.

The following program 2.8 shows the way while loop may be used.

```
#include<stdio.h>
#include<conio.h>
void main()
{
    int number, value;
    number=100;
    while(number>0)
    {
        printf("Please enter the number to be subtracted from 100 (<100) ");
        scanf("%d",&value);
        number=number-value;
        printf("Remaining Number:%d\n",number);
    }
    printf("Terminating...");
    getch();
}
```
