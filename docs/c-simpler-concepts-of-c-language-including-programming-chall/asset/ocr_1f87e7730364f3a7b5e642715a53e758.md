# Program 3.2 deals with the dynamic initialization of 1-D arrays.

```
#include <stdio.h>
#include <conio.h>
void main()
{
    int a[10];
    float c[3];
    int i,size;
    printf("Enter the number of elements in integer array (Max size 10):\n\n    scanf("%d",&size);
    printf("\n");
    printf("Enter the %d elements of the integer array one by one...\n",size);
    for(i=0;i<size;i++)
    scanf("%d",&a[i]);
    printf("Enter the 3 elements of the float array one by one...\n");
    for(i=0;i<3;i++)
    scanf("%f",&c[i]);
    printf("\nThe integer array elements are...\n");
    for(i=0;i<size;i++)
    printf("%d--> ",a[i]);
    printf("\nnThe float array elements are...\n");
    for(i=0;i<3;i++)
    printf("%f--> ",c[i]);
    getch();
}
```

# Output 3.2

As it can be observed from the Output 3.2, it's not necessary to input a float value compulsory for the float array. While printing, the value gets automatically cast to float and printed as -986.000000. This is known as upcasting or implicit conversion. More about casting in Chapter 4.
