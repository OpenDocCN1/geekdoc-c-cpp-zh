Well, the process can be made simpler more now. Without having necessity to generate the object files explicitly, one can generate the executable with the command

$ gcc -o prog1.c

This will get the executable file generated right away and will be named as a.out.

When this is run as ./a.out the program will be executed and results will be available on the screen.

There can be a question raised, if in a same directory, so many files are to be executed how the a.out file will be formed? It will be a over writing of a.out if multiple files are to be executed there can't be multiple a.out files kept for the purpose.

So to avoid this problem naming the executable file is allowed and it can be simply with following command,

$ gcc -o executable prog1.c

After execution, once will get the executable as the executable file and can be run as /executable.
