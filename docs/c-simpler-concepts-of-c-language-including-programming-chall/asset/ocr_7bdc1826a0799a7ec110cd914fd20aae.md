# ## 13.3.7. getpid() and getppid system calls

As discussed in the past, every process will have a process id and also parent process id. To get the information on PID (Process ID) and PPID (Parent Process ID) we have getpid getppid system calls. The usage is very simple and the same has been presented in the following code snippet. the execution procedure remains the same as usual. Refer Fig 13.9 for understanding.

```
# include <stdio.h>
# include <unistd.h>
```

```
int main ()
{
    printf("\n The Process id is %d", getpid() );
    printf("\n The Parent Process is %d", getppid() );
    return 0;
}
```

# ## 13.3.8. dup and dup2 system calls ()

As previously seen, file descriptors are unique identifiers for the processes which are open. (Those who are familiar with 'C' can correlate file descriptor with a pointer). Each process has a file descriptor table associated with them. The table has the file descriptors which refer to an open file, and a set of flags.

This particular system call 'dup' is intended to duplicate an open descriptor.

Note: dup () makes use of the lowest-numbered unused descriptor for the new descriptor.
