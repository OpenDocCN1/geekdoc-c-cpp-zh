# 11.6. CIRCULAR LINKED LISTS

Having seen about doubly linked lists, it will be very easy for the readers to learn circularly linked lists. The only difference between this and doubly linked list is that, in circularly linked list, the last node's next pointer will be pointing the first node in the list. Pictorially, it can be represented as follows.

![](img/5bbdccabcf90cef7ee48b1b48eaa187d_197_0.png)

Figure Circularly linked lists

While programming this data structure, care should be taken to converge at a particular place since the right pointer is not NULL.

# 11.7. ADVANTAGES OF LINKED LIST OVER ARRAYS

| Property | Linked List | Arrays |
|---|---|---|
| Size | Dynamically resizable | Static; declared initially. |
| Accessibility | In both directions, if doubly linked. | Only one way. |

**Note:** If there is a definite bound on size of linked list, it is wise for arrays rather than relying on linked lists, accessing the particular element in linked list is time consuming.
