Note: Generally, an integer variable occupies 4 bytes, char variable 1 byte and so on., in 32 bit processors. An Obvious question at this juncture would be, how much memory would a structure variable occupy? The following section answers this question?

Consider the following structure declaration,

```c
struct A1
```

According to the previous note, the size of the structure ‘A1’ would be 6. But, to the reader’s surprise, when sizeof(struct student) is printed, it would print the output as ‘8’.
What is the miracle?

The reason is that the compiler will align member variables to a multiple of the pack size or a multiple of the type size, whichever is smallest.

Default pack size is usually 8 bytes.

## 8.1.3. Bit fields and structures

Another interesting and useful concept with respect to the ‘memory saving methodology is the use of ‘bit fields’ in structure declaration.

Where can we use this ‘bit field’ concept?

There may be situations where the programmer is very sure of range of range of values a variable can take. For Example, suppose an integer variable ‘marks’ would contain values in the range [0,100].

It needs maximum 7 bits to store the upper bound value 100 (1100100). But every number is stored either in 8 bit or 16 bit format. Let’s consider the first. 8 bit representation. In our case, the value 100 would be stored, as 01100100. So, a total of 8 bits do for our ‘marks’ case!

So why to waste 4 bytes when 1 byte is enough?

Go for Bit Fields!!!

The Definition:

Both C and C++ allow integer values to be stored into memory spaces smaller than the compiler would ordinarily allow. This space-saving structure members are called fields, and their width in bits can be explicitly declared.

## Syntax:

```c
int <variable> : <number_of_bits>;
```

Example,

```c
int marks:8;
```

Program 8.5 explains the bit fields.

```c
#include<stdio.h>
#include<conio.h>
struct bitfieldtest {
    int marks:10;
    var var;
}
void main() {
    var.marks=100;
    printf("%d",var.marks);
    getch();
}
```

# Program 8.5 Bit Fields

The following restrictions apply to bit fields.

- There can't be an array of bit fields
- One can't take the address of a bit field
- We can't have a pointer to a bit field
- We can't have a reference to bit field

Note: The maximum bit field length is 64 bits.

## 8.1.5. Array of structures

Structure variable alone or Declaring Variable alone cannot satisfy the requirements of most of the applications like payroll processing where the same structure is applicable to all the employees of the organization. In this case, having an array of structures would help.

Declaring array of structures

```c
struct student
{
    char s_name[30];
    long int s_regno;
    int year_of_study;
    char branch[10];
```

| students[50] refers to the structure array!!

Accessing the member variables using the 1st student name,
- students[1].s_name -> refers to the 1st student register number,
- students[5].branch -> refers to the 5th student branch.

A program would explain the concept more clearly. Refer Program 8.9.

```c
#include <stdio.h>
#include <conio.h>
struct student {
    char s_name[30];
    long int s_regno;
    int year_of_study;
    char branch[10];
} var[50];
void main() {
    int index=0,yesno,i;
    do {
        printf("Enter the details of the Student[%d]:\n", index+1);
        printf("Name : "); scanf("%s", &var[index].s_name);
        printf("Reg No: "); scanf("%d", &var[index].s_regno);
        printf("Year : "); scanf("%d", &var[index].year_of_study);
        printf("Branch: "); scanf("%s", &var[index].branch);
        printf("\nWant to continue? (YES/NO: 1/0)"); scanf("%d", &yesno);
        index++;
    } while (yesno!=0);
    printf("\nThe Details of the students are......");
    printf("\nName\tREGNO\tYEAR\tBRANCH\n");
    for (i=0;i<index;i++) {
        printf("\t%s,\t", var[i].s_name);
        printf("\t%d,\t", var[i].s_regno);
    }
    printf("\t%d,\t", var[i].year_of_study);
    printf("\t%s\t\n", var[i].branch);
}
    getch();
}
```
