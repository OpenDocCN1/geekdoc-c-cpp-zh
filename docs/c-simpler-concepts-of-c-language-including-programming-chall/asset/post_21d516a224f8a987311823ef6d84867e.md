Unary operators are operators that take only one operand. There are several unary operators:

- Increment (++)
- Decrement (--)
- Logical NOT (!) )
- Bitwise NOT (~)
- Size of (sizeof)
- Address-of (&)
- Indirection/Dereference (*)

The increment operator is used to increase the value of a variable by 1. For example, suppose we have an integer variable a = 10; a++; a++;

The decrement operator is used to decrease the value of a variable by 1. For example, suppose we have an integer variable a = 10; a--; a--;

The logical NOT operator is used to invert the logical value of an operand. If the operand is true, NOT returns false, and if it is false, returns true.

The bitwise NOT operator is used to invert the bits of an operand.

The sizeof operator returns the size of a data type or variable in bytes.

The address-of operator is used to get the memory address of a variable.

The indirection operator is used to access the value stored at a memory address.

Example of unary operators:

```c
#include<stdio.h>
void main() {
    int a = 10;
    int b = 20;
    printf("Initial a: %d\n", a);
    a++;
    printf("After increment a: %d\n", a);
    a--;
    printf("After decrement a: %d\n", a);
    printf("Logical NOT of b: %d\n", !b);
    printf("Size of a: %zu bytes\n", sizeof(a));
    printf("Address of a: %p\n", &a);
    int *ptr = &a;
    printf("Value at ptr: %d\n", *ptr);
}
```
