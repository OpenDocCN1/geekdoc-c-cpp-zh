# 100 C-SIMPLER

(I) i=&&a;
(II) f=&&b;
(III) c=NULL;

(I) initializes the pointer i with address of variable a.
(II) initializes the pointer f with the address of variable b.
(III) initializes the pointer c with the value NULL.

> Any type pointer can be assigned with the value NULL. Such a pointer is called NULL pointer.

It is always a good practice to make the pointer variable assigned with a NULL during declaration itself. If it is not assigned with a NULL, then the pointer variable will be holding a random address in the memory space which is not the desirable character. Consider the following declaration.


# Effect of uninitialized jargon

In programming, uninitialized pointer is termed as 'bad pointer'. It is because, the effect of using such pointer can be wildly. It can halt the execution of program, may even corrupt some memory addresses. So beware of using such pointers.
