# 7.3. COMPATIBILITY AMONG POINTERS

The reader would have seen about conversion of variables. When there is an expression with different types of variables, the compiler checks for compatibility among the variables before executing the expression. Consider the following piece of code.

```
//ptr.c
#include<stdio.h>
void main()
{
    char c[10];
    c=10;
    getch();
}
```

In the above coding, there is a char array declared. And there is an assignment operation, which assigns an int value to a char array c. Compiling the above code will throw the following error!

C:\ptr.c incompatible types in assignment.

Similar to the above case, in pointers there is a rule that, pointer variable should be pointing to the address of another variable of its own type! If an int pointer holds the address of a float variable, then it is a compatibility problem. Refer to Program 7.3. On compiling the following program, the following warning was flashed.

C:\pointer3.c [Warning] initialization from incompatible pointer type

Purposefully the warning has been ignored. And the results results in Output 7.3. The value of the variable is not printed correctly. Try not to follow such practices.

```
#include<stdio.h>
void main()
{
    float var=20;
    int *p=&var;
    float *p1=&var;
    printf("Using int pointer,val of var :%%f",*p1);
    printf("\nUsing float pointer,val of var :%%f",*p);
    getch();
();
}
```
