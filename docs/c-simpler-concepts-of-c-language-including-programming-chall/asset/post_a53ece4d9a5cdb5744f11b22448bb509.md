# INTRODUCTION TO C PROGRAMMING

## 1. Comment lines

The first line of the code starts with /* THIS IS MY FIRST C PROGRAM */. It is a comment given for the program. The only intention of having comment lines is to increase the readability and to help in better documentation. It is used fully for the benefit of programmers. If person 1 codes a program and person 2 wants to understand and understand it, these comment lines will be as helpful as a walking stick to an old man.

The comments will not increase burden to the processor. Performance will no be affected because of including the comment line. Also size of binary executable will not increase if there are more number of comment lines. Because compiler on seeing the /* */ will ignore those lines.

## Methods of commenting:

As shown in the code, one can start with the first line of commenting in a single line.

Or the last lines of the code starting with /* and it has lines from it. All the characters inside the /* to */ are considered by the compiler as comment lines only.

So based on the comfort of the program any style can be followed.

And few compilers allow //. Whatever written after // are treated as comments and they will not be executed by the compiler. But this is not supported in few compilers which users need to remember.

## 2. include <stdio.h> and header files.

#include <stdio.h> is the second line of the program. It starts with a pound sign, # which is followed by include.#include forms a pre-processor directive that tells the C pre-processor to look for a file and place the contents of the file in the location where the #include indicates.

It is actually a kind of work for the further processing. The pre-processor is a program that does some preparations for the C compiler before code is compiled.

And the reason for using < > is to tell the pre-processor to search for file stdio.h in a standard list of system directories.

# include "stdio.h" is also a correct option which indicates the pre-processor to look for file (stdio.h) in the same directory of the file that contains the #statement.

Based on the required programmer can select one of the above methods.

## 3. main () function

This is most important and special function in C. A program can have only one main function. Normally main () will be written in the top of the program after pre-processor directive. But it can be written anywhere, since execution will start only from the main ( ) irrespective of where it is written. A program ends with main as well. A program ends with all the statements within the main ( ) are executed.

## 4. printf statement

printf is a useful function which helps in print messages. There are format specifiers which are in C programs for getting the output in desired format. Here are the set of format specifiers (table 1.2) available for the programmers.

```
%si or %d    int
%c         char
%vf         float
%lf         double
%s          string
```

outputs can be obtained in desired format using the format specifiers.

## 5. return

All C functions return values. And so is main ( ). It returns an integer by default. There is a statement, return 0; in the program, it indicates that 0 is returned from the main() function and the program is terminated normally. A nonzero value returned by the return statement tells the operating system that an error has occurred. The bigger the return value, the more severe the error.

Now to sum up, read the following points.

- 1. C is case sensitive programming language. It means in C printf and Printf will have different meanings.
- 2. C has a free-form structure. End of each C statement must be marked with a semicolon.
- 3. Multiple statements can be written on the same line.
- 4. White Spaces (i.e. tab space and bar) are ignored.
- 5. Statements continue over multiple lines.

# INTRODUCTION TO C PROGRAMMING

Now to compile the program written, some steps need to be followed. Before that would be better to know the internal happenings when a file is compiled. When compilation is on, firstly if there is no compilation or syntax errors the object file will be formed and it will be created with the extension .o. Then the object file will be made as an executable after process of linking with the library files. The executable file can be run to get the above statement mentioned in C code printed.

All these in a sequence and here are the commands presented for the same.

```
$ gcc -c prog1.c
```

In the above command, gcc is the compiler being used, expanded as GNU CCCompiler which will compile the code and get the object files. Object file will be generated with the same name as file name, it is prog1.o."o" is to just say it an object file.

After the process is over, one should get an executable file for the above generated object. It can be carried out with the following command.

```
$ gcc -o execfile prog1.o
```

Above command will convert the object file to an executable file after linking the file with necessary library files. To complete the execution step has to be followed.

```
$ ./execfile
```
