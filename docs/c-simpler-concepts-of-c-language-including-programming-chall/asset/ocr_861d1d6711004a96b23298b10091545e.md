# ## 8.1. STRUCTURE DEFINITION

There are situations when the applications need to read variables such as emp_Name, emp_Number, emp_Designation, emp_Salary, etc., for some kind of processing such as payroll processing.

As it can be seen in the previous example, the variables are of different types and every time we read these variables for each employee in the organisation! One way of accomplishing the task would be using an array for every variable and correlating them as follows:

```
//char array for emp_Name, emp_Designation.
char emp_Name [30], emp_Designation [15];
//long int array for emp_Number.
// Salary would involve double values for HRA, DA, etc.
Hence, //declare it as a double variable.
```

For Employee#1,

Every time we need to process his/her records, his/her details are obtained as emp_Name [1], emp_Designation [1], emp_Number [1], and emp_Salary [1].

Had there been a container which can hold these variables, it will be made simpler to deal with the processing of that container's variable.
