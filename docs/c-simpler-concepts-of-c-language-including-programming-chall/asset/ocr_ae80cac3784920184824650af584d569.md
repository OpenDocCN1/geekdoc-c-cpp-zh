# 1.7.2. Scope of a C variable

To solve a complex problem, the programmer normally breaks the problem into smaller pieces and deals with each piece of the problem by writing multiple functions. Then, all the functions are put together to form a complete program that can serve the purpose.

In the complete program, there might be variables that have to be shared by all the functions. On the other hand, the use of some other variables may be limited to only certain functions. That is, the visibility of those variables is limited, and values assigned to those variables are hidden from many functions.

Limiting the scope of variables is very useful when several programmers are working on different pieces of the same program. If they limit the scope of their variables to their pieces of code, they do not have to worry about conflict with variables of the same name used by others in other parts of the program.

Scope of the variable is the measure of life time of a variable.

There are two types of scoping for variables to be introduced now.

+   1. Local Scoping
2. Global Scoping

Reader is introduced with a small program on local scoping.

# Local Variables

Variable whose scope is limited within the block or function where it is defined called as Local variables. Local variables must always be defined at the top of a block. There are few things to remember when one goes on with using a local variable. When a variable is defined, it has to be initialized as well by user.

The variable will be alive only within the block. Once the execution is out of the block, the variable dies.
