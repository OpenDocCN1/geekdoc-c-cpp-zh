```
#include <stdio.h>
#define PI 3.14
#define area(r) PI*r*r
void main() 
{
    int radius;
    printf("Enter the radius..");
    scanf("%d", &radius);
    printf("%f Sq cm",area(radius));
    getch();

}
```

> Nesting macro within another macro

# Program 14.1 Macro Substitution

When Program 14.1 is executed, following steps occur.

+   1. PI's replaced by 'r', area(r) is evaluated as 3.14*r where 'r' is the radius obtained from the caller, from printf().
PI is present in macro definition. So, it becomes, 3.14*r.
2. After obtaining the value of 'r', area(r) is evaluated as 3.14*r where 'r' is the radius obtained from the caller, from printf().
3. Finally result is obtained as follows.

Following code shows the different flavour of Macros.

```
#include <stdio.h>
#define MAX(a,b) ((a>b)?printf("%d is bigger % %%d and %%%f",a,a,b):printf("%d is bigger % %%d and %%%f",b,a,b))
void main() 
{
    MAX(25,24.5);
    getch();
}
```

In the above piece of code, there is a macro named 'MAX' which is meant for the bigger among the two numbers. This macro uses conditional operator for performing the operation. The output will be as shown here.
