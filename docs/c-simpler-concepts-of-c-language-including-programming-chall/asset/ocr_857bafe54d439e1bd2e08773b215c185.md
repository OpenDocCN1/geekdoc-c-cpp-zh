# 10.3.4. Random access to files

These functions will let the users perform random access to the files.

**Note:** When the file is opened, the pointer will be pointing to the first byte in the file.

The following functions are available for moving around file contents.

# 10.3.4.1. fseek(file pointer, long_many_bytes_to_move, int_from_which_position)

This function helps to move the desired byte forward or backward from the desired position. There are some integers available to mention the third argument, from_which_position. They are given in table 10.2.

| Constant | Meaning |
| SEEK_CUR | Denotes current position |
| SEEK_SET | Denotes the beginning |
| SEEK_END | Denotes the EOF. |

Table 10.2 File constants

In order to move n bytes forward, fseek(fp, .nl , SEEK_SET) can be used. (Note that 'L' in second parameter denotes the long value). To move n bytes backward, fseek(fp, -NL, SEEK_CUR). (The minus (-) sign before 'n'). this function will return a non zero value in case of any error.

# 10.3.4.2. ftell(file pointer)

This function tells the user, the current location of the file pointer. Returns -1 on error.

# 10.3.4.3. rewind(file pointer)

After moving forward or backward, the file pointer can be made to point to the original position where it was previously pointing to. This function helps doing so.
