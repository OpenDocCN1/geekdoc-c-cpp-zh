# 14.2.3 Conditional compilation

So far, the reader would have been provided with the basics about pre-processor directives. This section will go deeper into it by introducing conditional compilation constructs. If the reader has enough experience working with conditional constructs such as ‘if’, ‘else if’ ‘else’, then this section can be easily crossed.

Some of the pre-processor conditional constructs are,

- #if <identifier>
- #elif <identifier>
- #else
- #endif
- #ifdef <identifier>
- #ifndef <identifier>
- #defined <identifier>
- #!defined <identifier>

Each of the above construct is discussed next.

```c
#define PI 3.14
#define i1 10
#define j1 20
#ifdef inc
#define dec(x) --x
#elif !defined inc
#define inc(x) ++x
#define dec(x) --x
#else
#endif
#ifdef PI
//undef PI
#endif
#if((j1-i1)>0)
#define positive 1
#else
#define negative -1
#endif
int i=10,j=11;
main() {
    printf("inc(10)=%d\n", inc(i));
    printf("dec(10)=%d\n", dec(j));
    printf("PI*10=%f\n", PI*10);
    getch();
}
```

# 14.2.4.3. pragma directive

This directive, is used by the programmer to give various instructions to the compiler. There are so many options that can be used with pragma directive. Following options are some of them.

- 1. #pragma optimize(on | off) forces the compiler to perform some optimizations based on optimization list.
- 2. #pragma warning(disable:warning) Using this, warnings are suppressed. For example, consider the following code, where pragma is used to suppress warnings with initializations.
- 3. #pragma warning(default) for enabling global optimizations.
- 4. #pragma optimize("", on) for generating short sequences of machine code.
- 5. #pragma warning(default:stack) for frame pointers.

Note that these directives are platform dependant. And so, results will be varying from platform to platform.

```c
#pragma warning(disable:default)
void Test() {
    int x;
    int y = x;
}
#pragma warning(default)
int main() {
    int x;
    int y = x;
}
```
