# Procedure for the execution of program:

+   1. Save the file as prog1.c
2. Compile it with gcc -o prog1 prog1c where prog1 is the executable name.
3. Run it in the background with ./prog1 & 
4. & represents that the program is in back ground.

Now to check if the files are created and the File Descriptor table is updated with the new entries, following steps are to be

+   1. Once run in the background with ./prog1 & there will be a process thrown immediately. A snapshot is presented with the details.
2. In this case 5720 is the process id.
3. Now navigate to /proc with cd /proc where /proc is the file system which has details of all the processes and it will be updated on the fly. All the processes will be updated in the proc file system.
4. Navigate to the /proc file system and search for presence of 5720 (This number will be different for the reader, when tried).
5. Then do a 5720. Do listing, a directory called fd will be present and navigating through it will get the complete details of fd table.
6. Do a listing with ls. Command will show series of number as 0 1 2 3 4. To get a detailed listing, do ls -l where the new files will be seen and will be allotted fd number as 3 and 4. Following snap shot (Fig 13.5) will stand as a reference for above conveyed explanations.
