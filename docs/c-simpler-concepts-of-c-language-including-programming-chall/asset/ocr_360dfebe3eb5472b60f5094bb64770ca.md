# 11.5. DOUBLY LINKED LISTS

One step ahead in linked list is doubly linked lists. The properties of doubly linked lists are similar to that of singly linked lists, in the fact that unlike linked lists which have only next pointer, doubly linked lists have two pointers, next and previous, or left right pointers.

Pictorial representation is as follows.

| Left Data Right | Left Data Right | Left Data Right |

![](bbox=[0.108, 0.783, 0.892, 0.843])

Figure Doubly linked list

As each node has pointers to its left and right nodes, doubly linked lists become flexible in accessing the nodes in the backward direction also! The implementation part is given in Program 11.5. Care should be taken during insertion and deletion to set the left and right pointers, failing which, the connectivity might be weird to handle.
