```
# include <stdio.h>

# include <unistd.h>
```

```
int main ()
{
int fd1, fd2;
fd1 = open("txt1.txt",O_RDONLY|O_CREAT, 777);
close (2);
// closing error fd.
// so generated fd should be kept in slot 2
ndup(fd1);
    while (1) {
    }
}
```

In this program, a file name 'txt1' has been created and assigned to a file descriptor named 'fd1'. In the next line, the file descriptor for standard error is closed; then 'fd1' is duplicated to the job of the sub routine 'stderr'. The execution has been done and snapshot is presented here for the reference. In the snapshot it is evident that file descriptor 2 has been assigned to the file txt1 instead of descriptor. So duplication has been done properly and task has been accomplished correctly.
