# 2.1. DISCUSSION OF CONDITIONAL CONSTRUCTS

There arises a need for a programmer to check for various conditions while writing a program. Conditional constructs help him achieve this. For example, there may arise a situation where the programmer needs to check whether the given input is in the range of 1 to 200. The following are the conditional constructs used for evaluating such types of conditions:

+   1. if.
2. if – else.
3. Nested if.
4. Switch case.

Each of this construct may use the relational operators given in Table 2.1.

| Operator | Meaning |
| = | Equal to |
| != | Not equal to |
| < | Less than |
| > | Greater than |
| <= | Less than or equal to |
| >= | Greater than or equal to |

Table 2.1 Operators

The return type of the relational operators is Boolean. (i.e.) either TRUE or FALSE (1/0).
For example,

If the mark obtained by the student is less than 35, he is not permitted to sit for the next level test.

In this statement, we identify the following tokens (Token is either an identifier or a symbol or an operator):

+   Variable – mark.
Operator used: < [less than operator].
