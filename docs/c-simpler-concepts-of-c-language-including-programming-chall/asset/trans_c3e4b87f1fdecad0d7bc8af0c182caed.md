# 10.3.4 文件的随机访问

### 表格 10.2

| 常量 | 含义 |
| :--- | :--- |
| SEEK_CUR | 当前位置 |
| SEEK_SET | 起始 |
| SEEK_END | 结束 (EOF) |

### 表格 10.2 文件常量

为了向前移动n字节，可以使用 fseek(fp, SEEK_SET)（注意第二个参数中的'L'表示长值）。向后移动n字节，使用fseek(fp, -SEEK_CUR)（n如果发生任何错误，该函数将返回非零值）。

### 10.3.4.2. ftell(文件指针)

此函数告诉用户文件指针当前的位置。出错时返回 -1。

### 10.3.4.3. rewind(文件指针)

在向前或向后移动后，可以将文件指针指向它之前指向的位置。此函数可以做到。
