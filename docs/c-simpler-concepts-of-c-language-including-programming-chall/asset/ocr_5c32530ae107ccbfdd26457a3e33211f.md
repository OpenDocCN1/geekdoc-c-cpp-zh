# 5.1.4. Function definition

Defining the function defining the logic! For instance, the sum() will be defined with the following statements.
void sum(int a,int b)

```
{
  int c;
  c=a-b;
  printf("The sum value is: %d",c);
}
```

> **Note: Actual Vs Formal Parameters:** Variables being passed in function calls are called actual parameters, those declared in function definition are called dummy variables/formal parameters. In the above code segment, int a,b are formal.

# Returning values from functions

If the function is called to return 'some value', while defining that function, there should be a return statement inside the function definition. If the function is a void one, return statement is not needed.

Syntax:
return <variable/value>

> **Important Note:** The number of formal parameters should be equal to the number of actual parameters. Actural and formal parameters can have the same variable name, since the latter one has only local scope. Order of parameters in function definition should be the same as in function call.
