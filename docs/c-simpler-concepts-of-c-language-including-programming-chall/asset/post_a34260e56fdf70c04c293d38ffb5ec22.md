### 5.1.1. Types of functions

- 1. Built-in
- 2. User defined

Built-in functions are already written and compiled for the programmers to use directly without having to write on their own.

Examples,
sin(x) → a built-in function to find the sine value of x.
sqrt(x) → to find the square root of x.
abs(x) → to find the absolute value of x.

User functions are those we are going to deal with in this chapter.

**Note:** Functions are interchangeably called as "methods/modules". The process of splitting the length and complex programs into smaller units/functions is called 'modularization'. Programming with such an approach is known as modular programming.

## Benefits of using functions

- Improves modularity and thereby the reusability
The advantageous characteristic of functions is that, if a set of instructions are to be reused, enclosing them as a function, whenever the need arises, the programmer need not write those set of instructions again and again. Instead, a simple call to them would do! This promotes reusability and reduces the developer's time as well as storage space.

## FUNCTIONS Debugging becomes easier

- Having the logic of the program as a single main() function would be complicated sometimes. It will be difficult to spot the errors and correct them. Instead, if the program is modularized, it will be pretty simpler for the programmer to easily spot the errors and correct them.
- Building Library functions

### 5.1.2. The declaration

Similar to the variable declaration, one needs to declare the functions in 'C' before using it. Unless the compiler will flash an error. The declaration may go either inside the main() or outside the main.

Syntax:
`<return function_name (types of parameters)>`

- A function needs to return a value of any type.
If it is meant to return an integer value, for instance, sum of 'n' numbers, the return type would be int. It can return a char, a float, a char pointer. If it has nothing to return, then the function will be declared 'void'.
- Function_name is the name given by the user according to the logic of the function. For instance, sum, avg, sort, etc.

Note: The rules for naming the variables are applicable to functions also.
- Parameters are the arguments being passed.

It may take any number of variables of any type including a structure variable, array variable, etc.

```c
Examples of function declarations
void sum(int,int);
int sum(int,int);
float avg(int []); -> passing an array variable.
char gender(struct student); -> passing a structure variable.
void swap(int,int);
sum(int,int)-> If no return value is mentioned, default data type- 'int' is used.
```

Note: Function declaration statement is also known as function prototype!

## Returning values from functions

If the function is called to return 'some value', while defining that function, there should be a return statement inside the function definition. If the function is void one, return statement is not needed.

Syntax:
`return <value>`

> **Important Note:** The number of formal parameters should be equal to the number of actual. Order of parameters in function definition should be the same as in function call.

### Type I Functions that take no argument, and return nothing:

In the following program 5.2, the following neither takes any argument nor return any value,

- void print_ArrayValues() – Return type 'void'. Parenthesis is empty.

### Type II Functions that take arguments but return nothing:

In the following program 5.2, the following do not return any value, but takes arguments,

- void get_ArrayValues(int) – Return type is 'void' but takes an input argument.
- void swap(int, int[]) – Return Type is 'void' but takes two integers as arguments.

Program 5.2 is an example that incorporates Type I & Type II functions.

```c
#include<stdio.h>
#include<conio.h>
void get_Arrayvalues(int);
void print_Arrayvalues();
void swap (int []);

int num, a[15], b[15], i;

void main()
{
    printf("Enter the number of elements:");
    scanf("%d", &num);
    printf("Enter the array1's elements one by one");
    for(i=0; i<num; i++) {
        scanf("%d", &a[i]);
    }
    printf("Enter the array2's elements one by one");
    for(i=0; i<num; i++) {
        scanf("%d", &b[i]);
    }
    swap(a, b);
    print_Arrayvalues();
}

void get_Arrayvalues(int n)
{
    for(i=0; i<n; i++) {
        printf("%d->", b[i]);
    }
    printf("\n");
}

void print_Arrayvalues()
{
    printf("Array1's elements are...");
    for(i=0; i<num; i++) {
        printf("%d->", a[i]);
    }
    printf("\nArray2's elements are...");
    for(i=0; i<num; i++) {
        printf("%d->", b[i]);
    }
    printf("\n");
}

void swap(int a[], int b[])
{
    int temp;
    printf("\n\n..............Swapping the array contents..............\n\n");
    for (i=0; i<num; i++) {
        temp=b[i];
        b[i]=a[i];
        a[i]=temp;
    }
    printf("After swapping, the contents of the arrays become..\n\n");
    print_Arrayvalues();
}
```
