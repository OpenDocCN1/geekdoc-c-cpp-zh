## 3.3. INITIALIZING AN ARRAY

Like any other variable in 'C', an array can also be initialized with the help of assignment operator '=').

- Initialization can be done during declaration or at a later point of time in the program.

For example, with respect to 1-D arrays,
1. While declaration,
int a[]={10,50,58,41,210,100}; // Note that size of the array is not mentioned.
2. At a later point in program (using a loop)
for(i=0;i<size;i++)
a[i]=0; // initializing all the values with '0'.
Or
Explicitly assigning values,
a[0]=10;
a[1]=20;
a[2]=30; and so on.

With respect to 2-D arrays,
int matrix[3][3]={1,2,3,4,5,6,7,8,9};
Or
int matrix[3][3]={{1,2,3},{4,5,6},{7,8,9]};

The above declarations assign 1 to matrix[0][0], 2 to matrix[0][1], and in a similar manner, 9 to matrix[2][2]; this assignment can be visualized as follows in Figure 3.2.

- Initialization falls in two categories, static and dynamic. If the array values are assigned during declaration itself or sometimes later when the scope of changing the array elements is zero, one can assign the array with values. It is known as static assignment. Refer previous point.
- Obtaining the array elements during the run time from the user comes in the second category, dynamic initialization.

The examples used in this chapter use dynamic initialization of arrays.
