
# STRINGS

Syntax: `strncpy(dest, source, number);`

| Parameter | Description |
| :--- | :--- |
| destination | Pointer to the destination array where the content is to be copied. |
| source | C string to be copied. |
| number | Maximum number of characters to be copied from source. |

Program 9.8 has used `strncpy()`, also see the null terminator is used.

```c
#include <stdio.h>
#include <string.h>

int main () {
    char string1[13];
    char string2[13];
    strcpy(string1, "C PROGRAMMING");
    strncpy(string2, string1, 6);
    string2[7] = '\0';
    printf("\n Source String %s \n",string1);
    printf("\n Destination String %s \n",string2);

    return 0;
}
```

Source String C PROGRAMMING
Destination String C PROG

## (d) strcat ()
This function helps the programmer with appending a copy of the source string to the destination string. The terminating null character in destination is overwritten by the first character of source string, and a new null-character is added at the end of the new string formed by the concatenation. Program 9.9 stands as a reference for `strcat()`.

```c
#include <stdio.h>
#include <string.h>

int main () {
    char string1[20];
    strcpy(string1, "C PROGRAMMING");
    printf("\n Before strcpy %s",string1);
    strcat(string1, " IS EASY TO LEARN.");
    printf("\n After strcat %s",string1);
    getchar();
    return 0;
}
```

Execution Result:
Before strcat C PROGRAMMING
After strcat C PROGRAMMING IS EASY TO LEARN.

## (f) strcmp ()

It is used to compare two strings. It will start comparing the first character of both the strings. If they are equal to each other, it continues with next successive characters until the characters differ or a terminating null-character is reached. Return value will be zero when similar strings are compared. When two strings are compared result can be positive or negative. Programs 9.11 and 9.12 covers all the possible results with use of `strcmp()`.

```c
#include <stdio.h>
#include <string.h>

int main () {
    char str1[20]="C PROGRAMMING";
    char str2[20]="C PROGRAMMING";
    int diff;
    diff=strcmp(str2,str1);
    printf("\n Return value %d",diff);
    getchar();
    return 0;
}
```

Execution Result:
Return value 0.

## 9.2. STRINGS AND POINTERS

Strings with pointers are an important area to be touched. It is interesting as well for someone to learn it.

Considering a small declaration as follows which has a character pointer and it is pointing to the start of the string.

Consider the following code snippet:

```c
char *str_pointer = "I LOVE MY COUNTRY.";
```

This defines a character pointer called str_pointer which points to the start of the text 'I LOVE MY COUNTRY.'. So to print the string pointer can be used as follows.

```c
printf("%s", str_pointer);
```

Reader is already aware of what a string is. It is nothing but series of characters stored in an array. The character pointer declared will point to the first character of the string. The following program 9.13 will just have a pointer and it will be pointing to the string’s first character.

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char *str_pointer = "I LOVE MY COUNTRY.";
    printf("%s", str_pointer);
    return 0;
}
```

Execution Result:
I LOVE MY COUNTRY.
