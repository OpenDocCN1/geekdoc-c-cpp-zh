```
struct student 
{
    char *s_name;
    long int s_regno;
    int year_of_study;
    char * branch;
};
void main() 
{
    var.s_name="Student";
    var.s_regno=1026319;
    var.year_of_study=3;
    var.branch="ECE";
    printf("Name: %s\n",var.s_name);
    printf("RegNo: %ld\n",var.s_regno);
    printf("nYear: %d\n",var.year_of_study);
    printf("nBranch: %s\n",var.branch);
    getch();
}
```

# Program 8.6 Structure Initialization – part I

The members variables of struct student, s_name, s_regno, year_of_study, and branch were initialized in the above code as follows,
var.s_name="Student"
var.s_regno=1026319;
var.year_of_study=3;
var.branch="ECE"
It is quite simple right?
Other way of doing it at the declaration time of structure itself. The code Program 8.7.

```
#include<stdio.h>
struct student 
{
    char s_name[30];
    long int s_regno;
    int year_of_study;
    char branch[10];
};
struct var={{"Student",1026319,"ECE"};
void main() 
{
    printf("Name: %s\n",var.s_name);
    printf("nRegNo: %ld\n",var.s_regno);
    printf("nYear: %d\n",var.year_of_study);
    printf("nBranch: %s\n",var.branch);
    getch();
}
```
