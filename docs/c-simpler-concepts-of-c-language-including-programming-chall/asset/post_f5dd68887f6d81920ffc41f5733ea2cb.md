## Increment Operator (++)

This operator is useful in many places as it allows the programmer's job and saves time (literally reducing the time to type!). The ultimate aim of this operator is to increment the value of operand by 1. There are two kinds of increment operators based on the operations performed.

- 1. Pre increment - First value of the operand is incremented; assigned to the left hand side of the expression.
- 2. Post increment - First current value of the operand is assigned to the left hand side of the expression, and the operand is incremented by one!

## Example

int a=10,b;
a++; $\rightarrow$ assigns 10 to b first; then increases the value of a by 1.
printf("%d",b); $\rightarrow$ 10 is printed!
b+=a; $\rightarrow$ increases the value of a by 1; then assigns the incremented value is assigned to b;
printf("%d",b); $\rightarrow$ 12 is printed. (Since, after b=a, a's value would have become 11; then after b+=a, it becomes 12.)
Now, the reader would got a clear picture about increment operators. Next, decrement operators are discussed.

## Decrement Operator (-)

This operator performs in the way just opposite to the increment operator. It decreases the value of the operand by 1. Similar to increment operator, it has two versions,

- 1. Pre decrement - First value of the operand is decremented by one; then assigned to the left hand side of the expression.
- 2. Post decrement - First current value of the operand is assigned to the left hand side of the expression, and the operand is decremented by one!

## Examples

int a=10,b;
a--; $\rightarrow$ assigns 10 to b first; then decreases the value of a by 1.
printf("%d",b); $\rightarrow$ 9 is printed!
b-=a; $\rightarrow$ decreases the value of a by 1; then assigns the decremented value is assigned to b;
printf("%d",b); $\rightarrow$ 8 is printed.

```c
#include<stdio.h>

    printf("Post Decrement operator : a--=%d\n",a--);

    getch();
}
```

## 4.2.7. Conditional operator

Consider the following code snippet.

```c
int x,y,bigger;
x=10;
y=20;
if(x>y)
bigger=x;
else
bigger=y;
```

As it is clear from the above statements, 'bigger' stores the bigger value among variables x and y. the above statements can be reduced to a single statement with the help of conditional operator as follows.

bigger=(x>y)?x:y;
"?" is said to be the conditional operator. Expression before '?' is executed. Based on the result, either expression/value before ':' (colon) or after ':' is executed. In the previous case, value of y will be assigned to bigger. The parts of conditional operator are as follows.

## 4.2.8. Comma operator

Used in declaring, initializing variables, inside for loops, and in 'scanf' and 'printf' while dealing with many variables.

```c
#include<stdio.h>
main() {
    int i,j;
    for (i=0,j=10;i<=10;i++,j--)
    {
        printf("\ni=%d\tj=%d\n",i,j);
    }
    getch();
}
```

## 4.3 PRECEDENCE OF OPERATORS

## POINTS TO REMEMBER

* Operators are those which act upon operands.
* There are 3 kinds of operators. Unary, Binary and ternary.
* An expression acts upon various kinds of operators.
* +, *, % are five arithmetic operators.
* Operators acting on bits are called bitwise operators.
* Operators based on truth values are called Logical operators.
* When operands of different types, casting is performed.
* Precedence of operator and associativity rules are used while evaluating the expressions.
* Unary operators have only one operand. They have the highest precedence.
* Increment and decrement operators can be used as post/pre operations.
* Conditional operator can replace if-else statements.
* Comma operator has the least precedence.
* Modulo operation cannot be performed on real operands.
