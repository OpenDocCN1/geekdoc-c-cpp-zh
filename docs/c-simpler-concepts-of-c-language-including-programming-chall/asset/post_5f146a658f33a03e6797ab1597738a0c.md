Points to be noted with switch cases:

- 1. The case label should be a variable of int or char type. (In the previous example, mark was the case label, which was of int type!)
- 2. Case values can be an integer or a character value or an integer expression!

Example,
```c
switch (mark)
{ 
    case 100-80+60: //absolutely valid;
        //statements to be executed
        break;
    case 'Y'://valid.
        //statements to be executed
        break;
}
```

- 3. It is a must to have a 'break' statement at the end of every case. If not, the cases following the present case will get executed automatically till a break is encountered.
- 4. default can be placed at the beginning or at the end, it is not mandatory to have a default statement also.

# 2.2. LOOPING CONSTRUCTS

Looping constructs are very much advantageous when the user needs to repeat certain statements many times.

For example, if the user needs to print his/her name 100 times, it is evident to write 100 print' continuously, which absolutely consumes much of the user's time. Loops' benefits are admirable in this kind of situation.

Instead of keeping on writing the same print 100 times, looping constructs can be made use of, since they:

- 1. Consume less time.
- 2. Reduce the length of the program.
- 3. Readability is improved.

The following sections will explain the usage of looping constructs.

# 2.2.1. The for loop.

Syntax:
for (initialization part; condition part; increment/decrement part)

---statements to be executed---
}

For example,
for(i=0;i<5;i++) -> This loop initializes i to 0, checks the condition to see if i is lesser than 5, i++ is the increment operator, which is similar to i=i+1; (More details about this operator in chapter 4.

Program 2.5 explains printing a statement 100 times,

```c
#include<stdio.h>
#include<conio.h>
void main() {
    int i;
    for(i=0;i<100;i++)
    printf("Hello, Welcome to C programming");
    getch();
}
```

# 2.2.2. The while loop

Syntax:
Initialization;
while(condition)
{
---statements to be executed---
Increment/decrement statement;
}

When is while loop preferred?
A while loop is preferred than for loop, when the programmer is not aware of the number of iterations. The following program 2.8 shows this.

```c
#include<stdio.h>
#include<conio.h>
void main()
{
    int number, value;
    number=100;
    while(number>0)
    {
        printf("Please enter the number to be subtracted:");
        scanf("%d",&value);
        printf("Remaining:%d\n",number);
        number=number-value;
    }
    getch();
}
```

# 2.2.1. The do-while loop

Syntax:
do
{
---statements to be executed---
} while(condition);

What is the difference between while and do-while loop?
The only difference is, do-while executes the body at least once. The following program 2.9 shows this.

```c
#include<stdio.h>
#include<conio.h>
main()
{
    int i;
    i=100;
    do{
        printf("enter the value of i:");
        scanf("%d",&i);
        printf("i=%d\n", i);
        i=i-10;
    }while(i>0);
    getch();
}
```

# 2.2.3. The break and continue statements.

If the reader could remember, break has already been used before. Yes, in 2.4, break statement was used to terminate the switch case.

This statement is self-descriptive. It is used to break something. If used in a loop, it breaks the loop and comes out of it. If used in a switch case, it breaks the switching process.

| Break | Continue |
|---|---|
| To terminate the process in it is used. | To skip the current step (Iteration) and proceed with the next step (Iteration). |

Following Program 2.11 explains this concept.

```c
//break_continue.c
#include <stdio.h>
#include <conio.h>
main() {
    float i;
    do {
        printf("enter the value of GPA value:\n");
        scanf("%f", &i);
        if (i<0)
            printf("Terminating...\n");
            break;
        else if (i>10) // GPA never crosses 10!
            printf("Sorry, GPA never crosses 10!!\n");
            continue;
        else
            printf("Your GPA is %f\n", i);
    } while (1);
    getch();
}
```
