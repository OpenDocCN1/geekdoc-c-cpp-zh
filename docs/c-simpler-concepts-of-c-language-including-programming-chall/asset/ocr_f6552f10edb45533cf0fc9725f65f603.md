As the figure shows, Stack has a pointer TOS (Top of Stack) which indicates the top most element (which was recently added). At the start, TOS will be pointing to the index ‘-1’. Every push increases the pointer by one. Once it reaches an upper bound MAX, no element can be added. Every pop reduces the pointer value by one. There is an index much like an array's, which helps to access the elements of array.

# Pushing, Popping

There are two major operations performed using stacks. 1. Push 2. Pop. The process of inserting an element into the stack is called Push operation. The reverse operation, taking an element out the stack is known as popping.

Stack used to follow Last In First Principle (LIFO) principle. This principle pops the element at TOS. (i.e.) Most recently added item is popped.
