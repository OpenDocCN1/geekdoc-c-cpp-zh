# POINTS TO REMEMBER

+   * Arrays, stacks, queues, linked lists are the popular data structures.
* Stack operates in LIFO fashion; Queue in FIFO fashion.
* Pop, push are the operations performed on stacks.
* Linked lists dynamically allocate space for each element as needed.
* Data structures can be used to sort items.
* Linked lists can be used to implement other data structures such as stacks and queues.

# PROBLEMS ON LINKED LISTS

+   1. Count the number of nodes present in a linked list.
2. Write a C program using linked lists to swap the alternate elements of linked list. (For example, if the contents of the linked list are: 14, 25, 58, 69, 55, the program should give the output as 25, 14, 69, 58, and 55).
3. Write a code snippet to check whether the given doubly linked list is a circularly linked list or not.
4. Write a C program using linked lists to insert an element in the nth position. (For example, if the contents of the linked list are: 14, 25, 58, 69, 55 and the user wants to insert at '100' at the 3rd position, the new list would be 14, 25, 58, 69, and 55).
5. Write a C program to merge two separate linked lists together.
6. Write a C program to remove the duplicate elements in linked lists.
7. Given the head singly linked list find the nth node from the back using a C program.
8. Given the pointer to a singly linked list with a loop or cycle in it using a C program.
9. Given a singly linked list, find the node in the middle using a C program.
