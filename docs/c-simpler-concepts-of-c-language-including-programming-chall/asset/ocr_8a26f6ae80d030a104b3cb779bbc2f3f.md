# 13.34. Read system call

The system call is followed by a read system call. A sample code would be useful and here to understand read, Here one will need 2 buffers (2 char arrays) for writing and for reading. The previous program is repeated for the first half of this code and the second part is slightly different. After writing into a char array named buf, reading can be performed with the file descriptor. Read system call needs fd as reference and to read into the next char array called as declared in the code. It can be printed with printf which should get the content read on the screen. Execution snapshot is presented in Fig 13.8.

```
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main ()
{
  char buf[5]=\hello";n  char buffer[5];
  int fd1, ret, ret1;
  fd1 = create("txt1.txt", 0777);
  ret = write(fd1, buf, sizeof(buf));
  ret1 = read(fd1, buffer, sizeof(buffer));
  fflush(stdin);
  printf("\n %s", buffer);
}
```
