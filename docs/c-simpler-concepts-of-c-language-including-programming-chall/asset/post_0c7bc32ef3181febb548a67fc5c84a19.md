The auto specifier indicates that the memory location of a variable is temporary. To be precise, a variable's reserved space in the memory can be erased or relocated when the variable is out of its scope. Only variables with block scope can be declared with the auto specifier. To put in better words, the scope of the auto variables is within a block of code or a function.

To prove the above concept a simple and elegant piece of code has been presented below program 6.2. Here in this program function add() will be called 10 times and it is expected to increment the sum accordingly.

But since scope of an auto variable is within the block of the code, it will die when the compiler goes out of the function. When the function add() for the second, or third or tenth, it will be initialized again with ten and increment once. So the result, return value will remain 11.

```c
#include <stdio.h>
main() {
    int i, ret;
    for (i=1; i<=10; i++)
    {
        ret = add();
    }
}
int add() {
    auto int sum = 0;
    sum++;
    printf("\nSum is %d", sum);
}
```

## 6.1.2. static

static is the default storage class for global variables. Static variables can be declared even within a block of code. The major difference between static and auto variable is, values of the static variables are retained and will not be re-initialized.

0 is stored by default for static variables. To check this program 6.3 has been written and the same is presented with execution result.

# STORAGE QUALIFIERS

```c
#include <stdio.h>
static int upper;
/*Defined as static, so initialized to 0*/
int lower;
/* Global, so by default static */
main()
{
    printf("Stored with value (defined as static) %d\n", upper);
    printf("Stored with value (global)%d\n", lower);
}
```

# Execution Result

Stored with value (defined as static) 0
Stored with value (global) 0

## 6.1.3. register

register storage qualifier is used to define local variables that should be stored in a CPU register instead of RAM.

```c
{
register int upper;
}
```

should only be used for variables that require faster access. However, the register specify only can give a suggestion to the compiler. A variable specified by the register keyword is not guaranteed to be stored in a register. The compiler can ignore the suggestion if there is no register available, or if some other restrictions have to apply.

## 6.1.4. extern

extern qualifier defines a global variable that is visible to all object modules (all .o files). When ‘extern’ keyword is used, the variable cannot be initialized (No declaration initialization is permitted; it can be initialized after declaration!) during declaration.

To prove this conceptually, couple of code snippets required Program 6.5 has both the snippets covered.

- Two files 1.c and 2.c are created.
- 1.c has a global variable ‘count’ is called from 2.c, where ‘extern int count’ is used. It says that the variable count has been declared in some external file, in this case it is ‘1.c’.
- When the function write () is called, it will fetch the value for count from file 1.c is 5.

To execute and check, following steps need to be executed! (gcc is the best weapon to handle the situation which involves extern keyword.)
Note: If the user has installed Dev-Cpp, the gcc class is defined by default and hence, he/she can execute the following commands from Windows – Command prompt itself. (To do so, go to Start->Run->cmd. Then using ‘gcc’, go to the path where the gcc has been installed. Finally, execute the following commands.) If the user doesn’t have Dev-Cpp software, they can execute the commands in Linux OS.

- Compile 1.c, 1.o will be generated. (gcc -c 1.c)
- Compile 2.c, 2.o will be generated. (gcc -c 2.c)
- Link 1.o and 2.o, generate executable file. (gcc -o output 1.o 2.o), where output is executable file name.
- Run the executable file with ./output. (In Dev-Cpp-Windows pair, just typing ‘output’ will fetch the answer!)

The execution on completion, will the output printed as “the count is 10”. This is how extern can be used.

```c
/* 1.c */
#include <stdio.h>
int count = 10;
void write();
main () {
    write();
}
```

```c
/* 2.c */
extern int count;
void write () {
    printf("\n the count is %d",count);
}
```

Execution Result
$ ./output
the count is 10

# CHAPTER 7 Pointers

## 7.1. INTRODUCTION

This chapter deals with a special kind of variable called pointer, which holds values which are not values, but so called addresses.

### Why to use pointers?

It is the misunderstanding that prevails among many that pointers are difficult to understand. It is not. pointers are very helpful and easy to use if learnt properly. It has got the benefits. The reader can substantiate them at the end of this chapter.

- Pointers let many parts of the program to share variables and other objects. Without them, the programmer has to do so many copying works.
- Pointers are used to create various data structures like linked lists, trees, etc. Data structures are discussed in Chapter 11.

### The definition

A pointer is a variable, which holds the address of the other variable of same type. A pointer variable is declared like any other variable, but with an asterisk (*) in front.

For example,

#### Declaration of pointers

- int *;
- char *c;
- float *f;
