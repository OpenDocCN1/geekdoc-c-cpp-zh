# Table 1.5 Data types

+   The data types are all dealt in detail int: This is a keyword used to refer integer number. An integer is some sequence of numbers that has no decimal points in between. Based on word length of the computers the range of int can be defined. If an 8 bit computer is used the range can be calculated with the following formula:

```
$$-2^{8-1}$ to $2^{8-1} - 1$
```

This will give the range as -128 to +127. Same is the case with 16 bit computer. There when used with the same scenario as one will get,

```
$$-2^{16-1}$ to $2^{16-1} - 1$
```

This will now set the range as -32,768 to +32,767. Similarly one can calculate the range for a 32 or 64 bit computer.
