# 4.2. Relational operators

These operators check the relationship between its operands. There are 6 operators under this category. They are

+   1. < (less than)
2. <= (less than nor equal to)
3. > (greater than)
4. >= (greater than or equal to)
5. == (equal to)
6. != (Not equal to)

Similar to logical operators, if the condition being checked is TRUE, the condition returns 1, else it returns a 0. For example, Let a=10,b=33:

+   * (a>b)? returns 1
* (a<b)? returns 0
* (a==b)? returns 0
* (a<=b)? returns 1
* (a>=b) returns 0
* (a!=b) returns 1
