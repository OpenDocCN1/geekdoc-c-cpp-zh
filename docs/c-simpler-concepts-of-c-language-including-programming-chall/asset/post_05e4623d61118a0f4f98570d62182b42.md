
# FILE HANDLING IN C

Both the functions return a non-zero value in case of failure. Following program illustrates their use.

In Program 10.4, the following things are done.

- 1. A file named fred.txt is renamed to new_file.txt using rename function.
- 2. After renaming, the contents of the new_file.txt are printed for testing purpose.
- 3. Then the same file is removed using remove() function.

Any operation trying to access the removed file will end up in failure!

```c
#include <stdio.h>
void main() {
    FILE *f;
    char c;
    int status;

    printf("File's name is: fred.txt\n");
    printf("File is going to be renamed as, new_file.txt..\n");
    status=rename("fred.txt", "new_file.txt");
    if(status!=0)
        printf("file renaming couldn't be succeeded now..\n");
    else {
        printf("Rename is successful..\n");
        printf("Old name:fred.txt\nname:new_file.txt\n");
    }

    printf("the new file contents are..\n");
    f=fopen("new_file.txt", "r");
    while ((c=getc(f))!=EOF) {
        printf("%c",c);
    }
    fclose(f);
    printf("\n the file \"new_file.txt\" is no longer needed..Let's delete it.\n");
    status=remove("new_file.txt");
    if(status!=0)
        printf("File is not removed..\n");
    else
        printf("File is successfully removed..\n");
    getch();
}
```

# POINTS TO REMEMBER

- fopen() will return a pointer to the FILE object.
- Files with extensions .doc, .docx, .txt, .dat can be created.
- Read, write, append are the mostly performed operations on files.
- If the opening pointer fails, NULL will be returned.
- EOF denotes the end of the whole integer equivalent is -1.
- fclose() should be used after every file operation for file handling.
- putw() writes the ASCII equivalent of the character being written.
- fseek() moves the file pointer forward or backward based on the offset value mentioned.
- ftell() tells the current position of the file pointer.
- rewind() moves back the file pointer to the previous position before fseek() executed.
- remove() cannot be applied on files that are opened.

# Stack

A data structure which is capable of storing data up to certain MAX Size after which overflows, not allowing to insert further. It can be visualized as shown in Figure 11.2.

![](img/5bbdccabcf90cef7ee48b18eaa17d_180_0.png)

# Figure 11.2. The stack

As the figure shows, Stack has a pointer TOS (Top of Stack) which indicates the top most element (which was recently added). At the start, TOS will be pointing to index ‘-1’. Every push increases the pointer by one. Once it reaches an upper bound MAX, no element can be added. Every pop reduces the pointer value by one. There is an index like an array's, which helps to access the elements of array.

# Pushing, Popping

There are two major operations performed using stacks. 1. Push 2. Pop. The process of inserting an element into the stack is called Push operation. The reverse operation, taking an element out the stack is known as popping.

Stack used to follow Last In First Principle (LIFO) principle. This principle pops the element at TOS. (i.e.) Most recently added item is popped.
