# (b) strcpy()

This will help the programmer with copying one string to another. Syntax of strcpy is very simple.

Syntax: strcpy (destination_string, source_string);
A sample code using strcpy () is presented below in program 9.6.

```
# include <stdio.h>
# include <string.h>

int main ()
{
    char string1[13];
    char string2[13];
    strcpy(string1, "C PROGRAMMING");
    strcpy(string2, string1);
    printf("\n Source String %s \n",string1);
    printf("\n Destination String %s \n",string2);
    getch();
    return 0;
}
```

Execution Result:

Source String C PROGRAMMING

Destination String C PROGRAMMING

# Program 9.6 strcpy content stored,

In the event of the destination string already having content stored, it will be overwritten after strcpy. The following example program 9.7 reveals it.

```
# include <stdio.h>
# include <string.h>

int main ()
{
    char string1[13];
    char string2[13]="TESTINPUT";
    strcpy(string1, "C PROGRAMMING");
    strcpy(string2, string1);
    printf("\n Source String %s \n",string1);
    printf("\n Destination String (over written) %s \n",string2);
    return 0;
}
```

Execution Result:

Source String C PROGRAMMING

Destination String C PROGRAMMING
