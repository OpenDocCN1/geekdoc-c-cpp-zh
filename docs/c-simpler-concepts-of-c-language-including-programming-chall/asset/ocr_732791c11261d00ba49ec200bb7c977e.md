# Global Variables

Global variable is defined at the top of the program file and it can be visible and modified by any function that may reference it. A global variable declaration looks normal, but is located outside of any of the program's functions. This is usually at the beginning of the program file, but after pre-processor directives. The variable is not declared in the body of the functions which access it. Modern programming practice recommends against the excessive use of global variables. They can lead to poor program structure, and tend to clog up the available name space. One important thing to know with respect to Global variable is, they are initialised automatically by the system when you define them. The following table 1.10 has summary of the same.

| Data Type | Initializer |
|---|---|
| Int | 0 |
| Char | '\\0' |
