# 14.2.4.2. Trigraph Sequences

C tokens and character set have been discussed in detail in Chapter 1. Of those, were some symbols mentioned which are present in the keyboards of almost all the PCs. But some keyboards do not support all them. ANSI decided to include trigraph sequences which consist of 3 characters. Mentioned below are some of them.

| Trigraph Sequence | Representing character |
|--- |--- |
| ?? | # |
| ??/ | \ |
| ??' | ^ |
| ??( | [ |
| ??) | ] |
| !! | | |
| ??< | < |
| ??> | } |
| ??- | ~ |

Table 14.1 Trigraph sequences

If the reader wants to experiment it, do the following steps.

[Note: Use the printf("%%%c",??-?\); in your program for testing purpose!]

+   1. Go to command prompt (Start->Run->cmd)
2. Traverse to the path where the turbo/ / gcc file is saved.
3. Compile the source file as follows.
4. After successful compilation, link the source file as follows.

B:\Folders\Dev-cpp\bin> gcc -c -trigraphs graph.c, where -trigraphs is to enable the compiler to read the trigraph sequences. graph.c is the source name.
B:\Folders\Dev-cpp\bin> gcc -o output -trigraphs graph.o. After linking successfully, type output in the prompt to view the answer.
