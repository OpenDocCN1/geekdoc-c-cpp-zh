# 10.3.5. Some other file related functions

There are some other used related functions available in ‘C’. They are listed here.

+   * int rename(file pointer);
* int remove(const char *oldname, const char *newname);

The first function deletes the file pointed to by the pointer. The second one is used to rename a file. While renaming a file, the file should not be open. Only closed files can be renamed. Else, the rename will not succeed.
