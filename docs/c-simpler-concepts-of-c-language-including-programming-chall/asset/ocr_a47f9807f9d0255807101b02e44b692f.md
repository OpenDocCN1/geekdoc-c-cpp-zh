The auto specifier indicates that the memory location of a variable is temporary. To be precise, a variable's reserved space in the memory can be erased or relocated when the variable is out of its scope. Only variables with block scope can be declared with the auto specifier. To put in better words, the scope of the auto variables is within a block of code or a function.

To prove the above concept a simple and elegant piece of code has been presented below program 6.2. Here in this program function add ( ) will be called 10 times and it is expected to increment the sum accordingly.

But since scope of an auto variable is within the block of the code, it will die when the compiler goes out of the function. When the function add ( ) for the second, or third or tenth, it will be initialized again with ten and increment once. So the result, return value will remain 11.

```
#include <stdio.h>
main() {
    int i, ret;
    for (i=1; i<=10; i++)
    {
        ret = add();
    }
}
int add() {
    auto int sum = 0;
    sum++;
    printf("\nSum is %d", sum);
}
```
