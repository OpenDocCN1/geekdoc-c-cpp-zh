# 11.6. CIRCULAR LINKED LISTS

Having seen about doubly linked lists, it will be very easy for the readers to learn circularly linked lists. The only difference between this and doubly linked list is that, in circularly linked list, the last node's next pointer will be pointing the first node in the list.
