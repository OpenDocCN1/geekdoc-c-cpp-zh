// Three programs are to be used for this program.
// add.sub.c and main.c are the programs

```
// main.c - This file will use the functions add and sub that has been written in two
// separate files.add.c and sub.c which are kept in the same directory as main.c
#include <stdio.h>
int main()
{
    int x=4, y=5;
    int res;
    res = add("\n The Added Result is %d", res);
    res = sub(x,y);
    printf("\n The Added Result is %d", res);
    return 0;
}
```

```
//add.c
// This is meant for addition.
int add(int a, int b)
{
    printf("\n Addition\");
    return (a+b);
}
```

```
//sub.c
// This is for subtraction.
int sub(int a, int b)
{
    printf("\n Subtraction\");
    return (a-b);
}
```

To get these entire executed one should go ahead with the following sequences.

+   1. gcc -c main.c -> This will generate object file main.o
2. gcc -c add.c -> This will generate object file add.o
3. gcc -c sub.c -> This will generate object file sub.o
