# 11.7. ADVANTAGES OF LINKED LISTS OVER ARRAYS

| Property | Linked List | Arrays |
|---|---|---|n| Size | Dynamically resizable | Static; declared initially. |
| Accessibility | In both the directions, if doubly linked. | Only one way accessibility. |

**Note:** If there is a definite upper bound on size of linked list, it is wise for arrays rather than relying on linked lists, accessing the particular element in linked list is time consuming than accessing the element in arrays. Only if the size of the list is unknown, linked lists can be made of.
