When a char pointer is assigned with some array, it points to the array’s base address; literally, the first member of the array. In the following program, according to the just mentioned logic, a diagram is given below for the readers understanding.

> IMPORTANT: ptr++ does not behave this way for all types of variables. It moves by sizeof(var) if of char type, then it moves 1 byte before. For int and float var, it is 2 & 4 or 4 or 8 bytes accordingly!!! Increment/Decrement operation is one among the few operations that are performed on pointers.

In this way, the entire array is traversed until it encounters a '\0'. Refer to the Program 7.5. The Program 7.6 has been written in the same way as Program 7.5, but the former deals with integer array.

```
#include <stdio.h>
void main()
{
    char a[]="C Programming";
    char *ptr=a;
    int len,i;
    len=strlen(a);
    for(i=0;i<len;i++)
{
        printf("\0%c",*ptr);
        ptr++;
    }
    getch();
}
```
