# STRINGS

# POINTS TO REMEMBER

+   1. A string terminator is a collection of characters. A group of characters stored in an array can be referred to as a string.

+   2. Null terminator is mandatory for a string. If used without null terminator, would lead to printing of garbage values.

+   3. It is always advised not to use gets () and puts (). Instead printf () and scanf () can be used in place.

+   4. There are lots of strings handling functions available with C programming language. All of them like strlen (), strcpy (), strcat (), strcmp (), strcpy () and strncpy () can be used when including a header file string.h.
