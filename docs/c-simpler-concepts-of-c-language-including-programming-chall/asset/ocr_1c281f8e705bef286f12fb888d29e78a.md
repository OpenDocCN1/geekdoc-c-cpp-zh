After having learned about initialization, Let's focus more on our topic, partially initialized structures.

Partially initialized structures are those with only few member variables initialized with the rest uninitialized. In this scenario, the compiler automatically assigns the uninitialized member variables with their default values.

Default value for integer variables :0

Default value for char variables: null

Default value for float variables:0.000000

Refer the following program Program 8.8

```
#include<stdio.h>
struct student
{
    char * s_name;
    long int s_regno;
    float year_of_study;
    char * branch;
};
void main ()
{
    var.s_name="Student";
    printf("nName: %s",var.s_name);
    printf("\nReg No: %ld",var.s_regno);
    printf("\nYear: %f",var.year_of_study);
    printf("\nBranch: %s",var.branch);
    getch();
}
```

| Beg No: 0 | with default values |
| Year: 0.000000 | |
| Branch:(null) | |
