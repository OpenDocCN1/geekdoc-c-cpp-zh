# 3.5. 3-D ARRAYS

If an array has only one subscript, we call it one dimensional. If it has more than one subscript, it becomes a multi dimensional array. We have understood 2-D arrays. Let's concentrate more on multi dimensional array by looking into a 3-D array.

# 3.5.1. Declaring a 3-D array

Just like other types of arrays, declaring a 3-D array is very simple.

Syntax

```
<data type> array_name[first subscript][2nd][3rd];
```
