# 5.5. TO REMEMBER

+   * Functions improve modularity, usability.
* The declaration, definition, function call are the three parts of functions.
* Actual parameters are those which present in function calls. Formal parameters are the dummy variables present inside the function definition.
* Functions do not return any value are declared void.
* Two parameter passing mechanisms are call by value and call by reference. Former passes a copy of variables to the called function, latter shares the address of the variables with the called function.
* Function calls itself is recursive function.
