# One's complement (−)

The last operator in this section simply inverts the bits from 0s to 1s and versa. For instance, the value 12's one's complement will be calculated as follows,

Binary equivalent of 12 is: 0000 0000 0000 1100 (in 16bit processors)

One's complement of 12: 1111 1111 1111 0011 → which is fff3
Where, all the zero's are flipped into 1s and vice versa.

# Examples

+   1. ~(15) = fff
2. ~(33) = fde (Since ~(0000 0000 0000 0001) is (1111 1111 1111 1110) which is fde).
3. ~(66) = fbfd
