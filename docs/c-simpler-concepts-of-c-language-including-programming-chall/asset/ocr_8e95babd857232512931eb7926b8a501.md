# 1.1. HISTORY – HOW DID C GROW?

C is basically derived from two earlier programming languages. They are BPCL and B language. BPCL is Basic Combined Programming Language and was created initiated by Martin Richards in 1967. With the traces being used from BPCL, B was developed in 1970s. Ken Thomson. Then led it. B was the mind and brain behind this utilized to create early versions of UNIX operating system. C led the way to new and most commonly utilized programming language. Dennis Ritchie had his extra-ordinary hard work and brain behind this programming revolution. UNIX operating system is considered to be one of the most robust and secured operating systems. C was used to write it, So C is very efficient that it can be used to create an OS which rules the world.

Note: UNIX is not UNIX, it is UNICS. Unplexed Information and Computing System.

Since C was growing enormously and utilization was more for the same, ANSI (American National Standards Institute) defined a standard for C and it is being used today. It is named as ANSI – C. International Standards Organization (ISO) also approved this version of C. This book will discuss on ANSI – C, fully.
