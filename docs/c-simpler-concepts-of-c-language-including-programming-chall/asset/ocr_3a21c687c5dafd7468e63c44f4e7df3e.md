# Pointers to functions

So far, the reader would have gone through programs where pointers to variables, arrays have been discussed. One can also have a pointer to functions; pass such a pointer to another function, do manipulations like any other pointer. Declaring a function pointer (pointer to a function) is simple.

Syntax:

<return_type> (*function_pointer_name) (parameters);

Example:

void (*fp) (int, int); declares a function pointer 'fp' which can point to a function that takes two integer arguments and returns nothing. It has to be noted that, function pointers can point only to the functions that match the function pointer declaration!

# Initializing function pointers

Suppose, there are two function declarations as follows.

+   - void sum(int,int);
- void diff(int,int);

The function pointer declared previously can be made to point to the above declared functions as follows.

fp=sum; → fp points to the function sum().

Hereafter instead of using sum(10,20), one can alternatively use fp(10,20); (Note that the function should have been defined already)

After some time, the function pointer can be made to point some other function diff() in the same manner as described now.

Any number of function pointers can point to the same function, just like many pointers pointing to the same variable. Comparison is the only operation that can be done with function pointers. A complex function which is supposed to do a lot of works can outsource a portion of work to some other function, by receiving a pointer to that function. Sometimes function pointers are preferred over switch cases.
