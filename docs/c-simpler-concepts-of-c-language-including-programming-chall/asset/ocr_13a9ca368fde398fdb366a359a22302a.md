There are two common methods for doing this.

+   1. Using #include “filename"
2. Using #include<filename>

> Note: Generally, commonly used header files are kept inside the /include folder of the software.

When the first type is used, the compiler searches for the particular file in two places. For instance, suppose there is a file called ‘l.c’ is present in “B:/tc/Cprog/”, and it includes the header file ‘stdio.h’. If the header file is present in the same path, (i.e) B:/tc/Cprog/stdio.h, the compiler won’t throw any error!

+   1. In the same directory/folder where the current file is present. For instance, suppose there is a file called ‘l.c’ is present in “B:/tc/Cprog/”, and it includes the header file ‘stdio.h’. If the header file is present in the same path, (i.e) B:/tc/Cprog/stdio.h, the compiler won’t throw any error!

+   2. In the default path, where all the header files will be saved.
Else, it will flash the error. ‘stdio.h: No such file or directory.

When the files are included using angle brackets (<stdio.h>), the search is performed in the default path alone. Even if the file is found in current working directory, it will flash the error!

What happens on successfully locating the file to be included?

If the file is located, all its contents will be pasted in the currently working file before compilation. So that any reference to the non-existing methods (that do not exist in current file but present in the #included file!) will perfectly work as if they are present in the current file.

# Examples

+   1. #include<stdio.h>
2. #include “arithmetic_operations.h"
3. #include “l.c"
4. #include<time.h>

# 14.2.2. Macro substitution

Suppose, there is a need to use the expression repeatedly in many places in the program.

```
"x* y + x / y -x+y -x”
```

where x and y are integers. Had there been a single substitution statement, upon calling, replaces the called value with the above expression, it would be better, isn’t it? Macros do the same job for us. Macros can be defined using the pre-processor directive ‘define’. For example, there can be a macro which replaces the constant ‘PI’ by 3.14 as.

```
#define PI 3.14
```

As it can be observed, macros are generally written in CAPS. But it’s not mandatory to have them in CAPS. Also note that there is no semi colon at the end! Following programs will clarify the logic behind macros.
