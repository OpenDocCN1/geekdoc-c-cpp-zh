# 10.1. THE NEED

Suppose you own a grocery shop. You want to log the sales details to a place from where you can refer to any particular sale, or you can find the total sales, etc. In this case, handling the operations using structures, or some other like arrays won't be flexible. Instead, it will be cumbersome. In such situations, using 'files' will pacify the crisis. They are simple to deal with. There is a greater flexibility in handling files.

# 10.2. PROPERTIES

+   File handling allows us to,
- create new files
- open the files
- read existing files
- write to a newly created file
- modify existing files
- overwrite file content
- append the existing file
- rename the existing file
- delete a file
- randomly access the file

These are the most widely used functions of file handling. In the upcoming sections, all the above mentioned properties will be put into programming area.
