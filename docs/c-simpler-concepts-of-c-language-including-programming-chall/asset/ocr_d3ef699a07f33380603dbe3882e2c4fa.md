# Type Casting Operator

This operator helps in converting the type of the operands. In an expression, only if both the operands are of same datatype, the result will be accurate. If not, there will be precision losses. To avoid this, type conversions are performed. There are two kinds of type conversions. Namely,

+   1. Implicit type conversion,
2. Explicit type conversion.

The first one is done automatically by the compiler by converting/promoting the lower datatype item to higher one.

# Example

```
float f; double d; long l;
int i; short s;
1. (d + f) -> f will be converted to double
2. (i / s) -> s will be converted to int
3. (l / i) -> i is converted to long;
```

The conversions are applied based on the hierarchies as mentioned below in Figure

| Hierarchy |
| Double |
| float |
| long |
| Int |
| Short and char |

Figure 4.2 Conversion hierarchy

As shown above,

+   * short and char will be promoted to int.
* int to long.
* long to float
* float to double.
