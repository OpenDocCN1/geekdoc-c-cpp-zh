But, one cannot add or subtract a pointer from another pointer, with two exceptions! One is, if we subtract two pointers which are of same type, then the result will always be 1. (subtracting void pointers will yield the size of the variable which is assigned to them). Second, with respect to arrays, if two pointers point to the same array, both pointers can be subtracted from one another, which will yield the number of elements between the two pointers. The effect is undefined for pointers pointing to different arrays. For example refer to the following figure.

```
#include<stdio.h>
void main(){
{
int a[3]={1,2,3},b[3]={4,5,6};
int *p3,*p4;
p3=a;
p4=b;
p3=p3+2;
p4=p4+4;
printf("%u",p4-p3); 	--> will print 2!
}
}
```
