# 4.2.6. Unary operators

These are operators that take only one operand. A couple of unary operators have been discussed in this chapter previously namely, NOT operator (!) and one’s complement operator (-) that take a single operand.

‘C’ describes the following unary operators.

+   - NOT (!)
- Unary Minus (-)
- Unary plus (+)
- Address of operator (&)
- Indirect/ value of operator (*)
- one’s complement (~)
- sizeof()
- casting operator (type_name) expression.
- Increment operator (++)
- Decrement operator (-)

# NOT operator (!)

This operator can be used in expressions where NOT operation is used.

# Example

Suppose a=3.
!a=0

Like NOT operator, these can be prefixed before operands.

# Examples

+   1. int a=10 and int +=10 are one and the same.
2. a=-33;
3. a=-(-33) → similar to a33
4. a=+(-33) → similar to -33

# address of, indirect operator

These operators are used with pointer concepts.

# Example

```
int a=10,*b;
b=&a;
printf("%d",*b) *b prints the value of b. In this case, b holds the address of a,
printf() will print 10.
```

Since one’s complement operator is discussed already, it is skipped.
