malloc() will be helpful to allocate memory for the dynamically growing data structures including, linked lists, trees, etc., to then and there allocate memory! The following program takes you through a concept called structures (discussed in detail in Chapter 11) where malloc() will be useful.

Structures are user defined types which can collectively hold any type of variable at a time. For example, there can be a structure 'student' which is defined to keep students details like, name, age, degree, area_of_specialization, etc., declaring a structure is simple. Here it goes.

```
struct student {
    long reg_no;
    char name[30];
    int age;
    var;
```

In the above declaration, struct is the keyword to be used, student refers the structure name, followed by a block of declarations. At the end, 'var' is declared, which serves as the variable for the just created student data type.(Yes, the structure hereafter serves as a data type, to which we can declare variables, assign values to the variables, just like we do for other built-in data types.)

Ok, how to allocate memory for a structure variable?

It's simple. Just declare a pointer for the structure student, then follow the syntax mentioned above.

For example,

```
struct student *s; // s is the pointer to a structure.
```

```
s = (struct student *) malloc(sizeof(struct)); // allocates memory based on the size of the structure.
```

calloc()

There are two basic differences between malloc() and calloc().

+   1. malloc() is used to allocate a single block of memory. Whereas, calloc() can allocate n blocks of memory.

+   Syntax:
void *calloc(size_t n, size_t size) -> allocates n blocks of size bytes. Returns a NULL if failed.

+   2. malloc() simply initializes all the requested memory. It doesn't initialize them. calloc() initializes all the bytes with zero.
