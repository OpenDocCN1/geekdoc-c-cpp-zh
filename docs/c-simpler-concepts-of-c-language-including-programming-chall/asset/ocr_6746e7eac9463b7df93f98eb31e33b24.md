# 109

Any element in the array = *(base address of the array+Column ID) +<Row ID>

```
#include <stdio.h>
void main() {
  int a[3][3]={{1,2,3},{4,5,6},{7,8,9}};
  printf("a[0][0]=%0d\n",*(a+0));
  printf("a[0][1]=%0d\n",*(a+1));
  printf("a[0][2]=%0d\n",*(a+2));
  printf("a[1][0]=%0d\n",*(a+3));
  printf("a[1][1]=%0d\n",*(a+4));
  printf("a[1][2]=%0d\n",*(a+5));
  printf("a[2][0]=%0d\n",*(a+6));
  printf("a[2][1]=%0d\n",*(a+7));
  printf("a[2][2]=%0d\n",*(a+8));
  getch();
}
```

# Output 7.7

To understand the above program, refer to Figure 7.4. The following points are observed.

+   * Here, 'a' points to the first element of the array.
* *equals a[0], i.e., it returns the address 1032. This address points to the element at offset [0,0], i.e., element 1.
* Therefore, *(a) returns the value 1. *(a) is equivalent to *(a+0)+0
* Incrementing 'a' by 1 makes it point to the next element in the array, i.e., it now points to the element containing the address 1044.
* Hence, *(a + 1) points to the second row first element. It returns the address 1044.
* Therefore, *((a + 1)) returns the value at this address, i.e., the element with the value 4. In other words, the element at the offset [1,0].
