# 9.1.3 String based I/O operations

For performing string based operations C programming provides the user with gets and puts() functions. gets() will obtain a string variable as input. puts() get the string displayed on the screen. puts() will make the cursor to be positioned at the start of next line after execution done. Program 9.2 is presented for making readers understand the usage of gets() and puts().

```
# include <stdio.h>
int main() {
    char str[9];
    puts("Enter string of 8 characters");
    gets(str); // accept the input string
    fflush(stdin);
    puts(str); // displays the string back in screen
    return 0;
}
```

Execution Result:
Enter string of 8 characters
OLYMPICS
OLYMPICS

Execution Result WRONG BEHAVIOR
Enter string of 8 characters
INDIA IS MY COUNTRY
INDIA IS MY COUNTRY

# Program 9.2 Usage of puts() and gets().

There is a flaw with gets() and puts(). The Reader can try running the program. During execution, more than 8 characters. It will still be printed accurately. gets() and puts() are not recommended to be used due to this reason. So how can this be avoided?

Simple again. Program 9.2 has been re-written in a better way which will address the problem stated.

```
# include <stdio.h>
int main() {
    char str[6];
    printf("\nEnter a string of 5 characters\n");
    scanf("%s", string);
    printf("\n%s Entered string is\n", string);
}
```

Execution Result:
Enter string of 5 characters
INDIA IS MY COUNTRY
Entered string is
INDIA
