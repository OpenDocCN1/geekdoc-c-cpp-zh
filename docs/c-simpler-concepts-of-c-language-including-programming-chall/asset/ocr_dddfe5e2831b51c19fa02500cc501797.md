How to pass the reference of the variables?

It is simple. Simply appending an ampersand (&) before the variable in function call would do.

For example, in the above swap program, the following statement will be used instead of swap(&a,b);

swap(&a,b);
where, &a and &b denotes the addresses of a and b respectively. Generally, values of one type variable can be assigned/copied to the variables of same type. For example, in the swap program above, the values of actual parameters a and b of integer type are copied to the dummy variables a and b of same type. By reference, we are passing the address of the variable. An obvious question now would be, 'how to catch the address of a variable?' Pointers doing this job are used to hold the addresses of other variables.

Example,
int a;
int *ptr=&a; -> ptr is an integer pointer which holds the address of integer variable 'a'.
float b;
float *ptr=&b-> float pointer which holds the address of float variable b;

**Important Note:** Like by value, in call by reference, the function does not get a copy of the variables instead, the called function refers to the memory location of the variables and, whatever change one does to the passed variables, it will get reflected in the original variables!
