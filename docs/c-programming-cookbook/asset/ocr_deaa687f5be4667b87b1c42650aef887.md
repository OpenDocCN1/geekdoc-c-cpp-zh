Pretend for a second that our application is dealing with a huge matrix, or 2D array. The data is stored in memory in a specific way, so accessing the matrix row-wise instead of column-wise can significantly impact performance.

```
constexpr size_t SIZE = 1024;

int matrix[SIZE][SIZE];

// Row-wise access (Cache-friendly)

for(size_t i = 0; i < SIZE; ++i) {

for(size_t j = 0; j < SIZE; ++j) {


matrix[i][j] *= 2;

}

}

// Column-wise access (Less cache-friendly)
```
