# Formatting Output

Fixed and Scientific Notation: Use std::fixed and std::scientific to control the formatting of floating-point values.

Set Precision: std::setprecision(int n) determines the number of digits displayed for floating-point values.

Width and Fill: Control field width with std::setw(int n) and fill characters with std::setfill(char c) for aligning output.
