# Commonly Used Type Traits

Type Categories: etc., help determine the category of a type.
Type Properties: and std::is_pod (Plain Old Data) provide information about type properties.

Type Relationships: std::is_sameU>, std::is_base_of<Derived>, and std::is_convertibleTo> enable checking relationships between types.
Type Modifiers: etc., modify types in a generic way.
