# # Lock Ordering

A common strategy to avoid deadlocks is to enforce a consistent order in which locks are acquired. If all threads lock resources in the same order, circular wait conditions (one of the necessary conditions for deadlocks) can be prevented.

Following is the sample program:

```
```cpp
std::mutex mutexA, mutexB;

void thread1Function(){

std::lock_guard< mutex> lockA(mutexA); // First lock A

// Perform some operation...

std::lock_guard< mutex> lockB(mutexB); // Then lock B

// Perform operations involving A and B

}
```
