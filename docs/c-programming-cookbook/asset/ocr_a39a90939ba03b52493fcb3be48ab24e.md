A `std::shared_ptr` can be created using the `std::make_shared` function, which allocates the object and returns a `std::shared_ptr` that owns it. `std::make_shared` is preferred over direct use of the `std::shared_ptr` constructor because it performs a single allocation for both the object and its control block, improving performance.
