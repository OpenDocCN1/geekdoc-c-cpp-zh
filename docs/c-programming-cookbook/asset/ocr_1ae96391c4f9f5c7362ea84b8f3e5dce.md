# Choosing the Right Execution Policy

+   - Sequential (default): std::execution::seq for operations that must be performed sequentially.
+   - Parallel: std::execution::par allows the implementation to parallelize the algorithm.
+   - Parallel and Vectorized: std::execution::par_unseq suggests that parallel execution and vectorization optimizations are permissible, potentially offering the highest performance for suitable algorithms and hardware.
