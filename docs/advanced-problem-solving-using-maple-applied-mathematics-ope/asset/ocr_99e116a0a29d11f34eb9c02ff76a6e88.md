Estimates of the $b_i$ are the final values from the numerical search method (if it converged) used to maximize the log-likelihood function $\ln L$ of (6.4). The values of $se(b_i)$, the standard error estimate for $b_i$, are the square roots of the main diagonal of the variance-covariance matrix $VC = -H(X'B^{-1}B)^{-1}B^{-1}$. The values of $t_i^* = b_i/se(b_i)$ and the $p$-value, the probability $P(T > |t_i^*|)$.
