
Therefore, the necessary conditions are

$\partial L/\partial x \Rightarrow 2(x-14)+2\lambda_1(x-11)+2\lambda_2x=0$  
$\partial L/\partial y \Rightarrow 2(y-11)+2\lambda_1(y-13)+2\lambda_2y=0$  
$\partial L/\partial \lambda_1 \Rightarrow (x-11)^2+(y-13)^2+\mu_1^2-49=0$  
$\partial L/\partial \lambda_2 \Rightarrow x+y+\mu_2^2-19=0$  
$\partial L/\partial \mu_1 \Rightarrow 2\lambda_1\mu_1=0$  
$\partial L/\partial \mu_2 \Rightarrow 2\lambda_2\mu_2=0$

Define the functions in Maple, then investigate the cases for $\lambda_i$ and $\mu_i$ being zero or nonzero. # Applications Using the Kuhn-Tucker Conditions Method

# Example 4.28. Maximizing Profit from Perfume Manufacturing.

A company manufactures perfumes. They can purchase up to 1,925 oz of the main chemical ingredient at $10 per oz. An ounce of the chemical can produce an ounce of Perfume #1 with a processing cost of $3 per oz. On the other hand, the chemical can produce an ounce of the higher priced Perfume #2 with a processing cost of $5 per oz. The Analytics department used historical data to estimate that Perfume #1 will sell for $(30 - 0.01x)$ per ounce if $x$ ounces are manufactured, and Perfume #2 can sell for $(50 - 0.02y)$ per ounce if $y$ ounces are manufactured. The company wants to maximize profits.

# MODEL FORMULATION. Let

$x$ = ounces of Perfume #1 produced  
$y$ = ounces of Perfume #2 produced  
$z$ = ounces of main chemical purchased

Then

Maximize $P(x,y,z)=x\cdot(30-0.01x)+y\cdot(50-0.02y)-(3x+5y+10z)$  
subject to  
$x+y\le z$  
$z\le 1925$

Solution. Set up the model, define the Lagrangian function $L$, and use the techniques from the previous examples.

```
P := (x,y,z) -> x·(30 − 0.01x) + y·(50 − 0.02y) − (3x + 5y + 10z):
g1 := (x,y,z) -> x + y − z:
g2 := (x,y,z) -> z:
L := (x,y,z,λ1,λ2,μ1,μ2) -> P(x,y,z) + λ1·g1(x,y,z) + μ1² − 0.0
    + λ2·(g2(x,y,z) − 1925.0):
grad := Gradient(L(x,z,λ1,λ2,μ1,μ2), [x,y,z,λ1,λ2,μ1,μ2]):
vars := [x,y,z,λ1,λ2,μ1,μ2]:
NecessaryConditions := [seq(G = 0, G in grad)]:
    {NecessaryConditions};
    [
      27 − 0.02x + λ1 = 0
      45 − 0.04y + λ1 = 0
      −10 − λ1 + λ2 = 0
      μ1² + x + y − z = 0
      z + μ2² − 1925.0 = 0
    ]
```

Once again, we’re ready to begin working through the four cases. A summary of the results from Maple is shown in Table 4.9.

The optimal manufacturing strategy is to purchase z = 1725 ounces of the chemical and produce x = 850 ounces of Perfume #1 and y = 875 ounces of Perfume #2 yielding a profit of P = $22,537.50.
