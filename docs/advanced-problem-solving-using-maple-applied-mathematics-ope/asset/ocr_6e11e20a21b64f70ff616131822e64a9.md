# ## 3.2 基于多源数据的城市交通拥堵预测模型

城市交通拥堵预测是智能交通系统的核心功能之一。传统的预测方法主要依赖单一数据源（如固定检测器数据），难以全面反映交通运行状态。本文提出一种基于多源数据融合的交通拥堵预测模型，综合利用浮动车GPS数据、交通卡口数据、气象数据和节假日信息，通过深度学习算法实现对未来15-60分钟交通拥堵状况的准确预测。

模型整体架构如图3-2所示，主要包括数据采集层、数据预处理层、特征融合层、预测引擎层和结果输出层五个部分。数据采集层负责接入多源异构数据；预处理层完成数据清洗、缺失值填补和标准化；特征融合层采用注意力机制对多源特征进行自适应加权；预测引擎层基于改进的时空图卷积网络（ST-GCN）构建；结果输出层提供路段级和路网级两种粒度的预测结果。

![](bbox=[0.15, 0.33, 0.85, 0.55])

在特征融合方面，本文设计了一种动态注意力融合机制（Dynamic Attention Fusion, DAF）。该机制能够根据实时交通状态自动调整不同数据源的权重，在拥堵形成初期重点依赖浮动车数据，在拥堵消散阶段则更多参考卡口数据。实验表明，DAF机制相比固定权重融合方法，预测精度提升了12.3%。

预测引擎采用改进的ST-GCN模型，在原有空间图卷积和时间卷积的基础上，引入了外部因素嵌入层和残差连接结构。模型输入为过去60分钟的多源特征序列，输出为未来15、30、45、60分钟四个时间尺度的拥堵指数预测值。训练过程中采用分阶段训练策略，先预训练基础模块，再联合微调整个网络。

为验证模型有效性，本文选取某市核心城区约50平方公里范围作为实验区域，收集了2023年1月至6月共6个月的实测数据。对比实验选取了ARIMA、LSTM、GRU和标准ST-GCN作为基线模型，采用MAE、RMSE和MAPE作为评价指标。实验结果如表3-1所示。

| 模型 | MAE | RMSE | MAPE(%) |
|------|-----|------|---------|
| ARIMA | 8.42 | 11.37 | 15.8 |
| LSTM | 6.15 | 8.92 | 11.2 |
| GRU | 5.87 | 8.45 | 10.6 |
| ST-GCN | 4.93 | 7.21 | 8.9 |
| 本文模型 | 3.86 | 5.64 | 6.8 |
