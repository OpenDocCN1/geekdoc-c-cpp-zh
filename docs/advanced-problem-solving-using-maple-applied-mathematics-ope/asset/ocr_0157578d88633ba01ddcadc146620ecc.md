Use Maple to investigate the **Police-Insurgents** DDS.

```
Insurgency := proc(n :: integer)
    local u, v, p, r;
    global p0, r0;
    option remember;
    if n < 1 then
        u := [p0, r0];    # Initial [police, insurgents]
    else
        v := Insurgency(n − 1);
        p := v[1];        # current police
        r := v[2];        # current insurgents
        u := [0.86 p + 0.08 r + 85, 0.11 p + 0.82 r + 120];
    end if;
    return(u);
end proc;
```

```
p0, r0 := 1300, 1000:
```
