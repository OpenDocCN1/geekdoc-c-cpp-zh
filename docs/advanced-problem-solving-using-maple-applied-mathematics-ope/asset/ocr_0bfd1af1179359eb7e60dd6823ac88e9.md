# Example 4.12. Finding the Least Squares Regression Line.

In using least squares regression to fit a line $y=a+bx$ to a set of $n$ data points $\{(x_i,y_i)\}$, we minimize the sum of squared errors

$$SSE=\sum_{i=1}^{n}\left(y_i-(a+bx_i)\right)^2.$$

the variables are $a$ and $b$.

Begin by finding the system of equations that will determine the critical points. First,

$$\frac{\partial f}{\partial a}=\sum_{i=1}^{n}2\left(y_i-(a+bx_i)\right)(-1)$$

$$\frac{\partial f}{\partial b}=\sum_{i=1}^{n}2\left(y_i-(a+bx_i)\right)(-x_i)$$
