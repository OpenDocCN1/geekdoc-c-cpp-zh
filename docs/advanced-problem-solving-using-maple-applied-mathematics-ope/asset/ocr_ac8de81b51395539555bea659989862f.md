# **Example 4.20. Lagrange Multipliers with Multiple Constraints.**

Minimize $w=x^2+y^2+z^2$ subject to $x+y=3$ and $x+3y+2z=7$.

First, we directly solve the problem using Maple.

```
with(Student[MultivariateCalculus]);
```

```
f := (x,y,z) -> x^2 + y^2 + 3z:
```

```
Constraints := (3 - (x + y), 7 - (x + 3y + 2z));
```

Now, define the Lagrangian function $L$ and find its gradient.

```
L := (x,y,z,λ,μ) -> f(x,y,z) + λ · Constraints + μ · Constraints2:
```

```
grad := Gradient(L(x,y,z,λ,μ), [x,y,z,λ,μ]);

  x + y − 3
  x + 3y + 2z − 7
```
