For a more thorough coverage, we suggest studying complete texts on the subject such as Ruszczynski’s *Nonlinear Optimization* (Princeton Univ. Press, 2006).

# Basic Theory

We begin with how to find an optimal solution, if one exists, for the unconstrained nonlinear optimization problem

Maximize (or minimize) $f(x_1,x_2,\ldots,x_n)$ over $\mathbb{R}^n$

We assume that all the first and second partial derivatives of $f$ exist and are continuous at all points in $f$’s domain. Let the partial derivative of $f$ with respect to $x_i$ be

$$\frac{\partial f(x_1,x_2,\ldots,x_n)}{\partial x_i}.$$
