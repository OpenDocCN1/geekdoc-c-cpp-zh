We define the individual cubic functions using an “indexed proname” to make the code more general.

```
S := proc(x)
    local i;
    i := op(x);
    return(a[i,3] · x^3 + a[i,2] · x^2 + a[i,1] · x + a[i,0];
end proc:
```

Now define the natural cubic spline function for our 6 point data set.


In order to avoid some convoluted statements, we’ll define the cubic segment’s derivative functions directly.

```
dS := proc(x)
    local i;
    i := op(proname);
    return(3 · a[i,3] · x^2 + 2a[i,2] · x + a[i,1]);
end proc:

d2S := proc(x) local i;
    i := op(proname);
    return(6 · a[i,3] · x + 2a[i,2]);
end proc:
```
