+   (c) Define: A differentiable function is
+   
+   - **convex or concave up** on the interval $[a,b]$ iff $f$ lies above all of its tangents; that is, for all $x_1<x<x_2$ in $[a,b]$,
+     $$f'(x)\le\frac{f(x_2)-f(x_1)}{x_2-x_1}$$
+   
+   - **concave or concave down** on the interval $[a,b]$ iff $f$ lies below all of its tangents; that is, for all $x_1<x<x_2$ in $[a,b]$,
+     $$f'(x)\ge\frac{f(x_2)-f(x_1)}{x_2-x_1}$$
+   
+   A twice differentiable function is
+
