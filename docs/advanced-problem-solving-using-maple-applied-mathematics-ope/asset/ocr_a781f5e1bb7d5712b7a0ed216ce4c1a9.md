# ### 1.1 认识三角形

三角形是生活中常见的图形。观察图1-1中哪些图片中有三角形？

![](bbox=[0.05, 0.18, 0.95, 0.45])

如图1-2，由不在同一条直线上的三条线段首尾顺次相接所组成的图形叫做三角形（triangle）。

![](bbox=[0.05, 0.57, 0.3, 0.75])

如图1-2，线段AB，BC，CA是三角形的边。点A，B，C是三角形的顶点。∠A，∠B，∠C是三角形的内角，简称三角形的角。

三角形用符号“△”表示，如图1-2的三角形记作“△ABC”，读作“三角形ABC”。

三角形的边AB，BC，CA可以用小写字母a，b，c表示。如图1-2，顶点A所对的边BC用a表示，顶点B所对的边CA用b表示，顶点C所对的边AB用c表示。

如图1-3，用橡皮筋在钉子板上围出不同形状的三角形，并画出这些三角形。
