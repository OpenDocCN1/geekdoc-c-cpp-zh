For the plot, we'll embed the contour plot into a 3D plot to make a better visual representation of $f$. To embed the plot, use the `transform` command from the `plots` package.

```
T := transform((x, y) → [x, y, -500]);
```

Then T will take a point $(x,y)$ on a 2D contour plot and embed it in a 3D plot on the plane $z=-500$.

```
rng := (x = -10..10, y = -10..10):
Surface := plot3d(f(x, y), rng, style = patchcontour, contours = 15):
Contours := contourplot(f(x, y), rng, contours = 15):
```

Now, put the graphs together.

```
display(Surface, T(Contours));
```
