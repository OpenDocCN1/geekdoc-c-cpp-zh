Lagrange multipliers⁶ can be used to solve nonlinear optimization problems (NLPs) in which all the constraints are equations. Consider the NLP given by

Maximize (Minimize) z = f(x)

# Lagrange Multipliers: Introduction and Basic Theory

In order to solve NLPs in the form of (4.2), we associate a Lagrange multiplier λᵢ with the iᵗʰ constraint, and form the Lagrangian function

L(x, λ) = f(x) + Σᵢ₌₁ᵐ λᵢ (gᵢ(x) − bᵢ)   (4.3)

The computational procedure for Lagrange multipliers requires that all the partials of the Lagrange function (4.3) must equal zero at x* form the necessary conditions that x* is a solution to the NLP problem; i.e., these conditions are required for x = ⟨x₁, x₂, ..., xₙ⟩ to be a solution to (4.2).
