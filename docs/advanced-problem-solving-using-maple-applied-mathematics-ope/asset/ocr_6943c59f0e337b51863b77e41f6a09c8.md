STEP 3. The normalized weights **w = [w_j]** are then given by

$$w_j = \frac{1-e_j}{\sum_{k=1}^{m}(1-e_k)}.$$

The degree of divergence vector **d = [d_j] = 1 − e** indicates the average amount of information contained by each attribute with higher being more.

The book’s **PSMv2** package contains **EntropyWeights** to calculate weights from a matrix via the entropy method and **Normalize** to normalize a matrix via column-sums. As an example, use the **AltM** preference matrix from the Car Selection example (pg. 377) above.

```
> AltM :=
[
  [27.8  9.4  3  7.5  44  40  8.7]
  [28.5  9.6  4  8.4  47  47  8.1]
  [38.7  9.6  3  8.2  35  40  6.3]
  [25.5  9.4  5  7.8  43  39  7.5]
  [27.5  9.6  5  7.6  36  40  8.3]
  [36.2  9.4  3  8.1  36.2  40  8.0]

```

```
> EntropyWeights(AltM);
[
  [0.2300  0.0010  0.4995  0.0155  0.1227  0.0389  0.0924]
]
```

Compare these weights with the other methods’ values. These weights can be used in our methods, SAW, AHP, or TOPSIS, in lieu of the pairwise comparison weight method.
