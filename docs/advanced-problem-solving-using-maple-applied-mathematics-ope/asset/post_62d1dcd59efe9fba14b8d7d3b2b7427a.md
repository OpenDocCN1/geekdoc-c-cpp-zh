## 1.1.1 认识金属材料

金属材料是重要的结构和功能材料，广泛应用于工业生产、建筑、交通运输、航空航天等领域。

金属材料通常分为黑色金属和有色金属两大类。黑色金属包括铁、铬、锰及其合金，有色金属包括铜、铝、钛、镁及其合金等。

![](img/0f04050177d82aebd17d3383d7334896_287_0.png)

金属材料具有许多优良的性能，如导电性、导热性、延展性和高强度等。

- 导电性好
- 导热性好
- 延展性好
- 强度高

合金是在金属中加热熔合某些金属或非金属所制得的具有金属特性的物质。合金的强度和硬度一般比组成它们的纯金属更高，抗腐蚀性能也更好。

| 金属材料类别 | 常见材料 | 主要用途 |
| --- | --- | --- |
| 黑色金属 | 铁、钢 | 建筑、机械制造 |
| 有色金属 | 铜、铝 | 电线、航空材料 |

金属材料在现代社会的发展中起着不可替代的作用。

# RECOMMENDED STEPS FOR REGRESSION ANALYSIS:

- STEP 1. Insure you understand the problem and what answers or predictions are required.
- STEP 2. Get the data that is available. Identify the dependent and independent variables.
- STEP 3. Plot the dependent versus each independent variable, and note any apparent trends.
- STEP 4. If the dependent variable is binary {0,1}, then use binary logistic regression. If the dependent variables are counts that follow a Poisson distribution, then use Poisson regression. Otherwise, try linear, multiple, or nonlinear regression as indicated by the situation being studied – science trumps curve fitting.
- STEP 5. Insure your model produces results that are acceptable. Always use the common-sense test.
