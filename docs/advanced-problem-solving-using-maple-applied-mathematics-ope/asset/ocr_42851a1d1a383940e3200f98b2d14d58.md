# Problem.

Build a mathematical model of this insurgency. Determine the equilibrium state, if it exists, for the DDS.

# Variables.

$n$ = current time period  
$p(n)$ = number of police in the force at the end of time period $n$  
$r(n)$ = number of insurgents/rebels at the end of time period $n$

for $n = 0, 1, 2, \ldots$ weeks.

# Model.

```
$$\begin{aligned}
p(n+1) &= p(n)-0.03p(n)-0.11p(n)+0.08r(n)+85 \\
       &= 0.86p(n)+0.08r(n)+85 \\
I(n+1) &= r(n)+0.11p(n)-0.08r(n)-0.1r(n)+120 \\
       &= 0.11p(n)+0.82r(n)+120
\end{aligned}$$
```

with $P(0)=1300$ and $I(0)=1000$ and $n=0,1,2,\ldots$.
