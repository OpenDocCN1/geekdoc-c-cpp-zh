# Projects

**Project 1.** Explain why we need to use the smallest integer solution for the balanced chemical reactions. Provide examples.

**Project 2.** The reduction of kerosene takes place in three steps

$$\mathrm{C_{10}H_{16} + O_2 \longrightarrow CO + H_2}$$
$$\mathrm{CO + O_2 \longrightarrow CO_2}$$
$$\mathrm{H_2 + O_2 \longrightarrow H_2O}$$

Balance the three reactions simultaneously.
