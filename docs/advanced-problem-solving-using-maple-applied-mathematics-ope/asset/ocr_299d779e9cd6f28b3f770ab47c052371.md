# General Introduction to Maple

Let’s consider an example.

```
> f := x → (x − 5)^2 − 3;
  f := x ↦ (x − 5)^2 − 3;
```

We plot the function to be able to estimate the roots for the procedure.

```
> plot(f(x), x = −1..10, thickness = 3, color = black);
```

![](bbox=[0.278, 0.227, 0.714, 0.524])
