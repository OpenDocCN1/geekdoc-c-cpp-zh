As a total conflict game, [Table 7.8](#) only needs to list the outcomes to Kenney in order to find a solution.

**TABLE 7.8: The Battle of the Bismarck Sea as a Zero Sum Game**

| Kenney |  | **Imamura** |
|---|---|---|
|  |  | **North** | **South** |
| **North** |  | 2 | 2 |
| **South** |  | 1 | 3 |

There is a dominant column strategy for Imamura: to sail *North* since the values in the column are correspondingly less than or equal to the values for sailing *South*. The dominant *North* column would eliminate the *South* column. Seeing that as an option, Kenney would search *North*—that option provides a greater outcome than searching *South*, (2 > 1). He could also apply the *minimax* theorem (*saddle point method*) to find a plausible Nash equilibrium as Kenney searches *Northern* and Imamura takes the Northern route. See [Table 7.9](#).

**TABLE 7.9: Minimax Method (Saddle Point Method)**

| Kenney |  | **Imamura** |  | **Row Min** | **Max of Min** |
|---|---|---|---|---|---|
|  |  | **North** | **South** |  |  |
| **North** |  | 2 | 2 | 2 | **2** |
| **South** |  | 1 | 3 | 1 |  |
| **Column Max** |  | 2 | 3 |  |  |
| **Min of Max** |  | **2** |  |  |  |

Applied to the Battle of the Bismarck Sea, the Nash equilibrium (*North, North*) implies that no player can do unilaterally better by changing their strategy. The solution is for the Japanese to sail *North* and for Kenney to search *North* yielding 2 bombing days. This result, (*North, North*), was indeed the real outcome in 1943.
