```
When a dynamical system does not have a closed-form analytical solution, the **rsolve** command chooses its input, so we cannot use a formula in the (seq) command to generate values. We’ll need to use **proc** to create a program to iterate the discrete dynamical system. Call the program *Tower* and use inputs *n0*, *t0*, and *n* where *n0* is the first non negative integer in our domain, *t0* is our first arrange value (that is, *(n0, t0)* is the initial condition), and *n* is the nonnegative integer value from our domain that we need. We use ‘option remember’ so the program stores and can recall the previously iterated values. Without remembering values, a simple recursion can take huge numbers of calculations to compute a value. For example, the Fibonacci numbers given by F(n) = F(n − 1) + F(n − 2) take on the order of 2ⁿ calculations to compute F(n) when previous values aren’t remembered.

```
```maple
> Tower := proc(n0,t0,n)
      option remember;
      local T;
      if n > n0 then
         T := 2 · Tower(n0,t0,n − 1) + 1;
      else
         T := t0;
      end if;
      return T;
   end proc:
```
