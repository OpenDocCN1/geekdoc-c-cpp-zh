# Example 4.23. Two Variable-Two Constraint Linear Problem.

```
$$\begin{aligned}
\text{Maximize } z &= 3x+2y\\
\text{subject to}\quad &2x+y\le 100\\
&x+y\le 80
\end{aligned}$$
```

Define the generalized Lagrangian (4.5) for this problem.

```
$$L(x,\lambda,\mu)=(3x+2y)+\lambda_1(2x+y+\mu_1^2-100)+\lambda_2(x+y+\mu_2^2-80)$$
```

The six Necessary Conditions are:

+   1. \(\partial L/\partial x=0\Rightarrow 3+2\lambda_1+\lambda_2=0\)  (4.7a)  
+   2. \(\partial L/\partial y=0\Rightarrow 2+\lambda_1+\lambda_2=0\)  (4.7b)  
+   3. \(\partial L/\partial \lambda_1=0\Rightarrow 2x+y+\mu_1^2-100=0\)  (4.7c)  
+   4. \(\partial L/\partial \lambda_2=0\Rightarrow x+y+\mu_2^2-80=0\)  (4.7d)  
+   5. \(\partial L/\partial \mu_1=0\Rightarrow 2\mu_1\lambda_1=0\)  (4.7e)  
+   6. \(\partial L/\partial \mu_2=0\Rightarrow 2\mu_2\lambda_2=0\)  (4.7f)

Recognize that, since there are two constraints, there are four (\(2^2\)) cases required to solve for the optimal solution. These 4 cases stem from necessary conditions \(2\mu_1\lambda_1=0\) and \(2\mu_2\lambda_2=0\), the complementary slackness conditions. The cases are collected in Table 4.7.

# ## 3.2 基于多源数据的城市交通拥堵预测模型

城市交通拥堵预测是智能交通系统的核心功能之一。传统的预测方法主要依赖单一数据源（如固定检测器数据），难以全面反映交通运行状态。本文提出一种基于多源数据融合的交通拥堵预测模型，综合利用浮动车GPS数据、交通卡口数据、气象数据和节假日信息，通过深度学习算法实现对未来15-60分钟交通拥堵状况的准确预测。

模型整体架构如图3-2所示，主要包括数据采集层、数据预处理层、特征融合层、预测引擎层和结果输出层五个部分。数据采集层负责接入多源异构数据；预处理层完成数据清洗、缺失值填补和标准化；特征融合层采用注意力机制对多源特征进行自适应加权；预测引擎层基于改进的时空图卷积网络（ST-GCN）构建；结果输出层提供路段级和路网级两种粒度的预测结果。

![](img/0f04050177d82aebd17d3383d7334896_197_0.png)

在特征融合方面，本文设计了一种动态注意力融合机制（Dynamic Attention Fusion, DAF）。该机制能够根据实时交通状态自动调整不同数据源的权重，在拥堵形成初期重点依赖浮动车数据，在拥堵消散阶段则更多参考卡口数据。实验表明，DAF机制相比固定权重融合方法，预测精度提升了12.3%。

预测引擎采用改进的ST-GCN模型，在原有空间图卷积和时间卷积的基础上，引入了外部因素嵌入层和残差连接结构。模型输入为过去60分钟的多源特征序列，输出为未来15、30、45、60分钟四个时间尺度的拥堵指数预测值。训练过程中采用分阶段训练策略，先预训练基础模块，再联合微调整个网络。

为验证模型有效性，本文选取某市核心城区约50平方公里范围作为实验区域，收集了2023年1月至6月共6个月的实测数据。对比实验选取了ARIMA、LSTM、GRU和标准ST-GCN作为基线模型，采用MAE、RMSE和MAPE作为评价指标。实验结果如表3-1所示。

The following is a short Maple session of the computations above.

```
with(Student[MultivariateCalculus]);
f := (x, y) → 3x + 2y:
Constrnt := [2x + y − 100, x + y − 80]:
L := (x, y, λ₁, λ₂, μ₁, μ₂) → f(x, y) + λ₁·Constrnt[1] + λ₂·Constrnt[2] + μ₁² + μ₂²:
grad := Gradient(L(x, y, λ₁, λ₂, μ₁, μ₂), [x, y, λ₁, λ₂, μ₁, μ₂]):
NecCond := [seq(G = 0, G in grad)]:
(NecCond);
```

```
3 + 2λ₁ + λ₂ = 0
2 + λ₁ + λ₂ = 0
μ₁² + 2x + y − 100 = 0
μ₂² + x + y − 80 = 0
2λ₁μ₁ = 0
2λ₂μ₂ = 0
```

```
soln := solve(NecCond, [x, y, λ₁, λ₂, μ₁, μ₂]);
soln := [[x = 20, y = 60, λ₁ = −1, λ₂ = −1, μ₁ = 0, μ₂ = 0]];
f(20, 60);
subs(x = 20, y = 60, Constraint);
180
[0, 0]
```

How do we know we’ve found a maximum? Recall the rules for finding the maximum or minimum.

MAXIMUM: If f(x) is a concave function and each constraint gᵢ(x) is a convex function, then any point that satisfies the necessary conditions is an optimal solution that maximizes the function subject to the constraints and has each λᵢ ≤ 0.

MINIMUM: If f(x) is a convex function and each constraint gᵢ(x) is a convex function, then any point that satisfies the necessary conditions is an optimal solution that minimizes the function subject to the constraints and has each λᵢ > 0.

The objective function is linear, and so is both convex and concave, as are the constraints. Since the values of λᵢ are both negative, we have found the maximum.

Maximize \(z=(x-14)^2+(y-11)^2\)  
subject to  
\[(x-11)^2+(y-13)^2\le 49\]  
\[x+y\le 19\]

Use Maple to generate contour plots overlaid with the constraints to obtain the geometrical interpretation shown in the worksheet below. The optimal solution, as visually shown, is the point where the level curve of the *objective function is tangent to the constraint* \(x+y=19\) in the direction of increase for the contours of \(f\). The solution satisfies the other constraint \((x-11)^2+(y-13)^2\le 49\), but there is slack in this constraint. The solution corresponds to the case where Constraint 2 is binding and Constraint 1 is nonbinding. The constraints being nonbinding and binding, respectively, are shown computationally by

\[(\lambda_1=0,\mu_1^2\ne 0)\text{ and }(\lambda_2\ne 0,\mu_2=0).\]

We use the fact that Constraint 1 is nonbinding and Constraint 2 is binding to directly solve this case to find the optimal solution. Graphically, we can obtain a good approximation, but we cannot obtain the shadow prices which are invaluable in sensitivity analysis. In this case, we saw that

$(\lambda_1 = 0,\; \mu_1^2 \ne 0)$ and $(\lambda_2 \ne 0,\; \mu_2^2 = 0)$.

The *necessary conditions* for this case are

\(\partial L/\partial x \implies 2x - 28 + \lambda_2 = 0\)

\(\partial L/\partial y \implies 2y - 22 + \lambda_2 = 0\)

\(\partial L/\partial \lambda_1 \implies (x - 11)^2 + (y - 13)^2 + \mu_1^2 - 49 = 0\)

\(\partial L/\partial \lambda_2 \implies x + y - 19 = 0\)

Let’s use Maple to find the optimal point and the shadow prices. We’ve defined \(f\) and \(g_i\) above, so start by loading the *Student[MultivariateCalculus]* package to make *Gradient* available.

Interpreting the shadow prices shows that if there are more resources for Constraint 2, our objective function will decrease. If we add Δ to the right-hand side of Constraint 2, the objective function value will decrease by approximately 6Δ.
