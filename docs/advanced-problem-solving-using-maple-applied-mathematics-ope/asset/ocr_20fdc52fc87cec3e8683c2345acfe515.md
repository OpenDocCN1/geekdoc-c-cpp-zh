# Example 4.23. Two Variable-Two Constraint Linear Problem.

```
$$\begin{aligned}
\text{Maximize } z &= 3x+2y\\
\text{subject to}\quad &2x+y\le 100\\
&x+y\le 80
\end{aligned}$$
```

Define the generalized Lagrangian (4.5) for this problem.

```
$$L(x,\lambda,\mu)=(3x+2y)+\lambda_1(2x+y+\mu_1^2-100)+\lambda_2(x+y+\mu_2^2-80)$$
```

The six Necessary Conditions are:

+   1. \(\partial L/\partial x=0\Rightarrow 3+2\lambda_1+\lambda_2=0\)  (4.7a)  
+   2. \(\partial L/\partial y=0\Rightarrow 2+\lambda_1+\lambda_2=0\)  (4.7b)  
+   3. \(\partial L/\partial \lambda_1=0\Rightarrow 2x+y+\mu_1^2-100=0\)  (4.7c)  
+   4. \(\partial L/\partial \lambda_2=0\Rightarrow x+y+\mu_2^2-80=0\)  (4.7d)  
+   5. \(\partial L/\partial \mu_1=0\Rightarrow 2\mu_1\lambda_1=0\)  (4.7e)  
+   6. \(\partial L/\partial \mu_2=0\Rightarrow 2\mu_2\lambda_2=0\)  (4.7f)

Recognize that, since there are two constraints, there are four (\(2^2\)) cases required to solve for the optimal solution. These 4 cases stem from necessary conditions \(2\mu_1\lambda_1=0\) and \(2\mu_2\lambda_2=0\), the complementary slackness conditions. The cases are collected in Table 4.7.
