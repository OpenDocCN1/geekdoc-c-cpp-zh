# Column Operations

In this section, the operations that can be performed directly on worksheet columns are present. The operations require the `LinearAlgebra` package to be loaded prior to use. The following demonstrates these commands with six examples using two columns of data; `c1 := [1, 2, 3, 4]` and `c2 := [5, 6, 7, 8]`.

```
```maple
> with(LinearAlgebra):
> c1 := <1|2|3|4>;
                         c1 := [1, 2, 3, 4]
> c2 := <5|6|7|8>;
                         c2 := [5, 6, 7, 8]
```
```

Summing the vectors c1 and c2

```
```maple
> VectorAdd(c1,c2);
                         [6, 8, 10, 12]
> c1 + c2;
                         [6, 8, 10, 12]
```
```

To add a constant to the entries of c1, use `+~`

```
```maple
> 10 +~ c1;
                         [11, 12, 13, 14]
```
```

To multiply c2 by constant, use either

```
```maple
> VectorScalarMultiply(c2, 0.5);
                         [2.50000000000000000  3.0  3.50000000000000000  4.0]
> 0.5 · c2;
                         [2.5  3.0  3.5  4.0]
```
```

To apply a function to the elements of a vector use map or `~`.

```
```maple
> map(ln,c1);
       evalf(%);
                         [0   ln(2)   ln(3)   2 ln(2)]
                         [0.0  0.6931471806  1.098612289  1.386294361]
> ln~(c2);
                         [ln(5)  ln(6)  ln(7)  3 ln(2)]
> map(x → x^2,c2);
                         [25  36  49  64]
```
