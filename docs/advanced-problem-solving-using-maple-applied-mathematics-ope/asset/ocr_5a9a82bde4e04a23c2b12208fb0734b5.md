```

We determine the optimal solution that satisfies the conditions is: x* = 11, y* = 8, λ₁ = 0, λ₂ = 6, μ₁² = 24, and μ₂² = 0. The value of the objective function is f(x*, y*) = 18.

Interpreting the shadow prices shows that if there are more resources for Constraint 2, our objective function will decrease. If we add Δ to the right-hand side of Constraint 2, the objective function value will decrease by approximately 6Δ. If we changed the right-hand side of the constraint from 19 to 20, the optimal solution becomes x* = 11.5, y* = 8.5, and f(x*, y*) = 12.5 or a decrease of 5.5 units (verification is left as an exercise).
```
