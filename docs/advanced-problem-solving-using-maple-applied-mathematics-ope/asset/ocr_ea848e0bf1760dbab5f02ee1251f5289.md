STEP 4. Write the system in matrix notation $A\mathbf{x}=\mathbf{b}$ where $A$ is the coefficient matrix and $\mathbf{b}$ is the column vector of zeros. Then form the augmented matrix for the system.

$$[A\mid \mathbf{b}]=\begin{bmatrix}6&0&-1&\mid&0\\0&2&-2&\mid&0\end{bmatrix}$$

STEP 5. Apply Gaussian elimination (row reduction) to the augmented matrix $[A\mid \mathbf{b}]$ to obtain $[H\mid \mathbf{c}]$, where $H$ is in reduced row echelon form.

$$[H\mid \mathbf{c}]=\begin{bmatrix}1&0&-1/6&\mid&0\\0&1&-1&\mid&0\end{bmatrix}$$

Read the system’s solution: $x_1-x_3/6=0$ and $x_2-x_3=0$.

Balancing the chemical equation means finding the *smallest whole numbers* $x_1$, $x_2$, and $x_3$ solving the system. Since there are more equations than unknowns, there is an infinite number of solutions. Note that $x_3$ is part of every equation, so $x_3$ can equal anything. The fraction $1/6$ is a coefficient of $x_3$ in one of the equations, so choose $x_3$ to be the smallest whole number that eliminates the fraction; i.e., choose $x_3=6$. Then $x_1=1$ and $x_2=6$.

The balanced reaction equation is

$$\mathrm{S}_6+6\,\mathrm{O}_2\longrightarrow 6\,\mathrm{SO}_2.$$

# Example 5.8. Ethylenediamine Mixed with Dinitrogen Tetroxide.

Balance the reaction

$$\mathrm{C}_2\mathrm{H}_8\mathrm{N}_2+\mathrm{N}_2\mathrm{O}_4\longrightarrow \mathrm{N}_2+\mathrm{CO}_2+\mathrm{H}_2\mathrm{O}$$

STEP 1. Introduce five multipliers $x_1$ through $x_5$, one for each of the 5 terms.

$$x_1\,\mathrm{C}_2\mathrm{H}_8\mathrm{N}_2+x_2\,\mathrm{N}_2\mathrm{O}_4\longrightarrow x_3\,\mathrm{N}_2+x_4\,\mathrm{CO}_2+x_5\,\mathrm{H}_2\mathrm{O}$$

STEP 2. List the equation for each element.

$$\begin{aligned}
\mathrm{C}:&\quad 2x_1=x_4\\
\mathrm{H}:&\quad 8x_1=2x_5\\
\mathrm{N}:&\quad 2x_1+2x_2=2x_3\\
\mathrm{O}:&\quad 4x_2=2x_4+x_5
\end{aligned}$$

STEP 3. Write the augmented matrix for the homogeneous system.

$$[A\mid \mathbf{b}]=\begin{bmatrix}2&0&0&-1&0&\mid&0\\8&0&0&0&-2&\mid&0\\2&2&-2&0&0&\mid&0\\0&4&0&-2&-1&\mid&0\end{bmatrix}$$
