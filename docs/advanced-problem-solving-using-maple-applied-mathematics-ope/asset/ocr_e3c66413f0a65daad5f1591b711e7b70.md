Therefore, the necessary conditions are

$\partial L/\partial x \Rightarrow 2(x-14)+2\lambda_1(x-11)+2\lambda_2x=0$  
$\partial L/\partial y \Rightarrow 2(y-11)+2\lambda_1(y-13)+2\lambda_2y=0$  
$\partial L/\partial \lambda_1 \Rightarrow (x-11)^2+(y-13)^2+\mu_1^2-49=0$  
$\partial L/\partial \lambda_2 \Rightarrow x+y+\mu_2^2-19=0$  
$\partial L/\partial \mu_1 \Rightarrow 2\lambda_1\mu_1=0$  
$\partial L/\partial \mu_2 \Rightarrow 2\lambda_2\mu_2=0$

Define the functions in Maple, then investigate the cases for $\lambda_i$ and $\mu_i$ being zero or nonzero. We’ll use decimals for the constants to force floating-point arithmetic to simplify the calculations. Remember to load the *Student[MultivariateCalculus]* package to make the *Gradient* function available.

```
g := (x, y) → (x − 14)^2 + (y − 11)^2:
g₁ := (x, y) → (x − 11)^2 + (y − 13)^2:
g₂ := (x, y) → x + y:
L := (x, y, λ₁, λ₂, μ₁, μ₂) → f(x, y) + λ₁ · (g₁(x, y) + μ₁² − 49.0) + λ₂ · (g₂(x, y) + μ₂² − 19.0):
grad := Gradient(L(x, y, λ₁, λ₂, μ₁, μ₂), [x, y, λ₁, λ₂, μ₁, μ₂]):
NecessaryConditions := [seq(G = 0, G in grad)]:
```

In each of the cases, we will solve for variables $\mu_i$ rather than $\mu_i$ to reduce complexity. We’ll also use *RealDomain:-solve* to avoid complex solutions. Defining the list of variables as *vars* reduces typing and simplifies the command structure making it more readable.

```
vars := [x, y, λ₁, λ₂, μ₁², μ₂²]:
```

CASE 1.  λ₁ = 0 and λ₂ = 0. Then μ₁² ≠ 0 and μ₂² ≠ 0.

```
Case1 := λ₁ = 0, λ₂ = 0:
subs(Case1, NecessaryConditions):
s1 := RealDomain:-solve(%, vars):
Matrix(subs(Case1, s1));
[2x − 28 = 0, 2y − 22 = 0, (x − 11)^2 + (y − 13)^2 + μ₁² − 49.0 = 0,
x + y + μ₂² − 19.0 = 0, μ₁ = 0, μ₂ = 0]
[x = 14, y = 11, 0 = 0, 0 = 0, μ₁² = 36, μ₂² = −6.]
```

This case is infeasible since $\mu_2^2=-6$ which indicates that Condition 2, $g_2(x,y)\leq 19$, is violated. It would have been easy to solve this necessary conditions system by hand. The first two necessary conditions give $x=14$ and $y=11$ directly, then substituting the values for $x$ and $y$ in the two constraints easily gives $\mu_1^2=36$ and $\mu_2^2=-6$. Using Maple, however, provided a template for solving all four cases.
