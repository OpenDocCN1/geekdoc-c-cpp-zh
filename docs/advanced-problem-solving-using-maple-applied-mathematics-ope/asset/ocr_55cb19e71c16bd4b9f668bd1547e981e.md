# ## 3.1 数据清洗

数据清洗是数据预处理中最关键的步骤之一，其目的是检测和修正数据集中可能存在的错误、不一致或不完整的信息。常见的数据清洗操作包括处理缺失值、去除重复记录、修正异常值以及统一数据格式等。

在实际应用中，数据清洗往往占据整个数据分析项目约60%至80%的时间，因此建立一套系统化的清洗流程对于提升数据质量和工作效率至关重要。

+   - 缺失值处理：删除、填充或插值
+   - 重复值处理：识别并合并或删除
+   - 异常值检测：基于统计方法或业务规则
+   - 格式统一：日期、文本、数值等标准化

| 清洗步骤 | 方法 | 适用场景 |
|---------|------|---------|
| 缺失值 | 均值填充 | 数值型数据 |
| 缺失值 | 众数填充 | 分类型数据 |
| 重复值 | 去重 | 记录重复 |
| 异常值 | 3σ原则 | 正态分布数据 |

> > 数据质量决定了分析结果的上限，而算法只是逼近这个上限的手段。
