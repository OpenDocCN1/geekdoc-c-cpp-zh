> > 这就是我们今天所处的境地。仅安大略省就有超过50万人接种了疫苗。到9月份，我们要赶着为该省所有1500万人接种疫苗。而主流媒体还在叫嚷着要加快速度。所有这些都意味着，官员们告诉我们有多少人因疫苗而生病或死亡真相的可能性非常渺茫。
