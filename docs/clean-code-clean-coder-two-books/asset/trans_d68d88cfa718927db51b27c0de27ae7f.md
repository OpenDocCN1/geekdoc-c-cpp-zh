## 1、AI Grok

### 基础概念

- Grok，原意是“深刻理解”。现在指马斯克旗下的xAI公司开发的大语言模型(LLM)，它通过一种注意力机制(Attention Mechanism)来生成文本，重点是理解上下文并生成相关响应。

### 核心能力

- 长上下文窗口(131,072 tokens)
- 阅读理解能力
- 参数规模314B(3140亿参数)
- 算术推理能力
- 数据更新至2025年9月

### 架构特点

- 采用Mixture-of-Experts (MoE)架构
- 仅注意力机制，无卷积层
- 使用旋转位置编码(RoPE)
- 采用RMSNorm归一化

### 应用场景

- 文本生成
- 代码生成
- 对话系统
- 自动问答

### 局限与未来

- 数学推理能力需进一步提升
- 无法直接处理图像识别任务
- 计划推出全新多模态版本
