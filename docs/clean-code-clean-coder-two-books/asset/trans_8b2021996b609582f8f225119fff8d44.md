我做了计算机搜索。无论是蒙塔尼耶、加洛，还是其他任何人都没有发表过描述实验的论文，这些实验会得出艾滋病毒可能导致艾滋病的结论。我读了他们在《科学》杂志上发表的论文，他们因此成为著名的艾滋病医生，但他们在所有论文中只说，他们发现了一些艾滋病患者过去感染过某种可能是艾滋病毒的东西的证据。
