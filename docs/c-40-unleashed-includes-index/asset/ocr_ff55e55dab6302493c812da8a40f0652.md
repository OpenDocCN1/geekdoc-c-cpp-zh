fields will recursively get zero-initialized. Primitive value types receive their default values; for example, an int will be set to 0. Consider the following example:

```
class Basis
{
    private Vector _direction1;
    private Vector _direction2;
}
```

```
class Vector
{
    private Point _start;
    private Point _end;
}
```

```
struct Point
{
    private int _x;
    private int _y;
}
```

Creation of a new Basis instance will result in both direction fields to be set to null. For each new Vector instance, we'll receive zero-initialized Points in both _start and _end. Such a zero-initialized Point will have both _x and _y set to a zero 32-bit integer.
