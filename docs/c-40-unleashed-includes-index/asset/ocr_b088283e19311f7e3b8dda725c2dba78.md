expensiveProducts query retains only a few tens of those. If products2 were to be persisted in memory as an intermediate query result, lots of storage space is wasted for no good reason.

Having to create intermediate query expressions to declare the query we've seen before seems unnecessary. And indeed, using the into clause, this can be simplified:

```
var expensiveProducts = from product in products
                            select new { Name = product.ProductName,
                                         Price = product.UnitPrice } into product
                            where product.Price > 100m
                            select product;
```
