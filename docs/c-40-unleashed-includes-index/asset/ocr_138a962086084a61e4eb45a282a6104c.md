# MORE COMPLEX GROUPING CLAUSES

The identifier specified right after the group and before the by keyword does not have to be the same as one of the range identifiers. For example, you can write things like this:

```
from product in products
group product.Price by product.Category
```

This will result in groups with a category as the key and prices inside each of the resulting groups. The translation for this form uses a different GroupBy overload that takes in an additional lambda expression for the "element selector."
