```
for (int j = 0; j < zs.GetLength(1); j++)
{
    zs[i, j] = 0.0;
    for (int k = 0; k < xs.GetLength(1); k++)
    {
        zs[i, j] += xs[i, k] * ys[k, j];
    }
});
sw.Stop();
Console.WriteLine(sw.Elapsed);
```

This typical example of the parallel for loop is used to perform a matrix multiplication where each of the rows in the resulting matrix is computed in parallel. Although we're dealing with a shared result array, there are no clashes in accessing it because each of the cells can be computed independently of each other.
