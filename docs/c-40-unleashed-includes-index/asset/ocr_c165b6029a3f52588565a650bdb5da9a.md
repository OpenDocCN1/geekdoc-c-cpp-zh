# SIMPLER TYPE DECLARATIONS

It would be nice if one day we had a language feature that allows the creation of a nominal type using lightweight syntax, as shown here:

```
class NameAndPrice(string Name, decimal Price) {}
```

Such a class with a "first-class constructor" could emit a class with two read-only properties and a constructor to initialize them. In addition, overrides for Equals, GetHashCode, and ToString would be provided.

Alternatively (or additionally), having a refactoring to create a nominal type from an anonymous type would come in handy, too.
