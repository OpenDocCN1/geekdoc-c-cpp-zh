At this point, it's no longer possible to instantiate an object of type Shape:

```
```csharp
Shape someShape = new Shape();
// The problem is gone: the above simply doesn't compile anymore.
```
```

But we can do a better job, getting rid of the bogus default implementations for Area and Circumference by declaring those properties as abstract members, again using the same abstract modifier:

```
```csharp
abstract class Shape
{
    public abstract double Area
    {
        get;
    }

    // Same for Circumference
}
```
```

At this point, we can no longer use the virtual modifier because every abstract member will be virtual per definition: It takes some subclass to override it before it's possible to use the member at all. Also, it's not allowed to have any implementation whatsoever on a virtual member, hence the use of a semicolon to indicate the absence of a code block implementing the member's behavior.
