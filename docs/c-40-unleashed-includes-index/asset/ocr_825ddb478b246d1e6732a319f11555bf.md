# STATIC CLASSES RECAP

While we're talking about static constructors, let's recap the concept of static classes. Those types are just regular classes but without the capability to create new instances; instead, they contain only static members and don't have an instance constructor available. A static constructor can be defined, though.

Static classes shine in scenarios where static helper methods have to be wrapped together. The lack of global methods in C# is easily circumvented by putting all helper methods in a static class. This also helps organize them in buckets that share certain tasks (for example, TypeHelpers or Math).
