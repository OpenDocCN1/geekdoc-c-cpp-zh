```
[Conditional("DEBUG")]
static void Bar(int i) { }

static void Main()
{
    int i = 0;
    Bar(i++);
    Console.WriteLine(i);
}
```

Bar is much like Debug.WriteLine in that it gets omitted from the compiled code if the DEBUG symbol is not defined. What do you think the code prints in Debug versus Release mode? Let me tell you: 1 versus 0. The reason is because the compiler takes away the whole call site to Bar, including evaluation of parameters (here using the post-increment operator on i) in case DEBUG is not defined. To make a long story short: Don't have side effects in calls to methods such as Debug.WriteLine!
