Modifiers allowed on interface members include abstract and virtual. The latter can be
used to allow subclasses to override the interface member's implementation.

Because multiple interfaces can be implemented by a single class or struct, it's obvious
that naming clashes can occur. For example, assume we're implementing both IBar and
IBaz, which have a member with the same name and signature:

```
```csharp
interface IBar
{
    void Foo();
}

interface IBaz
{
    void Foo();
}

class Qux : IBar, IBaz
{
    // How can we have two Foo methods here?
}
```
```

To satisfy the implementation needs, we somehow need to get out of the naming clash.
The answer lies in explicit interface implementation. Figure 14.21 shows the two options
