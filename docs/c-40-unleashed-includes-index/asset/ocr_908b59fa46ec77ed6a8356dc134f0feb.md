```
var res = from input in searchBox.TextChanged
    from suggestion in DictionaryService.Suggest(input)
        .TakeUntil(searchBox.TextChanged)
    select new { suggestion.Word, suggestion.Description };
res.Subscribe(result => { /* display in Results box */ });
```

In the preceding code, we're listening for the Suggest call to come back until the user types a new search key in the text box. At that point, the pending call is canceled out. Yes, you still have to put in the TakeUntil call manually (because the out-of-order behavior may be acceptable in some cases), but attempting to do the same with regular .NET events would be far from trivial with asynchronous operation cancellations and so on.
