Simply stated, the freed memory is returned to the free list. Obviously, adjacent free space can be merged into one block of free space to reduce fragmentation. In managed code, there's no deterministic deallocation. Instead, memory gets reclaimed when the heap runs out of space, a task carried out by the garbage collector, as shown in Figure 9.12.
