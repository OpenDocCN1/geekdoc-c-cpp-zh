Notice we're using IEnumerator<int> for the return type this time. This will simplify our analysis, but both the IEnumerable<T> and IEnumerator<T> interfaces can be used for the return type of an iterator method. On the consumer side, things look like this:

```
var countDown = CountDown();
while (countDown.MoveNext())
    Console.WriteLine(countDown.Current);
```

This loop will iterate four times, with the Current property surfacing values 3 through 0 subsequently, which will get printed to the screen. To make the iterator's execution model more explicit, let's add diagnostic output to the iterator body itself:

```
public IEnumerator<int> CountDown() {
    Console.WriteLine("Before three");
    yield return 3;

    Console.WriteLine("After three");
    Console.WriteLine("Before two");
    yield return 2;

    Console.WriteLine("After two");
    Console.WriteLine("Before one");
    yield return 1;

    Console.WriteLine("After one");
    Console.WriteLine("Before zero");
    yield return 0;
}
```

Consuming this iterator through the while loop, the following gets printed to the screen:

```
Before three
3
After three
Before two
2
After two
Before one
1
After one
Before zero
0
```
