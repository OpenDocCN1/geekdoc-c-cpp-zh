StyleCop, on the other hand, operates on the C# source file level and is currently not included with Visual Studio. It's a free download from http://code.msdn.microsoft.com/sourceanalysis. Its role is to enforce coding style guidelines to aid code readability. As usual, cop kinds of tools work best when applied right from the start of a project and when turned on in the build system from day one. Running such tools on existing large projects can be a great source of frustration in seeing how many potential issues are found.
