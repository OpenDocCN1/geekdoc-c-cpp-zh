Based on this observation, we expect List<int> to be a bit slower than int[]. However, the use of an ArrayList to store int values is expected to be quite painful due to the cost of having to box up the values when storing them in the array, as well as the inverse when retrieving a boxed value and casting it back to the value type.

In addition, we expect the excessive use of boxing behind the scenes to add pressure to the garbage collector (observe the huge managed heap cloud in Figure 15.12), so the number of garbage collections will provide an idea about the cost, too.
