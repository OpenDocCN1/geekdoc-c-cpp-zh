# Default Constructors

If no constructors are defined explicitly, a default parameterless constructor will be created for you. Because a newly allocated object will be guaranteed to have all of its fields zero-initialized, this shouldn't pose any problem.

```
class Person
{
    private string _name;
    private int _age;

    public string Name
    {
        get { return _name; }
        set { _name = value; }
    }

    public int Age
    {
        get { return _age; }
    }
}
```
