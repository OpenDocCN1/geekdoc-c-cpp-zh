We discuss the naming and versioning of assemblies in the next section. One thing to notice, though, is the difference between an assembly version (which is what the CLR cares about) and a file version (used by Windows and installers). The GUID and COM-Visible settings near the bottom are for advanced scenarios where the managed code assembly needs to be used from COM components.

Behind the scenes, those settings get persisted in a file called AssemblyInfo.cs, which can be found by expanding the Properties entry for the project in Solution Explorer, as shown in Figure 25.6. Extra information about various settings can be found in the emitted comments in this code file.
