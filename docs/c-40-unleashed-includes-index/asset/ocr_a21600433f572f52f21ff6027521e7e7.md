With the mapping in place, we now have a strongly typed way to talk to the database and formulate queries. Everything starts from a DataContext object, named after the LINQ to SQL Classes file (in our case, Northwind). From this context object, we can access the tables we exported through the designer. Let's take a look:

```
using (var ctx = new NorthwindDataContext()) {
    var cheap = from product in ctx.Products
                where product.UnitPrice < 25
                select product;

    foreach (var product in cheap)
        Console.WriteLine("{0} costs {1}", product.ProductName,
            product.UnitPrice);
}
```

We no longer have to deal with manual creation of a SQL SELECT statement and can use LINQ syntax to express a query over a totally foreign data domain using the generated objects.
