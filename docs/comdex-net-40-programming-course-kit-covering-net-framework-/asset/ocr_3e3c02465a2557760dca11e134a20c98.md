# ## Creating Themes

ASP.NET 4.0 provides you various built-in themes that you can apply on the controls and Web pages. Applying built-in themes to Web pages is easy, as you just need to specify the name of the theme using the Theme attribute of the @ Page directive. However, if the built-in themes do not suite your requirements, then you can also create and apply custom themes to Web pages.

Let’s perform the following steps to create a theme:

+   1. *Open* **Visual Studio 2010**.
+   2. *Select* **File→New Web Site** from the menu bar. The **New Web Site** dialog box opens.
+   3. *Select* **Visual C#** from the **Installed Templates** pane of the **New Web Site** dialog box.
+   4. *Select* **ASP.NET Empty Web Site** from the right pane of the **New Web Site** dialog box.
+   5. *Specify* the location and name of the application in the Web location combo box. In this case, we have specified the name as **ThemesExample**.
+   6. Click the **OK** button to create the **ThemesExample** application (also available on the CD).
+   7. *Right-click* the **ThemesExample** project in **Solution Explorer** and select **Add ASP.NET Folder→Theme** from the context menu, as shown in Fig.ASP-8.17.
