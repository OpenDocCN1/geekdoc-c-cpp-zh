Login 控件由以下标准 ASP.NET 控件组合而成：

- **用户名标签和文本框：** 显示用户名称文本框的文本。该文本框接受登录过程中用于验证用户身份的用户名。
- **密码标签和文本框：** 显示密码文本框的文本，该文本框接受用户输入的密码。密码文本框始终进行加密，以防止用户密码以明文形式显示。
- **验证控件：** 验证用户名和密码文本框。
- **记住我复选框：** 指定如果用户下次使用同一台计算机登录网站，是否应记住用户详细信息。
- **失败文本：** 如果用户登录尝试失败，显示一条消息。
- **登录按钮：** 提交用户的身份验证请求。
