Perform the following steps to create a Web application to use the **RangeValidator** control:

+   1. *Open* **Microsoft Visual Studio 2010**.
+   2. *Select* **File→New→Web Site** to create a new Web site. It opens the **New Web Site** dialog box.
+   3. *Select* **Visual C#** in the **Installed Templates** pane.
+   4. *Select* the **ASP.NET Web Site** template from the middle pane.
+   5. *Name* it as **RangeValidatorExample** (also available on the CD).
+   6. *Click* the **OK** button. It opens the **Default.aspx** Web page in the **Source** view.
+   7. *Select* the **Design** tab to view the design of the Web page.
+   8. *Drag and drop* two **Label** controls, two **TextBox** controls, and a **Button** control on the **Default.aspx** page from the **Standard** tab of the **Toolbox**.
+   9. *Right-click* the Label and Button controls, select the **Properties** option from the context menu to open the **Properties** window and set the properties, as listed in Table 4.7:

**Table 4.7: Properties Set for the Controls**

| Control Name | Property Name | Value |
|---|---|---|
| Label1 | Text | Enter your age: |
| Label2 | Text | Date of birth (MM/DD/YYYY format): |
| Button1 | Text | Submit |

+   10. *Drag and drop* two **RequiredFieldValidator** controls from the **Validation** tab on the **Default.aspx** page. *Right-click* **RequiredFieldValidator1**, select the **Properties** option from the context menu to open the **Properties** window and set the properties, as listed in Table 4.8:

**Table 4.8: Properties Set for the RequiredFieldValidator Controls**

| Control ID | Property Name | Value |
|---|---|---|
| RequiredFieldValidator1 | ControlToValidate | TextBox1 |
| RequiredFieldValidator1 | ErrorMessage | You must enter age. |
| RequiredFieldValidator2 | ControlToValidate | TextBox2 |
| RequiredFieldValidator2 | ErrorMessage | You must enter date of birth |

+   11. *Select* the **Validation** tab in the **Toolbox**. *Drag and drop* two **RangeValidator** controls on the **Default.aspx** page (Fig. ASP-4.8).
