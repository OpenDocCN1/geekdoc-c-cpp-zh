# Listing 2.7: Creating and Using Abstract Classes

```
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace AbstractClasses
{
    public abstract class Shape
    {
        public abstract void Area(int x);
    }
    public class Circle : Shape
    {
        public override void Area(int radius)
        {
            double result = 3.14 * radius * radius;
            Console.WriteLine("The area of the circle is: " + result);
        }
    }
    public class Square : Shape
    {
        public override void Area(int side)
        {
            double result = side * side;
            Console.WriteLine("The area of the square is: " + result);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            Circle c = new Circle();
            c.Area(10);
            Square s = new Square();
            s.Area(10);
            Console.ReadLine();
        }
    }
}

The first highlighted code snippet in Listing 2.7 shows the definitions of three classes: the abstract class, *Shape*, and its derived classes, *Circle* and *Square*. The *Shape* class declares an abstract method, Area(), which takes an int type of parameter. Both, the *Circle* and *Square* classes provide their own implementations of the Area() method. The *Circle* class defines the functionality to calculate and display the area of a circle in the Area() method.
