Let’s now discuss all these operators in detail, one by one.

# ### The Not Operator

The **Not** operator performs the logical negation operation of an expression that evaluates a Boolean value. It returns a value that is exactly opposite to the value of the operand on which it is applied. For example, if the expression evaluates to **True**, the result, after applying the **Not** operator, is **False** and vice-versa. The following code snippet shows the use of the Not operator:

```
```vb
Dim X, Y As Boolean
X = Not 5 > 3
Y = Not 2 > 7
```
```

After executing the preceding code snippet, the Boolean variables X and Y store the Boolean values, **False** and **True**, respectively. As you know, the expression (5>3) evaluates to True; however, when this expression is preceded by the **Not** operator, that is, Not(5>3), the expression returns **False**. Similarly, when the expression (2>7) is preceded by the **Not** operator, that is, Not(2>7), the expression returns **True**. When used as a bitwise operator, the **Not** operator reverses the bit values of a numeric expression, that is, it changes the binary digits from 0 to 1 and 1 to 0.

# ### The And Operator

The **And** operator is used to perform a logical conjunction of two Boolean expressions. If both the Boolean expressions evaluate to **True**, the final result, after applying the **And** operator, is also **True**. However, if one of the two Boolean expressions evaluates to **False**, the final result, after applying the **And** operator, is also **False**.

The following code snippet shows the use of the And operator:

```
```vb
Dim X, Y As Boolean
X = 21 > 14 And 15 > 9
Y = 12 > 26 And 24 > 8
```
```

After executing the preceding code snippet, the Boolean variables, X and Y, store the Boolean values, **True** and **False**, respectively. When used as a bitwise operator, the **And** operator performs a bitwise conjunction of identically positioned bits in two numeric expressions.

# ### The Or Operator

The **Or** operator is used to perform a logical operation between two Boolean expressions. If both Boolean expressions evaluate to **False**, then the result, after applying the **Or** operator, is also **False**. For all other cases, the result of applying the **Or** operator is **True**. The following code snippet shows the use of the Or operator:

```
```vb
Dim X, Y As Boolean
X = 10 > 18 Or 5 > 9
Y = 16 > 12 Or 15 > 27
```
```

After executing the preceding code snippet, the Boolean variables, X and Y, store the Boolean values, **False** and **True**, respectively. When used as a bitwise operator, the **Or** operator performs a bitwise disjunction of identically positioned bits in two numeric expressions.

# ### The Xor Operator

The **Xor** operator performs the logical exclusion on two Boolean expressions. If only one Boolean expression evaluates to **True**, then the final result after applying the **Xor** operator is **True**. However, if both the Boolean operators evaluate to **False**, the result of applying the Xor operator is **False**. The following code snippet shows the use of the Xor operator:

```
```vb
Dim X, Y As Boolean
X = 28 > 14 Xor 5 > 9
Y = 25 > 29 Xor 14 > 15
```
```

After executing the preceding code snippet, the Boolean variables, X and Y, store the Boolean values, **True** and **False**, respectively. When used as a bitwise operator, the **Xor** operator performs a bitwise exclusion of identically positioned bits in two numeric expressions.
