phenomenon of the switch statements, which occurs when the default statement gets executed even after executing the case statement that matches the expression. This happens because of the absence of a programming construct in the case statement to break the execution after executing the case statement. To counter the fall through of case statements, the **break** statement is used. In some of the earlier object-oriented programming languages such as C++, the **break** statement is optional. However, C# makes it mandatory to use of the **break** statements.

Note that if you have an empty **case** statement, that is, when the case statement has no statements to be executed, you can omit the **break** statement. In the absence of a **break** statement in the case statement, the execution falls through from an empty case statement to the next case statement. In such scenarios, you can execute a single set of statements for multiple empty case statements.

Let’s consider an example given in the following code snippet:

```
```csharp
Console.Write("Enter a letter: ");
char mychar = System.Convert.ToChar(Console.ReadLine());
char x = char.ToUpper(mychar);
switch (x)
{
    default:
        Console.WriteLine("Not a vowel");
        break;
    case 'A':
    case 'E':
    case 'I':
    case 'O':
    case 'U':
        Console.WriteLine("It is a vowel");
        break;
}
Console.ReadLine();
```
```

In the preceding code snippet, the expression of the switch statement is the value of the x variable. The value of x is compared with the case labels—A, E, I, O, and U. The case statements with the case labels A, E, I, O, and U are consecutive. Among these case statements, those with the case labels A, E, I, and O are empty. This implies that if x is equal to A, E, I, or O, then the execution falls through to the next case statement until it reaches the case statement with the case label U displaying the message It is a vowel. In case, x is not equal to A, E, I, O, or U, then the default statement is executed, which displays the message Not a vowel. Note that the default statement is written before the case statements.

# **Iteration Statements**

Iteration statements or loops are those control flow statements that allow you to execute a set of statements repeatedly, based on whether a given condition is met or not. The set of statements can execute any number of times, for example, you can execute the set of statements zero, one, two, fifty, or hundred times.

The condition used in loops is a **Boolean** expression that evaluates to **true** or **false**. It is checked either at the beginning or at the end of the loop. If the condition is **true**, then the control of execution passes to the set of statements inside the loop. This is referred to as one iteration of the loop. After the completion of one iteration, control passes to the next iteration of the loop, where the condition is checked again. The loop continues as long as the condition is **true**. In case, the condition is **false**, control passes out of the loop and executes the statement that immediately follows the loop.

The loops that are available in C# are as follows:

+   - The **while** loop
+   - The **do** loop
+   - The **for** loop
+   - The **foreach** loop
