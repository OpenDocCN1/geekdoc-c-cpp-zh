# # Using the Button Control

The Button control allows you to perform tasks, such as submit the user input or navigate to another form from the current form, by generating its Click event, which is raised when the user clicks the Button control at runtime. The Button class, which is included in the System.Windows.Forms namespace, provides the functionality for the Button control. Table 3.6 lists the noteworthy properties of the Button class:

| Table 3.6: Noteworthy Properties of the Button Class |  |
|---|---|
| **Property** | **Description** |
| AutoSize | Obtains or sets a value specifying whether the Button control is automatically resized to display all its contents |
| DialogResult | Obtains or sets the value returned to the parent form when the Button control is clicked |
| Image | Obtains or sets an image displayed on the Button control |
| TextAlign | Obtains or sets the alignment of the text on the Button control |

Table 3.7 lists the important methods of the Button class:

| Table 3.7: Noteworthy Methods of the Button Class |  |
|---|---|
| **Method** | **Description** |
| NotifyDefault | Notifies the button whether it is a default button so that it can adjust its appearance accordingly |
| PerformClick | Generates a Click event for the button, similar to a click performed by the user |

Perform the following steps to use the Button control in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic→Windows Forms** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
+   5. Enter the name of the application as **ButtonControl** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. Click the **OK** button to close the **New Project** dialog box. The ButtonControl application is created (Fig.VB-3.11).
+   7. *Drag and drop* three **Label** controls, three **TextBox** controls, and a **Button** control from the Toolbox on the form.
+   8. *Set* the **Text** properties of the first, second, and third Label controls to **User Name**, **Password**, and **Address**, respectively, by using the **Properties** window.
+   9. *Set* the **PasswordChar** property of the second **TextBox** control to `*` and the **Multiline** property of the third **TextBox** control to **True** by using the **Properties** window.
+   10. *Set* the **Text** property of the **Button** control to **Submit** by using the **Properties** window. The text appears on the Button control, as shown in Fig.VB-3.11.
