# Using the GroupBox Control

A GroupBox control can be used to group all the controls related to a specific task. You can specify a category for the controls placed inside a GroupBox control by setting the Text property of the GroupBox control. The multiple GroupBox controls can be used on a form to group controls related to different or same category. When you use the GroupBox controls to group radio buttons present on a form, each set of radio buttons function independently, which implies that you can select one radio button in each set. The GroupBox class, which is included in the System.Windows.Forms namespace, provides the functionality for the GroupBox control. Table 3.15 lists the important properties of the GroupBox class.

| Property | Description |
|---|---|
| **AutoSize** | Obtains or sets a value specifying whether the GroupBox control is automatically resized to display all its contents |
| **DisplayRectangle** | Obtains a rectangle to represent the dimensions of the GroupBox control |
