# Listing 2.9: Creating and Using Interfaces

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace Interfaces
{
    interface BaseInterface
    {
        void Add(int x, int y);
    }
    interface DerivedInterface : BaseInterface
    {
        void Multiply(int a, int b);
    }
    class MyClass : DerivedInterface
    {
        public void Add(int num1, int num2)
        {
            Console.WriteLine("Sum = " + (num1 + num2));
        }
        public void Multiply(int num1, int num2)
        {
            Console.WriteLine("Product = " + (num1 * num2));
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            MyClass obj = new MyClass();
            obj.Add(200, 100);
            obj.Multiply(50, 30);
            Console.ReadLine();
        }
    }
}
```

The first highlighted code snippet in Listing 2.9 shows the definitions of two interfaces, **BaseInterface** and **DerivedInterface**, and a class, **MyClass**. The **BaseInterface** interface is the base interface that contains declaration of a method, **Add()**. The **DerivedInterface** interface is derived from the **BaseInterface** interface and contains declaration of a method, **Multiply()**. The **MyClass** class implements the **DerivedInterface** interface. As the **DerivedInterface** interface inherits the **BaseInterface** interface; therefore, the **BaseInterface** interface is automatically implemented by the **MyClass** class. Therefore, the **MyClass** class provides implementation for both the **Add()** method of the **BaseInterface** interface and the **Multiply()** method of the **DerivedInterface** interface. In the second highlighted code snippet, we have first created an object, **obj**, of the **MyClass** class and then called the **Add()** and **Multiply()** methods, by using **obj**.
