Now, you learn how to use the `LoginStatus` control in a Web site by performing the following steps:

+   1. Click **Start→All Programs→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010**.
+   2. Select **File→New→Web Site** from the menu bar.  
+      The **New Web Site** dialog box appears.
+   3. Select **Visual C#** from the **Installed Templates** pane and then select the **ASP.NET Empty Web Site** template in the middle pane.  
+      Set the name of the Web site as **LoginStatusControl**.
+   4. Click the **OK** button.  
+      The **LoginStatusControl** application is created.
+   5. Open the **Solution Explorer** window and *right-click* the application name. In this case, we are right-clicking the **LoginStatusControl** application.
+   6. Add a Web form (**Default.aspx**) to the **LoginStatusControl** application.  
+      Similarly, add another Web form (**Default2.aspx**) to the **LoginStatusControl** application.
+   7. *Drag and drop* a **Login** control on the form and create a user account. Also, set the **DestinationPageUrl** property of the Login control to **Default2.aspx**.
+   8. *Drag and drop* a **Label** control and set its **Text** property as **WELCOME!**. Also, add the **LoginName** control from the Toolbox (Fig. ASP-5.29).
+   9. *Drag and drop* a **LoginView** control from the Toolbox on the **Default2.aspx** Web form and click the smart tag to open the **LoginStatus Tasks** menu (Fig. ASP-5.29).
+   10. Select the **Logged In** option from the **Views** drop-down list, as shown in Fig. ASP-5.29.
+   11. *Right-click* the **Login** control and select the **properties** option from the context menu to open the Properties window.
