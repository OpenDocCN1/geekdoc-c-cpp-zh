Imagine a situation where some engineers are given specialized tools and are told to make a luxurious car. Do you think that they will be able to make it without any proper model or design? Definitely the answer will be no. Similar to any other industry, software development also follows a model and prepares a proper design before developing an application. There are mainly two types of programming model followed in software development—Procedure-Oriented Programming (POP) and Object-Oriented Programming (OOP).

POP follows the concept of breaking a problem into smaller tasks, solving each task separately, and later combining all the tasks to solve the entire problem. Each small task to be solved is written within a block of code, called a method. You can call one method from another, implying these methods are dependent on each other and it becomes difficult to separate one method from another. Therefore, reusability of the application becomes difficult. Examples of languages that follow POP concepts are COBOL, FORTRAN, and C.

The concept of OOP has been introduced to overcome the difficulty of limited or no reusability of code. OOP uses the concept of object to reuse the existing code. An object in a programming language does not mean a tangible or visible entity; rather it is an organization of code. It may contain certain behaviors and properties. In programming languages, behaviors of an object are represented as methods and the properties of the object are represented as attributes. Examples of languages that follow OOP concepts are C++, JAVA, C#, and Visual Basic.

# ## Exploring Basic Principles of Object-Oriented Programming

The OOP language works similar to POP languages, such as C. In addition, OOP supports some important concepts and terminology, such as object and class, which make it popular among programming methodology. You know that the concept of OOP revolves entirely around objects. An object is an instance of a class; whereas, a class acts as a blueprint or template to create instances or objects. This blueprint or template describes the state and behavior for all the objects of the class.

OOP supports reusability; therefore, you can reuse some methods of an existing application to make a new application. In OOP, you can make changes to some modules, if required, without having to code the entire application from scratch.

OOP is based on the following four basic principles:

+   - Encapsulation
+   - Abstraction
+   - Inheritance
+   - Polymorphism

Let's now discuss each of these principles, one by one.

# ### Encapsulation

Encapsulation is the process of showing only the relevant information of a specific object and hiding the irrelevant information from a user. It binds the variables and the functions together into a single unit, called class. To understand the concept of encapsulation, let's take an example. When a customer goes to purchase a refrigerator, the customer generally looks for its color, functionalities, and the storage capacity; whereas, its internal working and wiring system are hidden from the customer. The company does not want the customer to tamper with the wiring system; and therefore, keeps the details of internal wiring system hidden from the customer. This process of hiding internal facts is known as encapsulation.
