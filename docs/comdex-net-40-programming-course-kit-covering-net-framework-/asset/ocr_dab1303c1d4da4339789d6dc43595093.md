# ## Assignment Operators

An assignment operator is an operator that stores the result of an operation in a variable on the left-side of the operator. Table 1.4 lists the different assignment operators available in Visual Basic 2010:

| Operator | Description |
|---|---|
| `=` (Assignment) | Assigns a value to a variable or property |
| `^=` (Exponentiation followed by assignment) | Multiplies the first operand to itself by N number of times, where N is the second operand, and assigns the result to the first operand |
| `*=` (Multiplication assignment) | Assigns the result of the product of the first and second operands to the first operand itself |
| `/=` (Division assignment) | Assigns the result of the division of the first operand by the second operand to the first operand itself |
| `\=` (Integer division assignment) | Assigns the integer result of the division of the first operand by the second operand to the first operand itself |
| `+=` (Addition assignment) | Assigns the result of the sum of the first and second operands to the first operand itself |
| `-=` (Subtraction assignment) | Assigns the result of the difference of the first and second operands to the first operand itself |
| `<<=` (Left-shift assignment) | Shifts the binary code of the first operand to left by N number of times, where N is the second operand, and assigns the result to the first operand |
| `>>=` (Right-shift assignment) | Shifts the binary code of the first operand to the right by N number of times, where N is the second operand, and assigns the result to the first operand |
| `&=` | Concatenates one string with another and assigns the result to the first string |

# ## Comparison Operators

Comparison operators are used to compare two expressions. You can use these operators to compare numeric values, strings, and objects. A comparison operation returns a Boolean value, either True or False, as the result. Table 1.5 lists the different comparison operators available in Visual Basic 2010:

| Operator | Description | Example |
|---|---|---|
| `=` (Equal to) | Checks if the value of the first expression is equal to the value of the second expression | `24=42 False`<br>`24=24 True`<br>`42=28 False` |
| `<>` (Not equal to) | Checks if the value of the first expression is not equal to the value of the second expression | `24<>42 True`<br>`24<>24 False`<br>`42<>28 True` |
| `<` (Less than) | Checks if the value of the first expression is less than the value of the second expression | `24<42 True`<br>`24<24 False`<br>`42<28 False` |
