Let’s learn how to use the ListView and DataPager control in a Web application by performing the following steps:

+   1. *Click* **Start→All Programs→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010.**
+   2. *Select* **File→New→Web Site** from the menu bar.  
+      The New Web Site dialog box appears.
+   3. *Select* **Visual C#→ASP.NET Web Site** from the middle templates pane.
+   4. *Set* the name of the Web application as **ListviewandDatapagerControl.**
+   5. *Click* the **OK** button.  
+      The **ListviewandDatapagerControl** application is created.
+   6. *Drag and drop* the ListView control on the **Default.aspx** page and create the connection with the database as done earlier.
+   7. *Click* the smart tag and select the Configure ListView option from the ListView Tasks menu.  
+      The Configure ListView dialog box appears (Fig.ASP-6.39).
+   8. *Select* the **Bulleted List** option from the **Select a Layout** pane and the **Colorful** option form the **Select a Style** pane (Fig.ASP-6.39).
+   9. *Click* the **OK** button, as shown in Fig.ASP-6.39:

![](bbox=[0.334, 0.392, 0.689, 0.579])

+   10. *Drag and drop* the **DataPager** control on the **Default.aspx** page.
+   11. *Open* the DataPager Tasks menu and set the pager style as **Numeric Pager**.
+   12. *Open* the **Properties** window of the **DataPager** control and set the **PageControlID** property as **ListView1**, as shown in Fig.ASP-6.40:
