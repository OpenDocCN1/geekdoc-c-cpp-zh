# Creating Input Boxes

An input box is a user interface similar to a message box. However, unlike a message box, an input box accepts the input from the user. An input box can be created with the help of the InputBox function, which can be accessed through the Microsoft.VisualBasic namespace. The syntax of the InputBox function is as follows:

```
Public Function InputBox(Prompt As String, [Title As String=""], _
[DefaultResponse As String=""], [Xpos As Integer=-1], [Ypos As Integer=-1]) As String
```

The parameters in the preceding syntax are as follows:

+   - **Prompt:** Represents a string expression that is displayed as a message in the input box. The maximum length of the string expression is 1024 characters.
+   - **Title:** Represents a string expression that is displayed in the title bar of the input box. If the title is not specified, then the application name is placed in the title bar.
+   - **DefaultResponse:** Represents a string expression that is displayed in the text box of the input box as the default response, if input is not provided. Note that if you omit DefaultResponse, the displayed text box is empty.
+   - **XPos:** Represents the distance in pixels of the left edge of the input box from the left side of the computer screen.
+   - **YPos:** Represents the distance in pixels from the upper edge of the input box to the top of the computer screen.

Perform the following steps to create an input box:

+   1. *Start* Visual Studio 2010.
+   2. *Select* File→New→Project from the menu bar. The New Project dialog box opens.
+   3. *Select* Visual Basic→Windows from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. *Select* **Windows Forms Application** in the middle pane to create a Windows Forms application.
+   5. *Enter* the name of the application as INPUTBOX (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the New Project dialog box. The INPUTBOX application is created, (Fig.VB-2.60).
+   7. *Drag* a **Button** control and a **TextBox** control on the form from the **Toolbox** and set the **Text** property of the Button control to **Show Input Box** by using the **Properties** window, (Fig.VB-2.61).
