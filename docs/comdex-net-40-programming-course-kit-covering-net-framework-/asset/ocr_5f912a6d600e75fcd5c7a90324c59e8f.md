# ## Using the StylesheetTheme Attribute

The **StylesheetTheme** attribute is an attribute of the **@ Page** directive that you can use to apply themes to a Web page. You can use this attribute with those pages in which you want to apply a common style. The **StylesheetTheme** attribute is similar to the **Theme** attribute as both are used to apply themes to a Web page. However, the difference is that the **StylesheetTheme** attribute does not override the local controls attributes or properties while the **Theme** attribute overrides the local controls attributes. You can use both **Theme** and **StylesheetTheme** attributes in a Web page. When you use both these attributes in a Web page, then they are applied in the following order:

+   1. First, the **StylesheetTheme** attribute is applied to a Web page.
+   2. Next, controls properties are applied, which implies that controls properties override the **StylesheetTheme** attribute.
+   3. Finally, the **Theme** attribute is applied, which overrides both the control properties and **StylesheetTheme** attribute. This means that the Theme attribute has higher precedence over the **StylesheetTheme** attribute and control properties.

Let’s perform the following steps to use the **StylesheetTheme** attribute in an application:

+   1. _Open_ **Visual Studio 2010**.
+   2. _Select_ **File→New→Web Site** from the menu bar. The **New Web Site** dialog box opens.
+   3. _Select_ **Visual C#** from the **Installed Templates** pane of the **New Web Site** dialog box.
+   4. _Select_ **ASP.NET Empty Web Site** from the right pane of the **New Web Site** dialog box.
+   5. _Specify_ the location and name of the application in the Web location combo box. In this case, we have specified the name as **StyleSheetThemeAttribute**.
+   6. _Click_ the **OK** button to create the **StyleSheetThemeAttribute** application (also available on the CD).
+   7. _Right-click_ the **StyleSheetThemeAttribute** project in **Solution Explorer** and select **Add ASP.NET Folder→Theme** from the context menu to add the Theme1 folder under the App_Themes folder in your project.
+   8. _Right-click_ the **Theme1** folder and select the **Add New Item** option from the context menu to add a skin file into the Theme1 folder. The **Add New Item** dialog box appears.
+   9. _Select_ **Skin File** from the middle pane of the **Add New Item** dialog box.
+   10. _Click_ the **Add** button to add the **SkinFile.skin** in the Solution Explorer window.
