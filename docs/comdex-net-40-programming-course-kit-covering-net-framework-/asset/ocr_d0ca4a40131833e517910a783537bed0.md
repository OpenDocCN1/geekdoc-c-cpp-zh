# ## The EntityDataSource Control

The EntityDataSource control helps you to connect with ADO.NET Entity Data Model (EDM) to perform various database operations, such as creating, inserting, removing, and updating data. When you add the EntityDataSource control to your ASP.NET page, the following code snippet appears in the Source view page:

```
```xml
<asp:EntityDataSource ID="EntityDataSource1" runat="server">
</asp:EntityDataSource>
```
