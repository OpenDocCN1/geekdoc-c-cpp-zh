The DataGrid control is an instance of the DataGrid class, which has various properties that allow you to work with the DataGrid control. Table 5.11 lists the noteworthy properties of the DataGrid class:

**Table 5.11: Noteworthy Properties of the DataGrid Class**

| Property | Description |
|---|---|
| AlternatingRowBackground | Returns or sets the back color for alternating rows in a DataGrid control |
| AutoGenerateColumns | Returns or sets a value indicating whether the columns are generated automatically in a DataGrid control |
| CanUserAddRows | Returns or sets a value indicating whether or not a user can add new rows to a DataGrid control |
| CanUserDeleteRows | Returns or sets a value indicating whether or not a user can delete rows from a DataGrid control |
| CellStyle | Returns or sets the style applied to all the cells in a DataGrid control |
| Columns | Returns a collection that contains all the columns in a DataGrid control |
| HasItems | Returns a value that indicates whether a DataGrid control contains any other controls, such as a TextBlock control or a Button control or items, such as strings within it |
| Items | Returns a collection of all the controls or items that are used to populate a DataGrid control |
| ItemTemplate | Returns or sets the DataTemplate objects used to display each item in a DataGrid control |
| SelectedCells | Returns a list of cells that are currently selected in a DataGrid control |
| SelectedIndex | Returns or assigns the index of the first item in the current selection or returns negative one (-1) if no item is selected in a DataGrid control |
| SelectedItem | Returns or assigns the first item in the current selection or returns null if no item is selected in a DataGrid control |
| SelectedValue | Returns or sets the value of the SelectedItem property in a DataGrid control |
| Template | Returns or sets a control template in a DataGrid control |
