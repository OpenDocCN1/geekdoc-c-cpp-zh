## Class Objects

The members of a class cannot be directly accessed from outside the class. To access the members of a class outside the class, you need to create an object of the class. All objects of a class have their own copies of the members of the class. For example, if you create two objects, named c1 and c2, of the class, Count, then both objects can access the variables and methods of this class separately by using their own copy of variables.

The syntax to create an object in C# is as follows:

```csharp
<class-name> <object-name> = new <class-name>();
```

In the preceding syntax, object-name represents the name of the object that you want to create and class-name represents the class for which you create an object. After creating an object of a class, you can access members of that class through the object. The syntax to access the members of a class through the class object is as follows:

```csharp
object-name.variable-name;
object-name.method-name();
```

In the preceding syntax, object-name refers to the object of the class. The dot operator (.) is used to access the members of the class; whereas, the variable-name and method-name are the names of the variable and method that you want to access.

## Constructors and Destructors

Constructors and destructors are special types of methods. A constructor is a method that is called when an object of a class is created. It is used to initialize class members whenever a new object of the class is created. The main features of a constructor are as follows:

- It has the same name as the name of the class in which it is declared
- It does not have any return type, implying it does not return any value
- It is always public
- A class can have multiple constructors
- It is not mandatory to declare a constructor; the default constructor of a class is automatically called when you create a new object of the class

A destructor is a method that is called when the object is to be finally destroyed. It is used to destroy the values assigned to the class members when the object is not required anymore. You cannot call a destructor in your application; the Common Language Runtime (CLR) invokes it automatically. CLR provides a feature, known as garbage collection, to destroy the unnecessary objects during the execution of an application. The garbage collection feature runs when the run-time environment finds it necessary or when an object is not destroyed. Similar to a constructor, a destructor also has the same name as the name of the class in which it is defined; however, the declaration of the destructor starts with a tilde (~) sign. When the compiler finds a destructor of a class at the compile time, it creates the Finalize() method corresponding to the destructor. The Finalize() method is automatically called by CLR before the garbage collection feature runs for the objects of the class.

Perform the following steps to use constructors and destructors:

- 2. *Select* File→New→Project from the menu bar. The New Project dialog box opens.
- 3. *Select* Visual C#→Windows from the Installed Templates section in the left pane of the New Project dialog box. The project templates available for developing Windows applications in Visual C# are displayed in the right pane of the New Project dialog box.

## Partial Classes

A class definition includes variables and methods, which are declared within the class body. You can also break the definition of a class into two or more classes where each class is known as a partial class and is stored in a separate source file. Each source file contains a part of the original class definition. These definitions in different source files are combined when the application is executed. You can divide a class into two or more partial classes so that you can work on each partial class separately. You can declare a partial class by using the partial keyword. This keyword indicates that all the parts of the class must be available at compile time to generate the final class.

Perform the following steps to create partial classes:
