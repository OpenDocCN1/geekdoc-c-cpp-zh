# Using the StackPanel Control

Suppose you want to place multiple controls on a WPF window (or page) such that one control appears on top of another control, forming a vertical stack of controls. In such a scenario, instead of using a **Grid** or **Canvas** control and placing the controls at exact locations, you can use a **StackPanel** control. The **StackPanel** control is a container control that allows you to position its child controls in a vertical or horizontal stack. By default, the child controls of the **StackPanel** control are stacked vertically. The vertical stack starts from the top of the **StackPanel** control and ends at its bottom. You can also stack the child controls horizontally. The horizontal stack starts from the left edge of the **StackPanel** control and ends at its right edge. The **StackPanel** control is an instance of the **StackPanel** class, which is derived from the **Panel** class. Table 5.10 lists the noteworthy properties of the **StackPanel** class:

| Property | Description |
|---|---|
| CanHorizontallyScroll | Returns or sets a value that indicates whether a StackPanel control can scroll horizontally |
| CanVerticallyScroll | Returns or sets a value that indicates whether a StackPanel control can scroll vertically |
| Orientation | Returns or sets a value that indicates whether the child controls of the StackPanel control are stacked horizontally or vertically |
