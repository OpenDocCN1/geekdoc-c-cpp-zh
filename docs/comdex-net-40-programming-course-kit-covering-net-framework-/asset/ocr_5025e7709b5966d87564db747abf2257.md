Perform the following steps to use the **Panel** control in a Windows Forms application:

+   1. Start Visual Studio 2010.
+   2. Select File→New→Project from the menu bar. The New Project dialog box opens.
+   3. Select Visual Basic→Windows from the Installed Templates section in the left pane of the New Project dialog box.
+   4. Select the Windows Forms Application template in the middle pane to create a Windows Forms application.
+   5. Enter the name of the application as PanelControl (also available on the CD) in the Name text box and an appropriate location for the application in the Location combo box.
+   6. Click the OK button to close the New Project dialog box. The PanelControl application is created (Fig.VB-3.35).
+   7. Drag and drop two Panel controls on the form from the Toolbox.
+   8. Add one Label control, two RadioButton controls, and a TextBox control to each of the Panel controls on the form from the Toolbox (Fig.VB-3.35).
+   9. Set the Text properties of the Label controls and the RadioButton controls, as shown in Fig.VB-3.35:
