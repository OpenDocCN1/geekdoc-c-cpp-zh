# Describing Operators and Operator Precedence

While developing programs in C#, you are required to perform various operations, such as addition, multiplication, comparison, and concatenation, on the data used in a program. C# 2010 provides you a number of operators to perform the different operations in the program. An operator is a symbol or word that is reserved in the programming language to perform some predefined operation. For example, * is used to multiply two values.

In C#, operators take one or more number of operands, which refer to the values, variables, or expressions. An expression refers to a combination of variables, constants, keywords, and operators that evaluates to a value of a particular data type. Every operator takes its operands, performs an operation on the operands, and returns the result of the operation. The number and the data type of operands may vary from one operator to another. Depending on the number of operands that an operator takes, operators in C# are classified as follows:

+   - **Unary operators:** Refer to the operators that take only one operand, for example, the increment operator (`++`) that increments the value of operand by one.
+   - **Binary operators:** Refer to the operators that take two operands, for example, the division operator (`/`) that divides the first operand by the second operand.
+   - **Ternary operators:** Refer to the operators that take three operands. In C#, the conditional operator (`?:`) is the only ternary operator that returns either the second operand or the third operand depending on the Boolean value of the first operand.

![](bbox=[0.215, 0.526, 0.273, 0.58])

> > Based on the context in which operators are used, certain operators can act as unary or binary operator. For example, when you prefix the + operator to a number, it acts as a unary operator indicating that the number is a positive number. However, when you use the + operator between two numbers, it acts as a binary operator, which adds the two numbers and returns the result.

A single expression can involve multiple operations, such as addition, multiplication, and division; therefore, you can have multiple operators in a single expression. While evaluating such expressions, the language compiler uses the precedence to determine which operation to perform first. Every operator in C# has a precedence level. Depending on the precedence level, the operators are evaluated. Operators with higher precedence are evaluated first, while operators with lower precedence are evaluated later.
