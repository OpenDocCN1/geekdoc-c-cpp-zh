# ## Using the RadioButton Control

The **RadioButton** control, also known as the option button, is used to select an option from a set of options. Radio buttons always work in groups, which imply that when you select one radio button from a group of radio buttons, the other radio buttons in the group are automatically deselected. A radio button can display text, image, or both. The **RadioButton** class, which is derived from the **System.Windows.Forms** namespace, provides the functionality for the **RadioButton** control. Some important properties of the **RadioButton** class are listed in Table 3.8:

**Table 3.8: Noteworthy Properties of the RadioButton Class**

| Property | Description |
|---|---|
| Appearance | Obtains or sets a value that determines the appearance of the RadioButton control |
| AutoCheck | Obtains or sets a value indicating whether the Checked value and the appearance of the control automatically change when the radio button is selected |
| AutoSize | Obtains or sets a value specifying whether the RadioButton control is automatically resized to display all its contents |
| Checked | Obtains or sets whether the RadioButton control is selected or not |
| Image | Obtains or sets an image displayed on the RadioButton control |
| TextAlign | Obtains or sets the alignment of the text on the RadioButton control |

Table 3.9 lists an important method of the **RadioButton** class:

**Table 3.9: Noteworthy Method of the RadioButton Class**

| Method | Description |
|---|---|
| PerformClick | Generates the Click event for the radio button, similar to a click performed by a user on the RadioButton control |

Perform the following steps to use the **RadioButton** control in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **RadioButtonControl** in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **RadioButtonControl** application is created (Fig.VB-3.14).
+   7. *Drag and drop* a **Label** control, four **RadioButton** controls, and a **TextBox** control from the **Toolbox** on the Form1 form.
