# Variables

A variable is an identifier that denotes a storage area in the memory. For example, you can use a variable to store values, such as 3, 5.2, or Hello World. Every variable has a type, which determines the values that can be stored in it. A variable can store different values during the execution of a program. It has a data type and can store only those values that fall in the range of values supported by its data type. A variable name should be meaningful, easy to understand, and should convey the value stored in the variable. A meaningful variable name helps to make the code more readable. Some examples of meaningful variable names are salary, height, name, age, and total_marks.

You should remember the following points while assigning a name to a variable in Visual Basic 2010:

+   - A variable name can only contain alphabets, digits, and underscores
+   - A variable name should not begin with a digit or numeric value
+   - A variable name cannot contain a blank space
+   - Keywords cannot be used as variable names

In Visual Basic 2010, a variable can be declared at the class, module, procedure, or block level by using the **Dim** statement, as shown in the following code snippet:

```
```vb
Dim Name As String
Dim RollNo As Integer
Dim Grade As Char
```
```

A variable can be assigned a value at the time of its declaration by using the = sign, as shown in the following code snippet:

```
```vb
Dim Name As String = "James"
Dim RollNo As Integer = 1
Dim Grade As Char = "A"
```
