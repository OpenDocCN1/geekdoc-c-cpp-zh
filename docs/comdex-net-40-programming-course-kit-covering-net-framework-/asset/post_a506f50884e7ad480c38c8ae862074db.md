In C#, there are two selection statements, which are as follows:

- The if statement
- The switch statement

Let’s discuss the use of these statements, one by one.

## Using the if Statement

Consider a situation where you want to execute a given set of statements based on a condition, whether a number is even or odd. In this situation, you can use the if statement to programmatically decide which of the given sets of statements is to be executed. The if statement allows you to select a set of statements from two given sets of statements based on the value of a Boolean expression, which evaluates to true or false. When the if statement is executed, the expression is evaluated. If the expression evaluates to true, then one of the given set of statements is executed and if the expression evaluates to false then the other set of statements is executed.

The syntax of the if statement is as follows:

```csharp
if(expression)
{
    //statements1
}
else
{
    //statements2
}
```

In the preceding syntax,

- **if:** Refers to the if keyword that indicates an if statement.
- **expression:** Refers to the Boolean expression that acts as a condition for the if statement.
- **{}:** Refers to a pair of curly braces, which is required when you want to execute a block of statements in the if statement. A block of statements refers to a group of multiple statements that is treated as a single statement.
- **statement1:** Refers to the set of statements that is executed when an expression evaluates to true. The set of statements can be a single statement or a block of statements.
- **else:** Refers to the else keyword that indicates the else clause of the if statement. The else clause of the if statement is optional. There can be one else clause in the if statement.
- **statement2:** Refers to the set of statements that is executed when an expression evaluates to false. This set of statements is also optional and can be a single statement or a block of statements.

![](img/9862a98a1a2d3bb14334137965a1ec60_303_0.png)

> The square brackets ([]) are not part of the syntax; they only indicate that its content is optional. This notation in syntax is followed throughout the chapter.

The preceding syntax is the syntax of a simple if statement that involves only one if clause and one else clause. However, C# allows you to nest one if statement within another if statement. You can nest multiple if statements in the if or else clause of the if statement. Note that in such cases, the else clause corresponds to the last or the most recent if statement. This is because the compiler associates the else clause with the last unmatched if statement (if statement without an else clause).

The syntax of nested if statements is as follows:

```csharp
if(expression1)
{
    if(expression2)
    {
        //statements1
    }
    else
    {
        //statements2
    }
}
else
{
    if(expression3)
    {
        //statements3
    }
    else
    {
        //statements4
    }
}
```

In the preceding syntax,

- **if**: Refers to the if keyword that indicates an if statement
- **else**: Refers to the else keyword that indicates the else clause of the if statement
- **expression1, expression2, expression3**: Refer to the Boolean expressions of the if statements
- **statements1, statements2, statements3, statements4**: Refer to the sets of statements

### Listing 1.4: Showing the code to Demonstrate the Use of the if Statement

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace IfStatement
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.Write("Enter a number: ");
            int Num = Convert.ToInt32(Console.ReadLine());
            if (Num % 2 == 0)
                Console.WriteLine(Num + " is an even number!");
            else
                Console.WriteLine(Num + " is an odd number?");
            Console.ReadLine();
        }
    }
}
```

In the highlighted lines of Listing 1.4, we first prompt a user to enter a number. Then, we store the entered number in the **int** type variable, **Num**. Next, we check whether or not the remainder of dividing the **Num** variable by 2 is 0, by using the **if** statement. Then, we display a message indicating that the entered number is an even number. This message is displayed only if the condition tested in the if statement is true. Finally, we display another message, corresponding to the else clause, indicating that the entered number is an odd number. This message is displayed only if the condition tested in the if statement is false.

### Listing 1.5: Showing the Code to Demonstrate the Use of Nested if Statements

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace NestedIfStatements {
    class Program {
        static void Main(string[] args) {
            Console.Write("Enter a vowel:");
            char myChar = Convert.ToChar(Console.ReadLine());
            char x = Char.ToUpper(myChar);
            if (x == 'A')     //First if statement
                Console.WriteLine("The entered vowel is: A");
            else if (x == 'E') //Second if statement
                Console.WriteLine("The entered vowel is: E");
            else if (x == 'I') //Third if statement
                Console.WriteLine("The entered vowel is: I");
            else if (x == 'O') //Fourth if statement
                Console.WriteLine("The entered vowel is: O");
            else if (x == 'U') //Fifth if statement
                Console.WriteLine("The entered vowel is: U");
            else
                Console.WriteLine("The entered character is not a vowel!");
            Console.ReadLine();
        }
    }
}
```

In the highlighted lines of Listing 1.5, we first prompt a user to enter a vowel. Then, we store the entered character in the char type variable, myChar. Next, we convert the entered character into its uppercase version and store the uppercase version in another char type variable, x. After this, we use a series of nested if statements to check which of the vowels in the English alphabet was entered by the user, and display a message specifying the entered vowel on the console. In the else clause of the last if statement, we display a message indicating that the entered character is not a vowel. This message is displayed only if none of the conditions in the if statements evaluate to true.
