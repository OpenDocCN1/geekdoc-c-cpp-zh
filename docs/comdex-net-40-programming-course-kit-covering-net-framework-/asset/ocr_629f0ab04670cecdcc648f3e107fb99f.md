# Listing 1.2: Creating a Single-Dimensional Array

```
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace SingleDimensionalArrays
{
    class Program
    {
        static void Main(string[] args)
        {
            int[] Marks = new int[3];
            int TotalMarks = 0;
            Console.Write("Enter the marks in subject A: ");
            Marks[0] = Convert.ToInt32(Console.ReadLine());
            Console.Write("Enter the marks in subject B: ");
            Marks[1] = Convert.ToInt32(Console.ReadLine());
            Console.Write("Enter the marks in subject C: ");
            Marks[2] = Convert.ToInt32(Console.ReadLine());
            TotalMarks = Marks[0] + Marks[1] + Marks[2];
            Console.Write("Total marks: " + TotalMarks);
            Console.ReadLine();
        }
    }
}
```
```

In the highlighted lines of Listing 1.2, we first create a single-dimensional array, named **Marks**, of the int data type that can store three elements. Next, we declare an int type variable, **TotalMarks**, and initialize it with the value 0. After this, we prompt a user to enter the marks in three different subjects, one by one, and store the entered marks into the three array elements. Next, we add the values stored in the three array elements and assign the resultant value to the **TotalMarks** variable. Finally, we display the value stored in the **TotalMarks** variable on the console.
