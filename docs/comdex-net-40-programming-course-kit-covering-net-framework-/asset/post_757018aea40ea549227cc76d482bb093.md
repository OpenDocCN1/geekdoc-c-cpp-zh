## Abstraction

Abstraction is the process of providing essential features of an object to a user and hiding its background details. It also signifies the development of classes, objects, and types in terms of their functionality, instead of their implementation details. To understand the concept of abstraction more clearly, let’s take an example. If you develop a module of software to track payroll information, you would probably want to create an Employee object. An employee can have different information, such as name, age, qualification, hobbies, rank, serial number, address, marital status, and bank account. However, in terms of the payroll application, the relevant information of an employee is a name, age, serial number, qualification, and address, while the other information is not relevant to the application. Determining only the required information among a variety of information is known as abstraction.

## Inheritance

Inheritance is a principle of OOP, which allows you to reuse the existing code. In other words, it is a mechanism to design or construct one class from another. Inheritance is a concept involving a base class and some derived classes where all the derived classes inherit some or all the features of the base class and also contain their unique features. Suppose, Animal is a base class in which you are defining common features for all the animals. After that, you create some derived classes, named Cat, Dog, and Cow from the base class, Animal. All these derived classes share some common features, which they are inheriting from the base class, Animal. In this way, you do not need to define all the features of Cat, Dog, and Cow in their respective classes. Instead you inherit the common features from the base class, Animal and define only those features, which are unique for each of them.

## Polymorphism

**Polymorphism means one name, multiple forms.** Using the feature of polymorphism, you can use one method in many ways based on your requirements. For example, you can write a method to calculate the area of a geometrical figure and use the same method to calculate the area of a circle, triangle, or rectangle using different values and type of parameters. Polymorphism can be implemented in two ways: method overloading and method overriding. In method overloading, you use the same name for more than one method. These methods differ from each other in number and type of parameters used. In method overriding, you make a method as virtual in the base class and redefine the same method in the derived classes. The method name, the number of parameters, and the types of parameters remain same for the method defined in both the base and derived classes.

## Working with Classes and Objects

A class is a primary building block for the programs created in a programming language that follows the OOP approach, such as Visual Basic and C#. You can use classes to encapsulate variables and methods into a single unit. Let’s consider an example to understand the concept of class better. Suppose you need to create an object of a class, named Bird, in your program. To do so, you first need to create a class called Bird, which contains all the functionalities or behaviors and properties of any bird. You can then use the Bird class to create its objects.

Classes allow you to define a self-contained environment, where you control all the functions that can be applied to a given set of data such as accessing or manipulating the data. The declaration of a class starts with the class keyword followed by the class name. A class is similar to a container that may have data members, such as variables, constants, fields, methods, properties, events, indexers, operators, constructors, and destructors. To access the member variables and member functions of a class, you need to create an object of that class. The syntax to create an object of a class in C# is as follows:

```csharp
<ClassName> <objectName> = new <ClassName>();
```

These are some important concepts that help you while working with classes and objects:

- Access modifiers
- Classes and class members
- Class objects
- Constructors and destructors
- Partial classes
- Static classes
- Extension methods

### Access Modifiers

Access modifiers are very important in OOP as they support one of the main principles of OOP—encapsulation. The concepts of access modifiers and encapsulation are complementary to each other. You know that encapsulation is a technique of hiding internal details of a class to prevent the data to be accessed from outside the class. For this purpose, encapsulation uses the access modifiers. The access modifiers protect an object from unauthorized access by defining a certain scope, such as private, public, and protected for the members (such as variables and methods) of the class. If the scope for a member of a class is defined as private, you cannot access the class member from outside that particular class. However, if the scope is defined as public, the class member can be accessed from outside the class. All access modifiers are keywords; therefore, you cannot use the access modifiers as a variable name. Table 2.1 lists these access modifiers available in C# 2010:

**Table 2.1: List of Access Modifiers in C# 2010**

| Modifier Name | Scope for Accessibility |
|---|---|
| public | Gives unrestricted access to a member of a class from both inside and outside the class |
| protected | Restricts access to a member of a class to its class and all the classes derived from its class |
| internal | Restricts access to a member of a class to the assembly in which its class is defined |
| protected internal | Restricts access to a member of a class to its class, all the classes derived from its class, and all the classes of the assembly in which its class is defined |
| private | Restricts access to a member of a class to its class only |

The following code snippet shows the use of access modifiers:

```
class Class1
{
    int a; // private by default
    private float b;
    public int c;
    protected float d;
    internal double e;
}
```

### Classes and Class Members

A class acts as a template to create objects of a new data type. After defining a class, you can create any number of objects belonging to that class. A class mainly consists of variables and methods, which are collectively referred to as members of the class. The basic syntax to define a class in C# is as follows:

```csharp
[access-modifier] class <class-name>
{
    variable-declarations;
    method-declarations;
}
```

In the preceding syntax, we have placed the **access modifier** inside square brackets ([ ]), implying that the use of an access modifier is optional.

As you know the variables are used to store a value that can be changed at run time. You can declare a variable within a class and provide it an access scope to specify whether or not the other classes in the application can access the variable. The variables declared within the class are known as **member variables**. The syntax to declare member variables of a class is as follows:

```csharp
[access-modifier] class <class-name>
{
    [access-modifier] data-type variable1;
    [access-modifier] data-type variable2;
    [access-modifier] data-type variable3;
}
```

The class in the preceding syntax contains three variables, **variable1**, **variable2**, and **variable3**. You can declare any number of variables inside a class. Member variables are generally declared with the private scope so that they cannot be directly accessed from outside the class.

Similar to variables, you can also declare methods in a class. Methods are used to perform specific operations on variables. Examples of such operations include calculating the average of values stored in a set of variables, displaying the values stored in a set of variables on the screen, and calculating the area of a circle. In this way, methods provide a means to access the variables of a class from outside the class. In C#, a method may or may not return a value. The syntax to declare a method in C# is as follows:

```csharp
[access modifier] type method-name(parameter-list)
{
    method-body
}
```

In the preceding syntax, **type** represents the return type of the method and **parameter-list** represents the list of parameters that the method accepts.

The following code snippet shows a class that has two variables and a method:

```csharp
class Class1
{
    private int num1 = 24;
    private int num2 = 36;
    public void Average()
    {
        int av = (num1 + num2) / 2;
        Console.WriteLine("Average: " + av);
    }
}
```

In the preceding code snippet, we have declared a class, Class1. Inside the class, we have declared two int type variables, num1 and num2, and a method, named Average(). This method calculates and displays the average of the values stored in the variables on the screen.

Using properties, you can allow the code outside a class to retrieve and set the values of the variables of the class. In C#, you can implement the properties by using the get and set accessors.
