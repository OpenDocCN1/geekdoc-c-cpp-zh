### Listing 10.4: Code for the Service.cs File

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Runtime.Serialization;
using System.ServiceModel;
using System.ServiceModel.Web;
using System.Text;
[ServiceContract()]
public interface IMyService
{
    [OperationContract]
    string MyTask1(string MyValue);
    [OperationContract]
    string MyTask2(DataContract1 dcValue);
}
// NOTE: You can use the "Rename" command on the "Refactor" menu to change the
// class name "Service" in code, svc and config file together.
public class Service : IMyService
{
    public string MyTask1(string MyValue)
    {
        return "Hello: " + MyValue;
    }
    public string MyTask2(DataContract1 dcValue)
    {
        return "Hello: " + dcValue.FirstName;
    }
}
[DataContract]
public class DataContract1
{
    string firstName;
    string lastName;
    [DataMember]
    public string FirstName
    {
        get { return firstName; }
        set { firstName = value; }
    }
    [DataMember]
    public string LastName
    {
        get { return lastName; }
        set { lastName = value; }
    }
}
```

## Using a WCF Service

As discussed earlier, you need to create a client to be able to use a Web service. However, before creating a client, you have to generate a proxy class that helps the client application to call the WCF service. Execute the following command in **Visual Studio 2010 Command Prompt** to generate the proxy class:

```text
svcutil.exe http://localhost:6913/WCFService/Service.svc?wsdl
```

The output on executing the preceding command is shown in Fig. ASP-10.18:

![](img/9862a98a1a2d3bb14334137965a1ec60_685_0.png)

Fig. ASP-10.18
