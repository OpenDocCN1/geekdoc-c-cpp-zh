## Multidimensional Arrays

Multidimensional arrays are arrays that have more than one dimension. Two-dimensional arrays are an example of multidimensional arrays. A two-dimensional array has two dimensions—rows and columns. The rows span horizontally and the columns span vertically. In two-dimensional arrays, there are two indexes—one for each dimension.

            Console.ReadLine();
        }
    }
}

## Exploring Control Flow Statements

As you know, a program is made up of several statements, which refer to the executable instructions written by programmers. By default, statements in a program are executed in a linear or sequential order. This implies the execution starts from the first statement in the program and sequentially steps through the next statement in the program up to the last statement. In such cases, every statement in the program is executed once during the execution of the program. However, you may have situations when you want to execute a set of statements repeatedly as long as a particular condition is met, or jump from the current statement to another statement depending on some expression. In such cases, the order of execution is non-linear. You can achieve such non-linear order of execution by using various control flow statements. In C#, you can classify the control flow statements into the following three categories:

- Selection statements
- Iteration statements
- Jump statements

Let’s now discuss each of these categories of control flow statements, one by one.
