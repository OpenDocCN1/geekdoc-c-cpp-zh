
## Windows Forms

Windows Forms or Windows Forms application is a smart-client technology for .NET Framework that allows you to develop Windows-based applications. The basic entity of a Windows Forms application is a form, which is a rectangular area on which you can place various controls to design the User Interface (UI) of the application. .NET Framework allows you to develop Windows Forms applications using any .NET-compliant language, such as Visual Basic and Visual C#. A Windows form can be used to accept input from a user or display information to the user. You can add controls to a Windows form and develop responses to the user actions, such as mouse clicks or key presses.

## ASP.NET and ASP.NET AJAX

ASP.NET is a Web development model, which is used to develop interactive, data-driven Web applications over the Internet. You can use any of the .NET-compliant languages, such as Visual Basic or Visual C#, to create web applications. A number of controls are provided to you to generate the UI of the Web applications, such as TextBox, Button, and Label. If required, you can also extend the functionalities of those controls in the code-behind file of the Web application. AJAX, formerly code-named as Atlas, is an extension of ASP.NET for developing and implementing AJAX functionality. ASP.NET AJAX includes both client-side and server-side components that allow you to create Web applications that do not require complete reload of the page while making modifications to the page. It enables you to send only the modified portions of a Web page to the Web server by making asynchronous calls to the Web server. This decreases the network traffic as well as the processing required on the Web server.

## ADO.NET

ADO.NET is a technology that is used for working with data and databases of all types. It provides access to various data sources, such as Microsoft SQL Server, and the data sources exposed through OLE DB and Extensible Markup Language (XML). You can use ADO.NET to connect to data sources for retrieving, manipulating, and updating data. The most important feature of ADO.NET is disconnected data architecture. In this architecture, applications are connected to databases only while data is being retrieved or modified. Datasets, which refer to a cached set of database records, follow disconnected data architecture for accessing or modifying data. Therefore, applications do not require connecting to the database for processing each record. In addition, all database operations are performed on the dataset instead of the database.

## Windows Presentation Foundation

The WPF technology supports various media, such as text, images, audio, and video, and allows you to work with two-dimensional (2-D) as well as three-dimensional (3-D) graphics. WPF provides a separation between the UI and the business logic. WPF supports Extensible Application Markup Language (XAML), a markup language provided by Microsoft. With XAML, both designers and developers can easily and efficiently work and collaborate in the development of WPF applications.

## Windows Communication Foundation

WCF was one of the main technologies introduced in .NET Framework 3.0. It provides a unified programming model to build service-oriented applications. With WCF, you can create service-oriented applications in which a service developed in .NET is used by another application that is built on a different platform or programming language. WCF combines and extends the capabilities of distributed systems, .NET remoting, and Web services. All these features help service-oriented applications to communicate with one another.

## Windows Workflow Foundation

WF is a technology introduced by Microsoft in .NET Framework 3.0. It provides a programming model for developing workflow-based applications. Workflow is a graphical representation of the flow of a process or a set of tasks. In other words, a workflow defines the business logic on which a program is based. WF includes various components, such as activities, workflow runtime, workflow designer, and a rules engine. With WF, the business logic of an application can be defined graphically using a workflow and the actual implementation of the business logic can be written in code by using a .NET language.

## Windows CardSpace

WCS is client software provided by Microsoft that makes the process of securing resources easier. It also makes sharing of personal information on the Internet secure. In addition, WCS helps programmers develop Web sites and software that are less prone to identity-related attacks, such as phishing. WCS solves the problems of traditional online security mechanisms by reducing dependence on user names and passwords. WCS, instead, uses a separate desktop and cryptographically strong authentication to ensure secure online transactions.

## Language-Integrated Query

LINQ is a feature of .NET Framework that was introduced in .NET Framework 3.5. It adds native data querying capabilities to .NET-compliant languages, such as Visual Basic and Visual C#, using syntax that is similar to SQL. This implies that with LINQ, you can write statements similar to SQL statements in a .NET language, such as Visual Basic or Visual C#. With LINQ, you can query SQL Server databases, datasets, objects in a collection, and XML documents.

## Parallel Extensions

When a large problem is divided into small parts that are addressed simultaneously, it is known as parallel computing. In other words, many computers of today have multiple Central Processing Units (CPUs) attached so that multiple threads are executed simultaneously. .NET Framework 4.0 has introduced a new programming model for such a situation so that the developers can develop multithreaded and asynchronous code. This new programming model is known as parallel computing. To support parallel computing, new extensions, known as parallel extensions, have been added to .NET Framework 4.0. These extensions include a new runtime, class library types, and diagnostic tools. The System.Threading.Tasks namespace is included in .NET Framework 4.0 to help implementation of parallel computing.

## Managed Extensibility Framework

MEF is a new library included in .NET Framework 4.0 to create lightweight and extensible applications. In other words, MEF helps in simplifying the creation of extensible applications. The developers can now use extensions without any configuration by using MEF. It helps in reusing the extensions in more than one application. The System.ComponentModel.Composition namespace is included in .NET Framework 4.0 that provides classes, which constitute the core of MEF.

It is a runtime environment that adds services to CLR to implement dynamic languages. The purpose of DLR is to enable the dynamic languages to run on .NET Framework and provide the advantages of .NET interoperability to dynamic languages. ## Improved Security Model

A new and improved security model has been introduced in .NET Framework 4.0. This new security model includes two major changes. The first is that machine-wide security policy has been removed, although the system of assigning permissions is kept unchanged. The second change is that security transparency has been made the default enforcement mechanism. In addition to preceding changes, the permission operations that were exposed to security issues have been made obsolete. In .NET Framework 4.0, the security policy is not applied to all the applications. In addition, the desktop applications, which include both the applications on computer and on the network, are now executed as full-trust applications. Full-trust applications are the applications that are not restricted by the security policies, such as system firewalls. There are many useful classes and services introduced in CLR and .NET Framework that help developers to write secure code and implement cryptography and role-based security in .NET applications.

## Networking Improvements

The various networking improvements in .NET Framework 4.0 include the following:

- Improvement in classes for Windows authentication, such as System.Net.HttpWebRequest, System.Net.HttpListener, System.Net.Mail.SmtpClient, and System.Net.Security.NegotiateStream.
- Improvement in support for Network Address Translation (NAT) traversal using the IPv6 and Teredo protocols.
- Introduction of new networking performance counters that provide information about HttpWebRequest objects.
- Introduction of AddRange method in the System.Net.HttpWebRequest class.
- Implementation of Secure Socket Layer (SSL) support for the System.Net.Mail.SmtpClient class.
- Improvement in support for mail headers in the System.Net.Mail.MailMessage class.
- Introduction of credentials for password-based authentication schemes, such as digest, NTLM, and Kerberos authentication.

## Improved Core ASP.NET Services

In .NET Framework 4.0, some features have been introduced to improve the core ASP.NET services. These features are as follows:

- Introduction of the Page.MetaKeywords and Page.MetaDescription page properties that are used to set meta tags.
- Improved browser capabilities.
- Introduction of ASP.NET routing with Web forms.
- Introduction of the new ASP.NET Chart control.
- Introduction of the new QueryExtender control, which provides filtering support for data source controls.
- Implementation of more control over HTML code in the FormView and ListView controls.
