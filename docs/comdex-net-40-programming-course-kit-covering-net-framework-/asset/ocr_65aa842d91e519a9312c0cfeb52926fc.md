The Copy Web Site utility also checks whether or not the latest version of a file is present in the destination. If files of the most recent version are found at the destination, then the Copy Web Site utility does not superimpose the older version of the files.

Now, let’s perform the following steps to copy a Web site using the Copy Web Site utility:

+   1. *Click* **Start→All Programs→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010.**
+   2. *Select* the **File→New Web Site** option from the menu bar.
+      The **New Web Site** dialog box appears.
+   3. *Select* the **Visual C#→ASP.NET Web Site** option in the dialog box.
+   4. *Enter* the location and name of the application as **CopyWebsiteUtility** in the combo box beside the Browse button.
+   5. Click the **OK** button.
