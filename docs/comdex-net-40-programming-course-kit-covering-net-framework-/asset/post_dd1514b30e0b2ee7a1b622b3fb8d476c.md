
## Using the Static Resources

The resources that are referenced by using the StaticResource markup extension are known as the static resources. You can reference a resource as a static resource when the resource remains static throughout the runtime, that is, the value of the resource does not change once it is referred.

> When a static resource is used as a property value, the key of the static resource is searched in the available resources at the time of loading the application. If a resource with the given key is found, then the value of a static resource is assigned to the property.

Perform the following steps to use a static resource in a WPF standalone application:

- 1. Start Visual Studio 2010.
- 2. Select File→New→Project from the menu bar. The New Project dialog box opens.
- 3. Select Visual Basic→Windows from the Installed Templates section in the left pane of the New Project dialog box.
- 4. Select the WPF Application template in the middle pane to create a WPF standalone application.
- 5. Enter the name of the application as MyStaticResource (also available on the CD) in the Name text box and an appropriate location for the application in the Location combo box.
- 6. Click the OK button to close the New Project dialog box and create the MyStaticResource application.
- 7. Replace the default code in the XAML view of the MainWindow.xaml file with the code given in Listing 5.16:

### Listing 5.16: Displaying the Code for the MainWindow.xaml File

```xml
<Window x:Class="MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="MyStaticResource Application" Height="300" Width="300">
    <Grid>
        <Grid.Resources>
            <SolidColorBrush x:Key="FirstBrush" Color="DeepSkyBlue"/>
            <SolidColorBrush x:Key="SecondBrush" Color="LightCoral"/>
        </Grid.Resources>
        <Button Name="Button1" Content="Button1" Height="100" Margin="30,0,200,0"
        Background="{StaticResource FirstBrush}"/>
        <Button Name="Button2" Content="Button2" Height="100" Margin="115,0,115,0"
        Background="{StaticResource SecondBrush}"/>
        <Button Name="Button3" Content="Button3" Height="100" Margin="200,0,30,0"
        Background="{StaticResource FirstBrush}"/>
    </Grid>
</Window>
```

In Listing 5.16, the Title property of the Window element is set to MyStaticResource Application. This implies that the text MyStaticResource Application appears on the title bar of the window. The Window element has a Grid control as its child element. The Resources property of the Grid control is used to define two resources of SolidColorBrush type. A resource of SolidColorBrush type is an element that fills a given area with a solid color. The first SolidColorBrush resource has the FirstBrush key and represents the DeepSkyBlue color. The second SolidColorBrush resource has the SecondBrush key and represents the LightCoral color. These two SolidColorBrush resources are used to set the Background property of the three buttons (Button1, Button2, and Button3) in the grid. The Background property of Button1 and Button3 is set by using the first SolidColorBrush (with the FirstBrush key); whereas, the Background property of Button2 is set by using the second SolidColorBrush (with the SecondBrush key). Note that the StaticResource markup extension is used to set the Background property of the three buttons.

- 8. Press the F5 key on the keyboard to run the application. The output of the application appears, as shown in Fig.VB-5.51:

![](img/9862a98a1a2d3bb14334137965a1ec60_222_0.png)

As you can see in Fig.VB-5.51, the **Button1** and **Button3** buttons have the same background color as the **Background** property of both the buttons is set by using the **FirstBrush** static resource. However, the **Background** property of the **Button2** button is set by using the **SecondBrush** static resource; and therefore, has a different background color than the **Button1** and **Button3** buttons.

Let's now learn about the dynamic resources.

## Using the Dynamic Resources

The resources that use the **DynamicResource** markup extension are known as dynamic resources. As compared to static resources, dynamic resources provide more flexibility and are useful in situations when you want to defer the assignment of a property value until runtime or change the value of the resource at runtime through user or system settings.

![](img/9862a98a1a2d3bb14334137965a1ec60_222_1.png)

> With dynamic resources, an expression is created for the requested resource. This expression is not evaluated until runtime. When the dynamic resource is used to assign a property value at runtime, the key of the dynamic resource is searched in the available resources. If the dynamic resource with the given key is found, then the expression is evaluated and assigned as the property value.

Perform the following steps to use a dynamic resource in a WPF standalone application:

- 1. Start Visual Studio 2010.
- 2. Select File→New→Project from the menu bar. The New Project dialog box opens.
- 3. Select Visual Basic→Windows from the Installed Templates section in the left pane of the New Project dialog box.
- 4. Select the WPF Application template in the middle pane to create a WPF standalone application.
- 5. Enter the name of the application as MyDynamicResource (also available on the CD) in the Name text box and an appropriate location for the application in the Location combo box.
- 6. Click the OK button to close the New Project dialog box and create the MyDynamicResource application.
- 7. Replace the default code in the XAML view of the MainWindow.xaml file with the code given in Listing 5.17:

### Listing 5.17: Displaying the Code for the MainWindow.xaml File

```xml
<Window x:Class="MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MyDynamicResource Application" Height="300" Width="300">
    <Window.Resources>
        <SolidColorBrush x:Key="FirstBrush" Color="Lavender"/>
        <SolidColorBrush x:Key="SecondBrush" Color="PowderBlue"/>
        <SolidColorBrush x:Key="ThirdBrush" Color="Violet"/>
    </Window.Resources>
    <Grid Name="Grid1" Background="{StaticResource FirstBrush}">
        <Button Name="Button1" Height="100" Width="150" Margin="0,0,0,75"
Content="Dynamic Button" BorderBrush="Black" BorderThickness="9"
Background="{DynamicResource Grid1.Background2}"/>
        <Button Name="button2" Height="25" Margin="0,183,100,0" Width="75"
Content="Color2"/>
        <Button Name="Button3" Margin="0,211,51,5,26" Width="75" Content="Color3"
HorizontalAlignment="Right" />
    </Grid>
</Window>
```

In Listing 5.17, the **Title** property of the **Window** element is set to **MyDynamicResource Application**. This implies that the text **MyDynamicResource Application** appears on the title bar of the window. The **Resources** property of the **Window** element defines three **SolidColorBrush** resources for the **Window**. The three **SolidColorBrush** resources have three keys, **FirstBrush**, **SecondBrush**, and **ThirdBrush**, representing the colors **Lavender**, **PowderBlue**, and **Violet**, respectively. The **Window** element has a **Grid** control as its child element. The **Background** property of the **Grid** control is set by using the **FirstBrush** static resource and used as a dynamic resource to set the value of the **Background** property of **Button1**. This implies that whenever the background of **Grid1** changes, the background of **Button1** also changes. The **Content** property of the **Button1**, **Button2**, and **Button3** controls are set to **Dynamic Button**, **Color2**, and **Color3**, respectively.

- 8. Double-click the **Color2** button (or **Button2**) in the Design view of the **MainWindow.xaml** file. This adds the event handler for the Click event of the **Color2** button in the **MainWindow.xaml.vb** file.
- 9. Add the following highlighted line of code in the event handler for the Click event of the **Color2** button:

```vb
Private Sub Button2_Click(ByVal sender As System.Object, ByVal e As System.Windows.RoutedEventArgs) Handles Button2.Click
    Grid1.Background = CType(Me.FindResource("SecondBrush"), Brush)
End Sub
```

In the preceding code snippet, **Button2_Click** is the event handler for the Click event of the **Color2** button. This event handler executes when you click the **Color2** button. It applies the color specified in the static resource with the **SecondBrush** key on the background of **Grid1**.

- 10. Switch to the **MainWindow.xaml** file.
- 11. Double-click the **Color3** button (or **Button3**) in the Design view of the **MainWindow.xaml** file. This adds the event handler for the Click event of the **Color3** button in the **MainWindow.xaml.vb** file.
- 12. Add the following highlighted line of code in the event handler for the Click event of the **Color3** button:

```vb
Private Sub Button3_Click(ByVal sender As System.Object, ByVal e As System.Windows.RoutedEventArgs) Handles Button3.Click
    Grid1.Background = CType(Me.FindResource("ThirdBrush"), Brush)
End Sub
```

In the preceding code snippet, **Button3_Click** is the event handler for the Click event of the **Color3** button. This event handler executes when you click the **Color3** button. It applies the color specified in the static resource with the **ThirdBrush** key on the background of **Grid1**.

- 13. Press the **F5** key on the keyboard to run the application. The output of the application appears (Fig.VB-5.52).
- 14. Click the **Color2** button, (Fig.VB-5.52). The background color of the grid changes, which in turn changes the background color of the **Dynamic Button** button (Fig.VB-5.53).
