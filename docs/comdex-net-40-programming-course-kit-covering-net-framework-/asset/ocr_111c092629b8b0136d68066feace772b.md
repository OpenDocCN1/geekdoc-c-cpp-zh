# Creating Always-On-Top Forms

An always-on-top form is the form that stays at the top of all the other forms, when you run an application. You can create an always-on-top form by setting the **TopMost** property of the form to **True** by using the **Properties** window.

Perform the following steps to create an always-on-top form:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The New Project dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the New Project dialog box.
+   4. *Select* **Windows Forms Application** in the middle pane to create a Windows Forms application.
+   5. Enter the name of the application as **ALWAYSONTOP** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **ALWAYSONTOP** application is created, displaying only one form, Form1, (Fig.VB-2.33).
+   7. *Add* one more form, **Form2**, to the current project in the application (Fig.VB-2.34).
+   8. *Add* a **Button** control to **Form1** from the Toolbox and set its **Text** property to **Show Form2** by using the **Properties** window, (Fig.VB-2.34).
