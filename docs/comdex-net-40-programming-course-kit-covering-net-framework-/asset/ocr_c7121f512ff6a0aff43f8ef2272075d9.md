**Table 1.3: Predefined Value Types in C#**

| Value Type | Description | Range of Values | Default Value |
|---|---|---|---|
| decimal | Represents a 128-bit decimal type with 28–29 significant digits | (-7.9×10^28 to 7.9×10^28) / (10^0 to 28) | 0.0M |
| bool | Represents an 8-bit Boolean data type | true or false | false |
| char | Represents a 16-bit Unicode character | U+0000 to U+ffff | '\\0' |

In Table 1.3, **bool** is a Boolean data type that is used to check the validity of a particular condition in a program. The **sbyte, byte, short, ushort, int, uint, long, ulong,** and **char** data types are integral data types because the variables of these data types hold whole numbers, such as **123, -45,** and **601298**. The **float** and **double** data types are floating-point types as variables of these types store the value in fractions, for example, **123.56** and **-123.45**. The decimal data type is equivalent to a floating-point type but with more precision and smaller range. Therefore, the decimal data type is suitable for use when you need to perform calculations in which truncation beyond the decimal point is not required. By default, a floating-point value is treated as a value of type double. To specify a floating-point value as a float type, you need to suffix the character F (or f) to the value, such as 12.4F. Similarly, to specify a floating-point value to be of decimal type, you need to suffix the character M (or m) to the value, such as 123.45M.

Value types can be user-defined too, that is, you can define your own value type. User-defined value types can be divided into the following two categories:

+   - Enumerations
+   - Structs

Let’s discuss these two data types, one by one.

# Enumerations

An enumeration type or enumeration is represented by the **enum** keyword. It is a user-defined value type that provides a list of values called the enumerator list. Each value in the enumerator list is called an enumerator, element, or member and is used to represent an integral constant, which is a value that does not change throughout the execution of a program. By default, the constants that the enumerators represent are of **int** data type; however, they can be of any value type other than the **char** type. By default, the first constant in the enumerator list contains value 0, and value for each of the other constants is determined by incrementing the value of its preceding constant by one.

You can use enumerations when you want to create a variable and specify the possible values that it can store. Consider an example of a traffic light where you can have three possible states: the green (or go) light, the yellow (or warning) light, and the red (or stop) light. In such a case, you can create an enumeration type with three possible values: Red, Yellow, and Green, and then create variables of that enumeration type. Consider the following code snippet that shows how to create an enumeration type:

```csharp
public enum Color { Red = 1, Green, Yellow };
```

In the preceding code snippet, an enumeration type named Color is created by using the **enum** keyword. The **Color** enumeration type defines three possible values—**Red, Green,** and **Yellow**. Note that the **Red** enumerator is given a value of 1, which implies that it represents the constant 1. In addition, the **Green** and **Yellow** enumerators represent the constants 2 and 3, respectively.

To use the **Color** enumeration type, you need to create a variable of the **Color** enumeration type. The following code snippet shows how to use an enumeration type:

```
```csharp
Color TColor;
TColor=Color.Red;
```
