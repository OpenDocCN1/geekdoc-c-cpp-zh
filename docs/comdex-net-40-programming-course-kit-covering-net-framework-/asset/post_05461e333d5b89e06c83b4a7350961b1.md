A solution explorer is a window in Visual Studio 2010 IDE that allows you to view and manage all the items of a .NET application in a single solution. A solution acts as a container that contains one or more projects, all the files, references and other resources used in the application. The solution displays all the projects and files, in the solution explorer window, in a hierarchical manner.

Fig.VS-2.21 shows Solution Explorer for a Windows Forms application:

- **Show All Files button:** Displays all the files that are the part of that solution

- **View Code button:** Allows you to switch from the designer to code editor

## The Navigate To Feature

Navigating to a specific symbol or file in the source code has become easier in Visual Studio 2010 with the Navigate To feature. You can use this feature to search for a symbol, variable, word, phrase, or file in the source code of an application. To use the Navigate To feature, you need to open the Navigate To dialog box by pressing the CTRL+, keys on the keyboard. This incremental search feature is especially beneficial when you are not sure of what you are looking for in the source code. For instance, when you enter a symbol, variable, word, or phrase in the Search terms combo box of the Navigate To dialog box, the Navigate To feature immediately starts displaying the results, based on the term that you have entered.
