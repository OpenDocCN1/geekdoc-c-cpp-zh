Perform the following steps to use the CheckBox control:

+   1. *Open* Visual Studio 2010.
+   2. *Select* **File → New → Web Site** from the menu bar. The **New Web Site** dialog box opens.
+   3. *Select* Visual C# from the **New Web Site** dialog box.
+   4. *Select* ASP.NET Web Site in the right pane of the **New Web Site** dialog box.
+   5. *Specify* the location and name of the application in the Web location combo box. In this case, we have provided the name as **CheckBoxExample**.
+   6. Click the **OK** button to save all the settings. The **CheckBoxExample** application is created (also available on the CD) (Fig. ASP-2.36).
+   7. Click the **Design** tab to view the design of the **Default.aspx** page (Fig. ASP-2.36).
+   8. *Add* a CheckBox control on the Web Form from **Toolbox**, as shown in Fig. ASP-2.36:
