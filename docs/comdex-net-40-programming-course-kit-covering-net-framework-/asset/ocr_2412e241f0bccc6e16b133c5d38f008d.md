# Establishing a Connection to a Database

To work with the data in a database, you need to first establish a connection to the database. You can create a new connection by using any of the following ways:

+   - The Add Connection wizard
+   - The connection string in the code editor

Let’s first see how to establish a connection to a database by using the Add Connection wizard.

# Establishing a Connection Using the Add Connection Wizard

You can create a connection string for any data provider by using the Add Connection wizard. In our case, we are establishing a connection with the northwind database.

Perform the following steps to create a connection string for Microsoft SQL Server by using the Add Connection wizard:

+   1. Open Microsoft Visual Studio 2010.
