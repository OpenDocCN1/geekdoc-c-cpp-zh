
While handling an exception, a large amount of system resources and execution time are used. Therefore, you should avoid handling exceptions for predictable events. You can handle exceptions by using the following two statements:

- The try-catch-finally statement
- The throw statement

Let’s discuss these statements in detail.

## Using the try-catch-finally Statement

In the .NET Framework, exceptions are raised and handled at runtime. The .NET Framework provides a handler, called the **try-catch-finally** statement, to handle exceptions. When you use the try-catch-finally statement, the application is divided into different blocks of code. The code that is most likely to cause an exception is placed within the try block and the code that handles the exception is placed in the catch block. If an exception occurs, the catch block is executed and then the control is transferred to the finally block. Irrespective of the fact whether an exception occurs or not, the finally block is always executed. Multiple catch blocks are allowed for a single try block; however, there can be only one finally block for a try block.

If an exception is raised within the try statement, the control is transferred to the associated catch statement and afterwards to the finally statement, if it exists. In case the try statement does not throw any exception, the control is directly transferred to the finally statement, if it exists. A try statement without a catch or finally statement, results in a syntax error. A try statement must always be accompanied by either a catch or a finally statement. The syntax of a try-catch-finally statement is as follows:

```csharp
try
{
    // code which can cause exception
}
catch (exception-declaration)
{
    // the block of code that handles the exception
}
finally
{
    // the block of code to be executed whether the exception is raised or not
}
```

### Listing 7.7: Showing the Code for the Click Event

```csharp
private void Button1_Click(object sender, EventArgs e)
{
    int num1, num2, result;
    try
    {
        num1 = System.Convert.ToInt32(textBox1.Text);
        num2 = System.Convert.ToInt32(textBox2.Text);
        result = num1 / num2;
        MessageBox.Show(result.ToString());
    }
    catch (DivideByZeroException ex)
    {
        MessageBox.Show("Cannot divide by zero." + "This is a logical error" + ex.ToString());
    }
    finally
    {
        MessageBox.Show("finally block");
    }
}
```

In Listing 7.7, three integer variables have been declared: num1, num2, and result. The numbers entered by the user are stored in num1 and num2 and their division is stored in the result variable. Finally, the MessageBox.Show method is used to display the result in a message box. The statements that can raise exceptions are written in the try statement. If the DivideByZeroException exception is raised, then the catch statement handles it and a message box with a detailed description of the exception is displayed. In the end, the finally statement executes and displays a message box with the message finally block.

## Using the throw Statement

You can raise exceptions in an application by using the throw statement. The exception thrown can be handled within the try-catch-finally statement. The syntax of a throw statement is as follows:

```csharp
throw [expression]
```

In the preceding syntax, expression refers to the information about the exception to be thrown. A throw statement without any expression can only be used within a catch statement, wherein the throw statement re-throws the exception, currently being handled by the catch statement.

### Listing 7.8: Showing the Code to Throw an Exception Using the throw Statement

```csharp
private void button1_Click(object sender, EventArgs e)
{
    int num1 = 0;
    try
    {
        num1 = System.Convert.ToInt32(textBox1.Text);
        if (num1 >= 0 && num1 <= 10)
        {
            MessageBox.Show("You have entered : " + textBox1.Text);
        }
        else
        {
            throw new Exception("Number should be between 0 and 10");
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show("Exception occurred " + ex.ToString());
    }
}
```

In Listing 7.8, an integer variable **num1** is declared that stores the value entered in TextBox1. Using the if statement, the value entered in the **num1** variable is checked to see if it is between 0 and 10. If the condition is true, a message box appears, displaying the number entered by the user. If the condition is false, then an exception is thrown and the control is passed to the catch statement.
