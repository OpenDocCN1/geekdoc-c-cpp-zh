# ## Deploying an ASP.NET Web Site

After the successful development, testing, and debugging of a Web application the next phase involves the deployment of a Web site. As you already know, the purpose of deploying a Web application is to ensure a simple and easy installation of application files on the server. The .NET Framework provides you some easy ways of deploying a Web application on a Web server. You can deploy a Web application by using different methods, such as by copying its contents to the destination using Copy Web Site utility, by publishing it, and by using MSI installer or XCOPY command. Let’s discuss these ways of deploying a Web application.

# ### Using the Copy Web Site Utility

Copy Web Site is a utility in ASP.NET that is used to deploy a Web application by copying its content files to the destination. This option of deployment consists of the following main entities:

+   - **Project source:** Contains the solutions of all the applications' content and references created at the time of development of an application. The Copy Web Site utility retrieves all the files for deployment from this location or folder.
+   - **Project destination:** Deploys the application in the destination folder. This destination folder can be situated on remote computers or servers, which allow copying the Web application content using Front Page Server extensions, File Transfer Protocol (FTP), or Hypertext Transfer Protocol (HTTP).
