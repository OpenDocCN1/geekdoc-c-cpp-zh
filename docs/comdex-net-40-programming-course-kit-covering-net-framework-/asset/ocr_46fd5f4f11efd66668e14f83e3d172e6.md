# Value Types

Value types refer to those data types that allow you to directly work with data. When you assign a variable of value type to another variable, the value stored in the first variable is copied and assigned to the second variable. This implies that two copies of the same value exist at two different locations in the memory. In addition, changes made to the value of the second variable do not affect the value of the first variable. A value type has a fixed size, that is, a variable of value type occupies a fixed number of bytes in the memory. Note that if you do not assign any initial value to a variable of value type, then a default value is used as the initial value of the variable.

In C#, there are some predefined value types. Table 1.3 lists the predefined value types in C#:

| `short` | Represents a 16-bit signed integral data type | -32,768 to 32,767 | 0 |
| `ushort` | Represents a 16-bit unsigned integral data type | 0 to 65,535 | 0 |

| `uint` | Represents a 32-bit unsigned integral data type | 0 to 4,294,967,295 | 0 |
