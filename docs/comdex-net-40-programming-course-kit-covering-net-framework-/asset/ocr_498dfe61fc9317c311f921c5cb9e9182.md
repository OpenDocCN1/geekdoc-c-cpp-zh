# ## The AndAlso Operator

The **AndAlso** operator works in the same way as the **And** operator. This operator performs the logical conjunction of two Boolean expressions. The difference between the **AndAlso** and **And** operators is that the **AndAlso** operator displays short-circuiting behavior, which means that if the first expression using the **AndAlso** operator evaluates to **False**, the second expression is not evaluated as the value of the second expression is evaluated based on the first expression. The following code snippet shows the use of the AndAlso operator:

```
```vb
    Dim l As Integer = 17
    Dim m As Integer = 12
    Dim n As Integer = 10
    Dim check, check1, check2 As Boolean
    check = l > m AndAlso m > n
    check1 = m > l AndAlso m > n
    check2 = l > m AndAlso n > m
```
```

After executing the preceding code snippet, the Boolean variables, **check**, **check1**, and **check2**, store the Boolean values, **True**, **False**, and **False**, respectively. In the case of the **check1** variable, the value of the second expression is not evaluated, as the first expression has been evaluated to **False**. However, in the case of the **check2** variable, the second expression is evaluated.

# ## The OrElse Operator

The **OrElse** operator performs the short-circuiting logical disjunction of two Boolean expressions. This means that if the first condition in the **OrElse** expression evaluates to **True**, then the second condition is not evaluated and the **OrElse** expression returns **True**. The following code snippet shows the use of the OrElse operator:

```
```vb
    Dim l As Integer = 17
    Dim m As Integer = 12
    Dim n As Integer = 10
    Dim check, check1, check2 As Boolean
    check = l > m OrElse m > n
    check1 = m > l OrElse m > n
    check2 = m > l OrElse n > m
```
```

After executing the preceding code snippet, the Boolean variables, **check**, **check1**, and **check2**, store the Boolean values, **True**, **True**, and **False**, respectively. In the case of the **check1** variable, the second expression is not evaluated as the first expression has been evaluated to **True**. However, in the case of the **check2** variable, the second expression is evaluated.

# ### *Miscellaneous Operators*

In addition to all the operators discussed so far, some other operators are also used in Visual Basic 2010, called miscellaneous operators. There are five miscellaneous operators in Visual Basic 2010: **AddressOf**, **GetType**, **TypeOf**, **If**, and **Function** expression. These operators are explained as follows:

+   - **AddressOf**: Obtains the address of a procedure
+   - **GetType**: Retrieves information about a type
+   - **TypeOf**: Compares an object reference variable with a data type
+   - **If**: Returns one of two values, True and False, after performing short-circuit evaluation
+   - **Function expression**: Declares the parameters and code that define a lambda expression
