Perform the following steps to create an application, named **DataAdapter** (also available on the CD) to access data from a database through a data adapter:

+   1. *Open* Microsoft Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual C#→Windows** from the **Installed Templates** pane and the **Windows Forms Application** option from the middle pane in the **New Project** dialog box.
+   4. *Enter* the name of the application as **DataAdapter** in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   5. *Click* the **OK** button to close the **New Project** dialog box. The **DataAdapter** application is created.

If the **SqlDataAdapter** control is not present in the Toolbox, perform steps 6 to 8 to add the **SqlDataAdapter** control to the Data tab of the Toolbox, else move directly to Step 9.
