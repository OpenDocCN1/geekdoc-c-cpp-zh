## Using the ViewBox Control

The ViewBox control can have only one child content or control and stretches that child to fit it into its size. Now, let’s understand the use of the ViewBox control by using it in an application. Perform the following steps to create an application ViewBoxExample (also available on CD):

- 1. Open **Microsoft Visual Studio 2010** and select **File→New→Project**. The New Project dialog box appears.

- 4. Specify the name of the application as **ViewBoxExample** in the **Name** text box and the appropriate location in the **Location** combo box.
- 5. Click the **OK** button.
    The **New Silverlight Application** dialog appears.
- 6. Select the Host the Silverlight application in a new Web site check box.
- 7. Select the **ASP.NET Web Application Project** option from the New Web project type drop down box.
- 8. Select **Silverlight 4** from the **Silverlight Version** drop down box.
- 9. Select the **Enable Web RIA Services** check box.
- 10. Click the **OK** button.

- 12. Replace the code of **MainPage.xaml.cs** file with the code shown in Listing 11.13, to handle the Click event of **btn1** button:

### Listing 11.13: Showing the Code for the MainPage.xaml.cs file

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Net;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Animation;
using System.Windows.Shapes;

namespace ViewBoxExample
{
    public partial class MainPage : UserControl
    {
        public MainPage()
        {
            InitializeComponent();
        }

        private void btn1_Click(object sender, RoutedEventArgs e)
        {
            string stretchValue = comboBox1.SelectionBoxItem.ToString();
            if (stretchValue.Equals("None"))
            {
                viewBox1.Stretch = Stretch.None;
            }
            else if (stretchValue.Equals("Fill"))
            {
                viewBox1.Stretch = Stretch.Fill;
            }
            else if (stretchValue.Equals("Uniform"))
            {
                viewBox1.Stretch = Stretch.Uniform;
            }
            else if (stretchValue.Equals("UniformToFill"))
            {
                viewBox1.Stretch = Stretch.UniformToFill;
            }
            textBlock1.Text = "Stretch is now set to " + stretchValue;
        }
    }
}
```

In the Listing 11.13, on the btn1_Click event, the Stretch property of the ViewBox control is set to the value selected in the ComboBox control.
