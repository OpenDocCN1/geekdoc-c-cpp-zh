## Using the ListBox Control

The ListBox control is a Standard Web server control that displays a list of items. It allows you to select one or more items from a list of items on a Web page. By default, you can select only one item at a time from the ListBox control; however, you can change the behavior of the ListBox control by setting the SelectionMode property to Multiple. The ListBox class resides in the System.Web.UI.WebControls namespace.

Noteworthy properties of the ListBox control are listed in Table 2.10:

| Property | Description |
|---|---|
| `BorderColor` | Obtains or sets the border color of the control |
| `BorderStyle` | Obtains or sets the border style of the control |
| `BorderWidth` | Obtains or sets the border width of the control |
| `Rows` | Obtains or sets the number of rows displayed in the ListBox control |
| `SelectionMode` | Obtains or sets the selection mode of the ListBox control |
| `Items` | Obtains or sets the items of the ListBox control |

The **ListBox** control has a property named as **Items**, which adds the items to the ListBox control. You can add and remove items to and from this collection.
