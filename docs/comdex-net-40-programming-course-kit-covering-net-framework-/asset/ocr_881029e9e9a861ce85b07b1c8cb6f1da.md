# Using a Web Service

To use a Web service in a Web site, you need to generate a proxy class for the Web service to allow a Web site access the Web service. A proxy class is a local copy of the class that represents a Web service. You can generate a proxy class for a Web service by adding a Web reference to the Web site.

Perform the following steps to create an ASP.NET Web site, named **UsingSimpleInterestWebService**, to access the Web service created earlier in this chapter:

+   1. Select **File→New→Web Site** to open the New Web Site dialog box.
+   2. Select **Visual C#** from the **Installed Templates** pane and the **ASP.NET Web Site** template from the middle pane of the **New Web Site** dialog box.
+   3. Enter the location and name (**UsingSimpleInterestWebService**) of the Web site in the New Web Site dialog box and click the **OK** button. The **UsingSimpleInterestWebService** application is created.
+   4. Open the default page (**Default.aspx**) by double-clicking the page in the **Solution Explorer** window and add the code shown in Listing 10.2 in the **Default.aspx** page:
