The System.Windows.Forms namespace provides the functionality for the Timer control. Table 3.19 lists the important properties of the Timer class:

| **Table 3.19: Noteworthy Properties of the Timer Class** |  |
|---|---|
| **Property** | **Description** |
| Enabled | Obtains or sets a value indicating whether the timer is running. |
| Interval | Obtains or sets the time interval (in milliseconds) between two occurrences of Tick events. The Tick event occurs when the specified time interval has elapsed and the timer is enabled. |

Table 3.20 lists the important methods of the Timer class:

| **Table 3.20: Noteworthy Methods of the Timer Class** |  |
|---|---|
| **Method** | **Description** |
| Start | Starts the timer |
| Stop | Stops the timer |

Perform the following steps to use the Timer control in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The New Project dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the New Project dialog box.
+   4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **TimerControl** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. Click the **OK** button to close the **New Project** dialog box. The **TimerControl** application is created (Fig.VB-3.45).
+   7. Drag and drop a **Label** control and a **Timer** control on the form from the **Toolbox**. The Label control is added to the form and the Timer control is added to the component tray (Fig.VB-3.45).
+   8. *Select* the **Timer** control in the component tray and set its **Enabled** property to **True** in the **Properties** window, as shown in Fig.VB-3.45.
