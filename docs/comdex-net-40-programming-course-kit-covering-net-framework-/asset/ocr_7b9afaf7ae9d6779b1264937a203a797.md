# ## Using the ListBox Control

The ListBox control is used to display a list of items, from where the user can select one or more items. It is similar to a ComboBox control; however, unlike a ComboBox control, you can select multiple items from a ListBox control and cannot manually type the item for a ListBox control at runtime. Each item in the ListBox control is recognized by its position, known as index, in the list. The ListBox class, which is included in the System.Windows.Forms namespace, provides the functionality for the ListBox control. Table 3.13 lists the important properties of the ListBox class:

**Table 3.13: Noteworthy Properties of the ListBox Class**

| Property | Description |
| :--- | :--- |
| ColumnWidth | Obtains or sets the width of columns in a multicolumn list box in pixels |
| DrawMode | Obtains or sets the drawing mode for the list box |
| HorizontalScrollbar | Obtains or sets a value specifying whether a horizontal scroll bar is displayed in the list box |
| IntegralHeight | Obtains or sets a value indicating whether the list box should resize to avoid displaying partial items |
| ItemHeight | Obtains or sets the height of an item in the list box in pixels |

| SelectedIndices | Obtains a collection that contains the indices of all the selected items in the list box |
