# **Listing 7.19: Adding code to Module1.vb File**

```
Module Module1
    Class Student
        Public Id As Integer
        Public Name As String
    End Class
    Private Function GetDataTable(ByVal students As Student()) As DataTable
        Dim table As DataTable = New DataTable()
        table.Columns.Add("Id", GetType(Integer))
        table.Columns.Add("Name", GetType(String))
        For Each s As Student In students
            table.Rows.Add(s.Id, s.Name)
        Next s
        Return (table)
    End Function
    Sub Main(ByVal args As String())
        Dim students As Student() = {New Student With {.Id = 1, .Name = "A"}, _
            New Student With {.Id = 2, .Name = "B"}, New Student With {.Id = 3, _
            .Name = "C"}, _
            New Student With {.Id = 4, .Name = "D"}, New Student With {.Id = 5, _
            .Name = "E"}, New Student With {.Id = 6, .Name = "F"}}
        Dim dt As DataTable = GetDataTable(students)
        For Each dr As DataRow In dt.Rows
            Console.WriteLine("{0}-{1}-{2}", dr.Field(Of Integer)(0), _
                dr.Field(Of String)(1))
        Next dr
        Console.ReadLine()
    End Sub
End Module
```

Listing 7.19 shows the code of the Module1.vb file. In the highlighted code snippet, we first define a class, **Student**, which has two **Public** variables, **ID** and **Name**. Then, we define a function, **GetDataTable**, which takes an array of **Student** objects as an argument. After that, we have created an object of the **DataTable** class that is adding a new row to data table and returning the object of the **DataTable** class. Finally, we define the **Sub** procedure, **Main**, which first creates an array of the **Student** objects, then creates an object of the **DataTable** class by calling the **GetDataTable** function, and then displays the data of the **DataTable** object on the screen.
