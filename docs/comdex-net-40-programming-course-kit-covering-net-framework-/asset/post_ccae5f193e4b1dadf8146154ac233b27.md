
```csharp
Console.WriteLine("Enumerator Name:"+TColor.ToString()+"\t\tConstant: "+ (int)TColor);
TColor = Color.Green;
Console.WriteLine("Enumerator Name:"+TColor.ToString()+"\t\tConstant: " + (int)TColor);
TColor = Color.Yellow;
Console.WriteLine("Enumerator Name:"+TColor.ToString()+"\t\tConstant: " + (int)TColor);
Console.ReadLine();
```

In the preceding code snippet, a variable named **TColor** of the **Color** enumeration type is created. The TColor variable is then assigned the Red enumerator of the Color enumeration. The value of the enumerator and the underlying constant is then displayed using the **Console.WriteLine()** method. Note that **(int)** prefixed to the TColor variable in the **Console.WriteLine()** method obtains the underlying constant of an enumerator.

## Structs

The struct type is represented by the struct keyword. It is a user-defined data type that contains several programming elements, such as variables, methods, properties, and events of different data types. The struct type allows you to create a variable that you can use to access different types of values. Being a value type, structs have a fixed size. In addition, when you assign a variable of struct type to another variable of struct type, the value in the first variable is copied to the second variable. The following code snippet shows how to create a struct type:

```csharp
public struct Rectangle
{
    int Length, Breadth;
    public Rectangle(int l, int b)
    {
        Length = l;
        Breadth = b;
    }
    public double Area()
    {
        return (Length * Breadth);
    }
}
```

In the preceding code snippet, a struct type named **Rectangle** is created by using the **struct** keyword. The **Rectangle** struct has two variables, **Length** and **Breadth**, of the int type. It also contains two methods, **Rectangle()** and **Area()**. The **Rectangle()** method is a constructor for the **Rectangle** type. It provides initial values to the **Length** and **Breadth** variables. The **Area()** method returns the area of a rectangle by multiplying the values in the **Length** and **Breadth** variables.

After creating the struct type, you can create variables of the struct type and use its variables, methods, and other elements. The following code snippet shows how to use a struct type:

```csharp
Rectangle Rect1 = new Rectangle(30,20);
Console.WriteLine("Area of Rect1= " + Rect1.Area());
Console.ReadLine();
```

In the preceding code snippet, a variable, Rect1, of the **Rectangle** type is created by calling the constructor of the **Rectangle** type. The values, 30 and 20, are passed to the constructor to set the **Length** and **Breadth** variables of the **Rectangle** type. The **Area()** method is then called on the **Rect1** variable to calculate the area.

## Reference Types

Reference types are those data types that work with the references or memory addresses of data rather than the data itself. When you assign a variable of a reference type to another variable of a reference type, the address of the first variable is copied and assigned to the second variable. This implies that there are two variables having the same memory address; and therefore, changes made to one variable affect the other variable.

![](img/9862a98a1a2d3bb14334137965a1ec60_292_0.png)

> Variables of reference types are called objects and are stored on the heap or managed heap, which is an area of memory that is reserved for storing a large amount of data. In addition, objects of reference types have variable lengths, that is, two objects of the same reference type can occupy different number of bytes in memory.

C# provides two predefined reference types, which are as follows:

- **The object type:** Represents the fundamental data type from which all other data types are created or derived. This data type is the base for both predefined and user-defined data types in C#.
- **The string type:** Represents a string or sequence of Unicode characters. Values of string data type are enclosed within a pair of double quotes (" "). You can perform various operations on strings, such as copying, comparing, and concatenating. Variables of the string data type are created by using the **string** keyword.

You can also create your own reference types in C#. The user-defined reference types can be classified as:

- **Classes:** Represent a data type that contains variables, methods, and properties. The variables, methods, properties, and other elements that a class contains are called members, and the instances of that class are called objects. Classes are created by using the **class** keyword.
- **Interfaces:** Represent a cohesive group containing only the declaration of programming elements, such as methods, events, and properties. You cannot create objects of an interface; however, you can implement it in several classes and use the containing elements. In C#, interfaces are created by using the **interface** keyword.
- **Arrays:** Represent an ordered collection of data or values that are of the same data type. The values in an array are stored at contiguous memory locations. This implies that the values are stored in sequential memory blocks.
- **Delegates:** Represent a data type that stores a reference or address of a particular method. A delegate behaves in the same way as the method to which it references. The declaration or signature of the delegate and the method to which it references must match. Delegates are created by using the **delegate** keyword.

## Pointer Types

A variable that holds the memory address of another variable is known as a pointer. Pointer types are used as the data type of variables declared as pointers. In C#, pointer types offer the same capabilities as offered by C and C++ languages. Pointers and references are similar as both represent memory address but the difference is that references are tracked by the garbage collector and pointers are not. C# uses delegates to maintain type safety and security in the context of references instead of using pointers. However, you can use pointers by defining an unsafe context (a simple code whose safety is not verified by the CLR). You can use the unsafe keyword to define an unsafe context. In other words, pointer types are used only in the unsafe context. Pointer types are not inherited from the Object class, which is the base class of all .NET types. You cannot convert pointer types to object type and vice-versa. A pointer variable is used to store the address of another variable. The following syntax shows the declaration of pointer type:

```csharp
datatype* identifier;
```

# Explaining Data Type Conversion

Data type conversion refers to the process of converting the values of one data type into another data type. When the value of a variable of one data type is converted into value of another data type, only the data type of the value is changed; the value itself remains the same. In C#, the following types of conversions are available:

- Implicit conversion
- Explicit conversion

Let’s discuss both these conversion types, one by one.

## Implicit Conversion

As the name suggests, implicit conversion refers to the process in which the C# compiler implicitly or automatically converts the value of one data type to value of another data type without any loss of data. Implicit conversion does not require any code to be written.

Table 1.4 lists the implicit conversions allowed for different data types:

**Table 1.4: Implicit Conversions**

| Data Type | Possible Conversion To |
|---|---|
| sbyte | short, int, long, float, double, decimal |
| byte | short, ushort, int, uint, long, ulong, float, double, decimal |
| short | int, long, float, double, decimal |
| ushort | int, uint, long, ulong, float, double, decimal |
| int | long, float, double, decimal |
| uint | long, float, double, decimal |
| long | float, double, decimal |
| ulong | float, double, decimal |
| float | double |
| char | ushort, int, uint, long, ulong, float, double, decimal |

The following code snippet shows an example of implicit conversion:

```csharp
short a = 20;
int b = a;  // Implicit conversion
```

The first line of the preceding code snippet declares a variable, a, of short data type, and initializes it with value, 20. The second line declares a variable, b, of int data type, and initializes it with the value stored in a. The second line involves implicit conversion as conversion from one data type (short) to another data type (int) is done without explicitly specifying the target data type. Note that the text after the double forward slash characters (//) is a comment, which is not executed by the compiler.

## Explicit Conversion

As you have seen that all data types could not be implicitly converted to others. For example, you cannot implicitly convert a string type value to an int type. In such situations, you need to explicitly request the C# compiler to perform the conversion. You can perform an explicit conversion through casting, which refers to the process of converting data types by prefixing a value or variable with the intended data type.

The syntax for casting data types is as follows:

```csharp
Variable2 = (Data_Type) Variable1;
```

- **Variable1:** Refers to the variable whose value you want to convert
- **Data_Type:** Refers to the data type which you want to convert the value of Variable1
- **Variable2:** Refers to the variable that holds the converted value

The following code snippet shows an example of casting of data types:

```csharp
float A = 24.05f;
int B = (int) A; // B holds the value 24
```

In the preceding code snippet, the float variable, A, has the value, 24.05. The value of A is converted into an int type by prefixing A with (int) while initializing the B variable. As a result of this explicit conversion, the fractional part of the value stored in the A variable is truncated and the integral part (24) of the value is assigned to the B variable. In this way, you can see that explicit conversions may involve data loss.
