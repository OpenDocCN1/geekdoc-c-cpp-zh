## Using the Label Control

The **Label** control is mainly used to name other controls present on a form that do not have a caption, such as **TextBox**, **ComboBox**, and **ListBox**. It displays text or message for the user in a non-editable format. In addition, you can also use the **Label** control to display dynamic text, which refers to a text that can change after the occurrence of an event in an application. The text for the label can only be changed while designing the form or through the code at runtime. The **Label** class, which is present in the **System.Windows.Forms** namespace, provides the functionality for the Label control.

You can use the properties of the Label control to adjust its appearance. Table 3.3 lists the important properties of the Label class:

**Table 3.3: Noteworthy Properties of the Label Class**

| BorderStyle | Obtains or sets the border style for the Label control |
| Image | Obtains or sets the image that is displayed on a Label control |
| TextAlign | Obtains or sets the alignment of text in the Label control |

## Using the TextBox Control

The TextBox control is a rectangular-shaped control in which you can enter a text. It is a Windows Forms control, which is mainly used to accept input from a user at runtime. You can also use the TextBox control to display text to the user at runtime. By default, a TextBox control accepts only a single line of text. You can make the TextBox control to accept multiple lines of text, display text in the form of password, or disable text editing by modifying the appropriate properties of the TextBox control. The TextBox class, which is included in the System.Windows.Forms namespace, provides the functionality for the TextBox control. Table 3.4 lists the important properties of the TextBox class:

The Button class, which is included in the System.Windows.Forms namespace, provides the functionality for the Button control. Table 3.6 lists the noteworthy properties of the Button class:

**Table 3.6: Noteworthy Properties of the Button Class**

| Property | Description |
| --- | --- |
| AutoSize | Obtains or sets a value specifying whether the Button control is automatically resized to display all its contents |
| DialogResult | Obtains or sets the value returned to the parent form when the Button control is clicked |
| Image | Obtains or sets an image displayed on the Button control |
| TextAlign | Obtains or sets the alignment of the text on the Button control |

Table 3.7 lists the important methods of the Button class:

**Table 3.7: Noteworthy Methods of the Button Class**
