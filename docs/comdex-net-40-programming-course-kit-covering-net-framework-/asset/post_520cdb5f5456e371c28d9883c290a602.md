## Using the For...Each Statement

The For...Each statement iterates through all the items in a list, which may be an array or a collection of objects. This statement works in the same way as the For...Next statement. The syntax of the For...Each statement is as follows:

```vb
For Each element [ As datatype ] In group
    [ statements ]
    [ Exit For ]
    [ statements ]
Next [ element ]
```

In the preceding syntax, element is required in the For...Each statement, but it is optional in the Next statement; datatype determines the data type of the element, but is required only if the element is not already declared; group refers to collections based on which iterations are to be repeated; statements refer to a set of statements between the For...Each and Next statements that are executed for each item in the group; Exit For takes the control out of the For...Each loop; and finally, Next terminates the definition of the For...Each loop.

## Using the While...End While Statement

The While...End While statement continues to execute a set of statements as long as a given condition is True. The While statement always checks the condition before executing the statements within the loop. When the control reaches the End While statement, the control is passed back to the While statement. If the condition is still True, the statements within the loop are executed; otherwise, the loop exits. The syntax of the While...End While statement is as follows:

```text
While condition
    [ statements ]
    [ Exit While ]
    [ statements ]
End While
```

In the preceding syntax, the statements enclosed in the While statement are executed repeatedly till the condition is True. You can also terminate a While statement any time with an Exit While statement.

Perform the following steps to use a While...End While statement in a Console application:

- 1. *Start* Visual Studio 2010.
- 2. *Select* File→New→Project from the menu bar. The New Project dialog box appears.
- 3. *Select* Visual Basic→Windows from the Installed Templates section in the left pane of the New Project dialog box.

Listing 1.5: Writing the While...End While Statement

```vb

    Sub Main()
        Dim Counter As Integer = 1
        Console.WriteLine("Iterations using While...End While statement")
        While Counter < 10
            Console.WriteLine(Counter)
            Counter += 1
        End While

    End Sub
End Module
```

In Listing 1.5, we have created a variable, Counter, of the Integer type and assigned a value of 1 to it. The While statement checks the condition whether the value of the Counter variable is less than 10. If it is, the value of the Counter variable is displayed on the screen and then the value of the Counter variable is incremented by 1. The loop continues to execute till the value of the Counter variable is less than 10. Now, when the value of the Counter variable becomes 10, the condition evaluates to **False** and the control exits the While statement.

## Using the Do...Loop Statement

Similar to other iteration statements, the **Do...Loop** statement is also used to execute a group of statements repeatedly. You need to use either the **While** keyword or the **Until** keyword with the **Do...Loop** statement. When you use the **While** keyword, the **Do...Loop** statement executes a group of statements repeatedly as long as a given condition is **True**. On the other hand, when you use the **Until** keyword, the **Do...Loop** statement executes a group of statements until a given condition evaluates to **True**. The syntax of the **Do...Loop** statement is as follows:

```text
Do { While | Until } condition
    [ statements ]
    [ Exit Do ]
    [ statements ]
Loop
```

In the preceding syntax, the **Do...Loop** statement keeps executing the set of statements till the given condition is **True** or until the given condition evaluates to **True**.

## Variables

A variable is an identifier that denotes a storage area in the memory. For example, you can use a variable to store values, such as 3, 5.2, or Hello World. Every variable has a type, which determines the values that can be stored in it. A variable can store different values during the execution of a program. It has a data type and can store only those values that fall in the range of values supported by its data type. A variable name should be meaningful, easy to understand, and should convey the value stored in the variable. A meaningful variable name helps to make the code more readable. Some examples of meaningful variable names are salary, height, name, age, and total_marks.

You should remember the following points while assigning a name to a variable in Visual Basic 2010:

- A variable name can only contain alphabets, digits, and underscores
- A variable name should not begin with a digit or numeric value
- A variable name cannot contain a blank space
- Keywords cannot be used as variable names

In Visual Basic 2010, a variable can be declared at the class, module, procedure, or block level by using the **Dim** statement, as shown in the following code snippet:

```vb
Dim Name As String
Dim RollNo As Integer
Dim Grade As Char
```

A variable can be assigned a value at the time of its declaration by using the = sign, as shown in the following code snippet:

```vb
Dim Name As String = "James"
Dim RollNo As Integer = 1
Dim Grade As Char = "A"
```
