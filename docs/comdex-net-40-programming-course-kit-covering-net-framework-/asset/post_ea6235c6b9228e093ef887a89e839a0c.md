## Using the ListBox Control

The ListBox control is used to display a list of items, from where the user can select one or more items. It is similar to a ComboBox control; however, unlike a ComboBox control, you can select multiple items from a ListBox control and cannot manually type the item for a ListBox control at runtime. Each item in the ListBox control is recognized by its position, known as index, in the list. The ListBox class, which is included in the System.Windows.Forms namespace, provides the functionality for the ListBox control. Table 3.13 lists the important properties of the ListBox class:

**Table 3.13: Noteworthy Properties of the ListBox Class**

| **Property** | **Description** |
|---|---|
| ColumnWidth | Obtains or sets the width of columns in a multicolumn list box in pixels |
| DrawMode | Obtains or sets the drawing mode for the list box |
| HorizontalScrollbar | Obtains or sets a value specifying whether a horizontal scroll bar is displayed in the list box |
| IntegralHeight | Obtains or sets a value indicating whether the list box should resize to avoid displaying partial items |
| ItemHeight | Obtains or sets the height of an item in the list box in pixels |
| Items | Obtains a collection of items available in the list box |
| MultiColumn | Obtains or sets a value specifying whether the list box supports multiple columns |
| ScrollAlwaysVisible | Obtains or sets a value specifying whether a vertical scroll bar is always visible |
| SelectedIndex | Obtains or sets the index of the currently selected item of the list box |
| SelectedIndices | Obtains a collection that contains the indices of all the selected items in the list box |
| SelectedItem | Obtains or sets the selected item in the list box |
| SelectedItems | Obtains a collection containing the selected items of the list box |
| SelectionMode | Obtains the mode with which items are selected |
| Sorted | Obtains or sets a value indicating whether the items in the list box are sorted alphabetically |

The SelectionMode property allows you to specify how many items can be selected from the list box at a time. You can use this property to allow multiple selections in a list box. The SelectionMode property can be set to any of the following values:

- **None:** Implies that no items can be selected from the list box
- **One:** Implies that only one item can be selected from the list box
- **MultiSimple:** Implies that multiple items can be selected from the list box
- **MultiExtended:** Implies that multiple items can be selected from the list box, and the user can use the SHIFT, CTRL, and arrow keys to make the selections
