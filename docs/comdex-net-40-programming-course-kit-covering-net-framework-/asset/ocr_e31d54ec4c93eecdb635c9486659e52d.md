# ## Explaining WPF 4.0 Architecture

WPF 4.0 has both managed and unmanaged components. Managed components refer to those components that use the services of Common Language Runtime (CLR), such as garbage collection and type safety, within the .NET environment, while unmanaged components are those components that do not use the CLR services. The essential components of WPF 4.0 are PresentationFramework, PresentationCore, and milcore. Let’s now discuss the essential components of WPF 4.0 architecture, one by one.

# ### *The PresentationFramework Component*

The **PresentationFramework** component refers to the **PresentationFramework.dll** assembly in .NET Framework 4.0. It offers various classes, such as Calendar and DataGrid, to manipulate the appearance and presentation of WPF 4.0 applications. It also provides end-user presentation features, such as layout, animation, and data binding. The **PresentationFramework** component supports higher-level program abstraction implementation, such as styles.

# ### *The PresentationCore Component*

The **PresentationCore** component refers to the **PresentationCore.dll** assembly. It implements core services for WPF that allow you to manage properties and events. It supports base types such as UIElement and Visual that are parents of all the controls and shapes. Note that the **PresentationCore** component does not offer classes for the UI of WPF 4.0 applications as offered by the PresentationFramework component.

# ### *The Milcore Component*

**Milcore** or **Media Integration Layer (MIL)** is an unmanaged component of WPF 4.0. It interacts with **DirectX**, which is the component that processes all the design-related elements to display 2D and 3D graphical content in WPF 4.0 applications. It is the foundation of MIL and core rendering system of WPF.
