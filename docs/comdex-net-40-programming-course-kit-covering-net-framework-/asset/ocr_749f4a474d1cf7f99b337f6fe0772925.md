In Listing 9.2, the `Text` property of the `Label3` control is set to the current time. A method named `GetTime` is also declared that returns the current time. To enable the `Substitution` control to work, you need to add the `GetTime` method to the `MethodName` property of the `Substitution` control. This method returns the current time to the `Substitution` control every time you refresh the page.
