# Projection Operators

Projection operators refer to the operators that transform an object into a new form; the new form generally consists of properties that will be used subsequently. The new form into which the objects are transformed is of a new type. Table 6.5 lists all the projection operators in LINQ:

| Operator | Description | Query Expression Syntax (C#) |
|---|---|---|
| Select | Projects (or selects) values from a single sequence or collection | select |
| SelectMany | Projects (or selects) values from multiple sequences or collections | Use the select clause with multiple from clauses |

Perform the following steps to project a sequence of words by using the select clause:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual C#→Windows Forms** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows-based applications in C# are displayed in the right pane of the **New Project** dialog box.
+   4. *Select* the **Windows Forms Application** template in the right pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **ProjectionOperator** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **ProjectionOperator** application is created (Fig.C#-6.14).
+   7. *Drag and drop* two **Label** controls, two **ListBox** controls, and a **Button** control on the form from the **Toolbox**.
+   8. *Set* the **Text** property of the **Label** controls to **Before Projection** and **After Projection**, respectively, and the **Text** property of the **Button** control to **Project Data**, by using the **Properties** window, as shown in Fig.C#-6.14.
