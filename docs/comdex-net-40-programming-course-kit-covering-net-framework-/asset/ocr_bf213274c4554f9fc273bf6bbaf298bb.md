As shown in Fig.ASP-8.11, **Company** is a master page from which two other master pages, Branch 1 and Branch 2, are inherited. This shows that these are nested master pages.

Let’s perform the following steps to create an application, which contains nested master pages.

+   1. *Open* Visual Studio 2010.
+   2. *Select* **File→New→Web Site** from the menu bar. The **New Web Site** dialog box opens.
+   3. *Select* **Visual C#** from the **Installed Templates** pane of the **New Web Site** dialog box.
+   4. *Select* **ASP.NET Empty Web Site** from the right pane of the **New Web Site** dialog box.
+   5. *Specify* the location and name of the application in the **Web location** combo box. In this case, we have specified the name as **NestedMasterPage**.
+   6. *Click* the **OK** button to create the **NestedMasterPage** application (also available on the CD).
+   7. *Right-click* the project name in **Solution Explorer** and select the **Add New Item** option from the context menu. The **Add New Item** dialog box opens.
+   8. *Select* the **Master Page** option from the middle pane of the **Add New Item** dialog box.
+   9. *Enter* the name of the master page as **Parent.master** in the **Name** text box.
+   10. *Click* the **Add** button. The **Parent.master** master page is added to the **Solution Explorer** window.
+   11. *Replace* the code of the **Parent.master** master page with the code shown in Listing 8.4:
