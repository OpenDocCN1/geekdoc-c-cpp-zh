+   - The data types of the parameters
+   - The order in which the parameters are passed

The following code snippet shows two overloaded versions of a method, Display():

```
void Display(string name)
{
    Console.WriteLine("Name: " + name);
}
void Display(string name, int marks)
{
    Console.WriteLine("Name: " + name);
    Console.WriteLine("Marks: " + marks);
}
```

In the preceding code snippet, the first overloaded version of the Display() method takes only one parameter that is of the string type. The second overloaded version of the Display() method takes two parameters, one is of the string type and the other is of the int type.
