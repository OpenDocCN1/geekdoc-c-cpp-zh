+   - **Business Intelligence:** Enables you to get all the status information about your application, such as monetary, sales reports, and feedback from users.

# ### Starting with the Windows Phone Developer Portal

To develop a Windows Phone application, you require a tool or platform on which the application can be build, tested, and debugged. You can download the Windows Phone Application Tools from the Windows Phone developer portal, also called as App Hub. To download this tool, you first need to sign up for a Windows Live ID. After signing up, you are registered to get the Windows Phone Application Tools and the related licensing materials that are required to develop applications using Visual Studio 2010 and Expression Blend. The Windows Phone Application Tools is a single and small tool that contains all the tools and runtimes needed for designing, developing, and debugging your applications.
