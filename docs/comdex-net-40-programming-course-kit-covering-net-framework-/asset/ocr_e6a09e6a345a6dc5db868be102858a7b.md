# Using the DatePicker Control

The DatePicker control is a new WPF control introduced in WPF 4.0. Similar to the **Calendar** control, the **DatePicker** control also allows you to select a date. However, the difference between the two controls is that while the Calendar control consists of only a calendar from which you can select a date, the DatePicker control is a combination of combo box and calendar. The **DatePicker** control is an instance of the **DatePicker** class, which is defined inside the **System.Windows.Controls** namespace. Table 5.13 lists the noteworthy properties of the **DatePicker** class:

**Table 5.13: Noteworthy Properties of the DatePicker Class**

| Property | Description |
|---|---|
| BlackOutDates | Retrieves or assigns a collection of dates that are marked as not selectable in a DatePicker control |
| DisplayDate | Retrieves or sets the date to display in a DatePicker control |
| DisplayDateEnd | Retrieves or sets the last date to be displayed in a DatePicker control |
