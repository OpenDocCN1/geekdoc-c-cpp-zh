# Working with Namespaces

The concept of namespaces is not new to C#. A namespace acts as a wrapper around one or more structural elements that make the elements unique. In other words, a namespace is a way to group related types under one name. Whether or not you explicitly declare a namespace in a source file, the C# compiler adds a default namespace to the source file.

Namespaces in C# can be divided into two categories:

+   - **User-defined:** Refer to namespaces that are defined in your code.
+   - **System-defined:** Refer to namespaces that are defined in .NET Framework Base Class Library, for example, System, System.Collections, and System.Data.

In C#, you can use the **using** keyword to include a namespace in your program.

> > Namespaces are always public; therefore, the declaration of a namespace cannot include any access modifier.
