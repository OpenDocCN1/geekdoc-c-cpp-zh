Business is growing faster day by day and so there is need to store data. In computing, data is logically stored in databases within tables. A database is a collection of tables and each table stores large amount of data logically, so that information can be accessed from the database quickly and efficiently whenever required. Such types of databases that store data in tables are called relational databases. Some popular relational databases are SQL Server, Oracle, and Microsoft Access.

Most business applications provide a user friendly interface, which helps in retrieving data from a database without using so much database related commands. ActiveX Data Object.NET (ADO.NET) is an example of such interface, used by the .NET Framework to communicate with the data and provide data access services to the .NET applications. It provides consistent co various data sources, such as Structured Query Language (SQL), Extensible Markup Language (XML), Object Linking and Embedding Database (OLE DB), and Open Database Connectivity (ODBC). The .NET Framework provides separate data providers to communicate with different data sources.

# Introducing SQL

SQL is the standard language used for accessing and manipulating data stored in databases. A **database**, as discussed earlier, is a structured collection of records or data so that you can easily access, manage, and update the data. In a database, data is stored in the form of tables. Tables store data in the form of rows and columns. Each column of a table represents a different attribute termed as a field. Each row stores entries for all the attribute values for a single record. These records can be sorted, indexed, updated, and organized easily by writing the different SQL query statements. SQL provides separate statements for inserting new records, updating records, and creating new tables and datasets. A dataset is an in-memory representation of data.

If you are working with SQL in C# 2010, you can use SQL statements to access and modify the data in databases. In our case, we work on a database, named **northwind**. This database contains different tables, such as the **Customers** table, which has different fields (such as **CustomerID** and **Address**), the **Orders** table, which has fields (such as **OrderID**), and the **OrderDetails** table, which has fields (such as **Quantity**).

# The SELECT Statement

The SELECT statement is used to retrieve values for some or all the fields of a table. For example, you can write the following SQL statement to retrieve all the records from the Customers table by using the wildcard character *:

```
SELECT * FROM Customers
```

The preceding SQL statement returns all the records from the **Customers** table. You can also use the SELECT statement to retrieve values of specific fields of a table. For example, you can retrieve values from the **CustomerID**, **Address**, and **City** fields of the Customers table by using the following SQL statement:

```
SELECT CustomerID, Address, City FROM Customers
```

The preceding statement returns the values of the **CustomerID**, **Address**, and **City** fields of the **Customers** table.
