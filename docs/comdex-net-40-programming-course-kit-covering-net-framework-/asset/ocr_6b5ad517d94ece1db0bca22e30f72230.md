# ### Start Page

As the name suggests, Start Page (Fig.VS-2.16) is the first page that appears whenever you open Visual Studio 2010. Start Page offers various links to access the recently opened applications, the resources, articles, news related to various products and technologies of Microsoft, samples, and walkthroughs to start working with Visual Studio 2010.

# ### Menu Bar and Toolbar

The menu bar is a collection of menus, each of which contains a logical set of options for performing various tasks. The menus that are available in the Visual Studio 2010 IDE may vary between different kinds of .NET applications. However, some of the menus are common to all kinds of .NET applications, for example, the **File**, **Edit**, **View**, **Build**, **Debug**, and **Help** menus. Every menu provides options for performing a particular type of task, for instance, the **File** menu has options for performing file management tasks, such as creating, opening, saving, and closing files (or applications).

The menu bar of the Visual Studio 2010 IDE has a set of comprehensive options, some of which are more frequently used than others. Some frequently-used options of this menu bar are contained in toolbars so that they can be accessed quickly. The toolbars appear just below the menu bar and have buttons as shortcuts for the most common menu options and other tasks. You can click the buttons on a toolbar to select an option or perform a particular task. Some of the common toolbars are **Standard**, **Build**, **Debug**, and **Layout**.

# ### Toolbox

Toolbox is a window that contains icons for various items and controls that you can add to a .NET application to design the UI of an application. The icons in Toolbox are logically grouped under different tabs, such as Common Controls, Containers, and Menus and Toolbars. Each tab contains the icons of the UI items and controls that pertain to a specific category; for example, the Containers tab contains the icons of those controls that allow you to group Windows controls, such as buttons, labels, text boxes, and radio buttons.
