> **While creating a user account by using the ASP.net Web Site Administration Tool, the password is changed in such a manner that it satisfies some predefined conditions.** First, it must contain a minimum of six characters. Second, it must have at least one numeric digit, for example, 1, 2, 3. Finally, it must contain at least one special character, for example, !, @, #, $, %, ^, or &. Examples of correct passwords are tester1#, Istudent&, collegeStudent1@, and 1myName. Examples of incorrect passwords are hello, 123, and collegeStudent1.
