# ## Improved Security Model

A new and improved security model has been introduced in .NET Framework 4.0. This new security model includes two major changes. The first is that machine-wide security policy has been removed, although the system of assigning permissions is kept unchanged. The second change is that security transparency has been made as the default enforcement mechanism. In addition to preceding changes, the permission operations that were exposed to security issues have been made obsolete. In .NET Framework 4.0, the security policy is not applied to all the applications. In addition, the desktop applications, which include both the applications on computer and on the network, are now executed as full-trust applications. Full-trust applications are the applications that are not restricted by the security-policies, such as system firewalls. There are many useful classes and services introduced in CLR and .NET Framework that help developers to write secure code and implement cryptography and role-based security in .NET applications.

# ## Networking Improvements

The various networking improvement in .NET Framework 4.0 include the following:

+   - Improvement in classes for Windows authentication, such as System.Net.HttpWebRequest, System.Net.HttpListener, System.Net.Mail.SmtpClient, and System.Net.Security.NegotiateStream.
+   - Improvement in support for Network Address Translation (NAT) traversal using the IPv6 and Teredo protocols
+   - Introduction of new networking performance counters that provide information about HttpWebRequest objects
+   - Introduction of AddRange method in the System.Net.HttpWebRequest class
+   - Implementation of Secure Socket Layer (SSL) support for the System.Net.Mail.SmtpClient class
+   - Improvement in support for mail headers in the System.Net.Mail.MailMessage class
+   - Introduction of credential for password-based authentication schemes, such as digest, NTLM, and Kerberos authentication

# ## Improved Core ASP.NET Services

In .NET Framework 4.0, some features have been introduced to improve the core ASP.NET services. These features are as follows:

+   - Introduction of the Page.MetaKeywords and Page.MetaDescription page properties that are used to set meta tags
+   - Improved browser capabilities
+   - Introduction of ASP.NET routing with Web forms
+   - Introduction of the new ASP.NET Chart control
+   - Introduction of the new QueryExtender control, which provides filtering support for data source controls
+   - Implementation of more control over HTML code in the FormView and ListView controls
