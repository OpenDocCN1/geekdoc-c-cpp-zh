## The ZIP Operator

The Zip operator is a new operator introduced in LINQ in ASP.NET 4.0 that helps in combining two collections. This operator helps to merge two collections, which are identical in length, into one. The Zip operator uses the order of elements to combine the elements from two given collections. This implies that the Zip operator takes an element from the first source and an element from the second source, which is at the same location, and returns a combined type.

## Implementing LINQ to ADO.NET

LINQ to ADO.NET is a term that describes the database-centric aspects of LINQ. It consists of the following three technologies:

- **LINQ to DataSet:** Represents a set of extensions to the standard ADO.NET DataSet programming model. It allows the **DataSet**, **DataTable**, and **DataRow** objects to be a natural target for a LINQ query expression. Moreover, LINQ to DataSet provides richer and optimized querying over datasets.
- **LINQ to SQL:** Allows you to interact with a relational database and also enables you to query the SQL Server database schemas directly.
- **LINQ to Entities:** Allows you to write queries for the Entity Framework conceptual model, which enables users to visually design models and map databases, tables, and views by using Visual Studio 2010 and .NET Framework 4.0.

Let’s now discuss two of the important technologies in detail.

### LINQ to DataSet

A dataset is an in-memory representation of data that acts as the core of a wide variety of data-based applications. After data is loaded into a dataset, you often need to perform additional queries on the data. These additional queries are generally executed by using the LINQ to DataSet technology.

LINQ to DataSet provides an easier and faster way to query data cached in a dataset object as compared to traditional methods of querying the data. LINQ to DataSet simplifies the process of querying by enabling you to write queries in the programming language itself. The query operators allow you to perform LINQ queries on the dataset. To begin querying a dataset by using LINQ to DataSet, you need to confirm whether your dataset is filled with data or not because you cannot get any output or result set from an empty dataset.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Data;

namespace LINQtoDataset
{
    class Student
    {
        public int Id;
        public string Name;
    }

    class Program
    {
        static DataTable GetDataTable(Student[] students)
        {
            DataTable table = new DataTable();
            table.Columns.Add("Id", typeof(Int32));
            table.Columns.Add("Name", typeof(string));
            foreach (Student s in students)
            {
                table.Rows.Add(s.Id, s.Name);
            }
            return (table);
        }

        static void OutputDataTableHeader(DataTable dt, int ColumnWidth)
        {
            string format = string.Format("{{0,-{0}}}", ColumnWidth);
            foreach (DataColumn c in dt.Columns)
            {
                Console.Write(format, c.ColumnName);
            }
            Console.WriteLine();
            foreach (DataColumn c in dt.Columns)
            {
                for (int i = 0; i < ColumnWidth; i++)
                {
                    Console.Write("=");
                }
            }
            Console.WriteLine();
        }

        static void Main(string[] args)
        {
            Student[] students = {
                new Student { Id = 1, Name = "A" },
                new Student { Id = 2, Name = "B" },
                new Student { Id = 3, Name = "C" },
                new Student { Id = 4, Name = "D" },
                new Student { Id = 5, Name = "E" },
                new Student { Id = 6, Name = "F" }
            };

            DataTable dt = GetDataTable(students);
            Console.WriteLine("{0,-15}{1,-15}", System.Environment.NewLine);
            OutputDataTableHeader(dt, 15);
            foreach (DataRow dr in dt.Rows)
            {
                Console.WriteLine("{0,-15}{1,-15}",
                    dr.Field<int>(0),
                    dr.Field<string>(1));
            }
            Console.ReadLine();
        }
    }
}
```

In the preceding code, we have first defined a class, Student, which has two Public variables, Id and Name. After that, we have defined a function, GetDataTable, which takes an array of Student objects as an argument. After that, we have created an object of the DataTable class that is adding a new row to data and returning the object of the DataTable class. Finally, we have defined the Main method, which first creates an array of Student objects, creates an object of the DataTable class by calling the GetDataTable function, and then displays the data of the DataTable object on the screen.
