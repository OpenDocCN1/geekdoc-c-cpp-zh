
## Using the DataPager control

The DataPager control, introduced with Silverlight 3.0, is used when you have a large collection of data and it is not possible to display the entire data in a single page. This control is used to represent the necessary UI for paging through a data collection. You can provide paging capabilities to a data collection that implements the IPagedCollectionView interface. This interface contains the definition of methods and properties to provide paging capabilities to a collection of data.

Perform the following steps to use the DataPager control with a DataGrid control in a Silverlight application:

- 1. Open Microsoft Visual Studio 2010 and select File→New→Project. The New Project dialog box appears.
- 2. Select Visual C#→Silverlight from the Installed Templates pane in the New Project dialog box.
- 3. Select Silverlight Application from the middle pane.
- 4. Specify the name of the application as SilverlightDataPager (also available on CD) in the Name text box and the appropriate location in the Location combo box.
- 5. Click the OK button. The New Silverlight Application dialog box appears.
- 6. Select the Host the Silverlight application in a new Web site check box.
- 7. Select the ASP.NET Web Application project option from the New Web project type drop-down box.
- 8. Select Silverlight 4 from the Silverlight Version drop-down box.
- 9. Select the Enable WCF RIA Services check box.
- 10. Click the OK button. The SilverlightDataPager application is created.
- 11. Replace the code of MainPage.xaml file with the code shown in Listing 11.6, to design the UI of your application:

**Listing 11.6:** Showing the Code for the MainPage.xaml File of the SilverlightDataPager Application

```xml
<UserControl
    xmlns:sdk="http://schemas.microsoft.com/winfx/2006/xaml/presentation/sdk"
    x:Class="SilverlightDataPager.MainPage"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
    xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
    mc:Ignorable="d"
    d:DesignHeight="300" d:DesignWidth="400">
<Grid x:Name="LayoutRoot" Background="Black" Height="300" Width="400">
<StackPanel x:Name="ContentStackPanel" Orientation="Vertical">
<sdk:DataGrid x:Name="myDataGrid" Height="200" Width="400" />
<sdk:DataPager x:Name="myPager" Source="{Binding Path=ItemsSource,
                ElementName=myDataGrid}" DisplayMode="Numeric"/>
</StackPanel>
</Grid>
</UserControl>
```

In Listing 11.6, a DataGrid control, myDataGrid, and a DataPager control, myPager, are added. The DataPager control is used to display the data items inside the DataGrid control, myDataGrid, in multiple pages.

- 12. Replace the code of MainPage.xaml.cs file with the code shown in Listing 11.7:

**Listing 11.7:** Showing the Code for the Code-Behind File of the MainPage.xaml File

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Net;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Documents;

using System.Windows.Data;
namespace SilverlightDataPager
{
    public partial class MainPage : UserControl
    {
        public MainPage()
        {
            InitializeComponent();
            PagedCollectionView pagedCollectionView = new PagedCollectionView
                ("WELCOME TO SILVERLIGHT 3");
            pagedCollectionView.PageSize = 5;

        }
    }
```

In Listing 11.7, the **System.Windows.Data** namespace is added to the **SilverlightDataPager** application. An instance of the **PagedCollectionView** class, called pagedCollectionView is created. This class is used for grouping, sorting, filtering, and paging a collection of data. Next, the string WELCOME TO SILVERLIGHT 3 is passed to that object and the **String.Split()** method is used that returns a string array and finds all the substrings that are separated by one or more characters.

## Using the TreeView control

The **TreeView** control, introduced with Silverlight 3.0, is used to display the hierarchical data in the form of nodes. A node that contains child nodes in a **TreeView** control can be collapsed and expanded. You can click any node of a TreeView control to collapse it or expand it. The **TreeView** control is a specialized **ItemsControl** control, which means that you can populate the **TreeView** control with some content by either setting its **Items** property or the **ItemsSource** property.

Now, let’s perform the following steps to use the TreeView control in a Silverlight application:

- 1. Open **Microsoft Visual Studio 2010** and select **File→New→Project**. The **New Project** dialog box appears.
- 2. Select **Visual C#→Silverlight** from the **Installed Templates** pane in the **New Project** dialog box.
- 3. Select **Silverlight Application** from the middle pane.
- 4. Specify the name of the application as **SilverlightTreeView** (also available on CD) in the **Name** text box and the appropriate location in the **Location** combo box.
- 5. Click the **OK** button. The **New Silverlight Application** dialog box appears.
- 6. Select the **Host the Silverlight application in a new Web site** check box.
- 7. Select the **ASP.NET Web Application Project** option from the **New Web project type** drop-down box.
- 8. Select **Silverlight 4** from the **Silverlight Version** drop-down box.
- 9. Select the **Enable WCF RIA Services** check box.
- 10. Click the **OK** button. The **SilverlightTreeView** application is created.
