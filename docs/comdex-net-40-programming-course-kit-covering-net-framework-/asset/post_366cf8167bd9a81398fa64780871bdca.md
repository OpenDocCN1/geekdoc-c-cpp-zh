## Performing Common Form Operations

You can perform a number of operations on the forms added to a Windows forms application. These operations allow you to customize the appearance and behavior of the forms. Some common operations that you can perform on the forms added to a Windows forms application are as follows:

- Setting the title of a form
- Setting the initial position and state of a form
- Hiding the Minimize, Maximize, and Close buttons
- Adding controls to a form
- Setting the tab order of controls
- Docking and anchoring controls
- Adding forms to a Windows forms application
- Setting the startup form
- Creating always-on-top forms
- Showing and hiding forms and controls
- Resizing and moving forms and controls at run time

Let’s start with learning how to change the title of a form.

### Setting the Title of a Form

You can set the title of a form in a Windows forms application by setting the **Text** property of the form at either design time or run time. To set the title of a form at design time, you need to select the form in the designer and then set the **Text** property of the form in the **Properties** window. To set the title of a form at run time, you need to set the **Text** property of the form in Code Editor.

Perform the following steps to set the title of a form at run time:

1. *Start* Visual Studio 2010.
2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
3. *Select* Visual Basic→**Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows-based applications in Visual Basic are displayed in the middle pane of the **New Project** dialog box.
4. *Select* **Windows Forms Application** in the middle pane to create a Windows forms application.
5. *Enter* the name of the application as **SETTITLE** (also available in the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
6. *Click* the **OK** button to close the **New Project** dialog box. The **SETTITLE** application is created, as shown in Fig.VB-2.2:

![](img/9862a98a1a2d3bb14334137965a1ec60_90_0.png)

7. Double-click the form and add the highlighted code shown in Listing 2.1 to Code Editor:

**Listing 2.1: Showing Code to Set the Title of a Form**

```vb

    Me.Text = "Hello"
End Sub
```

In Listing 2.1, the title text for the **Form1** form has been set as **Hello** using the Text property of **Form1** form.

### Setting the Initial Position and State of a Form

Sometimes, you are required to display a form at a specified position. You can set the initial position for a form by setting the **StartPosition** property of the form at either design time or run time. The **StartPosition** property takes its values from the **FormStartPosition** enumeration.

Table 2.4 shows all the members of the **FormStartPosition** enumeration:

| Member Name | Description |
|---|---|
| Manual | Sets the initial position for a form according to the value of the `Location` property of the form. |
| CenterScreen | Positions the form at the center of the screen and sets the dimensions of the form according to the value of the `Size` property of the form. |
| WindowsDefaultLocation | Positions the form at the Windows default location and sets the dimensions of the form according to the value of the `Size` property of the form. This is the default value for the `StartPosition` property of a form. |
| WindowsDefaultBounds | Positions the form at the Windows default location and sets the dimensions of the form according to the default settings of Windows (operating system). |
| CenterParent | Positions the form as centered within the bounds of its parent form. |

Depending upon your requirements, you can display a form in various states, such as normal, minimized, or maximized. In such a situation, you can set the initial state of the form by setting its **WindowState** property at either design time or run time. The **WindowState** property can be set to any of the following values:

- **Normal:** Sets the state of the form to the restored state. This is the default value for the **WindowState** property.
- **Minimized:** Sets the state of the form to the minimized state and as a result, the form appears on the taskbar.
