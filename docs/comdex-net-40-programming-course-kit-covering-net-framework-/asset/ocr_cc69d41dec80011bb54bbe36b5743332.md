**Table 2.1: System Requirements to Install Visual Studio 2010**

| Hardware/Software Component | Requirements |
|---|---|
| RAM | 1 GB RAM or more |
| Hard disk | For full installation: 3 GB of available hard disk space |
| Hard disk speed | 5400 revolutions per minute (RPM)<br>Recommended: 7200 RPM or higher |
| DVD-ROM drive | Required |
| Display | Minimum: 1024 X 768 display |
| Mouse | Mouse or compatible device |

After you have ensured that the hardware and software components listed in Table 2.1 exist on your computer, proceed with the installation of Microsoft Visual Studio 2010 by performing the following steps:

+   1. Insert the DVD-ROM of Visual Studio 2010 in the DVD-ROM drive of your computer. The **Microsoft Visual Studio 2010 Setup** dialog box appears (Fig.VS-2.5).

+   2. Click the **Install Microsoft Visual Studio 2010** link, as shown in Fig.VS-2.5:

![](bbox=[0.391, 0.404, 0.631, 0.562])

The setup starts loading the installation components (Fig.VS-2.6). After the setup completes loading the installation components, the **Next** button becomes enabled (Fig.VS-2.7).

+   3. Click the **Next** button, as shown in Fig.VS-2.7:

![](bbox=[0.24, 0.621, 0.787, 0.791])

Microsoft Visual Studio 2010 Ultimate Setup – Start Page appears (Fig.VS-2.8).

+   4. Select the **I have read and accept the license terms** radio button (Fig.VS-2.8).

+   5. Click the **Next** button (Fig.VS-2.8). Microsoft Visual Studio 2010 Ultimate Setup – Options Page appears (Fig.VS-2.9).
