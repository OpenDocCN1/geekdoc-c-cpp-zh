# ## Using the Canvas Control

Consider a situation where you want to place a control at an exact location rather than moving it on the window (or page) or specifying the margins for the control to place it appropriately. In such a situation, you can use the Canvas control, which allows you to place other controls (children controls) at exact or absolute positions inside it. The child controls are positioned by using coordinates with respect to the size of the Canvas control. It is an instance of the Canvas class, which is derived from the Panel class. Table 5.9 lists the noteworthy properties of the Canvas class:

| Property | Description |
|---|---|
| Bottom | Returns or sets a value that indicates the distance between the bottom of the Canvas control and the bottom of the child control |
| Left | Returns or sets a value that indicates the distance between the left borders of the Canvas control and the child control |
| Right | Returns or sets a value that indicates the distance between the right borders of the Canvas control and the child control |
| Top | Returns or sets a value that indicates the distance between the top of the Canvas control and the top of the child control |

![](bbox=[0.209, 0.413, 0.256, 0.446])

> > **The properties listed in Table 5.9 are attached properties and are used by the child controls of the Canvas control.**

Perform the following steps to use the Canvas control in a WPF standalone application:

+   1. Start Visual Studio 2010.
+   2. Select **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. Select **Visual Basic→Windows** from the Installed Templates section in the left pane of the **New Project** dialog box.
+   4. Select the **WPF Application** template in the middle pane to create a WPF standalone application.
+   5. Enter the name of the application as **MyCanvas** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. Click the **OK** button to close the **New Project** dialog box and create the **MyCanvas** application.
+   7. Replace the default code in the XAML view of the **MainWindow.xaml** file with the code given in Listing 5.9:

# **Listing 5.9:** Displaying the Code for the **MainWindow.xaml** File

```
```xml
<Window x:Class="MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MyCanvas Application" Height="250" Width="300">
    <Grid Background="Black">
        <Canvas Name="Canvas1" Height="100" Width="200" Background="LightYellow">
            <Button Name="Button1" Width="50" Height="25" Canvas.Top="15"
                    Canvas.Left="15" Background="Black" />
            <Button Name="Button2" Width="50" Height="25" Canvas.Bottom="15"
                    Canvas.Right="15" Background="Black" />
        </Canvas>
    </Grid>
</Window>
```
```

In Listing 5.9, the Title property of the Window element is set to **MyCanvas Application**. This implies that the text **MyCanvas Application** appears on the title bar of the window. The Window element has a Grid control as its child element that in turn has a Canvas control as its child. The Background property of the Grid control is set to **Black**.
