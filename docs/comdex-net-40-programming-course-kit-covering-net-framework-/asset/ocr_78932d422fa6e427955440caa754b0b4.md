# Executing Commands using a Command Object

After establishing a connection with a database, you can execute commands and obtain results from the database. To access a database, a data command should provide information about the connection, the SQL statement, or the name of the stored procedure to execute. A stored procedure is a set of one or more SQL statements that can be run and stored together in a database.
