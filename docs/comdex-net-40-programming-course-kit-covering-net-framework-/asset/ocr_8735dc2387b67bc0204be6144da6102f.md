In the preceding syntax, `struct` is a keyword indicating that a structure is defined and **structure-name** is the name of the structure being defined.

Perform the following steps to create and use structures:

+   1. **Start Visual Studio 2010.**
+   2. Select **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. Select **Visual C#→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows applications in Visual C# are displayed in the right pane of the **New Project** dialog box.
+   4. Select **Console Application** from the right pane to create a Console application.
+   5. Enter the name of the application as **Structures** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** box.
+   6. Click the **OK** button to close the **New Project** dialog box and create the **Structures** application.
+   7. Add the highlighted code snippets, shown in Listing 2.13, to the **Program.cs** file:

# Listing 2.13: Creating and Using Structures

```
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace Structures
{
    public struct X
    {
        public int a, b, c;
    }
    class Program
    {
        static void Main(string[] args)
        {
            X X1 = new X();
            X1.a = 1;
            X1.b = 2;
            X1.c = 3;
            Console.WriteLine("Data of the X1 object:");
            Console.WriteLine("a = " + X1.a);
            Console.WriteLine("b = " + X1.b);
            Console.WriteLine("c = " + X1.c);
            X X2 = new X();
            Console.WriteLine("Data of the X2 object:");
            Console.WriteLine("a = " + X2.a);
            Console.WriteLine("b = " + X2.b);
            Console.WriteLine("c = " + X2.c);
            Console.ReadLine();
        }
    }
}
```
```

The first highlighted code snippet in Listing 2.13 shows the definition of a structure, X. The X structure contains three int type variables, **a**, **b**, and **c**. In the second highlighted code snippet, we have created an object, X1, of the X structure and assigned the values 1, 2, and 3 to the **a**, **b**, and **c** variables of the X1 object, respectively. After that, we have displayed the values of all the three variables, **a**, **b**, and **c**, on the screen. Next, we have created another object, X2, of the X structure, and also displayed the values of all the three variables, **a**, **b**, and **c**, of the X2 object on the screen.
