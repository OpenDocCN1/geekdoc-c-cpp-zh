# Reference Highlighting

Another small yet significant feature added to the Visual Studio 2010 IDE is the Reference Highlighting feature. Using this feature, you can highlight all the instances of a class, object, variable, method, or property either by clicking or by placing mouse pointer over one of the instances in code editor. You can also navigate between these instances by using the CTRL+SHIFT+DOWN or CTRL+SHIFT+UP arrow keys in combination.

# IntelliSense Suggestion Mode

Visual Studio 2010 has two modes of IntelliSense: completion mode and suggestion mode. The completion mode is the default mode of IntelliSense that works similar to the IntelliSense feature of the previous versions of Visual Studio. In the completion mode, when you start typing the name of a class or class member, the IntelliSense feature tries to automatically complete the name by displaying a list of already defined classes and class members that start with the set of characters you have typed. The new suggestion mode of IntelliSense allows you to change this default behavior and adds the set of characters that you have typed in the list of options displayed. The suggestion mode of IntelliSense is useful in situations where you need to use classes or class members before they are defined. You can enable or disable the suggestion mode by pressing the CTRL+ALT+SPACEBAR keys in combination.
