## Set Operators

Set operators in LINQ refer to the operators that are used to produce a result set based on the presence or absence of the equivalent elements within the same or separate collection. There are various Set operators. Table 7.3 lists all the set operators in LINQ:

**Table 7.3: Set Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
| --- | --- | --- |
| Distinct | Removes duplicate values from a collection | Distinct |
| Except | Removes elements from a collection that are not common to another collection | Not available |
| Intersect | Retrieves common elements from two collections | Not available |
| Union | Retrieves all the elements from two collections, without duplicating an element | Not available |
