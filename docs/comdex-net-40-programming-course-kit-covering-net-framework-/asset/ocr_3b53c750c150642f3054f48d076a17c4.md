```xml
<Window x:Class="MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="MyTextBox Application" Height="250" Width="300">
    <Grid Background="Gray">

            TextWrapping="Wrap" TextAlignment="Center" Background="LavenderBlush"

            Background="LavenderBlush" Content="Clear TextBox"/>
    </Grid>

```
```

In Listing 5.4, the **Title** property of the **Window** element is set to **MyTextBox Application**, which implies that the text **MyTextBox Application** appears on the title bar of the window. The **Window** element has a **Grid** control as its child element. A **TextBox** control is added to the **Grid** control. This control is named as **TextBox1** and has its **CharacterCasing** property set to **Upper**, which implies that all the characters of the text that you enter in the text box appear in uppercase. The **TextWrapping** and **TextAlignment** properties of the **TextBox1** control are set to **Wrap** and **Center**, respectively. This implies that the entered text is wrapped around the text box and is aligned at the center of the text box. Note that another property of the **TextBox1** control, named **VerticalScrollBarVisibility**, which is inherited from the **TextBoxBase** class, is set to **Auto**. This property refers to a value that indicates whether a vertical scroll bar appears in the control. A **Button** control is also added to the **Grid** control and its **Content** property is set to **Clear TextBox**.
```
