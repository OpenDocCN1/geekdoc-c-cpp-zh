# Using the Button Control

The Button control is a very important Standard control that is used for submitting user data to the server by providing a click event. It allows you to perform some tasks, such as submit the user input or navigate to another page from the current page by generating its Click event. The Click event of the Button control is generated when the user clicks the Button control at run time. The Button class is contained in the System.Web.UI.WebControls namespace.
