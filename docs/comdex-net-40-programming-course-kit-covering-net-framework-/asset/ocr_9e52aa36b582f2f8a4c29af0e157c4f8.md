# Using the GridSplitter Control

The GridSplitter control in WPF offers a unique facility by allowing you to redistribute the space between the cells (rows and columns) of a Grid control. With the GridSplitter control, the height and width of the Grid control do not change; only the space between the cells of the grid changes. The GridSplitter control is an instance of the GridSplitter class. Table 5.8 lists the noteworthy properties of the GridSplitter class:

| Property | Description |
|---|---|
| PreviewStyle | Returns or sets the style that customizes the appearance, effects, or other style characteristics for the GridSplitter control preview indicator, which is displayed when the ShowsPreview property is set to True |
| ResizeBehavior | Returns or sets which columns or rows are resized relative to the column or row for which the GridSplitter control is defined |
| ResizeDirection | Returns or sets a value that indicates whether the GridSplitter control resizes rows or columns |
| ShowsPreview | Returns or sets a value that indicates whether the GridSplitter control updates a column or row size as a user drags the control |

Perform the following steps to use the **GridSplitter** control in a WPF standalone application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. *Select* the **WPF Application** template in the middle pane to create a WPF standalone application.
+   5. Enter the name of the application as **MyGridSplitter** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. Click the **OK** button to close the **New Project** dialog box and create the **MyGridSplitter** application.
+   7. *Replace* the default code in the XAML view of the **MainWindow.xaml** file with the code given in Listing 5.8:
