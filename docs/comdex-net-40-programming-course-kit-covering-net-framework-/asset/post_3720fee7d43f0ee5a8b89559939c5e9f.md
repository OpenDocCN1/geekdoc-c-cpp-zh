## Using the CompareValidator Control

The **CompareValidator** control is used to compare the value entered by the user into one input control with the value entered into either other control or an already existing value in the other control. The **CompareValidator** control exists within the **System.Web.UI.WebControls** namespace. The **Operator** property contains various comparison operations, as listed in Table 4.14:

**Table 4.14: Operator Property’s Various Comparison Operations**

| Type | Description |
|---|---|
| Equal | Specifies whether the compared values are equal or not |
| NotEqual | Checks that the values of controls are not equal to each other |
| GreaterThan | Checks for a greater than relationship |
| GreaterThanEqual | Checks for a greater than or equal to relationship |
| LessThan | Checks for a less than relationship |
| LessThanEqual | Checks for a less than or equal to relationship |
| DataTypeCheck | Checks whether the data types for the two controls are valid or not |

The Type property of the **CompareValidator** control is used to obtain or specify the data type of both the comparison values. The default data type of the **CompareValidator** control is **String**. All the values entered in this control are automatically converted into the default data type before the comparison operation is performed.

The following are the different data types that you can use:

- **String**: Refers to the string data type
- **Integer**: Refers to the integer data type
- **Double**: Refers to the double data type
- **Date**: Refers to the date data type
- **Currency**: Refers to the currency data type

Noteworthy properties of the **CompareValidator** class are listed in Table 4.15:

**Table 4.15: Noteworthy Properties of the CompareValidator Class**

| Property | Description |
|---|---|
| ControlToCompare | Sets or gets the input control that you want to compare |
| Operator | Obtains or sets the comparison operation to perform on the values in the input controls |
| ValueToCompare | Obtains or sets a constant value to compare with the value entered by the user in the input control |

In many Web sites, values of two controls are matched with each other to verify the authenticity of the entered value. For example, while creating a new password, you need to enter the password both in the user password and the confirm password text boxes.
