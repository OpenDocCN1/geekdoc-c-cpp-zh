## Creating Dynamic Menus

In a dynamic menu, data is provided by the DataSource controls. To create a functional dynamic menu on a Web page, you need to bind it with a DataSource control, which in turn, collects data from physical data storage, such as XML files or databases.

Now, let’s create an application displaying dynamic menus using XML file as data source by performing the following steps:

1. *Click* **Start→All Programs→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010**.
2. *Select* **File→New→Web Site** from the menu bar.  
   The New Web Site dialog box appears.
3. *Select* **Visual C#→ASP.NET Web Site** in the middle template.

   The **DynamicMenuControl** application is created.
