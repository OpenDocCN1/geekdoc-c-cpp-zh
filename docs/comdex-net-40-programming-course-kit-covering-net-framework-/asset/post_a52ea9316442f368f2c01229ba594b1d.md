Now, let’s discuss constants in Visual Basic 2010.

### Constants

Constants are the names given to the values that do not change during the execution of a program. Declaring a constant is useful when you have to use the same value at several places in the program. After you have declared a value as a constant at one place, you can use the name of the constant instead of the value in the rest of the program, and all the instances of that value can be modified by changing only the value of the constant where it is declared. A constant is declared with the Const keyword, as shown in the following code snippet:

```vb
Const Pi = 3.14159
```

In the preceding code snippet, you have created a constant, named Pi, with the value 3.14159.

After discussing constants, let’s now discuss arrays in Visual Basic 2010.

### Arrays

An array is a set of values that are logically related to each other, such as marks obtained by the students of a class in a particular subject. It enables you to store a set of elements of the same data type. If you do not use an array, you would have to use the same number of variables as the number of elements to be stored. Using an array to store a set of elements is much easier than storing each element inside a different variable, because an array allows declaring a set of elements by using only one name. An array allows you to refer to these related values by the same name and to use a number, called index, to identify individual values. The individual values of an array are called the elements of the array. These elements are stored in the array with the index values starting from 0 to one less than the size of the array.

The syntax to declare an array is as follows:

```vb
Dim Arrayname(upper-bound) As datatype
```

In the preceding syntax, upper-bound is the highest index of the array. The size of the array is one greater than its upper bound.

The code snippet for declaring an array that can hold 10 integer elements is as follows:

```vb
Dim age(9) As Integer
```

In the preceding code snippet, we have created an array, age, which contains 10 elements. The elements of the array are stored in the indexes starting from 0 to 9.

An enumeration is a user-defined data type that is used to assign numbers to names. Enumerations can be declared using the **Enum** keyword at the module, class, structure, procedure, or block level. You can use enumerations to define a set of values that are logically related to each other.

### Introducing the Form Class

A Windows form is an instance of the **Form** class, which is placed inside the **System.Windows.Forms** namespace. A namespace acts as a container for grouping classes of similar types. The class hierarchy for the Form class is given as follows:

```text
System.Object

        System.ComponentModel.Component
            System.Windows.Forms.Control
                System.Windows.Forms.ScrollableControl
```

In the class hierarchy for the Form class, the Object class is the base class for every class in the hierarchy and a class at every level is derived from the class that exists at its next higher level.
