### Listing 1.1: Demonstrating the Use of Operators

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace OperatorExample
{
    class Program
    {
        static void Main(string[] args)
        {
            int Num1 = 20, Num2 = 8, Result1, Result2, Result3, Result4;
            Result1 = Num1 + Num2;
            Console.WriteLine("Result1: " + Result1);
            Result2 = Num1 - Num2;
            Console.WriteLine("Result2: " + Result2);
            Result3 = -1 * 2 + 3 * 4 - 5;
            Console.WriteLine("Result3: " + Result3);
            Result4 = ((1 - 2) + 3) * (4 - 5);
            Console.WriteLine("Result4= " + Result4);
            Console.ReadLine();
        }
    }
}
```

In Listing 1.1, two variables, **Num1** and **Num2**, are declared and initialized with values, 20 and 8, respectively. In addition, four more variables, **Result1**, **Result2**, **Result3**, and **Result4** are declared. Then, addition operator (+) is used to add value stored in **Num1** and **Num2**, and the result of addition is assigned to **Result1**. Next, the value of **Result1** is displayed on the console by calling the **WriteLine()** method of the **Console** class. Note that the + operator in the **WriteLine()** method is used to concatenate the **Result1=** string with the value stored in **Result1**. Similarly, value stored in **Num2** is subtracted from the value stored in **Num1** by using the subtraction operator (-). The result is stored in **Result2**, and displayed on the console.

After this, the -1 * 2 + 3 * 4 − 5 expression is evaluated and the result is assigned to **Result3**. Then, the value stored in **Result3** is displayed on the console. Next, the expression ((-1 * 2) + 3) * (4 − 5) is evaluated. This expression is same as the previous expression having same operators, operands, and order, with the only difference that it uses parenthesis to divide the expression into sub expressions. In this expression, the operator precedence of the multiplication operator (*) is overridden by using parentheses to group the ((-1 * 2) + 3) and the (4 − 5) expressions. The result is assigned to **Result4** and then the value stored in **Result4** is displayed on the console. Finally, we call the **ReadLine()** method of the **Console** class to read the output displayed on the console.

Note that each line in Listing 1.1 ends with a semicolon (;), implying that each of these lines is a statement.

## Exploring Data Types in C# 2010

C# is a strongly typed programming language meaning that every variable or object that you create in a C# program must have a data type (however, with the introduction of the dynamic keyword, it is possible to delay the type resolution till run time). A data type indicates the type of values that a variable or an object can store and the number of bytes that the variable or object occupies in the memory. Depending on the requirements of your program, you can create variables and objects of different data types. For example, if you want to work with numbers, then you can create variables of integer type and if you want to work with text, then you can create variables of string type. ## Value Types

Value types refer to those data types that allow you to directly work with data. When you assign a variable of value type to another variable, the value stored in the first variable is copied and assigned to the second variable. This implies that two copies of the same value exist at two different locations in the memory. In addition, changes made to the value of the second variable do not affect the value of the first variable. A value type has a fixed size, that is, a variable of value type occupies a fixed number of bytes in the memory. Note that if you do not assign any initial value to a variable of value type, then a default value is used as the initial value of the variable.

In C#, there are some predefined value types. Table 1.3 lists the predefined value types in C#:

**Table 1.3: Predefined Value Types in C#**

| Value Type | Description | Range of Values | Default Value |
|---|---|---|---|
| `sbyte` | Represents an 8-bit signed integral data type | -128 to 127 | 0 |
| `byte` | Represents an 8-bit unsigned integral data type | 0 to 255 | 0 |
| `short` | Represents a 16-bit signed integral data type | -32,768 to 32,767 | 0 |
| `ushort` | Represents a 16-bit unsigned integral data type | 0 to 65,535 | 0 |
| `int` | Represents a 32-bit signed integral data type | -2,147,483,648 to 2,147,483,647 | 0 |
| `uint` | Represents a 32-bit unsigned integral data type | 0 to 4,294,967,295 | 0 |
| `long` | Represents a 64-bit signed integral data type | -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 | `0L` |
| `ulong` | Represents a 64-bit unsigned integral data type | 0 to 18,446,744,073,709,551,615 | 0 |
| `float` | Represents a 32-bit single-precision floating-point type | ±1.5 × 10⁻⁴⁵ to ±3.4 × 10³⁸ | `0.0F` |
| `double` | Represents a 64-bit double-precision floating-point type | ±5.0 × 10⁻³²⁴ to ±1.7 × 10³⁰⁸ | `0.0D` |
| `decimal` | Represents a 128-bit decimal type with 28–29 significant digits | (-7.9×10^28 to 7.9×10^28) / (10^0 to 28) | 0.0M |
| `bool` | Represents an 8-bit Boolean data type | true or false | false |
| `char` | Represents a 16-bit Unicode character | U+0000 to U+ffff | `'\0'` |

In Table 1.3, **bool** is a Boolean data type that is used to check the validity of a particular condition in a program. The **sbyte, byte, short, ushort, int, uint, long, ulong,** and **char** data types are integral data types because the variables of these data types hold whole numbers, such as **123, -45,** and **601298**. The **float** and **double** data types are floating-point types as variables of these types store the value in fractions, for example, **123.56** and **-123.45**. The decimal data type is equivalent to a floating-point type but with more precision and smaller range. Therefore, the decimal data type is suitable for use when you need to perform calculations in which truncation beyond the decimal point is not required. By default, a floating-point value is treated as a value of type double. To specify a floating-point value as a float type, you need to suffix the character F (or f) to the value, such as 12.4F. Similarly, to specify a floating-point value to be of decimal type, you need to suffix the character M (or m) to the value, such as 123.45M.

## Enumerations

An enumeration type or enumeration is represented by the **enum** keyword. It is a user-defined value type that provides a list of values called the enumerator list. Each value in the enumerator list is called an enumerator, element, or member and is used to represent an integral constant, which is a value that does not change throughout the execution of a program. By default, the constants that the enumerators represent are of **int** data type; however, they can be of any value type other than the **char** type. By default, the first constant in the enumerator list contains value 0, and value for each of the other constants is determined by incrementing the value of its preceding constant by one.

You can use enumerations when you want to create a variable and specify the possible values that it can store. Consider an example of a traffic light where you can have three possible states: the green (or go) light, the yellow (or warning) light, and the red (or stop) light. In such a case, you can create an enumeration type with three possible values: Red, Yellow, and Green, and then create variables of that enumeration type. Consider the following code snippet that shows how to create an enumeration type:

```csharp
public enum Color { Red = 1, Green, Yellow };
```

In the preceding code snippet, an enumeration type named Color is created by using the **enum** keyword. The **Color** enumeration type defines three possible values—**Red, Green,** and **Yellow**. Note that the **Red** enumerator is given a value of 1, which implies that it represents the constant 1. In addition, the **Green** and **Yellow** enumerators represent the constants 2 and 3, respectively.

To use the **Color** enumeration type, you need to create a variable of the **Color** enumeration type. The following code snippet shows how to use an enumeration type:

```csharp
Color TColor;
TColor=Color.Red;
```
