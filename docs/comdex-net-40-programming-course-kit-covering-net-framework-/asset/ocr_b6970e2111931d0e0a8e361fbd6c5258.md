# ## Describing Types of WPF Applications

WPF is a UI framework, which helps you to create interactive applications. There are various application development features such as controls, graphics, layout, and data binding that are supported by WPF. It is a next generation of UI framework that enables you to develop application with a rich user experience. You can create both Windows and Web applications using the WPF.

WPF applications are mainly of the following two types:

+   - Standalone WPF applications
+   - XAML Browser Applications (XBAPs)

Let's learn about each of these types of applications, one by one.

# ### WPF Standalone Applications

WPF standalone applications are similar to Windows Forms applications as you can install WPF applications on your computer and view them from the **Start** menu. Visual Studio 2010 provides you a project template that you can use to create WPF standalone applications. Some essential files, such as Application.xaml and MainWindow.xaml, are automatically added in your project when you start creating application using the project template.
