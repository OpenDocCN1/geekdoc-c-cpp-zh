## Creating WCF Data Services

WCF Data Service is a Microsoft technology that is used to create and consume data services, which makes it easy to separate the presentation layer from the data layers while working with them. This service provides facilities to query the data in the address bar of a Web browser. Data Services are naturally integrated with Web and enable you to add a query string in the address bar of a Web browser to retrieve data. Let’s create an application to understand the concept of WCF Data Service.

```csharp
using System;
using System.Data.Services;
using System.Data.Services.Common;
using System.Collections.Generic;
using System.Linq;
using System.ServiceModel.Web;
using System.Web;
using NORTHWNDModel;

public class WcfDataService : DataService<NORTHWNDEntities>
{
    // This method is called only once to initialize service-wide policies.
    public static void InitializeService(DataServiceConfiguration config)
    {
        config.SetEntitySetAccessRule("*", EntitySetRights.AllRead);
        config.SetServiceOperationAccessRule("*", ServiceOperationRights.All);
        config.DataServiceBehavior.MaxProtocolVersion =
            DataServiceProtocolVersion.V2;
    }
}
```
