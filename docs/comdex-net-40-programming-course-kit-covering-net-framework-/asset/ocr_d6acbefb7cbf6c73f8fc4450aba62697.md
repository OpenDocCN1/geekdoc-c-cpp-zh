**Table 2.3: Noteworthy Events of Form Class**

| Event | Description |
|---|---|
| Activated | Occurs when the Windows form is activated in the code or by the user |
| Click | Occurs when the form is clicked |
| Closed | Occurs when the form is closed |
| Closing | Occurs when the form is closing |
| DoubleClick | Occurs when the form is double-clicked |
| DragDrop | Occurs when the drag-and-drop operation is completed |
| ForeColorChanged | Occurs when the ForeColor property value changes |
| GotFocus | Occurs when the form receives focus |
| KeyDown | Occurs when a key is pressed, while the form is in focus |
| KeyPress | Occurs when a key is pressed, while the form is in focus |
| KeyUp | Occurs when a key is released, while the form is in focus |
| Load | Occurs before a form is displayed for the first time |
| MouseDown | Occurs when the mouse pointer is over the form and the mouse button is pressed |
| Resize | Occurs when the form is resized |
| SizeChanged | Occurs when the Size property value changes |
| TextChanged | Occurs when the Text property value changes |
