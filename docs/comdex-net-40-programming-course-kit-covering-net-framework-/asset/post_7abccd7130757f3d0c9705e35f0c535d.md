Language-Integrated Query (LINQ) was introduced with .NET Framework 3.5, and is also a component of .NET Framework 4.0. It allows you to query against a data source to generate the requested result set while writing programs for a .NET application. It means that you no longer have to use the Structured Query Language (SQL) to generate the result set from a data source. SQL is a database language, which is used to make the query against the data source and generate the result set according to that query. The syntax of LINQ is similar to the syntax of SQL. LINQ adds native data querying capabilities to .NET Framework and eliminates the need to use a separate query language while developing applications in .NET Framework. You can also create a LINQ query that manipulates a data source to get the desired result set. A LINQ query is a query expression based on numerous query operators designed to work in a manner similar to that of SQL. LINQ defines the set of query operators as the operators used to query, project, and filter data. However, the difference between query operators and query expressions is that unlike query operators, query expressions can be used to interact with numerous types of data. LINQ integrates the query syntax with a program by offering an abstraction layer, which makes it possible to access different data sources in a website.

You can use LINQ query operators to perform tasks, such as retrieving, projecting, and filtering data. LINQ provides a standard and unified way to access and modify data from different data sources and structures. It includes LINQ providers for SQL Server databases, Extensible Markup Language (XML) documents, ActiveX Data Objects .NET (ADO.NET) datasets, and in-memory object collections.

This chapter begins by discussing how to create a simple LINQ query. Then, you learn to work with different types of standard query operators used in LINQ. The chapter further discusses how to implement LINQ to ADO.NET. You also learn to use anonymous types and lambda expressions in LINQ queries. Towards the end, you learn about a new feature added to LINQ—parallel LINQ.

Let’s begin by discussing how to create a simple LINQ query.

### Creating a Simple LINQ Query

A LINQ query is an expression that is used to retrieve and manipulate data from a data source. You can use a LINQ query expression to first specify and then sort or group the related data. LINQ queries are written in a separate query language using the syntax similar to that of SQL. You can use various predefined clauses, such as From, Where, Order By, and Select to create a LINQ query. The basic syntax of a LINQ query starts with the From clause and ends with the Select or Group By clause. In addition, you can use the Where, Order By, and Order By ... Descending clauses to perform additional functions, such as filtering data and organizing data in a specific order.

To create a LINQ query, you first need to obtain the data source from where the LINQ query can get the data. A LINQ query must contain two clauses: From and Select. The From clause specifies the data source and the Select clause specifies the type of result. A LINQ query is executed inside the For Each statement.

Perform the following steps to create a LINQ query:

1. *Start* Visual Studio 2010.
2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
3. *Select* **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows-based applications in Visual Basic are displayed in the middle pane of the **New Project** dialog box.
4. *Select* **Windows Forms Application** in the middle pane to create a Windows Forms application.
5. Enter the name of the application as **LINQQuery** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
6. Click the **OK** button to close the **New Project** dialog box and create the **LINQQuery** application (Fig.VB-7.1).
7. *Drag and drop* a **Label** control, a **Button** control, and a **ListBox** control on the form from the **Toolbox** and set the **Text** properties of the Label control and the Button control to **List of numbers** and **Create List**, respectively by using the **Properties** window, as shown in Fig.VB-7.1.

8. Double-click the Create List button in the form to create the event handler for its Click event and add the highlighted code snippet shown in Listing 7.1 to Code Editor:

**Listing 7.1: Showing the Use of a LINQ Query**

```vb
Private Sub Button1_Click(ByVal sender As System.Object, ByVal e As
    System.EventArgs) Handles Button1.Click
    Dim numbers As Integer() = New Integer(6) {0, 1, 2, 3, 4, 5, 6}
    Dim numQuery = From num In numbers Where (num Mod 2) = 0 Select num
    For Each num As Integer In numQuery
        ListBox1.Items.Add(num.ToString())
    Next num
End Sub
```

The highlighted code snippet in Listing 7.1 shows how to create and use a simple LINQ query. Listing 7.1 uses an integer array, numbers, as the data source for the LINQ query. Then, we create the numQuery query that selects even numbers from the numbers array. Finally, the query is executed within the For Each statement, where the query result set is added to a list box.

### Working with Standard Query Operators

The standard query operators are the methods that form the LINQ pattern. These operators provide querying capabilities, including filtering, projection, aggregation, and sorting. The standard query operators in LINQ are a part of the Application Programming Interface (API), which enables querying of any .NET array or collection. You can use these standard query operators to perform a data querying operation on a sequence of data. Standard query operators differ according to their execution time. The time taken by a query depends on whether the query returns a single value or a sequence of values. The standard query operators that return a sequence of values take more time to return the output in comparison to the operators that return a single value.

Table 7.1 lists all the standard query operators used in LINQ:

**Table 7.1: Standard Query Operators**

| Operator Type | Description |
| --- | --- |
| Sorting operator | Changes the order of elements of a sequence returned by a query |
| Set operator | Returns a result set in the form of a collection based on the presence or absence of elements within the same set or different sets |
| Filtering operator | Restricts the result set to contain the elements that satisfy a specific condition |
| Projection operator | Transforms an object into a different type of new object |
| Partitioning operator | Divides the input sequence into two sections, without rearranging the elements, and returns one section |
| Grouping operator | Puts data into groups such that the elements in each group share a common attribute |
| Join operator | Joins two data sources with objects that share a common attribute in both data sources |
| Quantifier operator | Returns a Boolean value, either True or False, indicating whether all or some of the elements in a given sequence satisfy a specific condition |
| Generation operator | Creates a new sequence of values |
| Element operator | Returns a single, specific element from a collection |
| Conversion operator | Performs data type conversions |
| Aggregate operator | Computes a single value from a collection |
| Equality operator | Checks whether or not two sequences are equal |
| Concatenation operator | Appends one sequence of elements to another |
| Zip operator | Combines two collections into one |

Let’s now learn about all the query operators in each of the operator types listed in Table 7.1 in detail.

#### Sorting Operators

Sorting operators in LINQ arrange the elements of a sequence based on one or more attributes. It means that to use the Sorting operator, you first need to specify a particular attribute and perform primary sorting on the elements. Then you need to specify the second sort criterion and sort the elements within the primary sorted group. There are various sorting operators, which are listed in Table 7.2:

**Table 7.2: Sorting Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
| --- | --- | --- |
| OrderBy | Sorts a set of elements in ascending order | Order By |
| OrderByDescending | Sorts a set of elements in descending order | Order By … Descending |
| ThenBy | Performs a secondary sort on a set of elements, in ascending order | Order By |
