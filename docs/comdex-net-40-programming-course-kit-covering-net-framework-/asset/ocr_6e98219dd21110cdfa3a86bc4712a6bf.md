# ## Visual Basic Statements

A Visual Basic program consists of lines of code known as statements. A statement represents a complete instruction in a program. A Visual Basic statement is generally one of the following two types:

+   - **Declaration statement:** Creates and names a variable, constant, or procedure and specifies a data type, such as Boolean, Byte, Char, and Date, for the elements of a program.
+   - **Executable statement:** Performs an action, such as executing a method or loop in the code or acts as an assignment statement that assigns a value or expression to a variable or constant, such as subject="Math" and marks=82.
