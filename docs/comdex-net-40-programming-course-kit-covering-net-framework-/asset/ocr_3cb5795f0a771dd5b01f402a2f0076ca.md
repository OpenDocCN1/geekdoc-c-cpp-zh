```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace CreatingObjects
{
    class Class1
    {
        private int num1 = 24;
        private int num2 = 36;
        public void Average()
        {
            int av = (num1 + num2) / 2;
            Console.WriteLine("Average: " + av);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            Class1 obj = new Class1();
            obj.Average();
            Console.ReadLine();
        }
    }
}
```
```

The first highlighted code snippet in Listing 2.1 defines a class, Class1. This class contains two variables, num1 and num2, and a method, Average(), to calculate and display the average of the values stored in these variables. In the second highlighted code snippet, we have created an object, obj, of the Class1 class and used that object to call the Average() method of the Class1 class.

# Constructors and Destructors

Constructors and destructors are special types of methods. A constructor is a method that is called when an object of a class is created. It is used to initialize class members whenever a new object of the class is created. The main features of a constructor are as follows:

+   - It has the same name as the name of the class in which it is declared
+   - It does not have any return type, implying it does not return any value
+   - It is always public
+   - A class can have multiple constructors
+   - It is not mandatory to declare a constructor; the default constructor of a class is automatically called when you create a new object of the class
