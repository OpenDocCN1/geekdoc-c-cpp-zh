Language-Integrated Query (LINQ) was introduced with .NET Framework 3.5, and is still present as a component in .NET Framework 4.0. It allows you to query against a data source to generate the requested result set while writing programs for a .NET application. LINQ integrates the query syntax within a program by offering an abstraction layer, which makes it possible to access different data sources in a website. It means that you no longer have to use the Structured Query Language (SQL) to generate the result set from a data source. LINQ adds native data querying capabilities to.NET Framework and eliminates the need to use a separate query language while developing applications in .NET Framework. It provides a standard and unified way to access and modify data from different data sources and structures. It also includes providers for SQL Server databases, Extensible Markup Language (XML) documents, ActiveX Data Objects .NET (ADO.NET) datasets, and in-memory object collections to access data.

A LINQ query is a query expression based on numerous query operators designed to work in a manner similar to that of SQL. Query designed in LINQ manipulates a data source to get the desired result set. LINQ defines the set of query operators to query, project, and filter data. However, the difference between query operators and query expressions is that unlike query operators, query expressions can be used to interact with numerous types of data.

This chapter begins by discussing how to create a simple LINQ query. You also learn to work with different types of standard query operators used in LINQ and implement LINQ to ADO.NET. In addition, you learn to use anonymous types and lambda expressions in LINQ queries. Towards the end, you learn about a new feature added to LINQ—parallel LINQ (PLINQ).

Let's begin by discussing how to create a simple LINQ query.

# ## Creating a Simple LINQ Query

As already learned, a LINQ query is an expression that is used to retrieve and manipulate data from a data source. You can use a LINQ query expression to first specify the related data and then sort or group it. LINQ queries are written in a separate query language using the syntax similar to that of SQL. You can use various predefined clauses, such as *From*, *Where*, *OrderBy*, and *Select*, to create a LINQ query. The basic syntax of a LINQ query starts with the *From* clause and ends with the *Select* or *GroupBy* clause. In addition, you can use the *Where*, *OrderBy*, and *OrderBy ... Descending* clauses to perform additional functions, such as filtering data and organizing data in a specific order.

To create a LINQ query, you first need to obtain the data source from where the LINQ query can get the data. A LINQ query must contain two clauses: *From* and *Select*. The *From* clause specifies the data source and the *Select* clause specifies the type of result. A LINQ query is executed inside the *For Each* statement.
