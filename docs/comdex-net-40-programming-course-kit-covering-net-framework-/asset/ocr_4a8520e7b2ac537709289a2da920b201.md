# Using the ListView and DataPager Controls

The ListView control is a data-bound control that is used to display data from the associated data source. It enables you to display data in any format by using templates and styles. You can select, sort, delete, and insert records in the ListView control. This control resembles the GridView control, except that it displays data in templates instead of fields. You create the templates to give you more flexibility in controlling how you want the data to be displayed in the ListView control.

The ListView class defines several properties and methods that the ListView control supports as it is inherited from this class. Some noteworthy properties of the ListView class are given in Table 6.24:

| Table 6.24: Noteworthy Properties of the ListView Class |  |
|---|---|
| **Property** | **Description** |
| EditItem | Retrieves the item that is in edit mode in a ListView control |
| EditItemTemplate | Retrieves or sets the custom content for the item in edit mode |
| EmptyDataTemplate | Retrieves or sets the user-defined content for the empty template that is rendered when a ListView control is bound to a data source that does not contain any records |
| EmptyItemTemplate | Retrieves or sets the user-defined content for the empty item that is rendered in a ListView control when there are no more data items to display in the last row of the current data page |
| GroupItemCount | Retrieves or sets the number of items to display per group in a ListView control |
| GroupPlaceholderID | Retrieves or sets the ID for the group placeholder in a ListView control |
| GroupSeparatorTemplate | Retrieves or sets the user-defined content for the separator between groups in a ListView control |
| GroupTemplate | Retrieves or sets the user-defined content for the group container in a ListView control |
| ItemTemplate | Retrieves or sets the custom content for the data item in a ListView control |
