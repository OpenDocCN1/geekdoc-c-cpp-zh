
In the preceding expression, if you first add 5 and 3 and then multiply the result by 2, the result will be 16. However, if you first multiply 3 by 2 and then add 5 to the result, the result will be 11. As you can see, the result is different in each case. To avoid such contradictory results, Visual Basic 2010 has its own rules of precedence for all operators supported by the language.

According to the rules of precedence, arithmetic and concatenation operators have higher precedence than comparison and logical operators, and comparison operators have higher precedence than logical operators. However, all comparison operators have equal precedence; that is, they are evaluated in the order they appear in the expression, from left to right.

Arithmetic operators have the highest precedence among all types of operators. The order of precedence of arithmetic operators is as follows:

- Exponentiation (^)
- Unary identity and negation (+, -)
- Multiplication and division (*, /)
- Integer division (\)
- Modulus arithmetic (Mod)
- Addition and subtraction (+, -)

The concatenation operators are given precedence after arithmetic operators:

- String concatenation (+)
- String concatenation (&)
- Arithmetic bit shift (<<, >>)

Comparison operators are given precedence after Arithmetic bit shift operators and are evaluated in the following order:

- Equality (=)
- Inequality (<>)
- Less than, greater than (<, >)
- Greater than or equal to (>=)
- Less than or equal to (<=)
- Is
- IsNot
- Like
- TypeOf

Logical/bitwise operators have the lowest precedence among all Visual Basic 2010 operators. The order of precedence of different logical and bitwise operators, from highest to lowest, is as follows:

- Negation (Not)
- Conjunction (And, AndAlso)
- Inclusive disjunction (Or, OrElse)
- Exclusive disjunction (Xor)

### Working with Selection Statements

Selection statements are statements that change the flow of a program based on whether a specific condition is met or not. - The Select...Case statement

### Using the If...Else Statement

The If...Else statement is used to test whether a certain condition is fulfilled or not. If the condition is fulfilled, the program control is transferred to the blocks of code inside the If statement; otherwise, the program control is transferred to another block of code. The syntax for an If...Else statement is as follows:

```
If condition [ Then ]
    [ statements ]
[ ElseIf condition [ Then ]
    [ elseifstatements ] ]
[ Else
    [ elsestatements ] ]
End If
```

In the preceding syntax, if the condition evaluates to **True**, the statements after the If keyword are executed and ultimately the If statement terminates. If the condition evaluates to **False**, the condition in the **ElseIf** statement is tested and the corresponding block of code is executed. If none of the statements, If and ElseIf, is **True** and the Else statement is present, then the code in the **Else** statement is executed.
