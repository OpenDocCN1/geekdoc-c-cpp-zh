# Properties Window

There are several projects, files, and resources that you work with while developing .NET applications in Visual Studio 2010. These projects and files have various attributes or properties that you can view and set in the Properties window. The Properties window displays the properties of a solution, projects, files, and UI elements of a .NET application.
