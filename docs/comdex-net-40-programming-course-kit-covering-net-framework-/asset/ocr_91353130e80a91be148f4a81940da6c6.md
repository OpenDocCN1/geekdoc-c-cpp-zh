# Using the ComboBox Control

A **ComboBox** displays a list of items in a drop-down list. It is a combination of a text box in which a user can enter an item and a drop-down list from where the user can select an item. A user can select only a single option from the drop-down list. After the user selects an option, the drop-down list contained in the **ComboBox** automatically collapses. You can also add or remove an item from this drop-down list. Each item in a **ComboBox** control is recognized by its position, known as an index, in the drop-down list.
