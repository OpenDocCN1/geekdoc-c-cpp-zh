# Using Anonymous Types

While creating properties in an application, you might need to create a few read-only properties as well. You can encapsulate these read-only properties into a single unit by using anonymous types. An anonymous type provides you an easy way of encapsulating a set of read-only properties into a single unit without defining a new type. Anonymous types are unnamed structure types that you can access by using the var keyword. The anonymous type declaration starts with the new keyword.

> > When you create an application, you cannot use the name of an anonymous type because the name may change when you recompile the application. This is due to the fact that the name of the anonymous type is compiler generated and may vary from compilation to compilation.

Perform the following steps to create and use anonymous types:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File>New>Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual C#>Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows applications in Visual C# are displayed in the right pane of the **New Project** dialog box.
+   4. *Select* **Console Application** from the right pane to create a Console application.
+   5. Enter the name of the application as **AnonymousTypes** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** box.
+   6. Click the **OK** button to close the **New Project** dialog box and create the **AnonymousTypes** application.
+   7. *Add* the highlighted code snippet, shown in Listing 2.14, to the **Program.cs** file.
