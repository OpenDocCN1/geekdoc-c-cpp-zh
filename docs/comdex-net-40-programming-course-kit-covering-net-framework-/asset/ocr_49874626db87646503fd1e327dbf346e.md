# ## Developing Applications in Visual Studio 2010

Visual Studio 2010 provides several project templates to allow you to develop different types of .NET applications. These project templates offer an easy and convenient way of developing .NET applications as they, by default, include the essential files and assemblies required for an application. In Visual Studio 2010, you can develop mainly the following types of applications:

+   - Console applications
+   - Windows Forms applications
+   - WPF applications
+   - Web sites

# ### *Developing a Console Application*

A Console application refers to a .NET application that is command-line based application and does not have graphical User Interface (GUI). The user of a Console application interacts with the application only through the command-line console; that is, the user can read and write characters from the command-line console. This makes Console applications suitable for situations where less user interaction is required. The Console applications are supported by the **System.Console** class that allows you to read the characters from console and write the characters to the console. Visual Studio 2010 provides a project template which offers you an easy way to develop Console applications.

Perform the following steps to develop a Console application in Visual Studio 2010:
