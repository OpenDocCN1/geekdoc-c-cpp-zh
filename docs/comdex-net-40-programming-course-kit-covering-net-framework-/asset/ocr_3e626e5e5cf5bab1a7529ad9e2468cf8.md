# Using Lambda Expressions in LINQ Queries

A lambda expression is a function without a name that calculates and returns a single value. It is defined and executed at the same time. Lambda expressions in LINQ form a base for using many standard query operators used in LINQ. The compiler creates lambda expressions to manipulate the calculations defined in a query, such as Where, Select and Order By. The usage of a lambda expression is similar to a standard function except that it does not match the following features:

+   - Does not have a name
+   - Cannot have modifiers, such as Overloads or Overrides
+   - Does not use the As clause for the return type of the function representing the lambda expression
+   - Has its body as an expression and not a statement
+   - Has no Return statement; rather the value returned by a function is the value of the expression in the body of the function
+   - Does not have an End Function statement
+   - Does not accept generic parameters
