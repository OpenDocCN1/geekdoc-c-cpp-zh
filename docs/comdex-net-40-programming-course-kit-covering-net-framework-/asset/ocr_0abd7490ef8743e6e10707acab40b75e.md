# ## Accessing Members of the Base Class

When a class is derived from a base class, all the members of the base class automatically become the members of the derived class. However, the accessibility of a base class member in the derived class depends on the access modifier with which the member is declared in the base class.

Perform the following steps to access the members of the base class in the derived class:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual C#→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows applications in Visual C# are displayed in the right pane of the **New Project** dialog box.
+   4. *Select* **Console Application** from the right pane to create a Console application.
+   5. *Enter* the name of the application as **AccessingBaseClassMembers** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** box.
+   6. *Click* the **OK** button to close the **New Project** dialog box and create the **AccessingBaseClassMembers** application.
