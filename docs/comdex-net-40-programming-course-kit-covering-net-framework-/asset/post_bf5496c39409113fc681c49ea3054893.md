### Creating a Simple Silverlight Application

Now, you learn to create a Silverlight application. In this application, the GridSplitter control is used so that a user can resize rows and columns of the grid. To create a Web site MyFirstSilverlightApp (also available on the CD), perform the following steps:

1. Open Microsoft Visual Studio 2010 from the start menu.
2. Select File → New → Project, as shown in Fig. ASP-11.14:

    ![](img/9862a98a1a2d3bb14334137965a1ec60_709_0.png)

    Fig. ASP-11.14

    The New Project dialog box appears, as shown in Fig. ASP-11.15:

    ![](img/9862a98a1a2d3bb14334137965a1ec60_709_1.png)

    Fig. ASP-11.15

3. Select **Visual C# → Silverlight** from the *Installed Templates* pane (Fig. ASP-11.15).
4. Select **Silverlight Application** from the middle pane (Fig. ASP-11.15).
5. Specify the name of the application as **MyFirstSilverlightApp** in the *Name* text box (Fig. ASP-11.15).
6. Specify the location where you want to save the application in the *Location* combo box (Fig. ASP-11.15).
7. Click the **OK** button (Fig. ASP-11.15).

    The **New Silverlight Application** dialog box appears (Fig. ASP-11.16).

8. Select the *Host the Silverlight application in a new Web site* check box, as shown in Fig. ASP-11.16:

    ![](img/9862a98a1a2d3bb14334137965a1ec60_710_0.png)

9. Select the **ASP.NET Web Application Project** option from the **New Web** project type drop down box. You can also change your project type from the **New Web** project type drop down box.
10. Select **Silverlight 4** from the **Silverlight Version** drop down box (Fig. ASP-11.16).
11. Select the **Enable WCF RIA Services** check box (Fig. ASP-11.16).
12. Click the **OK** button (Fig. ASP-11.16).
