+   - Supports built-in paging capabilities
+   - Supports built-in row selection capabilities
+   - Allows you to customize its appearance through themes and styles

The **GridView** control exists within the **System.Web.UI.WebControls** namespace and is defined using the **GridView** class. This class defines several properties and methods that the **GridView** control supports. Some noteworthy properties of the **GridView** class are given in Table 6.15:

**Table 6.15: Noteworthy Properties of the GridView Class**

| Property | Description |
|---|---|
| AllowPaging | Retrieves or sets a value indicating whether or not the paging feature is enabled |

| AlternatingRowStyle | Retrieves a reference that allows you to set the appearance of alternating data rows in a **GridView** control |
| AutoGenerateColumns | Retrieves or sets a value indicating whether or not bound fields are automatically created for each field in the data source |
