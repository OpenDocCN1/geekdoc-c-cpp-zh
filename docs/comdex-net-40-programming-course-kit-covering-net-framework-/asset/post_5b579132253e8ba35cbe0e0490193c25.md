## Logical and Bitwise Operators

Logical operators can be defined as operators that are used with expressions and produce a Boolean value. Visual Basic 2010 supports six logical operators: Not, And, Or, Xor, AndAlso, and OrElse. Out of these six operators, the first three operators, that is, Not, And, and Or, when used with a numeric expression, perform bitwise operations; therefore, they are also referred to as bitwise operators. Moreover, the Not operator is called a unary logical operator as it takes only one operand. Other operators (And, Or, Xor, AndAlso, and OrElse) take two operands; therefore, they are called binary logical operators. The AndAlso and OrElse operators are also referred to as short-circuiting operators because they return the value of the second operand based on the value of the first operand.

Let’s now discuss all these operators in detail, one by one.

### The Not Operator

The **Not** operator performs the logical negation operation of an expression that evaluates a Boolean value. It returns a value that is exactly opposite to the value of the operand on which it is applied. For example, if the expression evaluates to **True**, the result, after applying the **Not** operator, is **False** and vice-versa. The following code snippet shows the use of the Not operator:

```vb
Dim X, Y As Boolean
X = Not 5 > 3
Y = Not 2 > 7
```

After executing the preceding code snippet, the Boolean variables X and Y store the Boolean values, **False** and **True**, respectively. As you know, the expression (5>3) evaluates to True; however, when this expression is preceded by the **Not** operator, that is, Not(5>3), the expression returns **False**. Similarly, when the expression (2>7) is preceded by the **Not** operator, that is, Not(2>7), the expression returns **True**. When used as a bitwise operator, the **Not** operator reverses the bit values of a numeric expression, that is, it changes the binary digits from 0 to 1 and 1 to 0.

### The And Operator

The **And** operator is used to perform a logical conjunction of two Boolean expressions. If both the Boolean expressions evaluate to **True**, the final result, after applying the **And** operator, is also **True**. However, if one of the two Boolean expressions evaluates to **False**, the final result, after applying the **And** operator, is also **False**.

The following code snippet shows the use of the And operator:

```vb
Dim X, Y As Boolean
X = 21 > 14 And 15 > 9
Y = 12 > 26 And 24 > 8
```

After executing the preceding code snippet, the Boolean variables, X and Y, store the Boolean values, **True** and **False**, respectively. When used as a bitwise operator, the **And** operator performs a bitwise conjunction of identically positioned bits in two numeric expressions.

### The Or Operator

The **Or** operator is used to perform a logical operation between two Boolean expressions. If both Boolean expressions evaluate to **False**, then the result, after applying the **Or** operator, is also **False**. For all other cases, the result of applying the **Or** operator is **True**. The following code snippet shows the use of the Or operator:

```vb
Dim X, Y As Boolean
X = 10 > 18 Or 5 > 9
Y = 16 > 12 Or 15 > 27
```

After executing the preceding code snippet, the Boolean variables, X and Y, store the Boolean values, **False** and **True**, respectively. When used as a bitwise operator, the **Or** operator performs a bitwise disjunction of identically positioned bits in two numeric expressions.

### The Xor Operator

The **Xor** operator performs the logical exclusion on two Boolean expressions. If only one Boolean expression evaluates to **True**, then the final result after applying the **Xor** operator is **True**. However, if both the Boolean operators evaluate to **False**, the result of applying the Xor operator is **False**. The following code snippet shows the use of the Xor operator:

```vb
Dim X, Y As Boolean
X = 28 > 14 Xor 5 > 9
Y = 25 > 29 Xor 14 > 15
```

After executing the preceding code snippet, the Boolean variables, X and Y, store the Boolean values, **True** and **False**, respectively. When used as a bitwise operator, the **Xor** operator performs a bitwise exclusion of identically positioned bits in two numeric expressions.

### The AndAlso Operator

The **AndAlso** operator works in the same way as the **And** operator. This operator performs the logical conjunction of two Boolean expressions. The difference between the **AndAlso** and **And** operators is that the **AndAlso** operator displays short-circuiting behavior, which means that if the first expression using the **AndAlso** operator evaluates to **False**, the second expression is not evaluated as the value of the second expression is evaluated based on the first expression. The following code snippet shows the use of the AndAlso operator:

```vb
    Dim l As Integer = 17
    Dim m As Integer = 12
    Dim n As Integer = 10
    Dim check, check1, check2 As Boolean
    check = l > m AndAlso m > n
    check1 = m > l AndAlso m > n
    check2 = l > m AndAlso n > m
```

After executing the preceding code snippet, the Boolean variables, **check**, **check1**, and **check2**, store the Boolean values, **True**, **False**, and **False**, respectively. In the case of the **check1** variable, the value of the second expression is not evaluated, as the first expression has been evaluated to **False**. However, in the case of the **check2** variable, the second expression is evaluated.

### The OrElse Operator

The **OrElse** operator performs the short-circuiting logical disjunction of two Boolean expressions. This means that if the first condition in the **OrElse** expression evaluates to **True**, then the second condition is not evaluated and the **OrElse** expression returns **True**. The following code snippet shows the use of the OrElse operator:

```vb
    Dim l As Integer = 17
    Dim m As Integer = 12
    Dim n As Integer = 10
    Dim check, check1, check2 As Boolean
    check = l > m OrElse m > n
    check1 = m > l OrElse m > n
    check2 = m > l OrElse n > m
```

After executing the preceding code snippet, the Boolean variables, **check**, **check1**, and **check2**, store the Boolean values, **True**, **True**, and **False**, respectively. In the case of the **check1** variable, the second expression is not evaluated as the first expression has been evaluated to **True**. However, in the case of the **check2** variable, the second expression is evaluated.

### Miscellaneous Operators

In addition to all the operators discussed so far, some other operators are also used in Visual Basic 2010, called miscellaneous operators. There are five miscellaneous operators in Visual Basic 2010: **AddressOf**, **GetType**, **TypeOf**, **If**, and **Function** expression. These operators are explained as follows:

- **AddressOf**: Obtains the address of a procedure
- **GetType**: Retrieves information about a type
- **TypeOf**: Compares an object reference variable with a data type
- **If**: Returns one of two values, True and False, after performing short-circuit evaluation
- **Function expression**: Declares the parameters and code that define a lambda expression
