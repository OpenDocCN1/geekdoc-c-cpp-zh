# ## Using the PictureBox Control

The **PictureBox** control allows you to display images and graphical data on a form in a Windows Forms application. It supports images of different file formats, such as Windows Bitmap (BMP), Joint Photographic Experts Group (JPEG), Graphics Interchange Format (GIF), and Portable Network Graphics (PNG). The PictureBox class, which is included in the **System.Windows.Forms** namespace, provides the functionality for the PictureBox control. Table 3.17 lists the important properties of the **PictureBox** class:

| Table 3.17: Noteworthy Properties of the PictureBox Class |  |
|---|---|
| **Property** | **Description** |
| BorderStyle | Sets the border style of the PictureBox control |
| ErrorImage | Obtains or sets the image that is displayed, in case the loading of another image failed due to an error or is cancelled |
| Image | Obtains or sets the image that is displayed by the PictureBox control |
| ImageLocation | Obtains or sets the path for the image that is displayed in the PictureBox control |
| InitialImage | Obtains or sets an image that is displayed, while another image is loading |
