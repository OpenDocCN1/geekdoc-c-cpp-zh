## Using Anonymous Types in Queries

Anonymous types in LINQ provide a convenient way to group a set of read-only properties into an element that you want to include in a query result. You do not need to define the type for these properties because it is defined by the compiler. These types enable you to create objects of a class, without writing the class definition. Such classes have no name and are, therefore, called anonymous types. Anonymous types enable you to select any combination of available fields in a query and in any order, without defining a named data type for any element.

The compiler constructs an anonymous type dynamically and assigns a name to it. The name changes each time you build an application and, therefore, the name of an anonymous type cannot be used directly in the application.

Anonymous types in LINQ are used in query expressions to combine the columns of data selected by a query. They enable you to write a query that selects any number of columns and in any order.

## Using Lambda Expressions in LINQ Queries

A lambda expression is a function without a name that calculates and returns a single value. It is defined and executed at the same time. Lambda expressions in LINQ form a base for using many standard query operators used in LINQ. The compiler creates lambda expressions to manipulate the calculations defined in a query, such as Where, Select, and Order By. The usage of a lambda expression is similar to a standard function except that it does not match the following features:

- Does not have a name
- Cannot have modifiers, such as Overloads or Overrides
- Does not use the As clause for the return type of the function representing the lambda expression
- Has its body as an expression and not a statement
- Has no Return statement; rather the value returned by a function is the value of the expression in the body of the function
- Does not have an End Function statement
- Does not accept generic parameters
