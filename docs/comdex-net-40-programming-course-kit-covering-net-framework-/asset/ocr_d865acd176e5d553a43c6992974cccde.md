# Using the While...End While Statement

The While...End While statement continues to execute a set of statements as long as a given condition is True. The While statement always checks the condition before executing the statements within the loop. When the control reaches the End While statement, the control is passed back to the While statement. If the condition is still True, the statements within the loop are executed; otherwise, the loop exits. The syntax of the While...End While statement is as follows:

```
```text
while condition
    [ statements ]
    [ Exit while ]
        [ statements ]
End
```
```

In the preceding syntax, the statements enclosed in the While statement are executed repeatedly till the condition is True. You can also terminate a While statement any time with an Exit While statement.

Perform the following steps to use a While...End While statement in a Console application:

+   1.  *Start* Visual Studio 2010.
+   2.  *Select* File→New→Project from the menu bar. The New Project dialog box appears.
+   3.  *Select* Visual Basic→Windows from the Installed Templates section in the left pane of the New Project dialog box.
+   4.  *Select Console Application* from the middle pane to create a Console application.
+   5.  *Enter* the name WHILE in the Name text box and an appropriate location for the application in the Location combo box.
+   6.  *Click* the OK button to close the New Project dialog box. The WHILE application (also available on the CD) is created.
+   7.  *Add* the highlighted code snippet, shown in Listing 1.5, to the Module1.vb file:

Listing 1.5: Writing the While...End While Statement

```
```vb
Module Module1
    Sub Main()
        Dim Counter As Integer = 1
        Console.WriteLine("Iterations using While...End While statement")
        While Counter < 10
            Console.WriteLine(Counter)
            Counter += 1
        End While
        Console.ReadLine()
    End Sub
End Module
```
```

In Listing 1.5, we have created a variable, Counter, of the Integer type and assigned a value of 1 to it. The While statement checks the condition whether the value of the Counter variable is less than 10. If it is, the value of the Counter variable is displayed on the screen and then the value of the Counter variable is incremented by 1. The loop continues to execute till the value of the Counter variable is less than 10.
