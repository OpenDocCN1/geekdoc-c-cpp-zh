| Event | Description |
|---|---|
| **WebPartsConnecting** | Occurs during the process of establishing a connection between the WebParts controls placed in a WebPartZoneBase zone. |
| **WebPartsDisconnected** | Occurs during the termination of the connection between two WebParts or server controls. |
| **WebPartsDisconnecting** | Occurs during the process of terminating the connection between previously connected WebParts or server controls. |

You can insert the WebPartManager control on the Design view of the Web Form by performing the following steps:

+   1. **Click** Start→All Programs→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010.
+   2. **Select** File→New→Web Site from the menu bar.
+      The New Web Site dialog box appears.
+   3. **Select** Visual C#→ASP.NET Web Site in the middle templates pane.
+   4. **Set** the name of the Web site as **WebpartmanagerControl**.
+   5. **Click** the **OK** button.
+      The **WebpartmanagerControl** application is created.
+   6. **Drag and drop** the WebPartManager control from the WebParts tab in the Toolbox.

# Using the CatalogZone Control

The **CatalogZone** control is a control that provides a catalog on the Web page from where an end-user makes a choice. It makes Web sites more personalized so that the end-users are able to manage the WebPartsControls in a more structured manner. The **CatalogZone** control resides within the `System.Web.UI.WebControls.WebParts` namespace.
