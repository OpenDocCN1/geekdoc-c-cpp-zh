As shown in Fig.ASP-11.1, Silverlight has two main components:

+   - **.NET Framework for Silverlight**: Refers to an abstract version of the Common Language Runtime (CLR), which offers basic functionalities, such as type checking, debugging, and garbage collection. It also allows you to integrate data in Silverlight applications through XML, LINQ, and LINQ to XML (XLINQ) as well as manipulate the data through serialization. The .NET Framework in Silverlight also enables you to easily access data and services at remote locations through WCF.
+   - **The core presentation Framework**: Refers to a component that offers features and services for designing the UI of Silverlight applications through controls, styles, templates, 2D vector graphics, animations, and multimedia. This component also allows you to accept user input through input devices, such as mouse and keyboard. It also enables you to bind data with various controls and specify the UI layout of Silverlight applications. The XAML parser is also present in the core presentation Framework to process the XAML content in Silverlight applications.

# Installing Silverlight 4.0 Tools

You can create **Silverlight** applications by using a text editor, such as **Notepad**. However, various tools, such as **Visual Studio 2010** and **Expression Studio**, provide an efficient way of creating **Silverlight** applications because these tools contain the essential files and functionalities required to create a **Silverlight** application. Among various tools, **Visual Studio 2010** is the best choice to create a **Silverlight** application as in **Visual Studio 2010**, you can create a **Silverlight** application using any **.NET Framework** language.

When you install **Visual Studio 2010**, it provides a built-in support for **Silverlight 3.0** to create a **Silverlight** application. However, if you want to create applications using **Silverlight 4.0** (which is the latest version), you need to install **Silverlight 4.0 Tools**. It is an add-on for **Visual Studio 2010** that provides a toolkit for **Silverlight 4.0** and **RIA** services. After installing **Silverlight 4.0 Tools**, both **Silverlight 3.0** and **Silverlight 4.0** are included in **Visual Studio 2010**.
