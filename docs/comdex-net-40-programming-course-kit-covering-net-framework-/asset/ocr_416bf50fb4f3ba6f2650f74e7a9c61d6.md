Windows Forms controls are controls that you add to your Windows Forms applications. You can use these controls to take input from the user or display some information to the user. In other words, a control is used to facilitate interaction between the user and the application. Controls are associated with certain properties, methods, and events that make them suitable to perform a particular action. Visual Basic 2010 provides you a number of controls that enable you to accept input from the user or display output to the user. These controls are available in the Toolbox of Visual Studio 2010 Integrated Development Environment (IDE). You can provide good visual interface to the user by positioning, designing, and aligning the controls on the Windows form.

The chapter begins with a discussion on the **Control** class. You also learn to work with some commonly used Windows Forms controls, including **Label, TextBox, Button, RadioButton, CheckBox, ComboBox, ListBox, GroupBox, Panel, PictureBox, Timer,** and **ProgressBar** controls.

Let's begin by discussing the Control class.

# Introducing the Control Class

The Control class is the base class for all the Windows Forms controls and it belongs to the **System.Windows.Forms** namespace. The inheritance hierarchy of the Control class is given as follows:

```
System.Object
    System.MarshalByRefObject
        System.ComponentModel.Component
            System.Windows.Forms.Control
```

In the preceding inheritance hierarchy, you can notice that the **Object** class is the base class for all the classes in the .NET Framework class library. The Control class is derived from the Component class, which is inherited from the **MarshalByRefObject** class.

All the Windows Forms controls inherit the common properties, methods, and events of the **Control** class. Table 3.1 lists the important properties of the Control class:

**Table 3.1: Noteworthy Properties of the Control Class**

| Property | Description |
|---|---|
| Anchor | Obtains or sets the edges of the parent control to which the child control is bound and determines how the control is resized with respect to the size of its parent control |
| BackColor | Obtains or sets the background color of the control |
| BackgroundImage | Obtains or sets the background image of the control |
| CausesValidation | Obtains or sets a value specifying whether the control validates any control that require validation when it receives focus |
| Controls | Obtains or sets a collection of controls contained within the control |
| Dock | Obtains or sets a value to indicate which control borders are docked to its parent control and determines how a control is resized with respect to the size of its parent control |
| Enabled | Obtains or sets a value to indicate whether the control can respond to user interaction |
| Font | Obtains or sets the font of the text displayed within the control |
| ForeColor | Obtains or sets the foreground color of the control |
| HasChildren | Returns a value specifying whether the control contains child controls |
| Height | Obtains or sets the height of the control in pixels |
| Name | Obtains or sets the name of the control |
| Size | Obtains or sets the height and width of the control in pixels |
| TabIndex | Obtains or sets the tab order of the controls in its container, such as Form |
