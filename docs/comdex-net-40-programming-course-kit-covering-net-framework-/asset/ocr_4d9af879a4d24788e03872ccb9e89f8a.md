# Using the QueryExtender Control

The QueryExtender control is a data-bound control that helps in retrieving only those records from a database that meet the specific criteria. In other words, the QueryExtender control filters the records. Filtering of records helps in displaying the records in various ways on the Web page without affecting the dataset. Table 6.32 lists noteworthy properties of the QueryExtender control.

| Table 6.32: Noteworthy Properties of the QueryExtender Class |  |
|---|---|
| **Property** | **Description** |
| `ClientIDMode` | Generates the ClientID property for the control |
| `EnableViewState` | Decides whether the control save its view state automatically or not |
| `TargetControlID` | Saves the id of the target control |
