In Listing 5.6, the Title property of the Window element is set to MyTextBlock Application. This implies that the text MyTextBlock Application appears on the title bar of the window. The Window element has a Grid control as its child element that in turn contains a TextBlock control. The Text property of the TextBlock control represents the text that appears on the control. The Foreground and Background properties of the TextBlock control are set to White and Black, respectively. This implies that the text in the TextBlock control is displayed in the white color, whereas, the background of the control is displayed in the black color. The FontSize and FontWeight properties of the control are set to 17 and Bold, respectively, to make the text display large. In addition, the TextWrapping and TextAlignment properties are set to Wrap and Center, respectively. This implies that the text (if it spans multiple lines) is wrapped around the TextBlock control and is displayed in the center of the TextBlock control.
