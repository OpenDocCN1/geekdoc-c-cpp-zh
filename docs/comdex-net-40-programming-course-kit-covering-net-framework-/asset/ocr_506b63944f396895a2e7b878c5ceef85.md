# **Join Operators**

Join operators in LINQ are used to join objects in one data source with the objects that share a common attribute in another data source. For example, suppose there are two columns in a table, one containing the first name and the second containing the last name. In such a case, you can use the join operator to join the first name with the last name and display the values jointly. Table 6.8 lists all the join operators in LINQ:

**Table 6.8:** Join Operators in LINQ

| Operator | Description | Query Expression Syntax (C#) |
| --- | --- | --- |
| Join | Combines elements from two data sources based on matching keys and returns pairs of values | join ...in...on...equals... |
| GroupJoin | Combines elements from two data sources based on matching keys and groups the results | join ...in...on...equals...into... |
