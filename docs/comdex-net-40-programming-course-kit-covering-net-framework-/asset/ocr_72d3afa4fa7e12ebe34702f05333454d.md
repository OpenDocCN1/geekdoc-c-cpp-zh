In ASP.NET 4.0, a new feature has been introduced in which you can create either an empty project or a project already having some layout and functionalities. Whenever you open a new Web site, the New Web Site dialog box appears, as shown in Fig.ASP-1.3:

![](bbox=[0.299, 0.455, 0.724, 0.656])

Fig.ASP-1.3

This implies that the New Web Site dialog box (Fig.ASP-1.3) now contains the following two options:

+   - **ASP.NET Web Site:** Creates a new Web site, which includes the following:
+     - A single folder that contains the membership pages, client script files, and CSS files
+     - A data folder (App_Data)
+     - A master page file (Site.Master)
+     - Two Web pages: Default.aspx and About.aspx
+     - A global application file, Global.asax
+     - A configuration file, web.config
+   - **ASP.NET Empty Web Site:** Creates a new Web site that includes only the web.config file and no other file or folder. You need to manually add pages, files, and folders required to create a simple Web site.
