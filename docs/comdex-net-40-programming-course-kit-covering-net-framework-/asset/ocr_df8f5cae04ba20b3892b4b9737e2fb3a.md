Windows Phone Developer Tools provide the following tools:

+   - **Visual Studio 2010:** Refers to a user-friendly, easy-to-use IDE that enables you to develop Windows Phone 7 applications. Visual Studio IDE provides you various features, such as phone based designer, Windows Phone project templates, set of controls that support Windows Phone, manifest generation, and debugger. These features allow you to create Silverlight or XNA Framework applications within Visual Studio that run on Windows Phone.
+   - **Expression Blend:** Allows you to design graphically rich and interactive Silverlight-based applications for Windows Phone 7. It facilitates you to create XAML-based interfaces that can be further extended by specifying the application logic in Visual Studio.
+   - **Windows Phone Emulator:** Provides you with an imaginary environment for developing, debugging, and testing applications. It is integrated with Visual Studio and Expression Blend to make the Windows Phone application development easier. It allows you to develop the phone applications without any requirement of a phone device to test or debug the application. It also supports for Graphics Processing Unit (GPU) emulation that is required to support game applications created on XNA Framework. A GPU is a graphics coprocessor that is used to compute the graphics related functions, such as transformations, lighting effects, and animations.
+   - **XNA Game Studio:** Provides you with an integrated design environment for developing more advanced and exciting games that can run on Microsoft Windows, the Microsoft Xbox 360 video game and entertainment system, Microsoft Zune, and Windows Phone. XNA Game Studio also includes the XNA Framework that contains a set of managed libraries that allow you to create game applications.

# ## Cloud Services

The cloud service is a service that is used to build cloud applications. These are the applications that can be accessed remotely through the Web and are managed from the central locations. The advantage of cloud application is that it enables you to use it without installing it on a device. It reduces the maintenance and support cost of the application as compared to those applications that are not developed using the cloud service. In .NET Framework 4.0, the cloud service or applications can be created by using the Windows Azure platform. This platform provides Windows Azure (cloud operating system), SQL Azure (cloud database), .NET services, and Live services. The Phone applications created using cloud services enhance the power and features of a Phone device as these applications are capable of accessing data on the phone.

The following are the different runtime services that can be used by the cloud services to access different Web services:

+   - **Notification Service:** Enables you to manage the flow and communication between users, applications, and different services. These notifications are generated by the cloud services accessed through a client API. These notifications let the users know that a particular task has been performed on the device.
+   - **Location Service:** Allows the applications to access the actual location information about the device. It uses different sources, such as Wi-Fi, Cellular, and GPS, to get the information about the location.
+   - **Identity, Feeds, Social, and Maps Services:** Allows consumers to communicate with different communities, receive the data feeds, and use maps for navigation.
+   - **Windows Azure Platform:** Provides Windows-based compute and storage service for cloud applications. The motive of the Windows Azure platform is to help developers build cloud services according to requirements. This platform also provides Internet scale infrastructure for deploying distributed applications and services. Visual Studio 2010 can be used to develop cloud service and can deploy it on the Azure platform.
