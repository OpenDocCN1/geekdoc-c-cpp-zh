# Using the ImageButton Control

The **ImageButton** control is used to display images that respond to a mouse click at run time. The **ImageButton** class is contained in the `System.Web.UI.WebControls` namespace. An **ImageButton** control is same as a normal **Button** control with the difference that in an **ImageButton** control, you can put an image, instead of text, on the button.

Noteworthy properties of the **ImageButton** control are listed in Table 2.8:

| Property | Description |
|---|---|
| `Enabled` | Obtains or sets a value indicating whether or not the `ImageButton` control can be clicked to perform a post back to the server |
| `PostBackUrl` | Obtains or sets the URL of the page to post from the current page when the `ImageButton` control is clicked |
| `ValidationGroup` | Obtains or sets the group of controls for which the `ImageButton` control causes validation when it posts back to the server |

The noteworthy event of the **ImageButton** control is listed in Table 2.9:

| Event | Description |
|---|---|
| `Click` | Occurs when the `ImageButton` is clicked. This event causes the page to be posted back to the server. |

Let’s follow these steps to see how to use the **ImageButton** control:

+   1. *Open* **Visual Studio 2010**.
+   2. *Select* **File > New > Web Site** from the menu bar. The New Web Site dialog box opens.
+   3. *Select* **Visual C#** from Installed Templates pane of the New Web Site dialog box.
+   4. *Select* **ASP.NET Web Site** in the right pane of the New Web Site dialog box.
+   5. *Specify* the location and name of the application in the Web location combo box. In this case, we have provided the name as **ImageButtonExample**.
+   6. *Click* the **OK** button to save all the settings. The **ImageButtonExample** application is created (also available on the CD) (Fig.ASP-2.12).
+   7. *Click* the **Design** tab to view the design of the Default.aspx page (Fig.ASP-2.12).
