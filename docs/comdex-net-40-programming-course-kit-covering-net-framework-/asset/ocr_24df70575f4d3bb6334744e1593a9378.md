# ### **Using ClickOnce**

ClickOnce is a deployment technique that is simpler and easier for both the end-users and the developers. The applications deployed using ClickOnce are not only self-updating but they also help in reducing the extent of user-interaction. In other words, ClickOnce allows you to deploy self-updated Windows and Console applications that can be installed, updated, and run from a Web site, a network share, or a Compact Disk (CD) or Digital Versatile Disk (DVD).

To deploy an application using the **ClickOnce** deployment technique, you need to first publish the application. Publishing refers to the process of deploying an application on one computer and installing it on other computers irrespective of whether a user is online or offline. In simple words, publishing makes the Windows application available on a Web server for installation. You can publish the application on the Web, a network share, or a CD or DVD. Let's perform the following steps to deploy an application, named **PictureBoxControl** (also available on the CD) using **ClickOnce**:

+   1. *Open* **Microsoft Visual Studio 2010**.
+   2. *Select* **File**→**Open**→**Project/Solution** from the menu bar to open the **Open Project** dialog box.
+   3. *Select* the application in your system that you want to open for deployment. In this case, we have selected the **PictureBoxControl** application that we created in Chapter 3, Windows Forms Controls-I, in the Visual Basic section of the book.
