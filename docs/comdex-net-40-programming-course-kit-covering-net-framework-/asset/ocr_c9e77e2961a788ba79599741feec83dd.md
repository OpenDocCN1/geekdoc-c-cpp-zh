Perform the following steps to use the **CheckBox** control in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the Installed Templates section in the left pane of the **New Project** dialog box.
+   4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **CheckBoxControl** (also available on the CD) in the Name text box and an appropriate location for the application in the Location combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **CheckBoxControl** application is created (Fig.VB-3.17).
+   7. *Drag and drop* a **Label** control and four **CheckBox** controls from the Toolbox on the Form1 form.
+   8. *Set* the **Text** property of the **Label** control to **Select the vehicle(s) owned by you:** by using the Properties window.
+   9. *Set* the Text properties of the first, second, third, and fourth CheckBox controls to **Cycle, Scooter, Motorcycle,** and **Car**, respectively, by using the Properties window. After setting the properties, the form appears, as shown in Fig.VB-3.17:

+   10. *Double-click* the **Cycle** check box and *add* the following highlighted lines of code to the Code Editor:

```
Private Sub CheckBox1_CheckedChanged(ByVal sender As System.Object, ByVal e As
    System.EventArgs) Handles CheckBox1.CheckedChanged
        If CheckBox1.Checked = True Then
            MsgBox("You have selected: 'Cycle'.")
        End If
End Sub
```

In the preceding code snippet, **CheckBox1_CheckedChanged** is an event handler that handles the **CheckedChanged** event of the **CheckBox** control, CheckBox1. This implies that when CheckBox1 is selected by the user at runtime, the code written inside the CheckBox1_CheckedChanged event handler is executed. The highlighted lines of code in the preceding code snippet check whether the Checked property of CheckBox1 is set to True, and if it is, then set the message in the **MsgBox** to **You have selected: 'Cycle'.**
