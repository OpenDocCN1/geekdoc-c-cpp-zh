# ## Using the Panel Control

Similar to the **GroupBox** control, the **Panel** control is also used to group other controls. However, there are two major differences between the **GroupBox** control and the **Panel** control. The first difference is that the **Panel** control has scroll bars; whereas, the **GroupBox** control does not have. Another difference is that the **Panel** control does not display a caption; whereas, the **GroupBox** control does. You can use panels to divide a form into a set of regions based on the different tasks performed on the form and place controls used to perform a particular task inside one panel. When you move a panel at design time, all the controls contained in that panel also move.
