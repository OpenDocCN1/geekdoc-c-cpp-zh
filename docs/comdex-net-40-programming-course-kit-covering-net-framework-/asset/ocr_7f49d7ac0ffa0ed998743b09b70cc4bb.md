# The Generate From Usage Feature

The Generate From Usage feature allows you to generate the code for any undefined class, constructor, method, property, field, or enumerator. You can generate the code without leaving the current code. It reduces the interruption of work. While working in Visual Basic, you can use the Generate from Usage feature by first clicking an undefined method, then pressing the CTRL keys on the keyboard, and finally clicking a link that appears in the context menu, as shown in Fig.VS-2.30:
