In our Web site, we have used four **LinkButton** controls to help the user change the mode of the Web page. Various modes of a Web page are:

+   - **Browse:** Refers to the default view of a Web page in which a user can view all the changes made to the content and layout of the Web page
+   - **Design:** Allows the end users to rearrange the components within or outside the Web Partzone
+   - **Catalog:** Allows the end users to restore the Web Parts controls, which were removed earlier
+   - **Edit:** Allows the end users to edit a Web Part, such as changing the Web Part’s title, color as well as properties

Once an end user has personalized the Web Parts controls, the changes can be seen in the Browse mode. Also, if the end user closes the Web page, then on the next visit to the Web site, the user is presented with the personalized Web page.
