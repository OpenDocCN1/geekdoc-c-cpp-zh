The members of the **MessageBoxOptions** enumeration are given in Table 2.9:

| **Table 2.9: Members of the MessageBoxOptions Enumeration** | |
|---|---|
| **Member** | **Description** |
| RightAlign | Specifies that the message box text is right-aligned. |
| RtlReading | Specifies that the message box text is displayed with the right-to-left reading order. |
| ServiceNotification | Displays the message box on the active desktop when a service makes a call notifying the user of an event. The function displays a message box on the current active desktop, even if no user is logged on to the computer. |
| DefaultDesktopOnly | Displays the message box on the active desktop which is similar to the ServiceNotification member, except that the system displays the message box only on the default desktop of the interactive window station. |

Perform the following steps to create a message box by using the **MessageBox.Show** function:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The New Project dialog box opens.
+   3. *Select* Visual Basic→**Windows Forms** from the **Installed Templates** section in the left pane of the New Project dialog box.
+   4. *Select* **Windows Forms Application** in the middle pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **MESSAGEBOXAPPLICATION** (also available on the CD) in the name text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **MESSAGEBOXAPPLICATION** application is created, (Fig.VB-2.55).
+   7. *Add* a **Button** control and a **TextBox** control to the form from the Toolbox and resize them, (Fig.VB-2.56).
