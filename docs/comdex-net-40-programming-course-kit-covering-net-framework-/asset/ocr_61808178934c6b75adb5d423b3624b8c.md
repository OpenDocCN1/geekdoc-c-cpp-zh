# Class View Window

The Class View window enables you to view items, such as assemblies, namespaces, classes, properties, and methods referenced or used in the current .NET application in a hierarchical manner. The Class View window has two panes—Objects pane and Members pane, as shown in Fig.VS-2.28:

![](bbox=[0.448, 0.205, 0.696, 0.334])

Fig.VS-2.28

In Fig.VS-2.28, you see that the upper half of the Class view window is the Objects pane and the lower half is the Members pane. In the Objects pane, the projects of a solution form the top-level nodes of the hierarchical display. The child nodes of the project nodes represent the classes and namespaces used in the project. When you select a node in the Objects pane of the Class View window, the properties and methods of the class are displayed in the Members pane.

> > You can open the Class View window by selecting the View->Class View option from the menu bar or by pressing the CTRL+SHIFT+C keys on the keyboard.

# The Navigate To Feature

Navigating to a specific symbol or file in the source code has become easier in Visual Studio 2010 with the Navigate To feature. You can use this feature to search for a symbol, variable, word, phrase, or file in the source code of an application. To use the Navigate To feature, you need to open the Navigate To dialog box by pressing the CTRL and, keys on the keyboard. This incremental search feature is especially beneficial when you are not sure of what you are looking for in the source code. For instance, when you enter a symbol, variable, word, or phrase in the Search terms combo box of the Navigate To dialog box, the Navigate To feature immediately starts displaying the results, based on the term that you have entered.
