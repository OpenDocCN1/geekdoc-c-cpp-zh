Perform the following steps to develop a stand-alone WPF application in Visual Studio 2010:

+   1. Click **Start**→**All Programs**→**Microsoft Visual Studio 2010**→**Microsoft Visual Studio 2010** to start Visual Studio 2010.

+   2. Click **File**→**New**→**Project** from the menu bar (Fig.VS-2.35). The New Project dialog box appears, as shown in Fig.VS-2.47.

![](bbox=[0.29, 0.24, 0.7, 0.46])

Fig.VS-2.47

+   3. Select **Visual Basic**→**Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box (Fig.VS-2.47). The project templates available for developing Windows-based applications in Visual Basic are displayed in the right pane of the New Project dialog box.

+   4. Select **WPF Application** in the right pane to create a WPF application (Fig.VS-2.47).

+   5. Enter an appropriate name for the WPF application in the **Name** text box (Fig.VS-2.47). In our case, we have entered **FirstWPFApplication** (also available on the CD) as the name of the application.

+   6. Enter the location of the folder for creating the WPF application in the **Location** combo box (Fig.VS-2.47). In our case, we have entered **D:\Books\Comdex\Code\Chapter 2** folder as the location.

+   7. Click the **OK** button (Fig.VS-2.47). The **FirstWPFApplication** application is created, as shown in Fig.VS-2.48.
