+   - **Self-Tracking Entities:** Refers to the entities that are able to track their own changes while working with n-tier applications. These changes are saved to a database. The .NET Framework 4.0 introduces T4 template to generate self-tracking entities.
+   - **Model-First Development:** Allows you to create your own EDM and then generate Transact-SQL (T-SQL) and customized code (relational model) database from that EDM with matching tables and relations.
+   - **Built-in Functions:** Enables you to use built-in SQL Server functions, such as date and time functions, directly in your queries.
+   - **Better N-Tier Support:** Supports Application Programming Interfaces (API’s) and templates to facilitate easier development of n-tier applications with the Entity Framework.

# ### Data Providers

A data provider is used to establish connection with a database, retrieve data from the database, store data in a dataset, read the data, and finally update the database. The data provider increases performance of applications without compromising on functionality.

Table 4.1 lists the different types of data providers included in ADO.NET:

| Data Provider | Description |
|---|---|
| .NET Framework Data Provider for SQL Server | Provides access to Microsoft SQL Server 7.0 or advanced version by using the **System.Data.SqlClient** namespace. |
| .NET Framework Data Provider for OLE DB | Provides access to databases exposed to OLE DB by using the **System.Data.OleDb** namespace. |
| .NET Framework Data Provider for ODBC | Provides access to databases exposed to ODBC by using the **System.Data.Odbc** namespace. |
| .NET Framework Data Provider for Oracle | Provides access to Oracle Database 8.1.7 or advanced versions by using the **System.Data.OracleClient** namespace. |

A data provider mainly contains the following four objects:

+   - **Connection:** Establishes connection with a database. The base class for all the **Connection** objects is the **DbConnection** class. The Connection objects contain methods to open and close connections.
