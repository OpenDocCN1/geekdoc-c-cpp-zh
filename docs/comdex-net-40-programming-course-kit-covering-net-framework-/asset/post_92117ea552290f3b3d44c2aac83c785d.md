### Introducing SQL

SQL is the standard language used for accessing and manipulating data stored in databases. A **database**, as discussed earlier, is a structured collection of records or data so that you can easily access, manage, and update the data. In a database, data is stored in the form of tables. Tables store data in the form of rows and columns. Each column of a table represents a different attribute termed as a field. Each row stores entries for all the attribute values for a single record. These records can be sorted, indexed, updated, and organized easily by writing the different SQL query statements. SQL provides separate statements for inserting new records, updating records, and creating new tables and datasets. A dataset is an in-memory representation of data.

If you are working with SQL in C# 2010, you can use SQL statements to access and modify the data in databases. In our case, we work on a database named **northwind**. This database contains different tables, such as the **Customers** table, which has different fields (such as **CustomerID** and **Address**), the **Orders** table, which has fields (such as **OrderID**), and the **OrderDetails** table, which has fields (such as **Quantity**).

Let’s learn about the basics of SQL.

### The SELECT Statement

The SELECT statement is used to retrieve values for some or all the fields of a table. For example, you can write the following SQL statement to retrieve all the records from the Customers table by using the wildcard character `*`:

```sql
SELECT * FROM Customers
```

The preceding SQL statement returns all the records from the **Customers** table. You can also use the SELECT statement to retrieve values of specific fields of a table. For example, you can retrieve values from the **CustomerID**, **Address**, and **City** fields of the Customers table by using the following SQL statement:

```sql
SELECT CustomerID, Address, City FROM Customers
```

The preceding statement returns the values of the **CustomerID**, **Address**, and **City** fields of the **Customers** table.

### The WHERE Clause

In SQL, you can use the WHERE clause to specify criteria to retrieve the records. For example, to retrieve all the records from the Customers table, where the value of City field is London, you can use the WHERE clause, as shown in the following SQL statement:

```sql
SELECT * FROM Customers WHERE City = 'London'
```

As shown in the preceding SQL statement, we have used the = (equal to) operator to specify criteria in the WHERE clause. In addition to the = operator, you can use the following operators in the WHERE clause:

- `<` (less than)
- `<=` (less than or equal to)
- `>` (greater than)
- `>=` (greater than or equal to)
- `BETWEEN`
- `IN`
- `LIKE`

The comparison operators, such as `<` and `>`, are used in the same way as the `=` operator. Now, let’s see how to use the BETWEEN, IN, and LIKE operators.

### The BETWEEN Operator

You can use the BETWEEN operator to access values that lie in a specified range. For example, if you want to select all the records from the Customers table, where the first letter of the CustomerID field is between R and T (which includes the letters R, S, and T), you can use the BETWEEN operator, as shown in the following SQL statement:

```sql
SELECT * FROM Customers WHERE CustomerID BETWEEN 'R' AND 'T'
```

### The IN Operator

In SQL, you can use the IN operator to match the values for a given field of a table with a set of specified values. For example, to select those records for which the City field has a value of London, Sao Paulo, or Madrid, you can use the IN operator, as shown in the following SQL statement:

```sql
SELECT * FROM Customers WHERE City IN ('London', 'Sao Paulo', 'Madrid')
```

### The LIKE Operator

The LIKE operator is used to match the values of a field in a table with some specified pattern. You can use the wildcard character % to specify the pattern. For example, to select all the records from the Customers table, where the City field matches the wildcard string Lo%, you can use the LIKE operator, as shown in the following SQL statement:

```sql
SELECT * FROM Customers WHERE City LIKE 'Lo%'
```

The preceding SQL statement selects all the records for which the City field contains names that match with the pattern Lo%, such as London. The three possible combinations of using the wildcard character % are as follows:

- `Lo%`: Matches the values starting with Lo, such as London or Los Angeles
- `%Lo`: Matches the values ending with Lo, such as São Paulo
- `%Lo%`: Matches the values containing Lo, such as Barcelona
