
## Partitioning Operators

Partitioning operators in LINQ are used to divide an input sequence into two sections, without rearranging the elements, and then returning the result set with one of the sections that satisfies the given condition. Table 6.6 lists all the partitioning operators in LINQ:

| Operator | Description | Query Expression Syntax (C#) |
| --- | --- | --- |
| Skip | Skips the specified number of elements in a collection and returns the rest of the elements | Not available |
| SkipWhile | Skips elements in a collection as long as a specified condition is true, and then returns the rest of the elements | Not available |
| Take | Retrieves the specified number of elements from a collection | Not available |
| TakeWhile | Retrieves elements from a collection as long as a specified condition is true | Not available |

## Grouping Operators

Grouping operators in LINQ are used to put data into groups so that the elements in each group share a common attribute. Table 6.7 lists all the grouping operators in LINQ:

| Operator | Description | Query Expression Syntax (C#) |
|---|---|---|
| **GroupBy** | Groups the elements of a collection based on a shared attribute | group ... by or group ... by ... into... |
| **ToLookup** | Creates a Lookup data structure, which contains key-value pairs, from a collection of objects | Not available |

```csharp
private void button1_Click(object sender, EventArgs e)
{
    string[] words = new string[10];
    for (int index = 0; index < 10; index++)
    {
        words[index] = listBox1.Items[index].ToString();
    }
    var query = from w in words
                group w by w[0] into g
                select new { FirstLetter = g.Key, Words = g };
    listBox1.Items.Clear();
    foreach (var q in query)
    {
        listBox1.Items.Add("Words beginning with letter:"
            + q.FirstLetter.ToString());
        foreach (var w in q.Words)
        {
            listBox1.Items.Add(w);
        }
    }
}
```
