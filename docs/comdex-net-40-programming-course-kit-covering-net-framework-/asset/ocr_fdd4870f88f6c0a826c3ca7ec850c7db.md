# Solution Explorer

A solution explorer is a window in Visual Studio 2010 IDE that allows you to view and manage all the items of a .NET application in a single solution. A solution acts as a container that contains one or more projects, all the files, references and other resources used in the application. The solution displays all the projects and files, in the solution explorer window, in a hierarchical manner.

+   - **Refresh button:** Refreshes Solution Explorer
+   - **View Code button:** Allows you to switch from the designer to code editor
+   - **View Designer button:** Allows you to switch from code editor to the designer
