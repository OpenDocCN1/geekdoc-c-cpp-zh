# Using the TreeView control

The **TreeView** control, introduced with Silverlight 3.0, is used to display the hierarchical data in the form of nodes. A node that contains child nodes in a **TreeView** control can be collapsed and expanded. You can click any node of a TreeView control to collapse it or expand it. The **TreeView** control is a specialized **ItemsControl** control, which means that you can populate the **TreeView** control with some content by either setting its **Items** property or the **ItemsSource** property.
