# # Working with Resources and Styles

Consider a situation where you want to apply the same background color on several controls in a WPF application. You can set the **Background** property of all those controls; however, this may prove to be rather tedious and time-consuming. Therefore, to simplify the use of such common properties, you can specify them as resources in the WPF application. A resource refers to an object, element, or value(s) that can be used by multiple controls or elements in the application.

You can define resources for any control or element; however, it is advisable to define the resources on the root element, such as the **Window** or **Page** element. The resource that you define for an element also applies to all the child elements of the element. For example, if you define a resource for a **Window** element with a **Grid** element as its child, then the resource for the **Window** element applies to the **Grid** element also. Furthermore, if you define a resource for the **Grid** element, then that resource also applies to its child elements.

> > **Suppose, you have a WPF standalone application with multiple windows and you want to apply a resource to all the windows, then you need to define the resource in the Application.xaml file of the application.**

You can define a resource on an element by using the **Resources** property of the element. The **Resources** property refers to the resource dictionary, which is a collection of resources defined on a particular control or element. With the **Resources** property, you can define as many resources as you want on an element. Every resource that you define on an element must have a unique key, which refers to a string that uniquely identifies the resource in the resource dictionary. The unique key is assigned to a resource by using the **x:Key** attribute. The basic syntax to define a resource on an element is given as follows:

```
```xml
<elementName>
    <elementName.Resources>
        <resourceName x:Key="keyName" />
    </elementName.Resources>
</elementName>
```
```

+   In the preceding syntax:
+   
+   - **elementName**: Refers to the name of the element on which the resource is defined
+   - **elementName.Resources**: Refers to the **Resources** property of the element
+   - **resourceName**: Refers to the name of the resource that is defined
+   - **x:Key**: Refers to the **x:Key** attribute of the resource
+   - **keyName**: Refers to the unique key name of the resource

After you define a resource, you can use it by referencing it as the value for properties of other elements. The syntax to reference a resource after it is defined is given as follows:

```
```xml
<elementName propertyName="{markupExtension keyName}">
    <content>...
</elementName>
```
```

+   In the preceding syntax:
+   
+   - **elementName**: Refers to the name of the element that uses the resource
+   - **propertyName**: Refers to the name of the property that takes its value from the resource
+   - **markupExtension**: Refers to the name of the markup extension
+   - **keyName**: Refers to the key name of the resource

Depending on the markup extension used to reference a resource, there are two types of resources—static and dynamic.
