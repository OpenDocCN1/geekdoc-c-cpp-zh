# ***Showing and Hiding Forms and Controls***

You can make a form or control visible or invisible at run time by setting its **Visible** property. The default value of this property is True. You can set the value of the Visible property of the form or control to False if you want to hide the form or control.

Perform the following steps to show or hide forms or controls:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The New Project dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the Installed Templates section in the left pane of the **New Project** dialog box.
+   4. *Select* **Windows Forms Application** in the middle pane to create a Windows Forms application.
+   5. Enter the name of the application as **SHOWHIDE** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **SHOWHIDE** application is created, displaying only one form, **Form1** (Fig.VB-2.38).
+   7. *Add* another form, **Form2**, to the current project in this application.
+   8. *Add* two Button controls, **Button1** and **Button2**, to **Form1**, as shown in Fig.VB-2.39:
