the functionality for the **ComboBox** control. Table 3.11 lists the important properties of the **ComboBox** class:

| Table 3.11: Noteworthy Properties of the ComboBox Class | |
|---|---|
| **Property** | **Description** |
| DrawMode | Obtains or sets a value indicating whether the code or the operating system handles the drawing of elements of the list |
| DropDownHeight | Obtains or sets a value to specify the height of the drop-down portion of a combo box |
| DropDownStyle | Obtains or sets a value to specify the style of the combo box |
| DropDownWidth | Obtains or sets a value to specify the width of the drop-down portion of a combo box |
| DroppedDown | Obtains or sets a value indicating whether the drop-down list of the ComboBox control is displayed |
| IntegralHeight | Obtains or sets a value indicating whether the ComboBox control resizes itself to completely display its items |
| ItemHeight | Obtains or sets a value to specify the height of an item in the ComboBox control |
| Items | Obtains a collection of items available in the ComboBox control |
| MaxDropDownItems | Obtains or sets a value to specify the maximum number of items that can be displayed in the drop-down list of the ComboBox control |
| MaxLength | Obtains or sets a value to specify the maximum number of characters that can be entered in the editable text field of the ComboBox control |
| SelectedIndex | Obtains or sets the index of the currently selected item |
| SelectedItem | Obtains or sets the currently selected item |
| SelectedText | Obtains or sets the currently selected text in the editable text field of the ComboBox control |
| Sorted | Obtains or sets a value indicating whether the items in the ComboBox control are alphabetically sorted in the ascending order |

Table 3.12 lists the important methods of the **ComboBox** class:

| Table 3.12: Noteworthy Methods of the ComboBox Class | |
|---|---|
| **Method** | **Description** |
| BeginUpdate | Maintains the performance of the ComboBox control by preventing flickers when items are added to the control. It does not paint the control until the EndUpdate method is called. |
| EndUpdate | Resumes painting the ComboBox control, after painting is suspended by the BeginUpdate method. |
| FindString | Finds the first item in the ComboBox control that starts with the specified string. |
| FindStringExact | Finds the first item in the ComboBox control that exactly matches the specified string. |
| GetItemHeight | Returns the height, in pixels, of a particular item in the ComboBox control. |
| ResetText | Resets the text in the editable text field of the ComboBox control. |
| Select | Selects a range of text in the editable text field of the ComboBox control. |
| SelectAll | Selects all the text in the editable text field of the ComboBox control. |

Perform the following steps to use the **ComboBox** control in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* File→New→Project from the menu bar. The New Project dialog box opens.
