# Using the Code-Behind File

Another way to implement data binding in WPF is to set the properties directly on the Binding object in code. You can call the SetBinding() method directly in your application to bind the control in code. The following code snippet shows how to implement binding in a WPF application using the code-behind file:

```
`this.MyText.SetBinding(TextBlock.TextProperty, Binding1);`
```

In the preceding code snippet, we have bound the Text property of the TextBlock control to the Binding1 data source.

Perform the following steps to implement data binding in WPF using the code-behind file by creating a Windows Forms application named UsingCodeBehindFile (also available on the CD):

+   1. Open **Microsoft Visual Studio**.
+   2. Select **File→New→Project** from the menu bar. The **New Project** dialog box appears.
+   3. Select **Visual C#→Windows** in the **Installed Templates** pane of the **New Project** dialog box.
+   4. Select **WPF Application** in the middle pane of the **New Project** dialog box.
+   5. Enter **UsingCodeBehindFile** as the name of the application in the **Name** text box.
+   6. Enter the complete path where you want to save the application in the **Location** combo box.
+   7. Click the **OK** button in the **New Project** dialog box to close it. The **UsingCodeBehindFile** application is created.
+   8. Set the title of **MainWindow** to **Binding using code-behind file** by using the **Title** property.
+   9. Add the code, given in Listing 5.10, to the **MainWindow.xaml** file:
