Forms are the basic building blocks of Windows applications and serve as a Graphical User Interface (GUI) to facilitate user interaction. In contrast to Console applications that use Command Prompt to get input from and display output to the user, Windows applications use forms to interact with the user. You can create a Windows application in any language that is supported by Common Language Runtime (CLR), such as Visual Basic and Visual C#. Visual Studio 2010 provides you with different types of controls, such as **Button**, **Label**, **TextBox**, **RadioButton**, and **ListBox** to help you make your Windows applications more functional and user-friendly. You can easily drag and drop different controls from the Toolbox and can arrange them structurally on a form. Controls allow you to input data in a form, for instance, you can enter your name, age, and other personal details in the specified TextBox controls on a form. You can add any number of Windows forms to your application and connect them with each other by using various controls such as Button control.

This chapter begins by discussing the **Form** class. Then, you learn to perform some basic operations on forms, such as setting the title of a form, setting the initial state and position of a form, adding controls to a form, docking and anchoring controls, and resizing and moving forms and controls at run time. You also learn to create message boxes, input boxes, and dialog boxes. In addition, you learn to handle mouse and keyboard events. Towards the end, you learn how to add comments to the code in a Windows forms application.

Let's begin by discussing the Form class.

# Introducing the Form Class

A Windows form is an instance of the **Form** class, which is placed inside the **System.Windows.Forms** namespace. A namespace acts as a container for grouping classes of similar types. The class hierarchy for the Form class is given as follows:

```
```text
System.Object
    System.MarshalByRefObject
        System.ComponentModel.Component
            System.Windows.Forms.Control
                System.Windows.Forms.ScrollableControl
                    System.Windows.Forms.ContainerControl
                        System.Windows.Forms.Form
```
```

In the class hierarchy for the Form class, the Object class is the base class for every class in the hierarchy and a class at every level is derived from the class that exists at its next higher level.

Noteworthy properties of the Form class are given in Table 2.1:

| Property | Description |
|---|---|
| AcceptButton | Gets or sets the button on the Windows form that is clicked when the user presses the ENTER key |
| ActiveControl | Gets or sets the active control present on the Windows form (the control that currently has focus) |
| ActiveMdiChild | Gets the currently active multiple document interface (MDI) child window |
| AutoScroll | Indicates whether the form implements auto scrolling |
| BackColor | Gets or sets the background color of the current form |
| BackgroundImage | Gets or sets the background image in the current form |
| CancelButton | Indicates the button control that is clicked when the user presses the Esc key |
| CanFocus | Indicates whether the form can receive focus |
| ContextMenuStrip | Gets or sets the ContextMenuStrip control associated with the current form |
| ControlBox | Gets or sets a value indicating whether or not a control box is displayed |
| Controls | Gets or sets the collection of controls contained within the form |
