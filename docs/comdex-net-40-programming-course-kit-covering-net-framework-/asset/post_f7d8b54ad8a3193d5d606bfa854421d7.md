### Working with the TreeView Control

The TreeView control is a navigation control that is used in Web applications to display the location of different Web pages in a tree structure. This control is used in Web pages to enable the user to view the structure of the Web application by traversing its nodes. In ASP.NET applications, you can use the TreeView control for representing the data accessed from an XML file or a database and arranging it logically for the user of the Web application. The TreeView class of the .NET Framework defines the properties of the TreeView control. This class is defined in the System.Web.UI.WebControls namespace. The TreeView control has the following four types of nodes:

- **Root:** Represents the top-level node in the tree
- **Parent:** Represents parent nodes, which have child nodes shown as branches of the parent nodes
- **Child:** Contains its parent nodes
- **Leaf:** Contains no child nodes

The data displayed on these nodes can be filled by using the **DataSource** property, which binds the control with data, of the TreeView control.

Validation controls are the in-built controls, provided by ASP.NET, that help you to perform validations on your data at client side. In other words, validation controls are controls that are used to validate the data entered in an input control, such as the textbox of a Web page. Validations can be set on an input control by associating it with a validation control and then specifying some properties for the validation control. Validation controls ensure that the values entered in a control are validated against a specified condition or criteria. For example, you cannot enter a string value in a TextBox control, if it is validated to accept only integer values. As the validation is performed at the client-end only, it reduces the load on the server by eliminating the need to send every piece of data to the server for validation.

When a user enters invalid data in an associated control, the validation control displays an error message on the screen. The data entered by a user is validated each time it is entered, and the error message disappears only when the data is found valid. Validation controls help in saving time and enhancing the efficiency of the applications by validating the data before a request is sent to the server. The BaseValidator class is the base class of all the validation controls.

In this chapter, you learn about all the validation controls provided by ASP.NET, such as CompareValidator, CustomValidator, RangeValidator, RegularExpressionValidator, RequiredFieldValidator, and ValidationSummary. The chapter also discusses the important properties of the validation controls as well as to implement them in your Web application.

Now, before exploring the different validation controls, let’s discuss the **BaseValidator** class.

### Introducing the BaseValidator Class

The **System.Web.UI.WebControls.BaseValidator** class is the base class for all validation controls. The inheritance hierarchy of the **System.Web.UI.WebControls.BaseValidator** class is given as follows:

```
        System.Web.UI.WebControls.WebControl
            System.Web.UI.WebControls.Label
                System.Web.UI.WebControls.BaseValidator
```
