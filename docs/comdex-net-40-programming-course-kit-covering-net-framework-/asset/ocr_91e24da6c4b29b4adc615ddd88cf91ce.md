# Training Kit for Programming Fundamentals, Visual Basic 2010, C# 2010, and ASP.NET 4.0

No previous programming experience required.

+   - **Visual Basic 2010:** Covers working with Windows Forms and its controls, Windows Presentation Foundation 4.0, Windows Workflow Foundation 4.0, and LINQ, which includes the new concept of PLINQ
+   - **C# 2010:** Covers the use of Object Oriented Programming concepts, the new concept of Dynamic Programming, how to bind data to .NET 4.0 applications, how to handle errors and exceptions, and the working of LINQ queries
+   - **ASP.NET 4.0:** Covers the use of Web controls in developing a Web site, use of Master Pages and Themes in a Web site, how to develop Web and WCF Service, and how to develop Silverlight 4.0 applications
+   - **Additional Information:** Covers advanced concepts of .NET 4.0, such as deploying a Windows or Web application and implementing mobile programming in .NET 4.0
