The Login control is made up of the following combination of standard ASP.NET controls:

- **User Name label and textbox:** Displays text for the user name textbox. The user name textbox accepts the user name used to authenticate the user during the login process.
- **Password label and textbox:** Displays text for the password textbox, which accepts the password entered by the user. The password textbox is always encrypted to prevent the user password from being displayed in plain text.
- **Validators:** Validates the user name and password textboxes.
- **Remember me check box:** Specifies whether or not the user details should be remembered, if the user logs on to the Web site next time by using the same computer.
- **Failure text literal:** Displays a message, if the login attempt by the user fails.
- **Login button:** Submits a user request for authentication.
