The Choose a Command Type page displays the following three options:

+   - **Use SQL statements:** Enables the data adapter to use a SQL statement to populate a table in a dataset. This option is by default selected.
+   - **Create new stored procedures:** Creates a new stored procedure to read and update a table in a database.
+   - **Use existing stored procedures:** Enables the data adapter to use an existing stored procedure to read and update a table in a database.

In our case, we are keeping the default option, **Use SQL statements**, selected.
