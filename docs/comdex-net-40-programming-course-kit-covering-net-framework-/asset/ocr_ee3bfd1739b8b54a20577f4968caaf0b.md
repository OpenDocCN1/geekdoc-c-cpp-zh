# The SqlDataSource Control

The SqlDataSource control enables you to work with ADO.NET managed data providers that provide access to a Microsoft SQL Server database. It is inherited from the SqlDataSource class that defines several properties and methods that the SqlDataSource control supports. Some noteworthy properties of the SqlDataSource class are given in Table 6.1.

**Table 6.1: Noteworthy Properties of the SqlDataSource Class**

| Property | Description |
|---|---|
| ConnectionString | Retrieves or sets the ADO.NET provider-specific connection string that the SqlDataSource control uses to connect to an underlying database |
| SelectCommand | Retrieves or sets the SQL string that the SqlDataSource control uses to retrieve data from the underlying database |
| InsertCommand | Retrieves or sets the SQL string that the SqlDataSource control uses to insert data into the underlying database |
| DeleteCommand | Retrieves or sets the SQL string that the SqlDataSource control uses to delete data from the underlying database |
| UpdateCommand | Obtains or specifies the SQL string that the SqlDataSource control uses to update data in the underlying database |

Table 6.2 lists the noteworthy methods of the SqlDataSource class:

**Table 6.2: Noteworthy Methods of the SqlDataSource Class**

| Method | Description |
|---|---|
| Databind | Binds a SQL data source to the SQL Server DataSource control |
| Select | Retrieves the records or data from a SQL Server database |
| Insert | Inserts the records or data into a SQL Server database |
| Delete | Deletes the records or data from a SQL Server database |
| Update | Updates the records or data in a SQL Server database |

The SqlDataSource class represents the SqlDataSource control that enables you to work with Microsoft SQL Server. This datasource control is helpful in retrieving data from a relational database, such as SQL server, in the data-bound controls, such as the GridView control. The SqlDataSource control supports sorting, filtering, and paging data when the data is returned in a control. Let’s learn how to use the SqlDataSource control in a Web site by performing the following steps:

+   1. *Click* **Start→All Programs→Microsoft Visual Studio 2010→Microsoft Visual Studio 2010**.
+   2. Select **File→New→Web Site** from the menu bar.
+      The New Web Site dialog box appears.
+   3. *Select* **Visual C#→ASP.NET Web Site** from the middle templates pane.
+   4. *Set* the name of the Web site as **SqlDataSourceControl**.
+   5. *Click* the **OK** button.
+      The SqlDataSourceControl application is created.
+   6. *Drag* and drop the **SqlDataSource** control from the Toolbox on the **Default.aspx** page.
