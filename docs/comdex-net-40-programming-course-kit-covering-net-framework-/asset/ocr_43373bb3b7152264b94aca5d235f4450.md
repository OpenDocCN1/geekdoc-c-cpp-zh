# Listing 7.23: Handling the Click Event of the Button1

```
Private Sub Button1_Click(ByVal sender As System.Object, ByVal e As
System.EventArgs) Handles Button1.Click
    Dim persons(6) As String
    For index = 0 To 6
        persons(index) = ListBox1.Items(index)
    Next
    Dim query = From p In persons.Where(Function(n) n.StartsWith("S")) Select p
    For Each q In query
        ListBox2.Items.Add(q.ToString())
    Next
End Sub
```

Listing 7.23 shows the code for the event handler of the Click event of Button1. In the highlighted code snippet, we first declare an array of String type, persons, and initialize the array with the items in the ListBox1 control. Then, we create a LINQ query in which we use a lambda expression to retrieve the names starting with letter 'S' from the persons array. Finally, we add the retrieved names to the Items collection of the ListBox2 control, by using a For Each loop.
