# Working with Data-Bound Controls

The data-bound controls in ASP.NET are the controls that can be bound to a datasource control to make it easy to display and modify data in a Web application. You can work with a data-bound control by binding it to a datasource control, such as the SqlDataSource control or the LinqDataSource control. The datasource controls enable you to connect to a database and then retrieve and update data, which is then used by the data-bound controls. You need to set the DataSourceID property of the data-bound control to point to a datasource control.
ASP.NET 4.0 provides various built-in data-bound controls, which are as follows:

+   - GridView
+   - DataList
+   - DetailsView
+   - Repeater
+   - ListView
+   - DataPager
+   - Chart
+   - QueryExtender

The Chart and QueryExtender controls are the two new data access controls introduced in ASP.NET 4.0. Now, let’s learn about each of the data-bound controls in detail.

# Using the GridView Control

The GridView control is a data-bound control that binds to and displays the data from a datasource control in the form of a table. In this table, each column represents a field and each row represents a record. You can perform various functions, such as selecting, sorting, editing, and deleting data in the GridView control. This control provides the following features:

+   - Supports built-in sorting capabilities
+   - Supports built-in updating and deleting capabilities
