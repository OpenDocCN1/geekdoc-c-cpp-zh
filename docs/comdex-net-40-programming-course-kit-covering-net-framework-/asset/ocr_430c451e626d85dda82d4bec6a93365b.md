# ## Complex Data Binding

As discussed, complex data binding enables binding of a control to more than one data element, such as more than one record in a database. Some of the controls that support complex data binding are **DataGridView**, **ComboBox**, **ListBox**, and **CheckedListBox**. Complex data binding can be performed using the following properties:

+   - **DataSource:** Represents the data source, typically a dataset.
+   - **DataMember:** Represents the data member you want to work with, in the data source, typically a table in a dataset, such as the Customers table in your northwind database. The **DataGridView** control uses this property to determine which table to display.
+   - **DisplayMember:** Represents the field you want a control to display, such as the customer’s ID. The **ListBox** control uses the **DisplayMember** and **ValueMember** properties instead of a **DataMember** property for data binding.
+   - **ValueMember:** Represents the field or a table that is returned by a control’s properties

Now, let’s learn to use the DisplayMember and ValueMember properties.

# ### The DisplayMember and ValueMember Properties

In C#, controls such as the **ComboBox** and **ListBox** support the **DisplayMember** and **ValueMember** properties (along with the **DataSource** property) to accomplish complex data binding.
