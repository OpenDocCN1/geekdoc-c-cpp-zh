
## Filtering Operator

Filtering refers to an operation that modifies a result set according to the specified condition in such a manner that it contains only those elements that satisfy a specified condition. Table 6.4 lists all the filtering operators in LINQ.

Table 6.4: Filtering Operators in LINQ

| **Operator** | **Description** | **Query Expression Syntax (C#)** |
|---|---|---|
| OfType | Selects those values from a set of values that can be converted to a specified type | Not available |
| Where | Selects those values from a set of values that satisfy a given condition | where |

## Projection Operators

Projection operators refer to the operators that transform an object into a new form; the new form generally consists of properties that will be used subsequently. The new form into which the objects are transformed is of a new type. Table 6.5 lists all the projection operators in LINQ:

| Operator | Description | Query Expression Syntax (C#) |
|---|---|---|
| Select | Projects (or selects) values from a single sequence or collection | select |
| SelectMany | Projects (or selects) values from multiple sequences or collections | Use the select clause with multiple from clauses |

Perform the following steps to project a sequence of words by using the select clause:

```csharp
private void button1_Click(object sender, EventArgs e)
{
    string[] words = new string[5];
    for (int index = 0; index < 5; index++)
    {
        words[index] = listBox1.Items[index].ToString();
    }
    var query = from w in words select w.Substring(0, 1);
    foreach (string letter in query)
    {
        ListBox2.Items.Add(letter);
    }
}
```

In the preceding code, we have first declared an array of string type, words, and initialized the array with the items in the **ListBox1** control. After that, we have used the select clause in a LINQ query to select the first letter of all the elements of the array. Finally, we have added the set of letters to the Items collection of the **ListBox2** control.
