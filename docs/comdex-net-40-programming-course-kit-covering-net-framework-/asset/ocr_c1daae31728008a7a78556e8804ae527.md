Let’s create an application to see an example of a run-time error and the way to fix it by performing the following steps:

+   1. *Start* **Visual Studio 2010**.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual C#→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box. The project templates available for developing Windows-based applications in C# are displayed in the right pane of the **New Project** dialog box.
+   4. *Select* **Windows Forms Application** in the right pane to create a Windows Forms application.
+   5. Enter the name of the application as **Runtime_Errors** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **Runtime_Errors** application is created (Fig.C#-7.7).
+   7. *Select* the Form1 and press the **F4** key to open the **Properties** window of Form1 (Fig.C#-7.7).
+   8. Set the **Text** property of the **Form1** form to **Runtime Error** (Fig.C#-7.7).

9. *Double-click* the **Form1** form and add the code snippet, given in Listing 7.3, in Code Editor:

```
```csharp
private void Form1_Load(object sender, EventArgs e)
{
    int result, ct1, ct2 = 0;
    ct1 = 4;
    result = ct1 / ct2;
    MessageBox.Show("The result is " + result.ToString());
}
```
```

In Listing 7.3, you can see that three **int** type variables, **result**, **ct1**, and **ct2** have been declared. Further, the result of the division of the **ct1** variable by the **ct2** variable is stored in the **result** variable, which is finally displayed through a message box.

+   10. Press the **F5** key to execute the application. You will get a **run-time error**, which highlights the line of code where the error has occurred, as shown in Fig.C#-7.8.
