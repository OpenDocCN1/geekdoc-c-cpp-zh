Perform the following steps to use the **PrintDialog** and **PrintDocument** controls in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File → New → Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic → Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **PrintingControls** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **PrintingControls** application is created (Fig.VB-4.62).
+   7. *Drag and drop* a **Label** control, a **TextBox** control, and a **Button** control on the form from the **Toolbox**.
+   8. *Set* the **Text** properties of the **Label** control and the **Button** control to **Enter text:** and **Print**, respectively, by using the **Properties** window.
+   9. *Set* the **Multiline** property of the **TextBox** control to **True** by using the **Properties** window and then resize the **TextBox** control to accommodate multiple lines of text.
+   10. *Drag and drop* a **PrintDialog** control and a **PrintDocument** control on the form from the **Printing** tab of the **Toolbox**. Both these controls are added to the component tray, as shown in Fig.VB-4.62.
