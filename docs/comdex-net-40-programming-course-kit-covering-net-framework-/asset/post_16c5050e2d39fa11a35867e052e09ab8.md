## Partitioning Operators

Partitioning operators in LINQ are used to divide an input sequence into two sections. When a partition is completed, this operator does not rearrange the elements in the input sequence. Finally, it returns the result set with one of the sections that satisfies the given condition.

Table 7.6 lists all the partitioning operators in LINQ:

**Table 7.6: Partitioning Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
|---|---|---|
| Skip | Skips the specified number of elements in a collection and returns the rest of the elements | Skip |
| SkipWhile | Skips elements in a collection as long as a specified condition is true, and then returns the rest of the elements | Skip While |
| Take | Retrieves the specified number of elements from a collection | Take |
| TakeWhile | Retrieves elements from a collection as long as a specified condition is true | Take While |

## Grouping Operators

For example, there is a set of fruit names and you want to divide all the fruit names into groups according to their first letter. In this situation, you can use the Grouping operator.

Table 7.7 lists all the grouping operators in LINQ:

**Table 7.7: Grouping Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
| --- | --- | --- |
| GroupBy | Groups the elements of a collection based on a shared attribute | Group ... By ... Into ... |
| ToLookup | Creates a lookup data structure, which contains key-value pairs, from a collection of objects | Not available |
