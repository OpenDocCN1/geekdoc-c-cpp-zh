# ## Using the throw Statement

You can raise exceptions in an application by using the throw statement. The exception thrown can be handled within the try-catch-finally statement. The syntax of a throw statement is as follows:

```
throw [expression]
```

In the preceding syntax, expression refers to the information about the exception to be thrown. A throw statement without any expression can only be used within a catch statement, wherein the throw statement re-throws the exception, currently being handled by the catch statement.

Let’s create an application to learn how to use the throw statement, by performing the following steps:

+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
