# Using the ViewBox Control

The ViewBox control is also a new control introduced in Silverlight 4.0. It enables you to resize and fit all the content and controls in your application dynamically. The ViewBox control can have only one child content or control and stretches that child to fit it into its size. Now, let’s understand the use of the ViewBox control by using it in an application. Perform the following steps to create an application ViewBoxExample (also available on CD):

+   1. Open **Microsoft Visual Studio 2010** and select **File→New→Project**. The New Project dialog box appears.
+   2. Select Visual C#→Silverlight from the Installed Templates pane in the New Project dialog box.
+   3. Select **Silverlight Application** from the middle pane.
+   4. Specify the name of the application as **ViewBoxExample** in the **Name** text box and the appropriate location in the **Location** combo box.
+   5. Click the **OK** button.  
+      The **New Silverlight Application** dialog appears.
+   6. Select the Host the Silverlight application in a new Web site check box.
+   7. Select the **ASP.NET Web Application Project** option from the New Web project type drop down box.
+   8. Select **Silverlight 4** from the **Silverlight Version** drop down box.
+   9. Select the **Enable Web RIA Services** check box.
+   10. Click the **OK** button.  
+       The **ViewBoxExample** application is created.
+   11. Replace the code of **MainPage.xaml** file with the code shown in Listing 11.12, to design the UI of your application:
