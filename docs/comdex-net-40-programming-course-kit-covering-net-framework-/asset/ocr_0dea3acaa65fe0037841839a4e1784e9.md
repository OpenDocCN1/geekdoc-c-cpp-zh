# Split View Bar

As already learned, you can simultaneously work with the Design view as well as the XAML view in a WPF application. It is possible because of the split view bar (Fig.VB-5.17) that provides a split view, which refers to the separation or division of WPF 4.0 Designer into the Design view and the XAML view. Split view bar contains two tabs on its left that correspond to two panes. The first tab corresponds to the Design pane allowing you to see the Design view and the second tab corresponds to the XAML pane allowing you to see the XAML view. There is a button, Swap Panes, between the Design and XAML panes on split view bar. When you click the Swap Panes button, the Design view and the XAML view are swapped with each other, as shown in Fig.VB-5.18:

![](bbox=[0.371, 0.272, 0.789, 0.392])

Fig.VB-5.18

You can again click the Swap Panes button to swap the Design view and the XAML view. You can drag the split view bar upwards or downwards to resize the Design or XAML view.

Split view bar also contains three buttons, Vertical Split, Horizontal Split, and Collapse Pane, on its right side. The first button, Vertical Split, allows you to vertically split the Design view and the XAML view, as shown in Fig.VB-5.19:

![](bbox=[0.231, 0.499, 0.771, 0.603])

Fig.VB-5.19

The second button, Horizontal Split, allows you to see both the Design and XAML views horizontally, which is the default view. The third button, Collapse Pane, allows you to collapse or hide one of the views. For example, if you click the Collapse Pane button in Fig.VB-5.19, then the XAML view collapses and you get more space for the Design view. In case you want to expand the collapsed pane, you can click the Expand Pane button that appears in place of the Collapse Pane button.

# Tag Navigator

Every control that you add to a WPF application is represented by an XAML tag or element. In WPF, the UI design of an application is in the form of a tree-like hierarchy in which one element is the topmost element that has a child element, which in turn have many child elements. You can navigate through the different elements in a WPF application by using the tag navigator, which by default appears just below the XAML view. The tag navigator allows you to navigate to the parent element of the currently selected element.
