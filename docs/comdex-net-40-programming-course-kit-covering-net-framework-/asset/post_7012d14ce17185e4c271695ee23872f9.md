## Operator Overloading

All the operators in C# have their specified meaning and functionality; for example, the + operator adds two numeric values and the - operator subtracts two numeric values. However, sometimes, you may need to change the default functionality of an operator. For example, you may want to use the + operator to add two complex numbers. As you know a complex number comprises a real number and an imaginary number; therefore, you cannot use the + operator to directly add two complex numbers. In such a situation, you can use operator overloading to assign a new meaning and functionality to an existing operator. Operator overloading is a mechanism of assigning new functionality to an operator, in addition to the already specified functionality of the operator.

In C# 2010, you cannot overload all the operators. Table 2.2 shows the overloading behavior of different operators:

| Operators | Type | Overloading Behavior |
|---|---|---|
| `+`, `-`, `~`, `!`, `++`, `--`, `true`, `false` | Unary | Can be overloaded |
| `+`, `-`, `*`, `/`, `%`, `&`, `\|`, `^`, `<<`, `>>` | Binary | Can be overloaded |
| `==`, `!=`, `<`, `>`, `<=`, `>=` | Comparison | Can be overloaded but only in pairs, such as `==` and `!=` and `<` and `>` |
| `&&`, `\|\|` | Conditional logic | Cannot be overloaded but can be evaluated using the `&` and `\|` operators |
| `[]` | Array indexing | Cannot be overloaded but can be used in defining indexers |
| `()` | Cast | Cannot be overloaded |
| `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `\|=`, `^=`, `<<=`, `>>=` | Assignment | Cannot be overloaded |
| `??`, `?:`, `->`, `new`, `is`, `sizeof`, `typeof` | Other | Cannot be overloaded |

## Run-Time Polymorphism

Run-time polymorphism, also known as method overriding, allows you to create virtual methods, which can be overridden in a derived class. After you have created a virtual method in a base class, any of the derived classes of that base class can provide a new implementation for the virtual method. In C#, the **virtual** keyword is used to declare a virtual method and the **override** keyword is used to declare a method that overrides the virtual method. The new method replaces the implementation of the virtual method in the derived class. Run-time polymorphism is named so because in run-time polymorphism, the compiler binds a method to an object while the program is being executed, and not when the program is being compiled.
