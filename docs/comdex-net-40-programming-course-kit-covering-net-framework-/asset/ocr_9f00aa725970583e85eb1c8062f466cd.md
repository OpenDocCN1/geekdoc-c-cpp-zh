# Multidimensional Arrays

Multidimensional arrays are arrays that have more than one dimension. Two-dimensional arrays are an example of multidimensional arrays. A two-dimensional array has two dimensions—rows and columns. The rows span horizontally and the columns span vertically. In two-dimensional arrays, there are two indexes—one for each dimension.

Perform the following steps to use a multidimensional array in a Console application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* File→New→Project from the menu bar. The New Project dialog box opens.
+   3. *Select* Visual C#→Windows from the Installed Templates section in the left pane of the New Project dialog box.
+   4. *Select* Console Application from the middle pane to create a Console application.
+   5. Enter the name of the application as **MultiDimensionalArrays** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** box.
+   6. *Click* the OK button to close the New Project dialog box and create the **MultiDimensionalArrays** application.
+   7. *Add* the highlighted code snippet, shown in Listing 1.3, to the **Program.cs** file:

**Listing 1.3:** Creating a Multidimensional Array

```
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace MultiDimensionalArrays
{
    class Program
    {
        static void Main(string[] args)
        {
            int[,] Matrix = new int[2, 2];
            Console.Write("Enter value for the Matrix[0, 0] element: ");
            Matrix[0, 0] = System.Convert.ToInt32(Console.ReadLine());
            Console.Write("Enter value for the Matrix[0, 1] element: ");
            Matrix[0, 1] = System.Convert.ToInt32(Console.ReadLine());
            Console.Write("Enter value for the Matrix[1, 0] element: ");
            Matrix[1, 0] = System.Convert.ToInt32(Console.ReadLine());
            Console.Write("Enter value for the Matrix[1, 1] element: ");
            Matrix[1, 1] = System.Convert.ToInt32(Console.ReadLine());
            Console.WriteLine("The generated matrix is:");
            Console.WriteLine("\t\t" + Matrix[0, 0] + "\t" + Matrix[0, 1]);
            Console.WriteLine("\t\t" + Matrix[1, 0] + "\t" + Matrix[1, 1]);
            Console.ReadLine();
        }
    }
}
```

In the highlighted lines of Listing 1.3, we first create a two-dimensional array, named Matrix, of the int data type that has two rows and two columns. Next, we prompt a user to enter values for each of the elements of the Matrix array, one by one, and store the entered values into the array elements. Finally, we display the values stored in each element of the Matrix array on the console.

+   8. *Press* the F5 key on the keyboard to run the application. The output of the application appears, prompting you to enter the value for the **Matrix[0, 0]** element, (Fig.C#-1.1).
+   9. *Type* 4 on the console as the value for the **Matrix[0, 0]** element and *press* the **ENTER** key. You are prompted to enter the value for the **Matrix[0, 1]** element (Fig.C#-1.12).
