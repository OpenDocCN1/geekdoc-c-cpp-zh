# Adding Comments to the Code

A comment is the additional text that is added to the program code only to make the program code easier to understand for the reader. Comments are neither compiled nor executed; they are ignored by the language compiler. Comments in Visual Basic 2010 start with an apostrophe ('). To comment multiple lines, you need to add an apostrophe (') before every line. You can also add or remove comments by selecting one or more lines of the code and then clicking the comment button or uncomment button, respectively, in the Text Editor toolbar.

Perform the following steps to add comments to the code:

+   1. *Start* Visual Studio 2010.
+   2. *Open* the **MOUSEANDKEYBOARDEVENTS** application.
+   3. Open Code Editor for the **Form1.vb** file and add some text inside the **Button1_Click** event handler (Fig.VB-2.83).
+   4. Select the text and click the comment button in the Text Editor toolbar (Fig.VB-2.83).
+      As a result, an apostrophe (') is added before each line selected in Code Editor, marking it as commented (Fig.VB-2.84).
+   5. *Select* the commented lines in Code Editor and click the uncomment button in the Text Editor toolbar to uncomment the selected lines, as shown in Fig.VB-2.84.
