```
caption As String, _
buttons As MessageBoxButtons, _
icon As MessageBoxIcon, _
defaultButton As MessageBoxDefaultButton, _
options As MessageBoxOptions _
) As DialogResult
```

The parameters in the preceding syntax are as follows:

+   - **text:** Represents the text displayed in the message box.
+   - **caption:** Represents the text displayed in the title bar of the message box.
+   - **buttons:** Represents a value that specifies which buttons to display in the message box. The buttons argument takes its value from the **MessageBoxButtons** enumeration.
+   - **icon:** Represents a value that specifies which icon to display in the message box. The icon argument takes its value from the **MessageBoxIcon** enumeration.
+   - **defaultButton:** Represents a value that specifies which button is the default button for the message box. The **defaultButton** argument takes its value from the **MessageBoxDefaultButton** enumeration.
+   - **options:** Represents a value that specifies which display and association options will be used for the message box. The **options** argument takes its value from the **MessageBoxOptions** enumeration.

The members of the **MessageBoxButtons** enumeration are given in Table 2.6:

**Table 2.6: Members of the MessageBoxButtons Enumeration**

| Member | Description |
|---|---|
| AbortRetryIgnore | Displays the message box with the Abort, Retry, and Ignore buttons |
| OK | Displays the message box with the OK button |
| OKCancel | Displays the message box with the OK and Cancel buttons |
| RetryCancel | Displays the message box with the Retry and Cancel buttons |
| YesNo | Displays the message box with the Yes and No buttons |
| YesNoCancel | Displays the message box with the Yes, No, and Cancel buttons |

The members of the **MessageBoxIcon** enumeration are given in Table 2.7:

**Table 2.7: Members of the MessageBoxIcon Enumeration**

| Member | Description |
|---|---|
| Asterisk | Shows an icon displaying a lowercase letter i in a circle (information icon) |
| Error | Shows an icon displaying a white X in a circle with a red background (error icon) |
| Exclamation | Shows an icon displaying an exclamation point in a triangle with a yellow background (warning icon) |
| Hand | Shows an icon displaying a white X in a circle with a red background (error icon) |
| Information | Shows an icon displaying a lowercase letter i in a circle (information icon) |
| None | No icons shown |
| Question | Shows an icon displaying a question mark in a circle (question icon) |
| Stop | Shows an icon displaying a white X in a circle with a red background (error icon) |
| Warning | Shows an icon displaying an exclamation point in a triangle with a yellow background (warning icon) |
