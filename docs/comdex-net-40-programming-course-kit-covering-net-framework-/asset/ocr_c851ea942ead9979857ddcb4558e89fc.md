# ### Using the DataList Control

The DataList control is a data-bound control that displays the data on a Web page by using templates. It renders data as tables and enables you to display the records in different layouts, such as ordering them in columns and rows. The layout of the DataList control is supported by the RepeatLayout property. For example, if you set the RepeatLayout property to RepeatLayout.Table, the data will be displayed in the DataList control in the form of a table. In the same way, to display the data in the DataList control without a table, set the RepeatLayout property to RepeatLayout.Flow. You can use the DataList control to edit or delete a record in a database.

The DataList control resides within the System.Web.UI.WebControls namespace and is inherited from the DataList class. This class defines several properties and methods that DataList control supports. Some noteworthy properties of the DataList class are given in Table 6.17:

**Table 6.17:** Noteworthy Properties of the DataList Class

| Property | Description |
|---|---|
| EditItemTemplate | Retrieves or sets the template for the item selected for editing in the **DataList** control |
| FooterStyle | Retrieves the style properties for the footer section of the **DataList** control |
| FooterTemplate | Retrieves or sets the template for the footer section of the **DataList** control |
| Items | Retrieves a collection of **DataListItem** objects representing the individual items within the control |
| ItemStyle | Retrieves the style properties for the items in the **DataList** control |
| ItemTemplate | Retrieves or sets the template for the items in the **DataList** control |
| RepeatColumns | Retrieves or sets the number of columns to display in the **DataList** control |
| RepeatDirection | Retrieves or sets whether the **DataList** control is displayed vertically or horizontally |
| RepeatLayout | Retrieves or sets whether the control is displayed in a table layout or flow layout |
| SelectedIndex | Retrieves or sets the index of the selected item in the **DataList** control |
| SelectedItem | Retrieves the selected item in the **DataList** control |

**Table 6.18:** Noteworthy Methods of the DataList Class
