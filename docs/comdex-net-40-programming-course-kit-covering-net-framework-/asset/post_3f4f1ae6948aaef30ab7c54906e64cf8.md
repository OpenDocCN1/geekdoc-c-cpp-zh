### **Listing 6.2:** Showing the Code of the MyCodeActivity.vb File

```
Imports System.Activities
Public NotInheritable Class MyCodeActivity
    Inherits CodeActivity
    Private m_Num1 As InArgument(Of Integer)
    Public Property Num1() As InArgument(Of Integer)
        Get
            Return m_Num1
        End Get
        Set(ByVal value As InArgument(Of Integer))
            m_Num1 = value
        End Set
    End Property
    Private m_Num2 As InArgument(Of Integer)
    Public Property Num2() As InArgument(Of Integer)
        Get
            Return m_Num2
        End Get
        Set(ByVal value As InArgument(Of Integer))
            m_Num2 = value
        End Set
    End Property
    Protected Overrides Sub Execute(ByVal context As CodeActivityContext)
        Dim a As Integer = context.GetValue(Me.Num1)
        Dim b As Integer = context.GetValue(Me.Num2)
        Dim c As Integer = a + b
        Console.WriteLine("The addition of " & a & " and " & b & " is: " & c.ToString())
        Console.ReadLine()
    End Sub
End Class
```

In the first highlighted portion of code (Listing 6.2), two variables, m_Num1 and m_Num2, are defined. These variables correspond to two properties, Num1 and Num2, respectively. Next, the Get and Set procedures are defined for each of these properties. The Get procedure of a property is called when data is retrieved from the property and the Set procedure of a property is called when data is assigned to the property. In the second highlighted portion of code, we redefine the Execute method of the CodeActivity activity class so that it can execute a custom activity. Inside the Execute method, we use the GetValue method of the CodeActivityContext class to assign the properties, Num1 and Num2, to local integer variables, a and b, respectively. Finally, the result of adding a and b is stored in the integer variable c and then displayed using the Console.WriteLine statement.
