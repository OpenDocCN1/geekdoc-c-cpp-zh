## Publishing a Web site

Publishing a Web site involves the precompilation of the Web site and then saving the output to some specified location. During the precompilation process, the compiler checks out for all the errors involving syntax and type matching errors, variables transfer errors, and calling of subroutines across different application modules. It also checks for the modules accessing application’s global resources and the local computer resources.

The precompilation process is the replica of the dynamic compilation of Web pages while rendering them in the browser. The output of the precompilation process is written in any directory of the local drives or external computer drives by using FTP or HTTP. Any error(s) in the precompilation process is visible in the **Output** window of the Visual Studio Integrated Development Environment (IDE). Let’s perform the following steps to create and publish a Web site:

- 1. *Open* **Microsoft Visual Studio** 2010.
