## Chapter 8: Master Pages and Themes

### In this Chapter:

- Creating Master Pages
- Explaining Themes

Prior the introductions of master page, every page of website apply a different layout, or you need to write the code repeatedly in your website for such items, which you want to show globally in your website. Therefore, to provide a consistent look throughout the website was difficult to developers. Therefore, the Web developers used various techniques, such as a template driven solution, to provide a common style to all pages of a website. A consistent look and feel is presently a necessity for real-world Web applications. Now, in ASP.NET 4.0, developers can incorporate a consistent look and feel in their applications by using features, such as master pages and themes.

The concept of master page is mainly about incorporating visual inheritance in Web applications. This implies that you can inherit the behavior and appearance of one page and apply the same on the other pages of your Web application. A master page defines the overall layout of a Web application and all the other pages of the Web application that are derived from the master page, inherit that layout, along with having their own content. This provides consistency, avoids duplication of code, and makes the website easy to maintain. The Web pages that inherit the properties defined in master page are called content pages. The content pages display their own properties as well as the properties inherited from the master page. Therefore, you can say that a master page is a template, which is referenced by all the content pages of a Web application. For example, you want to create a website for your company in which all the Web pages have a footer showing the address and logo of the company, then you can create the footer and logo in a master page and inherit all the content pages from the master page to show the logo and address of the company.

A master page has a .master extension, while a content page has the .aspx extension. You can create a master page by using a text editor, such as Notepad, Visual Web Developer Express Edition, or Microsoft Visual Studio 2010

In this chapter, you learn about creating master pages, which includes simple and nested master pages. You also learn about creating themes and applying them in your Web pages. In addition, you learn how to apply a theme to your Web page at runtime. Finally, you learn about the StylesheetTheme attribute.

Let’s start by learning about master pages.

### Creating Master Pages

A master page is a mechanism to provide a consistent layout throughout the website. You can include the elements that you want to display on all the Web pages of your website in a master page. After creating a master page, you can create content pages that inherit the master page. The content pages contain the properties and behavior of the master page from which they are derived as well as their own properties. When you make a request to a content page, the master page merges with the content page and generates a combined output. A master page can contain markups, controls, banners, navigation menus, and other elements that you want to include in all the Web pages. You can define a master page by specifying the @ Master directive at the top of a Web page, as shown in the following code snippet:

```aspx
<%@ Master Language="C#" CodeFile="MasterPage.master.cs" Inherits="MasterPage" %>
```

The @ Master directive is similar to the @ Page directive in a Web form (.aspx). This directive states that it belongs to a master page file and its properties, such as banner, header, footer, and menus, are inherited by the content pages.

Some of the important functions of a master page are as follows:

- Defines common properties of a website, such as banners, navigation menus, logo, and other elements that can be accessed by the content pages
- Allows single or multiple content pages to access it
- Displays the content of each content page in its placeholder

In ASP.NET, you can create following types of master pages:

- Simple master page
- Nested master page

Let’s discuss these in detail.

#### Simple Master Page

A master page is a page that is combined with the content page to display the final Web page. The functionality of simple master page is to define a common layout for all pages of a website and use it repeatedly. By creating a simple master page, you can save so much time and easily maintain a website from a single place. The simple master page allows you to store the master page code at one place and reuse it whenever you want to include similar type of appearance and functionality in your website. Moreover, you need not to write the same code repeatedly and if you want to modify your website appearance, you need to incorporate changes at only one place where you have stored the master page code.
