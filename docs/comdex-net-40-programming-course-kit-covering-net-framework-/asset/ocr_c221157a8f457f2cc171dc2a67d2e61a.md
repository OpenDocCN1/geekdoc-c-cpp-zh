# Using the Button Control

The Button control in WPF is similar to the one available for Windows Forms applications. It allows you to perform an action when a user clicks it. The Button control can contain text as well as an image and it is an instance of the Button class. Table 5.3 lists the noteworthy properties of the Button class:

**Table 5.3: Noteworthy Properties of the Button Class**

| Property | Description |
|---|---|
| IsCancel | Returns or sets a value that specifies whether the button is a Cancel button |
| Content | Returns or sets the content of the button |
| IsDefault | Returns or sets a value that specifies whether the button is the default button |
| IsDefauleted | Returns a value that specifies whether or not the button is activated when a user presses the ENTER key on the keyboard |
