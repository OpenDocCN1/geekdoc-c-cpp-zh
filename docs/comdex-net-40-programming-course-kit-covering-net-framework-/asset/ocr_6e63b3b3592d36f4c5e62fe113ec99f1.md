CLR provides a feature, known as garbage collection, to destroy the unnecessary objects during the execution of an application. The garbage collection feature runs when the run-time environment finds it necessary or when an object is not destroyed. Similar to a constructor, a destructor also has the same name as the name of the class in which it is defined; however, the declaration of the destructor starts with a tilde (~) sign. When the compiler finds a destructor of a class at the compile time, it creates the Finalize() method corresponding to the destructor. The Finalize() method is automatically called by CLR before the garbage collection feature runs for the objects of the class.

Perform the following steps to use constructors and destructors:

+   1. *Start* Visual Studio 2010.
+   2. *Select* File→New→Project from the menu bar. The New Project dialog box opens.
+   3. *Select* Visual C#→Windows from the Installed Templates section in the left pane of the New Project dialog box. The project templates available for developing Windows applications in Visual C# are displayed in the right pane of the New Project dialog box.
+   4. *Select* Console Application from the right pane to create a Console application.
+   5. Enter the name of the application as **ConstructorsAndDestructors** (also available on the CD) in the Name text box and an appropriate location for the application in the Location box.
+   6. Click the OK button to close the New Project dialog box and create the **ConstructorsAndDestructors** application.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
namespace ConstructorsAndDestructors
{
    class Rectangle
    {
        int length, width;
        public Rectangle(int x, int y)
        {
            length = x;
            width = y;
        }
        ~Rectangle()
        {
            Console.WriteLine("Finalizing rectangle...");
            Console.ReadLine();
        }
        public void Area()
        {
            Console.WriteLine("Area of the rectangle: " + length * width);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            Rectangle rect = new Rectangle(20, 10);
            rect.Area();
        }
    }
}
