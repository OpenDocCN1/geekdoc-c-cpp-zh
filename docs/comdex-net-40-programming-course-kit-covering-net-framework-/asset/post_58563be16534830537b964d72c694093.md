## Chapter 3: Navigation Controls

In this Chapter:

- Working with the SiteMapPath Control
- Working with the Menu Control
- Working with the TreeView Control

The controls that allow you to move back and forth between different Web pages of a Web site are called Navigation controls. These controls display the address of a Web page in the form of menus and hyperlinks, which you can use to navigate to any page of a Web application from the current page. The navigation controls represent the structure of a Web application, that is, how different Web pages of a Web application are linked together. These controls dynamically order the Web pages according to the sequence in which you have traversed through different Web pages, that is, the navigation controls keep a record of all the visited pages in a session. You can move back and forth to any Web page by clicking the corresponding nodes provided on a page. The navigation controls recognize the user’s current position in the Web site and shift the reference pointer to other pages accordingly when the user moves from a Web page to another.

This chapter makes you familiar with different types of navigation controls, such as SiteMapPath, Menu, and TreeView control. You also learn how to insert and use these controls in a Web application. The chapter also discusses all the noteworthy properties, methods, and events of each of these controls. Next, you learn to create the two types of menus, static and dynamic, in a Web application.

### Working with the SiteMapPath Control

The SiteMapPath control is a navigation control that displays the map of the site related to its Web pages. This map includes the pages of a particular Web site and displays the name of those pages. You can click the link for a particular page in the SiteMapPath control to navigate to that page. In other words, the SiteMapPath control displays links for connecting to Uniform Resource Locators (URLs) of Web pages. Out of all the Web pages contained in an ASP.NET Web site, you can select any page to act as the Home page or start page. This page is also known as the root node, as it provides navigation links to all the pages in the Web site.

The SiteMapPath control uses a property called `SiteMapProvider` for accessing data from a database. The `SiteMapProvider` property utilizes the `SiteMapProvider` abstract class defined under the `System.Web` namespace to store the information related to the SiteMapPath control in a data source.

The methods defined in this abstract class create a schema containing nodes that represent Web pages. This schema, which is produced by the `SiteMapProvider` property, is represented as a URL by the SiteMapPath control.

A default schema of the Web site is automatically created for use by the SiteMapPath controls. This schema is contained as an Extensible Markup Language (XML) file known as the sitemap file. This sitemap file has an extension `.sitemap` and is visible in the Solution Explorer window when a SiteMapPath control is included in the project. In this sitemap file, the Web pages are referred to in the URL attribute of the `siteMapNode` elements. The schematic representations of nodes are in the form of parent-child relationship. A child node can have more nested child nodes for each level of hierarchical nesting of Web pages.

Table 3.1 lists noteworthy properties of the SiteMapPath class:

| Property | Description |
|---|---|
| `ParentLevelsDisplayed` | Obtains or specifies the number of levels of parent nodes, and then displays the control accordingly |
| `RenderCurrentNodeAsLink` | Specifies whether or not the site navigation node that represents the currently displayed page is rendered as a hyperlink |
| `PathSeparator` | Obtains the string that delimits the SiteMapPath node in the rendered navigation path |
| `CurrentNodeStyle` | Obtains the style used for displaying text on the current node |
| `RootNodeStyle` | Obtains the style used for displaying text on the root node |
| `NodeStyle` | Obtains the style used for displaying text on all the child nodes |
