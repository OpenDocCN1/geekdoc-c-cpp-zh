# ### Simple Master Page

A master page is a page that is combined with the content page to display the final Web page. The functionality of simple master page is to define a common layout for all pages of a website and use it repeatedly. By creating a simple master page, you can preserve so much time and easily maintain a website from a single place. The simple master page allows you to store the master page code at one place and reuse it whenever you want to include similar type of appearance and functionality in your website. Moreover, you need not to write the same code repeatedly and if you want to modify your website appearance, you need to incorporate changes at only one place where you have stored the master page code. Let's create a website, **SimpleMasterPage** (also available on the CD), to learn how to create a master page. Perform the following steps to create the **SimpleMasterPage** website:

+   1. *Open Visual Studio 2010.*
+   2. *Select File→New→Web Site* from the menu bar. The **New Web Site** dialog box opens.
+   3. *Select Visual C#* from the Installed Templates pane of the **New Web Site** dialog box.
+   4. *Select ASP.NET Empty Web Site* from the right pane of the **New Web Site** dialog box.
+   5. *Specify* the location and name of the application in the Web location combo box. In this case, we have specified the name as **SimpleMasterPage**.
+   6. *Click* the **OK** button to create the **SimpleMasterPage** application (also available on the CD).
+   7. *Right-click* the project name in *Solution Explorer* and select the **Add New Item** option from the context menu, as shown in Fig.ASP-8.2.
