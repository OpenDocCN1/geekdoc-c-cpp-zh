Perform the following steps to use the Label control in a Windows Forms application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the Installed Templates section in the left pane of the **New Project** dialog box. The project templates available for developing Windows-based applications in Visual Basic are displayed in the middle pane of the **New Project** dialog box.
+   4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
+   5. Enter the name of the application as **LabelControl** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. Click the **OK** button to close the **New Project** dialog box. The **LabelControl** application is created.
+   7. *Drag and drop* a Label control from the Toolbox on the form, as shown in Fig.VB-3.1:

![](bbox=[0.329, 0.329, 0.68, 0.522])

Fig.VB-3.1

+   8. *Select* the **Label** control in the form and *set* its **Text** property to **Welcome to Visual Basic 2010** in the **Properties** window, as shown in Fig.VB-3.2:

![](bbox=[0.422, 0.579, 0.595, 0.749])

Fig.VB-3.2

+   9. *Select* the **BackColor** property, click the down arrow button in front of this property, and select a color from the color palette displayed on the **Custom** tab, to change the background color of the **Label** control (Fig.VB-3.3).
+   10. *Select* the **ForeColor** property, click the down arrow button in front of this property, and select a color from the color palette displayed on the **Custom** tab, to change the color of the text displayed in the **Label** control, (Fig.VB-3.4).
