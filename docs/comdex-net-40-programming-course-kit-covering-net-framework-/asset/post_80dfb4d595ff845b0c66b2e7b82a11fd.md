
## Architecture of Windows Phone Application Platform

The Windows Phone Application Platform architecture consists of four main components that provide a consistent user experience and features that you can use to develop Windows Phone 7 applications. These four components are as follows:

- **UI Design Tools:** Refer to different frameworks and environments that you can use to build and design secure and graphically-rich applications
- **Developer Tools:** Refer to the tools that enable you to implement the complete functionalities for Windows Phone applications and also debug, deploy, and update applications
- **Cloud Services:** Refer to different Web services that enable you to share data on the cloud
- **Portal Services:** Refer to the services that enable you to register, certify, and distribute your applications in the market

### UI Design Tools

As stated earlier, the Windows Phone Application Platform enables you to develop two types of Windows Phone applications: the XAML-based applications using Silverlight and the loop-based programs, such as games using the XNA Framework. In addition to these two technologies, there are various tools that are used to create highly interactive and graphically-rich interfaces. These are explained as follows:

- **Silverlight and .NET Framework:** Allows you to generate the UI that supports multimedia content and eye-catching visual effects, which in turn provide an attractive look and feel to your application. You can use Visual Studio 2010 or Expression Blend for building and designing the XAML based interfaces.
- **XNA Framework:** Contains different software, services, and resources that facilitate you to develop game applications. It provides a complete set of tools and managed APIs for developing games that are full of 3D animations and effects.
- **Sensors:** Returns the data received in the form of input from the users. Multi-touch input, accelerometer, compass, light, and microphone sensors are examples of sensors.
- **Media:** Refers to a platform that allows you to build the interfaces that integrate the audio, video, FM radio and music, and video hub. To create such interfaces, you can use both Silverlight and XNA Framework and along with these, you can also use the Windows Phone APIs provided by Microsoft.
- **Data:** Refers to the isolated storage of the application data. Isolated storage enables you to store and maintain data in a virtual folder that prevents your data from being accessed directly through the underlying OS file system. This helps in protecting your data from unauthorized and unwanted access by other applications.

### Developer Tools

Windows Phone Application Platform offers various tools that allow you to work with Windows Phone applications. The Windows Phone Developer Tools (vm_web.exe file) tool provided by the Application Platform includes all the tools, such as Visual Studio 2010 Express, the Windows Phone Emulator, XNA Game Studio, and Expression Blend for developing applications for Windows Phone 7.

When you install the Windows Phone Developer Tools in your system, the Visual Studio 2010 Express for Windows Phone also gets installed on your computer. If Visual Studio 2010 Professional or higher edition is already installed in your computer, then an add-in to Visual Studio 2010 gets installed on installing the Windows Phone Developer Tools.

Windows Phone Developer Tools provide the following tools:

- **Visual Studio 2010:** Refers to a user-friendly, easy-to-use IDE that enables you to develop Windows Phone 7 applications. Visual Studio IDE provides you various features, such as phone-based designer, Windows Phone project templates, set of controls that support Windows Phone, manifest generation, and debugger. These features allow you to create Silverlight or XNA Framework applications within Visual Studio that run on Windows Phone.
- **Expression Blend:** Allows you to design graphically rich and interactive Silverlight-based applications for Windows Phone 7. It facilitates you to create XAML-based interfaces that can be further extended by specifying the application logic in Visual Studio.
- **Windows Phone Emulator:** Provides you with an emulated environment for developing, debugging, and testing applications. It is integrated with Visual Studio and Expression Blend to make the Windows Phone application development easier. It allows you to develop the phone applications without any requirement of a phone device to test or debug the application. It also supports Graphics Processing Unit (GPU) emulation that is required to support game applications created on XNA Framework. A GPU is a graphics coprocessor that is used to compute the graphics related functions, such as transformations, lighting effects, and animations.
- **XNA Game Studio:** Provides you with an integrated design environment for developing more advanced and exciting games that can run on Microsoft Windows, the Microsoft Xbox 360 video game and entertainment system, Microsoft Zune, and Windows Phone. XNA Game Studio also includes the XNA Framework that contains a set of managed libraries that allow you to create game applications.

### Cloud Services

The cloud service is a service that is used to build cloud applications. These are the applications that can be accessed remotely through the Web and are managed from the central locations. The advantage of cloud application is that it enables you to use it without installing it on a device. It reduces the maintenance and support cost of the application as compared to those applications that are not developed using the cloud service. In .NET Framework 4.0, the cloud service or applications can be created by using the Windows Azure platform. This platform provides Windows Azure (cloud operating system), SQL Azure (cloud database), .NET services, and Live services. The Phone applications created using cloud services enhance the power and features of a Phone device as these applications are capable of accessing data on the phone.

The following are the different runtime services that can be used by the cloud services to access different Web services:

- **Notification Service:** Enables you to manage the flow and communication between users, applications, and different services. These notifications are generated by the cloud services accessed through a client API. These notifications let the users know that a particular task has been performed on the device.
- **Location Service:** Allows the applications to access the actual location information about the device. It uses different sources, such as Wi-Fi, Cellular, and GPS, to get the information about the location.
- **Identity, Feeds, Social, and Maps Services:** Allows consumers to communicate with different communities, receive the data feeds, and use maps for navigation.
- **Windows Azure Platform:** Provides Windows-based compute and storage service for cloud applications. The motive of the Windows Azure platform is to help developers build cloud services according to requirements. This platform also provides Internet-scale infrastructure for deploying distributed applications and services. Visual Studio 2010 can be used to develop cloud service and can deploy it on the Azure platform.

### Portal Services

After developing a Windows Phone application, you need to publish it on Windows Phone Marketplace to make it available to other users. The Windows Phone Marketplace provides you with a centralized location where you can submit and certify your applications. While publishing the application to the centralized location, the following services are provided by the Developer Portal:

- **Registration and Validation:** Facilitates you to sign up with your Windows Live ID on the Developer Portal. After getting registered successfully, you can then download the Windows Phone Application Development Tools needed for the application development.
- **Certification and Publishing:** Refers to the process of submitting and certifying applications for Windows Phone Marketplace. You need to submit the application in a .xap file format. Certification process ensures that the application satisfies all the rules and regulations of the target markets, and does not misuse users' information that is stored on the phone. After an application is certified, it can be published on Windows Phone Marketplace.
- **Billing:** Refers to the process through which consumers can purchase applications from the Windows Phone Marketplace. The consumers are allowed to make payment by using either mobile operator or credit card billing.
- **Business Intelligence:** Enables you to get all the status information about your application, such as monetary, sales reports, and feedback from users.

### Starting with the Windows Phone Developer Portal

To develop a Windows Phone application, you require a tool or platform on which the application can be built, tested, and debugged. You can download the Windows Phone Application Tools from the Windows Phone developer portal, also called App Hub. To download this tool, you first need to sign up for a Windows Live ID. After signing up, you are registered to get the Windows Phone Application Tools and the related licensing materials that are required to develop applications using Visual Studio 2010 and Expression Blend. The Windows Phone Application Tools is a single and small tool that contains all the tools and runtimes needed for designing, developing, and debugging your applications.
