# Exploring New Features of Silverlight 4.0

In the preceding section, you have learned about some of the most common features of Silverlight. Along with these features, there are some new features introduced in Silverlight 4.0. These features are as follows:

+   - Supports Google Chrome browser.
+   - Supports Web cam and microphone.
+   - Supports printing options
+   - Provides improved mouse support, such as **right-click** and **mouse-wheel** support
+   - Supports notification to display messages to the users.
+   - Provides various new controls, such as **RichTextBox**, **ViewBox**, and **WebBrowser** and an enhanced **DataGrid** control.
+   - Includes Windows Communication Foundation (WCF) data layer enhancements.
+   - Includes localization enhancements with bi-directional text that enable you to set the direction of flow of any UI element. For this, you need to set the FlowDirection property that is provided with all UI elements.
+   - Supports Managed Extensibility Framework that facilitates you to deploy your application in multiple XAP files.
+   - Supports enhanced data binding.
+   - Provides enhanced animation effects.
+   - Supports clipboard and drag and drop facilities.
+   - Provides WCF Rich Internet Application (RIA) services. These services help in building n-tier applications by integrating the ASP.NET and Silverlight platforms together and providing you the built-in networking and data access functionality.
+   - Supports playing offline Digital Rights Management (DRM) protected media.
