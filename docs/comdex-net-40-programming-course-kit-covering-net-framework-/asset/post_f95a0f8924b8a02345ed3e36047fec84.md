## Using Structures

In C#, a structure refers to a user-defined value type. It allows you to create new value-type objects that are similar to the built-in type objects, such as int, double, and bool. A structure can contain constructors, fields, methods, and properties. One major difference between a structure and a class in C# is that a structure does not support inheritance. By default, all the members of a structure are private. If you do not assign a value to a variable of a structure, a default value is automatically assigned to the variable.

The struct keyword is used to declare a structure in C#. The basic syntax to define a structure is as follows:

```csharp
[access-modifier] struct <structure-name>
{
    variable-declarations;
    method-declarations;
}
```

In the preceding syntax, `struct` is a keyword indicating that a structure is defined and **structure-name** is the name of the structure being defined.

## Using Anonymous Types

While creating properties in an application, you might need to create a few read-only properties as well. You can encapsulate these read-only properties into a single unit by using anonymous types. An anonymous type provides you an easy way of encapsulating a set of read-only properties into a single unit without defining a new type. Anonymous types are unnamed structure types that you can access by using the var keyword. The anonymous type declaration starts with the new keyword.

> When you create an application, you cannot use the name of an anonymous type because the name may change when you recompile the application. This is due to the fact that the name of the anonymous type is compiler generated and may vary from compilation to compilation.

## Working with Namespaces

The concept of namespaces is not new to C#. A namespace acts as a wrapper around one or more structural elements that make the elements unique. In other words, a namespace is a way to group related types under one name. Whether or not you explicitly declare a namespace in a source file, the C# compiler adds a default namespace to the source file.

Namespaces in C# can be divided into two categories:

- **User-defined:** Refer to namespaces that are defined in your code.
- **System-defined:** Refer to namespaces that are defined in .NET Framework Base Class Library, for example, System, System.Collections, and System.Data.

In C#, you can use the **using** keyword to include a namespace in your program.

> Namespaces are always public; therefore, the declaration of a namespace cannot include any access modifier.
