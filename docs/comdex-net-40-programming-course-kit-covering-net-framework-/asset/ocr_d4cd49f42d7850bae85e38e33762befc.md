# Exploring Data Types in C# 2010

C# is a strongly typed programming language meaning that every variable or object that you create in a C# program must have a data type (however, with the introduction of the dynamic keyword, it is possible to delay the type resolution till run time). A data type indicates the type of values that a variable or an object can store and the number of bytes that the variable or object occupies in the memory. Depending on the requirements of your program, you can create variables and objects of different data types.
