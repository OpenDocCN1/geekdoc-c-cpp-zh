## Adding Comments to the Code

A comment is the additional text that is added to the program code only to make the program code easier to understand for the reader. Comments are neither compiled nor executed; they are ignored by the language compiler. Comments in Visual Basic 2010 start with an apostrophe ('). To comment multiple lines, you need to add an apostrophe (') before every line. You can also add or remove comments by selecting one or more lines of the code and then clicking the comment button or uncomment button, respectively, in the Text Editor toolbar.

## Introducing the Control Class

The Control class is the base class for all the Windows Forms controls and it belongs to the **System.Windows.Forms** namespace. The inheritance hierarchy of the Control class is given as follows:

```
System.Object
    System.MarshalByRefObject
        System.ComponentModel.Component
            System.Windows.Forms.Control
```

In the preceding inheritance hierarchy, you can notice that the **Object** class is the base class for all the classes in the .NET Framework class library. The Control class is derived from the Component class, which is inherited from the **MarshalByRefObject** class.

All the Windows Forms controls inherit the common properties, methods, and events of the **Control** class. Table 3.1 lists the important properties of the Control class:
