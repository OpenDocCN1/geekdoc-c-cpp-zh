Applications developed to run on mobile devices, such as Personal Digital Assistants (PDAs) and Smartphones, are referred to as Windows mobile applications or smart device applications. The previous versions of Visual Studio had a platform named .NET Compact Framework that was used to develop Windows mobile applications. However, the latest version of Visual Studio, Visual Studio 2010, does not support the .NET Compact Framework. This version allows you to create applications that are applicable only for Windows Phone Operating System (OS) 7.0 and not for any prior versions of the Windows OS.

Visual Studio 2010 in combination with the Windows 7 OS offers you the latest version of Windows Mobile Operating System, Windows Phone 7, to develop Windows Phone 7 applications. To run these applications, the Windows Phone Application Platform has been released. This platform is a combination of existing tools and technologies, such as Visual Studio, Expression Blend, Silverlight, and XNA Framework.

This appendix explains an overview of Windows Phone Application Platform. It also discusses the architecture of the platform that includes different tools and services to enable you to develop the Windows Phone 7 applications. Further, this appendix also explains the lifecycle of the application development that includes designing, debugging, publishing, and managing the applications.

Let's start with the overview of the Windows Phone Application Platform.

# ## Overview of Windows Phone Application Platform

Windows Phone 7 applications are supported by .NET Framework 4.0. You can use any of the .NET-compliant language for developing Windows Phone 7 applications. .NET 4.0 provides the following two approaches to develop Windows Phone 7 applications:

+   - **Silverlight UI Framework for Windows Phone:** Allows you to develop event-driven Extensible Application Markup Language (XAML) based applications. XAML is a declarative markup language based on Extensible Markup Language (XML) introduced by Microsoft Corporation. This markup language allows designers to easily and quickly define and describe the elements for the User Interface (UI) of WPF applications. When creating a new Windows Phone application, you first need to choose a Silverlight framework upon which to build your application. The Silverlight Framework for Windows Phone which is based on Silverlight 3 and provides the core Silverlight functionalities along with some additional Application Programming Interface (APIs) and features. It allows you to use the existing Silverlight and .NET code, libraries, and markup for developing Windows Phone 7 Silverlight application. Silverlight for Windows Phone is hosted as a client-device; therefore, the applications that are hosted on browsers cannot be developed using Silverlight for Windows Phone.
+   - **XNA Framework 4.0 for Windows Phones:** Refers to the Microsoft's game development framework. It enables you to create cross-platform games that can run on both Windows and Xbox 360 (a video game console introduced by Microsoft). It provides great support for 2D and 3D games along with audio and video playback, Xbox Live multi-layer features, and Xbox 360 avatars. It includes a rich collection of classes, libraries, and APIs that are specific to game development, and allows you to develop advanced games for Windows Phone 7.

The Windows Phone Application Platform includes Visual Studio, Expression Blend, Windows Phone Marketplace services, and cloud-based Web services in it. It offers a complete platform to the developers for creating applications by providing a rich toolset, well designed and integrated set of APIs, a service-based marketplace where the users can distribute their Windows Phone applications and a distinct sandbox (tightly-controlled set of resources) in which every Windows Phone application runs. It also provides runtime services that you can use to access Web services in the cloud, such as Xbox LIVE, Windows Azure, location, and notification services. In addition to these, the Windows Phone Application Platform also supports the access of Windows Communication Foundation (WCF) and Representational State Transfer (REST) services across the Web. In short, the Windows Phone Application Platform is familiar and easy to use as it re-introduces the tools and technologies that are already known to many users.
