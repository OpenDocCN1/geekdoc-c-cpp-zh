While working with data types in Visual Basic, sometimes you need to convert the data type for a value stored in a variable to another data type. Converting one data type to another data type is known as data type conversion. Before performing data type conversion between two data types, you must ensure that these data types are compatible to one another, which means the value stored in the variable of one data type can be stored in a variable of another data type. For example, you can assign a value stored in a **Byte** variable to an **Integer** variable because both these data types are compatible with each other; whereas, you cannot assign a value stored in an **Integer** variable to a **Char** variable because these data types are not compatible with one another.
