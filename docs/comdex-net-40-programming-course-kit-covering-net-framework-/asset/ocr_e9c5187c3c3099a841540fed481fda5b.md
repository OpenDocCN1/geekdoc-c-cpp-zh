# ## Jump Statements

As the name suggests, jump statements allow you to jump from the current statement to another statement in your program. Jump statements are mainly used with loops and switch statements. In loops, you can use jump statements to break out of a loop or to skip the statements after a particular statement in the loop. C# provides the following two jump statements:

+   - The break statement
+   - The continue statement

Let’s discuss the use of each of these statements, one by one.

# ### Using the break Statement

We have already used the **break** statement in switch statements, where it helps in avoiding fall through. However, it can also be used in loops to terminate or stop the execution of the loop. This implies that the execution of the loop stops immediately and the control passes to the statement that follows the loop. If the loop has statements after the **break** statement, then all those statements are skipped. In nested loops, the break statement terminates only the current loop, that is, the loop in which it is used. For example, if there are two for loops nested within each other and you use the **break** statement in the inner for loop, then only the inner for loop is terminated without affecting the outer for loop.

The syntax of the break statement is as follows:

```
break;
```

In the preceding syntax, the **break** keyword is used to indicate a break statement.
