Noteworthy methods of the Form class are given in Table 2.2:

| Method | Description |
|---|---|
| Activate | Activates the form (gives it focus and makes it active) |
| Close | Closes the form |
| Contains | Indicates whether the specified control is a child of this form |
| Show | Displays the form by setting the visible property of the form to True |
| ShowDialog | Displays the form as a modal dialog box |

> > A modal dialog box is a window that requires users to interact with it before they can return to the application that initiated the dialog box.
