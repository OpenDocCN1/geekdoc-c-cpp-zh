## Designing an Application and Packaging it in a Package

After downloading the Windows Phone Application Tools from App Hub, you can install it on your computer and start developing applications. To develop games and graphically-rich applications, you can use Visual Studio 2010 that provides you with 2D and 3D libraries of the XNA Framework.

If you need to create XAML-based applications for Silverlight, you can use either Visual Studio 2010 or Expression Blend. After completing the designing process, provide the logical functionalities and behavior to all Windows Phone applications by writing the managed code in the Visual Studio IDE. Next, you need to group all the files and folders required by the application in a single package. Now, let’s learn to debug the Windows Phone applications.

## Debugging the Application

After developing a Windows Phone application, you need to test and debug it. Visual Studio 2010 provides a phone device and a tool, named Windows Phone Emulator to test and debug an application. This tool works in the same manner as a real phone device does. Debugging the application also includes creation of a package that can run on the target device (phone device) successfully.

After getting familiar with the debugging process of the Windows Phone applications, let’s learn to publish the applications.

## Publishing the Application

To publish the applications in the Windows Phone Marketplace, a .xap file should be created. A .xap file is a unit of deployment that contains all the necessary information, such as the application manifest and the assemblies of an application. This file also includes all the licensing terms required for using the applications.

When you create a .xap file, you need to sign into the developer portal (App Hub) and submit the package for certification so that your applications can be made available for different users. Your application needs to fulfill all the Windows Phone Marketplace certification requirements to get certified. This certification process ensures that your application fulfills all the rules and regulations of the market and permits you to distribute the application to consumers.

After all the certification requirements are satisfied, you can publish your application to the Windows Phone Marketplace. The applications are now ready-to-use and the consumers can now download the application from the Windows Phone Marketplace.

Once the application is published to the Windows Phone Marketplace, it is the responsibility of the developers to manage its different versions. It also includes reviewing the feedback given by the users and responding to that feedback.

## Installation Process of Windows Phone Application Tools

As already discussed, if you want to create Windows Phone 7 applications, you need to install the Windows Phone Application Tools on your system. Windows Phone Application Tools is a set of tools consisting of Visual Studio 2010 Express, Expression Blend, XNA Game Studio 4.0, and Silverlight for Windows Phone. This tool is available for free on the Microsoft Web site.

The following are the system requirements for the successful installation of Windows Phone Application Tools:

- Windows 7 (x86 and x64) or Windows Vista (x86 and x64)
- 2 GB of RAM and 3 GB of free disk space

You should also note that Windows Phone Application Tools is not supported in Windows XP or Windows Server.
