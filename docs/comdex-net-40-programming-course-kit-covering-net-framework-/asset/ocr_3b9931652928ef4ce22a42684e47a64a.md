[access-modifier] interface <InterfaceName>

    // method declarations

```

In the preceding syntax:

+   - **access-modifier**: Specifies the scope in which the interface can be accessed
+   - **interface**: Represents a keyword that declares an interface
+   - **InterfaceName**: Specifies a name for the interface

The following code snippet shows how to define an interface:

```
```csharp
interface MyInterface
{
    void DisplayMarks(int m);
}
```
```

The preceding code snippet shows the definition of an interface, **MyInterface**, which has a method, **DisplayMarks()**. The **DisplayMarks()** method takes an int type of parameter and does not return any value.

# Implementing an Interface

You can use the functionality of an interface by implementing the interface through a class. An interface can be implemented by multiple classes. Moreover, a single class can implement multiple interfaces. The class that implements an interface must provide implementation for all the methods of the interface that is being implemented. As with inheritance, a colon (:) is used to indicate that a class implements an interface. The syntax to implement an interface is as follows:

```
```csharp
class <ClassName> : <InterfaceName>
```
```

In the preceding syntax, **class** is a keyword indicating that a class is declared, **ClassName** specifies the name of the class being declared, and **InterfaceName** specifies the name of the interface that is implemented by the class.

The following code snippet shows how to implement an interface:

```
```csharp
public class MyClass : MyInterface
{
    private int marks;
    public void DisplayMarks(int m)
    {
        marks = m;
        Console.WriteLine(marks);
    }
}
```
```

The preceding code snippet shows the definition of a class, **MyClass**, which implements the **MyInterface** interface. In the **MyClass** class, we have declared a variable, **marks**, and provided implementation for the **DisplayMarks()** method of the **MyInterface** interface.

# Inheriting an Interface

Similar to inheriting a new class from a base class, you can inherit a new interface from an existing interface. The derived interface inherits all the members of the base interface. Suppose, you have a class that implements an interface derived from another interface. Now, when you call a method of the base interface by using an object of the class, then the entire interface definitions are searched by using the inheritance hierarchy to find that particular method.
