Perform the following steps to understand how to create a data service and consume it through a client:

+   1. Select **File→New→Web Site** to open the New Web Site dialog box.
+   2. Select **Visual C#** from the Installed Templates pane and the **ASP.NET Web Site** template from the middle pane of the Add New Web Site dialog box.
+   3. Enter the name of the application, say **DataService**, and click the **OK** button. The **DataService** application is created.
+   4. *Right-click* the name of the application and select the **Add New Item** option from context menu, (Fig.ASP-10.28).
+   5. Select **Visual C#** from the Installed Templates pane and **ADO.NET Entity Data Model** from the middle pane and then click the **Add** button in the Add New Item dialog box, (Fig ASP-10.29).

![](bbox=[0.203, 0.295, 0.4, 0.494])

![](bbox=[0.434, 0.294, 0.822, 0.495])

The **Entity Data Model Wizard** appears.

+   6. Select the **Generate from database** option and click the **Next** button, (Fig.ASP-10.30).

The next page for the Entity Data Model Wizard appears, prompting the user to select a data connection, (Fig.ASP-10.31).

![](bbox=[0.207, 0.585, 0.5, 0.785])

![](bbox=[0.524, 0.585, 0.82, 0.785])

+   7. Select a data connection from the **Which data connection should your application use to connect to the database?** list, as shown in Fig.ASP-10.31 combo box. You can also create a new connection by clicking the **New Connection** button. In this case, we are using the connection already created to connect to the **northwnd** database (Fig.ASP-10.31).
