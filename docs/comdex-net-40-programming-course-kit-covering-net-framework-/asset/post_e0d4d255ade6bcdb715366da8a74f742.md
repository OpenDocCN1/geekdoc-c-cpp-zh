**Listing 7.17: Handling the Load Event of the Form**

```vb
Private Sub Form1_Load(ByVal sender As System.Object, ByVal e As System.EventArgs) Handles MyBase.Load
    Dim customers = New List(Of Customer)(New Customer() {New Customer With {.Key = _
        1, .Name = "John"}, New Customer With {.Key = 2, .Name = "Peter"}, _
        New Customer With {.Key = 3, .Name = "David"}, New Customer With {.Key = 4, _
        .Name = "Mark"}, New Customer With {.Key = 5, .Name = "Steve"}})
    Dim orders = New List(Of Order)(New Order() {New Order With {.Key = _
        1, .Order = "Order 1"}, New Order With {.Key = 2, .Order = _
        "Order 2"}, New Order With {.Key = 3, .Order = "Order 3"}, _
        New Order With {.Key = 4, .Order = "Order 4"}, New Order With {.Key = 5, _
        .Order = "Order 5"}})
    Dim query = From c In customers Join o In orders On c.Key Equals o.Key _
        Select New With {c.Name, o.Order}
    For Each q In query
        ListBox1.Items.Add(q.Order.ToString() & " --> " & q.Name)
    Next q
End Sub
```

Listing 7.17 shows the code for the event handler of the Load event of Form1. In the highlighted code snippet, we first create a list of **Customer** objects and then create another list of **Order** objects. After this, we use the **Join** clause in a LINQ query to join **Customer** objects with the **Order** objects based on the values in the **Key** fields of both types of objects. Finally, we add the orders along with their respective customers to the **Items** collection of the **ListBox1** control.

## Quantifier Operators

Quantifier operators return a Boolean value (True or False) based on whether or not the elements in a sequence satisfy a given condition. Table 7.9 lists all the quantifier operators in LINQ:

**Table 7.9: Quantifier Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
|---|---|---|
| All | Checks whether or not all the elements in a collection satisfy a condition | Aggregate ... In ... Into All(...) |
| Any | Checks whether or not any element in a collection satisfies a condition | Aggregate ... In ... Into Any() |
| Contains | Determines whether a collection contains a specified element | Not available |

## Generation Operators

Generation operators help in creating a new sequence of values. It means that there is already a collection of value, which is in a particular sequence; however, you can also select a range of values or repeating values from that collection and put them in a different sequence.

Table 7.10 lists all the generation operators in LINQ:

**Table 7.10: Generation Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
|---|---|---|
| DefaultIfEmpty | Retrieves the elements of a specified collection or a default value in case the specified collection is empty | Not available |
| Empty | Returns an empty collection | Not available |
| Range | Creates a new collection with the help of a given range of values | Not available |
| Repeat | Creates a new collection by repeating a single value a specified number of times | Not available |

## Element Operators

Element operators are operators that return only one element from a sequence. It means that when you want to retrieve only one value from a particular sequence, you can use Element operators.

Table 7.11 lists all the element operators in LINQ:

**Table 7.11: Element Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
|---|---|---|
| ElementAt | Retrieves the element at a specific index in a collection. | Not available |
| ElementAtOrDefault | Retrieves the element at a specific index in a collection; or a default value if the specified index is out of range or not available. | Not available |
| First | Retrieves the first element in a collection; or the first element that satisfies a given condition from a collection. | Not available |
| FirstOrDefault | Retrieves the first element of a collection or the first element that satisfies a given condition. It returns a default value if there is no such element. | Not available |
| Last | Retrieves the last element in a collection; or the last element that satisfies a given condition from a collection. | Not available |
| LastOrDefault | Retrieves the last element from a collection; or the last element that satisfies a given condition from a collection; or a default value if no element in the collection satisfies the given condition. | Not available |
| Single | Retrieves an element from a collection containing only one element; or the element that satisfies a given condition from a collection. | Not available |
| SingleOrDefault | Retrieves the only element of a collection; or the only element that satisfies a given condition; or a default value if no element in the collection satisfies the given condition. | Not available |
