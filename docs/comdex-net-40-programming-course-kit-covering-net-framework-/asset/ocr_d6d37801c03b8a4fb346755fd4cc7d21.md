# Using the For...Each Statement

The For...Each statement iterates through all the items in a list, which may be an array or a collection of objects. This statement works in the same way as the For...Next statement. The syntax of the For...Each statement is as follows:

```
```vb
For Each element [ As datatype ] In group
    [ statements ]
    [ Exit For ]
    [ statements ]
Next [ element ]
```
```

In the preceding syntax, element is required in the For...Each statement, but it is optional in the Next statement; datatype determines the data type of the element, but is required only if the element is not already declared; group refers to collections based on which iterations are to be repeated; statements refer to a set of statements between the For...Each and Next statements that are executed for each item in the group; Exit For takes the control out of the For...Each loop; and finally, Next terminates the definition of the For...Each loop.

Perform the following steps to use a For...Each statement in a Console application:

+   1. Start Visual Studio 2010.
+   2. Select **File→New→Project** from the menu bar. The **New Project** dialog box appears.
+   3. Select **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. Select **Console Application** from the middle pane to create a Console application.
+   5. Enter the name, **FOREACH**, in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. Click the **OK** button to close the **New Project** dialog box. The **FOREACH** application (also available on the CD) is created.
+   7. Add the highlighted code snippet, shown in Listing 1.4, to the **Module1.vb** file:

**Listing 1.4: Writing the For...Each Statement**

```
```vb
Module Module1
    Sub Main()
        Dim num As Integer() = {10, 20, 30, 40, 50}
        Console.WriteLine("Iteration using For...Each statement:")
        For Each i As Integer In num
            Console.WriteLine(i)
        Next
        Console.ReadLine()
    End Sub
End Module
```
```

In Listing 1.4, you have declared an Integer array, num, with five values and printed the elements of the array by using a For...Each statement.
