Windows Forms is one of the primary technologies in .NET used to develop Windows-based desktop applications. It provides various controls, such as labels, radio buttons, tool strips, and menu strips, to design the User Interface (UI) of your applications. It also provides namespaces, classes, and methods to manipulate the behavior of the controls and applications. However, if you want to use two-dimensional (2D) graphics, three-dimensional (3D) graphics, and multimedia (audio, video, and images) in your Windows Forms application, then you need to use various Application Programming Interfaces (APIs) of additional technologies, such as Graphics Device Interface (GDI+), Windows Media Player, and DirectX. Therefore, .NET Framework has incorporated a new technology known as Windows Presentation Foundation (WPF), which was previously known as Avalon, to address the issues of employing different technologies to work with 2D and 3D graphics and multimedia in Windows Forms applications. WPF is a combination of various technologies, such as GDI+, Windows Media Player, and DirectX, to facilitate the development of high-end desktop applications. With WPF, you can easily and conveniently develop graphic-rich desktop applications because of its support for multimedia such as text, images, audio, video, and 2D and 3D graphics that was not available for Windows Forms applications.

In this chapter, you learn about the improvements in WPF 4.0 and the architecture of WPF 4.0. You also learn about the various types of WPF applications and their implementations. In addition, you learn about the WPF 4.0 Designer and the use of Extensible Application Markup Language (XAML) in WPF. Towards the end, you learn about the controls of WPF and their implementations.

Let’s begin by discussing the improvements in WPF 4.0.

# Exploring the Improvements in WPF 4.0

WPF forms an essential component of the .NET Framework that enables .NET application developers to create WPF applications with graphic-rich UIs. Using WPF 4.0, .NET developers can integrate functionalities, such as 3D graphics, multimedia, animation, document support, and speech recognition into their applications. In the new version of .NET Framework, WPF has been improved for building Windows applications that have a modern graphical UI. The improvements in WPF 4.0 are as follows:

+   - **Addition of new controls:** Refers to the introduction of the new controls, such as **DataGrid**, **Calendar**, and **DatePicker**. These controls enable application developers to create enhanced enterprise-level applications. In addition, these controls are 100% compatible with their Silverlight versions, which allow the reuse of code between Silverlight and WPF implementations.

+   - **Touch input and their manipulation:** Refers to the support for touch input that WPF 4.0 elements provide. Touch input means providing the input by touching the particular screen. The **UIElement**, **UIElement3D**, and **ContentElement** classes consist of events that are raised when a user touches an element on a touch-screen. In addition to touch events, the **UIElement** class supports manipulation events that interpret the touch input as certain user actions. For example, you can create a map viewing WPF application, which you can move, zoom, resize, or rotate by touching the computer screen.

+   - **New text rendering stack:** Refers to the improvements made in rendering text, which include text clarity, configurability, and support for international languages. In addition, the text stack includes support for the display-optimized character layout and snapping for either animated or static text.

+   - **Improved support for deployment:** Implies the improvements that have been made to the deployment size, time, and the overall deployment experience. A WPF application can either target the standard installation of the full **.NET Framework 4 Client Profile** or **.NET Framework 4.0**. **.NET Framework 4 Client Profile** is a subset of the full **.NET Framework 4.0**. The overall application deployment experience is improved when WPF applications target **.NET Framework 4 Client Profile**, as it contains only those functionalities that are required by desktop applications, such as Windows Forms and WPF. Therefore, instead of targeting the full **.NET Framework 4.0**, most of the desktop applications target **.NET Framework 4 Client Profile**.
