The following code snippet is added into the source code of the Web page as soon as an ImageButton control is placed on the Web Form:

```
<asp:ImageButton ID="ImageButton1" runat="server" />
```

It is an ImageButton control so you can add an image on it by setting the ImageUrl property of the ImageButton control.
