# Setting the Startup Form

A startup form is the first form displayed when an application having two or more forms is loaded. By default, **Form1** is the startup form. You can make a form as the startup form if you want to make it the first form to display when the application is executed.

Perform the following steps to set a form as the startup form:

+   1. *Open* the **MULTIPLEFORMS** application.
+   
+      By default, **Form1** is the startup form of the application. To make **Form2** as the startup form, you need to open Project Designer.
+   
+   2. *Select* **Project→MULTIPLEFORMS Properties** from the menu bar to open MULTIPLEFORMS properties window, (Fig.VB-2.30).
+   
+      The MULTIPLEFORMS properties window appears (Fig.VB-2.31).
+   
+   3. *Select Form2* from the combo box under the **Startup form** option, (Fig.VB-2.31).
