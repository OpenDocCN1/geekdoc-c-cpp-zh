# Output Window

When you compile or execute .NET applications, several messages are generated and displayed in the Output window. This window displays these messages depending on the status of the compilation or execution of the application.

Fig.VS-2.26 displays the Output window when a Windows Forms application is compiled:

![](bbox=[0.356, 0.221, 0.667, 0.277])

Fig.VS-2.26

You can specify whether or not you want to view the messages of compilation or execution by selecting the Build or Debug option from the Show output from drop-down list that appears on the toolbar of the Output window.

> To open the Output window, select the View>Output option from the menu bar or press the CTRL+ALT+O keys.

# Object Browser

Object Browser allows you to view entities or objects, such as namespaces, classes, properties, methods, and events that are available for an application. Object Browser has three panes:

+   - **Objects pane:** Appears on the left side of Object Browser
+   - **Members pane:** Appears on the upper-right side of Object Browser
+   - **Description pane:** Appears on the lower-right side of Object Browser

The Objects pane of Object Browser displays the available assemblies as nodes. You can expand the nodes and view the namespaces that exist in the assembly as the child nodes of the expanded node. When you expand a namespace node, you can view the classes contained in the namespace. Further, when you select a class, its properties and methods appear in the Members pane and a description about the class appears in the Description pane of Object Browser, as shown in Fig.VS-2.27:
