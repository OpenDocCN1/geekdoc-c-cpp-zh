# ## Developing a WPF Application

In Visual Studio 2010, you can easily and quickly develop graphic-rich WPF applications by using two-dimensional (2-D), three-dimensional (3-D), audio files, and video files. WPF applications are of the following two types:

+   - **Stand-alone WPF applications:** Refers to the WPF applications that are similar to Windows Forms applications and are installed on the user’s computer.
+   - **XAML browser applications (XBAP):** Refers to the WPF applications that are hosted on a Web server and are run in a Web browser, such as Internet Explorer.

Visual Studio 2010 provides you with project templates for developing both stand-alone WPF applications as well as XBAPs. In this section, you learn to develop a stand-alone WPF application.

> > You learn how to develop XBAPs in Chapter 5, Windows Presentation Foundation, of Visual Basic 2010 section.
