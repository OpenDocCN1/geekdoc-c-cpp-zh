# ## Logical Errors

**Logical errors** are considered as the most difficult errors to be found and removed. These errors appear due to some incorrect logic used while coding a program. Another thing about these errors is that they are difficult to be fixed, as their origin is not always clear. The result of these errors is that they do not disrupt the execution of the application, but due to these errors the expected output does not appear.

Let’s create a new Windows application to understand logical errors, by performing the following steps:

+   1. _Start_ Visual Studio 2010.  
+   2. _Select_ **File→New→Project** from the menu bar. The **New Project** dialog box opens.  
+   3. _Select_ **Visual C#→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.  
+   4. _Select_ **Windows Forms Application** in the right pane to create a Windows Forms application.  
+   5. _Enter_ the name of the application as **Logical_Errors** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** box.  
+   6. Click the **OK** button to close the **New Project** dialog box. The **Logical_Errors** application is created (Fig.C#-7.14).  
+   7. _Select_ the Form1 and press the **F4** key to open the **Properties** window of Form1 (Fig.C#-7.14).  
+   8. _Set_ the **Text** property of Form1 to **Logical Error** (Fig.C#-7.14).  
+   9. _Drag_ a **Label** control from the **Toolbox** and _drop_ it onto the **Form1** form, as shown in Fig.C#-7.14.
