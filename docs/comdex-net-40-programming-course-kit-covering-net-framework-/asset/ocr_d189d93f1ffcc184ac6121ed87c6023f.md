# Filtering Operator

Filtering refers to an operation that modifies a result set according to the specified condition in such a manner that it contains only those elements that satisfy a specified condition. Table 6.4 lists all the filtering operators in LINQ.

| Table 6.4: Filtering Operators in LINQ |  |  |
|---|---|---|
| **Operator** | **Description** | **Query Expression Syntax (C#)** |
| OfType | Selects those values from a set of values that can be converted to a specified type | Not available |
| Where | Selects those values from a set of values that satisfy a given condition | where |

Perform the following steps to filter data by using the **where** clause:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual C#→Windows** from the **Installed Templates** section in the left pane of the New Project dialog box. The project templates available for developing Windows-based applications in C# are displayed in the right pane of the New Project dialog box.
+   4. *Select* the **Windows Forms Application** template in the right pane to create a Windows Forms application.
+   5. *Enter* the name of the application as **FilteringOperator** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box. The **FilteringOperator** application is created (Fig.C#-6.11).
+   7. *Drag* and drop two **Label** controls, two **ListBox** controls, and a **Button** control on the form from the **Toolbox**.
+   8. *Set* the **Text** property of the **Label** controls to **Before Filter** and **After Filter**, respectively, and the **Text** property of the **Button** control to **Filter Data**, by using the **Properties** window, as shown in Fig.C#-6.11.
