
## Using the RequiredFieldValidator Control

The **RequiredFieldValidator** control ensures that the user has entered the required data in the input control, such as the **TextBox** control, to which it is associated. For example, if you are entering data to buy a T-shirt in an input control, then it is necessary to enter the size of the T-shirt that you want to buy. If you do not enter the size, the validation control displays an error message. The **RequiredFieldValidator** control exists within the **System.Web.UI.WebControls** namespace.

The noteworthy property of the RequiredFieldValidator class is listed in Table 4.3:

**Table 4.3: Noteworthy Property of the RequiredFieldValidator Class**

| Property | Description |
|---|---|
| `InitialValue` | Handles the initial value of the associated input control |

## Using the RangeValidator Control

The **RangeValidator** control checks whether or not the value of an input control lies within a specified range. This control exists within the **System.Web.UI.WebControls** namespace. It is also required to define the data types for the data entered in the input control. Therefore, set the **Type** property of the data type for the values in the input control. The following data types are used for the values:

- **String:** Refers to the string data type
- **Integer:** Refers to the integer data type
- **Double:** Refers to the double data type
- **Date:** Refers to the date data type
- **Currency:** Refers to the currency data type

Noteworthy properties of the **RangeValidator** class are listed in Table 4.6:

**Table 4.6: Noteworthy Properties of the RangeValidator Class**

| Property | Description |
|---|---|
| MaximumValue | Obtains or sets the maximum value of the validation range |
| MinimumValue | Obtains or sets the minimum value of the validation range |

![](img/9862a98a1a2d3bb14334137965a1ec60_539_1.png)

> If one of these properties is set, then the other property must also be set.
