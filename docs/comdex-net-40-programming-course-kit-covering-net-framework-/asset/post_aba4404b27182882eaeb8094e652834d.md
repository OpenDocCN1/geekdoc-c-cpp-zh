## Using the Button Control

It allows you to perform some tasks, such as submit the user input or navigate to another page from the current page by generating its Click event. The Click event of the Button control is generated when the user clicks the Button control at run time. The Button class is contained in the System.Web.UI.WebControls namespace.

Noteworthy properties of the Button control are listed in Table 2.6:

| `Text` | Obtains or sets the text caption displayed in the Button control |
| `ValidationGroup` | Obtains or sets the group of controls for which the Button control causes validation when it posts back to the server |

An **ImageButton** control is same as a normal **Button** control with the difference that in an **ImageButton** control, you can put an image, instead of text, on the button.

Noteworthy properties of the **ImageButton** control are listed in Table 2.8:

| Property | Description |
|---|---|
| `Enabled` | Obtains or sets a value indicating whether or not the `ImageButton` control can be clicked to perform a post back to the server |
| `PostBackUrl` | Obtains or sets the URL of the page to post from the current page when the `ImageButton` control is clicked |
| `ValidationGroup` | Obtains or sets the group of controls for which the `ImageButton` control causes validation when it posts back to the server |

The noteworthy event of the **ImageButton** control is listed in Table 2.9:

| Event | Description |
