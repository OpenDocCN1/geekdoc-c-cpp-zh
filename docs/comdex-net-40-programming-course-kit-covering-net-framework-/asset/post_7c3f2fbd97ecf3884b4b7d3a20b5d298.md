## Binding to ADO.NET Objects

You can also bind an ADO.NET object to a WPF application. For example, you can bind a data table to a WPF application. While binding an ADO.NET object to a WPF application, you can implement the **IBindingList** interface to provide change notifications. The **IBindingList** interface provides features to support both complex and simple data binding to a data source.

While binding your WPF application to an ADO.NET object, you need to establish a connection with the data source. After establishing the connection, you need to bind your controls with that data source by specifying the **ItemsSource** and **ItemTemplate** properties and then you need to create an adapter which executes the Structured Query Language (SQL) statement to retrieve a record from a database. The result is stored in the data table of a dataset by calling the Fill() method of the adapter. This result is then displayed in the WPF control.

Perform the following steps to bind an ADO.NET object to a WPF application by creating a WPF application named **BindingtoADO.NET** (also available on the CD):

- 1. *Open* Microsoft Visual Studio 2010.
- 2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box appears.
- 3. *Select* **Visual C#→Windows** in the **Installed Templates** pane of the **New Project** dialog box.
- 4. *Select* **WPF Application** in the middle pane of the **New Project** dialog box.
- 5. *Enter* **BindingtoADO.NET** as the name of the application in the **Name** text box.
- 6. *Enter* the complete path where you want to save the application in the **Location** combo box.
- 7. *Click* the **OK** button in the **New Project** dialog box to close it. The **BindingtoADO.NET** application is created.
