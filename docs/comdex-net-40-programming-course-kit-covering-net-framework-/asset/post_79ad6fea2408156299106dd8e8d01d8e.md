## Zip Operator

The Zip operator is a new operator introduced in LINQ in ASP.NET 4.0, which helps in combining two collections. This operator helps to merge two sequences, which are identical in length, into one. The Zip operator uses the order of elements to combine the elements from two given sequences. This implies that the Zip operator takes an element from the first source and an element from the second source, which is at the same location, and returns a combined type.

## Implementing LINQ to ADO.NET

LINQ to ADO.NET helps you to query on any ADO.NET object using LINQ programming model. It consists of the following three technologies:

- **LINQ to DataSet:** Represents a set of extensions to the standard ADO.NET DataSet programming model. It allows the **DataSet**, **DataTable**, and **DataRow** objects to be a natural target for a LINQ query expression. Moreover, LINQ to DataSet provides richer and optimized querying over datasets.
- **LINQ to SQL:** Allows you to interact with a relational database by removing the ADO.NET data types by the use of entity classes. It means that you can directly interact with database rather than using ADO.NET objects. LINQ to SQL enables you to query directly the SQL Server database schemas.
- **LINQ to Entities:** Allows you to write queries for the Entity Framework conceptual model, which enables users to visually design models and map databases, tables, and views by using Visual Studio 2010 and .NET Framework 4.0.

Let’s now discuss the two important technologies in detail.

### LINQ to DataSet

A dataset is an in-memory representation of data that acts as the core of a wide variety of data-based applications. After data is loaded into a dataset, you often need to perform additional queries on the data. These additional queries are generally executed by using the LINQ to DataSet technology.

LINQ to DataSet provides an easier and faster way to query data cached in a DataSet object as compared to traditional methods of querying the data. LINQ to DataSet simplifies the process of querying by enabling you to write queries in the programming language itself. The query operators allow you to perform LINQ queries on the dataset. To begin querying a dataset by using LINQ to DataSet, you need to confirm whether your dataset is filled with data or not because you cannot get any output or result-set from an empty dataset.

```
Module Module1
    Class Student
        Public Id As Integer
        Public Name As String
    End Class
    Private Function GetDataTable(ByVal students As Student()) As DataTable
        Dim table As DataTable = New DataTable()
        table.Columns.Add("Id", GetType(Integer))
        table.Columns.Add("Name", GetType(String))
        For Each s As Student In students
            table.Rows.Add(s.Id, s.Name)
        Next s
        Return (table)
    End Function
    Sub Main(ByVal args As String())
        Dim students As Student() = {New Student With {.Id = 1, .Name = "A"}, _
            New Student With {.Id = 2, .Name = "B"}, New Student With {.Id = 3, _
            .Name = "C"}, _
            New Student With {.Id = 4, .Name = "D"}, New Student With {.Id = 5, _
            .Name = "E"}, New Student With {.Id = 6, .Name = "F"}}
        Dim dt As DataTable = GetDataTable(students)
        For Each dr As DataRow In dt.Rows
            Console.WriteLine("{0}-{1}-{2}", dr.Field(Of Integer)(0), _
                dr.Field(Of String)(1))
        Next dr
        Console.ReadLine()
    End Sub
End Module
```

Finally, we define the **Sub** procedure, **Main**, which first creates an array of the **Student** objects, then creates an object of the **DataTable** class by calling the **GetDataTable** function, and then displays the data of the **DataTable** object on the screen.
