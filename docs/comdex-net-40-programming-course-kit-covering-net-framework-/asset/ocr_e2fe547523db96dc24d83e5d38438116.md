**Table 7.11: Element Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
|---|---|---|
| FirstOrDefault | Retrieves the first element of a collection or the first element that satisfies a given condition. It returns a default value if there is no such element. | Not available |
| Last | Retrieves the last element in a collection; or the last element that satisfies a given condition from a collection. | Not available |
| LastOrDefault | Retrieves the last element from a collection; or the last element that satisfies a given condition from a collection; or a default value if no element in the collection satisfies the given condition. | Not available |

| SingleOrDefault | Retrieves the only element of a collection; or the only element that satisfies a given condition; or a default value if no element in the collection satisfies the given condition. | Not available |
