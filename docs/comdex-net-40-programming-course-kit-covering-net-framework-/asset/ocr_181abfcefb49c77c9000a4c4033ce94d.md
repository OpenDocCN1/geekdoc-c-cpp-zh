| Table 11.1: Controls in Silverlight 4.0 |  |  |
|---|---|---|
| **Control** | **Description** | **XAML Element Example** |
| Image | Allows you to display a .png or .jpg images. | `<Image Height="300" Width="300" Source="Garden.jpg" />` |
| ItemsControl | Allows you to display a collection of items. Many controls that allow you to display a collection of items inherit the properties of this control. | `<ItemsControl ItemsSource="Silverlight" Height="270" Margin="100,0,0,0" />` |
| Label | Allows you to display a simple caption or message. | `<sdk:Label Content="Hello, this is a Label control" VerticalAlignment="Center" HorizontalAlignment="Center" />` |
| ListBox | Allows you to display a list of items. | `<ListBox Width="80" Height="100">`<br>`<ListBoxItem Content="Apple" Background="Yellow" />`<br>`<ListBoxItem Content="Mango" Background="Orange" />`<br>`<ListBoxItem Content="Strawberry" Background="Plum" />`<br>`</ListBox>` |
| MediaElement | Allows you to host audio and video files. | `<MediaElement Height="100" Width="100" Source="Wildlife.wmv" />` |
| PasswordBox | Allows you to enter the password characters that can not be viewed and understood by the user. | `<PasswordBox x:Name="PwdBox" Margin="210,0,0,0" Height="35" Width="200" PasswordChar="*" HorizontalAlignment="Left" />` |
| ProgressBar | Allows you to indicate the progress of any operation. | `<ProgressBar x:Name="prgbar" Value="100" Margin="178,10,143,10" Maximum="200" Height="15" IsIndeterminate="False" />` |
| Popup | Allows you to temporarily display information on top of some other control. | `<Popup IsOpen="True" HorizontalOffset="20" VerticalOffset="50">`<br>`<Popup.Child>`<br>`<Button x:Name="button1" Content="Hello" Height="30" Width="100" />`<br>`</Popup.Child></Popup>` |
| RadioButton | Allows you to display a radio button to represent an option. | `<RadioButton ClickMode="Press" Content="Apple" Margin="10,0,0,0" />`<br>`<RadioButton ClickMode="Press" Content="Mango" Margin="10,50,0,0" />`<br>`<RadioButton ClickMode="Press" Content="Strawberry" Margin="10,90,0,0" />` |
