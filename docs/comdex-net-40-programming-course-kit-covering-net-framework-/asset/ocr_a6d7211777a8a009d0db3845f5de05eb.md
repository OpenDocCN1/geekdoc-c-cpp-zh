# ***Partitioning Operators***

Partitioning operators in LINQ are used to divide an input sequence into two sections. When a partition is completed, this operator does not rearrange the elements in the input sequence. Finally, it returns the result set with one of the section that satisfies the given condition.

Table 7.6 lists all the partitioning operators in LINQ:

**Table 7.6: Partitioning Operators in LINQ**

| Operator | Description | Query Expression Syntax (Visual Basic) |
|---|---|---|
| Skip | Skips the specified number of elements in a collection and returns rest of the elements | Skip |
| SkipWhile | Skips elements in a collection as long as a specified condition is true, and then returns the rest of the elements | Skip While |
| Take | Retrieves the specified number of elements from a collection | Take |
| TakeWhile | Retrieves elements from a collection as long as a specified condition is true | Take While |
