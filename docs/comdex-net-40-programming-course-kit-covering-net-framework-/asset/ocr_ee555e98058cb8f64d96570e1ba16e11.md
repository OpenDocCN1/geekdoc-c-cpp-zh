# ## The LinqDataSource Control

The **LinqDataSource** control enables the use of Language Integrated Query (**LINQ**) in an ASP.NET Web page. LINQ is a query syntax that enables a set of query operators that enables different operations, such as filtering and sorting of data, to be expressed in a declarative way in a .NET-based programming language. The data can be either an in-memory data collection or an object that represents data from a database.

You can use the **LinqDataSource** control, through markup text, to retrieve and modify data from a data object by setting the properties in the markup text. You can create a **LinqDataSource** control that connects to data either from a SQL database or from an in-memory data collection, such as an array. The **LinqDataSource** control supports automatic generation of select, update, insert, and delete commands. It also supports sorting, filtering, and paging of data.

The **LinqDataSource** control applies the data operations in the following order:

+   - **Where:** Specifies which data records to return
+   - **Order By:** Specifies the order to sort the data
