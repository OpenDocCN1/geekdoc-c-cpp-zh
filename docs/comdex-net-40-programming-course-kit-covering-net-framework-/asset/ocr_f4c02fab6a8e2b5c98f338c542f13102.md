**Table 11.1: Controls in Silverlight 4.0**

| Control | Description | XAML Element Example |
|---|---|---|
| Rectangle | Allows you to display a rectangle. | `<Rectangle Fill="Violet" Height="50" Width="100"/>` |
| RepeatButton | Allows you to provide a button that periodically raises its Click event until the mouse is released. | `<RepeatButton Content="Hello" Delay="30" Interval="90" Height="30"/>` |
| RichTextBox | Allows you to display the formatted text, paragraphs, hyperlinks, or inline images. | `<RichTextBox HorizontalAlignment="Left" Margin="10,12,0,0" Name="contentBox" VerticalAlignment="Top" Height="76" Width="284" IsReadOnly="True"><Paragraph FontFamily="Georgia" FontSize="12" TextAlignment="Justify"></Paragraph></RichTextBox>` |
| ScrollBar | Allows you to provide a scroll bar with a Thumb that you can slide to change the value. | `<ScrollBar Minimum="0" Maximum="50" Value="5" ViewportSize="1" Height="30" Width="200" Margin="0,35"/>` |
| ScrollViewer | Allows you to view some content that can be scrolled using the horizontal and/or vertical scroll bars. | `<ScrollViewer Content="Silverlight" Height="100" Width="100" HorizontalScrollBarVisibility="Visible" VerticalScrollBarVisibility="Visible"/>` |
| Slider | Allows you to provide a slider that has a Thumb, which you can move to select a particular value from the given range of values. | `<Slider Orientation="Horizontal" Value="5" Maximum="100" Minimum="0"/>` |
| StackPanel | Allows you to arrange the containing controls in a horizontal or vertical stack. | `<StackPanel><Button Content="Apple"/><Button Content="Mango"/><Button Content="Strawberry"/></StackPanel>` |
| TabControl | Allows you to display information with the help of tabs. Each tab can hold various other controls. | `<sdk:TabControl Height="200" Width="250"><sdk:TabItem Header="General" Content="This tab has general Information"/><sdk:TabItem Header="Academics"/><sdk:TabItem Header="Professional"/></sdk:TabControl>` |
| TextBlock | Allows you to display text. | `<TextBlock Text="Hello"/>` |
