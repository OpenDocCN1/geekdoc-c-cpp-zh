# ## Using the LoginStatus Control

The LoginStatus control is a Web server control that displays the current status of a user, that is whether or not the user is currently logged in the Web site. The text displayed on this control changes according to the login status of the user. The LoginStatus control has the following views:

+   - **Logged Out:** Displayed when the user is not logged in. In this view, the text Login is displayed on the `LoginStatus` control.
+   - **Logged In:** Displayed when the user is logged in. In this view, the text Logout is displayed on the `LoginStatus` control.

| **Table 5.9: Public Properties of the LoginStatus Class** | |
|---|---|
| **Property** | **Description** |
| `LoginImageUrl` | Retrieves or sets the URL of the image used for the login link |
| `LoginText` | Retrieves or sets the text used for the login link |
