# Explaining Themes

A theme enables you to define appearance of controls and Web pages by setting their properties. It is used when you want to keep the style and layout information files separate from other files of a website. You can define all the settings in the theme file and apply it to all controls and Web pages to maintain consistency throughout the website. It is important to note that whenever you make changes in a theme, the changes are automatically applied to all the controls and Web pages on which the theme is applied. This saves a lot of time as you do not need to apply the same changes on each and every Web page of a website.

Themes include three elements, which are as follows:

+   - **Skin:** Provides tags, property settings, and formatting options for server side controls, such as Label, TextBox, and Button
+   - **Cascading Style Sheet (CSS):** Refers to the mechanism of adding fonts, colors, styles, and behavior to Web pages
+   - **Images:** Helps in making a Web page more interactive and user friendly

In ASP.NET 4.0, there are two types of themes. These are as follows:

+   - **Page theme:** Contains the control skins, style sheets, graphic files, and other resources inside the subfolders of the App_Themes folder, which is located in Solution Explorer. It is applied to a single page of a website. For different themes, separate subfolders are created in the App_Themes folder.
+   - **Global theme:** Includes property settings, style sheet settings, and graphics. This theme allows you to maintain all the websites on the same Web server and define the same style for all the Web pages.
