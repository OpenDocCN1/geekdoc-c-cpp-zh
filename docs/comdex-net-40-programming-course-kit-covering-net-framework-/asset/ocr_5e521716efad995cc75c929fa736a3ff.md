<Window x:Class="BindingtoADO.NET.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"

                <LinearGradientBrush>
                    <GradientStop Color="Bisque" Offset="0"/>

                <GridView>
                    <GridViewColumn Header="Employee ID" DisplayMemberBinding="{Binding Path=EmployeeID}"/>
                    <GridViewColumn Header="First Name" DisplayMemberBinding="{Binding Path=FirstName}"/>
                    <GridViewColumn Header="Last Name" DisplayMemberBinding="{Binding Path=LastName}"/>
                    <GridViewColumn Header="City" DisplayMemberBinding="{Binding Path=City}"/>
                    <GridViewColumn Header="Country" DisplayMemberBinding="{Binding Path=Country}"/>
                </GridView>
            </ListView.View>
        </ListView>

In Listing 5.16, we have added a **ListView** control in an application. Next, we have bound this control with the **Employees** table by using the **ItemSource** and the **ItemTemplate** properties. After that, a **GridView** control is added in the **ListView** control and the different columns of the **GridView** control are bounded with the different columns of the **Employees** table using the **DisplayMemberBinding** property.
