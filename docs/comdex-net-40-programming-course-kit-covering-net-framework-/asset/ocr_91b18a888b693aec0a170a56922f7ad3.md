# Server Explorer

Server Explorer is a window that you use to connect to a database file, database server, and other services on the computer. Server Explorer allows you to not only add tables but also to create, modify, query, and close connections to databases. In addition, you can use Server Explorer to view the resources of the servers, such as services, processes, and the event log.
