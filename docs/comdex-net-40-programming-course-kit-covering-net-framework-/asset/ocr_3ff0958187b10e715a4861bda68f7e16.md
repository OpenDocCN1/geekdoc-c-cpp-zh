# Binding to ADO.NET Objects

You can also bind an ADO.NET object to a WPF application. For example, you can bind a data table to a WPF application. While binding an ADO.NET object to a WPF application, you can implement the **IBindingList** interface to provide change notifications. The **IBindingList** interface provides features to support both complex and simple data binding to a data source.

While binding your WPF application to an ADO.NET object, you need to establish a connection with the data source. After establishing the connection, you need to bind your controls with that data source by specifying the **ItemSource** and **ItemTemplate** properties and then you need to create an adapter which executes the Structured Query Language (SQL) statement to retrieve a record from a database. The result is stored in the data table of a dataset by calling the Fill() method of the adapter. This result is then displayed in the WPF control.
