| **Table 3.13: Noteworthy Properties of the ListBox Class** |  |
|---|---|
| **Property** | **Description** |
| SelectionMode | Obtains the mode with which items are selected |
| Sorted | Obtains or sets a value indicating whether the items in the list box are sorted alphabetically |

The SelectionMode property allows you to specify how many items can be selected from the list box at a time. You can use this property to allow multiple selections in a list box. The SelectionMode property can be set to any of the following values:

+   - **None:** Implies that no items can be selected from the list box
+   - **One:** Implies that only one item can be selected from the list box
+   - **MultiSimple:** Implies that multiple items can be selected from the list box
+   - **MultiExtended:** Implies that multiple items can be selected from the list box, and the user can use the SHIFT, CTRL, and arrow keys to make the selections
