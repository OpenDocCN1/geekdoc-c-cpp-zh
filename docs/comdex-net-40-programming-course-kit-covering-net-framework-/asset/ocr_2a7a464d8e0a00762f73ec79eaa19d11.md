# ## Using the TextBox Control

If you want to allow users of your WPF application to enter textual data, you can use the **TextBox** control. It facilitates to enter or display formatted text. With the TextBox control, you can manipulate the text entered in it by performing various operations, such as aligning the text, wrapping the text around the control, and specifying the casing of the text. The TextBox control is an instance of the **TextBox** class, which is derived from the **TextBoxBase** class. Table 5.4 lists the noteworthy properties of the TextBox class:

| Table 5.4: Noteworthy Properties of the TextBox Class |  |
|---|---|
| **Property** | **Description** |
| CharacterCasing | Returns or sets a value that indicates the casing of the characters of the text when you enter the text in the TextBox control |
| MaxLength | Returns or sets the maximum number of characters that you can enter in the TextBox control |
| Text | Returns or sets the text contained in the TextBox control |
| TextAlignment | Returns or sets the horizontal alignment of the text in the TextBox control |
| TextWrapping | Returns or sets a value that indicates how the text is wrapped in the TextBox control |
