# # The Book at a Glance

The book comprises of 3 modules, each fulfilling the requirements to master Visual Basic 2010, C# 2010, and ASP.NET 4.0, and ensuring an easy to learn path in an effective manner. Let's discuss each module and the key points included in it.

![](bbox=[0.072, 0.155, 0.199, 0.252])

# ## Visual Basic 2010

Module 1 of the book introduces you to the basics of Visual Basic 2010. The module covers the basic of Visual Basic 2010 and the different Windows Forms controls. In addition, the module briefly describes the key terms, concepts and conventions used in creating a .NET application using Visual Basic 2010. This module also teaches you the steps that are used to create a basic Windows Forms application and the various events and methods associated with the different Windows Forms controls, which are integral to programming. Apart from creating a basic Windows Forms application, you also learn to create an application that uses two-dimensional graphics, three-dimensional graphics, and multimedia; by using a new technology known as Windows Presentation Foundation. Towards the end of the module, you learn about using built-in tools and workflows to perform a particular action by using Windows Workflow Foundation, using Language Integrated Query to query a data source.

![](bbox=[0.071, 0.37, 0.196, 0.465])

# ## C# 2010

Module 2 of the book familiarizes you with the modern, high-level, robust, powerful, and object-oriented programming language that is, C# 2010. You learn about the new and enhanced features of C# 2010, such as call hierarchy, live semantic errors, and the new command-line compiler options. The various keywords and identifiers used to create a C# application are also explained in this module. You also learn not only the basics of Object Oriented Programming but also the new concept introduced in C# 2010; that is dynamic programming. Apart from this, you learn to work with ADO.NET, implement data binding, use Language Integrated Query in a C# application. In addition you also learn to develop a perfect application by learning how to detect and address any errors and handle exceptions.

![](bbox=[0.071, 0.565, 0.196, 0.66])

# ## ASP.NET 4.0

Module 3 of the book familiarizes you with technology that is commonly used to create dynamic Web pages for Web sites, ASP.NET 4.0. You learn about the standard, navigation, validation, login, database, and WebParts controls, which are used to create not only small, personal Web sites but also large, enterprise-level Web sites. You also learn to use master pages and themes on different Web pages so as to provide a consistent look throughout the website and implement caching in a Web page so as to temporarily store the frequently accessed Web pages in memory. Apart from this, you learn about one of the important features of ASP.NET that allows a Web site to communicate with other Web sites irrespective of the programming languages in which they are created, Web service. This module also introduces you to Silverlight 4.0, which is used to create Web sites that can have high-resolution multimedia content and eye-catching visual effects.
