The **MenuStrip** class, which is placed inside the **System.Windows.Forms** namespace, provides the functionality for the **MenuStrip** control. Table 4.7 lists the noteworthy properties of the **MenuStrip** class:

**Table 4.7: Noteworthy Properties of the MenuStrip Class**

| Property | Description |
|---|---|
| CanOverflow | Returns or sets a value that indicates whether the **MenuStrip** control supports overflow functionality |

| Stretch | Returns or sets a value that indicates whether the **MenuStrip** control stretches from one end to another end in its container |

| Event | Description |

The **MenuStrip** control is only a container for the menus. After adding a **MenuStrip** control in a Windows Forms application, you need to add the menus and their menu items manually. You can also add separators to menu items, assign shortcut keys for menus and menu items, display check marks for menu items, and create submenus.

You can also add access keys to menus and menu items. An access key is a character that you can use with the ALT key to access or select a menu or menu item. To specify an access key for a menu or menu item, you need to prefix the character, which you want to make the access key, with an ampersand (&) in the Text property of the menu or menu item. The access key appears underlined in the menu or menu item name. For example, if you specify the Text property of the File menu as &File, then f (or F) becomes the access key for the File menu.

**Table 4.9: Noteworthy Common Properties of the Menus and Menu Items**

| Property | Description |

| Enabled | Returns or sets a value that indicates whether the menu (or menu item) is enabled |

You can follow some conventions related to menus and menu items to make Windows Forms applications more user-friendly. These conventions are as follows:

- If selecting a menu item opens a dialog box, then you can add an ellipsis (...) after the name of the menu item (for example, Print...).
- If a menu item performs a particular action immediately instead of opening a submenu, then you can append an exclamation point (!) to the name of the menu item (for example, Connect!).
- You should place the File menu as the first menu with the Exit item as its last menu item.
- You should use separator lines to group logically related menu items together on the menu drop-down list.

Perform the following steps to use the **MenuStrip** control in a Windows Forms application:

1. *Start* Visual Studio 2010.
2. *Select* **File→New→Project** from the menu bar. The New Project dialog box opens.
3. *Select* **Visual Basic→Windows** from the Installed Templates section in the left pane of the **New Project** dialog box.
4. *Select* the **Windows Forms Application** template in the middle pane to create a Windows Forms application.
5. Enter the name of the application as **MyMenuStrip** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
6. *Click* the **OK** button to close the **New Project** dialog box. The **MyMenuStrip** application is created (Fig.VB-4.8).
7. *Drag and drop* a **MenuStrip** control on the form from the **Menus & Toolbars** tab of the **Toolbox**. The **MenuStrip** control is added to the form as well as to the component tray (Fig.VB-4.8).

    In Fig.VB-4.8, the **MenuStrip** control displays a text box with the placeholder text **Type Here**. You can type the name of a menu in the **Type Here** text box.
8. *Click* inside the **Type Here** text box to specify the name of a menu, as shown in Fig.VB-4.8:
