# ## The ZIP Operator

The Zip operator is a new operator introduced in LINQ in ASP.NET 4.0 that helps in combining two collections. This operator helps to merge two collections, which are identical in length, into one. The Zip operator uses the order of elements to combine the elements from two given collections. This implies that the Zip operator takes an element from the first source and an element from the second source, which is at the same location, and returns a combined type.

Perform the following steps to implement the Zip operator in C#.

+   1. *Start* **VisualStudio2010**.
+   2. *Select* **File→New→Project** from the menu bar. The New Project dialog box opens.
+   3. *Select* **Visual C#→Windows** from the Installed Templates section in the left pane of the New Project dialog box. The project templates available for developing Windows-based applications in C# are displayed in the right pane of the New Project dialog box.
+   4. *Select* the Windows Forms Application template in the right pane to create a Windows Forms application.
+   5. Enter the name of the application as **ZipOperator** (also available on the CD) in the Name text box and an appropriate location for the application in the Location combo box.
+   6. *Click* the **OK** button to close the New Project dialog box. The **ZipOperator** application is created (Fig.C#-6.27).
+   7. *Drag* and drop a **ListBox** control and a **Button** control on the form from the Toolbox.
+   8. *Set* the Text property of the **Button** control to **Display** by using the Properties window, as shown in Fig.C#-6.27.
