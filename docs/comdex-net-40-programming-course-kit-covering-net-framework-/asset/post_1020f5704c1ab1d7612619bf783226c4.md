### Using the ProgressBar Control

In several situations, the task of copying or printing of a large file, or installation of an application on your computer, may take a long time to complete. In such situations, if the user is not notified about the running operation, the user may assume that the application is not working. You can avoid the misconception and provide an interactive display of the running operation by using the ProgressBar control, which indicates that the operation is in progress.

In other words, the ProgressBar control allows you to provide a visual representation of the progress of an operation. It displays the progress in a horizontal bar in which the number of segmented blocks increases from left to right depending on the progress. The ProgressBar class, which is included in the System.Windows.Forms namespace, provides the functionality for the ProgressBar control. Table 3.21 lists important properties of the ProgressBar class:

**Table 3.21: Noteworthy Properties of the ProgressBar Class**

| Property | Description |
| MarqueeAnimationSpeed | Obtains or sets the duration (in milliseconds) that the progress block takes to scroll through the ProgressBar control. |
| Maximum | Obtains or sets the maximum value of range of the ProgressBar control. When the progress reaches to this value, the specified operation completes. |
| Minimum | Obtains or sets the minimum value of range of the ProgressBar control. |
| RightToLeftLayout | Obtains or sets a value indicating whether the ProgressBar control and any text it contains are displayed from right to left. |
| Step | Obtains or sets an integer value by which the PerformStep method increments the position in the ProgressBar control. |
| Style | Obtains or sets the style in which the progress appears in the ProgressBar control. |
| Value | Obtains or sets an integer value to specify the current position of the ProgressBar control. |

Table 3.22 lists the important methods of the ProgressBar class:

**Table 3.22: Noteworthy Methods of the ProgressBar Class**

| Method | Description |
| Increment | Increments the current position of the ProgressBar control by the specified amount, which is an integer value |
| PerformStep | Increments the current position of the ProgressBar control by the amount specified in the Step property |

### Using the ToolStrip Control

The ToolStrip control offers a strip of tools or controls (also called tool strip items) that correspond to the common options, such as layout options and frequently performed tasks, such as saving and opening files. With the ToolStrip control, you can design your Windows Forms application with a rich yet compact UI, provide users a quick way to select the desired options, and perform the required tasks. The ToolStrip class, which is placed inside the **System.Windows.Forms** namespace, provides the functionality for the ToolStrip control.
