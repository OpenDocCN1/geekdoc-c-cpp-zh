These files are described as follows:

+   - **An ASP.NET file:** Hosts the **MainPage.xaml** file and is loaded when a Silverlight application runs. In our case, the ASP.NET file is **SilverlightApplication1TestPage.aspx** (Fig.ASP-11.12). This page is the default startup page of a Silverlight 4.0 application.
+   - **An HTML file:** Hosts the Silverlight application. In our case, the HTML file is **SilverlightApplication1TestPage.html**.
+   - **A JavaScript helper file:** Provides methods, such as **createObject()** and **createObjectEx()**, to embed a Silverlight application in a Web page. The **createObject()** and **createObjectEx()** methods are used to create and initialize the Silverlight content in an aspx or html test page that hosts the Silverlight application. In our case, the Silverlight helper file is **Silverlight.js**.

In addition to these files, there is one more important file that is created after the compilation of the Silverlight application. It is known as **Application Package** and it's extension is **.xap**.
