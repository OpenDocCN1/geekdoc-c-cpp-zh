The AccessDataSource control uses the **DataFile** property to specify the location of the Access file (.mdb file) that you want to use to access the data.

> > **You should save the Access file in the App_Data folder of the Web site and refer to the file by using a relative path, such as ~/App_Data/Northwind.mdb.**

The AccessDataSource control is inherited from the **AccessDataSource** class which defines several properties and methods that this control supports. Some noteworthy properties of the **AccessDataSource** class are given in Table 6.3:

**Table 6.3: Noteworthy Properties of the AccessDataSource Class**

| Property | Description |
|---|---|
| ConnectionString | Specifies the connection string to connect to the Microsoft Access database |
| DataFile | Retrieves the location of the .mdb file |
| ProviderName | Retrieves the name of the .NET data provider used to connect to the MS Access database |

Table 6.4 lists the noteworthy methods of the **AccessDataSource** class:

**Table 6.4: Noteworthy Methods of the AccessDataSource Class**

| Method | Description |
|---|---|
| Select | Retrieves the records or data from an Access database |
| Insert | Inserts the records or data into an Access database |
| Delete | Deletes the records or data from an Access database |
| Update | Updates the records or data in an Access database |
