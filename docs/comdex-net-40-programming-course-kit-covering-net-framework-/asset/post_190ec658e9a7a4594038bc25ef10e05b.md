## Using the RadioButton Control

The **RadioButton** control, also known as the option button, is used to select an option from a set of options. Radio buttons always work in groups, which implies that when you select one radio button from a group of radio buttons, the other radio buttons in the group are automatically deselected. A radio button can display text, image, or both. The **RadioButton** class, which is derived from the **System.Windows.Forms** namespace, provides the functionality for the **RadioButton** control. Some important properties of the **RadioButton** class are listed in Table 3.8:

**Table 3.8: Noteworthy Properties of the RadioButton Class**

| Property | Description |
|---|---|
| Appearance | Obtains or sets a value that determines the appearance of the RadioButton control |
| AutoCheck | Obtains or sets a value indicating whether the Checked value and the appearance of the control automatically change when the radio button is selected |
| AutoSize | Obtains or sets a value specifying whether the RadioButton control is automatically resized to display all its contents |
| Checked | Obtains or sets whether the RadioButton control is selected or not |
| Image | Obtains or sets an image displayed on the RadioButton control |
| TextAlign | Obtains or sets the alignment of the text on the RadioButton control |

## Using the ComboBox Control

A **ComboBox** displays a list of items in a drop-down list. It is a combination of a text box in which a user can enter an item and a drop-down list from where the user can select an item. A user can select only a single option from the drop-down list. After the user selects an option, the drop-down list contained in the **ComboBox** automatically collapses. You can also add or remove an item from this drop-down list. Each item in a **ComboBox** control is recognized by its position, known as an index, in the drop-down list.
