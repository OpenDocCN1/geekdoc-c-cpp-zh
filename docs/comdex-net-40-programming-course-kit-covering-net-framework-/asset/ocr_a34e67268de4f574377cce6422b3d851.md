# ## Defining Styles as Resources

One of the most common uses of WPF resources is to apply a given style on several controls or elements uniformly. For example, you may want that all the buttons in your WPF application have the same background color. In such a case, you can define the style that can be applied on multiple controls as a resource.

In WPF, you can use the Style element to define a style as a resource. Each Style element specifies an element to which you want to apply the style. A Style element also has one or more Setter elements that specify the properties of the element to which you want to apply the style and property values. The syntax of the Style element is given as follows:

```
```xml
<Style x:Key="name" TargetType="elementName">
    <Setter Property="propertyName1" Value="propertyValue1"/>
    <Setter Property="propertyName2" Value="propertyValue2"/>
    .
    .
    <Setter Property="propertyNameK" Value="propertyValueK"/>
</Style>
```
```

In the preceding syntax:

+   - **x:Key:** Refers to the key name of the Style element
+   - **TargetType:** Refers to the name of the type of an element on which the style is to be applied
+   - **propertyName1, propertyName2, . . . , propertyNameK:** Refers to the names of the properties
+   - **propertyValue1, propertyValue2, . . . , propertyValueK:** Refers to the values of the properties

Perform the following steps to define styles as resources in a WPF standalone application:

+   1. *Start* Visual Studio 2010.
+   2. *Select* **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. *Select* **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. *Select* the **WPF Application** template in the middle pane to create a WPF standalone application.
+   5. *Enter* the name of the application as **MyStyle** (also available on the CD) in the **Name** text box and an appropriate location for the application in the **Location** combo box.
+   6. *Click* the **OK** button to close the **New Project** dialog box and create the **MyStyle** application.
