## Implementing Data Binding

### CHAPTER 5

In this Chapter:

- Data Binding in Windows Forms
- Data Binding in WPF

Data binding is the process of binding data to a control. For example, you can bind the data stored in a database to a control. This helps you to retrieve or access the data through an application easily and quickly. It also allows you to navigate through a table, record by record. C# 2010 allows you to bind a single column of a table as well as an entire table with a control. In addition to binding controls to a database, you can bind controls to any programming construct that holds data, such as an array, a file, or a property of another control. Data binding can be useful in a number of ways in C# applications. For example, you can create data entry forms where you can bind the different controls, such as text box, list box, and radio button, with different fields of a table. After that, if you enter any value in these controls, the entered values get stored directly in the specified fields of the table.

In .NET Framework 4.0, you can accomplish data binding with Windows Form controls as well as Windows Presentation Foundation (WPF) controls. In WPF, data binding provides a simple and consistent way for applications to interact with data and display it. Data binding has several advantages in WPF, which includes a broad range of properties that inherently support binding of data, easy representation of data in user interface, and a complete separation of code and user interface.

In this chapter, you learn about the basic data binding concepts and different types of data binding. The chapter starts with the discussion on data binding in Windows Forms, which includes simple and complex data binding. Next, you learn about data binding in WPF, including data flow directions, declaration of data binding in WPF, and binding sources available in WPF.

Let’s start by learning about data binding in Windows Forms.

### Data Binding in Windows Forms

In C#, data binding can be categorized into two types, simple and complex. Simple data binding enables you to bind a control to one data element, such as a field in a data table. On the other hand, complex data binding enables you to bind a control to more than one data element, such as more than one record in a database or to an entire table. Binding of controls (using any one of the two ways: simple or complex) can be achieved, both at design time and at runtime. To bind the controls with data, you need to bind the properties of various controls with a data source. Therefore, before you begin binding controls to the data in a database, you must perform the following tasks that are necessary to bind a control to data:

- 1. **Create** a data connection, or use an existing data connection
- 2. **Create** a data adapter
- 3. **Generate** a dataset
- 4. _Fill_ the dataset by using the Fill() method of the data adapter

#### Simple Data Binding

Simple data binding enables you to display one data element, such as a field’s value, from a table on a control. In C#, you can simply bind a property of a control to a data value through the **Properties** window. For example, you can bind the **Text** property of a **TextBox** control, the **Size** and **Image** properties of a **PictureBox** control, or the **BackColor** property of a **Label** control, to a data source. You can bind a property of a control to a data source by using the **DataBindings** property of the control.

In simple words, you can say that simple data binding is the ability of a control to bind a single data element with itself.
