# # Creating Dialog Boxes

A dialog box is a window that is displayed on the screen as the result of an action performed by a user, for example, selection of a menu option. A dialog box is named so because it facilitates a dialog between the user and the computer by either informing the user about some event that has occurred or requesting the user for some sort of input, or both. However, pre-defined dialog boxes do not always fulfill our requirements. Therefore, many times you require creating customized dialog boxes. In this section, you create an application containing a form and a dialog box. At run time, prompt the user to enter some text in the dialog box and display the text that was entered by the user in the dialog box in the form.

Perform the following steps to create a dialog box:

+   1. Start **Visual Studio 2010**.
+   2. Select **File→New→Project** from the menu bar. The **New Project** dialog box opens.
+   3. Select **Visual Basic→Windows** from the **Installed Templates** section in the left pane of the **New Project** dialog box.
+   4. Select **Windows Forms Application** in the middle pane to create a Windows Forms application.
