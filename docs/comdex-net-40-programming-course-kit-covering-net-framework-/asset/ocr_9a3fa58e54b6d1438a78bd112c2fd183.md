| **Table 2.11: Mouse Events in Visual Basic 2010** | |
|---|---|
| **Event** | **Description** |
| MouseLeave | Occurs when the mouse pointer leaves the control region |
| MouseMove | Occurs when the mouse pointer moves over the control |
| MouseUp | Occurs when the mouse pointer is over the control and a mouse button is released |
| MouseWheel | Occurs when the mouse wheel moves, while the control has focus |

Keyboard events available in Visual Basic 2010 are listed in Table 2.12:

| **Table 2.12: Keyboard Events in Visual Basic 2010** | |
|---|---|
| **Event** | **Description** |
| KeyDown | Occurs when a key is pressed down while the control has focus |
| KeyPress | Occurs when a key is pressed while the control has focus |
| KeyUp | Occurs when a key is released while the control has focus |
