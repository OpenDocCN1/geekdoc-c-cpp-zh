## Using the PasswordBox Control

There may be situations when you may want users to enter some confidential information, such as passwords. You may use a **TextBox** control to allow users to enter their passwords. However, while a user enters the password, someone might see the password, which is an undesirable situation. In such a situation, you can use the **PasswordBox** control, which displays the text entered as hidden or masked. The **PasswordBox** control is a special type of text box, which is particularly aimed at entering passwords such that they remain undisclosed to other users. In the **PasswordBox** control, you need to set the **PasswordChar** property by a special character that masks the input text entered by the user. By default, any text entered in the **PasswordBox** control appears as a string of filled circles (●). The **PasswordBox** control is an instance of the PasswordBox class. Table 5.5 lists the noteworthy properties of the PasswordBox class:

**Table 5.5: Noteworthy Properties of the PasswordBox Class**

| Property | Description |
|---|---|
| MaxLength | Returns or sets the maximum length of the password |
| Password | Returns or sets the password currently contained in the PasswordBox control |
| PasswordChar | Returns or sets the character to mask the password in the PasswordBox control |

## Using the TextBlock Control

The TextBlock control in WPF allows you to work with text in a flexible manner as compared to the traditional Label control. This implies that it has several properties that allow you to modify the appearance of the text entered in the TextBlock control. It is an instance of the TextBlock class. Table 5.6 lists the noteworthy properties of the TextBlock class:

**Table 5.6: Noteworthy Properties of the TextBlock Class**

| Property | Description |
|---|---|
| FontFamily | Returns or sets the font for the text in the TextBlock control |
| FontSize | Returns or sets the font size for the text in the TextBlock control |
| FontStyle | Returns or sets the font style for the text in the TextBlock control |
| FontWeight | Returns or sets the font weight for the text in the TextBlock control |
| Text | Returns or sets the text of the TextBlock control |
| TextAlignment | Returns or sets a value that indicates the horizontal alignment of the text in the TextBlock control |
| TextTrimming | Returns or sets a value that indicates how the text is trimmed when the text overflows the content area of the TextBlock control |
| TextWrapping | Returns or sets a value that indicates how the TextBlock control should wrap the text within it |
