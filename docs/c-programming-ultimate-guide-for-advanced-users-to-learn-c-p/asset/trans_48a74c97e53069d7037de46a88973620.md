## Realizing the PlayControl

PlayControl 由按钮组成。与标准按钮一样，这些按钮响应 Click 事件。这样，控件非常直接：点击一个按钮，就会调用 Click 事件处理程序并运行一些代码。

有两个问题使得播放器控件在一般意义上可重用，而非仅用于一个应用程序的单次使用结构。按钮被实现为独立控件，而 PlayControl 本身不做任何事情。每个按钮 Click 事件基本上在实现 IPlayer 接口的另一个类上调用相关操作。（我们尚未讨论 IPlayer 接口；我们很快就会讨论。）例如，如果你点击播放，则会调用与 PlayControl 关联的播放器的 Play 过程——前提是它实现了 IPlayer 接口。从此以后，类使我们能够重用单个控件，而接口使我们能够重用整个部分。也许可以与收音机、VCR 或磁带座相比较的东西可以使用这个通用部分。

## Constructors, Destructors, and Dispose Method

由于控件是一个类，你可能会在控件中遇到在任何类中都可能找到的东西。在任何类中，包括控件，你最有可能找到的三种普通方法是构造函数、析构函数和 Dispose 过程。

RoundButton 未实现构造函数、析构函数或 Dispose 方法。在这种特定情况下我们不需要它们。在这种特定情况下我们不执行任何需要它们存在的操作。Controls.dll 中的各种类——VideoKiosk.sln 的一部分——展示了构造函数和 Dispose 方法的示例。

### Control Constructors

构造函数的解释是为了初始化你在类中声明的内容。这对于 Control 类也是一致的。如果你的控件不包含需要用 new 运算符创建的成员，或者你的类不需要执行任何特殊初始化，那么你不需要构造函数。

构造函数通常是公共的，不声明返回类型，并且与包含它们的类同名。在我们的 RoundButton 类中，我们不使用构造函数，因为我们不需要执行任何特殊初始化。

通过声明与类同名的额外方法，可以重载构造函数，但你不需要通过使用修饰符明确表示构造函数被重载。具有与类相同名称的两个方法——包括构造函数和析构函数——随后将被重载，并且对该构造函数的调用将根据各自的参数类型解析。

Form 类展示的一个良好做法是从构造函数中调用初始化方法，而不是使构造函数变得混乱。Form1 调用 InitializeComponent 过程。其原因在于 Form 上绘制了必须实例化的控件。

### Control Dispose Methods

C# 是一种 .NET 语言。我陈述显而易见的事情是为了处理可能不自明的话题。像 Object Pascal 或 C++ 这样的语言使用确定性分配和销毁。这意味着工程师负责创建和销毁对象。

.NET 使用非确定性销毁。这意味着软件专家不负责销毁对象。垃圾收集器会为你清理对象。因此，你将编写调用 new 运算符的代码，但没有对应的 free 运算符。不幸的是，在很大程度上你将编写使用需要确定性清理的资源代码。这就是 Dispose 方法发挥作用的地方。

其结果是，你更有可能看到实现 Dispose 方法而不是析构函数的类。由于 Dispose 是一个公共方法，客户端可以显式调用它，但你无法依赖 .NET 何时调用析构函数。如果需要确定性清理，则实现 Dispose 过程。

无论如何，你应该了解析构函数是什么样的以及适用于析构函数的规则。

### Completing a Paint Event Handler

Paint 事件处理程序接收两个参数。第一个参数是 object，第二个参数是 PaintEventArgs 类的实例。

当你需要执行自定义绘制时，可以实现 Paint 事件处理程序。为了我们的讨论目的，有两个自定义效果直接应用于 PlayControl。PlayControl 的 Paint 事件处理程序如下所示：

```csharp
private void PlayControl_Paint(
    object sender, System.Windows.Forms.PaintEventArgs e)
{
    OutlineControl(e.Graphics);
    DrawTrademark(e.Graphics);
}
```

重构的方法描述了各自执行的任务。第一个方法使 PlayControl 具有相当不错的完美边缘。这很重要，因为我们没有使用标准窗体形状。

第 17 到 24 行的 OutlineControl 使用传递给 PlayControl Paint 事件处理程序的 Graphics 对象并将 SmoothingMode 设置为 AntiAlias。AntiAlias 通过覆盖多边形中的一些像素来混合像素，从而有助于使线条更平滑，实现更平滑的外观。使用 GetPoints 返回的对应点绘制多边形——用于描述结构的状态——为结构创建无瑕、清晰的边缘。

DrawTrademark 使用我命名为 DrawShadowText 的第二种方法。DrawShadowText 使用两个画刷将文本绘制两次。通过以某种方式轻微调整文本，你可以获得明显的阴影效果。通过将文本抵消 −1 并使用更亮的颜色绘制文本，可以产生内嵌效果（base assistance）。通过移动第 30 行的偏移值，你可以获得不同的文本效果。
