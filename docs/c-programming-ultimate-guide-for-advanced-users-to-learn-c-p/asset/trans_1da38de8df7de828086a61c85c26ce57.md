你可以通过创建循环来重复执行一段代码序列。C# 提供了功能强大的各种循环结构。我们这里要介绍的是 for 循环。如果你熟悉 C、C++ 或 Java，你会很高兴地知道 C# 中的 for 循环与这些语言中的工作方式相同。for 循环最简单的形式如下所示：

```
for(initialization; condition; iteration) statement;
```

在最常见的形式中，循环的初始化部分将循环控制变量设置为初始值。条件是一个布尔表达式，用于测试循环控制变量。如果测试结果为 true，for 循环将继续迭代；如果为 false，循环结束。迭代表达式决定每次循环迭代时循环控制变量如何变化。

### 使用代码块

C# 的另一个关键元素是代码块。代码块是语句的分组。代码块是通过将语句括在左花括号和右花括号之间来创建的。一旦创建了代码块，它就成为一个逻辑单元，可以在任何可以使用单条语句的地方使用。例如，代码块可以作为 if 和 for 语句的目标。看看这个 if 语句：

```csharp
if(counter < max) {
    usercount = counter;
    delaytime = 0;
}
```

这里，如果 counter 小于 max，块中的两条语句都将被执行。因此，块中的两条语句形成一个逻辑单元，一条语句不能在没有另一条语句同时执行的情况下执行。这里的关键点是：每当你需要在逻辑上连接两条或更多语句时，都可以通过创建代码块来实现。代码块使众多算法能够以更高的清晰度和效率执行。

### 分号与位置

在 C# 中，分号标志着语句的结束。也就是说，每条单独的语句都必须以分号结尾。你可能已经知道，代码块是由左、右花括号括起来的一组逻辑关联的语句。代码块不以分号结尾。由于代码块是语句的分组，因此代码块不以分号结束是合理的；相反，代码块的结束由右花括号表示。
