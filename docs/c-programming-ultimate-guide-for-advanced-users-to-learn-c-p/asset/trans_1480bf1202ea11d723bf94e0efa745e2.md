如前所述，Java 源自 C 和 C++。其语言结构基于 C，其对象模型从 C++ 发展而来。尽管 Java 代码与 C 或 C++ 既不能向上兼容也不能向下兼容，但其语言结构足够相似，以至于现有庞大的 C/C++ 开发者群体几乎无需费力就能转向 Java。此外，由于 Java 建立在并改进了现有范式之上，Gosling 等人得以将精力集中在新的、富有想象力的亮点上。正如 Stroustrup 在制作 C++ 时不必“浪费时间”，Gosling 在创建 Java 时也不必从头制作一门全新的语言。

## 从方法返回

总的来说，有两种情况会导致方法返回。第一种，如上一示例中的 Range( ) 方法所示，发生在遇到方法的结束花括号时。第二种是执行 return 语句时。返回有两种类型：一种用于 void 方法（不返回值的方法），另一种用于返回值。这里分析主要结构。下一节说明如何返回值。在 void 方法中，可以使用以下 return 结构使方法立即结束：

```
return ;
```

当这条语句执行时，程序控制权返回给调用方，跳过方法中任何剩余的代码。这里，方法在完成时或发生错误时返回。但要注意，因为方法中退出点过多会破坏代码结构，所以不要随意使用它们。回顾一下：void 方法可以通过以下两种不同方式之一返回：到达其结束花括号，或执行 return 语句。

## 返回值

尽管返回类型为 void 的方法并不少见，但大多数方法都会返回一个值。事实上，返回值的能力是方法最有用的特性之一。你已经见过一个返回值的示例：在第 2 和第 3 部分中，我们使用 Math.Sqrt( ) 求平方根。返回值在编程中有各种用途。有时，例如 Math.Sqrt( )，返回值包含某种计算的结果。在其他情况下，返回值可能只表示成功或失败。还有一些情况下，它可能包含状态代码。无论原因如何，使用方法返回值是 C# 编程中不可或缺的一部分。

方法使用以下这种 return 将值返回给调用例程：

```
return value;
```

这里，value 是被返回的值。在这个变体中，i 在循环开始前初始化，而不是作为 for 的主要部分。通常，你需要在 for 内部初始化循环控制变量。将初始化设置在循环外部，通常只在初始值通过一个无法整齐地放入 for 语句的复杂过程推断出来时才这样做。
