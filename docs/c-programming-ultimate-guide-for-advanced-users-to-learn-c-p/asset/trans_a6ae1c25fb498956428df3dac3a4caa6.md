### 面向对象编程（OOP）与 C++ 编程：

尽管 C 语言看起来很有价值，但到了 20 世纪 70 年代末，许多任务的规模已接近或达到了结构化编程方法和 C 语言所能应对的极限。项目本质上变得过于庞大。为了解决这个问题，另一种编程方法开始兴起。

这种技术被称为面向对象编程（简称 OOP）。利用 OOP，软件工程师可以处理更大的项目。问题是，当时最主流的语言 C 并不支持面向对象编程。对面向对象版本的 C 语言的渴望，最终促成了 C++ 的形成。
