## Using TimeSpan to Evaluate Time Differences

The TimeSpan structure is used to measure time spans as short as 100 nanoseconds, which are represented as one tick in a TimeSpan. TimeSpan values can be represented as positive and negative spans of time measured in terms of days, hours, minutes, seconds, and fractions of a second. The string format d.hh:mm:ss.ff would show the days, hours, minutes, seconds, and fractions of a second represented by a single TimeSpan. The largest unit of time represented by the TimeSpan is the day.

If the default string representation of the TimeSpan were acceptable, then we could use the TimeSpan.ToString() method, which would return the TimeSpan in hh:mm:ss form normally.

If you perform a calculation operation on DateTime values, for instance subtracting one time from another, the operation will return a TimeSpan object.

## Formatting Strings

For our purposes we chose not to use the default TimeSpan.ToString method. This is an optional decision that enables us to explore the string.Format method and formatting mask. (In a production system, it is more advisable to use the TimeSpan.ToString method.)

GetMask returns a formatting string. The string is "{0}:{1,2:0#}:{2,2:0#}". Characters in the braces {} represent replaceable format characters, and everything else represents a literal value. Examining {1,2:0#}, we understand this replaceable parameter to be replaceable parameter 1, which is zero-based and can be up to two numeric characters long.

In general, the first argument in a format item represents the zero-based argument to be formatted. The second argument—if present, it is delimited by a comma—represents the width of the formatted value. If you include a negative sign, then the value is left-aligned, and a positive sign will right-align the value. Of course, the width will pad the formatted argument with spaces. The optional formatting string follows the colon. Our 0# formatting string indicates that the formatted output will be padded with a 0 and a number. If the number takes both spaces, then the 0 won't be displayed.

## Using the ToolTip Control

Windows Forms provides a ToolTip component. When you add the ToolTip component to your application, it is added to the Component Tray, rather than directly on the form. Components in the Component Tray are nonvisible components; that is, they do not appear at run-time.

When you add the ToolTip to the Component Tray for a specific Form, the controls on that form will have the ToolTip property added to their list of properties. If you provide content to the ToolTip property, then the tip will be displayed when a user moves the mouse over the control.

The Broadcaster implements the Singleton design. A Singleton is a class that you need to guarantee has just one instance. Usually, this instance is used to represent the presence of a single resource, similar to a single printer. A Singleton class is made by making the constructor protected or private and giving access only through a static member. The Broadcaster does this through the internal, private Instance property.

Each public method in Broadcaster is static. When you invoke a public member in the Broadcaster (or any Singleton), the method references the read-only Instance property. It verifies whether the single instance of the Broadcaster has been made. If the Singleton doesn't exist, then one instance is made and assigned to the private field instance. The Singleton object is then returned. The outcome is that the Broadcaster contains a reference to an instance of itself.
