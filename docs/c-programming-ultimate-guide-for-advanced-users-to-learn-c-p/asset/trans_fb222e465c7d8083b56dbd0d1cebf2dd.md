## 构造函数、析构函数和 Dispose 方法

由于控件是一个类，你可能会在控件中遇到一些在任何类中都可能发现的东西。在任何类（包括控件）中，你最可能发现三种普通机制——它们是构造函数、析构函数和 Dispose 过程。

RoundButton 没有实现构造函数、析构函数或 Dispose 方法。在这个特定事件中，我们无需处理它们。在这个特定情况下，我们不会执行任何需要它们存在的操作。Controls.dll 中的多个类——它们是 VideoKiosk.sln 的一部分——展示了构造函数和 Dispose 策略的示例。

### 控件构造函数

构造函数的目的在于初始化类中声明的内容。这对 Control 类同样适用。如果你的控件不包含必须用 new 运算符创建的成员，或者你的类不需要执行任何特殊初始化，那么你无需处理构造函数。

构造函数通常是公共的，不描述返回类型，并且与包含它们的类同名。在我们的 RoundButton 类中，我们不使用构造函数，因为不需要执行任何特殊初始化。

可以通过声明与类同名的其他方法来重载构造函数，但你不必使用修饰符明确表示某个构造函数已被重载。因此，与类同名的两个方法——包括构造函数和析构函数——将被重载，并且对该构造函数的调用将根据不同的参数类型进行解析。

Form 类展示的一个不错的方法是，从构造函数调用初始化方法，而不是把构造函数弄乱。Form1 调用 InitializeComponent 过程。这样做的原因是，窗体上有必须呈现的已绘制控件。

### 颜色结构

Color 结构包含对预定义色调的相当全面的概述。当需要颜色时，可以使用其中一种预定义色调，也可以通过以名称形式指定颜色来决定颜色。GetColor 方法展示了如何使用现有色调。

同样，可以通过传递 0 到 255 的 alpha 混合值、红色、绿色和蓝色特征来指定自定义色调。颜色的 alpha 分量表示透明度；值 127 表示大约 50% 透明的颜色。声明 Color.FromArgb(255, 0, 0, 255) 会生成一种相当不错的蓝色调。

Convert 类展示了一个只包含方法的类实例。由于 Convert 不需要处理状态，所有方法都可以是静态的，这意味着不必创建 Convert 类的实例即可使用它。

Convert 类中的过程已重载，并被描述为可识别大量数据类型。如果 Convert 方法无法将你传入的值转换为所引用的类型，则会引发 InvalidCastException。

## 使用对象

Graphics 类的实例表示 GDI+ 中的画布。每次需要执行自定义绘制时，都应请求一个 Graphics 对象。有几种不同方法可以获取 Graphics 对象。可以在具有画布的控件（如窗体）上调用 CreateGraphics 方法，也可以从传递给 Paint 事件处理程序的 PaintEventArgs 参数的属性获取 Graphics 对象。

无论以何种方式获取 Graphics 对象，当你拥有 Graphics 对象后，就可以调用 Graphics 类描述的任何方法。由于 GDI+ 是无状态的，不应存储 Graphics 对象，也不应在对方法的调用之间使用同一个 Graphics 对象。
