
它被称为。设想一个场景：你必须返回至少两项数据？例如，设想你需要编写一个方法，用于处理矩形的面积，并且还要判断该矩形是否为正方形？要做到这一点，必须返回两项数据：面积和一个表示“是否为正方形”的值。这个方法无法仅使用单个返回值来编写。out 修饰符解决了这个问题。

在许多编程语言中，动态分配内存的回收是手动处理的。例如，在 C++ 中，你使用 delete 运算符来释放已分配的内存。无论如何，C# 使用了一种不同的、更省事的方法：垃圾回收。C# 的垃圾回收系统会自动回收对象——直接发生，在幕后进行，无需程序员干预。它的工作方式如下：当不存在对某个对象的引用时，该对象就被认为不再需要，该对象所占用的内存会被释放。这块被重新利用的内存随后可以用于下一次分配。

垃圾回收只是在程序执行期间偶尔发生。它不会仅仅因为存在至少一个不再使用的对象就发生。因此，你无法确切知道垃圾回收会在何时发生。可以定义一个方法，它只会在对象被垃圾回收器最终销毁之前被调用。这个方法称为析构函数，它可能在一些非常特殊的情况下用于保证对象干净地结束。例如，你可以使用析构函数来确保某个对象占用的系统资源被释放。必须在一开始就说明，析构函数是一种非常高级的特性，适用于某些特定情况。它们通常不是必需的。尽管如此，由于它们是 C# 的一部分，为了完整性，这里对它们作了简要描述。

在前面的示例中，使用的是无参数构造函数。虽然这在少数情况下没问题，但通常你会需要一个至少接受一个参数的构造函数。向构造函数添加参数的方式与方法添加参数类似：只需在构造函数名称后的括号内声明它们。既然你已经了解了类及其构造函数，让我们来研究一下 new 运算符。它具有以下一般结构：

```
`new class-name(arg-list)`
```

这里，class-name 是正在被实例化的类的名称。类名后跟括号决定了该类的构造函数，如上一节所述。如果某个类没有定义自己的构造函数，new 将使用 C# 提供的默认构造函数。由于内存是有限的，new 可能因为内存不足而无法为对象分配内存。如果发生这种情况，就会发生运行时异常。对于本书中的示例程序，你不必担心内存耗尽，但在你编写的实际项目中，应该考虑这种可能性。

在 C# 中，值类型的变量包含其自身的值。保存该值的内存会在程序运行时自动分配。因此，无需使用 new 显式分配这块内存。另一方面，引用变量存储的是对对象的引用。保存该对象的内存会在执行期间动态分配。不把基元类型（例如 int 或 float）作为引用类型，会极大提高程序的性能。使用引用类型时，会有一层间接寻址，这会给每次对象访问增加开销。值类型则避免了这种开销。

## out 参数：

有时你会需要使用引用参数从方法中获取一个值，但不传入值。例如，你可能有一个执行某种功能的方法，比如打开网络套接字，它通过引用参数返回成功/失败代码。在这种情况下，没有数据要传入方法，但有数据要传出。这种情况的问题在于，ref 参数必须在调用之前初始化为某个值。因此，要使用 ref 参数，就需要给实参一个虚假的值，仅仅为了满足这一要求。幸运的是，C# 提供了更好的选择：out 参数。out 参数类似于 ref 参数，但有一个特殊情况：它必须用于从方法中传出值。在调用方法之前，不必（也没有帮助）为用作 out 参数的变量提供初始值。方法会给该变量一个值。此外，在方法内部，out 参数始终被视为未赋值；也就是说，它应当没有初始值。相反，方法必须在方法结束前为该参数赋值。这样，在调用方法之后，out 参数所引用的变量将包含一个值。

下面是一个使用 out 参数的示例。方法 RectInfo() 在给定矩形各边长度的情况下返回矩形的面积。在参数 isSquare 中，如果该矩形是正方形，则返回 true，否则返回 false。因此，RectInfo() 向调用方返回两项数据。

创建方法时，你通常会预先知道要传递给它的参数个数，但情况并非总是如此。有时你需要创建一个可以接受任意数量参数的方法。例如，考虑一个查找一组值中最小值的方法。这样的方法可能只传入两个值，或者三个、四个，等等。在所有情况下，你都需要该方法返回最小值。这样的方法无法使用普通参数来创建。相反，你应该使用一种特殊类型的参数，它表示任意数量的参数。这是通过创建 params 参数来实现的。

params 修饰符用于声明一个数组参数，该参数至少能够接收零个实参。数组中的元素个数将等于传递给方法的实参个数。然后程序访问该数组以获取这些实参。每次调用 MinVal() 时，实参都通过 nums 数组传递给它。数组的长度与元素个数一致。因此，你可以使用 MinVal() 来查找任意数量值中的最小值。

虽然你可以向 params 参数传递任意数量的实参，但它们都必须与参数所指示的数组类型兼容。例如，像这样调用 MinVal()：

```
min = ob.MinVal(1, 2.2);
```

是非法的，因为不存在从 double (2.2) 到 int 的隐式转换，而 int 是 MinVal() 中 nums 的类型。

使用 params 时，你应该注意边界情况，因为 params 参数可以接受任意数量的实参——甚至零个！例如，像下面这样调用 MinVal() 在语法上是合法的：

```
min = ob.MinVal();/no arguments
```

```
min = ob.MinVal(3);/1 argument
```

这就是 MinVal() 中要进行检查的原因：在尝试访问 nums 数组中的元素之前，先确认该数组中至少有一个元素。如果没有这个检查，那么在调用 MinVal() 时不带任何实参就会导致运行时异常。（在本书后面讨论异常时，你会看到处理这类错误的更好方法。）

此外，MinVal() 中的代码经过编写，允许在调用 MinVal() 时只传入一个实参。在这种情况下，会返回这个唯一的实参。
