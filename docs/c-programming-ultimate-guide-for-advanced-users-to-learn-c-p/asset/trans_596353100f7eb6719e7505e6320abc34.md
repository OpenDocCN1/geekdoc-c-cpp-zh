
听起来确实像是一个缺点，但事实并非如此。当你需要一个与已有字符串略有不同的字符串时，只需创建另一个包含所需更改的字符串。由于未使用的字符串对象会被自动垃圾回收，你不必担心被丢弃的字符串会怎样。

无论如何必须澄清，字符串引用变量当然可以改变它们所引用的对象。只是特定字符串对象的内容在创建后不能更改。为了完全理解为什么不可变字符串不是障碍，我们将使用字符串的另一个方法：Substring()。Substring() 方法返回另一个字符串，该字符串包含调用字符串中预定义的一部分。由于创建了一个包含子字符串的另一个字符串对象，第一个字符串保持不变，不可变性规则仍然完好。我们将使用的 Substring() 形式如下所示：

```
string Substring(int startIndex, int len)
```

这里，startIndex 确定起始索引，len 表示子字符串的长度。

## 访问说明符：

成员访问控制通过四个访问说明符完成：public、private、protected 和 internal。本部分我们将关注 public 和 private。protected 修饰符仅在涉及继承时适用，稍后描述。internal 修饰符一般适用于程序集的使用；在 C# 中，程序集意味着一个程序、项目或组件。internal 修饰符稍后简要描述。当类的成员由 public 说明符修饰时，该成员可以被程序中的任何其他代码访问。这包括在其他类中定义的方法。

当类的成员被指定为 private 时，该成员只能由其所在类的其他成员访问。因此，其他类中的方法无法访问另一个类的 private 成员。如第 4 章所述，如果未使用访问说明符，类成员默认对其类私有。因此，在创建私有类成员时，private 说明符是可选的。

访问说明符位于成员类型声明的其余部分之前。显而易见，在 MyClass 类内部，alpha 被显式指定为 private，beta 默认是 private，gamma 被指定为 public。由于 alpha 和 beta 是 private，它们不能被其类外部的代码访问。因此，在 AccessDemo 类内部，二者都不能直接使用。二者都必须通过 public 方法访问，例如，

SetAlpha() 和 GetAlpha()。例如，如果你从下面这行开头删除注释字符：

```
// ob.alpha = 10; // Wrong! alpha is private!
```

你将无法构建此程序，因为存在访问冲突。尽管 MyClass 外部的代码不允许访问 alpha，但 MyClass 内部定义的方法可以公开访问它，正如 SetAlpha() 和 GetAlpha() 方法所示。beta 也是如此。关键点在于：private 成员可以被其所在类的其他成员自由使用，但不能被其类外部的代码访问。

第一种方式是按值调用。这种方式将实参的值复制到子程序的形参中。因此，对子程序形参所做的更改不会影响实参。传递实参的第二种方式是按引用调用。在这种方式中，传递给形参的是对实参的引用（而不是实参的值）。在子程序内部，使用该引用来访问调用中指定的实际实参。这意味着对形参所做的更改将影响用于调用子程序的实参。

当然，C# 使用按值调用，这意味着会制作实参的副本并将其传递给接收形参。因此，当你传递值类型（如 int 或 double）时，接收实参的形参发生什么变化都不会在方法外部产生影响。显然，NoChange() 内部发生的操作不会影响调用中使用的 a 和 b 的值。
