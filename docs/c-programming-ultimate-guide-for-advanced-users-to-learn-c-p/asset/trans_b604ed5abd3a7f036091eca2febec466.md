## Identifiers

C# 3.0 定义了 13 个上下文关键字，它们在特定上下文中具有特殊含义。在这些特定上下文中，它们充当关键字。在特定上下文之外，它们可用作其他程序组件的名称，例如变量名。因此，它们实际上并非保留字。但作为一般规则，你应将上下文关键字视为保留字，并避免将其用于任何其他目的。将上下文关键字用作其他程序组件的名称可能会造成混淆，许多程序员认为这是不良做法。在 C# 中，标识符是分配给方法、变量或其他用户定义事物的名称。标识符长度可以为一到多个字符。变量名可以以字母表中的任何字母或下划线开头。其后可以是字母、数字或下划线。

下划线可用于提高变量名的可读性，如 line_count。请记住，标识符不能以数字开头。因此，例如 12x 是无效的。良好的编程实践要求使用能反映所命名事物重要性或用途的标识符名称。尽管不能将任何 C# 关键字用作标识符，但 C# 允许在关键字前加 @，使其成为合法标识符。例如，@for 是有效标识符。在这种情况下，标识符实际上是 for，而 @ 被忽略。老实说，除特定目的外，不建议将 @ 限定的关键字用于标识符。同样，@ 可以放在任何标识符之前，但这被视为不良做法。

回收只会在程序执行期间偶尔发生。它不会仅仅因为存在一个或多个不再使用的对象就发生。因此，你无法确切知道垃圾回收何时会发生。可以定义一个方法，该方法仅在对象被垃圾回收器最终销毁之前被调用。此方法称为析构函数，可在某些非常特定的情况下使用，以确保对象干净地结束。例如，可以使用析构函数确保释放对象拥有的系统资源。必须一开始就说明，析构函数是一项高级特性，适用于某些特定任务。

### Floating Point Type

浮点类型可以表示带小数部分的数字。浮点类型有两种，float 和 double，分别表示单精度和双精度数字。float 类型为 32 位宽，范围为 1.5E−45 到 3.4E+38。double 类型为 64 位宽，范围为 5E−324 到 1.7E+308。在这两者中，double 最常用。原因之一是 C# 类库（即 .NET Framework 库）中的许多数学函数使用 double 值。例如，Sqrt( ) 方法（由 System.Math 类定义）返回一个 double 值，该值是其 double 参数的平方根。这里，Sqrt( ) 用于在给定另外两条边长度的情况下计算斜边长度：注意 Sqrt( ) 是如何调用的；它前面有名称 Math。这与 Console 位于 WriteLine( ) 之前的方式类似。尽管并非所有标准方法都通过先指定其类名来调用，但有些是这样。

### Decimal Type

也许最有趣的 C# 数值类型是 decimal，它旨在用于财务估算。decimal 类型使用 128 位来表示 1E−28 到 7.9E+28 范围内的值。如你所知，典型的浮点数运算在应用于十进制数值时会出现各种舍入误差。decimal 类型消除了这些误差，并且最多可以精确表示 28 位小数（有时为 29 位）。这种在不产生舍入误差的情况下表示十进制值的能力，使其对于涉及现金的计算特别有价值。

### Characters

在 C# 中，字符不像在 C++ 等许多其他语言中那样是 8 位量。相反，C# 使用 Unicode。Unicode 定义了一个字符集，可以表示每种人类语言中出现的全部字符。因此，在 C# 中，char 是一种无符号 16 位类型，范围为 0 到 65,535。标准的 8 位 ASCII 字符集是 Unicode 的子集，范围为 0 到 127。这样一来，ASCII 字符仍然是有效的 C# 字符。可以通过将字符括在单引号中为字符变量赋值。例如，以下代码将 X 赋给变量 ch：

```
char ch; ch = 'X';
```

### C# Unicode Use

C# 旨在使项目能够为全球使用而编写。因此，它需要使用能够表示世界全部语言的字符集。Unicode 正是为此目的而明确规划的标准字符集。显然，对于英语、德语、西班牙语或法语等字符可以包含在 8 位内的语言来说，使用 Unicode 是浪费的。然而，这就是全球可移植性的代价。
