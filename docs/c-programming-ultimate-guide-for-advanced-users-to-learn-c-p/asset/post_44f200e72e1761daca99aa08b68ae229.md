The grandfather of C# is C. From C, C# derives its syntax, many of its keywords, and operators. C# builds upon and improves the object model defined by C++. If you know C or C++, you will feel comfortable with C#. C# and Java have a more complicated relationship. As explained, Java is likewise descended from C and C++. It, as well, shares the C/C++ syntax and object model. Like Java, C# is designed to produce portable code, and C# programs execute in a protected managed runtime environment. However, C# isn't descended from Java. Rather, C# and Java are more like cousins, sharing a common lineage, but differing in many ways. With version 3.0, Microsoft once again put C# on the forefront of language design, this time including a lot of innovative features that reimagined the programming landscape. Perhaps the two most exciting new features in C# 3.0 are language-integrated query (LINQ) and lambda expressions. LINQ empowers you to compose database queries utilizing C# programming constructs. Although C# is a language that can be considered by itself, it has a special relationship to its runtime environment, the .NET Framework. The reason for this is twofold. First, C# was originally designed by Microsoft to make code for the .NET Framework. Second, the libraries utilized by C# are the ones defined by the .NET Framework. Hence, although it is possible to isolate the C# language from the .NET environment, the two are closely connected. In this way, it is important to have a general understanding of the .NET Framework and why it is important to C#.

In a sentence, the .NET Framework defines an environment that supports the development and execution of highly distributed, component-based applications. It empowers different programming languages to interoperate and provides security, program portability, and a common programming model for the Windows platform.

As it relates to C#, the .NET Framework defines two significant elements. The first is the Common Language Runtime. This is the framework that manages the execution of your program. Along with other advantages, the Common Language Runtime is the part of the .NET Framework that empowers projects to be portable, supports mixed-language programming, and provides security.

The second element is the .NET class library. This library gives your program access to the runtime environment. For instance, if you need to perform I/O, for example, showing something on the screen, you will utilize the .NET class library to do it. If you are new to programming, the term class might be new. Although it will be clarified in detail somewhat later, briefly, a class is an object-oriented construct that organizes programs. As long as your program limits itself to the features defined by the .NET class library, your projects can run anywhere that the .NET runtime framework is supported. Since C# automatically utilizes the .NET class library, C# programs are consequently portable to every .NET environment.

The Common Language Runtime (CLR) deals with the execution of .NET code. Here is how it works. When you compile a C# program, the output of the compiler isn't executable code. Rather, it is a file that contains a special type of pseudocode called Microsoft Intermediate Language, or MSIL for short. MSIL defines a set of portable instructions that are free of a particular CPU. Basically, MSIL defines a portable low-level computing construct. One other point: although MSIL is comparable in idea to Java's bytecode, the two are not the same. It is the job of the CLR to translate the intermediate code into executable code when a program is run. In this way, any program compiled to MSIL can be run in any environment for which the CLR is implemented. This is part of how the .NET Framework accomplishes portability.

Microsoft Intermediate Language is transformed into executable code utilizing a JIT compiler. JIT means "just in time." The procedure works this way: When a .NET program is executed, the CLR activates the JIT compiler. The JIT compiler converts MSIL into native code on an as-needed basis, as each piece of your program is required.
