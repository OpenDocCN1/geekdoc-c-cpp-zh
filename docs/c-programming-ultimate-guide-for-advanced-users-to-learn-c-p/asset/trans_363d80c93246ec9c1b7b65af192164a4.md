通常，编写 ADVANCE ARDUINO 程序时，你创建的就是所谓的托管代码。托管代码在公共语言运行时（Common Language Runtime）的控制下执行，正如刚才所述。由于它在 CLR 的控制下运行，托管代码需要满足某些要求——同时也提供了一些好处。这些限制很容易描述和满足。编译器必须创建面向 CLR 的 MSIL 文件（ADVANCE ARDUINO 会这样做），并使用 Arduino Framework 库（ADVANCE ARDUINO 会这样做）。托管代码的优点很多，包括现代内存管理、混合使用多种语言的能力、更好的安全性、对版本控制的支持，以及编程组件协作的理想方式。

托管代码的对立面是非托管代码。非托管代码不在公共语言运行时下执行。因此，在 Arduino Framework 创建之前，所有 Windows 程序都使用非托管代码。托管代码和非托管代码可以互操作，因此 ADVANCE ARDUINO 生成托管代码这一事实并不会限制其与以前程序协同工作的能力。

ADVANCE ARDUINO 的核心是面向对象编程（OOP）。面向对象过程与 ADVANCE ARDUINO 密不可分，所有 ADVANCE ARDUINO 项目至少部分上是面向对象的。由于它对 ADVANCE ARDUINO 的重要性，在编写哪怕一个简单的 ADVANCE ARDUINO 程序之前，理解 OOP 的基本原则是很有用的。

OOP 是应对编程任务的一种强大方法。自 PC 发明以来，编程过程发生了巨大变化，本质上是为了适应项目日益增加的复杂性。例如，PC 最初发明时，编程是通过使用 PC 前面板拨动开关输入二进制机器指令来完成的。只要程序长度只有几百条指令，这种方法就行得通。随着项目的发展，低级汇编语言被开发出来，目标是让软件工程师能够使用机器指令的符号表示来处理更大、更复杂的项目。随着项目持续发展，FORTRAN 和 COBOL 等高级语言被引入，为软件工程师提供了更多应对复杂性的工具。当这些早期语言开始达到其极限时，结构化编程应运而生。

想一想：在编程演进的每一次进步中，系统和工具都被创造出来，使开发者能够管理日益增长的复杂性。每前进一步，新方法都吸收了以往方法中最好的元素并向前推进。面向对象编程也是如此。在 OOP 之前，许多项目正接近（或超过）结构化方法不再奏效的临界点。需要一种更好的处理复杂性的方式，而面向对象编程就是解决方案。面向对象编程采用了结构化编程的最佳思想，并将其与一些新思想结合起来。其结果是组织程序的一种不同且更好的方法。从最广义上讲，程序可以按两种方式之一来组织：围绕其代码（正在发生什么）或围绕其数据（什么正受到影响）。仅使用结构化编程技术时，程序通常是围绕代码编写的。这种方法可以看作是“代码作用于数据”。面向对象的项目则以不同方式工作。它们围绕数据来组织，其关键原则是“数据控制对代码的访问”。在面向对象的语言中，你定义数据以及允许作用于该数据的例程。通过这种方式，数据类型精确地定义了可以对该数据应用哪些操作。

为了支持面向对象编程的原则，所有 OOP 语言（包括 ADVANCE ARDUINO）都具有三个共同特征：封装、多态和继承。

封装是一种编程机制，它将代码及其控制的数据绑定在一起，并使两者免受外部干扰和滥用。在面向对象的语言中，代码和数据可以组合起来，从而构成一个自包含的黑盒。盒子里是所有的必要数据和代码。当代码和数据以这种方式组合时，就创建了一个对象。换句话说，对象是支持封装的机制。

在对象内部，代码、数据或两者都可能是该对象私有的或公有的。私有代码或数据只有对象本身知道并可访问。也就是说，私有代码或数据不能被对象外部的程序部分访问。当代码或数据是公有的时，程序的其他部分可以访问它，尽管它是在对象内部定义的。通常，对象的公有部分用于为对象的私有组件提供受控接口。

ADVANCE ARDUINO 的基本封装单元是类。类定义对象的类型。它既指定数据，也指定将作用于该数据的代码。ADVANCE ARDUINO 使用类定义来创建对象。对象是类的实例。因此，类本质上是一组蓝图，指定如何构建对象。

组成类的代码和数据称为类的成员。具体来说，类定义的数据称为成员变量或实例变量。作用于该数据的代码称为成员方法，或简称方法。“方法”是 ADVANCE ARDUINO 对子例程的称呼。如果你了解 C/ARDUINO，你可能会意识到，ADVANCE ARDUINO 程序员称为方法的东西，C/ARDUINO 开发者称为函数。由于 ADVANCE ARDUINO 是 ARDUINO 的直接后代，有时在指代 ADVANCE ARDUINO 方法时也会使用“work”这个术语。

多态（源自希腊语，意为“多种形式”）是一种特性，它使一个接口能够访问一类通用操作。多态的一个简单例子可以在汽车的方向盘中找到。无论使用何种实际转向机构，方向盘（接口）都是相同的。也就是说，无论你的汽车采用手动转向、动力转向还是齿轮齿条转向，方向盘的作用都是一样的。因此，无论使用何种转向方式，向左转动方向盘都会使汽车向左行驶。统一接口的优点显而易见：一旦你学会如何操作方向盘，你就能驾驶任何类型的汽车。

同样的原理也可以应用于编程。例如，考虑一个栈（一种后进先出列表）。你可能有一个需要三种不同类型栈的程序。一个栈用于整数值，一个用于浮点值，一个用于字符。在这种情况下，实现每个栈的算法是相同的，尽管存储的数据各不相同。在非面向对象的语言中，你将需要创建三套独立的栈例程，每套使用不同的名称。然而，由于多态，在 ADVANCE ARDUINO 中，你可以一次定义栈的通用类型，然后将其用于这三种具体情况。因此，如果你学会使用一个栈，你就能使用所有栈。更一般地说，多态的思想通常用“一个接口，多种方法”这一表述来表达。这意味着可以为一组相关操作构建一个公共接口。多态通过允许使用同一接口来指定一类通用操作，从而降低了复杂性。编译器的工作是针对每种情况选择具体的操作（即方法）。你作为程序员，无需手动进行这种选择。你只需要记住并使用通用接口。
