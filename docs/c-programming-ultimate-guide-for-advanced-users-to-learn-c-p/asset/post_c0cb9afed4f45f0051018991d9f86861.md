## Identifiers

C# 3.0 defines 13 contextual keywords that have a special meaning in specific contexts. In those specific contexts, they act as keywords. Outside their specific context, they can be used as names for other program components, for example, variable names. In this manner, they are not actually reserved. As a general rule, however, you should consider the contextual keywords reserved and avoid using them for any other purpose. Using a contextual keyword as a name for some other program component can be confusing and is considered bad practice by many programmers. In C#, an identifier is a name assigned to a method, a variable, or some other user-defined thing. Identifiers can be from one to several characters in length. Variable names may begin with any letter of the alphabet or with an underscore. Next might be a letter, a digit, or an underscore.

The underscore can be used to improve the readability of a variable name, as in line_count. Keep in mind that you can't begin an identifier with a digit. Therefore, 12x is invalid, for instance. Good programming practice dictates that you use identifier names that reflect the significance or use of the things being named. Although you can't use any of the C# keywords as identifiers, C# allows you to precede a keyword with an @, enabling it to be a legal identifier. For instance, @for is a valid identifier. In this case, the identifier is really for and the @ is disregarded. Honestly, using @-qualified keywords for identifiers isn't recommended, except for specific purposes. Likewise, the @ can precede any identifier, but this is considered bad practice.

### Floating Point Type

The floating-point types can represent numbers that have fractional parts. There are two sorts of floating-point types, float and double, which represent single- and double-precision numbers, respectively. One reason for this is that many of the math functions in C#'s class library (which is the .NET Framework library) use double values. ### Characters

In C#, characters are not 8-bit quantities like they are in many other languages, such as C++. Rather, C# uses Unicode. Unicode defines a character set that can represent the entirety of the characters found in every single human language. Consequently, in C#, char is an unsigned 16-bit type having a range of 0 to 65,535. The standard 8-bit ASCII character set is a subset of Unicode and extends from 0 to 127. In this manner, the ASCII characters are still valid C# characters. A character variable can be assigned a value by enclosing the character inside single quotes. For instance, this assigns X to the variable ch:

```
char ch; ch = 'X';
```
