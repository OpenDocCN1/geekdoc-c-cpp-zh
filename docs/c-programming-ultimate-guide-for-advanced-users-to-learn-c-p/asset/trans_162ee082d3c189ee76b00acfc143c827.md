### 赋值运算符

从第1章开始，你一直在使用赋值运算符。现在，是时候正式地审视它了。赋值运算符是单个等号`=`。赋值运算符在C#中的工作方式与其他语言非常相似。它的一般结构如下：

```
var = expression;
```

这里，`var`的类型必须与表达式的类型兼容。赋值运算符有一个你可能不太熟悉的引人入胜的特性：它允许你进行赋值链。这部分使用单个表达式将变量x、y和z设置为100。这之所以可行，是因为`=`是一个产生所赋值的运算符。因此，`z = 100`的值将是100，然后将其赋给y，y再赋给x。使用“赋值链”是将一组变量设置为一个公共值的简单方法。由于复合赋值表达式比其非复合对应形式更短，复合赋值运算符有时也被称为简写赋值运算符。

复合赋值运算符有两个优点。首先，它们比“长写法”对应形式更紧凑。其次，它们可以带来更高效的可执行代码（因为左侧操作数只计算一次）。因此，你会在精心编写的C#程序中经常看到复合赋值运算符的使用。当兼容的类型在赋值中混合时，右侧的值将被转换为左侧的类型。因此，在第一条语句中，`i`中的值被转换为`float`，然后赋给`f`。然而，由于C#严格的类型检查，并非所有类型都兼容，因此并非所有类型转换都被隐式允许。例如，`bool`和`int`不兼容。当满足这两个条件时，会发生加宽转换。例如，`int`类型总是足够大以容纳所有可能的`byte`值，并且`int`和`byte`都是数值类型，因此可以应用隐式转换。对于加宽转换，数值类型（包括整数和浮点类型）彼此兼容。例如，下面的程序是完全有效的，因为`long`到`double`是自动执行的加宽转换：尽管隐式类型转换很有用，但它们并不能满足所有编程需求，因为它们仅适用于兼容类型之间的加宽转换。对于所有其他情况，你应该使用强制转换。强制转换是向编译器发出的将表达式转换为指定类型的指令。因此，它需要显式类型转换。强制转换的一般结构如下：

```
(target-type) expression
```

这里，`target-type`表示要将指定表达式转换成的目标类型。
