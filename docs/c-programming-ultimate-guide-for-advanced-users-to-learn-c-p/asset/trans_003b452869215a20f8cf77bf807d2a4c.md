## 使用修饰符

修饰符涉及数据隐藏。数据隐藏体现了“需要知道”这一老生常谈。也就是说，作为创建者，如果你能对使用者隐藏某些东西，那么他们就不必担心它。随之而来的是，眼不见心不烦。

访问修饰符使你能够在编码时将事物置于心外。创建类时，只应将使用者使用该类所需交互的内容设为 public。通过限制你在公共接口中暴露的内容，你正在使类的使用变得更简单。无论你是不是自己所生成类的第一个使用者，这一点都成立。

有几个访问修饰符可供选择。C# 支持用于字段的 public、protected、internal、protected internal、private 和 readonly。下面的项目符号列表简要描述了每个访问修饰符的用途。

public 修饰符对类型和成员提供不受限制的访问。

protected 访问修饰符在子类内部及对子类提供不受限制的访问，而对使用者提供有限访问。protected 访问修饰符可应用于嵌套类型。

private 访问修饰符提供最有限的访问。只有类的作者才能使用其 private 成员。使用者和子类无权访问 private 成员。private 访问修饰符可应用于嵌套类型。

internal 访问修饰符意味着类型和成员仅在同一程序集内部可用。internal 修饰符用于使代码能够跨类边界在内部交互，而不会将这些组件暴露给程序集外部的使用者。

protected internal 修饰符将嵌套类型的访问限制在同一程序集内。

声明顶级类型时，你应使用 public 或 internal 访问修饰符。只有当这些类型是嵌套类型时，你才可以使用 private 和 protected 访问。嵌套类型是包含类型定义的类型定义。

除 protected internal 修饰符外，你不能组合访问修饰符。你不能对命名空间使用访问修饰符。如果你未指定访问修饰符，则将使用默认访问级别。最好显式显示访问程度，而不是依赖默认访问。

## 使用类修饰符

定义类且封闭元素为命名空间时，该类可以定义为具有 public 或 internal 访问权限。如果你未为顶级类指定修饰符，则该类将具有 public 访问权限。

嵌套类可以用任何访问修饰符定义，不过，对嵌套类你可能只能使用 protected、protected internal 和 private 访问修饰符。

类访问修饰符规则也适用于任何结构和枚举类型。

## 使用成员修饰符

你也可以对类型成员使用任何访问修饰符。如果你定义成员时未指定访问修饰符，则成员默认是 private。

## 运算符重载：

运算符是对数据执行操作的标记。当数据成为操作的对象时，数据被称为操作数。基本运算符（例如加法运算符 +）适用于值类型。值类型的一个示例是整数，例如 5。对整数类型执行诸如 5 + 4 的操作是直观的。

不幸的是，可能存在的所有潜在类型无法预先设想；然而，在创建类型时，对这些类型执行简单操作也可能很自然。字符串连接运算符演示了一个示例。当你遇到类似以下代码时

```
string s = "overload operators " + "are cool"
```

可以直观地理解该语句正在执行字符串连接。

重载运算符是方法。具体来说，它们是具有特殊语言语法的方法。你可以通过将重载运算符视为两部分来理解运算符。第一部分执行一个标准命名方法，该方法执行运算符将执行的任务。第二部分使用特殊语法定义运算符方法，并在运算符内调用该命名方法。（显然，你通常可以跳过重载运算符，但那样会令人不快。）
