栈类似于桌子上的盘子堆；最下面的第一个是最后被使用的。 队列类似于银行的排队；排在最前面的第一个是第一个被服务的。

使栈和队列等数据结构有趣的原因在于它们将数据的存储与访问该数据的方法结合在一起。 这样，栈和队列就是数据引擎，其中存储和检索由数据结构本身提供，而不是由你的程序手动提供。 这种组合显然是类的一个很好的选择，在本项目中你将创建一个简单的队列类。 通常，队列支持两种基本操作：put 和 get。 每个 put 操作将新元素放在队列的末尾。 每个 get 操作从队列的前端检索下一个元素。 队列操作是消耗性的。 当元素已被检索后，就不能再次检索。 如果没有可用空间存储项目，队列也会变得已满；如果所有元素都被移除，队列也会变得为空。

实现队列的方法有很多。 为简洁起见，我们将使用的那个可能是最简单的。 它创建一个单次使用、固定大小的队列，其中空区域不会被重用。 这样，队列最终会被耗尽并必须被丢弃。 虽然这种队列非常有限，但在某些情况下非常有用。 例如，这种队列可能保存由一个进程产生并由另一个进程消费的数据列表。 在这种情况下，生产者和消费者都不希望重用队列。 当产生更多数据时，会创建另一个队列。 先前的队列 simply 被丢弃并最终被垃圾回收。 当然，更复杂的队列也是可能的。 本书后面你将看到另一种实现队列的方法，称为循环队列，当元素被移除时，它会重用底层数组中的空区域。 这样，循环队列只要元素也在被取出，就可以继续放入元素。 你还将学习如何制作动态队列，它会自动增长以容纳更多元素。 然而，目前一个简单的队列就足够了。

在第 3 章中提到，C# 定义了一个名为 `foreach` 的循环，但对该语句的讨论被推迟到你学习 C# 之后。 讨论它的理想时间已经到来。 `foreach` 循环用于遍历集合中的元素。 集合是一组对象。 C# 定义了几种集合，其中一种是数组。 `foreach` 的一般形式如下所示：

```
foreach(type loopvar in collection) statement;
```

这里，`type loopvar` 指定迭代变量的类型和名称。 每次 `foreach` 循环迭代时，迭代变量都会接收集合中下一个元素的值。 被迭代的集合由 `collection` 表示，在本讨论的其余部分中，它是一个数组。 因此，`type` 必须等同于（或兼容于）数组的元素类型。 从 C# 3.0 开始，`type` 也可以是 `var`，在这种情况下，编译器根据数组的元素类型确定类型。 当处理某些查询时，这可能很有用，如本书后面所述。 通常，你会显式指定类型。

以下是 `foreach` 的工作原理。 循环开始时，数组中的第一个元素被获取并赋给 `loopvar`。 每次后续迭代都会从数组中获取下一个元素并将其存储在 `loopvar` 中。 当没有更多元素可获取时，循环结束。 因此，`foreach` 一次一个元素地从头到尾遍历数组。 关于 `foreach` 的一个重要点是要记住迭代变量 `loopvar` 是只读的。 这意味着你不能通过为迭代变量分配新值来更改数组的内容。 这里有一个使用 `foreach` 的简单示例。 它创建一个整数数组并显示其值。

## 字符串

从日常编程的角度来看，C# 数据类型中最重要的一种是 `string`。 `string` 定义并支持字符字符串。 在许多其他编程语言中，字符串是字符数组。 在 C# 中并非如此。 在 C# 中，字符串是对象。 因此，`string` 是引用类型。

事实上，你从第 1 章开始就一直在使用 `string` 类，只是你不知道。 当你创建一个字符串字面量时，你实际上是在创建一个 `string` 对象。 例如，在语句 `Console.WriteLine("In C#, strings are objects.");` 中，字符串 "In C#, strings are objects." 会自动由 C# 变成一个 `string` 对象。 因此，在之前的项目中，`string` 类的使用一直是“在表面之下”。 在本节中，你将学习如何显式地处理它们。 然而，请注意 `string` 类非常庞大，我们在这里只触及其表面。 这是一个你希望自行更深入探索的类。

`string` 类型还包括 `Length` 属性，其中包含字符串的长度。 要获取字符串中单个字符的值，只需使用索引即可。 例如：

```
string str = "test";
Console.WriteLine(str[0]);
```

这会显示 "t"。 与数组一样，字符串索引从零开始。 然而，一个重要点是，你不能使用索引为字符串中的字符分配新值。 索引只能用于获取字符。 要测试两个字符串是否相等，可以使用 `==` 运算符。 通常，当 `==` 运算符应用于对象引用时，它会确定两个引用是否引用同一对象。 对于 `string` 类型的对象则不同。 当 `==` 应用于两个字符串引用时，会比较字符串本身的内容是否相等。 对于 `!=` 运算符也是如此：比较字符串对象时，会比较字符串的内容。 对于其他种类的字符串比较，你应该使用 `CompareTo()` 方法。 这里有一件可能让你惊讶的事情：字符串对象的内容是不可变的。 也就是说，一旦创建，构成该字符串的字符序列就无法更改。 这种限制允许字符串更高效地实现。 虽然这很可能
