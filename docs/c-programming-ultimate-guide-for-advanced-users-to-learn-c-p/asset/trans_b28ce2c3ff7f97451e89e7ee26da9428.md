在深入了解使用 ref 和 out 的机制之前，了解为何需要按引用传递值类型是有价值的。总的来说，有两个原因：允许方法修改其参数的内容，或使方法能够返回多个值。让我们详细看看每个原因。通常，你需要一个方法能够操作传递给它的实际参数。这方面的典型例子是“swap”方法，它交换其两个参数的值。由于值类型按值传递，使用 C# 默认的按值参数传递机制是不可能编写这样的方法来交换两个 int 的值，例如。ref 修饰符解决了这个问题。如你所知，return 语句使方法能够向调用者返回一个值。然而，一次调用方法只能返回一个值。如果你必须返回至少两条数据怎么办？例如，如果你需要创建一个方法来计算矩形的面积，并且进一步判断该矩形是否为正方形怎么办？为此需要返回两条数据：面积和一个表示是否为正方形的数值。这个方法不能仅使用单个返回值来编写。out 修饰符解决了这个问题。

在许多编程语言中，动态分配内存的释放是手动处理的。例如，在 C++ 中，你使用 delete 运算符来释放已分配的内存。然而，C# 使用了一种替代的、更省心的方案：垃圾回收。C# 的垃圾回收系统会自动回收对象——在幕后直接进行，无需程序员干预。其工作原理如下：当不存在对对象的引用时，该对象被认为不再需要，其占用的内存会被释放。这样被重用的内存随后可用于后续分配。

垃圾回收只会在程序执行期间偶尔发生。它不会仅仅因为存在至少一个不再使用的对象就发生。因此，你无法确切知道垃圾回收何时会发生。可以定义一个方法，该方法仅在垃圾回收器最终销毁对象之前被调用。这个方法被称为析构函数，可在某些高度特定的情况下使用，以确保对象干净地结束。例如，你可以使用析构函数来确保对象拥有的系统资源被释放。必须一开始就说明，析构函数是一种高级特性，适用于某些特定情况。通常不需要它们。不过，由于它们是 C# 的一部分，这里简要描述以求完整。

在前面的示例中，使用了无参数构造函数。虽然这对某些情况来说是可以的，但经常你需要一个接受至少一个参数的构造函数。参数的添加方式与添加到方法中相同：只需在构造函数名称后的括号内声明它们。既然你已经了解类及其构造函数，我们应该研究 new 运算符。它的一般结构如下：

```
new class-name(arg-list)
```

这里，class-name 是正在实例化的类的名称。类名后跟括号决定了类的构造函数，如前文所述。如果类没有定义自己的构造函数，new 将使用 C# 提供的默认构造函数。由于内存有限，如果内存不足，new 可能无法为对象分配内存。如果发生这种情况，将会抛出运行时异常。对于本书中的示例程序，你不必担心内存不足，但在你编写的实际项目中应考虑这种可能性。在 C# 中，值类型变量包含其自身的值。存放该值的内存会在程序运行时自动提供。因此，没有必要显式使用 new 为其分配内存。另一方面，引用变量存储对一个
对象的引用。存放该对象的内存在执行期间动态分配。不将基本类型如 int 或 float 设为引用类型显著提高了程序的性能。使用引用类型时，会有一层间接引用，为每次对象访问增加开销。这种开销被值类型避免了。

## 运算符：
C# 提供了丰富的运算符环境。运算符是一个符号，告诉编译器执行特定的数值或逻辑操作。C# 有四类通用运算符：算术、按位、关系和逻辑。C# 还有一些处理特定特殊情况的其他运算符。本部分将分析算术、关系和逻辑运算符。它也分析赋值运算符。按位和其他特殊运算符将在后面介绍。

运算符 +、-、* 和 / 都按正常方式工作。它们可以应用于任何内置数值数据类型。尽管基本算术运算符的操作对所有读者都很熟悉，% 值得一些解释。首先，请记住当 / 应用于数字时，任何小数部分将被截断；例如，在整数除法中，10/3 等于 3。你可以通过使用取模运算符 % 得到该除法的余数。它在 C# 中的工作方式与其他语言相同：它产生数字除法的余数。例如，10 % 3 等于 1。在 C# 中，% 既可以应用于整数类型也可以应用于浮点类型。因此，10.0 % 3.0 也是 1。（这与 C/C++ 不同，后者仅允许对整数类型进行取模运算。）++ 和 -- 分别是自增和自减运算符。如你所见，它们有一些特殊属性，使其非常有趣。让我们先回顾一下自增和自减运算符的确切作用。自增运算符对其操作数加 1，自减运算符减 1。
