在C#中，方法可以调用自身。这个过程称为递归，调用自身的方法称为递归方法。通常，递归是用自身来定义某事物的过程，有点像循环定义。递归方法的关键部分是它包含一条执行自我调用的语句。递归是一种强大的控制机制。递归的经典例子是计算数字的阶乘。数字N的阶乘是1到N之间所有整数的乘积。例如，3的阶乘是1 × 2 × 3，即6。随附程序演示了计算数字阶乘的递归方法。为了比较，也包含了一个非递归的等价实现。例如，给定

```
int x;
x = 10;
```

x包含值10，因为x是int类型的变量，而int是一种值类型。然而，在

```
Vehicle minivan = new Vehicle();
```

这种情况下，minivan本身并不包含该对象。相反，它包含对该对象的引用。在赋值操作中，引用变量的行为与值类型（如int）的变量不同。当你将一个值类型变量赋给另一个时，情况很明确：左边的变量获得右边变量值的副本。当你将一个对象引用变量赋给另一个时，情况更复杂，因为你让左边的变量引用右边变量所引用的对象。起初，很容易想象car1和car2引用不同的对象，但事实并非如此。相反，car1和car2都将引用同一个对象。将car1赋给car2只是让car2像car1一样引用同一个对象。这样，该对象就可以通过car1或car2来操作。

如前所述，实例变量和方法是类的两个基本组成部分。

到目前为止，Vehicle类包含数据，但没有方法。虽然仅含数据的类是完全有效的，但大多数类都会有方法。方法是操纵类所定义的数据的子例程，并且通常提供对这些数据的访问。通常，程序的不同部分将通过方法来与类交互。一个方法至少包含一条语句。在编写良好的C#代码中，每个方法只执行一项任务。每个方法都有一个名称，该名称用于调用该方法。总的来说，你可以使用任何有效的标识符来命名方法。但是，请记住，Main( )是保留给启动程序执行的方法的。此外，不要使用C#的关键字作为方法名。在文本中表示方法时，本书已经并将继续使用一种在C#写作中常见的约定。方法名后面会有括号。例如，如果方法名是GetVal，那么在句子中使用其名称时，会写成GetVal( )。这种表示法有助于你在本书中区分变量名和方法名。

方法的一般形式如下所示：

```
access ret-type name(parameter-list) {
    // body of method
}
```

这里，access是访问修饰符，它控制程序的其他部分是否可以调用该方法。如前所述，访问修饰符是可选的。如果不存在，则该方法对其声明所在的类是私有的。在进一步说明之前，我们将方法声明为public，以便程序中的任何其他代码都可以调用它们。ret-type指定方法返回的数据类型。这可以是任何有效类型，包括你创建的类类型。如果方法不返回值，其返回类型必须是void。方法的名称由name指定。这可以是任何有效的标识符，但那些会导致当前声明空间内产生冲突的标识符除外。parameter-list是用逗号分隔的类型和标识符对的列表。参数本质上是变量，用于接收调用方法时传递给方法的参数值。如果方法没有参数，参数列表将为空。

正如刚才所解释的，类的方法通常操纵并提供对类数据的访问。有鉴于此，请回想一下，前面的示例中的Main( )通过将燃油消耗率乘以燃油容量来计算车辆的续航里程。虽然技术上正确，但这并不是处理此计算的最佳方式。车辆续航里程的计算最好由Vehicle类本身来处理。得出这一结论的原因很容易理解：车辆的续航里程取决于油箱容量和燃油消耗率，而这两个量都被封装在Vehicle中。通过向Vehicle添加一个计算续航里程的方法，你正在改进其面向对象的结构。要向Vehicle添加方法，请在Vehicle的声明内声明它。例如，下面的Vehicle版本包含一个名为Range( )的方法，用于显示车辆的续航里程。让我们看看这个程序的关键部分，从Range( )方法本身开始。

```
public void Range() {
```

这一行声明了一个名为Range的方法，它没有参数。它被指定为public，因此程序中的任何其他部分都可以使用它。其返回类型是void。因此，Range( )不向调用者返回值。该行以方法体的左花括号结束。Range( )的方法体仅由这一行组成：


这条语句通过将FuelCap乘以Mpg来显示车辆的续航里程。由于每个Vehicle类型的对象都有自己的FuelCap和Mpg副本，当调用Range( )时，计算会使用调用对象的这些变量副本。当遇到右花括号时，Range( )方法结束。这会使程序控制权移回调用者。接下来，看一下Main( )中的这行代码：

```
minivan.Range();
```

这条语句在minivan上调用Range( )方法。也就是说，它使用点运算符，相对于minivan引用的对象调用Range( )。当方法被调用时，程序控制权转移到该方法。当方法结束时，控制权移回调用者，并从调用后的代码行继续执行。在这种情况下，对minivan.Range( )的调用会显示minivan所定义的车辆的续航里程。类似地，对sportscar.Range( )的调用会显示sportscar所定义的车辆的续航里程。每次调用Range( )时，它都会显示指定对象的续航里程。
