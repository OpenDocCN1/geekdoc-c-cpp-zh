### 面向对象基础：

面向对象基础远非基础。每种面向对象语言都实现了构成优秀面向对象语言的一部分特性。此外，C#，尤其与 C++、Delphi、Visual Basic 6 或 Visual Basic.NET 相比，有自己独特的方式来实现面向对象编程语言（OOPL）的这些组成部分。

面向对象编程的原则是封装、继承、抽象和多态。支持这些基本原则的语言被视为面向对象语言。有许多构造有助于实现这些原则，包括模板、运算符重载、接口、多线程、多继承、特殊情况处理、指针和垃圾回收等。C# 是一种强大的 OOPL，它通过提供运算符重载、继承、接口、异常处理、垃圾回收、多接口继承、反射和多线程来支持面向对象编程的原则。C# 不支持模板、原始指针或多类继承。关于这三项特性是否带来的问题比解决的问题更多，存在很多讨论；因此它们被 C# 排除在外。

你得到的不是多继承、指针和模板，而是额外的新特性，这些特性将帮助你构建 Web 应用程序和 Web 服务。C# 支持 COM 互操作、多语言编程和快速应用程序开发。这有一些权衡取舍。

C# 是托管代码。其优点是你不必担心错误指针导致的崩溃问题，垃圾回收器将帮助你避免内存泄漏。权衡的代价是放弃原始指针。指针支持一些高级惯用法，例如引用计数项和访问所有内存。对任何内存地址的同等访问带来了极大的控制和责任。能力越大，责任越大。（对于原始指针，你仍然可以使用非托管 C++ 代码。）

C# 在语言上最接近 C++。你在 C# 中通常使用的大部分普通构造都与 C++ 具有相似的语法，这使得 C++ 软件工程师的学习曲线最平缓。Delphi 和 Java 软件工程师同样会发现向 C# 的过渡通常很简单，甚至 VB 开发者也会发现从 VB 到 C# 的转变比从 VB 到 C++ 更简单。

使用 Visual Studio 6 控制台项目——可在 Visual Studio .NET 的“我的配置文件”中修改——我们可以按 F5 运行应用程序。WriteLine 和 ReadLine 都是 Console 类中的静态成员，因此我们无需创建 Console 对象的实例即可调用这些方法。

Console.WriteLine 向命令提示符写入一行，并在内容末尾追加另一个新行；而 Console.ReadLine 语句会等待回车后再继续。同样地，请注意 C# 中的语句以分号结尾。
