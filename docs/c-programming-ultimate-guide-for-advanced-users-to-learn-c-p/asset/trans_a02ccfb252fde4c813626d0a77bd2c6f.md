## C# 类库：
本部分介绍的示例项目使用了 C# 的两个内置方法：WriteLine( ) 和 Write( )。如前所述，这些方法是 Console 类的成员，而 Console 类属于 System 命名空间，该命名空间由 .NET Framework 的类库定义。如本节前面所述，C# 环境依赖于 .NET Framework 类库来提供诸如 I/O、字符串处理、网络和 GUI 等支持。因此，C# 总体上是 C# 语言本身加上 .NET 标准类的组合。正如你将看到的，类库提供了任何 C# 程序的一部分的大量功能。的确，成为 C# 开发人员的一部分就是学习如何使用标准库。

整本书中描述了 .NET 库类和方法的各个组件。然而，.NET 库非常庞大，你也希望自行进一步探索。

## 重要数据类型：
数据类型在 C# 中特别重要，因为它是一种强类型语言。这意味着所有操作都会由编译器进行类型兼容性检查。非法操作无法编译。因此，强类型检查可以防止错误并提高可靠性。为了实现强类型检查，所有变量、表达式和值都有类型。例如，没有“无类型”变量的概念。此外，值的类型决定了对其允许执行的操作。一种类型上允许的操作可能不允许在另一种类型上执行。

### C# 值类型：
C# 包含两种通用内置数据类型类别：值类型和引用类型。两者的区别在于变量包含的内容。对于值类型，变量保存实际值，例如 101 或 98.6。对于引用类型，变量保存对值的引用。最常用的引用类型是类，关于类和引用类型的讨论将推迟到后面。值类型在此描述。C# 的核心是表 2-1 中所示的 13 种值类型。通常，这些被称为简单类型。它们被称为简单类型是因为它们由单个值组成。（换句话说，它们不是由两个或多个值组成的复合体。）它们构成了 C# 类型系统的基础，提供了程序工作的基本、低级数据元素。简单类型有时也被称为原始类型。C# 仔细指定了每种简单类型的范围和行为。基于可移植性要求并支持混合语言编程，C# 在这方面非常严格。例如，int 在所有执行环境中都相同。无需修改代码以适应特定平台。虽然仔细指定简单类型的大小在某些情况下可能会导致轻微的性能损失，但为了实现可移植性这是必不可少的。

## 字面量：
在 C# 中，字面量指的是以可读形式表示的固定值。例如，数字 100 就是一个字面量。通常，字面量及其使用如此直观，以至于它们已在某种形式下被所有第一个示例程序使用。现在是正式解释它们的时候了。

C# 字面量可以是任何值类型。每个字面量的表示方式取决于其类型。如前所述，字符字面量用单引号括起来。例如 'a' 和 '%' 都是字符字面量。整数字面量指定为没有小数部分的数量。例如，10 和 – 100 都是整数字面量。浮点字面量需要使用小数点后跟数字的小数部分。例如，11.123 是一个浮点字面量。C# 还允许你对浮点数使用科学记数法。由于 C# 是强类型语言，字面量也有类型。通常，这会引发以下问题：数字字面量的类型是什么？例如，12、123987 或 0.23 的类型是什么？幸运的是，C# 规定了一些易于遵循的规则来回答这些问题。首先，对于整数字面量，字面量的类型是从 int 开始能够容纳它的最小数值类型。因此，整数字面量的类型取决于其值，为 int、uint、long 或 ulong。其次，浮点字面量的类型为 double。

如果 C# 的默认类型不是你想要的字面量类型，你可以通过添加后缀显式指定其类型。要指定 long 字面量，添加 l 或 L。例如，12 是 int，但 12L 是 long。要指定无符号整数值，附加 u 或 U。因此，100 是 int，但 100U 是 uint。要指定无符号 long 整数，使用 ul 或 UL。例如，984375UL 的类型为 ulong。

要指定 float 字面量，附加 F 或 f。例如，10.19F 的类型为 float。尽管冗余，你也可以通过附加 D 或 d 来指定 double 字面量。（如前所述，浮点字面量默认为 double。）要指定 decimal 字面量，在其值后跟 m 或 M。例如，9.95M 是一个 decimal 字面量。

尽管整数字面量默认生成 int、uint、long 或 ulong 值，但只要被赋值的数值能由目标类型表示，它们仍可以赋给 byte、sbyte、short 或 ushort 类型的变量。

### 十六进制字面量：
在编程中，有时使用基于 16 而非 10 的数字系统更方便。基数为 16 的数字系统称为十六进制，使用数字 0 到 9 以及字母 A 到 F，分别代表 10、11、12、13、14 和 15。例如，十六进制数 10 在十进制中为 16。由于十六进制数的使用频率很高，C# 允许你以十六进制格式指定整数字面量。十六进制字面量必须以 0x 开头（零后跟 x）。

### 字符转义序列：
用单引号括起字符常量对大多数可打印字符有效，但少数字符，例如回车，在使用文本编辑器时会带来特殊问题。此外，某些其他字符，例如单引号和双引号，在 C# 中具有特殊意义，因此不能直接使用。因此，C# 提供了特殊的转义序列。

注意如何使用 \n 换行序列来产生新行。你不需要使用多个 WriteLine() 语句来获得多行输出。只需在希望出现换行的位置将 \n 嵌入更长的字符串中即可。
