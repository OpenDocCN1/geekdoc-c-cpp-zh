You have been using the assignment operator since Chapter 1. Now the time has come to take a formal look at it. The assignment operator is the single equals sign, `=`. The assignment operator works in C# much as it does in other languages. It has this general structure:

```
var = expression;
```

Here, the type of `var` must be compatible with the type of expression. The assignment operator has one intriguing property with which you may not be well-acquainted: It enables you to make a chain of assignments. This part sets the variables x, y, and z to 100 using a single expression. This works because the `=` is an operator that yields the assigned value. Therefore, the value of `z = 100` will be 100, which is then assigned to y, which, in turn, is assigned to x. Using a "chain of assignment" is a simple approach to set a group of variables to a common value. Since the compound assignment expressions are shorter than their noncompound counterparts, the compound assignment operators are additionally sometimes called the shorthand assignment operators.

The compound assignment operators give two advantages. First, they are more compact than their "longhand" counterparts. Second, they can bring about more efficient executable code (since the left-hand operand is evaluated just once). Thus, you will regularly observe the compound assignment operators used in expertly composed C# programs. When compatible types are mixed in an assignment, the value of the right side is consequently converted to the type of the left side.
