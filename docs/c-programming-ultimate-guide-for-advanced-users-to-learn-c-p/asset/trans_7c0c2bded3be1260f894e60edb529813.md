## 反射

反射是 C# 中实现的一种功能，它使你能够动态查找信息，例如程序集中的命名空间、接口、类、方法、属性和字段。除了提供一种请求由特性描述的元数据值的方法外，反射还使你能够了解程序集中定义的类型以及类型中的成员，并且反射使你能在运行时发出中间语言（IL）代码。IL 在用途上与 Java 字节码类似。IL 是代码被汇编成机器码之前的代码。反射是奇妙的魔法。

C# 3.0 定义了 13 个上下文关键字，它们在特定上下文中具有特殊含义。在这些特定上下文中，它们充当关键字。在它们的上下文之外，它们可以用作其他程序元素（例如变量名）的标识符。这样一来，它们实际上并未被保留。然而，作为一般规则，你应该将上下文关键字视为保留字，并避免将它们用于任何其他目的。将上下文关键字用作其他程序元素的名称可能会引起混淆，许多软件工程师认为这是一种不良做法。在 C# 中，标识符是分配给方法、变量或其他用户自定义事物的名称。标识符的长度可以从一个到几个字符不等。变量名可以以字母表中的任何字母或下划线开头。下一个字符可以是字母、数字或下划线。

下划线可用于提高变量名的可读性，例如 `line_count`。请记住，你不能以数字开头标识符。因此，例如 `12x` 是无效的。良好的编程实践要求你使用能反映所命名事物的含义或用途的标识符名称。虽然你不能使用任何 C# 关键字作为标识符，但 C# 允许你在关键字前加上 `@`，使其成为合法的标识符。例如，`@for` 是一个有效的标识符。在这种情况下，标识符实际上是 `for`，`@` 被忽略。老实说，除非出于特定目的，否则不建议使用 `@` 限定关键字作为标识符。同样，`@` 可以放在任何标识符前面，但这被认为是一种不良做法。

## 库

有符号数和无符号数的区别在于如何解释整数的最高位。如果指示为有符号整数，C# 编译器将生成假定整数最高位用作符号位的代码。如果符号位为 0，则该数字为正；如果为 1，则为负。负数几乎总是使用二进制补码来表示。在这种策略中，数字中的所有位都被反转，然后在该数字上加 1。有符号数对于大量计算非常重要，但它们的绝对范围只有无符号对应数的一半。例如，作为 short，这里为 32,767：0 1。对于有符号值，如果最高位被设置为 1，则该数字将被解释为 −1（假设采用二进制补码设计）。但是，如果你将其声明为 ushort，那么当最高位被设置为 1 时，该数字将得到 65,535。最常用的数字类型可能是 int。int 类型的变量通常用于控制循环、索引数组以及一般用途的整数运算。当你需要一个范围大于 int 的数字时，你有很多选择。如果你需要存储的值是无符号的，可以使用 uint。对于巨大的有符号值，使用 long。对于巨大的无符号值，使用 ulong。
