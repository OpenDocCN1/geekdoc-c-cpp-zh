### 保存文本文件

RichTextBox.SaveFile 执行与 LoadFile 对称的操作。SaveFile 通过调用 SaveFile 并传入文件名，将 RichTextBox 控件的内容写入 RTF 或 TXT 文件。

### 使用 ZoomFactor

RichTextBox.ZoomFactor 是一个有趣的属性。使用 ZoomFactor 可以指定文本大小增加的百分比。将 ZoomFactor 设置为 2 将使文本大小加倍，而 0.64 会将文本大小减小约一半。有效值为 0.64 到 64，最后一个值是正常大小的 64 倍。此属性对于支持残障人士的应用程序和演示来说是一个很棒的功能。例如，假设你正在通过投影仪显示 RichTextBox 的文本。设置 ZoomFactor 增大文本大小，将使观众更容易看到 RichTextBox 控件中的文本。
