## 数组排序

因为一维数组将信息组织成可索引的线性形式，所以它是排序的理想数据结构。此外，排序算法是数组处理的最佳示例之一。为此，本示例开发了一个相当著名的冒泡排序版本。你可能知道，有许多不同的排序算法。仅举三例，就有快速排序、摇动排序和希尔排序。然而，最简单、最易于理解的排序算法之一是冒泡排序。就性能而言，它也是最差的排序算法之一（尽管有时它可以有效地用于对非常小的数组进行排序）。不过，冒泡排序有一个有用的特点：它构成了一个有趣的数组处理示例！

通常，有两个原因：允许方法更改其参数的内容，或者使方法能够返回多个值。让我们详细看看每个原因。你常常会希望方法能够操作传递给它的实际参数。最典型的例子是“交换”方法，它交换两个参数的值。由于值类型是按值传递的，因此例如使用 C# 默认的按值调用参数传递机制，无法编写这样的方法来交换两个 int 的值。ref 修饰符解决了这个问题。你可能知道，return 语句使方法能够向调用方返回一个值。然而，方法每次被调用时只能返回一个值。如果你需要返回两条或更多信息呢？例如，如果你需要创建一个方法，计算矩形的面积，同时判断该矩形是否为正方形呢？要做到这一点，需要返回两项数据：面积和一个表示是否为正方形的值。这个方法不能只使用单个返回值来编写。out 修饰符解决了这个问题。

多维数组的最简单形式是二维数组。在二维数组中，元素的位置由两个索引指定。可以把二维数组看作数据表：一个索引表示行，另一个索引表示列。要声明一个大小为 10、20 的二维整数数组 table，可以这样写：

```csharp
int[,] table = new int[10, 20];
```

请特别注意该声明。注意两个维度之间用逗号分隔。在声明的第一部分，语法 [,] 表示正在创建一个二维数组引用变量。当使用 new 实际为数组分配内存时，使用的语法如下：

```csharp
new int[10, 20]
```

这会创建一个 10×20 的数组，同样，逗号分隔各个维度。要访问二维数组中的元素，必须指定两个索引，并用逗号分隔二者。例如，要将值 10 赋给数组 table 的位置 3, 5，可以使用：

```csharp
table[3, 5] = 10;
```

## 交错数组

在最初的示例中，创建二维数组时，你创建的是 C# 所称的矩形数组。把二维数组看作表，矩形数组就是整个数组中每一行长度都相同的二维数组。然而，C# 还允许你创建一种特殊的二维数组，称为交错数组。交错数组是数组的数组，其中每个数组的长度可以不同。因此，交错数组可用于创建行长度不相同的表。交错数组通过使用多组方括号来指示每个维度进行声明。例如，要声明一个二维交错数组，可使用以下一般形式：

```csharp
type[][] arrayName = new type[size][];
```
