## 使用 TimeSpan 评估时间差

TimeSpan 结构用于测量最短为 100 纳秒的时间跨度，在 TimeSpan 中表示为一个 tick。TimeSpan 值可以表示为以天、小时、分钟、秒和秒的小数部分表示的正负时间范围。字符串格式 d.hh:mm:ss.ff 将显示单个 TimeSpan 所表示的天、小时、分钟、秒和秒的小数部分。TimeSpan 表示的最大时间单位是天。

如果 TimeSpan 的默认字符串表示是可以接受的，那么我们可以使用 TimeSpan.ToString() 方法，该方法通常会以 hh:mm:ss 格式返回 TimeSpan。

如果对 DateTime 值执行算术运算，例如从一个时间减去另一个时间，该运算将返回一个 TimeSpan 对象。

## 摘要

本节介绍 Broadcaster.Broadcast 方法。这是为将内部数据发送到单一位置而定义的方法，允许需要了解情况的监听器调谐到广播器。例如，我们可以将主窗体注册为监听器并在主窗体上显示任务状态。AssemblyViewer 正是这样做的；主窗体有一个状态栏，用于在加载操作期间显示 AssemblyManager 的进度。

实现 IListener 并向 Broadcaster 注册的类能够接收发送到 Broadcaster 的字符串消息。该类和接口演示了几个值得注意的方法，因此我们将逐一查看。

## 实现 Broadcaster

Broadcaster 演示了单例模式。单例是一个您需要确保只有一个实例的类。通常，该实例用于表示单一资源的存在，类似于一台打印机。通过将构造函数设为 protected 或 private 并仅通过静态成员提供访问，可以创建单例类。Broadcaster 通过内部、私有的 Instance 属性来实现这一点。

Broadcaster 中的每个公共方法都是静态的。当您调用 Broadcaster（或任何单例）中的公共成员时，该方法会引用只读的 Instance 属性。Instance 属性检查 Broadcaster 的单一实例是否已创建。如果单例不存在，则创建一个实例并将其分配给私有字段 instance。然后返回单例对象。结果是 Broadcaster 包含对自身实例的引用。

如果将 IListener 添加到 listeners 的 ArrayList 中，则每次调用静态方法 Broadcast 时，所有正在监听的监听器都会接收到字符串内容。此技术可用于显示内部状态信息、写入日志文件、监控分布式应用程序，或执行这些任务的组合。（建议使用与 Broadcaster 习惯用法相关的 Debug 和 Trace 监听器。）另外，请注意 IEnumerable 用于遍历 listeners 的 ArrayList。

## 定义接口

IListener 接口定义了两个方法：Listening 和 Listen。Listening 是一个返回布尔值以指示实现 IListener 接口的对象是否希望接收消息的函数。这使得对象可以在不从 Broadcaster 注销的情况下 figuratively 堵住耳朵。Listen 方法是在监听时接收字符串内容的方法。

您可以通过实现 IListener 接口来使用 Broadcaster。FormMain 类实现 IListener 以在状态栏中显示广播消息。对于主窗体，您可以在 Form 的 Load 中将窗体添加到监听器列表中。另一个将监听器添加到监听器列表的好地方是在类的构造函数中。考虑实现 IDisposable 和 Dispose，以便在对象被释放时将其从 Broadcaster 的监听器列表中移除。
