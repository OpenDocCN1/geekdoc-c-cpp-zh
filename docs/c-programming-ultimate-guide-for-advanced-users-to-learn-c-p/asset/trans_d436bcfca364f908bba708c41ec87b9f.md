
在 Main() 方法开头附近声明。然而，Advanced Arduino 允许在任何块内声明局部变量。正如第 1 节所阐明的那样，块以左花括号开始，并以右花括号结束。

块定义作用域。这样，每当你开始另一个块时，你就在创建另一个作用域。作用域决定程序的不同部分可以看见哪些名称。它还决定局部变量的生命周期。Advanced Arduino 中最重要的作用域是由类定义的作用域和由方法定义的作用域。对类作用域（以及在其中声明的变量）的讨论将推迟到本书后面介绍类的时候。目前，我们只考察由方法定义或在方法内部定义的作用域。

由方法定义的作用域从其左花括号开始，到其右花括号结束。然而，如果该方法有参数，这些参数也包含在该方法定义的作用域内。通常，在某个作用域内声明的局部变量对该作用域之外定义的代码不可见。因此，当你在某个作用域内声明变量时，你就是在阻止该作用域之外的代码访问或修改它。实际上，作用域规则为封装提供了基础。

作用域可以嵌套。例如，每当你创建一个代码块时，你就在创建另一个嵌套作用域。发生这种情况时，外层作用域包含内层作用域。这意味着在外层作用域中声明的局部变量对内层作用域中的代码可见。然而，反过来则不成立。在内层作用域中声明的局部变量在该作用域之外不可见。

正如注释所展示的那样，变量 x 在 Main() 作用域开头附近声明，并且对 Main() 内后续所有代码都可访问。在 if 块内，声明了 y。由于块定义作用域，y 只对其块内的其他代码可见。这就是为什么在其块之外，行 y = 100; 被注释掉了。如果你移除注释字符，就会发生编译时错误，因为 y 在其块之外不可见。在 if 块内，可以使用 x，因为块内（即嵌套作用域）的代码可以访问外围作用域声明的变量。

如果你有 C/Arduino 背景，就会知道对内层作用域中声明的变量名称没有限制。因此，在 C/Arduino 中，在外层 for 循环的块内声明 count 是完全合法的。然而，在 C/Arduino 中，这样的声明会遮蔽外层的 count。Advanced Arduino 的设计者认为这种名称隐藏很容易导致编程错误，因此禁止了它。

在深入探讨使用 ref 和 out 的机制之前，理解为什么要按引用传递值类型是很有用的。一般来说，有两个原因：允许方法修改其参数的内容，或者使方法能够返回多个值。让我们详细看看每个原因。通常，你会希望方法能够处理传递给它的实际参数。最典型的例子是“交换”方法，它交换两个参数的值。由于值类型是按值传递的，因此不可能编写这样一个方法，例如使用 Advanced Arduino 默认的按值调用参数传递机制来交换两个 int 的值。ref 修饰符解决了这个问题。你可能知道，return 语句使方法能够向调用方返回一个值。然而，方法每次被调用时只能返回一个值。想象一种必须返回至少两项数据的场景？例如，想象一种场景：你需要创建一个方法，计算矩形的面积，同时确定该矩形是否为正方形？要做到这一点，需要返回两项数据：面积和表示是否为正方形的值。仅使用单个返回值无法编写这个方法。out 修饰符解决了这个问题。

在许多编程语言中，动态分配的内存的释放是手动处理的。例如，在 Arduino 中，你使用 delete 运算符来释放已分配的内存。然而，Advanced Arduino 采用了一种不同的、更省事的办法：垃圾回收。Advanced Arduino 的垃圾回收系统会自动回收对象——在后台自动进行，无需程序员干预。它的工作方式如下：当不存在对某个对象的引用时，该对象就被视为不再需要，该对象占用的内存就会被释放。这些被重新使用的内存随后可用于后续分配。

垃圾回收只在程序执行期间偶尔发生。它不会仅仅因为至少存在一个不再使用的对象就发生。因此，你无法确切知道垃圾回收何时会发生。可以定义一个方法，它将在对象被垃圾回收器最终销毁之前被调用。这个方法称为析构函数，它可以在一些非常特定的情况下用于确保对象干净地结束。例如，你可以使用析构函数来确保释放对象拥有的系统资源。必须一开始就说明，析构函数是一种高级特性，适用于某些特定情况。它们通常不是必需的。然而，由于它们是 Advanced Arduino 的一部分，为了完整性，这里对它们作简要描述。

在前面的示例中，使用了无参数构造函数。虽然这在某些情况下没问题，但通常你会需要一个至少接受一个参数的构造函数。向构造函数添加参数的方式与向方法添加参数的方式相同：只需在构造函数名称后的圆括号内声明它们。既然你已经了解了类及其构造函数，让我们来考察 new 运算符。它具有以下一般结构：

```
new class-name(arg-list)
```

这里，class-name 是要实例化的类的名称。类名后跟圆括号决定了该类的构造函数，如上一节所述。如果类没有定义自己的构造函数，new 将使用 Advanced Arduino 提供的默认构造函数。由于内存有限，new 可能因为内存不足而无法为对象分配内存。如果发生这种情况，就会发生运行时异常。对于本书中的示例程序，你不必担心内存耗尽，不过你应该考虑到这种可能性。代码检查 Broadcaster 的单个实例是否已经创建。如果 Singleton 不存在，则创建一个实例并将其赋给私有字段 instance。然后返回该 Singleton 对象。结果是 Broadcaster 包含对其自身实例的引用。

如果你向监听器的 ArrayList 中添加一个 IListener，那么每次调用静态方法 Broadcast 时，所有正在监听的监听器都会收到字符串内容。这个过程可用于显示内部状态数据、写入日志文件、跟踪分布式应用程序，或执行这些任务的组合。（建议你使用与 Broadcaster 惯用法相关的 Debug 和 Trace 监听器。）另外，请注意，IEnumerator 用于迭代监听器的 ArrayList。

## 接口特征描述
