## 使用 TimeSpan 评估时间差

TimeSpan 结构用于测量短至 100 纳秒的时间跨度，这在 TimeSpan 中表示为一个 tick。TimeSpan 值可以表示为以天、小时、分钟、秒和秒的小数部分衡量的正负时间跨度。字符串格式 d.hh:mm:ss.ff 将显示单个 TimeSpan 表示的天、小时、分钟、秒和秒的小数部分。TimeSpan 表示的最大时间单位是天。

如果 TimeSpan 的默认字符串表示是可以接受的，那么我们可以使用 TimeSpan.ToString() 方法，该方法通常会以 hh:mm:ss 形式返回 TimeSpan。

如果对 DateTime 值执行计算操作，例如从一个时间减去另一个时间，该操作将返回一个 TimeSpan 对象。

## 格式化字符串

出于我们的目的，我们选择不使用默认的 TimeSpan.ToString 方法。这是一个可选决定，使我们能够探索 string.Format 方法和格式化掩码。（在生产系统中，更建议使用 TimeSpan.ToString 方法。）

GetMask 返回一个格式化字符串。该字符串是 "{0}:{1,2:0#}:{2,2:0#}"。花括号 {} 中的字符代表可替换的格式字符，其余部分代表字面值。检查 {1,2:0#}，我们理解这个可替换参数为可替换参数 1，它是基于零的，长度可达两位数字。

通常，格式项中的第一个参数表示要格式化的基于零的参数。第二个参数——如果存在，以逗号分隔——表示格式化值的宽度。如果包含负号，则值左对齐，正号则右对齐值。当然，宽度会用空格填充格式化参数。可选的格式化字符串跟在冒号之后。我们的 0# 格式化字符串表示格式化输出将用 0 和一个数字填充。如果数字占用了两个空格，则 0 不会显示。

## 实现 Broadcaster

Broadcaster 实现了单例设计。单例是一个你需要保证只有一个实例的类。通常，该实例用于表示单个资源的存在，类似于单个打印机。单例类是通过将构造函数设为 protected 或 private 并仅通过静态成员提供访问来创建的。Broadcaster 通过内部、私有的 Instance 属性来实现这一点。

Broadcaster 中的每个公共方法都是静态的。当你调用 Broadcaster（或任何单例）中的公共成员时，该方法引用只读的 Instance 属性。它验证 Broadcaster 的单一实例是否已创建。如果单例不存在，则创建一个实例并将其分配给私有字段 instance。然后返回单例对象。结果是 Broadcaster 包含对自身实例的引用。
