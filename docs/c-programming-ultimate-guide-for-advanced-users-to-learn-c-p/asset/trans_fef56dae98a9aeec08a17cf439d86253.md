### 确定性销毁

C# 使用非确定性销毁。CLR 实现了一个垃圾回收器，在对象不再使用时清理内存。这意味着在 C# 中，你不必像在 C++ 或 Delphi 中那样为析构函数操心那么多。

当你的对象不再需要时，垃圾回收器将调用其析构函数。析构函数将调用任何 Finalize 方法。你可以通过调用 GC.Collect 强制进行垃圾回收，但这并不是推荐的做法。垃圾回收器会挂起任何正在运行的线程，这可能会搞乱执行。此外，垃圾回收器在决定何时运行方面会做得非常出色。
