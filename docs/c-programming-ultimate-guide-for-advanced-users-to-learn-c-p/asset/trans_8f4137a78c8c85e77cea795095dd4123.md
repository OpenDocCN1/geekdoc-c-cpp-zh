
更重要的是——对参数所引用的对象所做的更改会影响参数所引用的对象，因为它们是同一个对象。让我们看看原因。回想一下，当你创建一个类类型的变量时，你创建的是对对象的引用，而不是对象本身。对象是通过 new 分配的，并且对其的引用被赋给引用变量。当你将引用变量用作方法参数时，参数会获得与参数所引用的同一个对象的引用。因此，参数和形参都将引用同一个对象。这意味着对象是通过实质上按引用调用的方式传递给方法的。方法内部对对象的更改确实会影响用作参数的对象。在 C# 中，数组可以有一个或多个维度，尽管一维数组是最常见的。数组因其提供了一种方便的方式来分组相关变量而被用于各种目的。例如，你可以使用数组来保存一个月的每日最高气温记录、连接到网络的客户端列表，或你的编程书籍收藏。

数组的主要优点是它组织信息使其易于操作。例如，如果你有一个包含所选家庭群体薪水的数组，通过循环遍历数组很容易计算平均薪水。同样，数组组织信息使其易于排序。虽然 C# 中的数组可以像许多其他编程语言中的数组一样使用，但它们有一个独特的属性：它们被实现为对象。这一事实是为什么在介绍对象之前推迟讨论数组的原因之一。通过将数组实现为对象，可以获得几个显著的优势，其中最不重要的就是未使用的数组可以被垃圾回收。

由于复合赋值语句比其非复合对应语句更短，因此复合赋值运算符有时也被称为简写赋值运算符。

复合赋值运算符提供两个优点。首先，它们比其“长写法”对应运算符更紧凑。其次，它们可以生成更高效的可执行代码（因为左操作数只被求值一次）。因此，你经常会在编写精良的 C# 程序中看到复合赋值运算符的使用。当在赋值中混合兼容的类型时，右侧的值会自动转换为左侧的类型。因此，在上一节中，`i` 中的值被转换为 float 然后赋给 `f`。然而，由于 C# 的严格类型检查，并非所有类型都是兼容的，因此并非所有类型转换都被隐式允许。例如，bool 和 int 不兼容。

当这两个条件满足时，就会发生扩展转换。例如，int 类型总是足够大以容纳所有有效的 byte 值，并且 int 和 byte 都是整数类型，因此可以应用隐式转换。对于扩展转换，包括整数和浮点类型在内的数值类型彼此兼容。例如，以下程序是完全有效的，因为 long 到 double 是自动执行的扩展转换：

```
(target-type) expression
```

这里，target-type 表示要将指定表达式转换成的目标类型。例如，假设你希望表达式 x/y 的类型为 int。在这种情况下，虽然 x 和 y 的类型为 double，但强制转换会将表达式的结果转换为 int。x/y 周围的括号很重要。否则，转换为 int 的强制转换将只应用于 x，而不应用于除法的结果。这里强制转换至关重要，因为 double 到 int 没有隐式转换。

当强制转换包含窄化转换时，可能会丢失数据。例如，将 long 转换为 int 时，如果 long 的值大于 int 的范围，则会丢失数据，因为其高位会被丢弃。当浮点值转换为整数类型时，小数部分也会因截断而丢失。例如，如果值 1.23 被赋给整数，结果值将仅为 1。0.23 会丢失。在程序中，将 (x/y) 转换为 int 会导致小数部分被截断，数据丢失。接下来，当 b 被赋值为 100 时不会丢失数据，因为 byte 可以容纳值 100。然而，当尝试将 b 赋值为 257 时会发生数据丢失，因为 257 超出了 byte 的范围。这导致 b 的值为 1，因为在 257 的二进制表示的低 8 位中只有 1 位被设置。最后，没有数据丢失，但将 byte 值赋给 char 时仍需要强制转换。

一维数组是一组相关变量的列表。此类数组在编程中很常见。例如，你可以使用一维数组来存储网络上活动客户端的 ID 号。另一个数组可用于存储棒球队当前的打击率。由于 C# 中的数组被实现为对象，因此要在程序中使用它需要两个步骤。首先，你应该声明一个可以引用数组的变量。其次，你应该使用 new 创建数组的实例。因此，要声明一维数组，你通常会使用以下一般结构：

```
type[] arrayName = new type[size];
```

这里，type 声明数组的元素类型。元素类型决定了数组将包含的元素的数据类型。请注意 type 后面的方括号。它们表示正在声明对一维数组的引用。数组将容纳的元素数量由 size 决定。以下是一个示例。以下代码创建一个包含十个元素的 int 数组并将其连接到名为 test 的数组引用变量：

```
int[] test = new int[10];
```

test 变量保存着由 new 分配的内存的引用。该内存足够大，可以容纳十个 int 类型的元素。在这种情况下，test 最初创建时不引用任何物理对象。只有在第二个语句执行后，test 才引用一个数组。

数组内部的单个元素是通过索引访问的。索引描述了数组内部元素的位置。在 C# 中，所有数组的第一个元素的索引都为零。由于 test 有十个元素，因此它的索引值为 0 到 9。要索引数组，请指定你想要的元素编号，用方括号括起来。
