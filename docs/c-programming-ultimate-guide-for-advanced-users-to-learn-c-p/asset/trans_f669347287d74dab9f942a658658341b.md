析构函数具有以下通用结构：

```

    // destruction code

    }
```

这里，class-name 是类的名称。因此，析构函数的声明方式与构造函数类似，不过它前面加上了 ~（波浪号）。请注意它没有返回类型。理解析构函数仅在垃圾回收之前被调用。例如，当包含对对象的引用的变量离开作用域时，它不会被调用。（这与 C++ 中的析构函数形成对比，C++ 中的析构函数在对象超出作用域时会被调用。）这意味着你无法准确知道析构函数何时会被执行。此外，你的程序可能在垃圾回收发生之前就已结束，因此析构函数可能根本不会被调用。有时你需要使用引用参数从方法中获取值，但不需要传入值。例如，你可能有一个执行某些功能的方法，例如打开网络套接字，它会在引用参数中返回成功/失败代码。在这种情况下，没有数据传入方法，但是有数据传出。

这种情况下的问题是，ref 参数必须在调用前初始化为一个值。因此，使用 ref 参数就需要给参数一个虚拟值来满足这一限制。幸运的是，C# 提供了更好的替代方案：out 参数。out 参数与 ref 参数类似，只有一个例外：它必须用于将值从方法传出。在调用方法之前，给用作 out 参数的变量赋一个初始值既不是必要的也不是有用的。方法会为该变量赋此值。此外，在方法内部，out 参数始终被视为未赋值；也就是说，假定它没有初始值。相反，方法必须在方法结束前为该参数赋值。因此，在调用方法后，由 out 参数引用的变量将包含一个值。以下是使用 out 参数的示例。方法 RectInfo() 根据矩形的边长返回其面积。在参数 isSquare 中，如果矩形是正方形则返回 true，否则返回 false。因此，RectInfo() 向调用者返回两条信息。当你创建方法时，你通常事先知道将向其传递多少个参数，但并非总是如此。有时你需要创建一个可以传递任意数量参数的方法。例如，考虑一个查找一组值中最小值的方法。这样的 方法可能被传递最少两个值，或三个、四个等。在所有情况下，你都需要该方法返回最小值。这样的 方法无法使用普通参数实现。相反，你应该使用一种表示任意数量参数的特殊参数。这是通过创建 params 参数来完成的。

## 第5章：运算符和数据类型

数组是一组由共同名称引用的相同类型变量的集合。在 C# 中，数组可以有一个或多个维度，尽管一维数组是最常见的。数组用于各种目的，因为它们提供了对相关变量进行分组的便捷方式。例如，你可以使用数组保存一个月的每日最高温度记录、登录系统的用户列表，或你的编程书籍收藏。

数组的主要优点是它组织数据，使其易于操作。例如，如果你有一个包含所选家庭收入的数组，遍历该数组计算平均收入并不困难。同样，数组将数据组织起来，使其易于排序。虽然 C# 中的数组可以像许多其他编程语言中的数组一样使用，但它们有一个特殊之处：它们被实现为对象。这一事实是为什么在介绍对象之前推迟讨论数组的原因之一。通过将数组实现为对象，可以获得多个重要优势，其中最不重要的是未使用的数组可以被垃圾回收。一维数组是一组相关变量的列表。这样的列表在编程中是基础。例如，你可以使用一维数组存储系统中活动用户的记录号。另一个数组可用于存储棒球队当前的打击率。

由于 C# 中的数组被实现为对象，因此要在程序中使用它需要两个步骤。首先，你应该声明一个可以引用数组的变量。其次，你应该使用 new 创建数组的实例。因此，要声明一维数组，你通常会使用以下通用形式：

```
type[] arrayName = new type[size];
```

这里，type 声明数组的元素类型。元素类型决定了构成数组的元素的 数据类型。请注意 type 后面的方括号。它们表示正在声明对一维数组的引用。数组将容纳的元素数量由 size 决定。

这里有一个示例。以下代码创建了一个包含十个元素的 int 数组，并将其连接到名为 test 的数组引用变量：

```
int[] test = new int[10];
```

示例变量保存了由 new 分配的内存的引用。该内存足够容纳十个 int 类型的元素。在这种情况下，test 第一次创建时，它不引用任何物理对象。只有在第二个语句执行后，test 才引用一个数组。数组内部的单个元素通过使用索引来访问。索引描述了数组内部元素的 位置。在 C# 中，所有数组的第一个元素的索引都是零。由于 test 有十个元素，因此它的索引值为 0 到 9。要索引数组，请指定你想要的元素编号，用方括号括起来。因此，test 中的第一个元素是 test[0]，最后一个元素是 test[9]。在第一个程序中，nums 数组是通过十条单独的赋值语句手工赋值的。虽然完全正确，但有更简单的方法。数组可以在创建时初始化。一维数组初始化的通用形式如下所示：

```

```
