### 使控件无效

当需要重绘控件时，可以调用 Invalidate 方法。Invalidate 会通过调用 OnPaint 方法使控件被绘制，而 OnPaint 方法又会引发 Paint 事件。HasOutline 属性中展示了使控件无效的做法。当 HasOutline 更改时，hasOutline 字段会更改，并且控件会在第 72 行失效，以便带轮廓重绘控件。

### 绘制和填充形状

Graphics 类定义了多种用于绘制和填充形状的方法。DrawEllipse 和 FillEllipse 方法用于创建自定义按钮。例如，FillEllipse 填充基本按钮，而当 HasOutline 为 True 时，DrawEllipse 绘制按钮的轮廓。

绘制方法使用 Pen 对象来绘制表示形状的线条。形状表示为受边界矩形约束的区域。FillEllipse 的工作方式与 DrawEllipse 几乎相同；不过，必须向 FillEllipse 传递 Brush 而不是 Pen，因为填充方法绘制的是区域的内部。

填充和绘制方法有两类。一类接受定义矩形区域的整数参数，另一类接受表示矩形区域的浮点数。形状绘制方法提供浮点版本的优势在于，你可以执行数学运算并得到浮点数，而不必将这些数字截断为整数。

调用哪个特定的绘制或填充方法取决于参数类型。多态在这里很有帮助。每个绘制和填充方法都有多个重载版本，编译器会根据参数类型决定调用哪个具体方法。

除了通过指定四个点来定义矩形区域外，还可以将矩形区域表示为一对 Point 结构或一个 Rectangle 结构。如果使用点或矩形，那么当基础值为整数时应使用 Point 或 Rectangle，当基础值为浮点值时应使用 PointF 和 RectangleF。在 RoundButton.cs 模块中可以找到若干展示 Point 和 Rectangle 结构用法的示例。

## 对图形对象应用变换

GDI+ 使用世界坐标、页面坐标和设备坐标。当你调用 Graphics 方法时，指定的位置位于世界坐标空间中。GDI+ 通过两次变换来转换世界坐标参数：从世界坐标转换为页面坐标，然后再转换为设备坐标。

GDI+ 在后台处理这些变换。对于我们软件工程师来说，优势在于可以更改原点、将 PageUnit 从默认像素更改为其他度量单位，并执行缩放图像等任务。
