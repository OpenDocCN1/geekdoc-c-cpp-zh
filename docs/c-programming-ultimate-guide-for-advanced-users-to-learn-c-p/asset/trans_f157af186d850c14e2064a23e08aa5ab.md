变量已在第1章中介绍过。正如你所了解的，变量使用以下声明形式来声明：

```text
type var-name;
```

其中，type 是变量的数据类型，var-name 是变量的名称。你可以声明任何有效类型的变量，包括刚刚描述的值类型。必须理解，变量的能力由其类型控制。例如，bool 类型的变量不能用来存储浮点值。此外，变量的类型在其生存期内不能改变。例如，int 变量不能转变成 char 变量。C# 中的所有变量都必须声明。这是根本性的，因为编译器在适当编译任何使用该变量的语句之前，必须知道该变量包含何种信息。这同样使 C# 能够执行严格的类型检查。C# 定义了几种不同类型的变量。我们一直使用的类型称为局部变量，因为它们是在方法内部声明的。注意：你不应把字符串和字符混为一谈。字符字面量表示 char 类型的单个字母。只包含一个字母的字符串仍然是字符串。尽管字符串由字符组成，但它们并不是同一种类型。

## 初始化变量

给变量赋值的一种方法是通过赋值语句，正如你已经看到的那样。另一种方法是在声明变量时给它一个初始值。为此，在变量名后面跟一个等号以及要赋的值。初始化的一般形式如下所示：

```text
type var-name = value;
```

这里，value 是在创建 var-name 时赋给 var-name 的值。该值必须与指定的类型兼容。尽管最初的示例只使用常量作为初始化器，但 C# 允许动态初始化变量，即使用在声明变量时有效的任何表达式。

如前所述，在 C# 中所有变量都必须声明。通常，声明包含变量的类型（例如 int 或 bool），后面跟变量名。不过，从 C# 3.0 开始，可以让编译器根据用于初始化变量的值来确定变量的类型。这称为隐式类型变量。隐式类型变量使用关键字 var 声明，并且必须进行初始化。

编译器使用初始化器的类型来确定变量的类型。这个赋值是无效的，因为 range 的类型是 int。因此，不能给它赋浮点值。隐式类型变量与“普通”显式类型变量之间的主要区别在于类型被确定的方式。一旦该类型被确定，变量就具有一个类型，并且这个类型在变量的整个生存期内都是固定的。因此，span 的类型在程序执行期间不能改变。

隐式类型变量被添加到 C# 中，是为了处理一些不常见的情况，其中最重要的与 LINQ（语言集成查询）有关，本书稍后将对此进行描述。对于大多数变量，你应该使用显式类型变量，因为它们使你的代码更易于阅读、更加清晰。隐式类型变量只应在必要时使用。它们并非旨在普遍替代普通变量声明。一般来说，要使用这个新的 C# 特性，但不要滥用它。最后一点：在任何时候都只能声明一个隐式类型变量。

## 变量作用域

到目前为止，我们使用的所有变量都是在 Main( ) 方法开头声明的。然而，C# 允许在任何块内声明局部变量。如第1节所述，块以左花括号开始，以右花括号结束。

块定义了一个作用域。因此，每当你开始另一个块时，你就在创建另一个作用域。作用域决定了哪些名称对程序的不同部分是可见的。它还决定了局部变量的生存期。C# 中最重要的作用域是由类定义的作用域和由方法定义的作用域。对类作用域（以及在其中声明的变量）的讨论将推迟到本书后面描述类时进行。目前，我们只分析由方法定义的作用域或方法内部的作用域。

由方法定义的作用域从其左花括号开始，到其右花括号结束。不过，如果该方法有参数，这些参数也包含在由该方法定义的作用域内。一般来说，在某个作用域内声明的局部变量对该作用域之外定义的代码不可见。因此，当你在一个作用域内声明变量时，你是在阻止该作用域之外的代码访问或修改它。的确，作用域规则为封装提供了基础。

作用域可以嵌套。例如，每当你创建一个代码块时，你就在创建另一个嵌套作用域。发生这种情况时，外层作用域包围内层作用域。这意味着在外层作用域中声明的局部变量将对内层作用域中的代码可见。然而，反过来则不成立。在内层作用域中声明的局部变量在其外部将不可见。

正如注释所示，变量 x 是在 Main( ) 作用域的开头声明的，并且对 Main( ) 内所有后续代码都是可访问的。在 if 块内部，声明了 y。由于块定义了一个作用域，y 仅对其块内的其他代码可见。这就是为什么在其块外部，语句 y = 100; 被注释掉了。如果你去掉前面的注释符号，就会发生编译时错误，因为 y 在其块外部不可见。在 if 块内部，可以使用 x，因为块内（即嵌套作用域内）的代码可以访问由外层作用域声明的变量。
