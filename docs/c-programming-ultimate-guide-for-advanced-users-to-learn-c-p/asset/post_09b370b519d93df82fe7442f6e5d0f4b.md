### Handling Syntax Errors

If you have not yet done so, enter, compile, and run the preceding program. As you may know from your past programming experience, it is very easy to inadvertently type something incorrectly when entering code into your computer. If this occurs, the compiler will report a syntax error when it attempts to compile it. The message displayed will contain the line number and character position at which the error is found and a description of the error. Although the syntax errors reported by the compiler are, of course, useful, they are also sometimes misleading. The C# compiler attempts to make sense out of your source code no matter what you have written. Therefore, the error that is reported may not always reflect the actual cause of the problem. You can repeatedly execute a sequence of code by creating a loop. C# supplies a powerful assortment of loop constructs. The one we will look at here is the for loop. If you are familiar with C, C++, or Java, you will be pleased to know that the for loop in C# works the same way it does in those languages. The simplest form of the for loop is shown here:

```
for(initialization; condition; iteration) statement;
```

In its most common form, the initialization part of the loop sets a loop control variable to an initial value. The condition is a Boolean expression that tests the loop control variable. If the result of that test is true, the for loop continues to iterate. If it is false, the loop ends. The iteration expression determines how the loop control variable is changed each time the loop iterates.

### Using Blocks of Code

Another key element of C# is the code block. A code block is a grouping of statements. A code block is created by enclosing the statements between opening and closing curly braces. Once a block of code has been created, it becomes a logical unit that can be used wherever a single statement can. For instance, a block can be the target of if and for statements. Consider this if statement:

```csharp
if(counter < max) {
    usercount = counter;
    delaytime = 0;
}
```

Here, if counter is less than max, the two statements inside the block will be executed. Thus, the two statements inside the block form a logical unit, and one statement cannot execute without the other also executing. The key point here is that whenever you need to logically link two or more statements, you do so by creating a block. Code blocks enable numerous algorithms to be executed with greater clarity and efficiency.

### Semicolon and Positioning

In C#, the semicolon marks the end of a statement. That is, every individual statement must end with a semicolon. As you are probably aware, a block is a set of logically associated statements that are enclosed by opening and closing braces. A block is not ended with a semicolon. Since a block is a grouping of statements, it makes sense that a block is not ended by a semicolon; rather, the end of the block is indicated by the closing brace.
