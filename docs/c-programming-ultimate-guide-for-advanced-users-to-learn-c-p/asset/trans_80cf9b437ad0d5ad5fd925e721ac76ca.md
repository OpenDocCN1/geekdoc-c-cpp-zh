### 语句

有两个地方会看到 using 关键字。using 语句用于导入命名空间，并作为释放对象的块声明。

清单 2-1 展示如何使用命名空间。可将 using 语句视为添加对 DLL 的引用。框架中的程序集实际上包含在 DLL 文件中；因此

```
using System.Reflection;
```

表示一个以 System 一词开头的 DLL。

程序集可以包含不同的命名空间。例如，System.Reflection 包含在 System.dll 程序集中。然而，System.Windows.Forms 实际上是包含 Windows Forms 控件的程序集的名称。你可以通过研究 using 的用法来检查 .NET Framework 中的程序集，using 的用法类似于 VB.NET 中的 with 语句。在代码中对对象使用 using 语句时，你描述的是一个作用域，该作用域会在 using 块即将完成时正确释放对象。只要 using 块中创建的对象实现 IDisposable 接口，无论 using 块完成前是否抛出异常，该对象都会被释放。IDisposable 是一个只有一个方法的接口。

### 实现 Broadcaster

Broadcaster 实现了 Singleton 设计模式。单例是一个需要保证只有一个实例的类。通常，此实例用于反映单一资源的存在，类似于单台打印机。单例类通过将构造函数设为受保护或私有，并仅通过静态成员提供访问来创建。Broadcaster 通过 internal、private 的 Instance 属性实现这一点。

Broadcaster 中的每个公共方法都是静态的。调用 Broadcaster（或任何单例）中的公共成员时，该方法会引用只读的 Instance 属性。Instance 验证 Broadcaster 的单个实例是否已创建。如果单例不存在，则创建一个实例并赋给私有字段 instance。然后返回该单例对象。结果是 Broadcaster 包含对自身实例的引用。
