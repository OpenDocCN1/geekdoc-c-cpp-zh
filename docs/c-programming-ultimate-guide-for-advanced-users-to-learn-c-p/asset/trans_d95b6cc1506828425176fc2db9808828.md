
仅包含实例变量和方法的类定义的一般形式如下所示：

```
class classname {
// Declare instance variables.
access type var1;
access type var2;
// ...
access type varN;
}
```

注意每个字段和方法前面都有 access。这里，access 是访问说明符，例如 public，它指示成员可以如何被访问。如第 1 节所述，类成员可以是类私有的，也可以更公开。访问说明符决定允许何种访问。访问说明符是可选的，如果缺失，成员就是类私有的。具有私有访问权限的成员只能被其所在类的其他成员使用。对于本节中的示例，所有成员（Main() 方法除外）都将声明为 public。这意味着它们可以被所有其他代码使用——甚至包括在类外部定义的代码。（Main() 方法将继续使用默认访问权限，因为这是当前推荐的做法。）在你学习了类的基础知识之后，我们将在后续章节回到访问说明符这个主题。尽管没有语法规则强制要求，但结构良好的类应该定义且仅定义一个逻辑实体。例如，存储姓名和电话号码的类通常不会同时存储有关股票市场、平均降水量、太阳黑子周期或其他无关数据的数据。这里的要点是，设计良好的类会将始终相关联的数据分组在一起。将无关数据放入同一个类会迅速破坏你的代码！

## 对象是如何创建的：

在之前的项目中，以下行用于创建 **Vehicle：** 类型的对象：

```
Vehicle minivan = new Vehicle();
```

这个声明执行三个功能。首先，它声明一个名为 minivan 的变量，其类类型为 Vehicle。这个变量本身不是对象。相反，它只是一个可以引用对象的变量。其次，该声明创建对象的一个真实的物理实例。这是通过使用 new 运算符完成的。最后，它将对该对象的引用赋给 minivan。因此，该行执行后，minivan 引用一个 Vehicle 类型的对象。new 运算符为对象动态分配（即在运行时分配）内存，并返回对该对象的引用。然后，这个引用被存储在一个变量中。因此，在 C# 中，所有类项都必须动态分配。
