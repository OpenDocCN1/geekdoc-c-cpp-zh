
在 C# 中，字面量是指以其可理解形式表示的固定值。例如，数字 100 就是一个字面量。一般而言，字面量及其用法非常直观，以至于所有最初的示例程序都以某种形式使用过它们。现在该正式阐明它们了。

C# 字面量可以是任何值类型。每个字面量的表示方式取决于其类型。如前所述，字符字面量括在单引号之间。例如，'a' 和 '%' 都是字符字面量。整数字面量表示为不带小数部分的数字。例如，10 和 -100 是整数字面量。浮点字面量需要使用小数点，后跟数字的小数部分。例如，11.123 是浮点字面量。C# 还允许对浮点数使用科学计数法。由于 C# 是强类型语言，字面量也有类型。自然，这引出了以下问题：数值字面量的类型是什么？例如，12、123987 或 0.23 的类型是什么？幸运的是，C# 定义了一些简单易循的规则来回答这些问题。首先，对于整数字面量，字面量的类型是能够容纳它的最小整数类型，从 int 开始。因此，整数字面量的类型为 int、uint、long 或 ulong，具体取决于其值。其次，浮点字面量的类型为 double。

如果 C# 的默认类型不是你想要的字面量类型，可以通过添加后缀来显式指定其类型。要指定 long 字面量，请添加 l 或 L。例如，12 是 int，但 12L 是 long。要表示无符号整数值，请附加 u 或 U。这样，100 是 int，但 100U 是 uint。要表示无符号长整数，请使用 ul 或 UL。例如，984375UL 的类型是 ulong。

要指定 float 字面量，请附加 F 或 f。例如，10.19F 的类型是 float。尽管是多余的，你也可以通过追加 D 或 d 来表示 double 字面量。（如前所述，浮点字面量默认是 double。）要指定 decimal 字面量，请在其值后加上 m 或 M。例如，9.95M 是 decimal 字面量。

尽管整数字面量默认创建 int、uint、long 或 ulong 值，但只要所赋的值能够由目标类型表示，它们仍然可以赋给 byte、sbyte、short 或 ushort 类型的变量。

### 十六进制字面量

在编程中，有时使用基于 16 而不是 10 的记数系统更简单。基数为 16 的记数系统称为十六进制，使用数字 0 到 9，加上字母 A 到 F，它们分别表示 10、11、12、13、14 和 15。例如，十六进制数 10 在十进制中是 16。由于十六进制数使用频繁，C# 允许你以十六进制形式指定整数字面量。十六进制字面量必须以 0x 开头（一个零后跟一个 x）。

### 字符转义序列

将字符常量括在单引号中适用于大多数可打印字符，但少数字符（如回车符）在使用文本编辑器时会带来特殊问题。此外，某些其他字符（如单引号和双引号）在 C# 中具有特殊含义，因此不能直接使用它们。因此，C# 提供了独特的转义序列。

注意 `\n` 转义序列如何用于产生新行。你不必使用多个 WriteLine( ) 语句来获得多行输出。只需在希望出现换行符的位置，将 `\n` 嵌入较长的字符串中即可。

除了刚才描述的字符串字面量类型外，还可以指定逐字字符串字面量。逐字字符串字面量以 @ 开头，后跟带引号的字符串。带引号字符串的内容会原样接受，不做修改，并且可以跨两行或多行。因此，你可以包含换行符、制表符等，但不必使用转义序列。唯一的例外是，要得到双引号（`"`），必须连续使用两个双引号（`""`）。下面是一个展示逐字字符串字面量的程序。关于前面这个程序，需要注意的重要一点是：逐字字符串字面量完全按照它们在程序中的输入形式显示。逐字字符串字面量的好处是，你可以在程序中精确指定输出，使其与屏幕上显示的内容完全一致。然而，对于多行字符串，换行会使程序中的间距变得不明显。因此，本书中的程序将使用逐字字符串字面量。综合考虑，对于某些格式设置场景，它们仍然具有很大优势。

变量已在第 1 章中介绍。如你所知，变量使用以下声明形式进行声明：

```
type var-name;
```

其中 type 是变量的数据类型，var-name 是其名称。可以声明任何有效类型的变量，包括刚才描述的值类型。必须理解，变量的能力由其类型控制。例如，bool 类型的变量不能用于存储浮点值。此外，变量的类型在其生存期内不能改变。例如，int 变量不能转变为 char 变量。C# 中的所有变量都必须声明。这是根本性的，因为编译器必须知道变量的类型是什么。因此，变量的类型在程序执行期间不能改变。

C# 中添加了隐式类型变量，以处理一些特殊情况，其中最重要的与 LINQ（Language-Integrated Query，语言集成查询）有关，本书后面将对此进行描述。对于大多数变量，应使用显式类型变量，因为它们使代码更易读、更清晰。隐式类型变量应仅在必要时使用。一般而言，它们并非旨在替代普通变量声明。通常，应使用但不要滥用这个新的 C# 特性。最后一点：在任何时候都只能声明一个隐式类型变量。

### 变量作用域
