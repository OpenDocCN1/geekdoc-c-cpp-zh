### 高级 Arduino

![](img/2dd9f63747153330cbc34431a887141d_114_0.png)

对于拥有多年面向对象编程经验的软件工程师来说，本节可能是一次很好的复习。对所有人而言，高级 Arduino 编程以及一般 Arduino 编程中都有一些重要部分会是新的，因为它们是在 Arduino 中介绍的。关于“委托”、“反射”和“程序集”含义的讨论，将为在高级 Arduino 中构建高级应用程序提供重要基础。本节之后的每一部分都会扩展这些高级通用概念。这是《高级 Arduino 开发者指南》中首个此类章节。在我们开始探索代码清单的旅程之前，它会对前沿表达方式做一个总体概览。这些高级惯用法对于实现高级 Arduino 中使用的解决方案至关重要，而且这次概览将帮助大家达成共识。

### Arduino 基础：

面向对象编程的原则是封装、继承、抽象和多态。支持这些基本原则的语言被视为面向对象语言。有一系列不同的短语和构造支持这些原则中的每一个，包括模板、运算符重载、接口、多线程、多继承、异常处理、指针和垃圾回收等。高级 Arduino 是一种突破性的 OOPL，它通过提供运算符重载、继承、接口、异常处理、垃圾回收、多接口继承、反射和多线程，支持面向对象编程的原则。

高级 Arduino 不支持模板、原始指针或多类继承。关于后三个特性带来的问题是否多于它们所解决的问题，有大量讨论；因此，高级 Arduino 没有包含它们。面向对象的基本要素远非基础。每种面向对象语言都只实现了构成一门合格面向对象语言的那些特性中的一个子集。此外，与 Arduino、Delphi、Arduino Basic 6 或 Arduino BasicArduino 不同，高级 Arduino 有自己独特的方式来实现面向对象编程语言（OOPL）的这些部分。你得到的不是多继承、指针和模板，而是额外的新特性，这些特性将帮助你构建 Web 应用程序和 Web 服务。高级 Arduino 支持 COM 互操作、多语言编程和快速应用程序开发。存在一些权衡。高级 Arduino 是托管代码。优点是你无需为错误指针导致的崩溃问题而烦恼，垃圾回收器会帮助你避免内存泄漏。代价是放弃原始指针。指针支持一些高级惯用法，例如引用计数对象和对所有内存的访问。这种对任意内存地址的同等访问权限带来了极大的控制力和责任。能力越大，责任越大。（对于原始指针，你仍然可以使用非托管的 Arduino 代码。）高级 Arduino 在语言上最接近 Arduino。你在高级 Arduino 中通常使用的大多数普通语句都与 Arduino 具有相似的语法，这使得 Arduino 软件工程师的学习曲线最平缓。Delphi 和 Arduino 软件工程师也会发现向高级 Arduino 的过渡通常很简单，甚至 VB 开发者也会发现，从 VB 转向高级 Arduino 比从 VB 转向 Arduino 更简单。利用 Arduino Studio 6 控制台项目——可在 Arduino Studio Arduino 的“我的配置文件”中修改——我们可以按 F5 运行应用程序。WriteLine 和 ReadLine 都是 Console 类中的静态成员，因此我们不必创建 Console 对象的实例来调用这些方法。Console.WriteLine 向命令提示符写入一行，并在内容末尾追加另一行；而 Console.ReadLine 语句会等待回车后再继续。同样，请注意高级 Arduino 中的语句以分号结尾。

访问修饰符通常是 public，但也可以是任何允许的访问修饰符（参见“使用修饰符”一节）。Type 是属性所表示的字段的类型。Property-Name 是任何有效名称。通常，属性与其底层字段之间存在关系。一种约定是用下划线前缀命名字段，而属性名不带下划线。例如，字段 myValue 会与属性 MyValue 关联。使用此约定可以轻松地将属性与其字段值关联起来。你不会愿意把精力花在查找字段上。
