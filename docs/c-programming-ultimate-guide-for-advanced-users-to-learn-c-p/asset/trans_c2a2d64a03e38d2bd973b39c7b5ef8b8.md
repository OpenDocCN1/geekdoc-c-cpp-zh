
## 类

当你描述继承关系时，至少需要两个类。一个类是父类，另一个是子类。（父类与子类之间的关联也称为超类和子类，其中超类与父类同义，子类与子类同义。）这种父子关系被称为 IsA 关系。例如，我是我父亲（和母亲）的后代，所以我是 Kimmel（和 Symons），获得了来自 Kimmels（和 Symons）的 DNA。

当你在 C# 中描述继承关系时，子类会获得父类中描述的所有成员。继承时，你会获得父类中描述的所有字段、属性和方法。与染色体继承不同，面向对象的继承意味着你获得了一切。

我认为你已经了解了继承，但由于继承是一个重要的概念，我还想展示一个额外的描述。如果类 B 继承自类 A，那么逻辑上，B 的实例就是类 A。

继承的记法与接口继承相同。要表示类 B 继承自类 A，你将类头写成如下形式：

```
public class B : A
```

与接口继承不同，当你从一个类继承时，你不需要实现父类中的任何方法，因为它们已经在父类中实现了。

## 继承术语

与继承关系相关的术语有很多。由于你在本书中会遇到它们，我将在此简要总结其中几个。

如果类 B 继承自 A，则 A 是父类，B 是子类。

如果类 B 继承自 A，则 A 也称为超类，B 称为子类。

以及总计。

## 多态性

多态性已被以各种方式描述。有时我看到过对其希腊词根的引用，译为“多种形式”，有时描述又长又复杂。我将尝试做一些略有不同的尝试。我将使用一个我希望你能理解的类比。

假设你有一个适合孩子做的家务。我有四个孩子。我们在他们十八个月大时就开始让他们做家务。的确，一岁半的幼儿就能倒垃圾桶。可能很冷血，但很实用。这就是关系。

你正在观看超级碗。比赛进入最后一节，剩下两分钟，你的球队有球但落后 8 分。他们不仅要完成达阵，你的球队还需要完成两次转换得分。为了增加紧张感，你已经和庄家赌了 500 美元押你的球队获胜。现在，你没啤酒了。你需要一瓶啤酒，但你不能离开比赛，因为当你回来时比赛就结束了。你需要一个孩子去取啤酒，任何孩子都可以。

这就是多态性。

当你有一个通用问题，可以由一组通用提供者中的任何提供者解决时，你就需要多态性。

如果啤酒和足球的类比对你来说没有意义，别担心；对我来说也没有意义。让我们尝试一种更技术性的方法（适用于看 TLC 而不是《周一夜赛》的人）。

请记住我曾说过继承也被称为泛化？也就是说，如果你将某物声明为通用（或父）类型并实例化——创建特定类型的实例——那么你对所创建的具体类型就有更多选择。EventHandler 委托展示了这一点的具体例子。EventHandler 委托被定义为接受一个 object 作为第一个参数。object 类是所有类型的基类。有效地，这意味着任何对象都可以传递以满足 EventHandler 委托的 sender 参数。这就是多态性：声明通用类型，实际使用特定类型。

## 利用修饰符

修饰符处理数据隐藏。数据隐藏体现了“眼不见，心不烦”这句话。也就是说，作为制作者，如果你能把某物隐藏起来不让使用者看到，那么他们就不需要担心它。因此，心中无念。

访问修饰符允许你在编程时将事物排除在意识之外。在创建类时，只将使用者需要交互以使用该类的事物设为 public。通过限制你在公共接口中公开的内容，你使使用你的类变得更容易。无论你是否是自己所生产类的主要使用者，这都成立。

有几个访问修饰符可供选择。C# 支持 public、protected、internal、protected internal、private 以及用于字段的 readonly。下面的项目符号列表简要描述了每个访问修饰符的目的。

- public 修饰符对类型和成员提供无限制的访问。
- protected 访问修饰符在类内部和对子类提供无限访问，对使用者提供有限访问。protected 访问修饰符可以应用于嵌套类型。
- private 访问修饰符提供最受限的访问。只有类的创建者可以使用其私有成员。使用者和子类无法访问私有成员。private 访问修饰符可以应用于嵌套类型。
- internal 访问修饰符意味着类型和成员仅在同一程序集中可用。internal 修饰符用于使代码能够在类边界内内部工作，而不会将这些组件暴露给程序集外部的使用者。
- protected internal 修饰符将嵌套类型的访问限制在同一程序集中。

声明顶级类型时，你应使用 public 或 internal 访问修饰符。你只能在类型为嵌套时使用 private 和 protected 访问。嵌套类型是指包含在另一个类型定义内的类型定义。

除 protected internal 修饰符外，你不能组合访问修饰符。你不能在命名空间上使用访问修饰符。如果未指定访问修饰符，则将使用默认访问级别。最好明确显示访问级别，而不是依赖默认访问。

### 利用类修饰符

当你定义类且封闭元素是命名空间时，类可以被定义为具有 public 或 internal 访问。如果未为顶级类指定修饰符，则该类将具有 public 访问。

嵌套类可以用任何访问修饰符定义，但你只能对嵌套类使用 protected、protected internal 和 private 访问修饰符。

类访问修饰符规则同样适用于任何 struct 和 enum 类型。

你也可以在类型的成员上使用任何访问修饰符。如果未为成员定义访问修饰符，则成员默认为 private。
