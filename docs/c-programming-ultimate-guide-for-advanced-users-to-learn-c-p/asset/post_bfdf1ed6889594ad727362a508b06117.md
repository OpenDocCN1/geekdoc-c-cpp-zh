Destructors have this general structure:

```
    ~class-name( ) {

    // destruction code

    }
```

Here, class-name is the name of the class. Thus, a destructor is declared like a constructor, however, it is preceded with a ~ (tilde). Notice it has no return type. Understand that the destructor is called only before garbage collection. It is not invoked when a variable containing a reference to an object leaves scope, for example. (This contrasts from destructors in C++, which are invoked when an object goes out of scope.) This implies you can't know accurately when a destructor will be executed. Moreover, it is possible for your program to end before garbage collection happens, so a destructor may not get called at all. Sometimes you will need to use a reference parameter to get a value from a method but not pass in a value. For instance, you may have a method that performs some function, such as opening a network socket, that returns a success/failure code in a reference parameter. In this case, there is no data to go into the method, however there is data to take out.

The issue with this situation is that a ref parameter must be initialized to a value before the call. Thus, to use a ref parameter would require giving the argument a dummy value just to fulfill this limitation. Luckily, C# provides a better alternative: the out parameter. An out parameter is like a ref parameter with this one exception: It must be used to pass a value out of a method. It is not necessary (or useful) to give the variable used as an out parameter an initial value prior to calling the method. The method will give the variable this value. Furthermore, inside the method, an out parameter is always considered unassigned; that is, it is assumed to have no initial value. Rather, the method must assign the parameter a value before the method's end. Thus, after the call to the method, the variable referred to by an out parameter will contain a value. In the parameter isSquare, it returns true if the rectangle is a square and false otherwise. Thus, RectInfo() returns two pieces of information to the caller. When you create a method, you usually know in advance the number of arguments that you will pass it, but this is not always the case. Sometimes you will need to create a method that can be passed an arbitrary number of arguments. For instance, consider a method that finds the smallest of a set of values. Such a method may be passed as few as two values, or three, or four, etc. In all cases, you need that method to return the smallest value. Such a method cannot be made using ordinary parameters. Rather, you should use a special kind of parameter that represents an arbitrary number of parameters. This is done by creating a params parameter.

The params modifier is used to declare an array parameter that will be able to receive at least zero arguments. The number of elements in the array will be equal to the number of arguments passed to the method. Your program then accesses the array to obtain the arguments. ## CHAPTER 5: Operators AND DataTypes

An array is a collection of variables of the same type that are referred to by a common name. In C#, arrays can have one or more dimensions, although the one-dimensional array is the most common. Arrays are used for a variety of purposes because they offer a convenient means for grouping related variables. For example, you may use an array to hold a record of the daily high temperature for a month, a list of users signed onto a system, or your collection of programming books.

The main advantage of an array is that it organizes data so that it can be easily manipulated. For example, if you have an array containing the incomes for a selected group of households, it is not difficult to calculate the average income by going through the array. Likewise, arrays organize data so that it can be easily sorted. Although arrays in C# can be used just like arrays in many other programming languages, they have one special quality: They are implemented as objects. This fact is one reason that a discussion of arrays was deferred until objects had been introduced. By implementing arrays as objects, several important advantages are gained, not the least of which is that unused arrays can be garbage collected. A one-dimensional array is a list of related variables. Such lists are basic in programming. For example, you may use a one-dimensional array to store the record numbers of the active users on a system. Another array may be used to store the current batting averages for a baseball team.

Since arrays in C# are implemented as objects, two steps are required to obtain one for use in your program. First, you should declare a variable that can refer to an array. Second, you should create an instance of the array by use of new. Consequently, to declare a one-dimensional array, you will normally use this general form:

```
type[] arrayName = new type[size];
```

Here, type declares the element type of the array. The element type determines the data type of the elements that comprise the array. Notice the square brackets that follow type. They indicate that a reference to a one-dimensional array is being declared. The number of elements that the array will hold is determined by size.

Here is an example. The following creates an int array of ten elements and connects it to an array reference variable named test:

```
int[] test = new int[10];
```

The example variable holds a reference to the memory allocated by new. This memory is large enough to hold ten elements of type int. In this case, when test is first created, it refers to no physical object. It is only after the second statement executes that test refers to an array. An individual element inside an array is accessed by use of an index. An index describes the position of an element inside an array. In C#, all arrays have zero as the index of their first element. Since test has ten elements, it has index values of 0 through 9. To index an array, specify the number of the element you want, enclosed by square brackets. Thus, the first element in test is test[0], and the last element is test[9]. In the first program, the nums array was given values by hand, using ten separate assignment statements.
