
Hexadecimal numbers can also be started with the dollar sign ($) instead of 0x.

```
ldi r16, $2A
```

A binary number 0b0101010.

```
ldi r16, 0b00101010
```

The same binary number with an underscore in the number makes it easier to read and is accepted by the AVR assembler program.

```
ldi r16, 0b0010_1010
```

## 4.6 Numbers in C Programs

Those readers who are C programmers will know that decimal numbers are written just as numbers without any prefix, for example 16 is decimal 16 in a C program. Hexadecimal numbers in C start with the 0x prefix, for example 0x2A.

In standard C, there is no way to directly write a binary number, at least not in the C99 or earlier standards. Hexadecimal numbers are used instead. The GNU C programming tools used with Microchip Studio have an extension that is non-standard that allows binary numbers to be written in C programs. Binary numbers are started with the 0b prefix, the same as for assembly language discussed in the previous section, but does not support the underscore version of a binary number. For example, using the binary number 0b00010000 in a GCC C AVR project started in Microchip Studio will compile and build properly.

The following code snippet shows part of a C program with decimal, hexadecimal and binary numbers.

```
DDRB |= 16;    // DDB4 as decimal
while (1) {
    PORTB |= 0b00010000;    // PB4 as binary (non-standard)
    _delay_ms(1000);
    PORTB &= ~0x10;    // PB4 as hexadecimal
    _delay_ms(1000);
}
```

## 4.6 Summary

- A single memory cell can hold a single binary digit or bit that can have a value of 0 or 1.
- Memory in a microcontroller is usually arranged as groups of 8 memory cells which can hold 8 bits or one byte.
- Each byte of memory has an address that allows it to be accessed by the microcontroller.
- Half a byte or 4 bits is known as a nibble.
- With a single binary digit, we can count from 0 to 1. To count higher we use additional digits. The value of a binary number can be calculated by looking at the weight of each digit.
- Hexadecimal is a compact way of representing binary numbers with one hexadecimal digit representing 4 bits or a nibble.
- A calculator with number system conversion functionality such as the Windows calculator can be used to convert between different number systems such as decimal, binary and hexadecimal.
- The maximum size of a binary number can be calculated mathematically and the maximum size depends on how many digits the number consists of.
- 1K byte of memory is the same as 1024 bytes and not 1000 bytes.
- Numbers in AVR assembly language programs can be written in decimal, hexadecimal or binary format.
- Numbers in C language programs can be written in decimal or hexadecimal, but the GCC compiler allows numbers written in binary format.
- The octal number system consists of 8 digits, but is seldom if ever used.

### 5.1 AVR Registers

Registers in 8-bit AVR microcontrollers are 8-bit wide storage locations used for the temporary storage of data, or used to control peripheral devices in the case of control registers.

### 5.1.1 General Purpose Working Registers

Registers can be used to store data that is used in mathematical or logical operations, and to store the results of these operations. 8-bit AVR microcontrollers have 32 8-bit wide general purpose working registers grouped together in a general purpose register file as shown in Figure 5.1. An exception to this is the ATtiny4/5/9/10 range that have only 16 general purpose registers – R16 to R31.

### 5.1.2 I/O Registers

In addition to the general purpose working registers, ATtiny AVR microcontrollers have a set of 64 8-bit wide I/O registers which can be found in the datasheet under the Register Summary section. This set of registers includes control registers for controlling the on-chip peripherals such as timers, ADC, SPI, etc. as well as registers such as the status register and stack pointer which are discussed in the next chapter. Some of the bigger ATtiny devices and ATmega devices have an extended I/O register file, but in the interests of keeping things simple at the start, we will not look at this yet.
