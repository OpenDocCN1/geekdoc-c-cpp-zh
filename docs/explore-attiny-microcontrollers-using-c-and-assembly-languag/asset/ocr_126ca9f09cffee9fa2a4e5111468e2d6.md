When entering this calculation, we are using exponential notation where the key presses 1, exp, 6 (one exponent six) is a way of writing one million which is 1 followed by 6 zeros. The result of the calculation is 0.000001 which is easier to read after pressing the F-E button which changes the number to 1.e-6 or one exponent minus six. Minus six lets us know that this is microseconds. Click the F-E button again to change back to normal notation.

# 6.1.2.6 Calculating Clock Frequency from Period

To convert from period to frequency, use the formula:

f = 1/t Where t is the time period and f is the frequency.

To find the frequency of a clock source with a 1µs period on the Windows 10 calculator in scientific mode, enter 1, +, 1, exp, 6, ±, then click = followed by the F-E key. The key presses 1, exp, 6, ± is the same as one exponent minus six which is 0.000001 where –6 represents size in decimal places to the right of the decimal point. The ± key simply changes the sign of 6 from + (positive) to – (negative). The result of the calculation is 1.e+6 which is 1,000,000 or one million (1MHz). Pressing the F-E key converts the number to exponential notation which is easier to read as we can see that it is one with six zeros and know that it is therefore 1MHz or one megahertz.

To summarize, on the calculator, 1.e+6 is 1 exponent 6, or 1 x 10^6 or 1,000,000. Ten to the power of 6, or 1 followed by six zeros is mega, or megahertz if we are dealing with frequency. 1.e-6 is 1 Exponent -6, or 1 x 10^-6, or 0.000,001 and is micro, or microseconds when dealing with period.

# 6.1.3 The Program Counter

A program counter (PC) is a register in a microcontroller that contains the address of an instruction to execute. When an AVR microcontroller is powered on or reset, the program counter is reset to zero so that it addresses the first instruction in Flash memory at address 0x0000. This allows microcontroller to fetch the instruction at address 0, and execute it. The program counter is then incremented by one so that it points to the next instruction in Flash program memory at address 0x0001. The microcontroller then fetches the instruction at 0x0011 and executes it. Again the program counter is incremented so that it points to the instruction at 0x0002, which is fetched and executed.
