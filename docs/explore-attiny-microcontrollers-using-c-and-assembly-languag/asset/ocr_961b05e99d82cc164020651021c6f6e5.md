```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

The above line of code shows how avrdude would be called from the command line to load a program from a file to the Flash memory of an AVR microcontroller. Although we won't be calling avrdude directly from the command line, avrdude is a command-line program, and we need to understand how to use it when setting it up in Microchip Studio.

The first item in the above line is avrdude, which invokes the avrdude executable program – in other words it calls or runs the avrdude program that we downloaded, named avrdude.exe. Items following the call to avrdude are command-line options that are passed to avrdude from the command line, simply by typing them in after avrdude.

The first option is the -p switch, specifying which part is to be programmed, followed by the code for the specific part. In this example, -p is followed by t85, which is the code for the ATtiny85 part. Part codes for PDIP packaged ATtiny microcontrollers from Table 1.1 in section 1.3 of Chapter 1 are shown in Table A.1. Table A.1 only includes a small number of AVR parts that avrdude can program. The many other supported parts can be found in the avrdude PDF document.
