# 11.3.3.5 AVR+ CPU

Besides the few ATmega microcontrollers that use the AVRxt core, all other ATmega devices use the AVRe+ core. ATmega microcontrollers found on boards that are probably familiar to many readers, such as the Arduino Uno and Arduino MEGA 2560, use the AVRe+ CPU. This is the ATmega328 found on Arduino Uno boards and the ATmega2560 found on Arduino MEGA 2560 boards. AVRe+ CPU cores implement the following instructions that are not found on the AVR CPU core version: EICALL, EIJMP, ELPM, FMUL, FMULS, FMULSU, MUL, MULS and MULSU.

The AVR+ and AVRxt instruction sets are identical, except that the AVRxt instruction set includes the SPM Z+ instruction.

# 11.3.3.6 AVRxm CPU

The AVRxm CPU version is used exclusively in ATxmega (XMEGA devices) and the AVR DA range of microcontrollers. Although the AVRxm CPU specification includes all available AVR instructions, not every instruction is implemented in every part that has the AVRxm CPU.
