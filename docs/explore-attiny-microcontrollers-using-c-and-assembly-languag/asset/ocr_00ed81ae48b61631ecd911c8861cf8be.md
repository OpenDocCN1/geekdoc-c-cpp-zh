Although pins default to being inputs, this instruction shows that we explicitly want to use this pin as an input, we could however leave this instruction out and the code would still work. Because PB3 is set up as an input pin, setting bit PORTB3 in the PORTB register using the SBI instruction enables the internal pull-up resistor on pin PB3. Refer back to Figure 8.4 in section 8.2.1.8 of this chapter to see the registers and bits that control the I/O port, or refer to the AVR datasheet for the ATtiny part being used.

In the main loop of the program, two instructions are used to test the state of the switch on pin PB3, namely SBIC and SBIS. Both of these instructions test the logic state of bit PINB3 in the PINB register as can be seen in the code. Bit PINB3 contains the logic state of pin PB3 because PB3 was set up as an input pin. The flowchart of Figure 8.7 shows what the code does. An explanation of the use of SBIC and SBIS follows.

SBIC (Skip if Bit in I/O Register is Cleared) skips over the next instruction if pin PB3, that the switch is connected to, is at logic level 0 (the switch is closed). When the switch is open, PB3 is at logic level 1 because of the internal pull-up resistor that is enabled. In this case, the next instruction is a CBI instruction, which switches the LED off, and is therefore not skipped. This means that when the switch is open, the CBI instruction that follows SBIC is executed and the LED is switched off.

SBIS (Skip if Bit in I/O Register is Set) skips the next instruction if PB3 has a logic 1 level applied to it (the switch is open). When the switch is open, a logic 1 is applied to PB3 because of the pull-up resistor, causing the next instruction to be skipped. If the switch is closed, a logic 0 level is applied to PB3, and now the SBIS instruction does not skip the next instruction. The next instruction (SBI) switches the LED on.

Leaving the SBIC instruction out of the program won't seem to make a difference when running the program on physical hardware at full speed. The LED will always be switched off at the top of the loop, whether the switch is open or closed. When the switch is open, the LED will never be switched on. When the switch is closed, the LED will be switched off at the top of the loop and be switched on at the bottom of the loop. Because the LED is switched off for such a short time when the switch is closed, and then switched on, it appears to be solidly on to the eye.
