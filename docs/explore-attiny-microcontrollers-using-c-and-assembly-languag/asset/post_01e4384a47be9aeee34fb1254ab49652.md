
## 7.4.3 Logical Exclusive OR

Figure 7.3 shows the truth table for the exclusive OR (EOR) logical operation and an example of its use on two 8-bit registers. As with the AND and OR logical operations, the EOR performs a bitwise logical operation of each bit in the number in a register with the corresponding bit of a number in a second register. Exclusive ORing two input bits that have the same value always results in 0 as can be seen in the truth table. Exclusive ORing two bits of different values results in 1.

![](img/83ef13a6c66cc7882b2f357e97f451dc_146_0.png)

The AVR instruction set contains one exclusive OR instruction, EOR (Logical Exclusive OR), that exclusive ORs the values in two registers with each other. The following code demonstrates the use of the EOR instruction.

```
test_asm : main.asm – EOR example

ldi    r16, 0b1100_0101
ldi    r17, 0b1100_0111
eor    r16, r17

ldi    r18, 0b0000_0001
ldi    r19, 0b0000_0001
loop:
eor    r18, r19     ; Toggle bit in R18
rjmp   loop
```

In the above code, the first three instructions implement the example bitwise EOR operation of Figure 7.3. Step over the code and check the result against what is expected from the EOR truth table. As can be seen, the value in R16 is EORed with the value in R17, and the result saved back into R16.

Exclusive OR is often used to toggle a bit. Toggling a bit means changing its state. If a bit has a value of 0 and it is toggled, it will then have a value of 1. If a bit has a value of 1 and it is toggled, it will then have a value of 0. In the second part of the above code, R18 and R19 are both loaded with 0b0000_0001 – in other words the least significant bit of each register is set. An EOR operation is then done on the two registers inside a loop. Each time the EOR instruction is stepped over in the debugger, the LSB of R18 is toggled from 1 to 0, or 0 to 1 continually. Step through the code and verify that the LSB of R18 is toggling.

## 7.6 Summary

- Signed numbers in AVR microcontrollers are stored in 2's complement format.
- AVR microcontrollers have addition and subtraction arithmetic instructions.
- Flags in the Status Register are set or cleared depending on the result of an arithmetic or logic operation.
- If the result of an arithmetic operation is too big to store in an 8-bit register then the carry flag is set in the status register.
- Logic instructions perform logical operations on registers and immediate data according to their respective truth tables.
- AVR microcontrollers have AND, OR and EOR logic instructions.
- The instruction set summary section of the datasheet of an AVR microcontroller lists all of the instructions that are implemented in a particular AVR part.
- A detailed description of arithmetic, logic and other AVR instructions can be found in the AVR Instruction Set Manual.

On-chip peripherals, such as I/O ports and timers, on AVR microcontrollers are controlled through the I/O registers that are grouped together as 64 8-bit registers which can be found in the Register Summary section of the datasheet. A detailed description of these registers is found in the relevant sections of the datasheet, such as the I/O Ports section for controlling pins on an AVR, and 8-bit Timer/Counter0 with PWM section for details on controlling the timer/counter and its PWM features.

This chapter covers I/O ports as an introduction to accessing AVR peripherals on the ATtiny13(A) and ATtiny25/45/85 range of AVRs. Other peripherals are covered in later chapters of this book, and also where they are used in code or projects.

## 8.1 Instructions for Accessing I/O Registers

Several instructions from the AVR instruction set can be used to access (read and write) the 64 I/O registers. Instructions such as IN and OUT can be used to read and write between registers R0 to R31 and any of the 64 I/O registers. Because the I/O registers are mapped into data space, they can also be accessed by instructions such as LDS (Load Direct from Data Space) and STS (Store Direct to Data Space). Instructions for setting and clearing bits, and for testing the state of bits are also available.

### 8.1.1 Reading and Writing I/O Registers with IN and OUT

The IN instruction is used to read a value from an I/O register and the OUT instruction is used to write a value to an I/O register.

### 8.1.1.1 The IN Instruction

The IN (Load An I/O Location to Register) instruction is used to read an I/O register and place its contents into register R0 to R31. For example, to read the PINB I/O register into R16, the following code can be used.

```
in r16, 0x16
```

Refer to the Register Summary section of the ATtiny13(A) or ATtiny25/45/85 data sheet to find the PINB register and its address at 0x16. Fortunately Microchip Studio assembly language projects automatically include a file that has definitions for the I/O registers. This means that the registers can be accessed by using their names rather than their addresses in assembly language programs. The above line of code can be written as follows using the register name instead of its address.

```
in r16, PINB
```

To access the file that contains register definitions, open a project in Microchip Studio, such as the test_asm project that we have been using to test code snippets. In Microchip Studio, expand Dependencies in the Solution Explorer pane at the top right of Microchip Studio by clicking the small triangle at the left of it. The triangle will only be visible if the project has been successfully built. Double-click the file under Dependencies that ends with a .inc extension. For example, if an ATtiny45 is selected in a project, the name of the file is tn45def.inc as shown in Figure 8.1. After opening the definition file, scroll through it to see all of the registers and other definitions. Some of the register definitions can be seen in Figure 8.1, including the definition for the PINB register at address 0x16.

![](img/83ef13a6c66cc7882b2f357e97f451dc_150_0.png)

Figure 8.1: Opening a Definition File in a Microchip Studio Project

### 8.1.1.2 The OUT Instruction

OUT (Store Register to I/O Location) writes data to an I/O register from register R0 to R31. To write a value to an I/O location using the OUT instruction, a value must first be loaded to a working register (R0 to R31) and then the register written to the I/O register using OUT. To load a constant value to an I/O register, the value first needs to be loaded to a register using the LDI instruction. Remember that the LDI instruction only operates on registers R16 to R31. The following code shows how to write a constant value to an I/O register using OUT.

```
ldi r16, 0x1A
out DDRB, r16
```

In the above code, the constant value 0x1A is loaded to R16. The contents of R16, which is now 0x1A, is written to the DDRB register using the OUT instruction. As can be seen in Figure 8.1, DDRB is defined as 0x17. Once again, using the name DDRB makes the code easier to read, rather than directly using the address of DDRB which is 0x17.
