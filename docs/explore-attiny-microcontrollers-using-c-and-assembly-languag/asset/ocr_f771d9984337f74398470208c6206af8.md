# Set or Clear Sign Flag – SREG S Bit

# SES (Set Sign Flag)

Sets the S flag in the status register. Equivalent to BSET SREG_S.

# CLS (Clear Sign Flag)

Clears the S flag in the status register. Equivalent to BCLR SREG_S.

# Set or Clear Two's Compliment Overflow Flag – SREG V Bit

# SEV (Set Overflow Flag)

Sets the V flag in the status register. Equivalent to BSET SREG_V.

# CLV (Clear Overflow Flag)

Clears the V flag in the status register. Equivalent to BCLR SREG_V.

# Set or Clear T Bit in SREG – SREG T Bit

# SET (Set T Bit)

# CLT (Clear T Bit)

Clears the T flag in the status register. Equivalent to BCLR SREG_T.

# Set and Clear Half Carry Flag – SREG H bit

# CLH (Clear Half Carry Flag)

Clears the H flag in the status register. Equivalent to BCLR SREG_H.

# 11.2.4 Data Transfer Instructions

# 11.2.4.1 Move/Copy Instructions

# MOV (Copy Register)

MOV has the form MOV Rd, Rr where Rd is the destination register that the contents of the source register Rr are copied to. Rd and Rr can be any of the registers from R0 to R31. MOV was first used in the wait_1s_asm project from section 10.2.2 in Chapter 10 to copy a register so that its contents would not be overwritten.
