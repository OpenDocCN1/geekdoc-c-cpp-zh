As can be seen in the previous code, the loop still executes in 7 clock cycles with the switch closed, so the timing of the loop remains the same. The only changes that occur is that the SBIC instruction at the top of the loop now skips over the CBI instruction that follows it, and the SBIS instruction does not skip the SBIS instruction that follows it. Remember that this code sets up an internal pull-up resistor on pin PB3. When the switch attached to PB3 is open, a logic level 1 is read. When the switch is closed, a logic level 0 is read on pin PB3.

The total number of clock cycles that the code takes to execute from top to bottom is therefore 6 cycles above the loop, plus 7 cycles in the loop which totals 13 cycles. This takes 13µs to execute from the top of the code to the bottom of the loop on an ATtiny25/45/85, and 10.833µs on an ATtiny13(A), using the default clock frequencies.

If an SBIC or SBIS instruction is followed by a two word or 32-bit wide instruction, then it takes 3 clock cycles to execute if the condition that is tested is true, in other words if it skips the instruction that follows it. For example, if the switch on PB3 is open and the SBIS instruction testing it is followed by an LDS instruction, we get the following.

```
sbic PINB, PINB3 ; 3 clock cycles, if skip over next instruction
lds r1, 0x60 ; 32-bit instruction
```

In the above code if the switch is open, a logic 1 is read in PINB3, in other words PINB3 is set, SBIS therefore skips the LDS instruction. In this case SBIS takes 3 clock cycles to execute.

If the switch is closed, the SBIS instruction does not skip the next instruction and takes only one clock cycle, as we saw in the read_switch_asm examples.

```
sbis PINB, PINB3 ; 1 clock cycle, next instruction is executed
lds r1, 0x60 ; 32-bit instruction
```
