Finally the RJMP (Relative Jump) instruction appears at the end of the example code and can be found at the bottom of Figure 6.15. An RJMP instruction always starts with the binary digits 1100, followed by a 12-bit address. The address encoded in the RJMP instruction is an address that is relative to the current address in the program counter (PC). The jump can occur to a higher address if the address is positive or to a lower address if the address is negative. In the instruction set manual, the range of the relative jump instruction is given as PC – 2K + 1 to PC + 2K (words). This means that a jump can occur to a lower address, at the current PC address minus 2048 + 1, or to a higher address up to PC + 2048 where each address is the address of a 16-bit wide instruction.

In the example program the RJMP instruction is used to jump to the top of the program which means that the jump is jumping to a lower address. The address that is encoded in the instruction in Figure 6.15 is a negative number in two's complement format – Ob111111111100 which has a decimal value of –4. In the code we can see that the RJMP instruction jumps to the first instruction of the program at address 0, where the loop label is. This address is obtained from the formula PC – address + 1, where address is the address encoded in the RJMP instruction. There are four 16-bit instructions in the program starting at address 0 with the RJMP instruction at address 3. The PC will therefore contain 3 when the RJMP instruction is executed. We can calculate the address that will be jumped to as follows: 3 – 4 + 1 which is 0, so the program will jump to address 0 as expected. This just shows how the RJMP instruction is encoded. Fortunately we don’t need to do a calculation like this while programming because we can use labels as destinations to jump to, and let the assembler program calculate the relative address.

# 6.9 Addressing Modes

Addressing modes are part of any microcontroller or microprocessor instruction set architecture. Addressing modes specify the different ways that instructions access source and destination data, which is how the instructions address memory locations and registers or constant data values. In AVR microcontrollers, the addressing modes allow instructions to access program memory and data memory. Data memory includes SRAM and the registers that are mapped to data memory space, which includes the register file and I/O registers. AVR addressing modes can be found in section or Chapter 3 of the AVR instruction set manual.
