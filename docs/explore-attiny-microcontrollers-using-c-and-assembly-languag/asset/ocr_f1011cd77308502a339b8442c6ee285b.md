It was found that after installing the driver, the USBasp appears under Atmel USB Devices or under Microchip Tools in the Device Manager dialog box on computers that already had Microchip Studio installed. On computers that did not have Microchip Studio installed, the USBasp appeared under libusb-win32 devices in the Device Manager dialog box. Note that the USBasp must be plugged into a USB port for it to be seen in the Device Manager dialog box. As soon as it is unplugged, it will disappear from Device Manager. Unplug the USBasp from the USB port before connecting it to a circuit.

At this stage, if the USBasp can be found in Device Manger without any warning icons, the driver is successfully installed, and the USBasp is ready to use. Go to section A.3.2 to download and install the avrdude programming software.
