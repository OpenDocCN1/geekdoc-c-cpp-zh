```
#include <util/delay.h>

int main(void)
{
    DDRB = (1 << DDB4); // Set up pin PB4 as an output

    while (1) {
    PORTB |= (1 << PORTB4); // Set pin high (LED on)
    _delay_ms(1000); // 1 second delay
    PORTB &= ~(1 << PORTB4); // Set pin low (LED off)
    _delay_ms(1000); // 1 second delay
    }
}
```

As can be seen in the code listing, there are two definitions for F_CPU at the top of the file. F_CPU is used to tell the code what the initial clock speed of the microcontroller is set to. This is used by the _delay_ms() function to accurately set the time delay that it produces. The reason that there are two functions for F_CPU is because ATtiny13 devices have a different default clock frequency to ATtiny25/45/85 microcontrollers. The first definition is commented out using two forward slashes (//) which means that the second definition takes effect and is set up for ATtiny13 devices. If using one of the ATtiny25/45/85 devices, uncomment the top definition and comment out the second definition as shown in the following code snippet.

```
#define F_CPU 1000000UL // 1MHz default clock for ATtiny25/45/85
//#define F_CPU 1200000UL // 1.2MHz default clock for ATtiny13(A)
```

These two default clock frequencies are close enough so that the program will still work on any of the devices if the changes described above are not made, but to create more accurate timing, the changes can be made.
