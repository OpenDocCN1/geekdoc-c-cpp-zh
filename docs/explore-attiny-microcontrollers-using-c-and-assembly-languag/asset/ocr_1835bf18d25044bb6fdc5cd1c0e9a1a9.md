# ## 11.3.2 Other AVR Instructions

Of the 142 possible AVR instructions, the ATtiny microcontrollers covered in this book implement up to 123 instructions. This leaves 19 instructions that are not implemented. These remaining instructions are summarized in the following subsections.

# ## 11.3.2.1 Arithmetic and Logic Instructions

The full AVR instruction set implements an additional six multiply instructions and a data encryption instruction, listed below.

+   - MUL (Multiply Unsigned) : 8-bit by 8-bit unsigned multiply with a 16-bit result.
+   - MULS (Multiply Signed) : 8-bit by 8-bit signed multiply with a 16-bit result.
+   - MULSU (Multiply Signed with Unsigned) : multiply of 8-bit signed and unsigned numbers.
+   - FMUL (Fractional Multiply Unsigned) : same as MUL, but left shits result by one bit.
+   - FMULS (Fractional Multiply Signed) : same as MULS, but left shits result by one bit.
+   - FMULSU (Fractional Multiply Signed with Unsigned) : MULSU with left shift by one bit.
+   - DES (Data Encryption Standard) : implements data encryption DES algorithm.

Of the above instructions DES is only implemented in the AVRxm version of the AVR CPU. The six multiply instructions are implemented in the AVRe+, AVRxm and AVRxt CPU versions. Remember that the ATtiny microcontrollers used in this book have the AVRe CPU.

# ## 11.3.2.2 Branch Instructions

Two additional jump instructions and two additional subroutine call instructions are available in the full AVR instructions set.

+   - JUMP (Jump) : Jumps to an address between 0 and 4M words (22-bit address).
+   - EIJUMP (Extended Indirect Jump) : Indirect jump to an address between 0 and 4M words (22-bit address). Uses Z register and EIND register in I/O space as an address pointer.

ATtiny microcontrollers used in this book only implement the relative jump instruction RJMP and indirect jump instruction IJMP because of their small memory sizes. JMP and EIJMP are implemented on AVR microcontrollers that have bigger memories.

CALL (Long Call to a Subroutine) : Calls a subroutine within the entire program memory. The size of the return address pushed on the stack and the number of clock cycles used to execute this instruction depends on the size of the memory implemented on the AVR and therefore the size of its program counter or PC.
