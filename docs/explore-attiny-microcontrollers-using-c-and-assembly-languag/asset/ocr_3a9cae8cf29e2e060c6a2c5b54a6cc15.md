# Jumper Links and Wires

Jumper wires are needed to connect from a USB programmer/debugger to the AVR microcontroller in a breadboard circuit, as can be seen in Figure 0.5 that follows. Jumper wires with single pin male connectors on each end are an excellent choice for this purpose. These wires are usually sold as a ribbon cable of wires that can individually be peeled off. They are typically called “Dupon” cables, for example “10cm male to male Dupon jumper cable”.

Other single core jumper wires are useful for building circuits on a breadboard. DuPont cables with one male and one female connector can be used to connect from some hobby programmers to a breadboard circuit.
