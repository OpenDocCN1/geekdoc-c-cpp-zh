An initial circuit is used to blink a single LED on and off, and is shown in Figure 2.1. If you have a Microchip Studio compatible programmer, such as the Atmel-ICE, AVR Dragon, or AVRISP mkII, build this circuit on a breadboard and connect the programmer as shown in Figure 2.1, Figure 2.2 and Figure 2.3. Read the end of section 2.2.2 for details on connecting the programmer and then come back and build the circuit. Appendix B has alternate circuits that use 14-pin, 20-pin, and 28-pin ATtiny devices. Build a circuit from this appendix if you are using an alternate ATtiny.
