# 5.3.1 Program Memory

Program memory holds the machine code instructions of any program that is loaded to the AVR. Program memory consists of Flash memory that is in-system re-programmable, which allows it to be programmed using USB and other programming devices that connect to the microcontroller via the ISP header while the microcontroller is in a circuit. Unlike most earlier 8-bit microcontrollers, 8-bit AVRs don't have 8-bit wide program memory, but 16-bit wide memory instead.
