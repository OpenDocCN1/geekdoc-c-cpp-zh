# Chapter 3 • Basics of Assembly Language

A microcontroller can only execute or run machine language instructions in binary format. Assembly language consists of human readable mnemonics which are converted into binary machine language by a program called an assembler.

This chapter takes a look at what assembly language consists of, the set of assembly language instructions for AVR microcontrollers, and how the LED blink assembly language program works.

The chapter finishes off with a look at basic use of the debugger and simulator found in Microchip Studio.

# In this Chapter

+   - Basic AVR assembly language terms and concepts
+   - An introduction to the AVR instruction set
+   - Assembly language comments
+   - Operation of the LED blink assembly language program
+   - Using the debugger and simulator found in Microchip Studio
