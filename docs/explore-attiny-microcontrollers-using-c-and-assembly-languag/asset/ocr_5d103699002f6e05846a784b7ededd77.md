# 3.1 Mnemonics

The word "mnemonic" (pronounced with the first 'm' silent) means a device or technique used to assist remembering something. A simple example of a mnemonic is "Never Eat Silk Worms" used to remember the points of a compass in a clockwise direction starting with north at the top as follows: North East South West or NESW.

Assembly language instructions consist of mnemonics that are meant to be easy to remember acronyms or abbreviations, for example the mnemonic SBI stands for "Set Bit in I/O Register". Another example is LD which is short for "Load".

Mnemonics in an assembly language program are converted to their binary machine code equivalents by an assembler program. For example the mnemonic SBI is converted to the binary code 10011010 by the assembler. This binary machine code instruction can then be run by the AVR microcontroller, while its mnemonic equivalent is human readable and understandable. Technically, the SBI mnemonic is part of a machine code instruction that consists of an operational code (opcode for short) and two operands. The machine code instruction is actually 16 bits wide when the operands are included, despite ATtiny and ATmega devices having an 8-bit architecture. The opcode SBI converts to an 8-bit number as already explained, and the two operands convert to a second 8-bit number making up 16-bits. Instructions are stored 16-bits wide. This may be a bit difficult to understand at this stage, but it is properly explained as we become more familiar with the AVR architecture in the next few chapters.

The AVR assembler program used by Microchip Studio is not case sensitive, so the mnemonic instructions can be written in upper or lower case, for example SBI or sbi. This book uses uppercase when referring to mnemonics in the text and lowercase in code listings. The reason for this convention is that this is the convention used in the Microchip / Atmel datasheets and other documentation for AVR microcontrollers.
