Here the inner loop, marked in bold in the code listing, is simplified away to inner_loop, which is where the result of our inner loop calculation will be substituted. The above calculation is easier to visualize if we write it as follows. Note that inner_loop is shortened to CIL in this listing.

| Once off | Passes through loop, except last | Last pass through loop |
|---|---|---|
| 1 + | ((( CIL + 1 + 2 ) x 2) | + (1 + CIL + 1 + 1) |
| 1 + | (((1 + CIL + 1 + 2 ) x (3 - 1) ) | + (1 + CIL + 1 + 1 ) |
| 1di | (((1di + CIL + dec + brbc) x num_passes) | + (1di + CIL + dec + brbc) |

The above calculation works in a very similar way to the inner loop, except that there are a few extra clock cycles to include in the calculation. When the delay subroutine starts to execute, it runs the first LDI instruction only once, to load the count for the outer loop. This is marked in the once off section of the above listing. The other two sections in the listing result because of the same reason that the inner loop was divided. This is because the BRBC instruction executes in 2 clock cycles for all iterations through the loop, except for the last one. In the above listing, the middle section includes all iterations or passes through the loop, except for the last one. The last section in the listing takes care of the last pass through the loop.

It can be seen that for the middle section of the above listing, the number of cycles through the loop is the sum of the clock cycle from the second LDI instruction, plus the clock cycles from the inner loop, plus one clock cycle for the DEC instruction, plus two clock cycles for the BRBC instruction. The result of this sum is then multiplied by the number of times through the loop. This is 3 – 1 for this example because the last pass through the loop is treated differently to all other passes through the loop. The last pass through the loop is therefore subtracted from the total passes through the loop, the same as for the inner loop. In this example, 3 was loaded to R16, which is the count for the outer loop, so we must do this calculation 2 times instead of 3.

In the last pass through the loop, we have one clock cycle used by the second LDI instruction, plus the clock cycles used by the inner loop, plus the clock cycles used by the DEC instruction, plus one clock cycle used by BRBC instead of the usual two clock cycles.
