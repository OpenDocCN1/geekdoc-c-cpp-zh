# 10.4.2.2 Left Shift Operator

At the start of the code of the timer0_poll_asm project, the DDB4 bit is set in the DDRB register to set up pin PB4 as an output pin, as is shown below.

```
ldi r17, (1 << DDB4) ; Pin PB4 as output pin
out DDRB, r17
```

In this code, the value to write to DDRB is first written to R17 and then R17 is written to DDRB. The value written to R17 is (1 << DDB4) which works the same way as it does in C code, as explained next. DDB4 is defined in the .inc include file of the project as follows.

```
.equ DDB4 = 4 ;
```

What the code (1 << DDB4) means is "left shift 1 DDB4 times". Because DDB4 is equated to 4, it means left shift 1 four times. 1 in binary can be written as 0b0000_0001. When this number is left shifted by 4, it means that the 1 is moved to the left four bit places. This gives a value of 0b0001_0000, which means that bit number 4 is set. Bit number 4 is bit DDB4 in the DDRB register. It is bit number 4 when counting bits from the right starting with 0. This left shift allows the name of the bit being set to be used in the code, making it easier for anyone reading the code to see which bit is being set.

We could have directly set bit DDB4 using the SBI instruction as we have done in previous projects, shown below.

```
sbi DDRB, DDB4 ; Set pin PB4 as output
```

This code is useful when setting a single bit. If more than one bit must be set in the DDRB register, then multiple SBI instruction would be needed – one for each bit to set. Using a combination of the LDI instruction and OUT instruction becomes more efficient when setting more than one bit in a register, or to write to registers that are out of range of the SBI instruction, that is registers with addresses above 0x1F. We did use the LDI and OUT combination when setting up the DDRB register to drive more that one LED in Chapter 8. In these projects we did not use the left shift operator, but wrote a value instead. When registers have many differently named bits, it is often better to use the left shift operators. When bits are similar, such as in DDRB, either use the left shift, or write a value. The main reason for not using SBI in this project is because the value in R17 is reused later.
