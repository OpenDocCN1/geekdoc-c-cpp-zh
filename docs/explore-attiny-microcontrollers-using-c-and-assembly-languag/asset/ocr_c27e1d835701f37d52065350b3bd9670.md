# Flagging Out of Range High and Low Values

It is necessary to detect the minimum MS_TIME_DEL value and minimum F_CPU value in addition to the testing the result of the WAIT_MS_CYCLES calculation. We know that the subroutine is limited to the following values.

+   **F_CPU maximum value of 20MHz, chosen as maximum ATtiny frequency.**
+   **MS_TIME_DEL maximum value calculated as 2,147,483ms @ 20MHz.**
+   **MS_TIME_DEL minimum value of 1ms. Anything less than 1ms is meaningless. Testing the code with MS_TIME_DEL set to 1 does produce a 1ms time delay.**

The only thing that we need to calculate is the minimum F_CPU value that can be used with the wait_ms subroutine. We arrived at the following intermediate formula during the manipulation of the formula previously.

```
f_{CPU} \times t_{ms} = 10000(C_T+1)
```

This formula can easily be manipulated to calculate the value of f_cpu by dividing each side by t_ms to get rid of t_ms on the left. The result is the following.

```
f_{CPU} = \frac{10000(C_T+1)}{t_{ms}}
```

We know that the minimum value that t_ms can be is 1ms. The minimum value that C_T can be is if we make one pass through the wait_ms subroutine. This value is 20 clock cycles. Substituting these values into the above formula gives us the following.

```
f_{CPU} = \frac{10000(20+1)}{1}
= 210000
```

The calculated value of 210,000 is 210kHz. We now have the following to work with.

+   F_CPU max 20MHz
+   F_CPU min 210kHz
+   MS_TIME_DEL max 2,147,483ms @20MHz
+   MS_TIME_DEL min 1ms
