Each memory location of program memory is 16-bits wide and cannot be accessed as two 8-bit bytes, each at their own address, as there is no need for byte access of program instructions (an exception to this is that data can be stored in program memory and accessed as bytes, but program instructions are never accessed as bytes). The implications of this is that the first memory location is found at address 0x0000 and contains a 16-bit wide instruction. The second memory location is at 0x0001 and contains a 16-bit wide instruction. This is different from what would normally be expected on byte addressable systems that would address each 8-bit wide byte and thus have the first instruction at addresses 0x0000 and 0x0001, and the second instruction at 0x0002 and 0x0003 if the instructions were 16 bits wide.

With this in mind, refer to the program memory block at the left of Figure 5.3, and let us look at the ATtiny25 as an example. Program memory of the ATtiny25 starts at address 0x0000 and ends at 0x03FF. To calculate the size of the memory that this address range covers, we take the end address 0x03FF and add one (because addresses start at 0) to get 0x0400 and then convert it to decimal which is 1024 or 1K of memory. This can look confusing because now we know from the datasheet that the ATtiny25 has 2K of Flash memory. The reason is that this is 1K × 16-bit wide memory or 1K × 2 bytes which is 2K bytes of memory.

Program memory in the memory map shows that the ATtiny13(A) has memory from 0 to 0x01FF and the ATtiny25 has memory from address 0 to 0x3FF. The ATtiny45 has the same memory as the ATtiny25 and some additional memory from address 0 to 0x7FF. The ATtiny85 has the same memory that the ATtiny25 and ATtiny45 have as well as additional memory. This makes the program memory address range of the ATtiny85 from 0 to 0xFFF.

# 5.3.2 Data Memory

Data memory on ATtiny13(A) and ATtiny25/45/85 microcontrollers consists of SRAM (Static Random Access Memory). SRAM memory is known as volatile memory as it loses the data stored in it when power to the microcontroller is switched off. Data memory starts at address 0x60 and not 0 because the general purpose working registers and I/O registers are mapped at the beginning of the data space. Having registers mapped into data memory space allows them to be accessed as data memory by instructions, which can be convenient.
