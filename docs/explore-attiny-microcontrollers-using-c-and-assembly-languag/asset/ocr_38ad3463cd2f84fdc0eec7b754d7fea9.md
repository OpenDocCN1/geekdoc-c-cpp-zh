To create an AVR assembly language project in Microchip Studio that consists of more than one file, first create a new AVR Assembler Project as usual. Create a new AVR Assembler Project in Microchip Studio now, and call it wait_ms.asm.

Enter the code from the previous wait_ms.asm : main.asm listing into the main.asm file that is automatically created with the new project, replacing the skeleton code in this file.

To add a second assembly language file to the project, right-click the wait_ms.asm project name at the top right of the Solution Explorer pane in Microchip Studio. On the menu that opens, select Add > New Item... as shown in Figure 10.4. to open the Add New Item dialog box. This dialog box is used to add multiple files to any project.

![](bbox=[0.12, 0.37, 0.82, 0.8])

In the Add New Item dialog box, click the Assembler File item and then enter wait_ms.asm in the bottom Name: field of the dialog box, as shown in Figure 10.5. Click the Add button at the bottom right of the dialog box to add the new assembly language file to the project.
