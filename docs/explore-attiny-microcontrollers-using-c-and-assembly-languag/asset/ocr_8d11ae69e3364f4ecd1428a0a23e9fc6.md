# 4.4 Calculating Number Sizes

While on the subject of numbers and number systems, a very useful skill to learn is how to calculate the maximum value that a binary number can hold depending on how many digits it consists of. The maximum size of a number can be calculated mathematically and is useful for determining memory sizes and the maximum value that a certain storage location can hold.

# 4.4.1 Calculating the Maximum Value of a Binary Number

The formula to calculate the maximum value of a binary number is as follows.

```
2^X - 1
```

Where X is the size of the binary number in bits. The maximum size of a four bit binary number is calculated as follows.

```
2^4 - 1
= 16 - 1
= 15
```

The above calculation can be done on the Windows calculator by first putting it into Scientific mode. Click the top left menu icon on the calculator and then click the Scientific menu item. Press 2, x^, 4, = to raise 2 to the power of 4 (2^4), now press –, 1, = to calculate the result of 15. Table 4.1 and Table 4.4 confirm that 15 is the biggest number that can be represented by a 4-bit binary number.

An eight bit number can have a maximum value of 255 as shown by the following formula used to calculate the binary number maximum value.

```
2^8 - 1
= 256 - 1
= 255
```

This calculation can be done on the Windows calculator in Scientific mode again, as follows. Click 2, x^, 8, –, 1, = to get a result of 255.
