Figure B.1 is the same circuit as Figure 2.1 of Chapter 2, except the connections to the programmers are not drawn in as connecting wires, and it includes connections to the USBasp, and Arduino Uno as a programmer.

# Figure B.1: 8-Pin ATtiny13/25/45/85 Circuit and Programmer Connections

To make the connections to a programmer, match up the labels on the header of the programmer being used with the same labels on the ATtiny pins. If using a 10-pin to 6-pin adapter with the USBasp, then wire it according to the ISP/SPI connection. If using a USBtinyISP programmer, use the ISP/SPI wiring.

When using an Arduino Uno as an ISP programmer, reset from digital pin 10 must be used, but the other connections can be taken from the socket connector at the edge of the board, or from the Arduino Uno ICSP header. Don't take reset from the ICSP header, which is marked with an X. Orientation of the Arduino Uno headers in the circuit is with the USB connector of the Arduino Uno on the left. Use the led_blink_asm and led_blink_c programs from Chapter 2 with this circuit.
