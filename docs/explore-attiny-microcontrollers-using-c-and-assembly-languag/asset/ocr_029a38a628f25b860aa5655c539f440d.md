# ### 10.4.2.3 Register Write or Read-Modify-Write

One difference between using SBI and the LDI/OUT combination is that SBI sets only one bit, while the LDI/OUT combination overwrites everything in the DDRB register. This may be what is required, but in some instances it may not be. In cases where a bit or bits must be set in a register, without changing other bits in the register, a read-modify-write operation must be performed. In the timer0_poll.asm project the first two lines of code, repeated again below, effectively write 0b0001_0000, or 0x10 to R17. This value is then written from R17 to DDRB using the OUT instruction which sets bit 4, but also clears all other bits. In this project, it makes no difference that the other bits are cleared.

```
ldi   r17, (1 << DDRB)  ; Write 0b0001_0000 to R17
out   DDRB, r17         ; Set bit DDRB and clear all other bits
```

In the case where we don't want to change the other bits, the DDRB register must first be read using the IN instruction, then modified by using the OR operator to set the desired bit, or bits, and then written back to DDRB. This is done the following way.

```
in    r17, DDRB         ; Read -- read DDRB register
ori   r17, (1 << DDRB)  ; Modify -- set desired bit or bits
out   DDRB, r17         ; Write -- write value back to DDRB
```

In the above code, the value in DDRB is read and placed into R17 using the IN instruction, which is the READ part of the read-modify-write operation. ORI is used to set DDRB in R17 without changing any of the other bits, which is the MODIFY part of the read-modify-write operation. Finally the modified value in R17 is written back to DDRB, this is the WRITE part of the read-modify-write operation.

# ### 10.4.2.4 Initializing Timer 0

After setting up pin PB4 as an output pin, the initialization of Timer0 starts with the following code.

```
ldi   r16, (1 << WGM01)  ; CTC mode for timer
out   TCCR0A, r16
```
