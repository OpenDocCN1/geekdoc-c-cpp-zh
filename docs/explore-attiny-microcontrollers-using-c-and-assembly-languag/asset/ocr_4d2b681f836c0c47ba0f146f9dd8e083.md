# 10.4.1.2 Using Counter/Timer0 as a Timer

In order to use Counter/Timer0 as a simple timer, it can be put into CTC mode, which stands for Clear Timer on Compare. Counter/Timer0 is referred to as Timer0 in the remainder of this text, as it is used as a timer and this simplifies its name. WGM bits are used to put Timer0 into CTC mode and are spread across the TCCR0A and TCCR0B registers. WGM stands for Waveform Generation Mode. Bits WGM[2:0], which means WGM bits 2, 1 and 0, must be set to a binary value of 010 to put the timer into CTC mode. This is indicated near the top of Figure 10.6, below the horizontal dotted line. The same information can also be found in the datasheet for the microcontroller being used. In CTC mode, a value must initially be written to the OCR0A register. After the timer is started, the actual incrementing count value is found in the TCNT0 register. This register is not shown in Figure 10.6, as it is simply an 8-bit register that holds the count value. It is found at address 0x32 on both the ATtiny25/45/85 and ATtiny13(A) ranges. When TCNT0 reaches the same value that was written to OCR0A, a compare match occurs. In CTC mode, TCNT0 is automatically cleared and the timer starts counting from 0 again. At the same time, the OCF0A bit in the TIFR or TIFR0 register is set to flag the timer compare match. Continually reading or polling this bit allows us to check if the timer has timed out.

To initially start Timer0, a value is written to the CS (Clock Select) bits in TCCR0B. This value selects the clock source that clocks Timer0, which can be either the system clock, or the system clock divided down by a prescaler division factor, or an external clock source. These options can be found in the datasheet for the microcontroller being used. The system clock divided by 1024 through the prescaler is chosen for the projects that follow, so this is the value shown in Figure 10.6 below the horizontal dotted line, to the right. As can be seen in the figure, a binary value of 101 is written to the CS[2:0] bits found in the TCCR0B register.
