# ## 9.5 Further Reading

Documentation for the AVRASM2 AVR assembler can be found on the Microchip website in PDF format at: www1.microchip.com/downloads/en/DeviceDoc/40001917a.pdf

This AVR Assembler document is the primary source for anyone using the AVRASM2 assembler program, and includes more information on AVR assembler syntax, assembler directives, the preprocessor, and expressions used in AVR assembly language programs.

# ## 9.6 Summary

+   - AVRASM2 is the name of the default AVR assembler program used by Microchip Studio.
+   - The preprocessor can be used to include external files in an assembly language program.
+   - The correct header file is automatically included in an assembly language project in Microchip Studio for the AVR part selected when creating the project.
+   - Assembler directives are available for use in assembly language programs, and allow the programmer to specify code and data locations, select type of memory to place data in, reserve bytes for data in memory, name registers, and more.
+   - Assembler directives always start with a dot (.) when used in an assembly language program.
+   - Use the AVRASM2 AVR Assembler manual or document to find technical information on the AVRASM2 assembler program.
