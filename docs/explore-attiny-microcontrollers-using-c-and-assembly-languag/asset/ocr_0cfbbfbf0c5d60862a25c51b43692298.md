# 11.2.4.8 Store Direct to SRAM

STS (Store Direct to Data Space)
STS has the form STS k, rr and stores a value from a register to data space address k. k can be between 0 and 65535, while Rd can be R0 to R31. STS is demonstrated in section 5.4.1 in Chapter 5 along with LDS.

# 11.2.4.9 Load Program Memory Instructions

LPM (Load Program Memory)
LPM
LPM Rd, Z
LPM Rd, Z+

LPM has three variants, as shown above, and loads one byte from Flash program memory pointed to by the Z register to the destination register. The first variant above that consists of the LPM instruction on its own with no operands loads one byte from Flash program memory pointed to by the Z register to register R0. The use of LPM is demonstrated and explained in section 9.3.2.2 of Chapter 9.

# 11.2.4.10 Store Program Memory

SPM (Store Program Memory)
SPM is used to erase and write to Flash program memory. For more information on SPM see the AVR Instruction Set Manual, and also the Self-Programming the Flash section of the datasheet for the part being used.

# 11.2.4.11 Port IN and OUT Instructions

IN (Load an I/O Location to Register)
OUT (Store Register to I/O Location)

IN and OUT have been used many times throughout the text of this book. Remember that IN and OUT move data from I/O space to a register, and to I/O space from a register respectively. Both instructions are limited to operating on I/O register addresses 0 to 63, but can access general purpose working register R0 to R31. Refer to section 8.1.1 in Chapter 8 for information on using IN and OUT.
