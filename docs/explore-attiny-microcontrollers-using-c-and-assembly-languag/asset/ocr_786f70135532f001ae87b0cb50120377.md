# USBasp

```
-p t85 -c usbasp -P usb -U flash:w:"$(OutDir)Debug\$(TargetName).hex"
```

# USBtinyISP

```
-p t85 -c usbtiny -P usb -U flash:w:"$(OutDir)Debug\$(TargetName).hex"
```

# ArduinoISP (Arduino Uno with ArduinoISP sketch loaded)

```
-p t85 -c avrsp -P COM3 -b 19200 -U flash:w:"$(OutDir)Debug\$(TargetName).hex"
```

The part number after the `-p` switch must be changed to the correct code for the ATtiny being used in each of the lines above. Refer back to Table A.1 in section A.3.4.2 in this appendix to find the codes for ATtiny parts. Change the ArduinoISP COM port to the correct number. Copy the line to the Arguments field of the External Tools dialog box.

In the above lines, two macros are used: one to find the path to the hexadecimal file, and the other to get the name of the hexadecimal program file. The macro `$(OutDir)` resolves to the path to the current project. This is followed by `Debug` to add the Debug folder to the end of the path. The hexadecimal file is found in the Debug folder of a Microchip Studio project. The macro `$(TargetName)` resolves to the name of the current project, which is also the name of the hexadecimal program file. It is followed by `.hex` in the above lines, because the hexadecimal ends with a `.hex` file extension.

# Initial directory: $(ProjectDir)

Placing the $(ProjectDir) macro in this field allows Microchip Studio to automatically find the path to the current project folder and start avrdude from this folder.
