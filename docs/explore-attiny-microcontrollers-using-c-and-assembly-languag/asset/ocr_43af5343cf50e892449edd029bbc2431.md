Now step over the CLR instruction and the value in R0 will be cleared to zero (R0 and R00 are the same register. R0 is labeled R00 in the Processor Status window).

The INC (Increment) instruction is repeated three times after the CLR instruction, and is used to increment register R0. Step over the INC instructions and note that R0 increments by one after each INC instruction is executed. When the RJMP instruction is reached at the end of the program, R0 contains 0x03 as expected after three increments. Unlike the LDI instruction, the CLR and INC instructions can be used on any of the general purpose registers from R0 to R31. As already mentioned the counterpart to the CLR instruction, SER, sets all bits in a register, but only works on R16 to R31 and not on R0 to R15 – refer back to Figure 5.1. Experiment with these instructions in Microchip Studio. Try building a project that uses LDI or SER on registers R0 to R15 to see the error displayed in Microchip Studio. Remember to save and build the program each time after making changes to the code. Quick Tip: After building the project, hit the F10 key immediately to start the debugger and break instead of having to click the toolbar button. Continue pressing the F10 key to step over each line of code after this.

The previous two examples show some of the ways that the general purpose working registers are used in assembly language programs. Registers can be used to store values to be used in mathematical calculations and to store the results of calculations. The same applies to Boolean, or logical operations which are still to be covered. Usage of registers will become clearer as you progress through this book and see more code examples, and how other assembly language instructions operate on registers.
