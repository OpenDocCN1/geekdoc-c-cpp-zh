
RJMP to the interrupt handler or ISR for this interrupt is placed below this origin change so that it is at address 0x0006 in memory. In this code, there are no vector table entries for other interrupts, so the other interrupts must never be enabled. The dummy interrupt handler code can be removed from the project with this arrangement because it is never used.

## Main Program Code

After the interrupt vector table, we have the following code.

```
main:
    sbi   DDRB, DDB4        ; Pin PB4 as output pin
    ldi   r16, (1 << WGM01)  ; CTC mode for timer
    out   TCCR0A, r16
    ldi   r16, 0x7F         ; Output compare value
    out   OCR0A, r16
    ldi   r16, (1 << OCIE0A) ; Enable T0A compare match interrupt
    sts   TIMSK0, r16
    sei                     ; Set global interrupt enable bit
    ldi   r16, (1 << CS02) | (1 << CS00) ; Prescaler CLK/1024 and start timer
    out   TCCR0B, r16
loop:
    rjmp loop
```

In this code, pin PB4 is set up as an output pin using the SBI instruction. After this, timer 0 is set up in the same way as it was for the previous projects that polled the timer. The timer is first put into CTC mode, then a compare value loaded to OCR0A. This is followed by new code shown in bold above that enables the timer 0 compare match A interrupt and global interrupt enable bit. Bit OCIE0A is set in the TIMSK0 register in order to enable the timer/counter compare match A interrupt. This is followed by the SEI (Set Global Interrupt Enable Bit) instruction which sets the I bit in the status register. Refer back to Figure 6.8 in section 6.5 of Chapter 6 to see the status register. In the status register, the first bit on the left, or bit number 7, is the Global Interrupt Enable bit, or I bit. Once this bit is set, any individual interrupts that are enabled, such as the timer/counter 0 compare match A interrupt, will work when triggered. Finally the timer is started as done previously by selecting the system clock divided by 1024. Program execution then enters an infinite loop.

## Interrupt Service Routine Code

Finally we have the interrupt service routine code for the timer 0 compare match A interrupt, shown in the code snippet that follows. The code in this ISR simply toggles the LED attached to pin PB4 using the PINB register. The difference between this project and the polled project is that now the timer interrupt and ISR handle everything.

```
; Timer 0 compare match A interrupt service routine or handler
ISR_tim0_compa:
    sbi PINB, PINB4 ; Toggle LED
    reti
```

As the main program execution is doing nothing in an infinite loop, only the ISR can toggle the LED. When there is a compare match between the timer counter register TCNT0 and the output compare register OCR0A, the Timer/Counter compare match A Interrupt is triggered. Program execution jumps to the vector location for this interrupt in the interrupt vector table, which is address 0x0006 on the ATtiny13(A). At this location is the RJMP instruction that jumps to the ISR_tim0_compa interrupt service routine. In this ISR, the PINB4 bit is set in the PINB register which toggles the LED. The ISR returns to the main loop after executing the RETI instruction. It is important to always return from an ISR using RETI and not RET.

## Running the Timer Interrupt Code

Run the code using a debugger/programmer or using the simulator in Microchip Studio. Step through the code and notice that the first RJMP instruction at address 0 jumps to the main label. Before stepping over the SEI instruction, make sure that the Processor Status window is open. Look at the Status Register I flag, found near the top of the Processor Status window. It is initially clear or 0. After stepping over the SEI instruction it turns solid red, indicating that it has just changed state and that it is now set. Place a breakpoint on the RETI instruction at the bottom of the ISR_tim0_compa ISR. Now run the code using the F5 keyboard key. When code execution stops on the breakpoint, notice that the I flag in the Status Register is now clear. Step over the RETI instruction and notice that the I flag is automatically set and is solid red again. Remember that items in the Processor Status window turn red if their state has just changed. Items such as the bits in the status register will turn blue if they are still set, but did not change from the most recent step through the code. Open the I/O window and click the I/O Port (PORTB) item so that the port B registers are displayed at the bottom of the I/O window. Using the F5 keyboard key to run the code with the breakpoint still on the RETI instruction will cause execution to stop after pin PB4 is toggled. The bit corresponding to pin PB4 can be seen toggling at each break in the PORTB register at the bottom of the I/O window.

## 10.5.3.2 ATtiny25/45/85 Timer Interrupt Project

Because the interrupt vector table is different between the ATtiny13(A) and ATtiny25/45/85, the next project is included that is the same as the previous, but has been adjusted to work for an ATtiny25/45/85. Create the timer0_interrupt_asm project in Microchip Studio for an ATtiny25, ATtiny45 or ATtiny85. Enter the code from the following listing into the main.c file of the project.

```
timer0_interrupt.asm : main.asm

.org 0
rjmp main ; 0 - Reset vector
rjmp ISR_unused ; 1 - External interrupt 0 vector
rjmp ISR_unused ; 2 - Pin change interrupt 0 vector
rjmp ISR_unused ; 3 - Timer 1 compare match A interrupt vector
rjmp ISR_unused ; 4 - Timer 0 overflow interrupt vector
rjmp ISR_unused ; 5 - Timer 0 overflow interrupt vector
rjmp ISR_unused ; 6 - EEPROM ready interrupt vector
rjmp ISR_unused ; 7 - Analog comparator interrupt vector
rjmp ISR_unused ; 8 - ADC conversion complete interrupt vector
rjmp ISR_unused ; 9 - Timer 1 compare match B interrupt vector
rjmp ISR_tim0_compA ; A - Timer 0 compare match A interrupt vector
rjmp ISR_tim0_compB ; B - Timer 0 compare match B interrupt vector
rjmp ISR_unused ; C - Watchdog timer timeout interrupt vector
rjmp ISR_unused ; D - USI start interrupt vector
rjmp ISR_unused ; E - USI overflow interrupt vector

main:
sbi DDRB, DDB4 ; Pin PB4 as output pin
ldi r16, (1 << WGM01) ; CTC mode for timer
out TCCR0A, r16
ldi r16, 0x7F ; Output compare value
out OCR0A, r16
ldi r16, (1 << OCIE0A) ; Enable T0A compare match interrupt
out TIMSK, r16
sei ; Set global interrupt enable bit
ldi r16, (1 << CS02) | (1 << CS00) ; Prescaler CLK/1024 and start timer
out TCCR0B, r16

loop:
rjmp loop

; Timer 0 compare match A interrupt service routine or handler
ISR_tim0_compA:
sbi PINB, PINB4 ; Toggle LED
reti

; Dummy interrupt handler to catch all unused interrupts
ISR_unused:
nop
rjmp ISR_unused
```

The first and most obvious change in the above program when compared to the previous one is the bigger interrupt vector table. ATtiny25/45/85 devices have more on-chip peripherals than ATtiny13(A) devices, and these extra peripherals have interrupt capabilities. This means that extra interrupt vectors are needed for these extra interrupt sources. In addition to having a bigger interrupt vector table, the timer 0 compare match A interrupt vector is at a different location. This interrupt vector is at address 0x0006 on an ATtiny13(A), but is at address 0x000A on an ATtiny25/45/85. In fact, only the first three interrupt vectors, including the reset vector, are at the same addresses when comparing the two ATtiny device ranges. Everything in the remainder of the program is the same as for the ATtiny13(A), except that the TIMSK register is called TIMSK0 on an ATtiny13(A) and called TIMSK on an ATtiny25/45/85.

## 10.5.3.3 Universal Timer Interrupt Project

Because the ATtiny header files define names for interrupt vector addresses, it is possible to change the previous projects to work on both the ATtiny13(A) and ATtiny25/45/85. Create the timer0_uni_int.asm assembly language project in Microchip Studio, and add the following code to main.asm. This code works on both ATtiny13(A) and ATtiny25/45/85 devices without the need to change anything.

```
timer0_uni_int.asm : main.asm

.lfndef TIMSK
.equ TIMSK = TIMSK0
.endif

.org 0
rjmp main ; Reset vector

.org OCA0addr
rjmp ISR_tim0_compA ; Timer 0 compare match A interrupt vector

main:
sbi DDRB, DDB4 ; Pin PB4 as output pin
ldi r16, (1 << WGM01) ; CTC mode for timer
out TCCR0A, r16
ldi r16, 0x7F ; Output compare value
out OCR0A, r16
ldi r16, (1 << OCIE0A) ; Enable T0A compare match interrupt
out TIMSK, r16
sei ; Set global interrupt enable bit
ldi r16, (1 << CS02) | (1 << CS00) ; Prescaler CLK/1024 and start timer
out TCCR0B, r16

loop:
rjmp loop

; Timer 0 compare match A interrupt service routine or handler
ISR_tim0_compA:
sbi PINB, PINB4 ; Toggle LED
reti
```
