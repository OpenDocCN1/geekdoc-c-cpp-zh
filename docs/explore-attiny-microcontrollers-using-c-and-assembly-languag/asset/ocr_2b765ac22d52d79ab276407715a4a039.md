# 11.2.1.3 Increment and Decrement Instructions

# 11.2.1.4 Sign Change Instructions

# COM (One's Complement)

COM converts the number in a register to one's compliment, in other words it inverts each bit in the register, as the following code demonstrates by converting the binary number 1001_0011 to its 1's compliment value 0110_1100.

```
ldi R16, 0b1001_0011 ; Load 0x93 to R16
com R16 ; R16 now contains 0b110_1100 (0x6C)
```
