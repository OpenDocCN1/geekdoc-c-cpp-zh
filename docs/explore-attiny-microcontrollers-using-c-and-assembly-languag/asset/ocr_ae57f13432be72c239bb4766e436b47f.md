In the above listing, bit DDB0 is set in the DDRB register, configuring pin PB0 as an output. (1 << PORTB0) evaluates to 0x01, therefore a bitwise exclusive OR is performed between PORTB and 0x01, which causes pin PB0 and attached LED to toggle. In C it looks like PORTB is directly exclusive ORed with a value, but the disassembly shows that PORTB is read, then the PORTB value exclusive ORed, then the new value written back to PORTB. Take a look at the disassembly in Microchip Studio to see for yourself.

# 8.2.4.3 Toggling an LED with the PINB Register

The PINB register, shown at the bottom of Figure 8.4 in section 8.2.1.8, can be used to toggle the state of pins when these pins are set as outputs. Writing a logic 1 to the corresponding bit in the PINB register toggles the state of the corresponding pin.

Code to toggle 5 LEDs in parallel can be seen in the led_pinb_toggle_asm project code listing that follows. Use the circuit from Figure 8.2 again to run this program. As with the led_eor_toggle_asm project, the value written to R18 at the start of the code can be changed to select which LEDs to toggle in the program.

By now you should know that the binary value 0b0000_1111 written to R18 is the same as 0x1F. To toggle the LED on PB0 alone, this value can be changed to 0x01, or the decimal value 1, or 0b0000_0001. As with the previous code listings, the same delay subroutine is called in the main loop to leave the LEDs on for a time that is visible to the eye.
