# 4.1.2 Bytes and Nibbles

When a microcontroller is designed, a size of binary number is chosen that the microcontroller can fetch and operate on. In an 8-bit microcontroller architecture the microcontroller fetches and operates on 8-bit wide data. An 8-bit wide number can have a value from 0, or 0b00000000 (0 decimal) to a maximum of 0b11111111 (255 decimal). Figure 4.3 shows examples of 8-bit wide memory locations storing binary numbers. A byte refers to an 8-bit wide number or memory location that consists of 8 memory cells and is therefore 8 bits wide. Half a byte, or four bits is referred to as a nibble.

# 4.2 Weighted Number Systems

Both the decimal and binary number systems are weighted number systems. A quick explanation of weighting in the decimal system will help with understanding the same concept for binary numbers.
