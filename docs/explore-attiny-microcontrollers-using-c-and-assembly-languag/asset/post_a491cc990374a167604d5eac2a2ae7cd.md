## A.3.3.2 Connecting a USBtinyISP

USBtinyISP programmers, and variations of the original USBtinyISP design, usually have a 6-pin ISP/SPI connector. This could be in the form of a male header and/or a 6-pin female connector at the end of a ribbon cable. Connections to both a male header and female ribbon cable connector are described under the headings that follow.

### 6-pin Male Header

Connections can be made directly from a 6-pin male header on a USBtinyISP to an AVR circuit using Dupont wires with a female connector on one end and a male connector on the other. When making this connection, use connector J1, the SPI header, from the circuits in Appendix B to make the connections to the AVR circuit.

### 6-pin Female Connector on Ribbon Cable

Use either Dupont wires with a male pin on each end, or single strand wires, to connect from the 6-pin female connector of the USBtinyISP to the AVR circuit. If making this connection, use the inset image of the 6-pin female connector found above J1 in the circuits of Appendix B. The image is a view facing the holes of the female connector.

## A.3.3.3 Connecting an Arduino Uno ArduinoISP

Each circuit in Appendix B shows the connections needed to connect an Arduino Uno to an ATtiny microcontroller, when using the Arduino as an ISP programmer. The sketch called ArduinoISP must be loaded to the Arduino, as already described in this Appendix.

In the inset image of each circuit in Appendix B containing the Arduino Uno connections, the connections of just one of the Arduino Uno edge connectors and its ICSP header are shown. These connectors are for an Arduino Uno that has the top of the board facing up, and the USB connector at the left. All of the programming connections can be taken off the top left Arduino header at the edge of the board, which has all of the ISP/SPI pins available – GND, SCK, MISO, MOSI, and RESET. If using this connector to connect to the AVR circuit, either Dupont connectors with a male pin on each end, or single-strand wires, can be used to make the connections. To power the circuit from the Arduino Uno, use the 5V connection from the POWER connector of the Arduino on the opposite side of the board, or 5V from the Arduino Uno ICSP header.

As an alternative to using the edge connector to connect to the target AVR circuit, wires can be connected from the ICSP header to the AVR circuit. In this case, Dupont wires with a female connector on one end and a male connector on the other can be used. Note that RESET must still be taken from pin 10 of the edge connector, and not from the ICSP header. RESET on the ICSP header is a reset input to the Arduino.

## A.3.4 Programming Parameters

Programming parameters, or command line options (also called arguments), to be passed to avrdude must be worked out for each combination of ATtiny part and the programmer being used. These parameters will be set up in Microchip Studio, which will then pass them to avrdude when it is called.

### A.3.4.1 Documentation for avrdude

Documentation in the form of a PDF file for avrdude that contains more information on using avrdude can be found at download.savannah.gnu.org/releases/avrdude/ which contains PDF files for each version of avrdude. A file called avrdude-doc-6.3.pdf is the documentation for version 6.3 of avrdude, which was the current version at the time of writing. This is the official avrdude documentation that can be consulted for information on avrdude. It contains programming parameters that avrdude understands.

### A.3.4.2 Parameters for avrdude Explained

Parameters that must be passed to avrdude for different programmers is explained here. This section is just an overview to get a better understanding of how avrdude works. Specific parameters for the three hobby programmers covered in this book follow. As a first example, look at the following.

```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

The above line of code shows how avrdude would be called from the command line to load a program from a file to the Flash memory of an AVR microcontroller. Although we won't be calling avrdude directly from the command line, avrdude is a command-line program, and we need to understand how to use it when setting it up in Microchip Studio.

The first item in the above line is avrdude, which invokes the avrdude executable program – in other words it calls or runs the avrdude program that we downloaded, named avrdude.exe. Items following the call to avrdude are command-line options that are passed to avrdude from the command line, simply by typing them in after avrdude.

The first option is the -p switch, specifying which part is to be programmed, followed by the code for the specific part. In this example, -p is followed by t85, which is the code for the ATtiny85 part. Part codes for PDIP packaged ATtiny microcontrollers from Table 1.1 in section 1.3 of Chapter 1 are shown in Table A.1. Table A.1 only includes a small number of AVR parts that avrdude can program. The many other supported parts can be found in the avrdude PDF document.

```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

The -c switch must be followed by a programmer ID. In the example above, the programmer specified is the USBasp. Table A.2 shows the three programmers that are covered in this appendix with their avrdude programmer IDs.

| Programmer | ID |
| :--- | :--- |
| USBasp | usbasp |
| USBasp Clone | usbasp-clone |
| USBTinyISP | usbtiny |

For the USBasp pictured in this book, the usbasp ID works. If you are having trouble programming with your USBasp, you can try usbasp-clone instead. As can be seen in Table A.2, the programmer ID for a USBTinyISP is usbtiny. When an Arduino Uno has been loaded with the ArduinoISP sketch, it has effectively become an ISP programmer, so the ID avrisp must be used with it. Many more programmers are supported by avrdude, but as mentioned, only three programmers are covered in this appendix.
