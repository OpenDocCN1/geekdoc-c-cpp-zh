# Chapter 2 • Hardware and Software Setup

The objective of this chapter is to install Microchip Studio, build a circuit using an ATtiny25/45/85 or ATtiny13(A), then write a program and load it to the microcontroller.

Microchip Studio is used to write assembly language and C programs when following this book. Those readers who do not have hardware yet can still install Microchip Studio, read through the rest of this chapter and create the first assembly language and C language programs. Chapter 3 shows how to use the simulator found in Microchip Studio.

# In this Chapter

+   - Install Microchip Studio
+   - Build an ATtiny microcontroller circuit
+   - Write a simple assembly language program and load it to an ATtiny
+   - Write a simple C program for an ATtiny microcontroller
