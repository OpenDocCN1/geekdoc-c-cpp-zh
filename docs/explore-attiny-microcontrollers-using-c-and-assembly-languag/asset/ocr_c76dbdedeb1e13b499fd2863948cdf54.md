Opening the led_blink.asm project from Chapter 2 and running it in the debugger shows that the instructions in the main program are all single cycle instructions. After stepping over each instruction, the program counter increments by one. When the RJMP instruction is executed at the bottom of the main loop, the program counter is loaded with the address of the SBI instruction under the loop label and execution starts at the top of the loop again.

The program counter can be thought of as a binary counter that is driven by the main clock of the microcontroller and continues to count up with each clock pulse. A new count value is loaded to the PC when a jump or branch instruction is executed or a subroutine is called or returned from. The count value, of course, is used to address memory which causes the microcontroller to fetch an instruction from that memory address and execute it.

The ATtiny13(A) program counter is 9 bits wide so that it can address 2^9 or 512 16-bit wide instructions, which of course is 1024 bytes, or 1K. In the ATtiny25, the program counter is 10 bits wide because it only needs to address 2^10 instructions (1K or 1024 instructions) which is 2^10 x 2 bytes (2K or 2048 bytes because the program memory is 16-bits wide). In the ATtiny45, the program counter is 11 bits wide so that it can address its 2^11 or 2K 16-bit wide instruction memory (4K bytes). The ATtiny85 has a 12 bit wide PC for its 2^12 or 4K 16-bit wide instructions (8K bytes).

# 6.2 Microcontroller Buses

A bus on a microcontroller or microprocessor is a group of wires. An 8-bit bus is a group of 8 wires. Figure 6.4 shows a block diagram of a general microcontroller that has an address bus, data bus and control bus represented by wide lines. The address bus could be 16 bits wide, depending on the microcontroller, and would then consist of 16 wires. An 8-bit microcontroller would have an 8-bit wide data bus consisting of 8 wires. The number of wires on the control bus varies between architectures, but usually has some chip select lines as well as read and write control lines. Microcontroller buses are used to get data from, and send data to memory and I/O devices. Depending on the microcontroller, the buses may be internal only, or extend to pins on the microcontroller allowing external memory and peripherals to be interfaced to the microcontroller buses.
