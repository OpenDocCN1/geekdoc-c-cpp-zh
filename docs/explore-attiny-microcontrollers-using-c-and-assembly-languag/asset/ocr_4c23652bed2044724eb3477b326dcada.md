# 8.1.1.2 The OUT Instruction

OUT (Store Register to I/O Location) writes data to an I/O register from register R0 to R31. To write a value to an I/O location using the OUT instruction, a value must first be loaded to a working register (R0 to R31) and then the register written to the I/O register using OUT. To load a constant value to an I/O register, the value first needs to be loaded to a register using the LDI instruction. Remember that the LDI instruction only operates on registers R16 to R31. The following code shows how to write a constant value to an I/O register using OUT.

```
ldi r16, 0x1A
out DDRB, r16
```

In the above code, the constant value 0x1A is loaded to R16. The contents of R16, which is now 0x1A, is written to the DDRB register using the OUT instruction. As can be seen in Figure 8.1, DDRB is defined as 0x17. Once again, using the name DDRB makes the code easier to read, rather than directly using the address of DDRB which is 0x17.
