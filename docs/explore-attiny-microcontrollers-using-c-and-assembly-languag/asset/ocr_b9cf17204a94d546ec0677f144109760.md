+   - An instruction set for a particular microcontroller architecture is the set of all of the instructions that the architecture can execute and that a program can consist of.
+   - An assembler program converts assembly instructions written in text using mnemonics, to their binary machine language form.
+   - Comments are used to add notes to an assembly language program and start with a semicolon. C and C++ style comments can also be used in AVR assembler programs.
+   - A loop in programming is used to repeatedly run certain parts of code.
+   - The AVR simulator is useful to quickly see how certain assembly language instructions work and is a great tool when learning assembly language.

This chapter has been a brief introduction to assembly language and the tools used to write, build, simulate and debug AVR assembly language programs. In order to be able to understand assembly instructions properly, an understanding of internal registers of a microcontroller is necessary. Internal registers and memory of a microcontroller store binary numbers, and binary numbers are used to manipulate hardware devices connected to a microcontroller, such as LEDs.
