Counting in binary works the same way as decimal, except that only two values are available per digit instead of the ten values of decimal. In decimal we would count from 0 to 9 and then increment the next significant digit (the digit to the left) by one, then start counting from 0 to 9 again. In binary the same thing happens — we start at 0 and count to 1, now we have run out of digits, so we increment the next significant digit and have the number 0b10. The first digit is then incremented again, so we have 0b11. Now we have run out of digits again so need to add another digit and increment the number to 0b100. Table 4.1 shows how to count from 0 to 15 or 0b0000 to 0b1111 in binary.

| Decimal | Binary |
| :--- | :--- |
| 0 | 0000 |
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| 4 | 0100 |
| 5 | 0101 |
| 6 | 0110 |
| 7 | 0111 |
| 8 | 1000 |
| 9 | 1001 |
| 10 | 1010 |
| 11 | 1011 |
| 12 | 1100 |
| 13 | 1101 |
| 14 | 1110 |
| 15 | 1111 |

A calculator that has a binary mode can be used to help better understand how counting in binary works. This can be a hand-held calculator that has a binary mode, or the calculator that comes with the Windows operating system. To start the calculator in Windows, click the main Windows menu or “Start” button and then type calc which filters the installed applications making it easy to find the calculator application in the menu list. Click Calculator to start the calculator.

By default the calculator is in standard mode and must be changed to programmer mode in order to work with binary numbers. Click the calculator menu icon at the top left of the calculator application, and then click Programmer on the menu that opens. A list of numbering systems appear in the calculator application (HEX, DEC, OCT and BIN). Click the BIN item to put the calculator into binary mode.
