# ## 7.3 Subtraction

SUB (Subtract without Carry) subtracts the values from two registers. If the result of the subtraction is negative, the result will be in 2's compliment format. An example follows that uses the SUB instruction to subtract two registers with a positive result.

```
test_asm : main.asm - Subtraction with positive result
ldi    r16, 145
ldi    r17, 99
sub    r16, r17    ; R16 = R16 - R17 = 145 - 99 = 46 or 0x2E
```

The SUB instruction in the above example subtracts the value in R17 from the value in R16 and stores the result back in R16. Test the code in the Microchip Studio simulator.

In the following code, a subtraction is done that results in a negative result which is stored in the destination register in 2's compliment format.

```
test_asm : main.asm - Subtraction with negative result
ldi    r16, 84
ldi    r17, 199
sub    r16, r17    ; R16 = R16 - R17 = 84 - 199 = -115 or 0x8D
```

In the Microchip Studio debugger, the result of the subtraction from the above code is 0x8D found in R16, with the negative flag set in the status register. When R16 is converted to decimal in the Processor Status window, it does not take into consideration that the number is negative and so treats it as a positive number converting the most significant bit to its weight value instead of treating the number as 2's compliment. 0x8D in binary is 0b1000_1101. To convert this number from 2's compliment format to its actual value we subtract 1 and then invert:

```
0b1000_1101 - 1 = 0b1000_1100
```

Inverting the bits of the result, we get:

```
0b0111_0011 or 115
```

We know that it is a negative number so its actual value is -115 which is the correct result when 199 is subtracted from 84 as in the example code.
