
## 11.2.3 Bit and Bit-test Instructions

Instructions that operate on bits and test the status of bits follow in several subcategories.

### 11.2.3.1 Bit Set and Clear Instructions

- SBI (Set Bit in I/O Register)
- CBI (Clear Bit in I/O Register)

SBI and CBI should be very familiar to anyone who has worked through this book. These instructions were used in the very first assembly language program code in section 2.3.2 of Chapter 2. Remember that these instructions only work on I/O registers with addresses between 0 and 31.

### 11.2.3.2 Shift, Rotate and Swap Instructions

### Logical Shift Instructions

- LSL (Logical Shift Left)

LSL has the form LSL Rd and left shifts each bit in the destination register by one bit place. The MSB or bit 7 of the destination register is moved into the carry flag, and the LSB or bit 0 is cleared during the left shift operation.

- LSR (Logical Shift Right)

LSR is the counterpart to LSL and shifts each bit in the destination register one bit place to the right. The LSB or bit 0 is shifted into the carry flag of the status register, and the MSB or bit 7 is cleared.

### Rotate through Carry Instructions

- ROL (Rotate Left through Carry)

ROL has the form ROL Rd and rotates each bit in the destination register one bit place to the left through the carry flag. This means that bit 7 is put into the C flag, and the contents of the C flag is put into bit 0 of the destination register.

- ROR (Rotate Right through Carry)

ROR is the counterpart of ROL and rotates each bit in the destination register right through the C flag, placing bit 0 in the C flag, and the C flag in bit 7.

### Logical Shift and Rotate Code Example

The following code helps to understand the LSL, LSR, ROL and ROR instructions.

```
ldi   r16, 0x01    ; For demonstrating LSL 0000 0001
ldi   r17, 0x80    ; For demonstrating LSR 1000 0000
ldi   r18, 0x01    ; For demonstrating ROL 0000 0001
ldi   r19, 0x80    ; For demonstrating ROR 1000 0000
loop:
;lsl   r16        ; LSL (Logical Shift Left)
;lsr   r17        ; LSR (Logical Right Shift)
;rol   r18        ; ROL (Rotate Left through Carry)
;ror   r19        ; ROR (Rotate Right through Carry)
rjmp  loop
```

Uncomment one of the instructions in the loop and build the project to test that instruction. Run the code in the simulator and look at the register being shifted or rotated in the Processor Status window. Change the format of the register in the Processor Status window to Binary to see the bit being shifted or rotated.

Values have been chosen that set the LSB of the register for a left shift or rotate instruction, and the MSB for a right shift or rotate. When viewing the register in binary, it can easily be seen how the register is being shifted or rotated by looking at the single set bit, and where it is moving to. When the single set bit in the registers is shifted left or right using LSL or LSR, notice that once the bit is shifted out of bit 7 or 0, then the register contains 0 from then on. With the rotate instructions ROL and ROR, the set bit being shifted is shifted into the C flag and then into the opposite end of the register on the next rotation.

### Led Chaser Logical Shift Code Example

An LED chaser or "Knight Rider" display can be created using the circuit from Figure 8.2 and Figure 8.3 in section 8.2.1 of Chapter 8. This circuit has five LEDs attached to an 8-pin ATtiny microcontroller, from pin PB0 to pin PB4 in order. When the circuit is operated as a LED chaser, it switches a single LED on at the right of the row of LEDs. The LED is left on for a time period, then it is switched off and the LED to the left of it is switched on. After the time period, this LED is switched off and the LED to the left of it switched on, and so on, until the left most LED is on. After the left most LED has been for the time period, the sequence is repeated from left to right this time, where the left most LED is switched off and the LED to the right of it switched on. In the chaser_asm assembly language project that follows, the LED chaser is implemented using left shift and right shift instructions. Create this project in Microchip Studio, and use it with the circuit from Figure 8.2.

```
chaser_asm : main.asm

.def    s_value = r18     ; Shift value register - stores value to shift
.def    dir     = r19     ; Direction register - direction to shift
.equ    s_left  = 0       ; Left shift flag
.equ    s_right = 1       ; Right shift flag

ldi     r16, 0x1F         ; Pins PB0 to PB4 as output pins
out     DDRB, r16
ldi     s_value, 0x01     ; Load shift register with initial value
ldi     dir, s_left       ; Flag initial shift direction as left

loop:
    out     PORTB, s_value    ; Display shift value on LEDs
    rcall   delay
    cpi     dir, s_left       ; Check which direction to shift
    brne    shift_right
    lsl     s_value           ; Rotate the register left
    sbrc    s_value, 5        ; Skip if bit 5 is set
    rjmp    loop
    lsl     s_value           ; Shift the set bit to bit 4
    ldi     dir, s_right      ; Change shift direction to right

shift_right:
    lsr     s_value           ; Rotate the register right
    sbrc    s_value, 0        ; Skip if bit 0 is clear
    ldi     dir, s_left       ; Change shift direction to left
    rjmp    loop

; Delay subroutine
delay:
    ldi     r16, 0xFF

delloop1:
    ldi     r17, 0xFF

delloop2:
    dec     r17               ; Delay by decrementing
    brbc    SREG_Z, delloop2
    dec     r16               ; Delay by decrementing
    brbc    SREG_Z, delloop1
    ret
```

Code from the chaser_asm project is not guaranteed to be the most efficient LED chaser code, but does include the left and right shift instructions and some of the instructions from earlier on in this chapter that have not been used in previous chapters.

At the start of the code, two registers are given names using the .def directive. The s_value register is for holding the shifted value that is written to the LEDs. The dir register is used to remember, or flag, which direction to shift the value to display on the LEDs. Two flag values, s_left and s_right are flags that are saved to the dir register in order to flag which direction to shift the s_value register in. The principle of operation is to start the code with 0b0000_0001 in the s_value register. This value is then written to the LEDs so that the right-most LED switches on. At the start, the dir register flags that the direction to shift the value in the s_value register is to the left. After each shift, the new value in the s_value register is written to the LEDs, and then the delay subroutine is called to leave the new value displayed for a period. There are 5 LEDs on pins PB0 to PB4, which means that after the left shift moves the set bit in s_value into bit 5, zeros will be written to the LEDs if s_value is sent to the LEDs. Bit 5 in s_value is used to detect that the value has been shifted to the left end of the LEDs, and the direction needs to be changed to shift it right. The dir register is updated with the s_right flag, to flag that shifting to the right must now be performed. After the value in s_value is shifted as far right as it can go bit 0 is set, and when tested it indicates that a direction change is needed, so left shifting starts again.

The code starts by writing 0x1F to the DDRB register via R16 in order to enable pins PB0 to PB4 as output pins to drive the 5 LEDs, as shown below.

```
ldi   r16, 0x1F        ; PINS PB0 to PB4 as output pins
out   DDRB, r16
```

In the next two lines of code that follow, firstly s_value is loaded with 0x01, which is the same as 0b0000_0001, so that the right most LED is set when s_value is written to the PORTB register in the loop. Secondly, dir is loaded with the s_left flag, so that the program knows to initially left shift s_value.

```
ldi   s_value, 0x01    ; Load shift register with initial value
ldi   dir, s_left      ; Flag initial shift direction as left
```

The loop starts by writing s_value to PORTB. s_value initially contains 0x01, so the LSB LED is switched on. The delay routine is then called to leave the LED on for a period. Whenever the program jumps back to the top of the loop, the new value in s_value is written to the LEDs, and the delay called again.

```
loop:
  out   PORTB, s_value   ; Display shift value on LEDs
  rcall delay
```
