Figure 2.2 shows the pinout of the Atmel-ICE programming cable. Be sure to plug the small 10-pin connector at the end of this cable into the port marked AVR on the Atmel-ICE, as shown in Figure 2.3. The pinout of the 6-pin connector also applies to the AVRISP mkII and AVR Dragon, using the raised plastic key as a reference to find pin 1. This same pinout applies to any programmer that uses the 6-pin ISP/SPI connection, including hobby programmers that use this connector.
