
## 10.5.1 How Interrupts Work

AVR microcontrollers all have a number of interrupt sources, such as a timer compare match, external interrupt, timer/counter overflow, and others. Each interrupt source has its own enable bit found in one of the interrupt source peripheral registers. For example, the Timer/Counter0 peripheral has a timer/counter interrupt mask register called TIMSK that has interrupt enable bits for the timer overflow and compare matches. To enable one of the compare match interrupts, the corresponding bit in TIMSK is set. In addition to enabling an individual interrupt, the global interrupt enable bit in the status register must be set in order for any individual interrupt to be able to work.

When an interrupt does occur, for example there is a timer compare match, the global interrupt enable bit is automatically cleared, disabling interrupts. The interrupt service routine for the particular interrupt is then called. An interrupt service routine is just like a subroutine, except that to return from it the RETI (Return from Interrupt) instruction must be used instead of the RET instruction. When the RETI instruction is executed at the end of an ISR, the return address is loaded from the stack and the global interrupt enable bit is set, enabling interrupts again.

## 10.5.2 The Interrupt Vector Table

An interrupt vector table allows the correct interrupt service routine, or ISR, to be called when an interrupt occurs. For example, the ISR that was written for a particular timer compare match must be called when the compare match interrupt occurs.

Interrupts are assigned to jump to fixed program memory address locations starting at address 0, when they occur. The interrupt vector table is placed at these fixed program memory locations and consists of jump instructions to jump to the correct ISR code. Interrupt vector tables can be found in section or chapter 9 of the datasheet for ATtiny13(A) and ATtiny25/45/85 devices.

The interrupt vector tables for the ATtiny13(A) and ATtiny25/45/85 are different, so two different code examples follow in the next sub-section. Two examples are included for learning purposes as this makes the code easier to read and understand. Having two separate projects for the two different interrupt vector tables shows what the interrupt vector tables consist of and how they differ. A third project shows how to write the same code so that it can be used on both the ATtiny13(A) and ATtiny25/45/85 ranges.

## 10.5.3 Assembly Program Timer Interrupt

Two assembly language programs that toggle an LED on pin PB4 using an interrupt follow. The first program is for an ATtiny13(A) and the second is for a ATtiny25/45/85.

### 10.5.3.1 ATtiny13(A) Timer Interrupt Project

Create a new AVR assembly language program called timer0_interrupt13.asm in Microchip Studio for the ATtiny13 or ATtiny13A and add the following code to main.asm.

```
timer0_interrupt13.asm : main.asm

.org 0
rjmp    main            ; 0 - Reset vector
rjmp    ISR_unused      ; 1 - External interrupt 0 vector
rjmp    ISR_unused      ; 2 - Pin change interrupt 0 vector
rjmp    ISR_unused      ; 3 - Timer 0 overflow interrupt vector
rjmp    ISR_unused      ; 4 - EEPROM ready interrupt vector
rjmp    ISR_unused      ; 5 - Analog comparator interrupt vector
rjmp    ISR_tim0_compA  ; 6 - Timer 0 compare match A interrupt vector
rjmp    ISR_unused      ; 7 - Timer 0 compare match B interrupt vector
rjmp    ISR_unused      ; 8 - Watchdog timer timeout interrupt vector
rjmp    ISR_unused      ; 9 - ADC conversion complete interrupt vector

main:
sbi     DDRB, DDB4      ; Pin PB4 as output pin
ldi     r16, ( 1 << WGM01)  ; CTC mode for timer
out     TCCR0A, r16
ldi     r16, 0x7F       ; Output compare value
out     OCR0A, r16
ldi     r16, ( 1 << OCIE0A) ; Enable T0A compare match interrupt
out     TIMSK0, r16
sei                   ; Set global interrupt enable bit
ldi     r16, ( 1 << CS02) | ( 1 << CS00) ; Prescaler CLK/1024 and start timer
out     TCCR0B, r16

loop:
rjmp    loop

; Timer 0 compare match A interrupt service routine or handler
ISR_tim0_compA:
sbi     PINB, PINB4     ; Toggle LED
reti

; Dummy interrupt handler to catch all unused interrupts
ISR_unused:
nop
rjmp    ISR_unused
```

### The Interrupt Vector Table

At the start of the code, the full interrupt vector table can be found, as shown below.

```
.org 0
    rjmp    main            ; 0 - Reset vector
    rjmp    ISR_unused      ; 1 - External interrupt 0 vector
    rjmp    ISR_unused      ; 2 - Pin change interrupt 0 vector
    rjmp    ISR_unused      ; 3 - Timer 0 overflow interrupt vector
    rjmp    ISR_unused      ; 4 - EEPROM ready interrupt vector
    rjmp    ISR_unused      ; 5 - Analog comparator interrupt vector
    rjmp    ISR_tim0_compA  ; 6 - Timer 0 compare match A interrupt vector
    rjmp    ISR_unused      ; 7 - Timer 0 compare match B interrupt vector
    rjmp    ISR_unused      ; 8 - Watchdog timer timeout interrupt vector
    rjmp    ISR_unused      ; 9 - ADC conversion complete interrupt vector
```

The RJMP instructions in the above interrupt vector table are specifically placed in order, starting from address 0, so that when an interrupt occurs, program execution will execute the correct RJMP instruction to jump to the correct interrupt service routine. For example, with the timer 0 compare match A interrupt enabled, and with the timer started, when the timer counts up to a value that matches the value set in TCCR0A, the interrupt is triggered. This means that the return address is pushed onto the stack, and program execution jumps to program memory address 6 or 0x0006 on an ATtiny13(A). This is a fixed vector location for the timer 0 compare match A interrupt, and can be found in the ATtiny13 or ATtiny13(A) datasheet. In the above code, there is an RJMP instruction at address 6 that jumps to ISR_tim0_compA, which is the name of the interrupt service routine or interrupt handler that must execute when this interrupt is triggered. This RJMP instruction is at address 0x0006 because the first RJMP instruction that jumps to the main label is at address 0. Counting through the RJMP instructions that follow the first one, we arrive at address 0x0006.

Because other interrupts are not used in this project, all other interrupt vector table entries have been made to jump to a dummy interrupt service routine called ISR_unused. This has been done so that if any other interrupt were accidentally enabled, and that interrupt occurred, program execution would continue at a known location. The code from the dummy ISR is shown below.

```
; Dummy interrupt handler to catch all unused interrupts
ISR_unused:
    nop
    rjmp ISR_unused
```

In the dummy ISR code, a breakpoint could be put on the NOP instruction during program testing to see if execution ever arrived at the dummy ISR. As can be seen in the dummy ISR, the code simply loops and never returns. If the watchdog timer were enabled on the microcontroller, then this would cause the watchdog timer to time out and reset the microcontroller, which may be desirable if program execution ever arrived at an unused interrupt vector.

While the full interrupt vector table has been implemented in this project, this was done for learning purposes and is actually not necessary. The address of each interrupt vector is defined at the end of the include file for the selected microcontroller. For example, at the bottom of the automatically included tn13def.inc file are the following definitions for the ATtiny13 interrupt vectors.

```
; ********* INTERRUPT VECTORS ************************************************
.equ INT0addr = 0x0001 ; External Interrupt 0
.equ PCINT0addr = 0x0002 ; Timer/Counter Overflow 0
.equ OVF0addr = 0x0003 ; EEPROM Ready
.equ ADCCaddr = 0x0004 ; Analog Comparator
.equ ERDYaddr = 0x0005 ; Timer/Counter Compare Match A
.equ OC0Aaddr = 0x0006 ; Timer/Counter Compare Match B
.equ OC0Baddr = 0x0007 ; Watchdog Time-out
.equ WDTaddr = 0x0008 ; ADC Conversion Complete
.equ ADCaddr = 0x0009
.equ INT_VECTORS_SIZE = 10 ; size in words
```

Instead of using the full interrupt vector table in this project, we could use the above definition for the timer 0 interrupt match A vector location as follows.

```
.org 0
rjmp main ; Reset vector
.org OC0Aaddr
rjmp ISR_tim0_compA ; Timer 0 compare match A
main:
sbi DDRB, DDB4 ; Pin PB4 as output pin
...
```

The first RJMP instruction is necessary to jump over the vector table to the main program code after powering up the microcontroller or after a reset.
