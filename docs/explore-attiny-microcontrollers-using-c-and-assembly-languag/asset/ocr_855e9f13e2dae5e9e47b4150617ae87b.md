# 4.6 Summary

+   • A single memory cell can hold a single binary digit or bit that can have a value of 0 or 1.

+   • Memory in a microcontroller is usually arranged as groups of 8 memory cells which can hold 8 bits or one byte.

+   • Each byte of memory has an address that allows it to be accessed by the microcontroller.

+   • Half a byte or 4 bits is known as a nibble.

+   • With a single binary digit, we can count from 0 to 1. To count higher we use additional digits. The value of a binary number can be calculated by looking at the weight of each digit.

+   • Hexadecimal is a compact way of representing binary numbers with one hexadecimal digit representing 4 bits or a nibble.

+   • A calculator with number system conversion functionality such as the Windows calculator can be used to convert between different number systems such as decimal, binary and hexadecimal.

+   • The maximum size of a binary number can be calculated mathematically and the maximum size depends on how many digits the number consists of.

+   • 1K byte of memory is the same as 1024 bytes and not 1000 bytes.

+   • Numbers in AVR assembly language programs can be written in decimal, hexadecimal or binary format.

+   • Numbers in C language programs can be written in decimal or hexadecimal, but the GCC compiler allows numbers written in binary format.

+   • The octal number system consists of 8 digits, but is seldom if ever used.
