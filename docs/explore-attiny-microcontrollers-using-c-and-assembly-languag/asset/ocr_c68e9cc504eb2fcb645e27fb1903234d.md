The Customize dialog box should now look like Figure A.10. Click the Close button in the Customize dialog box. In the above procedure, External Command 1 corresponds to the first external tool added. If additional external tools are to be added, they will correspond to External Command 2, and so on. In this way a button can be added for each external tool.
