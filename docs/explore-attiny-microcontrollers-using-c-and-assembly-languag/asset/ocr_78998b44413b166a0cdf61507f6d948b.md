# The Interrupt Vector Table

At the start of the code, the full interrupt vector table can be found, as shown below.

```
.org 0
    rjmp    main            ; 0 - Reset vector
    rjmp    ISR_unused      ; 1 - External interrupt 0 vector
    rjmp    ISR_unused      ; 2 - Pin change interrupt 0 vector
    rjmp    ISR_unused      ; 3 - Timer 0 overflow interrupt vector
    rjmp    ISR_unused      ; 4 - EEPROM ready interrupt vector
    rjmp    ISR_unused      ; 5 - Analog comparator interrupt vector
    rjmp    ISR_tim0_compa  ; 6 - Timer 0 compare match A interrupt vector
    rjmp    ISR_unused      ; 7 - Timer 0 compare match B interrupt vector
    rjmp    ISR_unused      ; 8 - Watchdog timer timeout interrupt vector
    rjmp    ISR_unused      ; 9 - ADC conversion complete interrupt vector
```

The RJMP instructions in the above interrupt vector table are specifically placed in order, starting from address 0, so that when an interrupt occurs, program execution will execute the correct RJMP instruction to jump to the correct interrupt service routine. For example, with the timer 0 compare match A interrupt enabled, and with the timer started, when the timer counts up to a value that matches the value set in TCCR0A, the interrupt is triggered. This means that the return address is pushed onto the stack, and program execution jumps to program memory address 6 or 0x0006 on an ATtiny13(A). This is a fixed vector location for the timer 0 compare match A interrupt, and can be found in the ATtiny13 or ATtiny13(A) datasheet. In the above code, there is an RJMP instruction at address 6 that jumps to ISR_tim0_compa, which is the name of the interrupt service routine or interrupt handler that must execute when this interrupt is triggered. This RJMP instruction is at address 0x0006 because the first RJMP instruction that jumps to the main label is at address 0. Counting through the RJMP instructions that follow the first one, we arrive at address 0x0006.

Because other interrupts are not used in this project, all other interrupt vector table entries have been made to jump to a dummy interrupt service routine called ISR_unused. This has been done so that if any other interrupt were accidentally enabled, and that interrupt occurred, program execution would continue at a known location. The code from the dummy ISR is shown below.

```
; Dummy interrupt handler to catch all unused interrupts
ISR_unused:
    nop
    rjmp ISR_unused
```
