compare the dir register with the s_left flag. BRNE is then used to branch if the value in dir is not the same as the s_left flag value. Because dir was loaded with an initial value of s_left, a branch does not occur. Instead, the LSL instruction left shifts the value in s_value. SBRS is used to check if the single set bit in s_value has been shifted into the bit 5 position, which indicates that the shift direction must change. SBRS only skips if bit 5 is set. If it is not yet set, then the RJMP instruction below SBRS is not skipped, but causes program execution to continue from the top of the loop where the LEDs are updated with the new s_value, and the delay followed by the next left shift occurs.

```
cpi     dir, s_left         ; Check which direction to shift
brne    shift_right
lsl     s_value             ; Rotate the register left
sbrs    s_value, 5          ; Skip if bit 5 is set
rjmp    loop
lsl     s_value             ; Shift the set bit to bit 4
ldi     dir, s_right        ; Change shift direction to right
shift_right:
lsr     s_value             ; Rotate the register right
sbrc    s_value, 0          ; Skip if bit 0 is clear
ldi     dir, s_left         ; Change shift direction to left
rjmp    loop
```

When enough left shifts have occurred so that bit 5 in s_value is set, SBRS jumps the RJMP instruction below it so that this new left shifted value is not written to the LEDs. LSR is then used to right shift the value in s_value, so that the set bit in this register is lined up with the left most LED, or bit 4. In other words, in synchronizes the value in s_value with the current state of the LEDs, because the last left shifted the set bit too far left. s_value is now loaded into the dir register to flag that right shifting must now commence. LSR is used to right shift s_value again. Because the left most LED, or bit 4, has already been on for the delay period, the right shift is done to set the next LED to the right, or bit 3. SBRC is then used to check bit 0 to see if it is time to reverse direction. As direction has just been changed, at this stage bit 0 is clear, and SBRC skips over the next instruction that would flag the direction change to the left. Finally the bottom RJMP instruction is executed, and the new right shifted value in s_value is written to the LEDs.

Now that the right shift flag s_right is in the dir register, when the CPI and BRNE instructions are executed, BRNE branches to the shift_right label. This is because the comparison result is that the value in dir is not equal to s_left. At shift_right, LSR shifts the value in s_value right again. This will happen each time through the loop until the single set bit in s_value reaches bit position 0. This triggers the direction change under SBRC.
