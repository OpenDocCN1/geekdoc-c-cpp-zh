# 6.6.1 How the Stack Works

A register that is to be saved to the stack is "pushed" onto the stack. This copies the value from the register to a SRAM memory location currently pointed to by the stack pointer. A value that is to be retrieved from the stack is "popped" from the stack to a particular register. A stack can be thought of like a stack of boxes. A box is put down (pushed). Another box is put on top of the first box (a second push), a third and fourth box can be added to the stack of boxes. When a box is taken from the stack (popped) the top box is removed first. This is a "last in first out" (LIFO) arrangement. Boxes can only be popped in the reverse order in which they were pushed.
