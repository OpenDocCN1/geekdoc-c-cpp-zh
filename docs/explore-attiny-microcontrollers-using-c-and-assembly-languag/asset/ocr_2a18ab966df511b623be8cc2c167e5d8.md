Again we have an unknown result of the calculation, and a variable which is the number of passes through the loop. The unknown result will be called CT for total clock cycles.

Written with the second letter as a subscript, we have:

# **C_T – total clock cycles**

For the outer loop count variable, which is placed in register R16 in this code, it will be called VOL for value or variable (V) of the outer loop (OL). Written with the second two letters as subscript, we have:

# **V_OL – value or variable of outer loop**

Taking our calculation, we can say the following:

```
C_T = 1 + ((1 + inner_loop + 1 + 2) x 2) + (1 + inner_loop + 1 + 1)
```

The 2 in bold in the above formula is actually 3 – 1, or V_OL – 1, which changes the formula to the following when substituted in:

```
C_T = 1 + ((1 + inner_loop + 1 + 2) x (V_OL – 1)) + (1 + inner_loop + 1 + 1)
```

Substituting in the number of clock cycles for the inner loop, represented by C_IL, we get:

```
C_T = 1 + ((1 + C_IL + 1 + 2) x (V_OL – 1)) + (1 + C_IL + 1 + 1)
```

Simplification by adding known values, we now get:

```
C_T = 1 + ((C_IL + 4) x (V_OL – 1)) + (C_IL + 3)
```

Further simplification results in:

```
C_T = ((C_IL + 4) x (V_OL – 1)) + C_IL + 4
```

Working out the multiplication results in:

```
C_T = C_IL V_OL – C_IL + 4V_OL – 4 + C_IL + 4
```

Which simplifies to:

```
C_T = C_IL V_OL + 4V_OL
```
