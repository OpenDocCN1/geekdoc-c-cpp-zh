Now that the test_asm project has been changed to build for the ATtiny25, SPH is no longer defined for the project. This means that when the assembler program reaches the line with .IFDEF SPH, it does not include the two lines of code between IFDEF and ENDIF. We can check this with the start debug and break button in Microchip Studio, and then by opening the Disassembly window as we did before. The disassembled code now looks as follows.

```
ldi    r16, low(RAMEND)
00000000 LDI R16,0xDF    Load immediate
       out    SPL, r16
00000001 OUT 0x3D,R16    Out to I/O location
       ldi    r16, 0x8A    ; Load a value to R16
00000002 LDI R16,0x8A    Load immediate
       push   R16        ; Save R16 to the stack
```

Only two instruction appear before the LDI instruction that loads 0x5A to R16, as can be seen in the disassembled code above. The first two lines of code initialize SPL, but the code that initializes SPH has been left out, as expected because of the conditional assembly directives IFDEF and ENDIF.

Stop the debugger and change the device for the test_asm project back to ATtiny45. Click the button on the toolbar that should now say ATtiny25, and then use the Change Device... button to select the ATtiny45 again. Save and rebuild the project.

# 9.4 Other Assembly Language Elements

The AVR Assembler program does have more assembler directives and other elements that it recognizes, such as preprocessor directives, functions and operators. We did see the left shift operator (<<) in use when looking at DB. We have also used the high() and low() functions to get the high and low bytes of 16-bit numbers. All of these elements are used to make programming in assembly language easier. This chapter has been an introduction to how some of these elements can be useful. There is no point in covering every possible assembly language element in this book, as it will just result in an information overload. Further elements of assembly language are covered and used in practical programs throughout the remaining chapters. The AVR Assembler document from Microchip can be used as a reference when using the AVRASM2 assembly program, and also to learn about other assembly language elements.
