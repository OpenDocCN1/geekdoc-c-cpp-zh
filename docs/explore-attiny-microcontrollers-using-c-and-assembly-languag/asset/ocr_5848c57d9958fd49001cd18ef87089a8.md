# 2.3.2 LED Blink Assembly Code

Replace the skeleton code in main.asm created in the previous section, with the code shown in the led_blink.asm : main.asm listing that follows. If using an alternate circuit from Appendix B that has the LED connected to pin PB0 of the ATtiny, then use the alternate code from section B.5.1 of Appendix B. When learning any new programming language, it is best to type the code in yourself, rather than to copy and paste it. It is not necessary to type the comments at this stage – comments start with a semicolon ( ; ) and describe what is happening in the program. Use the Tab key to indent the code as shown in Figure 2.6. In some cases you may need to press Tab twice to align the text properly. Make sure that you type everything in exactly as shown in the code listing.

It is a good idea to carefully check the code typed into the main.asm file line by line to make sure that there are no typing errors. Being diligent when typing and checking code is the mark of a good programmer. After typing the program into the main.asm file of the led_blink_asm project, save the file by using the Ctrl + S keyboard shortcut, File ▶ Save from the top menu, or by using the Save icon on the top toolbar.
