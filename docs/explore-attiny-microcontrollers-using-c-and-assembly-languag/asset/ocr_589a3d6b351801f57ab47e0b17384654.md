The debugger can now be started in the same way as it was with the simulator. Make sure that the power to the target AVR circuit is on. Click the Start Debugging and Break icon on the second top toolbar at the left, or use the Alt + F5 keyboard keys. Step through the assembly language instructions using the F10 key or the Step Over icon on the second top toolbar. Everything will behave the same as the simulator, except when the SBI and CBI instructions in the loop are executed, the LED will switch on and off on the physical hardware circuit.

When you have finished experimenting with the debugger, click the Stop Debugging icon on the second top toolbar (the red square ■). Leave the AVR in debugWIRE mode for now so that the debugger can be used. Only the debugWIRE line (which is also the RESET line), +5V and GND need to be connected when using debugWIRE mode.
