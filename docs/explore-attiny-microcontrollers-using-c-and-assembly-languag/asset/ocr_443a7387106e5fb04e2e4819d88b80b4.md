```
C_T = \frac{f_{CPU} \times t_{ms}}{10000} - 1
```

First get rid of the -1 by adding 1 to both sides of the equation.

```
C_T + 1 = \frac{f_{CPU} \times t_{ms}}{10000}
```

Now get rid of the 10000 from under the right side of the equation by multiplying both sides by 10000 and swap the left and right sides around because we want t_ms to be on the left.

```
f_{CPU} \times t_{ms} = 10000(C_T + 1)
```

To get rid of f_CPU on the left, divide both sides by f_CPU.

```
t_{ms} = \frac{10000(C_T + 1)}{f_{CPU}}
```

We decided to use the value 2^32 - 1 for C_T and 20MHz for f_CPU, so we can substitute these values into the formula and calculate the maximum value of t_ms.

```
t_{ms} = \frac{10000(2^{32} - 1 + 1)}{20 \times 10^6}
= 2,147,483.648
```

The final result has a fractional part, which must be removed because our 32-bit number must be an integer or whole number. 2,147,483 is therefore the biggest millisecond value that can be used with a CPU frequency of 20MHz.
