Summarizing our formulas, we have:

# Inner loop:

C_IL = 3V_IL + 1

where:

C_IL – total clock cycles of inner loop

V_IL – value or variable of inner loop

# Outer loop:

C_T = C_IL V_OL + 4V_OL

where:

C_T – total clock cycles

V_OL – value or variable of outer loop

C_IL – total clock cycles of inner loop

The above formulas can be further simplified into one formula by substituting the inner loop formula into the outer loop formula:

C_T = (3V_IL + 1)V_OL + 4V_OL

Which multiplies out to:

C_T = 3V_IL V_OL + V_OL + 4V_OL

This can be simplified to:

C_T = 3V_IL V_OL + 3V_OL

Which can be written:

C_T = 3(V_IL V_OL + V_OL)

It can also be written with the register names instead of the symbols that we have been using, which will make the formula a bit easier to use when looking at the code:

C_T = 3 × (R17 × R16 + R16)
