# ## 7.5 Other Arithmetic and Logic Instructions

In this chapter we have looked at some of the basic arithmetic and logic instructions from the AVR instruction set. DEC (Decrement) is grouped with arithmetic and logic instructions in the instruction set summary found in AVR ATtiny datasheets. DEC was used in the LED blink program as part of the delay subroutine. INC (Increment) is the counterpart of DEC which simply increments the value in a register by one. Refer to the instruction set summary and the AVR Instruction Set Manual for other arithmetic and logical instructions that are available in the AVR and for a description of what these instructions do. # ## 7.6 Summary

+   - Signed numbers in AVR microcontrollers are stored in 2's compliment format.
+   - AVR microcontrollers have addition and subtraction arithmetic instructions.
+   - Flags in the Status Register are set or cleared depending on the result of an arithmetic or logic operation.
+   - If the result of an arithmetic operation is too big to store in an 8-bit register then the carry flag is set in the status register.
+   - Logic instructions perform logical operations on registers and immediate data according to their respective truth tables.
+   - AVR microcontrollers have AND, OR and EOR logic instructions.
+   - The instruction set summary section of the datasheet of an AVR microcontroller lists all of the instructions that are implemented in a particular AVR part.
+   - A detailed description of arithmetic, logic and other AVR instructions can be found in the AVR Instruction Set Manual.
