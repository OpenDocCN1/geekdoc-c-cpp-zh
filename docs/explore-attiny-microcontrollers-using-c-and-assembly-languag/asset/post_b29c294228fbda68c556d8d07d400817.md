```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

Both the USBasp and USBtinyISP must be passed usb after -P. For the ArduinoISP which appears as a virtual COM port, the COM port number must be specified after -P, for example COM3, if this is the port number that the Arduino is assigned when plugged into a USB port. For the ArduinoISP only, a baud rate must be specified using -b, which can be placed after the -P switch and the port type. This must be -b 19200.

Finally we get to the -U switch which specifies that a memory operation is to be performed. Note that this is an uppercase U. The -U switch is followed by the memory type, operation to perform, and the file name, all separated by colons. In our example the memory type is Flash program memory and the operation is a write operation. An example file called file.hex is shown. These options are passed to avrdude after the -U switch as flash:w:"file.hex", where flash specifies Flash memory, w specifies a write operation and file.hex is the name of the file that contains the program to load. The file name does not need to be placed between quotes, but when a path to the file is included that has one or more space characters in it, the quotes are necessary. The file is generated in Microchip Studio as part of the build process and is in hexadecimal format.

Now that we have an understanding of what must be passed to avrdude in order to specify the target AVR to be programmed, the programmer being used, and the operation for it to perform, we can look at parameters for the specific programmers covered in this appendix. The three sections that follow show the command-line parameters, or arguments, needed by avrdude for a USBasp, USBtinyISP, and an Arduino Uno with the ArduinoISP sketch loaded. These parameters are then used in section A.3.5 that follows to set up the external programmers in Microchip Studio.

## A.3.4.3 Parameters for a USBasp

Parameters passed to avrdude for a USBasp are the same as the example that was used in the previous section, and are shown again below.

```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

Be sure to change the part to the part that you are going to program. Use Table A.1 to find the correct part code. Remember that if you experience any problems with your USBasp, you may need to follow the -c option with usbasp-clone instead of usbasp.

## A.3.4.4 Parameters for a USBtinyISP

For a USBtinyISP, use the following parameters.

```
avrdude -p t85 -c usbtiny -P usb -U flash:w:"file.hex"
```

Remember to select the correct part that you are using from Table A.1 and place it after the -p switch.

## A.3.4.5 Parameters for an ArduinoISP

For an Arduino Uno loaded with the ArduinoISP sketch, use the following parameters.

```
avrdude -p t85 -c avrisp -P COM3 -b 19200 -U flash:w:"file.hex"
```

Change the part after the -p switch to the ATtiny being used, as per Table A.1. Find and specify the correct COM port after the -P switch. This can be found either using the Device Manager in Windows, or using the Arduino IDE.

## A.3.5 Microchip Studio External Tool Setup

Microchip Studio has an option for setting up external programming tools which allows avrdude to be run from within Microchip Studio. Command-line options for avrdude are included as part of the setup, which allows Microchip Studio to pass these options to avrdude when it is called. The correct program file is also automatically passed to avrdude so that it is loaded to the Flash program memory of the target AVR.

At this stage it is assumed that you have followed each part of this appendix from the beginning, and have an AVR circuit built on breadboard with one of the supported hobby programmers correctly connected. To set up one of the hobby programmers as an external programming tool in Microchip Studio, complete each step in the subsections that follow.

### A.3.5.1 Open an Assembly or C Project

Start Microchip Studio and open either the led_blink_asm or led_blink_c projects that were created in Chapter 2 in section 2.3.2 and section 2.4.2 respectively. If you are using one of the alternative circuits from Appendix B that has the LED and series resistor connected to pin PB0, then use one of the alternative programs from section B.5 of Appendix B.

### A.3.5.2 Add an External Tool in Microchip Studio

In Microchip Studio, select Tools ▶ External Tools... from the top menu. This opens the External Tools dialog box. If no other tools have been set up in this dialog box, you can start entering information into the various fields to set up an external tool. If one or more external tools have already been set up, you will need to click the Add button first. Figure A.9 follows showing the External Tools dialog box. Fill in the fields as follows.

### Title: USBasp ATtiny85

This can be any text you want. A good idea is to include the programmer name and target device being used, for example: USBasp ATtiny85

### Command: C:\avrdude-6.3-mingw32\avrdude.exe

Assuming that you installed avrdude to a folder called avrdude-6.3-mingw32 in the root of the C: drive, then the command field must contain the text as shown above. To avoid having to type this line in manually, click the button marked ... at the end of the Command field to open up the Open File dialog box. Use this dialog box to navigate to the folder containing avrdude. Once in the folder, click the avrdude.exe file to select it and then click the Open button in the dialog box.

### Arguments: Programmer and part specific, see below.

Programming parameters for avrdude that we looked at in section A.3.4 must be placed in the Arguments field. These are the command-line options that must be passed to avrdude. Because we have already specified the avrdude executable file in the Command field, we must leave it off the beginning of the avrdude parameters.

We also need to add macros to the parameters so that the path to the hexadecimal file to be loaded to Flash memory is passed to avrdude. The parameters to place in the Arguments field are as follows for the three hobby programmers.

### USBasp

```
-p t85 -c usbasp -P usb -U flash:w:"$(OutDir)Debug\$(TargetName).hex"
```

### USBtinyISP

```
-p t85 -c usbtiny -P usb -U flash:w:"$(OutDir)Debug\$(TargetName).hex"
```

### ArduinoISP (Arduino Uno with ArduinoISP sketch loaded)

```
-p t85 -c avrisp -P COM3 -b 19200 -U flash:w:"$(OutDir)Debug\$(TargetName).hex"
```

The part number after the `-p` switch must be changed to the correct code for the ATtiny being used in each of the lines above. Refer back to Table A.1 in section A.3.4.2 in this appendix to find the codes for ATtiny parts. Change the ArduinoISP COM port to the correct number. Copy the line to the Arguments field of the External Tools dialog box.

In the above lines, two macros are used: one to find the path to the hexadecimal file, and the other to get the name of the hexadecimal program file. The macro `$(OutDir)` resolves to the path to the current project. This is followed by `Debug` to add the Debug folder to the end of the path. The hexadecimal file is found in the Debug folder of a Microchip Studio project. The macro `$(TargetName)` resolves to the name of the current project, which is also the name of the hexadecimal program file. It is followed by `.hex` in the above lines, because the hexadecimal ends with a `.hex` file extension.

### Initial directory: $(ProjectDir)

Placing the $(ProjectDir) macro in this field allows Microchip Studio to automatically find the path to the current project folder and start avrdude from this folder.

### Use Output window

This field is a checkbox. Click the box so that a check mark appears in it.
