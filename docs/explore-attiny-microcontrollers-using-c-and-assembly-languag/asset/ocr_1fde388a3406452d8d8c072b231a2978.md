# Appendix B • Alternate Circuits and Programs

This appendix contains circuits for all of the PDIP packaged ATtiny microcontrollers from Table 1.1 in Chapter 1. It also has connections for USB programmers that use ISP, the USBasp 10-pin header, and the Arduino Uno used as an ISP programmer, as discussed in Appendix A.

The circuits in this appendix after Figure B.1 use alternate ATtiny PDIP microcontrollers to the circuit of Figure 2.1 in section 2.2 of Chapter 2. These circuits are for readers who want to use different ATtiny devices, and for those readers who are using the ISP/SPI programming interface only (not using debugWIRE) — using ATtiny devices with higher pin counts leaves more pins free when using ISP programming.

When the LED in a circuit is interfaced to a different I/O pin to that of Figure 2.1, an equivalent program to that of the led_blink_asm program from section 2.3.2 and the led_blink_c program of section 2.4.2, both from Chapter 2, is included.
