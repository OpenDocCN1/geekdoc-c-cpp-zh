# 2.5 Summary

+   - Microchip Studio is a complete development environment used to develop software for AVR microcontrollers. Microchip Studio is known as an IDE (Integrated Development Environment) and includes a text editor, as well as assembler, C compiler and other programming tools.

+   - Atmel Studio was rebranded to Microchip Studio in 2020.

+   - When writing a new assembly language or C program using Microchip Studio, a new project must be started.

+   - Assembly language and C programs are written in text using the text editor in Microchip Studio.

+   - If there are any syntax errors in a program, they will be caught during the build process.

+   - After building a program, it can be loaded to a microcontroller using a USB programming tool such as an Atmel-ICE or hobby programmer.

In the next chapter we look at the basics of assembly language programs, in order to gain enough knowledge to understand what is happening in a program when using the simulator and debugger. The basic operation of the LED blink program is explained and is run in both the simulator and on an AVR LED circuit using the hardware debugging capabilities of the Atmel-ICE.
