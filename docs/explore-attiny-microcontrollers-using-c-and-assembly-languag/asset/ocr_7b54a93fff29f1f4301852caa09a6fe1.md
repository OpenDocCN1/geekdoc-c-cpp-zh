After adding the new wait_ms.asm assembly language file to the project, it automatically opens in Microchip Studio, and can be seen in the right Solution Explorer pane. Replace the comments in this new file with the code from the **wait_ms.asm : wait_ms.asm** listing found at the beginning of this section.

Build the project and see if it produces two error messages: **Undefined symbol: wait_ms**. If these messages occur, they appear in the Error List pane at the bottom of Microchip Studio. To fix this error, be sure to hit the Enter key when the cursor is at the end of the last line of code in main.asm to add a newline to the end of the file. A comment is shown in this position in the code listing as follows.

```
.include "wait_ms.asm"
; Must put newline here
```

After adding a newline after the .include directive, build the project again and this time it will build without errors, assuming there were no typographical errors added when entering the code into the files. Note that the main code in this new project blinks an LED on pin PB4 again, but this time uses a modified version of the previous delay subroutine. Before testing the code in the simulator or on real hardware, be sure to change the value assigned to F_CPU at the top of the main.asm file to suit the clock frequency of the microcontroller that you are using. Build the project again if changes are made to F_CPU.
