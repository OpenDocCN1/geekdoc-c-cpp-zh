### A.3.1.3 Arduino Uno Sketch

To use an Arduino Uno as a programmer, a sketch must be loaded to the Arduino. Although other Arduino boards besides the Arduino Uno could be used, only the Uno is covered in this book as it is the most popular Arduino model. These instructions were tested on a genuine Arduino Uno R3 board from www.arduino.cc. Download the Arduino IDE from www.arduino.cc/en/software and install it to the host computer. Find installation instructions at www.arduino.cc/en/Guide for installing the IDE. After installing the Arduino IDE, run the Arduino IDE application and plug the Arduino Uno into a USB port of the host computer. Windows 10 computers will automatically install a driver for a genuine Arduino Uno R3.

In the Arduino IDE, open the ArduinoISP example sketch by selecting File ▶ Examples ▶ 11.ArduinoISP ▶ ArduinoISP from the top menu. Select the Arduino Uno as the target board by selecting Tools ▶ Board ▶ Arduino AVR Boards ▶ Arduino Uno from the top menu of the IDE. Select the correct port for the Arduino Uno under Tools ▶ Port from the top menu. The Arduino Uno must be plugged into a USB port for it to appear on the Port menu. Finally, with the ArduinoISP sketch window selected, click the Upload button, or select Sketch ▶ Upload using the top menu. The Arduino IDE will compile and upload the sketch to the target Arduino Uno, making it into a ISP programmer. Close the Arduino IDE application. Unplug the Arduino from the USB port before connecting it to a circuit.

At this stage, the Arduino Uno is ready to be used as a ISP/SPI programmer. In the next section, section A.3.2, the avrdude programming software is installed.

### A.3.2 Download and Install avrdude

Programming software, called avrdude, must be downloaded, unzipped and manually installed. This is done by simply copying it, and an accompanying configuration file, to a folder on the host computer.

Visit download.savannah.gnu.org/releases/avrdude/ and scroll down the page to find the newest version of avrdude. At the time of writing, the newest version of avrdude was version 6.3. Click the link called avrdude-6.3-mingw32.zip to download the zipped file that has this same name.

If you have 7-Zip (from www.7-zip.org) installed on your computer, simply right-click the downloaded file and then select 7-Zip ▶ Extract to "avrdude-6.3-mingw32" on the menu that pops up. This creates a folder called avrdude-6.3-mingw32 and extracts the two files from the zip file to it.

If you are not using 7-Zip, you will need to manually make a folder called avrdude-6.3-mingw32 in one instance of Windows File Explorer, and then double-click the avrdude-6.3-mingw32.zip zip file in another instance of File Explorer. Drag the two files from the opened zip file to the newly created folder.

To install avrdude, simply move the newly created folder containing avrdude to the root of the C: drive. It does not have to be placed there, but this makes finding it a lot easier, and referencing its path a lot shorter. Open a second instance of Windows File Explorer, and navigate directly to Local Disk (C:), or via This PC ▸ Local Disk (C:). Now drag and drop the avrdude-6.3-mingw32 folder to this location. Figure A.8 shows the folder copied to the C: drive. It should contain two files that were extracted from the zip file, namely avrdude.conf, and avrdude.exe.

### A.3.3.1 Connecting a USBasp

The 10-pin header of the USBasp is included in all of the circuits of Appendix B, and has the reference designator J2. This is actually an older AVR programming header that was replaced by the now common 6-pin ISP/SPI header that has the reference designator J1 in each of the circuits in the figures of Appendix B. The actual original 10-pin header has GND connections where the USBasp in the figures has n.c., indicating not connected pins. In the original USBasp design from Thomas Fischl, pin 4 and 6 of the 10-pin header are connected to pins on the microcontroller on the USBasp. On the version of the USBasp shown in Figure A.1 at the beginning of this chapter, these pins are not connected, as indicated in the Figures of Appendix B.

Before connecting a USBasp to an AVR microcontroller, it is important to decide if the AVR circuit is to be powered from the USBasp, or if an external power supply is to be used. If the circuit is to be powered by the USBasp, then connect the +5V pin from the USBasp connector to +5V of the circuit, which connects to the AVR VCC pin. If the AVR circuit is to be powered from an external power supply, then do not connect the +5V pin of the USBasp to the circuit – leave it disconnected.

There are three different ways to connect a USBasp to an ATtiny microcontroller:
- directly from the 10-pin header on the board
- from a 10-pin female connector at the end of a ribbon cable plugged into the header on the USBasp
- from a 10-pin to 6-pin adapter connected to the USBasp via a ribbon cable

These connections are each described under the headings that follow.

### 10-pin Male Header

Dupont wires with a female connector on one end and a male connector on the other end can be used to connect directly from the 10-pin male header on the USBasp to an ATtiny microcontroller on a breadboard. If using this method, the connections shown on the USBasp connector, J2, in each of the figures of Appendix B must be used. J2 is a top view of the 10-pin male header on the USBasp.

### 10-pin Female Connector on Ribbon Cable

Plugging a ribbon cable, with a 10-pin female connector at each end, into the male connector on the USBasp allows Dupont wires with a male connector on each end, or single-strand wires, to connect from the female connector to a breadboard circuit.
