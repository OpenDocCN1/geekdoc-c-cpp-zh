# 5.4.2 Store and Load Example in the Simulator

Build the test project that contains the code from the previous listing and start the debugger (start and break as done previously, remember that this can be done quickly by just pressing the F10 key), so that we can see what the program does in the AVR simulator.

When the debugger starts running, there should be a memory window visible at the bottom right of Microchip Studio as shown in Figure 5.4. If this memory window is not visible, select Debug ▶ Windows ▶ Memory from the top menu and then select one of the four possible memory windows from the sub-menu that appears. Use the drop down list at the top left of the memory window called Memory: to select data IRAM as shown in Figure 5.4. When data IRAM is selected, the memory window displays the contents of the internal SRAM starting at address 0x60.

Make sure that the Processor Status window is open, as used in previous examples. This is where there is a bug in the debugger/simulator of Microchip Studio used at the time of writing. For ATtiny13(A) and ATtiny25 devices, the memory window does not display the contents of the memory when data IRAM is selected. Selecting the ATtiny45 device solves this problem.

Step over the first instruction (LDI) in the program, and the value 0xAA is seen loaded to register R16 in the Processor Status window. After stepping over the STS instruction, observe that the value 0xAA from R16 is now stored at address 0x60 in SRAM as can be seen in the memory window. It is shown in lowercase letters as aa in the memory window.
