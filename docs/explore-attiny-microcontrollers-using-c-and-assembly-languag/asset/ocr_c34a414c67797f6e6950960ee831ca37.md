# 6.1.2.3 RC Oscillator Accuracy

Because the default clock for the AVR is derived from an RC oscillator it is not as accurate as a clock from a quartz crystal oscillator. An accuracy of ±10% is given in the datasheet for the RC oscillator. This accuracy is specified when operating the AVR from 3V at a temperature of 25°C.

# 6.1.2.4 Clock Sources and Improving Accuracy

An external quartz crystal can be used on the ATtiny25/45/85 to produce a more accurate clock source, but this uses up two pins of the microcontroller. This is one of the ways where ATtiny25/45/85 devices differ from ATtiny13(A) devices – ATtiny13(A) devices only have three clock sources to choose from, namely, an external clock input, internal RC oscillator, and internal 128kHz oscillator. This means that ATtiny13(A) devices do not have a crystal oscillator circuit, so can't use an external crystal or ceramic resonator directly on two pins. ATtiny25/45/85 devices on the other hand, have all of the clock sources that ATtiny13(A) devices have as well as a high frequency PLL clock, an additional internal RC oscillator source, a low-frequency crystal oscillator (uses an external 32.768kHz watch crystal), and a crystal oscillator / ceramic resonator derived clock (uses and external quartz crystal or ceramic resonator).

Another way of improving the accuracy of the oscillator is to follow a calibration procedure for the RC oscillator that uses a calibration register in the AVR. Alternatively an external clock source can be used that will use only one extra pin of the microcontroller.

# 6.1.2.5 Calculating Clock Period from Frequency

If an AVR is operating at 1MHz, then the period of its clock or clock pulse is 1µs (one microsecond). This means that an instruction that takes one clock cycle to run will be executed in 1µs. To convert from frequency to period, use the formula:

$t = \frac{1}{f}$ Where t is the time period and f is the frequency.

It is easy to convert between clock frequency and period using a calculator as follows. For a 1MHz frequency we divide one by one million and get 0.000001 or 1µs. To do this on the Windows calculator, first put the calculator into scientific mode using the top left menu icon. Click 1, +, 1, exp, 6, and then = which displays a result of 0.000001. Click the F-E button on the calculator and the result now displays as 1.e-6.
