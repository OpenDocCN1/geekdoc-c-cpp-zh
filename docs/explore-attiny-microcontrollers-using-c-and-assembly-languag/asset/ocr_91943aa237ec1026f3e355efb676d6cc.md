Plug the USBasp into a spare USB port on the Windows computer. Windows will try to install a driver for the USBasp, but fail, even through it reports that the device is ready. To verify that Windows has found the USBasp, but automatic driver installation failed, right-click the Windows Start button, and then select Device Manager on the menu that pops up. USBasp should be visible under Other devices in the Device Manager window. It will have a triangle icon on it, indicating that a driver was not installed, as shown in Figure A.2.

Run the Zadig executable program by navigating to it using Windows File Explorer, and then double-clicking it. Windows will pop up a dialog box asking Do you want to allow this app to make changes to your device? Click Yes in this dialog box. In the Zadig update policy dialog box, you can optionally click No to stop Zadig from checking for application updates online, as this is not necessary if the newest version of the software was downloaded. When the Zadig application window opens, it should automatically have the USBasp selected, as shown in Figure A.3, assuming that the USBasp is plugged into a USB port of the computer. Click the down arrow next to the box that contains WinUSB, as indicated in Figure A.3, so that libusb-win32 is selected, as shown in Figure A.4.

Click the Install Driver button to install the selected driver. Zadig now pops up a dialog box to show that the driver is busy installing. After the driver has finished installing, a dialog box pops up to show that the driver was installed successfully. Click the Close button in this dialog box. Close the Zadig application window.
