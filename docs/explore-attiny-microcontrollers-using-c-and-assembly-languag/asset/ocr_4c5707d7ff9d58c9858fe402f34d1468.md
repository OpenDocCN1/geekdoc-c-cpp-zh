The sei() macro is made available by including the interrupt.h file in order for the global interrupt enable bit, or I bit, in the status register to be set. As before, the timer is started by selecting the system clock divided by 1024 as the timer 0 clock source.

```
timer0_interrupt.c : main.c

#include <avr/io.h>
#include <avr/interrupt.h>

#ifndef TIMSK
#define TIMSK TIMSK0
#endif

int main(void)
{
  DDRB = (1 << DDB4);       // Pin PB4 as output pin
  TCCR0A = (1 << WGM01);    // CTC mode
  OCR0A = 0xFF;             // Output compare value
  TIMSK = (1 << OCIE0A);    // Enable T0A compare match interrupt
  sei();                    // Set global interrupt enable bit
  TCCR0B = (1 << CS02) | (1 << CS00); // Prescaler clk/1024 and start timer
  while(1) {
  }
}

ISR(TIM0_COMPA_vect)
{
  PINB = (1 << PORTB4);     // Toggle pin PB4/LED
}

```

Because C does not have a standard way to handle interrupts, compiler manufacturers implement their own ISR scheme. In the AVR GCC C compiler used by Microchip Studio, an interrupt service routine must use the ISR() macro that is defined in the interrupt.h file, as can be seen at the bottom of the above code listing. The name of the interrupt to implementation must be passed to the ISR() macro. Interrupt names are found in the header file for the AVR part chosen in Microchip Studio, for example the iotn13.h file for the ATtiny13(A) or the itn45.h for the ATtiny45. The correct file for the chosen part is automatically included in the project by including io.h in the project. This file can be found and opened by expanding the Dependencies folder in the Solution Explorer pane at the right of Microchip Studio. The definition name for the timer 0 compare match A interrupt that must be passed to the ISR() macro is found here and is called TIM0_COMPA_vect.
