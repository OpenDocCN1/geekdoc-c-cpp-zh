# B.2 14-Pin PDIP ATtiny24/44/84

Figure B.2 shows how to connect a programmer to a 14-Pin PDIP ATtiny from the ATtiny24/44/84 range. It includes connections to a 10-pin USBasp connector, ISP/SPI connector and Arduino Uno set up as an ISP programmer.

![](bbox=[0.11, 0.225, 0.86, 0.595])

There is no PB4 on this range of microcontrollers, so the LED is attached to PB0 instead. This means that the led_blink_asm and led_blink_c programs from Chapter 2 must be changed to use pin PB0 instead of pin PB4. Refer to section B.5 of this appendix for alternatives to the assembler and C programs that blink the LED attached to pin PB0.

If using a 10-pin to 6-pin adapter with the USBasp, then wire it according to the ISP/SPI connection. If using a USBtinyISP programmer, use the ISP/SPI wiring. When using an Arduino Uno as an ISP programmer, reset from digital pin 10 must be used, but the other connections can be taken from the socket connector at the edge of the board, or from the Arduino Uno ICSP header. Don't take reset from the Arduino Uno ICSP header, which is marked with an X. Orientation of the Arduino Uno headers in the circuit is with the USB connector of the Arduino Uno on the left.
