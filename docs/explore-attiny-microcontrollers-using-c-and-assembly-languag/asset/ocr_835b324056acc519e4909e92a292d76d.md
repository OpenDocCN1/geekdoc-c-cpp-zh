# 8.2.3 Limiting a Count Value

In the led_count_limit.asm project code that follows, the same incrementing count is displayed on the LEDs as the led_count.asm code, but this time the maximum count value is limited by a branch instruction and a clear instruction, instead of using the ANDI instruction. Because the ANDI instruction is not used, register R0 to R15 can be used as the count register. R0 has been selected for the count register for this example.
