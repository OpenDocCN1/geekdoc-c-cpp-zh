# A.3.5.1 Open an Assembly or C Project

Start Microchip Studio and open either the led_blink_asm or led_blink_c projects that were created in Chapter 2 in section 2.3.2 and section 2.4.2 respectively. If you are using one of the alternative circuits from Appendix B that has the LED and series resistor connected to pin PB0, then use one of the alternative programs from section B.5 of Appendix B.

# A.3.5.2 Add an External Tool in Microchip Studio

In Microchip Studio, select Tools ▶ External Tools... from the top menu. This opens the External Tools dialog box. If no other tools have been set up in this dialog box, you can start entering information into the various fields to set up an external tool. If one or more external tools have already been set up, you will need to click the Add button first. Figure A.9 follows showing the External Tools dialog box. Fill in the fields as follows.

# Title: USBasp ATtiny85

This can be any text you want. A good idea is to include the programmer name and target device being used, for example: USBasp ATtiny85

# Command: C:\avrdude-6.3-mingw32\avrdude.exe

Assuming that you installed avrdude to a folder called avrdude-6.3-mingw32 in the root of the C: drive, then the command field must contain the text as shown above. To avoid having to type this line in manually, click the button marked ... at the end of the Command field to open up the Open File dialog box. Use this dialog box no navigate to the folder containing avrdude. Once in the folder, click the avrdude.exe file to select it and then click the Open button in the dialog box.
