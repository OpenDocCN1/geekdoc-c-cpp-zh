Eight bits are used to encode the constant data value in the instruction. This leaves only four bits to address the destination register. The maximum number of address values that a four bit number can have is 2^4 = 16 (with addresses 0 to 15). The instruction is only capable of addressing 16 registers which have been chosen as R16 to R31 by using an internal offset of 16 on the encoded address.

Various letters or combinations of letters are used to represent registers, operands and bits used in the AVR instruction set manual. The meaning of each of these letters can be found in the fist section of the AVR Instruction Set Manual, called Instruction Set Nomenclature. It is necessary to refer to the meanings of these letters when reading about any instruction in the manual. For example, under the LDI instruction description, the operation of the instruction is given as: Rd <- K

From the Instruction Set Nomenclature section of the manual, K is constant data and Rd is the destination register. The operation therefore means that constant data (K) is loaded into the destination register (Rd).
