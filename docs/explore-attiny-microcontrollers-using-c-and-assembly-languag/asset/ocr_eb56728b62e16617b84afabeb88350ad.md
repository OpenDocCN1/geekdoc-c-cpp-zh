Save the code and build the project. Choose the Simulator as the tool to use with this project. Refer back to section 3.6.1 in Chapter 3 if you need a reminder on how to select the simulator. Start the debugger using the Start Debugging and Break icon at the left of the second toolbar, or use Alt + F5, as done before. Each line of the program is now explained starting with the first line shown below.

```
ldi r16, 34
```

The first instruction of the program uses the LDI (Load Immediate) instruction to load a value of 34 decimal to the R16 register. In Microchip Studio, select Debug > Windows > Processor Status on the top menu to open a window that displays the general purpose registers as shown in Figure 5.2. If the registers are not displayed, click the + sign at the left of Registers in the window to expand the list of registers. Make sure that registers R16 and R17 are visible by either resizing the Processor Status window or by scrolling down this window if needed. Figure 5.2 shows the Processor Status window split into two to fit it into a smaller area on the page, with R16 and R17 on the right.

By default the values in the registers are displayed in hexadecimal. Right-click register R16 in the Processor Status window and select Display as Decimal on the menu that pops up to display the contents of this register in decimal format. Do the same for register R17.
