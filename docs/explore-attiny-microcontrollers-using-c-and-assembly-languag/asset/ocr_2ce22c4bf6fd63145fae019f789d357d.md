Parameters passed to avrdude are case-sensitive. We saw that a lowercase -p switch is used to specify the part. An uppercase -P switch is used to specify the port used by the programmer, which is a USB port in our example, as can be seen in bold below.

```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

Both the USBasp and USBtinyISP must be passed usb after -P. For the ArduinoISP which appears as a virtual COM port, the COM port number must be specified after -P, for example COM3, if this is the port number that the Arduino is assigned when plugged into a USB port. For the ArduinoISP only, a baud rate must be specified using -b, which can be placed after the -P switch and the port type. This must be -b 19200.

Finally we get to the -U switch which specifies that a memory operation is to be performed. Note that this is an uppercase U. The -U switch is followed by the memory type, operation to perform, and the file name, all separated by colons. In our example the memory type is Flash program memory and the operation is a write operation. An example file called file.hex is shown. These options are passed to avrdude after the -U switch as flash:w:"file.hex", where flash specifies Flash memory, w specifies a write operation and file.hex is the name of the file that contains the program to load. The file name does not need to be placed between quotes, but when a path to the file is included that has one or more space characters in it, the quotes are necessary. The file is generated in Microchip Studio as part of the build process and is in hexadecimal format.

Now that we have an understanding of what must be passed to avrdude in order to specify the target AVR to be programmed, the programmer being used, and the operation for it to perform, we can look at parameters for the specific programmers covered in this appendix. The three sections that follow show the command-line parameters, or arguments, needed by avrdude for a USBasp, USBtinyISP, and an Arduino Uno with the ArduinoISP sketch loaded. These parameters are then used in section A.3.5 that follows to set up the external programmers in Microchip Studio.
