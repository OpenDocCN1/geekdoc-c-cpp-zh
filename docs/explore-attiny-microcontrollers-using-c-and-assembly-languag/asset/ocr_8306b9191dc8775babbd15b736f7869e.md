We need to change the AVR from its default ISP mode to debugWIRE mode in order to use it with the Microchip Studio debugger. With the debugger/programmer device already plugged into the USB port of the PC and the 6-pin header connected to the AVR microcontroller circuit, power up the AVR circuit. In Microchip Studio select Tools ▶ Device Programming or keyboard shortcut Ctrl + Shift + P. A Device Programming icon can also be found on the top toolbar to the right. The Device Programming dialog box opens and should have the current tool and device already selected. Make sure that the selected interface at the top of the dialog box is ISP and then click the Apply button. To test if the selected tool can correctly connect to the selected device, click the Read button under Device signature at the top of the dialog box. The device signature and target voltage boxes will be filled if the connection was successful. If there is any error when attempting to connect, make sure that the tool, device and interface are correct. Also check that the circuit is correctly wired to the programming tool and that it is powered by 5V. The target AVR must be in its default factory setting state with the ISP interface enabled.

Do not set the DWEN fuse with a program-only USB programmer because it will not be able to take the AVR back out of debugWIRE mode. Click the Fuses item in the left column of the Device Programming dialog box. Under Fuse Name find the DWEN (debugWIRE Enable) fuse which is labeled HIGH.DWEN. If this item is not visible, either use the scroll bar to the right to bring it into view, or resize the dialog box until it shows. Click the checkbox next to this fuse to check it as shown in Figure 3.4. Finally click the Program button in the dialog box. A Fuse Warnings dialog box pops up. Click the Continue button in this box. If it fails, simply click the Program button again. Close the Device Programming dialog box. After the DWEN fuse has been programmed, the AVR is still in ISP mode. The power to the AVR must be switched off and on again (called “cycling the power”) for it to change to debugWIRE mode. Cycle the power to the AVR now.

Now that the AVR is in debugWIRE mode, the tool interface must be changed in Microchip Studio. Once again, click the hammer icon on the second top toolbar. In the page that opens, the correct programming device should still be selected, but the interface must change. Click the Interface drop-down box and select debugWIRE. Save the changes.
