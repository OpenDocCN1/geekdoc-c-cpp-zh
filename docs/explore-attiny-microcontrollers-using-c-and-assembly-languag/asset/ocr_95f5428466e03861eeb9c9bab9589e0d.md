# 11.3 Entire AVR Instruction Set

In the previous section, section 11.2, all of the instructions implemented in the ATtiny microcontrollers used in this book are covered. Not all of the possible AVR instructions are implemented in these devices. In this section we look at the total number of AVR instructions and list the instructions not implemented in the ATtiny devices that we are using.

# 11.3.1 Number of AVR Instructions

The following subsections summarize the number of AVR instructions in the entire instruction set, the number of instructions implemented on ATtiny devices, and some discrepancies found in the AVR documentation.

# 11.3.1.1 Total Number of AVR Instructions

Adding up all of the instructions for the entire AVR instruction set found in the Instruction Set Summary section of the AVR Instruction Set manual, the total is 142 instructions.

# 11.3.1.2 Number of ATtiny AVR Instructions

Adding up all of the implemented instructions for all ATtiny devices from Table 1.1 in section 1.3 of Chapter 1, the total comes to 123 instructions, except for the ATtiny26 that implements 119 instructions. These implemented instructions are found in the Instruction Set Summary sections of the datasheets for each of the different ATtiny devices.

ATtiny26 devices don't implement the following instructions: BREAK, MOVW, LPM Rd, Z+, and SPM. These devices don't have debug capabilities because they do not implement the BREAK instruction.

# 11.3.1.3 Discrepancies in Documentation

Counting the number of implemented instructions for ATtiny microcontrollers by adding up the instructions in the Instruction Set Summary section of the datasheets totals 123 instructions except for the ATtiny26 which totals 119 instructions. In most datasheets at the time of writing, these counted totals differ from the number of instructions mentioned in the Features list at the beginning of the datasheets. For example, the ATtiny26 just mentioned quotes 118 instructions in the features section instead of 119. All other datasheets, except for two, quote 120 instructions instead of 123. Only the datasheets for the ATtiny261/461/861 and ATtiny48/88 quote 123 instructions.
