# 7.4.3 Logical Exclusive OR

Figure 7.3 shows the truth table for the exclusive OR (EOR) logical operation and an example of its use on two 8-bit registers. As with the AND and OR logical operations, the EOR performs a bitwise logical operation of each bit in the number in a register with the corresponding bit of a number in a second register. Exclusive ORing two input bits that have the same value always results in 0 as can be seen in the truth table. Exclusive ORing two bits of different values results in 1.

![](bbox=[0.2, 0.26, 0.85, 0.41])

The AVR instruction set contains one exclusive OR instruction, EOR (Logical Exclusive OR), that exclusive ORs the values in two registers with each other. The following code demonstrates the use of the EOR instruction.

```
test_asm : main.asm – EOR example

ldi    r16, 0b1100_0101
ldi    r17, 0b1100_0111
eor    r16, r17

ldi    r18, 0b0000_0001
ldi    r19, 0b0000_0001
loop:
eor    r18, r19     ; Toggle bit in R18
rjmp   loop
```

In the above code, the first three instructions implement the example bitwise EOR operation of Figure 7.3. Step over the code and check the result against what is expected from the EOR truth table. As can be seen, the value in R16 is EORed with the value in R17, and the result saved back into R16.
