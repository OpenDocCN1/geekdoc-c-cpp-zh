In Table A.1, the ATtiny48 part is marked with an asterisk because it is not included in the list of supported parts in the avrdude documentation and is not supported by avrdude version 6.3. Support for the ATtiny48 can be added by modifying the avrdude.conf file that came with avrdude. This text file can be edited using any text or code editor, and the entry from lists.nongnu.org/archive/html/avrdude-dev/2009-08/msg00005.html added to it. It is just a matter of opening this file in a text editor and searching for “ATtiny88” in order to place the entry of the above above ATtiny88. If you don’t feel confident to edit the file, or want a quick solution, find the modified avrdude.conf file with the accompanying files for this book. Simply copy the modified file and replace the currently existing one that is in the folder that we installed avrdude to, which is found in C:\avrdude-6.3-mingw32 if you followed the instructions in this appendix.

Back to the avrdude command line parameters example, we now have the -c switch followed by a programmer name, as can be seen in bold below.

```
avrdude -p t85 -c usbasp -P usb -U flash:w:"file.hex"
```

The -c switch must be followed by a programmer ID. In the example above, the programmer specified is the USBasp. Table A.2 shows the three programmers that are covered in this appendix with their avrdude programmer IDs.

| Programmer | ID |
| :--- | :--- |
| USBasp | usbasp |
| USBasp Clone | usbasp-clone |
| USBTinyISP | usbtiny |
| ArduinoISP | avrisp |

For the USBasp pictured in this book, the usbasp ID works. If you are having trouble programming with your USBasp, you can try usbasp-clone instead. As can be seen in Table A.2, the programmer ID for a USBTinyISP is usbtiny. When an Arduino Uno has been loaded with the ArduinoISP sketch, it has effectively become an ISP programmer, so the ID avrisp must be used with it. Many more programmers are supported by avrdude, but as mentioned, only three programmers are covered in this appendix.
