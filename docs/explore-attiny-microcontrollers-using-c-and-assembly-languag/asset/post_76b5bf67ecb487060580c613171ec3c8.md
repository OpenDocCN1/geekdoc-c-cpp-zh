
## 11.3 Entire AVR Instruction Set

In the previous section, section 11.2, all of the instructions implemented in the ATtiny microcontrollers used in this book are covered. Not all of the possible AVR instructions are implemented in these devices. In this section we look at the total number of AVR instructions and list the instructions not implemented in the ATtiny devices that we are using.

### 11.3.1 Number of AVR Instructions

The following subsections summarize the number of AVR instructions in the entire instruction set, the number of instructions implemented on ATtiny devices, and some discrepancies found in the AVR documentation.

### 11.3.1.1 Total Number of AVR Instructions

Adding up all of the instructions for the entire AVR instruction set found in the Instruction Set Summary section of the AVR Instruction Set manual, the total is 142 instructions.

### 11.3.1.2 Number of ATtiny AVR Instructions

Adding up all of the implemented instructions for all ATtiny devices from Table 1.1 in section 1.3 of Chapter 1, the total comes to 123 instructions, except for the ATtiny26 that implements 119 instructions. These implemented instructions are found in the Instruction Set Summary sections of the datasheets for each of the different ATtiny devices.

ATtiny26 devices don't implement the following instructions: BREAK, MOVW, LPM Rd, Z+, and SPM. These devices don't have debug capabilities because they do not implement the BREAK instruction.

### 11.3.1.3 Discrepancies in Documentation

Counting the number of implemented instructions for ATtiny microcontrollers by adding up the instructions in the Instruction Set Summary section of the datasheets totals 123 instructions except for the ATtiny26 which totals 119 instructions. In most datasheets at the time of writing, these counted totals differ from the number of instructions mentioned in the Features list at the beginning of the datasheets. For example, the ATtiny26 just mentioned quotes 118 instructions in the features section instead of 119. All other datasheets, except for two, quote 120 instructions instead of 123. Only the datasheets for the ATtiny261/461/861 and ATtiny48/88 quote 123 instructions.

### 11.3.2 Other AVR Instructions

Of the 142 possible AVR instructions, the ATtiny microcontrollers covered in this book implement up to 123 instructions. This leaves 19 instructions that are not implemented. These remaining instructions are summarized in the following subsections.

### 11.3.2.1 Arithmetic and Logic Instructions

The full AVR instruction set implements an additional six multiply instructions and a data encryption instruction, listed below.

- MUL (Multiply Unsigned): 8-bit by 8-bit unsigned multiply with a 16-bit result.
- MULS (Multiply Signed): 8-bit by 8-bit signed multiply with a 16-bit result.
- MULSU (Multiply Signed with Unsigned): multiply of 8-bit signed and unsigned numbers.
- FMUL (Fractional Multiply Unsigned): same as MUL, but left shifts result by one bit.
- FMULS (Fractional Multiply Signed): same as MULS, but left shifts result by one bit.
- FMULSU (Fractional Multiply Signed with Unsigned): MULSU with left shift by one bit.
- DES (Data Encryption Standard): implements data encryption DES algorithm.

Of the above instructions DES is only implemented in the AVRxm version of the AVR CPU. The six multiply instructions are implemented in the AVRe+, AVRxm and AVRxt CPU versions. Remember that the ATtiny microcontrollers used in this book have the AVRe CPU.

### 11.3.2.2 Branch Instructions

Two additional jump instructions and two additional subroutine call instructions are available in the full AVR instructions set.

- JUMP (Jump): Jumps to an address between 0 and 4M words (22-bit address).
- EIJUMP (Extended Indirect Jump): Indirect jump to an address between 0 and 4M words (22-bit address). Uses Z register and EIND register in I/O space as an address pointer.

ATtiny microcontrollers used in this book only implement the relative jump instruction RJMP and indirect jump instruction IJMP because of their small memory sizes. JMP and EIJUMP are implemented on AVR microcontrollers that have bigger memories.

CALL (Long Call to a Subroutine): Calls a subroutine within the entire program memory. The size of the return address pushed on the stack and the number of clock cycles used to execute this instruction depends on the size of the memory implemented on the AVR and therefore the size of its program counter or PC.

EICALL (Extended Indirect Call to Subroutine): Indirect call to a subroutine at an address between 0 and 4M words (22-bit address). Uses Z register and EIND register in I/O space as an address pointer.

ATtiny microcontrollers use the RCALL and ICALL instructions to call subroutines within their small memory ranges. CALL and EICALL instructions are used in AVRs that have bigger memories.

Although both JMP and CALL are part of the AVR CPU instruction set, they are not implemented on the ATtiny devices that we have been using. EIJUMP and EICALL are only available on AVRe+, AVRxm and AVRxt AVR cores.

### 11.3.2.3 Data Transfer Instructions

ELPM (Extended Load Program Memory)
ELPM Rd, Z
ELPM Rd, Z+

There are three variations of the ELPM instruction, as shown above. These instructions work the same way as the LPM instructions, but extend the addressing range by using the Z register, and the RAMPZ register from I/O space, as a pointer into program memory. This instruction and its variants are available on AVRe+, AVRxm and AVRxt CPU cores.

SPM Z+ (Store Program Memory): Although ATtiny microcontrollers implement the SPM instruction, this variation uses the Z register and RAMPZ with post increment. This instruction is only available on AVRxm and AVRxt CPU versions.

XCH (Exchange): Exchanges one byte between a register R0 to R31 and a byte from data space pointed to by the Z register. Found on the AVRxm CPU only.

LAS (Load and Set): Loads a byte from I/O space pointed to by the Z register, to a register R0 to R31, and sets bits in the data space specified by the register.

LAC (Load and Clear): Loads a byte from I/O space pointed to by the Z register, to a register R0 to R31, and clears bits in the data space specified by the register.

LAT (Load and Toggle): Loads a byte from I/O space pointed to by the Z register, to a register R0 to R31, and toggles bits in the data space specified by the register.

LAS, LAC and LAT are only implemented in the AVRxm version of the CPU.

## 11.3.3 Putting Instructions into Perspective

This section gives a better understanding of where the various AVR CPU versions and instructions are used across different AVR microcontroller ranges.

### 11.3.3.1 The Full AVR Instruction Set

Of the additional 19 instructions covered in the previous section, five are implemented on the AVRxm CPU only. These are DES, LAC, LAS, LAT, and XCH. This means that the AVRxm CPU is the only CPU version to implement all 142 instructions, however as with other AVR microcontrollers, not all parts that have the AVRxm CPU implement all instructions available in the AVRxm CPU, although some do.

### 11.3.3.2 The Plain AVR CPU

In the ATtiny range, some of the older devices have the plain AVR CPU and are no longer manufactured or not recommended for new designs. For example, the 8-pin ATtiny11, ATtiny12, and ATtiny15 have been replaced with the ATtiny13(A) and ATtiny25/45/85. Only the 20-pin ATtiny26 that is listed as having the plain AVR core in the AVR Instruction Set Manual is still in production at the time of writing.

### 11.3.3.3 Reduced AVRrc Core

The only AVR microcontrollers to use the AVRrc version of the CPU are in the ATtiny range of parts, and are only available in surface mount packages. ATtiny4/5/9/10 parts have the AVRrc core, and are available in 6-pin SOT-23 and 8-pin UDFN packages. ATtiny102/104, ATtiny20 and ATtiny40 are the only other AVR microcontrollers available with the AVRrc CPU version at the time of writing. AVRrc CPU cores only have registers R16 to R31 implemented and have fewer instructions from the full AVR instruction set available.

### 11.3.3.4 AVRe and AVRxt Cores

All other ATtiny microcontrollers not mentioned above have either the AVRe or AVRxt CPU. ATtiny devices that have more than 8K bytes (or 4K words) of program memory have to use a CPU that has instructions available to address the additional memory. These devices use either the AVRe CPU with all of the AVRe instructions implemented, or the AVRxt CPU version, as both CPU versions include instructions such as JMP and CALL. The AVRe CPU implemented in devices such as the ATtiny13(A) and ATtiny25/45/85 does not implement JMP and CALL, although they are part of the AVRe CPU specification. This is because these devices have small memories so only need RJMP and RCALL. Only very few members of the ATmega microcontroller range use the AVRxt core.
