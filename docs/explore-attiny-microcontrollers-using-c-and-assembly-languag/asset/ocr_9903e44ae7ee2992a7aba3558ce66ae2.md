When the result of an addition is greater than 255, which is the highest value that an 8-bit number can hold, the carry flag (C flag) is set as can be seen when the above code is stepped over in the debugger.

Use the debugger and simulator to experiment with adding of numbers to get a better understanding of what the status register flags are doing. Some examples are 255 + 1 which sets the H (half carry) flag, the C (carry) flag and the Z (zero) flag. The carry flag represents a ninth bit which has a value of 256, which is the result of 255 + 1. The destination register therefore contains zero, and so the zero flag is set in this example.

If the result of an addition operation is a number that has the MSB set, the N (negative) flag will be set in the status register. The programmer can choose to treat the number as negative, if needed, or ignore the negative flag if working with positive numbers only. As an example, try 128 + 1.

# 7.2.2 ADC – Add with Carry

ADC (ADD with Carry) adds the values in two registers and the carry bit where the carry bit is added as the least significant bit of an 8-bit number. This instruction can be used when adding two 16-bit numbers that are split across four registers – two 8-bit registers per 16-bit number. The procedure to add two 16-bit numbers together would be to first add the least significant bytes using the ADD instruction, then add the most significant bytes using the ADC instruction so that the carry from the previous addition is included.
