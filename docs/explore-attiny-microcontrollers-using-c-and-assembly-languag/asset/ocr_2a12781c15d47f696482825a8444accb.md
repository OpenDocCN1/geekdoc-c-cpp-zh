# 3.6.1 Using the AVR Simulator and Debugger

Using the debugger in Microchip Studio with the simulator does not require any physical hardware, or any programmer/debugger such as the Atmel-ICE. Start by opening the led_blink_asm project from Chapter 2 in Microchip Studio. Build the project if you have not already done so. To use the simulator, the simulator option must be selected as the tool that is used with the project – select the simulator instead of the Atmel-ICE or other programming tool. Click the hammer icon labeled None on the second horizontal toolbar, or click the name of the currently selected tool in the same place if you previously selected a programming tool. Alternatively select Project ▶ led_blink_asm Properties... from the top menu or the Alt + F7 keyboard shortcut, then click Tool in the left column. From the drop-down box under the heading Selected debugger/programmer, select Simulator and then save the changes. Tool settings are shown in Figure 3.2.

Start the simulator by clicking the Start Debugging and Break icon on the second top toolbar at the left as indicated in Figure 3.2, alternatively use the keyboard shortcut Alt + F5, or Debug ▶ Start Debugging and Break from the top menu.
