# 6.8 AVR Instruction Encoding

Instruction encoding refers to how machine language instructions are encoded or represented in binary. The following program is used to demonstrate how assembly instructions are encoded in binary. Replace the code in the test_asm project that we have been using with the following code and build the project.

```
test.asm : main.asm - Instruction encoding

loop:
    ldi   r16, 5
    ldi   r17, 12
    add   r16, r17
    rjmp  loop
```

Although some excerpts from the AVR Instruction Set Manual are included in this book, it is best to start learning to use the AVR Instruction Set Manual to look up instructions. If you have not already downloaded this manual, find it at:

ww1.microchip.com/downloads/en/DeviceDoc/AVR-Instruction-Set-Manual-DS400002198A.pdf (Search the Internet for “AVR instruction set manual” if this link changes and does not work)

The first instruction in the program, below the loop label, is an LDI instruction. Find the LDI (Load Immediate) instruction in the instruction set manual, or refer to Figure 6.12 which was taken from the AVR Instruction Set Manual. A description of any instruction which includes how it is encoded in binary can be found in the instruction set manual, followed by the state of the status register after the instruction has executed, and an example of its usage.

With the program from the above code listing entered into the main.asm file of the test_asm project, start the debugger with simulator selected, using Start Debugging and Break. The actual values of the instructions can be seen in the Memory window at the lower right of Microchip Studio. Make sure that the memory selected in the memory window is prog FLASH, which is the default. If Auto is selected for the Columns of the Memory window, then the bytes that make up the instructions of the program are shown in little-endian format, that is with the least significant byte of the instruction shown first. As an example, a 16-bit instruction that has the value 0xee05 is displayed as “05 e0”.
