# 10.5.1 How Interrupts Work

AVR microcontrollers all have a number of interrupt sources, such as a timer compare match, external interrupt, timer/counter overflow, and others. Each interrupt source has its own enable bit found in one of the interrupt source peripheral registers. For example, the Timer/Counter0 peripheral has a timer/counter interrupt mask register called TIMSK that has interrupt enable bits for the timer overflow and compare matches. To enable one of the compare match interrupts, the corresponding bit in TIMSK is set. In addition to enabling an individual interrupt, the global interrupt enable bit in the status register must be set in order for any individual interrupt to be able to work.

When an interrupt does occur, for example there is a timer compare match, the global interrupt enable bit is automatically cleared, disabling interrupts. The interrupt service routine for the particular interrupt is then called. An interrupt service routine is just like a subroutine, except that to return from it the RETI (Return from Interrupt) instruction must be used instead of the RET instruction. When the RETI instruction is executed at the end of an ISR, the return address is loaded from the stack and the global interrupt enable bit is set, enabling interrupts again.

# 10.5.2 The Interrupt Vector Table

An interrupt vector table allows the correct interrupt service routine, or ISR, to be called when an interrupt occurs. For example, the ISR that was written for a particular timer compare match must be called when the compare match interrupt occurs.

Interrupts are assigned to jump to fixed program memory address locations starting at address 0, when they occur. The interrupt vector table is placed at these fixed program memory locations and consists of jump instructions to jump to the correct ISR code. Interrupt vector tables can be found in section or chapter 9 of the datasheet for ATtiny13(A) and ATtiny25/45/85 devices.

The interrupt vector tables for the ATtiny13(A) and ATtiny25/45/85 are different, so two different code examples follow in the next sub-section. Two examples are included for learning purposes as this makes the code easier to read and understand. Having two separate projects for the two different interrupt vector tables shows what the interrupt vector tables consist of and how they differ. A third project shows how to write the same code so that it can be used on both the ATtiny13(A) and ATtiny25/45/85 ranges.
