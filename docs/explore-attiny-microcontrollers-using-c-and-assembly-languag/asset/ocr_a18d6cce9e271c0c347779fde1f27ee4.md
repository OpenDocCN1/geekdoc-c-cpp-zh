As can be seen from this example, the SBRC instruction has two operands, the first being the register to test, which can be R0 to R31. The second operand is the bit in this register to test, which can be 0 to 7.

# 8.2.4 Three Ways to Toggle an LED with an AVR

Three ways of toggling an LED attached to an AVR pin are, 1) to change the pin logic level by value by directly writing a logic level to the PORT register, 2) using exclusive OR, and 3) by using the PINB register. These three methods are explained in the subsections that follow. Toggling an LED of course means changing its logic state either from 0 to 1, or from 1 to 0.

# 8.2.4.1 Toggling an LED by Value

SBI and CBI were used to toggle an LED by value in the led_blink_asm project from section 2.3.2 of Chapter 2. Bitwise OR and AND instructions were used in the same way in the led_blink_c project from section 2.4.2.

As we saw in the led_count_asm project of section 8.2.1.4 of this chapter, the OUT instruction can also be used to change the value of a pin or pins by writing to the PORT register, and could be used in this way to toggle an LED. The same can be said for the led_count_c project, where a value was written directly to the PORTB register to change the values of LEDs. Alternately writing a 1 and then 0 to a bit in a PORT register will toggle an LED, if the corresponding pin is set as an output. As we have already covered how to toggle an LED by value in previous chapters, we will not look at any further code in this section.

# 8.2.4.2 Toggling an LED by Exclusive OR

An LED can be toggled by using the exclusive OR operator that was covered in section 7.4.3 of Chapter 7. If a single bit is always exclusive ORed with a logic level of 1, then if the bit starts out with a value of 1, 1 EOR 1 = 0, the bit ends up toggling from 1 to 0. This means that the next time the bit is exclusive ORed with 1, we have 0 EOR 1 = 1, so the bit now toggles from 0 to 1. If we continue to exclusive OR the bit with 1, it will keep toggling from 1 to 0 and back to 1. We saw this in the EOR example code snippet from section 7.4.3. An LED can be toggled in the same way, as shown in the led_eor_toggle_asm project that follows. Because EOR can’t directly toggle a pin, the pin value is first put into a register by reading the whole port using IN. After toggling the bit in the register using EOR, the new value is written back to the port using OUT.
