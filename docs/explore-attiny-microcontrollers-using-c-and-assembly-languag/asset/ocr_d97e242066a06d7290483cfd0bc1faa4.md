# Chapter 4 • Binary Numbers and Memory

All processing done by a microcontroller is performed on binary numbers. All machine language of any microcontroller consists entirely of binary numbers. It is therefore important to have a proper understanding of the binary numbering system before continuing with an explanation of registers and memory, and how assembler instructions act on registers and memory.

Those readers who already know how the binary number system works should at least read section 4.5 of this chapter to see how binary and hexadecimal numbers are used in assembly language programs.
