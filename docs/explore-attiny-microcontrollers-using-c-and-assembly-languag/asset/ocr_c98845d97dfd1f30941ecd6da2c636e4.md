capabilities. This means that extra interrupt vectors are needed for these extra interrupt sources. In addition to having a bigger interrupt vector table, the timer 0 compare match A interrupt vector is at a different location. This interrupt vector is at address 0x0006 on an ATtiny13(A), but is at address 0x000A on an ATtiny25/45/85. In fact, only the first three interrupt vectors, including the reset vector, are at the same addresses when comparing the two ATtiny device ranges. Everything in the remainder of the program is the same as for the ATtiny13(A), except that the TIMSK register is called TIMSK0 on an ATtiny13(A) and called TIMSK on an ATtiny25/45/85.

# 10.5.3.3 Universal Timer Interrupt Project

Because the ATtiny header files define names for interrupt vector addresses, it is possible to change the previous projects to work on both the ATtiny13(A) and ATtiny25/45/85. Create the timer0_uni_int.asm assembly language project in Microchip Studio, and add the following code to main.asm. This code works on both ATtiny13(A) and ATtiny25/45/85 devices without the need to change anything.

```
timer0_uni_int.asm : main.asm

.lfndef TIMSK
.equ TIMSK = TIMSK0
.endif

.org 0
rjmp main ; Reset vector

.org OCA0addr
rjmp ISR_tim0_compA ; Timer 0 compare match A interrupt vector

main:
sbi DDRB, DDB4 ; Pin PB4 as output pin
ldi r16, (1 << WGM01) ; CTC mode for timer
out TCCR0A, r16
ldi r16, 0x7F ; Output compare value
out OCR0A, r16
ldi r16, (1 << OCIE0A) ; Enable T0A compare match interrupt
out TIMSK, r16
sei ; Set global interrupt enable bit
ldi r16, (1 << CS02) | (1 << CS00) ; Prescaler CLK/1024 and start timer
out TCCR0B, r16

loop:
rjmp loop

; Timer 0 compare match A interrupt service routine or handler
ISR_tim0_compA:
sbi PINB, PINB4 ; Toggle LED
reti
```
