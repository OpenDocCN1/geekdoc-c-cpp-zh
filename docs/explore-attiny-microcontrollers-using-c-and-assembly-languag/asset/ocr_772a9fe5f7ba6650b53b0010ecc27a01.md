Starting at the bottom of the listing, we have num_passes, which is the number of passes through the loop. In our example, register R17 was loaded with 3, so this is the number of passes through the loop. Because the last pass through the loop generates a different number of clock cycles from all other passes, we must subtract 1 from the number of passes, thus num_passes becomes 3 – 1, which is 2. We are therefore left with 1 clock cycle for DEC plus 2 clock cycles for BRCC, which totals 3 clock cycles for every pass through the loop. For all passes through the loop, except the last we therefore have 3 × num_passes, which is 3 × 2 = 6 clock cycles for this example.

Treating the last pass through the loop separately from the preceding passes, we have 1 clock cycle used by DEC and 1 clock cycle used by BRCC, which is 1 + 1 = 2. Add these two clock cycles to the 6 clock cycles used by the previous passes through the loop and we get 8 clock cycles. From this understanding of how the inner loop works in terms of clock cycles used, we can now derive a formula.

In the calculation ((1 + 2) × 2) + 1 + 1 = 8, we have one variable, and one unknown value that we are trying to calculate. The unknown value, which is the number of clock cycles used by the inner loop worked out to 8 in this example.
