```
; Timer 0 compare match A interrupt service routine or handler
ISR_tim0_compa:
    sbi PINB, PINB4 ; Toggle LED
    reti
```

As the main program execution is doing nothing in an infinite loop, only the ISR can toggle the LED. When there is a compare match between the timer counter register TCNT0 and the output compare register OCR0A, the Timer/Counter compare match A Interrupt is triggered. Program execution jumps to the vector location for this interrupt in the interrupt vector table, which is address 0x0006 on the ATtiny13(A). At this location is the RJMP instruction that jumps to the ISR_tim0_compa interrupt service routine. In this ISR, the PINB4 bit is set in the PINB register which toggles the LED. The ISR returns to the main loop after executing the RETI instruction. It is important to always return from an ISR using RETI and not RET.

# Running the Timer Interrupt Code

Run the code using a debugger/programmer or using the simulator in Microchip Studio. Step through the code and notice that the first RJMP instruction at address 0 jumps to the main label. Before stepping over the SEI instruction, make sure that the Processor Status window is open. Look at the Status Register | flag, found near the top of the Processor Status window. It is initially clear or 0. After stepping over the SEI instruction it turns solid red, indicating that it has just changed state and that it is now set. Place a breakpoint on the RETI instruction at the bottom of the ISR_tim0_compa ISR. Now run the code using the F5 keyboard key. When code execution stops on the breakpoint, notice that the I flag in the Status Register is now clear. Step over the RETI instruction and notice that the I flag is automatically set and is solid red again. Remember that items in the Processor Status window turn red if their state has just changed. Items such as the bits in the status register will turn blue if they are still set, but did not change from the most recent step through the code. Open the I/O window and click the I/O Port (PORTB) item so that the port B registers are displayed at the bottom of the I/O window. Using the F5 keyboard key to run the code with the breakpoint still on the RETI instruction will cause execution to stop after pin PB4 is toggled. The bit corresponding to pin PB4 can be seen toggling at each break in the PORTB register at the bottom of the I/O window.
