# ICALL (Indirect Call to Subroutine)

ICALL works the same way as IJMP, using the Z register as a pointer, except that ICALL pushes the next program memory address onto the stack. ICALL is used to call a subroutine at the address that the Z register is holding.

# 11.2.2.3 Return from Subroutine and Interrupt Instructions

# RET (Return from Subroutine)

RET must be used to return from a subroutine that was called using RCALL or ICALL. The return address is loaded from the stack when RET is executed at the end of a subroutine.

# RETI (Return from Interrupt)

RETI must be the last instruction run in an interrupt service routine so that program execution continues where the main code was interrupted and so that the global interrupt enable bit in the status register is automatically set again. The use of the RETI instruction is explained in Chapter 10, starting from section 10.5.1.

# 11.2.2.4 Compare Instructions

Of the four compare instructions that follow, only CPSE branches. The other compare instructions don't branch, but are typically used in combination with branch instructions.

# CPSE (Compare Skip if Equal)

CPSE compares two registers and skips the next instruction if the values in the registers are equal. It has the format CPSE Rd,Rr where Rd and Rr can be any registers from R0 to R31. This instruction does not alter the status register.

# CP (Compare)

CP compares two registers in the range R0 to R31, which means that it affects flags in the status register. It has the form CP Rd,Rr where Rd and Rr can be any of the registers R0 to R31. The following example demonstrates the use of CP.

```
ldi   R16, 0x05
ldi   R17, 0x05
cp    R16, R17
breq  equal
nop   ; Values are not equal
equal:
nop   ; Values are equal
```
