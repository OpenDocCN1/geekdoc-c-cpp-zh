Because dir was loaded with an initial value of s_left, a branch does not occur. Instead, the LSL instruction left shifts the value in s_value. SBRS is used to check if the single set bit in s_value has been shifted into the bit 5 position, which indicates that the shift direction must change. SBRS only skips if bit 5 is set. If it is not yet set, then the RJMP instruction below SBRS is not skipped, but causes program execution to continue from the top of the loop where the LEDs are updated with the new s_value, and the delay followed by the next left shift occurs.

```
cpi     dir, s_left         ; Check which direction to shift
brne    shift_right
lsl     s_value             ; Rotate the register left
sbrs    s_value, 5          ; Skip if bit 5 is set
rjmp    loop
lsl     s_value             ; Shift the set bit to bit 4
ldi     dir, s_right        ; Change shift direction to right
shift_right:
lsr     s_value             ; Rotate the register right
sbrc    s_value, 0          ; Skip if bit 0 is clear
ldi     dir, s_left         ; Change shift direction to left
rjmp    loop
```

When enough left shifts have occurred so that bit 5 in s_value is set, SBRS jumps the RJMP instruction below it so that this new left shifted value is not written to the LEDs. LSR is then used to right shift the value in s_value, so that the set bit in this register is lined up with the left most LED, or bit 4. In other words, it synchronizes the value in s_value with the current state of the LEDs, because the last left shifted the set bit too far left. s_value is now loaded into the dir register to flag that right shifting must now commence. LSR is used to right shift s_value again. Because the left most LED, or bit 4, has already been on for the delay period, the right shift is done to set the next LED to the right, or bit 3. SBRC is then used to check bit 0 to see if it is time to reverse direction. As direction has just been changed, at this stage bit 0 is clear, and SBRC skips over the next instruction that would flag the direction change to the left. Finally the bottom RJMP instruction is executed, and the new right shifted value in s_value is written to the LEDs.

Now that the right shift flag s_right is in the dir register, when the CPI and BRNE instructions are executed, BRNE branches to the shift_right label. This is because the comparison result is that the value in dir is not equal to s_left. At shift_right, LSR shifts the value in s_value right again. This will happen each time through the loop until the single set bit in s_value reaches bit position 0. This triggers the direction change under SBRC.

## Arithmetic Shift and Swap Instructions

### ASR (Arithmetic Shift Right)

ASR has the form ASR Rd and shifts the bits in the destination register one bit place to the right, except for the MSB or bit 7. Bit zero is shifted into the C flag. You should have enough experience at this stage in the book to write your own code to test this instruction.

### SWAP (Swap Nibbles)

SWAP has the form SWAP Rd and swaps the upper and lower nibbles of the destination register. Write your own program to test the SWAP instruction. Test the program in the simulator.

## 11.2.3.3 Status Register Bit Set and Clear Instructions

Earlier in this chapter we saw that BRBS and BRBC instructions were used to branch, depending on the value of bits in the status register. These instructions were followed by pairs of instructions that were synonyms for BRBS and BRBC. In the same way, there are two instructions for setting and clearing bits in the status register called BSET and BCLR, followed by a number of pairs of instructions that are synonyms for setting and clearing status register bits. The exception to these synonyms are the BST and BLD instructions that immediately follow the BSET and BCLR instruction descriptions below. BST and BLD operate differently to BSET and BCLR, and are also encoded differently.

### Set or Clear SREG Bit

### BSET (Bit Set in SREG)

BSET has the form BSET s where s is the number of the bit in the status register to set, from 0 to 7. For example, BSET 1 sets the Z flag in the status register. This can be written using one of the names defined for bit 1 in the status register as follows: BSET SREG_Z

### BCLR (Bit Clear in SREG)

BCLR is the counterpart to BSET which clears the specified bit in the status register.

### Store or Load SREG T Bit to/from Register

### BST (Bit Store from Bit in Register to T Bit in SREG)

### BLD (Bit Load from the T Bit in SREG to a Bit in Register)

BST and BLD are the pair of instructions that are exceptions to being synonyms for the BSET and BCLR instructions. BST stores the specified bit from the specified register in the T bit of the status register. This instruction has the form BST Rd,b where Rd is the register to operate on which can be R0 to R31, and b is the bit in the register from 0 to 7. For example, BST R16,7 stores bit 7 of R16 in the status register T bit. Branch instructions BRTS or BRTC can then be used to check whether the bit is set or clear. BLD loads the T bit from the status register to the specified bit in the specified register. BLD has the form BLD Rd,b where Rd is the destination register and b is the specified bit. For example the instruction BLD R16,1 loads the T bit from the status register to bit 1 in R16. 8 pairs of instructions follow that are synonyms for the previous BSET and BCLR instructions.

- **CLC (Clear Carry Flag)**
