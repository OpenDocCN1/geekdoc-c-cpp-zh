In Microchip Studio, the include file for the particular AVR part selected does not have to be explicitly included because this is done in the project settings when the part is chosen during new project creation. For example tn25def.inc, which contains register definitions for the ATtiny25, is included in the project when an ATtiny25 microcontroller is chosen. This file is passed to the assembler program on the command line by Microchip Studio when the project is built – more details on this are found in Chapter 12.

Figure 9.1 shows an example of how tn45def.inc is automatically included in a project that was configured by selecting the ATtiny45 part. The part is selected when creating a new project, but can also be changed in the project by clicking the part name on the toolbar, as can be seen at the top of the figure. If the ATtiny45 is changed to a different part, the correct include file for that part is automatically updated in the project by Microchip Studio.
