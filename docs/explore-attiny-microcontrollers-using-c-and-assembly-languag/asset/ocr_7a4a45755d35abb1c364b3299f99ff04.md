RJMP to the interrupt handler or ISR for this interrupt is placed below this origin change so that it is at address 0x0006 in memory. In this code, there are no vector table entries for other interrupts, so the other interrupts must never be enabled. The dummy interrupt handler code can be removed from the project with this arrangement because it is never used.

# Main Program Code

After the interrupt vector table, we have the following code.

```
main:
    sbi   DDRB, DDB4        ; Pin PB4 as output pin
    ldi   r16, (1 << WGM01)  ; CTC mode for timer
    out   TCCR0A, r16
    ldi   r16, 0x7F         ; Output compare value
    out   OCR0A, r16
    ldi   r16, (1 << OCIE0A) ; Enable T0A compare match interrupt
    sts   TIMSK0, r16
    sei                     ; Set global interrupt enable bit
    ldi   r16, (1 << CS02) | (1 << CS00) ; Prescaler CLK/1024 and start timer
    out   TCCR0B, r16
loop:
    rjmp loop
```

In this code, pin PB4 is set up as an output pin using the SBI instruction. After this, timer 0 is set up in the same way as it was for the previous projects that polled the timer. The timer is first put into CTC mode, then a compare value loaded to OCR0A. This is followed by new code shown in bold above that enables the timer 0 compare match A interrupt and global interrupt enable bit. Bit OCIE0A is set in the TIMSK0 register in order to enable the timer/counter compare match A interrupt. This is followed by the SEI (Set Global Interrupt Enable Bit) instruction which sets the I bit in the status register. Refer back to Figure 6.8 in section 6.5 of Chapter 6 to see the status register. In the status register, the first bit on the left, or bit number 7, is the Global Interrupt Enable bit, or I bit. Once this bit is set, any individual interrupts that are enabled, such as the timer/counter 0 compare match A interrupt, will work when triggered. Finally the timer is started as done previously by selecting the system clock divided by 1024. Program execution then enters an infinite loop.
