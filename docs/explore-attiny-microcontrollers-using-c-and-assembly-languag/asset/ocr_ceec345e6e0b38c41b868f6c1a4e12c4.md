# 8.1 Instructions for Accessing I/O Registers

Several instructions from the AVR instruction set can be used to access (read and write) the 64 I/O registers. Instructions such as IN and OUT can be used to read and write between registers R0 to R31 and any of the 64 I/O registers. Because the I/O registers are mapped into data space, they can also be accessed by instructions such as LDS (Load Direct from Data Space) and STS (Store Direct to Data Space). Instructions for setting and clearing bits, and for testing the state of bits are also available.

# 8.1.1 Reading and Writing I/O Registers with IN and OUT

The IN instruction is used to read a value from an I/O register and the OUT instruction is used to write a value to an I/O register.

# 8.1.1.1 The IN Instruction

The IN (Load An I/O Location to Register) instruction is used to read an I/O register and place its contents into register R0 to R31. For example, to read the PINB I/O register into R16, the following code can be used.

```
in r16, 0x16
```

Refer to the Register Summary section of the ATtiny13(A) or ATtiny25/45/85 data sheet to find the PINB register and its address at 0x16. Fortunately Microchip Studio assembly language projects automatically include a file that has definitions for the I/O registers. This means that the registers can be accessed by using their names rather than their addresses in assembly language programs. The above line of code can be written as follows using the register name instead of its address.

```
in r16, PINB
```

To access the file that contains register definitions, open a project in Microchip Studio, such as the test_asm project that we have been using to test code snippets. In Microchip Studio, expand Dependencies in the Solution Explorer pane at the top right of Microchip Studio by clicking the small triangle at the left of it. The triangle will only be visible if the project has been successfully built. Double-click the file under Dependencies that ends with a .inc extension. For example, if an ATtiny45 is selected in a project, the name of the file is tn45def.inc as shown in Figure 8.1. After opening the definition file, scroll through it to see all of the registers and other definitions.
