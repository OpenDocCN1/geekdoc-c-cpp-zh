Figure 6.13: Hexadecimal Values of Instructions Shown in Flash Memory

Figure 6.14 shows how the two LDI instructions are encoded. The first four bits of an LDI instruction are always be 1110 binary, as shown in Figure 6.14 and Figure 6.12. LDI has a constant operand value that gets loaded to the selected register – in the example code this value is 5 for the first LDI instruction and 12 for the second. This constant value is split into two four bit parts as shown by KKKK in the figure when it is encoded into binary. When the two four bit parts are put together they form the 8-bit constant number that is loaded to the register. The constant number can be a value between 0 and 255, or 0b00000000 and 0b11111111. This value range appears in the instruction set manual in the LDI description section shown in Figure 6.12 as 0 ≤ K ≤ 255, which means that the constant value can be greater than or equal to 0, and less than or equal to 255.

The destination register is a four bit value dddd in Figure 6.14 and Figure 6.12. This value can be between 0b0000 and 0b1111, but because the instruction operates only on R16 to R31, it is offset by a value of 16. This means that 16 must be added to the binary encoded register value to get the actual register that is encoded in the instruction. 0b0000 therefore references R16 (0 + 16) and 0b0001 references R17 (1 + 16).
