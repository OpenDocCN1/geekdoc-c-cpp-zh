# Arithmetic Shift and Swap Instructions

# ASR (Arithmetic Shift Right)

ASR has the form ASR Rd and shifts the bits in the destination register one bit place to the right, except for the MSB or bit 7. Bit zero is shifted into the C flag. You should have enough experience at this stage in the book to write your own code to test this instruction.

# SWAP (Swap Nibbles)

SWAP has the form SWAP Rd and swaps the upper and lower nibbles of the destination register. Write your own program to test the SWAP instruction. Test the program in the simulator.

# 11.2.3.3 Status Register Bit Set and Clear Instructions

Earlier in this chapter we saw that BRBS and BRBC instructions were used to branch, depending on the value of bits in the status register. These instructions were followed by pairs of instructions that were synonyms for BRBS and BRBC. In the same way, there are two instructions for setting and clearing bits in the status register called BSET and BCLR, followed by a number of pairs of instructions that are synonyms for setting and clearing status register bits. The exception to these synonyms are the BST and BLD instructions that immediately follow the BSET and BCLR instruction descriptions below. BST and BLD operate differently to BSET and BCLR, and are also encoded differently.

# Set or Clear SREG Bit

# BSET (Bit Set in SREG)

BSET has the form BSET s where s is the number of the bit in the status register to set, from 0 to 7. For example, BSET 1 sets the Z flag in the status register. This can be written using one of the names defined for bit 1 in the status register as follows: BSET SREG_Z

# BCLR (Bit Clear in SREG)

BCLR is the counterpart to BSET which clears the specified bit in the status register.
