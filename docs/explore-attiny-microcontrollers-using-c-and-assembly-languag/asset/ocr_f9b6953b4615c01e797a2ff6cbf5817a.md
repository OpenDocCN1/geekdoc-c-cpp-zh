Be sure to change the part to the part that you are going to program. Use Table A.1 to find the correct part code. Remember that if you experience any problems with your USBasp, you may need to follow the -c option with usbasp-clone instead of usbasp.

# A.3.4.4 Parameters for a USBtinyISP

For a USBtinyISP, use the following parameters.

```
avrdude -p t85 -c usbtiny -P usb -U flash:w:"file.hex"
```

Remember to select the correct part that you are using from Table A.1 and place it after the -p switch.

# A.3.4.5 Parameters for an ArduinoISP

For an Arduino Uno loaded with the ArduinoISP sketch, use the following parameters.

```
avrdude -p t85 -c avrisp -P COM3 -b 19200 -U flash:w:"file.hex"
```

Change the part after the -p switch to the ATtiny being used, as per Table A.1. Find and specify the correct COM port after the -P switch. This can be found either using the Device Manager in Windows, or using the Arduino IDE.

# A.3.5 Microchip Studio External Tool Setup

Microchip Studio has an option for setting up external programming tools which allows avrdude to be run from within Microchip Studio. Command-line options for avrdude are included as part of the setup, which allows Microchip Studio to pass these options to avrdude when it is called. The correct program file is also automatically passed to avrdude so that it is loaded to the Flash program memory of the target AVR.
