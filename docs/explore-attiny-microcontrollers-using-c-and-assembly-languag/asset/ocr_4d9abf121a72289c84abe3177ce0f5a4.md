# 12.1.1.4 List File Options

The list file generated by AVRASM2 can be useful during software development as it shows the final instructions and machine code in hexadecimal format that the input assembly language files were converted to, as well as resource usage. When the list file is generated it includes the entire contents of the .inc file that is automatically included in a Microchip Studio assembly language project, placed at the top of the list file. This makes it necessary to scroll through the first long section of the list file to find the main program code. The normal solution to stop the contents of the .inc file being placed in the list file is to use the .nolist assembler directive before the file is included, and then use the .list assembler directive to enable listing again after the line that includes the .inc file. Because the .inc file is included automatically in a Microchip Studio project, the .nolist and .list directives can't be used without making a change to the project settings first.

In order to be able to use the .list and .nolist directives with the automatically included file in a Microchip Studio assembly language project, first go to the Toolchain General page, as shown in Figure 12.1 on the previous page. Cut (keys Ctrl + X) the file name out of the Include File box at the bottom of this page so that this box is empty, but the text that was in it is on the Windows clipboard. Add the .include directive to the top of the main.asm file of the project and paste the .inc file name next to it between angle brackets. Place a .nolist directive above the .include directive and a .list directive after it, as shown in the following code listing. The .inc file is tn85def.inc for an ATtiny85 selected for the project.

```
.nolist
.include <tn85def.inc>
.list

start:
    sbi   DDRB, DDB4        ; Set pin PB4 as output
    sbi   PORTB, PORTB4     ; Set LED pin high
loop:
    rjmp  loop
```

After saving the changes and building the project, the contents of the .inc file are no longer found in the list file. Take note that if the AVR part is changed in the project, then the new .inc file for the new part is automatically placed in the Include File field of the Toolchain General page. It must be cut from this field again and used to replace the previous .inc file next to the .include directive at the top of the main.asm file.
