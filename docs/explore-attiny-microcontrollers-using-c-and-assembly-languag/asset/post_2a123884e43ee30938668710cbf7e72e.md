
## 11.3.3.5 AVR+ CPU

Besides the few ATmega microcontrollers that use the AVRxt core, all other ATmega devices use the AVRe+ core. ATmega microcontrollers found on boards that are probably familiar to many readers, such as the Arduino Uno and Arduino MEGA 2560, use the AVRe+ CPU. This is the ATmega328 found on Arduino Uno boards and the ATmega2560 found on Arduino MEGA 2560 boards. AVRe+ CPU cores implement the following instructions that are not found on the AVR CPU core version: EICALL, EIJMP, ELPM, FMUL, FMULS, FMULSU, MUL, MULS and MULSU.

The AVR+ and AVRxt instruction sets are identical, except that the AVRxt instruction set includes the SPM Z+ instruction.

## 11.3.3.6 AVRxm CPU

The AVRxm CPU version is used exclusively in ATxmega (XMEGA devices) and the AVR DA range of microcontrollers. Although the AVRxm CPU specification includes all available AVR instructions, not every instruction is implemented in every part that has the AVRxm CPU.

## 12.1.1.1 Building a Project with AVRASM2

When an AVR assembly language program is built in Microchip Studio, the AVRASM2 command line program is invoked by Microchip Studio and passed various options or parameters. These parameters can be seen in the Output pane that opens at the bottom of Microchip Studio during the build process. The actual call to AVRASM2 with the various options passed to it is a long line, shown below as it appears in the Output pane, but with the program name and command line option switches highlighted in bold.

```
C:\Program Files\Atmel\Studio\7.0\toolchain\avr8\avrasm2\avrasm2.exe
-fi -o "test_asm.hex" -m "test_asm.map" -l "test_asm.lss" -S "test_asm.tmp"
-w+Ie -I"C:/Program Files\Atmel\Studio\7.0\Packs\atmel\ATtiny_DFP\1.8.332\avrasm\inc"
avrasm\inc" -i tn85def.inc -d "C:\Users\user\Documents\AVR_test_code\test_asm\test_asm\Debug\test_asm.obj"
-C "C:\Users\user\Documents\AVR_test_code\test_asm\test_asm\main.asm"
-I "C:\Program Files\Atmel\Studio\7.0\toolchain\avr8\avrasm2\include"
```

The various command line options or switches and their meanings can be found in the AVR Assembler document from Microchip. The options from above can be included below with descriptions. The above line is from the test_asm project built for an ATtiny85.

avrasm2.exe : The name of the AVRASM2 executable program. In the above listing it is preceded by the full path to its location on the host computer. Options are passed to this program by placing the options, each starting with a dash, after avrasm2.exe.

-fi -o "test_asm.hex" : Specifies the output file format as Intel Hex, and the output file name as test_asm.hex. This file in Intel Hex format is what is used to program the target AVR device as it contains a representation of the machine code of the program.

-m "test_asm.map" : Generate a map file called test_asm.map. The map file contains all of the names with their assigned values from the included .inc file, as well as definitions from the assembly language files of a project, such as label names and addresses.

-l "test_asm.lss" : Generate a list file called test_asm.lss. The list file contains the entire assembly language program, with the contents of any include files. Code from the program is included with the address of each instruction and the machine code that each instruction converted to in hexadecimal format. After the code, a section in the list file shows a summary of resources used by the program, such as registers used, instructions used, and memory used.

-S "test_asm.tmp" : Generate a include/label info file called test_asm.tmp. This is an XML file that contains assembler information, such as the AVR device used, paths to the working directory, include files, source code and other files of the project, as well as labels used in the project. Most of the items from this file are represented in the Solution Explorer pane of Microchip Studio when the project is successfully built.

-W : If an instruction is used that is not supported by the chosen AVR device, then generate an error.

-I : Add a directory to the include file search path. The first use of the -I switch in the listing on the previous page includes the path to the .inc files for AVR microcontrollers.

-i tn85def.inc : The lowercase -i switch is used in place of #include or .include to include the tn85def.inc file for the ATtiny85 in this example. This is why none of the Microchip Studio assembly language projects needed to have the definition files included at the top of the source code files.

-d : Generate a debug info file. In the listing on the previous page, the -d option is followed by the path to the debug file with a name specified as test_asm.obj. This file is used for debugging a program in Microchip Studio.

-I : Add a directory to the include file search path. This option was previously used, and is used here again which is perfectly acceptable. It seems that this second included directory does not exist, as the Include directory at the end of the path from the listing is not found in the avrasm2 directory, as specified at this second -I option in the listing.

After the AVRASM2 program runs with the options passed to it as described, its output is displayed in the Output window of Microchip Studio below the line used to invoke it. The output from AVRASM2 from the test_asm project built for the ATtiny85 is as follows, with two of the file paths shortened so that each uses one line of the page.

```
AVRASM: AVR macro assembler 2.2.8 (build 80 Jan 14 2020 18:27:59)
Copyright (C) 1995-2020 ATMEL Corporation
[builtin(2): Including file 'C:/Program Files\ ... \avrasm\inc\tn85def.inc'
[builtin(2): Including file 'C:/Program Files\ ... \avrasm\inc\tn85def.inc'
"ATtiny85" memory usage summary [bytes]:
Segment Begin End Code Data Used Size Use%
```

As can be seen in the above listing, AVRASM2 outputs the memory used by the program and the number of errors and warnings generated. ## 12.1.1.2 AVRASM2 on the Command Line

When Microchip Studio is installed on a computer, an item called Microchip Studio Command Prompt is also installed. This item can be found by opening the main Windows menu by clicking the Windows “Start” icon at the bottom left of the desktop. Scroll down this menu to find the Microchip Studio folder, which must be expanded by clicking it. After expanding the menu folder, click the Microchip Studio Command Prompt item. This opens a command prompt window that has the Microchip Studio tools in its path. AVRASM2 can be invoked from this command prompt window. Entering just the name of AVRASM2 at the command prompt, as shown below, prints the version, build and copyright information.

```
avrasm2
```

Invoking AVRASM2 and passing it the -h option or switch, as shown below, causes it to print out all of the command line options.

```
avrasm2 -h
```
