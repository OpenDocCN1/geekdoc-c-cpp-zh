# Chapter 9 · Assembly Language Elements

Up to now we have been writing very simple assembly language programs that don't use many of the assembler program capabilities, or assembly language features.

In this chapter we take a more in-depth look at the structure and syntax of assembly language programs, as well as the capabilities of the AVR assembler program. This includes the preprocessor, assembler directives and expressions.

Everything in this chapter applies to the AVR assembler program that comes with Microchip Studio which is known as AVRASM2. The executable assembler program avrasm2.exe is run by Microchip Studio when an assembly language program is built.
