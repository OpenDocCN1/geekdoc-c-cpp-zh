Notice in the memory window at the bottom right of Microchip Studio, with prog FLASH selected in the Memory drop-down list, at the very right column of this window, the text from the DB constant data lines can be seen (the words "Hello", "Hi", and the letters ABC). This is because this column contains the ASCII representation of the numbers in flash program memory. Computers and microcontrollers only work with numbers, so everything stored in memory is a number. ASCII is a standard way that assigns various numbers to characters, such as letters of the alphabet, punctuation marks and numbers 0 to 9. In this way, if a computer receives the number 0x48, it knows to display the letter 'H'. See the ASCII table in Appendix C of this book. Because the strings defined with DB are mixed with null terminators (zeros), numbers from next to the numbers: label, and program instructions, readable text in the memory window is mixed in with unreadable or meaningless characters. The right column in the memory window tries to convert every number in memory to an ASCII character. Some characters are unprintable (numbers 0 to 31 and 127, or 0x00 to 0x1F and 0x7F), and represented by a dot. Others are from the extended ASCII table, and include numbers above 127, or 0x7F. What extended ASCII characters appear as depends on which character or font set is used to display them.

## 9.3.2.3 DW – Define Constant Word

DW, or define constant word, is like DB, or define constant byte, except that it reserves 16-bit spaces in either Flash program memory or EEPROM, rather than 8-bit spaces.

## 9.3.2.4 DD – Define Constant Double-word

DD, or define constant double word reserves 32-bit data spaces in program memory or EEPROM.

## 9.3.2.5 DQ – Define Constant Quad-word

DQ, or define constant quad-word, reserves one or more 64-bit space in program memory or EEPROM.

## 9.3.3 Defining Names for Registers with DEF

DEF is a directive that can be used to give a register a human readable name. In the example that follows, R16 is given the name count. After being given the name count at the beginning of the code using DEF, R16 is referred to as count in the rest of the program. Enter this code into the test_asm project and run it in the simulator to see that when count is cleared, R16 is cleared, and when count is incremented using the INC instruction, R16 is incremented.

```
.DEF count = R16
ldi count, 0x00 ; Clear count register
loop:
inc count ; Increment count register
rjmp loop
```

## 9.3.4 Equating Names to Expressions using EQU and SET

EQU is used to set a human readable name equal to an expression. The expression can be a simple number, as the following example code shows.

```
.DEF count = R16
.EQU count_start = 5
ldi count, count_start ; Value to start counting from
loop:
inc count ; Increment count register
rjmp loop
```

The above code shows that EQU is used to make count_start equal to 5. Wherever count_start is used in the code, 5 is substituted. In this example code, count_start is used to load a value of 5 to R16, by using R16 defined as count using DEF, and making count_start equal to 5 using EQU. This causes the value in R16 to start incrementing from 5 instead of 0. Enter this code into the test_asm project and run it in the simulator.

SET assigns a value to a label in the same way as EQU, but unlike EQU, a label assigned to a value by SET can be changed or redefined later in a program. In the previous code example, SET can directly be substituted in place of EQU.
