# Figure A.7: Select the USBTinyISP Driver

To test the driver installation, plug the USBTinyISP into a USB port of the host computer. Right-click the Windows Start button, and then click Device Manager on the menu that pops up. Expand the Atmel USB Devices item in the Device Manager dialog box by clicking the arrow next to this item. USBTiny should be seen under Atmel USB Devices. If the USBTinyISP is disconnected from the USB port, it will disappear from the Device Manager. When it is plugged back into the USB port it will appear in Device Manager again. Unplug the USBTinyISP from the USB port before connecting it to a circuit.

At this stage the USBTinyISP driver is installed and the USBTinyISP programmer is ready to be used. Go to section A.3.2 to download and install the avrdude programming software.

# A.3.1.3 Arduino Uno Sketch

To use an Arduino Uno as a programmer, a sketch must be loaded to the Arduino. Although other Arduino boards besides the Arduino Uno could be used, only the Uno is covered in this book as it is the most popular Arduino model. These instructions were tested on a genuine Arduino Uno R3 board from www.arduino.cc. Download the Arduino IDE from www.arduino.cc/en/software and install it to the host computer. Find installation instructions at www.arduino.cc/en/Guide for installing the IDE. After installing the Arduino IDE, run the Arduino IDE application and plug the Arduino Uno into a USB port of the host computer. Windows 10 computers will automatically install a driver for a genuine Arduino Uno R3.
