Load the LSB of the first number to R16. Load the MSB of the first number to R17. Load the LSB of the second number to R18. Load the MSB of the second number to R19. We now have:

```
R16 = 0x55   LSB 1
R17 = 0x23   MSB 1
R18 = 0xFF   LSB 2
R19 = 0x01   MSB 2
```

Add the two registers containing the LSBs of each number using the ADD instruction. This is R16 + R18, or 0x55 + 0xFF = 0x54 and a carry of 1. Next, add the MSBs and the carry using the ADC instruction: R17 + R19 + carry, or 0x23 + 0x01 + 0x01 = 0x25. The result of these additions is the two 8-bit addition results put side by side: 0x2554 (9556). This example in code looks as follows. Remember to place an infinite loop below this code.

# test.asm : main.asm – Addition of two 16-bit numbers in 8-bit registers

```
; Add 9845 (0x2355) to 511 (0x01FF)
ldi r16, low(9555) ; Load first number LSB (0x55)
ldi r17, high(9455) ; Load first number MSB (0x23)
ldi r18, low(511) ; Load second number LSB (0xFF)
ldi r19, high(511) ; Load second number MSB (0x01)
add r16, r18 ; Add LSBs
adc r17, r19 ; Add MSBs with carry
```

To make it easier to use decimal notation in the program, the low() and high() functions are used to load the appropriate parts of the numbers to the desired register in byte sizes. The low() function gets the low byte of a 16-bit number and the high() function gets the high byte of a 16-bit number.

Load the above code in the Microchip Studio debugger using the simulator, and step through the program instructions while watching the results in the Processor Status window. R16 and R18 are added with the result stored in R16 and a carry generated, as can be seen by the carry flag in the Status Register. ADC is used to add R17 to R19 (the MSBs) and the carry flag from the LSB addition. The result is stored in R17. We now have the 16-bit addition result in R16 (LSB) of 0x54 and R17 (MSB) containing 0x25. Putting the two register values together we get a result of 0x2554, or 9556.
