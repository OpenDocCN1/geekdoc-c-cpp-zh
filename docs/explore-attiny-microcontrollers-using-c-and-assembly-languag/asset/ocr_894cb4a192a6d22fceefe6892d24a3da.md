# Chapter 1 • Overview of ATtiny Microcontrollers

This chapter takes a look at ATtiny microcontrollers that are available in DIP packages and can be programmed using an ISP programmer. ISP programming can be done using any of the Microchip AVR USB programmers as well as most hobby programmers built for 8-bit AVRs.

Basics of 8-pin, 14-pin, 20-pin and 28-pin ATtiny microcontrollers are covered.

# In this Chapter

+   - An overview of DIP packaged ATtiny AVR microcontrollers that can be programmed in-circuit
+   - A parametric table for easily comparing different ATtiny parts
