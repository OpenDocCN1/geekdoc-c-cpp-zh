This variable can be called VIL which stands for value or variable (V) of the inner loop (IL), which is mathematically written with the last two letters as subscript:

# V_IL = value or variable of inner loop

Substituting the new names for the unknown value and the variable into the calculation, we get the following.

```
((1 + 2) × (3 – 1)) + 1 + 1 = 8
```

becomes

```
((1 + 2) × (V_IL – 1)) + 1 + 1 = C_IL
```

Writing that the normal way for a mathematical equation with the unknown on the left, we get:

```
C_IL = ((1 + 2) × (V_IL – 1)) + 1 + 1
```

Simplifying the equation by doing the addition of known values we get:

```
C_IL = (3 × (V_IL – 1)) + 2
```

Further simplification by doing the multiplication gives us:

```
C_IL = (3V_IL – 3) + 2
```

Which is the same as:

```
C_IL = 3V_IL – 1
```

We can now work out the clock cycles for the outer loop, which includes the inner loop.

The code with the operands removed is repeated below for convenience.

```
ldi     1 +     ; Clock cycle used up once upon entry
deloop: 1 +     ; Clock cycle used every pass through outer loop
ldi     1 +     ; CIL - Clock cycles used by inner loop
inner_loop 1 +  ; Clock cycle used by outer loop
dec     1 +     ; Clock cycles on outer loop, except for last pass
brbc    (2 x 2) or 1 + ; Not counted in this example
ret
```

With a value of 3 loaded to R16, which is the outer loop count, and calling the inner loop calculation inner_loop we get the following calculation.

```
1 + ((1 + inner_loop + 1 + 2) x 2) + (1 + inner_loop + 1 + 1)
```
