### A.3.5.3 Add a Toolbar Button for the External Tool

It is much easier to click a toolbar button to load a program to the target AVR than having to select the external programmer using the top Tools menu. We now set up a toolbar button for the external tool that we just added to Microchip Studio.

In Microchip Studio, select Tools ▶ Customize... from the top menu. In the Customize dialog box, click the Commands tab. Now click the Toolbar radio button. In the drop-down list next to the Toolbar radio button, select Device and Debugger – this selects a toolbar called Device and Debugger that we will add our programming button to. Click the Add Command... button. In the left pane of the Add Command dialog box, click Tools. In the right pane of the Add Command dialog box, scroll down to find External Command 1 and click it to select it. Click the OK button in the Add Command dialog box. The Customize dialog box should now look like Figure A.10. Click the Close button in the Customize dialog box. A button with the same name given to the external tool in the Title field of the External Tools dialog box will be seen on one of the toolbars in Microchip Studio – next to the part number for the currently open project.

![](img/83ef13a6c66cc7882b2f357e97f451dc_353_0.png)

Figure A.10: Adding a Toolbar Button in the Customize Dialog Box

In the above procedure, External Command 1 corresponds to the first external tool added. If additional external tools are to be added, they will correspond to External Command 2, and so on. In this way a button can be added for each external tool.

### A.3.6 Testing the Programmer

After setting up a hobby programmer as an external tool in Microchip Studio, we are now ready to test the programmer. At this stage the programmer should be connected to an AVR circuit on a breadboard, as already described in this appendix. Check that the programmer is wired to the circuit correctly. If the programmer is to be used to power the circuit, make sure that 5V from the programmer is connected to the circuit. If the circuit is to be powered from an external power supply, disconnect the 5V or VCC connection from the programmer. Plug the programmer into a USB port of the host computer. If using an external power supply, switch it on.

With the ATtiny circuit connected to the programmer and powered up, and with one of the LED blink projects open in Microchip Studio, make sure that the project is built by clicking the Build toolbar button. Click the program button that we set up in the previous step to load the program to the target ATtiny microcontroller. Alternatively, click Tools on the top menu and then click the programmer on the menu that opens to load the program to the target ATtiny.

If all goes well during programming, the LED connected to the target ATtiny will start flashing or blinking. Output messages from avrdude appear at the bottom of Microchip Studio and shows success with a message that should look similar to the following.

```
avrdude.exe: verifying ...
avrdude.exe: 26 bytes of flash verified
```

### A.3.7 Programming Problems and Solutions

If there were problems programming the target AVR microcontroller, then first look at the output from avrdude that pops up at the bottom of Microchip Studio. Scroll through this text to try and find out what is wrong. If power was not connected, or the wrong part code was passed to avrdude, that can usually be found in the avrdude output text.

Check for the obvious, such as if the programmer is connected to the target AVR correctly, and that the programmer can be found in the Device Manager in Windows. If a USB cable is used to connect the programmer to the host computer, then check if the USB cable is faulty. Some USB cables are for charging only and have power connected, but not data.

Programmers usually have a power LED that lights up when they are connected to a USB port – check that the LED lights up.

Go back and check that the parameters passed to avrdude are correct and everything in the fields of the External Tools dialog box is correct for the programmer and target AVR microcontroller used.

If the program loads to the target ATtiny, but the LED does not blink, then check that the LED and series resistor are wired correctly, and that the LED blink program code is exactly as found in this book.
