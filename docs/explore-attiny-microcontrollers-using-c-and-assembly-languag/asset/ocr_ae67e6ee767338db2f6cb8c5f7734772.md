```
R16 = R17 = 0

Ct: = 3 x (R17 x R16 + R16)
    = 3 x (0 x 0 + 0)
    = 0 -- FAIL, measured result is 197376
```

```

    = 3 x (255 x 0 + 0)

    = 3 x (0 x 255 + 255)
    = 765 -- FAIL, measured result is 196605
```

The above test cases show that it is not possible to use 0 for either R16 or R17 in our formula, because the formula does not take into consideration these extreme cases that are the result of decrementing 0 before testing. After considering the previous test cases, we can finally summarize our formula in full as follows:

For: VIL > 0 and VOL > 0 (These values must also be ≤ 255 because of 8-bit register size)
CT = 3{(VIL.VOL + VOL)}
Where:
CT – total clock cycles
VIL – value or variable of inner loop
VOL – value or variable of outer loop

Whereas the previous summary uses a general formula, a more specific formula for the particular code using R16 for the outer loop and R17 for the inner loop, we get:

For: R17 > 0 and R16 > 0
CT = 3 x (R17 x R16 + R16)
Where:
CT – total clock cycles
R17 – value in register R17 used for inner loop
R16 – value in register R16 used for outer loop
