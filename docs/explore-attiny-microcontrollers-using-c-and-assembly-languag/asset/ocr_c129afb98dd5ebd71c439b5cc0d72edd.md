# Figure A.6: Running the Adafruit Drivers Application

When the Adafruit drivers application starts, you will need to agree to the license terms by clicking the I Agree button. In the next dialog box various drivers can be selected using checkboxes. Only the item that has USBtinyISP at the end needs to be checked in this dialog box, as shown in Figure A.7 on the next page. This item is labeled Trinket / Pro Trinket / Gemma (USBtinyISP), as can be seen in the figure. Click the Install button after selecting the correct driver.

During the installation, a dialog box will pop up, asking if you would like to install device software for the USBtiny device. Click the Install button to continue. After the driver installation has completed, click the Close button in the Adafruit driver installer window.
