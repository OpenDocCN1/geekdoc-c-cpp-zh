The program counter or PC continues to be incremented by one and the instruction that it points to is fetched and executed each time. Instructions are fetched and executed sequentially until a branch or jump instruction is executed that causes a non-sequential address to be loaded to the program counter. Once the jump has occurred, the instruction at the new address is fetched and executed, then the program counter continues to increment by one causing the microcontroller to fetch and execute sequential instructions after the new address that it jumped to. Calling a subroutine and returning from a subroutine also causes the address in the program counter to be altered so that the subroutine can be run. The above explanation assumes 16-bit wide instructions.
