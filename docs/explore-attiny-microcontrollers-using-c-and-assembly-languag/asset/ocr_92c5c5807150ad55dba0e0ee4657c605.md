BST and BLD are the pair of instructions that are exceptions to being synonyms for the BSET and BCLR instructions. BST stores the specified bit from the specified register in the T bit of the status register. This instruction has the form BST Rd,b where Rd is the register to operate on which can be R0 to R31, and b is the bit in the register from 0 to 7. For example, BST R16,7 stores bit 7 of R16 in the status register T bit. Branch instructions BRTS or BRTC can then be used to check whether the bit is set or clear. BLD loads the T bit from the status register to the specified bit in the specified register. BLD has the form BLD Rd,b where Rd is the destination register and b is the specified bit. For example the instruction BLD R16,1 loads the T bit from the status register to bit 1 in R16. Pairs of 8 instructions follow that are synonyms for the previous BSET and BCLR instructions.

# Set or Clear Carry Flag – SREG C Bit

+   **SEC (Set Carry Flag)**
+   Sets the C flag in the status register. Equivalent to BSET SREG_C.

+   **CLC (Clear Carry Flag)**
+   Clears the C flag in the status register. Equivalent to BCLR SREG_C.

# Set or Clear Negative Flag – SREG N Bit

+   **SEN (Set Negative Flag)**

+   **CLN (Clear Negative Flag)**
+   Clears the N flag in the status register. Equivalent to BCLR SREG_N.

+   **CLZ (Clear Zero Flag)**
+   Clears the Z flag in the status register. Equivalent to BCLR SREG_Z.
