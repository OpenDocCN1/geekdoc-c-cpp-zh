Blocks in other Algol-like languages establish similar scope rules. For example, in the following Ada code,

```
B1: declare
    x: integer;
    y: boolean;
    begin
    x := 2;
    y := false;
    B2: declare
        a, b: integer;
        begin
            if y then a := x;
            else b := x;
            end if;
        end B2;
    ...
end B1;
```
