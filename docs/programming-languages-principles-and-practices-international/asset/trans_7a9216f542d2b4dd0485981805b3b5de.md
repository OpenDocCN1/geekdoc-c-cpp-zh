

```cpp
class A{

// A C++ class

public:

// all public members here

protected:

// all protected members here

private:

// all private members here

};
```

（请注意右花括号后的最后一个分号，这是C语法的残留；分号前可以出现一个变量名列表，其数据类型就是前面的类定义。）

在C++中，对象的初始化与Java一样，由与类同名的构造函数完成。当对象在内存中分配空间时，构造函数会被自动调用，同时构造函数的实际参数也会在此时求值。因此，构造函数与Java中的类似，区别在于C++中的对象不必是引用，因此构造函数既可以在声明中作为一部分被自动调用，也可以在new表达式中被调用。与Java不同，C++没有必需的内置垃圾回收机制，因此C++还包含析构函数；析构函数与构造函数一样与类同名，但前面带有波浪号“~”（在逻辑中有时用来表示“非”）。当对象被释放（要么超出作用域，要么通过delete运算符）时，析构函数会被自动调用，但它们必须由程序员提供，因此代表了一种手动释放内存的方式。

C++中的类声明并不总是包含所有成员函数的实现代码。通过在类名后使用双冒号“::”表示的作用域解析运算符，可以在声明外部实现成员函数。它得名于这样一个事实：它会使类声明的作用域被重新进入。在类声明中给出实现的成员函数会被自动假定为内联（也就是说，编译器可能会用函数的实际代码替换函数调用）。

作为C++中的第一个示例，我们给出一个复数类的部分定义：

```cpp
class Complex{

public:

// Constructor
Complex(double r = 0, double i = 0)
: re(r), im(i) { }
```

这意味着**re**被初始化为**r**的值，**im**被初始化为**i**的值。换句话说，上述代码与以下代码的含义基本相同：

```cpp
Complex(double r = 0, double i = 0){
    re = r; im = i;
}
```

构造函数也为其参数给出了默认值：

```cpp
Complex(double r = 0, double i = 0)
```

这允许用0、1或2个参数创建Complex对象，并且避免了创建不同重载构造函数的需要：

```cpp
Complex i(0,1);  // i constructed as (0,1)
Complex y;       // y constructed as default (0,0)
Complex x(1);    // x constructed as (1,0)
```

### 5.4.2 使用模板类实现泛型集合

你在5.3.2节中看到了如何在Java中定义泛型集合类。C++使用一个名为**模板类**的类似特性来定义泛型集合。虽然C++的标准模板库（STL）包含几个内置的集合类，但让我们开发一个LinkedStack类来看C++模板类是如何工作的。

我们的C++ LinkedStack类与5.3.2节中讨论的Java版本具有相同的基本接口。下面是一个简短C++程序，它测试了该类的部分能力：

```cpp
#include <iostream>
using std::cout;
using std::endl;
#include "LinkedStack.c"

int main(){
    int number;
    LinkedStack<int> stack;
    for (number = 1; number <= 5; number++)
        stack.push(number);
    cout << "The size is " << stack.size() << endl;
    while (stack.size() != 0)
        cout << stack.pop() << " ";
    cout << endl;
}
```

正如你所看到的，这段代码以类似于Java版本的方式声明了一个栈类型，尽管在这种情况下，**int**类型可以直接指定为栈的元素类型。然而，与Java不同，只要在声明中提及变量**stack**，一个新的**LinkedStack**对象就会被自动创建并赋值给该变量。除此之外，**LinkedStack**的用法与Java示例完全相同。

我们的Java版LinkedStack通过继承AbstractCollection类利用了继承和多态，该类提供了更高级别的功能并作为其他集合类的接口。由于C++中没有这个类，我们将LinkedStack定义为一个顶层类。我们的C++版本包含一个构造函数、一个析构函数（稍后会详细讨论）、公共的栈实例方法、一个嵌套节点类型，以及一个用于分配和初始化新节点的辅助方法。以下是该类的代码：

```cpp
template <class E> class LinkedStack{

    public:

    // Constructor
    LinkedStack()
    : top(0), mySize(0) {}

    // Destructor
    ~LinkedStack(){
        while (size() > 0)
            pop();
    }

    E peek(){
        return top->data;
    }

    E pop(){
        E element = top->data;
        node * garbage = top;
        top = top->next;
        mySize -= 1;
        delete garbage;    // Must return node storage to the heap
        return element;
    }

    void push(E element){
        top = getNode(element, top);
        mySize += 1;
    }

    int size(){
        return mySize;
    }

    private:

    // The node type for LinkedStack
    struct node{
        E data;
        node* next;
    };

    // Data members for LinkedStack
    node* top;
    int mySize;

    // Helper method to initialize a new node
    node* getNode(E data, node * next){
        node * newNode = new node;
        newNode->data = data;
        newNode->next = next;
        return newNode;
    }

};
```

类头中的记号`template <class E>`为栈的元素类型引入了类型参数E。在编译时，该参数将由客户端程序代码中的实际C++类型填充。构造函数和公共实例方法与前面讨论的Complex类类似。

然而，由于LinkedStack类对其节点使用动态存储，它还应包含一个析构函数。当客户端程序无法再访问LinkedStack对象时（例如，当创建临时栈的函数从其调用返回时），该方法的任务是将每个节点返回给系统堆。析构函数通过弹空栈来实现这一点。反过来，pop方法使用delete运算符手动将刚从链接结构中移除的节点返回给系统堆。由于C++没有自动垃圾回收，如果未能以这种方式回收存储，就会造成内存泄漏，进而可能导致生产环境中的内存问题。

还要注意，节点类型是一个C风格的struct，但也可以改为定义为C++类。因为节点只是数据和链接的私有容器，所以使用struct以及一个构建并返回指向已初始化节点的指针的私有方法getNode也同样有效。

最后，使用显式的C风格指针而不是引用，说明了Java与C++之间的另一个区别。即使我们在C++中定义了一个Node类，我们仍然必须使用*运算符来指示到下一个节点的链接，以及一个指向节点本身的指针变量。

### 5.4.3 静态绑定、动态绑定和虚函数

C++中将成员函数的动态绑定作为一种选项提供，但它不是默认行为。所有成员函数在编译时都是静态绑定的。只有使用关键字`virtual`定义的函数才可能进行动态绑定。例如，如果我们想为从矩形派生的正方形重新定义area函数，在C++中应如下操作：

```cpp
class Rectangle{
    public:
        virtual double area(){
            return length * width;
        }
        ...
    private:
        double length,width;
};

class Square : public Rectangle{
    public:
        double area(){            // redefines rectangle::area dynamically
            return width * width;
        }
        ...
};
```

当然，在这个示例中，我们真正想要的是抽象类ClosedFigure中的一个抽象area函数。在C++中，这可以通过使用所谓的纯虚声明来实现：

```cpp
class ClosedFigure{            // an abstract class
    public:
        virtual double area() = 0; // pure virtual
        ...
};

class Rectangle : public ClosedFigure{
    public:
        double area(){
            return length * width; }
```
