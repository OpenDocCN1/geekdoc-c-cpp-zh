5.34 Given the following code in Java:

```
class A{
    public void p(){
        System.out.println("A.p");
    }
    public void q(){
        System.out.println("A.q");
    }
    public void r(){
        p();
        q();
    }
}
class B extends A{
    public void p(){
        System.out.println("B.p");
    }
}
class C extends B{
    public void q(){
        System.out.println("C.q");
    }
    public void r(){
        q();
        p();
    }
}
...
A a = new B();
a.r();
a = new C();
a.r();
```

What does this code print? Why?
