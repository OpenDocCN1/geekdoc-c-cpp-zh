As an example, let us reduce the while statement of the program

```
n := 0 - 3;
if n then i := n else i := 0 - n fi;
fact := 1;
while i do
    fact := fact * i;
    i := i - 1
od
```

to its environment value. The environment at the start of the while-loop is {n = -3, i = 3, fact = 1}. Since <i | {n = -3, i = 3, fact = 1}> => <3 | {n = -3, i = 3, fact = 1}> and 3 > 0, rule 24 applies, so by rule 18 we must compute the environment resulting from the application of the body of the loop to the environment {n = -3, i = 3, fact = 1}:

<fact := fact * i | {n = -3, i = 3, fact = 1}> =>
<fact := 1 * i | {n = -3, i = 3, fact = 1}> =>
<fact := 1 * 3 | {n = -3, i = 3, fact = 1}> =>
<fact := 3 | {n = -3, i = 3, fact = 1}> =>
{n = -3, i = 3, fact = 3}

and

<i := i - 1 | {n = -3, i = 3, fact = 1}> =>
<i := 3 - 1 | {n = -3, i = 3, fact = 3}> =>
<i := 2 | {n = -3, i = 3, fact = 3}> =>
{n = -3, i = 2, fact = 3}

so

<while i do ... od | {n = -3, i = 3, fact = 1}> =>
< fact := fact * i ; i := i - 1; while i do ... od | {n = -3, i = 3, fact = 1}> =>
< i := i - 1; while i do ... od | {n = -3, i = 3, fact = 3}> =>
< while i do ... od | {n = -3, i = 2, fact = 3}>

Continuing in this way, we get:

<while i do ... od | {n = -3, i = 2, fact = 3}> =>
<while i do ... od | {n = -3, i = 1, fact = 6}> =>
<while i do ... od | {n = -3, i = 0, fact = 6}> =>
{n = -3, i = 0, fact = 6}

so the final environment is {n = -3, i = 0, fact = 6}.
