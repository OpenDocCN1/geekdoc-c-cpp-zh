which itself includes ajdefine.h, which includes ajarch.h:

```
#ifdef __cplusplus
extern "C"
{
#endif

#ifndef ajdefine_h
#define ajdefine_h

#include "ajarch.h"
.
.
```

If you develop library code that uses the fundamental types, you must include ajdefine.h explicitly. For example from ajstr.h:

```
#ifdef __cplusplus
extern "C"
{
#endif

#ifndef ajstr_h
#define ajstr_h

#include "ajdefine.h"
#include "ajtable.h"
.
.
```

# 5.1.3 Derived types

A potentially infinite number of other types may be derived from the fundamental C datatypes as follows:

+   - Arrays of objects of a single type
+   - Functions returning objects of a single type
+   - Pointers to objects of a given type
+   - Structures of objects of various types
+   - Unions capable of holding one of several objects of different datatypes.

'Object' here might refer to a variable with a primitive datatype, to a function, to a data structure and so on. In general these methods can be applied in a compound manner. It is possible, for instance, to have a data structure that includes an array of functions which all return a pointer to an array of float variables. Pointers provide a handle on objects of a particular type and are used when managing memory for objects.
