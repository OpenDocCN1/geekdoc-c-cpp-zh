# Note

entrails is not compiled in a standard EMBOSS installation because it is in the ‘make check’ section of the Makefile.am file.

To compile the "check_PROGRAMS" applications, type:

```
make check
```

from the applications directory. If for some reason that fails (the section is after all reserved for applications that are in active development) edit the Makefile.am files accordingly so that entrails.c is treated as a normal application, and compile it as usual. For further information see Section 1.2, ‘Installation of CVS (Developer’s) Release’.
