## EMBOSS 开发者指南

欧洲分子生物学开放软件套件（EMBOSS）是一套高质量、文档齐全的面向分子生物学的开源软件工具包。它包含超过 200 个生物信息学应用程序，采用统一的命令行界面，并得到许多图形界面和工作流软件的支持。EMBOSS 包含广泛且可扩展的 C 编程库，为从零开始开发新的生物信息学工具提供了强大而可靠的工具包。

- 利用丰富的内置功能，无需或只需少量额外编码。
- 全面且一致的应用程序编程接口（API）。
- 强大的命令行界面自动处理。
- 大量用于控制程序行为和指定 IO 数据的限定符。
- 支持简单和复杂（生物）数据类型，并具有易于配置的数据库。
- 利用自动文件格式处理——无需自行编码。
- 代码文档齐全并已编入索引，便于搜索和导航；无需深入了解内部机制。
- 所有代码均采用 ANSI 标准 C 编写，并有定义的编码和文档标准。

EMBOSS 开发者指南是在 EMBOSS 下开发软件的官方权威指南。它包含全面的参考信息和指南，包括逐步说明和真实世界的代码示例：

- 学习如何在 EMBOSS 开发人员的指导下编写功能齐全的工具。
- 内容全面且最新——您需要的所有信息触手可及。
- 编写 EMBOSS 应用程序的逐步指南，并配有功能完善、已部署的代码示例。
- ACD 文件开发——学习如何在不编码的情况下自定义现有工具，或设计和编写全新的应用程序界面。
- EMBOSS API 编程指南——按主题组织，帮助您快速掌握应用程序开发。
- 在 EMBOSS 下封装和移植应用程序——学习如何集成第三方工具。
- 无需任何 EMBOSS 使用经验。

Peter M. Rice 是欧洲生物信息学研究所（EMBL-EBI，英国 Hinxton）的小组负责人，该中心是生物信息学研究与服务机构，也是欧洲分子生物学实验室（EMBL）的一部分。Peter 于 1996 年在桑格中心（英国 Hinxton）任职期间发起了 EMBOSS 项目，与 Alan Bleasby（SEQNET，Daresbury）合作，并与 Thure Etzold（EMBL-EBI）协作。

Alan J. Bleasby 是 EMBL-EBI 的高级科学官员。他在达尔斯伯里实验室（英国 Warrington）开发了早期的 EMBOSS 编程库（AJAX），并负责 SEQNET 英国国家生物信息学服务。他目前全职从事 EMBOSS 工作。

Jon C. Ison 自 2000 年起一直是 EMBOSS 的开发者。他也位于 EMBL-EBI，并与 Peter 和 Alan 一起协调 EMBOSS 工作。他目前正在从事本体学、数据集成和应用程序开发方面的工作。

EMBOSS 团队感谢以下机构对本项目的慷慨支持，包括 Wellcome Trust、医学研究委员会、生物技术与生物科学研究委员会（BBSRC）和 EMBL-EBI。
