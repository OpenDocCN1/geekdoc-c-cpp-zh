For floating point number input:

```
float: minscore
[
    default: "0.0"
    minimum: "0.0"
    information: "Minimum score of feature to display"
]
```

# 6.4.4.3 boolean

For boolean input:

```
boolean: feature
[
    default: "N"
    information: "Use feature information"
]
```

For toggle input:

```
toggle: tolower
[
    default: "N"

]
```
