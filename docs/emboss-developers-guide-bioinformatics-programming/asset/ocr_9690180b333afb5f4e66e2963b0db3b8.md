which is why farray can be deleted. Had ajHistDataAdd been used instead then AJFREE would not have been called:

```
void func(AjPHist hist, const ajint * results, ajint npts, ajint hist_num)
{
    ajint i;

    float *farray;

    AJCNEW(farray, npts);
    for(i=0; i<npts; i++)
        farray[i] = (float) results[i];

    ajHistDataCopy(hist, hist_num, farray);
    AJFREE(farray);
}
```
