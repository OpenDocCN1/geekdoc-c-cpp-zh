# 6.4.6.1 Retrieval of simple ACD datatypes

To retrieve data from the ACD file a simple variable or object pointer is declared as required, and then initialised using the appropriate ajAcadGet* function.

# 6.4.6.1.1 integer

```
```c
ajint wordsize = 0;
wordsize = ajAcadGetInt("wordsize");
```
```

# 6.4.6.1.2 float

```
```c
float minscore = 0.;
minscore = ajAcadGetFloat("minscore");
```
```

# 6.4.6.1.3 boolean

```
```c
AjBool showall = ajFalse;
showall = ajAcadGetBoolean("showall");
```
```

# 6.4.6.1.4 toggle

```
```c
AjBool tolower = ajFalse;
tolower = ajAcadGetToggle("tolower");
```
```

# 6.4.6.1.5 string

```
```c
AjPStr delimiter = NULL;
delimiter = ajAcadGetString("delimiter");
```
```

# 6.4.6.1.6 array

```
```c
AjPFloat thresholds = NULL;
thresholds = ajAcadGetArray("thresholds");
```
