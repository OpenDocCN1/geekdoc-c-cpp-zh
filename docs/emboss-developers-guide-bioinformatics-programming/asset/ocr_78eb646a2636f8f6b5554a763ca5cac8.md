# C.2.3.3 Braces

Matching braces should appear in the same column and indentation should be consistent. This is good:

```
```c
int fred(void)
{
    ...
    for(i=0; i<LIMIT; ++i)
    {
        ...
    }
    return 0;
}
```
```

whereas this is messy:

```
```c
int fred(void) {
    ...
    for(i=0; i<LIMIT; ++i) {
        ...
    }
    return 0;
}
```
```

and so is this:

```
```c
int fred(void)
{
    ...
    for(i=0; i<LIMIT; ++i)
        {
        ...
        } ...
    return 0;
}
```
```

Don't use braces unnecessarily. The following is good:

```
```c
for(i=0; i<LIMIT; ++i)
    sum += i;
```
```

but this code is cluttered:

```
```c
for(i=0; i<LIMIT; ++i)
{
    sum += i;
}
```
```
