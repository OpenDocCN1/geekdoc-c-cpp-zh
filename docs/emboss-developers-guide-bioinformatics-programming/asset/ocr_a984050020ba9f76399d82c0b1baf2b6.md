# 1.4 Project mailing lists

There are three EMBOSS mailing lists which you can join. These provide a forum for discussions about EMBOSS and its future development and are a valuable source of help.

# 1.4.1 User mailing list

```
emboss@emboss.open-bio.org
```

This is an open list (anyone can join) for general announcements and discussions by end-users. To subscribe to this list, please visit:

```
http://emboss.open-bio.org/mailman/listinfo/emboss
```

# 1.4.2 Developer mailing list

```
emboss-dev@emboss.open-bio.org
```

This is a closed list for discussions by developers using EMBOSS. To subscribe to this list, please visit:

```
http://emboss.open-bio.org/mailman/listinfo/emboss-dev
```

If you wish to contribute to EMBOSS, please send the code and documentation to:

```
emboss-submit@emboss.open-bio.org
```

```
emboss-announce@emboss.open-bio.org
```
