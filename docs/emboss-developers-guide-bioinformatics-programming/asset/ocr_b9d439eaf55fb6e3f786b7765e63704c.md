# ## A.7 Sequence types

All of the sequence ACD datatypes have an attribute called `type:`. Not surprisingly, this is used to limit the kind of sequence that EMBOSS will accept. The `type:` attribute describes the type of the sequence as a single token. The EMBOSS initialisation routines will try to establish the type, by reading the (first) sequence and examining the contents. Possible values for the `type:` attribute are listed in the table below.

Table A.6. ACD Sequence Types
