# 10.4.3.2 File reformatting and housekeeping

Code was added, where necessary and possible, to reformat the input files by using temporary files. Code to reformat the output files, again by using temporary files, was again added where necessary. Finally code to clean up memory for the ACD variables was added.

# 10.4.3.3 Command line generation

The hardest part of the code was to construct the call to the HMMER command line, but this is quite trivial once all the options are properly understood. A few tricky issues arose in generating the command line and you’ll see these in the code later. These were documented in the code to save others time in the future. You should always document such tricky steps in your own code.

# 10.4.4 Quality assurance testing

Quality assurance tests (Section 7.2, ‘Application quality assurance’) were written for the applications. These were based on the examples in the tutorial which use files from the HMMER distribution. In cases where test data are not already available then these would have to be collected.

# 10.4.5 Documentation

The documentation consisted of a README file for the package distribution and the standard EMBASSY package and application documentation.

A README file for the package distribution was written to cover all the basics and included the following topics:

+   - How to download the original and EMBASSY versions of HMMER
+   - Where to get installation instructions and documentation
+   - Requirements, caveats, etc.
+   - Differences in the application between the two versions (see below).

A note was made for each application to describe:

+   - Which HMMER options are supported as ACD qualifiers
+   - Any new qualifiers and parameters in the EMBOSS version
+   - If the order of parameters was changed.

Formal documentation for the package was then generated following the guidelines (Section 8.2, ‘Application documentation’). For many of the sections in the application documentation, text could be pasted in directly from the original documentation. No new documentation, other than the README file already described, was written. Once the text was inserted the EMBOSS-provided scripts were used to generate full documentation files automatically.
