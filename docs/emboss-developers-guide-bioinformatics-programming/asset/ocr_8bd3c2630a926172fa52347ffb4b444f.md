# ### 6.7.4.1 Parameter name

All data definitions for sequence input and output should have standard parameter names:

+   - sequence for any sequence inputs\n- outseq for any outputs\n- Alternatives and variations (e.g. asequence and bsequence for multiple inputs are allowed).

See Appendix A, ACD syntax reference.

# ### 6.7.4.2 Common attributes

Attributes that are typically specified are summarised below. They are datatype-specific (Section A.5, ‘Datatype-specific attributes’) unless they are indicated as being global attributes (Section A.4, ‘Global attributes’).

+   **parameter:** Sequences are typically the primary input or output of an EMBOSS application and, as such, should be defined as parameters by using the global attribute parameter: "Y".\n**type:** Specifies the type of the input or output sequence(s) for validation purposes. See Section A.7, ‘Sequence types’.\n**aligned:** Any seqset or seqsetall datatype must have the aligned: attribute set to indicate whether the sequences are aligned or not.\n**features:** Sequence features (Section 6.9, ‘Handling features’) will (if available) be read or written if the features: ACD attribute is set for the input or output sequence(s).\n**osformat:** FASTA format is used by default for the output sequence(s). The format is normally set at the command line but a default may be hard-coded with osformat:. All common sequence formats are supported (see the EMBOSS User’s Guide).
