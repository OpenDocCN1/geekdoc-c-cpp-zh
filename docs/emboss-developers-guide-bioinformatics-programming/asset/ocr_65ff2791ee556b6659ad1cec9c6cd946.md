# ## 6.20.7.1 Output graphics retrieval

To retrieve an output graphics object an object pointer is declared and then initialised using the appropriate ajAcdGet* function.

# ### 6.20.7.1.1 graph

```
AjPGraph graph=NULL;
graph = ajAcdGetGraph("graph");
```

# ### 6.20.7.1.2 graphxy

```
AjPGraph graph=NULL;
graph = ajAcdGetGraphxy("graph");
```

# ## 6.20.7.3 Memory and file management

Your application code will call embInit or embInitPV to process the ACD file and command line. All values from the ACD file are read into memory and files are opened as necessary. You have a handle on the files and memory through the ajAcdGet* family of functions which return pointers to appropriate objects. It is your responsibility to call the graphics library to close any files and free up memory at the end of the program.

# ### 6.20.7.3.1 Closing graphics files

To close an output graphics file call ajGraphicsClose. It closes graphics output through the PLplot library, closing any output files and screen displays:

```
AjPGraph graph=NULL;
graph = ajAcdGetGraphxy("graph");
/* Do something with graph */
ajGraphicsClose();
```
