# Install the Nagios web interface:

```
```bash
sudo make install-webconf
```
```

# Create User for Web Interface

Create a user for the web interface. You will be
prompted to create a password for this user:

```
```bash
sudo htpasswd -c /usr/local/nagios/etc/htpasswd.users
nagiosadmin
```
```

# Configure Apache

Enable the Apache rewrite and cgi modules:

```
```bash
sudo a2enmod rewrite
```
```

```
```bash
sudo a2enmod cgi
```
```

# Restart Apache
