according to the Nagios plugin API specification, which\nallows Nagios to understand the result of the check.

# Add the Custom Plugin to Nagios

Once you've created your custom plugin, you can add it\nto Nagios. Copy your script into the Nagios plugins\ndirectory, make it executable (chmod +x script.sh), then\nadd a new command definition and a service definition\nto your Nagios configuration:

```
define command{

    command_name    check_failed_ssh

    command_line
/usr/local/nagios/libexec/check_failed_ssh.sh

}

    use                local-service

    host_name                  your-host-name
```
