# Compile and Install Nagios

Compile and install Nagios:

```
```bash
./configure --with-nagios-group=nagios --with-command-
group=nagcmd --with-httpd-conf=/etc/apache2/sites-
enabled
```
```

```
`make all`
```

```
`sudo make install`
```

```
`sudo make install-init`
```

```
`sudo make install-config`
```

```
`sudo make install-commandmode`
```
