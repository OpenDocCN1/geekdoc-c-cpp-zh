The controlling conditional expression of an *if_statement* (§12.8.2), *while_statement* (§12.9.2), *do_statement* (§12.9.3), or *for_statement* (§12.9.4) is a *boolean_expression*. The controlling conditional expression of the ?: operator (§11.15) follows the same rules as a *boolean_expression*, but for reasons of operator precedence is classified as a *null_coalescing_expression*.

A *boolean_expression* E is required to be able to produce a value of type `bool`, as follows:

+   - If E is implicitly convertible to `bool` then at run-time that implicit conversion is applied.
+   - Otherwise, unary operator overload resolution (§11.4.4) is used to find a unique best implementation of `operator true` on E, and that implementation is applied at run-time.
+   - If no such operator is found, a binding-time error occurs.
