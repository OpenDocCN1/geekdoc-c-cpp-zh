A join clause that explicitly specifies a range variable type

```

```

The translations in the following sections assume that queries have no explicit range variable types.

*Example: The example*

```
```

where c.City == "London"
select c
```
```

is translated into

```
```

select c

```
```
customers.
Cast<Customer>().
Where(c => c.City == "London")
```
```

*end example*

# ### 11.17.3.4 Degenerate query expressions

A query expression of the form

```
```
from «x» in «e» select «x»
```
```

is translated into

```
```
( «e» ) . Select ( «x» => «x» )
```
```

*Example: The example*

```
```
from c in customers
select c
```
```

is translated into

```
```
(customers).Select(c => c)
```
```

*end example*

A degenerate query expression is one that trivially selects the elements of the source.

*Note: Later phases of the translation (§11.17.3.6 and §11.17.3.7) remove degenerate queries introduced by other translation steps by replacing them with their source. It is important, however, to ensure that the result of a query expression is never the source object itself.
