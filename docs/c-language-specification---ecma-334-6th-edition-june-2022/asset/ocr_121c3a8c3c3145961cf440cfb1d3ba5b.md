A let expression along with its preceding from clause:

```
from «x» in «e»
let «y» = «f»
...
```

is translated into

```
from * in ( «e» ) . Select ( «x» => new { «x» , «y» = «f» } )
...
```

Example: The example

```
from o in orders
let t = o.Details.Sum(d => d.UnitPrice * d.Quantity)
where t >= 1000
select new { o.OrderID, Total = t }
```

is translated into

```
from * in (orders).Select(o => new { o, t = o.Details.Sum(d => d.UnitPrice *
d.Quantity) })
where t >= 1000
select new { o.OrderID, Total = t }
```

the final translation of which is

```
orders
.Select(o => new { o, t = o.Details.Sum(d => d.UnitPrice * d.Quantity) })
.Where(x => x.t >= 1000)
.Select(x => new { x.o.OrderID, Total = x.t })
```

where x is a compiler generated identifier that is otherwise invisible and inaccessible.
end example

A where expression along with its preceding from clause:

```
from «x» in «e»
where «f»
...
```

is translated into

```
from «x» in ( «e» ) . Where ( «x» => «f» )
...
```

A join clause immediately followed by a select clause

```
from «x1» in «e1»
join «x2» in «e2» on «k1» equals «k2»
select «v»
```

is translated into

```
( «e1» ) . Join( «e2» , «x1» => «k1» , «x2» => «k2» , ( «x1» , «x2» ) => «v» )
```
