Example: In the following code

```
class A
{
    int x = 1;
    int y = x + 1;    // Error, reference to instance member of this
}
```

the variable initializer for y results in a compile-time error because it references a member of the instance being created.

end example

# 14.6 Methods

# 14.6.1 General

A method is a member that implements a computation or action that can be performed by an object or class. Methods are declared using method_declarations:

```
method_declaration
  : method_header method_body
  ;

method_header
  : attributes? method_modifier* 'partial'? return_type member_name
type_parameter_list?
  '(' formal_parameter_list? ')' type_parameter_constraints_clause*
  ;

method_modifier
  : 'new'
  | 'public'
  | 'protected'
  | 'internal'
  | 'private'
  | 'static'
  | 'virtual'
  | 'sealed'
  | 'override'
  | 'abstract'
  | 'extern'
  | 'async'
  | unsafe_modifier  // unsafe code support
  ;

return_type
  : type
  | 'void'
  ;

member_name
  : identifier
  | interface_type '.' identifier
  ;
```
