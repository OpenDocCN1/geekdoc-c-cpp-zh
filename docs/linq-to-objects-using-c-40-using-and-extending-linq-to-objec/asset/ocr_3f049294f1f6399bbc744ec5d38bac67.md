You will notice that the parallel IEnumerable<T> algorithm was actually slower than its sequential counterpart (even when forced parallel using the ExecutionMode extension). There is not enough work being done here to counteract the cost of accessing the enumerable (that is, locking it, retrieving elements from it, releasing the lock, processing those elements, and going back for more).
