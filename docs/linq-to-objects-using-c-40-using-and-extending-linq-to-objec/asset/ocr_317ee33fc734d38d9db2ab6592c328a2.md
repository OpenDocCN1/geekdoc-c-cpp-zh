# LINQ to Objects Five-Minute Overview

LINQ to Objects allows .NET developers to write "queries" over collections of objects. Microsoft provides a large set of query operators over the box, and these operators offer a similar depth of functionality to what is expected from any SQL language working with a relational database.

Traditionally, working with collections of objects meant writing a list of looping code using for loops or foreach loops to iterate through collections, carrying out filtering using if statements, while performing other computations like keeping a running sum of a total property.

LINQ frees you from having to write looping code; it allows you to write queries that filter a list or calculate aggregate functions on elements in in-memory collection, among many other capabilities. You can write queries against any collection type that implements an interface IEnumerable<T>, which most built-in collection classes available in the .NET Framework classes certainly do, including arrays.
