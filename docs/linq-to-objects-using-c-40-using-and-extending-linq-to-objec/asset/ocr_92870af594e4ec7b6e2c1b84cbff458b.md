# Sample Download Code and Updates

All of the samples listed in the book and further reference material can be found at the companion website, HookedOnLINQ.com reference wiki and website at http://hookedolinq.com/LINQBook.ashx.

Some examples required a large sample data source and the Geenames database of worldwide geographic place names and data. These data files can be downloaded from http://www.geenames.org/ and specifically the http://download.geenames.org/export/dump/allCountries.zip file. This file should be downloaded and placed in the same folder as the executable sample application to successfully run those specific samples that parse and query this source.

# Choice of Language

I chose to write the samples in this book using the C# language because including both C# and VB.Net example code would have bloated the number of pages beyond what would be acceptable. There is no specific reason why the examples couldn't have been in any other .NET language that supports LINQ.
