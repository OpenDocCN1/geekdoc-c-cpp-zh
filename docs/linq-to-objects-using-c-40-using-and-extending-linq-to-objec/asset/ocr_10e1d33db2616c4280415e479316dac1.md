# LINQ Approach

LINQ to Objects, the LINQ features designed to add query functionality over in-memory collections, this makes this scenario very easy to implement. Although the syntax is foreign at the moment (all will be explained in subsequent chapters), the code in Listing 1-2 is much shorter, and the coding gymnastics of sorting and grouping far less extreme.

Listing 1-2 C# 3.0 LINQ to objects code for grouping and sorting contact records—see Output 1-1

```
List<Contact> contacts = Contact.SampleData();

// perform the LINQ query
var query = from c in contacts
    orderby c.State, c.LastName
    group c by c.State;

// write out the results
foreach (var group in query)
{
    Console.WriteLine("*State: *" + group.Key);
    foreach (Contact c in group)
    {
        Console.WriteLine("{0} {1}*", c.FirstName, c.LastName);
    }
}
```

# The Result

The outputs for both solutions are identical and shown in Output 1-1. The advantages of using LINQ in this scenario are clearly seen in code readability and far less code. In the traditional pre-LINQ code, it was necessary to explicitly choose how data was sorted and grouped; there was substantial "how to do something" code. LINQ does away with the "how" code, requiring the minimalist "what to do" code.
