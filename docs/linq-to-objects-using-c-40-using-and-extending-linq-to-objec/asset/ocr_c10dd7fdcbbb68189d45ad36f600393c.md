The keySelector expression can be any expression that evaluates a consistent return result for the desired grouping scheme. It is often a single field value from the source collection, but it can be as complex as needed.
Listing 4-1 demonstrates how to group using the first three characters of a set of strings (the final strings are shown in Output 4-1).

# Listing 4-1 Elements that share the same return value from the key selector function will be grouped—see Output 4-1

```
string[] partNumbers = new string[] { "SCW10", "SCW1",
"SCW2", "SCW11", "NUT10", "NUT1", "NUT2", "NUT11" };

var q = from pn in partNumbers
    group pn by pn.Substring(0,3);

foreach (var group in q) {
    Console.WriteLine("Group key: {0}", group.Key);
    foreach (var part in group) {
        Console.WriteLine(" - {0}", part);
    }
}
```

# Output 4-1

+   Group key: SCW
- SCW10
- SCW1
- SCW2
- SCW11
Group key: NUT
- NUT10
- NUT1
- NUT2
- NUT11
