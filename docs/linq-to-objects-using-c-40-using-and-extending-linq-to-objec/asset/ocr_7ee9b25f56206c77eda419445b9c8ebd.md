To confirm this segment operator matches the previously stated requirements and to confirm it stays that way throughout multiple future revisions, Listing 7-18 shows some basic unit tests. In writing this operator, these tests helped me debug the boundary conditions for odd, even, and too small quantity source sequences.

# Listing 7-18 Basic unit tests for the Segment operator

```
[Test]
[ExpectedException("System.ArgumentNullException\)]
public void NullSourceTest()
{
    int[] values = null;
    var result = values.Segment(1);
}
```

```
[Test]
public void EmptySourceTest()
{
    // expecting 4 empty groups
    int[] values = Enumerable.Empty<int>().ToArray();
    var result = values.Segment(4);
    Assert.AreEqual(4, result.Count());
}
```
