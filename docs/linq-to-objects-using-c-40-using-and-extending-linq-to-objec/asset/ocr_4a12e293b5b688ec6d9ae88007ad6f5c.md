# Count and LongCount Operators

Count and LongCount return the number of elements in a sequence and only differ in their return types, with Count returning an int type result and LongCount returning a long type result.

There are two overloads for each operator. The first takes no arguments and returns the total number of elements in a sequence, and the second overload takes a predicate function and returns the count of elements that passed the predicate test. The method signatures are available:
