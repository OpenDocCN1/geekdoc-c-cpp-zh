# SequenceEqual Operator

The SequenceEqual operator compares one sequence with another and only returns true if the sequences are equal in element values, element order, and element count. There are two method signatures for SequenceEqual, one that takes the sequence to compare as an argument, and one that also allows a custom IComparer to be passed to control how element equality testing is carried out. When no IComparer is passed in, the default equality comparer is for the source element type.

The method signatures available for the SequenceEqual operator:

```
// Return true if the two sequences are equal
// in element values, order and count.
// Uses IComparer<TSource>.Default
// to compare elements for equality.
public static bool SequenceEqual<TSource>(
    IIEnumerable<TSource> first,
    IIEnumerable<TSource> second);

// Return true if the two sequences are equal
// in element values, order and count.
// Uses the IComparer passed in to
// compare elements for equality.
public static bool SequenceEqual<TSource>(
    IIEnumerable<TSource> first,
    IIEnumerable<TSource> second,
    IComparer<TSource> comparer);
```
