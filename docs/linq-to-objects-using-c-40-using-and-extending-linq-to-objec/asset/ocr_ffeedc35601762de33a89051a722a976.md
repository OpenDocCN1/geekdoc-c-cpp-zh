It operates by iterating the source sequence and returning each element of equal value once, effectively skipping duplicates. An ArgumentNullException is thrown if the source collection is null when this operator is called.
The method signatures available for the Distinct operator are:

```
// Returns unique elements from the source collection
// Uses EqualityComparer<TSource>.Default
// to compare elements for uniqueness
IEnumerable<TSource> Distinct<TSource>(n    this IEnumerable<TSource> source);
```

```
// Returns unique elements from the source collection
// Uses the supplied comparator to compare
// elements for uniqueness
IEnumerable<TSource> Distinct<TSource>(n    this IEnumerable<TSource> source,
    IEqualityComparer<TSource> comparer);
```
