# GENERATION OPERATORS—GENERATING SEQUENCES OF DATA 157

Sequences of numbers can be useful for data-binding controls. One example of this binding is a list of years to a combo-box control on a form. This can simply be achieved by assigning the Datasource property of any bindable control to a List<int> generated by Range, and in this particular case, reversing the order (so the most recent years are at the top):

Listing 5-21 The Range operator generates numeric sequences, in this case all years from 1900 to 2010–Form output is shown in Figure 5-3

```
// useful for databinding int sequences to combo-boxes
ComboBox yearsCombo = new ComboBox();
yearsCombo.DataSource =
enumerable.Range(1900, 111).Reverse().ToList();
```

```
Form form = new Form();
form.Controls.Add(yearsCombo);
form.Show();
```
