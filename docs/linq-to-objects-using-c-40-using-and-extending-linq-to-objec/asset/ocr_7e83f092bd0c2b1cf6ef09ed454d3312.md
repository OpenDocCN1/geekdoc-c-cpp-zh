# The join/into (GroupJoin) Operator

A small variation of the query expression join syntax allows joined records to be captured in a subgroup. Adding an into keyword after the join is similar to query continuation as discussed earlier in this chapter in the "How to Using Group Results in the Same Query (Query Continuation)" section. The result yields a single element for every outer record, and within these elements, a grouping of joined (related) records.
