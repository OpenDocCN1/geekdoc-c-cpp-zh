The alternative to handling the null values in all places that will process the query result, is to handle the null instances in the actual select projection of the query itself, avoiding duplication of null handling code. The following example demonstrates this technique and produces the identical result in Output 4-10:

```
var q1 = from c in customers
  join o in orders
  on c.CustomerID equals o.CustomerID into j
  from j.DefaultIfEmpty()
select new {
  LastName = c.LastName,
  OrderNumber = order == null ? "(no order)" : order.OrderNumber
}
```
