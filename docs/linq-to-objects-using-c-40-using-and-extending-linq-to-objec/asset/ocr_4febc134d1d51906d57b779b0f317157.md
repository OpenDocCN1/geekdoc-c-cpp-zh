# ToArray Operator

The ToArray operator returns an array (&lt;T&gt;) of a given type from any IEnumerable&lt;T&gt; sequence. The most common reason to use this operator is to

toforce the immediate execution of a query in order to capture the result-
ing data as a snapshot (forcing the execution of the query that is waiting to
be enumerated by deferred execution).
ToArray has a single overload with the following method signature:

```
// Returns an array of type T from a
// System.Collections.Generic.IEnumerable&lt;T&gt;.
public static TSource[] ToArray(TSource source)
    this IEnumerable&lt;TSource&gt; source);
```

To demonstrate the use of the ToArray operator, Listing 5-9 executes a
query over an IEnumerable&lt;int&gt; sequence and captures the results in any
int[] array.

Listing 5-9 The ToArray operator enumerates an IEnumerable&lt;T&gt; sequence and
returns the results in an array

```
IEnumerable&lt;int&gt; data = Enumerable.Range(1, 5);

int[] q = (from i in data
    where i < 3
    select i).ToArray();

Console.WriteLine("Returns {0}, {1}",
q[0], q[1]);
```
