# # Geenames Parallel LINQ

It is a very simple code change to turn a sequential query into a parallel query, although as is discussed later in this chapter, no one should blindly make all queries parallel. In most basic terms the .AsParallel() added to any IEnumerable<T> source will cause the parallel query operators to be invoked. Taking the query part from the code listed in Listing 9-1, the parallel-equivalent query utilizing Parallel LINQ is shown in Listing 9-2. (The only change is shown in bold.)

**Listing 9-2** Geenames parsing parallel LINQ query—CPU utilization is shown in
Figure 9-2 — Console output is shown in Output 9-1

```
var q = from line in lines.AsParallel()
  let fields = line.Split('\t')
  let elevation = string.IsNullOrEmpty(
      fields[elevationColumn]) ?
      0 : int.Parse(fields[elevationColumn])
  where elevation > 8000 // elevation in m's
  orderby elevation descending
  select new {
    name = fields[nameColumn] ?? "",
    elevation = elevation,
    country = fields[countryColumn];
```
