## ToArray 运算符

ToArray 运算符从任何 `IEnumerable<T>` 序列返回给定类型的数组 (<T>`)。使用此运算符最常见的原因是强制立即执行查询，以便将结果数据捕获为快照（强制执行等待通过延迟执行枚举的查询）。

`ToArray` 只有一个重载，其方法签名如下：

```csharp
// 从 System.Collections.Generic.IEnumerable<T> 
// 返回类型为 T 的数组。
public static TSource[] ToArray<TSource>(
    this IEnumerable<TSource> source);
```

为了演示 `ToArray` 运算符的使用，列表 5-9 在 `IEnumerable<int>` 序列上执行查询，并将结果捕获在任何 `int[]` 数组中。

### 列表 5-9 ToArray 运算符枚举 IEnumerable<T> 序列并将结果返回数组数组

```csharp
IEnumerable<int> data = Enumerable.Range(1, 5);

int[] q = (from i in data
    where i < 3
    select i).ToArray();

Console.WriteLine("Returns {0}, {1}",
q[0], q[1]);
```

## ToDictionary 运算符

ToDictionary 运算符将 `IEnumerable<TValue>` 序列转换为 `Dictionary<TKey, TValue>` 集合。`System.Collections.Generic.Dictionary<TKey, TValue>` 集合类型维护键值对列表，并确保每个键都是唯一的。如果在转换过程中尝试插入重复键，将抛出 `System.ArgumentException`。

`Dictionary` 集合允许根据键值高效访问元素，如果代码频繁需要根据键值查找元素，那么将序列转换为字典是提高查找性能的一种方法。

`ToDictionary` 运算符有四个方法重载。最简单的重载仅接受一个用于确定键选择函数的委托，而最复杂的重载接受一个用于键选择、选择的委托，以及一个用于判断键值是否等的 `IComparer`。当未传递元素选择器函数时，将使用元素类型本身，当使用 `IComparer<TSource>.Default` 时。可用的方法签名如下：

```csharp
// 为序列中的元素创建字典
// 键选择器函数返回的键值必须是唯一的，
// 否则将抛出 System.ArgumentException。
// 使用 EqualityComparer<TSource>.Default 
// 比较键的唯一性。
public static Dictionary<TKey, TSource> ToDictionary<TSource, TKey>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector);
```

```csharp
// 为序列中的元素创建字典
//并将元素投影到新类型。
// 键选择器函数返回的键值必须是唯一的，
// 否则将抛出 System.ArgumentException。
// 使用 EqualityComparer<TSource>.Default 
// 比较键的唯一性。
public static Dictionary<TKey, TElement> ToDictionary<TSource, TElement>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector,
    Func<TSource, TElement> elementSelector);
```

```csharp
// 为序列中的元素创建字典
// 键选择器函数返回的键值必须是唯一的，
// 否则将抛出 System.ArgumentException。
// 使用比较器测试键的唯一性。
public static Dictionary<TKey, TSource> ToDictionary<TSource, TKey>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector,
    IComparer<TKey> comparer);
```

```csharp
// 为序列中的元素创建字典
//并将返回的元素投影到新类型。
// 键选择器函数返回的键值必须是唯一的，
// 否则将抛出 System.ArgumentException。
// 使用比较器测试键的唯一性。
public static Dictionary<TKey, TElement> ToDictionary<TSource, TElement>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector,
    Func<TSource, TElement> elementSelector,
    IComparer<TKey> comparer);
```

为了演示 `ToDictionary` 运算符的使用，列表 5-10 根据姓氏和名字的组合作为键创建了一个示例联系人的字典，允许通过名称高效查找联系人。示例通过键值从结果字典中查找联系人来演示了这一点。

### 列表 5-10 ToDictionary 运算符为序列中的元素创建字典

```csharp
List<Contact> contacts = Contact.SampleData();

// 将结果实例化为字典
Dictionary<string, Contact> conDictionary = 
contacts.ToDictionary<Contact, string>(
    c => c.LastName + c.FirstName);

// 所有联系人记录现在都在字典中
// 通过键查找记录 = 非常高效
Contact record = conDictionary["Kamph" + "Mack"];

Console.WriteLine("Kamph DOB = {0}", record.DateOfBirth);
```

## ToList 运算符

ToList 运算符从任何 `IEnumerable<T>` 序列返回 `System.Collections.Generic.List<T>`。使用此运算符最常见的原因是强制立即执行查询，以便将结果数据捕获为快照（强制执行等待通过延迟执行枚举的查询）。

`ToList` 只有一个重载，其方法签名如下：

```csharp
// 从 System.Collections.Generic.IEnumerable<T> 
// 返回 System.Collections.Generic.List<T>。
public static List<TSource> ToList<TSource>(
    this IEnumerable<TSource> source);
```

为了演示 `ToList` 运算符的使用，列表 5-12 在 `IEnumerable<int>` 序列上执行查询，然后使用 `ForEach` 方法将结果写入 `List<T>` 并输出到控制台窗口。

### 列表 5-12 ToList 运算符枚举 IEnumerable<T> 序列并将结果返回 List<T>

```csharp
IEnumerable<int> data = Enumerable.Range(1, 5);

// 查询并捕获结果到 List<int>
List<int> q = (from i in data
    where i < 3
    select i).ToList();

// ForEach 是 List<T> 的方法
q.ForEach(j => Console.WriteLine(j));

```

## ToLookup 运算符

ToLookup 运算符在第4 章“数据分组与连接”中首次介绍，它用于促进两个序列之间非常高效的一对多连接。ToLookup 根据共享相同键值的元素创建子序列。ToLookup 在规模和行为上与 `ToDictionary` 相似，区别在于它们如何处理具有相同键值的重复元素。ToLookup 允许给定键值对应多个元素，而 `ToDictionary` 在发生这种情况时会抛出异常。
