To illustrate the operation of a decision tree, consider the following heuristics in selecting the appropriate wine to serve with a meal:

```
IF the main course is red meat
THEN serve red wine
IF the main course is poultry and it is turkey
THEN serve red wine
IF the main course is poultry and it is not turkey
THEN serve white wine
IF the main course is fish
THEN serve white wine.
```

The representation of the wine heuristics as a binary decision tree is shown in Figure 12.1. The decision nodes assume that each question can be answered only yes or no. A default answer node containing the answer “The best color is unknown” has been added to the set of heuristics in the event that the main course is neither red meat, nor poultry, nor fish.

The procedure for traversing the tree to reach an answer node is quite simple. The inferencing process is started by setting the current location in the decision tree to the root node. If the current location is a decision node, then the question associated with the decision node must be answered in some manner (typically by the person consulting the decision tree). If the answer is yes, then the current location is set to the child node connected to the yes (or left) branch of the current location.
