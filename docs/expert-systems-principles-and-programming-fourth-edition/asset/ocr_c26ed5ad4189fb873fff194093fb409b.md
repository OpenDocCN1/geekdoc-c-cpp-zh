The function matches the constraints at the three circled points in Figure 4.16. The formula for P(H | e) is calculated using linear interpolation as follows:

```
P(H | e) = {
    P(H | E') + \frac{P(H) - P(H | E')}{P(E)} P(E | e)
    for 0 <= P(E | e) < P(E)
    P(H) + \frac{P(H | E) - P(H)}{1 - P(E)} [P(E | e) - P(E)]
    for P(E) <= P(E | e) <= 1
}
```

Using this formula, the inconsistent case discussed before of LS > 1 and LN = 1, can be satisfied. Now the value of P(H | e) remains the same if P(E | e) < P(E), and increases if P(E | e) >= P(E). The reason for choosing this piecewise rather than a single straight line, is to ensure that when P(E | e) = P(E), then P(H | e) = P(H).
