# Figure 6.5 The Waterfall Model of the Software Life Cycle

![](bbox=[0.07, 0.08, 0.88, 0.75])

This model is familiar to programmers of conventional software. In the waterfall model each stage ends with a verification and validation (V & V) activity to minimize any problems in that stage. Also, notice that the arrows go back and forth only one stage at a time. This represents the iterative development between two adjacent stages in order to minimize the cost compared to the much higher cost of iterating development over several stages. The cost of going back stages is not a simple linear function but grows exponentially harder.
