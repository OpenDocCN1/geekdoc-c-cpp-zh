```
<single-field-variable> <type>* [<query>])
```

In this second form, which is surrounded by parentheses, the single-field variable is followed by zero or more types and then an optional query. The allowed values for <type> are any valid class name. This will be covered in detail in Chapter 11, but for now examples will be limited to the values already used with the type attribute, which also happens to be class names: SYMBOL, STRING, LEXEME, INTEGER, FLOAT, NUMBER, INSTANCE-NAME, INSTANCE-ADDRESS, INSTANCE, FACT-ADDRESS, and EXTERNAL-ADDRESS. The <query> value that comes last if specified must either be a global variable or a function call.

The wildcard-parameter-restriction> is similar to the <regular-parameter-restriction>, except that multifield variables are used in place of single-field variables. So its two forms are either a multifield variable or the following form:

```
<multifield-variable> <type>* [<query>])
```

With the exception of using <multifield-variable> instead of <single-field-variable>, the values that can be substituted for <type> and <query> follow the same restrictions as the <regular-parameter-restriction>. When a method is invoked, the multifield variable specified for the <wildcard-parameter-restriction> behaves similarly to the wildcard parameter of a defunction. Any remaining arguments in the method call that exceed the number of parameters for the method are grouped together as a single multifield value and are assigned to the wildcard parameter variable.

The final portion of the defmethod, represented by <expression>*, is the body of the method. Like the RHS of a defrule or the body of a defunction, it's a series of expressions that are executed in order when the method is invoked.

# Revisiting the Check-Input Defunction

Let's revisit the check-input defunction from Section 10.3. Its original definition was:

```
(defunction check-input (?question $?values)
  (printout t ?question " " ?values " ")
  (bind ?answer (read))
  (while (not (member$ ?answer ?values))
    (printout t ?question " " ?values " ")
    (bind ?answer (read)))
  (return ?answer))
```

This defunction can be directly converted to a defmethod simply by replacing the name of the construct:

```
(defmethod check-input (?question $?values)
  (printout t ?question " " ?values " ")
  (bind ?answer (read))
  (while (not (member$ ?answer ?values)))
```
