The probability of the system being in a certain state can be represented as a row matrix called the state matrix:

```
S = [P1  P2  ....  Pn]
```

where P1 + P2 + ... + Pn = 1

Initially with 80% of the people owning Brand X, the state matrix is:

```
S1 = [0.8   0.2]
```

As time goes on, these numbers will change depending on what drive people buy.
