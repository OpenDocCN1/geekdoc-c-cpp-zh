The variable X does not have to be a unary variable. Instead, X may be a binary or N-ary relation in general. For example, a proposition such as “X and Z are F” is subsumed by “X is F.” Defining CLOSE as a fuzzy binary relation in // X //.

```
CLOSE = 1/(1,1) + .5/(1,2) + .5/(2,1)
```

then:

```
X and Y are close -> Π(x,y) = CLOSE
```

```
X and Y are very close -> Π(x,y) = CLOSE²
= 1/(1,1) + .25/(1,2) + .25/(2,1)
```

An example of a type II rule is:

```
IF X is F then Y is G -> Π(x,y) = F̄ ⊗ Ḡ
```

where F̄ and Ḡ are the cylindrical extensions of F and G in their universes.

```
F̄ = F x V   Ḡ = U x G
```

and ⊗ is the bounded sum. For this rule:

```
μ_F⊗G(x,y) = 1 ∧ [1 - μ_F(x) + μ_G(y)]
```
