The qualification rules are those pertaining to fuzzy probabilities. The quantification rules deal with fuzzy quantifiers such as Most, which is not capable of being defined using the classical universal and existential quantifiers.

The translation of a Type I rule is represented by:

```
X is F -> Π_x = F
```

with translated proposition:

```
X is mF -> Π_x = F*
```

where m is a modifier such as Not, Very, More Or Less, and so on. F* represents the modification of F by m. Some default definitions for m and F* are shown in Table 5.18. These are defined the same as the linguistic hedges discussed previously. Other definitions for m and F* may also be used.

As an example, defining TALL,

```
TALL = .2/5 + .6/6 + 1/7
```

then the translations are as follows:

+   - John is not tall -> .8/5 + .4/6 + 0/7
+   - John is very tall -> .04/5 + .36/6 + 1/7
+   - John is more or less tall -> .45/5 + .77/6 + 1/7
