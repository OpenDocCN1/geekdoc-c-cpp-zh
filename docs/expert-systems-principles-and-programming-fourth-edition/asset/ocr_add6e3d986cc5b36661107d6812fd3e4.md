`(slot-range <class-name> <slot-name>)`
Returns the minimum and maximum numeric values allowed for a slot in a multifield value.

`(slot-sources <class-name> <slot-name>)`
Returns the names of the classes which provide facets for the specified slot of the specified class in a multifield value.

`(slot-types <class-name> <slot-name>)`
Returns the names of the primitive types allowed for the specified slot of the specified class in a multifield value.

`(slot-writablep <class-name> <slot-name>)`
Returns TRUE if the specified slot is writable, otherwise FALSE.

`(subclassp <class1-name> <class2-name>)`
Returns TRUE if the first class is a subclass of the second class.

`(superclassp <class1-name> <class2-name>)`
Returns TRUE if the first class is a superclass of the second class.

`(undefclass <class-name>)`
Deletes the specified class.

# Defacts

`(defacts-module <defacts-name>)`
Returns the module in which the specified defacts is defined.

`(get-defacts-list [<module-name>])`
Returns the list of all defacts in the specified module (or in the current module if <module-name> is unspecified).

`(list-defacts [<module-name>])`
Lists the defacts in the specified module (or in the current module if <module-name> is unspecified).

`(ppdefacts <defacts-name>)`
Displays the text of the specified defacts.

`(undefacts <defacts-name>)`
Deletes the specified defacts.
