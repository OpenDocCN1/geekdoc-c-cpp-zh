The evidential interval of a set S, EI(S), may be defined in terms of the belief:

EI(S) = [Bel(S), 1 - Bel(S')]

If S = {B}, then S' = {A,F} and:

Bel({A,F}) = m1 \(\oplus\) m2({A,F}) + m1 \(\oplus\) m2({A})
+ m1 \(\oplus\) m2({F})
= 0 + 0 + 0 = 0

since these are not focal elements and the mass is zero for nonfocal elements. Thus, the evidential interval for {B} is the following:

EI({B}) = [0.90, 1 - 0]
= [0.90, 1]

Likewise, if S = {B,F}, then S' = {A} and:

Bel({A}) = 0

since {A} is not a focal element. Also:

Bel({B,F}) = Bel1 \(\oplus\) Bel2({B,F}) = 0.97

EI({B,F}) = [0.97, 1 - 0] = [0.97, 1]

EI({A}) = [0, 1]

where the evidential interval [0, 1] reflects our total ignorance of {A}.
