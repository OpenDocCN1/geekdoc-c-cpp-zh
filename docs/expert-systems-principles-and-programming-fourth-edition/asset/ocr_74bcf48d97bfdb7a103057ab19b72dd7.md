where the name slot is the name of the sensor and the device slot is the name of the device with which the sensor is associated. The raw-value slot contains the data value read directly from the sensor before it has been processed. The state slot indicates the current state of the sensor (e.g., normal, low guard line, high red line, etc.). The low-red-line, low-guard-line, expected-average-value, high-guard-line, and high-red-line slots are used to contain the information described in Table 12.2.
