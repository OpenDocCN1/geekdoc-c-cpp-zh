```
CLIPS> (send [Jack] put-age 22)]
22
CLIPS> (send [Jack] get-age)]
22
CLIPS> (send [Jack] put-age)]
nil
CLIPS> (send [Jack] get-age)]
nil
CLIPS>
```

The `watch` command takes several instance-related watch items. One of these is `slots`. If slots are being watched, then an informational message is printed whenever the value of an instance slot is changed. Watching slot changes can be disabled using the `unwatch` command:

```
CLIPS> (watch slots)]
CLIPS> (send [Jack] put-age 24)]
::= local slot age in instance Jack <- 24
24
CLIPS> (unwatch slots)]
CLIPS> (send [Jack] put-age 22)]
22
CLIPS>
```

Another predefined message-handler is `delete`. As you might suspect, the delete message-handler is used to delete an instance. It returns the symbol TRUE if the instance was successfully deleted, otherwise the symbol FALSE:

```
CLIPS> (instances)]
[John] of PERSON
[gen1] of PERSON
[Jack] of PERSON
For a total of 3 instances.
CLIPS> (send [gen1 delete)]
TRUE
CLIPS> (instances)]
[John] of PERSON
[Jack] of PERSON
For a total of 2 instances.
CLIPS>
```

Another watch item is `instances`. If instances are being watched, CLIPS will automatically print a message whenever an instance is created or deleted.
