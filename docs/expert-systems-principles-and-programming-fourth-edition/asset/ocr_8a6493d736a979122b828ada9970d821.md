Having the inference engine check each rule to direct the search for facts after each cycle of execution provides a simple and straightforward technique for solving this problem. The primary disadvantage of such an approach is that it can be very slow. Most rule-based expert systems exhibit a property called *temporal redundancy*. Typically, the actions of a rule will change only a few facts in the fact list. That is, the facts in the expert system change slowly over time. Each cycle of execution may see only a small percentage of facts either added or removed and so only a small percentage of rules are typically affected by the changes in the fact list.
