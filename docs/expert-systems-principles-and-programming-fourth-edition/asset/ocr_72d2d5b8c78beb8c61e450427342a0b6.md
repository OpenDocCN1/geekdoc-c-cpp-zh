# Figure 5.17 Fuzzy Sets for Aircraft Identification

![](bbox=[0.04, 0.36, 0.86, 0.68])

The fuzzy set unions shown in Figure 5.17 can be considered as representing rules such as:

```
IF E THEN H
```

where E is the observed image and H is the fuzzy set union. For example,

```
IF IMAGE4 THEN TARGET (.2/M + .3/F + .5/A)
```

where the expression in parentheses is the fuzzy set union of the target. Alternatively, the rule could be expressed:

```
IF IMAGE4 THEN TARGET4
```
