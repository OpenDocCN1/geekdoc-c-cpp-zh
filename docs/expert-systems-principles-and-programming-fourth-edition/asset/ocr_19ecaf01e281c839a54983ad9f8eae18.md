# APPENDIX C
Some Set Properties

| Property | Formula |
| :--- | :--- |
| Commutativity | \( A \cup B = B \cup A \)
\( A \cap B = B \cap A \) |
| Associativity | \( A \cup (B \cup C) = (A \cup B) \cup C \)
\( A \cap (B \cap C) = (A \cap B) \cap C \) |
| Idempotence | \( A \cup A = A \)
\( A \cap A = A \) |
| Distributivity | \( A \cup (B \cap C) = (A \cup B) \cap (A \cup C) \)
\( A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \) |
| Law of the Excluded Middle | \( A \cup A' = U \) |
| Law of Contradiction | \( A \cap A' = \emptyset \) |
| Identity | \( A \cup \emptyset = A \)
\( A \cap U = A \) |
| Absorption | \( A \cup (A \cap B) = A \)
\( A \cap (A \cup B) = A \) |
| de Morgan's Laws | \( (A \cap B)' = A' \cup B' \)
\( (A \cup B)' = A' \cap B' \) |
| Involution | \( (A')' = A \) |
| Equivalence | \( (A' \cup B) \cap (A \cup B') = (A' \cap B') \cup (A \cap B) \) |
| Symmetrical Difference | \( (A' \cap B) \cup (A \cap B') = (A' \cup B') \cap (A \cup B) \) |
