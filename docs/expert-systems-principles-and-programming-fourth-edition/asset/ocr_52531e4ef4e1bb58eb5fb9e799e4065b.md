The fuzzy sets used for the fuzzy rule consequents are defined in Figure 5.19. As with the antecedents, there is overlap between these fuzzy consequent actions to provide a workable mix. Like the fuzzy set antecedents, the consequents may also be defined by S-functionns and \(\Pi\)-functions.
