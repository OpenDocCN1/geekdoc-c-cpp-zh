where e is the observed evidence that leads to the conclusion that the E<sub>i</sub> are known with certainty. These CF values are analogous to the conditional probabilities of the evidence of PROSPECTOR, P(E|e). The attenuation factor expresses the degree of certainty of the hypothesis, given certain evidence.

Just as with PROSPECTOR, a complication occurs if all the evidence is not known with certainty. With PROSPECTOR, the interpolation formula P(H|e) was used for uncertain evidence. In the case of MYCIN, the fundamental formula (8) must be used to determine the resulting CF value since CF(H,E<sub>1</sub> ∩ E<sub>2</sub> ∩ E<sub>3</sub>) = 0.7 is no longer valid for uncertain evidence.

For example, assuming:

+   - CF(E<sub>1</sub>, e) = 0.5
+   - CF(E<sub>2</sub>, e) = 0.6
+   - CF(E<sub>3</sub>, e) = 0.3

then:

```
CF(E, e) = CF(E<sub>1</sub> ∩ E<sub>2</sub> ∩ E<sub>3</sub>, e)
= min[CF(E<sub>1</sub>, e), CF(E<sub>2</sub>, e), CF(E<sub>3</sub>, e)]
= min[0.5, 0.6, 0.3]
= 0.3
```

Since the CF of the antecedent, CF(E,e) > 0.2, the antecedent is considered true and so the rule is activated. The certainty factor of the conclusion is:

```
CF(H, e) = CF(E, e) CF(H, E)
= 0.3 · 0.7
= 0.21
```

Suppose another rule also concludes the same hypothesis, but with a different certainty factor. The certainty factors of rules concluding the same hypothesis are calculated from the combining function for certainty factors defined as:

```
(9) CF<sub>COMBINE</sub>(CF<sub>1</sub>, CF<sub>2</sub>, ) = {
  CF<sub>1</sub> + CF<sub>2</sub> (1 - CF<sub>1</sub>)   both > 0
  (CF<sub>1</sub> + CF<sub>2</sub>) / (1 - min(|CF<sub>1</sub>|, |CF<sub>2</sub>|))   one < 0
  CF<sub>1</sub> + CF<sub>2</sub> (1 + CF<sub>1</sub>)   both < 0
}
```

where the formula for CF<sub>COMBINE</sub> used depends on whether the individual certainty factors are positive or negative. The combining function for more than two certainty factors is applied incrementally. That is, the CF<sub>COMBINE</sub> is calculated for two CF values, and then the CF<sub>COMBINE</sub> is combined using formula (9) with the third CF value, and so forth.
