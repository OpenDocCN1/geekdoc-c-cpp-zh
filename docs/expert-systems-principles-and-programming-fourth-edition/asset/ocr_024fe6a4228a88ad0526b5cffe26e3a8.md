# Figure 10.1 Method Precedence Determination

Compare the left-most unexamined parameter of each method.

The method without a parameter to compare has precedence.

Does only one method have a parameter to compare?
Is this parameter a regular parameter?
The method with a parameter to compare has precedence.
Do both methods have a parameter to compare?
The method that was defined first has precedence.
Is just one of the parameters a regular parameter?
The method with the regular parameter has precedence.
Does one of the parameters have more specific type restrictions?
The method with more specific type restrictions has precedence.
