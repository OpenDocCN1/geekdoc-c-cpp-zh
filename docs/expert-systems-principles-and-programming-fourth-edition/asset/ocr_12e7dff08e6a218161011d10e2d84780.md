The rules of inference can be applied to arguments with more than two premises. For example, consider the following argument:

> Chip prices rise only if the yen rises.
> The yen rises only if the dollar falls and
> if the dollar falls then the yen rises.
> Since chip prices have risen,
> the dollar must have fallen.

Let the propositions be defined as follows:

+   C = chip prices rise
+   Y = yen rises
+   D = dollar falls

Recall from Section 2.12 that one of the meanings of the conditional is “p, only if q.” A proposition such as “The yen rises only if the dollar falls” has this meaning and so is represented as C → Y. The entire argument has the following form:

```
C → Y
(Y → D) ∧ (D → Y)
C
-------
∴ D
```

The second premise has an interesting form, which can be further reduced by using variant of the conditional. The conditional p → q has several variants, which are the converse, inverse, and contrapositive. These are listed with the conditional, for completeness, in Table 3.10.

| conditional | p → q |
|---|---|
| converse | q → p |
| inverse | ¬p → ¬q |
| contrapositive | ¬q → ¬p |

As usual, it is assumed that the negation operator has a higher priority than the other logical operators and so no parentheses are used around ~p and ~q.
