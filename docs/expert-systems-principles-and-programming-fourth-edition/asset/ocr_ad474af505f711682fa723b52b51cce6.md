```
R_2 = .2/Y_1 + .3/Y_2 + .4/Y_3
```

In the general case of a relation involving N Cartesian points, drop all components of the N-tuple except those points on which the projection is to be made. For example, if the relation is over N points, then R_156 would drop all points except the first, third, and sixth.

For a relation over the universe X x Y,

```
R = { \mu_R(x, y) / (x, y) | for all (x, y) \in X x Y }
```

the 1st Projection is defined as:

```
proj(R; X) = R_1
```

where:

```
R_1 = { \max_Y \mu_R(x, y) / x | (x, y) \in X x Y }
```

and the max is taken over all y. Likewise,

```
proj(R; Y) = R_2
```

where:

```
R_2 = { \max_X \mu_R(x, y) / y | (x, y) \in X x Y }
```

where the max is taken over all x values for R3.

The cylindrical extension of the projection relation is defined as the largest fuzzy relation that is compatible with a projection. The cylindrical projection is somewhat analogous to projection since it expands the projected value (which is max) for all other elements, for example:

```
proj(R; X) = R_1 = .2/x_1 + .4/x_2
```

so:

```
R_1 = .2/x_1, y_1 + .2/x_1, y_2 + .2/x_1, y_3 + .4/x_2, y_1 + .4/x_2, y_2 + .4/x_2, y_3
```

```
R_2 = .2/y_1, x_1 + .2/y_1, x_2 + .3/y_2, x_1 + .3/y_2, x_2 + .3/y_2, x_3 + .4/y_3, x_1 + .4/y_3, x_2
```

that is, replace the second variable, .2/x1,[all var] + .4/x2, [all var]. Since the projection gives the max \mu then the cylindrical extension is the greatest relation compatible with the projection.
