# 7.12.14.5 The issgreater macro

Synopsis

```
#include <math.h>
int issgreater(real-floating x, real-floating y);
```

Description

The issgreater macro determines whether its first argument is less or greater than its second argument. The issgreater(x, y) macro is similar to (x) < (y) || (x) > (y); however, issgreater(x, y) does not raise the “invalid” floating-point exception when x and y are unordered (nor does it evaluate x and y twice).

Returns

The issgreater macro returns the value of (x) < (y) || (x) > (y).

# 7.12.14.6 The isunordered macro

Synopsis

```
#include <math.h>
int unordered(real-floating x, real-floating y);
```

Description

The unordered macro determines whether its arguments are unordered.

Returns

The unordered macro returns 1 if its arguments are unordered and 0 otherwise.
