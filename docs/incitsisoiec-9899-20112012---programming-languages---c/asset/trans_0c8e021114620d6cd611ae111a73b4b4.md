
值。指向同一个联合体对象成员的所有指针比较结果相等。如果表达式 P 指向一个数组对象的元素，而表达式 Q 指向同一个数组对象的最后一个元素，则指针表达式 Q+1 的结果大于 P。在所有其他情况下，行为是未定义的。

运算符 `<`（小于）、`>`（大于）、`<=`（小于等于）和 `>=`（大于等于）在指定的关系为真时应产生 1，为假时产生 0。（107）结果类型为 `int`。

## 6.5.9 等于运算符

### 语法

```
equality-expression:
relational-expression == relational-expression
equality-expression != relational-expression
```

### 约束

应满足以下条件之一：

- 两个操作数均为算术类型；
- 两个操作数都是指向兼容类型的限定或未限定版本的指针；
- 其中一个操作数是对象的指针，另一个是指向 void 的限定或未限定版本的指针；或
- 其中一个操作数是指针，另一个是空指针常量。

### 语义

`==`（等于）和 `!=`（不等于）运算符与关系运算符类似，不同之处它们的优先级较低。（108）每个运算符在指定的关系为真时产生 1，为假时产生 0。结果类型为 `int`。对于任何一对操作数，这些关系中恰好仅有一个为真。

如果两个操作数均为算术类型，则执行常数算术转换。复数类型的值相等，当且仅当它们的实部相等且虚部也相等时。来自不同类型的两个算术类型值相等，当且仅当它们转换为由常数算术转换确定的（复数）结果类型的结果相等时。

> 107 表达式 `a<b<c` 在数学中不被这样解释。正如语法所示，它意味着 `(a<b)<c`；换句话说，“如果 a 小于 b，则比较 1 和 c；否则，比较 0 和 c”。

> 108 因为优先级的原因，`a<b == c<d` 在 `a<b` 和 `c<d` 具有相同真值时成立。

否则，至少有一个操作数是指针。如果一个操作数是指针而另一个是空常量，则空常量转换为指针的类型。如果一个操作数是指向对象的指针，另一个是指向 void 的限定或未限定版本的指针，则前者转换为后者的类型。

两个指针比较相等，当且仅当：两者都是空指针；两者都指向同一个对象（包括指向对象起始位置子对象的指针）或函数；两者都是指向同一个数组对象最后一个元素之后的指针；或者其中一个是指向任何数组对象之外的指针，另一个是指向在地址空间中紧随第一个数组对象的不同数组起始的指针。

对于这些运算符而言，指向不是数组元素的对象的指针，其行为与长度为一且元素类型为该对象类型的数组的第一个元素相同。

## 6.5.10 按位与 AND 运算符

### 语法

```
AND-expression:
  equality-expression
  AND-expression & equality-expression
```

### 约束

每个操作数都应具有整数类型。

### 语义

对操作数执行常数算术转换。

二元运算符 `&` 的结果是操作数的按位与（即，当且仅当每个操作数的对应位都被设置时，结果中的该位才被设置）。

> 109 两个对象在内存中可能是相邻的，因为它们较大数组的相邻元素或结构成员，尽管它们相互无关。如果之前的操作（例如访问数组边界之外）产生了未定义行为，随后的比较也会产生未定义。

否则，至少有一个操作数是指针。如果一个操作数是指针而另一个是空常量，则空常量转换为指针的类型。对操作数执行常数算术转换。二元运算符 `&` 的结果是操作数的按位与（即，当且仅当每个操作数的对应位都被设置时，结果中的该位才被设置）。

## 三目运算符

### 语法

```
conditional-expression:
  or-expression
  or-expression : conditional-expression
```

### 约束

第一个操作数应具有标量类型。

第二个和第三个操作数满足以下条件之一：

- 两个操作数均为算术类型；
- 两个操作数具有相同的结构或联合体类型；
- 两个操作数均为 void 类型；
- 两个操作数都是指向兼容类型的限定或未限定版本的指针；
- 一个操作数是指针，另一个是空指针常量；
- 一个操作数是指向对象的指针，另一个是指向 void 的限定或未限定版本的指针。

### 语义

求值第一个操作数；在它的求值与第二个或第三个操作数（取决于后求值）之间存在一个序列点。只有当第一个操作数等于 0 时，才求值第二个操作数；只有当第一个操作数不为零时，才求值第三个操作数。结果是第二个或第三个操作数的值（取决于求值），转换为下面的类型。

如果第二个和第三个操作数均为算术类型，则对这两个操作数应用常数算术转换时得到的类型即为结果的类型。如果两个操作数具有结构或联合体类型，结果具有该类型。如果两个操作数均为 void 类型，结果具有 void 类型。
如果第二个和第三个操作数是指针或空指针常量，且另一个是指针，结果类型为带有两个操作数所引用类型的所有限定符的指针。此外，如果两个操作数指向兼容类型或指向不同限定版本的兼容类型，结果类型为指向复合类型的适当限定版本的指针；如果一个操作数是空指针常量，结果具有另一个操作数的类型；否则，一个操作数是指向 void 或其限定版本的指针，在这种情况下结果类型为指向适当限定版本的 void 的指针。

> ¹ 三目表达式不产生 Ivalue。
