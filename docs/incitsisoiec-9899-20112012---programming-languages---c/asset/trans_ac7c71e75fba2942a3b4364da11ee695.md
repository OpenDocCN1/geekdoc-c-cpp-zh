## K.3.9.2.1 宽字符串拷贝函数

## K.3.9.2.1.1 `wcscpy_s` 函数

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__
#include <wchar.h>
errno_t wcscpy_s(wchar_t * restrict s1,
size_t smax,
const wchar_t * restrict s2);
```

# Runtime-constraints

`s1` 和 `s2` 均不应为空指针。`smax` 不应大于 `RSIZE_MAX`。`smax` 不等于零。`smax` 应当大于 `wcslen_s(s2, smax)`。拷贝不在重叠的对象之间进行。

如果发生运行时约束违背，如果 `s1` 不是空指针且 `smax` 大于零且不超过 `RSIZE_MAX`，则 `wcscpy_s` 将 `s1[0]` 设置为空字符。

# Description

`wcscpy_s` 函数将指向 `s2` 的宽字符串（包括终止空字符）拷贝到 `s1` 所指的数组中。

`wcscpy_s` 在 `s1` 所指的 `smax` 个宽字符数组中写入终止空字符之后的所有元素（如果有），在 `wcscpy_s` 返回时其值是不确定的。442

## Returns

如果没有运行时约束违背，`wcscpy_s` 函数返回零⁴⁴³。否则，返回非零值。

> 442) 这允许实现在拷贝从 `s2` 的宽字符到 `s1` 的同时检查任何宽字符是否为空。这种方法可能会在发现第一个元素应设置为空字符之前，向 `s1` 的每个元素都写入了宽字符。

> 443) 返回零意味着指向 `s2` 的字符串中请求的所有宽字符都容纳在 `s1` 所指的数组中，且 `s1` 中的结果以空字符终止。
