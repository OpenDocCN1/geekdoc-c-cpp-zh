## 7.22.1.4 strtol, strtoll, strtoul, 和 strtou 函数

### 概要

```
#include <stdlib.h>
long int strtol(
const char * restrict nptr,
char ** restrict endptr,
int base);
long long int strtoll(
const char * restrict nptr,
char ** restrict endptr,
int base);
unsigned long int strtoul(
const char * restrict nptr,
char ** restrict endptr,
int base);
unsigned long long int strtoull(
const char * restrict nptr,
char ** restrict endptr,
int base);
```

### 描述

strtol、strtoll、strtoul 和 strtou 函数分别将 nptr 指向的字符串初始部分转换为 `long int`、`long long int`、`unsigned long int` 和 `unsigned long long int` 表示。首先，它们将输入字符串分解为三部分：初始的可能为空的空白字符序列（由 `isspace` 函数指定）、一个在 `base` 值决定的半径范围内类似于整数的主体序列，以及由一个或多个无法识别字符组成的最终字符串（包括输入字符串的终止字符）。

> 294 DECIMAL_DIGITS 定义在 <float.h> 中，应当足够大，使得 L 和 U 通常会舍入到相同的内部浮点值，但不会舍入到相邻的值。

然后，它们尝试将主体序列转换为整数并返回结果。

- 如果 `base` 的值为 0，则主体序列的预期形式为 6.4.4.1 描述的整数形式，可选地带有加号或减号，不包括整数后缀。如果 `base` 的值在 2 到 36 之间（包含），则主体序列的预期形式是一个字母和数字序列，表示由 `base` 指定半径的整数，可选地带有加号或减号，但不包括整数后缀。从 a（或 A）到 z（或 Z）的字母被赋予值 10 到 35；仅允许值小于 `base` 值的字母和数字。如果 `base` 的值为 16，则字符 0x 或 0X 可选地出现在字母和数字序列之前（如果存在符号，则在符号之后）。

- 主体序列定义为输入字符串中从第一个非空白字符开始的符合预期形式的最长初始子序列。如果输入字符串为空或完全由空白字符组成，或者第一个非空白字符不是符号或其他允许的字母或数字，则主体序列不包含任何字符。

- 如果主体序列具有预期形式且 `base` 的值为 0，则从第一个数字开始的字符序列将根据 6.4.4.1 的规则解释为整数常量。如果主体序列具有预期形式且 `base` 的值在 2 到 36 之间，则它被用作转换的基，按上述方式分配每个字母。如果主体序列以减号开头，则转换产生的值将取反（在返回类型中）。如果 `endptr` 不是空指针，则指向最终字符串的指针存储在 `endptr` 指向的对象中。

- 在 "C" 区域外，还可能接受额外的特定区域的主体形式。

- 如果主体序列为空或不具有预期形式，则不执行转换；如果 `endptr` 不是空指针，则 `nptr` 的值存储在 `endptr` 指向的对象中。

### 返回

- strtol、strtok、strtol 和 strtoll 函数返回转换后的值（如果有）。如果无法进行转换，则返回 0。如果正确的值在可表示范围之外，则返回 LONG_MIN、LONG_MAX、LLONG_MIN、LLONG_MAX、ULONG_MAX 或 ULONG_MAX（取决于返回类型和值的符号，如果有），并将宏 ERANGE 的值存储在 `errno` 中

## 7.22.2 伪随机序列生成函数

### 7.22.2.1 rand 函数

### 概要

```
#include <stdlib.h>
int rand(void);
```

### 描述

rand 函数计算 0 到 RAND_MAX 范围内的伪随机整数序列。295

rand 函数不要求避免与其他伪随机序列生成函数的调用之间产生数据竞态。该实现应当表现得好像没有库函数调用 rand 函数一样。

### 返回

rand 函数返回一个伪随机整数。

### 环境限制

RAND_MAX 宏的值应至少为 32767。

## 7.22.2.2 srand 函数

### 概要

```
#include <stdlib.h>
void srand(unsigned int seed);
```

### 描述

srand 函数使用参数作为新伪随机数序列的种子，随后的 rand 调用将返回该序列。如果随后使用相同的种子值调用 srand，则伪随机序列将重复。如果在调用任何 srand 之前调用了 rand，则生成的序列应与首次使用种子值 1 调用 srand 时生成的序列相同。

srand 函数不要求避免与其他伪随机序列生成函数的调用之间产生数据竞态。该实现应当表现得好像没有库函数调用 srand 函数。

> 295 对于产生的随机序列的质量没有保证，且已知某些实现会产生低位极度不随机的序列。具有特殊要求的应用程序应在使用足够满足其需求的生成器。

### 返回

srand 函数不返回任何值。

以下函数 `unsigned long int next = 1` 定义了 rand 和 srand 的可移植实现。

```c
static int rand(void) // 假设 RAND_MAX 为 32767
{
    next = next * 110351245 + 12345;
    return (unsigned int)(next/65536) % 32768;
}
void srand(unsigned int seed)
{
    next = seed;
}
```

## 7.2.2.3 内存管理函数

连续调用 aligned_alloc、calloc、malloc 和 realloc 函数分配的存储顺序和连续性是不确定的。如果分配成功，返回的指针是对齐的，可以赋值给具有基本要求的类型的指针，并需要访问此类对象或对象数组（直到空间显式释放）。被分配对象的生命周期从分配持续到释放。每次分配应产生一个与任何其他对象不相交的指针。返回的指针指向分配空间的起始（最低地址）。如果无法分配空间，则返回空指针。如果请求的空间大小为零，行为由实现定义：返回空指针，或者行为类似于大小为某个零值，但返回的指针不应用于访问对象。

为了确定数据竞态的存在，内存函数的表现应当仅访问了通过其参数访问的位置，而不是其他静态持续期存储。然而，这些函数可能会修改它们分配或释放的存储。调用 free 或 realloc 释放区域 p 与任何分配全部或部分区域 p 的同步。这种同步发生在释放函数对 p 的任何访问之后，以及分配函数对 p 的任何此类访问之前。
