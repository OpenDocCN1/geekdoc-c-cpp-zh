

## 7.21.7.7 putc 函数

### 语法概要

```
#include <stdio.h>
int putc(int c, FILE *stream);
```

### 描述

putc 函数等同于 fputc，不同在于如果它被实现为宏，它可能会多次求值 `stream`，因此该参数不应是带有副作用的表达式。

### 返回值

putc 函数返回写入的字符。如果发生写入错误，则流的错误指示位会被设置，putc 返回 EOF。

## 7.21.7.9 puts 函数

### 语法概要

```
#include <stdio.h>
int puts(const char *s);
```

### 描述

puts 函数将 `s` 指向的字符串写入 `stdout` 指向的流，并在输出末尾追加一个换行符。不写入终止的空字符。

### 返回值

如果发生写入错误，puts 函数返回 EOF；否则返回一个非负值。

## 7.21.7.10 ungetc 函数

### 语法概要

```
#include <stdio.h>
int ungetc(int c, FILE *stream);
```

### 描述

ungetc 函数将由 `c` 指定字符（转换为 `unsigned char`）推回到 `stream` 指向的输入流中。推回的字符将在随后的读取操作中按推入顺序的逆序返回。如果中间成功调用了针对（由 `stream` 指向）的文件定位函数（`fseek`、`fsetpos` 或 `rewind`），将丢弃该流任何已推回的字符。流对应的外部存储保持不变。

保证至少有一个字符可以被推回。如果在同一个流上多次调用 ungetc 函数而没有对该流进行读取或文件定位操作，则操作可能会失败。

如果 `c` 的值等于宏 `EOF`，则操作失败且输入流保持不变。

成功调用 ungetc 函数会清除流的末尾文件指示位。在读取或丢弃所有推回的字符后，该流的文件位置指示位的值应与推回字符之前的值相同。对于文本流，在成功调用 ungetc 函数后，其文件位置指示位的值在所有推回的字符被读取或丢弃之前是未指定的。对于二进制流，其文件位置指示位会在每次成功调用 ungetc 函数时增加 1；如果在调用之前值为 0，则在调用后将是不定的。

### 返回值

ungetc 函数返回转换后推回的字符，如果操作失败则返回 EOF。

向前引用：文件定位函数 (7.21.9)。

## 7.21.8 直接输入输出函数

## 7.21.8.1 fread 函数

### 语法概要

```
#include <stdio.h>
size_t fread(void * restrict ptr,
size_t size, size_t nmemb,
FILE * restrict stream);
```

### 描述

fread 函数从 `stream` 指向的流中读取最多 `nmemb` 个元素，每个元素的大小为 `size`，写入 `ptr` 指向的数组。对于每个对象，都会调用 `size` 次 `getc` 函数，并将结果按读取顺序存储在精确覆盖该对象的 `unsigned char` 数组中。流的文件位置指示位（如果已定义）根据读取的字符数向前移动。如果发生错误，则该流的文件位置指示位的结果是不定的。如果读取了部分元素，其值是不定的。

### 返回值

fread 函数返回成功读取的元素个数，如果遇到读取错误或文件末尾，结果可能小于 `nmemb`。如果 `size` 或 `nmemb` 为 0，fread 返回 0，数组的内容和流的状态保持不变。

## 7.21.8.2 fwrite 函数

### 语法概要

```
#include <stdio.h>
size_t fwrite(const void * restrict ptr,
size_t size, size_t nmemb,
FILE * restrict stream);
```

### 描述

fwrite 函数从 `ptr` 指向的数组中向 `stream` 指向的流写入最多 `nmemb` 个元素，每个元素的大小为 `size`。对于每个对象，都会调用 `size` 次 `fputc` 函数，按顺序从精确覆盖该对象的 `unsigned char` 数组中取值。流的文件位置指示位（如果已定义）根据成功写入的字符数向前移动。如果发生错误，则该流的文件位置指示位的结果是不定的。

fwrite 函数返回成功写入的元素个数，只有在遇到写入错误时才会小于 `nmemb`。如果 `size` 或 `nmemb` 为 0，fwrite 返回 0，流的状态保持不变。

## 7.21.9 文件定位函数

## 7.21.9.1 fgetpos 函数

### 语法概要

```
#include <stdio.h>
int fgetpos(FILE * restrict stream,
pos_t * restrict pos);
```

### 描述

fgetpos 函数将 `stream` 指向流的当前解析状态（如果有）和文件位置指示位的值存储在 `pos` 指向的对象中。存储的值包含未指定的信息，fgetpos 函数可利用这些信息重新定位流。

### 返回值

如果成功，fgetpos 函数返回 0；如果失败，则返回非零并在 `errno` 中设置值。

向前引用：setpos 函数 (7.21.9)。

## 7.21.9.2 fseek 函数

### 语法概要

```
#include <stdio.h>
int fseek(FILE *stream, long int offset, int whence);
```

### 描述 

fseek 函数设置 `stream` 指向流的位置指示位。如果发生读取或写入错误，则流的错误指示位会被设置且 fseek 失败。

对于二进制流，从文件开始计算的新位置是通过将 `offset` 加到 `whence` 指定的位置得到的。如果 `whence` 是 `SEEK_SET`，位置为文件开头；如果是 `SEEK_CUR`，为当前文件位置指示位；如果是 `SEEK_END`，为文件末尾。对于文本流，`offset` 应为 0，或者 `offset` 应为之前成功调用 ftell 函数返回的值，且 `whence` 应为 `SEEK_SET`。

成功调用 fseek 函数会撤销 ungetc 对流的影响，清除流的末尾文件指示位，然后建立新的位置。成功调用 fseek 后，更新流的下一次操作可以是输入或输出。

### 返回值

fseek 函数在无法满足请求时返回非零值。

向前引用：ftell 函数 (7.21.9.4)。

## 7.21.9.3 fsetpos 函数

### 语法概要

```
#include <stdio.h>
int fsetpos(FILE *stream, const fpos_t *pos);
```

### 描述 

setpos 函数根据 `pos` 指向的对象的值，设置 `stream` 指向流的 `mbstate_t` 对象（如果有）和文件位置指示位，该值将是之前在同一流上成功调用 fseek 函数获得的值。如果发生读取或写入错误，则流的错误指示位会被设置且 fsetpos 失败。

成功调用 fsetpos 函数会撤销 ungetc 对流的影响，清除流的末尾文件指示位，然后建立新的解析状态和位置。成功调用 fsetpos 后，更新流的下一次操作可以是输入或输出。

### 返回值

如果 fsetpos 函数返回 0；如果失败，则返回非零并在 `errno` 中设置实现的正值。
