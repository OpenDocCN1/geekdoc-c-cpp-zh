

## 7.29.2.4 swcanf 函数

### 语法概要

```c
#include <wchar.h>
int swcanf(const wchar_t * restrict s,
const wchar_t * restrict format, ...);
```

### 描述

swcanf 函数等同于 fscanf，不同之处在于参数 `s` 指定了一个用于获取输入的宽字符串，而不是从流（stream）中到达宽字符串的末尾等同于函数遇到文件结束（EOF）。

### 返回值

如果在第一次转换（任何）完成之前发生输入失败，swcanf 函数返回宏 `EOF` 的值。否则，swcanf 函数返回分配的输入项目数量；在发生早期匹配失败的情况下，该数量可能少于提供的数量，甚至为 0。

## 7.29.2.5 vprintf 函数

### 语法概要

```c
#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>
int vprintf(FILE * restrict stream,
const wchar_t * restrict format,
va_list arg);
```

### 描述

vprintf 函数等同于 fprintf，将可变参数列表替换为 `arg`，`arg` 应该由 `va_start` 宏（以及随后的 `va_arg` 调用）初始化。vprintf 函数不会调用 `va_end` 宏。

### 返回值

vprintf 函数返回传输的宽字符数量，如果发生输出或编码错误，则返回一个负值。

> 340) 由于函数 vprintf、vsprintf、swcanf、vwprintf、swcanf 和 swcanf 调用了 `va_arg` 宏，返回后 `arg` 的值是不确定的。

### 示例

以下显示了在通用错误报告程序中使用 `vfwprintf` 函数。

```c
#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>

void error(char *function_name, wchar_t format, ...)
{
    va_list args;
    va_start(args, format);
    // 打印引起错误的函数名
    vfwprintf(stderr, "ERROR in %s: ", function_name);
    // 打印剩余消息
    vfwprintf(stderr, format, args);
    va_end(args);
}
```

## 7.2.3 宽字符输入/输出

### 7.29.3.1 fgetwc 函数

### 语法概要

```c
#include <stdio.h>
#include <wchar.h>
wint_t fgetwc(FILE *stream);
```

### 描述

如果指向 `stream` 的输入文件结束标志未设置且存在下一个宽字符，fgetwc 函数获取该宽字符，将其转换为 `wint_t` 类型的 `wchar_t`，并移动流的文件位置指示器（如果定义）。

### 返回值

如果流的文件结束标志已设置，或者该流已到达文件结束，则设置流的文件结束标志并 fgetwc 返回 `WEOF`。否则，fgetwc 函数从输入流中返回下一个字符。如果发生读取错误，则设置流的错误指示器并 fgetwc 返回 `WEOF`。如果发生编码错误（包括字节数不足），宏 `EILSEQ` 的值将存储在 `errno` 中，且 fgetwc 返回 `WEOF`。341

### 7.29.3.2 fgetws 函数

### 语法概要

```c
#include <stdio.h>
#include <wchar.h>
wchar_t *fgetws(wchar_t * restrict s,
int n, FILE *restrict stream);
```

### 描述 

fgetws 函数从指向 `stream` 的流中读取至多比 `n` 少一个的宽字符，并存入指向 `s` 的数组中。在遇到换行宽字符（会被保留）或文件结束后，不再读取额外的宽字符。在数组中读取的最后一个宽字符之后立即写入一个空宽字符。

### 返回值

fgetws 函数在成功时返回 `s`。如果遇到文件结束且没有字符读取到数组中，则数组的内容保持不变并返回空指针。如果在操作过程中发生读取或编码错误，数组的内容是不确定的并返回空指针。

### 7.29.3.3 fputwc 函数

### 语法概要

```c
#include <stdio.h>
#include <wchar.h>
wint_t fputwc(wchar_t c, FILE *stream);
```

### 描述 

fputwc 函数将 `c` 指定的宽字符写入指向 `stream` 的输出流中，位于该流关联的文件位置指示器所示的位置（如果定义），并相应地移动指示器。
