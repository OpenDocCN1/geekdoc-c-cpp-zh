# p

匹配一个由实现定义的序列集合，该集合应与 `fprintf` 函数的 `%p` 转换可能产生的序列集相同。相应的参数应该是指向 `void` 指针的指针。输入项以实现定义的方式转换为指针值。如果输入项在同一程序执行期间之前已转换过的值，则指针应与该值相等；否则 `%p` 转换的行为是未定义的。

# n

不消耗任何输入。相应的参数应该是指向有符号整数的指针，用于写入到此此调用 `fscanf` 为止从输入流中读取的宽字符数。执行 `%n` 指令不会增加 `fscanf` 函数执行完成时返回的赋值计数。不转换任何参数，但消耗一个参数。如果转换包含抑制赋值的宽字符或字段宽度，其行为是未定义的。

# %

匹配单个 `%` 宽字符；不发生转换或赋值。完整的转换规范应为 `%%`。

# 79.23.3 swprintf 函数

# 梗概

```c
#include <wchar.h>
int swprintf(wchar_t * restrict s,
size_t n,
const wchar_t * restrict format, ...);
```

# 描述

2 `swprintf` 函数等于 `fwprintf`，区别在于参数 `s` 指定了写入输出内容的宽字符数组，而不是写入流。写入的宽字符不超过于 `n` 个，包括一个终止空宽字符，该字符始终会被添加（除非 `n` 为零）。

# 返回

3 `swprintf` 函数返回写入数组的宽字符数量，不计算终止空宽字符；如果请求写入 `n` 或更多宽字符时发生编码错误，则返回负值。
