

## X3.5.3.12 vsnprintf_f 函数

### 概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdarg.h>
#include <stdio.h>
int vsnprintf_f(char * restrict s, rsize_t n,
    const char * restrict format,
    va_list arg);
```

### 运行时约束

s 均不能为空指针。n 既不等于零，也不大于 RSIZE_MAX。%n 说明符^401（无论是否被标志、字段、宽度或精度修改）均不应出现在 format 指向的字符串中。传递给 vsnprintf_f 对应于 % 说明符的任何参数均不能为空指针。不应发生编码错误。

如果发生运行时约束违例，且 s 不为空指针且 n 大于 0 且小于 RSIZE_MAX，则 vsnprintf_f 函数将 s[0] 设置为空字符。

### 描述

vsnprintf_f 函数与 vsprintf 函数等效，但具有上述列出的显式运行时约束。

与 vsprintf_s 不同，vsnprintf_f 函数会将结果截断以适应 s 指向的数组。

### 返回值

vsnprintf_f 函数返回如果 n 足够大本应写入的字符数（不包括终止的空字符），或者在发生运行时约束违例时返回负值。因此，当且仅当返回值为非负且小于 n 时，空终止的输出才被视为完全写入。

> 401) 字符 %n 在这些字符指向的字符串中连续出现并不构成运行时约束违例，前提是这些字符不被解释为 %n 说明符。例如，如果整个格式字符串为 %n。

## K.3.5.3.13 vsprintf_s 函数

### 概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdarg.h>
#include <stdio.h>
int vsprintf_s(char * restrict s, size_t n,
const char * restrict format,
va_list arg);
```

### 运行时约束

s 和 format 均不能为空指针。n 应当为零或不大于 RSIZE_MAX。结果写入 s 指向的数组所需的字符数（包括末尾的 n）不应大于 n。%n 说明符^402（无论是否被标志、字段宽度或精度修改）均不应出现在 format 指向的字符串中。传递给 vsprintf_s 对应于 %s 说明符的任何参数均不能为空指针。不应发生编码错误。

如果发生运行时约束违例，且 s 不为空指针且 n 大于 0 且小于 RSIZE_MAX，则 vsprintf_s 函数将 s[0] 设置为空字符。

### 描述

vsprintf_s 函数与 vsprintf 函数等效，但参数 n 以及上述列出的显式运行时约束除外。

与 vsprintf_s（注：此处原文笔误）不同，vsprintf_s 函数将超出 s 指向数组容量的结果视为运行时约束违例。

### 返回值

如果没有发生 运行时约束违例，vsprintf_s 函数返回写入数组的字符数（不包括终止字符）。如果发生编码错误，vsprintf_s 返回负值。如果发生任何其他运行时约束违例，vsprintf_s 返回零。

> 402) 字符 %n 在 format 指向的字符串中连续出现并不构成运行时约束违例，前提是这些字符不被解释为 %n 说明符。例如，整个格式字符串为 %n。

## K.3.5.3.14 vsscanf_s 函数

### 概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdarg.h>
#include <stdio.h>
int vsscanf_s(const char * restrict s,
    const char * restrict format,
    va_list arg);
```

### 运行时约束

s 和 format 均不能为空指针。任何间接用于以存储转换后输入的参数均不能为空指针。

如果发生运行时约束违例，vsscanf_s 函数不会尝试执行后续输入，且 vsscanf_s 在发现运行时约束违例之前执行了多少输入是未确定的。

### 描述

vsscanf_s 函数与 sscanf_s 等效，将可变参数列表替换为 arg，arg 应当由 va_start 宏初始化（并可能使用了 va_arg 调用）。vsscanf_s 函数不调用 va_end 宏。

### 返回值

如果在任何转换之前发生输入失败或存在运行时约束违例，vsscanf_s 函数返回宏 EOF 值。否则，vsscanf_s 函数返回分配的输入项目数量，在匹配失败的情况下，该数量可能少于提供的数量甚至为零。

## K.3.5.4 字符输入/输出函数

## K.3.5.4.1 gets_s 函数

### 概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
char *gets_s(char *s, rsize_t n);
```

> 403) 与 fgets 函数一样，vscanf_s, vprintf_s, vsprintf_s, vsscanf_s, vsnprintf_s 调用 va_arg 宏，gets 的值未确定

### 运行时约束

s 应当是一个指针。n 既不等于零也不大于 RSIZE_MAX。

如果发生运行时约束违例，s[0] 被设置为空字符。

### 描述

gets_s 函数从标准输入读取少于 n 个字符到数组 s 中。如果遇到文件结束或发生读取错误，则写入空字符，s 的其他元素值未确定。

### 建议实践

fgets 函数允许安全地处理过长的输入行。考虑使用 fgets 代替 gets。

### 返回值

gets_s 函数成功时返回 s。如果发生运行时约束违例、遇到文件结束且未读取到字符或发生读取错误，则返回空指针。

> 404) 与历史 gets 函数不同，gets_s 将输入溢缓冲区视为运行时约束违例。与 fgets 函数不同，gets_s 维持了输入行与成功调用之间的一一对应关系。
