

## G.4 转换

### G.4.1 虚数类型

虚数类型之间的转换遵循与实数浮点类型类似的规则。

### G.4.2 实数与虚数

当虚数类型的值转换为除 _Bool_ 以外的实数类型时，结果为正零。

当实数类型的值转换为虚数类型时，结果为正虚零。

### G.4.3 虚数与复数

当虚数类型的值转换为复数类型时，复数值结果的实部为正零，而复数值结果的虚部由对应实数类型的转换规则决定。

当复数类型的值转换为虚数类型时，复数值的实部被丢弃，虚部的值则根据对应实数类型的转换规则进行转换。

## G.5 二元运算符

以下子句 6.5 节按顺序指定了具有虚数操作数的操作之结果的类型。

对于大多数操作数，具有虚数或复数操作数的二元运算符的结果值通过参考实数算术，由常规数学公式完全确定。对于某些操作数，由于常规数学公式对无穷大的处理以及不当的溢出或下溢，常规数学公式是有问题的；在这些情况下，结果满足某些属性（在 G.5.1 中指定），但并非完全确定。

### G.5.1 乘法运算符

语义

如果一个操作数是实数类型而另一个操作数是虚数类型，则结果为虚数类型。如果两个操作数都是虚数类型，则结果为实数类型。（如果任一操作数是复数类型，则结果为复数类型。）

如果操作数不是复数，则 * 运算符的结果和浮点异常行为由常规数学公式定义：

| | u | iv | u + iv |
|---|---|---|---|
| x | xu | i(xv) | (xu) + i(xv) |
| iy | i(yu) | -vy | (-vy) + i(yu) |
| x + iy | (xu) + i(yu) | (-vy) + i(xv) |

如果第二个操作数不是复数，则 / 运算符的结果和浮点异常行为由常规数学公式定义：

| | u | iv |
|---|---|---|
| x | x/u | i(-x/v) |
| iy | i(y/u) | y/v |
| x + iy | (x/u) + i(y/u) | (y/v) + i(-x/v) |

* 和 / 运算符对于所有实数、虚数和复数操作数满足以下无穷大属性：

- 如果一个操作数是无穷大而另一个操作是非是非有限数或无穷大，则 * 运算符的结果为无穷大；
- 如果第一个操作数是无穷大而第二个操作数是有限数，则 / 运算符的结果为无穷大；
- 如果第一个操作数是有限数而第二个操作数是无穷大，则 / 运算符的结果为零；

### G.5.2 加法运算符

语义

如果两个操作数都是虚数类型，则结果为虚数类型。（如果一个操作数是实数类型而另一个操作数是虚数类型，或者任一操作数是复数类型，则结果为复数类型。）

在所有情况下，+ - 运算符的结果和浮点异常行为由常规数学公式定义：

| | u | iv | u + iv |
|---|---|---|---|
| x | xu | i(xv) | (xu) + i(xv) |
| iy | i(yu) | -vy | (-vy) + i(yu) |
| x + iy | (xu) + i(yu) | (-vy) + i(xv) |
