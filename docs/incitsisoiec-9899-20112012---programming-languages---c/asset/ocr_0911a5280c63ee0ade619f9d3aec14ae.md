# Description

The setlocale function selects the appropriate portion of the program's locale as specified by the category and locale arguments. The setlocale function may be used to change or query the program's current locale or portions. The value LC_ALL for category name names the program's entire locale; the other values for category name only a portion of the program's locale. LC_COLLATE affects the behavior of the strcoll and strftime functions, LC_CTYPE affects the behavior of the character handling functions.(224) and the multibyte and wide character functions. LC_MONETARY affects the monetary formatting information returned by the localconv function. LC_NUMERIC affects the decimal-point character for the formatted input/output functions and the string conversion functions, as well as the nonmonetary formatting information returned by the localconv function. LC_TIME affects the behavior of the strftime and wstrftime functions.

A value "C" for locale specifies the minimal environment for C translation; a value of " for locale specifies the locale-specific native environment. Other implementation-defined strings may be passed as the second argument to setlocale.
