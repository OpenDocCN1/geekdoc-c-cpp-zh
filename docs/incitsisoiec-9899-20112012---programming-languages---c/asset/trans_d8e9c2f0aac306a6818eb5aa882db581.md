转换指定符字符，用于指定要应用的转换类型。

如上所述，字段宽度、精度或两者都可以由星号 `*` 表示。在这种情况下，一个 `int` 类型参数提供字段宽度或精度。指定字段宽度、精度或两者的参数应（按该顺序）出现在要转换的参数（如果有的话）之前。负数字段宽度参数被视为 `-` 标志后紧跟一个正数字段宽度。负数精度参数被视为省略了精度。

标志字符及其含义含义如下：

-   `-` - 转换结果在字段内左对齐。（如果未指定此标志，则右对齐。）
-   `+` + 有符号转换的结果始终以加号或 减号符号开头。（如果未指定此标志，则仅在转换负值时以符号开头。） 276

如果有符号转换的首字符不是符号，或者有符号转换的结果没有字符，则在结果前加一个空格。如果空格标志和 `+` 标志同时出现，则忽略空格标志。

结果被转换为“另一种形式”。对于 `o` 转换，它会增加精度，且仅在必要时强制结果的第一位数字为 0（如果是 `x` 或 `(X)` 转换，非零结果将带有前缀 `0x` 或 `(0X)`）。对于 `a`, `A`, `e`, `E`, `f`, `F`, `g` 和 `G` 转换，浮点数转换的结果始终包含一个小数点字符（通常情况下，这些转换结果中只有在小数点后有数字时才会出现）。对于 `g` 和 `G` 转换，结果中的末尾零不会删除。对于其他转换，其行为是未定义的。

对于 `d`, `i`, `o`, `u`, `x`, `X`, `A`, `e`, `E`, `f`, `F`, `g` 和 `G` 转换，前零（在任何符号或基数指示之后）用于填充字段宽度，而不是转换无穷大或 NaN。如果 `0` 和 `-` 标志同时出现，则忽略 `0` 标志。对于 `d`, `i`, `o`, `u`, `x` 和 `X` 276，负零的所有浮点转换结果以及舍入为零的负值的结果包含一个减号。如果指定了精度，则忽略 `0` 标志。对于其他转换，其行为是未定义的。

## 7 长度修饰符及其含义为：

-   `hh` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于有符号 `char` 或 `unsigned char` 参数（该参数已根据整数提升进行了提升，但在打印之前其值将转换为 `signed char` 或 `unsigned char`）；或者后续的 `n` 转换指定符适用于指向 `signed char` 参数的指针。
-   `h` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `short int` 或 `unsigned short int` 参数（该参数已根据整数提升进行了提升，但在打印之前其值将转换为 `short int` 或 `unsigned short int`）；或者后续的 `n` 转换指定符适用于指向 `short int` 参数的指针。
-   `L (ll)` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `long int` 或 `unsigned int` 参数；后续的 `n` 转换指定符适用于指向 `long int` 参数的指针；后续的 `c` 转换指定符适用于指向 `wchar_t` 参数的指针；或者后续的 `s` 转换指定符适用于指向 `a`, `E`, `f`, `F`, 或 `G` 参数的指针；
-   `LL (ll)` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `long long int` 或 `unsigned long int` 参数；或者后续的 `n` 转换指定符适用于指向 `long long int` 参数的指针。
-   `j` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `intmax_t` 或 `uintmax_t` 参数；或者后续的 `n` 转换指定符适用于指向 `intmax_t` 参数的指针。
-   `z` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `size_t` 或相应的整数类型参数；或者后续的 `n` 转换指定符适用于指向 `size_t` 参数的指针。
-   `t` 指定后续的 `d`, `i`, `o`, `u`, `x` 或 `X` 转换指定符适用于 `ptrdiff_t` 或无符号整数类型参数；或者后续的 `n` 转换指定符适用于 `ptrdiff_t` 参数。
-   `L` 指定后续的 `a`, `E`, `f`, `g` 或 `G` 转换指定符适用于 `long double` 参数。

如果长度修饰符出现在上述以外的转换指定符，其行为是未定义的。转换指定符及其含义为：

-   `d, i` `int` 参数被转换为 `.dd` 风格的有符号十进制。精度指定了出现的最小位数；如果转换后的值可以用较少的位数表示，则用前导零进行扩展。默认精度为 1。精度为零时转换零值没有字符。
-   `o, u, x, X` `unsigned int` 参数被转换为 `.ddd` 风格的无符号八进制 (`o`)、无符号十进制 (`u`) 或十六进制表示 (`x` 或 `X`)；字母 `abcdef` 用于转换，`X` 转换使用字母 `ABCDEF`。精度指定了最小位数（类似于 `d, i`，但此处不补零）。默认精度为 1。精度为零时转换零值没有字符。
-   `f, F` `double` 参数的浮点数被转换为 `.ddd` 风格的十进制表示，其中小数点后的位数等于精度。如果精度缺失，则取值为 6；如果精度为零且未指定 `#` 标志，则不出现小数点。如果出现小数点，则前面至少有一个数字。值被舍入到适当的位数。
-   `g, G` `double` 参数的浮点数被转换为 `f` 或 `e` 风格，取决于转换的值和精度。令 $P$ 等于精度（非零，缺失则为 6，零则为 1）。那么，使用 `E` 风格的转换将指数为 $X$：
  -   如果 $P > X \ge4$，则使用 `f`（或 `F`）且精度为 $P-(X+1)$。
  -   否则，使用 `e`（或 `E`）且精度为 $P-1$。

最后，除非使用 `#` 标志，否则将删除结果小数部分的末尾零，如果没有剩余小数部分，则删除小数点。
