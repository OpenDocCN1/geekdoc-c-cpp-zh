
The strnc_s function returns zero if no runtime-constraint violation and no encoding error occurred. Otherwise, a nonzero value is returned.

## K.3.7.1 Copying functions

### K.3.7.1.1 The memcpy_s

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t memcpy_s(void * restrict s1, rsize_t slmax,
const void * restrict s2, rsize_t n);
```

Runtime-constraints

- Neither s1 nor s2 shall be a null pointer. Neither slmax nor n shall be greater than SIZE_MAX. n shall not be greater than slmax. Copying shall not take place between objects that overlap.

If there is a runtime-constraint violation, the memcpy_s function returns zeros in the first slmax characters of the object pointed to by s1 if s1 is not a null pointer and slmax is not greater than SIZE_MAX.

Description

The memcpy_s function copies n characters from the object pointed to by s2 into the object pointed to by s1.

Returns

The memcpy_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

### K.3.7.1.2 The memmove_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1

errno_t memmove_s(void *s1, size_t smax,

```

Runtime-constraints

Description

This copying takes place as if the n characters from the object pointed to by s2 are first copied into a temporary array of n characters that does not overlap the objects pointed to by s1 or s2, and then the n characters from the temporary array are copied into the object pointed to by s1.

Returns

- The memmove_s function returns 0 if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

### K.3.7.1.3 The strcpy_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strcpy_s(char * restrict s1,
size_t smax,
const char * restrict s2);
```

Runtime-constraints

- Neither s1 nor s2 shall be a null pointer. smax shall not be greater than RSIZE_MAX. smax shall not be equal zero. smax shall be greater than strnlen(s2, smax). Copying shall not take place between objects that overlap.
- If there is a runtime-constraint violation, if s1 is not a null pointer and smax is greater than zero and not greater than RSIZE_MAX, then strcpy_s sets s1[0] to the null character.

The strncpy_s function copies the string pointed to by s2 (including the terminating null character) to the array pointed to by s1. All elements following the terminating null character (if any) written by strncpy_s in the array of slmax characters pointed to by s1 take unspecified values when strncpy_s returns.

Returns

The strncpy_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

### K.3.7.1.4 The strncpy_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strncpy_s(char * restrict s1,
size_t slmax,
const char * restrict s2,
size_t n);
```

Runtime-constraints

- Neither s1 nor s2 shall be a null pointer. Neither slmax nor n shall be greater than RSIZE_MAX. slmax shall not equal zero. If n is not less than slmax, then slmax shall be greater than strlen(s2, slmax). Copying shall not take place between objects that overlap.
- If there is a runtime-constraint violation, then s1 is not a null pointer and slmax is greater than zero and not greater than RSIZE_MAX, then strncpy_s sets s1[0] to the null character.

Description

The strncpy_s function copies more than n successive characters (characters that follow a null character are not copied) from the array pointed to by s2 to the array pointed to by s1. If no null character was copied from s2, then s1[n] is set to a null character. This allows an implementation to copy characters from s2 to s1 while simultaneously checking if any of characters are null. Such an approach might write a character to every element of s1 before discovering that the first element be set to the null character. A zero return value implies that all of the requested characters from the string pointed to by s2 fit within the array pointed to by s1 and the result is null terminated.

EXAMPLE 1 The strncpy_s function can be used to copy a string without the result will be null terminated or characters will pass the end of the destination array.

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
/* ... */
char src1[100] = "hello";
char src2[7] = ('g', 'o', 'o', 'd', 'y', 'e');
char dst1[6], dst2[5], dst3[5];
int r1, r2, r3;
r1 = strncpy_s(dst1, 6, src1, 100);
r2 = strncpy_s(dst2, 5, src2, 7);
r3 = strncpy_s(dst3, 5, src2, 4);
```

The first call will assign to r1 the value zero and to dst1 the sequence hello\0.
The second call will assign to r2 a nonzero value and to dst2 the sequence \0.
The third call will assign to r3 the value zero and to dst3 the sequence good\0.

```
size_t slmax,

```

Runtime-constraints

Let m denote the value slmax - strnlen_s(s1, slmax) upon entry to strcat_s. This allows an implementation to copy characters from s2 to s1 while simultaneously checking if any of those characters are null. Such an approach might write a character to every element of s1 before discovering the first element should be set to the null character. Neither s1 nor s2 be a null pointer. smaxmax shall not be greater than RSIZE_MAX. smax shall not equal zero. m shall be greater than strnlen_s(s2, m). Copying shall not take place over objects that overlap.

If there is a runtime-constraint violation, then s1 is not a null pointer and smax is greater than zero and not greater than RSIZE_MAX, then strcat_s sets s1[0] to the null character.

All elements terminating the null character (if any) written by strcat_s in the array of slmax characters pointed to by s1 take unspecified values when strcat_s returns.

Returns
