

# 6.6 常量表达式

## 语法

constant-expression:
    conditional-expression

## 描述

常量表达式可以在翻译期间求值，而不是在运行时求值，因此可以使用任何可以使用常量的地方。

## 约束

常量表达式不应包含赋值、递增、递减、函数调用或逗号运算符，除非它们包含在一个不进行求值的子表达式中。^{115}

每个常量表达式都应求出一个在其类型可表示值范围内的常量。

## 语义

在几种上下文中，需要一个求值为为常量的表达式。如果在翻译环境中求值了一个浮点表达式，则其算术环境和精度至少应与该表达式在执行环境中求值时的一样。^{116}

整数常量表达式^{117} 应当具有整数类型，且其操作数只能是整数常量、枚举常量、字符常量、结果为整数常量的 **sizeof** 表达式、**_Alignof** 表达式以及作为类型转换的直接操作数的浮点常量。整数常量表达式中的类型转换运算符应只将算术类型转换为整数类型，除非作为 **sizeof** 或 **_Alignof** 运算符的操作数的一部分。

初始化器中的常量表达式被允许更大的自由度。此类常量表达式应当是或求值为以下内容之一：

- 算术常量表达式，
- 空指针常量，
- 地址常量，或
- 完整对象类型加上或减去一个整数常量表达式的地址常量。

+ 8 算术常量表达式应当具有算术类型，且其操作数只能是整数常量、浮点常量、字符常量、结果为整数常量的 sizeof 表达式以及 Alignof 表达式。算术常量表达式中的类型转换运算符应只将算术类型转换为算术类型，除非作为 sizeof 或 _Alignof 运算符的操作数的一部分。

+ 9 地址常量是指空指针、指向具有静态存储期对象的指针，或指向函数指示符的指针；它应当显式地使用一元运算符 & 或将整数常量转换为指针类型来创建，或者通过使用数组或函数类型的表达式隐式地创建。在创建地址常量时，可以使用数组下标 []、成员访问运算符 . 和 ->、地址运算符 &、间接运算符 * 一元运算符以及指针类型转换，但不应通过使用这些运算符访问对象的值。

+ 10 实现可以接受其他形式的常量表达式。

+ 11 常量表达式求值的语义规则与非常量表达式相同。118

**前向引用：** 数组声明符 (6.7.6.2)，初始化 (6.7.9)。


115) **sizeof** 或 **_Alignof** 运算符的操作数通常不被求值 (6.5.3.4)。

116) 以 **FLT_EVAL_METHOD** 特征的求值格式也适用于翻译环境中的求值。

# 6.7 声明

## 语法

declaration:
    declaration-specifiers init-declarator-list_opt ;
    static-assert-declaration

declaration-specifiers:
    storage-class-specifier declaration-specifiers_opt
    type-specifier declaration-specifiers_opt
    type-qualifier declaration-specifiers_opt
    function-specifier declaration-specifiers_opt
    alignment-specifier declaration-specifiers_opt

init-declarator-list:
    init-declarator
    init-declarator-list , init-declarator

init-declarator:
    declarator
    declarator = initializer

## 约束

除 static_assert 声明外的声明，应当至少声明一个声明符（函数参数或结构体或联合体的成员除外）、标签（tag）或枚举的成员。

如果标识符没有链接（linkage），则在相同的作用域和相同的命名空间内，该标识符的声明（在声明符或类型说明符内）不超过一个，例外：

- typedef name 不可以重新定义以表示与其当前相同的类型，前提是该类型不是变体类型；
- 标签可以按照 6.7.2.3 的规定重新声明。

在同一作用域内引用相同对象或函数的声明应当指定兼容的类型。

## 语义

声明规定了一组标识符的解释方式和属性。标识符的定义是该标识符的声明：

- 对于对象，为该对象预留存储；
- 对于函数，包括函数体；119)
- 对于枚举常量，该标识符的（唯一）声明；
- 对于 typedef 的名称，是该标识符的第一个（或唯一的）声明。

6 声明说明符由一系列说明符组成，用于指示声明符所表示的实体的链接、存储期和部分。init-declarator-list 是由逗号分隔的声明符序列，每个声明符可以具有类型信息、初始化值，或两者兼有。

7 如果对象的标识符在在没有链接的情况下声明，则该对象的类型在其声明符结束时应当是完整的；对于函数参数（包括在原型中），则要求调整后的类型（见 6.7.3）是完整的。

**前向引用：** 声明符 (6.7.6)，枚举说明符 (6.7.2)，初始化 (6.7.9)，类型名 (6.7.7)。

# 6.7.1 存储类说明符

## 语法

```
storage-class-specifier:
typedef
extern
static
_Thread_local
auto
register
```

## 约束

2 声明中最多可以给出一个存储类说明符，但 Thread_local 可以与 static 或 external 一起出现.¹⁰

3 在具有块作用域的对象的声明中，如果声明说明符包含 Thread_local，它们也应当包含 static 或 external 之一。如果 Thread_local 出现在任何对象的声明中，它应当出现在该对象的每个声明中。

4 Thread_local 不应出现在函数的声明说明符中。

> 119) 函数定义有不同的语法，在 6.9.1 中描述。

> 120) 见“未来语言方向”(6.11.5)。

## 语义

`typedef` 说明符仅为了语法方便而被称为“存储类说明符”它在 6.7.8 中讨论。各种链接和存储期的含义在 6.2.2 和 6.2.4 中讨论过。

对具有存储类说明符 register 的对象的标识符声明建议尽可能地访问该对象。这种建议的实现程度取决于实现。¹²)

具有块作用域的函数的标识符声明除 extern 外不应有显式的存储类说明符。

如果聚合或联合体对象使用 typedef 外的存储类说明符声明，则存储类说明符产生的属性（链接除外）也适用于对象的成员，并递归地适用于任何聚合或联合体成员对象。

**前向引用：** 类型定义 (6.7.8)。

121) 实现可以将 register 声明简单视为 auto 声明。然而，无论是否实际使用了可寻址存储，使用存储类说明符 register 声明对象的任何部分的地址都无法计算，无论是显式的（通过使用 6.5.3.2 中的 & 运算符）还是隐式的（通过将数组名转换为指针，见 6.3.2.1）。因此，可以应用于使用存储类说明符 register 声明的数组的运算符只有 sizeof。
