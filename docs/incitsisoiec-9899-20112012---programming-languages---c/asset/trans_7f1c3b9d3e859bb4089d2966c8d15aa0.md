
## 6.7.6.1 指针声明符 (Pointer declarators)

### 语义

如果在声明 “TD1” 中，D1 的形式为：

+   * type-qualifier-listopt D

并且声明 “TD” 中为 ident 指定的类型为“derived-declarator-type-list T”，那么为 ident 指定的类型为“derived-declarator-type-list type-qualifier-list pointer to T”。对于列表中的每个类型限定符，ident 都是具有该限定符的指针。

两个指针类型要兼容，两者都应具有相同的限定符，且两者都指向兼容的类型。

示例 下述的成对声明演示了“指向常量值的变量指针”与“指向变量值的常量指针”之间的区别。

```
const int *ptr_to_constant;
int *constant_ptr;
```

ptr_to_constant 指向的任何对象的内容不能通过指针修改，但 ptr_to_constant 本身可以更改以指向另一个对象。同样，constant_ptr 指向的 int 内容可以修改，但 constant_ptr 本身应始终指向同一个位置。

通过包含对类型“pointer to int”的定义，可以明确常量指针 constant_ptr 的声明。

```
typedef int *int_ptr;
const int constant_ptr;
```

将 constant_ptr 声明为类型“const-qualified pointer to int”的对象。

## 6.7.6.2 数组声明符 (Array declarators)

### 约束

除了可选的类型限定符和关键字 static 外，[ ] 可以界定一个表达式或 *。如果它们界定一个表达式（指定数组的大小），该表达式应具有整数类型。如果该表达式是常量表达式，其值应大于零。元素类型不应是不完全类型或函数类型。可选的类型限定符和关键字 static 应仅出现在具有数组类型的函数参数声明中，且仅出现在最外层的数组类型推文中。

如果一个标识符被声明为具有变体类型（variably modified type），它应该是一个普通标识符（如 6.2.3 定义）、没有链接，且具有块作用域或函数原型作用域。如果一个标识符被声明为具有静态或线程存储持续期的对象，它不应具有变长数组类型。

### 语义

如果在声明 “T D1” 中，D1 具有以下形式之一：

**D[ type-qualifier-list_opt assignment-expression_opt ]**
**D[ static type-qualifier-list_opt assignment-expression ]**
**D[ type-qualifier-list_opt static assignment-expression * ]**

并且声明 “T D” 中为 ident 指定的类型为“derived-declarator-type-list array of T”¹⁴²（参见 6.7.6.3 关于可选类型限定符和关键字 **static** 的含义）。

如果没有设置大小，则数组是不完全类型。如果大小不是表达式，则该数组类型为未指定大小的变长数组，它只能在具有函数原型作用域的声明或类型名中使用¹⁴³；此类数组仍然完整类型。如果大小是整数常量表达式且元素类型具有已知的常量大小，则数组类型不是变长数组类型；否则，数组类型为变长数组类型。（变长数组是一种条件性特性，实现不一定支持；参见 6.10.8.3。）

如果大小是一个不是整数常量表达式的表达式：如果它出现在函数原型作用域的声明中，则被视为被 _ 替换；否则，每次求值时其值都应大于零。变长数组类型实例的大小在其生命周期内不会发生变化。当大小表达式是 sizeof 运算符的操作数的一部分，且更改大小表达式的值不会影响运算符的结果，则大小表达式是否求值是不确定的。

两个数组类型要兼容，两者都应具有兼容的元素类型，如果两个大小都存在且为常量表达式，则两个大小指定应具有相同的常量值。如果两个数组使用在需要它们兼容的语文中，且两个大小指定求出的值不相等，则将是未定义行为。

示例 1

```
float fa[11], *afp[17];
```

声明了一个 float 数值数组和一个指向 float 数值的指针数组。

示例 2 注意这些声明之间的区别。

142) 当多个“array of”指定符相邻出现时，则声明了一个多维数组。

143) 因此，* 只能用在非定义的函数声明中（参见 6.7.6.3）。

```
extern int *;
extern int y[];
```

第一个声明 x 为指向 int 的指针；第二个声明 y 为一个未指定大小的 int 数组（不完全类型），其存储在别处定义。

示例 3 下述声明演示了变体类型的兼容规则。

```
extern int n;
extern int m;
void fcompat(void)
{
int a[n][m];
int (*p)[4][n+1];
int c[n][6][m];
int (*r)[x][n+1];
np = a; // 无效：不兼容，因为 4 != 6
r = c; // 兼容，但仅当
 // n == 6m 且 m == n+1
}
```

示例 4 所有变体（VM）类型的声明必须位于块作用域或函数原型中。在参数声明中出现的唯一存储类限定符是 register。非定义部分的函数声明符中的标识符列表应为空。

## 6.7.6.3 函数声明符（包括原型） (Function declarators)

### 约束

1. 声明符不应指定返回类型为函数类型或数组类型。

2. 在参数声明中出现的唯一存储类限定符是 register。
3. 非定义部分的函数声明符中的标识符列表应为空。
4. 调整后，定义部分的参数类型列表不应是不完全类型。

### 语义

5. 如果在声明 “TD1” 中，D1 的形式为：

D ( parameter-type-list )
nor

D ( identifier-list_opt )

并且声明 “T D” 中为 ident 指定的类型为“derived-declarator-type-list T”，那么为 ident 指定的类型为“derived-declarator-type-list function returning T”。

6. 参数类型列表指定了标识符，并声明了函数的类型。

7. “array of type”的声明应调整为“qualified pointer to type”，其中类型限定符（如果有）是在数组类型推文 [ ] 内指定的。对于每次函数调用，大小表达式应访问数组的至少多个元素。
8. “function returning type”的声明应调整为“pointer to type”，如 6.3.2 所示。
9. 如果以省略号 (. . ) 结束，关于逗号之后参数的数量或类型的信息（¹⁴）。

10. 未命名类型 void 的特殊情况指定函数没有参数。¹⁴⁴ 在 <stdarg.h> 头文件中定义的宏（7）可能用于访问对应省略号的参数。
