

## 6.7.2 类型说明符

### 语法

```
type-specifier:
  void
  char
  short
  int
  long
  float
  double
  signed
  unsigned
  _Bool
  _Complex
  atomic-type-specifier
  struct-or-union-specifier
  enum-specifier
  typedef-name
```

### 约束
在每个声明的声明修饰符中，以及每个结构体声明（struct declaration）和类型名中的修饰符-限定符列表列表中，至少应给出一个类型说明符。每组类型说明符列表应为以下多集之一（当每个项目项目有多个多集时，用逗号分隔）；类型说明符可以以任何顺序出现，并可能与其他声明修饰符混杂。

- void
- char
- signed char
- unsigned char
- short, signed short, short int, or signed short int
- unsigned short, or unsigned short int
- int, signed, or signed int
- unsigned, or unsigned int
- long, signed long, long int, or signed long int
- unsigned long, or unsigned long int
- long long, signed long long, long int, or signed long int
- unsigned long long, or unsigned long long int
- float
- double
- long double
- _Bool
- float _Complex
- double _Complex
- long double _Complex
- atomic type specifier
- struct or union specifier
- enum specifier
- typedef name

如果实现不支持复数类型，则不使用类型说明符 _Complex（见 6.10.8.3）。

### 语义
结构体、联合体、枚举和原子类型的说明符在 6.7.2.1 至 6.7.2.4 中进行了讨论。typedef 名的声明在 6.7.8 中进行了讨论。其他类型的特性在 6.2.5 中进行了讨论。

每个用逗号分隔的多集指定相同的类型，但位域（bit-fields）除外，说明符 `int` 指定的是与 `signed int` 相同的还是与 `unsigned int` 相同的类型由实现决定。

前向引用：原子类型说明符 (6.7.2.4)，枚举说明符 (6.7.2.2)，结构体和联合体说明符 (6.7.2.1)，标签 (6.7.2.3)，类型定义 (6.7.8)。

### 语法

    struct-or-union identifier
