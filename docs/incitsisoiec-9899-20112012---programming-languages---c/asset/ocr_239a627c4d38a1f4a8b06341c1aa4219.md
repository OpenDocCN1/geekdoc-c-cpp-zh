fscanaf_s function returns the number of input items assigned, which can be fewer than provided, or even zero, in the event of an early matching failure.

EXAMPLE 1 The call:
```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
/* ... */
int n, i; float x; char name[50];
n = fscanaf_s(stdin, "%d%s", &i, &x, name, (size_t) 50);
```
with the input line:
```

```
will assign to n the value 3, to i the value 25, to x the value 5.432, and to name the sequence thompson\0.

# Runtime-constraints

**format** shall not be a null pointer. The %n specifier$^{394}$ (modified by or not by fields, field width, or precision) shall not appear in the string pointed to by **format**. Any argument to **printf_s** corresponding to a %s specifier shall not be a null pointer.

If there is a runtime-constraint violation, the **printf_s** function does not attempt to produce further output, and it is unspecified to what extent **printf_s** produced output before discovering the runtime violation.

> 394) It is not a runtime-constraint violation for the characters %n to appear in sequence in the string pointed at by **format** when those characters are not interpreted as a %n specifier. For example, the entire format string was %n.
