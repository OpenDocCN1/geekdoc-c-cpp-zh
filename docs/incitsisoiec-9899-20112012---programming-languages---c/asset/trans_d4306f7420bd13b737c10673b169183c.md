### K.3.8.2 时间转换函数

与 str 函数一样，`asctime_s` 和 `ctime_s` 函数不返回静态对象的指针，并且允许其他库函数调用它们。

### K.3.8.2.1 asctime_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <time.h>
errno_t asctime_s(char *s, rsize_t maxsize, const struct tm *timeptr);
```

运行时约束

- `s` 和 `timeptr` 均不能为空指针。`maxsize` 不应小于 26 且不应大于 RSIZE_MAX。`timeptr` 指向的拆解时间应当是归一化的。`timeptr` 指向的拆解时间所代表的公历年份不应小于 0 年不应大于 9999 年。
- 如果违反运行时约束，则不尝试转换时间；如果 `s` 不是空指针且 `maxsize` 不为 0 且大于 RSIZE_MAX，则 `s[0]` 被设置为空字符。

描述

`asctime_s` 函数将 `timeptr` 指向的结构中的归一化拆解时间转换为 26 个字符（包括空字符）的字符串，格式为 "# Sun Sep 16 01:03:52 1973\n\0"。

构成此字符串的字段如下（按顺序）：

- 1. 由 `timeptr->tm_wday` 表示的星期名称，使用以下三个字符的星期名：Sun, Mon, Tue, Wed, Thu, Fri 和 Sat。
- 2. 空格字符。
- 3. 由 `timeptr->tm_mon` 表示的月份名称，使用以下三个字符的月份名：Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep, Oct, Nov 和 Dec。
- 4. 空格字符。
- 5. `timeptr->tm_mday` 的值，类似于使用 `fprintf` 格式 "%2d" 打印。
- 6. 空格字符。
- 7. `timeptr->tm_hour` 的值，类似于使用 `fprintf` 格式 "%.2d" 打印。
- 8. 冒号字符。
- 9. `timeptr->tm_min` 的值，类似于使用 `fprintf` 格式 "%.2d" 打印。
- 10. 冒号字符。
- 11. `timeptr->tm_sec` 的值，类似于使用 `fprintf` 格式 "%.2d" 打印。
- 12. 空格字符。
- 13. `timeptr->tm_year + 1900` 的值，类似于使用 `fprintf` 格式 "%d" 打印。
- 14. 换行字符。
- 15. 空字符。

建议实践

`strftime` 函数允许更灵活的格式化并支持特定区域的行为。如果你不需要 `asctime_s` 函数产生结果的精确格式，请考虑使用 `strftime` 函数。

返回值

如果时间成功转换并存储在 `s` 指向的数组中，`asctime_s` 函数返回零。否则返回非零值。

### K.3.8.2.2 ctime_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <time.h>
errno_t ctime_s(char *s, rsize_t maxsize, const time_t *timer);
```

运行时约束

- `s` 和 `timer` 均不能为空指针。`maxsize` 不应小于 26 且大于 RSIZE_MAX。
- 如果违反运行时约束，如果 `s` 不是空指针且 `maxsize` 不为 0 且大于 RSIZE_MAX，则 `s[0]` 被设置为空字符。

描述

`ctime_s` 函数将 `timer` 指向的公历时间转换为字符串形式的本地时间。它等同于 `asctime_s(s, maxsize, localtime(timer))`。

建议实践

`strftime` 函数允许更灵活的格式化并支持特定区域的行为。如果你不需要 `ctime_s` 函数产生的字符串精确格式，请考虑使用 `strftime` 函数。

返回值

如果时间成功转换并存储在 `s` 指向的数组中，`ctime_s` 函数返回零。否则返回非零值。

### K.3.8.2.3 gmtime_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <time.h>
struct tm *gmtime_s(const time_t * timer, struct tm *result);
```

运行时约束

- `timer` 和 `result` 均不能为空指针。
- 如果违反运行时约束，则不尝试转换时间。

描述

`gmtime_s` 函数将 `timer` 指向的公历时间转换为 UTC 表示的拆解时间。拆解时间存储在 `result` 指向的结构体中。

返回值

`gmtime_s` 函数返回 `result`；如果时间无法转换为 UTC 或存在运行时约束违反，则返回空指针。

### K.3.8.2.4 localtime_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <time.h>
struct tm *localtime_s(const time_t * timer, struct tm *result);
```

运行时约束

- `timer` 和 `result` 都不能为空指针。
- 如果违反运行时约束，则不尝试转换。

描述

`localtime_s` 函数将 `timer` 指向的公历时间转换为本地表示的拆解时间。拆解时间存储在 `result` 中。

返回值

`localtime_s` 函数返回 `result`；如果时间无法转换为本地时间或存在运行时约束违反，则返回空指针。

## K.3.9.1 格式化宽字符输入输出函数

### K.3.9.1.1 fwprintf_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
int fwprintf_s(FILE * restrict stream, const wchar_t * restrict format, ...);
```

运行时约束

- `stream` 和 `format` 均不能为空指针。`%n` 说明符（无论是否有标志修改）不应出现在宽字符串中。`fwprintf_s` 对应 `%s` 说明符的参数不能为空指针。
- 如果违反运行时约束，`fwprintf_s` 函数不尝试产生输出，在发现运行时约束违反之前的输出程度未定义。

描述

`fwprintf_s` 函数等同于 `fwprintf` 函数，上述上述运行时约束外。

返回值

`fwprintf_s` 返回传输的宽字符数；如果发生输出错误、编码错误或运行时约束违反，则返回负值。

### K.3.9.1.2 fwscanf_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
#include <wchar.h>
int fwscanf_s(FILE * restrict stream, const wchar_t * restrict format, ...);
```

运行时约束

- `stream` 和 `format` 均不能为空指针。`fwscanf_s` 用于存储转换输入的参数不能为空指针。
- 在宽字符串中顺序出现宽字符 `"%n"` 不违反运行时约束。
- 如果违反运行时约束，`fwscanf_s` 函数不尝试进行任何输入，在发现运行时约束违反之前的输出程度未定义。

描述

`fwscanf_s` 函数等同于 `fwscanf`，但 `c` 和 `s` 转换说明适用于一对参数（除非由 `*` 指定）。这些参数中的第一个与 `fwscanf` 相同。紧随其后的第二个参数类型为 `size_t`，给出第一个参数指向数组的元素个数。如果第一个参数指向标量对象，则被视为包含一个元素的数组。

返回值

如果在任何转换之前发生输入失败或存在运行时约束违反，`fwscanf_s` 函数返回 `EOF` 值。否则，`fwscanf_s` 返回分配的输入项数，在早期匹配失败的情况下可能少于提供的数量甚至为零。

### K.3.9.1.3 swprintf_s 函数

概要

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
int swprintf_s(wchar_t * restrict s, size_t maxsize, const wchar_t * restrict format, ...);
```

运行时约束

- `s` 和 `maxsize` 均不能为空指针或零且不能大于 RSIZE_MAX。`%n` 说明符（无论是否有标志、字段宽度、精度修改）不应出现在宽字符串中。`swprintf_s` 对应 `%s` 说明符的参数不能为空指针。
