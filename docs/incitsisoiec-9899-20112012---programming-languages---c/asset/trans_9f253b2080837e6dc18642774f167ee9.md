

## 7.21.5.2 fflush 函数

概要

```
#include <stdio.h>
int fflush(FILE *stream);
```

描述

如果 `stream` 指向一个输出流或最近操作不是输入的更新流，`fflush` 函数将导致该流 `stream` 的任何未写入的数据被交付给主机环境以写入文件；否则，其行为是未定义的。

如果 `stream` 为空指针，则 `fflush` 函数对所有上述定义行为的流执行此刷新操作。

返回值

如果发生写入错误，`fflush` 函数会设置流的错误指示器并返回 `EOF`，否则返回 0。

前向引用：`fopen` 函数 (7.21.5.3)。

## 7.21.5.3 fopen 函数

概要

```
#include <stdio.h>
FILE *fopen(const char * restrict filename,
const char * restrict mode);
```

描述

`fopen` 函数打开由 `filename` 指向的字符串命名的文件，并将其与一个流关联。

参数 `mode` 指向字符串。如果该字符串是以下之一，则文件以指定的模式打开。否则，其行为是未定义的。²⁷¹¹

- r 以读取模式打开文本文件
- w 截断长度为零或创建文本文件用于写入
- wx 创建文本文件用于写入
- a 追加；或在文件末尾创建文本文件用于写入
- rb 以读取模式打开二进制文件
- wb 截断长度为零或创建二进制文件用于写入

> 如果字符串以上述序列之一开头，实现可能会可能会忽略剩余的字符，也可能使用它们来选择不同类型的文件（其中某些可能不符合 7.21.2 中的术语）。

- ab 创建二进制文件用于写入
- append 追加；在文件末尾打开或创建二进制文件用于写入
- r+ 以更新模式打开文本文件（读和写）
- w+ 截断长度为零或创建文本文件用于更新
- w+x 创建文本文件用于更新
- a+ 追加；打开或创建文本文件用于更新，在文件末尾写入
- r+b 或 rb+ 以更新模式打开二进制文件（读和写）
- w+b 或 wb+ 截断长度为零或创建二进制文件用于更新
- w+bx 或 wb+x 创建二进制文件用于更新
- a+b 或 ab+ 追加；打开或创建二进制文件用于更新，在文件末尾写入

以读取模式（'r' 作为 `mode` 参数的第一个字符）打开文件，如果文件不存在或不可读，则失败。

以独占模式（'x' 作为 `mode` 参数的最后一个字符）打开文件，如果文件已存在或可以创建，则失败。否则，文件将以独占（也称为非共享）访问创建，程度取决于底层系统对独占访问的支持。

以追加模式（'a' 作为 `mode` 参数的第一个字符）打开文件会导致后续对文件的所有写入操作都被强制置到当前文件末尾，无论中间调用了多少 `fseek` 函数。在某些实现中，用追加模式打开二进制文件（'b' 作为上述 `mode` 参数值列表中的第二个或第三字符）可能会初始将流的位置指针置于最后写入的数据之后，这是由于空字符填充。

当用更新模式（'+' 作为上述 `mode` 参数值列表中的第二个或第三字符）打开文件时，可以在关联的流上执行输入和输出。然而，在没有调用 `fflush` 函数或文件定位函数（`fseek`、`fsetpos` 或 `rewind`）的情况下，输出不应紧跟输入；在没有调用文件定位函数的情况下，输入不应紧跟输出，除非输入操作遇到文件末尾。在某些实现中，用更新模式打开（或创建）文本文件可能会打开（或创建）二进制流。

当流被全缓冲时，当且仅当可以确定它不是指向交互式设备。流的错误和文件指示器将被清空。

返回值

`fopen` 函数返回指向控制流的对象的指针。如果操作失败，`fopen` 返回空指针。

前向引用：文件定位函数 (7.21.9)。

## 7.21.5.4 freopen 函数

概要

```
#include <stdio.h>
FILE *freopen(const char * restrict filename,
const char * restrict mode,
FILE *restrict stream);
```

描述

`freopen` 函数打开由 `filename` 指向的字符串命名的文件，并将 `stream` 指向的流与其关联。`mode` 参数的使用方法与 `fopen` 函数相同。

如果 `filename` 为空指针，则 `freopen` 函数尝试将流的模式更改为 `mode` 指定的模式，仿佛使用了与流关联的文件名。允许哪些模式更改（如果有）以及在什么情况下更改取决于实现。

`freopen` 函数首先尝试关闭与指定 `stream` 关联的任何文件。关闭失败将被忽略。流的错误和文件结束指示器将被清空。

返回值

如果打开操作失败，`freopen` 返回空指针。否则，`freopen` 返回 `stream` 的值。

## 7.21.5.5 setbuf 函数

概要

```
#include <stdio.h>
void setbuf(FILE * restrict stream,
char * restrict buf);
```

描述

除了没有返回值外，`setbuf` 函数等同于调用了 `mode` 为 `_IOFBF` 且 `size` 为 `BUFSIZ` 的 `setbuf` 函数，或者（如果 `buf` 为空指针）`mode` 为 `_IONBF` 的调用。该函数的主要用途是更改标准流（`stderr`、`stdin` 或 `stdout`）关联的值。

`setbuf` 函数没有返回值。

前向引用：`setbuf` 函数 (7.21.5.6)。

## 7.21.5.6 setbuf 函数

概要

```
#include <stdio.h>
int setbuf(FILE * restrict stream,
char * restrict buf,
int mode, size_t size);
```

描述

`setbuf` 函数只有在流关联之后执行任何其他操作（失败的 `setbuf` 调用）之前可以使用。`mode` 参数决定流如何缓冲，如下：`IOBF` 使输入输出全缓冲；`IOBF` 使输入输出行缓冲；`BF` 使不缓冲。如果 `buf` 不是空指针，则可以使用它指向的数组代替缓冲区；否则由 `size` 决定数组。数组的内容是不确定的。

成功时返回 0，如果 `mode` 值无效或请求无法实现，则返回非零。

## 7.21.6 格式化输入输出函数

格式化输入输出函数的行为类似于在每个说明符之后有一个序列点。²274

### 7.21.6.1 fprintf 函数

概要

```c
#include <stdio.h>
int fprintf(FILE * restrict stream,
const char * restrict format, ...);
```

描述

`fprintf` 函数向 `stream` 指向的流写入内容，由 `format` 指向的字符串控制哪些后续参数用于输出。如果参数不足，其行为是未定义的。如果格式耗尽而仍有参数，多余的参数会被求值（如常），但会被忽略。`fprintf` 在遇到格式字符串结束时返回。

格式应是一个多字节字符序列，起始并结束于其初始位移状态。格式由零或多个指令组成：普通多字节字符（非 `%`），它们被原封不动地复制到输出流；以及转换规范，每个转换规范都会导致获取零或多个参数，如果适用，将它们转换为相应的转换说明符，并将结果写入输出流。

- 零或多个标志（任意顺序），用于修改转换规范的含义。
