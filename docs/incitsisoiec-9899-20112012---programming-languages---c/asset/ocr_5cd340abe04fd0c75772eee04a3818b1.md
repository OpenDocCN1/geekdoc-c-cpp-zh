A floating constant has a significand part that may be followed by an exponent part and a suffix that specifies its type. The components of the significand part may include a digit sequence followed by a period (.), followed by a digit sequence representing the fraction part. The components of the exponent part are an e, E, p, or P followed by an exponent consisting of an optionally signed digit sequence. Either the whole-number part or the fraction part has to be present; for decimal floating constants, the period or the exponent part has to be present.

# Semantics

The significand part is interpreted as a (decimal or hexadecimal) rational number; the digit sequence in the exponent part is interpreted as a decimal integer. For decimal floating constants, the exponent indicates the power of 10 by which the significand part is be scaled. For hexadecimal floating constants, the exponent indicates the power of 2 by which the significand part is be scaled. For decimal floating constants, and also for hexadecimal floating constants when FLT_RADIX is not a power of 2, the result is the nearest representable value, or the larger or smaller representable value immediately adjacent to the nearest representable value, chosen in an implementation-defined manner. For hexadecimal floating constants when FLT_RADIX is a power of 2, the result is correctly rounded.

An unsuff floating constant has type double. If suff by the letter f or F, it has type float. If suff by the letter 1 or L, it has long double.

Floating constants are converted to internal format as if at translation-time. The conversion of a floating constant shall not raise an exceptional condition or a floating-point exception at execution time. All floating constants of the same source format⁷⁵⁵) shall convert to the same internal format with the same value.

# Recommended practice

The implementation should produce a diagnostic message if a hexadecimal constant cannot be represented exactly in its evaluation format; the implementation should then proceed with the translation of the program.

The translation-time conversion of floating constants should match the execution-time conversion of character strings by library functions, such as strtod, given matching inputs for both conversions, the same result format, and default execution-time rounding.⁷⁶)

> ⁷⁵ 1.23, 1.230, 123e-2, 123e-02, and 1.23L are all different source forms and thus not need convert to the same internal format and value.

> ⁷⁶ The specification for the library functions recommends more accurate conversion than required for floating constants (see 7.22.1.3).
