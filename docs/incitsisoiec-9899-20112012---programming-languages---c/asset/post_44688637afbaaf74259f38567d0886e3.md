#include <stdarg.h>
#include <stdio.h>
void error(char *function_name, char *format, ...)

## The vscanf function

### Synopsis
```c
#include <stdarg.h>
#include <stdio.h>
int vscanf(FILE *restrict stream, const char *restrict format, va_list arg);
```

### Description
The vscanf function is equivalent to fscanf, with the argument list replaced by arg, which shall have been initialized by the va_start macro (possibly subsequent va_arg calls). The vscanf function does not invoke the va_end macro.

### Returns
The vscanf function returns the value of the macro EOF if an input failure occurs before the first conversion (any) completed. Otherwise, the vscanf function returns the number of input items assigned, which can be fewer than provided, or even zero, in the event of an early matching failure. As the functions fprintf, vscanf, vprintf, vsprintf, and vsscanf invoke the va_arg macro, the value of arg after the return is indeterminate.

## The vprintf function

### Synopsis
```c
#include <stdarg.h>
#include <stdio.h>
int vprintf(const char *restrict format, va_list arg);
```

### Description
The vprintf function is equivalent to printf, with the argument list replaced by arg, which shall have been initialized by the va_start macro (possibly subsequent va_arg calls). The vprintf function does not invoke the va_end macro. If copying takes place between objects that overlap, the behavior is undefined.

### Returns
The vprintf function returns the number of characters transmitted, or a negative value if an output error occurred. Thus, the null-terminated output has been completely written if and only if the returned value is nonnegative and less than n.

## The vsprintf function

### Synopsis
```c
#include <stdarg.h>
#include <stdio.h>
int vsprintf(char *restrict s, size_t n, const char *restrict format, va_list arg);
```

### Description
The vsprintf function is equivalent to sprintf, with the argument list replaced by arg, which shall have been initialized by the va_start macro (possibly subsequent va_arg calls). The vsprintf function does not invoke the va_end macro. If copying takes place between objects that overlap, the behavior is undefined.

### Returns
The vsprintf function returns the number of characters written in the array, not counting the terminating null character, or a negative value if an encoding error occurred.

## The vsscanf function

### Synopsis
```c
#include <stdarg.h>
#include <stdio.h>
int vsscanf(const char *restrict s, const char *restrict format, va_list args);
```

### Description
The vsscanf function is equivalent to sscanf, with the argument list replaced by arg, which shall have been initialized by the va_start macro (and possibly subsequent va_arg calls). The vsscanf function does not invoke the va_end macro.

### Returns
The vsscanf function returns the value of the macro EOF if an input failure occurs before the first conversion (any) has completed. Otherwise, the vsscanf function returns the number of input items assigned, which can be fewer than provided, or even zero, in the event of an early matching failure.

## Character input/output functions

### Synopsis
```c
#include <stdio.h>
int fgetc(FILE *stream);
```

### Description
If the end-file-indicator for the stream is not set and a next character is present, fgetc obtains the next character from the input stream pointed by stream. If the stream is end-of-file, the end-file-indicator for the stream is set and fgetc returns EOF. If a read error occurs, the error indicator for the stream is set and fgetc returns EOF.

### Synopsis
```c
#include <stdio.h>
char *fgets(char *restrict s, int n, FILE *restrict stream);
```

### Description
The fgets function reads at most one less than the number of characters specified by n from the stream until a new-line character (which is retained) or end-of-file. A null character is written after the last character read into the array. If a read error occurs, the array contents remain unchanged and a null pointer is returned.

### Synopsis
```c
#include <stdio.h>
int fputc(int c, FILE *stream);
```

### Description
The fputc function writes the character specified by c (converted to an unsigned char) to the output stream pointed by stream, at the position indicated by the file position indicator (if defined), and advances the indicator appropriately. If the file cannot support positioning, or if the stream was opened with append mode, the character is appended to the output stream.

### Returns
If a write error occurs, the error indicator for the stream is set and fputc returns EOF.

### Synopsis
```c
#include <stdio.h>
int fputs(const char *restrict s, FILE *restrict stream);
```

### Description
The fputs writes the string pointed to by s to the stream pointed by stream. The terminating null character is not written.

### Returns
If a write error occurs, fputs returns EOF; otherwise it returns a nonnegative value.

### Synopsis
```c
#include <stdio.h>
int getc(FILE *stream);
```

### Description
The getc function is equivalent to fgetc, except if it is implemented as a macro, it may evaluate stream more than once, if the argument should never be an expression with side effects.

### Returns
The getc function returns the next character from the input stream pointed by stream. If the stream is end-of-file, the end-file-indicator for the stream is set and getc returns EOF. If a read error occurs, the error-indicator for the stream is set and getc returns EOF.

### Synopsis
```c
#include <stdio.h>
int getchar(void);
```

### Description
The getchar function is equivalent to getc with the argument stdin.

### Returns
The getchar function returns the next character from the input stream pointed to stdin. If the stream is end-of-file, the end-file-indicator for the stream is set and getchar returns EOF. If a read error occurs, the error-indicator for the stream is set and getchar returns EOF.
