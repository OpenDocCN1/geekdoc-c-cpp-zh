If s is a null pointer, the wctomb_s function stores into the int pointed to by status nonzero or value, if multibyte character encodings, respectively, or do not have state-dependent dependencies.

If s is not a null pointer, the wctomb_s function stores into the int pointed to by status n or -1 if wc, respectively, does or does not correspond to a valid multibyte character.

# Returns

The wctomb_s function returns zero if successful, and a nonzero value if there was a runtime-constraint violation or wc did not correspond to a valid multibyte character.

# K.3.6.5 Multibyte/wide string functions

The behavior of the multibyte string functions is affected by the LC_CTYPE category of the current locale.

# K.3.6.5.1 The mbstowcs_s function

# Synopsis

# Runtime-constraints

Neither retval src be a null pointer. If dst is not a null pointer, neither len dstmax shall be greater than RSIZE_MAX. If dst is a null pointer, dstmax shall equal zero. If there is a runtime-constraint violation, mbstowcs_s does the following. If retval is not a null pointer, mbstowcs_s sets *retval to (size_t) (-1). If dst is not a null pointer and dstmax is greater than zero and less than RSIZE_MAX, mbstowcs_s sets dst [0] to the null wide character.
