# EXAMPLE 4 In:

```
#include <stdio.h>
```

the value 123 is assigned to d1 and the value to n1. Because %n can never get an input failure, the value of 3 is also assigned to n2. The value of d2 is not affected. The value 1 is assigned to i.

will assign to n the value 1 and to i the value 42 because input white-space characters are skipped for both the % and d conversion sequences.
