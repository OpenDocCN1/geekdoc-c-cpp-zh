

## 6.5.1 初级表达式 (Primary expressions)

### 语义

标识符（identifier）是一个一级表达式，前提是它被声明为指定一个对象（在这种情况下它是一个 Ivalue）或一个函数（在这种情况下它是一个函数指示符）。^{91}

常量（constant）是一个一级表达式。它的类型取决于其形式和值，详见 6.4.4。

字符串字面量（string literal）是一个一级表达式。它是一个 Ivalue，其类型详见 6.4.5。

带括号的表达式（parenthesized expression）是一个一级表达式。它的类型和值与不带括号的表达式相同。如果不带括号的表达式分别是 Ivalue、函数指示符或 void ，那么它也是 Ivalue、函数指示符或 void 。

通用选择（generic selection）是一个一级表达式。它的类型和值取决于所选的泛用关联，详见下述子句。

**前向引用：** 声明（6.7）。

### 6.5.1.1 通用选择

### 语法

```
generic-selection: ( assignment-expression , generic-assoc-list )
generic-assoc-list:
gener-association
generic-assoc-list , generic-association
generic-association:
type-name : assignment-expression
default : assignment-expression
```

91) 因此，未声明的标识符违反了语法。

### 约束

通用选择最多可以有一个默认泛用关联（default generic association）。泛用关联中的类型名应指定一个除可变类型（variably modified type）以外的完整对象。同一个通用选择中的任意两个泛用关联不能指定兼容的类型。通用选择的控制表达式（controlling expression）的类型应与其泛用关联列表中列出的类型中最多一个兼容。如果通用选择没有默认泛用关联，则其控制表达式的类型应与其泛用关联列表中列出的类型中恰好一个兼容。

### 语义

通用选择的控制表达式不求值。如果通用选择具有一个类型名与控制表达式类型兼容的泛用关联，则该通用选择的结果表达式（result expression）是该泛用关联中的表达式。否则，通用选择的结果表达式是默认泛用关联中的表达式。该通用选择中任何其他泛用关联的表达式都不会被求值。

通用选择的类型和值与其结果表达式相同。如果其结果表达式分别是 lvalue、函数指示符或 void ，那么它也是 lvalue、函数指示符或 void 。

示例 `cbrt` 类型泛型宏 `_Generic(X)` 可以如下所示实现：

```
#define cbrt (X) _Generic(X) \\
long double: cbrtl, \\
default: cbrt, \\
float: cbrtf \\
) (X)
```

### 6.5.2.1 数组下标 (Array subscribing)

其中一个表达式的类型为“指向完整对象的指针”，另一个表达式应为整数类型，结果具有“类型”。

### 语义

后置运算符后接方括号 `[]` 中的表达式是数组对象元素的下标指定（subscribed designation）。下标运算符 `[]` 的定义是 `E1 [E2]` 等同于 `(* (E1) + (E2))`。由于适用于二进制 `+` 运算符的转换规则，`E1` 是一个数组对象（等于指向数组初始元素的指针），`E2` 是整数，`E1 [E2]` 指定 E 的第 `E2` 个元素（从零开始计数）。

连续的下标运算符指定多维数组对象的元素。如果 `E` 是维度为 $i\times j...\times k$ 的 $n$ 维数组（$n\ge2$），则 `E`（作为 lvalue以外的使用）被转换为指向维度为 $j\times...\timesk$ 的 $(n-1)$ 维数组的指针。如果显式或隐式地将一元运算符 `*` 应用于此指针，则结果是被引用的 $(n-1)$ 维数组，该数组本身在作为 lvalue以外的使用时转换为指针。由此可以得出，这些数组按行主序存储（最后一个下标变化最快）。示例考虑声明 `x` 定义的数组对象是一个 $3\times5$ 的整数数组；准确来说，`x` 是一个元素对象数组，每个元素都是一个数组。在表达式 `x[i]` 中，它等同于 `((x) + (i))`，`x` 首先被转换为指向整数数组的指针。然后根据 `x` 的类型调整 `i`，这将 `i` 乘以指针指向的对象的大小，因此 `x[i][j]` 产生一个 `int`。

前向引用：加法运算符（6.5）、地址和间接运算符（6.5.3）、数组声明符（6.7）。
