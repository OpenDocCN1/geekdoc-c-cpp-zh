Forward references: IEC 60559-compatible complex arithmetic (annex G).

# 7.3.2 Conventions

Values are interpreted as radians, not degrees. An implementation may set errno but not required to.

# 7.3.3 Branch cuts

Some of the functions have branch cuts, across which the function is discontinuous. For implementations with a signed zero (including all IEC 60559 implementations) that follow the specifications of annex G, the sign of zero distinguishes one side of a cut from another so the function is continuous (except for format limitations) as the cut is approached from either side. For example, for the square root function, which has a cut along the negative real axis, the top of the cut, with imaginary part +0, maps to the positive imaginary axis, and the bottom of the cut, with imaginary part -0, maps to the negative imaginary axis.

Implementations do not support a signed zero (annex F) cannot distinguish the sides of branch cuts. These implementations shall map a cut so the function is continuous as the cut is approached coming around the finite endpoint of the cut in a counter clockwise direction. (Branch cuts for the functions specified here have just one endpoint.) For the square root function, coming counter clockwise around the finite endpoint of the cut along the negative real axis approaches the cut from above, so the cut map to the positive imaginary axis.

# 7.3.4 The CX_LIMITED_RANGE pragma

Synopsis

```
#include <complex.h>
#pragma STDC CX_LIMITED_RANGE on-off-switch
```

Description

The usual mathematical formulas for complex multiply, divide, and absolute value are problematic because of their treatment of infinities and of undue overflow and underflow. The CX_LIMITED_RANGE pragma can be used to inform the implementation (where the state is “on”) the usual mathematical formulas are acceptable. The pragma can occur either external declarations or preceding all explicit declarations and statements inside a compound statement. When external declarations, the pragma takes effect from its occurrence until another CX_LIMITED_RANGE pragma is encountered, or until the end of the translation unit.
