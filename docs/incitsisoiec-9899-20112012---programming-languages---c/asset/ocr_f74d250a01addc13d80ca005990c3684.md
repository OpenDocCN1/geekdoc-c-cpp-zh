The first wide character of a signed conversion is not a sign, or if signed conversion results in no wide characters, a space is prefixed to the result. If the space and flags appear both, the space flag is ignored.

The result is converted to an “alternative form”. For o conversion, the precision increases if and only if necessary, to force the first digit of the result to be a zero (if the value and precision are 0, a single 0 is printed). For x (or X) conversion, a nonzero result has 0x (or 0X) prefixed to it. For a, E, e, F, G, and G conversions, the result of converting a floating-point number always contains a decimal-point wide character, if no digits follow it. (Normally, a decimal-point wide character appears in the result of these conversions only if a digit follows it.) For g and G conversions, trailing zeros are not removed from the result. For other conversions, the behavior is undefined.

For d, i, o, u, x, A, a, E, e, F, g, and G conversions, leading zeros (following any indication of sign or base) are used to pad to the field width rather than performing space padding, when converting an infinity or NaN. The 0 and flags appear both, the 0 flag is ignored. For d, i, o, u, x conversions, if a precision is specified, the 0 flag is ignored. For other conversions, the behavior is undefined.
