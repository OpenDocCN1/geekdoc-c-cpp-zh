## 7.24.4.3 strlen 函数

用法

```c
#include <string.h>
int strlen(const char *s1, const char *s2);
```

描述
strlen 函数比较由 s1 指向的字符串与 s2 指向的字符串，两者均根据当前区域设置（locale）的 LC_COLLATE 类别进行相应的解释。

返回值

strlen 函数返回一个大于、等于零或小于零的整数，这取决于当两者都根据当前区域设置进行相应的解释时，由 s1 指向的字符串是否大于、等于或小于 s2 指向的字符串。

## 7.24.4.4 strcmp 函数

用法

```c
#include <string.h>
int strcmp(const char *s1, const char *s2, size_t n);
```

描述
strcmp 函数比较从 s1 指向的数组到 s2 指向的数组的至多 n 个字符（空字符之后的字符不进行比较）。

返回值
strcmp 函数返回一个大于、等于零或小于零的整数，这取决于可能以空字符终止的 s1 指向的数组是否大于、等于或小于可能以空字符终止的 s2 指向的数组。

## 7.24.4.5 strxfrm 函数

用法

```c
#include <string.h>
size_t strxfrm(char * restrict s1, const char * restrict s2, size_t n);
```

描述

strxfrm 函数转换 s2 指向的字符串并将结果放入 s1 指向的数组中。转换规则是：如果对两个转换后的字符串应用 strcmp 函数，它返回一个大于、等于或小于零的值，该值对应于对相同的原始字符串应用 strcoll 函数的结果。放入 s1 指向的输出数组中的字符数不少于 n 个，包括终止的空字符。如果 n 为零，则允许 s1 为空指针。如果在重叠的对象之间进行拷贝，则行为是未定义的。

返回值

strxfrm 返回转换后字符串的长度（不包括终止的空字符）。如果返回的值为 n 或更大，则 s1 指向的数组的内容是不确定的。

示例 下述表达式的值是存储 s 指向字符串转换结果所需的数组大小。

```c
1 + strxfrm(NULL, s, 0)
```

## 7.24.5 搜索函数

### 7.24.5.1 memchr 函数

用法

```c
#include <string.h>
void *memchr(const void *s, int c, size_t n);
```

描述

memchr 函数在 s 指向的对象的初始 n 个字符中（每个字符均解释为无符号 char）定位 c（转换为无符号 char）的首次出现。该实现行为类似于顺序读取字符并在找到匹配字符时立即停止。

返回值

memchr 函数返回指向找到字符的指针，如果该字符不在对象中，则返回空指针。

### 7.24.5.8 strtok 函数

用法

```c
#include <string.h>
char *strtok(char *s1, const char *s2);
```

描述
一系列的 strtok 调用将 s1 指向的字符串拆分为一系列标记（tokens），每个标记都由 s2 指向的字符串中的字符分隔。序列中的第一次调用具有非空第一个参数；后续调用的第一个参数为空。序列中的第一次调用在 s1 指向的字符串寻找不包含在分隔符字符串中的字符。如果没有找到这样的字符，则标记延伸到字符串末尾。strtok 函数保存指向后续字符的指针，下次搜索将从该处开始。每个后续调用（以空指针作为第一个参数）都从保存的指针开始搜索并按上述描述行为。strtok 函数不要求避免与该函数的其他调用产生数据竞态。

返回值

strtok 函数返回指向标记第一个字符的指针，如果没有标记，则返回空指针。
