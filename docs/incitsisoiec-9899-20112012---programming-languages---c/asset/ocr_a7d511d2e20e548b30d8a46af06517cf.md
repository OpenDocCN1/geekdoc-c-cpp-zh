# 72.94.2.4 The wmemmove function

Synopsis

```
#include <wchar.h>
wchar_t *wmemmove(wchar_t *s1, const wchar_t *s2,
size_t n);
```

Description

The wmemmove function copies n wide characters from the object pointed to by s2 to the object pointed to by s1. Copying takes as place if the n wide characters from the object pointed to by s2 overlap s1 they are first copied into a temporary array of n wide characters that does not overlap the objects pointed to by s1 or s2, and then the n wide characters from the temporary array are copied into the object pointed to by s1.

Returns

The wmemmove function returns the value of s1.

# 72.9.4.3 Wide string concatenation functions

# 72.9.4.3.1 The wcsscat function

Synopsis

```
#include <wchar.h>
wchar_t *wcsscat(wchar_t *restrict s1,
const wchar_t *restrict s2);
```

Description

The wcsscat function appends a copy of the wide pointed to by s2 (including the terminating null wide character) to the end of the wide string pointed to by s1. The initial wide character of s2 overwrites the null wide character at the end of s1.

Returns

The wcsscat function returns the value of s1.
