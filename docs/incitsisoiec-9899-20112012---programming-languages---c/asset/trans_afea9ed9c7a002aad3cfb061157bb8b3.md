

## L_tmpnam

它展开为一个整数常量表达式，其值是一个 `char` 数组的大小，该数组能够足够容纳由 `tmpnam` 函数生成的临时文件名字符串：

```
SEEK_CUR
SEEK_END
SEEK_SET
```

它们展开为具有不同值的整数常量表达式，适用于用作 `fseek` 函数的第三个参数：

## TMP_MAX

它展开为一个整数常量表达式，其值是 `tmpnam` 函数能够生成的唯一文件名的最少数量：

```
stderr
stdin
stdout
```

它们是类型为“指向 FILE 的指针”的表达式，分别指向与标准错误、输入和输出流相关的 `FILE` 对象。

头文件 `<wchar.h>` 声明了若干用于宽字符输入和输出的函数。该子节描述的宽字符输入/输出函数提供了与该子节描述的大多数函数类似的操作，区别在于程序内部的根本单位是宽字符。外部表示（在文件中）是一序列“广义”多字节字符，详见 7.21.3 的进一步描述。

这些输入/输出函数具有以下统称为：

- 宽字符输入函数 —— 7.29 节描述的执行向宽字符和宽字符串输入的函数：fgetwc, fgetws, getwc, getwchar, fwscanf, wscanf, vfwscanf, 和 vwgetwc。
- 宽字符输出函数 —— 7.29 节描述的执行从宽字符和宽字符串输出的函数：fputwc, fputws, putwc, putwchar, fwprintf, wprintf, vfwprintf, 和 vwprintf。

> 实现对文件名字符串的长度没有实际的限制，`FILENAME_MAX` 的值应指示用于存放文件名字符串的数组的建议大小。当然，文件名的内容受到其他特定系统的约束限制；因此，无法期望所有长度为 `FILENAME_MAX` 的字符串都能被成功打开。

宽字符输入/输出函数 —— `ungetwc` 函数与宽字符输出函数的并集。

字节输入/输出函数 —— 本子节描述的执行输入/输出的函数：fgetc, fgets, fprintf, fputc, fread, fgets, fscanf, fwrite, getc, getchar, printf, putc, putchar, puts, scanf, ungetc, vsprintf, vsscanf, 和 vsnprintf。

## 7.21.2 流

- 输入和输出，无论是来自物理设备（如终端和磁带驱动器），还是来自或传往结构化存储设备的文件，都被映射为逻辑数据流，其属性比其输入和输出更统一。支持两种映射形式：文本流和二进制流。
- 文本流是由字符组成的有序序列，并组成若干行，每行由零个或多个字符加一个终止换行符组成。最后一行是否需要终止换行符由实现定义。为了符合主机环境中表示文本的不同惯例，在输入和输出时可能需要添加、修改或删除字符。因此，流中的字符与外部表示中的字符不需要是一一对应的关系。如果满足以下条件，从文本流中读取的数据将与早先写入该流的数据比较：数据仅由字符以及制表符和换行符控制字符组成；换行符之前没有紧跟空格字符；最后一个字符是换行符。在换行符之前立即写入的空格字符在读取时是否出现由实现定义。
- 二进制流是能够透明记录内部数据的字符有序序列。从二进制流中读取的数据应与早先写入该流的数据相等：如果数据仅由字符以及制表符和换行符控制字符组成；换行符之前没有紧跟空格字符；且最后一个字符是换行符（注：此处原文逻辑似乎与文本流描述重复或冲突，此处按字面翻译）。在换行符之前立即写入的空格字符在读取时是否出现由实现定义。
