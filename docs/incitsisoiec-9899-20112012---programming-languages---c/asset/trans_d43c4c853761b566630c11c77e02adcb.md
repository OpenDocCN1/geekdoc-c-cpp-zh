

## K.3.9.2.3 宽字符串查找函数

### K.3.9.2.3.1 wcstok_s 函数

原型说明

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
wchar_t *wcstok(wchar_t * restrict s1,
size_t * restrict slmax,
const wchar_t * restrict s2,
wchar_t ** restrict ptr);
```

运行时约束

slmax、s2 或 ptr 均不能为空指针。如果 s1 为空指针，则 *ptr 不得为空指针。*slmax 的值不应大于 RSIZE_MAX。对于第一次调用，标记（token）的末尾应出现在 s1 的前 *slmax* 个宽字符内；在后续调用中，搜索继续时，末尾应出现在搜索恢复的前 *slmax* 个宽字符内。

如果发生运行时约束违反，wcstok_s 函数不会通过 s1 或 s2 指针进行间接访问，也不会在 ptr 指向的对象中存储值。

描述

通过连续调用 wcstok_s 函数，将 s1 指向的宽字符串拆分为一系列标记，每个标记都由 s2 指向的宽字符串中的宽字符分隔。第四个参数指向一个调用者提供的 wchar_t 指针，wcstok_s 函数向其中存储继续扫描宽字符串所需的信息。

序列中的第一次调用具有非空的第一个参数，且 slmax 指向一个对象，该对象的值为第一个参数指向的宽字符数组的元素个数。该调用在 ptr 指向的对象中存储一个初始值，并更新由 slmax 指向的值，以反映相对于 ptr 处仍剩余的元素个数。序列中的后续调用第一个参数为空指针，且要求 slmax 和 ptr 指向的对象具有之前序列中上一次调用所存储的值，这些值将得到更新。s2 指向的分隔符宽字符串可能每次调用都不同。

序列中的第一次调用在 s1 指向的宽字符串中查找第一个不包含当前 s2 指向的分隔符宽字符串中的宽字符。如果找到了这样的宽字符，则 s1 指向的宽字符串中没有标记，wcstok_s 返回空指针。如果找到了该宽字符，它就是第一个标记的起点。

wcsok_s 函数从该处开始搜索 s1 中第一个包含当前宽字符串的宽字符。如果没有找到这样的宽字符，则当前标记延伸到 s1 指向的宽字符串的末尾，并且在同一宽字符串中对标记的后续搜索将返回空指针。如果找到了该字符，它将被一个空字符覆盖，从而终止当前标记。

在所有情况下，wcsok_s 函数都会在 ptr 指向的指针中存储足够的信息，使得后续调用（s1 为空指针且 ptr 指针值保持未修改）将从被宽字符覆盖的元素（如果有）之后开始搜索。

# 返回值

wcsok_s 函数返回标记的第一个宽字符的指针；如果没有标记或发生运行时约束违反，则返回空指针。

# 示例

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
static wchar_t str1[1] = L"??b,c";
static wchar_t str2[2] = L"\t \t";
wchar_t *t, *ptr1, *ptr2;
size_t max1 = wcslen(str1+1)
size_t max2 = wcslen(str2+2)

t = wcsok_s(str1, max1, "", &ptr1); // t 指向标记 "a"
t = wcsok_s(str1, max1, ",\,", &ptr1); // t 指向标记 "??b"
t = wcsok_s(str2, max2, "\t", &ptr2); // t 为空指针
t = wcsok_s(NULL, max1, "##", &ptr1); // t 指向标记 "c"
t = wcsok_s(NULL, max1, "?", &ptr1); // t 为空指针
```

## K.3.9.2.4 其他函数

### K.3.9.2.4.1 wcslen_s 函数

原型说明

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
size_t wcslen_s(const wchar_t *s, size_t maxsize);
```

描述

wcslen_s 函数计算 s 指向字符串的长度。

# 返回值

如果 s 为空指针，wcslen_s 返回零。否则，wcslen_s 返回空字符之前的宽字符个数。

## K.3.9.3 扩展多字节字符转换

### K.3.9.3.1 wcrtomb_s 函数

原型说明

```
#include <wchar.h>
errno_t wcrtomb_s(size_t *retval, char *s, size_t smax, wchar_t wc, mbstate_t *ps);
```

运行时约束

retval、s 或 ps 均不能为空指针。如果 s 不是空指针，smax 不应大于 RSIZE_MAX。如果 s 为空指针，smax 应相等。

如果发生运行时约束违反，wcrtomb_s 执行以下操作：如果 retval 不是空指针，wcrtomb_s 将 *retval 设置为 (size_t) (-1)。如果 s 不是空指针且 smax 大于 0 且 RSIZE_MAX，wcrtomb_s 将 s[0] 设置为空字节。

描述

如果 s 不是空指针，wcrtomb_s 确定表示 wc 需要的字节数并存储在 s 指向的数组中。最多存储 MB_MAX 个字节，包括转换序列。如果 wc 不对应有效的多字节字符，则发生编码错误：wcrtomb_s 将 *retval 设置为 (size_t) (-1)，状态未定义。

# 返回值

如果没有发生运行时约束和编码错误，wcrtomb_s 函数返回零。否则返回非零值。

### K.3.9.3.2 可重入多字节字符串转换

### K.3.9.3.2.1 mbsrtowcs_s 函数

```
#include <wchar.h>
errno_t mbsrtowcs_s(size_t *retval, char_t *dst, size_t dstmax, char **src, size_t len, mbstate_t *ps);
```

运行时约束

retval、src、src 或 ps 都不能为空指针。如果 dst 不是空指针，len 和 dstmax 均不大于 RSIZE_MAX。如果 dst 为空指针，dstmax 应相等。如果 dst 不是空指针且 len 不小于 dstmax，则在 src 指向的数组的前 dmax 个多字节字符内应出现空字符。

如果发生运行时约束违反，mbsrtowcs_s 执行以下操作：如果 retval 不是空指针，mbsrtowcs_s 将 *retval 设置为 (size_t) (-1)。如果 dst 不是空指针且 dmax 大于 0 且 RSIZE_MAX，mbsrtowcs_s 将 dst[0] 设置为空宽字符。

描述

mbsrtowcs_s 函数根据 ps 指向的对象描述的转换状态，将 src 指向的多字节字符序列转换为相应的宽字符序列。如果 dst 不是空指针，转换后的字符存储在 dst 指向的数组中。转换持续直到包含终止空字符，该字符也会被存储。转换在两种情况下提前停止：遇到无法形成有效多字节字符的字节序列，或者（如果 dst 不是空指针）达到 len。
