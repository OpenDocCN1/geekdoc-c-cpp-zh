The implementation shall behave as if no library function calls the localconv function.

# Returns

The localconv function returns a pointer to the filled-in object. The structure pointed by the return value shall not be modified by the program, but may be overwritten by a subsequent call to the localconv function. In addition, calls to the setlocale function with categories LC_ALL, LC_MONETARY, or LC_NUMERIC may overwrite the contents of the structure.
