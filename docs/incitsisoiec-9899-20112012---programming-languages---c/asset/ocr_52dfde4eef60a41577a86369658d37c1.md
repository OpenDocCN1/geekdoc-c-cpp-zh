# 7.31 Future library directions

The following names are grouped under individual headers for convenience. All external names described below are no matter what headers are included by the program.

# 7.31.1 Complex arithmetic <complex.h>

The function names

```
cerf        cepm1       clog2
ferfc       clog10      clgamma
cpex2       clogip      ctgamma
```

and the same names suffixed with **f** or **l** may be added to the declarations in the <complex.h> header.

# 7.31.2 Character handling <ctype.h>

Function names that begin with either **is** or **to**, and a lowercase letter may be added to the declarations in the <ctype.h> header.

# 7.31.3 Errors <errno.h>

Macros that begin with **E** and a digit **D** or an uppercase letter may be added to the macros defined in the <errno.h> header.

# 7.31.4 Floating-point environment <fenv.h>

Macros that begin with **FE_** and an uppercase letter may be added to the macros defined in the <fenv.h> header.

# 7.31.5 Format conversion of integer types <inttypes.h>

Macros that begin with **PRI** **SCN**, either a lowercase letter or **X** may be added to the macros defined in the <inttypes.h> header.

# 7.31.6 Localization <locale.h>

Macros that begin with **LC_** and an uppercase letter may be added to the macros defined in the <locale.h> header.

# 7.31.7 Signal handling <signal.h>

Macros that begin with either **SIG** or **SIG_** and an uppercase letter may be added to the macros defined in the <signal.h> header.

# 7.31.8 Atoms <stdatomic.h>

Macros that begin with **ATOMIC_** and an uppercase letter may be added to the macros defined in the <stdatomic.h> header.
