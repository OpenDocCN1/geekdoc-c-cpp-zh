## 7.26.3.3 cnd_init 函数

### 概要

```c
#include <threads.h>
int cnd_init (cnd_t *cond);
```

### 描述

`cnd_init` 函数创建一个条件变量。如果执行成功，它会将 `cond` 指向的变量设置为一个唯一标识新创建的条件变量的值。在新创建的条件变量上调用 `cnd_wait` 的线程将会被阻塞。

### Returns

`cnd_init` 函数在执行成功时返回 `thrd_success`；如果无法为新创建的条件变量分配内存，则返回 `thrd_nomem`；如果请求无法实现，则返回 `thrd_error`。

## 7.26.3.4 cnd_signal 函数

### 概要

```c
#include <threads.h>
int cnd_signal (cnd_t *cond);
```

### 描述

`cnd_signal` 函数唤醒调用时阻塞在 `cond` 指向的条件变量上的一个线程。如果调用时没有线程阻塞在该条件变量上，该函数将不执行任何操作并返回成功。

### Returns

`cnd_signal` 函数在执行成功时返回 `thrd_success`；如果请求无法实现，则返回 `thrd_error`。

## 7.26.3.5 cnd_timedwait 函数

### 概要

```c
#include <threads.h>
int cnd_timedwait (cnd_t *restrict cond,
mtx_t *restrict mtx,
const struct timespec *restrict ts);
```

### 描述

**cnd_timedwait** 函数原子性地解锁由 **mtx** 指向的互斥锁，并尝试阻塞，直到 **cond** 指向的条件变量被 **cnd_signal** 或 **cnd_broadcast** 信号，或者直到达到 **ts** 指向的基于 TIME_UTC 的日历时间之后。当调用线程被唤醒时，它会在返回之前锁定 **mtx** 指向的变量。**cnd_timedwait** 函数要求调用线程必须已锁定 **mtx** 指向的互斥锁。

### Returns

**cnd_timedwait** 函数在执行成功时返回 **thrd_success**；如果在调用指定的时间到达前未获取请求的资源，则返回 **thrd_timedout**；如果请求无法实现，则返回 **thrd_error**。

## 7.26.3.6 cnd_wait 函数

### 概要

```c
#include <threads.h>
int cnd_wait(cnd_t *cond, mtx_t *mtx);
```

### 描述

**cnd_wait** 函数原子性地解锁由 **mtx** 指向的互斥锁，并尝试阻塞，直到 **cond** 指向的条件变量通过调用 **cnd_signal** 或 **cnd_broadcast** 收到信号。当调用线程被唤醒时，它会在返回之前锁定 **mtx** 指向的互斥锁。**cnd_wait** 函数要求调用线程必须已锁定 **mtx** 指向的互斥锁。

### Returns

**cnd_wait** 函数在执行成功时返回 **thrd_success**，如果请求无法实现，则返回 **thrd_error**。

## 7.26.4 互斥锁函数

### 7.26.4.1 mtx_destroy 函数

### 概要

```c
#include <threads.h>
void mtx_destroy(mtx_t *mtx);
```

### 描述

**mtx_destroy** 函数释放由 **mtx** 指向的互斥锁所使用的任何资源。没有线程可以阻塞等待 **mtx** 指向的互斥锁。

### Returns

**mtx_destroy** 函数没有没有值。

## 7.26.4.2 mtx_init 函数

### 概要

```c
#include <threads.h>
int mtx_init(mtx_t *mtx, int type);
```

### 描述

`mtx_init` 函数创建一个由 `type` 指定属性的互斥锁对象，`type` 必须是六个值之一：
- mtx_plain：用于简单的非递归互斥锁；
- mtx_timed：用于支持超时的非递归互斥锁；
- mtx_plain | mtx_recursive：用于简单的递归互斥锁；或
- mtx_timed | mtx_recursive：用于支持超时的递归互斥锁。

如果 `mtx_init` 函数执行成功，它会将 `mtx` 指向的互斥锁设置为一个唯一标识所创建互斥锁的值。

### Returns

`mtx_init` 函数在执行成功时返回 `thrd_success`；如果请求无法实现，则返回 `thrd_error`。

## 7.26.4.3 mtx_lock 函数

### 概要

```c
#include <threads.h>
int mtx_lock(mtx_t *mtx);
```

### 描述 

`mtx_lock` 函数阻塞直到它解锁由 `mtx` 指向的互斥锁。如果该互斥锁是非递归的，则调用线程不应已锁定它。之前对同一互斥锁的 `mtx_unlock` 调用应与此操作操作同步。

### Returns

`mtx_lock` 函数在执行成功时返回 `thrd_success`；如果请求无法实现，则返回 `thrd_error`。

## 7.26.4.4 mtx_timedlock 函数

### 概要

```c
#include <threads.h>
int mtx_timedlock(mtx_t *restrict mtx,
const struct timespec *restrict ts);
```

### 描述 

`mtx_timedlock` 函数尝试阻塞直到它锁定 `mtx` 指向的互斥锁，或者达到 `ts` 指向的基于 TIME_UTC 的日历时间。如果操作成功，之前对该互斥锁的 `mtx_unlock` 调用应与此操作同步。

### Returns

`mtx_timedlock` 函数在执行成功时返回成功；如果在调用指定的时间内未获取该互斥锁，则返回超时；或者如果请求无法实现。

## 7.26.4.5 mtx_trylock 函数

### 概要

```c
#include <threads.h>
int mtx_trylock(mtx_t *mtx);
```

### 描述 

`mtx_trylock` 函数尝试锁定 `mtx`。如果该互斥锁已锁定，该函数将不阻塞并返回。如果操作成功，之前对该互斥锁的 `mtx_unlock` 调用应与此操作同步。

### Returns

`mtx_trylock` 函数在执行成功时返回 `thrd_success`；如果互斥锁在使用中，则返回忙。

## 7.26.4.6 mtx_unlock 函数

### 概要

```c
#include <threads.h>
int mtx_unlock(mtx_t *mtx);
```

### 描述 

`mtx_unlock` 函数解锁由 `mtx` 指向的互斥锁。

### Returns

`mtx_unlock` 函数在执行成功时返回成功；如果请求无法实现。

## 7.26.5 线程函数

### 7.26.5.1 thrd_create 函数

### 概要

```c
#include <threads.h>
int thrd_create(thrd_t *thr, thrd_start func, void *arg);
```

### 描述

`thrd_create` 函数创建一个执行 `func(arg)` 的新线程。如果 `thrd_create` 执行成功，它将 `thr` 指向的对象设置为新创建线程的标识符。（当线程被分离或连接后，该标识符可以被重用。）`thrd_create` 函数与新线程的执行同步。

### Returns

`thrd_create` 函数在执行成功时返回 `thrd_success`；如果无法为请求的线程分配内存，或者请求无法实现。

### 7.26.5.2 thrd_current 函数

### 概要

```c
#include <threads.h>
thrd_t thrd_current(void);
```

### 描述 

`thrd_current` 函数标识调用它的线程。`thrd_current` 函数返回调用线程的标识符。

### 7.26.5.3 thrd_detach 函数

### 概要

```c
#include <threads.h>
int thrd_detach(thrd_t thr);
```

### 描述 

`thrd_detach` 函数告诉操作系统在 `thr` 指向的线程终止时释放分配给该线程的任何资源。`thr` 指向的线程之前不应被分离或连接到另一个线程。

`thrd_detach` 函数在执行成功时返回 `thrd_success`；如果请求无法实现。

### 7.26.5.4 thrd_equal 函数

### 概要

```c
#include <threads.h>
int thrd_equal(thrd_t thr0, thrd_t thr1);
```

### 描述 

`thrd_equal` 函数确定 `thr0` 所标识的线程是否引用 `thr1` 所标识的线程。

### Returns

如果线程 thr0 和线程 thr1 指向不同的线程，`thrd_equal` 函数返回零。否则`thrd_equal` 函数返回非零值。

### 7.26.5.5 thrd_exit 函数

### 概要

```c
#include <threads.h>
_Noreturn void thrd_exit(int res);
```

### 描述 

`thrd_exit` 函数终止调用线程的执行，并将其结果设置为 `res`。

在最后一个线程终止后，程序将正常终止。其行为将如同在线程终止时调用了带有 `EXIT_SUCCESS` 状态的 `exit` 函数一样。

### Returns

`thrd_exit` 函数没有没有值。
