7 All integer values in the <float.h> header, FLT_ROUNDS, shall be constant expressions suitable for use #if preprocessing directives; all floating values shall be constant expressions. 8 The rounding mode for floating-point addition is characterized by the implementationdefined value of FLT_ROUNDS.^{23}
