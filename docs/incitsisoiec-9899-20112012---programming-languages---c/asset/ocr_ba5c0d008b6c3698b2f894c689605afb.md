# 7.24.3 Concatenation functions

# 7.24.3.1 The strcat function

# Synopsis

```
#include <string.h>
char *strcat(char * restrict s1
```

# Description

The strcat function appends a copy of the string pointed to by s2 (including the null character) to the end of the string pointed to by s1. The initial character of s2 overwrites the null character at the end of s1. If copying takes place between objects that overlap, the behavior is undefined.

# Returns

The strcat function returns the value of s1.
