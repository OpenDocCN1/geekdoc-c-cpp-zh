# Description

The wscat_s function appends a copy of the wide string pointed to by s2 (including the terminating wide character) to the end of the string pointed to by s1. The initial wide character from s2 overwrites the null wide character at the end of s1.

All elements following the terminating wide character (if any) written by wscat_s in the array of s1max wide characters pointed to by s1 take undefined values when wscat_s returns.⁴47

# Returns

The wscat_s function returns zero⁴48) if there is no runtime-constraint violation. Otherwise, a nonzero value is returned.
