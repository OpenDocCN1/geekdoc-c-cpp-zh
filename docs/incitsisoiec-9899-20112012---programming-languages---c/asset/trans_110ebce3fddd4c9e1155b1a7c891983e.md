## 6.5.16 赋值运算符

### 语法

赋值-表达式:
条件表达式
一元-表达式 赋值运算符 赋值-表达式

赋值运算符: 以下者之一

```
= *= /= %= += - <= >= >= &= ^ |=
```

### 约束

赋值运算符的左操作数必须是一个可修改的左值（lvalue）。

### 语义

赋值运算符将值存储在左操作数指定的对象中。赋值表达式在赋值后具有左操作数的值¹¹¹¹ 但不是一个左值。赋值表达式的类型是左操作数在经过左值转换后可能具有的类型。更新左操作数存储值的副作用在在左、右操作数的值计算之后进行序列化。操作数的求值是非顺序的（unsequenced）。

> ¹¹¹¹实现允许读取该对象以确定值，但并不要求这样做，即使该对象具有带有 `volatile` 限定符的类型。

### 6.16.1 简单赋值

#### 约束

+ 1 应当满足以下条件之一：{112}
- 左操作数具有原子的、限定的或未限定的算术类型，或者右操作具有算术类型；
- 左操作数具有原子的、限定或未限定的结构或联合类型版本，且与右操作数的类型兼容；
- 左操作数具有原子的、限定或未限定的指针类型，并且（考虑到左操作数在左值转换后可能具有的类型）两个操作数都是指向兼容类型的限定或未限定版本的指针，且左操作数指向的类型具有右操作数指向的类型的所有限定符；
- 左操作数具有原子的、限定或未限定的指针类型，并且（考虑到左操作数在左值转换后可能具有的类型）一个操作数是指向对象类型的指针，另一个是指向 `void` 的限定或未限定版本的指针，且左操作数指向的类型具有右操作数指向的类型的所有限定符；
- 左操作数是原子的、限定或未限定的指针，而右侧是空指针常量；或者
- 左侧具有原子、限定或未限定的 _Bool_ 类型，而右侧是一个指针。

#### 语义

+ 2 在简单赋值 (=) 中，右操作数的值被转换为赋值表达式的类型，并替换左操作数类型所指定的对象中存储的值。

### 6.5.16.2 复合赋值

#### 约束

对于 `+=` 和 `-=` 运算符，左操作数应当是原子的、限定或未限定的指向对象类型的指针，且右侧具有算术类型；对于其他运算符，左操作数具有原子、限定或未限定的算术类型，并且（考虑到左操作数在左值转换后可能具有的类型）其具有算术类型。

#### 语义

形式为 `E1 op E2` 的复合赋值等于简单赋值 `E1 = (E2)`，但 `E1` 只求值一次，且如果 `E1` 是原子类型，复合赋值具有 `memory_order_cst` 内存语义¹¹3)。如果 `E1` 或 `E2` 是浮点类型，那么在求值 `new` 过程中遇到的浮点异常也应该丢弃，以满足 `E1 = E2` 的等价性。例如，如果 `F` 是 `float`，涉及的浮点类型具有 IEC 6059 格式，且 `FLT_EVAL_METHOD` 为 0，等效代码将：

```
#include <fenv.h>
#pragma STDC FENV_ACCESS
/* */
fenv fenv;
T1 *addr = &E1;
T2 val = E2;
T1 old = *addr;
T1 new;
feholdexcept(&fenv);
for (;;) {
    new = old op val;
    if (atomic_compare_exchange_strong(addr, &old, new))
        break;
    feclecept(FE_ALL_EXCEPTION);
}
feupdateenv(&fenv);
```

如果 `FLT_EVAL_METHOD` 不是 0，则 `T2` 必须是 `E2` 求值时的类型。

## 6.5.17 逗号运算符

### 语法

```
expression , assignment-expression
expression , assignment-expression
```

### 语义

逗号运算符的左操作数被求值为空表达式；在其求值与右操作数求值之间存在一个序列点。然后求值右操作数；结果具有其类型和值。¹14)}

示例 如语法所示，逗号运算符（在本子句中描述）不能出现在逗号用于分隔列表项的语文中（例如函数参数或初始化列表）。另一方面，它可以出现在此类语境的圆括号表达式中，或条件运算符的第二个表达式中。在函数调用中

```
f(a, (t=3, t+2), c)
```

该函数有三个参数，第二个参数的值为 5。

> 114) 逗号运算符不产生左值。
