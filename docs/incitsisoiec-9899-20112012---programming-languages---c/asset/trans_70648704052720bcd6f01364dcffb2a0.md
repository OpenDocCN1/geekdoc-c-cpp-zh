

符号转换的第一个宽字符不是符号位，或者如果符号转换的结果没有宽字符，则在结果前缀加一个空格。如果空格和标志（flags）同时出现，则忽略空格标志。

结果被转换为“备用形式”。对于 `o` 转换，当且仅当必要时会增加精度，以强制结果的第一位数字为零（如果值和精度均为 0，则打印单个 0）。对于 `x`（或 `X`）转换，非零结果将前缀加上 `0x`（或 `0X`）。对于 `a`、`E`、`e`、`F`、`G` 和 `G` 转换，浮点数转换的结果始终包含一个小数点宽字符，即使后面没有数字。（通常情况下，这些转换的结果只有在后面有数字时才会出现小数点宽字符。）对于 `g` 和 `G` 转换，不会移除结果中的末尾零。对于其他转换，其行为未定义。

对于 `d`、`i`、`o`、`u`、`x`、`A`、`a`、`E`、`e`、`F`、`g` 和 `G` 转换，在转换无穷大或 NaN 时，前导零（跟随任何符号或基数的指示之后）用于填充字段宽度，而不是执行空格填充。如果 0 和标志同时出现，则忽略 0 标志。对于 `d`、`i`、`o`、`u`、`x` 转换，如果指定了精度，则忽略 0 标志。对于其他转换，其行为未定义。

长度修及其含义为：

- hh 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于符号字符（signed char）或无符号字符（unsigned char）参数（该参数已根据整数提升进行了提升，但在打印之前其值应转换为符号字符或无符号字符）；或者指定后续的 `n` 转换符适用于指向符号字符参数的指针。
- h 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于短整数（short int）或无符号短整数（unsigned short int）参数（该参数已根据整数提升进行了提升，但在打印之前其值应转换为短整数或无符号短整数）；或者后续的 `n` 转换符适用于指向短整数参数的指针。
- (ll) 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于长整数（long int）或无符号长整数（unsigned long int）参数；且 `n` 转换符适用于指向长整数参数的指针；后续转换符适用于 `wint_t` 参数；后续转换符适用于指向 `wchar_t` 参数的指针；或者对 `a`、`A`、`e`、`E`、`f`、`F`、`g` 或 `G` 转换符没有影响。
- ll (ll-ll) 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于长整数或无符号长整数参数；或者后续的转换符适用于指向长长整数（long long int）参数的指针。
- j 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于 `intmax_t` 或 `uintmax_t` 参数；或者后续的 `n` 转换符适用于指向 `intmax_t` 参数的指针。
- z 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于 `size_t` 或对应的符号整数类型参数；或者后续转换符适用于指向与 `size_t` 参数对应的符号整数类型的指针。
- t 指定后续的 `d`、`i`、`o`、`u`、`x` 或 `X` 转换符适用于 `ptrdiff_t` 或对应的无符号整数类型参数；或者后续转换符适用于指向 `ptrdiff_t` 参数的指针。
- L 指定后续的 `a`、`A`、`e`、`E`、`f`、`F`、`g` 或 `G` 转换符对应长双 参数。

如果长度修饰符出现在上述指定的任何转换符之外，其行为未定义。

转换符及其含义为：

- d, i: `int` 参数被转换为 `[-]dddd` 风格的符号十进制。精度指定了出现的最小位数；如果转换的值可以用较少的数字表示，则用前导零进行扩展。默认精度为 1。精度为 0 时转换零值的结果没有宽字符。
- o, u, x, X: `unsigned int` 参数被转换为 `ddddd` 风格的八进制 (`o`)、无符号十进制 (`u`) 或十六进制表示法 (`x` 或 `U`)；`x` 转换使用字母 `abcdef`，`X` 转换使用字母 `ABCDEF`。精度指定了出现的最小位数；如果被转换的值可以用较少的数字表示，则用前导零进行扩展。默认精度为 1。精度为 0 时转换零值的结果没有宽字符。
- f, F: 代表浮点数的 `double` 参数转换为十进制表示法，其中小数点宽字符后的数字数等于精度指定。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则不出现小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
- e, E: 代表浮点数的 `double` 参数转换为科学计数法表示，其中小数点宽字符后的数字数等于精度指定。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则不出现小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
- g, G: 代表浮点数的 `double` 参数转换为十进制或科学计数法表示，以产生较短者为准。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则移除小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
- a, A: 代表浮点数的 `double` 参数转换为十六进制表示法，其中小数点宽字符后的数字数等于精度指定。如果缺少精度，则默认为 6；如果精度为 0 且未指定 `#` 标志，则不出现小数点宽字符。如果出现了小数点宽字符，则其前面至少有一个数字。该值将舍入到相应的位数。
