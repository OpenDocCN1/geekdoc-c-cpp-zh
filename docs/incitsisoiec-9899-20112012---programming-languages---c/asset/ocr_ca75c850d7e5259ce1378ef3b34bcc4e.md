# 7.8.2.2 The imdiv function

Synopsis

```
#include <inttypes.h>
imaxdiv_t imdiv(intmax_t numer, intmax_t denom);
```

Description

The imdiv function computes numer / denom and numer % denom in a single operation.

Returns

The imdiv function returns a structure of type imaxdiv_t comprising both the quotient and the remainder. The structure shall contain (in either order) the members quot (the quotient) and rem (the remainder), of each has type intmax_t. If either part of the result cannot be represented, the behavior is undefined.

# 7.8.2.3 The strtoumax and strtoullmax functions

Synopsis

```
#include <inttypes.h>
imax_t strtoumax(const char * restrict nptr,
char ** restrict endptr, int base);
uintmax_t strtoullmax(const char * restrict nptr,
char ** restrict endptr, int base);
```

Description

The strtoumax and strtoullmax functions are equivalent to the strtol, strtoll, strtou, and strtoull functions, except that the initial portion of the string is converted to intmax_t and uintmax_t representation, respectively.

Returns

The strtoumax and strtoullmax functions return the converted value, if any. If no conversion could be performed, zero is returned. If the correct value is outside the range of representable values, INTMAX_MAX, INTMAX_MIN, and UINTMAX_MAX is returned (according to the return type and sign of the value, if any), and the value of the ERANGE is stored in errno.

Forward references: the strtol, strtoll, strtou, and strtoull functions (7.22.1.4).
