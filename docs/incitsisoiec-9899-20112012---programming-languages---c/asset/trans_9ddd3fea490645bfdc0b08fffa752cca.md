
将 `string` 指向的字符串传递给命令处理器，并按照实现应说明的方式进行执行；这可能导致调用系统的程序产生不符合规范的行为或发生终止。

返回

如果参数为空指针，则只有在可用命令处理器时，系统函数才返回非零。如果参数不是空指针，系统函数确实会返回，它返回一个由实现定义的值。

## 7.2.25 搜索和排序工具

这些工具使用比较函数来对未指定位置的数组进行搜索或排序。当声明为 `size_t nmemb` 的参数指定数组长度时，在调用该函数时，`nmemb` 可以取零值；此时，比较函数不会被调用，搜索将找不到匹配元素，且排序将不进行任何重排。在此类调用中，指针参数仍应具有如 7.1.4 节所描述的有效值。

实现层应确保比较函数的第二个参数（当从 `bsearch` 调用时）或两个参数（当从 `qsort` 调用时）都是指向数组元素的指针。当从 `bsearch` 调用时，第一个参数应等于 `key`。

比较函数不应修改数组的内容。实现层可以在两次调用比较函数之间重新排列数组元素，但不应修改任何单个元素的内容。

当相同的对象（由 `size` 个字节组成，无论它们在数组中的当前位置）多次传递给比较函数时，其结果应该是一致的。也就是说，对于 `qsort`，它们定义了数组上的全序，而对于 `bsearch`，同一对象与 `key` 的比较结果应始终相同。

在每次调用比较函数之前和之后都会发生一个序列点，并且在任何比较函数调用与作为参数传递的对象的移动之间也会发生。

> 也就是说，如果传递的值为 `p`，则以下表达式始终为零：

```
((char*)p - (char*)base) % size == 0
(char*)p >= (char*)base
(char*)p < (char*)base + nmemb * size
```

### 7.2.5.1 bsearch 函数

### 概要

```c
#include <stdlib.h>
void *bsearch(const void *key, const void *base,
      size_t nmemb, size_t size,
      int (*compar)(const void *, const void *));
```

### 描述

`bsearch` 函数在一个包含 `nmemb` 个对象的数组（其初始元素由 `base` 指向）中搜索与 `key` 指向的对象匹配的元素。数组每个元素的大小由 `size` 指定。

由 `compare` 指向的比较函数通过两个参数调用，分别指向 `key` 对象和数组元素。如果 `key` 对象分别被认为小于、等于或大于数组元素，则函数应分别返回小于、等于或大于零的整数。数组应按以下顺序组成：所有小于 `key` 的元素、所有等于 `key` 对象的元素以及所有大于 `key` 对象的元素。

### 返回

`bsearch` 函数返回数组中匹配元素的指针，如果没有找到匹配项，则返回空指针。如果两个元素比较结果相等，则匹配哪一个元素是不指定的。

### 7.2.5.2 qsort 函数

### 概要

```c
#include <stdlib.h>
void qsort(void *base, size_t nmemb, size_t size,
      int (*compar)(const void *, const void *));
```

### 描述

`qsort` 函数对一个包含 `nmemb` 个对象的数组（其初始元素由 `base` 指向）进行排序。每个对象的大小由 `size` 指定。

数组的内容根据由 `compare` 指向的比较函数升序排序，该函数通过两个指向被比较对象的参数进行调用。如果第一个参数分别被认为小于、等于或大于第二个参数，则函数应分别返回小于、等于或大于零的整数。

> 在实践中，整个数组都根据比较函数进行排序。

如果两个元素比较结果相等，它们在结果排序数组中的顺序是不指定的。

### 返回

`qsort` 函数不返回值值。

## 7.2.6 整数算术函数

### 7.2.6.1 abs, labs 和 llabs 函数

### 概要

```c
#include <stdlib.h>
int abs(int j);
long labs(long int j);
long int llabs(long long int j);
```

`abs`、`labs` 和 `llabs` 函数计算整数 `j` 的绝对值。如果无法表示结果，则行为未定义。

### 返回

`abs`、`labs` 和 `llabs` 函数返回绝对值。

### 7.2.6.2 div, ldiv 和 ldivdiv 函数

### 概要

```c
div_t div(int numer, int denom);
lldiv_t ldiv(long int numer, long int denom);
lldiv_t ldivdiv(long long int numer, long long int denom);
```

### 描述

`div`、`ldiv` 和 `ldivdiv` 函数在单次操作中计算 `numer / denom` 和 `numer % denom`。

### 返回

`div`、`ldiv` 和 `ldivdiv` 函数分别返回类型为 `div_t`、`ldiv_t` 和 `lldiv_t` 的结构体，包含商和余数。结构体应包含商和余数。如果无法表示结果，则行为未定义。

## 7.2.7 多字节/字符转换函数

### 7.2.7.1 mlen 函数

### 概要

```c
#include <stdlib.h>
int mlen(const char *s, size_t n);
```

### 描述

如果 `s` 不是空指针，`mlen` 函数确定多字节字符中所包含的字节数。

### 返回

如果 `s` 是空指针，`mlen` 函数返回非零值或零值，取决于多字节字符编码是否具有状态依赖的编码。如果 `s` 不是空指针，`mlen` 函数返回 0（如果 `s` 指向空字符），或返回多字节字符中所包含的字节数（如果 `n` 或更少字节构成了一个有效的多字节字符），或返回 -1（如果它们没有构成有效的多字节字符）。

### 7.2.7.2 mbwtoc 函数

### 概要

```c
#include <stdlib.h>
int mbwtoc(wchar_t *pwc, const char *s, size_t n);
```

### 描述

如果 `s` 不是空指针，`mbwtoc` 函数检查从 `s` 指向的字节开始的最多 `n` 个字节，以确定完成该多字节字符所需的字节数。如果函数确定下一个多字节字符是完整且有效的，它将确定相应宽字符的值，然后如果 `pwc` 不是空指针，则将其存储在 `pwc` 指向的对象中。

### 返回

如果 `s` 是空指针，`mbwtoc` 函数返回非零值或零值，取决于多字节字符编码是否具有状态依赖的编码。如果 `s` 不是空指针，`mbwtoc` 函数返回 0（如果 `s` 指向空字符），或返回多字节字符中所包含的字节数（如果 `n` 或更少字节构成了一个有效的多字节字符），或返回 -1（如果它们没有构成有效的多字节字符）。

### 7.2.7.3 mbwtomb 函数

### 概要

```c
#include <stdlib.h>
int mbwtomb(char *s, wchar_t wc);
```

### 描述

`mbwtomb` 函数确定表示由 `wc` 给出的宽字符对应的多字节字符所需的字节数（包括任何偏移序列），并将多字节字符表示存储在由 `s` 指向第一个元素的数组中（如果 `s` 不是空指针）。如果 `wc` 是空宽字符，则存储一个空字节，在其之前存储任何以恢复初始偏移状态的偏移序列，并将函数留存在初始转换状态。
