

## W3.9.2.1.2 wscncpy_s 函数

### 概要概述

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
errno_t wscncpy_s(wchar_t * restrict s1,
rsize_t smax,
const wchar_t * restrict s2,
rsize_t n);
```

### 运行时约束

s1 和 s2 均不为空指针。smax 和 n 均不大于 RSIZE_MAX。smax 不得为零。如果 n 不小于 smax，则 s1 的长度应大于 wcsnlen(s2, smax)。不应在重叠的对象之间进行拷贝。

如果发生运行时约束违反，且 s1 不是空指针且 smax 大于零且不大于 RSIZE_MAX，则 wscncpy_s 将 s1[0] 设置为空宽字符。

### 描述

wscncpy_s 函数从 s1 指向的数组中拷贝不超过 n 个连续的宽字符（空宽字符之后的宽字符不被拷贝）。如果没有从 s2 拷贝空宽字符，则 s1[n] 被设为空宽字符。

当 wscncpy_s 返回时，s1 指向的 smax 个宽字符数组中，写入的终止空宽字符（如果有）之后的所有元素都具有未指定的值。^{444}

### 返回

如果没有发生运行时约束违反，wscncpy_s 函数返回零。否则，返回一个非零值。

示例 1 wscncpy_s 函数可以用于拷贝宽字符串，而不会产生结果未终止或宽字符写入目标数组末之外的危险。

> 444) 这允许实现在从 s2 拷贝宽字符到 s1 的同时，检查这些宽字符中是否有任何一个是空字符。这种方法在发现第一个元素应该被设置为空宽字符之前，可能会向 s1 的每个元素写入一个宽字符。

> 445) 返回值意味着从 s2 指向的字符串中请求的所有宽字符都容纳在 s1 指向的数组中，并且 s1 中的结果是已终止的。

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
/* ... */
wchar_t src1[100] = L"hello";
wchar_t src2[7] = {L'g', L'o', L'o', L'd', L'b', L'y', L'e'};
wchar_t dst1[6], dst2[5], dst3[5];
int r1, r2, r3;
r1 = wscncpy_s(dst1, 6, src1, 100);
r2 = wscncpy_s(dst2, 5, src2, 7);
r3 = wscncpy_s(dst3, 5, src2, 4);
```

第一次调用将零赋值给 r1，并给 dst1 赋值宽字符序列 \0。第二次调用将非零值赋值给 r2，并给 dst2 赋值宽字符序列 \0。第三次调用将零赋值给 r3，并给 dst3 赋值宽字符序列 good\0。

## K.3.9.2.1.3 wmemcpy_s 函数

### 概要概述

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
errno_t wmemcpy_s(wchar_t * restrict s1,
rsize_t slmax,
const wchar_t * restrict s2,
rsize_t n);
```

### 运行时约束

s1 和 s2 均不为空宽字符。slmax 和 n 均不大于 RSIZE_MAX。n 不大于 slmax。不应在重叠的对象之间进行拷贝。

如果发生运行时约束违反，且 s1 不是空指针且 slmax 不大于 RSIZE_MAX，则 wmemcpy_s 函数在 s1 指向的对象的前 slmax 个宽字符中存储零。

### 描述

wmemcpy_s 函数从 s2 指向的对象中拷贝 n 个连续的宽字符到 s1 指向的对象中。

### 返回

如果没有发生运行时约束违反，wmemcpy_s 函数返回零。否则，返回一个非零值。

## K.3.9.2.1.4 wmemmmove_s 函数

### 概要概述

```c
#define __STDC_WANT_LIB_EXT1__
#include <wchar.h>
errno_t wmemmmove_s(wchar_t *s1, rsize_t slmax,
               const wchar_t *s2, rsize_t n);
```

### 运行时约束

s1 和 s2 均不为空指针。slmax 和 n 均不大于 RSIZE_MAX；n 大于 slmax。

如果发生运行时约束违反，且 s1 不是空指针且 slmax 不大于 RSIZE_MAX，wmemmmove_s 函数将 s1 指向的对象的前 slmax 个宽字符置零。

### 描述

wmemmmove_s 函数从 s2 指向的对象中拷贝 n 个连续的宽字符到 s1 指向的对象。这种拷贝方式是先将从 s2 指向的对象的 n 个宽字符拷贝到一个临时宽字符数组中，然后将这 n 个字符拷贝到 s1 指向的对象中。

### 返回

如果没有发生运行时约束违反，wmemmmove_s 函数返回零。否则，返回一个非零值。

## K.3.9.2.2 宽字符串拼接

### K.3.9.2.2.1 wcscat_s 函数

### 概要概述

```c
#define __STDC_WANT_LIB_EXT1__
#include <wchar.h>
errno_t wcscat_s(wchar_t * restrict s1,
               rsize_t slmax,
               const wchar_t * restrict s2);
```

### 运行时约束

进入 wcscat_s 时，m 表示 slmax - wcslen_s(s1, slmax)。

s1 和 s2 均不为空指针。slmax 不大于 RSIZE_MAX；slmax 不为零。m 必须大于 wcslen_s(s2, m)。不应在重叠的对象之间进行拷贝。

如果发生运行时约束违反，且 s1 不是指针且 slmax 大于零且不大于 RSIZE_MAX，wcscat_s 将 s1[0] 设置为宽字符。

### 描述

wcscat_s 函数将 s2 指向的宽字符串（包括终止宽字符）的拷贝追加到 s1 指向的字符串末尾。s2 的起始宽字符覆盖 s1 末尾的空宽字符。

当 wcscat_s 返回时，s1 指向的 slmax 个宽字符数组中，写入的终止宽字符（如果有）之后的所有元素都具有未定义的值。^{447}

### 返回

如果没有发生运行时约束违反，wcscat_s 返回零。否则，返回一个非零值。

## K.3.9.2.2.2 wcscat_s 函数（带 n 参数）

### 概要概述

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
errno_t wcscat_s(wchar_t * restrict s1,
               rsize_t slmax,
               const wchar_t * restrict s2,
               rsize_t *n);
```

### 运行时约束

进入 wcscat_s 时，m 表示 slmax - wcslen_s(s1, slmax)。

s1 和 s2 均不为空指针。slmax 和 n 均不大于 RSIZE_MAX。m 不为零。^{449} 如果 n 不小于 m，则 m 大于 wcslen_s(s2, m)。不应在重叠的对象之间拷贝。

> 446) 零表示进入 wcscat_s 时 s1 未终止。

> 447) 这允许实现在从 s2 追加宽字符到 s1 的同时，检查这些字符中是否有任何一个是空字符。这种方法在发现第一个元素应该被设置为空宽字符之前，可能会向 s1 的每个元素写入一个宽字符。

> 448) 返回值意味着从 s2 指向的宽字符串的所有字符都追加到了 s1 指向的字符串中，并且 s1 中的结果未终止。

> 449) 零表示进入 wcscat_s 时 s1 未空终止。

如果发生运行时约束违反，且 s1 不是空指针且 slmax 大于零且不大于 SIZE_MAX，wcscat_s 将 s1[0] 设置为宽字符。

### 描述

wcscat_s 函数从 s2 指向的数组中追加 n 个连续的宽字符（空宽字符之后的字符不被拷贝）到 s1 指向的字符串末尾。s2 的起始宽字符覆盖 s1 末尾的空宽字符。如果没有从 s2 拷贝空字符，则 s1[slmax-m+n] 被设为空宽字符。

当 wcscat_s 返回时，s1 指向的 slmax 个宽字符数组中，写入的终止空字符（如果有）之后的所有元素具有未指定的值。^{450}

### 返回

如果没有发生运行时约束违反，wcscat_s 函数返回零。否则，返回一个非零值。

示例 1 wcscat_s 函数可以用于拷贝宽字符串，而不会产生结果未终止或字符写入目标数组之外的危险。

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
/* ... */
wchar_t s1[100] = L"good";
wchar_t s2[6] = L"hello";
wchar_t s3[6] = L"Hello";
wchar_t s4[7] = L"abc";
wchar_t s5[1000] = L"bye";
int r1, r2, r3, r4;
r1 = wcscat_s(s1, 100, s5, 1000);
r2 = wcscat_s(s2, 6, L"L", 1);
r3 = wcscat_s(s3, 6, L"X", 2);
r4 = wcscat_s(s4, 7, L"defghijklmn", 3);
```

第一次调用 r1 的值为零，s1 将变为宽字符 goodbye\0。第二次调用 r2 的值为零，s2 将变为宽字符 hello\0。第三次调用 r3 的值为非零，s3 将变为宽字符序列 \0。第四次调用 r4 的值为零，s4 将变为宽字符 abcdef\0。

> 451) 返回值意味着从 s2 指向的宽字符串请求的所有字符都追加到了 s1 指向的宽字符串中，并且 s1 中的结果是空终止的。
