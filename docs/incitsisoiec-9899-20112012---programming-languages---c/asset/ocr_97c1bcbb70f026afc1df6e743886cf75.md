# 7.21 Input/output <stdio.h>

# 7.21.1 Introduction

The header <stdio.h> defines several macros, and declares three types and many functions for performing input and output.

The types declared are size_t (described in 7.19);

FILE

which is an object type capable of recording all the information needed to control a stream, including its file position indicator, a pointer to its associated buffer (if any), an error indicator records whether a read/write error has occurred, and an end-of-file indicator records whether the end of the file has been reached; and

fpos_t

which is a complete object other than an array type capable of recording all the information needed to specify uniquely every position within a file.

The macros are NULL (described in 7.19);

BUFSIZ

EOF

FOPEN_MAX
