
## W3.9.2.1.2 The wscncpy_s function

### Synopsis

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
errno_t wscncpy_s(wchar_t * restrict s1,
rsize_t smax,
const wchar_t * restrict s2,
rsize_t n);
```

### Runtime-constraints

Neither s1 nor s2 shall be a null pointer. Neither smax nor n shall be greater than RSIZE_MAX. smax shall not equal zero. If n is not less than smax, then s1 shall be greater than wcsnlen(s2, smax). Copying shall not take place between objects that overlap.

If there is a runtime-constraint violation, if s1 is not a null pointer and smax is greater than zero and not greater than RSIZE_MAX, then wscncpy_s sets s1[0] to the null wide character.

### Description

The wscncpy_s function copies not more than n successive wide characters (wide characters that follow a null wide character are not copied) from the array pointed to by s1. If no null wide character was copied from s2, then s1[n] is set to a null wide character.

All elements following the terminating null wide character (if any) written by wscncpy_s in the array of smax wide characters pointed to by s1 take unspecified values when wscncpy_s returns.^{444}

### Returns

The wscncpy_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

EXAMPLE 1 The wscncpy_s function can be used to copy a wide string without the danger that the result will not be terminated or that wide characters will be written past the end of the destination array.

> 444) This allows an implementation to copy wide characters from s2 to s1 while simultaneously checking if any of those wide characters are null. Such an approach might write a wide character to every element of s1 before discovering the first element should be set to the null wide character.

> 445) A return value implies that all of the requested wide characters from the string pointed to by s2 fit within the array pointed to by s1 and that the result in s1 is terminated.

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
/* ... */
wchar_t src1[100] = L"hello";
wchar_t src2[7] = {L'g', L'o', L'o', L'd', L'b', L'y', L'e'};
wchar_t dst1[6], dst2[5], dst3[5];
int r1, r2, r3;
r1 = wscncpy_s(dst1, 6, src1, 100);
r2 = wscncpy_s(dst2, 5, src2, 7);
r3 = wscncpy_s(dst3, 5, src2, 4);
```

The first call will assign to r1 the value zero and to dst1 the sequence of wide characters \0. The second call will assign to r2 a nonzero value and to dst2 the sequence of wide characters \0. The third call will assign to r3 the value zero and to dst3 the sequence of wide characters good\0.

## K.3.9.2.1.3 The wmemcpy_s function

### Synopsis

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
errno_t wmemcpy_s(wchar_t * restrict s1,
rsize_t slmax,
const wchar_t * restrict s2,
rsize_t n);
```

### Runtime-constraints

Neither s1 nor s2 shall be a null of wide characters. Neither slmax nor n shall be greater than RSIZE_MAX. n shall not be greater than slmax. Copying shall not take place between objects that overlap.

If there is a runtime-constraint violation, the wmemcpy_s function stores zeros in the first slmax wide characters of the object pointed to by s1 if s1 is not a null pointer and slmax is not greater than RSIZE_MAX.

### Description

The wmemcpy_s function copies n successive wide characters from the object pointed to by s2 into the object pointed to by s1.

### Returns

The wmemcpy_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

## K.3.9.2.1.4 The wmemmmove_s function

### Synopsis

```c
#define __STDC_WANT_LIB_EXT1__
#include <wchar.h>
errno_t wmemmmove_s(wchar_t *s1, rsize_t slmax,
               const wchar_t *s2, rsize_t n);
```

### Runtime-constraints

Neither s1 nor s2 shall be a null pointer. Neither slmax nor n shall be greater than RSIZE_MAX; n shall be greater than slmax.

If there is a runtime-constraint violation, the wmemmmove_s function zeros the first slmax wide characters of the object pointed to by s1 if s1 is not a null pointer and slmax is not greater than RSIZE_MAX.

### Description

the wmemmmove_s function copies n successive wide characters from the object pointed to by s2 into the object pointed to by s1. This copying takes place as if the n wide characters from the object pointed to by s2 are first copied into a temporary array of n wide characters, and then the n characters are copied into the object pointed to by s1.

### Returns

the wmemmmove_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

## K.3.9.2.2 Wide string concatenation

### K.3.9.2.2.1 The wcscat_s function

### Synopsis

```c
#define __STDC_WANT_LIB_EXT1__
#include <wchar.h>
errno_t wcscat_s(wchar_t * restrict s1,
               rsize_t slmax,
               const wchar_t * restrict s2);
```

### Runtime-constraints

Let m denote the value slmax - wcslen_s(s1, slmax) upon entry to wcscat_s.

Neither s1 nor s2 shall be a null pointer. slmax shall not be greater than RSIZE_MAX; slmax shall not equal zero. m must be greater than wcslen_s(s2, m). Copying shall not take place between objects that overlap.

If there is a runtime-constraint violation, if s1 is not a pointer and slmax is greater than zero and not greater than RSIZE_MAX, then wcscat_s s1[0] to the null wide character.

### Description

The wcscat_s function appends a copy of the wide string pointed to by s2 (including the terminating wide character) to the end of the string pointed to by s1. The initial wide character from s2 overwrites the null wide character at the end of s1.

All elements following the terminating wide character (if any) written by wcscat_s in the array of slmax wide characters pointed to by s1 take undefined values when wcscat_s returns.^{447}

### Returns

The wcscat_s function returns zero if there is no runtime-constraint violation. Otherwise, a nonzero value is returned.

## K.3.9.2.2.2 The wcscat_s function (with n)

### Synopsis

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
errno_t wcscat_s(wchar_t * restrict s1,
               rsize_t slmax,
               const wchar_t * restrict s2,
               rsize_t *n);
```

### Runtime-constraints

Let m denote the value slmax - wcsnlen_s(s1, slmax) upon entry to wcscat_s.

Neither s1 nor s2 shall be a null pointer. Neither slmax nor n shall be greater than RSIZE_MAX. m shall not equal zero.^{449} If n is not less than m, then m shall be greater than wcsnlen_s(s2, m). Copying shall not place between objects that overlap.

> 446) Zero means that s1 was not terminated upon entry to wcscat_s.

> 447) This allows an implementation to append wide characters from s2 to s1 while simultaneously checking if any of those characters are null. Such an approach might write a wide character to every element of s1 before discovering that the first element should be set to the null wide character.

> 448) A return value implies that all of the required characters from the wide string pointed to by s2 were appended to the wide string pointed to by s1 and the result in s1 is not terminated.

> 449) Zero means that s1 was not null terminated upon entry to wcscat_s.

If there is a runtime-constraint violation, then if s1 is not a null pointer and slmax is greater than zero and not greater than SIZE_MAX, then wcscat_s s1[0] to the null wide character.

### Description

The wcscat_s function appends not n successive wide characters (which characters follow a null wide character are not copied) from the array pointed to by s2 to the end of the string pointed to by s1. The initial wide character from s2 overwrites the null wide character at the end of s1. If no null character was copied from s2, then s1[slmax-m+n] is set to a null wide character.

All elements following the terminating null character (if any) written by wcscat_s in the array of slmax wide characters pointed to by s1 take unspecified values when wcscat_s returns.^{450}

### Returns

The wcscat_s function returns zero if there was no runtime runtime-constraint violation. Otherwise, a nonzero value is returned.

EXAMPLE 1 The wcscat_s function can be used to copy a wide string without the danger that the result will not be terminated or that characters will be written past the end of the destination array.

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
/* ... */
wchar_t s1[100] = "good";
wchar_t s2[6] = "hello";
wchar_t s3[6] = "Hello";
wchar_t s4[7] = "abc";
wchar_t s5[1000] = "bye"
int r1, r2, r3, r4;
r1 = wcscat_s(s1, 100, s5, 1000);
r2 = wcscat_s(s2, 6, "L", 1);
r3 = wcscat_s(s3, 6, "X", 2);
r4 = wcscat_s(s4, 7, "defghijklmn", 3);
```

After the first call r1 will have the value zero and s1 will be the wide character goodbye\0. After the second call r2 will have the value zero and s2 will be the wide character hello\0. After the third call r3 will have a nonzero value and s3 will be the wide character sequence \0. After the fourth call r4 will have the value zero and s4 will be the wide character abcdef\0.

> 451) A return value implies that all of the requested characters from the wide string pointed to by s2 were appended to the wide string pointed to by s1 and the result in s1 is null terminated.
