# K.3.7.1.2 The memmove_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t memmove_s(void *s1, size_t smax,
const void *s2, size_t n);
```

Runtime-constraints

+   Neither s1 shall be a null pointer. Neither smax nor n shall be greater than RSIZE_MAX. n shall not be greater than smax.

+   If there is a runtime-constraint violation, the memmove_s function stores zeros in the first smax characters of the object pointed to by s1 if s1 is not a null pointer and smax is not greater than RSIZE_MAX.

Description

+   The memmove_s function copies n characters from the object pointed to by s2 into the object pointed to by s1. This copying takes place as if the n characters from the object pointed to by s2 are first copied into a temporary array of n characters that does not overlap the objects pointed to by s1 or s2, and then the n characters from the temporary array are copied into the object pointed to by s1.

Returns

+   The memmove_s function returns 0 if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

# K.3.7.1.3 The strcpy_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strcpy_s(char * restrict s1,
size_t smax,
const char * restrict s2);
```

Runtime-constraints

+   Neither s1 nor s2 shall be a null pointer. smax shall not be greater than RSIZE_MAX. smax shall not be equal zero. smax shall be greater than strnlen(s2, smax). Copying shall not take place between objects that overlap.

+   If there is a runtime-constraint violation, if s1 is not a null pointer and smax is greater than zero and not greater than RSIZE_MAX, then strcpy_s sets s1[0] to the null character.
