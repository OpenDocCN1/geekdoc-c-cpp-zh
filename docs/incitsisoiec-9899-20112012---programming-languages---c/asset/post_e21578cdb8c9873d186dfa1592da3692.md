## 7.3 Complex arithmetic <complex.h>

### 7.3.1 Introduction

The header <complex.h> defines macros and declares functions that support complex arithmetic.¹192)

Implementations that define the macro __STDC_NO_COMPLEX__ need not provide this header nor support any of its facilities.

Each synopsis specifies a family of functions consisting of a principal function with one or more double complex parameters and a double complex or double return value; and other functions with the same name but with f and l suffixes are corresponding functions with float and long double parameters and return values.

The macro

```
complex
```
expands to _Complex; the macro

```
_Complex_I
```
expands to a constant expression of type const float _Complex, with the value of the imaginary unit.¹193)

The macros

```
imaginary
```

and

```
_Imaginary_I
```
are defined if and only if the implementation supports imaginary types;¹194 if defined, they expand to _Imaginary and a constant expression of type float _Imaginary with the value of the imaginary unit.

The macro

```
I
```
expands to either _Imaginary_I or _Complex_I. If _Imaginary_I is not defined, I shall expand to _Complex_I.

Notwithstanding the provisions of 7.1.3, a program may undefined and perhaps redefine the macros complex, imaginary, and I.

## 7.3.2 Conventions

Values are interpreted as radians, not degrees. An implementation may set errno but not required to.

## 7.3.3 Branch cuts

Some of the functions have branch cuts, across which the function is discontinuous. For implementations with a signed zero (including all IEC 60559 implementations) that follow the specifications of annex G, the sign of zero distinguishes one side of a cut from another so the function is continuous (except for format limitations) as the cut is approached from either side. For example, for the square root function, which has a cut along the negative real axis, the top of the cut, with imaginary part +0, maps to the positive imaginary axis, and the bottom of the cut, with imaginary part -0, maps to the negative imaginary axis.

Implementations do not support a signed zero (annex F) cannot distinguish the sides of branch cuts. These implementations shall map a cut so the function is continuous as the cut is approached coming around the finite endpoint of the cut in a counter clockwise direction. (Branch cuts for the functions specified here have just one endpoint.) For the square root function, coming counter clockwise around the finite endpoint of the cut along the negative real axis approaches the cut from above, so the cut map to the positive imaginary axis.

## 7.3.4 The CX_LIMITED_RANGE pragma

Synopsis

```
#include <complex.h>
#pragma STDC CX_LIMITED_RANGE on-off-switch
```

Description

The usual mathematical formulas for complex multiply, divide, and absolute value are problematic because of their treatment of infinities and undue overflow and underflow. The CX_LIMITED_RANGE pragma can be used to inform the implementation (where the state is “on”) the usual mathematical formulas are acceptable. The pragma can occur either external or preceding all explicit declarations inside a compound statement. When external declarations, the pragma takes effect from its occurrence until another CX_LIMITED_RANGE pragma is encountered, or until the end of the translation unit. Inside a compound statement, the pragma takes effect from its occurrence until another CX_LIMITED_RANGE pragma is encountered (including within a nested compound statement), or until the end of the compound statement; the state for the pragma is restored to its condition just before. If this pragma is used in any other context, the behavior is undefined. The default state for the pragma is “off”.

## 7.3.5 Trigonometric functions

### 7.3.5.1 The cacos functions

Synopsis

```
#include <complex.h>
double complex cacos(double complex z);
float complex acos(float complex z);
long double complex acacos(long double complex z);
```

Description

The cacos functions compute the complex arc cosine of z, with branch cuts outside the interval [-1, +1] along the real axis.

Returns

The cacos functions return the complex arc cosine value, in the range of a strip mathematically unbounded along the imaginary axis and in the interval [0, π] along the real axis.

### 7.3.5.2 The casin functions

Synopsis

```

float complex casinf(float complex z);
long double casinl(long double complex z);
```

Description

The casin functions compute the complex arc sine of z, with branch cuts outside the interval [-1, +1] along the real axis.

The casin functions return the complex arc sine value, in the range of a strip mathematically unbounded along the imaginary axis and in the interval [-π/2, +π/2] along the real axis. 195) The purpose of the pragma is to allow the implementation to use formulas where the programmer can determine they are safe.

## 7.3.6 Hyperbolic functions

### 7.3.6.1 The cacosh functions

Synopsis

```
#include <complex.h>
double complex cacosh(double complex z);
float complex cacoshf(float complex z);
long double cacoshl(long double complex z);
```

Description

The cacosh functions compute the complex hyperbolic cosine of z, with a branch cut at values less than 1 along the real axis.

Returns

The cacosh functions return the complex arc hyperbolic cosine value, in the range of a half-strip of nonnegative values along the real axis and in the interval [-iπ,+iπ] along the imaginary axis.
