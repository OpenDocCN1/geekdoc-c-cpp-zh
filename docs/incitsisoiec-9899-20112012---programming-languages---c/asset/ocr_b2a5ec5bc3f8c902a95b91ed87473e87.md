# Returns

The fprintf function returns the number of wide characters transmitted, or a negative value if an output or encoding error occurred.

# Environmental limits

The number of wide characters that can be produced by any single conversion shall be at least 4095.

# 7.29.2.2 The fcanf function

# Synopsis

```
#include <stdio.h>
#include <wchar.h>
int fcanf(FILE * restrict stream,
const wchar_t * restrict format, ...);
```

The fcanf function reads input from the stream pointed to by stream, under control of the wide string pointed to by format that specifies the admissible input sequences and how they are to be converted for assignment, using subsequent arguments

For binary-to-decimal conversion, the result format's values are representable with the given format specifier. The number of significant digits is determined by the format specifier, and in the case of fixed-point conversion by the source value as well.
