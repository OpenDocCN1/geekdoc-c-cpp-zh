

## 7.29.6.4.1 mbsrtowcs 函数

### 摘要

```
#include <wchar.h>
size_t mbsrtowcs(wchar_t * restrict dst,
               const char ** restrict src,
size_t len,
mbstate_t * restrict ps);
```

### 描述

mbsrtowcs 函数将由 `src` 间接指向的数组中的多字节字符序列（从 `ps` 指向的对象所描述的转换状态开始）转换为相应的宽字符序列。如果 `dst` 不是空指针，则转换后的字符将存储在 `dst` 指向的数组中。转换将持续到包含终止空字符，该空字符也会被存储。在以下两种情况下，转换会提前停止：遇到无法构成有效多字节字符的字节序列，或者（如果 `dst` 不是空指针）已经将 `len` 个字符存储到 `dst` 指向的数组中。3350 每次转换的发生都如同调用了 `mbrtowc` 函数。

如果 `dst` 不是空指针，则 `src` 指向的指针对象将被赋值为空指针（如果转换是因为达到长度限制而停止）或最后一个转换的多字节字符之后的下一个地址（如果有的话）。如果转换是因为遇到终止空字符而停止，且 `dst` 不是空指针，则描述的最终状态为初始转换状态。

### 返回

如果输入转换遇到无法构成有效多字节字符的字节序列，则会发生编码错误：mbsrtowcs 函数将宏 `EILSEQ` 的值存入 `errno` 并返回 `(size_t) (-1)`；转换状态未定义。否则，它返回成功转换的多字节字符数，不包括终止空字符（如果有）。

> 350) 因此，如果 `dst` 是空指针，则 `len` 的值被忽略。

## 7.29.6.4.2 wcsrtombs 函数

### 摘要

```
#include <wchar.h>
size_t wcsrtombs(char * restrict dst,
               const wchar_t ** restrict src,
               size_t len,
               mbstate_t * restrict ps);
```

### 描述

wcsrtombs 函数将由 `src` 间接指向的数组中的宽字符序列转换为相应的多字节字符序列（从 `ps` 指向的对象所描述的转换状态开始）。如果 `dst` 不是空指针，则转换后的字符将存储在 `dst` 指向的数组中。转换将持续到包含终止空宽字符，该字符也会被存储。在以下两种情况下，转换会提前停止：遇到不对应有效多字节字符的宽字符，或者（如果 `dst` 不是空指针）下一个多字节字符将超过存储在 `dst` 指向数组中的 `len` 字节限制。 每次转换的发生都如同调用了 `wctombs` 函数。^351)

如果 `dst` 不是空指针，则 `src` 指向的指针对象将被赋值为空指针（如果转换是因为遇到终止空宽字符而停止）或最后一个转换的宽字符之后的下一个地址（如果有）。如果转换是因为遇到终止空宽字符而停止，则描述的最终状态为初始转换状态。

### 返回

如果转换因为遇到不对应有效多字节字符的宽字符而停止，则会发生编码错误：wcsrtombs 函数将宏 `EILSEQ` 的值存入 `errno` 并返回 `(size_t)(-1)`；转换状态未定义。否则，它返回生成的多字节字符序列的字节数，不包括终止空字符（如果有）。

> 351) 如果转换是因为遇到终止空宽字符而停止，则存储的字节包括为了到达空字节之前立即进入初始移位状态所需的字节。

## 7.30 宽字符分类与映射工具 <wctype.h>

### 7.30.1 引言

头文件 `<wctype.h>` 定义了一个宏，并声明了三种数据类型和许多函数。(352)

声明的类型有：

```
wint_t
```
在 7.29.1 中描述；

```
wctrans_t
```
这是一种标量类型，可以持有表示特定区域字符映射的值；

```
wctype_t
```
这是一种标量类型，可以持有表示特定区域字符分类的值。

定义的宏是 `WEOF`（在 7.29.1 中描述）。

声明的函数分组如下：

- 提供宽字符分类测试的函数；
- 提供宽字符大小分类的可扩展函数；
- 提供宽字符大小映射的函数；
- 提供宽字符映射的可扩展函数。

对于在本子节描述的所有接受 `wint_t` 类型参数的函数，该值应是可表示为 `wchar_t` 或等于宏 `WEOF` 的值。如果该参数具有任何其他值，则行为未定义。

这些函数的行为受当前区域设置 `LC_CTYPE` 类别的影响。

> 352) 参见“未来库方向”（7.31.17)。

## 7.30.2.2 iswalpha 函数

### 摘要

```
#include <wctype.h>
int iswalpha(wint_t wc);
```

### 描述

`iswalpha` 函数测试任何 `iswupper` 或 `islower` 为真的宽字符，或属于特定区域字母字符集的任何宽字符

> 353) 例如，如果表达式 `isalpha (wctob (wc))` 结果为真，则调用 `iswalpha (wc)` 也返回真。但，如果表达式 `isgraph (wctob (wc))` 结果为真（对于 `wc == L'` 则不可能发生），则 `isgraph (wc)` 或 `isprint (wc)` 为真，但不同时为真。

`iswctrl`、`iswdigit`、`iswpunct` 或 `isspace` 为真的宽字符。354

## 7.30.2.1.3 iswblank 函数

### 摘要

```
#include <ctype.h>
int iswblank(w_t wc);
```

### 描述

`iswblank` 函数测试任何标准宽字符，或 `isspace` 为真且用于分割行内单词的特定区域宽字符。标准宽空白包括：空格（L ' ）和水平制表符（L\t）。在 "C" 区域设置下，`iswblank` 只对标准空白字符返回真。
