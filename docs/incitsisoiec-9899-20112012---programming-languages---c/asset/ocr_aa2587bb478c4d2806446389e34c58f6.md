For each unspecified function in <complex.h> that is not a c-prefixed counterpart to a function in <math.h>, the corresponding type-generic macro has the same name as the function. These type-generic macros are:

```
carg conj creal
cimag cproj
```

Use of the macro with any real or complex argument invokes a complex function.

EXAMPLE With the declarations

```
#include <tgmath.h>
int n;
float f;
double d;
long double ld;
float complex fc;
double complex dc;
long double complex ldc;
```

functions invoked by use of type-generic macros are shown in the following table:

| macro use | invokes |
|---|---|
| exp(n) | exp(n), the function |
| acosh(f) | acosh(f) |
| sin(d) | sin(d), the function |
| atan(ld) | atanl(ld) |
| log(fc) | clogf(fc) |
| sqrt(dc) | csqrt(dc) |
| pow(ldc, f) | cpowl(ldc, f) |
| remainder(n, n) | remainder(n, n), the function |
| nextafter(d, f) | nextafter(d, f), the function |
| nexttoward(f, ldc) | nexttoward(f, ldc) |
| copysign(n, ldc) | copysign(n, ldc) |
| ceil(fc) | undefined behavior |
| rint(dc) | undefined behavior |
| fmax(ldc, ldc) | undefined behavior |
| carg(n) | carg(n), the function |
| cproj(f) | cproj(f) |
| creal(d) | creal(d), the function |
| cimag(ld) | cimag(ld) |
| fabs(fc) | fabs(fc) |
| carg(dc) | carg(dc), the function |
| cproj(ldc) | cproj(ldc) |
