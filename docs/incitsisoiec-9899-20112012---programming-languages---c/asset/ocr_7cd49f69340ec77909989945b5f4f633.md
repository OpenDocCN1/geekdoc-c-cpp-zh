# 72.61.12 The vsprintf function

Synopsis

```
#include <stdarg.h>
#include <stdio.h>
int vsprintf(char * restrict s, size_t n,
    const char * restrict format,
    va_list arg);
```

Description

The vsprintf function is equivalent to sprintf, with the variable argument list replaced by arg, which shall have been initialized by the va_start macro (possibly subsequent va_arg calls). The vsprintf function does not invoke the va_end macro. If copying takes place between objects that overlap, the behavior is undefined.

Returns

The vsprintf function returns the number of characters that would have been written had n sufficiently large, not counting the terminating null character, or a negative value if an encoding error occurred. Thus, the null-terminated output has been completely written if and only if the returned value is nonnegative and less than n.
