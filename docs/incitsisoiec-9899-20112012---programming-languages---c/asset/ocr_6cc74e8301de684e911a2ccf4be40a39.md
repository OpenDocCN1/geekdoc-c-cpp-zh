# Returns

The **iswtype** function returns nonzero (true) if and only if the value of the wide character **wc** has the property described by **desc**. If **desc** is zero, the **iswtype** function returns zero (false).

Forward references: the **wctype** function (7.30.2.2.2).

# 7.30.2.2.2 The wctype function

# Synopsis

```
#include <wctype.h>
wctype_t wctype(const char *property);
```

# Description

The **wctype** function constructs a value with type **wctype_t** that describes a class of wide characters identified by the string argument **property**.

The strings listed in the description of the **iswtype** function shall be valid in all locales as **property** arguments to the **wctype** function.

# Returns

If **property** identifies a valid class of wide characters according to the **LC_CTYPE** category of the current locale, the **wctype** function returns a nonzero value that is valid as the second argument to the **iswtype** function; otherwise, it returns zero.
