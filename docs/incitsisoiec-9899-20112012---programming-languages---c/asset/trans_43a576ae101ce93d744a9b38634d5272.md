## 6.4.4.4 字符常量

### 语法

```
character-constant:
    ' c-char-sequence '
    'L c-char-sequence '
    'u c-char-sequence '
    'U c-char-sequence '
```

```
c-char-sequence:
    c-char
    c-char-sequence c-char
```

```
c-char:
    源字符集中的任何成员，但
    单引号 '、反斜杠 \ 或换行字符
    转义序列
```

```
escape-sequence:
    simple-escape-sequence
    octal-escape-sequence
    hexadecimal-escape-sequence
    universal-character-name
```

```
simple-escape-sequence: 以下之一
    \' \? \\
    \a \b \e \n \r \v
```

```
octal-escape-sequence:
    \octal-digit
    \octal-digit octal-digit
    \octal-digit octal-digit octal-digit
```

```
hexadecimal-escape-sequence: \x hexadecimal-digit
hexadecimal-escape-sequence hexadecimal-digit
```

### 描述

整数常量是包含在单引号中的一个或多个多字节字符的序列，例如 `'\x'`。宽字符常量与之相同，但前缀带有字母 L、u 或 U。除了稍后详细说明的少数例外情况外，该序列的元素是源字符集中的任何成员；它们以实现定义的方式映射到执行字符集的成员。

根据下表转义序列表，单引号 '、双引号 "、问号 ?、反斜杠 \ 以及任意整数值都是可表示的：

- 单引号 ' \'
- 双引号 " \"
- 问号 ? \?
- 反斜杠 \\
- 八进制字符 \octal digits
- 十进制字符 \x hexadecimal digits

双引号 " 和问号 ? 既可以用自身表示，也可以通过转义序列 " 和 ? 分别表示，但单引号 ' 和反斜杠 \ 应分别用转义序列 \' 和 '\' 表示。

在八进制转义序列中，反斜杠后面的八进制数字被视为整数常量的单个字符或宽字符常量的单个宽字符的构造部分。所构成的八进制整数的数值值指定了所需字符或宽字符的值。

在十六进制转义序列中，跟随反斜杠和字母 x 后面的十六进制数字被视为整数字符常量的单个字符或宽字符常量的单个宽字符的构造部分。所构成的十六进制整数的数值值指定了所需字符或宽字符的值。

每个八进制或十六进制转义序列都是构成转义序列的最长字符序列。

此外，不在基本字符集中的字符可以通过通用字符名称表示，某些非图形字符可以通过由反斜杠 \ 后跟小写字母组成的转义序列表示：\a、\b、\f、\n、\r、\t 和 \v。（77）

### 约束

八进制或十六进制转义序列的值应在对应类型的可表示值范围内：

| 前缀 | 对应类型 |
|---|---|
| 无 | unsigned char |
| L | 与 char_t 对应的无符号类型 |
| u | char16_t |
| U | char32_t |

### 语义

整数字符常量的类型为 `int`。包含映射到单字节字符的单个字符的整数字符常量的值，是将映射字符的表示解释为整数时的数值值。包含多个字符（例如 `'\ab\'`）或包含未映射到单字节执行字符的字符或转义序列的整数字符常量的值是由实现定义的。如果整数字符常量包含单个字符或转义序列，其值是将类型为 `char` 且值为该单个字符或转义序列的对象转换为 `int` 时产生的值。

前缀为 L 的宽字符常量类型为 `char_t`，这是在 `<stddef.h>` 头文件中定义的整数类型；前缀为 u 或 U 的宽字符常量类型分别为 `char16_t` 或 `char32_t`，这些是在 `<uchar.h>` 头文件中定义的无符号整数类型。包含一个映射到扩展执行字符集单个成员的多字节字符的宽字符常量的值，是与该多字节字符对应的宽字符，根据其类型由 `mbtowc`、`mbrtoc16` 或 `mbrtoc32` 定义，并具有实现定义的当前区域。包含多个多字节字符或映射到扩展执行字符集多个成员的单个多字节字符，或包含在扩展执行字符集中未表示的多字节字符或转义序列的宽字符常量的值是由实现定义的。

示例 1 `'\0'` 的构造通常用于表示空字符。

示例 2 考虑使用补码表示整数并对类型为 `char` 的对象使用8位的实现。在类型 `char` 的取值范围与 `signed char` 相同的实现中，整数常量 `'\xff'` 的值为 -1；如果类型 `char` 的取值范围与 `unsigned char` 相同，则字符常量 `'\xff'` 的值为 +255。

十六进制转义序列中跟随反斜杠的十六进制数字被视为整数字符常量的单个字符或宽字符常量的单个宽字符的构造部分。所构成的十六进制整数的数值值指定了所需字符或宽字符的值。

每个八进制或十六进制转义序列都是构成转义序列的最长字符序列。

此外，不在基本字符集中的字符可以通过通用字符名称表示，某些非图形字符可以通过由反斜杠 \ 后跟小写字母组成的转义序列表示：\a、\b、\f、\n、\r、\t 和 \v。（77）

## 6.4.5 字符串字量

### 语法

```
string-literal:
  encoding-prefix_opt s-char-sequence_opt
encoding-prefix:
    u8
    u
    U
    L
s-char-sequence:
    s-char
s-char:
    源字符集中的任何成员，但
    双引号 " 或换行字符
```

### 约束

相邻的字符串字量不包含宽字符串字量。

### 描述

字符字量是包含在双引号中的一个或多个多字节字符的序列，例如 `"xyz"`。UTF-8 字符串字量与之相同，但带有前缀 u8。宽字量与之相同，但带有字母 L。

### 语义

在翻译阶段 6 中，相邻的多字节字符序列和相同前缀的字符串字量合并为一个多字节序列。如果标记中任何一个具有编码前缀，则生成的多字节序列被视为具有相同的前缀；否则，被视为字符字量。不同前缀的宽字符串字量可以合并，如果可以，则生成的多字节序列的处理是由实现定义的。

在翻译阶段 7 中，每个由字符串字量生成的多字节序列后追加一个值为零的字节或代码。该多字节序列随后用于初始化具有静态长度的数组。对于字符字量，数组元素用多字节序列的各个字节初始化。对于 UTF-8 字符串字量，数组元素类型为 `char`，并用 UTF-8 编码的多字节序列字符初始化。对于前缀为 L 的宽字量，数组元素类型为 `wchar_t`，并用对应多字节序列的宽字符序列初始化，根据实现定义的区域由 `mbtowcs` 函数定义。对于前缀为 u 或 U 的宽字符串字量，其数组元素类型分别为 `char16_t` 或 `char32_t`，并用对应多字节序列的宽字符序列初始化，根据其类型由连续调用 `mbrftoc16` 或 `mbrftoc32` 函数定义，并具有实现定义的区域。

示例 1 这对相邻的字符字量

```
"\x12" "3"
```

产生一个包含值为 `'\x12'` 和 `'3'` 的字符的单个字符字量，因为转义序列在相邻字符串字量合并之前会被转换为执行字符集的单个成员。

78) 字符串字量不需要是字符串（见 7.1.1），因为可以通过 `\0` 转义序列在其中嵌入空字符。
