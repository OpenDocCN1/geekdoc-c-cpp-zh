## 7.29.4.2 宽字符串拷贝


### 描述

`wcscpy` 函数将 `s2` 指向的宽字符串（包括终止空字符）拷贝到 `s1`。

### 返回

`wcscpy` 函数返回 `s1`。

### 7.294.2.2 `wcsncpy`

### 概要

```
#include <wchar.h>
wchar_t *wcsncpy(wchar_t * restrict s1,
const wchar_t *restrict s2,
size_t n);
```

### 描述

`wcsncpy` 函数从 `s2` 数组拷贝最多 `n` 个宽字符（空字符及其后续字符不被拷贝）到 `s1`。如果 `s2` 指向的数组少于 `n` 个宽字符，则追加空字符。

### 返回

`wcsncpy` 函数返回 `s1`。

### 7.294.2.3 `wmemcpy`

### 概要

```
#include <wchar.h>
wchar_t *wmemcpy(wchar_t * restrict s1,
const wchar_t * restrict s2,
size_t n);
```

### 描述

`wmemcpy` 函数从 `s2` 指向的对象拷贝 `n` 个宽字符到 `s1`。如果 `s2` 的前 `n` 个宽字符中没有空字符，结果将不会终止。

### 返回

`wmemcpy` 函数返回 `s1`。

### 7.294.2.4 `wmemmove`

### 概要

```
#include <wchar.h>
wchar_t *wmemmove(wchar_t *s1, const wchar_t *s2,
size_t n);
```

### 描述

`wmemmove` 函数从 `s2` 指向的对象拷贝 `n` 个宽字符到 `s1`。如果 `s2` 指向的 `n` 个宽字符与 `s1` 重叠，则首先将其拷贝到不与 `s1` 或 `s2` 重叠的 `n` 个宽字符临时数组中，然后将该临时数组的 `n` 个宽字符拷贝到 `s1`。

### 返回

`wmemmove` 函数返回 `s1`。
