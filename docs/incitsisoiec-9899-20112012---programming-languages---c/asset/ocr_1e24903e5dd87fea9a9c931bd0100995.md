# G.6.1 Trigonometric functions

# G.6.1.1 The cacos functions

+   - cacos(conj(z)) = conj(cacos(z)).
- cacos(±0+ i0) returns π/2 - i0.
- cacos(±0+ iNaN) returns π/2 + iNaN.
- cacos(x+ i0) returns π/2 - ∞, for finite x.
- cacos(x+ iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for nonzero finite x.
- cacos(-∞+ iy) returns π - ∞, for positive-signed finite y.
- cacos(+∞+ i0) returns +0 - ∞, for positive-signed finite y.
- cacos(-∞+ ∞) returns 3π/4 - ∞.
- cacos(+∞+ ∞) returns π/4 - ∞.
- cacos(±iNaN) returns NaN ±i∞ (where the sign of the imaginary part of the result is unspecified).
- cacos(NaN+ iy) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite y.
- cacos(NaN+ ∞) returns NaN - ∞.
- cacos(NaN+ iNaN) returns NaN + iNaN.

# G.6.2 Hyperbolic functions

# G.6.2.1 The ccosh functions

+   - ccosh(conj(z)) = conj(cosh(z)).
- ccosh(±0+ i0) returns +0 + iπ/2.
- ccosh(x+ ∞) returns ∞ + iP/2, for finite x.
- ccosh(x+ iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite x.
- ccosh(-∞+ iy) returns ∞ + iπ, for positive-signed finite y.
- ccosh(+∞+ iy) returns ∞ + i0, for positive-signed finite y.
- ccosh(-∞+ ∞) returns +∞ + i3π/4.
- ccosh(+∞+ ∞) returns +∞ + iP/4.
- ccosh(±iNaN) returns +∞ + iNaN.
