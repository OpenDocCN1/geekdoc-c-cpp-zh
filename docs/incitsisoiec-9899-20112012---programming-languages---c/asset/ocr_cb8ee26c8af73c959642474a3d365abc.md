# 6.7.3.1 Formal definition of restrict

Let D be a declaration of an ordinary identifier that provides a means of designating an object P as a restrict-qualified pointer to type T.

If D appears inside a block and does not have storage class extern, let B denote the block. If D appears in the list of parameter declarations of function definition, let B denote the associated block. Otherwise, let B denote block of main (or the block of whatever function is called at program startup in a freestanding environment).

In what follows, a pointer expression E is said to be based on object P if (at some sequence point in the execution of B prior to evaluation of E) modifying P to a copy of the array object which it formerly pointed would change the value of E.(137) Note that "based" is defined only for expressions with pointer types.

During each execution of B, let L denote that L has &bound to P. If L is used to access the value of the object X that it designates, and X is also modified (by means), then the following requirements apply: T shall not be const-qualified. Every other lvalue shall also have its address bound to P. Every access that modifies X shall also be considered to modify P, for the purposes of this subclass.
