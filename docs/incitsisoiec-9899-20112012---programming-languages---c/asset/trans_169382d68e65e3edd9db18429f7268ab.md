

## 7.12.2 FP_CONTRACT pragma

 概要

```
#include <math.h>
#pragma STDC FP_CONTRACT on-off-switch
```

描述

`FP_CONTRACT` pragma 可用于允许（当状态为“on”时）或禁止（当状态为“off”时）实现转换强制类型表达式（6.5）。每个 pragma 均出现在外部声明之外，或者位于复合语句内部所有显式声明和语句之前。在外部声明之外，该 pragma 从其出现处开始生效，直到遇到另一个 `FP_CONTRACT` pragma 或翻译单元的结束。在复合语句内部，该 pragma 从其出现处开始生效，直到遇到另一个 `FP_CONTRACT` pragma（包括嵌套的复合语句）或复合语句结束；在复合语句结束时，该 pragma 的状态将恢复到复合语句执行前的状态。如果在任何其他语文中使用此 pragma，其行为是未定义的。该 pragma 的默认状态（“on”或“off”）由实现定义。

## 7.12.3 分类宏

在本子类的概要中，`real-floating` 表示参数应为实数浮点类型的表达式。

### 7.12.3.1 fpclassify 宏

概要

```
#include <math.h>
int fpclassify(real-floating x);
```

描述

`fpclassify` 宏将其参数值分类为 NaN、无穷大、正规（normal）、次正规（subnormal）、零或另一个实现定义的类别。首先，将比其语义类型更宽的格式表示的参数转换为其语义类型。然后根据参数的类型进行分类。

返回值

`fpclassify` 宏返回与其参数值匹配的数字分类宏的值。

> 234) 由于表达式的评估范围和精度可能超过其类型所具有的范围，因此知道分类依据是重要的。例如，一个正规 double 值在转换为 double 时可能会变成次正规，在转换为 float 时可能变成零。

### 7.12.3.2 isfinite 宏

概要

```
#include <math.h>
int isfinite(real-floating x);
```

描述

`isfinite` 宏确定其参数是否具有有限值（零、次正规或正规，且不是无穷大或 NaN）。首先，将比其语义类型更宽的格式表示的参数转换为其语义类型。然后根据参数的类型进行确定。

返回值

`isfinite` 宏仅当其参数具有有限值时返回非零值。

### 7.12.3.3 isinf 宏

概要

```
#include <math.h>
int isinf(real-floating x);
```

描述

`isinf` 宏确定其参数是否为无穷大（正无穷或负无穷）。首先，将比其语义类型更宽的格式表示的参数转换为其语义类型。然后根据参数的类型进行确定。

返回值

`isinf` 宏仅当其参数具有无穷大值时返回非零值。

### 7.12.3.4 isnan 宏

概要

```
#include <math.h>
int isnan(real-floating x);
```

描述

`isnan` 宏确定其参数值是否为 NaN。首先，将比其语义类型更宽的格式的参数转换为其语义类型。然后根据参数的类型进行确定。

对于 `isnan` 宏，除非实现在评估类型中支持 NaN 但语义类型中不支持，否则用于确定的类型无关紧要。

`isnan` 宏仅当其参数具有 NaN 值时返回非零值。

### 7.12.3.5 isnnormal 宏

概要

```
#include <math.h>
int isnnormal(real-floating x);
```

描述

`isnormal` 宏确定其参数值是否为正规（既不是零、次正规、无穷大或 NaN）。首先，将比其语义类型更宽的格式表示的参数转换为其语义类型。然后根据参数的类型进行确定。

返回值

`isnormal` 宏仅当其参数具有正规值时返回非零值。

### 7.12.3.6 signbit 宏

概要

```
#include <math.h>
int signbit(real-floating x);
```

描述

`signbit` 宏确定其参数值的符号是否为负。

返回值

`signbit` 宏仅当其参数值的符号为负时返回非零值。

> 236) `signbit` 宏报告所有值的符号，包括无穷大、零和 NaN。如果零是无符号的，则被视为正数。

## 7.12.4 三角函数

### 7.12.4.1 acos 函数

概要

```
#include <math.h>
double acos(double x);
float acosf(float x);
long double acosl(long double x);
```

描述

`acos` 函数计算 x 的反余弦的主值。对于不在 [-1,+1] 范围内的参数，会发生定义域错误。

返回值

`acos` 函数返回 [0, π] 弧度内的 $\arccos x$。

### 7.12.4.2 asin 函数

概要

```
#include <math.h>
double asin(double x);
float asinf(float x);
long double asinl(long double x);
```

描述

`asin` 函数计算 x 的反正弦的主值。对于不在 [-1,+1] 范围内的参数，会发生域错误。

返回值

`asin` 函数返回 [-π/2, π/2] 弧度内的 $\arcsin x$。

### 7.12.4.3 atan 函数

概要

```
#include <math.h>
double atan(double x);
float atanf(float x);
long double atanl(long double x);
```

描述

`atan` 函数计算反正切的主值。对于不在 [-1,+1] 范围内的参数，会发生域错误。

返回值

`atan` 函数返回 [-π/2, π/2] 弧度内的 $\arctan x$。

### 7.12.4.4 atan2 函数

概要

```
#include <math.h>
double atan2(double y, double x);
float atan2f(float y, float x);
long double atan2l(long double y, long double x);
```

描述

`atan2` 函数计算反正切的主值。如果两个参数均为零时会发生域错误。

返回值

`atan2` 函数返回 [-π, π] 弧度内的 $\arctan(y/x)$。

### 7.12.4.5 cos 函数

概要

```
#include <math.h>
double cos(double x);
float cosf(float x);
long double cosl(long double x);
```

描述

`cos` 函数计算 x 的余弦的主值。

返回值

`cos` 函数返回 [0, π] 弧度内的 $\cos x$。

### 7.12.4.6 sin 函数

概要

```
#include <math.h>
double sin(double x);
float sinf(float x);
long double sinl(long double x);
```

描述

`sin` 函数计算 x 的正弦的主值。

返回值

`sin` 函数返回 [-1, 1] 弧度内的 $\sin x$。

### 7.12.4.7 tan 函数

概要

```
#include <math.h>
double tan(double x);
float tanf(float x);
long double tanl(long double x);
```

描述

`tan` 函数计算 x 的正切的主值。当 x 是 π/2 的奇数倍时，会发生域错误。

返回值

`tan` 函数返回 [-∞, ∞] 弧度内的 $\tan x$。

## 7.12.5 双曲函数

### 7.12.5.1 acosh 函数

概要

```
#include <math.h>
double acosh(double x);
float acoshf(float x);
long double acoshl(long double x);
```

描述

`acosh` 函数计算 x 的非负双曲余弦的主值。对于小于 1 的参数，会发生域错误。

返回值

`acosh` 函数返回 [0,+∞] 弧度内的 $\text{acosh } x$。

### 7.12.5.2 asinh 函数

概要

```
#include <math.h>
double asinh(double x);
float asinhf(float x);
long double asinhl(long double x);
```

描述

`asinh` 函数计算 x 的双曲正弦的主值。

返回值

`asinh` 函数返回 [-∞, ∞] 弧度内的 $\text{asinh } x$。

### 7.12.5.3 atanh 函数

概要

```
#include <math.h>
double atanh(double x);
float atanhf(float x);
long double atanhl(long double x);
```

描述

`atanh` 函数计算 x 的双曲正切的主值。对于不在 [-1,+1] 范围内的参数，会发生域错误。当参数等于 -1 或 +1 时，可能会发生极点错误。

返回值

`atanh` 函数返回 [-∞, ∞] 弧度内的 $\text{atanh } x$。

### 7.12.5.4 cosh 函数

概要

```
#include <math.h>
double cosh(double x);
float coshf(float x);
long double coshl(long double x);
```

描述

`cosh` 函数计算 x 的双曲余弦。当 x 的绝对值过大时会发生范围错误。

返回值

`cosh` 函数返回 $\text{cosh } x$。

### 7.12.5.5 sinh 函数

概要

返回值
