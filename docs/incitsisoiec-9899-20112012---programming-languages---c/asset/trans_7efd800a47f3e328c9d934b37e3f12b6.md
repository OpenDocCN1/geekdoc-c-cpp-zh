# 引言

随着新设备的引入和扩展字符集的出现，本国际标准可能会添加新特性。语言中的子类和库类会警告实现者和程序员，某些用法虽然本身是有效的，但可能与未来的新增发生冲突。

某些特性已经过时，这意味着它们在本文国际标准的未来修订中可能会被考虑撤回。保留它们是因为它们被广泛使用，但不鼓励在新的实现（针对实现特性）或新的程序（针对语言 [6.11] 或库特性 [7.31]）中使用。

本国际标准分为四个部分：
- 初步元素（第 1–4 节）
- 并执行 C 程序的环境特征（第 5 节）；
- 语言语法、约束和语义（第 6 节）；
- 库设施（第 7 节）。

示例说明了所述构造的可能形式。脚注用于强调该子节或本文国际标准其他处规则的影响。引用用于指向其他相关的子节。附录为实现者提供建议或指导。附录提供了额外信息并总结了本文国际标准包含的信息。参考文献列出了在标准准备期间引用的文档。

语言章节（第 6 节）源自《C 参考手册》。

库章节（第 7 节）基于 1984 /usr/group 标准。

## 1. 范围

本国际标准规定了用 C 语言编写的程序的格式并建立了程序的解释.¹11) 它规定了：

- C 程序的表示；
- C 语言的语法和约束；
- 解释 C 程序的语义规则；
- C 程序处理的输入数据的表示；
- C 程序产生的输出数据的表示；
- 符合标准的 C 实现所施加的限制和范围。

本国际标准未规定：

- C 程序转换以供数据处理系统使用的机制；
- C 程序调用以供数据处理系统使用的机制；
- 输入数据转换以供 C 程序使用的机制；
- C 程序产生输出数据转换机制；
