

## 7.29.4.6 杂项函数

### 7.29.4.6.1 wcslen 函数

概要

```
#include <wchar.h>
size_t wcslen(const wchar_t *s);
```

描述
wcslen 函数计算由 s 指向的宽字符串的长度。

返回值

wcslen 函数返回终止空字符之前的之前的宽字符个数。

### 7.29.4.6.2 wmemset 函数

概要

```
#include <wchar.h>
wchar_t *wmemset(wchar_t *s, wchar_t c, size_t n);
```

描述
wmemset 函数将 c 的值复制到由 s 指向的对象的前 n 个宽字符中的每一个中。

返回值

wmemset 函数返回 s 的值（即指针指向的地址）。

## 7.29.5 宽字符转换函数

### 7.29.5.1 wcsftime 函数

概要

```
#include <time.h>
#include <wchar.h>
size_t wcsftime(wchar_t * restrict s,
size_t maxsize,
const wchar_t * restrict format,
const struct tm * restrict timeptr);
```

描述
wcsftime 函数等同于 strftime 函数，不同之处在于：

- 参数 s 指向一个宽字符数组的起始元素，生成的输出将存放在该中。

参数 maxSize 表示限制的宽字符数量。

参数 format 是一个宽字符串，转换说明符被替换为相应的宽字符序列。

返回值表示宽字符的个数。

返回值

如果包括终止空字符在内的结果宽字符总数不超过 maxSize，则 wcsftime 函数返回存入 s 指向的数组中的宽字符个数（不包括终止宽字符）。否则，返回 0 且数组的内容是不确定的。

## 7.29.6 扩展多字节/宽字符转换工具

头文件 <wchar.h> 声明了一组扩展的函数，用于在多字节字符和宽字符之间进行转换。

大多数函数——即列为“可重入的”的函数（见 7.29.6.3 和 7.29.6.4）——最后一个参数接受一个指向 `mbstate_t` 类型对象的指针，该对象用于描述在当前 locale（区域）的 `LC_CTYPE` 类别特定规则下，从特定多字节序列到（反之）的当前转换状态。

在输入时，每个函数都将描述的转换状态（内部的或通过参数指向）作为参数。引用对象描述的转换状态将根据需要进行修改，以跟踪关联多字节字符序列的移位状态以及在多字节字符内部的位置。

> 348 因此，一个特定的 `mbstate_t` 对象可以同时用于 mbrtowc 和 mbrtowcs 函数，只要它们被用于顺序步进同一个多字节字符字符串即可。

### 7.29.6.1 单字节/宽字符转换函数

### 7.29.6.1.1 btowc 函数

概要

```
#include <wchar.h>
wint_t btowc(int c);
```

描述

btowc 函数确定 c 在初始移位状态下是否构成有效的单字节字符。

返回值

如果 c 的值为 EOF 或 (unsigned char) c 在初始移位状态下不构成有效的单字节字符，则 btowc 函数返回 EOF。否则，它返回该字符的宽字符表示。

### 7.29.6.1.2 wctob 函数

概要

```
#include <wchar.h>
wctob(wint_t c);
```

描述

wctob 函数确定 c 是否对应扩展字符集中的成员，该成员在初始移位状态下的多字节字符表示为单字节。

返回值

如果 c 在初始移位状态下对应长度为一的多字节字符，则 wctob 函数返回 EOF。否则，它返回该字符的单字节表示（转换为 int 的 unsigned char）。

### 7.29.6.2 转换状态函数

### 7.29.6.2.1 mbsisinit 函数

概要

```
#include <wchar.h>
mbsisinit(const mstate_t *ps);
```

描述
如果 ps 不是空指针，mbsisinit 函数确定引用的 `mstate_t` 对象是否描述一个初始转换状态。

如果 ps 为空指针或引用的对象描述一个初始的可重入转换状态，则 mbsisinit 返回非零；否则返回零。

### 7.29.6.3 多字节/宽字符函数

这些函数与 7.2.27 中对应的多字节字符函数（mblen、mbtowc 和 wctom）的区别在于，它们有一个额外的参数 ps，类型为指向 `mbstate_t` 对象的指针，该对象可以完全描述关联多字节序列的当前转换状态。如果 ps 为空指针，每个函数将使用其内部的 `mbstate_t` 对象，该对象在程序启动时初始化为初始转换状态；在这种情况下，函数不需要避免与其他对同一函数的其他调用产生数据竞态。其实现行为类似于没有库函数用空 指针 ps 调用了同一个函数。

此外，与其对应的函数不同，其返回值不表示编码是否依赖状态。

### 7.29.6.3.1 mbrlen 函数

概要

```
#include <wchar.h>
size_t mbrlen(const char * restrict s,
    size_t n,
    mbstate_t * restrict ps);
```

描述

mbrlen 函数等同于调用：
brtowc(NULL, s, n, ps != NULL ? ps : &internal)
其中 internal 是 mbrlen 函数的 `mbstate_t` 对象，但 ps 指定的表达式仅被求值一次。

返回值

mbrlen 函数返回零到 n（包含）之间的值、(size_t)-2 或 (size_t)(-1)。

前向引用：mbtowc 函数（7.29.6.3.2）。

### 7.29.6.3.2 mbrtowc 函数

概要

```
#include <char.h>
size_t mbrtowc(wchar_t * restrict pwc,
const char * restrict s,
size_t n,
mbstate_t * restrict ps);
```

描述
如果 s 为空指针，mbrtowc 函数等同于调用：
mbrtowc(NULL, "", 1, ps)
在这种情况下，忽略 pwc 和 n 的值。

如果 s 不是空指针，mbrtowc 函数检查 s 开始的最多 n 个字节以确定完成多字节字符所需的字节数。如果函数判断多字节字符完整且有效，它将该值存储在 pwc 指向的对象中。结果状态为初始转换状态。

返回值

mbrtowc 函数根据当前状态返回第一个适用值：

- 0：n 或更少字节完成空字符
- 1 到 n 之间：n 或更少字节完成多字节字符（即已存储的值）
- (size_t)-2：字节贡献于不完整但可能有效的多字节字符，且所有 n 个字节已处理
- (size_t)(-1)：发生编码错误：函数将宏 EILSEQ 的值存储在 errno 中

### 7.29.6.3.3 wcertomb 函数

概要

```
#include <wchar.h>
size_t wcertomb(char * restrict s,
wchar_t wc,
mbstate_t * restrict ps);
```

描述
如果 s 为空指针，wcertomb 函数等同于调用：
wcertomb(buf, L'\0', ps)
其中 buf 是内部缓冲区。

如果 s 不是空指针，wcertomb 函数确定表示 wc 多字节字符所需的字节数（包括任何移位），并将多字节字符表示存储在 s 指向的首元素的数组中。最多存储 MB_CUR_MAX 字节。如果 wc 是空宽字符，则存储一个空字节，任何移位序列恢复内部状态；结果状态为初始转换状态。

返回值

wcertomb 函数返回存储在数组中的字节数（包括任何移位序列）。当 wc 不是有效的宽字符时，发生编码错误：函数将宏 EILSEQ 的值存储在 errno 中并返回 ((size_t) -1);

### 7.29.6.4 可重入多字节/宽字符串函数

这些函数与 7.2.8 中对应的多字节字符串函数（mbstowcs 和 wcstombs）的区别在于，它们有一个额外的参数 ps，类型为指向 `mbstate_t` 的指针，指向一个可以完全描述多字节序列当前转换状态的对象。如果 s 为空指针，每个函数将使用其内部的 `mbstate_t` 对象，该对象在程序启动时初始化为初始转换状态；在这种情况下，函数不需要避免与其他对同一函数的调用产生竞态。

此外，与其对应的函数不同，转换源参数 src 具有指针指针类型。当函数存储转换结果时（即 dst 不是空指针），该参数所指向的指针对象将进行更新，以反映本次调用处理的源量。
