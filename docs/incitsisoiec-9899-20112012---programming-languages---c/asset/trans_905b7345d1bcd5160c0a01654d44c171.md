#include <fenv.h>
/* ... */

## 7.6.3 舍入

`fegetround` 和 `fesetround` 函数提供了对舍入方向模式的控制。

### 7.6.3.1 fegetround 函数

概要

```
#include <fenv.h>
int fegetround(void);
```

描述

`fegetround` 函数获取当前的舍入方向。

返回值

`fegetround` 函数返回代表当前舍入方向的舍入方向宏的值；如果不存在这样的舍入方向宏，或者无法确定当前的舍入方向，则返回一个负值。

### 7.6.3.2 fesetround 函数

概要

```
#include <fenv.h>
int fesetround(int round);
```

描述

`fesetround` 函数建立由参数 `round` 所表示的舍入方向。如果参数不等于某个舍入方向宏的值，则舍入方向将不会改变。

返回值

`fesetround` 函数当且仅当请求的舍入方向被成功建立时返回零。

示例：保存、设置并恢复舍入方向。如果设置舍入方向失败，则报告错误并终止。

```c
#include <fenv.h>
#include <assert.h>

void f() {
    #pragma STDC FENV_ACCESS ON
    int save_round;
    int setround_ok;
    save_round = fegetround();
    setround_ok = fesetround(dir);
    assert(setround_ok == 0);
    /* ... */
    fesetround(save_round);
    /* ... */
}
```

## 7.6.4 环境

本节中的函数将浮点环境——状态标志位和控制模式——作为一个整体进行管理。

### 7.6.4.1 fegetenv 函数

概要

```
#include <fenv.h>
int fegetenv(fenv_t *envp);
```

描述

`fegetenv` 函数尝试将当前的浮点环境存储在 `envp` 指向的对象中。

返回值

如果环境存储成功，`fegetenv` 函数返回零。否则，返回一个非零值。

### 7.6.4.2 feholdexcept 函数

概要

```
#include <fenv.h>
int feholdexcept(fenv_t *envp);
```

描述

`feholdexcept` 函数将当前的浮点环境存储在 `envp` 指向的对象中，清除浮点状态标志位，然后如果可用，为所有浮点异常安装非停止（在发生浮点异常时继续执行）模式。

返回值

`feholdexcept` 函数当且仅当成功安装非停止浮点异常处理模式时返回零。

### 7.6.4.3 fesetenv 函数

概要

```
#include <fenv.h>
int fesetenv(const fenv_t *envp);
```

描述

`fesetenv` 函数尝试建立由 `envp` 指向的对象所表示的浮点环境。参数 `envp` 应当指向通过调用 `fegetenv` 或 `feholdexcept` 设置的对象，或者等于一个浮点环境宏。注意，`fesetenv` 仅通过其参数安装浮点状态标志位的状态，而不会引发这些浮点异常。

返回值

如果环境成功建立，`fesetenv` 函数返回零。否则，返回一个非零值。

### 7.6.4.4 fesetexcept 函数

概要

```
#include <fenv.h>
int fesetexcept(fenv_t *envp);
```

描述

`fesholdexcept` 函数将当前的浮点环境保存在 `envp` 指向的对象中，清除浮点状态标志位，然后如果可用，为所有浮点异常安装非停止（在发生浮点异常时继续执行）模式。

返回值

`fesholdexcept` 函数当且仅当成功安装非停止浮点异常处理模式时返回零。
