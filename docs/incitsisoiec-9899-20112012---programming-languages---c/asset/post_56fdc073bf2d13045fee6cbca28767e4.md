## Annex C
### Sequence points

The following are sequence points described in 5.1.2:

- Between the evaluations of a function designator and actual arguments in a function call (6.5.2).
- Between the evaluations of the first and second operands of the following operators: logical AND && (6.5.13), logical OR || (6.5.14), comma (6.5.17).
- Between the evaluations of the first operand of the conditional ? : whichever of the second and third operands is evaluated (6.5.15).
- The end of a full declarator (6.7.6).
- Between the evaluation of a full expression and the next full expression to be evaluated. The following are full expressions: an initializer that is part of a compound literal (6.7.9); the expression in an statement (6.8.3); the controlling expression of a selection statement (if or switch) (6.8.4); the controlling expression of a while or do statement (6.8.5); each of the (optional) expressions of a for statement (6.8.3); the (optional) expression in a return statement (6.8.6).
- Immediately before a library function returns (7.1.4).
- After the actions associated with each formatted input/output conversion specifier (7.2.6, 7.2.9).
- Immediately before and immediately after each call to a comparison function, and between any call to a comparison function and movement of objects passed as arguments to that call (7.2.5).
