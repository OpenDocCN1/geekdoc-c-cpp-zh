## 7.6.1 FENV_ACCESS 编译指令

### 摘要

```
#include <fenv.h>
#pragma STDC FENV_ACCESS on-off-switch
```

### 描述

`FENV_ACCESS` pragma 提供了一种手段，用于告知实现程序可能会访问浮点环境以测试浮点状态标志或在非默认浮点控制模式下运行。^{213} 该 pragma 应该出现在外部声明之外，或者位于复合语句中所有显式声明和语句之前。在外部声明之外，该 pragma 从其出现处开始生效，直到遇到另一个 `FENV_ACCESS` pragma，或者到翻译单元的结束。在复合语句内部，该 pragma 从其出现处开始生效，直到遇到另一个 `FENV_ACCESS` pragma（在嵌套的复合语句内）或直到复合语句结束；在复合语句结束时，该 pragma 的状态恢复到复合语句之前的状态。如果在任何其他语境下此 pragma，则其行为是未定义的。如果程序的部分测试了浮点状态标志、浮点控制模式或在非默认模式设置下运行，是在 `FENV_ACCESS` pragma 状态为 "off" 的情况下翻译的，则该 pragma 的 "off" 是由实现定义的。（当执行从用 `FENV_ACCESS` 为 "off" 翻译的部分传递到用 `FENV_ACCESS` 为 "on" 翻译的部分时，浮点状态标志的状态是不确定的，且浮点控制模式具有其默认设置。）

212 参见“未来库目录”（7.31.4）。

213 `FENV_ACCESS` pragma 的目的是允许某些优化，这些优化可以影响标志测试和模式更改（例如全局子表达式消除、代码移动和常量折叠）。在状态 `FENV_ACCESS` 为 "off" 的情况下，翻译器可以假设默认模式正在生效且没有测试标志。

### 示例

```
#include <env.h>
void f(double x)
{
#pragma STDC FENV_ACCESS ON
void g(double);
void h(double);
/* ... * */
g(x + 1);
h(x + 1);
/* ... * */
}
```

如果函数 `g` 可能会作为调用 `g` 的副作用而依赖于状态标志，或者第二个 `x + 1` 可能会依赖于控制模式，则程序应该使用放置恰当的 `#pragma STDC FENV_ACCESS ON` 调用。^{214}

## 7.6.2 浮点异常

以下函数提供了访问浮点状态标志的方法。^{215} 函数的输入参数代表浮点异常的一个集，可以是零，也可以是一个或多个浮点异常宏的按位或，例如 `FE_OVERFLOW | FE_INEXACT`。对于其他参数，这些函数的行为是未定义的。

### 7.6.2.1 fcleareexcept 函数

### 摘要

```
#include <env.h>
int fcleareexcept(int exceptions);
```

### 描述

`fcleareexcept` 尝试清除由 `exceptions` 参数表示的浮点异常。

### 返回

如果 `exceptions` 参数为零或所有指定的异常都已成功清除，则 `fcleareexcept` 返回 0。否则返回非零值。

### 7.6.2.2 fegetexcept 函数

### 摘要

```
#include <fenv.h>
int fegetexcept(fenv_t *flagp, int exceptions);
```

### 描述

`fegetexcept` 尝试将 `exceptions` 参数指定的浮点状态标志的表示存储在 `flagp` 指向的对象中。

### 返回

如果存储成功，则 `fegetexcept` 返回 0。否则返回非零值。

### 7.6.2.3 feraiseexcept 函数

### 摘要

```
#include <fenv.h>
int feraiseexcept(int exceptions);
```

### 描述

`feraiseexcept` 尝试抛出 `exceptions` 参数表示的浮点异常。

### 返回

如果 `exceptions` 参数为零或所有指定的异常都已成功抛出，则 `feraiseexcept` 返回 0。否则返回非零值。

### 7.6.2.4 fesetexceptflag 函数

### 摘要

```
#include <fenv.h>
int fesetexceptflag(const fenv_t *flagp, int exceptions);
```

### 描述

`fesetexceptflag` 尝试将 `exceptions` 参数指定的浮点状态标志设置为 `flagp` 指向的对象中存储的状态。`*flagp` 的值应由之前的调用 `fegetexceptflag` 设置，且其第二个参数至少包含了由 `exceptions` 参数表示的浮点异常。

### 返回

如果 `exceptions` 参数为零或所有指定的标志都已成功设置为相应状态，则 `fesetexceptflag` 返回 0。否则返回非零值。

### 7.6.2.5 fesetexcept 函数

### 摘要

```
#include <fenv.h>
int fesetexcept(int exceptions);
```

### 描述

`fesetexcept` 确定指定的浮点异常标志子集中的哪些是当前设置的。`exceptions` 参数指定要查询的浮点状态标志。²17)

### 返回

`fesetexcept` 返回对应 `exceptions` 中包含的当前设置浮点异常宏的按位或值。
