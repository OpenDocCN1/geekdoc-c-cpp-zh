the int returned by the function may be truncated when stored in the char, and then converted to int width prior to comparison. In an implementation where "plain" char has the same range of values as unsigned char (char is narrower than int), the result of the comparison cannot be negative, so the operands of the comparison cannot compare equal. Therefore, for portability, the variable c should be declared as int.

# 6.5.16.2 Compound assignment

# Constraints

For the operators += and -= only, the left operand shall be atomic, qualified, or unqualified pointer to a complete object type, and the right hand have integer type; or the left operand shall have atomic, qualified, or unqualified arithmetic type, and the right shall have arithmetic type.

For the other operators, the left operand shall be atomic, qualified, or unqualified arithmetic type, and (considering the type left operand would have Aftervalue conversion) each operand shall have arithmetic type consistent with those allowed by the corresponding binary operator.
