

## F10.6.4 rint 函数

rint 函数与 nearbyint 函数的唯一区别在于，当结果在数值上与参数不符时，它们会抛出“不精确（inexact）”浮点异常。

## F10.6.5 lrint 和 llrint 函数

lrint 和 llrint 函数提供了 IEC 60559 规定的浮点数到整数的转换。它们根据当前的舍入方向进行四舍五入。如果返回值超出了返回类型的范围，则数值结果未定义，并会抛出“无效（invalid）”浮点异常。当它们没有抛出其他浮点异常且结果与参数不同时，它们会抛出“不精确（inexact）”浮点异常。

## F10.6.6 round 函数

- round (±0) 返回 ±0。
- round (±∞) 返回 ∞。

返回的值与当前的舍入方向模式无关。

double 版本的 round 行为类似于以下代码实现：

```c
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double round(double x)
{
    double result;
    fenv_t save_env;
    feholdexcept(&save_env);
    result = rint(x);
    if (fetestexcept(FE_INEXACT)) {
        fetetround(FE_TOWARDZERO);
        result = rint(copysign(0.5 + fabs(x), x));
    }
    updateenv(&save_env);
    return result;
}
```

round 函数可能会（但不是必须）对有限非整数数值参数抛出“不精确（inexact）”浮点异常，本实现正是这样做的。

## 10.6.7 round 和 llround 函数

round 和 llround 函数与默认舍入方向下的 lrint 和 llrint 函数的区别仅在于：round 和 llround 函数采用远离零舍入，且对于舍入后在返回类型范围内的非整数参数，不会抛出“不精确（inexact）”浮点异常。

## 10.6.8 trunc 函数

trunc 函数使用 IEC 60559 的向零舍入规则（无论当前的舍入方向如何）。返回的值是精确的。

- trunc (±0) 返回 ±0。
- trunc (±∞) 返回 ±∞。

返回的值与当前的舍入方向模式无关。trunc 函数可能会（但不是必须）对非整数参数抛出“不精确（inexact）”浮点异常。

## F10.6.7 余数函数

### F10.6.7.1 fmod 函数

- fmod (±0, y) 当 y 不零时返回 0。
- fmod (x, ±0) 返回 NaN。
- fmod (x, ±∞) 返回 x。
- fmod (NaN, y) 返回 NaN。

double 版本的 fmod 行为类似于以下代码实现：

```c
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double fmod(double x, double y)
{
    double result;
    result = remainder(x, y);
    if (isnan(result)) {
        return result;
    }
    if ((x > 0) != (result > 0)) {
        result = -result;
    }
    return result;
}
```

### F10.6.7.2 remainder 函数

- remainder (±0, y) 返回 ±0。
- remainder (x, ±0) 返回 NaN。
- remainder (x, ±∞) 返回 x。
- remainder (NaN, y) 返回 NaN。

### F10.6.7.3 remquo 函数

- remquo (x, y) 返回 0。
- remquo (x, ±0) 返回 NaN。
- remquo (x, ±∞) 返回 x。
- remquo (NaN, y) 返回 NaN。

## F10.8 操作函数

### F10.8.1 copysign 函数

- copysign(x, y) 返回带有 符号的 x。

### F10.8.2 nan 函数

- isnan(x) 当 x 为 NaN 时返回非零，否则返回零。

### F10.8.3 nextafter 函数

- nextafter(x, y) 返回沿 y 方向的下一个浮点数。

### F10.8.4 nexttoward 函数

- nexttoward(x, y) 返回向 y 方向的下一个浮点数。

## F10.9 最大值、最小值和差函数

### F10.9.1 dim 函数

- dim(x, y) 返回绝对值较大的。

### F10.9.2 fmax 函数

- fmax(x, y) 返回 x 和 y 的最大值。如果其中一个为 NaN，返回另一个；如果两个都是 NaN，则返回 NaN。

### F10.9.3 fmin 函数

- fmin(x, y) 返回 x 和 y 的最小值。如果其中一个为 NaN，返回另一个；如果两个都是 NaN，则返回 NaN。

## F10.10 浮点乘加

### F10.10.1 fma 函数

- fma(x, y, z) 单次舍入计算 xy + z。

## F10.11 比较宏

关系运算符及其比较宏产生等效的结果，即使参数使用了宽格式。

(规范性)

## 兼容 IEC 60559 的复数运算

### G.1 引言

本附录补充了 F 附录，规定了与 IEC 60559 实浮点运算兼容的复数运算。定义 __STDC_IEC_559_COMPLEX__ 的实现应符合本附录的规定。

### G.2 类型

新增关键字 _Imaginary 用于指定虚数类型。它以与 _Complex相同的方式作为声明说明符（因此 _Imaginary float 是一个有效的类型名称）。

有三种虚数类型，分别为 float _Imaginary、double _Imaginary 和 long double _Imaginary。虚数类型（以及实浮点复数类型）都是浮点类型。

对于虚数类型，通过删除类型名称中的关键字 _Imaginary 即可实类型。

每个虚数类型与其实类型具有相同的表示和对齐要求。虚数类型对象的值是实表示乘以虚单位。

虚数类型域包含虚数类型。

### G.3 惯例

至少有一个无穷部分的复数或虚数被视为无穷（即使其其他部分为 NaN）。如果每个部分都是有限数（既不是无穷也不是 NaN），则复数或虚数是有限数。如果每个部分都是零，则复数或虚数是零。
