# 7.29.4.4.5 The wmemcmp function

Synopsis

```
#include <wchar.h>
wmemcmp(const wchar_t *s1, const wchar_t *s2, size_t n);
```

Description

The wmemcmp function compares the first n wide characters of the object pointed to by s1 to the first n wide characters of the object pointed to by s2.

Returns

The wmemcmp function returns an integer greater than, equal to, or less than zero, accordingly as the object pointed to by s1 is greater than, equal to, or less than the object pointed to by s2.

# 7.29.4.4.5 Wide string search functions

# 7.29.4.5.1 The wcsnrchr function

Synopsis

```
#include <wchar.h>
wchar_t *wcsnrchr(const wchar_t *s, wchar_t c);
```

Description

The wcsnrchr function locates the first occurrence of c in the wide string pointed to by s. The terminating null character is considered to be part of the wide string.

Returns

The wcsnrchr function returns a pointer to the located wide character, or a null pointer if the wide character does not occur in the wide string.

# 7.29.4.5.2 The wcsspn function

Synopsis

```
#include <wchar.h>
size_t wcsspn(const wchar_t *s1, const wchar_t *s2);
```

Description

The wcsspn function computes the length of the maximum initial segment of the wide string pointed to by s1 which consists entirely of wide characters not from the wide string pointed to by s2.
