# 7.30.2.1.3 The iswblank function

Synopsis

```
#include <ctype.h>
int iswblank(w_t wc);
```

Description

The iswblank function tests for any wide character that is a standard wide character or one of a locale-specific set of wide characters for which iswspace is true and that is used to separate words within a line of text. The standard wide blank characters are the following: space (L '), and horizontal tab (L\t). In the "C" locale, iswblank returns true only for the standard blank characters.

# 7.30.2.1.5 The iswdigit function

Synopsis

```
#include <ctype.h>
int iswdigit(w_t wc);
```

Description

The iswdigit function tests for any wide character that corresponds to a decimal-digit character (as defined in 5.2.1).
