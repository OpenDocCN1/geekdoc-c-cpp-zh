## 7.25 Type-generic math <tgmath.h>

1 Header <tgmath.h> includes <math.h> and <complex.h> and defines several type-generic macros.

2 Of the <math.h> and <complex.h> functions without an f (float) or l (long double suffix), several have one or more parameters whose corresponding real type is double. For each function, except modf, there is a corresponding type-generic macro. (313) The parameters whose corresponding real type is double in the function synopsis are generic parameters. Use of the macro invokes a function whose corresponding real type and type domain are determined by the arguments for the generic parameters. (314)

3 Use of the macro invokes a function whose generic parameters have the corresponding real type determined as follows:

- First, if any argument for generic parameters has type long double, the type determined is long double.
- Otherwise, if any argument for generic parameters has type double or is integer type, the type determined is double.
- Otherwise, the type determined is float.

4 For each unsuffixed function in <math.h> for which there is a function in <complex.h> with the same name except for a c prefix, the corresponding type-generic macro (for both functions) has the same name as the function in <math.h>. The corresponding type-generic macro for fabs and cabs are fabs.

313 Like other function-like macros in Standard libraries, each type-generic macro can be suppressed to make available the corresponding ordinary function.

314 If the type of the argument is not compatible with the type of the parameter for the selected function, the behavior is undefined.

## 7.26 Threads <threads.h>

### 7.26.1 Introduction

The header <threads.h> includes the header <time.h>, defines macros, and declares types, enumeration constants, and functions that support multiple threads of execution. (315)

Implementations that define the macro __STDC_NO_THREADS__ need not provide this header nor support any of its facilities.

The macros are

```
thread_local
```

which expands to _Thread_local,

```
ONCE_FLAG_INIT
```

which expands to a value that can be used to initialize; and

```
TSS_ITERATIONS
```

which expands to an integer representing the maximum number of times destructors will be called.

The types are

```
cnd_t
```

which is a complete type that holds a condition variable;

```
thrd_t
```

which is a complete type that holds a thread;

```
tss_t
```

which is a complete type that holds thread-specific storage;

```
mtx_t
```

which is a complete type that holds a mutex;

```
thrd_start_t
```

which is the function type void*) that is passed to thrd_create to create a new thread; and

```
once_flag
```

which is a complete type for use by call_once.

The enumeration constants

```
mtx_plain
```

which is passed to mtx_init to create a mutex that supports neither timeout nor recursive;

```
mtx_recursive
```

which is passed to mtx_init to create a mutex that supports recursive locking;

```
mtx_timed
```

which is passed to mtx_init to create a mutex that supports timeout;

```
thrd_timeout
```

which is returned by timed wait function to indicate that the time specified was reached without acquiring the resource;

```
thrd_success
```

which is returned by a function to indicate that the operation succeeded;

```
thrd_busy
```

which is returned by a function to indicate that the operation failed because a resource requested by a test is already in use;

```
thrd_error
```

which is returned by a function to indicate that the operation failed; and

```
thrd_nomem
```

which is returned by a function to indicate that the operation failed because it was unable to allocate memory.

**Forward references:** date and time (27).

## 7.26.2 Initialization functions

### 7.26.2.1 The call_once function

Synopsis

```
#include <threads.h>
void call_once(once_flag *flag, void (*func)(void));
```

Description

The call_once function uses the once_flag pointed to flag to ensure that func is called exactly once, the first time the call_once function is called with value of flag. Completion of an effective call to the call_once function synchronizes with all subsequent calls to the call_once function with the same value of flag.

Returns

The call_once function returns no value.

## 7.26.3 Condition variable functions

### 7.26.3.1 The cnd_broadcast function

Synopsis

```
#include <threads.h>
int cnd_broadcast (cnd_t *cond);
```

Description

The cnd_broadcast function unblocks all of the threads that are blocked on the condition variable pointed to cond at the time of the call. If no threads are blocked on the condition variable pointed to cond at the time of the call, the function does nothing.

Returns

The cnd_broadcast function returns thrd_success on success, or thrd_error if the request could not be honored.

### 7.26.3.2 The cnd_destroy function

Synopsis

```
#include <threads.h>
void cnd_destroy (cnd_t *cond);
```

Description

The cnd_destroy function releases all resources used by the condition variable pointed by cond. The cnd_destroy function requires that no threads are blocked waiting for the condition variable pointed by cond.
