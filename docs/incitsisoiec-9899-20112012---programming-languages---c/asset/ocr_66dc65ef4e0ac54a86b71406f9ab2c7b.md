characters have been stored in the array pointed to by dst.{453} If dst is a null pointer and no wide character was stored in the array pointed to by dst, then dst[len] is set to the null wide character. Each conversion takes place as if a call to the mbtowc function.

If dst is not a null pointer, the pointer pointed to by src is assigned either a pointer (if conversion stopped due to reaching a terminating null character) or the address just past the last multibyte character converted (if any). If conversion stopped due to reaching a terminating null character and if dst is not a null pointer, the resulting state is described as the initial conversion state.

Regardless of whether dst is or not a null pointer, the input conversion encounters a sequence of bytes that do not form a multibyte character, an encoding error occurs: the mbtowccs_s function stores the value {size_t} (-1) to *retval and the conversion is unspecified. Otherwise, the mbtowccs_s function stores *retval the number of multibyte characters successfully converted, not including the terminating null character (if any).

All elements following the terminating null wide character (if any) written by mbtowcs_s in the array of dstmax wide characters pointed to by dst take unspecified values when mbtowcs_s returns.{454}

If copying takes place between objects that overlap, the objects take on unspecified values.

Returns

The mbtowccs_s function returns zero if no runtime-constraint violation and no encoding error occurs. Otherwise, a nonzero value is returned.
