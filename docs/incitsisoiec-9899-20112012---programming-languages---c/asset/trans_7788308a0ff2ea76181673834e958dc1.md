
实现行为应当类似于没有库函数调用 `wctomb` 函数。

如果 `s` 为空指针，且是多字节编码，或者不具有状态相关性影响，则 `wctomb` 函数返回一个非零值或零值。如果 `s` 不是空指针，若 `wc` 不对应多字节字符，则 `wctomb` 函数返回 -1；否则返回与 `wc` 的值对应的多字节字符所包含的字节数。

在任何情况下，该值都不会大于宏 `MB_CUR_MAX` 的值。

## 72.2.8 多字节字符串/宽字符串转换函数

多字节字符串函数的行为受当前区域（locale）的 `LC_CTYPE` 类别的影响。

### 72.2.8.1 mbstowcs 函数

# 语法概要

```
#include <stdlib.h>
size_t mbstowcs(wchar_t * restrict pwcs,
               const char * restrict s,
               size_t n);
```

# 描述

`mbstowcs` 函数将由 `s` 指向的数组中从初始状态开始的多字节字符序列转换为相应的宽字符序列，并将多于 `n` 个宽字符存储到 `pwcs` 指向的数组中。空字符（被转换为空宽字符）之后的多字节字符将不会被检查或转换。每个多字节字符的转换都类似于调用 `mbtowc` 函数，但 `mbtowc` 函数的转换状态不受影响。

由 `pwcs` 指向的数组中修改的元素不超过 `n` 个。如果在两个重叠的对象之间进行拷贝，则行为是未定义的。

# 返回

如果遇到无效的多字节字符，`mbstowcs` 函数返回 `(size_t) (-1)`。否则，`mbstowcs` 函数返回修改的数组元素个数，不包括（如果有）终止的空宽字符。

306) 如果返回值为 `n`，则数组将不会以空终止。

## 7.24 字符串处理 <string.h>

### 7.24.1 字符串函数约定

头文件 `<string.h>` 声明了一个或多个函数，并定义了一个用于操作字符类型数组和其他被视为字符类型数组对象的宏。(307) 该类型为 `size_t`，宏为 `NULL`（在 7.19 中描述）。使用了多种方法来确定数组的长度，但在所有情况下，参数都是指向数组初始（地址最小）字符的 `char *` 或 `void *`。如果访问了超出对象末尾的数组，则行为是未定义的。

当一个声明为 `size_t n` 的参数指定函数的长度时，在调用该函数时 `n` 的值可以为零。除非在本子句中特定函数的描述中另有说明，否则此类调用中的指针参数仍应具有 7.1.4 描述的有效值。在此类调用中，定位字符的函数未发现匹配项，比较两个字符序列的函数返回零，拷贝字符的函数拷贝零个字符。

对于本子句中的所有函数，每个字符的解释都类似于其类型为 `unsigned char`（因此每种可能的对象表示都是有效的且具有不同的值）。
