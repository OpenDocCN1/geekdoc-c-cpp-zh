
The erfc functions return erfc $x = 1 - \text{erfc } x = \frac{2}{\sqrt{\pi}} \int_{x}^{\infty} e^{-t^2} dt$.

## 7.12.10 Remainder functions

### 7.12.10.1 fmod functions

Synopsis

```c
#include <math.h>
double fmod(double x, double y);
float fmodf(float x, float y);
long double fmodl(long double x, long double y);
```

Description

The `fmod` functions compute the floating-point remainder of x/y.

Returns

The `fmod` functions return the value $x - ny$, for some integer $n$ such that, if $y$ is nonzero, the result has the same sign as $x$ and less than the magnitude of $y$. If $y$ is zero, a domain error occurs or the `fmod` functions return zero is implementation-defined.

### 7.12.10.2 The remainder functions

Synopsis

```c
#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
```

Description

The `remainder` functions compute the remainder of x/y. When $y \neq 0$, the remainder $r = x - ny$ is defined where $n$ is the even integer such that $|r| \le |y|/2$. If $|r| = |y|/2$, the sign of $r$ is the sign of $x$.

Returns

The `remainder` functions return the remainder value.

### 7.12.10.3 The remquo functions

Synopsis

```c
#include <math.h>
double remquo(double x, double y, int *quo);
float remquof(float x, float y, int *quo);
long double remqol(long double x, long double y, int *quo);
```

Description

The `remquo` functions compute the remainder of x/y. The object pointed to `quo` stores the integer quotient $n$. The result is a value whose magnitude is congruent to $x$ modulo $y$ and sign is that of $x$.

Returns

The `remquo` functions return the remainder. If $y$ is zero, a domain error occurs or the functions return zero is implementation-defined.

## 7.12.11 Manipulation functions
