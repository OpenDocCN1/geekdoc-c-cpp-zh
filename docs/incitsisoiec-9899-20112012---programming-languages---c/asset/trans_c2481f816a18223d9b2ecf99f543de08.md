
示例 4 限制限制指针之间赋值的规则不区分函数调用和异常，只有在嵌套块中声明的限制指针之间进行“从外到内”的赋值才具有定义行为。

```c
int * restrict p1;
int * restrict q1;
p1 = q1; // 未定义行为
{
    int * restrict p2 = p1; // 有效
    int * restrict q2 = q1; // 有效
    p1 = q2; // 未定义行为
    p2 = q2; // 未定义行为
}
```

异常允许限制指针的值在块执行结束时，带出其（或更准确地说，是用于指定它的标识符）被声明的块。例如，这允许 new_vector 返回一个向量。

```c
typedef struct { int n; float * restrict v; } vector;
vector new_vector(int n)
{
    vector t;
    t.n = n;
    t.v = malloc(n * sizeof(float));
    return t;
}
```

## 6.7.4 函数限定符

### 语法

```c
function-specifier:
inline
_Noturn
```

### 约束

函数限定符应仅用于函数标识符的声明。

具有外部链接的函数的内联（inline）定义不应包含具有静态或线程存储持续期的可修改对象的定义，且不应包含对具有内部链接标识符的引用。

在托管（hosted）环境中，main 的声明中不应出现函数限定符。

### 语义

函数限定符可以出现多次；其行为与出现一次相同。

用 `inline` 函数限定符声明的函数是内联函数。将函数标记为内联建议对该函数的调用将尽可能快。

此类建议的有效程度取决于实现（implementation-defined）。¹³⁹

任何具有外部链接的函数可以是内联函数。对于具有外部链接的函数，适用以下限制：如果使用 **inline** 函数限定符声明一个函数，则它也必须在同一个翻译单元中定义。如果一个翻译单元中某个函数的所有文件声明都包含 **inline** 函数限定符且没有 **extern**，则该翻译单元中的定义是*内联*的。内联定义不为函数提供外部定义，也不禁止在另一个翻译单元中进行外部定义。内联定义提供了外部定义的替代方案，翻译器可以使用它来实现同一翻译单元内对该函数的任何调用。对函数的调用是使用内联定义还是外部定义是未指定的。¹⁴⁰

用 `_noreturn` 函数限定符声明的函数不应返回其调用者。

## **推荐做法**

对于一个用 `_Noreturn` 函数限定符声明、且似乎能够返回其调用者的函数，实现应对其产生一个诊断消息。

示例 1 具有外部链接的内联函数的声明可以导致外部定义，也可以导致仅在翻译单元内可用的定义。带有 **extern** 的文件范围声明创建一个外部定义。此示例显示了整个翻译单元。

```c
inline double f(double t)
{
    return (9.0 * t) / 5.0 + 32.0;
}
inline double cells(double t)
{
    return (5.0 * (t - 32.0)) / 9.0;
}
extern double jahr(double); // 创建外部定义
```

138) 通过使用（例如）通常函数调用机制的替代方案，例如“内联替换”。内联替换不是文本上的，也不会创建一个新函数。因此，例如，在函数体内部使用的宏的扩展使用的是该函数体出现时具有的定义，而不是调用函数时的定义；且标识符指的是函数体发生处作用域内的声明。无论除外部定义外发生了多少次内联定义，该函数都有唯一的地址。

139) 例如，某种实现可能永远不执行内联替换，或者可能只对 **inline** 声明的作用域执行内联替换。

140) 由于内联定义区别于相应的外部定义并区别于其他翻译单元中的任何其他内联定义，所有具有静态存储持续期的对应对象在每个定义中也是不同的。

```c
double convert (int is_fahr, double temp)
{
    /* 翻译器执行内联替换 */
    return is_fahr ? cels(temp) : fahr(temp);
}
```

注意 fahr 的定义是一个外部定义，因为 fahr 是用 extern 声明的，但 cels 的定义是内联定义。由于 cels 具有外部链接并被引用，必须在另一个翻译单元中出现外部定义（见 6.9）；内联定义和外部定义是不同的，并可用于调用。

## 6.7.5 对齐实验

### 语法

```c
+ alignment-specifier:
__Alignas ( type-name ))
__Alignas ( constant-expression )
```

### 约束

在 typedef、位域、函数、参数或用 register 存储持续期声明的对象的声明中，不应指定对齐属性。

在 typedef、位域、函数、参数或用 register 存储持续期声明的对象的声明中，不应指定对齐属性。

在 typedef、位域、函数、参数或用 register 存储持续期声明的对象的声明中，指定对齐属性。

### 语义

常量表达式应是一个整数表达式。对象的对齐要求由同一声明中的对齐属性指定。

如果，在声明 **T D1** 中，**D1** 的形式为

```c
Alignas ( constant-expression )
```

则 ident 的类型由声明 **T (constant-expression)** 指定。因此，括号中的声明符与无括号的声明符相同，但复杂声明符的绑定可能会被括号改变。

## 6.7.6 声明符

### 语法

```c
declarator:
    pointer_opt
direct-declarator:
    identifier
    ( declarator )
    direct-declarator [ expression-opt ]
    direct-declarator [ static ]
    direct-declarator ( parameter-type-list )
pointer:
    * type-qualifier-list_opt
type-qualifier-list:
    type-qualifier
    type-qualifier type-qualifier
parameter-type-list:
    parameter-list
    parameter-list , ...
-list:

identifier
identifier-list , identifier
```

### 语义

每个声明符声明一个标识符，并断言当与声明符相同的操作数出现在表达式中时，它指定由限定符指示的作用、存储持续期和类型。

声明符是不属于另一个声明符的声明符。完整声明符的结束是一个序列点。如果在完整声明符的嵌套声明符序列中存在一个指定变长度类型的声明符，则完整声明符指定的类型被称为是*变修改的*。此外，任何通过声明符从变修改类型派生的类型本身也是变修改的。

在以下子句中，考虑声明

```c
T D1
```

其中 T 包含指定类型（如 **int**）的限定符，且 **D1** 是包含标识符 *ident* 的声明符。在各种声明符形式中标识符指定的类型通过这种归纳方式描述。

如果，在声明 **T D1** 中，**D1** 的形式为

```c
ident
```

则 *ident* 指定的类型为 T。

如果，在声明 **T D1** 中，**D1** 的形式为

```c
( D )
```

则 ident 的类型由声明 **T D** 指定。因此，括号中的声明符与无括号的声明符相同，但复杂声明符的绑定可能会被括号改变。
