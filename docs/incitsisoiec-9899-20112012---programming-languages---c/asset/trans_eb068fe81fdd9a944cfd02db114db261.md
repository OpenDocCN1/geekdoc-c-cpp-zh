### J.5 扩展

在许多系统中广泛使用的扩展，但不具有移植性。

5.1 环境参数

在宿主主环境中，`main` 函数接收一个指向指针数组的 `char *envp[]`。

5.2 特殊标识符

下划线、字母和数字以外的字符（如美元符号 `$`）可能出现在标识符中 (6.4.2)。

5.3 长度

标识符的大小是区分大小的 (6.4.2)。

5.4 作用域

具有文件作用域的函数标识符或对象声明 (6.2.1)。

5.5 字符串字面量

字符串字面量是可变的（在这种情况下，相同的字面量表示不同的对象） (6.4.5)。

5.6 其它算术类型

附加的算术类型，例如 `__int128` 或 `double double`，以及相应的转换 (6.2.5, 6.3.1)。额外的浮点类型可能比 `long double` 具有范围或精度，并可用于计算其他浮点类型的表达式，并用于定义 `float_t` 或 `double_t`。额外的浮点类型也可能比 `float` 具有更小的范围或精度。

5.7 函数指针转换

指向对象或 void 的指针可以转换为函数指针，允许数据作为函数调用 (6.5.4)。

指向函数的指针可以转换为指向对象或 void 的指针，允许对函数进行检查或修改（例如通过调试器） (6.5.4)。

5.8扩展位域类型

位域可以使用 `_Bool`、`unsigned int` 或 `signed int` 以外的类型声明，并具有适当宽度 (6.7.2.1)。

5.9 `fortran` 关键字

在函数声明中可以使用 `fortran` 函数限定符，以指示生成适用于 FORTRAN 的调用，或者为外部名生成不同的表示 (6.7.4)。

5.10 `asm` 关键字

`asm` 关键字可用于将汇编语言直接插入翻译器的输出 (6.8)。最常见的实现是通过形式如下语句：

```
asm ( character-string-literal )
```

5.11 多重外部定义

标识符可以有多个外部定义，或者没有显式使用 `extern` 关键字；如果定义不一致或有多个初始化，行为是未定义的 (6.9.2)。
