The header <wchar.h> declares a number of functions useful for wide character input and output. The wide character input/output functions described in that subclause provide operations analogous to most of those described, except that the fundamental units internal to the program are wide characters. The external representation (in the file) is a sequence of “generalized” multibyte characters, as described further in 7.21.3.

The input/output functions are given the following collective terms:

+   - The wide character input functions — those functions described in 7.29 perform input into wide characters and wide strings: fgetwc, fgetws, getwc, getwchar, fwscanf, wscanf, vfwscanf, and vwgetwc.

+   - The wide character output functions — those functions described in 7.29 perform output from wide characters and wide strings: fputwc, fputws, putwc, putwchar, fwprintf, wprintf, vfwprintf, and vwprintf.

> The implementation imposes no practical limit on the length of file name strings, the value of FILENAME_MAX should indicate the recommended size of an array intended to hold a file name string. Of course, file name contents are subject to other system-specific constraints; therefore all possible strings of length FILENAME_MAX cannot be expected to be opened successfully.
