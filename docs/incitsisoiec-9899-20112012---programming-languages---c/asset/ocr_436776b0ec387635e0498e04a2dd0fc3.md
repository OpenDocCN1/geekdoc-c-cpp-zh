# K.3.9.2 General wide string utilities

# K.3.9.2.1 Wide string copying functions

# K.3.9.2.1.1 The wcscpy_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__
#include <wchar.h>
errno_t wcscpy_s(wchar_t * restrict s1,
size_t smax,
const wchar_t * restrict s2);
```

# Runtime-constraints

Neither s1 nor s2 shall be a null pointer. smax shall not be greater than RSIZE_MAX. smax shall not equal zero. smax shall be greater than wcsnlen_s(s2, smax). Copying shall not take place between objects that overlap.

If there is a runtime-constraint violation, then if s1 is not a null pointer and smax is greater than zero and not greater than RSIZE_MAX, then wcscpy_s sets s1[0] to the null character.

# Description

The wcscpy_s function copies the wide string pointed to s2 (including the terminating null character) into the array pointed to by s1.

All elements following the terminating null character (if any) written by wcscpy_s in the array of smax wide characters pointed to by s1 take unspecified values when wcscpy_s returns.442

# Returns

The wcscpy_s function returns zero^{443} if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

> 442) This allows an implementation to copy wide characters from s2 to s1 while simultaneously checking if any of the wide characters are null. Such an approach might write a wide character to every element of s1 before discovering that the first element should be set to the null character.

> 443) A zero return value implies all of the requested wide characters from the string pointed to by s2 fit within the array pointed to by s1 and the result in s1 is null terminated.
