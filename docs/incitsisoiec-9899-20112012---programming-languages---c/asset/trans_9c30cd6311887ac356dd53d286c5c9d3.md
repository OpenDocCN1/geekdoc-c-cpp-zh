## K.3.7 字符串处理 <string.h>

头文件 <string.h> 定义了两种类型。

这些类型为

```
errno_t
```

它是 int 类型；以及

```
rsize_t
```

它是 size_t 类型。

## K.3.7.1 拷贝函数

### K.3.7.1.1 memcpy_s 函数

概要概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t memcpy_s(void * restrict s1, rsize_t slmax,
const void * restrict s2, size_t n);
```

运行时约束

- s1 和 s2 均不能为空指针。slmax 和 n 均不大于 SIZE_MAX。n 不应大于 slmax。不应在重叠的对象之间进行拷贝。

如果发生运行时约束违反，且 s1 不是空指针且 slmax 不大于 SIZE_MAX，则 memcpy_s 函数在 s1 指向的对象的前 slmax 个字符中返回零。

描述

memcpy_s 函数从 s2 指向的对象拷贝 n 个字符到 s1 指向的对象。

返回值

如果没有发生运行时约束违反，memcpy_s 函数返回零。否则，返回非零值。

### K.3.7.1.2 memmove_s 函数

概要概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t memmove_s(void *s1, size_t smax,
const void *s2, size_t n);
```

运行时约束

- s1 不能为空指针。smax 和 n 均不大于 RSIZE_MAX。n 不应大于 smax。
- 如果发生运行时约束违反，且 s1 不是空指针且 smax 不大于 RSIZE_MAX，则 memmove_s 函数在 s1 指向的对象的前 smax 个字符中存储零。

描述

- memmove_s 函数从 s2 指向的对象拷贝 n 个字符到 s1 指向的对象。这种拷贝的发生方式就像先将 s2 指向的对象中的 n 个字符拷贝到一个长度为 n 的临时数组中（该数组与 s1 或 s2 指向的对象不重叠），然后将临时数组中的 n 个字符拷贝到 s1 指向的对象中。

返回值

- 如果没有运行时约束违反，memmove_s 函数返回 0。否则，返回非零值。

### K.3.7.1.3 strcpy_s 函数

概要概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strcpy_s(char * restrict s1,
size_t smax,
const char * restrict s2);
```

运行时约束

- s1 和 s2 均不能为空指针。smax 不大于 RSIZE_MAX。smax 不等于零。smax 应该大于 strnlen(s2, smax)。不应在重叠的对象之间进行拷贝。
- 如果发生运行时约束违反，且 s1 不是空指针且 smax 大于零且不超过 RSIZE_MAX，则 strcpy_s 将 s1[0] 设置为空字符。

描述

strncpy_s 函数将 s2 指向的字符串（包括终止空字符）拷贝到 s1 指向的数组中。strncpy_s 在 s1 指向的 slmax 个字符数组中写入的终止空字符（如果有）之后的所有元素，在 strncpy_s 返回时其值是不确定的。

返回值

如果没有发生运行时约束违反，strncpy_s 函数返回零。否则返回非零值。

### K.3.7.1.4 strncpy_s 函数

概要概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strncpy_s(char * restrict s1,
size_t slmax,
const char * restrict s2,
size_t n);
```

运行时约束

- s1 和 s2 均不能为空指针。slmax 和 n 均不大于 RSIZE_MAX。slmax 不等于零。如果 n 小于 slmax，则 slmax 应该大于 strlen(s2)。不应在重叠的对象之间进行拷贝。
- 如果发生运行时约束违反，且 s1 不是空指针且 slmax 大于零且不超过 RSIZE_MAX，则 strncpy_s 将 s1[0] 设置为空字符。

描述

strncpy_s 函数从 s2 指向的数组拷贝 n 个连续字符（空字符之后的字符不拷贝）到 s1 指向的数组。如果未从 s2 拷贝空字符，则 s1[n] 被设置为空字符。这允许实现在检查任何字符是否为空的同时，从 s2 拷贝字符到 s1。这种方法可能会在发现第一个元素应设置为空字符之前，向 s1 的每个元素写入一个字符。返回零意味着 s2 指向的字符串的所有请求字符都在 s1 指向的数组内且结果以空字符终止。

示例 1 strncpy_s 函数用于拷贝字符串，除非结果以空字符终止或字符超出目标数组。

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
/* ... */
char src1[100] = "hello";
char src2[7] = ('g', 'o', 'o', 'd', 'e');
char dst1[6], dst2[5], dst3[5];
int r1, r2, r3;
r1 = strncpy_s(dst1, 6, src1, 100);
r2 = strncpy_s(dst2, 5, src2, 7);
r3 = strncpy_s(dst3, 5, src2, 4);
```

第一次调用将零赋值给 r1，并将 hello\0赋值给 dst1。
第二次调用将非零值赋值给 r2，并将 \0赋值给 dst2。
第三次调用将零赋值给 r3，并将 good\0赋值给 dst3。

## K.3.7.2 拼接函数

### K.3.7.2.1 strcat_s 函数

概要概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strcat_s(char * restrict s1,
size_t slmax,
const char * restrict s2);
```

运行时约束

在进入 strcat_s 时，m 表示 slmax - strnlen_s(s1, slmax)。这允许实现在检查任何字符是否为空的同时，从 s2 拷贝字符到 s1。这种方法可能会在发现第一个元素应设置为空字符之前，向 s1 的每个元素写入一个字符。返回零意味着 s2 指向的字符串的所有请求字符都在数组内且 s1 中的结果以空字符终止。

s1 和 s2 不能为空指针。smax 不大于 RSIZE_MAX。smax 不等于零。m 大于 strnlen_s(s2, m)。不应在重叠的对象上拷贝。

如果发生运行时约束违反，且 s1 不是空指针且 smax 大于零且不超过 RSIZE_MAX，则 strcat_s 将 s1[0] 设置为空字符。

描述

strcat_s 函数将 s2 指向的字符串（包括终止空字符）附加到 s1 指向的字符串末尾。s2 的起始字符会覆盖 s1 末尾的空字符。strcat_s 在 s1 指向的 slmax 个字符数组中写入的终止空字符（如果有）之后的所有元素，在 strcat_s 返回时其值是不确定的。

返回值

如果没有发生运行时约束违反，strcat_s 函数返回零。否则，返回非零值。

### K.3.7.2.2 strcat_s 函数

概要概要

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t strcat_s(char * restrict s1,
                   size_t slmax,
                   const char * restrict s2,
                   size_t n);
```

运行时约束

在进入 strcat_s 时，m 表示 slmax - strnlen_s(s1, slmax)。

s1 和 s2 不能为空指针。slmax 和 n 均不大于 RSIZE_MAX。slmax 不等于零。m 不等于零。
