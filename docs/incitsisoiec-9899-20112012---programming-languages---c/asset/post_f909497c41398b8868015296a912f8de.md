# K.3.7.3 Search functions

### K.3.7.3.1 The strtok_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__
#include <string.h>
char *strtok_s(char * restrict s1,
    size_t * restrict smax,
    const char * restrict s2,
    char ** restrict ptr);
```

# Runtime-constraints

- None of smax, s2, or ptr shall be a null pointer. If s1 is null the value of *smax shall not be greater than RSIZE_MAX. The end of the token found shall occur within the first *smax characters of s1 for the first call, and shall occur within the first *smax characters of searching resumes on subsequent calls.

- If there is a runtime violation, the strtok_s function does not indirect through the s1 or s2 pointers, and does not store a value in the object pointed to by ptr.

# Description

- A sequence of calls to the strtok_s breaks the string pointed to by s1 into a sequence of tokens, each of which is delimited by a character from the string pointed to by s2. The fourth argument is a caller-provided char pointer into which the strtok_s function stores information for it to continue the same string.

- The first call in a sequence has a non-null first argument and smax points to an object whose value is the number of elements in the character array pointed to by the first argument. The first call stores an initial value in the object pointed to by ptr and updates the value pointed to by smax to reflect the number of elements that remain in relation to ptr. Subsequent calls in the sequence have a first argument and the objects pointed to by smax and ptr are required to have the values stored by the previous call in the sequence, which are then updated. The separator pointed to by s2 may be different from call to call.

- The first call in the sequence searches the string pointed to by s1 for the first character that is not contained in the current string pointed to by s2. If no such character is found, there are no tokens in the string pointed to by s1 and the strtok_s function returns a null pointer. If such a character is found, it is the start of the first token.

The strtok_s function searches for the first character in s1 that is contained in the current string. If no such character is found, the current token extends to the string pointed to by s1, and subsequent searches in the string for a token return a null pointer. If such a character is found, it is overwritten by a null character, which terminates the current token.

In all cases, the strtok_s function returns sufficient information in the pointer pointed to by ptr that subsequent calls, with a null pointer for s1 and the unmodified pointer value for ptr, shall start searching just past the element overwritten by a null character (if any).

# Returns

The strtok_s function returns a pointer to the first character of a token, or a null pointer if there is no token or a runtime-constraint violation.

# K.3.7.4.2 The strerror_s function

# Synopsis

```

```

# Runtime-constraints

s shall be a null pointer. maxsize shall not be greater than RSIZE_MAX. maxsize shall not equal zero.

If there is a runtime-constraint violation, the array (if any) pointed to s is not modified.

# Description

The strerror_s function maps the number in errno to a locale-specific string. Typically, the values map any value of int to a message.

If the length of the desired string is less than maxsize, then the string is copied to the array pointed to s.

# Returns

The strerror_s function returns zero if the length of the desired string was less than maxsize and there was no runtime-constraint violation. Otherwise, the strerror_s returns a nonzero value.
