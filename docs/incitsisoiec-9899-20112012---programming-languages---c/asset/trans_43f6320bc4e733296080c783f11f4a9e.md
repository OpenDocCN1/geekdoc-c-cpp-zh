
尾随空格（包括换行符）除非被指令匹配，否则将保留。字面量匹配和抑制赋值的成功与否除了 `%n` 指令外，无法直接确定。

# 返回值

如果在第一次转换（任何）完成之前发生输入失败，`fscanf` 函数返回宏 `EOF` 的值。否则，该函数返回赋值的输入项目数量；在提前匹配失败的情况下，该数量少于提供的数量，甚至为零。

示例 1 运行：

```
#include <stdio.h>
/* ... */
int n, i; float x; char name[50];
n = fscanf(stdin, "%d%f%s", &i, &x, name);
```

配合输入：

```
25 54.32-E1 thompson
```

将将值 3 赋值给 n，给 i 赋值值 25，给 x 赋值值 5.432，给 name 赋值序列 thompson\0。

示例 2 调用：

```c
#include <stdio.h>
/* ... */
int i; float x; char name[50];
fscanf(stdin, "%d%f*d %[0123456789]", &i, &x, name);
```

配合输入：

```
56789 0123 56a72
```

将给 i 赋值值 56，给 x 赋值值 789.0，并给 name 赋值序列 56\0。从输入流中读取的下一个字符将是 a。

示例 3 为了从 `stdin` 重复读取数量、计量单位和项目名称：

```c
#include <stdio.h>
/* ... */
int count; float quant; char units[21], item[21];
d {
    count = fscanf(stdin, "%d%20s of %20s", &count, units, item);
    fscanf(stdin, "%*[^\n]");
} (!feof(stdin) && !ferror(stdin));
```

如果 `stdin` 流包含以下行：

- 2 quarts of oil
- 12.8degrees Celsius
- lots of luck
- 10.0LBS of
- dirt
- 100ergs of energy

上述示例的执行将类似于以下赋值：

```
quant = 2; strcpy(units, "quotes"); strcpy(item, "oil");
count = 3;
quant = -12.8; strcpy(units, "degrees");
count = 2; // "C" 无法匹配 "o"
count = 0; // "1" 无法匹配 "%f"
quant = 10.0; strcpy(units, "LBS"); strcpy(item, "dirt");
count = 3;
count = 0; // "100e" 无法匹配 "%f"
count = EOF;
```

# 示例 4 输入：

```c
#include <stdio.h>
/* ... */
int d1, d2, n1, n2, i;
i = scanf("123", "%d%n%d", &d1, &n1, &n2, &d2);
```

值 123 被赋值给 d1，值赋值给 n1。因为 `%n` 永远不会导致输入失败，值 3 也被赋值给 n2。d2 的值不受影响。值 1 被赋值给 i。

# 示例 5 调用：

```c
#include <stdio.h>
/* ... */
int n, i;
n = scanf("foo % bar 42", "foo%%bar%d", &i);
```

将值 1 赋值给 n，将值 42 赋值给 i，因为输入空白字符在 `%` 和 `d` 转换序列中都会被跳过。

示例 6 在这些示例中，多字节字符确实具有状态相关编码，扩展字符集的成员由多个字节组成，恰好由两个字节组成，第一个由 `a` 表示，第二个由大写字母表示，但只有在交替移位状态下才会被识别。移位序列由 ↑ 和 ↓ 表示，其中第一个进入交替移位状态。

调用后：

```c
#include <stdio.h>
/* ... */
char str[50];
canf(stdin, "%s", str);
```

配合输入：

a↑↓ bc
str 将包含 ↑↓↓，假设没有任何移位序列（或在更通用的情况下为多字节字符）看起来是单字节空白字符。

相比之下，调用后：

```c
#include <stdio.h>
#include <stddef.h>
/* */
char_t wstr[50];
fscanf(stdin, "%als", wstr);
```

配合相同的输入，wstr 将包含对应于 □ 和 Y 的两个宽字符以及一个终止空字符。

然而，调用：

```c
#include <stdio.h>
#include <stddef.h>
/* */
char_t wstr[50];
fscanf(stdin, "%a□X%ls", wstr);
```

配合相同的输入行将由于与格式化字符串中的 ↓ 序列匹配失败而返回零。

假设多字节字符 □ 的第一个字节与多字节字符 □ 的第一个字节相同，调用后：

```c
#include <stdio.h>
#include <stddef.h>
/* */
char_t wstr[50];
fscanf(stdin, "%a□Y%ls", wstr);
```

配合相同的输入行，将再次返回零，但 `stdin` 将留下一个部分消耗的多字节字符。

# 7.21.6.5 sprintf 函数

# 概要

```c
#include <stdio.h>
int sprintf(char * restrict s, size_t n, const char * restrict format, ...);
```

# 描述

sprintf 函数等同于 fprintf，其在参数之前插入了 `s` 作为参数。如果 `n` 为零，则不写入任何内容。否则，n-1 之外的将被丢弃而不是写入数组。如果在重叠的对象之间发生拷贝，行为是未定义的。

# 返回值

sprintf 函数返回如果 `n` 足够大时将写入的字符数（不计空字符），或者如果发生编码错误则返回负值。因此，仅当返回值为非负且小于 `n` 时，空终止的输出才完全写入。

# 7.21.6.6 sprintf 函数

# 概要

```c
#include <stdio.h>
int sprintf(char * restrict s, const char * restrict format, ...);
```

# 描述

sprintf 函数等同于 fprintf，其在参数之前插入了 `s` 作为参数。字符末尾写入空字符；它不计入返回值。如果在重叠的对象之间发生拷贝，行为是未定义的。

# 返回值

sprintf 函数返回写入数组的字符数（不计空字符），或者如果发生编码错误则返回负值。

# 7.21.6.7 sscanf 函数
