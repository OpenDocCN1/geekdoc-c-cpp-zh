# 6.8.4 Selection statements

# Syntax

```
selection-statement:
if ( expression ) statement
if ( expression ) statement else statement
switch ( expression ) statement
```

# Semantics

A selection statement selects among a set of statements depending on the value of a controlling expression.

A selection statement is a block whose scope is a strict subset of the scope of its enclosing block. Each substatement is also a block whose scope is a strict subset of the scope of the selection statement.
