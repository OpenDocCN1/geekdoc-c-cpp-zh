array whose first element is pointed to by s. Most MB_CUR_MAX bytes are stored. If c16 is a wide character, a null byte is stored, preceded by any shift sequence needed to restore the initial shift state; the resulting state described is the initial conversion state.

# Returns

The c16rtomb returns the number of bytes stored in the array (including any shift sequences). When c16 is not a valid wide character, an encoding error occurs: the function sets the value of the macro EILSEQ in errno and returns (size_t) (-1); the conversion state is unspecified.

# 7.28.1.3 The mbtorc32 function

# Synopsis

```
#include <uchar.h>
size_t mbtorc32(char32_t * restrict pc32,
const char * restrict s, size_t n,
mbstate_t * restrict ps);
```

# Description

If s is a null pointer, the mbtorc32 function is equivalent to the call:

```
mbtorc32 (NULL, "", 1, ps);
```

In this case, the values of the parameters pc32 and n are ignored.

If s is not a null pointer, the mbtorc32 function inspects at most n bytes beginning with the byte pointed to by s to determine the number of bytes needed to complete the next multibyte character (including any shift sequences). If the function determines the next multibyte character is complete and valid, it determines the values of the corresponding wide characters and then, if pc32 is not a null pointer, it stores the value of the first (or only) character in the object pointed to by pc32. Subsequent calls will store wide characters without consuming any additional input until the characters have been stored. If the corresponding wide character is the null wide character, the resulting state described is the initial conversion state.

# Returns

The mbtorc32 function returns the first of the following that applies (given the current conversion state):

+   if the next n or fewer bytes complete the multibyte character that corresponds to the null wide character (which is the value stored).

+   between 1 and n inclusive if the next n or fewer bytes complete a valid multibyte character (which is the value stored); the value returned is the number of bytes that complete the multibyte character.
