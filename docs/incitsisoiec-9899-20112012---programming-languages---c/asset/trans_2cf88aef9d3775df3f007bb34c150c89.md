

## 7.24.6.3 strlen 函数

用法概要

```
#include <string.h>
size_t strlen(const char *s);
```

描述

`strlen` 函数计算由 `s` 指向的字符串的长度。

返回值

`strlen` 函数返回终止空字符字符之前的字符数。

## 7.25 类型泛型数学库 <tgmath.h>

1 头文件 `<tgmath.h>` 包含了 `<math.h>` 和 `<complex.h>`，并定义了几个类型泛型宏。

2 在 `<math.h>` 和 `<complex.h>` 函数中，如果不带 `f` (float) 或 `l` (long double) 后缀，其中几个函数具有一个或多个实数类型为 `double` 的参数。对于 `modf` 之外的每个函数，都有一个对应的类型泛型宏。(313) 在函数概要中对应的实数类型为 `double` 的参数是泛型参数。使用该宏会调用一个函数，其对应的实数类型和类型域由泛型参数的参数决定。(314)

3 使用该宏会调用一个函数，其泛型参数对应的实数类型确定如下：

- 首先，如果泛型参数的任何参数类型为 `long double`，则确定的类型为 `long double`。
- 否则，如果泛型参数的任何参数类型为 `double` 或整数类型，则确定的类型为 `double`。
- 否则，确定的类型为 `float`。

4 对于 `<math.h>` 中没有后缀的函数，如果 `<complex.h>` 中存在一个除 `c` 前缀外同名的函数，则对应的类型泛型宏（针对两个函数）的名称与 `<math.h>` 中的函数名称相同。`fabs` 和 `cabs` 对应的类型泛型宏均为 `fabs`。

313 像标准库中的其他函数宏一样，每个类型泛型宏都可以被抑制，以提供对应的普通函数。

314 如果参数的类型与所选函数的参数类型不兼容，则行为未定义。

对于 `<math.h>` 中在 `<complex.h>` 中没有 `c` 前缀对应项的无后缀函数（`modf` 除外），对应的类型泛型宏与函数同名。这些类型泛型宏为：

如果所有泛型参数的参数都是实数，则使用该宏会调用实数函数；否则，使用该宏将导致未定义行为。

对于 `<complex.h>` 中不是 `<math.h>` 函数 `c` 前缀对应项的未指定函数，对应的类型泛型宏与函数同名。这些类型泛型宏为：

```
carg conj creal
cimag cproj
```

使用任何实数或复数参数使用该宏都会调用复数函数。

示例 假设有以下声明

```
#include <tgmath.h>
int n;
float f;
double d;
long double ld;
float complex fc;
double complex dc;
long double complex ldc;
```
