# 7.21.6 Formatted input/output functions

1 The formatted input/output functions behave as if there is a sequence point after the actions associated with each specifier.²274

# 7.21.6.1 The fprintf function

# Synopsis

```
#include <stdio.h>
int fprintf(FILE * restrict stream,
const char * restrict format, ...);
```

# Description

2 The fprintf function writes to the stream pointed to by stream, under control of the string pointed by format that specifies which subsequent arguments are converted for output. If there are insufficient arguments for the format, the behavior is undefined. If the format is exhausted while arguments remain, the excess arguments are evaluated (as always) but are otherwise ignored. The fprintf returns when the end of the format string is encountered.

3 The format shall be a multibyte character sequence, beginning and ending in its initial shift state. The format is composed of zero or more directives: ordinary multibyte characters (not %), which are copied unchanged to the output stream; and conversion specifications, each of which results in fetching zero or more subsequent arguments, converting them, if applicable, to the corresponding conversion specifier, and writing the result to the output stream.

4 Each conversion specification is introduced by the character %. After the %, the following appear in sequence:

+   — Zero or more flags (in any order) that modify the meaning of the conversion specification.

+   — An minimum field width. If the converted value has fewer characters than the field width, it is padded with spaces (by default) on the left (or right, if the adjustment flag, described later, has been given) to the field width. The field width takes the form of an asterisk * (described later) or a nonnegative decimal integer.²275

+   — An optional precision gives the minimum number of digits to appear for the d, o, u, x and X conversions, the number of digits to appear after the decimal-point character for a, A, E, f, and F conversions, the maximum number of significant digits for the g and G conversions, or the maximum number of bytes to be written for
