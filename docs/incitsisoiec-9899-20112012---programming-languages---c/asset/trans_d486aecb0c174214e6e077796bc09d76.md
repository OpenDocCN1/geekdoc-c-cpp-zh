## 6.5.2.4 后缀递增和减运算符

## 约束

+   后缀递增或减运算符的操作数应具有原子、限定或未限定的引用或指针类型，并且必须是可修改左值（lvalue）。

## 语义

+   后缀 `++` 运算符的结果是操作数的值。作为副作用，操作对象的值会增加（即对其加上相应类型的数值 1）。参见关于加法运算符和复合赋值的讨论，以获取有关约束、类型、转换以及操作对指针影响的信息。结果的值计算在更新操作数存储值的副作用之前按顺序执行。对于具有不确定性执行顺序的函数调用，后缀 `++` 的操作是单次求值。对原子类型对象的后缀 `++` 是一个具有 `memory_order_seq_cst` 内存语义的读-修改-写操作。

+   后缀 `--` 运算符类似于后缀 `++` 运算符，不同之处操作数的值减少（即对其减去相应类型的数值 1）。

前向引用：加法运算符 (6.5.6)，复合赋值 (6.5.16.2)。
