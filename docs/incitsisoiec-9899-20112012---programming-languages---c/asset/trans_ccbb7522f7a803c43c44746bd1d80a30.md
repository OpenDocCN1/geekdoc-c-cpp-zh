

```c
#include <stdio.h>
#include <time.h>
static const char wday[] = {
    "Sunday", "Monday", "Tuesday", "Wednesday",
    "Thursday", "Friday", "Saturday", "-unknown-"
};
struct tm time_str;
/* ... ... */
time_str.tm_year = 2001 - 1900;
time_str.tm_mday = 7;
time_str.tm_mon = 4;
```

## 7.27.2.4 time 函数

### 概要

```c
#include <time.h>
time_t time(time_t *timer);
```

### 描述

time 函数确定当前的日历时间。该值的编码方式未指定。

### 返回值

time 函数返回实现对当前日历时间的最佳近似值。如果无法获取日历时间，则返回值 (time_t) (-1)。如果 timer 不是空指针，则返回值也会赋值给它所指向的对象。

## 7.27.2.5 timespec_get 函数

### 概要

```c
#include <time.h>
timespec_get(struct timespec *ts, int base);
```

### 描述

timespec_get 函数设置 ts 指向的间隔，使其根据指定的 base 存储当前日历时间。

如果 base 为 TIME_UTC，则 tv_sec 成员被设置为自实现定义的纪元（epoch）以来的秒数，并截断为整数；tv_nsec 成员被设置为整数纳秒数，并根据系统时钟分辨率进行四舍五入。

### 返回值

如果 timespec_get 函数成功，则返回非零值 base；否则返回零。

## 7.27.3 时间转换函数

除了 strftime 函数外，这些函数每个返回指向两种静态对象之一的指针：分解时间结构（broken-down time structure）或字符数组。执行任何返回指向其中一种对象类型指针的函数，可能会覆盖之前对其中任何一个函数调用返回的值所指向的相同类型对象中的信息，且这些函数不需要避免彼此之间的数据竞态。实现的行为应当类似于没有其他库函数调用了这些函数。

## 7.27.3.1 asctime 函数

### 概要

```c
#include <time.h>
char asctime(const struct tm *timeptr);
```

### 描述

asctime 函数将 timeptr 指向的结构中的分解时间转换为如下字符串：

```
Sun Sep 16 01:03:52 1973\n\0
```
使用以下等效算法。

```c
char asctime(const struct tm *timeptr)
{
    static const char wday_name[7] [3] = {
        "Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"
    };
    static const char mon_name[12] [3] = {
        "Jan", "Feb", "Mar", "Apr", "May", "Jun",
        "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
    };
    static const char result[26];
```
```c
sprintf(result, "%3s %3s%3d:%2d:%2d:%2d %2d\n",
    day_name[timeptr->tm_wday],
    mon_name[timeptr->tm_mon],
    timeptr->tm_mday, timeptr->tm_hour,
    timeptr->tm_min, timeptr->tm_sec,
    1900 + timeptr->tm_year);
return result;
```
如果分解时间的任何成员包含超出其范围的值，则 asctime 函数的行为是未定义的。同样，如果计算出的年份超过四位数或小于 1000，其行为也是未定义的。

### 返回值

asctime 函数返回指向字符串的指针。

## 7.27.3.2 ctime 函数

### 概要

```c
#include <time.h>
char *ctime(const time_t *timer);
```

### 描述

ctime 函数将 timer 指向的日历时间转换为字符串形式的本地时间。它等同于 `asctime(localtime(timer))`。

### 返回值

ctime 函数返回以分解时间作为参数的 asctime 的返回值。向前引用：localtime 函数 (7.27.3.4)。

## 7.27.3.4 localtime 函数

### 概要

```c
#include <time.h>
struct tm *localtime(const time_t *timer);
```

### 描述

localtime 函数将 timer 指向的日历时间转换为以本地时间表示的分解时间。

### 返回值

localtime 函数返回指向分解时间的指针，如果指定的时间无法转换为本地时间，则返回空指针。

## 7.27.3.5 strftime 函数

### 概要

```c
#include <time.h>
size_t strftime(char *restrict s, size_t maxsize, const char *restrict format, const struct tm *restrict timeptr);
```

### 描述

strftime 函数根据 format 指向的字符串将字符放入 s 指向的数组中。format 应该是多字节字符序列，起始并结束于其初始状态。格式字符串由零或多个转换说明符和普通多字节字符组成。转换说明符由一个 % 字符、随后可能跟着 E 或 O 修饰符（下文描述）、以及一个决定转换行为的字符组成。所有多字节字符（包括终止空字符）都原封不动地复制到数组中。如果在重叠的对象之间进行拷贝，则行为是未定义的。放入数组的字符不超过 maxsize。每个转换说明符被替换为后续列表中描述的适当字符。适当字符取决于当前区域区域的 LC_TIME 类别以及 timeptr 指向的分解时间结构中的零或多个值（如描述中括号中所示）。如果任何指定值超出区域范围，则字符是未指定的。

- %a 被替换为区域的缩写星期名称。[tm_wday]
- %A 被替换为区域的完整星期名称。[tm_wday]
- %b 被替换为区域的缩写月份名称。[tm_mon]
- %B 被替换为区域的完整月份名称。[tm_mon]
- %c 被替换为区域适当的日期和时间表示。[7.27.1 中指定的所有内容]
- %C 被替换为年份除以 100 并截断为整数。[tm_year]
- %d 被替换为日期数字（0–31）。[tm_mday]
- %D 等于 "%m/%d/%Y"。[tm_mon, tm_mday, tm_year]
- %e 被替换为日期数字（1–31），前面有一个空格。[tm_mday]
- %F 被替换为 "Y-%m-%d"（ISO 8601 日期格式）。[tm_year, tm_mon, tm_mday]
- %g 被替换为周年份（见下文）的两位数字（00–99）。[tm_year, tm_wday, tm_yday]
- %V 被替换为周年份（见下文），例如1997。
- %G 等于 "%b".[tm_mon]
- %H 被替换为24小时制的小时（00–23）。[tm_hour]
- %I 被替换为12小时制的小时（01–12）。[tm_hour]
- %j 被替换为一年中的天数（001–366）。[tm_yday]
- %m 被替换为月份数字（01–12）。[tm_mon]
- %M 被替换为分钟数字（00–59）。[tm_min]
- %n 被替换为换行符。
- %p 被替换为与12小时制对应的区域AM/PM标记。[tm_hour]
- %r 被替换为区域12小时制时间。[tm_hour, tm_min, tm_sec]
- %R 等于 "%H:%M"。tm_hour, tm_min
- %S 被替换为秒数字（00–60）。[tm_sec]
- %t 被替换为制表符。
- %T 等于 "%H:%M:%S"（ISO 8601 时间格式）。[tm_hour, tm_min, tm_sec]
- %u 被替换为ISO 8601星期数字（1–7），其中周一为1。[tm_wday]
- %U 被替换为一年中的周（以第一个星期日为第一周的第一天），数字（00–53）。[tm_year, tm_wday, tm_yday]

321) 虽然 struct timespec 对象描述具有纳秒分辨率的时间，但可用分辨率取决于系统，甚至可能大于1秒。

322) 避免数据竞态的替代时间转换函数在 K.3.8.2 中指定。
