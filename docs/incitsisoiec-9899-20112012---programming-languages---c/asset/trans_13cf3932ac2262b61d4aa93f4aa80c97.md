## 7.12.10 余数函数

### 7.12.10.1 fmod 函数

概要

```c
#include <math.h>
double fmod(double x, double y);
float fmodf(float x, float y);
long double fmodl(long double x, long double y);
```

描述

`fmod` 函数计算 x/y 的浮点余数。

返回值

`fmod` 函数返回值 $x - ny$，对于某个整数 $n$，使得如果 $y$ 不为零，则结果与 $x$ 符号相同且幅度小于 $y$ 的幅度。如果 $y$ 为零，则发生域错误，或 `fmod` 函数返回零取决于实现。

### 7.12.10.2 remainder 函数

概要

```c
#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
```

描述

`remainder` 函数计算 x/y 的余数。当 $y \neq 0$ 时，余数 $r = x - ny$，其中 $n$ 是使得 $|r| \le |y|/2$ 的整数。如果 $|r| = |y|/2$，则 $r$ 的符号与 $x$ 相同。

返回值

`remainder` 函数返回余数值。

### 7.12.10.3 remquo 函数

概要

```c
#include <math.h>
double remquo(double x, double y);
float remquof(float x, float y);
long double remqol(long double x, long double y);
```

描述

`remquo` 函数计算 x/y 的余数。指向 `quo` 的对象存储整数商 $n$。结果是一个模 $y$ 同于 $x$ 且符号与 $x$ 相同的值。

返回值

`remquo` 函数返回余数。如果 $y$ 为零，则发生域错误或返回零取决于实现。

### 7.12.11.3 nextafter 函数

概要

```c
#include <math.h>
double nextafter(double x, float y);
float nextafter(float x, float y);
long double nextafter(long double x, long double y);
```

描述

`nextafter` 函数确定在 $y$ 的方向上 $x$ 之后在该类型中的下一个可表示值，其中 $x$ 和 $y$ 首先被转换为该类型。如果 $x$ 等于 $y$，`nextafter` 函数返回 $y$。如果 $x$ 的幅度是该类型允许的最大有限值且结果是无穷大或在该类型中不可表示，则可能会发生范围错误。

返回值

`nextafter` 函数返回指定格式下 $x$ 之后沿 $y$ 方向的下一个可表示值。
