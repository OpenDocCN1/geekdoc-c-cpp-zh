4 If there is a runtime-constraint violation, if s1 is not a pointer and smax is greater than zero and not greater than RSIZE_MAX, strcat_s sets s1[0] to the null character.

# Description

5 The strcat_s function appends not more than n successive characters (characters that follow a null are not copied) from the array to s2 to the end of the string pointed to s1. The initial character from s2 overwrites the null character at the end of s1. If no null character was copied from s2, s1[slmax-m+n] is set to a null character.

6 All elements following the terminating null character (if any) written by strcat_s in the array of slmax characters pointed to s1 take unspecified values when strcat_s returns.426)

# Returns

7 The strcat_s function returns zero^{427} if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

8 EXAMPLE 1 strcat_s function can be used to copy a string without the danger that the result will not be terminated or that it will the end of the destination array.

```
#define _STDC_WANT_LIB_EXT1__ 1
#include <string.h>
/* ... */
char s1[1000] = "good";
char s2[6] = "hello";
char s3[6] = "hello";
char s4[7] = "abc";
char s5[1000] = "bye";
int r1, r2, r3, r4;
r1 = strcat_s(s1, 100, s5, 1000);
r2 = strcat_s(s2, "", 1);
r3 = strcat_s(s3, "X", 2);
r4 = strcat_s(s4, 7, "defghijklmn", 3);
```

> 425) Zero means that s1 was not terminated upon entry to strcat_s.

> 426) This allows an implementation to append characters from s2 to s1 while simultaneously checking if any of those characters are null. Such an approach might write a character to every element of s1 before discovering that the first element is set to the null character.

> 427) A return value value implies that any of the requested characters from the string pointed to s2 were appended to the string pointed to by s1 and that the result in s1 is null terminated.
