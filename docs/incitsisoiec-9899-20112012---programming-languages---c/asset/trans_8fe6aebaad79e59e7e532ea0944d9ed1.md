
终止空零宽字符。如果指定了精度，则写入的宽字符数不超过该精度。如果未指定精度或精度大于转换数组的大小，则转换后的数组应包含一个空零宽字符。

如果存在 l1 长度修饰符，则参数应为指向 `wchar_t` 类型数组起始元素的指针。从数组中写入宽字符，直到（但不包括）终止空零字符。如果指定了精度，则写入的宽字符数不超过该精度。如果未指定精度或精度大于数组的大小，则数组应包含一个空零宽字符。

参数应为指向 `void` 的指针。指针的值以实现定义的方式转换为一组打印的宽字符序列。

参数应为指向符号整数的指针，该整数表示到此调用 `fprintf` 为止已向输出流写入的宽字符数。不对参数进行转换，但会消耗一个参数。如果转换规范包含任何标志、字段宽度或精度，则行为是未定义的。

写入一个 `%` 宽字符。不进行任何参数转换。整个转换规范应为 `%%`。

如果转换规范无效，行为是未定义的.³335) 如果任何参数的类型与相应的转换规范不匹配，行为是未定义的。

在不存在或较小的字段宽度导致字段被截断的情况下；如果转换结果比字段宽度宽，则该字段将扩展以包含转换结果。

对于 `a` 和 `A` 转换，`FLT_RADIX` 是 2 的幂，该值被正确舍入为具有给定精度的十六进制浮点数。

## 推荐实践

对于 `a` 和 `A` 转换，如果 `FLT_RADIX` 不是 2 的幂且结果在给定位置上无法精确表示，则结果应为给定精度下两个相邻的十六进制浮点格式之一，额外规定是误差对于当前的舍入方向应具有正确的符号。

对于 `e`、`f`、`g` 和 `G` 转换，如果有效数字位数最多为 `DECIMAL_DIG`，则结果应被正确舍入.³336) 如果有效位数多于 `DECIMAL_DIG` 但源值可以用 `DECIMAL_DIG` 位数字精确表示，则结果应为带有尾随零的精确表示。否则，源值被限制在具有 `DECIMAL_DIG` 位有效数字的两个相邻十进制 `L < U` 之间；生成的十进制字符串 `D` 的值应满足 `L ≤ D ≤ U`，额外规定是误差对于当前的运行方向应具有正确的符号。

## 返回

`fprintf` 函数返回传输的宽字符数，如果发生输出或编码错误，则返回负值。

## 环境限制

任何单个转换可以产生的宽字符数至少为 4095 个。

示例 打印格式为“Sunday, July 3, 10:02”的日期时间，后跟五位小数：

```
#include <math.h>
#include <stdio.h>
#include <wchar.h>
/* ... */
wchar_t *weekday, *month; // 指向宽字符串的指针
int day, hour, min;
fwprintf(stdout, "L%ls, %ls %d, %.2d:%2d\n", weekday, day, hour, min);
wprintf(stdout, "Lpi = %.5f\n", 4 * atan(1.0));
```

前引用：`btowc` 函数 (7.29.6.1.1)，`mbrtowc` 函数 (7.29.6.3.2)。

## 7.29.2.2 `fcanf` 函数

## 概要

```
#include <stdio.h>
#include <wchar.h>
int fcanf(FILE * restrict stream,
const wchar_t * restrict format, ...);
```

`fcanf` 函数从 `stream` 指向的流中读取输入，受 `format` 指向的宽字符串控制，该宽字符串指定了允许的输入序列以及如何通过后续参数将它们转换为用于赋值的值。

对于二进制到十进制的转换，结果格式的值可以使用给定的格式说明符表示。有效位数由格式说明符决定，在固定点转换的情况下也由源值决定。参数作为接收转换后输入的对象的指针。如果格式所需的参数不足，行为是未定义的。如果参数耗尽但仍剩余，则对多余参数进行（如常一样）求值，但会被忽略。

格式由零个或多个指令组成：一个或多个空白字符（既不是 `%` 也不是空白字符），或一个转换规范。每个转换规范由一个宽字符引入。在 `%` 之后，按顺序出现：

- 一个可选的抑制赋值的宽字符 `*`。
- 一个可选的大于零的十进制整数，指定最大字段宽度（以宽字符为单位）。
- 一个可选的长度修饰符，指定接收对象的大小。
- 一个转换规范宽字符，用于指定要应用的转换类型。

`fscanf` 函数执行格式的每个指令。当所有指令都失败时（详见下文），函数返回。失败被描述为输入失败（由于发生编码错误或无可用输入字符）或匹配失败（由于输入不当）。

由空白宽字符组成的指令通过读取输入直到第一个非空白宽字符（该字符仍保持未读状态），或直到无法读取更多宽字符为止执行。该指令永远不会失败。

作为普通字符的指令通过读取下一个宽字符来执行。如果该宽字符与指令不同，则指令失败。同样，如果遇到文件结束、编码错误或读取阻止了字符读取，则指令失败。

作为转换规范的指令定义了一组匹配序列，如下。转换规范按以下步骤执行：

跳过空白宽字符（如函数所示），除非规范包含 `[` 或 `c`。从流中读取输入项，除非规范包含 `n`。输入项定义为不超出任何字段宽度的最长输入字符序列。如果输入项长度为零，则指令失败；这种情况下为匹配失败，除非遇到文件结束、编码错误或读取阻止输入，在这种情况下为输入失败。

除 `%` 说明符的情况外，输入项（在 `%n` 指令的情况下为输入字符的计数）被转换为转换说明符相应的类型。如果输入项不是匹配序列，则指令失败；这种情况下为匹配失败。除非由 `*` 指示赋值，否则空白字符不计入指定的字段宽度.³37) 输入项后的第一个宽字符。

转换结果被放在指向未接收转换结果的第一个参数的对象中。如果该没有没有类型，或者转换结果无法在对象中表示，行为是未定义的。

长度修饰符及其含义为：

- `hh` 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `signed char` 或 `unsigned char` 参数。
- `h` 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `short int` 或 `unsigned short` 参数。
- `l` (ell) 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `long int` 或 `unsigned long int` 参数；或者后续的 `a`、`A`、`E`、`f`、`F` 或 `G` 转换规范适用于 `double` 类型参数；或者后续的 `c`、`s` 或 `[` 转换规范适用于 `wchar_t` 类型参数。
- `11` (ell-ell) 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `long long int` 或 `unsigned long int` 参数。
- `j` 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `intmax_t` 或 `uintmax_t` 参数。
- `z` 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `size_t` 或相应的符号整数类型参数。
- `t` 指定后续的 `d`、`i`、`o`、`u`、`x` 转换规范适用于 `ptrdiff_t` 或相应的符号整数类型参数。

> 338) fwscanf 将最多一个宽字符推回到输入流中。因此，某些 `wcstop`、`wcstol` 等接受的序列对 `fwscanf` 来说是不接受的。
