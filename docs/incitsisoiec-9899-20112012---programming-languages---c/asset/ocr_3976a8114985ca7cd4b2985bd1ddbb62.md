# 6.4.4.2 Floating constants

# Syntax

```

  decimal-floating-constant
  hexadecimal-floating-constant
ndecimal-floating-constant:
  fractional-constant exponent-part<sub>opt}\ floating-suffix<sub>opt}
  digit-sequence exponent-part floating-suffix<sub>opt}

  digit-sequence<sub>opt} . digit-sequence
  digit-sequence =

exponent-part:
  e sign<sub>opt} digit-sequence
  E sign<sub>opt} digit-sequence

sign: one of
  +
-
digit-sequence:
  digit
  digit-sequence digit

hexadecimal-fractional-constant:
  hexadecimal-digit-sequence<sub>opt} .
  hexadecimal-digit-sequence =

  P sign<sub>opt} digit-sequence
  P sign<sub>opt} digit-sequence

hexadecimal-digit-sequence:
  hexadecimal-digit
  hexadecimal-digit-sequence hexadecimal-digit

floating-suffix: one of
  f 1 F L *
```
