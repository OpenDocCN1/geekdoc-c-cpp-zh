## 7.29.4.4 Wide string comparison functions

Unless explicitly stated otherwise, the functions described in this subclause order two wide characters the same way as two integers of the underlying integer type designated by wchar_t.

### 7.29.4.4.1 The wcsmp function

# Synopsis

```
#include <wchar.h>
int wcsmp(const wchar_t *s1, const wchar_t *s2);
```

# Description

The wcsmp function compares the wide string pointed to by s1 to the wide string pointed to by s2.

# Returns

The wcsmp function returns an integer greater than, equal to, or less than zero, accordingly as the wide string pointed to by s1 is greater than, equal to, or less than the wide string pointed to by s2.

### 7.29.4.4.2 The wscolcoll function

# Synopsis

```
#include <wchar.h>
int wscolcoll(const wchar_t *s1, const wchar_t *s2);
```

# Description

The wscolcoll function compares the wide string pointed to by s1 to the wide string pointed to by s2, both interpreted as appropriate to the LC_COLLATE category of the current locale.

# Returns

The wscolcoll function returns an integer greater than, equal to, or less than zero, accordingly as the wide string pointed to by s1 is greater than, equal to, or less than the wide string pointed to by s2 when both are interpreted as appropriate to the current locale.

### 7.29.4.4.3 The wscnmp function

# Synopsis

```
#include <wchar.h>
int wscnmp(const wchar_t *s1, const wchar_t *s2,
       size_t n);
```

# Description

The wscnmp function compares not more than n wide characters (those that follow a null wide character are not compared) from the array pointed to by s1 to the array pointed to by s2.

# Returns

The wscnmp function returns an integer greater than, equal to, or less than zero, accordingly as the possibly null-terminated array pointed to by s1 is greater than, equal to, or less than the possibly null-terminated array pointed to by s2.

### 7.29.4.4.4 The wscxfrm function

# Synopsis

```
#include <wchar.h>
size_t wscxfrm(wchar_t restrict s1,
       const wchar_t restrict s2,
       size_t n);
```

# Description

The wscxfrm function transforms the wide string pointed to by s2 and places the resulting wide string into the array pointed to by s1. The transformation is such that if the wcsmp function is applied to two transformed wide strings, it returns a value greater than, equal to, or less than zero, according to the result of the wscoll applied to the two original wide strings. No more than n wide characters are placed into the resulting array pointed to by s1, including the terminating wide character. If n is zero, s1 is permitted to be a null pointer.

# Returns

The wscxfrm function returns the length of the transformed wide string (not including the terminating null character). If the value returned is n or greater, the contents of the array pointed to by s1 are indeterminate.

### 7.29.4.4.5 The wmemcmp function

# Synopsis

```
#include <wchar.h>
wmemcmp(const wchar_t *s1, const wchar_t *s2, size_t n);
```

## 7.29.4.4.5 Wide string search functions

### 7.29.4.5.1 The wcsnrchr function

# Synopsis

```
#include <wchar.h>
wchar_t *wcsnrchr(const wchar_t *s, wchar_t c);
```

# Description

The wcsnrchr function locates the first occurrence of c in the wide string pointed to by s. The terminating null character is considered to be part of the wide string.

# Returns

The wcsnrchr function returns a pointer to the located wide character, or a null pointer if the wide character does not occur in the wide string.

### 7.29.4.5.2 The wcsspn function

# Synopsis

```
#include <wchar.h>
size_t wcsspn(const wchar_t *s1, const wchar_t *s2);
```

# Description

The wcsspn function computes the length of the maximum initial segment of the wide string pointed to by s1 which consists entirely of wide characters not from the wide string pointed to by s2.

The wcspn function returns the length of the segment.

### 7.29.4.5.3 The wcspbrk function

# Synopsis

```
#include <wchar.h>
wchar_t *wcspbrk(const wchar_t *s1, const wchar_t *s2);
```

# Description

The wcspbrk function locates the first occurrence in the wide string pointed to by s1 of any wide character from the wide string pointed to by s2.

# Returns

The wcspbrk function returns a pointer to the wide character in s1, or a null pointer if no wide character from s2 occurs in s1.

### 7.29.4.5.4 The wcscchr function

# Synopsis

```
#include <wchar.h>
wchar_t *wcscchr(const wchar_t *s, wchar_t c);
```

# Description

The wcscchr function locates the last occurrence of c in the wide string pointed to by s. The terminating null wide character is considered to be part of the wide string.

# Returns

The wcscchr function returns a pointer to the wide character, or a null pointer if c does not occur in the wide string.

### 7.29.4.5.5 The wcspn function

# Synopsis

```
#include <wchar.h>
size_t wcspn(const wchar_t *s1, const wchar_t *s2);
```

# Description

The wcspn function computes the length of the maximum initial segment of the wide string pointed to by s1 which consists entirely of wide characters not from the wide string pointed to by s2.

# Returns

The wcspn function returns the length of the segment.

### 7.29.4.5.6 The wcsstr function

# Synopsis

```
#include <wchar.h>
wchar_t *wcsstr(const wchar_t *s1, const wchar_t *s2);
```

# Description

The wcsstr function locates the first occurrence in the wide string pointed to by s1 of the wide string pointed to by s2.

# Returns

The wcsstr function returns a pointer to the wide character in s1, or a null pointer if s2 does not occur in s1.

### 7.29.4.5.7 The wcstok function

# Synopsis

```
#include <wchar.h>
wchar_t *wcstok(wchar_t *s1, const wchar_t *s2, wchar_t **ptr);
```

# Description

The wcstok function breaks the wide string pointed to by s1 into tokens, each of which is delimited by the characters pointed to by s2. The first call to wcstok uses a null pointer for s1 and subsequent calls use the pointer stored in ptr to continue.

# Returns

The wcstok function returns a pointer to the first character of a token, or a null pointer if there is no token.
