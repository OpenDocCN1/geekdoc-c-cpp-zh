## 7.20.4 规定宽度整数类型的限制

### 7.20.4.1 最小宽度整数类型的限制

宏 `INTN_C(value)` 扩展为 `int_least_t` 类型的值。宏 `UINTN_C(value)` 扩展为 `uint_least_t` 类型的值。例如，如果 `uint_least_64_t` 是 `unsigned long long` 的别名，那么 `UINT64_C(23)` 可能会扩展为 23。

### 7.20.4.2 最快最小宽度整数类型的限制

宏 `INTFASTN_C(value)` 扩展为 `int_fast_t` 类型的值。宏 `UINTFASTN_C(value)` 扩展为类型的值。例如，如果 `uint_fast_64_t` 是 `unsigned long long` 的别名，那么 `UINT64_C(23)` 可能会扩展为 23。

### 7.20.4.3 最大宽度整数类型的限制

宏 `INTMAX_C(value)` 扩展为 `intmax_t` 类型的值。宏 `UINTMAX_C(value)` 扩展为 `uintmax_t` 类型的值。例如，如果 `intmax_t` 是 `long long` 的别名，那么 `INTMAX_C(23)` 可能会扩展为 23。

## 7.21 输入输出 <stdio.h>

### 7.21.1 引言

头文件 `<stdio.h>` 定义了几个宏，并声明了三种类型和许多用于输入输出的函数。

声明的类型有 `size_t`（见 7.19）；`FILE` 是一种能够记录流所需的全部信息的对象类型，包括文件位置指示器、关联缓冲区指针（如果有）、错误指示记录是否发生了读/写错误，以及文件结束指示记录是否到达文件末尾；以及 `fpos_t` 是一种除数组以外的完整对象，能够记录文件内每个位置所需的全部信息。

宏有 `NULL`（描述 7.19）；

- `_IOBF`
- `_IOLBF`
- `_IONBF`

它们扩展为具有不同值的整数常量表达式，适用于 `setvbuf` 函数的第三个参数；

- `BUFSIZ` 扩展为整数常量表达式，表示 `setvbuf` 函数使用的缓冲区的大小；

- `EOF` 扩展为整数常量表达式，类型为 int 且值为负，由几个函数返回以表示文件结束，即流没有更多输入；

- `FOPEN_MAX` 扩展为整数常量表达式，表示实现保证可以同时打开的文件最小数量；

- `FILENAME_MAX` 扩展为整数常量表达式，表示 `char` 数组所需的尺寸，以容纳实现的最长文件名字符串。
