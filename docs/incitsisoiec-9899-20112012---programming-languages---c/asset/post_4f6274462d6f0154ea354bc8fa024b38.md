
## K.3.9.2.3 Wide string search functions

### K.3.9.2.3.1 The wcstok_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
wchar_t *wcstok(wchar_t * restrict s1,
size_t * restrict slmax,
const wchar_t * restrict s2,
wchar_t ** restrict ptr);
```

Runtime-constraints

None of slmax, s2, or ptr will be a null pointer. If s1 is a null pointer, then *ptr shall not be a null pointer. The value of *slmax shall not be greater than RSIZE_MAX. The end of the token shall occur within the first *slmax wide characters of s1 for the first call, and shall occur within the first *slmax wide characters of searching resumes on subsequent calls.

If there is a runtime-constraint violation, the wcstok_s function does not indirect through the s1 or s2 pointers, and does not store a value in the object pointed to by ptr.

Description

A sequence of calls to the wcstok_s function breaks the wide string pointed to by s1 into a sequence of tokens, each of which is delimited by a wide character from the wide string pointed to by s2. The fourth argument points to a caller-provided wchar_t pointer into which the wcstok_s function stores information necessary for it to continue scanning the wide string.

The first call in a sequence has a non-null first argument and slmax points to an object whose value is the number of elements in the wide character array pointed to by the first argument. The call stores an initial value in the object pointed to by ptr and updates the value pointed to by slmax to reflect the number of elements that remain in relation to ptr. Subsequent calls in the sequence have a null first argument and the objects pointed to by slmax and ptr are required to have the values stored by the previous call in the sequence, which are then updated. The separator wide string pointed to by s2 may be different from call to call.

The first call in the sequence searches the wide string pointed to by s1 for the first wide character that is not contained in the current separator wide string pointed to by s2. If such wide character is found, then there are no tokens in the wide string pointed to by s1 and the wcstok_s function returns a null pointer. If such wide character is found, it is the start of the first token.

The wcsok_s function searches from there for the first wide character in s1 that is contained in the current wide string. If no such wide character is found, the current token extends to the end of the wide string pointed to by s1, and subsequent searches in the same wide string for a token return a null pointer. If such a character is found, it is overwritten by a null character, which terminates the current token.

In all cases, the wcsok_s function stores sufficient information in the pointer pointed to ptr so that subsequent calls, with a null pointer for s1 and the unmodified pointer value ptr, shall start searching past the element overwritten by a wide character (if any).

# Returns

The wcsok_s function returns a pointer to the first wide character of a token, or a null pointer if there is no token or a runtime-constraint violation.

# EXAMPLE

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
static wchar_t str1[1] = L"??b,c";
static wchar_t str2[2] = L"\t \t";
wchar_t *t, *ptr1, *ptr2;
size_t max1 = wcslen(str1+1)
size_t max2 = wcslen(str2+2)

t = wcsok_s(str1, max1, "", &ptr1); // t points to the token "a"
t = wcsok_s(str1, max1, ",\,", &ptr1); // t points to the token "??b"
t = wcsok_s(str2, max2, "\t", &ptr2); // t is a null pointer
t = wcsok_s(NULL, max1, "##", &ptr1); // t points to the token "c"
t = wcsok_s(NULL, max1, "?", &ptr1); // t is a null pointer
```

## K.3.9.2.4 Miscellaneous functions

### K.3.9.2.4.1 The wcslen_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
size_t wcslen_s(const wchar_t *s, size_t maxsize);
```

Description

The wcslen_s function computes the length of the string pointed to by s.

# Returns

If s is a null pointer, wcslen_s returns zero. Otherwise, wcslen_s returns the number of wide characters that precede the null character.

## K.3.9.3 Extended multibyte conversion

### K.3.9.3.1 The wcrtomb_s function

Synopsis

```
#include <wchar.h>
errno_t wcrtomb_s(size_t *retval, char *s, size_t smax, wchar_t wc, mbstate_t *ps);
```

Runtime-constraints

Neither retval, s, nor ps shall be null pointers. If s is not a null pointer, smax shall not be greater than RSIZE_MAX. If s is a null pointer, smax shall be equal.

If there is a runtime-constraint violation, wcrtomb_s does the following. If retval is not a null pointer, wcrtomb_s sets *retval to (size_t) (-1). If s is not a null pointer and smax is greater than zero and less than RSIZE_MAX, wcrtomb_s sets s[0] to the null byte.

Description

If s is not a null pointer, wcrtomb_s determines the number of bytes needed to represent wc and stores them in the array pointed by s. At most MB_MAX bytes are stored, including shift sequences. If wc does not correspond to a valid multibyte character, an encoding error occurs: wcrtomb_s sets *retval to (size_t) (-1) and the state is unspecified.

# Returns

The wcrtomb_s function returns zero if no runtime-constraint and encoding error occurred. Otherwise, a nonzero value is returned.

### K.3.9.3.2 Restartable multibyte string conversion

### K.3.9.3.2.1 The mbsrtowcs_s function

```
#include <wchar.h>
errno_t mbsrtowcs_s(size_t *retval, char_t *dst, size_t dstmax, char **src, size_t len, mbstate_t *ps);
```

Runtime-constraints

None of retval, src, *src, or ps shall be null pointers. If dst is not a null pointer, neither len nor dstmax shall be greater than RSIZE_MAX. If dst is a null pointer, dstmax shall be equal. If dst is not a null pointer and len is not less than dstmax, then a null character shall occur within the first dmax multibyte characters of the array pointed by *src.

If there is a runtime-constraint violation, mbsrtowcs_s does the following. If retval is not a null pointer, mbsrtowcs_s sets *retval to (size_t) (-1). If dst is not a null pointer and dmax is greater than zero and less than RSIZE_MAX, mbsrtowcs_s sets dst[0] to the null wide character.

Description

The mbsrtowcs_s function converts a sequence of multibyte characters in the conversion state described by the object pointed to by ps, from the array pointed to by src into a sequence of corresponding wide characters. If dst is not a null pointer, the converted characters are stored in the array pointed by dst. Conversion continues up to including a terminating null character, which is also stored. Conversion stops early in two cases: when a sequence of bytes is encountered that does not form a valid multibyte character, or (if dst is not a null pointer) len.
