## 7.2.25 Searching and sorting utilities

These utilities make use of a comparison function to search or sort arrays of unspecified type. When an argument declared as size_t nmemb specifies the length of the array for a function, nmemb can have the zero value on a call to that function; the comparison function is not called, search finds no matching element, and sorting performs no rearrangement. Pointer arguments on such a call shall still have valid values, as described in 7.1.4.

The implementation should ensure that the second argument of the comparison function (when called from bsearch), or both arguments (when called from qsort), are pointers to elements of the array. The first argument when called from bsearch shall equal key.

The comparison function shall not alter the contents of the array. The implementation may reorder elements of the array between calls to the comparison function, but shall not alter the contents of any individual element.

When the same objects (consisting of size bytes, irrespective of their current positions in the array) are passed more than once to the comparison function, the results shall be consistent with one another. That is, for qsort they define a total ordering over the array, and for bsearch the same object shall always compare the same way with the key.

A sequence point occurs before and immediately after each call to the comparison function, and also between any call to the comparison function and any movement of the objects passed as arguments to that call.

> That is, if the value passed is p, then the following expressions are always nonzero:

```
((char*)p - (char*)base) % size == 0
(char*)p >= (char*)base
(char*)p < (char*)base + nmemb * size
```

### 7.2.5.1 The bsearch function

### Synopsis

```
#include <stdlib.h>
void *bsearch(const void *key, const void *base,
      size_t nmemb, size_t size,
      int (*compar)(const void *, const void *));
```

### Description

The bsearch function searches an array of nmemb objects, the initial element of which is pointed to by base, for an element that matches the object pointed to by key. The size of each element of the array is specified by size.

The comparison function pointed to by compare is called with two arguments pointed to the key object and an array element, in that order. The function shall return an integer less than, equal to, or greater than zero if the key object is considered, respectively, to be less than, equal to match, or be greater than the array element. The array shall consist of all: all the elements that compare less than, all the elements that compare equal to, and all the elements that compare greater than the key object, in that order.

### Returns

The bsearch function returns a pointer to a matching element of the array, or a null pointer if no match is found. If two elements compare as equal, which element is matched is unspecified.

### 7.2.5.2 The qsort function

### Synopsis

```
#include <stdlib.h>
void qsort(void *base, size_t nmemb, size_t size,
      int (*compar)(const void *, const void *));
```

### Description

The qsort function sorts an array of nmemb objects, the initial element of which is pointed to by base. The size of each object is specified by size.

The contents of the array are sorted into ascending order according to a comparison function pointed to by compare, which is called with two arguments point to the objects being compared. The function shall return an integer less than, equal to, or greater than zero if the first argument is considered to be respectively less than, equal to, or greater than the second.

> In practice, the entire array is sorted according to the comparison function.

If two elements compare as equal, their order in the resulting sorted array is unspecified.

### Returns

The qsort function returns no value.

## 7.2.6 Integer arithmetic functions

### 7.2.6.1 The abs, labs and llabs functions

### Synopsis

```
#include <stdlib.h>
int abs(int j);
long labs(long int j);
long int llabs(long long int j);
```

The abs, labs, and llabs functions compute the absolute value of an integer j. If the result cannot be represented, the behavior is undefined.

### Returns

The abs, labs, and llabs functions return the absolute value.

### 7.2.6.2 The div, ldiv, and ldivdiv functions

### Synopsis

```
div_t div(int numer, int denom);
lldiv_t ldiv(long int numer, long int denom);
lldiv_t ldivdiv(long long int numer, long long int denom);
```

### Description

The div, ldiv, and ldivdiv functions compute numer / denom and numer % denom in a single operation.

### Returns

The div, ldiv, and ldivdiv functions return a structure of type div_t, ldiv_t, and lldiv_t, respectively, comprising the quotient and the remainder. The structures shall contain the quotient and the remainder. If the result cannot be represented, the behavior is undefined.

## 7.2.7 Multibyte/character conversion functions

### 7.2.7.1 The mlen function

### Synopsis

```
#include <stdlib.h>
int mlen(const char *s, size_t n);
```

### Description

If s is not a null pointer, the mlen function determines the number of bytes contained in the multibyte character.

### Returns

If s is a null pointer, the mlen function returns a nonzero or zero value, if multibyte character encodings, respectively, or not have state-dependent encodings. If s is not a null pointer, the mlen function returns 0 (if s points to the null character), or returns the number of bytes that are contained in the multibyte character (if the n or fewer bytes form a valid multibyte character), or returns -1 (if they do not form a valid multibyte character).

### 7.2.7.2 The mbwtoc function

### Synopsis

```
#include <stdlib.h>
int mbwtoc(wchar_t *pwc, const char *s, size_t n);
```

### Description

If s is not a null pointer, the mbwtoc function inspects at most n bytes beginning with the byte pointed to s to determine the number of bytes needed to complete the multibyte character. If the function determines that the next multibyte character is complete and valid, it determines the value of the corresponding wide character and then, if pwc is not a null pointer, stores that in the object pointed to by pwc.

### Returns

If s is a null pointer, the mbwtoc function returns a nonzero or zero value, if multibyte character encodings, respectively, or not have state-dependent encodings. If s is not a null pointer, the mbwtoc function returns 0 (if s points to the null character), or returns the number of bytes that are contained in the multibyte character (if n or fewer bytes form a valid multibyte character), or returns -1 (if they do not form a valid multibyte character).

### 7.2.7.3 The mbwtomb function

### Synopsis

```
#include <stdlib.h>
int mbwtomb(char *s, wchar_t wc);
```

### Description

The mbwtomb function determines the number of bytes needed to represent the multibyte character corresponding to the wide character given by wc (including any shift sequences), and stores the multibyte character representation in the array whose first element is pointed to by s (if s is not a null pointer). If wc is a null wide character, a null byte is stored, preceded by any shift sequence to restore the initial shift state, and the function is left in the initial conversion state.
