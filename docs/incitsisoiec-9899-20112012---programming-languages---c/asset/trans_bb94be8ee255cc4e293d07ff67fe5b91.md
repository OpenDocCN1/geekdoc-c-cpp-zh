共有三种复类型，分别指定为 `float _Complex`、`double _Complex` 和 `long double _Complex`⁴43)（复类型是一种实现不支持的条件特性；见 6.10.8.3）。）。实浮点类型和复类型统称为浮点类型。

每个浮点类型都有一个对应的实类型，该实类型始终是实浮点类型。对于复类型，它是同一种类型，即从类型名中删除关键字 `_Complex` 后得到的类型。

每个复类型与包含恰好两个对应实类型元素的任何其他类型具有相同的表示方法和对齐要求；第一个元素等于复数的实部，第二个元素等于复数的虚部。

`char` 类型、符号整数类型、无符号整数类型以及浮点类型统称为基本类型。基本类型是对象类型。即使实现定义两个或多个类型具有相同的表示方法，它们仍然是不同的类型⁴44)。

`char`、`signed char` 和 `unsigned char` 三类型统称为字符类型。实现允许 `char` 与 `signed char` 或 `unsigned char` 相同的范围、表示和行为⁴45)。

枚举由一组命名的整数常量值组成。每个不同的枚举构成一个不同的枚举类型。

`char` 类型、符号整数类型、无符号整数类型以及枚举类型统称为整数类型。整数类型和实浮点类型统称为实类型。

整数类型和浮点类型统称为算术类型。每个算术类型属于一个类型域：实类型域包含实类型，复类型域包含复类型。

`void` 类型是一个不完整的类型。

算术类型和指针类型统称为标量类型。数组类型和结构体类型统称为聚合类型⁴⁶。

22 未知大小数组是不完整类型。它在后续声明中通过指定大小来完全。

数组、函数和指针类型统称为声明符。从类型导出声明符是对数组类型、函数类型或指针类型的应用。

类型由其类型类别特征，该类别是派生类型的导出（如上所述），或者是类型本身不包含派生类型。

上述提到的所有类型都是未限定类型。每个未限定类型都有其限定版本⁷)，对应于 `const`、`volatile` 和 `restrict` 限定符的组合。类型的限定或未限定版本是属于相同类型类的不同类型，并具有相同的表示方法和对齐要求⁴⁸)。派生类型不被其导出的类型的限定符（如果有）限定。

此外，还有 `_Atomic` 限定符。`_Atomic` 限定符的存在指定了一个原子类型。原子类型的大小、表示和对齐可能与其未限定类型不同。因此，每当类型的原子版本与其其它限定版本允许使用时，标准显式使用“原子、限定或未限定类型”这一短语。在没有特定提及的情况下，“限定或未限定类型”不包含原子类型。

指向 `void` 的指针与指向 `char` 的指针具有相同的表示方法和对齐要求⁴⁸)。同样，指向兼容类型的限定或未限定版本的指针具有相同的表示方法和对齐要求。所有指向结构体的指针之间具有相同的表示方法和对齐要求。所有指向联合体的指针之间具有相同的表示方法和对齐要求。指向其他类型的指针不具有相同的表示方法和对齐要求。

示例 1 指定为 `float *` 的类型类型是“指向 float”。其类型类别不是浮点类型。该类型的限定版本被指定为 `float const *`，而指定为 `const float *` 的类型不是限定类型 —— 其类型是“指向 const”。
