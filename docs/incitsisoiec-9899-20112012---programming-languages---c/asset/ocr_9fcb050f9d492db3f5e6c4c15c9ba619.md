Moreover, if the expression P points either to an element of an array object or past the last element of an array object, and the expression Q points to the last element of the same array object, ((Q)+1)-(P) has the same value as -((Q)-(P)-((Q)+1)), and has the value zero if the expression P passes past the last element of the array object, even though the expression (Q)+1) does not point to an element of the array object.106

EXAMPLE Pointer arithmetic is well defined with pointers to variable length array types.

```
int n = 4, m = 3;
int a[n];
int (*p)[m] = a;   // p == &a[0]
p += 1;           // p == &a[1]
(*p)[2] = 99;      
n = p - a;         // n == 1
```

If a in the above example were declared to be an array of known constant size, and pointer p was declared to be a pointer to an array of the same known constant size (pointing to a), the results would be the same.
