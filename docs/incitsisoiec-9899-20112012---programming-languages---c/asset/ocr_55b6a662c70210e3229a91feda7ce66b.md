# 10.6.7 The round and 11round functions

The round and 11round functions differ from the lrint and 11rint functions with the default rounding direction just in that the round and 11round functions halfway away from zero and not raise the “inexact” floating-point exception for non-integer arguments that round to the range of the return type.

# 10.6.8 The trunc functions

The trunc functions use IEC 60559 rounding toward zero (regardless of the current rounding direction). The returned value is exact.

+   - trunc (±0) returns ±0.
- trunc (±∞) returns ±∞.

The returned value is independent of the current rounding direction mode. The trunc functions may, but are not required to, raise the “inexact” floating-point exception for non-integer arguments.

# F10.6.7 Remainder functions

# F10.6.7.1 The fmod functions

+   - fmod (±0, y) returns 0 for y not zero.
- fmod (x, y) returns a NaN and raises the “invalid” floating-point exception for x or y (and neither is a NaN).
- fmod (x, ±∞) returns x for x not infinite.

When subnormals are supported, the returned value is exact and is independent of the current rounding direction mode.

The double version of fmod behaves as though implemented by

```
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS_ON
double fmod(double x, double y)
{
    double result;
    result = remainder(fabs(x), (y = fabs(y)));
    if (signbit(result)) result += y;
    return copysign(result, x);
}
```
