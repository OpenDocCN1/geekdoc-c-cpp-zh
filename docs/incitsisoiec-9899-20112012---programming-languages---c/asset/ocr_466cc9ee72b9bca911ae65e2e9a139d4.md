#  6.7.8 Type definitions

# Syntax

```
typedef-name:
    identifier
```

# Constraints

If a typedef name specifies a variably modified type then it shall have block scope.

# Semantics

In a declaration whose storage-class specifier is typedef, each declarator defines an identifier to be a typedef name that denotes the type for the identifier in the way described in 6.7.6. Any array size expressions associated with variable length array declarators are evaluated each time the typedef name is reached in the order of execution. A typedef declaration does not introduce a new type, only a synonym for the type specified. That is, in the following declarations:

```
typedef T type_ident;
type_ident D;
```

type_ident is defined as a typedef name with the type specified by the declaration specifiers in T (known as T), and the identifier in D has the type “derived-declarator-type-list” where the derived-declarator-type-list is specified by the declarators of D. A typedef name shares the same name space as other identifiers declared in ordinary declarators.

EXAMPLE 1 After

```
typedef int MILES, KLICKSP();
typedef struct { double hi, lo; } range;
```

the constructions

```
MILES distance;
extern x;
range *metric;
range z, *zp;
```

are all valid declarations. The type of distance is int, and of metric is “pointer to function with no parameter specification returning int”, and x and z are the specified structure; zp is a pointer to such a structure. The object has a type compatible with any other int object.
