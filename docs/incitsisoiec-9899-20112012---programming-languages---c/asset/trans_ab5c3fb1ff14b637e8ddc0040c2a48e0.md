## K.3.4 整数类型 <stdint.h>

头文件 <stdint.h> 定义了一个宏。

该宏是：

```
RSIZE_MAX
```

它展开为类型 size_t 的值.³386)。对于参数类型为 rsize_t 的函数，如果这些参数的值大于 RSIZE_MAX，则被视为运行时约束违反。

## 建议实践

极大的对象大小是对象大小计算错误的常见迹象。例如，负数在转换为无符号类型 size_t 时会显示为巨大的正数。

由于这些原因，有时限制对象的范围对于防止编程错误是有益的。对于大地址空间的实现，建议将 RSIZE_MAX 定义为支持的最大对象或 (SIZE_MAX >> 1)，如果此限制小于某些合法对象的大小。针对小地址空间的实现可以使用 SIZE_MAX 作为 RSIZE_MAX，这意味着它被视为运行时约束违反。384) 就编程而言，errno 可能被用于处理可能出现在 errno 中的值。例如，返回 errno 值的函数可能声明为返回 errno_t。385) <stdint.h> 中 RSIZE_MAX 宏的描述。386) 宏 RSIZE_MAX 不需要展开为常量表达式。

## K.3.5 输入输出 <stdio.h>

头文件 <stdio.h> 定义了几个宏和两个类型。

宏有：

- L_tmpnam_s 展开为整数常量，表示容纳 tmpnam_s 函数生成的临时字符串所需的数组大小；
- TMP_MAX 展开为整数常量，表示 tmpnam_s 函数可以生成的唯一文件名数量。

类型有：

- errno_t，类型为 int；以及
- rsize_t，类型为 size_t。

## K.3.5.1 文件的操作

### K.3.5.1.1 tmpfile_s 函数

#### 概要

```
#define __STDC_WANT_LIB_EXT__ 1
#include <stdio.h>
errno_t tmpfile_s(FILE * restrict restrict streamptr);
```

#### 运行时约束

- streamptr 不得为空指针。

如果存在运行时约束违反，tmpfile_s 不尝试创建文件。

#### 描述

tmpfile_s 函数创建一个与其他现有文件不同的临时二进制文件，并在关闭或程序终止时自动删除。如果程序异常终止，是否删除打开的临时文件取决于实现。该文件以 "wb" 模式打开进行更新，其含义与 fopen_s 函数中的模式相同（包括模式对独占访问和文件权限的影响）。

如果文件创建成功，streamptr 指的 FILE 指针将指向打开的文件。否则，streamptr 指的 FILE 指针将被设置为空指针。

#### 建议实践

在程序生命周期内应该能够打开 TMP_MAX 个临时文件，且除了此限制以及任何对打开文件数量的限制（FOPEN_MAX）外不应有其他限制。

#### 返回

如果 tmpfile_s 创建了文件，则返回零。如果它没有创建文件或存在运行时约束违反，tmpfile_s 返回非零值。

### K.3.5.1.2 tmpnam_s 函数

#### 概要

```
#define __STDC_WANT_LIB_EXT__ 1
#include <stdio.h>
errno_t tmpnam_s(char *s, rsize_t maxsize);
```

#### 运行时约束

+ s 不得为空指针。
+ maxsize 小于或等于 RSIZE_MAX
+ maxsize 大于生成的文件名字符串的长度。

#### 描述

+ tmpnam_s 函数生成一个有效文件名且与现有文件文件名不同的字符串。该函数潜在能够生成 TMP_MAX 个不同的字符串，但其中任何一个或所有字符串可能已经存在于现有文件中，因此不是理想的返回值。这些字符串的长度应小于 L_tmpnam_s 宏的值。

+ tmpnam_s 函数每次被调用时都会生成不同的字符串。

+ 假设 s 指向一个至少有 maxsize 个字符的数组。该数组将按照下文所述设置为生成的字符串。

> 387) 使用 tmpnam_s 函数通过字符串创建的文件只是临时的，仅意味着它们的名称与该实现的常规命名规则生成的名称不冲突。仍然需要使用 remove 删除此类文件。

#### 建议实践

在程序使用 tmpnam_s 获取文件名后、程序创建文件之前，存在其他人创建了同名文件的情况。为了避免这种竞态条件，应该使用 tmpfile_s。

#### 返回

如果无法生成合适的字符串，或者存在运行时约束违反，tmpnam_s 函数向 s[0] 写入一个空字符并返回非零值。

否则，tmpnam_s 函数将字符串写入 s 并返回零。

#### 环境限制

TMP_MAX 的值至少为 2。

## K.3.5.2 文件访问

### K.3.5.2.1 fopen_s 函数

#### 概要

```
#define __STDC_WANT_LIB_EXT__ 1
#include <stdio.h>
errno_t fopen_s(FILE * restrict restrict streamptr,
               const char * restrict filename,
               const char * restrict mode);
```

#### 运行时约束

streamptr、filename 或 mode 中的任何一个都为空指针。

如果存在运行时约束违反，fopen_s 不尝试打开文件。此外，如果 streamptr 不是空指针，fopen_s 将其设置为空指针。

> 388) 实现可以具有用于临时文件的 tmpnam，但并非强制。

#### 描述

fopen_s 函数打开名为 filename 字符串的文件，并关联如 fopen 所述的流，额外是以 'w' 或 'a' 开头的模式前可以加上字符 'u'，如下：

- uw 置零长度或创建文本文件，默认权限
- uwx 创建文本文件，默认权限
- ua 追加或在末尾创建文本文件，默认权限
- uwb 置零长度或创建二进制文件，默认权限
- ubwx 创建二进制文件，默认权限
- uab 追加或在末尾创建二进制文件，默认权限
- uw+ 置零长度或创建文本文件用于更新，默认权限
- uw+x 创建文本文件用于更新，默认权限
- ua+ 追加或在末尾创建文本文件用于更新，默认权限
- uw+b 或 uw+b 置零长度或创建二进制文件用于更新，默认权限
- uw+bx 或 uw+bx 创建二进制文件用于更新，默认权限
- ua+ 或 uab+ 追加或在末尾创建二进制文件用于更新，默认权限
