precision shall not appear in the wide string pointed to by format. Any argument to snprintf_f corresponding to a %s specifier shall not be a null pointer. No encoding error shall occur.

If there is a runtime-constraint violation, if s is not a null pointer and n is greater than zero and less than RSIZE_MAX, then the snprintf_f function sets s[0] to the null character.

# Description

The snprintf_f function is equivalent to the swprintf function except for the explicit runtime-constraints listed above.

The snprintf_s, unlike swprintf_f, will truncate the result to fit within the array pointed to by s.

# Returns

The snprintf_f function returns the number of wide characters that would have been written if n been sufficiently large, not counting the terminating null character, or a negative value if a runtime-constraint violation occurred. Thus, the null-terminated output has been completely written if and only if the returned value is nonnegative and less than n.

# K.3.9.1.4 The swprintf_f function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
int swprintf_f(wchar_t * restrict s, rsize_t n,
const wchar_t * restrict format, ...);
```

# Runtime-constraints

Neither s nor format be a null pointer. n shall neither equal zero nor greater than RSIZE_MAX. The number of wide characters (including the trailing null) required for the result to be written to the array pointed by s shall not be greater than n. The %n specifier^{433}(modified or not by flags, field width, or precision) shall not appear in the wide string pointed to by format. Any argument to swprintf_f corresponding to a %s specifier shall not be a null pointer. No encoding error shall occur.

432) It is not a runtime-constraint violation for the wide characters %n to appear in sequence in the wide string pointed to by format when those characters are not interpreted as a %n specifier. For example, if the entire string was L"%nn".

433) It is not a runtime-constraint violation for the wide characters %n to appear in sequence in the wide string pointed to by format when those characters are not interpreted as a %n specifier. For example, if the entire string was L"%nn".
