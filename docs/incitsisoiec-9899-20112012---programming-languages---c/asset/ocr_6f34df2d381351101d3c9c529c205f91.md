# 29.6.3.3 The wcertomb function

# Synopsis

```
#include <wchar.h>
size_t wcertomb(char * restrict s,
wchar_t wc,
mbstate_t * restrict ps);
```

# Description

If s is a null pointer, the wcertomb function is equivalent to the call wcertomb(buf, L'\0', ps)
where buf is an internal buffer.

If s is not a null pointer, the wcertomb function determines the number of bytes needed to represent the multibyte character that corresponds to the character given by wc (including any shift sequences), and stores the multibyte character representation in the array whose first element is pointed to by s. At most MB_CUR_MAX bytes are stored. If wc is a null wide character, a null byte is stored, by any shift sequence pointed to restore the internal state; the resulting state is described as the initial conversion state.

# Returns

The wcertomb function returns the number of bytes stored in the array object (including any shift sequences). When wc is not a valid wide character, an encoding error occurs: the function stores the value of the macro EILSEQ in errno and returns ((size_t) -1); the conversion is unspecified.

# 29.6.4.4 Restartable multibyte/wide string functions

These functions differ from the corresponding multibyte string functions of 7.22.8 (mbstowcs and wcstombs) in that they have an extra parameter, ps, of type pointer to mbstate_t that points to an object that can completely describe the current conversion state of the multibyte character sequence. If s is a null pointer, each function uses its internal mbstate_t object instead, which is initialized at program startup to the initial conversion state; the functions are not required to avoid races with other calls to the same function in this case. The implementation behaves as if no library calls these functions with a null pointer for ps.

Also unlike their corresponding functions, the conversion source parameter, src, has a pointer-to-pointer type. When the function is storing the results of conversions (that is, when dst is not a null pointer), the pointer object pointed to by this parameter is updated to reflect the amount of the source processed by invocation.
