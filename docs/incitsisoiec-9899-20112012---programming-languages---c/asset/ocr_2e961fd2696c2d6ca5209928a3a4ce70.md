# 3.5.3.2 The fscaf_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
int fscaf_s (FILE * restrict stream,
           const char * restrict format, ...);
```

Runtime-constraints

Neither format shall be a null pointer. Any argument indirect though in to store converted input shall be a null pointer.

If there is a runtime-constraint violation,392) the fscaf_s function does not attempt to perform further input, and it is unspecified to what extent fscaf_s performed input before discovering the runtime-constraint violation.

# Description

The fscaf_s function is equivalent to fscaf except the c, s, and [ conversion specifiers apply to a pair of arguments (unless assignment suppression is indicated by a *). The first of these arguments is the same as for fscaf. That argument is immediately followed by the argument list by the second argument, which has type size_t and gives the number of elements in the array pointed to by the first if the first argument points to a scalar object, it is considered to be an array of one element.393)

A matching failure occurs if the number of elements in a receiving object is insufficient to hold the converted input (including any trailing null character).
