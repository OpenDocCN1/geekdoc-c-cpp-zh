
Trailing whitespace (including new-line characters) is left un unless matched by a directive. The success of literal matches and suppressed assignments is not directly determinable other than via the %n directive.

# Returns

The fscanf function returns the value of the macro EOF if an input failure occurs before the first conversion (any) has completed. Otherwise, the function returns the number of input items assigned, which can be fewer than provided for, or even zero, in the event of an early matching failure.

EXAMPLE 1 The call:

```
#include <stdio.h>
/* ... */
int n, i; float x; char name[50];
n = fscanf(stdin, "%d%f%s", &i, &x, name);
```

with the input:

```
25 54.32-E1 thompson
```

will assign to n the value 3, to the i value 25, to x the value 5.432, and to name the sequence thompson\0.

EXAMPLE 2 The call:

```c
#include <stdio.h>
/* ... */
int i; float x; char name[50];
fscanf(stdin, "%d%f*d %[0123456789]", &i, &x, name);
```

with input:

```
56789 0123 56a72
```

will assign to i the value 56 and to x the value 789.0, and will assign to name the sequence 56\0. The next character read from the input stream will be a.

EXAMPLE 3 To repeatedly read from stdin a quantity, a unit of measure, and an item name:

```c
#include <stdio.h>
/* ... */
int count; float quant; char units[21], item[21];
d {
    count = fscanf(stdin, "%d%20s of %20s", &count, units, item);
    fscanf(stdin, "%*[^\n]");
} (!feof(stdin) && !ferror(stdin));
```

If the stdin stream contains the following lines:

- 2 quarts of oil
- 12.8degrees Celsius
- lots of luck
- 10.0LBS of
- dirt
- 100ergs of energy

the execution of the example above will be analogous to the following assignments:

```
quant = 2; strcpy(units, "quotes"); strcpy(item, "oil");
count = 3;
quant = -12.8; strcpy(units, "degrees");
count = 2; // "C" fails to match "o"
count = 0; // "1" fails to match "%f"
quant = 10.0; strcpy(units, "LBS"); strcpy(item, "dirt");
count = 3;
count = 0; // "100e" fails to match "%f"
count = EOF;
```

# EXAMPLE 5 The call:

```c
#include <stdio.h>
/* ... */
int n, i;
n = scanf("foo % bar 42", "foo%%bar%d", &i);
```

will assign to n the value 1 and to i the value 42 because input white-space characters are skipped for both the % and d conversion sequences.

# Synopsis

# Description

The printf function is equivalent to fprintf with the argument stdout interposed before the arguments to printf.

# 7.21.6.5 The sprintf function

# Synopsis

```c
#include <stdio.h>
int sprintf(char * restrict s, size_t n, const char * restrict format, ...);
```

# Description

The sprintf function is equivalent to fprintf with the argument s interposed before the arguments. If n is zero, nothing is written. Otherwise, output beyond the n-1 are discarded rather than written to the array. If copying takes place between objects that overlap, the behavior is undefined.

# Returns

The sprintf function returns the number of characters that would have been written had n been sufficiently large, not counting the null character, or a negative value if an encoding error occurred. Thus, the null-terminated output has been completely written if and only the returned value is nonnegative and less than n.

# 7.21.6.6 The sprintf function

# Synopsis

```c
#include <stdio.h>
int sprintf(char * restrict s, const char * restrict format, ...);
```

# Description

The sprintf function is equivalent to fprintf with the argument s interposed before the arguments. A null character is written at the end of the characters written; it is not counted as part the returned value. If copying takes place between objects that overlap, the behavior is undefined.

# Returns

The sprintf function returns the returns the number of characters written in the array, not counting the null character, or a negative value if an encoding error occurred.

# 7.21.6.7 The sscanf function

# Synopsis

```c
#include <stdio.h>
int sscanf(const char * restrict s, const char * restrict format, ...);
```

# Description

The sscanf function is equivalent to sscanf, except that input is obtained from a string (specified by the argument s) rather than from a stream. Reaching the end of the string is equivalent to encountering end-of-file for the sscanf function. If copying takes place between objects that overlap, the behavior is undefined.

# Returns

The sscanf function returns the value of the macro EOF if an input failure occurs before the first conversion (if any) has completed. Otherwise, the sscanf function returns the number of input items assigned, which can be fewer than provided for, or even zero, in the event of an early matching failure.
