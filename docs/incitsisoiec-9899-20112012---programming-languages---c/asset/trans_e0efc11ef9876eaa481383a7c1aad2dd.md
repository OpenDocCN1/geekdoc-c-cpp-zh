除了赋值和类型转换（它们会移除额外的范围和精度）外，带有浮点操作数的运算符产生的值以及常规算术转换的浮点常量将被评估为一个范围和精度可能大于类型的。格式的使用由实现定义值 FLT_EVAL_METHOD 进行表征：

- 不确定
- 将所有操作和常量仅评估为类型的范围和精度
- 将所有 float 和 double 类型的操作和常量评估为 double 类型的范围和精度，将 long 操作和常量评估为 long double 类型的范围和精度
- 将所有操作和常量评估为 long double 类型的范围和精度

FLT_EVAL_METHOD 的负值表征实现定义的行为。
