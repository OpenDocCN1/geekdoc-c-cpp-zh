### 返回
fprintf 函数返回传输的字符数，如果发生输出错误，则返回一个负值。

### 示例 以下示例显示了在通用错误报告例程中使用 fprintf 函数的方法。
```c
#include <stdarg.h>
#include <stdio.h>
void error(char *function_name, char *format, ...)
{
    va_list args;
    va_start(args, format);
    // 输出导致错误的函数名
    fprintf(stderr, "ERROR in %s: ", function_name);
    // 打印剩余消息
    fprintf(stderr, args);
    va_end(args);
}
```

## vscanf 函数

### 概要
```c
#include <stdarg.h>
#include <stdio.h>
int vscanf(FILE *restrict stream, const char *restrict format, va_list arg);
```

### 描述
vscanf 函数等同于 fscanf，但将参数列表替换为 arg，该 arg 应该由 va_start 宏（可能通过随后的 va_arg 调用）进行初始化。vscanf 函数不调用 va_end 宏。

### 返回
如果在第一次转换（任何一次转换）完成之前发生输入失败，vscanf 函数返回宏 EOF 的值。否则，vscanf 函数返回分配的输入项目数量，在早期匹配失败的情况下，该数量可能少于提供的数量，甚至为零。由于 fprintf、vscanf、vprintf、vsprintf 和 vsscanf 函数调用了 va_arg 宏，返回后 arg 的值是不确定的。

## vprintf 函数

### 概要
```c
#include <stdarg.h>
#include <stdio.h>
int vprintf(const char *restrict format, va_list arg);
```

### 描述
vprintf 函数等同于 printf，但将参数列表替换为 arg，该 arg 应该由 va_start 宏（可能通过随后的 va_arg 调用）进行初始化。vprintf 函数不调用 va_end 宏。如果在相互重叠的对象之间之间进行拷贝，则行为未定义。

### 返回
vprintf 函数返回传输的字符数，如果发生输出错误，则返回一个负值。因此，当且仅当返回值为非负且小于 n 时，空终止终止的输出才被完全写入。

## vsprintf 函数

### 概要
```c
#include <stdarg.h>
#include <stdio.h>
int vsprintf(char *restrict s, size_t n, const char *restrict format, va_list arg);
```

### 描述
vsprintf 函数等同于 sprintf，但将参数列表替换为 arg，该 arg 应该由 va_start 宏（可能通过随后的 va_arg 调用）进行初始化。vsprintf 函数不调用 va_end 宏。如果在相互重叠的对象之间进行拷贝，则行为未定义。

### 返回
vsprintf 函数返回写入数组的字符数（不包括末尾的空字符），如果发生编码错误，则返回一个负值。

### 返回

## 字符输入输出函数

### 概要
```c
#include <stdio.h>
int fgetc(FILE *stream);
```

### 描述
如果没有文件结束指示位且存在下一个字符，fgetc 从输入流获取下一个字符。如果文件结束，文件结束指示位被设置，fgetc 返回 EOF。如果发生读取错误，错误指示位被设置，fgetc 返回 EOF。

### 概要
```c
#include <stdio.h>
char *fgets(char *restrict s, int n, FILE *restrict stream);
```

### 描述
fgets 函数流中读取最多 n-1 个字符，直到遇到换行符（会被保留）或文件结束。读取的最后一个字符后会写入一个空字符。如果发生读取错误，数组内容保持不变并返回空指针。

### 概要
```c
#include <stdio.h>
int fputc(int c, FILE *stream);
```

### 描述
fputc 函数将指定的字符 c（转换为 unsigned char）写入指向 stream 的输出流，位于位置指示器指示（如果定义），并相应移动指示器。如果文件不支持定位，或者流是以追加模式打开的，则字符将追加到输出流中。

### 返回
如果发生写入错误，错误指示位被设置，fputc 返回 EOF。

### 概要
```c
#include <stdio.h>
int fputs(const char *restrict s, FILE *restrict stream);
```

### 描述
fputs 将指向 s 的字符串写入指向 stream 中。不写入末尾的空字符。

### 返回
如果发生写入错误，fputs 返回 EOF；否则返回非负值。

### 概要
```c
#include <stdio.h>
int getc(FILE *stream);
```

### 描述
getc 函数等同于 fgetc，但如果它是作为宏实现的，它可能会多次求值 stream，因此参数不应是具有副作用的表达式。

### 返回
getc 函数从指向 stream 的输入流获取下一个字符。如果文件结束，文件结束指示位被设置，getc 返回 EOF。如果发生读取错误，错误指示位被设置，getc 返回 EOF。

### 概要
```c
#include <stdio.h>
int getchar(void);
```

### 描述
getchar 函数等同于带有参数 stdin 的 getc。

### 返回
getchar 函数从指向 stdin 的输入流获取下一个字符。如果文件结束，文件结束指示位被设置，getchar 返回 EOF。如果发生读取错误，错误指示位被设置，getchar 返回 EOF。
