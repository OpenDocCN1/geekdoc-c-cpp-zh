The isgreaterequal macro determines whether its first argument is greater or equal to its second. The value of isgreaterequal(x, y) is always equal to (x) >= (y); however, unlike (x) >= (y), isgreaterequal(x, y) does not raise the “invalid” floating-point exception when x and y are unordered.

# Returns

The isgreaterequal macro returns the value of (x) >= (y).
