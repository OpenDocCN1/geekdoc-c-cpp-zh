If there is a runtime-constraint violation, wcstombs_s does the following. If retval is not a null pointer, wcstombs_s sets *retval (size_t) (-1). If dst is not a null pointer and dstmax is greater than zero and less than RSIZE_MAX, then wcstombs_s sets dst [0] to the null character.

# Description

The wcstombs_s function converts a sequence of wide characters from the array pointed to by src into a sequence of corresponding multibyte characters that begins in the initial shift state. If dst is not a null pointer, the converted characters are stored into the array pointed to by dst. Conversion continues up to and including a terminating null character, which is also stored. Conversion starts early in two cases:

+   - when a wide character is reached that does not correspond to a valid multibyte character;
- (if dst is not a null pointer) the next multibyte character would exceed the limit of n bytes to be stored in the array pointed to by dst. If the character being converted is the null character, then n is the lesser of len or dstmax. Otherwise, n is the lesser of len or dstmax-1.

If the conversion stops without converting a wide character and dst is not a null pointer, then a null character is stored in the array pointed to by dst immediately following any multibyte characters already stored. Each conversion takes place as if a call to the wcertmb function were made.⁴¹⁶

Regardless of whether dst is or not a null pointer, if the input encounters a wide character that does not correspond to a valid multibyte character, an encoding error occurs: the wcstombs_s function stores the value (size_t) (-1) into *retval. Otherwise, the wcstombs_s function stores into *retval the number of bytes in the resulting multibyte sequence, including the terminating null character (if any).

All elements following the terminating null character (if any) written by wcstombs_s in the array of dstmax elements pointed to by dst take unspecified values when wcstombs_s returns.⁴¹⁷

If copying takes place between objects that overlap, the objects take on unspecified values.

> ⁴⁶ If conversion stops because a terminating null character has been reached, the bytes include those necessary to reach the initial shift state immediately before the null byte. However, if the conversion stops before a terminating null character has been reached, the result will be null, but might not end in the initial shift state.

> ⁴¹⁷ When len is less than dstmax, the implementation might fill the array before discovering a runtime-constraint violation.
