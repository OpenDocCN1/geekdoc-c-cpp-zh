If at one argument for a generic parameter is complex, then use of the macro invokes a complex function; otherwise, use of the macro results in a real function.

For each unsuffixed function in `<math.h>` without a c-fixed counterpart in `<complex.h>` (except modf), the corresponding type-generic macro has the same name as the function. These type-generic macros are:

| atan2 | fma | ll1round | remainder |

| floor | l1rint | nexttoward | |

If all arguments for generic parameters are real, then use of the macro invokes a real function; otherwise, use of the macro results in undefined behavior.
