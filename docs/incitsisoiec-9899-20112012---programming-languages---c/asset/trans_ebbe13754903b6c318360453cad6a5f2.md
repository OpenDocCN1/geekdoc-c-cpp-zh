

对于在作用域内没有函数原型的函数调用，该函数未以函数原型的形式定义，或者在提升后的参数类型与提升后的参数类型不兼容（某些例外除外）(6.5.2.2)。

-   函数定义的类型与表示被调用函数的表达式所指向的类型（表达式的类型）不兼容 (6.5.2.2)。

-   访问了原子结构体或联合体的成员 (6.5.2.3)。

-   一元运算符 `*` 的操作数具有无效值 (6.5.3.2)。

-   指针被转换为整数或指针以外的类型 (6.5.4)。

-   `/` 或 `%` 运算符的第二个操作数为零 (6.5.5)。

-   指向数组对象内部或紧邻其边界的指针与整数类型进行加减法，产生的结果未指向同一个数组对象内部或紧邻其边界 (6.5.6)。

-   指向数组对象内部或紧邻其边界的指针与整数类型进行加减法，产生的结果指向该数组对象的边界，并被用作已求值的一元运算符 `*` 的操作数 (6.5.6)。

-   未指向同一个数组对象内部或紧邻其边界的指针进行相减法 (6.5.6)。

-   数组下标超出范围，即使在给定声明 `int a[4][5]` 的情况下，该下标对应的对象显然是可以访问的（例如在值表达式 `a[1][7]` 中）(6.5.6)。

-   两个指针相减的结果无法在 `ptrdiff_t` 类型对象中表示 (6.5.6)。

-   表达式被负数位移，或位移量大于或等于提升后的表达式宽度 (6.5.7)。

-   表达式的符号提升后类型被左移，且表达式的值为负，或者位移结果无法在提升后的类型中表示 (6.5.7)。

-   使用关系运算符比较未指向同一个聚合体或联合体（且未紧邻数组对象边界）的指针 (6.5.8)。

-   将一个对象赋值给部分重叠的对象，或赋值给类型不兼容的全重叠的对象 (6.5.16.1)。

-   要求为整数常量表达式的表达式不具有整数类型；其操作数不是整数常量、枚举常量、字符常量、结果为整数常量的 `sizeof` 表达式、`_Align` 表达式或立即类型转换常量；或者包含类型转换（`sizeof` 或 `_Align` 运算符的操作数外）或其他算术类型到整数类型的转换；或者在初始化器中在程序执行时求值不等于以下之一：
-   算术常量表达式、空指针常量、地址常量，或完整对象类型加或减整数常量表达式 (6.6)。
-   算术常量表达式不具有算术类型；其操作数不是整数常量、浮点常量、枚举常量、字符常量、结果为整数常量的 `sizeof` 表达式或 `_Align` 表达式；或包含类型转换（`sizeof` 或 `_Align` 运算符的操作数外）或其他算术类型到算术类型的转换 (6.6)。

-   通过下标 `[]`、成员访问 `.` 或 `->`、地址 `&`、间接运算符 `*` 或创建地址常量中的指针访问对象的值 (6.6)。

-   一个无链接的对象标识符在在声明符后类型不完整，或者在有初始化器的情况下其类型不完整 (6.7)。

-   在块作用域内使用非 `extern` 的明确存储类说明符声明函数 (6.7.1)。

-   结构体或联合体未定义命名成员（包括通过匿名结构体和联合体间接指定的成员）(6.7.2.1)。

-   当引用对象未提供该数组元素时，尝试访问或生成指向结构体成员边界的指针 (6.7.2.1)。

-   当需要完整类型时，不完整的结构体或联合体类型在定义内容的另一个声明中未被完成 (6.7.2.3)。

-   通过非 `const` 限定类型的左值修改具有 `const` 限定类型的对象 (6.7.3)。

-   通过非 `volatile` 限定类型的左值引用具有 `volatile` 限定类型的对象 (6.7.3)。

-   函数类型说明包含任何类型限定符 (6.7.3)。

-   两个要求兼容的限定类型未具有该类型的相同限定符版本 (6.7.3)。

-   已修改的对象通过 `const` 限定类型的指针访问，或者通过未基于相同对象的指针访问 (6.7.3)。

-   具有 `restrict` 限定类型的指针通过另一个指针赋值，该指针的关联块在赋值前已执行，但在赋值前未结束 (6.7.3.1)。

-   具有外部链接的函数声明了 `inline` 说明符，但在同一编译文件中未定义 (6.7.4)。

-   函数返回给调用者 (6.7.4)。

-   对象的定义具有对齐说明符，而另一个声明具有不同的对齐说明符 (6.7.5)。

-   不同编译文件的对象声明具有不同的对齐说明符 (6.7.5)。

-   两个要求相同限定的指针不兼容，或者不是指向兼容类型的指针 (6.7.6)。

-   数组声明中的 `size` 表达式不是常量表达式，且在程序执行时求值为非正值 (6.7.6)。

-   在要求两个数组兼容的情况下，它们不具有兼容的元素，或者它们的大小说明符求值不等 (6.7.6)。

-   数组参数包含 `static` 关键字，且对应的参数未提供对具有至少指定数量元素的数组访问 (6.7.6.3)。

-   函数定义包含标识符列表，但参数类型未在随后的声明列表中声明 (6.9.1)。

-   函数定义中的调整后参数类型不是完整对象类型 (6.9.1)。

-   接受可变参数的函数没有以省略号 `...` 结尾的参数列表 (6.9.1)。

-   到达结束函数的 `)`，且调用值被调用者使用 (6.9.1)。

-   具有内部链接且类型不完整的对象标识符通过尝试定义声明 (6.9.2)。

-   在 `#if` 或 `#elif` 预处理指令的扩展期间生成 `defined` 标记，或者 `defined` 一元运算符的使用在宏替换前不符合指定的两种形式之一 (6.10.1)。

-   展开后的 `#include` 预处理指令不符合两种头文件名形式之一 (6.10.2)。

-   `#include` 预处理指令中的字符序列未以字母开头 (6.10.2)。

-   宏参数列表中存在在其他情况下将作为预处理指令的预处理标记 (6.10.3)。

-   预处理运算符 `#` 的结果不是有效的字符字符串字量 (6.10.3.2)。

-   预处理运算符 `##` 的结果不是有效的预处理标记 (6.10.3.3)。

-   展开后的 `#line` 预处理指令不符合两种定义形式之一，或者其数字序列指定零或大于 2147483647 的数 (6.10.4)。

-   遇到了记录为会导致编译失败或其他形式的未定义行为的非 `STDC #pragma` 预处理指令 (6.10.6)。

-   `#pragma STDC` 预处理指令或标识符 `defined` 不符合两种定义形式之一 (6.10.6)。

-   预定义宏的名字是 `#define` 或 `#undef` 预处理指令的主体 (6.10.8)。
