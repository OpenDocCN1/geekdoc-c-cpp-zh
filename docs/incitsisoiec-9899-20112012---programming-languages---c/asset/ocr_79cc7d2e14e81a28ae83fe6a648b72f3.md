# K.3.8 Date and time <time.h>

1 The header <time.h> defines two types.

2 The types are

erno_t
which is type int; and

rsize_t
which is the type size_t.

# K.3.8.1 Components of time

1 A broken-down time is normalized if the values of the members of the tm structure are in their normal ranges.(429)

# K.3.8.2 Time conversion functions

1 Like the str function, the asctime_s and ctime_s functions do not return a pointer to static object, and other library functions are permitted to call them.

# K.3.8.2.1 The asctime_s function

Synopsis

```
1 #define __STDC_WANT_LIB_EXT1__ 1
#include <time.h>
erno_t asctime_s(char *s, rsize_t maxsize,
const struct tm *timeptr);
```

Runtime-constraints

2 Neither nor timeptr shall be a null pointer. maxsize shall not be less than 26 and shall not be greater than RSIZE_MAX. The broken-down time pointed to timeptr shall be normalized. The calendar year represented by the broken-down time pointed to timeptr shall not be less than calendar year 0 and shall not be greater than calendar 9999.

3 If there is a runtime-constraint violation, there is no attempt to convert the time, and s[0] is set to a null character if s is not a null pointer and maxsize is not zero and is not greater than RSIZE_MAX.
