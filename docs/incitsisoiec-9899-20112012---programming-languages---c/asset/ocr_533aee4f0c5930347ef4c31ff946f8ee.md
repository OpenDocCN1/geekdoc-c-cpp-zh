# 6.4.6 Punctuators

# Syntax

+   punctuator: one of
[ ] ( ) { } ->
++ -- & * + ~ !
/ : % << >> > <= == != | && ||
? : i ...
* = /= % += - <= >> &= ^= | =
# ##
<: : > < % > &: % ::

# Semantics

+   A punctuator is a symbol that has independent syntactic and semantic significance. Depending on context, it may specify an operation to be performed (which in turn may yield a value or a function designator, produce a side effect, or some combination thereof) in case it is known as an operator (other forms of operator also exist in some contexts). An operand is an entity on which an operator acts.
