# EXAMPLE 8 The declaration

```
char s[] = "abc", t[3] = "abc";
```

defines “plain” char array objects s and t whose elements are initialized with character string literals.
de This declaration is identical to

```
char s[] = { 'a', 'b', 'c', '\0' };
t[] = { 'a', 'b', 'c' };
```

The contents of the arrays are modifiable. On the other hand, the declaration

```
char *p = "abc";
```

p with type "pointer to char" and initializes it to point to an object with type "array of char"
with length 4 elements are initialized with a character string literal. If an attempt is made to use p
modify the contents of the array, his behavior is undefined.

# EXAMPLE 9 Arrays are initialized to correspond to the elements of an enumeration using
designators:

```
enum { member_one, member_two };
const char *nm[] = {
    [member_two] = "member two",
    [member_one] = "member one"\n};
```

# EXAMPLE 10 Structures are initialized to nonzero values depending on their order:

```
div_t answer = { .quot = 2, .rem = -1 };
```

# EXAMPLE 11 Designators can be used to provide explicit initialization when unadorned lists
might be misunderstood:

```
struct { int a[3], b; w[] = =
    [0].a = {1}, [1].a[0] = 2 };
```

# EXAMPLE 12 Space can be "allocated" from both ends of an array by using a single designator:

```
int a[MAX] = {
    1, 3, 5, 7, 9, [MAX-5] = 8, 6, 4, 2, 0
};
```

In the above, if MAX is greater than ten, there will be zero-valued elements in the middle; if it is less
than ten, some of the values provided by the first five initializers will be overridden by the second five.

# EXAMPLE 13 Any member of a union can be initialized:

```
union { /* ... */ } u = { .any_member = 42 };
```
