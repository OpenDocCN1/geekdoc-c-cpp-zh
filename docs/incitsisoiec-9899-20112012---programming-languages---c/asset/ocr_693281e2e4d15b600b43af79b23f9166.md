#  7.30.3.2.1 The wctrans function

# Synopsis

```
#include <ctype.h>
wint_t wctrans(wint_t wc, wctrans_t desc);
```

# Description

The wctrans function maps the wide character wc using the mapping described by desc. The current setting of the LC_CTYPE category shall be the same as during the call to wctrans that returned the value desc.

Each of the following expressions behaves the same as the call to the wide character mapping function (7.30.3.1) in the comment that follows the expression:

```
wctrans(wc, "towlower") // towlower(wc)
wctrans(wc, wctrans("toupper")) // toupper(wc)
```

# Returns

The wctrans function returns the mapped value of wc using the mapping described by desc. If desc is zero, the wctrans function returns the value of wc.

#  7.30.3.2.2 The wctrans function

# Synopsis

```
#include <ctype.h>
wctrans_t wctrans(const char *property);
```

# Description

The wctrans function constructs a value with type wctrans_t that describes a mapping between wide characters identified by the string argument property.

The strings listed in the description of the wctrans function shall be valid in all locales as property arguments to the wctrans function.

# Returns

If property identifies a valid mapping of wide characters according to the LC_CTYPE category of the current locale, the wctrans function returns a nonzero value that is valid as the second argument to the wctrans function; otherwise, it returns zero.
