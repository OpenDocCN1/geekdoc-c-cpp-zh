The conversion specifier includes all subsequent characters in the format string, up to and including the matching bracket (]). The characters between the brackets (scanlist) compose the scanet, unless the character after the left bracket is a circumflex (^), in which case the scanet contains all characters that do not appear in the scanet between the circumflex and the right bracket. If the conversion specifier begins with [] or [^], the right bracket character is in the scanlist and the next right bracket character is the matching right bracket that ends the specification; otherwise the first following right bracket character is the one that ends the specification. If a - character is in the scanet and not the first, nor the first character is a ^, nor the last character, the behavior is implementation-defined.

If the conversion specification includes an assignment-suppressing character or a field width, the behavior is undefined.
