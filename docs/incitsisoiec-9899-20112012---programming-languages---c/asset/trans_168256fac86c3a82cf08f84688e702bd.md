
如果初始化了一个大小未知的数组，其大小由具有显式初始化器的最大索引元素决定。数组类型在它的初始化列表结束时完成。

初始化列表中的表达式的求值顺序彼此之间是不确定顺序（indeterminately sequenced），因此任何副作用发生的顺序是未指定的。¹152)

示例 1 假设已包含 `<complex.h>`，以下声明：

```c
int i = 3.5;
double complex c = 5 + 3 * I;
```

定义了 `i` 并将其初始化为值 `c` 以及值 `5.0 + i`。

示例 2 声明：

```c
int x[] = { 1, 3, 5 };
```

定义并初始化 `x` 为一个具有三个元素的一维数组对象，因为没有指定大小，且有三个初始化器。

示例 3 声明：

```c
int y[4][3] = {
{ 1, 3, 5 },
{ 2, 4, 6 },
{ 3, 5, 7 },
};
```

这是一个带有全括号初始化的定义：1, 3 和 5 分初始化了 `y` 的第一行（数组对象 `y[0]`），即 `y[0][0]`、`y[0][1]` 和 `y[0][2]`。同样地，接下来的两行 `y[1]` 和 `y[2]`。初始化器提前结束，`y[3]` 被初始化为零。也可以达到完全相同的效果：

```c
int y[4][3] = {
{ 1, 3, 5, 2, 4, 6, 3, 5, 0 },
};
```

`y[0]` 的初始化器没有以左括号开头，因此使用了列表中的三个元素。同样，接下来的三个元素依次用于 `y[1]` 和 `y[2]`。

示例 4 声明：

```c
int z[4][3] = {
{ 1 }, { 2 }, { 3 }, { 4 },
};
```

按指定初始化了 `z` 的第一列，并将其余部分初始化为零。

示例 5 声明：

```c
struct { int a[3], b; } w[] = { 1 }, { 2 };
```

这是一个带有不一致括号初始化的定义。它定义了一个包含两个结构的数组：`w[0].a[0]` 为 1，`w[1].a[0]` 为 2；所有其他元素均为 0。

152) 特别地，求值顺序不需要与子对象初始化的顺序一致。

示例 6 声明：

```c
short q[4][3][2] = {
 { 1 },
  { 2, 3 },
  { 4, 5, 6 }
};
```

包含一个不完整但括号一致的初始化。它定义了一个三维数组对象：`q[0][0][0]` 为 1，`q[1][0][0]` 为 2，`q[1][0][1]` 为 3，而 4, 5 和 6 分别初始化了 `q[2][0][0]`。`q[2][0][1]` 为 1，`q[2][1][0]` 为 2；其余部分均为零。`q[0][0][0]` 的初始化器没有以左括号开头，因此可以使用当前列表中的最多六项。由于这里只有一个，所以其余五个元素的值被初始化为零。同样，`q[1][0]` 和 `q[2][0]` 的初始化器没有以左括号开头，因此每个都使用了最多六项，初始化了它们各自的二维子聚合。如果任何列表中的项目多于六项，则会发出诊断信息。

```c
short q[4][3][2] = {
 1, 0, 0, 0, 0,
  2, 3, 0, 0, 0,
  4, 5, 6
}
```

或者通过：

```c
short q[4][3][2] = {
 { 1 },
 {
 { 2, 3 },
 {
 { 4, 5 },
 { 6 },
 };};
```

以全括号格式进行。

注意，通常情况下，全括号和最少括号形式的初始化不容易引起混淆。

示例 7 一完成数组类型的初始化形式涉及类型定义名。给定声明：

```c
typedef int a[]; // OK - 在块作用域内声明
```

声明：

```c

```

由于不完全类型的规则，它等同于：

```c
int a[] = { 1, 2 }, b[] = { 3, 4, 5 };
```

示例 8 声明：

```c
char s[] = "abc", t[3] = "abc";
```

定义了“普通”字符数组对象 `s` 和 `t`，其元素用字符字符串字面量初始化。该声明等同于：

```c
char s[] = { 'a', 'b', 'c', '\0' };
t[] = { 'a', 'b', 'c' };
```

数组的内容是可修改的。另一方面，声明：

```c
char *p = "abc";
```

`p` 的类型为“指向字符的指针”，并初始化为指向一个长度为 4 个元素的“字符数组”类型的对象。

## 6.8 语句

### 语法
```c
statement:
- labeled-statement
- compound-statement
- expression-statement
- selection-statement
- iteration-statement
- jump-statement
```

### 语义
语句指定执行的操作。

#### 6.8.1 L语句

### 语法
```c
labeled-statement:
- identifier : statement
- case constant-expression : statement
- default : statement
```

### 约束
`case` 或 `default` 标签仅出现在 `switch` 语句中。此类标签的进一步约束在 `switch` 语句部分讨论。标签名在函数范围内应该是唯一的。

### 语义
标签本身不改变控制流，控制流不受阻地继续。

**引用：** `goto` (6.8.6.1)，`switch` 语句 (6.8.4.2)。

#### 6.8.2 复合语句

### 语法
```c
compound-statement:
  { block-item-list opt }

  block-item-list:
    block-item
    block-item-list block-item

  block-item:
    declaration
    statement
```

### 语义
复合语句是一个块。

#### 6.8.3 表达式语句和空语句

### 语法
```c
expression-statement:
  expression_opt ;
```

### 语义
表达式语句中的表达式作为 void 表达式进行求值。¹153

空语句（仅由分号组成）不执行任何操作。

示例 1 如果函数调用仅为了副作用作为表达式语句求值，可以通过强制转换将表达式转换为 void 表达式来显式丢弃其值：

```c
int p(int);
/* ... * */
(void)p(0);
```

> 153) 这些赋值以及具有副作用的函数调用。
