# Semantics

If, in the declaration “T D1”, D1 has one of the forms:

**D[ type-qualifier-list_opt assignment-expression_opt ]**
**D[ static type-qualifier-list_opt assignment-expression ]**
**D[ type-qualifier-list_opt static assignment-expression * ]**

and the type specified for ident in the declaration “T D” is “derived-declarator-type-list array of T”¹⁴²² (See 6.7.6.3 for the meaning of the optional type qualifiers and the keyword **static.**)

If the size is not set, the array is an incomplete type. If the size is instead of being an expression, the array type is a variable length array of unspecified size, which can only be used in declarations or type names with function prototype scope¹⁴³ such arrays are nevertheless complete types. If the size is an integer constant expression and the element type has a known constant size, the array type is not a variable length array type; otherwise, the array type is a variable length array type. (Variable length arrays are a conditional feature that implementations need not support; see 6.10.8.3.)

If the size is an expression that is not an integer constant expression: if it occurs in a declaration at function prototype scope, it is treated as if it were replaced by _; otherwise each time it is evaluated it will have a value greater than zero. The size of instance of a variable length array type does not change during its lifetime. Where a size expression is part of the operand of a sizeof operator and changing the value of the size expression would not affect the result of the operator, it is unspecified whether or not the size expression is evaluated.

For two array types to be compatible, both shall have compatible element types, and if both sizes are present, and integer constant expressions, then both size specifies shall have the same constant value. If the two arrays are used in a context which requires them to be compatible, it is undefined behavior if the two size specifies evaluate to unequal values.

EXAMPLE 1

```
float fa[11], *afp[17];
```

declares an array of float numbers and an array of pointers to float numbers.
