## 7.3 复数算术 <complex.h>

### 7.3.1 引言

头文件 <complex.h> 定义了支持复数算术的宏并声明了函数.¹192)

定义宏 __STDC_NO_COMPLEX__ 的实现不需要提供此头文件，也不支持其任何功能。

每个概要都指定了一系列函数，由具有一个或多个 `double complex` 参数以及 `double complex` 或 `double` 返回值的主函数组成；具有相同名称但带有 `f` 和 `l` 后缀的函数是对应 `float` 和 `long double` 参数及返回值的函数。

宏

```
complex
```
展开为 `_Complex`；宏

```
_Complex_I
```
展开为类型为 `const float _Complex` 的常量表达式，其值为虚数单位.¹193)

宏

```
imaginary
```

和

```
_Imaginary_I
```
当且仅当实现支持虚数类型时定义；¹194 如果已定义，它们展开为 `_Imaginary` 和类型为 `float _Imaginary` 的虚数单位常量表达式。

宏

```
I
```
展开为 `_Imaginary_I` 或 `_Complex_I`。如果 `_Imaginary_I` 未定义，则 `I` 应展开为 `_Complex_I`。

尽管有 7.1.3 的规定，程序也可以取消定义并重新定义宏 `complex`、`imaginary` 和 `I`。

192) 参见“未来库方向”(7.31.1)。

193) 虚数单位是 `i`，使得 $i^2 = -1$。

194) 虚数类型的规范见信息性附件 G。

前向引用：兼容 IEC 60559 的复数算术（附件 G）。

## 7.3.3 支割

某些函数具有支割，函数在跨越支割时是不连续的。对于具有符号零（包括所有 IEC 60559 实现）并遵循附件 G 规范的实现，零的符号区分了支割的两个侧，因此当从任侧接近支割时，函数是连续的（格式限制除外）。例如，对于平方根函数，它在负实轴上有一个支割，支割的顶部（虚部为 +0）映射到正虚轴，而支割的底部（虚部为 -0）映射到负虚轴。

不支持符号零（附件 F）的实现无法区分支割的侧边。这些实现应当映射支割，使得当逆时针绕支割的有限端点接近支割时，函数是连续的。（此处指定的函数支割只有一个端点。）对于平方根函数，沿负实轴逆时针绕支割的有限端点从上方接近支割，因此支割映射到正虚轴。

## 7.3.4 CX_LIMITED_RANGE pragma

概要

```
#include <complex.h>
#pragma STDC CX_LIMITED_RANGE on-off-switch
```

描述

复数乘法、除和绝对值的通常数学公式由于其对无穷大的处理以及不必要的溢出和下溢存在问题。`CX_LIMITED_RANGE` pragma 可用于告知实现（当状态为“开启”时）通常数学公式是可以接受的。该 pragma 可以出现在复合语句的外部，也可以出现在所有显式声明之前。当在外部声明时，该 pragma 从出现处开始生效，直到遇到另一个 `CX_LIMITED_RANGE` pragma，或者到翻译单元的结束。在复合语句内部，该 pragma 从出现处开始生效，直到遇到另一个 `CX_LIMITED_RANGE` pragma（包括在嵌套复合语句内部），或者到复合语句结束；该 pragma 的状态将恢复到之前的条件。如果在任何其他上下文中使用此 pragma，则行为是未定义的。该 pragma 的默认状态为“关闭”。

## 7.3.5 三角函数

### 7.3.5.1 cacos 函数

概要

```
#include <complex.h>
double complex cacos(double complex z);
float complex acos(float complex z);
long double complex acacos(long double complex z);
```

描述

`cacos` 函数计算 z 的复数反余弦，其支割沿实轴位于区间 $[-1, +1]$ 之外。

返回值

`cacos` 函数返回复数反余弦值，其范围在一个在沿虚轴方向数学上无界的带内，并在实轴上处于 $[0, \pi]$ 区间。
