If the declaration occurs outside of any function, the identifiers have file scope and external link. If the declaration occurs inside a function, the identifiers of the functions f and fip have file scope and internal or external link depending on what file scope declarations for these identifiers are visible), and the identifier of the pointer pfi has file scope and no linkage.

# EXAMPLE 2 The declaration

```
int (*apfi[3]) (int *x, int *y);
```

declares an array apfi of three pointers to functions returning int. Each of the functions has two parameters that are pointers to int. The identifiers x and y are declared for descriptive purposes only and go out of scope at the end of the declaration of apfi.

# EXAMPLE 3 The declaration

```
int (*fpfi (int (*long), int), ...));
```

declares a function fpfi that returns a pointer to a function returning int. The function fpfi has two parameters: a pointer to a function returning int (with one parameter of type long), and an int. The pointer returned by fpfi points to a function that has one int parameter and accepts zero or more arguments of any type.

# EXAMPLE 4 The following prototype has a variably modified parameter.

```
void addscalar(int n, int m,
    double a[n][n*m+300], double x);

int main() {
    double b[4][308];
    addscalar(4, 2, b, 2.17);
    return 0;
}

void addscalar(int n, int m,
    double a[n][n*m+300], double x) {
    for (int i = 0; i < n; i++) {
        for (int j = 0, k = n*m+300; j < k; j++) {
            // a is a pointer to a VLA with n*m+300
            a[i][j] += x;
        }
    }
}
```
