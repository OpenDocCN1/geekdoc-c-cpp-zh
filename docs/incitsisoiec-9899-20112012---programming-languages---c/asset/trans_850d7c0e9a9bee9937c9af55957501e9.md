## 6.10.4 行控制

约束条件

- 1 `#line` 指令的字符串字面量（如果存在）应当是一个字符字符串字面量。
- 2 在处理源文件到当前标记时，翻译阶段 1 中读取或引入的换行符字符数量（5.1.1.2）小于当前源行的行号。

语义

- 3 形式如下的预处理指令：

`# line digit-sequence new-line`

会导致实现将当前源文件的行号设置为 `digit-sequence` 指定的数字。

- 4 形式如下的预处理指令：

`# line digit-sequence "s"`
该实现将行号设置为 `digit-sequence`，并将源文件名设置为 `"s"` 的内容。

- 5 形式如下的预处理指令：

`# line pp-tokens new-line`
实现将当前源文件的行号设置为 `new-line` 指定的数字，该数字不为 0，也不大于 214748367。

## 6.10.5 错误指令

语义

形式如下的预处理指令：

```c
# error pp-tokens
```
会导致实现产生包含 `pp-tokens` 的诊断信息。

## 6.10.6 指令

语义

形式如下的预处理指令：

```c
# pragma pp-tokens
```
实现应当忽略 `pp-tokens`。

## 6.10.7 空指令

语义

形式如下的指令：

```c
#
```
没有任何影响。

## 6.10.8 预定义宏

除下述宏外，预定义宏的值在整个翻译单元中保持不变。

这些宏的任何标识符都不应以下划线后跟大写字母开头。

## 6.10.8.1 强制宏

实现应当定义以下宏：

- `__DATE__` 翻译日期：形式为 "mm dd yyyy" 的字符串字面量。如果日期不可，应提供一个实现有效的日期。
- `__FILE__` 假设源文件名（字符字符串），¹⁶
- `__LINE__` 假设行号（整数）。¹⁷
- `__STDC__` 整数常量 1，用于表示实现是标准的。
- `__STDC_HOSTED__` 如果实现是宿主的则为 1，否则为 0。

## 6.10.8.2 环境宏

以下宏根据条件定义：

- `__STDC_ISO_10646__` 形式为 yymmL 的整数常量（例如 1997L）。如果该符号被定义，则存储在 `char_t` 对象中的每一个字符都与其值相等。Unicode 要求集包含了截至指定年份月份 ISO/IEC 10646 定义的所有修订和技术修正。如果使用了其他编码，则该宏不定义，且实际编码由实现决定。
- `__STDC_MB_MIGHT_NEO_WC__` 常量 1，用于表示在 `char_t` 编码中，基本字符集的成员在作为整数常量中的唯一字符使用时，其值可能与其相等。
- `__STDC_UTF_16__` 整数常量 1，用于表示 `char16_t` 的值为 UTF–16。
- `__STDC_UTF_32__` 整数常量 1，用于表示 `char32_t` 的值为 UTF–32。

¹⁶ 参见“未来方向”（6.11）。
¹⁷ 假设源文件名和行号可以通过 `#line` 指令更改。
¹⁸ `__STDC_VERSION__` 整数常量形式为 yymmL
