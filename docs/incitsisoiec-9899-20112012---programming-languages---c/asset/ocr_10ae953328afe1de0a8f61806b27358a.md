If a type specifier of the form

```
struct-or-union identifier
enum identifier
```

occurs other than as part of the above forms, and a declaration of the identifier as a tag is visible, if it specifies the same type as that other declaration, and does not redeclare the tag.

EXAMPLE 1 This mechanism allows declaration of a self-referential structure.

```
struct tnode {
    int count;
    struct tnode *left, *right;
};
```

specifies a structure that contains an integer and two pointers to objects of the same type. Once this declaration has been given, the declaration

```
struct tnode s, *sp;
```

declares s to be an object of the given type and sp to be a pointer to an object of the given type. With these declarations, the expression sp->left refers to the left struct tnode pointer of the object to which sp points; the expression s.right->count designates the count member of the right struct tnode pointed to by s.

11 The following alternative formulation uses the typedef TNODE;

```
typedef struct tnode TNODE;
struct tnode {
    int count;
    TNODE *left, *right;
};
TNODE s, *sp;
```

12 EXAMPLE 2 To illustrate the use of prior declaration of a tag to specify a pair of mutually referential structures, the declarations

```
struct s1 { struct s2 *sp2; /* ... }; // D1
struct s2 { struct s1 *sp1; /* ... }; // D2
```

specify a pair of structures that contain pointers to each other. However, if s2 were already declared as a tag in an enclosing scope, the declaration D1 would refer to it, not to the tag s2 declared in D2. To eliminate this context, the declaration

```
struct s2;
```

may be inserted ahead of D1. This declares a new tag s2 in the inner scope; the declaration D2 then completes the specification of the new type.
