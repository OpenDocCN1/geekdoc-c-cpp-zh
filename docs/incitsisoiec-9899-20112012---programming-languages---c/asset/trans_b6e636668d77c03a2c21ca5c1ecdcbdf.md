
输入空白字符（由 `ispace` 函数指定）将被跳过，除非规范中包含 `[`、`c` 或 `n` 格式指定符。²8⁴

从流中读取一个输入项，除非规范中包含 `n` 格式指定符。输入项被定义为不超过任何指定字段宽且是匹配序列的前缀的最长输入字符序列。输入项后的第一个字符（如果有的话）将保持不读状态。如果输入项的长度为 0，则该指令的执行将失败；此条件属于匹配失败，除非是因为文件结束（EOF）、编码错误或读取错误阻止了从流中输入，在这种情况下，它属于输入失败。

除 `%` 格式指定符的情况外，输入项（或在 `%n` 指令的情况下，输入字符的计数）将被转换为与转换格式指定符适当的类型。如果输入项不是匹配序列，则该指令的执行将失败；除非通过 `*` 表明了抑制赋值，否则转换结果将放在尚未接收结果的第一个参数所指向的对象中。如果该对象没有适当的类型，或者转换结果无法在对象中表示，则行为是未定义的。

修饰符及其含义为：

- `+ hh`
指定 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `signed char` 或 `unsigned char` 指针的参数。

- `+ h`
指定 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `short int` 或 `unsigned short int` 指针的参数。

- `+ l` (ell)
指定 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `long int` 或 `unsigned long int` 指针的参数；或者后续 `a`、`E`、`e`、`F`、`g` 或 `G` 格式指定符适用于类型为 `double` 指针的参数；或者后续 `c`、`s` 或 `[` 格式指定符适用于类型为 `wchar_t` 指针的参数。

- `+ ll` (ell-ell)
指定 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `long long int` 或 `unsigned long long int` 指针的参数。

²⁸⁴ 这些空白字符不计入指定的字段宽度。

²⁸⁵ `fscanf` 最将一个字符推回输入流。因此，某些 `strtod`、`strtol` 等可以接受的序列在 `fscanf` 中是不允许的。

- `+ j`
指定后续的 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `intmax_t` 或 `uintmax_t` 指针的参数。

- `+ z`
指定后续的 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `size_t` 或相应的符号整数类型指针的参数。

- `+ t`
指定后续的 `d`、`i`、`o`、`u`、`x` 或 `n` 格式指定符适用于类型为 `ptrdiff_t` 或相应的无符号整数类型指针的参数。

- `+ L`
指定后续的 `a`、`E`、`f`、`F`、`g` 或 `G` 格式指定符适用于类型为 `long double` 指针的参数。

如果在任何指定的格式指定符之外出现长度修饰符，则行为是未定义的。

转换格式指定符及其含义为：

- `+ d` 匹配一个可选带符号的十进制整数，其格式与 `strtol` 函数主体序列的预期格式相同，其中基数参数值为 10。相应的参数应为指向符号整数的指针。

- `+ i` 匹配一个可选带符号的整数，其格式与 `strtol` 函数主体序列的预期格式相同，其中基数参数值为 0。相应的参数应为指向符号整数的指针。

- `+ o` 匹配一个可选带符号的八进制整数，其格式与 `strtol` 函数主体序列的预期格式相同，其中基数参数值为 8。相应的参数应该是指向无符号整数的指针。

- `+ u` 匹配一个可选带符号的十进制整数，其格式与 `strtol` 函数主体序列的预期格式相同，其中基数参数值为 10。相应的参数应为指向无符号整数的指针。

- `+ x` 匹配一个可选带符号的十六进制整数，其格式与 `strtol` 函数主体序列的预期格式相同，其中基数参数值为 16。相应的参数应为指向无符号整数的指针。

- `+ a,e,f,g` 匹配一个可选带符号的浮点数、无穷大或 NaN，其格式与 `strtod` 函数主体序列的预期格式相同。相应的参数应为指向 `float` 的指针。

匹配长度与字段宽度指定的完全相同的字符序列（如果指令中没有字段宽度，则为 1）²²⁸⁶

如果不存在 `l` 长度修饰符，相应的参数应指向字符数组的起始元素，该数组应足够容纳该序列。不添加空字符。

如果存在 `l` 长度修饰符，输入应为从初始偏移状态开始的多字节字符序列。序列中的每个多字节字符都通过调用 `mbstowc` 函数转换为宽字符，转换状态由在转换第一个多字节字符之前初始化为零的 `mbstate_t` 对象描述。相应的参数应指向 `wchar_t` 数组的起始元素，该数组应足够容纳生成的宽字符序列。不添加空宽字符。

匹配非空白字符序列²²⁸⁶

如果不存在 `l` 长度修饰符，相应的参数应指向字符数组的起始元素，该数组应足够容纳序列。

如果存在 `l` 长度修饰符，输入应为从初始偏移状态开始的多字节字符序列。每个多字节字符通过调用 `mbstowc` 函数转换为宽字符，转换状态由在转换第一个多字节字符之前初始化为零的 `mbstate_t` 对象描述。相应的参数应指向 `wchar_t` 数组的起始元素，该数组应足够容纳生成的宽字符序列。不添加空宽字符。

匹配集合中的字符序列²²⁸⁶

如果不存在 `l` 长度修饰符，相应的参数应指向字符数组的起始元素，该数组应足够容纳序列，并添加空字符。

如果存在 `l` 长度修饰符，输入应为从初始偏移状态开始的多字节字符序列，每个多字节字符通过调用 `mbstowc` 函数转换为宽字符，转换状态由在转换第一个多字节字符之前初始化为零的 `mbstate_t` 对象描述。相应的参数应指向 `wchar_t` 数组的起始元素，该数组应足够容纳生成的宽字符序列。不添加空宽字符。

匹配格式字符串中随后的所有字符，直到并包括匹配的右括号 `]`。括号之间的字符（扫描列表）构成了扫描集，除非左括号后的字符是取反符号 `^`，在这种情况下扫描集包含 `^` 与右括号之间的所有字符。如果转换格式指定符以 `[]` 或 `[^` 开头，则右括号字符在扫描列表中，下一个右括号字符结束规范；否则，第一个后续右括号字符即结束规范。如果 `-` 字符在扫描集中且不是第一个字符，或者第一个字符是 `^` 且最后一个字符，则行为取决于实现。

匹配一个实现的序列，应与 `fprintf` 函数的 `%` 转换可能产生的序列相同。相应的参数应为指向 `void` 的指针。输入项将以实现的方式转换为指针值。如果输入是在同一程序执行期间之前转换的值，则指针应与该值相等；否则 `%` 转换的行为是未定义的。

不消耗输入。相应的参数应指向将写入此调用 `fscanf` 时从输入流中读取的字符数。执行 `%n` 指令不会增加 `fscanf` 执行完成时返回的赋值计数。没有参数被转换，但有一个。如果转换规范包含抑制字符或字段宽度，则行为是未定义的。

匹配单个 `%` 字符；不发生转换或赋值。整个转换规范无效，应为 `%`.
