## FLT_MANT_DIG
DBL_MANT_DIG
LDBL_MANT_DIG

十进制数字位数，$n$，使得任何具有 $p$ 位基 $b$ 位数字的浮点数都能舍入为具有 $n$ 位十进制数的浮点数并转换回来而值不变，

```
$p \log_{10} b \quad$ 如果 $b$ 是 10 的幂
$[1 + p \log_{10} b] \quad$ 否则
```

## FLT_DECIMAL_DIG
DBL_DECIMAL_DIG
LDBL_DECIMAL_DIG

十进制数字位数，$n$，使得在支持的最宽类型中具有 $p_{\max}$ 位基 $b$ 位数字的浮点数都能舍入为具有 $n$ 位十进制数的浮点数并转换回来而值不变，

```
$p_{\max} \log_{10} b \quad$ 如果 $b$ 是 10 的幂
$[1 + p_{\max} \log_{10} b] \quad$ 否则
```

## DECIMAL_DIG

十进制数字位数，$q$，使得任何具有 $q$ 位十进制数字的浮点数都能舍入为具有 $p$ 位基 $b$ 位数字的浮点数并转换回来而 $q$ 位十进制数字不变，

```
$p \log_{10} b \quad$ 如果 $b$ 是 10 的幂
[(p - 1) \log_{10} b] \quad$ 否则
```

# 6 语言

## 6.1 符号

在本句使用的语法符号中，语法类别（非终符）用*斜体类型*表示，字面量单词和字符集成员（终符）用**粗体类型**表示。非终符后的冒号（:）引入其定义。备选定义分行列出，除非以单词“one of”（之一）开头。可选符号由下标‘opt’标出，因此：

```
{ expression_opt }
```

表示大括号内的可选表达式。

在正文中引用语法类别时，它们不使用斜体，且单词用空格代替连字符分隔。

## 6.2 概念

### 6.2.1 标识符的作用域

标识符可以表示对象；函数；结构、联合或枚举的标记（tag）或成员；typedef 名称；标签名称；宏名称；或宏参数。同一个标识符可以在程序的不同点表示不同的实体。

对于每个表示标识符的实体，该标识符仅在称为*作用域*的程序文本区域内是*可见的*（即可以使用）。由同一标识符指定的不同实体具有不同的作用域，或在不同的命名空间中。作用域有四种：函数、文件、块和函数原型。（*函数原型*是声明了其参数类型的函数声明）。

标签是唯一具有*函数作用域*的种类。它可以在其出现的函数任何地方（在 goto 语句中）使用并通过其语法出现（后跟冒号和语句）被隐式声明。

每个标识符的作用域由声明符的位置决定。如果声明符或类型限定符声明标识符出现在任何块或参数列表之外，则该标识符具有*文件作用域*，在翻译单元的结束处终止。如果声明符或类型限定符声明标识符出现在块内部或函数定义中的参数列表中，则该标识符具有*块作用域*，在关联块的结束处终止。如果声明符或类型限定符声明标识符
