# ### ADD A COLORED MESSAGE

Let's add a message in colored text.

Add the following block to your program:

This message will appear above the flag.

The font size will automatically be set to 14, but you can change it to any size you want.

```
    when flag clicked
    set size to 14
    go to x: -150 y: 50
    say 'This is the Argentine flag!' for 2 secs
```

Press ▶ Run to test your program.

# ## 10 ADD TEXT

Now we can add some facts using print blocks from the Text menu:

These lines will appear separately at the bottom of the screen.

```
    when flag clicked
    go to x: -150 y: 50
    set size to 14
    print 'This is the Argentine flag!'
    print 'The capital of Argentina is Buenos Aires.'
    print 'The official language is Spanish.'
    print 'Lionel Messi was born in Argentina.'
```

# ### TROUBLESHOOTING

If the message: “This is the Argentine flag.” is not right above the flag, change the coordinates in these blocks:

```
    when flag clicked
    set size to 14
    go to x: -150 y: 50
    say 'This is the Argentine flag!'
```
