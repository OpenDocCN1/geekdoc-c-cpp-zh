# 6. ADD ITEMS TO THE LIST

A caterpillar’s body is made of several parts. The list you created in the previous step will help you add parts of the body to your drawing. Click on the list icon in the `create list with` block to add items.

```
`create list with`
```

You have to drag the `item` block and drop it inside the list block in the pop-out list. Add `item` until you have six inside the list block. The items will appear as six jigsaw slots in the `create list with` block.

```
`create list with`
```
