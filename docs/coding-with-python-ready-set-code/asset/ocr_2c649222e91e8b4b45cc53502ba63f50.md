# Creating Trinket accounts

Parental permission is required to create accounts for children under 13. It is recommended that a Trinket account be created by a parent or responsible adult.

Trinket can be used without downloading plug-ins or installing software. For your child to be able to save and share his or her projects, you will have to sign up and create a username and a password.
