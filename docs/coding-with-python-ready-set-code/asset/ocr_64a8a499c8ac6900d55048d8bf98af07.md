# ## OPEN A NEW TRINKET

Click on **New Trinket** and click on Blocks.

![](bbox=[0.094, 0.251, 0.878, 0.515])

You will see the following window. Click on Loops.

You will drop the blocks for your program in this white canvas.

The following menu will open up.

![](bbox=[0.095, 0.64, 0.458, 0.958])

> **What is a loop?**
> 
> A loop is a repeated command or set of commands. Loops repeat actions.

![](bbox=[0.815, 0.647, 0.976, 0.753])
