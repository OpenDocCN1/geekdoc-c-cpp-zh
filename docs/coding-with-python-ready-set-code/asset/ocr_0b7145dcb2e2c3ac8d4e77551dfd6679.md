# ## The life cycle of a butterfly

+   1. **Egg**
+      The female lays lots of little round eggs and attaches them to leaves or stems.
+   2. **Caterpillar (or larva)**
+      The eggs develop into caterpillars.
+   3. **Chrysalis (often called the pupa)**
+      This is a rest stage in which the caterpillar develops a hard, outer case. Inside the chrysalis, the caterpillar changes and becomes a butterfly.
+   4. **Butterfly**
+      Once the butterfly is ready to emerge, the case around the chrysalis splits open.
