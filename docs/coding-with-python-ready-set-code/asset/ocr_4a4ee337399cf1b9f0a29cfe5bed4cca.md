# DRAW THE CATERPILLAR'S HEAD

Add the following blocks to your program:

```
```scratch
when green flag clicked
set size to 50%
go to x: 0 y: 25
set pen size to 10
set color to [selected color]
pen down
repeat 25
  move 10 steps
  turn right 15 degrees
  move 10 steps
  turn left 15 degrees
pen up
```
```

This block will position the caterpillar's head.

Choose any suitable color for your caterpillar's head.

Press ▶ Run to test your program.

# TROUBLESHOOTING

If the circles that make the body of the caterpillar are a bit separated, you can solve this by reducing the number in the variable.

```
```scratch

  move 10 steps
