# COMPLETING THE DIALOGUE

To complete the dialogue between the turtles, add the following blocks to your program.

```
get [say] [Hello!]
when [green flag clicked]
say [Hello!]
wait [2] seconds
say [What can you code?]
wait [4] seconds
```

> You can right click on any block in the white canvas and copy it.

# CHALLENGE

Add more lines to the program to make the turtles have a longer conversation.

+   - Hello! What are you doing?
+   - I am coding with Python.
+   - What can you code?
+   - A circle
+   - Wow! That's great.
+   - Thanks.

# DRAW A CIRCLE

At the end of the dialogue, the blue turtle will draw a circle. Add the following blocks:

```
pen up
move [20] steps
pen down
set color to [orange]
forward [25]
turn right [20]
```

Press ▶ Run to test your program.

# TROUBLESHOOTING

If you prefer the text centered, use the [go to x: 0 y: 0] block to position the dialogue in the middle of your screen. Try [go to x: 0 y: 0] for your x-coordinates.
