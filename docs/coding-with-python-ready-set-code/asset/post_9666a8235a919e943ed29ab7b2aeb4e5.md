## DRAW THE CATERPILLAR’S HEAD

Add the following blocks to your program:

```scratch
when green flag clicked
set size to 50%
go to x: 0 y: 25
set pen size to 10
set color to [selected color]
pen down
repeat 25
  move 10 steps
  turn right 15 degrees
  move 10 steps
  turn left 15 degrees
pen up
```

This block will position the caterpillar's head.

Choose any suitable color for your caterpillar’s head.

Press ▶ Run to test your program.

![](img/a1849c7d7e98817476d64684d9c96952_32_0.png)

### TROUBLESHOOTING

If the circles that make the body of the caterpillar are a bit separated, you can solve this by reducing the number in the variable.

```scratch
repeat [triangle]
  move 10 steps
set [x] to [45]
```

## GLOSSARY

- **Canvas**: An area of the screen for drawing on
- **Pixel**: A point on the screen. It is the smallest dot a computer is capable of drawing.
- **Coordinates**: The position of a pixel on the screen. It is the number of pixels across the screen (x-axis/horizontally) and the number of pixels down (y-axis/vertically).
- **Turtle**: An image that shows the position of the program on the white canvas
- **Function**: A set of instructions that can be used to do an action
- **Variable**: A place to store data in a computer program. It has a name and a value.
- **Loop**: An instruction or set of instructions that keep repeating
