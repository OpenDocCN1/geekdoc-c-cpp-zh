# GLOSSARY

**Canvas**
An area of the screen for drawing on

**Pixel**
A point on the screen. It is the smallest dot a computer is capable of drawing.

**Coordinates**
The position of a pixel on the screen. It is the number of pixels across the screen (x-axis/horizontally) and the number of pixels down (y-axis/vertically).

**Turtle**
An image that shows the position of the program on the white canvas

**Function**
A set of instructions that can be used to do an action

**Variable**
A place to store data in a computer program. It has a name and a value.

**Loop**
An instruction or set of instructions that keep repeating
