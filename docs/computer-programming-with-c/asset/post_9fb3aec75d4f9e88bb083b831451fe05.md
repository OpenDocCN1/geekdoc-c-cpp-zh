Hence, we traverse the array a and subtract 32 from its ASCII value as shown below:

```c
for (int i=0;a[i]!='\0';i++)
{

    {
        a[i] = a[i]-32;
```

The function `toupper()` converts a character to uppercase if it's currently not in uppercase. It does not affect the character if it is already in uppercase.
