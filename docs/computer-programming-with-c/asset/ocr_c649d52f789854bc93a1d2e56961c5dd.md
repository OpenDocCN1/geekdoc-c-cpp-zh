```
#include<stdio.h>
#include<math.h>
void main()
{
    int k,n,t;
    float f,s=0.0,x,sign=1;
    printf("Enter the value of n:");
    scanf("%d",&n);
    printf("Enter the value of x:");
    scanf("%f",&x);
        for(k=2; k<=n; k++)
        {
            t=k;
            f=1.0;
            /*Calculate the factorial of 't'*/
                while(t>0)
                {
                    f=f*t;
                    t--;
                }
            sign=sign*(-1);
            s=s+ pow(x,k)/f*sign;
        }
    printf("Result of the series is %f",s);
}
```

# SCRATCH PAD

The function pow(x,k) can be used to calculate the value of x to the power of k. The function is defined in the header file math.h which we have included in the code. Further, the value of variable sign is multiplied with the ratio pow(x,k)/f so as to evaluate the series with alternate "+" and "-" signs as seen in the code. Therefore, on executing following statement in each iteration of the for loop:

s=s+pow(x,k)/f*sign;

we will get the result of the required series in variable s after the loop completes.
