as seen in the code. As we expect the result to contain the fractional component, we have created the variable `result` of type `float` as seen in the code. However, dividing the variables `a` and `b` will always produce an integer value because the data type of both the operands is integer. This is because compiler follows a rule that `int/int=int`. This means that, when both the operands are of same type then the data type of the result will be same as that of the data type of the operands.

Therefore, the statement,

```
```c
result = a/b;
```
```

will truncate the result of the expression to `3` instead of `3.5` as shown in Figure 3.29. Therefore, the value of variable `result` will be printed as `3.000000` as seen in the output of the code.

![](bbox=[0.28, 0.323, 0.652, 0.472])

**Figure 3.29:** Truncation of the result

So as to solve this problem, we can convert the data type of the result to `float` by explicitly type casting the result of division of two integers into a float using the statement below:

```
```c
result = (float)a/b;
```
```

The type casting informs the compiler that the user expects a `float` result after the division of two integers is performed. Hence, the compiler reserves 4 bytes in memory to store the result of division even if both the operands are of type integer. Therefore, the value of variable `result` will now be initialized as `3.5` as seen in Figure 3.30.

![](bbox=[0.229, 0.697, 0.689, 0.885])

**Figure 3.30:** Explicit type casting
