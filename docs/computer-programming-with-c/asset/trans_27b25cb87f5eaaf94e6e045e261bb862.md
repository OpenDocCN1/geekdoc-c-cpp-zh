## C++ 计算机编程

本教材深入讲解 C 和 C++ 编程语言，以及面向对象编程范式的基础知识。函数、数组、指针和继承等基本概念均以连贯的方式加以说明。

本书采用示例驱动的方法，便于轻松理解理论概念。必要时，书中也详细阐述了 C 编程语言的常见概念。本书对动态内存分配、对象切片、VTABLE、向上转型和向下转型等复杂主题进行了详细解释。

书中使用线条图、注释、对话主题和流程图来解释概念。本书提供了一些实用功能，包括找错练习、测验题和要点记忆。为便于读者理解，书中提供了必要的注释，以解释用于实现特定功能的逻辑。文中穿插了大量计算机程序、复习问题和有用的案例研究。

本书面向工程和计算机科学的本科生与研究生。

**Kunal Pimparkhede** 是孟买维迪亚兰卡尔理工学院的兼职教师。作为一名软件专业人士，他拥有 Adobe Flex、Informatica 等技术，Oracle、Sybase 等数据库系统，以及 Spring、Struts 等基于 Java 的框架的开发经验。他的兴趣领域包括微处理器、自动机理论、数据结构、算法分析、人工智能和计算机编程。
