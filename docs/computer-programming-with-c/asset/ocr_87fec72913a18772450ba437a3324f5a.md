When we access the value of variable x directly inside the `main()` function then the local value of the variable ‘x’ will always be accessed. This means that, the following statement,

```
cout<<"Value of x is: "<<x<<endl;
```

will print the value of x as 50 because it will always access the local value of the variable x. Whereas, the statement,

```
cout<<"Global Value of x is: "<<<::x;
```

will print the global value of the variable x which is 100 because we have applied the scope resolution to the variable x before accessing its value.
