On the other hand, it is important to note that the default precision of Turbo C++ version 3.0 is 6. This means that, although you have not set any value of the precision, all the floating point numbers will be printed up to 6 digits after the decimal point.</p>

        <p>If you do not set any precision, this function will return zero, but as said before, floating point numbers will still be printed with a default precision of 6. This function, returning zero only means that programmer has not specified any value of the precision explicitly.</p>
        <p>The function <code>width()</code> forces C++ to print the output in the right justified form (when used without <code>ios::left</code> flag). By default, C++ prints the values in the left justified form but if the width function is invoked, the next value that will be printed using <code>cout</code> will be in the right justified form.</p>
        <p>This function is used to specify symbol width to be reserved for printing the output. The function takes integer argument, which is used to specify the number of symbol spaces to be reserved to generate the output. The integer value returned by the function gives the width that was set previously.</p>
        <p>For example, we can set the width as 6 using the following statement:</p>
        <pre><code>cout.width(6);</code></pre>
