If the value present in variable `min` is greater than the value at next position in the array, it indicates that the value in variable `min` is not the minimum value and hence we overwrite `min` with the value of the array element which has lesser value than the current value of `min`. This way we keep comparing the value of variable `min` with each element of the array one by one starting from `a[1]` and ending at `a[n−1]` using a for loop. If the value of `min` is found to be greater than an element `a[i]` of the array, then we replace the value of variable `min` by the value stored in `a[i]`. Hence, the value of variable `min` will represent the minimum element of the array at the end of the for loop.
