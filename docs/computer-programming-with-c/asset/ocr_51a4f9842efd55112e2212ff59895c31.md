```
# Can we have a if block without a else block in a C++ program?

> Yes, we can have a if block in the program without a corresponding else block. As an example,
> consider the construct given below:

```
```cpp
if(condition)
{
printf("Inside if block \n");
}
printf("Outside if block\n");
```
```

> If the condition specified as a part of the if block is evaluated as true the control of execution will be transferred
> inside the if block thereby printing the message as "Inside if block" on the computer screen. If the
> condition specified by the if block is evaluated as false, the control of execution will not enter inside the if
> block and hence the printf() statement which is present inside the if block will not be executed. Note that,
> the printf() statement written outside the if block will always be executed even if the condition is true or
> false. Hence, the message "Outside if block" will always be printed on the computer screen.
```
