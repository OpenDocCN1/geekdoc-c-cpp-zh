Declaration of a function is called **function prototype**. Prototyping a function is not necessary if we define the function before `main()`, it is mandatory only when the function is defined after `main()`.

Hence, we have two options to make the code work:

+   1. Include function prototype of `add()` in the program.
+   2. Define function `add()` before `main()`: In this case prototyping `add()` is not mandatory.

To understand option 1 we need to know what is a function prototype? We know that C/C++ does not support forward referencing. This means that you cannot use a variable in the program before its declaration. The general rule is that an identifier can be used only after its declaration. Same is true with functions. You cannot call a function `add()` without declaring (prototyping) it. The ‘function prototype’ informs the compiler about the exact way in which the function `add()` is defined later in the program.

Prototype includes the following information about the function:

+   1. Name of the function
+   2. Return type of the function
+   3. Data type and order of the arguments of the function

+   1. **Name of the function:** The name of the function specified in the prototype should exactly match with the name that is given in the ‘function definition’ appearing after `main()`.
