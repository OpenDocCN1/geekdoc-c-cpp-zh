The above ‘return statement’ makes another call to the `exp()` function before it can return any value to the ‘calling’ function. Hence, another activation frame for `exp()` is created with formal argument x initialized to 2 and formal argument y initialized to 3 as shown in Figure 7.30. The new instance of `exp()` starts executing with x=2 and y=3 which makes another call to `exp()` using the statement

```
return 2*exp(2,2);
```
