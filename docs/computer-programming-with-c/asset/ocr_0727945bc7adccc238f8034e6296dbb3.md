Size of the list is essentially the number of elements in the list. Currently, the list `l1` is empty and hence its size is zero.

```
One way by which you can add elements to the list is by using a `push_back()` method of `list` class. You can invoke the `push_back()` method using object of list `l1` as shown below:

```
```cpp

```
```

```

