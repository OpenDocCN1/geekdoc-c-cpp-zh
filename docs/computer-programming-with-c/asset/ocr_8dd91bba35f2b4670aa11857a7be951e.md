The compiler guarantees that the value of `arg_c` will be correctly set to the count of parameters which are passed in command line. If the command is

`pro1 100 200 300 400 500 600 700 800`

the value of `arg_c` will be set to 8 and hence the while loop will have eight iterations each time accumulating one value in sum. Therefore, at the end of the while loop the value of sum will be correctly set to 3600.
