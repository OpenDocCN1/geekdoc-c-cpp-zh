The table below gives the description of few `printf()` statements which can be help to understand the concept of creating array of pointers.

| Statement | Description |
|---|---|
| `printf("%u", p[0]);` | This statement prints the value stored inside the pointer `p[0]`. As shown in the Figure 8.35 the pointer `p[0]` contains the address of variable a. Hence, the statement `printf("%u", p[0])` will print 1000 on the computer screen. |
| `printf("%d", *p[0]);` | This statement applies an direction operator (*) to the pointer `p[0]`. The operator (*) directs the CPU to access the memory location using the address contained in the pointer and read the value stored inside that location. As pointer `p[0]` contains the address 1000, CPU will now fetch the value stored at location 1000 which is in reality the value of variable a as shown in the figure 8.35. Hence the statement `printf("%d", *p[0]);` will print the value of variable a thereby giving the output as 10 on the computer screen. |

Similarly the values of variables b and c can be accessed using `*p[1]` and `*p[2]`, respectively.

# NOTES

When you create different variables, they are not guaranteed to be stored in contiguous memory locations. Hence we have assumed the addresses of variables a, b and c as 1000, 2000 and 3000, respectively to show that they will never be guaranteed to be contiguous in memory.

When we create an array, its elements will always be stored in contiguous memory locations. Hence, each pointer in an array of pointers will be stored in consecutive memory locations.
