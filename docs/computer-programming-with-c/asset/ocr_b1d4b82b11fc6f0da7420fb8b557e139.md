The statement

`Data<int> o1;`

creates an object `o1` specifying the generic type as `int`. This means that members `a` and `b` for object `o1` will be of type integer as shown in Figure 16.2. Whereas, the statement

`Data<float> o2;`

creates object `o2` specifying the generic type as `float`. This means that members `a` and `b` for object `o2` will be of type `float` as shown in Figure 16.2.

Note that under this design, it is not possible to have members `a` and `b` of different data types for a same object because we have defined just one generic type for the entire class. The generic type can take different forms for different objects, but it can take only one form for one particular object. For object `o1`, it has taken the form of `int`, whereas for object `o2`, it has taken form of `float`.
