# CAUTION

If a pointer is used in the program without initializing it to a valid memory location then such a pointer is called wild pointer. Wild pointers are dangerous because whenever we use new memory location they are pointing to, then they may corrupt some location in RAM resulting the program to crash or make the system misbehave.
