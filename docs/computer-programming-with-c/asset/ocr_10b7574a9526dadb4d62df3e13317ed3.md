+   **NOTES**
+   1. Any object type can be converted into primitive type by overloading the **type cast operator function**, just like we have converted Weight object to long value.
+   2. Any primitive type can be converted into an object type using a **constructor** or an **operator= function**. These options can be used interchangeably.
