Advanced programming languages like **Java** support built-in **Wrapper** classes which wrap basic data types into object types to simplify accessing elements from collections. We have designed one of the built-in features of Java in our program because C++ does not have such wrapper classes in its core libraries. In the above example, we have stored student data as key-value pair, where roll number is a key and marks is the value. A data structure that stores data in this format is called as **Map**. C++ has a standard template library (STL) which supports multiple collections and **Map** is one of them, we have discussed STL in chapter 16. In this program we have achieved effect of **Map** by **overloading ->** and by creating our own wrapper class.

If you only look at the `main()` function, it just creates a Wrapper object named as `markList`, adds Student objects in it and accesses these objects based on roll number. # Points to Remember when Overloading an Operator

We have overloaded multiple operators of C++ in this chapter to make them work with user-defined data types. We will quickly summarize the rules that must be followed when overloading an operator in C++:

+   1. There must be an operator function defined for every operator which is to be overloaded.
+   2. Operator function can be defined as a member function of the class or it can be defined globally.
+   3. If the operator function is defined as a member function, compiler invokes the operator function using the object that appears on the left hand side of the operator and passes the object on the right hand side as an argument to it.
