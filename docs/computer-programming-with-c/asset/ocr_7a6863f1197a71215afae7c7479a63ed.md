> **What happens if the class does not have any constructor?**
> 
> If we do not create a constructor in the class, compiler provides a default constructor with every class. The constructor provided by the compiler does not take any arguments. Hence, if we do not define a constructor in class ShoppingCart then the statement,
> 
> `ShoppingCart c1;`
> 
> will invoke the constructor provided by the compiler, so as to create the object c1. Obviously, in this case initial value to the members of the object will not be given automatically. Rather, it will be the responsibility of the programmer to create a separate member function to give initial values to the members of the object. This member function must be invoked explicitly in the program to initialize the members of the object as discussed in the Section 12.1.
