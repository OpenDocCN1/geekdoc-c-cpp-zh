The first three statements of main() function

```
```cpp
Abc *p;
Child o1;
p=&o1;
```
```

create a parent type pointer named as p and make it point to a child object o1.
The statement

```
```cpp
p->add(10, 20);
```
```

will invoke add() defined in parent class which does not return anything. This is because data type of the pointer p is Abc, which directs the compiler to invoke add() defined in class Abc as per principle of early binding.
The next statement

```
```cpp
int res1 = ((Child*)p ) ->add(80, 85);
```
```

performs explicit down casting of pointer p to Child*. Hence, this statement will invoke add() defined in Child which returns an integer. The result of addition will be stored in res1.
The statement

```
```cpp
Child *q = &o1;
```
```

creates a Child type pointer q and makes it point to the existing child object o1.
The statement

```
```cpp
int res2 = (q->add(40, 45));
```
```

will invoke the add() defined in Child which returns an integer value. This is because data type of the pointer q is Child, which directs the compiler to invoke add() defined in class Child as per principle of early binding.

If you need to invoke add() defined in parent class using the pointer q, you can perform explicit up casting of q to parent type Abc*. The statement

```
```cpp
((Abc*) q) ->add(100, 15);
```
```

will invoke add() function in parent class that returns void because of up casting applied to pointer q. This is one of the cases where up casting needs to be applied explicitly.

Another method to invoke the add() function in parent class using a pointer q is with the help of scope resolution operator as shown below:

```
```cpp
q->Abc::add(200, 225);
```
```

This statement instructs the compiler to invoke the add() function which is inherited from class Abc even if the data type of the q is Child.
