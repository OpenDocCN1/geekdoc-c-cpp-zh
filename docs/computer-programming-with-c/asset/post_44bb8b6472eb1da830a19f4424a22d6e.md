### 9.3 Array of Structure Objects

It is possible to create an array such that each element of the array is an object of a structure. Let us consider the structure Book defined in Section 9.2 with members id, title, author and price. We can create an array of Book objects named as b by using the following statement:

```c
struct Book b[size];
```

The following statement will create an array b to store information about three books in the computer memory:

```c
Book b[3];
```

Each element of the array b is an object of Book, because the data type of the array b is defined as Book. As the size of the array b is specified as 3, there will be three Book objects in an array b. The first Book object can be accessed as b[0], the second Book object can be accessed as b[1], and the third Book object can be accessed as b[2] as shown in the Figure 9.12.

![](img/57c0d966bb33c67a5a188e6bf39e4e02_473_0.png)

We will be able to access the members `id`, `title`, `author`, and `price` for each of the Book objects by using a membership operator “.”. For example, the following statement will accept the members (`id`, `title`, `author`, and `price`) of object `b[0]` as input from the user:

```c
scanf("%d%s%s%f",&b[0].id,b[0].title,b[0].author,&b[0].price);
```

Since we have only taken the members of `b[0]` as input, the state of array `b` assuming input data as `{id=1, title="C++", author="Kunal", price=900}` is shown in the Figure 9.13.

Similarly, we can accept members of objects `b[1]` and `b[2]` as input from the user. Following `for` loop will accept the details for each of the Book objects `b[0]`, `b[1]`, and `b[2]` as input from the user because we have specified the range of loop variable `i` from 0 to 2.

![](img/57c0d966bb33c67a5a188e6bf39e4e02_473_1.png)

```c
for(i=0;i<=2;i++)
{
    scanf("%d%s%s%f", &b[i].id,b[i].title,b[i].author,&b[i].price);
}
```

Figure 9.14 shows the final state of an array assuming sample input data.

![](img/57c0d966bb33c67a5a188e6bf39e4e02_474_0.png)

**Figure 9.14:** State of objects b[0], b[1], and b[2] after user input

In general, we can access a member of iᵗʰ Book object in b by using the following statement:

```c
b[i].<memberName>;
```

Following for loop will print the details of each of the Book objects on the computer screen:

```c
for(i=0;i<=2;i++)
{
    printf("%d\t%s\t%s\t%f\n", b[i].id, b[i].title, b[i].author, b[i].price);
}
```

When counter variable i takes the value 0, the **printf()** statement will print the id, title, author, and price of object b[0], whereas when the value of i is incremented to 1, the **printf()** statement will print the id, title, author, and price of object b[1] and so on. As the size of the array is 3, we terminate the for loop when the value of index variable i crosses 2. This is because the last Book object will be stored at position 2 as shown in the Figure 9.14. Therefore, the output of the given for loop will be as shown below:

```text
1  C++      Kunal 900
2  Java     Jack  800
3  Fortran  Jill  400
```

The following is the full source code which creates an array of type Book of size 3, accepts the details about each book as input from the user and prints them back on the computer screen.

```c
#include<stdio.h>
struct Book
{
int id;
char title[100];
char author[100];
float price;
};
void main()
{
int i;
/*Create an array of books with size 3*/
struct Book b[3];
printf("Enter the id,title,author and price of 3 books\n");
for(i=0;i<=2;i++)
{
scanf("%d%s%s%f",&b[i].id,b[i].title,b[i].author,&b[i].price);
}
printf("The Book details are\n");
for(i=0;i<=2;i++)
{
printf("%d\t%s\t%s\t%f\n", b[i].id, b[i].title, b[i].author, b[i].price);
}
}
```
