The actual value of variable x is substituted in place of the format specifier %d by the `printf()` statement.

```
printf("There are %d students", x);
```

# NOTES

As variable x is of type integer, we have used the format specifier `%d`. There are different format specifiers supported by C/C++ for each of the different data types. For example, `%f` is used to print a floating point value, `%c` is used to print character value and so on. Table 2.2 gives the list of all format specifiers supported by C/C++.

# **Table 2.2:** Examples of format specifiers

| Format specifier | Description | Example | Output |
|---|---|---|---|
| `%d` | `%d` is used to print a value of integer variable. We can also use `%i` to print integer value. `%d` and `%i` have same meaning | `int v = 320;`<br>`printf("Value is %d",v);` | `Value is 320` |
| `%c` | `%c` is used to print a value of character variable | `char ch='$';`<br>`printf("Value is %c",ch);` | `Value is $` |
| `%f` | `%f` is used to print a value of floating point variable in a decimal form | `float v=32.8;`<br>`printf("Value is %f",v);` | `Value is 32.8` |
| `%u` | `%u` is to print the value of an unsigned integer variable | `unsigned int v = 65532;`<br>`printf("Value is %u",v);` | `Value is 65532` |
| `%ld` | `%ld` is used to print a value of long variable. We can also use `%li` to print long value. `%ld` and `%li` have same meaning | `long v = 3200000;`<br>`printf("Value is %ld",v);` | `Value is 3200000` |
| `%o` | `%o` is used to print the octal equivalent of an integer | `int v = 320;`<br>`printf("Value is %o",v);`<br>`/*This prints 500 which is an octal equivalent of decimal value 320*/` | `Value is 500` |
