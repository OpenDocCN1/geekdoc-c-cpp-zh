# 6.2 Creating an Array

Given below is the syntax to create an array:

```
`<DataType> array_name[SIZE];`
```

Given below are some examples, showing creation of an array in computer memory:

| Statement | Description |
|---|---|
| `int p[10];` | Creates an integer array named p with a size of 10 integers |
| `float q[5];` | Creates a float array named q with a size of 5 floats |
| `char r[20];` | Creates a character array named r with a size of 20 characters |

To understand few more aspects, let us create an integer array a of size 3 as shown in the following statement:

```
`int a[3];`
```

Note that a is a collection of three integers as shown in Figure 6.3. All the array elements store junk values, unless they are individually initialized.

![](bbox=[0.237, 0.526, 0.736, 0.745])

**Figure 6.3:** Creation of array a to store 3 integers

Each element of array a is indexed starting from 0. Hence, the first element should be accessed as `a[0]`, second element should be accessed as `a[1]` and the third element should be accessed as `a[2]`. Let us now initialize these elements to values 10, 20 and 30, respectively; this can be done by using the following statements:

```
a[0]=10;
a[1]=20;
a[2]=30;
```
