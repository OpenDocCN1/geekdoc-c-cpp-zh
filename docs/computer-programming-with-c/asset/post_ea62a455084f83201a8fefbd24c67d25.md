
## 2.12 Defining Constants Using `#define`—A Preprocessor Directive

`#define` is a preprocessor directive that is used to define constant values that are not going to change throughout the execution of the program. The constants defined by the `#define` directive are also called macros in a C/C++ program. Recall from Chapter 1 that the preprocessor replaces every occurrence of a macro name in the program with the macro definition before the compilation of the program starts.

As an example, let us consider the following preprocessor directive:

```c
#define PI 3.14
```

This means that we have defined a constant PI (the name of the macro is PI) with a value of 3.14. Remember that `#define` statements are not compiled; rather, they are preprocessed before the compilation of the program starts. Hence, the preprocessor will replace every occurrence of PI with 3.14 before compilation of the program. Given below is the program to find the volume of a cone using the `#define` directive to define the constant value 3.14.

```c
#include <stdio.h>
#define PI 3.14

void main()
{
    float radius, height, volume;

    printf("Enter the radius and height of the cone\n");
    scanf("%f %f", &radius, &height);

    volume = 0.3333 * PI * radius * radius * height;
    printf("Volume of the cone is %f\n", volume);
}
```

Output:

```text
Enter the radius and height of the cone
10 2.3
Volume of the cone is 240.709259
```

The above-given code defines a constant PI using the preprocessor directive `#define`. Hence, the statement

```c
volume = 0.3333 * PI * radius * radius * height;
```

will be translated by the preprocessor to:

```c
volume = 0.3333 * 3.14 * radius * radius * height;
```

by substituting the value 3.14 instead of the constant PI. Once the preprocessor completes the substitution, a temporary file is generated on the disk, which is then compiled by the compiler.

### 2.12.1 `NULL`—A Built-in Macro

`NULL` is a constant defined in C/C++ with a value set to zero. `NULL` is a name given to a built-in macro that is defined inside C/C++ libraries using the `#define` statement shown below:

```c
#define NULL 0
```

This means that we can use the symbol `NULL` or the integer constant `0` interchangeably in a C/C++ program.

The statement

```c
int a = NULL;
```

is the same as

```c
int a = 0;
```

Therefore, when we attempt to initialize a variable with a `NULL` value, the value of the variable will actually be initialized to zero.

Although using either the symbol `0` or the symbol `NULL` will not affect the output of the program, the symbol `NULL` is often used when working with **pointers**. A pointer that is initialized to `NULL` (also called a **NULL pointer**) does not point to any location in the computer memory. The exact usage of NULL pointers will be discussed in Chapters 8 and 10.

## 2.13 **Character-Specific Input/Output**

We know that we can use `scanf()`/`printf()` as well as `cin`/`cout` for input/output operations for different types of data values, including characters. C/C++ supports `getchar()` and `putchar()`, which are functions specifically used for character input and output operations.

`getchar()` is a function used to read a character from the keyboard, and `putchar()` is a function used to print the character on the computer screen. Although their job can also be done by `scanf()`/`printf()` as well as `cin`/`cout`, the functions `getchar()` and `putchar()` are much simpler to use compared to `scanf()`/`printf()` or `cin`/`cout`. The only point to note is that they can input or print only one character at a time. Consider the following program as an example:

```c
#include <stdio.h>

void main()
{
    char x;
    printf("Enter a character\n");

    /* getchar() is used to get a character as input */
    x = getchar();

    printf("Character you entered is\n");

    /* putchar(x) prints the value of character variable x */
    putchar(x);
}
```

## Output:

```text
Enter a character
$
Character you entered is
$
```

The statement

```c
x = getchar();
```

waits for the user to input a character. The character input by the user is stored in variable `x`. In reality, the function stores the ASCII value of the input character in the variable `x`, and hence the function `getchar()` returns an integer value, as ASCII values are integers. All we need to note at this stage is that the character input by the user is stored in variable `x`; so, if the user inputs, say, `$`, then `x` will contain `$`. Remember, the function can take only one character as input at a time, so if you need to input another character, you need to use another `getchar()` function.

The statement

```c
putchar(x);
```

prints the character value stored in variable `x` on the computer screen. So, for example, if the value of `x` is `$`, then `$` will appear on the computer screen.

> **NOTES**
>
> The functions `getchar()` and `putchar()` are declared in the header file `stdio.h`. Hence, this header file must be included before using these functions in the program.
