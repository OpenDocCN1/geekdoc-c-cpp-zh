In the above discussion, we have just pushed and popped integer values to/from stack. We can always implement a generic stack using templates. In this example, we will implement stack using the built-in list present in C++.

```cpp
#include<list.h>
template<class G>
class Stack
{
private:
    list<G> l1;
    int size;

public:
    Stack()
    {
        size = 0;
    }

    void push(G element)
    {
        l1.push_back(element);
        size++;
    }

    G pop()
    {
        G element = l1.back();  // get the topmost element
        l1.pop_back();          // delete the element from stack
        size--;
        return element;
    }

    int isempty()
    {
        return (size == 0);
    }
};

void main()
{
    Stack<int> s;
    s.push(10);
    cout << "Pushed 10" << endl;
    s.push(20);
    cout << "Pushed 20" << endl;
    s.push(30);
    cout << "Pushed 30" << endl;
    cout << "**********Elements popped**************" << endl;
    int temp;
    while (!s.isempty())
    {
        temp = s.pop();
        cout << temp << endl;
    }
}
```

In the class `Stack`, we have created a generic list `l1`:

```cpp
list<G> l1;
```

We will use this list to store the elements of stack. We have created the list `l1` as a private member of `Stack`, so the outside world cannot directly access the list `l1`. Every access to elements of list `l1` must be passed through the public methods of class `Stack`. There are two public methods in class `Stack`.

### void push(G element)

This method is used to insert elements into the stack by calling the `push_back()` method of list `l1`. This means that all elements are inserted only from the back side of the list. The `push` method takes the element to be pushed as input and performs the following two steps:

| Statement | Description |
|---|---|
| `l1.push_back(element);` | Insert the element in linked list `l1` from the back side. (The back side of the list actually acts as the stack top in our implementation.) |
| `size++;` | Increase the size of the stack by 1. |

If you refer to the code written in the `main()` method, we have created an object of `Stack` named `s` using the statement below:

```cpp
Stack<int> s;
```

At this stage, the stack is empty because object `s` has just been created.

> **NOTES**
>
> The class `Stack` has another integer-type variable named `size`. It is used to represent the size of the stack at any point in time. When an object of class `Stack` is created, the default constructor is called, which sets the size to zero.

We have called the `push` method three times. Each call to `push` internally calls the `push_back()` method of the linked list `l1`. Hence, three elements are inserted into the list `l1` from the back side.

```cpp
s.push(10);
s.push(20);
s.push(30);
```

Each call to `push()` also increases the size of the stack. Hence, after three elements are pushed into the stack, its size is 3.

The method `isempty()` is used to check if the stack is empty. The logic inside this method checks the variable `size`. Each time you push an element into the stack, `size` is increased by 1 using the following statement in the `push()` method:

```cpp
size++;
```

Whereas, each time you pop an element from the stack, the size of the stack is decreased by 1 using the following statement inside the `pop()` method:

```cpp
size--;
```

Hence, if `size` is zero, it means that the stack is empty. The `isempty()` method returns false (0) if the stack is not empty and returns true (1) if the stack is empty.

### 6 pop()

Since the elements were pushed from the back side of the list, popping should also be done from the same side. This is because a stack has only one open end by definition. The `pop()` method performs the following four steps:

| Statement | Description |
|---|---|
| `element = l1.back();` | Read the backmost element in list `l1` and store it in a variable named `element`. |
| `l1.pop_back();` | Delete the backmost element in the list. (This gives the effect of deleting the topmost element of the stack.) |
| `size--;` | Reduce the size of the stack by 1. |
| `return element;` | Return the deleted element to the calling method. |

The following loop written in the `main()` method invokes `pop()` while the stack is not empty. The condition of the `while` loop is:

```cpp
!s.isempty()
```

This means the `while` loop will continue to run while the stack is not empty. Inside the loop, we invoke the `pop()` method, so the loop keeps popping elements and printing them on the screen using the `cout` statement. The loop terminates once all the elements of the stack are popped out, thereby leaving the stack empty.

```cpp
while (!s.isempty())
{
    temp = s.pop();
    cout << temp << endl;
}
```

## 16.6 Queue using List

A queue is a first-in-first-out type of data structure. A queue has two open ends, as shown in Figure 16.22. Elements are inserted into the queue through the rear end and removed from the queue through the front end. Thus, the element inserted first is the first to come out of the queue.

![](img/57c0d966bb33c67a5a188e6bf39e4e02_979_0.png)

To understand, let us first insert the value 10 into the queue. After the first insertion, the size of the queue is 1, as shown in Figure 16.23.

![](img/57c0d966bb33c67a5a188e6bf39e4e02_979_1.png)

If we now insert 20 into the queue, its size becomes 2, and 20 is stored in the queue behind 10, as shown in Figure 16.24.

Inserting a third value, 30, into the queue will make it look as shown in Figure 16.25. The value 30 will be stored behind 20 because it was inserted after 20.

![](img/57c0d966bb33c67a5a188e6bf39e4e02_979_2.png)

![](img/57c0d966bb33c67a5a188e6bf39e4e02_979_3.png)

**NOTES**

On each insertion, the size of the queue increases by 1. We have written an `add()` function in class `Queue` to insert elements into the queue, so `add()` contains the statement:

```cpp
size++;
```

This ensures that the size of the queue increases by 1 on each insertion. Keep in mind that the default constructor of the `Queue` class is executed only once, giving the variable `size` an initial value of `0`.

We will implement a generic queue using a built-in C++ list. The implementation of `Queue` is very similar to that of `Stack`. The only point to remember is that we should not use the same end for insertion and deletion of elements. If elements are inserted at the back end of the linked list `l1`, they should be deleted from the front end of the list. In the code below, the `add()` method is responsible for adding elements to the queue; internally, it invokes the `push_back()` method of linked list `l1`. This means that elements are inserted from the back side of the list.

The `remove()` method uses `pop_front()`, which removes an element from the front side of the list. Hence, the element inserted first will be the first to come out. As seen in the program output, 10 was added to the queue first and is the first to come out of the queue.

```cpp
#include<list.h>
template<class G>
class Queue
{
private:
    list<G> l1;
    int size;

public:
    Queue()
    {
        size = 0;
    }

    void add(G element)
    {
        l1.push_back(element);
        size++;
    }

    G remove()
    {
        G element = l1.front(); // get the front element
        l1.pop_front();         // delete the element from the queue
        size--;
        return element;
    }
}
```
