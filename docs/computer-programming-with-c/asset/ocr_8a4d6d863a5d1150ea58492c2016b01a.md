# **Figure 14.36**  Hierarchy of classes

Accidently, if you create the Scientific class as a child class of both Basic as well as Trigonometric, you are creating an ambiguous situation by trying to inherit the features of Basic twice in Scientific class (once through Trigonometric class and the second time directly through Basic class). Compiler does not allow such ambiguities to occur and generates an error complaining that the child class of Trigonometric will anyway contain the features of Basic and hence it should not be specified as another parent explicitly, as shown in the figure 14.37.
