# Solved Example 6.18

Write a program to take a 2D array as input from the user and find the greatest element in the 2D array.

```
```c
#include<stdio.h>
void main()
{
    int r,c,i,j;
    int a[100][100];
    int max;
    printf("Enter the no. of rows and columns of the array:\n");
    scanf("%d",&r,&c);
    printf("Enter a Matrix:\n");
    for(i=0;i<=r-1;i++)
    {
        for(j=0;j<=c-1;j++)
        {
            scanf("%d", &a[i][j]);
        }
    }
    max=a[0][0];
    for(i=0;i<=r-1;i++)
    {
        for(j=0;j<=c-1;j++)
        {
            if(a[i][j]>max)
            {
                max=a[i][j];
            }
        }
    }
    printf("Maximum is %d",max);
}
```
