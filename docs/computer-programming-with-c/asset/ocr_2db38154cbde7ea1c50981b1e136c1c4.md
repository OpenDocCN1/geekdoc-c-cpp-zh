# ### 9.3  Array of Structure Objects

It is possible to create an array such that each element of the array is an object of a structure. Let us consider the structure Book defined in Sections 9.2 with members id, title, author and price. We can create an array of Book objects named as b by using the following statement:

```
```c
struct Book b[size];
```
```

The following statement will create an array b to store information about three books in the computer memory:

```
```c
Book b[3];
```
```

Each element of the array b is an object of Book, because the data type of the array b is defined as Book. As the size of the array b is specified as 3 there will be three Book objects in an array b.
