> > Instead of printing a pattern of stars, we now need to print the pattern of characters starting from ‘a’ as seen in the question. Therefore, we create a variable named v with the initial value as ‘a’. Further, we also increment the value of variable v at the beginning of each row. This can be done by writing the following statement inside the body of the outer for loop.
> >
> > ```c
> > v=v+1;
> > ```
> >
> > The inner for loop prints the value of variable v in every iteration on the computer screen. Thereby printing the same character within the a single row of the triangle using the statement as shown below:
> >
> > ```c
> > printf("%c",v);
> > ```
> >
> > Hence we get a pattern as,
> >
> > ```text
> > a        a        a        a
> > b        b        b
