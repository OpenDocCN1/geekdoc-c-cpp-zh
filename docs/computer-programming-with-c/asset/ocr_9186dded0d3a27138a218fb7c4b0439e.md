Remember, when you reinitialize the pointer the previous array to which it was pointing to is lost and there is no way to refer it back. In this case, since we have reinitialized the pointer p to point to string "pigs" there is no way to refer to "ducks" unless some other pointer was made point to it before redirecting p to "pigs".
