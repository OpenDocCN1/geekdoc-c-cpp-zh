+   - Process of hiding the complexities and only revealing necessary details required to implement a particular solution is called **abstraction**.
+   - Apart from instantiation, encapsulation and abstraction; C++ also provides other object oriented features like polymorphism, data hiding, message passing, inheritance, etc. These features are discussed one by one in the later chapters of this text book.
