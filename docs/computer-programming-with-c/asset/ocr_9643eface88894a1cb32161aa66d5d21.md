+   1. **Local variables**
+      These are variables declared within the scope of the function.
+   2. **Arguments**
+      These are values which the function accepts as arguments.
+   3. **Return value**
+      The value returned by the function.
+   4. **Return location**
+      This is the address of the statement of caller where the control of execution should return after the called function ends.

Activation frames are used to handle function calls and returns by the CPU.
