# 10.3.1 Structure of a node in a linked list

Every node of a linked list consists of two parts in it. The first part of the node stores the data value to be stored in the list and the second part of the node is a pointer that points to the next node thereby creating a chain of nodes. Figure 10.11 shows the structure of a single node in a linked list:

![](bbox=[0.313, 0.219, 0.604, 0.358])

**Figure 10.11:** Structure of a node in a linked list

The data element to be stored in a node can be a primitive or of an object type. For simplicity of programming we assume an integer data to be stored inside a linked list. Along with the data to be stored, each node also has a pointer that points to the next Node object as shown in the Figure 10.12. Hence we can consider that each node should have following two members:

![](bbox=[0.121, 0.473, 0.859, 0.679])

**Figure 10.12:** Basic representation of a linked list

+   1. `data`: A integer data value
+   2. `next`: A pointer to a next node present in the linked list. The pointer next will contain `NULL` for a last node of the linked list.

Since the members data and next is a common requirement of each of the node objects to be created in a linked list, we can now create a structure Node which defines the properties of each of the node objects as follows:

```
```cpp
struct Node
{
int data;
Node *next;
};
```
