statement is only executed if condition of the if block is satisfied, thereby skipping the later part of the code in f1(). If the condition in if block is false, the return; statement will not be executed and the execution of f1() will continue till the end as usual. Hence, in this case, we have designed an execution flow that will terminate f1() abruptly if a specific condition is satisfied.
