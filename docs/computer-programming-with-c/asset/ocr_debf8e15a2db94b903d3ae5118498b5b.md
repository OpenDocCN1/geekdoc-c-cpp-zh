# Can assignment operator be used with objects? For example, can we write a statement `e1=e2;` in the code?

Yes. Assignment operator can be used with objects. If you write a statement

```
e1=e2;
```

all the values of members of object e2 will be copied to corresponding members of object e1. Hence the statement will modify object e1 and set its member values same as that of object e2 as shown below:

| Object e1 | Value |
|---|---|
| id | 2 |
| name | Jack |
| salary | 5000 |

*Values copied from object e2*

This is possible because the **assignment operator function** is overloaded in every class by the compiler. We will learn operator overloading in Chapter 13, but remember for now that assignment operator function is a function which does a member by member copy when used with objects and is by default provided by the compiler with every class you create.

# What is the difference between a structure and a class?

In C++, you can use structure or a class interchangeably. Like class, we can also have members and member functions in structure. This means that everything that you can achieve using classes can also be achieved using structures.
