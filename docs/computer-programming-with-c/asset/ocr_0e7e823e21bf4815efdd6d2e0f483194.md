# # 安全电子病历系统

本系统遵循国家信息安全等级保护三级标准，采用国密算法对患者隐私数据进行全链路加密存储与传输。

+   - 支持门诊、住院、急诊等多场景电子病历书写
+   - 内置临床知识库与智能辅助诊断
+   - 三级质控与病历全程追溯

![](bbox=[0.62, 0.2, 0.95, 0.45])

| 模块 | 功能 | 权限等级 |
| --- | --- | --- |
| 门诊病历 | 书写、修改、提交 | 主治医师 |
| 住院病历 | 入院记录、病程记录 | 住院医师 |
| 质量控制 | 三级质控、缺陷管理 | 质控办 |

> > “以患者为中心，以质量为生命。” —— 系统设计理念
