In the class Stack, we have created a generic list l1

```
list<G> l1;
```

We will use this list to store the elements of stack. We have created the list l1 as a private member of Stack, so the outside world cannot directly access the list l1. Every access to elements of list l1 must be passed through the public methods of class Stack. There are two public methods in class Stack.

# void push(G element)

This method is used to insert elements into the stack by calling push_back() method of list l1. So this means that all elements which are inserted are only from back side of the list. The push method takes the element to be pushed as input and performs following two steps:

| Statement | Description |
|---|---|
| l1.push_back(element); | Insert the element in linked list l1 from the back side.(The back side of the list actually acts as a stack top in our implementation) |
| size++; | Increase the size of stack by 1 |

If you refer to the code written in main() method, we have created an object of Stack named as s using the statement below:

```
Stack<int> s;
```

At this stage, the stack is empty because object s is just created.

> 
> The class Stack has another integer type variable named is size. It is used to represent the size of stack at any point in time. When an object of class Stack is created, the default constructor will be called which sets the size to zero.
