We have named the user-defined function as `compareLogic()`. It takes two integer arguments `firstValue` and `secondValue` which represents two values of the list which are compared by the `sort()` algorithm at any given point of time. We have written the function `compareLogic()`, such that it returns false if `firstValue<secondValue`. This means that for any two values in the list if the value before is less than the value after, then their positions will be interchanged. In summary, this means that all the values that appear before in the list must be greater than all the values that appear after. Hence, our custom logic of comparison forces `sort()` function to arrange the elements of linked list in **descending order**. Recall, the default behaviour of `sort()` is to arrange elements in ascending order.
