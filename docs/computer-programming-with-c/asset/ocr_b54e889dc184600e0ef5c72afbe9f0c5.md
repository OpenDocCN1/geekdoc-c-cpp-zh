# ## 2.6 printf() Statement (Supported by both C and C++)

`printf()` is a function used to print a message on the computer screen. The function is supported by both C and C++. Given below is the syntax to use `printf()` function to print a message on the screen

```
```c
printf("message");
```
```

The function is declared in a header file `stdio.h`, hence this header file must be included in the program before using the `printf()` function.

```
```c
#include<stdio.h>
```
```

For example, the program given below prints a message I like computer programming on the screen

```
```c
#include<stdio.h>
void main()
{
printf("I like computer programming");
}
```
```

*Output:*

```
```
I like computer programming
```
```
