Following substitutions are required to be applied on the solution discussed in Chapter 6, to solve the same program by using pointers:

+   1. Every occurrence of a [i] in the code should be replaced by * (p+i).
+   2. Every occurrence of &a [i] in the code should be replaced by (p+i).
+   3. Every occurrence of a [j] in the code should be replaced by * (p+j).

{
int a[100],temp,n,i,j;
int *p;
p=&a[0];
printf("Enter length of the array:");
scanf("%d",&n);

    for(i=0;i<=n-1;i++)

        {
        if(*(p+i) > *(p+j))
            {
            temp=*(p+i);  /*store value of a[i] in variable temp*/
            *(p+i)=*(p+j);  /* store value of a[j] in a[i]*/
            *(p+j)=temp;    /*store value of temp in a[j]*/
            }
        }
    }
printf("Ascending order is as below\n");
    for(i=0;i<=n-1;i++)
