# 8.9  Array of Pointers

It is possible to create an array such that, each element of an array is a pointer. Every element of such an array can store the address of different variables thereby pointing to different data items. Below is the syntax to create an array of pointers:

```
Datatype *<array_name>[size];
```

For example, the statement,

```
int *p[3];
```

will create an array of pointers named as p of size 3. This array will contain three pointers p[0], p[1], and p[2]. And, because the array p is not yet initialized, each of the pointers p[0], p[1], and p[2] will contain junk addresses as shown in the Figure 8.32.

Let us now create three different integer variables a, b, and c with values 10, 20, and 30, respectively as shown in the Figure 8.33. We assume that the addresses of variables a, b, and c are 1000, 2000, and 3000, respectively.

```
int a=10,b=20,c=30;
```

We can now store address of each of these variables inside individual pointers present in array p. As a first step, let us store the address of variable a inside a pointer p[0] which can be done using the statement below:

```
p[0]=&a;
```

The Figure 8.34 now shows that p[0] contains 1000 which is the address of variable a. Note that the pointers p[1] and p[2] still contain junk values and they do not point to any meaningful location in the memory as shown in the Figure 8.34.

We can similarly store the addresses of variables b and c in the pointers p[1] and p[2] using statements below:

```
p[1]=&b;
p[2]=&c;
```
