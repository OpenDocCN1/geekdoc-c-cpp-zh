# 7.9  Storage Classes in C/C++

The place in the memory where a variable is stored on its creation is called a ‘storage class’ of that variable. C/C++ supports following storage classes for each of its variables:

+   1. `auto` storage class
+   2. `register` storage class
+   3. `static` storage class
+   4. `extern` storage class
