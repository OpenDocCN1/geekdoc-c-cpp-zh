iostream.h. Hence, we need to use the extraction operator along with the built-in object of class istream which is named as cin. As the object cin and the extraction operator function >> are defined in the header file iostream.h, we must include the contents of iostream.h in the C++ program before we can use the object cin in the C++ program. The pre-processor directive #include can be used to include the contents of the header file in the C++ program as discussed in Section 2.2.
