# ABSTRACT DATA TYPE: PRIORITY QUEUE

## DATA
* A finite number of objects, not necessarily distinct, having the same data type and ordered by priority.

## OPERATIONS
| PSEUDOCODE | DESCRIPTION |
| :--- | :--- |
| isEmpty() | Task: Sees whether this priority queue is empty. Input: None. Output: True if the priority queue is empty; otherwise false. |
| add(newEntry) | Task: Adds newEntry to this priority queue. Input: newEntry. Output: True if the operation is successful; otherwise false. |
| remove() | Task: Removes the entry with the highest priority from this priority queue. Input: None. Output: True if the operation is successful; otherwise false. |
| peek() | Task: Returns the entry in this priority queue with the highest priority. The operation does not change the priority queue. Input: None. Output: The entry with the highest priority. |
