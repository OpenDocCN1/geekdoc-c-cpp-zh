The recursive method removeLeftmostNode, which is called by removeNode if N has two children, also uses this strategy to remove the inorder successor of the node containing the item to be removed.

Exercise 12 at the end of this chapter describes an easier removal algorithm. However, that algorithm tends to increase the height of the tree, and, as you will see later, an increase in height can decrease the efficiency of searching the tree.
