+   1. You can ignore low-order terms in an algorithm's growth-rate function. For example, if an algorithm is O(n² + 4 × n² + 3 × n), it is also O(n²). By examining the table in Figure 10-3a, you can see that the n² term is significantly larger than either 4 × n² or 3 × n, particularly for large values of n. For large n, the growth rate of n² + 4 × n² + 3 × n is the same as the growth rate of n². It is the growth rate of f(n), not the value of f(n), that is important here. Thus, even if an algorithm is O(n² + 4 × n² + 3 × n), we say that it is simply O(n²). In general, you can usually conclude that an algorithm is O(f(n)), where f is a function similar to the ones listed in Figure 10-3.
