# ABSTRACT DATA TYPE: SORTED LIST

## DATA
- A finite number of objects, not necessarily distinct, having the same data type and ordered by their values.

## OPERATIONS

| PSEUDOCODE | DESCRIPTION |
| :--- | :--- |
| insertSorted(newEntry) | Task: Inserts an entry into this sorted list in its proper order so that the list remains sorted.<br>Input: newEntry is the new entry.<br>Output: None. |
| removeSorted(anEntry) | Task: Removes the first or only occurrence of anEntry from this sorted list.<br>Input: anEntry is the entry to remove.<br>Output: Returns true if anEntry was located and removed, or false if not. In the latter case, the list remains unchanged. |
| getPosition(anEntry) | Task: Gets the position of the first or only occurrence of anEntry in this sorted list.<br>Input: anEntry is the entry to be located.<br>Output: Returns the position of anEntry if it occurs in the sorted list. Otherwise, returns the position where anEntry would occur in the list, but as a negative integer. |
