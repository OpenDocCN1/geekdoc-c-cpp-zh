+   - Unsorted, array-based
+   - Unsorted, link-based

The unsorted implementations store the items in no particular order; they can insert a new item into any convenient location. Notice that the add operation has two parameters: a data item and the item's search key. The sorted implementations must insert a new item into its proper position as determined by the value of its search key. Whether sorted or unsorted, the dictionary must not only store both pieces of data—search key and data item—but also form an association between the two. To do so, we will encapsulate each item with its search key into an object of a new class, Entry, as pictured in Figure 18-3.
