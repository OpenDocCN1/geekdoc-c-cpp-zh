This chapter considers the ADT dictionary, which is appropriate for problems that must manage data by value. Several dictionary implementations—which use arrays, linked chains, binary search trees, and a new technique known as hashing—will be presented, along with their advantages and disadvantages.

To make an intelligent choice among the various possible dictionary implementations, you must analyze the efficiency with which each of the implementations supports the dictionary operations. For example, we analyze the time-efficiency of array-based and linked-based dictionary implementations and conclude that, in many applications, the implementations do not support the dictionary operations as efficiently as possible. This conclusion motivates the use of more sophisticated dictionary implementations.
