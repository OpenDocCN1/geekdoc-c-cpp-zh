# Updating Data

To update an existing record in a database table, you can use the Execute method with an UPDATE SQL statement. For example:

```
using (var connection = new SqlConnection(connectionString))
{
    var user = new User { Id = 1, Name = "John Doe", Age = 35 };
    var sql = "UPDATE Users SET Name = @Name, Age = @Age WHERE Id = @Id";
    var affectedRows = connection.Execute(sql, user);
}
```

# Deleting Data

To delete a record from a database table, you can use the Execute method with a DELETE SQL statement. For example:

```
using (var connection = new SqlConnection(connectionString))
{
    var sql = "DELETE FROM Users WHERE Id = @Id";
    var affectedRows = connection.Execute(sql, new { Id = 1 });
}
```
