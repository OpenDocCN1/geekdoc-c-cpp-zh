# Bind the DataSet to a Data Control

Use the DataSource property of a data control, such as a DataGridView or a ComboBox, to bind the DataSet to the control.

```
dataGridView1.DataSource = dataSet.Tables["Employees"];
```

# Display Data in the User Interface

The data from the DataSet will now be displayed in the data control.

```
foreach (DataRow row in dataSet.Tables["Employees"].Rows)
{
    Console.WriteLine("Employee ID: {0}, Employee Name: {1}", row["EmployeeID"], row["EmployeeName"]);
}
```
