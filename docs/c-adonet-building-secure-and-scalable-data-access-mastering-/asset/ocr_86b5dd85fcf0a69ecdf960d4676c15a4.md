To insert records into the database using LINQ to SQL, follow these steps:

+   1. Create a new instance of the LINQ to SQL data context.
+   2. Create a new instance of the class that maps to the table you want to insert records into.
+   3. Add the new instance to the LINQ to SQL table.
+   4. Call the SubmitChanges method on the data context to commit the changes to the database.

Here's an example of how to insert a new customer into the "Customers" table:

```
```csharp
using (var db = new DataClassesDataContext())
{
    Customer newCustomer = new Customer();
    newCustomer.CustomerName = "New Customer";
    newCustomer.CustomerAddress = "123 Main Street";
    newCustomer.CustomerCity = "Anytown";
    newCustomer.CustomerState = "CA";
    newCustomer.CustomerZip = "12345";
    newCustomer.CustomerPhone = "555-555-5555";

    db.Customers.InsertOnSubmit(newCustomer);
    db.SubmitChanges();
}
```
```

In this example, the "DataClassesDataContext" class is the LINQ to SQL data context, and the "Customers" property is the LINQ to SQL table that maps to the "Customers" table in the database. The new customer is added to the "Customers" table using the InsertOnSubmit method, and the changes are committed to the database using the SubmitChanges method.
