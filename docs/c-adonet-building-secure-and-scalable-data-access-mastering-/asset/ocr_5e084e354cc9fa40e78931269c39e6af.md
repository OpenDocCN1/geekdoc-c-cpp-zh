# Introduction to ADO.NET Core

This module is designed to give you a foundational understanding of ADO.NET Core, its key features, improvements over traditional ADO.NET, and strategies for migrating existing applications to .NET Core.

# Overview of ADO.NET Core

ADO.NET Core is the modernized version of ADO.NET, optimized for use in .NET Core applications. It introduces simplified APIs, improved performance, and enhanced security features. These enhancements make ADO.NET Core well-suited for modern cloud-based applications.

# Key Features and Improvements

One of the significant improvements in ADO.NET Core is the introduction of the Microsoft.Data.SqlClient library. This library is optimized for performance and supports features such as Azure Active Directory authentication and Always Encrypted. Additionally, ADO.NET Core offers improved support for asynchronous programming and can work with various databases, including SQL Server, Oracle, MySQL, and SQLite.
