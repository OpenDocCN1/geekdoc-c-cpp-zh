# SQLDataReader Class

The SqlDataReader class is used to retrieve data from a database. You can use the ExecuteReader method to execute a SELECT statement and return a SqlDataReader object.

```
```csharp
string sql = "SELECT * FROM Employees;";
SqlCommand command = new SqlCommand(sql, connection);
SqlDataReader reader = command.ExecuteReader();
while (reader.Read())
{
    Console.WriteLine($"Name: {reader["Name"]}, Age: {reader["Age"]}, Department: {reader["Department"]}");
}
```
```

# SQLDataAdapter Class

The SqlDataAdapter class is used to populate a DataSet object with data from a database. You can use the Fill method to fill the DataSet with data from a SELECT statement.

```
```csharp
string sql = "SELECT * FROM Employees;";
SqlCommand command = new SqlCommand(sql, connection);
SqlDataAdapter adapter = new SqlDataAdapter(command);
DataSet dataSet = new DataSet();
adapter.Fill(dataSet, "Employees");
```
