# Updating Records

To update records in the database using LINQ to SQL, follow these steps:

+   1. Retrieve the record you want to update from the database.
+   2. Modify the record's properties.
+   3. Call the SubmitChanges method on the data context to commit the changes to the database.

Here's an example of how to update a customer's address in the "Customers" table:

```
using (var db = new DataClassesDataContext())
{
    Customer customerToUpdate = db.Customers.Single(c => c.CustomerId == 1);
    customerToUpdate.CustomerAddress = "456 Elm Street";

    db.SubmitChanges();
}
```

In this example, the "DataClassesDataContext" class is the LINQ to SQL data context, and the "Customers" property is the LINQ to SQL table that maps to the "Customers" table in the database. The record with the CustomerId of 1 is retrieved from the "Customers" table using the Single method, and its CustomerAddress property is modified. The changes are then committed to the database using the SubmitChanges method.
