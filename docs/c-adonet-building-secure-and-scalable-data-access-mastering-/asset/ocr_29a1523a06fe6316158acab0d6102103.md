```
[Table(Name = "Customers")]
public class Customer
{
    [Column(IsPrimaryKey = true)]
    public int CustomerId { get; set; }

    [Column]
    public string CustomerName { get; set; }

    [Column]
    public string CustomerAddress { get; set; }

    [Column]
    public string CustomerCity { get; set; }

    [Column]
    public string CustomerState { get; set; }

    [Column]
    public string CustomerZip { get; set; }

    [Column]
    public string CustomerPhone { get; set; }
}
}
```

In this example, the "MyDataContext" class is the LINQ to SQL data context, and the "GetCustomers" method is a compiled query that retrieves all customers from the "Customers" table. The "GetCustomersQuery" field is a static field that stores the compiled query for reuse.
