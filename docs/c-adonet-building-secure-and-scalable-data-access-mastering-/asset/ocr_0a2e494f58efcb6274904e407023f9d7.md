# INSERT Statement

The INSERT statement is used to insert new rows into a table. The basic syntax of the INSERT statement is:

```
INSERT INTO table_name (column1, column2, ...)
VALUES (value1, value2, ...);
```

In this syntax:

+   - table_name is the name of the table you want to insert data into.
+   - column1, column2, ... are the columns you want to insert data into.
+   - value1, value2, ... are the values you want to insert into the columns.

# UPDATE Statement

The UPDATE statement is used to update existing rows in a table. The basic syntax of the UPDATE statement is:

```
UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;
```

In this syntax:

+   - table_name is the name of the table you want to update data in.
+   - column1 = value1, column2 = value2, ... are the columns you want to update and the new values you want to set them to.
