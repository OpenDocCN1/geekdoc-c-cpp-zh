# ## Example of Implementing Paging with SQL Server

Here's an example of how to implement paging with SQL Server:

```
```sql
DECLARE @PageSize INT = 10
DECLARE @PageNumber INT = 1

SELECT * FROM Employees
ORDER BY EmployeeId
OFFSET (@PageNumber - 1) * @PageSize ROWS
FETCH NEXT @PageSize ROWS ONLY
```
```

In this example, we're retrieving data from the Employees table, ordering the results by the EmployeeId column, and using the OFFSET and FETCH clauses to skip records for previous pages and fetch records for the current page.
