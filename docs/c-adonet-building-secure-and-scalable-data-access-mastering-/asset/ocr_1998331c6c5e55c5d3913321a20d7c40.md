# ## Writing LINQ Queries

Once you have created a LINQ to SQL data model, you can write LINQ queries to query databases and manipulate data. LINQ queries allow you to use LINQ syntax to query databases, making it easier to work with relational data in your C# applications.

Here's an example of a LINQ query that retrieves all customers from the "Customers" table:

```
```csharp
using (var db = new DataClassesDataContext())
{
    var customers = from c in db.Customers
                    select c;

    foreach (var customer in customers)
    {
        Console.WriteLine(customer.CustomerName);
    }
}
```
```

In this example, the "DataClassesDataContext" class is the LINQ to SQL data context, and the "Customers" property is the LINQ to SQL table that maps to the "Customers" table in the database. The LINQ query retrieves all customers from the "Customers" table and iterates over them, printing the name of each customer to the console.
