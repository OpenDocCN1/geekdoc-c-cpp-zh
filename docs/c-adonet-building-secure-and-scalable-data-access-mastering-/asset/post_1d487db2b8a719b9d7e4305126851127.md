## Advanced SQL Techniques

In this section, we'll delve into some advanced SQL techniques that will help you perform complex data operations efficiently.

### Subqueries

A subquery is a query nested within another query. It allows you to perform a query within a query and use the result of the inner query in the outer query. Here's an example of a subquery:

```sql
SELECT * FROM Employees
WHERE Department IN (SELECT Department FROM Departments WHERE Location = 'New York');
```

In this example, the inner query retrieves the Department values where the Location is 'New York', and the outer query retrieves all records from the Employees table where the Department is in the result of the inner query.

### Joins

Joins are used to combine data from two or more tables based on a related column between them. There are several types of joins, including:

- **INNER JOIN**: Returns rows when there is a match in both tables.
- **LEFT JOIN**: Returns all rows from the left table and the matched rows from the right table.
- **RIGHT JOIN**: Returns all rows from the right table and the matched rows from the left table.
- **FULL JOIN**: Returns all rows when there is a match in one of the tables.

Here's an example of an INNER JOIN:

```
SELECT Employees.Name, Departments.Name AS Department
FROM Employees
INNER JOIN Departments ON Employees.DepartmentID = Departments.ID;
```

In this example, we're joining the Employees and Departments tables based on the DepartmentID column and selecting the Name column from both tables.

### Views

A view is a virtual table based on the result of a SELECT statement. It allows you to store complex queries as a single object and access the results as if they were a table. Here's an example of creating a view:

```sql
CREATE VIEW EmployeesWithDepartments AS
SELECT Employees.Name, Departments.Name AS Department
FROM Employees
INNER JOIN Departments ON Employees.DepartmentID = Departments.ID;
```

In this example, we're creating a view called EmployeesWithDepartments that combines the Employees and Departments tables based on the DepartmentID column.

### Stored Procedures

A stored procedure is a precompiled collection of SQL statements that can be executed by calling the stored procedure name. It allows you to encapsulate complex logic and reuse it across multiple applications. Here's an example of creating a stored procedure:

```sql
CREATE PROCEDURE GetEmployeesByDepartment
@DepartmentID INT
AS
BEGIN
SELECT * FROM Employees WHERE DepartmentID = @DepartmentID;
END;
```

In this example, we're creating a stored procedure called GetEmployeesByDepartment that retrieves all employees in a specific department based on the DepartmentID parameter.

string connectionString = "Data Source=MyServer;Initial Catalog=MyDatabase;Integrated Security=True;";

### SqlCommand Class

The SqlCommand class is used to execute SQL commands against a database. You can use the ExecuteNonQuery method to execute commands that do not return data, such as INSERT, UPDATE, and DELETE.

```
string sql = "INSERT INTO Employees (Name, Age, Department) VALUES ('John Doe', 30, 'IT');";
SqlCommand command = new SqlCommand(sql, connection);
command.ExecuteNonQuery();
```

### SqlDataReader Class

The SqlDataReader class is used to retrieve data from a database. You can use the ExecuteReader method to execute a SELECT statement and return a SqlDataReader object.

```csharp
string sql = "SELECT * FROM Employees;";
SqlCommand command = new SqlCommand(sql, connection);
SqlDataReader reader = command.ExecuteReader();
while (reader.Read())
{
    Console.WriteLine($"Name: {reader["Name"]}, Age: {reader["Age"]}, Department: {reader["Department"]}");
}
```

### SqlDataAdapter Class

The SqlDataAdapter class is used to populate a DataSet object with data from a database. You can use the Fill method to fill the DataSet with data from a SELECT statement.

```csharp
string sql = "SELECT * FROM Employees;";
SqlCommand command = new SqlCommand(sql, connection);
SqlDataAdapter adapter = new SqlDataAdapter(command);
DataSet dataSet = new DataSet();
adapter.Fill(dataSet, "Employees");
```
