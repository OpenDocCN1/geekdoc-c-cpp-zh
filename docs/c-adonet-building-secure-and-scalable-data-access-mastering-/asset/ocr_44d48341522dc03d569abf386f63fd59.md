To filter data using EF, use the Where method on the DbSet<TEntity> class, specifying the filter condition using a lambda expression. For instance, to retrieve all customers with a specific name:

```
using (var db = new MyDbContext())
{
    var customers = db.Customers.Where(c => c.Name == "John Doe").ToList();
}
```

# Sorting Data

You can sort data using the OrderBy, OrderByDescending, ThenBy, and ThenByDescending methods. For example, to sort customers by name:

```
using (var db = new MyDbContext())
{
    var sortedCustomers = db.Customers.OrderBy(c => c.Name).ToList();
}
```

# Projecting Data

EF supports projecting data using the Select method. This allows you to retrieve only the specific properties you need. For example, to retrieve only customer names:

```
using (var db = new MyDbContext())
{
    var customerNames = db.Customers.Select(c => c.Name).ToList();
}
```
