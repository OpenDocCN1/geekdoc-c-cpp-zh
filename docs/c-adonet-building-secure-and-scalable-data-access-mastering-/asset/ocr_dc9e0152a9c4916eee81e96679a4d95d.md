A DataSet is an in-memory representation of a set of related data tables. Each DataTable in a DataSet represents a table of data, and each DataRow in a DataTable represents a single row of data.

# Creating a DataSet

You can create a DataSet using the DataSet class in ADO.NET. Here's an example:

```
DataSet dataSet = new DataSet();
```

# Creating a DataTable

You can create a DataTable using the DataTable class in ADO.NET. Here's an example:

```
DataTable dataTable = new DataTable();
```

# Populating a DataTable

You can populate a DataTable using a DataAdapter. Here's an example:

```
string sql = "SELECT * FROM Employees";
SqlDataAdapter adapter = new SqlDataAdapter(sql, connection);
adapter.Fill(dataTable);
```

# Accessing Data in a DataTable

You can access data in a DataTable using the Rows property. Here's an example:

```
foreach (DataRow row in dataTable.Rows)
{
    Console.WriteLine("Employee ID: {0}, Employee Name: {1}", row["EmployeeID"], row["EmployeeName"]);
}
```
