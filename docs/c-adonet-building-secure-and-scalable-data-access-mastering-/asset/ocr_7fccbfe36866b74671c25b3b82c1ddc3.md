# ADO.NET Overview

ADO.NET is a data access technology that allows you to interact with databases in .NET applications. It provides a set of classes and interfaces for performing data operations, such as querying, updating, and deleting data.

# SQLConnection Class

The SqlConnection class is used to establish a connection to a SQL Server database. You can use the SqlConnectionStringBuilder class to build connection strings dynamically, or you can specify the connection string directly.

```
string connectionString = "Data Source=MyServer;Initial Catalog=MyDatabase;Integrated Security=True;";
SqlConnection connection = new SqlConnection(connectionString);
connection.Open();
```

# SQLCommand Class

The SqlCommand class is used to execute SQL commands against a database. You can use the ExecuteNonQuery method to execute commands that do not return data, such as INSERT, UPDATE, and DELETE.

```
string sql = "INSERT INTO Employees (Name, Age, Department) VALUES ('John Doe', 30, 'IT');";
SqlCommand command = new SqlCommand(sql, connection);
command.ExecuteNonQuery();
```
