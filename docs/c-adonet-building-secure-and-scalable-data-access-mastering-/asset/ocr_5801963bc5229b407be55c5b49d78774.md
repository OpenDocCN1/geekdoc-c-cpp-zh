+   1. Retrieve the record you want to delete from the database.
+   2. Call the DeleteOnSubmit method on the data context to mark the record for deletion.
+   3. Call the SubmitChanges method on the data context to commit the changes to the database.

Here's an example of how to delete a customer from the "Customers" table:

```
using (var db = new DataClassesDataContext())
{
    Customer customerToDelete = db.Customers.Single(c => c.CustomerId == 1);
    db.Customers.DeleteOnSubmit(customerToDelete);

    db.SubmitChanges();
}
```

In this example, the "DataClassesDataContext" class is the LINQ to SQL data context, and the "Customers" property is the LINQ to SQL table that maps to the "Customers" table in the database. The record with the CustomerId of 1 is retrieved from the "Customers" table using the Single method, marked for deletion using the DeleteOnSubmit method, and the changes are committed to the database using the SubmitChanges method.

LINQ to SQL allows you to write LINQ queries that modify data in the database, including inserting, updating, and deleting records. By using LINQ to SQL, you can work with relational data in a more natural and expressive way, making it easier to develop and maintain your applications.
