Dapper allows you to map query results to custom objects by specifying the mapping using the Map method.
For example:

```
public class CustomUser
{
    public string FullName { get; set; }
}

using (var connection = new SqlConnection(connectionString))
{
    var users = connection.Query<CustomUser>("SELECT FirstName + ' ' + LastName AS FullName FROM Users").ToList();
}
```

Dapper provides a simple and efficient way to execute various types of queries against a database. By using Dapper, you can improve the performance and maintainability of your data access code while keeping it simple and easy to understand.
