# How to Perform Server-Side Data Validation

There are several ways to perform server-side data validation in your C# applications:

+   - **Use Custom Validation Logic**: You can write custom validation logic in the code behind of your web pages or in a web service to validate data before it is saved to the database.
+   - **Use Data Annotations**: You can use data annotations in your C# classes to perform server-side validation. For example, you can use the Required attribute to ensure that a property is not null or empty.
+   - **Use ASP.NET Validation Controls**: If you are using ASP.NET Web Forms, you can use validation controls such as the RequiredFieldValidator and RegularExpressionValidator to perform server-side validation.
