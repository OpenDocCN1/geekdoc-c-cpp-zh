# ## Migrating Existing ADO.NET Applications to Core

In this section, we'll explore how to migrate existing ADO.NET applications to ADO.NET Core.

+   1. Updating References:

The first step in migrating an existing ADO.NET application to ADO.NET Core is to update the references in your project. You'll need to replace the ADO.NET references with ADO.NET Core references, which are included in the Microsoft.EntityFrameworkCore.SqlServer package. You can do this using the NuGet Package Manager in Visual Studio or by manually editing your project file.

+   2. Updating Code:

Next, you'll need to update your code to use ADO.NET Core classes and methods. This may involve making changes to your connection strings, data reader and data adapter code, and any other code that interacts with the database.
