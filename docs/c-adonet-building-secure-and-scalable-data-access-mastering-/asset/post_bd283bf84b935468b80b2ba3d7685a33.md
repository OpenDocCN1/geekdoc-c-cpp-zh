### Key Features of Entity Framework

- **Entity Data Model (EDM)**: The Entity Data Model is a conceptual model that maps database tables to classes in your application. It allows you to work with database data as objects in your application.
- **LINQ to Entities**: Entity Framework provides a LINQ provider that allows you to use LINQ queries to query databases and manipulate data. LINQ to Entities translates LINQ queries into SQL queries that can be executed against the database.
- **Automatic Change Tracking**: Entity Framework automatically tracks changes to objects in your application and generates the necessary SQL commands to update the database.
- **Lazy Loading**: Entity Framework supports lazy loading, which means that related objects are loaded from the database only when they are accessed.
- **Database First, Model First, and Code First Approaches**: Entity Framework supports three different approaches to model creation: Database First, Model First, and Code First. This allows you to choose the approach that best fits your project's needs.

## Querying Databases with Entity Framework

Entity Framework (EF) allows you to query databases using LINQ (Language Integrated Query) to Entities. This section will delve into how to query databases using EF, including filtering, sorting, and projecting data.

### Filtering Data

To filter data using EF, use the Where method on the DbSet<TEntity> class, specifying the filter condition using a lambda expression. For instance, to retrieve all customers with a specific name:

```
using (var db = new MyDbContext())
{
    var customers = db.Customers.Where(c => c.Name == "John Doe").ToList();
}
```

### Sorting Data

You can sort data using the OrderBy, OrderByDescending, ThenBy, and ThenByDescending methods. For example, to sort customers by name:

```
using (var db = new MyDbContext())
{
    var sortedCustomers = db.Customers.OrderBy(c => c.Name).ToList();
}
```

### Projecting Data

EF supports projecting data using the Select method. This allows you to retrieve only the specific properties you need. For example, to retrieve only customer names:

```
using (var db = new MyDbContext())
{
    var customerNames = db.Customers.Select(c => c.Name).ToList();
}
```

### Including Related Data

EF allows you to include related data in your queries using the Include method. This is useful when you need to retrieve data from related tables. For example, to include order details with customers:

```
using (var db = new MyDbContext())
{
    var customersWithOrders = db.Customers.Include(c => c.Orders).ToList();
}
```

### Asynchronous Queries

EF supports asynchronous queries using the asynchronous variants of the methods. This allows your application to continue running while waiting for the database to respond. For example, to retrieve customers asynchronously:

```
using (var db = new MyDbContext())
{
    var customers = await db.Customers.ToListAsync();
}
```

Entity Framework provides powerful querying capabilities, allowing you to filter, sort, project, and include related data in your queries. By using EF, you can write expressive and efficient queries that simplify data access in your C# applications.

## Modifying Data with Entity Framework

Entity Framework (EF) provides various methods for modifying data in your database. This section will cover how to add, update, and delete records using EF.

### Adding Records

To add a new record to your database using EF, create a new instance of the entity class, add it to the appropriate DbSet<TEntity>, and then call SaveChanges on the DbContext. For example, to add a new customer:

```csharp
using (var db = new MyDbContext())
{
    var newCustomer = new Customer
    {
        Name = "John Doe",
        Email = "john@example.com"
    };

    db.Customers.Add(newCustomer);
    db.SaveChanges();
}
```

### Updating Records

To update an existing record in your database using EF, retrieve the record, modify its properties, and then call SaveChanges on the DbContext. For example, to update a customer's email address:
