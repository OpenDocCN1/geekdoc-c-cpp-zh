# Overview of LINQ to SQL

LINQ to SQL is an Object-Relational Mapping (ORM) framework that allows developers to query and manipulate databases using LINQ (Language-Integrated Query) syntax. In this section, we'll introduce LINQ to SQL, discuss its key features, and explore how it can be used in C# applications.

# What is LINQ to SQL?

LINQ to SQL is a component of the .NET Framework that provides a mapping between database tables and classes in your application. It allows you to use LINQ queries to retrieve and manipulate data from databases, making it easier to work with relational data in your C# applications.
