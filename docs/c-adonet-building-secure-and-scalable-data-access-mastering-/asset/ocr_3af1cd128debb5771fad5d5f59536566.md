Here's an example of how to use transactions in LINQ to SQL:

```
using System.Transactions;

namespace MyNamespace
{
    public class MyService
    {
        public void UpdateCustomer(int customerId, string newAddress)
        {
            using (var scope = new TransactionScope())
            {
                using (var db = MyDataContext.GetMyDataContext())
                {
                    Customer customerToUpdate = db.Customers.Single(c => c.CustomerId == customerId);
                    customerToUpdate.CustomerAddress = newAddress;

                    db.SubmitChanges();
                }

                scope.Complete();
            }
        }
    }
}
```

In this example, the "UpdateCustomer" method updates a customer's address in the "Customers" table. The changes are committed to the database using the SubmitChanges method, and the transaction is completed using the Complete method.
