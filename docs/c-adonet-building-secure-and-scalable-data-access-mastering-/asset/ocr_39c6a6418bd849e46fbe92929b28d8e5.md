To add a new record to your database using EF, create a new instance of the entity class, add it to the appropriate DbSet<TEntity>, and then call SaveChanges on the DbContext. For example, to add a new customer:

```
```csharp
using (var db = new MyDbContext())
{
    var newCustomer = new Customer
    {
        Name = "John Doe",
        Email = "john@example.com"
    };

    db.Customers.Add(newCustomer);
    db.SaveChanges();
}
```
```

# Updating Records

To update an existing record in your database using EF, retrieve the record, modify its properties, and then call SaveChanges on the DbContext. For example, to update a customer's email address:

```
```csharp
using (var db = new MyDbContext())
{
    var customerToUpdate = db.Customers.Single(c => c.Id == customerId);
    customerToUpdate.Email = "new_email@example.com";

    db.SaveChanges();
}
```
