ADO.NET Core supports different types of commands, such as SqlCommand, MySqlCommand, and NpgsqlCommand, for executing SQL queries and stored procedures. The ExecuteReader, ExecuteScalar, and ExecuteNonQuery methods are used to retrieve data from the database.

```
```csharp
using (SqlCommand command = new SqlCommand("SELECT * FROM Employees", connection))
{
    using (SqlDataReader reader = command.ExecuteReader())
    {
        while (reader.Read())
        {
            // Process each row of data
        }
    }
}
```
```

# Performing CRUD Operations

ADO.NET Core supports Create, Read, Update, and Delete (CRUD) operations using SQL commands or stored procedures. Parameters can be used to pass values to the SQL commands, preventing SQL injection attacks.

```
```csharp
using (SqlCommand command = new SqlCommand("INSERT INTO Employees (Name) VALUES (@name)", connection))
{
    command.Parameters.AddWithValue("@name", "John Doe");
    command.ExecuteNonQuery();
}
```
