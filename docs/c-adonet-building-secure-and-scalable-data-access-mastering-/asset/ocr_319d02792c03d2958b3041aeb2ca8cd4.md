# Using Transactions in ADO.NET

1. **Begin Transaction**: To initiate a transaction, create a new instance of SqlTransaction object within an existing connection. Ensure the connection is open before starting the transaction.

```
SqlConnection connection = new SqlConnection(connectionString);
connection.Open();
SqlTransaction transaction = connection.BeginTransaction();
```

2. **Perform Database Operations**: Execute SQL commands within the transaction scope using the SqlCommand object, specifying the transaction object as a parameter.

```
SqlCommand command1 = new SqlCommand("INSERT INTO Employees (Name) VALUES ('John')", connection, transaction);
command1.ExecuteNonQuery();
```

3. **Commit or Rollback**: After executing all operations, decide whether to commit or rollback the transaction based on the success or failure of the operations.

{
    transaction.Commit();
    Console.WriteLine("Transaction committed successfully.");
}
