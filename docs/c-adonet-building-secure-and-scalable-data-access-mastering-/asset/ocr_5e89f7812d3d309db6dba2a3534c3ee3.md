The CREATE operation is used to add new records to a database table. In SQL, this is achieved using the INSERT statement. Here's an example of how to use the INSERT statement:

```
INSERT INTO Employees (Name, Age, Department)
VALUES ('John Doe', 30, 'IT');
```

In this example, we're inserting a new record into the Employees table with the Name, Age, and Department columns.

# Read Operation (SELECT)

The READ operation is used to retrieve data from a database table. In SQL, this is achieved using the SELECT statement. Here's an example of how to use the SELECT statement:

```
SELECT * FROM Employees;
```

In this example, we're retrieving all records from the Employees table.

# Update Operation (UPDATE)

The UPDATE operation is used to modify existing records in a database table. In SQL, this is achieved using the UPDATE statement. Here's an example of how to use the UPDATE statement:

```
UPDATE Employees
SET Age = 31
WHERE Name = 'John Doe';
```

In this example, we're updating the Age column of the record where the Name column is 'John Doe'.
