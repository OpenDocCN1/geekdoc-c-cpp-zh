# Batch Processing with Data Adapters

Data adapters support batch processing, which allows you to perform multiple database operations in a single transaction. We'll discuss how to use the BatchSize property of a data adapter to control the size of batches, and how to use the FillBatchSize property to control the size of data retrieval batches. We'll also discuss how to use the AcceptChangesDuringFill property to control when changes are applied to a DataSet during data retrieval.

# What is a Data Adapter?

A Data Adapter is a class that provides a bridge between a DataSet and a data source for retrieving and saving data. It acts as an intermediary between the application and the data source, allowing you to work with data in a disconnected manner.
