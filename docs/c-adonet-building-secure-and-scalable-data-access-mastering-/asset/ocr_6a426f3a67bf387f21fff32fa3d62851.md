To delete a record from your database using EF, retrieve the record, call Remove on the DbSet<TEntity>, and then call SaveChanges on the DbContext. For example, to delete a customer:

```
using (var db = new MyDbContext())
{
    var customerToDelete = db.Customers.Single(c => c.Id == customerId);
    db.Customers.Remove(customerToDelete);

    db.SaveChanges();
}
```

# Bulk Operations

EF also supports bulk operations for adding, updating, and deleting multiple records. This can improve performance when dealing with large datasets. For example, to add multiple customers:

```
using (var db = new MyDbContext())
{
    var customers = new List<Customer>
    {
        new Customer { Name = "John Doe", Email = "john@example.com" },
        new Customer { Name = "Jane Doe", Email = "jane@example.com" }
    };

    db.Customers.AddRange(customers);
    db.SaveChanges();
}
```

Entity Framework provides various methods for adding, updating, and deleting records in your database. By using EF, you can easily modify data in your C# applications, making it easier to develop and maintain your applications.
