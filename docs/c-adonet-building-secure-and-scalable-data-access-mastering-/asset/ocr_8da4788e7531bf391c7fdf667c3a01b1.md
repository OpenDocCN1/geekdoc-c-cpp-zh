+   - **First Normal Form (1NF)**: The first normal form requires that each column in a table contains atomic (indivisible) values. This means that a column cannot contain multiple values or a combination of values.
+   - **Second Normal Form (2NF)**: The second normal form requires that a table be in first normal form and that all non-key attributes are fully functionally dependent on the primary key. This means that each non-key attribute is determined by the entire primary key, not just part of it.
+   - **Third Normal Form (3NF)**: The third normal form requires that a table be in second normal form and that all non-key attributes are non-transitively dependent on the primary key. This means that each non-key attribute is determined by the primary key, not by any other non-key attributes.
+   - **Boyce-Codd Normal Form (BCNF)**: The Boyce-Codd normal form is a stricter form of the third normal form. It requires that a table be in third normal form and that every determinant (a set of attributes that uniquely determines another attribute) is a candidate key.
+   - **Fourth Normal Form (4NF)**: The fourth normal form requires that a table be in third normal form and that there are no non-trivial multi-valued dependencies.
+   - **Fifth Normal Form (5NF)**: The fifth normal form requires that a table be in fourth normal form and that there are no non-trivial join dependencies.
