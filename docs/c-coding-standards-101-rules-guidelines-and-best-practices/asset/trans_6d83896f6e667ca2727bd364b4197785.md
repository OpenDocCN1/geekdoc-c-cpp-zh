## C++ 深度系列

Bjarne Stroustrup，编者

> “我把这封信写得比平常更长，因为我没有时间把它写短。”
> ——布莱兹·帕斯卡

ISO/ANSI C++ 标准的出现标志着 C++ 程序员新时代的开始。该标准提供了许多新设施和机会，但实际工作中的程序员如何才能抽出时间，从海量信息中发现智慧精华？**C++ 深度系列**通过为程序员提供简明、聚焦于特定主题的指南，最大限度减少学习时间和困惑。

本系列每本书只讲一个主题，其技术深度与该主题相称。本系列的实践方法旨在帮助专业人士将编程技能提升到新水平。这些简短而深入的专著由该领域专家撰写，阅读和查阅时不会受到无关材料的干扰。本系列各书之间相互交叉引用，并引用 Bjarne Stroustrup 的 *C++ 程序设计语言*。

随着你提升 C++ 技能，区分核心信息与炒作和浮华、找到成长所需的深度内容，变得越来越重要。C++ 深度系列提供工具、概念、技术和 C++ 新方法，助你获得关键优势。
