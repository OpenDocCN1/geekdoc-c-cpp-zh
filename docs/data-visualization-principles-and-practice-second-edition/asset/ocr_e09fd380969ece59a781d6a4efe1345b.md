The techniques discussed above effectively “project” the time dimension of the input graph to one spatial dimension (the vertical, respectively horizontal screen axes in Figures 11.24(a,b)). As such, the entire graph dataset is visualized in a single image. This approach is named the *small multiples* technique. Small multiple displays can be effectively used to visualize other types of dynamic datasets and, more generally, for comparing several data keyframes in an ordered sequence [Tufte 01]. However, the scalability of small multiples is limited by the available screen space to about 10.20 keyframes, thereby their name.

*Using animation:* A different approach to showing dynamic graphs is to use *animation* to encode the time dimension. The general idea is simple: Given a dynamic streaming or sequence graph, produce a visualization where the amount of change (in terms of color, size, position, or similar visual elements) is proportional to the amount of change in the underlying graph data. As the eye is attracted by visual changes, this helps in discovering the data changes.

Figure 11.25 introduces a simple graph animation technique for the visualization of large dynamic hierarchical graphs. The underlying sequence graph captures the software hierarchy and call relations from 14 revisions of the Wicket open-source software system. Node correspondence relations $c^{node}$ are based on the fully qualified name of a node. In other words, a node $n^t$ is the same as a node $n^{t+1}$ if the two nodes have the same name and same-name parents in the graphs $G^t$ and $G^{t+1}$. Edge correspondence relations are based on correspondences of their end nodes. That is, a call edge $e^{t+1}$ is the same as an edge $e^t$ if it links the same nodes (in $G^{t+1}$) as $e^t$ links in $G^t$.

Before constructing the actual animation, a so-called *union graph* $G_U$ is built. This graph contains all nodes present in all keyframes $G^t$ in our sequence, together with their hierarchy relations. $G_U$ is next drawn using the by now familiar circular icicle plot technique. Next, call relations $E^t$ in each keyframe $G^t$ are bundled images $B^t$, one for each keyframe. The animation is next constructed by a linear interpolation that links a bundle keyframe $B^t$ with its previous and next keyframes $B^{t-1}$ and $B^{t+1}$, respectively.
