# 9.3.4 Edge Detection

Edges are important visual elements in images. Informally speaking, edges in 2D images can be defined as 1D curves that separate image regions of different luminance, for grayscale images, or hues, for color images. Detecting edges in images is an important step in the process of extracting shapes from unstructured image data (see Section 9.4).
