Distance preservation. A stronger, and equally useful property used in many visualization applications, is that the function Map tries to preserve distances when mapping from the data to the visual domain. That is, the distance d(x1, x2) between any two values x1 and x2 in the dataset D should suggest the distance d'(Map(x1), Map(x2)) in the visual feature dataset Dv. The simplest way to do this is to use a direct proportionality relationship between the two. This is useful when we are interested in visually comparing relative values rather than assessing absolute attribute values. For example, looking at our 3D elevation plot, we can tell the relative function values of various data points in the domain by visually comparing their heights in the 3D plot, even though we may have no exact idea about their absolute values.
