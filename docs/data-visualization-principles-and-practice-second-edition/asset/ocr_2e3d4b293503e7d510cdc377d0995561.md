Ellipsoids do not have any of these problems, but their two-dimensional projection does not always convey a non-ambiguous 3D orientation when viewed from certain angles. To solve this problem, superquadric glyphs have been introduced by Kindlmann [Kindlmann 04a]. These are defined as superquadric shapes parameterized as functions of the planar and linear certainty metrics $c_l$ and $c_p$, respectively [Kindlmann 04b]. If we express the superquadric shape as an implicit function $q(x, y, z) = 0$, the actual superquadric glyph formulations become

```
q(x, y, z) = \left\{ \begin{array}{ll} (y^{2/\alpha} + z^{2/\alpha})^{\alpha/\beta} + x^{2/\beta} - 1 = 0, \text{ if } c_l \ge c_p, \text{ where } \left\{ \begin{array}{l} \alpha = (1 - c_p)^\gamma, \\ \beta = (1 - c_l)^\gamma, \\ \gamma = (1 - c_l)^\gamma, \end{array} \right. \\ (x^{2/\alpha} + y^{2/\alpha})^{\alpha/\beta} + z^{2/\beta} - 1 = 0, \text{ if } c_l < c_p, \text{ where } \left\{ \begin{array}{l} \alpha = (1 - c_l)^\gamma, \\ \beta = (1 - c_p)^\gamma, \\ \gamma = (1 - c_p)^\gamma. \end{array} \right. \end{array} \right.
```
