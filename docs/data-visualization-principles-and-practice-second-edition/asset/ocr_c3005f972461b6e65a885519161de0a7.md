Every location x in a Voronoi diagram is included in the Voronoi cell that has as center the closest point p in the input point set {pi}. Hence, Voronoi diagrams can be used to quickly find the closest point p from a given scattered point set to a given test location x. Note that the Voronoi cells corresponding to vertices on the convex hull of the input point set are unbounded, as they contain all points in the 2D plane that are closest to every point on the input's convex hull.
