Poisson reconstruction. We can extend the basic idea of using distance functions to reconstruct surfaces from point clouds presented earlier in this section in several ways. One such way is to incorporate normal information, as follows. Given a point cloud \((x_i, \mathbf{n}_i)\) of point locations \(x_i\) and normals \(\mathbf{n}_i\), the reconstructed surface \(S\) can be described implicitly by a function \(f : \mathbb{R}^3 \rightarrow \mathbb{R}\), so that \(f\) is one inside \(S\) and zero outside. It follows that the gradient \(\nabla f\) of \(f\) over \(f\) equals the inward normal of \(f\). Hence, reconstructing \(S\) amounts to finding a scalar function \(f\) whose gradient best approximates the point normals \(\mathbf{n}_i\) at the sample points \(x_i\), i.e., finding \(f\) so that

```
\(\nabla f \simeq \mathbf{n}\) (8.7)
```

at \(x_i\). If we apply the divergence operator to both sides of Equation 8.7, we obtain
