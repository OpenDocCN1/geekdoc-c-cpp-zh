We saw in Chapter 2 that Gourand shading requires surface normals to be available, in some way, at the polygon vertices. Also, we saw how to compute surface normals using the derivatives of the data, in case these are a continuous function. In this section, we address the problem of computing derivatives when we have a sampled dataset.

One of the requirements mentioned in the previous section for a sampled dataset $\mathcal{D}_s$ was that it should be generic, i.e., that we can easily replace the various data-processing operations available for its continuous counterpart $\mathcal{D}_c$ with equivalent operations on the $\mathcal{D}_s$. We saw, also, that computing derivatives is such an operation. Derivatives of data are needed for a wide range of processing tasks, ranging from the simple normal computation for Gourand shading to more complex data filtering and smoothing and feature detection tasks, as described in Chapters 5 and 9.

How should we compute data derivatives in case all we have is a sampled dataset $\mathcal{D}_s = (p_i, c_i, f_i, \Phi_i)^i$? Since we replaced our continuous signal $\bar{f}$ with $\bar{f}$, a logical choice is to compute derivatives of the reconstructed signal $\bar{f}$ and use them instead of the derivatives of the original signal $f$. We know how to reconstruct $\bar{f}$ from $\mathcal{D}_s$ using a given set of basis functions: $\bar{f} = \sum_{i=1}^N f_i \phi_i$ (see Equation (3.2)). Remember, $f$ is a $d$-dimensional function, i.e., $f : \mathbf{D} \in \mathbb{R}^d$. We can now compute the derivative of $\bar{f}$ with respect to its $i$th variable $x_i$ as

```
$$ \frac{\partial \bar{f}}{\partial x_i} = \sum_{j=1}^N f_j \frac{\partial \phi_j}{\partial x_i} $$
```

This is a linear combination of the derivatives of the basis functions in use. However, this expression is not very convenient to use, since the actual basis functions $\phi_j$ are quite complex on a general grid (see Equation (3.10)). We can simplify the the computation of the derivatives of $\bar{f}$ using the expressions of the reference basis functions $\Phi_j$, since these look the same on all cells of a given type in a given grid. Using Equations (3.9) and (3.32), we get

```
$$ \frac{\partial \bar{f}}{\partial x_i} = \sum_{j=1}^N f_j \frac{\partial \Phi_j}{\partial x_i}(r). $$
```

We now use the derivation chain rule and obtain

```
$$ \frac{\partial \Phi}{\partial x_i} = \sum_{j=1}^d \frac{\partial \Phi}{\partial r_j} \frac{\partial r_j}{\partial x_i} $$
```
