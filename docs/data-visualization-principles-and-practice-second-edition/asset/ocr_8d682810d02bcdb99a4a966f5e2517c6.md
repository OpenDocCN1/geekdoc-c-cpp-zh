Hence, all visualizations shown in Section 2.1 that rendered our height plot using a set of quads are nothing else but reconstructions of the function graph surface with C^1 basis functions. Luckily, we do not have to program this interpolation ourselves when doing rendering. For a number of cell types, such as lines, triangles, and quads, virtually all rendering engines nowadays (such as OpenGL) provide efficient interpolation implementations as rendering primitives.
