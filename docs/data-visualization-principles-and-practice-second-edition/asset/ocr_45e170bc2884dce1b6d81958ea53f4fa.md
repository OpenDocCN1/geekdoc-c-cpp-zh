These large cushions actually correspond to the nonleaf nodes of the tree. Using the shaded cushions, several levels of the tree hierarchy can be displayed with no additional screen space by borrowing from the screen space already allocated to show the leaf nodes. To explicitly visualize non-leaf nodes, we can use interaction: For the node n under the mouse cursor, we highlight the path from n to the tree root by drawing outlines around its nodes. Using different outline colors, such as red, orange, and yellow in Figure 11.10, allows easily assessing the depth of a leaf node into the tree. Using additional interaction, e.g., the mouse wheel, allows us to implement a simple mechanism to select non-leaf nodes along the highlighted path. In contrast to drawing borders for all nodes, this solution shows parent information only on demand, but is more space-efficient, especially for deep trees.
