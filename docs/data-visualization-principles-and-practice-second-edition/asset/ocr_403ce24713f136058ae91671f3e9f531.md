The original implementation of shaded cushions [van Wijk and van de Wetering 99] renders the cushion treemap in software by applying the Phong lighting (see Equation (2.1)) at every pixel of the treemap image, using an analytically computed normal from the summed profiles. This method works well for treemap images of moderate size, but cannot render full-screen images at interactive rates. When this is required, such as in applications where the user needs to change various visualization parameters and quickly regenerate the treemap rendering, pixel-shader techniques can be used to compute the shaded cushions in graphics hardware.
