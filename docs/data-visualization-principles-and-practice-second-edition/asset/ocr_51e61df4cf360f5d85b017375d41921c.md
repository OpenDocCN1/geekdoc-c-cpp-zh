```
glMatrixMode(GL_PROJECTION);
glLoadIdentity( );
gluPerspective(fov, aspect, z_near, z_far)
```

The first two function calls (glMatrixMode and glLoadIdentity) ensure that the subsequent gluPerspective call will affect the intrinsic, or projection, camera parameters rather than the extrinsic ones, which were discussed in the previous section. The constraints for gluPerspective call are that both z_near and z_far should be positive values.
