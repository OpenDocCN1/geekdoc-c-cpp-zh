This says that the streamline point at position \(\mathbf{x}\) is tangent to the vector field \(\mathbf{v}(\mathbf{x})\) at the same position. This can also be expressed in terms of the ordinary differential equation

```
\(\frac{d\mathbf{x}(\tau)}{d\tau} = \mathbf{v}(\mathbf{x}(\tau)) \tag{6.9}\)
```

with initial condition \(\mathbf{x}(\tau = 0) = \mathbf{x}_0\) (the streamline must pass through a given seed point \(\mathbf{x}_0\)) and with the constraint \(\tau \in [0, S_{max}]\) (the streamline has a length given by \(S_{max}\)). If we integrate Equation 6.9 over \(\tau\), we obtain the streamline

```
\(S_{stream} = \{ \mathbf{x}(\tau), \tau \in [0, S_{max}] \}, \mathbf{x}(\tau) = \mathbf{x}(0) + \int_0^\tau \mathbf{v}(\mathbf{x}(s)) ds,\)

with \(\mathbf{x}(\tau = 0) = \mathbf{x}_0.\) (6.10)
```

Streamlines are defined for time-independent vector fields. However, in various texts, streamline computation mentions a concept of *time*. This refers to the parameters \(\tau\) and \(s\) in the above equations, which can be thought of as an *integration time*, and should not be confounded with the *physical time* of a time-dependent dataset.

**Pathlines.** In case of time-dependent vector fields \(\mathbf{v}(\mathbf{x}, t)\), several types of curves can be integrated in the vector field. First and simplest, streamlines can be computed by fixing, or freezing, the physical time \(t\) to a desired value \(t_{fixed}\) and using Equation (6.10) to compute the curves that a particle would follow in \(\mathbf{v}(\mathbf{x}, t_{fixed})\).

A second option is to compute the actual path \(\mathbf{x}(t)\) of a particle in the time-dependent vector field, given by

```
\(\frac{d\mathbf{x}(t)}{dt} = \mathbf{v}(\mathbf{x}(t), t) \tag{6.11}\)
```

starting from a given seed point \(\mathbf{x}(t_0) = \mathbf{x}_0\). This is nothing but applying Equation 6.9 while making the integration time \(\tau\) run in sync with the physical time \(t\). The emerging curves \(S_{path} = \mathbf{x}(t)\) are called *particle traces*, or *pathlines*. They describe the actual trajectory, over physical time, that a particle released at \(\mathbf{x}_0\) follows in the time-dependent vector field.

Over the considered time interval \(T\), imagine that ink is continuously released from \(\mathbf{x}_0\).
