German mobile phone numbers always start with 01, followed by one of the digits 5, 6, or 7. And they have a total length between 9 and 13 digits. The regular expression R"([0-567])\d{6,10}" catches them. We will discuss the pattern used for searching with rgxMobile in more detail later in Table 28.1.

While regex_match always checks if the entire pattern, regex_search also finds matches anywhere in the text.

```
// https://godbolt.org/z/E9hcWGMW4
#include <regex>
#include <string>
#include <iostream>
using std::regex; using std::regex_match; using std::regex_search;
int main() {
    std::cout << std::boolalpha;
    regex pattern("hello");
    std::string text = "Hello world";
    auto b1 = regex_match(text.begin(),text.end(), pattern); // does not match
    std::cout << b1 << "\n"; // Output: false
    auto b2 = regex_search(text.begin(),text.end(), pattern); // found
    std::cout << b2 << "\n"; // Output: true
}
```
