```
// https://cppreference.com/w/cpp/language/literals
using std::pair; // using user-defined literals in a namespace
namespace l {
    constexpr pair<char, char> operator ''"(const char* s, size_t len) {
        // operator to parse user-defined literals in a custom type
        return len==2 ? make_pair(s[0], s[1]) : make_pair('-', ' ');
    }
}
struct O {
    char a; int n;
    O(char a, int n) : a(a), n(n) {}
    operator pair<const char, int>() const { return make_pair(a, n); }
};
// explicit pairs:
map<int, int> nums = {pair(int,6), make_pair(7,8), make_pair(11,23)};
map nums2 = {pair<int>(1,6), make_pair(5,2)};
// implicit pairs from initializer lists:
map<int, char> numch = {{1,'a'}, {2,'b'}, {3,'c'};
map<int, int> nums3 = {{7,2}, {9,4}};
using namespace l;
map<char, char> cmap = {"ab_p", "ed_f"}; // detour custom literal
cout << cmap; // Output: a:b c:d e:f
map<char,int> qmap = {0('a',1), 0('b',2), 0('c',3)}; // implicit conversions
cout << qmap; // Output: a:1 b:2 c:3
```

**Listing 24.62** The initializer list must contain "pair" elements.

As you can see in code of qmap, the elements of the initializer
list can be implicitly converted to the pair<const Key,Target>.
This is quite useful for compact notation.

# Insert

Just like with a set, you can add elements with insert, emplace,
emplace hint, and from C++23 with insert_range. There are also
operator[] and insert_assign, which may also insert new
elements under certain circumstances.
