# Listing 29.25 Late initialization with multiple threads.

This way, useBigData can be called within threads, and the standard library guarantees that initBigData is called exactly once. You see that the function is passed here as a parameter to call_once, so it's similar to jthread{}. You are correct if you suspect that you can also use lambdas and function objects here.
