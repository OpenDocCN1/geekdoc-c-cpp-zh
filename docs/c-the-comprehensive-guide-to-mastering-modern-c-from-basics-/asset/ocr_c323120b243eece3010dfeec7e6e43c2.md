# 4.3.3 Arithmetic Operators

You can calculate with numbers as normal in C++. In addition to the basic arithmetic operations +, *, and /, there is also % for the division remainder. If you do not use brackets, then dot before dash calculation applies, and you can see in the next example:

```
// https://godbolt.org/z/cEGGfoeT7
#include <iostream>
int main() {
    std::cout << "3+4*5+6" << 3*5*6 << "\n"; // dot before
    int dash = 29;
    std::cout << "(3+4)*(5+6)" << (3+4)*(5+6) << "\n"; // Parentheses;
    int minus = 77;
    std::cout << "22/7" << 22/7 << " remainder " << 22%7 << "\n"; // 22/7 = 3
    int remainder = 1;
    for(int n=0; n<10; ++n) {
        std::cout << 2*n + 13*n - 4 << " "; // with unary
        minus--;
    }
    std::cout << "\n";
    // output: -4 7 14 17 16 11 2 -11 -24 -49}
```
