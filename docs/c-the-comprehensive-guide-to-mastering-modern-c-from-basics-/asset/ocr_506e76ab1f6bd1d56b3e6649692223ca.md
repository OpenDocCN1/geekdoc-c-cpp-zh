# 26.3 Implementing Algorithms That Are Specialized Depending on the Container

If you want to write algorithms that behave differently depending on the type of range (or container) they operate on, starting with C++20, you can use constexpr if and the well-thought-out hierarchy of ranges concepts to use the appropriate implementation in the different constexpr branches.

Within a single function, you can decide which algorithm you want to use for which range. All of this happens at compile time, as shown in Listing 26.4.

```
// https://godbolt.org/z/rgzis6hll
#include <iostream>
#include <vector>
#include <list>
#include <ranges>
namespace rs = std::ranges;

template<class R>
void alg(R& range) {
    if constexpr (rs::random_access_range<R>)
        std::cout << "random access.\n";
    else if constexpr (rs::bidirectional_range<R>)
        std::cout << "bidirectional, but not random access\n";
    else static_assert(false, "unsupported range type");
}

int main() {
    std::vector<int> vec; // vector is random access
    alg(vec);
    std::list<int> lst; // list is only bidirectional
    alg(lst);
    std::istambuf_iterator<char> il(std::cin), i12; // not even bidirectional
    auto fwd = rs::subrange{il, i12};
    alg(fwd); // Error: no matching
```
