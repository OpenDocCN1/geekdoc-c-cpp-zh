10*24*hours results in a ten-day span. Each duration type has period defined as using. It's defined as a ratio of what you requested with the template. For example hours the definition hours::period will be ratio<3600>. Sounds more complicated than it looks in code (slightly simplified):

```
template<typename Rep, typename Period>

    using rep = Rep;

using hours = duration<int,ratio<3600>>;
```

# Time Points: "time_point"

While duration represents some relative duration, time_point is absolute. For <chrono>, a time_point is a firmly connected pair of duration and a reference point.

For example, the reference point could be January 1, 2000, and the duration 6,518 days; then the pair of these two values would name the time point as November 5, 2017.
