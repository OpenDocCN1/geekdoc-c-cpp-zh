# A coroutine is a 29.8.1 Coroutines in the Compiler function that contains the keyword co_return instead of return and can optionally contain co_yield and co_await:

+   - **co_return**
  - This defines the final return value of the coroutine instead of return. The caller can then continue its execution path.

+   - **co_await**
  - This allows the coroutine to pause its work and promises it can resume its work, for example, when an intermediate result it needs is available.

+   - **co_yield**
  - This produces an intermediate result from the coroutine and suspends it at the same time. In principle, it is a combination of co_await and co_return.
