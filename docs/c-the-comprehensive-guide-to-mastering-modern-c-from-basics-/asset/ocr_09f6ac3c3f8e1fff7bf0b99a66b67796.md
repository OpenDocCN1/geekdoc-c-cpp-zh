not deleted, but merely rearrange elements—for example, moving them to the end where they can be easily deleted. This also applies to ranges—that is, everything from the std::ranges namespace.

You can delete all elements effectively with a simple call to clear():

```
std::vector v{1, 2, 3};
v.clear();                                     // v is not empty
```

You could delete a single element with erase:

```
// https://godbolt.org/r/683bdcdrd
std::vector v{1, 2, 3, 4, 5, 6};
for(auto it=v.begin(); it!=v.end(); ++it) {
    it = v.erase(it);
}
// Here v is: {2, 4, 6}
```

The return value of erase is an iterator pointing to the first element beyond the erased one. Because the loop increments with ++it, this loop deletes every second element.

If you want to delete a range, also use erase, but specify the range with two iterators.

```
// https://godbolt.org/r/febe9v9
std::vector v{1, 2, 3, 4, 5, 6};
v.erase(v.begin(), v.begin()+5);             // v is now {1, 2, 6}
v.erase(v.begin(), v.end());               // deletes the rest
```

# Listing 24.31 "erase" with two parameters deletes an entire range.

The first parameter is the element to be deleted; the second parameter is the first element that should remain after the range to be deleted, so it points to an element after the last element to be deleted.

To delete the end of a vector, pop_back is more suitable:

```
std::vector v{1, 2, 3};
v.pop_back();                             // v becomes {1, 2}
```

When you combine erase with free functions like remove or remove_if from <algorithm>, you have many flexible, elegant, and efficient options to remove elements from a vector—or indeed from any container. You can find examples in Chapter 25.
