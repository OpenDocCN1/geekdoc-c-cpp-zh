# 6.1.4 For Viewing Only: “string_view” be long. Very long.

And modern C++ advocates that you program with values instead of pointers or references. This is a crucial issue with potentially huge objects; it is not wise to use values rigorously with long strings. What are you to to do? The new string_view in C++17 is the solution.

A string_view (and the corresponding w_view and the like) is a read-only object into a string. The class offers the same functions and methods so long as they are read-only. So you can iterate with begin() and end(), find with find(), compare with compare() or ==, check the starts with starts_with(), and much more—and use them in algorithms.
