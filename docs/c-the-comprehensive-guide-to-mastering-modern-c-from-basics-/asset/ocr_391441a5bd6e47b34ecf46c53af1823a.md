# 4.1.6 Variables

A variable is the name for a memory area that can hold a value. Yes, in C++ a variable must always have a type. When you use a variable for the first time, you must tell the compiler its type. The type accompanies the variable as long as it lives and can no longer be changed.

In the program I use two variables: value represents the number whose divisor I output, divisor is the number with which I check whether a division can be performed without remainder. First I define value. From this point on, I can use value, which is also done immediately for the output:

```
int value = 100; // Variable with
initial value
std::cout << "Divider of " << value << " are:\n"; // Output of text
```

Because value is of type int, you can only use this variable for integers—that is, use it in calculations or change it.

The other variable is divisor in the for loop:

```
for(int divisor = 1; divisor <= value; divisor = divisor+1) // Loop from
1 to 100
```
