The following function template serves as a simple recipe that you can use to convert a C++ basic data to a string or a string to a basic data type.

```
```cpp
// [https://godbolt.com/z/vcoEcYcY](https://godbolt.com/z/vcoEcYcY)
#includeinclude <sstream> // stringstream
#include <iostream>
#include <stdexcept> // invalid_argument
template <class T1, T2>
void myConvert(const T1& in, T2& out) {
    std::stringstream ss;
    ss << in;
    if(!ss.eof()) {
        throw std::invalid_argument("Error during conversion");
    }
}

int main() {
    std::string val;
    float fval=3.1415f;
    std::string sval("5.321");
    double dval=0;
    std::string doesnot("does not work");
    try {
        myConvert(fval, val);
        std::cout << val << std::endl; // Output: 3.1415
        myConvert(dval, sval);
        std::cout << dval << std::endl; // Output: 5.321
        myConvert(doesnot, dval); // triggers "Error during conversion"
    } catch(const std::invalid_argument& e) {
        std::cout << e.what() << std::endl;
    }

    return 0;
}
```

**Listing 27.27** Type conversion using "stringstream".

The main focus in this example is on the myConvert function template. This should convert values of type T1 to type T2. For this, I simply send the data with << into the string stream ss and then retrieve it with >>.
