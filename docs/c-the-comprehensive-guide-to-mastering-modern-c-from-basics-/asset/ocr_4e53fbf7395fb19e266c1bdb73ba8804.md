You will see that the standard library does not work with overlaps of this kind. Instead, you use span, input_range, or view to pass the elements to be output:

```
void show(span<const int> arg);                    // for vector<int> and
array<int, _>
void show(span<const Student> arg);         // for vector/array<Student>
void show(ranges::input_range auto&& arg); // for all Views and Containers
```

You can also pass a pair of iterators that represent the beginning and end of the elements, with the availability of span and the various types of ranges, this has become uncommon.

With iterators, it looks as follows, with an abbreviated function template using auto and the input_iterator concept—both available from C++20:

```
void show(input_iterator auto begin, input_iterator auto end);
```

Without C++20 features, you make the template<int> and without concepts:

```
template<typename IT>
void show(IT begin, IT end);
```
