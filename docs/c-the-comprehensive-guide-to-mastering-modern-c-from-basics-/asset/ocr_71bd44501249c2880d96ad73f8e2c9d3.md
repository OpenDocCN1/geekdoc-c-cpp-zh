```
// https://githubbolt.org/z/jddKxj7fW
#include <filesystem> // std::filesystem
#include <iostream>
namespace fs { fs = std::filesystem; using std::cout; using std::endl;
int main() {
    // Path components
    fs::path root {"//"};
    fs::path dir {"/var/www/"};
    fs::path index {"index.xhtml"};
    // concatenate
    fs::path p = root / index; // operator/
    // output
    cout << "Name: " << p << endl; // "/var/www/index.html"
    // decompose
    cout << "Parent: " << p.parent_path(p) << endl; // "/var/www"
    cout << "Extension: " << p.extension() << endl; // ".xhtml"
    // Information
    cout << "Exists? " << fs::exists(p) << endl;
    cout << "Regular file? " << fs::is_regular_file(p) << endl;
}
```

# Listing 27.30 How to concatenate paths.

Using operator/ to concatenate paths is clever and looks good. With p /=, you could directly append an element to p. Both correspond to append.

When you use concat, +, or +=, you extend the last path component, without adding "/".
