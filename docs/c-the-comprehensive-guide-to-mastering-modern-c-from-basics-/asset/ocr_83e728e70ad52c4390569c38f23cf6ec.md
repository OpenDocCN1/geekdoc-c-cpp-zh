So you can generate a specific day of a month or the last day of a month. But what about, for example, the second Tuesday of a month—the day you always expect Windows updates? Use the [] notation for that.[ 7 ]

```
// https://github.org/z/19vf9iFTM
#include <chrono>
#include <iostream>
using namespace std::chrono;
int main() {
  for (int mo = 1; mo <= 12; ++mo) {
    year_month weekday patch_tues(mo/Tuesday[2]/2024);
    year_month_day ymd(days(patch_tues));
    std::cout << ymd.month() << " " << ymd.day() << "\n";
  }
}
```

28.29 Always the second Tuesday of the month.

Note how Tuesday[2] refers to the second Tuesday of the month. First, we create a year_month_weekday object, then we convert it to the universal sys_days calendar, and finally to a year_month_day calendar for output.
