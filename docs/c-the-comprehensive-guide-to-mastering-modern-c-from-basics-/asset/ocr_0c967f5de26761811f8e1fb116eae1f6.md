### Awaiter and Awaitable
The suspend and types are so-called awaitables. They are the simplest possible
awaitables and are provided by the library. These are
classes where the compiler expects you to
implement the methods await_ready(),
await_suspend(), and await resume(). Normally, you
don't have to do this. With awaiters, you also get
values back into the coroutine.

Because we don't return any values with co_yield or
co_return, we define the method return_void() in the
promise_type. If we were dealing with values, a different
method would be here. For example, if we used co_yield
54, it would be auto yield_value(int), and for co_return 73L,
it would be auto return_value(long).
