```
cout << year; // Output: 2025
```

It is also useful to be able to check in an if statement whether two years are equal. and if you can no longer rely on the int value via value(), then you need a method for that:

```
bool Year::equals(const Year& other);
// allows:
Year year(2024);
if(year.equals(Year(2020).advance(Year(4)))) {
    // do something
}
```

In this example, you can see why you need operations on your own data type, which internal values are encapsulated. For the mentioned functions, it would look like the following listing for Year.

```
// https://godbolt.org/z/EPz4Kd6jP
class Year {
    int value;
public:
    explicit Year(int v) : value(v){}
    std::ostream& print(std::ostream& os) const;
    Year& advance(const Year& other) const;
    bool equals(const Year& other) const;
    bool lessthan(const Year& other) const;
};

std::ostream& operator<<(std::ostream& os, const Year& year) const {
    return year.print(os);
}

Year& Year::advance(const Year& other) {
    value += other.value;
    return *this;
}

bool Year::equals(const Year& other) const {
    return value == other.value;
}
```
