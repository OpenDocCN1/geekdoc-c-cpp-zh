# Old Equal Sign or Standardized Initialization?

The new initialization with {...} is supported by all
current compilers. So you have a choice. The “old
style” cannot be eradicated (and it is debatable
whether this would make sense), but you should use
the new style wherever you are not just initializing a
native data type such as int. This will equip you for
the tricky cases.

4.2.11 Initialize with “auto” initialization. It
always always consists of

+   - the type of variable you are initializing,
-* the name of the variable, and
-* an expression for the first value of the variable.
