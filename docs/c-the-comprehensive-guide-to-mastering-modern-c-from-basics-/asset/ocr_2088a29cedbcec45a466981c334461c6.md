The #define OUT::cout introduces the new name OUT to the preprocessor. This time, it is not just a pure introduction of a name, but with std::cout, the replacement text std::cout is desired. From now on, the preprocessor will replace every occurrence of the token OUT with std::cout. The preprocessor has similar word separation rules as C++, so SHOUT naturally does not become Hstd::cout—but std::OUT does become std::std::cout. The preprocessor does not recognize the scope resolution operator ::.
