# 15.1.1 Has-a Composition

When you learned about using struct and class in Chapter 12, I initially bundled data fields into aggregates.

```
class Car {
Windscreen windscreen_
std::vector<Wheel> wheels_;
//
};
```

This Car has-a windscreen_ as well as wheels—each of the corresponding type. In this case, a has-relationship, Car is ever composed of these objects or consists of these objects. This is a composition. That means that the object usually owns its components—which in C++ means that it is responsible for their construction and destruction. The lifetime of the components is limited by the lifetime of the object.
