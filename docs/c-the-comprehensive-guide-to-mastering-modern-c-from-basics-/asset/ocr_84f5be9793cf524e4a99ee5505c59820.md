The compiler then turns this into a sequence of actual parameters at the moment of concrete use.

The important thing here is that first no longer appears. As you can see, it is a recursive call to output. Without first, the list of parameters is one shorter. The list is recursively shortened until there is only a single arbitrary parameter, because the nonvariadic template fits. Its call ends the recursion.

Specifically, this means that the variadic call leads to a chain of the following calls:

```
// Call:
output(std::cout, "end", 2, 3.14, 'A', false);
// 1st Pass:
output(std::cout, "end");
output(std::cout, 2, 3.14, 'A', false);
// 2nd Pass
output(std::cout, 2);
output(std::cout, 3.14, 'A', false);
// 3rd Pass
output(std::cout, 3.14);
output(std::cout, 'A', false);
// 4th Pass
output(std::cout, 'A');
output(std::cout, false);
```
