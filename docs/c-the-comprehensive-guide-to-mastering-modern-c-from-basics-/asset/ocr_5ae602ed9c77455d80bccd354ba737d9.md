That means that for ct1, the constructor was fully executed. The object was fully created, and ct1 is available to the program until the end of the block.

For ct2, the constructor was started but exited with an exception. Thus, ct2 is considered not created.
Therefore, you do not see a more than CanThrow, such as initializing some data fields, then all objects created up to the exception will be cleaned up as if their scope exited (so not use new together with raw pointers here).

```
class Mega {
    std::vector<int> data;
    CanThrow canThrow;
    std::map<string, int> more;
public:
    Mega()
        : data_{},
        canThrow_{666} // triggers an exception
        more_{(){}
    }
;
```
