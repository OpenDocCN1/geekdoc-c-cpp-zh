Pass the target of the output as a parameter. cout and cerr are of type std::ostream. And if you want to write to a file, then stream is also suitable for that.

```
void Person::print(std::ostream& os) {
    os << "{{ {}}} from {}", name , age_, city_);
}
```

Note that you use the type ostream&, which is a reference. You do not want to create a copy of the stream, but change its state. Outputting something to a stream is a state change.

    // automatic test:
    std::string oss{}; // writes to a string
    carl.print(oss);
