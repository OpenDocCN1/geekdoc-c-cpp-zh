# 13.3 “static” Makes Local

For exactly this purpose, you can also use the keyword static. Instead of opening an anonymous namespace, you write static before the variables and functions. You achieve the same thing: the name of the variable or function is only visible within this module. Other modules can use the same name without the compiler complaining.

The debug variable is not yet static. As a result, no other module can define a global function or global variable debug, but that is intentional here. Because although debug is not in the modul.hpp header, someone with enough insider knowledge (the author?) can manipulate the variable. Consider this excursion as it should not be part of usual programming practice to hide and change variables in this way. In some other module of the project, someone can manipulate the variable with

```
extern bool debug;
```
