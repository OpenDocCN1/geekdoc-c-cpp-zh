Note
15.1.4 Instance-of versus Is-a Relationship that
is-a relationship for car herbie; does not mean "herbie is-a car." This is called "is an instance of," or in C++, "herbie is of type car." It is almost unavoidable that the terms are not always used correctly. For example, "7 is an integer" or "7 is an int" is not precise in this context.
