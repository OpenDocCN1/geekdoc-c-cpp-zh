#include <iostream>

        result += data[i];
    }

template<typename T, size_t SZ>

    Elem result = 0;

    }

// C++20 concept function with auto
template<input_iterator It>
auto sum(It begin, It end) {
    return std::accumulate(begin, end);
}

// abbreviated function with auto
int sumauto(input_iterator auto begin, std::input_iterator auto end) {
    return std::accumulate(begin, end);
}

int main() {

    cout << sumElem(b) << '\n'; // Output: 8
    array<int, 6> c = {1, 2, 3, 4, 5, 6};
    cout << sum(c.begin(), c.end()) << '\n'; // Output: 21

## Initialize

The initialization operations for array are:

- **constructor**
When you define array<int,4> x{}, all elements are zero initialized. You can also initialize all—or some—elements according to the rules of aggregate initialization with array<int,4>{1,2,3,4} or array<int,4>{1,2}.
- **Copy constructor, move constructor**
You can copy arrays of the same size and pass and return them by value. Moving is also possible if the element type allows it.

## Assignment

You have the following operations available to modify content of an array at once:

- **Assignment operator**
You can assign new values to an array by assigning it another array with a compatible element type and the same size. operator= is therefore defined as expected.
- **Assign**
There is no assign because array also does not have a complete set of constructors.

- **Fill**
However, there is fill, which allows you to set all values of an array at once, as you can see in Listing_24.35.

## Insert and Delete

Inserting and deleting elements is not possible with array.

## Read and Write

You can read and write parts of an array in the following ways:

- **Index access**
However, you can access the elements unprotected or protected with [] and at. You get back a reference that you can read.
- **Iterators**
The iterators of array are contiguous and random-access, meaning they can move forward, backward, and can be arbitrarily positioned, similar to vector.
- **Beginning and end**
You also have front and back available, which give you references to the first and last elements of the array, respectively.
- **Tuple interface**
You can read and write an array like tuple using std::get(), as you can see in Listing_24.36.
- **Span**
Since C++20, array can work wonderfully with span, just like vector. From C++23 onward, you also have `std::span`.
- **C interface**
Because the elements of an array are contiguous like those of a vector, data() to get a pointer to the first element and handle it like a C-pointer. With slight modifications, Listing_24.25 also works.
- **Fill**
Specifically for array, fill which allows all elements simultaneously.
```cpp
// https://cppreference.org/cpp/array/fill
array<int, 3> data={1, 6, 3};
data.fill(8); // now all are 8
```
Listing 24.35 "fill" writes all values at once.

## Specialties: Tuple Interface

From an array, you can not access elements with the usual methods, but you can also use array like tuple. A detailed description of tuple follows in Chapter 28. For this, there is an overload of std::get<size_t>(std::array<...>).
```cpp
// https://godbolt.org/z/KrbTrAg
array<int,5> data = {10, 11, 12, 14};
cout << get<2>(data) << "\n";
```
Listing 24.36 "array" supports "get" from "tuple".

As with tuples, the index must be constexpr as a template argument to get. There is more similarity to tuple, as size_t templates are also declared for array you need them for metaprogramming. One of the most practical things is undoubtedly that you can bind the elements of an array like structured variables.
```cpp
// https://godbolt.org/p/j6nrWfm
#include <array>
#include <iostream>
int main() {
    std::array<int, 2> ports = {80, 443};
    auto [ht, htt] = ports; // declares variables and binds them
    auto [const& rht, int& rhts] = ports; // Reference and const are possible
    std::cout << ht << "\n";
    std::cout << rht << " " << rhts << "\n";
}
```
Listing 24.37 array supports structured binding. Here, int ht and int htt are defined and initialized with the values 80 and 443. For rht and rhts, you can see that references to the array also work—here, const& rht.

## Specialties: Comparisons

You can compare two arrays of the same type with all comparison operators: <, == and so on. You get a lexicographical result. For arrays, operator<=> is defined, from which all comparisons are derived. The operator behaves as if the free function lexicographical_compare from the <algorithm> header is called. Here, <=> or < is used, depending on the availability for the element type. Instead of operator<=, all comparison operators for containers were overloaded in C++20. In both cases, this means that the first elements of both arrays are compared first, and if they are not equal, the result is determined. if they are equal, the second element is compared in the same way, and so on. If all elements are equal, then the two arrays are also equal.
```cpp
// https://godbolt.org/z/IEarsMT
// intentionally arranging a&b as arguments
void all(const std::array<int, 3>& a, const std::array<int, 3>& b) {
    std::cout << a << " compared with " << b << " is " << std::endl;
    if (a < b) std::cout << "<, \n";
    if (a > b) std::cout << ">, \n";
    if (a == b) std::cout << "==, \n";
    if (a != b) std::cout << "!=, \n";
    std::cout << "\n";
}

int main() {
    std::array<int, 3> a = {10,10,10};
    std::array<int, 3> b = {20,5,5};
    std::array<int, 3> c = {10,5,21};
    std::cout << (a < b ? "smaller\n" : "smaller") // "smaller", because 10 < 20
    std::cout << (a < c ? "not smaller\n" : "not smaller") // "not smaller", because
    std::cout << (a == c ? "equal\n" : "equal") // "equal", because all are 10
    for(auto x : {a,b,c}) {
        for(auto y : x) {
            all(x,y);
        }
    }
}
```
