It looks like this for two expressions:

( Expression-1 , Expression-2 )

The compiler first calculates Expression-1 and then Expression-2. The result of the first expression is dissipated so that the total expression receives the value and type of the second expression.

```
// https://godbolt.org/r/ga6cWr3d
int main() {

        for(int w2 = w1; w2 < 10; ++w2) { // 0..9
            int max = w1 > w2 ? (a+=b-=1, w2) : // sequence
                operator;
        }
    }
}
```

**Listing 4.26** You can concatenate several expressions with commas in brackets.

If w1 > w2, the expression (a+=b, w1) is evaluated. Although w1 is returned as the result for max, the expression a+=b executed first. In the case of w <= w2, the term w2 from (b+=1, w2) is assigned to the variable max after b+=1 has been evaluated.
