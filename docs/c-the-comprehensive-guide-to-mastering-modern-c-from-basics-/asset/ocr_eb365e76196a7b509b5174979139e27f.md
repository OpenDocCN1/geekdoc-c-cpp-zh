As the program is set in main(), 10 asteroids are
generated as targets on the game board. Each starts
ten ten “structure” points; when these reach zero, the
asteroid is destroyed. The last line of Ship::fireUpon(
checks this. This method is called by the main method
of the GameBoard::shipFires() minigame. Because the
game board manages the asteroids as data fields, it is
responsible for removing a destroyed asteroid from the
“universe.”. This happens after the line with
ship_.fireUpon(): the method reports with the
return value whether the asteroid was destroyed. If that
is the case, the ship gets points, and the hit rock is
removed from the vector with asteroids_.erase().

Which of the available asteroids the ship shoots at
determined by a die roll. For this, there is the rollDice()
helper function. With the two min and max parameters,
y specify how many sides the die should have and
what the smallest rolled number is. The die itself is
done using std::uniform_int_distribution<int>{min, max}
