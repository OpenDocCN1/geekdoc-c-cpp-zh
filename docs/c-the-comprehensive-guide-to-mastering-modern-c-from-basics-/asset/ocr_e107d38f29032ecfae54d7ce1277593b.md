At "Done", millisSince determines the time in
milliseconds required to build the data structure. I chose
the number 100*1000*1000 (i.e., 100 million) so that my
computer can just handle it:

+   - Building it takes my computer about 52,000
milliseconds with nine gigabytes of memory.[[ 51 ]

+   - Tearing it down takes 6,700 milliseconds.

It's not really much—but on other computers and
different conditions, it might take more time. Whether
you need this time-saving feature when exiting is up to
you. However, do not let the program design suffer
because of it.

In the millisSince() helper function, I use steady_clock
from <chrono> for precise measurement.
