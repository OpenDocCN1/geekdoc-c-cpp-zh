# 13.7 “static” Makes Permanent

Similar, but not the same, is the use of static with local variables—that is, within a function. When you add static to the declaration of a local variable, this variable persists when the program leaves the scope and is reused when it is entered again.

```
// https://ggbolt.org/z/h5qond6db
#include <iostream> // cout
class Keyboard {
    Keyboard(Keyboard&) = delete; // no copy
    const size_t nr_; // current number
public:
    static inline size_t count = 0; // counts created instances
    explicit Keyboard() : nr_(count++) {
        std::cout << "Keyboard(j).nr:" << nr_ << "\n";
    }
};

Keyboard& getKeyboard() {
    static Keyboard keyboard();// static local variable
    return keyboard;
}

void func() {
    std::cout << "kbFunc...\n";
    Keyboard& kbFunc = getKeyboard();
}

int main() {
    std::cout << "kbA...\n";
    Keyboard& kbA = getKeyboard();
    func();
    std::cout << "kbB...\n";
    Keyboard& kbB = getKeyboard();
    std::cout << "count:" << Keyboard::count_ << "\n";
}
```

+   **Listing 13.5** A static variable is initialized once and reused thereafter.
