# How matter you you insert, iterators pointing to the map retain your validity.

# Inserting a Single Element with Automatic Positioning

In map, a single element consists of a pair of key and target. You then specify this as a parameter. As with set, insert and emplace do not overwrite in this case.

```
// https://godbolt.org/z/YlebrxbT
map<int,string> pl2zip;
pl2zip.insert(std::make_pair(94103, "San Francisco"));
pl2zip.emplace(10001, "New York");
cout << pl2zip; // Output: 10001:New York 94103:San Francisco
map<string,int> dwarves;
pl2zip.emplace("New York", 10001);
pl2zip.emplace("New York", 10002); // does not overwrite
cout << pl2zip; // Output: New York:10001
```

+   **Listing 24.63** You specify a new element as a pair.

# Automatic Insertion and Overwriting

With operator[], you can search for a key. The return value is a reference to the target. If there is no entry for the key yet, it will be newly created. A new target is then created with default constructor Target(). If [] appears on the left side of an assignment, you can immediately overwrite the newly created target with a new target.

```
// https://godbolt.org/z/7h3vsWYG
map<string,int> dwarves;
dwarves.emplace("Fii", 2859);
cout << dwarves["Fii"] << "\n"; // Output: 2859
cout << dwarves["Dori"] << "\n"; // newly created. Output: 0
dwarves["Kii"] = 2846;     // newly created and immediately overwritten
cout << dwarves["Kii"] << "\n"; // Output: 2846
cout << dwarves; // Output: Dori:0 Fii:2859 Kii:2846
```

+   **Listing 24.64** Automatically create and immediately overwrite with "operator[]".
