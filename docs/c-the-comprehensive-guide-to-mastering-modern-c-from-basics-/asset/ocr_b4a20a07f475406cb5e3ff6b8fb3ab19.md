# 18.4.2 Caution with Pointer Type Conversions

there is a surprise you need to be prepared for dealing with multiple inheritance: the value of a pointer to an object you can change when casting.

```
// https://godbolt.org/z/oc7jsbrEK
#include <iostream>
using namespace std;
struct Basel {
    virtual void f1() {}
};
struct Base2 {
    virtual void f2() {}
};
struct Derived : public Basel, public Base2 {
    virtual void g() {}
};
void compare(void* a, void* b) {
    cout << (a==b) ? "identical\n" : "different\n";
}
int main() {
    Derived d;
    auto *pd = &d;
    cout << pd << '\n'; // for example 0x1000
    auto *pb1 = static_cast<Basel*>(pd);
    cout << pb1 << '\n'; // still 0x1000
    auto *pb2 = static_cast<Base2*>(pd);
    cout << pb2 << '\n'; // now 0x1008!
    cout << (pd==pb1) ? "same\n" : "different\n"; // Output: same
    cout << (pd==pb2) ? "same\n" : "different\n"; // Output: same
    compare(pb1, pd); // Output: identical
    compare(pb2, pd); // Output: different
}
```

**Listing 18.16** With multiple inheritance, the value of a pointer change.
