+   Enables locale-dependent formatting for numbers and Booleans.

+   type Switches the output to a specific type: d for integers, f for floating-point numbers, and so on.


To use instances of your own class as an argument for format, you need to specialize the class std::formatter<> for your class. This class must then provide two methods with the correct signature:

+   Parse Evaluates format attributes and returns an iterator to the first character after the parsed format attributes.

+   Format Writes the formatted output of the argument to the output and returns the iterator to the end of the output.

The class must also have a default constructor and must be copyable as well assignable.
