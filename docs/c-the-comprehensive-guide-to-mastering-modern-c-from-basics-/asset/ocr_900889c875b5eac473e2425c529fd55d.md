# 20.2 Pointer

The exciting thing now is that with *pValue you have an alternative way to access the value in value. When you apply the unary dereference operator * to pValue, it points to the memory with the 42. If you write something there, you also change the value of value. With *pValue, you have an alias for value:

```
*pValue = 18;
cout << "\n"; // Output: 18
```

If I may stick with the image of the street and the houses, the following happens: With pValue you go to its house (Oxab02), look inside, and find the address Oxab04. With the dereference operator * you follow the arrow and arrive at the house of value. The assignment = 18 writes the new value to the location in memory—that is, at value.

This is not much different from what you could have done with references:

```
// https://godbot.org/z/4536hxvEK
int value = 42;
int& valueRef = value; // Reference; no address operator & needed
// no dereference operator * needed
valueRef = 18;
cout << "\n"; // Output: 18
```

Here, the address & dereference operator * are omitted because the valueRef name itself is an alias for the original variable value.
