# Access via Spans

An extension—that is, span—serves as access to a vector (or an array). The previous section provided an overview of this. The span class since C++20 is so useful that I would like to go into more detail about it in this separate section.

A typical use case is that you want to pass a container to a parameter to a function. Without span, it would look like this:

```
// very specific parameter type
void func(vector<int>& v);
```

But that unnecessarily restricts to a specific container and the range of the entire container. To make parameters iterators and remove the restrictions on the range:

```
// general
void func(vector<int>::iterator b, vector<int>::iterator e);
```

Or with C++20 concepts to avoid unnecessary coupling with vector:

```cpp
// C++20 concept
void func(contiguous_iterator b, contiguous_iterator e);
```

Now there are two parameters, which is error-prone and not nice. With span, the two parameters are now combined into one:

```cpp
// C++20: span
void func(span<int> area);
```

The span thus combines two iterators into a single entity. Besides the fact that fewer entities are always better for the programmer, protects against some errors. Isn't that neat! The next listing shows how you use it.

```
// https://godbolt.org/z/ba4
#include <vector>
#include <span>
#include <iostream>
using namespace std;
int sum(span<int> area) { // C++20: span
  int sum = 0;
  for(auto e : range) { // algorithm would be better
    sum += e;
  }
  return sum;
}

int main() {
  vector<int> vec; // implicit container to span
  cout << sum(vec) << "\n";
  auto [b, e] = make_pair(vec.begin(), vec.end());
  cout << sum(b, e-1) << "\n"; // 1..4 (Iter, size)
  cout << sum(b+1, e-1) << "\n"; // 2..5 (Iter, size)
  cout << sum(b, e-2) << "\n"; // 1..3 (Iter, Iter)
  cout << sum(b+1, e) << "\n"; // 2..4 (Iter, Iter)
  cout << sum(b+2, e) << "\n"; // 3..5 (Iter, Iter)
  return 0;
}
```

**Listing 24.26** How to use span. Here use several ways to create a span:

- Implicit from a container, like it is passed as a parameter
- Explicitly from an iterator or a size
- Explicitly from two iterators

Note that the std::span<int> parameter is not passed by reference, but by value, because it is just a small object.

Other ways to create a span include from a C-array, from a range, and of course another span. But it is also the useful way: say you have a C++ object and want to pass it to a C API. In the earlier Listing 24.24 with fwrite, it looked like this:

```cpp
auto write(span<int> what, FILE* where) { // C++20: span
    return fwrite(what.data(), sizeof(int), what.size(), where);
}
```

A span has an optional template argument that specifies the size of the span at compile time. If you omit it, span is dynamic as shown in Listing 24.26. You cannot change the size of the extent directly, but only in relation to the underlying content:

```cpp
span sp(vec.data(), 3); // the first three elements
sp = span(vec.end(), vec.end()); // Assignment, now the last five elements
```

You created fixed-size extents, for example, in the next listing:

```cpp
//://godbolt.org/z/aqr
int arr[] = {1, 2, 3, 4, 5}; // directly from a C-array
span<int> arr2 = {1, 2, 3, 4, 5};
span span2(arr); // directly from a std::array
vector vec = {1, 2, 3, 4, 5}; // with 'Extent' from a std::vector

```

# Listing 24.27 These are spans when you want to take advantage of the compiler

You can use fixed-size spans when you want to take advantage of the compiler performing certain size checks at compile time for you:

```cpp
std::array arr{1, 2, 3, 4, 5, 6}; // size 6
std::span<int, 3> sp3(vec); // size 3
sp3 = arr; // does not compile
```

The as_bytes(span) and as_writable_bytes(span) functions are also very exciting. With these you can convert a span into span<const byte> or span<writable_byte>. You could also use these here for fwrite() or even change the underlying memory location.

An example of how you can write back into the underlying container through an extension is shown in the next listing.

```cpp
// https://github.com/bolt/org/6Er5do2G
#include <vector>
#include <span>
#include <iostream>
using namespace std;
void inc(span<int> span) {
    for(auto& e : span) { // Reference
        e += 1;
    }
}
int main() {
    vector<int> data={1,2,3,4,5};
    span<int> span(data);
    inc(span.first(3)); // -> 2,3,4
    inc(span.last(3)); // -> 3,4,5
    inc(span.last(4).first(3)); // -> 4,6,6
    inc(span.subspan(first(3))); // -> 5,7,7
    for(auto i:span) cout << i << " "; // Output: 2 5 7 7 6
    return 0;
}
```

# Listing 24.28

Here, inc() writes through the span into the container. In addition, you see other ways to create a span with first, last, and subspan.

span also offers the begin() and end() container methods as well as front() and back() and operator().

# Dangerous Uses of "span":

You must be careful, with all references, that the underlying data is not destroyed while you are using span. Be particularly careful when dealing with temp-values:

```cpp

sp_m = create_data(); // This also references a temp-value
for(auto e : create_data().last(3)) { // e references a temp-value
auto data = create_data();
span ref = data(data); // okay, data is not a temp-value
data.push_back(4); // may trigger a reallocation
cout << ref[0] << " "; // possibly invalid access
```
