**Listing 23.9** Pass your own algorithm ranges as arguments, not the container.

With `auto&&` ` as the second parameter, you have defined a template. Before C++17, you had to put template<typename T> before the function and then T&& for the parameter—as described in the previous section. The && ensures that you can pass both values directly from variables and temp-values from expressions. Before auto is the `ranges::input_range` concept. It works without it, but you tell the compiler and the user of the function a lot when you write it. In particular, the compiler's error messages will be better. You can find more about ranges as parameters in Chapter 25, Section 25.6, under the subheading “Ranges as Parameters (and More).
