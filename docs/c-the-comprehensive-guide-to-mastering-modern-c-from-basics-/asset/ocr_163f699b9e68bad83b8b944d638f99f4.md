# 24.6.2 Methods of Sequence Containers

In this section, cont or c stands for one of the types like vector<int> or array<Hob,4>. Here, cont stands for an instance of a container, as in list<double> cont;. For element type, use Ele or E, and for iterator types, I abbreviate with It. Rg stands for a range.

To save space and increase clarity, I am not always precise or detailed with the function signatures here. If I do not include the parentheses with method, there are usually multiple overloads:

+   * Constructors: C(), C(size_t), C(size_t, E), C(It, It), C(from_range, rg) The default constructor creates an empty container. With cont(size_t), you can create a container of a predetermined size filled with default elements, as vector<int>(5), which creates a vector with five times. If you do not like the default value, specify your own: vector<double>(5,42) will contain the value 42 five times, for example. With a pair of iterators from any other container, you can copy its contents. Since C++23, you can also use the from_range to initialize a range. You can specify an initializer list that your container should contain at the beginning. Exception: You always create an array using an initializer list.

+   * Copy and Move: C(const C&), C operator=(const C&), assign, assign_range, C(C&&), C operator=(C&&), swap You can pass a different Const as an argument to the copy and move constructors and operators. There is an assign method in several variants to reinitialize the container similarly to one of the constructors, with assign_range() existing since C++23. All containers implement swap(Cont& other) efficiently (in constant time, independent of the number of elements), which allows for great performance tricks when used skillfully;; swap takes linear time for array.

+   * Destructor: ~Cont() All containers have destructors that remove the contained elements. Note that this does not apply if you pack pointers into containers. Use smart pointers for, or managing the dynamic objects elements. The destructors do not implicitly throw exceptions.[57]

+   * Iterate forward: begin(), end() and backward: rbegin(), rend() Get an iterator with begin() that points to the first element, and with end() one points the last element; you can use these iterators for a loop to iterate forward. For the backward loop, use rbegin(), which points to the last element, and rend(), which points the first element. In sequence containers, you always iterate over the elements in the order in which you inserted them or where you inserted them. All methods return a Cont::iterator or Cont::const_iterator also come in variants
