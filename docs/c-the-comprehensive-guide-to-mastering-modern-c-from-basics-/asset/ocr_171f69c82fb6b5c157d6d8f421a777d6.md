Functions other than main could return any other types.

The value returned by main is determined by the first return that the computer encounters when running the program. Here, this will always be return 0. The return value is therefore always 0.

Depending on the operating system, the return value can be evaluated. If your program is to be able to receive arguments on the command line, the round brackets for the parameters would not be empty. You will later see what you need to do for this.
