In addition, I worked here without the practical BOOST_AUTO_TEST_CASE macro, which takes care of assembling the main test suite. This time I wanted to have all tests as methods of a separate test class. However, with Boost, this means you have to manually add the individual methods to a suite. I take the opportunity to demonstrate this to you here because this is exactly the way to build large and potentially nested suites.
