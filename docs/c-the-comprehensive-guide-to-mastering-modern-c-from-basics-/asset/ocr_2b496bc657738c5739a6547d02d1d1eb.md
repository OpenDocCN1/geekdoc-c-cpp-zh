# Parameter by Move

Instead of a copy or reference, assume you have a
resource that you cannot or not want to copy, but
you can move—for example, a unique_ptr (copying
forbidden) or an Image you painted (copying expensive).
In case, you use std::move, and the source object is
empty after starting the thread.

```
// https://godbolt.org/Pjqzsv9nz
// ... includes
#include <thread>
using namespace std::chrono; // seconds, suffix
struct Image {
    std::vector<char> data; // Copying expensive
    explicit Image() : data(1'000'000) {}
}
void show(Image img) {
    std::cout << img.data.size() << '\\n';
}
void showIptr(std::unique_ptr<int> ptr) {
    std::cout << *ptr << '\\n';
}
int main() {
    // expensive to copy, but good to move:
    Image image;
    std::cout << image.data.size() << std::endl; // Output: 1000000
    std::thread th1(show, std::move(image)); // Output: 1000000
    th1::sleep_for(1s);
    std::cout << image.data.size() << std::endl; // Output: 0
    th1.join(); // explicitly wait until the thread is done
    // impossible to copy, but good to move:
    auto ptr = std::make_unique<int>(57);
```
