# 21.1 The Preprocessor

Preprocessor directives always begin with the hash # at the start of a line. The entire line is then an instruction for the preprocessor to evaluate. You can add a comment with // or /* /. A line ending with a backslash \ (without a space after it) continues on the next line if the line break were not there.

```
// https://godbolt.org/z/j6WxPheP
// Filename: my-macros.hpp
#ifndef MY_MACROS_HPP // Include Guard
#define MY_MACROS_HPP
#include <iostream> // cout, cerr
#include <vector>

#ifdef OUTPUT_TO_STANDARD
#define OUT std::cout
#else
#define OUT std::cerr
#endif
```

```
#define MESSAGE(text) { (OUT) text << "\n"; }
using container_type = std::vector<int>;nstatic constexpr unsigned SIZE = 10;
#endif
```

**Listing 21.1** Lines containing preprocessor directives start with a #. 

You can now include this header. For example, the next listing showing your main file with main looks.

```
// https://godbolt.org/z/feGrM4f6j
// Filename: makros.cpp
#define OUTPUT_TO_STANDARD // Switch between cerr and cout
#include "my-macros.hpp"
#include "my-macros.hpp" // Oops, accidentally twice.
int main() {
    MESSAGE("Program start");
    container_type data(SIZE);
    MESSAGE("The container has " << data.size() << " elements.");
    MESSAGE("Program end");
}
```
