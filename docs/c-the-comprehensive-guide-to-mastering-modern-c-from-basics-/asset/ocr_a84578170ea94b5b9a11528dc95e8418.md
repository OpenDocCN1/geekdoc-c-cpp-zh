# However, as it is 2.5.2 Automate with Makefile tedious to call the compiler again and in this way,

it is best to create a Makefile in which the necessary commands are listed. To do this, create the following Makefile file:

```
emacs Makefile &
```

The content of the file is then simple:

```
# -*- Makefile -*
all: modern101.x
modern101.x: modern101.cpp
[Tab] g++ modern101.cpp -o modern101.x
# clean up:
clean:
[Tab] rm -f *.x *.o
```
