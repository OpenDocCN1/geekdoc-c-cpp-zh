unique_ptr<index_impl> pimpl? So far, we have only declared it as a forward declaration. Therefore, the compiler can only help us here if we let it generate the code in the qwort.cpp file—especially for the constructor, destructor, and move constructor. You will see how this works shortly. We can simply let the compiler generate the other three here with = default. However, we must list them here, because according to C+ rules, they would otherwise be completely missing as we have defined at least one other member of the “big five” family.
