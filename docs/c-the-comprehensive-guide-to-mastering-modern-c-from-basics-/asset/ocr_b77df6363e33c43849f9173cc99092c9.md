This is where a pointer * comes into play, because a function type actually represents a pointer. You can find out more about these two different notations in Chapter 23. For now, you should understand that there is a representation of the type of of functions and that this type depends on the parameter types and the return type.

You will see later that this is important because you can store functions in C++ just like int and string values in variables, pass them as parameters, or return them from functions.
