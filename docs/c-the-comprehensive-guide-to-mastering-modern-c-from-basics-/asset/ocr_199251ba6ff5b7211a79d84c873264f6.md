However, only a few people can do this in their heads. I myself calculate smaller numbers in head the other way round: starting from the top, I subtract the powers of 2—32, 16, 8, 4, 2, and 1—until I reach zero. In $_{10}25$, 16 fits, then 8, then 1, which results in binary $2^{11001}$.

The computer often calculates with 32 bits for an *int*. It therefore fills the front with 0s—that is, $2^{00000000 00000000 00000001 10011100$ for $_{10}412$.

# Negative Integers and the Two's Complement

For signed integers, such as *int*, which is implicitly signed *int*, the most significant bit represents the sign; 0 stands for a positive number and 1 for a negative number.

If the sign is positive, the remaining bits contain the value of the number as usual. However, if it is negative, the interpretation of the value bits changes. The computer stores this in the *two's* complement. To convert the bit representation of a negative number into a decimal number, proceed as follows:

+   * Invert all value bits.
* Convert this to a decimal number as usual.
* Add one.
* Set the negative sign.
