
```cpp
cout << lets; // Output: a:4 b:2 c:3
struct comp { // Functor
    bool operator()(char a, char b) const { return toupper(a) < toupper(b); }
};
map<char,int,Comp> lets2; // here the template parameter is sufficient
```

**Listing 24.61** You can also provide a custom comparison function for a "map".

When you define a functor—that is, a class with an operator()—it is sufficient to specify this class as a template parameter. When creating the map, an instance of the functor is then created using its default constructor. With a lambda, you already have an instance that is callable.

## Initialize

As a template parameter for map, you specify the types for Key and 
Target—for example:

```cpp
map<int,string> // int as Key, string as Target
map<Person,size_t> // Person to age
map<unsigned,unsigned> // Key and target types can also be the same
map<int,shared_ptr<Image>> // a pointer as the target
```

Optionally, you can specify the types of Key (previous section) as well
as an allocator. If you specify one, you can provide the usual constructor arguments. The following variants are commonly used for initialization:

- Default constructor creates an empty container
- Iterator copies a range from another container
- Initializer list initializes with explicit values
- C++23 from_range

For filling via an initializer list, you must consider that each element consists of a pair. Fortunately, pairs can also be created by initializer list, so the construct still looks compact, as shown in Listing 24.62.

```cpp
// https://cppreference.com/cpp/language/literals
using std::pair;
namespace {
    constexpr pair<char, char> operator ""(const char* s, size_t len) {
        return len==2 ? make_pair(s[0], s[1]) : make_pair(' ');
    }
}
struct O {
    char a;
    int n;
    O(char a, int n) : a(a), n(n) {}
    operator pair<const char, int>() const { return make_pair(a, n); }
};
// explicit pairs:
map<int, int> nums = {pair<int>(6), make_pair(7,8)};
map<int, int> nums2 = {pair<int>(1,6), make_pair(5,7)};
// implicit pairs from initializer lists:
map<int, char> num = {{1,'a'}, {2,'b'}, {3,'c'};
map<int, int> nums3 = {{7,2}, {9,4}};
using namespace;
map<char, char> cmap = {"ab", "cd"}; // custom literal
cout << cmap; // Output: a:b c:d
map<char,int> qmap = {('a',1), ('b',2), ('c',3)}; // implicit conversions
cout << qmap; // Output: a:1 b:2 c:3
```

**Listing 24.62** The initializer list must contain "pair" elements.

As you can see in code of qmap, the elements of the initializer list can be implicitly converted to pair<const Key,Target>. This is quite useful for compact notation.

## Assignment

Similar to set, you can initialize a map with operator=. There are overloads for copy, and an assign or assign_range method is also not available in map, but like all other containers, there is swap.

## Insert

Just like with a set, you can add elements with insert, emplace, emplace hint, and from C++23 with insert_range. There are also operator[] and insert_assign, which may also insert new elements under certain circumstances. How matter you insert, iterators pointing to the map retain your validity.

### Inserting a Single Element with Automatic Positioning

In map, a single element consists of a pair of key and target. You then specify this as a parameter. As with set, insert and emplace do not overwrite in this case.

```cpp
// https://godbolt.org/z/YlebrxbT
map<int,string> pl2zip;
pl2zip.insert(std::make_pair(94103, "San Francisco"));
pl2zip.emplace(10001, "New York");
cout << pl2zip; // Output: 10001:New York 94103:San Francisco
map<string,int> dwarves;
pl2zip.emplace("New York", 10001);
pl2zip.emplace("New York", 10002); // does not overwrite
cout << pl2zip; // Output: New York:10001
```

**Listing 24.63** You specify a new element as a pair.

### Automatic Insertion and Overwriting

With operator[], you can search for a key. The return value is a reference to the target. If there is no entry for the key yet, it will be newly created. A new target is then created with default constructor Target(). If [] appears on the left side of an assignment, you can immediately overwrite the newly created target with a new target.

```cpp
// https://godbolt.org/z/7h3vsWYG
map<string,int> dwarves;
dwarves.emplace("Fii", 2859);
cout << dwarves["Fii"] << "\n"; // Output: 2859
cout << dwarves["Dori"] << "\n"; // newly created. Output: 0
dwarves["Kii"] = 2846;     // newly created and immediately overwritten
cout << dwarves["Kii"] << "\n"; // Output: 2846
```

**Listing 24.64** You specify a new element as a pair.

## Access via Iterators

As with all ordered containers, you get bidirectional iterators with begin() and end().

```cpp
// https://godbolt.org/z16t5dobq7
map<char, int> data = {{'a', 1}, {'b', 2}, {'c', 3}};
for(auto it=data.begin(); it!=data.end(); ++it) { // backwards
    cout << it->first << " : " << it->second << "\n"; // dereference with
}
cout << '\n'; // Output: a:1 b:2 c:3
for(auto e : data) { // forwards, uses begin() and end()
    cout << e.first << " : " << e.second << "\n"; // pair, element access with
}
out << '\n'; // Output: a:1 b:2 c:3
```

**Listing 24.66** Iterators of "map" are type of "pair".

## Index-Like Access

As a special feature among associative containers, ordered or unordered, map has the operator[] and at methods, which you know from vector and array. This allows you to use a map as if it had an index. Unlike its counterparts, the index is not of type size_t, but of type Key. Therefore, the argument for operator[] and at is a value of this type. As shown in Listing 24.59 and Listing 24.64, operator[] automatically inserts elements if the key is not found. at, on the other hand, throws an out_of_range exception in such cases.
