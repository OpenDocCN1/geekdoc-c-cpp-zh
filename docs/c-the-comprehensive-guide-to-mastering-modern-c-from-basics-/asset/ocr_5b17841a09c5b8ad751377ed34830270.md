# Specialty: Size and Capacity

In **Listing 24.32**, you can see few operations for the size and capacity of a vector. Understanding these metrics is fundamental for the efficient use of vector.

```
// https://cppbolt.org/YzGkMIwaE
#include <vector>
#include <iostream>
#include <format> // C++20
using namespace std;

ostream& operator<<(ostream& os, const vector<int>& vec) {
    for(auto const& v : os) os << v << " ";
    return os;
}

int main() {
    vector<int> data; // creates an empty vector
    data.reserve(3); // Space for 3 elements
    cout << format("{}/{}\n", data.size(), data.capacity()); // 0/3
    data.push_back(11); // add an element
    data.resize(3); // Resize, it appends new elements
    data.push_back(99); // add another element
    cout << format("{}/{}\n", data.size(), data.capacity()); // 4/6
    data.push_back(33); // add another element
    cout << format("{}/{}\n", data.size(), data.capacity()); // 111, 0, 999
    data.resize(1); // nothing happens, because capacity() > 1
    cout << data << "\n";"; // shrink, elements are removed
    cout << format("{}/{}\n", data.size(), data.capacity()); // 3/6
    data.resize(44); // resize again, fill with 44s
    cout << data << "\n"; // 111, 0, 44, 44 ...
}
```

### 24.6.4 array
an array is an exception among containers in that it is the only container that cannot change its size. You determine at compile time duration of existence, it maintains that size. You cannot add elements or remove elements—only replacing elements.

Therefore, you also specify the size of this container as a template parameter within angle brackets—for example, array<int,5> for array with five elements. The array<int,5> type is different from the array<int,4> type because that is the nature of templates. Consequently, you need write a single function that can handle different array sizes as parameters. These are two overloads:

```
// https://cppbolt.org/YIWbfXn
#include <array>
void calculate(const std::array<int,4>& array) { /* ... */ }
void calculate(const std::array<int,5>& array) { /* ... */ }
```

If you don't want to write multiple overloads, you need a function template that takes the array size as a template parameter.
