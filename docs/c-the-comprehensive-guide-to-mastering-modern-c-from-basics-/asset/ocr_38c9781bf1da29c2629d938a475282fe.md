# Listing 27.29 Transferring data from the "rdbuf".

Thanks to bufptr = file.rdbuf(), you now have full control over the streambuf buffer with the streambuf pointer. First, I use seekoff and file.end to set the stream buffer pointer to the end of the buffer to obtain the size buffer size. Because I also want to read from the buffer afterward, I then set the position of the streambuf back to the beginning of the buffer with file.beg.

In a unique_ptr<char[]>, I now reserve memory for the heap in which I can store the entire contents of the buffer. With the getn() method, I copy size bytes from the stream buffer into the char array. In this way, I would have transferred the entire stream buffer into a raw char array. For demonstration purposes, I use cout.write(...) to output the contents of char[] to the console.

This time used char[] as a data buffer together with a unique_ptr. Without unique_ptr, you would have had to take care of delete[] in a larger program. This solution is here an alternative to using a vector as a buffer, as you saw in Listing 27.22.

You now know how to use the rdbuf() method to get a stream buffer (of any kind). With the returned pointer, you can now use various methods within the stream to change the position, read characters or entire blocks, and write or reset characters in the stream buffer.
