# 8.7 The “do-while” Loop

This much rarer variant of the while loop has the condition at the end:

do Statement while( Condition )

Here, the Statement is executed first and then the Condition is checked, as you can see in the flowchart Figure 8.4. The check occurs after each iteration. This means that the statement is executed at least once.

```
// https://cppbolt.org/z/6hh5KhExM
#include <iostream> // cin
#include <string>
int main() {
    std::string line;
    do {
        std::getline(std::cin, line); // execute getline at least once
        if(!std::cin) break; // error or end of file
    } while(line != "quit"); // end on specific input
}
```
