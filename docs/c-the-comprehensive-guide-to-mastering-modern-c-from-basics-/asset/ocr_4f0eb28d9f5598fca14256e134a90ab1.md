Again, τ stands for the formal data type, which the compiler replaces with the desired type during instantiation—that is, the generation of machine code. The name τ can again be any valid identifier; τ is a very common usage here. You can also use <class T> instead of <typename T>. As function templates, it makes no difference at this point what you use.

Since C++20, you can use a concept instead of typename here. This would be the shortened and preferred notation. Instead, after this line, a requirement for the type τ can also be specified with requires.

The following listing shows the definition of a complete class template.

```
// https://godbolt.org/z/jgzTMYKv
template<std::copyable T> // C++20
class MyContainer {
public:
    void setData(const T& d) { data_ = d; }
    T getData() const { return data_; }
};
```

**Listing 23.29** A class template takes a type as a formal parameter.

At the beginning, I defined a MyContainer class template, which can now almost be defined like std::vector<T>; of course, many functionalities are still missing, but this already serves as a theoretical comparison. I have sensibly restricted τ with the copyable C++20 concept. However, you can also simply write typename or class.
