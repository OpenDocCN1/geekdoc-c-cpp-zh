the multimap. This is nominally the same with map, as there is only a maximum of one key, but I particularly emphasize it for the multimap.

+   - Deleting multiple elements erase With a pair of iterators refers to multiple elements to be deleted.

The following listing demonstrates deletion—with iterators of nondeleted elements of the container retaining their validity.

```
// https://cppbolt.org/z/DvKtn4xP
multimap<char,int> vals({{'c1',1}, {'c8',8}, {'g1',1}, {'c1',1}, {'a7',7}, {'a1',1}, {'c2',2});
cout << vals; // Output: a:7 a:1 c:8 c:1 c:2 g:1
vals.erase('c'); // deletes all 'c's
cout << vals; // Output: a:7 a:1 g:1
vals.erase(vals.begin()); // deletes only one of the 'a's
out << vals; // Output: a:1 g:1
```
