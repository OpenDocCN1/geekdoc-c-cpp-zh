# 15.2 Inheritance in C++

In C++, you represent inheritance as follows:

```
class Car {  // Base or superclass
public:
    Windscreen windscreen;
    std::vector<Wheel> wheels_;
    //
};
class VwBus : public Car {  // VwBulli is a subclass
public:
    Flowers flowers_
    //
};
```

So you write the name of the base class separated by a colon : and public after the name of the current class:

class Subclass : public Baseclass { ...

Now you can happily create new VwBus instances. each of them automatically has a windscreen_ and wheels_, even though you didn't explicitly mention it in the VwBus class:

```
VwBus vww();
cout << vw.windscreen;
cout << vw.flowers_;
```

If you create a pure Car;, then car.windscreen_ will be a valid access, but in the class car, car.flowers_ does not exist.
