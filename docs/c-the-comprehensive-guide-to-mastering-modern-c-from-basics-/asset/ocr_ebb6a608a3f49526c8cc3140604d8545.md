carr is implicitly converted to an int* and is the beginning. For standard containers, you get the beginning with the begin() method or the begin(container) free function. And where there is a beginning, in this case, there is also an end: you get it with the end() method or end(container). This works for all standard containers, from list to vector and unordered_map, and so on.

```
// https://godbolt.org/z/4ngz4ed4W
#include <vector>
#include <iostream> // cut

std::vector;
int main() {
    vector<int> data={5,4,3,2,1};
    vector<int>::const_iterator end = data.end(); // or end(data)
    for(vector<int>::const_iterator it = data.begin(); it!=end; ++it) {
        std::cout << it << " ";
    }
}
```

Listing 20.14 Retrieve iterators with "begin" and "end".

You can also increment an iterator with++. The loop end check is also done with a comparison, here with it!=end. You can also access the actual value with the * dereference operator, here with *it. What pointers can do, an iterator must also be able to do. Therefore, you could also determine the number of elements with end(data)-begin(data) or distance(data),end(data)).

No sooner said that than I need to add a caveat: only most iterators are capable of forming differences. There is an additional function called difference() from <iterator>, which is even better suited for this purpose.
