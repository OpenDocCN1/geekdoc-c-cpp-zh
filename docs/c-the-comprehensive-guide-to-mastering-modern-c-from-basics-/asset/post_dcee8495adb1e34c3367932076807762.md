
Nevertheless, it is possible to throw and catch this exception yourself using throw.

## 27.5 Manipulating and Formatting Streams

How characters are input or output in a stream is controlled by so-called flags, which are defined in the ios_base base class. You can think of flags as an array of bits, where the values can be either 1 or 0. Individual bits, of course, do not make a value, so the bits are stored in a variable. Depending on the set bits, each value has a special meaning. All flags have a default setting, where, for example, without further specification, all integral values are output in decimal (dec) notation.

You can directly change the format flags by using methods like setf(), unsetf(), or flags() from the ios_base class. However, a better alternative has been available for a long time (specifically) with manipulators. With these, you can insert and call all flags directly as a function in an input or output stream. In practice, the use of manipulators is therefore usually preferable to direct access the format with methods. Therefore, manipulators will be discussed first. The methods by which you can directly change the format flags will be briefly introduced in Section 27.5.4.

Manipulators for streams are objects that you can insert with the standard input/output operators << and >>. You are already familiar with the manipulator endl which adds a newline character to the output buffer.

### 27.5.1 Manipulators

The basic manipulators are listed in <iostream> and <ostream> in Table 27.2.

| Manipulator | Meaning |
| --- | --- |
| endl | Outputs a new line and flushes the output buffer. |
| ends | Adds the null terminator ('\0') to the buffer. |
| flush | Flushes the stream's output buffer. |
| ws | Ignores leading whitespace when reading input. |

**Table 27.2** Basic manipulators in <iostream> and <ostream>.

## Independent Manipulators in “ios”

You can find a considerable number of additional manipulators in the header file <ios>. These are manipulators to format the data during outputting. Since C++20, you can often use format() instead of manipulators. It is easy to enable or disable states. Once activated in a particular stream, the state remains until you call the opposite manipulator again. Consider the following simple example.

```cpp
// https://godbolt.org/z/slc51z
#include <iostream>
#include <iomanip>
using std::cin; using std::cout; using std::endl;

void f(bool b) {
    cout << b << endl;
}

int main() {
    bool b = true;
    cout << std::boolalpha << endl; // Output: true
    b = false;
    cout << b << endl; // Output: false
    f(true);
    cout << std::nobalpha << endl; // Output: 0
    b = true;
    cout << b << endl; // Output: 1
}
```

### 27.5 Outputting a Boolean as text or as a number

First, push std::boolalpha into the cout stream to output true or false from Boolean variables literally, the cout << b afterwards also outputs the value literally. From this, you can see that the setting, once activated, remains active. The output in the function f() shows that the setting is globally applicable. After the function call, deactivate the setting again by sending std::nobalpha into the stream. The output of the numeric values of 0 and 1 instead of false and true confirm this process. Even if the example doesn't show it, you can certainly apply the manipulator on input streams like std::cin as well—for example:

```cpp
bool b;
std::cin >> std::boolalpha >> b;
```

Here you can now enter true or false, and it will be recognized as a Boolean value.

## Manipulators for integers

Other manipulators are available that allow you to set the number format between decimal, hexadecimal, and octal. In Table 27.3, you will find an overview from the <ios> header file.

| Manipulator | Reading/writing integral values |
| --- | --- |
| dec | decimal number format (default setting). |
| hex | hexadecimal number format. |
| oct | octal number format. |

**Table 27.3** Manipulators for the format of integral types.

The following listing shows the three manipulators for changing the integer format.

```cpp
// https://godbolt.org/z/bEKaYdssE
#include <iostream>
#include <ios>
using std::cout; using std::endl;

void f() {
    int val = 100;
    cout << val << endl;
} // Output: 100

int main() {
    int val = 255;
    cout << std::showbase;
    cout << std::dec val << endl; // Output: 255
    cout << std::hex val << endl; // Output: 0xff
    f();
    cout << std::oct << val << endl; // Output: 377
    cout << val << std::endl; // Output: 377
}
```

**Listing 27.6** Number formats for std::showbase manipulator in output.

First, use the std::showbase manipulator so that the number base 0x for hexadecimal or o for octal values appears. I could have skipped the manipulator dec at this point because it is the default setting, and thus the value is output in decimal form anyway.

Next is the hex manipulator, which causes the value to be output in hexadecimal notation. The setting remains global for the stream, as confirmed by the output of the f() function. Then the value is output in octal representation after applying the oct manipulator. The very last output shows again that the setting remains for the stream. If you want to have the decimal notation again, you must reset the format with the dec manipulator.

Using these manipulators to align the output is, of course, only if the output has been set to a specific width using setw() from the <iomanip> header file. For better understanding, here is an example with the corresponding output on the screen:

```cpp
// https://godbolt.org/z/TMdzrjvhd
#include <iostream>
#include <ios>         // left, right, internal
#include <iomanip>    // setw
using std::cout; using std::endl;

int main() {
    int val = -1000;
    cout << std::setw(10) << std::internal
         << val << endl;

    cout << std::setw(10) << std::left << val << endl;

    cout << std::setw(10) << std::right
         << val << endl;
}
```
