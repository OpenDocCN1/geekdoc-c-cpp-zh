# ## 8.1 The Statement Block

Anywhere you are allowed to write a single statement, you can also group multiple statements within curly braces {...}. You can see the schematic flowchart in Figure 8.1. This is also called a compound statement. You do **not** need to end this block with a semicolon; doing so would create an empty statement, which you should avoid (see Chapter 9, Section 9.2).

**Figure 8.1** Flowchart for the statement block.
