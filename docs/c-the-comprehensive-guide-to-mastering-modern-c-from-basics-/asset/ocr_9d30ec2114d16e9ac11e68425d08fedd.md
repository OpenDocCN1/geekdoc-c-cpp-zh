# 29.3 Other Synchronization Options

There are special tasks for which a mutex with a lock is unsuitable. In this section, I will show you a few cases that you can solve using the tools of the standard library.

29.3.1 Call Only Once with "once_flag" and "call_once"

It often happens that you do not want to create a large object in advance just because it might be used later. You want to create the object only on first use—the socalled lazy initialization, or sometimes called late initialization. With only one thread, you could hold a global unique_ptr to the object and initialize it only on first use.

```
// https://godbolt.org/z/T7veha58b
std::shared_ptr<BigData> bigData();
BigData& getBigData() {
    if(!bigData) bigData.reset(new BigData());
    return *bigData;
}
int useBigData() {
    auto bigData = getBigData();
    // bigData->...
}
```
