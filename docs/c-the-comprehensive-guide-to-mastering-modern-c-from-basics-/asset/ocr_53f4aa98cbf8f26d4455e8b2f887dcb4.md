You should only use references in the access clause when absolutely necessary. As always, references carry risks. With anonymous functions, it is quite common to send them on a journey—that is, pass them as parameters to other functions, return them as results, and so on. It may happen that the lambda then “lives” longer than the referenced variable. However, if you accessed a copy, there is no danger.
