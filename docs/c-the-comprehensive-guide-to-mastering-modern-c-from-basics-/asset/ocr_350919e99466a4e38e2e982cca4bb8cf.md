# 16.7 Assignment Operator

You are now familiar with the MyValue class, and you also know that you can create new instances either with the MyValue(string) constructor or by copying with MyValue(const MyValue&). You also know of the assignment = and should therefore be able to say exactly what happens in the following examples.

```
void byVal(MyValue arg) {
int main() {
    MyValue value1{"ABCD"}; // new instance, constructed via string
    MyValue value2(value1); // new instance, constructed via copy
    MyValue value3 = value1; // new instance, also copy, despite
    byVal(value1); // a new instance via copy
    value2 = value2; // not a new instance, but an assignment
}
```

While the first two lines contain no surprises, one might sometimes observe a raised eyebrow at MyValue value3 = value1; Therefore, as a reminder: an equal sign = *never* an assignment, but just another way of writing initialization. To avoid confusion when reading, you should avoid this—least when dealing with real classes. With simple types like int, int val{7} might look strange to some, so you can safely initialize with = here.
