This data type is intended for manipulating raw memory and has the width of an unsigned char, which means eight bits on the most common platforms. If you have two variables, byte a and byte b, then the following operations are available to you, where n stands for any integer value:

+   - std::byte b{n} Creates a new byte.
- to_integer(b) returns the numerical value.
- b << n, b >> returns a new byte with bits shifted to the left or right.
- b << n, b >>= shifts bits in b to the left or right.
- a | b, a&b, a^b links two bytes bit by bit using OR, AND, and exclusive-or(XOR).
- b |= a, b&=a, b^= saves the result of the link back to b.
- -b returns a new byte with bits negated.

A typical use is a vector<byte>, in which you read the content of the file, for example.

# 4.4.4 Floating-Point Numbers

In addition to the integer types, there are also float, double, and long double types for floating-point numbers. Instead of throwing away the remainder of 5/2 when dividing, you can store it in a double; for example, double x = 5.0 / 2.0; stores 2.5 in x. But beware, floating-point numbers also have their limits: they only have a fixed number of bits available, but they use them differently than the integer types do. They use some of the bits for "scaling" the value. This means you can use them to store extremely large and tiny numbers, but only up to a certain precision.
