All preprocessor actions take place purely on a textual level before the compiler actually comes into play. Under Linux, you invoke the compiler for macros.cpp like this (adjust accordingly for other systems):

```
g++ -o macros.x macros.cpp
```

You read the source code from the macros.cpp file and output the fully translated program to macros.x.

The preprocessor reads the makros.cpp file by line. The first line is #define OUTPUT_TO_STANDARD. This introduces the OUTPUT_TO_STANDARD identifier to the preprocessor. You simply introduce it as a name whose existence you can later check with #ifdef or #ifndef.

> Defines on the Command Line

Instead writing #define OUTPUT_TO_STANDARD in the source code, you can also inform the compiler during translation that a specific define should be kept. How to do this depends on the compiler. For g++, this is done with the -D switch on the command line. So you can have started the translation like this:

```
g++ -OUTPUT_TO_STANDARD -o macros.x macros.cpp
```
