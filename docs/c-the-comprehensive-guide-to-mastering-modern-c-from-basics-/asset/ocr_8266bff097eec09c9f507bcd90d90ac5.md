# **List 4.34 Floating-point literals become imprecise at some point.**

There are many ways to output floating-point numbers or prepare them for output:

+   * format("{}

+   * to chars(buffer, buffer + size, number)
This function writes numbers to a buffer. There are optional arguments for formatting and an error check. You can use it from C++17 on.

+   * to_string(number)
This is only possible for numbers. You have no control over the format and can do little to check for errors.

+   * cout << number
The direct output of any type to a stream. For numbers, there are manipulators such as `setprecision` that influence the format.

+   * print(cout, "{}", number)
As of C++23, you can output any arguments to a stream as with format. The implementations are not yet complete as of the end of 2023.
