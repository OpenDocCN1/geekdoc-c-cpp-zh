But because else branches make the code more complex, blocks are really recommended here.

Now you actually know everything about if that you can know. What remains is to combine the knowledge: An if is a statement, if the condition, then the branch, and optional else all together is a statement. You both then and else each get a statement associated. You can combine this into complex nestings. It is common to use another if in the else branch to sequentially query different possibilities:

```
if(number < 0) {
    std::cout << "The number is negative.\\n";n} else if (number == 0) { // else and follow directly one after another
    std::cout << "The number is zero.\\n";n} else if (number > 1000) { // also possible multiple times
    std::cout << "The number is large.\\n";n} else { /* x > 0 but x <= 1000 */
    std::cout << "The number is positive.\\n";n}
```
