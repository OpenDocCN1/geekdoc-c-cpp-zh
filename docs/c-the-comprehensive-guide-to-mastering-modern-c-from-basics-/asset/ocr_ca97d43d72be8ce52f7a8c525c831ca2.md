```
#include <iostream> // Module of the standard library
#include <asteroids.h> // Module of a third-party provider
#include "myModule.hpp" // Module of the current project
#include "algo/myModule.h" // in a subdirectory
```

Write the name of the header file in angle brackets if the file is installed on your system; the compiler should search for it. Use the quotation marks "..." if the header file is part of your current project and not installed somewhere. Some compilers then search for the file in the current project first.

> Don'ts for Includes

Pay attention to upper- and lowercase when naming the file, as this is observed on some systems, dear Windows users! If the header is located in a subdirectory, always use / to separate it:

#include "MY_MODULE.H" // not good if the file is called
"myModule.h"
#include "algo/myModule.h" // also use "/" under Windows
#include "c:/project/myModule.h" // no absolute paths
#include "../algo/myModule.h" // no relative paths with ".."
