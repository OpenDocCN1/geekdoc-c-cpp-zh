If a space occurs in the user input, everything that follows it is held back for the next output operation via >>, and everything gets mixed up.

This is the reason why I do not `getline` use for name in std::getline(cin, name); but instead use getline().

This function reads not only up to the next whitespace, but up to the next end of line—and therefore allows names with spaces.

When you call Files for Input and Output program, you can “redirect” to a file with > file. The following program converts the arguments to uppercase and outputs them:

```
// https://godbolt.org/z/a60gbWKMs
#include <cstdlib>
#include <iostream>

int main(int argc, char* argv[]) { // start at 1
  for(int i=1; i<argc; ++i) {
    for(char* p=argv[i]; *p!='\0'; ++p) {
      char c = toupper(*p);
      std::cout << c;
    }
    std::cout << '\n';
  }
n}
```
