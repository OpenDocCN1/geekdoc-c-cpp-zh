If you use the range-based for, you get the pair as e directly and
access the key and target with e.first and e.second.

# Access via Iterators

As with all ordered associative containers, you get bidirectional
iterators back with [c][r]begin() and [c][r]end().

```
// https://godbolt.org/z16t5dobq75
map<char, int> data = {{'a', 1}, {'b', 2}, {'c', 3}};
for(auto it=data.begin(); it!=data.end(); ++it) { // backwards
    cout << it->first << " : " << it->second << '\n'; // dereference with -
}
cout << '\n'; // Output: a:1 b:2 c:3
for(auto e : data) { // forwards, uses begin() and end()
    cout << e.first << " : " << e.second << '\n'; // pair, element access with
}
out << '\n'; // Output: a:1 b:2 c:3
```

**Listing 24.66** Iterators of "map" are type of "pair".

# Access via Search

You can search for keys in the map using find, upper_bound,
lower_bound, and equal_range. You get an iterator to the found
element or end(), as described with set. With count, you can
find out if a key occurs zero times or one time; with contains, you
get that information as a bool since C++20.

# Index-Like Access

As a special feature among associative containers, ordered or
unordered, map has the operator[] and at methods, which you know
from vector and array. This allows you to use a map as if it had an
index. Unlike its counterparts, the index is not of type size_t, but of
type Key. Therefore, the argument for operator[] and at is a value of
this type. As shown in Listing 24.59 and Listing 24.64, operator[]
automatically inserts elements if the key is not found. at,
on the other hand, throws an out_of_range exception in such cases.
