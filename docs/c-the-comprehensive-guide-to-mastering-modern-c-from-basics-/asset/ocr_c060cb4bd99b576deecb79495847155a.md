Sometimes you want to decide which code to execute at compile time rather than at runtime. You do this all the time with overloads. “If the argument is a pointer, then dereference it; otherwise, return the value itself.” This problem could be solved with an overload, but it can also be done with constexpr.

```
// https://godbolt.org/z/zMbnYzo17
template<typename T>
auto deref(T t) {
    if constexpr (std::is_pointer_v<T>) {
        return *t;
    } else {
        return t;
    }
}

int main() {
    int i = 42;
    std::cout << deref(i) << '\n';
    auto p = std::make_unique<int>(73);
    std::cout << deref(p) << '\n'; // directly the value
// dereferenced pointer
```

Listing 13.15 With "constexpr", you can decide at compile time what code will be executed.

Here it is decided at compile time what code will be executed. For I, it is return t—because is_pointer_v<int> is false. For p.get(), it is return *.
