# String Streams Instead of File Streams

String streams can indeed be used excellently for converting to and from strings, but in practice, they are even more frequently used for buffering purposes to avoid temporary files. Basically, you just need to use a corresponding string stream instead of a file stream. The advantage is obvious: string streams are significantly faster (as they are in main memory) than slow temporary files, which require rather slow access to a storage medium. However, this depends on the use case. It should also be clear that data only resides in the buffer of the main memory will be lost in the event of a program crash.
