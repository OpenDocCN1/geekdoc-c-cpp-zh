# Do Not Compare Floating-Point Numbers with ==

Because none of the floating-point types, float, double, and long double, can store all numbers exactly, you should never test for equality using ==. Instead, calculate the difference and check whether the result is close to zero. For example, if you want to know whether the two double values a and b are "almost equal," you can check this in this way:

```
if fabs(b-a)<0.0001)
```

The fabs() function returns the absolute value (makes it positive) and is located in the <cmath> header. For 0.0001, use an epsilon that suits your application.

# Floating-Point Literals

Similar to integers, you can write floating-point numbers naturally in the source text. However, you must use the dot . as a separator; the continental comma does not work. In the literal 124.258, the continental recognizes from the dot . that it is not an integer.
