template, I used only one TYPE, and it must match exactly in both places. So the template does not match the call. Therefore, simply add another overload:

```
const char* max2(const char* a, const char* b) {
  return std::string(a) > std::string(b) ? a : b;
}
```

This also immediately solves the problem that comparing two const char* is no means a comparison of the texts, but only of the addresses of the pointers. Converting to string specifically for the comparison with > solves the problem—albeit not elegantly.
Unfortunately, > string, unlike for int, is not constexpr, and the compiler thus does not allow the use of > string in a function marked as constexpr. But at least you now have a template for almost all cases—and an extra overload for a special case.
