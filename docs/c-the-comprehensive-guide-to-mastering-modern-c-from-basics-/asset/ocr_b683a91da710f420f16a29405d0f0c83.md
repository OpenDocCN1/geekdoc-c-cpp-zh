```
// https://godbolt.org/z/T9jsEoMjq4
#include <vector> // You need this header
int main() {
    std::vector<int> squares; // initialize empty
    for(int idx = 0; idx<100; ++idx) {
        squares.push_back(idx*idx); // append element
    }
}
```

With push_back(), you append an element to the end of
t vector. Alongside index access, this is one of the
most useful functions of vector—for example,
squares[idx].

In a vector, the elements are stored consecutively in
computer memory. This is CPU-friendly and makes it
extremely fast when accessing from front to back.
However, the vector has the following disadvantage: if
you want to insert an element in the middle or at the
front, all elements to the right of it are shifted one
position to the side—and this is usually a time-
consuming process.
