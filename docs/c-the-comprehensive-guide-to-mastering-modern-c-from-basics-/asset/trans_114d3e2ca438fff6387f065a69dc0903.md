

## 25.6.1 范围适配器与视图（Range Adapters and Views）

现在我们来看异常。范围适配器定义在 `<ranges>` 头文件中。它们支持算法函数或通过巧妙的组合取代这些函数。它们不是函数，而是类。我从范围适配器开始说，因为它们可能代表了未来。它们在 C++20 中引入，并在 C++23 中进行了重大更新，并且已经对 C++26 将要添加的内容有了计划。我特别强调了仅在 C++23 中添加的内容。

范围适配器是 `std::view` 中的函数对象，用于从 `std::ranges` 创建模板类的实例。例如，`std::views::take()` 与一个范围结合时，会创建一个 `std::ranges::take_view` 实例——这才是实际的视图。因此，你通常可以直接使用不带 _view_ 后缀的名称来创建视图——通常是相同的名称并加上 _view_，但也可以有其他方法（你可能自己编写）。

```
// https://godbolt.org/rgjv5aPs
std::list lst(1, 2, 3, 4, 5, 6, 7, 8, 9);
auto take5 = rs::take_view(lst, 5); // 通过类型创建视图
auto take6 = lst | vs::take(6); // 通过适配器创建视图
```

所有视图实现了 `std::ranges::view_interface` 接口，因此具有以下成员函数，其中某些仅在特定条件下有效：

- empty(), operator bool()：用于 `if(v)`
  检查 `forward_range` 或 `sized_range` 是否为空。
- size()
  返回 `sized_sentinel_for` 视图中的元素数量。
- front(), back()
  返回 `forward_range` 的第一个元素或 `bidirectional_range` 的最后一个元素。
- data()
  获取 `random_access_range` 的第 n 个元素。
- cbegin(), cend()
  从 C++23 开始，它们返回 `begin()` 和 `end()` 的常量版本。

视图最重要的属性之一是它们是**惰性的**（`lazy`）。例如，如果你执行 `auto v = mydata | take(5)`，最初什么都不会发生！`v` 的类型是一个视图且不包含任何数据。只有当你遍历并对元素进行某些操作时，操作才会执行并产生结果元素。通常，你会通过 `ranges::to()`、容器的 `from_range` 构造函数或在循环中将视图实例化。

- views::all
  用法：罕见；迭代器：
  范围的所有元素。
- ranges::subrange
  用法：频繁；迭代器：输入/输出
  从迭代器和哨兵（sentinel）创建视图。某些适配器、工厂和算法也使用这种类型。用途：当算法返回一个子范围时，你可以通过 `auto [beg, end] = ....` 提取范围的迭代器。

- views::empty
  用法：偶尔；迭代器：-
  创建一个不包含元素的空视图。
- views::single
  用法：偶尔；迭代器：-
  产生一个包含单个元素的视图。
- views::iota
  用法：偶尔；迭代器：-
  用于递增值序列。对应 `iota` 算法。
- views::istream
  用法：罕见；迭代器：输入
  通过多个 `operator>>` 创建的视图。
- views::repeat
  用法：偶尔 (C++23);迭代器：输入
  重复相同的值。
- views::filter
  用法：频繁；迭代器：输入
  过滤范围中满足谓词的元素。注意，只有当修改后的值也满足谓词时，你才能修改值！
- views::transform
  用法：频繁；迭代器：输入
  对每个元素应用函数。
- views::counted
  用法：罕见；迭代器：输入
  从迭代器和计数 n 创建一个范围。
- views::take
  用法：频繁；迭代器：输入
  传递范围的前 n 个元素。
- views::take_while
  用法：频繁；迭代器：输入
  在谓词为真时持续传递元素。
- views::drop
  用法：频繁；迭代器：输入
  跳过范围的前 n 个元素。
- views::drop_while
  用法：频繁；迭代器：输入
  在谓词为真时持续跳过元素。
- views::join
  用法：频繁；迭代器：输入
  将范围的范围展平为范围。
- views::join_with
  用法：频繁 (C++23);迭代器：输入
  类似于 `ranges::join`，但在连接的范围之间有分隔元素。
- views::split
  用法：频繁；迭代器：前向(fw)
  根据分隔符将范围分割多个范围。
- views::lazy_split
  用法：罕见；迭代器：输入
  也是分割，但只需要 `input_range`。
- views::reverse
  用法：频繁；迭代器：输入
  反转范围。
- views::enumerate
  用法：频繁 (C++23);迭代器：输入
  将范围转换为包含索引和元素的元组范围。
- views::elements
  用法：偶尔；迭代器：输入
  将范围转换为元组范围。
- views::keys
  用法：偶尔；迭代器：输入
  将范围转换为键的元组范围。
- views::values
  用法：偶尔；迭代器：输入
  将范围转换为值的元组范围。
- views::zip
  用法：频繁 (C++23);迭代器：输入
  获取多个范围并创建元组范围。
- views::transform
  用法：频繁；迭代器：输入
  获取多个范围并创建元组范围。
- views::chunk
  用法：频繁 (C++23);迭代器：输入
  根据标准分组连续元素。
- views::chunk_by
  用法：频繁 (C++23);迭代器：输入
  根据准则分组连续元素。
- views::slide
  用法：罕见 (C++23);迭代器：输入
  在范围内创建滑动窗口视图。
- views::stride
  用法：偶尔 (C++23);迭代器：输入
  每隔 n 个元素获取一个元素。
- views::adjacent
  用法：频繁 (C++23);迭代器：输入
  创建相邻元素的元组。
- views::pairwise
  用法：罕见 (C++23);迭代器：输入
  对相邻元素应用函数。
- views::adjacent_transform
  用法：频繁 (C++23);迭代器：输入
  对相邻元素应用函数。
- views::cartesian_product
  用法：(C++23);迭代器：输入
  生成多个范围的所有组合。
- views::repeat
  用法：偶尔 (C++23);迭代器：输入
  多次重复一个值。
- views::iota
  用法：偶尔 (C++23);迭代器：输入
  生成递增值序列。
