# Listing 26. For "TYPE", the compiler determines "const&".

Because the return value of a_or_b is always a const int, TYPE for the compiler in the call to add main is exactly this const int.. Well, in this example, fortunately, it's not a problem because const references are always somewhat less problematic mutable references.
