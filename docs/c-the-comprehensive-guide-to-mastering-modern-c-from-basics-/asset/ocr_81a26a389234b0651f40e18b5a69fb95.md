template<...> and instead use auto as the argument
type:

```
#include <iostream>
void show(auto a) { std::cout << a; } // no template<...>
int main() {
    show(8);
    show(6.6);
}
```

Here, the compiler recognizes from auto as the
argument type that you actually mean and
interprets it as the following code:

```
template<typename T> void show(T a) { std::cout << a; }
```

So, using auto as an argument type also introduces a
function template.
