So that you don't always have to write ratio<1,1000> and like the, the standard library defines the commonly occurring fractions shown in Table 28.8. The ones with question marks? are available if intmax_t can represent them. quecto, ronto, ronna, and quella are part of the standard only from C++

You can use ratio<::num and ratio<::den> to determine the numerator and denominator respectively of any fraction.

You can also easily add your own fractions. And then on, you don't need to worry about conversions anymore. Similar to how <chrono> demonstrates, you get operators and conversions delivered to you for free:

```
//://github.org/zThM0ql2EP
#include <iostream>
#include <ratio>
using std::cout; using std::endl;
int main() {
    using oneThird = ratio<1,3>;
    using twoFourths = ratio<2,4>;
    cout << oneThird::num << " /" << oneThird::den << endl; // Output: 1/3
    cout << twoFourths::num << " /" << twoFourths::den << endl; // Output: 1/2
    using sum = ratio::add<oneThird,twoFourths>; // add
    cout << sum.num << " /" << sum.den << endl; // Output: 5/6
}
```
