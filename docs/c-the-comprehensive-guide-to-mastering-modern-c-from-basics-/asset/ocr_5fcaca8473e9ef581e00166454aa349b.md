One of the most important properties of views is that they are `lazy`. For example, if you execute auto v = mydata | take(5), initially nothing happens! The type of v is a view and contains no data. Only when you iterate over and do something with the elements is the operation executed and the result element produced. Typically, you materialize a view with ranges::to(), the from_range constructors of the containers, or in a loop.
