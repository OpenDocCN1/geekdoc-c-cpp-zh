As you saw in Chapter 4, Section 4.3, there are more
operators. And just like operator=, you can define most of
them for your class yourself. But how? As a free function
or as a method? Most of the time, you can choose
whether to define an operator for your own classes as a
method of the class or as a free function. In practice,
however, one or the other has become established for
each operator. The following rules of thumb will help you
choose:

+   - Binary operators that do not modify any of the
arguments should be defined as free functions. These
are primarily the bitwise and arithmetic operators,
including << and >>, which are used for input and
output. Comparison operators are implemented via
== and optionally also ==.

+   - Binary operators that modify the left argument are
best suited as methods—for example, operator+=.

+   - Assignment, index operator, and call operator must
be methods—that is, operator=, operator[], and
operator().
