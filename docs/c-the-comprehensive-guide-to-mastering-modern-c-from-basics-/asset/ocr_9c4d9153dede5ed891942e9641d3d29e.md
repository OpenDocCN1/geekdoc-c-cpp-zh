# ## 4.4 Built-In Data Types

So far you have only learned about types in a flyover—and around them, just as much fundamental C++ as was necessary to understand them.

This section builds on these basics. You now know enough about the language to understand the comprehensive explanations of all the built-in types.

In this section, you will learn what data types are available to you in C++ if you do not use #include in your program or do not use the standard library. What are the built-in data types, and what can you do with them?

Pay attention to the types of variables and function parameters in the following example.

```
// https://godbolt.org/z/MPPbddg9c
#include <iostream>
using cin, for input and output

void input(unsigned birthday,
          unsigned birthMonth,
          unsigned birthYear,
          unsigned long &taxnumber,
          double &height)
{
    /* Inputs without good error handling ... */
    std::cout << "Date of birth: " cin >> birthday;
    std::cout << "Month of birth: " cin >> birthMonth;
    std::cout << "Year of birth: " cin >> birthYear;
    std::cout << "Tax number: " cin >> taxnumber;
    std::cout << "Height: " cin >> height;
}

int main() {
    /* data */
    unsigned birthday = 0;
    unsigned birthMonth = 0;
    unsigned birthYear = 0;
    unsigned long taxnumber = 0;
    double height = 0.0;
    /* Input / */
    input(birthday, birthMonth, birthYear, taxnumber, height);
    /* Calculations */
    return 0;
}
```
