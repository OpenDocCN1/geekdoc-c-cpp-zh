Use the prefix u before a character literal—for example, char16_t ced = u'Z'; The character string type std::u16string is based on this. A single char16_t is sufficient for the vast majority of Unicode characters. Very rarely do you need two consecutive ones, which are then encoded in UTF-16.

+   * char8_t
This type is added in C++20. It accepts UTF-8 code units and is therefore at least eight bits wide, just like char and unsigned char, but is different as a type. Only ASCII characters fit into a single char8_t. This means that for a Unicode ä, you need two char8_t—that is, 0xC3 followed by 0xA4 in UTF-8 encoding. You rarely use literals of this type with a u prefix—that is, u8'a' for characters and u8"uF66" for character strings.
* wchar_t
Depending on the system, this character has 16 bits (Windows) or 32 bits (many Linux variants). If you write an l in a character literal, it is of this type—for example, wchar_t ced = L'Z'; As it can be of different widths, you should not use this type in programs that have run on several systems. The character string type std::wstring is based on this type; to output it, use std::wout or std::werr or as input std::win.
