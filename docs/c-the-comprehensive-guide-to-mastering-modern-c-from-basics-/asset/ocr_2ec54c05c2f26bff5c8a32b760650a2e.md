+   * Fill

However, there is fill, which allows you to set all values of an array at once,
asas you can see in Listing_24.35.

# Insert and Delete

Inserting and deleting elements is not possible with array.

# Read and Write

You can read and write parts of an array in the following ways:

+   * Index access
However, you can access the elements unprotected or protected with [] and
at. You get back a reference that you can read and overwrite.

+   * Iterators
The iterators of array are contiguous and random-access, meaning they can
move forward, backward, and can be arbitrarily positioned, similar to vector.

+   * Beginning and end
You also have front and back available, which give you references to the first
last elements of the array, respectively.

+   * Tuple interface
You can read and write an array like a tuple using std::get<>, as you can see in
Listing_24.36.

+   * Span
Since C++20, array can work wonderfully with span, just like vector. From
C++23 onward, you can also overlay an `mdspan`.

+   * C interface
Because the elements of an array are contiguous like those of a vector, you
can data() to get a pointer to the first element and handle it like a C-
array or C-pointer. With slight modifications, Listing_24.25 also works with
array.

+   * Fill
Specifically for array, fill, which allows all elements simultaneously.

```
// https://cppreference.org/w/cpp/array/fill
array<int, 3> data={1, 6, 3};
data.fill(8); // now (8, 8, 8);
```
