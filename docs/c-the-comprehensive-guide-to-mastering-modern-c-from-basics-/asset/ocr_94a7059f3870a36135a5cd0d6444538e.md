# Operators for Streams

The input and output data streams of the standard library streams use the << and >> operators, which are actually intended for bitwise arithmetic, for writing and reading. You have already seen this for std::cout and std::cin in many listings. In C++ today, << and >> are used more frequently for streams than for real bitwise arithmetic.
