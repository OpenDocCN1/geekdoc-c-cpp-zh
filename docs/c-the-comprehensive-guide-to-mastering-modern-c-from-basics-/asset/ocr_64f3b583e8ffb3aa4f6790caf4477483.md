If you decide on a constantly sorted vector, starting from C++23, flat_set is available. It is as easy to use as a set but stores its elements in a vector. This does not nullify the cost of an insertion in the middle; if you do not have many elements, and they are also small, you can use flat_set.

Against keeping sorted with list or even forward_list, it argues finding the insertion position takes a while. Even if a list is sorted, you usually have to traverse from the beginning to the desired element when searching. This is faster in a sorted vector or array.
