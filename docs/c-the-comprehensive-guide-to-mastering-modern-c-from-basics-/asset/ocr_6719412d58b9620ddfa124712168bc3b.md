# 4.3.4 Bit-by-Bit Arithmetic Bit-by-bit arithmetic probably looks a bit strange at first:

```
int a = 41; // decimal 41
int b = a & 15; // results in 9
```

The explanation is that numbers are represented in the computer as a sequence of 0s and 1s—that is, as bits. The decimal 41 is 10101 in bit representation—that is, in binary.

Because 10 is the base in the decimal system, we write “four hundred and twelve” as 412 as an abbreviation for $4 \cdot 10^2 + 1 \cdot 10^1 + 2 \cdot 10^0 = 412$. For a computer, with base 2, this is $1 \cdot 2^8 + 1 \cdot 2^7 + 0 \cdot 2^6 + 0 \cdot 2^5 + 1 \cdot 2^4 + 1 \cdot 2^3 + 1 \cdot 2^2 + 0 \cdot 2^1 + 0 \cdot 2^0$, abbreviated to $2_1 1001 1100$. The subscript 10 or 2 indicates the number system in which the number is represented.
