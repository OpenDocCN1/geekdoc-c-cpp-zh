# **Listing 27.24** Synchronizing output between threads with "osyncstream".

Here, the Fibonacci numbers are calculated in three threads in steps of 1 to 42. The variable osync locks the output to std::cout for other threads as long as it exists—but only if the other threads also use osyncstream. Apart from the order, the output is nice and clean line by line:

```
fib(2)=1
fib(5)=5
fib(8)=21
fib(11)=89
fib(14)=377
```
