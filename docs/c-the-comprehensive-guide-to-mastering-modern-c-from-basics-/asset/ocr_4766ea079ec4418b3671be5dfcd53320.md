# **Listing 27.21** Line-by-line reading and writing.

This listing largely corresponds to the previous example, in which data was read byte byte by byte. Now you will find std::string instead of char as a buffer, into which I read a line from the file file stream using getline() in the while loop. filecopy copies this line into the filecopy file stream. The newline is automatically removed by getline(), so you need to add a newline to the stream here. I also output the line to std::cout (usually the screen). The while loop reads line by line until EOF is reached.
