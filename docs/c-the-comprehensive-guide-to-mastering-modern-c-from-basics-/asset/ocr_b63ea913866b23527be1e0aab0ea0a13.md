All in all, it is often very worthwhile if the compiler saves a function call. And function templates are the ultimate sign to tell the compiler to “inline, please.” Here, the compiler puts in a lot of effort.

# 23.1.6 Parameters with Extras

Some functions use the “pure” formal template, while others qualify it:

```
template<typename TYPE>
TYPE add(TYPE a, TYPE b) { // use the pure type
  return a + b;
}

template<typename TYPE>
void print(const TYPE& value) { // type enriched with const & &
  cout << value;
}
```

It depends on what you want to do with the parameters in the function. Because the add() function probably only makes sense for numbers, it will very likely be only applied to built-in types. Thus, passing parameters by value is very sensible: simply use TYPE.
