multiple elements of the original container in another container that contains the objects.

The shared_ptr is also for regulated ownership, but it is not quite as possessive.
shared_ptr is willing to share the object it owns with many others—so long as they are also shared_ptr or weak_ptr. The wrapped object exists only once. When the last shared_ptr that references this object disappears, the object also disappears.

You can use this mechanism when it is not clear who owns the objects and when exactly they should be cleaned up—or even when you know for sure that there are times when multiple entities own the objects. All in all, there are probably many more different use cases for shared_ptr, precisely because it allows so much freedom in terms of ownership.
