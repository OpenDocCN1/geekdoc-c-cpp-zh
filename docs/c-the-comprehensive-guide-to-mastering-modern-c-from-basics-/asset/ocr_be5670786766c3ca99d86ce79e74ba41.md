I have stored the details of the search results in Listing_28.12 in an instance of cmatch. But this is actually just a typedef for a template of match_results for searching in a string. For the other search types, there are other predefined typedefs:

+   - smatch for searching in string
- cmatch for searching in const char*
- wsmatch for searching in wstring
- wcmatch for searching in const wchar*

You saw in Listing_28.10 that besides searching, matching, and replacing, you can also iterate over all matches. This is done with the regex_iterator template class. We have already seen its work on string with the srex_iterator specialization. For char*, wstring, and wchar*, there are typedef with c, ws, and wc instead of the prefix s.

# 28.2.5 Iterators

Internally, regex_iterator uses the regex_search function for searching and is merely an adapter class for the iterators it provides. Therefore, they only point to corresponding match_result instances.
