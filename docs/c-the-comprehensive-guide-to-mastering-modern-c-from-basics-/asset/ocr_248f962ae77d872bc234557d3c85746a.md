In the example room, with an appropriate operator<, you can indeed consider actually different elements in a multiset as equal. Here, for example, only the first letter of the name is compared. When I then search with raum.equal_range(Person("K")), all names with k fall within the returned range. Note that the defined operator< is also used for internal sorting, so only the first letters of the names are used for sorting. This is why the unsorted "..." names appear in the search results.

The return value of equal_range is a pair, and since C++17, it can be assigned to two new variables using a structured binding. Before C++17, you would use auto x and then x.first or x.second.

# Deleting

As with set, you delete with erase or clear:

+   * Deleting all elements
  clear(), you remove everything.

+   * Deleting or transferring a single element
  erase deletes either a single element if you provide an iterator, or all elements that match the given search key.

extract does that too if you want to insert elsewhere afterward.

+   * Deleting multiple of elements
  With two iterators as parameters, you delete multiple elements as with set.

All iterators for nondeleted elements retain their validity.
