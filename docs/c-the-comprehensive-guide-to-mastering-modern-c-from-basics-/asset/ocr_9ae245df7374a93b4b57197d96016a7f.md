Call the test program with --help or -? to get a detailed list of parameters.

In the output, you will see that Boost.Test provides the summary for the master test suite. It is a specialty of this framework that suites suites and cases can be hierarchically nested like a tree. The root is always the master test suite. Most other xUnit frameworks do not have this nested structure but are limited to a set of test cases in a set of test suites.
