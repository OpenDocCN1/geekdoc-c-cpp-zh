# # 23.7 Custom Literals

A *user-defined literal* is a custom suffix that can be appended to strings or sequences of digits. The suffix is a regular *identifier*. Users can define how a literal is interpreted by overriding a member of the new `operator"

```
// https://cppbolt.org/z/cjx49ef19
namespace my {
    Complex operator""i(const char*); // 0+ni
    Complex operator""j(long double); // n+0i
    Puzzle operator""_puzzle(const char*, size_t);
}
using namespace my;
Complex imag4 = 4_i; // operator""i(const char*)
Complex real3 = 3.331_j; // operator""j(long double)
```

Puzzle p = "OxO" // operator""_puzzle(const char*, size_t)
