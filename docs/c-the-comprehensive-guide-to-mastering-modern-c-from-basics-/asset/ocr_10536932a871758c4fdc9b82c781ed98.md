# Listing 28.41 Use "typeindex" for reliable type information.

The pure call of typeid(...).name() provides a name, but not a reliable one. For me, it returns simply as "i". And for an iterator or a template like map, the output is only limitedly informative.

You counteract this by applying type_index(...) to the result of typeid—that is, to the const type_info&. As you can see in the names example, you can also populate a map with more readable names this way.

Note that you can use both plain types like iterator as a parameter for typeid, as well as an expression like integer, *one, or string("World"}.begin(). The expression is not executed; only its type typeinfo(666/0) would otherwise cause the program to crash.
