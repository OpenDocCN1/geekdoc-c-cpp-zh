# # 6.1 The String Type "string"

Strings are best (or at least normally) stored and manipulated in std::string. This type is located in the <string> header of the standard library. Make sure you add this header before you use string.

```

In C and many C++ programs, character strings are stored in char* or char[] and their const variants. This is generally fine, but here I will discuss the much more C++-like variant std::string, which you should prefer to char* and char[] in many cases.
```
