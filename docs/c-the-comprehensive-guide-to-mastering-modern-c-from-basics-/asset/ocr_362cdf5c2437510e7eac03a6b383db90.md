# Line-by-Line Reading and Writing

Processing a file line by line naturally requires files that contain line breaks. Therefore, line-by-line reading or writing is more suitable for formatted files. It makes little sense to process a binary file-by-line. For reading a stream line by line, the getline() method is suitable, and for formatted writing to the stream, the operator<<().
