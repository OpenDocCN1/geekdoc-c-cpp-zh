Note that the Compiler Explorer URL (godbolt.org) in the listing, I added the extra library in the interface. I needed to use GCC 11.2 though, a later version did not work with that specific installation. Locally I used GCC 13.2 with the library installed in docker. This is my Dockerfile `gcc13.Dockerfile:`

```
FROM gcc:13.2
RUN apt-get --allow-unauthenticated --allow-insecure-repositories \
&& \ \
    apt-get install --allow-unauthenticated -y libtbb-dev && \\
    rm -rf /var/lib/apt/lists/*
CMD [ "/bin/bash" ]
```

This is how you build the gcc13 Docker container:

```
docker build -f gcc13.Dockerfile -t gcc13 .
```

You can now compile in this container:

```
docker run --rm -i --volume $(pwd):/workdir --workdir /workdir gcc13 \
g++ -O3 -std=c++23 -ltbb 25AlgoPar.cpp -o GCC-25AlgoPar.x
```
