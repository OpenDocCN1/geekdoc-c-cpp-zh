merge transfers all elements between two multimaps and does not leave duplicates in the source as with map.

# Insert

You can insert new elements into the multimap with insert, inplace, emplacement_hint, and from C++23 also insert_range. Unlike map, elements are always inserted, even if the new key already exists. What does not exist compared to map is operator[] for automatic insertion:

+   Inserting a single element with automatic positioning
As map, you can use insert to add a new pair<Key,Target> to the multimap. With the emplacement method, you provide Key and Target directly as parameters. Unlike map, these do not return a boolean indicating the success of the insertion, but only an iterator with the position of the inserted element. This is demonstrated in Listing 24.73.

+   Inserting a single element with a position hint
As map, you can provide insert with an additional iterator as a position hint or use emplacement_hint in the same way. If the hint is correct, then the insertion happens on average in O(1).

+   Inserting multiple elements
The insert of the multimap can also receive a pair of iterators, just like map. Starting from C++23, you can use insert_range.

The following listing shows how to insert elements into a multimap.

```
// https://cppbolt.org/z/d68e9j7
using namespace std::literals; for << "s"

mimap<int,string> numlang;
numlang.insert(std::make_pair(7, "seven"s));
numlang.insert(std::make_pair<int,string>(7, "sieben"s));
numlang.emplace(7, "yedi"s);
cout << numlang; // Output: 7:seven 7:sieben 7:yedi
```
