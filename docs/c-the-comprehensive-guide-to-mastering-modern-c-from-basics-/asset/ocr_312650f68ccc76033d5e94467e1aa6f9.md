You can provide constructor arguments similar to set and the other containers, as follows:

+   * No arguments
* A range from another container using a pair of iterators
* An initializer list
* The tag from range and a range, if you use C++23
* Another unordered_set to copy from

Except for the last two variants, all optionally take a size_t, with which you can set the initial size of the hash table.

This, in a brief example, as shown in Listing 24.79.

```
// https://github.com/r/z1/6PM0jr
#include <set>
template<typename Key>
std::set<Key> set_data(const unordered_set<Key>& data) {
    return std::set(data.begin(), data.end());
}
//
// without argument
unordered_set empty = empty();
cout << empty; // Output:
//
// initializer list
unordered_set data({1,2,3,2,3,4,5,5}); // duplicates are not included
cout << data; // Output approximately: 5 4 3 2 1
//
// copy
 copy = copy(data);
cout << copy; // Output approximately: 5 4 3 2 1
//
// Argument
auto sol = sorted(data);
unordered_set range(std::next(sol.begin()), std::prev(sol.end()));
cout << range; // Output approximately: 2 3 4
```
