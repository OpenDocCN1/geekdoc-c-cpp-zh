If you are dealing with multiple time zones, the time zone database enters into play:

+   - tzdb
This type stores the data of the time zone database. You get it with the get_tzdb() function. There are the zones, version, and links vectors as well as the version field. With the current_zone() and location_zone(string tz_name) methods, you get a const time_zone*.

+   - tzdb_list
You can use the tzdb_list() method to get a list of all time zones, and multiple versions may be stored.

+   - time_zone_link
This represents an alternative designation of a time zone.
