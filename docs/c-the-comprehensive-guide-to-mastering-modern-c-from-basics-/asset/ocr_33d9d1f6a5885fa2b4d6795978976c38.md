# 10.2 What Is an Exception?

You cannot avoid the really important checks for error states: you have to teach the computer what an error is and what is not. But the passing on of codes is tedious and long-winded. You can also central handling for errors that occur in multiple places with a different approach.

Instead of generating and passing on error codes, you can trigger an exception—or, in other words, throw an exception.
