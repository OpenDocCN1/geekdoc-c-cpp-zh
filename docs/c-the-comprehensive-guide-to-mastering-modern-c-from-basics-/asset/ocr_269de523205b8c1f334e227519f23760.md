Thus, you can not move all elements of another container but also those of a range.

The move_iterator created by make_iterator ensures that every a = b the element-wise initialization of target a std::move(b). This means for string that b will contain the empty string afterward. Moving from source to target a move operation element-wise—meaning that the content of the elements is moved, not the element itself.

All containers support initialization with an initializer list and can usually deduce the template parameter for you since C++17. However, avoid the pitfalls of putting strings into the initializer list. In such a case, explicitly write vector<string> to force a conversion or use the ""s suffix for string (or even ""sv for string view).
