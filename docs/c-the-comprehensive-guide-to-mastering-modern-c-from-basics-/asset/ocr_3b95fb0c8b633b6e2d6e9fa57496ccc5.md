# The "int" Type

In this chapter, int is a representative of all types that you can use in C++ to represent integers—that is, negative integers, zero, and positive integers. However, a computer has limitations when it comes to its number range. With int, you have a different number of bits available depending on the system. If you are working on a current system, it is probably 32 bits, but it could be 16, 64, or a completely different number. With 32 bits, int can store integers from about -2 billion to +2 billion. You can find out exactly with Listing 23.29. If you want to cover other number ranges, you should take a closer look at the relatives char and short as well as long and long long in Section 4.4.
