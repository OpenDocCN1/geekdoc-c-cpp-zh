| 26.2.1 Two Phases? "vector" as a Good "set" Replacement |

Note that whenever you use set splits into two distinct phases for filling and reading, you should prefer using a vector. A set keeps its elements sorted at all times and incurs some overhead with every insertion. Often, it is better to dump all elements into a vector using push_back() and then sort them in one go with sort() from the header <algorithm>.
