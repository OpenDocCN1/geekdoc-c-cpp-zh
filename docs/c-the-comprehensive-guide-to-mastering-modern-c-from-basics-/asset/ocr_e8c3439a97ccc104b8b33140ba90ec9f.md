In the last example, you see that you can also format your own types. Here is the <chrono> header brings in its own formatter.

By the way, did you notice the new C++20 notation for date literals in 2023y/11/5?

In general, the standard formatting attributes are structured as follows; these are the possible elements in a compact form:

fill sign #  width .precision L type

All elements are optional, but the order must be maintained. The elements are partially dependent on each other and only make sense in certain combinations
