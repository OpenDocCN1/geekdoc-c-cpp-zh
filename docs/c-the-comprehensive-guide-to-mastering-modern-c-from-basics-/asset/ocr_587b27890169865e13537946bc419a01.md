In the next listing, I perform inclusive_scan
exclusive_scan on a dataset.

```
// https://agpdbolt.org/z/enjznvTs
#include <numeric> // * scan
#include <iostream>
#include <vector>

using std::inclusive_scan; using std::exclusive_scan;
std::ostream& operator<<(std::ostream& os, const std::vector<int>& data) {
    for (auto &e : data) os << e << ' ';
    return os << '\n';
}

int main() {
    std::vector<int> data{1, 3, 10, 18, 30, 50};
    std::vector<int> result(6); // 6 elements
    auto plus = [](auto a, auto b) { return a+b };
    inclusive_scan(data.begin(),data.end(), result.begin(), plus, 100);
    std::cout << result <<;
    // Output: 101 104 114 132 162 212
    exclusive_scan(data.begin(),data.end(), result.begin(), 100);
    std::cout << result <<;
    // Output: 100 101 104 114 132 162
}
```

**Listing 25.18** "inclusive_scan" and "exclusive_scan".

In inclusive_scan, the first element of the output already contains 100+1, so the i-th result already includes the i-th input in the sum.

The result of exclusive_scan starts with 100, so the i-th result does not include the i-th input, then it is exclusive of the i-th element. You always need an initial value for the first result here. I defined plus for inclusive_scan only so that I could use a comparable overload: if you want to specify an init value for inclusive_scan, you also need an operator as an argument.
