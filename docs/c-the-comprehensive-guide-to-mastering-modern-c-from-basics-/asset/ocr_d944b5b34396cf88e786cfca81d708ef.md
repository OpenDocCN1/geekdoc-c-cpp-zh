And not only that, but it also violates SRP, as a change in radio0ff(), for which driver is the user, potentially affects the busStop. Such a thing should never happen.

Changing interfaces is always dangerous because it can have implications for the users. You usually have control over the implementation, but not always over the users. One could therefore say that interfaces belong to the users, not the implementations. Hence, the perspective from **Figure 19.3** is so important. You should always strive to optimize interfaces for users. Sometimes you do not yet know the actual users, which makes it harder.
