several methods that can be called with a streambuf object.

To access a stream buffer, each I/O stream object provides a method called rdbuf(), which returns a pointer to the streambuf object. With this, you can now access the streambuf methods. For example, you can connect the streambuf pointer to another stream using operator<<:

```
std::ifstream file("logfile.log");
std::cout << file.rdbuf();
```

With cout << file.rdbuf(), the entire content of the file is pushed to cout and displayed in one go. This method of passing the entire content to another stream in one go is even significantly more efficient than outputting the entire content using read() and write(), as you did in Listing_27.23.
