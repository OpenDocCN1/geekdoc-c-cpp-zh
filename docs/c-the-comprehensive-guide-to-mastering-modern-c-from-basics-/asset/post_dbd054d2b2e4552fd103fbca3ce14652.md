# Listing 27.29 Transferring data from the "rdbuf".

Thanks to bufptr = file.rdbuf(), you now have full control over the streambuf buffer with the streambuf pointer. First, I use seekoff and file.end to set the stream buffer pointer to the end of the buffer to obtain the size buffer size. Because I also want to read from the buffer afterward, I then set the position of the streambuf back to the beginning of the buffer with file.beg.

In a unique_ptr<char[]>, I now reserve memory for the heap in which I can store the entire contents of the buffer. With the getn() method, I copy size bytes from the stream buffer into the char array. In this way, I would have transferred the entire stream buffer into a raw char array. For demonstration purposes, I use cout.write(...) to output the contents of char[] to the console.

This time used char[] as a data buffer together with a unique_ptr. Without unique_ptr, you would have had to take care of delete[] in a larger program. This solution is here an alternative to using a vector as a buffer, as you saw in Listing 27.22.

You now know how to use the rdbuf() method to get a stream buffer (of any kind). With the returned pointer, you can now use various methods within the stream to change the position, read characters or entire blocks, and write or reset characters in the stream buffer.

The filebuf class derived from streambuf also contains methods to directly open a file and create a stream buffer. The following code snippet is intended to briefly demonstrate this:

```cpp
std::ofstream file;
std::filebuf bufptr = file.rdbuf();
bufptr->open("file.txt", std::ios::out|std::ios::app);
const char text[]="This goes into the file"; bufptr->sputn(text, sizeof(text)-1);
bufptr->close();
```

In this example, I open or create a file named file.txt and directly associate the file content with the file buffer to perform direct operations on it. In the example, I use the streambuf method sputn() to write the text into the buffer and simultaneously into the file.

stringbuf contains all the methods from the streambuf base class. It also contains the str() method with the same meaning as in the class stringstream, but here in connection with a string stream buffer.

## 27.9 “filesystem”

The <filesystem> header deals less with the contents of files and more with files as a whole and their relationship to each other. Since C++17, it has been part of the standard; previously, it was extensively tested in Boost.Filesystem.

All components of the header are located in the std::filesystem namespace. The most important components are as follows:

- *Class path*
Represents the name of a file or directory. A path can be easily converted into a string or, starting from C++20, into a ustring. With append, you add a path component; with concat, you modify the last path component.

- *Class directory_entry*
Contains metadata about a file or directory.

- *Classes directory_iterator and recursive_directory_iterator*
Allow iterating over all elements of a directory.

- *Helper functions*
Many free functions to facilitate working with permissions, creating directories, copying or deleting entire files, and so on.

In Listing 27.30, you can see an example of how to concatenate paths and obtain some basic information about files.

```cpp
// https://github.org/z/jddKxj7fW
#include <filesystem> // std::filesystem
#include <iostream>
namespace fs { fs = std::filesystem; using std::cout; using std::endl;
int main() {
    // Path components
    fs::path root {"//"};
    fs::path dir {"/var/www/"};
    fs::path index {"index.xhtml"};
    // concatenate
    fs::path p = root / index; // operator/
    // output
    cout << "Name: " << p << endl; // "/var/www/index.html"
    // decompose
    cout << "Parent: " << p.parent_path() << endl; // "/var/www"
    cout << "Extension: " << p.extension() << endl; // ".xhtml"
    // Information
    cout << "Exists? " << fs::exists(p) << endl;
    cout << "Regular file? " << fs::is_regular_file(p) << endl;
}
```

# Listing 27.30 How to concatenate paths.

Using operator/ to concatenate paths is clever and looks good. With p /=, you could directly append an element to p. Both correspond to append.

When you use concat, +, or +=, you extend the last path component, without adding "/".

## 27.10 Formatting

Since C++20, there is a new way to format. The <format> header brings in its own formatter.

```cpp
#include <string>
#include <iostream>
#include <iomanip>
using namespace std; using namespace literals;
void pr(string v) { cout << v << endl; }
double pi = 3.1415926539;

int main() {
    pr("Hello, {}", "Reader"); // simple string
    pr("Hello, {}", "Author"); // simple string
    pr("You are {} years old.\n", 30); // integers
    pr("That makes {:.2f} euros.\n", 19.9933); // 2 decimal places
    pr("Scientific: {:e}\n", -4.876); // results in -4.87600e+01
    pr("Binary of {} is {:b}\n", 42, 42); // binary without base
    pr("Hex of {} is {:x}\n", 73, 73); // hexadecimal
    pr("Zero-padded: {:03d}\n", 7); // results in "007"
    pr("{:<10}|{:<10}|{:>10}\n", "left", "mi", "ri"); // Alignment and index
    pr("{}}\n", "Boa", "Constrictor"); // without index
    using std::chrono;
    pr("{}}\n", 2023y/11/5, minutes(20)); // Output: 2023-11-05, 20min
}
```
