There is also the family of side effect assignments. All arithmetic operations are available in these variants: all expressions are and therefore have a value that you can use as part of a larger expression. However, they are not usually used as expressions, but as instructions like a simple assignment:

```
// https://godbolt.org/z/r5hirgqK9
#include <iostream>
int main() {
    int var = 10;
    var += 2;
    var *= 3;
    var /= 4;
    var -= 5;
    std::cout << var << "\n"; // results in 4
}
```

In addition to -, +, *, and /, there are a few others that I will refer to in Section 4.3 in more detail.
