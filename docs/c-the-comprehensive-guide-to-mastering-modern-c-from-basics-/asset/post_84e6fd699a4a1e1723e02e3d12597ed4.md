# 27.4 Error Handling and Stream States

For streams, it is often not enough to simply check whether something works (true) or not (false). Because various types of errors can occur, the I/O stream provides mechanisms to check the state. The constants are defined in ios_base as public members and can be accessed directly (e.g., ios::goodbit). Table 27.1.

# 27.4.1 Methods for Handling Errors
