+   - Assignment
Assignment is an expression with the equals sign = as an operator, such as x=4. The value of the right operand is assigned to the left operand.

+   - Type casting
Type casting comes in various forms. The C cast uses the target type in parentheses the value to be cast—for example, (int)30.1. Alternatively, you can also use the function notation for this, like int(30.1). A C++ cast also looks similar to a function call, with the target type written in angle brackets—for example, in the expression static_cast<int>(30.1).

If you can master and apply these kinds of expressions, then you are already well equipped. While the listed expressions appear in C programs, the following are typical of C++ and are therefore powerful tools:

+   - Memory management
Allocating with new and deallocating with delete

+   - Lambda expression
An anonymous function that is (usually) defined at the place where it is used

+   - Template usage
When the name of a called function can also include angle brackets <...>, like numeric_limits<int>::is_signed

+   - Throw exception
A throw followed by an expression, as you have briefly seen in Chapter 8
