methods, and vector lacks emplacement_front. The container forward_list lacks
emplace_back.

+   * Other modifications: clear(), erase, insert and merge
clear() simply removes all elements from the container, leaving it with a size
zero. With erase, you can remove a single element using an iterator or an
entire area using a pair. Similarly, you can use insert and an iterator as a
position to insert at a specific spot—a single element (multiple
copies of it), the elements of an initializer list, or an area from another
container using a pair. With merge, you can create one or more\elements at a specified position in the container without copying. Exceptions:
array has no of these methods, and forward_list instead has __after(1)
methods (but does have clear()).

+   * List operation: splice, splice_after, merge and algorithm methods
Only list and forward_list can easily merge ranges of different containers with
slice or splice_after—removing from one and adding to the other. And among
t sequence containers, only these two can merge presorted lists in
sorted order using merge. Because the two list containers do not offer random
access iterators, the free functions from <algorithm> are not applicable to
t. As a substitute, use methods that mimic the algorithms: merge,
remove, remove_if, unique, and sort. Unlike their counterparts
<algorithm>, the remove methods of the lists actually remove the found
elements without just changing their position.
