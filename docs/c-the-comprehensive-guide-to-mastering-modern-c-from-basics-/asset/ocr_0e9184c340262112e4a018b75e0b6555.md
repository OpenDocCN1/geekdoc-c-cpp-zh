+   * ranges::ends_with
Usage: frequent (C++23); iterators: fw
Checks if one range ends with another.

std::search optionally takes an additional parameter, which specifies the algorithm to be used for searching a subsequence in a container (e.g., string):

```
template<forward_iterator It, class Searcher>
ForwardIterator std::search(It first, It last, const Searcher& searcher);
```

At least the well-known Boyer-Moore algorithms like boyer_more_searcher and Boyer-Moore-Horspool algorithms like boyer_more_horspool_searcher are available. These can significantly speed up the search, especially when the search text is long and consists of many different characters. Do not expect a significant speedup when searching for "aaaaaa" or "abababab". You can also let the implementation decide by using default_search. The std::ranges::search variant does not support the Searcher parameter.
