23.6.1 "sizeof ..." Operator  There is indeed an operator with sizeof...() for parameter packs. With this, you can find the number of elements in the parameter pack at compile time. Here is the operator in action:

```
#include <iostream> ... <typename>
template <typename Args>
auto countArgs(Args ... args) {
    return (sizeof ... (args));
}
int main() {
    std::cout << countArgs("one", 2, 3.14) << '\\n'; // Output: 3
}
```
