```
// https://godbolt.org/znpbKT9GEa
#include <array>
#include <numeric> // accumulate
#include <iostream>
template<class T>
int sum(const std::array<int, SZ>& data) {
    int result = 0;
    for(auto i=0; i<SZ; ++i) // us is fix for size_t since C++23
        result += data[i];
    }
    return result;
}

template<typename T, size_t SZ>
Elem elem(const std::array<Elem, SZ>& data) {
    Elem result = 0;
    for(auto i=0; i<SZ; ++i) {
        result += data[i];
    }
    return result;
}

// C++20 concept function with auto
template<input_iterator It>
auto sum(It begin, It end) {
    return std::accumulate(begin, end);
}

// abbreviated function with auto
int sumauto(input_iterator auto begin, std::input_iterator auto end) {
    return std::accumulate(begin, end);
}

int main() {
    array<int, 4> a = {1, 2, 5, 8};
    cout << sumSz(a) << '\n'; // Output: 16
    array<int, 5> b = {1, 5, 3, 7, 2};
    cout << sumElem(b) << '\n'; // Output: 8
    array<int, 6> c = {1, 2, 3, 4, 5, 6};
    cout << sum(c.begin(), c.end()) << '\n'; // Output: 21
    array<int, 7> d = {1, 2, 3, 4, 5, 6, 7};
    cout << sumauto(d.begin(), d.end()) << '\n'; // Output: 28
}
```

**Listing 24.33** Different "arrays" as parameters require template programming.

For demonstration, I call sumSz<4>(a) with the explicit template parameter <4>. It also works without it. And because I don't want to hide from you that the task of summing elements of a container is already solved in the library, I use the corresponding function accumulate from <numeric>. You always have flexibility regarding containers when you use iter as template parameters, as shown here. With array a, can also see that the compiler can deduce both template parameters from the constructor arguments. In sumauto, I use template<std::input_iterator It>, and C++20 concept, which you can replace with template if you are not yet using C++20. In sumauto, auto as a parameter type further shortens the function header to liberate the template syntax.

The array is thus most similar to the fixed-size C-array. array<int, 100> corresponds to int[100]—with the crucial difference that an array does not decay to a pointer and retains its size information even after being passed as a function parameter.
