We run the tool Histogram. Define the input range and select the option for chart output and cumulative percentage. Take the report from Excel by specifying “output range.” Table A10.1 and Figure A10.1 show the histogram of coupling and the cumulative curve, known as ogive. # Interpretation

The coupling histogram is skewed to the right. The tendency of developers seems to produce less complex classes. That is a very good sign. There seems to be a few high complex outlier classes. This appears as a small independent bar on the right.
