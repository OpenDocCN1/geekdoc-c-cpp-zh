# Application of Bayes Theorem in Software Development

Chulani et al. [5] applied the Bayes theorem to software development. The Bayes theorem is elegantly applied to software cost models.

> The Bayesian approach provides a formal process by which a-priori expert judgment can be combined with sampling information (data) to produce a robust a-posteriori model

Posterior = Sample × Prior

> In the above equation “Posterior” refers to the posterior density function summarizing all the information. “Sample” refers to the sample information (or collected data) and is algebraically equivalent to the likelihood function. “Prior” refers to the prior information summarizing the expert judgment. In order to determine the Bayesian posterior mean and variance, we need to determine the mean and precision of the prior information and the sampling information.
