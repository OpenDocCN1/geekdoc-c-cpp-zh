# Exercises

+   1. The median value of a certain data set is 4.5. The data are suspected to have standard Weibull distribution. Calculate the scale shape.
+   2. Plot a Weibull curve with a shape factor of 3 and a scale factor of 15, making use of the Excel function WEIBULL.DIST. (Clue: set the cumulative value = 0.)
+   3. In software review, defect discovery follows the Weibull model with a shape of 2 and a scale of 15 days. Find the remaining defects in the code if review is terminated on day 20.
+   4. Software productivity data (lines of code [LOC] per person day) is fitted to Weibull with the following parameters: location = 30, shape = 3, and scale = 50. Find the probability that productivity will go above 70 LOC/person-day.
+   5. Fit Putnam’s software reliability model to BSPIN data (graphs in Figure 19.8) and predict the percentage of postrelease defect.
