|---|---|---|

# Coefficient of Standard Deviation

This is the ratio of standard deviation to mean. For bug repair time data, the ratio is calculated as follows:

|  |  |
|---|---|---|
| SD | 11.284 |
| Mean | 20.517 |
| Ratio | 0.550 |

This ratio is commonly known as coefficient of variation (COV). It can be expressed as a percentage. For bug repair time data, COV can be expressed as 55%. This is also called relative standard deviation (RSD).
