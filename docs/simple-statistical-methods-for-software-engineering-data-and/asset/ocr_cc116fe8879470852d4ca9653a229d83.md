# Figure 15.2 Triangular estimation—a widely used mental model.

The probability density function (PDF) is split between simple equations to the two straight lines to the peak from the two base points. The equation to the first line, from the left base point to the peak, is given as follows:

```
y(x) = 2(x - a) / ((b - a)(c - a))    (15.1)
```

The equation to the second line, from the peak to the second base point, is given as follows:

```
y(x) = 2(b - x) / ((b - a)(b - c))    (15.2)
```

# Mean

The model statistics are derived from elementary geometrical properties of a triangle. Arithmetic mean is according to the following equation:

```
Mean = (a + b + c) / 3    (15.3)
```
