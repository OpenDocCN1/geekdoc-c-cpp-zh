# BOX 3.2 ICEBERG ANALOGY

Data are like an iceberg. The peak contains only 15% of ice. The remaining 85% is beneath the water level, unseen by the onlooker. The unseen ice details could do great harm to ships. Likewise, the central values constitute just the tip. The real process behavior is in the spread of data. The true behavior of a process is understood when the spread is also recognized.
