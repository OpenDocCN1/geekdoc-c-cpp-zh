# BOX 17.2  LOGARITHMIC SCALE

The human ear responds to sound in a logarithmic scale; the response has an amazing dynamic range, from extremely small to extremely large sound. Such a range is possible if the scale were logarithmic. If the sound level increases tenfold, the response increases one notch. Sound level is measured in decibels, logarithms to the base 10 of sound intensities.
