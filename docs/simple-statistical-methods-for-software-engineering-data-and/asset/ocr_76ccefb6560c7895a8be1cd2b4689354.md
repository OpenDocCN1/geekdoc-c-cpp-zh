The tools predictions turned out to be different from the intuitive predictions of the software team. When we tried to understand the reason, we found that the testing was done quite randomly.

Table 21.1 gives an example. Defects found during six weeks of testing are tabulated. Test cases executed have been included in the table to set the context and environment. Figure 21.7 contains the cumulative plot of defects. Apparently, the curve is not Gompertzian. There is a hike in the number of test cases executed that corresponds to the hike in the defects discovered.

In the tool, we were looking at only the week number and number of defects. We had ignored very crucial data in number of test cases executed. So, instead of looking at the absolute number of defects, we started looking at the defects in the context of the test cases executed every week.
