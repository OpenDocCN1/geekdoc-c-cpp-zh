```
Skew = √2 (a + b - 2c)(2a - b - c)(a - 2b + c) / [5 (a² + b² + c² - ab - ac - bc)^(3/2)] (15.7)
```

Equation 15.7 is used to construct a relationship between skew and mode c for a given a = 0 and b = 10. A graph of the relationship is plotted in Figure 15.6.
