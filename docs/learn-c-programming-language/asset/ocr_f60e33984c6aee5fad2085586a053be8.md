```
# Function-Like Macros

You can use #define to define a macro which will take argument as follows:

```
```cpp
#include <iostream>
using namespace std;

#define MIN(a,b) (((a)<(b)) ? a : b)

int main ()
{
    int i, j;
    i = 100;
    j = 30;
    cout <<"The minimum is " << MIN(i, j) << endl;

    return 0;
}
```
