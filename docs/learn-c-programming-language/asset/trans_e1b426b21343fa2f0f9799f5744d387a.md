

按照惯例，如果指针包含空（零）值，则它被认为不指向任何内容。

要检查空指针，可以使用如下所示的 `if` 语句：

```cpp
if(ptr)    // succeeds if p is not null

if(!ptr)   // succeeds if p is null
```

因此，如果所有未使用的指针都被赋予空值，并且你避免使用空指针，就可以避免意外误用未初始化的指针。很多时候，未初始化的变量会持有一些垃圾值，这会使程序调试变得困难。

## 指针算术

正如你所了解的，指针是一个地址，而地址是数值；因此，你可以像对数值进行算术运算一样，对指针执行算术运算。有四个算术运算符可用于指针：`++`、`--`、`+` 和 `-`。

为了理解指针算术，假设 **ptr** 是一个整型指针，指向地址 1000。假设整数为 32 位，让我们对指针执行以下算术运算：

```cpp
ptr++
```

**ptr** 将指向位置 1004，因为每次 `ptr` 递增时，它都会指向下一个整数。此操作会将指针移动到下一个内存位置，而不会影响该内存位置上的实际值。如果 `ptr` 指向一个字符，其地址为 1000，那么上述操作将指向位置 1001，因为下一个字符将在 1001 处可用。

## 递增指针

在程序中，我们更倾向于使用指针而不是数组，因为变量指针可以递增，而数组名不能递增，因为它是一个常量指针。下面的程序通过递增变量指针来访问数组的每一个连续元素：

```cpp
#include <iostream>

using namespace std;

const int MAX = 3;

int main ()
{
    int var[MAX] = {10, 100, 200};
    int *ptr;

    // let us have array address in pointer.
    ptr = var;
    for (int i = 0; i < MAX; i++)
    {
        cout << "Address of var[" << i << "] = ";
        cout << ptr << endl;

        cout << "Value of var[" << i << "] = ";
        cout << *ptr << endl;

        // point to the next location
        ptr++;
    }
    return 0;
}
```

编译并执行上述代码后，会产生类似以下的结果：

```text
Address of var[0] = 0xbfa088b0
Value of var[0] = 10
Address of var[1] = 0xbfa088b4
Value of var[1] = 100
Address of var[2] = 0xbfa088b8
Value of var[2] = 200
```

## 递减指针

递减指针也适用同样的考虑，指针按其所指数据类型的字节数减少其值，如下所示：

```cpp
#include <iostream>

using namespace std;

const int MAX = 3;

int main ()
{
    int var[MAX] = {10, 100, 200};
    int *ptr;

    // let us have address of the last element in pointer.
    ptr = &var[MAX-1];
    for (int i = MAX; i > 0; i--)
    {
        cout << "Address of var[" << i << "] = ";
        cout << ptr << endl;

        cout << "Value of var[" << i << "] = ";
        cout << *ptr << endl;

        // point to the previous location
        ptr--;
    }
    return 0;
}
```

编译并执行上述代码后，会产生类似以下的结果：

```text
Address of var[3] = 0xbfdb70f8
Value of var[3] = 200
Address of var[2] = 0xbfdb70f4
Value of var[2] = 100
Address of var[1] = 0xbfdb70f0
Value of var[1] = 10
```

## 指针比较

指针可以使用关系运算符（如 `==`、`<` 和 `>`）进行比较。如果 `p1` 和 `p2` 指向彼此相关的变量，例如同一数组中的元素，那么 `p1` 和 `p2` 的比较是有意义的。

下面的程序修改了前面的示例，只要变量指针指向的地址小于或等于数组最后一个元素的地址（即 `&var[MAX - 1]`），就继续递增该指针：

```cpp
#include <iostream>

using namespace std;

const int MAX = 3;

int main ()
{
    int  var[MAX] = {10, 100, 200};
    int *ptr;

    // let us have address of the first element in pointer.
    ptr = var;
    int i = 0;
    while ( ptr <= &var[MAX - 1] )
    {
        cout << "Address of var[" << i << "] = ";
        cout << ptr << endl;

        cout << "Value of var[" << i << "] = ";
        cout << *ptr << endl;

        // point to the next location
        ptr++;
        i++;
    }
    return 0;
}
```

编译并执行上述代码后，会产生类似以下的结果：

```text
Address of var[0] = 0xbfce42d0

Value of var[0] = 10

Address of var[1] = 0xbfce42d4

Value of var[1] = 100

Address of var[2] = 0xbfce42d8

Value of var[2] = 200
```

## 指针与数组

指针和数组关系密切。实际上，在许多情况下，指针和数组是可以互换的。例如，指向数组首元素的指针既可以使用指针算术，也可以使用数组风格的下标来访问该数组。请看下面的程序：

```cpp
#include <iostream>

using namespace std;

const int MAX = 3;

int main ()
{
    int var[MAX] = {10, 100, 200};
    int *ptr;

    // let us have array address in pointer.
    ptr = var;
    for (int i = 0; i < MAX; i++)
    {
        cout << "Address of var[" << i << "] = ";
        cout << ptr << endl;

        cout << "Value of var[" << i << "] = ";
        cout << *ptr << endl;

        // point to the next location
        ptr++;
    }
    return 0;
}
```

编译并执行上述代码后，会产生类似以下的结果：

```text
Address of var[0] = 0xbfa088b0

Value of var[0] = 10

Address of var[1] = 0xbfa088b4

Value of var[1] = 100

Address of var[2] = 0xbfa088b8

Value of var[2] = 200
```

然而，指针和数组并不能完全互换。例如，请看下面的程序：

```cpp
#include <iostream>

using namespace std;

const int MAX = 3;

int main ()
{
    int  var[MAX] = {10, 100, 200};

    for (int i = 0; i < MAX; i++)
    {
        *var = i;   // This is a correct syntax

        var++;      // This is incorrect.
    }
    return 0;
}
```

对 `var` 应用指针运算符 `*` 是完全合法的，但修改 `var` 的值则是非法的。原因是 `var` 是一个指向数组首元素的常量，不能用作左值。

由于数组名生成一个指针常量，只要不被修改，它就仍可用于指针风格的表达式。例如，下面这个为 `var[2]` 赋值为 500 的语句是有效的：

```cpp
*(var + 2) = 500;
```

上面的语句有效，并且会成功编译，因为 `var` 没有被修改。

## 指针数组

在理解指针数组的概念之前，先看下面的例子，它使用了一个包含 3 个整数的数组：

```cpp
#include <iostream>

using namespace std;

const int MAX = 3;

int main ()
{
    int  var[MAX] = {10, 100, 200};

    for (int i = 0; i < MAX; i++)
    {
        cout << "Value of var[" << i << "] = ";
        cout << var[i] << endl;
    }
    return 0;
}
```

编译并执行上述代码后，会产生以下结果：

```text
Value of var[0] = 10

Value of var[1] = 100

Value of var[2] = 200
```

有时候，我们可能需要维护一个数组，该数组可以存储指向 `int`、`char` 或任何其他可用数据类型的指针。下面是一个指向整数的指针数组的声明：

```cpp
int *ptr[MAX];
```

这条语句将 `ptr` 声明为包含 `MAX` 个整型指针的数组。因此，`ptr` 中的每个元素现在都持有一个指向 `int` 值的指针。下面的示例使用了三个整数，它们将按如下方式存储在一个指针数组中：

```cpp
#include <iostream>
```

```cpp
char *names[MAX] = {
                "Zara Ali",
                "Hina Ali",
                "Nuha Ali",
                "Sara Ali",
};

for (int i = 0; i < MAX; i++)
{
    cout << "Value of names[" << i << "] = ";
    cout << names[i] << endl;
}
return 0;
}
```

编译并执行上述代码后，会产生以下结果：

```text
Value of names[0] = Zara Ali

Value of names[1] = Hina Ali

Value of names[2] = Nuha Ali

Value of names[3] = Sara Ali
```

指向指针的指针是一种多重间接引用形式，也就是一条指针链。通常，指针包含一个变量的地址。当我们定义一个指向指针的指针时，第一个指针包含第二个指针的地址，而第二个指针指向包含实际值的位置，如下图所示。

```cpp
int **var;
```
