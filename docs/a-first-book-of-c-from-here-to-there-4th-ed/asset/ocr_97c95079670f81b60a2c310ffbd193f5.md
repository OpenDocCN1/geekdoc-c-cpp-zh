Figure 12.12 Including attributes in UML class and object diagrams

Attributes have two qualities: type and visibility. An attribute's type is either a primitive data type—such as integer, double, Boolean, or character—or for a class data type, such as a string. Type is required in a class diagram and is indicated after an attribute name with a colon followed by the data type.
