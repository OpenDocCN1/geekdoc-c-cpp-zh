Notice that after each object is retrieved from the list, the underlying class's accessor methods extract name and phoneNum values. Because the dot operator has a left-to-right associativity, an expression such as employee.front().getName() is interpreted as (employee.front()).getName(). Therefore, the STL list class's front() method is used to return the front object from the list, which is then further processed by the NameTele class's getName() method.
