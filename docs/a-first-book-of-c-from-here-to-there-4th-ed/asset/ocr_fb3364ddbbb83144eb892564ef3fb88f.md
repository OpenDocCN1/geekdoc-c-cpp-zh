# 12. (Program) Write a C++ program that allows users to enter the following information from the keyboard for each student in a class (up to 20 students) and stores the data in a text file named grade.dat:

Name    Exam 1 Grade    Exam 2 Grade    Homework Grade    Final Exam Grade

For each student, your program should first calculate a final grade, using this formula:
Final Grade = 0.20 × Exam 1 + 0.20 × Exam 2 + 0.35 × Homework + 0.25 × Final Exam

Then assign a letter grade on the basis of 90–100 = A, 80–89 = B, 70–79 = C, 60–69 = D, and less than 60 = F. All the information, including the final grade and the letter grade, should then be displayed and written to a file.
