# 12.1 Class Inheritance

Constructing one class from another is accomplished by using **inheritance**, which is the capability of deriving one class from another class. An equally important and related feature called **polymorphism** allows redefining how member functions of the same name operate, based on an object’s class. This section describes C++’s inheritance features, and polymorphism is discussed in Section 12.2.

The class used as the basis for a derived class is referred to as the **base class**, **parent class**, or **superclass**. The **derived class**, also referred to as the **child class** or **subclass**, is a new class incorporating all data members and member functions of its base class. However, it can, and usually does, add its own new data members and member functions and can override any base class function.

As an example of inheritance, consider three geometric shapes: a circle, a cylinder, and a sphere. All these shapes share a common characteristic—a radius. Therefore, you can make the circle a base type for the other two shapes, as shown in Figure 12.1. By convention, arrows always point from the derived class to the base class. In this example, the circle is the base class, and the cylinder and sphere are the derived classes.
