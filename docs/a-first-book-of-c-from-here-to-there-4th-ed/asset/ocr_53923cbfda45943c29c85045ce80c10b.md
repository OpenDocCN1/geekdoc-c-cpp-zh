Program 3.9 shows using the sqrt() function to determine the time it takes a ball to hit the ground after it has been dropped from an 800-foot tower. The mathematical formula for calculating the time in seconds it takes for the ball to fall a given distance in feet is as follows, where g is the gravitational constant equal to 32.2 ft/sec²:

time = sqrt(2 × distance / g)

# Program 3.9

![](bbox=[0.1, 0.7, 0.18, 0.78])

```
#include <iostream> // this line can be placed second instead of first
#include <cmath> // this line can be placed first instead of second
using namespace std;

int main()
{
    int height;
    double time;

    height = 800;
    time = sqrt(2 * height / 32.2);
    cout << "It will take " << time << " seconds to fall "
         << height << " feet.\n";

    return 0;
}
```
