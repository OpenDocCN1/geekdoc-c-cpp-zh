# ## 3.2.2 数据链路层

数据链路层是OSI参考模型的第二层，位于物理层之上、网络层之下。它的主要任务是负责在两个相邻节点之间可靠地传输数据帧。

数据链路层的主要功能包括：

+   - 封装成帧
+   - 透明传输
+   - 差错检测
+   - 可靠传输

数据链路层使用的信道主要有以下两种类型：

+   1. 点对点信道
+   2. 广播信道

点对点信道使用一对一的通信方式，而广播信道使用一对多的通信方式。在广播信道上连接的主机很多，因此必须使用专用的共享信道协议来协调这些主机的数据发送。

| 信道类型 | 通信方式 | 典型协议 |
|---------|---------|---------|
| 点对点信道 | 一对一 | PPP协议 |
| 广播信道 | 一对多 | CSMA/CD协议 |

数据链路层的协议数据单元是帧（Frame），帧由帧头、数据部分和帧尾组成。帧头包含目的地址和源地址等信息，帧尾包含差错检测码。
