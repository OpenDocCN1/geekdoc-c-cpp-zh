In main(), the file is an ostream object named outFile. This object is passed to the inOut() function and accepted as the formal parameter fileOut, which is declared as a reference to an ostream object type. The inOut() function then uses its reference parameter outFile as an output file stream name in the same manner that main() would use the fileOut stream object. Program 9.8 uses the getline() method introduced in Section 9.2 (see Table 9.3).

Program 9.9 expands on Program 9.8 by adding a getOpen() function to perform the open. Like inOut(), getOpen() accepts a reference argument to an ofstream object. After getOpen() finishes executing, this reference is passed to inOut(), as in Program 9.8. Although you might be tempted to write getOpen() to return a reference to an ofstream, it won’t work because it results in an attempt to assign a returned reference to an existing one.
