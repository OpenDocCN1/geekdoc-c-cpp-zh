# 重新审视亚利桑那马主感知需求，以更新并聚焦合作扩展马术教育计划及资源开发方向







期刊主页：www.j-evs.com


https://doi.org/10.1016/j.jvet.2023.104516

## 170 重新审视亚利桑那州马主感知的需求，以更新并重点关注合作推广马类教育计划和资源开发

E.A. Greene1*, J.F. Trott2, J.K. Beard3†

1 亚利桑那大学，亚利桑那州图森森，美国
2 加利福尼亚大学戴维斯分校，加利福尼亚州，美国

2021年，使用 Qualtrics® 软件对匿名在线牲畜/股权调查（最初于2015年发布）进行了重新调查，通过社交媒体、参与者以及推广活动的参会者分发给亚利桑那行业的利益相关者。我们将2021年的回复与2015年的回复（在280名马主中共收到118/233份回复）进行了比较，以更新并在必要时将教育计划的重点转向亚利桑那州马主的关键需求。结果涵盖了亚利桑那州的所有15个县，并根据马的数量分类（1–3匹、4–6匹、7–9匹和10匹及以上）。数据集使用卡方检验进行独立分析。2021年拥有1–3匹马的主者存在显著差异（P < 0.05），且更多受访者将马用于休闲骑乘（P < 0.05），更多拥有≥10匹马的主者将其用于经营（P < 0.05）。在2015年，对信息传递方式的偏好受受访者年龄显著影响，70%的0–69岁和70岁及以上的受访者倾向于实地操作活动日（P < 0.05）。此外，50–69岁的受访者想要事实资料表（P < 0.05）。在2021年，70岁及以上的受访者对虚拟研讨会的反应较小（P < 0.05）。调查者根据关键需求对与马饲养、管理、训练、马健康、经营规划相关的22个主题分别进行了排名：无需求、中度需求或关键需求。2021年的主题排名显示了主者的需求范围（关键需求）；包括毒植物、接种计划和跛行；包括热量、利用亚利桑那马匹及行为、蹄部护理。在2015年，拥有≥10匹马的主者对管理（P < 0.05）和热应激（P < 0.05）教育有较高需求，但在2021年，马主并未感知到热应激教育的关键需求。需求较高的主题在2021年和2015年相似，这允许我们继续目前的计划领域和重点，尽管我们发现受访者的年龄影响了他们对信息传递方式的偏好，并且我们需要继续拥有1–3匹马的休闲马主持续热应激教育。

**关键词：** 利益相关者调查，推广计划，马
