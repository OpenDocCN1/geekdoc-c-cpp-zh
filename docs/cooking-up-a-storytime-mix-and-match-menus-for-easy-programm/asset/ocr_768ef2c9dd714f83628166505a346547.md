# Subitizing Snowmen

Here’s another flannelboard to help children practice  
subitizing.

![](bbox=[0.713, 0.306, 0.909, 0.469])

Here’s a snowman standing tall.  
Can we count him, one and all?

*(Count the snowman and then ask, “How many?”)*

Another snowman standing tall.  
Can we count them, one and all?

*(Count the snowmen and then ask, “How many?” Add up to six snowmen.)*
