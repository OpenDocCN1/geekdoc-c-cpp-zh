# Code: Overloading a Binary Operator

```
#include <iostream>
using namespace std;
class myclass
{
    public:
    int m,n;
    void display()
    {
        cout<<"\nEnter any two numbers\n";
        cin>>m>>n;
    }
    int operator - ()
    {
        return m-n;
    }
};

int main()
{
    myclass obj;
    int r;
    obj.display();
    r= -obj;
    cout<<"Difference is "<<r <<endl;
    return 0;
}
```

Enter any two numbers
23
67
Difference is -44
