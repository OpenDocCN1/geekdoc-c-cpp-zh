# Code: Working with Structures

```
#include <iostream>
using namespace std;
struct OurStructure {
    int x;
    char c;
};
int main()
{
    struct OurStructure s1 = { 240,'S' };
    struct OurStructure* s2 = &s1;
    cout << "The value is : "<< s2->x << endl;
    cout << "The value is : "<< s2->c << endl;
    cout<<"Size of structure : "<<sizeof(s1)<<endl;
    return 0;
}
```

# Output:

The value is : 240
The value is : S
Size of structure : 8
