+   - **break:** Breaking out of a difficult and unwanted situation is important for the code’s “health,” so this statement terminates the loop and executes the next statement.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 0; i < 6; i++) {
        if (i == 4) {
            break;
        }
        cout << i << "\\n";
    }
    return 0;
}
```
```

# **Output:**

```
0
1
2
3
```
