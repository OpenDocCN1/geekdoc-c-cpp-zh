# Code: Implementing Parameterized Constructors

```
```cpp
#include <iostream>
using namespace std;
class People
{
    public:
    int x;

};
int main() {
    People Object1;
    cout<<"\nWill be provided with any random value:
        "<<Object1.x<<endl;
//Garbage value would be shown as x is not initialized

    return 0;
}
```
```

# Output:

Will be provided with any random value: 9015333
