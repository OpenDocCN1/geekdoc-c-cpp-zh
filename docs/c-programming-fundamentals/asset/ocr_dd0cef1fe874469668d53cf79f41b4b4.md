# Code: Working with Structure

```
```cpp
#include <iostream>
using namespace std;
struct OurStructure {
        int x;
        char c;

};
int main()
{

        struct OurStructure  s1;
        s1.x = 85;
        s1.c = 'G';
        cout << "The value is : "<< s1.x << endl;
        cout << "The value is : "<< s1.c << endl;
        cout<<"Size of structure : "<<sizeof(s1)<<endl;
        return 0;
}
```
```

# Output:

```
The value is : 85
The value is : G
Size of structure : 9
