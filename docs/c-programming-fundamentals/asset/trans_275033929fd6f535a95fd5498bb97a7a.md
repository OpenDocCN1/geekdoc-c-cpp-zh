## 30. 以下 C++ 代码的输出是什么？

```cpp
#include <iostream>
using namespace std;
int main()
{
    int var = -12;
    try {
        cout<<"Inside try\n";
        if (var < 0)
        {
            throw var;
            cout<<"After throw\n";
        }
    }
    catch (int var) {
        cout<<"Exception Caught\n";
    }
    cout<<"After catch\n";
    return 0;
}
```

- **a.** 在 try 内<br>捕获异常<br>在 catch 之后
- **b.** 在 try 内<br>在 throw 之后<br>在 catch 之后
- **c.** 在 try 内<br>捕获异常<br>在 throw 之后
- **d.** 在 try 内<br>捕获异常<br>在 throw 之后<br>在 catch 之后
