# C.4.1 The evaluation of \( N_3 \)

In the calculation of the American Put approximation of Geske and Johnson (1984), a trivariate normal needs to be evaluated. Following the discussion in the paper, this is evaluated as

```
N_3(h, k, j; \rho_{12}, \rho_{13}, \rho_{23}) = \int_{-\infty}^{j} n(z) N_2 \left( \frac{k - \rho_{23}z}{\sqrt{1 - \rho_{23}^2}}, \frac{h - \rho_{13}z}{\sqrt{1 - \rho_{13}^2}} \bigg| \frac{\rho_{12} - \rho_{13}\rho_{23}}{\sqrt{1 - \rho_{13}^2}\sqrt{1 - \rho_{23}^2}} \right)
```
