# PROBLEM 5.5

The *addition theorem* for the spherical harmonics equates the summed products of all spherical harmonics for a particular order *l* and given angles $(\theta_1,\varphi_1)$ and $(\theta_2,\varphi_2)$ with the Legendre polynomial of order *l*,

$$P_l(\cos\gamma)=\frac{4\pi}{2l+1}\sum_{m=-l}^{m=l}Y_{lm}^{*}(\theta_2,\varphi_2)Y_{lm}(\theta_1,\varphi_1), \tag{5.70}$$

where $\gamma$ is the angle between directions $(\theta_1,\varphi_1)$ and $(\theta_2,\varphi_2)$, which can be expressed as

$$\cos\gamma=\cos\theta_1\cos\theta_2+\sin\theta_1\sin\theta_2\cos(\varphi_1-\varphi_2), \tag{5.71}$$

and the spherical harmonics $Y_{lm}(\theta,\varphi)$ are defined in Equation 5.35. Using routines Legendre and SpherY included in files `specfunc.py` and, respectively, `specfunc.h`, write Python and C/C++ programs to check the addition theorem for $l=5$ and the angle combination $\theta_1=\pi/9$, $\varphi_1=\pi/3$, $\theta_2=\pi/3$, $\varphi_2=\pi/8$.
