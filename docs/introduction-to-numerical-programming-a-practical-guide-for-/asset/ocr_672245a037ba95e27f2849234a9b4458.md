# PROBLEM 8.3

Consider the tetragonal methane molecule CH₄, characterized by the relative atomic masses m_C = 12 and m_H = 1, and by the following Cartesian positions of the 5 atoms in a body-fixed reference frame (in Å):

```
x = [0.000  0.635  -0.635  -0.635   0.635],
 y = [0.000  0.635  -0.635   0.635  -0.635],
 z = [0.000  0.635   0.635  -0.635  -0.635],
 r = [1.700  1.200   1.200   1.200   1.200].
```

The C atom is located at the origin and the quantities r represent the van der Waals radii of the atoms (Bondi 1964).

+   a. Place the molecule in its center-of-mass system by subtracting from the individual coordinates the coordinates of the mass center:

```
x_CM = 1/m_CM Σ_i m_i x_i,   y_CM = 1/m_CM Σ_i m_i y_i,   z_CM = 1/m_CM Σ_i m_i z_i,
```

where

```
m_CM = Σ_i m_i
```

is the total mass of the system of atoms.

+   b. Calculate the inertia tensor of the molecule in its Cartesian center-of-mass system:

