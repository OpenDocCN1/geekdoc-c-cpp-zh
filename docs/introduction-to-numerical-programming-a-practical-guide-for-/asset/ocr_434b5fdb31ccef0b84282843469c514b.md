**Listing 10.12** Gauss–Legendre Integrator (Python Coding)

```python
#===============================================================================
def qGaussLeg(Func, a, b, n):
#-------------------------------------------------------------------------------
#  Integrates function Func on interval [a,b] using n-point Gauss-Legendre
#  quadratures
#  Calls: xGaussLeg
#-------------------------------------------------------------------------------

    x = [0]*n
    w = [0]*n


    (x,w) = xGaussLeg(a,b,n)

    s = 0e0
    for i in range(0,n) : s += w[i] * Func(x[i])

    return s

For the more general case of a finite but nonzero lower boundary *a* and an integrand not featuring explicitly an exponential factor, the Gauss–Laguerre quadrature formula can be rewritten as

$$\int_a^\infty f(x)\,dx \approx \sum_{i=1}^{n} w_i f(x_i+a), \tag{10.79}$$

$$w_i=\frac{\exp(x_i)}{x_i[L_n'(x_i)]^2},\qquad i=1,2,\ldots,n. \tag{10.80}$$

The function `xGaussLag` (Listing 10.13) returns the integration abscissas x and weights w for the n-point Gauss–Laguerre integration on the interval [*a*, +∞) and its overall structure is similar to the one of function `xGaussLeg`. The initial approximations of the zeros are taken from Stroud and Secrest (1966) and Stroud (1971), and have been commonly used in similar implementations (see, e.g., Press et al. 2007; Beu 2004).
