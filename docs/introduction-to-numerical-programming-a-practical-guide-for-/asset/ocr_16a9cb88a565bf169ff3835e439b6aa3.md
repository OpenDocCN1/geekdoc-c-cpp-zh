If x1 < x2 < ⋯ < xM are the zeros of f′(x) and one forms Rolle’s sequence, f(−∞),f(x1),f(x2),…,f(xM),f(+∞), then, according to the mentioned consequence, each subinterval,

Consequently, the equation f(x) = 0 possesses as many zeros as the sign changes shown by Rolle’s sequence. From a practical point of view, this approach has an important drawback, since it implies solving the equation f′(x) = 0, which can be sometimes as cumbersome as solving the original equation f(x) = 0. The following theorem has direct practical utility for separating zeros of functions.

# Theorem 6.1

If a continuous real-valued function f(x) changes sign at the ends of a closed interval [a,b], that is, f(a)f(b) < 0, then the interval contains at least a real zero of f(x); in other words, there exists at least an interior point ξ ∈ (a,b) so that f(ξ) = 0.

The root ξ is unique in [a,b] if the derivative f′(x) exists and preserves its sign. Otherwise, it is possible that [a,b] contains multiple roots (as in Figure 6.2a) and, moreover, this is possible even if f(a)f(b) > 0 (as in Figure 6.2b).
