Here, we use the function `Matrix` from the include file `memalloc.h` to dynamically allocate the array `u[][]` of the function values. The function is sampled on a regular grid with nx × ny nodes. As limiting values for the contour plot, the routine `Contour` receives the minimum and maximum function values. The resulting plot is identical with the one shown in Figure 3.11.
