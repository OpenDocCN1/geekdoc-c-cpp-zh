The routine QuickSort (Listing 4.4) is a one-to-one implementation of the described algorithm. The indexes l and n, passed as arguments, define the subarray of the array x[] that is to be sorted at a given call, and they are particularly meaningful in the context of recursivity. Considering as pivot the last element, x[n], Quicksort starts with a void “<”-array, identifying its upper index m with the lower array index, l. The algorithm then scans for elements smaller than the pivot. Each such element is swapped to the end of the “<”-list, which is thus expanded. Once no element smaller than the pivot is found, the partitioning into the “<”- and “≥”-arrays is considered finalized and the pivot is swapped with the first element of the “≥”-array, acquiring its final sorted position between the “<”- and “≥”-arrays. The “<”- and “≥”-arrays are next sorted recursively by self-calls of Quicksort. The exit from recursivity occurs as soon as the condition l>=n no longer holds.
