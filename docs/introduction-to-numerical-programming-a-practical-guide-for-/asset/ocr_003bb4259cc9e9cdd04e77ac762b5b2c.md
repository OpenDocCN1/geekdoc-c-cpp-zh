# PROBLEM 9.9

Build a program calling the routine MultiFit to perform the real Fourier analysis of observational data by multilinear regression.

The Fourier series for an arbitrary real function may be written as

```
f(x) = a₁ + Σᵢ₌₁ (a₂ᵢ cos i x + a₂ᵢ₊₁ sin i x).
```

The involved cosines and sines can be calculated most efficiently by using the recurrences

```
cos i x = cos x cos(i − 1)x − sin x sin(i − 1)x,

sin i x = sin x cos(i − 1)x + cos x sin(i − 1)x,
```

started with cos 0 = 1 and sin 0 = 0. Indeed, the procedure involves the effective evaluation of a single cos x and a single sin x at the beginning of the recurrence.

In the case of odd functions, f(−x) = −f(x), the Fourier series reduces to the Fourier sine series, f(x) = Σᵢ aᵢ sin i x, whereas for even functions, f(−x) = f(x), the so-called Fourier cosine series is applied, f(x) = a₁ + Σᵢ aᵢ cos i x.
