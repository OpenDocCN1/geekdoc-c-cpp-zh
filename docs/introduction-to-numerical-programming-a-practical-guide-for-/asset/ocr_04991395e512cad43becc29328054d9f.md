# 5.3 Continued Fractions

A mathematical expression implying recursive summations of fractions in the successive denominators, that is,

a0 + b1/(a1 + b2/(a2 + ⋯)) ≡ [a0; b1/a1, b2/a2, …, bi/ai, …] (5.16)

is called a continued fraction. The elements ai and bi (i = 0, 1, 2, …) can be either numbers or functions. A finite (or terminating) continued fraction is one having a finite number of elements and it is identical with the common fraction obtained by successive reductions to a common denominator, starting from the highest-index elements. In the case of an infinite (or nonterminating) continued fraction, the evaluation cannot be simplified to reductions to a common denominator, and certainly not in a finite number of steps.

For example, the number e = 2.71828… admits the continued-fraction representation:

e = [1; 1/1, -1/2, 1/3, -1/2, 1/5, -1/2, …].

We call convergents of a continued fraction the expressions:

R1 = a0 + b1/a1, R2 = a0 + b1/(a1 + b2/a2), …

Ri being the i-th-order convergent.

A continued fraction is said to be convergent if the series of convergents has a limit

A = lim_{i→∞} Ri,

and this value is attributed to the fraction. If the limit does not exist, the fraction is termed divergent.
