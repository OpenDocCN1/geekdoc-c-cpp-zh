You can save specific search items to a Favorites list by clicking the icon that appears at the right end of the search list next to each article.

To add the 3ds Max 2011 Bible PDF to InfoCenter, follow these steps:

+   1. Locate and copy the 3ds Max 2011 Bible PDF from the book's DVD to a location on your hard drive.
+   2. Select the Add Search Location option from the Search pop-up menu by clicking the Search icon in the InfoCenter toolbar.
+   3. Click the Browse button, locate the saved location of the book's PDF, and click OK. The book's PDF is added to the InfoCenter list.

# Viewing the Essential Skills Movies

When Max loads, users are greeted with a Learning Movies dialog box, shown in Figure 1.17, that includes six Essential Skills Movies (seven movies are available in 3ds Max 2009 Design). These simple movies explain the basics of working with Max.

The Learning Movies dialog box also includes links to What's New and to Learning Path, which are pages on the Autodesk Web site where you can find more tutorials and resources. After viewing the Essential Skills Movies, you can disable the Show this dialog at startup option to prevent this dialog box from appearing the next time you start Max. You can access the Learning Movies dialog box at any time using the Help menu.

# Note

The Essential Skills Movies require an installation of QuickTime.
