# Time toolbar

The Time toolbar is one of the default toolbars for the Dope Sheet. It is used to work with time ranges. Table 36.4 describes these buttons.

**TABLE 36.4**

**Time Toolbar Buttons**

| Toolbar Button | Name | Description |
|---|---|---|
| [图标] | Select Time | Enables you to select a block of time by clicking and dragging |
| [图标] | Delete Time | Deletes the selected block of time |
| [图标] | Reverse Time | Reverses the order of the selected time block |
| [图标] | Scale Time | Scales the current time block |
| [图标] | Insert Time | Inserts an additional amount of time |
| [图标] | Cut Time | Deletes the selected block of time and places it on the clipboard for pasting |
| [图标] | Copy Time | Makes a copy of the selected block of time and places it on the clipboard for pasting |
| [图标] | Paste Time | Inserts the current clipboard time selection |
