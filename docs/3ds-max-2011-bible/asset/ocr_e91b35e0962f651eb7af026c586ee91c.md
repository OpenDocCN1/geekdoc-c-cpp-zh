# Saving Animation Files

Before an animation sequence can be mixed in the Motion Mixer, it must be saved. The Motion Mixer easily can load any existing animation sequence in the current opened Max file, but saving a sequence to the local hard disk makes it accessible for other Max scenes. The Motion Mixer can be accessed using the Graph Editors Motion Mixer menu command. More on the Motion Mixer is presented later in this chapter.
