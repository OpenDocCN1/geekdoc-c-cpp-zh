# Part X: Dynamic Animation

The Bitmap and Map buttons let you load images to use as a displacement map; the amount of displacement corresponds with the brightness of the image. A Blur setting blurs the image. You can apply these maps with different mapping options, including Planar, Cylindrical, Spherical, and Shrink Wrap. You can also adjust the Length, Width, and Height dimensions and the U, V, and W Tile values.

# Deflector Space Warps

The Deflectors subcategory of Space Warps includes PDynaFlect, SDynaFlect, UDynaFlect, POmniFlect, SOmniFlect, UOmniFlect, Deflector, SDeflector, and UDeflector. You use them all with particle systems, but only the DynaFlect Space Warps can be used with dynamic objects. This category includes several different types of deflectors starting with P, S, and U. The difference between these types is in their shape. P-type (planar) deflectors are box shaped, S-type (spherical) deflectors are spherical, and U-type (universal) deflectors include a Pick Object button that you can use to select any object as a deflector.
