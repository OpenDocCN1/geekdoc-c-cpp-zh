To load a map node into the Node View panel of the Slate Material Editor, simply double-click on it or drag the material from the Material/Map Browser to the Node View panel. All map nodes are easily identified by their green title bars in the Node View and Navigator panels.

# Connecting maps to materials

A map by itself in the Node View panel cannot be applied to objects in the scene. To add a map to a material it must be connected to one of the material properties. This is done by dragging on the map node's output socket and dropping the connecting line on the input socket for the material property where the map is being applied.
