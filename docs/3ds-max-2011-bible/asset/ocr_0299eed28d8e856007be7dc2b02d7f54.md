# Applying out-of-range, ease, and multiplier curves

Out-of-range curves define what the curve should do when it is beyond the range of specified keys. For example, you could tell the curve to loop or repeat its previous range of keys. To apply these curves, select a track and click the Parameter Curve Out-of-Range Types button on the Curves toolbar (or select the Out-of-Range menu command from the Controller menu). This opens a dialog box, shown in Figure 36.17, where you can select from the available curve types.

# Note

You can also apply an out-of-range curve to a select range of frames using the Create Out-of-Range Keys utility. This utility is available via the Track View Utilities button.
