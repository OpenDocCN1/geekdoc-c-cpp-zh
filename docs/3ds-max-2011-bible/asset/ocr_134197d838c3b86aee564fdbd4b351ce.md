+   3. With the plane object selected, choose the Modifiers ▸ Cloth ▸ Cloth menu command to apply the Cloth modifier to the object.

+   4. Open the Modifier panel, and click the Object Properties button in the Object rollout to open the Object Properties dialog box. Select the Plane01 object in the left list, and choose the Cloth option. Then select the Silk option from the Presets drop-down list, and set the Thickness to 0.5.

+   5. With the Object Properties dialog box still open, click the Add Objects button, click the Select All button, and click the Add button. With all added properties in the left list selected, choose the Collision Object option and click OK to close the dialog box.
