# Painting with multiple objects

If you have multiple objects in the Paint Objects list, you can choose which objects to paint with using the option in the Paint Objects panel. The first option is to paint with just the most recently picked object. The second option is to paint with all objects in order, and the last option is to randomly paint with all objects.
