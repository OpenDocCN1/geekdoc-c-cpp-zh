# Exporting to the DWF format

The Design Web Format (DWF) is an ideal format for displaying your textured models to others via the Web. It creates relatively small files that can be attached easily to an e-mail. You can use the Application Button Export Export to DWF menu command to export the current scene to this format. This command opens a dialog box of options, shown in Figure 3.15, that specify to Group by Object or Group by Layer. You also can choose to publish the Object Properties, Materials, Selected Objects Only, or Hidden Objects. Another option is to Rescale Bitmaps to a size entered in pixels.
