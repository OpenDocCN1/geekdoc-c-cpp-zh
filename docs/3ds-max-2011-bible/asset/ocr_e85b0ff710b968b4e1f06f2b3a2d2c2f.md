# Limiting nodes

When the Schematic View window is opened, Max traverses the entire hierarchy looking for objects and features that can be presented as nodes. If you have a complex scene and don’t intend on using the Schematic View to see materials or modifiers, you can disable them in the Include in Calculation section of the Schematic View Preferences dialog box. This provides a way to simplify the data presented. With less data, locating and manipulating what you are looking for becomes easier.
