# Debugging and evaluating expressions

After typing an expression in the Expression pane, you can check the values of all variables at any frame by clicking the Debug button. This opens the Expression Debug window, shown in Figure 35.5. This window displays the values for all variables, as well as the return value. The values are automatically updated as you move the Time Slider.
