The Waveform Controller dialog box lets you produce sinusoidal motions.

![](bbox=[0.073, 0.157, 0.602, 0.476])

The Effect option determines how different waveforms in the list are combined. They can be added, multiplied, clamped above, or clamped below. The Add option simply adds the waveform values together, and the Multiply option multiplies the separate values. The Clamp Above and Clamp Below options force the values of one curve to its maximum or minimum while not exceeding the values of the other curve. The Characteristic Graph shows the selected waveform, the output, or the final resulting curve. Figure 34.28 shows the Characteristic Graph for each Effect option when a sine wave and a square wave are combined.
