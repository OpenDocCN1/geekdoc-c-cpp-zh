# Chapter 24: Building Complex Scenes with Containers and XRefs

# Note

These same commands for working with containers are available in the Tools ➔ Containers menu.

**TABLE 24.1 — Containers Toolbar Buttons**

| Toolbar Button | Name | Description |
|---|---|---|
| [icon] | Inherit Container | Opens a file dialog box where a source container is loaded into the current scene |
| [icon] | Create Container from Selection | Creates a new container and adds the current selection to the container |
| [icon] | Add Selected to Container | Opens an object dialog box where you can select which objects to add to the current container |
| [icon] | Remove Selected from Container | Opens an object dialog box where you can select which objects to remove from the current container |
| [icon] | Load Container | Loads and displays the current container’s objects in the scene |
| [icon] | Unload Container | Saves the current container and removes the display of its objects |
| [icon] | Open Container | Allows the container’s objects to be edited |
| [icon] | Close Container | Saves the container and makes its objects so they can’t be edited |
| [icon] | Save Container | Saves the current container |
| [icon] | Update Container | Reloads the saved container with any new edits |
| [icon] | Reload Container | Throws away any recent edits and reloads the saved container |
| [icon] | Make All Content Unique | Converts all displayed container objects including nested containers to a unique container |
| [icon] | Merge Container Source | Loads the most recent saved container without opening its nested containers |
| [icon] | Edit Container | Allows the current container to be opened and edited |
| [icon] | Override Object Properties | Uses the display settings for the container object instead of the display settings for the individual objects |
| [icon] | Override All Locks | Temporarily overrides the locks for the current local container |
