# Drawing curves

If you know what the curve you want is supposed to look like, you can actually draw it in the Key pane with the Draw Curves button enabled. This mode adds a key for every change in the curve. You may want to use the Reduce Keys option after drawing a curve.

# Tip

If you make a mistake, you can just draw over the top of the existing curve to make corrections.

Figure 36.13 shows a curve that was created with the Draw Curves feature.

# Reducing keys

The Reduce Keys button enables you to optimize the number of keys used in an animation. Certain IK (inverse kinematics) methods and the Dynamics utility calculate keys for every frame in the scene, which can increase your file size greatly. By optimizing with the Reduce Keys button, you can reduce the file size and complexity of your animations.

Clicking the Reduce Keys button opens the Reduce Keys dialog box. The threshold value determines how close to the actual position the solution must be to eliminate the key.
