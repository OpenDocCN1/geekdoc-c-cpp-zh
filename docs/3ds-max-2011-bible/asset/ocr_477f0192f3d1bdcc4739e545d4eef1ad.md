Presets button

Clicking the Map Export button lets you specify the export map path where the textures for the scene are saved. You can also automatically convert the maps to a specific size or format. For each map format, you can configure the bits per pixel and any compression settings.

If you click the Presets button in the OBJ Export dialog box, then the export options for each format are shown in a table, like the one in Figure 3.12. Each of those settings can be quickly altered using this dialog box.
