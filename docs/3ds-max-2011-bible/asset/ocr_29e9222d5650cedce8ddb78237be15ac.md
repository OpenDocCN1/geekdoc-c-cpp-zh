# Rendering UV templates

After all the UV coordinates are mapped onto a model, you can paint the desired textures in an external paint program like Photoshop and load the texture back into the Edit UVWs window, where they can be aligned to the correct UVs. Using the Tools▸Render UVW menu command, you can create a template that can be saved and loaded into Photoshop, showing you exactly where the UV boundaries are.

The Tools▸Render UVW Template menu command opens the Render UVs dialog box, shown in Figure 32.10. This dialog box lets you set the template’s dimensions, set the template’s Fill and Edges colors, and show overlaps and seams. The Fill mode can be set to None, Solid, Normals, and Shaded, providing more information about the object.

Clicking the Render UV Template button renders the template into the Render Frame Buffer window where it can be saved to the needed image format. Then within Photoshop, you can make the template layer a background layer that you can turn on and off to show the lines that you need to stay within when creating a texture.
