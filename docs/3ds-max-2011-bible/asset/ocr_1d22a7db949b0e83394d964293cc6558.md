# Exporting to the JSR-184 (M3G) format

The JSR-184 export option lets you save a scene to a format that can be viewed on mobile devices that support the Java 2 Micro Edition standard interface, such as mobile phones and PDA devices.

Because wireless devices have such a limited bandwidth, the JSR-184 Exporter dialog box, shown in Figure 3.13, includes several options for optimizing the exported scene. This dialog box lists the Max scene hierarchy, the JSR-184 scene hierarchy, and the parameters for the selected scene object. Using the toolbar buttons at the top of the dialog box, you can change the hierarchy that is to be exported.
