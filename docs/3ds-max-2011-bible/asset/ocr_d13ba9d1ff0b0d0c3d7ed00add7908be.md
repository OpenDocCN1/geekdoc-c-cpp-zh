# Cross-Ref

The various cloning methods are covered in Chapter 8, “Cloning Objects and Creating Object Arrays.”

Clicking the Scatter button causes the Scatter Objects dialog box, shown in Figure 39.20, to open. This dialog box includes several panels used to randomize the Position, Rotation, and Scale of the cloned delegates. In the Clone panel, you can select the Object to Clone and How Many clones to create. After the settings are correct, click the Generate Clones button to create the duplicates.
