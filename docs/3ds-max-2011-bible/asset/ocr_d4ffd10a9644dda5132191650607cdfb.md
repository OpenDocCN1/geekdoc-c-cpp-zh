Next to the Ring and Loop buttons is a set of up/down arrows. These arrows are used to shift the current ring and/or loop selection left and right for the Ring selection, or up and down for the Loop selection. Holding down the Ctrl key adds the adjacent ring or loop to the current selection, and holding down the Alt key removes the adjacent selection. Figure 13.4 shows how the Ring and Loop buttons work. The first sphere shows a selection made using the Ring button; the second sphere has increased this selection by holding down the Ctrl key while clicking the up arrow next to the Loop button; the third sphere shows the selection made using the Loop button; the fourth sphere has increased this selection by holding down the Ctrl key while clicking the up arrow next to the Ring button.
