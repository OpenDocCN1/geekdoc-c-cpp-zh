The Slate Material Editor has four unique panels.

Below the menus are several toolbar buttons. These buttons are defined in Table 15.1.

# TABLE 15.1

| Toolbar Button | Name | Description |
|---|---|---|
| [图标] | Select Tool | Enables a tool for selecting, moving, and working with material trees and nodes. |
| [图标] | Pick Material From Object | Enables you to select a material from an object in the scene and load the material into the Node View panel. |
| [图标] | Assign Material to Selection | Applies the selected object with the selected material. |
| [图标] | Delete Selection | Removes any modified properties and resets the material properties to their defaults. The selected node is also deleted from the Node View panel. |
