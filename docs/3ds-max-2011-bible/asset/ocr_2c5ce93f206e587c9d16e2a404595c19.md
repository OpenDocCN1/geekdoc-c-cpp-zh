# Donut

As another variation of the Circle shape, the Donut shape consists of two concentric circles you can create it by dragging one to specify the outer circle and again to specify the inner circle. The parameters for this object are simply two radii.

# NGon

The NGon shape lets you create regular polygons by specifying the Number of Sides and the Corner Radius. You can also specify whether the NGon is Inscribed or Circumscribed, as shown in Figure 12.7. Inscribed polygons are positioned within a circle that touches all the outer polygon’s vertices. Circumscribed polygons are positioned outside of a circle that touches the midpoint of each polygon edge. The Circular option changes the polygon to a circle that inscribes the polygon.

# Star

The Star shape also includes two radii values—the larger Radius value defines the distance of the outer points of the Star shape from its center, and the smaller Radius value is the distance from the center of the star to the inner points. The Point setting indicates the number of points. This value can range from 3 to 100. The Distortion value causes the inner points to rotate relative to the outer points and can be used to create some interesting new star types. The Fillet Radius 1 and Fillet Radius 2 values adjust the Fillet for the inner and outer points. Figure 12.8 shows a sampling of what is possible with the Star shape.
