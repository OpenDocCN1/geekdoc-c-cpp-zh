# Summary

Inverse kinematics (IK) provides a unique way to control and animate hierarchical structures by transforming the child node. In this chapter, you accomplished the following:

+   - Learned the basic concepts behind IK
+   - Explored the difference between interactive and applied IK methods
+   - Created and animated an IK system
+   - Used the IK settings in the Preference Settings dialog box
+   - Learned how to use IK solvers

Now that you've learned the process for rigging a character and using IK, we'll take a look at using the Character Animation Toolkit (CAT) next and discover the benefits of using a pre-rigged skeleton.
