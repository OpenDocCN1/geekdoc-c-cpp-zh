# Part VI: Advanced Modeling

**TABLE 29.1 (continued)**

| Toolbar Button | Name | Description |
|---|---|---|
| Box Maker | Marker Style drop-down list | Choose the style to mark the selected vertices. Options include Box, Plus, X, and Dot. |
| [icon] | Invert Selection (Shift+Ctrl+N) | Deselects the current selection, and selects all hairs not currently selected. |
| [icon] | Rotate Selection (Shift+Ctrl+R) | Rotates the current selection. |
| [icon] | Expand Selection (Shift+Ctrl+E) | Adds to the current selection set by increasing the selection area. |
| [icon] | Hide Selected (Shift+Ctrl+H) | Hides the selected vertices. |
| [icon] | Show Hidden (Shift+Ctrl+W) | Unhides all hidden vertices. |
| [icon] | Hair Brush (Ctrl+B) | Moves all selected vertices in the direction of the brush. Press Escape to exit this mode. |
| [icon] | Hair Cut (Ctrl+C) | Cuts the hair in length. |
| [icon] | Select (Ctrl+S) | Enters selection mode where you can select hairs by dragging over them. |
| Distance Fade | Distance Fade (Shift+Ctrl+F) | Causes the brush effect to fade with distance. Available only in Hair Brush mode. |
| Ignore Back Hairs | Ignore Back Hairs (Shift+Ctrl+B) | Causes only hairs facing the camera to be affected. |
| [slider] | Brush Size Slider (Ctrl+Shift+mouse drag) | Changes the size of the brush. |
| [icon] | Translate (Shift+Ctrl+1, Ctrl+T) | Moves the selected guides in the direction of the brush when you drag. |
| [icon] | Stand (Shift+Ctrl+2, Ctrl+N) | Stands the selected guides up straight. |
| [icon] | Puff Roots (Shift+Ctrl+3, Ctrl+P) | Causes small deviations to appear at the root of each selected guide. |
| [icon] | Clump (Shift+Ctrl+4, Ctrl+M) | Pulls the selected guides together to the center of the brush. |
| [icon] | Rotate (Shift+Ctrl+5, Ctrl+R) | Rotates and spins the selected guides about the center of the brush. |
| [icon] | Scale (Shift+Ctrl+6, Ctrl+E) | Scales the selected guides when you drag with the brush. |
| [icon] | Attenuate (Shift+Ctrl+A) | Scales the hairs based on the size of the polygon. |
