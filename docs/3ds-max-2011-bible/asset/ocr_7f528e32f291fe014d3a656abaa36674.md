# Creation Method and Keyboard Entry rollouts

Most shape primitives also include Creation Method and Keyboard Entry rollouts (Text, Section, and Star are the exceptions). The Creation Method rollout offers options for specifying different ways to create the spline by dragging in a viewport, such as from edge to edge or from the center out. Table 12.1 lists the various creation method options for each of the shapes and of the extended shapes.

| Primitive Object | Primitive Object Name | Number of Viewport Clicks to Create | Default Creation Method | Other Creation Method |
|---|---|---:|---|---|
| Line | Line | 2 to Infinite | Corner Initial, Bézier Drag | Smooth, Initial, Corner, or Smooth Drag |
| Circle | Circle | 1 | Center | Edge |
| Arc | Arc | 2 | End-End-Middle | Center-End-End |
| NGon | NGon | 1 | Center | Edge |
| Text | Text | 1 | none | none |
| Section | Section | 1 | none | none |
| Rectangle | Rectangle | 1 | Edge | Center |
| Ellipse | Ellipse | 1 | Edge | Center |
