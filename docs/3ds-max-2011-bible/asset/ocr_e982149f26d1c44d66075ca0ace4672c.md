# FIGURE 27.18

The Deformation dialog box interface lets you control the cross section over the length of the path.

![](bbox=[0.014, 0.161, 0.54, 0.356])

To move a control point, select and drag it or enter a horizontal and/or vertical value in the fields at the bottom of the window.

Table 27.2 describes the buttons at the top of the Deformation window.

# TABLE 27.2

| Toolbar Button | Name | Description |
|---|---|---|
| [icon] | Make Symmetrical | Links the two curves so that changes made to one curve are also made to the other |
| [icon] | Display X-Axis | Makes the line controlling the X-axis visible |
| [icon] | Display Y-Axis | Makes the line controlling the Y-axis visible |
| [icon] | Display XY axes | Makes both lines visible |
| [icon] | Swap Deform Curves | Switches the lines |
| [icon] | Move Control Point | Enables you to move control points, and includes flyouts for horizontal and vertical movements |
| [icon] | Scale Control Point | Scales the selected control point |
| [icons] | Insert Corner Point, Insert Bézier Point | Inserts new points on a deformation curve |
| [icon] | Delete Control Point | Deletes the current control point |
