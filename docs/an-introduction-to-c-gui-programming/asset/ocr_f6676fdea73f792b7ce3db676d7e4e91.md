# INTRODUCTION TO C PROGRAMMING

The mathematical operators > and < are used to test for 'is greater than' and 'is less than' respectively, and they can also be combined with an equals sign to give >= and <=, the tests for 'is greater than equal to' and 'is less than equal to':

You combine tests with logical operators. The symbol && is Boolean AND (i.e test both sides are true), and || is Boolean OR (i.e test either side is true). So, to execute code only if a and b are 0 you use if (a == 0 && b == 0). To test either a or b is 0, you use if (a == 0 || b == 0).

Similarly, you use the operator ! as Boolean NOT to invert the result of a test, so if (!(a == 0)) is the same as (a != 0).
