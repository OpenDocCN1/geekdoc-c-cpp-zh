# The string library

Using the C string library to simplify common operations on strings

```
n the previous chapter, we saw how to access strings using pointers. This works perfectly well, and gives you a good understanding of how pointers work, but it's a bit long-winded. Fortunately, C provides a library of useful string functions, which save a lot of typing! In the last chapter, we saw how to join two strings together using pointers. We're going to do the same thing using the string handling library. Here's the code rewritten using string functions:

#include <stdio.h>
#include <string.h>

void main(void)
{
    char str1[10] = "first";
    char str2[10] = "second";
    char str3[20];

    strcat(str3, str1);
    strcat(str3, str2);

    printf("%s + %s = %s\n", str1, str2, str3);
}
```

> ### KEEP INSIDE YOUR STRING
The string library functions won't generally prevent you from writing off the end of a string, just as when using pointers. When using library functions you must ensure that your string variables are large enough for the values you store.
