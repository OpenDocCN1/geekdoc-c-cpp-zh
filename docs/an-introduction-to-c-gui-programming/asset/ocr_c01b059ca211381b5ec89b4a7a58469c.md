We create a new GtkTable with:

# Gtkwidget *tbl = gtk_table_new (2, 2, TRUE);

The arguments to the gtk_table_new function are the number of rows and the number of columns

To insert a widget into the table, we use:

```
gtk_table_attach_defaults (GTK_TABLE) (tbl), 1bl, 0, 1, 0, 1);
```

We pass as arguments the names of the table and the widget we are putting into it. The following numbers are the co-ordinates where the widget is attached to the table - in order they are the position of the left and right-hand edges of the widget, and then the top and bottom edges. So this positions the widget in the first column - between x positions 0 and 1 - and in the first row - between y positions 0 and 1.

Note that you can spread a widget across multiple rows and/or columns, as in how bnt is placed:

```
gtk_table_attach_defaults (GTK_TABLE) (tbl), btn, 0, 2, 1, 2);
```

In this case, the widget spans the first and second columns, because it is attached to 0 at the left and to 2 at the right.
For completeness, note that gtk_table_attach_defaults is a shortened version of the function gtk_table_attach which has several other options These other options include the ability to expand: fill and padding options for each widget as in the gtk_box_pack_ functions described in the previous chapter. But these functions can then get rather winded to type out - using gtk_table_attach_defaults sets padding to 0 and expand both to TRUE for each widget. Free to play with the full versions you want!
