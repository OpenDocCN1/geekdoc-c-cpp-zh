```
fp = fopen("/home/pi/output.txt", "wb");
if (fp)
{
    for (value = 48; value < 58; value++)
    {
        fputc(value, fp);
    }
    fclose(fp);
}
```

In this case, we open the file /home/pi/output.txt with the mode "wb", which indicates
'write binary'. This opens the file for writing, if this file already exists, the contents are deleted
We then call the function fputc ('for file character') in a loop, writing the bytes 48,
49..57. (These are the character codes for the text characters for the ten digits
0, 1..9). As before, we then close the file pointer. If you run this and then look in your home
directory, you should find the file output.txt, containing the string 0123456789
