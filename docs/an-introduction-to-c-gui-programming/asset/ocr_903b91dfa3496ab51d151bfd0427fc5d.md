# Control Structures

```

```

```

    <code executed if test is true>
else
    <code executed if test is false>
```

```

    <code executed if test1 is true>
else if (<test2>)
    <code executed if test1 is false and test2 is true>

    <code executed if test1 is false and test2 is false>
```
