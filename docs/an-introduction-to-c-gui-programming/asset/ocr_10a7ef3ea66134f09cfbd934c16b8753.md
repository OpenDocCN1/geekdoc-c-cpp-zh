# AN INTRODUCTION TO C PROGRAMMING

Now we need to tell the compiler where to find the GTK header files, and also we need to tell the linker that we want the program linked with the GTK library files, or all the 'GTK-ness' we want to use will be unavailable

There is a utility called pkg-config that helps us here pkg config is a tool that generates the arguments required by gcc in order to use additional libraries. By typing `pkg-config --cflags --libs gtk+-2.0` at the command line and looking at the output You'll see a list of strings - those which start -I/ are the directories where the GTK include files are stored, and those which start -l are the names of the GTK library files.

![](bbox=[0.068, 0.285, 0.931, 0.635])

All of these need to be added to the gcc command line in order to build our GTK program, so the pkg-config command is enclosed within back-ticks (``), like so

```
gcc pkg-config --cflags --libs gtk+-2.0 gtktest -o gtktest
```

If you run this, you should end up with an executable file called gtktest Run this by typing

```
./gtktest
```

and see what happens.
