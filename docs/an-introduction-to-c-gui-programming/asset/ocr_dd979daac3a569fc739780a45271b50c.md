```
void main (void) {
    printf("The sum of %d and %d is %d\n", 5, 2, ADD(5,2));
    printf("The sum of %d and %d is %d\n", 3, 7, ADD(3,7));
}
```

Again, this does a text substitution, whenever ADD(a, b) appears in the code, it's replaced by (a+b), with the values of a and b replaced by the arguments to ADD.

The preprocessor can also evaluate conditions with the #if directive:

```
#include <stdio.h>
```

```
void main (void) {
    #if 0
        printf("Some code\n");
    #else
        printf("Some other code\n");
    #endif
}
```

With a 0 after the #if, the code between the #if and the #else doesn't get called, but the code between the #else and the #endif does. If you change the value after the #if to a 1, the code between the #if and the #else gets called, but the code between the #else and the #endif doesn't. This is a really useful trick to temporarily remove or replace a piece of code when you're debugging.
