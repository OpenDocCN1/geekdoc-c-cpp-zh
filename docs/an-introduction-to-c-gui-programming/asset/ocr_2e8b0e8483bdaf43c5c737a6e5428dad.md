# Adding a vertical box

You've now got a blank window with a line across the middle, showing the VBox. We're going to add a label to the top, and a button to the bottom. Find these in the 'Control and Display' section of the palette - first click on each in the palette, and then click in the relevant VBox in the design area to add them.
