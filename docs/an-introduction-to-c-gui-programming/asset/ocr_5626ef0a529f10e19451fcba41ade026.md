In this case, we create a button to open the dialog, and then have to manually create and open the dialog in the button handler.

The dialog is created calling gtk_file_chooser_dialog_new, whose arguments are very similar to those for gtk_dialog_new_with_buttons that we saw in the previous chapter. The title of the dialog is provided, followed by a pointer to the parent window and then a flag that determines the behaviour of the dialog in this case is set up to provide a file name and path to which a file can be saved. The remaining arguments are NULL-terminated list of labels and return values for the buttons at the bottom of the dialog.

We create the dialog calling gtk_dialog_run when the button is pressed, the button handler waits for the dialog to return: We then read the file path back from the file chooser using gtk_file_chooser_get_filename, as we did for the file open dialog.
