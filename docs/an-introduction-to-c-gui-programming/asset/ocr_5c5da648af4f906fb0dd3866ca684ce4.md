```
}
```

In this example, we declare a pointer to the GtkTextEntry widget txt as a global variable. This is because we need to access it from the button handler, which in this case, the handler needs access to the Gtklabel widget. We previously used the general-purpose pointer in the g_signal_connect function to pass widget information to a handler, but for two separate widgets we've only got one pointer (There are ways of using a single pointer for this, but using a global variable is easier to understand).

We've added a new function, copy_text which uses the function gtk_entry_get_text to get a pointer to the text buffer by the GtkEntry, which stores whatever the user has typed into the entry box. Note that this buffer of chars is declared with the modifier const - this indicates a variable that cannot be changed by the programmer. We then pass this buffer to gtk_label_set_text, which copies the contents of the GtkEntry to the GtkLabel.

Finally, we created the GtkEntry itself with gtk_entry_new, and added it to the table (Note we've also moved the attachment points of btn so that it only takes one cell of the table rather than two, so as to give enough space for the GtkEntry).

Build the code and run it; try typing something into the entry box and pressing the 'Copy' button to see what happens.
