We can see that these parameters only affect the vertical size of the widgets; this is because they are used inside a GtkVBox. If we want to control the horizontal size of the widgets as well, we need to create a GtkBox which contains a set of GtkBoxes, which are then used to contain the widgets themselves.
The final argument in the call to `gtk_box_pack_start` is called `padding` – this is the amount of free space (in pixels) which is inserted at either end of this widget, this is in addition to the `spacing` which was requested between all widgets in the `gtk_box_new_call
By careful tweaking of `expand`, `fill`, and `padding` parameters, you can create a window which displays all its widgets tidily and resizes exactly as you expect.
