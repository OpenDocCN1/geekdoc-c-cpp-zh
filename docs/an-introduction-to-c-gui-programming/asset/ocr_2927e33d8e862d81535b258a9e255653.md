# Chapter 2
Variables and arithmetic

Doing some real work in C: creating variables and performing mathematical operations on them

In some languages, you can create variables as you go along and put whatever data you want into them. C isn't like that: to use a variable in C, you need to have created it, and at the time you create it, you have to set what type of value it's going to store. By doing this, a block of memory of the correct size can be allocated by the compiler to hold the variable. This process of creating a variable is known as declaration

# Integers

There are several fundamental data types in C, but we'll start by looking at one of the most commonly used: the int type, used to store an integer value.

```
#include <stdio.h>

void main (void) {
  int a;
  int b = 3;
  int c;

  a = 2;
  a = a + b;
  printf("The sum of adding %d and %d is %d\n", a, b, c);
}
```

The three lines inside the main function here are declarations. They tell the compiler that we would like to use variables called a, b, and c respectively and that each one is of type int, i.e. an integer.
