# INTRODUCTION TO C PROGRAMMING

```
int a = 0;
doo {
    printf("a is equal to %d\n", a);
    a++;
} while (a < 5);
printf("a is equal to %d and I've finished\n", a);
```

The keyword do now goes before the curly bracket, and the while test goes after the closing curly bracket. When this runs, the code in the loop always executes once before the test. You can test this by running both the loop examples above with a generalised to 5 rather than 0, and seeing how the behaviour differs
