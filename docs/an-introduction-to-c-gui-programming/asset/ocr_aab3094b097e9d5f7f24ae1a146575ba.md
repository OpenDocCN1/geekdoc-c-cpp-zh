a++ is the increment, this code which is executed at the end of each iteration of the loop, before the test is evaluated again. In this case, it adds 1 to a

So when this for loop runs, what happens? First a is set to 0 The test is then checked: is a (which is 0) less than 5? Yes it is, so the code inside the curly brackets is executed, and the value of a is printed. Finally, the increment is applied, meaning 1 is added to a

The test is then repeated if true the loop code is executed again, and the increment is again applied, this repeats over and over until the test is false, at which point execution continues after the closing curly bracket

In terms of what they do, for loops and while loops are pretty much identical, both wrap up a section of code you want to run more than once in some logic that controls how many times it runs. You can use whichever makes the most sense, or whichever looks tidiest to you!
