# Chapter 18
GUI user input

Enable users to enter text, and to select options using check and radio buttons

We've seen how we can display text on a window using a label, but what about if we want to read in some text that the user has typed? GTK provides the GtkTextEntry widget for this

# Text entry

Modify the example code above to add a new cell to the table with the GtkTextEntry widget, like so:

```
#include <gtk/gtk.h>

GtkWidget *txt;

void end_program(GtkWidget *wid, gpointer ptr)
{
    gtk_main_quit();
}

void edit(GtkWidget *wid, gpointer ptr)
{
    const char *input = gtk_entry_get_text(GTK_ENTRY(txt));
    gtk_label_set_text(GTK_LABEL(ptr), input);
}

void main(int argc, char *argv[])
{
    gtk_init(&argc, &argv);
    GtkWidget *win = gtk_window_new(GTK_WINDOW_TOPLEVEL);
    GtkWidget *btn = gtk_button_new_with_label("edit");
    gtk_signal_connect(btn, "clicked", G_CALLBACK(end_program), NULL);
    gtk_signal_connect(win, "delete_event", G_CALLBACK(end_program), NULL);
```
