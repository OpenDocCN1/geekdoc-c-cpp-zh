The C programming language is used for a huge range of applications, from the tiny microcontrollers used in toasters and watches up to complete operating systems. The first half of this book is an introduction to C, and covers the basics of writing simple command-line programs. The second half shows how to use the GTK library, a popular widget toolkit, with C to create feature-rich graphical applications which can be run on the desktop. No previous experience of C or GTK is required – even if you are an absolute beginner, this book will teach you all you need to know to...

+   - Create simple command-line C programs
- Control flow with conditions and loops
- Handle variables, strings, and files
- Design graphical user interface applications in C
- Handle user input with buttons and menus
- Use advanced UI features such as data stores and dialogs
