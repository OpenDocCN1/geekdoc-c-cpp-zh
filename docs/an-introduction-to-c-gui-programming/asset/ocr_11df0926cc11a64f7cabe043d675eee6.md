The widget properties editor

Click on the GtkButton, and find the Label section for it - it's under 'Label with optional image' – change the label for the button to 'Quit' at the bottom of the right-hand column – it is worth investigating the options on all the tabs at go into here, but of particular interest are those on the 'Packing' tab, these allow you to expand the expand, fill and padding options which were available when adding widgets to boxes code if you play with them, you can get a good feeling for how much control you have over layout of the window, particularly when combining multiple boxes inside each, as Glade allows you to do.

The other thing that it is important to note about right hand column is that Glade assigns every widget name – it can be seen in the hierarchy list at the top, and as the last entry on the 'General' tab Glade assigns names as name of the widget type followed by a number, but you can change these if you want But there is one vital rule – every widget in a layout file must have a unique name If two widgets have the same name, the layout file is invalid and will not load correctly.
