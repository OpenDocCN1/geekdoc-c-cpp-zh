There are several other predefined dialogs which can be added to an application just by including a button. Two of the most useful ones are the colour picker and the font chooser.

# Colour picker

Sometimes you need to allow the user to select a colour to determine how things will be highlighted, for example: This is easy to do with the GtkColorButton (Note that GTK refers to 'colour', it does so using the US spelling, without the 'u'-it's a common source of compile-time errors for those of us on the East side of the Atlantic!)

Colours in GTK are stored as GdkColor structures which contain separate values for the red, green, and blue components of a colour. The GtkColorButton therefore operates on data stored as a GdkColor.
