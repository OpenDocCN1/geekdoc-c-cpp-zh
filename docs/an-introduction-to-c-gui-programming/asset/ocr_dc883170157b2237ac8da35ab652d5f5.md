# mystring.h

Strings are stored as an array of single characters, with the element after the last character set to zero

You can use the index in square brackets to access individual characters in a string, or you can use a pointer. Here's an example of using pointers to join two strings together:

```
#include <stdio.h>

void main (void) {
    char str1[10] = "first";
    char str2[10] = "second";
    char str3[20];

    char *src, *dst;

    src = str1;
    dst = str3;
    while (*src != 0) {
        *dst = *src;
        src++;
        dst++;
    }
    src = str2;
    while (*src != 0) {
        *dst = *src;
        src++;
        dst++;
    }
    printf("%s + %s = %s\n", str1, str2, str3);
}
```
