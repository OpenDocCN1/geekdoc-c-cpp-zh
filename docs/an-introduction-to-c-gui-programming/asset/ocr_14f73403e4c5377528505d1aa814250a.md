When second and subsequent buttons are created, the group of the first button can be read
with the function gtk_radio_button_get_group passed into subsequent gtk_
adio_button_new_with_label calls:

```
GList *group = gtk_radio_button_get_group (
  GTK_RADIO_BUTTON (rad1));
```

```
GtkWidget *rad2 = gtk_radio_button_new_with_label (group,
  );
```

Every button in the group needs to be associated with another button in the same group in
manner in order for the link to work correctly. (Any radio button which is not linked with a
group will not function correctly, it will always be selected and clicking on it has no effect.)

Try replacing the check button and the label in the previous example with the pair of
grouped radio buttons shown above – you should get something that looks like this:

If you've linked them correctly, then when you click 'Button 2', it will be selected and
'Button 1' will be unselected, and vice versa.
