The third argument to gtk_box_pack_start is called expand. If set to TRUE, then when a window is enlarged, the amount of space allocated for this widget is enlarged in proportion If set to FALSE, the amount of space allocated for this widget is never more than the minimum it requires.

The fourth argument is called fill. This has no effect if expand is set to FALSE, but if expand is set to TRUE, it controls whether or not it is the space allocated to the widget or the widget itself grows. If expand is TRUE and fill is FALSE, the widget itself stays the same size, if both expand and fill are TRUE, the widget itself grows to fill the increased space.

That is somewhat hard to follow when written down, but a few examples will help to get it straight Change the GtkHB back to a GtkVBox in the example above, and then both expand and fill for all three gtk_box_pack_start calls in the example above to FALSE. If you resize the window, the label and two buttons will stay the same height at the top of the window.
