box, 'Option 1'. Note that this is a function for the widget GtkComboBox, rather than for

To read the currently selected value, use:

```
int sel = gtk_combo_box_get_active (GTK_COMBO_BOX ());
```

This returns the index of the currently selected item - so 0 for 'Option 1', 1 for 'Option 2' and
s on. Alternatively,

```
char *selected = gtk_combo_box_text_get_active_text (
GTK_COMBO_BOX_TEXT (comb));
```

...can be used to return the actual text string which is selected. (Note that this function
only works on combo boxes; it can't be used on the full combo box described in the
next section.)

The signal generated by a combo box when the value is changed by the user is called
changed, so a suitable callback like:

```
void combo_changed (GtkWidget *wid, gpointer ptr) {
  int sel = gtk_combo_box_get_active (GTK_COMBO_BOX (wid));
  char *selected = gtk_combo_box_text_get_active_text (
    GTK_COMBO_BOX_TEXT (wid));
  printf("The value of the combo is %d %s\n", sel, selected);
}
```
