# Chapter 20
Tree views

Use the GtkTreeView widget to display
Information and user input options

As mentioned in the previous chapter, using a list store for a combo box can
sometimes be overkill! – although in some circumstances, it is exactly the right thing
to do! But the situation for which a list store is really designed is as the data store for a widget called GtkTreeView.
GtkTreeView is a table of data arranged in columns. The table can show images as well as
text, and can even contain other widgets, such as check buttons, alongside the data.
