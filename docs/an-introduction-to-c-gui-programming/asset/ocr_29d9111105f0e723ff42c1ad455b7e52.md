This is very similar to an if statement, but the code in the curly brackets is executed repeatedly for as long as the test in the round brackets is true, not just once.
In our example code, a is initialized to 0. We enter the loop, and to see if a is less than 5, so the code inside the curly brackets is executed. The value of a is printed out, and then we have one of C's useful shortcuts to save too much typing...
a++ is the same as a+=1, the double plus means 'add one to this variable'; these are very commonly used to count the times around a loop. The notation a+=1 can also be used to add a value to a variable; this also works for other arithmetic operators, so as a*=3 multiplies by 3, and so on.

In the loop, each time the code in the curly brackets has been executed, the test in the round brackets is repeated, if it's still true, the loop code is repeated again. As soon as the test is false, execution continues with the line after the closing bracket.
