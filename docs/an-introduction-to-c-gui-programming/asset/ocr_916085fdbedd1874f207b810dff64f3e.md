# Containers

In the example, we use the line

gtk_container_add (GTK_CONTAINER (win), btn);

to put the button into the window.
As you've probably noticed, each function call in GTK starts with the prefix gtk_ which is followed by the name of the widget type upon which it operates – so gtk_window_new creates a widget of type GtkWindow. This function call therefore operates on properties of widgets of type GtkContainer, but we are using it on win, which is a GtkWindow. How does that work?

There is a hierarchy of widget types within GTK, and a widget type inherits of its parents within the hierarchy, that type can be described as a child of the widget types above it in the hierarchy.

Because GtkContainer is one of the parents of GtkWindow, you can use gtk_container functions on Gtk widgets. Many widgets have GtkContainer as a parent, because putting one widget inside another like this is something we need to do often.
