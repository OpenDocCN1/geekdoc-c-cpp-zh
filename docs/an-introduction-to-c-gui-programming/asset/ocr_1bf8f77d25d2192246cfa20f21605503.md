And create the handler for the font-set signal:

```
static void font_cb(GtkButton *btn, gpointer ptr)
{
    printf("font = %s\n", gtk_font_button_get_font_name(btn));
}
```

When run, a font button is shown with the currently selected font name:

![](bbox=[0.12243000000000001, 0.27643, 0.41757, 0.44914])

Pressing the font button opens the selector dialog, which allows you to pick any of the fonts currently installed on the system:

![](bbox=[0.12243000000000001, 0.52643, 0.7685700000000001, 0.8518600000000001])

When you click 'OK', the selected font name and size will be printed to the terminal.
