If it is assumed that the cost of capital is 10 percent, the project will be accepted.

# ### Profitability Index

The profitability index (PI) is defined as the present value of future flows divided by the initial investment:

$$\mathrm{PI} = \left[ \sum_{t=1}^{m} \frac{\mathrm{EATCF}_t}{(1+k)^t} \right] / \text{Initial investment}$$

Since the future cash flows are typically positive,

$$\mathrm{PI} = \left[ \frac{40,000}{1.10} + \frac{40,000}{(1.10)^2} + \frac{30,000}{(1.10)^3} + \frac{30,000}{(1.10)^4} \right] / 100,000$$
$$\mathrm{PI} = (36,360 + 33,040 + 22,530 + 20,490) / 100,000$$
$$\mathrm{PI} = 110,243 / 100,000 = 1.12$$

The decision rule is

+   - If PI > 1, accept the Motor Grader (*ceteris Paribus*).
+   - If PI < 1, reject the Motor Grader (*ceteris Paribus*).

Like the NPV and IRR methods, the PI method accounts for timing.
