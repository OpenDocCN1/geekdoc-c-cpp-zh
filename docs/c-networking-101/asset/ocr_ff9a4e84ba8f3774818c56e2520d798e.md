Open a command prompt in the directory where you extracted Boost and
run these commands:

```
bootstrap.bat
```

```
.\\b2.exe
```

This will build and install Boost, which may take a while. After it's done,
add C:\\boost\\boost_1_xx_0 to your include path and
C:\\boost\\boost_1_xx_0\\stage\\lib to your library path.

# POCO C++

Download the latest POCO C++ Libraries from the official website.

Extract the downloaded file to a directory, e.g., C:\\poco.

Open a command prompt in the directory where you extracted POCO and
run these commands:

```
buildwin.cmd 141
```

Replace 141 with your Visual Studio version number.

This will build POCO. After it's done, add C:\\poco\\include to your include
path and C:\\poco\\lib to your library path.
