This program teaches you to check the number of messages in an IMAP mailbox using VMime. Before you can use the code examples, you'll need to have VMime linked in your project and replace smtp.example.com and imap.example.com with the actual SMTP and IMAP server URLs, and me@example.com and you@example.com with the actual email addresses.

Both SMTP and IMAP may require authentication, so you may need to use the setProperty() method to set your username and password. For example:

```
```cpp
tr->setProperty("options.need-authentication", true);

tr->setProperty("auth.username", "myusername");

tr->setProperty("auth.password", "mypassword");
