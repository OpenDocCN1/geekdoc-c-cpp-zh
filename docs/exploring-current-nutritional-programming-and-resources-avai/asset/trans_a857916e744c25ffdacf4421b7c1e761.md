## *综述结果*

### 人群

大多数可用的营养和食品项目针对的是加拿大 PLWH 的总体人群。在纳入综述的 64 项结果中，部分项目为一个以上的特定人群提供服务，共计 69 项针对性项目资源。在这 69 项结果中，44 项（63.8%）广泛聚焦于 PLWH，而非将项目细分为针对特定多元人群。综述中识别出的部分项目确实针对了与 PLWH 总体人群相比需求不同的特定人群（见图 2，了解加拿大各城市提供针对性项目的资源）。这些结果中识别出的项目和资源聚焦于妇女和/或儿童（n = 6；8.7%）；吸毒的 PLWH（n = 3；4.3%）；跨性别、非二元性别和性别多元的 PLWH（n = 3；4.3%）；接受抗逆转录病毒治疗的 PLWH（n = 3；4.3%）；非洲、加勒比和黑人 PLWH（n = 2；2.9%）；原住民 PLWH（n = 2；2.9%）；gbMSM（n = 2；2.9%）；低收入 PLWH（n = 1；1.4%），法语使用者 PLWH（n = 1；1.4%）；性工作者（n = 1；1.4%）；以及遭受边缘化的 PLWH（n = 1；1.4%）。

### 背景

根据研究纳入标准，综述中纳入的所有结果均基于加拿大。在识别出的 64 项结果中，18 项（28.1%）发表于不列颠哥伦比亚省；14 项（21.9%）在安大略省；10 项（15.6%）为加拿大全国范围非省/地区特定；7 项（10.9%）在新斯科舍省；3 项（4.7%）在阿尔伯塔省；3 项（4.7%）在萨斯喀彻温省；2 项（3.1%）在马尼托巴省；魁北克、新不伦瑞克、爱德华王子岛、新foundland and Labrador、育空、西北地区和努纳武特各 1 项（1.6%）。作为背景，2019 年各省和地区每 10 万人 HIV 诊断率为：萨斯喀彻温省，n = 16.9；马尼托巴省，n = 8.8；魁北克省，n = 7.4；阿尔伯塔省，n = 5.8；安大略省，n = 4.7；不列颠哥伦比亚省，n = 3.5；大西洋省份，n = 3.0；西北地区，n = 1.7。²

### 概念

共定位到 76 项资源，因为纳入综述的 64 项结果中有些提供了不止 1 项资源（见图 3，了解各省和地区资源分布）。我们将这 76 项资源归类为慈善食品供应（例如，食品银行、汤厨房、杂货券；n = 21；27.6%）；经济援助（即省级政府补贴；n = 14；18.4%）；营养护理（例如，营养师服务包括营养护理流程和 MNT；n = 12；15.8%）；提供次级来源的渠道（即不提供营养和食品项目的网站，但提供链接到提供此类服务的其他网站；n = 10；13.2%）；食品和营养专业知识（例如，专业人士提供的营养和饮食指南、书籍、PDF 和组织提供的研讨会；n = 10；13.2%）；以及人群健康促进（例如，烹饪课程和以社区融合和社会性为重点的一般健康饮食建议；n = 9；11.8%）。通过搜索这些资源提供的网站链接，我们发现了另外 69 个食品和营养项目的次级来源，其中 10 个已通过初始搜索（主要结果）捕获。因此，加拿大范围内为 PLWH 提供的营养和食品项目资源共计 135 项。

## 已知服务中的差距及未来研究领域

结果显示，关于加拿大 PLWH 可用营养和食品项目的同行评审文献缺乏，因为大多数结果来自灰色文献（n = 47/64；73.4%）。这凸显了开展范围综述的重要性，因为许多政策制定者认为系统性范围综述提供了最强有力的证据。⁴⁵ 此外，政策制定者，如公共卫生部门和联邦政府，在收集政策相关证据时最常参考同行评审文献和原始研究。⁴⁵ 为了在政策层面做出任何干预，需要更多关于该主题的同行评审研究。灰色文献的结果表明，虽然加拿大各组织提供的项目在为 PLWH 提供营养和食品项目方面没有标准方法，但各省的方法和提供的支持之间存在相似之处。确定了四个关于已知服务的未来研究领域：i) 针对性项目有限，ii) 资源地理分布，iii) 提供的资源类型，iv) 资源/项目有效性与其对个体体验的关系。

首先，已识别的项目中设计用于多元亚人群的数量有限。例如，许多妇女和儿童；原住民；跨性别和性别多元人群；以及黑人、非洲和加勒比人群有不同的需求需要解决。生活在 HIV 感染下的顺性别和跨性别女性，例如，需要创伤知情和性别安全的空间来获取食品服务。¹⁷ 黑人、非洲和加勒比人，如黑人艾滋病预防联盟（Black CAP）的客户，需要考虑种族主义、同性恋恐惧症和贫困等社会障碍的项目。⁴⁶ 尽管需求存在差异，只有 36% 的结果提供了针对性项目。这使得许多遭受边缘化的人群无法获得他们需要的特定资源。例如，本综述中识别的资源中只有 3% 针对原住民，尽管该人群在 2019 年占新 HIV 病例的近 25%。³ 多伦多的 Black CAP 是针对性资源的例子。他们的项目专注于为多伦多低收入黑人、非洲和加勒比家庭提供文化特定的基本食品。⁴⁶ 多伦多还设有安大略原住民 HIV/AIDS 策略（OAHAS），为安大略省城市的原住民、因纽特人、梅蒂斯人和无地位社区团体/组织/机构、学校和个人提供获取食物和住所的帮助。⁴⁷ OAHAS 在街道、社区、活动、战舞、机构进行外展，在矫正设施、医院、医疗中心和学校进行内展。这也表明大多数针对性项目是在大城市提供的。

其次，大城市，如温哥华（n = 11/18；不列颠哥伦比亚省结果的 61%）和多伦多（n = 7/14；安大略省结果的 50%），被确定为其省份大部分资源所在地（见图 2 和图 3），这导致推测农村地区提供的资源可能较少。总体而言，这些地区识别出的项目涵盖了 PLWH 的广泛需求，为针对性人群提供不同资源。发现的资源大多由非营利组织、私人（营利）诊所和省级政府提供。例如，在不列颠哥伦比亚省，我们识别出 18 项结果，涵盖全部 6 个类别的项目，而在马尼托巴省我们识别出 2 项结果，涵盖 6 个类别中的 3 个，即慈善食品供应、营养护理和经济援助。由 Nine Circles 社区健康中心（非营利组织）、7th Street Access Centre（省级运营健康诊所）和温尼伯健康科学中心（省级医院）运营的马尼托巴 HIV 项目提供慈善食品供应和营养护理。⁴⁸ 虽然马尼托巴省识别出的资源不多，但 Nine Circles 等组织提供多种类型的项目（例如，紧急食品供应、营养师营养教育），可能能够针对需求不同的 PLWH。⁴⁸ 然而，仍有许多地区没有任何服务可用。资源较少难以覆盖大量受影响人群，可能导致项目资源紧张，无法满足需求。

第三，识别出的最常见营养和食品项目类型是慈善食品供应服务。这包括食品银行、杂货券和汤厨房等支持，占所有识别营养和食品服务的 27.6%（21/76）。这些支持似乎对 PLWH 与普通人群没有不同；然而，某些食品供应服务是专门为 PLWH 保留的。许多已识别的组织将慈善食品供应作为为 PLWH 提供的唯一营养相关资源。例如，ACT（原多伦多艾滋病委员会）每周两次为 PLWH 提供热午餐⁴⁹，HIV/AIDS 资源和社区健康每月为 PLWH 提供 10 美元杂货店礼品卡。⁵⁰ 对许多 PLWH 来说，慈善食品供应服务可能是他们为管理症状和药物副作用而获得的唯一营养支持。²¹ 未来研究将受益于探索长期解决方案；然而，慈善食品服务在过渡期间是必要的，不是作为解决方案，而是满足即时需求。识别出的第二常见支持类型是经济援助（14/76；18.4%），因为每个省和地区都有自己的政府经济援助形式，供符合条件的 PLWH 在就业支持和收入援助下使用（即营养师转介）。提供给每个个人的金额可包括基本食品、饮食补充剂和热量摄入/特殊饮食津贴。识别出的第三常见支持类型是营养护理（12/76；15.8%）。营养护理包括营养师服务获取以获取饮食补充剂转介和 MNT 流程等资源，这已被证明对 PLWH 有益。¹ 次级来源（即不提供营养和食品资源的组织网站，但提供其他提供者的清单/网站链接）并列为第四常见支持（10/76；13.2%）。然而，次级来源可能对寻求营养和食品支持的人帮助有限。由于大量发现的资源来自服务提供者网站，提供链接到次级来源，这表明可用支持不足，因为部分次级来源进一步提供链接到三级来源，使得找到提供营养或食品项目的切实资源变得困难。其他并列第四最常见
