Texture Memory:

Texture memory serves a similar purpose to constant memory but offers
specialized caching and addressing modes suited for graphics textures—nwhich can also be harnessed for general-purpose calculations. Texture
memory can be beneficial for reads that exhibit spatial locality, thus
ennhancing reading efficiency for specific patterns of memory access.
