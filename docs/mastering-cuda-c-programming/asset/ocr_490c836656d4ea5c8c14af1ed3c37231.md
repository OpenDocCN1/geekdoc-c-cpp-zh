```
__global void grayscale_filter_kernel(unsigned input_frame, output_frame, width, int height) { idx = blockIdx.x * blockDim.x + threadIdx.x; id = blockIdx.y * blockDim.y + threadIdx.y; (idx < width && id < height) { pixel_pos = id * width + idx; char r = input_frame[pixel_pos * 3 + 0]; char b = input_frame[pixel_pos * 3 + 2]; g = 0.299f * r + 0.587f * g + 0.114f * b; }
```

This kernel converts a color to grayscale by calculating a weighted sum of the RGB values of each pixel. The constants 0.299, 0.587, and 0.114 represent the luminance contribution of each color channel. Executing this kernel on a GPU enables the processing of thousands of pixels in parallel, facilitating real-time video filtering.
