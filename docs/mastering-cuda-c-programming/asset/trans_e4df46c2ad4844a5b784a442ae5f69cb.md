

# 优化访问模式

高效使用全局内存的关键在于优化访问模式，以减少延迟并增加带宽利用率。需要遵循的两个基本原则是合并（coalescing）和避免银行冲突（bank conflicts）。

## 合内存访问

合并是指当内存访问满足某些对齐和连续性条件时，将多次访问合并为单次事务的过程。理想情况下，warp 内的线程应该访问连续的内存地址以充分利用内存带宽。为了说明这一点，请考虑以下示例：

```
__global__ void kernel(float *dst, float *src, int N) {
    int idx = threadIdx.x + blockIdx.x * blockDim.x;
    if (idx < N) dst[idx] = src[idx];
}
```

在这个示例中，如果 warp 中的每个线程都访问连续的 src 元素，读取（和写入）将合并，从而实现高效的内存事务。相比之下，如果线程以步长模式访问内存，带宽利用率将会下降，增加延迟。

## 避免银行冲突

虽然银行冲突与共享内存关联更直接，但类似的原理可以扩展到理解全局内存效率上。具体而言，避免线程内存访问中出现巨大的间隙（或步长），可以防止这些访问的序列化，从而保持高吞吐量。

## 高效使用策略

最大化全局内存效率涉及采用几种关键策略：

- 最小化主机和设备之间传输的数据量，因为这些传输会产生巨大的开销。相反，专注于最大化 GPU 上的计算，以充分利用其计算能力。
- 优化数据结构，使内存访问自然合并，并对结构进行填充（pad）以避免可能降低性能的非对齐访问。
- 使用 CUDA 流（Streams）使内存传输与计算重叠，有效隐藏传输延迟。
- 利用内存池（Memory pools）处理频繁的分配和释放（会导致内存碎片），使用内存池策略来动态管理全局内存。

高效管理和访问全局内存对于充分发挥 GPU 的威力至关重要。通过遵循合并访问原则、最小化数据传输、优化数据布局并利用并发，尽管全局内存存在固有局限性，开发者仍然显著提升 CUDA 应用程序的性能。

## 4.4

## 共享内存：概念、用法与模式

在 CUDA 编程领域，理解并利用共享内存可以显著提升应用程序的性能。正如其名，共享内存是同一块（block）内线程共享的内存类型。与全局内存相比，它的访问速度快得多，几乎充当了一个高效的、用户管理的缓存。本节将揭示 CUDA 中共享内存的概念、用法和模式，以充分利用其潜力。

## 理解共享内存

共享内存是 NVIDIA GPU 上可用的一种受限但极快的内存类型。每个 CUDA 核心都可以访问其块的共享内存，使得同块内的线程能够高效地共享数据。共享内存的大小在内核启动时预先确定。由于它比全局内存快，合理使用共享内存对于优化 CUDA 应用程序的性能至关重要。

## 分配共享内存

共享内存可以静态或动态分配。静态分配的共享存在在编译时定义，而动态分配的共享存在在运行时指定。下面演示了两种方法的共享内存分配。

```cpp
// 静态分配的共享内存
__global__ void staticallyAllocatedKernel() {
    __shared__ int sharedArray[256];
}

// 动态分配的共享内存
__global__ void dynamicallyAllocatedKernel(int size) {
    extern __shared__ int sharedArray[];
}
```

在动态分配共享内存时，其将在启动时作为参数传递给内核。

## 访问模式与性能

共享内存的性能受访问模式的影响。需要理解的两个关键概念是银行冲突和合并访问。共享内存被分为等大小的内存模块，称为银行（banks）。当多个线程同时访问同一个内存银行的数据时，就会发生银行冲突，导致访问序列化。

另一方面，合并访问是指线程访问连续内存的情况。这里有一个演示共享内存的示例：

```cpp
__global__ void kernel() {
    __shared__ float sharedData[256];
    int tid = threadIdx.x;
    // ...访问 sharedData[tid] ...
}
```

## 优化策略

为了最大化共享内存的收益，可以采用以下策略：

- 通过构建访问模式来最小化银行冲突。
- 平衡共享内存的使用以最大化占用率（occupancy）。
- 使用共享内存处理来自全局内存的频繁数据以减少延迟。

有效理解和利用共享内存需要对计算问题和架构都有实践和洞察。通过遵循所讨论的概念、用法模式和优化策略，可以实现性能的提升。

## 4.5

## 本地内存：用法与优化

在 CUDA 编程中，本地内存是指每个线程私有的内存空间。它用于当自动变量因大小原因无法分配到寄存器时。理解本地内存用用的细节对于增强 CUDA 应用程序的性能至关重要，因为不当的使用会导致巨大的内存延迟。

## 本地内存的特性

本地内存位于片外 DRAM 中，在访问延迟和带宽方面，它不如寄存器或共享内存等片内内存。然而，它的使用有时是避免的。定义本地内存的特性包括：

- 它是每个线程私有的。
- 通过全局内存路径访问，比寄存器和共享内存慢。
- 编译器在寄存器不足时自动使用它。
- 只要线程上下文保持不变，其内容在不同内核的执行之间保留。

## 优化技术

优化本地内存使用的关键在于最小化其需求和访问时间。以下策略为通过高效管理实现更好的性能提供了指导。

## 最小化变量使用

减少每个线程所需的变量数量可以帮助减少本地内存的使用。通过优化内核复杂性并尽可能减少变量的作用范围和生命周期，优先使用寄存器。

## 使用共享内存进行线程间通信

不要依赖本地内存，而是使用共享内存处理同一块内多个线程需要访问的数据。这需要仔细管理共享内存的分配和访问模式，但会显著减少与本地内存访问相关的延迟。
