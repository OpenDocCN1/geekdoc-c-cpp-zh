# Memory Access Patterns

The way memory is accessed by threads plays a crucial role in the performance of CUDA applications. Utilizing memory efficiently can result in substantial speedups.

Coalesced When threads of a warp access consecutive memory locations, the memory accesses can be coalesced into a single transaction, significantly reducing the number of required memory operations. Ensuring that your kernel’s memory access patterns are aligned with this principle is key to achieving high memory throughput. Shared CUDA provides shared memory, a programmable cache accessible by threads within the same block. By carefully staging data in shared memory, one can minimize slower global memory accesses and greatly improve the performance. However, shared memory is limited, and its effective use requires balancing between the memory available and the number of active threads per block.
