# Pinning Host Memory

To enable faster data transfers, CUDA allows for the allocation of pinned (or page-locked) host memory. Pinned memory does not get swapped out by the operating system, which enables higher transfer rates between the host and the device.

size;

cudaMallocHost is used to allocate pinned memory on the host. Transferring data from pinned memory is faster compared to pageable memory because the GPU can access pinned memory directly via DMA (Direct Memory Access), bypassing the CPU.
