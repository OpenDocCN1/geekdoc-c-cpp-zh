## 2.5

## 搭建 CUDA 开发环境

搭建 CUDA 开发环境是开启 CUDA C 编程之旅的关键一步。这一过程涉及几个阶段，包括检查系统是否满足必要要求、安装 CUDA Toolkit 以及配置你的开发环境。通过确保配置妥当，你可以避免后期可能碍开发进程的常见问题。

## 系统要求

第一步是验证你的系统是否满足支持 CUDA 编程的需求。这些要求包括：

- 支持 CUDA 的 GPU：NVIDIA 显卡是必需的，因为 CUDA 是 NVIDIA 为其 GPU 开发的技术。
- CUDA Toolkit 支持的操作系统：这通常包括各种版本的 Windows、Linux 和 macOS。
- 足够的 RAM 和存储空间：具体取决于你计划开发的应用程序的复杂度。
- 支持的开发工具版本：这可能涉及 Linux/Mac 的特定版本 GCC 或 Windows 的 Visual Studio。

要检查你的 GPU 是否支持 CUDA，请在终端或命令提示符中运行以下命令（分别对应 Linux/Mac 和 Windows）：

```
lspci | grep -i nvidia
```

或者

```
wmic path win32_VideoController get name
```

这些命令将列出系统中安装的显卡。然后你可以参考 NVIDIA 官方的支持 CUDA 的 GPU 列表来验证你 GPU 的 CUDA 能力。

## 安装 CUDA Toolkit

一旦确认系统满足先决条件，下一步是从 NVIDIA 官方网站下载并安装 CUDA Toolkit。CUDA Toolkit 包含了开发 CUDA 应用程序所需的编译器、库和调试工具。

导航到 NVIDIA 网站上的 CUDA Toolkit 下载页面。选择与你的操作系统和 GPU 兼容的版本。下载安装程序并运行，按照屏幕上的指令操作。

建议在安装过程中包含 toolkit 提供的示例（samples）。这些示例是学习和测试你的 CUDA 开发环境的宝贵资源。

## 配置环境变量

安装 CUDA Toolkit 后，配置系统环境变量至关重要。这将允许你从命令行或你偏好的 IDE 编译并运行 CUDA 程序。

对于 Windows 用户，将 CUDA Toolkit 的 bin 目录添加到 PATH 环境变量中。对于 Linux 和 macOS 用户，过程涉及编辑你的 shell 配置文件（例如 .bashrc 或 .bash_profile）以包含以下行：

```
export PATH=/usr/local/cuda/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH
```

这些命令使得 CUDA 编译器 (nvcc) 和库在全局范围内可用。

## 测试安装

要验证你的 CUDA 开发环境已正确设置，请编译并运行 CUDA Toolkit 包含的一个示例项目。导航到 samples 目录，选择一个示例项目，并按照 README 文件提供的指令构建并执行程序。如果你看到了预期输出，恭喜你！你已成功搭建了 CUDA 开发环境。

例如，为了测试一个简单的向量加法程序，你可能会使用：

```
cd NVIDIA_CUDA-/samples/0_Simple/vectorAdd
make
```

预期的输出应该确认两个向量已成功相加，表明你的环境已为 CUDA 开发正确配置。

通过遵循这些步骤，你现在应该拥有了一个功能完的 CUDA 开发环境。这个设置是你通过 CUDA C 探索广阔的 GPU 加速计算世界的大门。

## 初探 CUDA C 代码

开启 CUDA C 编程领域的旅程最初可能看起来令人敬畏。CUDA，即统一计算设备架构，通过添加控制 GPU 并行特性的特定功能扩展了 C 语言。本节旨在通过基础示例消除 CUDA C 的神秘感，突出其与标准 C 编程的关键区别，并阐述 CUDA 并行计算方法的底层概念。

CUDA 编程的核心是内核（kernels）的概念。内核是函数，当被调用时会在 GPU 上的大量线程中并发执行。为了将它们与普通 C 函数区分来，使用 `__global__` 关键字定义内核。此示例演示了如何实现并调用一个简单的内核来相数组：

```cpp
// 用于加两个数组元素的 CUDA 内核函数
__global__ void add(int *a, int *b, int *c, int N) {
    int index = threadIdx.x;
    if (index < N) c[index] = a[index] + b[index];
}

int main() {
    int N = 10;
    // 在主机分配内存
    int size = N * sizeof(int);
    // 为设备分配内存
    int *a, *b, *c;
    int *d_a, *d_b, *d_c;
    // 拷贝数据到设备
    for (int i = 0; i < N; i++) {
        a[i] = i;
        b[i] = i + 1;
    }
    cudaMalloc(&d_a, size);
    cudaMalloc(&d_b, size);
    cudaMalloc(&d_c, size);
    cudaMemcpy(d_a, a, size, cudaMemHostToDevice);
    cudaMemcpy(d_b, b, size, cudaMemHostToDevice);

    // 启动内核
    int threadsPerBlock = 256;
    int numBlocks = (N + threadsPerBlock - 1) / threadsPerBlock;
    add<<<numBlocks, threadsPerBlock>>>(d_a, d_b, d_c, N);

    // 将结果拷贝回主机
    cudaMemcpy(c, d_c, size, cudaMemDeviceToHost);
    for (int i = 0; i < N; i++) {
        printf("%d + %d = %d\n", a[i], b[i], c[i]);
    }

    // 释放内存
    cudaFree(d_a);
    cudaFree(d_b);
    cudaFree(d_c);
    return 0;
}
```

在这个程序中，VectorAdd 内核以指定的配置启动，执行并行向量加法。这个示例封装了 CUDA 编程的核心：定义内核、配置其执行以及管理内存。

精通 CUDA C 语法和结构是开发高性能 GPU 加速应用程序的基础。通过利用内核、理解 CUDA 的内存层次结构并恰当地配置内核执行，开发者可以释放 GPU 的计算能力，用于无数并行处理任务。

## CUDA C 与标准 C 的区别

CUDA C 的引入和演进标志着计算任务处理和执行方式的重大变革，特别是在利用 GPU 的并行处理领域。核心，CUDA（统一计算设备架构）是由 NVIDIA 开发的一种并行计算平台和编程模型，允许开发者使用支持 CUDA 的图形处理器（GPU）进行通用用途处理——这种方法被称为 GPGPU（在图形处理器上的通用计算）。虽然 CUDA C 的语法很大程度上源于标准 C 编程语言，让已经精通 C 编程的人感到熟悉，但存在一些区分 CUDA C 的显著区别，这些区别要求思维和实现上的转变。这些区别不仅是语法上的，也是概念上的，反映了 GPU 相较于 CPU 的根本性架构差异。
