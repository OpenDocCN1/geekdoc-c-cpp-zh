# Understanding Memory Fragmentation:

Memory fragmentation occurs when available memory is broken into small, disjoint blocks, preventing the allocation of larger blocks of memory even though there may be enough free memory in total. Fragmentation can be of two types:

Internal memory is allocated but not used within a block. This happens when the allocated memory is larger than needed. External is enough total memory available, but it is not contiguous, preventing the allocation of larger blocks of memory.
