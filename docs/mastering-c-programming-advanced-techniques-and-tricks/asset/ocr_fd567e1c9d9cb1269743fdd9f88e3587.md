# Using Compiler Security Flags and Extensions for Enhanced Protection

Modern C compilers offer a variety of security flags and extensions that can significantly enhance the protection of C programs against common vulnerabilities such as buffer overflows, format string vulnerabilities, and undefined behaviors. These compiler-assisted security features can serve as an additional layer of defense, making it harder for attackers to exploit such vulnerabilities. This section explores the most impactful compiler security flags and extensions available in popular C compilers like GCC and Clang and provides guidance on their effective use.
