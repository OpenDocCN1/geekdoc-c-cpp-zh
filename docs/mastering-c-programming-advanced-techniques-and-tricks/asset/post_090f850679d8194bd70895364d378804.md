
# Dynamic Arrays and Their Automatic Resizing

Dynamic arrays provide an elegant solution to the limitations posed by static arrays in C programming, mainly the requirement to declare an array's size before compilation and the inability to change this size at runtime. Unlike static arrays, dynamic arrays can adjust their size during runtime to accommodate more elements as needed. This capability significantly enhances the efficiency and flexibility of managing collections where the total number of elements is not known in advance. In this section, we delve into the implementation details of dynamic arrays in C, including how they automatically resize to handle increasing or decreasing dataset.

## Concept and Implementation:

A dynamic array increases its size automatically when it reaches capacity, and optionally, decreases its size when a significant number of elements are removed. The key to efficiently resizing a dynamic array lies in striking a balance between minimizing memory usage and reducing the frequency of resizing operations, which are computationally expensive.

Structural Definition: A typical dynamic array in C can be defined using a structure that encapsulates the array, its capacity, and the current number of elements, as shown below.

```c
typedef struct {
    int *array;
    size_t capacity;
    size_t size;
} DynamicArray;
```

Initial Creation and Resizing: The dynamic array is initially created with a pre-defined capacity. When adding an element this exceeds the capacity, the array’s capacity is increased (usually doubled) to make space for more elements.

```c
void initDynamicArray(DynamicArray *dArray, size_t initialCapacity) {
    dArray->array = malloc(initialCapacity * sizeof(int));
    dArray->capacity = initialCapacity;
    dArray->size = 0;
}

void resizeIfNecessary(DynamicArray *dArray) {
    if (dArray->size == dArray->capacity) {
        dArray->capacity *= 2;
        dArray->array = realloc(dArray->array, dArray->capacity * sizeof(int));
    }
}
```

Adding and Removing Elements: The functions to add or remove elements involve whether resizing is needed either to increase or decrease the array’s capacity.

```c
void addElement(DynamicArray *dArray, int element) {
    resizeIfNecessary(dArray);
    dArray->array[dArray->size] = element;
    dArray->size++;
}

void removeElement(DynamicArray *dArray, size_t index) {
    for (size_t i = index; i < dArray->size - 1; i++) {
        dArray->array[i] = dArray->array[i + 1];
    }
    dArray->size--;
    // Optional: Decrease capacity if size is much smaller than capacity
}
```

Accessing Elements: Accessing elements in a dynamic array is similar to accessing elements in a static array, utilizing the array index.

```c
int getElement(DynamicArray *dArray, size_t index) {
    if (index < dArray->size) {
        return dArray->array[index];
    }
    return -1; // Error value
}
```

Destruction: To avoid memory leaks, a dynamic array must be properly deallocated when it is no longer needed.

```c
void freeDynamicArray(DynamicArray *dArray) {
    free(dArray->array);
    dArray->array = NULL;
    dArray->size = 0;
    dArray->capacity = 0;
}
```

Removing element at index 1
Array size: 2, Array capacity: 4

Dynamic arrays exhibit a blend of flexibility in size management and efficiency in data access, positioning them as indispensable tools in solving real-world problems where data collections are dynamic. Through careful implementation, dynamic arrays can significantly optimize both memory usage and performance in C programs.

# Priority Queues and Binary Heaps for Scheduling Applications

Priority queues are an essential data structure in numerous computer science fields, particularly in scheduling applications where tasks need to be managed according to their urgency or importance. Unlike a typical queue that adheres to the First-In-First-Out (FIFO) principle, a priority queue ensures the element with the highest priority is removed first, regardless of its position in the queue. This section delves into the implementation of priority queues using binary heaps, a highly efficient method that leverages the properties of complete binary trees to ensure optimal enqueueing and dequeuing operations based on priority.

Binary Heaps: A binary heap is a complete binary tree that satisfies the heap property; each node is greater than or equal to (max heap) or less than or equal to (min heap) its children. This property ensures that the highest (or lowest) priority element is always located at the root of the tree. Binary heaps are typically implemented using arrays, where the children of an element at index i are found at indices 2i+1 (left child) and 2i+2 (right child), and the parent of an element at index i is located at

Priority Queue Operations:

- enqueue an element to the priority queue, maintaining the heap property.
- return the element with the highest (or lowest) priority from the queue.
- peek the element with the highest (or lowest) priority without removing it.

Implementing a Priority Queue using a Min Heap: For illustration, we will implement priority queue as a min heap, where elements with lower values have higher priority.

```c
#define MAX_SIZE 100
typedef struct {
    int data[MAX_SIZE];
    int size;
} MinHeap;

void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}

void heapify(MinHeap *heap, int index) {
    int smallest = index;
    int left = 2 * index + 1;
    int right = 2 * index + 2;
    if (left < heap->size && heap->data[left] < heap->data[smallest])
        smallest = left;
    if (right < heap->size && heap->data[right] < heap->data[smallest])
        smallest = right;
    if (smallest != index) {
        swap(&heap->data[index], &heap->data[smallest]);
        heapify(heap, smallest);
    }
}

void enqueue(MinHeap *heap, int item) {
    if (heap->size < MAX_SIZE) {
        heap->data[heap->size] = item;
        int i = heap->size;
        while (i != 0 && heap->data[(i-1)/2] > heap->data[i]) {
            swap(&heap->data[i], &heap->data[(i-1)/2]);
            i = (i-1)/2;
        }
        heap->size++;
    }
}

int dequeue(MinHeap *heap) {
    if (heap->size <= 0) return -1;
    int root = heap->data[0];
    heap->data[0] = heap->data[heap->size - 1];
    heap->size--;
    heapify(heap, 0);
    return root;
}

int peek(MinHeap *heap) {
    if (heap->size <= 0) return -1;
    return heap->data[0];
}
```

# Trie Data Structures for Fast String Searches

Tries, also known as prefix trees, are an invaluable data structure for managing sets of strings over an alphabet. Due to their unique design, tries enable fast queries to ascertain the presence of a string in a set, making them indispensable for applications requiring swift string searches and autocomplete functionalities. In this section, we explore the trie data structure, focusing on its implementation in C for efficient string searches and dictionary operations such as insertion, search, and prefix matching.

## Structure of a Trie:

A trie is a tree-like structure where each node represents a single character of a string. The root node represents an empty string, and paths from the root to a leaf node represent words stored in the trie. Each node may contain an array or map of child nodes for each character of the alphabet and a boolean flag to indicate if the node completes a valid word.

## Trie Node Definition:

To implement a trie in C, we start by defining the trie node structure. For simplicity, let’s assume our alphabet consists of lowercase English letters.

```c
#define ALPHABET_SIZE 26
typedef struct TrieNode {
    struct TrieNode* children[ALPHABET_SIZE];
    bool isEndOfWord;
} TrieNode;
```

## Initializing Trie Nodes:

To initialize a new trie node, we need to allocate memory for it, initialize all its children to NULL, and set isEndOfWord to.

```c
TrieNode* createTrieNode() {
    TrieNode* node = (TrieNode*)malloc(sizeof(TrieNode));
    for (int i = 0; i < ALPHABET_SIZE; i++) {
        node->children[i] = NULL;
    }
    node->isEndOfWord = false;
    return node;
}
```

Insertion:

To insert a string into the trie, we start at the root and traverse or create nodes corresponding to each character of the string. The last character's node is marked as the end of a word.

```c
void insert(TrieNode* root, const char* key) {
    TrieNode* pCrawl = root;
    int index, level;
    int length = strlen(key);
    for (level = 0; level < length; level++) {
        index = key[level] - 'a';
        if (!pCrawl->children[index]) {
            pCrawl->children[index] = createTrieNode();
        }
        pCrawl = pCrawl->children[index];
    }
    pCrawl->isEndOfWord = true;
}
```

Search:

Searching for a key involves traversing the trie follow the characters of the string. If the string is in the trie, each character will successfully lead to the next unit until the end of the string is reached.

```c
bool search(TrieNode* root, const char* key) {
    TrieNode* pCrawl = root;
    int level, length = strlen(key);
    for (level = 0; level < length; level++) {
        int index = key[level] - 'a';
        if (!pCrawl->children[index]) return false;
        pCrawl = pCrawl->children[index];
    }
    return pCrawl->isEndOfWord;
}
```
