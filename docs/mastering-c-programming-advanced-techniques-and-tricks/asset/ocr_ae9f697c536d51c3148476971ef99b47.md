# Implementing a Hash Table with Chaining

Chaining is a popular technique to handle collisions in a hash table. It involves creating a linked list of entries at each bucket if multiple keys hash to the same value.

Hash Table Entry Structure: Each entry in the hash table contains a key, value, and a pointer to the next entry to form a chain.

Inserting Entries: To insert a key-value pair, we use the hash function to determine the appropriate bucket and add the new entry to the front of the linked list at that bucket.

```

newEntry = (Entry*)malloc(sizeof(Entry)); key = key; value = ht[index];
```
