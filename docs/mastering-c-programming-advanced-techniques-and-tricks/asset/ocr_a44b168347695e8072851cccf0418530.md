# Understanding Encryption

Encryption is the process of converting plain text into ciphertext, a scrambled version of the original data, using an encryption algorithm and a key. Only those with the correct key can decrypt the ciphertext back into readable form. Encryption algorithms can be broadly categorized into two types: symmetric and asymmetric.

Symmetric the same key for both encryption and decryption. It is efficient and suitable for encrypting large volumes of data. However, secure key exchange and management can be challenging.
Asymmetric a pair of keys - a public key for encryption and a private key for decryption. While it addresses the key exchange problem of symmetric encryption, it is computationally more intensive.
