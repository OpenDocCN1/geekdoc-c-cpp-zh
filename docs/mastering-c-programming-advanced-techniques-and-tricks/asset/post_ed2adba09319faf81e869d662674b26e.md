## 3.4

## Stacks and Queues: Implementing Functionalities with Arrays and Linked Lists

Stacks and Queues are fundamental data structures that are widely used in computer science to manage data in a specific order. Stacks follow the Last-In-First-Out (LIFO) principle, where the last element added is the first to be removed. Conversely, Queues follow the First-In-First-Out (FIFO) principle, where the first element added is the first to be removed. This section explores how stacks and queues can be implemented using arrays and linked lists in C programming, providing a detailed perspective on their operations, advantages, and practical applications.

## Stacks

### Stack Operations:

- Push an element to the top of the stack.
- Pop an element and return the top element of the stack.
- Peek the top element of the stack without removing it.
- Check if the stack is empty.

Implementing Stacks using Arrays: Arrays provide a simple way to implement stacks, using an integer to track the top element’s index.

```c
#define MAX_SIZE 100
typedef struct {
    int items[MAX_SIZE];
    int top;
} Stack;

void initializeStack(Stack* stack) {
    stack->top = -1;
}

void push(Stack* stack, int item) {
    if (stack->top == MAX_SIZE - 1) {
        stack->items[++stack->top] = item;
    }
}

int pop(Stack* stack) {
    if (stack->top == -1) {
        return -1;
    }
    return stack->items[stack->top--];
}

int peek(Stack* stack) {
    if (stack->top == -1) {
        return -1;
    }
    return stack->items[stack->top];
}

int isEmpty(Stack* stack) {
    return stack->top == -1;
}
```

Implementing Stacks using Linked Lists: For dynamic size requirements, linked lists offer a more flexible implementation of stacks without a fixed size limit.

```c
typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* top;
} StackLinkedList;

void initializeStackLinkedList(StackLinkedList* stack) {
    stack->top = NULL;
}

void pushLinkedList(StackLinkedList* stack, int item) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = item;
    newNode->next = stack->top;
    stack->top = newNode;
}
```

```c
int popLinkedList(StackLinkedList* stack) {
    if (stack->top == NULL) {
        return -1;
    }
    Node* temp = stack->top;
    int item = temp->data;
    stack->top = temp->next;
    free(temp);
    return item;
}

int peekLinkedList(StackLinkedList* stack) {
    if (stack->top == NULL) {
        return -1;
    }
    return stack->top->data;
}
```

## Queues

### Queue Operations:

- Enqueue an element to the end of the queue.
- Dequeue an element and return the front element of the queue.
- Peek the front element of the queue without removing it.
- Check if the queue is empty.

Implementing Queues using Arrays: Similar to stacks, arrays can be used to implement queues. However, to efficiently manage the queue’s front and rear, we utilize a circular queue approach.

```c
#define MAX_SIZE 100
typedef struct {
    int items[MAX_SIZE];
    int front, rear;
} Queue;

void initializeQueue(Queue* queue) {
    queue->front = -1;
    queue->rear = -1;
}

void enqueue(Queue* queue, int item) {
    if ((queue->front == 0 && queue->rear == MAX_SIZE - 1) || 
        (queue->front == (queue->rear + 1) % MAX_SIZE)) {
        // Queue is full
    } else {
        if (queue->front == -1) { // First element to enqueue
            queue->front = queue->rear = 0;
            queue->items[queue->rear] = item;
        } else if (queue->rear == MAX_SIZE - 1 && queue->front != 0) {
            // Wrap around
            queue->rear = 0;
            queue->items[queue->rear] = item;
        } else {
            queue->items[++queue->rear] = item;
        }
    }
}

int dequeue(Queue* queue) {
    if (queue->front == -1) {
        return -1;
    }
    int data = queue->items[queue->front];
    if (queue->front == queue->rear) { // Single element
        queue->front = queue->rear = -1;
    } else if (queue->front == MAX_SIZE - 1) {
        queue->front = 0;
    } else {
        queue->front++;
    }
    return data;
}
```

Implementing Queues using Linked Lists: Linked lists provide an elegant and efficient way to implement queues dynamically, avoiding the circular queue complexity.

```c
typedef struct QueueNode {
    int data;
    struct QueueNode* next;
} QueueNode;

typedef struct {
    QueueNode *front, *rear;
} QueueLinkedList;

void initializeQueueLinkedList(QueueLinkedList* queue) {
    queue->rear = NULL;
    queue->front = NULL;
}

void enqueueLinkedList(QueueLinkedList* queue, int item) {
    QueueNode* newNode = (QueueNode*)malloc(sizeof(QueueNode));
    newNode->data = item;
    newNode->next = NULL;
    if (queue->rear == NULL) {
        queue->front = queue->rear = newNode;
    } else {
        queue->rear->next = newNode;
        queue->rear = newNode;
    }
}

int dequeueLinkedList(QueueLinkedList* queue) {
    if (queue->front == NULL) {
        return -1;
    }
    QueueNode* temp = queue->front;
    int data = temp->data;
    queue->front = queue->front->next;
    if (queue->front == NULL) {
        queue->rear = NULL;
    }
    free(temp);
    return data;
}
```

By implementing stacks and queues using both arrays and linked lists, we offer a detailed exploration of their functionalities, potential applications, and adaptability in programming practices. Whether managing data dynamically with linked lists or in a fixed-size environment with arrays, understanding these fundamental structures is crucial for proficient C programming.

## Hash Tables: Designing and Handling Collisions

Hash tables are a pivotal data structure that underpins the design of efficient algorithms and data storage systems. By offering fast data insertion, deletion, and lookup operations, hash tables significantly enhance the performance of modern software applications. The essence of a hash table lies in its ability to map keys to values through a hashing function, thereby organizing data for swift access. This section delves into the nitty-gritty of designing hash tables in C, including the pivotal aspect of handling collisions—a scenario where two keys hash to the same index in the table.

## Designing a Basic Hash Table

The primary components of a hash table include:

- Hash function that converts a key into an index in the hash table’s array.
- Array slots where the data (value) associated with a key is stored.
- Collision Handling strategy to manage situations where multiple keys hash to the same bucket.

### Simple Hash Function: A fundamental step in designing a hash table involves formulating an efficient hash function. For demonstration, we’ll use a simple modulo-based hash function that maps any integer key to a slot in the hash table.

```c
#define TABLE_SIZE 100
unsigned int hash(int key) {
    return key % TABLE_SIZE;
}
```

## Implementing a Hash Table with Chaining

Chaining is a popular technique to handle collisions in a hash table. It involves creating a linked list of entries at each bucket if multiple keys hash to the same value.

### Hash Table Entry Structure: Each entry in the hash table contains a key, value, and a pointer to the next entry to form a chain.

```c
typedef struct Entry {
    int key;
    int value;
    struct Entry* next;
} Entry;

typedef Entry* HashTable[TABLE_SIZE];
```

### Inserting Entries: To insert a key-value pair, we use the hash function to determine the appropriate bucket and add the new entry to the front of the linked list at that bucket.

```c
void insert(HashTable ht, int key, int value) {
    int index = hash(key);
    Entry* newEntry = (Entry*)malloc(sizeof(Entry));
    newEntry->key = key;
    newEntry->value = value;
    newEntry->next = ht[index];
    ht[index] = newEntry;
}
```

### Searching for Entries: Searching involves hashing the key to locate the appropriate bucket and then traversing the linked list to find the entry.

```c
Entry* search(HashTable ht, int key) {
    int index = hash(key);
    Entry* entry = ht[index];
    while (entry != NULL) {
        if (entry->key == key) return entry;
        entry = entry->next;
    }
    return NULL; // Key not found
}
```

### Deleting Entries: Deletion requires finding the entry in the linked list at the hashed index and then removing it from the list.

```c
void delete(HashTable ht, int key) {
    int index = hash(key);
    Entry* entry = ht[index];
    Entry* prev = NULL;
    while (entry != NULL) {
        if (entry->key == key) {
            if (prev == NULL) {
                ht[index] = entry->next; // First entry in the list
            } else {
                prev->next = entry->next;
            }
            free(entry);
            return;
        }
        prev = entry;
        entry = entry->next;
    }
}
```
