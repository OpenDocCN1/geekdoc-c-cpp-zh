# Interpreting Watchpoint Output

Once a watchpoint is set, GDB will pause execution anytime the watched variable changes, displaying a message similar to the following:

Hardware watchpoint 1: counter

```
Old value = 1
New value = 3
main () at example.c:6
6      counter += i;
```

This output indicates that program execution was halted because counter changed from 1 to 3 at line 6 in the file The developer can then examine the call stack, variable states, and surrounding code to understand why the change occurred.
