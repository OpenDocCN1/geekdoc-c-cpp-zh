# Understanding Integer Overflows

An integer overflow occurs when an arithmetic operation attempts to create a numeric value that exceeds the range that can be represented with a given number of bits. In C, the behavior of an overflowed integer is undefined, often wrapping around to produce a negative value or a lower positive value unintended by the developer.

overflows can be exploited to bypass security checks, cause buffer overflows, or even lead to arbitrary code execution.
