```
gcc -O2 -fprofile-generate -o program program.c
```

Step 2: Profiling Run

Next, run the program with a typical workload:

```
./program
```

This run will generate a profile (**.gcda* files) based on the execution.

Step 3: Optimization Compilation

Finally, recompile the program using the profile data to guide optimizations:

```
gcc -O2 -fprofile-use -o program_optimized program.c
```

The 'program_optimized' binary should be more efficient than one compiled without PGO, as optimizations are now based on actual runtime data.

Profile-Guided Optimization offers a robust method for enhancing the performance of C programs by leveraging real-world execution data. By guiding optimization decisions based on how a program is actually used, PGO enables the creation of highly efficient software tailored to its specific workload.
