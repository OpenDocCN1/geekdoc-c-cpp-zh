Insertion Operations: Insertion in a linked list can be performed in various
ways:

+   - At the beginning of the list.
- After a given node.
- At the end of the list.

Insertion at the beginning: This involves creating a new node and pointing
its next to the current then updating the head to this new node.

```
void insertAtBeginning(Node** head, int newData) { newNode =
(Node*)malloc(sizeof(Node)); = newData; = *head; = newNode; }
```

Code Output:

After insertion at the beginning: 5 -> 3 -> 1 -> NULL

Insertion after a given node: This involves adjusting the next pointer of
the given node to point to the new node, and the new node's next to point
to what was previously after the given node.

```
void insertAfterNode(Node* prevNode, int newData) { (prevNode ==
NULL) // Cannot insert after NULL newNode =
(Node*)malloc(sizeof(Node)); = newData; = prevNode->next; =
newNode; }
```
