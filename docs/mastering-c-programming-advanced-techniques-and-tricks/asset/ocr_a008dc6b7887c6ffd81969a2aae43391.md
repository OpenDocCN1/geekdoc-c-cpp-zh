# Types of Automated Tools

A broad range of automated tools exists in the marketplace, spanning open-source and commercial offerings. Examples include:

Static Analysis like Clang Static Analyzer, Coverity, andCppcheck can automatically detect a multitude of security vulnerabilities and coding errors in C source code.

Dynamic Analysis AddressSanitizer, and LeakSanitizer offer deep insights into the runtime behavior of C programs, helping to identify memory leaks, buffer overflows, and other runtime errors.

Fuzz Testing (American Fuzzy Lop) and LibFuzzer are examples of fuzzing tools that automatically generate unexpected inputs to programs, exposing potential crashes and vulnerabilities.
