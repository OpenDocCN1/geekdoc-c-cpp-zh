# Capabilities of Automated Tools

Automated code analysis tools leverage a variety of techniques, including static code analysis, dynamic analysis, and formal verification, to identify vulnerabilities such as buffer overflows, integer overflows, memory leaks, and misuse of APIs. These tools can also enforce coding standards, such as CERT C and MISRA C, ensuring adherence to best practices for secure programming.

Static Code source code without executing it, identifying potential vulnerabilities based on code structure and known patterns. Dynamic running the program in a controlled environment to observe its behavior and detect issues like memory corruption or unauthorized access attempts.

Formal mathematical methods to prove or disprove the correctness of algorithms with respect to a certain formal specification or property.
