# An Introduction to gprof

‘gprof’ is a performance analysis tool for C programs that provides both flat profiles and call graph information. A flat profile shows how much time your program spent executing each function, while the call graph shows the call relationships between functions and how much time was spent in the call trees.

To use ‘gprof’, you first need to compile your program with the ‘pg’ flag, which instructs the compiler to insert special instrumentation code into the executable. After running your program, a file named ‘gmon.out’ is generated, containing profiling data that ‘gprof’ can analyze.
