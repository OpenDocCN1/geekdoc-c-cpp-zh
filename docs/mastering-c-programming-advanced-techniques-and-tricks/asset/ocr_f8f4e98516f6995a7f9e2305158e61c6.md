# Fundamentals of Secure Communication Protocols

Secure communication protocols encompass a suite of cryptographic protocols that provide security over a network. Key components include:

data is read only by intended recipients by converting it into a format that is unreadable without the decryption key.
the identity of the parties involved in the communication to prevent impersonation.
that the data has not been tampered with during transmission.

TLS, the successor to SSL, is currently the most widely used protocol for secure communication on the internet.
