# Code Example: Detecting a Buffer Overflow

Consider the following simple C program that copies a string into a buffer without checking the size of the input:

```
#include #include int main() { buffer[10]; buffer); 0; }
```

This program exhibits a buffer overflow because the length of the string "a very long string" exceeds the size of the buffer array. Running this program under Valgrind using the command valgrind ./yourprogram will give output indicating memory issues.
