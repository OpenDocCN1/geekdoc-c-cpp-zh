# Code Example: Using Conditional Breakpoints

Imagine you are debugging a loop that iterates thousands of times, but you are only interested in the state of the program when a certain variable, is equal to 999.

```
int main() { counter; (counter = 0; counter < 1000; ++counter) { Some complex logic 0; } }
```

In gdb, you can set a conditional breakpoint to halt the program when counter reaches 999, without stopping at each iteration:

```
break if counter == 999
```
