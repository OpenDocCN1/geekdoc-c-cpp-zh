# Interpreting gprof Output

The ‘gprof’ output report, which is redirected to ‘analysis.txt’ in the above command, provides detailed information about the execution profile of the program. The key sections to pay attention to are the flat profile and the call graph.

Flat profile:

Each sample counts as 0.01 seconds.

```
% cumulative self total
time seconds seconds calls ms/call ms/call
70.93 0.61 0.61 quicksort
29.07 1.00 0.25 1 250.00 1000.00 main
```

The flat profile section shows that the ‘quicksort’ function is where most of the execution time is spent. This is a sign that optimization efforts should perhaps focus there.
