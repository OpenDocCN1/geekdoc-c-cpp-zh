For a two-dimensional array (matrix), where the first index moves along rows and the second along columns, accessing elements in row-major order (horizontally) exhibits better spatial locality on most systems because this is how they are stored in memory.

```
#define ROWS 100 #define COLS 100 int matrix[ROWS][COLS]; // Accessing elements in row-major order for better locality for i = 0; i < ROWS; i++) { j = 0; j < COLS; j++) { }
```

Optimizing memory access patterns and improving data locality are paramount for developing high-performance C programs. By organizing data to enhance spatial and temporal locality, and carefully structuring code to access this data efficiently, cache utilization can be maximized, resulting in faster program execution. While these optimizations require careful consideration and sometimes a deeper understanding of the underlying hardware, they often lead to significant performance gains.
