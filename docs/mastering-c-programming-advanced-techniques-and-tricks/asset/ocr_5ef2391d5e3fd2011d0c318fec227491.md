# Understanding Thread Sanitizer

Thread Sanitizer is a runtime tool designed to detect threading issues in C/C++ programs. It intercepts all thread operations, including lock management, and checks for various concurrency problems, such as:

+   - Data races
- Deadlocks
- Use after free in multithreaded contexts
- Double locks
- Thread leaks

To use Thread Sanitizer, you must compile your program with the -fsanitize=thread flag using a supported compiler, such as GCC or Clang. This flag instructs the compiler to include the TSan instrumentation code in the resulting binary.
