```
NSString *field2Str = [[NSString alloc] initWithUTF8String: field2];

NSString *str = [[NSString alloc] initWithFormat:@"%@ - %@",
                 field1Str, field2Str];

NSLog(str);

[field1Str release];
[field2Str release];
[str release];
}
//--deletes the compiled statement from memory--
sqlite3_finalize(statement);
```

To retrieve the value for the first field in the row, you use the `sqlite3_column_text()` function by passing the `sqlite3_stmt` object as well as the index of the field you are retrieving. For example, to retrieve the first field of the returned row, you use:

```
char *field1 = (char *) sqlite3_column_text(statement, 0);
```

To retrieve an integer column (field), use the `sqlite3_column_int()` function.
