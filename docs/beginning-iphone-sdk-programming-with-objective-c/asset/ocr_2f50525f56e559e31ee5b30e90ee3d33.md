# How It Works

What you have done is basically modify the Root.plist file to store three preferences — Login Name, Password, and Favorite Color. For the password field, you use the IsSecure key to indicate that the value must be masked when displaying it to the user. Also of particular interest is the Favorite Color preference, for which you use the Titles and Values keys to display a list of selectable choices and their corresponding values to store on the phone.
