# Running the Application

To execute an application, you first select the active SDK to use. You also choose whether you want to test it on a real device or use the included iPhone Simulator. You do so by selecting from the Overview list (see Figure B-9).

![](bbox=[0.13, 0.4, 0.6, 0.75])

FIGURE B-9

To run the application, press Command-R, and Xcode will build and deploy the application onto the selected device or Simulator.
