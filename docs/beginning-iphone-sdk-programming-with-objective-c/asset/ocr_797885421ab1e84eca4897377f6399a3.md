Click Done to dismiss the dialog.

In Xcode, look for the Active SDK item. If this item is not already on the toolbar, choose View → Customize Toolbar and add it to the toolbar. Then, under Active SDK, select the OS version number of the device that is currently connected to your Mac. In my case, my iPhone is running the older iPhone OS 2.0, so I selected `iPhone Device (2.0)` (see Figure E-22).
