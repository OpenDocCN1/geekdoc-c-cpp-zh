# Adding a View Controller

To manually add a View Controller class to the project, right-click the project name (BasicUI2) in Xcode and choose Add ⌘ New File. You'll need to download the code to do this.

You see the New File window, as shown in Figure 3-32. Under the iPhone OS section on the left, select Cocoa Touch Class and then select the UIViewController subclass template on the right. Select the With XIB for User Interface option so that in addition to adding a View Controller class, it will also add an XIB file. Click Next.
