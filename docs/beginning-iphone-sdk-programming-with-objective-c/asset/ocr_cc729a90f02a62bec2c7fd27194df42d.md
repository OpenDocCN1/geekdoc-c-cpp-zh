# How It Works

The action sheet works very similarly to the Alert view but is visually different. To show the action sheet, you need to specify the view that the action sheet is originating from:

```
```objective-c
UIActionSheet *action = [[UIActionSheet alloc]
                         initWithTitle:@"Title of Action Sheet"
                         delegate:self
                         cancelButtonTitle:@"OK"
                         destructiveButtonTitle:@"Delete Message"
                         otherButtonTitles:@"Option 1", @"Option 2", nil];
[action showInView:self.view];
```
```

Note that the button as specified in the `destructiveButtonTitle` parameter is displayed in red.
