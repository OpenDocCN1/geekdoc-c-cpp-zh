# iPhone Simulator

The iPhone Simulator (see Figure 1-7) is a very useful tool included in the iPhone SDK that you can use to test your application without using your actual iPhone/iPod Touch. The iPhone Simulator is located in the /Developer/iPhone OS/Platforms/iPhoneSimulator.platform/Developer/Applications/ folder. Most of the time, you don’t need to launch the iPhone Simulator directly — running (or debugging) your application in Xcode automatically brings up the iPhone Simulator. Xcode installs the application on the iPhone Simulator automatically.
