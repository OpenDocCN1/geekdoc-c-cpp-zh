
## Performance Measurement

Edge fund managers and CTAs can use leverage and take short positions (as opposed to traditional managers who cannot), and since their returns over time will be a direct function of leverage and their long-short portfolio mix, so the manager's performance should be measured on a cash basis (unleveraged) 'relative' to the 'portfolio risk' in order to offset the effects of leverage. The risk proxy measure used is generally based on the second moment of the distribution of returns e.g the 'volatility' or some other measurable statistical estimate of the variation of the spread of returns associated with the manager. This chapter will look at the various performance measurements which can be used to analyse hedge fund returns in a risk-adjusted sense using the most common metrics applied in industry.

In order to implement the performance measurements described in this chapter we will developing another class PMetrics in the same way as we did for the Stats class in the previous chapter. Source 5.1 shows the skeleton of the PMetrics class we will add to as required.

### 5.2 INTUITION BEHIND RISK-ADJUSTED RETURNS

Consider CTAs Manager A (MgrA) and Manager B (MgrB) and assume:
- both managers are operating in the same scale (e.g. diversified futures)
- they both use similar instruments for investment and trading purposes.

Also assume that funding is available for an investor who has $5 million to a managed account with choice and is hoping one CTA will manage all part of their capital through Power of Attorney (POA).

¹Notional funding can be used to maximise capital efficiency since with marked account, only a certain amount of collateral (C) is required for potential downturns. If the managed account has minimum size of P, then actual committed are M + C, and the notional leverage G obtained by investment as a function of funding for a fixed minimum size is given by G = P/A.

²The POA is an official document signed by the investor legally authorizes the CTA to manage the client's account and receive payment for management services.

double PMetrics::M1M2(const std::vector<double>& v, const char& c, const int& f)
{
    size_t n = v.size();
    double tmp; // Declare a temporary variable
    std::vector<double> m2; // Declare vector of doubles for Skew
    double mean = Mean(v, c); // Inherit Mean from Stats class
    double std = StdDev(v, c, f); // Inherit St. Dev. from Stats class

    // Calculate M1M2
    for (size_t j=1; j<v.size(); j++) {
        tmp = 0.0;
        for (size_t i=0; i<n; i++) {
            tmp = mean[j-1] / std[j-1];
        }
        m2.push_back(tmp);
    }
    return m2;
}

#include "PMetrics.h"
#include <algorithm>
#include <iostream>
using std::make_pair;
using std::setw;
using std::cout;
using std::fixed;
using std::setprecision;

// GetIdx()
class GetIdx
{
public:
    GetIdx(const std::vector<double>& target) : m_target(target) {}
    virtual ~GetIdx() {}

    inline bool operator() (const double a, const double b) const { return m_target[a] > m_target[b]; }
protected:
private:
    const std::vector<double>& m_target;
};

std::map<string, int>::iterator PMetrics::GetName(std::map<string, int>& names, int n)
{
    // Iterate through all elements in the map and get index value
    std::map<string, int>::iterator it = names.begin();
    while (it != names.end()) {
        if (it->second == n)
            return it;
        it++;
    }
}

void PMetrics::SortPrint(const std::vector<double>& v, const std::vector<std::string>& s)
{
    // Declare a map for the names
    std::map<string, int> names;
    for (size_t i=0; i<s.size(); i++)
    {
        // Insert names into map
        names.insert(make_pair(s[i], i+1));
    }
    std::vector<int> y; // Declare 1D vector for indexes
    // Initialise indexes
    for (size_t i = 0; i < v.size(); ++i)
        y.push_back(i);
    // Sort and store index
    sort(y.begin(), y.end(), GetIdx(v));

    cout << "\n";
    cout << fixed << setprecision(2);
    for (size_t i=0; i<y.size(); i++)
    {
        // Find and match name to index
        std::map<string, int>::iterator it = GetName(names, y[i]+1);
        if (it != names.end())
            cout << " " << it->first << "\t" << v[y[i]] << "\n";
    }
}
