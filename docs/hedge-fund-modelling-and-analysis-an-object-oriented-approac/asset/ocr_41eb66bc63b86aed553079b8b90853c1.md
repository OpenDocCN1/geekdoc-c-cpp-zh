# 4.8.1 Standard Normal Distribution

If $\mu = 0$ and $\sigma = 1$ the distribution is said to be a standard normal distribution (or z-distribution), such that:

```
$X \sim N(0,1)$
```

With the following PDF:

```
$f(x) = \frac{1}{\sqrt{2\pi}} \exp(\left(-\{x^2}{2}\right)$
```

The normal random variable of a standard normal distribution is known as a z-score (or score). Every normal random variable $X$ can be converted into a z-score using the following transformation:

```
$z = \frac{X - \mu}{\sigma}$
```

where $X$, $\mu$ and $\sigma$ are the random variable, mean and standard deviation from the original normal distribution, respectively. The z-score indicates the number of standard deviations above or below the mean e.g. if the z-score is 2, then the original random variable $X$ is 2 standard deviations above the mean. A negative z-score means that $X$ is below the standard deviation by a certain amount.
