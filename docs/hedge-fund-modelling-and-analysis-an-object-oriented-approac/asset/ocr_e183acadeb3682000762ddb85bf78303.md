Note that type casting will not change the type of the variables from integer only the type of the result to double.

# 1.3.4 Variable Scope

A variable can have either global (i.e. public) or local (i.e. private) scope depending on where it is declared within the program. Any variables declared with global should be prefixed with the keyword const. An example is shown in Source 1.5.

```
SOURCE 1.5: VARIABLE SCOPE
// ...
// GLOBAL variable
int globalN = 144;

int main() {
SetConsoleTitle("Console Output"); // Set title of console
window

// LOCAL variable
int localN = 72;

cout << "\n" << "# of data points (LOCAL) = " << localN;
cout << "\n" << "# of data points (GLOBAL) = " << globalN;

cin.get(); // Pause console window
return 0; // Return null integer
}
```
