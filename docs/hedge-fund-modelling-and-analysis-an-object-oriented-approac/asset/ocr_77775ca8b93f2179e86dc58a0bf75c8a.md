# 4.5 PROBABILITY DISTRIBUTIONS

In order to understand probability distributions, it is important to know what is meant by a random variable. When a numerical value of a variable is determined by an unknown (or chance) event, that variable is said to be random. Random variables can either be discrete or continuous. For example, suppose an experiment consists of flipping a coin six times and recording the number of heads that appear after each toss. The number of heads from a random process (i.e. flipping the coin) and the actual number is a value between 0 and 6 i.e. a finite integer. Therefore, the number of heads is said to be a discrete random variable. Now suppose the experiment is performed, but the average number of heads after flipping the coin six times is recorded. The average number of heads results from a random process, however, the actual number of heads can now be any value between 0 and 1 i.e. an infinite number of values. In this case, the average number of heads is said to be a continuous random variable.

A probability distribution describes all the possible values a random variable can take within a given range. Probability distributions can be discrete or continuous. For example, consider an experiment in which a coin is flipped two times and a random variable X represent the number of heads that occur. The four outcomes to this experiment are HH, HT, TH and TT so the discrete random variable X can only have values, 0, 1 or 2.
