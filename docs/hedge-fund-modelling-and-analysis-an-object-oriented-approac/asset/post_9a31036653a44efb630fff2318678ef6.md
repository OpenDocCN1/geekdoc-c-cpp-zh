# 1.6.5 The do ... While loop

The do ... while loop is exactly the same as the while loop, except that the statement block (or single statement) is evaluated at least once even if the condition is not satisfied. The do ... while loop is written as:

```cpp
do
{
    statements
}
while(condition)
```

A typical use of the do ... while loop is when the condition that determines the end of the loop is determined within the loop as shown in Source 1.17.

SOURCE 1.17: THE DO ... WHILE LOOP
```cpp
// ...
int n;
// do...while loop
do
{
    cout << "\n" << "Enter number (0 to end loop):" ";
    cin >> n;
    cout << "\n" << "The number was " << n << "\n ";
}
while(n != 0);
cout << "0 ends the loop!" << "\n ";
// ...
```

# 1.7 ARRAYS

C++ provides a data structure, the array, which stores a fixed-size sequential collection of elements (data) of the same type. All arrays consist of contiguous memory locations with the lowest address corresponding to the first element and the highest address to the last element. Source 1.18 shows a typical initialisation and implementation of an array structure. Note that in C++ the first element of an array is [0] i.e. indexing starts at 0 not 1.

# SOURCE 1.18: ARRAYS

```cpp
// ...

// Declare an array of 10 integers
int n[10];

// Initialise elements of array
for (int i=0; i<10; i++)
{
    n[i] = i + 100; // Set element at location i to i + 100
}

cout << "\n " << "Element" << setw(13) << "Value" << "\n";
```

In Source 1.18, we have made use of setting field width to make the output look more tidy using setw() which is declared in the header <iomanip>.

Just like arrays, vectors use contiguous storage locations for their elements (data) within so-called sequence containers. However, unlike arrays, their size can change dynamically, with their storage being handled automatically by the container. Internally, vectors use a dynamically allocated array to store them. Arrays need to be reallocated in order to grow when new elements are inserted, which implies allocating a new array and moving all elements to it. This is a relatively expensive task in terms of processing time, and thus, vectors do not allocate each time an element is added to the container. Instead, vector containers may allocate some extra storage to accommodate for possible growth, and thus the container may have an actual capacity greater than the storage strictly needed to contain its elements (i.e. its size). Source 1.19 shows a typical initialisation and implementation of a vector.

```cpp

vector<double> v; // Vector of doubles

v.push_back(0.054);

Note that when using vectors for loops it is often necessary to explicitly set the increment counter to unsigned int. The at() function returns the element at the index; if the index is out of bounds, it throws an exception.

# 1.9 FUNCTIONS

Often programs can become long and hard to debug; functions allow us to break down code into manageable units. A function is defined by its return type, name, and parameter list. The structure of a function is:

```cpp
type function_name(type param1, type param2, ...)
{
    statements
    return value;
}
```

In C++, it is possible to declare a function before defining it using a prototype. The prototype is a copy of the function header terminated with a semicolon (;). Be aware when declaring a function (through the prototype) we refer to parameters; when calling the function, we refer to arguments. Arguments are the values passed to the function when it is called.

In Source 1.20, x and y are the parameters of the Product() function and a b are the arguments. When Product() is called the values entered for a and b are passed to x and y and subsequently used in the function. The function can change the values of x and y but cannot change the values of a and b. If it is a requirement that the value of a parameter passed to a function is only allowed to read and not change the value inside the function, the parameter can be set to constant in both prototype and header declaration. For example:

```cpp
double Product(const x, double y);
```

In this case, y of x cannot be changed in the body of the function; however, y can still be changed. When using arguments in a function it is also possible to initialize the values for the parameters in the function prototype. For example:

```cpp
int Init(int x, int y = 10, int z = 30);
```

Note that once a parameter has an initial value then all parameters to the right of it must also be declared with initial values. We have already seen that it is not explicitly necessary to state parameter names in function prototypes, the third parameter in Init() is quite acceptable. In C++, function prototypes are usually put in files with extension .h, known as header files, while function definitions go into files with the extension .cpp. Preprocessor directives (#) can be used to avoid multiple includes during compilation, for example:

```cpp
#ifndef HEADERNAME_H
#define HEADERNAME_H
...
contents of the header file.
#endif
```

On most modern compilers it is possible to replace the above statements with a single pragma statement as follows:

```cpp
#pragma once
```
