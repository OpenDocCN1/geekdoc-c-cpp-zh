# 5.6 THE MINIMUM ACCEPTABLE RETURN

These two metrics are based around the concept of separating outside 'good volatility' and downside 'bad volatility'. The variance and the standard deviation are two-sided measures of the degree of the spread in an asset's returns. However, often it is desirable to specify a Minimum Acceptable Return (MAR) threshold for a certain statistic in order to define kind of minimum acceptable loss threshold.

# 5.6.1 The Sortino Ratio

The Sortino¹⁴ ratio is defined as:

> $$R_p - MAR$$

$$Sortino = \frac{1}{T} \sum_{t=0, R_p<MAR}^T (R_{p,t} - MAR)^2 \quad (5.19)$$
