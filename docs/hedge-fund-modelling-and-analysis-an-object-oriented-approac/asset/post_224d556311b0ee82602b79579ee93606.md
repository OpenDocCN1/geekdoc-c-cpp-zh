
The se is used for calculating the t-statistic used in statistical tests of significance. The t-statistic is compared with the value from the Student's t distribution so as to determine a p-value. The se for the intercept (a) is given by:

```
$se_a = se = \sqrt{\frac{\sum_{i=1}^n X_i^2}{n \sum_{i=1}^n (X_i - \bar{x})^2}}$
```

And for the slope (b) by:

```
$se_b = \sqrt{\frac{se^2}{\sum_{i=1}^n (X_i - \bar{x})^2}}$
```

The subsequent t-statistic for the intercept (a) is given by:

```
$t_a = \frac{a}{se_a}$
```

And for the slope (b) by:

```
$t_b = \frac{b}{se_b}$
```

The Student's t-distribution is generally defined as the probability distribution of a set of random variables that best fit the data without knowing the population deviation. The particular form of the t-distribution depends on the number of degrees of freedom i.e. the number of independent observations in a set of data. The higher the degrees of freedom, the closer the t-distribution to the standard normal distribution. The t-distribution is very similar in shape to the normal distribution but has fatter tails resulting in more values further away from the mean value as shown in Figure 4.18.

t-distribution plays a central role in the associated t-test for assessing the statistical significance of the difference between two sample means, the development of confidence intervals to determine the difference between two population means, and in linear regression analysis.

![](img/2d1ac831a270b8b08f8b8ec2205913dc_178_0.png)

The $p$-value is the probability of obtaining a test statistic (e.g. $t$-statistic) at least as extreme as the one that was actually observed, assuming that the NULL hypothesis is true. It is often necessary to reject the NULL hypothesis when the $p$-value is less than 0.05 i.e. a 5% chance of rejecting the NULL hypothesis when it is true. When the NULL hypothesis is rejected, the result is said to be statistically significant. That is, if 95% of the $t$-distribution is closer to the mean than the $t$-statistic for the coefficient of the regression, this relates to a $p$-value of 5%. With such a value there is only a 5% chance that the results of the regression analysis would have occurred in a random distribution, or there is a 95% probability that the coefficient is having some effect on the regression model. It is important to note that the size of the $p$-value for a coefficient indicates nothing about the effect the coefficient is having on the regression model i.e. it is possible to have a coefficient with a very low $p$-value which has only a minimal effect on the model.

double LinReg::StdErr(const Vector2D& v, const char c)
{
    if(v.size() < 3) m_utils.ErrorChk("More than one series required!");

    if(c == 's' && (c != 'i')) m_utils.ErrorChk("Type must be 's' (slope) or 'i' (intercept)!");

    int n = v.size();
    double xx, x2; // xy = (x-bar)*(y-bar), x2 = x^2
    double avg = m_stats.Mean(v); // Calculate Means using Stats class

    for (int j=0; j<v.size(); j++)
    {
        xx = 0.0, x2 = 0.0;
        for (int i=0; i<n; i++)
        {
            xx += pow(v[i][j] - avg, 2);
            x2 += pow(v[i][j], 2);
        }
    }
}
