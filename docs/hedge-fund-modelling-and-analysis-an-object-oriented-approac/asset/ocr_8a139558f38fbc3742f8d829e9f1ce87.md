Both default constructors and destructors are provided automatically in C++ so do not have to them explicitly implemented in the class. However, experienced programmers usually include them for completeness and especially if any member variables need to be initialise with default values. Constructors are generally used to initialise data whereas destructors are used to tidy up any outstanding code issues once an object has been destroyed. There are several methods of initialising data with constructors, for example ::initialising the data inside the constructor:

```
AClass::AClass()
{
m_x = 5;
}
```

It is also possible to write generalised constructors, for example:

```
AClass::AClass(int x, int y, int z)
{
m_x = x;
m_y = y;
m_z = z;
}
```
