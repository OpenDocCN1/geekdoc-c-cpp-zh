To the extent that the distribution of returns is non-normal, the SR falls short. It is a particularly poor performance metric when comparing positively skewed strategies like trend following to negatively skewed strategies like option selling (see Figure 5.9). In fact, for positively skewed return distributions, performance is actually achieved with less risk than the SR suggests. Conversely, standard deviation underestimates risk for negatively skewed return distributions, the strategy is actually riskier than the SR suggests.
