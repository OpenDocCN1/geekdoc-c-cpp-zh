Just like arrays, vectors use contiguous storage locations for their elements (data) within so-called sequence containers. However, unlike arrays, their size can change dynamically, with their storage being handled automatically by the container. Internally, vectors use a dynamically allocated array to store them. Arrays need to be reallocated in order to grow when new elements are inserted, which implies allocating a new array and moving all elements to it.
