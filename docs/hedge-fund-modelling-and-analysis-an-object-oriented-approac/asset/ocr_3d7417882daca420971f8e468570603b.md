# 1.10 OBJECT ORIENTED PROGRAMMING

As already mentioned, only those parts of the C++ language that we need to success-
fully implement the tools and techniques in the rest of the book have been covered.
However, one very useful development in C++, and something we will make great use
of this book, is the concept of Object-Oriented Programming (OOP). OOP allows
t building of large and complex programs that can be broken down into smaller
self-contained reusable code units known as classes. In OOP, data and its manipula-
t brought together into a single entity called an object. Programs consist
of or more objects interacting with each other only to solve a particular problem. The
object is responsible for its data and manipulated by a predefined
list of applicable operations. In essence, OOP aims to emulate the ways humans-
 with the world around them. In this way, pretty anything can be modelled
as an object. A typical day, get out of bed, have a cup of coffee, catch a bus
to work, go to a restaurant for lunch, go to your home, eat dinner with a knife
and fork, watch television etc. It is possible to look on life as a series of interactions
with things. These things we call objects. We can view all of these objects as cons-
sisting of data (properties) and operations that can be performed on them (methods).
