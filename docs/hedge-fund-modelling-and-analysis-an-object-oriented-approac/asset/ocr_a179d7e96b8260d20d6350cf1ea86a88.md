Once a regression model has been fitted to a set of data, a further investigation of the error terms allows another test of the validity of the linearity assumption. The error terms are determined by the difference between the observed values and those predicted from the linear regression model, that is:

$$\hat{Y}_i = Y_i - \hat{Y}_i$                               (4.25)

where $\hat{Y}_i = a + bX_i$. A residual plot as shown in Figure 4.19 can reveal the possibility of any fundamental nonlinear relationship between the two variables as well as the presence of outliers. Such outliers may represent erroneous data, or indicate a poorly fitting regression model. If the residual plot shows a random scatter of data points, as in Figure 4.20, this is consistent with the model being linear.
