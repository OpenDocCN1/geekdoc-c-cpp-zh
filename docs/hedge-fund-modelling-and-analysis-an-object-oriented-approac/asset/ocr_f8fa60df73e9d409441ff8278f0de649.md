If each week day is not explicitly initialized, they are automatically assigned the values 0, 1, 2, 3, etc., starting with the variable Sun. Note that the default value starts at 0 and not 1. Alternatively, it is possible to initialise one or more of the variables to any integer value, for example:

```
enum WeekDays {
Sun = 10,
Mon,
Tue,
Wed = 6,
Thu,
Fri,
Sat
};
```

Variables that are not explicitly initialized are given initial values count-wards from the preceding initialized variable i.e. Sun = 10, Mon = 11, Tue = 6, Wed = 7, Thu = 8 and so on.

# OPERATORS

Operators are used to perform a specific operation on a set of operands in an expresssion. Operators can be of two types:

+   - Unary – take only one argument
- Binary – take two arguments.



The assignment operator simply assigns a value to a variable, for example:

```
x = 4;
```

The statement above assigns to the variable x the value 4. Note that the assignment operator always reads from -> left, and never the other around. The following statement is valid in C++:

```
x = y = z = 3;
```

In this statement, the value 3 is assigned to all three variables x, y and z. Expressions that are evaluated within the assignment operator, such as:

```
x = x + 1;
```
