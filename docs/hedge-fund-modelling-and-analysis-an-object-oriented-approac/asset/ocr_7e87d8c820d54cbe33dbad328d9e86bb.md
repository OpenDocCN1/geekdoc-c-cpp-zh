Notice that we longer pass v by constant reference but by reference since we are making changes to v within the member function to calculate the slope for each hedge fund based on their individual regression against the market benchmark (SDX). We have also added a handle to the LinReg class through the variable m_linreg so that we can call LinReg member functions (e.g. Slope()) when we invoke TR(). Remember we must include the LinReg class header file in Pmetrics.h to allow access to the Lin functions.

The TR is a more commonly used for equity portfolios (which we are using a global equity market measurement, then the benchmark must be relevant. Since we are using a global equity market benchmark, it follows that CTAs (i.e. CTA1, CTA2, CTA3) and global macro funds (i.e. CM1, GM2) have little or no exposure to the benchmark, so to use it for any of the risk-adjusted metrics would be practically meaningless. However, most equity markets are highly correlated, the global benchmark would be efficient at capturing the returns associated with a passive investment. As such, it may be a suitable metric for the hedge funds LS1, LS2, LS3 and the market neutral hedge funds MN1 and MN2 all of which are assumed to be global equity hedge funds.

From the results we can see that LS2 is now ranked highest and LS3 the bottom ranked hedge fund. Primarily because LS2 has a beta of 0.08 and LS3 has a beta of -0.04. In fact, the results can be highly misleading, since both may be no different from zero which is noted using hypothesis testing (see Chapter 4). Note that, in such a market neutral case, the TR approaches infinity. The higher the maxima and minima of the ranks of the TR, therefore, the more market neutral the fund is and so more the manager's returns are subsequently less influenced by the market which is a sign of outperformance with respect to the market. In fact, the TR is difficult to interpret and clearly unsuitable for analysing non-equity hedge funds.
