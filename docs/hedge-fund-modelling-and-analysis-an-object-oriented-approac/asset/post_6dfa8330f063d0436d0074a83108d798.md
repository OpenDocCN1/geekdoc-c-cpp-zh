
# Performance Measurement

As can be seen, the SR produces a ranked list which captures very well in one metric of the risk-adjusted return (or return per unit). This metric is already a vast improvement over just using the annualised returns for performance since the hedge fund manager can use leverage (as opposed to traditional fund managers who cannot use leverage), so they need to be relative to their ‘peers’ in a risk-adjusted manner. As mentioned earlier, a poorer manager can simply use leverage to gain superior results when measured against the SR performance, their results would not seem superior. It is for this reason that the SR is a very commonly used metric in the world of hedge funds – enabling a manager or investor to get a quick picture of whether a strategy or fund is worth pursuing. In general, the SR is the first port of call for any hedge fund analysis, and if SR is high, further analysis is required to assess other characteristics of the fund.

The disadvantage of the SR is that it is absolute in the sense that it does not measure the manager meaningfully against a market benchmark (i.e. the risk-free rate). However, other measures will be described in the following sections which are relative versus a market benchmark for ranking purposes. Other disadvantages are that the SR is based exclusively on mean-variance, so higher moments are neglected and assumed to be zero. The SR assumes that the returns are Gaussian which is not always the case for hedge funds, especially the more exotic relative strategies as highlighted by Lhabitant (2007).

In this section, we will consider performance metrics based around the Market Model (MM). The MM differs from the Capital Asset Pricing Model (CAPM) in that it is based around a regression of excess returns of individual assets over some reference market benchmark (or aggregate index). MM can be written as:

```
$R_i = \alpha_i + R_F + \beta_i(R_M - R_F) + \epsilon_i \quad (5.5)$
```

in terms of risk preferences:

```
$R_i - R_F = \alpha_i + \beta_i(R_M - R_F) + \epsilon_i \quad (5.6)$
```

According to the CAPM all priced assets with respect to publicly known information should fall on the Security Market Line (SML) as shown in Figure 5.10.

In 5.10 Hedge Fund B exhibits greater than expected performance (i.e. –ve alpha) where Fund A exhibits less than expected performance (i.e. –ve alpha), both with respect to the market benchmark. From the CAPM we can estimate this measure of a hedge fund’s added value:

```
$\alpha_p = R_p - E^{CAPM}(R_M) \quad (5.7)$
```

```
$\alpha_p = (R_p - R_F) - \beta_p(R_M - R_F) \quad (5.8)$
```

where $E^{CAPM}(R_M)$ is the 'unconditional expectation operator' i.e. the expected return on the market (not conditioned on anything else occurring) applied to the benchmark (or market index). Equation (5.8) allows the calculation of a manager's added value relative to some beta controlled quality of systematic market return premium; (5.8) is commonly referred to as *Jensen's alpha* i.e.

$\alpha_J = (R_P - R_F) - \beta_P(R_M - R_F) \quad (5.9)$

## 5.5.1 The Information Ratio

The *information ratio* (IR) as described by Goodwin (1998) is similar to the Sharpe ratio in that it is based on a fund's return and volatility. However, where the Sharpe ratio uses a risk-free rate as a benchmark for the numerator, the information ratio goes one step further and uses a *market reference* benchmark. If $R_{Pt}$ is the return on a fund in period $t$ and $R_{Bi}$ is the return on a benchmark portfolio in period $t$ then $\Delta_t$, the excess return can be written as:

$\Delta_t = R_{Pt} - R_{Bi} \quad (5.10)$

$\bar{\Delta}$ is the mean excess returns from $t=1$ to $T$ i.e.

$$\bar{\Delta} = \frac{1}{T} \sum_{t=1}^{T} \Delta_t \quad (5.11)$$

$\sigma_{\Delta}$ is the standard deviation of the excess returns from the benchmark (aka tracking error) written as:

$$\sigma_{\Delta} = \sqrt{\frac{1}{T} \sum_{t=1}^{T}(\Delta_t - \bar{\Delta})^2} \quad (5.12)$$

then, the IR is given by:

$$IR = \frac{\bar{\Delta}}{\sigma_{\Delta}} \quad (5.13)$$

Since we are now using a market reference we must import 10_funds_mkt.dat which includes the monthly returns for a global equity benchmark (SDX). Figure 5.11 shows the same 10 hedge funds along with the new benchmark data. Source 5.5 shows the IR() declaration and definition.

```cpp
// ...
// PMetrics.h
// ...
double IR(const vector<double>& v); // IR()

// ...
// PMetrics.cpp
// ...
// IR()
double PMetrics::IR(const vector<double>& v) {
    int n = v.size();
    double tmp; // Declare a temporary variable

    vector<double> vtmp; // Declare a temporary holding vector
    vector<vector<double>> vadj; // Declare 2D vector for adjusted returns
    vector<vector<double>>::iterator ROW; // Declare 1D iterator for the ROWS
    vector<vector<double>>::iterator COL; // Declare 1D iterator for COLS
    int i = 0; // Declare and initialise counter to zero

    for(auto ROW = v.begin(); ROW != v.end(); ++ROW) {
        i = 0; // Reset counter
        vtmp.clear(); // Reset 1D vector
        for(auto COL = ROW->begin(); COL != ROW->end(); ++COL) {
            // Subtract market benchmark
            vtmp.push_back(COL[0].size() - i);
        }
        vadj.push_back(vtmp); // Fill 2D vector with adjusted returns
    }

    vector<double> ir; // 1D vector of doubles for Information ratio
    double mean = Mean(vadj); // Inher Mean from Stats class
    double std = Stddev(vadj); // Inher St. Dev. from Stats class

    // Calculate Information ratio using j. (5.13)
    for(int j=0; j<vadj[0].size(); j++) {
        tmp = 0.0;
        for (int i=0; i<n; i++) {
            tmp = mean[j] / std[j];
        }
        ir.push_back(tmp);
    }
    return ir;
}
```

You will see from Source 5.5 that we have introduced some new syntax and made use of the STL library discussed in Chapter 1. For example, we are now making use of explicit iterators, i.e.

```cpp
vector<vector<double>>::iterator ROW;
vector<double>::iterator COL;
```

These allow us to walk through the vector v using ROW and COL iterators and point (*) to each element as we go and subsequently modify each element if necessary. In our case subtracting the market benchmark (SDX) from each of the 10 hedge fund returns. Using C++11, the keyword auto can be used to avoid specifying the very long, complicated type of the iterator. Note that we are also walking through the vector using begin() and end() member functions of the vector class. begin() returns an iterator pointing to the first element in the vector v. end(), on the other hand, returns an iterator referring to the past-end element in the vector container. The past-end element is the theoretical element that would follow the last element in the vector. The ranges used by functions of the STL library do not include the element pointed to by their closing iterator; this function is often used in combination with begin() to specify a range including all the elements in the container.

The address of a variable can be obtained by preceding the name of a variable with an ampersand sign (&), known as address-of-operator. For example:

```cpp
a = &var;
```
