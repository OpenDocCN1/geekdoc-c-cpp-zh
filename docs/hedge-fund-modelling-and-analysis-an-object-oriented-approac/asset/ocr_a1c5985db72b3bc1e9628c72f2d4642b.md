# 1.10.7 Constructors and Destructors

The default constructor is a member function that has the same name as the class and invoked automatically once an instance of an object is created. Similarly, the default destructor has the same name as the class prefixed with a tilde (~) and invoked automatically once an object is destroyed. In practice, there is only one default destructor although the constructor can have several overloaded methods. It is generally good practice to include the keyword virtual before the destructor so as to alleviate any potential memory leaks.
