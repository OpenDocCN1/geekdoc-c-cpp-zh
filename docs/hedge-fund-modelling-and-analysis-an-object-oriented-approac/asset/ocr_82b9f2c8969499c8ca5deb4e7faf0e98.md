Note the situation if the investor had uninformed as to the virtues of risk-adjusted investing through CTAs. If they had erroneously chosen CTA B (at first glance whereas CTA B had higher returns) to create their 30% return expectation using annual notional funding, their volatility would have been higher at 35.9% (30.0/1.81 x 14.14). This example demonstrates that using risk-adjusted returns to measure the manager's relative performance and by correctly choosing CTA A to invest in, their expected volatility for reaching an annual return of 30.0% would be around 23.0% for CTA A versus 35.9% for CTA B – a significant difference of 12.9%.

This example shows why in the world of capital-efficient leveraged investing using collateralised margining (something inherent with futures markets), the manager with the highest risk-adjusted return should be in hot demand and as a consequence, many CTAs and hedge fund managers use the Sharpe ratio as their longterm performance objective function.
