We briefly encountered a friend in Chapter 1; a friend can access the private and protected members of the class in which it is declared a friend. Friendship may allow a class to be better encapsulated by granting per-class access to parts of its implementation that would otherwise have to be public. This increased encapsulation comes at the cost of tighter coupling between classes.



Markowitz's work ultimately led to the development of mean-variance portfolio optimisation⁵ as a method of achieving a desired level of expected return for a degree of portfolio risk i.e. variance. Given a target return r*, the mean-variance optimisation problem can be solved as follows:

```
min \frac{1}{2}w^T\Sigma w
```

subject to the constraints:

```
w^TR = r*
\sum_{i=1}^N w_i = 1
```

Such an optimisation problem can be solved analytically (as opposed to numerically) by using the method of Lagrange multipliers.



A portfolio is a frontier portfolio if it minimizes the variance for a given expected return i.e. a frontier portfolio solves the following optimisation problem:

```
min \frac{1}{2}w^T\Sigma w
```

subject to the constraints:

```
w^TR = r*
w^T\1 = 1
```

> ⁵Such a technique is known as a quadratic programming (QP) involving the optimisation (minimising or maximising) of a quadratic function of several variables subject to a set of linear constraints on these variables. In this case, portfolio variance is a quadratic function of the weights w_i.
