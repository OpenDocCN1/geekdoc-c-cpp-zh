Quantiles are points taken at regular intervals from a probability distribution. More formally, the quantile function for any probability distribution is the inverse of the Cumulative Distribution Function (CDF). Some $q$-quantiles have special names, for example:

+   - 4-quantiles are known as quartiles
- 100-quantiles are known as percentiles.

For an ordered set of data from smallest to largest the required percentile is a value that represents the number below which a certain percentage of the data fall e.g. the 5th percentile is the value below which 95% of all the observations fall.

Note that $VaR_{1-\alpha}$ scales with the volatility (see Box 7.2). VaR is usually reported on a monthly basis in negative dollar terms, which further emphasizes that it is a measure of losses, or as an absolute dollar amount. In (7.2), since $Z_{\alpha}$ is negative, $VaR_{1-\alpha}$ will always be a negative value indicating a dollar loss. Some managers report VaR on a monthly basis in percentage terms so as be consistent with the reporting of other risk measures.
