In Source 1.10, an integer holds the value entered by the user when prompted by the cout statement. Once the user inputs a value and presses Enter the value is stored in and subsequently output to the screen through the second cout statement, cin can only store the value into a once the Enter key has been pressed. It is possible to allow the user to input several values when prompted using the concept of chaining as shown in Source 1.11.
