You will see from Source 5.5 that we have introduced some new syntax and made use of the STL library discussed in Chapter 1. For example, we are now making use of explicit iterators, i.e.

```
VDI2::iterator ROW;
VDI1::iterator COL;
```

These allow us to walk through the vector v using ROW and COL iterators and point (*) to each element as we go and subsequently modify each element if necessary. In our case subtracting the market benchmark (SDX) from each of the 10 hedge fund returns. Using C++11, the keyword auto can be used to avoid specifying the very long, complicated type of the iterator. Note that we are also walking through the vector using begin() and end() member functions of the vector class. begin() returns an iterator pointing to the first element in the vector v. end(), on the other hand, returns an iterator referring to the past-end element in the vector container. The past-end element is the theoretical element that would follow the last element in the vector. The ranges used by functions of the STL library do not include the element pointed to their closing iterator, this function is often used in combination with begin() to specify a range including all the elements in the container.

The address of a variable can be obtained by preceding the name of a variable with an ampersand sign (&), known as address-of-operator. For example:

```
a = &var;
```
