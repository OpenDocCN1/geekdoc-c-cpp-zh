# 1.10.10 Operator Overloading

Operator overloading allows the manipulation of standard C++ operators to change the way they are implemented. For example, suppose you had two class objects you wanted to add together, operator overloading allows you to treat the operator + differently for these objects. Table 1.7 shows a list of operators that can be overloaded in C++.

| Table 1.7 Operators that can be overloaded in C++ |
|--- |
| + - * / < > += - = * /= << >> |
| <= >= != ! <= >= && || = = [ ] , * |
| ++ - % & ^ ! | ~ & = | & || = = [ ] , -* -> - |
| new delete new[] | delete [] |
