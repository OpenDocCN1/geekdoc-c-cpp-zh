poly (many) and morph (forms), will again only be mentioned here for completeness. Objects interact by calling each other's methods. How does object A know the supported methods of object B, so that it can call a valid method of B? In general, there is no magic for A to determine the methods of B, which means A must know the class of B. However, polymorphism means that A does not need to know the class of another instance in order to call a method of B. In other words, an instance of class A can call a method of another instance, without knowing its exact class. The calling instance need only know that the other instance supports a method, it does not need to know the exact class of the other instance. It is the instance receiving the method call that determines what happens, not the calling instance.
