## 1.3.3 Type Casting

One way to force an expression to produce a result that is of a different type to the variables declared in the expression is to use a construct called cast (i.e. type casting). Source 1.4 shows an example of declaring two variables as int and dividing them to produce an int and double division through type casting.

> SOURCE 1.4: TYPE CASTING

```cpp
// ...

cout << "\n" << a/b << "\n"; // Integer division
cout << " " << (double)a/b << "\n"; // Type casting to double division

// ...
```

## 1.3.4 Variable Scope

A variable can have either global (i.e. public) or local (i.e. private) scope depending on where it is declared within the program. Any variables declared with global should be prefixed with the keyword const. An example is shown in Source 1.5.

```cpp
SOURCE 1.5: VARIABLE SCOPE
// ...
// GLOBAL variable
int globalN = 144;

int main() {
    SetConsoleTitle("Console Output"); // Set title of console window

    // LOCAL variable
    int localN = 72;

    cout << "\n" << "# of data points (LOCAL) = " << localN;
    cout << "\n" << "# of data points (GLOBAL) = " << globalN;

    cin.get(); // Pause console window
    return 0; // Return null integer
}
```

![](img/2d1ac831a270b8b08f8b8ec2205913dc_24_0.png)

In Source 1.5, you can see that the variable globalN has been declared globally and initialised to the value 144. Global variables can be accessed from anywhere in the program once they have been declared. Local variables, on the other hand, as localN can only be used within the block enclosed by the braces ({}) in which it is declared.

## 1.3.5 Constants

Constants are fixed values assigned to variables that cannot be changed once they have been declared and initialised. We have already used literal constants when a variable was declared and initialised in Source 1.2:

```cpp
string FirstName = "Paul";
```

Or, as in Source 1.5:

```cpp
int localN = 72;
```

With symbolic constants the const keyword is used in front of the declaration and initialisation, for example:

```cpp
const double Volatility = 0.18;
```

Enumerated constants are an alternative way of creating a series of integer constants. Suppose you wanted to assign an integer value of 0 to 6 to the days of the week starting at Sunday. This could be achieved using a list of symbolic constants written as:

```cpp
const int Sun = 0;
const int Mon = 1;
const int Tue = 2; etc.
```

However, with enumeration it is possible to write:

```cpp
enum WeekDays
{
    Sun,
    Mon,
    Tue,
    Wed,
    Thu,
    Fri,
    Sat
};
```

If each week day is not explicitly initialized, they are automatically assigned the values 0, 1, 2, 3, etc., starting with the variable Sun. Note that the default value starts at 0 and not 1. Alternatively, it is possible to initialise one or more of the variables to any integer value, for example:

```cpp
enum WeekDays {
    Sun = 10,
    Mon,
    Tue,
    Wed = 6,
    Thu,
    Fri,
    Sat
};
```

Variables that are not explicitly initialized are given initial values count-wards from the preceding initialized variable i.e. Sun = 10, Mon = 11, Tue = 6, Wed = 7, Thu = 8 and so on.

## OPERATORS

Operators are used to perform a specific operation on a set of operands in an expresssion. Operators can be of two types:

- Unary – take only one argument
- Binary – take two arguments.

The assignment operator simply assigns a value to a variable, for example:

```cpp
x = 4;
```

The statement above assigns to the variable x the value 4. Note that the assignment operator always reads from left, and never the other around. The following statement is valid in C++:

```cpp
x = y = z = 3;
```

In this statement, the value 3 is assigned to all three variables x, y and z. Expressions that are evaluated within the assignment operator, such as:

```cpp
x = x + 1;
```

are read as ‘the value 1 to x and assign this value to x’ i.e. increase the value of x by 1. Indeed, this statement can also be written in a more compact form:

```cpp
x += 1;
```

There are other compound assignment operators in C++, such as:

| %= | Modulo and assignment |

## 1.4.3 Relational Operators

Sometimes it is necessary to test the relationship between two expressions so that some action can be performed based on the outcome of the result. Relational operators can be used to perform such tasks. The most common C++ relational operators are shown in Table 1.5.

The only result of a relational operator when evaluated is either 1 (true) or 0 (false) i.e. a Boolean value. C++ automatically converts a Boolean value to an integer as shown in Source 1.8.

Table 1.5 Common relational

| Operator | Name |
| --- | --- |
| == | Equal to |
| != | Not equal to |
| > | Greater than |
| >= | Greater than or equal to |
| < | Less than |
| <= | Less than or equal to |

# SOURCE 1.8: RELATIONAL OPERATORS

```cpp

cout << "4 is equal to 3 = " << (4 == 3) << "\n";
cout << "4 is not equal to 3 = " << (4 != 3) << "\n";

// ...

// Declare variable
```
