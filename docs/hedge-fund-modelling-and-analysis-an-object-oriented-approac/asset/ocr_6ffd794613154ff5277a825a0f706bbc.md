Statements beginning with a hash symbol (#) indicate directives to the preprocessor that initialise the compiler is first invoked, in this case, to inform the compiler that certain functions from the C++ Standard Library must be included. #include windows.h gives the program access to certain functions in the library, such as SetConsoleTitle() whilst #include <iostream> enables console input and output (I/O). Typical objects in the iostream library include cin and cout which are explicitly included using the statement at the top of the program. Writing using std::cout at the top of the program avoids the need to keep retyping std through the scope resolution operator (::) every time cout is used.
