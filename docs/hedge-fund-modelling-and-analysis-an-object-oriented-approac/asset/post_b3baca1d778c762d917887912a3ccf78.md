## 7.2 VALUE-AT-RISK

The Value-at-Risk (VaR) for a portfolio of assets is the worst estimated loss over a given horizon (e.g. monthly) at a specified level of confidence (e.g. 95%). That is, the risk of the hedge fund portfolio at a specified level of probability in the left-tail of the P&L distribution. VaR is often based on the assumption that asset returns follow a normal distribution and the performance of the hedge fund portfolio is affected by a set of linear market factors. As discussed in Chapter 4, under such assumptions it is possible to describe the distribution of asset returns by just two statistical parameters i.e. $\mu$ and $\sigma$. That is, assuming that a distribution of hedge fund P&Ls is characterized by a normal distribution, then at a confidence $c\%$ there is an expected loss for the hedge fund of no more than $z_{\alpha}\sigma$ standard deviations below the mean over the next month.

For example, at a 95% confidence level (5th percentile or significance), 95% of the time loss is expected to be no more than 1.645$\sigma$. That, the critical value is

## 7.3 TRADITIONAL VaR METHODS

There are generally three accepted methods for estimating VaR, namely:

1. Historical simulation
2. Parametric method
3. Monte-Carlo simulation

Each has a different approach in how they describe the distribution.

### 7.3.1 Historical Simulation

Of all the traditional methods, the historical simulation (or non-parametric) method is the simplest to implement since only a set of historic returns is required. In general, the historical simulation requires a relatively long history of returns to be meaningful.

![](img/2d1ac831a270b8b08f8b8ec2205913dc_262_0.png)
**Figure 7.3** Histogram monthly VaR

Estimating VaR by simulation involves calculating a series of simulated P&Ls based on a set of historic returns. A set of simulated P&Ls are generated for each hedge fund return and ordered smallest to largest using a relevant sorting algorithm. For a 95% confidence level ($\alpha=0.05$), the $100\alpha = 5^{th}$ percentile in the sorted P&L is used to estimate VaR. That is, if we want to know the expected loss at 95% confidence level then we look at the $5^{th}$ percentile, on an historical basis, the simulated P&L distribution tells us 95% of the time we will no more than this. Source 7.2 shows an implementation of the historical simulation method to estimate the monthly VaR at a 95% confidence level for the CTA Index (i.e. *cta_index.dat*) with a value of $100m (AuM). The historical monthly VaR is estimated at $1,670,000 for a 95% confidence level i.e. there is a 5% probability that the CTA Index will lose $1,670 000 in value. If required, to express VaR in percentage terms, simply divide by the current value of the hedge fund AuM (i.e. $100m). With historical simulation, since actual monthly returns are used, the distribution is already assumed to be centred, so there is no need to subtract the relevant number of $\sigma$'s from $\mu$ in order to get the VaR figure.
