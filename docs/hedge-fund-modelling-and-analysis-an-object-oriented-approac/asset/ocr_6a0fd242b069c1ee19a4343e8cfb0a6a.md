# BOX 4.1: SQUARE ROOT RULE – STANDARD DEVIATION

If a series of hedge fund returns are quoted in monthly or quarterly figures, they can be transformed into an equivalent annualised series using the so-called square root rule. To get the annualised figure, the original standard deviation is multiplied by the square root of the frequency representing the original period e.g. 12 for monthly and 4 for quarterly. More formally:

```
$\sigma_{annual} = \sigma_{monthly} \times \sqrt{12}$
$\sigma_{annual} = \sigma_{quarterly} \times \sqrt{4}$
```
