# 1.5 INPUT AND OUTPUT

For the majority of cases, programs will require inputs from the keyboard and outputs to the console window. We have already encountered the <iostream> header file from the C++ Standard Library which allows us to handle I/O in our programs. As we have already seen in all of the above examples, output to the console window is handled with cout along with the insertion operator (<<). Inputs from the keyboard are handled by cin along with the extraction operator (>>). Source 1.10 shows an example of using both cout and cin.
