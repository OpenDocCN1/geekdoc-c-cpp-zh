Algorithm 3.4: (Pattern Matching). The pattern matching table F(Qi, T) of a pattern P is in memory, and the input is an N-character string T = T1 T2 ... TN. This algorithm finds the INDEX of P in T.

+   1. [Initialize.] Set K := 1 and S1 = Q0
+   2. Repeat Steps 3 to 5 while S_K ' P and K £ N.
+   3. Read T_K.
+   4. Set S_K + 1 := F(S_K, T_K). [Finds next state.]
+   5. Set K := K + 1. [Updates counter.]
+   [End of Step 2 loop.]
+   6. [Successful?]
+   If S_K = P, then:
+   INDEX = K - LENGTH(P).
+   Else:
+   INDEX = 0.
+   [End of If structure.]
+   7. Exit
