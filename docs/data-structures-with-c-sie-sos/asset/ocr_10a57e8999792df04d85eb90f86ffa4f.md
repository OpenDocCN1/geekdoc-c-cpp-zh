Selecting the (i + 1)th record can be done by accessing PA[i] and following the pointer found there to the entry of A in which the (i + 1)th record begins. A[PA[i]] is the name assigned to the base of this record We should always ensure that the selection process is done first PA followed by A. where each array takes a fixed time and hence the (i + 1)th record is selected. Traversing through the records becomes easy by making use of PA, which can be seen in the following program.

```
traverse(A, PA, N)
/* Traverses through the N records stored in A which are pointed to by
indices stored in the pointer array PA */
int A[], PA[], N;
{
int i;
for (i=0; i<N; i++)
process(A, PA, i);
}
```

When pointer arrays are used it leads to additional storage but gives a solution for the variable-length records. All these records stored in an array have related pointers which are easy to use on violating language typing constraints.
