# Iteration Logic (Repetitive Flow)

The third kind of logic refers to either of two types of structures involving loops. Each type begins with a Repeat statement and is followed by a module, called the *body of the loop*. For clarity, we will indicate the end of the structure by the statement [End of loop.]

or some equivalent.

Each type of loop structure is discussed separately.

The *repeat-for loop* uses an index variable, such as K, to control the loop. The loop will usually have the form:

```
Repeat for K = R to S by T:
[Module]
[End of loop.]
```

The logic of this structure is pictured in Fig. 2.5(a). Here R is called the *initial value*, S the *end value* or *test value*, and T the *increment*. Observe that the body of the loop is executed fitst with K = R, then with K = R + T, then with K = R + 2T, and so on. The cycling ends when K > S. The flow chart assumes that the increment T is positive; if T is negative, so that K decreases in value, then the cycling ends when K < S.
