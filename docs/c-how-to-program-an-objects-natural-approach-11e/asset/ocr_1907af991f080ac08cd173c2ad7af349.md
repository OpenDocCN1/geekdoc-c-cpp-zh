# 15.7 Testing C++20 Concepts with static_assert

Concepts produce compile-time bool values, which you can test at compile-time with a static_assert declaration.69 **static_assert** was developed to add compile-time assertion support for reporting incorrect usage of template libraries.70 Figure 15.9 tests our custom Numeric concept from Section 15.6.1 in a multiply function template that is not concept constrained.71

```
```cpp
 1   // Fig15_09.cpp
 2   // Testing custom concepts with static_assert.
 3   #include <iostream>
 4   #include <string>
 5
 6   template<typename T>
 7   concept Numeric = std::integral<T> || std::floating_point<T>;
 8
 9   template<typename T>
10   auto multiply(T a, T b) {
11      static_assert(Numeric<T>);
12      return a * b;
13   }
14
15   int main() {
16      using namespace std::string_literals;
17      multiply(2, 5); // OK: int is Numeric
18      multiply(2.5, 5.5); // OK: double is Numeric
19      multiply("2"s, "5"s); // error: string is not Numeric
20   }
```
