This is a popular type of array-processing application (Fig. 6.8). We wish to summarize the number of responses of each rating (that is, 1–5). The array responses (lines 9–10) is a 20-element array of integers with the students’ survey responses. It’s declared `constexpr` because its values do not (and should not) change and are known at compile-time. We use a six-element array frequency (line 18) to count each response’s number of occurrences. Each frequency element is used as a counter for one of the survey responses and is initialized to zero. As in Fig. 6.7, we ignore element 0.

// Fig06_08.cpp
// Poll analysis program.
#include <format>
#include <iostream>
#include <array>

int main() {
   // place survey responses in array responses
   constexpr std::array responses{
      1, 2, 5, 4, 3, 5, 2, 1, 3, 1, 4, 3, 3, 2, 3, 3, 2, 2, 2, 5};

   // initialize frequency counters to 0
   constexpr size_t frequencySize{6}; // size of array frequency
   std::array<int, frequencySize> frequency{};

   // for each response in responses, use that value
   // as the index to determine element to increment
   for (const int& response : responses) {
      ++frequency.at(response);
   }

   std::cout << std::format("{:>2}\n", "Rating", "Frequency");

   // output each array element
   for (size_t rating{1}; rating < frequency.size(); ++rating) {
      std::cout << std::format("{:>6}{:>12}\n",
         rating, frequency.at(rating));
   }
}
