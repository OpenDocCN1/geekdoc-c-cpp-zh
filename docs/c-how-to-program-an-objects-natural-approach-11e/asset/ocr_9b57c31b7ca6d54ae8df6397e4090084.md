# ARCHITECT'S INSTRUCTIONS — BARRIER-FREE DESIGN

In addition to the general instructions and structural notes, the following items for barrier-free design are to be considered without restriction:

+   1. Approach paths and entrance areas are to be designed without steps, and accessible without restriction.
+   2. Door systems are to be designed as automatic sliding doors or automatic swing doors.
+   3. All stairways are to be supplemented with a sufficiently dimensioned ramp or a barrier-free lift. This does not apply to stairways that only serve as secondary escape routes.

All required plans are to be prepared in accordance with DIN 18040-1.

Drawings in red: changes from the preliminary planning stage.
