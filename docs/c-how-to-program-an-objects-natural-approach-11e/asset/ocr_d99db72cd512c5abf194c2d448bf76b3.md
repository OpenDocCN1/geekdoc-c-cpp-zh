# §9.9.1 C++20 std::format Presentation Types

When you specify a placeholder for a value in a format string, the std::format function assumes the value should be displayed as a string unless you specify another type. In some cases, the type is required—for example, if you want to specify precision for a floating-point number or change the base in which to display an integer. In these cases, you can specify the presentation type in each placeholder. Figure 19.20 shows the various presentation types.

```
```cpp
// fig19_20.cpp
// C++20 text formatting presentation types.
#include <format>
#include <iostream>

int main() {
    // floating-point presentation types
    std::cout << "Display 17.489 with default, .1 and .2 precisions:\n"
        << std::format("f: {:f}\n.1f: {:0.1f}\n.2f: {:0.2f}\n\n", 17.489);

    std::cout << "Display 1000000000000000000.0 with f, e, g and a\n"
        << std::format("f: {:f}\ne: {:e}\ng: {:g}\na: {:a}\n\n",
            1000000000000000000.0);

    // integer presentation types; # displays a base prefix
    std::cout << "Display 100 with d, #b, %o and #x:\n"
        << std::format("d: {0:d}\n%b: {0:#b}\n%o: {0:#o}\n%x: {0:#x}\n", 100);

    // character presentation types
    std::cout << "Display 65 and 97 with c:\n"
        << std::format("{:c} {:c}\n", 65, 97);

    // string presentation type
    std::cout << "Display the \"a\" with s:\n"
        << std::format("{:s}\n", "hello");
}
