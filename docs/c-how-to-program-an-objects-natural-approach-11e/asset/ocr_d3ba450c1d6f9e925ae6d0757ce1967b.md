# ### 6.13 **Multidimensional arrays**

You can use arrays with two dimensions (i.e., indices) to represent tables of values with data arranged in rows and columns. To identify a particular table element, we must specify two indices. By convention, the first identifies the row, and the second identifies the column. **2-D arrays** that require two indices to identify a particular element are called two-dimensional arrays or **2-D arrays**. arrays with two or more dimensions are known as multidimensional arrays. The following diagram illustrates a two-dimensional array named a:

![](bbox=[0.282, 0.508, 0.718, 0.66])

The array contains three rows and four columns, so it’s said to be a 3-by-4 array. In general, an array with *m* rows and *n* columns is called an *m*-by-*n* array.

We have identified every element in the diagram above with an element name of the form a[row][column]. Similarly, you can access each element with an assignment

```
a.at(i).at(j)
```

The elements names in row 0 all have a first index of 0; the elements names in column 3 all have a second index of 3.
