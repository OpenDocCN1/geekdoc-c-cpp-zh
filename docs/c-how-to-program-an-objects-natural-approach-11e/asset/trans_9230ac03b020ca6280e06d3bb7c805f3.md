**17.3** 实现共享可变资源互斥访问的一种常见方法是创建临界区。这些同步代码块使用 `<mutex>` 头文件中的功能以原子方式执行。一个 `std::mutex` 一次只能由一个线程拥有。需要独占访问资源的线程必须首先获取互斥量的锁——通常是在代码块的开头。其他试图执行需要同一互斥量的操作的线程将被阻塞，直到第一个线程释放锁——通常是在代码块末尾。此时，被阻塞的线程可以尝试获取锁并继续执行该操作。
