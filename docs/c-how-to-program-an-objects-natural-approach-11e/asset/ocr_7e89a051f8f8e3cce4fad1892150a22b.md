# ## 8.9 Inserting Characters into a string

std::string provides overloaded member function for inserting characters into a string (Fig. 8.8). Line 14 uses string member function insert to insert "middle " before index 10 of s1. Line 15 uses insert to insert "xx" before s2's index 3. The last two arguments specify the starting and last element of "xx" to insert. Using string::npos causes the entire string to be inserted.

```
```cpp
// Fig08_08.cpp
// Demonstrating std::string insert member functions.
#include <format>
#include <iostream>
#include <string>

int main() {
    std::string s1{"beginning end"};
    std::string s2{"12345678"};

    std::cout << std::format("Initial strings:\ns1: {}\ns2: {}\n\n",
        s1, s2);

    s1.insert(10, "middle "); // insert "middle " at location 10
    s2.insert(3, "xx", 0, std::string::npos); // insert "xx" at location 3

    std::cout << std::format("Strings after insert:\ns1: {}\ns2: {}\n",
        s1, s2);
}
