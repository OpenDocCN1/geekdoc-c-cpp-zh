# **13.33** *(Optimizing the Simple Compiler)*

When a program is compiled and converted into SML, a set of instructions is generated. Certain combinations of instructions often repeat themselves, often in triplets called productions. A production normally consists of three instructions such as *load*, *add* and *store*. For example, here are five of the unoptimized SML instructions produced while compiling the program in Fig. 13.13:

```
04 +2098    (load)
05 +3097    (add)
06 +2196    (store)
07 +2096    (load)
08 +2198    (store)
```

The first three instructions are the production that adds 1 to y. Instructions 06 and 07 store the accumulator value in temporary location 96, then load the value from that location right back into the accumulator so instruction 08 can store the value in location 98. Often a production is followed by a load instruction for the same location that was just stored.
