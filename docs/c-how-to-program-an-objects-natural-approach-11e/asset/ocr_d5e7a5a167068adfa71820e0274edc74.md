# deitel.math Primary Module Interface Unit

Figures 16.16 and 16.18 are now separate modules. The names `deitel.math.powers` and `deitel.math.roots` imply a logical relationship between them, and both modules export the `deitel::math` namespace, but they do not define one module. For convenience, we can aggregate these separate modules in a **primary module interface unit** that **export imports both “submodules,”** as shown in lines 7 and 8 of Fig. 16.20.
