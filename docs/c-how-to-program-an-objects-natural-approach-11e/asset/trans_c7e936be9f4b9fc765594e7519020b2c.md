**14.4** 说明下列各项是 *真* 还是 *假*。如果为 *假*，请解释原因。

- a) 由于标准库算法直接处理容器，因此一个算法通常可以与许多不同的容器一起使用。

- g) Lambda 表达式也可以用在算法中使用函数指针和函数对象的地方。
- h) Lambda 表达式可以“捕获”（按值或按引用）外围函数的局部变量，然后在 lambda 的函数体中操作这些变量。
