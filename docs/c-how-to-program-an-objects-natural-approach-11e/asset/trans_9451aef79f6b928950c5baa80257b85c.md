**异常与异常处理**

如你所知，异常表示程序执行期间发生的问题。异常可能通过以下方式出现：

- try 块中显式出现的代码，
- 对其他函数（包括库调用）的调用，以及
- 运算符错误，例如 new 在执行时未能获取额外内存（12.8 节）。

异常处理可帮助你编写健壮、容错的程序，这些程序能够捕获不常发生的问题，并

- 处理这些问题并继续执行，
- 对无法处理或不应处理的异常执行适当的清理，并在退出时优雅终止，或者
- 在遇到未预料到的异常时立即终止——这一概念称为快速失败，我们将在 12.6.2 节讨论。
