It’s good practice in a module to **put exported identifiers in namespaces to help avoid name collisions** when multiple modules export the same identifier. We found in our research that namespace names typically mimic their module names⁴⁷—so for the `deitel16.math` module, we specified the namespace `deitel::math` (line 5).
