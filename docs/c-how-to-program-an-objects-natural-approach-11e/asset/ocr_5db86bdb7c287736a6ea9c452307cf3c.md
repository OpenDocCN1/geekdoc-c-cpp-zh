# ### 14.4.14 Heapsort and Priority Queues

Section 13.12.3 introduced the **priority_queue** container adaptor. Elements added to a **priority_queue** are stored in a manner that enables removing them in **priority order**. The highest-priority element is always removed first—usually, the highest-priority element has the largest value, but this is customizable. Finding the highest-priority element can be accomplished efficiently by arranging the elements in a data structure called a **heap**—not to be confused with the C++ memory allocation. A common use of priority queues is in operating system process scheduling.

# #### Heap Data Structure

A heap is commonly implemented as a binary tree. A **max heap** stores its largest value in the root node, and any given child node's value is less than or equal to its parent node's value. Heaps may contain duplicate values. A heap also can be a **min heap** in which the smallest value is in the root node, and any given child node's value is greater than or equal to its parent node's value.
