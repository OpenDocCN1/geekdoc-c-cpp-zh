# Type-Safe union

A union<sup>14</sup> is a region of memory that, over time, can contain objects of various types. A union’s members share the same storage space, so a union may contain a maximum of one object at a time and requires enough memory to hold the largest of its members. A `std::variant` object is often referred to as a type-safe union.<sup>15</sup>
