## Pearson 对多样性、公平与包容的承诺

Pearson 致力于创建无偏见的内容，反映所有学习者生活经历的多样性、深度与广度。我们拥抱多样性的诸多维度，包括但不限于种族、民族、性别、生理性别、性取向、社会经济地位、能力、年龄以及宗教或政治信仰。

教育是促进世界公平与变革的强大力量。它有可能带来改善生活、实现经济流动的机会。当我们与作者合作，为每款产品和服务创建内容时，我们承认有责任展现包容性并纳入多元学术成果，使每个人都能通过学习发挥潜能。作为全球领先的学习公司，我们有义务帮助推动变革，践行我们的宗旨——帮助更多人创造更美好的生活，并创造一个更美好的世界。

我们的愿景是有目的地为一个这样的世界贡献力量：

- 每个人都拥有通过学习的公平且终身的机会取得成功。
- 我们的教育产品和服务具有包容性，并体现学习者的丰富多样性。
- 我们的教育内容准确反映我们所服务学习者的历史和生活经历。
- 我们的教育内容促使与学生进行更深入的讨论，并激励他们拓展自己的学习（和世界观）。

我们还致力于提供所有学习者都能完全访问的产品。根据 Pearson 的无障碍教育 Web 媒体指南，我们按照 WCAG 指南为 2022 年版权年度及以后的新产品开发，并在每次发布时依据最高标准测试和重新测试产品的能力。您可以在 https://www.pearson.com/us/accessibility.html 了解更多关于 Pearson 对无障碍的承诺。

尽管我们努力呈现无偏见、完全可访问的内容，但我们希望听取您对本 Pearson 产品的任何疑虑或需求，以便我们调查并解决。
