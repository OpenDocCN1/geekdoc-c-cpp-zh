# Finding a Match Anywhere in a String

The calls to function `regex_search` in lines 14–16 search in `s1` ("Programming is fun") for the first occurrence of a substring that matches a regular expression—in this case, the literal strings "Programming", "fun" and "fn". Function `regex_search`’s two-argument version returns true or false to indicate a match.

```
```cpp
// fig08_19.cpp
// Matching patterns throughout a string.
#include <format>
#include <iostream>
#include <regex>
#include <string>

int main() {
   // performing a simple match
   std::string s1{"Programming is fun"};
   std::cout << std::format("s1: {}\n\n", s1);
   std::cout << "Search anywhere in s1:\n"
      << std::format("Programming: {}; fun: {}; fn: {}\n",
            std::regex_search(s1, std::regex{"Programming"}),
            std::regex_search(s1, std::regex{"fun"}),
            std::regex_search(s1, std::regex{"fn"}));
}
```

# Ignoring Case in a Regular Expression and Viewing the Matching Text

The `regex` constants in the header `<regex>` can customize how regular expressions perform matches. For example, matches are case-sensitive by default. Using the constant `regex_constants::icase`, you can perform a case-insensitive search.

```
```cpp
// ignoring case
std::string s2{"AZURE MAGAR"};
std::smatch match; // store the text that matches the pattern
std::cout << std::format("s2: {}\n\n", s2);
std::cout << "Case insensitive search for Azure in s2:\n"
   << std::format("Azure: {}\n", std::regex_search(s2, match,
         std::regex("Azure", std::regex_constants::icase)))
   << std::format("Matched text: {}\n", match.str());
```
