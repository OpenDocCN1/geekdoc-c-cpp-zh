
（本例中的第二位数字）舍入到最接近的偶数。因此，使用 `cpp_dec_float_50` 时，值 1157.625 向下舍入为 1157.62。类似地，

- 1157.635 将向上舍入为 1157.64，
- 1157.645 将向下舍入为 1157.64，
- 1157.655 将向上舍入为 1157.66，
- 1157.665 将向下舍入为 1157.66，
- 等等。
