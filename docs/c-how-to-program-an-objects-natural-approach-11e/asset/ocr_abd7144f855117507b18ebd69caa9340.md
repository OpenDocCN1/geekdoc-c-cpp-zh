**insertion sort algorithm**
An easy-to-implement but inefficient sorting algorithm. The algorithm’s first iteration takes the array’s second element and, if it’s less than the first element, swaps it with the first element. The second iteration looks at the third element and inserts it into the correct position with respect to the first two elements so all three elements are in order. At the ith iteration of this algorithm, the first i elements in the original array will be sorted.
