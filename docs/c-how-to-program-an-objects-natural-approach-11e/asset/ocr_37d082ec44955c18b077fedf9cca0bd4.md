# ### 16.6.1 module Declaration for a Module Interface Unit

Figure 16.2 defines our first module unit^37^—a translation unit that is part of a module. When a module is composed of one translation unit, the module unit is commonly referred to simply as a module. The module in Fig. 16.2 contains four functions (lines 8–10, 14–16, 21–23 and 28–30) to demonstrate exporting declarations for use in other translation units. In the following subsections, we’ll discuss the export and namespace “wrappers” around the functions in lines 14–16, 21–23 and 28–30.
