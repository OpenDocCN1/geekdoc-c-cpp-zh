## 1. Lambdas in C++98/03

To start out, it's good to create some background for our main topic. To do this, we'll move into the past and look at code that doesn't use any modern C++ techniques.

In this chapter, you'll learn:

- How to pass functors to algorithms from the Standard Library.
- The limitations of functors and function pointers.
- Why functional helpers weren't good enough.
- The motivation for the new feature for C++0x/C++11.

## Callable Objects in C++98/03

One of the fundamental ideas of the Standard Library is that algorithms like std::sort, std::for_each, std::transform and many others, can take any callable object and call it on elements of the input container. However, in C++98/03, we can only use function pointers or functors.

In C++98/03, a functor is a class that overloads the `operator()`. For example:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Count {
    mutable int count;
    void operator()(int) const {
        count++;
    }
};

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    Count c;
    std::for_each(v.begin(), v.end(), c);
    std::cout << "Count: " << c.count << std::endl;
    return 0;
}
```

The example above uses a functor to count the number of elements. Since the `operator()` is a const member function, I had to use a mutable variable.

We can also use a temporary functor without naming it. For example:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::for_each(v.begin(), v.end(), [](int x) {
        std::cout << x << "\n";
    });
    return 0;
}
```

Wait, the example above uses a lambda expression, which was introduced in C++11. In C++98/03, we would have to write:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Print {
    void operator()(int x) const {
        std::cout << x << "\n";
    }
};

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::for_each(v.begin(), v.end(), Print());
    return 0;
}
```

The problem with this approach is that we have to define a new class for every functor we want to use. This is very verbose and can clutter the code. Lambdas were introduced in C++11 to solve this problem. They allow us to define functors in-place.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::for_each(v.begin(), v.end(), [](int x) {
        std::cout << x << "\n";
    });
    return 0;
}
```

Lambdas can also capture variables from the surrounding scope. For example:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    int threshold = 10;
    std::for_each(v.begin(), v.end(), [threshold](int x) {
        if (x < threshold) {
            std::cout << x << "\n";
        }
    });
    return 0;
}
```

The `[threshold]` captures the variable by value, while `[&]` captures all variables by reference. We can also capture specific variables by reference. In C++17, we have even more powerful capture features, such as init-capture.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    int sum = 0;
    std::for_each(v.begin(), v.end(), [&sum](int x) {
        sum += x;
    });
    std::cout << "Sum: " << sum << std::endl;
    return 0;
}
```
