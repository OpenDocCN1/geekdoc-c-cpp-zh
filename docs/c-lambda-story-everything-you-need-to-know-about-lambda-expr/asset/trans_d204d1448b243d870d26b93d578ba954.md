## C++98/03 中的可调用对象

标准库的核心思想之一是，像 `std::sort`、`std::for_each`、`std::transform` 等算法可以接受任何可调用对象并在输入容器的元素上调用它。然而，在 C++98/03 中，我们只能使用函数指针或函数对象。

在 C++98/03 中，函数对象是一个重载了 `operator()` 的类。例如：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Count {
    int count = 0;
    void operator()() const {
        count++;
    }
};

int main() {
    std::vector<int> v(5);
    Count c;
    std::for_each(v.begin(), v.end(), c);
    std::cout << c.count << std::endl;
    return 0;
}
```

上面的示例使用了函数对象来计数元素。由于 `operator()` 是 `const` 成员，我必须使用 `mutable`：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Count {
    mutable int count = 0;
    void operator()() const {
        count++;
    }
};

int main() {
    std::vector<int> v(5);
    Count c;
    std::for_each(v.begin(), v.end(), c);
    std::cout << c.count << std::endl;
    return 0;
}
```

等等，上面的示例使用了 lambda 表达式，这是 C++11 引入的。在 C++98/03 中，我们必须写成：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct Print {
    void operator()(int x) const {
        std::cout << x << "\n";
    }
};

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::for_each(v.begin(), v.end(), Print());
    return 0;
}
```

这种方法的问题是，为使用的每个函数对象都要定义一个新类。这非常繁琐并会让代码混乱。Lambda 在 C++11 中的引入是为了解决这个问题。它们允许我们就地定义定义函数对象。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::for_each(v.begin(), v.end(), [](int x) {
        std::cout << x << "\n";
    });
    return 0;
}
```

Lambda 还可以捕获作用域变量。例如：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    int threshold = 10;
    std::for_each(v.begin(), v.end(), [threshold](int x) {
        if (x < threshold) {
            std::cout << x << "\n";
        }
    });
    return 0;
}
```

`[threshold]` 按值捕获变量，而 `[&]` 按引用捕获所有变量。我们按引用捕获特定变量。在 C++17 中，我们有了更强大的捕获功能，例如初始化捕获。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    int sum = 0;
    std::for_each(v.begin(), v.end(), [&sum](int x) {
        sum += x;
    });
    std::cout << "Sum: " << sum << std::endl;
    return 0;
}
```
