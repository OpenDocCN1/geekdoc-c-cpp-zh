```
int x = 10;
for (const auto &entry : ptrFuncVec)
entry(x);
}
```

In the above example, we create a vector of functions that will be applied to the variable. There are three entries in the container:

+   - The first one prints the value of the input argument.
- The second one modifies the value.
- The third is a copy of the first, so it also prints the value.

The solution works, but it's limited to stateless lambdas only. What if we wanted to lift this restriction?

To solve this issue we can reach for the heavy helper: std::function To make the example interesting, it switched from simple integers to lambdas that use std::string objects:

Storing Lambdas As std::function. Live code @Wandbox

```
#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>

int main() {
    std::vector<std::function<std::string(const std::string&)>> vecFilters;

    size_t removedSpaceCounter = 0;
    auto removeSpaces = [&removedSpaceCounter](const std::string& str) {
        std::string tmp;
        std::copy_if(str.begin(), str.end(), std::back_inserter(tmp), [](char c) { return std::isspace(c); });
        removedSpaceCounter += str.length() - tmp.length();
        return tmp;
    };

    auto makeUpperCase = [](const std::string& str) {
        std::string tmp = str;
        std::transform(tmp.begin(), tmp.end(), tmp.begin(), [](unsigned char c) { return std::toupper(c); });
        return tmp;
    };

    vecFilters.emplace_back(removeSpaces);
    vecFilters.emplace_back([](const std::string& str) {
        return str + " Amazing: ";
    });
    vecFilters.emplace_back([](const std::string& str) {
        return str + " Modern: ";
    });
    vecFilters.emplace_back([](const std::string& str) {
        return str + " C++: ";
    });
}
```
