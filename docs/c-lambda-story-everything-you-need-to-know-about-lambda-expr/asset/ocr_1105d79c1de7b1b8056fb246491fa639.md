# 4. Lambdas in C++17

C++17 added two significant enhancements to lambda expressions:

+   - constexpr lambdas
- Capture of *this

The new C++ revision also updated the type system - it now contains exception specification, which also relates to lambda expressions.

You can see the specification related to lambdas in N659 (C++17 draft just before publication) and the lambda section: [expr.prim.lambda].

Additionally, you'll learn about the following techniques:

+   - How to improve the IIFE pattern in C++17.
- How to improve variadic generic lambdas with fold expressions from C++17.
- How to derive from multiple lambdas.
- Lambdas and Asynchronous Execution.
