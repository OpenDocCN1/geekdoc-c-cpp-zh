executed at compile time.

As another example we can use and enhance a recursive lambda from the C++14 chapter :

Recursive constexpr Lambda. Live code @Compiler Explorer

```
int main() {
    constexpr auto factorial = [](int n) {
        constexpr auto fact_impl = [](int n, const auto& impl) -> int {
            return n > 1 ? impl(n - 1, impl) : 1;
        };
        return fact_impl(n, fact_impl);
    };
    static_assert(factorial(5) == 120);
}
```

In the example, we marked the factorial with constexpr_constpr , and this allows checking the computation through static_assert. Have a look at the live code at Compiler Explorer to see the generated assembler - it's almost “no-op” even with disabled optimisation level.

# Capturing Variables

You can capture variables (assuming they are also constant expressions):

Capturing constexpr variable. Live code @Wandbox

```
constexpr int add(int const& t, int const& u) { return t + u; }

int main() {
    constexpr int x = 0;
    constexpr auto lam = [&](int n) { return add(x, n); };
    static_assert(lam(10) == 10);
}
```

However, there’s an interesting case where you don’t “pass” a captured variable any further, like:

```
constexpr int x = 0;
constexpr auto lam = [&](int n) { return n + x; };
```
