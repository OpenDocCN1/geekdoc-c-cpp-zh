# Online Compilers

Instead of creating local projects to play with the code samples, you can also leverage online compilers. They offer a basic text editor and usually allow you compile only one source file (the code you edit). They are convenient if you want to play with code samples and check the results using various compilers vendors and versions.

For example, many of the code samples for this book were created using Coliru Online, Wandbox or Compiler Explorer and then adapted for the book.

Here's a list of the useful services:

+   - Coliru - uses GCC 9.2.0 (as of July 2020), offers link sharing and a basic text editor, it's simple but very effective.
- Wandbox - offers a list of compilers, including most Clang and GCC versions, can use libraries; offers link sharing and multiple file compilation.
- Compiler Explorer - offers many compilers, shows generated assembly code, can execute the code, or make static code analysis.
- CppBench - runs simple C++ performance tests (using google benchmark library).
