To close off during the capture clause, we should mention that you can also leverage captures with variadic templates. The compiler expands the pack into a list of non-static data members which might be handy if you want to use lambda in a templated code. For example, here's a code sample that experiments with the captures:

# Capturing a Variadic Pack. Live code [Wandbox](Wandbox)

```
#include <iostream>
#include <tuple>

template <class... Args>
void captureTest(Args... args) {
    const auto lambda = [args...];
    const auto tuple = std::make_tuple(args...);
    std::cout << "tuple size: " << std::tuple_size<decltype(tuple)>() << '\\n';
    std::cout << "tuple ist: " << std::get<0>(tuple) << '\\n';
    lambda(); // call it
}

int main() {
    captureTest(1, 2, 3, 4);
    captureTest("Hello world", 10.0f);
}
```

After running the code, we'll get the following output:

tuple size: 4
tuple ist: 1
tuple size: 2
tuple ist: Hello world

This somewhat experimental code shows that you can capture a variadic parameter pack (by reference is also possible) and then the pack is “stored” into a tuple object. We then call helper functions to access its data and properties.
