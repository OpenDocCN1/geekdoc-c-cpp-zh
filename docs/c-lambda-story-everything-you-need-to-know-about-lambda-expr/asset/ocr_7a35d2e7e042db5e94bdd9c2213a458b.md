# write a generic lambda:

```
Implementations of IRenderable concept/interface. Live code @Wandbox
#include <concepts>
#include <iostream>

template < typename T>
concept IRenderable = requires(T v) {
    (v.render()) -> std::same_as<void>;
    (v.getVertCount()) -> std::convertible_to<size_t>;
};

struct Circle {
    void render() { std::cout << "drawing circle \n " };
    size_t getVertCount() const { return 10; };
};

struct Square {
    void render() { std::cout << "drawing square \n " };
    size_t getVertCount() const { return 4; };
};

int main () {
    const auto RenderCaller = [](IRenderable auto& obj) {
        obj.render();
    };

    Circle c;
    RenderCaller(c);
    Square s;
    RenderCaller(s);
}
```

In the above example RenderCaller is a generic lambda which can support types that satisfies the IRenderable concept.

# Changes to Stateless Lambdas

You might recall from the chapter about C++11 lambdas, even stateless, are not default constructible. However, this limitation is lifted in C++20.

That's why, if your lambda doesn't capture anything, then you can write the following code:
