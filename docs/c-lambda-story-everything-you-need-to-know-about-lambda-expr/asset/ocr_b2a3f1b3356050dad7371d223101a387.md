```
#include <iostream>

int main() {
    const auto printer = [] (auto ... args) {
        (std::cout << << args) << '\n';
    };

    printer(1, 2, 3, "hello", 10.5f);
}
```

However, if you run the code it will print all arguments without any separator:

123hello10.5

And to solve this issue, we can introduce a little helper and also fold over comma operator rather than over <<

> Printer With a Helper Internal Lambda. Live code @Wandbox

```
#include <iostream>
int main() {
    const auto printer = [] (auto ... args) {
        const auto printElem = [](auto elem) {
            std::cout << elem << ", \n        };
        (printElem(args), ...);
        std::cout << '\n';
    };

    printer(1, 2, 3, "hello", 10.5f);
}
```

And now we have the the following output:

1, 2, 3, hello, 10.5,

And this can be even shortened into:

```
const auto printer = [] (auto ... args) {
    ((std::cout << args << ", "), ...);
    std::cout << '\n';
}
```
