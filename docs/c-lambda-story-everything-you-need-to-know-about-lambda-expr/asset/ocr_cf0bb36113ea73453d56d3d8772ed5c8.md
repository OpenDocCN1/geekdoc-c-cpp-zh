Additionally, it's also possible to write a compact generic lambda for all types from a variant object. This can support runtime polymorphism based on std::variant.

Runtime Polymorphism Based on std::variant/std::visit. Live code @Compiler Explorer
#include <variant>

```
struct Circle { void Draw() const { };
struct Square { void Draw() const { };
struct Triangle { void Draw() const { };

int main() {
  std::variant<Circle, Square, Triangle> shape;
  shape = Triangle();
  const auto callDraw = [](auto & sh) { sh.Draw(); };
  std::visit(callDraw, shape);
}
```

This technique is an alternative to runtime polymorphism based on virtual functions. Here we can work with unrelated types. There's no need for a common base class. You can read about this approach in my blog article: Runtime Polymorphism with std::variant and std::visit.
