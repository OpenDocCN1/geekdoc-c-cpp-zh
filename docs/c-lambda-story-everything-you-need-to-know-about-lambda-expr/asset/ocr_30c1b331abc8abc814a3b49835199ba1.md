```
Triple ttt{ 10.0f , 90 , std::string{"hello"} };
```

And τ will be deduced as float, u as int and v as std::string.

The overloaded pattern in C++20 is now just:

```
template < class... > struct overload: Ts... { using Ts::operator (().); };
```

The proposal for this feature is available in P1021 and also P1816 (wording).

> GCC10 fails to implement this proposal, but it doesn't work for advanced cases with inheritance, so we have to wait for the full conformance here.

In this chapter, we reviewed the changes that C++20 has brought.

First of all, we have a few clarifications and improvements: for example the capture of this , capturing structured bindings or the ability to default construct stateless lambdas. What's more, there are more significant additions! One of the prominent capabilities now is template lambdas and concepts - so that you get more control over generic lambdas.
