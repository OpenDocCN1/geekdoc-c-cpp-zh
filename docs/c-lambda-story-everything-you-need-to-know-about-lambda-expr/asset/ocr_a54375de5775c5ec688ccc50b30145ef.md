```
}};
std::cout << "number of comparisons: " << compCounter << '\\n';
for (const auto & v : vec) {
std::cout << v << ",";
}
```

As you can see, we can capture a local variable and then use it across all invocations of the binary comparator. Such behaviour is not possible with regular functions 15, but it's not straightforward with custom functions types. Lambdas make it very natural and also very convenient to use.
