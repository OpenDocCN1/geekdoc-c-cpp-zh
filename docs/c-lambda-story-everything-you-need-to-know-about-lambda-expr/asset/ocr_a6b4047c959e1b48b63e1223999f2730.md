The code uses std::is_nothrow_invocable_v to check if the given callable object is marked with noexcept.

> In C++17, the Exception Specification is cleaned up. Effectively, you can only use noexcept for declaring a function that won't throw. The dynamic exception specification, i.e. throw(X, Y, Z) is now removed.

> > **Quick Question:** What happens if you mark a function with noexcept and yet it throws an exception? In that case, the compiler will call std::terminate.
