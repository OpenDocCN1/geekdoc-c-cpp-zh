> The lambda return type is auto, which is replaced by the trailing-return-type if provided and/or deduced from return statements as described in [dcl.spec.auto]

If you have multiple return statements they all have to deduce the same type:

```
auto foo = [](int x) {
    if (x < 0)
        return x * 1.1f; // float!
    else
        return x * 2.1;    // double!
};
```

The above code won't compile as the first return statement returns float while the second double decide . The compiler cannot decide, so you have to select the single type.

While deciding integers or doubles might be helpful, there are far more reasons why return type deduction is valuable. This functionality plays a considerable aspect of template code and things that are “unknown”.

For example, lambda closure type is anonymous, and we cannot specify it explicitly in our code. If you want to return a lambda from a function, how do you specify the type?

Before C++14 you could use std::function :

```
#include <functional>
#include <iostream>

std::function<int(int)> CreateMullLambda(int x) {
    return [x](int param) noexcept { return x * param; }
}

int main() {
    const auto lam = CreateMullLambda(10);

    std::cout << lam(2);

    return 0;
}
```
