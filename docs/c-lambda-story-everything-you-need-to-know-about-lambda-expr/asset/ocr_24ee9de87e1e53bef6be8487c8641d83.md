# Capturing Two Variables by Reference

```
int x = 1, y = 1;
std::cout << x << " " << y << std::endl;
const auto foo = [&x, &y](() noexcept { ++ x; ++ y; };
foo();
std::cout << x << " " << y << std::endl;
```
