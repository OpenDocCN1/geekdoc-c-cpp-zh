```
const auto test = overloaded{
[](const int & i) { std::cout << "int " << i << '\\n'; };
[](const float & f) { std::cout << "float " << f << '\\n'; };
[](const std::string& s) { std::cout << "string " << s << '\\n'; }
};

test("10.0f");
```

In the above example, we create a test object which is composed of three lambdas. We can then call the object with a parameter, and the correct
lambda will be selected, depending on the type of the input parameter.

Let's now have a closer look at the core parts of this pattern.

Those lines of code benefit from three features available since C++17:

+   * Pack expansions in using declarations - short and compact syntax for variadic templates.
* Custom template argument deduction rules - that allows converting a list of lambda objects into a list of base classes for the overloaded class. (note: not needed in C++20).
* Extension to aggregate initialisation - before C++17 you couldn't aggregate initialise type that derives from other types.

In the C++11 chapter, we already covered the need for using declaration. This is important for bringing the call operators into the same scope of the overloaded structure. C++17 gives us a syntax that supports variadic templates, which was not possible in the previous revisions of the language.
