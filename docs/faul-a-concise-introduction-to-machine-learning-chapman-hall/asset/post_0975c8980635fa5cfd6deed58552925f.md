
Combining these two, we can write

$$
\mathcal{L}(\boldsymbol{\alpha}) = -\frac{1}{2} \left( N \log(2\pi) + \log |\mathbf{C}_{-i}| + \mathbf{t}^T \mathbf{C}_{-i}^{-1} \mathbf{t} - \log \alpha_i \right. \\
\left. + \log(\alpha_i + \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i) - \frac{\mathbf{t}^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{t}}{\alpha_i + \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i} \right) \\
= \mathcal{L}(\boldsymbol{\alpha}_{-i}) + \frac{1}{2} \left( \log \alpha_i - \log(\alpha_i + \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i) + \frac{(\mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{t})^2}{\alpha_i + \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i} \right) \\
= \mathcal{L}(\boldsymbol{\alpha}_{-i}) + \ell(\alpha_i).
$$

Hence we have separated the dependencies on $\alpha_i$ into $\ell(\alpha_i)$, while $\mathcal{L}(\boldsymbol{\alpha}_{-i})$ contains the portion of the log evidence independent of $\alpha_i$.

We define the quantities

$$s_i = \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i \quad \text{and} \quad q_i = \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{t},$$

which are independent of $\alpha_i$. With this definition

$$\ell(\alpha_i) = \frac{1}{2} \left( \log \alpha_i - \log(\alpha_i + s_i) + \frac{q_i^2}{\alpha_i + s_i} \right).$$

The derivative of the log evidence with respect to $\alpha_i$ is given by

$$
\frac{\partial \mathcal{L}(\boldsymbol{\alpha})}{\partial \alpha_i} = \frac{\partial \ell(\alpha_i)}{\partial \alpha_i} = \frac{1}{2} \left( \frac{1}{\alpha_i} - \frac{1}{\alpha_i + s_i} - \frac{q_i^2}{(\alpha_i + s_i)^2} \right) \\
= \frac{1}{2} (\alpha_i + s_i)^{-2} \left( s_i - q_i^2 + \frac{s_i^2}{\alpha_i} \right), \quad (8.8)
$$

since $\mathcal{L}(\boldsymbol{\alpha}_{-i})$ is independent of $\alpha_i$.

If $s_i - q_i^2$ is non-negative, then the derivative is always positive, since $\alpha_i$ is positive, and $\ell(\alpha_i)$ is monotonically increasing. If on the other hand $s_i - q_i^2$ is negative, then equation (8.8) vanishes for

$$\alpha_i = \frac{s_i^2}{q_i^2 - s_i}, \quad (8.9)$$

where $\ell(\alpha_i)$ has a maximum. Figure 8.10 illustrates these two cases. Setting $\alpha_i = \infty$ in the first case and adjusting $\alpha_i$ to the value given in (8.9) in the second case, increases the logarithm of the marginal likelihood. For $\alpha_i = \infty$, the probability density function for $\mathbf{c}_i$ becomes infinitely peaked at zero. In practice, this means that $d_i(\mathbf{x})$ is regarded as not contributing to explaining the data, and therefore can be excluded from the model. This introduces *sparsity* in the model.

To avoid many different matrices $\mathbf{C}_{-i}$, it is convenient to define

$$
Q_i = \mathbf{d}_i^T \mathbf{C}^{-1} \mathbf{t}, \\
S_i = \mathbf{d}_i^T \mathbf{C}^{-1} \mathbf{d}_i.
$$

For infinite $\alpha_i$, we have $q_i = Q_i$ and $s_i = S_i$, since in this case $\mathbf{C} = \mathbf{C}_{-i}$. While for finite $\alpha_i$,

```
$s_i = \mathbf{d}_i^T \mathbf{C}_{-i}^{-1} \mathbf{d}_i = \mathbf{d}_i^T (\mathbf{C} + \mathbf{d}_i(-\alpha_i)^{-1} \mathbf{d}_i^T)^{-1} \mathbf{d}_i$
$= \mathbf{d}_i^T [\mathbf{C}^{-1} - \mathbf{C}^{-1} \mathbf{d}_i (-\alpha_i + \mathbf{d}_i^T \mathbf{C}^{-1} \mathbf{d}_i)^{-1} \mathbf{d}_i^T \mathbf{C}^{-1}] \mathbf{d}_i$
$= S_i + \frac{S_i^2}{\alpha_i - S_i} = \frac{\alpha_i S_i}{\alpha_i - S_i}.$
```

Similarly,

```
$q_i = \frac{\alpha_i Q_i}{\alpha_i - S_i}.$
```

Let's examine $Q_i$ more closely. The matrices $\Sigma$ and $\mathbf{C}$ are related by the Woodbury matrix identity in Appendix A.1.3,

```
$\mathbf{C}^{-1} = (\sigma^2 \mathbf{I} + \mathbf{D} \mathbf{A}^{-1} \mathbf{D}^T)^{-1}$
$= \sigma^{-2} \mathbf{I} - \sigma^{-2} \mathbf{D} (\mathbf{A} + \mathbf{D}^T \sigma^{-2} \mathbf{D})^{-1} \mathbf{D}^T \sigma^{-2}$
$= \sigma^{-2} (\mathbf{I} - \sigma^{-2} \mathbf{D} \Sigma \mathbf{D}^T).$
```

Using this and (8.7),

```
$\mathbf{C}^{-1} \mathbf{t} = \sigma^{-2} (\mathbf{t} - \mathbf{D} \mu).$
```

However, $\mathbf{D}\mu$ is exactly the mean of our predictive probability distribution for $\mathbf{t}$. Thus, $\mathbf{C}^{-1} \mathbf{t}$ gives the difference between the target and the predictive mean for each sample scaled by the noise variance. If this is small, our current model is adequate to explain the data. If not, we consider $\mathbf{C}^{-1} \mathbf{t}$ an error which needs to be removed. Calculating $Q_i = \mathbf{d}_i^T \mathbf{C}^{-1} \mathbf{t}$ checks how well aligned $\mathbf{d}_i$ is with this error. If it is orthogonal, then $\mathbf{d}_i$ will not help in removing this error. If it is well aligned, then the inclusion of $\mathbf{d}_i$ in the model will be beneficial. Therefore $Q_i$ is known as the *quality factor*.

$S_i$ on the other hand is known as the sparsity factor, since, as we will see below, it helps to evaluate how collinear $\mathbf{d}_i$ is to the other basis functions. The quantity $s_i$ is a penalty term associated with the basis functions $d_i$. It quantifies how well $d_i$ could be modeled by the other basis functions. On the other hand, $q_i$ is a quality term, measuring how well $d_i$ would contribute to explaining the data, given the current model. Both $s_i$ and $q_i$ depend on $\mathbf{C}_{-i}$ which in turn depends on $\alpha_{-i}$. Thus the optimal value for $\alpha_i$ changes as the other hyperparameters $\alpha_{-i}$ are adjusted.

The possibility to optimize the hyperparameters individually in turn gives rise to the following algorithm. It initializes the model with a single basis function and its optimal hyperparameter value, and sets the hyper-parameters of the others notably to infinity. At the start of the algorithm when only one basis function is in the model, $\mathbf{D}$ has only one column, and $\Sigma$ is a $1 \times 1$ matrix. $\mathbf{C}$ is $\sigma^2 \mathbf{I}$ plus the outer product of that single basis function evaluated at the sample points with itself. Its inverse is easily calculated using the Sherman-Morrison formula from Appendix A.1.4. Then the basis function $d_i(\mathbf{x})$, where

![](img/d3c00252180686426c9e63ab889b535b_267_0.png)

setting its hyper-parameter \(\alpha_i\) to its optimal value (given the current model) gives the largest increase in the marginal likelihood, is found and the model updated accordingly.

The algorithm converges, if no significant increase in the logarithm of the marginal likelihood can be achieved anymore. Since the optimal value of \(\alpha_i\) can be finite or infinite, there are three different possible updates. If \(d_i(\mathbf{x})\) is not in the model and the optimal \(\alpha_i\) is finite, it gets added to the model. If \(d_i(\mathbf{x})\) is in the model and the optimal \(\alpha_i\) is infinite, it gets deleted from the model. The third option is that \(d_i(\mathbf{x})\) is in the model and the optimal \(\alpha_i\) is finite, in which case \(\alpha_i\) is updated to this value. Note that in the case when the optimal \(\alpha_i\) is infinite and \(d_i(\mathbf{x})\) is already excluded from the model, no action is necessary. In all three cases, \(\mathbf{\Sigma}\) and \(\mu\) have to be updated, since \(A\) has changed.

The matrices $\mathbf{D}$ and $\mathbf{\Sigma}$ change in size during the run of the algorithm. However, they stay comparatively small compared to the number $M$ of basis functions in the dictionary and the sample number $N$. The matrix $\mathbf{C}$ is subject to rank 1 updates as basis functions are added, deleted or their hyperparameters re-estimated. These rank 1 updates are the addition or subtraction of the outer product of the basis function evaluated at the sample points with itself with suitable coefficients derived from the hyperparameter updates. However, in practice $\mathbf{C}$ and its inverse are not calculated.

It should be noted here that the dictionary of candidate basis functions does not need to be static. A new candidate basis function can be created, evaluated, and possibly added to the model at any point.
