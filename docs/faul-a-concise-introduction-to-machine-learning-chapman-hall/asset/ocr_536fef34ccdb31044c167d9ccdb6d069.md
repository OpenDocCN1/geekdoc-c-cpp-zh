# 5.2 Kernel Trick

In the quadratic

```
v^T A v + v^T b + c = 0
```

the matrix A is symmetric, since A is the difference of covariance matrices
which are symmetric. Assuming M = 2 and writing

```
A = ( A11 A12 ; A12 A22 ), b = ( b1 ; b2 ),
```

the boundary equation can be written as

```
A11 v1^2 + 2 A12 v1 v2 + A22 v2^2 + b1 v1 + b2 v2 + c = 0.
```

Now we can rearrange this as

```
( A11 2 A12 A22 b1 b2 ) ( v1^2 ; v1 v2 ; v2^2 ; v1 ; v2 ) + c = 0.
```
