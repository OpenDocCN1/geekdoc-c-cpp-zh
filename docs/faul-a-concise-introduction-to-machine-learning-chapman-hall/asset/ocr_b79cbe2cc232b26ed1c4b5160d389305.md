Using integration by parts, we can calculate

```
$$\Gamma(z+1) = \int_0^\infty x^z \exp(-x) dx = [-x^z \exp(-x)]_0^\infty + \int_0^\infty z x^{z-1} \exp(-x) dx.$$
```

The first term vanishes, since at zero we have a positive power of zero, while when $x$ tends to infinity, $\exp(-x)$ tends to zero quicker than any power of $x$. Therefore,

```
$$\Gamma(z+1) = z \int_0^\infty x^{z-1} \exp(-x) dx = z \Gamma(z), \quad (2.15)$$
```

and it is regarded as an extension of the factorial to real, positive numbers. Indeed, if $z=n$ is an integer, then using the above relation repeatedly leads to

```
$$\Gamma(n+1) = n \Gamma(n) = n(n-1) \Gamma(n-1) = n(n-1) \cdots 1 \Gamma(1) = n!,$$
```

since $\Gamma(1) = 1$.

The fraction

```
$$B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha + \beta)}$$
```

is known as the beta function, giving the distribution its name. It can be regarded as an extension to the inverse of the binomial coefficient. Indeed, if $\alpha=m$ and $\beta=n$ are integers, then

```
$$\frac{1}{B(m,n)} = \frac{(m+n)!}{m!n!} = \binom{m+n}{m} = \binom{m+n}{n}.$$
```
