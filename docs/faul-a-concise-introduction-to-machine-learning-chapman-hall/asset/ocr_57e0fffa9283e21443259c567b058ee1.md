we see that \(\hat{\mathcal{L}}\) is the expectation of the logarithm of the complete data likelihood

```
\(\sum_{n=1}^N \log p(\mathbf{v}_n, \mathbf{z}_n),\)
```

where the expectation is taken with respect to the responsibilities, that is the posterior probabilities of the latent variables. In the following, we will derive a lower bound which shows the relationship between \(\mathcal{L}\) and \(\hat{\mathcal{L}}\).

Using the product rule for probabilities, the logarithm of the complete data likelihood can also be written as

```
\(\sum_{n=1}^N \log p(\mathbf{v}_n, \mathbf{z}_n) = \sum_{n=1}^N \log p(\mathbf{v}_n) + \log p(\mathbf{z}_n|\mathbf{v}_n).\)
```

Both sides can be viewed as functions of the random variables \(\mathbf{z}_n\), and the expectation with respect to any distribution \(q(\mathbf{z}_n)\) can be taken. Since \(\mathbf{z}_n\) is a 1-of-K representation, the expectation is calculated by summing over all possible values for \(\mathbf{z}_n\):

```
\(\begin{aligned} \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log p(\mathbf{v}_n, z_{n,k}=1) \\ = \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log p(\mathbf{v}_n) + \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log p(z_{n,k}=1|\mathbf{v}_n) \\ = \underbrace{\sum_{n=1}^N \log p(\mathbf{v}_n)}_{\mathcal{L}} + \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log p(z_{n,k}=1|\mathbf{v}_n), \end{aligned}\)
```

because of \(\sum_{k=1}^K q(z_{n,k}=1) = 1\). Rearranging, we see that the logarithm of the data likelihood is given by

```
\(\begin{aligned} \mathcal{L} = \sum_{n=1}^N \log p(\mathbf{v}_n) = \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log p(\mathbf{v}_n, z_{n,k}=1) \\ - \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log p(z_{n,k}=1|\mathbf{v}_n). \end{aligned}\)
```
