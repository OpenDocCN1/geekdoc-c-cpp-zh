\(\alpha = \alpha_0 = \sum_{k=1}^K \alpha_k,\)
\(\mu = \left( \frac{\alpha_1}{\alpha_0}, \dots, \frac{\alpha_K}{\alpha_0} \right)^T.\)

In this case, \(\alpha\) is known as the (single) *concentration parameter*, while \(\mu\) is the *base distribution*. It is also the expectation of the distribution and satisfies the constraint

\(\sum_{k=1}^K \mu_k = 1.\)

With this notation,

\(\text{var}[x_j] = \frac{1}{\alpha + 1} \mu_j (1 - \mu_j),\)
\(\text{cov}[x_j, x_k] = \frac{1}{\alpha + 1} \mu_j \mu_k.\)

We have already seen that, if \(\alpha = 1\), the Dirichlet distribution is the uniform distribution. This means all distributions \(\mathbf{x}\) are equally likely. If \(\alpha\) tends to infinity, then only distributions which are themselves nearly uniform distributions become likely. The Dirichlet probability density function becomes infinitely peaked around the uniform distribution given by \(\mathbf{x} = (1/K, \dots, 1/K)^T\). In Figure 2.23, \(\alpha_0 = \alpha\) is largest for \(\alpha = (5, 5, 5)^T\) and the probability mass is concentrated around \((1/3, 1/3, 1/3)\), which describes the uniform distribution for three possible outcomes.

If \(\alpha\) tends to zero, let \(\mu_k\) be the component which is largest, i.e. \(\mu_k > \mu_j\) for all \(j \neq k\). Then the Dirichlet distribution tends to be peaked at this corner of the simplex. If there are several components with the same largest value, it tends to peaks at these corners, while it is zero everywhere else.

Both the beta distribution and the Dirichlet distribution can be illustrated by the *Pólya urn model*. Imagine an urn which contains balls of \(K\) different colours. For the beta distribution, these are two colours. Initially the urn contains \(\alpha_1\) balls of colour 1, \(\alpha_2\) balls of colour 2, and so on. As given in Equation 2.17, the total number of balls is the concentration \(\alpha\) and the initial proportions are given by the base distribution \(\mu\).

Now, each time a ball is drawn from the urn and replaced, but also another ball of the same colour is added, until the urn contains \(N\) balls. Since the colour drawn is random, the final number of balls of each colour is a random variable. However, it is influenced by the initial proportion of balls. If initially there are only balls of one colour, then the outcome is determined, because then the urn will continue to contain only balls of one colour. ## 2.5 Functions of Continuous Random Variables

If \(x\) is a continuous random variable with probability density function \(f_x(x)\), then, for a continuous function \(g\), \(y = g(x)\) is also a continuous random variable, but what is its probability density function \(f_y(y)\)? We include subscripts to be clear which random variable the probability density function and the cumulative distribution function refer to.

We first restrict our attention to the case, when \(g\) is a one-to-one transformation. That is each value of \(x\) generates exactly one value of \(y\), and each value of \(y\) is generated by exactly one value of \(x\). Because of this, an inverse function \(g^{-1}\) exists such that \(x = g^{-1}(y)\). Since \(g\) is continuous, it has to be either strictly decreasing or increasing.

Taking the strictly increasing case first, we can derive the probability density function by using the cumulative distribution functions, \(F_x\) and \(F_y\). Given a value \(y\), then

\(F_y(y) = p(g(x) \le y)\).

Now, since $g$ is strictly increasing, if $g(x) \le y$, then $x \le g^{-1}(y)$ at the same time. Hence,

```
$F_y(y) = p(x \le g^{-1}(y)) = F_x(g^{-1}(y)) = \int_{-\infty}^{g^{-1}(y)} f_x(x) dx.$
```

Using integration by substitution, we get

```
$F_y(y) = \int_{-\infty}^{y} f_x(g^{-1}(t))(g^{-1})'(t) dt.$
```

To find the probability density function, we differentiate with respect to $y$. By the Fundamental Theorem of Calculus

```
$f_y(y) = f_x(g^{-1}(y))(g^{-1})'(y).$
```

The derivation for the strictly decreasing case starts off in the same way. However, $g(x)$ is less than or equal to $y$, if and only if $x \ge g^{-1}(y)$, due to $g$ being decreasing. Thus,

```
$F_y(y) = p(x \ge g^{-1}(y)) = 1 - F_x(g^{-1}(y)) = 1 - \int_{-\infty}^{g^{-1}(y)} f_x(x) dx.$
```

Again, integrating by substitution and differentiating with respect to $y$ gives

```
$f_y(y) = -f_x(g^{-1}(y))(g^{-1})'(y).$
```

Since $g$ is decreasing, so is $g^{-1}$ and thus its derivative is negative. This makes the expression overall positive.

Since in the strictly increasing case, the derivative of $g^{-1}(y)$ is always positive, both cases can be summarized as

```
$f_y(y) = f_x(g^{-1}(y)) |(g^{-1})'(y)| = |f_x(g^{-1}(y))| \left| \frac{dx}{dy} \right|, \quad (2.18)$
```

where the last equation uses a common short-hand notation. This is known as *change-of-variable technique*, since in its derivation we change the variable in the integral. Another name is *method of direct transformation*.

We illustrate the case, when $g$ is not a one-to-one transformation, by an example first. Let $x$ follow the standard normal distribution $\mathcal{N}(0, 1)$ and let $y = x^2$. While $-\infty < x < \infty$, we have $0 \le y < \infty$. Each value of $y$ is generated by two values $x_1 = -\sqrt{y}$ and $x_2 = \sqrt{y}$. Taking the same approach as before

```
$F_y(y) = p(x^2 \le y) = p(-\sqrt{y} \le x \le \sqrt{y}) = F_x(\sqrt{y}) - F_x(-\sqrt{y})$
```

```
$= \int_{-\infty}^{\sqrt{y}} f_x(x) dx - \int_{-\infty}^{-\sqrt{y}} f_x(x) dx$
```
