
![](img/d3c00252180686426c9e63ab889b535b_77_0.png)

Figure 2.31: Prior (top left) and posterior beta probability distributions after some observations. The bottom right shows the beta distribution after an equal number of 0 and 1.

If the data is categorical in nature, the outcomes are described using a 1-of-K representation and follow the categorical distribution as given in (2.9). Let $\mathcal{D} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ be the results of $N$ experiments. The likelihood of this data is then

```
$p(\mathcal{D}|\boldsymbol{\mu}) = \prod_{n=1}^N \text{Cat}(\mathbf{x}_n|\boldsymbol{\mu}) = \prod_{n=1}^N \prod_{k=1}^K \mu_k^{x_{nk}} = \prod_{k=1}^K \mu_k^{\sum_{n=1}^N x_{nk}}.$
```

Since each $\mathbf{x}_n$ is a 1-of-K representation, let $m_k$ be the number of times we had $x_{nk} = 1$ for $n = 1, \dots, N$. The likelihood then becomes

```
$p(\mathcal{D}|\boldsymbol{\mu}) = \prod_{k=1}^K \mu_k^{m_k}.$
```

Again an estimator for \(\mu\) can be found by maximizing the likelihood, or equivalently its logarithm. However, this task is not as straight-forward as before, since \(\mu\) has to satisfy the constraints

\(\sum_{k=1}^K \mu_k = 1 \quad \text{and} \quad 0 \le \mu_k \le 1, k=1, \dots, K.\)

hence the task is a constraint optimization.

Let \(i\) be any index in \(\{1, \dots, K\}\). We incorporate the first constraint by noting

\(\mu_i = 1 - \sum_{k=1, k \neq i}^K \mu_k.\)

With this modification, the log likelihood is

\(\log p(\mathcal{D}|\mu) = \sum_{k=1}^K m_k \log \mu_k + m_i \log \left( 1 - \sum_{k=1, k \neq i}^K \mu_k \right).\)

Let \(j \neq i\) be any other index. The parameter \(\mu_j\) appears in both sums, and the derivative with respect to \(\mu_j\) is

\(\frac{d}{d\mu_j} \log p(\mathcal{D}|\mu) = \frac{m_j}{\mu_j} - \frac{m_i}{1 - \sum_{k=1, k \neq i}^K \mu_k} = \frac{m_j}{\mu_j} - \frac{m_i}{\mu_i}.\)

Setting to zero, we see that the ratio of \(\mu_i\) to \(\mu_j\) has to be the same as the ratio of $m_i$ to $m_j$. Since $i$ and $j$ were freely chosen, the ratio of any pair of components of $\mu$ must be the same as the ratio of the corresponding pair in $\mathbf{m} = (m_1, \dots, m_k)^T$. The only possible choice for $\mu_k$, which also satisfies the second constraint, is the maximum likelihood estimator

\(\mu_k = \frac{m_k}{m_1 + \dots + m_K} = \frac{m_k}{N}, \quad k=1, \dots, K.\)

As before, this can be a poor estimate, if $N$ is not large enough.

Constraint optimization problems occur often in machine learning. A general technique uses *Lagrange multipliers*, which we will encounter in Section 4.6. For more background knowledge on optimization see [2].

The vector \(\mu\) of the probabilities of different outcomes needs to be estimated. The Dirichlet distribution \(\text{Dir}(\mu|\alpha)\) is chosen as conjugate prior for \(\mu\), where \(\alpha\) is suitably chosen. The posterior density function is proportional to the product of the likelihood and the prior (which is the joint distribution):

\(f(\mu|\mathbf{m}, \alpha) \propto \prod_{k=1}^K \mu_k^{m_k + \alpha_k - 1},\) where all constant factors were dropped due to the proportional sign. The posterior has again the functional form of a Dirichlet distribution. Incorporating the factor such that the posterior integrates to one leads to

```
f(\mu|\mathbf{m}, \alpha) = \frac{\Gamma(\alpha_0 + N)}{\Gamma(\alpha_1 + m_1) \cdots \Gamma(\alpha_K + m_K)} \prod_{k=1}^K \mu_k^{m_k + \alpha_k - 1} = \text{Dir}(\mu|\mathbf{m} + \alpha),
```

where \(\alpha_0 = \alpha_1 + \cdots + \alpha_K\).

As before with the beta distribution, the knowledge gained from the experiments is given by $\mathbf{m}$ and modifies the location and the mean and the shape of the distribution. The parameters $\alpha$ and $\beta$ in the prior beta distribution and $\alpha$ in the prior Dirichlet distribution can be viewed as initial guesses of the true distribution or fictional trial runs informed by expert knowledge and experience.

The probability of a particular outcome $x_k = 1$ is

```
p(x_k = 1|\mathcal{D}) = \int p(x_k = 1|\mu) f(\mu|\mathbf{m}, \alpha) d\mu,
```

where the integral is over the simplex, where $\mu$ must lie. Since $p(x_k = 1|\mu) = \mu_k$, this becomes

```
p(x_k = 1|\mathcal{D}) = \mathbb{E}[\mu_k|\mathbf{m}, \alpha] = \frac{m_k + \alpha_k}{N + \alpha_0}. \quad (2.23)
```

As $N$ grows, $p(x_k = 1|\mathcal{D})$ approaches the maximum likelihood estimator. Again, the above result no longer depends on $\mu$ and therefore $\mu$ is a latent variable.

We have seen two examples of conjugate probability distributions and will see more. For example, if the mean of a normal distribution is the unknown parameter, the conjugate prior is also a normal distribution. For a more thorough treatment of conjugacy see [16].

## Sampling

Sampling is necessary, since in machine learning often a closed form describing the probability distribution is not accessible, but the distribution can be sampled. The chapter explains standard sampling techniques such as inverse transform sampling, rejection sampling and importance sampling as well as Markov chains and Markov Chain Monte Carlo in an intuitive way.

In the previous chapter, we have seen how data is used to estimate the parameters of the assumed underlying distribution generating the data $\mathcal{D}$ using Bayes rule. For example, let $\theta_1$ be the vector of all parameters governing the distribution and $\theta_2$ the vector of all hyperparameters governing the prior distributions for the parameters $\theta_1$. Then the posterior is given by

```
$$f(\theta_1|\mathcal{D}, \theta_2) = \frac{p(\mathcal{D}|\theta_1)f(\theta_1|\theta_2)}{\int p(\mathcal{D}|\theta_1)f(\theta_1|\theta_2)d\theta_1}.$$ (3.1)
```

Unless we are dealing with conjugate probability distributions, no closed solution might exist. It might not be possible to evaluate the integral in the denominator.

Note that, by the product rule, the integrand is the joint probability density function of $\mathcal{D}$ and $\theta_1$ conditioned on $\theta_2$, i.e. $f(\mathcal{D}, \theta_1|\theta_2)$. This means the denominator is the marginal distribution function $f(D|\theta_2)$.

Another way of interpreting the integral is that it is the expectation of the function $p(D|\theta_1)$ with respect to the distribution described by the probability density function $f(\theta_1|\theta_2)$. We already encountered a similar situation in Equation (2.19), when attempting to derive the probability density function of a random variable which is a function of two other random variables. The outer integral can be interpreted as the expectation of the function given by the inner integral with respect to the probability density function in the outer integral.
