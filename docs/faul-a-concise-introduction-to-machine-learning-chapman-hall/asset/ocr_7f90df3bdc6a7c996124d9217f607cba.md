The covariance matrices $\Sigma_k$ follow the inverse Wishart distribution given by $\Psi$ and $\nu$, $\Sigma_k \sim \mathcal{W}^{-1}(\Psi, \nu)$. It has the probability density function

$$\mathcal{W}^{-1}(\Sigma_k | \Psi, \nu) = \frac{|\Psi|^{\nu/2}}{2^{\nu d/2} \Gamma_d(\frac{\nu}{2})} |\Sigma_k|^{-(\nu+d+1)/2} \exp \left( -\frac{1}{2} \text{tr}(\Psi \Sigma_k^{-1}) \right), \quad (6.10)$$

where $|\cdot|$ denotes the determinant and $\text{tr}(\cdot)$ denotes the trace of a matrix. $\Gamma_d$ is the multivariate gamma function.

The expectation of the inverse Wishart distribution is given by

$$\mathbb{E}[\Sigma_k] = \frac{\Psi}{\nu - d - 1}.$$

The variance of each element $\Sigma_{ij}$ of $\Sigma$ is calculated as

$$\text{var}[\Sigma_{ij}] = \frac{(\nu - d + 1)\Psi_{ij}^2 + (\nu - d + 1)\Psi_{ii}\Psi_{jj}}{(\nu - d)(\nu - d - 1)^2(\nu - d - 3)} = \text{var}[\Sigma_{ji}],$$

since $\Psi$ is symmetric. On the diagonal, that is $i = j$, this simplifies to

$$\text{var}[\Sigma_{ii}] = \frac{2\Psi_{ii}^2}{(\nu - d - 1)^2(\nu - d - 3)}.$$
