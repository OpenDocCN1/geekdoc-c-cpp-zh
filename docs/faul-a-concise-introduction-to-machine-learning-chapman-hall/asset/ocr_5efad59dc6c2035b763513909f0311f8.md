The algorithm converges, if no significant increase in the logarithm of the marginal likelihood can be achieved anymore. Since the optimal value of \(\alpha_i\) can be finite or infinite, there are three different possible updates. If \(d_i(\mathbf{x})\) is not in the model and the optimal \(\alpha_i\) is finite, it gets added to the model. If \(d_i(\mathbf{x})\) is in the model and the optimal \(\alpha_i\) is infinite, it gets deleted from the model. The third option is that \(d_i(\mathbf{x})\) is in the model and the optimal \(\alpha_i\) is finite, in which case \(\alpha_i\) is updated to this value. Note that in the case when the optimal \(\alpha_i\) is infinite and \(d_i(\mathbf{x})\) is already excluded from the model, no action is necessary. In all three cases, \(\mathbf{\Sigma}\) and \(\mu\) have to be updated, since \(A\) has changed.

The matrices \(\mathbf{D}\) and \(\mathbf{\Sigma}\) change in size during the run of the algorithm. However, they stay comparatively small compared to the number \(M\) of basis functions in the dictionary and the sample number \(N\). The matrix \(\mathbf{C}\) is subject to rank 1 updates as basis functions are added, deleted or their hyperparameters re-estimated. These rank 1 updates are the addition or subtraction of the outer product of the basis function evaluated at the sample points with itself with suitable coefficients derived from the hyperparameter updates. However, in practice \(\mathbf{C}\) and its inverse are not calculated.

It should be noted here that the dictionary of candidate basis functions does not need to be static. A new candidate basis function can be created, evaluated, and possibly added to the model at any point.
