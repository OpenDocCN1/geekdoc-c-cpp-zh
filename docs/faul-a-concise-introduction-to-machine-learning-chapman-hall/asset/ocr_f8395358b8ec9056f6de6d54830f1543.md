If the data is categorical in nature, the outcomes are described using a 1-of-K representation and follow the categorical distribution as given in (2.9). Let $\mathcal{D} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ be the results of $N$ experiments. The likelihood of this data is then

```
$p(\mathcal{D}|\boldsymbol{\mu}) = \prod_{n=1}^N \text{Cat}(\mathbf{x}_n|\boldsymbol{\mu}) = \prod_{n=1}^N \prod_{k=1}^K \mu_k^{x_{nk}} = \prod_{k=1}^K \mu_k^{\sum_{n=1}^N x_{nk}}.$
```

Since each $\mathbf{x}_n$ is a 1-of-K representation, let $m_k$ be the number of times we had $x_{nk} = 1$ for $n = 1, \dots, N$. The likelihood then becomes

```
$p(\mathcal{D}|\boldsymbol{\mu}) = \prod_{k=1}^K p_k^{m_k}.$
```
