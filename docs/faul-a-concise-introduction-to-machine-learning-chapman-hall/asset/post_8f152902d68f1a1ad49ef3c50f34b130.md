
consider normal distributions $\mathcal{N}(\mu_k, \Sigma_k)$. That is

$$ p_k(\mathbf{v}) = \frac{1}{\sqrt{|2\pi \Sigma_k|}} \exp \left( - \frac{1}{2} (\mathbf{v} - \mu_k)^T \Sigma_k^{-1} (\mathbf{v} - \mu_k) \right), \quad (6.6) $$

where $|\cdot|$ denotes the matrix determinant. The derivative of $p_k(\mathbf{v})$ with respect to $\mu_k$ is given by

$$ \frac{\partial}{\partial \mu_k} p_k(\mathbf{v}) = p_k(\mathbf{v}) \Sigma_k^{-1} (\mathbf{v} - \mu_k), $$

where we used the chain rule, Appendix A.2.3 and the symmetry of $\Sigma_k$. Differentiating (6.3) with respect to $\mu_k$ therefore results in

$$ \begin{aligned} \frac{\partial}{\partial \mu_k} \mathcal{L} &= \sum_{n=1}^N \frac{1}{p(\mathbf{v}_n)} \pi_k \frac{\partial}{\partial \mu_k} p_k(\mathbf{v}) \\ &= \sum_{n=1}^N \frac{1}{p(\mathbf{v}_n)} \pi_k p_k(\mathbf{v}) \Sigma_k^{-1} (\mathbf{v}_n - \mu_k) \\ &= \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n) \Sigma_k^{-1} (\mathbf{v}_n - \mu_k). \end{aligned} $$

To approximate the extremum, we set this to zero and multiply through by $\Sigma_k$ which is non-singular, since it is a covariance matrix:

$$ \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n) (\mathbf{v}_n - \mu_k) = 0. $$

We define

$$ N_k = \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n), $$

which is comparable to the expected number of samples in cluster $k$. With this definition

$$ \mu_k = \frac{1}{N_k} \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n) \mathbf{v}_n. \quad (6.7) $$

We see that $\mu_k$ is a weighted average of all samples in the data set where the weights are the responsibilities that the sample was generated by process $k$. It is reminiscent of formula (4.1) for the sample mean.

To maximize with respect to the covariance $\Sigma_k$, we need the derivative of $p_k(\mathbf{v})$ with respect to $\Sigma_k$. Using the product and chain rule and the differentiation rules given in Appendices A.2.4 and A.2.8, we have

$$ \frac{\partial}{\partial \Sigma_k} p_k(\mathbf{v}) = -\frac{1}{2} p_k(\mathbf{v}) \left[ \Sigma_k^{-1} - \Sigma_k^{-1} (\mathbf{v} - \mu_k) (\mathbf{v} - \mu_k)^T \Sigma_k^{-1} \right], $$

since $\Sigma_k^{-1}$ is symmetric. From this we derive the derivative of the logarithm of the likelihood given in (6.3) as

$$\frac{\partial}{\partial \Sigma_k} \mathcal{L} = \frac{1}{2} \sum_{n=1}^N p(z_{n,k} = 1 | \mathbf{v}_n) [\Sigma_k^{-1} - \Sigma_k^{-1} (\mathbf{v}_n - \mu_k)(\mathbf{v}_n - \mu_k)^T \Sigma_k^{-1}].$$

As before, we approximate the extremum by setting the derivative to zero and multiplying through with $\Sigma_k$, but this time from both sides:

$$\sum_{n=1}^N p(z_{n,k} = 1 | \mathbf{v}_n) [\Sigma_k - (\mathbf{v}_n - \mu_k)(\mathbf{v}_n - \mu_k)^T] = 0.$$

Solving for $\Sigma_k$, we arrive at

$$\Sigma_k = \frac{1}{N_k} \sum_{n=1}^N p(z_{n,k} = 1 | \mathbf{v}_n) (\mathbf{v}_n - \mu_k)(\mathbf{v}_n - \mu_k)^T. \quad (6.8)$$

The formula is very similar to (4.2) for the sample covariance. The main difference is that the sum is over all samples and that each summand is weighted by the responsibility that process $k$ generated this sample.

To summarize, the Gaussian mixture algorithm proceeds as follows

- Choose $K$ and convergence threshold.
- Initialize means $\mu_k$, covariances $\Sigma_k$, and mixing coefficients $\pi_k$ for $k = 1, \dots, K$, and calculate the initial value of the logarithm of the likelihood according to (6.3).
- For $n = 1, \dots, N$ and $k = 1, \dots, K$, calculate all the responsibilities $p(z_{n,k} = 1 | \mathbf{v}_n)$.
- Use these responsibilities to update means $\mu_k$, covariances $\Sigma_k$, and mixing coefficients $\pi_k$ for $k = 1, \dots, K$ according to equations (6.7), (6.8) and (6.5).
- Evaluate the change in the logarithm of the likelihood and terminate if this is below the convergence threshold. Otherwise return to step 3.

Alternatively, the algorithm converges if the change in all parameters is below the convergence threshold. It is common to use the $K$ means algorithm to obtain good initializations. The means are initialized to the cluster centres obtained from the $K$ means procedure, while the covariances are set to the sample covariances of the clusters, and the mixing coefficients are initially the fractions of data samples assigned to a particular cluster.

```
% Number of samples to be generated.
N = 100;
% Array of means.
MU = [ 1 1; -4 -1; 1 -2];
% Concatenated array of co-variance matrices.
SIGMA = cat(3,[2 0; 0 0.5],[1 0.5; 0.5 1],[1 0; 0 1]);
% Mixing coefficients.
p = [0.4 0.5 0.1];
% Gaussian mixture model.
GModel = qdistribution('MIX',SIGMA,p);
% Generate and display data.
num = 1000 % for reproducibility
[V,idx] = gmixrnd(GModel,num);
scatter(V(:,1),V(:,2),idx,'bgr','.',...,[10 10]);
```
