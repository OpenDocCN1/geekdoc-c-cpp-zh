However, the first quantity on the right hand side is not known.

To overcome the unknowns, note that we can scale the vector \(\mathbf{D}\mathbf{a}\) by a factor \(\alpha\) such that

```
\(\|\alpha\mathbf{D}\mathbf{a}\|^2 = \mathbf{a}^T\mathbf{D}^T\mathbf{D}\mathbf{\Sigma}\mathbf{A}\mathbf{a}.\)
```

Since \(\alpha\mathbf{D}\mathbf{a}\) and \(\mathbf{b}\) are orthogonal, the square of the length of the vector \(\alpha\mathbf{D}\mathbf{a} + \mathbf{b}\) is

```
\(\begin{aligned} \|\alpha\mathbf{D}\mathbf{a} + \mathbf{b}\|^2 &= \|\alpha\mathbf{D}\mathbf{a}\|^2 + \|\mathbf{b}\|^2 \\ &= \mathbf{a}^T\mathbf{D}^T\mathbf{D}\mathbf{\Sigma}\mathbf{A}\mathbf{a} + \|\mathbf{b}\|^2 = \sigma^2 S_i. \end{aligned}\)
```
