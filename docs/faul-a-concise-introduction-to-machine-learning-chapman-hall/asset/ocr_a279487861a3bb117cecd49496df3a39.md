# Writing

```
(t - Dc)^T(t - Dc) = c^T D^T Dc - 2c^T D^T t + t^T t,
```

we can differentiate with regards to c using Appendix A.2.3 and set to zero to find the extremum,

```
D^T Dc = D^T t. (8.2)
```

Since D is a N x M matrix, D^T D is an M x M matrix. If the inverse (D^T D)^-1 exists, then the choice for c is

```
c = (D^T D)^-1 D^T t.
```
