on the right hand side leaves the equation unchanged, and we obtain

```
\mathcal{L} = \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log \frac{p(\mathbf{v}_n, z_{n,k}=1)}{q(z_{n,k}=1)} + \sum_{n=1}^N \sum_{k=1}^K q(z_{n,k}=1) \log \frac{q(z_{n,k}=1)}{p(z_{n,k}=1|\mathbf{v}_n)}, \quad (6.9)
```

Now, in the last line each sum over \(k = 1, ..., K\) is the Kullback-Leibler divergence (\(KL\) divergence) from the discrete distribution \(p(\mathbf{z}_n|\mathbf{v}_n)\) to the discrete distribution \(q(\mathbf{z}_n)\).

More generally, given two discrete probability distributions \(P\) and \(Q\), the Kullback-Leibler divergence from \(Q\) to \(P\) is defined as

```
\(D_{KL}(P||Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)}\).
```

To avoid a division by zero, it is only defined if \(Q(i) = 0\) implies \(P(i) = 0\). In this case, that particular term of the sum is interpreted as zero, since \(\lim_{x \to 0} x \log x = 0\). If both distributions are the same, then the Kullback-Leibler divergence is zero. It is also non-negative, since \(\log x \le x - 1\) and therefore

```
\(\begin{aligned} D_{KL}(P||Q) &= - \sum_i P(i) \log \frac{Q(i)}{P(i)} \ge - \sum_i P(i) \left( \frac{Q(i)}{P(i)} - 1 \right) \\ &= - \sum_i Q(i) + \sum_i P(i) = 0, \end{aligned}\)
```

since the probabilities need to sum to 1.

The last line in (6.9) is always non-negative, and therefore the first line is a lower bound for the logarithm of the data likelihood. We can rewrite this lower bound as

```
\(\begin{aligned} \tilde{\mathcal{L}} &= \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log \frac{p(\mathbf{v}_n, z_{n,k}=1)}{q(z_{n,k}=1)} \\ &= \overbrace{\sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log \left( p(z_{n,k}=1) p(\mathbf{v}_n|z_{n,k}=1) \right)}^{\tilde{\mathcal{L}}} \\ &- \sum_{k=1}^K \sum_{n=1}^N q(z_{n,k}=1) \log q(z_{n,k}=1). \end{aligned}\)
```

The lower bound has the same value as the logarithm of the data likelihood \(\mathcal{L}\), if \(q(\mathbf{z}_n)\) is equal to \(p(\mathbf{z}_n|\mathbf{v}_n)\), because then the Kullback-Leibler divergence is zero.
