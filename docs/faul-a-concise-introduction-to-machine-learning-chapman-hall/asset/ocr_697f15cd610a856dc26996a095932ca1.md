The state diagram should not be confused with the graphical representation of the Markov chain.

If the transition probability from one state to another is zero, this arrow is left off the state diagram. For example.

![](bbox=[0.28, 0.47, 0.72, 0.65])

has the transition matrix

```
P = \begin{pmatrix} \frac{1}{2} & \frac{1}{2} & 0 \\ 0 & \frac{1}{2} & \frac{1}{2} \\ 1 & 0 & 0 \end{pmatrix}
```

State 1 remains state 1 with probability 1/2 or changes to state 2 with probability 1/2. Similarly, state 2 remains state 2 with probability 1/2 or changes to state 3 with probability 1/2. State 3 always changes to state 1.

The Markov chain generated by this transition matrix is irreducible, since all states can be reached by every other state. States 1 and 2 are obviously aperiodic, making the Markov chain aperiodic.
