Now, since $g$ is strictly increasing, if $g(x) \le y$, then $x \le g^{-1}(y)$ at the same time. Hence,

```
$F_y(y) = p(x \le g^{-1}(y)) = F_x(g^{-1}(y)) = \int_{-\infty}^{g^{-1}(y)} f_x(x) dx.$
```

Using integration by substitution, we get

```
$F_y(y) = \int_{-\infty}^{y} f_x(g^{-1}(t))(g^{-1})'(t) dt.$
```

To find the probability density function, we differentiate with respect to $y$. By the Fundamental Theorem of Calculus

```
$f_y(y) = f_x(g^{-1}(y))(g^{-1})'(y).$
```

The derivation for the strictly decreasing case starts off in the same way. However, $g(x)$ is less than or equal to $y$, if and only if $x \ge g^{-1}(y)$, due to $g$ being decreasing. Thus,

```
$F_y(y) = p(x \ge g^{-1}(y)) = 1 - F_x(g^{-1}(y)) = 1 - \int_{-\infty}^{g^{-1}(y)} f_x(x) dx.$
```

Again, integrating by substitution and differentiating with respect to $y$ gives

```
$f_y(y) = -f_x(g^{-1}(y))(g^{-1})'(y).$
```

Since $g$ is decreasing, so is $g^{-1}$ and thus its derivative is negative. This makes the expression overall positive.

Since in the strictly increasing case, the derivative of $g^{-1}(y)$ is always positive, both cases can be summarized as

```
$f_y(y) = f_x(g^{-1}(y)) |(g^{-1})'(y)| = |f_x(g^{-1}(y))| \left| \frac{dx}{dy} \right|, \quad (2.18)$
```

where the last equation uses a common short-hand notation. This is known as *change-of-variable technique*, since in its derivation we change the variable in the integral. Another name is *method of direct transformation*.

We illustrate the case, when $g$ is not a one-to-one transformation, by an example first. Let $x$ follow the standard normal distribution $\mathcal{N}(0, 1)$ and let $y = x^2$. While $-\infty < x < \infty$, we have $0 \le y < \infty$. Each value of $y$ is generated by two values $x_1 = -\sqrt{y}$ and $x_2 = \sqrt{y}$. Taking the same approach as before

```
$F_y(y) = p(x^2 \le y) = p(-\sqrt{y} \le x \le \sqrt{y}) = F_x(\sqrt{y}) - F_x(-\sqrt{y})$
```

```
$= \int_{-\infty}^{\sqrt{y}} f_x(x) dx - \int_{-\infty}^{-\sqrt{y}} f_x(x) dx$
```

```
$= \int_{-\infty}^{\sqrt{y}} f_x(\sqrt{t}) \frac{1}{2\sqrt{t}} dt - \int_{-\infty}^{y} f_x(-\sqrt{t}) \frac{-1}{2\sqrt{t}} dt,$
```
