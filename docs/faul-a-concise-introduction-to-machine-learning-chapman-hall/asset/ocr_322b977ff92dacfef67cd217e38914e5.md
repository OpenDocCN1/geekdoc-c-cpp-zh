One possible solution is an activation function with two steps, for example

```
$$h(x) = \begin{cases} 0 & \text{if } x \le 0.25 \\ 1 & \text{if } 0.25 < x < 0.75 \\ 0 & \text{if } x \ge 0.75 \end{cases}$$ (5.3)
```
