# ### Problem 1

The program will branch off depending on what is returned by the expression in the parentheses. However, all is not what it seems. Examine the output of this example:

```
```c
#include <stdio.h>
#include <conio.h>
void main()
{
int a;
printf("Pick a number from 1 to 4:\n");
scanf("%d", &a);
switch (a)
case 1:
printf("You chose number 1\n");
case 2:
printf("You chose number 2\n");
case 3:
printf("You chose number 3\n");
case 4:
printf("You chose number 4\n");
default:
printf("That’s not 1,2,3 or 4!\n");
}
```
```

The output of the above code is as follows:

**Pick a number from 1 to 4:**

**You choose number 2**

**You choose number 3**

**You choose number 4**

**That is not 1,2,3 or 4!**

You will notice that the program will select the correct case but will also run through all the cases below it (including the default) until the switch block’s closing bracket is reached. To prevent this from happening, we shall need to insert another statement into our cases i.e break statement that we will discuss later on.
