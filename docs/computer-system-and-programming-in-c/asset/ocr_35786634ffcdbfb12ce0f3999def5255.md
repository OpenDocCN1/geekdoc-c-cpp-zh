# ## UNFORMATTED CONSOLE I/O FUNCTIONS

The basic difference between formatted and unformatted I/O functions is that the formatted functions allow the input read from the keyboard or the output displayed on the VDU to be formatted as per our requirements. For example, if values of average marks and percentage marks are to be exposed on the screen, then the details like where this output would appear on the screen, how many spaces would be present among the two values, the number of places after the decimal points, etc. can be controlled using formatted functions.

In the unformatted console I/O functions we cannot provide the formatting according to our requirement.

In this category, we will discuss the following unformatted I/O functions.

+   - getchar()
+   - putchar()
+   - getch()
+   - putch()
+   - getche()
+   - gets()
+   - puts()

# ### Putchar() Function

putchar is a function in C programming language that writes a single character to the standard output stream, stdout. Its prototype is as follows:

int putchar (int character)

The character to be printed is fed into the function as an argument, and if the writing is successful, the argument character is returned. Otherwise, end-of-file is returned.

The putchar function is specified in the C standard library header file stdio.h.
