```
# (d) *fmod()*

The fmod() function is used to compute remainder of division.

The general syntax of fmod() function is as follows

```
```c
double fmod (double numerator,double denominator );
float fmod (float numerator, float denominator);
long double fmod (long double numerator,
long double denominator);
```
```

The above function returns the floating-point remainder of *numerator/denominator*.

The remainder of a division operation is the result of subtracting the integral quotient multiplied by the denominator from the numerator:

remainder= numerator - quotient * denominator

# Parameters

The following are the parameters that can be passed in fmod() function.

*numerator*

Floating point value with the division numerator.

*denominator*

Floating point value with the division denominator.

# Return value

The above function returns the remainder of dividing the arguments.

# Portability

In C, only the double version of this function exists with this name.
```
