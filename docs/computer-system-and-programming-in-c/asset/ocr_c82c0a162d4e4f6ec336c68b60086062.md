# Problem 3

Write a program to input a number and print the factorial of that number with the help of function and use the case of no arguments but return value.

# Solution

```
```c
#include<stdio.h>
#include<conio.h>
int fact ();//function prototype
void main()
{
int f;
clrscr();
f=fact();
printf("\n the factorial is %d",f);
getch();
}
int fact()
{
int n,f=1;
clrscr();
printf("\n enter the number");
scanf("%d",&n);
while(n>0)
{
f=f*n;
n--;
}
return(f);
}
```
