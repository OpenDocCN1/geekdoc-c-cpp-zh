# # 课程核心

本课程旨在帮助学员掌握人工智能的基本概念、核心技术及实际应用场景，通过理论与实践相结合的方式，培养学员解决实际问题的能力。

+   - 第一章：人工智能导论
+   - 第二章：机器学习基础
+   - 第三章：深度学习与神经网络
+   - 第四章：自然语言处理
+   - 第五章：计算机视觉
+   - 第六章：强化学习

| 章节 | 课时 | 难度 |
|------|------|------|
| 第一章 | 4 | 低 |
| 第二章 | 6 | 中 |
| 第三章 | 8 | 高 |
| 第四章 | 6 | 中 |
| 第五章 | 6 | 中 |
| 第六章 | 4 | 高 |

> > 人工智能不仅是一种技术，更是一种改变世界的思维方式。
