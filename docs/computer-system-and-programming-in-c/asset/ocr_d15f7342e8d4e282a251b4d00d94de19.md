+   - If we define int a[10] the meaning of this line is that a is an array which holds 10 integer elements and 20 bytes memory is allocated for this array.
+   - If we define int a[3][3] the meaning of this line is that a is an array which holds 3 rows and 3 columns and total 9 elements are stored in this array and 18 bytes memory is allocated for this array.
