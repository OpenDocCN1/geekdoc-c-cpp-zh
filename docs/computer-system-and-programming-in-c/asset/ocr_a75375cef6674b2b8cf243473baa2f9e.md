Now here address will become a user-defined data type and you can define the variable of user defined data type address as follows:
address billing_addr;
address shipping_addr;
The typedef statement does not occupy storage; it simply defines a new type.

# ACCESSING THE MEMBERS OF
A STRUCTURE

We can directly access all the data members of the structure with the help of dot operator. The general syntax for accessing the member of the structure is as follows:
*structurevarible. member-name;

# Example

Let us define a structure student which has sno and name are the data members.

```
struct student
{
    int sno;
    char name[25];
};
```

And we want to access the sno and name then we can directly access the sno and name as follows:
s.sno and s.name
But if the structure variable is not a simple variable that is a pointer type variable then we use -> sign in place of. Operator to access the members of the structure.

```
struct student
{
    int sno;
    char name[25];
}*s;
```

Now we want to access the sno and name then we can directly access the sno and name as
s->sno and s->name
