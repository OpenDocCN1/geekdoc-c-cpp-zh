# ARRAY OF STRINGS

Array of strings are multiple strings, stored in the form of table. Declaring array of strings is same as strings, except it will have additional dimension to store the number of strings.

The general syntax of defining an array of string is as follow:
char array-name[size][size];
For example
char names[4][25];
where names is the name of the character array and the constant in first square brackets will gives number of string we are going to store, and the value in second square bracket will gives the maximum length of the string.

# Example

```
char names [3][10] = {“manish”, “priya”,
“shiva”};
```
