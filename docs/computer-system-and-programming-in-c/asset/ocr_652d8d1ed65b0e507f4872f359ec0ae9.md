# POINTER TYPE DECLARATION AND ASSIGNMENT

We already know that &qty returns the address of qty and this address can be stored in a variable as shown below:
ptr = &qty;

![](bbox=[0.177, 0.816, 0.935, 0.936])

In C programming language, every variable must be declared for its data type before it is used. Even this holds good for the pointers too. We know that ptr is not an ordinary variable like any integer variable. We declare the data type of the pointer variable as that of the type of data that will be stored at the address to which it is pointing to. Since ptr is a variable, which contains the address of an integer variable qty, it can be declared as follows:
int *ptr;
Where ptr is called a pointer variable. In C, we define a pointer variable by preceding its name with an asterisk(*). The “*” informs the compiler that we want a pointer variable, i.e. to set aside the bytes that are required to store the address in memory. The int says that we intend to use our pointer variable to store the address of an integer.
