# # 4 Number System

Number system is used to represent information in quantitative form. Some of the common number systems are binary, octal, decimal and hexadecimal. A number system of base (also called radix) r is a system, which has r distinct symbols for r digits. A string of these symbolic digits represents a number. To determine the value that a number represents, we multiply the number by its place value that is an integer power of r depending on the place it is located and then finding the sum of weighted digits.

The number system we are all companion with is the **decimal numeration system**, or **base 10** number system. Computers, on the other hand, use the **binary numeration system**, which is **base 2**. Other number systems, notably **hex (base 16)** and, to a lesser degree, **octal (base 8)** are also used in the study and computer programming of computers, but only because they provide a more compact notation for representing binary values. Internally the computing device only knows the binary system.

# ## Decimal to Binary Conversion

The First remainder is the LSB (Least Significant Bit or Digit, the digit on the right of the number) of the Binary number. The next remainder is the next digit, and so on until the value is 0.
