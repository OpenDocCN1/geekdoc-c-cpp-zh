+   - Another advantage is an increase in productivity.
+   - Modularity allows multiple programmers to work on a project at the same time.
+   - Modules can be re-used many times, which saves time and reduces complexity, and increases reliability.
+   - It enables easier updates or fixing the program by replacing individual modules rather than larger amounts of code.

# SUMMARY

+   - Computer programming (often shortened to programming or coding) is the process of writing, testing, debugging/troubleshooting, and maintaining the source code of computer programs.
+   - Compiler is a system software which is used to convert high level language into an equivalent machine level language.
+   - Interpreter is also a system software which is used to convert higher level language into equivalent machine level language but the execution is done line by line.
+   - Loader is a program which is used to load the program segment into main memory.
+   - Linker is also a program which is used to convert the object code into equivalent direct executable code.
+   - Programming languages can be classified into first-generation language, second generation language, third-generation language, fourth generation language and fifth-generation language.
+   - The first-generation language is also known as machine language.
+   - The second-generation language is also known as assembly language.
+   - The third-generation language is also known as higher level language.
+   - An algorithm is a set of instructions to solve any problem step by step.
+   - A flow chart is the pictorial representation to solve any problem.
