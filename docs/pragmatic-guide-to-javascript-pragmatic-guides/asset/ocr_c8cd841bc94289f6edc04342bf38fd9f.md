# Trigger at DOM load.

```
// Prototype
document.observe('dom:ready', fx)
// jQuery
$(fx)
// MooTools
window.addEvent('domready', fx)
// YUI 3
Y.on('domready', fx)
// Dojo
dojo.addOnLoad(fx)
// Ext JS
Ext.onReady(fx)
```
