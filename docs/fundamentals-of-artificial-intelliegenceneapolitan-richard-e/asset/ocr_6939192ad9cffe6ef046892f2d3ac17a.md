A parameterized EM algorithm, which has faster convergence, is discussed in [Bauer et al., 1997]. The EM Algorithm is not the only method for handling missing data items. Other methods include Monte Carlo techniques, in particular Gibb's sampling, which is discussed in Section 13.2.6.2.
