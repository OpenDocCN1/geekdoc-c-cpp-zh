# Determine a shortest tour.

+   1. Edges are sorted by weight

+   $(v_2, v_3) 1
+   $(v_1, v_2) 2
+   $(v_2, v_4) 3
+   $(v_1, v_3) 4
+   $(v_1, v_4) 5
+   $(v_3, v_4) 6

+   2. Disjoint sets are created.

+   2. Edge $(v_2, v_3)$ is selected.

+   3. Edge $(v_1, v_4)$ is selected.

+   4. Edge $(v_2, v_4)$ is selected.

+   4. Edge $(v_1, v_2)$ is rejected.

+   5. Edge $(v_1, v_5)$ is selected.
