# 13.2.5 Using the Learned Network to Do Inference

Once we learn a DAG from data, we can then learn the parameters. The result will be a Bayesian network that we can use to do inference for the next case. The next example illustrates the technique.

Suppose now that we find out that Sam has F = f_2. That is, Sam has never defaulted on a loan. We can use the Bayesian network to compute the probability that Sam is a white-collar worker. For this simple network, we can just use Bayes' theorem as follows:

```
P(j_1|f_1) = \frac{P(f_1|j_1)P(j_1)}{P(f_1|j_1)P(j_1) + P(f_1|j_2)P(j_2)} \n = \frac{(5/7)(7/12)}{(5/7)(7/12) + (2/5)(5/12)} = .714.
```
