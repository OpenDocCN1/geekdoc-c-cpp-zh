```
(TripPart
SupersetOf: TravelStep;
SupersetOf: LodgingStay;
BeginDate: date;
EndDate: date;
Cost: price;
PaymentMethod: method;
)
```

```
(TravelStep
SubsetOf: TripPart;
Origin: city;
Destination: city;
OriginLodgingStay: LodgingStay;
DestinationLodgingStay: LodgingStay;
FormofTransportation: travelmeans;
NextStep: TravelStep;
PreviousStep: TravelStep;
)
```

```
(LodgingStay
SubsetOf: TripPart;
Place: city;
Lodging: hotel;
ArrivingTravelStep: TravelStep;
DepartingTravelStep: TravelStep;
)
```

Note that TravelStep and LodgingStay are both subsets of TripPart. So they inherit the attributes in TripPart, namely BeginDate, EndDate, Cost, and PaymentMethod. Next we develop a simple trip that starts at the home city Chicago, visits Melbourne, and returns to Chicago.

(trip1
