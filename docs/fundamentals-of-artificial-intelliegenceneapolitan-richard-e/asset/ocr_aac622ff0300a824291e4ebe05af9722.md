```
EU(D) = max(EU(d1), EU(d2))
= max($152,000, $145,000) = $152,000,
```

and our decision choice is d1. You may wonder where we obtained the values of P($5|d1) and P($5|d2). Once we instantiate the decision node, the chance nodes comprise a Bayesian network. We then call a Bayesian network inference algorithm to compute the needed conditional probabilities. For example, that algorithm would do the following computation:

```
P($5|d1) = P($5|11,000, d1)P(11,000) + P($5|10,000, d1)P(10,000)
= (.2)(.6) + (.5)(.4) = .32.
```

Henceforth, we will not usually show the computations done by the Bayesian network inference algorithm. We will only show the results.
