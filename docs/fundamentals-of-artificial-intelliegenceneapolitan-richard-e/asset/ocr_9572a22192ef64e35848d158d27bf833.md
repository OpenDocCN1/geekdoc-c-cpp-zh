**Definition 3.3** A formula is **valid** if it is satisfied by every interpretation.♦

Clearly, every tautology is a valid formula. Other examples of valid statements follow.

**Example 3.16** The sentence human(Socrates) \(\lor \neg\) human(Socrates) is valid. A simple truth table shows this.

**Example 3.17** The sentence \(\forall x\) (human(x) \(\lor \neg\) human(x)) is valid.

**Example 3.18** The formula loves(Socrates, y) \(\lor \neg\) loves(Socrates, y) is valid. Regardless of which individual in the domain of discourse is assigned to y, the formula is true in every interpretation. So it is valid.

**Definition 3.4** A sentence is a **contradiction** if there is no interpretation that satisfies it.♦

**Example 3.19** The sentence \(\exists x\) (human(x) \(\land \neg\) human(x)) is not satisfiable under any interpretation and is therefore a contradiction.

**Definition 3.5** Given two formulas A and B, if A \(\Rightarrow\) B is valid, we say that A logically implies B and we write A \(\Rightarrow\) B.♦

**Example 3.20** It is left as an exercise to show that human(Socrates) \(\land\) (human(Socrates) \(\Rightarrow\) mortal(Socrates)) \(\Rightarrow\) mortal(Socrates).

**Definition 3.6** Given two formulas A and B, if A \(\Leftrightarrow\) B is valid, we say that A is logically equivalent to B and we write A \(\equiv\) B.♦

**Example 3.21** It is left as an exercise to show that human(Socrates) \(\Rightarrow\) mortal(Socrates) \(\equiv \neg\) human(Socrates) \(\lor\) mortal(Socrates).
