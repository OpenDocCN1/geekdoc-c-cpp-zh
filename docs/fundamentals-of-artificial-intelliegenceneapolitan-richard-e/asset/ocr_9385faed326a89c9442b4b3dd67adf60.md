Williams et al. [2003] develop an agent similar to the wumpus that plans actions and diagnosis faults for NASA aircraft. Besides running programs, this agent uses the circuit-based approach, which is to transmit signals in hardware circuits instead of running standard computer programs [Rosenschein, 1985].
