We now provide examples of evaluating the truth values of expressions.

**Example 2.4** Consider the following proposition: Q∧P∨R. This is the proposition in Example 2.3. Because ∧ has precedence over ∨, the meaning of Q∧P∨R is the second statement shown at the beginning of this section, namely: It is *either* true that the pavement is wet and it is raining outside *or* true that the sprinkler is on.

A truth table shows which assignments of values to P, Q, and R make Q∧P∨R true. That is, it discloses us the possible worlds in which the proposition is true. The truth table is as follows:

| Q | P | R | Q∧P | Q∧P∨R |
|---|---|---|---|---|
| T | T | T | T | T |
| T | T | F | T | T |
| T | F | T | F | T |
| T | F | F | F | F |
| F | T | T | F | T |
| F | T | F | F | F |
| F | F | T | F | T |
| F | F | F | F | F |

The truth table is constructed by first listing all eight possible assignments of values to Q, P, and R; next computing the values of Q∧P using Truth Table b because ∧ has precedence over ∨; and finally computing the values of Q∧P∨R using Truth Table c.
