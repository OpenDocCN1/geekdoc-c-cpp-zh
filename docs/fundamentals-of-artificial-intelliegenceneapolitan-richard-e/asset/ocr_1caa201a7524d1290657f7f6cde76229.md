# ## 7.3 Markov Equivalence

Many DAGs are equivalent in the sense that they have the same d-separations, which means they entail the same conditional independencies. For example, each of the DAGs in Figure 7.8 contains the d-separations \(I_G(Y, Z | X)\) and \(I_G(X, W | \{Y, Z\})\), and these are the only d-separations each has. After stating a formal definition of this equivalence, we give a theorem showing how it relates to probability distributions. Finally, we establish a criterion for recognizing this equivalence.

**Definition 7.5** Let \(\mathbb{G}_1 = (\mathsf{V}, \mathsf{E}_1)\) and \(\mathbb{G}_2 = (\mathsf{V}, \mathsf{E}_2)\) be two DAGs containing the same set of variables \(\mathsf{V}\). Then \(\mathbb{G}_1\) and \(\mathbb{G}_2\) are called **Markov equivalent** if for every three mutually disjoint subsets \(\mathsf{A}, \mathsf{B}, \mathsf{C} \subseteq \mathsf{V}\), \(\mathsf{A}\) and \(\mathsf{B}\) are d-separated by \(\mathsf{C}\) in \(\mathbb{G}_1\) if and only if \(\mathsf{A}\) and \(\mathsf{B}\) are d-separated by \(\mathsf{C}\) in \(\mathbb{G}_2\). That is,

\(I_{\mathbb{G}_1}(\mathsf{A}, \mathsf{B}|\mathsf{C}) \Longleftrightarrow I_{\mathbb{G}_2}(\mathsf{A}, \mathsf{B}|\mathsf{C}).\blacklozenge\)

Although the previous definition has only to do with graph properties, its application is in probability due to the following theorem:

**Theorem 7.2** Two DAGs are Markov equivalent if and only if they entail the same conditional independencies.

**Proof.** The proof follows immediately from Theorem 7.1. \(\blacksquare\)
