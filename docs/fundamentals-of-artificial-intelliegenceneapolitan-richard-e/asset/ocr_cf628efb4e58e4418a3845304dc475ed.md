**A Simplification** It is burdensome to compute the sizes of the neighborhoods of the DAGs in each step. Alternatively, we could include DAGs with cycles in the neighborhoods. That is, \(\text{Nbhd}(\mathbb{G}_i)\) is the set of all graphs (including ones with cycles) that differ from \(\mathbb{G}_i\) by one edge addition, one edge deletion, or one edge reversal. It is not hard to see that then the size of every neighborhood is equal \(n(n-1)\). We therefore define

```
\(q_{ij} = \left\{ \begin{array}{ll} \frac{1}{n(n-1)} & \mathbb{G}_j \in \text{Nbhd}(\mathbb{G}_i) \\ 0 & \mathbb{G}_j \notin \text{Nbhd}(\mathbb{G}_i) \end{array} \right.\)
```

If we are currently in state \(\mathbb{G}_i\) and we obtain a graph \(\mathbb{G}_j\) that is not a DAG, we set \(P(\mathbf{D}|\mathbb{G}_j) = 0\) (effectively making \(r_j\) zero). In this way, \(\alpha_{ij}\) is zero, the graph is not chosen, and we stay at \(\mathbb{G}_i\) in this step. Because \(\mathbf{Q}\) is now symmetric, we can use Equality 13.13 to compute \(\alpha_{ij}\).
