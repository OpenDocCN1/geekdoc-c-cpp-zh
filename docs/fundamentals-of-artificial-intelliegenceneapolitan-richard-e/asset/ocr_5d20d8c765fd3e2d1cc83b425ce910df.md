```
EH_{overcast,Temp}(Activity) = H_{overcast,cool}(Activity)P(cool|overcast) + H_{overcast,mild}(Activity)P(mild|overcast) + H_{overcast,hot}(Activity)P(hot|overcast)
= 1 \times \frac{1}{2} + 0 \times \frac{1}{4} + 0 \times \frac{1}{4} = \frac{1}{2}.
```

So

```
Gain_{overcast,Temp}(Activity) = H_{overcast}(Activity) - EH_{overcast,Temp}(Activity)
= 1 - \frac{1}{2} = \frac{1}{2}.
```

It is left an exercise to compute the gain associated with the other two variables, and show that Temp has the largest gain. So the ID3 Algorithm makes Temp the node touching the edge emanating from Outlook that is labeled overcast. When the value of Outlook is rain, the value of Activity is always to stay home. So we make “stay home” the node touching the edge emanating from Outlook that is labeled rain; this node is a leaf. It is left as an exercise to determine the remaining nodes in the tree.

# Algorithm 11.1 ID3

```
Input: A data file whose records contains values of predictors and a target variable.
Output: A decision tree.
Function Addnode(datafile, set_of_predictors);
if every record in datafile has the same value V of target then return a node labeled with V;
elseif set_of_predictors is empty then return a node labeled with disjunction of values of target in datafile;
else choose predictor in set_of_predictors with largest gain; create a node node labeled with predictor; set_of_predictors = set_of_predictors - {predictor}; for each value V of predictor datafile = data file consisting only of records where predictor has value V; newnode = Addnode(datafile, set_of_predictors); create an edge from node to newnode labeled with V; endfor return node;
endelse
```
