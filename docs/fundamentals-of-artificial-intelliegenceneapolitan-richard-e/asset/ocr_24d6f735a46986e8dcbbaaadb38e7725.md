# 2.1.4 Logical Arguments

Now that we've laid some groundwork, we can return to our initial goal stated at the beginning of this chapter — namely, to mathematically model deductive inference. Recall the following example:

Socrates is a man.
If Socrates is a man, then Socrates is mortal.
Therefore, Socrates is mortal.

We said earlier that if we assume we know that Socrates is a man and we believe that “if Socrates is a man, then Socrates is mortal” is a true statement, then most of us would reason that Socrates is mortal. Let’s see how proportional logic can model this inference. Let the following propositions stand for these statements about the world:

P: Socrates is man.
Q: Socrates is mortal.

Then the statement “if Socrates is a man, then Socrates is mortal” is modeled by this proposition:

P \(\Rightarrow\) Q.
