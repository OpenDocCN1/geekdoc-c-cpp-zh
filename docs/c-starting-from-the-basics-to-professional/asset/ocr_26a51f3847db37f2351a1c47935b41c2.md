**Tip** Analogous to the projection parameter of range-based algorithms, range adaptors such as `transform()` and `filter()` also accept member pointers as input. Provided `Box::isCube()` is a member function that returns a Boolean, and `Box::m_height` is made public (for shame!), the following pipeline would thus produce a view of the heights of all cubes in a range of Boxes:

```
```cpp
boxes | filter(&Box::isCube) | transform(&Box::m_height)
```

Building on the running example of the previous sections, you might expect any of the following commented-out statements to work:

No such luck, sadly. The Standard Library provides no particularly elegant syntax yet to convert a range into a container. We hope they address this in C++23, but for now you will have to rely on the iterator pair-based APIs of containers, applying `begin()` and `end()` to the range first.

```
```cpp
large_boxes.assign(begin(range), end(range));
```

# Range Factories

Besides range adaptors, the `<ranges>` module also offers so-called **range factories**. As the name suggests, these are constructs that do not adapt a given range, but instead produce a new range out of thin air. The following example shows one such range factory in action, in combination with several view adaptors, some of which will be new to you as well.

```
```cpp
// Ex20_17.cpp - Range factories and range adaptors
import <iostream>;
import <ranges>;  // For views, range factories, and range adaptors

using namespace std::ranges::views;

bool isEven(int i) { return i % 2 == 0; }
int squared(int i) { return i * i; }
```
