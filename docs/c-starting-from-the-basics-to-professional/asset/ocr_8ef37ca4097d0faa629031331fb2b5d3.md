**Caution** A common mistake is to write an if statement of the form `if (s1.compare(s2))`, assuming this condition will evaluate to true if `s1` and `s2` are equal. But the actual result, of course, is precisely the opposite. For equal operands, `compare()` returns zero, and zero converts to the Boolean value false. To compare for equality, you should use the `==` operator instead.

The expression `if (s1 <=> s2)`, on the other hand, does not compile. The type of `s1 <=> s2` is `std::strong_ordering`, a class type that purposely does not convert to a Boolean.
