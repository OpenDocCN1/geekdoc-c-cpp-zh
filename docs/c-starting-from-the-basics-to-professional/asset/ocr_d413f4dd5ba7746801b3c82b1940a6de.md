As we explained earlier, a Stack<> object only needs to "remember" the top node so it has only one member variable, m_head, of type Node*. There's a default constructor, a destructor, a copy constructor, and a copy assignment operator function. The destructor and copy members are essential here because nodes will be created dynamically using new and their addresses stored in raw pointers. The swap() function will be used to implement the copy-and-swap idiom for the assignment operator, the push() and pop() members will transfer objects to and from the stack, and the isEmpty() function, obviously, will return true if the Stack<> object is empty. We'll discuss the definitions of all member function templates for the Stack<> type in the next subsection.

# ## Function Templates for Stack Members

We'll start with the constructors. The default constructor is defaulted within the class template, so the compiler will generate one for you if and when needed. The copy constructor must replicate a Stack<T> object, which can be done by walking through the nodes and copying them one by one, as follows:

```
```cpp
template <typename T>
Stack<T>::Stack(const Stack& stack)
{
    if (stack.m_head)
    {
        m_head = new Node {*stack.m_head}; // Copy the top node of the original
        Node* oldNode {stack.m_head};      // Points to the top node of the original
        Node* newNode {m_head};            // Points to the node in the new stack

        while (oldNode = oldNode->m_next)  // If m_next was nullptr, the last node was copied
        {
            newNode->m_next = new Node{*oldNode}; // Duplicate it
            newNode = newNode->m_next;            // Move to the node just created
        }
    }
}
