Whitespace is any sequence of spaces, tabs, newlines, or form feed characters. Whitespace is generally ignored by the compiler, except when it is necessary for syntactic reasons to distinguish one element from another.

# Standard Library Modules

The third line in Figure 1-1 is an *import* declaration. It imports the `<iostream>` module of the C++ Standard Library into Ex1_01.cpp, thus making all types and functionality that is exported by that module available for you to use in that source file. The `<iostream>` module provides you with the means to perform input from the keyboard and text output to the screen. In particular, it defines `std::cout` and `std::endl` among many other things. If the declaration to import the `<iostream>` module was omitted from Ex1_01.cpp, the source file wouldn’t compile because the compiler would not know what `std::cout` or `std::endl` is.

You’ll be importing one or more Standard Library modules into nearly every file. For now, you can recognize Standard Library modules by the angle brackets around their name (we will revise this later in Appendix A). In the second half of the book you’ll also be creating and using your own modules that export types and functions of your own creation. To import these modules, you never put angle brackets around their names.

> **Note**  `<iostream>` also doubles as a header file. In fact, it was a header file long before it became usable as a module in C++20. Nearly all pre-C++20 headers of the Standard Library can be imported as a C++20 module (all except the headers that originate from the C Standard Library, that is). We will have more to say about the difference between header files and modules in Appendix A.

# Functions

Every C++ program consists of at least one and usually many more functions. A function is a named block of code that carries out a well-defined operation such as “read the input data” or “calculate the average value” or “output the results.” You execute, or call, a function in a program using its name. All the executable code in a program appears within functions. There must be one function with the name `main`, and execution always starts automatically with this function. The `main()` function usually calls other functions, which in turn can call other functions, and so on. Functions provide several important advantages:

+   - A program that is broken down into discrete functions is easier to develop and test.
+   - You can reuse a function in several different places in a program, which makes the program smaller than if you coded the operation in each place that it is needed.
+   - You can often reuse a function in many different programs, thus saving time and effort.
+   - Large programs are typically developed by a team of programmers. Each team member is responsible for programming a set of functions that are a well-defined subset of the whole program. Without a functional structure, this would be impractical.
