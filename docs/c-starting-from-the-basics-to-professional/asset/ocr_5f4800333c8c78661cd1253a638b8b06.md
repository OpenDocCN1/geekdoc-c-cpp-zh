```
~~~cpp
using Carton::volume;
using FoodContainer::getWeight;
};
~~~
```

Earlier this chapter you encountered a similar use of the using keyword to inherit constructors from the base class. In this case you use it to cherry-pick from which base class a multiply inherited member function needs to be inherited. Now CerealPack users—or breakfast eaters, as they are more commonly known—can simply write this:

```
~~~cpp
std::cout << "cornflakes volume is " << cornflakes.volume() << std::endl
          << "cornflakes weight is " << cornflakes.getWeight() << std::endl;
~~~
```

Clearly this last option is the preferred whenever there is a clear answer as to which multiply inherited members should be used. If you disambiguate the inheritance already in the class definition, it saves the users of your class the hassle of fighting against the compiler errors that would otherwise surely follow.
