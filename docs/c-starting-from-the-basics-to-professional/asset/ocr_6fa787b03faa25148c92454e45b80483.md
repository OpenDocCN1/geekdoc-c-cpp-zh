fun_ptr is initialized to nullptr, so before using it, the address of the function product() is stored in fun_ptr. The product() function is then called indirectly through the pointer fun_ptr in the output statement. The name of the pointer is used just as if it were a function name and is followed by the arguments between parentheses, exactly as they would appear if the original function name were being used.
