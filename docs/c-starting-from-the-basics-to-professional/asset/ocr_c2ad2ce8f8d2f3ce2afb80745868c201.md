Figure 13-2 illustrates the Box object that will be produced by adding two Box objects. Because the result of this addition is a new Box object, the function implementing addition must return a Box object. If the function that overloads the + operator is to be a member function, then the declaration of the function in the Box class definition can be as follows:

```
Box operator+(const Box& aBox) const;    // Adding two Box objects
```

The aBox parameter is const because the function won't modify the argument, which is the right operand. It's a const reference to avoid unnecessary copying of the right operand. The function itself is specified as const because it doesn't alter the left operand. The definition of the member function in Box.cpp will be as follows:

```
// Operator function to add two Box objects
Box Box::operator+(const Box& aBox) const
{
    // New object has larger length and width, and sum of heights
    return Box{ std::max(m_length, aBox.m_length),
                std::max(m_width, aBox.m_width),
                m_height + aBox.m_height };
}
```
