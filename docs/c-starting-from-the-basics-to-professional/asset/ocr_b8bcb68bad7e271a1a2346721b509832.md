# Named Comparison Functions

You can write the last three lines of Ex4_02 more compactly as follows (see Ex4_02A):

```
```cpp
std::cout << std::format("value = 0: {}\n", std::is_lt(ordering));  // is less than
std::cout << std::format("value = 0: {}\n", std::is_gt(ordering));  // is greater than
std::cout << std::format("value = 0: {}\n", std::is_eq(ordering));  // is equivalent
```
```

The std::is_lt(), is_gt(), and is_eq() are so-called named comparison functions, and are defined by the <compare> module. Three more such functions exist, namely std::is_neq() (is not equivalent), std::is_lteq() (is less than or equivalent), and std::is_gteq() (is greater than or equivalent). The last two especially can save you a lot of typing. To express std::lteq(ordering), for instance, you'd otherwise have to compare ordering to both less and equal and combine the results using the logical OR operator you'll encounter later in this chapter.

The named comparison functions can be used with all three comparison category types of Table 4-2, and behave exactly as you would expect.

# The if Statement

```
```cpp
if (condition)
    statement;

if (condition)

    statement;
    ...
}
