This defines `pstr` to be of type `const char*`. Because it is a pointer-to-const type, the type is now consistent with that of the string literal. Any assignment to the literal’s characters through this pointer will now be stopped by the compiler as well. There’s plenty more to say about using `const` with pointers, so we’ll come back to this later in this chapter. For now, let’s see how using variables of type `const char*` operates in an example. This is a version of the “lucky stars” example, `Ex5_11.cpp`, using pointers instead of an array:

Obviously the original array version is far more elegant, but let’s look past that. In this reworked version, the array has been replaced by eight pointers, `pstar1` to `pstar8`, each initialized with a string literal. There’s an additional pointer, `pstr`, initialized with the phrase to use at the start of a normal output line. Because these pointers contain addresses of string literals, they are specified as `const`.
