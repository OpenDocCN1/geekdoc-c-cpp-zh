## Finer Bounds

Lai and Robbins in 1985 considered the special setting (7.61), and introduced a procedure to obtain a sharp logarithmic lower bound on the regret. It is based on the relative entropy (or Kullback–Leibler divergence) over the densities. For each $\theta, \xi \in \mathbb{R}^K$, this is defined by

```
$D(\theta; \xi) = \int \log\left(\frac{f(r;\theta)}{f(r;\xi)}\right)f(r)dr. \quad (7.66)$
```

It is obviously zero for $\xi = 0$, and also known to be everywhere nonnegative. The bound obtained in [208] for an optimal algorithm, minimizing the regret, is expressed as an approximation:

```
$E[|L_{\mathcal{N}}|] \leq \sum_J \frac{1}{D(\theta_j|\theta^*)} |\bar{r} - \bar{f}_j| \log(\mathcal{N}), \quad (7.67)$
```

with the symbol $\sim$ means that the ratio tends to one as $\mathcal{N} \to \infty$.

## 7.8 Consider the average-optimal control problem with cost function $c$ and relative value $h^*$, solving the ACOE:

```
$\min_{u \in U} \{c(x,u) + P_u h^*(x)\} = \min_{u \in U} \{c(x,u) + \sum_{y \in X} P_u(x,y)h^*(y)\} = h^*(x) + \eta^*$.
```

Assume that the state and action are finite. Consider the value iteration algorithm designed to approximate the Q-function, (7.7):
```
$Q_{n+1}(x) = \min_{u \in U} \{c(x,u) + P_u Q_n(x)\}$
```
where $x \in X$. This is a finite horizon control problem.

## 7.9 Consider the one-dimensional inventory model defined by the

```
$X(k+1) = X(k) + S(k+1) - A(k+1), \quad k \geq 0$
```
where $S, A$ are i.i.d. in the CRW queue. In this model, $A(k)$ represents new demand at time $k$, and $S(k)$ represents a potential control at $k$. A positive value of $X(k)$ corresponds to inventory excess and a negative deficit. A piecewise cost function $c : \mathbb{R} \to \mathbb{R}$ is given, of the form $c(x) = c_-x + c_+$ with $0 < c_- < c_+$, $x_- = \min(x,0)$, and $x_+ = \max(-x,0)$. In this exercise, you will restrict the policy to a finite form: Given $\overline{T} > 0$, define $U$ such that $X'(k) = \overline{T} - X(k)$ is the CRW queue under the nonidling policy. Here $X(k)$ is restricted to the state space $X_{\overline{T}} = \{\overline{T}, \overline{T}-1, \dots, 0\}$, and $U(k) = 1$ if and only if $X(k) \leq \overline{T}-1$. For this threshold, the fluid model is defined by

```
$\frac{dx}{dt} = \begin{cases} \mu - \alpha & \text{if } x < \overline{T} \\ 0 & x = \overline{T} \end{cases}$
```

for any initial condition $x_0 = x = \overline{T}$, where $\mu$ and $\alpha$ are the mean values of $S(k)$ and $A(k)$ respectively. That is, for $x_0 < \overline{T}$, $x_t$ increases linearly until it reaches the level $\overline{T}$, and thereafter stays at this level.
