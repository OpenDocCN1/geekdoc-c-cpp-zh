# 7.3 Queues

The reflected random walk, introduced in Example 6.2, is a model for the evolution of workload in the single server queue. The **controlled random walk** (CRW) queue has its form, but with an input of:

```
$X(k+1) = X(k) - S(k+1)U(k) + A(k+1), \quad (7.29)$
```

where $N(k)\overset{	ext{iid}}{=}(S(k), A(k))$ is an i.i.d. sequence, and $S(k)$ has a Bernoulli distribution. It is assumed that $X_i \overset{	ext{iid}}{=}\{0,1\}$ and $U \overset{	ext{iid}}{=}\{0,1\}$. The input process is interpreted as the sequences of times at which the server is busy. It is subject to the constraint $U(k) \in U(X(k))$ for each $k$, where $U(x)=\{0,1\}$ for $x \ge 1$, and $U(0)=\{0\}$ (the server can't work if there is nobody in the queue).

Example 6.2.3 provides a simple example where $A$ is an i.i.d. Bernoulli process with parameter $\alpha$. Setting $S(k) = 1 - A(k)$ for each $k$, it follows that $S$ is also an i.i.d. Bernoulli process with parameter $\mu = 1 - \alpha$. The MDP in this case is the controlled M/M/1 queue:

+   (i) The following is controlled transition matrix:

```
$P_u(x,x') = \begin{cases} \alpha & x' = x+1 \ \mu & x' = x-u. \ 0 & else \end{cases} \quad (7.30)$
```

+   (ii) A standard cost function is $c(x,u) = x$ for each $x$, so that $E[c(X(k))] = E[X(k)]$ is the mean queue length at time $k$.
-(iii) A typical objective in queueing network applications is a average cost $(7,2)$, which requires $ho = \alpha/\mu < 1$.

The M/M/1 queue is obtained with the nonidling policy, $U(k) = \phi^*(X(k))$, with $\phi^*(x) = 1$ for $x \ge 1$. This is average optimal cost, resulting in $\eta^* = \rho/(1-\rho)$.
