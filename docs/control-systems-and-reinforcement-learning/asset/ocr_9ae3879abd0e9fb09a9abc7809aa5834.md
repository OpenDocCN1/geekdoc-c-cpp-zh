# 4.9 Convergence Theory for QSA

Proof of Proposition 4.34 Choose $T > 0$ so that $|\partial_t^	heta\| \le \frac{1}{2}|\theta\|$ when $t \ge T$, for any solution to (4.139), from any initial condition $\partial_0^	heta = \theta$. We then define

```
$V(\theta) = \int_0^T |\partial_t^	heta\| dt, \quad \partial_0^	heta = \theta$,
$V(\theta) = \int_0^T V^{\infty}(\theta_t)dt, \quad \theta_0 = \theta$.
```

The Gronwall Inequality implies that it is a Lipschitz continuous function of $\theta$. Moreover, applying Lemma 4.35 it shows that the first is radially homogeneous, $V^{\infty}(s\theta) = sV^{\infty}(	heta)$ for each $\theta$ and $s > 0$, and satisfies the lower bound for some $\delta > 0$:

```
$V^{\infty}(\theta) \ge \delta|\theta||$
```

Consequently, this is a Lyapunov function for the ODE=$\infty$: For each initial condition $\partial_0^{\infty} = \theta$,

```
$V^{\infty}(\partial_T^{\infty}) = \int_0^T |\partial_{t+T}^{\infty}\| dt \le \frac{1}{2}V^{\infty}(\theta) \le V^{\infty}(\theta) - \frac{1}{2}\delta|\theta||$.
```

The next step is to show that a similar bound holds with $\partial_T^{\infty}$ replaced by $\partial_T$. Let $L_V$ denote the Lipschitz constant for $V^{\infty}$. The preceding bound combined with Lemma 4.36 gives

```
$V^{\infty}(\partial_T) \le V^{\infty}(\theta) - \frac{1}{8}\delta|\theta|| + L_V(B_T(\\varepsilon)) + K_T[1 + |\theta||]$.
```

Fix $\varepsilon \in (0,1)$ so that

```
$L_V K_T \varepsilon \le \delta/A$,
```

giving

```
$V^{\infty}(\partial_T) \le V^{\infty}(\theta) - \frac{1}{8}\delta|\theta|| + K'_V$
```

with $K'_V = L_V(B_T(\varepsilon)) + K_T$.\To complete the proof, write

```
$V(\theta_s) = \int_s^T V^{\infty}(\theta_t)dt + \int_0^s V^{\infty}(\theta_{T+t}) dt$.
```

The preceding bound gives

```
$V^{\infty}(\partial_T+t) \le V^{\infty}(\theta_t) - \frac{1}{8}\delta|\theta_t|| + K'_V$
```

so that

```
$V(\theta_s) \le V(\theta_0) - \frac{1}{8}\delta \int_0^s |\theta_t|| dt + sK'_V$.
```

This bound implies (QSVI).
