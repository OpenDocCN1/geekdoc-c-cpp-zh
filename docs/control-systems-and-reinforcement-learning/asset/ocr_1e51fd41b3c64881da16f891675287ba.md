# 9.7 Relative Q-Learning

The following then hold for any $\delta \geq 0$ (not excluding $\delta = 0$), with step-size sequence $\alpha_n^\gamma$;

+   (i) For any vector $v \in \mathbb{R}^d$ satisfying $\sum_i v_i \theta_i^\dagger = 0$,

```
lim_{n\to\infty} n[(v^T\theta_n^\dagger)^2] = lim_{n\to\infty} nE[(\hat{\theta}_n^\dagger)^2] = v^T \Sigma_{\gamma} v < \infty.   (9.91)
```

+   (ii) The scaled mean-square semanor vanishes at rate $1/n$;

```
sup_n E[||Q^n - Q^*||_{sp}^2] < \infty.
```

These conclusions are illustrated using the Example of 9.1. Figure 9.3 compares three algorithms, with two different discount factors, $\gamma = 1 - 10^{-3}$ and $\gamma = 1 - 10^{-4}$. The three algorithms are distinguished by step-size (the value of $\gamma$ in $\alpha_n=\alpha_n^{\\gamma}$) and the value of $\delta$:

+   (1) Relative Q-learning with gain $g_h \doteq 1/(1-\\gamma)$ and $\delta = 1$.

+   (2) Watkins's Q-learning ($\delta = 0$) with gain $g_h$, and (3) Watkins's Q-learning with $g_q \doteq 1/(1-\gamma)$.

Consider first relative Q-learning. Figure 1.3 shows histograms of $\hat{\theta}_n(i)$ for algorithm $i = 10$ and $\gamma = 1 - 10^{-3}$ (based on 10 independent runs); the value of $i$ chosen is not important - similar results are observed for each component. The CLT approximation is perfect for $n \geq 10$. The curse of dimension is solved in this example: the condition $\kappa(A_h)$ is less than 30 for all $\gamma < 1$, while $\kappa(A_q)$ is of order $1/(1-\\gamma)$, tending to infinity as $\gamma \to 1$ (recall (8.55) for the definition of $\kappa$).

It is also found that Watkins's algorithm works great with $g_h$, when performance is measured in the semanor: Figure 9.3a shows the behavior of each of the three algorithms on a single sample path. Figure 9.3b shows the average error, obtained by averaging $10^3$ independent runs of each algorithm. The evolution of $||Q^n - Q^*|_{sp}$ is nearly identical using either Watkins's algorithm or relative Q-learning, with common step-size gain $g_h = 1/(1-\\gamma)$.

Figure 6.5 shows results for Watkins's algorithm with the standard step-size $\alpha_n = \alpha^{\\gammagamma}$ ($g=1$), and $\gamma = 0.8$ for the asymptotic convergence is infinite. The infinite variance is not apparent because of the poor design of the experiment, using $\delta = 0$ for each $i$.
