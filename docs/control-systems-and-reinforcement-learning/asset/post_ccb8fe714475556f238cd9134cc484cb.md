### 8.5.1 Approximating the Newton-Raphson Flow

This algorithm is designed so that it approximates the regularized Newton-Raphson flow introduced in (4.15):

$$\frac{d}{dt}\theta_t = -[I + A(\theta_t)^\top A(\theta_t)]^{-1} A(\theta_t)^\top f(\theta_t)$$

## Zap Stochastic Approximation

Initialize $\theta_0 \in \mathbb{R}^d, A_0 \in \mathbb{R}^{d \times d}, \epsilon > 0$. Update for $n \geq 0$:

$$\bar{A}_{n+1} = \bar{A}_n + \beta_n[\bar{A}_{n+1} - \bar{A}_n], \quad \bar{\theta}_{n+1} = \bar{\theta}_n + \alpha_n \partial f_n(\bar{\theta}_n), \quad \theta_{n+1} = \theta_n + \alpha_n G_n f_n(\theta_n), \quad G_{n+1} = -[I + \bar{A}_{n+1}^\top \bar{A}_{n+1}]^{-1} \bar{A}_{n+1}^\top. \quad (8.51a) (8.51b)$$

The two step-size sequences $\{\alpha_n\}$ and $\{\beta_n\}$ satisfy (8.22):

$$\lim_{n \to \infty} \frac{\beta_n}{\alpha_n} = \infty.$$

Under the "high-gain" assumption (8.22), we expect that $\bar{A}_{n+1}$ is a reasonable estimate of $A(\theta_n)$ for large $n$, with $A(\theta_n)$ defined in (8.13). This intuition is supported by the general theory of two-scale SA, summarized in Section 8.2.4. In particular, the high-gain assumption for (8.51a) tells us that we can expect $A_n \approx A(\theta_n)$ after a transient period. The ODE approximation for $\{\theta_n\}$ is precisely the regularized Newton-Raphson flow.

### 8.5.2 Zap Zero Zero

In most of the algorithms considered in later chapters, the matrix $A_{n+1}$ appearing in (8.51a) is of low rank. For the special case $\epsilon=0$, the matrix update for $G_n$ is efficiently computed using the Matrix Inversion Lemma (A.1). This is particularly simple when the rank of $A_{n+1}$ is equal to one, and defined in factored form $A_{n+1} = W_{n+1}V_{n+1}$ with $W_{n+1}$ and $V_{n+1}$ column vectors. Then, (A.1) gives the following update equation:

$$G_{n+1} = [G_n^{-1} - A_{n+1}] = G_n - \frac{1}{1-V_{n+1}^\top G_nW_{n+1}}G_nW_{n+1}V_{n+1}^\top G_n.$$

The right-hand side involves the two matrix-vector products, $G_nW_{n+1}$ and $V_{n+1}^\top G_n$, which introduces complexity of order $O(d^2)$.

An update of complexity $O(d)$ (and even $O(1)$) is possible under stronger conditions.

Then, $\lim_{n\to\infty} f(\theta_n) = 0$.

$$\theta_{n+1} = \theta_n + \alpha_{n+1}[A_{n+1}\theta_n - b_{n+1}]. \quad (8.53b)$$

## 8.5 Zap Stochastic Approximation

This is a very special case because $A(\theta) = E[A_n]$ does not depend on $\theta$. It is the only situation for relaxation of the assumption (8.22) can be easily justified.

The proposition that follows considers SNR using $\alpha_n = \beta_n = 1/n$, so that in particular (8.51a) becomes

$$\bar{A}_{n+1} = \bar{A}_n + \frac{1}{n+1}[A_{n+1} - \bar{A}_n].$$

Recall from Section 8.3.1 that the solution to this recursion can be expressed as an average:

$$\bar{A}_{n+1} = \frac{1}{n+1} \sum_{k=1}^{n+1} A_k.$$

**Proposition 8.8** Consider the SNR algorithm for the linear model (8.53a) in the following form:

$$\theta_{n+1} = \theta_n - \frac{1}{n+1}[A_{n+1}\theta_n - b_n],$$
$$\bar{A}_{n+1} = \frac{1}{n+1}\{\bar{A}_0 + \sum_{k=1}^{n} A_k\}. \quad (8.54)$$

Suppose that the $d \times d$ matrix $A_n$ is chosen so that $A_n$ is invertible for each $n$. For each $n \ge 1$, regardless of the initial condition $\theta_0$,

$$\theta_n = \bar{A}_n^{-1}b_n, \quad \text{where} \bar{b}_n = \frac{1}{n} \sum_{k=1}^{n} b_k.$$

An example is the minimization of a quadratic loss function with noisy observations, in the setting of Section 8.3.3. This is the linear SA algorithm (8.53b) with $A_n = M_n^T M_n$, $b_n = M_n^T \xi_n$, and $A(\theta) = -E[M_n^T M_n] < 0$ by assumption. We also have $M_n^T M_n \ge 0$ for all $n$, so any initialization $\bar{A}_0 < 0$ will satisfy the assumption. Proposition 8.8 implies that SNR is essentially equivalent to ERM.

For the more general (non-quadratic) optimization problem (8.42), we cannot claim that even stochastic gradient descent with SNR will be used. Algorithms can be obtained using SA or PJR averaging to obtain the same asymptotic covariance as ERM.

**Proof of Proposition 8.8** Multiply each step of the recursion for $\{\theta_n\}$ in (8.54) by $(n+1)A_{n+1}$ to obtain

$$(n+1)\bar{A}_{n+1}\theta_{n+1} = (n+1)\bar{A}_n\theta_n - [A_{n+1}\theta_n - b_n].$$

By definition, $(n+1)\bar{A}_{n+1} = n\bar{A}_n + A_{n+1}$, giving

$$\bar{A}_{n+1}\theta_{n+1} = \bar{A}_n\theta_n + \frac{b_n}{n+1}.$$$$

Iterating this recursion gives $(n+1)\bar{A}_{n+1}\theta_{n+1} = \sum_{k=1}^{n+1} b_k$ for each $n \ge 0$.

## 8.6 Buyer Beware

Stochastic approximation can be difficult to apply because of nonlinear dynamics. This is often resolved using SA, while PJR averaging might fail.

### 8.6.1 Curse of Condition Number

The condition number of linearization matrix $A = \partial f(\theta^*)$ is the ratio of maximal and minimal singular values:

$$\kappa(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)} \quad (8.55)$$

where singular values $\sigma_i(A)$ are obtained by taking the square root of eigenvalues of $AA^\top$. If the condition number is large, then the benefit of Polyak-Ruppert averaging may not be observed until a very long run. The example is early warning of what might go wrong in reinforcement learning. The standard Q-learning algorithm has linearization matrix $A$ with massive condition number, and examples in Section 9 reveal PJR averaging may provide no benefit for time horizons less than 10. The point is illustrated using SA recursion

$$\theta_{n+1} = \theta_n + n^{-1}[A\theta_n + \Delta_n] \quad (8.56)$$

in which $\Delta$ is Gaussian and i.i.d., with marginal $N(0,1)$. The matrix is to be simple form $A = -I + (\kappa-1)vv^\top$, in which $\|v\| = 1$ and $\kappa > 1$. The condition number of $A$ is $\kappa$. Let's consider two algorithms with optimal convergence:

- (i) Stochastic Newton-Raphson: $\theta_{n+1} = \theta_n + n^{-1}(A_n)^{-1}\Delta_n \quad (8.57)$
- (ii) PJR estimates with carefully selected step-size. One challenge with a large condition number is that the step-size needs to be reduced to avoid explosion of the parameter estimates. This is required even if there is no noise, so motivates the modification $\alpha_n = \min(\alpha_0, n^{-\rho})$ (8.58)$

The value $\alpha_0 = 1/\kappa$ was reliable in experiments, with $\rho \in (1/2,1)$. Either algorithm achieves the optimal variance for each component of the parameter:

$$\Sigma_{\theta} = G\Sigma_A G^\top = (I + rv^\top)^{-1} = I - \frac{r}{1+r}vv^\top,$$
with $r = \kappa-1$. In particular, each approach reaches the optimal variance for

$$\lim_{n\to\infty} E[\theta_n(i)^2] = \lim_{n\to\infty} E[\theta^*(i)^2] = \Sigma_{\theta^*}(i).$$

## 8.6 Buyer Beware

In fact, no limit is required for SA recursion. This is seen through a refinement of Proposition 8.8: First note when $n = 0$ in (8.57), the initial condition is canceled:

$$\theta_1 = \theta_0 + \theta_0 - A^{-1}\Delta_1 = -A^{-1}\Delta_1.$$

It can be shown by induction that for each $n \geq 1$,

$$\theta_n = -A^{-1}\frac{1}{n}\sum_{k=1}^n \Delta_k.$$

Here $\sqrt{n}\theta_n \sim N(0, \Sigma^*)$ for each $n$.

 In the experimental results described here, the vector $v$ was chosen as $v = z/\|z\|$, with $z$ selected $N(0,d)$ with $d=50$. It was found that $\hat{\Sigma}(i)$ is close to unity for each $i$ with values of $\kappa$ considered. The exponent for Polyak-Ruppert averaging was taken to be $\rho = 0.75$, averaging over the recent 70% of samples:

$$\theta_n = \frac{1}{0.7n}\sum_{0.3n \leq k \leq n} \theta_k.$$

Histograms were obtained for $Z_n^i = \sqrt{n}\theta_n^i : 1 \leq i \leq 500$ (500 independent runs), with initialization $\theta_0^i \sim N(0,\sigma^2I)$ using $\sigma^2 = 25$.

For $\kappa = 100$, the behaviors of Polyak-Ruppert estimates are very similar after $10^3$ iterations. Increasing the value to $\kappa = 500$ revealed differences. The source of the problem is clear from Figure 8.8: The bound $\alpha_n \leq 1/n$ was used to avoid explosion of the parameter estimates. The figure shows only the first three parameter estimates for each of the three parameter estimates. In these-cases, the estimates $\theta_n(1)$ and $\theta_n(1)$ are not visible since $\theta_0(1)$ is out of range and the step-size is so small.

Figure 9, $n=10^3$, reveals significantly high variance when using Polyak-Ruppert averaging. With $n=10^4$, the situation is improved, and the results from PJR averaging are more similar to SNR.

However, $n=10^4$ samples is no longer sufficient if condition $\kappa$ is increased from 500 to 1,000.
