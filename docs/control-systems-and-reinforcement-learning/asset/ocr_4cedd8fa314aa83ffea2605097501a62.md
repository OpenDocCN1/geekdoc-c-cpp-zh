(ii) The infinite horizon optimal reward is defined by

```
$\eta^* = \max_{N \to \infty} \frac{1}{N} \sum_{k=1}^{N} R(k).$
```

Denote $ar{f}_u = 	ext{E}[Z_u(k)]$ (assumed independent of $k$), and $ar{f}^* = \max_u \bar{f}_u$. An optimizing policy is given by the open-loop strategy,

```
$U^*(k) = \arg \max_{1 \le u \le K} \bar{f}_u$.
```

This is not feasible unless the means are given.

We can course estimate $\bar{f}_u : 1 \le u \le K$ using Monte Carlo, which is an example of exploration. However, for any action $u \in \1, \dots, K\}$, an accurate estimate of $\bar{f}_u$ will likely require frequent selection of this action. In the big-money applications of bandit theory (such as in advertising), we are learning as went to maximize profit. This means we must minimize the time spent exploring with suboptimal actions, which motivates a finer notion of optimal reward:

**Regret:** For a given time horizon $\mathcal{N}$, the regret is defined as the sum

```
$L_{\mathcal{N}} = \sum_{k=1}^{\mathcal{N}} {\bar{f}^* - R(k)}\ \quad (7.55)$
```

Under mild additional assumptions, its mean grows logarithmically in $\mathcal{N}$ for the best policies.

# 7.8.2 Bayesian Bandits

If we formulate the bandit problem within an MDP setting, theory in Appendix C predicts that we can express an optimal policy as a form of state feedback:

```
$U^*(k) = \Phi^*_{-k}(\mathcal{X}(k)), \quad 0 \le k \le \mathcal{N}.\ \quad (7.56)$
```

The belief state $\mathcal{X}(k)$ coincides with the distribution of the state at time $k$, given observations up to time $k$. This requires a Bayesian setting for which the reward is some randomized function of the state. A hopefully simple starting point, let's turn to a linear-Gaussian model for which the belief state is finite dimensional.
