# 6.3 Spectra and Ergodicity

Remember that the left-hand side is a conditional expectation, so that

```
$E[v(X(n)) | X(0) = x] = \lambda^n v(x).$
```

The left-hand side of this equation is bounded in $n$, which means that $|\lambda| \le 1$ as claimed.

The Markov chain is called ergodic if for each $x,y \in X$,

```
$\lim_{n\to\infty} P\{X(n) = y | X(0) = x\} = \lim_{n\to\infty} P^n(x,y) = \pi(y). \quad (6.16)
```

Concurrently, for any function $c \in X$,

```
$\lim_{n\to\infty} E[c(X(n)) | X(0) = x] = \pi(c) = \sum_{y} c(y)\pi(y). \quad (6.17)
```

This leads to one more observation:

+   (iv) Suppose that $\lambda$ is an eigenvalue $\lambda \neq 1$ but satisfying $|\lambda| = 1$ (the eigenvalue lies on the boundary of the unit). Then the Markov chain cannot be ergodic. To see this, let $v \in \mathbb{C}^d$ be an eigenvector (nonzero) and let $\lambda = e^{i\theta}$ with $0 < \theta < 2\pi$. Hence $P^nv = \lambda^n v$ for each $n$. With $c = v$, we obtain

```
$E[c(X(n)) | X(0) = x] = \sum_{y\in\X} P^n(x,y)v(y) = e^{in\theta}v(x).
```

The right-hand side does not converge as $n \to \infty$.

The following may be expected from the following.

**Theorem 6.2 (Spectral Conditions for Ergodicity)** Suppose that $\lambda_1=1$ is the only eigenvalue satisfying $|\lambda| = 1$ and this eigenvalue is not repeated. Then the chain is ergodic, and the convergence rate in (6.16) is geometric:

```
$\frac{1}{n} \log(\max_{x,y} |P^n(x,y) - \pi(y)|) = \log(\rho) < 0, \quad (6.18)
```

where $\rho = \max\{|lambda_k| : k \ge 2\}$.

Proof The first step is to consider a modified matrix $\hat{P}$ defined by

```
$\hat{P}(x,y) = P(x,y) - \pi(y), \quad x,y \in X. \quad (6.19)
```

This can be expressed $\hat{P} = P - \mathbf{1} \otimes \pi$, where $\mathbf{1}^v$ is a column vector of ones, $\pi$ is the invariant pm, and "" is an outer product. It can be shown by induction that

```
$\hat{P}^n = P^n - \mathbf{1} \otimes \pi. \quad (6.20)
```

That is, for each $x,y$,

```
$\hat{P}^n(x,y) = P^n(x,y) - \pi(y).
```

With a bit more effort, it can be shown that $\lambda(\hat{P}) = \{0, \lambda_2, \dots, \lambda_m\}$. That is, all of the eigenvalues of $\hat{P}$ coincide with those of $P$, except the first eigenvalue, which is moved to the origin. A bit of linear algebra completes the proof of (6.18).
