# Optimal Control

At time $T_1 = (\mu_1 - \alpha_1)^{-1}$, the first buffer enters, and we have for $t > T_1, t \approx T_1$,

```
$q_t = q_{T_1} + t(0, \alpha_1 - \mu_2, \alpha_3, 0)^	op$.
```

At time $T_2 = T_1 + q_{T_1}/(\mu_2 - \alpha_1)$, the second buffer will drain, and all of the work will be at three. Note that over the interval $[T_1, T_2]$, buffer 1 remains empty; the arrivals to buffer 1 at rate $\alpha_1$ are passed directly to buffer 2.

The main point is that during the entire interval $[0, T_2]$, the exit at Station 1 is starved. Starting from time $T_2$, an analogous situation arises, now the exit at Station 2 is temporarily starved. We can conclude that either $u_t(4) = 0$ or $u_t(2) = 0$ for all $t \ge 0$. This implies that

```
$u_t(2) + u_t(4) \le 1$, (3.57)
```

so that buffers 2 and 4 behave as if they are located at a single station. The inequality (3.57) resulting from this policy is known as the virtual load constraint. The virtual load and virtual workload process are defined by the following:

```
$\rho_v = \frac{\alpha_1}{\mu_2} + \frac{\alpha_3}{\mu_4}$ (3.58)
```

```
$w_t^v = \frac{q_t(1) + q_t(2)}{\mu_2} + \frac{q_t(3) + q_t(4)}{\mu_4} \quad t \ge 0$. (3.59)
```

We can compute

```
$\frac{dw_t^v}{dt} = \frac{\alpha_1 - \mu_2 u_t(2)}{\mu_2} + \frac{\alpha_3 - \mu_4 u_t(4)}{\mu_4} = \rho_v - [u_t(2) + u_t(4)]$.
```

If $ho_v > 1$ then $\frac{dw_t^v}{dt} \ge -(1-ho_v) > 0$ for all $t$, so that $\|q_t\| 	o \infty$ as $t 	o \infty$.

A specific example is

```
$\mu_1 = \mu_3 = 10; \quad \mu_2 = \mu_4 = 3; \quad \alpha_1 = \alpha_3 = 2$.
```

The network load is given by $ho_v = 2(1/3 + 1/10) < 1$, which implies that there are many stabilizing policies. However, $ho_v = 2(1/3 + 1/10) > 1$, so that the fluid model controlled by LBFS is unstable in the strongest possible sense.
