
## 10.6 SGD without Bias

We disregard any part of $\Lambda^\theta_-$ that does not depend upon $u$. Let $\mathcal{F}_k^-$ denote the partial history up to time $k$:

```
$$\mathcal{F}_k=\{X(k), \Phi(i) : 0 \leq i \leq k-1\}$$
```

This is the entire history to $k$, except that $U(k)$ is discarded.

**Lemma 10.20** *For any initial distribution for $X(0)$, $E[\Lambda^\theta(\Phi(k)) | \mathcal{F}_k] = 0$. Consequently,*

- (i) $\Lambda^\theta(\Phi(k)) : k \geq 0$ is a martingale difference sequence.
- (ii) For any function $g: X \to \mathbb{R}$,

```
$0 = E[g(X(k))\Lambda^\theta(\Phi(k))].$
```

*Proof* From the definitions, we have the following for any $k$ and $x$ in $X$:

```
$E[\Lambda^\theta(\Phi(k)) | \mathcal{F}_k : X(k) = x] = \sum_{u} \Lambda^\theta(x,u)\phi^\theta(u | x).$
```

Given the definition $\Lambda^\theta(x,u) = \nabla_\theta\phi^\theta (u | x)/\phi^\theta (u | x)$, it follows that

```
$E[\Lambda^\theta(\Phi(k)) | \mathcal{F}_k : X(k) = x] = \sum_{u} \nabla_\theta\phi^\theta (u | x) = \nabla_\theta\sum_{u} \phi^\theta (u | x) = 0,$
```

the final equality holds because $\phi^\theta(\cdot | x)$ is a pmf for $U$ for each $x$. smoothing property of conditional expectation gives

```
$E[g(X(k))\Lambda^\theta(\Phi(k))] = E[g(X(k))\Lambda^\theta(X(k),U(k)) | \mathcal{F}_k] = 0.$
```

Lemma 10.20 implies that we can relax the definition of conditional features to read as follows: For each $\theta \in \mathbb{R}^d$ and $1 \leq i \leq d$, there is a function $G^\theta: X \to \mathbb{R}$ such that

```
$$\Lambda^\theta - G^\theta \in \mathcal{H}^\theta.$$
```

Gibbs Policy consider for each policy $\theta$

Given a $d$-dimensional vector $\psi^\theta$, consider for each policy $\theta$

```
$$\phi^\theta (u | x) = \frac{1}{\kappa(\theta,x)} \exp(\theta^T\psi^\theta(x,u)).$$
```

where $\kappa$ is a normalizing constant (recall 9.46). We then have the following from the definitions:

**Lemma 10.21** *For the Gibbs policy*

```
$$\Lambda^\theta(x,u) \overset{\text{=}}{=} \psi^\theta(x,u) - \psi^\theta(x), \ \psi^\theta(x) \overset{\text{=}}{=} \sum_{v} \phi^\theta (v | x)\psi^\theta(x,v).$$
```

Consequently, for this policy we can take $d' = d$ and $\mathcal{H}^\theta ={\omega^T\psi^\theta : \omega \in \mathbb{R}^d\}$ to ensure that the CFP is satisfied in the relaxed form (10.51). However, in the next subsection we see that it may be best to use $\mathcal{H}^\theta ={\omega^T\psi^\theta : \omega \in \mathbb{R}^d\}$.

## 10.7 Advantage and Control Variates

First, and most important: Don't be fooled by the reality of unbiased gradient observations. The ideal algorithm using TD(1) may come with variance. In practice, you are likely to resort to the introduction of $\lambda < 1$ TD($\lambda$) along with the application of state weighting, so that the eligibility vector in (10.4cc) is replaced

```
$\zeta_{n+1} = \lambda\{\Phi(n) \neq z^*\}\zeta_n + w_{n+1}\psi_{\theta_{n+1}}(\Phi(n+1))$
```

where $w_{n+1} = w(X(n+1))$ for the weighting function $w: X \to \mathbb{R}_+$.
You may go further and experiment with the discounted-cost value function as an approximation for $Q_\theta$. This is unfortunate, but bias/variance tradeoffs are a theme in machine learning that appears to be inescapable.
The following pages describe techniques to reduce variance without bias.

### 10.7.1 Variance Reduction through Advantage

Lemma 10.20 tells us that we construct a second family of functions $\mathcal{G}$, where $G: X \to \mathbb{R}$ for each $G \in \mathcal{G}$, and replace (10.44a) with the following:

```
$\theta_{n+1} = \theta_n - \alpha_n \Lambda^{\theta_n}(\Phi(n))[H_{\theta_n}^w(\Phi(n)) - G_n(X(n))]. \quad (10.44a')$
```

Provided that the CFP holds, we will maintain the ODE approximation as gradient descent, regardless of how $\{G_n\}$ are defined. The favored value of $G$ is as shown in 9.1.

```
$G_\theta^w(x) = E[H_\theta^w(\Phi(n)) | X(n)=x] = \sum_{u} H_\theta^w(x,u)\phi^\theta(u | x).$
```

The difference $Q_\theta - \theta$ was designated the advantage function associated with $\phi^\theta$. A modified function $\mathcal{H}_\theta^v$ is defined such that for $V_0 \in \mathcal{H}^\theta$, $H_0(x) = H_0(x) - L_0(x)$, for some $H_0 \in \mathcal{H}^\theta$, with $L_0(x) \overset{\text{=}}{=} \sum_{u} H_0(x,u)\phi^\theta(u | x)$.

And for you, we write $V_\theta^w(x,u) \overset{\text{=}}{=} H_\theta^w(x,u) - L_\theta^w(x) = w(x)\psi_\theta(x,u)$,

```
$\tilde{\psi}_\theta(x) = \psi_\theta(x) - \psi_\theta(x),$
```

We arrive at an update that is preferred:

```
$\theta_{n+1} = \theta_n - \alpha_{n}\tilde{\Gamma}^\theta(n), \quad \tilde{\Gamma}^\theta(n) = \Lambda^{\theta_n}(\Phi(n))V_{\theta_n}^w(\Phi(n)). \quad (10.44a^*)$
```

This form comes for free when $\psi_\theta = \Lambda^\theta$, in this case $\psi_\theta = 0$ is obtained as an application of Lemma 10.20. The introduction of $\{\Lambda^{\theta_n}(\Phi(n))H_{\theta_n}^w(X(n)) : n \geq 0\}$ to obtain (10.44a*) from (10.44a) is an example of the control variance technique that was introduced in Section 6.7.5.

### 10.7.2 A Better Advantage

Consider a function classifying the CFP. Suppose that the input is not large, so that it is practical to compute $H_\theta^w(x)$ based on $H_\theta^w(x,u)$ for each observed $x \in X$. In this case, there is an alternative control variate, defined by a different sort of smoothing. It is no more complex and has lower variance.

For any $\theta$, $\omega$ and $x$ denote

```
$$\Delta_\theta^w(x) = E[\Lambda^\theta(\Phi(n))H_\theta^w(\Phi(n)) | \mathcal{F}_n ; X(n)=x]$$
```

with $\{\mathcal{F}_k\}$ defined in (10.50). Applying the definition of conditional mean using $\phi^0$ gives

```
$$\Delta_\theta^w(x) = \sum_u \nabla_\phi^0(u|x)H_\theta^w(x,u), \quad x \in X.$$
```

From the smoothing property of conditional expectation, we obtain a new unbiased algorithm by “smoothing” (10.44a):

```
$$\theta_{n+1} = \theta_n - \alpha_n \nabla{\hat{\Gamma}}_r^v(n), \quad \nabla{\hat{\Gamma}}_r^w(n) \overset{\text{def}}{=} \hat{\Delta}_{\theta}^w(X(n)). \quad (10.44a^{**})$$
```

We see that $\nabla{\hat{\Gamma}}_r^v(n)$ has lower variance when compared to $\nabla{\hat{\Gamma}}_r^w(n)$ in (10.44a). More important is a comparison of the respect asymptotic covariance matrices $\Sigma_\Delta$, as defined in (8.27). The first step in this comparison is to consider the gradient estimates evaluated at the optimal parameters. If $\nabla L(\theta^*)=0$ for any limit of either, the following two processes have zero mean for the process $\mathcal{F}$ in steady state:

```
$$\Delta_n^{\infty,v} = \nabla{\hat{\Gamma}}_r^v(n) \overset{\text{def}}{=} \hat{\Delta}_{\theta}^v(\Phi(n))V_{\theta*}^w(\Phi(n)),$$
```

```
$$\Delta_n^{\infty,w} = \nabla{\hat{\Gamma}}_r^w(n) \overset{\text{def}}{=} \hat{\Delta}_{\theta}^w(X(n)).$$
```

The respective asymptotic covariance matrices are denoted

```
$$\Sigma_{n}^{\infty,\Delta} = \sum_{n=-\infty}^{\infty} E[\nabla{\hat{\Gamma}}_r^v(n)(\nabla{\hat{\Gamma}}_r^v(0))^T], \quad \text{and} \quad \Sigma_{n}^{\infty,\Delta} = \sum_{n=-\infty}^{\infty} E[\nabla{\hat{\Gamma}}_r^w(n)(\nabla{\hat{\Gamma}}_r^w(0))^T].$$
```
