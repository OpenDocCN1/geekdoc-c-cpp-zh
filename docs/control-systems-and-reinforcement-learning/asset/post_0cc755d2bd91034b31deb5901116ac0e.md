```
$0 = \frac{1}{2} \nabla_\theta E_n[\mathcal{B}^\theta(X)^2] = E_n[\mathcal{B}^\theta(X) \nabla_\theta \mathcal{B}^\theta(X)].$
```

On substituting the definitions, we obtain representations that suggest algorithms.

**Lemma 9.5** *The following holds for each $\theta \in \mathbb{R}^d$:*

```
$-\frac{1}{2} \nabla_\theta E_n[\mathcal{B}^\theta(X)^2] = E_n[\mathcal{D}^\theta_{n+1} \zeta_n^\theta].$
```

where

```
$\zeta_n^\theta = \nabla_\theta E[h^\theta(X(n)) - \gamma h^\theta(X(n+1)) | \mathcal{F}_n].$ (9.30)
```

*Proof.* By the Markov property, we have

```
$\mathcal{B}^\theta(X(n)) \overset{=}{=} \mathcal{D}^\theta_{n+1} | X(n)] = E[\mathcal{D}^\theta_{n+1} | \mathcal{F}_n].$
```

The gradient of interest is thus

```
$-\frac{1}{2} \nabla_\theta E_n[\mathcal{B}^\theta(X)^2] = E[\mathcal{D}^\theta_{n+1} | \mathcal{F}_n] \zeta_n^\theta.$
```

where $\zeta_n^\theta$ is given in the statement of the lemma:

```
$\zeta_n^\theta = -\nabla_\theta E[\mathcal{D}^\theta_{n+1} | \mathcal{F}_n] = \nabla_\theta E[h^\theta(X(n)) - \gamma h^\theta(X(n+1)) | \mathcal{F}_n].$
```

The smoothing property of conditional expectation completes the proof:

```
$E[\mathcal{D}^\theta_{n+1} | \mathcal{F}_n]\zeta_n^\theta] = E[\mathcal{D}^\theta_{n+1} \zeta_n^\theta]. \square$
```

The lemma suggests that it is possible to approximate the gradient flow for the objective $\Gamma(\theta) = E[\mathcal{B}^\theta(X)^2]$ using stochastic approximation, we have

```
$\theta_{n+1} = \theta_n + \alpha_{n+1}\mathcal{D}^\theta_{n+1} \zeta_n^\theta|_{\theta=\theta_n}.$
```

However, the conditional expectation in (9.30) presents a challenge. Proposition 9.4 suggests many approximations based on the conditional expectation (9.19).

**Proposition 9.6**

```
$E_n[\mathcal{B}^\theta(X(n))^2] = E_n[\mathcal{D}^\theta_{n+1}^2] - \sigma_n^2(\theta),$ (9.31)
```

where $\sigma_n^2(\theta)$ denotes the conditional variance:

```
$\sigma_n^2(\theta) = E[\mathcal{D}^\theta_{n+1}^2] - E[\mathcal{D}^\theta_{n+1} | \mathcal{F}_n]^2. \square$
```

The objective function $\Gamma(\theta) = E[\mathcal{B}^\theta(X)^2]$ is given by the MSBE plus $\sigma_n^2(\theta)$, which is small in many cases. An SA algorithm designed to approximate the gradient flow is straightforward:

```

## 9.4 TD($\lambda$) Learning

### 9.3.2 Mean-Square Value Function Error

An alternative mean-square error is defined in terms of the function value

```
$\theta^* = \arg\min_{\theta} ||h^\theta - h||$
```

in which the choice of norm is part of the design of the algorithm. Most common is

```
$||h^\theta - h||_{\pi}^2 = \sum_{x\in X} (h^\theta(x) - h(x))^2\pi(x),$
```

in which $\pi$ is the steady-state penalty for $X$. It is remarkable that this loss function can be minimized without observations of $\{h(X(k))\}$. One class of algorithms for this purpose is TD(1)-learning. The algorithm is defined in Section 9.4.1, and conditions under which it solves (9.33) are presented in Theorem 9.7.

### 9.3.3 Projected Bellman Error

Assumed given a $d$-dimensional stochastic process $\zeta$ known as the sequence of eligibility vectors. The goal is to obtain vector $\theta^* \in \mathbb{R}^d$ that solves the Galerkin relation of (9.8). The smoothing property of expectation gives

```
$0 = E[-\h^\theta(X(k)) + c(X(k)) + \gamma h^\theta(X(k+1))\}\zeta_k(i)], \quad 1 \le i \le d.$
```

It is usually assumed in the expectation $X(k)$ is distributed according to $\pi$. If $h = h^\theta$ for some $\theta \in \mathbb{R}^d$, and the solution to (9.35) is unique, then the Galerkin approach will yield the exact solution.

The goal of this algorithm is to solve (9.35) for a particular choice of eligibility vector. We begin with a special case for which there is theory.

#### 9.4.1 Linear Function Class

In TD($\lambda$) learning with function approximation, the eligibility vectors are defined by passing $\{\psi(X(n))\}$ through a first-order low-pass filter:

```
$\zeta_{n+1} = \lambda\zeta_n + \psi(X(n+1)), \quad n \ge 0.$
```

It is always assumed that $\lambda \in [0,1]$.

#### TD($\lambda$) Algorithm

For initialization $\theta_0, \zeta_0 \in \mathbb{R}^d$, the sequence of estimates are defined recursively:

```
$\theta_{n+1} = \theta_n + \alpha_{n}\zeta_n\mathcal{D}_{n+1},$
$\mathcal{D}_{n+1} = (-h^\theta(X(n)) + c(X(n)) + \gamma h^\theta(X(n+1)))|_{\theta=\theta_n},$
$\zeta_{n+1} = \lambda\zeta_n + \psi(X(n+1)).
```
