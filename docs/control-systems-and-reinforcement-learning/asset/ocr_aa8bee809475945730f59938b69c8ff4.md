# Mathematical Background

sup $a_t$: Supremum of the scalars $\{a_t : t \in T\}$, also known as the least upper bound (LUB). Denote the set of all upper bounds by $S=\{r \in \mathbb{R} : a_t \leq r \text{ for each } t \in T\}$. If $\{a_t\}$ is bounded from above, then this set is nonempty and can be expressed as $[s_0, \infty)$ for some $s_0 \in \mathbb{R}$. This is by definition of supremum: $\sup a_t = \min\{s : s \in S\} = s_0$.

+   * The infimum is the greatest lower bound, or $\inf\{a_t\} = -\sup\{-a_t\}$.

+   * $\lim_{t\to\infty} \delta_t$: Limit supremum, defined as follows for a scalar-valued function of $t$. First

$\delta_r = \sup\{\delta_t : t \geq r\},\quad r \in T$.

As $r$ increases, $\delta_r$, cannot increase (the supremum is taken over a smaller set). The limit as $r \to \infty$ is the limit supremum:

$\lim_{t\to\infty} \limsup \delta_t = \lim_{r\to\infty} \delta_r$.

+   * $\liminf_{t\to\infty} \delta_t = -\limsup_{t\to\infty}(-\delta_t)$: limit infimum.

+   * We say the limits of the same dimension if $\inf \delta_t = \sup \delta_t$.

+   * For two-scalar functions of time $\{a_t, b_t : t \in T\}$:
  * $a_t = O(b_t)$: The radius is bounded, so that $|a_t| \leq B|b_t|$ for some constant $B$ and all $t \in T$.
  * $a_t = o(b_t)$: $\lim_{t\to\infty} a_t/b_t = 0$.

+   * We also consider the parameter tending to zero rather than infinity. For example, this bound might be anticipated in Section 4.6:

```
$\Gamma(0 + \varepsilon\Gamma) = \Gamma(0) + \varepsilon^TT\Gamma(o) + o(\varepsilon),\quad \varepsilon > 0$.
```

This is shorthand for the following:

```
$\lim_{\varepsilon\to\0} |\Gamma(0 + \varepsilon\Gamma) - {\Gamma(0) + \varepsilon^TT\Gamma(o)}| = 0$.
```

# A.1.3 Linear Algebra

+   * For: two vectors of the same dimension, this dimension is the inner product. Written as column vectors: $v \cdot w = v^T w$.

+   * Singular values of a matrix $R$: $\{\sigma_1, \dots, \sigma_n\}$. First obtain the eigenvalues $\{\lambda_i\}$ of $RR^T$, and then define $\sigma_i = \sqrt{\lambda_i}$.

+   * Condition number of $R$: $R > 0$ means $x^T Rx > 0$ whenever $x \in \mathbb{R}^n$ with $x \neq 0$.

+   * Positive definite: $R \geq 0$ means $x^T Rx \geq 0$ whenever $x \in \mathbb{R}^n$.

+   * Positive semidefinite: $R \geq 0$ means the statement that $R$ is positive definite, or positive semidefinite, carries with the hidden assumption that the matrix is symmetric: $R = R^T$.

Note: In this book, the statement that $R$ is positive definite, or positive semidefinite, carries with the hidden assumption that the matrix is symmetric: $R = R^T$.
