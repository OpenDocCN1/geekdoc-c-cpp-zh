# 4.2 A Brief Return to Reality

This entire considers ODE approaches to algorithm design: means design of the function f appearing in (4.2), or design of the more exotic “quasistochastic” ODEs for which theory and applications are developed in Sections 4.5–4.7.

There is the inevitable translation step: Any design formulated in continuous time must be translated to create a practical algorithm. If you have taken a first-year calculus course, you probably have predicted the most common approach: select a sequence of times $\{0=t_0<t_1<...\}$, and replace the derivative in (4.2) by a finite difference: With $\dot{d}_0=0$ given, for each $n \ge 0$,

```
$$\alpha_n^{-1} = |\dot{t}_{n+1} - \dot{t}_n| = f(\dot{t}_n),$
```

where $\alpha_{n+1} = t_{n+1} - t_n - t > 0$. The recursive nature is evident when rearranging terms:

```
$$\dot{t}_{n+1} = \dot{t}_n + \alpha_n f(\dot{t}_n).$quad (4.8)
```

In our final approach, we simplify notation, writing $\theta_n = \dot{t}_n$, and $\{\alpha_n\}$ is known as the step-size sequence. This is known as the Euler approximation of an ODE, or simply Euler’s method.

This approximation is successful under the following conditions for Proposition 4.1: It can

```
$$\max_{0 \le t \le T} |\dot{d}_t - \dot{t}_t| \le K(L,T)\alpha,$quad (4.9)
```

where $\alpha = max(\alpha_k: t_k \le T)$, and $L$ was introduced in (4.5). Grönwall’s Inequality is used in the proof of (4.9), which leads to bounds on $K(L,T)$ that at first appear frightening (growing exponentially fast in $L$ and $T$).

Fortunately, asymptotic stability of the ODE often implies stability of (4.8), and in this case we can obtain the bound (4.9) with $K(L,T)$ independent of $T > 0$. Theorem 4.9 is an important special case for applications to optimization.

The Euler approximation for the LTI system in continuous time (2.44), with $f(x) = Ax$, results in the discrete time case (2.42), with $F = (1 + \alpha A)$ with constant-step $\alpha_n \equiv \alpha > 0$).

Consider the case $\frac{d\theta}{dt} = a\theta$, which admits the solution $\theta_t = \theta_0 e^{at}$. The Euler approximation results in a similar-looking solution, as a function of the initial condition:

```
$$\dot{	heta}_{n+1} = F^n \dot{	heta}_0,$quad F = (1 + \alpha).$
```

The approximation $\dot{	heta}_n = \dot{	heta}_0 + O(\alpha)$ follows from the Taylor series approximation for the exponential, $(1 + \alpha n)^n \approx e^{\alpha n} = e^{at}$.

If $a < 0$ and $|a|^{-1}$, the approximation holds on the infinite interval, since both $\dot{	heta}_n$ and $\dot{	heta}_t$ converge to zero geometrically, as $n \to \infty$. This bound on the step-size may be regarded as a special case of more general theory—see Theorem 4.9.
