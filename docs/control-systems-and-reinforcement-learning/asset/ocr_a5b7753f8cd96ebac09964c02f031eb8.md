The interpretation of a Lyapunov function as a weighting function is particularly useful in the definitions that follow. For this, we assume that $V(x) \ge 1$ for each $x$, and denote for $c: X \to \mathbb{R}$,

```
$||c|| = sup_x \frac{|c(x)|}{V(x)}$
```

Let $L_V$, the set of Borel-measurable functions for which this is finite. We say that the Markov chain is $V$-uniformly ergodic if there exists an invariant measure $\pi$, along with $\rho < 1, B < \infty$ for any $c \in L^\infty_V$,

```
$|E_x[c(X(k))]| - \pi(c)| \le B^k ||c||V(x), \quad k \ge 0, x \in X$.
```

Or, in operator-theoretic notation, denoting $\tilde{c} = c - \pi(c)$:

```
$||P^k c||V \le B\rho^k ||c||_V, \quad k \ge 0$.
```

**Theorem 6.13 (Lyapunov Condition for V-Uniform Ergodicity)** Suppose that the Markov chain is $V$-irreducible and aperiodic, and the drift condition holds for function $V: X \to [1, \infty)$; for constants $\varepsilon > 0, b < \infty$, and a small set $S \in \mathcal{B}(X)$.

```
$PV(x) \le (1 - \varepsilon)V(x) + b 1_S(x), \quad x \in X$.
```

Then the Markov chain is $V$-uniformly ergodic.
