**Proposition 2.4** Suppose that (2.33) holds, along with the following assumptions:

- (i) $J$ is continuous, inf-compact, and vanishes only at $x^\sigma$.
- (ii) $J^\sigma$ is continuous.

Then, $J(x) = J^\sigma(x) - J^\sigma(x^\sigma)$ for each $x$.

## 2.4.4 Technical Proofs

To establish Propositions 2.3 and 2.4, we first require Lemma 2.1.

*Proof of Lemma 2.1* We begin with the sample path representation of (2.25):

```
$J(x(k+1)) - J(x(k)) + c(x(k)) = 0. \quad (2.34)
```

Summing each side from $k=0$ to $N-1$ gives for each $x=x(0)$, and each $N$,

```
$J(N) = J(x(N)) + \sum_{k=0}^{N-1} c(x(k)).
```

On taking limits, we obtain

```
$J(x) = \lim_{N\to\infty} \{J(x(N)) + \sum_{k=0}^{N-1} c(x(k))\} = \lim_{N\to\infty} J(x(N)) + J(x),
```

which implies (i) under the assumption that $J(x)$ is finite.
The inf-compact assumption in (ii) is imposed to ensure that the state trajectory evolves in a bounded set: (2.30) implies that $x(k) \in S_J(r)$ for the particular value $r=J(0)$, and each $k \ge 0$. Suppose that $\{x_i; i \ge 0\}$ is a convergent subsequence of the state trajectory, with limit $x^\infty$. Then $J(x^\infty) = \lim_{k\to\infty} J(x(k))$ by continuity of $J$.

The assumption that $J$ vanishes only at $x^\sigma$ implies that $x^\infty = x^\sigma$. Part (ii) follows, because every convergent subsequence reaches the same value $x^\sigma$.

*Proof of Proposition 2.3* The bound (2.32) is established by the previous proceeding the proposition. We begin with the sample path representation of (2.31), similar to (2.34):

```
$V(k+1)) - V(x(k)) + c(x(k)) \le \overline{\eta}. \quad (2.35)
```

Summing each side from $k=0$ to $N-1$ gives (1):

```
$V(N)) - V(x(0)) + \sum_{k=0}^{N-1} c(x(k)) \le \overline{\eta}N$.
```

(ii) follows since $V(x(N)) \ge 0$ for each $N$, so that when $\overline{\eta} = 0$ we obtain from the preceding bound

```
$\sum_{k=0}^{N-1} c(x(k)) \le V(x(0)).$
```

The proof of (iii) is identical to Lemma 2.1: part (ii) implies that $\lim_{k\to\infty} c(x(k)) = 0$, and the assumptions on $c$ then imply that $x(k) \to x^\sigma$ as $k \to \infty$.

## 2.4 Stability and Performance

It remains to show that $x^e$ is stable in the sense of Lyapunov. To see this, first observe that $\eta = 0$, the bound (2.31) implies that $V \geq c$, so that $V$ is also inf-compact. The bound (2.31), and conditions on $c, \eta$, also imply that $V(x(k))$ is strictly decreasing when $x(k) \neq x^e$. Continuity of $V$ implies $V(x(k)) \leq V(x^*)$ for each $x(0)$, so $V(x^e) < V(x(0))$ for all $x(0) \in X$. Stability in the sense of Lyapunov then follows from Proposition 2.2.

Proof of Proposition 2.4 proves with iteration, as in Proposition 2.3:

```
$J^e(x(N)) + \sum_{k=0}^{N-1} c(x(k)) = J^e(x^e).
```

Lemma 2.1 (ii) and continuity of $J$ implies that $J^e(x(\mathcal{N})) \to J^e(x^e)$ as $\mathcal{N} \to \infty$, which implies the desired identity: $J^e(x^e) + J(x) = J(x^e)$.

## 2.4.5 Geometry in Continuous Time

Let's consider an analog of (2.21) in continuous time, with state evolving on $X = \mathbb{R}^n$:

```
$\frac{d}{dt}x_t = f(x_t),
```

where $f: \mathbb{R}^n \to \mathbb{R}^n$ is the vector field. It is common to suppress the time index, writing $\dot{x} = f(x)$.

We $\mathcal{X}(t; x_0)$ denote the solution to (2.36) at time $t$, when we need to emphasize dependency on the initial condition $x_0$. The definition of asymptotic stability of an equilibrium $x^e$ is the same as for the state space model in discrete time (2.21). The equilibrium is globally asymptotically stable if, in:

```
$\lim_{t\to\infty} \mathcal{X}(t; x_0) = x^e$, for all $x_0 \in X$.
```

Verification of global asymptotic stability invites the following assumptions, generalizing the theory in discrete time. Recall that $V: \mathbb{R}^n \to \mathbb{R}$ is continuously differentiable ($C^1$) if the gradient $\nabla V$ exists and is continuous.

### Lyapunov Function for Global Asymptotic Stability
- V is non-valued and concave
- It is inf-compact (recall the definition that (2.28)).
- For any $x$, whenever $x_t \neq x^e$,

```
$\frac{d}{dt}V(x_t) = 0$ if $x_t = x^e$; in this case, $V(x_t+s) = V(x^e)$ for all $s \geq 0$.
```

Figure 2.5 illustrates the meaning of the vector field $f$ for the state case $X = \mathbb{R}^2$, and the figure is intended to emphasize that $V(x_t)$ is nonincreasing when $V$ is a Lyapunov function. The drift condition (2.27) can be expressed in functional form,

```
$(\nabla V(x),f(x)) < 0, \quad x \neq x^e$.
```

**Proposition 2.5** If there exists a Lyapunov function $V$ satisfying the assumptions for global stability, the equilibrium $x^*$ is globally asymptotically stable.

Proposition 2.5 is a partial extension of Proposition 2.3 to the continuous time model. A full extension requires $c: \mathbb{R}^n \to \mathbb{R}_+$ is continuous, $V: \mathbb{R}^n \to \mathbb{R}_+$ is continuously differentiable, and $\eta \geq 0$ is a constant satisfying

```
$(\nabla V(x),f(x)) \leq -c(x) + \eta, \quad x \in X.
```

An application of the chain rule implies that this is continuous time version of (2.31):

```
$\frac{d}{dt}V(x_t) \leq -c(x_t) + \eta, \quad t \geq 0.
```

And with a bit more work, we reach the following conclusions:

**Proposition 2.6** If (2.39) holds for nonnegative $c, \eta$, then

```
$V(x_T) + \int_{0}^{T} c(x_t) dt \leq V(x_0) + T\eta, \quad x_0 \in X, T > 0.
```

If $\eta = 0$, then the total cost is finite:

```
$\int_{0}^{\infty} c(x_t) dt \leq V(x_0), \quad x_0 \in X.
```

## 2.4 Stability and Performance

For any $T > 0$, we obtain by the fundamental theorem of calculus,

```
$-V(x_0) \leq V(x_T) - \int_{0}^{T} \frac{d}{dt}V(x_t) dt \leq T\eta - \int_{0}^{T} c(x_t) dt, \quad T \geq 0.
```

**Converse** We have seen this implication: Existence of Lyapunov function $\implies$ Stability/performance bound. What about a converse? That is, if the system is stable, we can infer a Lyapunov function exists? Assume moreover that the total cost is finite:

```
$J(x) = \int_{0}^{\infty} c(x_t) dt, \quad x_0 = x.
```

with arbitrary initial condition. If $J$ is differentiable, then we obtain a solution to (2.37) using $V = J$;

**Proposition 2.7** If $J$ is finite for each initial condition $x_0$ and each $t$,

```
$\frac{d}{dt}J(x_t) = -c(x_t). \quad (41)
```

If $J$ is continuously differentiable, the Lyapunov bound (2.37) follows with:

```
$\nabla J(x) \cdot f(x) = -c(x).
```

**Proof** We have a simple version of Bessel's principle (focus of Chapter 3): for any $T > 0$ given,

```
$J(x_0) = \int_{0}^{T} c(x_r) dr + J(x_T).
```

For $t \geq 0, \delta > 0$, apply this equation with $T = t + \delta$ and $T = t$;

```
$J(x_0) = \int_{0}^{t+\delta} c(x_r) dr + J(x_{t+\delta}),
```

```
$J(x_0) = \int_{0}^{t} c(x_r) dr + J(x_t).
```

On subtracting, and dividing by $\delta$, this gives

$$
0 \leq \frac{1}{\delta} \int_{t}^{t+\delta} c(x_r) dr + \frac{J(x_{t+\delta}) - J(x_t)}{\delta}.$$$$

Let $\delta \downarrow 0$, the first term converges to $c(x_t)$ because $\mathbb{R}^n \to \mathbb{R}$ is continuous, and the second term converges to the derivative of $J(x_t)$ with respect to time, which establishes (41). The final conclusion follows from the chain rule.

## 2.4.6 Linear State Models

If the dynamics in (2.21) are linear, with $x(k) \in \mathbb{R}^n$, then

```
$x(k+1) = Fx(k), \quad k \geq 0 \quad (42)
```

for an $n \times n$ matrix $F$, and by iteration

```
$x(k) = F^k x, \quad k \geq 0, x(0) = x.
```

This equation is valid for $k=0$ since we take $F^0 = I$, the $n \times n$ identity matrix. Suppose that the cost is also quadratic, $c(x) = x^T S x$, for a symmetric and positive definite matrix $S$. It follows that $c(x(k))$ is a quadratic function of $x(0)$ for each $k$:

```
$c(x(k)) = (F^k x)^T S F^k x.
```

Hence the value function $J$ defined in (2.24) is also quadratic:

```
$J(x) = x^T \sum_{k=0}^{\infty} (F^k)^T S F^k x, \quad x(0) = x \in \mathbb{X}.
```

That is, $J(x) = x^T M x$, where $M$ is the matrix within the brackets. It satisfies a linear fixed point equation, known as the (discrete-time) Lyapunov equation:

```
$M = S + F^T M F. \quad (43)
```

A proof of the following can be obtained based on these calculations:

**Proposition 2.8** The *origin is locally asymptotically stable.* for the linear state space model (42):

- (i) The origin is locally asymptotically stable.
- (ii) The origin is globally asymptotically stable.
- (iii) The Lyapunov equation (43) admits a solution $M \geq 0$ for any $S \geq 0$.
- (iv) Each eigenvalue $\lambda$ of $F$ satisfies $|\lambda| < 1$.

**Controllable Canonical Form.** Recall that this space realization was based on the ARMA model (2,4), with $N=n$. If you have taken a course in signals and systems, you then know that stability of the ARMA model (in an input-output sense called bounded input bounded output [BIBO] stability) is verified by examining the roots $\{p_i : 1 \leq i \leq n\}$ of the rational function

```
$a(z) = 1 + \sum_{i=1}^{n} p_i z^{i-1} = \prod_{i=1}^{n} (1 - p_i z), \quad z \in \mathbb{C}.
```
