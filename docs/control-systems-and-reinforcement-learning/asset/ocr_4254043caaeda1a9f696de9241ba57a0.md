# 9.9.2 TD Stability Theory

Bounds on the eigenvalues of $A$ for on-policy $TD(\\lambda)$ are established by careful consideration of the autocorrelation sequence (9.223). This can be expressed

```
$R(j) = \Sigma(j) + \psi\psi^{\top}, \quad j \in \mathbb{Z}_+$,
```

where $\widetilde{\psi} = E_{\pi}[\psi(X(N))]$, and letting $\widetilde{\psi} = \psi - \widetilde{\psi}$,

```
$\Sigma(j) = E_{\pi}[\widetilde{\psi}(X(n+j))\widetilde{\psi}(X(n))^{\top}].
```

Eigenvalue bounds are obtained in terms of the scalars

```
$\varrho = \gamma \frac{1-\\lambda}{1-\gamma\lambda} \varrho, \quad \varrho = \max_{i \in \mathbb{Z}, y \in \mathbb{C}} \frac{|y^{\top}R(i)|}{y^{\top}y}$,
```

where $y^{\top}$ denotes complex conjugate, $R^{\top}=R(0)$, and the maximum excludes $y=0$.

**Lemma 9.28** We have $\varrho \le 1$ and $\varrho_{\gamma} \le \varrho$. If $\Sigma^{\psi} > 0$ and $\Phi$ is aperiodic, then $\varrho < 1$.

Proof It is obvious that $\varrho_{\gamma} \le \varrho$ whenever $\lambda \le \1$. For any nonzero $y \in \mathbb{C}$,

```
$|y^{\top}R(i)| = |E_{\pi}[\psi(X(n+i))\psi(X(n))y^{\top}]]\n\le \sqrt{E_{\pi}[|y^{\top}\psi(X(n+i))|^2]} \sqrt{E_{\pi}[|\psi(X(n))^{\top}|^2]}.
```

The right-hand side is precisely $E_{\pi}[|\psi(X(n))y^{\top}|^2] = y^{\top}Ry$, from which we conclude that $\varrho \le 1$.
