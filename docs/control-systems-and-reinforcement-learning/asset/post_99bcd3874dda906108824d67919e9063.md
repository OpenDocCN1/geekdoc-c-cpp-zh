## Value Function Approximations

We have now all the preliminaries necessary to describe reinforcement learning algorithms designed for value functions denoted $\mathcal{H}$.

The approximation techniques are built around a family of functions, Standard examples discussed in Section 5.1 include neural networks and kernels, as well as linear approximation using a basis (an example of this can be found in Section 4.5.3). In most cases, the function class is finite dimensional, with dimension $d$. For example, to approximate the $Q$-function $Q^*$ defined in (3.7a), the family is denoted $\{Q^\theta : \theta \in \mathbb{R}^d\}$.

Most algorithms are based on optimization: An algorithm to compute the optimal parameter $\theta^*$ will be based on some loss function $\Gamma(\theta)$, with $\theta^* = \arg min \Gamma(\theta)$. The algorithm may be recursive, in which it generates a sequence of parameter $\{\theta_n\}$, so that $\theta_n \to \theta^*$ as $n \to \infty$. It should come as no surprise that Chapter 4 will guide algorithm design.

Reinforcement learning algorithms are typically designed to be model-free, with the inputs to the algorithm consist of three terms: $\{u(k)\}$ the input sequence to the control system, the sequence of observed costs $c(x(k),u(k))$, and observed features that depend on the class of algorithms. For the linear parameterization $Q^\theta(x,u) = \sum \theta_i \psi_i(x,u)$, the features is the $d$-dimensional sequence $\{\psi(x(k))\}$.

## 5.1 Function Architectures

This section might be viewed as a brief course on machine learning. The goal is to approximate a function $H^*: Z \to \mathbb{R}$, where interpretation of $H^*$ and the definition of the set of points $Z$ depend on context. This is regarded as a learning problem when the data is gathered from experiments: for example, $H^*$ might be the Q-function defined in (3.7a), and $Z = X \times U$. The techniques described here for function approximation require a few ingredients:

- (i) *A function class $\mathcal{H}$.* Three examples are described in this chapter: a $d$-dimensional linear function class, $d$-dimensional nonlinear function class defined by a neural network, and one-dimensional class: the reproducing Hilbert space (RKHS).
- (ii) For each $h \in \mathcal{H}$, we associate a “loss” denoted $\Gamma(h)$. The loss is designed so that $\Gamma(h)$ is small when $h = H^*$; our approximation is loose if $\Gamma(h)$ is large. We use just one requirement on this loss: assumed are samples $\{z_i : 1 \leq i \leq N\} \subset Z$, and, rather than thinking the domain of $\Gamma$ as the abstract collection $\mathcal{H}$, it is a mapping $\Gamma: \mathbb{R}^N \to \mathbb{R}$,

```
$\Gamma(h) = \Gamma(z_1), \dots, \Gamma(z_N). \quad (5.2)$
```

- (iii) An algorithm to obtain the minimizer of $\Gamma(h)$ over $h \in \mathcal{H}$. This book is filled with techniques for constructing algorithms, and techniques to obtain insight on their rate of convergence.

## 5.1 Function Approximation

The objective $\Gamma$ in (5.2) is known as the *empirical risk*, and its minimization over a function class $\mathcal{H}$ is known as *empirical risk minimization* (ERM). We begin with two examples of loss functions, and three examples of the function class $\mathcal{H}$.

### 5.1.1 Function Approximation Based on Training Data

#### Curve Fitting

Suppose that we have noisy observations of a function $H^* : \mathbb{R} \to \mathbb{R}$:

```
$$y_i = H^*(z_i) + d_i,$$
```

where the noise $\{d_i\}$ is not too large and has statistical properties (for example, its average is close to zero). The sequence $\{(z_i, y_i) : 1 \le i \le N\}$ is *training data*. The quadratic loss function is defined by

```
$$\Gamma(h) = \frac{1}{N} \sum_{i=1}^N |y_i - h(z_i)|^2, \quad h \in \mathcal{H}. \quad (5.3)$$
```

If $\Gamma(h^*) = 0$, then the function exactly matches the observations: $h^*(z_i) = y_i$, for each $i$. This looks like good news in the disturbance-free setting ($d_i = 0$), so that $h^*(z_i) = H^*(z_i)$ for each $i$.

Figure 5 shows function approximation outcomes from three different algorithms: One algorithm constructs the function $h$ based on the training samples $\{(z_i, y_i\}$. The first illustrates typical results when we put too much data in the truth: We achieved $\Gamma(h) = 0$, which should be good news. However, it is unlikely that the true function exhibits many peaks and valleys—this behavior is more likely the product of a bad algorithm. The term *overfitting* is used to describe this undesirable behavior when $\Gamma(h) \approx 0$. A good algorithm produces the smooth approximation shown in the middle. This is achieved using a regularizer. With too much regularization, you obtain a poor approximation, as shown on the right.

The preference for the middle plot in Figure 5.2 is based on a *smoothness prior* for the underlying data; that is, a substitute for the probabilistic priors in Bayesian statistics.
