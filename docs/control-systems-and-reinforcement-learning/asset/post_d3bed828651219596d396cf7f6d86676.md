## Empirical Distributions

In RL literature, you will find the term experience buffer used in training data, and from this empirical distribution (or empirical $pmf$) generated from these data:

```
$\omega^N(x,u,x^+) = \sum_{k=0}^{N-1} \mathbb{1}\{x(k) = x, u(k) = u, x(k+1) = x^+\}, \quad x^+ \in X, u \in U. \quad 5.6$
```

This is a pmf on $X \times U$ for any sequence $\{x(k), u(k)\}$ and any $N \ge 1$. Simple accounting leads to the following alternative expression for (5.5a):

```
$\Gamma(h) = \sum_{x,u,x^+} \omega^N(x,u,x^+) \{-h(x,u) + c(x,u) + h(x^+)\}, \quad 5.7$
```

where the sum is over all $(x,u,x^+) \in X \times U \times X$ for $\omega^N(x,x^+) > 0$. This interpretation of $\Gamma(h)$ as an $empirical$ mean is useful for both intuition and theory (such as the LP approach to RL) is surveyed over the final sections of this chapter.

### 5.1.2 Linear Function Approximation

This refers to a family of functions, linearly parameterized by $\theta \in \mathbb{R}^d$.

```
$h^0(z) = \sum_{i=1}^d \psi_i(z), \quad z \in Z, \quad 5.8$
```

where $\{\psi_i\}$ are the basis functions. It is convenient to stack these together to form a function $\psi: Z \to \mathbb{R}^d$, and then write $h^0 = \theta^T\psi$. For any smooth loss function, the first-order condition for optimality is $0 = \nabla\theta\Gamma(h\theta)$ (5.5a), this becomes

```
$0 = \sum_{k=1}^{N} D_k(h^0(z_k),h^0(z_{k+1}))\zeta^0(k) \quad (5.9)$
```

where $\zeta^0(k) = \nabla_z D_k(h^0(z_k),h^0(z_{k+1}))$.

The choice of basis can be informed by some understanding of the control problem. For example, if $Z=\mathbb{R}^2$ and it is known that $H^0$ is convex, then it may be sufficient to choose $h^0$ quadratic, with $d=6$:

$\psi_1(z) = z_1, \psi_2(z) = z_2, \psi_3(z) = z_1^2, \psi_4(z) = z_1z_2, \psi_5(z) = z_2^2$, and $\psi_6(z) = 1$ for all $z \in \mathbb{R}^2$.

## Tabular and Binning

A common choice in theory of RL is the tabular method in which $z$ denotes a typical pair $(x,u)$. It is assumed that $X$ and $U$ are finite, and an ordering is chosen: $X \times U = \{z^i = (x^i,u^i) : 1 \leq i \leq d\}$, where $d$ is the total number of state-disjoint pairs. The tabular basis is based on the family of indicators

```
$\psi_i(x,u) = \mathbb{1}\{(x,u)=(x^i,u^i)\}, \quad (x,u) \in X \times U, 1 \leq i \leq d. \quad (5.10)$
```

If $Z=X \times U$ is not finite, then we can apply binning. Recall from Section 3.9 how binning was applied to approximate the model through "quantizing" the state, and computing the optimal policy for the model. In RL, we do not approximate the model, but we can perform through extension of tabular basis. A basic decomposition $Z = \sum_{i=1}^d B_i$, the $i$-th basis is the indicator

```
$\psi_i(x,u) = \mathbb{1}\{(x,u) \in B_i\}, \quad (x,u) \in X \times U, 1 \leq i \leq d. \quad (5.11)$
```

Exercise 9.3 is designed to show how this is a good choice in RL, in the sense that it leads to a consistent algorithm for value function approximation.

## Galerkin Relaxation

The term Galerkin relaxation appears throughout the book as a method to approximate equality constraints, and sometimes inequality constraints. As an example of this technique, consider again the loss (5.5) associated with mean-square error. An analytical approximation of DP is obtained by choosing a $d$-dimensional sequence $\{\zeta(k)\}$, and search for a function $h$ that satisfies:

```
$0 = \sum_{k=1}^{N} D_k(h(z_k),h(z_{k+1}))\zeta(k), \quad i \leq d. \quad (5.12)$
```

This is called Galerkin relaxation, and potentially to find a function $h$ for which temporal difference $D_k(h(z_k),h(z_{k+1}))$ is zero for each $k$. In the context of RL, the vectors $\{\zeta(k)\}$ appear as eligibility vectors. For a finite-dimensional function class, we set $d=d$, so that (5.12) represents $d$ unknowns, $\{\theta_i : 1 \leq i \leq d\}$.

Equation (5.12) appears similar to (5.9). However, $\zeta(k) = \theta$ is not a valid since Galerkin relaxation does not allow $\zeta(k)$ to depend on $\theta$. In practice, we might design $\zeta(k)$ so that $\zeta(k) \approx \theta$ in a region of interest. We are not fortunate to have intuition regarding the shape of $H^*$, and binning may be too complex.

### 5.1.3 Neural Networks

Neural networks can be used to define a parameterized family of approximations $\{h^\theta\}$ that are highly nonlinear in $\theta$. The purpose of this brief introduction is to explain how a neural network can be used for function approximation, especially for value approximation.

Figure 5.3 shows an example of a feedforward neural network with a single input layer, three hidden layers (bias terms are not included). For our purposes, this figure represents a function approximation $h: \mathbb{R}^3 \to \mathbb{R}$, so the input layer is $z = (z_1, z_2, z_3)^T$.

This is called a feedforward neural network because calculation of $y$ as a function of $z$ is performed sequentially, moving from left to right. For weight vectors $\{w_k^l\}$ (whose dimensions will be clear from the definitions), the calculations proceed as follows:

```
$s_k^1 = \sigma(\langle w_k^1, z \rangle), \quad 1 \le k \le 4$
```

where the notation $(\langle w_k^l, z \rangle)$ represents the dot product of two vectors, and $\sigma: \mathbb{R} \to \mathbb{R}$ is known as the activation function. We have two standard choices:

```
Sigmoid: $\sigma(r) = 1/(1+e^{-r}), \quad ReLU: $\sigma(r) = \max(0,r)$
```

Calculation of $s^2, s^3 \in \mathbb{R}^4$ is similar:

```
$s_k^2 = \sigma(\langle w_k^2, s^1 \rangle), \quad s_k^3 = \sigma(\langle w_k^3, s^2 \rangle), \quad 1 \le k \le 4$.
```

The output is defined by $y = h(s^2, s^3)$, which is a linear function of the third layer, but a complex nonlinear function of the input $z$. The weights are identified with the parameter $\theta$: we write $y = h^\theta(z)$, with

```
\{\theta_i : 1 \le i \le d\} = \{w_k^l \quad d = 3 \times 4 \times 4 \times 4 \times 4 \times 4 \times 4 = 48\}.
```

### 5.1.4 Kernels

Let’s start at the conclusion: When applying kernel methods, our approximation of $H^*$ takes the form:

```
$h^0(z) = \sum_{i=1}^N \alpha_i \mathbf{k}(z, z_i), \quad z \in Z, \quad (5.13)$
```

where $k$ is the kernel function that we choose from a large library.

You might argue that this is a simple linear function approximation approach described earlier, with $d=N$ and $\psi_i(z) = \mathbf{k}(z, z_i)$ for each $i$ and $z$. Your argument is absolutely correct! To appreciate the kernel method, you need to see how we arrive at this particular form for $h^0$. We return to the "beginning," which is the choice of kernel.

## Choice of Kernel, and Requirements

Three standard examples are

- Gaussian: $\mathbf{k}(z, z') = \exp\left(-\frac{\|z-z'\|^2}{2\sigma^2}\right)$
- Laplacian: $\mathbf{k}(z, z') = \exp\left(-\frac{\|z-z'\|}{\sigma}\right)$
- Polynomial: $\mathbf{k}(z, z') = (r(z, z') + 1)^m, \quad z, z' \in Z$.

$\sigma > 0, r > 0$ and $m \ge 1$ are design parameters. Recall that in some applications we may know that $H^*$ is convex and nonnegative. In this case, the polynomial kernel is attractive because $h^\theta$ in (5.13) is convex if $m$ is even.

Each of these three examples has the symmetry property, $k(x, y) = k(y, x)$. This is one of several required properties of a kernel. A crucial requirement is that it is *positive definite*: For every $n \ge 1$, every collection $\{z_i : 1 \le i \le n\} \subset Z$, and every $\alpha \in \mathbb{R}^n$,

```
$$\sum_{i,j=1}^n \alpha_i \alpha_j \mathbf{k}(z_i, z_j) \ge 0, \quad (5.14)$
```

with equality and only if $\alpha = 0$.

## Function Class for Approximation

Once have selected a kernel, we arrive at a function class $\mathcal{H}$: an infinite-dimensional analog of the functions $\{\mathcal{H}^0 : \theta \in \mathbb{R}^d\}$ defined in (5.8). There is no space in this book to give a full definition of $\mathcal{H}$, and the norm $\|\cdot\|_{\mathcal{H}}$ is a critical part of the theory.

For our purposes, it is enough to know that $\mathcal{H}$ contains every function of the form (5.13). That is, for any integer $n$, scalars $\{\alpha_i\}$, and $\{z_i\} \subset Z$, the following function lies in $\mathcal{H}$:

```
$h^\alpha(z) = \sum_{i=1}^n \alpha_i \mathbf{k}(z, z_i), \quad z \in Z$.
```
