Initialize $	heta_0 \in \mathbb{R}^d, A_0 \in \mathbb{R}^{d 	imes d}, \epsilon > 0$. Update for $n \geq 0$:

```
$$\bar{A}_{n+1} = \bar{A}_n + \beta_n[\bar{A}_{n+1} - \bar{A}_n], \quad \bar{	heta}_{n+1} = \bar{	heta}_n + \alpha_n \partial f_n(\ar{	heta}_n), \quad \theta_{n+1} = \theta_n + \alpha_n G_n f_n(\\theta_n), \quad G_{n+1} = -[I + \bar{A}_{n+1}^	op \bar{A}_{n+1}]^{-1} \bar{A}_{n+1}^	op. \quad (8.51a) (8.51b)$$$
```

The two step-size sequences $\{\alpha_n\}$ and $\{\beta_n\}$ satisfy (8.22):

```
$$\lim_{n \to \infty} \frac{\beta_n}{\alpha_n} = \infty.$$$
```

Under the "high-gain" assumption (8.22), we expect that $\bar{A}_{n+1}$ is a reasonable estimate of $A(\	heta_n)$ for large $n$, with $A(\	heta_n)$ defined in (8.13). This intuition is supported by the general theory of two-scale SA, summarized in Section 8.2.4. In particular, the high-gain assumption for (8.51a) tells us that we can expect $A_n \approx A(\	heta_n)$ after a transient period. The ODE approximation for $\{\theta_n\}$ is precisely the regularized Newton-Raphson flow.

# 8.5.2 Zap Zero Zero

In most of the algorithms considered in later chapters, the matrix $A_{n+1}$ appearing in (8.51a) is of low rank. For the special case $\epsilon=0$, the matrix update for $G_n$ is efficiently computed using the Matrix Inversion Lemma (A.1). This is particularly simple when the rank of $A_{n+1}$ is equal to one, and defined in factored form $A_{n+1} = W_{n+1}V_{n+1}$ with $W_{n+1}$ and $V_{n+1}$ column vectors. Then, (A.1) gives the following update equation:

```
$$\G_{n+1} = [G_n^{-1} - A_{n+1}] = G_n - \frac{1}{1-V_{n+1}^	op G_nW_{n+1}}G_nW_{n+1}V_{n+1}^	op G_n.$$$
```

The right-hand side involves the two matrix-vector products, $G_nW_{n+1}$ and $V_{n+1}^	op G_n$, which introduces complexity of order $O(d^2)$.

An update of complexity $O(d)$ (and even $O(1)$) is possible under stronger conditions.
