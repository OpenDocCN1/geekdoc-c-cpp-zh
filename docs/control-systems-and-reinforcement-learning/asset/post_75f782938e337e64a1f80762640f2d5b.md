Under our assumption that $c$ is nonnegative, the value function is also nonnegative. The following are minimal assumptions to ensure that $J^*$ is finite:

- (i) There is a target state $x^e$ that is an equilibrium for some $u^e$:

```
$F(x^e, u^e) = x^e$.
```

- (ii) The cost function $c$ is nonnegative and vanishes at equilibrium, $c(x^e, u^e) = 0$,

- (iii) For any initial condition $x_0$, there is an input sequence $u_0$ and a time $T^0$ such that with this initial condition and input we have $J^*(x_0) = T^0$.

Condition (iii) is a weak form of controllability. Under these three assumptions, it follows that $J^*(x) < \infty$ for each $x$.

**Example 3.1.1 (Linear Quadratic Regulator)** The Linear Quadratic Regulator problem refers to the class of linear dynamics (2.13), with quadratic cost:

```

```

It is always assumed that $S \geq 0$ (positive semidefinite) and $R > 0$ (positive definite). There is one policy for which $J^*$ is finite, the value function is quadratic: $J^*(x) = x^T M^* x$, the optimal policy is obtained by linear state feedback: $\phi^*(x) = -K^*x$ for a matrix $K^*$ of $M^*$. ## 3.2 Bellman Equation

Let $x = x(0)$ be an arbitrary initial state, and let $k_m$ be an intermediate time, $0 < k_m < \infty$. We regard $J^*(x(k_m))$ as the cost to go at time $k_m$. This is the total cost over the remaining lifetime of the optimal input-output trajectory.

Based on this interpretation, we obtain following:

```
$J^*(x) = \min_{u_{[0, \infty)}} \left[ \sum_{k=0}^{k_m-1} c(x(k), u(k)) + \sum_{k=k_m}^{\infty} c(x(k), u(k)) \right]
= \min_{u_{[0, k_m]}} \left[ \sum_{k=0}^{k_m-1} c(x(k), u(k)) + \min_{u_{(k_m, \infty)}} \left(\sum c(x(k), u(k))\right)\ \right]
^*(x(k_m))$
```

```
$J^*(x) = \min_{u_{k_m-1}} \sum c(x(k),u(k)) + J^*(x(k_m))$. (3.4)
```

As a consequence, the optimal control over the interval has the property illustrated in Figure 3.1: If the optimal trajectory follows the state $x_m$ at time $x(k_m)$ using the control $u^*=u_{(0, \infty)}$, then the control $u^*_{k_m}$ must be optimal for the system starting at $x_m$ at time $k_m$. If a better $u^*$ existed on $[k_m, \infty)$, we would have chosen it. This concept is called the *principle of optimality*.
Analysis in continuous time proceeds by letting $k_m \downarrow 0$ to obtain a partial differential equation. The theory is far simpler in discrete time: Set $k_m=1$ to obtain the following celebrated result.

**Theorem 3.1** Suppose that the value function $J^*$ is finite valued, and an optimal input $u^*$ solving (3.2) exists. Then the value function satisfies

```
$J^*(x) = \min \{c(x,u) + J^*(F(x,u))\}$. (3.5)
```

Suppose that the minimum in (3.5) is unique for each $x$, and let $\phi^*(x)$ denote the minimum. The optimal input is expressed as state feedback.

```
$u^*(k) = \phi^*(x^*(k))$. (3.6)
```

Equation (3.5) is often interpreted as a *fixed point equation* in the unknown $J^*$. It goes by the name *Bellman equation* or dynamic programming (DP) equation: the terms are used interchangeably in this book.

**Q-Function.** The function of two variables within the minimum in (3.5) is the *Q-function* of reinforcement learning:

```
$Q^*(x,u) \overset{\text{def}}= c(x,u) + J^*(F(x,u))$. (3.7a)
The Bellman equation is expressed
$J^*(x) = \min_u Q^*(x,u)$ (3.7b)
and the optimal feedback law expressed as follows:
$\Phi^*(x) \in \arg \min_u Q^*(x,u), \quad x \in X$. (3.7c)

The Q-function solves the point equation,

```
$Q^*(x,u) = c(x,u) + Q^*(F(x,u)), \quad x \in X, u \in U, \quad (3.7d)
```

$Q(x) \stackrel{\text{def}}= \min_u Q(x,u), x \in X,$ for any function $Q$.

Equation (3.7d) is obtained by eliminating $J^*$ in (3.7a) via (3.7b). Applications of this dynamic programming equation appear throughout the book, starting in Section 3.7. The term dynamic programming also refers to recursive algorithms designed to obtain the solution to Bellman equation.

### 3.2.1 Value Iteration

Given an initial approximation $V^0$ for $V^*$ appearing in (3.5), a sequence of approximations is defined recursively

```
$V^{n+1}(x) = \min_u\{c(x,u) + V^n(F(x,u))\}, \quad x \in X, n \ge 0. (3.8)
```

Recursions like this to fixed point equations are generally known as successive approximation. Exercise 3.5, you will establish the following interpretation:

```
$V^{n+1}(x) = \min_{u(0,n)} \sum_{k=0}^n c(x(k), u(k)) + V^0(x(n+1)), \quad x(0) = x \in X. (3.9)
```

The recursion (3.8) is known as the value iteration algorithm (VIA). It is convergent under very general conditions: for each $x$,

```
$\lim_{n\to\infty} [V^n(x) - V^n(x^e)] = J^*(x^e).
```

Here is the simplest result of kind:

**Proposition 3.2** Consider the VIA under the following assumptions:

- (i) The state space $X$ and input space $U$ are finite.
- (ii) The cost function $c$ is nonnegative and vanishes only at $(x^e, u^e)$, and $J^*$ is finite valued.
- (iii) The initialization $V^0$ is chosen with nonnegative entries, and $V^0(x^e) = 0$.

Then there is $n0 \ge 1$ such that

```
$V^n(x) = J^*(x), \quad x \in X, n \ge n_0.
```

Proof Let $\phi^*$ be an optimal policy, and let $n_0 \ge 1$ denote a value such that $(x^*(k),u^*(k)) = (x^e, u^e)$ for $k \ge n_0$. An integer exists because $J^*$ is finite valued.

We have from (3.9),

$V^n(x) = \sum_{k=0}^{n-1} c(x(k), u(k)) + V^0(x(n)), \quad u(k) = \phi^*(x(k)) \text{ for each } k, \quad x(0) = x \in X$.

The right-hand side is precisely $J^*(x) = V^0(x^n) = J^*(x) \text{ for } n \ge n_0.$ And for each $n$, the inequality is not equality due to (3.9) and property of $\phi^*$.

The VIA generates a sequence of policies, defined as minimizers in (3.8). For each $n \ge 0$,

$$\Phi^n(x) = \arg \min_u \{c(x, u) + V^n(F(x, u))\}, \quad x \in \text{X}, \quad (3.10)$$

Each of these policies is stabilizing, subject to an assumption on the initial value function: The function $V^0$ is non-negative, and satisfies for some $\bar{\gamma} \ge 0$,

$$\min\{c(x, u) + V^0(F(x, u))\} \le V^0(x) + \bar{\gamma}, \quad x \in \text{X}. \quad (3.11)$$

This can be interpreted as a version of Poisson's inequality (2.31) for the system controlled using the policy $\phi^0$,

$V^0(F(x, \phi^0(x))) \le V^0(x) - c(x, \phi^0(x)) + \bar{\gamma}.$

**Proposition 3** *Suppose that (3.11) holds, with $V^0$ non-negative. That is,

$\{c(x, u) + V^0(F(x, u))\}_{u=\phi^0(x)} \le V^0(x) + \bar{\gamma}, \quad x \in \text{X}.$

Then a lower bound holds for each $n$:

$\{c(x, u) + V^n(F(x, u))\}_{u=\phi^n(x)} \le V^n(x) + \bar{\gamma}_n, \quad x \in \text{X},$

where the upper bounds are non-negative and nonincreasing:

$\bar{\gamma}_0 \ge \bar{\gamma}_1 \ge \dots$

The conclusions of Proposition 3 are most interesting when $\bar{\gamma} = 0$ so that, for each $n$,

$\{c(x, u) + V^n(F(x, u))\}_{u=\phi^n(x)} \le V^n(x).$

The following bound follows from Proposition 2.3:

$J^n(x) \le V^n(x), \quad x \in \text{X},$

where $J^n$ is the total cost using policy $\phi^n$.
