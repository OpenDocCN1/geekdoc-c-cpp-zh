# 4.5 Quasistochastic Approximation

Without a linear parameterization, we turn to gradient descent to minimize $\Gamma$, with gradient

```
$$\Gamma(\theta) = \lim_{T\to\infty} \frac{1}{T} \int_0^T [\mathcal{B}^	heta(x_t, u_t)] \nabla_\theta \mathcal{B}^	heta(x_t, u_t) dt$$
```

The first-order condition for optimality is expressed as the root-problem $\nabla_\theta \Gamma(\theta) = 0$, and the standard gradient descent algorithm in ODE form is

```
$$\frac{d}{dt}\theta_t = -\nabla_\theta \Gamma(\theta_t)$.$
```

Its QSA counterpart (4.44) is

```
$$\frac{d}{dt}\theta_t = -a_t\mathcal{B}^	heta(x_t, u_t) + c_t\zeta_t^Q$, (4.62a)
```

```
$$\zeta_t^Q \equiv \nabla_\theta \mathcal{B}^	heta(x_t, u_t) = -\nabla_\theta Q^Q(x_t, u_t) + \{\nabla Q^Q(x_t, \phi(x_t)) + \nablaphiphi Q^Q(x_t \phi(x_t))\}$, (4.62b)
```

where (4.62b) follows from (4.58), and can be provided to justify the exchange of differentiation with respect to time and with respect to $\theta$.

The QSA gradient descent algorithm (4.62) is best viewed by a nonlinear function approximation, but it is instructive to show how the ODE simplifies for the linearly parameterized (3.43). We have in this case

```
$$\zeta_t = -\psi(x_t, u_t) + c(x_t, \phi(x_t)) + \frac{1}{t}\psi(x_t, \phi(x_t))$$$$
```

and $\mathcal{B}^	heta(x_t, u_t) = c_t + \zeta_t^	heta$ using $c_t$ so that (4.62) becomes

```
$$\frac{d}{dt}\theta_t = -a_t[\zeta_t\Gamma \theta_t + c_t\zeta_t].$$ (4.63)
```

The convergence of (4.62) may be very slow if the matrix

```
$$\mathcal{R}^C = \lim_{t\to\infty} \frac{1}{t} \int_0^t \zeta_\tau^C d\tau$$ (4.64)
```

has eigenvalues close to zero. This can be resolved through the introduction of a larger gain $\alpha$, or a matrix gain. One approach is to estimate $\mathcal{R}^C$ from data and invert: $G_t = [\mathcal{R}^C]^{-1}$ with

```
$$\tilde{R}_t^C = \frac{1}{t+1}[\mathcal{B}_0^	heta + \int_0^t \zeta_\tau^C d\tau], \quad \tilde{R}_0 > 0$ (4.65a)
```

```
$$\frac{d}{dt}\theta_t = -a_t G_t[\zeta_t\Gamma \theta_t + c_t\zeta_t], \quad t \ge 0.$ (4.65b)
```

# Numerical Example

Consider the LQR problem in which $\dot{x} = Ax + Bu$, and $c(x,u) = x^T S x + u^T Ru$, with $S \ge 0$ and $R > 0$. The fixed-policy $Q$-function associated with any stable linear policy $\phi(x) = -Kx$, takes the form

```
$$\Q^\Phi(x,u) = \left[ \begin{matrix} S & 0 \ 0 & R \end{matrix} \right]^T \left[ \begin{matrix} A^TM + MA + MB \ B^T M & 0 \end{matrix} \right] [x \ u]$$$
```

where $M$ solves the Lyapunov equation (2.46) with $S$ replaced by $K^T RK + S$:

```
$A^TM + MA + K^T RK + S = 0.$
```
