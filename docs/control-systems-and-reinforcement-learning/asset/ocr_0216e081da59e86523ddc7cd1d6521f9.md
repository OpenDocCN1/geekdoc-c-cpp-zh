Proof of Proposition 4.27 Taking derivatives of each side of (4.72), by the product rule,

```
$$\frac{dZ_t}{dt} = \frac{d}{dt}\left(\frac{1}{a_t}(\Theta_t - \overline{\Theta}_t)\right)\\\\left(-\frac{1}{a_t}\frac{d}{dt}a_t\right)(\Theta_t - \overline{\Theta}_t) + f(\Theta_t, \Xi_t) - f(\overline{\Theta}_t)\\= r_t Z_t + f(\Theta_t, \Xi_t) - \tilde{f}(\overline{\Theta}_t)$
```

where in the final equation we use the chain rule for the derivative of a logarithm (recall $r_t = -\frac{d}{dt}\log(a_t)$ and the definition of $Z_t$).
Adding and subtracting $f(\overline{\Theta}_t)$, we arrive at a suggestive decomposition:

```
$$\frac{dZ_t}{dt} = r_t Z_t + [f(\overline{\Theta}_t) - f(\overline{\Theta}_t)] + [f(\Theta_t, \Xi_t) - f(\overline{\Theta}_t)]$$
```

$\Xi_t$: bounded disturbance

```
$R_t = A(\overline{\Theta}_t)[\Theta_t - \overline{\Theta}_t] + \epsilon_t$,
```
