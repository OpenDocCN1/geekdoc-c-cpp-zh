# Linearization about an Equilibrium State

The linearization is defined exactly as the frictionless pendulum (2.49). Assume that the signals $x_1, x_2$, and $u$ remain close to the fixed point $(x_1^o, x_2^o, u^o)$, and write

```
$x_1 = x_1^o + \tilde{x}_1,\nx_2 = x_2^o + \tilde{x}_2,\nu u = u^o + \tilde{u}$.
```

where $\tilde{x}_1, \tilde{x}_2$, and $\tilde{u}$ are small-amplitude signals. From the state equations (2.60), we then have

```
$\frac{d}{dt}\tilde{x}_1 = x_2^o + \tilde{x}_2,\n$\frac{d}{dt}\tilde{x}_2 = f_2(x_1^o + \tilde{x}_1, x_2^o + \tilde{x}_2, u^o + \tilde{u})$.
```

Applying a first-order Taylor series expansion to the right-hand side of the second equation gives
