# 102 ODE Methods for Algorithm Design

The goal is to estimate $	heta^* \in \mathbb{R}^d$ based on input–output measurements, where this “best parameter” corresponds to a model that reflects input–output observations.

In the prediction error method, we introduce a loss function $\Gamma: \mathbb{R}^d 	o \mathbb{R}$, defined by

```
$$\Gamma(\theta) = \frac{1}{T} \int_0^T \ell(y_t - y_t^	heta)dt.$
```

in which $y_t$ is observed at time $t$, and $y_t^	heta$ is obtained from the model with identical input $\mathbf{u}$, and initial state $x_0^	heta = x_0$. The function $\ell: \mathbb{R} \to \mathbb{R}$ satisfies $\ell(0) = 0$ and $\ell(z) > 0$ for $z \neq 0$.

Consider the typical quadratic loss, $\ell(z) = z^2$. We might apply gradient descent to find the minimizer $\theta^*$ of $\Gamma$, where the gradient is expressed

```
$$\nabla_{	heta}\Gamma(\theta) = \frac{1}{T} \int_0^T \nabla_{	heta}\ell(y_t - y_t^	heta)dt\n=-\frac{2}{T} \int_0^T (y_t - y_t^	heta)\nabla_{	heta}y_t dt.$
```

We are faced with finding a model for the gradient of the observations.
We might design the model so that this is an easy task:

```
$y_t^	heta = \theta^T\phi_t,$
```

where the regression vector $\phi_t \in \mathbb{R}^d$ is a function of observations and not the model. Hence the gradient is expressed in terms of observations, $\nabla_{	heta}y_t^	heta = \phi_t$, and the gradient of the loss function is linear: $\frac{1}{2}\nabla_{	heta}\Gamma(\theta) = M\theta - b$,

```
$M = \frac{1}{T} \int_0^T \phi_t\phi_t^T dt \quad \text{and} \quad b = \frac{1}{T} \int_0^T y_t\phi_t dt.$
```

These representations are one motivation for ARMA models (see Section 2.2 for a definition in discrete time).

In the absence of such a simple description, we look more closely at the state space model. Assume $x_t^	heta$ and $y_t^	heta$ are continuously differentiable in $(t,\theta)$. Let $S_t^	heta = \partial_{\theta}x_t^	heta$ denote the $n \times d$ matrix of partial derivatives of:

```
$[S_t^	heta]_{i,k} = \frac{\partial}{\partial\theta_k}x_t^	heta(i), \quad 1 \leq i \leq n, \quad 1 \leq k \leq d.$
```

Recalling the calculus identity $\nabla_{	heta}y_t^	heta = |\partial_{	heta}y_t^	heta|$, we obtain by chain rule

```
$$\frac{d}{dt}S_t^	heta = f_x(x_t^	heta,u;theta)S_t^	heta + f_{	heta}(x_t^	heta,u;theta);\n\partial_{	heta}y_t^	heta = g_x(x_t^	heta,u;theta)S_t^	heta + g_{	heta}(x_t^	heta,u;theta);$
```

```
$[f_x(x,u;\theta)]_{i,j} = \frac{\partial}{\partial x_j}f_i(x,u;\theta).$
```
