# 8.3 Examples

Markov chain Monte car (MCMC) techniques include methods to construct a Markov chain Φ whose steady-state distribution has density equal to the target density p [12, 115]. Computation of the mean θ* is in an SA problem:

```
$0 = f(\theta^*) = E[f(\theta^*, \Phi)] = E[c(\Phi) - \theta^*].$
```

Consider the SA recursion (8.2) in which $\alpha_n = g/n$, with $g>0:

```
$\theta_{n+1} = \theta_n + \frac{g}{n+1}[c(\Phi(n+1)) - \theta_n], \quad n \geq 0. \quad (8.36)
```

This recursion and the ODE are linked:

```
$$\frac{d}{dt}\theta = -g[\theta - \theta^*].$
```

This ODE is globally asymptotically stable for any $g>0$. The case $g=1$ is very special:

**Proposition 8.5** For the special case $g=1$, the estimates obtained from (8.36) can be expressed as the sample path average:

```
$\theta_n = \frac{1}{n}\sum_{k=1}^n c(\Phi(k)). \quad (8.37)
```

This representation holds regardless of the initial condition $	heta_0$.

*Proof* Multiplying each side of (8.36) by $(n+1)$ results in a recursive representation of the scaled sequence $\{S_k = k\theta_k : k \geq 0\}$:

```
$S_{n+1} = (n+1)\theta_n + [c(\Phi(n+1)) - \theta_n], \quad S_n + c(\Phi(n+1)), \quad n \geq 0.$
```

The representation of $S_n/n$ as a Monte Carlo average (8.37) shows, since $S_0 = 0$. \square$

# Optimizing the Gain

The recursion (8.36) converges to $\theta^*$ under mild conditions on the Markov chain, and asymptotic statistics tell us something about the rate of convergence. The covariance $\Sigma_n$ in (8.5) is a scalar in this:

```
$\sigma_n^2 = \text{trace}(\Sigma_n) = \Sigma_n = E[\theta_n^2].$
```

which typically admits the approximation

```
$$\sigma_n^2 = n^{-1}\sigma_0^2 + o(n^{-1}),$
```

where the asymptotic variance $\sigma_0^2$ is the solution to (8.28a) with $A=-1$, and $\sigma_{\Delta}^2 = \Sigma_{\Delta}$ defined in (8.27). The Lyapunov function admits the explicit solution shown in Figure 8.3 in this scalar setting.

However, this solution is valid only if $g>1/2$. Assuming $\sigma_{\Delta}^2$ is nonzero, the asymptotic variance is infinite for $g \leq 1/2$ and minimized using $g^*=1$.
