## 7.1 Admission Inputs

Before optimizing, it is necessary to first specify the class of allowable inputs. We already impose a hard constraint that $U(k) \in \mathbb{U}$ for each $k$, and occasionally have state-dependent constraints: $U(k) \in \mathbb{U}(x)$ when $X(k)=x$. We also allow, and to make this precise a bit more obtain

We could settle for the following definition: We only allow input sequences of the form

$$U(k) = \phi_k(X(0), \dots, X(k)), \quad k \ge 0. \quad (7.8)$$

where $\phi_k : \mathbb{X}^{k+1} \to \mathbb{U}$ for each $k$ (perhaps also to finer state-dependent constraints). However, theory requires that we allow randomized policies for $U(k)$ depends on present and past state values, with independent "noise" included for exploration, as discussed in Section 5.2.

**Admissible Input** Given a sequence of independent and identically random variables $\varepsilon_k$, evolving on a countable set $\Omega$. The sequence is exogenous to the control system in the following: For any input sequence of the form (7.8),

$$P(X(k+1) = x', \varepsilon_k = w' \mid X(0), \dots, X(k), U(0), \dots, U(k); X(k) = x, U(k) = u) = P_u(x, x')\nu(w') \quad \text{for all } u \in \mathbb{U}, x' \in \mathbb{X}, w' \in \Omega. \quad (7.9)$$

where $\mathcal{X}(k) = (X(k), \varepsilon(k))$, and $\nu$ is for $\phi_k$ (independent of $k$ by assumption).
We then say that an input sequence $U$ is admissible if it is a causal function of the joint process:

$$U(k) = \phi_k(X(0), \dots, X(k)), \quad k \ge 0. \quad (7.10)$$

We have essentially enlarged the state space to $\mathbb{X} \times \Omega$, with new state process $\mathcal{X}$. For any admissible input,

$$\mathcal{X}(k+1) = (x', w') \mid \mathcal{X}(0), \dots, \mathcal{X}(k), U(0), \dots, U(k); \mathcal{X}(k) = (x, w), U(k) = u] = P_u(x, x')\nu(w').$$

The right-hand side is the controlled transition matrix for $\mathcal{X}$.

## 7.1 MDPs: A Quick Introduction

## Notation and Conventions

The standard MDP terminology uses “Markov” in the definition of a stationary policy:

- Markov policy: $U(k) = \phi_k(X(k))$ for a sequence of maps $\phi_k: X \to U, k \ge 0$.
- Stationary Markov policy: $U(k) = \Phi(X(k))$.

We usually opt for simply “stationary policy” or even “policy” for $\phi$, which is also synonymous with the term feedback law introduced in Chapter 2.

These definitions extend to randomized policies by substituting $X'$ for $X$. However, it is cumbersome to introduce $\ whenever we require randomization. We instead let $\phi$ denote a randomized policy, which is defined as a conditional probability: For each $u$ and $x$,
$P\{U(k) = u \mid X(0), \dots, X(k-1), U(0), \dots, X(k-1)\} = \phi(u \mid x)\}$. (7.11)$

Proposition 7.1 then follows from these definitions:

**Proposition 7.1** *When the input sequence U is defined by a stationary (possibly randomized) policy $\phi$, it follows that the state process $X$ is a Markov chain, with transition matrix* $P_\phi(x,x') = \sum_u \phi(u \mid x)P_u(x,x'), \quad x,x' \in X. (7.12)$

For a function $h: X \to \mathbb{R}$, we use the following compact notation for expectations:

$P_u h(x) = \sum_{x'} \phi(u \mid x)P_u(x,x')h(x') = E[h(X(k+1)) \mid X(k) = x, U(k) = u]$,
$P_u h(x) = \sum_{x'} \phi(u \mid x)P_u(x,x')h(x') = E[h(X(k+1)) \mid X(k) = x]$, (7.13)

where $X$ is controlled by using policy in the second decision.

*For Those of You Who Know About Stochastic Processes*
The expression (7.9) is an example of an equation that is begging for streamlined notation. It is common to introduce a nondecreasing sequence of $\sigma$-algebras (a *filtration*) as a way to model the history appearing in this equation:

$$\mathcal{F}_k = \sigma\{X(0), \dots, X(k), U(0), \dots, U(k)\}. (7.14)$$

If “$\sigma$” looks foreign to you, then simply take $\mathcal{F}_k$ as a notational convention. We have under admissible input
$P\{X(k+1) = x' \mid \mathcal{F}_k; X(k) = x, U(k) = u\} = P_u(x, x')$ (7.15a)

and for any function $h: X \to \mathbb{R}$,
$E[h(X(k+1)) \mid \mathcal{F}_k; X(k) = x] = \sum_{x'} P_u(x,x')h(x'),$ (7.15b)

which is also expressed using the matrix notation analogous to (6.9),
$P_u h(x) = \sum_{x'} P_u(x,x')h(x').$ (7.15c)

## Deterministic and Stochastic Control Aren't Different

One justification for this is proposed in Proposition 9.6, but requires more background than is available at this stage in the book. Justification is provided here by comparison of DP equations for stochastic and deterministic models. Assume that the state and action spaces are convex subsets of Euclidean space, and consider function $J: X \to \mathbb{R}$ whose gradient $\nabla J$ is continuous. The mean value theorem (MVT) tells us that for any $x,x' \in X$, there exists $\varrho \in [0,1]$ such that
$J(x') = J(x) + \nabla J(\bar{x}) \cdot (x' - x), \quad \bar{x} = \varrho x + (1-\varrho)x. \quad (7.20)$

In the remainder of this subsection, we show how to interpret MVT with $J = J^*$ equal to the total-cost value function for the deterministic fluid model. It will be useful to impose a Lipschitz bound on the gradient: For a Lipschitz constraint $L > 0$,
$|\nabla J(x') - \nabla J(x)| \le L|x' - x|, \quad x,x' \in X. \quad (7.21)$

## Fluid Model in Discrete Time

Let's first consider the total-cost value function $J^*$ associated with the (deterministic) fluid model (7.17). This satisfies the DP equation
$J^*(x) = \min\{c(x,u) + J^*(\bar{F}(x,u))\}, \quad (7.22)$

Apply the MVT (7.20) using
$x' = X(k+1) \quad \text{and} \quad x = \bar{F}(x,u) \overset{\text{}}{=} E[X(k+1) | X(k)=x, U(k)=u].$

This gives, for any continuously differentiable function $J$,
$J(X(k+1)) = J(\bar{F}(x,u)) + \nabla J(\bar{F}(x,u)) \cdot \bar{X}(k+1) \quad (7.23)$
$\bar{X}(k+1) \overset{\text{}}{=} X(k+1) - \bar{F}(x,u),$
where $\bar{X} = qX(k+1) + (1-q)\bar{F}(x,u)$, with $q$ a random variable taking in the interval [0,1].
