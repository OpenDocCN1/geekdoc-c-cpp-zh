## 4.6.1 Simulated Annealing

The primary motivation for SPSA and ESC algorithms is that they can be run purely on observations of the loss function. A secondary motivation is that the probing is designed to emulate a "simulated annealing" algorithm for optimization of functions that are not convex: The probing can help avoid local minima. The example described here was illustrated to this point.

![](img/0790f102da4ffa7564329bf76c7d0815_131_1.png)

Figure 4.9 shows a plot of a highly nonconvex function, defined as the "soft min" of convex quadratic functions.

> $$\Gamma(\theta) = -\log\left(\sum_{i=1}^{4} \exp(-\{\|z_i - \theta^*\|^2/\sigma^2\)\right)$$

with $\sigma = 1/10$, and

${[\theta, z_i\]} = \{\{\left(\binom{1}{0}\right), -1\], [\left(\binom{1}{1}\right), -2\], [\left(\binom{0}{1}\right), -3\]\{\}.$

**Figure 4.9** A highly nonconvex function.

The algorithm qSGD #1 is defined in unit. It was tested in this special case: the minimizer is $\Gamma(\theta^*) \approx -300$.

```
$$\frac{d}{dt}\Theta_t = -a_t\varepsilon_d\Gamma(\Theta_t + \varepsilon_d)$$
```

using $\varepsilon = 0.15$, $a_t = \min{\{\bar{z}, (1+t)^{-\rho}\}}$ with $\rho = 0.9$ and $\bar{z} = 10^{-3}$. The probing signal was chosen to satisfy (4:48).

```
$$\varepsilon_d = \sqrt{2}[\sin(t\omega_1), \sin(t\omega_2)]^T$$
```

with $\omega_1 = 1/4$ and $\omega_2 = 1/e^2$ to obtain attractive plots–higher frequencies lead faster convergence.

## 4.6.2 A Menu of Algorithms

In each of the algorithms defined, it is assumed that the process $\Psi$ is the sum of two terms: $\Psi_t = \Theta_0 + \varepsilon\Xi_t, t \geq 0$, where $\varepsilon > 0$, and $\Xi_t$ is a $d$-dimensional probing signal. For simplicity, we impose the normalization conditions unless otherwise stated:

```
$$\lim_{T\to\infty} \frac{1}{T} \int_{t=0}^T \Xi_t \ dt = 0, \quad \frac{1}{T} \int_{t=0}^T \Xi_t\Xi_t^T \ dt = I. \quad (4.95)$$
```

This is easily arranged using a mixture of sinusoids.
The first is the simplest:

### SGD #1

For a given $d \times d$ positive definite matrix $G$, and $\Theta_0 \in \mathbb{R}^d$,

```
$$\dot{\Theta}_t = -a_t\frac{1}{\varepsilon}G\Gamma(\Theta_t), \quad (4.96a)$$
```

```
$$\Psi_t = \Theta_t + \varepsilon\Xi_t. \quad (4.96b)$$
```

# ODE Methods for Algorithm Design

This algorithm takes the form (4.44),

```
f(0, \varepsilon_d) = -\frac{1}{\varepsilon}G\varepsilon_d\Gamma(\varepsilon_d).$$
```

If $\Gamma: \mathbb{R}^d \to \mathbb{R}$ is continuously differentiable, a second-order Taylor expansion of the objective function gives

```
\Gamma(0 + \varepsilon_d) = \Gamma(0) + \varepsilon_d\nabla\Gamma(0) + \frac{1}{2}\varepsilon_d^2\nabla^2\Gamma(0) + o(\varepsilon_d^2)
```

and $f(0, \varepsilon_d) = -\frac{1}{\varepsilon}G\Gamma(0)\varepsilon_d - G\varepsilon_d^2\nabla\Gamma(0) + O(\varepsilon),$

where the error notation $o(\cdot)$ and $O(\cdot)$ is reviewed in Appendix A. Under (4.95), this implies the following approximation for averaged vector field:

```
f_{\varepsilon}(\theta) = \lim_{T\to\infty}\frac{1}{T}\int_0^T f(\theta_t)dt = -G\Gamma(\theta) + O(\varepsilon).
```

QSA theory predicts that qSGD #1 will approximate the steepest descent algorithm for the choice $G = I$.

The next algorithm requires differentiation of measurements. It is motivated by

```
$$\frac{d}{dt}(\Psi_t) = \nabla\Gamma(\Psi_t)^\top\varepsilon_t,$$
```

where a prime denotes a derivative $\varepsilon'_t = \frac{d}{dt}\varepsilon_t$.

### qSGD #2

For a given $d \times d$ positive definite matrix $G$, and initial condition $\Theta_0$,

```
$$\frac{d}{dt}\Theta_t = -\frac{1}{\varepsilon}G\varepsilon_d\Gamma(\Psi_t).$$
```

```
$$\Psi_t = \Theta_t + \varepsilon\Xi_t.$$
```

This algorithm fits neatly in the ESC architecture in Figure 4.8, in which high-pass (HP) filters are chosen to be pure differentiation:

```
$$\dot{\Gamma}(t) = \frac{d}{dt}\varepsilon_t \frac{d}{dt}\Gamma(\Psi_t). \in \mathbb{R}^{2m}$$
```

Algorithm (4.99) can also be cast as a QSA ODE, in which we view $\varepsilon_t = (\varepsilon_t, \frac{d}{dt}\varepsilon_t) \in \mathbb{R}^{2m}$ as the exploration equation. (4.99) gives

```
f(0, \varepsilon'_0) = -\frac{1}{\varepsilon}G\{\varepsilon'_0\}^\top\nabla\Gamma(\theta + \varepsilon_d).$$
```

Analysis of each of these two algorithms presents challenges. A challenge with qSGD #2 is differentiation of the observations $\{\Gamma(\Psi_t)\}$. This is motivation for replacing differentiation with a high-pass filter.

For qSGD #1, the challenge is presented by the form of $f$ in (4.97). In many problems, we know that $\nabla\Gamma$ is globally Lipschitz continuous, but $\Gamma$ is *not*. In such cases, $f$ is not Lipschitz continuous in $\theta$, which will be a standing assumption in the theory. This is not an enormous challenge, since we can modify the algorithm to obtain convergence (say, using a projection of parameter estimates to a bounded set).

Lipschitz continuity is easily established for the next algorithm.

### qSGD #3

For a given $d \times d$ positive matrix $G$, and initial condition $\Theta_0$,

```
$$\frac{d}{dt}\Theta_t = -a_t\frac{1}{\varepsilon}G\xi_t\{\Gamma(\Theta_t + \varepsilon\xi_t) - \Gamma(\Theta_t - \varepsilon\xi_t)\}. \quad (4.100)$$
```

Denoting by $a_t(\Theta_t, \xi_t)$ the right-hand side of (4.100), we find that $f$ is Lipschitz in its first variable whenever $\nabla\Gamma$ is Lipschitz, and in this case $f(\theta, \xi) = -G\xi^T\nabla\Gamma(\theta) + O(\varepsilon)$.

The mean vector $f_t$ for (4.100) admits the same approximation (4.98) under slightly milder conditions on the probing signal, the zero-mean approximation (4.48a) dropped. Moreover, the following global consistency result holds:

**Proposition 4.18** *Suppose that the following hold for the function $\Gamma$ and algorithm parameters in qSGD #3:*

- (i) Assumption (QSA1).
- (ii) The probing signal satisfies (4.48b).
- (iii) $\Gamma$ is globally Lipschitz continuous, and $\Gamma$ is strongly convex (review Section 4.1 for definitions), with unique minimizer $\theta^* \in \mathbb{R}^d$.

Then there exists $\varepsilon > 0$ such that for each $\varepsilon \in (0, \varepsilon)$, there is a unique root $\theta_\varepsilon^*$ of $f_\varepsilon$, satisfying $||\theta_\varepsilon^* - \theta^*|| \le O(\varepsilon)$. Moreover, convergence holds from each initial condition: $\lim_{t\to\infty}\theta_t = \theta^*$.

Proof The hypotheses of this proposition imply that Assumptions (QSA1)-(QSA2) of Section 4.5 hold for $f(\theta, \xi) = -G\xi^T\nabla\Gamma(\theta) + O(\varepsilon)$ and $f_t$ defined in (4.98). Since $\Gamma$ is strongly convex, it holds that there is $\varepsilon_0 >0$ such that there is a unique solution to $G\Gamma(\theta) = z$ whenever $||z|| \le \varepsilon_0$, from which Assumption QSA3 may be established for $\varepsilon > 0$ sufficiently small. Theorem 4.15 implies that for each $\varepsilon > 0$, $\Theta_t$ converges to the unique root $\theta_\varepsilon^*$ of $f_\varepsilon$ satisfying $||\Gamma(\theta_\varepsilon^*)|| = O(\varepsilon)$. Due to strong convexity, we have following:

```
$\Gamma(\theta^*) \ge \Gamma(\theta^*) + (
nabla\Gamma(\theta^*))^T(\theta^ - - \theta^*) + \frac{1}{2}||\theta^ - - \theta^*||^2$.
```

```
$\frac{1}{2}||\theta^* - \theta^*||^2 \le ||\Gamma(\theta^*) - \Gamma(\theta^*)|| + $(nabla\Gamma(\theta^*))^T(\theta^* - \theta^*) \le ||\Gamma(\theta^*)|| ||\theta^* - \theta^*||$,
```

implying that $||\theta_\varepsilon^* - \theta^*|| \le O(\varepsilon)$.
