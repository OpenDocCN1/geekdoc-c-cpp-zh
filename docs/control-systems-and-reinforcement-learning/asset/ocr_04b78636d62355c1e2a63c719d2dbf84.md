5.10 ER and Kernel Methods. This exercise is intended to improve understanding of both kernel methods and batch algorithms. The integer $r_n \ge 1$ denotes the batch size, using the same interpretation as in DQN (see 5.58), and the batch of stage at $n$ is denoted $\{z_i^n : 1 \le i \le r_n\}$.

Consider the recursive algorithm

```
h_{n+1} = \arg\min_{h} { \Gamma_n(h) + \frac{1}{\alpha_n}||h - h_n||^2 + \delta||h||_c^2 }
```

```
||h - h_n||^2 = \frac{1}{r_n} \sum_{k=1}^{r_n} (h(z_k^n) - h_n(z_k^n))^2
```

{\alpha_n\}$ a sequence of positive scalars, and the objective has this form

```
\Gamma_n(h) = \Gamma(h(z_1^n)), \dots, h(z_{r_n}^n).
```
