The following control architecture is of the category studied in [130]:

```
$u^i = -K[z^i - z^{i-1}] - K^+[z^i - z^{i+1}] - K_v[\frac{d}{dt}z^i - v^{rm}], \quad 1 \leq i \leq N$
```

where for notation we interpret $z^0 = z^N$ and $z^{N+1} = z^1$. This architecture is well met in terms of goals, and to make our decisions based on only local information. Unfortunately, theory predicts problems when $N$ is large.
