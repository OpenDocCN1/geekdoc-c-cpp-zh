# 4.7 Quasi Policy Gradient Algorithms

The total cost in this example coincides with the time to reach the goal. For initial condition $x_0 \in \mathbb{R}^d$, we estimate the minimum of the corresponding total cost $J_{	heta}(x_0)$ over $\theta$. A natural approach is episodic: at stage $n$ of the algorithm, we initialize the car at state $x_n$, and run the policy $\phi^{	heta_n} = \Theta_n + \varepsilon\Theta_{n+1}$. On reaching the goal state, we have a measure of $J_{	heta}(x_0)$ for this value of $\theta$.

We make two modifications to this objective function. First, because we don't know if the policy is stabilizing for all $\theta$, we maximize over our choosing. Second, we are interested in more than one initial condition. Let $v$ denote a pdf on $X$, and define our objective function

```
$$\Gamma(\theta) = \sum \nu(x) \min\{J^{max}, J_{\theta}(x)\}$\}$
```

where the sum is over the support of $v$. If $v$ has $K$ points of support, then $K$ experiments are required to obtain the benefit $\Gamma(\Theta_{n+1})$ at stage $n+1$ of the algorithm.
The value $J^{max} = 5000$ is used in all of the numerical experiments that follow.

A second option is to use a constant probing signal to generate a quasirandom sequence of initial conditions $\{x_n^s : n \geq 0\}$ that induce an ergodic average: For any subset $S \subset X$,

```
$$\nu(S) = \lim_{N\to\infty} \sum_{n=1}^{N} \mathbb{1}\{x_n^s \in S\\}$
```

In this case, we don't require that $v$ has finite support, so our objective requires the general notation,

```
$$\Gamma(\theta) = \int \min\{J^{max}, J_{\theta}(x)\} \nu(dx)$.$ (4.103)
```

In this case, the recursion (4.102a) is modified as follows:

```
$$\Gamma_{n+1} = \Theta_n - \alpha_{n+1}\frac{1}{\varepsilon}\Gamma_n + \varepsilon\text{set}\{\min\{J^{max}, J_{\theta}(x_{n+1}))\}_{	heta=\Theta_{n+1}}\}$
```

The experiments that follow are based on (4.104) option 2, though the first option (using K experiments per iteration of the algorithm) is most likely feasible in terms of accelerating convergence. The sequence $\{x_n^s\{s=1}^K}$ was chosen to cover the state space uniformly. This was achieved by introducing a second probing signal $\xi_n^v = (\xi_n, \varepsilon_n^v)$

```
$x_n^s = \text{frac}(nr_s), \quad \xi_n^v = \text{frac}(nr_v)$
```

where "frac" denotes the fractional part of a real number, $r_v, r_e$ are irrational, and $r_v = e$ were chosen in all experiments. Then we define

```
$v_0^s = \overline{(2\pi z_0^s - 1)}, \quad z_0^s = z_0^{goal} + z^{goal} - z^{max}^s$ (4.105)
```

Figure 4.12 shows one using the constant-step $\alpha_n = 0.05, \varepsilonxi_n = \sin(n)$. The large step-size we chose simply to explore the nonlinear dynamics that emerge from this algorithm. It would seem that the algorithm has failed, since the estimates oscillate between -0.1 and -0.3 in time, while the actual optimal is $\theta^* \approx -0.8$. The dashed line shows the average of $\{\Theta_n\}$ over the final 20% of estimates. This average is very near optimal, since the objective function is nearly flat for $\theta$ near the optimizer.
