# 4.9.4 Deterministic Markovian Model

The goal here is to understand Assumption QSA5 in a simple setting. For this, we suppress the variable $\theta$ in function $f(\theta, \xi)$ in (4.117), and adopt the new notation:

```
$$\hat{g}(\mathcal{E}_{t_0}) = \int_{t_0}^{t_1} |g(\mathcal{E}_t) - g| \ dt + \hat{g}(\mathcal{E}_{t_1}), \quad 0 \leq t_0 \leq t_1.$
```

We are essentially fixing a single index $i$ and parameter $\theta$, and setting $\hat{g}(\mathcal{E}_t) \overset{def}{=} f(\theta, \mathcal{E}_t)$. This is a version of Poisson's equation —see Section 4.9 for further discussion. The function $\hat{g}$ is the solution (known as relative value in some applications), $g$ is the forcing function, and $\hat{g}$ its steady-state mean. Lemma 4.37 concerns the special case (4.80) where $H$ has $z \in \mathcal{C}^K$.

**Lemma 4.37** Suppose that $g: \mathcal{C}^K \to \mathbb{R}$ admits the Taylor's representation,

```
$g(z) = \sum_{n_1,...,n_K} a_{n_1,...,n_K} z_1^{n_1}...z_K^{n_K}, \quad z \in \Omega.$
```

where the sum is over all $K$-length sequences in $\mathbb{Z}_+^K$, and the coefficients $(a_{n_1,...,n_K}) \subset \mathcal{C}^K$ are absolutely summable:

```
$\sum_{n_1,...,n_K} |a_{n_1,...,n_K}| < \infty.$
```

Then, with $\xi$ defined in (4.80),

+   (i) The ergodic limit holds:

```
$$\hat{g} = \lim_{T \to \infty} \frac{1}{T} \int_{0}^{T} \hat{g}(\mathcal{E}_t) dt = \int_{0}^{1}...\int_{0}^{1} g(e^{2\pi jt_1}...e^{2\pi jt_K}) \ dt_1...dt_K,$
```

where $g = 0$ (the coefficient when $n_i = 0$ for each $i$).

+   (ii) There exists a solution $\hat{g}: \mathcal{C}^K \to \mathbb{R}$ in (4.10). It is of the form (4.141):

```
$$\hat{g}(x) = \sum_{n_1,...,n_K} a_{n_1,...,n_K} x_1^{n_1}...x_K^{n_K},$
```

in which $|a_{n_1,...,n_K}| \leq |a_{n_1,...,n_K}|/\omega$ for each coefficient.

Proof Complex exponentials are used to obtain the following simple formula:

```
$$\hat{g}(\mathcal{E}_{t_0}) = \sum_{n_1,...,n_K} a_{n_1,...,n_K} \exp(\{n_1\omega_1+...+n_K\omega_K\})jt.$
```

The absolute-summability assumption (4.142) justifies Fubini's theorem:

```
$$\int_{t_0}^{t_1} [\hat{g}(\mathcal{E}_{t_0}) - g] \ dt = \sum_{n_1,...,n_K} a_{n_1,...,n_K} \int_{t_0}^{t_1} \exp(\{n_1\omega_1+...+n_K\omega_K\})jt \ dt$$
```

```
$$\hat{g}(\mathcal{E}_{t_0}) - \hat{g}(\mathcal{E}_{t_1}),.$
```

where $\hat{g}$ is given by (4.143) with $\bar{a}_0 = 0$ (that is, $n_k = 0$ for each $k$), and for all other coefficients, $\hat{a}_{n_1,...,n_K} = a_{n_1,...,n_K}\{n_1\omega_1+...+n_K\omega_K\}^{-1}$.
