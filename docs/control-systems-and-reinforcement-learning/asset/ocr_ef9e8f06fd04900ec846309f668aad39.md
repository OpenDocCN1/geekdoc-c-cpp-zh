To keep notation simple, let's assume that X and U are finite. There are no special input constraints: $U(x) = U$ for each $x

The variables in the LP consist of nonnegative functions on $X 	imes U$. Utilization requires a different perspective on optimal control. For any input sequence $\omega$, we define what is known as the (conditional) occupancy pmf:

```
$$\omega(x, u | x_0) = \sum_{k=0}^{\infty} 1\{x(k)=x, u(k)=u\}, \quad (x, u) \in X \times U, x \neq x^e$$
```

where $x$ is the state process with initial condition $x_0$ and input $\omega$. For notational convenience, we set $\omega(x, u | x_0) = 0$ for any $u$. A bit of accounting gives

```
$$\sum_{x,u} c(x, u)\omega(x, u | x_0) = J(x_0) = \sum_{k=0}^{\infty} c(x(k), u(k)), \quad x(0)=x_0$$
```

Part of this including these assumptions: $c(x^e, u^e) = 0$ and $U(x^e) = \{u^e\}$. We then define the following for a given pmf $\omega$ on $X$:

```
$$\omega(x) = \sum_{x_0} \omega(x, u | x_0)$.$$
```
