# 7.15 Parameter Estimation. In Section 7.8.2, we saw that parameter estimation can be cast as a state estimation problem. The purpose of this exercise is to look at a simpler problem, with the 'exploration' issue set aside.

We are given scalar measurements

```
$Y(k) = \theta + W(k)$,
```

and to obtain $\hat{	heta}$ of $\theta$, based on n observations. If you are told that $\mathbf{W}$ is a zero mean Gaussian, a natural choice is Monte Carlo:

```
$\hat{	heta}_{MC}(n) = \frac{1}{n} \sum_{k=1}^{n} Y(k)$.
```

Suppose that the noise $\mathbf{W}$ is the input of a stable filter. For some $1 \times n$ matrix $G$, and $n \times n$ matrix, we have the following for $k \ge 0$:

```
$Z(k+1) = FZ(k) + N(k+1), \quad W(k) = GZ(k)$.
```

It is assumed that $N$ is Gaussian white noise with marginal $N(0, \Sigma_N)$, and $\theta$ has a known Gaussian distribution that is independent of $N$.

+   (a) Write down state equations for this system with state $X(k) = (langle Z(k), \theta \rangle)^T$, and write down the Kalman filter equations to estimate $X$ and $\theta$.
