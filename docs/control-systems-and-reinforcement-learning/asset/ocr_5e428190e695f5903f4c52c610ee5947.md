# Transient and Asymptotic Behavior

Figure 8.5 shows results from SA using $\alpha_n=g*/n^ho$ for three values of $ho$. The columns are distinguished by the value of $ho$. The plots in the first row compare the output of the algorithm $	heta_{	au_k}$ with the deterministic Euler approximation:

> $\theta_{	au_{n+1}} = 	heta_{	au_n} + \alpha_n f(	heta_{	au_n}), \quad n \geq 0, \quad \theta_0 = \theta_0.$ (8.50)

The approximation $	heta_{	au_k} \approx \tau_k$ appears to be very accurate. The high accuracy is due in part to the large initial condition, since the fluctuations of $\alpha_k$ are small compared to its magnitude (the plots shown in Figure 8.2 are for the same example, but with $	heta_0=1$). These plots show on the "ODE time scale": the $x$-axis is $	au_k$ rather than $k$, so that the final $	au_N$ depends on the stepsize:

> $\tau_N = \sum_{k=1}^N \alpha_k.$

The value $N=10^5$ was chosen in this experiment, so that $\alpha_k=g^*/k^ho$ results in the values of $	au_N$ shown in the top row of Figure 8.5. We see that $\theta_{	au_N}$ remains far from the equilibrium value $	heta^*=0$ when using $\rho=1$.

The histograms in Figure 8.5 were based on 500 independent runs, horizon $N=10^6$, and with initial condition sampled independently $\theta_0 \sim N(0,1)$ (so that the transient behavior has less impact). The normalized error at the end of the runs appears approximately Gaussian in all cases.
