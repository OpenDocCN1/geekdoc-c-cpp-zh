```

```

Moreover, the second inequality is strict whenever $\theta_t \neq \theta^*$. From here, we may follow the steps of Proposition 4.11 to conclude that $\theta_t$ converges to $\theta^*$.

# 4.8.4 The ODE at $\infty$

We consider here another way to verify that the ODE (4.2) is ultimately bounded. idea is pretty simple: to see if the ODE is ultimately bounded, we only need to consider values of $\vartheta$ that are "very big". Rather than using a telescope to examine these big states, we scale and use the resulting dynamics. To make this explicit we require to make dependency on the initial condition explicit, writing $\vartheta(t;\theta_0)$ for the solution to (4.2) with initial condition $\vartheta_0 = \theta_0$.

```
$$\vartheta_t^r \stackrel{\text{def}}{=} r^{-1}\vartheta(t;r\theta_0)..$
```

We have $\vartheta_0^r = \theta_0$ for any $r \ge 1$, and we obtain from (4.2),

```
$$\frac{d}{dt}\vartheta_t^r = r^{-1}\frac{d}{dt}(t;r\theta_0) = r^{-1}f(\vartheta(t;r\theta_0))..$
```
