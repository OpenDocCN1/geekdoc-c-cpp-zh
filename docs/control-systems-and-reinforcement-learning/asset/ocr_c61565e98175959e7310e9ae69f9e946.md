# Value Function Approximations

**What’s a Good Approximation?** If you have read Chapter 3 on optimal control, you surely want to learn how to approximate the Q-function $Q^*$. However, you are more eager to obtain an estimate of the optimal policy:

```
$\Phi^Q(x) = \arg\min_{u \in \mathcal{U}(x)} Q^*(x,u), \quad x \in X.$
```

A few things to keep in mind as we do not need a highly accurate approximation of the Q-function

+   (i) *Approximation fidelity.* If our goal is to obtain a policy that is approximately optimal. Rather, the goal is that the performance of policy $\phi^*$ is approximately ideal. Then, if $\Gamma(\theta)$ would be some measure of policy performance, the mean-square Bellman error (5.5) is a common surrogate.
(ii) *Policy evaluation.* Suppose it is computationally feasible to compute $\Gamma(\theta_n)$ (perhaps based on a model). In this case, we can keep a tally of performance for selected iterations $\Gamma(\{	heta_k : k \geq 1\}$. We then select these policies among $\{\phi^{\theta_k} : k \geq 1\}$ with the best performance. Most likely we will do so, following the guidelines in Section 2.2 and suggestions found in Section 5.1.5.

# 5.1 Function Approximation Architectures

This section might be viewed as the brief course on machine learning. [557] for a more leisurely introduction to the function approximation concepts covered here.

The goal is to approximate a function $H^*: Z \to \mathbb{R}_m$, where interpretation of $H^*$ and the definition of the set of points $Z$ depend on context. This is regarded as a learning problem when the data is gathered in an experiment. For example, $H^*$ might be the Q-function defined in (3.7a), and $Z = X \times U$. In this case, the data will be obtained from experiments on the control system: the input applied to the system, along with functions of the resulting input-process state.

The techniques described here for function approximation require a few ingredients:

+   (i) *A function class $\mathcal{H}$. Three examples are described in this chapter: a $d$-dimensional linear function class, $d$-dimensional nonlinear function class defined by a neural network, and one-dimensional class: the reproducing kernel Hilbert space (RKHS).
(ii) For each $h \in \mathcal{H}$, we associate a negative “loss” denoted $\Gamma(h)$. The loss is designed so that $\Gamma(h)$ is small when $h = H^*$; our approximation is loose if $\Gamma(h)$ is large. We use just one requirement on this function loss: assumed given are samples $\{z_i : 1 \leq i \leq N\} \subset Z$, and $\Gamma$ depends only on $h$ evaluated at the samples. Consequently, rather than thinking the domain of $\Gamma$ as the abstract collection $\mathcal{H}$, it is a mapping $\Gamma: \mathbb{R}^N \to \mathbb{R}$,

```
$\Gamma(h) = \Gamma(z_1), \dots, h(z_N). \quad (5.2)$
```

+   (iii) An algorithm to obtain the minimizer of $\Gamma(h)$ over $h \in \mathcal{H}$. This book is filled with techniques for constructing algorithms, and techniques to obtain insight on their rate of convergence.
