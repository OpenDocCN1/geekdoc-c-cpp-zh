Proof of Proposition 10.22 We have by definition

```
$\Delta_n^A \stackrel{\text{def}}{=} \Lambda^0(\Phi(n)) - \Phi(n)) - \Delta H_n^{\omega_n^*} (X(n))$
```

The conditional expectation is

```
$E[\Delta_n^A | \mathcal{F}_n] = E[\Lambda^0(\Phi(n)) V_{\Phi(n)}^* | \mathcal{F}_n] - \Delta H_n^{\omega_n^*} (X(n))]\n= E[\Lambda^0(\Phi(n)) V_{\Phi(n)}^* | \mathcal{F}_n] - \Delta H_n^{\omega_n^*} (X(n))]\n= 0
```

where the second equality follows from Lemma 10.20. The conclusion $E[\Delta_n^A | \mathcal{F}_n] = 0$ implies that $\{\Delta_n^A\}$ is a martingale difference sequence. Part (i) follows because $\hat{V}_n^{\omega_n^*}(n) = \Delta H_n^{\omega_n^*}(X(n))$ is measurable with respect to $\mathcal{F}_n$, so that $\Delta_n^A$ and $\hat{V}_n^{\omega_n^*}(n)$ are uncorrelated.

For (ii), observe the martingale property implies that $\Delta_n^A$ and $\hat{V}_n^{\omega_n^*}(0)$ are uncorrelated for $n \ge 1$,

```
$E_{\omega}[\hat{V}_n^{\omega_n^*}(n)(\hat{V}_0^{\omega_0^*}(0))^	op] = E_{\omega}[\hat{V}_0^{\omega_0^*}(0)(\hat{V}_n^{\omega_n^*}(n))^	op]$.
```

Taking transposes of each side, we obtain the same identity for $n \le -1$. Here twice the auto-covariance sequences are identical for $n \neq 0$.
