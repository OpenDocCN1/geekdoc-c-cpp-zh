
## 6.8 Sensitivity and Actor-Only Methods

- There is a solution $h_\theta$ to Poisson's equation:

```
$$c_0 + P_\theta h_\theta = h_\theta + \eta_\theta. \quad (6.50)$$
```

- The average cost $\eta_\theta$ and other functions of $\theta$ are continuously differentiable in $\theta$.

The assumption that $\eta_\theta$ and $h_\theta$ are continuously differentiable functions of $\theta$ is not strong. See Example 6.21 for hints how to obtain a representation of the gradient of $h_\theta$, subject to mild assumptions on the parameterized model. The "Notes" section contains references with full details.

The control objective is to minimize the loss function $\Gamma(\theta) = \eta_\theta$ over all $\theta \in \mathbb{R}^d$ and, in Section 4, our approach is to approximate by gradient descent: $\frac{d\Gamma}{d\theta}_t = -\Gamma'(\theta_t)$.

A formula from the 1960s provides one example for approximating the gradient, based on the so-called *score function*, for a finite state space model:

```
$$S^\theta(x,x') = \nabla_x \log(P_\theta(x,x')), \quad x,x' \in X. \quad (6.51)$$
```

Lemma 6.7 is merely a restriction of that, using the chain rule for the gradient of a logarithm:

**Lemma 6.7** *For a finite state Markov chain, and any function $g: X \to \mathbb{R}$,*

```
$$\nabla_\theta{\sum_x P_\theta(x,x')g(x')} = \sum_x P_\theta(x,x')S^\theta(x,x')g(x'). \quad \square$$
```

The proof of the following is at the end of this section.

**Theorem 6.8 (Sensitivity Theorem)** *Suppose that the assumptions of this section hold, and in addition $X$ is finite, $c_\theta(x)$ is continuously differentiable in $\theta$ for each, and the score function is continuous at all value of $\theta$ for $P_\theta(x,x') > 0$. Then,*

```
$$\Gamma(\theta) = E_{\pi_\theta}[c_\theta(X(k)) + S^\theta(X(k), X(k+1))h_\theta(X(k+1))], \quad (6.52)$$
```

where the expectation is in state under.

The stochastic approximation of Section 8 invites the *stochastic gradient descent (SGD) algorithm*:

```
$$\theta_{n+1} = \theta_n - \alpha_{n+1}\hat{\Gamma}(X(n)), \quad (6.53)$$
$$\hat{\Gamma}(n+1) = [\nabla_\theta\Gamma(X(n)) + S^\theta(X(n), X(n+1))h_\theta(X(n+1))]|_{\theta=\theta_n}$$
```

where (in *early chapters*) $\alpha$ is a step-size approach. It is likely that we have designed $P_\theta$ and $c_\theta$, so the score function is available. A challenge with this algorithm is the computational complexity of computing $h_{\theta_n}$, at each iteration $n$.

The update equation for $\theta$ is an example of the *actor* in the RL literature, and the relative value function $h_{\theta_n}$ is the critic at iteration $n$. The actor-critic methods surveyed in Section 10 provide a computationally feasible refinement of (6.53), in which the relative value function is estimated simultaneously with estimation of the parameter $\theta^*$ that minimizes $\Gamma$.

How is the score function defined for a general state space? Suppose that $X = \mathbb{R}^n$ and there is a transition density:

```
$P_\theta(x,A) = \int_{y \in A} p_\theta(x,y)dy, \quad x \in X, A \in B(X)$.
```

In this case, the definition is analogue to the finite state space case

```
$S^\theta(x,x') = \nabla_{\theta}\log p_\theta(x,x'), \quad x,x' \in X. \quad (6.54)$
```

Lemma 6.7 continues to hold with this definition of the score function, subject to smoothness assumptions on the density, and growth conditions on $g$.

Consider, for example, the nonlinear model with additive noise, $X(k+1) = F(X(k);\theta)$, where the marginal of $N$ has density $p_N$. For $g: X \to \mathbb{R}$, we have

```
$P_\theta(x) = \int g(F(x;\theta) + z) p_N(z)dz$.
```

Consequently, it would appear that $\nabla_{\theta}P_\theta(x)$ requires differentiation of $g$. This is avoided through the change of variables $y = F(x;\theta)$

```
$P_\theta(x) = \int g(y)p_\theta(x,y)dy, \quad p_\theta(x,y) = p_N(y - F(x;\theta))$,
```

and this, we obtain a version of Lemma 6.7:

```
$\nabla_{\theta}P_\theta(x) = E[g(X(k+1))S^\theta(X,X(k+1)) | X(k)=x]$,
$S^\theta(x,x') = \nabla_{\theta}\log\{p_N(x' - F(x;\theta))\}, \quad x,x' \in X. \quad (6.55)$
```

Proof of Theorem 6.8 Expanding Poisson's equation fibres, for each $x$ and $\theta$,

```
$c_\theta(x) + \sum_{x'} P_\theta(x,x')h_\theta(x') = h_\theta(x) + \Gamma(\theta)$.
```

We take the gradient of each side, applying the product rule:

```
$\nabla_{\theta}c_\theta(x) + \sum_{x'}{\{\nabla_{\theta}P_\theta(x,x')h_\theta(x') + P_\theta(x,x')\nabla_{\theta}h_\theta(x')\}} = \nabla_{\theta}h_\theta(x) + \nabla_{\theta}\Gamma(\theta)$.
```

The introduction of the score function is only that we can bring $P_\theta$ outside of the brackets (easy application of Lemma 6.7) to obtain Multiplying each side by $\pi_\theta(x)$ and summing gives

```
$E_{\pi_\theta}[c_\theta(X(k)) + S^\theta(X(k), X(k+1))h_\theta(X(k+1))] = E_{\pi_\theta}[h_\theta(X(k)) + \Gamma(\theta)].
```

The proof is completed by canceling $E_{\pi_\theta}[h_\theta(X(k))]$ from each side.

### 6.9 Ergodic Theory for General Markov Chains

- Spectral theory for Markov chains can be extended beyond the finite state setting. In particular, a full generalization of Theorem 6.2 is available, known as the $V$-uniform ergodic theorem. Ergodic theory and bounds on solutions to Poisson's equation are important in the remainder of the book, but you will have to go to other sources for details: A survey can be found in the appendix, and a high-level survey is provided here.

### 6.9.1 Classification

For a Markov chain on a general state space, it remains true that $\psi$-irreducibility is always a right notion. Recalling the notation in (6.9), where $P^k(x,A) = P^k(x,A)$ denotes a function: $1(x) = 1$ for all $x \in X$. More, for each $k \ge 1$ and $x \in X$, the assumptions on any of Theorem 6.2 are traditionally replaced with the following notion of irreducibility and aperiodicity. A probability measure $\psi$ on $X$ is defined and we have the following classification:

- (i) The chain is $\psi$-irreducible, for any $A \in B(X)$ satisfying $\psi(A) > 0$, and any $x \in X$, there is $n_0 \ge 1$ satisfying $P^n(x, A) > 0$.
- (ii) The chain is aperiodic, for any set $A \in B(X)$ satisfying $\psi(A) > 0$, and any $x \in X$, there is $n_0 \ge 1$ satisfying $P^n(x, A) > 0$.

These definitions appear verifiable: How one test every $A \in B(X)$? One approach is through verification of a condition: A set $S \in B(X)$ is called small if there is a probability measure $\nu$, $\delta > 0$, and a $n$ such that

```
$P^n(x, A) \ge \nu(A), \quad x \in S, A \in B(X). \quad (6.56)$
```

This isn't hard to verify as it might appear. For example, it is easy to construct small sets if $X = \mathbb{R}^n$ and $P^n$ has a continuous density.

**Lemma 6** Suppose that the pair $(S,\nu)$ satisfies (6.56). Then,

- (i) Suppose that $\sum_{k=0}^{\infty} P^k(x_0, S) > 0$ for any $x_0 \in X$. Then the chain is $\psi$-irreducible, with $\psi = \nu$.
- (ii) Suppose that for $x \in X$, there is $n_0 \ge 1$ satisfying $P^n(x, S) > 0$.

The chain is also aperiodic. $\square$

### Markov Chains

The situation is even simpler when $X$ is countable, since every singleton is small (a set $S$ consisting of just one element). Suppose that there is $x^{*}\in X$ satisfying

```
$$\sum_{k=0}^{\infty} P^k(x_0,x^*) > 0 \quad \text{for every } x_0 \in X.$$```

Applying Lemma 6.9, using $S=\{x^*\}$, we see that the chain is $\psi$-irreducible, with $\psi(\cdot)=P(x^*)$. In this case, uni-chain is satisfied if $\psi$-irreducible (or we call it $x^*$-irreducible if we want to emphasize the particular reachable state $x^*$). The definition of aperiodicity is also more easily verified: there is $n_0 \ge 1$ satisfying

```
$P^n(x,x^*) > 0, \quad n \ge n_0. \qquad (6.57)$
```

One celebrated property of an invariant measure $\pi^*$ is known as Kac's theorem:

**Proposition 6.10 (Kac's Theorem)** Suppose that $X$ is a Markov chain on a countable state space. Suppose that $x^*$ satisfies $[\tau_{x^*}] < \infty$. Then there is an invariant measure $\pi^*(x^*) > 0$, and for all functions $g$ for which $\pi(|g|)$ is finite:

```
$$\pi(g) = \sum_{k=0}^{\tau_{x^*}-1} \pi(x)g(x) = \pi^*(x^*)E_{x^*}[g(X(k))]. \qquad (6.58)$$
```

The invariant $\pi$ is unique if $\Phi$ is uni-chain. The connection with the finite state space is made in the following:

**Proposition 6.11** The following equivalences hold for a finite state Markov chain:

- (i) The eigenvalue $\lambda_1=1$ is not repeated $\implies$ the uni-chain assumption holds.
- (ii) The eigenvalue $\lambda_1=1$ is the only eigenvalue satisfying $|\lambda|=1$, and this eigenvalue is not repeated $\implies$ the chain is aperiodic.

## 6.9.2 Lyapunov Theory

Recall that the coercive assumption was a useful property for Lyapunov functions in a deterministic setting: $V$ is coercive means that the sublevel $S_V(r)$ is a bounded set of $X$ for any $r$. In the theory of $\psi$-irreducible Markov chains, the sublevel sets are small, either by direct assumption or a consequence of other assumptions. The two Lyapunov conditions $(V3)$ and $(V4)$ follow from. Each of these bounds a "negative drift" whenever the state is outside of a small set:

```
$E[X(k+1) | X(0), \dots, X(k)] < V(X(k)) \quad whenever X(k) \notin S.$
```

Assumption (V3) is a refinement of the Poisson inequality (6.27).

**Theorem 6.12 (Lyapunov Condition for Poisson's Equation)** Suppose that the Markov chain is $\psi$-irreducible, and there exists a solution to the following Lyapunov bound: For a nonnegative-valued function $V$ on $X$, a small set $S \in B(X)$, $b < \infty$, and a function $f: X \to [1, \infty)$,

```
$PV(x) \le V(x) - f(x) + b\S(x), \quad x \in X. \quad (V3)$
```
