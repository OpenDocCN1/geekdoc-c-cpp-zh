
## 2.4 Stability and Performance

Example 2.4.1 (Linear Model in Continuous Time) Consider the linear ODE

```
\frac{d}{dt}x = Ax
```

whose solution is the matrix exponential:

```
x_t = e^{At}x(0), \quad e^{At} = \sum_{m=0}^{\infty} \frac{1}{m!}t^mA^m.
```

Consequently, $x_t \rightarrow 0$ as $t \rightarrow \infty$ from each initial condition if and only if $A$ is Hurwitz; each eigenvalue of A has strictly negative real part.

The solution to (2.41) is given with a quadratic $J(x) = x^TZx$, where the matrix $Z$ can be found through a bit of linear algebra and calculus. The value is non-unique, so we may assume $Z$ is semidefinite (hence in particular, symmetric: $Z = Z^T$). Symmetry implies,

```
\frac{d}{dt}J(x_t) = 2x_t^TZAx_t = x_t^T[ZA + A^TZ]x_t
```

and from (2.41) this gives

```
x_t^T[ZA + A^TZ]x_t = -c(x_t) = -x_t^TSx_t.
```

This must hold for each $t$ and each $x(0)$, giving the Lyapunov equation in continuous time:

```
0 = ZA + A^TZ + S.
```

Euler Approximation. If we sample, with sampling interval $\Delta > 0$, then from the continuous time model (2.42) we obtain the linear model (2.42); with $t_k = k\Delta$,

```
x(t_k+1) = e^{\Delta A}x(t_k), \quad k \geq 0.
```

The Euler approximation of (2.44) also results in the linear model (2.42), but with $F = I + \Delta A$. The matrix F is the first-order Taylor series approximation of the matrix exponential. While only an approximation, it is enough for good control design.

A particular two-dimensional example is $A = \begin{pmatrix}-0.2 & 1 \\ -1 & -0.2\end{pmatrix}$. The matrix is Hurwitz, with two eigenvalues $\lambda(A) = -0.2 \pm j$; with sampling interval $\Delta = 0.2$, we find that $F = I + \Delta A$ has two complex eigenvalues:

```
\lambda(F) = 1 + \Delta\lambda(A) \approx 0.996 \pm 0.02j.
```

The eigenvalues satisfy $|F| < 1$, so we see that stability of the discrete-time approximation is inherited from the continuous-time model.

The Matlab command `M = dylap(F', eye(2))` returns a solution to the Lyapunov equation (2.43) with $S = I$ (the identity matrix):

```
M = \begin{pmatrix}131.9 & 0.0 \\ 0.0 & 131.9\end{pmatrix}.
```

The fact that $F$ has complex eigenvalues implies that the process will exhibit rotational motion. ## 2.5 A Glance Ahead: From Control Theory to RL

The origin is stable in the sense of. To see this, consider a Lyapunov function defined as the sum of potential and kinetic energy:

```
$V(x) = PE + KE = mg[1 - \cos(x_1)] + \frac{1}{2}mv_2^2.$
```

The first term potential energy relative to the height at the equilibrium $x^e = 0$, and the second is the classical $KE = \frac{1}{2}mv^2$ formula for kinetic energy. It is surprising that $V$ is minimized at $x^e = 0$. We have

```
$\nabla V(x) = m[g\sin(x_1), v_2]^T$, and $\nabla V(x) \cdot f(x) = (g/\ell)\sin(x_1) = 0.$
```

This means that $\frac{d}{dt}V(x)=0$, and hence $V(x)$ does not depend on time. For example, the periodic orbit shown in Figure 2.8 evolves in a set of V:

```
$[1 - \cos(x_1(t))] + \frac{1}{2}x_2(t)^2 = \text{const}.$
```

From this follows that the origin is stable in the sense of Lyapunov. *Linearization:* Using the first-order Taylor series approximation $\sin(\theta) \approx \theta$, the state space equation for the pendulum can be approximated by the LTI model (2.44): $\frac{dx}{dt} = Ax$, with

```
$A = \begin{bmatrix} 0 & 1 \\ -g/\ell & 0 \end{bmatrix}. \quad (2.50)$
```

The eigenvalues of $A$ are obtained by solving the quadratic equation $0 = \det(\lambda I - A)$:

```
$0 = \det\left(\begin{bmatrix} \lambda & -1 \\ g/\ell & \lambda \end{bmatrix}\right) = \lambda^2 - g/\ell \implies \lambda = \pm\sqrt{g/\ell}j.$
```

The complex eigenvalues are consistent with the periodic behavior of the pendulum.

### 2.5.1 Actors and Critics

The actor-critic algorithm of reinforcement learning is specifically designed within the context of stochastic control, so this is a topic for Part II. The origins of the terms are worth explaining here. We are given a parameterized family of functions $\{\phi^\theta : \theta \in \mathbb{R}^d\}$, which play the role of actors. For each $\theta$, we (or our "software agents") can observe features of the state process $x$ under chosen policy. The ideal critic computes the associated value function $J_\theta$, but in realistic situations we have only an estimate.

Since in this book we are minimizing cost rather than maximizing reward, the output of an actor-critic algorithm is

```
$$\theta^* = \arg_{\theta}\langle v, J_\theta\rangle,$$
```

where $v \geq 0$ serves as a state weighting. This will be defined as a sum

```
$$\langle v, J_\theta\rangle = \sum_i J_\theta(x^i)v(x^i),$
```

where $v(x^i)$ is relatively large for "important states." (Note: text cuts off/continues based on OCR). These algorithms are intended to approximate the true gradient descent algorithms of optimization surveyed in Section 4.4, and are often called "actor-only methods."
