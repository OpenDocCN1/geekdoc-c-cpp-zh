In fact, no limit is required for the Zap recursion. This is seen through a refinement of Proposition 8.8: First note when $n = 0$ in (8.57), the initial condition is canceled:

```
$$\theta_1^{zap} = \theta_0^{zap} + {\theta_0^{zap} - A^{-1}\Delta_1} = -A^{-1}\Delta_1$.
```

It can be shown by induction that for each $n \geq 1$,

```
$$\theta_n^{zap} = -A^{-1}\frac{1}{n}\sum_{k=1}^n \Delta_k$.
```

Here $\sqrt{n}\theta_n^{zap} \sim N(0, \Sigma^*)$ for each $n!$.

In the experimental results described here, the vector $v$ was chosen as $v = z/||z||$, with $z$ selected $N(0,d)$ with $d=50$. It was found that $\hat{\Sigma}(i)$ is close to unity for each $i$ with values of $\kappa$ considered

The exponent for Polyak–Ruppert averaging was taken to be $\rho = 0.75$, averaging over the recent 70% of samples:

```
$$\theta_n^ho = \frac{1}{0.7n}\sum_{0.3n \leq k \leq n} \theta_k^ho$.
```

Histograms were obtained for $Z_n^i = \sqrt{n}\theta_n^i : 1 \leq i \leq 500$ (500 independent runs), with initialization $\theta_0^i \sim N(0,\sigma^2I)$ using $\sigma^2 = 25$.

For $\kappa = 100$, the behaviors of Polyak–Ruppert estimates are very similar after $10^3$ iterations. Increasing the value to $\kappa = 500$ revealed differences. The source of the problem is clear from Figure 8.8: The bound $\alpha_n \leq 1/n$ was used to avoid explosion of the parameter estimates. The figure shows only the first three parameter estimates for each of the three parameter estimates. In these-cases, the estimates $\theta_n(1)$ and $\theta_n(1)$ are not visible since $\theta_0(1)$ is out of range and the step-size is so small.

Figure 9, $n=10^3$, reveals significantly high variance when using Polyak–Ruppert averaging. With $n=10^4$, the situation is improved, and the results from PJR averaging are more similar to SNR.

However, $n=10^4$ samples is no longer sufficient if condition $\kappa$ is increased from 500 to 1,000. The empirical variance of each parameter is found to be approximately 14 for $n=10^4$ when using PJR averaging, while the optimal variance is slightly less than one.
