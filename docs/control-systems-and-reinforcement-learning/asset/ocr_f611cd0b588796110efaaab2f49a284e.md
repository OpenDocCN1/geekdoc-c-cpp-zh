```
$E[c(X_k, U_k) \mid \mathcal{Y}_n] = E[C(b_k, U_k) \mid \mathcal{Y}_n],\n$C(b_k, U_k) \stackrel{\text{def}}{=} \sum_{x} b_k(x)c(x, U_k) = E[c(X_k, U_k) \mid \mathcal{Y}_n].$
```

```
$E[V_0(X_n) \mid \mathcal{Y}_n] = E[V_0(b_n) \mid \mathcal{Y}_n],\n$V_0(b_n) \stackrel{\text{def}}{=} \sum_{x} b_n(x)V_0(b_n)$.
```

Consequently, the (possibly nonoptimal) cost to admits the representation

```
$V_{n,N} = \stackrel{\text{def}}{=} E \left[ \sum_{k=n}^{N-1} c(X_k, U_k) + V_0(X_N) \mid \mathcal{Y}_n \right],\n$= E \left[ \sum_{k=n}^{N-1} c(b_k, U_k) + \mathcal{V}_0(b_N) \mid \mathcal{Y}_n \right],\n$= E \left[ \sum_{k=n}^{N-1} c(b_k, U_k) + \mathcal{V}_0(b_n) \mid b_n, U_n \right]$.
```

where the final equality follows from Proposition C.1. On minimizing over admissible inputs, we obtain the representation (C.11).

Besides the remaining work involved in establishing Proposition C.1, the biggest question is, can we ever solve a POMDP? A solution can be found for the special case of Linear Gaussian models where the belief $b_n$ is Gaussian and hence characterized by the mean and variance.

We could potentially value iteration to obtain the optimal policy. Given an initial value function $V_0 : S \to \mathbb{R}$, we define the following by induction:

```
$\mathcal{V}(b_n) = \min_{u} \C(b_n, u) + \sum_{y', x, x'} b_n(x)P_u(x, x')q(y' \mid x')\mathcal{V}_{n-1}(\mathcal{M}(b_n, y', u))\}, \quad b \in S$.
```

Or, if you are interested in the average-cost optimization problem you would solve the dynamic programming equation:

```
$\eta^* + H^*(b) = \min_{u} \{C(b, u) + \sum_{y', x, x'} b(x)P_u(x, x')q(y' \mid x')H^*(\mathcal{M}(b, y', u))\}$.
```

where $H^* : S \to \mathbb{R}$ and $\eta^*$ is the optimal average cost for the partially observed optimal control problem.
