# ODE@\infty$

When extending the techniques of Section 4.8.4, we require the vector field at $\infty$ associated with the average vector field:

```
$f_{\infty}(\theta) := \lim_{r\to\infty} r^{-1}f(r\theta), \quad \theta \in \mathbb{R}^d. (4.138)
```

+   (i) The limit (4.138) exists for all $	heta$ to define a continuous function $f_{\infty}: \mathbb{R}^d \to \mathbb{R}^d$.
(ii) The origin is globally asymptotically stable for the ODE at $\infty$:

```
$$\frac{d}{dt}\tilde{x}_t^{\infty} = f_{\infty}(\tilde{x}_t^{\infty}), \quad \theta \in \mathbb{R}^d. (4.139)
```

Then there the main step in the proof of Proposition 4.34 is to show that the assumptions of the theorem imply that the ODE (4.42) is ultimately bounded. Lemma 4.23 is repeated here in the new notation for convergence:

**Lemma 4.35** *Suppose that (QSA2) holds, and the limit (4.138) exists for all $	heta$ to define a continuous function $f_{\infty}: \mathbb{R}^d \to \mathbb{R}^d$. Moreover that the origin is asymptotically stable for (4.139). Then the following holds:*

+   (i) $\tilde{x}_t^{\infty}(s) = sf_{\infty}(\theta)$ for each $	heta \in \mathbb{R}^d$ and $s \geq 0$.
(ii) If $\{t : t \geq 0\}$ is any solution to the ODE, (4.139), and $s > 0$, then $\{y_t = s\tilde{x}_t^{\infty} : t \geq 0\}$ is also a solution, starting from $s\tilde{x}_0^{\infty} \in \mathbb{R}^d$.
(iii) The origin is globally asymptotically stable for (4.139), and convergence to the origin is exponentially fast: For some $R < \infty$ and $\rho > 0$,

```
$|\tilde{x}_t^{\infty}\| \leq Re^{-\rho t}|\tilde{x}_0^{\infty}\|, \quad \\tilde{x}_0^{\infty} \in \mathbb{R}^d.$
```

This is essentially one step in the proof of Proposition 4.22.

**Lemma 4.36** *Under the assumptions of Lemma 4.35, for each $T < \infty$ and $\varepsilon \in (0,1]$, there exists $K_T < \infty$ independent of $\varepsilon$, and $B_T(\varepsilon) < \infty$ such that for all solutions to (4.42) and (4.139) from common initial condition $\theta_0$,

```
$|\tilde{x}_t - \tilde{x}_0^{\infty}\| \leq K_T[1 + |\theta_0|\]\varepsilon.$
```
