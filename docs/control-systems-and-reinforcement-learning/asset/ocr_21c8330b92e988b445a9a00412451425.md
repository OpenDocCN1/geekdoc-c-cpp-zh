# 2.5 A Glance Ahead: From Control Theory to RL

After collecting $N$ observations, we obtain the mean-square loss:

```
$\Gamma^c(J) = \frac{1}{N} \sum_{k=0}^{N-1} [D_{k+1}(J)]^2. \quad (2.53)$
```

We are then faced with another machine learning problem: minimize this objective function over $J$ in a given class (for example, this is where neural networks frequently play a role).

If we can (2.53) nearly zero, then we have a good estimate of a value function. Beyond its application to actor-critic methods, there are TD- and Q-learning techniques, designed to minimize (2.53) or a surrogate, that are part of a RL toolbox.

# 2.5.3 Bandits and Exploration

Suppose that our policy is not optimal in any sense, but $x(k) \to x^e$, $u(k) \to u^e$ rapidly as $k \to \infty$, where the limit satisfies $c(x^e, u^e) = 0$. We typically then have

```
$\lim_{k\to\infty} [-J(x(k+1)) + \tilde{J}(x(k)) - c(x(k), u(k))] = -	ilde{J}(x^e) + \tilde{J}(x^e) - c(x^e, u^e) = 0. \quad (2.54)$
```

It follows that we aren't observing much via the temporal difference (2.52). If $N$ is large, then $\Gamma^c(\tilde{J}) \approx 0$. This essentially destroys any hope for a reliable estimate of the value function. Express another way: a good policy does not lead to sufficient exploration of the state space.

There are many ways to introduce exploration. We can, for example, adapt our criterion as follows: denote by $\Gamma^c(J; x)$ the mean-square loss obtained with $x(0)=x$. Rather than take a very long run, perform many shorter runs, from many $(M > 1)$ initial conditions. The loss function to be minimized is the average

```
$\Gamma^c(J) = \frac{1}{M} \sum_{i=1}^{M} \Gamma^c(J; x^i). \quad (2.55)$
```

The best way to choose the samples $\{x^i\}$ is to topic of research.

Another approach is to let the input explore the exploring. The policy is modified slightly through the introduction of "noise":

```
$u(k) = \phi(x(k), \xi(k)).
```

For example, $\xi(k)$ might be a scalar value, defined as a mixture of sinusoids. The noisy policy is defined so that

+   (i) $\phi(x(k), \xi(k)) \approx \phi^0(x(k))$ for "most $k$."
(ii) The state process "explores." in the policy is designed to avoid convergence of $(x(k), u(k))$ to any limiting value.
