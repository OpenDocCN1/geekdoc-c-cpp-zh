# **2.4 Stability and Performance**

In this section, we consider the state model in a **closed loop**: a policy $\Phi$ is chosen, so that $u(k) = \Phi(x(k))$ for each $k$. Since the feedback law is fixed, the state evolves as a state model without control. With just a slight abuse of notation, we write

```
$x(k+1) = F(x(k)), \quad kgeq 0.$
```

Our interest is in the long-run behavior of the state process; in particular, does it converge to an equilibrium? We also seek bounds on a performance metric called the *total cost*.

The following is assumed throughout:

```
$The state space $X$ is equal to $\mathbb{R}^n$, or a closed subset.$
```

For example, we allow the positive orthant, $X = \mathbb{R}^n$. The restriction on the state space (2.22) is imposed so that any closed and bounded set $S \subset X$ is necessarily a compact subset of $X$. The definition of an equilibrium $x^e$ is straightforward—if it is a state with which the system is frozen:

```
$x^e = F(x^e).$
```

The equilibrium will in fact be a part of the control design. Think of cruise control in your car, where "equilibrium" means traveling in a straight line at constant speed. The particular speed is something that as the driver will choose. The control system then does the best it can keep $x(k)$ near the desired value $x^e$.
