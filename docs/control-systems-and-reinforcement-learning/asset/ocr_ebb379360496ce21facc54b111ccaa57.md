# 9.7 Relative Q-Learning

Proposition 9.17 extends to the relative Q-learning algorithm with a slightly different ODE analysis:

**Proposition 9.20** The ODE$\infty$ for relative Q-learning is obtained using the vector field (9.87) with cost set to zero:

```
\dot{h}_t^\infty(z) = -h_t^\infty(z) + \gamma P_\mu h_t^\infty(x) - \delta(\mu, h_t^\infty), \quad z = (x, u) \in X \times U.
```

The origin is globally asymptotically stable for any choice of $\gamma \in [0, 1]$ and $\delta > 0$.

```
V(\theta) = ||\theta||_p^2 = \frac{1}{2}(\max |\theta_i| - \min |\theta_i|) = \max |\theta_i - r|.
```

Following the steps in the proof of Proposition 9.17, we obtain

```
\dot{V}(h_t^\infty) \leq -(1-\gamma)V(h_t^\infty).
```

Separate arguments show that on $r_t = \langle\mu, h_t^\infty\rangle$, there is $\kappa>0$ such that

```
\dot{r}_t \leq -(1+\delta-\gamma)r_t + \kappa V(h_t^\infty).
```

Given the bound $V(h_t^\infty) \leq e^{-(1-\gamma)V(h_0^\infty)}$, it follows that $r_t \to 0$ exponentially fast as well.

# 9.7.1 Gain Selection

**Lemma 9.18** is more easily extended, which is the first step in a variance analysis:

**Lemma 9.21** Suppose the optimal policy $\phi^*$ is unique. Then the Jacobian $A_h = \partial f(\phi^*)$, with $f$ given in (9.87), is given by

```
A_h = -I + \gamma T^* - \delta 1 \odot \mu. (9.88)
```

Analysis of the eigenvalues is simplified under the following assumption, which is actually a restatement of the assumption that $\pi$ is unique.

The Markov chain with transition matrix $T^*$ is uni-chain: the eigenspace corresponding to the eigenvalue $\lambda=1$ is one dimensional.

Under this assumption, we denote by $[{\lambda}_i]$ the eigenvalues of $T^*$, ordered so that $\lambda_1=1$, and denote

```
\rho^* = \max{\Re(\\lambda_i) : i \geq 2\}, \quad \rho_+^* = \max{\rho^*, 0\}, (9.90a)\n\rho = \max{\{|\lambda_i| : i \geq 2\}. (9.90b)
```

The value $1-\rho$ appeared in Section 6.3, where it was designated the *spectral gap* of the transition matrix.

**Lemma 9.22** The quantities defined in (9.90) satisfy $\rho_+^* \leq \rho$.
