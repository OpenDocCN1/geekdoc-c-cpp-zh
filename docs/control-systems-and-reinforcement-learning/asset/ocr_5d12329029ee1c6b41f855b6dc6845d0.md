# 3.3.3 Finite Horizon

Your choice of discount factor is based on concerned you are with the distant future. Motivation is similar for the horizon formulation: Fix a horizon \mathcal{N} \ge 1, and denote

$J^*(x) = \min_{k=0}^{\mathcal{N}} c(x(k), u(k)), \quad x(0) = x \in \mathcal{X}.$$

This can be interpreted as the total-cost problem (3.2), following two modifications of the state description and the cost function, similar to the SPP:

+   Enlarge the state process to $x^*(k) = (x(k), \tau(k))$, where the second component is "time" plus after: $\tau(k) = \tau(0) + k, \quad k \ge 0$.
Extend the definition of the cost function as follows:

$c^N((x, \tau), u) = \begin{cases} c(x, u) & \tau \le \mathcal{N} \ 0 & \tau > \mathcal{N} \end{cases}$

That is, $c^N((x, \tau), u) = c(x, u)\{\tau \le \mathcal{N}\}$ for all $x, \tau, u$.
If these definitions are clear, then you understand that we have succeeded in the transformation:

$J^*(x) = \min_{k=0} c^a(x^*(k), u(k)), \quad x^a(0) = (x, \tau), \quad \tau = 0.$

However, to write the Bellman equation is necessary to consider all values of $\tau$ (at least $\tau \le \mathcal{N}$), and not just the desired value $\tau=0$. Letting $J^*(x, \tau)$ denote the right-hand side of (3.25) for arbitrary values of $\tau \ge 0$, the Bellman equation becomes

$J^*(x, \tau) = \min\{c(x, u)\{\tau \le \mathcal{N}\} + J^*(F(x, u), \tau + 1)\}.$

The similarity with (3.8) is clear in Exercise 3.5.
