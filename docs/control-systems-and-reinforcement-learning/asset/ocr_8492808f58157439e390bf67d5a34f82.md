# 4.4 Optimization

The so-called dual function is the minimum of the Lagrangian, with constraints removed:

```
$$\varphi^*(\lambda) = \min_{\theta} \mathcal{L}(\theta, \lambda). \quad (4.33)$
```

The value $-\infty$ is possible: Consider what happens when $\Gamma$ is a linear function of $\theta$. For any $\lambda \in \mathbb{R}^m$, we obtain a lower bound on $\Gamma$ as follows:

```
$$\varphi^*(\lambda) \leq \min_{\theta} [\mathcal{L}(\theta, \lambda) : g(\theta) = 0] = \min_{\theta} [\Gamma(\theta) : g(\theta) = 0] = \Gamma^*.,$$
```

where the inequality holds because we have reintroduced the constraints, which means we are minimizing $\mathcal{L}$ over a potentially smaller set. The dual problem is defined to be the maximum of $\varphi^*$ over all $\lambda$:

```
$$\max_{\lambda} \mathcal{L}(\theta, \lambda) = \varphi^*(\lambda) \leq \Gamma^*. \quad (4.34)$
```

We say there is a duality gap if the inequality is strict. The left-hand side is called a min-max (or saddle point) problem. Figure 4.2 shows a typical example of convex optimization without duality gap.

There is a simple ODE to obtain a solution to the saddle point problem (4.34), known as the primal-dual flow:

```
$$\frac{d\theta}{dt} = -\nabla_{\theta} \mathcal{L}(\theta, \lambda) = -\nabla_{\theta} \Gamma(\theta) - [\partial_theta g(\theta)]^T\lambda, \quad (4.35a)\n$\frac{d\lambda}{dt} = \nabla_{\lambda} \mathcal{L}(\theta, \lambda) = g(\theta), \quad (4.35b)$
```

where, under the affine assumption, $[\partial_theta g(\theta)]^T\lambda = D^T\lambda$.

**Proposition 4.11** *Suppose that the following holds: (i) $\Gamma$ is strictly convex and coercive, and (ii) the function $g$ is affine, of the form (4.31), in which $m \times d$ matrix $D$ has rank $m$. Then the primal-dual flow converges to the unique solution $(	heta^*, \lambda^*)$ of the dual: $\mathcal{L}(\theta^*, \lambda^*) = \varphi^*(\lambda^*) = \Gamma^*$.*

The proof can be found in Section 4.8.3. The first step is to exploit convexity to show that $V(\	heta, \lambda) = \frac{1}{2}|\theta - \theta^*||^2 + |\lambda - \lambda^*||^2$ is a Lyapunov function. This part of the proof is very similar to the proof of Proposition 4.7.
