# 7.4 Speed Scaling

**Dynamic speed scaling** in processor uses algorithms that adjust processing speed in response to environment. While initially proposed for processor design [25], the ideas have impacted other application areas such as wireless communication.

Dynamic speed scaling is modeled as an MDP in discrete time, using a variation of the CRW queuing model. For each $k=0,1,2,...,A(k)$ denote the arrivals in this time slot, $X(k)$ the number of jobs in the queue awaiting service, and $U(k)$ the rate of service. The evolution of the state is

```
$X(k+1) = X(k) - U(k) + A(k+1), \quad k \geq 0. \quad (7.32)
```

It is assumed that the arrival process $A$ is i.i.d., so that this forms the dynamic system for an MDP model.

One source of complexity comes from integer constraints on the state and input: each evolve on the non-negative integers $X = U = \mathbb{Z}_+ = \{0,1,2,3...\}$, and the constraint $U(k) \leq x$ is also imposed, so that $U(x) \in \mathbb{Z}_+ : u \leq x.$

The arrival process also evolves in $\mathbb{Z}_+$. The common mean and variance of $A(k)$ are assumed, with mean denoted $\alpha$. Assume moreover that $P\{A(1) > 0\} > 0$. Under this assumption, there is a stationary policy under which $X$ becomes a Markov chain that $x^*$-irreducible with $x^* = 0$ (see 6.57 and surrounding discussion). A simple example is

```
$U(k) = \Phi^k(X(k)) = X(k),$
```
