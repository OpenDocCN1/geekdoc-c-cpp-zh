# 6.7.2 Asymptotic Variance and Mixing Time

The “mixing time” is formally defined as the number of iterations required for the Markov chain to approximately reach its steady-state distribution. This might be formalized with the introduction of $\epsilon > 0$ to quantify “approximately,” and $T(\epsilon) > 0$ denote the minimal time for

> $|P^n(x, A) - \pi(A)| \le \epsilon, \quad 	ext{for all } n \ge T(\epsilon), \quad A \subset X$.

This implies following bound for functions $f: X 	o \mathbb{R}$ satisfying $|f(x)| \le 1$ for all $x$:

> $E_x[f(X(n)) - \pi(f)]| \le 2\epsilon, \quad 	ext{for all } n \ge T(\epsilon)$.

This follows on observing that a function $f$ maximizing the left-hand side can be taken of the form $f^*(x) = 2\mathbb{1}_A-1$ for some $A \in \mathcal{B}(X)$. In the finite state space setting, we can take $A = \{y : P(x, y) \ge \pi(y)\}$.

Remaining in the finite state space setting, it is immediate from Theorem 6.2 and the surrounding discussion that the mixing time will be very large if there is an eigenvalue $\lambda$ of $P$ satisfying $\lambda 
eq 1$ but $|\lambda| \sim 1$. In particular, if $\lambda$ is on the unit circle, such as $|\lambda|=1$, the mixing time is infinite. This is an example of a two-state Markov chain with $X=\{1,2\}$ and transition matrix $P(i,j)=1$ if $i 
eq j$.
