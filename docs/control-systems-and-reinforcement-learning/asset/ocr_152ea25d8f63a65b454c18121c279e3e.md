A key component of the proof of Proposition 4.1 is Gronwall’s Inequality, which commonly appears in the theory of stochastic approximation, as well as ordinary differential equations. Note that Bellman had early influence [34], which is why Proposition 4.2 is often called the Bellman-Gronwall lemma.

**Proposition 4.2 (Gronwall Inequality)** Let $\alpha$, $\beta$ and $z$ be nonnegative functions defined on an interval $[0,T]$, with $T>0$. Assume that $\beta$ and $z$ are continuous, and the integral holds:

```
$z_t \le \alpha_t + \int_0^t \beta_s z_s ds, \quad 0 \le t \le T. \quad (4.6a)$
```

+   (1) The Gronwall Inequality holds:

```
$z_t \le \alpha_t + \int_0^t \alpha_s \exp(\intint_s^t \beta_r dr) ds, \quad 0 \le t \le T. \quad (4.6b)$
```

+   (2) If, in addition, the function $\alpha$ is nondecreasing,

```
$z_t \le \alpha_t \exp(\int_0^t \beta_s ds), \quad 0 \le t \le T. \quad (4.6c)$
```

The proof can be found in Section 4.8, or if you have background in linear state space models, you might want to work it out on your own. First: solve the problem with equality:

```
$z_t = \alpha_t + \int_0^t \beta_s z_s ds. \quad (4.7)$
```

You can construct a state space model, with $x_t = z_t - \alpha_t$, and because it is a linear system you obtain an explicit solution. The solution leads to something like (4.6b), but with equality.

The following simple lemma is frequently required in ODE analysis.

**Lemma 4.3** Suppose that{\{\gamma_t : t \in \mathbb{R}\}$ is a nonnegative function satisfying the following: (i) $|\gamma_t - \gamma_s| \le L|t-s|$ for a constant $L$ and all $t,s$ and (ii) $\int^\infty \gamma_t dt < \infty$. Then, $\lim_{t\to\infty} \gamma_t = 0$.

*Proof* Assumption implies that for any $t_0$ we have the bound $\gamma_t \ge \gamma_{t_0} - L(t-t_0)$ for $t_0 \le t \le t_0+\gamma_{t0}/L$. Combined with (ii), this gives

```
$$\frac{1}{2L} \lim_{t_0\to\infty} \gamma_{t_0}^2 = \lim_{t_0\to\infty} \int_{t_0}^{t_0+\gamma_{t_0}/L} $(\gamma_{t_0} - L(t-t_0)) dt \le \lim_{t_0\to\infty} \int_{t_0}^\infty \gamma_t dt = 0.$
```
