Let's turn to a common approach to RL in which we choose a parameterized family of functions $\{Q^	heta:\theta\in\mathbb{R}^d\}$, and seek among them an approximation to the Q-function $Q^\star$ defined in (3.7a). We frequently use a linear parameterization

```
$Q^	heta(x,u) = \theta^T\psi(x,u), \quad \theta\in\mathbb{R}^d \quad (3.43)$
```

in which $\psi_i:X\times U\to\mathbb{R}$ is the $i$-th basis function, $1\le i\le d$. For any $\theta$, we obtain a policy by mimicking (3.7c):

```
$$\Phi^	heta(x) = \arg\min_u Q^	heta(x,u), \quad x\in X \quad (3.44)$
```

Consider how we might approximate PIA in Section 3.2.2: Given an initial policy $\Phi^0$, generate a sequence of policies $\{\Phi^n\}$ and parameter estimates $\{\theta_n\}$ as follows:

+   (i) Obtain a parameter $\theta_n$ to achieve the approximation $Q^{	heta_n}\approx Q_n$, where the latter is the fixed-policy Q-function that satisfies

```
$Q_n(x,u) = c(x,u) + Q_n(x^+,u^+), \quad x^+=F(x,u), u^+=\Phi^n(x^+)$
```

+   (ii) Define a new policy $\Phi^{	heta+1}=\Phi^	heta$.

```
$Q^\star(x,u) = c(x,u) + Q^\star(F(x,u)), \quad Q^\star(x) = \min_u Q^\star(x,u)$
```

```
$Q^\star(x(k),u(k)) = c(x(k),u(k)) + Q^\star(x(k+1)) \quad (3.46)$
```

