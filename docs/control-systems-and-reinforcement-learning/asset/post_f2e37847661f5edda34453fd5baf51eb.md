## 5.5.2 BCQL and Kernel Methods

Batch methods are featured in this book because they are currently popular with practitioners, and also because kernel methods are anticipated. In this setting, we use no larger than a $d$-dimensional basis. Rather, due to Theorem 5.1 (the Representer Theorem), an effective basis emerges from the observed samples in which the dimension of $\theta$ is equal to the number of observations $N$. In simple examples, the value of $N$ for a reliable estimate may be larger than 1.

Suppose that $\mathcal{H}$ is defined by a RKHS. BCQL #2 is easily adapted to this setting with a change in notation. In particular, we redefine the loss function as (5.67c):

```
$$\Gamma_n^\gamma(Q) = \frac{1}{r_n} \sum_{k=T_n}^{T_{n+1}-1} [\mathcal{D}_{k+1}(Q)]_n$$
$$\mathcal{D}_{k+1}(Q) = -Q(x(k),u(k)) + c(x(k),u(k)) + Q(x(k+1)), \quad Q \in \mathcal{H}.$$
```

```
$\|Q - Q^n\|_{r_n}^2 = \frac{1}{r_n} \sum_{k=T_n}^{T_{n+1}} (Q(x(k),u(k)) - Q^n(x(k),u(k)))^2.$
```

With this regularizer, the Representer Theorem tells us that for each $n$, the optimizer takes the following form: for some $\theta_n \in \mathbb{R}^{r_n}$

```
$Q^n(x,u) = \sum_{i=1}^{r_n} \theta_n^i \mathbf{k}(z_i, z), \quad z = (x,u).$
```
