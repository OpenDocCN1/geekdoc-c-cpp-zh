It is common to employ the Gibbs policy (9.46a) using $G = H^n$;

```
$P(U(n) = u \mid X(n) = x) = \frac{1}{\kappa^n(x)}exp(-H^n(x,u)/\varepsilon), \quad (9.77)$
```

where $\kappa^n$ is a normalizing constant, and $\varepsilon > 0$ is typically concave (fit it may too much upon $n$, possibly vanishing as $n \to \infty$). This is often highly, but avoided in the theoretical development of this chapter. While SA theory has now matured to the point where it can be applied to establish stability of Q-learning with a time-varying policy such as this, there is no space in this book for a proper treatment.

We assume that $U$ is defined using a random Markov process $\phi$, so that $\Phi = \{\Phi(k) \overset{def}{}= X(k), U(k)) : k \ge 0\}$ is a Markov chain. Recall from (9.3b) that its invariant pmf can be expressed as $\varrho(x,u) = \pi(x)\phi(u)$, where $\pi$ is invariant pmf of Markov chain $X$. It is assumed throughout that $X$ is un-chain, so $\pi$ is unique.

Linear independence of the basis is defined by the rank condition $R^\varrho > 0$, with matrix $R^\varrho > 0$ defined in (9.24). For the tabular setting, this reduces to the diagonal matrix, (9.25):

```
$R^\varrho(i,i) = \varrho(x^i,u^i), \quad 1 \le i \le d. \quad (9.78)$
```

It follows that the tabular basis is full rank only if $\varrho(x^i,u^i)$ is nonzero for each $i$.
