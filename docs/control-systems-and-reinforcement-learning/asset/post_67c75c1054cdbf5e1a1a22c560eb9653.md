## 9.6.5 Variance Matters

While stability of Watkins' algorithm is easily established, it should also be clear that the asymptotic convergence of this algorithm is typically slow. To apply the general SA theory, we require the Jacobian of $f$ at $\theta^*$. Existence of a derivative requires more than one:

**Lemma 9.18** Suppose the optimal policy $\phi^*$ is unique. Then the Jacobian $A = \partial f (\theta^*)$, with $f$ given in (9.81), is given by

```
$A = -I + \gamma T^*$
```

where $T^*$ defines the transition matrix for $\Phi$ under the optimal policy:

```
$T^*(i,j) = P_u(x^i, x^j)\mathbb{1}\{u=\phi^*(x^j)\}, \quad 1 \leq i,j \leq d.
```

*Proof* The uniqueness implies that there exists $\varepsilon > 0$ such that whenever $\theta \in \mathbb{R}^d$ satisfies $|\theta - \theta^*| < \varepsilon$,

```
$$\phi^*(x) = \arg \max_{u \in U} H^0(x,u) \quad x \in X.
```

```
$$\bar{f}_i(\theta) = -H^0(x^i, u^i) + \gamma \sum_{x'} P_u(x^i, x') H^0(x', \phi^*(x')), \quad i \geq 1.$$
```

It follows that $\bar{f}$ is linear in a neighborhood of the optimal parameter and

```
$A_{i,j}(0) \frac{\partial}{\partial\theta_j} \bar{f}_i(\theta) = -\frac{\partial}{\partial\theta_j} H^0(x^i, u^i) + \gamma \sum_{x'} P_u(x^i, x') \frac{\partial}{\partial\theta_j} H^0(x', \phi^*(x'))$
```

```
$=-1\mathbb{1}\{i=j\} + \gamma P_u(x^i, x^j)\mathbb{1}\{u=\phi^*(x^j)\}, \quad \text{whenever } |\theta - \theta^*| < \varepsilon. \square$
```

Lemma 9.18 suggests trouble, as $A$ has an eigenvalue at $(1-\gamma)$ with eigenvector $v=1$. It is fortunate that this "worst" eigenvalue is known, so we can design the step-size rule to ensure finite asymptotic covariance $\Sigma_{\theta}$ (as defined in (8.6), with $\rho=1$):

**Proposition 9.19** Suppose that the uniqueness of Lemma 9.18 holds, and the step-size rule is modified: $\alpha_n = \min\{\alpha_0, \alpha_n^*\}$ with $\alpha_0 > 0, g \geq 1/(1-\gamma)$, and $\alpha_n^*$ defined in (9.79). Then $\{\theta_n\}$ is consistent, and the asymptotic covariance of the resulting algorithm is obtained as a solution to the Lyapunov equation (8.28a), where the noise covariance is diagonal,

```
$\Sigma_\Delta(i,i) = \gamma^2 \mathbb{E}[(h^*(X(n+1)) - P_{u^*}(h^*(x'))^2 \mid \Phi], \quad (9.84)
```

$h^*$ is the value function (9.6). Many improvements are possible based on theory in previous sections. Relative TD is easily extended to Q-learning and is far more reliable when $\gamma \sim 1$. This is explained next.
