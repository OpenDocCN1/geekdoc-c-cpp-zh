7.14 Parameter Estimation. In Section 7.8.2, we saw that parameter estimation can be cast as a state estimation problem. The purpose of this exercise is to look at a simpler problem, with the 'exploration' issue set aside.

We are given scalar measurements

```
$Y(k) = \theta + W(k)$,
```

and to obtain $\hat{\theta}$ of $\theta$, based on n observations. If you are told that $\mathbf{W}$ is a zero mean Gaussian, a natural choice is Monte Carlo:

```
$\hat{\theta}_{MC}(n) = \frac{1}{n} \sum_{k=1}^{n} Y(k)$.
```

Suppose that the noise $\mathbf{W}$ is the input of a stable filter. For some $1 \times n$ matrix $G$, and $n \times n$ matrix, we have the following for $k \ge 0$:

```
$Z(k+1) = FZ(k) + N(k+1), \quad W(k) = GZ(k)$.
```

It is assumed that $N$ is Gaussian white noise with marginal $N(0, \Sigma_N)$, and $\theta$ has a known Gaussian distribution that is independent of $N$.

- (a) The MAP estimator of $X$ given observations up to time is $\hat{X}^{MAP}$ using two policies: (i) degenerate and (ii) a policy of your choosing. Plot the true state and its sequence of estimates on the same plot in each, and estimate the mean-square error (MSE). Please use the same random seed for (i) and (ii). To estimate the MSE, you may want to run independent trials with different seeds.
