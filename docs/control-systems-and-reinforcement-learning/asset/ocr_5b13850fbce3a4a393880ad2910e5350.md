Under our assumption that $c$ is nonnegative, the value function is also nonnegative. The following are minimal assumptions to ensure that $J^*$ is finite:

+   (i) There is a target state $x^e$ that is an equilibrium for some $u^e$:

```
$F(x^e, u^e) = x^e$.
```

+   (ii) The cost function $c$ is nonnegative and vanishes at equilibrium, $c(x^e, u^e) = 0$,

+   (iii) For any initial condition $x_0$, there is an input sequence $u_0$ and a time $T^0$ such that with this initial condition and input we have $J^*(x_0) = T^0$.

Condition (iii) is a weak form of controllability. Under these three assumptions, it follows that $J^*(x) < \infty$ for each $x$.

**Example 3.1.1 (Linear Quadratic Regulator)** The Linear Quadratic Regulator problem refers to the class of linear dynamics (2.13), with quadratic cost:

```
$c(x, u) = x^T S x + u^T R$. (3.3)
```

It is always assumed that $S \geq 0$ (positive semidefinite) and $R > 0$ (positive definite). There is one policy for which $J^*$ is finite, the value function is quadratic: $J^*(x) = x^T M^* x$, the optimal policy is obtained by linear state feedback: $\phi^*(x) = -K^*x$ for a matrix $K^*$ of $M^*$. A bit more on this special case is $J^*$ is a function of $x$ and other parameters. In Section 3.6, where will be clear why we impose $R > 0$.

# 3.2 Bellman Equation

Let $x = x(0)$ be an arbitrary initial state, and let $k_m$ be an intermediate time, $0 < k_m < \infty$. We regard $J^*(x(k_m))$ as the cost to go at time $k_m$. This is the total cost over the remaining lifetime of the optimal input-output trajectory.

Based on this interpretation, we obtain following:

```
$J^*(x) = \min_{u_{[0, \infty)}} \left[ \sum_{k=0}^{k_m-1} c(x(k), u(k)) + \sum_{k=k_m}^{\infty} c(x(k), u(k)) \right]
= \min_{u_{[0, k_m]}} \left[ \sum_{k=0}^{k_m-1} c(x(k), u(k)) + \min_{u_{(k_m, \infty)}} \left(\sum c(x(k), u(k))\right)\ \right]
^*(x(k_m))$
```
