
## Proposition 9.1 The optimizer is the value function: $G^* = E[\Phi(n) | X(n)=x] = h(x)$.

The difference $V=Q-h$ is known as the advantage function. The probabilistic implication holds:

$0=E[|V(\Phi(k))-h(X(k)))+c(\Phi(k))+\gamma h(X(k+1))| | \Phi(0), \dots, \Phi(k)].\quad (9.11)$

Any of the TD algorithms can be adapted to approximate a solution, based on a joint parameterization $[V^\theta, h^\theta : 0 \in \mathbb{R}^d]$. Details can be found in Sections 9.5.4 and 10.2, as well as algorithms to approximate the advantage function without joint parameterization. The advantage function used in actor-critic methods is a variance reduction technique, and also because of the following proposition, provides means to compare policies.

## Proposition 9.2 For any two policies $\phi$ and $\psi$, let $h_\phi$ and $h_\psi$ denote the associated value functions on $X$, and $V_\phi$ the advantage function for policy $\phi$. Then,

$h_\phi(x) = h_\phi(x) + E^\phi[\sum_{k=0}^{\infty} \gamma^k V_\phi(\Phi(k)) | X(0)=x] ; \quad x \in X,$

where the superscript indicates that $\Phi(k)$ is the Markov chain chained with policy $\phi$.

Consider for the choice $\phi(x) = \arg\min V_\phi(x)$, which represents the policy improvement step. We then have

$V_\phi(x,\phi(x)) = \min V_\phi(x,u) = -h_\phi(x) + \min Q_\phi(x,u) \le -h_\phi(x) + Q_\phi(x,\phi(x))=0, \ x \in X.$

It follows that $V(\Phi(k)) = V_\Phi(X(k),\Phi(k)) \le 0$ under the policy $\phi$, for any $k \ge 0$. Together with Proposition 9.2, this justifies the policy improvement: $h_\phi(x) \le h_\phi(x)$ for each $x$.

## 9.2 Function Approximation and Smoothing

We first attempt to demystify the conditional expectations appearing in the previous section. It is best to start with an abstraction:

$\tilde{Z} \overset{\text{mean}}{=} E[Z|Y], (9.14)$

where $Z$ and $\tilde{Z}$ are scalar-valued random variables, and $Y$ is a vector-valued random variable. For example, $Y=(X(0),\dots,X(k))$ in (9.8). When convenient to emphasize dependence on $k$, we adopt the notation (7.14):

$E[Z|\mathcal{F}_k] \overset{\text{mean}}{=} E[Z|X(0),\dots,X(k)].$

### 9.2.1 Conditional Expectation and Projection

Subject to the assumption that $E[Z^2] < \infty$, the random variable $\tilde{Z}$ is the solution to a function approximation problem of the form surveyed in Section 5.1: $\tilde{Z} = \phi^*(Y)$, where

$\phi^* = \arg \min_{\phi \in \mathcal{H}} E[(Z - \phi(Y))^2] \quad (9.15)$

and $\mathcal{H}=\{\phi : E[\phi(Y)^2] < \infty\}$. So, keep the following in mind throughout the remainder of the book:

> **Conditional Expectation** The conditional expectation $\tilde{Z}$, given the "data" $Y$, is the minimum-square error estimate of the random variable $Z$ based on these data.

The solution to the optimization problem (9.15) can be characterized geometrically; for a proof of Proposition 9.3, with much more theory and intuition on this topic.

**Proposition 9.3** *A function $\phi^* \in \mathcal{H}$ solves the problem in (9.15) if and only if the orthogonality property holds for each $g \in \mathcal{H}$:*

$0 = E[(Z - \phi^*(Y))g(Y)].$

A valuable corollary to Proposition 9.3 is the smoothing property of conditional expectation. If we have two random vectors $X,Y$, we can take the conditional expectation based on the total data $(X,Y)$ to obtain a better estimate of $Z$ (we have increased the size of the function class (9.15) to all functions of $(x,y)$, the mean-square error cannot be worse). The smoothing property is then the consistency identity,

$E[Z \mid Y] = E[E[Z \mid X,Y] \mid Y]. \quad (9.16)$

Given basis functions $\{\psi_i\}$ defines a finite-dimensional function class $\mathcal{H}=\{\psi_i : i \in \mathbb{R}^d\}$. estimate $\phi^*(Y)$ of $Z$, with $\phi^* \in \mathcal{H}$, is defined by Galerkin relaxation or projection:

- **Galerkin relaxation:** Define a second collection of functions $\mathcal{G}=\{\psi_i : i \in \mathbb{R}^d\}$, and select $\phi^* \in \mathcal{H}$ that solves

$0 = E[(Z - \phi^*(Y))g(Y)], \quad g \in \mathcal{G}. \quad (9.17)$

- **Projection onto $\mathcal{H}$:** Solve the following projection:

$\phi^* \in \arg \min E[(Z - \phi^*(Y))^2]; \quad \phi \in \mathcal{H}. \quad (9.18)$

We write then $E[Z \mid Y] = \phi^*(Y). \quad (9.19)$

Proposition 9.4 implies that the solution to (9.18) is identical to Galerkin relaxation using $\mathcal{G} = \mathcal{H}$. Its proof is similar to (and simpler than) the derivation of (5.4).

## Proposition 9.4 A function $\phi^* = \sum_i \psi_i^*$ solves the minimum in (9.18) if and only if

$0 = E[(Z - \phi^*(Y))g(Y)], \quad g \in \mathcal{H}. \quad (9.20)$

Any solution satisfies $\phi^* = \psi^* \theta^*$,

$R^\psi = E[\psi^* \psi^*], \quad (9.21)$

where $R^\psi$ is a $d \times d$ matrix and $\psi^*$ is a $d$-dimensional vector, with entries

$R_{ij}^\psi = E[\psi_i(Y)\psi_j(Y)], \quad \psi_i^* = E[Z \mid Y]. \quad (9.22)$

Consequently, if $R^\psi$ is full rank, then $\theta^* = [R^\psi]^{-1}\psi^*$ is the unique solution.
