## 5.4.2 TD($\lambda$)-Learning

The fixed point equation (5.27) is one of the (5.38): Define for any function $h: X \times U \to \mathbb{R}$,

```
$T(h)|_{(x,u)} = c(x,u) + h(x,u^+), \quad x^+ = F(x,u), \quad u^+ = \Phi(x^+)$
```

so that $Q^\theta = T(Q^\theta)$.

Galerkin relaxation leads to only the most celebrated RL algorithms. Consider specification of $h$ as a finite-dimensional function class $\{h = \theta^\top\psi : \theta \in \mathbb{R}^d\}$, $\psi_i: X \times U \to \mathbb{R}$ for each $i$. We arrive at the projected Bellman equation by applying the approximation (5.39) to its current form (5.44): For each $i$,

```
$0 = E\langle\zeta_i(k)(h(x(k),u(k)) - c(x(k),u(k)) + h(x(k+1),\phi(x(k+1))))\rangle$
```

where we have used definition of the inner product, along with the notation $\zeta(k) = \zeta(\Phi(k))$. The solution of this root-finding problem defines the projected Bellman equation $Q^\theta \in \mathcal{H}$.

Recalling the definition (5.29), the projected Bellman equation is equivalently expressed

```
$0 = E\langle\zeta(k)D_k + 1(Q^\theta)\rangle_{\theta=\theta}.$ (5.45)
```

Given $N$ observations, an approximation is

```
$0 = \frac{1}{N} \sum_{k=0}^{N-1} \zeta(k)D_k + 1(Q^\theta)\rangle_{\theta=\theta}.$ (5.46)
```

which is precisely the form of (5.12).

We can now define the meaning of “$\lambda$” in TD($\lambda$) learning, which depends entirely on the choice of $\gamma$. To keep more compact, dense

```
$$\psi_{(k)} \stackrel{\text{def}}{=} \psi(x(k),u(k)), \quad c_k \stackrel{\text{def}}{=} c(x(k),u(k)), \quad k \geq 0.$$ (5.47)
```

and when possible use $\zeta_k$ instead of $\zeta(k)$ for the eligibility vector, and we denote $Q^\theta_\phi(x) = Q^\theta(x,\Phi(x))$.

## 5.4 Projected Bellman Equations and TD Algorithms

### TD($\lambda$) Learning

For a given $\lambda \in [0,1]$, nonnegative step-size sequence $\{\alpha_n\}$, initial conditions $\theta_0, \zeta_0$, and observed samples $\{u(k),x(k) : 0 \leq k \leq N\}$, the sequence of estimates is defined by the coupled equations:

```
$$\theta_{n+1} = \theta_n + \alpha_n\mathcal{D}_n\zeta_n,$$
\mathcal{D}_{n+1}(Q) = -Q^{\theta_n}(\psi(n),u(n)) + c_n + Q^*(x(n+1)),$$
\zeta_{n+1} = \zeta_n + \psi(n+1)).$$
```

This defines the approximation of the Q-function $Q^{\theta^N} = \sum_i \theta_N(i)\psi_i$.

For the purposes of analysis, we require an extension of the state process:

```
$$\Phi(k) = \langle x(k),u(k),\zeta(k)\rangle.$$
```

so that $f_{\lambda}(\theta)$ is a linear function of $\Phi(k)$. Denote $f_{\lambda}(\theta) = E_{\theta}[\zeta(k)\mathcal{D}_k+1(Q^{\theta})]$. TD($\lambda$) is an approximation of the ODE

```
$$\frac{d\theta}{dt} = f_{\lambda}(\theta).
```

The right-hand side is linear: $f_{\lambda}(\theta) = A(\theta-\theta^*)$, in which

```
$A = E_{\theta}[\zeta(k)]-\psi(k)+\psi(k+1)].$
```

Convergence of TD($\lambda$) learning is not guaranteed in the policy-offset setting, with $\lambda=0$. A famous example is described after Figure 5.5. What about neural networks? ### Unstable Dynamics with Perfect Exploration

Figure 5.5 shows Baird's counterexample, which provides an example of instability using TD($\lambda$). There are six states and no control, with which the state remains at $x(k)=7$ for all $k \ge 1$. $Q^*(x,u) = h^*(x) = 0$ for each $x$. Note that $\theta'$ denotes the $i$th index of $\theta$. The example violates two conventions in this chapter:

- (i) $\psi(x) = (0, \dots, 2)^T = 0$ with $x^*=7$ is violated.
- (ii) If there are only states, then the basis is essential. This implies that the sample correlation matrix (5.19) is never full, for any value of $N$.

The degenerate correlation matrix is not such a concern, since $h^0 = h^*$ and $\mathcal{D}_{n+1}^0 = 0$ for all $n$ with $\theta^0=0$. Rank degeneracy implies that $\theta'$ is not unique.

The example was introduced in the discounted cost setting, with discount factor $\gamma \le 1$. This is maintained here, and because there is no control we use value function to define the temporal difference:

```
$\mathcal{D}_{n+1}^0 = -h^0(n) + \gamma h(n+1) = -h^0(n) + \gamma h(7),$
```

where the second equality holds because of the trivial definitions. The definition of eligibility method is slightly modified in the discounted setting:

```
$\zeta_{n+1} = \lambda\zeta_n + \psi(n+1).$$
```

Perfect exploration is based on a version of restart, in which each episode allows only one transition, and each of seven states is sampled uniformly. A periodic implementation is described as follows: for $n=0, 1, \dots, 6$, choose $x(n)=n+1$ and obtain

```
$\mathcal{D}_{n+1} = -h(n+1) + \gamma h(n).
```

where $\{\theta_n\}$ are updated using TD($\lambda$); $\theta_{n+1} = \theta_n + \alpha_n\mathcal{D}_{n+1}\zeta_n$. This procedure is repeated that $x(n)-1 \equiv n \pmod 7$ for all $n \ge 1$.

The algorithm converges for $\gamma \le 1$ sufficiently large and some initial conditions (under which standing assumption that $\sum \alpha_n = \infty$). To see this closer look at the difference:

```
$\mathcal{D}_{n+1} = \begin{cases} -[\theta_n^0 + 2\theta_n^1] + \gamma[2\theta_n^0 + \theta_n^1] & x(n)=k \le 6 \\ -[\theta_n^0 + \theta_n^1] + \gamma[2\theta_n^0 + \theta_n^1] & x(n)=7 \end{cases}$
```

The source of instability is revealed by looking at the last of the six parameter:

```
$\theta_{n+1}^0 = \theta_n^0 + \begin{cases} \alpha_{n+1}\{(2-1)\theta_n^0 + \gamma\theta_n^0 - 2\theta_n^1\}\zeta_n^0 & x(n)=k \le 6 \\ \alpha_{n+1}\{(1-\gamma)[2\theta_n^0 + \theta_n^1]\}\zeta_n^0 & x(n)=7 \end{cases}
```

Suppose that $\gamma > \frac{1}{2}$ and $\theta_0^0 > 0$ is large relative to the other parameters. Whenever $x(n)\le 6$, the estimate $\theta_{n+1}^0$ tends to increase, because of the positive coefficient $(2\gamma-1)$.
