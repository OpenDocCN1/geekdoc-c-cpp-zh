The discounted shortest path (SPP) is defined to be the minimal discounted cost
incurred before this time:

```
$J^*(x) = \min_{k=0}^{	au_A-1} \gamma^k c(x(k),u(k)), \quad x(0) = x. \quad (3.22)$
```

**Proposition 3.6** If $J^*$ is finite valued, then it is the solution to the DP equation:

```
$J^*(x) = \min \{c(x,u) + \gamma^1(F(x,u) \in A^c)\}, \quad x \in X. \quad (3.23)$
```

*Proof* As in the total cost problem

```
$J^*(x) = \min \{c(x,u(0)) + \sum_{k=1}^{	au_A-1} \gamma^k c(x(k),u(k))\},$
```

with the understanding that $\sum_{k=1}^{	au_A-1} 0=0$: The upper limit is equal to 0 when $\tau_A=1$ (equivalently, $x(1) \in A$). Consequently,

```
$J^*(x) = \min_{u(0)} \{c(x,u(0)) + \gamma^1\{x(1) \in A^c\} \min_{u_{[1,\infty))}} \sum_{k=1}^{	au_A-1} \gamma^{k-1} c(x(k),u(k))\}\n= \min_{u(0)} \{c(x,u(0)) + \gamma^1\{x(1) \in A^c\} J^*(x^*(1))\}, \quad x(1) = F(x,u(0))\n= \min \{c(x,u) + \gamma^1\{F(x,u) \in A^c\} J^*(F(x,u))\}$
```

For the purposes of using the control techniques, it is possible to recast (3.22) as an instance of the total cost problem (3.21). This requires the definition of a new state $x^a$ with dynamics $F^a$, and a new cost $c^a$ defined as:

+   (i) Modified state dynamics: $F^a(x,u) = \begin{cases} F(x,u) & x \in A^c \ x & x \in A \end{cases}$

so that $x^a(k+1) = x^a(k)$ if $x^a(k) \in A$ (a called guardset for the control system).

+   (ii) Modified cost: $c^a(x,u) = \begin{cases} c(x,u) & x \in A^c \ 0 & x \in A \end{cases}$

From these definitions, it follows that the value function (3.22) can be expressed as as:

```
$J^*(x) = \min_{k=0}^{\infty} \gamma^k c^a(x^a(k),u(k)), \quad x \in A^c.$
```

**3.3.1 (Mountain Car)** Recall the Mountain Car example is a shortest path problem: to reach the goal in minimal time. Let $c(x,u)=1$ for all $u$, with $x \neq z^{goal}$, and $c(z^{goal},u)=0$ for any $u$. The SPP can be expressed as a total cost-optimal control problem based on the model and this control system. The optimal cost (3,5) is finite for each initial condition, and the Bellman equation (3,5) becomes

```
$J^*(x) = 1+\min_u J^*(F(x,u)), \quad x_1 < z^{goal}$
```

and $J^*(z^{goal},x_2) = 0$ for any value of $x_2$.
