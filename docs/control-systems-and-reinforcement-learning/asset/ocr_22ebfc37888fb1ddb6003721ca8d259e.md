# 4.4 Optimization

Here we turn to minimization of a loss function $\GammaGamma \mathbb{R}^d \to \mathbb{R}_+$, for which we would like to compute a global minimum:

```
$$\vartheta^* \in \arg\min \Gamma(\theta).$.
```

This section contains a brief survey of optimization and ODE techniques to estimate $\vartheta^*$. In particular, we establish conditions under which the steepest-ODE exists converges:

```
$\frac{d\theta}{dt} = -\nabla\Gamma(\theta).$ (4.20)
```

This is also known as the *gradient flow*.

Recall that the gradient $
abla\Gamma$ at a vector $	heta_0 \in \mathbb{R}^d$ is orthogonal to the level set $\{\theta \in \mathbb{R}^d : \Gamma(\theta) = \Gamma(\theta_0)\}$, in the sense illustrated in Figure 4.1. For a given time $t_0$, denote $\theta_0 = \vartheta_{t_0}, r_0 = \Gamma(\theta_0)$, and recall from (2.28) the definition of the level set is

```
$S_Gamma(r_0) = \{\theta \in \mathbb{R}^d : \Gamma(\theta) \le r_0}.
```

If the gradient at $\theta_0$ is nonzero, in the example shown, the gradient flow drives the solution into the interior of this set: $\Gamma(\vartheta_t) < r_0$ for all $t > t_0$. In particular, each sublevel is **absorbing**; once a solution to the gradient flow enters the set $S_Gamma(r_0)$, it can never leave.
