# 7.2 Fluid Models for Approximation

In the remainder of this subsection, we show how to interpret the MVT with J = J* equal to the total-cost value function for the deterministic fluid model. It will be useful to impose a Lipschitz bound on the gradient: For a Lipschitz constraint $L > 0$,

```
$|\nabla J(x') - \nabla J(x)|| \le L|x' - x|, \quad x,x' \in X.\ \quad (7.21)$
```

# Fluid Model in Discrete Time

Let's first consider the total-cost value function $J^*$ associated with the (deterministic) fluid model (7.17). This satisfies the DP equation

```
$J^*(x) = \min\{c(x,u) + J^*(\bar{F}(x,u))},\ \quad (7.22)$
```

Apply the MVT (7.20) using

```
$x' = X(k+1) \quad \text{and} \quad x = \bar{F}(x,u) \overset{\text{def}}{=} E[X(k+1) | X(k)=x, U(k)=u].$
```

This gives, for any continuously differentiable function $J$,

```
$J(X(k+1)) = J(\bar{F}(x,u)) + \nabla J(\bar{F}(x,u)) \cdot \bar{X}(k+1) \quad (7.23)\n\bar{X}(k+1) \overset{\text{def}}{=} X(k+1) - \bar{F}(x,u),
```

where $ar{X} = qX(k+1) + (1-q)\bar{F}(x,u)$, with $q$ a random variable taking in the interval [0,1].

Lemma 7.2 provides a link between deterministic and stochastic programming equations. Denote

```
$$\eta(k+1) = \{
abla J(\bar{X}) - \nabla J(\bar{F}(x,u))}\ \cdot \bar{X}(k+1).$
```

We have $X - \bar{F}(x,u) = q\bar{X}(k+1)$, to show, that (7.21) implies the bound on $\eta$ given in (7.24a).

**Lemma 7.2** $J: X \to \mathbb{R}$ is differentiable, and its gradient satisfies the Lipschitz bound (7.21). The following approximation holds for each: $k$: Letting $\eta = X(k)$ and $u = U(k)$,

```
$J(X(k+1)) = J(\bar{F}(x,u)) + \nabla J(\bar{F}(x,u)) \cdot \bar{X}(k+1) + \eta(k+1), \n|\eta(k+1)| \le L|\bar{X}(k)||^2.\ \quad (7.24a)$
```

Consequently, for any $x,u$, and $k$, in the notation of (7.15),

```
$P_u J(x) = J(\bar{F}(x,u)) | X(k)=x, U(k)=u \n\eta(x,u) = E[\eta(k+1) | X(k)=x] \n= E[J(X(k+1)) | X(k)=x, U(k)=u] - \bar{F}(x,u)].\ \quad (7.24b)$
```

The function $\eta$ can be expressed in the more compact notation

```
$$\eta(x,u) = P_u J(x) - \bar{F}(x,u)$.$
```
