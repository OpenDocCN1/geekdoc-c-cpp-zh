# 8.7 Some Theory

It's difficult to prove that two of the other terms should be relatively small:

+   (i) $E_f(	heta_n^f) = O(\|	heta_n^f - 	heta^*\|^2)$ when $f$ is smooth.
(ii) We can only expect $\Delta_{n+1} - \Delta_n^\infty = O(\|	heta_n^f - 	heta^*\|)$ (without the square). It is the sum $S_N^f$ that is small (compared to $M_N$) under (SA2).

It is a simple miracle that $\{S_N^f\}$ is small relative to $\{M_N^\infty\}$, given their very similar definitions. Bounds on $\{S_N^f\}$ are made possible by order representation, by rearranging the terms in the bounds (8.10a):

```
$f_{n+1}(	heta_n^f) = \frac{1}{eta_{n+1}}[	heta_{n+1}^f - 	heta_n^f], \quad (8.76)$
```

with $\theta_n^f = \theta_n' - \theta^*$. A useful representation for the sum is obtained using this simple transformation:

**Lemma 8.2 (Summation by Parts)** For any two real-valued sequences $\{x_n, y_n : n \geq 0\}$ and integers $0 \leq N_0 < N$,

```
$$\sum_{n=N_0+1}^N x_n(y_n - y_{n-1}) = x_N y_N - x_{N_0} y_{N_0} - \sum_{n=N_0+1}^N (x_{n+1} - x_n)y_n$.$
```

Consequently,

```
$S_N^f = \sum_{n=N_0+1}^N \frac{1}{\beta_n}[\theta_{n+1}^f - \theta_n^f] \n= \frac{1}{\beta_{N_0}}\theta_{N_0}^f - \frac{1}{\beta_N}}\theta_N^f - \sum_{n=N_0+1}^N (\frac{1}{\beta_n} - \frac{1}{\beta_{n+1}})\theta_n^f., \quad (8.77)$
```

The assumptions in the following discussion imply strong bounds on each term.
