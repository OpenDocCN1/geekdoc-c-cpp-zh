# # Value Function Approximations

We have now all the preliminaries necessary to describe reinforcement learning algorithms designed for value functions denoted $\mathcal{H}$.

The approximation techniques are built around a family of functions, Standard examples examples discussed in Section 5.1 include neural networks and kernels, as well as linear approximation using a basis (an example of this can be found in Section 4.5.3). In most cases, the function class is finite dimensional, with dimension $d$. For example, to approximate the $Q$-function $Q^*$ defined in (3.7a), the family is denoted $\{Q^	heta : \theta \in \mathbb{R}^d\}$.

Most algorithms are based on optimization: An algorithm to compute the optimal parameter $	heta^*$ will be based on some loss function $\Gamma(\theta)$, with $\theta^* = \arg min \Gamma(\theta)$. The algorithm may be recursive, in which it generates a sequence of parameter $\{\theta_n\}$, so that $\theta_n \to \theta^*$ as $n \to \infty$. It should come as no surprise that Chapter 4 will guide algorithm design.

Reinforcement learning algorithms are typically designed to be model free, with the inputs to the algorithm consist of three terms: $\{u(k)\}$ the input sequence to the control system, the sequence of observed costs $c(x(k),u(k))$, and observed features that depend on the class of algorithms. For the linear parameterization $Q^	heta(x,u) = \sum \theta_i \psi_i(x,u)$, the features is the $d$-dimensional sequence $\{\psi(x(k))\}$.

Figure 5.1 is included to emphasize that the these are the only inputs to the algorithm. We don't require a model, and the state sequence $\{x(k)\}$ may not be fully observed. For any approximation $Q^	heta$, we define a policy by optimal control theory (in particular, (3.7c)):

```
$$\Phi^	heta(x) = \arg min_u Q^	heta(x,u), \quad x \in X.$ (5.1)
```

In standard textbooks, there is a two-step process: (1) identify a model, such as the ARMA model (2.4) and (2) design a control solution based on this model (perhaps through optimal control techniques). Step (2) is often a significant computational challenge. One of the greatest challenges of RL is to sidestep this challenge by estimating the Q-function directly.

System identification and value function approximation share common challenges and remedies. The method of exploration that is so important in this chapter is entirely analogous to the persistence of excitation requirement in system identification [80, 297, 293].
