# 6.4 A Random Glance Ahead

For the linear space model, the M/M/1 queue, and for finite state Markov chains, we identified conditions under which a limiting probability measure $\pi$ satisfying (6.6): For each state $x \in X$ and $S \in \mathcal{B}(X)$,

> $$\lim_{k\to\infty} P^k(x,S) = \pi(S).$$

The limit $\pi$ is invariant, and in state one says

> $$\int_X(dx)\pi^k(x,S) = \pi(S), \quad S \in \mathcal{B}(X), k \ge 1.$$

That is, $\pi^k = \pi$. Conditions for the existence of an invariant measure on an infinite state space will be surveyed later in the chapter, with far stronger ergodic theorems.
The existence of an invariant measure is equivalent to the existence of a steady-state realization of the process $X$. The state process satisfies the stationarity property:
P\{X(k) \in A_0, X(k+1) \in A_1, \dots, X(k+m) \in A_n\}$ is independent of $k \ge 0$, for any $m \ge 0$ and any sequence of sets $\{A_0, \dots, A_m\}$, each in $\mathcal{B}(X)$. Naturally, the stationary realization satisfies $X(k) \sim \pi$ for each $k$. While we don't expect to encounter true stationarity in the real world, this idealism is helpful for conceptualizing and analyzing algorithms.
