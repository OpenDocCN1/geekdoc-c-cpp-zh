# 4.5 Quasistochastic Approximation

The following assumptions are imposed throughout the remainder of the chapter:

(QSA1) The function $a$ is nonnegative, monotonically decreasing, and

```
$$\lim_{t\to\infty} a_t = 0, \quad \int_{0}^{\infty} a_r dr = \infty. \quad (4.81)$
```

(QSA2) The functions $f$ and $f$ are Lipschitz continuous: for a constant $L_f < \infty$,

```
$||f'(\theta) - f(z)|| \le L_f ||\theta - z|$\n$||f'(\theta) - f(\theta')|| \le L_f ||\theta' - \theta'||, \quad \theta, \theta' \in \mathbb{R}^d, z \in \Omega.$
```

There exists a Lipschitz continuous function $b_0: \mathbb{R}^d \to \mathbb{R}_+$, such that for all $\theta \in \mathbb{R}^d$

```
$|\int_{t_0}^{t_1} f_t(\theta)dt|| \le b_0(0), \quad 0 \le t_0 \le t_1, \quad \text{where} \tilde{f}_t(\theta) = f(\theta, \Xi_t) - \tilde{f}(0). \quad (4.82)$
```

(QSA3) The ODE (4.42) has a globally asymptotically stable equilibrium $\^*$.

The Lipschitz conditions on $\tilde{f}$ and $f$ in (QSA2) are what you would expect if you have been exposed to theory for stochastic approximation. General conditions on both $f$ and $\ell$ for the ergodic bound (4.82) are given in Lemma 4.37.

A assumption is that the QSA ODE is ultimately bounded in the following sense: there exists $b < \infty$ such that for all $\theta \in \mathbb{R}^d$ and $z \in \Omega$, there is a $T_{\theta,z}$ such that

```
$||\Theta_	au|| \le b \quad \text{for all } \tau \ge T_{\theta,z}, \quad \hat{\Theta}_0 = \theta, \Xi_0 = z. \quad (4.83)$
```

Verification of ultimate boundedness is the subject of Section 4.9.3. For example, (4.83) can be established using a Lyapunov drift condition similar to (2.39).

The proof of Theorem 4.15 is also found in Section 4.9.

**Theorem 4.15 (Boundedness Implies Convergence)** Suppose that (QSA1)-(QSA3) hold, along with the ultimate boundedness assumption (4.83). Then the solution to (4.44) converges to $	heta^*$ for each initial condition.

# Coupling

The partial integrals play a central role when we turn to rates of convergence: For $\theta \in \mathbb{R}^d$ and $T \ge 0$,

```
$$\Xi_T(\theta) = \int_{0}^{T} f_t(\theta)dt. \quad (4.84)$
```

This is a bounded function of $T$ under (QSA2) (recall (4.82)). The coupling to be established is expressed as the limit,

```
$$\lim_{t\to\infty} ||Z_t - \Xi(\theta^*)|| = 0. \quad (4.85)$
```

This implies precise bounds on the rate of convergence of $\Theta_t$ to $	heta^*$, by the definition (4.72),

```
$$\Theta_t = \theta^* + a_t Z_t.$
```
