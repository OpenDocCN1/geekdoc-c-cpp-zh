This intuition is the starting point toward finding conditions under which the gradient flow is convergent using Lyapunov functions. Two typical choices for a Lyapunov function are

```
$V(\theta)=\frac{1}{2}|\theta-\theta^*|^2\quad\text{or}\quad V(\theta)=\frac{1}{2}|\Gamma(\theta)-\Gamma^*|^2,\(4.21)$
```

where $\theta^*=\min_{\theta}\Gamma(\theta)$. The latter is most natural, based on the intuition obtained from this figure and Figure 2.6.

The Polyak–Łojaziewicz (PL) condition considered in Section 4.4.2 is one minimal criterion for convergence. When we are ready to approximate the gradient flow using an Euler approximation, it is standard to follow the $L$-smooth condition: for $L>0$, and all $\theta_0$,

```
$$\Gamma(\theta) \geq \Gamma(\theta^*)+[\theta-\theta^*]^T\nabla\Gamma(\theta)+\frac{L}{2}|\theta-\theta^*|^2.\(4.22)$
```

The usefulness of this bound is explained in Section 4.4.3.

Please not feel free to prove a theorem before you experiment: the algorithms we obtain are frequently successful in practice, even when our assumptions are violated. For example, the optimization problems presented here, in training neural networks do not satisfy any of the assumptions listed, but practitioners commonly apply the gradient descent algorithm described in Section 4.4.3, which is nothing but a Euler approximation of the gradient flow.

### 4.4.1 Role of Convexity

The term has come up in discussion in preceding chapters, but now requires a formal definition:

### Convexity

- A set $S \subset \mathbb{R}^d$ is convex if it contains, all line segments with endpoints in $S$. That is, $(1-\alpha)\theta^0+\alpha\theta^1 \in S$ for $\theta^0,\theta^1 \in S$ and any $\alpha \in (0,1)$.
- A function $\Gamma: S \to \mathbb{R}$, with convex domain $S$, is called convex if the following bound holds: For any pair $\theta^0,\theta^1 \in S$ and $\rho \in (0,1)$:

```
$$\Gamma((1-\rho)\theta^0+\rho\theta^1) \leq (1-\rho)\Gamma(\theta^0)+\rho\Gamma(\theta^1).\quad(4.23)$
```

It is quasiconvex if the sublevel set $S_{\Gamma}(r)$ is convex (or empty) for any $r \in \mathbb{R}$.

A convex function is always quasi-convex, with $S = \mathbb{R}$, any nondecreasing function is quasiconvex, since in this case $S_{\Gamma}(r) = (-\infty, a(r))$ for each $r$, where $a(r) = \max{\theta : \Gamma(\theta) \leq r\}$ (continuity is not required to ensure quasiconvexity, but is required to arrive at this representation for the sublevel).

The following characterization has a stronger generic:

**Lemma 4.5** For any convex set $S$, $\Gamma: S \to \mathbb{R}$ is $convex$ if and only if for each $\theta^0 \in \mathbb{R}^d$, there is a vector $v^0 \in \mathbb{R}^d$ satisfying

```
$$\Gamma(\theta) \geq \Gamma(\theta^0) + \langle v^0, \theta - \theta^0\rangle, \quad \quad \text{for all } \theta \in S.\ \quad (4.24)$
```

The right-hand side of (4.24) is regarded as an affine function of $\theta$, and the bound means that the graph of $\Gamma$ is always above the graph of the affine function. The vector $v^0$ is called a subgradient. If $\Gamma$ is differentiable at $\theta^0$, then it is unique $v^0 = \nabla\Gamma(\theta^0)$.

There are also several conditions:

- The $\Gamma$ is *strictly convex* if the inequality (4.23) is strict when $\theta^1 \neq \theta^0$.
- If $\Gamma$ is differentiable, then it is strongly convex for a constant $\delta_0 > 0$,

```
$$\nabla\Gamma(\theta) - \nabla\Gamma(\theta^0), \theta - \theta^0\rangle \geq \delta_0|\theta - \theta^0||^2\quad \quad \text{for all } \theta^0 \in \mathbb{R}^d.\quad \ (4.25)$
```

Strong convexity is used to establish nice numerical properties of the gradient flow. The value of convexity and strong convexity is clear in the following:

**Proposition 4.6** Suppose that $\Gamma: \mathbb{R}^d \to \mathbb{R}_+$ is $convex$. Then, for given $\theta^0 \in \mathbb{R}^d$,

- (i) if $\theta^0$ is a local minimum, then it is a global minimum;
- (ii) if $\Gamma$ is differentiable at $\theta^0$, with $\nabla\Gamma(\theta^0) = 0$, then $\theta^0$ is a global minimum;
- (iii) if either of (i) or (ii) holds, or if $\Gamma$ is strictly convex, then $\theta^0$ is the unique minimum.

The gradient flow converges under mild conditions. See Exercise 4.7 for generalization.

**Proposition 4.7** Suppose that $\Gamma$ is continuously differentiable, convex, and coercive, with unique minimizer $\theta^0$. Then the gradient flow (4.20) is globally asymptotically, with unique equilibrium $\theta^0$. If $\Gamma$ is strongly convex, then the rate of convergence is exponential:

```
$|\theta_t - \theta^0|| \leq e^{-\delta_0 t}|\theta_0||.\quad (4.26)$
```

where $\delta_0$ appears in (25). Proof We adopt a Lyapunov function using $V(\theta) = \frac{1}{2}|\theta - \theta^0|^2$. From the chain rule,

```
$$\frac{d}{dt}V(\theta_t) = \langle\nabla\Gamma(\theta_t), \theta_t - \theta^0\rangle.$$
```

Convexity implies that $\Gamma(\theta^0) \geq \Gamma(\theta_t) + \langle\nabla\Gamma(\theta_t), \theta_t - \theta^0\rangle$, giving

```
$$\frac{d}{dt}V(\theta_t) \leq -[\Gamma(\theta_t) - \Gamma(\theta^0)] \leq 0,$$
```

where the inequality is strict when $\theta_t \neq \theta^0$. Proposition 2.5 then implies global stability.

Under strong convexity, we have $\nabla\Gamma(\theta^*) = 0$ to obtain the stronger bound:

```
$$\frac{d}{dt}V(\theta_t) = -\langle\nabla\Gamma(\theta_t) - \nabla\Gamma(\theta^*), \theta_t - \theta^* \rangle \leq -\delta_0|\theta_t - \theta^*\|^2.$$
```

That is, $V(\theta_t) \leq -2\delta_0 V(\theta_t)$. This implies that $V(\theta_t) \leq V(\theta_0)\exp(-2\delta_0 t)$ for any $t$, which establishes (4.26).

### 4.4.2 Polyak-Lojasiewicz Condition

The use of the Euclidean norm to define a Lyapunov function in Proposition 4.7 relied heavily on convexity. An alternative is using the Polyak-Lojasiewicz (PL) inequality: For $\mu > 0$ and all $\theta$,

```
$$\frac{1}{2}|\nabla\Gamma(\theta)\|^2 \geq \mu|\Gamma(\theta) - \Gamma^*. (4.27)$
```

We do not assume here that $\Gamma$ is convex, or that there is a unique optimizer $\theta_{\infty}$.

**Theorem 4.8** If the PL inequality holds, then the gradient flow satisfies, for each initial $\theta_0$:

```
$$\Gamma(\theta_t) - \Gamma^* \leq e^{-mt}|\Gamma(\theta_0) - \Gamma^*.$$
```

If $\Gamma$ is coercive, then the solutions are bounded, and any limit point $\theta_{\infty}$ of $\{\theta_t\}$ is an optimizer: $V(\theta_{\infty}) = \Gamma^*$.

Proof We adopt the second option in (4.21) for a Lyapunov function:

```
$$V(\theta_t) = \frac{1}{2}|\Gamma(\theta_t) - \Gamma^*| \implies -\frac{1}{2}|\nabla\Gamma(\theta_t)\|^2 \leq -\mu V(\theta_t).$$
```

This implies the desired $\Gamma(\theta_t) - \Gamma^* = V(\theta_t) \leq e^{-mt}V(\theta_0)$.

If $\Gamma$ is coercive, trajectories of $\theta$ evolve in the set $S = \{\theta : V(\theta) \leq V(\theta_0)\}$. If $\theta_{\infty}$ is a limit point, then $\theta_{\infty} = \lim_{n\to\infty} \theta_n$, with $t_n \to \infty$. Continuity of the loss function then implies optimality: $\Gamma(\theta_{\infty}) = \Gamma^*$.

### 4.4.3 Euler Approximation

The Standard Euler approximation of the gradient flow (4.20) is known as steepest descent:

```
$$\theta_{k+1} = \theta_k - \alpha\nabla\Gamma(\theta_k). (4.28)$$
```

To convergence from each initial condition, we suppose that the objective function is $L$-smooth (recall (4.22)). This is one of two crucial bounds in the proof of the following cousin of Theorem 4.8:

**Theorem 4.9** Suppose that $\Gamma$ satisfies two bounds: the $L$-smooth inequality (4.22), and the PL inequality (4.27). Provided, provide the following bounds for (4.28):

```
$$\Gamma(\theta_k) - \Gamma^* \leq (1 - \alpha\mu)^k|\Gamma(\theta_0) - \Gamma^*.$$
```

Proof The $L$-smooth inequality applied to the gradient descent (4.28) gives

```
$$\Gamma(\theta_{k+1}) - \Gamma(\theta_k) \leq [\theta_{k+1} - \theta_k]^T\nabla\Gamma(\theta_k) + \frac{L}{2}|\theta_{k+1} - \theta_k\|^2 = (-\alpha + \frac{L}{2}\alpha^2)|\Gamma(\theta_k) - \Gamma^*\|^2.$$
```
