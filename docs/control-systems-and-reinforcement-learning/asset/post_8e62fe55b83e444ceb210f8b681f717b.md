## 2.4.1 Total Cost

This performance metric is based on a function $c: X \rightarrow \mathbb{R}_+$, interpreted as the “cost function under policy $\phi$,” to be considered in greater depth in Chapter 3. But then we arrive at a reason with unambiguous definition: the total cost of $x$, known as the (fixed policy) value function, and defined as the infinite sum:

```
$J(x) = \sum_{k=0}^{\infty} c(k), \quad x(0) = x \in X. \qquad (2.24)
```

It is assumed that $c(x^e) = 0$, and we seek conditions that $x(k) \rightarrow x^e$ as $k \rightarrow \infty$, so there is hope that $J$ is finite valued. For the cruise control problem, the cost function is designed that $c(x)$ is large if the state $x$ corresponds to a state that is far from desired.

**Why is the Controls Community So Excited about Total Cost?** This metric for performance is not intuitive, but there are compelling reasons for using it as a performance metric in control design:

- (i) "forward looking." One might argue that (2.24) is looking too forward (who cares about infinity?), but there is implied "discounting" of the future for a good policy we have $c(k) \rightarrow 0$ as $k \rightarrow \infty$.
- (ii) Theory for total cost optimal control is often closely related to average optimal control – to be seen in Part II of the book.
- (iii) If $J$ is finite valued, then stability is typically guaranteed.

Benefit is the most abstract, but the most valuable aspect of this performance metric. Section 2.4.2 is dedicated to showing stability and its relationship to value functions. A part of this theory is based on the (fixed policy) dynamic programming equation$^4$

```
$J(x) = c(x) + J(F(x)). \qquad (2.25)
```

This can be derived from the definition (2.21), with

```
$J(x) = c(x) + \sum_{k=0}^{\infty} c(x^+).
```

where $x^+$ is the solution to (2.21), starting at $x^+(0) = F(x)$.

## 2.4.2 Stability of Equilibria

We survey here the most common definitions of stability for a nonlinear state space model. The first and most basic is a form of continuity near the equilibrium $x^e$. Let $\mathcal{X}(k; x_0)$ denote the state at time $k$ with initial condition $x_0$; this is simply $x(k)$, obtained recursively from (2.21), starting at $x(0) = x_0$. In particular, the equilibrium property (2.23) implies that $\mathcal{X}(k; x^e) = x^e$ for all $k$.

## 2.4 Stability and Performance

**Stable in the Sense of Lyapunov.** The equilibrium $x^s$ is stable in the sense of Lyapunov if for $\varepsilon > 0$, there exists $\delta > 0$ such that $\|x_0 - x^s\| < \delta$, then

> $|x(k;x_0) - x(k;x^s)\| \le \varepsilon \quad \text{for all } k \ge 0.$

If an initial condition is close to the equilibrium, $B(r) = \{x \in \mathbb{R}^n : \|x - x^s\| < r\}$ for any $r > 0$. An illustration is provided in Figure 2.3,

This is a weak notion of stability, since there is no guarantee that the state will approach the desired equilibrium. The next definitions impose convergence:

**Asymptotic Stability.** An equilibrium $x^s$ is said to be asymptotically stable if $x^s$ is stable in the sense of Lyapunov and for some $\delta > 0$, $\|x_0 - x^s\| < \delta_0$,

> $\lim_{k\to\infty} \mathcal{X}(k;x_0) = x^s.$

The set of $x_0$ for which the preceding limit holds is called the **region of attraction** for $x^s$.

The equilibrium is **globally asymptotically stable** if the region of attraction is all of $X$: that is, $\delta_0 = \infty$, and hence $x(k) \to x^s$ from any initial condition.

It is common to say that the state model is globally asymptotically stable. That is, it is often stressed that this is a property of the system (2.21) rather than the equilibrium $x^s \in X$.

Sometimes we obtain a fast rate of convergence: the state model is said to be **globally exponentially asymptotically stable** if there are constants $\alpha_0 > 0$ and $B_0 < \infty$ such that for each initial condition and $k \ge 0$

> $|\mathcal{X}(k;x_0) - x^s| \le B_0 ||x_0 - x^s|| e^{-\alpha_0 k}$.

## 2.4.3 Lyapunov Functions

The construction of a Lyapunov function $V$ is the most common approach to establishing asymptotic stability, as well as bounds on a value function (and more general bounds on the state process). In generality, $V$ is a function on $X$ taking nonnegative values, and the crucial property that makes it a Lyapunov function $V(x(k))$ is decreasing when $x(k)$ is large: this is called *drift inequality*. The Lyapunov function $V$ is often regarded as a crude notion of "distance" to the "center of state space".

For any scalar $r$, let $S_V(r)$ denote the **sublevel set**:

> $S_V(r) = \{x \in X : V(x) \le r\}$.

In addition to the nonnegativity of $V$, we frequently assume it is inf-compact:

![](img/0790f102ffa7564329bf76cd0815_36_0.png)

$\{x \in X : V(x) \leq V(x^0)\}$ is a bounded set for $x^0 \in X$. That is, the set $S_V(r)$ takes on one of forms for any $r$: $S_V(r) = X$, or $S_V(r) \subset X$ is bounded. In most cases, find find $S_V(r) = X$ is impossible, so that we arrive at the stricter assumption:

**Figure 2.4** Inf-compact and coercive.

```
$$\lim_{|x| \to \infty} V(x) = \infty.$$
```

(the function on the left is bounded). In this case, under our standing assumption (2.22), the set $S_V(r)$ is either empty or bounded for each $r$. Figure 2.4 illustrates the classes of functions with $X = \mathbb{R}$ here are numerical examples:

- (i) $V(x) = x^2$ is coercive (2.29).
- (ii) $V(x) = x^2/(1+x^2)$ is inf-compact but not coercive: $S_V(r) = \mathbb{R}$ for $r \geq 1$, and $S_V(r) = [-a, a]$ (a bounded interval) for $0 \leq r < 1$, with $a = \sqrt{r/(1-r)}$.
- (iii) $V(x) = e^x$ is neither: $S_V(r) = (-\infty, \log(r))$ is not a bounded subset of $\mathbb{R}$ for $r > 0$.

The function $J$ satisfies the intuitive properties of a Lyapunov function under $c$ and the value function $J$ defined in (2.24) are nonnegative and finite valued.

- $J(k)$ is nonincreasing, and $\lim_{k \to \infty} J(k) = 0$ for each initial condition.
- (ii) In addition $J$ is continuous, inf-compact, and vanishes only at $x^c$. Then, for each initial condition, $lim(k) = x^c$.

The proof is postscribed to Section 2.4.4, but we note here the first steps: the dynamic programming equation (2.25) implies that for each $k \geq 0$,

```
$J(k+1) = J(k) - c(k) \leq J(k).
```

That is, $J(k)$ is nonincreasing, so that $x(k) \in S_J(r)$ for each $k \geq 0$, with $r = J(0)$. The inf-compact assumption implies that the state trajectory is “bottled-up” in the bounded set $S_J(r)$.

In the context of total-cost optimal control, the basic drift inequality in this book is *Poisson’s inequality*: for nonnegative functions $V, c: X \to \mathbb{R}_+$, and a constant $\eta \geq 0$,

```
$V(Fx) \leq V(x) - c(x) + \eta.
```

The reference to a French mathematician is explained in the notes. Poisson’s inequality is a relaxation of the dynamic programming equation (2.25) through the introduction of $\eta$, as well as the inequality.

Poisson’s inequality is defined with attention to the dynamics: on combining (2.31) and (2.21), we obtain (similar to 2.30))

```
$V(k+1) \leq V(k) - c(k) + \eta, \quad k \geq 0$.
```

If $\overline{\gamma} = 0$, it follows that the sequence $\{V(x(k): k \geq 0\}$ is nonincreasing. Under mild assumptions on $V$, we obtain a weak form of stability:

**Proposition 2.2** Suppose that (2.31) holds with $\overline{\gamma} = 0$. Suppose moreover that $V$ is continuous, inf-compact, and has a unique minimum at $x^e$. The equilibrium is stable in the sense of Lyapunov.

Proof From the definition of the sublevel sets, we obtain

```
$\{Sv(r) : r > V(x^e)\} = Sv(r)_{r=V(x^e)} = \{x^e\}$
```

The final equality follows from the assumption that $x^e$ is the unique minimum of $V$. The inf-compact assumption implies the following inner and outer approximations: for each $\varepsilon > 0$, we take $r > V(x^e)$ such that

```
$\{x \in X : V(x) < r\} \subset Sv(r) \subset \{x \in X : V(x) \leq r\}$.
```

If $\|x_0 - x^e\| < \delta$, then $x_0 \in Sv(r)$ and hence $x(k) \in Sv(r)$ for all $k \geq 0$ is nonincreasing.
