While DQN is easy to implement, it does not resolve the issues surrounding Q($\lambda$)-learning:

**Proposition 5.10** Consider the DQN algorithm with possibly nonlinear function approximation. Assume $Q$ is continuously differentiable, and its gradient $\nabla_\theta Q^{\theta}(x,u)$ is globally Lipschitz continuous, with Lipschitz constant independent of $(x,u)$. Suppose that $B = \infty$, the nonnegative step-size sequence, satisfies

- $\sum \alpha_n = \infty$ (Wait, likely $\sum \alpha_n = \infty$)
- $\sum \alpha_n^2 < \infty$

and suppose that the sequence $\{\theta_n\}$ defined by the DQN algorithm is convergent to $\theta_{\infty} \in \mathbb{R}^d$. Then

- (i) $\dot{(\theta_n)} = 0$, with $f$ defined via (5.53) using $\zeta_n = (\nabla_\theta Q^{\theta}(x,u))_{\theta=\theta_n}$
- (ii) The algorithm admits the ODE approximation $\frac{d\theta}{dt} = f(\theta)$.

These conclusions could raise a warning, since we do not know if $f$ defined in (5.53) has a root. If we manage to establish the existence of a solution to $f(\theta_*)=0$, we do not know if the ODE is stable, or if $\theta_{\infty}$ has desirable properties.

On the other hand, DQN is used every day with success, so it should not be ignored.

## 5.5 Convex Q-Learning

We have surveyed three classes of algorithms within the “TD taxonomy”:

- (i) Approximate PIA using LSTD or TD. We can be assured success under two conditions: (a) The function class is linear, and (b) the function class is complete in the sense that we can be assured that $Q^{\phi n} = Q^{\phi}$ for each $n$.
- (ii) GQ learning to obtain the minimal mean-square Bellman error. We are assured success if $Q^*$ lies in our function class, and the objective conditions satisfied with gradient descent (like the PL condition introduced in Section 4.4.2).
- (iii) Galerkin relaxations of the ODE equation are retained using Q($\lambda$) learning, DQN, or Batch Q(0) learning. Here theory is almost nonexistent.

## 5.5 Convex Q-Learning

The RL algorithms surveyed in this section are all motivated by the DPLP(3.36). We begin with a direct approach based on a joint parametrization: In notation of Section 5.1, $\mathcal{H} = \{h^\theta = (J^\theta, Q^\theta): \theta \in \mathbb{R}^d\}$. The value $\theta_i$ might represent the $i$-th weight in a neural function approximation architecture, but to justify the adjective convex, we require a linearly parameterized family:

```
$J^\theta(x) = \theta^T \psi^j(x), \quad Q^\theta(x, u) = \theta^T \psi(x, u).
```

The function class is normalized with $J^\theta(x) = 0$ for each $\theta$. For a linear architecture, this requires $\psi^i(x) = 0$ for each $1 \leq i \leq d$; for a neural architecture, this normalization is imposed through the output of the network. Convex Q-learning algorithms based on RKHS are described in Section 5.5.2. Consider the translation of (3.36) based on a parameterized family:

```
\max_{\theta} \langle \mu, Q^\theta \rangle \text{s.t.} \quad Q^\theta(x, u) \leq c(x, u) + J^\theta(x, u),
Q^\theta(x, u) \geq J^\theta(x), \quad x \in X, u \in U. (5.62)
```

where $\mu$ is now a weighting on $X \times U$. We can strengthen the constraint to equality: $Q^\theta(x, u) = c(x, u) + J^\theta(x, u)$. This is reasonable if we have a good parameterized family $\{J^\theta\}$. However, if we don't have a highly accurate model, it is then better to relax the equality constraint, which is why (5.62) is our starting point.

Another inequality that can be removed from (5.62) is $Q^\theta \geq J^\theta$, since the optimal solution for DPLP results $J^* = Q^*$. We can remove $J^\theta$ from (5.62) by imposing this constraint:

```
\max_{\theta} \langle \mu, Q^\theta \rangle \text{s.t.} \quad Q^\theta(x, u) \leq c(x, u) + J^\theta(x, u), \quad x \in X, u \in U. (5.63)
```

or even $\max_{\theta} \langle \mu, Q^\theta \rangle$ subject to the inequality in (5.63), with $\mu$ on $X$. With each objective, this remains a convex program provided the function class is linear in $\theta$. Through design, we must ensure that $Q^\theta(x) = 0$ for all $i$ and $u$, recognizing that once we are at equilibrium with zero cost, there is no reason to leave.

The algorithms in this section are based on approximations of (5.63). Special options are surveyed in following.

### 5.5.1 Convex Q-Learning with a Finite-Dimensional Function Class

We begin with the linear function class:

```
Q^\theta(x, u) = \theta^T \psi(x, u). (5.64)
```

While this is required for convergence theory, any of the algorithms can be applied using a nonlinear function architecture. An approximation of the inequality in (5.63) is given by $\Gamma^\zeta(\theta) \leq 0$, where

```
\Gamma^\zeta(\theta) = \lim_{N\to\infty} \frac{1}{N} \sum_{k=0}^{N-1} [D_{k+1}(\theta)]_-, (5.66a)
```

```
\tilde{D}_{k+1}(\theta) = -Q^\theta(x,u) + c_k + Q^\theta(x(k+1)). (5.66b)
```

and $[z]_- = \max(0, -z)$ for any $z \in \mathbb{R}$, and $c_k = c(x,u)$. Subject to (5.64), the function $\Gamma^\zeta$ is convex, so that $\{\theta : \Gamma^\zeta(\theta) \leq 0\}$ is a convex subset of $\mathbb{R}^d$.

This motivates the first algorithm:

## Convex Q-Learning

Choose a $\mu$ on $X \times U$, a convex regularizer $\mathcal{R}_N(\theta)$, tolerance $Tol \geq 0$, and solve

```
\theta^* = \arg\min_{\theta} \langle \mu, Q^\theta \rangle + \mathcal{R}_N(\theta) (5.66a)
```

```
s.t. \Gamma_N^\zeta(\theta) \overset{\text{def}}{}=\frac{1}{N} \sum_{k=0}^{N-1} [D_{k+1}(\theta)]_- \leq Tol. (5.66b)
```

The choice of regularizer might depend on computational efficiency. The introduction of the tolerance "Tol" is in anticipation of computational challenges to be discussed shortly.

The next algorithm is inspired by the architecture of DQN: Choose intermediate times $T_0 = 0 < T_1 < T_2 < \dots < T_{B-1} < T_B = N$, and a sequence of regularizers: $\mathcal{R}_n(Q, \theta)$ is a convex functional of $Q, \theta$, which may depend on $\theta_n$. Examples follow.

## Batch Q-Learning #1

With $\theta_0 \in \mathbb{R}^d$ given, defined recursively

```
\theta_{n+1} = \arg\min_{\theta} \{-\langle\mu, Q^\theta\rangle + \mathcal{R}_n(Q^\theta)\} (5.67a)
```

```
s.t. \Gamma_n^\zeta(\theta) \leq Tol. (5.67b)
```

where $0 \leq n \leq B - 1$, with $r_n = T_{n+1}-T_n$,

```
\Gamma_n^\zeta(\theta) = \frac{1}{r_n} \sum_{k=T_n}^{T_{n+1}-1} [D_{k+1}(\theta)]_-. (5.67c)
```

It is expected that $\mathcal{R}_n$ is positive, which prevents $\theta$ from drifting away. This is because $\mathcal{R}_n$ is strongly convex, and we have

```
\mathcal{R}_n(\theta) = \frac{1}{2}\|\theta - \theta_n\|^2. (5.68)
```

in which $\beta_n$ are positive scalars.
