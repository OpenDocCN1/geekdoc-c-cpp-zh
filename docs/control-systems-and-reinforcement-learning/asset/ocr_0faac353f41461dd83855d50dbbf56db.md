Based on (3.25) and the definition of $c^\alpha$, we know that $J^*(x,	au) = 0$ for $	au > \mathcal{N}$. This is considered a boundary condition for the recursion (3.26), which is put to work as follows: First, $J^*(x,\mathcal{N}+1) = 0$,

```
$J^*(x,\mathcal{N}) = \underset{u}{	ext{def}} g(x) = \min c(x,u).
```

Applying (3.26) once gives

```
$J^*(x,N-1) = \underset{u}{\min} \{c(x,u) + g(F(x,u))\}$.
```

These steps can be repeated until the finite horizon value function $J^*(\cdot) = J^*(\cdot,0)$. What about the policy? It is again obtained via (3.26), but the optimal policy depends on the extended state:

```
$\Phi^*(x,	au) = \arg\min_u \{c(x,u) + J^*(F(x,u),	au+1)\}, \quad \tau \le \mathcal{N}$. (3.27)
```

This means that the feedback is no longer homogeneous:$1$

```
$u^*(k) = \Phi^*(x^*(k),k). (3.28)
```

# 3.3.4 Model Predictive Control

An extremely successful technique in many fields (such as in manufacturing and building operations) is model predictive control (MPC). It is a slight variant of (3.28) to obtain a stationary policy:

```
$u(k) = \Phi^{	ext{MPC}}(x^*(k)) = \Phi^*(x(k),0), (3.29)
```

where the right-hand side is defined in (3.27) using $	au=0$. However, MPC is never presented as state feedback because the policy $\Phi^{	ext{MPC}}$ is not computed and stored in memory. Rather, for each $k$, when the state $x=x(k)$ is observed, the finite horizon optimization is performed to obtain the value $u(k) = \Phi^*(x,0)$. That is, the policy is evaluated for those states that observed [242, 443]

Nevertheless, the general optimal control theory surveyed provides techniques to ensure that the total cost associated with (3.29) is finite. Denote for $x \in X$,

```
$J^{	ext{MPC}}(x) = \sum_{k=0}^{\infty} c(x(k),u(k)),
```

subject to $x(0)=x$, and $u(k) = \Phi^{	ext{MPC}}(x(k))$ for all $k$.

**Proposition 3** The optimal policy (3.29), modified with objective:

$J^*(x;0) = \min_{u \in [0,\mathcal{N}]} \{c(x(k),u(k)) + V^0(x(\mathcal{N}))\}, \quad x(0)=x \in X, (3.30)
