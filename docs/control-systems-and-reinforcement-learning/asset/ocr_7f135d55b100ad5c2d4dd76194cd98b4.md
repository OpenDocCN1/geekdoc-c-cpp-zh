It is here that we arrive at an apparent conflict of choice of gain. To make this clear, suppose that the ODE (4.42) satisfies the following form of exponential asymptotic stability: there exists $\rho_0 > 0, B_0 < \infty$ for any solution to (4.42), and any $t \geq 0$

```
$|\Theta_t - \Theta^0|| \leq B_0 ||\Theta_t - \Theta^0|| \exp(-\rhorho_0 t)$ (4.76)
```

From the identity $|\Theta_t - \Theta^0|| = |\vartheta_t - \vartheta^0||$, we come to very different conclusions, depending on $\rho$

$\rho < 1$: $\{\Theta_t\}$ converges to $\theta^0$ very quickly. However, in this case boundedness of $\{Z_t\}$ implies a suboptimal rate

```
$|\Theta_t| \leq B_z \frac{1}{(1+t)^{\rhorho}}$ (4.77)
```

where $B_z$ is B function of the initial condition $\Theta_0$.\$\rho = 1$: The bound (4.77) is ideal, but the rate of convergence of $\{\Theta_t\}$ may not be: not an application of (4.75) gives

```
$|\Theta_t - \Theta^0|| \leq B_0 ||\Theta_0 - \Theta^0|| \frac{1}{(1+t)^{\rhorho}}$
```

To obtain the optimal $1/T$ convergence rate for QSA requires $g \geq 1$. This high gain may lead to other problems, such as large transients.

It is here that the averaging technique of Polyak, Juditsky, and Rupp (RPR) averaging comes to the rescue. We use $\rho < 1$ to exploit the fast convergence of $\{\Theta_t\}$ to $\theta^0$, and then reduce volatility by simply averaging some fraction of the iterates:

```
$\Theta_T^{M} \coloneqq \frac{1}{T-T_0} \int_{T_0}^{T} \Theta_t dt.$ (4.78)
```

For example, $T_0, T_0 = T-T/5$ shows that we average the final 20%. This approach will achieve the optimal $1/T$ convergence rate under very mild assumptions. Section 4.5.5 provides a introduction to the theory for a special case.

# Basic Assumptions and Conclusions

It is simplest to adopt a ‘Markovian’ setting in the probing signal is itself the state for a dynamical system:

```
$\frac{d}{dt} \xi = H(\xi)$ (4.79)
```

where $\Omega: \Omega \to \Omega$ is continuous, with $\Omega$ a bounded subset of Euclidean space. A canonical is the $K$-dimensional torus: $\Omega = [x \in \mathbb{C}^K : |x_i| = 1, 1 \leq i \leq K]$, and $\xi$ defined to allow of excitation with a mixture of mixtures:

```
$\xi_t = [exp(\omega_1 t), \dots, exp(\omega_K t)]^T$ (4.80)
```

with distinct frequencies, ordered for convenience: $0 < \omega_1 < \omega_2 < \dots < \omega_K$. The dynamical system (4.79) is linear in this special case. It is ergodic, in a sense precise in Lemma 4.37.
