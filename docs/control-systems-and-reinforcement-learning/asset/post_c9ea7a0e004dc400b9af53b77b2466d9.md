
## Temporal Difference Methods

### 9.4.2 Nonlinear Parameterizations

Suppose $h^0: 0 \in \mathbb{R}^d$ are not linear functions of $\theta$, but are differentiable. A generalization of the foregoing are based on the definition

$$\psi_t(x;\theta) = \frac{\partial}{\partial\theta_s}h^{\theta}(x).$$

The temporal difference and eligibility sequence are redefined as follows:

$$\mathcal{D}_{n+1} = c(X(n)) + \gamma h^{\theta}(X(n+1)) - h^{\theta}(X(n)), \quad (9.43a)$$
$$\zeta_{n+1} = \lambda\zeta_n + \psi(X(n+1); \theta_n), \quad n \geq 0. \quad (9.43b)$$

The TD($\lambda$) or LSTD($\lambda$) algorithms can be defined using these definitions, because their theory is lacking.

The Zap($\lambda$) algorithm is a potential alternative, which will be convergent under mild conditions. However, it is useful to go back to basics, and ask if there is good motivation for the choice of eligibility vector.

If the algorithm is chosen, the limit $\theta^*$ can be solved as follows:

$$0 = \mathbb{E}[(c(X(n)) + \gamma h^{\theta}(X(n+1)) - h^{\theta}(X(n))\zeta_n^{\theta*}], \quad (9.44)$$

where $\zeta_n^{\theta^*} = \lambda\zeta_n^{\theta^*} + \psi(X(n+1);\theta^*), n \geq 0$, and the expectation in (9.44) is taken with respect to the joint stationary process $(X,\zeta^{\theta^*})$. The fixed-point equation $\Phi = \Phi(k) : k \geq 0$ no longer has an interpretation as a Galerkin relation when the eligibility vector depends upon the parameter $\theta$. It may be best to modify the definition of the loss function so that the solution is more easily understood. Examples include convex Q-learning and actor-critic methods.

## 9.5 Return to the Q-Function

In this section, it is assumed that the input is defined by a (possibly randomized) stationary process $\phi$. For the sake of analysis, it is assumed that $\Phi = \{\Phi(k) = (U(k)) : k \geq 0\}$ is uni-chain, with unique invariant pmf given by (9.3b).

### 9.5.1 Exploration

It is time to discuss how to define $\Phi$ when our true goal is to estimate a value function for a deterministic policy $\Phi$. It is useful to construct the randomized policy that it can be regarded as an '$\varepsilon$-perturbation' of $\Phi$, where $\varepsilon$ is a small but constant.

One approach is to start with any randomized policy $\phi^{\varepsilon}$. This might be completely random, in the sense that $\phi^{\varepsilon}(u|x)$ does not depend upon $x$. The $\varepsilon$-approximation is then defined as:

$$\phi(u|x) = (1 - \varepsilon)\{u = \phi(x)\} + \varepsilon\phi(u|x). \quad (9.45)$$

This is implemented using an i.i.d. Bernoulli sequence $\{I_k\}$ with parameter $\varepsilon$, so that $P\{I_k=1\} = \varepsilon$. The policy $\phi$ is applied at time $k$ if and only if $I_k=0$; otherwise the input is determined by $\phi^{\varepsilon}$.

## 9.5 Return to the Q-Function

An alternative approach is available in the context of policy iteration, surveyed in Section 9.1. Suppose $\phi$ is itself defined as a minimizer: For a function $G: X \times U \to \mathbb{R}$,

$$\phi(x) = \arg\min_u G(x,u) = \max_u \{-G(x,u)\}$$

Given $\varepsilon > 0$, the $soft-max$ is defined as

$$\varepsilon \log{\sum_u \exp(-G(x,u)/\varepsilon)}$$

As $\varepsilon \downarrow 0$, this converges to $\max_u \{-G(x,u)\}$. This motivates a class of randomized policies: Gibbs Policy Given $G: X \times U \to \mathbb{R}$ and $\varepsilon > 0$,

$$\Phi^\varepsilon(u|x) = \frac{1}{\kappa^\varepsilon(x)} \exp(-G(x,u)/\varepsilon), \quad (9.46a)$$

with $\kappa^\varepsilon$ the normalizing constant, defined so that $\Phi^\varepsilon(\cdot|x)$ is a pmf on $U$ for each $x$:

$$\kappa^\varepsilon(x) = \sum_u \exp(-G(x,u)/\varepsilon). \quad (9.46b)$$

The parameter $\varepsilon$ is called the *temperature*.

$$\lim_{\varepsilon \downarrow 0} \Phi^\varepsilon(u|x) = \mathbb{1}\{\phi(x) = u\}.$$

### 9.5.2 On and Off Algorithms

Our main motivation for value function approximation is application to policy iteration, so we consider the fixed-policy (9.6):

$$Q(x,u) = \sum_{k=0}^{\infty} \gamma^k c(\phi(k)), \ X = x, U = u.$$

When the policy $\phi$ is randomized, we require the definition (9.5b): $Q(x) = \sum_u Q(x,u)\phi(u|x)$. The fixed-policy equations (9.7) continue to hold, with following relations:

**Proposition 9.10** The value functions $h$ and $Q$ obtained from a randomized policy $\phi$ satisfy

$$h(x) = c_{\phi}(x) + \sum_{x'} \gamma P_{\phi}(x,x'), \quad Q(x,u) = c(x,u) + \sum_{x'} \gamma P_{\phi}(x,x'),$$

with $c_{\phi}(x) = \sum_u c(x,u)\phi(u|x)$, and $P_{\phi}$ defined in (7.12). The two are related via

$$h(x) = \sum_u Q(x,u)\phi(u), \quad \text{for each } x,u. \quad (9.48)$$

Difference Methods

We obtain two model-free representations of the fixed-point equation for $Q$ (9.47), distinguished by the choice of learning:

- On-policy method: If $U$ is chosen according to the policy $\phi$, $Q(\Phi(k)) = c(\Phi(k)) + \gamma E[Q(\Phi(k+1)) \mid \mathcal{F}_k]. \quad (9.49)$
- Off-policy method: If $U$ is any admissible, the representation must be modified: $Q(\Phi(k)) = c(\Phi(k)) + \gamma E[Q(\Phi(k+1)) \mid \mathcal{F}_k]. \quad (9.50)$

Consider now application of these representations for function approximation within parameterized $H^\theta: \mathbb{R}^d$. The on-policy TD-learning algorithms surveyed in the previous pages are directly applicable recognizing that $\Phi$ is a Markov chain and $Q$ is its discounted-cost value function. For example, here is the TD($\lambda$) algorithm for a linear function architecture: $H^\theta(x,u)=\psi(x,u)$ with $\psi: X \times U \to \mathbb{R}$.

### TD($\lambda$) Algorithm (On-Policy for Q)

For initialization $\theta_0, \zeta_0 \in \mathbb{R}^d$, the sequence of estimates are defined recursively:

$$\theta_{n+1} = \theta_n + \alpha_n \zeta_n D_n(\Phi(n))$$
$$D_{n+1} = (-H^\theta(\Phi(n)) + c_n \gamma H^\theta(\Phi(n))) \big|_{\theta=\theta_n}, \quad (9.51)$$
$$\zeta_{n+1} = \lambda \zeta_n + \psi(n+1), \quad \psi(n+1) = \psi(\Phi(n+1)), \quad c_n \triangleq c(\Phi(n)).$$
