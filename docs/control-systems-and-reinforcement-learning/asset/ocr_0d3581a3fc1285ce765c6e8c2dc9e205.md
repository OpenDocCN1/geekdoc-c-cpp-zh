# 6.7 Simulation: Confidence Bounds and Control Variates

The eigenvalues of $P$ are $\lambda_1=1$ and $\lambda_2=-1$. The Markov chain cycles between the two states; the second eigenvalue $\lambda_2=e^{2\pi i/T}$ with $T=2$ reflects the period-2 dynamics. The mixing time is finite. What does this say about simulation?

It is often granted that for a large mixing time makes Monte Carlo methods take a long time to converge. This is clearly false in the two-state example, for any function $c: X \rightarrow \mathbb{R}$,

```
$$\eta_n = \frac{n}{n-1} \sum_{k=0}^n c(X(k)) = \frac{n}{n+\eta} + \frac{\eta}{n+\eta}c(X(n)) \text{ if } n \text{ is even else}$
```

The asymptotic variance is zero since $\eta_n$ converges to zero at rate $1/n$. The fast convergence is explained by the fact that this is an almost quasi-Monte Carlo method.
