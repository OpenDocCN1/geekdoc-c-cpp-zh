6.8 On Poisson's inequality. This problem shows to a dynamic programming equation that must be treated with care.

For the M/M/1 queue, with $\rho = \alpha/\mu \in (0,1)$, perform the following computations:

+   (a) Let $V(x) = \rho^*$, and compute the drift

$$\Delta(x) = PV - V(x), \quad x = 0, 1, 2, \dots$

+   (b) Compute the steady-state mean of $\$\Delta\$. From this, verify that the invariant pmf $\pi(x) = (1-\rho)\rho^x$, so that $m = \sum_{x} \pi(x)\Delta(x)$. Verify that $m$ is not equal to zero. Also verify that $V$ is not finite.

+   (c) Compute a solution $h$ to Poisson's equation, with forcing function $\$\Delta$.$

$Ph = h - \Delta + m.$.

6.9 Consider the general generalization of the M/M/1 queue over the nonintegers $\mathbb{Z}_+ = \{0, 1, 2, \dots\}$. The transition matrix satisfies $P(n,m)=0$ if $|n-m| > 1$. Equivalently, for Markov chain $X$,

$|X(k+1) - X(k)| \le 1 \quad for each \ X(0) \text{ and } k \ge 1$.$

This is a birth-death process. Verify that the detailed balance equations, when an invariant pmf $\$\pi$ exists,

$$\pi(i)P(i,j) = \pi(j)P(j,i)$.$

Can you obtain an expression for $\pi$, similar to the M/M/1 queue?
