**Proof of Proposition 8.8** Multiply each step of the recursion for $\{\theta_n\}$ in (8.54) by $(n+1)A_{n+1}$ to obtain

```
$$\n+1)\bar{A}_{n+1}\theta_{n+1} = (n+1)\bar{A}_{n+1}\theta_n - [A_{n+1}\theta_n - b_n].$$
```

By definition, $(n+1)\bar{A}_{n+1} = n\bar{A}_n + A_{n+1}$, giving

```
$$\n\bar{A}_{n+1}\theta_{n+1} = [n\bar{A}_n + A_{n+1}]\theta_n - [A_{n+1}\theta_n - b_n],$\n = n\bar{A}_n\theta_n + b_n.$$
```

Iterating this recursion gives $(n+1)\bar{A}_{n+1}\theta_{n+1} = \sum_{k=1}^{n+1} b_k$ for each $n \ge 0$.
