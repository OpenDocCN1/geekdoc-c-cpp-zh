# 8.3.2 Stochastic Gradient Descent

Assuming the minimization problem $	heta^* = \arg \min_{	heta} \Gamma(	heta)$, with $\Gamma(	heta) = E[	ilde{\Gamma}(	heta, \Phi)]$, $	heta \in \mathbb{R}^d$. The gradient descent ODE is defined by

```
$\dot{\thetatheta} = -
abla\Gamma(\theta).$ (8.38)
```

An approximation of gradient descent can be realized with

```
$$\tilde{\theta} = -
abla E[\tilde{\Gamma}(\theta, \Phi)] = -E[\nabla\tilde{\Gamma}(\theta, \Phi)].$
```

The exchange of derivative and expectation can be justified under mild conditions. Suppose we are given samples $\Phi = \{\Phi_n, n \geq 1\}$ for which the distribution of $\Phi_n$ converges to $\Phi$, as $n \to \infty$, and denote $\Gamma_n(	heta) = \tilde{\Gamma}(	heta, \Phi_n)$ for any $n$ and $	heta$. The basic algorithm (8.2) results in stochastic gradient descent (SGD):

```
$$\theta_{n+1} = \theta_n - \alpha_n\nabla\Gamma_{n+1}(\theta_n).$ (8.39)
```

# Stability of the Algorithm

Provided $\Gamma$ is strongly convex (recall 4.22), Proposition 4.7 tells us that the flow (8.38) is exponentially asymptotically stable. In the proof, it is shown that $V(\theta) = \frac{1}{2}|\theta - \theta^*||^2$ serves as a Lyapunov function.

```
$$\dot{V}(\theta_t) \leq -2\delta_0V(\theta_t) \leq -\delta_0|\theta - \theta^*||^2\exp(-\delta_0t).$ (8.40)
```

Consequently, the bound (8.33) holds with $\beta_0=1$ and $\alpha_0=\delta_0$. Conditions for exponential asymptotic stability without convexity can be obtained from Theorem 4.9.

What about the stability of the SA algorithm? A sufficient condition is based on the ODE@$\infty$, just as in the deterministic case of Section 4.4.4: Define for $\theta \in \mathbb{R}^d$

```
$$\Gamma^{\infty}(\theta) = \lim_{r\to\infty}\frac{1}{r}\Gamma(r\theta), \quad\nabla\Gamma^{\infty}(\theta) = \lim_{r\to\infty}\frac{1}{r}\nabla\Gamma(r\theta).$
```

Assuming these functions are finite valued, it that the first is radially quadratic, and the second is radially linear,

```
$$\Gamma^{\infty}(s\theta) = s^2\Gamma^{\infty}(\theta), \quad\nabla\Gamma^{\infty}(s\theta) = s\nabla\Gamma^{\infty}(\theta), \quad s > 0.$
```

If $\Gamma$ is strongly convex, (4.25) implies the lower bounds:

```
$$\theta^T\nabla\Gamma^{\infty}(\theta) \geq \delta_0||\theta||^2, \quad\Gamma^{\infty}(\theta) \geq \frac{1}{2}\delta_0||\theta||^2.$
```
