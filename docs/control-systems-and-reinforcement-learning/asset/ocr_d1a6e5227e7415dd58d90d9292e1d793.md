Averaging each side gives

```
$$\frac{1}{n}\sum_{k=1}^n \Delta_k^i = \frac{1}{n}\sum_{k=1}^n {v^i(X(k)) - \lambda_i v^i(X(k-1))}$$
$$(1-\lambda_i)\frac{1}{n}\sum_{k=0}^{n-1} v^i(X(k)) + \frac{1}{n}[v^i(X(n)) - v^i(X(0))].$$
```

Multiplying each side by $\beta_i/(1-\lambda_i)$ and summing

```
$$\frac{1}{n}\sum_{k=1}^n \Delta_k^Delta = \eta_n + \frac{1}{n}\sum_{i=1}^m \frac{1}{1-\lambda_i}\beta_i\Delta_k^i$$$
$$\$\eta_n + \frac{1}{n}\sum_{i=1}^m \frac{\beta_i}{1-\lambda_i}[v^i(X(n)) - v^i(X(0))].$$$$
```

It follows that the asymptotic variance $\sigma_c^2$ coincides with the ordinary variance of the martingale difference sequence $[\Delta_k^i]$ in steady state. It can be expected to be very large if $|\beta_i/(1-\lambda_i)|$ is large for one $i$. The vector $\beta$ depends on the function $c$, and the quantity $|1/(1-\lambda_i)|$ is large if the eigenvalue $\lambda_i$ is near unity.

# 6.7.3 Sample Complexity

What if a random confidence interval gives you no confidence? A deterministic interval requires what is known as a finite-$n$ bound,

```
$P[\eta_n - \eta| \ge r/\sqrt{n}] \le \mathcal{B}(n,r), \quad (6.42)
```

```
$P[\eta_n - \eta| \ge \varepsilon] \le \tilde{b}\exp(-nI(\varepsilon)), \quad (6.43)
```

where $\tilde{b}$ is a finite constant, and $I(\varepsilon) > 0$ for $\varepsilon > 0$. This leads to sample complexity bounds for estimating the mean—the terminology is explained in Section 8.2 in a more general setting.

In the majority of applications, you are out of luck. If you want (6.42) or (6.43) with explicit values, you will require substantial assumptions on the Markov model and the cost function. For example, bounds are available for a finite state space Markov chain, but the bounds are loose unless there is substantial prior knowledge available. See the “Notes” section for background.
