
## 102 ODE Methods for Algorithm Design

The goal is to estimate $\theta^* \in \mathbb{R}^d$ based on input–output measurements, where this “best parameter” corresponds to a model that reflects input–output observations.

In the prediction error method, we introduce a loss function $\Gamma: \mathbb{R}^d \to \mathbb{R}$, defined by

```
$$\Gamma(\theta) = \frac{1}{T} \int_0^T \ell(y_t - y_t^\theta)dt.$$
```

in which $y_t$ is observed at time $t$, and $y_t^\theta$ is obtained from the model with identical input $\mathbf{u}$, and initial state $x_0^\theta = x_0$. The function $\ell: \mathbb{R} \to \mathbb{R}$ satisfies $\ell(0) = 0$ and $\ell(z) > 0$ for $z \neq 0$.

Consider the typical quadratic loss, $\ell(z) = z^2$. We might apply gradient descent to find the minimizer $\theta^*$ of $\Gamma$, where the gradient is expressed

```
$$\nabla_{\theta}\Gamma(\theta) = \frac{1}{T} \int_0^T \nabla_{\theta}\ell(y_t - y_t^\theta)dt=-\frac{2}{T} \int_0^T (y_t - y_t^\theta)\nabla_{\theta}y_t dt.$$
```

We are faced with finding a model for the gradient of the observations. We might design the model so that this is an easy task:

```
$y_t^\theta = \theta^T\phi_t,$
```

where the regression vector $\phi_t \in \mathbb{R}^d$ is a function of observations and not the model. Hence the gradient is expressed in terms of observations, $\nabla_{\theta}y_t^\theta = \phi_t$, and the gradient of the loss function is linear: $\frac{1}{2}\nabla_{\theta}\Gamma(\theta) = M\theta - b$,

```
$M = \frac{1}{T} \int_0^T \phi_t\phi_t^T dt \quad \text{and} \quad b = \frac{1}{T} \int_0^T y_t\phi_t dt.$
```

These representations are one motivation for ARMA models (see Section 2.2 for a definition in discrete time).

In the absence of such a simple description, we look more closely at the state space model. Assume $x_t^\theta$ and $y_t^\theta$ are continuously differentiable in $(t,\theta)$. Let $S_t^\theta = \partial_{\theta}x_t^\theta$ denote the $n \times d$ matrix of partial derivatives of:

```
$[S_t^\theta]_{i,k} = \frac{\partial}{\partial\theta_k}x_t^\theta(i), \quad 1 \leq i \leq n, \quad 1 \leq k \leq d.$
```

Recalling the calculus identity $\nabla_{\theta}y_t^\theta = |\partial_{\theta}y_t^\theta|$, we obtain by chain rule

```
$$\frac{d}{dt}S_t^\theta = f_x(x_t^\theta,u;\theta)S_t^\theta + f_{\theta}(x_t^\theta,u;\theta);\n\partial_{\theta}y_t^\theta = g_x(x_t^\theta,u;\theta)S_t^\theta + g_{\theta}(x_t^\theta,u;\theta);$$
```

```
$[f_x(x,u;\theta)]_{i,j} = \frac{\partial}{\partial x_j}f_i(x,u;\theta).$
```

There are two challenges with this approach: Potential numerical instability of the differential equation $\{S_t^\theta\}$. Another is the complexity of the ODE, especially

### 4.5.3 Approximate Policy Improvement

Consider again a nonlinear state model in continuous time,

```
$$\Delta x_t = f(x_t, u_t), \quad t \geq 0,$$
```

with $x_t \in \mathbb{R}^n, u_t \in \mathbb{R}^m$, Given a cost function $c: \mathbb{R}^{n+m} \to \mathbb{R}$, our goal is to approximate the optimal value function

```
$J^*(x) = \min \int_0^\infty c(x_t, u_t)dt, \quad x=x_0$
```

and approximate the optimal policy. For this, we first explain how policy improvement extends to the continuous time setting.

For any feedback loop $u_t = \phi(x_t)$, denote the optimal value by

```
$J^\Phi(x) = \int_0^\infty c(x_t, \phi(x_t))dt, \quad x=x_0.$
```

```
$0 = c(x,\phi(x)) + \nabla J^\Phi(x) \cdot f(x,\phi(x)).$
```

The policy improvement step in this continuous time defines the new policy as the minimizer

```
$\Phi^+(x) = \arg \min_u c(x,u) + \nabla J^\Phi(x) \cdot f(x,u)..$
```

Consequently, approximating the term in brackets is key to approximating PIA. In Section 3.7). First, we'll show how to add $J^\Phi$ to each side of the fixed-policy dynamic programming equation:

```
$J^\Phi(x) = J^\Phi(x) + c(x,\phi(x)) + \nabla J^\Phi(x) \cdot f(x,\phi(x)).$
```

The right-hand side motivates the following definition of the fixed-policy Q-function:

```
$Q^\Phi(x,u) = J^\Phi(x) + c(x,u) + f(x,u) \cdot \nabla J^\Phi(x).$
```

The policy update can be equivalently expressed $\Phi^+(x) = \arg \min_u Q^\Phi(x,u),$ and this Q-function solves the fixed-point equation

```
$Q^\Phi(x,u) = Q^\Phi(x,u) + c(x,u) + f(x,u) \cdot \nabla Q^\Phi(x), \quad (4.56)
```

where $H^\Phi(x) = H(x,\phi(x))$ for any function $H$; note that this is not a substitution, rather than the minimization appearing in (3.7). Consider now a family of functions for approximation $\{Q^\theta : \theta \in \mathbb{R}^d\}$, and consider the Bellman error:

```
$B^\theta(x,u) = -Q^\theta(x,u) + Q^\theta(x,u) + c(x,u) + f(x,u) \cdot \nabla Q^\theta(x). \quad (4.57)
```

## Methods for Algorithm Design

A model-free representation is obtained, recognizing that for any state-input pair $(x_t, u_t)$,

```
$B^\theta(x_t, u_t) = -Q^\theta(x_t) + Q^\theta(x_t) + c(x_t, u_t) + \frac{1}{t}Q^\theta(x_t). \quad (4.58)
```

The error $B^\theta(x_t, u_t)$ can be observed without knowledge of the dynamics $f$ or the cost $c$. The goal is to find $\theta^*$ that minimizes the mean-square error:

```
$\|B^\theta\|^2_{\lim_{T\to\infty} \int_0^T [B^\theta(x_t, u_t)]^2 dt. \quad (4.59)
```

We choose feedback law with "exploration" introduced in Section 2.5:

```
$u_t = \Phi(x_t, \mathcal{L}), \quad (4.60)
```

so that the resulting trajectories are bounded for any initial condition, and the joint process $(x, u, \mathcal{L})$ is an "ergodic steady state" (meaning the existence of sample paths such as (4.59) is guaranteed). This approximation technique defines an approximate version of PIA: Given a policy $\phi$ and approximation $\hat{Q}$, the policy is updated:

```
$\phi(x) = \arg\min_u Q(x, u). \quad (4.61)
```

This procedure is repeated to obtain a recursive algorithm.

## Least Squares loss

Consider the loss function

```
$$\Gamma(\theta) = \lim_{T\to\infty} \frac{1}{T} \int_0^T \frac{1}{2}[B^\theta(x_t, u_t)]^2 dt.$$
```

Suppose that the approximation architecture is linear (3.4), so that $\Gamma_T$ is a quadratic function of $\theta$:

```
$$\Gamma(\theta) = \theta^T M_T \theta - 2b_T^T \theta + \Gamma_T(0) = (\theta - \theta^*)^T M_T (\theta - \theta^*) + \Gamma_T(\theta^*).$
```

We leave it to the reader to find expressions for $M_T, b_T$, and $\Gamma_T(0)$. In this special case, we do not need gradient descent techniques: the matrices $M_T$ and $b_T$ are obtained as sample-path averages–the Monte Carlo approach surveyed in Section 4.5– and then $\theta^* = M_T^{-1}b_T$ is the unique minimizer of $\Gamma_T$.

## 4.5 Quasistochastic Approximation

Without linear parameterization, we turn to gradient descent to minimize $\Gamma$, with gradient

```
$$\Gamma(\theta) = \lim_{T\to\infty} \frac{1}{T} \int_0^T [B^\theta(x_t, u_t)] \nabla_\theta B^\theta(x_t, u_t) dt.$$
```

The first-order condition for optimality is expressed as the root-problem $\nabla_\theta \Gamma(\theta) = 0$, and the standard gradient descent algorithm in ODE form is

```
$$\frac{d}{dt}\theta_t = -\nabla_\theta \Gamma(\theta_t).$$
```

Its QSA counterpart (4.44) is

```
$$\frac{d}{dt}\theta_t = -a_t B^\theta(x_t, u_t) + c_t\zeta_t^Q, \quad (4.62a)
```

```
$$\zeta_t^Q \equiv \nabla_\theta B^\theta(x_t, u_t) = -\nabla_\theta Q^Q(x_t, u_t) + \{\nabla Q^Q(x_t, \phi(x_t)) + \nabla_\phi Q^Q(x_t, \phi(x_t))\}, \quad (4.62b)
```

where (4.62b) follows from (4.58), and can be provided to justify the exchange of differentiation with respect to time and with respect to $\theta$.

The QSA gradient descent algorithm (4.62) is best viewed by a nonlinear function approximation, but it is instructive to show how the ODE simplifies for the linearly parameterized (3.4). We have in this case

```
$$\zeta_t = -\psi(x_t, u_t) + c(x_t, \phi(x_t)) + \frac{1}{t}\psi(x_t, \phi(x_t))$$
```

and $\mathcal{B}^\theta(x_t, u_t) = c_t + \zeta_t^\theta$ using $c_t$ so that (4.62) becomes

```
$$\frac{d}{dt}\theta_t = -a_t[\zeta_t\theta_t + c_t].$$ (4.63)
```

The convergence of (4.62) may be very slow if the matrix

```
$$\mathcal{R}^C = \lim_{t\to\infty} \frac{1}{t} \int_0^t \zeta_\tau^C d\tau$$ (4.64)
```

has eigenvalues close to zero. This can be resolved through the introduction of a larger gain $\alpha$, or a matrix gain. One approach is to estimate $\mathcal{R}^C$ from data and invert: $G_t = [\mathcal{R}^C]^{-1}$ with

```
$$\tilde{R}_t^C = \frac{1}{t+1}[\mathcal{B}_0^\theta + \int_0^t \zeta_\tau^C d\tau], \quad \tilde{R}_0 > 0$ (4.65a)
```

```
$$\frac{d}{dt}\theta_t = -a_t G_t[\zeta_t\theta + c_t], \quad t \ge 0.$ (4.65b)
```

## Numerical Example

Consider the LQR problem in which $\dot{x} = Ax + Bu$, and $c(x,u) = x^T S x + u^TR$, with $S \ge 0$ and $R > 0$. The fixed-policy $Q$-function associated with any stable linear policy $\phi(x) = -Kx$, takes the form

```
$$\Q^\Phi(x,u) = \left[ \begin{matrix} S & 0 \\ 0 & R \end{matrix} \right]^T \left[ \begin{matrix} A^TM + MA + MB & 0 \\ B^T M \end{matrix} \right] [x \ u]$$$
```

where $M$ solves the Lyapunov equation (2.46) with $S$ replaced by $K^T RK + S$:

```
$A^TM + MA + K^T RK + S = 0.$
```
