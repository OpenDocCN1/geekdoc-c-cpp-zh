# Unstable Dynamics with Perfect Exploration

Figure 5.5 shows Baird's counterexample, which provides an example of instability when using TD($\lambda$). There are six states and no control, with which the state remains at $x(k)=7$ for all $k \ge 1$. $Q^*(x,u) = h^*(x) = 0$ for each $x$. Note that $	heta'$ denotes the $i$th index of the vector $	heta$.

The example violates two conventions in this chapter:

+   (i) $\psi(x) = (0, \dots, 1, 2)^T 
eq 0$ with $x^*=7$, so that is violated.
(ii) If there are only states, then the basis is essential. This implies that the sample correlation matrix (5.19) is never full, for any value of $N$.

The degenerate correlation matrix not be such a concern, since $h^0 = h^*$ and also $\mathcal{D}_{n+1}^0 = 0$ for all $n$ with $	heta^0=0$. Rank degeneracy implies that $	heta'$ is not unique.

The example was introduced in the discounted cost setting, with discount factor $\gamma \le 1$. This is maintained here, and because there is no control we use value function to define the temporal difference:

```
$\mathcal{D}_{n+1}^0 = -h^0(x(n)) + \gamma h^	heta(x(n+1)) = -h^0(x(n)) + \gamma h^	heta(7),$
```

where the second equality holds because of the trivial definitions. The definition of the eligibility method is slightly modified in the discounted setting:

```
$\zeta_{n+1} = \lambda\zeta_n + \psi(n+1)).$
```

So-perfect exploration is based on a version of restart, in which each episode allows only one transition, and of each seven states is sampled uniformly. A periodic implementation is described as follows: for $n=0, 1, \dots, 6$, choose $x(n)=n+1$ and obtain

```
$\mathcal{D}_{n+1} = -h^	heta(n+1) + \gamma h^	heta(n)).$
```

where $\{	heta_n\}$ are updated using TD($\lambda$); $	heta_{n+1} = 	heta_n + \alpha_n\mathcal{D}_{n+1}\zeta_n$. This procedure is repeated that $x(n)-1 \equiv n \pmod 7$ for all $n \ge 1$.

The algorithm converges for $\gamma \le 1$ sufficiently large and some initial conditions (under which standing assumption that $\sum \alpha_n = \infty$). To see this closer look at the difference:

```
$\mathcal{D}_{n+1} = \begin{cases} -[	heta_n^0 + 2	heta_n^1] + \gamma[2	heta_n^0 + 	heta_n^1] & x(n)=k \le 6 \ -[	heta_n^0 + 	heta_n^1] + \gamma[2	heta_n^0 + 	heta_n^1] & x(n)=7 \end{cases}$
```

The source of instability is revealed by looking at the last of the six parameter:

```
$\theta_{n+1}^0 = \theta_n^0 + \begin{cases} \alpha_{n+1}\{(2-1)\theta_n^0 + \gamma	heta_n^0 - 2\theta_n^1\}\zeta_n^0 & x(n)=k \le 6 \ \alpha_{n+1}\{(1-\gamma)[2\theta_n^0 + \theta_n^1]\}\zeta_n^0 & x(n)=7 \ \end{cases}$
```

Suppose that $\gamma > \frac{1}{2}$ and $	heta_0^0 > 0$ is large relative to the other parameters. Whenever $x(n)=k \le 6$, the estimate $	heta_{n+1}^0$ tends to increase, because of the positive coefficient $(2\gamma-1)$.
