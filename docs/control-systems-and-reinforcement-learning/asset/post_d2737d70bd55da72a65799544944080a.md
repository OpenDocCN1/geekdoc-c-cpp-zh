## 9.8 GQ

This section contains more ideas to accelerate Watkins' Q-learning, and also new techniques for outside of tabular setting. However, theory in this section is restricted to tabular basis. An understanding of the matrix chain algorithms requires a closer look at vector field $f^0$ given in Proposition 9.15.

When state and input space are finite as assumed here, $\{\Phi^m : 1 \le m \le M\}$, where $M$ is the number of possible functions from $X$ to $U$. For each $m$, denote

$$\Theta^m = \{\theta \in \mathbb{R}^d : \Phi^m(x) \in \arg \min f(x,u) \text{ for each } x\}$$

Each $\Theta^m$ is a convex cone: $r_1\theta^1 + r_2\theta^2 \in \Theta^m$ whenever $\theta^1 \in \Theta^m$ and $r_i \in \mathbb{R}_+$ for $i=1,2$. Figure 9.4 provides an illustration of these sets.

Let $Q^m$ denote fixed-function with policy $\Phi^m$. Denoting by $T_m$ the transition matrix for Markov chain $\Phi$ with control $\Phi^m$, we have

$$Q^m = [I - \gamma T_m]^{-1}c.$$

![](img/0790f102da4ffa7564329bf76c7d0815_365_0.png)

These Q-functions are also indicated in Figure 9.4, which is justified by the identity (9.73). The index $m^*$ is special because $Q^{m^*} \in \Theta^{m^*}$ which implies fixed-point equation:

$$\Phi^{m^*}(x) \in \arg \min Q^{m^*}(x,u) \text{ for each } x \in X.$$

That is, this policy iteration returns the same policy, which implies $Q^{m^*} = Q^*$. Let $\Pi$ denote the diagonal matrix $\text{diag}(\alpha)$ (also equal to $R$) in (9.78).

**Lemma 9.25** The Jacobian $A = \partial f^0$ is piecewise, with $A(\theta)$ independent of $\theta$ within the interior of $\Theta^m$ for each $m$. If $\theta \in \mathbb{R}^d$ satisfies $\theta \in \text{interior}(\Theta^m)$ for any $m$, then at this value the Jacobian is given

$$A(\theta) = -\Pi[I - \gamma T_m] \quad (9.92a)$$

With $T_m(i,j) = P(x^i,x^j)\{u^j = \Phi^m(x^j)\}, \quad 1 \le i,j \le d.$

The function $f^0$ is thus continuous and piecewise linear, and for each,

$$f^0(\theta) = A(\theta) - \Pi b, \quad b_i = -c(x^i,u^i) \text{ for each } i. \quad (9.92b)$$

## 9.8 GQ-Learning

### 9.8.1 GQ-Learning

This algorithm is defined exactly as in the deterministic setting of Section 5.4.4, with the same objective: solve

$$\min \Gamma(\theta) = \min_{\theta} \frac{1}{2} {f^0(\theta)}^T M f^0(\theta),$$

where once again $M^{-1} = E_{\theta}[\zeta_n \zeta_n^T]$ with $\zeta_n = \psi(n)$ (recall 9.4 for notation). For the tabular case, this reduces to $M^{-1} = \Pi$, and $\Gamma(\theta) = 0$.

The ODE method based on gradient descent will provide a recursive algorithm, as in the deterministic setting considered previously (recall (5.55)). We must first inspect the ODE. The following representations are implied by (9.92b).

- **Lemma 9.26** $\theta \in \mathbb{R}^d$ satisfies $0 \in \Theta^m$ for any $m$, then $\Gamma$ is quadratic in a neighborhood of $\theta$, with partial derivatives

$$\Gamma(\theta) = A(\theta)^T M f^0(\theta) = -[I - \gamma T_m]^T f^0(\theta), \nabla(\theta) = [I - \gamma T_m].$$
