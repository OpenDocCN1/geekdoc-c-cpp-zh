# 5.4.3 Projected Bellman Operator and Q-Learning

The Q-function for the total optimal control problem solves the fixed point equation (3.7d), copied here for convenience:

```
$Q^*(x,u) = c(x,u) + Q^*(F(x,u)),$
```

with $Q(x) = \min_u Q(x,u)$ for any $Q$. For a parameterized family of approximations $\{Q^theta$ $	heta \in \mathbb{R}^d\}$, recall that for each $	heta$ we define a policy by (3.44):

```
$\phi^	heta(x) = \arg \min_u Q^	heta(x,u), \quad x \in X$.
```

We obtain an algorithm for approximation via "pattern matching" with (5.48). The algorithm with linear function approximation is presented here:

# Q(\lambda) Learning

For a given $\lambda \in [0,1]$, nonnegative step-sequence $\{\alpha_n\}$, initial conditions $	heta_0, \zeta_0$, and observed samples $u(k,x) : 0 \leq k \leq N$, the sequence of estimates is defined by the following equations:

```
$$\theta_{n+1} = \theta_n + \alpha_n \mathcal{D}_n \zeta_n, \quad (5.52a)\n$\zeta_{n+1} = \lambda \zeta_n + \psi_{(n+1)}, \quad (5.52b)$
```

```
$$\mathcal{D}_n = -Q^	heta(x(n),u(n)) + c_n + Q^	heta(x(n+1),\phi^	heta(x(n+1))), \quad (5.52c)$
```

with $\psi(n+1) = \psi(x(n+1),u(n+1)), c_n = c(x(n),u(n)).

The algorithm has significant similarities and differences with TD-learning:

+   The change is in (5.52c): the current policy estimate $\phi^	heta$ is used, rather than the fixed policy $\phi$ in TD($\lambda$). Note that in (5.52c) we can substitute

```
$Q^	heta(x(n+1)),\phi^	heta(x(n+1)) \overset{def}{=} Q^	heta(x(n+1))$
```

+   QSA theory predicts that a target $\theta^*$ for Q($\lambda$)learning will solve $f(\theta^*) = 0$, with

```
$f(\theta) = E_	heta [f_{n+1}(	heta)], \quad f_{n+1}(	heta) = \mathcal{D}_n Q^	heta \zeta_n. \quad (5.53)$
```

This appears as TD($\lambda$) until you recognize the different definition for $\mathcal{D}_n(Q^{	heta^*})$ obtained from (5.52c):

```
$$\mathcal{D}_n(Q^{	heta^*}) = -Q^{	heta^*}(x(n),u(n)) + c_n + Q^{	heta^*}(x(n+1),u).$
```

```
$Q^{	heta^*} = P_h\{T(Q^{	heta^*})\}$
```
