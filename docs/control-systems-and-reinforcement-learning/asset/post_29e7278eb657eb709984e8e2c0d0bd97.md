## 2.7.2 Mountain Car

The goal is to drive a car with a very weak engine to the top of a very high mountain, as illustrated in Figure 2.9. A two-dimensional state model is obtained using position and velocity $x_t = (z_t, v_t)^T$, and the input $u$ is the throttle position (which is negative when the car is in reverse). In the following, the state space is defined to be a rectangular,

```
X = [z_t^{min}, z_t^{goal}] \times [-\overline{f}, \overline{f}]
```

in which $z_t^{min}$ is a lower limit for the position $z_t$, and the target position is $z_t^{goal}$. The constraint $x_i \in X$ means that the velocity $v_i$ is bounded in magnitude by $|v| > 0$. Within the RL literature, this example was introduced in the dissertation [264], and has become a favorite basic example [3338].

What makes this problem interesting is that the engine is so weak that it is impossible to reach the hill directly from some initial conditions. A successful policy sometimes puts the car in reverse, and travel at maximum speed from the goal to a higher elevation to the left. Several cycles back and forth may be required to reach the goal.

A continuous-time model can be constructed based on the forces on the car, illustrated in Figure 2.10. To obtain a simple model, we need to be careful with our notion of distance: $z_t^{goal}$ denotes the *path distance* along the road to the goal, which is not the same as the distance along the $x$-axis in Figure 2.9. ## 2.7 Examples

With $x = (z, v)^T$, we arrive at the two-dimensional state model,

```
$$\begin{aligned} \frac{d}{dt}x_1 &= x_2, \ \frac{d}{dt}x_2 &= -\frac{\kappa}{m} - g\sin(\theta(x_1)), \end{aligned} (2.56)$
```

where $\theta(x_1)$ is the road grade at $z = x_1$,

An examination of the potential energy $U$ tells us from which states we can reach the goal without control (setting $u=0$ in (2.56)). The potential energy is proportional to elevation and can be computed by integrating the negative of force, $-F(z)$. For the control-free model, we have $-F(z) = mg\sin(\theta(z))$, and hence

```
$U(z) = U(0) + mg\int_{0}^{z} \sin(\theta(z))\ dz.$ (2.57)$
```

The version of this model adopted in [338, 10] has these numerical values:

$\kappa=1, z=2.5, \theta(z) = \pi+3z$.

In this case $U(z) = U(0) + mg\sin(3z)/3$. Figure 2.11 shows the potential energy as a function of $z$ on the interval $[z^{min}, z^{max}]$. It has a maximum at $z^{goal}$, which implies that it is necessary to apply external force to reach the goal of any initial condition $z(0) < z^{goal}$ and $v(0) \le 0$.

![](img/0790f102da4ffa7564329bf76c7d0815_52_0.png)

Figure 2.11 Potential energy for the mountain car.

**Is the goal reachable?** We examine again potential energy. Consider the force as a function of $z$ with $u(k)=1$ for all $k$. We obtain $-F(z)=mg\sin(\theta(z))-\kappa$, and the resulting potential energy is the integral, denoted $\dot{U}(z)=U(z)-\kappa$ and shown in Figure 2.11. We now have $U(z^{min}) > U(z^{goal})$, so from $z(0)=z^{min}$ we will reach the goal with this open-loop control law.

Consider the initial position $z(0)=-0.6$, for which $\dot{U}(z^0)$ is identified with a dashed line, and let $z'$ denote the other value satisfying $z' > z^0$ and $\dot{U}(z')=U(z^0)$. If $u(k)=1$ for all $k$, then initial condition $z(0)=-0.6$ and $v(0)=0$, the car will initially move to the right, and stall at time $t_1$, where $z(t_1)=z^1$. It will then reverse direction until it hits at location $z^0$, and this process will repeat.

A discrete scheme used in [338, 10], based on sampling the ODE with sampling interval $\Delta x(k)=(z(k), v(k))^T$,

```
$$\begin{aligned} z(k+1)=z(k) +\Delta v(k), \ v(k+1)=v(k) +\Delta [u(k)-2.5\cos(3z(k))]|\Delta t. \end{aligned} (2.58a)(2.58b)$
```

This is expressed in (2.6a) by substituting the expression for $v(k+1)$ in (2.58b) into the right-hand side. The method is consistent with $\theta(z)=\pi+3z$. The bars denote projection of values of $z(k)$ to the interval $[z^{min}, z^{goal}]$, and $v(k)$ to the interval $[-\pi, \pi]$. In addition, the constraint $v(k) \ge 0$ is imposed when $z(k)=z^{min}$, and $v(k)=0$ when $z(k)=z^{goal}$ (the car is parked once it reaches its target). The following values are chosen in experiments:

$z^{min} = -1.2, z^{goal} = 0.5, \bar{v} = 0.7.$ (2.58c)

Here is an aggressive policy will get you to the top: Wherever you are going, accelerate in that direction at maximum rate (provided this is feasible):

```
u(k) = \begin{cases} 0 & z(k) = z^{goal} \\ \text{sign}(v(k)) & \text{else} \end{cases} \quad (2.59)
```

If $v(k) = 0$, $\text{sign}(v(k))$ can be taken to be 1 or -1, subject to the constraint $v(k) \neq 0$.

## 2.7 Magnetically suspended ball

The magnetically suspended ball illustrated in Figure 2.12 will be used to illustrate important concepts. In particular, it shows how to transform a set of nonlinear equations into state space, and how to approximate this by a linear state space model of form (20). The input $u$ is the current applied to electromagnet, and the output $y$ is the distance between the center of the ball and the bottom of magnet. Since positive and negative inputs are indistinguishable at the output of this system, it follows that this cannot be a linear system. The upward force due to current is proportional to $u^2/y$, and hence from Newton’s law for translational motion we adopt the model

```
ma = m\frac{d^2y}{dt^2} = mg - \kappa \frac{u^2}{y}
```

where $g$ is gravitational constant, and $\kappa$ is some constant depending on physical properties of magnet and ball. Control goal: Maintain the distance to the magnet at some reference value $r$. We obtain a state space model as a first step to control design. This input-output model can be converted to state space form to obtain something similar to controllable description in (16) and (18): using $x_1 = y$ and $x_2 = \frac{dy}{dt}$.

```
\frac{d}{dt}x_1 = x_2, \frac{d}{dt}x_2 = g - \frac{\kappa u^2}{x_1^2}
```

![](img/0790f102da4ffa7564329bf76c7d0815_53_0.png)

Figure 2.12 Magnetically suspended ball.

where the latter equation follows from the formula $\frac{d}{dt}x_2 = g - y$. This pair of equations defines a two-dimensional state space model of form (19):

```
$\frac{d}{dt}x_1 = x_2 = f_1(x_1, x_2, u), \quad (2.60a)$
$\frac{d}{dt}x_2 = g - \frac{\kappa}{m}(x_1)^2 = f_2(x_1, x_2, u). \quad (2.60b)$
```

It is nonlinear, since $f_2$ is a nonlinear function of $x$, and also the state space is constrained $X = \{x \in \mathbb{R}^2 : x_1 \geq 0\}$. Suppose that fixed current $u^o > 0$ is applied, and the state $x^o$ is an equilibrium: $f_2(x^o, u^o) = 0$. By the definition of $f_1$ in (2.60a), we must have $x_2^o = 0$, and setting $f_2(x^o, u^o)$ to zero in (2.60b)

```
$x_1^o = \sqrt{\frac{mg}{\kappa}}u^o > 0. \quad (2.61)$
```

If we are very successful with our control design, and $x_t = (r,0)^T$ for all $t$, we will have

```
$u_t = u^o, \quad t \geq 0, \quad \text{where } u^o = r\sqrt{\kappa/mg} : \text{the solution to (2.61) with } x_1^o = r.$
```

Of course, we don't expect this ‘open-loop’ approach to be successful. If realistically successful, so that $x_t \approx r$ for all $t$ (perhaps a transient), we should expect that $u_t \approx u^o$. The design of a feedback loop to achieve this goal is often obtained through an approximate linear model, called *linearization*.

## Linearization about an Equilibrium State

The linearization is defined exactly as the frictionless pendulum (2.49). Assume that the signals $x_1, x_2$, and $u$ remain close to the fixed point $(x_1^o, x_2^o, u^o)$, and write

```
$x_1 = x_1^o + \tilde{x}_1, x_2 = x_2^o + \tilde{x}_2, u = u^o + \tilde{u}.$
```

where $\tilde{x}_1, \tilde{x}_2$, and $\tilde{u}$ are small-amplitude signals. From the state equations (2.60), we then have

```
$\frac{d}{dt}\tilde{x}_1 = x_2^o + \tilde{x}_2,$
$\frac{d}{dt}\tilde{x}_2 = f_2(x_1^o + \tilde{x}_1, x_2^o + \tilde{x}_2, u^o + \tilde{u})$.
```

Applying a first-order Taylor series expansion to the right-hand side of the second equation gives

```
$\frac{d}{dt}\tilde{x}_2 = f_2(x_1^o, x_2^o, u^o) + \frac{\partial f_2}{\partial x_1}|_{(x_1^o, x_2^o, u^o)}\tilde{x}_1 + \frac{\partial f_2}{\partial x_2}|_{(x_1^o, x_2^o, u^o)}\tilde{x}_2 + \frac{\partial f_2}{\partial u}|_{(x_1^o, x_2^o, u^o)}\tilde{u} + d$.
```
