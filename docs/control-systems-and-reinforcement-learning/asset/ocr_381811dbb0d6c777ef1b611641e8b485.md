# 10.2.2 Weighted Norm

If we seek an approximation in a weighted norm, then a convenient choice for $G$ is the solution to the $L_2$ optimization problem,

```
$G^w=\min_G ||Q-G||^2_{\omega}=\min_G \mathbb{E}[\{Q(\Phi(n))-G(X(n))\}^2\Phi(n)]$,
```

where the minimum is over all $G: X \to \mathbb{R}$.

```
$<langleQ^w,G^w\rangle_{\omega}=0 \quad \text{for all } G:X \to \mathbb{R}$.
```

The proof of Proposition 10.9 is obtained on setting $G=G^+$, where $G'(x)=1\{x=x^i\}$ for each $i$, where $\{x^i\}$ is an enumeration of the state space X.

**Proposition 10.9** The optimizer is given by

```
$G^w(x)=\frac{1}{\kappa(x)}\sum_u \Phi(u|x)Q(x,u)w(x,u), \quad \kappa(x)=\sum_u \Phi(u|x)w(x,u), \quad x \in X$.
```

If $w$ does not depend upon $u$, this gives

```
$G^w(x)=\widetilde{Q}^{\sim{}}=\sum_u \Phi(u|x)Q(x,u), \quad x \in X.$
```

Hence, in this case, $G^w=\widetilde{Q}^{\sim{}}=h$, so that $V=Q-h$ exactly as in (9.65a).
