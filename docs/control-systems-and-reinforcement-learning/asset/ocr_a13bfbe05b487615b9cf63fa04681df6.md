6.1 Consider the two-state Markov chain on X = [0, 1] with transition matrix

```
$P = \begin{pmatrix} \frac{9}{10} & \frac{1}{10} \ \frac{1}{4} & \frac{3}{4} \end{pmatrix}$
```

+   (First) think probabilistically: Explain why the first hitting time to x = 1 from the starting point X(0) = 0 has a geometric distribution on {1, 2, ...}. Compute the invariant pmf π using Proposition 6.10 (Kac's theorem).

The rest is algebra:

+   (b) Obtain the spectral representation of P,

```
$P = \lambda_1 v^1\mu^1 + \lambda_2 v^2\mu^2$,
```

where {\lambda_i} are eigenvalues, {\mu^i} are left eigenvectors (to be row vectors), and {\v^i} are right eigenvectors (to be columns vectors).

+   (c) Find an expression for P^n. At what rate does P^n(i,j) tend to π(j)?

+   (d) Choose a pair of two-dimensional vectors w and v. The product wv^T is then a 2 x 2 matrix (written with w ⊗ v in this book). Compute the inverse,

```
$G = [I - (P - wv^T)]^{-1}$,
```

and verify that the vector vG is proportional to π. If you are unlucky, and the inverse does not exist; then try a different pair!

This is an example of the Perron-Frobenius construction from Section 3.2.3, for which there is theory available to ensure invertibility. See Example 6.20 for another example.
