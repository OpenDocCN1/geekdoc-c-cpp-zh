# 8.1 Asymptotic Covariance

The rate of convergence of the error sequence $\hat{	heta}_n = \theta_n - \theta^*$ can be measured in terms of the error covariance

```
$$\Sigma_n = E[\hat{	heta}_n\hat{	heta}_n^T]$$
```

from which we obtain the mean-square error (MSE) $\sigma_n^{2} = E[|\hat{	heta}_n||^2] = trace(\Sigma_n).$ When using the step-size $\alpha_n = g/(n+n_0)$ with $n_0 > 0, g > 0$, and $\rho \in (0,1]$, the asymptotic covariance is defined to be the:

```
$$\Sigma_{	hetatheta = \lim_{n\to\infty} n^{\rho}\Sigma_n$
```

The limit exists and is finite under mild assumptions. Moreover, it admits an expression in terms of simple algorithm primitives: The asymptotic covariance of $\{\Delta_n^S\}$ appearing in (8.3b), and the linearization of $f$ at $\theta^*$. See Section 8.2.5 for more details.

Similar to the definition (4.68), we see that $\sigma_n^2$ tends to zero at rate $1/n^{\mu}$ (with $\mu > 0$) for each $\varepsilon > 0$,

```
$$\lim_{n\to\infty} n^{\mu-\varepsilon}\sigma_n^2 = 0 \quad \text{and} \quad \lim_{n\to\infty} n^{\mu+\varepsilon}\sigma_n^2 = \infty.$
```

When (8.6) holds with nonzero limit $\Sigma_{	heta}$, we obtain (8.7) with $\mu = \rho$. For the applications considered in the remainder of this book, the optimal convergence rate is obtained using $\rho=1:

```
$$\sigma_n^2 = E[|\theta_n - \theta^*||^2] = O(1/n)$$
```

In 8.2.5 we see that this is fast only with $g > 0$ sufficiently large when $\alpha_n = g/(n+n)$.
