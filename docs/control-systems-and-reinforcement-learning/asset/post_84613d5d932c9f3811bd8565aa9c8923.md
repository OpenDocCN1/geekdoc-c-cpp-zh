B.2 Computational Aspects of MDPs

The value iteration and policy iteration (improvement) algorithms each have extensions to the MDP setting. These techniques are reviewed here, with a linear programming approach that relates to the LPS introduced in Section 3.5.

This section is devoted to the ACOE (B.6). The relative value function $h^*$ is not unique—we can always add a constant to it. Here is convenient to introduce the additional constraint $h^*(x^*) = \eta^*$, where $\eta^*$ is some distinguished state. Under mild conditions, the solution is then unique, and we eliminate $\eta^*$ from the ACOE:

```
$$\min_u\{c(x,u) + P_u h^*(x)\} = h^*(x) + h^*(x^*).$$
```

Algorithm design begins with the representation of (B.7) as a fixed-point equation: Let $T$ denote the functional that maps $h : X \to \mathbb{R}$, and creates a new function by the following:

```
$$T(h) = \min_u\{c(x,u) + P_u h(x)\} - h(x), \quad x \in X.$$
```

The ACOE can be expressed as the fixed-point equation:

```
$$h^* = T(h^*).$$
```

There are two common approaches to solve a fixed-point equation: The first one is successive approximation, which leads to value iteration algorithm (VIA). The second approach is the Newton-Raphson method, which leads to the policy improvement algorithm (PIA) method.

### B.2.1 Value Iteration and Successive Approximation

In successive approximation, we initialize with a function $h_0 : X \to \mathbb{R}$, and then for $n \ge 0$,

```
$$h_{n+1}(x) = T(h_n)(x) = \min_u\{c(x,u) + P_u h_n(x)\} - h_n(x^*), \quad x \in X.$$
```

The value iteration algorithm is obtained by disregarding $h_n(x^*)$.

### Value Iteration Algorithm (VIA)

VIA is initialized with a function $V_0 : X \to \mathbb{R}$. Then, for each $n \ge 0$,

```
$$V_{n+1}(x) = \min_u \{c(x,u) + P_u V_n(x)\}.$$
```

A policy at stage $n$ is defined as the minimizer:

```
$$\phi_n(x) = \text{arg}_u \{c(x,u) + P_u V_n(x)\}.$$
```

VIA solves a finite horizon optimal control problem:

**Proposition B.1** At stage $n$, we have a sequence of policies $(\Phi_0, ..., \Phi_{n-1})$. The function $V_n$ can be expressed as

```
$$V_n(x) = \min E[\sum_{k=0}^{n-1} c(X_k, U_k) + V_0(X_n)],\,,
```

where the minimum is over all admissible inputs. There is a minimizer that is Markov, but not necessarily stationary.

```
$$U_k^* = \Phi_{n-k}(X_k^*), \quad 0 \le k \le n-1.$$
```

Suppose that $\{V_n\}$ are obtained using VIA, and $\{h_n\}$ are obtained using successive approximation, with common initialization $h_0 \equiv V_0$. It can be shown by induction on $n$ that

```
$$h_n(x) - h_n(x^*) = V_n(x) - V_n(x^*) \text{ for each } x \text{ and } n \ge 0.$$
```

Consequently, we have convergence under mild assumptions [45]:

```
$$\lim_{n\to\infty} |V_n(x) - V_n(x^*)| = h^*(x^*).$$
```

It is argued in [126] that the rate of convergence can be improved by introducing additional “control loops” in the VIA recursion (B.10).

### B.2.2 Policy Improvement and Newton–Raphson

The second well-known algorithm is far more complex per iteration, but often converges very quickly.

### Policy Improvement Algorithm (PIA)

Given an initial policy $\Phi_0$, a sequence $(\phi_n, h_n)$ is constructed as follows: At stage $n$, given $\phi_n$,

- (i) solve Poisson’s equation:
```
$$P_n h_n = h_n - c_n + \eta_n,$$
```

- (ii) construct a policy:
$$\phi_{n+1}(x) = \text{arg}\min \{c(x,u) + P_u h_n(x)\}, \quad x \in X.$$

PIA is a special case of the Newton-Raphson method, in which the function $T$ appearing in (B.8) is replaced by its linearization $\hat{T}_n$ to obtain a sequence of approximations to $h^*$. Given some $h_n$, the mapping $\hat{T}_n$ is defined as a first-order Taylor expansion:

$$\hat{T}_n(h_n) \approx T(h_n) + D_n(h-h_n). \quad (B.15)$$

where $D_n = \nabla T(h_n)$ is a $d \times d$ matrix when $X$ consists of $d$ elements. The Newton-Raphson method then defines $h_{n+1}$ as a solution of the equation

$$h_n = T(h_n) + D_n(h-h_n). \quad (B.16)$$

The functional $T$ may not be differentiable, but we can always find a subgradient $D_n$. This means that for any $h_n$ and any other function $g$,

$$T(h_n) \le T(h_n) + D_n(g).$$

The function $h-T(h)$ is convex, as illustrated in Figure B.1. The following lemma shows how to obtain the gradient of $T(h)$.

**Lemma B.2** For any function $h: X \to \mathbb{R}$, let $\phi+$ denote a policy satisfying
$$\phi_+(x) = \text{arg}\min \{c(x,u) + P_u h(x)\}, \quad x \in X.$$

Let $P_+ = P_{\phi_+}$ and let $S$ the substitution operator for any function $g: X \to \mathbb{R}$ by
$$S(x)=g(x^*), \quad x \in X.$$

**Figure B.1** PIA interpreted as an application of Newton-Raphson. The functional $T$ is piecewise linear for a finite-state/finite-action MDP.

Then a subgradient of $T$ at $h$ is given by $D_h = P_+ - S$. To prove the lemma, we must establish the following pointwise bound for any function $g$:

$$T(h+g) \leq T(h) + P_+g - g(x^*).$$

It will follow that $D_h(g) = P_+g - g(x^*)$. Denote the evaluation $T(h+g)$ at $x$ by $T(h+g)|_x$. The notation $Ph(x)$ and $Ph|_x$ both denote the evaluation of $Ph$ at $x$. Then, on $c_+(x) = c(x, \phi_+(x))$,

$$T(h+g)|_x = \min\{c(x,u) + P_u(h+g)|_x - h(x^*) - g(x^)\} \le c(x) + P_+(h+g) - h(x^*) - g(x^*) = c_+(x) + P_+h(x) - h(x^*) + P_+g = T(h)|_x - g(x^*) + P_+g \quad (B.17)$$

which is the desired (the inequality is obtained by replacing the minimum over $u$ with the particular value $u = \phi_+(x)$).

Given the function $h_n$, denote $\phi_{n+1}(x) = \text{arg}\min_u\{c(x,u) + P_uh_n(x)\}$, and denote the resulting transition law and cost function as follows:

$$P_{n+1} = P_{\phi_{n+1}}, c_{n+1}(x) = c(x, \phi_{n+1}(x)).$$

Then, as $\phi_{n+1}$ is the desired $\phi+$ in the lemma with $h=h_n$, and $P_{n+1}$ is precisely $P_+$. Letting $g_{n+1}=h_{n+1}-h_n$, the lemma provides the representation of the Newton-Raphson update (B.16):

```
$$h_{n+1}(x) = T(h_n)|_x + P_{n+1}(h_{n+1}-h_n)|_x - h_{n+1}(x^*) + h_n(x^*) = c_+(x) + P_+h_n(x) - h_n(x^*) - g_{n+1}(x^*) + P_{n+1}(h_{n+1}-h_n)|_x - h_{n+1}(x^*) + h_n(x^*) \quad (B.18)$$
```

Canceling terms, we conclude that $h_{n+1}$ satisfies the following fixed-point equation:

$$P_{n+1}h_{n+1}(x) = h_{n+1}(x) - c_{n+1}(x) + h_{n+1}(x^*). \quad (B.19)$$

On writing $\eta_{n+1}=h_{n+1}(x^*)$, the identity (B.19) becomes Poisson's equation:

```
$$P_{n+1}h_{n+1} = h_{n+1}-c_{n+1}+\eta_{n+1}.$$
```

This is precisely the PIA.

### B.2.3 LP Formulations

The basic idea of the LP approach is as follows. Let $\varrho$ denote a pmf on state-action pairs $(x,u) \in \mathcal{X} \times \mathcal{U}$. We denote by $\mathcal{G}$ the set of all such measures. That is, $\omega \in \mathcal{G}$ if there is an admissible input $U$ and a subsequence $\{N_i\}$ such that

```
$$\lim_{i\to\infty} \hat{N}_i(x,u) = \varrho(x,u).\quad (B.20)$$

It is known that $\mathcal{G}$ is a polyhedron with a simple characterization:

- (1) Any $\omega \in \mathcal{G}$ is a pmf on $X \times U$. A factorization is obtained via:
```
$$\varrho(x,u) = \pi(x)\phi(u|x) \quad (B.21)$$
```

- (2) $\pi$ is an invariant pmf for $P_\Phi$. The main step in the proof is the following consequence of (B.20):
$$\pi(x) = \sum_{u} \varrho(x,u), \quad \text{all } x,u.$$

Let $P_\Phi$ denote the transition matrix

```
$$P_\Phi(x,x') = \sum_{u} \phi(u|x)P_u(x,x').$$
```

We arrive at a DCPL for the ACOE:

| ACOE Linear Program |
| :--- |
| $\eta^* = \min \sum_{u,x} \varrho(x,u)c(x,u) \quad (B.22a)<br>ns.t. $\sum_{u,x} \varrho(x,u)P_u(x,x') = \sum_{u} \varrho(x',u), \quad x' \in X, \quad (B.22b)<br>\sum_{u,x} \varrho(x,u) = 1, \quad \varrho \ge 0. \quad (B.22c)$ |

Justification is provided in the following. See [63] or [254, section 9.2] for details.

**Proposition 3** The set $\mathcal{G}$ is the convex set characterized by (B.22b, B.22c). The optimizer $\varrho^*$ defines an optimal policy $\phi^*$ via the factorization (B.21).
