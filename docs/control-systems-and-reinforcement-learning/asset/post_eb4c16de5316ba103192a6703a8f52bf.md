Proof of Proposition 10.22 We have by definition

```
$\Delta_n^A \stackrel{\text{def}}{=} \Lambda^0(\Phi(n)) - \Phi(n)) - \Delta H_n^{\omega_n^*} (X(n))$
```

The conditional expectation is

```
$E[\Delta_n^A | \mathcal{F}_n] = E[\Lambda^0(\Phi(n)) V_{\Phi(n)}^* | \mathcal{F}_n] - \Delta H_n^{\omega_n^*} (X(n))]
= E[\Lambda^0(\Phi(n)) V_{\Phi(n)}^* | \mathcal{F}_n] - \Delta H_n^{\omega_n^*} (X(n))]
= 0
```

where the second equality follows from Lemma 10.20. The conclusion $E[\Delta_n^A | \mathcal{F}_n] = 0$ implies that $\{\Delta_n^A\}$ is a martingale difference sequence. Part (i) follows because $\hat{V}_n^{\omega_n^*}(n) = \Delta H_n^{\omega_n^*}(X(n))$ is measurable with respect to $\mathcal{F}_n$, so that $\Delta_n^A$ and $\hat{V}_n^{\omega_n^*}(n)$ are uncorrelated.

For (ii), observe the martingale property implies that $\Delta_n^A$ and $\hat{V}_n^{\omega_n^*}(0)$ are uncorrelated for $n \ge 1$,

```
$E_{\omega}[\hat{V}_n^{\omega_n^*}(n)(\hat{V}_0^{\omega_0^*}(0))^T] = E_{\omega}[\hat{V}_0^{\omega_0^*}(0)(\hat{V}_n^{\omega_n^*}(n))^T]$.
```

Taking transposes of each side, we obtain the same identity for $n \le -1$. Here twice the auto-covariance sequences are identical for $n \neq 0$.

## 10.8 Natural Gradient and Zap

What about the Newton-Raphson flow? If we had direct observations of the gradient, this would become

```
$$\frac{\partial\theta}{\partial t} = -G(\theta)\nabla\Gamma(\theta), (10.53)
```

with $G = [\nabla^2]^{-1}$. Theorem 10.16 might provide a mean to obtain unbiased estimates, but a tractable Zap-SA algorithm is not yet available. Moreover, this approach could compute a local maximum rather than local minimum of $\Gamma$.

There is an alternative choice of matrix gain that is the natural gradient algorithm.

To set notation, let's review theory surrounding the approximation of the critic $Q_\theta$. For the fixed-policy setting with linear function approximation, Theorem 10.14 tells us that the optimal matrix gain is given by $-A^{-1}=R(0)^{-1}$, with $R(0)$ the autocorrelation matrix for the basis.

Consider the minimal class function with compatible features $\psi_\theta = \Lambda^\theta(x, u)$. We have seen that this has mean zero for each $\theta$, so that the autocorrelation coincides with the autocovariance, and the notation $R(0)$ is abandoned in favor of

```
$F(\theta) = \sum_{x,u}^{\text{not}} \Lambda^\theta(x,u)\Lambda^\theta(x,u)^T \theta(x,u), (10.54)
```

This is known as the Fisher information matrix because of its association with a matrix of this name appearing in statistics (see the close of Section 10.10 for further discussion).

For fixed-policy TD-learning with linear function approximation, the asymptotic covariance can be optimized using stochastic Newton-Raphson, and the same is true for this time-scale algorithm. The matrix gain $G(\theta) \overset{est}{F^{-1}}(\theta)$ is also used in the definition of the natural gradient algorithm, whose ODE approximation is (10.53) with this choice of $G$.

Look over the next algorithm carefully: The matrix gain $G_n$ that approximates $F^{-1}(\theta_n)$ appears twice. Its first appearance is used to approximate the natural gradient, and it appears again in the update for $\omega_n$, (version of stochastic Newton-Raphson). The variance might be reduced using the variant technique described in Section 10.7, replacing $\Gamma_{\Gamma}^n(\alpha)$ in (10.52) by $\Gamma_{\Gamma}(n)$.

## Actor-Critic with Zap

The function is defined using $\psi_n = \Lambda^n$. For initialization $R_0 > 0 (d \times d)$, $\theta_0 \in \mathbb{R}$, and $\zeta_0 \in \mathbb{R}^d$,

```
\begin{aligned}
\theta_{n+1} &= \theta_n - \alpha G_n\Gamma_{\Gamma}^n(\theta), \\
\Gamma_{\Gamma}^n(\theta) \overset{est}{=}\Lambda_{\omega_n}^n(\Phi(n)), \quad G_n = R_n^{-1}, & (10.55a) \\
\Lambda_n &= \Lambda^\theta(\Phi(n)), & (10.55b) \\
\Phi(n+1) &= T_{\theta}(z, \cdot), \quad z = \Phi(n), & (10.55c)
\end{aligned}
```

```
\begin{aligned}
\omega_{n+1} &= \omega_n + \beta_n G_n[H_{\omega_n}^n(\Phi(n)) + \bar{c}_n[\Phi(n+1) \neq z^*]], \\
\zeta_{n+1} &= \lambda[\Phi(n+1) \neq z^*]\zeta_n + \psi(\Phi(n+1)), \\
\eta_{n+1} &= \eta_n + \beta_n c_n, \\
c_{n+1} &= c(\Phi(n+1)) - \eta_n, & (10.55d)
\end{aligned}
```

The inverse that defines the matrix gain $G_n = R_n^{-1}$ can be computed efficiently using the Matrix Inversion Lemma (A.1), or an algorithm can be obtained without matrix inversion by adapting the first-order Zap algorithm (8.2). Do not forget the warnings in Section 9.4: If $R_n$ is never invertible, you will need to prune the bias or use pseudo inverse to define $G_n$.

## 10.9 Technical Proofs

The proofs of Theorems 10.11 and 10.15 are similar to the proof of Theorem 9.7, except that we need to understand the impact of regeneration. Recall that $\Phi$ is assumed defined on the two-sided axis. For $\lambda = 1$, the steady-state relation of eligibility vectors is defined by

```
$$\zeta_n = \sum_{k=-\infty}^{n} \gamma^{n-k}\psi(\Phi(k)), \quad n \in \mathbb{Z}. (10.56)
```

That is, we allow negative values of $n$ and $k$ (recall (10.19)).

The following solves half of the “regeneration puzzle.” For any function $g: X \times \mathbb{R}$ and $\gamma \in [0,1]$, denote $\hat{g} = \tau_\gamma^* g$, with

```
$$\hat{g}(z) = E\left[\sum_{k=0}^{\tau_\gamma^*-1}\gamma^k g(\Phi(k)) \mid \Phi(0) = z\right].$$
```

We have $\hat{g} = J_\gamma(g)$ if $g=c$, and $\hat{g} = Hc$ if $g=c$ and $\gamma=1$.

**Lemma 10.23** *The adjoint of $T_\gamma^*$, satisfying $\langle T_\gamma g, h\rangle = \langle g, [T_\gamma^*]h\rangle$ for each $h \in L_2(\Omega)$, is given by*

```
$[T_\gamma^*]h(z) = E\left[\sum_{n=k}^{\tau_\gamma^*-1}\gamma^{n-k}h(\Phi(n)) \mid \Phi(n) = z\right], \quad z \in X \times X, n \in \mathbb{Z},$
```

where $\Phi(k) : k \in \mathbb{Z}$ is a stationary version of the Markov chain. In particular, with $\zeta_n$ defined in (10.56).

```
$E[g(\Phi(n))w(\Phi(n))] = E[g(\Phi(n))\zeta_n].$
```

Proof It is enough to establish the identity for $n=0$. From the definitions,

```
$\langle T_\gamma g, h\rangle = E[h(\Phi(0))\hat{g}(\Phi(0))] = E[h(\Phi(0))E[\sum_{k=0}^{\tau_\gamma^*-1}\gamma^k g(\Phi(k))]].$.
```

The smoothing property of conditional expectation gives

```
$E[h(\Phi(0))\hat{g}(\Phi(0))] = E[h(\Phi(0))\sum_{k=0}^{\tau_\gamma^*-1}\gamma^k g(\Phi(k)].$
```

and then stationarity and the definition of $\tau_\gamma$,

```
$E[h(\Phi(0))g(\Phi(0))] + \sum_{k=1}^{\infty}\gamma^k E[\Phi(j) \neq z^* \mid 1 \le j \le k]h(\Phi(0)),
```
$E[h(\Phi(0))g(\Phi(0))] + \sum_{k=1}^{\infty}\gamma^k E[\Phi(j-k) \neq z^* \mid 1 \le j \le k]h(\Phi(0)),
```

Make the change of variables $\ell = j-k$, so that $\Phi(j-k) \neq z^* \mid 1 \le j \le k = \Phi(\ell) \neq z^* \mid -k \le \ell \le 0$. By adopting this, and returning the sum and the coefficient $\gamma^k$ within the expectation

```
$E[h(\Phi(0))g(\Phi(0))] + E[g(\Phi(0))\sum_{k=1}^{\infty}\gamma^k E[\Phi(\ell) \neq z^* \mid -k \le \ell \le 0]h(-k)].$
```
$E[h(\Phi(0))g(\Phi(0))] + E[g(\Phi(0))\sum_{k=1}^{\tau_\gamma}\gamma^k h(-k)].$
```

where the sum is defined to be zero when $\tau_\gamma=0$. This establishes the desired result for $n=0$.

The second half of the puzzle is solved next:

**Lemma 20.** $E_\gamma$ for any $\gamma \in [0,1]$ and function $H: X \times \mathbb{R}$,

(i) $E_\gamma[-H(\Phi(n)) + \gamma\mathbb{1}\{\Phi(n+1) \neq z^*\}H(\Phi(n+1))] = -E_\gamma[H(\Phi(n))\psi(\Phi(n))]$.
(ii) $E_\gamma[-H(\Phi(n)) + H(\Phi(n+1))] = E_\gamma[\psi(\Phi(n))]$.

*Proof* of the theorem is obtained as a corollary to the previous lemma, using

```
$g(z) = -H(z) + E_\gamma[\mathbb{1}\{\Phi(n+1) \neq z^*\}H(\Phi(n+1)) \mid \Phi(n) = z],
```

so by this property,
$E_\gamma[-H(\Phi(n)) + \mathbb{1}\{\Phi(n+1) \neq z^*\}H(\Phi(n+1))\zeta_n] = E_\gamma[g(\Phi(n))\zeta_n$.

It remains to prove that $E_\gamma[g(\Phi(n))\zeta_n = -E_\gamma[H(\Phi(n))\psi(\Phi(n))]$. Lemma 10.23 gives

```
$E_\gamma[g(\Phi(n))\zeta_n] = E_\gamma[g(\Phi(0))\zeta_0] = E_\gamma[\psi(\Phi(0)) \sum_{k=0}^{\tau-1} \gamma^k g(\Phi(k))] = \sum_{k=0}^{\infty} \gamma^k E_\gamma[\psi(\Phi(0))g(\Phi(k))\mathbb{1}\{k < \tau^*\}].
```

The smoothing property of the conditional expectation provides a useful representation for each expectation:

```
$E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\}g(\Phi(k))] = E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\} \{-H(\Phi(k)) + E_\gamma[\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1)) \mid \mathcal{F}_k]\}]
= E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\} \{-H(\Phi(k)) + \gamma\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))\}].
```

so that on,

```
$E_\gamma[g(\Phi(n))\zeta_n] = \sum_{k=0}^{\infty} \gamma^k E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\}] + \sum_{k=0}^{\infty} \gamma^k E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\} \{\gamma\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))\}]
= -E_\gamma[\psi(\Phi(0)) \sum_{k=0}^{\tau-1} \gamma^{k+1}\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))] - \psi(\Phi(n)) \sum_{k=0}^{\tau-1} \gamma^{k+1}\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))].
```
