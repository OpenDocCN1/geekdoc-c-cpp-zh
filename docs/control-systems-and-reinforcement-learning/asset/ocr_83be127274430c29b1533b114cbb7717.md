# 2.5 A Glance Ahead: From Control Theory to RL

The origin is stable in the sense of Lyapunov. To see this, consider a Lyapunov function defined as the sum of potential and kinetic energy:

```
$V(x) = PE + KE = mg\ell[1 - \cos(x_1)] + \frac{1}{2}m\ell^2x_2^2.$
```

The first term potential energy relative to the height at the equilibrium $x^e = 0$, and the second is the classical $KE = \frac{1}{2}mv^2$ formula for kinetic energy. It is surprising that V is minimized at $^e = 0$.

We have $\nabla V(x) = m\ell^2(g/\ell)\sin(x_1), x_2^T$, and

```
$\nabla V(x) \cdot f(x) = m\ell^2(g/\ell)\sin(x_1) \cdot x_2 - x_2 \cdot (g/\ell)\sin(x_1) = 0.$
```

This means that $\frac{d}{dt}V(x)=0$, and hence $V(x)$ does not depend on time. For example, the periodic orbit shown in Figure 2.8 evolves in a set of V:

```
$\frac{1}{\ell}[1 - \cos(x_1(t))] + \frac{1}{2}x_2(t)^2 = const.$
```

From this follows that the origin is stable in the sense of Lyapunov.

*Linearization:* Using the first-order Taylor series approximation $\sin(\theta) \approx \theta$, the state space equation for the pendulum can be approximated by the LTI model (2.44): $\frac{dx}{dt} = Ax$, with

```
$A = \begin{bmatrix} 0 & 1 \ -g/\ell & 0 \end{bmatrix}. \quad (2.50)$
```

The eigenvalues of $A$ are obtained by solving the quadratic equation $0 = \det(I\lambda - A)$:

```
$0 = \det\left(\begin{bmatrix} \lambda & -1 \ g/\ell & \lambda \end{bmatrix}\right) = \lambda^2 - g/\ell \implies \lambda = \pm\sqrt{g/\ell}j.$
```

The complex eigenvalues are consistent with the periodic behavior of the pendulum.

# 2.5 A Glance Ahead: From Control Theory to RL

Here is a definition from Wikipedia, as seen in July 2020: "Reinforcement learning (RL) is an area of machine learning concerned with software agents to take actions in an environment to maximize the notion of cumulative reward." Here is a translation of some the keys:

+   **Machine learning (ML)** refers to prediction/inference based on sample data.
**Take actions** $\equiv$ feedback. That is, the cost of $u(k)$ for each $k$ based on observations.
**Take agent** $\equiv$ policy $\Phi$. This is where the machine learning comes in: the creation of $\Phi$ is based on a large amount of training data collected in "the environment."
**Cumulative reward** $\equiv$ negative of the sum of cost, as seen as (2.24), but with the inclusion of the input:

```
$Cumulative reward = -\sum_{k} c(x(k), u(k))..$
```
