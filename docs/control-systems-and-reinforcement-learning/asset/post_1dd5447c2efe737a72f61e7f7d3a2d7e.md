In the more compact operator-theoretic notation, this becomes

```
$$PV \leq V - c + \bar{\eta}. \quad (6.27)
```

As in the deterministic case, the function $c$ is usually interpreted as a cost function on the state space. It is frequently assumed that $c(x)$ is large for "large" $x$ (recall the definition of *coercive* from Section 2.4). In this case, the Poisson inequality implies that $V(X(k))$ decreases whenever $X(k)$ is large. ## 6.6.1 Average Cost

Let $\eta(x)$ denote the average cost:

```
$$\eta(x) = \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} E[c(X(k)) \mid X(0) = x].$$
```

Using the operator-theoretic notation (6.9b) gives

```
$$\eta(x) = \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} P^k c(x).$$
```

The dependency on $x$ and the use of "limit supremum" rather than limit in the definition of $\eta(x)$ are both required because we are not imposing any particular structure on $X$. The average cost admits a stable bound under Poisson's inequality (6.27). This is an extension of Proposition 2.3 to the Markovian setting.

**Proposition 6.4** *Suppose that (6.27) holds with $V \geq 0$ everywhere. Then the following transient bounds hold for each $n \geq 1$ and each $x \in X$:*

```
$$\frac{1}{n} \sum_{k=0}^{n-1} P^k c(x) \leq \bar{\eta} + \frac{1}{n}V(x).
```

Consequently, the average cost admits the bound $\eta(x) \leq \bar{\eta}$.

*Proof* Applying $P$ to both sides gives $P^2V \leq PV - Pc + P\bar{\eta}$, and since $\eta$ is constant,

```
$$P^2V \leq PV - Pc + \bar{\eta} \leq V - Pc + 2\bar{\eta}.$$
```

By repeated multiplication by $P$, we conclude that, for each $n$,

```
$$P^nV \leq V + n\bar{\eta} - \sum_{k=0}^{n-1} P^k c.$$$
```

This gives the desired result by rearranging terms and using the assumption that $V \geq 0$. $\square$

We have seen that the average-cost bound given in Proposition 6.4 is tight for a finite space Markov chain, under the assumptions of Theorem 6.3: we can take $V = h + const.,$ where the constant is chosen large enough so that $V \geq 0$.

The beauty of Lyapunov theory is that we can obtain performance bounds without knowing your model. This is illustrated in the next example.

## Example: The Scalar Linear State Model

Consider the scalar model,

```
X(k+1) = \alpha X(k) + N(k+1), \quad k \geq 0, \quad (6.28)
```

where $N$ i.i.d., with zero mean and finite second moment $\sigma_N^2$ (not necessarily Gaussian).
The cost function is the quadratic, $c(x) = \frac{1}{2}x^2$.
Let $V(x) = \frac{1}{2}\kappa x^2$, with $\kappa > 0$. We then have the following:

```
$PV(x) = E[V(X(k+1)) \mid X(k)=x]\\= \frac{1}{2}\kappa(\alpha x + N(1))^2\\= V(x) + \frac{1}{2}\kappa(\alpha^2 - 1)^2 + \frac{1}{2}\kappa\sigma_N^2., \quad (6.29)
```

Provided $|\alpha| < 1$, we can set $\kappa = (1-\alpha^2)^{-1}$ in the definition of $V$ to obtain a solution to Poisson's equation with forcing $\eta$

```
$PV(x) = V(x) + \eta(x), \quad with \ \eta = \frac{1}{2}(1-\alpha^2)^{-1}\sigma_N^2., \quad (6.30)
```

It follows from Proposition 6.4 that $\eta(x) \leq \Gamma$ each $x$. In fact, the preceding steps show that $E[\eta(X(k))] \to \bar{\eta}$ for each initial condition, so we have equality: $\eta(x) = \bar{\eta}$.
If $N$ is Gaussian, then $P^k(x, \cdot)$ converges to a Gaussian $N(0, \sigma_{\eta}^2)$ distribution as $k \to \infty$, with $\sigma_{\eta}^2 = (1-\alpha^2)^{-2}\sigma_N^2$.

## 6.6.2 Discounted Cost

*In the long run we are all dead.* This quote is attributed to John Keynes, and is commonly used to justify the use of discounting in optimal control. I believe this is a mistake in most applications. However, the discounted criterion is sometimes convenient because it is easier to analyze, and is also preferred in many disciplines (in particular, operations research and economics). Lyapunov bounds and their consequences, as presented in (6.4), indicate that a policy with steady-state behavior will have good behavior. In particular, if the average cost is finite, then there is a solution to (6.27), from which we obtain the transient bound. Given a parameter $\gamma \in (0,1)$, the discounted cost from initial condition $x$ is defined as the sum:

```
$h_{\gamma}(x) = \sum_{k=0}^{\infty} \gamma^k E[c(X(k)) \mid X(0)=x]. \quad (6.31)
```

Once again, this has the operator-theoretic form:

```
$h_{\gamma} = \sum_{k=0}^{\infty} \gamma^k P^k c., \quad (6.32)
```

If $c$ is nonnegative valued, the lower bound $h_{\gamma}(x) \geq c(x)$ holds so that the discounted cost is unbiased. And, again, we obtain a bound on $h_{\gamma}$ under Poisson's inequality:

```
$h_{\gamma} = c + \gamma Ph_{\gamma}. \quad (6.33)
```

**Proposition 6.5** If (6.27) holds with $V \geq 0$ everywhere, $h_{\gamma}(x) \leq V + \bar{\eta}(1-\gamma)^{-1}$ for each $x$, and $\gamma \in (0,1)$.

*Proof* The bound (6.27) gives

```
$\gamma PV \leq V - g + \bar{\eta}.$ (634)
```

where $g = (1-\gamma)V + \gamma c$ is a convex combination of the Lyapunov function and the cost function. Applying $\gamma P$ to each side gives

```
$(\gamma P)^2V \leq \gamma PV - \gamma g + \gamma\bar{\eta}.$
```

and then, using (6.34),

```
$(\gamma P)^nV \leq V - \sum_{k=0}^{n-1} \gamma^k g + \sum_{k=0}^{n-1} \gamma^k \bar{\eta}.$
```

As in the average-cost problem, we obtain by induction from the definition $g = (1-\gamma)V + \gamma c$ that:

```
$\sum_{k=0}^{\infty} \gamma^k P^k c(x) + (1-\gamma)V(x) \leq V(x) + \frac{\bar{\eta}}{1-\gamma}.$ (6.35)
```

Using the fact that $V \geq 0$, we can drop all terms involving $V$ on the left side of (6.35) to obtain:

```
$(1-\gamma)V(x) + \sum_{k=0}^{\infty} \gamma^k P^k c(x) \leq V(x) + \frac{\bar{\eta}}{1-\gamma}.$
```

The bound $h_{\gamma} \leq V + \bar{\eta}(1-\gamma)^{-1}$ by subtracting $(1-\gamma)V(x)$ from each side and dividing the resulting inequality by $\gamma$.

**Example 6.4.1** Discounted Cost for the Linear State Model with cost $c(x) = \frac{1}{2}x^2$, the solution to Poisson's equation was obtained in (6.30). Proposition 6.5 gives the bound $h_{\gamma} \leq V + \bar{\eta}(1-\gamma)^{-1}$, in which case becomes

```
$h_{\gamma}(x) \leq \frac{1}{1-\alpha^2}[x^2 + \frac{\sigma^2}{1-\gamma}]. (6.36)
```

We next compute $h_{\gamma}$ to see if this bound is accurate. For this, we begin with the dynamic programming equation (6.33). We let $V(x) = A_{\gamma} + \frac{1}{2}\kappa x^2$, with $A_{\gamma}, \kappa_{\gamma}$ constants to be chosen. From (6.29), we have

```
$PV \leq \alpha^2 V + (1-\alpha^2)A_{\gamma} + \frac{1}{2}\kappa\sigma^2.$
```

Scaling by $\gamma$ and adding $c$ to each gives

```
$c+\gamma PV=c+\gamma(\alpha^2 V+(1-\alpha^2) A_{\gamma}+\kappa_{\gamma}),$
```

or, reintroducing the quadratic expressions,

```
$c(x)+\gamma PV(x)=\frac{1}{2}(1+\gamma^2\kappa_{\gamma})x^2+\frac{1}{2}(\kappa_{\gamma}\sigma_{N}^2+A_{\gamma}).$
```

To solve the dynamic programming equation, we require that the right-hand side matches with $V$. This requires that we match coefficients: $1+\gamma^2\kappa_{\gamma}=\kappa_{\gamma}$, and $\gamma(\frac{1}{2}\kappa_{\gamma}\sigma_{N}^2+A_{\gamma})=A_{\gamma}$, giving

```
$h_{\gamma}(x)=A_{\gamma}+\frac{1}{2}\kappa_{\gamma}x^{2}=\frac{1}{1-\gamma \alpha^{2}}[x^{2}-\frac{\gamma}{1-\gamma}\sigma_{N}^{2}].$
```

In particular, the bound (6.36) holds.

## 6.7 Simulation: optimal control, we face Confidence Bounds and Control Variates

In average-cost optimal control, we are faced not with a single Markov chain, but an entire family: one Markov chain for each in a family of policies. We would like to estimate the average cost $\eta=\pi(c)$ for many different policies so we can select the best in the family. Lyapunov functions provide bounds, but it is rare to obtain bounds that are sufficiently tight so that we can determine which policy is optimal. Without alternatives, in the majority of cases we resort to simulation.

## 6.7.1 Asymptotic Statistics Make Finite

We are blessed by the fact that the Law of Large Numbers (LLN) holds whenever there is an invariant probability measure $\pi$. The Monte Carlo estimate based on $n$ samples is denoted

```
$$\eta_{n}=\frac{1}{n}\sum_{k=0}^{n}c(X(k)).$$ (6.37)
```

The LLN tells us that this is asymptotically consistent:

```
$$\lim_{n\to\infty}\eta_{n}=\eta.$$ (6.38)
```

where the limit holds with probability one, for almost every (with respect to $\pi$) initial condition $X(0)$. In most cases, the limit holds for every initial condition.

The next question is the rate of convergence. This is it most common to turn to the Central Limit Theorem, which tells us that

```
$$\lim_{n\to\infty}P{\eta_{n}-\eta|\geq r/\sqrt{n}}=P{\sigma_{clt}|W|\geq r},\quad r>0,\$$ (6.39)
```
