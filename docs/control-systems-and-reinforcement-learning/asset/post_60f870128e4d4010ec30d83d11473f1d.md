
# 10.4 Average Cost and Every Other Criterion

## Finite-Horizon

Let $N \ge 1$ and $z^* \in \mathbb{Z}$ be given, consider the finite horizon criterion

$$\Gamma = E\left[ \sum_{k=0}^{\mathcal{N}^\star_{\mathcal{N}}} \gamma^k c(\Phi(k)) \right], \quad \Phi(0) \sim \mu,$$ (10.27)$$

$$\mathcal{N}^\star = \min\{k \ge 1 : \Phi(k) = z^*\}; \mathcal{N}^\star_{\mathcal{N}} = \min(N, \mathcal{N}^\star),$ and $\gamma > 0$ is arbitrary. This is the shortest problem with $\mathcal{N} = \infty$ and $\gamma = 1$.

To construct a Markov chain $\Psi$ for which (10.27) is proportional to average cost we require a different construction. We define $\Psi$ as a pair process $\Psi(k) = (\Phi(k), k)$, where the setting $t$ is defined to be deterministic and periodic: $t = k \pmod N$. The regeneration times are also deterministic: $\mathcal{N}_n = nN$ for $n \ge 1$, and the construction is defined such that the sequence $(\Phi(\mathcal{N}_n) : n \ge 1)$ is i.i.d. with marginal $\mu$.

We borrow from the discounted cost setting with $\Psi$: The state space $Z$ is enlarged to include a graveyard state denoted $\blacktriangle$. Here the state space for $\Psi$ is $[Z \cup \blacktriangle] \times \{0, \dots, N-1\}$. The dynamics on each interval $\mathcal{N}_n < k < \mathcal{N}_{n+1}$ are defined as follows:

- (i) $\Phi(k) = \blacktriangle \mid\Phi(k-1) = z^*$; $\Phi(k) = \blacktriangle \mid\Phi(k-1) = \blacktriangle| = 1$.
- (ii) $\Phi(k) = z' \mid\Phi(k-1) = z| = T(z, z')$ for $z, z' \in \mathbb{Z}$, where $z \neq z^*$.

As in the discounted case, there is a simple interpretation that leads to simulation or experimental design: for $n$, initialize $\Phi(\mathcal{N}_n) \sim \mu$, independent of samples of the state process according to the natural dynamics of $\Phi(k) : k < \mathcal{N}_{n+1}$ for $\mathcal{N}_n < k < \mathcal{N}_{n+1}$, stopping the experiment if $z^*$ is reached during this interval.

The cost function is defined by $c(\blacktriangle) \doteq 0$, and $c(z) \doteq \gamma^t c(z)$ for $z \in \mathbb{Z}$ and $t \in \{0, \dots, N-1\}$.

An analog of Proposition 10.12 is obtained through this construction:

**Proposition 10.13** The partial sums $\{S_n\}$ in (10.24) are i.i.d. with common mean $\Gamma$, now defined in (10.27). Consequently, the average cost is given by

$$\lim_{N \to \infty} \frac{1}{N} E\left[ \sum_{k=1}^N c(\Phi(k)) \right] = \Gamma.$$

Proposition 10.13 also applies to the truncated discounted-cost criterion:

$$\Gamma = E\left[ \sum_{k=1}^{\mathcal{N}^\star} \gamma^k c(\Phi(k)) \right], \quad \Phi(0) \sim \mu.$$

This may be preferred to the infinite horizon objective (10.25), since the use of deterministic regeneration cycles will lead to lower variance.

Both regeneration and relative DP equations are used next to construct algorithms designed to estimate the solution of Poisson’s equation (9.56). Regeneration motivates the representation $H_3$ given in (10.17), which is the unique solution $H_3(z^*) = 0$.

## 10.4.2 Average-Cost Algorithms

### Setting the Stage, Return of the Actors

We begin with an algorithm inspired by the regenerative algorithm (10.20) and Theorem 10.11.

### Regenerative TD(\lambda) Algorithm for Average Cost (On-Policy)

For initialization $\theta_0, \zeta_0 \in \mathbb{R}^d$, the sequence of estimates are defined recursively:

```
$$\theta_{n+1} = \theta_n + \alpha_n + \zeta_n\mathcal{D}_{n+1},$
$\mathcal{D}_{n+1} = (-H^{\theta}(\Phi(n)) + \tilde{c}_n + \mathbb{1}\{\Phi(n+1) \neq z^*\})H^{\theta}(\Phi(n)))_{\theta=\theta_n}$
$\zeta_{n+1} = \lambda\mathbb{1}[\Phi(n+1) \neq z^*]\zeta_n + \psi(n),$$
$\eta_{n+1} = \eta_n + \tilde{c}_n/(n+1), \quad \tilde{c}_n = c(\Phi(n)) - \eta_n, \quad n \geq 0.$
```

This is a linear SA algorithm based on a slight modification of (10.21); $\gamma = 1$ in the definition of $A_{n+1}$ and $b_{n+1} = -\zeta_n[c_n - \eta_n]$. The associated ODE is thus linear, vector field.

**Theorem 10.14 ($L_2$ Optimality of TD(1) for Average Cost**) Consider the algorithm (10.28) with linear function approximation $H^{\theta} = \theta^T\psi$. Assume that $\Phi$ is uni-chain and $\alpha(z) > 0$.

Then, in the case $\lambda = 1$,

- (i) $A = -R(0)$.
- (ii) Any solution to $f=0$ ($f^{\theta} = E_{\zeta_n}\mathcal{D}_{n+1}$) solves the minimum norm problem:

```
$$\theta^* = \arg\min ||H^{\theta} - H_3||_{\infty}^2 = \arg\min E_{\zeta_n}[(H^{\theta}(\Phi(n)) - H_3(\Phi(n)))^2],
```

where $H_3$ is the solution to Poisson's equation

```
$H_3(z) = E[\sum_{k=0}^{\infty} \tilde{c}(\Phi(k)) \mid \Phi(0) = z].$
```

Once again, in most cases it is best to use LSTD(1) formulation (10.23) if the function class is linear. It is anticipated that an algorithm derived from recursive DP equation will have lower variance. Consider

```
$0 = -H(\Phi(k)) - \delta(\mu, H) + c(\Phi(k)) + H(\Phi(k+1)) \mid \Phi(k) = z, \quad z \in X \times U.
```

The function $H$ is the unique solution to Poisson's equation $\delta(\mu, H) = \eta$. Consequently,

```
$H(z) - H(z^*) = H_3(z), \quad z \in X \times U.
```

Given the foregoing, we have a natural candidate for approximation in which estimation of $\eta$ is abandoned.

### Regenerative TD($\lambda$) Algorithm for Average Cost

For initialization $\theta_0, \zeta_0 \in \mathbb{R}^d$, the sequence of estimates is defined:

```
$$\theta_{n+1} = \theta_n + \alpha_n + \zeta_n\mathcal{D}_{n+1}.$$
$\mathcal{D}_{n+1} = (-H^{\theta}(\Phi(n)) + \tilde{c}_n + \mathbb{1}\{\Phi(n+1) \neq z^*\})H^{\theta}(\Phi(n)))_{\theta=\theta_n}$
$\zeta_{n+1} = \lambda\mathbb{1}[\Phi(n+1) \neq z^*]\zeta_n + \psi(n).$$
```

We have $\theta_{n+1} = \theta_n + \alpha_n[A_{n+1} - b_n]$ with

```
$$A_{n+1} = \zeta_n[-\psi(n) - \delta\psi^{\mu} + \psi(n+1)]^T, \quad b_{n+1} = -\zeta_nc_n.$$
```

where $\psi^\mu = (\mu, \psi_i)$ for each $i$. We have the following companion to Theorem 10.14:

**Theorem 10.15 (Optimality of TD(1) for Average Cost)** Consider the algorithm (10.32) with linear function approximation $H^{\theta} = \theta^T\psi$. Assume that $\Phi$ is uni-chain, that $\varrho(z^*) > 0$, and for some parameter $z^* \in \mathbb{R}^d$

```
$$\sum \theta_i\psi_i(z) = \mathbb{1}[z = z^*], \quad z \in X \times U.
```

Then, in the case $\lambda = 1$, for any solution to $f(\theta) = 0$,

- (i) $\delta = \langle\mu, H^{\theta}\rangle$.
- (ii) The “projected Poisson’s equation” has: $Y = \psi(\Phi(n)),$
```
$$H^{\theta}(\Phi(n)) = \mathbb{E}[H^{\theta}(\Phi(n)) + H^{\theta}(\Phi(n+1)) \mid Y].$$
```
- (iii) Suppose in addition that 1 is in the span of the basis: for some $\theta^1 \in \mathbb{R}^d$,

```
$$\sum \theta_i^1\psi_i(z)=1, \quad z \in X \times U.
```

Then, $H^{\theta}(\Phi(n)) = \mathbb{E}[H_3(\Phi(n)) + H^*(z^*) \mid Y]$, and the minimum norm problem is solved in the following semiminorm with $r^* = H^*(z^*)$:

```
$$(\theta^*, r^*) = \arg\min \mathbb{E}_{\omega}[(H^{\theta}(\Phi(n)) - H_3(\Phi(n)))^2].
```

Unfortunately we lose the elegant expression $A = R(\theta)$ for this algorithm. A glance at the proof reveals that,

```
$$A = \mathbb{E}[\zeta_n[-\psi(n) - \delta\psi^{\mu} + \psi(n+1)]^T.$$
$$b = -\delta\mathbb{E}_{\omega}[\zeta_n\psi^{\mu}]^T + \mathbb{E}_{\omega}[\psi(n)\{-\psi(n) + \psi(z)\}]^T.$$
```

It can be shown that $A$ is invertible for sufficiently small $\delta > 0$ provided $\psi^*R(0)^{-1}\psi^*(z) < 1$. Moreover,

```
$$\hat{\psi}^T R(0)^{-1}\psi(z) < \sqrt{\psi(z)^T R(0)^{-1}\psi(z)}.$$
```

which might lead to choices for basis selection to ensure the right-hand side is no greater than one. One approach to ensure $A$ is Hurwitz is not yet available, so this approach may be best implemented using stochastic Newton–Raphson, implemented as LSTD(1). The estimate at final $N$ would then be defined by (10.23) where the “hats” represent sample path averages of $\{A_n, b_n\}$ defined in (10.33).

## 10.5 Gather the Actors

We meet the actors briefly at the start of this chapter, defined to be a family of randomized policies $\{\phi^{\theta} : \theta \in \mathbb{R}^d\}$. It is assumed henceforth that they are continuously differentiable in $\theta$. Examples include the Gibbs policy (9.6a), and the linear family:

```
$$\phi^{\theta}(u|x) = \sum_{i=1}^d \theta_i \phi^i(x)$$
```

where $\{\phi^i : 1 \leq i \leq d\}$ is a preselected family of deterministic policies, and the parameter is constrained to be nonnegative and sum to unity: $\theta \in \mathbb{R}^d$, and $\sum_i \theta_i = 1$. The linear family (10.35) can be regarded as a compression of the input, replacing $U$ with the set of $d$ indices $I = \{1, \dots, d\}$, with $\theta_i$ interpreted as the probability of choosing index $i$.
