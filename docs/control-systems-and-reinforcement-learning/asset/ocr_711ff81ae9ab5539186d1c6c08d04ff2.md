# Events

What is $(\Omega, \mathcal{F}, P)$? First, recall that the $\sigma$-field $\mathcal{F}$ denotes the domain of the *events*. Each event $A \in \mathcal{F}$ must be a subset of $\Omega$, and $\mathcal{F}$ defines the domain of the probability measure $P$. By “domain,” we mean that $P(A)$ is defined only if $A \in \mathcal{F}$, and not for any other subset $A \subset \Omega$.

To be a $\sigma$-field, $\mathcal{F}$ must be closed under union and finite intersections. Please review this material, along with the definition of sub-$\sigma$-fields and conditional expectation. The first chapter of Jaeger's textbook [154] is a reference which

A (real-valued) random variable $H$ is a mapping $H: \Omega 	o \mathbb{R}$ that is measurable with respect to $\mathcal{F}$. That, the set $E_c = \{\omega : H(\omega) \le c\}$ is an event (i.e., $E_c \in \mathcal{F}$) for each $c \in \mathbb{R}$. We write $P(H \le c)$ for the probability of the event: $P(E_c)$.

A *stochastic process* is a family of random variables indexed by time. If we discrete time, and restrict to times $k \ge 0$, a stochastic process is a sequence of random variables denoted $X = \{X_k : k \in \mathbb{Z}_+\}$. Subscripts are adopted for sequence of random variables, and we need to ensure $X_k$ is a function on $\Omega$ for each $k$.

Suppose that random variable takes values in a discrete set $X$. For an integer $N \ge 1$, denoted by $\mathcal{F}_N \subset \mathcal{F}$ the $\sigma$-field that contains events of the

> $$$E_{(x_0, \dots, x_N)}=\{\omega \in \Omega : X_k(\omega)=x_k, \quad 0 \le i \le N\}\quad(A.2)$$

for any collection $\{x_i\} \subset X$. If $H$ is a random variable on $(\Omega, \mathcal{F}_N, P)$, then there is a function $h: X^{N+1} 	o \mathbb{R}$ such that

> $$$H(\omega)=h(X_0(\omega), X_1(\omega), \dots, X_N(\omega), \quad \omega \in \Omega.$$

# Sample Space

The set $\Omega$ is the sample space, whose definition is a modeling choice. When studying a single stochastic process, it is convenient to choose the set of all possible sample sequences. That is, each $\omega \in \Omega$ is a sequence of:
