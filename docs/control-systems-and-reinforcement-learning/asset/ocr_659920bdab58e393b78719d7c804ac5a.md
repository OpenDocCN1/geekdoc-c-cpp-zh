# 9.1 Policy Improvement

(ii) Construct a new policy:

```
$\Phi_{n+1}(x) = \arg\min_{u} c(x,u) + \gamma P_u h_n(x), \quad x \in X, \quad (9.9b)$
```

where $P_u^\gamma h_n(x)$ is defined in (7.15).

This algorithm is consistent, with $h_n(x) \downarrow h(x)$ for each $x$, as $n \to \infty$ (the fact that $h_n(x)$ is nonincreasing is a corollary to Proposition 9.2). TD-learning algorithms are designed to approximate the solution to (9.9a). However, we cannot update the updated policy (9.9b) unless we have the model $P_u$, and are also prepared to solve the minimization over $u$ for each $x$. A potential solution to both challenges is to approximate the function of two variables within the brackets in (9.9b), the fixed-policy Q-function associated with the policy $\Phi_n$:

```
$Q_n(x,u) = c(x,u) + \gamma P_u h_n(x)$.
```

```
$Q_n(x,u) = \sum_{k=0}^{\infty} \gamma^k E[c(\Phi(k)) | \Phi(0) = x,u] \quad \text{with } U = \Phi_n(X(k)) \text{ for } k \ge 1$,
```

along with a fixed-point iteration that varies up to (9.9a):

```
$0 = E[-Q_n(\Phi(n)) + c(\Phi(n)) + \gamma Q_n(\Phi(n+1)) | F_n], \text{with } U = \Phi_n(X(k)) \text{ for each } k,$\nand with $F_n$ shorthand for $\Phi(0), \dots, \Phi(n).$ Any TD-learning algorithm can be applied
to approximate this Q-function, which is made possible by recognizing that the pair process
$\mathbf{\Phi}$ is a time-homogeneous Markov chain, whenever $U$ is defined using a stationary Markov
policy.
```

A TD-learning algorithm designed to estimate a fixed-policy Q-function is commonly
known as SARSA. However, as explained in Section 5.3, we will opt for the TD-learning
regardless of whether we are estimating $h$ or $Q$.

# 9.3 Advantage Functions

If we compute exactly the Q-function for a policy $\Phi$, then the policy improvement step
gis given by $\Phi^+(x) \arg\min_u Q(x,u)$. Rather than estimate $Q$, we could estimate $Q-G$
for any function $G$ that does not depend upon $U$. The Q-policy greedy is:

```
$\Phi^+(x) = \arg\min_u [Q(x,u) - G(x)] = \arg\min_u Q(x,u). \quad (9.10)$
```

A reasonable way to choose $G$ is by minimizing the mean-square error:

```
$G^* = \arg\min_G ||Q - G||^2 = \arg\min_G E_{\pi}[|Q(\Phi(n)) - G(X(n))\|^2],
```

where the subscript indicates that the expectation is in steady state.
