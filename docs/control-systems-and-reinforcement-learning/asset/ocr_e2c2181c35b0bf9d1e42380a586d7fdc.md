**Theorem 4.25** Suppose that the assumptions of Theorem 4.24 hold, so that in particular $a_t = 1/(1+t)^\rho$ with $\rho \in (0,1)$. Then, with $\Theta_t^*$ defined by (4.12c), with $\kappa > 1$, we have

```
$$\Theta_t^* = \Theta^* + a_t\kappa(\rho,\kappa)Y + \Phi_T,$ \quad (4.1222)$
```

Where $\Y$ is defined in (4.12b), and $\kappa(\rho,\kappa) = \kappa(1-(1/\kappa)^\rho)/(-\rho)$, and where $\{\Phi_t\}$ is a bounded function of time. Consequently, the convergence rate is $1/T$ if and only if $\Y \neq 0$.
