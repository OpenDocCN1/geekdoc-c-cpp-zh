# 3.7 A Second Glance Ahead

Now, to the derivation of (342). The variables in the linear program introduced in Proposition 3.10 consist of functions $J$ and $Q$. For the LQR problem, we restrict to quadratic functions

```
$J(x) = x^T M^J x, \quad Q(x,u) = z^T M^Q z$
```

and the symmetric matrices $(M, M^Q)$ as variables. To establish (3.42), we are left to show (1) the objective functions (3.36a) and (3.42a) coincide for some $v$, and the (2) functional constraints (3.36b, 3.36c) are equivalent to the matrix inequality (3.42b). The first task is the simplest:

```
$trace(M) = \sum_{i=1}^n J(e^i) = \langle v, J \rangle$
```

with $\{e^i\}$ the standard basis elements in $\mathbb{R}^n$, and $v(e^i) = 1$ for all $i$. The equivalence of (3.42b) and (3.36b, 3.36c) is established next, and through this we also obtain (3.41c). In view of the preceding discussion (3.37), the inequality (3.36b) can be strengthened to:

```
$Q^*(x,u) = c(x,u) + J^*(Fx+Gu)$
```

It remains to establish the equivalence of (3.42b) and (3.37). Applying (3.38), we define a mapping from $M$ to $M^Q$. Denote

giving for all $x$ and $z^T = (x^T, u^T)$

```
$J(x) = x^T M^J z, \quad J(Fx+Gu) = z^T \Xi^T M^J \Xi z$.
```

And this (3.38), for any $z$,

```
$z^T M^Q z = Q(x,u) = c(x,u) + J(Fx+Gu) \n = z^T M^C z + z^T \Xi^T M^J \Xi z$.
```

The desired mapping from $M$ to $M^Q$ then follows, under the standing assumption that $M^Q$ is a symmetric matrix:

```
$M^Q = M^C + \begin{bmatrix} S & 0 \ 0 & R \end{bmatrix} + \begin{bmatrix} F^T MF & F^T MG \ G^T MF & G^T MG \end{bmatrix}$
```

The constraint (3.37) is thus to equivalent

```
$z^T M^J z \leq Q(x,u) = z^T M^Q z$, for all $z$.
```

This is equivalent to the constraint $M^J \leq M^Q$, which is (3.42b).
