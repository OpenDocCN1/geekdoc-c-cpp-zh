# Shortest Path Problem (SPP) Given a target set $S \subset X$ and a terminal cost $V_0: S ightarrow \mathbb{R}$, define for each $x \in S^0$:

```
$h^*(x) = \min E_x \left[sum_{k=0}^{	au_S-1} c(\Phi_k) + V_0(X_{	au_S})\right].$
```

This is transformed to the total-cost problem by the enlargement of X to include a graveyard state denoted $	riangle$. The “graveyard property” indicates that $P_u(\triangle, \triangle) = 1$ for each $u$, and we impose $P_u(x, \triangle) = 1$, for $x \in S$ and any $u$. The cost function is also modified: $c(x, u) = V_0(x)$ for $x \in S$, and $c(\triangle, u) = 0$ for each $u$. Under these conventions, the value function for the SP can be represented as (B.1).

Discounted-Cost Value Function Given a discount factor $\gamma \in [0, 1]$,

```
$h^*(x) = \min E_x \sum_{k=0}^{\infty} \gamma^k E_x[c(\Phi_k)]. (B.2)
```

Enlarge the state space for the MDP with a geometric random variable $T$ with parameter $\gamma$, and independent of everything:

```
$P[T \geq k | \Phi_0^x] = \gamma^k$.
```

Then $\Psi_k = (X_k, B_k)$ is a Markovian state, with $B_k = \mathbb{1}[T \geq k]$. Independence of **X** and **B** implies that

```
$\gamma^k E_x[c(\Phi_k)] = E_x[c(\Phi_k)B_k].
```

Consequently,

```
$h^*(x) = \min E_x \sum_{k=0}^{\infty} c(\Psi_k, U_k)].$
```

with $\widehat{c}(z,u) = c(x,u)b$ when $z = (x,b)$.
