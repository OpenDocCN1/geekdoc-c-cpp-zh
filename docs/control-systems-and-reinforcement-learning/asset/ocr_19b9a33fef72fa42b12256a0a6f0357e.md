# 7.6 A Queuing Game

We return now to the two-station network model with four-dimensional queue-length processes introduced in Section 3.9.3.

An MDP model can be obtained by analogy with the fluid model described there. We might
might opt for an extension of the CRW model for the single queue (7.29), in which the four buffers evolve in discrete time as:

```
$X_1(k+1) = X_1(k) - S_1(k+1)U_1(k) + A_1(k+1)$,
$X_2(k+1) = X_2(k) - S_2(k+1)U_2(k) + S_1(k+1)$,
$X_3(k+1) = X_3(k) - S_3(k+1)U_3(k) + A_3(k+1)$,
$X_4(k+1) = X_4(k) - S_4(k+1)U_4(k) + S_3(k+1)$,
```

in each $S_i(k)$ is Bernoulli with mean $\mu_i$, and each $A_i(k)$ has mean $\alpha_i$ and finite variance. This is subject to a Controlled Markov chain, it is necessary to assume that the six-dimensional stochastic process $(S, A)$ is i.i.d. The input process is subject to the same constraints as the fluid model, but in addition it is assumed that $U_i(k)$ takes values zero or one for each $i$ and $k$. Solidarity between the fluid model and this MDP model is investigated in [159], where you can find numerical results similar to what was obtained for the single queue.

We can now explain the simulation on the left-hand side of Figure 3.6: The random variables $S_i(k), A_i(k)$ are all Bernoulli and highly dependent in the sense that only one is nonzero at time $k$.

Let's consider a problem where we cannot solve using the theory in this: Restrict each input to be a function of *local information*. This is a game, because the decision at a station is based only on the history of buffers at that station. We consider a *cooperative* setting, in which the two players (stations) have a common goal of minimizing the long-run average cost.

By imposing symmetry, we can simplify the problem by imposing the following constraint: $X^1(k) = (X_1(k), X_4(k))$, $X^2(k) = (X_3(k), X_2(k))$, and the input is of the form

```
$U_1(k) = \Phi_a(X^1(k))$, $U_2(k) = \Phi_b(X^2(k))$,
$U_4(k) = \Phi_b(X^1(k))$, $U_3(k) = \Phi_a(X^2(k))$,
```

Our goal is to find $\Phi^*$ that minimizes the average cost, with $c(x,u) = \sum x_i$. The information structure may be motivated by the desire to reduce communication cost, which is easily the case in applications to global chains. In this, the network models a simple business, with geographically separated manufacturing. Noncooperative games can be addressed using the concepts introduced here.
