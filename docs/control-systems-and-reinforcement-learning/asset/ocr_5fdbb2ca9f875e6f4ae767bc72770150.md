z(k) = z^{goal} (the car is parked once it reaches its target). The following values are chosen in numerical experiments:

z^{min} = -1.2, z^{goal} = 0.5, \bar{v} = 70. \quad (2.58c)

Here is an aggressive policy that will get you to the top: Wherever you are going, accelerate in that direction at maximum rate (provided this is feasible):

```
u(k) = \begin{cases} 0 & z(k) = z^{goal} \ sign(v(k)) & else \end{cases} \quad (2.59)
```

If v(k) = 0, sign(v(k)) can be taken to be 1 or -1, subject to the constraint that v(k+1) \neq 0.

# 2.7. MagBall

The magnetically suspended ball illustrated in Figure 2.12 will be used to illustrate important modeling concepts. In particular, it shows how to transform a set of nonlinear differential equations into a state space, and how to approximate this by a linear state space model of the form (2.20). Further details from a control systems perspective may be found in the lecture notes [29].

The input u is the current applied to an electromagnet, and the output y is the distance between the center of the ball and the bottom of the magnet. Since positive and negative inputs are indistinguishable at the output of this system, it follows that this cannot be a linear system. The upward force due to the current is approximately proportional to $u^2/y^2$, and hence from Newton's law for translational motion we adopt the model

```
ma = m\frac{d^2}{dt^2}y = mq - \kappa \frac{u^2}{y^2}
```

where q is the gravitational constant, and \kappa is some constant depending on the physical properties of the magnet and ball.

Control goal: Maintain the distance to the magnet at some reference value r. We obtain a state space model as a first step to control design. This input-output model can be converted to a state space form to obtain something similar to the controllable form description of the ARMA model in (2.16) and (2.18): using $x_1 = y$ and $x_2 = \frac{d}{dt}y$.

```
\frac{d}{dt}x_1 = x_2, \frac{d}{dt}x_2 = g - \frac{\kappa u^2}{m x_1^2}
```
