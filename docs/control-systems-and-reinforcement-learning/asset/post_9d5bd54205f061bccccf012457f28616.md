## 3.2.2 Policy Improvement

The policy improvement algorithm (PIA) starts with an initial policy $\Phi^0$, and updates recursively as follows: For policy $\Phi^n$, the associated total cost is:

$$J^n(x) = \sum_{k=0}^{\infty} c(x,u(k)), \quad u(k) = \Phi^n(x(k)) \text{ for each } k, \quad x(0) = x \in X. (3.12)$$

This solves the fixed-policy Bellman equation,

$$J^n(x) = \|c(x,u) + J^n(F(x,u))\|_{u=\Phi^n(x)} \quad (3.13)$$

This is followed by the policy improvement step to obtain the next policy:

$$\Phi^{n+1}(x) = \arg\min_u \{c(x,u) + J^n(F(x,u))\}, \quad x \in X. (3.14)$$

The proof of the tracking is similar to the proof of Proposition 3.3. The proof that the value functions are nonincreasing is an application of Proposition 2.3.

**Proposition 3.4** Suppose that $\Phi^0$ is stabilizing, in the case that $J^0$ is finite valued. For each $n \geq 0$,

$$\|c(x,u) + J^n(F(x,u))\|_{u=\Phi^{n+1}(x)} \leq J^n(x), \quad x \in X.$$

Consequently, the value functions are nonincreasing:

$$J^0(x) \geq J^1(x) \geq J^2(x) \geq \dots$$

## 3.2.3 Perron-Frobenius Theory: A Gentle Introduction*

One step in the PIA requires a subroutine: how to solve the fixed policy dynamic programming equation (3.13)? The purpose here is to present an efficient approach to computing the value function when the state space is finite; this is also a prelude to theory for Markov chains, as well as spectral graph theory that arises in ML.

Let's return for a moment to the setting of Section 2.4, where we considered the state space model without control:

$$x(k+1) = F(x(k)), \quad k \geq 0,$$

and associated value function (2.24), recalled here:

$$J(x) = \sum_{k=0}^{\infty} c(x(k)), \quad x(0) = x \in X.$$

The value function satisfies a version of (3.13), which in (2.25) is expressed in the simpler form

$$J(x) = c(x) + J(F(x)), \quad x \in X. (3.15)$$

Much of Perron-Frobenius theory concerns classification of fixed point equations involving matrices. To apply this theory, we need a matrix. Assume the state space is finite, and the set of positive integers: $X=\{1,2,3,...,N\}$ for some $N > 1$. Assume that $x^e = N$, which satisfies $F(N) = N$; Assume that $c(N) = 0$, and that the value function is finite valued.

Define an $N \times N$ transition matrix $P$ as follows: $P(i,j) = 0$ or 1 for each $i$ and $j$, and $P(i,j) = 1$ means that the $i$-th row of $P$ has exactly one nonzero element. In particular, $P(N,N) = 1$ characterizes the equilibrium property. With this notation, we have a new way of thinking about the fixed-policy dynamic programming equation:

$$J(i) = c(i) + \sum_{j=1}^{N} P(i,j)J(j), \quad 1 \leq i \leq N. (3.16)$$

Now, dear reader: accept a new way of thinking about notation:

$$J = \tilde{c} + PJ. (17)$$

That is, $J$ is an $N$-dimensional column vector whose element is $J(i)$, and definition of $\tilde{c}$ is analogous. I am pleased with you here because I know from experience that graduate students feel uncomfortable going from (15) to (17). At first glance, it seems clear that we can solve this equation by inversion:

$$J = [I - P]^{-1}\tilde{c}.$$

The problem, however, is that $I - P$ is not invertible. To see this, $v \in \mathbb{R}^N$ with constant entries $v(i) \neq 0$ for all $i$), and observe that by construction of $P$,

$$Pv = v.$$

That is, $v$ is an eigenvector of $P$ with eigenvalue 1. It follows that $v$ is in the null space of $I - P$. You might try pseudo inverse. Here is one ingenious idea behind Perron and Frobenius: Choose two vectors $s, v \in \mathbb{R}^N$ with nonnegative entries, and satisfying

$$P(i,j) \geq s(i)\otimes v(j), \quad 1 \leq i,j \leq N. (3.18)$$

This is called a *minorization condition*. Letting $s \otimes v$ denote the "outer product" of these two vectors, this is equivalently expressed

$$P(i,j) \geq (s\otimes v)(i,j), \quad 1 \leq i,j \leq N.$$

We then use fixed point equation:

$$\tilde{c} = [I-P]J = [I-(s\otimes v)]J - [s\otimes v]J,$$

and note that the final term is just a constant times, represented as a column vector:

$$[s\otimes v]J = \delta, \quad \delta = \sum_j v(j)J(j)$$

so that

$$\tilde{c} = [I-(s\otimes v)]J - \delta s. (3.19)$$

Under very mild conditions, we can invert the matrix $J$ in (3.19). The inverse is known as the *fundamental matrix*:

$$G = [I-(s\otimes v)]^{-1} = \sum_{n=0}^{\infty}(P-s\otimes v)^n, \quad (3.20)$$

with $(P-s\otimes v)^k$ the $k$-th power for $k \geq 1$, and with $(P-s\otimes v)^0=I$ (the identity matrix). Here where the minorization condition exists: the Matrix $(P-s\otimes v)^k$ has nonnegative entries for each $k \geq 0$, so that the infinite sum is always meaningful. If it is finite, then from (3.19) we obtain

$$\tilde{J} = G\tilde{c} + \delta G.$$

To find $\delta$, you must apply the boundary condition for $J$,

$$0 = J(N) = \sum_k G(N,k)c(k) + \delta \sum_k G(N,k)s(k),$$

And then obtain $\delta$ by division.

Alternatively, think about your choice of $v$! Here is a simple consequence of the Perron-Frobenius decomposition.

**Proposition 3.5** Consider the state space model with $X=\{1,2,3,\dots,N\}$. Suppose that $c: X \to \mathbb{R}$ vanishes at the state $N$, and suppose that the total cost $J$ is finite value. Define the matrix $G$ using $s=v=e^N$ (the $N$th basis vector in $\mathbb{R}^N$).

### 3.3.1 Discounted Cost

A more popular objective in the operations research literature is the *discounted-cost problem*:

$$J^*(x) = \min_{u}^{\infty} \gamma^k c(x(k),u(k)), \quad x(0) = x \in X,$$

with $\gamma \in (0,1)$ the *discount factor*. This solves the discounted-optimality equation

$$J^*(x) = \min_{u}\{c(x,u) + \gamma J^*(F(x,u))}.$$

The Q-function becomes $Q^*(x,u) \overset{\text{def}}{=} c(x,u) + \gamma J^*(F(x,u))$, so that $J^*(x) = \min_u Q^*(x,u)$.
