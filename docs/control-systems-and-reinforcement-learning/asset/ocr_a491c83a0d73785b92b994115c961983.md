# 10.1 Linear Operators and Adjoints

Let $T: L_2(\varrho) \rightarrow L_2(\varrho)$ be a linear operator. For any $g, h \in L_2(\varrho)$ and scalars $\alpha, \beta \in \mathbb{R}$.

```
$T(\alpha g + eta h) = \alpha T(g) + eta T(h).
```

It is customary to write $Tg$ rather than $T(g)$ when there is no risk of confusion. For TD-learning with discounted-cost deconstruction, the linear operator of interest is defined by

```
$T_g(z) = \sum_{k=0}^{\infty} \gamma^k E[g(\Phi(k)) | \Phi(0) = z], \quad \text{for any } g \in L_2(\varrho) \text{ and } z \in Z, \eqno(10.4)
```

so that $Q = T_c$. Basic theory of linear operators provides tools to efficiently estimate the vector $\psi^Q$ appearing in (10.2) with $G = Q$. The main idea is the adjoint of a linear operator $T$, denoted $T^{\dagger}$. This is defined by the simple identity,

```
$\langle Tg, h \varrho\rangle = \langle g, T^{\dagger}h \varrho\rangle, \quad \text{for all } h \in L_2(\varrho). \eqno(10.5)
```

In this finite there is a simple formula, based on expressing $T$ as a matrix:

```
$T(z) = \sum_{z' \in Z} T(z, z')g(z').
```

**Lemma 10.2** The adjoint of $T$ is equal to its transpose, followed by a similarity transformation:

```
$T^{\dagger}(z, z') = \frac{1}{\varrho(z)}T(z', z)@varrho(z'), \quad z, z' \in Z$.
```

Consequently, for any $h \in L_2(\varrho)$,

```
$T^{\dagger}h(z') = \sum_{z \in Z} T^{\dagger}(z, z')h(z) = \sum_{z \in Z} \sum_{z' \in Z} T(z, z')g(z)h(z)\frac{\varrho(z)}{\varrho(z')}, \quad z' \in Z. \eqno(10.6)
```
