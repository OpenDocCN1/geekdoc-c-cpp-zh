# 2.4 Stability and Performance

If $\overline{\gamma} = 0$, it follows that the sequence $\{V(x(k): k \geq 0\}$ is nonincreasing. Under mild assumptions on $V$, we obtain a weak form of stability:

**Proposition 2.2** Suppose that (2.31) holds with $\overline{\gamma} = 0$. Suppose moreover that $V$ is continuous, inf-compact, and has a unique minimum at $x^e$. The equilibrium is stable in the sense of Lyapunov.

Proof From the definition of the sublevel sets, we obtain

```
${Sv(r) : r > V(x^e)\} = Sv(r)_{r=V(x^e)} = \{x^e\}$$
```

The final equality follows from the assumption that $x^e$ is the unique minimum of $V$. The inf-compact assumption implies the following inner and outer approximations: for each $\varepsilon > 0$, we can take $r > V(x^e)$ and $\delta < \varepsilon$ such that

```
${x \in X : \|x - x^e\| < \delta\} \subset Sv(r) \subset \{x \in X : \|x - x^e\| < \varepsilon\}$
```

If $\|x_0 - x^e\| < \delta$, then $x_0 \in Sv(r)$ and hence $x(k) \in Sv(r)$ for all $k \geq 0$ is nonincreasing. The preceding inclusion implies that $\|x(k) - x^e\| < \varepsilon$ for all $k$. Stability in the sense of Lyapunov.

Bounds on the value function $J$ are obtained by iteration: for example, the two bounds

```
$V(x(2)) \leq V(x(1)) - c(x(1)) + \overline{\gamma}, \leq V(x(0)) - c(x(0)) + \overline{\gamma}$
```

imply that $V(x(2)) \leq V(x(0)) - c(x(0)) - c(x(1)) + 2\overline{\gamma}$. We can course of go further:

**Proposition 2.3** ((Comparison Theorem)) Poisson’s inequality (2.31) implies the following bounds:

+   (i) For each $N \geq 1$ and $x=x(0)$,

```
$V(x(N)) + \sum_{k=0}^{N-1} c(x(k)) \leq V(x) + N\overline{\gamma}. (2.32)$
```

+   (ii) If $\overline{\gamma} = 0$, then $J(x) \leq V(x)$ for all $x$.

+   (iii) Suppose that $\overline{\gamma} = 0$, and that $V, c$ are continuous. Suppose moreover that $c$ is compact, and vanishes at $x^e$. The equilibrium is globally asymptotically stable.

The proof is found in Section 2.4.4.
