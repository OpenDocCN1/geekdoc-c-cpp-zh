The distribution of $X(k)$ for $k \ge 0$ is defined by the initial distribution (the distribution of the potentially random $X(0)$) and the transition kernel. This defines the one-step transition probabilities.

```
$P(x,S) = P\{X(k+1) \in S \mid X(k) = x\}, \quad x \in X, S \subset X. \quad (6.4)
```

It is called the transition matrix if the state space is finite. For the nonlinear state model (6.3),

```
$P(x,S) = P\{X(1) \in S \mid X(0) = x\} = P\{F(x,N(1)) \in S\$
```

For $j > 1$, the j-step transition probability from $x$ to $S$ is defined as follows:

```
$P^j(x,S) = P\{X(k+j) \in S \mid X(k) = x\}. \quad (6.5)
```

In the majority of cases, we no longer think about equilibria $x^c \in X$ when studying Markov chains. We seek an equilibrium measure $\pi$ (more commonly called an invariant measure) that is ergodic the ergodic theorem:

```
$$\lim_{k\to\infty} P^k(x,S) = \pi(S), \quad any \ x \in X \text{ and } S \subset X.\ \quad (6.6)
```

We will see that this implies the existence of a steady state: If $X(0) \sim \pi$, then **X** is a stationary process (so, in particular, $X(k) \sim \pi$ for all $k$). This is interpreted as a stability property for the Markov chain, much like global asymptotic stability for deterministic nonlinear state models.

# 6.1.1 Notation and Conventions

If you have taken a course with an introduction to measure theory, then you know that may be taken in defining the class of sets $S$ for (6.4) and the equations that follow be meaningful. For those of you with this background, keep mind that X will be a Borel subset of Euclidean space (such as a closed subset), and any $S \subset X$ will also be assumed to have this property. We denote $S \in \mathcal{B}(X)$. In $\mathbb{R}$ include any interval $[a,b], [a,b], (a,b)$ or $(a,b)$ with $b > a$, and any finite or countable union of intervals. Similarly, any set $S_h(r) = \{x : h(x) \le r\}$ is a Borel set for each $r$.

**Never heard the word "Borel"?** Don't worry. Measure theory is not important for understanding any of the concepts that follow. The notation is required because transition kernels cannot in general be defined on **every subset** of the state space, except when the state space is finite or countably infinite.
