# Inequality Constraints

We again have a function $g: \mathbb{R}^d ightarrow \mathbb{R}^m$ that defines the constraints, but replace equality with inequality in the primal:

```
$$\Gamma^* = \min \Gamma(\theta) \\ntext{s.t.} \quad g(\theta) \leq 0. \quad (4.36)$
```

If $g_i$ is a convex function for each $i$ (or simply quasiconvex), then the constraint region $S = \{	heta : g(\theta) \leq 0\}$ is a convex set.\nThe Lagrangian and dual function $\varphi^*$ are defined exactly as before, but we restrict $\lambda \in \mathbb{R}^m$ to obtain the prior bound:

```
$$\varphi^*(\lambda) \leq \min \{\mathcal{L}(\lambda; \theta) : g(\theta) \leq 0\} \leq \min \{\Gamma(\theta) : g(\theta) \leq 0\} = \Gamma^*$,
```

where the second inequality is based on the bound $\lambda^T g(\theta) \leq 0$, whenever $g(\theta) \leq 0$ and $\lambda \geq 0$. The saddle point is defined as:

```
$$\max \mathcal{L}(\theta, \lambda) = \max \varphi^*(\lambda) = \Gamma^*. \quad (4.37)$
```

Subject to convexity and minor additional assumptions, there is no duality gap (the inequality is replaced with equality).

A pure steepest ascent algorithm to compute $\lambda_t$ would be of the form $\nabla \varphi^*(\lambda_t)$. In the case of inequality constraints considered, we must include a reflection process to ensure that $\lambda_t(i) \geq 0$ for each $i$ (details to follow shortly).

A representation of the dual is easily found. For that each $\lambda \in \mathbb{R}^m$, there is $\varphi^*(\lambda)$ satisfying

```
$$\varphi^*(\lambda) = \min_{\theta} \{\Gamma(\theta) + \lambda^T g(\theta)\} = \Gamma(\theta^*(\lambda)) + \lambda^T g(\theta^*(\lambda)).$.
```

**Proposition 4.12** For each $\lambda^0 \in \mathbb{R}^m$, a subgradient of the dual function is given by $\nabla \varphi^*(\lambda^0) = [g(\theta^*(\lambda^0))]^T$. That is, for all $\lambda \in \mathbb{R}^m_+$,

```
$$\varphi^*(\lambda) \leq \varphi^*(\lambda^0) + [g(\	heta^*(\lambda^0))]^T(\\lambda - \lambda^0).$
```

*Proof* We have by definitions

```
$$\varphi^*(\lambda) = \min_{\theta} \{\Gamma(\theta) + \lambda^T g(\theta)\} \leq \Gamma(\theta^*(\lambda^0)) + \lambda^T g(\theta^*(\lambda^0)) \\n = [g(\	heta^*(\lambda^0)) + \lambda^0 g(\theta^*(\lambda^0))] + (\lambda - \lambda^0)^T g(\	heta^*(\lambda^0)) \\n = \varphi^*(\lambda^0) + [g(\	heta^*(\lambda^0))]^T(\\lambda - \lambda^0). \quad \square$
```

This inspires the primal-dual flow that is almost the same as the (4.35). The ODE for the parameter estimate is identical:

```
$$\frac{d}{dt}\theta_t =-\Gamma(\theta_t) - [\partial g (\theta_t)]^T \lambda_t$.
```
