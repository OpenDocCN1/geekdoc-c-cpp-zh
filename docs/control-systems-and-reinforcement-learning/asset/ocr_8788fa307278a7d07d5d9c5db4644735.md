# **Lemma4.39** Under the assumptions of Theorem 4.25.

```
$\int_{T_0}^T [\Theta_t - \bar{\Theta}_t] dt = |A^*|^{-1} \{Z_{T_0} - \int_{T_0}^T \bar{\Xi}_t dt + \Psi_t^T + o(1)\}. $
```

Proof Combining the definition $a_t$, $Z_t = a_t(\Theta_t - \bar{\Theta}_t)$ and

```
\frac{d}{dt}Z_t = a_t A^* Z_t + a_t \Delta t + \bar{\Xi}_t$
```

(see (4.125d)) gives, by the Fundamental Theorem of Calculus,

```
$Z_T - Z_{T_0} = A^* \int_{T_0}^T [\Theta_t - \bar{\Theta}_t] dt + \int_{T_0}^T [a_t \Delta t + \bar{\Xi}_t] dt.$
```

Applying Proposition 4.27, the scaled error can be expressed

```
$a_t D_t = a_t \Delta_t^{(p)} + r_t Z_t.$
```

Theorem 4.24 (i) implies that $r_t||Z_t||=O(1/t)$ and $a_t|\Delta_t^{(p)}||=O(|\Theta_t - \bar{\Theta}_t||^2)=O(\alpha^2)$, so that (4.148) follows on reasoning in (4.149) and using the definition (4.147b). $\square$

# **Lemma4.40** Under the assumptions of Theorem 4.25.

```
$$\Theta_T^T - \theta^* = |A^*|^{-1} \{Y_T - Y_{T_0} + \int_{T_0}^T a_t \Upsilon_t dt + \Psi_t^T + o(1)\}.$
```

Proof Calling (4.145) and (4.119), which gives

```
$\int_{T_0}^T \bar{\Xi}_t dt = \bar{\Xi}_T(\\Theta_T) - \bar{\Xi}_T(\barbar{\Theta}_{T_0}) - \int_{T_0}^T a_t \Upsilon_t(\\Theta_t)dt$
```

```
$$\bar{\Xi}_T(\\Theta_T) - \bar{\Xi}_T(\barbar{\Theta}_{T_0}) - \int_{T_0}^T a_t \Upsilon_t dt + \int_{T_0}^T a_t O(|\Theta_t - \bar{\Theta}_t|)dt,$
```

where $\int_{T_0}^T a_t O(|\Theta_t - \bar{\Theta}_t|)dt=o(1)$ for $\rho \in (\frac{1}{2}, 1)$. Recalling the definition $Y_t \overset{\text{def}}{=} Z_t - \XiXi(t)$ in (4.126) gives

```
$Z_T - Z_{T_0} = \int_{T_0}^T \bar{\Xi}_t dt = Y_T - Y_{T_0} + \int_{T_0}^T a_t \Upsilon_t dt + o(1).$
```

Combining (4.148) and (4.151) completes the proof:

```
$$\Theta_T^m - \theta^* = \frac{1}{T-T_0} \int_{T_0}^T [\Theta_t - \bar{\Theta}_t] dt + o(1/T)$
```

```
$$\frac{1}{T-T_0} |A^*|^{-1} \{Y_T - Y_{T_0} + \int_{T_0}^T a_t \Upsilon_t dt + \Psi_t^T + o(1)\}.$
```

The integral on the right-hand side of (4.150) is the crucial term, which can be expressed

```
$\int_{T_0}^T a_t \Upsilon_t dt = \bar{\Upsilon} \int_{T_0}^T a_t dt + \Psi_{T_0}^T,$ $
```

with $\Psi_b^T$ defined in (4.147b).
