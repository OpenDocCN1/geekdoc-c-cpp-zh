The information constraints in this example justify any destruction for the application of the dynamic programming equations of MDP theory, but we may still apply algorithms and if we get lucky. In this simple example we get lucky.

Here is an approach that leads to a successful control solution in this example: The goal is to obtain a sequence of approximating MDP models with state process $X^1$ and input $U^1=(U_1(k), U_4(k))$. We simultaneously obtain an identical sequence of MDP models with state process $X^2$ and input $U^2(k)=(U_3(k), U_4(k))$.

The procedure requires initialization: Choose a randomized policy $\phi^0=(\Phi_m^0, \Phi_b^0)$ so that the resulting Markov chain $X$ is positive. Then follow these steps for $m=0$ to $M$, with $M>1$ fixed, or by some stopping criterion:

- (i) System identification: Simulate the Markov chain using policy $\phi^m$ to obtain the steady-state distribution

$$\omega_m^n(z,v,z') = \sum_{k=0}^{n-1}\mathbb{1}\{X^1(k)=z, U^1(k)=v, X^1(k+1)=z'\} + \sum_{k=0}^{n-1}\mathbb{1}\{X^2(k)=z, U^2(k)=v, X^2(k+1)=z'\}$$

for $z=(z_1,z_2), z'=(z_1',z_2') \in \mathbb{Z}_2^2$, and $v \in \{v^0,v^1,v^2\} \overset{\text{def}}{=} \{(0,0), (0,1), (0,0,1)\}$. Based on this, define a controlled transition matrix:

$$P_v^m(z,z') = \frac{1}{\gamma_m(z,v)}\omega_m^n(z,v,z'), \overset{\text{def}}{=} \sum_{z'} \omega_m^n(z,v,z'). \quad (7.52)$$

- (ii) Cost identification: Include in your simulation the following estimate:

$$C^m(z,v) = \sum_{k=0}^{n-1}c(X(k))\mathbb{1}\{X^1(k)=z, U^1(k)=v\} + \sum_{k=0}^{n-1}c(X(k))\mathbb{1}\{X^2(k)=z, U^2(k)=v\}$$

for each $z \in \mathbb{Z}_2^2$, and $v \in \{0,1\}^2$. Based on this, define a cost function:

$$c^{(m)}(z,v) = \frac{1}{\gamma_m(z,v)}C^m(z,v).$$

- (iii) Policy update: Solve the AOE with controlled transition matrix $P^{(m)}$ and cost function $c^{(m)}$ to obtain a policy $\phi^{m+1}$. Define $\Phi^{m+1}$ to be a randomized policy approximating $\phi^{m+1}$, and go to step (i), with $m$ incremented to $m+1$.

The system identification is motivated by Bayes's rule. Suppose that $Z(k) = X^1(k)$ were indeed an MDP model with $V(k) = (U_1(k), U_4(k))$. Its controlled transition matrix is defined by the ratio of probabilities:

$$P_v(z, z') = P\{Z(k+1) = z' | Z(k) = z, V(k) = v\} = \frac{P\{Z(k+1) = z', V(k) = v\}}{P\{Z(k) = z, V(k) = v\}}$$

The cost identification step has similar motivation. For large $n_c$, we have the approximation

$$c^{(m)}(z, v) \approx E[c(X(k)) | Z(k) = z, V(k) = v], \quad (7.53)$$

so that the steady-state of $c^{(m)}(Z(k), V(k))$ approximates the steady-state average cost.
Shown on the right in Figure 7.4 is an illustration of a policy obtained using this approach.
The initial policy was chosen to be a perturbation of the “serve the longest queue” policy:

$$\phi^0 (v^1 | z) = \begin{cases} 0.85 & \text{if } z_1 \geq z_2 \\ 0.15 & \text{else} \end{cases}$$

with $\phi^0 (v^2 | z) = 1 - \phi^0 (v^1 | z)$ (provided $z_2 \geq 1$).

The final policy shown on the right in the figure is more similar to a threshold policy of the form “Serve buffer 4 when $X_1 \leq \varpi_1$ and $X_4 \geq 1$”, where $\varpi_1 \approx 10$. The resulting performance is close to that of the centralized optimal solution [255].

## 7.7 Controlling Rover with Partial Information

We now turn to a setting where information is limited, but the theory in this book is directly applicable. This is illustrated with a simple example.

Setting: A rover on Mars depends on solar panels to get energy, but the goal is to collect as much energy as possible. The question is: *How can we control the rover?*

The state space is summarized by the following three cases:

- 1. Top: If driving, then it is at top with probability 0.9.
- 2. Rolling: If driving, then it is at rolling with probability 0.2.
- 3. Bottom: If driving, then it is at bottom with probability 0.1.

Cost: The reward depends on the action:

| Action | Top | Bottom |
|---|---|---|
| Driving | 1 | 0 |
| Not driving | 0 | 0 |

The state $\mathcal{X}(k)$ is a two-dimensional simplex. In the context of MDP theory, we may still apply algorithms and if we get lucky.

A brief survey of POMDP theory is found in Appendix C, where you can find a recursive update for belief state:

$$\mathcal{X}(k+1) = \mathcal{M}(\mathcal{X}(k), Y(k+1)), \quad k \geq 0$$

with the details of update map $\mathcal{M}$ provided.

Computation of $\phi^*$ is a major challenge in POMDP because the state space $S$ is never finite. We are left to use approximation techniques, and reinforcement learning provides many tools for this purpose.

Suppose that the solution to the fully observed problem is defined by $U(k) = \mathcal{B}$ if and only if $\mathcal{X}(k) = \mathcal{T}$. The policy shown in Figure 7.5 is well motivated in partially observed setting. This was obtained based on the following formula, given nonnegative $a_T, a_R, a_B$:

$$\phi(b) = \begin{cases} \mathcal{B} & \text{if } a_T(b_T-1)^2 + a_R b_R^2 + a_B b_B^2 \leq r \\ \mathcal{D} & \text{else} \end{cases}, \quad b \in S$$

The degenerate case using $r=0$ is not excluded, giving $\phi(b) = \mathcal{B}$ only if $b_T=1$. This example and the example in Section 7.6 expose several challenges and opportunities:

- (i) Information constraints on the input can reward MDP theory inappable, MDP algorithms may still lead to a useful policy.

- (ii) If the POMDP assumptions are valid, then the theory is very rich, but direct application of computational tools like VIA is a significant challenge. Reinforcement learning is a great alternative.

- (iii) RL + POMDP is not model-free, in practice, we either use a model, or replace the belief state depends crucially on a model. that with some other "features" to create a "pseudo state" that is believed to include enough information for reliable control.
