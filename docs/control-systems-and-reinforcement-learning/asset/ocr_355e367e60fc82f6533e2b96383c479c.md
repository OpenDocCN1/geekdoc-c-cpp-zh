7.8 Consider the average-optimal control problem with cost function $c$ and relative value $h^*$, solving the ACOE:

```
$\min_{u \in U} \{c(x,u) + P_u h^*(x)\} = \min_{u \in U} \{c(x,u) + \sum_{y \in X} P_u(x,y)h^*(y)\} = h^*(x) + \eta^*$.
```

Assume that the state and action are finite. Consider the value iteration algorithm designed to approximate the Q-function, (7,7):

```
$Q_n+1(x,u) = c(x,u) + P_u Q_n(x), \quad \text{where } Q_n(y) = \min_{u \in U} Q_n(y,u).
```

For each $n$, $Q_n$ is the value function for a finite horizon optimal control problem, similar to what we see for ordinary value iteration (7.44). Conjecture on the form of this optimization, and justify it.

7.9 Consider the one-dimensional inventory model defined by the recursion

```
$X(k+1) = X(k) + S(k+1)U(k) - A(k+1), \quad k \geq 0, X(0) \in \mathbb{R}$.
```

(where $oldsymbol{S, A}$ is i.i.d. in the CRW queue. In this model, $A(k)$ represents new demand for product at time $k$, and $S(k)$ represents a potential control at time $k$. A positive value of $X(k)$ corresponds to inventory excess and a negative value deficit. This is a simplified version of the model shown in Figure 7.7 since we are modeling the inventory buffer and not the representing storage of raw materials.

A piecewise cost function $c : \mathbb{R} \to \mathbb{R}$ is given, of the form $c(x) = c_-x + c_+$ with $0 < c_- < c_+$, $x_- = \min(x,0)$, and $x_+ = \max(-x,0)$.

In this exercise, you will restrict the policy to a finite form: Given $\overline{T} > 0$, define $U$ such that $X'(k) = \overline{T} - X(k)$ is the CRW queue under the nonidling policy. Here $X(k)$ is restricted to the state space $X_{\overline{T}} = {{\overline{T}, \overline{T}-1, \dots, 0\}$, and $U(k) = 1$ if and only if $X(k) \leq \overline{T} -1$.

For this threshold, the fluid model is defined by

```
$\frac{dx}{dt} = \begin{cases} \mu - \alpha & \text{if } x < \overline{T} \ 0 & x = \overline{T} \end{cases}$
```

for any initial condition $x_0 = x = \overline{T}$, where $\mu$ and $\alpha$ are the mean values of $S(k)$ and $A(k)$ respectively. That is, for $x_0 < \overline{T}$, $x_t$ increases linearly until it reaches the level $\overline{T}$, and thereafter stays at this level.
