# 10.7 Advantage and Control Variates

First, and most important: Don't be fooled by the reality of unbiased gradient observations. The ideal algorithm using TD(1) may come with variance. In practice, you are likely to resort to the introduction of $\lambda < 1$ TD($\lambda$) along with the application of state weighting, so that the eligibility vector in (10.4cc) is replaced

```
$\zeta_{n+1} = \lambda{\{\Phi(n) \neq z^*\}\zeta_n + w_{n+1}\psi_{	heta_{n+1}}(\Phi(n+1))$
```

where $w_{n+1} = w(X(n+1))$ for the weighting function $w: X \to \mathbb{R}_+$.
You may go further and experiment with the discounted-cost value function as an approximation for $Q_{	heta}$. This is unfortunate, but bias/variance tradeoffs are a theme in machine learning that appears to be inescapable.
The following pages describe techniques to reduce variance without bias.

# 10.7.1 Variance Reduction through Advantage

Lemma 10.20 tells us that we construct a second family of functions $\mathcal{G}$, where $G: X \to \mathbb{R}$ for each $G \in \mathcal{G}$, and replace (10.44a) with the following:

```
$\theta_{n+1} = \theta_n - \alpha_n \Lambda^{\theta_n}(\Phi(n))[H_{	heta_n}^w(\Phi(n)) - G_n(X(n))]]. \quad (10.44a')$
```

Provided that the CFP holds, we will maintain the ODE approximation as gradient descent, regardless of how $\{G_n\}$ are defined (subject to continuous dependency on parameter estimates). The favored value of $G$ is as shown in Section 9.1.3.

```
$G_{	heta}^w(x) = E[H_{	heta}^w(\Phi(n)) | X(n)=x] = \sum_{u} H_{	heta}^w(x,u)\phi^{	heta}(u | x).
```

The difference $Q_{	heta} - h_{	heta}$ was designated the advantage function associated with $\phi^{	heta}$. A modified function $\mathcal{H}_{	heta}^v$ is defined such that for $V_0 \in \mathcal{H}_{	heta}^v$, $H_0}(x) = H_0(x) - L_0(x)$, for some $H_0 \in \mathcal{H}^{	heta}$, with $L_0(x) \overset{\text{def}}{=} \sum_{u} H_0(x,u)\phi^{	heta}(u | x).

```
$\tilde{\psi}_{	heta}(x,u) = \psi_{	heta}(x) - \psi_{	heta}(x),$

We arrive at an update that is preferred in recent:

```
