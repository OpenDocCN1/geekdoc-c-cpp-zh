
# Optimal Control

Let's turn to a common approach to RL in which we choose a parameterized family of functions $\{Q^\theta:\theta\in\mathbb{R}^d\}$, and seek among them an approximation to the Q-function $Q^\star$ defined in (3.7a). We frequently use a linear parameterization

```
$Q^\theta(x,u) = \theta^T\psi(x,u), \quad \theta\in\mathbb{R}^d \quad (3.43)$
```

in which $\psi_i:X\times U\to\mathbb{R}$ is the $i$-th basis function, $1\le i\le d$. For any $\theta$, we obtain a policy by mimicking (3.7c):

```
$$\Phi^\theta(x) = \arg\min_u Q^\theta(x,u), \quad x\in X \quad (3.44)$$
```

Consider how we might approximate PIA in Section 3.2.2: Given an initial policy $\Phi^0$, generate a sequence of policies $\{\Phi^n\}$ and parameter estimates $\{\theta_n\}$ as follows:

- (i) Obtain a parameter $\theta_n$ to achieve the approximation $Q^{\theta_n}\approx Q_n$, where the latter is the fixed-policy Q-function that satisfies

```
$Q_n(x,u) = c(x,u) + Q_n(x^+,u^+), \quad x^+=F(x,u), u^+=\Phi^n(x^+)$
```

- (ii) Define a new policy $\Phi^{\theta+1}=\Phi^\theta$.

Variations of this approximation of PIA are explored in greater depth in Section 5.3 and Part II. An alternative is to build an approximation algorithm based on the dynamic programming equation for the Q-function in (3.7d):

```
$Q^\star(x,u) = c(x,u) + Q^\star(F(x,u)), \quad Q^\star(x) = \min_u Q^\star(x,u)$
```

which admits the model-free representation, for any state-input trajectory:

```
$Q^\star(x(k),u(k)) = c(x(k),u(k)) + Q^\star(x(k+1)) \quad (3.46)$
```

Just as in (2.52), for any approximation $Q$ we can learn the Bellman error:

```
$$\Delta_{k+1}(\tilde{Q})\overset{\text{=}}{}=-Q(x(k),u(k)) + c(x(k),u(k)) + \tilde{Q}(x(k+1)) \quad (3.47)$$
```

This is zero if $Q=Q^\star$. Learning is defined as algorithms to choose $\theta^\star$ so that it is minimized over all $\theta$, based on observations of the system for $k=0$ to $N$. The first approach that might come to mind is to mimic the mean-square criterion (2.53):

```
$$\Gamma^c(\theta) = \frac{1}{N-k}\sum_{k=0}^N [D_{k+1}(\tilde{Q}^\theta)]^2 \quad (3.48)$$
```

The LP approach of Section 3.5 suggests alternatives, and other approaches are investigated in Chapter 5.

## 3.8 Optimal Control in Continuous Time*

Hopefully it was made clear in Section 2.34 that calculus can bring clarity to theory of state space models. For example, the discrete-time counterpart of Figure 2.2 is far less enlightening. Further motivation was given in prior examples and in Section 2.6: In many cases, the system model is based on laws of physics. The value of control is even greater when we come to optimal control, it is frequently simpler to pose and approximate optimal control problems in continuous time.

The nonlinear state space was previously introduced in (2.19). The total cost $J$ associated with a particular control input $u = u_{(0,\infty)}$ is defined by the integral

```
$J(u) = \int_{0}^{\infty} c(x_t, u_t)dt$,
```

where $c$ is a scalar-valued function of $(x,u)$ as before, and our goal is to minimize $J$ over all inputs. This will require assumptions. If we assume that there is a target state $x^e$ which is an equilibrium for some input $u^e$, and the costs vanish at this equilibrium:

```
$f(x^e, u^e) = 0, \quad c(x^e, u^e) = 0$.
```

The value function is defined as in (3.2):

```
$J^*(x) = \min_{u_{(0,\infty)}} \int_{0}^{\infty} c(x_t, u_t)dt, \quad x_0 \in \mathbb{X}$.
```

Under general conditions, it satisfies a differential equation known as the Hamilton–Jacobi–Bellman (HJB) equation. Its derivation proceeds in the construction of the Bellman equation in Section 3.2.

Let $x$ be an initial state, and let $t_m$ be an intermediate time, $0 < t_m < \infty$. As in the discrete-time development, we regard $J^*(x_{t_m})$ as the cost to go. Based on this interpretation, we obtain the following:

```
$J^*(x) = \min_{u_{(0,t_m)}} \int_{0}^{t_m} c(x_t, u_t)dt + \int_{t_m}^{\infty} c(x_t, u_t)dt \quad = \min_{u_{[t_m,\infty)}} \left( \int_{t_m}^{t_m} c(x_t, u_t)dt + \int_{t_m}^{\infty} c(x_t, u_t)dt \right) \quad J^*(x_{t_m})$
```

That is,

```
$J^*(x) = \min_{u_{(0,t_m)}} \int_{0}^{t_m} c(x_t, u_t)dt + J^*(x_{t_m}), \quad x_0 = \mathbf{0}. \quad (3.49)$
```

```
$\Delta x = x_{t_m} - x_0 = x_m - x$.
```

Assuming the value function is continuously differentiable, we may perform a Taylor series expansion using optimality equation (3.49) to obtain

```
$J^*(x) = \min_{u_{(0,t_m)}} \{c(x, u_0)t_m + J^*(x) + \nabla J^*(x) \cdot \Delta x_m\} + o(t_m)$.
```

The "little oh" notation $o(t_m)$ is recalled in Appendix A. Subtracting $J^*(x)$ from each side and dividing by $t_m$ then

```
$0 = \min_{u_{(0,t_m)}} \{c(x, u_0) + \nabla J^*(x) \cdot \frac{\Delta x_m}{t_m}\} + o(1)$.
```

Letting $t_m \to 0$, we obtain $u(0) \to 0$ by definition, and the ratio $\Delta x_m/t_m$ can be replaced by derivative:

```
$\lim_{t_m\to0} \frac{\Delta x_m}{t_m}|_{t=0}=f(x,u)$.
```

This gives the following celebrated equation:

```
$0 = \min [c(x,u) + \nabla J^*(x) \cdot f(x,u)]. \quad (3.50)$
```

**Theorem 12** If the value $J^*$ has continuous derivatives, then it satisfies the HJB equation (3.50). Suppose that the minimum in (3.50) exists and is unique for each $x$, to form a continuous function $\phi^*$. Then the optimal control is expressed as state feedback:

```
$u^* = \phi^*(x) = \arg_u [c(x,u) + \nabla J^*(x) \cdot f(x,u)].$
```

The terms in (3.50) have important interpretation in terms of the Hamiltonian,

```
$H(x,p,u) = c(x,u) + p^T f(x). \quad (3.51)$
```

The following result is a version of the **minimum principle**:

**Theorem 13** Suppose that an optimal input-state pair exists, and that the value function $J^*$ has continuous derivatives. The optimal control $u^*$ must minimize the Hamiltonian for each $t$,

```
$\min_u H(x^*,p_t^*,u) = H(x^*,p_t^*) \quad (3.52)$
```

with $p_t^* = \nabla_x J^*(x)$. The standard minimum principle does not hold. Rather, the vector-valued co-state process $\{p_t^*\}$ is defined by another differential equation. This can provide enormous reduction in complexity since we do not need to compute the value function for an optimal control problem with infinite state space.

### 3.9 Mountain Car

#### Quantized Space

A continuous state model is commonly approximated through a partition of the state space into a finite collection of bins $X = \cup_i B_i$. This step is called quantization or binning. The next step is to choose a representative state $x^i \in B_i$ for each $i$, and define approximate dynamics on the state composition. In this two-dimensional case, it is convenient to choose bins based on a rectangular grid: For an integer $N > 1$, choose $n=N^2$, and select $X_o=\{x^{i,j}=(z^i,v^j)^top : 1 \leq i,j \leq N\}$, where the position and velocity values are equally spaced

```
$-1 = z^1 < z^2 < \dots < z^N = 0.5, \quad -v = v^1 < v^2 < \dots < v^N = v$.
```

Each $x^{i,j}$ belongs to a bin $B_{i,j}$; the bins are disjoint, with union equal to X. The value $N=20$ was used to obtain the approximation shown in Figure 3.2. The state model with velocity $x$, is denoted

```
$x_o(k+1) = F(x_o(k),u(k)), \quad (3.53)$
```

where $x_o(k) \in X_o$ and $u(k) \in U=\{-1,1\}$ for each $k$. The next step is to define the dynamics $F(\cdot)$ which require some care. We define $F(x^{N,j},u) = (z^N,0)$ for any $u$ and $j$, since in this case $x^{N,j}=(0.5,v)$ (so the card is packed).

Consider $x^{i,j} \in X_o$ with $i < N$ and $u \in U$. Denote $x^{i,j}(u)=F(x^{i,j},u)$, the two-dimensional component with

```
$z^{i,j}(u)=F_1(x^{i,j},u), \quad v^{i,j}(u)=F_2(x^{i,j},u)$.
```

Define $i_+$ and $j_+$, uniquely by the constraint $x_{i_+,j_+}(u) \in B_{i_+,j_+}$. The specification of velocity dynamics is straightforward: The position dynamics are modified as follows:

```
$F_{\times1}(x^{i,j},u) = \begin{cases} z^+ , & z^{i,j}(u) \geq z^+ \\ z^+-1, & z^{i,j}(u) < z^+ \text{ and } u=-1 \\ z^--, & \text{else} \end{cases} \quad (3.54)$
```

These dynamics are defined so that $F_{\times1}(x^{i,j},u) \neq z^i$ for any $i < N$. *Rationale*: to avoid the existence of state $x_o=x^{i,j}$ satisfying $i < N$ and $v=F(x_o,u)$ for any $u \in U$.

### VIA and PIA Implementation

VIA will be successful for any initialization $V^0$ in this finite state space model. The choice $V^0=0$ was used in the numerical experiments described in the following. Successful implementation of PIA requires an initial policy that is stabilizing, in the sense that the goal is reached from each initial condition. A variant of (2.59) was chosen: For each $x=(z,v)^top \in X_o$,

```
$\Phi^0(x) = \begin{cases} \sign(v) & z+v \geq Tol \\ 1 & \text{else} \end{cases}$
```
