# 10.5.2 A Few Warnings and Remedies

It is time to say a few words about the randomization here, which wasn't required in Sections 4.6 and 4.7. Randomization is required if we want to apply sensitivity theory for Markov chains, which brings in the source functions $S^	heta$ and $\Lambda^	heta$. In particular, there is no meaningful definition of $\Lambda^	heta$ for deterministic policies, such as the policy for the mountain car in Section 47.1.$^1$ In most applications, it is reasonable to abandon randomization in the final step of policy design: Once we have our parameter estimate $\theta \approx \theta^*$, construct a deterministic policy:

```
$$\Phi^{\tilde{\theta}}(x) = \arg\max_u \	ilde{\theta}}(u|x), x \in X.$
```

We expect that $\tilde{\theta}$ will be nearly deterministic if it is optimal, in which case $\Phi^{final}$ is some slight perturbation of $\Phi$. The example that follows this point.

**Example 10.5.1 (The Best Parameter Is Probably $\infty$)** Consider an entirely ideal setting in $d=1$ and $\theta$ plays the role of "inverse temperature" in the Gibbs policy (9.66a):

```
$$\Phi(u|x) = \frac{\exp(-\theta H(x,u))}{\kappa(x,\theta)}$
```

where $H: X \times X \to \mathbb{R}$, and $\kappa(x,\theta)$ is a normalizing constant. Suppose that we are fortunate that the optimal policy is possible from H:

```
$$\Phi^*(x) = \arg\max_u H(x,u), x \in X.$
```

and that $\Phi^*$ is unique (only one policy optimal). Optimal conclusions follows:

+   (i) $\Phi$ is not an optimal policy for any $\theta$, and (ii) $\lim_{\theta \to \infty} \Phi = \Phi^*$.

This example might seem contrived, but Gibbs policies will be featured in the coming sections, and we will see in Section 10.6 that there is good reason to include an approximation to the Q-function in a Gibbs policy.

The example suggests that a good algorithm must allow for $\theta_n$ to converge to $\infty$. It may not be practical, so instead introduce regularization: choose a convex regularizer
