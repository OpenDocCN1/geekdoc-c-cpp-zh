# ODE Approximations

Just as in the previous chapter, ergodic allows for approximation of algorithms by simpler ODE approximations. In particular, consider a recursion of the form

$$\theta_{n+1} = \theta_n + \alpha_n f_{n+1}(\theta_n), \quad n \ge 0. $$

in which $\{f_n\}$ is a sequence of functions that approach an ergodic limit:

$$f(\theta) = \lim_{N \to \infty} \frac{1}{N} \sum f_k(\theta), \quad \theta \in \mathbb{R}^d. $$

The associated ODE is defined using this vector field:

$$\frac{d}{dt}\theta_t = f(\theta_t). $$

An ODE approximation is defined by the naive Euler construction: the time scale is defined by the nondecreasing time points $\tau_0=0$ and $\tau_n = \sum_0^n \alpha_k$ for $n \ge 1$. Define a continuous process by $\Theta_{\tau_n} = \theta_n$ for each $n$, and extend to all $t$ through piecewise linear interpolation. Let $[\theta_t^* : t \ge \tau_n]$ denote the solution to the ODE (5.25) with initial condition $\theta_{\tau_0}^* = \theta_0$. We will then show that the algorithm (5.25) an **ODE approximation** for each initial condition $\theta_0$ and $N > 0$,

$$\lim_{n \to \infty} \sup_{\tau_n \le \tau \le \tau_{n+N}} ||\Theta_\tau - \theta_\tau^*|| = 0. $$

# Value Function Approximations

For any policy $\phi$ with associated value function $J^\phi$, the fixed-policy Q-function is denoted:

$$Q^\phi(x,u) = c(x,u) + J^\phi(F(x))$$

In this notation, the fixed-point equation (3.45) is

$$Q^\phi(x,u) = c(x,u) + Q^\phi(x^+), \quad x^+ = F(x), \quad u^+ = \phi(x^+). \quad (27)$$

For any input $Q$, we observe the error in this fixed-point equation as another temporal difference: For any input sequence $(x,u)$

$$\mathcal{D}_{k+1}(Q) = -Q(x,k) + c(x,k) + Q(k+1), \quad (28a)$$
$$Q^\phi(x) = Q(x,\phi), \quad x \in X. \quad (28b)$$

The temporal difference (28a) is zero for all $k$ if we substitute $Q^\phi$ for $Q$. Algorithms to approximate $Q^\phi$ based on the temporal difference (28a) are called SARSA. These algorithms are only a minor variation of the TD-learning algorithms designed to estimate $J^\phi$, throughout the book.

There are two distinct flavors of TD-learning: on policy and off policy. The on-policy versions $u(k) = \phi(x)$ in the definition (28a). The difficulties with off-policy algorithms should be cleared by the following discussion in Section 5.3: If $\phi$ is a good policy, in the case that $x(k) \to x^*, u(k) \to x^*$ as $k \to \infty$, for any function $Q$

$$\lim_{k \to \infty} \mathcal{D}_{k+1}(Q) = \lim_{k \to \infty} \{-Q(x,k) + c(x,k) + Q(k+1)\}, \quad u = \phi(x) \text{ for each } k. \quad (29)$$

Consequently, under the convention $c(x^*,u^*) = 0$, the temporal difference approaches zero for any choice of $Q$.

In this part of the book, we focus mainly on off-policy algorithms to allow for exploration. The elegant theory for on-policy algorithms in stochastic control is explored in Part II.

This can be expressed in a form that will inspire a statistician. On denoting

$$\Gamma_k = c(x(k), u(k)),$$
$$\Gamma_{k+1} = \psi(x(k), u(k)) - \psi(k+1), \phi(k+1))$$

we obtain this representation

$$\Gamma_k = \Gamma_{k+1}^T\theta + \mathcal{D}_k(Q)$$

This is the form of a standard regression problem:

$$\Gamma_k = \Gamma_{k+1}^T\theta^* + \varepsilon_k,$$

where $[\varepsilon_k = \mathcal{D}_k(Q); k \geq 0]$ is regarded as "noise," and $\theta^*$ is typically defined as the minimum variance parameter: $\theta^* = \arg\min_{\theta} \Gamma(\theta)$

$$\Gamma(\theta) = E_{\theta}[Y_0 - \Upsilon_0\theta]^2 = \lim_{N\to\infty} \frac{1}{N} \sum_{k=0}^{N} |Y_k - \Upsilon_k^T\theta|^2.$$

This is the mean-square error for the temporal difference sequence: Applying (5.32c)

$$\Gamma(\theta) = \lim_{N\to\infty} \frac{1}{N} \sum_{k=1}^{N} [\mathcal{D}_k(Q^{\theta})]^2.$$

Convergence of this limit requires conditions on the input, and further conditions are required so that this function is meaningful. In particular, on the on-policy approach which (5.29) holds, $\Gamma(\theta) = 0$ for every $\theta$. This is why explanation is needed. # Least Squares Temporal Difference Learning (LSTD)

For a given $d\times d$ matrix $W>0$, integer $N$, and observed samples $\{u(k), x(k) : 0 \leq k \leq N\}$, the minimizer is optimized:

$$\Gamma_{\theta}^{LSTD}(\theta) = \arg\min_{\theta} \Gamma(\theta), \quad \Gamma(\theta) = \theta^T W + \sum_{k=1}^{N} |Y_k - \Upsilon_k^T\theta|^2.$$

This defines the approximation of the Q-function: $Q_N^{LSTD} = \sum_{i} \psi_N^i.$

The objective is a positive-definite quadratic, so that the solution is obtained on setting the gradient of the objective to zero: $\nabla_{\theta}\Gamma_N(\theta) = 0$ for $\theta = \theta_N^{LSTD}$.

Proposition 5.3 $\theta_N^{LSTD} = [N^{-1}W + R_N]^{-1}\psi_N$, with

$R_N = \frac{1}{N} \sum_{k=1}^{N} \Upsilon_k^T\Upsilon_k, \quad \psi_N = \frac{1}{N} \sum_{k=1}^{N} \Upsilon_k^T Y_k.$

The regularizer $\theta^T W\theta$ is introduced to ensure a unique solution. It is worth investigating the implications if $R_N$ is not invertible.
