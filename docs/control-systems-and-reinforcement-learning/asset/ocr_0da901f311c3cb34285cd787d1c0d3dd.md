# 4.1 Ordinary Differential Equations

In this chapter, the "state variable" often represents the output of an algorithm rather than anything directly related to a control system. For this reason, throughout this chapter we use $\vartheta = {\vartheta_t : t \geq 0}$ to denote the state process for the ODE, and restrict to the Euclidean space: $\vartheta_t \in \mathbb{R}^d$ for an integer $d$. The state space (2.36) in this notation is

```
$$\frac{d}{dt}\vartheta = f(\vartheta), \quad \vartheta_0 = 0$ given, (4.2)
```

where $f: \mathbb{R}^d \to \mathbb{R}^d$ is the vector field as in (2.3). Examples with $d = 1$:

```
$f(\vartheta) = a\vartheta$ and $\vartheta_t = \vartheta_0e^{at}$.\n$\vartheta_t = \vartheta_0(1 - e^{-at})..$
```

The ODE (4.2) is called time homogeneous since $f$ does not depend on $t$. See Section 3.3 for hints on how to use state augmentation to create homogeneity for a model in which the vector field depends on $t$.

In every application of the ODE approach to design, the first step is to construct the vector field so that $\vartheta^* \in \mathbb{R}^d$. In particular, if $\vartheta_0 = \vartheta^*$, then the solution to the ODE should be: $\vartheta_t = \vartheta^*$ for all $t \geq 0$. This requires that $\dot{\vartheta_t} = 0$ which by (4.2) implies that $\vartheta^*$ is an equilibrium: $f(\vartheta^*) = 0$. Advanced material for stability theory for ODEs is contained in Section 4.8. This can be anticipated from the Lyapunov theory contained in Section 2.4.5.

Understanding theory existence of solutions of (4.2) is the first step toward understanding ODE principles in design and in Part II of the book. Much like the Bellman equation (3.5) is regarded as a fixed point iteration, the ODE (4.2) is a fixed point in the variable $\vartheta = {\vartheta_t : t \geq 0\}$. Perhaps we can mirror the success of the value iteration algorithm (3.8) (an instance of successive approximation?) Writing (4.2) as $\dot{\vartheta} = \frac{d}{dt}\vartheta = f(\vartheta)$, an analog to

```
$$\vartheta_t^{n+1} = \vartheta_0 - \int_0^t f(\vartheta_tau^n)d\tau, \quad t \geq 0, n \geq 0$,
```

with $\vartheta^0 = {\vartheta_t : t \geq 0}$ given initial condition. Sorry to say, this approach is doomed to fail! One of downside is the repeated definition in this recursion, which means we have to be very careful with our selection of $\vartheta^n$. Also, this recursion does not respect the requirement that the initial condition $\vartheta_0$ is specified.

The Fundamental Theorem of Calculus provides a more sensible approach. That is,

```
$$\vartheta_t = \vartheta_0 + \int_0^t f(\vartheta_tau)d\tau, \quad 0 \leq t \leq T$, (4.3)
```

where the finite horizon $T$ is chosen for the sake of analysis. Successive approximation is defined as before: Take an initial guess $\vartheta^0 = {\vartheta_t : 0 \leq t \leq T\}$, and define for $n \geq 0$,

```
$$\vartheta_t^{n+1} = \vartheta_0 + \int_0^t f(\vartheta_tau^n)d\tau, \quad 0 \leq t \leq T$. (4.4)
```

This recursion is known as Picard iteration. It is successful under mild assumptions:

**Proposition 4.1** Suppose that $f$ is Lipschitz continuous; then there is $L > 0$ such that for $x,y \in \mathbb{R}^d$,

```
$||f(x) - f(y)|| \leq L||x - y||$. (4.5)
```
