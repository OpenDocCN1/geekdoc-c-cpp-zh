# 9.5 Return to the Q-Function

An alternative approach is available in the context of policy iteration, surveyed in Section 9.1. Suppose $\phi$ is itself defined as a minimizer: For a function $G: X \times U \to \mathbb{R}$,

```
$$\phi(x) = \arg\min_u G(x,u) = \max_u \{-G(x,u)\}$
```

Given $\varepsilon > 0$, the $soft-max$ is defined as

```
$$\varepsilon \log{\sum_u exp(-G(x,u)/\varepsilon)\}$
```

As $\varepsilon \downarrow 0$, this converges to $\max_u \{-G(x,u)\}$. This motivates a class of randomized policies:

Gibbs Policy Given $G: X \times U \to \mathbb{R}$ and $\varepsilon > 0$,

```
$$\Phi^\varepsilon(u|x) = \frac{1}{\kappa^\varepsilon(x)} exp(-G(x,u)/\varepsilon), \quad (9.46a)
```

with $\kappa^\varepsilon$ the normalizing constant, defined so that $\Phi^\varepsilon(\cdot|x)$ is a pmf on $U$ for each $x$:

```
$$\kappa^\varepsilon(x) = \sum_u exp(-G(x,u)/\varepsilon). \quad (9.46b)
```

The parameter $\varepsilon$ is called the *temperature*

```
$$\lim_{\varepsilon \downarrow 0} \Phi^\varepsilon(u|x) = \mathbb{1}\{\phi(x) = u\\}$.
```

# 9.5.2 On and Off Algorithms

Our main motivation for value function approximation is in application to approximate policy iteration, so we consider the fixed-policy Q-function (9.6b):

```
$Q(x,u) = \sum_{k=0}^{\infty} \gamma^k c(\phi(k)) \|\ X(0) = x, U(0) = u\$.
```

When the policy $\phi$ is randomized, we require the definition (9.5b): $Q(x) = \sum_u Q(x,u)\phi(u|x)$. The fixed-policy equations (9.7) continue to hold, also with following expected relations:

**Proposition 9.10** The value functions $h$ and $Q$ obtained from a randomized policy $\phi$ satisfy

```
$h(x) = c_{\phi}(x) + \sum_{x'} \gamma P_{\phi}(x,x')h(x'), \quad Q(x,u) = c(x,u) + \sum_{x'} \gamma P_{\phi}(x,x')Q(x')$,
```

with $c_{\phi}(x) = \sum_u c(x,u)\phi(u|x)$, and $P_{\phi}$ defined in (7.12). The two are related via

```
$h(x) = Q(x) \text{and } Q(x,u) = c(x,u) + \gamma \sum_{x'} P_u(x,x')h(x'), \quad \text{for each } x,u. \quad (9.48)
```
