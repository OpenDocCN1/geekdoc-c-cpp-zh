# Tabular and Binning

A common choice in theory of RL is the tabular method in which $z$ denotes a typical pair $(x,u)$. It is assumed that $X$ and $U$ are finite, and an ordering is chosen: $X \times U = \{z^i = (x^i,u^i) : 1 \leq i \leq d\}$, where $d$ is the total number of state-disjoint pairs. The tabular basis is based on the family of indicators

```
$\psi_i(x,u) = \mathbb{1}\{(x,u)=(x^i,u^i)\}, \quad (x,u) \in X \times U, 1 \leq i \leq d. \quad (5.10)$
```

If $Z=X \times U$ is not finite, then we can apply binning. Recall from Section 3.9.1 how binning was applied to approximate the model for the car example through "quantizing" the state, and computing the optimal policy for the model using VIA. In RL, we do not approximate the model, but we can perform through an extension of the tabular basis. A basic decomposition $Z = \sum_{i=1}^d B_i$, the $i$-th basis is the indicator

```
$\psi_i(x,u) = \mathbb{1}\{(x,u) \in B_i\}, \quad (x,u) \in X \times U, 1 \leq i \leq d. \quad (5.11)$
```

This is also written $\psi_i = \mathbb{1}_{B_i}$. Exercise 9.3 is designed to show how this is a good choice in RL, in the sense that it leads to a consistent algorithm for value function approximation.

# Galerkin Relaxation

The term Galerkin relaxation appears throughout the book as a method to approximate equality constraints, and sometimes inequality constraints. As an example of this technique, consider again the loss (5.5) associated with the mean-square Bellman error. An analytical approximation of the DP equation is obtained by choosing a $d_z$-dimensional sequence $\{\zeta(k)\}$, and search for a function $h$ that satisfies the constraint:

```
$0 = \sum_{k=1}^{N} D_k(h(z_k),h(z_{k+1}))\zeta(k), \quad 1 \leq i \leq d_z. \quad (5.12)$
```

This is called a Galerkin relaxation, and potentially a relaxation of our ultimate under unrealistic goal: to find a function $h$ for which the temporal difference $D_k(h(z_k),h(z_{k+1}))$ is zero for each $k$. In the context of RL, the vectors $\{\\zeta(k)\}$ appear as eligibility vectors in standard algorithms (see Section 5.4).

For a finite-dimensional function class, we set $d_z=d$, so that (5.12) represents $d$ constraints, which is consistent with the unknowns, $\{\theta_i^* : 1 \leq i \leq d\}$.
