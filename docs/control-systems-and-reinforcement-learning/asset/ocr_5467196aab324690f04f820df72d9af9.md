First, the extreme points of this LP admit the factorization (B.21) with $\phi$ deterministic $(\phi(u \mid x)$ is zero or for each $x, u$) and $\pi$ "ergodic” (the chain restricted to the support of $\pi$ is irreducible).

There is something called the *dual* of an LP:

```
$\min c^T x \quad \text{s.t.} \ Ax \le b, x \ge 0 \quad \longleftrightarrow \quad \max b^T \xi \quad \text{s.t.} \ A^T \xi \ge c, \xi \ge 0$
```

The dual of (B.22) can be reduced to a version of the ACOE:

```
$\max \quad z \n\text{s.t.} \quad c(x) - z + \sum_{y\in X} P_u(x,y)h(y) - h(x) \ge 0, \quad x \in X, u \in U. \quad (B.23)$
```

This looks very much like the DPLP (3.36), and its dual (5.82) resembles (B.22).
