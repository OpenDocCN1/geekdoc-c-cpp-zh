# 4.8.2 Lyapunov Functions

The survey contained in Section 2.4.5 tells us much of what we need to know about Lyapunov functions. The goals of algorithm design, is to ensure global asymptotic stability, so that the drift condition of interest is in (2.38) with $x^*$ replaced by $\theta^*$:

$\nabla V(\theta), f(\theta)\rangle < 0, \quad \quad \ \theta \neq \theta^*.$

This (and a few additional assumptions) allows application of Proposition 2.5 to establish convergence of $\theta$.

Often the first step to establishing consistency of an ODE or algorithm is to show that the estimates do not “blow up”. The ODE is ultimately bounded if there is a bounded set $S \subset \mathbb{R}^d$ such that for each initial condition $\theta_0$, there is a time $T(\theta_0)$ such that $\theta_t \in S$ for $t \ge T(\theta_0)$.

There is naturally a Lyapunov condition to:

$\nabla V(\theta), f(\theta)\rangle \le -\delta_0, \quad \quad \ \theta \in \mathbb{R}^d. \quad (4.109)

**Proposition 4.20** Assume that there is a continuously differentiable function $V: \mathbb{R}^d \to \mathbb{R}_+$ satisfying (4.109) for $\delta_0 > 0$ and set $S \subset \mathbb{R}^d$. Then $T(\theta_0) \le \delta_0^{-1}V(\theta_0)$ for $\theta \in \mathbb{R}^d$, where

$T(\theta_0) = \min\{t \ge 0: \theta_t \in S\}, \quad \quad \theta_0 \in \mathbb{R}^d.$

If $S$ is compact, and $V$ is inf-compact, then the ODE (4.2) is ultimately bounded.

*Proof* We take $\delta_0 = 0$ without loss of generality (obtained by scaling the function $V$ if necessary).

$\frac{d}{dt}V(\theta_t) \le -1, \quad \quad \ 0 \le t \le T_S(\theta), \quad \quad \ \theta_0 \in \mathbb{R}^d. \quad (4.110)

Integrate each side from time $t=0$ to $t=T_N = \min(N, T_S(\theta))$ (the minimum with $N$ is required since we don't know if $T_S(\theta) < 0$). Next, apply the fundamental theorem of calculus

$V(\theta_0) \le V(\theta_{T_N}) - V(\theta_0) \le -T_N,$
