In much of the SA and RL literature, it is assumed that $\Phi$ is a Markov chain: a topic considered in depth in Chapter 6. A motivating observation in the present chapter is that Markov chains need not be stochastic: the state space model (2.21) (without control) satisfies the Markov property used in Part II of this book. For example, given $\omega > 0$, the sequence $\theta_n = [cos(\omega n), sin(\omega n)]$ is a Markov chain on $\Omega$ (the unit circle in $\mathbb{R}^2$). ```
$$\frac{d}{dt}\theta_t = a_t(\theta_t, \xi_t).$

The expectation in (4.41) is defined by the sample path average:

```
$f(\theta) = \lim_{T\to\infty} \frac{1}{T} \int_0^T f(\theta, \xi_t)dt, \text{for all } \theta \in \mathbb{R}^d.$
```

The existence of this limit requires assumptions on $f$ and the probing signal.

## 4.5 Quasistochastic Approximation

The probing signal is deterministic in the QSA developed in this chapter. Two canonical choices with $\Omega \subset \mathbb{R}^m$ are the $m$-dimensional mixtures of periodic functions:

```
$\Xi_d = \sum_{i=1}^K v^i[\phi_i + \omega_i t]_{(\text{mod } 1)} \quad (4.46a)$
```

```
$\Xi_d = \sum_{i=1}^K v^i\sin(2\pi[\phi_i + \omega_i t]) \quad (4.46b)$
```

for fixed $K \geq 1$, vectors $\{v^i \subset \mathbb{R}^m$, phases $\{\phi_i\}$, and frequencies $\{\omega_i\}$. Such signals have well-defined steady-state mean and covariances. Consider example (4.46b) in the special case

```
$\Xi_d(i) = \sqrt{2}\sin(\omega_i t), \quad 1 \leq i \leq m \quad (4.47)$
```

with $\omega_i \neq \omega_j$ for all $i \neq j$. The steady-state mean and covariance then satisfy

```
$\lim_{T\to\infty} \frac{1}{T} \int_0^T \Xi_d \ dt = 0, \quad (4.48a)$
```

```
$\lim_{T\to\infty} \frac{1}{T} \int_0^T \Xi_d^2 \ dt = 1, \quad (4.48b)$
```

where $1$ is the identity matrix.
For a function $g: \mathbb{R}^K \to \mathbb{R}$, we can expect the following asymptotic independence, provided the frequencies $\{\omega_i\}$ are distinct:

```
$\lim_{T\to\infty} \frac{1}{T} \int_0^T g(2\pi[\phi_1 + \omega_1 t]), \dots,sin(2\pi[\phi_K + \omega_K t]) \ dt =\ \int_0^1 \dots\int_0^1 g(2\pi[\phi_1 + \omega_1 t_1]), \dots,sin(2\pi[\phi_K + \omega_K t_K]) \ dt_1 \dots dt_K. \quad (4.49)$
```

See Lemma 4.37 for a precise statement about another general class of probing signals. The following subsections contain examples to illustrate theory of QSA, and also a glimpse at applications.

### 4.5.1 Quasi Monte-Carlo

Consider the problem of integrating over the interval $[0, 1]$ of a function $y: \mathbb{R} \to \mathbb{R}$. In a standard Monte-Carlo approach we would draw independent random variables $\{\Phi(k)\}$, with distribution uniform on the interval $[0,1]$, and then:

```
$\theta_n = \frac{1}{n} \sum_{k=0}^{n-1} y(\Phi(k)). \quad (4.50)$
```

In a QSA approach, the probing signal is the one-dimensional sawtooth function, $\Xi_d \equiv t$ (modulo 1), and estimates are defined by the average

```
$\Theta_t = \frac{1}{t} \int_0^t y(\Xi_r) dr. \quad (4.51)$
```

Alternatively, we can adapt the QSA model (4.44) to this example, with $f(0, \xi_t) \stackrel{\text{dist}}{=} y(\xi_t) - \theta$.
The mean is given by

$f(0) = \lim_{T \to \infty} \frac{1}{T} \int_0^T f(0, \xi_t)dt = \int_0^1 y(\xi_t)dt,$

so that $\theta^* = \int_0^1 y(\xi_t)dt$ is the unique root of $f$. The QSA ODE (4.44) gives

$\frac{d}{dt}\Theta_t = a_t[y(\xi_t) - \Theta_t].$

The Monte Carlo approach (4.51) can be transformed into resembling (4.53). Derivatives of each (4.51), can be estimated using the product rule of differentiation, and the fundamental theorem of calculus,

$\frac{d}{dt}\Theta_t = -\frac{1}{t} \int_0^t y(\xi_r)dr + \frac{1}{t}y(\xi_t) = \frac{1}{t}[y(\xi_t) - \Theta_t].$

This is precisely (4.53) with $a_t = 1/t$ (not a great choice for ODE design, since it is bounded as $t \downarrow$).

The numerical results that follow are based on $y(\theta) = e^{at}\sin(\theta)$, whose mean is $\theta^* \approx -0.5$. The differential equation (4.53) was approximated using a standard Euler scheme with sampling interval $10^{-3}$. Several variations were simulated, differentiated by the gain $a_t = g/(1+t)$. Figure 4.3 shows typical sample paths of the resulting estimates for a range of gains, with initialization $\Theta_0 = t$. In each case, the estimates converge to the true mean $\theta^* \approx -0.5$, but convergence is very slow for $g > 0$ significantly less than one.

Independent trials were conducted to obtain variance estimates. In $10^4$ independent runs, the initial condition was drawn randomly, and the estimate was calculated at time $T=100$. Figure 4.4 shows histograms of estimates for standard Monte Carlo (4.50) and QSA using $g=1$ and $2$. An alert reader might wonder: Why is the variance reduced by four orders of magnitude when the gain is increased from 1 to 2? The relative success of the high-gain algorithm is explained in Section 4.5.
