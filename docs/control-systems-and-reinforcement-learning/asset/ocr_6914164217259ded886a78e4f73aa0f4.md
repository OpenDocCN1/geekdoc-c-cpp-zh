# Stochastic Approximation

Quasistochastic approximation is the engine behind the gradient-free optimization algorithms surveyed in Section 4.6 and Q-learning algorithms introduced in Chapter 5. The history of stochastic approximation (SA) is far older, so that SA techniques are far more familiar to algorithm designers.

The goal is identical to the starting point of Section 4.5: We wish to solve the root-finding problem $f(	heta*)*) 0$, where $f: \mathbb{R}^d 	o \mathbb{R}^d$ is defined as an expectation:

```
$f(\theta*) \stackrel{\text{def}}{=} E[f(\theta, \Phi)], \quad \theta \in \mathbb{R}^d.$
```

As in the deterministic setting, $f: \mathbb{R}^d \times \Omega \to \mathbb{R}^d$, and $\Phi \in \Omega$ is a random vector. The SA recursion is entirely analogous to the QSA ODE (4.44):

# Stochastic Approximation

For initialization $\theta_0 \in \mathbb{R}^d$, obtain the sequence of estimates recursively:

```
$$\theta_{n+1} = \theta_n + \alpha_n f_{n+1}(\theta_n),$
```

where $f_{n+1}(\theta_n) = f(\theta_n, \Phi(n+1)), \Phi$ has the same distribution as $\Phi$ for each $n$ (or its distribution converges to that of $\Phi$ as $n \to \infty$), and $\{\theta_n\}$ is a nonnegative scalar step-size sequence.

Analysis begins with a representation of (8.2) as a "noisy" Euler approximation,

```
$$\theta_{n+1} = \theta_n + \alpha_n[f(\theta_n) + \Delta_n]|, \quad n \ge 0$
```

```
in which $\Delta_{n+1} = f_{n+1}(\theta_n) - f(\theta_n) \quad \text{and} \quad \Delta_{n+1}^* = f_{n+1}(\theta^*).$
```

Stability of the ODE and additional minor assumptions imply consistency:

```
$$\lim_{n\to\infty} \theta_n = \theta^* \quad \text{with probability} one.$
```

See Theorem 8.1 for a proof that follows in Section 4.5.
