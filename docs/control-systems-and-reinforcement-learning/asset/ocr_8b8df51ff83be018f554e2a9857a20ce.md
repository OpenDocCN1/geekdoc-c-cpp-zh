# Quantized State Space

A continuous state model is commonly approximated through a partition of the state space into a finite collection of bins $X = \cup_i B_i$. This step is called quantization or binning. The next step is to choose a representative state $x^i \in B_i$ for each $i$, and define approximate dynamics on the state-dimensional composition, $X_o \overset{def}{}=\{x^i : 1 \leq i \leq n\}$.

In this two-dimensional case, it is convenient to choose bins based on a rectangular grid: For an integer $N > 1$, choose $n=N^2$, and select $X_o=\{x^{i,j}=(z^i,w^j)^top : 1 \leq i,j \leq N\}$, where the position and velocity values are equally spaced

```
$-1.2 = z^1 < z^2 < \dots < z^N = 0.5, \quad -v = v^1 < v^2 < \dots < v^N = v$.
```

Each $x^{i,j}$ belongs to a bin $B_{i,j}$; The bins are disjoint, with union equal to X. The value $N=160$ was used to obtain the approximation shown in Figure 3.2. The state model with velocity $x$, is denoted

```
$x_o(k+1) = F(x_o(k),u(k)), (3.53)
```

where $x_o(k) \in X_o$ and $u(k) \in U=\{-1,1\}$ for each $k$. The next step is to define the dynamics, $F(\cdot)$ which require some care.

We define $F(x^{N,j},u) = (z^N,0)$ for any $u$ and $j$, since in this case $x^{N,j}=(0.5,v)$ (so the card is packed).

Consider $x^{i,j} \in X_o$ with $i < N$ and $u \in U$. Denote $x^{i,j}(u)=F(x^{i,j},u)$, the two-dimensional component with

```
$z^{i,j}(u)=F_1(x^{i,j},u), \quad v^{i,j}(u)=F_2(x^{i,j},u)$.
```

Define $i_+$ and $j_+$, uniquely by the constraint $x^{i_+,j_+}(u) \in B_{i_+,j_+}$. The specification of velocity dynamics is straightforward:

The position dynamics are modified as follows:

```
$F_{\times1}(x^{i,j},u) = \begin{cases} z^+ , & z^{i,j}(u) \geq z^+ \ z^+-1, & z^{i,j}(u) < z^+ \texttext{ and } z^+ = z^+ \ z^-, & \text{else} \end{cases} (3.54)
```

These dynamics are defined so that $F_{\times1}(x^{i,j},u) \neq z^i$ for any $i < N$. *Rationale*: to avoid the existence of state $x_o=x^{i,j}$ satisfying $i < N$ and $v=F(x_o,u)$ for any $u \in U$.

# VIA and PIA Implementation

VIA will be successful for any initialization $V^0$ in this finite state space model. The choice $V^0=0$ was used in the numerical experiments described in the following.

Successful implementation of PIA requires an initial policy that is stabilizing, in the sense that the goal is reached from each initial condition. A variant of (2.59) was chosen: For each $x=(z,v)^top \in X_o$,

```
$\Phi^0(x) = \begin{cases} \sign(v) & z+v \geq Tol \ 1 & \text{else} \end{cases}$
```
