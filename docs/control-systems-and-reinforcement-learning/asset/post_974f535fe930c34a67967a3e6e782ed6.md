
## 4.9 Convergence Theory for QSA

Proof of Theorem 4.24 (1.414)

```
$$\frac{d}{dt}Y_t = a_t \left[ (A^* + \frac{r_t}{a_t}I)Y_t + \Delta_t^Y - Y_t + (A^* + \frac{r_t}{a_t}I)\Xi_t \right],$$
```

where $r_t/a_t = o(1)$ for $\rho < 1$, and $r_t/a_t = 1$ if $\rho = 1$. The resulting can be regarded as a linear QSA ODE with vanishing disturbance. Let $\kappa(\rho) = 1_{\{\rho=1)}$ (equal to zero for $\rho < 1$, and $1$). Under the condition $A^* + \kappa(\rho)I$ is Hurwitz, the proof of Theorem 4.15 can be

```
$$\widetilde{Y} = \lim_{t\to\infty} Y_t = \lim_{T\to\infty} \frac{1}{T} \int_0^T [A^* + \kappa(\rho)I]^{-1}\partial_0\Xi_t \cdot f(\theta_t, \xi_t) dt = [A^* + \kappa(\rho)I]^{-1}\widetilde{Y},$$
```

where the second equality holds because $\lim_{T\to\infty} \frac{1}{T} \int_0^T \Xi_t dt = 0$ under (4.119), and the definition of $\widetilde{Y}$ in QSA5. This gives the coupling result $Z_t = Y + \widetilde{Y} + o(1)$.

The second approximation in (4.120a) follows from the first: Applying the definition

```
$$\Theta_t = \theta^* + a_t[\widetilde{Y}] + o(a_t).$$
```

For $\rho < 1$, we have $\Theta_t = \theta^* + o(a_t)$ since it converges to 0 faster than $t^{-N}$ for any $N$. For $\rho=1$, Proposition 4.26 implies that $\Theta_t = \theta^* + O(t^{-\varrho})$ where $\text{Re}(\lambda < -q_0)$ for every eigenvalue $\lambda$ of $A^*$. Therefore, $\Theta_t = \theta^* + O(1)$ if $I + A^*$ is Hurwitz.

The proof of Theorem 4.25 is broken into three lemmas that follow. The assumptions of the theorem are assumed throughout. In particular, in the definition (4.121c) of $\Theta_t^T$, it is assumed that $a_t = 1/(1+t)$ with $\rho \in (\{0,1\})$, and $T_0 = (1-1/\kappa T)$.

The first step is to approximate the estimation error

```
$$\Theta_T^T - \theta^* = \frac{1}{T-T_0} \int_{T_0}^T [\Theta_t - \theta^*] dt = \frac{1}{T-T_0} \int_{T_0}^T [\Theta_t - \widetilde{\Theta}_t] dt + o(1/T), (4.146)$$$
```

where $\rho > 1$ is fixed by arbitrary. The result follows from Proposition 4.26 (ii) regarding (4.124).

The vector-valued process $\Phi_T$ in (4.122) is constructed as part of the proof. It is

```
$$\Phi_T = [A^*]^{-1}(Y_T - Y_{T_0} + \Psi_T^Y + \Psi_T^\Psi) + o(1) (4.147a)$$$
```

```
$$\with \Psi_T^Y = \int_{T_0}^T r_t dY_t \text{ and } \Psi_T^\Psi = \int_{T_0}^T a_t d\widetilde{Y}_t dt = a_t d\widetilde{Y}_t, (4.147b)$$$
```

where, from (4.118),

```
$$\widetilde{Y}_t = Y_t - \widetilde{Y} \text{ and } \widetilde{Y}'_t = \int_0^t [Y_r - \widetilde{Y}] dr$$
```

where $\widetilde{Y}$ the ergodic mean introduced in (QSA5). The first term $\Psi_T^\Psi$ is bounded because

$\{Z_t\}$ is bounded, and $r_t = 1/(1+t)$, giving

```
$$\|\Psi_T^\Psi\| \le \log(T/T_0) \sup ||Z_t|| = \log(\kappa/(\kappa-1)) \sup ||Z_t|| < \infty.$$$$
```

### Lemma 4.39 Under the assumptions of Theorem 4.25.

```
$\int_{T_0}^T [\Theta_t - \bar{\Theta}_t] dt = |A^*|^{-1} \{Z_{T_0} - \int_{T_0}^T \bar{\Xi}_t dt + \Psi_t^T + o(1)\}. $
```

Proof Combining the definition $a_t$, $Z_t = a_t(\Theta_t - \bar{\Theta}_t)$ and

```
\frac{d}{dt}Z_t = a_t A^* Z_t + a_t \Delta t + \bar{\Xi}_t$
```

(see (4.125d)) gives, by the Fundamental Theorem of Calculus,

```
$Z_T - Z_{T_0} = A^* \int_{T_0}^T [\Theta_t - \bar{\Theta}_t] dt + \int_{T_0}^T [a_t \Delta t + \bar{\Xi}_t] dt.$
```

Applying Proposition 4.27, the scaled error can be expressed

```
$a_t D_t = a_t \Delta_t^{(p)} + r_t Z_t.$
```

Theorem 4.24 (i) implies that $r_t||Z_t||=O(1/t)$ and $a_t|\Delta_t^{(p)}||=O(|\Theta_t - \bar{\Theta}_t|^2)=O(\alpha^2)$, so that (4.148) follows on reasoning in (4.149) and using the definition (4.147b). $\square$

### Lemma 4.40 Under the assumptions of Theorem 25.

```

$$\Theta_T^T - \theta^* = |A^*|^{-1} \{Y_T - Y_{T_0} + \int_{T_0}^T a_t \Upsilon_t dt + \Psi_t^T + o(1)\}.$$
```

Proof Calling (4.145) and (4.119), which gives

```
$\int_{T_0}^T \bar{\Xi}_t dt = \bar{\Xi}_T(\Theta_T) - \bar{\Xi}_T(\bar{\Theta}_0) - \int_{T_0}^T a_t \Upsilon_t(\Theta_t)$
```

```
$$\bar{\Xi}_T(\Theta_T) - \bar{\Xi}_T(\bar{\Theta}_0) - \int_{T_0}^T a_t \Upsilon_t dt + \int_{T_0}^T a_t O(|\Theta_t - \bar{\Theta}_t|)dt,$$
```

where $\int_{T_0}^T a_t O(|\Theta_t - \bar{\Theta}_t|)dt=o(1)$ for $\rho \in (\frac{1}{2}, 1)$. Recalling the definition $Y_t \overset{def}{=} Z_t - \Xi_t$ in (4.126) gives

```
$Z_T - Z_{T_0} = \int_{T_0}^T \bar{\Xi}_t dt = Y_T - Y_{T_0} + \int_{T_0}^T a_t \Upsilon_t dt + o(1).$
```

Combining (4.148) and (4.151) completes the proof:

```
$$\Theta_T^T - \theta^* = \frac{1}{T-T_0} \int_{T_0}^T [\Theta_t - \bar{\Theta}_t] dt + o(1/T)$$
```

```
$$\frac{1}{T-T_0} |A^*|^{-1} \{Y_T - Y_{T_0} + \int_{T_0}^T a_t \Upsilon_t dt + \Psi_t^T + o(1)\}.$$
```

The integral on the right-hand side of (4.150) is the crucial term, which can be expressed

```
$\int_{T_0}^T a_t \Upsilon_t dt = \Psi_{T_0}^T,$
```

with $\Psi_T^T$ defined in (4.147b).
