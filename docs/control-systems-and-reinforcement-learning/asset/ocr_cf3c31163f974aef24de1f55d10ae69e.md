The following solves half of the “regeneration puzzle.” For any function $g: X 	imes \mathbb{R}$ and $\gamma \in [0,1]$, denote $\hat{g} = 	au_\gamma^* g$, with

```
$$\hat{g}(z) = E\left[\sum_{k=0}^{\tau_\gamma^*-1}\gamma^k g(\Phi(k)) \|\ \Phi(0) = z\right].$
```

We have $\hat{g} = J_\gamma(g)$ if $g=c$, and $\hat{g} = Hc$ if $g=c$ and $\gamma=1$.

**Lemma 10.23** *The adjoint of $T_\gamma^*$, satisfying $\langle T_\gamma g, h\rangle = \langle g, [T_\gamma^*]h\rangle$ for each $h \in L_2(\Omega)$, is given by*

```
$[T_\gamma^*]h(z) = E\left[\sum_{n=k}^{\tau_\gamma^*-1}\gamma^{n-k}h(\Phi(n)) \|\ \Phi(n) = z\right], \quad z \in X \times X, n \in \mathbb{Z},$
```

where $\Phi(k) : k \in \mathbb{Z}$ is a stationary version of the Markov chain. In particular, with $\zeta_n$ defined in (10.56).

```
$E[g(\Phi(n))w(\Phi(n))] = E[g(\Phi(n))\zeta_n].$
```

Proof It is enough to establish the identity for $n=0$. From the definitions,

```
$\langle T_\gamma g, h\rangle = E[h(\Phi(0))\hat{g}(\Phi(0))] = E[h(\Phi(0))E[\sum_{k=0}^{\tau_\gamma^*-1}\gamma^k g(\Phi(k))]].$.
```

The smoothing property of conditional expectation gives

```
$E[h(\Phi(0))\hat{g}(\Phi(0))] = E[h(\Phi(0))\sum_{k=0}^{\tau_\gamma^*-1}\gamma^k g(\Phi(k))].$
```

and then stationarity and the definition of $\tau_\gamma$,

```
$E[h(\Phi(0))g(\Phi(0))] + \sum_{k=1}^{\infty}\gamma^k E[1{\Phi(j) \neq z^* : 1 \le j \le k\}h(\Phi(0))g(\Phi(k))]$.$
```

```
$E[h(\Phi(0))g(\Phi(0))] + \sum_{k=1}^{\infty}\gamma^k E[1{\Phi(j-k) \neq z^* : 1 \le j \le k\}h(\Phi(-k))g(\Phi(0))].$
```

Make the change of variables $\ell = j-k$, so that $1{\Phi(j-k) \neq z^* : 1 \le j \le k\} = 1{\Phi(\ell) \neq z^* : -k \le \ell \le 0\}$. By adopting this, and returning the sum and the coefficient $\gamma^k$ within the expectation gives

```
$E[h(\Phi(0))g(\Phi(0))] + E[g(\Phi(0))\sum_{k=1}^{\infty}\gamma^k 1{\Phi(\ell) \neq z^* : -k \le \ell \le 0\}h(\Phi(-k))].$.$
```

```
$E[h(\Phi(0))g(\Phi(0))] + E[g(\Phi(0))\sum_{k=1}^{\tau_\gamma^{(0]}}\gamma^{-k}h(\Phi(-k))].$.
```

where the sum is defined to be zero when $\delta_\gamma^{(0)} = 0$. This establishes the desired result for $n=0$.
