260	Stochastic Control

The estimate $\hat{X}(k)$ is defined recursively as follows, based on this important fact: The conditional distribution of $X(k)$ given $Y_0^k$ is Gaussian $N(m_k,\Sigma_k)$ in which

+   (a) The conditional mean $m_k = \hat{X}(k)$ evolves as the time-varying linear system,

```
$$\hat{X}(k+1) = F\hat{X}(k) + GU(k) + L_kY(k+1) - \hat{Y}(k+1|k)$,$
$\hat{Y}(k+1|k) = H\hat{X}(k+1) = H(F\hat{X}(k) + GU(k)), \quad k \ge 0$
```

with initial condition

```
$$\hat{X}(0) = E[\hat{X}(0)] + L_0Y(0) - HE[X(0)]$.
```

+   (b) The filter gains are defined by

```
$L_k = \Sigma_{k+1}H^T(\Sigma_W + H\Sigma_{k+1}H^T)^{-1}, \quad k \ge -1$.
```

+   (c) The conditional covariance does not depend on the observations, but evolves according to a deterministic Riccati recursion:

```
$$\Sigma_k = \Sigma_{k+1} - \Sigma_{k+1}H^T[H\Sigma_{k+1}H^T + \Sigma_W]^{-1}H\Sigma_{k+1\|+\Sigma_W$, \quad (7.50)
```

with initial condition

```
$$\Sigma_{0} = E[\hat{X}(0)\hat{X}(0)^T], \quad \hat{X}(0) = X(0) - \tilde{X}(0)$.$
```

+   (ii) The solution to the average-cost optimal control problem, subject to the constraint (7.49) on the input sequence, is obtained using linear feedback:

```
$U(k) = -K^*\hat{X}(k)$,
```

where $\hat{X}(k)$ is the conditional mean, as in (i).

One step in the proof of the proposition is that the cost can be expressed in terms of the new state $\tilde{X}$ as follows:

```
$$\E[X(k),U(k)] = E[X(k)^TSX(k) + U(k)^TRU(k)] + E[\tilde{X}(k)^T\tilde{X}(k)]$,$\n$= E[\hat{X}(k)^TS\hat{X}(k) + \tilde{X}(k)^TRU(\tilde{X}(k)]$,
```

in this tilde denotes error: $\tilde{X}(k) = X(k) - \hat{X}(k)$. The last term is independent of control:

```
$$\E[\hat{X}(k)^TS\hat{X}(k)] = trace(\Sigma_kS)$.
```

This leads to the *separation principle*: The optimal input is the "plug-and-play" control law:

```
$U(k) = \phi^*(\hat{X}(k)) = K^*\hat{X}(k)$, \quad (7.51)
```

where $K^*$ is the feedback gain obtained for the control problem with full observations. This optimal control solution is known as *certainty-equivalent form*. Please don't forget that the certainty-equivalence conclusion is very particular to the assumptions imposed.
