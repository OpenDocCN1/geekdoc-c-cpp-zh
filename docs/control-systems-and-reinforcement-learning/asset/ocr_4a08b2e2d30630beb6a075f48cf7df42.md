# 5.5 Convex Q-Learning

The RL algorithms surveyed in this section are all motivated by the DPLP(3.36). We begin with a direct approach based on a joint parametrization: In notation of Section 5.1, $\mathcal{H} = \{h^	heta = (J^	heta, Q^	heta): 	heta \in \mathbb{R}^d\}$. The value $	heta_i$ might represent the $i$-th weight in a neural function approximation architecture, but to justify the adjective convex, we require a linearly parameterized family:

```
$J^	heta(x) = 	heta^	op \psi^j(x), \quad Q^	heta(x, u) = 	heta^	op \psi(x, u).$
```

The function class is normalized with $J^	heta(x^	heta) = 0$ for each $	heta$. For the linear approximation architecture, this requires $\psi^i(x^	heta) = 0$ for each $1 \leq i \leq d$; for a neural network architecture, this normalization is imposed through definition of the output of the network. Convex Q-learning algorithms based on RKHS are described in Section 5.5.2. Consider the translation of (3.36) based on a parameterized family:

```
$$\max_{\theta} \langle \mu, Q^	heta \rangle\n\text{s.t.} \quad Q^	heta(x, u) \leq c(x, u) + J^	heta(F(x, u)),\nQ^	heta(x, u) \geq J^	heta(x), \quad x \in X, u \in U(X)$ (5.62)
```

where $u$ is now a weighting on $X 	imes U$. We can strengthen the constraint to equality: $Q^	heta(x, u) = c(x, u) + J^	heta(F(x, u))$. This is reasonable if we have a good model: first a parameterized family $\{J^	heta\}$, then define $Q^	heta(x, u) = c(x, u) + J^	heta(F(x, u))$ for each $	heta, x, u$. However, if we don't have a highly accurate model, it is then better to relax the equity constraint, which is why (5.62) is our starting point.

Another inequality that can be removed from (5.62) is $Q^	heta \geq J^	heta$, since the optimal solution for the DPLP results $J^* = Q^*$. We can remove $J^	heta$ from (5.62) by imposing this constraint:

```
$$\max_{\theta} \langle \mu, Q^	heta \rangle\n\text{s.t.} \quad Q^	heta(x, u) \leq c(x, u) + Q^	heta(F(x, u)), \quad x \in X, u \in U(X)$ (5.63)
```

or even $\$\max_{\theta} \langle \mu, Q^	heta \rangle$ subject to the inequality constraints in (5.63),

with $v$ weighting on $X$. With each objective function, this remains a convex program provided the function class is linear in $	heta$. And through design, we must ensure that $Q^	heta(x^	heta) = 0$ for each $	heta$. This is achieved by imposing $\psi_i(x^	heta, u) = 0$ for all $i$ and $u$, and recognizing that it is reasonable to assume that $U(x^	heta) = \{u^	heta\}$ (once we are at the equilibrium with zero cost, there is no reason to leave)

The algorithms in this section are based on approximations of (5.63). Special options are surveyed in the following.
