```
$$\frac{d^2z^i}{dt^2} = -a_i\frac{dz^i}{dt} + b_iu^i - d^i,$
```

in which $\{a_i, b_i\}$ are positive scalars, and the disturbance $\{d_t^i\}$ is left unmodeled. If we ignore the disturbance (for the purposes of control design), we can pose the rowing as a linear-quadratic optimal control problem: a topic covered in Sections 3.1 and 3.6. We will then result in a policy of the following

```
$u^i = K^ix + r^i,$
```

where $x$ is the 2N-dimensional vector of positions and velocities for all the rowers, $K^i$ is a 2N-dimensional row vector, and $r^i$ is a scalar function of time that depends upon the tracking goal. Implementation of this policy requires that each rower know the position and velocity of every other rower at time. Let's think about how the rowers might cooperate without so much data.

Each rower only views the neighbors to the left and right. This breaks the team of size N into N (overlapping) subteams of size three that coordinate individually. Unfortunately, if $N$ is large, it is known that this distributed control architecture can lead to large oscillations in the positions of the boats relative to the distant island [130].

The theory of mean-field games suggests that a more robust strategy is obtained with a bit of global information: Assume that at each time $t$, rower $i$ has access to three scalar observations: her position $z_t^i$, $v_t^i$, and the average position of all rowers:

```
$$\tilde{z}_t = \frac{1}{N}\sum_{j=1}^N z_t^j.$ \quad (2.67)$
```

One possibility is to pretend that $x_t^i = (z_t^i, v_t^i, \tilde{z}_t)^T$ evolves according to a state space model of the form (2.19), in which case it is appropriate to search for a state feedback policy $u_t^i = \Phi^t(x_t^i)$.

Before fixing the architecture of the policy, it is essential to consider the goals. Since we have assumed social distancing is managed through an independent control mechanism, there remain only:

```
$z_t^i \approx \tilde{z}_t, \quad v_t^i = \frac{dz_t^i}{dt} \approx v^{mt} \quad$ for all large $t$.
```

Based on the discussion in Section 2.3.2, we might obtain better coordination through the introduction of a fourth variable, defined as the integral of the position

```
$z_t^i = z_0^i + \int_0^t e^{\rho(t-r)}|z_r^i - z_r| dr,$
```

or the discounted approximation,

```
$z_t^i = z_0^i + \int_0^t e^{\rho(t-r)}|z_r^i - \tilde{z}_r| dr,$
```

with $\rho > 0$. Once we have made our choice, we then search for a policy defined as a function of the four variables, $u_t^i = \Phi^t(z_t^i, v_t^i, \tilde{z}_t, z_t^i)$.
