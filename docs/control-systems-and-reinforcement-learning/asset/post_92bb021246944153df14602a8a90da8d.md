
## 6.1 Markov Models Are State Space Models

The state $X(k)$ at time $k$ is a random variable. Its distribution is a probability measure denoted $\mu_k$, defined for any Borel measure function $h$

$$E[h(X(k))] = \int h(x) \mu_k(dx). \quad (6.7)$$

The notation may look strange, but I know of no better alternative when we don't know the form of $\mu_k$. If there is a density, then by $\mu_k(dx) = p_k(x)dx$ for nonnegative $p_k$; if $\mu_k$ is discrete, the integral becomes a sum. The Gaussian linear state space model discussed in Example 6.2.1 makes clear why we need this abstract notation.

Please keep in mind: We don't know the form of $\mu_k$. We want to write one book for Markov chains with densities, another for those on a countable state space, and a third for when neither assumption applies (as found in Example 6.2.1). The notation (6.7) is agnostic to the form of $\mu_k$.

## Notation Surrounding Conditional Expectations

Conditional expectations of the form

$$E[h(X(k+1)) | X(0), \dots, X(k)]$$

appear everywhere in the remainder of the chapter and the book (which is meaningful provided $E[h|X(k+1)] < \infty$). Never heard of conditional expectation? Example 6.3 is provided as a mini-crash-course, with a longer course in Section 9.2. You should review [154] or some other foundational source for a fuller understanding.

Fortunately, definitions are simplified when considering functions of a Markov chain, because the conditional expectation can be expressed in terms of the transition kernel: for any $x \in X$, and any initial distribution for $X(0)$.

$$E[h(X(k+1)) | X(0),\dots,X(k-1); X(k) = x] = E[h(X(k+1)) | X(k) = x] = \int P(x,dy)h(y). \quad (6.8)$$

If $X$ is finite, of size $m$, then $P$ is presented as an $m \times m$ matrix. In this case, $P(x_0,x_1)$ is the probability of moving from $x_0$ to $x_1$ in one step. The conditional expectation is expressed as sum:

$$E[h(X(k+1)) | X(k) = x] = \sum_{x_1 \in X} P(x,x_1)h(x_1)$$

Conditional expectations appear so frequently that we require shorthand notation: For a function $h: X \to \mathbb{R}$ and integers $r,k \geq 0$,

$$E_x[h(X(k))] \overset{\text{def}}{=} E[h(X(r+k)) | X(r) = x], \quad (6.9a)$$
$$P^k h(x) \overset{\text{def}}{=} E[h(X(r+k)) | X(r) = x], \quad x \in X. \quad (6.9b)$$

In the special case $k=1$, we write $Ph$ rather than $P^1h$.

In (6.9b), we view $P^k$ as a mapping from functions to functions. This representation was introduced for finite state space models early in this book, just above (3.17), where for emphasis we introduced the vector notation

$$\hat{h}=[h(x_1),\dots,h(x_m)]^T, \quad X=\{x_1,\dots,x_m\}$$

and wrote $P^k \hat{h}$ rather than $P^k h$. This cumbersome vector notation will not appear again in this book.

If $\mu$ is a probability measure on $X$, and $X(k+r) \sim \mu$ (the state is distributed according to $\mu$ at time $r$), then it follows $X(k+r) \sim \mu_k$ for any $k \geq 1$,

$$\mu_k(S) = \int \mu(dx)P^k(x,S), \quad S \in \mathcal{B}(X).$$

This is expressed $\mu_k = \mu P^k$, which is also consistent with vector-matrix multiplication in the finite state space. When $r=0$, this probability measure is precisely the same as in (6.7). We could further write

$$\mu h = \int h(x)\mu(dx).$$

However, "$\mu h$" can create ambiguity, so we introduce parentheses for emphasis:

$$\mu(h) = \int h(x)\mu(dx). \quad (6.11)$$

Please get used to this notation! They will be used throughout the remainder of the book.

## 6.2 Simple Examples

We begin with a few examples. The linear model is standard in physics, systems theory, and many other areas.

**Example 6.2.1 (The Linear Space Model)** Suppose $X=\{X(k); k \geq 0\}$ is a stochastic process for which there is an $n \times n$ matrix $F$ and an i.i.d. sequence $N$ taking values in $\mathbb{R}^n$ such that $X(0) \in \mathbb{R}^n$ is independent of $N$. Then $X$ is called the (uncontrolled) linear state space model. We denote the state process using lower case where $N=0$, as in

$$x(k+1) = Fx(k), \quad k \geq 0. \quad (6.12)$$

The state process $x$ is also Markovian: Given the full history of observations $\{x(i) : i \le k\}$, we can still predict $x(k+1)$ with exact accuracy based only on knowledge of $x(k)$. The transition kernel is easily described: For any $x \in X = \mathbb{R}^n$ and set $S \subset X$, we have

$$P(x,S) = P\{X(1) \in S | X(0) = x\} = P\{Fx + N(1) \in S\}$$

If $N(1)$ is Gaussian $N(0, \Sigma_N)$, then $P(x, \cdot)$ is a Gaussian distribution with mean $Fx$ rather than zero. If at some time $r \ge 0$ we observe $X(r) = x$, then for each $j \ge 0$

$$X(r+j) = F^jx + \sum_{i=1}^j F^{j-i}N(r+i).$$

That is, conditioned on $X(r) = x$, the random vector $X(r+j)$ has a Gaussian distribution with mean $F^jx$ and covariance

$$\Sigma_{X_j} = \sum_{i=1}^j (F^{j-i})^\top \Sigma_N F^{j-i}.$$

If $\Sigma_{X_j}$ is full rank (so its inverse exists), $P^j$ admits a density:

$$p_j(x,y) = \frac{1}{\sqrt{(2\pi)^n \det(\Sigma_{X_j})}} \exp(-\frac{1}{2}(y-F^jx)^\top \Sigma_{X_j}^{-1}(y-F^jx))$$
$$P^j(x,S) = \int_S p_j(x,y)dy.$$

The $j$-step transition kernel is defined in (6.5). From this, we obtain our first ergodic theorem:

**Proposition 6.1** Suppose that the eigenvalues of $F$ lie in the open unit disk in $\mathbb{C}$, and that $N$ is i.i.d., with Gaussian marginal $N(0,\Sigma_N)$. Consider any factorization, $\Sigma_N = GG^\top$, with $G$ an $n \times m$ matrix for some $m \ge 1$, and suppose that the rank condition holds:

$$rank(C) = n, \text{ where } C = [G | FG | \dots | F^{n-1}G]. \quad (6.13)$$

Then the following conclusions hold:

- (i) The steady-state covariance $\Sigma_{X_\infty}$ has rank $n$, where

$$\Sigma_{X_\infty} = \lim_{j\to\infty} \sum_{k=0}^\infty (F^k)^\top \Sigma_N F^k.$$

- (ii) The density $p_k$ exists for $k \ge n$, and converges as $k \to \infty$:

$$\lim_{k\to\infty} p_k(x,y) = p_\infty(y) = \frac{1}{\sqrt{(2\pi)^n \det(\Sigma_{X_\infty})}} \exp(-\frac{1}{2}y^\top \Sigma_{X_\infty}^{-1} y).$$
