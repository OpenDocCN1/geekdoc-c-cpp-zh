$\Lambda^\theta(x,u) = \nabla_\theta \log^\Phi(u \mid \theta). \quad (10.38)$

In particular, we have

$\nabla_\theta c_\theta(x) = \sum_u \Phi^\theta(u \mid x) \Lambda^\theta(x,u)c(x,u), \quad (10.39)$

$\nabla_\theta P_\theta(x,x') = \sum_u \Phi^\theta(u \mid x) \Lambda^\theta(x,x'), \quad x,x' \in X, \theta \in \mathbb{R}^d$.

Perhaps fundamental is that $\Lambda^0$ is the score function for the transition matrix on $Z$:

$\Lambda^0(z,z') = \nabla_z T_\theta(z,z'), \quad z,z' \in Z. \quad (10.40)$

The reason that actor-critic methods appear here, right after TD(1)-learning for average cost, is that the sensitivity formula in Theorem 6.8 can be expressed in terms of the fixed-Q-function. Denote for any $\theta$,

$Q_\theta(x,u) \overset{\text{def}}{=} c(x) + P_\theta h_\theta(x) = c(x,u) + \sum_{x' \in X} P_\theta(x,x')h_\theta(x'), \quad x \in X, u \in U, \quad (10.41)$

where $h_\theta$ follows Poisson's equation, $P_\theta h_\theta = h_\theta + \Gamma(\theta)$.

**Theorem 10.16** *Under the assumptions of this section, for each $\theta \in \mathbb{R}^d$,*
$\Gamma(\theta) = E_{\Phi}[\Lambda^\theta(\Phi(k))Q_\theta(\Phi(k))]. \quad (10.42)$

$E[Q_\theta(\Phi(k+1)) \mid \Phi(k)] = \sum_{x'} \sum_{u'} P_\theta(x,x') \Phi^\theta(u \mid x') \{c(x',u) + P_\theta h_\theta(x')\}$
$= \sum_{x'} P_\theta(x,x') \{c_\theta(x') + P_\theta h_\theta(x')\}$
$= \sum_{x'} P_\theta(x,x')[b_\theta(x') + \Gamma(\theta)] = Q_\theta(x,u) - c(x,u) - \Gamma(\theta)$.

In matrix notation, this is $T_\theta Q_\theta = Q_\theta - c + \Gamma(\theta)$.

This combined with (10.40) and Theorem 6.8 completes the proof.

The theorem invites many questions:

- (i) How can this be used for optimization? Stochastic approximation is an option:
$\theta_{n+1} = \theta_n - \alpha_{n+1}\Gamma(\theta_n), \quad \hat{\Gamma}_n = \Lambda^\theta(\Phi(n))Q_{\theta_n}(\Phi(n))$.

This is a version of stochastic gradient descent (SGD). The $\Lambda^0$ is known, since we constructed our policy. The Q-function is not known, and a poor estimate would mean poor approximation of $\theta^0$.

- (ii) Even if $Q_\theta$ were known, the stochastic approximation algorithm is expected to have large variance. How can the variance be reduced?

The questions are addressed by one, and justify new conclusions and algorithms. Each algorithm requires two function classes: one to define the family of randomized policies $\{\phi : 0 \in \mathbb{R}^d\}$, and a second function class $\{\mathcal{H}^\theta : 0 \in \mathbb{R}^d\}$ to define the approximations for the Q functions. The following assumptions are imposed so the $L_2$ theory from this section will be:

### Actor-Critic Basis 
A linear parameterization for $\{\mathcal{H}^\theta : 0 \in \mathbb{R}^d\}$ is assumed, with fixed dimension $d'$. The basis functions may depend upon $\theta$, so that a generic function in $\mathcal{H}^\theta$ can be

$H_\theta^\omega = \omega^\top \psi_\theta, \quad \omega \in \mathbb{R}^d, \quad \theta \in \mathbb{R}^d. \quad (10.43)$

It is assumed that $\psi_\theta$ is continuously differentiable and Lipschitz continuous in $\theta$.

We will see shortly that $d' \geq d$ is usually desirable.

### Actor-Critic Algorithm

For initialization $\theta_0 \in \mathbb{R}^d$ and $\omega_0, \zeta_0 \in \mathbb{R}^d$,

$\theta_{n+1} = \theta_n - \alpha_n + \frac{1}{\sqrt{r(n)}}, \quad \tilde{R}(n) = \Lambda^{\theta_n}(\Phi(n))H^{\omega_n}_{\theta_n}(\Phi(n)), \quad (10.44a)$

$\Phi(n+1) \sim T_{\theta_n}(z, \cdot), \quad z = \Phi(n), \quad (10.44b)$

$\mathcal{D}_{n+1} = \{-H^{\omega_n}_{\theta_n}(\Phi(n)) + \tilde{C}_n + \mathbb{I}_{\{\Phi(n+1) \neq z'\}}H^{\omega_n}_{\theta_n}(z') \mid \theta = \theta_n\}$
$\omega_{n+1} = \omega_n + \beta_n \zeta_n$
$\zeta_{n+1} = \lambda \mathbb{I}_{\{\Phi(n+1) \neq z'\}}\zeta_n + \psi_{n+1}(\Phi(n+1))$
$\eta_{n+1} = \eta_n + \beta_n + \tilde{c}_n - \eta_n, \quad (10.44c)$

The set of equations in (10.44) is based on the TD(1) algorithm (10.28) (on setting $\lambda =1$). This version of TD(1) is favored because there is firmer stability compared to (10.32).

The algorithm has two step-sizes, satisfying:

$\sum_{n=1}^\infty \alpha_n = \infty, \quad \sum_{n=1}^\infty \beta_n = \infty, \quad \sum_{n=1}^\infty (\alpha_n^2 + \beta_n^2) < \infty.$

It is argued that the latter is much larger than the former, so it is possible for $H^{\omega_n}_{\theta_n}$ to track the estimate of fixed-policy Q-function $Q_\theta$ (associated with policy $\phi^*_\theta$).

The following would be expected from the theory of two-scale SA:

**Proposition 10.17** Suppose that $\lambda =1$ and step-size sequences satisfy assumption (8.22).

$\lim_{n\to\infty} \frac{\beta_n}{\alpha_n} = \infty.$

### Gather the Actors

Assume moreover that the parameter estimates are bounded, and the following consistency condition holds: For each $\theta \in \mathbb{R}^d$ there is a $w \in \mathbb{R}^d$ satisfying $\Lambda^w = Q_\theta$. (10.45)

Then, the ODE approximation of (10.44) is gradient descent $\dot{\theta} = -\Gamma(\theta)$. $\square$

The consistency assumption (10.45) is unrealistic outside the tabular setting. Removing this assumption is possible through an application of Theorem 10.14– details are provided in Section 10.6.

### 10.5.2 A Few Warnings and Remedies

It is time to say a few words about the randomization, which wasn't required in Sections 4.6 and 4.7. Randomization is required if we want to apply sensitivity theory for Markov chains, which brings in the source functions $S^\theta$ and $\Lambda^\theta$. In particular, there is no meaningful definition of $\Lambda^\theta$ for deterministic policies, such as the policy for the mountain car in Section 4.1.$^1$ In most applications, it is reasonable to abandon randomization in the final step of policy design: Once we have our parameter estimate $\theta \approx \theta^*$, construct a deterministic policy:

$\Phi^{\tilde{\theta}}(x) = \arg\max_u \tilde{\theta}(u|x), x \in X.$

We expect that $\tilde{\theta}$ will be nearly deterministic if it is optimal, in which case $\Phi^{\text{final}}$ is some slight perturbation of $\Phi$. The example that follows this point.

**Example 10.5.1 (The Best Parameter Is Probably $\infty$)** Consider an entirely ideal setting in $d=1$ and $\theta$ plays the role of "inverse temperature" in the Gibbs policy (9.66a):

$\Phi(u|x) = \frac{\exp(-\theta H(x,u))}{\kappa(x,\theta)}$

where $H: X \times X \to \mathbb{R}$, and $\kappa(x,\theta)$ is a normalizing constant. Suppose that we are fortunate that the optimal policy is possible from $H$:

$\Phi^*(x) = \arg\max_u H(x,u), x \in X.$

and that $\Phi^*$ is unique (only one policy optimal). Optimal conclusions follows:

- (i) $\Phi$ is not an optimal policy for any $\theta$, and (ii) $\lim_{\theta \to \infty} \Phi = \Phi^*$.

This example might seem contrived, but Gibbs policies will be featured in the coming sections, and we will see in Section 10.6 that there is good reason to include an approximation to the Q-function in a Gibbs policy.

The example suggests that a good algorithm must allow for $\theta_n$ to converge to $\infty$. It may not be practical, so instead introduce regularization: choose a convex regularizer.

$^1$ See [323] for alternative formulations of actor-critic methods for deterministic policies.

## 10.6 SGD without Bias

The ODE approximation in Proposition 10.17 can be obtained under assumptions weaker than (10.45).

A function class $\{\mathcal{H}^\theta: \theta \in \mathbb{R}^d\}$ of candidate approximations to the Q-functions is said to satisfy the compatible features property (CFP) if

$\Lambda_i^\theta = \theta \quad$ for each $\theta \in \mathbb{R}^d$ and $1 \le i \le d. \quad (10.47)$

**Proposition 10.18** Suppose that $\{\mathcal{H}^\theta : \theta \in \mathbb{R}^d\}$ satisfies the CFP (10.47). Given $\theta \in \mathbb{R}^d$, let $Q$ denote a solution to the minimum norm problem:

$\tilde{Q} = \arg\min ||H - Q_0\|_\theta^2 : H \in \mathcal{H}^\theta.$

Then,

$\Gamma(\theta) = E_{\theta}[\Lambda^\theta(\Phi(k))Q(\Phi(k))] = E_{\theta}[\Lambda^\theta(\Phi(k))\Phi(k))]. \quad (10.48)$

Proof $L_2$ locality is equivalent to the orthogonality property:

$0 = E_{\theta}[[Q(\Phi(k)) - \tilde{Q}(\Phi(k))]H(\Phi(k))], \quad$ for all $H \in \mathcal{H}^\theta.$

The identity (10.48) is obtained by setting $\theta = \Lambda^\theta$ for each $i$.

This assumption is not restrictive. In practice, we might start with a function class $\mathcal{H}^\theta$, and for each $\theta$ define

$\mathcal{H}^\theta = \{h = h^0 + \sum_{i=1}^d \omega_i\Lambda_i^\theta : h^0 \in \mathcal{H}^\theta, \omega \in \mathbb{R}^d\}. \quad (10.49)$
