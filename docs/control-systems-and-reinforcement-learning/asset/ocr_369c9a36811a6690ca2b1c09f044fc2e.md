```
$\theta_{n+1} = [I - \alpha_{n+1}A_n]^{-1}\{	heta_n - \alpha_{n+1}b_n\}.$
```

```
$\theta_{n+1} \approx [I + \alpha_{n+1}A_n]{\theta_n - \alpha_{n+1}b_n\} \approx \theta_n + \alpha_{n+1}\{A_n\theta_n - b_n\}.$
```
