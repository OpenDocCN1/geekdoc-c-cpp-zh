# 5.3.3 Recursive LSTD and Zap

LSTD learning is often presented as a recursive algorithm:

**Proposition 5.5** LSTD learning in the form (5.34) admits the recursive representation:

```
$$\theta_{N+1}^1 = \theta_N^1 + G_{N+1}Y_{N+1}^1[Y_N - \Y_{N+1}^1\theta_N], \quad (5.37a)$
```

```
$G_{N+1} = G_N - \frac{1}{k_{N+1}}G_N\Y_{N+1}^1\Y_{N+1}^1G_N, \quad N \geq 0 \quad (5.37b)$
```

with $k_{N+1} = 1 + \Y_{N+1}^1TG_N\Y_{N+1}^1$.

**Proof** The recursion is an application of Proposition 5.3: Letting $G_N = [W + NR_N]^{-1}$,nt proposition implies that for $N \geq 0$,

```
$$\theta_{N+1}^1 = (N+1)\psi_{N+1}^Y$\n$G_{N+1}^1 = G_N^1 + \Y_{N+1}^1\T_{N+1}^1.$
```

The recursion (5.37b) follows from the Matrix Inversion Lemma (A.1).
To obtain (5.37a), we use this recursion for $\psi_N^Y$, also implied by Proposition 5.3:

```
$$(N+1)\psi_{N+1}^Y = N\psi_N^Y + \Y_{N+1}Y_N.$
```

Consequently,

```
$$\G_{N+1}^1\theta_{N+1}^1 = (N+1)\psi_{N+1}^Y$\n= N\psi_N^Y + \Y_{N+1}Y_N$\n=G_N^1\theta_N^1 + \Y_{N+1}Y_N$\n=\{G_{N+1}^1 - \T_{N+1}^1\Y_{N+1}^1}\theta_N + \Y_{N+1}Y_N.$$$
```

Multiplying each side by $G_{N+1}$ and rearranging terms establishes (5.37a).

The algorithm (5.37) can be represented as a QSA recursion with matrix gain:

```
$$\theta_{N+1}^1 = \theta_N^1 + \alpha_{N+1}R_{N+1}[Y_N - \Y_{N+1}^1\theta_N]$
```
