
## 4 ODE Methods for Algorithm Design

For our purposes, an *algorithm* is a finite sequence of computer-implementable instructions, designed to compute or approximate a policy, its performance, a value function, or related quantities. In algorithm *design*, it is useful to throw away the constraints of computers, and pretend that they can operate with infinite clock speed. An ordinary differential equation (ODE) for which there is a far richer theory than stability of recursions in discrete time is regarded as an example of an algorithm operating on this imaginary computer.

The motivation comes from two sources. First, we want to know if our algorithm will eventually lead to a good approximation. This is easily caught in the theory of stability of ODEs. Second, once we have constructed an ODE with desirable properties, including stability, we can then get advice from experts to provide the translation from calculus to a practical recursive algorithm. In this chapter, the translation step is performed using an Euler approximation, but it is hoped that the reader will experiment with more efficient ODE solvers on an evolving theory of numerical methods [79].

Throughout the remainder of the book, we apply the following steps in algorithm design:

## ODE Method

- 1. Formulate the algorithmic goal as the root problem:
$$f(\theta) = 0, \quad \text{where } f: R^d \to R^d.$$
- 2. Refine the design of $f$, if necessary, to ensure that the associated ODE is globally asymptotically stable:
$$\frac{d\theta}{dt} = f(\theta).$$
- 3. Is an Euler approximation appropriate?
$$\theta_{n+1} = \theta_n + \alpha_n f(\theta_n), \quad n \ge 0.$$
See Section 4.1 for conditions under which (4.1b) is a good approximation.
- 4. Design an algorithm to approximate (4.1b) based on whatever observations are available.

## 4.1 Ordinary Differential Equations

Let's start with a question we should have probably posed earlier: *What is an ODE?* The question was taken for granted many times in the preceding pages. Up to now, the state space model in continuous time considered in Section 2.4.5 is the most significant example.

In this chapter, the "state variable" often represents the output of an algorithm rather than anything directly related to a control system. For this reason, throughout this chapter we use $\vartheta = \{\vartheta_t : t \geq 0\}$ to denote the state process for the ODE, and restrict to the Euclidean space: $\vartheta_t \in \mathbb{R}^d$ for an integer $d$. The state space (2.36) in this notation is:

$$\frac{d}{dt}\vartheta = f(\vartheta), \quad \vartheta_0 = 0, \quad (4.2)$$

where $f: \mathbb{R}^d \to \mathbb{R}^d$ is the vector field as in (2.3). Examples with $d = 1$:

$$f(\vartheta) = a\vartheta \text{ and } \vartheta_t = \vartheta_0e^{at}.$$
$$\vartheta_t = \vartheta_0(1 - e^{-at}).$$

The ODE (4.2) is called time homogeneous since $f$ does not depend on $t$. See Section 3.3 for hints on how to use state augmentation to create homogeneity for a model in which the vector field depends on $t$.

In every application of the ODE approach to design, the first step is to construct the vector field so that $\vartheta^* \in \mathbb{R}^d$. In particular, if $\vartheta_0 = \vartheta^*$, then the solution to the ODE should be: $\vartheta_t = \vartheta^*$ for all $t \geq 0$. This requires that $\dot{\vartheta_t} = 0$ which by (4.2) implies that $\vartheta^*$ is an equilibrium: $f(\vartheta^*) = 0$. Advanced material for stability theory for ODEs is contained in Section 4.8. This can be anticipated from the Lyapunov theory contained in Section 2.4.5.

Understanding the existence of solutions of (4.2) is the first step toward understanding ODE principles in design and in Part II of the book. Much like the Bellman equation (3.5) is regarded as a fixed point iteration, the ODE (4.2) is a fixed point in the variable $\vartheta = \{\vartheta_t : t \geq 0\}$. Perhaps we can mirror the success of the value iteration algorithm (3.8) (an instance of successive approximation?) Writing (4.2) as $\dot{\vartheta} = \frac{d}{dt}\vartheta = f(\vartheta)$, an analog to:

$$\vartheta_t^{n+1} = \vartheta_0 - \int_0^t f(\vartheta_\tau^n)d\tau, \quad t \geq 0, n \geq 0,$$

with $\vartheta^0 = \{\vartheta_t : t \geq 0\}$ given initial condition. Sorry to say, this approach is doomed to fail! One of the downside is the repeated definition in this recursion, which means we have to be very careful with our selection of $\vartheta^n$. Also, this recursion does not respect the requirement that the initial condition $\vartheta_0$ is specified.

The Fundamental Theorem of Calculus provides a more sensible approach. That is:

$$\vartheta_t = \vartheta_0 + \int_0^t f(\vartheta_\tau)d\tau, \quad 0 \leq t \leq T, \quad (4.3)$$

where the finite horizon $T$ is chosen for the sake of analysis. Successive approximation is defined as before: Take an initial guess $\vartheta^0 = \{\vartheta_t : 0 \leq t \leq T\}$, and define for $n \geq 0$:

$$\vartheta_t^{n+1} = \vartheta_0 + \int_0^t f(\vartheta_\tau^n)d\tau, \quad 0 \leq t \leq T. \quad (4.4)$$

This recursion is known as Picard iteration. It is successful under mild assumptions:

**Proposition 4.1.** Suppose that $f$ is Lipschitz continuous; then there is $L > 0$ such that for $x,y \in \mathbb{R}^d$:
$$\|f(x) - f(y)\| \leq L\|x - y\|. \quad (4.5)$$

Then for each $\vartheta_0$ there exists a unique solution to (4.3) on the infinite horizon. Moreover, successive approximation is uniformly convergent:
$$\lim_{n\to\infty} \max_{0\le t\le T} \|\vartheta_t^n - \vartheta_t\| = .$$

A key component of the proof of 4.1 is Gronwall’s Inequality, which commonly appears in the theory of stochastic approximation as well as ordinary differential equations. Note that Bellman had early influence, which is why Proposition 4.2 is often called the Bellman-Gronwall lemma.

**Proposition 4.2 (Gronwall Inequality).** Let $\alpha$, $\beta$ and $z$ be nonnegative functions defined on an interval $[0,T]$ with $T>0$. Assume that $\beta$ and $z$ are continuous, and the integral holds:
$$z_t \le \alpha_t + \int_0^t \beta_s ds, \quad 0 \le t \le T. \quad (4.6a)$$
- (1) The Gronwall Inequality holds:
$$z_t \le \alpha_t + \int_0^t \alpha_s \exp\left(\int_s^t \beta_r dr\right ds, \quad 0 \le t \le T. \quad (4.6b)$$
- (2) If, in addition, the function $\alpha$ is nondecreasing:
$$z_t \le \alpha_t \exp\left(\int_0^t \beta_s ds\right), \quad 0 \le t \le T. \quad (4.6c)$$

The proof can be found in Section 4.8, or if you have background in linear state models, you might want to work it out on your own. First: solve the problem with equality:
$$z_t = \alpha_t + \int_0^t \beta_s ds. \quad (4.7)$$

You can construct a state space model with $x_t = z_t - \alpha_t$, and because it is a linear system you obtain an explicit solution. The solution leads to something like (4.6b), but with equality. The following simple lemma is frequently required in ODE analysis:

**Lemma 4.3.** Suppose that $\{\gamma_t : t \in \mathbb{R}\}$ is a nonnegative function satisfying the following: (i) $|\gamma_t - \gamma_s| \le L|t-s|$ for a constant $L$ and all $t,s$ and (ii) $\int^\infty \gamma_t dt < \infty$. Then, $\lim_{t\to\infty} \gamma_t = 0$.

*Proof.* Assumption implies that for any $t_0$ we have the bound $\gamma_t \ge \gamma_{t_0} - L(t-t_0)$ for $t_0 \le t \le t_0+\gamma_{t_0}/L$. Combined with (ii), this gives:
$$\frac{1}{2L} \lim_{t_0\to\infty} \gamma_{t_0}^2 = \lim_{t_0\to\infty} \int_{t_0}^{t_0+\gamma_{t_0}/L} (\gamma_{t_0} - L(t-t_0)) dt \le \lim_{t_0\to\infty} \int_{t_0}^\infty \gamma_t dt = 0.$$

## 4.2 A Brief Return to Reality

This chapter considers ODE approaches to algorithm design: means design of the function $f$ appearing in (4.2), or design of the more exotic “quasistochastic” ODEs for which theory and applications are developed in Sections 4.5–4.7.

There is the inevitable translation step: any design formulated in continuous time must be translated to create a practical algorithm. If you have taken a first-year calculus course, you probably have predicted the most common approach: select a sequence of times $\{0=t_0<t_1<...\}$, and replace the derivative in (4.2) by a finite difference: With $\dot{d}_0=0$ given, for each $n \ge 0$,
$$\alpha_n^{-1} = |\dot{t}_{n+1} - \dot{t}_n| = f(\dot{t}_n),$$
where $\alpha_{n+1} = t_{n+1} - t_n - t > 0$. The recursive nature is evident when rearranging terms:
$$\dot{t}_{n+1} = \dot{t}_n + \alpha_n f(\dot{t}_n), \quad (4.8)$$

In our final approach, we simplify notation, $\theta_t = \dot{t}_n$, and $\{\alpha_n\}$ is known as step-size.
