# 8.7.3 Polyak–Ruppert Averaging

We conclude with an approximation of the error covariance obtained using PJR averaging,

denoted

```
$\bar{\Sigma}_{n_0}^{det} = E\{(\theta_n^0 - \theta^*)\{\theta_n^0 - \theta^*)^T\];
```

The goal is to justify the approximation $n_0\bar{\Sigma}_{n_0}^{det} \approx \Sigma_{\Delta}^*$, where $\\Sigma_{\Delta}^* \coltriangleq A^{-1}\Sigma_{\Delta}(A^{-1})^T$ denotes the optimal asymptotic covariance matrix.

The following little lemmas are our starting point.

+   **Lemma 8.11** The Polyak–Ruppert estimate can be expressed

```
$\theta_N^0 = \theta^* - \frac{1}{N-N_0}A^{-1}[M_N^0 - S_f^N + S_T^N + S_{\Delta}^N];$ (8.72)
```

where $A = A(\theta^*)$,

```
$M_N^0 = \sum_{n=N_0+1}^N f_{n+1}(\theta^0) = \sum_{n=N_0+1}^N \Delta_{n+1};$ (8.73a)
```

```
$S_f^N = \sum_{n=N_0+1}^N f_{n+1}(\theta_n^0);$ (8.73b)
```

```
$S_T^N = \sum_{n=N_0+1}^N E_f(\	heta_n^0);$ (8.73c)
```

```
$S_{\Delta}^N = \sum_{n=N_0+1}^N {\Delta_{n+1} - \Delta_{n+1}^{\infty}\};$ (8.73d)
```

with $E_f(\theta)$ defined as in (8.65), and as in (8.3b).

```
$$\Delta_{n+1} = f_{n+1}(\theta_n^0) - \bar{f}(\theta_n^0);$ (8.74)
```

*Proof* By the definitions.

```
$f_{n+1}(\theta_n^0) = \bar{f}(\theta_n^0) + \Delta_{n+1} = A[\theta_n^0 - \Delta_{n+1}^{\infty}] + E_f(\	heta_n^0) + {\Delta_{n+1} - \Delta_{n+1}^{\infty}\};$
```

The representation follows by multiplying each side of the equation by $A^{-1}$, summing over $n$, and rearranging terms.

Under general conditions, the first term (8.73a) dominates, and from this we obtain

