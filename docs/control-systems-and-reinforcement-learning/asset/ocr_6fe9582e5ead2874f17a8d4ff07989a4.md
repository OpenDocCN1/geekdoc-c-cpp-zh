# 9.1.1 Fixed-Policy Value Functions and DP Equations

Two value functions are of great interest in this chapter:

```
$h(x) = \sum_{k=0}^{\infty} \gamma^k E[c(\Phi(k)) \mid X(0) = x], \quad U(k) = \phi(\Phi(k)), k \geq 0$\n(9.6a)
```

```
$Q(x,u) = \sum_{k=0}^{\infty} \gamma^k E[c(\Phi(k)) \mid X(0) = x, U(0) = u], \quad U(k) = \phi(\Phi(k)), k \geq 1$.
(9.6b)
```

The latter is known as the fixed-policy Q-function. It facilitates a dynamic programming equation:

```
$h(x) = c_{\phi}(x) + \gamma \sum_{x'} P_{\phi}(x,x')h(x'), \quad Q(x,u) = c(x,u) + \gamma \sum_{x'} P_{\phi}(x,x')Q(x')$\n(9.7)
```

with $c_{\phi}(x) = c(x, \phi(x))$ and $Q(x) = Q(x, \phi(x))$ for $x \in X$ (recall 9.5a). The DP equation for $h$ has been used to approximate in (6.33).

The chapter starts off with methods to approximate $h$. In this case, it is convenient to suppress dependency of the transition matrix and the cost function on $\phi$. That, we say, we write $P$ instead of $P_{\phi}$, and $c$ instead of $c_{\phi}$. Under these conventions, the DP equation for $h$ in (9.7) becomes $h = c + \gamma P h$, with the probabilistic interpretation

```
$0 = E[-h(X(k)) + c(X(k)) + \gamma h(X(k+1)) \mid X(0), \dots, X(k)], \quad k \geq 0$.\n(9.8)
```

The fact that $h$ solves a linear fixed-point equation makes the function approximation problem far simpler than the nonlinear fixed-point equation (9.1). The biggest challenge is, how do we devise a learning algorithm that takes into account the conditional expectation appearing in (9.8)? Approaches to answer this question are surveyed in Section 9.2.

We answer this question: What do we do with a value function? The most common answer is the policy improvement step in the policy improvement algorithm (also called the policy iteration algorithm (PIA)). The definition isn't very different from the deterministic counterpart introduced in Section 3.2.2
