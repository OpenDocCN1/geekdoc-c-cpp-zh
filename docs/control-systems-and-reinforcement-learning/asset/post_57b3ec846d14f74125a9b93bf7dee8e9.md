
The discounted shortest path (SPP) is defined to be the minimal discounted cost incurred before this time:

```
$J^*(x) = \min_{k=0}^{\tau_A-1} \gamma^k c(x(k),u(k)), \quad x(0) = x. \quad (3.22)$
```

**Proposition 3.6** If $J^*$ is finite valued, then it is the solution to the DP equation:

```
$J^*(x) = \min \{c(x,u) + \gamma^1(F(x,u) \in A^c)\}, \quad x \in X. \quad (3.23)$
```

*Proof* As in the total cost problem

```
$J^*(x) = \min \{c(x,u(0)) + \sum_{k=1}^{\tau_A-1} \gamma^k c(x(k),u(k))\},$
```

with the understanding that $\sum_{k=1}^{\tau_A-1} 0=0$: The upper limit is equal to 0 when $\tau_A=1$ (equivalently, $x(1) \in A$). Consequently,

```
$J^*(x) = \min_{u(0)} \{c(x,u(0)) + \gamma^1\{x(1) \in A^c\} \min_{u_{[1,\infty))}} \sum_{k=1}^{\tau_A-1} \gamma^{k-1} c(x(k),u(k))\}\n= \min_{u(0)} \{c(x,u(0)) + \gamma^1\{x(1) \in A^c\} J^*(x^*(1))\}, \quad x(1) = F(x,u(0))\n= \min \{c(x,u) + \gamma^1\{F(x,u) \in A^c\} J^*(F(x,u))\}$
```

For the purposes of using the control techniques, it is possible to recast (3.22) as an instance of the total cost problem (3.21). This requires the definition of a new state $x^a$ with dynamics $F^a$, and a new cost $c^a$ defined as:

- (i) Modified state dynamics: $F^a(x,u) = \begin{cases} F(x,u) & x \in A^c \\ x & x \in A \end{cases}$

so that $x^a(k+1) = x^a(k)$ if $x^a(k) \in A$ (a called guardset for the control system).

- (ii) Modified cost: $c^a(x,u) = \begin{cases} c(x,u) & x \in A^c \\ 0 & x \in A \end{cases}$

From these definitions, it follows that the value function (3.22) can be expressed as as:

```
$J^*(x) = \min_{k=0}^{\infty} \gamma^k c^a(x^a(k),u(k)), \quad x \in A^c.$
```

### 3.3.1 (Mountain Car) Recall the Mountain Car example is a shortest path problem: to reach the goal in minimal time. ### 3.3.3 Finite Horizon

Your choice of discount factor is based on concerned with the distant future. Motivation is similar for horizon formulation: Fix a horizon $\mathcal{N} \ge 1$, and denote

$J^*(x) = \min_{k=0}^{\mathcal{N}} c(x(k), u(k)), \quad x(0) = x \in X.$

This can be interpreted as the total-cost problem (3.2), following two modifications of the state description and the cost function, similar to SPP:

- Enlarge the state process to $x^*(k) = (x(k), \tau))$, where the second component is "time" plus: $\tau(k) = \tau(0) + k, \quad k \ge 0$.

- Extend the definition of the cost function as follows:

$c^N((x, \tau), u) = \begin{cases} c(x, u) & \tau \le \mathcal{N} \\ 0 & \tau > \mathcal{N} \end{cases}$

That is, $c^N((x, \tau), u) = c(x, u)\{\tau \le \mathcal{N}\}$ for all $x, \tau, u$.

If these definitions are clear, then you understand that we have succeeded in transformation:

$J^*(x) = \min_{k=0} c^a(x^*(k), u(k)), \quad x^a(0) = (x, \tau), \quad \tau = 0.$

However, to write the Bellman equation is necessary to consider all values of $\tau$ (at least $\tau \le \mathcal{N}$), and not just the desired value $\tau=0$. Letting $J^*(x, \tau)$ denote the right-hand side of (3.25) for arbitrary values of $\tau \ge 0$, the Bellman equation becomes

$J^*(x, \tau) = \min\{c(x, u)\{\tau \le \mathcal{N}\} + J^*(F(x, u), \tau + 1)\}.$

The similarity with (3.8) is clear. Based on (3.25) and the definition of $c^\alpha$, we know that $J^*(x, \tau) = 0$ for $\tau > \mathcal{N}$. This is considered a boundary condition for recursion (3.26), which is put to work as follows: First, $J^*(x, \mathcal{N}+1) = 0$,

```
$J^*(x, \mathcal{N}) = \min_{u} c(x, u).$
```

Applying (3.26) once gives

$J^*(x, N-1) = \min_{u} \{c(x, u) + J^*(F(x, u))\}$.

These steps can be repeated until the finite horizon value function $J^*(\cdot, 0)$. What about the policy? It is again obtained via recursion (3.26), but the optimal policy depends on the extended state:

```
$\Phi^*(x, \tau) = \arg\min_u \{c(x, u) + J^*(F(x, u), \tau+1)\}, \quad \tau \le \mathcal{N}.$
```

This means that the feedback is no longer homogeneous:

$u^*(k) = \Phi^*(x^*(k), k).$

### 3.3.4 Model Predictive Control

An extremely successful technique in many fields (such as in manufacturing and building operations) is model predictive control (MPC). It is a slight variant of (3.28) to obtain a stationary policy:

```
$u(k) = \Phi^{MPC}(x^*(k)) = \Phi^*(x(k),0), \quad (3.29)$
```

where the right-hand side is defined in (3.27) using $\tau=0$. However, MPC is never presented as state feedback because policy $\Phi^{MPC}$ is not computed and stored in memory. Rather, for each $k$, when the state $x=x(k)$ is observed, the finite horizon optimization is performed to obtain the value $u(k) = \Phi^*(x,0)$. That is, the policy is evaluated for those states observed.

Nevertheless, the general optimal control theory provides techniques to ensure that the total cost associated with (3.29) is finite. Denote for $x \in X$,

```
$J^{MPC}(x) = \sum_{k=0}^{\infty} c(x(k),u(k)),
```

subject to $x(0)=x$, and $u(k) = \Phi^{MPC}(x(k))$ for all $k$.

**Proposition 3** The optimal policy (3.29), modified with objective:

```
$J^*(x;0) = \min_{u \in [0,\mathcal{N}]} \{c(x(k),u(k)) + V^0(x(\mathcal{N}))\}, \quad x(0)=x \in X, \quad (3.30)$
```

where $V^0: X \to \mathbb{R}$ satisfies (3.11) with $\bar{\eta}=0$,

```
$\min_u \{c(x,u) + V^0(F(x,u))\} \le V^0(x), \quad x \in X.$
```

The total cost $J^{MPC}$ is everywhere finite.

### 3.4 Inverse Dynamic Programming

An alternative to dynamic programming is to change the problem: In optimal control, we are given $c$, and face the (often daunting) task of computing $J^*$. Here we reverse the computational task: Given any function $J$, find a cost function $c^J$ that satisfies (3.5). To proceed in a way that respects our original goal, we consider the Bellman error:

```
$B(x) = J(x) - \min_u[c(x,u) + J(F(x,u))].\quad (3.31)$
```

This is precisely the error in Bellman equation (3.5). Based on this, we obtain a solution to a Bellman equation, with a modified cost:

```
$J(x) = \min_u[c^J(x,u) + J(F(x,u))].\quad (3.32a)$
```

```
$c^J(x) = c(x,u) - B(x).\quad (3.32b)$
```

The minimizer in (3.32a) defines a policy, denoted $\Phi^J$:

```
$\Phi^J(x) = \arg\min_u[c(x,u) + J(F(x,u))] = \arg\min_u[c(x,u) + J(F(x,u))].\quad (3.33)$
```

This procedure is known as inverse dynamic programming (IDP). It is one formulation of the control-Lyapunov function approach to control design. Minimizing the Bellman error is a goal of many approaches to reinforcement learning. Motivation is provided in the following:

**Proposition 3** Suppose that the following holds:

- (i) $J$ is nonnegative, continuous, and vanishes only at $x^c$.
- (ii) The function $c^J(x) = c(x,\Phi^J(x))$ satisfies the following: It is nonnegative, continuous, inf-compact, and vanishes only at $x^c$.
- (iii) There is a constant $g$ satisfying $0 \leq g < 1$, and

```
$$B(x) = c(x,u) - c^J(x,u) \geq -gc(x,u)\quad$ for all $x,u.$
```

Let $J^{\infty}$ denote the value function under the policy $\Phi^J$:

```
$$J^{\infty}(x) = \sum_{k=0}^{\infty} c(x(k),u(k)),\quad x(0)=x, u(k)=\Phi^J(k)$ for all $k.\\quad (3.34)$$
```

This admits a pair of bounds:

```
$$J^* \leq J^{\infty} \leq (1+g)J^*$$
```
