# 4.5 Quasistochastic Approximation

However, please be warned: the conclusions that follow are highly sensitive to the precise modeling assumption (4.86). Consider the minor variant, using

```
$f(\theta, z) = |A_0 + \varepsilon A_1|\theta, \quad \theta \in \mathbb{R}^d, \quad z \in \mathbb{R}. \qquad (4.88)$
```

Stability of the constant gain algorithm is characterized in [36] for this and more general linear systems with multiplicative "quasisturburbance". The characterizations have resemblance to ours in this book - in particular, the average vector field $\hat{	heta}=A_0\theta$ is often useless for stability analysis. See Exercise 4.18 for a short tour of this theory.

Convergence theory for vanishing gain algorithms is more intuitive, even when subject to multiplicative disturbances as in (4.88).

Analysis for the linear model (4.86) is simplified since QSA is a time-invariant linear system

```
$\dot{\hat{	heta}}_t = \alpha[\hat{	heta}_t + B\varepsilon_t],$
```

where $\hat{	heta}_t \coloneqq{\text{def}} \theta_t - \theta'$ is the error at time $t$. We can solve this ODE where the probing signal is the mixture of sinusoids (4.46b), whose derivation is simplified by applying the principle of super-position. To put this to work, we restrict to the probing signal (4.46b), and for each $i$, consider the ODE

```
$\dot{\hat{	heta}}_t^i = \alpha[\hat{	heta}_t + v^i\sin(2\pi(\omega_it + \phi_i))]), \quad \dot{\hat{	heta}}_i = 0.$
```

The principle states that to solve this ODE can be represented as the sum

```
$\tilde{	heta}_t = e^{\alpha A^t}\tilde{	heta}_0 + B \sum_{i=1}^K \tilde{	heta}_i. \qquad (4.89)$
```

The response to the initial error $\tilde{	heta}_0 = \theta_0 - \theta'$ decays to zero exponentially quickly. Consequently, to understand the steady-state behavior of the algorithm, it suffices to fix a single value of $i$.

For more complex probing we can again justify consideration of sinusoids, Let's keep things simple, and stick to sinusoids. And it is much easier to work with complex exponentials:

```
$\dot{\hat{	heta}}_t = \alpha[\hat{	heta}_t + v\exp(j\omega t)], \quad \dot{\hat{	heta}}_0 = 0,$
```

with $\omega \in \mathbb{R}$ and $v \in \mathbb{R}^d$ (dropping the scaling $2\pi$ and the phase $\phi$ for simplicity). We can express the solution as a convolution

```
$\hat{	heta}_t = \alpha \int_0^t \exp(\alpha Ar)v\exp(j\omega(t-r))dr\n\= \alpha \int_0^t \exp([\alpha A - j\omega I]r)v\exp(j\omega t)$
```

Writing $D = [\alpha A - j\omega I]$, the integral of the matrix exponential is expressed:

```
$\int_0^t e^{Dr}dr = D^{-1}[e^{Dt}-I].$
```
