Stochastic Control

Once again, we are not interested in estimating $	heta_u$ if $ar{r}_u < ar{r}^*$, but we don't know in advance which arms are suboptimal in this sense.

The frequentist will consider alternative representations of the regret (7.55). The following is most valuable in obtaining sharp bounds:

```
$E[L_{\mathcal{N}}] = \mathcal{N} \sum_{u} E[\{ar{r}^* - \bar{r}_u\tilde{\mu}_{\mathcal{N}}(u)\}],$
```

in which $	ilde{\mu}_{\mathcal{N}}(u)$ is the empirical perf:

```
$\tilde{\mu}_{\mathcal{N}}(u) = \frac{1}{\mathcal{N}}n_u(\mathcal{N}) = \frac{1}{\mathcal{N}}\sum_{k=1}^{\mathcal{N}}1\{U(k)=u\}, \quad u \in U. (7.62)
```

The goal of optimal control is to steer the empirical perf so that $\{\bar{r}^* - \bar{r}_u\tilde{\mu}_{\mathcal{N}}(u)\} \approx 0$ for each $u$.

To avoid avoiding techniques, we may represent the

```
$L_{\mathcal{N}} = \sum_{u}\{{\bar{r}^* - \bar{r}_u\}n_u(\mathcal{N}),\ (7.63)
```

in which "reward estimates" are defined by

```
$\tilde{r}_u(k) = \frac{1}{n_u(k)}\sum_{j=1}^k1\{U(j)=u\}Z_j(j).
```

The certainty equivalent policy $U(k+1) = \arg\max_{u,\bar{r}_u(k)$ is again doomed to failure. However, small tweaks result in a very good policy.

The idea is to define recursively a sequence of positive scalars $\varrho_u(k) : k \ge 1, 1 \le u \le K\}$, denote

```
$UCB_u(k) = \bar{r}_u(k) + \varrho_u(k)$
```

and ensure that the policy is designed so that these values serve as *upper confidence bounds* in the sense that

```
$\lim_{k\to\infty}P\{UCB_u(k) > \bar{r}_u\\} = 1. (7.64)
```

One version of the UCB algorithm is the most optimistic rule:

```
$U(k+1) \in \arg\max_i UCB_i(k), \quad 0 \le k \le N-1, (7.65)
```

using $\varrho_u(k) = b_u\sqrt{\log(k)}/[1+n_u(k)], \quad 1 \le u \le K$,

$\{b_u\}$ are positive constants chosen by the user. Regardless of their values, the decision (7.65) ensures $n_u(k) \to \infty$ as $\infty$ for each $u$, and results in logarithmic regret under mild assumptions [216].
