```
$$\|partial_\varepsilon^t - v\| \ll \varepsilon \quad \text{for all } v \ge \mathcal{T}_\varepsilon, \quad \text{whenever } \|\partial_\varepsilon^t\| \le b.$
```

Proposition 4.28

