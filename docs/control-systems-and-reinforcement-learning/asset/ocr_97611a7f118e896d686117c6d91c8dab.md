**Lemma 20.** $E_\gamma$ for any $\gamma \in [0,1]$ and function $H: X 	imes U 	o \mathbb{R}$,

+   (i) $E_\gamma[[-H(\Phi(n)) + \gamma\mathbb{1}\{\Phi(n+1) 
eq z^*\}H(\Phi(n+1))\zeta_n]\} = -E_\gamma[H(\Phi(n))\psi(\Phi(n))]$.
(ii) $E_\gamma[[-H(\Phi(n)) + H(\Phi(n+1))\zeta_n]\} = E_\gamma\{[-H(\Phi(n)) + \gamma^*z^*]\psi(\Phi(n))\}$.

*Proof* of the theorem is obtained as a corollary to the previous lemma, using

```
$g(z) = -H(z) + E_\gamma[\mathbb{1}\{\Phi(n+1) \neq z^*\}H(\Phi(n+1)) \mid \Phi(n) = z],$
```

so by this property,
E_\gamma[[-H(\Phi(n)) + \mathbb{1}\{\Phi(n+1) \neq z^*\}H(\Phi(n+1))\zeta_n]\} = E_\gamma[g(\Phi(n))\zeta_n].$.

It remains to prove that $E_\gamma[g(\Phi(n))\zeta_n] = -E_\gamma[H(\Phi(n))\psi(\Phi(n))]$.
Lemma 10.23 gives

```
$E_\gamma[g(\Phi(n))\zeta_n] = E_\gamma[g(\Phi(0))\zeta_0] = \n= E_\gamma[\psi(\Phi(0)) \sum_{k=0}^{\tau-1} \gamma^k g(\Phi(k))]\n= \sum_{k=0}^{\infty} \gamma^k E_\gamma[\psi(\Phi(0))g(\Phi(k))\mathbb{1}\{k < \tau_*\\}].
```

The smoothing property of the conditional expectation provides a useful representation for each expectation:

```
$E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\}g(\Phi(k))] =\n= E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\} \{-H(\Phi(k)) + E_\gamma[\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1)) \mid \mathcal{F}_k]\}]\n= E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\} \{-H(\Phi(k)) + \gamma\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))\\}].
```

so that on,

```
$E_\gamma[g(\Phi(n))\zeta_n] =\sum_{k=0}^{\infty} \gamma^k E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\}]\n+ \sum_{k=0}^{\infty} \gamma^k E_\gamma[\psi(\Phi(0))\mathbb{1}\{k < \tau_*\} \{\gamma\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))\\}]\n= -E_\gamma[\psi(\Phi(0)) \sum_{k=0}^{\tau-1} \gamma^{k+1}\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))].\n- \psi(\Phi(n)) \sum_{k=0}^{\tau-1} \gamma^{k+1}\mathbb{1}\{\Phi(k+1) \neq z^*\}H(\Phi(k+1))].
```

The difference of sums reduces to $\psi(\Phi(n))H(\Phi(0))$ (all other terms cancel), giving (i).
The proof of (ii) is the same, except that all two terms cancel.
