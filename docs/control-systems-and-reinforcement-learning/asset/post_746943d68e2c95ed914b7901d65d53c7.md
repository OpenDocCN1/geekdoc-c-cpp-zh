## 8.3.2 Stochastic Gradient Descent

Assuming the minimization problem $\theta^* = \arg \min_{\theta} \Gamma(\theta)$, with $\Gamma(\theta) = E[\tilde{\Gamma}(\theta, \Phi)]$, $\theta \in \mathbb{R}^d$. The gradient descent ODE is defined by

```
$\dot{\theta} = -\nabla\Gamma(\theta).$ (8.38)
```

An approximation of gradient descent can be realized with

```
$$\tilde{\theta} = -\nabla E[\tilde{\Gamma}(\theta, \Phi)] = -E[\nabla\tilde{\Gamma}(\theta, \Phi)].$$
```

The exchange of derivative and expectation can be justified under mild conditions. Suppose we are given samples $\Phi = \{\Phi_n, n \geq 1\}$ for which the distribution of $\Phi_n$ converges to $\Phi$, as $n \to \infty$, and denote $\Gamma_n(\theta) = \tilde{\Gamma}(\theta, \Phi_n)$ for any $n$ and $\theta$. The basic algorithm (8.2) results in stochastic gradient descent (SGD):

```
$$\theta_{n+1} = \theta_n - \alpha_n\nabla\Gamma_{n+1}(\theta_n).$ (8.39)
```

### Stability of the Algorithm

Provided $\Gamma$ is strongly convex (recall 4.22), Proposition 4.7 tells us that the flow (8.38) is exponentially asymptotically stable. In the proof, it is shown that $V(\theta) = \frac{1}{2}|\theta - \theta^*\|^2$ serves as a Lyapunov function.

```
$$\dot{V}(\theta_t) \leq -2\delta_0V(\theta_t) \leq -\delta_0|\theta - \theta^*\|^2\exp(-\delta_0t).$ (8.40)
```

Consequently, the bound (8.33) holds with $\beta_0=1$ and $\alpha_0=\delta_0$. Conditions for exponential asymptotic stability without convexity can be obtained from Theorem 4.9.

What about the stability of the SA algorithm? A sufficient condition is based on the ODE@$\infty$, just as in the deterministic case of Section 4.4.4: Define for $\theta \in \mathbb{R}^d$

```
$$\Gamma^{\infty}(\theta) = \lim_{r\to\infty}\frac{1}{r}\Gamma(r\theta), \quad\nabla\Gamma^{\infty}(\theta) = \lim_{r\to\infty}\frac{1}{r}\nabla\Gamma(r\theta).$$
```

Assuming these functions are finite valued, it that the first is radially quadratic, and the second is radially linear,

```
$$\Gamma^{\infty}(s\theta) = s^2\Gamma^{\infty}(\theta), \quad\nabla\Gamma^{\infty}(s\theta) = s\nabla\Gamma^{\infty}(\theta), \quad s > 0.$$
```

If $\Gamma$ is strongly convex, (4.25) implies the lower bounds:

```
$$\theta^T\nabla\Gamma^{\infty}(\theta) \geq \delta_0||\theta||^2, \quad\Gamma^{\infty}(\theta) \geq \frac{1}{2}\delta_0||\theta||^2.$$
```

## 8.3 Examples

The first bound follows directly from (4.25) and the definition of $\nabla\Gamma^{\infty}$. The second bound follows from the first and the following:

**Lemma 8.6** If $\Gamma^{\infty}$ is continuously differentiable, then $\Gamma^{\infty}(\theta) = \frac{1}{2}\theta^{\top}\nabla\Gamma^{\infty}(\theta)$, $\theta \in \mathbb{R}^d$.

*Proof* Differentiability justifies the chain rule in following:

```
$\Gamma^{\infty}(\theta) = \int_{0}^{1} \frac{d}{dt}\Gamma^{\infty}(t\theta) dt = \int_{0}^{1} \theta^{\top}\nabla\Gamma^{\infty}(t\theta) dt.$
```

The equality follows the fundamental theorem of calculus, and the identity $\Gamma^{\infty}(0) = 0$. The ODE^{\infty}$ is defined by $\frac{d\theta}{dt} = -\nabla\Gamma^{\infty}(\theta)$. Convergence from stability of ODEs:

- (i) If $\Gamma^{\infty}$ is continuous, and $\Gamma^{\infty}(\theta) > 0$ for $\theta \neq 0$, the ODE^{\infty}$ is globally asymptotically stable. Theory in Section 8.7 implies that the sequence of estimates from SA algorithm (8.39) are bounded:
```
$\sup ||\theta_n|| < \infty \quad a.s.$
```
- (ii) If the assumptions of (i) hold, and in addition the ODE is globally asymptotically stable, then the estimates converge to the unique root $\Gamma(\theta^*) = 0$.

The asymptotic convergence in (8.6), or any of its variants, can be expressed in terms of the linearization matrix $A$. For this class of algorithms, it is symmetric to represent with matrix:

```
$$A_{i,j}(\theta) = \frac{\partial^2}{\partial\theta_i\partial\theta_j}\Gamma(\theta).\quad (8.41)$$
```

Variance ensures that $A(\theta^*)$ is Hurwitz (8.2a and 8.2b), in which this case means that the Hessian of $\Gamma$ is positive definite at the optimizer: $-A(\theta^*) = \nabla^2\Gamma(\theta^*) > 0$.

### Tension between Asymptotic and Transient Performance

Let's consider a case where tension is not: $\Gamma$ is quadratic, with $\Gamma(\theta) = \frac{1}{2}(\theta-\theta^*)^{\top}G(\theta-\theta^*)$, and $G>0$ (positive definite). This is strongly convex, with $\delta_0 = \lambda_1$, the minimum eigenvalue of $G$. Consider the step-size $\alpha_n = g/n$:

- **Transient bounds:** The right-hand side of bound (8.34) will decay as $1/n$ when using step-size $\alpha_n = g/n$ and $g=1/\lambda_1$.
- **Asymptotic convergence:** The linearization matrix used to compute asymptotic variance is $A=G$. The gain $g=1/\lambda_1$ will result in finite variance since all eigenvalues of $gA$ satisfy $\lambda(gA) < -1/2$.
- **ODE fidelity for small n:** We require $n_0 \gg n$ to avoid transients for small $n$ (or employ restart to keep the parameters within a predefined region).

Theory surrounding $G$ motivates the use of $\alpha_n = g/n$ with a smaller value of $g$ (say, $g=\alpha$ if a good choice is available), $<1$. This approach requires less 'tinkering' with parameters. It is true that we are left with $\theta, g$, and $N_0$ to obtain the final estimate $\hat{\theta}_{N_0}$ via (8.10b). Theory and practice suggest that sensitivity to $\rho \leq 0.9$ and $g$ is not high, and $N_0$ should be clear after observing sample paths from various initial conditions. Or, we might give up SA entirely. An alternative to SGD is considered next.

## 8.3 Empirical Risk Minimization

Recall from Section 5.1 brief survey of empirical risk minimization (ERM). This approach can be applied here, with the empirical risk equal to the empirical mean:

```
$$\Gamma_N(\theta) = \frac{1}{N} \sum_{i=1}^N \Gamma_i(\theta).\quad (8.42)$$
```

Application of ERM means that we favor a recursive algorithm, and minimize to obtain $\hat{\theta}_N^M$. This approach has become popular in recent years for optimization in high dimensions.

For sake illustration, consider the special case of quadratic loss $\Gamma_i(\theta) = \frac{1}{2}\|M_i\theta-\xi_i\|^2$, in which the matrix $M_i$ and vector $\xi_i$ are random. We then define $\Gamma_i(\theta) = M_i^T(M_i\theta-\xi_i)$, so the SA algorithm is defined by

```
$$\theta_{n+1} = \theta_n - \alpha_n M_{n+1}^T(M_{n+1}\theta_n - \xi_{n+1})\quad (8.43)$$
```

The ERM solution can be obtained in closed form, by applying the first-order condition for optimality $\bar{\Gamma}_N(\theta) = 0$, where

```
$$\bar{\Gamma}_N(\theta) = \frac{1}{N} \sum_{i=1}^N M_i^T(M_i\theta - \xi_i)$$
```

Conversely, the existence proved

```
$$\hat{\theta}_N^M = (\sum_{i=1}^N M_i^T M_i)^{-1} \sum_{i=1}^N M_i^T \xi_i.\quad (8.44)$$
```

Proposition 8.8 shows that $\hat{\theta}_N^M$ coincides with a particular SA algorithm using a carefully constructed matrix gain:

```
$$\theta_{n+1} = \theta_n - \alpha_n G_{n+1} M_{n+1}^T(M_{n+1}\theta_n - \xi_{n+1})\quad (8.45)$$
```

in which

```
$$G_{n+1} = \frac{1}{n+1} \sum_{i=1}^n M_i^T M_i, \quad n \geq 0.$$
```
