# TD($\lambda$) Algorithm (Off-Policy for $Q$)

For initialization $	heta_0, \zeta_0 \in \mathbb{R}$, the sequence of estimates are defined recursively:

```
$$\theta_{n+1} = \theta_n + \alpha_n \zeta_n D_n + 1$,$
$\mathcal{D}_{n+1} = (-H^0(\Phi(n)) + c_n + \gamma H^0(X(n+1)))|_{\det=\theta_n}, \quad (9.53)$
```

```
$$\zeta_{n+1} = \lambda \gamma \zeta_n + \psi(n+1), \quad \psi(n+1)} = \psi(\Phi(n+1)), \quad c_n^{\det} = c(\Phi(n))$
```

A critical difference is to determine: Obtain form of the temporal difference: To obtain $\mathcal{D}_{n+1}$, it is necessary to compute

```
$$\mathcal{H}^0(X(n+1)) = (\sum_{u} Q(u,x)\Phi(u|x))|_{x=X(n+1)}. \quad (9.54)$
```

If this is too complex, an alternative is split sampling (recall 6.47):

```
$$\mathcal{D}_{n+1} = (-H^0(\Phi(n)) + c_n + \gamma H^0(X(n+1), U_{n+1}))|_{\det=\theta_n}, \quad (9.55)$
```

in which $U_{n+1}$ is a random variable that can be independent of $\mathcal{F}_{n+1}$ given $X(n)$, with conditional deif as

```
$$\P\{U_{n+1}=u|\mathcal{F}_{n+1}\} = \Phi(u|x') \quad when x'=X(n+1)$.
```

The update equation is unchanged: $\theta_{n+1} = \theta_n + \alpha_n \zeta_n \mathcal{D}_{n+1}$. For convergence using (9.55) is unchanged, but the algorithm will have higher variance (the covariance $\\Sigma_{\Delta}$ appearing in Section 8.2.5 will be larger.

The geometry behind the proof of Theorem 7.9 breaks down in the off-policy setting. The off-policy algorithm intends to solve

```
$0 = \mathbb{E}[(-H^0(\Phi(n)) + c_n + \gamma H^0(X(n+1), U'_{n+1}))\zeta_n],$
```

which can be expressed as the linear equation $A\theta = b$ with

```
$A = \mathbb{E}[\zeta_n(-\psi(\Phi(n)) + \gamma^0 \psi(X(n+1))], \quad b = -\mathbb{E}[c_n\zeta_n], \quad \overline{x} = \sum_{u} \psi(x,u)\Phi(u|x)$.
```

We don't even know if $A$ is invertible, so the linear equation may have solution. The result gives us some hope. The proposition locks the entire range of $\gamma \in [0,1]$. We will write $A_{\gamma}$ to emphasize the dependence.

# **Proposition 9.12** Suppose that the linear independence condition (9.24) holds then we have the following:

+   (i) For $\lambda = 0$, the matrix $A_{\gamma}$ is invertible for at most $d$ values of $\gamma \in [0,1]$.
(ii) For each $\lambda \in (0,1)$, the matrix $A_{\gamma}$ is invertible for all but a finite number of values of $\gamma \in [0,1]$.

+   (iii) The matrix $A_{\gamma}$, with $\lambda = 1$ is invertible for all but a finite number of values of $\gamma \in [0, 1-\delta]$ for $\delta > 0$.

Proposition 9.12 does not claim that the matrix $A_{\gamma}$ is Hurwitz, so stability of off-policy TD($\lambda$) is not resolved. In the off-policy setting since it is highly likely that $A_{\gamma}$ is full rank.
