**Proposition 2.4** Suppose that (2.33) holds, along with the following assumptions:

+   (i) $J$ is continuous, inf-compact, and vanishes only at $x^\sigma$.
(ii) $J^\sigma$ is continuous.

Then, $J(x) = J^\sigma(x) - J^\sigma(x^\sigma)$ for each $x$.

# 2.4.4 Technical Proofs

To establish Propositions 2.3 and 2.4, we first require Lemma 2.1.

*Proof of Lemma 2.1* We begin with the sample path representation of (2.25):

```
$J(x(k+1)) - J(x(k)) + c(x(k)) = 0. \quad (2.34)
```

Summing each side from $k=0$ to $N-1$ gives for each $x=x(0)$, and each $N$,

```
$J(N) = J(x(N)) + \sum_{k=0}^{N-1} c(x(k)).
```

On taking limits, we obtain

```
$J(x) = \lim_{N\to\infty} \{J(x(N)) + \sum_{k=0}^{N-1} c(x(k))\} = \lim_{N\to\infty} J(x(N)) + J(x),
```

which implies (i) under the assumption that $J(x)$ is finite.
The inf-compact assumption in (ii) is imposed to ensure that the state trajectory evolves in a bounded set: (2.30) implies that $x(k) \in S_J(r)$ for the particular value $r=J(0)$, and each $k \ge 0$. Suppose that $\{x_i; i \ge 0\}$ is a convergent subsequence of the state trajectory, with limit $x^\infty$. Then $J(x^\infty) = \lim_{k\to\infty} J(x(k))$ by continuity of $J$.

The assumption that $J$ vanishes only at $x^\sigma$ implies that $x^\infty = x^\sigma$. Part (ii) follows, because every convergent subsequence reaches the same value $x^\sigma$.

*Proof of Proposition 2.3* The bound (2.32) is established by the previous proceeding-the proposition. We begin with the sample path representation of (2.31), similar to (2.34):

```
$V(k+1)) - V(x(k)) + c(x(k)) \le \overline{\eta}. \quad (2.35)
```

Summing each side from $k=0$ to $N-1$ gives (1):

```
$V(N)) - V(x(0)) + \sum_{k=0}^{N-1} c(x(k)) \le \overline{\eta}N$.
```

(ii) follows since $V(x(N)) \ge 0$ for each $N$, so that when $\overline{\eta} = 0$ we obtain from the preceding bound

```
$\sum_{k=0}^{N-1} c(x(k)) \le V(x(0)).$
```

The proof of (iii) is identical to Lemma 2.1: part (ii) implies that $\lim_{k\to\infty} c(x(k)) = 0$, and the assumptions on $c$ then imply that $x(k) \to x^\sigma$ as $k \to \infty$.
