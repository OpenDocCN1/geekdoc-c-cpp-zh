# **Proposition 9.17** for Watkins's algorithm. (9.80).

+   (i) The function $V(\theta) = ||\theta||\infty$ is a Lyapunov function for the ODE with vector field:

```
$$\frac{d}{dt}V(\theta_t) \le -(1-\gamma)V(\theta_t)$.$
```

+   (ii) The function $V_{\infty}(	heta) = ||\theta||\infty$ is a Lyapunov function for the ODE@\infty$:

```
$$\frac{d}{dt}V_{\infty}(\partial_t^+) \le -(1-\gamma)V_{\infty}(\partial_t^+)$.$
```

where the superscript “+” indicates right derivative.

It follows that each of the stability criteria of Proposition 8.9 hold: V is a Lipschitz-continuous solution to QSVI, and the drift condition for $V_{\infty}$ implies that the origin is asymptotically stable for the ODE@\infty$.
