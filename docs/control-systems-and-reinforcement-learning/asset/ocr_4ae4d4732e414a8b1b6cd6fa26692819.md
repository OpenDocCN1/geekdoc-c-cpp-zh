# A.2.3 Strong Markov Property

The strong Markov property is described by a significant extension of the formula (A.4). The definition of this property requires these three ingredients:

+   (i) A function $\tau : \Omega \to \mathbb{Z}_+ \cup{\{infty\}$ is a *stopping time* for **X** if the event $\{\tau = n\}$ lies in $\mathcal{F}_n$ for each $n \in \mathbb{Z}_+$. That is, for each $n$ there is a function $f_n$ such that\n{\tau = n\} = f_n(X_0, \dots, X_n)$.

+   (ii) The associated shift operator $\theta^{\tau}$ is defined exactly as before:\n$\theta^{\tau} H = h(X_{\tau}, X_{\tau+1}, \dots)$.

+   (iii) An associated $\sigma$-field is also defined as:\n$\mathcal{F}_\tau \stackrel{\text{def}}{=} \{A \in F :{\tau = n\} \cap A \text{ for each } n \in \mathbb{Z}_+\}\ \quad (A.5)$

This is interpreted as the events that happen "up to time $\tau$."

Two important examples of stopping times, for any set $A \subset X$,\n$\tau_A \stackrel{\text{def}}{=} \min\{n \ge 1 : X_n \in A\}\n$\sigma_A \stackrel{\text{def}}{=} \min\{n \ge 0 : X_n \in A\}$

is known as the first and first hitting times into A, respectively.

**Proposition A.1** For any set $A \subset X$, the variables $\tau_A$ and $\sigma_A$ are stopping times for **X**.

*Proof* The random variables $\tau_A$ and $\sigma_A$ have this representation, for any $n \ge 1$,

```
$1{\tau_A = n\} = f_n(X_0, \dots, X_n) \stackrel{\text{def}}{=} 1{\X_n \in A\} \prod_{i=1}^{n-1} 1{\X_i \notin A\}$,
```

```
$1{\sigma_A = n\} = g_n(X_0, \dots, X_n) \stackrel{\text{def}}{=} f_n(X_0, \dots, X_n) 1{\X_0 \notin A\}$,
```

where $\prod_{i=1}^{0} \stackrel{\text{def}}{=} 1$ (handles the case $n=1$).\nFor $n=0$, we have $1{\tau_A = 0\} = f_0(X_0) = 0$ and $1{\sigma_A = 0} = g_0(X_0) 1{\X_0 \in A\}$.\square
