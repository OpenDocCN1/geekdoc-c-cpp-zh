# A Few Words on Ergodic Averages

Assumption (A\xi) that follows from Assumption (QSA5) appearing in Section 4.9, and that both concern averages of observations. In the discrete-time setting of this chapter, we denote

```
$g_N = \frac{1}{N} \sum_{k=1}^{N} g(\\Phi(k))$
```

for $g: Z \to R$ continuous, and $N \ge 1$. The main assumption is the existence of a limit, known as the ergodic mean (or ergodic average) and expectation):

```
$E_{\xi}[|g(\Phi)|] = \lim_{N\to\infty} g_N. \quad (5.22)$
```

The expression $E_{\xi}[|g(\Phi)|]$ may be regarded as notation, but in many cases it is represented as an integral. The *probability measure* $\mu$ has a density $\rho$, so that

```
$E_{\xi}[|g(\Phi)|] = \int_{Z} g(z)\rho(z)dz.$
```

Here is a simple example to illustrate the origin of a density:

**Lemma 5.2** *Consider the scalar signal $\xi(k) = \sin(2\pi k/T), k \ge 0$. Provided $T$ is an irrational number, for any continuous function $g: R \to R$, we have*

```
$\lim_{N\to\infty} \frac{1}{N} \sum_{k=1}^{N} g(\\xi(k)) = \int_{0}^{1} g(\sin(2\pi r))dr = \int_{-1}^{1} g(t)dt, \quad (5.23)$
```

where $\rho(t) = [\pi\sqrt{1-|t|^2}]^{-1}$ is known as the arcsine density.

*Proof* Consider the first signal $\xi^0(k) = [k/T]_1$, where $[r]_1$ denotes the fractional part of a scalar $r \in R_+$. This signal samples points uniformly in the interval $[0,1]$, giving for continuous functions $h: R \to R$,

```
$\lim_{N\to\infty} \frac{1}{N} \sum_{k=1}^{N} h(\\xi^0(k)) = \int_{0}^{1} h(r)dr.$
```
