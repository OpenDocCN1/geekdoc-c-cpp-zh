## 8.7.3 Polyak–Ruppert Averaging

We conclude with an approximation of the error covariance obtained using PJR averaging, denoted

```
$\bar{\Sigma}_{n_0}^{det} = E\{(\theta_n^0 - \theta^*)\{\theta_n^0 - \theta^*)^T\}$;
```

The goal is to justify the approximation $n_0\bar{\Sigma}_{n_0}^{det} \approx \Sigma_{\Delta}^*$, where $\Sigma_{\Delta}^* \coltriangleq A^{-1}\Sigma_{\Delta}(A^{-1})^T$ denotes the optimal asymptotic covariance matrix.

The following little lemmas are our starting point.

- **Lemma 8.11** The Polyak–Ruppert estimate can be expressed

```
$\theta_N^0 = \theta^* - \frac{1}{N-N_0}A^{-1}[M_N^0 - S_f^N + S_T^N + S_{\Delta}^N];$ (8.72)
```

where $A = A(\theta^*)$,

```
$M_N^0 = \sum_{n=N_0+1}^N f_{n+1}(\theta^0) = \sum_{n=N_0+1}^N \Delta_{n+1};$ (8.73a)
```

```
$S_f^N = \sum_{n=N_0+1}^N f_{n+1}(\theta_n^0);$ (8.73b)
```

```
$S_T^N = \sum_{n=N_0+1}^N E_f(\theta_n^0);$ (8.73c)
```

```
$S_{\Delta}^N = \sum_{n=N_0+1}^N {\Delta_{n+1} - \Delta_{n+1}^{\infty}\};$ (8.73d)
```

with $E_f(\theta)$ defined as in (8.65), and as in (8.3b).

```
$$\Delta_{n+1} = f_{n+1}(\theta_n^0) - \bar{f}(\theta_n^0);$ (8.74)
```

*Proof* By the definitions.

```
$f_{n+1}(\theta_n^0) = \bar{f}(\theta_n^0) + \Delta_{n+1} = A[\theta_n^0 - \Delta_{n+1}^{\infty}] + E_f(\theta_n^0) + {\Delta_{n+1} - \Delta_{n+1}^{\infty}\};
```

The representation follows by multiplying each side of the equation by $A^{-1}$, summing over $n$, and rearranging terms.

Under general conditions, the first term (8.73a) dominates, and from this we obtain

```
$$(N-N_0)\bar{\Sigma}_N^M = \frac{1}{N-N_0}ACov(M_N^0)A^T + o(1) = \Sigma_0^* + o(1);$ (8.75)
```

## 8.7 Some Theory

It's difficult to prove that two of the other terms should be relatively small:

- (i) $E_f(\theta_n^f) = O(\|\theta_n^f - \theta^*\|^2)$ when $f$ is smooth.
- (ii) We can only expect $\Delta_{n+1} - \Delta_n^\infty = O(\|\theta_n^f - \theta^*\|)$ (without the square). It is the sum $S_N^f$ that is small (compared to $M_N$) under (SA2).

It is a simple miracle that $\{S_N^f\}$ is small relative to $\{M_N^\infty\}$, given their very similar definitions. Bounds on $\{S_N^f\}$ are made possible by order representation, by rearranging the terms in the bounds (8.10a):

```
$f_{n+1}(\theta_n^f) = \frac{1}{\beta_{n+1}}[theta_{n+1}^f - \theta_n^f], \quad (8.76)$
```

with $\theta_n^f = \theta_n' - \theta^*$. A useful representation for the sum is obtained using this simple transformation:

**Lemma 8.2 (Summation by Parts)** For any two real-valued sequences $\{x_n, y_n : n \geq 0\}$ and integers $0 \leq N_0 < N$,

```
$$\sum_{n=N_0+1}^N x_n(y_n - y_{n-1}) = x_N y_N - x_{N_0} y_{N_0} - \sum_{n=N_0+1}^N (x_{n+1} - x_n)y_n.$$
```

Consequently,

```
$S_N^f = \sum_{n=N_0+1}^N \frac{1}{\beta_n}[\theta_{n+1}^f - \theta_n^f] = \frac{1}{\beta_{N_0}}\theta_{N_0}^f - \frac{1}{\beta_N}\theta_N^f - \sum_{n=N_0+1}^N (\frac{1}{\beta_n} - \frac{1}{\beta_{n+1}})\theta_n^f; \quad (8.77)$
```

The assumptions in the following imply strong bounds on each term.

## Assumptions for PJR Averaging

For fixed constants $b_\delta, b_f, b_Z$, and every $n \geq 1$,

- (PR1) The step-size $\beta_n = n^{-\rho}$ with $\frac{1}{2} < \rho < 1$.
- (PR2) $E[\Delta_n^\infty] = \Delta_n^\infty + O(n^{-\rho})$ for some $\rho \in (0,1)$. $E[\|\Delta_{n+1} - \Delta_n^\infty\|^2] \leq b_\delta|\theta_n^f|^2$.
- (PR3) $E[E_f(\theta_n^f)] \leq b_f|\theta_n^f|^2$.
- (PR4) $E[\|Z_n\|^4] \leq b_Z$, with $Z_n = n^{\rho/2}\theta_n$.

Once again, the martingale difference assumption (PR2) is stronger than required, which allows for simple calculations. The fourth moment for $Z$ is not enough to establish under a strengthening of (PR2):

```
$E[\|\Delta_{n+1} - \Delta_n^\infty\|^4] \leq b_\delta|\theta_n^f\|^4.$
```

for a constant $b_\delta$, along with (i) or (ii) of Proposition 8.9. The optimal convergence rate for PJR is now established. For simplicity, we take $N_0 = 0$ in Theorem 8.13.

## Stochastic Approximation

**Theorem 8.13** Under (PR1)-(PR4), consider the PJR scheme obtained for arbitrary $N \ge 1$ and $N_0 = 0$. Then (8.75) holds in the form

```
$$\Sigma_0^N = \frac{1}{N}\Sigma_0^* + \Sigma_N^N$$
```

where $\tilde{\Sigma}_0 = A\Sigma_0 A^T$, $\|\Sigma_N^N\| \le O(N^{-1-\delta})$, and $\delta = \min(\frac{1}{2}-\rho, \frac{\rho}{2}) > 0$. Consequently, the asymptotic convergence of $\{\Sigma_n^N\}$ is optimal. We require a simple comparison to summation:

**Lemma 8.14** The following bounds hold under (PR1):

```
$$\sum_{n=1}^N [\frac{1}{\beta_{n+1}} - \frac{1}{\beta_n}] \sqrt{\beta_n} = 2N^{\rho/2} + O(1) \quad \text{and} \quad \sum_{n=1}^N \beta_n = \frac{1}{1-\rho}N^{1-\rho} + O(1).
```

**Proof** Each bound is obtained by comparing a sum to an integral. For the first bound follow:

```
$$\sum_{n=1}^N [\frac{1}{\beta_{n+1}} - \frac{1}{\beta_n}] \sqrt{\beta_n} = \sum_{n=1}^N [(n+1)^{\rho} - n^{\rho}]n^{-\rho/2}
= \rho \sum_{n=1}^N n^{-1}n^{\rho}n^{-\rho/2} + O(1)\\
= \rho \int_{x=1}^N x^{-1+\rho/2} dx + O(1)\\
= \rho [\frac{x^{\rho/2}}{\rho/2}]_1^N + O(1) = 2N^{\rho/2} + O(1).
```

The proof of the second bound is similar. It is convenient to use vector space notation for the remainder of proof: For any vector-valued random variable $Z$,

```
$||Z||_2^{def} = (\sum E[|Z(i)|^2])^{1/2}$.
```

To refine the bound (8.75) with $N_0 = 0$), we begin with (8.72), written as

```
$$\bar{\mathcal{E}}_N = \mathcal{V}_N - \mathcal{E}_N, \quad \text{where} \mathcal{V}_N = \frac{1}{A^{-1}}M^{\tilde{N}} \quad \text{and} \mathcal{E}_N = \frac{1}{A^{-1}}[S_N^T - S_N^T].
```

**Lemma 8.15** the covariance admits the approximation

```
$$\Sigma_N^{cov} = Cov(\mathcal{V}_N) + \Sigma_N^N$$
```

where $Cov(\mathcal{V}_N) = \frac{1}{N}\Sigma_0^* + O(N^{-2})$, $\|\Sigma_N^N\| \le \epsilon_N$ with $\epsilon_N = 2\|\mathcal{V}_N\|_2 + \|S_N^T\|_2$.

**Proof** Note first that the approximation for the covariance $\mathcal{V}_N$ follows immediately from (PR2). Next we obtain by definitions

```
$$\Sigma_N^{cov} = E[(\mathcal{V}_N - \mathcal{E}_N)(\mathcal{V}_N - \mathcal{E}_N)^T] = Cov(\mathcal{V}_N) + \Sigma_N^N.
```

The remainder of the proof is concerned with bound on the maximal eigenvalue of the error term:

```
\max_{||v||=1} v^T \Sigma_N v
```

For any $v \in \mathbb{R}^d$, we have

```
$v^T \Sigma_N v = E[2(\mathcal{V}_N v) + (\mathcal{E}_N v)^2].$
```

The Cauchy-Schwarz inequality for vectors, we have $\|\mathcal{E}_N\| \le \|\mathcal{V}_N\|$ and $\|\mathcal{V}_N\| \le O(N^{-1})$ when $||v||=1$, and by the Cauchy-Schwarz inequality for expectation of random variables, we have

```
$v^T \Sigma_N v \le 2\|\mathcal{V}_N\|^2 \|\mathcal{E}_N\|_2 + \epsilon_N^2 = \epsilon_N.$
```

Proof of Theorem 8.13 We follow the following from the definitions and the triangle inequality:

```
\epsilon_N \le 2\|\mathcal{V}_N\| \frac{1}{2}(\|S_K^N\|^2 + \|S_L^N\|^2 + \|S_S^N\|^2) + N^{-2}(\|S_K^N\|^2 + \|S_L^N\|^2 + \|S_S^N\|^2)
```

and also $\|\mathcal{V}_N\|^2 \le O(N^{-1/2})$, giving $N^{-3/2}\|S_T^N\|_2 \le O(N^{-1-\rho})$. 

Applying (8.77) and Lemma 8.14,

```
\|S_T^N\|_2 \le \sum_{n=1}^{N} \|E_f(\theta_n)\|_2 \le bf\sqrt{b_z}\sum_{n=1}^{N} \beta_n \le O(N^{1-\rho}).$$
```
