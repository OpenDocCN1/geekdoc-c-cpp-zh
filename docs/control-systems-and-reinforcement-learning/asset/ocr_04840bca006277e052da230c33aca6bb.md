The goal is to estimate the parameter $\eta_0$ minimizing $\pi_	heta(c)$ for a function $c: X \to \mathbb{R}$. If using (6.37) to estimate $\eta_	heta$ for different values of $	heta$, be sure to reuse the sample path $\{N(k): 1 \le k \le n\}$ for each $	heta$.

Consider, for example a linear system:

```
$X^0(k+1) = (1-\theta)X^0 + N(k+1),$
```

with an i.i.d. sequence $c(x)$, and our interest is minimizing over $	heta \in \mathbb{R}$ the objective function $\Gamma(\theta) = (\theta^2 + 1)\eta_	heta^2$. This is easily computed for this simple example:

```
$\Gamma(\theta) = \frac{(\theta^2+1)}{(1-\theta)^2}\eta_	heta^2$.
```

The upper plots in Figure 6.8 compare estimates obtained with common random numbers, and those with independent random numbers (meaning that the samples of the disturbance $N(k)$ are chosen independently for each value of $\theta$). The plot obtained using common random numbers is smooth as a function of $\theta$.

Independent trials were performed, where in each of 500 experiments the minimizer was computed for each approach. The histograms shown in Figure 6.8 confirm that the estimate of $\theta^* \approx 0.6$ is far more reliable using common random numbers.

# Splitting Sampling

Consider estimation of an $E[L(X(k),X(k+1))]$ where $X$ is a finite state Markov chain with unique invariant measure $\pi$. The standard estimator is

```
$$\hat{L}_N = \frac{1}{N}\sum_{k=0}^{N-1} L(X(k),X(k+1))$.$
```

If the second eigenvalue of the transition matrix $P$ is close to unity, then the mixing time of the Markov chain $X$ will be slow, and this will adversely affect the convergence rate. In this case, the following variant, known as splitting sampling, can be used. $X^1$ denotes an i.i.d. sequence with marginal $\pi$. For each $k=1,2,\dots$, the random variable $X^2(k)$ is chosen in two stages. First, the value $x=X^1(k-1)$ is observed. Then the value of $X^2(k)$ is chosen according to the distribution $P(x,\cdot)$, independent of $\{X^1(j),X^2(j) : j \le k-1\}$.
