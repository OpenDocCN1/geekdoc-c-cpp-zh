# 7.2 Fluid Models for Approximation

It is often best to ignore disturbances, as a means to obtain intuition regarding a good policy. Many of the examples in this chapter are designed to illustrate this point. One approach is to consider the \textbf{averaged dynamics} associated with (7.1):

```
$\bar{F}(x,u) \overset{\text{eq}}{=} E[F(x,u,N(k+1))], \quad x \in X, u \in U(x), \quad (7.16)
```

which is independent of $k$ since $N$ is i.i.d. The \textbf{averaged fluid model} is the deterministic state space model

```
$x(k+1) = \bar{f}(x(k),u(k)). \quad (7.17)
```

It is sometimes simpler to introduce a model in continuous time, with vector field

```
$\bar{f}(x,u) \overset{\text{eq}}{=} \bar{F}(x,u) - x, \quad x \in X, u \in U(x), \quad (7.18)
```

so that (7.17) is expressed as and this is then by the nonlinear state space model in continuous time:

```
$x(k+1) - x(k) = \bar{f}(x(k),u(k)),
```

```
$\frac{d}{dt}x_t = \bar{f}(x_t,u_t). \quad (7.19)
```

These deterministic systems appear in approximating a large number of interacting stochastic systems, where they are called \textbf{mean-field models}. We will sometimes use this language, even when we are only interested in a single system in isolation.
\nFor either of the approximations (7.17) or (7.19) we require that the state space $X$ be a convex subset of Euclidean space, and typically also also approximate $U$ by a convex set. This brings challenges not: In [254], concerns about queuing networks, two models are considered by side. The state space $X_c$ is used for a countable-state space model, and $X$ denotes a convex state space for a deterministic fluid model. It is simplest here to allow the definition of $X$ and $U$ to change with the context.
