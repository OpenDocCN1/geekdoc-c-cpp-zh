which is (2,4), $M = 0$ and $b_0 = 1$. We obtain the state space model (2.13) with $n = N$
by choosing $x(k) = (y(k), \dots, y(k-N+1))$, and

```
$F = \begin{pmatrix} -a_1 & -a_2 & -a_3 & \dots & -a_N \ 1 & 0 & 0 & \dots & 0 \ 0 & 1 & 0 & \dots & 0 \ 0 & 0 & 1 & \dots & 0 \ \vdots & \vdots & \vdots & \ddots & \vdots \ 0 & 0 & 0 & \dots & 1 \end{pmatrix} G = \begin{pmatrix} 1 \ 0 \ 0 \ \vdots \ 0 \end{pmatrix}, \quad (2.16)$
```

$H = [1, 0, 0, \dots, 0]$, and $E = E$.
This construction can be generalized: with $M = N-1$ in (2.4), we define an
intermediate process

```
$z(k) = \sum_{i=1}^{N} a_i z(k-i) + u(k), \quad k \geq 0. \quad (2.17)$
```

So we arrive at a state space model with state space $x(k) = (z(k), \dots, z(k-N+1))\top
tode describe the evolution of $z$. We next use the assumption that $M = N-1$: setting
nu(k) = z(k) = 0$ for $k < 0$, it is possible to show that

```
$y(k) = \sum_{i=0}^{N-1} b_i z(k-i) = Hx(k) + Eu(k), \quad (2.18)$
```

where

```
$H = [b_0, b_1, \dots, b_{N-1}], \quad E = 0. \quad (2.18)$
```

The state space description (2.16, 2.18) is known as controllable canonical form. There are
other "canonical forms," with special properties you can learn about in a linear systems
course [7, 15, 29, 205].

# 2.3.4 A Nod to Newton and Leibniz

In many engineering applications, it is best to start off in continuous time, thanks to
Newton and Leibniz for bringing calculus.
*Some notations reserved for continuous time:* First, time is denoted by
a subscript (such as $u_t$ rather than $u(t)$ as a reminder that time is continuous. Moreover,
it is often convenient to suppress time dependency altogether, so that $\frac{d}{dt}u$ represents the
derivative at an unspecified time.

The state space model in continuous time has this form

```
$\frac{d}{dt}x = f(x,u), \quad (2.19)$
```
