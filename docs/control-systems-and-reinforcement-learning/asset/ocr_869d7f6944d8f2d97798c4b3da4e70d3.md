# 10.1 The Stage, Projection, and Adjoints

The geometry developed in this chapter requires a linearly parameterized function class. If space permitted, we might allow an RKHS for this purpose. Since this is not an option, a $d$-dimensional basis $\psi: Z \rightarrow \mathbb{R}^d$ is chosen, and any approximation is expressed $H^{\theta} = \theta^{\tau}\psi$ with $\theta \in \mathbb{R}^d$.

The interpretation of $Q$ in (10.1), the approximation $H^{\omega}$ is known as the projection of $Q$ onto the subspace $H = \{H^{\theta} : \theta \in \mathbb{R}^d\}$, and can be expressed

> $H^{\omega}(\Phi(k)) = E[Q(\Phi(k)) Y]$

with $Y = \psi(\Phi(k))$ (recall 9.19 for the definitions). These interpretations were discussed in Section 5.4. For any two functions $g,h: Z \rightarrow \mathbb{R}$, the inner product is defined by

> $$\langle g,h \rangle^{\omega} \triangleq E[g(\Phi(k))h(\Phi(k))] = \sum_{z \in Z} g(z)h(z)\omega(z)$

so that

> $||H^{\omega} - Q^{\omega}\|_{\omega} = \langle H^{\omega} - Q, H^{\omega} - Q \rangle_{\omega}$.

Recall that we write $g \in L_2(\omega)$ whenever $||g|| < < \infty$. This comes for free since we assume in this chapter that $X$ and $U$ are finite.

The conclusions of Propositions 5.7 and 9.4 are used here for reference of:

**Proposition 10.1** Suppose that $\{\psi_i\}$ are linearly independent in $L_2(\omega)$; $||\theta^{\tau}\psi|| = 0$ implies that $\theta=0$. Then, for any function $G \in L_2(\omega)$, the projection exists, is unique, and is given by $\G^* = \theta^{*\tau}\psi^*$ with $\theta^* = R(0)^{-1}\psi^*$, where $\psi^*^{G} \in \mathbb{R}$ and the $d \times d$ matrix defined by

```
$$\psi_i^{G} = \langle \psi_i, G \rangle_{\omega}, \quad R_{i,j}^{G} = \langle \psi_i, \psi_j \rangle_{\omega}, \quad 1 \leq i, j \leq d. \quad (10.2)$
```

Some interest comes when $G$ is the Q-function. For the discounted-cost criterion, the vector $\psi^{Q} \in \mathbb{R}^d$ can be expressed

```
$$\psi^Q = E_{\omega}[\psi(\Phi(0))Q(\Phi(0))] = \sum_{k=0}^{\infty} \gamma^k E_{\omega}[\psi(\Phi(0))c(\Phi(k))]. \quad (10.3)$
```
