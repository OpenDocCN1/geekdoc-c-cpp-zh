# 3.6 Linear Quadratic Regulator

We obtain a convex optimization problem that is suitable for RL implementation by applying a common technique: Overparameterize the search space. The first step is to regard J* and Q* as independent variables, and regard (3.7a) as a linear constraint. Following this approach, we obtain a linear program that lends itself to RL algorithm design.

Naturally, a finite-dimensional linear program is finite if the state and action space are finite. In this case, as part of the algorithm we choose a weighting function v, and denote for any candidate approximation J,

```
(v, J) \overset{def}{=} ∑_{x\in X} v(x)J(x).
```

It is assumed that v(x) > 0 for each x. In most cases, this is a probability mass function (pmf), meaning that in addition we assume ∑ v(x) = 1. Even when the state space is not finite, X = Rⁿ, we continue to assume that v has finite subset {x^i : 1 ≤ i ≤ M}. In this case, the definition becomes

```
(v, J) \overset{def}{=} ∑_{i} v(x^i)J(x^i).
```

Proposition 3.10 states that the Bellman equation can be cast as a linear program.

**Proposition 3.10** Suppose that the value function J* defined in (3.2) is continuous, compact, and vanishes at infinity. The pair (J,Q*) solves the following linear program (LP) in the "variables" (J,Q):

```
max_{J,Q} \langle v, J \rangle (3.36a)
s.t. Q(x,u) ≤ c(x,u) + J(F(x,u)), (3.36b)
Q(x,u) ≥ J(x),   x \in X, u ∈ U(x), (3.36c)
J is continuous, and J(x^*) = 0. (3.36d)
```

The linear program will be called the dynamic programming program (DLPP). It reappears in Section 5.5 as followed, by several approaches to approximately solve the DP equation.
We can without loss of generality strengthen (3.36b) to equality: Q(x,u) = c(x,u) + J(F(x,u)). Based on this substitution, the variable Q is eliminated:

```
max \langle v, J \rangle (3.37a)
s.t. c(x,u) + J(F(x,u)) ≥ J(x),   x ∈ X, u ∈ U(x). (3.37b)
```

This closely resembles what is found in the stochastic control literature (see [10] for a survey). The more complex LP (3.36) is introduced because it is easily adapted to RL applications.
