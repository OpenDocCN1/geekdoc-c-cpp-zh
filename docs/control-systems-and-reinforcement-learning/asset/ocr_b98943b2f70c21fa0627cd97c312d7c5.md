$N-3/2\|\hat{S}_N\|_2^2 \leq O(N^{-1-ho/2})$ The sequence $\{\hat{\Delta}_{n+1} = \Delta_n - \Delta_{n+1}^\infty\}$ is uncorrelated, so

$\|\hat{S}_N\|_2^2 = \|\sum_{n=1}^N \hat{\Delta}_{n+1}\|_2^2 = |\sum_{n=1}^N \hat{\Delta}_{n+1}|^2.$

Applying (PR2) gives $|\hat{\Delta}_{n+1}\| \leq bE[\|\hat{\Delta}_n\|^2]$, and from (8.78) we obtain $|\hat{\Delta}_{n+1}\|^2 \leq b_d\sqrt{b_z}\beta_n$. Putting these together with Lemma 8.14,

$\|\hat{S}_N\|_2^2 \leq \sqrt{b_z b_\Delta} \beta_n \leq O(N^{1-ho}).$
