## 6.4 A Random Glance Ahead

For the linear space model, the M/M/1 queue, and for finite state Markov chains, we identified conditions under which a limiting probability measure $\pi$ satisfying (6.6): For each state $x \in X$ and $S \in \mathcal{B}(X)$,

> $$\lim_{k\to\infty} P^k(x,S) = \pi(S).$$

The limit $\pi$ is invariant, and in state one says

> $$\int_X(dx)\pi^k(x,S) = \pi(S), \quad S \in \mathcal{B}(X), k \ge 1.$$

That is, $\pi^k = \pi$. Conditions for the existence of an invariant measure on an infinite state space will be surveyed later in the chapter, with far stronger ergodic theorems.

The existence of an invariant measure is equivalent to the existence of a steady-state realization of the process $X$. The state process satisfies the stationarity property:
$P\{X(k) \in A_0, X(k+1) \in A_1, \dots, X(k+m) \in A_n\}$ is independent of $k \ge 0$, for any $m \ge 0$ and any sequence of sets $\{A_0, \dots, A_m\}$, each in $\mathcal{B}(X)$. Naturally, the stationary realization satisfies $X(k) \sim \pi$ for each $k$. While we don't expect to encounter true stationarity in the real world, this idealism is helpful for conceptualizing and analyzing algorithms.

### 6.4.1 Critic Methods

The term "critic" in RL refers to a value function $h$, which is defined with respect to a one-step cost function $c$. One example is felt by discounted cost: For $0 \le \gamma < 1$,

$$h(x) = E_x \left[\sum_{k=0}^{\infty} \gamma^k c(X(k))\right].$$

TD(\lambda$) learning was introduced in the 1970s to obtain an approximate solution to the discounted-cost dynamic programming equation, based on a generalization of the temporal difference that is the core of TD-learning algorithms found in Part I. The stochastic setting Markov Chains gives new tools and insights. For example, it will be seen that the final output of the TD(1) alg solves the minimum norm problem:

$\min\{||h-h'||_2^2 : h \in \mathcal{H}\}$

$\mathcal{H}$ is the function class through which we seek an approximation, and the norm is defined with respect to the steady state:

$|\hat{h}-h||_2^2 = E[||\hat{h}(X(k))-h(X(k))||_2^2] \quad \text{when } X(k) \sim \pi. (6.22)$

### 6.4.2 Actor Methods

One of RL begins with a parameterized family $\{P_{\theta : \theta \in \mathbb{R}^d}\}$, along with cost functions $\{c_{\theta : \theta \in \mathbb{R}^d}\}$. The "actor" methods are designed to find the parameter $\theta^* \in \mathbb{R}^d$ that minimizes the average cost $\eta_{\theta} = \int c(x)\pi_{\theta}(dx)$, with $\pi_{\theta}$ invariant under $P_{\theta}$. See Theorem 6.8 for one technique to estimate the gradient of $\eta$, so that $\theta \in \mathbb{R}^d$ can be estimated stochastic gradient descent. Actor-critic methods make use of a combination of Theorem 6.8 and (6.22) to obtain model-free and unbiased estimates of the gradient.

## 6.5 Poisson's Equation

This little will appear in many forms in the book:

$c + Ph = h + \eta. (6.23)$

It is known as Poisson's equation. The function $c$ is known as the forcing function, $\eta$ is a constant, and the solution $h$ is called the relative value function. The conditions imposed to establish a solution to (6.23) also imply that an invariant measure $\pi$ exists, and that $\eta = \pi(c) = \intint c(x)\pi(dx)$. In many cases, we obtain a solution by iteration or inversion:

$h = \sum_{k=0}^{\infty} P^k \tilde{c}. (6.24)$

with $\tilde{c}(x) = c(x) - \eta$ (one rationale for the relative value function). The solution to (6.23) is not unique: if $h$ is a solution, then we obtain a new solution by adding a constant. The abstract notion in (6.23) and (6.24) is based on (6.9b). For a finite state space model, Poisson's equation becomes

$c(x) + \sum_{x'} P(x,x')h(x') = h(x) + \eta, \quad x \in X. (6.25)$

An equivalent representation is reinforcement of the fixed policy dynamic programming (2.25), based on the Markov model (6.3):

$h(x) = \tilde{c}(x) + E[h(F(x,N(k+1)))]$.

This implies sample path formulae similar those discussed in Section 2.5.2 and throughout Section 5:

$h(X(k)) = \tilde{c}(X(k)) + E[h(X(k+1)) | X(0), \dots, X(k)].$

Poisson's equation plays a starring role in later chapters:

- (i) The relative value function of average-cost optimal control is the solution to a particular Poisson equation.
- (ii) Recall that Poisson's inequality was the engine behind performance bounds in Section 2.4.3 (i.e., on the value function $J$). The analogous inequality is used in Section 6.6 to obtain bounds on the steady-state mean $\eta$ as well as the relative value function $h$.
- (iii) The Central Limit Theorem (CLT) is used to obtain rates of convergence for algorithms in nearly every chapter. The covariance matrix in the CLT has a representation in terms of solution to (6.23), where the choice of $c$ depends on the application. The first introduction to CLT is in Section 6.7.
- (iv) As presented in Section 6.4, in some applications to control we have a family of transition kernels $\{P_\theta : \theta \in \mathbb{R}^d\}$. With $c: X \to \mathbb{R}$ interpreted as cost, we would like to minimize the steady-state average cost $\eta$ over all $\theta$. Many approximations of gradient descent are based on Poisson's equation and sensitivity analysis surveyed in Section 6.8.
- (v) One of the main result of Section 6.8 is for actor-critic methods for RL, which is the topic of Section 10.

The concepts in Section 6.3 provide conditions for existence of solution to (6.23) when $X$ is finite. The discussion in Section 3.2 provides early introduction to the Perron–Frobenius theorem beyond Section 6.3.

**Theorem 6.3 (Spectral Conditions for Poisson Equation)** Suppose $X$ is finite, and the assumptions of Theorem 6.2 are satisfied. Then the following hold:

- (i) The function $h_1 = \sum_{k=0}^\infty P^k c$ is a solution to (6.23) (recall 6.24).
- (ii) Let $x^* \in \mathbb{R}_+$ be a function satisfying $\pi(s) > 0$, and $v$ a function satisfying $P(x, x') \ge s(x), x' \in X,$ also $P \ge s \otimes v$. Then a solution to Poisson's equation is given by $h_2 = G_{s,v}c, G_{s,v} = \sum_{n=0}^\infty (P - s \otimes v)^n = [I - (s \otimes v)]^{-1}$.
- (iii) Let $x^* \in X$ denote any state for which $\pi(x^*) > 0$. Another solution to Poisson's equation is defined by the expectation: $h_3(x) = \mathbb{E}_x \left[\sum_{k=0}^{\tau-1} c(X(k))\right], (6.26)$ where $\tau = \min\{k \ge 1 : X(k) = x^*\}$. This solution satisfies $h_3(x^*) = 0$.
- (iv) If a function $g$ and constant $\eta$ solve $c + Pg = g + \eta$, then $\eta = \pi(c)$, and $g(x) - g(x^*) = h_1(x) - h_1(x^*) = h_2(x) - h_2(x^*) = h_3(x)$ for each $x \in X.\square$

Proof The simplest of the three is (i), $Ph_1 = \sum_{k=0}^{\infty} P^k \hat{c}$ where used $P P^k = P^{k+1}$. The right-hand side is equal to $h_1 - \hat{c}$. The remainder of the proof is a “roadmap.” For the full details, see the appendix of [4].

For (ii) and (iii), recall that the invariant measure $\pi$ exists and is unique, due to Theorem 6.2. Poisson's equation with invariance of $\pi$ implies:

$$\pi(h) = \sum_{x} \pi(x)h(x) = \sum_{x} \sum_{y} \pi(x)P(x,y)h(y)$$
$$\eta = \sum_{x} \pi(x)\{h(x)-c(x)\} = \pi(h) - \pi(c) + \eta$$

Hence $\eta = \pi(c)$.

The proof that $h_2$ solves Poisson's equation follows to Proposition 3.5. A full proof can be found in [7] or the appendix of [4]. This solution is related to $h_1\hat{c}$. We have $P^k\hat{c} = \tilde{P}^k\hat{c}$ for any $k$, where $\tilde{P} = P-\odot \pi$ was introduced in (6.19). Hence $h_1 = G_{1,\pi}\hat{c}$.

The third representation can be reduced to the second, starting with

$h_3(x) = \sum_{k=0}^{\infty} E_x[\mathbb{1}_{\{\tau > k}]}\hat{c}(X(k))$$

It can be shown that $h_2$ is in the special case $s(x) = \mathbb{1}_{\cdot}(x)$, and $v(y) = P^*(x,y)$.
We come to (iv): If $C+Pg = g+\beta$ and $C+Ph = h+\eta$, then let $\Delta = h-g$, giving Using invariance of $\pi$ gives

$$\pi(\Delta) = \sum_{x} \pi(x)\Delta(x) = \sum_{x} \sum_{y} \pi(x)P(x,y)\Delta(y) = \sum_{x} \pi(x)\Delta(x) + \eta-\eta = \pi(\Delta)+\eta-\eta.$$

This gives $\eta = \beta$, and also the following eigenvector equation:

$P\Delta = \Delta.$

Under the assumptions of the theorem, it follows that $\Delta(x)$ does not depend on $x$.

## 6.6 Lyapunov Functions

Much of the Lyapunov stability theory for dynamical systems can be adapted to the Markovian setting. For an irreducible Markov chain in a finite state space, where the term “stability” may not be meaningful, Lyapunov functions are useful as means to obtain performance bounds (generalizing the Comparison Theorem in Proposition 2.3).

Poisson's inequality for the Markovian model is the extension of (2.31): For a function $V: X \to \mathbb{R}_+$, a function $c: X \to \mathbb{R}_+$, and a constant $\bar{\gamma} < \infty$.

```
$E[V(X(k+1)) | X(k)=x] \leq V(x)-c(x)+\bar{\gamma}, \quad x \in X.$
```
