# 8.2.2 ODE Approximation

Comparison of (8.3a) with an ODE requires a time transformation similar to the introduction of $\tau$ in (4.73) for analysis of QSA. Our first introduction to a stochastic Euler approximation was in (4.8), in which the time points $\{\tau_k\}$ were assumed given. The step-size $\{\alpha_k\}$ is given, and we define the time points via $\tau_0 = 0$, and $\tau_{k+1} = \tau_k + \alpha_k$ for $k \ge 0$. The ODE approximation is based on a comparison of two processes in continuous time:

+   (i) $\theta_t = \theta_k$ when $t = \tau_k$, for each $k \ge 0$, and defined for all $t$ through piecewise interpolation. The notation is used to emphasize the similarity with the QSA parameter estimates in Section 4.5.

+   (ii) For each $n \ge 0$, let $\{\theta_t^{(n)}\ : t \ge \tau_n\}$ denote the solution of (8.4a), initialized according to the current parameter estimate

```
$$\frac{d}{dt}\theta_t^{(n)} = \bar{f}(\theta_t^{(n)}), \quad t \ge \tau_n, \quad \theta_{\tau_n}^{(n)} = \theta_n.$
```

Expressed as a differential equation, it seems difficult to compare $\theta_k^{(n)}$ and $\theta_k$ for $k > n$. This is why the ODE approximation is obtained in integral form.

The cumulative disturbance is defined for

```
$M_K^{(n)} = \sum_{i=n+1}^K \alpha_i \Delta_i,$
```

with $\Delta_i$ defined in (8.3b). Iteration then gives

```
$$\Theta_{\tau_K}^{(n)} = \theta_n + \sum_{i=n+1}^K \alpha_i f(\Theta_{	au_i}) + M_K^{(n)},$
```

```
$$\theta_n + \int_{\tau_n}^{\tau_K} \bar{f}(\Theta_	au) d\tau + E_{\tau_K}^{(n)}.$
```

where $E_{\tau_K}^{(n)}$ is the sum of $M_k^{(n)}$ and the error resulting from the Riemann-Stieltjes approximation of the integral. This disturbance term will vanish with $n$, uniformly in $K$, subject to conditions on $\{\Delta_i\}$ and the step-size.
