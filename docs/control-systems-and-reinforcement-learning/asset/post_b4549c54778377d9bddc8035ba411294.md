```
$\mathcal{D}_{k+1}(Q^{\theta})=\mathcal{D}_{k+1}(Q^{\theta'}), \quad \text{with } \theta'=\theta+rv$
```

- (ii) For the on-policy implementation,

```
$v^T \psi(x(0), u(0)) = v^T \psi(x(k), u(k)).$
```

Hence this falls into the "redundant" category discussed in Section 5.1.5.

Proof *If $R_N$ does not have full rank, then it follows that there is a nonzero vector $v$ satisfying $v^T R_N v = 0$. By definition,

```
$0 = v^T R_N v = \frac{1}{N} \sum_{k=0}^{N-1} (v^T \Upsilon_{k+1})^2$.
```

That is, $v^T \Upsilon_k = 0$ for every observed sample, which means

```
$0 = v^T \psi(x(k), u(k)) - v^T \psi(x(k+1), \phi(x(k+1))), \quad 0 \le k \le N-1. \quad (5.35)
```

Part (i) follows from (5.35) and the definition (5.28a): for any scalar $r$, with $\theta' = \theta + rv$

```
$\mathcal{D}_{k+1}(Q^{\theta}) = -Q^{\theta}(x(k), u(k)) + c(x(k), u(k)) + Q^{\theta}(x(k+1), \phi(x(k+1)))\n= c(x(k), u(k)) + [\theta + rv]^T [-\psi(x(k), u(k)) + \psi(x(k+1), \phi(x(k+1)))]\n= c(x(k), u(k)) + \theta^T [-\psi(x(k), u(k)) + \psi(x(k+1), \phi(x(k+1)))] = \mathcal{D}_{k+1}(Q^{\theta}).$
```

If $u(k) = \phi(x)$ for all $k$, then (5.35) becomes

```
$v^T \psi(x(k), u(k)) = v^T \psi(x(k+1), u(k)), \quad 0 \le k \le N-1$,
```

which implies (ii).

## 5.3.3 Recursive LSTD and Zap

LSTD learning is often presented as a recursive algorithm:

**Proposition 5.5** LSTD learning in the form (5.34) admits the recursive representation:

```
$$\theta_{N+1}^1 = \theta_N^1 + G_{N+1}Y_{N+1}^1[Y_N - \Upsilon_{N+1}^1\theta_N], \quad (5.37a)$$
```

```
$G_{N+1} = G_N - \frac{1}{k_{N+1}}G_N\Upsilon_{N+1}^1G_N, \quad N \geq 0 \quad (5.37b)$
```

with $k_{N+1} = 1 + \Upsilon_{N+1}^1G_N$.

**Proof** The recursion is an application of Proposition 5.3: Letting $G_N = [W + R_N]^{-1}$, implies that for $N \geq 0$,

```
$$\theta_{N+1}^1 = (N+1)\psi_{N+1}^Y$$
$$G_{N+1}^1 = G_N^1 + \Upsilon_{N+1}^1.$$
```

The recursion (5.37b) follows from the Matrix Inversion Lemma (A.1). To obtain (5.37a), we use this recursion for $\psi_N^Y$, also implied by Proposition 5.3:

```
$$(N+1)\psi_{N+1}^Y = N\psi_N^Y + \Upsilon_{N+1}^Y.$$
```

Consequently,

```
$$\Gamma_{N+1}^1\theta_{N+1}^1 = (N+1)\psi_{N+1}^Y\\
= N\psi_N^Y + \Upsilon_{N+1}^Y\\
= G_N^1\theta_N^1 + \Upsilon_{N+1}^Y\\
= \{G_{N+1}^1 - \Upsilon_{N+1}^1\}\theta_N^1 + \Upsilon_{N+1}^Y.$$
```

Multiplying each side by $G_{N+1}$ establishes (5.37a). The algorithm (5.37) can be represented as a QSA recursion with matrix gain:

```
$$\theta_{N+1}^1 = \theta_N^1 + \alpha_{N+1}[Y_N - \Upsilon_{N+1}^1\theta_N]$$
```

We might have arrived at this algorithm through the ODE method, which the recursive algorithm is designed to approximate a matrix-gain ODE:

```
$$\partial_t \theta_t = M(\theta_t).$$
```

Given our objective to minimize the loss function (5.33), it is natural to take $f(\theta) = -\frac{1}{2}\Gamma(\theta)$ and $M$ positive. The recursion (5.37a) is an approximation of this ODE using $M = E_0[\Upsilon_k \Upsilon_k^T]$. We can also write

```
$$M^{-1} = E_0[\Upsilon_k \Upsilon_k^T] = \partial^2 E_0[(\Upsilon_k \theta)^2] = \partial^2 \Gamma(\theta) = -\partial f(\theta).$$
```

Hence LSTD is a single time-scale approximation of QSA. Fact.

## 5.4 Projected Bellman Equations and TD Algorithms

LSTD suffers from two computational challenges:

- (i) What do you do if $d = 10^7$? Practitioners in machine learning often face high-dimensional problems and claim that dimensions of one million are no longer concern. This success story is attributed to advances in optimization theory, computer engineering, and computing power.
- (ii) How can LSTD be extended to nonlinear function approximation, as when each $\theta_t$ is a weight in a neural network?

In the RL research community, it is typical to modify the objective in order to reduce complexity. A favored approach is to create algorithms that obtain solutions for a *projected* dynamic programming equation. While there is little supporting theory, the algorithms inspired by this viewpoint have been highly successful with neural network function approximation.

The motivation behind these algorithms requires a bit more background on function approximation, described here using the notation of Section 5.1. We begin with an abstraction: Find a function $h^*$ that solves a fixed point equation:

```
$$h^* = T(h^*).$$
```

The specifics of domain and range of $h^*$, and the meaning of the mapping $T$, depend on the problem we would like to solve. The DP equation (3.5) is one example, with $h^* = J^*$. If solving (5.38) is intractable, we seek an approximation.

We choose a class $\mathcal{H}$ and a mapping $P_H : \mathcal{H} \to \mathcal{H}$. That is, $P_H(h) \in \mathcal{H}$ for any $h \in \mathcal{H}$. More conditions on this mapping will be imposed later. We then introduce an approximation of (5.38):

```
$$h = \mathcal{T}(h) \overset{\text{and}}{=} P_H\{T(h)\}.$$
```

## 5.4 Projected Bellman Equations and TD Algorithms

In some cases, this approach fails or is too complex, so we consider an alternative: Given a second function class $\mathcal{G}$, find a function $h \in \mathcal{H}$ solving

```
$0 = P_{\mathcal{G}}(h - T(h)).$
```

This is a generalization of (39):

**Proposition 5.6** Suppose the following hold:

- (i) $\mathcal{H} = \mathcal{G}$.
- (ii) $\mathcal{H}$ is linear: $a_1h_1 + a_2h_2 \in \mathcal{H}$ whenever $h_1, h_2 \in \mathcal{H}$.
- (iii) The mapping $P_{\mathcal{H}}$ is linear: $a_1P_{\mathcal{H}}(h_1) + a_2P_{\mathcal{H}}(h_2) = P_{\mathcal{H}}(a_1h_1 + a_2h_2)$.

## 5.4.1 Galerkin Relaxations Projection

We begin with assumptions on $\mathcal{G}$: the expectation introduced in (A1) is used to define an inner product over functions $h_1, h_2: Z \to \mathbb{R}$:

```
$\langle h_1, h_2 \rangle_{\omega} = \mathbb{E}[h_1(\Phi)h_2(\Phi)], \quad \|h_1\|_{\omega} = \sqrt{\mathbb{E}[(h_1(\Phi))^2]} = \sqrt{\langle h_1, h_1 \rangle_{\omega}}.$
```

The projection $L_{\mathcal{G}}(\omega)$ is defined to be all functions $h$ for which $\|h\|_{\omega}$ is finite. For $h \in L_2(\omega)$, the projection onto $\mathcal{G}$ is defined as

```
$h = P_{\mathcal{G}}(h) = \arg\min_{g \in \mathcal{G}} \|g - h\|_{\omega}.$
```

The optimizer $h \in \mathcal{G}$ satisfies the orthogonality condition,

```
$\langle h - h, g \rangle_{\omega} = 0, \quad g \in \mathcal{G}.$
```

**Proposition 5.7** Suppose that $\zeta_i \in L_2(\omega)$ for each $i$, and that these functions are linearly independent in $L_2(\omega)$. That is, $\|	theta^T\zeta\|_{\omega} = 0$ implies that $	theta = 0$.
For each $h \in L_2(\omega)$, the projection exists, is unique, and given by $h^* = \theta^{*T}\zeta$ with

```
$$	theta^* = [C^{-1}]^Th.$
```
