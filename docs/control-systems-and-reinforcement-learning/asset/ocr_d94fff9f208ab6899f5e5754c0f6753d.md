Proof of (4.132a) Denote

```
$$\mathcal{E}_{	au}^v = \int_{	au}^{	au+v} |f(\Theta_w, \xi(s^{-1}(w))) - \tilde{f}(\Theta_w)| dw.$
```

To establish (4.132a), we show that this converges to zero as $\tau \to \infty$, uniformly for $v
bounded intervals.
Fix $\delta > 0$ and denote $\tau_k = \tau + k\delta$ for $k \geq 0$. In the theory of Riemann integration,
The Lipschitz constants (QSA2) imply the following:

```
$$\mathcal{E}_{	au}^v = \sum_{k=0}^{n_v-1} \int_{\tau_k}^{\tau_k+\delta} [f(\Theta_k, \xi(s^{-1}(w))) - \tilde{f}(\Theta_k)] dw + \varepsilon_{	au}^v,$
```

where $n_v$ denotes the integeur part of $v/\delta$, and $|\mathcal{E}_{	au}^v| \leq b_L v\delta$ for some constant $b_L < \infty$. The
bound is uniform under $\tau$ under the assumption that $\Theta$ is bounded.
Lemma 4.30 and the triangle inequality imply

```
$$\|\mathcal{E}_{	au}^v + v\| \leq \sum_{k=0}^{n_v-1} \varepsilon_{	au_k} b_0(\Theta_k) + b_L v\delta \leq \sum_{k=0}^{n_v-1} b_0(\Theta_k) + b_L v\delta.$
```

Let $b_* < \infty$ denote a constant satisfying $b_0(\\Theta_{	au}) \leq b_*$, for all $\tau$. Then,

```
$$\\|\mathcal{E}_{	au}^v + v\| \leq b_* \varepsilon_{	au}^v + b_L v\delta.$
```

Lemma 4.30 then implies that for any $T > 0$,

```
$$\sup_{\tau \to \infty} \sup_{v \in [0,T]} |\mathcal{E}_{	au}^v + v\| \leq b_L T.$
```

This completes the proof of (4.132a), since $\delta > 0$ was arbitrary.
