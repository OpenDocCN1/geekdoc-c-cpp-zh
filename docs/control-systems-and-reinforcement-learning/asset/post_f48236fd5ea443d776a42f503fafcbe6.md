On denoting $f_r(\theta) = r^{-1}f(r\theta)$ for $\theta \in \mathbb{R}^d$, this becomes

```
$\frac{d}{dt}\theta_i^r = f_r(\theta^r).\quad\quad (4.112)$
```

Suppose that a limiting vector field exists:

```
$f_{\infty}(\theta) = \lim_{r\to\infty} f_r(\theta) = \lim_{r\to\infty} r^{-1}f(r\theta),\quad\quad\theta \in \mathbb{R}^d.\quad\quad (4.113)$
```

and define the ODE at $\infty$ as the limiting case of (4.112):

```
$\frac{d}{dt}\theta_i^{\infty} = f_{\infty}(\theta^{\infty}),\quad\quad\theta^{\infty} \in \mathbb{R}^d.\quad\quad (4.114)$
```

We have $f_{\infty}(0)=0$ by (4.113), so the origin is an equilibrium of (4.114).

**Proposition 4.2** Suppose that $f$ is globally Lipschitz, with Lipschitz constant $L$. Suppose that the limit (4.113) exists for all $\theta$ to define a continuous function $f_{\infty}: \mathbb{R}^d \to \mathbb{R}^d$. Then, if the origin is asymptotically stable for (4.114), it follows that the ODE (4.2) is ultimately bounded.

To prove the proposition, we need to better understand the special properties of the solution to (4.114):

**Lemma 4.23** Suppose that the assumptions of Proposition 4.2 hold, in particular the origin is asymptotically stable for (4.114). Then the following holds:

- (i) For each $\theta \in \mathbb{R}^d$ and $s \ge 0$, $f_{\infty}(s\theta) = sf_{\infty}(\theta).$

- (ii) If $\{\theta_i^{\infty} : t \ge 0\}$ is any solution to the ODE (4.114), and $s>0$, then $\{y_i = s\theta_i^{\infty} : t \ge 0\}$ is also a solution, starting from $y_0 = s\theta_0^{\infty} \in \mathbb{R}^d$.

- (iii) The origin is globally asymptotically stable for (4.114), and convergence to the origin is exponentially fast: For some $R < \infty$ and $\rho > 0$,

```
$\|\theta^{\infty}\| \le Re^{-\rho t}\|\theta_0^{\infty}\|,\quad\quad\theta_0^{\infty} \in \mathbb{R}^d$.
```

## 4.9 Convergence Theory for QSA*

We consider in this scenario the general nonlinear ODE (4.44), subject to Assumptions (QSA1)-(QSA3) (introduced in Section 4.5). The proof of Theorem 4.15 is mainly a straightforward application of Gronwall’s Inequality, as stated in Proposition 4.12. Stability theory for QSA follows closely the stability theory of ODEs surveyed in 4.8. It is only when we convergence to rates that we encounter mathematical challenges. These results also require further assumptions, a slight strengthening of (QSA2):

(QSA4) The vector field $f$ is differentiable, with derivative named

```
$A(\theta) = \partial_\theta f(\theta).$ (4.116)
```

That is, $A(\theta)$ is a $d \times d$ matrix for each $\theta \in \mathbb{R}^d$, $A_{i,j}(\theta) = \frac{\partial}{\partialtheta_j}f_i(\theta)$. Moreover, the derivative $A$ is Lipschitz continuous, and $A^* = A(\theta^*)$ is Hurwitz.

The matrix-valued function $A$ is uniformly bounded over $\mathbb{R}^d$, subject to the global Lipschitz assumption on $f$ in QSA2. The Hurwitz assumption implies that the ODE (4.42) is (locally) exponentially asymptotically stable.
