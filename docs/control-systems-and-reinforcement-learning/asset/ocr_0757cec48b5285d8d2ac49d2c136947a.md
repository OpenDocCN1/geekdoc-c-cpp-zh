# 9.3 Loss Functions

In this section and the next, we seek approximations of the discounted-cost value function $h$ in (9.6). This is formulated as an approximate solution to (9.8) for each $k$, among a class of functions $\{h^0 : \theta \in \mathbb{R}^d\}$. The temporal difference is defined as the error without the conditional expectation:

```
$\mathcal{D}^0_{n+1} = -h^0(X(n)) + c(X(n)) + \gamma h^0(X(n+1)). \quad (9.26)$
```

If there is $\theta^0 \in \mathbb{R}^d$ giving $E[\mathcal{D}^0_{n+1} | F_n] = 0$ for all $n$, and every state in $X$ is visited, $h^0$ solves (9.8). As previous chapters, we can use many cases to handle this operate. For linear function approximation, we denote

```
$h^0 = \theta^	op \psi, \quad (9.27)$
```

where $\psi$ is a $d$-dimensional function on $X$ rather than $Z = X \times U$. To avoid of confusion, we abandon the simplified notation (9.4) in this case.

For each $\theta$, there is an associated Bellman error,

```
$B^0(x) = E[\mathcal{D}^0_{n+1} | X(n)=x] = -h^0(x) + c(x) + \gamma h^0(x), \quad x \in X, \quad (9.28)$
```

where the second equality is the definition of the transition matrix. The mean-square Bellman error (MSBE) is then defined by
