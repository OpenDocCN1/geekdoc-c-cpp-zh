# 7.3.1 Fluid Models and Value Functions

To define the fluid model for the CRW queue, we begin with a convex relaxation, taking
X = ... , and U = [0,1]. The mean-field dynamics and mean-field vector field associated
with (7.29) are

$\hat{f}(x,u) = E[X(k) - S(k+1)U(k) + A(k+1) \mid X(k) = x, U(k) = u]$

$\hat{f}(x,u) = -\mu+\alpha$.

Shown on the left-hand side of Figure 7.1 is a copy of the left-hand side of Figure 6.1, and
on the right-hand side is the solution of the fluid model $\frac{dq}{dt} = \hat{f}(q,u)$, under the nonididing
policy $u=1$ when $q > 0$, and $u = ho = \alpha/\mu$ otherwise.

Let's compare three value functions under the respective nonlinear policies, and
cost function $c(x,u) = x$:

+   (i) It is easy to verify that the ACOE (7.5) is given by

$h^*(x) = \frac{x^2+x}{\mu-\alpha}. \quad (7.31)$

+   (ii) The value function in continuous time is easily obtained:

$J^*(x) = \int_0^W q_t dt = \int_0^x q_t dt = \frac{1}{2}W \times x$ (area of a triangle),

where H refers to the height of the triangle defined by the linear path of $q$, and $W$ the
width, which is the time to reach zero. A glance at the plot on the right-hand side of
Figure 7.1 should convince you that $H = q_0 = x/(\mu-\alpha)$, so that

$J^*(x) = \frac{x^2}{\mu-\alpha}$.

We can compute the function $\eta(x,u)$ appearing in 7.28b:

$\eta(x,u) = E[J^*(X(k+1)) - J^*(X(k)) \mid X(k) = x, U(k) = u] - \nabla J^*(x) \cdot \hat{f}(x,u)$

$\frac{1}{2}\frac{\mu u+\alpha}{\mu-\alpha}$.

This is bounded, and independent of $x$. It follows from Lemma 7.3 that $J^*$ almost solves
t ACOE for the MDP model.
