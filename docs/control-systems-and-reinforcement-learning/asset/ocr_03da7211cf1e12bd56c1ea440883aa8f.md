You might try a pseudo inverse. In Matlab, this is computed with the command $J=(I-P)\c$. But if you do this, you may not understand what is going behind Matlab's curtain. Also, how do you know if you have obtained the boundary constraint $J(x^*) = 0$?

Here is one ingenious idea behind the theory of Perron and Frobenius: Choose two vectors $s, v \in \mathbb{R}^n$ with nonnegative entries, and satisfying

```
$P(i,j) \geq s(i)\otimes v(j), \quad 1 \leq i,j \leq N. \quad (3.18)$
```

This is called a *minorization condition*. Letting $s \otimes v$ denote the "outer product" of these two vectors, this is equivalently expressed

```
$P(i,j) \geq |s\otimes v(i,j)|, \quad 1 \leq i,j \leq N.$
```

We then use the fixed point equation:

```
$\tilde{c} = [I-P]\tilde{J} = [I-(P-s\otimes v)]\tilde{J} - [s\otimes v]\tilde{J},$
```

and note that the final term is just a constant times, represented as a column vector:

```
$[s\otimes v]\tilde{J} = \delta, \quad \delta = \sum_j v(j)J(j)$
```

so that

```
$\tilde{c} = [I-(P-s\otimes v)]\tilde{J} - \delta s. \quad (3.19)$
```

Under very mild conditions, we can invert the matrix mapping $J$ in (3.19). The inverse is known as the *fundamental matrix*:

```
$G = [I-(P-s\otimes v)]^{-1} = \sum_{n=0}^{\infty}(P-s\otimes v)^n, \quad (3.20)$
```

with $(P-s\otimes v)^k$ the $k$-th power for $k \geq 1$, and with $(P-s\otimes v)^0=1$ (the identity matrix). Here where the minorization condition exists: in the Matrix $(P-s\otimes v)^k$ has nonnegative entries for each $k \geq 0$, so that the infinite sum is always meaningful. If it is finite, then from (3.19) we obtain

```
$\tilde{J} = G\tilde{c} + \deltaGs.$
```

To find $\delta$, you must apply the boundary condition for $J$,

```
$0 = J(N) = \sum_k G(N,k)c(k) + \delta \sum_k G(N,k)s(k),$
```

And then obtain $\delta$ by division.
