## 4.5.5 Constant Gain Algorithm

The choice $a_t = \alpha$ (independent of time) is often favored in practice. For the linear model (4.86), this is not unreasonable, as we will see in the following. The highlight is Corollary 4.17, establishing the optimal rate of convergence when PJR averaging.

## 4.5 Quasistochastic Approximation

However, please be warned: the conclusions that follow are highly sensitive to the precise modeling assumption (4.86). Consider the minor variant, using

```
$f(\theta, z) = |A_0 + \varepsilon A_1|\theta, \quad \theta \in \mathbb{R}^d, \quad z \in \mathbb{R}. \qquad (4.88)$
```

Stability of the constant gain algorithm is characterized in [36] for this and more general linear systems with multiplicative "quasisturburbance". The characterizations have resemblance to ours in this book - in particular, the average vector field $\hat{\theta}=A_0\theta$ is often useless for stability analysis. See Exercise 4.18 for a short tour of this theory.

Convergence theory for vanishing gain algorithms is more intuitive, even when subject to multiplicative disturbances as in (4.88).

Analysis for the linear model (4.86) is simplified since QSA is a time-invariant linear system

```
$\dot{\hat{\theta}}_t = \alpha[\hat{\theta}_t + B\varepsilon_t],$
```

where $\hat{\theta}_t \coloneqq{\text{def}} \theta_t - \theta'$ is the error at time $t$. We can solve this ODE where the probing signal is the mixture of sinusoids (4.46b), whose derivation is simplified by applying the principle of super-position. To put this to work, we restrict to the probing signal (4.46b), and for each $i$, consider the ODE

```
$\dot{\hat{\theta}}_t^i = \alpha[\hat{\theta}_t + v^i\sin(2\pi(\omega_it + \phi_i))]), \quad \dot{\hat{\theta}}_i = 0.$
```

The principle states that to solve this ODE can be represented as the sum

```
$\tilde{\theta}_t = e^{\alpha A}\tilde{\theta}_0 + B \sum_{i=1}^K \tilde{\theta}_i. \qquad (4.89)$
```

The response to initial error $\tilde{\theta}_0 = \theta_0 - \theta'$ decays to zero quickly. Consequently, to understand the steady-state behavior of the algorithm, it suffices to fix a single value of $i$. For more complex probing we again justify consideration of sinusoids. Let's keep things simple, and stick to sinusoids. And it is much easier to work with complex exponentials:

```
$\dot{\hat{\theta}}_t = \alpha[\hat{\theta}_t + v\exp(j\omega t)], \quad \dot{\hat{\theta}}_0 = 0,$
```

with $\omega \in \mathbb{R}$ and $v \in \mathbb{R}^d$ (dropping the scaling $2\pi$ and phase $\phi$ for simplicity). We can express the solution as a convolution

```
$\hat{\theta}_t = \alpha \int_0^t \exp(\alpha Ar)v\exp(j\omega(t-r))dr = \alpha \int_0^t \exp([\alpha A - j\omega I]r)v\exp(j\omega t)$
```

Writing $D = [\alpha A - j\omega I]$, the integral of the matrix exponential is expressed:

```
$\int_0^t e^{Dr} = D^{-1}[e^{Dt}-I].
```

# ODE Methods for Algorithm Design

Using linearity once more, and the fact that the imaginary part of $e^{j\omega}$ is $\sin(\omega)$, we arrive at a complete representation for (4.89):

**Proposition 4.16** Consider the linear model with $A$ Hurwitz, and probing signal (4.46b), the constant gain QSA ODE solution (4.89) $\Theta_t^i = \alpha W_t^i$ for each $i$ and $t$,

```
$W_t^i = \text{Im}([\alpha A - j\omega I]^{-1}[\exp(\alpha At) - I]). \quad (4.90)$
```

Proposition 4.16 addresses a challenge with large gains: If we want small $\alpha$ (or large $\omega_i$), the PJR averaging technique can be used to improve steady-state behavior:

**Corollary 4.17** Suppose that the assumptions of Proposition 4.16 hold, so in particular $f$ is linear. The averaged estimates (4.78) in $T_0 = T/\kappa$ for fixed $\kappa > 1$, then:

```
$\Theta_T^M = \theta^* + \frac{I}{\kappa}(\kappa M_T \theta_0 + B \sum_{i=1}^K M_T^i v^i)$
```where

```
$M_T = A^{-1}[\exp(\alpha AT) - \exp(\alpha AT_0)]$
```

$M_T^i$ is equal to the integral of $W_t^i$ appearing in (4.90):

```
$\Theta_T^i = \text{Im}([\alpha A - j\omega I]^{-1}[\exp(\alpha AT) - I]) + \kappa \text{Im}(\frac{j}{2\omega_i}[\alpha A - j\omega I]^{-1}[\exp(2\pi[\phi_i + \omega_i T_0)])$
```

Hence $\Theta_T^M$ converges to $\theta^*$ at rate $1/T$.

## 4.5.6 Zap QSA

What if $A^*$ is not Hurwitz? Or what the crucial stability assumption fails? Consider the two time-scale algorithm:

```
$\frac{\dot{\Theta}_t}{dt} = \frac{1}{1+\frac{g}{\rho}}[-A_t - I]^{-1}f(\Theta_t, \Xi_t)$
$\frac{\dot{A}_t}{dt} = \frac{g}{(1+\frac{g}{\rho})}[A_t - I], \quad A_t = \partial_\theta f(\Theta_t, \Xi_t). \quad (4.91)$
```

This is called Zap-QSA, designed to mimic the Newton-Raphson flow.

## 4.6 Gradient-Free Optimization

The second ODE is introduced so that $\hat{A}_t \approx A(\Theta_t) \nabla f(\Theta_t)$ (following a transient). This requires $0 < \rho < 1$, meaning we use the gain for the matrix estimate. To ensure a bounded inverse, we arrive at something more closely resembling the Newton–Raphson flow:

```
$$\frac{d}{dt} = \frac{1}{1+t}[-A(\Theta_t)]^{-1}[\hat{f}(\Theta_t) + \Xi_t]$$
```

where $\Xi_t = f(\Theta_t, \varepsilon_t) - \hat{f}(\Theta_t) + \varepsilon_t$; the error $\varepsilon_t$ comes from the approximation $\hat{A}_t \approx A(\Theta_t)$.

The most important motivation for the matrix gain in (4.91) is stability, by appealing to theory for Newton–Raphson flow. Zap QSA shows very fast convergence whenever the assumptions required for Newton-Raphson flow are satisfied.
