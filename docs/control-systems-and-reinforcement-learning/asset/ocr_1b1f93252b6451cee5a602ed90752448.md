# 4.3 Newton–Raphson Flow

This section concerns approx about ODE design in which the goal is to solve the root finding problem (4.10). The parameter $	heta^*$ is regarded as an equilibrium condition for the ODE (4.2). The problem we face here is that ODE may not be stable in any sense. In this section, we describe a general approach to modify the dynamics and ensure stability.

Section 4.4 concerns root finding problems for the special case in which $f = -
abla_\Gamma f$, where $\Gamma: \mathbb{R}^d 	o \mathbb{R}^s$ is a loss function with some optimization problem. The root problem is then equivalent to the first-order condition for optimality, $
abla_\Gamma f(	heta^*) = 0$. If $f$ has nice properties (such as convexity), it is not difficult to ensure stability of (4.2) using Lyapunov function techniques (such results are surveyed in Section 4.4). The techniques in this section may provide useful applications for stability of (4.2) fails.

Our starting point is to regard $f(	heta_t)$ as the "state variable," and our next step is to define the dynamics so that $\lim_{t \to \infty} f(\theta_t) = 0$ for each initial condition. Under amid mild assumptions on $f$, it will follow $\lim_{t \to \infty} \theta_t = \theta^*$, which is our design objective.

If $f(	heta_t)$ is a state variable, this means there is an associated vector field $\mathcal{V}: \mathbb{R}^s 	o \mathbb{R}^d$, with

```
\frac{d}{dt}f(\theta_t) = \mathcal{V}(f(\theta_t)).
```

One way to ensure $f(\theta_t)$ converges to choose $\mathcal{V}(f) = -f$, giving

```
\frac{d}{dt}f(\theta_t) = -f(\theta_t).
```

The solution is $f(\theta_t) = e^{-t}f(\theta_0)$, which converges zero exponentially. Achieving these dynamics will be an amazing feat!

Well, it isnt so difficult to do. Apply the chain rule:

```
\frac{d}{dt}f(\theta_t) = A(\theta_t)\frac{d}{dt}\theta_t, \quad A(\theta_t) = \partial_\theta f(\theta_t), \quad \theta \in \mathbb{R}^d,
```

where $\partial_	heta f$ denotes the $d 	imes d$ Jacobian matrix with entries

```
A_{i,j}(	heta) = \frac{\partial^2}{\partial\theta_j}f_i(\theta).
```

This means that achieving the dynamics (4.11) is equivalent to

```
\frac{d}{dt}\theta_t = [A(\theta_t)]^{-1}\mathcal{V}(f(\theta_t)).
```
