## Partial Observations and Belief States

We now have an observation process $Y$, and no direct measurements of the state process $X$. This short survey concerns a model in which $X$, $Y$, and the input process $U$ takes values in finite sets, denoted $X$, $Y$, and $U$.

We continue to write $\Phi_n = (X_n, U_n)$ when convenient.

### C.1 POMDP Model

The state process is a controlled Markov chain before. The observation $Y_n$ is assumed to be a noisy, memoryless measurement of the state $X_n$. A family of pmfs on $\{q(\mid x) : x \in X\}$. For each $y \in Y$ and $x \in X$,

```
$P\{Y_n = y \mid \Phi_k, k \le n\} = q(y \mid x) \quad (C.1)$
```

Our goal remains the same: we want to optimize some performance criterion. This may be discounted cost, finite horizon, or the average cost, which has been the focus of the appendices up to now:

```
$\eta = \limsup_{T\to\infty} \frac{1}{T} \sum_{k=0}^{T-1} c(\Phi_k).$
```

The optimization problem becomes more complex when only $Y$ is available for choosing $U$.

It is rarely true that the optimal input is of the form $U_n = \Phi(Y_n)$. We need the full history in general: For a sequence of functions $\{\Phi_n\}$,

```
$U_n = \Phi_n(Y_0, \dots, Y_n). \quad (C.2)$
```

This sounds horrible, but we will discover beautiful structure.

## Partial Observations and Belief States

It is sometimes useful to view the pair (X, Y) as the state process for an MDP model:

```
$P\{X_{n+1} = x', Y_{n+1} = y | X_n = x, Y_n = y, U_n = u\}$$
$$
= f(x, u, N_{n+1}) = x' \text{ and } g(x', W_{n+1}) = y'$$
$$
= p(x' | x, u)q(y' | x').$ (C.4)
```

This gives the controlled transition matrix for the state-observation process:

```
$T_u(z, z') = p(x' | x, u)q(y' | x'), \quad \text{with } z = (x, y) \text{ and } z' = (x', y').$ (C.5)
```

Given observations of (X, Y), we can use our machinery to compute or approximate an optimal policy $U_n = \Phi^*(X_n)$.

However, the PO in POMDP stands for partial observations. This means that inputs are restricted to the form (C.2). We need to develop new tools to respect the limited information for control that is captured in (C.2).

## C.2 A Fully Observed MDP

The new state process $b_n : n \ge 0$ is also called the belief state, and coincides with the conditional distribution of the state given the observations: For each $x \in X$,

```
$b_n(x) = P\{X_n = x | Y_n\},$ (C.6)
```

in which $Y_n = \sigma(Y_k : k \le n)$. The belief state evolves on what is called the simplex of pmfs on $X$, denoted $S$. If $X$ consists of $d$ states,

```
$\mathcal{S} = \{b \in \mathbb{R}^+ : \sum_{i} b(i) = 1\}.$


The definition implies that for any function $h$,

```
$E[h(X_n) | Y_n] = \sum_{x \in X} b_n(x)h(x).$
```

In this short survey, we restrict to the finite horizon problem to explain the MDP. The extension to average cost and discounted cost will be obvious. For fixed $N \ge 1$ and $0 \le n < N$, assume that some input has been applied for $k < n$, and denote the cost to go by function,

```
$V_{n,N}^* = \min_{U_n, \dots, U_{N-1}} E[\sum_{k=n}^{N-1} c(\Phi_k) + V_0(X_N) | Y_n].$
```

This is random and grows in complexity with $n$, since $V_{n,N}^*$ is a function of $Y_0, \dots, Y_n$. In order to mimic the characterization of optimal policies from the fully observed setting, we require a sufficient statistic $I=\{I_0, \dots, I_n\}$ evolving over some space, such that for some function $V_{n,N}^*$,

```
$V_{n,N}^* = V_{N-n}(I_n).
```

Since this is time-homogeneous model, we might hope to have $V_{n,N}^* = V_{N-n}(I_n)$ for a sequence of functions $\{V_m^* : m \ge 0\}$. The amazing conclusion is: a sufficient statistic exists with $I_n=b_n$, for which the belief $b_n$ is sometimes called the information state. Moreover the stochastic process $b=\{b_0,b_1,\dots\}$ is itself a controlled Markov model that is fully observed. The Markov property is explained in Proposition C.1. A deterministic Markov policy is defined via $U=\Phi(b)$, where $\Phi: S \to U$ states that for each $n \ge 0$,

```
$b_{n+1} = \mathcal{M}(b_n, Y_{n+1}), \quad (C.8)
```

From this, a specific formula for the transition kernel for $\{b_n\}$ is obtained in (C.9). The proof is postponed to Section C.3

**Proposition C.1 (Transition Law for the Belief State)** The following properties hold: for any admissible $U$, any set $S \subset S$, and any $y' \in Y$,

```
$P(b_{n+1} \in S, Y_{n+1} = y' | b_n=b, U_n) = P(b_{n+1} \in S | b_n, U_n),$
```

The transition kernel for the belief state is given as: for any $b \in S, u \in U$, and any $S \subset S$,

```
$P(b_{n+1} \in S, b_n=b, U_n=u) = \sum_{y'} \mathbb{1}\{\mathcal{M}(b,y',u) \in S\} \left( \sum_{x,x' \in X} b(x)P_u(x,x')q(y' | x') \right). \quad (C.9)
```

Moreover, for any function $F: S \times Y \to \mathbb{R}$,

```
$E[F(b_{n+1}, Y_{n+1}) | Y_n=b, U_n=u] = \sum_{y'} \sum_{x'} b(x)P_u(x,x')q(y' | x')F(\mathcal{M}(b,y',u)).
```

The representation of the cost to go is given in the following:

**Proposition C.2** For any $b \in S$ and $u \in U$, denote the following:

```
$C(b,u) \stackrel{\text{def}}{=}sum_x b(x)c(x,u), \quad \mathcal{V}_0(u) \stackrel{\text{def}}{=}sum_x b(x)V_0(x). \quad (C.10)
```

Then the cost admits the representation

```
$V_{n,N}^* = V_{N-n}^*(b_n) = \min_{U_n^{N-1}} E \left[ \sum_{k=n}^{N-1} C(b_k, U_k) + \mathcal{V}_0(b_N) \mid b_n \right]. \quad (C.11)$
```

Proof The cost function $c : X \times U \to \mathbb{R}$ and the terminal cost $V_0$ are replaced with functions of the belief state by applying the smoothing property of conditional expectation: For any admissible $U$ and $k, N \geq n$,

```
$E[c(X_k, U_k) \mid \mathcal{Y}_n] = E[C(b_k, U_k) \mid \mathcal{Y}_n],\
$C(b_k, U_k) \stackrel{\text{def}}{=}sum_x b_k(x)c(x, U_k) = E[c(X_k, U_k) \mid \mathcal{Y}_n].$
```

```
$E[V_0(X_n) \mid \mathcal{Y}_n] = E[V_0(b_n) \mid \mathcal{Y}_n],\n$V_0(b_n) \stackrel{\text{def}}{=}sum_x b_n(x)V_0(b_n).$
```

Consequently, the (possibly nonoptimal) cost admits the representation

```
$V_{n,N} = \stackrel{\text{def}}{=} E \left[ \sum_{k=n}^{N-1} c(X_k, U_k) + V_0(X_N) \mid \mathcal{Y}_n \right],\n E \left[ \sum_{k=n}^{N-1} c(b_k, U_k) + \mathcal{V}_0(b_N) \mid \mathcal{Y}_n \right],\n$= E \left[ \sum_{k=n}^{N-1} c(b_k, U_k) + \mathcal{V}_0(b_n) \mid b_n, U_n \right]$.
```

where the final equality follows from Proposition C.1. On minimizing over admissible inputs, we obtain the representation (C.11).
