# 10.6 SGD without Bias

We disregard any part of $\Lambda^	heta_-$ that does not depend upon $u$. Let $\mathcal{F}_k^-$ denote the partial history up to time $k$:

```
$$\mathcal{F}_k=\{X(k), \Phi(i) : 0 \leq i \leq k-1\}..$
```

This is the entire history to $k$, except that $U(k)$ is discarded.

**Lemma 10.20** *For any initial distribution for $X(0)$, $E[\Lambda^	heta(\Phi(k)) | \mathcal{F}_k] = 0$. Consequently,

+   (i) $\Lambda^	heta(\Phi(k)) : k \geq 0$ is a martingale difference sequence.
(ii) For any function $g: X \to \mathbb{R}$,

```
$0 = E[g(X(k))\Lambda^	heta(\Phi(k))].$
```

*Proof* From the definitions, we have the following for any $k$ and $x$ in $X$:

```
$E[\Lambda^	heta(\Phi(k)) | \mathcal{F}_k : X(k) = x] = \sum_{u} \Lambda^	heta(x,u)\phi^	heta(u | x).$
```

Given the definition $\Lambda^	heta(x,u) = \nabla_theta\phi^	heta (u | x)/\phi^	heta (u | x)$, it follows that

```
$E[\Lambda^	heta(\Phi(k)) | \mathcal{F}_k : X(k) = x] = \sum_{u} \nabla_theta\phi^	heta (u | x) = \nabla_theta\sum_{u} \phi^	heta (u | x) = 0,$
```

the final equality holds because $\phi^	heta(\cdot | x)$ is a pmf for $U$ for each $x$. smoothing property of conditional expectation gives

```
$E[g(X(k))\Lambda^	heta(\Phi(k))] = E[g(X(k))\Lambda^	heta(X(k),U(k)) | \mathcal{F}_k] = 0.$
```

Lemma 10.20 implies that we can relax the definition of conditional features to read as follows: For each $\theta \in \mathbb{R}^d$ and $1 \leq i \leq d$, there is a function $G^	heta: X \to \mathbb{R}$ such that

```
$$\Lambda^	heta - G^	heta \in \mathcal{H}^	heta.$
```

Gibbs Policy consider for each policy $\theta$

Given a $d$-dimensional vector $\psi^	heta$, consider for each policy $\theta$

```
$$\phi^	heta (u | x) = \frac{1}{\kappa(\theta,x)} \exp(\theta^T\psi^	heta(x,u))..$
```

where $\kappa$ is a normalizing constant (recall 9.46). We then have the following from the definitions:

**Lemma 10.21** *For the Gibbs policy

```
$$\Lambda^	heta(x,u) \overset{\text{=}}{=} \psi^	heta(x,u) - \psi^	heta(x), \ \psi^	heta(x) \overset{\text{=}}{=} \sum_{v} \phi^	heta (v | x)\psi^	heta(x,v)..$
```

Consequently, for this policy we can take $d' = d$ and $\mathcal{H}^	heta ={\omega^T\psi^	heta : \omega \in \mathbb{R}^d\}$ to ensure that the CFP is satisfied in the relaxed form (10.51). However, in the next subsection we see that it may be best to use $\mathcal{H}^	heta ={\omega^T\psi^	heta : \omega \in \mathbb{R}^d\}$.
