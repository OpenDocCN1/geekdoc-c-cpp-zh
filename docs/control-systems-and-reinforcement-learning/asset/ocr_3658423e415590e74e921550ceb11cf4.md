```
$\delta = \sum_{j} v(j)J(j) = J(N) = 0.$
```

To see that $G$ is finite valued, we establish an interpretation for each term in the sum: for $j < N$,

```
$(P - s \otimes v)^n(i,j) = 1\{x(n) = j\}, \quad \text{when } x(0) = i.$
```

The left-hand side is zero for any $i$ and $n \ge 1$ when $j = N$. Let $n_0 \ge 1$ be an integer for which $x(n) = N$ for $n \ge n_0$ and any initial condition. Then $G$ can be expressed as a finite sum:

```
$G = \sum_{n=0}^{\infty}(P - s \otimes v)^n.$
```

# 3.3.1 Discounted Cost

A more popular objective in the operations research literature is the *discounted-cost problem*:

```
$J^*(x) = \min_{u}^{\infty} \gamma^k c(x(k),u(k)), \quad x(0) = x \in X,$
```

with $\gamma \in (0,1)$ the *discount factor*. This solves the discounted-optimality equation

```
$J^*(x) = \min_{u}\{c(x,u) + \gamma J^*(F(x,u))}.$
```

The Q-function becomes $Q^*(x,u) \overset{\text{def}}{=} c(x,u) + \gamma J^*(F(x,u))$, so that $J^*(x) = \min_u Q^*(x,u)$.
