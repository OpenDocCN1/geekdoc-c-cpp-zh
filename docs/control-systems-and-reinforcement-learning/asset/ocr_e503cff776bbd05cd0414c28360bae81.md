# 9.4 TD($\lambda$) Learning

**Lemma 9.9** $A = -R^\psi$ if $\lambda = 0$ or $\lambda = 1$, for any $\gamma \in [0,1)$. Otherwise,

```
$A = -R(0) + (\lambda^{-1} - 1)\sum_{i=1}^{\infty}(\gamma\lambda)^i R(i)^	op \quad (9.41)$
```

with autocorrelation sequence $\{R(i)\}$ defined in (9.23).

Proof We start with the steady-state representation of the eligibility vector:

```
$\zeta_n = \sum_{i=0}^{\infty}(\lambda\gamma)^i\psi(X(n-i))$.
```

Applying (9.38) then we gives

```
$A = E_n[\zeta_n[\gamma\psi(X(n+1)) - \psi(X(n))]^	op] \\n = \sum_{i=0}^{\infty}\lambda^i E_n[\psi(X(n-i))(-\psi(X(n)) + \gamma\psi(X(n+1)))^	op] \\n = \sum_{i=0}^{\infty}(\lambda\gamma)^i\{-R(-i) + \gamma R(-i-1)\}$.
```

The representation (9.41) follows, using $R(-i) = R(i)^	op$.

Although TD($\lambda$) converges, the mean-square error may converge at a rate far slower than optimal. The optimal $O(1/n)$ rate can be achieved by using one of the techniques in Chapter 8: $\alpha_n = g/n$ with $g>0$ sufficiently, the use of Polyak-Ruppert averaging (8.10), or an appropriate matrix gain. One of the last approach is the stochastic Newton–Raphson algorithm (8.54), which is known as LSTD($\lambda$) in the present context.
