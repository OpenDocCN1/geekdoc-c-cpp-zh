# 4.8 Stability of ODEs

On denoting $f_r(	heta) = r^{-1}f(r	heta)$ for $	heta \in \mathbb{R}^d$, this becomes

```
$\frac{d}{dt}\theta_i^r = f_r(\theta^r).\quad\quad (4.112)$
```

Suppose that a limiting vector field exists:

```
$f_{\infty}(	heta) = \lim_{r\to\infty} f_r(\theta) = \lim_{r\to\infty} r^{-1}f(r\theta),\quad\quad\theta \in \mathbb{R}^d.\quad\quad (4.113)$
```

and define the ODE at $\infty$ as the limiting case of (4.112):

```
$\frac{d}{dt}\theta_i^{\infty} = f_{\infty}(\theta^{\infty}),\quad\quad\theta^{\infty} \in \mathbb{R}^d.\quad\quad (4.114)$
```

We have $f_{\infty}(0)=0$ by (4.113), so the origin is an equilibrium of (4.114).

**Proposition 4.2** Suppose that $f$ is globally Lipschitz, with Lipschitz constant $L$. Suppose that the limit (4.113) exists for all $	heta$ to define a continuous function $f_{\infty}: \mathbb{R}^d \to \mathbb{R}^d$. Then, if the origin is asymptotically stable for (4.114), it follows that the ODE (4.2) is ultimately bounded.

To prove the proposition, we need to better understand the special properties of the solution to (4.114):

**Lemma 4.23** Suppose that the assumptions of Proposition 4.2 hold, in particular particular the origin is asymptotically stable for (4.114). Then the following holds:

+   (i) For each $	heta \in \mathbb{R}^d$ and $s \ge 0$,$
 f_{\infty}(s\theta) = sf_{\infty}(\theta).$

+   (ii) If $\{\theta_i^{\infty} : t \ge 0\}$ is any solution to the ODE (4.114), and $s>0$, then $\{y_i = s\theta_i^{\infty} : t \ge 0\}$ is also a solution, starting from $y_0 = s\theta_0^{\infty} \in \mathbb{R}^d$.

+   (iii) The origin is globally asymptotically stable for (4.114), and convergence to the origin is exponentially fast: For some $R < \infty$ and $\rho > 0$,

```
$\|\theta^{\infty}\| \le Re^{-\rho t}\|\theta_0^{\infty}\|,,\quad\quad\theta_0^{\infty} \in \mathbb{R}^d$.
```

Proof Consider the first scaling result in part (i): by the definition of (4.113), with $s>0$,

```
$f_{\infty}(s\theta) = \lim_{r\to\infty} r^{-1}f(r\theta) = s\lim_{r\to\infty} r^{-1}f(r\theta) = sf_{\infty}(\theta).$.
```

The case $s=0$ is trivial, it is clear that $f_{\infty}(0)=0$. This establishes (i).\nNext, write

```
$\theta^{\infty} = \theta_0^{\infty} + \int_0^t f_{\infty}(\theta^tau^{\infty})d\tau$.
```

Multiplying both sides by $s$ and applying (i) gives (ii).\nAsymptotic stability of the origin implies the following: There exists $\varepsilon > 0$ such that $\lim_{t\to\infty}\|\theta_i^{\infty}\|=0$ whenever $\|\theta_0^{\infty}\| \le \varepsilon$ and the convergence is uniform in the initial condition. Consequently, there exists $T_0>0$ such that

```
$\\|\theta^{\infty}\| \le \varepsilon,\quad\quad t \ge T_0$ whenever $\\|\theta_0^{\infty}\| \le \varepsilon$.
```
