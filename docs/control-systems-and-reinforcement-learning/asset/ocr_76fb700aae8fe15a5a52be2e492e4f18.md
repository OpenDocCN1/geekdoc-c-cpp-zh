# ODE Approximations

Just as in the previous chapter, ergodic allows for approximation of algorithms by simpler ODE approximations. In particular, consider a recursion of the form

$$\theta_{n+1} = \theta_n + \alpha_n f_{n+1}(\theta_n), \quad n \ge 0. $$$

in which $\{f_n\}$ is a sequence of functions that approach an ergodic limit:

$$\f(\theta) = \lim_{N \to \infty} \frac{1}{N} \sum f_k(\theta), \quad \theta \in \mathbb{R}^d. $$$

The associated ODE is defined using this vector field:

$$\frac{d}{dt}\theta_t = f(\theta_t). $$$

An ODE approximation is defined by the naive Euler construction: the time scale is defined by the nondecreasing time points $\tau_0=0$ and $\tau_n = \sum_0^n \alpha_k$ for $n \ge 1$. Define a continuous process by $\Theta_{	au_n} = \theta_n$ for each $n$, and extend to all $t$ through piecewise linear interpolation. Let $[\theta_t^* : t \ge \tau_n]$ denote the solution to the ODE (5.25) with initial condition $\theta_{	au_0}^* = \theta_0$. We will then show that the algorithm (5.25) an **ODE approximation** for each initial condition $\theta_0$ and $N > 0$,

$$\lim_{n \to \infty} \sup_{\tau_n \le \tau \le \tau_{n+N}} ||\Theta_	au - \theta_	au^*|| = 0. $$$
