# 4.8.1 Grönwall’s Inequality

Proof of Grönwall’s Inequality, Proposition 4.2 Consider first the simpler inequality (4.7):

```
z_t = \gamma_t + \int_0^t \beta_s z_s ds.
```

Observe that $\gamma$ is continuous, under the assumption that $z$ and $\beta$ are continuous. We can "solve" this equation through the construction of a state space model with $x_t = z_t - \gamma_t$, and output $z_t$. From the integral equation

```
x_t = \int_0^t \beta_s [x_s + \gamma_s] ds,
```

We obtain the time-varying state space model

```
\frac{d}{dt}x_t = \beta_t x_t + \beta_t \gamma_t, \quad z_t = x_t + \gamma_t
```

with initial condition $x_0 = z_0 - \gamma_0 = 0$. This linear state space model, with "input" $u_t = \beta_t \gamma_t$, has an explicit solution:

```
x_t = \int_0^t u_s \exp(\int_s^t \beta_r dr) ds.
```
