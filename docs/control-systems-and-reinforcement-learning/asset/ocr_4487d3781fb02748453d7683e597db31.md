# ODE Methods for Algorithm Design

A model-free representation is obtained, recognizing that for any state-input pair $(x_t, u_t)$,

```
$B^	heta(x_t, u_t) = -Q^	heta(x_t, u_t) + Q^	heta(x_t) + c(x_t, u_t) + \frac{1}{h}Q^	heta(x_t). \quad (4.58)$
```

The error $B^	heta(x_t, u_t)$ can be observed without knowledge of the dynamics $f$ or over the cost $c$. The goal is to find $	heta^*$ that minimizes the mean-square error:

```
$\|B^	heta\|^2_{\lim_{T\to\infty} \int_0^T [B^	heta(x_t, u_t)]^2 dt. \quad (4.59)$
```

We choose a feedback law with "exploration" of the form introduced in Section 2.5.3:

```
$u_t = \Phi(x_t, \mathcal{L}_t), \quad (4.60)$
```

so that the resulting trajectories are bounded for any initial condition, and the joint process $(x, u, \mathcal{L})$ is an "ergodic steady state" (meaning the existence of sample paths such as (4.59) is guaranteed).

This approximation technique defines an approximate version of PIA: Given a policy $\phi$ and approximation $\hat{Q}$, the policy is updated:

```
$$\phi(x) = \arg\min_u Q(x, u). \quad (4.61)$
```

This procedure is repeated to obtain a recursive algorithm.

# Least Squares loss

Consider the loss function

```
$$\Gamma(\theta) = \lim_{T\to\infty} \lim_{T\to\infty} \int_0^T \frac{1}{2}[B^	heta(x_t, u_t)]^2 dt.$
```

Suppose that the approximation architecture is linear of (3.43), so that $\Gamma_T$ is a quadratic function of $	heta$:

```
$$\Gamma(\theta) = \theta^T M_T \theta - 2b_T^T \theta + \Gamma_T(0) = (\theta - \theta^*)^T M_T (\theta - \theta^*) + \Gamma_T(\theta^*).$
```

We leave it to the reader to find expressions for $M_T, b_T$, and $\Gamma_T(0)$.

In this special case, we do not need gradient descent techniques: the matrices $M_T$ and $b_T$ are obtained as sample-path averages–the Monte Carlo approach surveyed in Section 4.5.1– and then $	heta^* = M_T^{-1}b_T$ is the unique minimizer of $\Gamma_T$.
