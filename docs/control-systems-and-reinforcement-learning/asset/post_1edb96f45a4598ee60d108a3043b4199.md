
# 194 Value Function Approximations

This section might be regarded as a review of techniques used in stochastic control and RL for Markovian models.

To keep notation simple, let's assume that $X$ and $U$ are finite. There are no special input constraints: $U(x) = U$ for each $x \neq x^e$, but we require $u(k) = u^e$ when $x(k) = x^e$, so that $U(x^e) = \{u^e\}$. The equilibrium satisfies by definition $x^e = F(x^e, u^e)$. The cost is nonnegative, with $c(x^e, u^e) = 0$.

The variables in the LP consist of nonnegative functions on $X \times U$. Utilization requires a different perspective on optimal control. For any input sequence $\omega$, we define what is known as the (conditional) occupancy pmf:

$$\omega(x, u | x_0) = \sum_{k=0}^{\infty} \mathbb{1}\{x(k)=x, u(k)=u\}, \quad (x, u) \in X \times U, x \neq x^e$$

where $x$ is the state process with initial condition $x_0$ and input $\omega$. For notational convenience, we set $\omega(x, u | x_0) = 0$ for any $u$. A bit of accounting gives:

$$\sum_{x,u} c(x, u)\omega(x, u | x_0) = J(x_0) = \sum_{k=0}^{\infty} c(x(k), u(k)), \quad x(0)=x_0$$

Part of this including these assumptions: $c(x^e, u^e) = 0$ and $U(x^e) = \{u^e\}$. We then define the following for a given pmf $\omega$ on $X$:

$$\omega(x) = \sum_{x_0} \omega(x, u | x_0).$$

This has a very different interpretation than the steady-state probability measure introduced in (5.22). The function $\omega : X \times U \rightarrow \mathbb{R}_+$ is an example of a feasible variable for the LP to be constructed, with the following objective function:

$$\omega(c) = \sum_{x,u} c(x, u)\omega(x, u) = \langle\nu, J\rangle.$$

The constraints in the LP require further effort. For any occupancy pmf and each $x$:

$$\omega(x) = \sum_{u} \omega(x, u),$$

and when $\omega(x) > 0$, we denote:

$$\Phi(u | x) = \frac{\omega(x, u)}{\omega(x)}. \quad 5.81$$

In stochastic control, this is viewed as a random policy: $\phi(u | x)$ is the probability that $u(k) = u$ when $x(k) = x$. More notation from stochastic control is a mapping $P$: For any occupation measure $\omega$, let $\omega_x^* = P$ be defined by:

$$\omega_x^*(x) = \sum_{x^-, u^-} \omega(x^-, u^-)\mathbb{1}\{F(x^-, u^-) = x\}$$

# 5.7 Duality

The representation $\pi_x = u + \pi P$ provides the constraint (5.82b) in the following LP:

$$\min_{\pi} \langle \pi, c \rangle \quad (5.82a)$$
$$\text{s.t. } \sum_{u} \pi(x,u) = \nu(x) + \sum_{x^-,u^-} \pi(x,u^-)\mathbb{1}\{F(x^-,u^-) = x\}, \quad x \neq x^c, \quad (5.82b)$$
$$\sum_{u} \pi(x^c,u) = 0, \quad (5.82c)$$
$$\pi(x,u) \geq 0, \quad (x,u) \in X \times U. \quad (5.82d)$$

**Proposition 5.1** *If $J^*$ is finite, then the following holds:*

- (i) If $\pi$ satisfies Equations (5.82b) to (5.82d), then $\langle \pi, c \rangle \geq \langle \nu, J^* \rangle$.
- (ii) The LP (5.82) has a solution $\pi^*$ satisfying $\langle \pi^*, c \rangle = \langle \nu, J^* \rangle$.
- (iii) If $\phi^*$ is an optimal policy, then one optimal solution matches the decomposition:

$$\phi^*(x,u) = \mathbb{1}\{\phi^*(x) = u\}\phi^*(x). \quad (5.83)$$

**Proof** of the representation proof requires material from Part II. In particular, it requires familiarity with probability concepts beyond what was required to do this point in the book. If you have background in probability theory, then read on.

Parts (ii) and (iii) are constrained to Choose: $\omega^*$ to be the occupancy pmf with $\phi^*$. We move to (i): For any feasible $\pi$, we design an input sequence defined as a randomized function of the state using (5.81):

$$J^{\phi}(x_0) = \sum_{k=0}^{\infty} c(x(k), u(k)), \quad x(0) = x_0.$$

With assumption, $\pi(x^c) = 0$ is not a problem since we already assume $u(k) = u$ whenever $x(k) = x^c$. The policy is not defined for other states $x$ satisfying $\pi(x) = 0$, which is not a problem for a reason: Such states are never visited when this policy is used and initial condition satisfies $J^{\phi}(x_0) > 0$.

The proof of (i) is completed on establishing $\langle \omega, c \rangle = \langle \nu, J^* \rangle$, and that $J^{\phi}(x_0) \geq J^*(x_0)$ for any $x_0$.

Every linear program has a dual. Here it is simple to construct the dual following the steps in Section 4. The dual variable is a function $\lambda: X \to \mathbb{R}$ associated with constraint 5.82b, and the dual function is defined as policies:

$$\phi^*(\lambda) = \min_{\omega} \langle \omega, c \rangle + \langle \nu, \lambda \rangle$$
$$\text{s.t. } \sum_{u} \omega(x,u) = \nu(x) + \sum_{x^-,u^-} \omega(x,u^-)\mathbb{1}\{F(x^-,u^-) = x\}, \quad x \neq x^c, \quad (5.84a)$$
$$\omega(x,u) \geq 0, \quad (x,u) \in X \times U, \quad \omega(x^c) = 0. \quad (5.84b)$$

# Value Function Approximations

We impose the constraint $\lambda(x^e) = 0$ since (5.82b) is imposed only for $x \neq x^e$. The dual LP is by defining the maximum of $\varphi^*$ over all $\lambda$. The main conclusion is this dual is precisely the:

**Proposition 5.1** The dual function admits the representation

$$\varphi^*(\lambda) = \begin{cases} \langle \nu, \lambda \rangle & \text{if } c + \lambda - P\lambda \geq 0 \dots \\ -\infty & \text{else} \end{cases} \quad (5.85)$$

If $J^*$ is finite, then $\varphi^*(\lambda) \leq \langle \nu, J^* \rangle$ for any $\lambda$, and this bound is achieved using $\lambda^* = J^*$.

Proof Using this identity: $\lambda(F(x,u))$ it follows that the objective can be expressed:

$$\varphi^*(\lambda) = \min_{\omega} \langle \omega, c - \lambda + P\lambda \rangle + \langle \nu, \lambda \rangle$$

subject to the constraints (5.84b), and where the value $\lambda^* = P\lambda$ is defined by

$$\lambda^*(x,u) = \lambda(F(x,u))$$

This implies (5.85). The bound $\varphi^*(\lambda) \leq \langle \nu, J^* \rangle$ holds because the constraint (5.82b) has been relaxed in (5.84) (this bound is known as weak duality). The fact that this upper bound is achieved using $\lambda^* = J^*$ is immediate from the dynamic programming equation that $J^*$ satisfies.
