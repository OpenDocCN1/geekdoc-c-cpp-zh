# 4.3 Newton–Raphson Flow

This section concerns approx about ODE design in which the goal is to solve the root finding problem (4.10). The parameter $\theta^*$ is regarded as an equilibrium condition for the ODE (4.2). The problem we face here is that ODE may not be stable in any sense. In this section, we describe a general approach to modify the dynamics and ensure stability.

Section 4.4 concerns root finding problems for the special case in which $f = -\nabla_\Gamma f$, where $\Gamma: \mathbb{R}^d \to \mathbb{R}^s$ is a loss function with some optimization problem. The root problem is then equivalent to the first-order condition for optimality, $\nabla_\Gamma f(\theta^*) = 0$. If $f$ has nice properties (such as convexity), it is not difficult to ensure stability of (4.2) using Lyapunov function techniques (such results are surveyed in Section 4.4). The techniques in this section may provide useful applications for stability of (4.2) fails.

Our starting point is to regard $f(\theta_t)$ as the "state variable," and our next step is to define the dynamics so that $\lim_{t \to \infty} f(\theta_t) = 0$ for each initial condition. Under amid mild assumptions on $f$, it will follow $\lim_{t \to \infty} \theta_t = \theta^*$, which is our design objective.

If $f(\theta_t)$ is a state variable, this means there is an associated vector field $\mathcal{V}: \mathbb{R}^s \to \mathbb{R}^d$, with

```
\frac{d}{dt}f(\theta_t) = \mathcal{V}(f(\theta_t)).
```

One way to ensure $f(\theta_t)$ converges to choose $\mathcal{V}(f) = -f$, giving

```
\frac{d}{dt}f(\theta_t) = -f(\theta_t).
```

The solution is $f(\theta_t) = e^{-t}f(\theta_0)$, which converges zero exponentially. Achieving these dynamics will be an amazing feat!

Well, it isnt so difficult to do. Apply the chain rule:

```
\frac{d}{dt}f(\theta_t) = A(\theta_t)\frac{d}{dt}\theta_t, \quad A(\theta_t) = \partial_\theta f(\theta_t), \quad \theta \in \mathbb{R}^d,
```

where $\partial_\theta f$ denotes the $d \times d$ Jacobian matrix with entries

```
A_{i,j}(\theta) = \frac{\partial^2}{\partial\theta_j}f_i(\theta).
```

This means that achieving the dynamics (4.11) is equivalent to

```
\frac{d}{dt}\theta_t = [A(\theta_t)]^{-1}\mathcal{V}(f(\theta_t)).
```

Application of this identity for the special case $\mathcal{V}(f) = -f$ results in a famous ODE:

# Newton–Raphson Flow

```
$$\frac{d}{dt}\partial_t = -[A(\partial_t)]^{-1}\mathbf{f}(\partial_t). \quad (4.14a)$$
```

The function on the right-hand side is the Newton–Raphson vector field

```
$$\mathbf{f}^{rn}(\theta) = -[A(\theta)]^{-1}\mathbf{f}(\theta). \quad (4.14b)$$
```

In most applications, it is not possible to determine a priori if the matrix $A(\theta) = \partial_\theta\mathbf{f}(\theta)$ is full rank, which motivates a regularized Newton–Raphson flow: For fixed $\varepsilon > 0$,

```
$$\frac{d}{dt}\partial_t = G(\partial_t)\mathbf{f}(\partial_t). \quad (4.15)$$
```

$G(\theta) \stackrel{\text{def}}{=} -[I + A(\theta)^T A(\theta^*)]^{-1}A(\theta^*)$ is an approximation of the pseudo-inverse of $-A(\theta)$. It is shown in Proposition 4.4 that solutions to (4.15) are bounded in time, provided $V = ||\mathbf{f}||^2$ is a coercive function on $\mathbb{R}^d$. Mild conditions imply that $V$ serves as a Lyapunov function for (4.15),

```
$$\lim_{t\to\infty} \partial_t = 0. \quad (4.16)$$
```

**Proposition 4.4** Consider the following conditions for the function $\mathbf{f}$:

- (a) f is Lipschitz continuous and continuously differentiable. Hence $A(\cdot)$ is a bounded and continuous matrix-valued function.
- (b) $||\mathbf{f}||$ is coercive. That is, the set $\{||\mathbf{f}|| \le n\}$ is bounded for each $n$.
- (c) The function $\mathbf{f}$ has a unique root $\theta^*$, and $A^T(\theta)\mathbf{f}(\theta) \neq 0$ for $\theta \neq \theta^*$. Moreover the matrix $A(\theta^*)$ is nonsingular.

The following hold for solutions to the ODE (4.15) under increasingly strong assumptions:

- (i) If (a) holds, for each $t$, and each initial condition,
```
$$\frac{d}{dt}\partial_t = -A(\partial_t)[I + A(\partial_t)^T]^{-1}A^T(\partial_t)\mathbf{f}(\partial_t). \quad (4.17)$$
```
- (ii) If in addition (b) holds
```
$$\lim_{t\to\infty} \partial_t^T\mathbf{f}(\partial_t) = 0. \quad (4.18)$$
```
- (iii) If (a)-(c) holds, (4.15) is globally stable.

Proof The result (ii) follows from chain rule and the definitions. The result of (ii) follows on Lyapunov function $V(\partial_t) = \frac{1}{2}||\mathbf{f}(\partial_t)||^2$ combined with:

```
$$\frac{d}{dt}V(\partial_t) = -\mathbf{f}(\partial_t)^T A(\partial_t)[I + A(\partial_t)^T]^{-1}A^T(\partial_t)\mathbf{f}(\partial_t).$$
```

The right-hand side is nonpositive when $\partial_t \neq \theta^*$. Integrating each step for any $T > 0$,

```
$$V(\partial_T) = V(\partial_0) - \int_0^T \mathbf{f}(\partial_t)^T A(\partial_t)[I + A(\partial_t)^T]^{-1}A^T(\partial_t)\mathbf{f}(\partial_t)dt, \quad (4.19)$$
```

so that $V(\partial_T) \le V(\partial_0)$ for all $T$. Under coercive assumption, it follows that solutions to (4.15) are also bounded. Letting $T \to \infty$, we obtain from (4.19) the bound

```
$$\int_0^{\infty} f(\partial_t)^T A(\partial_t) (I + A(\partial_t)^T)^{-1} A^T(\partial_t)f(\partial_t) dt \le V(\partial_0).$$
```

Boundedness of $\partial_t$ and continuity of $A$ imply the existence of $B(\partial_0) < \infty$ such that $\int_0^{\infty} \gamma_t dt \le B(\partial_0) < \infty, \quad \gamma_t \stackrel{\text{def}}{=} \|A(\partial_t)f(\partial_t)\|_2^2.$

The functions $f$ and $A$ are Lipschitz continuous, and boundedness implies that $\gamma_t$ satisfies the Lipschitz condition in Lemma 4.3. Hence $\lim_{t\to\infty} \gamma_t = A(\theta^*)^2=0$ as claimed.

We next prove (iii). While from Proposition 2.5, we have the ingredients for a short alternative proof that offers additional insight.

Global asymptotic stability of (4.15) requires solutions to converge to $\theta^*$ from each initial condition, and that $\theta_t$ is stable in the sense of Lyapunov. Assumption (c) combined with (ii) gives us the fact, that $\lim_{t\to\infty} \theta_t = \theta^*$. A sufficient condition for the latter is obtained by considering $A_\theta = \nabla_\theta \Gamma(\theta)|_{\theta=\theta}$. Stability in the sense of Lyapunov holds if its eigenvalues are in the strict left-half plane in $\mathbb{C}$ [1, 2].

Applying the definitions, we obtain $A_\theta = -[I+M]^{-1}M$ with $M = A(\theta^*)^T A(\theta^*) > 0$ (recall that $A(\theta^*)$ is assumed to be non-singular). The eigenvalues of $A_\theta$ coincide with those of $M$, and for each eigenvalue-eigenvector pair we have

```
$A_\theta v = \lambda_A v, \quad \lambda_A = -\frac{\lambda}{\varepsilon + \lambda} < 0.$
```

This establishes that $A_\theta$ is Hurwitz.

# 4.4 Optimization

Here we turn to minimization of a loss function $\Gamma: \mathbb{R}^d \to \mathbb{R}_+$, for which we would like to compute a global minimum:

```
$$\theta^* \in \arg\min \Gamma(\theta).$$
```

This section contains a brief survey of optimization and ODE techniques to estimate $\theta^*$. In particular, we establish conditions under which the steepest-ODE exists converges:

```
$\frac{d\theta}{dt} = -\nabla\Gamma(\theta). \quad (4.20)$
```

This is also known as the *gradient flow*.

Recall that the gradient $\nabla\Gamma$ at a vector $\theta_0 \in \mathbb{R}^d$ is orthogonal to the level set $\{\theta \in \mathbb{R}^d : \Gamma(\theta) = \Gamma(\theta_0)\}$, in the sense illustrated in Figure 4.1. For a given time $t_0$, denote $\theta_0 = \theta_{t_0}, r_0 = \Gamma(\theta_0)$, and recall from (2.28) the definition of the level set is

```
$S_\Gamma(r_0) = \{\theta \in \mathbb{R}^d : \Gamma(\theta) \le r_0\}.
```

If the gradient at $\theta_0$ is nonzero, in the example shown, the gradient flow drives the solution into the interior of this set: $\Gamma(\theta_t) < r_0$ for all $t > t_0$. In particular, each sublevel is **absorbing**; once a solution to the gradient flow enters the set $S_\Gamma(r_0)$, it can never leave.
