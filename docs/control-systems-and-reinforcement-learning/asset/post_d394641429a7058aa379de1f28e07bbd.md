In practice, the $L$-smooth inequality for $\Gamma$ is usually verified via a global Lipschitz condition on its gradient:

$\|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\| \le L|\theta' - \theta|.$ (4.29)

**Lemma 4.10** Suppose that (4.29) holds for all $\theta, \theta' \in \Theta$, where $\Theta \subseteq \mathbb{R}^d$. We then have:

- (i) $\|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\|^2 \le L|\theta' - \theta\|^2$ for all $\theta, \theta' \in \Theta$.
- (ii) If $\Theta$ is convex, then $\Gamma$ is $L$-smooth.

*Proof* (i) is immediate from (4.29):

$\|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\| \le \|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\|\|\theta' - \theta\| \le L|\theta' - \theta\|^2.$

To establish this, for $\theta \in \Theta$ denote $\theta_t = \theta + t(\theta' - \theta)$ and $\xi_t = \Gamma(\theta_t)$. We have $\theta_t \in \Theta$ for $0 \le t \le 1$ under the convexity assumption. The function is differentiable on this domain, with $\frac{d}{dt}\xi_t = \nabla\Gamma(\theta_t)(\theta' - \theta).$ Applying (i):

$\xi_t - \xi_0 = \Gamma(\theta_t) - \Gamma(\theta_0) - \nabla\Gamma(\theta_0)(\theta' - \theta) \le tL|\theta' - \theta\|^2.$

Integrating from $t=0$ to $t=1$ gives (4.22):

$\Gamma(\theta') = \Gamma(\theta_1) = \Gamma(\theta_0) + \int_0^1 \xi_t dt$
$\le \Gamma_0 + \xi_0 + \frac{1}{2}L|\theta' - \theta\|^2$
$= \Gamma(\theta) + \langle\nabla\Gamma(\theta_0), \theta' - \theta\rangle + \frac{1}{2}L|\theta' - \theta\|^2.$

## 4.4.4 Constrained Optimization

Consider the optimization problem with equality constraints:

$\Gamma^* = \min_{\theta} \Gamma(\theta) \text{ s.t. } g(\theta) = 0,$ (4.30)

where $g: \mathbb{R}^d \to \mathbb{R}^m$ (so there are $m \ge 1$ constraints). The constraints are convex if and only if $g$ is an affine function of $\theta$: For an $m \times d$ matrix $D$ and vector $d \in \mathbb{R}^m$,

$g(\theta) = D\theta + d.$ (4.31)

One approach to the solution of these problems is through a Lagrangian relaxation, defined through a sequence of steps. Introducing the Lagrangian $\mathcal{L}: \mathbb{R}^d \times \mathbb{R}^m \to \mathbb{R}$:

$\mathcal{L}(\theta, \lambda) = \Gamma(\theta) + \lambda^Tg(\theta), \quad \theta \in \mathbb{R}^d, \quad \lambda \in \mathbb{R}^m.$ (4.32)

The so-called dual function is the minimum of the Lagrangian, with constraints removed:

$$\varphi^*(\lambda) = \min_{\theta} \mathcal{L}(\theta, \lambda). \quad (4.33)$$

The value $-\infty$ is possible: Consider what happens when $\Gamma$ is a linear function of $\theta$. For any $\lambda \in \mathbb{R}^m$, we obtain a lower bound on $\Gamma$ as follows:

$$\varphi^*(\lambda) \leq \min_{\theta} [\mathcal{L}(\theta, \lambda) : g(\theta) = 0] = \min_{\theta} [\Gamma(\theta) : g(\theta) = 0] = \Gamma^*,$$

where the inequality holds because we have reintroduced the constraints, which means we are minimizing $\mathcal{L}$ over a potentially smaller set. The dual problem is defined to be the maximum of $\varphi^*$ over all $\lambda$:

$$\max_{\lambda} \mathcal{L}(\theta, \lambda) = \varphi^*(\lambda) \leq \Gamma^*. \quad (4.34)$$

We say there is duality gap if the inequality is strict. The left-hand side is called a min-max (or saddle point) problem. Figure 4.2 shows a typical example of convex optimization without duality gap. There is a simple ODE to obtain a solution to saddle point problem (4.34), known as the primal-dual flow:

$$\frac{d\theta}{dt} = \nabla_{\theta} \mathcal{L}(\theta, \lambda) = -\nabla\Gamma(\theta) - [\nabla g(\theta)]^T\lambda, \quad (4.35a)$$
$$\frac{d\lambda}{dt} = \nabla_{\lambda} \mathcal{L}(\theta, \lambda) = g(\theta), \quad (4.35b)$$

where, under affine assumption, $[\nabla g(\theta)]^T = D^T.$

**Proposition 4.11** Suppose that the following holds: (i) $\Gamma$ is strictly convex and coercive, and (ii) the function $g$ is affine, of form (4.31), in which $m \times d$ matrix $D$ has rank $m$. Then the primal-dual flow converges to the unique solution $(\theta^*, \lambda^*)$ of the: $\mathcal{L}(\theta^*, \lambda^*) = \varphi^*(\lambda^*) = \Gamma^*.$

The proof can be found in Section 4.8. The first step is to exploit convexity to show that $V(\theta, \lambda) = \frac{1}{2}\|\theta - \theta^*\|^2 + \|\lambda - \lambda^*\|^2$ is a Lyapunov function. This part of the proof is very similar to Proposition 4.7. The case of inequality constraints is considered next, where similar analysis can be applied.

## Inequality Constraints

We again have a function $g:\mathbb{R}^d \to \mathbb{R}^m$ that defines the constraints, but replace equality with inequality in the primal:

$$\Gamma^* = \min_{\theta} \Gamma(\theta) \text{ s.t. } g(\theta) \leq 0. \quad (4.36)$$

If $g_i$ is a convex function for each $i$ (or simply quasconvex), then the constraint region $S = \{\theta : g(\theta) \leq 0\}$ is a convex set. The Lagrangian and dual function $\varphi^*$ are defined exactly as before, but we restrict $\lambda \in \mathbb{R}^m$ to obtain the bound:

$$\varphi^*(\lambda) \leq \min_{\theta} \{\mathcal{L}(\theta, \lambda) : g(\theta) \leq 0\} \leq \min_{\theta} \{\Gamma(\theta) : g(\theta) \leq 0\} = \Gamma^*,$$

where the second inequality is based on the bound $\lambda^Tg(\theta) \leq 0$, whenever $g(\theta) \leq 0$ and $\lambda \geq 0$. The saddle point is defined as:

$$\mathcal{L}(\theta, \lambda) = \varphi^*(\lambda) = \Gamma^*. \quad (4.37)$$

Subject to convexity and minor additional assumptions, there is no duality gap (the inequality is replaced with equality). A pure ascent algorithm to compute $\lambda_t$ would be of form $\nabla\varphi^*(\lambda)$. In the case of inequality constraints considered, we must include a reflection process to ensure that $\lambda_t(i) \geq 0$ for each $i$ (details to follow). A representation of the dual is easily found. For each $\lambda \in \mathbb{R}^m$, there is $\varphi^*(\lambda)$ satisfying

$$\varphi^*(\lambda) = \min_{\theta} \{\Gamma(\theta) + \lambda^T g(\theta)\} = \Gamma(\theta^*) + \lambda^T g(\theta^*).$$

**Proposition 4.12** For each $\lambda^0 \in \mathbb{R}^m$, a subgradient of the dual function is given by $\nabla\varphi^*(\lambda^0) = [g(\theta^*)]^T$. That is, for all $\lambda \in \mathbb{R}^m_+$,

$$\varphi^*(\lambda) \leq \varphi^*(\lambda^0) + [g(\theta^*)]^T(\lambda - \lambda^0).$$

*Proof* We have by definitions

$$\varphi^*(\lambda) = \min_{\theta} \{\Gamma(\theta) + \lambda^T g(\theta)\} \leq \Gamma(\theta^0) + \lambda^T g(\theta^0)$$
$= [\Gamma(\theta^0) + \lambda^0 g(\theta^0)] + (\lambda - \lambda^0)^T g(\theta^0)$$
$= \varphi^*(\lambda^0) + [g(\theta^*)]^T(\lambda - \lambda^0). \quad \square$$

This inspires the primal-dual flow that is almost the same as (4.35). The ODE for the parameter estimate is identical:

$$\frac{d}{dt}\theta_t = -\Gamma(\theta_t) - [\nabla g(\theta_t)]^T \lambda_t.$$

The ODE for the dual variable $\lambda$ must be modified to ensure nonnegativity. This comes in the form of an $m$-dimensional reflection process $\gamma$. It is easiest to express the new dynamics in integral form

## 4.5 Quasistochastic Approximation

$$\lambda_t = \lambda_0 + \int_0^t g(\theta_r)dr + \gamma_t, \quad (4.38)$$

where $\lambda_0 \ge 0$ is the initial condition. The reflection process is defined by three constraints (for each $1 \le i \le m$):

- (1) $\gamma_0(i) = 0$.
- (2) $\gamma(i)$ is nondecreasing, and the solution to (4.38) is nonnegative ($\lambda_t(i)$ is nonnegative for each $i$ and $t$).
- (3) It is the minimal function of time satisfying 1 and 2. This is equivalently expressed

$$\int_0^T \lambda_t(i)d\gamma_t = 0, \quad \text{for all } T > 0. \quad (4.39)$$

The integral (4.39) is defined in the sense of Riemann-Stieltjes, and by combining (1)-(3), we see that

$$\lambda_t(i) > 0 \implies \frac{d}{dt}\gamma_t(i) = 0.$$
