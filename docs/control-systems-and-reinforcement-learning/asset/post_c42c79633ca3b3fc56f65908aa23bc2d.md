**Proposition 3.9** Suppose that the value function $J^\star$ is finite valued, and the optimal policy $\phi^*(k)$ is stabilizing, in the sense that $x^*(k) \to x^\star$ as $k \to \infty$ for any initial condition.

Suppose that $J: X \to \mathbb{R}$, is continuous, vanishes at $x^\star$, and solves

$J(x) \le \min \{c(x,u)\}$

$J = J^\star$.

*Proof* Adopt the same notation in inverse dynamic programming: $\phi^j(x)$ is defined as a minimizer in (3.35) for each $x$, and $J^j$ the associated value function (3.34). We have the bound $J^{N} \le J$ by the Comparison Theorem, Proposition 2.3. We can also establish the following by induction on $N$ (starting with (3.35)):

$J(x) \le \min_{u[0,N-1]} \{\sum_{k=0}^{N-1} c(x,u(k)) + J(x(N))\}N^{N-1} \le \sum_{k=0}^{N-1} c^*(x,u^*(k)) + J(x^*(N)), \quad x(0)=x, u^*(k)=\phi^*(x^*(k))$ for all $k$,

with the second inequality obtained because we replaced the minimum with a specific policy. We have $J^*(N) \to 0$ as $N \to \infty$ by the assumptions on $J$ and $\phi^*$, and hence $J \le J^\star$.

Putting these bounds together gives for all $x$,

$J^*(x) \le J^{\star} \le J(x) \le J^*(x)$,

which implies these functions coincide, and in particular $J = J^\star$.

*Proof of 3.8* The assumptions on $J$ and $c^j$ are imposed so that we may apply Proposition 2.3 for the state space model subject to $u(k) = \phi^j(k)$. (i) implies that $J^{jx}(x) \le J(x)$ for all $x$, and (iii) tells that $x^\star$ is globally stable under this policy. We can then apply Proposition 3.9 to establish equality:

$J(x) = J^{\star}(x) = \min_{u} \sum_{k=0}^{\infty} c^j(x^*(k),u(k))$.

In the proof of Proposition 3.9, the right-hand side can only be replaced by replacing the minimum with the optimal policy: $x(0) = x$,

$J^{\star}(x) = \sum_{k=0}^{\infty} c^j(x^*(k),u^*(k)) \le (1+j)J^*(x)$,

with the second inequality $c^j \le (1+j)c$.

# 3.5 Bellman Equation Is a Linear Program

One approach to control design is to introduce a family of value function approximations $\{J^\theta : \theta \in \mathbb{R}^d\}$, and compute the parameter $\theta^\star$ that minimizes the Bellman error, such as using the mean-square criterion (2.53). A significant challenge is that the loss function $\Gamma^\theta(J^\theta)$ is not convex, even when $J^\theta$ depends linearly on $\theta$.

# 3.6 Linear Quadratic Regulator

We obtain a convex optimization problem that is suitable for RL implementation by applying a common technique: Overparameterize the search space. The first step is to regard $J^*$ and $Q^*$ as independent variables, and regard (3.7a) as a linear constraint. Following this approach, we obtain a linear program that lends itself to RL algorithm design.

Naturally, a finite-dimensional linear program is finite if the state and action space are finite. In this case, as part of the algorithm we choose a weighting function $v$, and denote for any candidate approximation $J$,

$(v, J) \overset{def}{=} \sum_{x\in X} v(x)J(x)$.

It is assumed that $v(x) > 0$ for each $x$. In most cases, this is a probability mass function (pmf), meaning that in addition we assume $\sum v(x) = 1$. Even when the state space is not finite, $X = \mathbb{R}^n$, we continue to assume that $v$ has finite subset $\{x^i : 1 \le i \le M\}$. In this case, the definition becomes

$(v, J) \overset{def}{=} \sum_{i} v(x^i)J(x^i)$.

Proposition 3.10 states that the Bellman equation can be cast as a linear program.

**Proposition 3.10** Suppose that the value function $J^*$ defined in (3.2) is continuous, compact, and vanishes at infinity. The pair $(J,Q^*)$ solves the following linear program (LP) in the "variables" $(J,Q):

$\max_{J,Q} \langle v, J \rangle$ (3.36a)
s.t. $Q(x,u) \le c(x,u) + J(F(x,u))$, (3.36b)
$Q(x,u) \ge J(x),   x \in X, u \in U(x)$, (3.36c)
$J$ is continuous, and $J(x^*) = 0$. (3.36d)

The linear program will be called the dynamic programming program (DP). It reappears in Section 5.5 followed by several approaches to solve the DP equation. We can without loss of generality strengthen (3.36b) to equality $Q(x,u) = c(x,u) + J(F(x,u))$. Based on this substitution, the variable $Q$ is eliminated:

$\max \langle v, J \rangle$ (3.37a)
s.t. $c(x,u) + J(F(x,u)) \ge J(x), x \in X, u \in U(x)$. (3.37b)

This closely resembles what is found in stochastic control literature (see [10] for survey). The more complex LP (3.36) is introduced because it is easily adapted to RL applications.

# 3.6 Linear Quadratic Regulator

For the linear system model (2.3), it is known that the value function is quadratic $J^*(x) = x^T M^* x$ for each $x$. The Q-function is also quadratic. Combining the definition (3.7a) with the system model (2.3a),

$Q^*(x,u) = c(x,u) + J^*(Fx+u)$. (3.38)

The optimal value is obtained by minimizing the Q-function over $u$, which is easily done via the first-order condition for optimality:

$0 = \nabla_u Q^*(x,u) = Ru^* + G^T M^*(Fx+u)$

Under the assumption $R > 0$, it follows that $R+G^T M^* > 0$ (hence invertible). The minimizer $u^* = \phi^*(x)$ defines the optimal policy for linear state feedback:

$\phi^*(x) = -K^*x$ with $K^* = [R+G^T M^*]^{-1}G^T F$. (3.39)

To obtain $\phi^*$, we must compute the value function since $K^*$ depends on $M^* \ge 0$. This matrix solves a fixed point equation known as the algebraic Riccati equation (ARE):

$M^* = F^T(M^* - M^*G[R+G^T M^*]^{-1}G^T F) + S$. (3.40)

The derivation of the ARE for the linear quadratic regulator (LQR) in continuous time is found in Section 3.9.4. To understand the LP (3.36) in this special case, it is most convenient to express all three functions appearing in (3.36b) in the terms of $z^T = [x^T, u^T]^T$:

$J^*(x,u) = z^T M^* z, \quad Q^*(x,u) = z^T M^* z, \quad c(x,u) = z^T M^* z$. (3.41a)

$M^* = \begin{bmatrix} S & 0 \\ 0 & 0 \end{bmatrix}, \quad M^C = \begin{bmatrix} S & 0 \\ 0 & R \end{bmatrix}$. (3.41b)

$M^Q = M^C + \begin{bmatrix} F^T M^* F & F^T M^* G \\ G^T M^* F & G^T M^* G \end{bmatrix}$ (3.41c)

Justification of the formula for $M^*$ is contained in the proof of Proposition 3.11 that follows.

**Proposition 3.11** Suppose that $J^*$ is everywhere finite. Then the value function and Q-function are quadratic: $J^*(x) = x^T M^* x$ for each $x$, where $M^* \ge 0$ is a solution to the algebraic Riccati equation (3.40), and the quadratic Q-function is given in (3.41c). The matrix $M^*$ is also the solution to the following convex program:

$M^* \in \arg \max trace(M)$ (3.42a)
s.t. $\begin{bmatrix} F^T M F & F^T M G \\ G^T M F & G^T M G \end{bmatrix} \ge \begin{bmatrix} S & 0 \\ 0 & R \end{bmatrix}$ (3.42b)

where the maximum is over symmetric matrices $M$, and the inequality constraint (3.42b) is in the sense of symmetric matrices.

**Proof of Proposition 3.11** The reader is referred to standard texts for the derivation of the ARE [7, 76]. This is a following exercise: to prove that $J^*$ is a quadratic function of $x$, and you will find that the Bellman equation implies the ARE.
