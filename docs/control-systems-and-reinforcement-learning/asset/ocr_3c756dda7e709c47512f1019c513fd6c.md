Optimal Control

Assuming the value function is continuously differentiable, we may perform a Taylor series expansion using the optimality equation (3.49) to obtain

```
$J^*(x) = \min_{u(0,t_m)} \{c(x, u_0)t_m + J^*(x) + \nabla J^*(x) \cdot \Delta x_m\} + o(t_m)$.
```

The "little oh" notation $o(t_m)$ is recalled in Appendix A. Subtracting $J^*(x)$ from each side and dividing by $t_m$ then get

```
$0 = \min_{u(0,t_m)} \{c(x, u_0) + \nabla J^*(x) \cdot \frac{\Delta x_m}{t_m}\} + o(1).
```

Letting $t_m \to 0$, we obtain $u(0) \to 0$ by definition, and the ratio $\Delta x_m/t_m$ can be replaced by a derivative:

```
$\lim_{t_m\to0} \frac{\Delta x_m}{t_m}|_{t=0}=f(x,u_0)$.
```

This gives the following celebrated equation:

```
$0 = \min [c(x,u) + \nabla J^*(x) \cdot f(x,u)]. (3.50)
```

**Theorem 3.12** If the value $J^*$ has continuous derivatives, then it satisfies the HJB equation (3.50). Suppose that the minimum in (3.50) exists and is unique for each $x$, to form a continuous function $\phi^*$. Then the optimal control is expressed as state feedback:

```
$u_t^* = \phi^*(x^*) = \arg_u [c(x,u) + \nabla J^*(x^*) \cdot f(x^*,u)].$
```

The terms in (3.50) have an important interpretation in terms of the Hamiltonian,

```
$H(x,p,u) \overset{\texttext{Q}}{=} c(x,u) + p^T f(x,u).$ is the Q-function of reinforcement learning for models in continuous time. (3.51)
```

The function of two variables $Q(x,u)$ and $H(x,\nabla_x J^*(x))$ is the Q-function of reinforcement learning for models in continuous time.

The following result is a version of the **minimum principle** of optimal control.

**Theorem 3.13** Suppose that an optimal input-state pair exists, and that the value function $J^*$ has continuous derivatives. The optimal control $u^*$ must minimize the Hamiltonian for each time $t$,

```
$\min_u H(x^*,p_t^*,u) = H(x^*,p_t^*,u^*) $ (3.52)
```

with $p_t^* = \nabla_x J^*(x^*).$

The standard minimum principle does not hold. Rather, the vector valued "co-state" process $\{p_t^*\}$ is defined by another differential equation. This can provide enormous reduction in complexity since we do not need to compute the value.
