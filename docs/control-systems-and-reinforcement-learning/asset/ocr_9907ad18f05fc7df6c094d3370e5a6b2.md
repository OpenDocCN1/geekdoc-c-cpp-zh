```

```

For MDP models, the sequence of differences $\{h_n(x) = V_n(x) - V_n(x^*)\}$ consists of approximations of the relative value function. The convergence of $\{h_n\}$ to $h^*$ is illustrated in Figure 7.3 using $x^* = 0$. The error $\||h_{n+1} - h_n\|$ is much smaller for initial $n$ when the algorithm is initialized using the fluid value function.
