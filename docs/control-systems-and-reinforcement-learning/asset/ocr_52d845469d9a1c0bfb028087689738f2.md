# 10.7 Advantage and Control Variates

# 10.7.2 A Better Advantage

Consider a function classifying the CFP. Suppose that the input is not large, so that it is practical to compute $H_	heta^w(x)$ based on $H_	heta^w(x,u)$ for each observed $x \in X$. In this case, there is an alternative control variate, defined by a different sort of smoothing. It is no more complex and has lower variance.

For any $	heta$, $\omega$ and $x$ denote

```
$$\Delta_	heta^w(x) = E[\Lambda^	heta(\phi(n))H_	heta^w(\phi(n)) | \mathcal{F}_n ; X(n)=x]$$
```

with $\{\mathcal{F}_k\}$ defined in (10.50). Applying the definition of conditional mean using $\phi^0$ gives

```
$$\Delta_	heta^w(x) = \sum_u \nabla_\phi^0(u|x)H_	heta^w(x,u), \quad x \in X.$$
```

From the smoothing property of conditional expectation, we obtain a new unbiased algorithm by “smoothing” (10.44a):

```
$$\theta_{n+1} = \theta_n - \alpha_n + \nabla{\hat{\Gamma}}_r^v(n), \quad \nabla{\hat{\Gamma}}_r^w(n) \stackrel{\text{def}}{=} \hat{\Delta}_{\theta}^w(X(n)). \quad \quad (10.44a^{**})$$
```

We see that $
abla{\hat{\Gamma}}_r^v(n)$ has lower variance when compared to $
abla{\hat{\Gamma}}_r^w(n)$ in (10.44a). More important is a comparison of the respect asymptotic covariance matrices $\Sigma_\Delta$, as defined in (8.27). The first step in this comparison is to consider the gradient estimates evaluated at the optimal parameters. If $\nabla L(\theta^*)=0$ for any limit of either, the following two processes have zero mean for the process $\mathcal{F}$ in steady state:

```
$$\Delta_n^{\infty,v} = \nabla{\hat{\Gamma}}_r^v(n) \stackrel{\text{def}}{=} \hat{\Delta}_{\theta}^v(\Phi(n))V_{\theta*}^w(\Phi(n)),$
```

```
$$\Delta_n^{\infty,w} = \nabla{\hat{\Gamma}}_r^w(n) \stackrel{\text{def}}{=} \hat{\Delta}_{\theta}^w(X(n)).$
```

The respective asymptotic covariance matrices are denoted

```
$$\Sigma_{n}^{\infty,\Delta} = \sum_{n=-\infty}^{\infty} E[\nabla{\hat{\Gamma}}_r^v(n)(\nabla{\hat{\Gamma}}_r^v(0))^T], \quad \text{and} \quad \Sigma_{n}^{\infty,\Delta} = \sum_{n=-\infty}^{\infty} E[\nabla{\hat{\Gamma}}_r^w(n)(\nabla{\hat{\Gamma}}_r^w(0))^T].$
```

Proposition **10.22** We have, for any n,

```
$$\nabla{\hat{\Gamma}}_r^v(n) = (n) + \Delta_{\theta}^A_,$$
```

where $\{\Delta_{\theta}^A\}$ is a martingale difference sequence, satisfying $E[\Delta_{\theta}^A | \mathcal{F}_n]=0$. Consequently,

+   (i) The asymptotic covariances are ordered:

```
$$\Cov(\nabla{\hat{\Gamma}}_r^{v,\infty}(n)) = Cov(\nabla{\hat{\Gamma}}_r^{v,\infty}(n)) + Cov(\Delta_{\theta}^A(n)) \ge Cov(\nabla{\hat{\Gamma}}_r^{v,\infty}(n)).$$
```

+   (ii) The asymptotic covariances are also ordered: $\Sigma_{\theta}^{\infty} = \Sigma_{\theta}^{\infty} + Cov(\Delta_{\theta}^A).$

Part (i) is not helpful for understanding the variance of the respective actor-critic algorithms. The ordinary covariance is not of interest in convergence theory for stochastic approximation. Part (ii) tells us that the alternative control variate approach is preferable whenever $Cov(\Delta_{\theta}^A)$ is large.
