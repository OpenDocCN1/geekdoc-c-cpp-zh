# 192 Value Function Approximations

A similar construction was introduced in Section 4.5.3 using $\sigma = 1$. The addition of a function of $x$ doesn't change the minimizer, so that whatever the conditions of Theorem 3.12 hold,

```
$H^*(x) = \arg\min_u H^*(x,u).
```

The identity $H^*(x) = \min_u H^*(x,u) = \sigma J^*(x)$ follows from the HJB equation, on substituting into the definition of $H^*$

```
$H^*(x,u) = c(x,u) + \sigma^{-1}\nabla H^*(x) - f(x,u) + H^*(x). \quad (5.73)
```

The component involving the model can be eliminated using the chain rule, $H^*(x)\frac{\partial}{\partial x_t} = \partial H^*(x)\frac{\partial}{\partial x_t}$, and substituting the dynamics $\frac{\partial x_t}{\partial t}=f(x_t,u_t)$ gives for any input-state trajectory

```
$H^*(x_t) = \nabla H^*(x_t) \cdot f(x_t,u_t).
```

We can follow the steps in discrete time: Substituting the derivative formula into (5.73) gives the sample representation:

```
$H^*(x_t,u_t) = c(x_t,u_t) + \sigma^{-1}H^*(x_t) + H^*(x_t).
```

This is valid for any input and resulting state satisfying $\frac{\partial x_t}{\partial t}=f(x_t,u_t)$ for all $t$. Rearranging, $H^*(x_t)$ is expressed as the output of a first-order, stable linear system:

```
$\frac{\partial H^*(x_t)}{\partial t} = -\sigma H^*(x_t) + \sigma u_t, \quad (5.74)
```

with "input" $\mathcal{u}_t \triangleq H^*(x_t,u_t)-c(x_t,u_t)$, whose solution is

```
$H^*(x_t) = e^{-\sigma t}H^*(x_0) + \sigma \int_0^t e^{-\sigma(t-\tau)}H^*(x_{\tau},u_{\tau})-c(x_{\tau},u_{\tau})d\tau. \quad (5.75)
```

It is convenient to use compact notation for the "smoothed" processes on the right-hand side:

```
$\mathcal{H}_t \triangleq \sigma \int_0^t e^{-\sigma(t-\tau)}H^*(x_{\tau},u_{\tau})d\tau, \quad \mathcal{C}_t \triangleq \sigma \int_0^t e^{-\sigma(t-\tau)}c(x_{\tau},u_{\tau})d\tau. \quad (5.76)
```

Each satisfies a first-order differential equation:

```
$\frac{\partial \mathcal{H}_t}{\partial t} = -\sigma\mathcal{H}_t - H^*(x_t,u_t), \quad \frac{\partial \mathcal{C}_t}{\partial t} = -\sigma\mathcal{C}_t - c(x_t,u_t).
```
