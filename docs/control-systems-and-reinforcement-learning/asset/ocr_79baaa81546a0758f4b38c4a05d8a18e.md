# Value Function Approximations

For any policy $\phi$ with associated value function $J^\phi$, the fixed policy $Q$-function is denoted

```
$Q^\phi(x,u) = c(x,u) + J^\phi(F(x,\phi(x)))$
```

In this notation, the fixed-point equation (3.45)

```
$Q^\phi(x,u) = c(x,u) + Q^\phi(x^+,u^+), \quad x^+ = F(x), \quad u^+ = \phi(x^+). \quad (5.27)
```

For any input $Q$, we observe the error in this fixed-point equation as another temporal difference: For any input-sequence $(x,u)$

```
$\mathcal{D}_{k+1}(Q) \overset{\text{def}}{=} -Q(x,u(k)) + c(x,u(k)) + Q(x(k+1)), \quad (5.28a)
```

```
$Q^\phi(x) \overset{\text{def}}{=} Q(x,\phi(x)), \quad x \in X. \quad (5.28b)
```

The temporal difference (5.28a) is zero for all $k$ if we substitute $Q^\phi$ for $Q$.\nAlgorithms to approximate $Q^\phi$ based on the temporal difference (5.28a) are called SARSA. These algorithms are only a minor variation of the TD-learning algorithms designed to estimate $J^\phi$, so we opt for the simpler terminology “TD-learning” throughout the book.

There are two distinct flavors of TD-learning: on policy and off policy. The on-policy versions $u(k) = \phi(x(k))$ in the definition (5.28a). The difficulties with off-policy algorithms should be cleared by the following discussion in Section 2.5.3: If $\phi$ is a good policy, in the case that $x(k) \to x^*, u(k)=\phi(x(k)) \to u^*$ as $k \to \infty$, for any function $Q$

```
$lim_{k \to \infty} \mathcal{D}_{k+1}(Q) = lim_{k \to \infty} \{-Q(x,u(k)) + c(x,u(k)) + Q(x(k+1),\phi(k+1))}
n= c(x,u^phi), \quad if u = \phi(x) \text{ for each } k. \quad (5.29)
```

Consequently, under the convention $c(x^*,u^*) = 0$, the temporal difference error approaches zero for any choice of $Q$.

In this part of the book, we focus mainly on off-policy algorithms designed to allow for exploration. The elegant theory for on-policy algorithms in stochastic control is explored in Part II.
