# 10.5 Gather the Actors

We meet the actors briefly at the start of this chapter, defined to be a family of randomized policies $\{\phi^	heta : \theta \in \mathbb{R}^d\}$. It is assumed henceforth that they are continuously differentiable in $	heta$. Examples include the Gibbs policy (9.6a), and the linear family:

```
$$\phi^	heta(u|x) = \sum_{i=1}^d \theta_i \phi^i(x)$
```

where $\{\phi^i : 1 \leq i \leq d\}$ is a preselected family of deterministic policies, and the parameter is constrained to be nonnegative and sum to unity: $\theta \in \mathbb{R}^d$, and $\sum_i \theta_i = 1$. The linear family (10.35) can be regarded as a compression of the input, replacing $U$ with the set of $d$ indices $I = \{1, \dots, d\}$, with $\theta_i$ interpreted as the probability of choosing index $i$.
