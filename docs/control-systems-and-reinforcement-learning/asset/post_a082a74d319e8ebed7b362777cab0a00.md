Proof of Proposition 4.34 Choose $T > 0$ so that $|\partial_t \theta| \le \frac{1}{2}|\theta\|$ when $t \ge T$, for any solution to (4.139), from any initial condition $\partial_0 \theta = \theta$. We then define

```

```

Consequently, this is a Lyapunov function for the ODE=$\infty$: For each initial condition $\partial_0^{\infty} = \theta$,


```
$V^{\infty}(\partial_T) \le V^{\infty}(\theta) - \frac{1}{8}\delta|\theta| + L_V(B_T(\varepsilon)) + K_T[1 + |\theta|]$.
```

Fix $\varepsilon \in (0,1)$ so that

```
$L_V K_T \varepsilon \le \delta/A$,
```

giving

```
$V^{\infty}(\partial_T) \le V^{\infty}(\theta) - \frac{1}{8}\delta|\theta| + K'_V$
```

with $K'_V = L_V(B_T(\varepsilon)) + K_T$. To complete the proof, write

```
$V(\theta_s) = \int_s^T V^{\infty}(\theta_t)dt + \int_0^s V^{\infty}(\theta_{T+t}) dt$.
```

The preceding bound gives

```
$V^{\infty}(\partial_T+t) \le V^{\infty}(\theta_t) - \frac{1}{8}\delta|\theta_t| + K'_V$
```

so that

```
$V(\theta_s) \le V(\theta_0) - \frac{1}{8}\delta \int_0^s |\theta_t| dt + sK'_V$.
```
