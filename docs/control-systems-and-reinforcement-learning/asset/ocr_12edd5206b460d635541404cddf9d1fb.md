The bound $-\alpha + \frac{1}{2}\alpha^2 \le -\frac{1}{2}\alpha$ holds when $\alpha \le 1/L$. This and the PL inequality (4.27) imply

$\Gamma(\theta_{k+1}) - \Gamma(\theta_k) \le -\alpha|\nabla\Gamma(\theta_k)\|^2 \le -\mu|\Gamma(\theta_k) - \Gamma|.$

Rearranging and subtracting $\Gamma^*$ from both sides gives

$\Gamma(\theta_{k+1}) - \Gamma^* \le (1-\mu)|\Gamma(\theta_k) - \Gamma^*|.$

Iterating this inequality gives the result.

In practice, the $L$-smooth inequality for $\Gamma$ is usually verified via a global Lipschitz condition on its gradient:

$\|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\| \le L|\theta' - \theta|.$ (4.29)

**Lemma 4.10** Suppose that (4.29) holds for all $\theta, \theta' \in \Theta$, where $\Theta \subseteq \mathbb{R}^d$. We then have:

+   (i) $|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\|^2 \le L|\theta' - \theta|\|^2$ for all $\theta, \theta' \in \Theta$.

+   (ii) If $\Theta$ is convex, then $\Gamma$ is $L$-smooth.

*Proof* (i) is immediate from (4.29):

$\|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\| \le \|\nabla\Gamma(\theta') - \nabla\Gamma(\theta)\||\theta' - \theta|\| \le L|\theta' - \theta|\|^2.$

To establish this, for $	heta \in \Theta$ denote $\theta_t = \theta + t(\theta' - \theta)$ and $\xi_t = \Gamma(\theta_t)$. We have $\theta_t \in \Theta$ for $0 \le t \le 1$ under the convexity assumption. The function is differentiable on this domain, with $\frac{d}{dt}\xi_t = \nabla\Gamma(\theta_t)(\theta' - \theta).$ Applying (i):

$\xi_t - \xi_0 = \Gamma(\theta_t) - \Gamma(\theta_0) - \nabla\Gamma(\theta_0)(\theta' - \theta) \le tL|\theta' - \theta|\|^2.$

Integrating from $t=0$ to $t=1$ gives (4.22):

$\Gamma(\theta') = \Gamma(\theta_1) = \Gamma(\theta_0) + \int_0^1 \xi_t dt \\
\le \Gamma_0 + \xi_0 + \frac{1}{2}L|\theta' - \theta|\|^2 \\
= \Gamma(\theta) + \langle\nabla\Gamma(\theta_0), \theta' - \theta\rangle + \frac{1}{2}L|\theta' - \theta|\|^2.$

# 4.4.4 Constrained Optimization

Consider the optimization problem with equality constraints:

$\Gamma^* = \min_{\theta} \Gamma(\theta) \$ s.t. \g(\theta) = 0,$ (4.30)

where $g: \mathbb{R}^d \to \mathbb{R}^m$ (so there are $m \ge 1$ constraints). The constraints are convex if and only if $g$ is an affine function of $\theta$: For an $m \times d$ matrix $D$ and vector $d \in \mathbb{R}^m$,

$\g(\theta) = D\theta + d.$ (4.31)

One approach to the solution of these problems is through a Lagrangian relaxation, defined through a sequence of steps. Introducing the Lagrangian $\mathcal{L}: \mathbb{R}^d \times \mathbb{R}^m \to \mathbb{R}$:

$\mathcal{L}(\theta, \lambda) = \Gamma(\theta) + \lambda^T\g(\theta), \quad \theta \in \mathbb{R}^d, \quadlambda \in \mathbb{R}^m.$ (4.32)
