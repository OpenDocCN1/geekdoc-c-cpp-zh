# Example 3.9.2 (Linear System with Polynomial Cost) Consider a scalar integrator model, with polynomial cost:

```
$$\frac{dx}{dt} = f(x,u) = u, \quad c(x,u) = u^2 + x^4. \quad (3.62)$
```

The HJB equation $0 = \min_u (u \frac{D}{dx} J^*(x) + u^2 + x^4)$. Minimizing with respect to $u$ defines the state feedback solution,

```
$$\phi^*(x) = -\frac{d}{dx} J^*(x)$.$
```

The closed-loop system has the appearing form

```
$$\frac{dx}{dt}x^* = -\frac{1}{2} \frac{d}{dx} J^*(x^*)$.
```

Substituting the formula for $u^*$ back into the HJB equation gives the differential equation

```
$$\0 = \frac{D}{dx} J^*(x) + u^2 + x^4}|u=\phi^*(x)} = -\frac{1}{4}(\frac{D}{dx} J^*(x))^2 + x^4$,
```

giving $\frac{D}{dx} J^*(x) = \pm 2x$. The unique nonnegative and continuously differentiable solution is $J^*(x) = \frac{2}{3}|x|^3$, and hence the optimal policy is

```
$$\phi^*(x) = -\frac{1}{2dx} J^*(x) = -x^2\sin(x)$.$
```
