Then there exists a unique invariant probability measure $\pi$. It satisfies $\pi(f) < \infty$, and the following additional conclusions hold for any function $c: X \to \mathbb{R}$ satisfying

There are also ergodic theorems available under (V3) – for details, see [257]. In most cases, a far stronger drift condition is available, and from we obtain a strong form of geometric ergodicity. The interpretation of a Lyapunov function as a weighting function is particularly useful in the definitions that follow. For this, we assume that $V(x) \ge 1$ for each $x$, and denote for $c: X \to \mathbb{R}$,

$$\|c\| = \sup_x \frac{|c(x)|}{V(x)}$$

Let $L_V$ be the set of Borel-measurable functions for which this is finite. We say that the Markov chain is $V$-uniformly ergodic if there exists an invariant measure $\pi$, along with $\rho < 1, B < \infty$ for any $c \in L^\infty_V$,

$$|E_x[c(X(k))] - \pi(c)| \le B^k \|c\|V(x), \quad k \ge 0, x \in X.$$

Or, in operator-theoretic notation, denoting $\tilde{c} = c - \pi(c)$:

$$\|P^k c\|V \le B\rho^k \|c\|_V, \quad k \ge 0.$$

**Theorem 6.13 (Lyapunov Condition for V-Uniform Ergodicity)** Suppose that the Markov chain is $V$-irreducible and aperiodic, and the drift condition holds for function $V: X \to [1, \infty)$; for constants $\varepsilon > 0, b < \infty$, and a small set $S \in \mathcal{B}(X)$.

$$PV(x) \le (1 - \varepsilon)V(x) + b 1_S(x), \quad x \in X.$$

Then the Markov chain is $V$-uniformly ergodic.

The fact that we can identify the state dependency in the bound (6.59) is fantastic news. Unfortunately, obtaining bounds on $B$ or $\rho$ is not all easy [232, 256, 302, 303].

6.1 Consider the two-state Markov chain on $X = [0, 1]$ with transition matrix

$$P = \begin{pmatrix} \frac{9}{10} & \frac{1}{10} \\ \frac{1}{4} & \frac{3}{4} \end{pmatrix}$$

- (First) think probabilistically: Explain why the first hitting time to $x = 1$ from the starting point $X(0) = 0$ has a geometric distribution on $\{1, 2, ...\}$. Compute the invariant pmf $\pi$ using Proposition 6.10 (Kac's theorem).

The rest is algebra:

- (b) Obtain the spectral representation of $P$,

$$P = \lambda_1 v^1\mu^1 + \lambda_2 v^2\mu^2,$$

where $\{\lambda_i\}$ are eigenvalues, $\{\mu^i\}$ are left eigenvectors (to be row vectors), and $\{v^i\}$ are right eigenvectors (to be columns vectors).

- (c) Find an expression for $P^n$. At what rate does $P^n(i,j)$ tend to $\pi(j)$?

- (d) Choose a pair of two-dimensional vectors $w$ and $v$. The product $wv^T$ is then a $2 \times 2$ matrix (written with $w \otimes v$ in this book). Compute the inverse,

$$G = [I - (P - wv^T)]^{-1},$$

and verify that the vector $vG$ is proportional to $\pi$. If you are unlucky, and the inverse does not exist; then try a different pair!

This is an example of the Perron-Frobenius construction from Section 3.2.3, for which there is theory available to ensure invertibility. See Example 6.20 for another example.
