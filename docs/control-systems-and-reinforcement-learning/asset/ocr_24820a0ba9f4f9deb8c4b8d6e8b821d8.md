# 8.3 Empirical Risk Minimization

Recall from Section 5.1 our brief survey of empirical risk minimization (ERM). This approach can be applied here, with the empirical risk equal to the empirical mean:

```
$$\Gamma_N}(	heta) = \frac{1}{N} \sum_{i=1}^N \Gamma_i(\theta). \quad (8.42)$
```

Application of ERM means that we favor a recursive algorithm, and minimize to obtain $\hat{	heta}_N^M$. This approach has become popular in recent years for optimization in high dimensions.
For sake illustration, consider the special case of quadratic loss $\Gamma_i(\theta) = \frac{1}{2}||M_i\theta - \xi_i||^2$, in which the matrix $M_i$ and vector $\xi_i$ are random. We then define $\Gamma_i(\theta) = M_i^T(M_i\theta - \xi_i)$, so the SA algorithm is defined by

```
$$\theta_{n+1} = \theta_n - \alpha_n M_{n+1}^T{M_{n+1}\theta_n - \xi_{n+1}\} \quad (8.43)$
```

The ERM solution can be obtained in closed form, by applying the first-order condition for optimality $\bar{\Gamma}_N(\theta) = 0$, where

```
$$\bar{\Gamma}_N(\theta) = \frac{1}{N} \sum_{i=1}^N M_i^T{M_i\theta - \xi_i}\}$
```

Conversely, the existence proved

```
$$\hat{	heta}_N^{M} = (\sum_{i=1}^N M_i^T M_i)^{-1} \sum_{i=1}^N M_i^T \xi_i}\} \quad (8.44)$
```

Proposition 8.8 shows that $\hat{	heta}_N^{M}$ coincides with a particular SA algorithm using a carefully constructed matrix gain:

```
$$\theta_{n+1} = \theta_n - \alpha_n G_{n+1} M_{n+1}^T{M_{n+1}\theta_n - \xi_{n+1}\} \quad (8.45)$
```

in which

```
$G_{n+1} = \frac{1}{n+1} \sum_{i=1}^n M_i^T M_i, \quad n \geq 0.$
```

It will follow from Proposition 8.8 that $\hat{	heta}_N^M$ is an estimate of $\theta^*$ with minimum covariance.
Outside of some special cases (such as high dimension), ERM should be used as a last resort. ERM and Zap have approximately the same covariance as the PJR estimate $\hat{	heta}_N^ho$ defined in (8.10b). Given the simplicity of the recursions defining $\\hat{	heta}_N^ho$, this is probably the first algorithm to try in many applications.
