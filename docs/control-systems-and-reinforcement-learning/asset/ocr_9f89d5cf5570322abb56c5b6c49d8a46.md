# 5.4 Projected Bellman Equations and TD Algorithms

LSTD suffers from two computational challenges:

+   (i) What do you do if $d = 10^7$? Practitioners in machine learning often face high-dimensional problems and claim that dimensions of one million are no longer a concern. This success story is attributed to advances in optimization theory, computer engineering, and computing power.
(ii) How can LSTD be extended to nonlinear function approximation, as when each $	heta_t$ is a weight in a neural network?

In the RL research community, it is typical to modify the objective in order to reduce complexity. A favored approach is to create algorithms that obtain solutions for a *projected* dynamic programming equation. While there is little supporting theory, the algorithms inspired by this viewpoint have been highly successful with neural network function approximation.

The motivation behind these algorithms requires a bit more background on function approximation, described here using the notation of Section 5.1. We begin with an abstraction: Find a function $h^*$ that solves a fixed point equation:

```
$$h^* = T(h^*).$$$$
```

The specifics of domain and range of $h^*$, and the meaning of the mapping $T$, depend on the problem we would like to solve. The DP equation (3.5) is one example, with $h^* = J^*$. If solving (5.38) is intractable, we seek an approximation.

We choose a class $\mathcal{H}$ and a mapping $P_H : \mathcal{H} 	o \mathcal{H}$. That is, $P_H(h) \in \mathcal{H}$ for any $h \in \mathcal{H}$. More conditions on this mapping will be imposed later. We then introduce an approximation of (5.38):

```
$$h = \mathcal{T}(h) \overset{	ext{and}}{=} P_H\{T(h)\}.$$$$
```
