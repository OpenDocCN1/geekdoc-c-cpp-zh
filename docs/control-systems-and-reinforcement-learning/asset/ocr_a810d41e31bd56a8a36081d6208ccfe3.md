Suppose that stochastic process $X$ is defined by the recursion:

```
$X(k+1) = [X(k) + N(k+1)]_+ \overset{	ext{d}}{=} \max(0, X(k) + N(k+1)), \quad k \geq 0,$
```

where $X(0) \in \mathbb{R}$, and $N$ is an i.i.d. sequence of random variables taking values in $\mathbb{R}$. Then $X$ is the *reflected walk*. The reflected walk is a special case of the one-dimensional nonlinear linear state space model with $F(x,d) = [x+d]_+$ for each $x,d \in \mathbb{R}$.

The reflected walk is a model for storage systems and queuing systems. For all applications, there are similar concerns: “we need to know whether a dam overflows, whether a computer network jams” [257, 13]. We are also interested in finer questions regarding performance, such as the mean and variance of delay.

One of the simplest reflected walks is also the most famous model for a queue.

**Example 6.2.3 (The M/M/1 Queue)** The transition function for the M/M/1 queue is defined as

```
$P(X(k+1) = y \mid X(k) = x) = \begin{cases} \alpha & \text{if } y = x+1 \ \mu & \text{if } y = (x-1)_+, \end{cases} \quad (6.14)$
```

where $\alpha$ denotes the arrival rate to the queue, $\mu$ is the service rate, and these parameters are normalized so that $\alpha + \mu = 1$.

The parameter $\rho \triangleq \alpha/\mu$ is known as the *load* for the queue. If $\rho < 1$, then the arrival rate is strictly less than the service rate. In this process, there is a pmf $\pi$ on the nonnegative integers such that for any initial queue length $X(0) = x$, and any integer $m \geq 0$,

```
$\lim_{k\to\infty} P_x\X(k) = m\} = \pi(m).$
```

The invariant pmf is geometric with parameter $\rho$, so that $\pi(m) = (1-\rho)\rho^m$. The existence of $\pi$ is interpreted as a form of stability for the queuing model, so that the path behavior looks like shown in the left-hand side of Figure 6.1 and in Figure 6.2.
