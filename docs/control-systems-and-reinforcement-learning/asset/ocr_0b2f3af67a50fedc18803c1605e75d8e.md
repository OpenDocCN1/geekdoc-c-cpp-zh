The integral representation of solutions to the ODE are identical, with the disturbance
removed:

```
$$\theta_{	au_K}^{(n)} = \theta_{	au_n} + \int_{	au_n}^{\tau_K} f(\theta_{	au}^{(n)})d\tau.$
```

Theory in Section 4.9 can then be applied to establish the following:

**Theorem 8.1** Suppose that the following holds:

+   * f is Lipschitz continuous.
* The parameter sequence $\{\theta_n : n \ge 0\}$ is bounded a.s.
* The disturbance vanishes in the following uniform sense: For each $T > 0$,

```
$$\lim_{n\to\infty} |M_K^{(n)}\| = 0 \quad a.s.,$
```

where the supremum is over $K$ satisfying $K > n$ and $\kappa - \tau_n \le T$.
Then,

+   (i) For each $\theta$

```
$$\lim_{n\to\infty, \tau_n \le t \le \tau_n+T} |\theta_t^{(n)}\| = 0 \quad a.s.$
```

+   (ii) If the ODE (8.4a) is globally asymptotically stable, with unique equilibrium $	heta^*$, then

```
$$\Theta_t = \lim_{n\to\infty} \theta_n = \theta^* \quad a.s.$
```

Proof Part (ii) of the theorem is illustrated in Figure 8.1 (see Figure 8.5 and
surrounding discussion).

Global asymptotic stability with boundedness of the parameter sequence
impl the following: for any $\delta > 0$, there is $T < \infty$ and $\varepsilon < \delta$ such that

+   (i) If $|\theta_n^{(n)} - \theta^*| \le \varepsilon$, then $|\theta_{	au}^{(n)} - \theta^*| \le \delta$ for $\tau \ge \tau_n$.
(ii) $|\theta_{	au}^{(n)}\| \le \varepsilon/2$ for each $n$ and all $\tau \ge \tau_n+T$;

The sampling times indicated in the figure are defined by $\mathcal{N}_0=0$ and for $n \ge 1$,

```
$$\mathcal{N}_n = \min{\mathcal{N}_k : \tau_k \ge \mathcal{N}_{n-1}+T}..$
```

Each of these times can be expressed as $\mathcal{N}_n = \tau_{n_n}$ for some integer $n_n \ge n$. They are
constructed so that the ODE solution $[\mathcal{N}_n, \infty)$ will satisfy $|\theta_{\tau}^{(n)}\| - \theta^*| \le \varepsilon/2
for $\tau \ge \mathcal{N}_n+1$.
