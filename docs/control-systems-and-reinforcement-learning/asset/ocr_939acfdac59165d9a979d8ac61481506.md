# 8.2.6 Asymptotic versus Transient Performance

As in the QSA question of Section 4.9, there are trade-offs in choice of step-size: crucially: While $\alpha_n = g/n$ will typically yield the optimal convergence rate (8.8) (most crucially, $g > 0$ is chosen sufficiently large), this may also result in poor transient behavior.

Please review the summaries in both Section 8.2.2 and Section 4.5.4 to recall that convergence theory for SA and QSA results on comparing with $	heta_t$ amounts to a time scaling of the ODE (8.4a) recall (8.16 and (8.17)). Bounds on this time scaling are easily obtained:

```
$\tau_n^- \le \tau_n \le \tau_n^+$
```

where $\tau_n = \frac{\log(n+1)}{\frac{1}{ho}[(n+1)^{1-ho}-1]}$ if $\rho < 1$, and $\tau_n^+=\frac{1+\log(n)}{\frac{1}{1-ho}[n^{1-ho}-1]}$ if $\rho < 1$.

Proof The following bounds hold for any $t \ge 0$:

```
$t+1 \le \frac{1}{t} \le \frac{1}{[t]} \le \frac{1}{max(1,t)}$
```

where $[t+1]$ is the integer part of $t+1$; in particular, $[t+1] = 1$ for $0 \le t < 1$. The lemma follows from these bounds, combined with the integral representation

```
$\tau_n = \int_0^n (\frac{1}{[t+1]})^\rho dt.$
```

Let us review the uniform convergence obtained in (8.19) that motivated the lemma. Suppose that the ODE converges exponentially quickly to the optimal parameter: There exists $\theta_0 > 0

```
$\|\theta_{t_0+t} - \theta^*|| \le B_0 ||\theta_0 - \theta^*|| \exp(-\rho t)$. (8.33)
```

To apply (8.19), we set $t_0 = \tau_n$, so that $\theta^{(	au_n)} = \theta_n$ by construction, and choose $t_0+t = n+k$ for $\alpha_n = g/n$. If (8.19) gives, for a large range of $k \ge 1$,

```
$\|\theta_{n+k} - \theta^*|| \ge ||\theta_{\tau_n+k}^* - \theta^*|| \le B_0 ||\theta_0 - \theta^*|| \exp(-\rho \_0 g) (\log(n+k) - 1 - \log(n)) \ \= B_0 ||\theta_0 - \theta^*|| \exp(-\rho \_0 g) (\frac{n}{n+k})$ (8.34)
```

If $\rho_0 g$ is not sufficiently large, the convergence of $\theta^{(	au_n)}_{n+k}}$ to $\theta^*$ may be very slow. In this case, it doesn't make much sense to worry about the variance of the parameter estimation error: It is the slow transient behavior that we should worry about.
