Scaling by $\gamma$ and adding $c$ to each gives

$c+\gamma PV=c+\gamma(\alpha^2 V+(1-\alpha^2) A_{\gamma}+\kappa_{\gamma}),$$

or, reintroducing the quadratic expressions,

$c(x)+\gamma PV(x)=\frac{1}{2}(1+\gamma^2\kappa_{\gamma})x^2+\frac{1}{2}(\kappa_{\gamma}\sigma_{N}^2+A_{\gamma}).$$

To solve the dynamic programming equation, we require that the right-hand side code with $V$. This requires that we match coefficients: $1+\gamma^2\kappa_{\gamma}=\kappa_{\gamma}$, and $\gamma(\frac{1}{2}\kappa_{\gamma}\sigma_{N}^2+A_{\gamma})=A_{\gamma}$, giving

$h_{\gamma}(x)=A_{\gamma\|+\frac{1}{2}\kappa_{\gamma}x^{2}=\frac{1}{1-\gamma \alpha^{2}}[x^{2}-\frac{\gamma}{1-\gamma}\sigma_{N}^{2}].$$

In particular, the bound (6.36) holds.

# 6.7 Simulation: optimal control, we face Confidence Bounds and Control Variates

In average-cost optimal control, we are faced not with a single Markov chain, but an entire family: one Markov chain for each in a family of policies. We would like to estimate the average cost $\eta=\pi(c)$ for many different policies so we can select the best in the family. Lyapunov functions provide bounds, but it is rare to obtain bounds that are sufficiently tight so that we can determine which policy is optimal. Without alternatives, in the majority of cases we resort to simulation.
