To minimize this objective function, we might apply first-order methods to find a stationary point: a vector $	heta$ satisfying

```
$0 = \frac{1}{2} \nabla_\theta E_n[\mathcal{B}^\theta(X)^2] = E_n[\mathcal{B}^\theta(X) \nabla_\theta \mathcal{B}^\theta(X)].$
```

On substituting the definitions, we obtain representations that suggest algorithms.

**Lemma 9.5** *The following holds for each $	heta \in \mathbb{R}^d$:*

```
$-rac{1}{2} \nabla_\theta E_n[\mathcal{B}^\theta(X)^2] = E_n[\mathcal{D}^	heta_{n+1} \zeta_n^	heta].$
```

where

```
$\zeta_n^	heta = \nabla_\theta E[h^	heta(X(n)) - \gamma h^	heta(X(n+1)) | \mathcal{F}_n].$ (9.30)
```

*Proof.* By the Markov property, we have

```
$\mathcal{B}^\theta(X(n)) \overset{\texttext{=}}{=} \mathcal{D}^	heta_{n+1} | X(n)] = E[\mathcal{D}^	heta_{n+1} | \mathcal{F}_n].$
```

The gradient of interest is thus

```
$-rac{1}{2} \nabla_\theta E_n[\mathcal{B}^\theta(X)^2] = E[\mathcal{D}^	heta_{n+1} | \mathcal{F}_n] \zeta_n^	heta$.$
```

where $\zeta_n^	heta$ is given in the statement of the lemma:

```
$\zeta_n^	heta = -
abla_\theta E[\mathcal{D}^	heta_{n+1} | \mathcal{F}_n] = \nabla_\theta E[h^	heta(X(n)) - \gamma h^	heta(X(n+1)) | \mathcal{F}_n].$
```

The smoothing property of conditional expectation completes the proof:

```
$E[\mathcal{D}^	heta_{n+1} | \mathcal{F}_n]\zeta_n^	heta] = E[\mathcal{D}^	heta_{n+1} \zeta_n^	heta]. \square$
```

The lemma suggests that it is possible to approximate the gradient flow for the objective $\Gamma(\theta) = E[\mathcal{B}^\theta(X)^2]$ using stochastic approximation, we have

```
$\theta_{n+1} = \theta_n + \alpha_{n+1}\mathcal{D}^	heta_{n+1} \zeta_n^	heta|_{\theta=\theta_n}$.$
```

However, the conditional expectation in (9.30) presents a challenge. Proposition 9.4 suggests many approximations based on the conditional expectation (9.19).

**Proposition 9.6**

```
$E_n[\mathcal{B}^\theta(X(n))^2] = E_n[\mathcal{D}^	heta_{n+1}^2] - \sigma_n^2(\theta),$ (9.31)
```

where $\sigma_n^2(\theta)$ denotes the conditional variance:

```
$\sigma_n^2(\theta) \overset{\texttext{=}}{=} E[\mathcal{D}^	heta_{n+1}^2] - E[\mathcal{D}^	heta_{n+1} | \mathcal{F}_n]^2]. \square$
```

The objective function $\Gamma(\theta) = E[\mathcal{D}^	heta_{n+1}^2]$ is given by the MSBE plus $\sigma_n^2(\theta)$, which is small in many cases. An SA algorithm designed to approximate the gradient flow is straightforward:

with $\mathcal{D}_{n+1} \overset{\texttext{=}}{=} \mathcal{D}^	heta_{n+1}$, and

```
$\zeta_{n+1} = -
abla_\theta \mathcal{D}^	heta_{n+1}|_{\theta=\theta_n} = \nabla_\theta h^	heta(X(n)) - \gamma h^	heta(X(n+1))|_{\theta=\theta_n}.$
```

One can use one of the techniques in Chapter 8 to accelerate this algorithm.
