The uplift of stochastic approximation is that it can be implemented without knowledge of the function $f$ or the distribution of $\Phi$; rather, it can rely on observations of the sequence $\{\theta_n, \Phi_n\}$. This is one why these algorithms are valuable in the context of reinforcement learning.

In much of the SA and RL literature, it is assumed that $\Phi$ is a Markov chain: a topic considered in depth in Chapter 6. A motivating observation in the present chapter is that Markov chains need not be stochastic: the state space model (2.21) (without control) satisfies the Markov property used in Part II of this book. For example, given $\omega > 0$, the sequence $\theta_n = [cos(\omega n), sin(\omega n)]$ is a Markov chain on $\Omega$ (the unit circle in $\mathbb{R}^2$). This motivates the quasi-stochastic approximation (QSA) ODE:

```
$$\frac{d}{dt}\theta_t = a_t(\theta_t, \xi_t).$
```

We use the terms gain and step-size interchangeably for the nonnegative process $a$, and $\xi$, is called the probing signal.
The expectation in (4.41) is defined by the sample path average:

```
$f(\theta) = \lim_{T\to\infty} \frac{1}{T} \int_0^T f(\theta, \xi_t)dt, \text{for all } \theta \in \mathbb{R}^d.$
```

The existence of this limit requires assumptions on $f$ and the probing signal.
