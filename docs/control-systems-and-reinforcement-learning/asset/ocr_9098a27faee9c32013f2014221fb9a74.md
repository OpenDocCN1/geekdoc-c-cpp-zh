In (6.9b), we view $P^k$ as a mapping from functions to functions. This representation was introduced for finite state space models early in this book, just above (3.17), where for emphasis we introduced the vector notation

```
$\hat{h}=[h(x_1),\dots,h(x_m)]^T, \quad X=\{x_1,\\dots,x_m\}$
```

and wrote $P^k \hat{h}$ rather than $P^k h$. This cumbersvector notation will not appear again in this book.

If $\mu$ is a probability measure on $X$, and $X(k+r) \sim \mu$ (the state is distributed according to $\mu$ at time $r$), then it follows $X(k+r) \sim \mu_k$ for any $k \geq 1$,

```
$\mu_k(S) = \int \mu(dx)P^k(x,S), \quad S \in \mathcal{B}(X).
```

This is expressed $\mu_k = \mu P^k$, which is also consistent with vector-matrix multiplication in the finite state space setting. This probability measure is precisely the same as in (6.7) when $r=0$.

We could further, write

```
$\mu h = \int h(x)\mu(dx).
```

This is consistent with multiplication of a column vector $h$ by a row vector $\mu$ to obtain a scalar (an inner product). However, “$\mu h$” can create ambiguity, so we introduce parentheses for emphasis:

```
$\mu(h) = \int h(x)\mu(dx).$ (6.11)
```

Please get used to these notation! They will be used throughout the remainder of the book.

# 6.2 Simple Examples

We begin with a few basic examples. The linear model is standard in physics, systems theory, economics, and many other areas.

**Example 6.2.1 (The Linear State Space Model)** Suppose $X=\{X(k)\}$ is a stochastic process for which there is an $n\times n$ matrix $F$ and an i.i.d. sequence $N$ taking values in $\mathbb{R}^n$ such that

```
$X(k+1) = FX(k)+N(k+1), \quad k \geq 0$,
```

where $X(0) \in \mathbb{R}^n$ is independent of $N$. Then $X$ is called the (uncontrolled) linear state space model. It is precisely of the form (6.3) in which $F(x,n)=Fx+n$.

We denote the state process using a lower case where $N=0$, as in

```
$x(k+1) = Fx(k), \quad k \geq 0$. (6.12)
```
