# 4.9 Convergence Theory for QSA

The Lipschitz conditions in (QSA2) imply the bound:

$$\|\mathcal{E}_v^{\tau+v}\| \leq \delta^\tau v + L_f \int_{\tau}^{\tau+v} \|\mathcal{E}_w^\tau\| dw,$$

where

$$\delta^\tau \frac{\text{def}}{=} \sup_{\tau \geq 0 < v < \tau} \int_{\tau}^{\tau+v} |f(\mathbf{\Theta}_w) - f(\mathbf{\Theta}_w, \xi(s^{-1}(w)))| dw.$$

Proposition 4.2 gives $|\mathcal{E}_v^{\tau+v}\| \leq e^{l/\tau}$ for all $\tau$, and all $0 \leq v \leq 1$. The error term $\delta^\tau$ vanishes as $\tau \to \infty$ (4.132a).

## Local Solidarity

We conclude this subsection with a weak but general bound on the difference between $\mathbf{\Theta}$ and $\mathbf{\Theta}^\tau$. The inequality does not require boundedness of solutions to the ODEs and is useful for small $T$ to establish a Lyapunov drift condition for $\mathbf{\Theta}$.

**Lemma 4.31** for $b < 0$ and any $0 < T \leq 1$.

$$\|\mathbf{\Theta}_{\tau+T} - \mathbf{\Theta}^\tau\| \leq e^{l/\tau}b_0(\tau) + b(1 + |\mathbf{\Theta}_\tau\|)T^2, \quad (4.136)$$

where $b_0(\tau)$ is given in (4.82), and $L_f$ is the Lipschitz constant introduced in Assumption (QSA2).

*Proof.* Denote $\mathcal{E}_w^\tau = \mathbf{\Theta}_w - \mathbf{\Theta}^\tau$ for $w \geq \tau$. The property of (4.131) give

$$\mathcal{E}_{\tau+T} = \int_{\tau}^{\tau+T} [f(\mathbf{\Theta}_w) - f(\mathbf{\Theta}_w, \xi(s^{-1}(w)))] dw + \int_{\tau}^{\tau+T} [f(\mathbf{\Theta}_w^\tau) - f(\mathbf{\Theta}_w)] dw, \quad (4.137)$$

The Lipschitz conditions in (QSA2) are used to bound the:

$$\|f(\mathbf{\Theta}_w) - f(\mathbf{\Theta}_\tau)\| \leq L_f|\mathbf{\Theta}_w - \mathbf{\Theta}_\tau\|,$$

$$\|f(\mathbf{\Theta}_w, \xi(s^{-1}(w))) - f(\mathbf{\Theta}_\tau, \xi(s^{-1}(w)))\| \leq L_f|\mathbf{\Theta}_w - \mathbf{\Theta}_\tau\|,$$

$$\|f(\mathbf{\Theta}_w^\tau) - f(\mathbf{\Theta}_w)\| \leq L_f|\mathcal{E}_w^\tau\|.$$

Consequently for $T \geq 0$,

$$\|\mathcal{E}_{\tau+T}^\tau\| \leq \int_{\tau}^{\tau+T} [f(\mathbf{\Theta}_w) - f(\mathbf{\Theta}_w, \xi(s^{-1}(w)))] dw + 2L_f \int_{\tau}^{\tau+T} |\mathbf{\Theta}_w - \mathbf{\Theta}_\tau| dw + \int_{\tau}^{\tau+T} |\mathcal{E}_w^\tau| dw$$

$$\leq e^{l/\tau} + L_f \int_{\tau}^{\tau+T} |\mathcal{E}_w^\tau| dw, \quad \delta^\tau \frac{\text{def}}{=} b_0(\tau)\mathcal{E}_\tau^\tau + 2L_f |\mathbf{\Theta}_{\tau+w} - \mathbf{\Theta}_\tau| dw.$$

By Grönwall's lemma, in the form (4.6c),

$$\|\mathcal{E}_{\tau+T}^\tau\| \leq |\mathcal{E}_\tau^\tau|e^{L_f T}.$$

Using the same proof to derive (4.108b) by Grönwall's lemma, we have

$$\|\mathbf{\Theta}_{\tau+w} - \mathbf{\Theta}_\tau\| \leq (B_f + L_f|\mathbf{\Theta}_\tau\|)e^{L_f w}.$$

## ODE Methods for Algorithm Design

Increasing $e^{L_f w}$ to $e^{L_f T}$ for the range of integration gives

```
$2 \int_0^T ||\dot{\theta}_w - \dot{\theta}_\tau|| dw \leq 2(B_f + L_f ||\dot{\theta}_\tau||)e^{L_f T} \int_0^T w dw = \langle B_f + L_f ||\dot{\theta}_\tau||\rangle T^2 e^{L_f T}$.
```

Hence

```
$$\hat{\alpha}_T^2 \leq b_0(\dot{\theta}_0)\varepsilon_0^2 + L_f(B_f + L_f ||\dot{\theta}_\tau||)T^2 e^{L_f T},
```

which completes the proof, since $0 \leq T \leq 1$.

## 4.9.3 Criteria for Stability

The first step in establishing convergence of QSA is to show that the solutions are bounded in time. Two approaches can be borrowed from dynamical systems: Lyapunov function, or the ODE at $\infty$ introduced in Section 4.8.

### Lyapunov Criterion and (QSV1)

There exists a continuous function $V: \mathbb{R}^d \to \mathbb{R}_+$ and constants $c_0 > 0, \delta_0 > 0$ such that, for any initial condition $\theta_0$ of (4.42), and any $0 \leq T \leq 1$, the following bounds hold when $\|\theta_s\| > c_0$:

```
$V(\theta_s + T) - V(\theta_s) \leq \delta_0 \int_0^T ||\dot{\theta}_t|| dt.
```

The Lyapunov function is Lipschitz: there exists a constant $L_V < \infty$ such that $||V(\theta') - V(\theta)|| \leq L_V ||\theta' - \theta||$ for all $\theta, \theta'$.

Assumption (QSV1) ensures that $V(\theta_t)$ is strictly decreasing when $\theta_t$ escapes a ball of radius $c_0$. If $V$ is quadratic, then this assumption implies

```
$$\frac{d}{dt}V(\theta_t) \leq -\delta_0||\dot{\theta}_t||, \quad \text{whenever } ||\dot{\theta}_t|| > c_0.
```

The integral form is chosen since sometimes it is easier to establish a bound in this form. In particular, the proof of Proposition 4.3 is based on the construction of solution to (QSV1).

### Verifying (QSV1) for a Linear System

Consider the ODE (4.42), in which $f(x) = Ax$ with $A$ a Hurwitz $d \times d$ matrix. There is a quadratic function $V_2(x) = x^T Mx$ with $M \in \mathbb{R}^{d \times d}$ satisfying the Lyapunov equation $MA + A^T = -I, M > 0$. Consequently, solutions to (4.42) satisfy

```
$$\frac{d}{dt}V_2(\theta_t) = -||\dot{\theta}_t||^2.
```

Choose $V = \sqrt{V_2}$, also by this chain rule

```
$$\frac{d}{dt}V(\theta_t) = -\frac{1}{2}\frac{1}{\sqrt{V_2(\theta_t)}}||\dot{\theta}_t||^2 \leq -\frac{1}{2}\sqrt{\lambda_{max}}||\dot{\theta}_t||,
```

where $\lambda_{max}$ is the largest eigenvalue of $M$. This $V$ is a Lipschitz function to to (QSV1), for any $c_0 > 0$.

## 4.9 Convergence Theory for QSA

We first establish boundedness under a variant of (QSV1):

**Lemma 4.3** The solution to (4.29) is ultimately bounded if, for some $T > 0, 0 < \delta_1 < 1$, and $\tau_0, b < \infty$,

```
$V(\tilde{\Theta}_{\tau+T}) - V(\tilde{\Theta}_\tau) \le -\delta_1|\tilde{\Theta}_\tau||,
```

for all $\tau \geq \tau_0, ||\tilde{\Theta}_\tau|| > b$.

*Proof.* For each initial condition $\tilde{\Theta}_0 = 0$ and $\tau \geq \tau_0$, denote

```
$\tau = \tau(\theta, b) \triangleq \min(v \ge 0 : ||\tilde{\Theta}_{\tau+v}|| \le b),
```

where $\tau_0$ and $b$ are defined in the lemma. If $||\tilde{\Theta}_0|| \le b$, then $\tau = 0$, and $||\tilde{\Theta}_{\tau+v}|| > b$ for all $v \ge 0, \tau \in \mathbb{Z}_+$, define $\tau_m = \min(\tau, m)$. Then,

```
$-\tau_m b \delta_1 \ge -\delta_1 \int_{\tau}^{\tau+\tau_m} ||\Theta_w|| dw \ge \int_{\tau}^{\tau+\tau_m} V(\Theta_w+T)dw = \int_{\tau}^{\tau+\tau_m} V(\Theta_w)dw - \int_{\tau}^{\tau+T} V(\Theta_w)dw \ge \int_{\tau}^{\tau+T} V(\Theta_w)dw.
```

The right-hand side is independent of $m$, which establishes the upper bound

```
$\tau \le \frac{1}{b\delta_1} V(\Theta_{\tau})$.
```

Under the Lipschitz assumption on $V$, for some constant $b_v$, Proposition 4.19 can be applied to establish that for

```
$\tau \le b_v(1+||\Theta_{\tau}||).
```

Hence $\tau(\theta, \tau)$ is everywhere finite. $b_1 = \sup\{||\Theta_{\tau+v}|| : \tau \ge \tau_0, v \le \tau(\theta, \tau)\}$. $b_1$ bounds the maximum number of excursion of $\Theta$ at time $\tau$ if $\tau \in S = \{\theta : ||\theta|| \le b+1\}$, and ends at the set $S_0 = \{\theta : ||\theta|| \le b\}$, denoted $\tau(\theta, \tau)$. Every trajectory enters $S_0$ for some time $\tau \ge \tau_0$, it follows that $||\Theta_\tau|| \le b_1$ for all $\tau$ sufficiently large.

**Proposition 4.33** Under (QSV1), the solution to (4.29) is ultimately bounded: there exist $b < \infty$ such that for any $\theta_0 = \theta, \lim_{\tau \to \infty} ||\Theta_\tau|| \le b$.

*Proof.* Recall that $V$ is the Lyapunov function, and $c_0 > 0$ is the constant introduced in (QSV1). For $0 \le \tau \le 1, ||\Theta_\tau|| \le \tau_0 + 1$,

```
$V(\Theta_{\tau+T}) - V(\Theta_\tau) = V(\Theta_{\tau+T}) + V(\Theta_\tau) - V(\Theta_\tau) \le L_\tau||\Theta_\tau|| + -\delta_0 T||\Theta_\tau|| \le e^{L_\tau T}b_0(\Theta_\tau) + b(1+|Theta_\tau||) - -\delta_0 T||\Theta_\tau||,
```

## ODE at $\infty$

When extending the techniques of Section 4.8, we require the vector field at $\infty$ associated with the average vector field:

```
$f_{\infty}(\theta) := \lim_{r\to\infty} r^{-1}f(r\theta), \quad \theta \in \mathbb{R}^d. (4.138)
```

(i) The limit (4.138) exists for all $\theta$ to define a continuous function $f_{\infty}: \mathbb{R}^d \to \mathbb{R}^d$.
(ii) The origin is globally asymptotically stable for the ODE at $\infty$:

```
$$\frac{d}{dt}\tilde{x}_t^{\infty} = f_{\infty}(\tilde{x}_t^{\infty}), \quad \theta \in \mathbb{R}^d. (4.139)
```

Then the main step in proof of Proposition 4.34 is to show that the assumptions of the theorem imply the ODE (4.42) is ultimately bounded. Lemma 4.23 is repeated here in the new notation for convergence:

**Lemma 4.35** Suppose that (QSA2) holds, and the limit (4.138) exists for all $\theta$ to define a continuous function $f_{\infty}: \mathbb{R}^d \to \mathbb{R}^d$. Moreover that the origin is asymptotically stable for (4.139). Then the following holds:*

(i) $\tilde{x}_t^{\infty}(s) = sf_{\infty}(\theta)$ for each $\theta \in \mathbb{R}^d$ and $s \geq 0$.
(ii) If $\{t : t \geq 0\}$ is any solution to the ODE, (4.139), and $s > 0$, then $\{y_t = s\tilde{x}_t^{\infty} : t \geq 0\}$ is also a solution, starting from $s\tilde{x}_0^{\infty} \in \mathbb{R}^d$.
(iii) The origin is globally asymptotically stable for (4.139), and convergence to the origin is exponentially fast: For some $R < \infty$ and $\rho > 0$,

```
$|\tilde{x}_t^{\infty}\| \leq Re^{-\rho t}|\tilde{x}_0^{\infty}\|, \quad \tilde{x}_0^{\infty} \in \mathbb{R}^d.$
```

This is essentially one step in the proof of Proposition 4.22.

**Lemma 4.36** Under the assumptions of Lemma 4.35, for each $T < \infty$ and $\epsilon \in (0,1]$, there exists $K_T < \infty$ independent of $\epsilon$, and $B_T(\epsilon) < \infty$ such that for all solutions to (4.42) and (4.139) from common initial condition $\theta_0$,

```
$|\tilde{x}_t - \tilde{x}_0^{\infty}\| \leq K_T[1 + |\theta_0|\]\epsilon.$
```
