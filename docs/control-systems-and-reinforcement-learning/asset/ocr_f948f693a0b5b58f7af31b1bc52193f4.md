# 6.9.1 Classification

For a Markov chain on a general state space, it remains true that $\lambda_1 = 1$ is always a right eigenvalue. Recalling the notation in (6,9b), where $P^1 = 1$, generally “1” denotes a function: $1(x) = 1$ for all $x \in X$. More, for each $k \ge 1$ and $x \in X$,

```
$P^k(x) = E[1(X(r+k)) \mid X(r) = x]=1$
```

The assumptions on any eigenvalue in Theorem 6.2 are traditionally replaced with the following notion of irreducibility and aperiodicity. A probability measure $\psi$ on $X$ is defined and we have the following classification:

+   (i) The chain is $\psi$-irreducible, for any $A \in B(X)$ satisfying $\psi(A) > 0$, and any $x \in X$, there is $n \ge 1$ satisfying $P^n(x, A) > 0$.
(ii) The chain is aperiodic, for any set $A \in B(X)$ satisfying $\psi(A) > 0$, and any $x \in X$, there is $n_0 \ge 1$ satisfying

```
$P^n(x, A) > 0, \quad n \ge n_0$.
```

These definitions appear unverifiable: How can one test every $A \in B(X)$? One approach is through verification of a minimization condition: A set $S \in B(X)$ is called small if there is a probability measure $
u, \delta > 0$, and a $n$ such that

```
$P^n(x, A) \ge \nu(A), \quad x \in S, A \in B(X). (6.56)
```

This isn't hard to verify as it might appear. For example, it is easy to construct small sets if $X = \mathbb{R}^n$ and $P^n$ has a continuous density.

**Lemma 6** Suppose that the pair $(S,\nu)$ satisfies (6.56). Then,

+   (i) Suppose that $\sum_{k=0}^{\infty} P^k(x_0, S) > 0$ for any $x_0 \in X$. Then the chain is $\psi$-irreducible, with $\psi = \nu$.
(ii) Suppose that for any $x \in X$, there is $n_0 \ge 1$ satisfying

```
$P^n(x, S) > 0, \quad n \ge n_0$.
```

The chain is also aperiodic. $\square$
