# 7.5 Partial Observations

If only $Y$ is observed, we may attempt to minimize $J$ over all functions of these observations. That is, restrict inputs to functions of current and past observations:

```
$U(k) = \phi_k(Y(0), \dots, Y(k)).
```

An explicit solution can be obtained under the assumption that $(N,W)$ is jointly Gaussian:

**Proposition 7.5** Suppose that $(N,W)$ is jointly Gaussian, and independent of $X(0)$. Then:

+   (i) The solution to the finite horizon optimal control problem, in which $J$ is minimized over all input sequences of the form (7.49), is obtained using

```
$U(k) = -K_k\tilde{X}(k)$.
```
