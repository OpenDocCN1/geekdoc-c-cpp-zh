## 10.10 Fisher Information

The interpretation of (10.54) as Fisher information is not trivial.
The term arises in the theory of parameter estimation, as in Borkar's thesis [61, 62]: In the context of this chapter, the estimation problem is the same as before. The input is chosen according to $\phi^\theta$ for some $\theta \in \mathbb{R}^d$. Given samples $\{\Phi(k) : 0 \le k \le n\}$, the maximum likelihood estimate $\hat{\theta}_n$ is a solution to

$$0 = \nabla_{\theta} \log \left( \prod_{k=0}^{n-1} T_{\theta}(\Phi(k), \Phi(k+1)) \right) \big|_{\theta=\hat{\theta}_n} = \sum_{k=1}^n \Lambda_{\theta}(\Phi(k)) \big|_{\theta=\hat{\theta}_n}.$$

In this context, the Fisher information is the normalized covariance of this statistic, evaluated at $\theta = \hat{\theta}$:

$$F_n(\hat{\theta}) = \frac{1}{n} \text{Cov} \left( \sum_{k=1}^n \Lambda_{(k)}^{\theta} \right).$$

Due to the martingale difference property established Lemma 10.20,

$$\lim_{n \to \infty} F_n(\hat{\theta}) = \frac{1}{n} \text{Cov}(\Lambda_{(k)}^{\theta}) = F(\hat{\theta}),$$

with the right-hand side defined in (10.54).

The matrix $F_n(\hat{\theta})$ is a measure of the sensitivity of the first $n$ observations to the parameter $\hat{\theta}$, and from this limit we can justify the interpretation of $F(\hat{\theta})$ as the sensitivity with respect to the entire history of observations. This is an elegant conclusion for applications to parameter estimation, but doesn't explain why the inverse of $F(\theta_n)$ is a good gain for applications to actor-critic algorithms.

### A.1 Notation and Math Background

This section reviews basic notation and concepts from calculus and real analysis.

#### A.1.1 Generalities

- $\mathbf{1}_A$: Indicator function of a set $A$. This means that $\mathbf{1}_A(x) = 1$ when $x \in A$ and 0 otherwise.
- $J(-)$: The "dot" is used to stress that $J$ is a function of some variable.
- $\mathbf{u}$: Boldface is compact notation used to designate a sequence. Alternative notation: $\mathbf{u}=\{u_0, u_1, \dots\} = u_{0,\infty}$.
- For a function $J: \mathbb{R}^n \to \mathbb{R}$, do not forget the gradient $\nabla J$ is *not the same* as the derivative $\partial J$. The gradient is a column vector, and the derivative a row vector (the linear approximation of the scalar valued function $J$).

Concerning sets and sequences in $\mathbb{R}^n$.

### A.1.2 Topology

- Neighborhood of $x \in \mathbb{R}^n$: a set containing $x$ that is open.
- A set $S \subset \mathbb{R}^n$ is compact if it is closed and bounded.
- A collection of sets $\{O_u : u \in \mathcal{N}\}$ (where the index $\mathcal{N}$ may be uncountable infinite) is called a covering of a set $S \subset \mathbb{R}^n$ if $S \subset O_u$ for each $u \in \mathcal{N}$, and $S \subset \bigcup O_u$. Many books in the theory make implicit use one of the following characterization: A set $S$ is compact if and only if every cover admits a finite subcovering (there is a finite collection of indices $\{u_i : 1 \le i \le n\}$ satisfying $S \subset \bigcup_{i=1}^n O_{u_i}$).
- For a function $g: Z \to \mathbb{R}$, the span is defined by

$$\|g\|_{ap} = \max_{\hat{z}} |g(z) - r| = \frac{1}{2}[\max_{\hat{z}} g(z) - \min_{\hat{z}} g(z)]$$

Equation (10.34) shows an example of a variation of this.

The following notation refers to a collection of vectors or scalars scaled by a variable $t \in \mathbb{T}$ interpreted as time, or the number of iterations in an algorithm. Examples: $\mathbb{Z}_+ = \{0, 1, 2, \dots\}$ and $\mathbb{R}_+$.

$\sup a_t$: Supremum of the scalars $\{a_t : t \in T\}$, also known as the least upper bound (LUB). Denote the set of all upper bounds by $S=\{r \in \mathbb{R} : a_t \leq r \text{ for each } t \in T\}$. If $\{a_t\}$ is bounded from above, then this set is nonempty and can be expressed as $[s_0, \infty)$ for some $s_0 \in \mathbb{R}$. This is by definition of supremum: $\sup a_t = \min\{s : s \in S\} = s_0$.

- The infimum is the greatest lower bound, or $\inf\{a_t\} = -\sup\{-a_t\}$.
- $\lim_{t\to\infty} \delta_t$: Limit supremum, defined as follows for a scalar-valued function of $t$. First

$$\delta_r = \sup\{\delta_t : t \geq r\},\ \quad r \in T.$$

As $r$ increases, $\delta_r$, cannot increase (the supremum is taken over a smaller set). The limit as $r \to \infty$ is the limit supremum:

$$\lim_{t\to\infty} \limsup \delta_t = \lim_{r\to\infty} \delta_r.$$

- $\liminf_{t\to\infty} \delta_t = -\limsup_{t\to\infty} (-\delta_t)$.
- $\lim_{t\to\infty} \delta_t$: Limit inferior, defined as follows for a scalar-valued function of $t$. First

$$\delta_r = \inf\{\delta_t : t \geq r\},\ \quad r \in T.$$

As $r$ increases, $\delta_r$, cannot decrease (the infimum is taken over a smaller set). The limit as $r \to \infty$ is the limit inferior:

$$\lim_{t\to\infty} \liminf \delta_t = \lim_{r\to\infty} \delta_r.$$

- $\liminf_{t\to\infty} \delta_t = -\limsup_{t\to\infty} (-\delta_t)$.

### A.1.3 Linear Algebra

- Inner product: For $u, v \in \mathbb{R}^n$, the inner product is $\langle u, v \rangle = \sum_{i=1}^n u_i v_i$.
- Norm: For $u \in \mathbb{R}^n$, the Euclidean norm is $\|u\| = \sqrt{\langle u, u \rangle}$.
- Orthogonality: Two vectors $u, v$ are orthogonal if $\langle u, v \rangle = 0$.
- Linear transformation: A mapping $T: \mathbb{R}^n \to \mathbb{R}^m$ is linear if $T(au + bv) = aT(u) + bT(v)$ for all $a, b \in \mathbb{R}$ and $u, v \in \mathbb{R}^n$.
