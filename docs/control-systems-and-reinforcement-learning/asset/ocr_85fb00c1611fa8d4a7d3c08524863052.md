The final assumption is a substantial strengthening of the ergodic limit (4.82):
(QSA5) The probing signal is the solution to (4.79), with $\Omega$ a compact subset of Euclidean space. It has a unique invariant measure $\mu$ on $\Omega$, and satisfies the following for each initial condition $\Xi_0 \in \Omega$:

+   * For each $	heta$ there exists a function $\hat{f}(	heta)$ satisfying
$$\hat{f}(	heta, \Xi_{t_0}) = \int_{t_0}^{t_1} [f(	heta, \Xi_t) - \hat{f}(	heta)] \, dt + \hat{f}(	heta, \Xi_{t_1}), \quad \text{for all } 0 \le t_0 \le t_1 \quad (4.117)$$

with $\hat{f}(	heta) = \int_{\Omega} f(	heta, x) \mu(dx) \quad 	ext{and} \quad 0 = \int_{\Omega} \hat{f}(	heta, x) \mu(dx).

+   * (ii) The function $f$, and derivatives $\partial_	heta f$ and $\partial_\Xi f$ are $C^1$ and Lipschitz continuous in $	heta$. In particular, $f$ admits a derivative $A$ satisfying
$$\hat{A}(	heta, \Xi_{t_0}) = \int_{t_0}^{t_1} [A(	heta, \Xi_t) - A(	heta)] \, dt + \hat{A}(	heta, \Xi_{t_1}), \quad 0 \le t_0 \le t_1,$$
$A(	heta, \Xi_t) = \int_{t_0}^{t_1} \partial_	heta f(	heta, \Xi_t) \, dt = \partial_	heta f(	heta)$ was defined in (4.116).
Lipschitz continuity is assumed uniform with respect to the exploration process: For $L_f < \infty$,
$$egin{aligned} \|f(	heta, \Xi) - f(	heta', \Xi)\| &\le L_f \|	heta - 	heta'\| \ \|A(	heta, \Xi) - A(	heta', \Xi)\| &\le L_f \|	heta - 	heta'\| \ \|A(	heta, \Xi) - A(	heta', \Xi')\| &\le L_f \|	heta - 	heta'\| \end{aligned} \quad 	heta, 	heta' \in \mathbb{R}^d, \Xi, \Xi' \in \Omega.$

+   * (iii) Denote $\hat{\Upsilon}_t = \int_0^t \hat{A}(	heta^*, \Xi_s) f(	heta^*, \Xi_s)$. The following limit exists:
$$ar{\Upsilon} = \lim_{T 	o \infty} \frac{1}{T} \int_0^T \hat{\Upsilon}_t \, dt = -\int_0^\infty \hat{A}(	heta^*, \Xi_t) f(	heta^*, \Xi_t) \mu(dx)$$
and the partial integral is bounded in:
$$\hat{\Upsilon}_t = \int_0^t [\hat{\Upsilon}_r - ar{\Upsilon}] \, dr, \quad 	ext{where} \quad \hat{\Upsilon}_t = \Upsilon_t - ar{\Upsilon}. \quad (4.118)$

Assumption (QSA5) (iii) is imposed because the vector $\Upsilon$ arises in an approximation of the scaled error $\Xi_t$. This is not much larger than the others. In particular, the partial integral in (4.118) will be bounded if there is a bounded solution $\{\hat{\Upsilon}_t\}$ to
$$\hat{\Upsilon}_{t_0} = \int_{t_0}^{t_1} [\hat{\Upsilon}_t - ar{\Upsilon}] \, dt + \hat{\Upsilon}_{t_1}, \quad 	ext{for all } 0 \le t_0 \le t_1.$
