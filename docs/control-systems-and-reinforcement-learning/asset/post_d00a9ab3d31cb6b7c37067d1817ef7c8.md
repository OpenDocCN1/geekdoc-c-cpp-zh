## Q(\lambda$) Learning

For a given $\lambda \in [0,1]$, nonnegative step-sequence $\{\alpha_n\}$, initial conditions $\theta_0, \zeta_0$, and observed samples $u(k,x) : 0 \leq k \leq N$, the sequence of estimates is defined by the following equations:

```
$$\theta_{n+1} = \theta_n + \alpha_n \mathcal{D}_n \zeta_n, \quad (5.52a)$$
$$\zeta_{n+1} = \lambda \zeta_n + \psi_{(n+1)}, \quad (5.52b)$$
```

```
$$\mathcal{D}_n = -Q^\theta(x(n),u(n)) + c_n + Q^\theta(x(n+1),\phi^\theta(x(n+1))), \quad (5.52c)$$
```

with $\psi(n+1) = \psi(x(n+1),u(n+1)), c_n = c(x(n),u(n))$.

The algorithm has significant similarities and differences with TD-learning:

- The change is in (5.52c): the current policy estimate $\phi^\theta$ is used, rather than the fixed policy $\phi$ in TD($\lambda$). Note that in (5.52c) we can substitute

```
$Q^\theta(x(n+1)),\phi^\theta(x(n+1)) \overset{def}{=} Q^\theta(x(n+1))$
```

- QSA theory predicts that a target $\theta^*$ for Q($\lambda$)learning will solve $f(\theta^*) = 0$, with

```
$f(\theta) = E_\theta [f_{n+1}(\theta)], \quad f_{n+1}(\theta) = \mathcal{D}_n Q^\theta \zeta_n. \quad (5.53)$
```

This appears as TD($\lambda$) until you recognize the different definition for $\mathcal{D}_n(Q^{\theta^*})$ obtained from (5.52c):

```
$$\mathcal{D}_n(Q^{\theta^*}) = -Q^{\theta^*}(x(n),u(n)) + c_n + Q^{\theta^*}(x(n+1),u).$$
```

- For the special case $\lambda = 0$, we can apply Proposition 5.6 to conclude that $Q^{\theta^*}$ solves the projected Bellman equation:

```
$Q^{\theta^*} = P_h\{T(Q^{\theta^*})\}$
```

in which the Bellman operator is redefined: $T(Q)|_{(x,u)} = c(x,u) + Q(F(x,u)).

## 5.4 Projected Bellman Equations and TD Algorithms

Sadly, these observations bring us to a dead-end. An ODE analysis of Q($\lambda$)-learning requires us to look at global asymptotic stability of the ODE with vector field $f$ defined in (5.53). As a first step, we must find conditions under which the root finding problem admits a solution! Unfortunately, very little is known about existence, even in the case $\lambda = 0$. And, if an equilibrium exists, stability is nearly inert.

## 5.4.4 GQ-Learning

If we are concerned $f({\theta^*}) = 0$ does not admit a solution, we might turn to the next best option: For a given $d \times d$ matrix $M > 0$,

```
$$\min \Gamma(\theta) = \min_{\theta} \frac{1}{2}f(\theta)^\top M f(\theta).$$
```

We can use the ODE method to devise an algorithm. An approach is gradient descent:

```
$$\frac{d}{dt}\theta_t = -[\partial_{\theta} f(\theta_t)]^\top M f(\theta_t).$$
```

The GQ-learning algorithm of [234] can be regarded as a discrete-time translation of this ODE, using $M = E[\zeta_n\zeta_n^\top]$. Matrix inversion is avoided through a two-timescale algorithm: an ODE approximation of $Mf(\theta_t)$ is obtained using the solution to the “high-gain” ODE,

```
$$\frac{d}{dt}\omega_t = b_t[f(\theta_t) - R\omega_t],$$
```

where $R = M^{-1}$. Provided $\{b_t\}$ is chosen very large and $\{\theta_t\}$ is bounded, it is not difficult to establish that the approximation $\omega_t \approx Mf(\theta_t)$ will hold after a transient period.

These ODEs are native for the two-scale GQ algorithm, presented here for linear function approximation:

## GQ($\lambda$) Learning

With the same starting point as Q($\lambda$) learning, and an additional initialization $\omega_0 \in \mathbb{R}^d$.

```
$$\theta_{n+1} = \theta_n - \alpha_{n+1}\Lambda_n^\top \omega_n, \quad (5.56a)$$
$$\omega_{n+1} = \omega_n + \beta_{n+1}\{f_{n+1}(\theta_n) - \zeta_n + \zeta_{n+1}^\top \omega_n\}, \quad (5.56b)$$
```

```
$$\zeta_{n+1} = \lambda\zeta_n + \psi_{(n+1)},$$
$$\mathcal{D}_{n+1} = -Q^{\theta_n}(x(n), u(n)) + c_n + Q^{\theta_n}(x(n+1)),$$
$$f_{n+1}(\theta_n) = D_{n+1}\zeta_n, \quad A_{n+1} = \partial_{\theta_n}f(\theta_1) = \zeta_n\{\psi_{(n)} + \psi_{(n+1)}^\top\}^\top \quad (5.56c)$$
```

with $\psi_{(n+1)} = \psi(x(n+1), u(n+1))$, and $\psi'_{(n+1)} = \psi(x(n+1), \phi^{\theta n}(x(n+1)))$.

## Value Function Approximations

As always, the output of the algorithm defines the final approximation $Q^{\theta^*}$. The ODE approximation is successful provided the second-step sequence size is relatively large:

```
$$\lim_{n\to\infty} \frac{\beta_n}{\alpha_n} = \infty.$$
```
