# 4.11 ODE Methods for Algorithm Design

The ODE (4.14a) was introduced in the economics literature, which led to the comprehensive analysis by Smale [325]. The term Newton–Raphson flow for (4.14a) was introduced in the deterministic control literature [320, 370]. The Zap Sa algorithm was introduced at the same time, and based on the same ODE [90, 110, 112]. Within the optimization literature, the term “Newton–Raphson dynamical system” is used: see [5] for history. Much more on this technique will appear in the second half of the book. The paper [335] sparked new appreciation for ODE methods within the optimization community (with particular interest in applications to ML). The goal was to understand the dynamics of two common optimization algorithms with “acceleration":

+   (i) Polyak’s heavy-ball method:

```
$x_{k+1} = x_k + \delta_{k+1}[x_k - x_{k-1}] - \alpha_k\nabla\Gamma(x_k). \quad (4.155)$
```

+   (ii) Nesterov’s accelerated gradient algorithm:

```
$x_{k+1} = y_k - \alpha_k\nabla\Gamma(y_k), \quad y_k = x_k + \delta_k[x_k - x_{k-1}]. \quad (4.156)$
```

An ODE approximation for Polyak’s (4.155) with $\delta_k \equiv \delta$ is easily anticipated by denoting $\theta_k = x_k$, and $D_{k+1} = \theta_{k+1} - \theta_k$ [16]. For simplicity, take $\alpha = 1$ and write (4.155)

```
$D_{k+1} - D_k = -(1-\delta)D_k - \Gamma(\theta_k).$
```

This is an Euler approximation of the second-order ODE:

```
$$\frac{d^2\theta}{dt^2} = -(1-\delta)\frac{d\theta}{dt} - \Gamma(\theta).$$
```

Nesterov’s algorithm (4.156) is cited in [335], for alerting me to Smale’s early, using the time-varying choice of $\delta_k$. A similar ODE approximation is established:

```
$$\frac{d^2\theta}{dt^2} = -\beta_t\frac{d\theta}{dt} - \Gamma(\theta), \quad \beta_t = 3/t.$
```

The appearance of “3” is explained by the representation $\delta_k = 1-3/(k+2)$.
Better understanding of the dynamics of these ODEs leads to a much fuller understanding of why Polyak and Nesterov were successful [16, 198, 335]. This work was part of the inspiration for growing interest in ODE and stochastic differential equation (SDE) approximations for more efficient recursive algorithms [200, 294, 318, 375, 384], for neural network approximation [84, 358], and ODE design based on concepts from robust control theory
