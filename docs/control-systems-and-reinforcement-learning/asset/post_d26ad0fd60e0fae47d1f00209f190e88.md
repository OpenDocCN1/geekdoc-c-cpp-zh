
## C.3 Belief State Dynamics

While it is unfortunate that we have to move from the finite state space $X$ to the simplex $S$, we are fortunate that the value functions have simple structure: It can be shown by induction that $V_n$ is concave and piecewise linear as a function of $b \in S[201, 326]$. We would rightly conclude that $H^*$ is also concave as a function of $b$. This opens the door to simple approximation architectures for approximate dynamic programming or reinforcement learning.

The next section contains the proof of Proposition C.1.

## C.3 Belief State Dynamics

A complete and detailed exposition of these notes can be found in Hajek's book [154] or Van Handel's Lecture Notes on Hidden Markov Models [362]. However, Proposition C.1 giving the transition law for the belief state is more difficult to find (this is usually taken for granted).

Recall that $(X, Y)$ is regarded as the state process for an MDP model with transition law given in (C.5). This notation is complex for our purposes. Our interest is in constructing a recursive algorithm that generates the belief state — a function of $x$ so we suppress the role of observations. For each $n$, the observed quantities $y_n = Y_n$ and $u_{n-1} = U_{n-1}$, denoted by the notation of (C.5):

$$\rho_n(x_n | x_{n-1}) = p(x_n | x_{n-1}, u_{n-1})q(y_n | x_n),$$

where it is understood that $x_{n-1}$ and $x_n$ are variables. In contrast, $y_n$ and $u_{n-1}$ appearing in (C.12) are not variables. They are observed quantities.

We first consider a (seemingly) more complex problem: Given a sequence $x^n \in X^{n+1}$, we want to find the conditional probability that $X_0^n \triangleq (X_0, \dots, X_n) = x_0^n$, denoted

$$\beta_n(x_0^n) = P\{X_0^n = x_0^n | Y_n\}$$

This is known as a smoothing problem since we wish to estimate past states given and present observations. The output and input sequences $u_0^{n-1}, y_0^{n-1}$ are obtained using Bayes's rule:

$$\beta_n(x_0^n) = P\{X_0^n = x_0^n | Y_n = y_0^n, U_{n-1} = u_0^{n-1}\} = \frac{P\{X_0^n = x_0^n, Y_n = y_0^n, U_{n-1} = u_0^{n-1}\}}{P\{Y_n = y_0^n, U_{n-1} = u_0^{n-1}\}}$$

The denominator can be regarded as a normalizing constant (it does not depend on $x_0^n$). Letting $\beta_n^*$ denote the numerator gives

$$\beta_n^*(x_0^n) = P\{X_0^n = x_0^n \text{ and } Y_n = y_0^n, U_{n-1} = u_0^{n-1}\} = \rho_n(x_n | x_{n-1}) \times \dots \times \rho_1(x_1 | x_0) \times \mu(x_0),$$

where the $\mu$ defines the distribution for $X_0$.

This is true for any $n$, so we obtain a recursive relationship.

$$\beta_n^*(x_0^n) = \rho_n(x_n, x_{n-1})\beta_{n-1}^*(x_0^{n-1}).$$

## 414 Partial Observations and Belief States

We obtain $\beta_n$ through normalization, since we know it is a pmf:

$$\beta_n(x_0^n) = \kappa_n \beta_n^*(x_0^n), \quad \kappa_n^{-1} = \sum_{x_0, \dots, x_n} \beta_n^*(x_0, \dots, x_n).$$

What about the original problem? We again have Bayes's rule:

$$b_n(x_n) = P\{X_n = x_n | Y_n^0 = y_n^0, U_{n-1}^{-1} = u_{n-1}^{-1}\} = \frac{P\{X_n = x_n, Y_n^0 = y_n^0, U_{n-1}^{-1} = u_{n-1}^{-1}\}}{b_n^*(u_n^1)}.$$

The numerator, denoted $b_n^*(x_n)$, is obtained from $\beta_n^*$ as follows:

$$b_n^*(x_n) = P\{X_n = x_n | Y_n^0 = y_n^0, U_{n-1}^{-1} = u_{n-1}^{-1}\}.$$

Applying (C.13) gives a recursive formula for the unnormalized belief state:

$$\beta_n^*(x_n) = \sum_{x_0, \dots, x_{n-1}} \rho_n(x_n | x_{n-1}) \beta_{n-1}^*(x_0, \dots, x_{n-1}) = \sum_{x_0, \dots, x_{n-1}} \rho_n(x_n | x_{n-1}) \left[ \sum_{x_0, \dots, x_{n-2}} \rho_{n-1}(x_{n-1} | x_{n-2}) \beta_{n-2}^*(x_0, \dots, x_{n-2}) \right].$$

From this, we obtain the linear dynamics:

$$b_n^*(x') = \sum_{x} \rho_n(x' | x) b_{n-1}^*(x), \quad n \geq 1, x' \in X.$$

From Proposition C.3, we obtain the transition matrix for belief state given in Proposition C.1.

## Proposition C.3 (Nonlinear Filter) The belief state dynamics are nonlinear:

$$beta_n(x') = \kappa_0 \mu(x')q(Y_0 | x').$$

$$\beta_n(x') = M(b_{n-1}, Y_n, U_{n-1}) = \kappa_n \sum_{x} \rho_n(x' | x) b_{n-1}(x), \quad x' \in X, n \geq 1.$$

where $\rho_n$ is defined in (C.12), and $\kappa_n$ is determined by the constraint $\sum_{x} b_n(x) = 1$.
