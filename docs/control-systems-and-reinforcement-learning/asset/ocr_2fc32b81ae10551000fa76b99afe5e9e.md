# 7.7 Controlling Rover with Partial Information

In the POMDP literature, we introduce the belief state $\mathcal{X}(k)$, which is nothing more than the conditional pnf for the state $\mathcal{X}(k)$, given observations up to time $k$. In the example considered here, the belief evolves on the simplex $S$ (a two-dimensional region in $\mathbb{R}^2$), with the interpretation

```
$$\mathcal{X}_x(k) = \mathcal{P}\{\mathcal{X}(k) = x \mid Y(0), \dots, Y(k)\},, \quad x \in \mathcal{X} = \{T, B, R\$
```

For the average- or discounted-criterion, the optimal policy can be represented as state feedback:

```
$U^*(k) = \phi^*(\mathcal{X}(k)),$
```

where $\phi^* : S \rightarrow U$. The LQG solution in Proposition 7.5 is an example of this construction in which the belief state can be summarized by the conditional mean and conditional covariance.

A brief survey of POMDP theory is found in Appendix C, where you can find a recursive update for the belief state:

```
$$\mathcal{X}(k+1) = \mathcal{M}(\mathcal{X}(k), Y(k+1), U(k)), \quad k \geq 0$
```

with the details of update map $\mathcal{M}$ provided in Proposition 0.3.

Computation of $\phi^*$ is a major challenge in POMDP practice because the state space $S$ is never finite. We are left to use approximation techniques, and reinforcement learning provides many tools for this purpose.

Suppose that the solution to the fully observed problem is defined by $U(k) = \mathcal{B}$ if and only if $\mathcal{X}(k) = \mathcal{T}$. The policy shown in Figure 7.5 is well motivated in the partially observed setting. This was obtained based on the following formula, given nonnegative $a_T, a_R, a_B$:

```
$$\phi(b) = \begin{cases} \mathcal{B} & \text{if } a_T[b_T-1]^2 + a_R b_R^2 + a_B b_B^2 \leq r \ \mathcal{D} & \text{else} \end{cases}, \quad b \in S\$
```

The degenerate case using $r=0$ is not excluded, giving $\phi(b) = \mathcal{B}$ only if $b_T=1$. This example and the example in Section 7.6 expose several challenges and opportunities:

+   (i) Information constraints on the input can reward MDP theory inappable, MDP algorithms may still lead to a useful policy.

+   (ii) If the POMDP assumptions are valid, then the theory is very rich, but direct application of computational tools like VIA is a significant challenge. Reinforcement learning is a great alternative.

+   (iii) RL + POMDP is not model-free, in practice, we either use a model, or replace the belief state depends crucially on a model. that with some other \"features\" to create a \"pseudo state\" that is believed to include enough information for reliable control.
