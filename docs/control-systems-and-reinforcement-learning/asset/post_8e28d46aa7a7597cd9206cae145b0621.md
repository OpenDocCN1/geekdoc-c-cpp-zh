The final assumption is a substantial strengthening of the ergodic limit (4.82):
(QSA5) The probing signal is the solution to (4.79), with $\Omega$ a compact subset of Euclidean space. It has a unique invariant measure $\mu$ on $\Omega$, and satisfies the following for each initial condition $\Xi_0 \in \Omega$:

- * For each $\theta$ there exists a function $\hat{f}(\theta)$ satisfying
$$\hat{f}(\theta, \Xi_{t_0}) = \int_{t_0}^{t_1} [f(\theta, \Xi_t) - \hat{f}(\theta)] \, dt + \hat{f}(\theta, \Xi_{t_1}), \quad \text{for all } 0 \le t_0 \le t_1 \quad (4.117)$$

with $\hat{f}(\theta) = \int_{\Omega} f(\theta, x) \mu(dx) \quad \text{and} \quad 0 = \int_{\Omega} \hat{f}(\theta, x) \mu(dx)$.

- * (ii) The function $f$, and derivatives $\partial_\theta f$ and $\partial_\Xi f$ are $C^1$ and Lipschitz continuous in $\theta$. In particular, $f$ admits a derivative $A$ satisfying
$$\hat{A}(\theta, \Xi_{t_0}) = \int_{t_0}^{t_1} [A(\theta, \Xi_t) - A(\theta)] \, dt + \hat{A}(\theta, \Xi_{t_1}), \quad 0 \le t_0 \le t_1,$$
$A(\theta, \Xi_t) = \int_{t_0}^{t_1} \partial_\theta f(\theta, \Xi_t) \, dt = \partial_\theta f(\theta)$ was defined in (4.116).
Lipschitz continuity is assumed uniform with respect to the exploration process: For $L_f < \infty$,
$$\begin{aligned} \|f(\theta, \Xi) - f(\theta', \Xi)\| &\le L_f \|\theta - \theta'\| \\ \|A(\theta, \Xi) - A(\theta', \Xi)\| &\le L_f \|\theta - \theta'\| \\ \|A(\theta, \Xi) - A(\theta', \Xi')\| &\le L_f \|\theta - \theta'\| \end{aligned} \quad \theta, \theta' \in \mathbb{R}^d, \Xi, \Xi' \in \Omega.$$

- * (iii) Denote $\hat{\Upsilon}_t = \int_0^t \hat{A}(\theta^*, \Xi_s) f(\theta^*, \Xi_s)$. The following limit exists:
$$\bar{\Upsilon} = \lim_{T \to \infty} \frac{1}{T} \int_0^T \hat{\Upsilon}_t \, dt = -\int_0^\infty \hat{A}(\theta^*, \Xi_t) f(\theta^*, \Xi_t) \mu(dx)$$
and the partial integral is bounded in:
$$\hat{\Upsilon}_t = \int_0^t [\hat{\Upsilon}_r - \bar{\Upsilon}] \, dr, \quad \text{where} \quad \hat{\Upsilon}_t = \Upsilon_t - \bar{\Upsilon}. \quad (4.118)$$

Assumption (QSA5) (iii) is imposed because the vector $\Upsilon$ arises in an approximation of the scaled error $\Xi_t$. This is not much larger than the others. In particular, the partial integral in (4.118) will be bounded if there is a bounded solution $\{\hat{\Upsilon}_t\}$ to
$$\hat{\Upsilon}_{t_0} = \int_{t_0}^{t_1} [\hat{\Upsilon}_t - \bar{\Upsilon}] \, dt + \hat{\Upsilon}_{t_1}, \quad \text{for all } 0 \le t_0 \le t_1.$$

# 4.9.1 Main Results and Some Insights

The notation $\hat{f}$ in (4.117) is used to emphasize the parallels with Markov process and stochastic approximation theory: this is precisely the solution to Poisson’s equation (with forcing function $f(\cdot) = f(\cdot) - \hat{f}(\cdot)$) that appears in simulation of Markov processes, average-optimal control, and stochastic approximation [12, 39, 144, 250]. For the one-dimensional signal defined by sawtooth function $\xi_t = t \pmod 1$, $t \ge 1$, a solution to Poisson’s equation has a simple form:
$$\tilde{g}(z) = -\int_{0}^{z} g(x) \, dx + \hat{g}(0) \quad z \in [0,1), \quad \tilde{g} = \int_{0}^{\infty} g(x) \, dx.$$

It would be useful to introduce new notation: For $\theta \in \mathbb{R}^d$ and $T \ge 0$,
$$\Xi_T(\theta) = \int_{0}^{T} [f(\theta, \xi_t) - \hat{f}(\theta)] \, dt = \hat{f}(\theta, \xi_T) - \hat{f}(\theta), \quad (4.119)$$
where the second equality follows from (4.117). The special case $\theta = \theta^*$ serves notation:
$$\Xi_T(\theta^*) = \int_{0}^{T} f(\theta^*, \xi_t) \, dt,$$
where the right-hand side is justified by the equilibrium condition $f(\theta^*) = 0$.

**Theorem 4.24** Suppose that (QSA)–(QSA5) hold, and the gain is $a_t = 1/(1+t)^\rho$.

- (i) $\rho < 1$. The following hold:
$$\Theta_t = \theta^* + a_t Z_t + o(a_t), \quad Z_t = \bar{Y} + \Xi_t + o(1), \quad (4.120a)$$
where
$$\bar{Y} = (I + A^*)^{-1}\bar{Y}. \quad (4.120b)$$

- (ii) $\rho = 1$. If $I+A^*$ is Hurwitz, the convergence rate is $1/t$:
$$\Theta_t = \theta^* + a_t Z_t + o(a_t), \quad Z_t = \bar{Y} + \Xi_t + o(1), \quad \text{with } \bar{Y} = (I + A^*)^{-1}\bar{Y}. \quad (4.120c)$$

We then perform Polyak averaging (4.78). This is also presented as a two-timescale algorithm:
$$\frac{d}{dt}\Theta_t = a_t f(\Theta_t, \xi_t), \quad (4.121a)$$
$$\frac{d}{dt}\Theta_t^\rho = \frac{1}{1+t}[\Theta_t - \Theta_t^\rho]. \quad (4.121b)$$

What is crucial in this estimation technique that the first gain is relatively large: $(1+t)a_t \to \infty$. The solution to (4.12b) can be expressed as an approximate average:
$$\Theta_t^M = \frac{1}{1+T}\Theta_0^M + \frac{1}{1+T}\int_0^T \Theta_t \, dt, \quad T \geq 0.$$

It may make sense to average over the entire history, since this might induce initial transients. This is when (4.78) is usually preferred, which rests here: for $\kappa > 1$,
$$\Theta_t^M = \frac{1}{T-T_0}\int_{T_0}^T \Theta_t \, dt, \quad T \geq 0, T_0=T/\kappa. \quad (4.121c)$$

The choice of $T_0$ is so made that $1/(T-T_0) = \kappa/T$. The set of equations (4.121) are called Polyak-Ruppert averaging, but the theory that follows is restricted to (4.121c).

**Theorem 4.25** Suppose that the assumptions of Theorem 4.24 hold, so that in particular $a_t = 1/(1+t)^\rho$ with $\rho \in (0,1)$. Then, with $\Theta_t^*$ defined by (4.12c), with $\kappa > 1$, we have
$$\Theta_t^* = \Theta^* + a_t\kappa(\rho,\kappa)Y + \Phi_T, \quad (4.122)$$
Where $\bar{Y}$ is defined in (4.12b), and $\kappa(\rho,\kappa) = \kappa(1-(1/\kappa)^\rho)/\rho$, and where $\{\Phi_t\}$ is a bounded function of time. Consequently, the convergence rate is $1/T$ if and only if $\bar{Y} \neq 0$.

Exercise 4.11 provides a simple example for when $\bar{Y} \neq 0$, and averaging might actually slow convergence. Exercise 4.12 contains a positive message: When using qSGD #1, we might have $\bar{Y} \neq 0$, but its norm is of order $\epsilon$ (the scaling used in the algorithm).
