
# Optimal Control

At time $T_1 = (\mu_1 - \alpha_1)^{-1}$, the first buffer enters, and we have for $t > T_1, t \approx T_1$,

```
$q_t = q_{T_1} + t(0, \alpha_1 - \mu_2, \alpha_3, 0)^T$.
```

At time $T_2 = T_1 + q_{T_1}/(\mu_2 - \alpha_1)$, the second buffer will drain, and all of the work will be at three. Note that over the interval $[T_1, T_2]$, buffer 1 remains empty; the arrivals to buffer 1 at rate $\alpha_1$ are passed directly to buffer 2.

The main point is that during the entire interval $[0, T_2]$, the exit at Station 1 is starved. Starting from time $T_2$, an analogous situation arises, now the exit at Station 2 is temporarily starved. We can conclude that either $u_t(4) = 0$ or $u_t(2) = 0$ for all $t \ge 0$. This implies that

```
$u_t(2) + u_t(4) \le 1$, (3.57)
```

so that buffers 2 and 4 behave as if they are located at a single station. The inequality (3.57) resulting from this policy is known as the virtual load constraint. The virtual load and virtual workload process are defined by the following:

```
$\rho_v = \frac{\alpha_1}{\mu_2} + \frac{\alpha_3}{\mu_4}$ (3.58)
```

```
$w_t^v = \frac{q_t(1) + q_t(2)}{\mu_2} + \frac{q_t(3) + q_t(4)}{\mu_4} \quad t \ge 0$. (3.59)
```

We can compute

```
$\frac{dw_t^v}{dt} = \frac{\alpha_1 - \mu_2 u_t(2)}{\mu_2} + \frac{\alpha_3 - \mu_4 u_t(4)}{\mu_4} = \rho_v - [u_t(2) + u_t(4)]$.
```

If $\rho_v > 1$ then $\frac{dw_t^v}{dt} \ge -(1-\rho_v) > 0$ for all $t$, so that $\|q_t\| \to \infty$ as $t \to \infty$.

A specific example is

```
$\mu_1 = \mu_3 = 10; \quad \mu_2 = \mu_4 = 3; \quad \alpha_1 = \alpha_3 = 2$.
```

The network load is given by $\rho_v = 2(1/3 + 1/10) < 1$, which implies that there are many stabilizing policies. However, $\rho_v = 2(1/3 + 1/10) > 1$, so that the fluid model controlled by LBFS is unstable in the strongest possible sense.

# 3.9.4 Solving the HJB Equation

These examples illustrate optimal control solutions for models in continuous time.

Example 3.9.1 (LQR) The formulation of the linear quadratic regulator problem is as expected:

```
$$\frac{d}{dt}x = Fx + Gu, \quad x(0) = x_0; \quad J(x,u) = x^T S x + u^T Ru, \quad (3.60)$$
```

where $S$ is a positive semidefinite matrix, and $R > 0$. Provided the value function $J^*$ is finite valued, it follows that it is a quadratic function of $x$, and an optimal policy is obtained via linear state feedback. The proof of these statements is exactly the same as in Section 3.6. In particular, we know that $J^*(x) = x^T M^* x$ for $x$, then the HJB equation gives

```
$$\phi^*(x) = \argmin_u \{x^T S x + u^T Ru + [2M^*x]^T[Fx + Gu]\}; \quad = \argmin_u \{u^T Ru + 2x^T M^* Gu\},$$
```

where in this second equation we is obtained by imposing symmetry of $M^*$, $[M^*]^T = M^*$. The minimum of this quadratic function of $u$ is obtained by solving the linear equation:

```
$$\nabla_u(u^T Ru + 2x^T M^* Gu)|_{u=\phi^*(x)} = 0,$$
```

which gives $\phi^*(x) = -R^{-1}G^T M^* x$. The closed-loop dynamics are given by

```
$$\frac{d}{dt}x^* = Fx - GR^{-1}G^T M^* x,$$
```

The HJB equation (3.50) is also obtained from:

```
$$\frac{d}{dt}J^*(x^*) = -c_{\phi^*}(x^*); \quad c_{\phi^*}(x) = c(x, \phi^*(x)) = x^{*T}\{S + M^*GR^{-1}G^*\}x, \quad x \in X.$$
```

A fixed point for $M^*$ is also obtained from

```
$$0 = x^{*T}\{Sx + Ru + [2M^*x]^T[Fx + Gu]\}_{u=\phi^*(x)} = x^{*T}\{S + M^*GR^{-1}G^*\}x + x^{*T}\{2M^*F - 2M^*GR^{-1}G^*\}x,$$
```

Substitute $2M^*F$, and after canceling terms results in

```
$$0 = x^{*T}\{S + M^*F - M^*GR^{-1}G^*\},$$
```

Since this holds for any $x$, and since the matrix within the brackets is symmetric, it follows that $M^*$ is a positive semidefinite solution to the ARE:

```
$$0 = S + M^*F - M^*GR^{-1}G^*, \quad (3.61)$$
```

# Example 3.9.2 (Linear System with Polynomial Cost) Consider a scalar integrator model, with polynomial cost:

```
$$\frac{dx}{dt} = f(x,u) = u, \quad c(x,u) = u^2 + x^4. \quad (3.62)$$
```

The HJB equation $0 = \min_u (u \frac{d}{dx}J^*(x) + u^2 + x^4)$. Minimizing with respect to $u$ defines the state feedback solution

```
$$\phi^*(x) = -\frac{d}{dx}J^*(x).$$
```

The closed-loop system has the appearing

```
$$\frac{dx}{dt}x^* = -\frac{1}{2} \frac{d}{dx}J^*(x^*).$$
```

Substituting the formula for $u^*$ back into the HJB equation gives the differential equation

```
$$0 = \frac{d}{dx}J^*(x) + u^2 + x^4|_{u=\phi^*(x)} = -\frac{1}{4}(\frac{d}{dx}J^*(x))^2 + x^4,$$
```

giving $\frac{d}{dx}J^*(x) = \pm 2x$. The unique nonnegative and continuously differentiable solution is $J^*(x) = \frac{2}{3}|x|^3$, and hence the optimal policy is

```
$$\phi^*(x) = -\frac{1}{dx}J^*(x) = -x^2.$$
```
