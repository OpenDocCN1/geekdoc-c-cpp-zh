An enigmatic letter is fitting for this mysterious class of algorithms!

## Markov Chains

We begin Part II with the foundations of state space models, but now in a stochastic setting. The notation is essentially the same as in previous chapters, except that we use upper case to denote random variables: $X = \{X(0), X(1), X(2), \dots\}$ denotes a sample path of the state process. For each time $k \ge 0$, it is assumed that $X(k)$ takes values in a state space denoted $X(k)$; the state space is a closed subset of $\mathbb{R}^n$ (recall (2.22)). We don't run out a finite space, but there is no reason to be bound to this special case.

Recall from Section 2.3 that the process in nonlinear state model is interpreted as a sufficient statistic. Consider the controlled model (2.6), under a stationary policy $u(k) = \phi(x(k))$ for $k \ge 0$. To compute future states $x(j)$ for $j \ge k$, we only need to know $x(k)$; the prior history $x(i), i < k$ is irrelevant in determining behavior. The definition of a Markov chain is formulated to capture memoryless property in a stochastic environment. An example is an independent and identically distributed (i.i.d.) sequence $N$, $X(0) \sim \pi$ for a probability measure $\pi$, and there is no memory: $P\{X(k) \mid N(0), \dots, N(k-1)\} = \pi(S)$, for each $k \subset X$. (6.1)

Here are two definitions of a Markov chain. The first makes precise the "memoryless" in a milder term:

- **Memoryless property**: The stochastic process $X$ is a Markov chain if the following holds: For $S \subset X$, any time $k$, and initial $X(0)$, $P\{X(k+1) \in S \mid X(0), \dots, X(k)\}$ (6.2).

- **Nonlinear state model**: A Markov chain is a process that evolves according to nonlinear state space model, $X(k+1) = F(X(k), N(k+1))$. (6.3)

Where $N$ is i.i.d., and the initial condition $X(0)$ is specified. The first definition is slightly more general than the second because the dynamics defined by F do not depend upon time. We will restrict to time-homogeneous Markov chains throughout the book. The distribution of $X(k)$ for $k \ge 0$ is defined by the initial distribution (the distribution of the potentially random $X(0)$) and the transition kernel. This defines the one-step transition probabilities: $P(x,S) = P\{X(k+1) \in S \mid X(k) = x\}$, for $x \in X, S \subset X$. (6.4) It is called a transition matrix if the state space is finite. For the nonlinear state model (6.3), $P(x,S) = P\{X(1) \in S \mid X(0) = x\} = P\{F(x,N(1)) \in S\}$.

For $j > 1$, the j-step transition probability from $x$ to $S$ is defined as follows: $P^j(x,S) = P\{X(k+j) \in S \mid X(k) = x\}$. (6.5)

In the majority of cases, we no longer think about equilibria $x \in X$ when studying Markov chains. We seek an equilibrium measure $\pi$ (more commonly called an invariant measure) that satisfies the ergodic theorem: $\lim_{k\to\infty} P^k(x,S) = \pi(S)$, any $x \in X$ and $S \subset X$. (6.6)

We will see that this implies the existence of a steady state: If $X(0) \sim \pi$, then $X$ is a stationary process (so, in particular, $X(k) \sim \pi$ for all $k$). This is interpreted as a stability property for the Markov chain, much like global asymptotic stability for deterministic nonlinear state models.

### 6.1.1 Notation and Conventions

If you have taken a course with an introduction to measure theory, then you know that care may be taken in defining the class of sets $S$ for (6.4) and the equations that follow meaningful. For those of you with this background, keep in mind that $X$ will be a Borel subset of Euclidean space (such as a closed subset), and any $S \subset X$ will also be assumed to have this property. We denote $S \in \mathcal{B}(X)$. In $\mathbb{R}$ include any interval $[a,b], [a,b)$, or $(a,b)$ with $b > a$, and any finite or countable union of intervals. Similarly, any set $S_h(r) = \{x : h(x) \le r\}$ is a Borel set for each $r$.

**Never heard the word "Borel"?** Don't worry. Measure theory is not important for understanding any of the concepts that follow. The notation is required because transition kernels cannot in general be defined on every subset of the state space, except when the state space is finite or countably infinite.

### Integrals and Expectations

The symbols $\mu, \nu$, and $\pi$ are reserved for probability measures over $\mathcal{B}(X)$. We opt for the probability mass function (pmf) when $X$ is finite or countable.
