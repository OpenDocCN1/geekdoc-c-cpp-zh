# 8.2.5 Algorithm Performance

An emphasis in these later chapters of the book is consideration of covariance of parameter estimates, as defined in (8.5). The asymptotic covariance (8.6) exists under general conditions, and a representation is possible based on matrices: the linearization matrix

```
$A = A(\theta^*) \overset{det}{=} \partial_theta f (\theta^*)$ (8.26)
```

and the steady-state disturbance covariance:

```
$$\Delta_k^n = \overset{def}{=} \lim_{n\to\infty} E[M_n M_n], \quad M_n = \sum_{k=1}^n \Delta_k^n,$ (8.27)
```

where $\Delta_k^n \overset{def}{=} f_k(\theta^*)$. This is also known as the asymptotic covariance of $\{\Delta_k^n\}$, as it is the covariance that appears in the Central Limit Theorem for this sequence. If $\{\Delta_k^n\}$ is uncorrelated, then $\Sigma\Delta = \Sigma\theta(\Delta_k^n)^T$.

The following conclusions can be expected, subject to additional conditions (such as stability of the ODE (8.4a))

+   (i) Step-size $\alpha_n = g/(n+n_0)$, is finite provided each eigenvalue of $A$ satisfies $\Re(\lambda(A)) < -\frac{1}{2}$, and in this case $\Sigma\theta$ solves the Lyapunov equation

```
$$\g+I)\Sigma\theta + \Sigma\theta(g+I)^T + g^2\Sigma\Delta = 0.$ (8.28a)
```

+   (ii) For $\alpha_n = g/(n+n_0)^\rho$ with $0.5 < \rho < 1$, the definition of asymptotic covariance is modified:

```
$$\Sigma\theta = \lim_{n\to\infty} \Sigma_n.$
```

This is finite provided $\Re(\lambda(A)) < 0$ ($A$ is Hurwitz), and in this case $\Sigma\theta$ solves

```
$$\Sigma\theta A^T + A\Sigma\theta + g\Sigma\Delta = 0.$ (8.28b)
```
