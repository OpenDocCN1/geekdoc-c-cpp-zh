# Optimal Control

# Fluid Model

In this simplest model, the buffer levels take on nonnegative but continuous values. Raw material flows into buffers 1 and 3 continuously at rates $\alpha_1$ and $\alpha_3$, respectively. Each of the two stations has a single server. For example, at station 1 the server may work on buffer 1 or buffer 4. During a time interval during which server devoting its capacity to buffer 1, material flows from buffer 1 to buffer 2 at rate $\mu_1$. The evolution of the queue lengths can be described by the linear state space model, with state $q$ evolving in $X = \mathbb{R}^4_+$.

```
$\frac{dq}{dt} = Fq + Gu_t + \alpha.$
```

The right derivative $\frac{d'}{dt}$ is used since trajectories are piecewise smooth. The system parameters are $\alpha = (\alpha_1, \alpha_2, \alpha_4)^	op$.

```
$F = 0_{4\times 4} \quad G = \begin{bmatrix} \mu_1 & 0 & 0 & 0 \ 0 & -\mu_2 & 0 & 0 \ 0 & 0 & -\mu_3 & 0 \ 0 & 0 & \mu_3 & -\mu_4 \end{bmatrix}$
```

The four-dimensional input $u(i)$ is subject to several constraints:

+   - $u_t(i) \geq 0$ for each $i$ (it isn't possible to "un-do" processing at a buffer).
- $u_t(1) + u_t(4) \leq 1$ and $u_t(2) + u_t(3) \leq 1$ (station constraints).
- $q'_t(i) \geq 0$ whenever $q_t(i) = 0$ (enforces nonnegativity of the four buffers).

Collectively these constraints define the region $U(x)$ for each $x \in X = \mathbb{R}^4_+$.

# Stabilizability and Load

Is the equilibrium for some input? Is this one question to answer the dynamics are linear. If $q_t \equiv q'_t = 0$ for some input $u^*_t$, and all $t$, then

```
$\frac{d}{dt} = Fq^* + Gu^*_t + \alpha = Gu^*_t + \alpha.$
```

This gives $u^*_t \equiv u^c = -G^{-1}\alpha$. The matrix $-G^{-1}$ exists and has nonnegative entries. To see if $u^c \in U$, we consider the station constraints, expressed as $Cu^c \leq 1$, where $C$ is known as the constituency matrix:

```
$C = \begin{bmatrix} 1 & 0 & 0 & 1 \ 0 & 1 & 1 & 0 \end{bmatrix}$
```

The $2 \times 4$ dimensional matrix obtained as the product is the workload matrix:

```
$\Xi \equiv -G^{-1} = \begin{bmatrix} 1/\mu_1 & 0 & 1/\mu_4 & 0 \ 1/\mu_2 & 0 & 1/\mu_3 & 0 \end{bmatrix}$
```

The two-dimensional vector $\rho \equiv Cu^c$ is obviously important, since $ho_i \leq 1$ for each $i$ is feasible of usability of $u^c$. The network load is defined to be the maximum, $\rho_* = \max_i \rho_i$.

There is also a dynamic notion of workload, $w_t \equiv \Xi q_t$, which evolves as

```
$\frac{d'}{dt} = -CG^{-1}\{Gu_t + \alpha\} = -Cu_t + \rho.$
```
