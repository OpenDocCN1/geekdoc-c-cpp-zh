## 7.5.1 Fluid Model Dynamics

Under the assumption that the disturbance is zero mean, the fluid model in discrete time is the linear state space model introduced in (2.13a):

```
$x(k+1) = Fx(k) + Gu(k), \quad k \geq 0.$
```

Before turning to comparisons, let's compare the dynamics of the two models under control:

```
$x(k+1) = Fx(k) \quad X(k+1) = FX(k) + N(k+1), \quad k \geq 0. \quad (7.46)$
```

Consider the special case used as an example in Section 2.4.6, with

```
$F = I + 0.02A, \quad A = \begin{pmatrix} -0.2, 1 \\ -1, & -0.2 \end{pmatrix}$.
```

The fluid model in continuous time is defined by $\frac{dx(t)}{dt} = \bar{f}(x) = 0.02Ax$ (in this example, with $u \equiv 0$). This is entirely consistent with the construction of $F$ (which was based on Euler approximation). We can now explain the nature of the disturbance used to obtain the plots shown in Figure 2.7: $N$ was i.i.d. and Gaussian, with rank-deficient covariance: $N(k) = gV(k)$ with $V$ scalar $1/2$. Trajectories of the two state processes are shown in Figure 2.7. A careful look at the figure right reveals the degeneracy of the noise, which influences the state directly in directions $\pm g$.

## 7.5.2 DP Equations

The linear dynamics in (7.45) are the explanation for the "L" in LQG, and the "Q" appears because we adopt the quadratic cost appearing in LQR framework:

```
$c(x, u) = x^T Sx + u^T Ru, \quad (7.47)$
```

With $S \geq 0$ and $R > 0$. Positive explanation of the "G" because it is irrelevant until we adopt the measurements $Y$. The infinite horizon is typically infinite, so let's consider the first-horizon problem

```
$J(x) = E\left[ X(N)^T R X(N) + \sum_{k=0}^{N-1} (X(k)^T SX(k) + U(k)^T RU(k)) \mid X(0) = x \right] \quad (7.48)$
```

With $R \geq 0$. The minimization of $J$ is easily obtained as linear state feedback:

**Proposition 7.4** (i) The minimization of (7.48) over all policies is obtained using linear state feedback $U(k) = -K_k X(k)$, in which the gain matrix is

```
$K_k = [R+G^T M_k]^{-1}G^T M_k,$
```

where $\{M_k\}$ is determined by the matrix Riccati difference equation, which runs backward in time:

```
$M_k = F^T(M_{k+1}-M_k)(G^T M_k+R)^{-1}G^T M_{k+1} + S,$
```

- (ii) The value function is quadratic: $J_N^\infty(x)=J_N^\infty(0)+x^T M_0 x$.
- (iii) The limiting limits exists:

```
$\eta^\star = \lim_{N\to\infty} \frac{1}{N}J_N^\infty(x) \quad (\text{independent of } x).$
```

```
$h^*(x) = \lim_{N\to\infty} [J_N^\infty(x)-J_N^\infty(0)], \quad \in X.$
```

The pair solves the ACOE (7.5), for $\eta^\star$ the optimal average cost. The average-cost optimal policy (7.6) is linear feedback:

```
$\phi^*(x) = -K^\star x \text{ with } K^\star = [R+G^T M^\star G]^{-1}G^T M^\star,$
```

where $M^\star$ is the solution to the algebraic Riccati equation (3.40):

```
$M^\star = F^T(M^\star-M^\star G^T M^\star G)^{-1}G^T M^\star + S.$
```

A remarkable takeaway from this result is that the finite horizon and average-cost control problems do not depend in any way on the distribution of the disturbance despite the assumption that they are zero mean with finite variance, and the standing i.i.d. assumptions (even the independence assumption can be relaxed, to a restricted definition of optimality ([7,81])). In addition, the optimal policy for the average-cost control problem coincides with the optimal policy for the associated fluid model (in discrete time) with total-cost criterion: Recall (3.39).

The only reason to impose assumptions on the distributions is when we come to the next topic.

## 7.5 Partial Observations

If only $Y$ is observed, we may attempt to minimize $J$ over all functions of these observations. That is, restrict inputs to functions of current and past observations:

```
$U(k) = \phi_k(Y(0), \dots, Y(k)).$
```

An explicit solution can be obtained under the assumption that $(N,W)$ is jointly Gaussian:

**Proposition 7.5** Suppose that $(N,W)$ is jointly Gaussian, and independent of $X(0)$. Then:

- (i) The solution to the finite horizon optimal control problem, in which $J$ is minimized over all input sequences of the form (7.49), is obtained using

```
$U(k) = -K_k\hat{X}(k).$
```

The gain $K_k$ is the same matrix sequence introduced in Proposition 7.4.

260

The estimate $\hat{X}(k)$ is defined recursively as follows, based on this important fact: The conditional distribution of $X(k)$ given $Y_0^k$ is Gaussian $N(m_k,\Sigma_k)$ in which

- (a) The conditional mean $m_k = \hat{X}(k)$ evolves as the time-varying linear system,

```
$\hat{X}(k+1) = F\hat{X}(k) + GU(k) + L_k(Y(k+1)-\hat{X}(k)), \quad k \ge 0$
```

with initial condition

```
$\hat{X}(0) = E[X(0)].$
```

- (b) The filter gains are defined by

```
$L_k = \Sigma_{k+1}H^T(H\Sigma_{k+1}H^T+R)^{-1}, \quad k \ge 1.$
```

- (c) The conditional covariance does not depend on the observations, but evolves according to deterministic Riccati recursion:

```
$\Sigma_k = F^T\Sigma_{k+1}(I-L_kH)F + Q, \quad \text{for } k \ge 1, \quad (7.50)$
```

with initial condition

```
$\Sigma_0 = E[X(0)X(0)^T], \quad \tilde{X}(0) = X(0) - \hat{X}(0).$
```

- (ii) The solution to the average-cost control problem, subject to the constraint (7.49) on the input sequence, is obtained using linear feedback:

```
$U(k) = -K^*\hat{X}(k),$
```

where $\hat{X}(k)$ is the conditional mean, as in (i). One step in proof of the proposition is that the cost can be expressed in terms of the new state $\tilde{X}$ as follows:

```
$E[J(k,k)] = E[X(k)^TX(k) + U(k)^TU(k)] + E[\tilde{X}(k)^T\tilde{X}(k)],$
```

where tilde denotes error: $\tilde{X}(k) = X(k) - \hat{X}(k)$. The last term is independent of control:

```
$E[\tilde{X}(k)^T\tilde{X}(k)] = \text{trace}(\Sigma_k).$
```

This leads to the *separation principle*: The optimal input is the "plug-and-play" control law:

```
$U(k) = \phi^*(\hat{X}(k)) = K^*\hat{X}(k), \quad (7.51)$
```

where $K^*$ is the feedback gain obtained for the control problem with full observations. This optimal control solution is known as *certainty-equivalent form*. Please don't forget that the certainty-equivalence conclusion is very particular to the assumptions imposed. It may be tempting to use the policy $U(k) = \phi^*(\hat{X}(k))$ in more general settings when the state is only partially observed. In general the optimal feedback law requires more information regarding the conditional distribution of the state process. Appendix C contains a derivation of the optimal policy for more observed control systems.

## 7.6 A Queuing Game

We return now to the two-station network model with four-dimensional queue-length processes introduced in Section 3.9.3.

An MDP model can be obtained by analogy with the fluid model described there. We might opt for an extension of the CRW model for the single queue (7.29), in which the four buffers evolve in discrete time as:

```
$X_1(k+1) = X_1(k) - S_1(k+1)U_1(k) + A_1(k+1),$
$X_2(k+1) = X_2(k) - S_2(k+1)U_2(k) + S_1(k+1),$
$X_3(k+1) = X_3(k) - S_3(k+1)U_3(k) + A_3(k+1),$
$X_4(k+1) = X_4(k) - S_4(k+1)U_4(k) + S_3(k+1),$
```

in each $S_i(k)$ is Bernoulli with mean $\mu_i$, and each $A_i(k)$ has mean $\alpha_i$ and finite variance. This is subject to a Controlled Markov chain, it is necessary to assume that the six-dimensional stochastic process $(S, A)$ is i.i.d. The input process is subject to the same constraints as the fluid model, but in addition it is assumed that $U_i(k)$ takes values zero or one for each $i$ and $k$. Solidarity between the fluid model and this MDP model is investigated in [159], where you can find numerical results similar to what was obtained for the single queue.
