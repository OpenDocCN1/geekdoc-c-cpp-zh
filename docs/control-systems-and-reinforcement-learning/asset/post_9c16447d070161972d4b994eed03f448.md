### 9.1.1 Fixed-Policy Value Functions and DP Equations

Two value functions are of great interest in this chapter:

```
$h(x) = \sum_{k=0}^{\infty} \gamma^k E[c(\Phi(k)) \mid X(0) = x], \quad U(k) = \phi(\Phi(k)), k \geq 0 \quad (9.6a)$
```

```
$Q(x,u) = \sum_{k=0}^{\infty} \gamma^k E[c(\Phi(k)) \mid X(0) = x, U(0) = u], \quad U(k) = \phi(\Phi(k)), k \geq 1 \quad (9.6b)$
```

The latter is known as fixed-policy Q-function. It facilitates dynamic programming equation:

```
$h(x) = c_{\phi}(x) + \gamma \sum_{x'} P_{\phi}(x,x')h(x'), \quad Q(x,u) = c(x,u) + \gamma \sum_{x'} P_{\phi}(x,x')Q(x') \quad (9.7)$
```

with $c_{\phi}(x) = c(x, \phi)$ and $Q(x) = Q(x, \phi)$ for $x \in X$ (recall 9.5a). The DP equation for $h$ has been used to approximate $h$. In this case, it is convenient to suppress dependency of the transition matrix and cost function on $\phi$. That is, we write $P$ instead of $P_{\phi}$, and $c$ instead of $c_{\phi}$. Under these conventions, the DP equation for $h$ in (9.7) becomes $h = c + \gamma P$, with probabilistic interpretation:

```
$0 = E[-h(X(k)) + c(X(k)) + \gamma h(X(k+1)) \mid X(0), \dots, X(k)], \quad k \geq 0 \quad (9.8)$
```

The fact that $h$ solves linear fixed-point equation makes the function approximation problem far simpler than nonlinear fixed-point equation (9.1). The biggest challenge is, how do we devise a learning algorithm that takes into account expectation appearing in (9.8)? Approaches to answer this are surveyed in Section 9.2. We answer this question: What do we do with a value function? The most common answer is the policy improvement step in the policy iteration algorithm (also called PIA).

### 9.1.2 PIA and the Q-Function

For discounted-cost criterion, the algorithm is defined as follows: Given an initial policy $\phi_0$, a sequence $(\phi_n, h_n)$ is defined as follows. At stage $n$, given $\phi_n$, these steps:

- (i) Solve
```
$c_{\phi_n} + \gamma P_n h_n = h_n \quad (9.9a)$
```
where $P_n = P_{\phi_n}$ is the transition matrix obtained when the chain is controlled using $\phi_n$.

- (ii) Construct a new policy:
```
$\Phi_{n+1}(x) = \arg\min_{u} c(x,u) + \gamma P_u h_n(x), \quad x \in X \quad (9.9b)$
```
where $P_u^\gamma h_n(x)$ is defined in (7.15).

This algorithm is consistent, with $h_n(x) \downarrow h(x)$ for each $x$, as $n \to \infty (the fact that $h_n(x)$ is nonincreasing is a corollary to Proposition 9.2). TD-learning algorithms are designed to approximate the solution to (9.9a). However, we cannot update policy (9.9b) unless we have the model $P_u$, and are also prepared to solve the minimization over $u$ for each $x$. A potential solution to both challenges is to approximate the function of two variables within the brackets in (9.9b), the fixed-policy Q-function associated with the policy $\Phi_n$:

```
$Q_n(x,u) = c(x,u) + \gamma P_u h_n(x).$
```

```
$Q_n(x,u) = \sum_{k=0}^{\infty} \gamma^k E[c(\Phi(k)) | \Phi(0) = x,u] \quad \text{with } U = \Phi_n(X(k)) \text{ for } k \ge 1,$
```

along with a fixed-point iteration that varies up to (9.9a):

```
$0 = E[-Q_n(\Phi(n)) + c(\Phi(n)) + \gamma Q_n(\Phi(n+1)) | F_n], \text{with } U = \Phi_n(X(k)) \text{ for each } k,$
and with $F_n$ shorthand for $\Phi(0), \dots, \Phi(n).$
Any TD-learning algorithm can be applied to approximate this Q-function, which is made possible by recognizing that the pair process $\mathbf{\Phi}$ is a time-homogeneous Markov chain, whenever $U$ is defined using a stationary Markov policy.
```

A TD-learning algorithm designed to estimate a fixed-policy Q-function is commonly known as SARSA. However, as explained in Section 5.3, we will opt for the TD-learning regardless of whether we are estimating $h$ or $Q$.

## 9.3 Advantage Functions

If we compute exactly the Q-function for a policy $\Phi$, then the policy improvement step is given by $\Phi^+(x) = \arg\min_u Q(x,u)$. Rather than estimate $Q$, we could estimate $Q-G$ for any function $G$ that does not depend upon $U$. The Q-policy greedy is:

```
$\Phi^+(x) = \arg\min_u [Q(x,u) - G(x)] = \arg\min_u Q(x,u). \quad (9.10)$
```
