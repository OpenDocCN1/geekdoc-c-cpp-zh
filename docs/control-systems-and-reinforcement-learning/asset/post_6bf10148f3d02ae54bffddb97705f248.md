where $z$ evolves on $\mathbb{R}^p$ for some integer $p \geq 1$. The functions $F_m : \mathbb{R}^p \to \mathbb{R}^p$ and $G_m : \mathbb{R}^p \to \mathbb{R}$ are assumed known. Part of this state description is $d(k+1) = d(k)$ if the disturbance is static.
Given the larger state model (2.8, 2.10), we might opt for an *observer*-based solution:

```
$u(k) = \phi(x(k),r(k),d(k)).
```

where $\{d(k)\}$ are estimates of the disturbance, based on input–output measurements up to time $k$ we replace $x(k)$ with $x'(k)$ if we don't directly observe the state. Observer designs make about 20% of a typical introductory course on state control systems [7, 29, 76]. A second option, call the Internal Model Principle, is to create a different state augmentation that is entirely observed. For the sake of illustration, consider the case of constant reference/disturbance. We have this with $z(k) = y_m(k)$, and $F_m$ is the identity function:

```
$z(k+1) = z(k).
```

State augmentation is performed on this model: define for each $k$,

```
$z'(k+1) = z'(k)+\tilde{y}(k).\quad (2.11)
```

with error $\tilde{y}(k+1)$ defined above (2.9). Regarding $(x(k),z'(k))$ as the state for the purposes of control, and have state feedback takes the

```
$u(k) = \phi(x(k),z'(k)).\quad (2.12)
```

The control design (2.12) is an example of integral control, where $z'$ is the sum of the errors (discrete-time analog of integration).
Suppose that $z'(k)$ converges to some finite limit $z'(\infty)$, as $k \to \infty$, the value of the limit is irrelevant. Implement perfect tracking:

```
$$\lim_{k\to\infty} \tilde{y}(k) = \lim_{k\to\infty} |z'(k+1)-z'(k)| = 0.
```

This conclusion is remarkable: to obtain perfect tracking, we only require that the policy $\phi$ converges to *some* finite limit. The secret to success is a hidden element of “learning” that with integral control.

## 2.3 State Space Models

State augmentation has many other dimensions. If we have forecasts of significant disturbances, then it may be to make use of these data: forecasts can be used in the design of the feedforward component $u_{ff}(k)$ in the decomposition (2.1), or they may be used for state augmentation.

## 2.3.3 Linear State Space Model

When $F$ and $G$ are linear, we obtain the linear state space model:

```
$x(k+1) = Fx(k) + Gu(k), \quad x(0) = x_0,$
$y(k) = Hx(k) + Eu(k),$
```

where $F,G,H,E$ are matrices of suitable dimension (in particular, $F$ is $n \times n$ for $n$-dimensional state space).

The state model is not unique, in the sense that there are many choices for $(F,G,H,E)$ that result in the same input-output behavior, even though definition of the state process $x$ will change depending on the model. And never forget, we may add additional components to $x(k)$ as a means to solve a control problem.

## Linear State Feedback

The linear model (2.13) is often constructed so that the goal is to keep $x(k)$ near the origin—the regulation problem; consider, for example, flight control, where we wish to maintain velocity and altitude at constant values. We first normalize the problem so that these constant values are zero. It is then common to apply a linear control law

```
$u(k) = -Kx(k),$
```

where $K$ is called the gain matrix. To evaluate choice of gain, we take on something like a reference signal:

```
$u(k) = -Kx(k) + v(k),$
```

The closed-loop behavior with new "input" has a similar state space description:

```
$x(k+1) = (F-GK)x(k) + Gu(k), \quad x(0) = x_0,$
$y(k) = (C-EK)x(k) + Ev(k),$
```

The signal $v(k)$ appearing in (2.15a) is viewed as an “input disturbance.” A goal of control is to choose $K$ so that the closed-loop behavior is not sensitive to this disturbance while simultaneously ensuring good tracking.

## Realization Theory

The ARMA model (2.4) admits an infinite number of distinct state space descriptions. Let’s begin with the scalar auto-regressive model:

```
$y(k) = -\sum_{i=1}^{N} a_iy(k-i) + u(k), \quad k \geq 0$.
```

which is (2,4), $M = 0$ and $b_0 = 1$. We obtain the state space model (2.13) with $n = N$
by choosing $x(k) = (y(k), \dots, y(k-N+1))$, and

```
$F = \begin{pmatrix} -a_1 & -a_2 & -a_3 & \dots & -a_N \\ 1 & 0 & 0 & \dots & 0 \\ 0 & 1 & 0 & \dots & 0 \\ 0 & 0 & 1 & \dots & 0 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & \dots & 1 \end{pmatrix} G = \begin{pmatrix} 1 \\ 0 \\ 0 \\ \vdots \\ 0 \end{pmatrix}, \quad (2.16)$
```

$H = [1, 0, 0, \dots, 0]$, and $E = E$.
This construction can be generalized: with $M = N-1$ in (2.4), we define an
intermediate process

```
$z(k) = \sum_{i=1}^{N} a_i z(k-i) + u(k), \quad k \geq 0. \quad (2.17)$
```

So we arrive at a state space model with state space $x(k) = (z(k), \dots, z(k-N+1))^\top$.
