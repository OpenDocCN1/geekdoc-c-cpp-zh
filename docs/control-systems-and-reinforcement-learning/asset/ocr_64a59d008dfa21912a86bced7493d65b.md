# 3.9.2 Spiders and Flies

In the example illustrated in Figure 3.4, there are 15 "agents" (the spiders) that are cooperating to capture a single fly. In any "realistic" version of this example, the fly will hop around the grid in an unpredictable fashion. This realism requires a stochastic model that is beyond our reach at this stage of the book. For now, let's assume the fly is stationary, and the spiders move to their desired position without error.

![](bbox=[0.148, 0.473, 0.363, 0.663])

At each time $k$, each spider can move to the next square (horizontally or vertically), or in its current position. There are five possible moves per spider: the input space $U$ is massive: $|U| = 5^{15}$ (over $10^{10}$ elements). The minimization step (3.8) in the value iteration is infeasible.

**Figure 3.4** A multi-agent control problem: 15 spiders cooperate to kill a fly.

The state space is also large: If we define the state as $|X|=(10)^{18}$ (over $10^{17}$ elements). Let's not worry about this complexity right now. We will develop techniques to effectively compress a complex state space.

The size of the input space can be reduced dramatically by a modification of dynamics. This system as evolves in discrete time, with an increment from $k$ to $k+1$ representing spiders in "real time." In the new system description, we divide this by 15, and enforce that only one spider changes position at each time step on this new scale. For this, we assume that there is a unique number $1,\dots,15$ associated with each spider, and the spiders move in the given order.
