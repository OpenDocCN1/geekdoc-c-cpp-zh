# Mathematical Background

A finite-valued random variable $H$ that is $\mathcal{F}_t$-measurable can be expressed as an infinite sum:

```
$H = \sum_{n=0}^{\infty} h_n(X_0, \dots, X_n)\mathbb{1}\{\tau = n\}$
```

for a sequence of functions $\{h_n\}$; this is true for what the required property:

```
$H\mathbb{1}\{\tau = k\ = h_k(X_0, \dots, X_k)\mathbb{1}\{\tau = k\\}$ is $\mathcal{F}_k$-measurable for each $k$.
```

An example is the random variable $X_{\tau}$, defined by setting $X_{\tau} = X_n$ on the event $\{\tau = n\}:

```
$X_{\tau} = \sum_{n=0}^{\infty} X_n\mathbb{1}\{\tau = n\}$
```

Finally, we come to a key definition:

**Strong Markov Property X** has the strong Markov property if for any initial distribution $\mu$, any real-valued bounded random variable $H$, and any stopping time $\tau$,

```
$E_{\mu}[\theta^{\tau} H | \mathcal{F}_{\tau}] = E_{X_{\tau}}[H] \quad a.s. [\mathcal{P}_{\mu}]$, on the event $\{\tau < \infty\},\quadquad (A.6)
```

**Proposition A.2** For a Markov chain **X** with a discrete time parameter, the **strong Markov property** always holds.

*Proof* This is a consequence of decomposing the expectations on both sides of (A.6) over the set where $\{\tau = n\}$, and using the ordinary Markov property, in the form of equation (A.4), at each of these fixed times $n$.
