How is the score function defined for a general state space? Suppose that X = R^n and there is a transition density:

```
$P_{	heta}(x,A) = \int_{y \in A} p_{	heta}(x,y)dy, \quad x \in X, A \in B(X).
```

In this case, the definition is analogue to the finite state space case

```
$S^{	heta}(x,x') = \nabla_{	heta}\log p_{	heta}(x,x'), \quad x,x' \in X. \quad (6.54)
```

Lemma 6.7 continues to hold with this definition of the score function, subject to smoothness assumptions on the density, and growth conditions on $g$.

Consider, for example, the nonlinear model with additive noise, $X(k+1) = F(X(k);\theta)$, where the marginal of $N$ has density $p_N$. For $g: X \to R$, we have

```
$P_{	heta}(x) = \int g(F(x;\theta) + z) p_N(z)dz$.
```

Consequently, it would appear that $\nabla_{	heta}P_{	heta}(x)$ requires differentiation of $g$. This is avoided through the change of variables $y = F(x;\theta)$

```
$P_{	heta}(x) = \int g(y)p_{	heta}(x,y)dy, \quad p_{	heta}(x,y) = p_N(y - F(x;\theta))$,
```

and this, we obtain a version of Lemma 6.7:

```
$\nabla_{	heta}P_{	heta}(x) = E[g(X(k+1))S^{	heta}(X,X(k+1)) | X(k)=x],\nS^{	heta}(x,x') = \nabla_{	heta}\log\{p_N(x' - F(x;\theta))\}, \quad x,x' \in X. \quad (6.55)
```
