That is, $\omega \in \mathcal{G}$ if there is an admissible input $U$ and a subsequence $\{N_i\}$ such that

```
$\lim_{i\to\infty} \hat{N}_i(x,u) = \varrho(x,u) \quad \text{all } x,u. \quad (B.20)$
```

It is known that $\mathcal{G}$ is a polyhedron with a single characterization is easily obtained:

+   (1) Any $\omega \in \mathcal{G}$ is a pmf on $X \times U$.\nA factorization is obtained via Bayes's rule:

```
$\varrho(x,u) = \pi(x)\phi(u|x) \quad (B.21)$
```

$\pi(x) = \sum_{u} \varrho(x,u), \phi(u|x) = \frac{\varrho(x,u)}{\pi(x)} \quad \text{all } x,u.$

Let $P_{\Phi}$ denote the transition matrix

```
$P_{\Phi}(x,x') = \sum_{u} \check{\phi}(u|x)P_u(x,x').$
```

+   (2) $\pi$ is an invariant pmf for $P_{\Phi}$. The main step in the proof is the following consequence of (B.20):

```
$\lim_{i\to\infty} \hat{N}_i+1(x,u) = \varrho(x,u) \quad \text{all } x,u.$
```

We arrive at a DCPL for the ACOE:

# ACOE Linear Program

| \eta^* = \min \sum_{u,x} \varrho(x,u)c(x,u) \quad (B.22a)\ns.t. \ \sum_{u,x} \varrho(x,u)P_u(x,x') = \sum_{u} \varrho(x',u), \quad x' \in X, \quad (B.22b)\n\sum_{u,x} \varrho(x,u) = 1, \quad \varrho \ge 0. \quad (B.22c) |

Justification is provided in the following. See [63] or [254, section 9.2] for details.

**Proposition 3** The set $\mathcal{G}$ is the convex set characterized by (B.22b, B.22c). The optimizer $\varrho^*$ defines an optimal policy $\phi^*$ via the factorization (B.21).

The LP approach is more flexible to extensions, such as multi-objective optimal control: Given a collection of functions $\{c^i\}$ and bounds $\{\eta^i\}$, we can consider the following:

```
$\min (\varrho,c) \quad \text{s.t.} \quad \varrho \in \mathcal{G}.\n(\varrho,c^i) \le \eta^i \quad \text{each } i.$
```
