# 9.3.2 Mean-Square Value Function Error

An alternative mean-square error is defined in terms of the function value:

```
$$\theta^* = \arg\min_{\theta} ||h^\theta - h||$
```

in which the choice of norm is not part of the design of the algorithm. Most common is

```
$||h^\theta - h||_{\pi}^2 = \sum_{x\in X} (h^\theta(x) - h(x))^2\pi(x)$,
```

in which $\pi$ is the steady-state penalty for $X$.\nIt is remarkable that this loss function can be minimized without observations of $\{h(X(k))\}$. One class of algorithms for this purpose is TD(1)-learning. The algorithm is defined in Section 9.4.1, and conditions under which it solves (9.33) are presented in Theorem 9.7.

# 9.3.3 Projected Bellman Error

Assumed given a $d$-dimensional stochastic process $\zeta$ known as the sequence of eligibility vectors. The goal is to obtain the vector $\theta^* \in \mathbb{R}^d$ that solves the Galerkin relation of (9.8). The smoothing property of contraction expectation gives

```
$0 = E[\{-\h^\theta(X(k)) + c(X(k)) + \gamma h^\theta(X(k+1))\}\zeta_k(i)], \quad 1 \le i \le d$.
```

It is usually that the expectation is in steady that $X(k)$ is distributed according to $\pi$. If $h = h^\theta$ for some $\theta \in \mathbb{R}^d$, and the solution to (9.35) is unique, then the Galerkin approach will yield the exact solution.

# 9.4 TD(\lambda) Learning

The goal of this algorithm is to solve (9.35) for a particular choice of eligibility vector. We begin with a special case for which there is a supporting theory.

# 9.4.1 Linear Function Class

In TD(\lambda$) learning with linear function approximation, the eligibility vectors are defined by passing $\{\psi(X(n))\}$ through a first-order low-pass filter:

```
$$\zeta_{n+1} = \lambda\zeta_n + \psi(X(n+1)), \quad n \ge 0.$.
```

It is always assumed that $\lambda \in [0, 1]$.
