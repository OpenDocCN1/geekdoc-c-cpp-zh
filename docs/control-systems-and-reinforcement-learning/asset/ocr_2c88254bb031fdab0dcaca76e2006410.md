
# qSGD #2

For a given $d \times d$ positive definite matrix $G$, and initial condition $\Theta_0$,

```
$$\frac{d}{dt}\Theta_t = -\frac{1}{\varepsilon}G\varepsilon_d\Gamma(\Psi_t)..$
```

```
$$\Psi_t = \Theta_t + \varepsilon_t.$
```

This algorithm fits neatly in the ESC architecture in Figure 4.8, in which the high-pass (HP) filters are chosen to be pure differentiation:

```
$$\dot{\Gamma}(t) = \frac{d}{dt}\varepsilon_t \times \frac{d}{dt}\Gamma(\Psi_t). \in \mathbb{R}^{2m}$
```

```

```
