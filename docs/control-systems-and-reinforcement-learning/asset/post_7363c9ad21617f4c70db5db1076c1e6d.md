
This is optimal for any criterion: finite horizon, discounted, or average reward. However, we only observe the rewards received $\{R(j) : j < k\}$, so this policy is not feasible.

## 7.8 Bandits

(ii) The infinite horizon optimal reward is defined by

```
$\eta^* = \max_{N \to \infty} \frac{1}{N} \sum_{k=1}^{N} R(k).$
```

Denote $\bar{f}_u = \text{E}[Z_u(k)]$ (assumed independent of $k$), and $\bar{f}^* = \max_u \bar{f}_u$. An optimizing policy is given by the open-loop strategy,

```
$U^*(k) = \arg \max_{1 \le u \le K} \bar{f}_u$.
```

This is not feasible unless the means are given.

We can coarse estimate $\bar{f}_u : 1 \le u \le K$ using Monte Carlo, which is an example of exploration. However, for any action $u \in \{1, \dots, K\}$, an accurate estimate of $\bar{f}_u$ will likely require frequent selection of this action. In the big-money applications of bandit theory (such as in advertising), we are learning as went to maximize profit. This means we must minimize the time spent exploring with suboptimal actions, which motivates a finer notion of optimal reward:

**Regret:** For a given time horizon $\mathcal{N}$, the regret is defined as the sum

```
$L_{\mathcal{N}} = \sum_{k=1}^{\mathcal{N}} {\bar{f}^* - R(k)}\ \quad (7.55)
```

Under mild additional assumptions, its mean grows logarithmically in $\mathcal{N}$ for the best policies.

### 7.8.2 Bayesian Bandits

If we formulate the bandit problem within an MDP setting, theory in Appendix C predicts that we can express an optimal policy as a form of state feedback:

```
$U^*(k) = \Phi^*_{-k}(\mathcal{X}(k)), \quad 0 \le k \le \mathcal{N}.\ \quad (7.56)$
```

The belief state $\mathcal{X}(k)$ coincides with the distribution of the state at time $k$, given observations up to time $k$. This requires a Bayesian setting for which the reward is some randomized function of the state. A hopefully simple starting point, let's turn to a linear-Gaussian model for which the belief state is finite dimensional.

In the *Gaussian bandit*, we create a state process evolving on $\mathbb{R}^K$ that is: $X(k) = X(0)$ for each $k$. While, the state can be modeled by the linear dynamics

```
$X(k+1) = X(k), \quad k \ge 0.\ \quad (7.57a)$
```

The vector $X \overset{\text{iid}}{==} X(0)$ is assumed random, with Gaussian distribution. The process $\mathcal{Z}$ is also assumed Gaussian:

```
$Z(k) = X(k) + W(k),$
```

in $W$ is an i.i.d. Gaussian stochastic process with zero mean, and independent of $X$. The reward received at time $k$ is interpreted as an observation equation:

```
$Y(k) = R(k) = H_kX(k) + H_kW(k), \quad (7.57b)
```

where $H_k$ is the $K$-dimensional row vector with $H_k(i) = \mathbb{1}\{U(k) = i\}$. The pair of equations (7.57) looks like a special case of (7.45) when the input $U(k)$ is hidden in the row $H_k$, and the observation noise has a slightly different form due to the multiplication by $H_k$ in (7.5b). The conclusion of Proposition 7.5 stands: The conditional distribution of $X(k)$ given all observations up to time $k$ is Gaussian, and the filtering equations simplify greatly.

For this model, we can replace the bias by conditional mean and variance that define the conditional distribution. That is, we can take $X(k) = \{\hat{X}(k), \Sigma_k\}$ in the state feedback architecture (7.56). The dependency on both the conditional mean and variance invites questions:

- Policy strategy: How much $\Phi^*$ depend upon the sufficient $\{\hat{X}(k), \Sigma_k\}$ at time $k$? The ternary equivalent policy, generalizing (7.51),

```
$U(k) = \max_u \hat{X}_u(k).\quad \quad (7.58)
```

This coincides with $\Phi_{N,k}^*(X(k))$ in a special case: $\Sigma_k = 0$, so that $\hat{X}_u(k) = X_u$ for each $u$. Conversely, this is a terrible approach when the conditional is far from zero, so there is significant uncertainty in the reward anticipated from one or more arms. We need to explore when there is high uncertainty.

- Exploration: How much is required? The following are anticipated for a good policy, in which the time horizon is bounded:
  (i) $\Sigma_k \to 0$ as $k \to \infty$ (uncertainty may lead to excessive suboptimal pulls)
  (ii) The rate of convergence of $\Sigma_k(i,i)$ to zero will be slow if $X_i$ is less than $X^*=\max_j X_j$.

```
$n_i(k) = \sum_{j=1}^k \mathbb{1}\{U(j) = i\}.\quad (7.59)
```

The regret grows logarithmically in $N$ if and only if $n_i(k)\{X_i < X^*\}$ grows logarithmically in $k$ for each $i$. We might then ask, is there a conflict between exploration and exploitation? If $n_i(k)$ is constrained to grow logarithmically in $k$ for "exploitation", can we be sure that $\Sigma_k(i,i)$ vanishes as $k \to \infty$ (exploration)? Since $F = I$ and $\Sigma_N = 0$, the update equation for $\Sigma_k$ is both simple and intuitive:

**Proposition 7.6** The covariance evolution for the Gaussian bandit is summarized as follows:
- (i) $\Sigma_{k+1} = \Sigma_k$ for each $k \ge 0$.
- (ii) The inverse of the covariance has the representation

```
$\Sigma_k^{-1} = \Sigma_0^{-1} + D_k,\quad (7.60)
```

in which $D_k$ is a diagonal matrix with entries

```
$D_k(i,i) = \frac{1}{\sigma_{W_i}^2}n_i(k),
```

where $\sigma_{W_i}^2$ is the variance of the Gaussian variable $W_i(k)$ (independent of $k$). Consequently, $\Sigma_k \to 0$ as $k \to \infty$ if and only if each arm is pulled infinitely. Proof Part (i) follows from the first equation in (7.60), and from the second we obtain the update equation

```
$\Sigma_k = \Sigma_{k-1} - \gamma^{-1}VV^T, \quad V = \Sigma_{k-1}H_k^T, \quad \gamma = H_k\Sigma_{k-1}H_k^T + \sigma_W^2,
```

The Matrix Inversion Lemma gives

```
$\Sigma_k^{-1} = \Sigma_{k-1}^{-1} + \Sigma_{k-1}^{-1}V[\gamma - V^T\Sigma_{k-1}^{-1}V]^{-T}\Sigma_{k-1}^{-1},
```

which simplifies dramatically when we insert the definition of $V$ and $\gamma$:

```
$\Sigma_k^{-1} = \Sigma_{k-1}^{-1} + \frac{1}{H_k\Sigma_{k-1}H_k^T}H_k^TH_k$.
```

The second term is a matrix with all entries zero, except a term on the diagonal. Specifically, for all $i,j$,

```
$\Sigma_k^{-1}(i,j) = \begin{cases} \Sigma_0^{-1}(i,j) & i \neq j \\ \Sigma_{k-1}^{-1}(i,i) + \frac{1}{\sigma_{W_i}^2}\mathbb{1}\{U(k)=i\} & i = j \end{cases}
```

which establishes (ii). The Proposition implies that to compute the conditional covariance, it is sufficient to keep track of the number of times we have pulled each arm.

```
$\lim_{k\to\infty} \Sigma_k^{-1}(i,i) = \Sigma_0^{-1}(i,i) + \frac{1}{\sigma_{W_i}^2}\sum_{k=1}^{\infty}\mathbb{1}\{U(k)=i\}$.
```

Hence a logarithmic boost over $n_i(k)$ does not prevent convergence of $\Sigma_k(i,i)$ to zero.

## 7.8 Naive Optimism Can Be Successful

Bandit theory is theoretically posed in a far more general than Gaussian bandits, and algorithm design is often based on a frequentist setting. That, algorithms are based on empirical priors, and there is no use for a prior distribution over the rewards.

A model is required for analysis. A typical choice is a parameterized model in which the vector-valued process $\mathbf{Z}$ is i.i.d.,

```
$Z_u(k) \sim f(\cdot;\theta_u)$,
```

in which $f(\cdot;\theta_u)$ is a density on $\mathbb{R}$ for $u \in \mathbb{U}$, with parameter $\theta \in \mathbb{R}^K$. Hence for $u$,

```
$\bar{r}_u = E[Z_u(k)] = \int f(r;\theta_u)dr.
```

Once again, we are not interested in estimating $\theta_u$ if $\bar{r}_u < \bar{r}^*$, but we don't know in advance which arms are suboptimal in this sense.

The frequentist will consider alternative representations of the regret (7.55). The following is most valuable in obtaining sharp bounds:

```
$E[L_{\mathcal{N}}] = \mathcal{N} \sum_{u} E[\{\bar{r}^* - \bar{r}_u\}],
```

in which $\tilde{\mu}_{\mathcal{N}}(u)$ is the empirical perf:

```
$\tilde{\mu}_{\mathcal{N}}(u) = \frac{1}{\mathcal{N}}\sum_{k=1}^{\mathcal{N}}\mathbb{1}\{U(k)=u\}, \quad (7.62)
```

The goal of optimal control is to steer the empirical perf so that $\bar{r}^*-\tilde{\mu}_{\mathcal{N}}(u) \approx 0$ for each $u$. To avoid avoiding techniques, we may represent the

```
$L_{\mathcal{N}} = \sum_{k=1}^{\mathcal{N}} \{\bar{r}^* - \bar{r}_u\}, \quad (7.63)
```

The regret grows logarithmically in $N$ if and only if $n_i(k)\{X_i < X^*\}$ grows logarithmically in $k$ for each $i$. is again doomed to failure. However, small tweaks result in a very good policy. One version of the UCB algorithm is the most optimistic rule:

```
$U(k+1) \in \arg\max_i UCB_i(k), \quad 0 \le k \le N-1, \quad (7.65)
```

using $\varrho_u(k) = b_u\sqrt{\log(k)}/[1+n_u(k)], \quad 1 \le u \le K$,

$\{b_u\}$ are positive constants chosen by the user. Regardless of their values, the decision (7.65) ensures $n_u(k) \to \infty$ as $\infty$ for each $u$, and results in logarithmic regret under mild assumptions [216].
