There is no need to identify which policy is under consideration in the constructions that follow so we write $\Gamma$ instead of $\Gamma(\Phi)$, and let $T$ denote the transition matrix for the Markov chain $\Phi$.

# Discounted Cost

Take $h$ equal to the discounted-cost value function obtained by a policy $\Phi$, and denote

```
$$\Gamma = \sum_{z}^{\infty} h(z)u(z) = E\left[sum_{k=0}^{\infty} \gamma^k c(\Phi(k))\right], \Phi(0)\sim \gamma.$
```

The construction is defined through regeneration: $\Psi(k) = (\Phi(k), B(k))$, in which $B(k) \in \{0,1\}$ for each $k$, with $B(k)=1$ indicating that a regeneration occurred at time $k$, and $\Phi(k)$ evolves along the transition matrix $T$ between regeneration times.

We begin with the construction of the first regeneration time along with an alternative representation of (10.25). Let $B$ be a Bernoulli process with parameter $1-\gamma$, independent of $\Phi$:

```
$P\{B(k)=0 \Phi_0^0\} = \gamma,$
```

where the aforementioned conditioning is on the entire trajectory of the Markov chain $\Phi$. On denoting $T_* = \min\{k \ge 1 : B(k)=1\}$, we have $P\{T_* > k | \Phi_0^0\} = \gamma^k$ for $k \ge 0$, and by independence

```
$E[T_* > k]c(\Phi(k)) = E[T_* > k]c(\Phi(k)) = \gamma^k E c(\Phi(k))..$
```

Summing each side removes the decomposition from (10.25), which converges to a stochastic path process:

```
$h(z) = E\left[sum_{k=0}^{T_*-1} c(\Phi(k)) | \Phi(0)=z\right].$
```

To define $\Psi$, we let $N_1 = T_*$, define the first regeneration time, and $\widehat{\Phi}(k) = \Phi(k)$ for $0 \le k \le T_*-1$. The random variable $\widehat{\Phi}(T_*)$ is independently sampled from the process, with distribution $\mu$. This construction, with $\{N_n\}$, a renewal process, defined inductively by

```
$N_{n+1} = \min\{k \ge N_n+1 : B(k)=1\}, \quad n \ge 1$
```

with $\Phi(k)$ defined as before on the interval $[N_n \le k < N_{n+1}]$ for each $n$.

The following is a variant of Kac's theorem for this Markov chain (see Proposition 6.10):

**Proposition 10.12** for the Markov chain $\Psi$ with cost function $c(\Psi(k)) = c(\widetilde{X}(k))$, $k \ge 0$, the partial sums $\{S_n\}$ in (10.24) are i.i.d. with common mean $\Gamma$ in (10.25).

Consequently, the average cost is given

```
$$\lim_{N\to\infty} \frac{1}{N} \sum_{k=0}^{N-1} c(\Phi(k)) = \lim_{M\to\infty} \frac{1}{M} \sum_{m=1}^{M-1} S_m = (1-\gamma)\Gamma.$
```
