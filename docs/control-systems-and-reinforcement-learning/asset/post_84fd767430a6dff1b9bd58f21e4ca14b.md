## 4.9.2 ODE Solidarity

The proof of Theorem 4.15 requires a precise ODE approximation, which is explained in this subsection. For this, we recall the “averaged” vector field introduced in (4.45):

```
$$\tilde{f}(\theta) = \lim_{T\to\infty} \int_{0}^{T} f(\theta,\xi_t)dt, \quad \text{for all } \theta \in \mathbb{R}^d. \quad (4.127)$$
```

The first step in the theory is to find assumptions to ensure that the limit exists. Following this, the solutions to the ODE (4.42) and the QSA ODE (4.44) are compared and shown to converge to the same limit without bounded solutions.

Recall that the starting point in an ODE approximation is the temporal transformation (4.73). The time-scaled process is then defined

```
$$\Theta_t \overset{ad}{=} \Theta(s^{-1}(\tau)) = \Theta_t|_{t=s^{-1}(\tau)}. \quad (4.128)$$
```

The chain rule of differentiation (and using $d\tau = a_t dt$) gives

```
$$\frac{d}{d\tau}\Theta(s^{-1}(\tau)) = f(\Theta(s^{-1}(\tau)),\xi(s^{-1}(\tau))).$$
```

That is, the time-scaled process solves the ODE:

```
$$\frac{d}{d\tau}\tau = f(\Theta(s^{-1}(\tau)),\xi(s^{-1}(\tau))). \quad (4.129)$$
```

The two processes $\Theta$ and $\theta$ differ only in time scale, and hence, proving convergence of one proves that of the other. In this subsection, we deal exclusively with $\Theta$; it is on the “right” time scale for comparison with $\theta$, the solution of (4.42).
Define $\Theta_w^\tau, w \ge \tau$, is the unique solution of (4.42) “starting” at $\Theta_\tau$:

```
$$\frac{d}{dw}\Theta_w^\tau = f(\Theta_w^\tau), w \ge \tau, \Theta_\tau^\tau = \hat{\Theta}_\tau. \quad (4.130)$$
```

We have the following suggestions:

```
$$\hat{\Theta}_{\tau+\nu} = \Theta_{\tau+\nu} + \int_{\tau}^{\tau+\nu} f(\theta_w,\xi(s^{-1}(w))) dw, \quad (4.131)$$
$$\Theta_{\tau+\nu} = \Theta_{\tau} + \int_{\tau}^{\tau+\nu} f(\theta_w^\tau) dw, \quad \tau, \nu \ge 0.$$
```

**Proposition 4.28** Assume that $\theta$ is bounded. Then, for any $T>0$,

```
$$\lim_{\tau\to\infty} \sup_{\nu\in[0,T]} \|\int_{\tau}^{\tau+\nu} [f(\theta_w,\xi(s^{-1}(w))) - f(\theta_w^\tau)] dw\| = 0, \quad (4.132a)$$
```

```
$$\lim_{\tau\to\infty} \sup_{\nu\in[0,T]} \|\Theta_{\tau+\nu} - \Theta_{\tau}^\tau\| = 0. \quad (4.132b)$$
```

The (4.134) in Lemma 4.30 is a strong version of Law of Large Numbers (LLN) for the time-scaled process $\{\xi(s^{-1}(\tau))}_{\tau\to\infty}$. Note the difference with a classical LLN. Here, the interval of integration is arbitrary $T$, and averaging becomes more accurate as the interval is shifted toward infinity.

**Lemma 4.30** For any $T > 0$ and $\theta \in \mathbb{R}^d$,

```
$$\int_{\tau}^{\tau+\nu} [f(\theta,\xi(s^{-1}(w))) - f(\theta_w^\tau)] dw \le b_0(\theta)\varepsilon, \quad \varepsilon = 3a_t|_{t=s^{-1}(\tau)}. \quad (4.134)$$
```

where $b_0(\theta)$ is given in 4.82.

**Proof** With $\tilde{f}_w(\theta) = f(\theta, \varepsilon_w)$ for $f$ and $\theta$, denote $\varepsilon_t^1 = \int_0^t \tilde{f}_w(\theta)dw$. By assumed bound (4.82),

```
$$\varepsilon_t^t \le b_0(\theta), \quad t \ge 0. \quad (4.135)$$
```

The following integral is simplified using integration parts:

```
$$\int_{t_0}^{t_1} a_t \tilde{f}_w(\theta)dt = a_t \varepsilon_t|_{t_0}^{t_1} - \int_{t_0}^{t_1} a_t' \varepsilon_t.$$
```

Taking the norm of each side, by triangle inequality

```
$$\int_{t_0}^{t_1} a_t \tilde{f}_w(\theta)dt \le a_{t_0}\|\varepsilon_{t_0}\| + a_{t_1}\|\varepsilon_{t_1}\| + \int_{t_0}^{t_1} |a_t'| \|\varepsilon_t\| dt.$$
```

Proof of (4.132a) Denote

```
$$\mathcal{E}_{\tau}^v = \int_{\tau}^{\tau+v} |f(\Theta_w, \xi(s^{-1}(w))) - \tilde{f}(\Theta_w)| dw.$$
```

To establish (4.132a), we show that this converges to zero as $\tau \to \infty$, uniformly for $v$ bounded intervals. Fix $\delta > 0$ and denote $\tau_k = \tau + k\delta$ for $k \geq 0$. In the theory of Riemann integration, the Lipschitz constants (QSA2) imply the following:

```
$$\mathcal{E}_{\tau}^v = \sum_{k=0}^{n_v-1} \int_{\tau_k}^{\tau_k+\delta} [f(\Theta_k, \xi(s^{-1}(w))) - \tilde{f}(\Theta_k)] dw + \varepsilon_{\tau}^v,$$
```

where $n_v$ denotes the integer part of $v/\delta$, and $|\mathcal{E}_{\tau}^v| \leq b_L v\delta$ for some constant $b_L < \infty$. The bound is uniform under $\tau$ under the assumption that $\Theta$ is bounded. Lemma 4.30 and the triangle inequality imply

```
\|\mathcal{E}_{\tau}^v + v\| \leq \sum_{k=0}^{n_v-1} \varepsilon_{\tau_k} b_0(\Theta_k) + b_L v\delta \leq \sum_{k=0}^{n_v-1} b_0(\Theta_k) + b_L v\delta.$$
```

Let $b_* < \infty$ denote a constant satisfying $b_0(\Theta_{\tau}) \leq b_*$, for all $\tau$. Then,

```
\|\mathcal{E}_{\tau}^v + v\| \leq b_* \varepsilon_{\tau}^v + b_L v\delta.$$
```

This completes the proof of (4.132a), since $\delta > 0$ was arbitrary.
