# Perron–Frobenius Theory

Section 3.2.3 contains a brief introduction to Perron–Frobenius theory. Application to finite state space Markov chains are served in the exercises that follow. These concepts provide useful computational tools and insight.
In of the problems that follow, we consider a Markov chain $X$ on a countable state space $X$, with transition matrix $P$.

6.19 An Introduction. Suppose that $P$ is “rank one”. This means that there exists a function $s$ and a pmf $v$ over $X$ satisfying $P=s \otimes v$ (that is, $P(x,y)=s(x)v(y)$ for $x,y \in X$). Show that $s=1$ is an invariant pmf, and $X$ is i.i.d. with marginal distribution $v$.
