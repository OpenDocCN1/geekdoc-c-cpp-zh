```objective-c
#include <stdio.h>

int main (int argc, const char * argv[])

        fprintf(stderr, "Usage: Affirmation <name> <number>\n");
        return 1;
    }

    int count = atoi(argv[2]);
    for (int j = 0; j < count; j++) {
        printf("%s is cool.\n", argv[1]);
    }

    return 0;
}
```

# 37 Switch 语句

检查变量是否属于一组值的情况并不罕见。如果使用 *if*-*else* 语句，代码将如下所示：

```
int yeastType = . . . ;

if (yeastType == 1) {
	makeBread();
} else if (yeastType == 2) {
	makeBeer();
} else if (yeastType == 3) {
	makeWine();
} else {
	makeFuel();
}
```

为了让这类事情更容易，C 语言有 *switch* 语句。上面的代码可以改为：

```
int yeastType = . . . ;

switch (yeastType) {
	case 1:
		makeBread();
		break;
	case 2:
		makeBeer();
		break;
	case 3:
		makeWine();
		break;
	default:
		makeFuel();
		break;
}
```

注意 *break* 语句。如果没有 *break*，在执行完相应的 case 子句后，系统将执行所有后续的 case 子句。例如，如果我写了这段代码：

```
int yeastType = 2;

switch (yeastType) {
	case 1:
	case 2:
		makeBeer();
	case 3:
		makeWine();
	default:
		makeFuel();
}
```

程序将运行 `makeBeer()`、`makeWine()` 和 `makeFuel()`。这主要是为了让你可以有多个可能的值触发相同的代码：

```
int yeastType = ...;

switch (yeastType) {
    case 1:
    case 4:
        makeBread();
        break;
    case 2:
    case 5:
        makeBeer();
        break;
    case 3:
        makeWine();
        break;
    default:
        makeFuel();
        break;
}
```

正如你可以想象的那样，忘记在 case 子句末尾添加 break 是程序员常见的错误，而且只有在你的程序开始表现异常时才会被发现。

在 C 语言中，switch 语句用于非常具体的情况：case 只能是常量整数。因此，你在大多的 Objective-C 程序中看不到很多 switch 语句。这就是为什么我把它悄悄放在这本书结束之前。
