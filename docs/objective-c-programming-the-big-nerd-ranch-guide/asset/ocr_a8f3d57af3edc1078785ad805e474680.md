# NSSString

**NSSString** is another class like **NSDate**. Instances of **NSSString** hold character strings. In code, you can create a literal instance of **NSSString** like this;

```
```python
NSSString *lament = @"Why me!?";
```
```

In your TimeAfterTime project, you typed in this code:

```
```python
NSLog(@"The date is %@", now);
```
```

**NSLog**() is an Objective-C function (not a method!) that works a lot like **printf**(). In **NSLog**(), however, the format string is actually an instance of **NSSString**.

Instances of **NSSString** can also be created programmatically using the stringWithFormat: class method:

```
```python
NSSString *x = [NSSString stringWithFormat:@"The best number is %d", 5];
```
```

To get the number of characters in a string, you use the length method:

```
```python
NSUInteger charCount = [x length];
```
```

And you check to see if two strings are equal using the isEqual: method:

```
```python
if ([lament isEqual:x])
    NSLog(@"%@ and %@ are equal", lament, x);
```
```

The C language also has a character string construct. Here’s what the preceding string examples would look like in C:

```
```c
char *lament = "Why me!?";
char *x;
asprintf(&x, "The best number is %d", 5);
size_t charCount = strlen(x);
if (strcmp(lament, x) == 0)
    printf("%s and %s are equal\n", lament, x);
free(x);
```
```

We will discuss C strings in Chapter 34. But whenever you have a choice, use **NSSString** objects instead of C strings. The **NSSString** class has many methods designed to make your life easier. Plus, **NSSString** (which is based on the UNICODE standard) is exceedingly good at holding text from any language on the planet. Strange characters? No problem. Text that reads from right to left? No worries.
