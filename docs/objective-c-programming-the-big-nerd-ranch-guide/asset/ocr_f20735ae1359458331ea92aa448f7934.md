# ## Wiring up the table view

You’ve got a table view on the screen, but it has no clue about what it should display. As a view object, the table view does not contain anything about actual data. It needs an object to act as its data source. In iTahDoodle, your table view’s data source will be the instance of **BNRAAppDelegate**.

In BNRAAppDelegate.m, update **application:didFinishLaunchingWithOptions:** to send a message to the table view that makes the **BNRAAppDelegate** instance its data source:
