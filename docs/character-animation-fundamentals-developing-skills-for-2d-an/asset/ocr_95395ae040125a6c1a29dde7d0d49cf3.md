# ‘EH’

As in ‘wet’. A large, wide smiling mouth with the jaw dropped, but not quite as dropped as for ‘O’ and ‘A’.

# ‘EEE’

As in ‘squeeze’. Still quite loud but the jaw will not be as open as for the other loud vowels. It consists of a wide smile.
