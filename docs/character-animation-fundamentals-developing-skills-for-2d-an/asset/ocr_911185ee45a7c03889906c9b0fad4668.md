You have now created your first key in 3D Studio Max! Alternatively, you could select the Auto Key button. Then, whenever you move the ball, a key is automatically set.

Move the Time Slider to frame 14 and then drag the ball down so that it is sitting on the thick horizontal line running through the grid. Set your second key (or, if Auto Key is selected, a key will be set automatically).
