A flag cycle consists of a piece of cloth that has a wave running through it. Each crest of the wave on one drawing becomes the crest of the wave on the next drawing. The first key drawing (number 5) is the mirror image of the first key position (number 1) and the fourth key drawing (number 13) is the mirror image of the second key drawing. These key drawings need in-betweening. You should shoot these drawings as follows: 1, 3, 5, 7, 9, 11, 13, 15, 1, 3, 5, 7, 9, 11, 13, 15, etc.

Imagine a piece of cloth being pulled through the air. The cloth will drag behind the point where it is being held by the hand, falling outwards at the end. If the hand slows down or stops, the cloth will catch up with the hand and start to move ahead.

A piece of string or rope will act in a similar way but, because it has greater flexibility than a piece of cloth, it will fall out of the path set by the character to a larger degree.
