If you make a mistake and set a key that you don't want, just right click on the key position in the Time Slider and select **Delete**. Select the bones you haven't moved and set keys on them (the back bones, neck bones and so on). Move the Time Slider to frame 19 so you can do the third key position (take a look at the illustration above).
