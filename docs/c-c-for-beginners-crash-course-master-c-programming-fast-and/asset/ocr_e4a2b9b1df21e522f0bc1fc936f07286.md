The ref keyword is used for declaring the reference parameter.

# Example:

```
```csharp
class Program
{
    void IncreaseNo(int no)
    {
        no++;
    }
    public static void Main()
    {
        Program p = new Program();
        int number = 2;
        p.IncreaseNo(ref number);
        Console.WriteLine(number);
    }
}
```

3
