# 5.2 Arithmetic operators

Arithmetic operators are used for performing the **arithmetic operations** on variables. The table shows the arithmetic operators in C#.

| Operator | Description | Example |
|---|---|---|
| + | Add two operands | c=a+b<br>If a=10, b=20, c=10+20=30 |
| - | Subtracts second operand from the first | c=a-b<br>If a=10, b=5, c=10-5=5 |
| * | Multiplies both the operands | c=a*b<br>If a=10, b=5, c=10*5=50 |
| / | Divides the numerator by denominator | c=a/b<br>If a=21, b=2, c=21/2=10 |
| % | Modulus operator and remainder after integer division | c=a%b<br>If a=21, b=2, c=21%2=1 |
| ++ | Increment operator. User for increasing value by one | If a=10,<br>a++=11 |
| -- | Decrement. The value can be decreased by one | If a=10<br>a--=9 |
