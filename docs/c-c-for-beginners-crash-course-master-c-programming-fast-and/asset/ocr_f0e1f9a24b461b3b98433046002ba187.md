+   - Save: All the programs created in a particular solution are saved. The [Save] button is used.
+   - Save All: It saves all the unsaved items in an application. The [Save All] button is used.
+   - Cut: The selected objects are placed on the clipboard using this option. The [Cut] icon is used.
+   - Copy: The copy of the selected item is kept on the clipboard. The [Copy] icon is used.
+   - Paste: It is used to paste the contents in the document. The [Paste] icon is used.
+   - Debugging: The compilation and execution of the project is done. The [Debugging] icon is used.
