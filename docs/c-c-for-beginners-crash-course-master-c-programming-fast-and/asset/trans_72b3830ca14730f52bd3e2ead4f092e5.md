
## 第11章 封装与多态

### 11.1 封装简介

**封装** 是将数据和函数封装在物理或逻辑包中的过程。它帮助开发者防止访问应用程序的必要细节。它将代码和数据绑定在一起。

**抽象** 表明所有信息都存在，但只向用户提供 **相关信息**。

抽象和封装是相关的特性。封装通过提供隐藏非必要细节的手段来辅助抽象。使用封装，部分信息可见，其他信息被隐藏。

### 11.2 C# 中的访问修饰符

访问修饰符定义了类成员的作用域。成员用于引用类的函数和变量。程序由一个或多个类组成。某些类成员需要被其他类访问。

#### 访问修饰符的类型

C# 支持以下访问修饰符。

- 公共
- 私有
- 受保护
- 内部
- 受保护内部

#### 公共访问修饰符

**公共** 访问修饰符允许类向其他类公开成员变量和函数。声明为公共的成员可以从类外部访问。

#### 公共访问修饰符示例

```csharp
using System;
namespace public1
{
    class User
    {
        //member variables
        public string name;
        public int age;
        public void AddValue()
        {
            Console.WriteLine("Enter the user name:");
            name = Console.ReadLine();
            Console.WriteLine("Enter the age:");
            age = Convert.ToInt32(Console.ReadLine());
        }
        public void Show()
        {
            Console.WriteLine("User name is:{0}", name);
            Console.WriteLine("Age is:{0}", age);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            User u = new User();
            u.AddValue();
            u.Show();
            Console.Read();
        }
    }
}
```

编译并执行代码后，输出为：

Enter the user name:
Mark
Enter the age:
20
User name is: Mark
Age is: 20

#### 私有访问修饰符

私有访问修饰符允许用户将类的成员变量和函数隐藏在其他类对象和函数之外。私有成员在类外部不可见。只有类本身内部的类函数可以访问私有实体。类的对象或实例无法访问任何私有变量或函数，因为它们被声明为类外部的。

#### 示例 39

```csharp
using System;
namespace private1
{
    class Student
    {
        //member variables
        private string name;
        private int age;
        public void AddValue()
        {
            Console.WriteLine("Enter the student name:");
            name = Console.ReadLine();
            Console.WriteLine("Enter the age:");
            age = Convert.ToInt32(Console.ReadLine());
        }
        public void Show()
        {
            Console.WriteLine("Student name is:{0}", name);
            Console.WriteLine("Age is:{0}", age);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            Student s = new Student();
            s.AddValue();
            s.Show();
            Console.Read();
        }
    }
}
```

编译并执行代码后，输出为：

Enter the student name:
Harry
Enter the age:
15

Student name is: Harry
Age is: 15

#### 受保护访问修饰符

受保护访问修饰符允许类将成员变量和函数隐藏在其他类对象和函数之外，除了子类。修饰符在继承实现期间很有用。

#### 示例 40

```csharp
using System;
namespace protected1
{
    class Employee
    {
        //member variables
        protected string name;
        public void AddValue()
        {
            Console.WriteLine("Enter the employee name:");
            name = Console.ReadLine();
        }
        public void Show()
        {
            Console.WriteLine("Employee name is:{0}", name);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            Employee e = new Employee();
            e.AddValue();
            e.Show();
            Console.Read();
        }
    }
}
```

编译并执行代码后，输出为：

Enter the employee name:
Ajay
Employee name is: Ajay

#### 内部访问修饰符

内部访问修饰符允许类将其成员函数和变量暴露给包含的子类或同一应用程序内的类。

#### 示例 41

```csharp
using System;
namespace internal1
{
    class Location
    {
        //member variables
        internal string city;
        public void AddValue()
        {
            Console.WriteLine("Enter the city name:");
            city = Console.ReadLine();
        }
        public void Show()
        {
            Console.WriteLine("City name is:{0}", city);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            Location l = new Location();
            l.AddValue();
            l.Show();
            Console.Read();
        }
    }
}
```

编译并执行代码后，输出为：

Enter the city name:
London
City name is: London

#### 受保护内部访问修饰符

**受保护内部** 访问修饰符允许类将成员函数和变量暴露给包含的类、子类或同一应用程序中的类。允许对应用程序外部的派生类进行访问。

#### 示例 42

```csharp
using System;
namespace protectedinternal1
{
    class number
    {
        //member variables
        protected internal int no;
        public void AddValue()
        {
            Console.WriteLine("Enter the number:");
            no = Convert.ToInt32(Console.ReadLine());
        }
        public void Show()
        {
            Console.WriteLine("Number is:{0}", no);
        }
    }
    class Program
    {
        static void Main(string[] args)
        {
            number n = new number();
            n.AddValue();
            n.Show();
            Console.Read();
        }
    }
}
```

编译并执行代码后，输出为：

Enter the number:
10
Number is: 10

### 11.3 多态

**多态** 是函数以不同形式存在的能力。单词‘poly’意为多和‘morphos’意为形式。

有两种类型多态：

- **静态：** 对函数的响应在编译时决定
- **动态：** 对函数的响应在运行时决定

### 11.4 静态多态

静态多态是指以不同形式存在的实体。C# 有两种实现多态的方法。

- 函数重载
- 运算符重载

#### 函数重载

函数重载帮助用户对两个或多个函数使用相似的名称。
函数定义必须通过参数列表的类型或数量彼此不同。

#### 示例 43

```csharp
using System;
namespace calculate
{
    class calculate
    {
        public int Min(int no1, int no2)
        {
            if (no1 < no2)
            {
                return no1;
            }
            else
            {
                return no2;
            }
        }
        public float Min(float no1, float no2)
        {
            if (no1 < no2)
            {
                return no1;
            }
            else
            {
                return no2;
            }
        }
    }
}
class Program
{
    static void Main(string[] args)
    {
        Program p = new Program();
        Console.WriteLine("Minimum value is:{0}", p.Min(3, 4));
        Console.WriteLine("Minimum value is:{0}", p.Min(3.2F, 1.2F));
        Console.ReadLine();
    }
}
```

编译并执行代码后，输出为：

Minimum value is: 3
Minimum value is: 1.2
