
where ∧_T, *_T' denote t-norms T, T' for aggregation operation and composition respectively.

In individual rule based inference (FITA) each rule in the fuzzy rule base determines an output fuzzy set and after that an aggregation via intersection or average operation is performed. So the output fuzzy set is expressed by means of the formulas:

B'' = ⋂_{k=1}^{K}_{T,Σ} { A' ∘ (A^{(k)} ⇒ B^{(k)}) }  (11.18)

or:

B''(y) = [ ⋀_{k=1}^{K}_T  ∑_{k=1}^{K} ] sup_{x∈X} [ A'(x) *_T' R^{(k)}(x,y) ].  (11.19)

It can be proved that B' is more specified than B'', i.e.,:

B' ⊆ B'' or ∀_{y∈Y} B'(y) ≤ B''(y).  (11.20)

It means that the consequent B' is equal to or contained in the intersection of fuzzy inference results - B''. For simplicity of calculation the consequent B' is replaced by B'', under the assumption that the differences are not so big.

If the input fuzzy sets A'_1, ..., A'_n or (A') are singletons in x_{10}, ..., x_{n0} or (x_0), the consequence B' is equal to B'' (B'(y) = B''(y)). In that case we obtain:

B'(y) = B''(y) = [ ⋁_{k=1}^{K}_S  ∑_{k=1}^{K} ] [ A^{(k)}(x_0) *_T' B^{(k)}(y) ]  (11.21)

or with logical interpretation of fuzzy implication:

B'(y) = B''(y) = [ ⋀_{k=1}^{K}_T  ∑_{k=1}^{K} ] I( A^{(k)}(x_0), B^{(k)}(y) ).  (11.22)

## 11.4 Fundamentals of fuzzy systems

In approximate reasoning realized in fuzzy systems the if-then fuzzy rules play an essential role. Often they are also used to capture the human ability to make a decision or control in an uncertain and imprecise environment. In this section we will use such fuzzy rules to recall the important approximate reasoning methods which are basic in our further considerations. Assume that m numbers of n-input and one-output (MISO) fuzzy if-then rules are given. The k-th rule in which the consequent is represented by a linguistic variable Y may be written in the following forms:

R^{(k)} : if X₁ is A₁^{(k)} and ... and Xₙ is Aₙ^{(k)} then Y is B^{(k)}    (11.23)

or in a pseudo-vector notation

R^{(k)} : if X̲ is A̲^{(k)} then Y = B^{(k)},    (11.24)

where:

X̲ = [X₁ X₂ ... Xₙ].    (11.25)

X₁, X₂, ..., Xₙ and Y are linguistic variables which may be interpreted as inputs of a fuzzy system and the output of that system. A₁^{(k)}, ..., Aₙ^{(k)} are linguistic values of the linguistic variables X₁, X₂, ..., Xₙ and B^{(k)} is a linguistic value of the linguistic variable Y.

A collection of the above written rules for k = 1, 2, ... K creates a rule base which may be activated (fired) under the singleton inputs:

X₁ is x₁₀ and ... and Xₙ is xₙ₀    (11.26)

or

X̲ is x̲₀.    (11.27)

It can easily be concluded from (11.22) that such a type of reasoning, where the inferred value of k-th rule output for crisp inputs (singletons), may be written for logical implication interpretation in the form:

B^{I(k)}(y) = Rₖ(x̲₀) ⟹ B^{(k)}(y) = I(Rₖ(x̲₀), B^{(k)}(y))    (11.28)

and for conjunctive implication interpretation:

B^{I(k)}(y) = Rₖ(x̲₀) *ₜ B^{(k)}(y) = *ₜ(Rₖ(x̲₀), B^{(k)}(y)),    (11.29)

where ⟹ stands for fuzzy implication, *ₜ for t-norm T and

Rₖ(x̲₀) = A₁^{(k)}(x₁₀) and ... and Aₙ^{(k)}(xₙ₀) = A̲^{(k)}(x̲₀)    (11.30)

denotes the degree of activation (the firing strength) of the k-th rule with respect to minimum (∧) or product (·). The last represents explicit connective (AND) of the predicates X_i is A_i^(k), k = 1,2,...,K in the antecedent of an if-then rule.

A crisp value of the output we can get from the Modified Center of Gravity (MCOG) as defuzzification [5]:

MCOG[B(x)] = ∫ x [B(x) − α] dx / ∫ [B(x) − α] dx , (11.31)

where α is constant.

The subtraction of value α ∈ [0,1] eliminates the non-informative part of the membership function B(x). For α = 0 we get well known COG defuzzification. A final crisp value of the system output for sum as aggregation and MCOG defuzzification can be evaluated from formula:

y0 = ∫ y Σ_{k=1}^K { Ψ [R_k(x0), B^(k)(y)] − α_k } dy / ∫ Σ_{k=1}^K { Ψ [R_k(x0), B^(k)(y)] − α_k } dy = ∫ y Σ_{k=1}^K [B'^(k)(y) − α_k] dy / ∫ Σ_{k=1}^K [B'^(k)(y) − α_k] dy , (11.32)

where Ψ stands for fuzzy implication I or t-norm T for logical or conjunctive implication interpretation, respectively.

A method of determination, the values α will be described later. Now we introduce symbol B*^(k) := B'^(k) − α_k. Membership functions of fuzzy sets B*^(k) can be represented by the parameterized functions:

B*^(k) ~ f^(k) [ Area ( B*^(k) ), y^(k) ] , (11.33)

where y^(k) is the center of gravity (COG) location of the fuzzy set B*^(k):

y^(k) = COG ( B*^(k) ) = ∫ y B*^(k)(y) dy / ∫ B*^(k)(y) dy . (11.34)

A general form for final output value can be put in the form:

y0 = Σ_{k=1}^K y^(k) Area ( B*^(k) ) / Σ_{k=1}^K Area ( B*^(k) ) , (11.35)

where B*^(k) is a resulting conclusion for the k-th rule before aggregation.

Now we note that fuzzy systems with Larsen’s product operation as conjunctive "fuzzy implication" of the if-then rules and symmetric triangle (isosceles triangle) membership functions for consequents B*^(k) we can write in well known from literature formula [15]:

y0 = (∑_{k=1}^{K} (w^(k)/2) R_k (x_0) y^(k)) / (∑_{k=1}^{K} (w^(k)/2) R_k (x_0)) , (11.36)

where w^(k) is the width of the triangle base for k-th rule.

It should be noted that the w^(k)/2 factor may be interpreted as a respective weight of k-th rule or its certainty factor.

Another very important fuzzy system is called Takagi-Sugeno-Kang. Assume that m numbers of n-input and one-output (MISO) fuzzy implicative rules or fuzzy conditional statements are given. The k-th rule may be written in the following forms:

R^(k) : if X1 is A1^(k) and ... and Xn is A_n^(k) then Y = f^(k) (X1, ..., Xn) (11.37)

or in a pseudo-vector notation

R^(k) : if X is A^(k) then Y = f^(k) (X) . (11.38)

A crisp value of the output for Larsen’s fuzzy relation (product) and aggregation (normalized sum) can be evaluated from [3]:

y0 = (∑_{k=1}^{K} A_k (x_0) f^(k) (x_0)) / (∑_{k=1}^{K} A_k (x_0)) . (11.39)

Take into account that function f^(k) is of the form:

f^(k) (x_0) = p0^(k) (11.40)

where p0^(k) is crisply defined constant in the consequent of the k-th rule.

Such a model is called a zero-order Sugeno fuzzy model. The more general first-order Sugeno fuzzy model is of the form:

f^(k) (x_0) = p0^(k) + p1^(k) x10 + ... + p_n^(k) x_n0, (11.41)

where p0^(k), p1^(k), ..., p_n^(k) are all constants.

In vector notation it takes the form:

f^{(k)}(\underline{x}_0) = \underline{p}^{(k)T} \underline{x}'_0, \quad (11.42)

where .^T stands for transposition and \underline{x}'_0 denotes an extended input vector:

\underline{x}'_0 = \begin{bmatrix} 1 \\ \underline{x}_0 \end{bmatrix}. \quad (11.43)

Notice that in both models the consequent is crisp.

In equation (11.35) the value describing the location of COG's consequent fuzzy set in if-then rules is constant and equals y^{(k)} for k-th rule. A natural extension of the above-described situation is an assumption that the location of the consequent fuzzy set is a linear combination of all inputs for k-th rule:

y^{(k)}(\underline{x}_0) = \underline{p}^{(k)T} \underline{x}'_0. \quad (11.44)

Hence we get the final output value in the form:

y_0 = \frac{\sum_{k=1}^{K} \text{Area}\left(B^{*(k)}\right) \underline{p}^{(k)T} \underline{x}'_0}{\sum_{k=1}^{K} \text{Area}\left(B^{*(k)}\right)}, \quad (11.45)

where B^{*(k)} is the conclusion for the k-th rule before aggregation.

## 11.5 Fuzzy system with logical interpretation of if-then rules

We assume that premises of if-then rules A_1^{(k)},...,A_n^{(k)} have Gaussian membership functions:

A_j^{(k)}(x_{j0}) = \exp\left[ -\frac{\left(x_{j0} - c_j^{(k)}\right)^2}{2\left(s_j^{(k)}\right)^2} \right], \quad (11.46)

where c_j^{(k)}, s_j^{(k)}, j = 1,2,...,n; k = 1,2,...,K are the parameters.

On the basis of (11.30) and for explicit connective AND taken as product we get:

\underline{A}^{(k)}(\underline{x}_0) = \prod_{j=1}^{n} A_j^{(k)}(x_{j0}). \quad (11.47)
