# **Error formula**  The error E is calculated as:

E = √( 1/(O P_eq) Σ_{o=1}^{O} Σ_{p=1}^{P} k_{op}^2 (y_{op} - y'_{op})^2 )   (1.6)

where

+   - O is the number of outputs;
+   - P is the number of learning patterns;
+   - y_{op} and y'_{op} are respectively the calculated and desired o th outputs of the p th learning pattern;
+   - k_{op} are user definable coefficients;
+   - P_{eq} is generally equal to P, but it can assume other values.

# **Possible errors**  Using equation (1.6) it is possible to use different approaches to learning.

**Root mean squared error:** If k_{op} = 1 ∀p, o and P_{eq} = P we obtain the so-called root mean squared error (RMSE) [26].

**Root mean squared normalized error:** If Δ_o indicates the difference between the maximum and minimum values that the o th output can assume, if we put k_{op} = 1/Δ_o ∀p, o and P_{eq} = P, we obtain the root mean squared normalized error (RMSNE). It indicates how much each output differs on average from the desired value with regard to its range. This kind of error was adopted in the previously proposed fuzzy modeling method (see FuGeNeSys).

**Root mean squared relative error:** If k_{op} = 1/y'_{op} ∀p, o and P_{eq} = P we obtain the root mean squared relative error (RMSRE). It indicates the average relative error. This error measure was used in the field of High Energy Physics (HEP) [27].

With the aid of these techniques a reduced set of significant samples (codewords) for the learning phase can be extracted.
