Stage 1 :
IF x0 is A1,0^1 ∧ ⋯ ∧ xL1 is A1,L1^1
THEN y1 is B1^1
⋯
IF x0 is An,0^1 ∧ ⋯ ∧ xL1 is An,L1^1
THEN y1 is Bn^1
⇒ (output to 2nd stage)

Stage 2 :
IF y1 is A1,1^2 ∧ ⋯ ∧ xL2 is A1,L2^2
THEN y2 is B1^2
⋯
IF y1 is An,1^2 ∧ ⋯ ∧ xL2 is An,L2^2
THEN y2 is Bn^2
⇒ (output to 3rd stage)

Stage m :
IF ym−1 is A1,m−1^m ∧ ⋯ ∧ xLm is A1,Lm^m
THEN ym is B1^m
⋯
IF ym−1 is An,m−1^m ∧ ⋯ ∧ xLm is An,Lm^m
THEN ym is Bn^m
⇒ (to control input)

where ∧ is ‘and’ operator, Aj,k^i and Bj^i are linguistic terms characterized by fuzzy membership functions μAj,k^i(x) and μBj^i(yi), respectively, (i=1,2,…,m; j=1,2,…,n; k=0,1,…,Li); xk and yi (i=1,…,m−1) in the IF-parts are input and intermediate variables, respectively, and ym in the THEN-parts is the output variable.

# 5.2.1 Multistage fuzzy inference engine

The multistage fuzzy inference engine is decision-making logic, which employs fuzzy rules from the fuzzy rule bases, to determine a mapping from the fuzzy sets in the input universe of discourse Ux to the fuzzy set in the output universe
