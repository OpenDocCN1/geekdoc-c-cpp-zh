denotes the degree of activation (the firing strength) of the k-th rule with respect to minimum (∧) or product (·). The last represents explicit connective (AND) of the predicates X_i is A_i^(k), k = 1,2,...,K in the antecedent of an if-then rule.

A crisp value of the output we can get from the Modified Center of Gravity (MCOG) as defuzzification [5]:

```
MCOG[B(x)] = ∫ x [B(x) − α] dx / ∫ [B(x) − α] dx , (11.31)
```

where α is constant.

The subtraction of value α ∈ [0,1] eliminates the non-informative part of the membership function B(x). For α = 0 we get well known COG defuzzification. A final crisp value of the system output for sum as aggregation and MCOG defuzzification can be evaluated from formula:

```
y0 = ∫ y Σ_{k=1}^K { Ψ [R_k(x0), B^(k)(y)] − α_k } dy / ∫ Σ_{k=1}^K { Ψ [R_k(x0), B^(k)(y)] − α_k } dy = ∫ y Σ_{k=1}^K [B'^(k)(y) − α_k] dy / ∫ Σ_{k=1}^K [B'^(k)(y) − α_k] dy , (11.32)
```

where Ψ stands for fuzzy implication I or t-norm T for logical or conjunctive implication interpretation, respectively.

A method of determination, the values α will be described later. Now we introduce symbol B*^(k) := B'^(k) − α_k. Membership functions of fuzzy sets B*^(k) can be represented by the parameterized functions:

```
B*^(k) ~ f^(k) [ Area ( B*^(k) ), y^(k) ] , (11.33)
```

where y^(k) is the center of gravity (COG) location of the fuzzy set B*^(k):

```
y^(k) = COG ( B*^(k) ) = ∫ y B*^(k)(y) dy / ∫ B*^(k)(y) dy . (11.34)
```

A general form for final output value can be put in the form:

```
y0 = Σ_{k=1}^K y^(k) Area ( B*^(k) ) / Σ_{k=1}^K Area ( B*^(k) ) , (11.35)
```

where B*^(k) is a resulting conclusion for the k-th rule before aggregation.
