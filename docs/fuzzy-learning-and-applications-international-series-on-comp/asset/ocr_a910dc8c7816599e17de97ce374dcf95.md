# 方舟生存进化 泰克复制器 材质更换教程

作者：xxx | 日期：2023-11-05

# 一、前言

泰克复制器是方舟生存进化中的高级制作设备，玩家可以通过修改材质来个性化其外观。下面将介绍更换材质的具体步骤。

# 二、准备工作

+   - 确认游戏版本为最新版
+   - 备份游戏文件
+   - 准备材质包（如 .pak 文件）

# 三、操作步骤

+   1. 找到游戏安装目录下的 `ShooterGame/Content/Mods` 文件夹。
+   2. 将材质包复制到该文件夹。
+   3. 启动游戏，在模组设置中启用该材质包。
+   4. 进入游戏后，打开泰克复制器即可看到新材质。

# 四、注意事项

+   - 材质更换不影响游戏平衡
+   - 如果未生效，请检查模组加载顺序
+   - 联机时需确保所有玩家都安装了相同材质包
