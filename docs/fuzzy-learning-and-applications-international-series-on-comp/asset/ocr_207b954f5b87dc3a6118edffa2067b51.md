# 6.2 Fuzzy Systems

There are many different types of fuzzy systems, such as those first proposed by (and named after) Mamdani [17], and Takagi and Sugeno [27]. The one which will be utilised in this chapter is a special case of the Mamdani type in which the rules always have crisp consequents. This model has been used extensively to express the relationship between output and input variables either for control or for system modelling.

R^i: If x_1 is Ã_1^i and ... x_j is Ã_j^i ... and x_p is Ã_p^i then y is B^i

The label of the i^th rule is R^i. The j^th input variable is x_j : j = 1,2,...,p and y is the output. Ã_j^i (i = 1,2,...,n and j = 1,2,...,p) are fuzzy labels, and B^i are real numbers. n and p are the numbers of rules and input variables, respectively. The number of distinguishable membership functions for a specific input variable x_j (Ã_j^1, Ã_j^2,..., Ã_j^i,..., Ã_j^n) is K_j. It is assumed that the universe of input variables is limited to lower limit (LL) and upper limit (UL) bounds, i.e., x_j ∈ [LL_j, UL_j], j = 1,...,p.
