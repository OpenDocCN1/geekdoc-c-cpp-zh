```
x ∧₀ y = min₀ (x, y) = { 0,          if x ≤ N(y),  min(x, y),  if x > N(y), }  (11.6)
```

and

```
x ∨₁ y = max₁ (x, y) = { 1,          if x ≤ N(y),  max(x, y),  if x > N(y) }  (11.7)
```

Then the residuated implication is of the form:

```
I_min₀ (x, y) = I_Fo (x, y) = { 1,          if x ≤ y,  max(1 − x, y),  if x > y }  (11.8)
```

Although I_min₀ is not continuous, I_min₀ (x, 0) = 1 − x, x ∈ [0,1], is the standard strong negation. Fuzzy implication (11.8) has been introduced by Fodor [9], [11] and will be also taken into account in further considerations.

Since t-norms (e.g., M-, Π-, W-, Z- norms), t-conorms (e.g., M'-, Π'-, W'-, Z'- conorms) and strong negation (e.g., N(x) = 1 − x) are well-established models for AND, OR, NOT respectively, fuzzy implications should be regarded as closely related to those models. We may also classify and order fuzzy implications using an integrated index obtained from the location of fuzzy implications versus fuzzy operations within the interval [0,1].

Let ⋆₁, ⋆₂ : [0,1]² → [0,1] be measurable functions treated as two-argument operations in [0,1]. The distance between the operations ⋆₁ and ⋆₂ with respect to the values of their arguments is calculated as follows [6]:

```
d(⋆₁, ⋆₂) = ∫₀¹ ∫₀¹ |x ⋆₁ y − x ⋆₂ y| dx dy,  (11.9)
```

where d is here a pseudometric distance.

For constant operations, i.e., for x ⋆₁ y = 0, x ⋆₂ y = 1, for all x, y ∈ [0,1] we get d(⋆₁, ⋆₂) = 1. Because constant operations differ from drastic operations only by boundary conditions, the distance for drastic operations is obtained as follows:

```
d(⊓, ⊔) = 1  (11.10)
```

where ⊓ and ⊔ denote drastic product (Z-norm) and drastic sum (Z'-conorm), respectively.
