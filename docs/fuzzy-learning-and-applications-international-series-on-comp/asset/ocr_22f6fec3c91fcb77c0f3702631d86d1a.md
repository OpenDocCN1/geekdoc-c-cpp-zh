For instance, any input pair (x₁, x₂) in the light-shaded interval Cₘₙ = [(ε₁ₘ, ε₁ₘ₊₁) × (ε₂ₙ, ε₂ₙ₊₁)] maps onto an output determined by the rules in the dark-shaded interval (active rules) while all remaining rules have no influence on the output. Only the active rule membership functions and their associated singleton values (the output values defining the consequent action at the center of each rule interval) are needed for the interpolation procedure. In addition, the only membership function pieces needed are those which actually contribute to the system output. Thus, in the case illustrated in Fig.2.4, only the pieces drawn with thick lines and the singletons associated with the four active rule consequents, y*ₘₙ, y*ₘ(ₙ₊₁), y*₍ₘ₊₁₎ₙ and y*₍ₘ₊₁₎(ₙ₊₁), are needed to generate the output in the interval Cₘₙ.
