passed on to the (i+1)-th stage as an inferred fact. When the intermediate variable y_i (in if-part) in the (i+1)-th stage equals the y_i variable (in then-part) in the i-th stage, the match-degree α_h^{i+1}(y_i), 1 ≤ i ≤(m−1), h ∈ {1,⋯,l_i}, j ∈ {1,⋯,n_i} of the h-th fuzzy value of the variable y_i can be pre-computed according to the following theorem:

# Theorem 2 [5, 20]: The consequence μ_{\bar{B}_i}(u^i) of the then-part variable y_i in the i-th stage is passed on to the (i+1)-th stage as an inferred fact, μ_{\bar{A}_{i+1}}(u^i). The match-degree α_h^{i+1}(y_i), 1 ≤ i ≤(m−1), h ∈ {1,⋯,l_{i+1}} of the h-th fuzzy value of the variable y_i in the (i+1)-th stage can be pre-computed as

```
α_h^{i+1}(y_i) = max_{g∈{1,⋯,q_{i+1}}} (α_{t_g}^i_T ∧ β_{h,g}), if β_{h,g} > 0   (5.23)
β_{h,g} = max_{u^i∈U_{y_i}} (μ_{F V_h^{i+1}(y_i)}(u^i) ∧ μ_{F V_g^i(y_i)}(u^i))   (5.24)
```

where α_{t_g}^i_T = max_{i∈T_g^i} (α_{j_T}^i), 1 ≤ i ≤ m, j ∈ {1,⋯,n_i}. Note that the T_i, i ∈ {0,⋯,3}, operators in if-part and then-part must be of the same type as T-norm operators, and the S-norm operator is only the S_0 operator [5]. When the intermediate variable y_i, 1 ≤ i ≤ m − 1 (in if-part), in the (i+1)-th stage is the same as the one (in then-part) in the i-th stage, the β_{h,g}s are easily obtained from the membership function definitions of variable y_i. Meanwhile, the match-degree α_h^{i+1}(y_i) is broadcasted to the if-part of fuzzy rules. Then the firing strength of rule R_j^{i+1}, 1 ≤ i ≤ m, j ∈ {1,⋯,n_{i+1}} can also be derived from the following:

```
α_{j_T}^{i+1} = α_{h'}^{i+1}(x_{i+1,k}) ∧ α_h^{i+1}(y_i),
k ∈ {0,1,⋯,L_i}, h ∈ {1,⋯,l_{i+1}}, h' ∈ {1,⋯,l'_{i+1}}   (5.25)
```
