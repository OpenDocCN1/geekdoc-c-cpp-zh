a node (e.g., $m_{ij}$ and $\sigma_{ij}$ in our class), the general learning rule used is given by:

$$\Delta w \propto -\frac{\partial E}{\partial w},$$ $$w(t+1) = w(t) + \eta\left(-\frac{\partial E}{\partial w}\right),$$

where $\eta$ is the learning rate and

$$\frac{\partial E}{\partial w} = \frac{\partial E}{\partial a} \frac{\partial a}{\partial w}.$$

# 10.6.2 NFS Heuristics

The neuro-fuzzy scheduler solves the scheduling problem by intelligently combining heuristics presented in this section. Note that such a selection is based on the current state of the system and the SI's work-load.

The first heuristic is based on the Forward-Earliest Completion Time (F-ECT) rule. F-ECT constructs a schedule by proceeding forward in time. It starts with the AUS needed at the beginning of the presentation and attempts to schedule each AUS on a channel that can transmit it at the earliest time. Let $\alpha_j$ denote the earliest time when channel $C_j$ becomes idle. The values of $\alpha_j$'s are initially set to zero and are updated to $\alpha_j = \alpha_j + \frac{s_i}{c_j}$ whenever an $AUS_i$ is assigned to channel $C_j$. Let $\mathcal{S}_j$ be the list of AUSs that are scheduled on channel $C_j$. The F-ECT algorithm computes $\mathcal{S}_j, 1 \le j \le m$ as follows:

# Forward-Earliest Completion Time (F-ECT) Algorithm

+   - **F_ECT.1** Sort AUSs to be scheduled during the SI in non-decreasing order of their playout deadlines. Put the sorted AUSs in a list $\mathcal{W}$. If two AUSs have the same deadlines, then apply the longest processing time (LPT) rule, i.e., the AUS with larger size precedes the one with smaller size.

+   - **F_ECT.2** Initialize $\mathcal{S}_j := \{\emptyset\}$ and $\alpha_j := 0$ for all channels, $1 \le j \le m$.

+   - **F_ECT.3** Starting from the head of the list, schedule each AUS in $\mathcal{W}$ on the channel that minimizes its arrival time at the client location, i.e., follow the earliest completion time (ECT) rule. In other words, $$\mathcal{S}_j = \mathcal{S}_j \cup \{AUS_i\} \quad \text{if} \quad j = \arg \min_{1 \le k \le m} \{\alpha_k + \frac{s_i}{c_k} + J_k\}.$$
