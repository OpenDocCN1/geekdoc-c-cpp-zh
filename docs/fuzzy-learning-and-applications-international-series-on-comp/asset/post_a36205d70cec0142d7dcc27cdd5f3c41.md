
Using (11.46) we obtain:

$$
R_k(\underline{x}_0) = \exp\left[ -\sum_{j=1}^{n} \frac{\left(x_{j0} - c_j^{(k)}\right)^2}{2\left(s_j^{(k)}\right)^2} \right]. \tag{11.48}
$$

Additionally, we assume that the consequent \(B^{(k)}\) of the \(k\)-th if-then rule has a symmetric triangular (isosceles triangle) membership function with the width of the triangle base \(w^{(k)}\). For computing the system output we must calculate \(\mathrm{Area}\left(B^{*(k)}\right)\). From (11.28) and (11.32) we have:

$$
B^{*(k)}(y) = I\left[R_k(\underline{x}_0), B^{(k)}\right] - \alpha_k. \tag{11.49}
$$

For an implication satisfying condition \(I_9\) we assume:

$$
\alpha_k = 1 - R_k(\underline{x}_0). \tag{11.50}
$$

For example, if we use the Reichenbach implication we get:

$$
\mathrm{Area}\left(B^{*(k)}\right) = 2 \int_{y^{(k)} - \frac{w^{(k)}}{2}}^{y^{(k)}} \left\{ I\left[R_k(\underline{x}_0), B^{(k)}\right] - \alpha_k \right\} dy = 2 \int_{y^{(k)} - \frac{w^{(k)}}{2}}^{y^{(k)}} \left[1 - R_k(\underline{x}_0) + R_k(\underline{x}_0) B^{(k)} - 1 + R_k(\underline{x}_0)\right] dy = 2 R_k(\underline{x}_0) \int_{y^{(k)} - \frac{w^{(k)}}{2}}^{y^{(k)}} \left[\frac{2\left(y - y^{(k)}\right)}{w^{(k)}} + 1\right] dy = \frac{w^{(k)}}{2} R_k(\underline{x}_0) := g\left[R_k(\underline{x}_0), w^{(k)}\right]. \tag{11.51}
$$

For \(n\) inputs and \(K\) if-then rules we have to establish the following unknown parameters:

- \(c_j^{(k)}, s_j^{(k)}; j = 1, 2, \dots, n; k = 1, 2, \dots, K\) — the parameters of membership functions of input sets,
- \(p_j^{(k)}; j = 0, 1, \dots, n; k = 1, 2, \dots, K\) — the parameters determining the location of output sets,
- \(w^{(k)}; k = 1, 2, \dots, K\) — the parameters of output sets.

Obviously, the number of if-then rules is unknown. Let us observe that equations (11.48) and (11.52) describe a radial neural network. The unknown parameters (except the number of rules \(K\)) are estimated by means of a gradient method performing the steepest descent on a surface in the parameter space. Therefore the so-called learning set is necessary, i.e., a set of inputs for which the output values are known \(\{\underline{z}_0(i), t_0(i)\}; i = 1, 2, \dots, N\). The measure of the error of output value may be defined for a single pair from the training set:

$$
E = \frac{1}{2}(t_0 - y_0)^2, \tag{11.53}
$$

where \(t_0\) is the desired (target) value of output.

Another solution accelerating the convergence of the method is the estimation of parameters \(\underline{p}^{(k)}; k = 1, \dots, K\) by means of the least squares method. The output value \(y_0\) of the system in equation (11.52) may be considered to be a linear combination of unknown parameters \(\underline{p}^{(k)}\). If we introduce the following notation:

$$
S^{(k)}(\underline{x}_0) = \frac{g\left[R_k(\underline{x}_0), w^{(k)}\right]}{\sum_{i=1}^{K} g\left[R_i(\underline{x}_0), w^{(i)}\right]}, \tag{11.60}
$$

$$
\underline{D}(\underline{x}_0) = \left[ S^{(1)}\underline{x}_0'^T : S^{(2)}\underline{x}_0'^T : \cdots : S^{(K)}\underline{x}_0'^T \right]^T, \tag{11.61}
$$

$$
\underline{P} = \left[ \underline{p}^{(1)T} : \underline{p}^{(2)T} : \cdots : \underline{p}^{(K)T} \right]^T, \tag{11.62}
$$

equation (11.52) may be written in the form:

$$
y_0 = \underline{D}(\underline{x}_0)^T \underline{P}. \tag{11.63}
$$

Hence parameters \(\underline{P}\) may be estimated by means of the least squares method. To eliminate the matrix inverse we use the recursive method. For the \(k\)-th step, e.g., (\(k\)-th element from the learning set) we get [18]:

$$
\hat{\underline{P}}(k) = \hat{\underline{P}}(k - 1) + \underline{G}(k - 1)\underline{D}[\underline{x}_0(k)] \left\{ y_0(k) - \underline{D}[\underline{x}_0(k)]^T \hat{\underline{P}}(k - 1) \right\}, \tag{11.64}
$$

$$
\underline{G}(k) = \underline{G}(k - 1) - \underline{G}(k - 1)\underline{D}[\underline{x}_0(k)] \times \left\{ \underline{D}[\underline{x}_0(k)]^T \underline{G}(k - 1)\underline{D}[\underline{x}_0(k)] + 1 \right\}^{-1} \underline{D}[\underline{x}_0(k)]^T \underline{G}(k - 1). \tag{11.65}
$$

To initialize the computations we take:

$$
\hat{\underline{P}}(0) = 0, \quad \underline{G}(0) = \beta \underline{I}, \tag{11.66}
$$

where \(\underline{I}\) is the identity matrix, \(\beta\) is a large positive constant (e.g., \(10^6\)).

Finally in each iteration parameters \(\underline{p}^{(k)}\) are estimated on the basis of equations (11.64) and (11.65), whereas the other parameters are estimated by means of a gradient method (11.54), (11.55), (11.56), (11.59).

Another problem is the estimation of the number \(m\) of if-then rules and initial values of membership functions for the premise part. This task is solved by means of preliminary clustering of the input part of training data using the fuzzy c-means method [1], [23]. This method assigns each input vector \(\underline{x}_0(k); k = 1, 2, \dots, N\) to clusters represented by prototypes \(\underline{v}_i; i = 1, \dots, K\) measured by grade of membership \(u_{ik} \in [0,1]\). The \(K \times n\) dimensional partition matrix fulfills the following assumptions:

$$
\forall k \sum_{i=1}^{K} u_{ik} = 1, \quad \forall i \sum_{k=1}^{N} u_{ik} \in (0,N). \tag{11.67}
$$

The c-means method minimizes the scalar index for parameter \(r > 1\):

$$
J_r = \sum_{k=1}^{N} \sum_{i=1}^{K} (u_{ik})^r \|\underline{x}_0(k) - \underline{v}_i\|^2. \tag{11.68}
$$

Defining \(D_{ik}^2 = \|\underline{x}_0(k) - \underline{v}_i\|^2\), where \(\|\cdot\|\) is a vector norm (the most frequent Euclidean norm), we get an iterative method of commutative modification of the partition matrix and prototypes [1]:

$$
\underline{v}_i = \frac{\sum_{k=1}^{N}(u_{ik})^r \underline{x}_0(k)}{\sum_{k=1}^{N}(u_{ik})^r}, \tag{11.69}
$$

$$
u_{ik} = \left[ \sum_{j=1}^{K} \left( \frac{D_{ik}}{D_{jk}} \right)^{2/(r-1)} \right]^{-1}. \tag{11.70}
$$

According to the above written equations the calculations are initialized using a random partition matrix \(U\) which fulfills conditions (11.67). Such a method leads to the local minimum for index (11.68). Therefore the most frequently used solution is multiple repeated calculations in accordance with equations (11.69), (11.70) for various random realizations of partition matrix initializations. The computations are stopped when the predefined number of iterations (in our case 500) is executed or when in two successive iterations the change of index value \(J_r\) is less than the set value (in our case 0.001).

As a result of preliminary clustering the following assumption for ANBLIR initialization can be made: \(c^{(j)} = \underline{v}_j; j = 1, 2, \dots, K\) and:

$$
s^{(j)} = \sqrt{ \frac{\sum_{k=1}^{N} (u_{jk})^r \left[\underline{x}_0(k) - \underline{v}_j\right]^2}{\sum_{k=1}^{N} (u_{jk})^r} }. \tag{11.71}
$$

For calculations presented in the next section, the Reichenbach fuzzy implication and the following parameter values, \(\eta = 0.01\), \(n_r = 1.1\), \(n_d = 0.9\), \(\beta = 10^6\), \(r = 2\), have been applied.

## 11.6 Application of ANBLIR to pattern recognition

In this section, we present an application of the fuzzy system described previously to a pattern recognition problem. If patterns from a learning set belong to classes \(\omega_1\) and \(\omega_2\) then we can build a fuzzy system whose output takes positive values for patterns from class \(\omega_1\) and negative or zero values for class \(\omega_2\). $$
