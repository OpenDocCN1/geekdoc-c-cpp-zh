
During the learning process of a classifier we take \(t_0(k)=1\) for pattern \(x_0(k)\) from class \(\omega_1\) and \(t_0(k)=-1\) for pattern from class \(\omega_2\). For a bigger number of class \((\omega_1,\omega_2,\ldots,\omega_p, p>2)\) an extension class-rest or class-class can be used [24], [25]. The latter was used in our method due to existence of common feature regions for which the classificator class-rest does not give the answer to which class the classified pattern belongs. The disadvantage of such a solution is the necessity of constructing a greater number of classifiers. Let us denote the classifier making decision whether a pattern belongs to the \(i\)-th or \(j\)-th class as:

\[y_0(k)=FNN_{ij}[x_0(k)]\begin{cases}>0, & \text{if }x_0(k)\in\omega_i,\\ \le 0, & \text{if }x_0(k)\in\omega_j.\end{cases}\tag{11.73}\]

Obviously we do not construct the classifier \(FNN_{ij}\), and the information about membership to \(i\)-th and \(j\)-th classes can be obtained on the basis of \(FNN_{ij}\) or \(FNN_{ji}\) classifiers. Hence we construct \(p(p-1)/2\) classifiers \(FNN_{ij}\) for \(1\le i<p;\ j>i\). The classification condition for \(i\)-th class has the form:

\[\forall_{j\ne i}\ FNN_{ij}[x_0(k)]>0\Longrightarrow x_0(k)\in\omega_i.\tag{11.74}\]

The learning process goes as follows: for each pair of indices \(ij\) \((1\le i<p;\ j>i)\) we assume \(t_0(k)=1\) for pattern \(x_0(k)\) belonging to class \(\omega_i\) and \(t_0(k)=-1\) for pattern \(x_0(k)\) belonging to class \(\omega_j\) (the patterns belonging to other classes are removed from the training set) and we conduct the learning process of the classifier. The final pattern classification is made on the basis of condition (11.74).
