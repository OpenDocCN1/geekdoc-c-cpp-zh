μ ≥ Δy*_{imin} / ε_{ymin} (2.22)

where ε_{ymin} = |y_d(x)−y(x)|_{min} is the minimum deviation of the output from the target which can be translated into an increment in the singleton value. In other words, beyond this minimum value the learning process stops and the parameters (singletons) are not updated anymore.

The input-output training samples were obtained from the function y = 2 + sin(πx₁) sin(πx₂), up to 11 × 11 samples to cover the input interval [0, 2] × [0, 2].
