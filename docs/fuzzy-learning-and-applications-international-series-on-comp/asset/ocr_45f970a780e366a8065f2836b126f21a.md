# 6.6 Conclusions

In this chapter, reviews of fuzzy and learning fuzzy systems are presented followed by a gradient descent method to update the parameters of a fuzzy system. It has been shown that the integrity of learning fuzzy systems can be preserved by using a constrained training algorithm. There is a trade-off between obtaining the minimum of cost function and the preservation of integrity in the sense of the interpretability of the learning fuzzy systems.
