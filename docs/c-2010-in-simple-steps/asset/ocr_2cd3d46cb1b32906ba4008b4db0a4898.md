The Extension Manager feature helps application developers to easily add, remove, enable, and disable Visual Studio extensions. These extensions include project templates and new controls for ASP.NET, WPF, and Silverlight. You can open the Extension Manager window by selecting the Extension Manager option in the Tools menu.
