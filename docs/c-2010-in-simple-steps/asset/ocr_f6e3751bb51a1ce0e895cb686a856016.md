# Snaplines

Snapline is a feature in the WPF Design view that helps you to align the controls in a WPF 4.0 application. A snapline appears only when you have more than one control in a WPF application and you drag or align the edges and text of a control horizontally or vertically. The snapline appears as a light brown line along the edges of the control, as shown in Fig.C7-7.11:

![](bbox=[0.33, 0.24, 0.66, 0.42])

Fig.C7-7.11

In Fig.C7-7.11, you can see the number 49 displayed at one end of the snapline. This number represents the distance between the edges of the controls you want to align. In case you do not want to see the snaplines, you can press the ALT key while dragging or resizing the control.

# The XAML View

As the name suggests, the XAML view allows you to view and work with the XAML code of WPF 4.0 applications. The XAML view and the Design view are inter-related such that whatever changes you make in the Design view are reflected in the XAML view and vice versa. This implies that you can also design WPF applications by using the XAML view. Fig.C7-7.12 shows the XAML view (along with the tag navigator) of a WPF 4.0 application:
