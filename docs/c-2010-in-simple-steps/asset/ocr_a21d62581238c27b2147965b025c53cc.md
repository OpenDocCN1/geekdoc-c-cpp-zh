# The Tag Navigator

By default, the tag navigator appears just below the XAML view. It allows you to navigate to the parent XAML tag or element of the currently selected element. When you hover the mouse over a tag in the tag navigator, a thumbnail preview of that tag is displayed, as shown in Fig.C7.15:
