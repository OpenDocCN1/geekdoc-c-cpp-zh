# Anchoring and Docking a Control

Docking and anchoring refer to the techniques used to align and arrange the existing controls of a form.

Docking refers to attaching a control to the edge of a parent control and anchoring refers to specifying the distance that each edge of a control should maintain from the edges of the parent control.

Let's perform the following steps to dock the Button control in the SampleApplication application:
