Now, let's learn how to nest multiple if statements.

By nesting multiple if statements, you can further refine the process of taking decisions on the basis of the specific condition, as it helps in examining multiple conditions. As a program increases in complexity, the number of conditions that you use to execute the code also increases. In such cases, it is better to nest multiple if statements to attain the required result. The syntax of using the nested if statements is as follows:

```
if condition //condition
{
    //statement
}
else
if condition //condition
{
    //statement
}
else
{
    //statement
}
```

In the preceding syntax, if the condition in the first if block is evaluated to true, then the first if block executed; otherwise, the program control transfers to the else...if block and checks the condition specified in the if statement. Now, if this condition evaluates to true, then the block of code inside the else...if block executes; otherwise, the program control transfers to the else block.
