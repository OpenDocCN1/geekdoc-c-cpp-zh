This system may have zero, one, or an infinite number of solutions, depending on the coefficients of the matrix \textbf{A} and the vector \textbf{b}. There are various methods for solving linear systems. We use a classic scheme, called Gaussian elimination (see Freeman and Phillips, *Parallel Numerical Algorithms*; Stewart, *Matrix Algorithms, Volume I*; and Wood, *Introduction to Numerical Analysis*).
