# A.6 Statements

Here is a grammar for C++'s statements ( $\mathit{opt}$ means "optional"):

```
statement:
	declaration
	{ statement-list $\mathit{opt}$ }
	try { statement-list $\mathit{opt}$ } handler-list
	expression $\mathit{opt}$ ;
	selection-statement
	iteration-statement
	labeled-statement
	control-statement

selection-statement:
	if ( condition ) statement
	if ( condition ) statement else statement
	switch ( condition ) statement

iteration-statement:
	while ( condition ) statement
	do statement while ( expression ) ;
	for ( for-init-statement condition $\mathit{opt}$ ; expression $\mathit{opt}$ ) statement
	for ( declaration : expression ) statement

labeled-statement:
	case constant-expression : statement
	default : statement
	identifier : statement

control-statement:
	break ;
	continue ;
	return expression $\mathit{opt}$ ;
	goto identifier ;

statement-list:
	statement statement-list $\mathit{opt}$

condition:
	expression
	type-specifier declarator = expression
```
