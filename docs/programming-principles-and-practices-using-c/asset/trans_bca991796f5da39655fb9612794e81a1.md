
可供下载的歌曲列表、一组汽车支付选项、未来一周的天气预报列表、不同网店中相机的价格列表等。可能性实际上是无限的，因此在程序中无处不在。我们将看到多种存储数据集合的方式（多种数据容器；见第 20 章和第 21 章）。这里我们将从存储数据最简单、也许也最有用的一种方式开始：**向量**。

**向量** 只是一个你可以按索引访问的元素序列。例如，这里有一个名为 **v** 的 **向量**：

![](img/e0ceba017429f80f5cf63e81a1e7ef4f_150_0.png)

也就是说，第一个元素的索引为 0，第二个为 1，依此类推。我们通过将 **向量** 的名称与元素的索引组合来引用元素，因此这里 **v[0]** 的值是 **5**，**v[1]** 的值是 **7**，以此类推。**向量** 的索引总是从 0 开始并以 1 递增。这应该看起来很熟悉：标准库中的 **向量** 只不过是 C++ 标准库对一种古老且众所周知的概念的诠释。我画出向量是为了强调它“知道自己的大小”；也就是说，**向量** 不仅存储其元素，还存储其大小。

我们可以像这样创建一个这样的 **向量**：

```
vector<int> v = {5, 7, 9, 4, 6, 8};    // 包含 6 个整数的向量
```

我们看到，要创建一个 **向量**，我们需要指定元素的类型和初始元素集合。元素类型位于 **vector** 之后的尖括号（<, >）中，这里是 **<int>**。这是另一个例子：

```
vector<string> philosopher
    = {"Kant", "Plato", "Hume", "Kierkegaard"};   // 包含 4 个字符串的向量
```

自然地，**向量** 只会接受其声明的元素类型的元素：

```
philosopher[2] = 99;     // 错误：试图将整数赋值给字符串
v[2] = "Hume";           // 错误：试图将字符串赋值给整数
```

我们还可以定义一个指定大小的 **向量** 而不指定元素值。在这种情况下，我们使用 (**n**) 表示法，其中 **n** 是元素的数量，元素根据其类型获得默认值。例如：

```
vector<int> vi(6);        // 初始化为 0 的 6 个整数的向量
vector<string> vs(4);     // 初始化为 "" 的 4 个字符串的向量
```

没有字符的字符串 `""` 被称为空字符串。

请注意，你不能简单地引用 **向量** 中不存在的元素：

```
vi[20000] = 44; // 运行时错误
```

我们将在下一章讨论运行时错误和索引引用。

### 4.6.1 遍历向量

**向量** “知道”它的大小，因此我们可以像这样打印 **向量** 的元素：

```
vector<int> v = {5, 7, 9, 4, 6, 8};
for (int i=0; i<v.size(); ++i)
cout << v[i] << "\n";
```

调用 **v.size()** 给出名为 **v** 的 **向量** 的元素数量。一般来说，**v.size()** 让我们能够访问 **向量** 的元素，而不会意外地引用超出 **向量** 范围之外的元素。**向量** **v** 的范围是 **[0:v.size())**。这是半开元素序列的数学表示法。**v** 的第一个元素是 **v[0]**，最后一个元素是 **v[v.size()-1]**。如果 **v.size()==0**，则 **v** 没有元素，也就是说，**v** 是一个空 **向量**。这种半开序列的概念在整个 C++ 和 C++ 标准库中都有使用（§17.3, §20.3）。

语言利用半开序列的概念来提供一种简单的循环，以遍历序列（例如 **向量** 的元素）中的所有元素。例如：

```
vector<int> v = {5, 7, 9, 4, 6, 8};
for (int x : v) // 对于 v 中的每个 x
cout << x << "\n";
```

这被称为范围-**for**-循环，因为*范围*一词常被用来表示与“元素序列”相同的意思。我们将 **for (int x : v)** 读作“对于 **v** 中的每个 **int x**”，该循环的含义与遍历下标 **[0:v.size())** 的等效循环完全相同。我们使用范围-**for**-循环来执行遍历序列所有元素的简单循环，每次查看一个元素。更复杂的循环，例如查看 **向量** 中每隔第三个元素、仅查看 **向量** 的后半部分，或比较两个 **向量** 的元素，通常最好使用更复杂和更通用的传统 **for** 语句（§4.4.2.3）。

### 4.6.2 扩展向量

通常，我们从一个空 **向量** 开始，并在读取或计算所需数据时将其扩展到期望的大小。这里的关键操作是 **push_back()**，它向 **向量** 添加一个新元素。新元素成为 **向量** 的最后一个元素。例如：

```
vector<double> v; // 从空开始；即 v 没有元素
```

![](img/e0ceba017429f80f5cf63e81a1e7ef4f_152_0.png)

```
v.push_back(2.7); // 在 v 的末尾（“后部”）添加一个值为 2.7 的元素
// v 现在有一个元素且 v[0]==2.7
```

![](img/e0ceba017429f80f5cf63e81a1e7ef4f_152_1.png)

```
v.push_back(5.6); // 在 v 的末尾添加一个值为 5.6 的元素
// v 现在有两个元素且 v[1]==5.6
```

![](img/e0ceba017429f80f5cf63e81a1e7ef4f_152_2.png)

```
v.push_back(7.9); // 在 v 的末尾添加一个值为 7.9 的元素
// v 现在有三个元素且 v[2]==7.9
```

![](img/e0ceba017429f80f5cf63e81a1e7ef4f_152_3.png)

注意 **push_back**() 调用的语法。它被称为*成员函数调用*；**push_back**() 是 **vector** 的成员函数，必须使用这种点符号来调用：

```
*成员函数调用*:
对象名称.成员函数名称 ( 参数列表 )
```

可以通过调用 **vector** 的另一个成员函数来获取 **向量** 的大小：**size**()。最初 **v.size**() 是 **0**，在第三次调用 **push_back**() 后，**v.size**() 变成了 **3**。

如果你以前编写过程序，你会注意到 **向量** 类似于 C 和其他语言中的数组。然而，你不需要预先指定 **向量** 的大小（长度），你可以添加任意数量的元素。随着学习的深入，你会发现 C++ 标准 **向量** 还有其他有用的属性。

### 4.6.3 一个数值示例

让我们看一个更现实的例子。通常，我们有一系列数值，希望读取到程序中，以便对它们进行处理。“处理”可能包括生成数值的图表，计算均值和中位数，查找最大元素，排序，将它们与其他数据结合，搜索“有趣”的值，将它们与其他数据比较等。我们对数据可能执行的计算范围没有限制，但首先我们需要将它们放入计算机内存中。这里是将未知——可能很大——数量的数据引入计算机的基本技术。作为一个具体的例子，我们选择读取代表温度的浮点数：

```c
// 将一些温度读取到向量中
int main()
{
  vector<double> temps;        // 温度
  for (double temp; cin>>temp; )  // 读取到 temp
    temps.push_back(temp);     // 将 temp 放入向量
    // ... 执行某些操作 ...
}
```

那么，这里发生了什么？首先我们声明一个 **向量** 来存储数据：

```c
vector<double> temps;          // 温度
```

这里提到了我们期望的输入类型。我们读取并存储 **double**。接下来是实际的读取循环：

```c
for (double temp; cin>>temp; )        // 读取到 temp
  temps.push_back(temp);              // 将 temp 放入向量
```

我们定义了一个类型为 **double** 的变量 **temp** 用于读取。**cin>>temp** 读取一个 **double**，该 **double** 被压入 **向量**（放在后部）。我们之前已经见过这些单独的 operação。这里新的是我们将输入操作 **cin>>temp** 用作 **for** 语句的条件。基本上，如果值被正确读取，**cin>>temp** 为真，否则为假，因此该 **for** 语句将读取我们提供的所有 **doubles**，并在我们提供其他任何内容时停止。例如，如果你输入

**1.2 3.4 5.6 7.8 9.0**

那么 **temps** 将包含五个元素 **1.2**、**3.4**、**5.6**、**7.8**、**9.0**（按此顺序，例如，**temps[0]=1.2**）。我们使用字符 ‘␣’ 来终止输入——任何不是 **double** 的内容都可以使用。在 §10.6 中，我们讨论如何终止输入以及如何解决输入错误。
