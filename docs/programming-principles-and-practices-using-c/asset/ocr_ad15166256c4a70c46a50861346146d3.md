Basically, we implement **vector\<T,A>::erase()** by copying all elements after the element we erase (remove, delete). Using the definition of **vector** from \u00a719.3.7 with the additions above, we get

```
```cpp
template<typename T, typename A>      // requires Element<T>() &&
                                      // Allocator<A>() (\u00a719.3.3)
vector<T,A>::iterator vector<T,A>::erase(iterator p)
{
   if (p==end()) return p;
   for (auto pos = p+1; pos!=end(); ++pos)
       *(pos-1) = *pos;               // copy element "one position to the left"
   alloc.destroy(&*(end()-1));        // destroy surplus copy of last element
   --sz;
   return p;
}
