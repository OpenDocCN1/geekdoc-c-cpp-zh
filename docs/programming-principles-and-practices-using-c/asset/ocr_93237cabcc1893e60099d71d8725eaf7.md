# 13.12 **Circle**

Just to show that the world isn't completely rectangular, we provide class **Circle** and class **Ellipse**. A **Circle** is defined by a center and a radius:

```
struct Circle : Shape {
    Circle(Point p, int rr);    // center and radius

    void draw\_lines() const;

    Point center() const ;
    int radius() const { return r; }
    void set\_radius(int rr)
    {
        set\_point(0,Point{center().x-rr,center().y-rr}); // maintain
                                                      // the center

        r = rr;
    }
private:
    int r;
};
```

We can use **Circle** like this:

```
Circle c1 {Point{100,200},50};
Circle c2 {Point{150,200},100};
Circle c3 {Point{200,200},150};
```
