One obvious use of \*\*Marks\*\* is to display data that represents discrete events so that drawing connecting lines would be inappropriate. An example would be (height, weight) data for a group of people.

A \*\*Marks\*\* is simply a \*\*Marked\_polyline\*\* with the lines \*\*invisible\*\*:

```
```cpp
struct Marks : Marked_polyline {
    Marks(const string& m)
        :Marked_polyline(m)
    {
        set_color(Color{Color::invisible});
    }
    Marks(const string& m, initializer_list<Point> lst)
        : Marked_polyline(m, lst)
    {
        set_color(Color{Color::invisible});
    }
};
```
```

The ::Marked\_polyline(m) notation is used to initialize the \*\*Marked\_polyline\*\* part of a \*\*Marks\*\* object. This notation is a variant of the syntax used to initialize members (§9.4.4).
