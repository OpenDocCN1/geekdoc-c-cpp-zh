The operations on a (non-**void**) object pointer are:

Note that any form of pointer arithmetic (e.g., <code>++p</code> and <code>p+=7</code>) is allowed only for pointers into an array and that the effect of dereferencing a pointer pointing outside the array is undefined (and most likely not checked by the compiler or the language run-time system). The comparisons <code>&lt;</code>, <code>&lt;=</code>, <code>&gt;</code>, and <code>&gt;=</code> can also be used for pointers of the same type into the same object or array.

The only operations on a <code>void*</code> pointer are copying (assignment or initialization), casting (type conversion), and comparison (<code>==</code>, <code>!=</code>, <code>&lt;</code>, <code>&lt;=</code>, <code>&gt;</code>, and <code>&gt;=</code>).

A pointer to function (\S27.2.5) can only be copied and called. For example:

```
using Handle_type = void (*)(int);
void my_handler(int);
Handle_type handle = my_handler;
handle(10);    // equivalent to my_handler(10)
```

# A.8.2 Arrays

An *array* is a fixed-length contiguous sequence of objects (elements) of a given type:

```
int a[10];      // 10 ints
```
