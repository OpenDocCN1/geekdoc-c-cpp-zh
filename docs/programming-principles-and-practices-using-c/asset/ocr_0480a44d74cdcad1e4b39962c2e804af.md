That’s all pretty obvious. We get integer coordinates from the `ln_box` using `get_int()`. We use an `ostringstream` to format the string to be put into the `Out_box`; the `str()` member function lets us get to the string within the `ostringstream`. The final `redraw()` here is needed to present the results to the user; until a `Window`’s `redraw()` is called, the old image remains on the screen.
