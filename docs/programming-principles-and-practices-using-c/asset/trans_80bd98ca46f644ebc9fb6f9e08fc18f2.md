## 后记

那么，嵌入式系统编程基本上就是“位操作”吗？完全不是，特别是如果你刻意试图将位操作作为潜在的正确性问题加以最小化。然而，在系统中的某个地方，位和字节“必须被操作”；问题只是在哪里以及如何进行。在大多数系统中，低级代码可以被并且应该被局部化。我们处理的许多最有趣的系统都是嵌入式的，而该领域中一些最有趣且具有挑战性的编程任务也存在于此。
