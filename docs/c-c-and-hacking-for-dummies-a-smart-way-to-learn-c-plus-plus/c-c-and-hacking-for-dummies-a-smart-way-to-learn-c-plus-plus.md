## 引言

数据库充当一个容器。它是一个存储空间，程序员可以在其中以建设性的方式组织数据。请记住，如果你只处理少量数据，则无需创建数据库。例如，处理数百个 Excel 电子表格需要数据库，而五个电子表格即使没有数据库也可以处理。换句话说，在数据库中组织一定数量的数据将帮助你避免复杂的数据管理。

### 深入了解数据库

将数据全部组织在数据库中，可以让你轻松执行查询数据、更新数据和删除旧数据等任务。最重要的是，数据库可以防止因数据存在多个副本而引发的冲突。

例如，假设一家公司必须管理其整体财务支出。基本上，有一个专门的部门负责此事，该部门中有多人。现在，如果这些人各自持有电子表格的副本，那么考虑到人为错误的可能性，要得出无冲突的数据会有些困难。

而数据库则能够以更高的准确性和更少的冲突来存储和组织数据。

另一个帮助你理解数据库的示例是查看手机的通讯录。每个联系人是一条数据，而你的智能手机是数据库。只需轻按几个按钮，你就能轻松找到所需联系人。你也可以轻松编辑每个联系人的详细信息。这种先进的数据管理方式远胜于用纸笔电话簿列出手写联系人。

### 数据库的类型

数据库的不同类型如下：

- 关系型数据库
- 面向对象数据库
- 基于文档的数据库

在本电子书中，我主要关注关系型数据库。不过，如有必要，我也会毫不犹豫地介绍其他两种类型。

你可能已经听说过某种新型数据库，例如 NoSQL。它们被认为属于基于文档的数据库这一类别。这些数据库如今正变得越来越流行，你可能会认为学习它们比学习 SQL 更好。

请不要认为关系型数据库已是过时之物。我们今天仍然使用的许多数据库都采用关系模型。此外，SQL 在关系数据查询方面非常有用。而且，新流行的数据库的查询语言仍然与 SQL 有某种关联，因为它们大多是在 SQL 之后开发的。

换句话说，如果不理解 SQL 就直接跳入新型数据库领域，你会遇到许多挑战。因此，在转向 MongoDB 等其他数据库之前，先学习 SQL 是正确的决定。

话不多说，现在让我带你进入 SQL 的世界。

## 第 1 章 – 深入了解关系模型

结构化查询语言（Structured Query Language，简称 SQL）最初是为关系模型设计的。它是用于定义多个数据之间关系的语言。它也是用于在关系模式中查询数据的数据库编程语言。

那么这一切是从何时开始的呢？

第一个关系数据库创建于 60 年代，该模型的编程主要由数学定义。事实上，这种数据库模型基于元组关系演算和关系代数。

不过，不用担心，你不需要深入学习代数和演算来处理关系数据库。SQL 将使关系数据库编程变得更加容易。

### 表、列和行

在关系数据库中，数据存储在表中。在这种模型中，所有表都有名称。例如，你可以将一个表命名为“people”，同时将另一个表命名为“sales”。这些名称指的是存储在表中的数据类型。换句话说，我们称为“people”的表包含人员数据，而称为“sales”的表包含销售数据。

每个表都有一组列。这些列定义了表中不同的数据片段。这也是关系模型区别于其他类型数据库的地方。你会发现有些数据库将数据整体存储。然而，在关系模型中，所有数据都按列分隔，每列都有名称。每列还可以限制将添加到其中的数据的类别和大小。例如，某些列只能存储字符串，而某些列只能存储数字。分配给每列的限制取决于数据库的创建者。

列还分为必填列和非必填列。必填列意味着表中的每一行都必须具有与该列要求相对应的数据。另一方面，非必填列意味着我们可以在该列下为每行设置 NULL 值。随着你学习 SQL，你会发现 NULL 在数据库编程中有很多用途。

使用行的主要意义在于拥有可检索的数据和可以存储数据的容器。我们为什么要存储数据？仅仅是因为我们希望在将来再次获取这些数据，并且我们只是希望暂时有一个地方让它们存放。因此，这就是数据库的核心思想。

### 键

关系数据库的关键要素之一是键。我们现在知道表有多个列，每列都有名称。每列也具有相关属性。我们可以在列上设置的这些属性之一就是键。

在关系数据库中，我们总是为每一行分配一个主键。这种特殊类型的键用于唯一地确定特定行。这意味着该键的值必须保持唯一，并且在表内不得有任何重复。当且仅当我们的关系模型中有另一个表包含该键时，我们才可以将这两个表合并在一起。

合并两个表时，总是会有没有重复值的主键。合并后，你会注意到表中将出现一个包含这些键的新列。这些键现在称为外键。它们充当第二个表主键的链接，使你能够方便地将两个分离表中的行关联起来。

除了主键和外键，我们还有自然键。自然键是全局性的。这意味着你不能更改它们，因为它们在全世界范围内用于标识单个实体。例如，已出版的书籍总是有自然键，我们称之为 ISBN。每本已出版的书籍都有其唯一的 ISBN，在处理书籍的关系数据库时，你需要将其用作主键。这与处理具有非自然键的数据库（如电子邮件、人员）不同，你需要为每一行自行创建主键。

让我们以人员及其联系方式的数据库为例。我们不能将姓名视为主键。我们也不能将人员的电话号码视为主键。这是因为全球可能有两个或更多人具有相同的联系电话、名字甚至姓氏。因此，我们应该自己创建主键。这就是标识列发挥作用的地方。

标识列充当自动递增的列，随着我们在表中添加数据，它会持续生成唯一的键。键的组合方式并不重要，因为我们所需的只是为数据库中的每个标识提供一个唯一键。

## 第 3 章 – SQL 语句

SQL 是一种特定的数据库语言。我们使用这种语言来创建语句。这些语句由有效单词组成。其中一些单词应由 SQL 定义，而另一些单词应由你定义。你将在这些语句中声明的一些单词是表名、列名，以及表中的变量或数据。

### SQL 事实

在我们继续之前，我想向你展示一些关于 SQL 的重要事实。

关于 SQL，你需要知道的第一件事是它可读，因为它是用英语编写的。换句话说，学习 SQL 比学习任何其他编程语言都更容易。

第二，使用 SQL 可以做更多事情。这与大多数人的印象相反，他们认为 SQL 只用于数据查询。这是错误的。

第三，有效的 SQL 语句应以分号（;）结尾。尽管有些人会告诉你它不再需要，但我建议你在查询中加上它，因为它是 ANSI 标准的一部分。此外，它在旧数据库和现代数据库中都能正常工作。分号让你可以方便地将多条语句一起声明为我们所说的一个批处理。这种方法即使在现代数据库中也有效。

第四，SQL 不区分大小写。你可以将变量写成小写和大写。两种方式在结构化查询语言中都能正常工作。练习这一点的一个好方法是：将 SQL 特定关键字写成大写，将用户定义的关键字写成小写。这将让你能够高效快速地识别语句中的不同关键字。

### SQL 命令

重要的是要记住，所有 SQL 语句都以命令开头。命令通常是一个动词，用来表示数据库需要做什么。SQL 语句中使用的命令的一个好例子是 SELECT。

SELECT 命令告诉数据库选择一组数据。如你所见，它是一个基于英语的单词，系统会做什么也相当明显。该命令在 SQL 语句中使用时如下所示。

```sql
SELECT VALUES
FROM TABLENAME;
```

上面的示例是一个 SQL 语句的通用示例，我稍后会逐部分讨论它。

请注意，你在语句中需要声明的值或变量集合取决于你试图执行什么命令。所有这些变量都紧跟在命令之后出现在语句中。

### 在 SQL 中创建数据

我无意教你如何从零开始创建数据库。作为初学者，你的任务应该只围绕向已有数据库添加或更新值。不过，我感觉你们中有些人仍然渴望学习 SQL，以便创建包括数据库本身在内的整个应用程序。因此，我会介绍 SQL 的那部分内容，但只介绍足够帮助你起步的内容。

用于创建新数据库的 SQL 关键字是 CREATE DATABASE 语句，这属于 ANSI 规范。假设你想为人们的联系电话创建一个新数据库，并想将这个新数据库命名为 Contacts。你可以按以下方式操作。

```sql
CREATE DATABASE Contacts;
```

为了在该数据库上工作，你需要先使用它。我们这里需要的关键字是 USE DATABASE 命令。我们将按以下方式执行它。

```sql
USE DATABASE Contacts;
```

如果你想在 Contacts 数据库中创建表，那么你需要执行 CREATE TABLE 命令，方法如下。

```sql
CREATE TABLE Contacts.User (...);
```

之后，你就可以放入所有列名、类型和定义。

## 第 4 章 – 在 MySQL 中编码

我将教你如何使用 MySQL 编写 SQL 数据库代码。为什么选择 MySQL？首先，因为它是一个开源平台，你可以免费获取。其次，因为它兼容所有主流操作系统：Linux、OSX 和 Windows。第三，因为它具有 ANSI 模式，可以对你的数据库强制执行 ANSI 规范。并非所有 RDBMS 都有这种功能。

在本章中，我将教你如何高效使用 SELECT 命令。这将让你能够有效地使用该命令来创建有趣且高效的数据查询。





### SELECT 命令剖析

到目前为止，你应该已经知道 SQL 关键字 SELECT 是一条用于从数据库中获取特定数据的命令。在 SELECT 关键字之后，应当跟随我们希望从数据库中获取的项目列表。我们称之为“选择列表”。如果选择列表只包含变量，那么你可以简单地按以下方式编写语句：

```sql
SELECT '[Variable]', '[Variable]';
```

大多数情况下，选择列表包含列名。此时，定义我们可以在哪个表中找到这些列就很重要了。这正是 FROM 命令发挥作用的地方。

例如，我们的选择列表包含 User（列 A）和 Email（列 B），并且我们可以在名为 Contact 的表中找到这些列。为了定义要查找哪个表，我们应该加入 FROM 命令，如下所示。

```sql
Format:
SELECT      [COLUMN_NAME],      [COLUMN_NAME]      FROM
[TABLE_NAME];

Example:
SELECT User, Email FROM Contact;
```

但你会问：如果表中有很多列，而我想全部选中，该怎么办？这就是星号（*）的威力所在。在 SQL 语句中，它被称为通配符。要选择表内的所有列，你需要按以下格式执行语句。

```sql
SELECT * FROM [TABLE_NAME];
```

如你所见，通配符位于 SELECT 命令之后。这在需要选择所有列时非常有用。如果你不需要选择所有列，那么使用通配符可能会变得危险且低效。

根据你所使用的平台，在 SQL 语句中快速指定多个列有不同的方法。我个人建议你避免使用通配符命令，因为这种语法使用不当也可能会破坏应用程序。

#### FROM 命令

编写选择单张表的 SQL 语句相当容易。正如你在前面的示例中所看到的，它只遵循一个简单的格式。

```sql
FROM [TABLE_NAME]
```

在 FROM 子句中，你可以通过为表名创建别名来缩短表名。假设你的表名是“telecommunication”，并且你正在查找表“owner”列下的所有者姓名列表。使用通用格式输入会得到如下结果。

```sql
SELECT telecommunication.owner FROM telecommunication;
```

为什么在上面的格式中，我们需要在列名之前输入表名？这是因为我们必须使用表名来限定列。此外，这也能避免将来出现名称相同的列时发生名称冲突。我建议你养成这个习惯。

回到主题，这样做太不方便了。我们可以通过在 FROM 子句中指定别名来缩短表名。格式如下。

```sql
SELECT      [TABLE_NAME_ALIAS].[COLUMN_NAME]      FROM
[TABLE_NAME] [TABLE_NAME_ALIAS];
```

使用 owner 列和 telecommunication 表，我们的新语句将如下所示。

```sql
SELECT t.owner FROM telecommunication t;
```

如你所见，我将字母“t”指定为表名的别名。这比一遍又一遍地重复完整名称要容易写得多。请记住，不一定非得使用表名的第一个字符作为别名。你可以为表名指定任何别名，也可以是字符组合。只要确保你使用的别名保持一致即可。

#### 限制结果

每当你执行 SELECT 查询时，数据库都会返回你指定列下的所有行。这意味着，如果你的表有 20,000 行，那么它就会返回 20,000 个值来响应你的语句。

有两种方法可以解决这个问题。一种是在 FROM 子句之后添加额外的子句。另一种是在选择列表之前添加 DISTINCT 限定符。其格式如下所示。

```sql
SELECT DISTINCT [SELECT LIST] FROM [TABLE_NAME];
```

这种格式只会返回不同的值，而不是提供指定列下的所有值。这是获取该列所有唯一值的完美方式。例如，你有一张联系人表，有些实体因为拥有多个电话号码而出现在多行中。

依赖通用格式会给你带来重复结果。如果你只想知道你的联系人是谁，这样效率并不高，对吧？使用 DISTINCT 限定符可以防止你收到同一实体的多行记录。

## 结论

到目前为止，你已经熟悉了关系数据库的工作方式，以及 SQL 在查询使用关系模型的数据库时的高效性。

注意如何为列设置限制，以及如何通过 SELECT 语句具体调用它们，这一点很重要。你还学到了 SQL 语句既包含 SQL 定义的关键字，也包含用户定义的关键字。这些关键字不区分大小写，但强烈建议以对视觉友好的方式组织并编写语句。这样做不仅让你在查看 SQL 代码时更方便，也能方便其他人。如果你与团队一起工作，这是一个最佳实践。

你还可以使用 FROM 等子句来指定 SELECT 语句的数据提取范围。使用 FROM 子句可以在你的 SQL 语句查找列时指定要查看哪张表。除此之外，FROM 子句还允许你为表名指定别名。

你还学习了如何通过使用 DISTINCT 限定符和 WHERE 子句来限制返回值的数量。请记住，你必须避免使用通配符，因为它是从数据库提取数据的低效方式。另一方面，WHERE 子句是一个强大的命令，作为初学者你需要掌握它。熟悉各种运算符，并在已建好的数据库上尝试它们。

## 引言

C++ 程序本质上是一个文本文件，其中包含一段使用特定 C++ 文本编写的命令序列。我们可以将这种文本文件称为*源文件*，它通常以 .CPP 扩展名结尾（就像音频文件以 .MP3 结尾或 PDF 文档以 .PDF 结尾一样）。

编写 C++ 程序的目的是将一系列特定的 C++ 命令组合在一起，由计算机将其转换为*机器语言*，从而执行我们想要完成的任何任务。这个转换过程称为*编译*，由编译器执行。此外，我们编写的代码还必须包含初始化和清理指令，这个过程称为*链接*。编译和链接的过程合在一起称为*构建*，它将我们的代码构建成计算机可以识别并作为程序运行的机器可执行 .EXE 文件。

要在 C++ 中编写程序，你只需要两样东西——一个用于编写代码并构建 .CPP 文件的编辑器，以及一个将代码（源文件）转换为机器可执行文件的编译器，该文件将执行我们为其编程的任务（例如打开文件、播放视频、在屏幕上打印文本等）。

## 第 1 章 – 编写你的第一个 C++ 程序

在我们编写第一个 C++ 程序之前，你需要下载名为 Microsoft Visual Studio 的软件，它允许你编写、编译和执行用 C++ 代码语言编写的命令和程序。它也是一个出色的程序，可用于调试和编辑你的程序——如果你需要更改或出现问题。

![](img/daba5f3166d292521ef5009ae8ef9c37_50_0.png)

作为你的第一个程序，我们将探索基本的“Hello World”程序，对于每个想学习如何编写和编码 C++ 的人来说，这是必修内容。Hello World 程序将展示几乎每个用 C++ 编写的程序都会共享的绝对最基本要素。无论程序多么简单或多么复杂，它仍然需要下面几行非常基础的代码。

你需要做的第一步是打开 Microsoft Visual Studio 并创建一个新项目。我们将这个项目称为“Hello World”，如果你愿意，也可以称为“First Program”。如果你现在还不理解下面几行文本，不必担心，我们稍后会仔细查看，并在后续章节中深入探讨。

倒数第二行代码应该是：

```cpp
return 0;
```

这里我们告诉编译器，如果程序顺利运行且没有任何问题，就“返回”命令提示符（稍后我们会更深入地讨论）。

最后，最后一行代码应写为：

```cpp
} //end main
```

`}` 基本上就是右花括号。如上所述，所有命令都应以作用域括号结束，它告诉编译器该命令已完成（针对该行或整个程序）。最后一部分 `//end main` 是一个我们称为“注释”的功能。我们用它来跟踪程序中正在使用和编写的内容。在编写很长的程序时，这最后一条语句基本上就是我们开始时的函数 `int main()` 的右括号，它会把整个程序保持为一个整体。

现在，我们的程序应该如下所示：

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello World" << endl;

    return 0;
} //end main
```

现在，当我们保存程序并运行它时，它将显示“Hello World”这几个字。再试一次，只是这次我希望你写点别的内容，看看会发生什么。

## 第 2 章 – 扩展你的程序：变量

C++ 代码中最重要的部分是*变量*。你可以把它们看作小存储盒，我们可以在其中存储供程序以后使用的内容——尤其是数字。这些变量的术语和用法来自数学。你应该熟悉类似这样的内容：

```cpp
x = 1
```

这意味着 x 等于数字 1。该语句还表示，无论字母 x 出现在哪里，它的值都是数字 1。本质上，字母 x 会*持有或存储*数字 1，直到需要在语句或算法中使用它。变量在 C++ 中的工作方式完全相同，只不过我们总会在末尾包含一个作用域括号，以暗示并告诉程序这是函数的结束。例如：

```cpp
x = 1;
```

从此以后，无论我们在程序中哪里使用字母 x，它都会被识别为数字 1。但是，我们如何声明变量呢？一般来说，我们不会在直接写出数字容易得多的时候还只使用一个变量。让我们看一个代数示例，你可能会在更高层次的数学中见到：

(x + 2) = y / 2<br>
x + 4 = y<br>
求解 x 和 y

如果你擅长代数，你可能已经解出了这个问题。然而，仅将这些信息输入 C++ 并不足以让程序理解这一切意味着什么。它只会把它读成乱码，对计算机来说完全无法理解。这就是为什么我们必须在使用变量之前向程序*声明*变量，以便计算机确切知道我们想做什么。因此，我们会这样声明变量：

```cpp
int x;
x = 10;

int y;
y = 5;
```

正如我们在上一章所见，语句“int”基本上表示“整数”。这里，我们是在说 x 等于 10，y 等于 5。如果我们随后再次编写代码，程序就能解决这个问题。我们可以在程序中的任何位置使用这些变量，但必须始终先向系统声明它们的含义，然后才能使用它们。而且，我们可以在变量中存储的不仅仅是数字。我们还可以使用以下内容：

```cpp
x = 1
x = 2.3
x = "this is a sentence"
```

为了进一步说明变量如何工作，请看以下示例。我让你记住数字 5 和数字 2。你刚刚在脑海中存储了两个值。然后我让你把数字 1 加到我说的第一个数字上。现在，在你的记忆中，你应该有数字 6（5+1）和数字 2。然后我让你用第二个数字减去第一个数字，于是我们得到答案 4。

这基本上解释了 C++ 如何存储变量，然后使用它们来解决问题或语句。实际用代码编写时，它看起来会像这样：

```cpp
int main ()
{
    // declaring variables:
    int a, b;
    int result;

    // process:
    a = 5;
    b = 2;
    a = a + 1;
    result = a - b;

    // print out the result:
    cout << result;

    // terminate the program:
    return 0;
}
```

当我们运行程序时，我们会看到它将为我们显示答案。非常简单，你应该能够利用我们到目前为止在“Hello World”程序及所用变量中讨论的内容，解释其中每一部分的含义。然而，这里有一些新东西，那就是使用“//”后跟一些文本。第一个“// operating with variables”只是我们程序的标题，而后面每个 // 都只是小标题，说明我们在程序的该位置正在做什么。这会容易得多，尤其是在处理大量代码时，你可以回溯这些行并找到你要找的内容，而不必试图逐行解读。

对于我们刚才使用的示例，还有一种更简单的代码编写方式。第二种方法称为变量的*“初始化”*，我们有三种方式可以做到。要*初始化*一个变量，基本上意味着我们可以在声明变量的同时声明其值。我们可以通过编写以下任意一种形式来实现这三种方式：

```cpp
int x = 0;
```

```cpp
int x (0);
```

```cpp
int x {0};
```

使用哪种方法并不重要，因为它们的作用都相同。然而，最好的一点是，如果你愿意，可以同时使用这三种类型。例如：

```cpp
// initialization of variables

#include <iostream>
using namespace std;

int main ()
{
    int a=5;
    int b(3);
    int c{2};
    int result;

    a = a + b;
    result = a - c;
    cout << result;

    return 0;
}
```

如你所见，程序将完成与之前编写的程序完全相同的事情，只不过现在我们在声明变量本身的同时也声明了变量的值。

## 第 3 章 – 运算符

现在我们已经熟悉了变量的使用，可以扩展我们的程序，并开始使用所谓的“运算符”。运算符基本上是一些符号，它们告诉编译器（Microsoft Visual Studio）使用数学或逻辑来解决我们用代码编写的问题。C++ 最常用的运算符有 6 种。它们是：

- 1. 算术运算符。
- 2. 关系运算符。
- 3. 逻辑运算符。
- 4. 位运算符。
- 5. 赋值运算符。
- 6. 杂项运算符。

我们将只介绍主要且最重要的运算符类型，并定义每个最常用符号的含义及其作用。

### 算术运算符



要查看条件并让程序做出选择，我们将使用如下语法：

```text
if (and then we include our condition here)
{
    insert our program here for the program to work out
}
```

这基本上是在说：“如果发生这种情况，那么就执行这个”。你应该熟悉 IF、THEN、AND、OR 这些基本术语，它们属于基础数学和问题求解技能。不过，条件是我们放在括号里的，程序可以据此选择是否执行该条件。例如，如果我们有三个变量 x、y 和 z，首先需要向程序声明它们的值。不过，为了开始在表达式中引入一些运算符，假设变量“x”大于变量“y”。

我们的代码会像这样：

```cpp
int x,y,z;

cin>>x;

cin>>y;

if(x>y)
{
    z = x+y;
    cout<<z;
}
```

一旦我们声明了变量 x 和 y 的值，程序就会判断“x”是否确实大于“y”。如果程序发现这一点为真，那么未初始化的变量“z”将被赋值为 x 与 y 的和，然后给我们答案。然而，如果程序发现 x 不大于变量 y，则什么也不会发生。

在这里，我们让程序能够选择在不同场景下可以做什么。在这个例子中，我们现在必须告诉程序：如果 x 不大于变量 y，应该做什么。

看看下面的代码：

```cpp
int x,y,z;

cin>>x;
cin>>y;

if(x>y)
{
    z = x+y;
    cout<<z;
}
else if (x<y)
{
    z=x-y;
    cout<<z;
}
```

现在我们已经告诉程序：如果 x 不大于 y，就转到下一个选项，该选项告诉我们要给出 x 减 y 的结果作为答案。你可以按需添加任意多个这样的条件，这将使你能够创建一个用途非常广泛、可应用于多种方式的程序。但是，沿用我们的例子，如果变量 x 既不大于也不小于变量 y，会怎样？什么也不会发生。我们仍然希望程序做*某些事情*，因此可以加入：

```cpp
//Full Working Program
#include <iostream>
using namespace std;

int main()
{
    int x,y,z;

    cin>>x;
    cin>>y;

    if(x>y)
    {
        z=x+y;
        cout<<z;
    }
    else if (x<y)
    {
        z=x-y;
        cout<<z;
    }
    else
    {
        cout<<"x is not greater or less than y so they must be equal"<<endl;
    }
    return 0;
}
```

现在我们创建了一个程序：如果 x 既不大于也不小于变量 y，那么“if”和“else if”条件将不会被执行。由于前两个条件无法满足，程序现在可以选择执行第三个条件“else”。我们还可以在这些条件串中使用许多不同类型的运算符。请参阅前面关于运算符的章节。

## 第 5 章 – 循环

我们已经了解了基础编程、变量、运算符和条件。现在我们必须看看循环。循环是编程中非常重要的一部分，因为它们使我们的程序能够按照你指定的次数反复运行相同的代码行。你可能认为一遍又一遍地做同样的任务毫无意义且没有用处，但随着我们学习接下来的内容，循环背后的意义会变得非常清楚。

让我们看看下面这段程序中的代码行。

```cpp
#include <iostream>

using namespace std;

int main()
{
    cout<<"1"<<endl;
    cout<<"2"<<endl;
    cout<<"3"<<endl;
    cout<<"4"<<endl;
    cout<<"5"<<endl;
    cout<<"6"<<endl;
    cout<<"7"<<endl;
    cout<<"8"<<endl;
    cout<<"9"<<endl;
    cout<<"10"<<endl;

    return 0;
}
```

你大概可以看出，根据我们目前所学，这个简单的程序会向我们显示从 1 到 10 的数字。你大概能猜到，如果你不得不在程序中加入许多这样的代码行，这项任务会变得非常无聊和单调。你能想象如果必须设计一个显示从 1 到 1000 的数字的程序吗？不过幸运的是，有一个解决方案可以让我们的工作轻松得多。我们可以创建一种语法，把上面的例子变成一行简单的代码。这种语法就是循环，看起来像这样：

```cpp
for (initialization; condition; increment/decrement)
```

这基本上是在说：“对于下面的内容，执行这个”。初始化是程序的起点（你现在应该已经知道），条件是我们交给程序去执行的选择，最后，递增和递减表示随着程序和循环继续运行，我们希望从起始数字中增加或减去多少。

下面是与上面相同的例子，只不过这次我们加入了一个循环。

```cpp
#include <iostream>

using namespace std;

int main()
{
    int x;

    for (x=0; x<=10; x++)
    {
        cout<<x;
    }

    return 0;
}
```

这个程序执行后打印数字的效果与上面的例子完全相同，只不过在这个程序中，我们不需要为程序指定 1 到 10 之间的每一个数字来显示。

这组新代码之所以更有效，是因为我们可以看到我们使用了“for (x=0; x<=10; x++)”，这就是上面看过的（初始化；条件；递增/递减）语句。在这里，我们声明程序开始时 x 等于 0，并且当 x 小于或等于 10 时程序将结束。“x++”的递增/递减意味着 x 的值会在每次循环结束时增加 1。

进一步解释一下，循环运行的条件是程序会问自己：x 是否等于 10 或小于 10？如果是，就给 x 加 1。然后程序会问自己：如果 x 现在为 1，它等于或小于 10 吗？是的，所以我再加 1。最终程序会对自己说：“x 等于 10，它等于或小于 10 吗？是的。我不会再循环，现在结束程序”。这基本上就是循环的工作方式。程序会有一定数量的条件被持续检查，如果这些条件通过或满足，就会再进行一次循环或重复该序列。

我们刚才看到的是“for”循环。我们还将了解另外两种循环。我们要看的第一个新循环称为“while”循环。while 循环将使你的程序在某些情况下更加灵活，基本语法大致如下：

```cpp
while (condition)
{
    statement section;
}
```

这是因为 while 循环只关注为它设置的条件，以及循环之间数字的递增。我们也可以通过编写以下内容来简化 while 循环：

```cpp
while (x<=10)
{
    cout<<x++<<endl;
}
```

这表示当 x 小于或等于 10 时，它会给 x 加 1。这里唯一的区别是 x 已在程序开始时声明。

我们要看的第三种循环称为“do while”循环。它会执行相同的任务，但条件放在循环末尾，因此直到循环第一次运行之后，才会检查它是否应该执行。例如：

```cpp
//Full Working Program
#include <iostream>
using namespace std;

int main()
{
    int x=0;
    do
    {
        cout<<x<<endl;
        x++;
    } while(x<=10);

    return 0;
}
```

这表示当 x 小于或等于 10 时，会给 x 加 1。你注意到 while 循环末尾的分号了吗？这意味着我们将这一行作为一个语句结束，供程序执行。





## 第 6 章 – 数组

数组与变量非常相似，因为它们允许我们存储信息以备后用。数组允许我们在单个名称下存储一组数据，这意味着我们可以在组织数据方面拥有更高程度的控制力，这在处理具有数千行代码的大型程序时尤其有用。

为了举例说明一组数据如何存储在数组中，想象一下你想设计一个程序来显示5个人的年龄。你需要声明变量的名称和变量的值，看起来会像这样：

```cpp
int age1=15;
int age2=24;
int age3=54;
int age4=33;
int age5=120;
```

我们现在面临着与前一章相同的问题，当时我们想打印从1到10的数字。想象一下，如果你必须设计一个程序来显示500人的年龄列表呢？幸运的是，正如我们在前一章中所看到的，有一种方法可以显示这些信息，而不必手动输入每一行代码。

数组的语法如下所示：

```cpp
datatype name [index];
```

这意味着我们想要列出一系列存储的值，就像变量一样。为了创建一个存储类似内容的数组，在本例中即5个人的年龄，我们可以这样写：

```cpp
int ages [5];
```

这意味着我们有一个包含5个元素的列表，程序此时只知道它叫做“ages”。就像为字母“x”声明一个值一样，我们也必须为这个名为“ages”的新变量声明值。我们可以通过以下方式做到这一点：

```cpp
int ages [5];
```

```cpp
ages[0]=15;
ages[1]=24;
ages[2]=54;
ages[3]=33;
ages[4]=120;
```

虽然我提到过有一个更简单的方法来编写这个索引，但上面的写法看起来完全一样。原因在于我想向你们展示我们如何声明这个新的ages数据类型。当我们启动程序时，我们已告诉它，在开始时有一个包含[5]个元素的数组。我们的声明列表从0开始的原因，是因为计算机就是这样读取数字列表的。0始终表示第一个。

然而，如果我们想用更简单的方式编写上面的内容，可以这样写：

```cpp
int ages [5];
```

```cpp
ages = {15,24,54,33,120};
```

这告诉程序的信息与上面相同，即0等于15，1等于24，依此类推。如果我们将其完整地写成代码，会是什么样子呢？

```cpp
#include <iostream>
using namespace std;

int main()
{
    int ages [5];
    ages={15,24,54,33,120};
    cout<<ages<<endl;


return 0;
}
```

你能看出上面代码中的错误吗？大多数人会认为我们可以像之前的示例那样编写这个程序，即定义一组变量，然后让程序在执行时列出这些变量。然而，在处理数组时情况并非如此。这段代码的问题在于，我们在定义数组后，以“cout<<ages<<endl;”结束了程序。问题在于C++不能直接打印整个数组，因为必须告诉编译器（Microsoft Visual Studio）要显示哪个数组。例如，如果我们想显示年龄120，就需要让它显示ages[4]。然后我们需要像下面这样列出每个变量：

```cpp
int main()
{
    int ages [5];
    ages={15,24,54,33,120};
    cout<<ages[0]<<endl;
    cout<<ages[1]<<endl;
    cout<<ages[2]<<endl;
    cout<<ages[3]<<endl;
    cout<<ages[4]<<endl;


return 0;
}
```

但你不是说有办法将一整套整数存储到数组中吗？确实有，我们这样做的方式是声明一个变量，比如“k”，并告诉程序它存储的是要使用的整数。

例如：

```cpp
//Full working program
#include <iostream>

using namespace std;

int main ()
{
    int k;
    int ages [5];
    ages = {15,24,54,33,120};

        for (k=0; k<5; k++)
        {
                cout<<ages[k]<<endl;
        }

return 0;
}
```

注意我们是如何定义“k”为一个变量，并声明它包含上面的整个数组的？基本上，“k”被声明为0，只要“k”保持小于5，它就会执行数组（如果你注意到这里使用的运算符不同，在这种情况下是不等于）。程序基本上是在说，它会显示这些年龄，直到“ages”数据类型达到5，此时程序将停止显示年龄。

```cpp
*p=25.3;
```

现在这表示，通过将p设为指针，并将p指向x，x等于25.3。由于p持有x，x现在的值为25.3（无论p的值是什么）。如果我们想编写一个完整的程序，使用指针并为其赋值，我们可以这样写：

```cpp
//Full working program
#include <iostream>
#include <stdlib.h>

using namespace std;

int main()
{
double x;
double *p;
p=&x;
*p=25.3;
    cout<<x<<endl;

system("pause");
return 0;
}
```

这个程序将p指向x，并告诉程序x的值为25.3。然而，这看起来似乎指针并不是很有用。我们完全可以只使用变量并定义它们（也许再使用一些条件循环）来让程序工作。不过，它们的有用之处在于，只需将一个变量指向另一个变量，就能操纵信息和代码。这就是它们真正变得有用的地方。

比如说，你已经编写了几千行代码。现在，想象一下，如果你突然需要更改代码中50个变量的值呢？要在代码行中找到所有这些值会花费很长时间，甚至可能意味着你必须重写整个代码。如果你在这个过程中意外更改了不应更改的内容，程序可能会被破坏。

幸运的是，这正是指针真正发挥重要有用功能的地方。我们可以使用指针来更改程序中已经存在的变量的值，也可以在编写程序开始时指向并声明这些变量。指针允许我们操纵函数，而普通变量则无法做到这一点。

这就是入门阶段你需要了解的关于指针的全部内容。

一切事物，甚至代码行，都需要存储空间来保存和执行。例如，当你将一首歌或一张照片从电脑复制到手机，或者反过来复制时，会有一个程序在文件移动之前询问手机或电脑是否有足够的空间。这是因为如果没有足够的存储空间来保存新文件，那么尝试移动它是毫无意义的。程序会在操作执行之前确定是否有足够的存储空间来执行该操作。

然而，在某些情况下，程序要等到执行时才会知道需要多少内存或存储空间，而且这个内存量可能会不断变化。这就是为什么在编写任何C++程序时，你需要告诉它分配一定数量的内存或存储空间来满足需求（而这个数量有时可能是未知的）。这里我们将重点讨论第二种内存类型，因为在任务执行之前确定存储的内存需求是很容易的。

每次程序执行时，分配的内存需求可以称为“new”运算符。但是，一旦不再需要该内存分配，我们就称之为“delete”运算符。其语法如下所示：

```cpp
new datatype;
```

这基本上意味着我们正在定义一个新的运算符，后面跟随着我们之后定义的任何内容。举个例子，我们可以编写一些代码，在程序执行时立即使用指针分配内存：

```cpp
double* pvalue = NULL;
pvalue = new double;
```

然而，这些代码行不会告诉我们内存是否已成功分配——它只是一个分配命令。在这种情况下，为了让程序告诉我们内存已成功分配，我们可以这样写：

```cpp
double* pvalue = NULL;
if( !(pvalue = new double ))
{
    cout << "Error: out of memory." <<endl;
    exit(1);
```




本书到目前为止学到的其他内容。但让我们进一步看看还有哪些其他方式可以为程序分配内存。例如，假设我们想编写一个程序，向我们显示一行 100 个字符。基于上面的示例，代码将如下所示：

```cpp
char* pvalue = NULL;
pvalue = new char[100];
```

这表示我们声明指针为 NULL，并且已经执行了一个新的内存请求，以便为我们的 100 个字符分配内存。一旦我们不再需要分配这块内存，就插入一个 delete 运算符：

```cpp
delete [] pvalue;
```

现在我们已经告诉程序删除前面几行代码中指针所指向的数组。但是，如果我们想同时为多个数组分配内存呢？我们不需要为每一个都启动一个新的运算符。相反，我们可以这样写：

```cpp
double ** pvalue = NULL;
pvalue = new double [4] [5];
```

这里，我们首先声明指针的值为 NULL，然后告诉程序我们要为一个维度为 4x5 的数组分配内存。删除操作与之前相同：

```cpp
delete [] pvalue;
```

## 第 9 章 – 类与对象

现在我们已经学习了 C++ 编程的基础知识，是时候看看稍微高级一些的内容了。类是所谓“面向对象”编程的一部分。这让我们可以通过使用对象来把程序应用于日常生活。对象可以定义为我们在日常生活中使用的任何东西——例如汽车、电脑、手机等等。到现在我们应该已经了解到，一个程序是由其中许多很小的程序组成的，就像汽车由许多很小的部件组成，这些部件协同工作以便汽车运行。其中一些组件可以改变，比如打开和关闭汽车里的灯，而另一些则不能改变，比如汽车的中心计算机。这些可以通过我们所说的“私有”和“公共”变量来区分，换句话说，就是哪些允许你更改，哪些不允许（但我们稍后会讨论这一点）。

在学习 C++ 时，类存在于稍微更高级的层面上，因为它们涉及的内容更多。然而，学习它们会带来很大的回报，因为它将使我们能够创建和开发可应用于日常生活的程序。它们还允许我们重用代码并将其应用于不同的场景。例如，一支足球队中的每名球员都会有姓名、年龄和收入，但每个球员的这些信息都会不同。在这种情况下，代码将创建类的属性，也就是每名球员的姓名、年龄和收入。

将这个作为示例写出来，我们用于球员信息的代码将如下所示：

```cpp
class Player
{
    string name;
    string age;
    double income;
};
```

我们的 Player 类现在有了结构。从现在开始，每当我们为单个球员的各个变量声明值时，我们都会创建一条新记录，或者说创建一个存在于 Player 类中的新对象。每个对象都将包含姓名、年龄和收入。为了声明每个 Player 类型的变量，我们使用与声明任何其他变量相同的方法：

```cpp
Player player1;
Player player2;
Player player3;
```

一旦我们像第一个示例那样创建了一个类，我们就可以像使用之前用过的任何其他数据类型示例一样使用它。然而，我们还希望能够限制程序在这些类结构中可以访问和操作的内容。有些对象或类必须始终保持不变（私有类），而有些则可以更改（公共）。例如，只包含姓名、年龄和收入的类必须保持私有，因为这是常量。另一方面，我们为每个个体声明的变量是公共的，因为该信息不是常量。

要在代码中看到这一点，我们会这样写：

```cpp
class Player
{
private:
    string name;
    string age;
    double income;

public:
    Player();
};
```

执行上面的代码行将禁止程序更改姓名、年龄和收入的私有类，但会允许它更改单个球员信息的公共类。我们在声明 private 和 public 后使用“:”，因为它们告诉程序，其后的所有内容都被视为该类别类型。

当我们看到构造函数在代码中的作用时，理解起来会简单得多。基本上，它们会根据我们给它的内容创建一个类或一条信息条目。它们在一定程度上为我们完成了工作。然而，我们还需要看看析构函数以及它们在程序中的作用。

析构函数与构造函数相反，因为它们会删除而不是创建数据。执行析构函数所用的语法是 ~ 后跟类的名称。例如：

```cpp
~Player();
```

以上就是 C++ 编程中类和对象的基础知识。当然，还有很多内容可以研究，但那超出了初学者水平的范围。
