Luckily, this is where pointers actually have a useful and important function. We can use pointers to change the value of variables which already exist in the program, or we can point and declare the variables at the start of writing the program. Pointers allow us to manipulate a function, whereas this is impossible with a normal variable.

This is all that you need to know about pointers at a beginner level.
