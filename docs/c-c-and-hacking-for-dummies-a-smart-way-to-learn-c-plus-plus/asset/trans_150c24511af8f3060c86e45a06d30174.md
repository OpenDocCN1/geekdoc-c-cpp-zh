
## 第 1 章 – 编写你的第一个 C++ 程序

在我们编写第一个 C++ 程序之前，你需要下载名为 Microsoft Visual Studio 的软件，它允许你编写、编译和执行用 C++ 代码语言编写的命令和程序。它也是一个出色的程序，可用于调试和编辑你的程序——如果你需要更改或出现问题。

![](img/daba5f3166d292521ef5009ae8ef9c37_50_0.png)

作为你的第一个程序，我们将探索基本的“Hello World”程序，对于每个想学习如何编写和编码 C++ 的人来说，这是必修内容。Hello World 程序将展示几乎每个用 C++ 编写的程序都会共享的绝对最基本要素。无论程序多么简单或多么复杂，它仍然需要下面几行非常基础的代码。

你需要做的第一步是打开 Microsoft Visual Studio 并创建一个新项目。我们将这个项目称为“Hello World”，如果你愿意，也可以称为“First Program”。如果你现在还不理解下面几行文本，不必担心，我们稍后会仔细查看，并在后续章节中深入探讨。

倒数第二行代码应该是：

```cpp
return 0;
```

这里我们告诉编译器，如果程序顺利运行且没有任何问题，就“返回”命令提示符（稍后我们会更深入地讨论）。

最后，最后一行代码应写为：

```cpp
} //end main
```

`}` 基本上就是右花括号。如上所述，所有命令都应以作用域括号结束，它告诉编译器该命令已完成（针对该行或整个程序）。最后一部分 `//end main` 是一个我们称为“注释”的功能。我们用它来跟踪程序中正在使用和编写的内容。在编写很长的程序时，这最后一条语句基本上就是我们开始时的函数 `int main()` 的右括号，它会把整个程序保持为一个整体。

现在，我们的程序应该如下所示：

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello World" << endl;

    return 0;
} //end main
```

现在，当我们保存程序并运行它时，它将显示“Hello World”这几个字。再试一次，只是这次我希望你写点别的内容，看看会发生什么。

在下一章中，我们将开始了解程序的一些主要特性和功能。

## 第 2 章 – 扩展你的程序：变量

C++ 代码中最重要的部分是*变量*。你可以把它们看作小存储盒，我们可以在其中存储供程序以后使用的内容——尤其是数字。这些变量的术语和用法来自数学。你应该熟悉类似这样的内容：

```cpp
x = 1
```

这意味着 x 等于数字 1。该语句还表示，无论字母 x 出现在哪里，它的值都是数字 1。本质上，字母 x 会*持有或存储*数字 1，直到需要在语句或算法中使用它。变量在 C++ 中的工作方式完全相同，只不过我们总会在末尾包含一个作用域括号，以暗示并告诉程序这是函数的结束。例如：

```cpp
x = 1;
```

从此以后，无论我们在程序中哪里使用字母 x，它都会被识别为数字 1。但是，我们如何声明变量呢？一般来说，我们不会在直接写出数字容易得多的时候还只使用一个变量。让我们看一个代数示例，你可能会在更高层次的数学中见到：

(x + 2) = y / 2<br>
x + 4 = y<br>
求解 x 和 y

如果你擅长代数，你可能已经解出了这个问题。然而，仅将这些信息输入 C++ 并不足以让程序理解这一切意味着什么。它只会把它读成乱码，对计算机来说完全无法理解。这就是为什么我们必须在使用变量之前向程序*声明*变量，以便计算机确切知道我们想做什么。因此，我们会这样声明变量：

```cpp
int x;
x = 10;

int y;
y = 5;
```

正如我们在上一章所见，语句“int”基本上表示“整数”。这里，我们是在说 x 等于 10，y 等于 5。如果我们随后再次编写代码，程序就能解决这个问题。我们可以在程序中的任何位置使用这些变量，但必须始终先向系统声明它们的含义，然后才能使用它们。而且，我们可以在变量中存储的不仅仅是数字。我们还可以使用以下内容：

```cpp
x = 1
x = 2.3
x = "this is a sentence"
```

为了进一步说明变量如何工作，请看以下示例。我让你记住数字 5 和数字 2。你刚刚在脑海中存储了两个值。然后我让你把数字 1 加到我说的第一个数字上。现在，在你的记忆中，你应该有数字 6（5+1）和数字 2。然后我让你用第二个数字减去第一个数字，于是我们得到答案 4。

这基本上解释了 C++ 如何存储变量，然后使用它们来解决问题或语句。实际用代码编写时，它看起来会像这样：

```cpp
int main ()
{
    // declaring variables:
    int a, b;
    int result;

    // process:
    a = 5;
    b = 2;
    a = a + 1;
    result = a - b;

    // print out the result:
    cout << result;

    // terminate the program:
    return 0;
}
```

当我们运行程序时，我们会看到它将为我们显示答案。非常简单，你应该能够利用我们到目前为止在“Hello World”程序及所用变量中讨论的内容，解释其中每一部分的含义。然而，这里有一些新东西，那就是使用“//”后跟一些文本。第一个“// operating with variables”只是我们程序的标题，而后面每个 // 都只是小标题，说明我们在程序的该位置正在做什么。这会容易得多，尤其是在处理大量代码时，你可以回溯这些行并找到你要找的内容，而不必试图逐行解读。

对于我们刚才使用的示例，还有一种更简单的代码编写方式。第二种方法称为变量的*“初始化”*，我们有三种方式可以做到。要*初始化*一个变量，基本上意味着我们可以在声明变量的同时声明其值。我们可以通过编写以下任意一种形式来实现这三种方式：

```cpp
int x = 0;
```

```cpp
int x (0);
```

```cpp
int x {0};
```

使用哪种方法并不重要，因为它们的作用都相同。然而，最好的一点是，如果你愿意，可以同时使用这三种类型。例如：

```cpp
// initialization of variables

#include <iostream>
using namespace std;

int main ()
{
    int a=5;
    int b(3);
    int c{2};
    int result;

    a = a + b;
    result = a - c;
    cout << result;

    return 0;
}
```

如你所见，程序将完成与之前编写的程序完全相同的事情，只不过现在我们在声明变量本身的同时也声明了变量的值。

## 第 3 章 – 运算符

现在我们已经熟悉了变量的使用，可以扩展我们的程序，并开始使用所谓的“运算符”。运算符基本上是一些符号，它们告诉编译器（Microsoft Visual Studio）使用数学或逻辑来解决我们用代码编写的问题。C++ 最常用的运算符有 6 种。它们是：

- 1. 算术运算符。
- 2. 关系运算符。
- 3. 逻辑运算符。
- 4. 位运算符。
- 5. 赋值运算符。
- 6. 杂项运算符。

我们将只介绍主要且最重要的运算符类型，并定义每个最常用符号的含义及其作用。
