# Key Concepts:

WebApplication.CreateBuilder(args) initializes the app with defaults.

app.MapGet(...) registers an HTTP GET endpoint.

app.Run() starts the app and listens for incoming requests.

ASP.NET Core apps run on Kestrel, a cross-platform web server.

They can handle dynamic pages, REST APIs, and connect to databases.

This framework is highly modular, meaning you add only the parts you need (e.g., routing, MVC, Razor, etc.). It’s fast and suited for cloud-native apps, microservices, and traditional websites alike.
