# 76. USING IDENTITY FOR AUTHENTICATION & AUTHORIZATION

The Identity framework in ASP.NET Core handles user login, registration, role management, and access control.

This is a basic setup showing how to scaffold Identity in a Razor Pages project using the .NET CLI.

[Code Example]

```
```bash
# Create a new ASP.NET Core Razor Pages project
dotnet new webapp -o IdentityDemo
cd IdentityDemo

# Add Identity UI scaffolding
dotnet add package Microsoft.AspNetCore.Identity.UI

# Enable Identity in Program.cs (automatically configured with template)
# Run the app
dotnet run
```
```

After this, visit /Identity/Account/Register to register a new user.

Visit /Identity/Account/Login to log in.

[Execution Result]

A working web application with:

+   - Registration
+   - Login
+   - Logout
+   - Account management pages
+   - All powered by ASP.NET Core Identity.
