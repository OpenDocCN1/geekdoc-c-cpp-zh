# 36. USING INDEXERS TO MAKE OBJECTS ACT LIKE ARRAYS

Indexers allow a class or struct to expose array-like syntax for accessing its internal data.

This simple example shows how to implement an indexer to access elements of a collection-like class using square bracket syntax.

[Code Example]

```
using System;

class Week
{
    private string[] days = { "Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday" };

    // Indexer declaration
    public string this[int index]
    {
        get { return days[index]; }
        set { days[index] = value; }
    }
}

class Program
{
    static void Main()
    {
        Week week = new Week();
        Console.WriteLine(week[0]); // Access like an array: Sunday
        week[0] = "Funday"; // Modify value using indexer
        Console.WriteLine(week[0]); // Now: Funday
    }
}
```
