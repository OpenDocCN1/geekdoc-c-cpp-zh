# 2. UNDERSTANDING VALUE TYPES AND REFERENCE TYPES

C# supports two fundamental types of data storage: **Value Types** (stored in the stack) and **Reference Types** (stored in the heap). This affects how data is managed in memory.

Understanding the difference between value types and reference types is crucial in C# programming. Below is an example demonstrating how assigning values works differently between them.

[Code Example]

```
```csharp
using System;

class Program
{
    struct ValueTypeExample
    {
        public int number;
    }

    class ReferenceTypeExample
    {
        public int number;
    }

    static void Main()
    {
        // Value type (struct) - stored in the stack
        ValueTypeExample v1 = new ValueTypeExample();
        v1.number = 10;
        ValueTypeExample v2 = v1; // Copying value (new copy in stack)
        v2.number = 20;
        Console.WriteLine("Value Type - v1: " + v1.number); // Outputs 10
        Console.WriteLine("Value Type - v2: " + v2.number); // Outputs 20
```
