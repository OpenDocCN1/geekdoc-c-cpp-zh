# 77. SIMPLIFIED WEB DEVELOPMENT WITH RAZOR PAGES

Razor Pages is a page-focused framework in ASP.NET Core that makes web app development easier by combining the controller and view logic into a single .cshtml file.

Below is a basic example of a Razor Page that handles a simple form submission.

[Code Example]

```
// Pages/Hello.cshtml
@page
@model HelloModel
<h2>Hello Razor Page</h2>
<form method="post">
<input type="text" name="UserName" />
<button type="submit">Submit</button>
</form>
@if (!string.IsNullOrEmpty(Model.Message))
{
<p>@Model.Message</p>
}

// Pages/Hello.cshtml.cs
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.RazorPages;
public class HelloModel : PageModel
{
[BindProperty]
public string UserName { get; set; }
public string Message { get; set; }
```
