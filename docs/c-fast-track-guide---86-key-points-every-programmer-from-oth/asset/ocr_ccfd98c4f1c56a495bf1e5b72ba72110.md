# 55. USING [OBSOLETE] TO MARK DEPRECATED CODE

The [Obsolete] attribute in C# is used to mark code elements (methods, classes, properties, etc.) that should no longer be used. It can show a warning or an error when that code is used elsewhere.

Here is a simple example that shows how to use the [Obsolete] attribute to warn developers about outdated methods.

[Code Example]

```
```csharp
using System;
class MyLibrary
{
    // Marked as obsolete, this method should not be used anymore
    [Obsolete("Use NewMethod instead")]
    public static void OldMethod()
    {
        Console.WriteLine("This is the old method.");
    }
    public static void NewMethod()
    {
        Console.WriteLine("This is the new method.");
    }
}
class Program
{
    static void Main()
    {
        MyLibrary.OldMethod(); // This line will generate a compiler warning
        MyLibrary.NewMethod();
    }
}
```
