# 59. Splitting One Class into Multiple Files Using Partial Classes

![](bbox=[0.14, 0.38, 0.22, 0.42])

Partial classes let developers split the definition of a single class across multiple files.

This is useful when working on large classes or when auto-generated code and custom code need to coexist without conflict.

[Code Example]

```
```csharp
// File: MyClass.Part1.cs

public partial class MyClass
{

public void SayHello()
{

Console.WriteLine("Hello from Part 1");

}
}

// File: MyClass.Part2.cs

public partial class MyClass
```
