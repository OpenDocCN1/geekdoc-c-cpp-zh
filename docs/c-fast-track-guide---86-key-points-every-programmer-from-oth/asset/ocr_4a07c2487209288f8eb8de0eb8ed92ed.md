# # 11. USING NULLABLE VALUE TYPES WITH ?

In C#, value types like int, bool, or DateTime cannot normally hold null. However, by using ?, you can allow them to represent the absence of a value.

Here's a short example showing how a nullable integer (int?) can be used to represent missing or optional data.

[Code Example]

```
```csharp
using System;

class Program
{
static void Main()
{
int? age = null; // The variable can be null
if (age.HasValue)
{
Console.WriteLine($"Age is {age.Value}");
}
else
{
Console.WriteLine("Age is unknown.");
}
age = 30; // Now we assign a real value
Console.WriteLine($"Updated age: {age}");
}
}
```
