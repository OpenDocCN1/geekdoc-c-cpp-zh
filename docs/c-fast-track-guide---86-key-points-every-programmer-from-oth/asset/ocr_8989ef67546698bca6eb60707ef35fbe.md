# 75. Getting Started with ASP.NET Core for Web Development

![](bbox=[0.127, 0.287, 0.173, 0.305])

ASP.NET Core is the primary modern framework provided by Microsoft for building web applications and APIs in C#.

Here’s a basic ASP.NET Core application that displays “Hello World!” in the browser.

[Code Example]

```
```csharp
// Program.cs

var builder = WebApplication.CreateBuilder(args); // Sets up the web app
builder

var app = builder.Build(); // Builds the application

// Defines a single HTTP GET endpoint at the root path
app.MapGet("/", () => "Hello World!");

app.Run(); // Starts the web application
```
```

To run the app, use the .NET CLI command in the terminal:

```
```bash
dotnet run
```
```

This will launch a local web server.
