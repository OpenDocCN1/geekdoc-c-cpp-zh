# 45. GETTING STRING NAMES OF VARIABLES AND MEMBERS WITH NAMEOF

The nameof operator returns the name of a variable, method, or property as a string.

This example shows how to use nameof to get the names of members without hardcoding strings.

[Code Example]

```
```csharp
using System;
class Person
{
public string FirstName { get; set; }
public void SayHello()
{
Console.WriteLine("Hello!");
}
}
class Program
{
static void Main()
{
// Get the name of the property
string propertyName = nameof(Person.FirstName);
// Get the name of the method
string methodName = nameof(Person.SayHello);
// Get the name of a variable
int age = 30;
string variableName = nameof(age);
Console.WriteLine(propertyName); // Output: FirstName
```
