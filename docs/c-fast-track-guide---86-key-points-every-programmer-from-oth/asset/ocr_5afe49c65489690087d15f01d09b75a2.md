# ## 14. USING FOREACH WITH ENUMERABLE COLLECTIONS

C#'s foreach loop simplifies iteration over collections that implement IEnumerable, making code cleaner and safer.

Here’s an example showing how you can loop through a list using foreach without needing indexes or manual iteration.

[Code Example]

```
```csharp
using System;
using System.Collections.Generic;
class Program
{
static void Main()
{
// A list of strings
List<string> fruits = new List<string> { "Apple", "Banana", "Cherry" };
// Loop over each fruit using foreach
foreach (string fruit in fruits)
{
Console.WriteLine($"I love {fruit}!");
}
}
}
```
```

[Execution Result]

I love Apple!
I love Banana!
I love Cherry!
