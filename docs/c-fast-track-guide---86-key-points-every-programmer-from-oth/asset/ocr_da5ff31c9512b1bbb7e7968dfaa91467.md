# 47. PREVENTING INHERITANCE WITH SEALED

The sealed keyword in C# prevents other classes from inheriting a class. It ensures that a class cannot be used as a base class.

Here is a basic example showing how the sealed keyword is used and what happens when someone tries to inherit from a sealed class.

[Code Example]

```
// This is a sealed class. It cannot be inherited.
sealed class Animal {
public void Speak() {
Console.WriteLine("The animal makes a sound.");
}
}

// Trying to inherit from Animal will cause a compile-time error.
// Uncommenting the line below will produce a CS0509 error:
// class Dog : Animal { } // ERROR: cannot derive from sealed type 'Animal'
class Program {
static void Main() {
Animal a = new Animal();
a.Speak(); // Works fine
}
}
```

[Execution Result]

The animal makes a sound.
