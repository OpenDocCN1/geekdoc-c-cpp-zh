# 24. INTERFACE IMPLEMENTATION
WITH INTERFACE KEYWORD

C# uses the interface keyword to define contracts that classes must follow.
An interface specifies method signatures and properties but contains no implementation.

Below is a basic example of defining and implementing an interface in C#.

[Code Example]

```
```csharp
using System;

// Define an interface (contract)
interface IAnimal
{
    void Speak(); // Any class that implements IAnimal must define this method
}

// Implement the interface in a class
class Dog : IAnimal
{
    public void Speak()
    {
        Console.WriteLine("Woof!");
    }
}

class Program
{
    static void Main()
    {
        IAnimal myDog = new Dog(); // Polymorphic assignment
        myDog.Speak();  // Call method via interface
    }
}
```
