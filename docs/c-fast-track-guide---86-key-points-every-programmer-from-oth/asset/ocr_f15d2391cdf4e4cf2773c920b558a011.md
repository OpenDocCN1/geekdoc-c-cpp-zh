# Real-world usage:

In ASP.NET, attributes define routes: [HttpPost("login")]

In unit testing: [TestMethod]

In Unity game development: [SerializeField]

# [Supplement]

Attributes must inherit from System.Attribute.

Built-in attributes include [Obsolete], [Serializable], [DllImport], etc.

You can define positional and named parameters inside attribute constructors.

Reflection is used to access these attributes at runtime, making them powerful for framework-level decisions.
