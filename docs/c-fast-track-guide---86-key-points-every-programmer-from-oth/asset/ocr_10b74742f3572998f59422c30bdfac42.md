# [Supplement]

In .NET 6+ project templates, global using is used by default.

For example, if you create a new console app, you might notice that System, System.Linq, and other common namespaces are not explicitly included in each file—they’re being added through implicit global usings.

You can customize this behavior via .csproj settings with `<ImplicitUsings>enable</ImplicitUsings>`.
