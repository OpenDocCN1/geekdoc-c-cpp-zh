# # 74. HIGH-PERFORMANCE INTER-SERVICE COMMUNICATION WITH GRPC

gRPC is a modern Remote Procedure Call (RPC) framework that enables fast communication between microservices. In .NET, gRPC is fully supported and optimized for high throughput and low latency.

Here's how a basic gRPC server and client are set up in C#. We'll show just the minimal core parts.

[Code Example]

```
```
// file: greet.proto
syntax = "proto3";

service Greeter {
  rpc SayHello (HelloRequest) returns (HelloReply);
}

message HelloRequest {
  string name = 1;
}

message HelloReply {
  string message = 1;
}

// Server-side implementation
public class GreeterService : Greeter.GreeterBase
{
    public override Task<HelloReply> SayHello(HelloRequest request, ServerCallContext context)
    {
        return Task.FromResult(new HelloReply { Message = $"Hello, {request.Name}" });
    }
}
