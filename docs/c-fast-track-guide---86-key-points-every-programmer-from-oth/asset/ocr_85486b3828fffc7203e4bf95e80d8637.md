Parallel.For(start, end, action) is like a regular for loop, but iterations can run simultaneously across multiple threads.

The i => { ... } is a lambda function that specifies what to do for each index.

This parallelism is handled by the .NET Task Parallel Library (TPL), which efficiently manages thread usage behind the scenes.

This approach is beneficial when the loop body contains CPU-bound operations and iterations are independent of each other.
