# What's going on:

xUnit is a .NET testing framework, similar in purpose to Python’s unittest or Java’s JUnit.

A [Fact] attribute marks a method as a test case. It means “this should always pass with no inputs.”

Assert.Equal(expected, actual) checks if the values match. If they don’t, the test fails.

dotnet test will auto-discover and run tests in the project.

# How to set it up:

Install xUnit via NuGet:

```
dotnet add package xunit
dotnet add package xunit.runner.visualstudio
```

Create a test project:

```
dotnet new xunit -n MyTests
```
