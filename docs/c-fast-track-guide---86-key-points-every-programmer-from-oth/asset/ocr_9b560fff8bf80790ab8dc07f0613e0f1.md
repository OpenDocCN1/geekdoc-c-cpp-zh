delegate int Operation(int x, int y); declares a delegate type that expects a method with two int parameters and an int return.

Operation op = Add; binds the delegate to the Add method.

op(5, 3) calls Add(5, 3) indirectly via the delegate.

This is functionally similar to function pointers in C++ but type-safe and secure.

Real-world use cases include:

+   - Passing logic into methods (like comparison rules for sorting).
+   - Implementing event systems (delegates are the core of C# events).
+   - Plugging in different behaviors dynamically at runtime.

# [Supplement]

Delegates are the foundation of events in C#.

Action<>, Func<>, and Predicate<> are built-in generic delegates that simplify delegate usage.

Anonymous methods and lambda expressions can also be assigned to delegates.

Delegates enable decoupling—your code becomes more flexible and testable.
