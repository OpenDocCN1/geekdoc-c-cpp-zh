The init accessor was introduced in C# 9.0 and is part of the move toward more immutable data structures.

Unlike set, init allows setting the property only at the time of object creation—either through an object initializer or constructor.

This makes your objects more predictable and safe, especially useful in:

+   - Domain-driven design (value objects)
+   - Configuration objects
+   - Data transfer objects (DTOs)

It also works beautifully with records, which are often immutable by design.

By limiting mutation, init helps prevent accidental or unauthorized changes to properties after initialization.
