# 23. AUTOMATIC RESOURCE CLEANUP WITH USING

C# provides the using statement to automatically clean up resources like files, database connections, or network streams when you're done with them.

Here's a simple example showing how to use using to automatically close a file after reading its content.

[Code Example]

```
using System;
using System.IO;
class Program
{
    static void Main()
    {
        // 'using' ensures the file is closed and memory is released automatically
        using (StreamReader reader = new StreamReader("example.txt"))
        {
            string content = reader.ReadToEnd(); // Read entire file
            Console.WriteLine(content); // Print file contents
        }
        // At this point, the file is already closed, even if an error occurred inside the using block
    }
}
```

[Execution Result]

(Assuming example.txt contains "Hello, world!")Hello, world!
