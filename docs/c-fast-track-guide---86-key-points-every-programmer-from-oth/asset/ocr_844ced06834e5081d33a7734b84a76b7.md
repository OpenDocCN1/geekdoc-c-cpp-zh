Extension methods are declared in static classes and must be static methods themselves.

The keyword this before the first parameter (this string str) tells the compiler that this method is an extension for the string type.

Once defined, you can use the method as if it's a member of the type you're extending—no special syntax required when calling it.

This is especially useful when working with .NET types or libraries where you can't modify the original source code, but still want to add custom functionality.

They are also commonly used in LINQ, which heavily relies on extension methods.

# [Supplement]

You must include the namespace where the extension method is defined (using YourNamespace;) in files where you want to use it.

IntelliSense in Visual Studio shows extension methods with a special icon (↓).

Extension methods don't override existing methods—they only work when no instance method with the same signature exists.
