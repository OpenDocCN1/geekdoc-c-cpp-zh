You need a simple data structure for temporary use.

You don’t want to create a full class for holding just a few pieces of data.

The compiler automatically infers the type and generates a class with read-only properties. You can only define them inside a method (not as a class member).

# Important:

+   - You can’t add methods to anonymous types.
+   - Once created, you cannot modify or add new properties.
+   - You cannot return anonymous types from methods unless using dynamic or returning to the same scope where it was created.

# [Supplement]

Anonymous types are reference types.

Their property names and types determine their type identity — if two anonymous types have the same properties and order, they are considered the same type only within the same assembly.

They are commonly used with LINQ for projecting data into new shapes without defining new types.
