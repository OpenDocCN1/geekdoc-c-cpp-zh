Factorial of 5 is 120

In this example, Factorial is a local function defined inside the CalculateFactorial method.

It cannot be accessed from outside CalculateFactorial, which helps keep the code clean and encapsulated.

# Why use local functions?

+   - Encapsulation: Keeps helper logic close to where it's used.
+   - Readability: Prevents polluting the class with methods used only in one place.

Access to variables: Local functions have access to the outer method's variables (n in this case).

Note: You can also define local functions as static inside static methods if they don’t need outer scope access.

# [Supplement]

Local functions were introduced in C# 7.0.

You can nest multiple levels of local functions if needed (though it’s rare and can reduce readability).

They are different from lambda expressions and anonymous methods, which are inline delegates rather than named functions.
