ASP.NET Core Identity is a membership system that adds:

+   - User storage (via EF Core and a database like SQL Server)
+   - Password hashing and security mechanisms
+   - Role-based authorization

Identity works with cookies for session management and supports:

+   - 2FA (Two-Factor Authentication)
+   - External logins (Google, Facebook, etc.)
+   - Email confirmation
+   - Account lockout on failed login attempts

The default Identity pages can be fully customized. The Scaffold-Identity tool (in Visual Studio or CLI) allows you to generate Razor Pages that you can then modify.

Program.cs will typically contain:

```
builder.Services.AddDefaultIdentity<IdentityUser>(options =>
options.SignIn.RequireConfirmedAccount = true)
    .AddEntityFrameworkStores<ApplicationDbContext>();
```

Middleware is added with:

```
app.UseAuthentication();
app.UseAuthorization();
```

[Supplement]

Identity uses Entity Framework Core under the hood.
