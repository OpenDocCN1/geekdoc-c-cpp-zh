Current count: 1, 2, 3, etc.

Blazor is part of ASP.NET Core and allows you to write frontend logic in C# instead of JavaScript. There are two main hosting models:

+   - Blazor Server: Executes code on the server and updates the browser via SignalR.
+   - Blazor WebAssembly: Runs entirely in the browser via WebAssembly.

In the code above:

+   - @onclick binds a C# method to the button’s click event.
+   - The @code block defines C# logic within the Razor file.
+   - State is automatically refreshed on the screen when count changes.
+   - This is especially useful for C# developers who don’t want to switch between languages when building modern web apps.

# [Supplement]

+   - Blazor components are .razor files and can be reused like React components.
+   - You can mix HTML and C# logic directly.
+   - Blazor WebAssembly compiles C# into WebAssembly, which runs natively in the browser.
