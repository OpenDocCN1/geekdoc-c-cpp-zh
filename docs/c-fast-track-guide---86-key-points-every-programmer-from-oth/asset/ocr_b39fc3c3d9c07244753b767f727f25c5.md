# 21. ENSURING VISIBILITY WITH VOLATILE IN MULTITHREADED CODE

The volatile keyword in C# tells the compiler and runtime that a field might be accessed by multiple threads and should not be cached or optimized in ways that could cause stale values to be read.

Here's an example of using volatile to ensure that one thread sees changes made by another thread.

[Code Example]

```
```csharp
using System;

using System.Threading;
class VolatileExample
{
    // Shared flag. Volatile ensures thread visibility.
    private static volatile bool isRunning = true;
    static void Worker()
    {
        Console.WriteLine("Worker started.");
        while (isRunning)
        {
            // Simulate work
        }
        Console.WriteLine("Worker stopped.");
    }
    static void Main()
    {
        Thread t = new Thread(Worker);
        t.Start();
        Thread.Sleep(1000); // Let the worker run a bit
```
