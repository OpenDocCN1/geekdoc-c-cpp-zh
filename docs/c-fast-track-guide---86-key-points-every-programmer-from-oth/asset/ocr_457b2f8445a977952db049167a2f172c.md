# 28. FLEXIBLE PROGRAMMING WITH GENERICS

C# supports generic classes, methods, and interfaces that work with any data type, helping you write reusable and type-safe code.

Below is an example of a generic class that stores a value of any type, and a generic method that swaps two variables.

[Code Example]

```
using System;

// A generic class that can hold any data type
class Box<T>
{
    public T Value;
    public Box(T value)
    {
        Value = value;
    }
    public void Display()
    {
        Console.WriteLine("Box holds: " + Value);
    }
}
```
