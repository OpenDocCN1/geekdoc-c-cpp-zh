# 9. READONLY FIELDS MUST BE SET
IN THE CONSTRUCTOR

In C#, a readonly field can only be assigned when it is declared or inside
the constructor of the class.

This code shows how a readonly field can be set in the constructor, but
not elsewhere.

```
[Code Example]

using System;
class Person
{
    // Readonly field
    public readonly string Name;

    // Constructor assigns the readonly field
    public Person(string name)
    {
        Name = name; // OK: assigning in constructor
    }

    public void ChangeName(string newName)
    {
        // Name = newName; // ERROR: Cannot assign to readonly field here
    }
}
class Program
{
    static void Main()
    {
        Person p = new Person("Alice");
        Console.WriteLine(p.Name);
    }
}
```
