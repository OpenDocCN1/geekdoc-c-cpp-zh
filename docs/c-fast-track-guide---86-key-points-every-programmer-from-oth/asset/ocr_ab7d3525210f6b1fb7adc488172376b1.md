# 56. INTRO TO UNIT TESTING: MSTEST, XUNIT, AND NUNIT

Unit testing ensures your code works correctly by checking individual units (like methods) in isolation. In C#, common testing frameworks are MSTest, xUnit, and NUnit.

This is an example using xUnit, one of the most popular unit testing frameworks for C#. We'll test a simple method to ensure it returns correct results.

[Code Example]

```
// File: Calculator.cs
public class Calculator
{
public int Add(int a, int b) => a + b;
}

// File: CalculatorTests.cs
using Xunit;
public class CalculatorTests
{
[Fact] // This attribute marks a test method
public void Add_ShouldReturnCorrectSum()
{
var calc = new Calculator();
int result = calc.Add(2, 3);
Assert.Equal(5, result); // Passes if result == 5
}
}
```

To run the test, use:
dotnet test
