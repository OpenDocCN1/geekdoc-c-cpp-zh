# Step-by-step explanation:

typeof(HelloWorld) gets the Type object for the HelloWorld class. This object contains metadata about the class.

Activator.CreateInstance(type) dynamically creates an instance of HelloWorld. You don’t need to use new HelloWorld() directly.

type.GetMethod("SayHello") retrieves metadata about the method named "SayHello".

method.Invoke(instance, null) actually calls the method on the created instance.

Why is this powerful?

You can build flexible systems, like plugin loaders, object mappers, or test frameworks.

Useful when you don’t know the exact types at compile-time.

# Common pitfalls:

Reflection is slower than direct calls.

You lose compile-time checking — misspelled method names won’t be caught until runtime.
