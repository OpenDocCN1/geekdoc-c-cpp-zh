# 64. THREAD-SAFE COLLECTIONS
WITH
SYSTEM.COLLECTIONS.CONCURRENT

The System.Collections.Concurrent namespace provides collections that are safe to use across multiple threads without additional locking.

This example demonstrates how to use ConcurrentDictionary, a dictionary designed to be thread-safe.

[Code Example]

```
using System;
using System.Collections.Concurrent;
using System.Threading.Tasks;
class Program
{
static void Main()
{
var dict = new ConcurrentDictionary<int, string>();
// Run 3 tasks in parallel to add items to the dictionary
Parallel.For(0, 3, i =>
{
dict.TryAdd(i, $"Value {i}");
});
// Display the dictionary content
foreach (var kvp in dict)
{
Console.WriteLine($"Key: {kvp.Key}, Value: {kvp.Value}");
}
}
}
```
