# 12. UNDERSTANDING VAR: IMPLICIT TYPING WITH STRONG TYPING

var lets you declare a variable without explicitly writing the type, but C# still figures it out during compilation — so the type is fixed and strongly typed.

Here’s how var can simplify code while keeping strong typing intact.

[Code Example]

```
using System;
class Program
{
static void Main()
{
var name = "Alice"; // Compiler sees this as string
var age = 25; // Compiler sees this as int
var isMember = true; // Compiler sees this as bool
Console.WriteLine($"Name: {name}, Age: {age}, Member: {isMember}");
}
}
```

[Execution Result]

Name: Alice, Age: 25, Member: True

Even though we write var, the C# compiler infers the type at compile time based on what value you assign. After that point, the type is locked — name is a string, age is an int, etc. This is not like JavaScript or Python where types can change dynamically.
