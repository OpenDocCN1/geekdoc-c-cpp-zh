# 62. USING FUNC<> AND ACTION<> FOR FUNCTIONAL PROGRAMMING

Func<> and Action<> are built-in generic delegates in C#. They let you store methods in variables, pass them as parameters, and build flexible, reusable code using functional programming techniques.

This example shows how to use Func<> and Action<> to assign and use methods as first-class citizens.

[Code Example]

```
```csharp
using System;

class Program
{
    static void Main()
    {
        // Func<int, int, int> means a function taking two ints and returning an int
        Func<int, int, int> add = (a, b) => a + b;

        // Action<string> means a method taking one string and returning void
        Action<string> printMessage = message => Console.WriteLine($"Message: {message}");
        int result = add(10, 20); // Calling the Func delegate
        printMessage($"The result is {result}"); // Using the Action delegate
    }
}
```
```

[Execution Result]

Message: The result is 30

Func<T1, T2, TResult> is a generic delegate that takes parameters T1, T2, and returns a value of type TResult.
