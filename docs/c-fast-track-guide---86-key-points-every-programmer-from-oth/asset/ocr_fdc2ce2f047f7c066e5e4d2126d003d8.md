In older C# versions, you’d have to write:

```
if (pet is Dog)
{
Dog d = (Dog)pet;
d.Bark();
}
```

But with is + variable declaration (is Dog d), you both check and cast at the same time. This is:

+   - More concise: fewer lines.
+   - Safer: no accidental invalid casts.
+   - Scoped: the variable d only exists inside the if block.

This pattern is called type pattern matching, and it’s a clean, modern way to handle polymorphism in C#.

This becomes even more powerful with newer C# versions supporting nested patterns and the switch expression.
