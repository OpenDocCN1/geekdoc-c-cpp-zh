# 49. HIGH-PERFORMANCE STACK MEMORY ALLOCATION WITH STACKALLOC

The stackalloc keyword in C# allows you to allocate memory on the stack, which is faster than allocating on the heap. It's mostly used in performance-critical scenarios, like working with low-level memory or span types.

Here’s a simple example using stackalloc to allocate a small array of bytes on the stack.

[Code Example]

```
```csharp
using System;

class Program
{
    static void Main()
    {
        // Allocate memory for 5 bytes on the stack
        Span<byte> buffer = stackalloc byte[5];

        // Fill the buffer
        for (int i = 0; i < buffer.Length; i++)
        {
            buffer[i] = (byte)(i * 10); // Assign 0, 10, 20, 30, 40
        }

        // Print the contents
        foreach (var b in buffer)
        {
            Console.WriteLine(b);
        }
    }
}
