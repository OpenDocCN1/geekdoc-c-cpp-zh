Can be installed in Global Assembly Cache (GAC) for shared use.

Assemblies in .NET are compiled code (DLLs or EXEs). Without versioning, newer versions can overwrite old ones and break existing apps.

Strong naming solves this by combining the assembly's name, version, culture, and a public key into a unique identity.

Side-by-side execution allows different versions of the same library to run simultaneously, preventing "DLL Hell" — a common issue in older Windows development.

To enable strong naming:

+   - Use sn.exe to generate a key pair.
+   - Add [assembly: AssemblyKeyFile("...")] to your AssemblyInfo.cs.
+   - Compile with the /keyfile: option.

This results in a cryptographic signature. The CLR can now verify the integrity and origin of the assembly.

# [Supplement]

The Global Assembly Cache (GAC) stores strongly-named assemblies that can be shared across applications.

Versioning uses the format: Major.Minor.Build.Revision

Only strongly-named assemblies can be installed in the GAC.

Weak-named assemblies can be overwritten, which is why strong naming is essential for public/shared libraries.
