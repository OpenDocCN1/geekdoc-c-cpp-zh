In C#, a partial class allows you to break a single class into multiple .cs files. This is particularly helpful when:

You have auto-generated code (e.g., designer code in WinForms or ASP.NET) that you don’t want to manually modify.

You want to organize a large class into logical parts across files to make it easier to navigate and maintain.

All parts must be within the same namespace, and they must all use the partial keyword.

When compiled, the compiler merges all partial class parts into a single class. It's important to avoid naming conflicts (e.g., two methods with the same name) across the partial definitions.

Also, partial classes can be used with structs and interfaces, not just classes.

# [Supplement]

Visual Studio's designer files (e.g., Form1.Designer.cs) are automatically declared as partial. This is so that the user-written logic in Form1.cs and the designer-generated layout code can exist in parallel without interfering with each other.
