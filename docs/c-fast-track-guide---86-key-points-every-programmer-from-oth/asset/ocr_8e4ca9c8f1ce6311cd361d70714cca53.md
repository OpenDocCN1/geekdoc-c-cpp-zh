The key difference between **value types** and **reference types** is how they are stored and copied in memory:

# ### **Value Types (Stack)**

+   - Stored in the **stack** (a small, fast memory area).
+   - When assigned to another variable, a **copy** is created.
+   - Changes in one variable **do not** affect the other.
+   - Examples: `int`, `double`, `char`, `bool`, `struct`, `enum`.

# ### **Reference Types (Heap)**

+   - Stored in the **heap** (a dynamically allocated memory area).
