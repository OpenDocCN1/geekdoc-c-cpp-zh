
Always double-check pointer logic to avoid memory corruption or crashes.

## 49. HIGH-PERFORMANCE STACK MEMORY ALLOCATION WITH STACKALLOC

The stackalloc keyword in C# allows you to allocate memory on the stack, which is faster than allocating on the heap. It's mostly used in performance-critical scenarios, like working with low-level memory or span types.

Here’s a simple example using stackalloc to allocate a small array of bytes on the stack.

[Code Example]

```csharp
using System;

class Program
{
    static void Main()
    {
        // Allocate memory for 5 bytes on the stack
        Span<byte> buffer = stackalloc byte[5];

        // Fill the buffer
        for (int i = 0; i < buffer.Length; i++)
        {
            buffer[i] = (byte)(i * 10); // Assign 0, 10, 20, 30, 40
        }

        // Print the contents
        foreach (var b in buffer)
        {
            Console.WriteLine(b);
        }
    }
}
```

You cannot use stackalloc in async methods unless marked as unsafe or using `Span<T>`.

It's not commonly needed in everyday business apps but is invaluable in high-performance or systems-level code.

## 50. CALLING NATIVE CODE WITH DLLIMPORT AND P/INVOKE

C# supports calling functions from native DLLs (e.g., Windows API) using Platform Invocation Services (P/Invoke) via the DllImport attribute. This allows direct access to OS-level functions or legacy C/C++ libraries.

This example shows how to call the native Windows function MessageBox from user32.dll.

[Code Example]

```csharp
using System;
using System.Runtime.InteropServices;

class Program
{
    // Declare external function from user32.dll
    [DllImport("user32.dll", CharSet = CharSet.Auto)]
    public static extern int MessageBox(IntPtr hWnd, String text, String caption, uint type);

    static void Main()
    {
        // Call the native MessageBox function
        MessageBox(IntPtr.Zero, "Hello from native code!", "P/Invoke Example", 0);
    }
}
```

[Execution Result]

A native Windows message box appears with the text:

Title: P/Invoke Example

Message: Hello from native code!

- DllImport tells the C# compiler to link a method with a native DLL function.
- user32.dll is a Windows system DLL that contains GUI-related functions.
- MessageBox is a simple function from that DLL that creates a pop-up message box.
- IntPtr.Zero is used to indicate no owner window.
- The CharSet option ensures correct string marshaling between C# and native code.
- The uint type parameter specifies the type of message box (e.g., with OK/Cancel, icons, etc.).
- P/Invoke is powerful but must be used carefully: incorrect parameter types or unmanaged resources can cause crashes or memory leaks.
- Ideal when dealing with legacy code, hardware access, or OS-level functionality.

### [Supplement]

- You can also use P/Invoke to call C functions in your own compiled DLLs, not just system DLLs.
- Tools like DllImport Generator and PInvoke.net help you find signatures.
- You must ensure correct data types and memory layout—managed and unmanaged code handle memory differently.
- P/Invoke is part of .NET’s broader native interop features, including COM and unsafe code.

## 51. READING AND WRITING FILES WITH SYSTEM.IO

In C#, the System.IO namespace provides classes for file and directory manipulation. You can read, write, create, and delete files using types like File, StreamReader, and StreamWriter.

This example shows how to write text to a file and then read it back using System.IO.

[Code Example]

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string filePath = "example.txt"; // The file name
        
        // Write text to the file
        File.WriteAllText(filePath, "Hello, world!"); // Overwrites if file exists
        
        // Read the text back from the file
        string content = File.ReadAllText(filePath);
        
        // Show the content in console
        Console.WriteLine("File content: " + content);
    }
}
```

[Execution Result]

File content: Hello, world!

System.IO.File.WriteAllText writes the entire string to the file. If the file already exists, it is overwritten.

System.IO.File.ReadAllText reads the entire file content as a single string.

These methods are useful for simple file operations without needing to manage streams manually.

Note that:

- File path can be absolute or relative.
- Exceptions (like IOException, UnauthorizedAccessException) may occur if the file cannot be accessed.
- Always handle exceptions in real applications for safety.
- Also, StreamReader and StreamWriter allow more control when reading or writing large files line-by-line.

### [Supplement]

- Files can also be written in binary format using File.WriteAllBytes.
- Use File.AppendText or File.AppendAllText if you want to add content to existing files.
- You can use Directory.Exists(path) to check for folders.
- File access may differ based on OS and permissions, especially between Windows and Linux.

## 52. EFFICIENT MEMORY ACCESS WITH `SPAN<T>`

`Span<T>` is a stack-only type in C# that allows working with slices of arrays or memory buffers efficiently, without copying or allocating new memory.

The following example demonstrates how to use `Span<T>` to manipulate part of an array efficiently.

[Code Example]

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] numbers = { 1, 2, 3, 4, 5 };
        Span<int> slice = numbers.AsSpan(1, 3); // Takes 3 elements starting from index 1
        for (int i = 0; i < slice.Length; i++)
        {
            slice[i] *= 10; // Modify values in-place
        }
        Console.WriteLine(string.Join(", ", numbers)); // Original array is changed
    }
}
```

[Execution Result]

1, 20, 30, 40, 5

`Span<T>` represents a contiguous region of memory. Unlike arrays or lists, `Span<T>` does not cause heap allocations, making it faster and more memory-efficient for temporary data manipulation.

Key points:

- `Span<T>` can only live on the stack, so it can't be stored in fields of classes.
- You can create spans from arrays using AsSpan() and also from stackalloc.
- Changes made to the span reflect on the underlying data (e.g., the original array).
- It is mostly used in high-performance code, such as parsing or memory slicing.

`Span<T>` provides:

- Slicing: mySpan.Slice(start, length)
- Bounds checking
- Safety (unlike pointers, no unsafe code is needed)

### [Supplement]

- `ReadOnlySpan<T>` is an immutable version used when data should not be modified.
- `Span<T>` is extremely useful in methods that process parts of strings, buffers, or arrays repeatedly.
- Useful in scenarios like CSV parsing, string tokenization, or buffer manipulation without copying.

It was introduced in C# 7.2 and requires targeting .NET Core 2.1+ or .NET Standard 2.1+.

## 53. BUILT-IN JSON SERIALIZATION WITH SYSTEM.TEXT.JSON

C# provides native support for JSON serialization and deserialization using the System.Text.Json namespace, which is both efficient and easy to use.

Here's a simple example of how to serialize and deserialize an object using System.Text.Json.

[Code Example]

```csharp
using System;
using System.Text.Json;

// Define a simple class
public class Person
{
    public string Name { get; set; }
    public int Age { get; set; }
}

class Program
{
    static void Main()
    {
        // Create a Person object
        var person = new Person { Name = "Alice", Age = 30 };

        // Serialize the object to a JSON string
        string jsonString = JsonSerializer.Serialize(person);
        Console.WriteLine("Serialized JSON: " + jsonString);

        // Deserialize the JSON string back to a Person object
        var deserializedPerson = JsonSerializer.Deserialize<Person>(jsonString);
        Console.WriteLine("Deserialized Name: " + deserializedPerson.Name);
        Console.WriteLine("Deserialized Age: " + deserializedPerson.Age);
    }
}
```
