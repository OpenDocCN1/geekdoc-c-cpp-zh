
- Use const for universal, unchanging values like Pi or mathematical constants.
- Use readonly when the value depends on runtime logic, but must stay fixed after initialization.

If a const value is used across assemblies, changing its value requires recompiling all dependent assemblies, because the value is baked into the code at compile time.

## 11. USING NULLABLE VALUE TYPES WITH ?

In C#, value types like int, bool, or DateTime cannot normally hold null. However, by using ?, you can allow them to represent the absence of a value.

Here's a short example showing how a nullable integer (int?) can be used to represent missing or optional data.

[Code Example]

```csharp
using System;

class Program
{
static void Main()
{
int? age = null; // The variable can be null
if (age.HasValue)
{
Console.WriteLine($"Age is {age.Value}");
}
else
{
Console.WriteLine("Age is unknown.");
}
age = 30; // Now we assign a real value
Console.WriteLine($"Updated age: {age}");
}
}
```

[Execution Result]

Age is unknown.
Updated age: 30

In C#, value types (like int, float, bool) normally cannot be null. This makes sense because they are designed to hold actual values (e.g., a number). But sometimes, especially when dealing with databases, APIs, or user input, you may want to represent "no data" or "unknown" — and for that, int? (read as "nullable int") is your friend.

When you declare int?, C# is actually creating a shorthand for Nullable<int>. This structure has properties like .HasValue (true if it holds a value) and .Value (the value itself).

This concept is crucial in real-world applications — imagine a user hasn't filled in their birthday yet. Instead of using a fake number like -1, nullable types let you say "this has no value, and that's okay."

Be very careful not to access .Value unless you're sure .HasValue is true — otherwise, your code will crash.

### [Supplement]

- Nullable types are structs under the hood (Nullable<T>), not reference types.
- You can also use the null-coalescing operator (??) to provide a default value:

```csharp
int displayedAge = age ?? 0; // use 0 if age is null
```

Useful when mapping between database fields (which are often nullable) and C# types.

## 12. UNDERSTANDING VAR: IMPLICIT TYPING WITH STRONG TYPING

var lets you declare a variable without explicitly writing the type, but C# still figures it out during compilation — so the type is fixed and strongly typed.

Here’s how var can simplify code while keeping strong typing intact.

[Code Example]

```
using System;
class Program
{
static void Main()
{
var name = "Alice"; // Compiler sees this as string
var age = 25; // Compiler sees this as int
var isMember = true; // Compiler sees this as bool
Console.WriteLine($"Name: {name}, Age: {age}, Member: {isMember}");
}
}
```

[Execution Result]

Name: Alice, Age: 25, Member: True

Even though we write var, the C# compiler infers the type at compile time based on what value you assign. After that point, the type is locked — name is a string, age is an int, etc. This is not like JavaScript or Python where types can change dynamically.

You must assign a value when using var, otherwise the compiler has nothing to infer the type from. For example, var x; is invalid — but var x = 5; is fine.

This makes code cleaner, especially when dealing with complex types:

```
var orders = new Dictionary<string, List<int>>();
```

...instead of:

```
Dictionary<string, List<int>> orders = new Dictionary<string, List<int>>();
```

But use var wisely: overusing it can make code harder to read if the type is not obvious from context.

### [Supplement]

- The use of var does not mean dynamic typing — it's still strongly typed.
- Avoid using var when it makes the code unclear.
- Useful with LINQ or anonymous types, where the exact type is long or unknown.

## 13. PATTERN MATCHING FOR TYPE-SAFE DATA HANDLING

Pattern matching in C# lets you inspect and extract data from objects based on their type and shape, improving code safety and readability.

Here’s a simple example showing how pattern matching can determine an object’s type and access its properties safely.

[Code Example]

```csharp
using System;
class Program
{
static void PrintShapeInfo(object shape)
{
// Use pattern matching to safely check type and extract data
if (shape is Circle c)
{
Console.WriteLine($"This is a circle with radius: {c.Radius}");
}
else if (shape is Rectangle r)
{
Console.WriteLine($"This is a rectangle with width {r.Width} and height {r.Height}");
}
else
{
Console.WriteLine("Unknown shape");
}
}
// Sample shape classes
class Circle { public double Radius { get; set; } }
class Rectangle { public double Width { get; set; } public double Height { get; set; } }

static void Main()
{
PrintShapeInfo(new Circle { Radius = 5 });
PrintShapeInfo(new Rectangle { Width = 10, Height = 20 });
PrintShapeInfo("Just a string");
}
}
```

[Execution Result]

```
This is a circle with radius: 5
This is a rectangle with width 10 and height 20
Unknown shape
```

Pattern matching uses the is keyword in combination with variable declaration (is Circle c) to check the type and extract the instance into a new variable of that type (c). This avoids manual casting and null checks.

This mechanism is especially powerful in switch expressions and with newer features like relational patterns and recursive patterns (e.g., checking values inside properties).

For beginners, understanding this requires some knowledge of classes and type checking, so it's slightly advanced but very valuable for writing clean, safe code.

### [Supplement]

Pattern matching became significantly more powerful starting from C# 7.0 and has been extended in later versions.

## 15. LINQ: QUERY DATA LIKE SQL IN C#

LINQ (Language Integrated Query) lets you query collections and databases using readable, SQL-like syntax directly in C# code.

Here's a simple example of using LINQ to filter a list of numbers and select only the even ones.

[Code Example]

```csharp
using System;
using System.Linq; // Required to use LINQ
class Program
{
static void Main()
{
int[] numbers = { 1, 2, 3, 4, 5, 6 };

// LINQ query to select even numbers
var evenNumbers = numbers.Where(n => n % 2 == 0);

// Display the results
foreach (int num in evenNumbers)
{
Console.WriteLine(num); // Output each even number
}
}
}
```

[Execution Result]

2
4
6

using System.Linq; is essential to access LINQ methods.

numbers.Where(...) uses a lambda function (n => n % 2 == 0) that means:

- For each number n in the array, include it only if n % 2 == 0 (i.e., it's even).

The result is not a new array but an enumerable, meaning it's evaluated when we loop over it with foreach.

This method is extremely powerful because it replaces complex loops with clear, readable logic.

Terms you should know:

- Lambda expression: A quick way to define a function inline.
- Enumerable: A collection that can be looped through, like arrays or lists.
- Deferred execution: LINQ doesn't actually run the query until you use it (like in foreach).

### [Supplement]

- LINQ can be used not only with arrays/lists but also with databases (like SQL Server) via LINQ to SQL or Entity Framework.
- LINQ methods include Select, Where, OrderBy, GroupBy, and more—each serving a purpose like in SQL.
- LINQ improves code readability and reduces bugs from manual looping logic.
