# [Supplement]

catch (Exception) catches any exception, but be cautious — it can hide bugs.

You can filter exceptions using when: catch (IOException ex) when (ex.Message.Contains("disk"))

Unhandled exceptions crash the application unless caught at the top level.

For cleanup without exceptions, use using or try/finally.
