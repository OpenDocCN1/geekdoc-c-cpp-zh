# 48. WORKING WITH POINTERS USING UNSAFE

C# normally protects you from low-level memory access. But using unsafe allows you to use pointers, like in C or C++, for advanced memory manipulation.

Here's a simple, safe demo of how to use unsafe code to directly manipulate a variable's memory using pointers.

[Code Example]

```
```csharp
using System;

class Program {
    static void Main() {
        int num = 10;

        // unsafe block to work with pointers
        unsafe {
            int* p = &num // Get the address of num
            *p = 20; // Modify the value at the address
        }

        Console.WriteLine(num); // Output will be 20
    }
}
```
```

To compile this, you must enable unsafe code:

In Visual Studio: Project Properties → Build → Allow unsafe code

Or with command line:

csc /unsafe Program.cs

[Execution Result]

20
