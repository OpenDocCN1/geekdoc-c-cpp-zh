# [Supplement]

gRPC was developed by Google and is used in production at massive scale.

It uses Protocol Buffers (protobuf) for message serialization, which is faster and smaller than JSON.

gRPC supports streaming — not just request/response, but bidirectional and server-side streams.

gRPC is not ideal for browser-based APIs — although gRPC-Web exists, REST or GraphQL may be easier for frontend.
