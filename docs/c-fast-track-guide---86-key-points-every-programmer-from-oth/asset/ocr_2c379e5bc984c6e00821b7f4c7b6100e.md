# 43. CONCISE PATTERN MATCHING WITH SWITCH EXPRESSIONS

switch expressions in C# allow for more compact and readable code compared to traditional switch statements, especially when matching multiple patterns or returning values.

Here's a short example demonstrating how switch expressions can simplify decision logic in C#.

[Code Example]

```
using System;

class Program
{
    static void Main()
    {
        // Input: day of the week
        string day = "Saturday";

        // Using switch expression to get the type of the day
        string dayType = day switch
        {
            "Saturday" or "Sunday" => "Weekend",  // matches either Saturday or Sunday
            "Monday" => "Start of work week",  // single match
            "Friday" => "Almost weekend",  // single match
            _ => "Weekday"  // default case
        };

        Console.WriteLine(dayType);
    }
}
```
