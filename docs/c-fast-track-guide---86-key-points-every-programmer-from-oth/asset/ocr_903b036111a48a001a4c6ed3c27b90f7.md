# 37. CUSTOM BEHAVIOR FOR OPERATORS USING OVERLOADING

Operator overloading allows developers to redefine how standard operators (like +, -, ==) behave for custom classes.

The following code demonstrates how to overload the + operator for a simple Point class so that two points can be added together intuitively.

[Code Example]

```
using System;
class Point
{
public int X, Y;
public Point(int x, int y)
{
X = x;
Y = y;
}
// Overload the + operator to add two Point objects
public static Point operator +(Point a, Point b)
{
return new Point(a.X + b.X, a.Y + b.Y);
}
public override string ToString()
{
return $"({X}, {Y})";
}
}
```
