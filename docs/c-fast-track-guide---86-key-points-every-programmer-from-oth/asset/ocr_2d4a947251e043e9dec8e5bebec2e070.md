# 34. USING TUPLES TO RETURN MULTIPLE VALUES

Tuples allow you to return multiple values from a method without creating a class or struct. They are lightweight, flexible, and readable.

This example shows how to return multiple values using a tuple and how to access those values.

[Code Example]

```
```csharp
using System;

class Program
{
    // A method returning a tuple with two values
    static (string name, int age) GetPerson()
    {
        return ("Bob", 28);
    }

    static void Main()
    {
        // Receiving the tuple result
        var person = GetPerson();
        // Accessing tuple values by name
        Console.WriteLine($"Name: {person.name}, Age: {person.age}");
    }
}
```
```

[Execution Result]

Name: Bob, Age: 28
