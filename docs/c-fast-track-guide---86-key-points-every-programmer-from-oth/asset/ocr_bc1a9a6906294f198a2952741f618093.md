# 72. USING ENTITY FRAMEWORK CORE FOR DATABASE ACCESS

Entity Framework Core (EF Core) is the default Object-Relational Mapper (ORM) in C#. It helps developers work with databases using C# code instead of writing SQL manually.

This example shows how to define a simple model and use EF Core to insert and retrieve data from an in-memory database.

# [Code Example]

```
```csharp
using Microsoft.EntityFrameworkCore;
using System;
using System.Linq;

// Define a model (table)
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }
}
// Define a DbContext (database session)
public class AppDbContext : DbContext
{
    public DbSet<Product> Products { get; set; }
    protected override void OnConfiguring(DbContextOptionsBuilder options)
    => options.UseInMemoryDatabase("TestDb"); // Using an in-memory DB for testing
}
