Step-by-step explanation:

[AttributeUsage(AttributeTargets.Class)] specifies where the attribute can be used (e.g., on classes).

InfoAttribute is a custom attribute class that stores a message.

[Info("...")] applies the attribute to the ImportantClass.

Attribute.IsDefined(...) checks if the attribute is present.

Attribute.GetCustomAttribute(...) retrieves the actual instance, so you can read the Message property.

Why use attributes?

They add structured, retrievable metadata.

Common in frameworks — for example, [Serializable], [Obsolete], or [HttpGet].
