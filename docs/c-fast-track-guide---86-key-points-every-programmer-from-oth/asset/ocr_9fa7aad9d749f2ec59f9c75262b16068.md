Hot Reload is a feature introduced in .NET 6 and improved in .NET 7 and beyond.

It allows you to change your code while the application is running, especially when debugging.

This is useful because:

+   - You don’t have to stop and rebuild the app.
+   - You can test small tweaks in real-time.
+   - You stay in the "flow" of debugging.

How to use it:

+   - Open your project in Visual Studio or run from CLI with dotnet watch.
+   - Start the app in debug mode.
+   - Make changes in your code (like editing a message or logic).
+   - If Hot Reload supports it, it will automatically apply your changes.

Important Notes:

+   - Works best with ASP.NET Core, WPF, WinForms, Console Apps.
+   - Not all changes are reloadable (e.g., changing class/struct definitions sometimes requires a rebuild).
+   - Visual Studio usually shows a lightning bolt [] icon when Hot Reload applies your code.

# ## [Supplement]

Hot Reload internally uses the Edit and Continue (EnC) feature of the .NET runtime.
