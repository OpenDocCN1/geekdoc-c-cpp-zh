# 32. USING ATTRIBUTES AS
METADATA TAGS

Attributes are like special tags added to your code. They add extra information (metadata) that tools or reflection-based code can read.

Here’s an example of defining and reading a custom attribute using reflection.

[Code Example]

```
using System;
using System.Reflection;

// Define a custom attribute
[AttributeUsage(AttributeTargets.Class)]
public class InfoAttribute : Attribute
{
    public string Message { get; }
    public InfoAttribute(string message)
    {
        Message = message;
    }
}

// Apply the custom attribute to a class
[Info("This class does something important.")]
public class ImportantClass
{
}
```
