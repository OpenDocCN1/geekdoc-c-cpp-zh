System.Text.Json is available in .NET Core 3.0+ and .NET 5+.

JsonSerializer.Serialize() converts an object into a JSON-formatted
string.

JsonSerializer.Deserialize<T>() takes a JSON string and converts it
back into an object of type T.

This approach avoids external dependencies like Newtonsoft.Json and is
optimized for performance.

By default, the serializer is case-sensitive and expects PascalCase in C#.

# [Supplement]

You can customize serialization with attributes like
[JsonPropertyName("customName")].

By default, null values are included; you can change behavior with
JsonSerializerOptions.

This is widely used in REST APIs built with ASP.NET Core.
