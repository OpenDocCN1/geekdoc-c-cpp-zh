Hello, [UserName]!

Razor Pages are part of ASP.NET Core and are ideal for scenarios where each page contains its own logic, especially for form-based pages.

+   - The @page directive at the top tells ASP.NET this is a Razor Page.
+   - The .cshtml file contains both HTML and Razor syntax (like @Model.Message).
+   - The associated .cshtml.cs file contains the backend logic.
+   - OnPost() is automatically called when the form is submitted via POST.
+   - BindProperty binds the form field to the property.
+   - This structure avoids needing a separate controller, making Razor Pages less complex than MVC for smaller applications or beginners.

# [Supplement]

Razor Pages were introduced in ASP.NET Core 2.0.

They follow the MVVM (Model-View-ViewModel) pattern, making them beginner-friendly.
