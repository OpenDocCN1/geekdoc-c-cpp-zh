This example defines a generic class Printer<T> with a where T : IPrintable constraint. This means you cannot use Printer<T> with any type that does not implement IPrintable.

The benefit of this is type safety—the compiler knows that T will always have a Print() method, so you avoid runtime errors.

You can use multiple constraints as well:

```
where T : class, new(), IPrintable
```

This means:

+   - T must be a class (not a struct),
+   - must have a parameterless constructor (new()),
+   - and must implement IPrintable.

Constraints are powerful tools to write reusable but safe code.
