# Use system dialogs

The Electron.NET API Demos allow you to use system dialogs for opening files, printing files, launching a file or editing informations messages.

This is more native, more usable because the process is more effective with native callbacks and allow to call it remotely in Interprocess. See the electron.net page's render process.

# Information Dialog

ELECTRON.NET / API / DEMOS / API / DEMOS

View Demo

In this demo, the Electron.NET API will send a message to the renderer process to open an information dialog. The renderer process will capture the message and perform the response which can then be reflected back in the renderer process.

Note: The Electron.NET property is disabled in macOS.

An information dialog can contain an icon, your choice of buttons, title and message.

# Play Along

Use the demo applet in Electron app of your own. The Electron Quick Start app is a bare bones app that main with these demos. Follow the instructions here to get going here and clone Electron Quick Start. Use Electron.NET API Demos as your ASP.NET Core API.

# Build Electron.NET Quick Start

This includes the ElectronNET.WebHostExtensions extension into the Program.cs file of your ASP.NET Core project.

```
public static IWebHost BuildWebHost(string[] args) =>
    WebHost.CreateDefaultBuilder(args)
    .UseElectron(args)
    .UseStartup<Startup>()
    .Build();
```
