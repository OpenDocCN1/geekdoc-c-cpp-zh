The “GtkBasicForm” example does implement a signal on the button clicked event with the corresponding handler method button1_clicked. The event is implemented inline (it should be integrate in the .gradle file).

This project provides a good starting point for starting the development of a GTK .NET Core 3 application, it can be use as template for just doing that.

The edition of the GUI is much more flexible than coding the GUI, and, offer greater possibilities to design a proper GUI in a minimum of time (once you are familiar with Glade GUI).

You will find the source of this project example on the netcore3 GitHub repos.
