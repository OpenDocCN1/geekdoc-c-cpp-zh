# 3.5 Keywords

Keywords are the reserved words of a programming language. All the keywords have fixed meanings and these meanings cannot be changed. Keywords serve as basic building blocks for program statements. The list of all keywords in ANSI C are listed in the Table 3.3.

+   - auto
+   - break
+   - case
+   - char
+   - const
+   - continue default
+   - do

# Table 3.3: ANSI C Keywords

+   - else long

+   - struct
