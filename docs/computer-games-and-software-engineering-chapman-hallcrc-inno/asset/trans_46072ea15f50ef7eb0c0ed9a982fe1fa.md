
从学生动机和参与度来看，这些体验总体上是积极的，并且在推广计算机科学/软件工程（CS/SE）和招收学生方面效果良好。然而，能够证明在学业成绩（分数）方面有显著提升的研究太少。必须开展更多研究，以考察游戏开发用于教授其他主题的教育效果。
