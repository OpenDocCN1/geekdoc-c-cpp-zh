# 7.22.7.2 The mbtowc function

# Synopsis

```
#include <stdlib.h>
int mbtowc(wchar_t * restrict pwc,
       const char * restrict s,
       size_t n);
```

# Description

If s is not a pointer, the mbtowc function inspects at n bytes beginning with the byte pointed to by s to determine the number of bytes needed to complete the next multibyte character (including any shift sequences). If the function determines that the next multibyte character is complete and valid, it determines the value of the corresponding wide character and, if pwc is not a null pointer, stores that value in the object pointed to by pwc. If the corresponding wide character is the null character, the character is left in the initial conversion state.

The implementation shall behave as if no library function calls the mbtowc function.

# Returns

If s is a null pointer, the mbtowc function returns a non-zero value, if multibyte character encodings, or do not have state-dependent encodings. If s is not a null pointer, the mbtowc function returns 0 (if s points to the null character), or returns the number of bytes that are contained in the multibyte character (if the n or fewer bytes form a valid multibyte character), or returns -1 (if they do not form a valid multibyte character).

In no case will the value returned greater than n or the value of the MB_CUR_MAX macro.

# 7.22.7.3 The wctowmb function

# Synopsis

```
#include <stdlib.h>
int wctowmb(char *s, wchar_t wc);
```

# Description

The wctowmb function determines the number of bytes to represent the multibyte character corresponding to the wide character given by wc (including any shift sequences), and stores the multibyte character representation in the array whose first element is pointed to by s (if s is not a null pointer). At most MB_CUR_MAX characters are stored. If wc is a null character, a byte preceded by any shift sequence needs to restore the initial state shift, and the character is left in the initial conversion state.
