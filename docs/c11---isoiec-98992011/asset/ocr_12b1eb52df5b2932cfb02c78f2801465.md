9 The range of nonnegative values of a signed integer type is a subrange of the
corresponding unsigned integer type, and the representation of the same value in each
type is the same.41) A computation involving unsigned can never overflow,
because a result that cannot be represented by the resulting unsigned integer type is
reduced modulo the number that is greater than the largest value that can be
represented by the resulting type.

10 There are three floating types, designated as float, double, and long

type double; the set of values of the type double is a subset of the set of values of the
type long double.
