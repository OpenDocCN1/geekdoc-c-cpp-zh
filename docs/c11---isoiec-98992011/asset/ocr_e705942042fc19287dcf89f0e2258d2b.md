hexadecimal-escape-sequence hexadecimal-digit

# Description

+   2 An integer character constant is a sequence of one or more multibyte characters enclosed in single-quotes, as in 'x'. A wide character constant is the same, except prefixed by the letter L, u, or U. With a few exceptions detailed, the elements of the sequence are members of the source character set; they are mapped in an implementation-defined manner to members of the execution character set.

+   3 The single-quote ', the double-quote ", question-mark ?, the backslash \, and arbitrary integers are representable according to the following table of escape sequences:
| single quote ' | \' |
| double quote " | \" |
| question mark ? | \? |
| backslash \ | \\\ |
| octal character | \octal digits |
| hexadecimal character | \x hexadecimal-digit |

+   4 The double-quote " and question-mark ? are representable either by themselves or by the escape sequences \" and \?, respectively, the single-quote ' and the backslash \ shall be represented, by the escape sequences \' and \\.

+   5 The digits that follow the backslash in an escape sequence are taken to be part of the construction of a single character for an integer character constant or of a single character for a wide character constant. The numerical value of the octal integer so forms the value of the desired character or wide character.

+   6 The hexadecimal digits that follow the backslash and the letter \x in a hexadecimal escape sequence are taken to be part of the construction of a single character for an integer character constant or of a single character for a wide character constant. The numerical value of the hexadecimal integer so forms the value of the desired character or wide character.

+   7 Each octal or hexadecimal escape sequence is the longest sequence of characters that can constitute the escape sequence.

+   8 In addition, characters not in the basic character set are representable by universal character names and certain nongraphic characters consisting of the backslash \ followed by a lowercase letter: \a, \b, \f, \n, \r, \t, and \v(77).
