If there is a runtime-constraint violation, wcstumbs_s does the following. If retval is not a null pointer, wcstumbs_s sets *retval to (size_t) (-1). If dst is not a null pointer and dstmax is greater than zero and less RSIZE_MAX, then wcstumbs_s sets dst [0] to null character.

# Description

The wcstumbs_s function converts a sequence of wide characters from the array pointed to by src into a sequence of multibyte characters that begins in the initial shift state. If dst is not a null pointer, the converted characters are stored into the array pointed to by dst. Conversion continues up to and including a terminating null character, which is also stored. Conversion stops in two cases:

+   - when a character is reached that does not correspond to a valid multibyte character;
- (if dst is not a null pointer) the next multibyte character would exceed the limit of n bytes to be stored into the array pointed to by dst. If the wide character being converted is the null character, then n is the lesser of len or dstmax. Otherwise, n is the lesser of len or dstmax-1.
If the conversion stops without converting a null character and dst is not a null pointer, then a null character is stored into the array pointed to by dst immediately following any multibyte characters already stored. Each conversion takes place as if a call to the wcrtomb function.⁴16

Regardless of whether dst is or not a null pointer, if the input conversion encounters a wide character that does not correspond to a valid multibyte character, an encoding error occurs: the wcstumbs_s function stores the (size_t) (-1) to *retval. Otherwise, the wcstumbs_s function stores into *retval the number of bytes in the resulting multibyte sequence, including the terminating null character (if any).

All elements following the terminating character (if any) written by wcstumbs_s in the array of dstmax elements pointed to by dst are unspecified values when wcstumbs_s returns.⁴17

If copying takes between objects that overlap, the objects take on unspecified values.

> ⁴16 If conversion stops as a terminating null character has been reached, the bytes stored include those necessary to reach the initial shift state immediately before the null byte. However, if the conversion stops before a terminating null character has been reached, the result will be null terminated, but might not end in the initial shift state.

> ⁴17 When len is not less than dstmax, the implementation might fill the array before discovering a runtime-constraint violation.
