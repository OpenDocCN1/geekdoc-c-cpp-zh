# 7.3.9.4 The conj functions

Synopsis

```
#include <complex.h>
double complex conj(double complex z);
float complex conjf(float complex z);
long double complex conjl(long double complex z);
```

Description

+   2 The conj functions computes the complex conjugate of z, by reversing the sign of its imaginary part.

Returns

+   3 The conj functions return the complex conjugate value.

# 7.3.9.5 The cproj functions

Synopsis

```
#include <complex.h>
double complex cproj(double complex z);
float complex cproj(float complex z);
long double complex cprojl(long double complex z);
```

Description

+   2 The cproj functions compute a projection of z onto the Riemann sphere: projects to z except that all complex infinities (even with one infinite part and NaN part) project to positive infinity on the real axis. If z has an infinite part, then cproj(z) is equivalent to

> INFINITY + I * copys(0.0, cimag(z))

Returns

+   3 The cproj functions return the value of the projection onto the Riemann sphere.
