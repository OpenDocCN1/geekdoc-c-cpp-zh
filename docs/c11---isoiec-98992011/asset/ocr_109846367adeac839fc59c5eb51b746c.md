# K.3.7.4.3 The strerrorlen_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
size_t strerrorlen_s(errno_t errnum);
```

Description

+   The strerrorlen_s function calculates the length of the (untruncated) locale-specific message string that the strerror_s function maps to errno.

Returns

+   The strerrorlen_s function returns the number of characters (not including the null character) in the full message string.

# K.3.7.4.4 The strlen_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
size_t strlen_s(const char *s, size_t maxsize);
```

Description

+   The strlen_s function computes the length of the string pointed to by s.

Returns

+   If s is a null pointer,428) then the strlen_s function returns zero.

+   Otherwise, the strlen_s function returns the number of characters that precede the terminating null. If there is no null character in the first maxsize characters of s then strlen_s returns maxsize. At most the first maxsize characters of s shall be accessed by strlen_s.

> 428) Note that the strlen_s function has no runtime-constraints. This lack of runtime-constraints along with the values returned for a null pointer or an unterterminated string argument make strlen_s useful in algorithms that gracefully handle exceptional data.
