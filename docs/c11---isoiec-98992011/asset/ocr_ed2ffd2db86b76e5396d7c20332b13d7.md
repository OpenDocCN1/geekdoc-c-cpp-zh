# 7.4.1.3 The isblank

Synopsis

```
#include <ctype.h>
int isblank(int c);
```

Description

The isblank tests for any character that is a standard blank character or is one of a locale-specific set of characters for which isspace is true and is used to separate words within a line of text. The standard blank characters are the following: space (' '), and horizontal tab ('\t'). In the "C" locale, isblank returns true only for the standard blank characters.

# 7.4.1.4 The iscntrl

Synopsis

```
#include <ctype.h>
int iscntrl(int c);
```

Description

The iscntrl tests for any control character.

# 7.4.1.5 The isdigit

Synopsis

```
#include <ctype.h>
int isdigit(int c);
```

Description

The isdigit function tests for any decimal-digit character (as defined in 5.2.1).
