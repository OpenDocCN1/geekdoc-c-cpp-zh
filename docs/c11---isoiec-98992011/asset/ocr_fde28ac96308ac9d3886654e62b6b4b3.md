# Returns

+   The mbrtoc16 function returns the first of the following that applies (given the current conversion state):

0 if the n or fewer bytes complete the multibyte character that corresponds to the null wide character (which is the value stored)
between 1 and n inclusive if the n or fewer bytes complete a valid character (which is the value stored); the value returned is the number of bytes that complete the multibyte character.

+   (size_t) (-3) if the next character resulting from a previous call has been stored (no bytes from the input have been consumed by this).

+   (size_t) (-2) if the n bytes contribute to an incomplete (but potentially valid) multibyte character, and all n bytes have been processed (no value is stored).324

+   (size_t) (-1) if an encoding error occurs, in which case the n or fewer bytes do not contribute to a complete and valid multibyte character (no value is stored); the value of the macro EISEQ is stored in errno, and the conversion state is unspecified.
