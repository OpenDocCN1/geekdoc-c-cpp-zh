# 6.5.2.3 Structure and union members

Constraints

1 The first operand of the . shall have atomic, qualified, or unqualified structure or union, and the second operand shall name a member of that type.

2 The first operand of the -> operator shall have type "pointer to atomic, qualified, or unqualified structure" or "pointer to atomic, qualified, or unqualified union", and the second operand shall name a member of the type pointed to.

⁹⁴ In order, function executions do not "interleave" with each other.

# Semantics

A postfix expression followed by a . operator and an identifier designates a member of a structure or union object. The value is that of the named member,⁹⁵⁾ and is an lvalue if the first expression has qualified type, the result is the so-qualified version of the type of the designated member.

A postfix expression followed by the -> operator and an identifier designates member of a structure or union object. The value is that of the named member of the object to which the first expression points, and is an lvalue.⁶⁾ If the first expression is a pointer to a qualified type, the result has the so-qualified version of the type of the designated member.

Accessing a member of an atomic structure or union object results in undefined behavior.⁹⁷⁾

One special guarantee is made in order to simplify the use of unions: if a union contains structures that share a common initial sequence (see below), and if the union object contains only one of these structures, any declaration of the completed type of union is visible. Two structures share a common initial sequence with corresponding members have compatible types (and, for bit-fields, the widths) of one or more initial members.

# 6.5.2.4 Postfix increment and decrement operators

Constraints

The operand of the postfix increment or decrement operator shall have atomic, qualified, or unqualified or pointer type, and be a modifiable value.

Semantics

The result of the postfix operator is the value of the operand. As a side effect, the value of the operand is incremented (that is, the value 1 of the appropriate type is added to it). See the discussions of additive operators and compound assignment for information on constraints, types, and effects on pointers. The value computation of the result is sequenced before the side effect of updating the stored value of the operand. With respect to indeterminately-sequenced function, the operation of postfix ++ is a single evaluation. Postfix ++ on atomic type is a read-modify-write operation with memory_order_seq_cst semantics⁹⁸

The postfix -- operator is analogous to the postfix ++ operator, except that the value of the operand is subtracted (that is, the value 1 of the appropriate type is subtracted from it).

**Forward references:** additive operators (6.5.6), compound assignment (6.5.16.2).
