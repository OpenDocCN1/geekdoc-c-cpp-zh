EXAMPLE 9 Arrays can be initialized to correspond to elements of an enumeration by using designators:

```
enum { member_one, member_two };
const char *nm[] = {
[member_two] = "member two",
[member_one] = "member one",
};
```

EXAMPLE 10 Structure can be initialized to nonzero values depending on their order:

```
div_t answer = { .quot = 2, .rem = -1 };
```

```
struct { int a[3]; b; } w[] = {
( [0].a = 1, [1].a[0] = 2 ); };
```

Space can be "allocated" from ends of an array by using a single designator:

```
int a[MAX] = {
1, 3, 5, 7, 9, [MAX-5] = 8, 6, 4, 2, 0
};
```

In the above, if MAX is greater than ten, then there will be some zero-valued elements in the middle; if it is less than ten, the five values provided by the first initialization will be overridden by the second one.
