# ISO/IEC 9899:2011 (E)

+   The numeric result of the ilogb functions when the correct value is outside the range of the return type (7.12.6.5, F.10.3.5).

+   The result of rounding when the value is out of range (7.12.9.5, 7.12.9.7, F.10.6.5).

+   The value stored by the remqo functions in the object pointed to by quo when y is zero (7.12.10.3).

+   Whether a comparison macro argument that is represented in a format wider than its semantic type is converted to the semantic type (7.12.14).

+   Whether setjmp and va_end are macros or identifiers with external linkage (7.13).

+   Whether va_copy and va_end are macros or identifiers with external linkage (7.16.1).

+   The hexadecimal digit before the decimal point when a non-normalized floating-point number is printed with an a or A conversion function (7.21.6.1, 7.29.2.1).

+   The value of the file position indicator before a successful call to the ungetc function for a text stream, or the ungetc function for any stream, until all pushed-back characters are read or discarded (7.21.10, 7.29.3.10).

+   The details of the value stored by the fgetpos function (7.21.9.1).

+   The details of the value returned by the ftell function for a text stream (7.21.9.4).

+   Whether strtod, strtof, strtol, wcstod, wcstof, and wcstol functions convert a minus-signed sequence to a negative number or by negating the value resulting from converting the corresponding unsigned sequence (7.22.3.1, 7.29.4.1.1).

+   The order and continuity of storage allocated by successive calls to the calloc, malloc, and realloc functions (7.22.3).

+   The amount of storage allocated by a successful call to the calloc, malloc, or realloc function when 0 bytes was requested (7.22.3).

+   Whether a call to the clear function that does not happen before the exit function is called will succeed (7.22.4.2).

+   Whether a call to the at_quick_exit function that does not happen before the quick_exit function is called will succeed (7.22.4.3).

+   Which of two elements that compare as equal is matched by the bsearch function (7.22.5.1).

+   The order of two elements that compare as equal in an array sorted by the qsort function (7.22.5.2).
