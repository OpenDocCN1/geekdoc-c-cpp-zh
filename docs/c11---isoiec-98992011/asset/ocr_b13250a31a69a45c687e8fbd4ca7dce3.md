The field width takes the form of an asterisk * (described later) or a nonnegative decimal integer.³330

+   - An optional precision gives the minimum number of digits to appear after the d, i, o, u, and X conversions, the number of digits to appear after the decimal-point wide character for A, E, f, and F conversions, the number of significant digits for the g and G conversions, or the maximum number of wide characters to be written for a given conversions. The precision takes the form of a period (.) followed either by an asterisk * (described later) or by an optional decimal integer; if only the period is specified, the precision is taken as zero. If a precision appears with any other conversion, the behavior is undefined.

+   - An optional length modifier that specifies the size of the argument.

+   - A conversion specifier character that specifies the type of conversion to be applied.

5 As noted above, a field width or precision, or both, may be indicated by an asterisk. In this case, an int argument specifies the field width or precision. The arguments specifying field width, precision, or both, shall appear (at any order) before the argument (if any) to be converted. A negative field width is taken as a – flag followed by a positive field width. A negative argument is taken as if the precision were omitted.
