# 21 EXAMPLE 4 In:

```
#include <stdio.h>
/* ... */
int d1, d2, n1, n2;
i = sscanf("123", "%d%n%%n", &d1, &n1, &n2);
```

the value 123 is assigned to d1 and the value 3 is assigned to n2. Because %n never get an integer value, the value of 3 is also assigned to n2. The value of d2 is not affected. The value is assigned to i.

# 22 EXAMPLE 5 The call:

```
#include <stdio.h>
/* ... */
int n, i;
s = sscanf("foo%c bar 42", "foo%%bar%d", &i);
```

will assign to n the value 1 and to i the 42 because input white-space characters are skipped for the conversion and the % d conversion specifiers.

The shift sequences are denoted by ↑ and ↓, in which the first causes entry into the alternate shift state.
