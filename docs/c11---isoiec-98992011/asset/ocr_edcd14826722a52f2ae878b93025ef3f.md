# 6.7.6.1 Pointer declarations

# Semantics

If, in the declaration “T D1”, D1 has the form

+   * type-qualifier-listopt D

and the type specified for ident in the declaration “T D” is *derived-declarator-type-list T”, and the type specified for ident is *derived-declarator-type-list type-qualifier-list pointer to T”. For each qualifier in the list, ident is a so-qualified pointer.

For two pointers to be compatible, both shall be identically identified and shall be pointers to compatible types.

EXAMPLE The following pair of declarations demonstrates the difference between a “variable pointer to a constant value” and a “constant pointer to a variable value”.

```
const int *ptr_to_const;
int *const constant_ptr;
```

The contents of any object pointed by ptr_to_const shall not be modified by that pointer, but ptr_to_const itself may be changed to point to another object. Similarly, the contents of the int pointed by constant_ptr may be modified, constant_ptr itself shall always point to the same location.

The declaration of the constant pointer_ptr may be clarified by using a definition for the type “pointer to int”.

```
typedef int *int_ptr;
const int *int_ptr constant_ptr;
```

declares constant_ptr as an object that has type “const-qualified pointer to int”.

# 6.7.6.2 Array declarations

Constraints

In addition to type qualifiers and the keyword static, the [ ] may delimit an expression or *. If they delimit an expression (which specifies the size of an array), the expression shall have an integer type. If the expression is a constant expression, it shall have a value greater than zero. The element type shall not be an incomplete or function type. The only qualifiers and the keyword static shall appear only in a declaration of a function parameter with an array, and only in the outermost array derivation.

If an identifier is declared as having a variably modified type, it shall be an ordinary identifier (defined in 6.2.3), without linkage, and have either block scope or function prototype scope. If an identifier is declared to be an object with static or storage duration, it shall not have a variable length array type.
