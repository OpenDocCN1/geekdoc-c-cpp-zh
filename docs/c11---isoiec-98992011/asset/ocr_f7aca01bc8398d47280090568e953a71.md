# 6.8.5 Iteration statements

# Syntax

+   iteration-statement:
    while ( expression ) statement
    do statement while ( expression ) ;
    for ( expression_opt ; expression_opt ; expression_opt ) statement
    for ( declaration expression_opt ; expression_opt ) statement

# Constraints

+   The controlling expression of an iteration statement shall have scalar type.

+   The declaration part of a for statement shall only declare identifiers for objects with storage class auto or register.

# Semantics

+   An iteration statement causes a statement called the loop body to be executed repeatedly until the controlling expression compares to 0. The repetition occurs regardless of whether the loop body is entered from the iteration statement or by a jump.¹⁵⁵

+   An iteration statement is a block whose scope is a subset of the scope of its enclosing block. The loop body is also a block whose scope is a subset of the scope of the iteration statement.
