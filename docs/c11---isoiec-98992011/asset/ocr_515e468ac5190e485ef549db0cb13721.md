#  7.21.2 Streams

+   Input and output, whether or to physical devices such as terminals and tape drives, or whether or from files supported on supported storage devices, are mapped into logical data streams, whose properties are more uniform than their various inputs and outputs. *Two forms of mapping are supported, for text streams and for binary streams.*²⁶⁶

+   A text stream is an ordered sequence of characters composed into lines, each line consisting of zero or more characters plus a terminating new-line character. Whether the last line is a terminating new-line character is implementation-defined. Characters may be added, altered, or deleted on input and output to conform to defining conventions for representing text in the host environment. Thus, there need not be one-to-one correspondence between the characters in a stream and those in the external representation. Data read from a text stream will necessarily compare equal to the data that were written earlier to that stream only if: the data consists only of printing characters and the control characters horizontal tab and new-line; no new-line character is immediately preceded by space characters; and the last is a new-line character. Whether space characters that are written out immediately before a new-line character appear when read is implementation-defined.

+   A binary stream is an ordered sequence of characters that can transparently record internal data. Data read from a binary stream shall compare equal to the data that were written earlier to that stream, under the same implementation. Such a stream, however, have an implementation-defined number of characters appended to the end of the stream.
