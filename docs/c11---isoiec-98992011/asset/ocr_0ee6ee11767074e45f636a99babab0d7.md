# 7.12.6.13 The calbn and scalbn functions

# Synopsis

+   1 ```#include <math.h>
double scalbn(double x, int n);
float scalbnf(float x, int n);
long double scalnl(long double x, int n);
double scalbn(double x, int n);
float scalbnf(float x, int n);
long double scalbnl(long double x, int n)
```

# Description

+   2 The `calbn` and `scalbn` functions compute $x 	imes FLT\_RADIX^n$ efficiently, normally by computing $FLT\_RADIX^n$ explicitly. A range error may occur.

# Returns

+   3 The `calbn` and `scalbn` functions return $x 	imes FLT\_RADIX^n$.

# 7.12.7 Power and absolute-value functions

# 7.12.7.1 The cbrt functions

# Synopsis

+   1 ```#include <math.h>
double cbrt(double x);
float cbrtf(float x);
long double cbrtl(long double x)
```

# Description

+   2 The `cbrt` functions compute the real cube root of $x$.

# Returns

+   3 The `cbrt` functions return $x^{1/3}$.
