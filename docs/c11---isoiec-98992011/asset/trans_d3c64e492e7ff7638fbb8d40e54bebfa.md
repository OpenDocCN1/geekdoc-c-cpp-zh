# 信息技术 — 编程语言 — C

# 1. 范围

本国际标准规定了用 C 编程语言编写的程序^1) 的形式并建立了其解释。它规定了：

- C 程序的表示；
- C 语言的语法和约束；
- 解释 C 程序的语义规则；
- C 程序处理的输入数据的表示；
- C 程序产生的输出数据的表示；
- 符合规范的 C 实现所实施的限制和范围。

本国际标准未规定：

- C 程序转换以供数据处理系统使用的机制；
- C 程序被调用以供数据处理系统使用的机制；
- 输入数据转换以供 C 程序使用的机制；
- C 程序产生后的输出数据转换机制；
- 超过任何特定数据处理系统容量或特定处理器容量的程序及其数据的大小或复杂度；
- 能够支持规范实现的数据处理系统的所有最小要求。

> ^1) 本国际标准旨在促进 C 程序在各种数据处理系统之间的可移植性。它供实现者和程序员使用。
