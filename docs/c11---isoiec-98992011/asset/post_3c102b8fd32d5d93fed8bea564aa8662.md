## K.3.6.5 Multibyte/wide string conversion functions

+ 1 The behavior of the multibyte string is affected by the LC_TYPE category of the current locale.

### K.3.6.5.1 The mbstowcs_s function

#### Synopsis

```
#include <stdlib.h>
errno_t mbstowcs_s(size_t * restrict retval,
               wchar_t * restrict dst, size_t dstmax,
               const char * restrict src, size_t len);
```

#### Runtime-constraints

+ 2 Neither retval nor src shall be a null pointer. If dst is not a null pointer, then len nor dstmax must be greater than RSIZE_MAX. If dst is not a null pointer, then dstmax should equal zero. If dst is not a null pointer, and len is not equal to len, then a null character shall occur within the first dstmax multibyte characters of the array pointed to src.

+ 3 If there is a runtime-constraint violation, then mbstowcs_s sets *retval to (size_t) (-1). If dst is not a null pointer and dstmax is greater than and less than RSIZE_MAX, then mbstowcs_s sets dst [0] to the wide character.

#### Description

+ 4 The mbstowcs_s function converts a sequence of multibyte characters that begins in the initial shift state from the array pointed to src into a sequence of corresponding wide characters. If dst is not a null pointer, the converted characters are stored in the array pointed to dst. Conversion stops early in two cases: when a sequence of a null character is encountered, which is also stored. bytes encountered that does not form a valid multibyte character, or (if dst is not a null pointer) when len wide characters have been stored in the array pointed to by dst.414) If dst is not a null pointer and no wide character was stored into the array pointed to by dst, then dst[len] is set to the wide character. Each conversion takes place as by a call to the mbtowc function

+ 5 Regardless of whether dst is or not a null pointer, if the input conversion encounters a sequence of bytes that do not form a valid multibyte character, an encoding error occurs: the mbtowcs_s function stores the value (size_t)(-1) into *retval. Otherwise, the mbtowcs_s function stores into *retval the number of multibyte characters successfully converted, not including the terminating character (if any).

+ 6 All elements the terminating wide character (if any) written by mbstowcs_s in the array dstmax wide characters pointed to by dst unspecified values when mbstowcs_s returns.415)

+ 7 If copying takes place between objects that overlap, the objects take on unspecified values.

Returns

The mbstowcs_s function returns zero if no runtime-constraint violation and no encoding error occurred. Otherwise, a nonzero value is returned.

### K.3.6.5.2 The wctombs_s function

#### Synopsis

```
#include <stdlib.h>
errno_t wctombs_s(size_t * restrict retval,
char * restrict dst, rsize_t dstmax,
const wchar_t * restrict src, rsize_t len);
```

#### Runtime-constraints

+ 2 Neither retval nor src shall be a null pointer. If dst is not a null pointer, neither len dstmax shall be greater than RSIZE_MAX. If dst is a null pointer, then dstmax shall not equal zero. If dst is not a null pointer, then dstmax is not less than dstmax, and the conversion shall have been shown (see below) because a terminating wide character was reached or because an encoding error occurred.

> 414) Thus, the value of len is ignored if dst is a null pointer.

> 415) This allows an implementation to convert the multibyte string before discovering a terminating null did not occur where required.

If there is a runtime-constraint violation, wctombs_s does the following. If retval is not a null pointer, wctombs_s sets *retval to (size_t) (-1). If dst is not a null pointer and dstmax is greater than zero and less RSIZE_MAX, then wctombs_s sets dst [0] to null character.

#### Description

The wctombs_s function converts a sequence of wide characters from the array pointed to src into a sequence of multibyte characters that begins in the initial shift state. If dst is not a null pointer, the converted characters are stored in the array pointed to dst. Conversion stops early in two cases: when a sequence of a null character is encountered, which is also stored. bytes encountered that does not form a valid multibyte character, or (if dst is not a null pointer) when len wide characters have been stored in the array pointed to by dst.414) If dst is not a null pointer and no wide character was stored into the array pointed to by dst, then dst[len] is set to the wide character. Each conversion takes place as by a call to the mbtowc function

+ 5 Regardless of whether dst is or not a null pointer, if the input conversion encounters a sequence of bytes that do not form a valid multibyte character, an encoding error occurs: the mbtowcs_s function stores the value (size_t)(-1) into *retval. Otherwise, the mbtowcs_s function stores into *retval the number of multibyte characters successfully converted, not including the terminating character (if any).

+ 6 All elements the terminating wide character (if any) written by mbstowcs_s in the array dstmax wide characters pointed to by dst unspecified values when mbstowcs_s returns.

+ 7 If copying takes place between objects that overlap, the objects take on unspecified values.

Returns

The mctombs_s function returns zero if no runtime-constraint violation and no encoding error occurred. Otherwise, a nonzero value is returned.
