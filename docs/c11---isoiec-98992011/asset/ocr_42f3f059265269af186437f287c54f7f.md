5 The wcstock function searches from there a wide character that is contained in the current separator string. If no such wide character is found, the current token extends to the end of the wide string by sl, and subsequent searches in the same wide string for a token return a null pointer. If such a wide character is found, it is overwritten by a null character, which terminates the current token.

6 In all cases, the wcstock function stores sufficient information in the pointer pointed to by ptr or subsequent calls, with a null pointer for sl and the unmodified pointer value for ptr, start searching just past the overwritten by a null character (if any).

# Returns

7 The wcstock function returns a pointer to the first wide character of a token, or a null pointer if there is no token.

# EXAMPLE

```
#include <wchar.h>
static wchar_t str1[] = L"?a??b,,#c";
static wchar_t str2[] = L"\t \t";
char_t t, *ptr1, *ptr2;

t = wcstock(str1, L, &ptr1);      // t points to the token L"a"
t = wcstock(NULL, L"", &ptr1);     // t points to the token L"??b"
t = wcstock(str2, L"\t", &ptr2);  // t is a null pointer
t = wcstock(NULL, L"#", &ptr1);    // t points to the token L"c"
t = wcstock(NULL, L"?", &ptr1);     // t is a null pointer
```

# 7.29.4.5.8 The wmemchr function

# Synopsis

```
#include <wchar.h>
wchar_t *wmemchr(const wchar_t *s, wchar_t c,
size_t n);
```

# Description

2 The wmemchr function locates the first occurrence of c in the initial n wide characters of the object pointed to by s.

# Returns

3 The wmemchr function returns a pointer to the located wide character, or a null pointer if the wide character does not occur in the object.
