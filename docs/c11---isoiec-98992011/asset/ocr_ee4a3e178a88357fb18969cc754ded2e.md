# 7.6.2.2 The fetgetexceptflag function

Synopsis

```
```c
1&nbsp;&nbsp;#include <fenv.h>
   int fetgetexceptflag(fexcept_t *flagmp,
   int excepts);
```
```

Description The fetgetexceptflag function attempts to store an implementation-defined representation of the states of the floating-point status flags indicated by the argument flag.

Returns

3 The fetgetexceptflag function returns zero if the representation was successfully stored. Otherwise, it returns a nonzero value.

# 7.6.2.3 The feraiseexcept function

Synopsis

```
```c
1&nbsp;&nbsp;#include <fenv.h>
   int feraiseexcept(int excepts);
```
```

Description

2 The feraiseexcept function attempts to raise the supported floating-point exceptions represented by its argument.<sup>216</sup> The order in which these floating-point exceptions are raised is unspecified, as stated in F.8.6. Whether the feraiseexcept function additionally raises the "ineact" floating-point exception whenever it raises the "overflow" or "underflow" floating-point exception is implementation-defined.

Returns

3 The feraiseexcept function returns zero if the except argument is zero or if all specified exceptions were successfully raised. Otherwise, it returns a nonzero value.

> <sup>216) The effect is intended to be similar to that of floating-point exceptions raised by arithmetic operations. Hence, enabled traps for floating-point exceptions raised by this function are taken. The specification in F.8.6 is in the same spirit.
