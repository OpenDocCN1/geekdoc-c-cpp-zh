# 7.27.3 Time conversion functions

+   Except for the strftime function, these functions return a pointer to one of two types of static objects: a broken-down time structure or an array of char. Execution of any of the functions return a pointer to one of these object types may overwrite the information in any object of the same type pointed to by the value returned from previous call to any of them and the functions are not required to avoid races with each other.^{321} The implementation shall behave as if no other library functions call these functions.

# 7.27.3.1 The astime function

# Synopsis

```
#include <time.h>
char *astime(const struct tm *timer)
```

# Description

The astime function converts the broken-down time in the structure pointed to by timerptr into a string in the form

```
Sun Sep 16 01:03:52 1973\n\0
```

using of the following algorithm.

```
char *astime(const struct tm wday_name[7][3]) = {
    static const char mon_name[12][3] = {
        "Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"
        
        "Jan", "Feb", "Mar", "Apr", "May", "Jun"
        
        "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
    };
    static const char result[26] =;
}
```
