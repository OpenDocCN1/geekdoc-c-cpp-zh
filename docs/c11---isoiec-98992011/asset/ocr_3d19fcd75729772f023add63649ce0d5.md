# Semantics

A postfix expression followed by a . operator and an identifier designates a member of a structure or union object. The value is that of the named member,⁹⁵⁾ and is an ivalue if the first expression has qualified type, the result is the so-qualified version of the type of the designated member.

A postfix expression followed by the -> operator and an identifier designates member of a structure or union object. The value is that of the named member of the object to which the first expression points, and is ivalue.⁶⁾ If the first expression is a pointer to a qualified type, the result has the so-qualified version of the type of the designated member.

Accessing a member of an atomic structure or union object results in undefined behavior.⁹⁷⁾

One special guarantee is made in order to simplify the use of unions: if a union contains structures that share a common initial sequence (see below), and if the union object contains only one of these structures, any declaration of the completed type of union is visible. Two structures share a common initial sequence with corresponding members have compatible types (and, for bit-fields, the widths) of one or more initial members.

EXAMPLE 1 If f is a function returning a structure or union, and x is a member of that structure or union, f().x is a valid postfix expression but is not an ivalue.
