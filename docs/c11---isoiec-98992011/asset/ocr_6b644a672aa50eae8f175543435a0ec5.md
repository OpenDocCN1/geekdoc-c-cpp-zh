+   EXAMPLE Pointer arithmetic is well defined with pointers to variable length types.

```
{
int n = 4, m = 3;
int a[n][m];
int (*p)[m] = a;   // p == &a[0]
p += 1;            // p == &a[1]
(*p)[2] = 99;      // a[1][2] == 99
int n = p - a;      // n == 1
}
```
