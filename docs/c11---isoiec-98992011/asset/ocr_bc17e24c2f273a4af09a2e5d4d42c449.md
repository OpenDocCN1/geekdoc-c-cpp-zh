9 If a specifier of the form

```
struct-or-union identifier
```

or

```
enum identifier
```

occurs other than as part of the above forms, and a declaration of an identifier as a tag is visible, then it specifies the same type as that other declaration, and does not redeclare the tag.

10 EXAMPLE 1 This mechanism allows declaration of a self-referential structure.

```
struct tnode {
    int count;
    struct tnode *left, *right;

}
```

specifies a structure that contains an integer and two pointers to objects of the same type. Once this declaration has been given, the declaration

```
struct s, *sp;
```

declares s to be an object of the given type and sp to be a pointer to object of the given type. With these declarations, the sp->left refers to the struct tnode pointer of the object to which sp points; the expression s.right->count designates the count member of the right tnode pointed to from s.

11 The following alternative formulation uses the typedef mechanism:

```
typedef struct tnode TNODE {
    struct tnode {
        int count;
        TNODE *left, *right;
    };
TNODE s, *sp;
```

12 EXAMPLE 2 To illustrate the use of pointer declaration of a tag to specify a pair of mutually referential structures, the declaration

```
struct s1 { struct s2 *sp2; /* ... */ }; // D1
struct s2 { struct s1 *sp1; /* ... */ }; // D2
```

specify a pair of structures that contain pointers to each other. However, that if s2 were already declared as a tag in an enclosing scope, the declaration D1 would refer to it, not to the tag s2 declared in D2. To eliminate this sensitivity, the declaration

```
struct s2;
```

may be inserted ahead of D1. This declares a new tag s2 in the inner scope; the declaration D2 then completes the specification of the new type.
