# 7.20.4.2 Macros for greatest-width integer constants

+   1  The following macro expands to an integer constant having the value specified
   by its argument and the type `intmax_t`:


```
INTMAX_C (value)
```

The following macro expands to an integer constant having the value specified
   by its argument and the type `uintmax_t`:

```
UINTMAX_C (value)
```
