# K.3.7.1 Copying functions

# K.3.7.1.1 The memcpy_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
errno_t memcpy_s (void * restrict s1, rsize_t smax,
const void * restrict s2, rsize_t n);
```

# Runtime-constraints

2 Neither s1 nor s2 should be a null pointer. smax nor n shall not be greater than RSIZE_MAX shall not be greater than smax. Copying shall not take place objects that overlap.

3 If there is a runtime-constraint violation, the memcpy_s function sets zeros in the first smax characters of the object pointed to by s1 if s1 is not a null pointer and smax is not greater than RSIZE_MAX.

# Description

4 The memcpy_s function copies n characters from the object pointed to by s2 into the object pointed to by s1.

# Returns

5 The memcpy_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.
