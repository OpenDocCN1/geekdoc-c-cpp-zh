If no such wide character is found, the current token extends to the end of the wide string by sl, and subsequent searches in the same wide string for a token return a null pointer. # EXAMPLE

```
#include <wchar.h>
static wchar_t str1[] = L"?a??b,,#c";
static wchar_t str2[] = L"\t \t";
wchar_t t, *ptr1, *ptr2;

t = wcstock(str1, L, &ptr1);      // t points to the token L"a"
t = wcstock(NULL, L"", &ptr1);     // t points to the token L"??b"
t = wcstock(str2, L"\t", &ptr2);  // t is a null pointer
t = wcstock(NULL, L"#", &ptr1);    // t points to the token L"c"
t = wcstock(NULL, L"?", &ptr1);     // t is a null pointer
```

## 7.29.5 Wide character conversion functions

## 7.29.5.1 The wcsftime function

# Synopsis

```
#include <time.h>
#include <wchar.h>
size_t wcsftime(wchar_t * restrict s,
size_t maxsize,
const wchar_t * restrict format,
const struct tm * restrict timeptr);
```

# Description

- 2 The wcsftime function is equivalent to the strftime function, except that:
The argument s points to the initial element of an array of wide characters into which the generated output is to be placed.
- The argument maxsize indicates the limiting number of wide characters.
- The argument format takes as a wide string and the conversion specifiers are replaced by corresponding sequences of wide characters.
- The return value indicates the number of wide characters.

# Returns

- 3 If the total number of wide characters including the terminating null character is not more than maxsize, the wcsftime returns the number of wide characters placed into the array pointed to by s not including the terminating character. Otherwise, zero is returned and the contents of the array are indeterminate.

## 7.29.6 Extended multibyte/wide character utilities

- 1 The header <wchar.h> declares an extended set of functions useful for conversion between multibyte and wide characters.
- 2 Most of the following functions—those that listed as "restartable", 7.29.6.3 and 7.29.6.4—take as last argument pointer to an object of type mbstate_t that is used to describe the current state from a multibyte character to a wide character (or the reverse) under the rules of a particular setting for the LC_CTYPE category of the current locale.
- 3 The initial conversion state corresponds, for a conversion in either direction, to the beginning of a multibyte in the initial state. A zero-valued mbstate_t is one way to describe an initial state. A zero-valued mbstate_t can be used to initiate conversion involving any multibyte character sequence, if an mbstate_t object has been altered by any of the functions in this subclause or with a different LC_CTYPE setting than earlier calls, the behavior is undefined.
- 4 On entry, each function takes the described state (either internal or pointed to by argument) as current. The conversion state described by the referenced object is altered as needed to track the position within the multibyte character, for the associated multibyte character sequence. Thus, a particular mbstate_t object can be used, for example, with both the mbrtow and mbrtow functions as they are used to step sequentially through the multibyte string.

## 7.29.6.1 Single-byte/wide character functions

### 7.29.6.1.1 The btowc function

# Synopsis

```
#include <wchar.h>
int btowc(int c);
```

# Description

The btowc function determines whether c constitutes a valid single-byte character in the initial state.

# Returns

The btowc returns EOF if c has the value EOF or if c does not constitute a valid single-byte character in the initial state. Otherwise, it returns the character representation of that character.

### 7.29.6.1.2 The wctob function

# Synopsis

```
#include <wchar.h>
int wctob(int c);
```

# Description

The wctob function determines whether c corresponds to a member of the extended character set whose multibyte representation is a single byte in the initial state.

# Returns

The wctob returns EOF if c does not correspond to a multibyte character with length one in the initial state. Otherwise, it returns the single-byte representation of that character as an unsigned char converted to an int.

## 7.29.6.2 Conversion state functions

### 7.29.6.2.1 The mbsinit function

# Synopsis

```
#include <wchar.h>
int mbsinit(const mbstate_t *ps);
```

# Description

If ps is not a null pointer, the mbsinit function determines whether the referenced mbstate_t object describes an initial state.

# Returns

The mbsinit function returns nonzero if ps is a null pointer or if the referenced object describes an initial state; otherwise, it returns zero.

## 7.29.6.3 Restartable multibyte/wide character functions

- These functions differ from the corresponding multibyte character functions of 7.27 (mblen, mbtowc, wctomb) that they have an extra parameter, ps, of type pointer to mbstate_t that points to an object that can completely describe the current conversion state of the associated multibyte character sequence. If ps is a null pointer, each function uses its own internal mbstate_t object instead, which is initialized at program startup to the initial conversion state; the functions are not required to avoid data races with other calls to the same function in this. The implementation behaves as if no library function calls these with a null pointer for ps.
- Also unlike their corresponding functions, the return value does not represent whether the encoding is state-dependent.

### 7.29.6.3.1 The mbrblen function

# Synopsis

```
#include <wchar.h>
size_t mbrblen(const char * restrict s,
               size_t n,
               mbstate_t * restrict ps);
```

# Description

The mbrblen function is equivalent to the call:

```
mbrtowc(NULL, s, n, ps) != NULL ? ps : &internal
```

where internal is the mbstate_t object for the mbrblen function, except that the expression designed by ps is evaluated only once.

# Returns

The mbrblen function returns a value between zero and n, inclusive, (size_t) (-2), or (size_t) (-1).
