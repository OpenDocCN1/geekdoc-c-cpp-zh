# J.2 Undefined behavior

The behavior is undefined in the following circumstances:

+   - “shall” or “shall not” requirement that appears outside of a constraint is violated (clause 4).

+   - A nonempty source file does not end in a line-character which is not immediately preceded by a backslash character or ends in a partial preprocessing token or comment (5.1.1.2).

+   - Token concatenation produces a sequence matching the syntax of a universal character name (5.1.1.2).

+   - A program in a hosted environment does not define a function named main using one of the specified forms (5.1.2.1).
