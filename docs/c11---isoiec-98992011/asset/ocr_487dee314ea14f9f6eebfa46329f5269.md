# 7.24.5.3 The strspn function

# Synopsis

```
1 #include <string.h>
size_t strspn(const char *s1, const char *s2);
```

2 The strspn function computes the length of the maximum initial segment of the string pointed to by s1 which consists entirely of characters not from the string pointed to by s2.

# Returns

3 The strspn function returns the length of the segment.

# 7.24.5.4 The strbrk function

# Synopsis

```
1 #include <string.h>
char *strbrk(const char *s1, const char *s2);
```

# Description

2 The strbrk function locates the first occurrence in the string pointed to by s1 of any character from the string pointed to by s2.

# Returns

3 The strbrk function returns a pointer to the character, or a null pointer if no character from s2 occurs in s1.

# 7.24.5.5 The strchr function

# Synopsis

```
1 #include <string.h>
char *strrchr(const char *s, int c);
```

# Description

2 The strchr function locates the last occurrence of c (converted to a char) in the string pointed to by s. The terminating null character is considered to be part of the string.
