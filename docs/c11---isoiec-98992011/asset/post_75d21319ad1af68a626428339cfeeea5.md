
## 72.4.6 Miscellaneous functions

### 72.4.6.1 The memset function

Synopsis

```
#include <string.h>
void *memset(void *s, int c, size_t n);
```

Description

- The memset function copies the value of c (converted to an unsigned char) into each of the first n characters of the object pointed to by s.

Returns

- The memset function returns the value of s.

### 72.4.6.2 The strerror function

Synopsis

```
#include <string.h>
char *strerror(int errnum);
```

Description

- The strerror function maps the number in errnum to a message string. Typically, the values for errnum come from errno, but strerror shall map any value of type to a message.

- The strerror function is not required to avoid data races with other calls to the strerror function. The implementation shall behave as if no library function calls the strerror function.

Returns

- The strerror function returns a pointer to the string, the contents of which are locale-specific. The array pointed to shall not be modified by the program, but may be overwritten by a subsequent call to the strerror function.

Forward references: The strerror_s function (K.3.7.4.2).

> The strerror_s function can be used instead to avoid data races.

- The strlen function returns the number of characters that precede the terminating null character.

## 7.25 Type-generic math <tgmath.h>

- The header <tgmath.h> includes the headers <math.h> and <complex.h> and defines several type-generic macros.

- Of the <math.h> and <complex.h> functions without an f (float) or l (long double suffix), several have one or more parameters whose corresponding real type is double. For each such function, except modf, there is a corresponding type-generic macro. The parameters whose corresponding real type is double in the function synopsis are generic parameters. Use of the macro invokes a function whose corresponding real type and type domain are determined by the arguments for the generic parameters.

- Use of the macro invokes a function whose generic parameters have the corresponding real type determined as follows:
    - First, if any argument for generic parameters has type long double, the type determined is long double.
    - Otherwise, if any argument for generic parameters has type double or is of integer type, the type determined is double.
    - The type determined is float.

- For each unspecified function in <math.h> for which there is a function in <complex.h> with the same name except for a c prefix, the corresponding type-generic macro (for both functions) has the same name as the function in <math.h>. The corresponding type-generic macro for fabs and cabs is fabs.

> Like other function-like macros in Standard libraries, each type-generic macro can be suppressed to make the corresponding ordinary function.

> If the argument is not compatible with the type of the parameter for the selected function, the behavior is undefined.

## 7.26 Threads <threads.h>

### 7.26.1 Introduction

- The header <threads.h> includes the header <time.h>, defines macros, declares types, enumeration constants, and functions that support threads.

- Implementations that define the macro `_STDC_THREADS__` need not provide this header.

- The macros are:
```cpp
thread_local
```
expands to `_Thread`;
```cpp
ONCE_FLAG_INIT
```
expands to a value that can be used to initialize a once_flag; and
```cpp
TSS_DTOR_ITERATIONS
```
expands to an integer constant representing the maximum number of times destructors will be called when a thread terminates.

- The types are:
```cpp
cnd_t
```
which is a complete object type that holds an identifier for a condition variable;
```cpp
thrd_t
```
which is a complete object type that holds an identifier for a thread;
```cpp
tss_t
```
which is a complete object type that holds an identifier for thread-specific storage;
```cpp
mtx_t
```
which is a complete object type that holds an identifier for a mutex;
```cpp
tss_dtor_t
```
which is the function pointer void (*), used for a destructor for thread-specific storage;

- The enumeration constants are:
```cpp
mtx_plain
```
which is passed to mtx_init to create a mutex object that supports neither timeout nor test and return;
```cpp
mtx_recursive
```
which is passed to mtx_init to create a mutex object that supports recursive locking;
```cpp
mtx_timed
```
which is passed to mtx_init to create a mutex object that supports timeout;
```cpp
thrd_timedout
```
which is returned by a wait function to indicate that the time specified in the call was reached without acquiring the requested resource;
```cpp
thrd_success
```
which is returned by a function to indicate that the requested operation succeeded;
```cpp
thrd_busy
```
which is returned by a function to indicate that the requested operation failed because a resource requested by a test and return function is already in use;
```cpp
thrd_error
```
which is returned by a function to indicate that the requested operation failed; and
```cpp
thrd_nomem
```
which is returned by a function to indicate that the requested operation failed because it was unable to allocate memory.

- The function pointer is:
```cpp
thrd_start_t
```
which is the function pointer type int (*) (void*) that is passed to thrd_create to create a new thread;

- The object is:
```cpp
once_flag
```
which is a complete object that holds a flag for use by call_once.

> See “future directions” (7.31.15).
