## J.2 未定义行为 (Undefined behavior)

在以下情况下行为是未定义的：

+   - 违反出现在约束之外的“应当”或“不应当”要求（第4章）。
+   - 非空源文件未以紧跟在斜杠字符之前的行字符结束，或未以部分预处理标记或注释结束 (5.1.1.2)。
+   - 拼接产生了符合通用字符名称语法的序列 (5.1.1.2)。
+   -宿主环境中的程序未以一种指定的形式定义名为 `main` 的函数 (5.1.2.1)。
