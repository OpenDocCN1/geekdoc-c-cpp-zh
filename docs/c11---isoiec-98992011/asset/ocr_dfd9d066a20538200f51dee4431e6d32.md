# 7.12.13 Floating multiply-add

# 7.12.13.1 The fma functions

# Synopsis

```
#include <math.h>
double fma(double x, double y, double z);
float faf(float x, float y, float z);
long double fmal(long double x, long double y,
long double z);
```

# Description

The fma functions compute (x × y) + z, rounded as ternary operation; compute the value (as if to infinite precision and round once to the result format, according to the current rounding mode. A range error may occur.

# Returns

The fma functions return (x × y) + z, rounded as one ternary operation.

> 242) NaN arguments are treated as missing data: if one is a NaN and the other numeric, then the fmax functions chooses the numeric value. See E.10.9.2.

> 243) The fmin functions are analogous to the fmax functions in their treatment of NaNs.
