# Description

2 The casinh functions compute the complex hyperbolic sine of z, with branch cuts outside the interval [-i, +i] along the imaginary axis.

# Returns

3 The casinh functions return the complex hyperbolic sine value, in the range of a strip mathematically unbounded along the real axis and in the interval [-pi/2, +pi/2] along the imaginary axis.
