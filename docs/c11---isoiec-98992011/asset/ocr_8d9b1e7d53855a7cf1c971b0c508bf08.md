# Constraints

+   2 A-declaration that does not declare an anonymous structure or anonymous union shall contain a struct-declarator-list.

+   3 A structure or union shall not contain a member with incomplete or function type (hence, a structure shall not contain an instance of itself, except that the last member of a structure with more than one named member may have incomplete type; such a structure (and any union containing, possibly recursively, a member that is such structure) shall not be a member of a structure or element of an array.

+   4 The expression that specifies the width of a bit-field is an integer constant expression with a nonnegative value that does not exceed the width of an object of the type that would be specified were the core and expression emitted.¹122 If the value is zero, the declaration shall have no declarator.

+   5 A bit-field has a type that is qualified or unqualified version of _Bool, signed int, unsigned int, or some other implementation-defined type. It is implementation-defined whether atoms are permitted.

> 122 While the number of bits in a _Bool object is at least CHAR_BIT, the width (number of sign and value bits) of _Bool may be just 1.
