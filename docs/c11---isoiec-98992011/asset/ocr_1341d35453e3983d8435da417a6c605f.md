# Returns

If the end-of-file indicator for the stream is set, or if the stream is end-of-file, the end-of-file indicator for the stream is set and the fgetwc function returns the next wide character from the input stream pointed to by stream. If a read error occurs, the error indicator for the stream is set and the fgetwc function returns WEOF. If an encoding error occurs (including too few bytes), the value of the macro ESEQ is set in errno and the fgetwc function returns WEOF.³341

# 7.29.3.2 The fgetwc function

# Synopsis

```
#include <stdio.h>
#include <wchar.h>
char_t *fgetwc(wchar_t * restrict s,
 int, FILE *restrict stream);
```

# Description

The fgetwc function reads at most one the number of wide characters specified by n from the stream pointed to by stream into the array pointed by s. No additional wide characters are read after a new-line wide character (which is retained) or after end-of-file. A null wide character is written immediately after the last wide character read into the array.

# Returns

The fgetwc function returns s if successful. If end-of-file is encountered and no characters have been read into the array, the array remain unchanged and a null pointer is returned. If a read or encoding error occurs during the operation, the array contents are indeterminate and a null pointer is returned.
