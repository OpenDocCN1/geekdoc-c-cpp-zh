# 7.3.5.3 The Catan functions

Synopsis

```
#include <complex.h>
double complex catan(double complex z);
float complex catf(float complex z);
long double complex catanl(long complex z);
```

Description

The catan functions compute the complex tangent of z, with branch cuts outside the interval [-i,+i] along the imaginary axis.

Returns

The catan functions return the complex tangent value, in the range of a strip mathematically unbounded along the imaginary axis and in the interval [-π/2,+π/2] along the real axis.
