# 7.4.1.7 The is function

# Synopsis

```
#include <ctype.h>
int islower(int c);
```

# Description

The islower function tests for any character that is a lowercase letter or is one of a locale-specific set of characters for which none of iscntrl, isdigit, ispunct, or isspace is true. In the "C" locale, islower returns true only for the lowercase letters (defined in 5.2.1).

# 7.4.1.9 The isispunct function

# Synopsis

```
#include <ctype.h>
int ispunct(int c);
```

# Description

The ispunct function tests for any printing character that is one of locale-specific set of punctuation characters for which neither isspace nor isnum is true. In the "C" locale, ispunct returns true for every printing character for which neither isspace nor isnum is true.
