## 6.7.2 Enumeration specifiers

Syntax

+ 1 enum-specifier:
    enum identifier_opt { enumerator-list }
    enum identifier_opt { enumerator-list , }
    enumerator-list:
        enumerator
        enumerator-list , enumerator

    enumeration-constant
    enumeration-constant = constant-expression

# Constraints

+ 2 The expression that defines the value of an enumeration constant shall be an integer constant expression that has a value representable as int.

# Semantics

The identifiers in an enumerator list are declared as constants that have type int and may appear wherever such are permitted.¹27) An enumerator defines its enumeration constant as the value of the constant expression. If the first enumerator has no =, the value of its enumeration constant is 0. Each subsequent enumerator with no = defines its enumeration constant as the value of the constant expression obtained by adding 1 to the value of the previous enumerator. (The use of enumerators with = may produce enumeration constants with values that duplicate other values in the same enumeration.) The enumerators of an enumeration are also known as its members.

Each enumerator type shall be compatible with char, a signed integer, or an unsigned integer. The choice of type is implementation-defined,¹28) but should be capable of representing the values of all members of the enumeration. The enumerator type is incomplete until immediately after the } that terminates the list of enumerator declarations, and complete thereafter.

makes the hue of an enumerator, and declares col as an object that has type and cp as a pointer to that type. The enumerated values are in the set { 0, 1, 20, 21 }.
