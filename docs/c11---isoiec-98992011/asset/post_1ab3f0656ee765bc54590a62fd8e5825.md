# f,F

A double argument representing a floating-point number is converted to decimal notation in the style []ddd.ddd, where the number of digits after the decimal-point character is equal to the precision. If the precision is missing, it is taken as 6; if the precision is zero and the # flag is not specified, no decimal-point character appears. If a decimal-point character appears, at least one digit appears before it. The value is rounded to the appropriate number of digits.

A double argument representing an infinity is converted into one of the styles [-inf or [-infinity — which style is implementation-defined. A double argument representing a NaN is converted into one of the [-nan or [-nan(n-sequence) — which style, and the meaning of any n-sequence, is implementation-defined. The F conversion specifier produces INF, INFINITY, or NAN instead of inf, infinity, or nan.332

# e,E

A double argument representing a floating-point number is converted into the style [-]ddd.dddE, where there is one digit (nonzero if the argument is nonzero) before the decimal-point character and the number of digits after it is equal to the precision; if the precision is missing, it is taken as 6; if the precision is zero and the # flag is not specified, no decimal-point character appears. The value is rounded to the appropriate number of digits. The E conversion specifier produces a number with E instead introducing the exponent. The exponent contains at least two digits, and only as many digits as necessary to represent the exponent. If the value is zero, the exponent is zero.

A double argument representing an infinity or NaN is converted into the style of an f F conversion specifier.

# g,G

A double argument representing a floating-point number is converted into style f or e (or in style E or in the case of a G conversion specifier), depending on the value converted and the precision. Let P equal the precision nonzero, 6 if the precision is omitted, or 1 if the precision is zero. Then, if a conversion with style E would have an exponent of X:

-   if P > X ≥−4, the conversion is with f (or F) and precision P–(X+1).
-   otherwise, the conversion is with style e (or E) and precision P– 1.
