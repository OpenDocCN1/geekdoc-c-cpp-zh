Otherwise, the integer promotions are performed on both operands. Then the following rules are applied to the promoted operands:

+   - If both operands have the same type, no further conversion is needed.
- Otherwise, if both operands have signed integer types or have unsigned integer types, the operand with the type of lesser integer rank is converted to the type of the operand with greater rank.
- Otherwise, if the operand that has unsigned integer type has rank greater or equal to the rank of the other operand, the operand with signed integer type is converted to the type of the operand with unsigned integer type.
- Otherwise, if the type of the operand with signed integer type can represent all of the values of the type of the operand with unsigned integer type, then the operand with unsigned integer type is converted to the type of the operand with signed integer type.
- Otherwise, both operands are converted to the unsigned integer corresponding to the type of the operand with signed integer type.

+   2 The values of floating operands and of the results of floating expressions are represented in greater range and precision than that required by the type; the types are not changed thereby.63)

> 62) For example, addition of a double _Complex and a float entails the conversion of the float operand to double (yields a double _Complex result).
