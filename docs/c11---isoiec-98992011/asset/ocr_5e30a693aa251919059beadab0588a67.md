# 7.11 Localization <locale.h>

1 The header <locale.h> declares two functions, one type, and defines several macros.

2 The type is

```
struct lconv
which contains members related to the formatting of numeric values. The structure should\contain at least the following members, in any order. The semantics of the members and
them ranges are explained in 7.11.2.1. In the "C" locale, the members shall have
values specified in the comments.

char *decimal_point;      // ""
char *thousands_sep;      // ""
char *grouping;            // ""
char *mon_decimal_point;   // ""
char *mon_thousands_sep;  // ""
char *mon_grouping;        // ""
char *positive_sign;       // ""
char *negative_sign;       // ""
char *currency_symbol;     // ""
char frac_digits;          // CHAR_MAX
char *p_cs_precedes       // CHAR_MAX
char n_cs_precedes        // CHAR_MAX
char p_sep_by_space;      // CHAR_MAX
char n_sep_by_space;      // CHAR_MAX
char p_sign_posn;         // CHAR_MAX
char n_sign_posn;         // CHAR_MAX
char *int_curr_symbol;    // ""
char int_frac_digits;      // CHAR_MAX
char int_p_cs_precedes    // CHAR_MAX
char int_n_cs_precedes    // CHAR_MAX
char int_p_sep_by_space;  // CHAR_MAX
char int_n_sep_by_space;  // CHAR_MAX
char int_p_sign_posn;     // CHAR_MAX
char int_n_sign_posn;     // CHAR_MAX
```
