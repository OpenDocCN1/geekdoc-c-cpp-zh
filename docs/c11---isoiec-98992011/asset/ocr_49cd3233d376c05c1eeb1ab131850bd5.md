# 7.20.4 Macros for integer constants

+   1 The function-like macros expand to integer constants suitable for initializing objects that have types defined in <stdint.h>. Each macro name corresponds to a similar type in 7.20.1.2 or 7.20.1.5.

+   2 The argument in any instance of these macros shall be an unsuffixed integer constant (as defined in 6.4.4.1) with a value that does not exceed the limits for the corresponding type.

+   3 Each invocation of one of these macros shall expand to an integer expression suitable for use in #if preprocessor directives. The type of the expression shall have the same type as would be an expression of the corresponding type converted according to the integer promotions. The value of the expression shall be that of the argument.

# 7.20.4.1 Macro for minimum-width integer constants

+   1 The macro INT_t (value) shall expand to an integer expression corresponding to the type int_least_N_t. The macro UINT_N_t (value) shall expand to an integer constant expression corresponding to the type uint_least_N_t. For example, if uint_least_64_t is a name for the type unsigned long int, then UINT64_C (0x123) might expand to the integer constant 0x123ULL.
