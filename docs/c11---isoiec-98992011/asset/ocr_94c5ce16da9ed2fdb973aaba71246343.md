# Semantics

An integer character has type int. The value of an integer constant containing a single character that maps to a single-byte execution character is the numerical value of the representation of the mapped character interpreted as the integer. The value of integer character constant containing more than one character (e.g., 'ab'), or containing a character or escape sequence that does not map to a single-byte execution character, is implementation-defined. If an integer constant contains a single character or escape sequence, its value is the one that results when an object type char whose value is that of the single character or escape sequence is converted to int.

A wide character prefixed by the letter L has type wchar_, an integer type defined in the <stddef.h> header; a wide character prefixed by the letter u or U has type char16_t or char32_t, respectively, unsigned integer types defined in the <uchar.h> header. The value of a wide character containing a single multibyte character corresponding to the extended execution character set is the wide character as defined by the mbtwc, mbrtoc16, or mbrtoc32 function as its type, with an implementation-defined current value. The value of a wide character containing more than one multibyte character or single multibyte character that maps to members of the extended execution character set, or containing a multibyte character not represented in the extended execution character set, is implementation-defined.
