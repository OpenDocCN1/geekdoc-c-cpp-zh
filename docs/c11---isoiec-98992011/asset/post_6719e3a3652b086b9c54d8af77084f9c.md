## K.3.7.3 Search functions

### K.3.7.3.1 The strtok_s function

#### Synopsis

```
#define _STDC_WANT_LIB_EXT1__ 1
#include <string.h>
char strtok_s(char * restrict s1,
               size_t * restrict slmax,
               const char * restrict s2,
               char ** restrict ptr);
```

#### Runtime-constraints

-   None of slmax, or ptr shall be a null pointer. If s1 is a null pointer, *ptr shall not be a null pointer. The value of *slmax shall not be greater than RSIZE_MAX. The end of the token shall occur within the first *slmax characters of the first call, and shall occur within the first *slmax characters of searching resumes on subsequent calls.
-   If there is a runtime-constraint, the strtok_s function does not indirect through the s1 or s2 pointers, and does not store a value in the object pointed to by ptr.

#### Description

-   A sequence of calls to the strtok_s function breaks the string pointed to by s1 into a sequence of tokens, each of which is delimited by a character from the string pointed to by s2. The fourth argument points to a caller-provided char pointer into which to continue scanning the strtok_s stores information necessary for it to continue scanning the string.

-   The first call in a sequence has a non-null first argument and slmax points to an object whose value is the number of elements in the character array pointed to by the first argument. The first call stores an initial value in the object pointed to by and updates the value pointed by slmax to reflect the number of elements that remain in relation to ptr. Subsequent calls in the sequence have a null first argument and the objects pointed to by slmax and ptr are required to have the values stored by the previous call in the sequence, which are updated. The separator string pointed to by s2 may differ from call to call.

-   The first call in the sequence searches the string pointed to by s1 for the first character that is not contained in the current string pointed to by s2. If no such character is found, then there are no tokens in the string pointed to by s1 and the strtok_s returns a null pointer. If such a character is found, it is the start of the first token.

7 The strtok_s function searches from there for the first character in s1 that is contained in the separator string. If no such character is found, the current token extends to the end of the string pointed to by s1, and subsequent searches in the same string for a token return a null pointer. If such a character is found, it is overwritten by a null character, which terminates the current.

8 In all cases, the strtok_s function provides sufficient information in the pointer pointed to by ptr so that subsequent calls, with a null pointer for s1 and the unmodified pointer value for ptr, start searching just the element overwritten by a null character (if any).

#### Returns

9 The strtok_s function returns a pointer to the first character of a token, or a null pointer if there is no token or a runtime-constraint violation.

#### 10 EXAMPLE

```
#define _STDC_WANT_LIB_EXT1_ 1
#include <string.h>
static char str1[] = "???b,#c";
static char str2[] = "\t \t";
char *t, *ptr1, *ptr2;
size_t max1 = sizeof(str1);
size_t max2 = sizeof(str2);
t = strtok_s(str1, max1, "?", &ptr1); // t points to the token "a"
t = strtok_s(NULL, max1, "#", &ptr1); // t points to the token "??b"
t = strtok_s(str2, max2, "#", &ptr2); // t is a null pointer
t = strtok_s(NULL, max1, "#", &ptr1); // t points to the token "c"
t = strtok_s(NULL, max1, "?", &ptr1); // t is a null pointer
```

#### Synopsis

```
#define _STDC_WANT_LIB_EXT1_ 1
```

#### Runtime-constraints

s shall not be a null pointer. Neither smax nor n shall be greater than RSIZE_MAX. n shall not be greater than smax.

### K.3.7.4.2 The strerror_s function

#### Synopsis

```
#define _STDC_WANT_LIB_EXT1_ 1
#include <string.h>
errno_t strerror_s(char *s, size_t maxsize, errno_t errum);
```

#### Runtime-constraints

-   s shall not be a null pointer. maxsize shall not be greater than RSIZE_MAX. maxsize shall not equal zero.
-   If there is a runtime-constraint violation, the array (if any) pointed to s is not modified.

#### Description

-   The strerror_s function copies the number in errum to a locale-specific message. Typically, the values for errum come from errno.
-   If the length of the desired string is less than maxsize, the string is copied to the array pointed to s.
-   Otherwise, if maxsize is greater than zero, maxsize-1 characters are copied from the string to the array pointed to s and s[maxsize-1] is set to the null character. Then, if maxsize is greater than 3, s[maxsize-2], s[maxsize-3], and s[maxsize-4] are set to the period.

#### Returns

The strerror_s function returns zero if the length of the desired string was less than maxsize and there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

### K.3.7.4.3 The strerrorlen_s function

#### Synopsis

```
#define _STDC_WANT_LIB_EXT1__ 1
#include <string.h>
size_t strerrorlen_s(errno_t errnum);
```

#### Description

The strerrorlen_s function calculates the length of the (untruncated) locale-specific message string that the strerror_s function maps to errno.

#### Returns

The strerrorlen_s function returns the number of characters (not including the null character) in the full message string.

### K.3.7.4.4 The strlen_s function

#### Synopsis

```
#define _STDC_WANT_LIB_EXT1__ 1
#include <string.h>
size_t strlen_s(const char *s, size_t maxsize);
```

#### Description

The strlen_s function computes the length of the string pointed to by s.

#### Returns

-   If s is a null pointer, then the strlen_s function returns zero.
-   Otherwise, the strlen_s function returns the number of characters that precede the terminating null. If there is no null character in the first maxsize characters of s then strlen_s returns maxsize. At most the first maxsize characters of s shall be accessed by strlen_s.
