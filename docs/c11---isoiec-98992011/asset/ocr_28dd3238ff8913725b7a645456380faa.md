14 EXAMPLE 5 Rearrangement for floating-point operations is often restricted because of the
precision as well as range. The implementation cannot generally apply the mathematical rules
for addition or multiplication, not the distributive rule, because of rounding error, in the absence of
overflow and underflow. In the following fragment, rearrangements cannot replace decimal constants in order to
rearrange expressions. rearrangements suggested by mathematical rules for real
numbers are not valid (see F.9).

```
double x, y, z;
/* ... */
x = (x * y) * z; // not equivalent to x = y * z;
z = (x - y) + y; // not equivalent to z = x;
z = z + x * y; // not equivalent to z = x * (1.0 + y);
y = x / 5.0; // not equivalent to y = x * 0.2;
```
