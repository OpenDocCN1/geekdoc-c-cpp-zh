__STDC_VERSION__ The integer constant 201ymmL^{178)}

__TIME__ The time of translation of the preprocessing unit: a character string literal of the time "hh:mm:ss" as in the time generated by the asctime function. If the translation is not available, an implementation-defined valid time will be supplied.

**Forward references:** the asctime function (7.27.3.1).

# 6.10.8.2 Environment macros

+   1 The following macros are conditionally defined by the implementation:
   __STDC_ISO_10646__ An integer constant of the form yyyymmL (for example, 19972L). If this symbol is defined, then every character in the Unicode required set, when stored in an object of type wchar_t, has the same value as the short identifier of that character. The Unicode required set consists of all the characters that are defined by ISO/IEC 10646, along with all amendments and technical corrigenda, as of the specified year and month. If other encoding is used, the macro shall not be defined and the actual encoding used is implementation-defined.
   __STDC_MB_MIGHT_NEQ__ The integer constant 1, intended to indicate that, the encoding for a member of the basic character set not have a code value equal to its value used as the lone character in an integer constant.
   __STDC_UTF_16__ The integer constant 1, intended to indicate that values of type char16_t are UTF-16 encoded. If some other encoding is used, the macro shall not be defined and the actual encoding used is implementation-defined.
   __STDC_UTF_32__ The integer constant 1, intended to indicate that values of type char32_t are UTF-32 encoded. If some other encoding is used, the macro shall not be defined and the actual encoding used is implementation-defined.

**Forward references:** common definitions (7.19), unicode utilities (7.28).

> 178) This macro was not specified in ISO/IEC 9899:1990 and was specified as 199409L in ISO/IEC 9899:1990/Amd.1:1995 and as 199501L in ISO/IEC 9899:1999. The intention is that this will remain an integer constant of type long that is created with each revision of this International Standard.
