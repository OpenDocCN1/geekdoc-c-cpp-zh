## 7.21.6.5 The sprintf function

Synopsis

```c
#include <stdio.h>
int sprintf(char * restrict s, size_t n,
const char * restrict format, ...);
```

Description

The sprintf function is equivalent to fprintf, except that the output is written into an array (by argument s) rather than a stream. If n is zero, nothing is written, and s may be a null pointer. Otherwise, output characters beyond the n-1 are discarded before being written to the array, and a null character is written at the end of the characters actually written into the array. If copying takes place between objects that overlap, the behavior is undefined.

Returns

The sprintf function returns the number of characters that would have been written had n sufficiently large, not counting the null character, or a negative value if an encoding error occurred. Thus, the null-terminated output has been completely written if only if the returned value is nonnegative and less than n.
