# Annex H

(informative)

# Language independent arithmetic

# H.1 Introduction

+   1. This annex documents the extent to which the C language supports the ISO/IEC 10967–1 standard for language-independent arithmetic (LIA–1), LIA–1 is more general than IEC 60559 (Annex F) in that it covers integer diverse floating-point arithmetic.

+   1. The relevant C types meet the requirements of LIA–1 types if an implementation adds notification of exceptional arithmetic operations and meets the 1 unit in the last place (ULP) accuracy requirement (LIA–1 clause 5.2.8).

# H.2 Types

+   1. The LIA–1 data type Boolean is implemented by the C data type bool with values of true and false, all from <stdbool.h>.

# H.2.2 Integer types

+   1. The signed C types int, long int, long long int, and the corresponding unsigned types are compatible with LIA–1. If an implementation adds support for the LIA–1 exceptional values “overflow” and “undefined”, then those are LIA–1 conform types. C’s unsigned integer types are “modulo” in the LIA–1 sense that overflows or out-of-bounds results wrap silently. An implementation that defines signed integer types as being modulo does not detect integer overflow, in which case, only integer divide-by-zero may be detected.

+   2. The parameters for the integer data types can be accessed by the following:

```
INT_MAX, LONG_MAX, LLONG_MAX, UINTINT_MAX, ULONG_MAX,
       ULLONG_MAX
```

```
INT_MIN, LONG_MIN, LLONG_MIN
```

+   3. The parameter “bounded” is always true, and is not provided. The parameter “minint” is 0 for the unsigned types, and is not provided for those types.
