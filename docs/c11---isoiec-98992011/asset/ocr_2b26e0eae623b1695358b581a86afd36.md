# Description

+   4 The `strncpy_s` function copies the string pointed to by `s2` (including the terminating null character) into the array pointed to by `s1`.

+   5 All elements following the terminating null character (if any) written by `strncpy_s` in the array of `slmax` characters pointed to by `s1` take unspecified values when `strncpy_s` returns.

# Returns

+   6 The `strncpy_s` function returns `zero`¹⁴¹⁹ if there is no runtime-constraint violation. Otherwise, a nonzero value is returned.

# K.3.7.1.4 The strncpy_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT__ 1
#include <string.h>
errno_t strncpy_s(char * restrict s1,
               size_t slmax,
               const char * restrict s2,
               size_t n);
```

# Runtime-constraints

+   2 Neither `s1` `s2` should be a null pointer. `slmax` nor `n` shall be greater than `RSIZE_MAX`. `slmax` shall not be equal. If `n` is not less than `slmax`, `slmax` shall be greater than `strlen(s2, slmax)`. Copying shall not take between objects that overlap.

+   3 If there is a runtime-constraint violation, if `s1` is not a null pointer and `n` is greater than zero and not greater than `RSIZE_MAX`, `strncpy_s` sets `s1[0]` to the null character.

# Description

+   4 The `strncpy_s` function copies not more than `n` successive characters (characters that follow a null character are not copied) from the array pointed to by `s2` to the array pointed to by `s1`. If no null character was copied from `s2`, `s1[n]` is set to a null character.

> 418) This allows an implementation to copy characters from `s2` to `s1` while simultaneously checking if any of those characters are. Such an approach might write every character to the first element should be set to the null character.

> 419) A zero return value implies all of the requested characters from the string pointed to by `s2` fit within the array pointed by `s1` and that the result in `s1` is terminated.
