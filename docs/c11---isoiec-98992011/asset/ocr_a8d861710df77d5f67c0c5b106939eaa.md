# 7.22.4.3 The at_quick_exit function function

Synopsis

```
#include <stdlib.h>
int at_quick_exit(void (*func) (void));
```

Description
at_quick_exit function registers the function pointed to by func, to be called without arguments should quick_exit be called. It is unspecified whether a call to the at_quick_exit function that does not happen before the quick_exit function is will called.

Environmental limits

The implementation should support the registration of at least 32 functions.

Returns

The at_quick_exit function returns zero if the registration succeeds, nonzero if it fails.

Forward references: the quick_exit exit function (7.22.4.7).

# 7.22.4.4 The exit function

Synopsis

```
#include <stdlib.h>
_Nturn void exit(int status);
```

Description

The exit function causes normal program termination to occur. No functions registered by the at_quick_exit function are called. If a program calls the exit function more than once, or calls the quick_exit function in addition to the exit function, the behavior is undefined.

First, all functions by the atexit are called, in the reverse order of their registration, except that a function called after previously registered functions that had already been called at the time it was registered. If, during the call to any such function, a call to the longjump function is made that would terminate the registered function, the behavior is undefined.

> 298 The at_quick_exit function are distinct from the atexit registrations, so applications may need to call both registration functions with the same argument.
299 Each function is called as many times as it is registered, and in the correct order with respect to other registered functions.
