## 7.29.3.2 The fgetwc function

### Synopsis

```
#include <stdio.h>
#include <wchar.h>
wchar_t *fgetwc(wchar_t * restrict s,
 int, FILE *restrict stream);
```

### Description

The fgetwc function reads at most one number of wide characters specified by n from the stream pointed to by stream into the array pointed by s. No additional wide characters are read after a new-line wide character (which is retained) or after end-of-file. A null wide character is written immediately after the last wide character read into the array.

### Returns

The fgetwc function returns s if successful. If end-of-file is encountered and no characters have been read into the array, the array remain unchanged and a null pointer is returned. If a read or encoding error occurs during the operation, the array contents are indeterminate and a null pointer is returned.

## 7.29.3.3 The fputwc function

### Synopsis

```
#include <stdio.h>
#include <wchar.h>
int_t fputwc(wchar_t c, FILE *stream);
```

### Description

The fputwc function writes the wide character specified by c to the output stream pointed to by stream, at the position indicated by the associated file position indicator for the stream (if defined), and advances the indicator appropriately. If the cannot support positioning requests, or if the stream was opened with append mode, the character is appended to the output stream.

### Returns

- 3 The fputwc function returns the wide character written. If a write error occurs, the error indicator for the stream is set and fputwc returns WEOF. If an encoding error occurs, the value of the macro EISEQ is stored in errno and fputwc returns WEOF.

## 7.29.3.4 The fputwc function

### Synopsis

```
#include <stdio.h>
#include <wchar.h>
int fputwc(const wchar_t * restrict s,
FILE * restrict stream);
```

### Description

- 2 The fputwc function writes the wide string pointed to by s to the stream pointed to. The terminating null wide character is not written.

### Returns

- 3 The fputwc function returns EOF if a write error or encoding error occurs; otherwise, it returns a nonnegative value.

## 7.29.3.5 The fwide function

### Synopsis

```

#include <wchar.h>
int fwide(FILE *stream, int mode);
```

### Description

- 2 The fwide function determines the orientation of the stream pointed to by stream. If mode is greater than zero, the function first attempts to make the stream wide oriented. If mode is less than zero, the function first attempts to make the stream wide oriented.^{342 Otherwise, mode is zero and the function does not alter the orientation of the stream.

### Returns

## 7.29.3.6 The getwc function

### Synopsis

```
#include <stdio.h>
#include <wchar.h>
wint_t getwc(FILE *stream);
```

### Description

The getwc function is equivalent to fgetwc, except if it is implemented as a macro, it may evaluate stream more than once, so the argument should never be an expression with side effects.

### Returns

The getwc function returns the next character from the input stream pointed to by stream, or WEOF.

## 7.29.3.7 The getwchar function

### Synopsis

```
#include <wchar.h>
wint_t getwchar(void);
```

### Description

The getwchar function is equivalent to getwc with the argument stdin.

### Returns

The getwchar function returns the next character from the input stream pointed to by stdin, or WEOF.

## 7.29.3.10 The ungetwchar function

### Synopsis

```
#include <stdio.h>
#include <wchar.h>
wint_t ungetwchar(wchar_t c, FILE *stream);
```

### Description

The ungetwchar function pushes the wide character specified by c back onto the input stream pointed to by stream. Pushed-back wide characters will be returned by subsequent reads on stream in reverse order of their pushing. A successful intervening call (with the stream pointed to) file positioning call (fseek, fsetpos, or rewind) discards any pushed-back wide characters for the stream. The external storage corresponding to the stream is unchanged. One order of pushback is guaranteed, if the call to ungetwchar follows just after a call to a formatted wide character function fscanf, fwscanf, vfscanf, or wscanf. If ungetwchar function is called too many times on the same stream without an intervening read or file positioning operation on that stream, the operation may fail. If the value of c equals the macro WEOF, the operation fails and the input stream is unchanged. A successful call to ungetwchar function clears the end-of-file indicator for the stream. The value of the file positioning indicator for the stream after reading or discarding all pushed-back wide characters is the same as it was before the wide characters were pushed back. For a text or binary stream, the value of its position indicator after a successful call is unspecified until all pushed-back wide characters are read or discarded.

The ungetwchar function returns the character pushed back if the operation fails.

## 7.29.4 General wide string utilities

The header <wchar.h> declares a number of functions useful for wide string manipulation. Various methods are used for determining the lengths of the arrays, but in all cases a wchar_t * argument points to the initial (lowest addressed) element of the array. If an array is accessed beyond the end of an object, the behavior is undefined.

Where an argument declared as size_t n determines the length of the array for a function, n can have the value zero on a call to that function. Unless explicitly stated otherwise in the description of a particular function in this clause, pointer arguments on such a call shall still have valid values, as described in 7.1.4. On such a call, a function that finds no occurrence, a function that compares two wide character sequences returns zero, and a function that copies wide characters copies zero characters.

## 7.29.4.1 Wide string conversion functions

### 7.29.4.1.1 The wcstod, wcsof, and wcstold

### Synopsis

```
#include <wchar.h>
double wcstod(const wchar_t * restrict nptr,
wchar_t ** restrict endptr);
float wcsof(const wchar_t * restrict nptr,
wchar_t ** restrict endptr);
long double wcstold(const wchar_t * restrict nptr,
wchar_t ** restrict endptr);
```

### Description

The wcstod, wcsof, and wcstold convert the initial portion of the wide string pointed to double, float, and long double representation, respectively. They decompose the input string into three parts: an initial, possibly empty, sequence of white-space wide characters (as specified by the isspace function), a sequence resembling a floating-point constant or representing an infinity or NaN; a wide final of one or more unrecognized characters, including the terminating null character of the input string. They attempt to convert the sequence to a floating-point number, and return the result.
