## G.5.2 Additive operators

### Semantics

- 1 If both operands have imaginary type, the result has imaginary type. (If one operand has real type and the other operand has imaginary type, or if either operand has complex type, then the result has complex type.)

- 2 In all cases and floating-point exception behavior of a + - operator is defined by the usual mathematical formula:

| + or - | | | u + iv |
|---|---|---|---|
| n | x | x ± u | x ± iv | (x ± u) ± iv |
| iy | ± u + iy | i(y ± v) | ± u + i(y ± v) |
| x + iy | (x ± u) + iy | x + i(y ± v) | (x ± u) + i(y ± v) |

## G.6 Complex arithmetic <complex.h>

- 1 The macros `imaginary` and `_Imaginary_I` are defined, respectively, as `_Imaginary` and a constant expression of type float `Imaginary` with the value of the imaginary unit. The macro `I` is defined to be `_Imaginary_I` (not `_Complex_I` as stated in 7.3). Notwithstanding the provisions of 7.1.3, a program may define and then redefine the macro imaginary.

- 2 This clause contains specifications for the <complex.h> functions that are particularly suited to IEC 60559 implementations. For families of functions, the specifications apply to all of the functions even if only the principal function is shown. Unless otherwise specified, where the symbol “±” occurs in both argument and the result, the result has the same sign as the argument.

The functions are continuous onto both sides of their branch cuts, taking into account the sign of zero. For example, csqrt(-2±0) = ±√2.

Since complex and imaginary values are considered of real values, each function being regarded as complex values from real values. As noted, the functions treat real infinities, NaNs, signed zeros, subnormals, and the floating-point exception flags in a manner consistent with the specifications for real functions in F.10.378.

The functions cimag, conj, cproj, and creal are fully specified for all implementations, including IEC 60559 ones, in 7.3.9. These functions raise no floating-point exceptions.

Each of the functions cabs and carg is specified by a formula in a real function (whose special cases are covered in annex F):

```c
cabs(x + iy) = hypot(x, y)
carg(x + iy) = atan2(y, x)
```

Each of the functions casin, ccat, ccos, and ctan is specified implicitly by a formula in terms of other complex functions (whose special cases are specified below):

```c
casin(z) = - casin(z)
catan(z) = - catanh(z)
ccos(z) = ccosh(z)
csin(z) = - csinh(z)
ctan(z) = - ctanh(z)
```

For the others, the following subclauses specify behavior for special cases, including treatment of the “invalid” and “divide-by-zero” floating-point exceptions. For families of functions, the specifications apply to all of the functions except only the principal function. For a function f satisfying conj(f(z))=conj(z), the specifications for the upper half-plane imply the specifications for the lower half-plane; if the f is also even, f(-z) = f(z), or f(-z) = -f(z), then the specifications for the first quadrant imply the specifications for the other three quadrants.

In the subclauses, cisin(y) is defined as cos(y) + i sin(y).

As noted in G.3, a complex value with at least one infinite part is regarded as an infinity even if its part is a NaN.

## G.6.1 Trigonometric functions

### G.6.1.1 The cacos functions

- - cacos (conj (z)) = conj (cacos (z))
- cacos (±0 + i0) returns π/2 - i0.
- cacos (±0 + iNaN) returns π/2 + iNaN.
- cacos (x + ∞) returns π/2 - ∞, for finite x.
- cacos (x + iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for nonzero x.
- cacos (-∞ + iy) returns π - ∞, for positive-signed y.
- cacos (+∞ + iy) returns +0 - ∞, for positive-signed y.
- cacos (-∞ + ∞) returns 3π/4 - ∞.
- cacos (+∞ + ∞) returns π/4 - ∞.
- cacos (±∞ iNaN) returns NaN ± ∞ (where the sign of imaginary part of the result is unspecified).
- cacos (NaN + iy) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite y.
- cacos (NaN + ∞) returns NaN - ∞,
- cacos (NaN + iNaN) returns NaN + iNaN.

## G.6.2 Hyperbolic functions

### G.6.2.1 The cacosh functions

- cacosh (conj (z)) = conj (cacosh (z))
- cacosh (±0 + i0) returns +0 + i/2.
- cacosh (x + ∞) returns +∞ + i/2, for finite x.
- cacosh (x + iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite x.
- cacosh (-∞ + iy) returns -∞ + iπ, for positive-signed y.
- cacosh (+∞ + iy) returns +∞ + i0, for positive-signed y.
- cacosh (-∞ + ∞) returns +∞ + iπ/4.
- cacosh (+∞ + ∞) returns +∞ + iπ/4.
- cacosh (±∞ iNaN) returns +∞ + iNaN.
- cacosh(NaN + iy) returns NaN + iNaN and-- for finite y.
- cacosh(NaN + ∞) returns NaN + iNaN.
- cacosh(NaN + iNaN) returns NaN + iNaN.

### G.6.2.2 The casinh functions

- casinh (conj (z)) = conj (casinh (z)) and casinh is odd.
- casinh(+0 + i0) returns 0 + i0.
- casinh(x + ∞) returns ∞ + i/2 for positive-signed x.
- casinh(x + iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite x.
- casinh(+∞ + iy) returns ∞ + i0 for positive-signed y.
- casinh(∞ + ∞) returns ∞ + iπ/4.
- casinh(NaN + iNaN) returns ∞ + iNaN.
- casinh(NaN + i0) returns NaN + i0.
- casinh(NaN + iy) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for nonzero y.
- casinh(NaN + ∞) returns ±∞ + iNaN (where the sign of real part of the result is unspecified).
- casinh(NaN + iNaN) returns NaN + iNaN.

### G.6.2.3 The catanh functions

- catanh(conj (z)) = conj(catanh (z)) and catanh is odd.
- catanh(+0 + i0) returns +0 + i0.
- catanh(+0 + iNaN) returns +0 + iNaN.
- catanh(+1 + i0) returns +∞ + i0 and raises the “divide-by-zero” floating-point exception.
- catanh(x + ∞) returns ∞ + i/2, for positive-signed x.
- catanh(x + iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for nonzero finite x.
- catanh(+0 + iy) returns +0 + i/2, for positive-signed y.
- catanh(+0 + ∞) returns +∞ + i/2.
- catanh(+0 + iNaN) returns +0 + iNaN.
- catanh(NaN + iy) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite y.
- catanh(NaN + ∞) returns ±0 + iπ2 (where the sign of real part of the result is unspecified).
- catanh(NaN + iNaN) returns NaN + iNaN.

### G.6.2.4 The ccosh functions

- ccosh(conj(z)) = conj(ccosh (z)) and ccosh is even.
- ccosh(+0 + i0) returns 1 + i0.
- ccosh(+0 + ∞) returns NaN±i0 (where the sign of the imaginary part of the result is unspecified) and raises the “invalid” floating-point exception.
- ccosh(+0 + iNaN) returns NaN±i0 (where the sign of the imaginary part of the result is unspecified).
- ccosh(x + ∞) returns NaN + iNaN and raises the “invalid” floating-point exception, for finite nonzero x.
- ccosh(x + iNaN) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for finite nonzero x.
- ccosh(+0 + i0) returns ∞ + i0.
- ccosh(+0 + iy) returns cis(y), for finite nonzero y.
- ccosh(+0 + ∞) returns ∞ +iNaN (where the sign of the real part of the result is unspecified) and raises the “invalid” floating-point exception.
- ccosh(+0 + iNaN) returns ∞ + iNaN.
- ccosh(NaN + i0) returns NaN±i0 (where the sign of the imaginary part of the result is unspecified).
- ccosh(NaN + iy) returns NaN + iNaN and optionally raises the “invalid” floating-point exception, for all nonzero y.
- ccosh(NaN + iNaN) returns NaN + iNaN.
