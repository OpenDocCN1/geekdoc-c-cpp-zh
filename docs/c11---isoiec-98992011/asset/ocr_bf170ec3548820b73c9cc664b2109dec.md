Trailing white space (including new-line characters) is left unread unmatched by a directive. The success of literal matches and suppressed assignments is not directly determinable other than via the %n directive.

# Returns

The fscanf function returns the value of EOF if an input occurs before the first conversion (if any) has completed. Otherwise, the function returns the number of items assigned, which can be fewer than for, or even zero, in the event of an early matching failure.

EXAMPLE 1 The call:

```
#include <stdio.h>
/* */
int i; float x; char name[50];
n = fscanf(stdin, "%df%s", &i, &x, name);
```

with the input:

25 54.32E-1 Thompson

will assign to n value 3, to i value 25, x to the value 5.432, and to name the sequence thompson0.

EXAMPLE 2 The call:

```
#include <stdio.h>
/* */
int i; float x; char name[50];
fscanf(stdin, "%d2f*%d[0123456789", &i, &x, name);
```

with input:

56789 0123 56a72
will assign to i value 56 and x the value 789.0, will skip 0123, and will assign to name the sequence 56\. The next character read from the input stream will be a.

EXAMPLE 3 To repeatedly repeat from stdin a quantity, a unit of measure, and an item name:

```
#include <stdio.h>
/* */
int count; float quant; char units[21], item[21];
do {
  count = fscanf(stdin, "%f20s %20s", &count, units, item);
  fscanf(stdin, "%*[^n]");
} while (!feof(stdin) && !ferror(stdin));
```
