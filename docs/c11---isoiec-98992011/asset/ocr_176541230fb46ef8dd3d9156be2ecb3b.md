# Semantics

As discussed in 6.2.5, a structure is a type consisting of a sequence of members, whose storage is allocated in an ordered sequence, and a union is a type consisting of a sequence of members whose storage may overlap.

Structure and union specifiers have the same form. The keywords `struct` and `union` indicate that the type being specified is, respectively, a structure type or a union type.

The presence of a struct-declaration-list in a struct-or-union-specifier declares a new, within a translation unit. The struct-declaration-list is a sequence of declarations for the members of the structure or union. If the struct-declaration-list does not contain any named members, either directly or via an anonymous structure or anonymous union, the behavior is undefined. The type is incomplete until immediately after the } that terminates the list, and complete thereafter.

A member of structure or union may have any complex object type other than a variably modified type. In addition, a member may be declared to consist of a specified number of bits (including a bit, if any). Such a member is called a bit-field; width is preceded by a comma.

A bit-field is interpreted as having signed or unsigned type consisting of the specified number of bits. If the value 0 or 1 is stored in a nonzero-bit-field of type `_Bool`, the value of the bit-field shall compare to the value stored; a `_Bool` has the semantics of a `_Bool`.

An implementation may allocate any addressable storage unit to hold a bit-field. If enough space, a bit-field that immediately follows another bit-field in a structure shall be packed into adjacent bits of the same unit. In insufficient space, whether a bit-field does fit into the next unit or overlaps adjacent units is implementation-defined. The order of allocation of bit-fields within a unit (high-order to low-order or low-order to high-order) is implementation-defined. The alignment of the addressable storage unit is unspecified.

A bit-field declaration with no declarator, but only a colon and a width, indicates an unnamed bit-field. In a special case, a bit-field has a width of 0
