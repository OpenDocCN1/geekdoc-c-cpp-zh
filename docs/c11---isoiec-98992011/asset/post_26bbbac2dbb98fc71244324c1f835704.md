## F.10.6 Nearest integer functions

### F.10.6.1 The ceil functions

+ 1 — ceil(±0) returns ±0.
+ — ceil(±∞) returns ±∞.

#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double ceil(double x)

### F.10.6.4 The rint functions

The rint functions differ from the nearbyint functions only in that they raise the “inexact” floating-point exception if the result differs value from the argument.

### F.10.6.5 The llint and llrint functions

The llint and llrint functions provide floating-to-integer conversion as prescribed by IEC 60559. They round according to the current rounding direction. If the rounded value is outside the range of the return type, the numeric result is unspecified and the “invalid” floating-point exception is raised. When there is no other floating-point exception and the result differs from the argument, they raise the “inexact” floating-point exception.

### F.10.6.6 The round functions

+ - round (±0) returns ±0.
- round (±∞) ±∞.

The returned value is independent of the current rounding direction implemented by

```
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double round (double x)
{
    double result;
    fenv_t save_env = fetchenv(&save_env);
    result = rint(x);
    if (fetestexcept(FE_INEXACT)) {
        fesetround(FE_TOWARD);
        result = copysign(0, x);
    }
    feupdateenv(save_env);
    return result;
}
```
The round functions may, but are not required, to raise the “inexact” floating-point exception for finite non-integer arguments, as this implementation does.

## F.10.9 Maximum, minimum, and positive difference functions

### F.10.9.1 The fdim functions

No additional requirements.

### F.10.9.2 The fmax functions

If one argument is a NaN, the **fmax** functions return the other argument (if both arguments are NaNs, the functions return a NaN).

The returned value is exact and is independent of the current rounding direction mode.

The body of the **fmax** function must be

```c
return { isgreaterequal(x, y) || isnan(y)) ? x : y; }
```

### F.10.9.3 The fmin functions

The **fmin** functions are analogous to the **fmax** functions (see F.10.9.2).

The returned value is exact and is independent of the current rounding direction mode.
