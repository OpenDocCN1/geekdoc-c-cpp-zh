29 EXAMPLE 6 The declaration

```
short q[4][3][2] = {
  { 1 },
  { 2, 3 },
  { 4, 5, 6 }
};
```

contains an implicitly but consistently bracketed initialization. It defines a three-dimensional array object: q[0][0][0] is 1, q[1][0][0] is 2, q[1][0][1] is 3, 4, 5, and 6 initialize q[2][0][0] is 0, q[2][0][1] is 0, and q[2][1][0] is 0; respectively, the rest are zero. The initializer for q[0][0] does not begin with a left brace, so up to six items from the current list may be used. There is only one, the values for the remaining five elements are initialized with zero. Likewise, the initializers for q[1][0] and q[2][0] do not begin with a left brace, so each uses up to six items, initializing their respective two-dimensional subaggregates. short q[4][3][2] = {
