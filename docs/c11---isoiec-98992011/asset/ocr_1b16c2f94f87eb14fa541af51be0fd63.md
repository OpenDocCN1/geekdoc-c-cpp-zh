# K.3.9.1.12 The vwscancf_s function

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdarg.h>
#include <wchar.h>
int vwscancf_s(const wchar_t * restrict format,
va_list arg);
```

Runtime-constraints format shall not be a null pointer. Any argument indirect through in order to store converted input shall not be a null pointer.

If there is a runtime-constraint violation, the vwscancf_s function does not attempt to perform further input, and it is unspecified to what extent vwscancf_s performed input before the runtime-constraint violation.

Description

The vwscancf_s function is equivalent to wscanff_s, with the variable argument list replaced by arg, which shall have been initialized by the va_start macro (and possibly subsequent va_arg calls). The vwscancf_s function does not invoke the va_end macro.

Returns

The vwscancf_s function returns the value of the macro EOF if an input failure occurs before any conversion or if there is a runtime-constraint violation. Otherwise, the vwscancf_s function returns the number of input items assigned, which can be fewer than provided for, or even zero, in the event of any matching failure.

Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
int wprintf_s(const wchar_t * restrict format, ...);
```

Runtime-constraints format shall not be a null pointer. The %n specifier^{441} (if not modified by fields,
