+   If the value of **base** is zero, the expected form of the subject sequence is that of an integer constant as described in 6.4.4.1, optionally preceded by a plus or minus sign, not including an integer suffix. If the value of **base** is between 2 and 36 (inclusive), the expected form of the subject sequence is a sequence of letters and digits representing the integer with the radix specified by **base**, optionally preceded by a plus or minus sign, but not including an integer suffix. The letters from a **a** (or **A**) through **z** (or **Z**) are assigned the values 10 through 35; only letters and digits whose values are less than that of **base** are permitted. If the value of **base** is 36, the characters **0x** or **0OX** are returned. They may optionally provide the sequence of letters and digits, following the sign if present.

+   The sequence is defined as the longest initial subsequence of the input string, starting with the first non-white-space character, that is of the expected form. The subject sequence contains no characters if the input string is empty or consists of entirely white space, or if the first non-white-space character is other than a sign or a permissible character or digit.

+   If the sequence has the expected form and the value of **base** is zero, the sequence of characters starting with the first digit is interpreted as an integer constant according to the rules of 6.4.4.1. If the sequence has the expected form and the value of **base** is between 2 and 36, it is used as the base for conversion, adapting each letter to value as given above. If the subject begins with a minus sign, the value resulting from the conversion is negated (in the return type). A pointer to the final string is stored in the object pointed to by **endptr**, provided that **endptr** is not a null pointer.

+   In other than the "C" locale, additional locale-specific subject sequence forms may be accepted.

+   If the sequence is empty or does not have the expected form, no conversion is performed; the value of **nptr** is stored in the object pointed to by **endptr**, provided that **endptr** is not a null pointer.

# Returns

+   The **strtol**, **stroll**, **strtoul**, and **strtoll** functions return the converted value, if any. If no conversion could be performed, zero is returned. If the correct value is outside the range of representable values, **LONG_MIN**, **LONG_MAX**, **LLONG_MIN**, **LLONG_MAX**, **ULONG_MAX**, or **ULLONG_MAX** is returned (according to the return type and sign of the value, if any), and the value of the macro **ERANGE** is stored in **errno**.
