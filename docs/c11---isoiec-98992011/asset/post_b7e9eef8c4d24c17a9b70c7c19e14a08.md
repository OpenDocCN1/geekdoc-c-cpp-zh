
## 7.12.9.6 The round functions

Synopsis

```
#include <math.h>
double round(double x);
float roundf(float x);
long double roundl(long double x);
```

Description

The round functions return their argument to the nearest integer value in floating-point format, rounding halfway cases away from zero, regardless of the current rounding direction.

Returns

The round functions return the rounded integer value.

## 7.12.9.7 The round and lround functions

Synopsis

```
#include <math.h>
long int round(double x);
int roundf(float x);
long int roundl(double x);
long int llround(double x);
long int llroundf(float x);
long int llroundl(double x);
```

Description

The round and lround functions return their argument to the nearest integer value, rounding halfway cases away from zero, regardless of the current rounding direction. If the rounded value is outside the range of the return type, the numeric result is unspecified and a domain error or range error may occur.

Returns

The round and lround functions return the rounded integer value.

## 7.12.10 Remainder functions

### 7.12.10.1 The fmod functions

### Synopsis

```
#include <math.h>
double fmod(double x, double y);
float fmod(float x, float y);
long double fmodl(long double x, long double y);
```

Description

- The fmod functions compute the floating-point remainder of x/y.

Returns

- The fmod functions return the value x–ny, for some integer n such that, if y is nonzero, the result has the same sign as x and magnitude less than the magnitude of y. If y is zero, a domain error or the fmod functions return zero is implementation-defined.

### 7.12.10.2 The remainder functions

### Synopsis

```
#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
```

Description

- The remainder functions compute the remainder x REM y required by IEC 60559:239

> 239) When x ≠ 0, the remainder r=x REM y is defined regardless of the rounding by the mathematical relation r=x–ny, where n is the integer near the exact value of x/y; whenever |n-ny| = 1/2, then n is even. If r=0, its sign shall be that of x. This definition is applicable for all implementations.

Returns

- The remainder functions return x REM y. If y is zero, a domain error occurs or the functions return zero is implementation defined.

### 7.12.10.3 The remquo functions

### Synopsis

```
#include <math.h>
double remquo (double x, double y, int *quo);
float remquof (float x, float y, int *quo);
long double remquoi (long double x, long double y, int *quo);
```

Description

- The remquo function computes the same remainder as the remainder functions. In the object pointed to by quo they store a value whose sign is of x/y and magnitude is congruent modulo 2* to the magnitude of the integral quotient of x/y, where n is an implementation-defined integer greater than equal to 3.

Returns

- The remquo functions return x REM y. If y is zero, the value stored in the object pointed to by quo is unspecified and a domain error occurs or the functions return zero is implementation defined.

## 7.12.11 Manipulation functions

### 7.12.11.1 The copysign functions

### Synopsis

```
#include <math.h>
double copysign (double x, double y);
float copysignf (float x, float y);
long double copysign (long double x, long double y);
```

Description

- The copysign functions produce a value with the magnitude of x and the sign of y. They produce a NaN (with the sign of y) if x is a NaN. On implementations that represent signed zero but do not treat negative zero consistently in arithmetic operations, the copysign functions regard the sign of zero as positive.

Returns

- The copysign functions return a value with the magnitude of x and the sign of y.

### 7.12.11.2 The nan functions

Synopsis

```
#include <math.h>
double nan(const char *tagp);
float nanof(const char *tagp);
long double nanl(const char *tagp);
```

Description

- The call nan("n-char-sequence") is equivalent to strtod("NAN n-char-sequence", (char**) NULL); the call nan("") is equivalent to strtod("NAN", (char**) NULL); If tagp does not point to an n-char sequence or an entry string, the call is equivalent to strtod("NAN", (char**) NULL). Calls to nanof and nanl are equivalent to the corresponding calls to strtof and strtold.

Returns

- The nan functions return a quiet NaN, if available, with content indicated through tagp. If the implementation does not support quiet NaNs, the function return zero.

Forward references: the strtod, strtof, and strtold functions (7.22.1.3).

### 7.12.11.3 The nextafter functions

Synopsis

```
#include <math.h>
double nextafter(double x, double y);
float nanofter(float x, float y);
long double nextafterl(long double x, long double y);
```

Description

- The nextafter functions determine the next representable value in the type, nearest to but no larger in magnitude than the argument, where x and y are first converted to the type. A range error may occur if x is the largest finite value and the result is infinite.

Returns

- The nextafter functions return the next representable value in the type, after of y.

### 7.12.11.4 The nexttoward functions

Synopsis

```
#include <math.h>
double nexttoward(double x, long double y);
float nexttolardf(float x, long double y);
long double nexttowardl(long double x, long double y);
```

Description

- The nexttoward functions are equivalent to the nextafter functions except that the second parameter has long double and the functions return y if x equals y.

Returns

- The nexttoward functions return the next representable value in the type, toward y.

## 7.12.12 Maximum, minimum, and positive difference functions

> 22) NaN arguments are treated as missing data: if one is a NaN and the other numeric, then the fmax functions chooses the numeric value. See E.10.9.2.

## 7.12.13 Floating multiply-add

### 7.12.13.1 The fma functions

Synopsis

```
#include <math.h>
double fma(double x, double y, double z);
float faf(float x, float y, float z);
long double fmal(long double x, long double y, long double z);
```

Description

- The fma functions compute (x × y) + z, rounded as ternary operation; compute the value (as if to infinite precision and round once to the result format, according to the current rounding mode). A range error may occur.

Returns

- The fma functions return (x × y) + z, rounded as one ternary operation.
