# K.3.9.2.1.2 The wscncpy_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>

erno_t wscncpy_s(wchar_t * restrict s1,
rsize_t slmax,
const wchar_t * restrict s2,
rsize_t n);
```

# Runtime-constraints

+   7 Neither s1 s2 be a null pointer. Neither slmax nor n shall be greater than RSIZE_MAX. slmax shall not be equal. If n is not less than slmax, then slmax shall be greater than wscnclen_s(s2, slmax). Copying shall not take place between objects that overlap.

+   9 If there is a runtime-constraint violation, if s1 is not a null pointer and slmax is greater than zero and not greater than RSIZE_MAX, then wscncpy_s sets s1[0] to the null wide character.

# Description

+   10 The wscncpy_s function copies not more than n wide characters (wide characters that follow a null wide character are not copied) from the array pointed to by s1. If no null wide character was copied from s2, s1[n] is set to a null wide character.

+   11 All elements following the terminating null wide character (if any) written by wscncpy_s in the array of slmax wide characters pointed to by s1 take unspecified values when wscncpy_s returns.444

# Returns

+   12 The wscncpy_s function returns445 if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

+   13 EXAMPLE1 The wscncpy_s function can be used to copy a wide string without the danger that the result will not be null terminated or that wide characters will be written past the end of the destination array.

> 444 This allows an implementation to copy wide characters from s2 to s1 while simultaneously checking any of those wide characters are null. Such approach writes a wide character to every element of s1 before deciding the first element should be set to the null wide character.

> 445 A zero return value implies that all of the requested characters from the string pointed to by s2 fit within the array pointed to by s1 and that the result in s1 is null terminated.
