# F.10.6 Nearest integer functions

# F.10.6.1 The ceil functions

+   1 — ceil(±0) returns ±0.

+   — ceil(±∞) returns ±∞.

+   2 The returned value is independent of the current rounding direction mode.

+   3 The double version of ceil behaves as implemented by

```c
#include <math.h>
#include <fenv.h>
#pragma STDC FENV_ACCESS ON
double ceil(double x)
{
double result;
int save_round = fegetround();
fesetround(FE_UPWARD);
result = rint(x); // or nearbyint instead of rint
fersetround(save_round);
return result;
}
```

+   4 The ceil functions may, but are not required, to raise the “ineact” floating-point exception for finite non-integer arguments, as this implementation does.

# F.10.6.2 The floor functions

+   1 — floor(±0) returns ±0.

+   — floor(±∞) returns ±∞.

+   2 The returned value is independent of the current rounding direction mode.

+   3 See the implementation details for ceil in F.10.6.1. The floor functions may be, but are not required to, raise the “ineact” floating-point exception for finite non-integer arguments, as this implementation does.

# F.10.6.3 The nearbyint functions

+   1 The nearbyint functions use IEC 60559 rounding according to the current rounding direction. They do not raise the “ineact” floating-point exception if the result differs in value from the argument.

+   — nearbyint(±0) returns ±0 (for all rounding directions).

+   — nearbyint(±∞) returns ±∞ (for all rounding directions).
