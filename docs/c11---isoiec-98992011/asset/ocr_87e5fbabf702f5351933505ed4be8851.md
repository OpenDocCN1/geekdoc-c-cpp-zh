# 7.12.4.7 The tan functions

# Synopsis

```
1 #include <math.h>
double tan (double x);
float tanf(float x);
long double tanl(long double x);
```

# Description

+   2 The tan functions return the tangent of x (measured in radians).

# Returns

+   3 The tan functions return tan x.

# 7.12.5 Hyperbolic functions

# 7.12.5.1 The acosh functions

# Synopsis

```
1 #include <math.h>
double acosh (double x);
float acosh(float x);
long double acosh(long double x);
```

# Description

+   2 The acosh functions compute the (nonnegative) hyperbolic cosine of x. A domain error occurs for arguments less than 1.

# Returns

+   3 The acosh functions return arcosh x in the interval [0,+∞).

# 7.12.5.2 The asinh functions

# Synopsis

```
1 #include <math.h>
double asinh (double x);
float asinh(float x);
long double asinh(long double x);
```

# Description

+   2 The asinh functions compute the arc hyperbolic sine of x.
