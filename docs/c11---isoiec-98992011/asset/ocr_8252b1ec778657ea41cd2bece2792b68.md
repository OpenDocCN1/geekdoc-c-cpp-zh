# Semantics

+   Preprocessing directives of the forms

```
# if constant-expression new-line groupopt
# elif constant-expression new-line groupopt
```

check whether the controlling expression evaluates to nonzero.

+   Prior to evaluation, macro invocations in the list of preprocessing tokens that will become the controlling expression are replaced (except for macro names identified by the defined unary operator), just as in text. If the token defined generated as a result of this replacement process or of the defined unary operator does not match one of the two specified forms for macro replacement, the behavior is undefined. After all replacements due to macro expansion and the defined unary operator have been performed, all remaining identifiers (including leeway to keywords) are replaced with the pp-number, and each preprocessing token is converted into a token. The resulting tokens compose the controlling expression which is evaluated according to the rules of 6.6. For the purposes of this conversion and evaluation, all signed integer types have the same representation, respectively, the types intmax_t and uintmax_t defined in the header <stdint.h>⁷ This includes interpreting character constants, which may involve converting escape sequences into character sets. Whether the numeric value for these characters matches the value obtained in an expression (other than within a #if or #elif directive) is implementation-defined.¹¹⁶⁸) Also, whether a single-character constant may have a value that is implementation-defined.

> 16⁷) Thus, on an implementation where INT_MAX is 07FFF and UINT_MAX is 0FFFF, the constant 0x8000 is signed and positive with a #if expression even though it would be unsigned in translation phase 7.

> 16⁸) Thus, the constant expression in the following #if directive and if statement is not guaranteed to evaluate to the same value in two contexts.

```
#if 'z' - 'a' == 25
if ('z' - 'a' == 25)
```
