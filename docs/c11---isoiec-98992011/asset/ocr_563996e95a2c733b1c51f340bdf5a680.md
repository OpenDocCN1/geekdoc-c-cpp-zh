# ISO/IEC 9899:2011 (E)

# Semantics

The identifiers in an enumerator list are declared as constants that have type int and may appear wherever such are permitted.¹127) An enumerator defines its enumeration constant as the value of the constant expression. If the first enumerator has no =, the value of its enumeration constant is 0. Each subsequent enumerator with no = defines its enumeration constant as the value of the constant expression obtained by adding 1 to the value of the previous enumerator. (The use of enumerators with = may produce enumeration constants with values that duplicate other values in the same enumeration.) The enumerators of an enumeration are also known as its members.

Each enumerator type shall be compatible with char, a signed integer, or an unsigned integer. The choice of type is implementation-defined,¹²⁸) but should be capable of representing the values of all members of the enumeration. The enumerator type is incomplete until immediately after the } that terminates the list of enumerator declarations, and complete thereafter.

EXAMPLE The following:

```
enum hue { chartreuse, burgundy, claret=20, winedark };nenum hue col; *cp;
col = claret;
cp = &col;
if (*cp != burgundy)
{ /* ... * */
```

makes the hue of an enumerator, and declares col as an object that has type and cp as a pointer to that has type. The enumerated values are in the set { 0, 1, 20, 21 }.

# 6.7.2.3 Tags

# Constraints

A specific type shall have its content defined at most once.

Where two declarations use the same tag declare the same type, they shall both use the same code of struct, union, or enum.

A type specifies of the form

```
enum identifier
```

without an enumerator list shall only appear after the type it specifies, complete.

> ¹²⁷) Thus, the identifiers of enumeration constants declared in the scope shall be distinct from each other and from other identifiers declared in ordinary declarations.

> ¹²⁸ An implementation may delay the choice of which integer type until all enumeration constants have seen.
