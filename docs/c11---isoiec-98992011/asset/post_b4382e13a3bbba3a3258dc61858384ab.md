## K.3.9.3 Extended multibyte/wide character conversion utilities

### K.3.9.3.1 Restartable multibyte/wide character conversion functions

- Unlike wctomb, wctomb_s does not permit the ps parameter (the pointer to the conversion state) to be a null pointer.

### K.3.9.3.1.1 The wctomb_s function

#### Synopsis

```
#include <wchar.h>
errno_t wctomb_s(size_t * restrict retrieval,
char * restrict s, size_t smax,
wchar_t wc, mbstate_t * restrict ps);
```

#### Runtime-constraints

- Neither nor ps shall be a null pointer. If s is not a null pointer, smax shall not equal zero and be greater than RSIZE_MAX. If s is not a null pointer, then smax shall not be greater than the number of bytes to be stored in the array pointed to by s. If s is a null pointer, smax shall equal zero.

- If there is a runtime-constraint violation, wctomb_s does the following. If s is not a null pointer and smax is greater than zero and not greater than RSIZE_MAX, then wctomb_s sets s[0] to the null character. If retval is not a null pointer, then wctomb_s sets *retrieval to (size_t) (-1).

#### Description

- If s is a null pointer, the wctomb_s function is equivalent to the call wctomb_s(&retval, buf, sizeof buf, L'\0', ps) where retval and buf are variables of the appropriate types, and the size of buf is greater than MB_CUR_MAX.

- If s is not a null pointer, the wctomb_s function determines the number of bytes needed to represent the multibyte character that corresponds to the wide character wc (any shift sequences), and stores the multibyte character representation in the array where the first element is pointed to by s. If wc is a wide character, a byte is stored, preceded by any shift sequence to restore the initial shift state; the resulting state describes the initial conversion state.

- Note that the wcsnlen_s has no runtime-constraints. This lack of runtime-constraints along with the values returned for a null pointer or uncertain wide string argument make wcsnlen_s useful in algorithms that gracefully handle exceptional data.

#### §K.3.9.3.1.1 Bounds-checking interfaces

If wc does not correspond to a valid multibyte character, an encoding error occurs: the wctomb_s function stores the value (size_t) (-1) into *retval and the conversion state is unspecified. Otherwise the wctomb_s function stores into *retval the number of bytes (including any shift sequences) stored in the array pointed to by s.

#### Returns

The wctomb_s function returns zero if no runtime-constraint violation and no encoding error occurs. Otherwise, a nonzero value is returned.

## K.3.9.3.2 Restartable multibyte/wide string functions

- Unlike mbsrtowcs and wctombs, mbsrtowcs_s and wctombs_s do not permit the ps parameter (the pointer to the conversion state) to be a null pointer.

### K.3.9.3.2.1 mbsrtowcs_s function

#### Synopsis

```
#include <wchar.h>
errno_t mbsrtowcs_s(size_t * restrict retval,
char * restrict dst, size_t dstmax,
const char ** restrict src, size_t len,
mbstate_t * restrict ps);
```

#### Runtime-constraints

- None of retval, *src, *dst shall be null pointers. If dst is not a null pointer, then neither nor dstmax shall be greater than RSIZE_MAX. If dst is a null pointer, then dstmax shall equal zero. If dst is not a null pointer, then dstmax shall not be less than len, and no character shall occur after the first multibyte characters of the array pointed to by *src.

- If there is a runtime-constraint violation, then mbsrtowcs_s sets *retval to (size_t) (-1). If dst is not a null pointer and dstmax is greater than zero and less than RSIZE_MAX, then mbsrtowcs_s sets dst[0] to the wide character.

#### Description

The mbsrtowcs_s function converts a sequence of multibyte characters that begins in the conversion state described by the object pointed to by ps, from the array indexed by src. If dst is not a null pointer, the converted characters are stored into the array pointed to by dst. Conversion continues to and until reaching a terminating null character, which is also stored. Conversion stops earlier in cases: when a sequence of bytes is encountered that is not a valid multibyte character, or if dst is not a null pointer when len characters have been stored into the array pointed to by dst.
