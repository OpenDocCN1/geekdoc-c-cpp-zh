4 EXAMPLE 2 The following defines a function-like macro whose value is the maximum of the arguments.
It has the advantages of being free for any compatible types of the arguments and generating in-line code
without the overhead of function calling. It has the disadvantages of evaluating one or the other of its
arguments a second time (including side effects) and generating more than a function if invoked
se times. It also cannot access its address, as it has none.

```
#define max(a, b) ((a) > (b) ? (a) : (b))
The parentheses ensure that the arguments and the resulting expression are bound properly.
```
