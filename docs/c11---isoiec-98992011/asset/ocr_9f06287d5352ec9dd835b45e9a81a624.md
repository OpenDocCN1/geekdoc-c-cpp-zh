+   7 The length modifiers and their meanings are:

+   hh Specifies that a following d. i, o, u, or X conversion specifier applies to a signed char or unsigned char argument (the argument will have been promoted according to the integer promotions, but its value will be converted to signed char or unsigned char before printing); or that a following n conversion specifier applies to a pointer to a signed char argument.

+   h Specifies that a following d. i, o, u, or X conversion specifier applies to a short int or unsigned short int (the argument will have been promoted according to the integer promotions, but its value will be converted to short int or unsigned int before printing); or that a following n conversion specifier applies to a pointer to a short int argument.

+   1 (ell) Specifies that a following d. i, o, u, or X conversion specifier applies to a long int or unsigned long int argument; or that a n conversion specifier applies to a pointer to a long int argument; or that a c conversion specifier applies to a wint_t argument; or that a s conversion specifier applies to a pointer to a wchar_t argument; or has no effect on a following a, E, e, F, g, or G conversion specifier.

+   11 (ell-ell) Specifies that a following d. i, o, u, or X conversion specifier applies to a long int or unsigned long int argument; or that a n conversion specifier applies to a pointer to a long int argument.

+   j Specifies that a following d. i, o, u, or X conversion specifier applies to an intmax_t or uintmax_t argument; or that a n conversion specifier applies to a pointer to an intmax_t argument.

+   z Specifies that a following d. i, o, u, or X conversion specifier applies to a size_t or the corresponding signed integer type argument; or that a n conversion specifier applies to a pointer to a signed integer type corresponding to size_t argument.

+   t Specifies that a following d. i, o, u, or X conversion specifier applies to a ptrdiff_t or the corresponding unsigned integer type argument; or that a n conversion specifier applies to a pointer to a ptrdiff_t argument.
