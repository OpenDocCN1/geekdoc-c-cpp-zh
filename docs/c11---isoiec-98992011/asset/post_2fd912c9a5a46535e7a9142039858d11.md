## 7.28.1.3 The mbtorc32 function

# Synopsis

```
#include <uchar.h>
mbtorc32(char32_t * restrict pc32,
const char * restrict s, size_t n,
mbstate_t * restrict ps);
```

# Description

+   If s is a null pointer, the mbtorc32 function is equivalent to the call:
mbtorc32(NULL, "", 1, ps)

mbtorc32(NULL, "", 1, ps)
In this case, the values of the parameters pc32 and n are ignored.

+   If s is not a null pointer, the mbtorc32 function inspects at most n bytes beginning with the byte pointed to s to determine the number of bytes needed to complete the next multibyte character (including any shift sequences). If the function determines that the next multibyte character is complete and valid, it determines the values of the corresponding wide characters and then, if pc32 is not a null pointer, it stores the value of the first (or only) such character in the object pointed to by pc32. Subsequent calls will store wide characters without consuming any additional input until all characters have been stored. If the corresponding wide character is the null character, the resulting state described is the initial conversion state.

## 7.29 Extended multibyte and wide character

1 The header <char.h> defines four macros, and declares four types, one tag, and many functions

2 The types wchar_t and size_t (both described in 7.19); mbstate_t is a complete type that can hold state information necessary to convert between multibyte and wide characters; wint_t is an integer type that can hold any value corresponding to wide characters

3 The macros WCHAR_MIN and WCHAR_MAX (described in 7.20); and WEOF expands to a constant expression of wint_t

4 The functions declared are grouped as follows:

    - Functions that perform input and output of wide characters, or multibyte characters, or both
    - Functions that provide numeric conversion
    - Functions that perform wide string manipulation
    - Functions for wide string date and time

5 Arguments to the functions in this subclause may point to arrays containing wchar_t values that do not correspond to members of the character set. Such values shall be processed according to the specified semantics, except that it is unspecified whether an encoding error occurs if such a value in the format string for a function in 7.2 or 7.5 and the specified semantics do not require that value to be processed by wctype

6 Unless explicitly stated otherwise, if the execution of a function described in this subclause allows copying to place between elements that overlap, the behavior is undefined.

## 7.29.2.1 The fwprintf function

# Synopsis

```
#include <stdio.h>
#include <wchar.h>
int fwprintf(FILE * restrict stream, const wchar_t * restrict format, ...);
```

# Description

2 The fwprintf function writes output to the stream pointed to, under control of the wide string pointed to format specifies which subsequent arguments are converted for output. If there are insufficient arguments for the format, the behavior is undefined. If the format is exhausted while arguments remain, the excess arguments are evaluated (as always) but are otherwise ignored. The fwprintf function returns when the end of the format string is encountered.

The format is composed of zero or more directives: ordinary wide characters (not %), which are copied unchanged to the output stream; and conversion specifications, each of which results in fetching zero or more arguments, converting them, if applicable, according to the corresponding conversion specifier, and writing the result to the output stream.

> ³⁹ The fwprintf function writes to memory for the %n specifier.
