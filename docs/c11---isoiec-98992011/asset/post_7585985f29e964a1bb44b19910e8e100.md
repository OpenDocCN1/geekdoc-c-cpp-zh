## H.2.3.2 Floating-point operations

1 The floating-point operations on floating-point types are the following:

```
addF	 x + y
subF	x - y
mulF	 x * y
divF	 x / y
negF	-x
absF	fabsf(x), fabs(x), fabsl(x)
exponentF	1.+log2f(x), 1.0+log2(x), 1.L+log2(x)
scaleF	scalnf(x, n), scalbn(x, n), scbnl(x, n), scalfl(x, li), scalbnl(x, li), scbnln(x, li)
```

```
intpartF	modf(x, &y), modf(x, &y), modfl(x, &y)
fractpartF	modf(x, &y), modf(x, &y), modfl(x, &y)
eqF	 x = y
qF	 x != y
lssF	 x < y
leqF	 x <= y
gtrF	 x > y
geqF	 x >= y
```

where x and y are expressions of the same floating point type, n is of type int, and li is of type long int.

## H.2.3.3 Rounding styles

1 The C standard requires all floating types to use the same radix and rounding styles, so that only one identifier for each type to map to LIA–1.

2 The FLT_ROUNDS parameter can be used to indicate the LIA–1 rounding styles:

```
truncate	 FLT_ROUNDS == 0
```

nearest FLT_ROUNDS == 1

other FLT_ROUNDS != 0 && FLT_ROUNDS != 1

provided that an implementation extends FLT_ROUNDS to cover the rounding style used in all relevant LIA–1 operations, not just addition as in C.

## H.2.4 Type conversions

- The LIA–1 conversions are the following type casts:
ctvl' → I (int)i, (long int)i, (long long int)i, (unsigned int)i, (unsigned long int)i, (unsigned long int)i
cvf → I (int)x, (long int)x, (long long int)x, (unsigned int)x, (unsigned long int)x, (unsigned long int)x
ctvl → F (float)i, (double)i, (long double)i
cvfF → F (float)x, (double)x, (long double)x

- In the above conversions from floating to integer, the use of (cast)x can be replaced with (cast) round(x), (cast) wint(x), (cast) nearbyint(x), (cast) trunc(x), (cast) ceil(x), or (cast) floor(x). In C’s floating-to-integer conversion functions, lrint(i), llrint(i), lround(j), and lround(j), can be used. They all LIA–1's requirements on floating to integer rounding for in-range values. For out-of-range values, the conversions shall silently wrap for the modules.

- The fmod() function is useful for silent wrapping to unsigned integer types, e.g., fmod(fabsint(x), 65536.0 ) or (0.0 < (y = fmod(rint(x), 65536.0) ) ? 65536.0 + y) will compute an integer value in the range 0.0 to 65535.0 which can then be cast to unsigned short int. But, the remainder( ) is not useful for silent wrapping to signed integer types, e.g., remainder( rint(x), 65536.0 ) will compute an integer value in the range -32767.0 to +32768.0 which is not, in general, the range of signed short int.

- C’s conversions (casts) from floating-point to floating-point can meet LIA–1 requirements if an implementation uses round-to-nearest (IEC 60559 default).

- C’s conversions (casts) from integer to floating-point can meet LIA–1 requirements if an implementation uses round-to-nearest.

## H.3 Notification

- Notification is the process by which a user operations or program is informed that an exceptional arithmetic operation has occurred. C’s operations are compatible with LIA–1 in that C allows.

## H.3.1 Notification

- LIA–1 requires at least two alternatives for handling: setting or trap-and-terminate.

- An implementation can provide a notification for--, for-PE, but not required.

- LIA–1 allows a third alternative: trap-andresume.
