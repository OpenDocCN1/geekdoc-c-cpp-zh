The conversion speculator includes all subsequent characters in the format string, up to and including the matching right bracket (]). The characters between the brackets (the scanlist) compose the scanset, unless the character after the left bracket is a circumflex (^), in which case the scanset contains all characters that do not appear in the scanlist and the right bracket. If the conversion speculator begins with [ or ^], the next following right bracket character is the matching right bracket that ends the specification; otherwise the first following right bracket character is the one that ends the specification. if a - character is in the scanlist and is not the first, nor the second where the first character is ^, nor the last character, the behavior is implementation-defined.
