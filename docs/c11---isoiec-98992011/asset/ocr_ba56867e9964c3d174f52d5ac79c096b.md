# K.3.6.3.2 The qsort_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdlib.h>
erno_t qsort_s(void *base, size_t nmemb, size_t size,
	int (*compar)(const void *, const void *y,
		void *context),
	void *context);
```

# Runtime-constraints

2 Neither nmemb size shall be greater than RSIZE_MAX. If nmemb is not equal to zero, then base nor compar be a null pointer.

3 If there is a runtime-constraint violation, the qsort_s function does not sort the array.

# Description

4 The qsort_s function sorts an array of nmemb objects, the initial element of which is pointed to by base. The size of each object is specified by size.

5 The contents of the array are sorted in ascending order according a comparison function pointed to compar, which is called with three arguments. The first two point to the objects being compared. The function shall return an integer less, equal to, or greater than zero if the first argument is considered to be respectively less than, equal to, or greater the second. The third argument of the comparison function is the context argument passed to qsort_s. The sole use of context by qsort_s is to pass it to the comparison function.¹⁴²

6 If two elements compare as equal, their relative order in the resulting sorted array is unspecified.

# Returns

7 The qsort_s function returns zero if there was no runtime-constraint violation. Otherwise, a nonzero value is returned.

> ¹⁴² The context argument is for the use of the comparison function in performing its duties. It might signify a collating sequence used by the comparison function.
