The wcstol, wctoll, wcstoul, and wcstoll convert the initial portion of the wide string pointed by nptr to long int, long long int, unsigned long int, and unsigned long int, respectively. They decompose the input into three parts: an initial, possibly empty, sequence of white space (as characterized by the isspace function), a sequence of unrecognized wide characters, and a final string.

The subject sequence is defined as the longest initial subsequence of the input wide string, starting with the first non-space-wide wide character, that is of the expected form. The subject sequence contains no wide characters if the input string is empty or consists entirely of white space, or if the first non-space-wide character is other than a sign or a digit.

If the subject sequence has the expected form and the value of base is zero, the sequence of wide characters starting with the first digit is interpreted as an integer constant according to the rules of 6.4.4.1. If the subject sequence has the expected form and the value of base is between 2 and 36, it is used as the base, assigning to each letter its value as given above. If the subject sequence begins with a minus sign, the value is negated (in the return type). A pointer to the wide string is stored in the object pointed to by endptr, provided that endptr is not a null pointer.

In other than the "C" locale, additional locale-specific sequence forms may be accepted.

If the subject sequence is empty or does not have the expected form, no conversion is performed; the value of nptr is stored in the object pointed to by endptr, provided that endptr is not a null pointer.
