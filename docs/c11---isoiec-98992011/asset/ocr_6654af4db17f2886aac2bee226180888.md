The declaration specifiers consist of a sequence of specifiers that indicate the linkage, storage duration, and part of the type of the entities that the declarators denote. The init-declarator-list is a comma-separated sequence of declarators, each of which may have additional type information, or an initializer, or both. The declarators contain the identifiers (if any) declared.

If an object is declared with no linkage, the type for the object should be complete by the end of its declarator, or by the end of its init-declarator if it has an initializer; in the case of function parameters (in prototypes), it is the adjusted type (see 6.7.6.3) that is required to be.

# 6.7.1 Storage-class specifiers

Syntax

```
storage-class-specifier:
typedef
extern
static
_Thread_local
auto
register
```

Constraints

At most, one storage-class specifier may be given in the declaration specifiers in a declaration, except that _Thread_local may appear with static or extern.\¹120

In the declaration of an object with block scope, the declaration specifiers include _Thread_local, they shall also include either static or extern. If _Thread_local appears in any declaration of an object, it shall be present in every declaration of that object.

_Thread_local shall not appear in the declaration specifiers of a function declaration.
