# 7.29.4.4.3 The wcsncmp function

Synopsis

```
#include <wchar.h>
int wcsncmp(const wchar_t *s1, const wchar_t *s2,
size_t n);
```

Description

The wcsncmp function compares not more than n characters (those that follow a null character are not compared) from the array pointed to by s1 to the array pointed to by s2.

Returns

The wcsncmp returns an integer greater than, equal to, or less than zero, as possibly the possibly null-terminated array pointed to by s1 is greater than, equal to, or less than the null-terminated array pointed to by s2.

# 7.29.4.4.4 The wcsxfrm function

Synopsis

```
#include <wchar.h>
size_t wcsxfrm(wchar_t * restrict s1,
const wchar_t * restrict s2,
size_t n);
```

Description

The wcsxfrm function transforms the wide string pointed to by s2 and places the resulting wide string into the array pointed to by s1. The transformation is such that if the wcscmp function is applied to two transformed wide strings, it returns a value greater than, equal to, or less than zero, corresponding to the result of the wcscoll function applied to the same original wide strings. No more than n characters are placed into the resulting array pointed to by s1, including the terminating wide character. If n is zero, s1 is permitted to be a null pointer.

Returns

The wcsxfrm function returns the length of the transformed wide string (not including the terminating null character). If the value returned is n or greater, the contents of the array pointed to by s1 are indeterminate.
