# 17.18 Boolean type and values <stddb.h>

+   1 The Header <stdb.h> defines four macros.

+   2 The macro
```c
bool
```
expands to _Bool.
The remaining three macros are suitable for use in #if preprocessing directives. are
```c
true
```
which expands to the integer constant 1,
```c
false
```
which expands to the integer 0, and
```c
__bool_true_false_are_defined
```
which expands to the integer constant 1.

+   4 Notwithstanding the provisions of 7.1.3, a program may undefined and perhaps then redefine the macros bool, true, and false.259)
