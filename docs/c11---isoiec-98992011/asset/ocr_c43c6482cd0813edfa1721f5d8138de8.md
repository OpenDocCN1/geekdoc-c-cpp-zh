> 121) The implementation may treat any **register** declaration simply as an **auto** declaration. However, whether or not addressable storage is actually used, the address of any part of an object declared with storage-class specifier **register** cannot be computed, explicitly (by use of the **&** operator as discussed in 6.5.3.2) or implicitly (by converting an array name to a pointer as discussed in 6.2.1). Thus, the only operator that can be applied to an array declared with storage-class specifier is **sizeof**.
