# 7.3.5.6 The ctan functions

# Synopsis

```
#include <complex.h>
double complex ctan(double complex z);
float complex ctanf(float complex z);
long double complex ctan(long double complex z);
```

# Description

+   2 The ctan functions compute the complex tangent of z.

# Returns

+   3 The ctan functions return the complex tangent value.

# 7.3.6 Hyperbolic functions

# 7.3.6.1 The cacosh functions

# Synopsis

```
#include <complex.h>
double complex cacosh(double complex z);
float complex cacoshf(float complex z);
long double complex cacosh(long double complex z);
```

# Description

+   2 The cacosh functions compute the arc hyperbolic cosine of z, with a branch cut at values less than 1 along the real axis.

# Returns

+   3 The cacosh functions return the arc hyperbolic cosine value, in the range of a half-strip of nonnegative values along the real axis and in the interval [-iπ,+iπ] along the imaginary axis.
