# 7.29.2 Formatted wide character input/output functions

1 The formatted wide character input/output functions shall behave as if there is a sequence point after the associates associated with each specifier.³⁹

# 7.29.2.1 The fwprintf function

# Synopsis

```
#include <stdio.h>
#include <wchar.h>
int fwprintf(FILE * restrict stream, const wchar_t * restrict format, ...);
```

# Description

2 The fwprintf function writes output to the stream pointed to, under control of the wide string pointed to by format specifies which subsequent arguments are converted for output. If there are insufficient arguments for the format, the behavior is undefined. If the format is exhausted while arguments remain, the excess arguments are evaluated (as always) but are otherwise ignored. The fwprintf function returns when the end of the format string is encountered.

3 The format is composed of zero or more directives: ordinary wide characters (not %), which are copied unchanged to the output stream; and conversion specifications, each of which results in fetching zero or more arguments, converting them, if applicable, according to the corresponding conversion specifier, and writing the result to the output stream.

> ³⁹ The fwprintf function writes to memory for the %n specifier.
