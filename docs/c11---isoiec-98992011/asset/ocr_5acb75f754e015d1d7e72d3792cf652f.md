# 7.8 Format conversion of integer types <intypes.h>

+   1 The header <intypes.h> includes the header <stdint.h> and extends it with additional facilities provided by hosted implementations.

+   2 It declares functions for manipulating greatest-width integers and converting numeric strings to greatest-width integers, and it declares the type `div_t`

```
imaxdiv_t
```

which is a structure that is of the value returned by the imaxdiv function. For each type described in <stdint.h>, it defines corresponding macros for conversion specifies by using the formatted input/output functions.(219)

**Forward references:** integer types <stdint.h> (7.20), formatted input/output functions (7.21.6), formatted wide character input/output functions (7.29.2).).

# 7.8.1 Macros for format specifies

+   1 Each of the following object-like macros expands a character string containing a conversion specified, possibly modified by a length modifier, suitable for use within the format argument of a formatted input/output function when converting the corresponding integer type. These macros have the general form of PRI (character strings for the `printf` and `fprintf` function) or SCN (character strings for the `fscanf` and `sscanf` function).220 followed by the converter specified, followed by a name describing a similar type name in 7.20.1. In these names, $N$ represents the width of the type as described in 7.20.1. For example, `PRIFAST32` can be used in a format string to print the value of an integer type `int_fast32_t`.

+   2 The `printf` macros for signed integers are:

```
PRIdN       PRILEASTN   PRIFASTN    PRIdMAX     PRIdPTR
PRIIAN      PRILEASTN   PRIFASTN    PRIMAX      PRIPTR
```

+   3 The `printf` macros for unsigned integers are:

```
PRIoN       PRILEASTN   PRIFASTN    PRIOMAX     PRIOPTR
PRiUN       PRIULEASTN   PRIFASTN    PRIUMAX     PRIUPTR
PRIXN       PRILEASTN   PRIFASTN    PRIMAX      PRIXPTR
PRiXN       PRILEASTN   PRIFASTN    PRIMAX     PRXPTR
```

> 219) “future library directories” (7.31.5).

> 220 Separate macros are used for `printf` and `fcanf` functions because, in the general, different macros may be required for `printf` and `fcanf`, even when the type is the same.
