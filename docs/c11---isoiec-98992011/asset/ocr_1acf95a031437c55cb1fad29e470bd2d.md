# K.3.9.2.3 Wide string search functions

# K.3.9.2.3.1 wcwstok_s function

Synopsis

```
1 #define STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
wchar_t *wcwstok_s(wchar_t * restrict s1,
    size_t * restrict smax,
    const wchar_t * restrict s2,
    wchar_t ** restrict ptr);
```

# Runtime-constraints

+   2 None of smax, s2, or ptr shall be a null pointer. If s1 is a null pointer, then *ptr shall be a null pointer. The value of *smax shall not be greater than RSIZE_MAX. The end of the token found shall occur within the first *smax characters of s1 for the first call, and shall occur within the first *smax characters of searching resumes on subsequent calls.

+   3 If there is a runtime-constraint violation, the wcwstok_s function does not indirect through the s1 or s2 ptr, and does not store a value in the object pointed to by ptr.

# Description

+   4 A sequence of calls to the wcwstok_s function breaks the wide string pointed to by s1 into a sequence of tokens, each of which is delimited by a wide character from the wide string pointed to by s2. The fourth argument points to a caller-provided wchar_t pointer into which the wcwstok_s function stores information necessary for it to continue scanning the same wide string.

+   5 The first call in a sequence has a non-null first argument and smax points to an object whose value is the number of elements in the wide character array pointed to by the first call. The first call stores an initial value in the object pointed to by ptr and updates the value by smax to reflect the number of elements that remain in relation to ptr. Subsequent calls in the sequence have a first argument and the objects pointed to by smax and ptr are required to have the values stored by the previous call in the sequence, which are then updated. The separator wide string pointed to s2 may be different from call to call.

+   6 The first call in a sequence searches the wide string pointed to by s1 for the first wide character that is not contained in the current separator wide string pointed to by s2. If no such character is found, then there are no tokens in the wide string pointed to by s1 and the wcwstok_s function returns a null pointer. If such a character is found, it is the start of the first token.
