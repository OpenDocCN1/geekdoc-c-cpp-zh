16 EXAMPLE 7 The grouping of an expression does not completely determine its evaluation. In the following fragment

```
#include <stdio.h>
int sum;
char *p;
/* ... */
sum = sum * 10 + '0' + (*p++) = getchar());

the expression statement is grouped if it were written as

```
sum = ((sum * 10) - ' ') + ((*p++)) = (getchar()));

the actual execution of p can occur at any time between the previous sequence point and the next sequence point (the *); and the call to getchar can occur at any point prior to the need of its returned value.
