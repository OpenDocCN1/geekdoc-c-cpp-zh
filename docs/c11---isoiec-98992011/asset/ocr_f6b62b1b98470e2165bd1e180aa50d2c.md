# K.3.9.1 Formatted wide character input/output functions

# K.3.9.1.1 fwprintf_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <wchar.h>
int fwprintf_s(FILE * restrict stream,
const wchar_t * restrict format, ...);
```

# Runtime-constraints

+   Neither stream nor format should be a null pointer. The %n specifier⁴³⁰ (modified or not by flags, width, or precision) shall not appear in the wide string pointed by format. Any argument to fwprintf_s corresponding to a %s specifier shall not be a null pointer.

+   If there is a runtime-constraint violation, the fwprintf_s function does not attempt to produce further output, and it is specified to what extent fwprintf_s produced output before discovering the runtime-constraint violation.

# Description

+   The fwprintf_s function is equivalent to the fwprintf function except for the explicit runtime-constraints listed above.

# Returns

+   The fwprintf_s function returns the number of wide characters transmitted, or a negative value if an output error occurs, encoding error, or runtime-constraint violation occurred.

# K.3.9.1.2 swscanf_s function

# Synopsis

```
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
#include <wchar.h>
int swscanf_s(FILE * restrict stream,
const wchar_t * restrict format, ...);
```

# Runtime-constraints

+   Neither stream nor format should be a null pointer. Any argument indirected through in order to store converted input should not be a null pointer.

> 430) It is not a runtime-constraint violation for the wide %n to appear in sequence in the wide string pointed at format when those characters are not interpreted as a %s specifier. For example, if the format string was "%%s%n".
