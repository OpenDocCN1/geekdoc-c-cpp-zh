# Returns

# 7.21.7.5 The getc function

# Synopsis

```
#include <stdio.h>
int getc (FILE *stream);
```

# Description

+   2 The getc function is equivalent to fgetc, except if it is implemented as a macro, it may evaluate stream more than once, so the argument should never be an expression with side effects.

# Returns

+   3 The getc function returns the next character from the input stream pointed to by stream. If the stream is end-of-file, the end-of-file indicator for the stream is set and getc returns EOF. If a read error occurs, the error indicator for the stream is set and getc returns EOF.

# 7.21.7.6 The getchar function

# Synopsis

```
#include <stdio.h>
int getchar (void);
```

# Description

+   2 The getchar function is equivalent to getc with the argument stdin.

# Returns

+   3 The getchar function returns the next character from the stream pointed to by stdin. If the stream is end-of-file, the end-of-file indicator for the stream is set and getchar returns EOF. If a read error occurs, the error indicator for the stream is set and getchar returns EOF.
