
# ISO/IEC 9899:2011 (E)

Whether or when library functions raise the “inexact” floating-point exception is unspecified, unless explicitly specified otherwise.

Whether or when library functions raise an undesired “underflow” floating-point exception is unspecified³372). Otherwise, as implied by F.8.6, the <math.h> functions do not raise spurious floating-point exceptions (detectable by the user), other than the “inexact” floating-point exception.

Whether the functions honor the rounding direction mode is implementation-defined, unless explicitly specified otherwise.

Functions with a NaN argument return a NaN result and no floating-point exception, except where stated otherwise.

The specifications in the following clauses appends to the definitions in <math.h>. For families of functions, the specifications apply to all the functions even though only the principal function is shown. Unless otherwise specified, where the symbol “±” occurs in both an argument and the result, the result has the same sign as the argument.

## Recommended practice

If a function with one or more NaN arguments returns a NaN result, the result should be the same as one of the NaN arguments (after possible type conversion), except perhaps for the sign.

## F.10.1 Trigonometric functions

### F.10.1.1 The acos functions

- acos (1) returns +0.
- acos (x) returns a NaN and raises the “invalid” floating-point exception for |x| > 1.

### F.10.1.2 The asin functions

- asin (±) returns +0.
- asin (x) returns a NaN and raises the “invalid” floating-point exception for |x| > 1.

> 372) It is intended that undesired “underflow” and “inexact” floating-point exceptions are raised only if avoiding them would be too costly.

### F.10.1.3 The atan functions

- atan(±0) returns ±0.
- atan(±∞) returns ±π/2.

### F.10.1.4 The atan2 functions

- atan2(±0, -0) returns ±π.
- atan2(±0, +0) returns ±0.
- atan2(±0, x) returns ±π for x < 0.
- atan2(±0, x) returns ±0 for x > 0.
- atan2(y, ±0) returns -π/2 for y < 0.
- atan2(y, ±0) returns π/2 for y > 0.
- atan2(±y, -∞) returns ±π for finite y > 0.
- atan2(±y, +∞) returns ±0 for finite y > 0.
- atan2(±∞, x) returns ±π/2 for finite x.
- atan2(±∞, -∞) returns ±3π/4.
- atan2(±∞, +∞) returns ±π/4.

### F.10.1.5 The cos functions

- cos(±0) returns 1.
- cos(±∞) returns a NaN and raises the “invalid” floating-point exception.

### F.10.1.6 The sin functions

- sin(±0) returns ±0.
- sin(±∞) returns a NaN and raises the “invalid” floating-point exception.

### F.10.1.7 The tan functions

- tan(±0) returns ±0.
- tan(±∞) returns a NaN and raises the “invalid” floating-point exception.

## F.10.2 Hyperbolic functions

### F.10.2.1 The acosh functions

- acosh (1) returns ±0.
- acosh (x) returns a NaN and raises the “invalid” floating-point exception for x < 1.
- acosh (±∞) returns +∞.

### F.10.2.2 The asinh functions

- asinh (±0) returns ±0.
- asinh (±∞) returns ±∞.

### F.10.2.3 The ananh functions

- ananh (±0) returns ±0.
- ananh (±1) returns ±∞ and raises the “divide-by-zero” floating-point exception.
- ananh (x) returns a NaN and raises the “invalid” floating-point exception for x > 1.

### F.10.2.4 The cosh functions

- cosh (±0) returns 1.
- cosh (±∞) returns +∞.

### F.10.2.5 The sinh functions

- sinh (±0) returns ±0.
- sinh (±∞) returns ±∞.

### F.10.2.6 The tanh functions

- tanh (±0) returns ±0.
- tanh (±∞) returns ±1.

## F.10.3 Exponential and logarithmic functions

### F.10.3.1 The exp functions

- exp (±0) returns 1.
- exp (∞) returns +0.
- exp (±∞) returns +∞.

### F.10.3.2 The exp2 functions

- exp2(±0) returns 1.
- exp2(-∞) returns +0.
- exp2(+∞) returns ∞.

### F.10.3.3 The exppm1 functions

- exppm1(±0) returns ±0.
- exppm1(-∞) returns -1.
- exppm1(+∞) returns ∞.

### F.10.3.4 The frexp functions

- frexp(±0, exp) returns ±0, and stores 0 in the object pointed to exp.
- frexp(±∞, exp) returns ±∞, and stores an unspecified value in the object pointed to exp.
- frexp(NaN, exp) stores an unspecified value in the object pointed to exp (and returns a NaN).

frexp raises floating-point exceptions.
When the radix of the argument is a power of 2, the returned value is exact and independent of the current rounding mode.
On a binary system, the body of frexp might be:

```c
*exp = (value == 0) ? 0 : (int) (1 + logb(value));
return scalbn(value, -(exp));
```

### F.10.3.5 The ilogb functions

When the correct result is representable in the return type, the returned value is exact and independent of the current rounding mode.
If the correct result is outside the range of the return type, the numeric result is unspecified and the "invalid" floating-point exception is raised.
ilogb(x), for zero, infinite, or NaN, raises the "invalid" floating-point exception and returns the value specified in 7.12.6.5.

### F.10.3.6 The 1dexp functions

On a binary system, 1dexp(x, exp) is equivalent to scalbn(x, exp).

### F.10.3.7 The log functions

- log(±0) returns -∞ and raises the “divide-by-zero” floating-point exception.
- log(1) returns +0.
- log(x) returns a NaN and raises the “invalid” floating-point exception for x < 0.
- log(+∞) returns +∞.

### F.10.3.8 The log10 functions

- log10(±0) returns -∞ and raises the “divide-by-zero” floating-point exception.
- log10(1) returns +0.
- log10(x) returns a NaN and raises the “invalid” floating-point exception for x < 0.
- log10(+∞) returns +∞.

### F.10.3.9 The log1p functions

- log1p(±0) returns ±0.
- log1p(-1) returns -∞ and raises the “divide-by-zero” floating-point exception.
- log1p(x) returns a NaN and raises the “invalid” floating-point exception for x < -1.
- log1p(+∞) returns +∞.

### F.10.3.10 The log2 functions

- log2(±0) returns -∞ and raises the “divide-by-zero” floating-point exception.
- log2(1) returns +0.
- log2(x) returns a NaN and raises the “invalid” floating-point exception for x < 0.
- log2(+∞) returns +∞.

### F.10.3.11 The logb functions

- logb(±0) returns -∞ and raises the “divide-by-zero” floating-point exception.
- logb(±∞) returns +∞.
The returned value is exact and is independent of the current rounding direction mode.

### F.10.3.12 The mod functions

- mod(±x, iptr) returns a result with the same sign as ±x.
- mod(±∞, iptr) returns ±0 in the object pointed to iptr.
- mod(NaN, iptr) returns NaN in the object pointed to iptr (and returns NaN).

modf behaves as though:

```c
#include <math.h>
#include <fenv.h>
double modf(double value, double *iptr) {
    int save_round = fegetround();
    fesetround(FE_TOWZERO);
    *iptr = isinf(value);
    fesetround(save_round);
    return copysign(
        value);
```

### F.10.3.13 The scalbn and scalbin functions

- scalbn(±0, n) returns ±0.
- scalbn(x) returns x.
- scalbn(±∞, n) returns ±∞.
If the calculation does not overflow or underflow, the returned value is exact and independent of the current rounding mode.

## F.10.4 Power and absolute value functions

### F.10.4.1 The cbrt functions

- cbrt(±0) returns ±0.
- cbrt(±∞) returns ±∞.

### F.10.4.2 The fabs functions

- fabs(±0) returns +0.
- fabs(±∞) returns +∞.
The returned value is exact and is independent of the current direction mode.

### F.10.4.3 The hypot functions

- hypot (x, y), hypot (y, x), and hypot (x, -y) are equivalent.
- hypot (x, ±0) is equivalent to fabs (x).
- hypot (±∞, y) returns ±∞, even if y is a NaN.

### F.10.4.4 The pow functions

- pow (±0, y) returns ±0 and raises the “divide-by-zero” floating-point exception for y an odd integer < 0.
- pow (±0, y) returns ±0 and raises the “divide-by-zero” floating-point exception for y < 0, and not an odd integer.
- pow (±0, -∞) returns ±∞ and may raise the “divide-by-zero” floating-point exception.
- pow (±0, y) returns ±0 for an odd integer > 0.
- pow (, y) returns +0 for y > 0 and not an odd integer.
- pow (-1, ±∞) returns 1.
- pow (+1, y) returns 1 for any y, even a NaN.
- pow (x, ±0) returns 1 for any x, even a NaN.
- pow (x, y) returns a NaN and raises the “invalid” floating-point exception for finite x < 0 and non-integer y.
- pow (x, -∞) returns +∞ for |x| < 1.
- pow (x, -∞) returns +0 for |x| > 1.
