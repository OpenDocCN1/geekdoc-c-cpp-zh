# Returns

+   10 The functions return the converted value, if any. If no conversion is performed, zero is returned. If the correct value overflows and default rounding is in effect (7.12.1), plus or minus HUGE_VAL, HUGE_VALF, or HUGE_VALL is returned (according to the return type and sign of the value), and the value of macro ER ER is stored in errno.
