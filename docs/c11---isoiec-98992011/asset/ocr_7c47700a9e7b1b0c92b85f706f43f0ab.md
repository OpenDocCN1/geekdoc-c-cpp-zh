# Semantics

4 If both operands have arithmetic type, the usual arithmetic conversions are performed on them.

5 The result of the binary + operator is the sum of the operands.

6 The result of the binary – operator is the difference resulting from the subtraction of the second operand from the first.

7 For the purposes of these operators, a pointer to an object that is not an element of an array behaves as a pointer to the first element of an array of length one with the type of the object as its element type.

8 When an expression has integer type is added to or subtracted from a pointer, the result is the type of the pointer operand. If the pointer points to an element of an array object, and the array is large enough, the result points to an element offset from the original element such that the difference of the subscripts of the resulting and original array elements equals the integer expression. Or, if the expression P points to the i-th element of an array object, the expressions (P)+N, N+(P) and (P)–N (where N has the value n) point to, respectively, the i+n and i–n elements of the array object, provided they exist. Moreover, if the expression P points to the last element of an array object, the expression (P)+1 points past the last element of the array object, and if the expression Q points past the last element of an array object, the expression (Q)–1 points to the last element of the array object. If both pointer point to elements of the same array object, or one past the last element of the array object, the evaluation shall not overflow; otherwise, the behavior is undefined. If the result points past the last element of the array object, it shall not be used as the operand of unary * operator that is evaluated.

9 When two pointers are subtracted, both point to elements of the same array object, or one past the last element of the array object; the result is the difference of the subscripts of the two array elements. The type (a signed integer type) is ptrdiff_t, defined in the <stddef.h> header. If the result is not an element of an array object of that type, the behavior is undefined.
