If one type has a parameter type list and the other is specified by a function declarator that is not part of a definition and contains an identifier list, the parameter list shall not have an ellipsis terminator and the type of each parameter shall be compatible with the type that results from the application of default argument promotions. EXAMPLE 1 The declaration

```
int f(void), *fip(), (*pfi);
```

declares a function f with no parameters returning an int, int fip returning a pointer to an int, and a pointer pfi to a function with no parameter specification returning an int. It is essential to compare the last two. The binding of fip() is *fip(), so that the declaration suggests, and the construction in an expression requires, the calling of a function fip, and then using indirection through the pointer result to yield an int.
