# Description

+   The strncat_s function appends not than n successive characters (characters that follow a null character are not copied) from the array pointed to s2 to the end of the string pointed to s1. The initial character from s2 overwrites the null character at the end of s1. If no null character is copied from s2, s1[smax-n] is set to a null character.

# Returns

+   The strncat_s function returns 0 if there was no runtime-constraint violation. Otherwise, a non-zero value is returned.

EXAMPLE 1  The strncat_s function can be used to copy a string without the danger that the result will not be terminated or that characters will be copied past the end of the destination array.

```
#define __STDC_NULL_LIB_EXT1__ 1
#include <string.h>
/* ... */
char s1[10] = "good"
char s2[6] = "hello"
char s3[6] = "hello"
char s4[7] = "abc"
char s5[1000] = "bye"
int r1, r2, r3, r4
r1 = strncat_s(s1, s2, 1000);
r2 = strncat_s(s2, 6, ",", 1);
r3 = strncat_s(s3, 6, "X", 2);
r4 = strncat_s(s4, 7, "abcdefghijklmn");
```

After the first call r1 will have the value 0 and s1 will contain the sequence goodbye\0.
