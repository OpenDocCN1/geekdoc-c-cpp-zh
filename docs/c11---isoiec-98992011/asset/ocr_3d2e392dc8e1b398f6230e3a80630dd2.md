The macro

NAN
is defined if and only if the implementation supports quiet NaNs for the float type. It expands to a constant expression of type float representing a quiet NaN.

6 The number classification macros

```
FP_INFINITE
FP_NAN
FP_NORMAL
FP_SUBNORMAL
FP_ZERO
```

are the mutually exclusive kinds of floating-point values. They expand to integer constant expressions with distinct values. Additional implementation-defined floating-classifications, with macro definitions beginning with FP_, and an uppercase letter, may also be specified by the implementation.

7 The macro

```
FP_FAST_FMA
```

is optionally defined. If defined, it indicates that the fma function generally executes about fast as, or faster than, a multiply and add double operands.230) The macros

```
FP_FAST_FMAF
FP_FAST_FMAL
```

are, respectively, float and long double analogs of FP_FAST_FMA. If defined, these macros expand to the integer constant 1.

8 The macros

```
FP_ILOGB
FP_ILOGBNAN
```

expand to integer expressions whose values are returned by logb(x) if x is zero or NaN, The value of FP_ILOGB shall be either INT_MIN or -INT_MAX. The value of FP_ILOGBNAN shall be either INT_MAX or INT_MIN.

> 229) In this case, using INFINITY will violate the constraint in 6.4.4 and thus require a diagnostic.
230) Typically, the FP_FAST_FMA macro is defined and only if the fma function is implemented directly with a hardware multiply-add instruction. Software implementations are expected to be substantially slower.
