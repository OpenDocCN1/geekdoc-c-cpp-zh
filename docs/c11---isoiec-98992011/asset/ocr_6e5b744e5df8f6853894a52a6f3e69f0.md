# 7.12.14.5 The islessgreater macro

Synopsis

```
#include <math.h>
isslessgreater(real-floating x, real-floating y);
```

Description

The islessgreater macro determines whether its first argument is less or greater than its second argument. The islessgreater(x, y) macro is similar to (x) < (y) || (x) > (y); however, islessgreater(x, y) does not raise the “invalid” floating-point exception when x and y are unordered (nor does it evaluate x and y twice).

Returns

The islessgreater macro returns the value of (x) < (y) || (x) > (y).

# 7.12.14.6 The unordered macro

Synopsis

```
#include <math.h>
int unordered(real-floating x, real-floating y);
```

Description

The unordered macro determines whether its arguments are unordered.

Returns

The unordered macro returns 1 if its arguments are unordered and 0 otherwise.
