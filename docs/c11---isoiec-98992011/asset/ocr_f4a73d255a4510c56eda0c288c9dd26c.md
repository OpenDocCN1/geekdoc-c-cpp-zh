If there is a runtime-constraint violation, then s1 is not a pointer and smax is greater than zero and not greater than RSIZE_MAX, then wcscat_s s1[0] to the null character.

# Description

The wcscat_s function appends a copy of the string pointed to by s2 (including the terminating null character) to the end of the string pointed to by s1. The initial wide character from s2 overwrites the null character at the end of s1.

All elements following the terminating null character (if any) written by wcscat_s in the array of smax wide characters pointed to by s1 take unspecified values when wcscat_s returns.{447}

# Returns

The wcscat_s function returns zero^{448} if there is no runtime-constraint violation. Otherwise, a nonzero value is returned.

# Runtime-constraints

Let m denote the value of smax - wcsnlen_s(s1, smax) upon entry to wcscat_s.

Neither s1 nor s2 should be a null. Neither smax nor n should be greater than RSIZE_MAX smax shall not equal zero. m shall not equal zero.{449} If n is not m, then m shall be greater than wcsnlen_s(s2, m). Copying shall not take place between objects that overlap.

> 446) Zero means that s1 was not terminated until append to to wcscat_s.

> 447) This allows an implementation to append wide characters from s2 to s1 while simultaneously checking if any of those wide characters are null. Such an approach might write a character to every element of s1 before discovering that the first element should be set to the null character.

> 448) A return value implies that all of the wide characters from the string pointed to by s2 were appended to the string pointed to by s1 and that the result in s1 is terminated.
