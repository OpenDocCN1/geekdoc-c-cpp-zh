# How it works...

In the file main.h we have defined the QueueElement structure in order to load each group
of coordinates to the queue easily. In main.cpp, we have declared a few global variables:
sFilePath for the file that the user will select; szResult represents the mutex for displaying messages upon
calculation; queue for the actual queue; and szMutex for synchronization. At the application entry point (WinMain), we initialize and create the window,
 the hLabel control, which we will use for displaying the messages about user interaction;
h hResult control, which threads will use for displaying the calculation results; the hStart control, which the user
 use in order to select the file; and the hProgress control, which the application will use to display
the calculation progress.

Before the main thread enters the loop, it will create a mutex object. When the user
licks on Browse, we will display the Open dialog box for the user to choose the actual
When the user clicks the Start button, we will check if the file was previously selected.
If so, we will read one line at a time and initialize the QueueElement object.
The QueueElement object expects coordinates, and provides the handles to the progress
control and the result control. These handles will be used by the threads in order to display
the calculation and the result properly.
