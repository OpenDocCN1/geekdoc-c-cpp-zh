# There's more...

We said earlier, every application has a main thread. Additional threads are created using the CreateThread Win32 API. A prototype of the same is as follows:

```
HANDLE CreateThread( LPSECURITY_ATTRIBUTES lpThreadAttributes,
SIZE_T dwStackSize, LPTHREAD_START_ROUTINE lpStartAddress,
LPVOID lpParameter, DWORD dwFlags, LPWORD lpThreadId );
```

It is important to set a thread start address or thread routine by the lpStartAddress parameter and a value for the routine passed by the lpParameter. It is a predefined routine function and is shown in the following code:

```
typedef DWORD (WINAPI *THREAD_START_ROUTINE )
( LPVOID lpParameter );
```

Our ThreadStart method matches the prototype, and this is where the thread starts its execution. The fourth parameter of the CreateThread API is passed to the thread routine. If you need more than one parameter, you could create a class or pass the object address. You can find more on the CreateThread API on MSDN(http://cdn.microsoft.com/en-us/library/windows/desktop/ms68243d28-vs.8529.aspx).
