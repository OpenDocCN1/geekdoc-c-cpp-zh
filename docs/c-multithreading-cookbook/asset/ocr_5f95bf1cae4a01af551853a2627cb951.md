# Preface

Also very important is a step in the "How to do it" sections when we say, for example, "Add existing header file Cqueue h previously implemented in Chapter 1, Introduction to C++ Concepts and Features". What we mean by this is that you should navigate to the folder where Cqueue h file resides using Windows Explorer and you should then copy the file along with all its dependencies—in this case Listh—to the example project folder, before you add it to the project, using the "Add Existing Header File" option. By following this procedure you will be able to compile and run the example code.
