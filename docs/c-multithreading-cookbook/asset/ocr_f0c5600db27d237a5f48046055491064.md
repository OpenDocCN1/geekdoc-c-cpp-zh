# How it works...

We achieved the same thing, this time safely, using .NET's integrated features method and the BackgroundWorker property SupportsCancellation. It is not always possible to implement the described mechanism, especially in situations where you have full control over execution, and thread cancellation must be performed instantly. In such a case, you could use a bool variable (or other type) to mimic the described property, surrounded with a Lock object, to ensure exclusive access.

Let's review the code. We added FormClosingEventHandler to handle the form closing event, and we've set the BackgroundWorker Cancellation to true. Inside StartAddress, we've added the following statement:

