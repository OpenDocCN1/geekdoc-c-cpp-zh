# How it works...

First, we need to define the Cclass. We are going to store it in an array of double values ranging from -65536 to 65536, which is the range of the allowed values for this function. We will name this array allele, similar to the genome structure. Also, we will need the allele size, sum of elements, minimum value, score, the best value, and the end time.

We have two default constructors with allele size. If we use the default constructor, we'll simply create a dummy object, and we will call the Initialize method before any supply the allele size. However, we can use another constructor with built-in initialization, but the second one is the obvious choice. We need to implement the set and get methods for our examples. double* Allele(void) returns the pointer to the allele index of a class object Allele(unsigned uIndex) Allele(double dvalue, unsigned uIndex) sets the value with dvalue and returns the newly-added value. The unsigned Size(void) attribute returns the allele size; unsigned Size(unsigned uSize) sets a new array and returns the newly-added size.

The Sum, Min, Score, StartTime, and EndTimes return a reference to the class attributes d, dmin, dbest, stStart, and stEnd so that we can use these methods for the set and get methods at the same time. Initialize(void) and Initialize(unsigned uSize) methods fill the allele array with random values from -65536 to 65536, and at the same time, calculating the sum of the allele and min value from the same array.

The Evaluate(void*) method as well are declared as virtual methods because the derived classes can change the evaluation sequence or the approach that we will follow for our concurrent approach later on. The Elapsed(void) and Elapsed(TCHAR*) methods simply write the output to the console. We also add the constant value, ThreadName, which we will use to set the maximum allowed threads. You can change this to any preferred one.

In the protected scope, we've placed a copy constructor and overloaded operator= (in order to disable the programmer from using them because the default copy operation is performed in a manner such that all the class attributes' values are copied by one. This is OK for any integer type but not for pointers. It is not enough to copy a pointer value--this would mean that the pointers from both the objects point to the same array or any other memory that is referenced by this pointer. You must implement both the copy constructor and the equal operator to allocate new memory and copy the values that the old pointer refers to, one by one. The TCHAR* ObjectName simply returns the class name when formatting the output string in the Elapsed method. In each of our derived classes, we will overload the ObjectName method to return the correct overloaded class name.
