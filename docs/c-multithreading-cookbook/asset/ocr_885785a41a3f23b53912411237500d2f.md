In examples to come, we will use Charles Simonyi's Hungarian notation. In his PhD in 1977, he used Meta-Programming – A software production method to make a standard for notation in programming, which says that the first letter of type or variable should represent the data type. For the example class that we want to call, a Test data type should be CTest, where the first letter says Test is a class. This is good practice because a programmer who is not familiar with the Test data type will immediately know that Test is a class. The same stands for primitive types, such as int or double. For example, iCount for an integer Count, while dValue for a double variable Value. Using the given prefixes, it is easy to read code even if you are not so familiar with it.

# How it works...

The structure of a C++ program varies due to different programming techniques. What most programs must have is the #include or preprocessor directives.

The include <iostream> header tells the compiler to include the iostream.h header file where the available function prototypes reside. It also means that libraries with the 'functions' implementations should be built into executables. So, if we want to use some API or function, we need to include an appropriate header file, and maybe we will have to add an additional input library that contains the function/API implementation. One more important difference when including files is <header> versus "header". The first (<>) solution-configured project paths, while the other (") targets folders relative to the C++ project.
