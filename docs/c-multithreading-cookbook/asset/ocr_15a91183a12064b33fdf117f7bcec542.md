# Understanding parallelism in code design

We have properly said that the most difficult work for a programmer is not to create the code—it is to properly design the application. When you follow these steps, after creating a good and stable design, you only have one step left: to write the code following the created design by step. Our following example will teach you in a step-by-step manner how to approach the application creation from scratch, and at the same time think about how to add parallelism.

We will create a program that will calculate Schwefel's function. Usually, for the calculation of Schwefel's function and simple functions where probability and statistics make a significant difference in the results genetic algorithm is used. This is because such an algorithm generates a huge population of genomes with its features, and compares their score (result).
