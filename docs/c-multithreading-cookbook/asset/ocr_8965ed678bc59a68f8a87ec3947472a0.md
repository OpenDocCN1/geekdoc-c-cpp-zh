# # Getting ready

Make sure that Visual Studio is up and running.

# # How to do it...

Now, let's create the CSwefelMT class and explain its structure. Perform the following steps:

+   1. Open Solution Explorer and open the file stdafx.h. Copy and paste the following code to it:
```cpp
#pragma once

#include "targetver.h"

#include <stdio.h>
#include <char.h>
#include <Windows.h>
#include <float.h>
#include <time.h>
#include <omp.h>

#include "SchwefelMT.h"
#include "SchwefelMT.h"
```

+   2. Open Solution Explorer and right-click on Header file. Add a new header file named SchwefelMT. Open SchwefelMT.h. Copy and paste the following code to it:
```cpp
#ifndef __SCHWEFELMT_
#define __SCHWEFELMT_

#include "stdafx.h"

class CSwefelMT : public CSwefel {
public:
    CSwefelMT() : CSwefel() {}
    CSwefelMT(unsigned uSize) : CSwefel(uSize) {}
    virtual CSwefelMT(void) {}
    virtual double Evaluate(void* lParameters = 0);
protected:
    CSwefelMT(const CSwefel&) : (const CSwefel&) {}
    operator = (const CSwefel&) { return *this; }
```
