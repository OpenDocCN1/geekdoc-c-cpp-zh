# Introduction to C++ Concepts and Features

The using command instructs the compiler to use the std namespace. Namespaces are packages with object declarations and function implementations. Namespaces have a very important usage. They are used to minimize ambiguity when including third-party libraries when the same function name is used in two different packages.

We need to implement a program entry point--the main function. As we said before, we can use main for ANSI signature, wmain for a Unicode signature, or _main where the compiler will resolve its signature depending on the preprocessor directives project properties. For a console application, the main function can have the four different prototypes:

+   * int _main(int argc, TCHAR* argv[])
* void _main(int argc, TCHAR* argv[])
* void _main(void)

The first prototype has two arguments, argc and argv. The first argument, argc, or the argument count, says how many arguments are present in the second argument, argv, or the argument values. The argv parameter is an array of strings, where each string represents one command-line argument. The first string in argv is the current program name. The second prototype is the same as the first, except the return type is returned to the OS. This means that the main function or may not return a value. This value is returned to the caller. The third prototype has no arguments and returns an integer value, while the fourth prototype neither has arguments nor returns a value. It is good practice to use the first format.

The next command uses the cout object. The cout object is the name of the standard output stream in C++, and the meaning of the entity statement is to insert a sequence of characters (in this case, the Hello world sequence of characters) into the standard output stream (usually corresponds to the screen).

The cout is declared in the iostream standard file within the std namespace. This is why we need to include the specific file and declare that we will use this specific namespace in our code.

In our selection of the (int _main(int,TCHAR**)) prototype, _main returns an integer. We may specify some value after the return command, in this case 0. When returning a value to the operating system, o usually means success, but this is operating system dependent.
