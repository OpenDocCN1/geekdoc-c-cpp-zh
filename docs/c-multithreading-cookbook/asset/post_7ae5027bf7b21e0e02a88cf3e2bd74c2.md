# How it works...

The purpose of this example was to demonstrate the basic message passing. You need to pay close attention to the BUTTON_CLOSE and LABEL macros that we defined earlier. We need them later as child-control identifiers. For a child window, hMenu specifies the child-window identifier.

> The child-control identifier is an integer value used by the window to notify its parent about events. The application determines the child-window identifier, it must be unique for all child windows for the same parent window (from MSDN).

Let's examine the WinMain entry point now. We created the WNDCLASS instance and initialized it. After a successful window class registration with subsequent call to RegisterClassEx, we create a main window, followed by a call to CreateWindow.
