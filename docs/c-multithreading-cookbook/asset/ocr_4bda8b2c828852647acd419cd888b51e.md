The CThreadPool classes implements the actual pool. It has two attributes: a pointer to the list of items and the maximum possible number of threads that can be created by the pool. It has constructor: one where thread max count is set by default using the machine's number of logical processors. The second constructor has one argument--the actual maximum threads pool can instantiate. In the destructor, we'll use the RemoveAll method to free the resources. The Count method returns the count of items on the list. The RemoveThread method searches for the thread specified argument and if found, it removes it. The Thread creates an array of thread handles that will be used in the WaitMultipleObjects API setting TRUS for the bWaitAll parameter in order to wait for all threads to finish. After WaitMultipleObjects returns, it deletes the array of handles. The RemoveAll method removes all threads from the list using the RemoveThread method for each thread in the list. The MaxCount method returns the dwCount attribute to get or set its value. The pool can increase or decrease its size, if necessary. The RequestThread method searches for the thread specified by the dwThread parameter and returns the handle of that thread. The RequestThread method is used for obtaining a free thread. If the maximum number of threads is not reached, the method creates a new thread and inserts it into the list. If the maximum is already reached, the method iterates through the entire list and queries the exit code for each thread.

If all threads are active, it waits for 0.1 seconds and tries again until it finds the first thread or creates a new one with the start address provided by the user.

main.cpp, we have created the Random function to obtain a random double number in dmin to dmax range. In the application entry point, we'll set a random generator to the current time and create twelve bank accounts with random balance values. Then we'll instantiate the pool with five tasks to process. For each task, we'll select a random bank account and find another (random) bank account that must be different from the first one. After both accounts are found, we'll perform a transfer with a random value, using the RequestThread and Start methods. After we set all tasks, we'll call the WaitAll method in order to wait for the completion of the task. When WaitAll returns, we can delete the pool.
