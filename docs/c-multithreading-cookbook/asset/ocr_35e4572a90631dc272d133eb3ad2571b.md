# How it works...

This is a simple example that demonstrates basic thread thread usage. The idea was to somehow split the problem and distribute it among the threads in order to reduce the execution time by adding parallelism (divide and conquer). As we said earlier, the ability to divide the problem into smaller units (dependent or independent) makes it easier for us to create parallel logic in implementation, while at the same time, using system resources makes our application faster and more optimized.
