
# How it works...

First, we need to define the Class. We are going to store it in an array of double values ranging from -65536 to 65536, which is the range of the allowed values for this function. We will name this array allele, similar to the genome structure. Also, we will need the allele size, sum of elements, minimum value, score, the best value, and the end time.

We have two default constructors with allele size. If we use the default constructor, we'll simply create a dummy object, and we will call the Initialize method before any supply the allele size. However, we can use another constructor with built-in initialization, but the second one is the obvious choice. We need to implement the set and get methods for our examples. `double* Allele(void)` returns the pointer to the allele index of a class object. `Allele(unsigned uIndex)` `Allele(double dvalue, unsigned uIndex)` sets the value with dvalue and returns the newly-added value. `unsigned Size(void)` attribute returns the allele size; `unsigned Size(unsigned uSize)` sets a new array and returns the newly-added size.

The Sum, Min, Score, StartTime, and EndTimes return a reference to the class attributes d, dmin, dbest, stStart, and stEnd so that we can use these methods for the set and get methods at the same time. `Initialize(void)` and `Initialize(unsigned uSize)` methods fill the allele array with random values from -65536 to 65536, and at the same time, calculating the sum of the allele and min value from the same array.

The `Evaluate(void*)` method as well are declared as virtual methods because the derived classes can change the evaluation sequence or the approach that we will follow for our concurrent approach later on. `Elapsed(void)` and `Elapsed(TCHAR*)` methods simply write the output to the console. We also add the constant value, ThreadName, which we will use to set the maximum allowed threads. You can change this to any preferred one.

In the protected scope, we've placed a copy constructor and overloaded operator= (in order to disable the programmer from using them because the default copy operation is performed in a manner such that all the class attributes' values are copied by one. This is OK for any integer type but not for pointers. It is not enough to copy a pointer value—this would mean that the pointers from both the objects point to the same array or any other memory that is referenced by this pointer. You must implement both the copy constructor and the equal operator to allocate new memory and copy the values that the old pointer refers to, one by one. The `TCHAR* ObjectName` simply returns the class name when formatting the output string in the Elapsed method. In each of our derived classes, we will overload the ObjectName method to return the correct overloaded class name.

# Understanding Concurrent Code Design

In the private scope, we've placed the `Random(double dMin, double dMax)` and `Seed(void)` methods that return a random number from dMin to dMax and seed for a random generator respectively.

As previously mentioned, the Evaluate methods were declared as virtual, and for the Schwefel class, implementation is straightforward. First, we call the GetSystemTime API, with Start as the parameter in order to store the time before we start calculating; then, inside the outer loop, we'll calculate the sum and multiply it with itself. According to Schwefel's formula, we'll add it to code and calculate the best value. When in the outer loop, we'll GetSystemTime with the std parameter in order to obtain the system time again. When we subtract these two times, we'll get the elapsed time for calculation. One thing about the Evaluate method: for the sake of future implementation (for example, class derivation), we've planned one argument but you can pass as many arguments as you like in a manner—just like any of our examples, which use some routine for the CreateThread API.

Since the SYSTEMTIME structure does not implement for the SYSTEMTIME subtraction, we'll implement our own: `SYSTEMTIME operator - (const SYSTEMTIME& stFirst, const SYSTEMTIME& stSecond);`; This method, we'll convert the system time to file time using the SystemTimeToFile API so that we get the integer value from the human-readable time for both the arguments. Then, we'll subtract these two integers and we'll convert the result to a human readable time using the FileTimeToSystem API.

In our application's entry point, we'll simply instantiate the Schwefel object with a size of 100,000 alleles and call the Evaluate and Elapsed methods.

DWORD WINAPI SchwefelMT::StartAddress(LPVOID lParameter)
{
    ThreadParams* params = (ThreadParams*)lParameter;
    unsigned uChunk = ((unsigned)params->this_ptr->Size()) /
    ThreadNumber; 
    unsigned uMax = (params->uThreadIndex + 1) * uChunk;

    for (unsigned i = params->uThreadIndex * uChunk; i < uMax; i++)
    {
        params->this_ptr->Sum() += params->this_ptr->Allele(i);
    }

    if (params->this_ptr->Min() > params->this_ptr->Allele(i))
    {
        params->this_ptr->Min() = params->this_ptr->Allele(i);
    }

    double dInnerSum = 0;
    for (unsigned j = 0; j < i; j++)
    {
        dInnerSum += params->this_ptr->Allele(j);
    }

    double dTmp = dInnerSum * dInnerSum;
    params->this_ptr->Score() += dTmp;

    if (i != 0 && params->this_ptr->Best() > dTmp)
        params->this_ptr->Best() = dTmp;

    return 0L;
}
