# Introduction to C++ Concepts and Features

One of the most important settings that you need to change when building 64-bit executables is under Project properties. Press Alt + F7, or select Project properties in Solution explorer after right-clicking on the Test project. The Test Property Pages window will appear. Expand Configuration Properties and C/C++, select Preprocessor. Under Preprocessor definitions, you'll see certain values from the Win32 settings. You'll need to change WIN32 to WIN64 in order to build a 64-bit executable. Leave the rest as is.

Whether you build 32 or 64-bit code, there is one more thing that you need to set properly, which is code generation. You can select whether your application will depend on Dynamic Link Libraries (DLL) for C++ runtime on the user PC. If you create an application that runs on one PC than the PC where it is created, you'll need to think about this. On the PC you use, the required C++ runtime is already installed, so this does not matter. On other PCs, for example, C++ runtime isn't installed, this might cause issues. You'll need to be sure that no dependency is required, you'll need to change the Runtime option to Multi-threaded (/MT) or Multi-threaded Debug (/MTD) for the Debug, or Release mode can be switched in the Solution Configurations combobox.

For our examples, you can leave everything as it is because 32-bit executables can be run on 32-bit and 64-bit machines. The runtime library can also be left as default because the application will run fine on the PC where it is built as the required C++ Redistributable framework is already installed.

# Program structure, execution flow, and runtime objects

A programming paradigm is a fundamental style of computer programming. There are four main paradigms: imperative, declarative, functional (or structural), and object-oriented. The C++ language is certainly the most popular object-oriented language today. It is a very powerful, flexible, and comfortable programming language. Program adopted it very gladly and quickly, The key to such success lies in the fact that it was made by a single programmer, adjusting it to his needs.

Unfortunately, C++ isn't an easy language at all. Sometimes, you can think that it is a limitless language that cannot be learned and understood entirely, but you don't need to worry about that. It is not important to know everything; it is important to use the parts that are required in specific situations correctly. Practice is the best teacher, so it is better to understand how to use as many of the features as needed.
