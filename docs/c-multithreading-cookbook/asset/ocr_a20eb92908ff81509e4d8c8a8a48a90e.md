# How it works...

We created a new type, CFigure. We would like to create some real figures, such as triangles, squares, circles, and methods that will calculate their circumference and area. You'll agree that we can't calculate these features for the figure itself because we don't know what type of real figure it is. This is why we use CFigure as an abstract class. An abstract class is a class where at least one of its virtual methods is declared with no implementation and has =0 after its prototype. Functions declared in such manner are pure virtual functions. Abstract classes can't have objects, inherited classes can. You can instantiate pointers and references of abstract classes. We extend the CTangle, CSquare, and CCircle classes that represent triangles, squares, and circles, respectively. In these derived classes, we implement the FigureType, Circumference, and Area methods because we want to have the ability to instantiate these types of objects.
