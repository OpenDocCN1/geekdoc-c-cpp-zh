# How it works...

While threads are created as a foreground, tasks are not. They are, by default, created as background threads. In your development, you should carefully choose which type of thread you need and select the appropriate one. For example, if we want to calculate a large factorial (for example, 10,000), it would take a long time, and we would use the Task object in order to be able to interrupt execution by closing the application. On the other hand, if our program must complete its task without any interruption from the user (even though there are other ways to prevent this), we would use the Thread object and its ability to perform tasks as a foreground thread.

# There's more...

We'll point out that you could use the Thread object for both types of execution, foreground and background, while the Task object cannot be used for this. In order to use Thread as a background thread, you would only change its IsBackground property to true before starting it. The code to do so is follows:

```
Thread thread = new Thread(
  new ParameterizedThreadStart(&MyForm::StartAddress));
thread->IsBackground = true;
thread->Start(this);
```

# Understanding the .NET synchronization essentials

After basic thread operations such as starting the thread or task and providing its start address, .NET also provides synchronization mechanisms. These mechanisms are important in order to understand the proper use of threads for concurrent operations without interfering with threads. Furthermore, we will explain blocking mechanisms, locking, signaling, and non-blocking synchronization.

In .NET, the blocking methods are Thread::Sleep, Thread::Join, and Task::Wait. It is better to block the thread instead of spinning and wasting processor time. When we say, we think of a loop where a thread will iterate the loop until some condition is satisfied. The Sleep method simply changes the thread state to suspended for a certain period of time. The Join method blocks the calling thread until the running thread terminates. The Wait method waits for Task to complete its execution within a specified time interval.
