# # How it works...

We choose to draw an 800 x 600 (pixels) figure in our example. That's why we've set iWidth to 800 and iHeight to 600. Then, we'll allocate Bitmap and the color array. We will draw a symmetrical left and right part of the canvas, we will iterate through half of the pixels' width. That's why we'll set the maximum to iWidth / 2. When we click the Start button, we'll create a method delegate in order to pass it the Tasks::Invoke method. Before we call a parallel invoke, we need to instantiate the barrier object with two participants and a postAction method delegate. This post action method delegate is important for because we want to draw the figure after the entire calculation is done. We could accomplish this with an event, or we could post a message to the window message queue, but this is the proper way when using threads: post action method is Enfin, which needs to draw the plot and set the label text. We must use delegates to invoke proper methods because a different thread will make this call and we will avoid cross-thread operations with UI elements.
