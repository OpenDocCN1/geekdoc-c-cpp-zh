# Advanced Thread Management

7. Open Solution Explorer and right-click on Source files. Add a new source file named
main. Open main.cpp. Copy and paste the following code:

```
#include "main.h"
#include "CBankAccount.h"
#include "CThreadPool.h"

int main(void)
{
    int i = 0;
    while (i++ < 10)
    {
        CBankAccount* a = new CBankAccount(200);
        CBankAccount* b = new CBankAccount(200);

        CThreadPool* pool = new CThreadPool(4);

        CParameters* params1 = new CParameters(a, b, 100);
        pool->RequestThread(CBankAccount::Transfer)->SetMaxWaitTime(
6000)->Start(params1);

        CParameters* params2 = new CParameters(b, a, 50);
        pool->RequestThread(CBankAccount::Transfer)->Start(params2);

        pool->WaitAll();
        delete pool;
    }

    #ifdef _DEBUG
    return system("pause");
    #endif
    return 0;
}
```

# How it works.

Let's explain header files. In main.h, we have included necessary Windows headers. We
also define two macros: MSG_ENDTASK used for posting the message about a completed task
from the worker to the dispatcher and MAX_WAIT_TIME in order the thread not to wait too
long for its context thread. The maximum waiting time could be increased or decreased from
t CThread object using the SetMaxWaitTime method, which we will explain later.
