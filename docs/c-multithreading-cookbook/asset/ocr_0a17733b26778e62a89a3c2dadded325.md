# Using the BackgroundWorker class

As we said, EAP is a very good mechanism, which enables a programmer to create multithreaded applications easily and with much less coding. The BackgroundWorker object is a general-purpose implementation of EAP, and has many good features, such as the handy cancellation model, the ability to safely update another thread's UI controls, the reporting progress feature, exception forwarding, raising completion, and more. We will now implement our functional example using the BackgroundWorker class that resides in System::ComponentModel namespace.
