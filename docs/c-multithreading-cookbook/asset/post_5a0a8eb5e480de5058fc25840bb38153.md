A programming paradigm is a fundamental style of computer programming. There are four main paradigms: imperative, declarative, functional (or structural), and object-oriented. The C++ language is certainly the most popular object-oriented language today. It is a very powerful, flexible, and comfortable programming language. In examples to come, we will use Charles Simonyi's Hungarian notation. In his PhD in 1977, he used Meta-Programming – A software production method to make a standard for notation in programming, which says that the first letter of type or variable should represent the data type. For the example class that we want to call, a Test data type should be CTest, where the first letter says Test is a class. This is good practice because a programmer who is not familiar with the Test data type will immediately know that Test is a class. The same stands for primitive types, such as int or double. For example, iCount for an integer Count, while dValue for a double variable Value. Using the given prefixes, it is easy to read code even if you are not so familiar with it.

# How it works...

The main function is the entry point for every C++ program. As we said before, we can use main for ANSI signature, wmain for Unicode signature, or _main where the compiler will resolve its signature depending on preprocessor directives. For a console application, the main function can have four different prototypes:

- int main(int argc, char* argv[])
- void main(int argc, char* argv[])
- void main(void)

The first prototype has two arguments, argc and argv. The first argument, argc, or the argument count, says how many arguments are present in the second argument, argv, or the argument values. The argv parameter is an array of strings, where each string represents one command-line argument. The first string in argv is the current program name. The second prototype is the same as the first, except the return type is returned to the OS. This means that the main function may not return a value. The third prototype has no arguments and returns an integer value, while the fourth prototype neither has arguments nor returns a value. It is good practice to use the first format.

The next command uses the cout object. The cout object is the name of the standard output stream in C++, and the meaning of the entity statement is to insert a sequence of characters (in this case, the Hello world sequence of characters) into the standard output stream (usually corresponds to the screen).

The cout is declared in the iostream standard file within the std namespace. This is why we need to include the specific file and declare that we will use this specific namespace in our code.
