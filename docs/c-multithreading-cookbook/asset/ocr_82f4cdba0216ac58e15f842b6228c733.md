# How it works...

As you will, the deeper we go into the framework's features, the less development and coding effort is needed. In our previous variations of factorial application, we had to implement delegates in order to manipulate with different UI controls. BackgroundWorker does all for that with integrated events such as ProgressChanged or RunWorkerCompleted. These features making a lot easier. Here, you need not worry about cross-thread operations, which are also a programmer's nightmare. Programming logic becomes a lot simpler; just review the code. Major changes were done inside Initialize where we had to create the BackgroundWorker object, we had to provide methods for delegate events and also set the WorkerReportsProgress to true. Note that, in order to match the event prototype, we had to change the StartAddress prototype's signature to:

```
System:Void StartAddress(Object sender, DoWorkEventArgs e)
```

We can still pass an argument via the RunWorkerAsync method and obtain it later, the StartAddress method via the Argument attribute of the DoWorkEventArgs object. When we want to raise a ProgressChanged event, we simply call the BackgroundWorkerReportProgress method and pass an integer as the argument, which tells how much of the progress will be updated. Execution, that's why we've registered the RunWorkerCompleted event. When the thread exits, it is raised.

# There's more..

Unlike the Thread class, which is implemented as a sealed class, BackgroundWorker is not. This means you could subclass and derive your own version of the BackgroundWorker object, which will be expanded for any need that you have. This might come in handy when you have a complex task, such as a weather forecast prediction, where your BackgroundWorker class has numerous attributes in order to save a lot of data that needs to be processed. Note that you need to use the OnDoWork virtual method in class of deriving the BackgroundWorker class. One variation should look like this:

```
ref class Worker : BackgroundWorker
{
public:
    Worker() : BackgroundWorker()
    {
        WorkerReportsProgress = true;
    }
protected:
    virtual void OnDoWork(DoWorkEventArgs e) override
{}
```
