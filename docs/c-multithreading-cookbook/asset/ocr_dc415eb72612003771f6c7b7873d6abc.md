# Message Passing –

Now, let's review request processing. After we've obtained a handle to a pipe, we need to allocate enough heap memory for the request as well as for the response. We will use ReadFile from the other end of the pipe and then do some processing. The response is sent using WriteFile in the following manner:

```
WriteFile(hPipe, sReply, dwReplyBytes, &dwBytesWritten, NULL);
```

Now, let's review the client: We can open the pipe in two ways: CreateFile or the CallNamedPipe API. The client needs to wait for the server until the pipe is available. The execution will continue when the server calls ConnectNamedPipe, and then the thread gets suspended. We are using WriteFile and ReadFile in the same manner like we did in the server process. When all the processing is done, we must close the pipe handle.
