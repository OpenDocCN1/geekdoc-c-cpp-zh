# Threads in the .NET Framework

```
String^ szValues = gcnew String(L" ");

for each (int iValue in lst)
{
szValues += iValue + L" ";
}

MessageBox::Show(szValues, (String^)_tParams[1]);

```

As said before, each thread will get a different enumerating object. Hence, we say that it is thread-safe. Another feature that .NET provides us is the initonly keyword, which enables a concurrent read operation to be safe. So when two (or more) threads are accessing it, it is safe. The sure code follows:

```
ref class SafeValue{
public:
    SafeValue( void ) { }
    void Run( void )
    {
        Task^ _t1 = gcnew Task(gcnew Action(&iValue ) );
        _t1->Start( );
    }
    Task^ _t2 = gcnew Task(gcnew Action(&iValue ) );
        _t2->Start( );
    }
protected:
    -SafeValue( void ) { }
private:
    static void AccessValue( void )
    {
        MessageBox::Show( Convert::ToString( SafeValue::iValue ) );
    }
    static initonly int iValue = 10;
}

int main()
{
    SafeValue^ safeValue = gcnew SafeValue();
    safeValue->Run( );
}
```
