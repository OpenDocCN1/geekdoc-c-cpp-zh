# How it works...

We are using the CThread class that we've implemented in the previous example. As we said, we need to include it in order to use it. So, we created the Thread class that is derived from CThread. There is a routine, Run, which we must define (implement) as it declared above.

Let's explain the Run routine. First, we will calculate the window rectangle size. We need these coordinates in order to sustain what window to paint. For that purpose, we will use the GetClient API. Then we will determine the color so that we can create a proper brush. Now we need the device context in order to paint. The GetDC API is used. We will use CreateSolidBrush in addition to the GetNearestColor to get a known color. After using resources, we will free them by calling proper methods such as DeleteBrush and ReleaseDC respectively.
