+   c. wavethresh
Wavethresh function draw can be used to plot mother and fatherlets. For example, the command
draw(filter.number=2,family='DaubExPhase',enhance=FALSE,scaling=FALSE)
plots the Daub(4) in our notation. See the note at the end of Section 12.3.2 regarding wavelet numbering. The command
draw(filter.number=2,family='DaubExPhase',enhance=FALSE,scaling=TRUE)
plots the recurring father wavelet (scaling function). In wavethresh, the Daubelets are referred to as the wavelet family DaubExPhase while the Symlet (least asymmetric) wavelets are called DaubleAsym. Again, for a Dalet(4), that is, the D4 wavelet in our notation, you would use filter.number=2 and family='DaubExPhase'.

+   d. waveband
As mentioned in Example 12.4, the test.data generates test signals from CRAN package waveband studied by Donne and Johnstone (1994). For example, the code below
best.data(type='bumps',n=256,signal=1,rsnr=7,plot fn=TRUE)
generates the bumps256 signal used above. Specifically, based on this command, b$ contains the bumps256 signal and bnoise is a vector containing a noisy signal in which the ratio of the standard deviation of the function to the standard deviation of the simulated errors is 7. Other test functions generated by test.data apply poly (piecewise polynomial), blocks, heavi (heavisine), and doppler.
