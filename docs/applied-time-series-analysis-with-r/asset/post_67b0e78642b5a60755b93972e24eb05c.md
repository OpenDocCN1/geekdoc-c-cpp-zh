
is.sample.wge(data, lambda, offset, phi) computes and plots the instantaneous spectrum based on a spectral estimate of the dual using a Parzen window.

lambda is the value of λ in the G(λ; p) model (default lambda = 0, i.e. an M-stationary model)

offset is the offset parameter (see for example the discussion about Figure 13.2 (default = 60))

Example: To compute the instantaneous spectrum based on a periodogram fit to the dual data in Figure 13.4b obtained from the data in Figure 13.2c (and Figure 13.4a), using the following commands:

```
data(fig13.2)
is.sample.wge(fig13.2c, lambda = -0.4, offset = 63)
```

Compare with the AR-based instantaneous spectrum shown in Figure 13.8c.

data(fig13.18a)
