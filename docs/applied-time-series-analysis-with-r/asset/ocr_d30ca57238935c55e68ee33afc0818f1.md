est.garma.wge(x,low.u,low.lambda,high.u,lambda,inc.u,inc.lambda,p.max,nback) is a function that obtains parameter estimates of a GARMA(p,d,q) model using the grid-search algorithm discussed in Section 11.5.

low.u is the vector of lower boundaries of u's in the grid search
low.lambda is the vector of lower boundaries of λ's in the grid search
high.u is the vector of upper boundaries of u's in the grid search
high.lambda is the vector of upper boundaries of λ's in the grid search

inc.u is the increment for u's in the grid search
inc.lambda is the increment for λ's in the grid search
p.max is the maximum AR order
back is the number of backcast observations (see discussion following Equation 11.27)

The program outputs:
uu (the estimate of u)
lam (the estimate of λ)
phi (the estimates of the parameters $\phi_1, \dots, \phi_q$)
vara (the estimated white noise variance (based on backcast residuals))
ic associated with the final GARMA fit

+   NOTES:
1. If you use est.garma.wge to estimate the parameters of a FARMA model by restricting u to be 1, then based on the fact that $(1-2B+B^2)^\lambda=(1-B)^{2\lambda}$, the resulting estimate of $d$ would be 2 (or min(2,4)) to retain a stationary model.
2. We only consider the case in which there is onebauer factor.
3. We assume q=0, i.e. there are no MA factors in the model.
4. The tswge function ar.burg2.wge is used by est.garma.wge.

Example: We use est.garma.wge to implement the gridsearch procedure to estimate the parameters of the 1-factor GARMA(1,0,45,8,0) model in Example 11.8(1). The statement test=est.garma.wge(fig11.12,low.u=.6,low.lambda=.2,high.u=.95,high.lambda=.85,inc.u=.05,inc.lambda=.02,p.max=3)

performs the calculations using the grid described in Example 11.8(1) and obtains output consistent with that given in Example 11.8(1).
