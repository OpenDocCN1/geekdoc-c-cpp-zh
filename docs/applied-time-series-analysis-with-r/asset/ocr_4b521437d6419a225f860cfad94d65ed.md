# Proof of Theorem 3.2

(Necessity) Suppose the roots of the characteristic equation all lie outside the unit circle. Now, we need to show that $\sum_{t=0}^\infty |\psi(p)| < \infty$. Now if $p=1$, $\psi_1(p)=\alpha'_1$, and since $|\alpha_1| < 1$, then $\sum_{t=0}^\infty|\psi_t(p)| = \sum_{t=0}^\infty|\alpha_1|^t < \infty$. For $p>1$, we rewrite Equation 3.27) as

```
$\sum_{k=1}^p c_k(\alpha_p^{\ell+1}-\alpha_{p-k}^{\ell+1}),$
```

and note that the coefficients,

```
$c_k = \frac{\alpha_{p-k}^{p-1}}{(\alpha_p-\alpha_{p-k})\prod_{h=1, h
eq k}^{p-1}(\alpha_{p-k}-\alpha_h)}$
```
