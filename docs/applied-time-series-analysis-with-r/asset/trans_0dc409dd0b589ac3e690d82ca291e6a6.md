

# 使用 R 进行应用时间序列分析

正如我们所出的，自相关性在时间序列分析中起着核心作用。然而，当我们想要确定数据的频率或周期内容时，自相关性中的相关信息通过自相关性的傅里叶变换（称为谱密度）传递得更为直观，而不是通过自相关性本身。功率谱和谱密度是检查时间序列数据中频率内容的主要工具，其定义如下。

## 定义 1.11

设 $[X(t); t \in (-\infty,\infty)]$ 为平稳时间序列。

- 1. 功率谱 $P_X(f)$ 定义为：

$$P_X(f) = \int_{-\infty}^{\infty} e^{-2\piif}\gamma(h)dh, \quad (1.23)$$

其中 $-\infty < f < \infty, i = \sqrt{-1}$ 是协方差函数。（注：原文为“是协方差函数”，但上下文暗示是自相关或笔误，此处保留原文）。

- 2. 谱密度是 $P_X(f)$ 的归一化版本。具体而言，我们定义的谱密度 $S_X(f)$ 为：

$$S_X(f) = \frac{P_X(f)}{\sigma_X^2} = \int_{-\infty}^{\infty} e^{-2\piif}\rho(h)dh. \quad (1.24)$$

功率谱通常被简单称为谱。定义 1.11 要求索引集 $T$ 是连续的。可以给出一个包含离散情况的更通用的定义。然而，这将需要我们在定义中使用 Stieltjes 积分。读者若需了解此类方法请参考 Priestley (1981) 和 Koopmans (1974)。我们则选择单独考虑离散参数的情况。

## 定义 1.12

设 $[X_i; t=0, \pm1, \pm2, \dots]$ 为平稳时间序列，并令 $|f| \le 0.5$。

- 1. $X_i$ 的功率谱定义为：

$$P_X(f) = \sum_{k=-\infty}^{\infty} e^{-2\piif}\gamma_k. \quad (1.23)$$

- 2. 谱密度定义为：

$$S_X(f) = \frac{P_X(f)}{\sigma_X^2} = \sum_{k=-\infty}^{\infty} e^{-2\pi ikf}\rho_k. \quad (1.26)$$

如果

$$\sum_{k=-\infty}^{\infty} |\gamma_k| < \infty, \quad (1.27)$$

则可以证明方程 1.25 和 1.26 中的序列收敛，且：

$$\gamma_k = \int_{-0.5}^{0.5} e^{2\pi ikf}P_X(f)df, \quad (1.28)$$

即谱和自协方差函数是傅里叶变换对。因此，给定满足方程 1.27 的平稳过程的谱，可以从数学上得到自协方差函数，反之亦然。方程 1.25 和 1.28 中的结果表明，过程传递了关于该过程的信息。自协方差在时域传递这些信息，而谱则在频域表示等效的信息。我们将看到，对于特定的应用，其中一个可能比另一个提供关于过程更易理解的信息。自相关与谱密度之间也存在类似的关系。

我们将此留作练习，证明定义 1.12 中的 $P_X(f)$ 和 $S_X(f)$ 可以写为：

$$P_X(f) = \sigma_X^2 + 2\sum_{k=1}^{\infty} \gamma_k \cos(2\pi kf), \quad (1.29)$$

以及

$$S_X(f) = 1 + 2\sum_{k=1}^{\infty} \rho_k \cos(2\pi kf), \quad (1.30)$$

同样限制 $|f| \leq 0.5$。

## 尼奎斯特频率

定义 1.12 似乎是定义 1.11 的自然离散版本，除了对参数 $f$ 范围的限制。对于单位增量采样的离散时间数据，可以观测到的最短周期是 2，即最高频率为 0.5。这被称为尼奎斯特频率。例如，考虑两个信号 $Y_t = \cos(2\pi(0.3)t)$ 和 $Z_t = \cos(2\pi(1.3)t)$，它们的频率分别为 0.3 和 1.3。这些信号定义在连续线上，但我们考虑在整数处采样的情况。在图 1.13 中，我们了这两个信号的叠加，有趣的是，这两个信号在 $t$ 取整数值时是相等的。这些公共值由图中的圆圈表示。因此，在整数处采样时，这两个信号是区分的。这种现象被称为*混叠*（aliasing），因为频率 $f=1.3$ “看起来”是 $f=0.3$。对于离散数据，由于无法检测到小于 2 个样本的周期，因此在离散情况下我们必须限制 $|f| \le 0.5$ 并不意外。需要注意的是，如果存在更高频率，为了能够检测它们，我们需要更快速地采样。这引发了以下定义。

## 定义 1.13

如果数据以 $\Delta$ 为增量采样，则尼奎斯特频率为 $1/(2\Delta)$，最短观测周期为 $2\Delta$。
