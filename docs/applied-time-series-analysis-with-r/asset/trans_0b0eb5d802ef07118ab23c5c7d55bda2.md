从 $t_0 = n - k$ 处进行预测，其中 $0 < k < n$。使用这种技术，你可以通过对实现中已观察到的 $k$ 个值进行预测来评估你的预测效果。这些预测可以使用拟合到整个数据集的模型进行，或者你可以将模型拟合到前 $n - k$ 个数据值上，并使用该模型进行预测。评估预测的这种技术在示例 6.8 中显示，涉及图 6.10 所示的航空预测，并在示例 6.9 中显示。你可以简单地比较你的预测与实际值有多接近（图 6.10 中非常接近），或者绘制预测限并计算落在预测限内的实际值的数量。如果预测表现适当，例如，约 95% 的实际值应落在 95% 预测限内。

注意：给定一个模型，对数据中最后 $k$ 个值进行预测有两种方法：（a）使用 $t_0 = n - k$ 并从此原点进行所有预测，或（b）在每一步更新预测并进行一步前瞻预测。在第二种情况下，$x_{n-k+2}$ 使用 $t_0 = n - k$ 作为预测原点进行预测，等等。参见问题 6.12，了解获得这些类型 (b) 预测的简单更新公式，即一步前瞻预测。在我们的经验中，我们一直希望检查预测性能（a）预测，即评估模型从固定原点 $t_0 = n - k$ 开始对最后 $k$ 个值的表现如何。然而，我们的经验也表明，在获取时间序列最后 $k$ 个值的预测时，学生和从业者经常不知不觉地在计算固定原点预测之前先计算了一步前瞻预测。当这种情况发生时，反应通常是，“哇，这些预测太棒了”，直到意识到这些预测实际上是一组一步前瞻预测，而这些预测应该非常准确。小心！

**使用 R：** `tswge` 中 `fore.arima.wge` 的参数 `last` 可用于指定预测是面向未来（`last=FALSE`）还是你希望从固定原点对现有数据集最后 $k$ 个值的观测值进行预测（`last=TRUE`）。为了避免上述类型的混淆，不要计算一步前瞻预测。有关 `fore.arima.wge` 用法的更多细节，请参阅附录 6B。

# 预测

模型也是预测的重要模型类。假设 $X_t$ 遵循 ARIMA$(p,d,q)$ 模型

$$\phi(B)\lambda(B)(X_t - \mu) = \theta(B)a_t, \quad (6.35)$$

其中 $\phi(z)$ 是一个 $p$ 次多项式，其所有根都位于单位圆之外。此外，$\lambda(z)$ 是一个 $d$ 次多项式 $(d > 0)$，其所有根 $\lambda(z)=0$ 都位于单位圆上。令 $\phi^{(u)}(B)=\phi(B)\lambda(B)$，使得 $\phi^{(u)}(B)$ 是一个 $(p+d)$ 阶算子，其系数为 $\phi_0^{(u)}, \dots, \phi_{p+d}^{(u)}$。将方程 6.35 视为平稳模型的极限

$$\phi(B)\lambda_m(B)(X_t^m) = \theta(B)a_t,$$

其中 $\lambda_m(z)$ 的根在单位圆外为零，但 $\lambda(z)=0$ 的根（当 $m \to \infty$ 时位于单位圆上）。由方程 6.21，我们得到 '极限' 预测

$$\hat{X}_t(\ell) = \sum_{j=1}^{p+d} \phi_j^{(u)}\hat{X}_{t-j}(\ell-j) - \sum_{j=1}^{q} \theta_j\hat{a}_{t+\ell-j} \left(1 - \sum_{j=1}^{p+d} \phi_j^{(u)}\right) \mu.$$

与平稳情形一样，在实践中，我们使用此公式

$$\hat{X}_t(\ell) = \sum_{j=1}^{p+d} \phi_j^{(u)}\hat{X}_{t-j}(\ell-j) - \sum_{j=1}^{q} \theta_j\hat{a}_{t+\ell-j} \left(1 - \sum_{j=1}^{p+d} \phi_j^{(u)}\right) \hat{X}, \quad (6.36)$$

其中 $\hat{a}_t$ 给出

$$\hat{a}_t = 0, t \le p+d$$
$$= X_t - \sum_{j=1}^{p+d} \phi_j^{(u)}X_{t-j} + \sum_{j=1}^{q} \theta_j\hat{a}_{t-j} \left(1 - \sum_{j=1}^{p+d} \phi_j^{(u)}\right) \hat{X}, \quad (6.37)$$

$t = p+d+1, \dots, t_0$。它还遵循 $\gamma_\ell = \hat{X}_t(\ell) - X_t$ 满足 $(p+d)$ 阶差分方程 $\phi^{(u)}(B)\gamma_\ell=0$。然而，由于 $X_t$ 在方程 6.35 中遵循非平稳模型，一般线性过程形式

$$\hat{X}_t(1) = \hat{X}_t(0) = X_t,$$

# 示例 6.4：来自 ARIMA(1,1,0) 模型的预测

考虑 ARIMA(1,1,0) 模型

$$(1 - 0.8B)(1 - B)X_t = a_t. \quad (6.42)$$

从此模型中得到的长度 $n = 50$ 的实现如图 6.6 所示（可在 `tswge` 数据集 `fig6nf` 中获得）。将方程 6.42 中的因子相乘，我们得到

$$(1 - 1.8B + 0.8B^2)X_t = a_t,$$

使得 $\phi_1^{(u)}$ 和 $\phi_2^{(u)} = -0.8$。由方程 6.36，此模型的预测为

$$\hat{X}_t(\ell) = 1.8\hat{X}_t(\ell-1) - 0.8\hat{X}_t(\ell-2) + (1 - 1.8 + 0.8)\bar{X}$$
$$= 1.8\hat{X}_t(\ell-1) - 0.8\hat{X}_t(\ell-2).$$

再次由于 $(1 - B)$ 因子，$\bar{X}$ 在预测中不起作用。由此可得

$$\hat{X}_t(1) = 1.8\hat{X}_t - 0.8\hat{X}_{t-1},$$
$$\hat{X}_t(2) = 1.8\hat{X}_t(1) - 0.8\hat{X}_{t-1},$$

一般地，对于 $\ell > 0$，

$$\hat{X}_t(\ell) = 1.8\hat{X}_t(\ell-1) - 0.8\hat{X}_t(\ell-2). \quad (6.43)$$

这些预测和 $\ell = 1, ..., 20$ 的 95% 预测限如图 6.6 所示，连同原始实现。
