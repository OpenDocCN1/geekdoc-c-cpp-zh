# 12.2.2 Wigner–Ville Spectrum

Recall that the spectrum for a stationary discrete time series defined on $t = 0$,\n\pm 1, \pm 2, \dots$ is defined in Equation 1.25 to be

```
$$P(f) = \sum_{k=-\infty}^{\infty} \gamma(k)e^{-2\pi i fk}, \quad (12.7)$
```

$-0.5 < f < 0.5$. However, for time series whose autocorrelation associated with\n time, Condition 3 in (12.1) does not hold. Letting $\gamma(t_1, t_2)$ denote the\nautocovariance between $X_{t_1}$ and $X_{t_2}$, the discrete Wigner–Ville spectrum can\nbe defined by

```
$$W(t, f) = \sum_{k=-\infty}^{\infty} \gamma(t+k/2, t-k/2)e^{-2\pi i fk}, \quad (12.8)$
```

If $X$, is approximately stationary in a neighborhood of $t$, then $\gamma(t+k/2)$,\n$t-k/2$ can be approximated by use of a (time domain) window centered\nat t, see Martin and Flandrin (1985) and Boashash (2003). Figure 12.3c and d\nshows the Wigner–Ville time–frequency representation associated with the\ondata in Figure 12.2a and $b$, respectively. It is seen that the information con-\ncerning time–frequency relationships are consistent with those using\nt Gabor spectrum shown in Figure 12.3a and $b$. Similarly, the Wigner–Ville\nplot in Figure 12.4b for the chirp shows the same linearly increasing\ntime–frequency relationship shown in Figure 12.4a.

# 12.3 Wavelet Analysis

In this section we give an overview of wavelet analysis and its application\nto statistical time series analysis of nonstationary data. Wavelets provide\nan alternative to the window methods for investigating frequency behavior\nthat changes across time. Wavelet analysis is a relatively recent methodology\ndeveloped primarily in the mathematical sciences and engineering, and it\nproved to be a powerful tool for the analysis of localized behavior of data\nwhose characteristics change with time. These methods can be viewed as\nvariations of classical Fourier analysis in short waves (or “wavelets")\nare used in place of the classical sines and cosines.
