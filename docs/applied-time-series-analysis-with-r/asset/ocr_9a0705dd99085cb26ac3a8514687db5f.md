```

```

```
$\hat{X}_{50}(\ell) = \hat{X} + \ell C_2\n=-573.9 - 1.2\ell,$
```

which is the straight line through the points $\hat{X}_{50}(0) = X_{50}$ and $\hat{X}_{50}(-1) = X_{49}$. In general, it can be seen (Problem 6.10) that forecasts $\hat{X}_{i}(\ell)$ from Equation 6.46 all lie on a straight line that passes through $X_i$ and $X_{i-1}$. That is, the forecasts predict whether an upward or downward trend will continue. Had we obtained forecasts using forecast origin $\ell_0=49$, the forecasts would have predicted an increasing trend.
