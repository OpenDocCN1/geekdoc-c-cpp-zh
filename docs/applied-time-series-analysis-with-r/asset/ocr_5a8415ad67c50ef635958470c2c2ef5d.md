# 11.4.2 Generating Realizations

Gray et al. (1989, 1994) generate realizations of Gegenbauer and GARMA models using the strategy of truncating the general linear process given in Equation 11.1 to obtain

```
$X_t = \mu + \sum_{h=0}^{M} C_h^{(k)}(u)a_{t-h} \quad (11.26)$
```

with $M=290,000$. Woodward et al. (1998) suggest a more efficient algorithm due to Ramsey (1974) based on conditional expectations and variances of $X$, given $X_0, X_t, X_{t-j}$. However, the more efficient method involves the true autocavariances, and our experience is due to the computational difficulties described earlier, of the conditional quantities became corrupted. Consequently, the realizations shown here will be based on the truncated linear process.

In order to generate realizations from a $k$-factor GARMA, we let $Z_t$ be the corresponding $k$-factor Gegenbauer process, which we express as

```
$Z_t = \prod_{j=1}^{k} (1-2u_jB+B^2)^{-\lambda_j}a_t,$
```

and we write Equation 11.20 as

```
$\phi(B)X_t = \mu(1-\phi_1-\cdots-\phi_p)+\theta(B)Z_t.$
```

A realization from the $k$-factor Gegenbauer process, $Z_t$, is generated using the truncation method described earlier, and the $k$-factor GARMA process is then simulated using the recursion

```
$X_t = \mu(1-\phi_1-\cdots-\phi_p)+\sum_{j=1}^{p}\phi_j X_{t-j}+Z_t-\sum_{j=1}^{q}\theta_j Z_{t-j}.$
```

See Haskell (1984), Gray et al. (1989, 1994), and Woodward et al. (1998).

**Using R:** The tswge root gen.garma.wge generates realizations from a given 1-factor GARMA model. We recommend the function fracdiffsim in CRAN package for simulating realizations from fractional or FARMA models. For more information see Appendix 11A.
