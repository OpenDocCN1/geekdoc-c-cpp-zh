# EXAMPLE 13.13: A LINEAR CHIRP SIGNAL WITH TWO FREQUCIES

Figure 13.15a shows a realization from Equation 13.22 with $m=2$. Specifically, it is a realization of the model

> $X(t)=A_1cos[2\pi\beta_1(at^2+bt)+\psi_1]+A_2cos[2\pi\beta_2(at^2+bt)+\psi_2]+N(t), (13.23)$

where $A_1=1, \beta_1=1, \psi_1=0, A_2=2, \beta_2=2, \psi_2=1.5, a=1, b=1$, and $\sigma_N^2=0.04$. In Figure 13.15a, it can be seen that there is more than one frequency component that increasing with time, and Figure 13.15b shows the dual realization in which the TVF behavior has been removed.
