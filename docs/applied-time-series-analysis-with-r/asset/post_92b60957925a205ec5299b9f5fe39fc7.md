## 4.1.1 Pure Harmonic Models

We begin by considering purely harmonic discrete parameter models

```
$$Y_t = \sum_{j=1}^{m} A_j \cos(2\pi f_jt + U_j)$$ (4.5)
```

in which there is no additive noise component, the $A_j$ and $f_j$ are constants, and the $U_j$ are independent random variables distributed as uniform $[0, 2\pi]$. We first consider the case $m=1$ that was considered in the continuous parameter case in Examples 1.3 and 1.7. In Example 1.3, it was shown that $Y_t$ is stationary with $E[Y_t]=0$, variance $\sigma_Y^2 = A_1^2/2$, and auto-variance function

```
$$\gamma_k = \frac{A_1^2}{2} \cos 2\pi f_1k$$ (4.6)
```

from which it immediately follows that

$$\rho_k = \cos 2\pi f_k. \quad (4.7)$$

Unlike the autocorrelation function for an ARMA$(p,q)$ process, $\rho_k$ in Equation 4.7 does not damp, and in fact, $|\rho_k| = 1$ if $f_k$ is an integer. In the discrete parameter case, the spectrum defined in Equation 1.25 is given by

$$P_Y(f) = \sum_{k=-\infty}^{\infty} e^{-2\pi f_k} A_k^2 \cos 2\pi f_k k, \quad (4.8)$$

which does not converge. In order to calculate the spectrum in this case, it is necessary to use the spectral distribution function (see Brockwell and Davis, 1991). We will not cover this topic here, except to note that using this approach, the spectrum can be shown to be

$$P_Y(f) = \frac{A_i^2}{2} \Delta(f - f_i) + \Delta(f + f_i)}{2}$$

and hence

$$S_Y(f) = \frac{\Delta(f - f_i) + \Delta(f + f_i)}{2} \quad (4.9)$$

where $\Delta(x)$ is the Kronecker delta function given by

$$\Delta(x) = 1, \quad x = 0 \n= 0, \quad x \neq 0.$$

As usual, we only plot the spectral plots for $f \in [0, 0.5]$, and Figure 4.2 shows the spectral density (not plotted in dB) for the process in Equation 4.5 with $m=1$. It will be clear that realizations of perfectly sinusoidal, which is consistent with $\gamma$ and $P_Y(f)$, and although the series has random phase (due to U), there is no phase shifting in the sense of an AR process or otherwise within a reality.

The autocorrelations and spectral density for the full model in Equation 4.5 are given by

$$\rho_k = \frac{\sum_{j=1}^{m} A_j^2 \cos 2\pi f k}{\sum_{j=1}^{m} A_j^2}$$

## 4.1.2 Harmonic Signal-Plus-Noise Models

We consider the signal-plus-noise model

$Y_t = \sum_{j=1}^m A_j \cos(2\pi f_j t + U_j) + N_t \n= H_t + N_t,$

for $t=0, \pm1, ...$, where $H_t$ is referred to as the harmonic component or signal and $N_t$ is a stationary noise process. In Equation 4.5, the $A_j$ and $f_j$ are constants, and the $U_j$ are uncorrelated random variables which are distributed as uniform $[0, 2\pi]$. Additionally, $H_t$ and $N_t$ are uncorrelated processes. It follows that once $Y_t$ in Equation 4.10 is a stationary process, it is the sum of uncorrelated stationary processes (see Problem 1.10).
