# ##7.1 Introduction

Suppose a realization $x_1, x_2, ..., x_n$ is observed. The problem of fitting an ARMA$(p,q)$ model to the data is the problem of estimating

```
$p,q \n\phi_1, \phi_2, ..., \phi_p \n\theta_1, \theta_2, ..., \theta_q \n\mu, \sigma_2^2. (7.1)
```

The estimation of $p$ and $q$ is called order identification, and this topic will be covered in detail in Chapter 8. In the current chapter, we assume that $p$ and $q$ are known, and techniques will be discussed for estimating the additional parameters in (7.1). An analysis of a time series using an ARMA model typically first order identification followed by the estimation procedures to be discussed in this chapter. However, the dichotomy between the order identification and parameter estimation steps is not clear-cut since the means of selecting the appropriate model orders. Now, we discuss parameter estimation assuming known $p$ and $q$.

Much work has been done recently by statisticians on the problem of obtaining maximum likelihood (ML) estimates of the parameters due to their well-known optimality properties. The estimation of ARIMA parameters involves iterative procedures that require starting values. In this chapter, we first deal with the issue of finding computationally preliminary estimates of the parameters that can be used as starting values for the ML routines. It should be noted that these computationally efficient estimates have received considerable attention in the engineering and geophysical literature partially due to their need to estimate parameters in real time, to obtain estimates for a large collection of time series, or for time series of several thousand points.
