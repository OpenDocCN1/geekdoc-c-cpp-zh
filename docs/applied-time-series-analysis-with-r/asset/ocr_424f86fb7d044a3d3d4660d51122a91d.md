where the $\alpha_j$ may be real or complex numbers with $|\alpha_j| < 1, j=1, 2$. Then, from Equations 3.26 and 3.27

```
$X_t = \sum_{k=0}^{\infty} \psi_k(2)a_{t-k},$$
```

where

```
$$\psi_k(2) = \frac{\alpha_2^{k+1}-\alpha_1^{k+1}}{\alpha_2-\\alpha_1},$
```

Now suppose that $r_1$ and $r_2$ are complex conjugate roots of the characteristic equation associated with the AR(2) model in Equation 3.66. Then, $\alpha_1 = r_1^{-1} = (a+bi)^{-1}$ and $\alpha_2 = r_2^{-1} = (a-bi)^{-1}$, so it follows that

```
$$\alpha_1 = \frac{a-bi}{a^2+b^2},$\n$\alpha_2 = \frac{a+bi}{a^2+b^2},$$
```

where $b \neq 0$. Letting $R = \sqrt{a^2+b^2}$, then $\alpha_1 = R^{-1}e^{-i\theta}$ and $\alpha_2 = R^{-1}e^{i\theta}$, where $	heta = \arc\tan(b/a)$. Then,

```
$$\alpha_2-\alpha_1 = 2R^{-1} \left[ \frac{e^{i\theta}-e^{-i\theta}}{2} \right],$\n=2iR^{-1} \sin\theta,$$$$
```

and

```
$$\psi_k(2) = R^{-k-1} \left[ \frac{e^{i\theta(k+1)}-e^{-i\theta(k+1)}}{2iR^{-1} \sin\theta} \right],$\n=R^{-k} \frac{\sin\theta(k+1)}{\sin\theta}.$$
```

Therefore,

```
$X_t = \sum_{k=0}^{\infty} R^{-k} \frac{\sin\theta(k+1)}{\sin\theta}a_{t-k}. \quad (3.67)$
```
