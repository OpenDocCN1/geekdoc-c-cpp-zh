A useful way to view the pyramid algorithm is that the coefficients $s_{m,k}$ and $d_{m,k}$ $k=1, \dots, n/2^m$ obtained at the $m$th step of the pyramid algorithm are the outputs from a low-pass and high-pass filter, respectively, applied to $s_{m-1}, k=1, \dots, n/2^{m-1}$. ## 12.3.6 Multiresolution Analysis

The pyramid algorithm not only is an efficient algorithm for performing the matrix multiplication in Equation 12.22, but it also provides insight into a useful wavelet decomposition of the data, referred to as multiresolution analysis (MRA). Using the partitioning in Equation 12.23 as we can write Equation 12.24 as

```
$\mathbf{x} = \left( \mathbf{M}_1' & \mathbf{M}_2' & \dots & \mathbf{M}_{j_0}' & \mathbf{V}_{j_0}' \right) \begin{pmatrix} \mathbf{w}_1 \ \mathbf{w}_2 \ \vdots \ \mathbf{w}_{j_0} \ \mathbf{v}_{j_0} \end{pmatrix}$
$\mathbf{x} = \mathbf{M}_1'\mathbf{w}_1 + \mathbf{M}_2'\mathbf{w}_2 + \dots + \mathbf{M}_{j_0}'\mathbf{w}_{j_0} + \mathbf{V}_{j_0}'\mathbf{v}_{j_0}. \quad (12.29)$
```

So, for example, if $n=2^3$, the first element, $x_{1,r}$ of $\mathbf{x}$ is given by

```
$x_{1,1} = \sum_{k=1}^4 d_{1,k}\psi_{1,k}(1) + \sum_{k=1}^2 d_{2,k}\psi_{2,k}(1) + d_{3,1}\psi_{3,1}(1) + s_{3,1}\phi_{3,1}(1), \quad (12.30)$
```

Note that Equation 12.31 is the DWT version of Equation 12.21. Each of the discrete wavelet, $\psi_{j,k}$ in Equation 12.21 is associated with a “short wave” behavior. In the discussion following Equation 12.14 we noted that the Haar wavelet, $\psi_{j,k}$ is associated with behavior in the neighborhood of $t=2(k+0.5)$ with a duration of 2. Thus, larger values of $|d_{j,k}|$ are associated with time periods in which the data display some sort of “cyclic-type” behavior, with a duration of about 2. The $d_{j,k}$ are referred to as *detail coefficients*. Small values of $j$ are associated with more localized behavior, while the larger values of $j$ are associated with coarser detail behavior (i.e., longer-span behavior).

The partitioning in Equation 12.21 is referred to as a *multiresolution decomposition* (MRD). In the case $j_0=4$ (i.e., $n=16$) considered in Example 12.3 which follows, this decomposition becomes

