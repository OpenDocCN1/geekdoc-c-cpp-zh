$(\)$ Let $Z_{t_0}^*$ be such that $E[(X_{t_0+\ell}-Z_{t_0}^*)X_j]=0, \ j=1,\dots,t_0,$ and let $Z_t$ be an arbitrary linear combination of $X_t, \ t=1,2,\dots,t_0.$ Then it follows that

```
$E[(X_{t_0+\ell}-Z_{t_0}^*)^2]=E[(X_{t_0+\ell}-Z_{t_0}^*+Z_{t_0}-Z_{t_0}^*)^2] \\n\=E[(X_{t_0+\ell}-Z_{t_0}^*)^2]+E[(Z_{t_0}-Z_{t_0}^*)^2] \\n\=+2E[(X_{t_0+\ell}-Z_{t_0}^*)(Z_{t_0}-Z_{t_0}^*)] \\n\ge E[(X_{t_0+\ell}-Z_{t_0}^*)^2], \,{}$
```
