# EXAMPLE 5.9: THE AIRLINE MODEL

The monthly data for the number of international airline passengers (log scale) have been well analyzed as a seasonal data set with a trending behavior. A variety of models have been proposed for this data set, and as a group, these are referred to as “airline models.” We will use here for this purpose an AR($($p, d, q$)($p_{ij}, Q_{ij}$) model of the form an

```
$$\phi(B)\Phi(B^2)(1-B)(1-B^2)(X_t - \mu) = \theta(B)\Theta(B)a_t.$
```

Note that this model has 13 roots on the unit circle: a seasonal factor $1 - B$ and 12 months with the characteristic factor equation $(1-z)(1-z^{12}) = 0$ would be the same as the one in Table 5.5, except that it would include two factors of $1 - B$. Thus, in Theorem 5.1 we will find that $d=13, j=1, \ell=2$. Notice that the autocorrelations, $\rho_t$, of such a process are given

```
$$\rho_t^2 = 1.$
```

since the root of 1 is repeated twice. These will be discussed in detail in Section 8.3.5.3 as we analyze seasonal data.

**Using R:** The `tswege` function `gen.arma` can be used to generate real realizations from multiple seasonal models. In the model you would generate data from the ARMA($($p,d,q$)) $\phi(B)\lambda_t(B)(X_t - \mu) = \theta(B)a_t$ where $\phi(B) = \phi(B)\Phi(B^{12}), \lambda_t(B) = (1-B)(1-B^{12})$, and $\theta_t(B) = \theta(B)$
