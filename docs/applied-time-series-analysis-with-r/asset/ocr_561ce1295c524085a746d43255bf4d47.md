+   acf(x, lag.max, type, plot) (base R function): calculates (and optionally plots) the sample autocovrelations (or sample covariances and sample variance) of the time series realization where x is a vector containing the time series realization, t = 1, ..., n. lag.max is the maximum lag at which to calculate the sample autocorrelations (or covariances) type="correlation" (default) produces the sample autocorrelations, "covariance" specifies the autocovances, and "partial" indicates the partial autocorrelations (discussed in Chapter 8).

plot is a logical variable. plot = "TRUE" produces a plot of the sample autocorrelations (or autocovariances) Example: data(hadley); tempaut = acf(x = hadley, lag.max = 25)

calculates and plots the first 25 sample autocorrelations for the global temperature data in hadley that are shown in Figure 1.2a. The sample autocorrelations are placed in the vector$acf[1] (which has 26 elements counting tempaut$acf[1] = 1, i.e the sample autocorrelation at lag 0). If type = "covariance" is selected, then the vector$acf contains the sample autocariances, and tempaut$acf[1] contains the sample variance (using the divisor).
