# 3.2.2 AR(1) Model

We first consider the properties of the AR(1) model given by

```
$X_t - \phi_1 X_{t-1} = a_t, \quad (3.28)$
```

where $|\phi_t| < 1$.

+   $\psi$-weights and stationarity conditions for an AR(1): From Equation 3.27, we see that the general linear process of an AR(1) process is

```
$X_t = \sum_{k=0} \phi_t^k a_{t-k}$.
```

That is, $\psi$-weights are $\psi_t(1) = \phi_t^k$. The characteristic equation is given by $1 - \phi_t r=0$, which has root $\eta_t = \phi_t^{-1}$ where $|\eta_t|=|\phi_t^{-1}|>1$ since $|\phi_t| < 1$, from which it follows that the model in Equation 3.28 is stationary and causal. We also noted that the $\psi$-weights of an AR(1) model in the preceding discussion about inverting the operator.

+   Autocorrelations of an AR(1) process: In order to find $\gamma_0$ and $ho_k$ for an AR(1) process, it is necessary to evaluate the expectation $E[X_tX_{t-k}] = E[X_{t-k}X_t]$. To obtain $\gamma_k$, multiply both sides of the equality in Equation 3.28 by $X_{t-k}$ $k>0$, to yield

```
$X_{t-k}[X_t = \phi_1 X_{t-1} + a_t].
```

Taking the expectation of both sides we obtain

```
$E[X_{t}X_{t-k}] = \phi_1 E[X_{t-k}X_{t-1}] + E[X_{t-k}a_t]. \quad (3.29)$
```

Now, $X_{t-k} = \sum_{j=0}^k \phi_{t-k}^j a_{t-k-j}$ and thus $X_{t-k}$ depends only on $a_{t-k-j}$ $0, 1, \dots$. It follows that $X_{t-k}$ is uncorrelated with $a_{t_r}$ that is, $E[X_{t-k}a_{t_r}]=0$ for $k>0$. Thus, from Equation 3.29, $\gamma_k = \phi_1\gamma_{k-1}$ for $k>0$, and
