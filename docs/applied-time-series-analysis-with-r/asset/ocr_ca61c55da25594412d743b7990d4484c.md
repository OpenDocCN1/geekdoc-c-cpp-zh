# Theorem 3.1

Let X, be causal and cause suppose

```
$\phi(B)X_t = (1-\alpha_1 B)(1-\alpha_2 B)\cdots(1-\alpha_p B)X_t = a_t,$(3.25)
```

where the $\alpha_k$ are real or complex numbers, $\alpha_k \neq \alpha_j, k \neq j$, $|\alpha_k| < 1, k=1, \dots, p$, and $a_t$ is zero mean white noise. Then, X, is an AR(p) process and

```
$X_t = \sum_{\ell=0}^p \psi_{\\ell}(p)a_{t-\ell},(3.26)
```

where

+   a. $\psi_1(p) = \alpha_1^{p-1}$ for $p=1$\nb. $\psi_k(p) = \frac{\alpha_k^{-p-k}(\alpha_k^{p+1}-\alpha_j^{p+1})}{\alpha_k-\\alpha_j} \prod_{h \neq k}^{p-k} (\alpha_{p-k}-\alpha_h)$, for $p \geq 2$.$(3.27)

Proof: See Appendix 3A.

We note that Theorem 3.1 gives the $\psi$-weights for the case of no repeated roots. Problem 3.33 shows how Equation 3.27 can be used in the case of a repeated root. The constants $\psi(p)$ will be referred to as the “$\psi$-weights” for an AR(p) process. Definition 3.3 introduces the characteristic equation, which is a useful tool in the analysis of AR(p) models.
