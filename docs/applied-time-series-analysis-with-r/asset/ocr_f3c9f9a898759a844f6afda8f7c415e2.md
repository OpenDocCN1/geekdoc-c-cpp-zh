# 10.6.6 Parameter Estimation

$\Theta$ denote the vector of parameters to be estimated in Equations 10.48 and 10.49. It will be convenient for us to write the likelihood function $L(\Theta\; Y_1, \dots, Y_t)$ (conditional on $Y_0$) $L(\Theta\; Y_1, \dots, Y_t) = \prod_{j=1}^t f_j(Y_j|Y_{j^{-1}})$, where $f_j(Y_j|Y_{j^{-1}})$ is the conditional density of $Y_j$ given that $Y_j=y_j$, $j=1,\dots,t-1$ (and conditional that $Y_0=y_0$). Calculation of the likelihood is complicated but can be made more tractable if the $V_t$ and $W_t$ are jointly normally distributed and uncorrelated and if the initial state $Y \sim MVN(\mu_0, \Gamma_0)$. The innovations, $I_t$, are calculated where

```
$I_t = Y_t - G\hat{X}_{t^{-1}}^{-1},$
```

and

```
$$\Gamma_t = \text{Var}[I_t] = \text{Var}[G(X_t - \hat{X}_{t^{-1}}^{-1}) + W_t]$\n= G_t\Gamma_{t^{-1}}^{-1}G_t^top + \Gamma_W.$
```

(see also proof of Kalman filtering and prediction in Appendix 10A). Based on the aforementioned assumptions, the likelihood can be written as

```
$L(\Theta\; Y_1, \dots, Y_n) = \frac{1}{(2\pi)^{nw/2}} \left[ \prod_{t=1}^n |\Gamma_t| \right]^{-1/2} \exp \left[ -\frac{1}{2} \sum_{t=1}^n I_t^top \Gamma_t^{-1} I_t \right].$
```
