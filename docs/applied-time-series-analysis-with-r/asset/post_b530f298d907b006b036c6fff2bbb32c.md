### Theorem 8A.1

Let $X_t$ be an ARMA process with AR order greater than zero.
Then

- 1. $X_t$ is ARMA$(p,q)$ if and only if $\phi_{kk}^{(q)}=0, k > p$ and $\phi_{pp}^{(q)} \neq 0$.
- 2. If $X_t$ is ARMA$(p,q)$ then $\phi_{pp}^{(h)}=\phi_p, h \geq 0$.

Proof: See Woodward and Gray (1981).
