Secondly, it is important to note that the eventual form of the forecast function depends on starting values. Specifically, when $\ell > q$, $\hat{X}_t(\ell) - \bar{X}$ satisfies the difference equation in Equation 6.28, the solution of which depends on $p$ starting values $\hat{X}_q(q-p+1), ..., \hat{X}_q(q)$ where $\hat{X}_k = X_{t+k}$ for $k \le 0$. The characteristic equation $1 - 1.2z + 0.6z^2 = 0$ associated with the ARMA (2,1) model of Example 6.2 has complex roots. The forecasts shown in Figure 6.2 have the damped sinusoidal behavior of autocorrelations from such a model. The values $\hat{X}_{25}(0) = X_{25} = 52.05$ and $\hat{X}_{25}(1) = 51.40$ serve as starting values for the forecasts, which can be observed to damp toward $\bar{X} = 50.04$ as $\ell$ increases.
