# 12.3.10 Two-Dimensional Wavelets

Although this is a book on time series analysis, we cover this section on wavelet analysis with a brief discussion of two-dimensional wavelets. This section briefly covers wavelet analysis of an $m 	imes n$ image, $F_{m,n}$ where, in the univariate case, we assume that both dimensions are dyadic (i.e., powers of 2). Examples will be based on a square image, that is, of size $2^l 	imes 2^l$ for some integer $J_n$. The two-dimensional DWT maps the $m 	imes n$ image $F_{m,n}$ of wavelet coefficients. The univariate DWT is based on two types of wavelets: father wavelets measure smooth behavior and mother wavelets measure more detailed behavior. In the case of the two-dimensional DWT, there are four types of wavelets

$\Phi(x, y) = \varphi_0(x) \times \varphi_0(y)$ (captures smooth features of the image)
$\Psi^x(x, y) = \psi_0(x) \times \varphi_0(y)$ (captures vertical features of the image)
$\Psi^y(x, y) = \varphi_0(x) \times \psi_0(y)$ (captures horizontal features of the image)
$\Psi^{xy}(x, y) = \psi_0(x) \times \psi_0(y)$ (captures diagonal features of the image)
