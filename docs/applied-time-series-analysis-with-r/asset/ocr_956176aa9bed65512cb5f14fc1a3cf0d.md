# **Definition 10**

Let $[X_t; t=0, \pm1, \pm2, \dots]$ be a causal stationary multivariate process with covariance matrix $\Gamma(k)$ given in Equation 10.1 and where $\sum_{k=-\infty}^{\infty} |\gamma_{jh}(k)| < \infty$ for $1 \leq j, h \leq m$. For $0 \leq f \leq 0.5$, the power spectrum of $X_j$ is given by

```
$$\mathbf{P}_x(f) = \sum_{k=-\infty}^{\infty} e^{-2\pi if} \Gamma(k)$.$
```

Note that in the multivariate case, $\mathbf{P}_x(f)$ in Equation 10.7 is often called the spectral density. For consistency of notation with the univariate case, we will refer to it as the spectrum. Note also that $\mathbf{P}_x(f)$ is an $m \times m$ matrix for each $f$. Analogous to Equation 10.28 for the univariate case, it can be shown that

```
$$\Gamma(f) = \int_{-0.5}^{0.5} e^{2\pi if} \mathbf{P}_x(f) df$.$
```

where $i = \sqrt{-1}$. The $jh$th element of $\mathbf{P}_x(f)$ is given by

```
$$\mathbf{P}_{jh}(f) = \sum_{k=-\infty}^{\infty} e^{-2\pi if} \gamma_{jh}(k)$,$
```

where $|f| \leq 0.5$, and the $\gamma_{jk}(k)$s are defined following Equation 10.1. Note that $P_{jj}^0(f)$ is the usual spectrum of the univariate series $X_j$ while if $j \neq h$ $P_{jh}^0(f)$ is called the cross spectrum of $X_j$ and $X_{lh}$ which can be complex valued with the property that $P_{jh}(f)$ is the complex conjugate of $P_{hj}(f)$. Denoting $P_{jh}(f) = c_{jh}(f) - iq_{jh}(f)$, then $q_{jh}(f)$ is called the quadrature spectrum. Expressing $P_{jh}(f)$ in polar form, we have $P_{jh}(f) = \alpha_{jh}(f)e^{i\varphi_{jh}(f)}$, where $\alpha_{jh}(f) = \sqrt{c_{jh}^2(f) + q_{jh}^2(f)}$ is referred to as the amplitude spectrum and $\varphi_{jh}(f) = \tan^{-1}(-q_{jh}(f)/c_{jh}(f))$ is the phase spectrum.
