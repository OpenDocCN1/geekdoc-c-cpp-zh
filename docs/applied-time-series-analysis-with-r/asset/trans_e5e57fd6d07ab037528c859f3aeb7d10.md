## 定义 10.7

设 $X_t$ 为满足以下方程的平稳多元过程：

```
$$\mathbf{X}_t - \Phi_1 \mathbf{X}_{t-1} - \dots - \Phi_p \mathbf{X}_{t-p} = \alpha + \mathbf{a}_t - \Theta_1 \mathbf{a}_{t-1} - \dots - \Theta_q \mathbf{a}_{t-q} $$
```

其中 $\Phi_s$ 和 $\Theta_s$ 是实值 $m \times m$ 矩阵，$\mathbf{a}_t$ 是多元白噪声。那么，$X_t$ 是一个 VARMA$(p,q)$ 过程。

## 10.3.1 使用 VAR(p) 模型进行预测

给定 VAR(p) 模型，Box-Jenkins 风格的预测 $\hat{X}_t$，“假设”无限过去 $X_t$（$t=t_0-1, t_0-2, \dots$）对于 $\hat{X}_{t+h}$ 可以类似于单变量情况下第 6.2 节的方法获得。具体来说，这些预测可以用差分方程表示：

```
$$\hat{X}_t(\ell) = \sum_{j=1}^p \Phi_j \hat{X}_t(\ell-j) + (\mathbf{I} - \Phi_1 - \dots - \Phi_p)\mu,$$ (10.24)
```

对应方程 6.21。在第 6 章中，我们基于模型已假设计算预测。由于 $\mu$ 必须从数据中估计，我们使用从 VAR(p) 模型计算的基本公式：

```
$$\hat{X}_t(\ell) = \sum_{j=1}^p \Phi_j \hat{X}_t(\ell-j) + (\mathbf{I} - \Phi_1 - \dots - \Phi_p)\mu,$$ (10.25)
```

对应单变量情况下的方程 6.24。在实践中，模型是从数据中估计的，方程 10.25 中的 $\Phi_s$ 被它们的估计值 $\hat{\Phi}_s$ 替换。VAR(p) 模型的参数估计将讨论。

```
$$e_t(\ell) = X_{t+\ell} - \hat{X}_t(\ell)$$
$$= \sum_{j=0}^{\ell-1} \Psi_j X_{t+\ell-j}$$ (10.30)
```

由此得出e_t(\ell)$ 的期望值为 0，协方差矩阵 $\Gamma_x(\ell)$ 给出：

```
$$\Gamma_x(\ell) = E[e_t(\ell)e_t(\ell')]$$
$$= \sum_{j=0}^{\ell-1} \Psi_j \Psi_{j'}$$ (10.31)
```

在正态误差的情况下，可以使用方程 10.31 的对角元素获得类似于方程 6.33 的预测极限。

## 10.3.2 VAR($p$) 模型的谱

在 VAR($p$) 情况下，方程 10.7 定义的多元谱 $P_x(f)$ 是对于每个 $-0.5 \leq f \leq 0.5$ 的 $m \times m$ 矩阵：

```
$P_x(f) = \Phi^{-1}(e^{-2\pi i f}) \Gamma_x \Phi^{-1}(e^{-2\pi i f})$ (10.32)
```

其中对于实数或复数 $z$，多项式 $\Phi(z) = \mathbf{I} - \Phi z - \dots - \Phi z'$ 是方程 10.16 定义的算子 $\Phi(B)$ 的代数等价物。
