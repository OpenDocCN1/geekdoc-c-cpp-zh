# G-Stationary Processes

$D_t$ and $D_u$ are derivatives with respect to $t$ and $u$, respectively, as $Y(t) = Y(at^2 + bt) = X(t)$. It follows that the dual process of $X(t)$ in Equation 13.24 is an ARPr. For a further discussion of this, see Liu, Robertson (2008), and Robertson et al. (2010).

As mentioned earlier, the time-transformation technique for G-stationary processes is essentially based on the concept of sampling at the appropriate points. If $X$ is a GLC(p) process, we define $Y_k = Y(u_k) = X(t_k)$, where the sample points, $t_k \in (t_{(0)}, t_{(\infty)})$ are given by

```
$t_k = \frac{-b - \sqrt{b^2 + 4au}}{2a}, \quad t_k \in \left(t_{(0)}, \frac{-b}{2a}\right)\nt_k = \frac{-b + \sqrt{b^2 + 4au}}{2a}, \quad t_k \in \left(-\frac{b}{2a}, t_{(\infty)}\right), \quad (13.26)$
```

where $u_k = |k|\Delta_u$ and the $\Delta_u$ are equally spaced increments in $U$ space. The point $-b/(2a)$ is referred to as the reference process. If $\Delta_u$ is sufficiently small, it can be shown that $Y_k$ is a unique ARMA(p,q) process with $q \leq p-1$. See Jiang et al. (2006) and Robertson et al. (2010). Thus, by sampling properly, one can convert the TVF (nonstationary) data to stationary data, perform the required analyses, and transform back to the original index.

# EXAMPLE 13.14: SAMPLING AN SLC PROCESS

$X(t)=\cos(2\pi t^2 + \psi)$ where $\psi \sim \text{Uniform}(0, 2)$, and $t \in [-2, 2]$ and $\Delta_u = 0.05$. Then, as defined earlier, $t_{(0)}=-2, t_{(\infty)}=2, a=1$, and $b=0$, with constant $-b/(2a)=0$. Taking $u=X(t)=t^2$, then from Equation 13.26, if $t_k \in [t_{(0)}, t_{(\infty)})$ then $u_k \in [0, 4]$. For this example we let $t_k = \sqrt{u_k}$ where $u_k = |k|\Delta_u$.

Also, if $\Delta_u = 0.1$, then $(t_k, u_k) \in (-b/(2a), \{0, 2\}$, where we let $u \in [0, 4]$ and $t_k = \sqrt{u_k}$, $u_k = |k|\Delta_u = 1, 2, \dots, 39$, and $a=0.1$. This was selected to ensure that the data values in the dual realization is the same as the number of data values in the original realization.

Figure 13.16 is similar to Figure 13.1 for the case of a linear chirp. A realization of $X(t)$, where $\psi=0$, is shown in Figure 13.16a which shows the plot of 81 equally spaced points $t$ between $-2$ and $2$. The plot shows that the sampling rate per cycle is lower in the regions of the data where the frequency is high. Conversely, the sampling rate per cycle is higher where the frequency is low, which is somewhat undesirable.

Figure 13.16b displays the same realization in Figure 13.16a where $t_k = \sqrt{u_k}$. As evidenced by the tick marks in Figure 13.16b, this sampling strategy defines $t_k$ so that there are the same number of observations per cycle, and proceeds without interruption. Finally, Figure 13.16c shows a plot of the data indexed by $k$. This is the dual process, and it can be seen that the frequencies are fixed.
