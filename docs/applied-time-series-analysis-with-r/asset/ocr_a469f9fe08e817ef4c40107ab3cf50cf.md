# Applied Time Series Analysis with R

arlimits (default = FALSE) is a logical variable specifying whether 95% limit lines will be included on sample auto-correlation plots

Example:

```
data(airline)
airlog = log(airline)
airsam = plotts.sample.wge
(x = airlog,lag.max = 50)
```

plots the realization (x = airlog), sample autocorrelations (lags0 to lag.max), the periodogram in dB, and the Parzen spectral estimator (in using truncation point M=2√). The vectors ps$freq and ps$pgrm contain the frequencies and Parzen-spectral estimates in dB, respectively.

+   * plotters.wge = function(x,m2) is a tswge function that plots the periodogram and up to 3 Parzen window spectral estimates with different truncation points (all plotted in dB).
x is a vector containing the time series realization x, t = 1, ..., n.
m2 is a 2-component vector of addition, supplied, truncation points (default = c(0,0))

Example:
m2 = c(10,24) indicates in addition to the default truncation point, the Parzen spectral estimator is to be calculated using truncation points 10 and 24

m2 = c(0,0) indicates that no additional truncation points are used

m2 = c(10,0) indicates the use of one additional truncation point (10)

dbplot = TRUE(default) produces spectral plots in dB
Example: Suppose x contains a realization of n = 250 generated using gen.sigplnoise.wge and you want to calculate the Parzen spectral density at a variety of truncation points. You can use the following

```
x = gen.sigplnoise.wge (n = 250, coef = c(3,1), freq = c(.1,.52)
psi = c(0,1), phi = 0, var = 1
pz = plotters.wge(x, m2 = c(10,50))
```
