## 3.3.5 ARMA(p,q) 的 $\psi$-权重

我们已经证明 ARMA(p,q) 过程可以表示为线性滤波器，$X_t = \sum_{i=0}^{\infty} \psi_i a_{t-i}$。在本节中，我们讨论使用三种方法计算 $\psi$-权重：（a）系数等同，（b）除法，以及（c）使用定理 3.1 找到一般表达式。

- 1. 通过系数等同求 $\psi$-权重：由于平稳 ARMA(p,q) 过程可以写成 $X_t = \psi(B)a_t$ 的形式，其中 $\psi(B) = \phi^{-1}(B)\theta(B)$，我们有关系 $\phi(B)\psi(B) = \theta(B)$，或展开形式

$$$(1-\phi_1B-...-\phi_pBp)(1+\psi_1B+\psi_2B^2+...) = (1-\	heta_1B-...-\theta_qB^q). \quad (3.115)$$$$

在方程 3.115 中等同 $B^l$ 的系数描述了 $\theta$、$\phi$ 和 $\psi$ 之间的关系。特别是，等同 $\psi$ 的系数得到
