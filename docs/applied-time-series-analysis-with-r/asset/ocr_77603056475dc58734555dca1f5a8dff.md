# EXAMPLE 12.9: WAVELET PACKET TRANSFORM FOR AN AR(2) REALIZATION

As a final illustration using the case of wavelet packets we consider the realization of n=256 in Figure 12.19a which is from the AR(2) model

> $(1 + 0.995B^2)X_t = a_t$

Examination of the factor table (not given here) shows that this is a stationary model with system frequency f=0.25. The time-scale plot should essentially follow a horizontal line at 1/scale=0.5 (i.e., f=0.25). The time-scale plot based on the DWT is shown it is seen that the poor frequency localization for higher frequencies causes the time-scale plot to lose precision. Figure 12.19c shows the time-scale plot based on the best algorithm, and the horizontal behavior at 1/scale=0.5 is much more clearly. A schematic diagram of the wavelet packet transform obtained from the best algorithm is shown in Figure 12.17b. Note that the wavelet packet coefficients “hone” on 1/scale=0.5 (i.e., system frequency f=0.25) and provide best frequency localization in this region of the 1/scale axis. This is similar to the manner in which DWT coefficients focus on lower frequencies.
