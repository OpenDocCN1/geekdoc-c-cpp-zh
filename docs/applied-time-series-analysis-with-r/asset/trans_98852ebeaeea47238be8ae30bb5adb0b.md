## 7.2.1.3 Burg 估计

回顾，当 $\mu=0$ 时，OLS 估计基于方程 7.12 中的方程

$X_t = \phi_1 X_{t-1} + \dots + \phi_p X_{t-p} + \delta_t. \quad (7.15)$

由于 $X_t, t \le 0$ 无法观测，最小二乘估计仅基于方程 7.12 中的 $n-p$ 个方程，“响应变量 $X_{t-p}$ 到 $X_t$”。这些方程的使用似乎对可用信息利用效率不高，这促使 Burg (1975)、Ulrych 和 Clayton (1976) 以及 Nuttall (1976b) 考虑替代方案。他们认为，对于平稳过程，时间差没有“偏好”，因为 $X_t$ 与 $X_{t-i}$ 之间的相关性与 $X_t$ 与 $X_{t-k}$ 之间的相关性相同，对于平稳过程。Cheng (1999) 表明，平稳高斯过程是时间可逆的，并且非高斯广义线性平稳过程在前两个矩存在时是时间可逆的。因此，对于给定 $AR(p)$ 模型在方程 7.15 中适用的一组数据，我们可以考虑“向后”或“逆向” $AR(p)$ 模型

$X_t = \phi_1 X_{t-1} + \dots + \phi_p X_{t-p} + \delta_t, \quad (7.16)$

其中 $\delta$ 是零均值、方差为 $\sigma_{\delta}^2$ 的白噪声且 $t=0, \pm1$，标准 $AR(p)$ 模型将时间 $t$ 的结果指定为 $p$ 个前一时间值加上随机噪声。$X_t$ 与 $X_{t-i} \dots, X_{t-p}$ 之间的自相关是方程 7.16 模型中 $X_t$ 与 $X_{t+i} \dots, X_{t+p}$ 之间存在的自相关。
