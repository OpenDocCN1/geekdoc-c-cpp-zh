# 10.6.4.3 Smoothing Using the Kalman Filter

In this setting, values of $\mathbf{Y}_1, ..., \mathbf{Y}_n$ are observed and the goal is to estimate $\mathbf{X}_t$ where $t < n$, that is, we want to calculate $\mathbf{X}_t^f$. The recursion proceeds by calculating $\hat{\mathbf{X}}_t^f \hat{\mathbf{X}}_{t-1}^f \mathbf{\Gamma}_t^f$, and $t=1, ..., n$ using Equations 10.50 through 10.54. Then, for $t=n, n-1, ... we calculate

```
$$\hat{\mathbf{X}}_t^f = \hat{\mathbf{X}}_{t-1}^f + \mathbf{J}_{t-1}(\hat{\mathbf{X}}_t - \hat{\mathbf{X}}_{t-1}^f)$
```

```
$$\mathbf{\Gamma}_{t-1}^f = \mathbf{\Gamma}_{t-1}^f + \mathbf{J}_{t-1}(\mathbf{\Gamma}_t^f - \mathbf{\Gamma}_{t-1}^f)\mathbf{J}_{t-1}'$
```

where

```
$$\mathbf{J}_{t-1} = \hat{\mathbf{X}}_t - \mathbf{F}'[\hat{\mathbf{X}}_{t-1}^f]$
```

# 10.6.4.4 h-Step Ahead Predictions

It should be noted that the predictions in Equation 10.50 are one-step ahead predictions (or forecasts), that is, predictors of $X_t$ given observations of the random variables $Y_1, ..., Y_{t-1}$. However, the ARMA-based forecasting discussed in Chapter 6 provided ahead forecasts but also $h$-step ahead forecasts. State-space methodology can also be used to find $h$-step ahead predictors, that is the predictor of $X_{t+h-1}$ given observations on the random variables $Y_1, ..., Y_{t-1}$. The $h$-step ahead predictor, $\hat{\mathbf{X}}_{t+h-1}^f$, is defined to be

```
$$\hat{\mathbf{X}}_{t+h-1}}^f = E(\mathbf{X}_{t+h-1} | \mathbf{Y}_1, ..., \mathbf{Y}_{t-1})$
```

From Equation 10.48, it follows that $\hat{X}_{t+h-1} = \mathbf{FX}_{t+h-1} + \mathbf{V}_{t+h-1}$, so, from Equation 10.58, we have

```
$$\hat{\mathbf{X}}_{t+h-1}}^f = E(\mathbf{FX}_{t+h-2} + \mathbf{V}_{t+h-1} | \mathbf{Y}_1, ..., \mathbf{Y}_{t-1})\n= \mathbf{F}(\hat{\mathbf{X}}_{t+h-2} | \mathbf{Y}_1, ..., \mathbf{Y}_{t-1})\n= \hat{\mathbf{X}}_{t+h-2}}^f$
```

Continuing recursively, it follows that

```
$$\hat{\mathbf{X}}_{t+h-1}}^f = \mathbf{F}^{h-1}\hat{\mathbf{X}}_{t-1}}^f$
```
