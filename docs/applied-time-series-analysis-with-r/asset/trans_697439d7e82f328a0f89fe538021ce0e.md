## 3.3.4 ARMA(p,q) 模型的自相关系数

将方程 3.86 中的每一项（不失一般性地使用零均值）乘以 $X_{t-k}$ ($k \ge 0$) 并取期望，得到：

```
\gamma_k - \phi_1\gamma_{k-1} - \cdots - \phi_p\gamma_{k-p} = E[X_{t-k}a_t] - \theta_1E[X_{t-k}a_{t-1}] - \cdots - \theta_qE[X_{t-k}a_{t-q}]
= \gamma_X(0) - \theta_1\gamma_X(k-1) - \cdots, \quad (3.96)
```

其中

```
\gamma_X(m) = E[X_{t-m}a_t] = E\left( \sum_{j=0}^{\infty} \psi_j a_{t-j}\right). \quad (3.97)
```

使得 $\gamma_k'$ 和 $\rho_k$ 在 $k>q$ 时满足 $p$ 阶常系数齐次方程。由于我们假设 $\phi(z)$ 和 $\theta(z)$ 没有公因子，$p$ 是 $\rho_k$ 满足的常系数齐次方程的最低阶。方程 102 的解可以使其满足方程 3.99 在 $k=q,q-1,\dots,q-p$ 时的 $p$ 个线性边界条件。因此，对于 $k>q-p$，可得：

```
\rho_k=\sum_{i=1}^{m-1}\sum_{j=1}^{q}C_{ij}'\rho_{k-i}, \quad (103)
```

或者在特征方程无重根的情况下：

```
\rho_k=C_1\rho_1^{-k}+\cdots+C_p\rho_p^{-k}, \quad (104)
```

其中 $C_{ij}$ 和 $C_l'$ 是由方程 3.99 在 $k=q,q-1,\dots,q-p+1$ 时唯一定的常数。自方差函数也可以作为非齐次线性方程组的解来找到。令 $\nu=\max(p,q+1)$ 并在方程 3.99 中取 $\dots$ 得到关于 $\nu+1$ 个未知数 $\gamma_0, \gamma_1, \dots, \gamma_\nu$ 的 $\nu+1$ 个线性方程：

```
\gamma_0 = \phi_1\gamma_1 + \phi_2\gamma_2 + \dots + \phi_p\gamma_p - \sigma_a^2(-1+\theta_1\psi_1 + \dots + \theta_q\psi_q)
\gamma_1 = \phi_1\gamma_0 + \phi_2\gamma_1 + \dots + \phi_p\gamma_{p-1} - \sigma_a^2(\theta_2\psi_1 + \dots + \theta_{q+1}\psi_{q-1}) \quad (105)
\gamma_\nu = \phi_1\gamma_{\nu-1} + \phi_2\gamma_{\nu-2} + \dots + \phi_p\gamma_{\nu-p} - \sigma_a^2(\theta_\nu\psi_1 + \dots + \theta_{\nu+q-1}\psi_{q-1})
```

当 $j>q$ 时 $\theta_j=0$。$\psi$ 权重通过将给出的递归算法从 $\phi$ 和 $\theta$ 获得。对于 $k>\nu$，可以通过简单使用方程 101 中的递归式，利用起始值 $\gamma_\nu, \gamma_{\nu-1}, \dots, \gamma_0$ 来求解 $\gamma_k$。

注意，方程 103 显示对于 $ARMA(p,q)$，当 $k\to\infty$ 时 $\rho_k\to0$（等于 $\gamma_k\to0$）。根据定理 1.1，$ARMA(p,q)$ 过程 $\Gamma_k$ 和 $\rho_k$（分别在方程 1.2 和 1.3 中定义）对于每个整数 $k>0$ 都是正定的。

## 示例 3.19：特定 ARMA(P,Q) 模型的自协方差

- 1. ARMA(1,1) 模型：考虑由下式给出的 ARMA(1,1) 模型：

```
$X_i - \phi_1X_{i-1} = a_i - \theta_1a_{i-1}. \quad (3.106)
```

从方程 3.99，我们得到：

```
\gamma_0 = \phi_1\gamma_1 - \sigma_a^2(\theta_0\psi_0 + \theta_1\psi_1)
\gamma_1 = \phi_1\gamma_0 - \sigma_a^2(\theta_1\psi_0)
\gamma_k = \phi_1\gamma_{k-1}, \quad k>1, \quad (107)
```

```
\rho_k = \phi_1\rho_{k-1}=0, \quad (108)
```

且从方程 104 可得：

```
\rho_k = C_1(\frac{1}{\phi_1})^{-k}=C_1\phi_1^k. \quad (109)
```

为了找到 $C_1$，注意从方程 108 得 $\rho_2=\phi_1\rho_1$，且从方程 109 得 $\rho_2=C_1\phi_1^2$，因此 $\phi_1\rho_1=C_1\phi_1^2$，即 $C_1=\rho_1\phi_1^{-1}$，方程 110 变为：

```
\rho_k = \rho_1(\phi_1^{-1})^{k-1}, \quad (110)
```

对于 $k \ge 2$。现在，为了在 $k=0,1$ 时使用方程 107，需要找到 $\psi_1$。对于 ARMA(1,1)，$\psi_1=\phi_1-\theta_1$（见方程 316）。所以方程 111 变为：

```
\gamma_0 = \phi_1\gamma_1 - \sigma_a^2(-1+\theta_1(\phi_1-\theta_1)),
\gamma_1 = \phi_1\gamma_0 - \sigma_a^2\theta_1, \quad (111)
```

以及 $\gamma_k = \phi_1\gamma_{k-1}, k > 1$。求解方程 111 以得 $\gamma_0$ 和 $\gamma_1$，得到：

```
\gamma_0 = \frac{1-2\phi_1\theta_1+\theta_1^2}{1-\phi_1^2}\sigma_a^2,
```

以及

```
\gamma_1 = \frac{(\phi_1-\theta_1)(1-\theta_1)}{1-\phi_1^2}\sigma_a^2,
```

因此：

```
\rho_1 = \frac{(\phi_1-\theta_1)(1-\theta_1)}{1-2\phi_1+\theta_1^2}. \quad (112)
```

回顾示例16 中的 ARMA(1,1) 模型：再次考虑 ARMA(1,1) 模型 $(1-0.95B)X_t=(1-0.8B)a_t$，在方程 112 中，我们得到 $\rho_2=0.3$，且从方程 110 可得 $\rho_1=0.3(0.95^{-1})$ 对于 $k \ge 2$。注意，虽然 $\rho_1$ 不满足方程 108 中的线性齐次差分方程，但由于 $\rho_1=0.3$，它满足方程 110。

- 2. ARMA(2,1) 模型：考虑由下式给出的 ARMA(2,1) 模型：

```
$(1-\phi_1B-\phi_2B^2)X_t=(1-\theta_1B)a_t.
```

对于该模型：

```
\gamma_0 = \frac{2\theta_1\phi_1-(1-\theta_2)(1+\theta_2)}{(1+\phi_2)(\phi_1^2-(1-\phi_2^2))}\sigma_a^2, \quad (113)
```

以及

```
\gamma_1 = \frac{(\phi_1-\theta_1)(1-\phi_1\theta_1)+\phi_2^2\sigma_a^2}{(1+\phi_2)(1-\theta_2^2)-\phi_2^2} \quad (114)
```

对于 $k>1$，$\gamma_k$ 可以通过给定起始值 $\gamma_0$ 和 $\gamma_1$ 使用递归式 $\gamma_k = \phi_1\gamma_{k-1} + \phi_2\gamma_{k-2}$ 得到。

- 3. ARMA(1,2) 模型：对于 ARMA(1,2) 模型

```
$(1-\phi_1B)X_t = (1-\theta_1B-\theta_2B^2)a_t.
```

可以证明：

```
\gamma_0 = \frac{1-2\phi_1\theta_1-2\phi_2\theta_2+\theta_1^2+\theta_2^2}{1-\phi_1^2}\sigma_a^2,
\gamma_1 = \frac{(1-\phi_2^2-\phi_1\theta_1)(\phi_1-\theta_1)+\phi_1\theta_2^2}{1-\phi_1^2}
```

以及

```
\gamma_2 = \frac{\phi_1[(1-\theta_2-\theta_2^2-\phi_1\theta_1)(\phi_1-\theta_1)+\theta_2^2]-\theta_2+\sigma_a^2}{1-\phi_1^2}
```

同样，对于 $k>2$，自协方差可以使用递归公式 $\gamma_k = \phi_1\gamma_{k-1}$ 找到。

## 3.3.5 ARMA(p,q) 的 $\psi$-权重

我们已经证明 ARMA(p,q) 过程可以表示为线性滤波器 $X_t = \sum_{i=0}^{\infty} \psi_i a_{t-i}$。在本节中，我们讨论使用三种方法计算 $\psi$ 权重：(a) 系数法，(b) 除法和 (c) 使用定理 3.1 寻找通表达式。

- 1. 通过系数法寻找 $\psi$ 权重：由于平稳的 ARMA(p,q) 过程可以写成形式 $X_t = \psi(B)a_t$，其中 $\psi(B) = \phi^{-1}(B)\theta(B)$，我们有关系 $\phi(B)\psi(B) = \theta(B)$，或者展开形式为：

$$(1-\phi_1B-...-\phi_pBp)(1+\psi_1B+\psi_2B^2+...) = (1-\	heta_1B-...-\theta_qB^q). \quad (3.115)$$$
