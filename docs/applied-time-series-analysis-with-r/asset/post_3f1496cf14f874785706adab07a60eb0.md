Ljung and Box (1978) show that $L$ in Equation 9.3 is approximately distributed as $\chi^2$ with $K$ degrees of freedom when the data are white noise. When the data to be tested are residuals from a fitted ARMA$(p,q)$ model, then the test is statistically $\chi^2$ with $K-p-q$ degrees of freedom. Examination of Equation 9.3 shows that the test statistic measures the size of the first $K$ sample autocorrelations as a group, so that large values of $L$ suggest that the data are not white. Thus, the null hypothesis of white noise is rejected if $L > \chi^2_{1-\alpha}(K-p-q)$ where $\chi^2_{1-\alpha}$ denotes the $(1-\alpha) \times 100\%$ percentile of the $\chi^2$ distribution with $m$ degrees of freedom. In the examples that we use the Ljung-Box test with $K=24$ and $K=48$, which is consistent with the value of $K$ used by Box et al. (2008). For small sizes ($n \le 100$), Box et al. (2008) and Ljung (1986) recommend the use of smaller values of $K$.

**Using R:** `tsLboxtest` performs the Ljung–Box test. For more details see Appendix 9A.

## 9.1.3 Other Tests for Randomness

There are many other tests for white noise that could be used. Testing for white noise is essentially a test for randomness, so any such test (e.g., runs tests) could be used in this regard. See Davis and Jones (1968) for a test based on the log periodogram. Li (1988) and Chan (1994) have developed tests to be more robust than the Ljung–Box test to non-normal white noise. Peña and Rodriguez (2002) have developed a portmanteau that is claimed to be a more powerful alternative to the Ljung-Box test in the presence of normal noise.

## 9.1.4 Testing Residuals for Normality

Another issue that may be checked concerning residuals is normality. Normality is an assumption upon which ML estimates are based. Additionally, if uncorrelated residuals are non-normal, the ARCH-type behavior is a possibility. (See Section 4.2). Methods for checking normality include the use of Q-Q plots or formal tests for normality such as the Shapiro-Wilk test (Shapiro and Wilk, 1965). Other tests, for example the Anderson–Darling test (see Anderson and Darling, 1952) and a host of others can also be used to test for normality. In Figure 9.3, we see Q-Q plots of the (standardized) residuals in Figure 9.2. The normality of the residuals for the airline model seems like an appropriate assumption while the normality of the PA temperature residuals seems more questionable. Neither the Anderson–Darling nor the Shapiro–Wilk test reject normality for either set of residuals at $\alpha=0.05$.

**Using R:** Basic functions are available for checking normality. The function `qnorm(x)` plots a Q–Q plot, and `shapiro.test(x)` will perform a Shapiro–Wilk test of the null hypothesis that the data (in vector) are normal. Other tests for normality, including the Anderson-Dar test, Cramer–von Mises, and Lilliefors (Kolmogorov-Smirnov) tests, see Stephens (1974), can be obtained using functions in the CRAN package `forecast`.

## 9.2 Stationarity versus Nonstationarity

As discussed in Section 8.3, the decision concerning or not to include a nonstationary component in the model (e.g., a factor of $1–B$, a seasonal $1-B$, and so forth is one that will need to be made by the investigator. For example, AIC will not make such a decision for you. It was noted in Section 8.3 that there are tests for a unit root (i.e., the factor $1-B$ in model). However, as noted, the decision to retain a unit root is the result of failure to reject a null hypothesis, and as such the unit root tests do not sufficient power in general to distinguish between models near unit roots and with unit roots. The final decision whether to include a factor $1-B$ should be based on such considerations as there is any physical reason to believe there is an attraction to the mean. Another important issue is that realizations from the

```
$(1 - \delta B)(X_t - \mu) = a_t,$
```

where $\delta$ is close to 1 (but not greater than 1) may show piecewise trending behavior. In Example 5.1, we discussed whether the upward trend in the global temperature data is due to a deterministic (e.g., man-made) signal or simply random trending behavior. This is further discussed in the following example.
