# 7.6 Estimation Examples Using Data

In this section, we will use realizations discussed in Chapters 3 and 5 from known models to illustrate some of the concepts of this chapter.

Using R: As mentioned earlier, to obtain YW, Burg, or ML estimates of AR(p) parameters you can use est.ar.wge. To obtain ML estimates of ARMA model parameters use the tswge function est.arma.wge. The output contains the parameter estimates, residuals (using backcasting), white noise variance estimate obtained from the backcast residuals, and the standard errors for the parameter estimates.

# EXAMPLE 7.8: ESTIMATING PARAMETERS IN MA(q) MODELS

We consider the realization of length $n=100$ in Figure 3.1a from the MA(1) model $X_t = (1-0.99)Y_t$. In this case $	heta_1=0.99$ and $\sigma_\epsilon^2=1$. The MA characteristic equation has its root (1/0.99) very close to the noninvertible region. Using the itmr function to calculate innovations estimates, the estimates are $\hat{	heta}_1=0.8$ with $\hat{\sigma}_\epsilon^2=0.97$ while the MLE is $\hat{	heta}_1^2=0.94$. We see that in each case, the parameter is underestimated. It should be noted that the MM estimate does not exist because $ho_1=-0.54$. See Example 7.1. As previously mentioned, we do not recommend the MM estimates for MA(q) models.

We revisit this case, the AR(p) examples considered in Chapters 3 and 5. As mentioned earlier, the methods (YW, Burg, and MLE) behave similarly, but for AR(p) models with roots close to the nonstationary region, the YW estimates do not perform as well.

# EXAMPLE 7.9: PARAMETER ESTIMATION FOR SELECTED AR MODELS

+   AR(1): Figure 3.5a shows a realization of length $n=100$ from the AR(1) model $X_t = (1-0.95)X_{t-1}+a_t$, when $\sigma_a^2=1$. > $SD(\hat{\phi}_1) = \sqrt{\frac{(1-0.95^2)}{100}} = 0.03,$

from which it follows that all of these estimates are within one SE of the true value.
