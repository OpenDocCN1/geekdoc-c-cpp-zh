## 13.2.2 Discrete M-Stationary Process

Example 13.1: Motivates the Definition.

### Definition 13.3

Let h > 1 and S = {t_k : t_k = h^k, k = 0, ±1, ±2, ...} and suppose

- 1. E[X(h^k)] = $\mu$
- 2. Var[X(h^k)] = $\sigma^2 < \infty$
- 3. E[(X(h^k) - \mu)(X(h^{k-j}) - \mu)] = R_X(h^j)$

for all t_k = h^k ∈ S. Then X(t_k) is a discrete M-stationary process with the discrete dual process Y(t_k) = X(h^{-k}).

C_Y(j) = E[(Y(t_k)-\mu)(Y(t_{k-j})-\mu)]. This can be rewritten C_Y(j) = E[(X(h^k) - \mu)(X(h^{k-j}) - \mu)] = R_X(h^j). Since C_Y(j) = C_{-Y}(j), it follows that R_X(h^j) = R_X(h^{-j}). If t_k = h^k and u = g(t) = t/ln h, then u_k = g(t_k) = g(h^k) = h^k/ln h. Then, t_k = g^{-1}(u_k) = h^k. So

```
$g^{-1}(g(t_k) + g(t_j)) = h^{(g(t_k)+g(t_j))}$
$= h^{k+j}$
$= h^{k'}$
```

Thus, a discrete M-stationary process is a discrete G-stationary process with u_k = g(t_k) = t/ln h and S = {t_k : t_k = h^k, k = 0, ±1, ±2, ...}. That is, u_k = k.

## 13.2.3 Discrete Euler(p) Model

Making use of Definition 13.3, Vijverberg and Gray (2009) and Gray et al. (2005) introduced and studied Euler(p) processes. See also Vijverberg and Gray (2009).

### Definition 13.4

Let t_i ∈ S = {t_k = h^k, k = 0, ±1, ±2, ...}, and suppose X(t_i) is the M-stationary solution of

```
$(X(h^k) - \mu) - \phi_1(X(h^{k-1}) - \mu) - \dots - \phi_p(X(h^{k-p}) - \mu) = a(h^k)$
```

where a(h^k) is white noise. Then X(t_i) is called a discrete Euler(p) process.

## Applied Time Series Analysis with R

Whenever there is no loss in generality, we will, without comment, generally take $\mu = 0$. So, we write Equation 13.5

```
$X(h^k) - \phi_1 X(h^{k-1}) - \cdots - \phi_p X(h^{k-p}) = a(h^k).$
```

If $Y_k = X(h^k)$ and $a(h^k) = Z_k$, then

```
$Y_k - \phi_1 Y_{k-1} - \cdots - \phi_p Y_k = Z_k.$
```

Consequently, if $X(t)$ is a $p$-th order discrete Euler process, then its dual process is a discrete AR(p). Choi et al. (2006) extend Definition 13.4 to the discrete Euler $(p,q)$ process.

## 13.2.4 Transformation and Sampling

It should be clear from Definition 13.3 that an M-stationary process requires sample values at unequally spaced points. This is true in general for G-stationary processes. Thus, finding a transformation $u = g(t)$, is equivalent to determining a sampling scheme such that $X(t_k) = X(g^{-1}(u_k)) = Y_k$, where $Y_k$ is stationary. That is, $X(t)$ should be sampled at points $t = t_k = g^{-1}(u_k)$. In the case of M-stationary processes, $t_k = h^k$ and $u_k = k\Delta$. In general, of generality, we take $\Delta = 1$, so $t_k = h^k$ and $u_k = k$.

In general, data only will be available at equally spaced points and may not necessarily be obtainable at the points $t_k$. This problem can be overcome by over-sampling or interpolation. By over-sampling, we indicate the situation in which data are sampled at sufficiently small increments in time so that the values of the realization are available at the $t_k$. The data available only at equally spaced points cannot be sufficiently over-sampled, and interpolation and Kalman filter can be used to process the data.
