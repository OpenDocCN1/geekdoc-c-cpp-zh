To obtain and fit the desired spectral density, we use
trsp=true.spec.wge(phi=ar$model.coef, theta=ma$model.

+   3. factor.comp.wge(x, p, ncomp, report, append) fits an
(p) model to a realization x, calculates and prints a factor table
associated with an AR(p) model to fit the data using Burg estimates,
and plots ncomp additive components where ncomp
is less than or equal to the number of factors in the factor table.

x is a vector of n containing the time series realization x,
t=1..,n.
p is the order of the AR model to fit to the data
ncompcomp is the number of additive components to be calculated and
plotted

Example: In this example we find additive components for the data
in Figure 3.26a (also shown in Figure 3.16a) and contained in tswge
daset fig3.16a. If we use the command,

```
data(fig3.16a); test=factor.comp.wge(fig3.16a,p=3,ncomp=2)
```

| Factor | Roots | Abs Recip | System Freq |
|---|---|---|--|
| 1-0.9651B | 1.0361 | 0.9651 | 0.0000 |
| 1-1.5594B+0.8397B^2 | 0.9286 -0.5733i | 0.9164 | 0.0880 |

This is the factor table for the model (1–2.5426B+2.3488B-
0.8104B^3)X=at, which is the AR(3) model to fit to the data
in Figure 3.26a see Chapter 7 for a discussion of parameter estimation.
Note that this model is similar to slightly different from the AR(3)
model used in Example 3.20. The components will be very sim-
lar different from those shown in Figure 3.26b and c.

+   4. atrans.wge(x,phi,tr,lag.max,plottr) performs an AR trans-
formation yi=phi(B)x, where the coefficients of phi(B) are given in phi.
t.
x=original realization
phi.tr=vector of transforming components
lag.max=maximum lag for calculated sample autocorrelations
(original and a transformed data) (default=25)
plottr=logical variable.
