## 13A.3 GIF and Instantaneous Spectrum of a GLC($p$) Process

In the case of the GLC($p$) process, the GIF is given by

```
$f_t = \frac{2a}{(2at+b)\pm\sqrt{\frac{1+8a\pi}{(2at+b)^2}}} (13A.6)$
```

where the + - relate to frequencies to the right and left of the reflection point, respectively. Corresponding to Equations 13A.3 and 13A.4, it follows that the instantaneous spectrum, $S(f_t; t; a, b)$, is given by $S(f_t; t; a, b) = G(f; a, b)$, where $G(f; a, b)$ is the spectrum of the dual and

```
$f_t^* = \frac{f_t^2}{(2at+b)f_t+a} (13A.7)$
```

See Robertson et al. (2010) and Jiang et al. (2006).

## Appendix 13B: R Commands

Several swge functions are available for performing analysis of TVF data. The functions are particularly focused on the use of $G(\lambda; p)$ models to analyze TVF data.

- * gen.glamba.wge(n,lambda,phi,offset,vara,plot,sn) is a function that generates a realization of length $n$ from a given $G(\lambda; p)$ model.
* n is the realization length $(x_t, t=1, ..., n)$, that is evaluated at equally spaced points $1, ..., n$.
* NOTE: The generated model is based on zero mean. If $xt$ is the time series generated by gen.glamba.wge, then to convert this to a time series with mean $\mu=10$, simply compute $yt = xt+10$
* lambda is the value of $\lambda$ in the $G(\lambda; p)$ model (default is $\lambda=0$,)
* phi is the vector of AR parameters (default is $\phi=0$)
* offset is the offset parameter (for example the discussion about Figure 13.2 (default = 60)

vara is the white noise variance (default = 1)
plot = TRUE (default) produces a plot of the realization generated
sn determines the seed used in the simulation. (see Note (5) below).

## NOTES:

- 1. This function finds p as length of phi. If phi = 0 (default) the value for p is set to zero.
2. gen.lambda.wge calls the tswge function gen.arma.wge which in turn calls the base R function arma.sim.
3. It will be useful to call the utility mult.wge if you know tactors of the AR model instead of coefficients.
4. By default the white noise is zero mean, normal noise with variance vara = 1
5. sn = 0 (default) produces results based on a randomly selected runs if you want to produce the same realization on subsequent of gen.lambda.wge then set sn to the same positive value on each run.

Example: The command

```
x = gen.lambda.wge(n = 500,lambda = 0.5,phi = c(1.9,-
.99),offset = 25, vara = 1)
```

generates and plots a realization from the model used to generate t realization in Figure 13.6b. The seed is randomly selected, realization generated here will not match Figure 13.6b exactly, but it will have the decreasing frequency TV characteristics.

- b. est.lambda.wge(x,lambda.range,offset.range) estimates lambda and offset (within specified ranges) that produce the "most stationary" dual.

x is an exactly spaced TFV data set
lambda.range is a 2-component vector specifying the lowest and highest values of lambda to be considered.

offset.range is a 2-component vector specifying the lowest and highest values of offset to be considered.

Example: The commands to find the values of lambda and offset that create the data set in Figure 13.4b are

```
data(fig13.2c
est.lambda.wge(fig13.2c,lambda.range = c(-.5,.5),offset
range = c(0,100))
```

NOTE: The top values of lambda and offset that were returned are lambda = -0.4 and offset = 63. Example 13.7.

c. trans.to.dual.wge(x,lambda,offset,plot) transforms the time axis to create a dual process using linear interpolation.
x is an equally spaced TVF data set
lambda is the value of $\lambda$ in the $G(\lambda; p)$ model (default is lambda = 0, i.e., x is a realization from an M-stationary model)
offset is the offset parameter (see for example the discussion about Figure 13.2) (default = 60)
plot = TRUE (dual) produces a plot of the dual realization created

The function outputs:
intX and intY: The input realization x is of length $n$, and the values x are available at the time points $t=1, ..., n$. The values intY $n$ interpolated values of the original time series at the values of intX in the original time set. The dual data set obtained by associating the $n$ values of intY with $t=1, ..., n$ respectively.

h is an output value of the scaling parameter that assures that the dual realization and the original realization are of the same length.

> NOTE: trans.to.dual is based on $G(\lambda)$-stationary modeling. M-stationary models are obtained by using $\lambda=0$.

Example: The command
data(fig13.2c)
y = trans.to.dual.wge(fig13.2c,lambda=-0.4,offset=63)
compute and in this plot the dual data shown in Figure 13.4b saves the dual data in yintY using the $G(\lambda)$ transform- sified by lambda and offset, which in this case were obtained in Example 13.7.

d. trans.to.original.wge(xd,lambda,offset,h,plot) transforms a dual data set in transformed time back to the original time set. The values of lambda and offset are used in the function trans.to.dual.wge used previously to transform the time axis, the value of h is obtained as output from the function trans.to.dual.wge.

xd is the equally spaced dual data set in the transformed specified by the $G(\lambda)$ time used in trans.to.dual
lambda is the value of lambda in the $G(\lambda)$ transformation used to create the dual
offset is the value of offset in the $G(\lambda)$ transformation used to create the dual
h is a scaling parameter (obtained as output from trans.to.dual) designed to assure that the dual realization and the original realization is of the same length
plot = TRUE (default) or optionally plots) produces a plot of the dual realization created

The function outputs (and optionally plots) reintY which are the Y values to be plotted against $t=1, \dots, n$ that approximate the original TV realization.

*Example:* The G-filtering code used to create the dual, low-pass filtered, and associated filtered data in the original time space discussed in Section 13.5 are as follows (using the true values $\lambda = 0$ and offset = 175).

```
data(fig13.18a)
dual = trans.to.dual(fig13.18a,lambda = 0,offset = 175)
l1 = butterworth.wage(dual$intY,order = 4,type = 'low',cutoff = .075)
l10 = trans.to.original(wde$x.filt,offset = 175,
h = dual$h,lambda = 0)
```

e.fore.glambda.wa (x, lambda, phi, n.ahead, lastn, plot)

This function forecasts n.ahead steps ahead using the 3-step approach discussed in Section 13.3.3 and further illustrated in Example 13.7. You can optionally calculate and plot forecasts n.ahead steps beyond t end of the series or you can forecast the last n.ahead data values. For comparison, AR forecasts will also be plotted.

x = realization
lambda is the value of $\lambda$ in the $G(\lambda; p)$ model (default is $\lambda = 0$, i.e. an M-stationary model)
offset is the offset parameter (for example the discussion about Figure 13.2) (default = 60)
phi is a vector of AR parameters for the AR model fit to the dual data (default is phi = 0)
n.ahead = the number of steps ahead you want to forecast (default = 2)

G-Stationary Processes

lastn = logical variable. If lastn = FALSE (default) then the forecasts are for x(n+1), x(n+2), ..., x(n+n.ahead) where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization (default = FALSE). AR forecasts are also plotted for comparison.

plot is a logical variable. If plot = TRUE (default) then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output. (default = TRUE)

Example: To plot and show the forecasts in Figure 13.8b, using the following commands:
data(fig13.2c)
dual=trans.to.dual.wge(fig13.2c, lambda = -.4, offset = 63)
aic5.wge(dual.data,p=0:12,type = 'bic')
#BIC picks p=5
ardual=est.ar.wge(dual.data,p=5)
example=fore.glambda.wge(fig13.2c, lambda = -.1, offset = 38, phi=ardual$phi,n.ahead=60.lastn=TRUE

NOTE: The data was obtained by transforming using the λ and off-set found in Example 13.2. Also see example for est.glambda. wge.
