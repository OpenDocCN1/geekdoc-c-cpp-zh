# EXAMPLE 5.2:atNX DATA

We return to the lynx data (data set lynx in *tswe*) shown in Figure 3.15 represents the annual number of lynx trappings in Canada from 1821 to 1934 (see Campbell and Walker, 1977). We previously considered this data set in Example 3.7 where we noted that the asymmetry in the actual lynx data shown in Figure 3.15a, the data has historically been analyzed after first taking the base 10 of the number of lynx trapped, and this data set (*tswe*) shown in Figure 3.15b it can be seen that the asymmetry is largely removed. The Parzen density estimate of the log-lynx data where the cyclic behavior of 10 years is apparent in both plots. A feature to note about the sample autocorrelations are their slowly damping behavior.

We used a AR(2) model for the log-lynx data in Example 3.7, where the AR model typically used to model the log-lynx data is the AR(11) model

```
$(1 - 1.13B + 0.51B^2 - 0.23B^3 + 0.29B^4 - 0.14B^5 + 0.08B^6 - 0.04B^7 - 0.013B^8 - 0.019B^9 + 0.031B^{11})(X_t - 2.904) = a_t, \ \hat{\sigma}_a^2 = 0.036$
```

proposed by Tong (1977). Also, Campbell and Walker (1997) obtained the harmonic component model

```
$X_t = 2.9036 + 0.3649\cos(\frac{2\pi}{9.5}) - 0.4866\sin(\frac{2\pi}{9.5}) + U_t$,
```

where $u_t = 1.0302u_{t-1} - 0.3228u_{t-2} + a_t$, and $a_t$, has a zero mean variance 0.044. Bhansali (1979) compared the results and concluded, that the Priestley's test data contained a harmonic component. Woodward and Gray (1983) pointed out that the factored form of the Tong model has a factor of $1-1.562B + 0.967B^2$ which has roots very close to the unit circle (the absolute reciprocal $|r| = 0.98$) associated with frequency $f_0=0.104$ (=1/96). Additionally they generated realizations from the AR(11) model, which does not have harmonic components, and found that the Priestley's $P(\lambda)$ test usually detected "harmonic components." The lynx data will be re-examined in Chapter 11 when we discuss cyclic long-memory behavior.
