# EXAMPLE 10.8: STATE-SPACE FORMULATION OF A STATIONARY AR(1) MODEL

Let $Y$ be a univariate stationary AR(1) process given by $Y_t = \phi_1 Y_{t-1} + a$. A univariate state-space representation is straightforward using the following:

```
$X_t = \phi_1 X_{t-1} + V_t \quad$ (state equation)\n$Y_t = X_t \quad$ (observation equation).
```

That is, in this case, $F = \phi_1, G_1 = 1, V_t = a_t$, and $W_t = 0$.

# EXAMPLE 10.9: STATE-SPACE FORMULATION OF A STATIONARY AR(1)-PLUS-NOISE MODEL

Consider the state and observation equations

```
$X_t = \phi_1 X_{t-1} + V_t \quad$ (state equation)\n$Y_t = X_t + W_t \quad$ (observation equation).
```

which are the same as those in Example 10.8 except that the noise $W_t$ is not identically zero. Consider, for example, the case in $\phi_1 = 0.9, \sigma_V^2 = 1$, and $\Gamma_W = \sigma_W^2 = 0.75$. In this case, $X$ is AR(1), but the observed $Y$ is not AR(1). In Figure 10.11, we show plots of realizations from $X$ and $Y$. These realizations are contained in twage files fig10.11x and fig10.11y, respectively.
