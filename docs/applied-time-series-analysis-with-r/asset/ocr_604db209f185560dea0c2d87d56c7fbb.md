# EXAMPLE 5.4: AN ARIMA(2, 2, 2) PROCESS

Consider the process

$X_i + 0.3X_{i-1} + 0.6X_{i-2} - 0.3X_{i-3} = 9 = a_i + 0.5a_{i-1} + 0.9a_{i-2}$,

which factored in form is given

> $(1-0.5B)(1+0.8B)(1+B^2)(X-5) = (1+0.5B+0.9B^2)Y_i$. (5.10)

From the factored form in Equation 5.10, it is seen that $X_i$ satisfies an ARIMA $(2, 2, 2)$ with $\mu = \phi(1)(1)$ is 5 where $Y_i = (1+B)^2(X-5)$ satisfies the equation

> $(1-0.5B)(1+0.8B)Y_i = a_i + 0.5a_{i-1} + 0.9a_{i-2}$,

and $Y_i$ is stationary with $E[Y_i]=0$.
