# Forecasting

The prediction interval in Equation 6.33 has the intuitively reasonable property that the half widths

```
$Z_{1-a/2}\sigma_a = \left( \sum_{k=0}^{t-1} \psi_k^2 \right)^{1/2}, \quad (6.34)$
```

are non-decreasing as $\ell$ increases. For a stationary process, as $\ell \to \infty$,

```
$\sigma_a = \left( \sum_{k=0}^{t-1} \psi_k^2 \right)^{1/2} \to \sigma_a = \left( \sum_{k=0}^{\infty} \psi_k^2 \right)^{1/2} = \sigma_X(<\infty)$.
```

**Using R:** Forecast limits can be calculated using limits = TRUE in the call statement to tswge function fore.arma.wge. If you want the forecasts and the limits to be plotted then limits and plot should be set to TRUE. If you want only to plot the forecasts then use plot = TRUE and limits = FALSE. See Appendix 6B.

```
$$\psi_1 = \phi_1 - \theta_1 = 1.2 - 0.5 = 0.7$
```

and for $k > 1$,

```
$$\psi_k = \phi_1\psi_{k-1} + \phi_2\psi_{k-2} = 1.2\psi_{k-1} - 0.6\psi_{k-2}$.$
```

Thus, since $\psi_0 = 1$, it follows that

```
$$\psi_2 = 1.2\psi_1 - 0.6\psi_0 = 1.2(0.7) - 0.6(1) = 0.24$,
```

and the calculation of $\psi_k$ for $k > 2$ follows similarly.
