## 7.3.2 ML Estimation Using the Innovations Algorithm

The exact likelihood function in the ARMA$(p,q)$ case can be expressed in terms of the innovations algorithm (see Brockwell and Davis, 1991) for calculating one-step ahead forecasts. The log-likelihood function can be written as

```
$l(\phi, \theta, \sigma_a^2) = -\frac{n}{2}\ln(2\pi\sigma_a^2) - \frac{1}{2}\sum_{t=0}^{n-1}\ln(r_t) - \frac{\sigma_a^2}{2}\sum_{t=1}^{n}\frac{(X_t - \hat{X}_{t-1}(1))^2}{r_{t-1}}, \quad (7.43)$
```

where, using the notation of Chapter 6, $\hat{X}_{t-1}(1)$ is the one-step ahead forecast for $X_t$ (using the $\phi'_j$ and $\theta'_s$)

```
$r_t = \frac{E[X_{t+1} - \hat{X}_t(1)]^2}{\sigma_a^2}$
```

Taking the partial derivative of $l(\phi, \theta, \sigma_a^2)$ with respect to $\sigma_a^2$ results in

```
$\hat{\sigma}_a^2 = \frac{1}{n}S_u(\hat{\phi}, \hat{\theta}), \quad (7.44)$
```

where

```
$S_u(\hat{\phi}, \hat{\theta}) = \sum_{t=1}^{n}\frac{(X_t - \hat{X}_t(1))^2}{r_{t-1}}$
```

is evaluated at the ML estimates of the $\phi'_s$ and $\theta'_s$. By inserting $\sigma^2$ in Equation 7.44 into Equation 7.43, it can be seen that the ML estimates of the $\phi'_s$ and $\theta'_s$ are those values that minimize the reduced likelihood

```
$l_r(\phi, \theta) = \ln(n^{-1}S_u(\phi, \theta)) + n^{-1}\sum_{t=1}^{n}\ln r_{t-1}$.
```

The least squares estimates can be obtained by simply finding the $\hat{\phi}$ and $\hat{\theta}$ that minimize

```
$S_n(\hat{\phi}, \hat{\theta}) = \sum_{t=1}^{n} \frac{(X_t - \hat{X}_t(1))^2}{r_{t-1}}$
```

These estimates are often very similar to the ML estimates.

A closed form of the unconditional or exact likelihood function for the ARMA($p,q$) case has been given by Newbold (1974). Ansley (1979) and Ljung and Box (1979) discuss algorithms for finding the exact ML estimates.

## 7.4 Backcasting and Estimating $\sigma_a^2$

In this section, we discuss the use of backcasting to the white noise estimates $\hat{a}_k, \dots, \hat{a}_n$ in Equation 7.39 that are used to estimate the unconditional sum of squares in Equation 7.38. Not only does backcasting provide estimates, $\hat{a}_k, \dots, \hat{a}_0$ but it produces improved estimates of $\hat{a}_1, \dots, \hat{a}_n$ compared to those obtained using the conditional approach (e.g., the white noise estimates in Table 6.1). Although a few estimation procedures (e.g., MM, Jung, and innovations) provide an estimate of the white noise variance, in practice, we recommend the use of the estimator given in Equation 7.41 where the white noise estimates are obtained using backcasting. While the estimator in Equation 7.41 is based on ML estimation of the parameters, the procedure can be generated by

The procedure in tswege function backcast.wge for backcasting is outlined as follows:

- 1. Obtain the parameter estimates $\hat{\phi}_1, \dots, \hat{\phi}_p, \dots, \hat{\theta}_q$ using an estimation method
- 2. Backcast using these parameter estimates to obtain estimates of $X_k, X_{k-1}, \dots, X_K$ for $K=50$ based on the (backward) model

```
$X_t - \hat{\phi}_1 X_{t-1} - \dots - \hat{\phi}_p X_{t-p} = \delta_t - \hat{\theta}_1 \delta_{t+1} - \dots - \hat{\theta}_q \delta_{t+q}$
```

Notice that $\delta_1, \dots, \delta_q$ will need to be estimated whenever $q>0$.

- 3. Use the backcast estimates of $X_k, X_{k-1}, \dots, X_{-K}$ to obtain the white noise estimates

```
$\hat{a}_t = \hat{X}_t - \hat{\phi}_1 \hat{X}_{t-1} - \dots - \hat{\phi}_p \hat{X}_{t-p} + \hat{\theta}_1 \hat{a}_{t-1} + \dots + \hat{\theta}_q \hat{a}_{t-q}$
```

$t = -K+p, \dots, n$, when $\hat{X}_t$, is taken to be a value obtained using backcasting for $t=-K+p, \dots, 0$, and $\hat{X}=X_t, t=1, \dots, n$. Also, $\hat{a}_t$ is taken to be 0 for $t < -K+p$.

- 4. Use the estimates $\hat{a}_t, t=1, \dots, n$ to obtain the white noise variance estimate

```
$$\hat{\sigma}_a^2 = \frac{1}{n} \sum_{t=1}^n \hat{a}_t^2. \quad (7.45)$$
```

### EXAMPLE 7.4: USING BACKCASTING TO ESTIMATE RESIDUALS FOR DATA IN TABLE 6.1

In Example 6.2, we found forecasts based on the ARMA(2,1) model

```
$(1-1.2B+0.6B^2)(X_t-50) = (1-0.5B)a_t. \quad (7.46)$
```

In this example, we found estimates of the residuals for purposes of calculating the forecasts. Actually, only $\hat{a}_{23}$ and $\hat{a}_{25}$ were obtained by the conditional implementation of setting $\hat{a}_1$ and $\hat{a}_2$ to zero. This procedure is satisfactory for calculating $\hat{a}_{25}$ yet it does not provide estimates of $a_1$ and $a_s$, and the estimates of $a_t$, for smaller values of $t$ are poor because of their dependence on the starting values. Consequently, $(\sum_{t=1}^n \hat{a}_t^2)/(n-2)$ may be a poor estimator of $\sigma_a^2$. We use the backcasting technique to obtain and use the steps outlined earlier. We illustrate the backcasting procedure using the steps outlined.

- 1. In this example, we simply use the true parameters as the estimated values for better comparison with the results in Table 6.1.
- 2. Backcasts from the model

```
$X_t-1.2X_{t+1}+0.6X_{t+2} = \delta_t-0.5\delta_{t+1}, \quad (7.47)$
```

involve $\delta_t$ and to calculate this quantity, we set $\hat{\delta}_{25}=\hat{\delta}_{24}=0$ and recursively compute $\hat{\delta}_t, t=23, 22, \dots, 1$ using the formula

```
$$\hat{\delta}_t=X_t-1.2X_{t+1}+0.6X_{t+2}+0.5\hat{\delta}_{t+1}-50.04(0.4), \quad (7.48)$$
```

which is analogous to the formula used in Example 6.2 for calculating residuals based on the forward model in Equation 7.46. For example,

$$\hat{\delta}_{23}=X_{23}-1.2X_{24}+0.6X_{25}+0.5\hat{\delta}_{24}-50.04(0.4)=0.48,$$

and continuing the calculation gives $\hat{\delta}_t = -1.36$. We next backcast to obtain estimates of $\hat{X}_{ur}, \dots, \hat{X}_K$ using the formula

```
$$\hat{X}_t^\ell(1) = 1.2\hat{X}_t^\ell(2) - 0.6\hat{X}_t^\ell(3) - 0.5\hat{\delta}_t + 50.04(0.4),$$
```

and for $\ell > 1$

```
$$\hat{X}_t^\ell(\ell) = 1.2\hat{X}_t^\ell(\ell+1) - 0.6\hat{X}_t^\ell(\ell+2) + 50.04(0.4), \quad (7.49)$$
```

where $\hat{X}_t^\ell(\ell)$ is the forecast of $X_{t-\ell}$ given data from $X_1, X_2, \dots$ the default value for $K$ in $wge$ is 50, but show in Table 7.2, we only show the residuals for $X_t, X_{t-1}, \dots, X_{t-\ell}$. Set $\hat{a}_{50} = \hat{a}_{49}$ and calculate the residuals

```
$$\hat{a}_t = -1.2\hat{X}_{t-1}^B + 0.6\hat{X}_{t-2}^B - 0.5\hat{a}_{t-1} - 50.04(0.4),$$
```

where $\hat{X}_t^B$ is defined in Step 2. These values are shown for $t=-12, -11, \dots, 25$ in Table 7.2, it can be seen that for $t \geq 12$ the residuals then obtain agree with those shown in Table 6.1 obtained using the conditional approach.

- 4. Estimate $\sigma_t^2$ using $\hat{\sigma}_t^2 = \frac{1}{25}\hat{a}_t^2 = 0.68$
