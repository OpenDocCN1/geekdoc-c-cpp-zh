# Definition 3.3

If X, the AR(p) process defined by Equation 3.17, then the algebraic equation $\phi(z)=0$ is called the associated characteristic equation where

```
$$\phi(z) = 1 - \phi_1 z - \dots - \phi_p z^p,$$
```

and $z$ is a real or complex number. The polynomial $\phi(z)$ is called the characteristic polynomial.

Theorem 3.2 is an important result for determining whether a given set of AR(p) coefficients yield a causal, stationary AR(p) process.
