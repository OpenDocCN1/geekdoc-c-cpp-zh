# 1.4.3 Estimation of $ho_k$

The natural estimator of $ho_k = \gamma_k/\gamma_0$ is $\hat{ho}_k = 	ilde{\gamma}_k/	ilde{\gamma}_0$, which we will refer to as the sample autocorrelation function. The estimator $\hat{ho}$ has the desirable property that $|hat{ho}| \le 1$, a property that $	ilde{ho}_k = 	ilde{\gamma}_k/	ilde{\gamma}_0$ does not possess. This property can be shown by relating $\hat{ho}$ to the Pearson product-moment correlation between the two sets of $n+k$ observations

```
$0,0,...,0, X_1-\tilde{X}_1, X_2-\tilde{X}_2, ..., X_n-\tilde{X}_n$,\nX_1-\tilde{X}_1, X_2-\tilde{X}_2, ..., X_n-\tilde{X}_n, 0,0,...,0,$
```

where, in each case, there are zeros. For notational convenience, we will denote the first row by $V_ho$ $i=1, ..., n+k$ and the second row by $W_ho$ $i=1, ..., n+k$. Thus, $	ilde{V} = 	ilde{W} = 0$ and the product-moment correlation between $V$ and $W$ is given by

```
$r = \frac{\sum_{i=1}^{n+k} V_i W_i}{\sqrt{\sum_{i=1}^{n+k} V_i^2 \sum_{i=1}^{n+k} W_i^2}}$
```

The denominator can be rewritten as $\sum_{t=1}^n (X_t-\tilde{X}_t)^2$, and the numerator can be written as $\sum_{i=1}^k V_i W_i + \sum_{i=n+1}^n V_i W_i + \sum_{i=n+1}^{n+k} V_i W_i$. The first and last sums are zero, so that the numerator can be written as

```
$\sum_{i=1}^k V_i W_i + \sum_{i=n+1}^n V_i W_i = \sum_{t=1}^n (X_t-\tilde{X}_t)(X_{t+k}-	ilde{X}_{t+k}).$
```

Thus $r = \hat{ho}_k$ and so $|\hat{ho}_k| \le 1$.

