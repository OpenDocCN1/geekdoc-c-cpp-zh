# Long-Memory Processes

# 11.3.3 GARMA Process

In the same manner that the fractional process has been extended to FARMA process, Definition 11.6 which follows extends the Gegenbauer process by combining it with the ARMA process.

# Definition 11.6

If $X_i$ is a causal, stationary, and invertible process satisfying

```
$$\phi(B)(1-2uB+B^2)^\lambda(X_i-\mu) = \theta(B)a_i, \quad (11.16)$
```

where $\phi(z)$ and $	heta(z)$ share no common factors, then $X_i$ is a Gegenbauer ARMA (GARMA) process which will be denoted GARMA$(p, \lambda, u, q)$. Theorem 11.5 summarizes the properties of the GARMA process.

# Theorem 11.5

Let $X$, be a GARMA process $(\lambda \neq 0)$ and let all roots of $\phi(z)=0$ and $	heta(z)=0$ lie outside the unit circle. Then we have the following:

+   1. $X_i$ is stationary if $\lambda < 1/4$ when $u = \pm1$ or $\lambda < 1/2$ when $|u| < 1$.
2. $X_i$ is invertible if $\lambda > -1/4$ when $u = \pm1$ or $\lambda > -1/2$ when $|u| < 1$.
3. The spectrum is given by

```
$P(f) = \sigma_\eta^2 \left| \frac{\theta(e^{-2\pi i f})^2}{\phi(e^{-2\pi i f})^2} \right|^{1-2u\exp(-2\pi i f)+\exp(-4\pi i f))^{-\lambda}}\n= \sigma_\eta^2 \left| \frac{\theta(e^{-2\pi i f})^2}{\phi(e^{-2\pi i f})^2} \right|^2 [4(\cos(2\pi f)-\cos(2\pi f_G))^2]^{-\lambda}$.
```

+   4. $X_i$ is long memory if $\lambda < 1/4$ when $u = \pm1$ and $0 < \lambda < 1/2$ when $|u| < 1$.
5. As $k \to \infty$,
na. $\rho_k \simeq k^{4\lambda-1}$ when $u = 1$ and $0 < \lambda < 1/4$\nb. $\rho_k \simeq (-1)^k k^{4\lambda-1}$ when $u = -1$ and $0 < \lambda < 1/4$\nc. $\rho_k \simeq k^{2\lambda-1} \cos(2\pi f_G)$ when $|u| < 1$ and $0 < \lambda < 1/4$.

Proof: See Gray et al. (1989, 1994).
