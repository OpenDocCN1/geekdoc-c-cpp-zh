# EXAMPLE 6.4: FORECASTS FROM AN ARIMA(1,1,0) MODEL

Consider the ARIMA(1,1,0) model

```
$$(1 - 0.8B)(1 - B)X_t = a_t. \quad (6.42)$
```

A realization of length $n = 50$ from this model is shown in Figure 6.6 (and is available in tswage data set fig6nf). Upon multiplication of the factors in Equation 6.42, we obtain

```
$$(1 - 1.8B + 0.8B^2)X_t = a_t,$$
```

so that $\phi_1^{(i)}$ and $\phi_2^{(i)} = -0.8$. From Equation 6.36, forecasts from this model are given by

```
$$\hat{X}_t(\ell) = 1.8\hat{X}_t(\ell-1) - 0.8\hat{X}_t(\ell-2) + (1 - 1.8 + 0.8)\bar{X} \n = 1.8\hat{X}_t(\ell-1) - 0.8\hat{X}_t(\ell-2).$$
```

Again, because of the $(1 - B)$ factor, X plays no role in the forecasts. It follows that

```
$$\hat{X}_t(1) = 1.8\hat{X}_t - 0.8\hat{X}_{t-1}, \n\hat{X}_t(2) = 1.8\hat{X}_t(1) - 0.8\hat{X}_{t-1},$
```

and, in general, for $\ell > 0$,

```
$$\hat{X}_t(\ell) = 1.8\hat{X}_t(\ell-1) - 0.8\hat{X}_t(\ell-2). \quad (6.43)$
```

These forecasts and 95% prediction limits for $\ell = 1, ..., 20$ are shown in Figure 6.6 along with the original realization. \nAlthough Equation 6.43 furnishes a convenient method for computing forecasts, the general behavior of the forecasts can often be observed
