$Var(\hat{\rho}_k) = \frac{1}{n} \sum_{u=-\infty}^{\infty} {\rho_u^2 + \rho_{u+k}\rho_{u-k} - 4\rho_k\rho_{u-k} + 2\rho_u^2}. (1.20)$

当时间序列具有当 $k \to \infty$ 时 $\hat{\rho}_k \to 0$ 的属性时，对于“大”$k$，有：

$Cov(\hat{\rho}_k, \hat{\rho}_j) = \frac{1}{n} \sum_{u=-\infty}^{\infty} \rho_u\rho_{u+j-k}. (1.21)$

以及

$Var(\hat{\rho}_k) = \frac{1}{n} \sum_{u=-\infty}^{\infty} \rho_u^2. (1.22)$

Bartlett 近似在我们分析时间序列数据时将非常重要。在确定样本自相关系数何时显著异于零时，近似 $\hat{\rho}_k$ 的方差，方程 1.21 显示相邻样本自相关系数之间可能存在相关性。当我们进行时间序列分析并检查 $\hat{\rho}_k$ 图表时，这是一个需要记住的重要结果。

在第 1.3 节关于图 1.3 和 1.4 的讨论中，我们描述了自相关中的模式如何提供有关时间序列模型本质的信息。在图 1.9 中，我们展示了使用与图1.3 中实现相关的 $\hat{\rho}_v$ 所估计的样本自相关系数。这些样本自相关系数是图 1.4 中所示真实自相关系数的估计。可以看出，这些样本自相关近似了真实自相关系数，但应该注意 $\hat{\rho}_k$ 值之间的相关性。例如，注意 $\hat{\rho}_k$ 的值对于“接近”的 $k$ 倾向于低估 $\rho_k$，这也倾向于低估真实值。当 $\hat{\rho}_u$ 的图中存在这种行为时，这会在 $\hat{\rho}_k$ 的图中产生周期性行为。这在图 1.9a 和 d 中可见。还应该注意到，白噪声实现的样本自相关系数不会精确为零。在第 8.1 节中，我们将讨论白噪声检验，这将帮助你判断诸如图 1.9b 所示的样本自相关系数的幅度是否大于白噪声实现的预期值。

# 定义 1.9

如果 $p$ 是最小值，使得对于所有 $t$ 和整数 $k$，都有 $g(t) = g(t+kp)$，则函数 $g(t)$ 以周期（或周期长度）$p>0$ 为周期。如果不存在这样的 $p$，则称 $g(t)$ 为非周期。

显然，$g(t) = \cos(t)$ 是周期为 $2\pi$ 的周期（周期长度），$\cos(2\pi t)$ 是周期为 1 的周期，而 $\cos(2\pi ft)$ 的频率为 $1/f$。在我们的研究中，我们经常用频率来讨论周期行为。我们将使用的频率定义规定如下。

# 定义 1.10

频率（$f$）测量每个采样单位的周期或循环次数，即 $f=1/\text{周期}$。

如果数据是按每年、每月或每小时收集的，则采样单位分别为一年、一个月和一小时，相应的频率测量每年、每月和每小时的循环次数。在科学工程文献中，通常用赫兹（Hz）测量频率，即每秒循环数。

根据定义 1.9 之后的讨论，$\sin(t)$ 的频率为 $1/(2\pi)$，$\sin(2\pi t)$ 的频率为 1，而 $\sin(2\pi ft)$ 的频率为 $f$。这些事实在图 1.11 中说明。
