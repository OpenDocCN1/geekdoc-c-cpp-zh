# EXAMPLE 3.5: AUTOCORRELATIONS OF AN AR(1) MODEL

For the case of the AR(1) model $X_t - \phi_1 X_{t-1} = a_t$, the autocorrelation $\rho_k$ satisfies the equation

```
$$\rho_k - \phi_1\rho_{k-1} = 0, k > 0. \quad (3.50)$
```

Since there is only one root (and no repeated roots), we use Equation 3.49, and $\rho_k$ satisfies. $\rho_k = C_{r_1}^k, k > 0$ Also, for an AR(1) model, $r_1 = 1/\phi_1$, so this can be rewritten

```
$$\rho_k = C_1\phi_1^k, k > 0. \quad (3.51)$
```

Since $\rho_0 = 1$, it follows from Equation 3.50 that $\rho_1 - \phi_1\rho_0 = 0$. Thus, $\rho_1 = \phi_1$, and thus $C_1 = 1., so

```
$$\rho_k = C_1\phi_1^k, k \ge 0. \quad (3.52)$
```

Since $\rho_k = \rho_{k}$, the autocorrelation function for an AR(1) process satisfies $\rho_k = C_1\phi_1^k$ which is the result derived earlier in Equation 3.32.

NOTE: In general, for the $m$-order difference equation with no repeated roots, the values $C_1, ..., C_m$ are chosen in such a way that the starting values, $g_0, g_1, ..., g_{m-1}$ also satisfy Equation 3.46 although they do not satisfy Equation 3.44.
