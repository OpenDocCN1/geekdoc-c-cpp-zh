In practical situations, $\sigma_a^2$ (and the model coefficients) will not be known and must be estimated from the data. Thus, an approximate 95% prediction interval is given by

```
$\hat{X}_{t}(\ell) = 1.96\hat{\sigma}_{a} \sum_{k=0}^{(\ell-1)^{1/2}} \psi_{k}^2,$
```

where $\hat{\sigma}_a^2$ is

```
$\hat{\sigma}_{a}^2 = \frac{1}{n-p} \sum_{t=p+1}^{n} \hat{a}_{t}^2 = \frac{1}{3} \sum_{t=3}^{3} \hat{a}_{t}^2 = 0.7497,$
```

and $n=t_0=25$. The $\psi_s$ are the $\psi$-weights from the estimated model. The half width of the approximate 95% prediction interval for $\ell = 3$ is given by

```
$1.96\sigma_{a} \sum_{k=0}^{1/2} \psi_{k}^2 = 1.96\sqrt{0.7497}(1+0.7^2+0.24^2)^{1/2}$
$=2.11.$
```
