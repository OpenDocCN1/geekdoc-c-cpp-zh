# 11.7.1 Testing for Long Memory in the Fractional and FARMA Setting

Several authors have addressed the problem of testing for long memory of the fractional or FARMA type. These tests fall into two major categories: (a) tests developed to check for long runs above or below the mean and (b) tests based on estimates of $d$.

Tests for long-memory behavior (i.e., type (a) above) are often based on the classical R/S statistic introduced by Hurst (1951) given by

```
$$\tilde{Q}^N = \frac{	ilde{R}_N}{\hat{\sigma}}\nR_N = \max \sum_{t=1}^L (X_t - \bar{X}) - \min \sum_{t=1}^L (X_t - \bar{X})\n\n\hat{\sigma}^2 = \frac{1}{N} \sum_{t=1}^N (X_t - \bar{X})^2.$
```

Mandelbrot and Taqqu (1979) and Lo (1991) investigated the use of this statistic for long memory. Other variations such as the KPSS statistic

```
$KPSS = \frac{1}{N} \hat{\sigma}^2(q)N \sum_{j=1}^q \sum_{t=1}^j (X_t - \bar{X})^2$$
```

proposed by Kwiatkowski et al. (1992). Other variations have been proposed by Giritais et al. (2003a,b). Many of the test statistics are based on asymptotic properties or bootstrap methods. Hauser (1997) investigated tests using the Geweke Porter-Hudak (1983) estimates of $d$. See Xing (2015) who has summarized this work and has proposed a more powerful bootstrap-method.

# 11.7.2 Testing for Long Memory in the Gegenbauer Setting

By the majority of the work involving testing for long memory has focused on the fractional, that is, $f=0$, type-long-memory behavior. However, as we have discussed, long-memory behavior can occur at any frequency between 0 and 0.5 inclusive. Giritais et al. (2003a) applied R/S-type tests to test for Gegenbauer-type long memory with very little success. Specifically, the tests for long memory only worked when the Gegenbauer was very close to zero. This is not an unexpected finding since the R/S-type tests are looking for runs above and below the mean and are not designed to detect cyclic behavior. Xing (2015) has developed promising tests for Gegenbauer long memory that are based on detected slowly decaying cyclic behavior in sample autocorrelations.
