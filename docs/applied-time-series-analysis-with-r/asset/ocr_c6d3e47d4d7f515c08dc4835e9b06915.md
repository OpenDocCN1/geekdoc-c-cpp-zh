For additional discussion of conditional and unconditional ML estimation, see Priestley (1981).

Another similarity is to use $f(x_{t-p}, ..., x_{t-1}, ..., x_t)$ as the likelihood function and maximize

```
$l(\phi_1, ..., \phi_p, \theta_1, \sigma_a^2) = -\frac{n-p}{2} \ln(2\pi\sigma_a^2) - \frac{S}{2\sigma_a^2} \quad (7.40)$
```

The estimates obtained by maximizing Equation 7.40 are called the conditional ML estimates.

Estimation of $\sigma_a^2$: The ML estimate of $\sigma_a^2$ (based on maximizing either Equation 7.35 or Equation 7.37 can be obtained by differentiating $l(\phi, \theta, \sigma_a^2)$) with respect to $\sigma_a^2$, which yields (in case)

```
$\frac{\partial l}{\partial \sigma_a^2} = -\frac{n}{2\sigma_a^2} + \frac{S}{2\sigma_a^4} = 0$
```

where $S = S$ or $S_c$. Setting this partial derivative to zero and solving for $\sigma_a^2$ gives

```
$$\hat{\sigma}_a^2 = \frac{1}{n} \sum_{t=1}^n \hat{a}_t^2 \quad (7.41)$
```

the $\hat{a}_t$'s in Equation 7.41 denote the estimates obtained via backcasting. If backcasting is not used and the conditional sum of squares $\hat{S}_c = \sum_{t=p+1}^n \hat{a}_t^2$ is obtained (based on $\hat{a}_1 = \hat{a}_2 = ... = \hat{a}_p = 0$), then in this case, the conditional ML estimate of $\sigma_a^2$ is

```
$$\hat{\sigma}_a^2 = \frac{\hat{S}_c}{(n-p)} \quad (7.42)$
```

where $\hat{S}_c$, denotes the sum of squares function with conditional ML estimates inserted for $\phi_1, ..., \phi_p, \theta_1, ..., \theta_q$.
