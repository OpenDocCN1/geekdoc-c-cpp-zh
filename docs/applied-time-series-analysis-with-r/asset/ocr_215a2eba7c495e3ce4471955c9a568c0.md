# Definition 11.8

If $X_i$ is a causal, stationary, and invertible process satisfying

```
$$\phi(B) = \prod_{i=1}^{k} (1-2u_iB+B^2)^{\lambda_i}(X_t - \mu) = \theta(B)a_t \quad (11.20)$
```

where $\phi(z)$ and $	heta(z)$ share no common factors, then $X_i$ is a $k$-factor GARMA
process.

In Theorem 11.7 we give the stationary, long memory, and invertibility
conditions for a $k$-factor GARMA process.

# Theorem 11.7

+   1. $X$, in Equation 11.20 is causal, stationary, and invertible if $u_i$ and
$\lambda_i$ ($i=1,...,k$) satisfy the conditions in Theorem 11.5(1) and all the
roots of the equation $\phi(z)=0$ and $\theta(z)=0$ lie outside the unit circle.
2. The spectrum of a causal, stationary, and invertible $k$-factor GARMA
process is given by

```
$P(f) = \sigma_{\eta}^2 \frac{\theta(e^{i2\pi f})^2}{\phi(e^{i2\pi f})^2} \prod_{j=1}^{k}[4\cos(2\pi f - u_j)^2]^{\lambda_j}. \quad (11.21)$
```

+   3. A process $X$, satisfying the conditions in (1) is also long memory if
$\lambda_j>0$ for any $j=1,...,k$.

Proof: See Woodward et al. (1998) and Giraitis and Leipus (1995).
