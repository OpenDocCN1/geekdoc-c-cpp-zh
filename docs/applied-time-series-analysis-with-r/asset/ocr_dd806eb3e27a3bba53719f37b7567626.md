NOTE: The equation, $1 - 1.6z + 0.81z^2 = 0$, is the same form as that of a characteristic equation for a univariate ARMA(p,q) model. Consequently the roots (associated assessment concerning stationarity) can be obtained using factor.wge in tswge and entering 1.6, -0.81 as the coefficients.

A realization of length $n=75$ where the VAR(1) process in Equation 10.23 is shown in Figure 10.3 where it can be seen that the VAR(1) model can exhibit pseudo-cyclic behavior in the bivariate case. Using the fact that $\Gamma(0) - \Phi\Gamma(0)\Phi^* = \Gamma_z$, and solving for $\Gamma(0)$, it follows that

```
$\Gamma(0) = \begin{pmatrix} 27.74 & -0.40 \ -0.40 & 13.07 \end{pmatrix}$
```

This is consistent with Figure 10.3, where it can be seen that $X_{i1}$ (upper plot) has larger variance than $X_{i2}$ (lower plot). Using the property $\Gamma(k) = \Gamma(k-1)\Phi^k, k>0$, it can be shown that

```
$\Gamma(1) = \begin{pmatrix} 24.73 & -8.60 \ 7.48 & 9.27 \end{pmatrix}, \Gamma(2) = \begin{pmatrix} 17.09 & -13.34 \ 12.30 & 4.24 \end{pmatrix}, \dotsdots$$
```
