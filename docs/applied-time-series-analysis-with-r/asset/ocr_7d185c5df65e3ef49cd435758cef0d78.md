Note in this case, $v=p$, $w=1$, and $W_t=0$. This example illustrates the fact that the AR(1)-type form of the state equation does not place the limitations on the applicable settings that might be expected.
If $Y_t$ satisfies the zero-mean VAR(p) model $Y_t = \Phi_1 Y_{t-1} + \dots + \Phi_p Y_{t-p} + \mathbf{a}_t$, then a state-space formulation is obtained using the following equations

```
$X_t = \Phi X_{t-1} + V_t \quad \text{(state equation)},$
$Y_t = (0 \ 0 \dots 1)X_t \quad \text{(observation equation)},}$
```

where $X_t, \Phi$, and $V_t$ are the $p 	imes 1$, $p 	imes p$, and $p 	imes m$ matrices respectively, by:

```
$X_t = \begin{pmatrix} Y_{t-p+1} \ Y_{t-p+2} \ \vdots \ Y_t \end{pmatrix}, \quad \Phi = \begin{pmatrix} 0 & 0 & 0 & \dots & 0 \ 0 & 0 & I & \dots & 0 \ \vdots & \vdots & \vdots & \vdots & \vdots \ 0 & 0 & 0 & \dots & I \ \Phi_p & \Phi_{p-1} & \Phi_{p-2} & \dots & \Phi_1 \end{pmatrix}, \quad V_t = \begin{pmatrix} a_1 \ a_2 \ \vdots \ a_p \end{pmatrix}$
```
