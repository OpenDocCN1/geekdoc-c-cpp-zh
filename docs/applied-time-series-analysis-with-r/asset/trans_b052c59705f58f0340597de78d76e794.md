首先，我们讨论基于方程 10.18 给出的多变量 Yule-Walker 方程的多变量 Yule-Walker 估计。将 Yule-Walker 方程中的 $\Gamma(k)$ 替换为方程 10.11 中定义的 $\tilde{\Gamma}(k)$，即可得到样本多元 Yule-Walker 方程

```
$\tilde{\Gamma}(k) = \hat{\Gamma}(k-1)\hat{\Phi}_1^* + \dots + \tilde{\Gamma}(k-p)\hat{\Phi}_p^*, k=1, 2, \dots, p.$
```

与单变量情况一样，多元 Yule-Walker 估计始终产生平稳过程。

## 10.3.3.2 最小二乘法和条件极大然估计

VAR($p$) 过程参数的最小二乘估计可以通过将 VAR($p$) 模型表示为：

```
$X_t = \alpha + \sum_{i=1}^p \hat{\Phi}_i X_{t-i} + a_t
= \alpha + \hat{\Phi}_p^* X_t(p), \ t=p+1, \dots, n,$
```

其中，$X_t(p)$ 是给出的 $mp \times 1$ 矩阵

```
$X_t(p) = (X_{t-1}, \dots, X_{t-p})^*.$
```

方程 10.34 中的方程与单变量情况下的方程 7.12 类似。我们使用方程 10.10 给出的 $X$ 来估计 $\mu$，并分析零均值过程 $X_t-X$。在本节中，为了方便起见，我们将这个均值调整过程称为 $X_t^*$。因此，方程 10.35 中的模型没有常数项，即 $\alpha=0$，AR 参数的最小二乘估计位于 $mp \times m$ 矩阵中

```
$\hat{\mathbf{\Phi}}_{p)} = [\hat{\Phi}_1, \dots, \hat{\Phi}_p]
= (X')^{-1}X'X_t^*,$
```

其中 $X_{(ip)}$ 是一个 $(n-p) \times m$ 矩阵，其行 $(X_{t_1}, \dots, X_{t_m}), t=p+1, \dots, n,$，$X$ 是一个 $(n-p) \times p$ 矩阵，其行值为

```
$(X_{t-1}, \dots, X_{t-p}), t=p+1, \dots, n,$
```

其中 $X_{t-j} = (X_{t-j,1}, \dots, X_{t-j,m})$。

## 10.3.3.3 Burg 型估计

Nuttall (1976a,b) 和 Strand (1977) 通过考虑类似于方程 7.16 的多元后向模型以及前向模型，获得了 AR 参数的 Burg 型估计。另见 Jones (1978)。与单变量 Burg 估计一样，Burg 型 AR 估计始终产生平稳解。Marple 和 Nuttall (1983) 通过仿真结果表明，Burg 型（Nuttall-Strand）估计量具有比 Yule-Walker 估计量更好的性质。

## 10.3.4 计算残差并估计 $\Gamma_a$

与方程 9.2 类似，与估计的 VAR(p) 模型相关的残差由

```
$$\hat{\mathbf{a}}_t = \mathbf{X}_t - \sum_{j=1}^{p} \mathbf{\hat{\Phi}}_{t-j} - \hat{\mathbf{\alpha}}, \quad t=p+1,\dots,n.$$
```

$\hat{\Gamma}_a$ 的最小二乘估计量为

```
$$\hat{\Gamma}_a = \frac{1}{n-2p-1} \sum_{t=p+1}^{n} \hat{\mathbf{a}}_t \hat{\mathbf{a}}'_t.$$
```

条件极大然估计量为

```
$$\hat{\Gamma}_a = \frac{1}{n} \sum_{t=p+1}^{n} \hat{\mathbf{a}}_t \hat{\mathbf{a}}'_t.$$
```

使用第 7.4 节讨论的回溯程序扩展可用于获取 $t=1, \dots, n$ 的残差，并不可避免地提高估计 $\Gamma_a$ 的能力。

回想在正态性下，$\Phi_1, \dots, \Phi_p$ 的最小二乘估计和条件极大然估计是相同的。如果使用回溯计算 $\hat{\mathbf{a}}_1, \dots, \hat{\mathbf{a}}_p$，则无条件极大然估计量为

```
$$\hat{\Gamma}_a = \frac{1}{n} \sum_{t=1}^{n} \hat{\mathbf{a}}_t \hat{\mathbf{a}}'_t.$$
```

任何估计程序（例如 Burg 型估计、Yule-Walker 等）得到的残差都可以方程 10.39 得到 $\Gamma_a$ 的估计，每当使用回溯计算 $\hat{\mathbf{a}}_1, \dots, \hat{\mathbf{a}}_p$ 时。

## 10.3.6 对数据拟合 VAR($p$) 模型

下简要总结了对向量序列拟合 VAR($p$) 模型涉及的步骤。

### 10.3.6.1 模型选择

与单变量情况一样，拟拟合 VAR($p$) 模型的第一步是识别阶 $p$。AIC 的多元扩展（基于参数的极大然估计）给出

```
AIC = \ln|\hat{\Gamma}_a| + \frac{2mp}{n}$$
```

与单变量情况一样，可以使用方程 41 基于其他估计程序（例如 Burg 型估计）找到 AIC 的版本。模型选择为对于某个整数 $P$，在 $0 \le p \le P$ 的范围内获得 AIC 最小值。AIC 的多元替代方案如 BIC 和 AICC 也可用（见第 8 章）。

### 10.3.6.2 估计参数

一旦确定了阶 $p$，即可使用上述方法获得与选模型相关的参数 $\Phi_1, \dots, \Phi_p$ 和 $\mu$ 的估计。回想通常先估计 $\mu$，然后使用 $X_t-\hat{\mu}$ 估计剩余参数。将在将在使用此程序。

### 10.3.6.3 残差白噪声检验

第 9.1 节讨论的 Ljung-Box 检验已扩展到多元（见 Hosking, 1981）。假设你想测试多元时间序列 $Z$ 是否为白噪声。这里，$Z$ 可以是观测时间序列，也可以是基于数据拟合 VAR($p$) 的残差序列。$H_0: \rho(k)=0, k=1, \dots,$ 对 $H_a: \rho(k)\neq 0$（对于 1 到 $K$ 之间的某个 $k$）的检验基于统计量

```
$L = \sum_{k=1}^{K} \frac{k}{n-k} \text{tr}(\hat{\Gamma}(k)\hat{\Gamma}^{-1}(k)), \quad (10.42)$
```

$\hat{\Gamma}(k)$ 定义在方程 10.11 中，$\text{tr}[\mathbf{M}]$ 表示矩阵 $\mathbf{M}$ 的迹（即元素之和）。当数据为多元白噪声时，方程 10.42 中的统计量 $L$ 近似服从自由度为 $mK$ 的 $\chi^2$，如果计算出的 $L$ 足够大，我们拒绝 $H_0: \rho(k)=0$。当数据是拟合 VAR($p$) 过程的残差时，在 $H_0$ 下统计量近似服从自由度为 $m^2(K-p)$ 的 $\chi^2$。
