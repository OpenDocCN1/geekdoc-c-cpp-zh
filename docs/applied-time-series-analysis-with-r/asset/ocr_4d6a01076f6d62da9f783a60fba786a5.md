# G-Stationary Processes

c. trans.to.dual.wge(x,lambda,offset,plot) transforms the
time axis to create a dual process using linear interpolation.
x is an equally spaced TVF data set
lambda is the value of $\lambda$ in the $G(\lambda; p)$ model (default is lambda = 0,
cie, x is a realization from an M-stationary model)
offset is the offset parameter (see for example the discussion about
Figure 13.2) (default = 60)
plot = TRUE (dual) produces a plot of the dual realization created

The function outputs:
intX and intY: The input realization x is of length $n$, and the val-
us x are available at the time points $t=1, ..., n$. The values
intY $n$ interpolated values of the original time series at the
values of intX in the original time set. The dual data set
obtained by associating the $n$ values of intY with $t=1, ..., n
respectively.

h is an output value of the scaling parameter that assures that the
dual realization and the original realization are of the same
length.

> NOTE: trans.to.dual is based on $G(\lambda)$-stationary modeling.
M-stationary models are obtained by using $\lambda=0$.

Example: The command
data(fig13.2c)
y = trans.to.dual.wge(fig13.2c,lambda=-0.4,offset=63)
compute and in this plot the dual data shown in Figure 13.4b
saves the dual data in yintY using the $G(\lambda)$ transform-
sified by lambda and offset, which in this case were
obtained in Example 13.7.
