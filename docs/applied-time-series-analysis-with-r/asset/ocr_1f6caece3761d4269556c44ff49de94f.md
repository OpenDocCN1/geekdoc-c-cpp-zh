# Model Identification

p is the value of p in the selected ARMA(p,q) model
q is the value of q in the selected ARMA(p,q) model
phi is a vector containing the ML estimates of the p AR parameters
theta is a vector containing the ML estimates of the q MA parameters
vara is the white variance estimate for the selected model

NOTES:

+   1. ML parameter estimation is performed using base R function arima.
2. In order, for example, to choose the 'best' AR model, then use q=0:0.

Example: In Example 8.3a we used aic.we to identify the orders of the ARMA(p,q) model used to generate the data in Figure 3.18a (data set fig318a in tswge) allowing p to range from 0 to 8 and q range from 0 to 4. The following commands can be used:

```
data(fig318a)
aic.we(fig318a,p=0:4,q=0:4,type='aic')
```

Inspecting the output it can be seen that AIC correctly selects an AR(4) model. The output includes the AIC value (the minimum of all those calculated within the specified range of p and q), the selected p and q along with associated ML parameters estimates,

aic.we(x,p=min:max,q=min:max,type) is a function that finds the best ARMA(p,q) models within the p and q ranges in the call statement using the selection criterion specified by type. x is a vector containing the realization to be analyzed
p=min:max specifies the range of values for the AR order p to be used in the search for the best model (default is p=0:5)
q=min:max specifies the range of values for MA order q to be used in the search for the best model (default is q=0:2)
type specifies the criterion used to select the model. Choices are type="aic", "bic", or "aicc". (default is "aic")

The program outputs the model orders of the top five models (and associated criterion values) within the range of p and q specified in the function statement.

NOTES:

+   1. ML parameter estimation is performed using base R function arima and tswge function aic.we.
