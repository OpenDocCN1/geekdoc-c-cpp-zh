# 3.3.6 Approximating ARMA$(p,q)$ Processes Using High-Order AR(p) Models

We have discussed the fact that the stationary and invertible ARMA$(p,q)$ model $\phi(B)X_t = \theta(B)a$, can be written as the infinite-order AR process $\theta^{-1}(B)\phi(B)X_t$. Thus, an ARMA$(p,q)$ model can be well approximated using a high-order AR(p) model. For this reason, time series analysts use the approach of fitting AR models to data since parameter estimation and model identification to be more difficult when MA parameters are included in the model. On the other hand, some analysts prefer the ARMA$(p,q)$ model since it contains fewer parameters (is more parsimonious) than an AR model fit to the data set. In this text, we will cover parameter estimation, forecasting, etc., in the generality provided by the ARMA$(p,q)$ model. In practice, we will often restrict ourselves to AR(p) models.

An example of this trade-off between parsimonious ARMA$(p,q)$ model and a high-order AR(p) model is illustrated in Example 4.1, where theoretical justification is used to show that ARMA$(2,2)$ model is a good approximation for harmonic signal-plus-noise data. However, in that example, we also show that an AR(7) model also works as well as an approximating model.
