Granger and Joyeux (1980), Hosking (1981, 1984), and Geweke and
Porter-Hudak (1983) proposed the fractional difference model defined in
Definition 11.3.

# Definition 11.3

If $\sum_{k=0}^{\infty} (|\Gamma(k+d)| / |\Gamma(d)|) < \infty$, then the general linear process defined by

```
$X_t - \mu = (1-B)^{-d}a_t$$
$$\sum_{k=0}^{\infty} \frac{\Gamma(k+d)}{\Gamma(d)k!}a_{t-k}, \quad t=0, \pm1, \pm2, ... \quad (11.4)$
```

where $a_t$ is white noise, is called a fractional process. If $X$ is invertible, then the
fractional model is written

```
$(1-B)^d(X_t - \mu) = a_t. \quad (11.5)$
```

We typically express the fractional model in the form given in Equation
11.5. Theorem 11.1 gives basic properties of the fractional model including
conditions for stationarity and invertibility.

# Theorem 11.1

Let $X$, be a fractional process of the form Equation 11.4.

+   1. If $d < 0.5$, then $X$ is causal and stationary
2. If $d > -0.5$, then $X$ is invertible
3. The spectral density of $X$, is given by $S(f) = [4[sin \pi f]^2]-d$,
0 < f \leq 0.5$ and $\lim_{f\to0} f^{2d}S(f)$ exists and is finite
4. If $d \in (-0.5, 0.5)$, the autocorrelation function is given by

```
$\rho_k = \frac{\Gamma(-d+1)\Gamma(k+d)}{\Gamma(d)\Gamma(k-d+1)}, \quad k=0, \pm1, ...$
```

and $ho_k \approx k^{2d-1}$ as $k \to \infty$, $\sigma_X^2 = \Gamma(-2d+1)/\Gamma(-d+1)]$
5. If $0 < d < 0.5$ then $X$, is long memory

Proof: See Hosking (1981). The long-memory result in (5) follows from
using Definition 11.1 and from (3) using Definition 11.2.
