# 示例 1.4：非遍历过程

作为非遍历过程的一个假设性示例，考虑一个会产生次品的线制造过程。在每天结束时对机器进行清洗和调整，直径保持不变直到第二天结束，届时再次清洗。直径设置可以被看是一个随机过程，每一天是一个实现。在图 1.7 中，我们展示了该假设性过程 $X(t)$ 的三个实现值。

$\mu$ 是跨天的平均直径，那么显然 $\gamma(t, t+h)$ 在一天之内不依赖于 $t$。同样清楚，对于所有 $h$，$\gamma(t, h) = \gamma(0) < \infty$。因此，该过程是平稳的。然而，试图通过 $\bar{X}_t$（即对单个实现的时间轴取平均）来估计 $\mu$ 显然没有意义。从启发角度来看，可以通过平均多个实现来估计 $\mu$，但本质上使用一个实现只提供了一条信息。显然，在这种情况下，$X_t$ 对于 $\mu$ 不是遍历的。

```
$\bar{X}-1.96 \sum_{k=(n-1)}^{n-1} \left(1 - \frac{|k|}{n}\right) \hat{\rho}_k, \bar{X}+1.96 \sum_{k=(n-1)}^{n-1} \left(1 - \frac{|k|}{n}\right) \hat{\rho}_k. \quad (1.17)$
```

## 1.4.2 $\gamma_k$ 的估计

由于平稳性，$E[(X_t-\mu)(X_{t+k}-\mu)]gamma_k$ 不依赖于 $t$。因此，通过单实现估计 $\gamma_k$ 似乎是合理的：

```
$\hat{\gamma}_k = \frac{1}{n-|k|} \sum_{t=1}^{n-|k|} (X_t-\bar{X})(X_{t+k}-\bar{X}), \quad k=0, \pm1, \dots, \pm(n-1), |k| \geq n. \quad (18)$
```

即通过移动时间轴并找到间隔 $k$ 个单位的平均值。注意，如果我们将方程 18 中的 $\bar{X}$ 替换为 $\mu$，则得到的估计是无偏的。然而，方程 18 中的估计量 $\hat{\gamma}_k$ 仅是渐近无偏。尽管 $\hat{\gamma}_k$ 在直觉上有吸引力，但大多数序列分析师使用另一种估计量 $\tilde{\gamma}_k$，其定义为：

```
$\tilde{\gamma}_k = \frac{1}{n-|k|} \sum_{t=1}^{n-|k|} (X_t-\bar{X})(X_{t+k}-\bar{X}), \quad k=0, \pm1, \dots, \pm(n-1), |k| \geq n. \quad (19)$
```

通过检查方程 19 清楚，当 $|k|$ 相对于 $n$ 很大时，$|\tilde{\gamma}_k|$ 的值将趋于“小”。方程 19 给出的估计量 $\hat{\gamma}_k$ 在大多数情况下比 $\tilde{\gamma}_k$ 有更大的偏差，但均方误差更小。当 $|k|$ 对于 $n$ 很大时，这两个估计之间的差异最为显著。当将方程 18 和 19 中的 $\bar{X}$ 替换为 $\mu$ 时，可以进行比较。在这种情况下，$\hat{\gamma}_k$ 的偏差可见为 $(|k|/n)\gamma_k$。随着 $|k|$ 趋于 $n$，$|k|/n$ 因子趋于一，因此偏差趋于 $\gamma_k$。随着 $|k|$ 趋于 $n-1$，$\text{Var}(\hat{\gamma}_k)$ 将增大，$\hat{\gamma}_k$ 的值将表现出非常不稳定的行为。$\hat{\gamma}_k$ 的整体模式通常由 $\hat{\gamma}_k$ 优于 $\tilde{\gamma}_k$，我们将看到自相关函数的*模式*才是重要的。$\hat{\gamma}_k$ 的行为也由 $\tilde{\gamma}_k$ 更好地近似，其中 $\tilde{\gamma}_k$ 在节 1.3 给出的性质 (4) 下是正定的，而 $\hat{\gamma}_k$ 则一定。关于这些主题的进一步讨论，请参考 Priestley (1981)。

## 1.4.3 $\rho_k$ 的估计

$\rho_k = \gamma_k/\gamma_0$ 的自然估计是 $\hat{\rho}_k = \tilde{\gamma}_k/\tilde{\gamma}_0$，我们将其称为样本自相关函数。估计量 $\hat{\rho}$ 具有 $|\hat{\rho}| \le 1$ 的良好性质， $\tilde{\rho}_k = \tilde{\gamma}_k/\tilde{\gamma}_0$ 不具备这一性质。这一性质可以通过将 $\hat{\rho}$ 与两组数据之间的皮尔逊矩相关相关来证明：

```
0,0,...,0, X_1-\tilde{X}_1, X_2-\tilde{X}_2, ..., X_n-\tilde{X}_n,
X_1-\tilde{X}_1, X_2-\tilde{X}_2, ..., X_n-\tilde{X}_n, 0,0,...,0,
```

其中在每种情况下都有零。为了符号表示方便，我们将第一行标记为 $V_\rho$ $i=1, ..., n+k$，第二行标记为 $W_\rho$ $i=1, ..., n+k$。因此，$\tilde{V} = \tilde{W} = 0$，$V$ 和 $W$ 之间的乘矩相关给出：

```
$r = \frac{\sum_{i=1}^{n+k} V_i W_i}{\sqrt{\sum_{i=1}^{n+k} V_i^2 \sum_{i=1}^{n+k} W_i^2}}$
```

分母可以重写为 $\sum_{t=1}^n (X_t-\tilde{X}_t)^2$，而分子可以写为

```
$\sum_{t=1}^n (X_t-\tilde{X}_t)(X_{t+k}-\tilde{X}_{t+k}).$
```

因此 $r = \hat{\rho}_k$，所以 $|\hat{\rho}_k| \le 1$。
