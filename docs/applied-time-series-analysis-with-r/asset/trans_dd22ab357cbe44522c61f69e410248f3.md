## 3 ARMA 时间序列模型

在本章中，我们将讨论用于描述时间序列行为的一些重要模型。特别感兴趣的是 AR、MA 和 ARMA 模型。这些模型由 George Box 和 Gwilym Jenkins 在其经典时间序列书籍中推广，最新版为 Box et al. (2008)。这些模型已成为时间序列理论和应用的基础。虽然本章考察了基于真实数据的若干示例，但我们大量使用模拟实现以了解已知模型的性质并加深理解。此外，除非另有说明，本章中图示的自相关和谱密度均为所研究模型的理论量。在后面的章节中，我们将利用本章学到的经验来分析实际时间序列。

### 3.1 MA 过程

我们首先定义阶数为 $q$ 的 MA 过程，记为 $MA(q)$。

定义 3.1

设 $a_t$ 为零均值、有限方差 $\sigma_a^2$ 的白噪声过程，且过程 $X_t, t=0, \pm1, \pm2, ...$ 由

```
$X_t - \mu = a_t - \theta_1 a_{t-1} - \dots - \theta_q a_{t-q},$$
```

定义，其中 $\theta_j, j = 1, ..., q$ 为实常数且 $\theta_j \neq 0$。由方程 3.1 定义的过程 $X$ 称为阶数为 $q$ 的 MA 过程，通常简写为 $MA(q)$。

我们经常将方程 3.1 写成

```
$X_t - \mu = \theta(B)a_t,$$
```

的形式，其中

```
$\theta(B) = 1 - \theta_1 B - \theta_2 B^2 - \dots - \theta_q B^q.$
```

注意：在继续之前，我们指出有些作者和软件包编写者将方程 3.1 写成 $X_i-\mu = a_i + \theta_{i-1} + \dots + \theta_{i-q}$。考虑 MA(2) 模型 $X_i = a_i - 1.2a_{i-1} + 0.8a_{i-2}$。使用方程 3.1 中的定义可得 $\theta_1 = 1$ 且 $\theta_2 = -0.8$，而使用替代表示法系数将为 $\theta_1 = -1.2$ 且 $\theta_2 = 0.8$。在将系数输入时间序列计算机包或比较不同教科书中涉及 $\theta$ 的公式之前，务必非常仔细地检查 MA(q) 定义。

注意 MA(q) 过程是一个具有有限项的一般线性过程。特别地
