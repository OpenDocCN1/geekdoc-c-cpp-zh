# ## Appendix 3B: R Basic Computation and Plot Routines for Chapter 3

# ### 3.1 Basic Computation

+   - gen.arma.wge(n,phi,theta,vara,plot,sn) generates a realization of length n from a stationary AR, MA, or ARMA model.
- n is the realization length ($xt, t=1, \dots, n$). Note that the generated data are based on zero mean. If xt is the time series generated by gen.arma.wge, then to convert to a time series with mean $\mu=10$, simply compute yt = xt + 10
- phi is a vector of AR parameters (default is phi=0)
- theta is a vector of MA parameters (using signs as in this text) (default is theta=0)
- vara is the white noise variance (default=1)
- plot = TRUE (default) produces a plot of the realization generated
- sn determines the seed used in the simulation (see Note (6) below).
