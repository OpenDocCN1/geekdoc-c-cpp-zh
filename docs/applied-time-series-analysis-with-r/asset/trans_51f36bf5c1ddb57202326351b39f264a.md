
$a_j^2 + b_j^2$ 的值表示数据中在 $f_j = j/n$ 处或附近的频率行为。等式 1A.4 与另外两种形式相等的证明留作问题 1.20。

当 $n=2m$ 为偶数时，之前推导出的公式略有不同。具体而言，$a_j$ 和 $b_j$ 的公式适用于 $j=1,\dots,m-1$。然而，

```
$a_m = \sum_{t=1}^n (-1)^t x_t, b_m = 0,$ and $l(f_m) = na_m^2$.
```

## 附录 1B: R 命令

如序言提到的，您应该安装并加载 R 命令库 `tswage`。这里列出的某些命令仅为不需要安装特殊库的 R 命令。这些将被标记为 Base R 命令。执行计算并绘制与第 1 章涵盖的主题相关的结果的命令分为两类：

- 1. 基础计算与绘图
- 2. “组合例程”，出于教学目的提供相关图表的图形化输出

例如，`plot.sample.wege` 绘制了实现值、样本自相关图、周期图以及通过 Parzen 窗口平滑的周期图。检查这四张图是理解时间序列实现特征的典型步骤。

- 1. 第 1 章基础计算例程
- `mean(x)` (base R 函数)：计算时间序列实现的的平均值，其中 x 是一个包含时间序列实现 $x_t, t=1,\dots,n$ 的向量。
示例：基础 R 命令
`data(ss08); ssm = mean(ss08)`
计算 `tswage` 数据集 ss08 中太阳黑子数据的样本平均值，并将其放在变量 ssm 中。在这种情况下，$ssm = 52.24385$。
- `tswage` R 函数
`plots.wege(x)`
提供了对基础 R 绘图命令的简化使用，其中 x, t = 1, ..., n。如需更多灵活性请使用基础 R 绘图命令。

示例：`data(airline); airlog = log(airline); plots.wge (airlog)` 绘制图 1.25a 所示的对数航空数据。

- `acf(x, lag.max, type, plot)` (base R 函数)：计算（并可选地绘制）时间序列实现的样本自相关（或样本协方差和样本方差），其中 x 是一个包含时间序列实现 t = 1, ..., n 的向量。lag.max 是计算样本自相关（或协方差）的最大滞后阶。type="correlation"（默认）产生样本自相关，"covariance" 指定自协方差，而 "partial" 表示部分自相关（在第 8 章中讨论）。

plot 是一个逻辑变量。plot = "TRUE" 产生样本自相关（或自协方差）的图表。示例：`data(hadley); tempaut = acf(x = hadley, lag.max = 25)` 计算并绘制 hadley 中全球温度数据的前 25 个样本自相关，如图 1.2a 所示。样本自相关被放在向量 $acf[1]$ 中（该向量包含 26 个元素，计数 tempaut$acf[1] = 1$，即滞后为 0 的样本自相关）。如果选择 type = "covariance"，则向量$acf 包含样本自协方差，且 tempaut$acf[1] 包含样本方差（使用除因子）。

- `wge(x, dbcalc, plot)` (twge 函数) 计算并替代绘制周期图。x 是一个包含时间序列实现 x, t = 1, ..., n 的向量。dbcalc 是一个逻辑变量。dbcalc="TRUE"（默认）在对数尺度上（以 dB，即 10*log10）计算周期图。plot 是一个逻辑变量。plot = "TRUE" 产生周期图（取决于 dbcalc，显示为对数尺度或非对数尺度）。

示例：`data(ss08) per = period(ss08)` 计算并绘制周期图（单位为 dB）。向量 per$freq 和 per$pgram 包含频率和相关的周期图值（对数或非对数）。

- `parzen.wge(x, dbcalc, trunc, plot)` (tswave R 函数) 计算并替代绘制基于 Parzen 窗口的平滑周期图。

x 是一个包含时间序列关系 x, t = 1, ..., n 的向量。
dbcalc 是一个逻辑变量。dbcalc = "TRUE"（默认）在对数尺度（dB）上计算平滑谱估计量。
trunc（整数≥0）指定截断点。
trunc = 0（默认或未指定 trunc 值）表示默认截断点为 M=2\sqrt{n}。
trunc > 0 是用户指定的截断点，即计算将在 M=trunc 处。

plot 是一个逻辑变量。plot = "TRUE"（默认）产生平滑谱估计量的图（取决于 dbcalc，显示为对数尺度或非对数尺度）。

示例：

```
data(ss08) <- sparz:parzen.wge(ss08)
```
使用默认截断点 M=2\sqrt{26}=32 对太阳黑子数据计算并绘制平滑谱估计量（单位为 dB）。向量 ssparz$freq 和 ssparz$pgram 包含频率和相关的基于 Parzen 的谱估计。
