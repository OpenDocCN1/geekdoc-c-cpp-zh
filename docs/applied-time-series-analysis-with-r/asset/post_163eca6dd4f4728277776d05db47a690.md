- c. gen.garma.wge(n,u,lambda,phi,theta,trun,burnin,var,sn) is a function that generates (and optionally plots) a realization of length $n$ from a given GARMA or Gegenbauer model. We recommend using fracdiff.sim from the fracdiff CRAN package for generating realization from a FARMA or frac-model. See Note 1.

n is the length ($t=1,...,n$)
u and lambda are the parameters of the Gegenbauer factor in Equation 11.16.

phi is a vector of the AR parameters (default $\phi = 0$)
theta is a vector of MA parameters (using signs as in this text) (default = 0)

trun is the truncation point of the infinite GLP form (default=300,000)
burn is in the burning-in period (default = 600)
vara is the white noise variance (default = 1)
plot = TRUE produces a plot of the realization generated.
sn determines the seed used in the simulation. (See Note 4 below)
The output is the generated realization.

NOTES:

- 1. While fractional and FARMA models can be generated using gen.garma.wge, we recommend using fracdiff.sim in the CRAN package fracdiff. For example, to generate a realization of length $n = 500$ from the model $(1 + .5B^2)(1–B)^{45} X_t = (1 +.8B)$, you could use the statement `fgen = fracdiff.sim(n = 500, sr = c(0,-5),ma = -.8,d=.45)`. See the fracdiff documentation for more details.
- 2. It will be useful to call the utility function mult.wge if you know the factors of the AR or MA parts of the model instead of the coefficients.
- 3. By the default white noise is zero mean, normal noise with variance vara = 1.
- 4. sn=0 (default) produces results based on a randomly selected seed. If you want to reproduce the same realization on subsequent runs of gen.garma.wge then set sn to the same positive integer value on each run.

Example: The `x=gen.garma.wge(n=30,u=0.8,lambda=0.35,phi=.8)` generates and plots a realization from the model $(1-0.8B) (1-2.8B+B^2))X, a=a$, and stores it in the vector xss$data. The white noise was normally distributed with mean zero and since defaults were used, there are no MA parameters, the white noise variance is 1, a random seed is used, and the realization will be plotted.

- d. est.farma.wge(x,low.d,high.d,inc.d,p.max,nback) is a function that obtains estimates of a FARMA(p,d,q) model (with $q=0$) using the grid-search algorithm described in Section 11.5.

low.d is the vector of lower boundaries of $d$'s in the grid search
high.d is the vector of upper boundaries of $d$'s in the grid search
inc.d is the increment for $d$ in the grid search
p.max is the maximum AR order
nback is the number of observations.

The output:
d (the estimate of $d$)
phi (the estimates of $\phi$)
vara (the white noise variance)

NOTES:

- 1. We assume $q=0$, that is, there are no MA parameters.
- 2. For other functions, see 11.5.

Example: We use `est.farma.wge(x,low.d,high.d,inc.d,p.max,nback)` to estimate the parameters of the FARMA model. The statement `test=est.farma.wge(Nile,low.d=.2,high.d=.95,inc.d=.05,p.max=3,nback=10)` performs the calculations using the grid search described in 11.5.
