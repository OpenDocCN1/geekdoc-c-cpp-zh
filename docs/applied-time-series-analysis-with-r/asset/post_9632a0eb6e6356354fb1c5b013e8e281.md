NOTES: In the remainder of this section, we will assume without loss of generality that the mean $\mu = 0$. It should be noted that if $u = 1$ then

```
$$(1-B)^{2\lambda}X_t = a_t.$$
```

That is, $X_t$ is a fractional process of order $2\lambda$. If $u = -1$ then Equation 11.12 becomes

```
$$(1+B)^{2\lambda}X_t = a_t.$$
```

Theorem 11.4 gives the stationarity, long memory, and invertibility conditions for the Gegenbauer process.

# Theorem 11.4

Let $X_t$ be a Gegenbauer process of the form Equation 11.11.

1. $|u| < 1$ and $\lambda < 1/2$ or if $u = \pm1$ and $\lambda < 1/4$, then $X$ is causal and stationary
2. $|u| < 1$ and $\lambda > -1/2$ or if $u = \pm1$ and $\lambda > -1/4$, then $X$ is invertible
3. The spectrum of a stationary and invertible Gegenbauer process is given by

```
$$P(f) = \sigma_{\lambda}^2 |1-2u\exp(2\pi f)+\exp(4\pi f)|^{-2\lambda} = \sigma_{\lambda}^2[4(\cos(2\pi f)-u)^2]^{-\lambda}.$$
```

The frequency $f_c = (\cos^{-1}u)/(2\pi)$ is referred to as the Gegenbauer frequency (G-frequency).

4. $0 < \lambda < 1/2$ and $|u| < 1$ or if $|u| = 0$ and $\lambda < 1/4$, then $X$ is long memory
5. The autocorrelations of a stationary and invertible Gegenbauer process, $X_u$, are given in the following:

a. If $u = 0$ and $0 < \lambda < 1/4$, the autocorrelation function of $X_t$ is

```
$$\rho_k = \frac{\Gamma(1-2\lambda)(k+2\lambda)}{\Gamma(2\lambda)\Gamma(k-2\lambda+1)}.$$
```

Thus $\rho_k \simeq k^{4\lambda-1}$ as $k \to \infty$. Also,

```
$$\sigma_{\lambda}^2 = \frac{\Gamma(-4\lambda+1)}{\Gamma(-2\lambda+1)^2}.$$
```

# Long-Memory Processes

b. If $u = -1$ and $0 < \lambda < 1/4$, the autocorrelation function of $X_i$ is:
$$\rho_k = (-1)^k \frac{\Gamma(1-2\lambda)\Gamma(k+2\lambda)}{\Gamma(2\lambda)\Gamma(k-2\lambda)}$$

Thus $\rho_k \approx (-1)^k k^{4\lambda-1}$ as $k \to \infty$, Also,
$$\sigma_u^2 = \frac{\Gamma(-2\lambda+1)}{(\Gamma(-2\lambda+1))^2}$$

c. If $|u| < 1$ and $0 < \lambda < 1/2$, then $\rho_k \approx k^{2\lambda-1} \cos(2\pi f_G)$, as $k \to \infty$ where $f_G$ is the G-frequency defined in (3). Also, $\sigma_u^2 = \sum_{j=-\infty}^{\infty}[C^{(\lambda)}(u)]^2\sigma_j^2$.

Proof: See Gray et al. (1989, 1994) and Appel (1986). Note that (4) follows from the fact that the spectrum in Equation 11.15 is unbounded at the G-frequency, $f_G$.

As a result of Theorem 11.4, for a stationary, long-memory Gegenbauer process, it follows that $\rho_k \approx k^{2\lambda-1} \cos(2\pi f_G)$ as $k \to \infty$, and the spectrum is unbounded at $f_G$ where $f_G \in [0, 0.5]$. When $u=1$, it can be shown using half-angle formulas that the spectral process defined in Equation 11.15 simplifies to Theorem 11.1(3). That is, when $u=1$, the spectrum in Equation 11.15 has an infinite peak at $f=0$.

Figure 11.6 (originally given by Gray et al., 1989) shows the stationary long-memory region (range of $u$ and $\lambda$) for the Gegenbauer processes. The stationary long-memory region for $u$ and $\lambda$ is the shaded region ($0 < \lambda < 0.5$ and $|u| < 1$) along the solid horizontal borders ($u=\pm1$ and $0 < \lambda < 0.25$). The spectral process is represented by the solid horizontal line segment at the top of the rectangle. This figure illustrates that the Gegenbauer represents a considerable generalization of the process. As $u$ and $\lambda$ move along a path that approaches a dashed boundary of the rectangle, the corresponding Gegenbauer processes approach nonstationarity. For example, if $u$ is held constant at $\lambda=0.4$, then as $u$ approaches 1 from below, the processes associated with these $u$ and $\lambda$ values will increasingly display "near-nonstationarity." While $u$ determines the G-frequency, it also affects the degree of "stationarity."

# 11.3.3 GARMA Process

In the same manner that the fractional process has been extended to FARMA process, Definition 11.6 follows the Gegenbauer process by combining it with ARMA process.

# Definition 11.6

If $X_i$ is a causal, stationary, and invertible process satisfying

```
$$\phi(B)(1-2uB+B^2)^\lambda(X_i-\mu) = \theta(B)a_i, \quad (11.6)$$
```

where $\phi(z)$ and $\theta(z)$ share no common factors, then $X_i$ is a Gegenbauer ARMA (GARMA) process which will be denoted GARMA$(p, \lambda, u, q)$. Theorem 11.5 summarizes the properties of the GARMA process.

# Theorem 11.5

Let $X$ be a GARMA process $(\lambda \neq 0)$ and let all roots of $\phi(z)=0$ and $\theta(z)=0$ lie outside the unit circle. Then we have the following:

1. $X_i$ is stationary if $\lambda < 1/4$ when $u = \pm1$ or $\lambda < 1/2$ when $|u| < 1$.
2. $X_i$ is invertible if $\lambda > -1/4$ when $u = \pm1$ or $\lambda > -1/2$ when $|u| < 1$.
3. The spectrum is given by

```
$P(f) = \sigma_\eta^2 \left| \frac{\theta(e^{-2\pi f})^2}{\phi(e^{-2\pi f})^2} \right|^{1-2u\exp(-2\pi f)+\exp(-4\pi f))^{-\lambda}}$
= \sigma_\eta^2 \left| \frac{\theta(e^{-2\pi f})^2}{\phi(e^{-2\pi f})^2} \right|^2 [4(\cos(2\pi f)-\cos(2\pi f_G))^2]^{-\lambda}$.
```

4. $X_i$ is long memory if $\lambda < 1/4$ when $u = \pm1$ and $0 < \lambda < 1/2$ when $|u| < 1$.
5. As $k \to \infty$,
a. $\rho_k \simeq k^{4\lambda-1}$ when $u = 1$ and $0 < \lambda < 1/4$
b. $\rho_k \simeq (-1)^k k^{4\lambda-1}$ when $u = -1$ and $0 < \lambda < 1/4$
c. $\rho_k \simeq k^{2\lambda-1} \cos(2\pi f_G)$ when $|u| < 1$ and $0 < \lambda < 1/4$.

Proof: See Gray et al. (1989, 1994).
