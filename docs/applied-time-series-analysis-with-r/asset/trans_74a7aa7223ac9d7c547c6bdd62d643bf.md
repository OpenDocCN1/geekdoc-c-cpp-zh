## 1.4 平稳时间序列均值、自协方差和自相关性的估计

如前所述，时间序列分析的一个共同目标是根据单一实现获取有关时间序列的信息。在本节中，我们将讨论如何从单一实现估计 $\gamma(h)$ 和 $\rho(h)$。我们的重点是离散参数时间序列，其中 $T = \{..., -2, -1, 0, 1, 2, ...\}$，在这种情况下通常观测到有限长度的实现 $t = 1, 2, ..., n$。与给出的这些连续参数时间序列也是类似的，将在示例中简要提及。更一般的结果请参阅 Parzen (1962)。

### 1.4.1 $\mu$ 的估计

给定平稳时间序列的实现 $[x_t, t = 1, 2, ... , n]$，共同值 $\mu$ 的自然估计是样本均值

$$\bar{X} = \frac{1}{n} \sum_{t=1}^{n} X_t. \quad (1.4)$$

显然，估计量 $\bar{X}$ 对 $\mu$ 是无偏的。

### 1.4.1.1 $\bar{X}$ 的遍历性性

如果随着 $n$ 的增加，$\bar{X}$ 以均方意义收敛于 $\mu$，我们称 $\bar{X}$ 对 $\mu$ 是平稳的，即 $\lim_{n\to\infty} E[(\bar{X}-\mu)^2] = 0$。

## 定理 1.2

假设 $\{X_t; t = 0, \pm1, \pm2, ...\}$ 是平稳时间序列。那么，$\bar{X} = \frac{1}{n} \sum_{t=1}^{n} X_t$ 对 $\mu$ 是平稳的，当且仅当

$$\lim_{k\to\infty} \frac{1}{k} \sum_{t=0}^{k-1} \gamma_t = 0. \quad (1.5)$$

定理 1.2 的证明请参阅 Yaglom (1962)。我们还有以下推论。

## 推论 1.1

设 $X_t$ 为定理 1.2 中的的离散参数平稳时间序列。那么，$X$ 对 $\mu$ 是平稳的，如果

$$\lim_{k\to\infty} \gamma_k = 0, \quad (1.6)$$

## 示例 1.2：一个遍历过程

考虑由 $X_t, t=0, \pm1, \pm2,$ ... 定义的过程

$X_t = 0.8X_{t-1} + a_t. \quad (1.8)$

$a_t$ 是均值为零、方差为 $\sigma_a^2$ 的离散白噪声。换句话之，方程 1.8 是一个“回归类型”模型，其中 $X$（因变量）是 $X_t$（自变量）的 0.8 倍加上一个不相关的“噪声”。注意对于 $k>0$，$X_t$ 和 $a_k$ 是不相关的。方程 1.8 中的过程是阶阶自回归过程的例子，称为 AR(1)，将在第 3 章中详细检查。我们将在该章中证明方程 1.8 所定义的 $X_t$ 是一个平稳过程。通过对方程 1.8 两边取期望，并回想起 $a_t$ 的均值为零，得到

$E[X_t] = 0.8E[X_{t-1}]. \quad (1.9)$

由于 $X$ 是平稳的，得到 $E[X_t] = E[X_{t-1}] = \mu$。现在，方程 1.9 意味着 $\mu = 0.8\mu$，即 $\mu = 0$。令 $k>0$，通过将方程 1.8 中的 $E[X_t, a_k] = E[X_t]$ 的每一项乘以 $X_{t-k}$ 并取这些期望，得到

$E[X_t, a_k] = 0.8E[X_{t-1}, X_{t-k}] + E[a_t, X_{t-k}]. \quad (10)$

由于 $E[X_{t-1}, a_k] = 0$，方程 11简化为 $\gamma_k = 0.8\gamma_{k-1}$，意味着 $\gamma_k = (0.8)^k$ 且 $\rho_k = 0.8^k$。因此，根据推论 1.1，$\tilde{X}$ 对 $\mu$ 是遍历的（1.8）。见第 3.2 节。

假设 $\varphi(1) = \varphi(2) = 0$。从方程 1.2 显然：

a. $E[\cos Y] = E[\sin Y] = 0$
b. $E[\cos 2Y] = E[\sin 2Y] = 0$

从方程 13 看出，a) 意味着 $E[X(t)] = 0$。此外，对方程 14 中的 $X(t)X(t+h)$ 取期望，看到 (b) 意味着

$\gamma(h) = E[X(t)X(t+h)] = \frac{C^2}{2}\cos(\lambda h),$

它依赖于 $h$ 而依赖于 $t$。此外，$\sigma_X^2 = \gamma(0) = (C^2/2) < \infty$。因此，$X(t)$ 是协方平稳的。

假设 $X(t)$ 是协方平稳的。那么，由于 $E[X(t)]$ 不依赖于 $t$，从方程 13 得到 $E[\cos Y] = E[\sin Y] = 0$，因此 $\varphi(1) = 0$。同样，$E[X(t)X(t+h)]$ 依赖于 $h$ 而依赖于 $t$，从方程 14 的最后一个方程得到 $E[\cos 2Y] = E[\sin 2Y] = 0$，即 $\varphi(2) = 0$。那么，如果 $Y$ 服从均匀分布 $[0, 2\pi]$，则

$$\varphi(u) = \int_0^{2\pi} e^{iu} \frac{1}{2\pi} dy = \frac{e^{2\pi iu}-1}{2\pi iu},$$
