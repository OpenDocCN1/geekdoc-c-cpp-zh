The realizations in Figure 3.10 were each generated with σ_z²=1 and using the same seed for the random number generator, so that differences among the realizations are due to the differing autocorrelation functions and variances. It is noticed that the existence of the second real root strengthens the behavior seen in Figures 3.4a and 3.5a for the AR(1) model. For example, as λ increases, the autocorrelation functions damp more slowly, and therefore the realizations have more pronounced on the vertical axis and a resulting higher variance. The process standard deviations are σ_z=3.2, 10.0, 26.3, and 45.3, respectively, and if we consider X as “signal” and a as “noise,” the signal-to-noise ratio, σ_z/σ_a increases as λ increases. Also note that when λ=0.95, the model has repeated roots. (The data set in Figure 3.10d can be found in fig3.10d in twsg.) The examples given here show behavior of the realizations and autocorrelations as λ=0.95. Clearly, the behavior of the autocorrelations and realizations for the case of equal roots is similar to the behavior when the roots are unequal yet close together. In this book, we typically consider cases in which the roots are not repeated (except for certain nonstationary and seasonal models).
