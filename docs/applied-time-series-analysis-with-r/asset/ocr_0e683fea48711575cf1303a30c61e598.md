+   c. gen.garma.wge(n,u,lambda,phi,theta,trun,burn
in,var,sn) is a function that generates (and optionally
plots) a realization of length n from a given GARMA or Gegenbauer
odel We recommend using fracdiff.sim from the fracdiff
CRAN package for generating realization from a FARMA or frac-\model. See Note 1.

n is the length (x,t=1,...,n)
u and lambda are the parameters of the Gegenbauer factor in
Equation 11.16

phi is a vector of the AR parameters (default phi = 0)
theta is a vector of MA parameters (using signs as in this text)
(default = 0)

trun is the truncation point of the infinite GLP form(default=300,000)
burn is in the burning-in period (default = 600)
vara is the white noise variance (default = 1)
plot = TRUE produces a plot of the realization generated
s determines the seed used in the simulation. (See Note 4 below)
The outputs the generated realization.

NOTES:

+   1. While fractional and FARMA models can be generated using
gen.garma.wge, we recommend using fracdiff.sim in the
CRAN package fracdiff. For example, to generate a realizazi-
of length n = 500 from the model
(1 + .5B^2)(1–B)^{45} X_t = (1 +.8B), you could use the statement
fgen = fracdiff.sim(n = 500, sr = c(0,-5),ma = -.8,d=.45).
See the fracdiff documentation for more details.
2. It will be useful to call the utility function mult.wge if you know
the factors of the AR or MA parts of the model instead of the
coefficients.
3. By the default white noise is zero mean, normal noise with vari-
ance vara = 1.
