# EXAMPLE 7.5: ASYMPTOTIC DISTRIBUTIONS AR(1) AND AR(2) MODELS

+   1. AR(1): In the case of an AR(1) model, $\Gamma$ is the $l 	imes l$ matrix whose element is $\gamma_0$, which from Equation 3.37 is given by $\gamma_0 = \sigma_0^2/(1-\phi_1^2)$. Thus, it follows that

```

```

so that $\hat{\phi}_1$ is asymptotically normal with mean $\hat{\phi}_1$ and variance $(1-\phi_1^2)/n$.

+   2. AR(2): The matrix $\Gamma$, for an AR(2), is given by

```
$$\Gamma = \begin{pmatrix} \gamma_0 & \gamma_1 \ \gamma_1 & \gamma_2 \end{pmatrix},$
```
