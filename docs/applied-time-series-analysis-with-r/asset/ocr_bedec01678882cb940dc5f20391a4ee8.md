Equation 3.124 requires modification to allow for this type of behavior. The multiplicative seasonal ARMA model

```
$\Phi(B^s)\phi(B)X_t = \Theta(B^s)	heta(B)_s a_t, \quad (3.126)$
```

where the roots of $\phi(z) = 1 - \phi_1 z - \dots - \phi_p z^p = 0$ and $	heta(z) = 1 - 	heta_1 z - \dots - \theta_q z^q = 0$ all lie outside the unit circle, is widely used for this purpose. The model in Equation 3.126 is denoted by ARMA$(p,q) \times (P_s,Q_s)_s$.
