# 13.2.4 Transformation and Sampling

It should be clear from Definition 13.3 that an M-stationary process requires sample values at unequally spaced points. This is true in general for G-stationary processes. Thus, finding a transformation $u = g(t)$, is equivalent to determining a sampling scheme such that $X(t_k) = X(g^{-1}(u_k)) = Y_k$, where $Y_k$ is stationary. That is, $X(t)$ should be sampled at points $t = t_k = g^{-1}(u_k)$. In the case of M-stationary processes, $t_k = h^k$ and $u_k = k\Delta$. In general, of generality, we take $\Delta = 1$, so $t_k = h^k$ and $u_k = k$.

In general, data only will be available at equally spaced points and may not necessarily be obtainable at the points $t_k$. This problem can be overcome by over-sampling or interpolation. By over-sampling, we indicate the situation in which data are sampled at sufficiently small increments in time so that the values of the realization are available at the $t_k$. The data available only at equally spaced points cannot be sufficiently over-sampled, and interpolation and Kalman filter can be used to process the data.

# EXAMPLE 13.2: A DISCRETE EULER(2) MODEL

Figure 13.2 shows a realization of length $n=200$ from the discrete Euler(2) process

```
$X(h^k) - 1.6X(h^{k-1}) + 0.99X(h^{k-2}) = a(h^k),$
```

with $h=1.01$. Unlike stationary processes for which it can always be assumed loss of generality that the origin is at $t=0$, for M-stationary processes the origin offset or simply the offset is a parameter to be estimated. In this case, we use $h'=30$ and $60$. For a discussion of the origin problem for G-stationary processes in general, see Gray et al. (2005), Jiang (2003), and Jiang et al. (2006).
