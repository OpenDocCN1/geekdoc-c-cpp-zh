## EXAMPLE 10.11: STATE-SPACE FORM OF AN ARMA(p,q) PROCESS

A state-space formulation of the univariate, zero-mean ARMA(p,q) process

```
$Y_t - \phi_1 Y_{t-1} - \dots - \phi_p Y_{t-p} = a_t - \theta_1 a_{t-1} - \dots - \theta_q a_{t-q},$
```

is given by

```
$X_t = \Phi X_{t-1} + V_t \quad \text{(state equation),}$
$Y_t = (-\theta_1, -\theta_2, \dots, -\theta_q, 1)X_t \quad \text{(observation equation)},$
```

where

$X_t = \begin{pmatrix} U_{t-r+1} \\ \vdots \\ U_{t+2} \end{pmatrix}, \Phi = \begin{pmatrix} 0 & 1 & 0 & \dots & 0 \\ 0 & 0 & 1 & \dots & 0 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & \dots & 1 \\ \phi_r & \phi_{r-1} & & \dots & \phi_1 \end{pmatrix}, V_t = \begin{pmatrix} 0 \\ 0 \\ \vdots \\ a_t \end{pmatrix}$

where $U_t$, is the AR(p) process given by $\phi(B)U_t = a_t$, $r=\max(p,q+1)$, $\phi_j=0$ for $j>p$, and $\theta_j=0$ for $j>q$. (See Problem 10.9)

## 10.6.3 Goals of State-Space Modeling

Recall that in the case of ARMA and ARIMA modeling, we typically analyze the data in a realization to estimate the model parameters and then use the estimated model for purposes of forecasting/predicting future values, spectral estimation, Given a state-space model

```
$X_t = \Phi X_{t-1} + V_t$
$Y_t = GX_t + W_t$,
```

the fundamental goal is to estimate the underlying unobserved signal $X_t$, given the observations $Y_r, \dots, Y_t$, for some time $s$. The typical procedure used to accomplish this goal is

1. Estimate the parameters $(\mu, \Gamma_{\Phi}, \Gamma_G, \Gamma_W)$ of the state-space model.
2. Estimate the best linear estimator of $X_t$ (for some time $t$) in the mean-square sense. Specifically, we want to find $E(X_t|Y_r, \dots, Y_t)$. For simplicity, we will use $\hat{X}_t$ to denote $E(X_t|Y_r, \dots, Y_t)$, and we denote the mean-squared error by $\Gamma_t^X = E[(X_t - \hat{X}_t)(X_t - \hat{X}_t)^T]$. This step has three categories based on the relationship between time $t$ and the time of the last observed value, $s$:

- a. Prediction: This is the case in which $s < t$. An example would be the one-step forecasts $\hat{X}_t^1, \hat{X}_t^2, \dots$
- b. Filtering: The case in which $s = t$.
- c. Smoothing: The case in which $s > t$. This case is called smoothing, since a plot of $\hat{X}_t^1, \hat{X}_t^2, \dots$ tends to be smoother than the one-step ahead forecasts $\hat{X}_t^0, \hat{X}_t^2, \dots$ or the "filters" $\hat{X}_t^1, \hat{X}_t^2, \dots$.

## 10.6.4 Kalman Filter

The Kalman filter is a very useful iterative procedure for obtaining the estimates $\hat{X}_t^i$ for the state-space model in Equations 10.48 and 10.49 with initial conditions $\hat{X}_0=\mu$ and $\Gamma_0=\Gamma_0$. In the following, we give the Kalman recursions for computing predictions, filters, and smoothers of $X_t$. In Appendix 10A, we give a proof of the prediction and filtering recursion.

### 10.6.4.1 Prediction (Forecasting)

The following equations provide one-step ahead predictions, $\hat{X}_t^1$ (or equivalently $\hat{X}_{t+1}$); Specifically, we have observed $Y_0, \dots, Y_{t-1}$ and want to use this information to predict $X_t$. The Kalman recursion is as follows:

```
$\hat{X}_t^1 = \mathbf{F}\hat{X}_{t-1}^1$
```

```
$\Gamma_t^1 = \mathbf{F}\Gamma_{t-1}^1\mathbf{F}' + \Gamma_v$
```

### 10.6.4.2 Filtering

The filtering and prediction recursions are run simultaneously. For example, note that the prediction in Equation 10.50 involves the filter term $\hat{X}_t^1$. The equations in the Kalman recursions for filtering, that is, for estimating $X_t$ based on $Y_0, \dots, Y_t$, are given by

```
$\hat{X}_t = \hat{X}_t^1 + \mathbf{K}_t(Y_t - \mathbf{G}\hat{X}_t^1)$
```

```
$\Gamma_t = [\mathbf{I} - \mathbf{K}_t\mathbf{G}]\Gamma_{t-1}^1$
```

where

```
$\mathbf{K}_t = \Gamma_t^{-1}\mathbf{G}'[\mathbf{G}\Gamma_{t-1}^1\mathbf{G}' + \Gamma_v]^{-1}$
```

$\mathbf{K}_t$ is called the Kalman gain.

Proof: A proof of the validity of the prediction and filtering recursions given in Appendix 10A.

### 10.6.4.3 Smoothing Using the Kalman Filter

In this setting, values of $Y_1, \dots, Y_n$ are observed and the goal is to estimate $X_t$ where $t < n$, that is, we want to calculate $X_t^f$. The recursion proceeds by calculating $\hat{X}_t^f, \hat{X}_{t-1}^f, \Gamma_t^f$, and $t=1, \dots, n$ using Equations 10.50 through 10.54. Then, for $t=n, n-1, \dots$ we calculate

```
$\hat{X}_t^f = \hat{X}_{t-1}^f + \mathbf{J}_{t-1}(\hat{X}_t - \hat{X}_{t-1}^f)$
```

```
$\Gamma_{t-1}^f = \Gamma_t^f + \mathbf{J}_{t-1}(\Gamma_t^f - \Gamma_{t-1}^f)\mathbf{J}_{t-1}'$
```

where

```
$\mathbf{J}_{t-1} = \hat{X}_t - \mathbf{F}\hat{X}_{t-1}^f$
```

### 10.6.4.4 h-Step Ahead Predictions

It should be noted that the predictions in Equation 10.50 are one-step ahead predictions (or forecasts), that is, predictors of $X_t$ given observations of the random variables $Y_1, \dots, Y_{t-1}$. However, the ARMA-based forecasting in Chapter 6 provided ahead forecasts but also $h$-step forecasts. State-space methodology can also be used to find $h$-step ahead predictors, that is the predictor of $X_{t+h-1}$ given observations on the random variables $Y_1, \dots, Y_{t-1}$. The $h$-step ahead predictor, $\hat{X}_{t+h-1}^f$, is defined to be

```
$\hat{X}_{t+h-1}^f = E(X_{t+h-1} | Y_1, \dots, Y_{t-1})$
```

From Equation 10.48, it follows that $\hat{X}_{t+h-1} = \mathbf{FX}_{t+h-2} + \mathbf{V}_{t+h-1}$, so, from Equation 10.58, we have

```
$\hat{X}_{t+h-1}^f = E(\mathbf{FX}_{t+h-2} + \mathbf{V}_{t+h-1} | Y_1, \dots, Y_{t-1})$
= \mathbf{F}(\hat{X}_{t+h-2} | Y_1, \dots, Y_{t-1})$
= \hat{X}_{t+h-2}^f$
```

Continuing recursively, it follows that

```
$\hat{X}_{t+h-1}^f = \mathbf{F}^{h-1}\hat{X}_{t-1}^f$
```
