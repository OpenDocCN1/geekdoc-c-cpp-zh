## 3.6.3 General Procedure

It is apparent from the preceding AR(2) example that finding appropriate starting values can be difficult for higher-order models. For this reason, we typically use appropriate techniques that are designed to be relatively insensitive to starting values. Since $\rho_k \rightarrow 0$ as $k \rightarrow \infty$ for a stationary ARMA(p,q) process, it follows that $X_t$ is uncorrelated with the starting values for sufficiently large $t$. That is, for $\varepsilon > 0$, there is a $K$ such that $|rho_k| < \varepsilon$ for $k > K$. One conservative technique is to choose $K$ such that $|r_{max}| < K$ where $|r_{max}|$ is the maximum absolute reciprocal of the roots, $r_v$ of the characteristic equation $\phi(z) = 0$. In Table 3.9, we show the "warm-up" length, $K$, sometimes referred to as the induction period, required for various values of $\varepsilon$ and $|r_{max}|$.

A procedure for generating a realization of length $n$ from an ARMA(p,q) model is to use arbitrarily selected starting values, generate a realization of these starting values, and retain only the last $n$ values as the realization $x_t, t=1,...,n$. According to the preceding discussion, these last n values are “nearly uncorrelated” with the starting values. This procedure is used in the gen.arma.wge program where the starting values $a_i$, and $x_i$, are set equal to their unconditional expectations of zero and $\mu$, respectively.

## 3.7 Transformations

It will at times be useful to apply a transformation to time series data. In this section, we cover the basic issues regarding memorylessness and AR transformations.

### 3.7.1 Memoryless Transformations

Sometimes, it will be helpful to transform each observation in order to produce data that more nearly satisfy underlying assumptions. In Figure 1.25a, we showed the logarithmic of number of airline passengers for the classical airline data. Figure 3.31a shows the “raw airline data” (airline in tswe) without applying the logarithmic transformation, and in Figure 3.31b, we show the log airline data as previously shown in Figure 1.27a. The “raw” airline data in Figure 3.31a do not appear to be a realization from a stationary process, since the variance seems to be increasing with time. In such cases, a variance stabilizing transformation such as the logarithmic transformation could be applied to produce the series $Y_t=\log(X)$ such as the one in Figure 3.31b (airlog in tswe) that more nearly satisfies the variance condition of stationarity. Techniques for parameter estimation, model identification, and forecasting the airline data, which will be given in chapters follow, are more appropriately applied to $Y_t$. The logarithmic transformation is an example of a memoryless transformation (1964)

### 3.7.2 AR Transformations

A second type of transformation, referred to here as an AR *transformation*, is also useful. Consider the AR(1) model

$$(1-0.95B)X_t = a_t,$$

and let $Y_t$ be defined by

```
$Y_t = X_t - 0.95X_{t-1}$\
= (1-0.95B)X_t.$
```

It follows that $Y_t$ is white noise

```
$Y_t = (1-0.95B)X_{t-1}$\
= a_t.$
```

Thus, the AR model itself can be viewed as a transformation to white noise or as a “whitening filter”. In fact, this is one of the primary applications of the AR model. Note that application of transformation in Equation 3.311 to a realization of length $n$ produces a “new” realization of length $n-1$ given by

```
$Y_1 = X_2 - 0.95X_1$\
$Y_2 = X_3 - 0.95X_2\
$\vdots$
$Y_{n-1} = X_n - 0.95X_{n-1}.$
```

In Figure 3.32b, we show the corresponding realization of length $n = 99$ for $Y_i$. The realization for $Y_i$ in Figure 3.32b has the appearance of white noise. More generally for the ARMA$(p,q)$ model

> $\phi(B)X_t = \theta(B)a_t,$  (3.132)

we consider the problem of determining the model satisfied by $Y_t$ where

> $Y_t = \alpha(B)X_t$

$\alpha(B)$ is of order $k$, that is, $\alpha(B) = 1 - \alpha_1B - \dots - \alpha_kB^k$. Thus, $X_i = \alpha^{-1}(B)Y_t$ and Equation 3.132 can be rewritten as

> $\phi(B)\alpha^{-1}(B)Y_t = \theta(B)a_t$.

There are two cases of primary interest.

Case (1) $\alpha(B)$ is a factor of $\phi(B)$. In this case, $k \leq p$ and $\phi(B)$ can be factored as $\phi_t(B)\alpha(B)$, so that formally

> $\phi(B)\alpha^{-1}(B) = \phi_t(B)\alpha(B)\alpha^{-1}(B)$
$= \phi_t(B),$

that is $\phi_t(B)Y_t = \theta(B)a_t$, and $Y_t$ satisfies an ARMA$(p - k, q)$ model.

Case (2) $\alpha(B)$ is not a factor of $\phi(B)$ and has no common subfactors: In this case

> $\phi(B)\alpha^{-1}(B)Y_t = \theta(B)a_t$,

or

$\phi(B)Y_t = \alpha(B)\theta(B)a_t$,

that is, $Y_t$ is ARMA $(p, q + k)$.
