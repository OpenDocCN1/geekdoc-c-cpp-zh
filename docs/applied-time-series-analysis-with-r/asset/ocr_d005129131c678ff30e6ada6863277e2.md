# 4.2 ARCH and GARCH Processes

In Definition 1.6 we white noise to be zero mean, uncorrelated, and identically distributed random variables. We have often used examples in which these random variables are also normally distributed, although this is not a requirement for white noise. However, it is not uncommon to have data for which the noise appears more variable or volatile over certain sections of the time axis than others. For example, consider the data in Figure 4.7 that shows the DOW daily rate of return from October 1, 1928 to December 31, 2010 (data set dow.rate in tswge). Clearly, the data look much more variable in some regions than others. Isolated extremes are also evident, the 1930s were a period of continuing volatility. Isolated notably on the 1929 stock market crash on October 29, 1929 and Black Monday, October 19, 1987. However, as we will see in Example 4.4 these data seem to be a type of noise, $a_t$ which the observations are uncorrelated.

For the rate of returns ($a_t, t=1, \dots, 2065$) in Figure 4.7 it appears that the conditional variance, $\sigma_{t-1}^2$ of $a_t$, given $a_{t-k}, a_{t-j}, \dots$, that is,

```
$$\sigma_{t-1}^2 = E[a_t^2 | a_{t-k}, k=1, 2, \dots], \quad (4.18)$
```

depends on $t$. Thus, as we will see in Example 4.4, the $a_t^2$ in Figure 4.7 appear to be uncorrelated and not independent. The time series for which the conditional variance of the noise, $\sigma_{t-1}^2$, depends on $t$ is said to be *volatile*, and the conditional variance is often referred to as the *conditional volatility*.
