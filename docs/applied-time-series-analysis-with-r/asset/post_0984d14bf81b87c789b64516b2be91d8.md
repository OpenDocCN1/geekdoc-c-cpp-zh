Linear Filters

Many of the time series that we will study can be viewed as the output of a linear operator or filter. In this chapter, we introduce the basic concepts and terminology of linear filter theory. We also discuss the general linear process, which is a linear filter with white noise input that plays a fundamental role in the study of stationary processes. Finally, we discuss the application of linear filters for purposes of removing or retaining certain types of frequency behavior from a time series realization.

### 2.1 Introduction to Linear Filters

Consider the process $[X_t - \mu; t=0, \pm1, \pm2, \dots]$ given by

$X_t - \mu = \sum_{j=-\infty}^{\infty} h_j Z_{t-j}, \quad (2.1)$

where
$h_j$ are constants
$Z_i$ is a random variable with $E[Z]=0$ for each $t$

The process $X_i$ is referred to as the output of a linear filter, and $Z_i$ is the input. If $h_j=0$ for $j<0$ then this is called a *causal filter*, $X_i$ only depends on present and past values of the input $Z_i$. In this book, we focus on causal filters, and thus, although Theorems 2.1 and 2.2 and Definition 2.1, which have noncausal analogs, we state them here only for causal filters. We will find it convenient to use the backshift operator $B$, defined by $B^j Z_i = Z_{i-j}$ to write (the causal version of) Equation 2.1 as

$X_i - \mu = \sum_{j=0}^{\infty} h_j B^j Z_i,\n$=H(B)Z_i, \quad (2.2)$

where $H(B) = \sum_{j=0}^{m} h_j B^j$. The linear filter in Equation 2.1 is symbolically described as follows:

$Z_t = \text{Input} \rightarrow [H(B)]_{\text{Filter}} \rightarrow \text{Output} = X_t$

We will use the following notation:

$X_t$, is the output
$Z_t$, is the input

$h_j$ are the filter weights; collectively, $\{h_j\}$ is called the impulse response function
$H(e^{-2\pi i\omega})$ is the frequency response function (defined in Equation 2.4)

The sense in which an infinite series of random variables such as Equation 2.1 converges will always be taken in this book to be in the mean-square sense. Theorem 2.1 follows sufficient conditions for the series on the right-hand side of Equation 2.1 to converge in mean square to $X_t - \mu$.

### Theorem 2.1

If the $h_j=0, 1, \dots$ of a causal linear filter are such that $\sum_{j=0}^{\infty} |h_j| < \infty$, for each $t$, $E[Z_t^2] \leq M$ for some finite $M$, and $\mu$ is a real number, then there is a unique stochastic process, $X_t$, with $E[X_t^2] < \infty$ such that for each $t_i$,

### 2.2 Stationary General Linear Processes

Many of the statistical time series that we will study be viewed as the output, $X_t$, of a linear filter with white noise input. Such a process is called a general linear process, which is defined in the following.

### Definition 2.1 (General Linear Process) The process $X_t$, $t=0, \pm1, \pm2, \dots$ given by

$X_i - \mu = \sum_{j=0}^{\infty} \Psi_j a_{i-j},$

is defined to be a general linear process if $a_t$ is a white noise process with zero mean and finite variance and $\sum_{j=0}^{\infty} |\psi_j| < \infty$.

Using the backshift operator $B$, Equation 2.5 can be written as

$X_t - \mu = \sum_{j=0}^{\infty} \psi_j B^j a_t\n= \psi(B)a_t$$

we

$$\psi(B) = \sum_{j=0}^{\infty} \psi_j B^j.$$

In this section, we will consider the problem of finding stationarity conditions for $X_t$ in Equation 2.5 along with expressions for the autocovariance function and power spectrum. In this connection the following theorem is helpful. We include its proof here because of its use of fundamental concepts.

### Theorem 2.3

If $X_t$ is a causal linear process, then $X_t$ is stationary.

Proof: Without loss of generality assume that $\mu=0$. Since $E[a_t] = 0$, it follows immediately that $E[X_t] = 0$, and thus the autocovariance function for $X_t$ is given by, $E[X_t X_{t+k}]$. Now, noticing that

$X_{t+k} = \sum_{m=0}^{\infty} \psi_m a_{t+k-m}$

we have

$E[X_t, X_{t+k}] = E\left[\sum_{j=0}^{\infty} \psi_j a_{t-j} \left[ \sum_{m=0}^{\infty} \psi_m a_{t+k-m} \right] \right]\n= E\left[\sum_{j=0}^{\infty} \sum_{m=0}^{\infty} \psi_j \psi_m a_{t-j} a_{t+k-m} \right]\n= E\left[\sum_{j=0}^{\infty} \sum_{m=0}^{\infty} \psi_j \psi_m E[a_{t-j} a_{t+k-m}] \right] \quad (2.6)$

### 2.3 Wold Decomposition Theorem

Before proceeding, we state the Wold decomposition theorem that emphasizes the central role of the general linear process in the study of covariance stationary processes. For a proof and discussion of this result, the reader is referred to Brockwell and Davis (1991).

### Theorem 2.4

Let $(X_t; t = 0, \pm1, \pm2, \dots)$ be a zero mean, covariance stationary process. Then, $X_t$ can be expressed as the sum of two zero mean, uncorrelated, covariance stationary processes,

$X_t = U_t + V_t,$

such that

- 1. $U_t$ is a general linear process with $\psi_0 = 1$
- 2. $V_t$ is completely determined by a linear function of $X_t$ its past values

The process $V_t$ is usually referred to as the nondeterministic component. In Chapter 3, it will be shown that $U_t$ is called stationary autoregressive, moving average, and autoregressive moving average processes can be expressed as general linear processes. Thus, the Wold decomposition provides justification for these models to be fundamentally well suited for the analysis of stationary processes.
