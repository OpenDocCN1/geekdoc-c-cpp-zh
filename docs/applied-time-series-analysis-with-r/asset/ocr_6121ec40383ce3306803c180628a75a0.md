# Appendix 1A: Fourier Series

In Definition 1.15, we define the periodogram of a discrete time series X, to be

```
I(f_j) = \hat{f}_j^2 + 2 \sum_{k=1}^{n-1} \hat{f}_k \cos 2\pi f_j k,    (1A.1)
```

f_j are the harmonics of the fundamental frequency 1/n. Specifically,

```
f_j = \frac{\hat{j}}{n}, j=1,...,\frac{n}{2} (if n is even)
= \frac{\hat{j}}{n}, j=1,...,m, (if n is odd and n = 2m+1).
```

It is interesting to note that the periodogram in Equation 1A.1 can be obtained as 1/n times the modulus squared of the Fourier transform of the data as given by Equation 1A.2.

```
I(f_j) = \frac{1}{n} \sum_{i=1}^{n} x_i e^{(-2\pi i tj/n)}^2    (1A.2)
```

The proof of the equality of Equations 1A.1 and 1A.2 is left as Problem 1.20.
