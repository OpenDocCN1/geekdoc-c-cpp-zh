# ARMA Time Series Models

From Equation 3.97, it follows that

```
$$\gamma_{X_t}(m)=0, \quad m>0$$
$$=\Psi_{|m|}\sigma_a^2, \quad m\le 0.\ \quad (3.98)$
```

Thus, for $k\ge 0$

```
$$\gamma_k=\phi_1\gamma_{k-1}+\cdots+\phi_q\gamma_{k-p}-\sigma_a^2(\theta_k\Psi_0+\cdots+\theta_q\Psi_{q-k}),\quad (3.99)$
```

where $\theta_0=-1$, and the parenthetical expression is taken to be zero if $k>q$. Specifically, $\gamma_k'$ is given by

```
$$\gamma_k'=\phi_1\gamma_{q-1}+\cdots+\phi_q\gamma_{q-p}-\sigma_a^2\theta_k,\quad (3.100)$
```

and $\gamma_k'$ does not satisfy a homogeneous equation, since $\sigma_a^2\theta_k\neq 0$. However, for $k>q$,

```
$$\gamma_k-\\phi_1\gamma_{k-1}-\cdots-\\phi_q\gamma_{k-p}=0,\quad (3.101)$
```

and

```
$$\rho_k-\\phi_1\rho_{k-1}-\cdots-\\phi_q\rho_{k-p}=0,\quad (3.102)$
```

so that $\gamma_k'$ and $\rho_k$ satisfy a $p$-th order homogeneous difference equation with constant coefficients for $k>q$. Since we have assumed that $\phi(z)$ and $\theta(z)$ share no common factors, $p$ is the lowest order of a homogeneous difference equation with constant coefficients satisfied by $\rho_k$. The solution to Equation 3.102 can be made to satisfy $p$ linear boundary conditions obtained from Equation 3.99 for $k=q,q-1,\dots,q-p$. Thus, for $k>q-p$, it follows that

```
$$\rho_k=\sum_{i=1}^{m-1}\sum_{j=1}^{q}C_{ij}'\rho_{k-i},\quad (3.103)$
```

or in the case of no repeated roots of the characteristic equation,

```
$$\rho_k=C_1\r_1^{-k}+\cdots+C_p\r_p^{-k},\quad (3.104)$
```

where the $C_{ij}$ and $C_l'$ are constants uniquely determined from Equation 3.99 with $k=q,q-1,\dots,q-p+1$.
