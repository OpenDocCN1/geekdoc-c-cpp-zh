# 3.2.4 Autocorrelations of an AR(p) Model

In order to find the autocorrelations of an AR(p) process, pre-multiply each side of Equation 3.17 by $X_{i-k}$ where $k > 0$, to obtain

$X_{i-k}\{X_i - \phi_1 X_{i-1} - \cdots - \phi_p X_{i-p} = a_k\}$.

Taking expectations in Equation 3.36 yields

$\gamma_k = \phi_1 \gamma_{k-1} - \cdots - \phi_p \gamma_{k-p} = 0$,

where we have used the fact that, in the AR(1) case, $E[X_{i-k}a_i] = 0$ for $k > 0$. It follows for $k > 0$,

$\rho_k = \phi_1 \rho_{k-1} - \cdots - \phi_p \rho_{k-p} = 0$.

Writing Equation 3.37 as

$\rho_k = \phi_1 \rho_{k-1} + \cdots + \phi_p \rho_{k-p}$

the first $p$ equations specified in Equation 3.38 can be written as

$\rho_1 = \phi_1 + \phi_2 \rho_1 + \cdots + \phi_p \rho_{p-1}$
$\rho_2 = \phi_1 \rho_1 + \phi_2 \rho_2 + \cdots + \phi_p \rho_{p-2}$
:
$\rho_p = \phi_1 \rho_{p-1} + \phi_2 \rho_{p-2} + \cdots + \phi_p$.

The equations in Equation 3.39 are called the Yule-Walker equations. When the coefficients $\phi_1, \dots, \phi_p$ are known, the Yule–Walker equations are $p$ equations that can be solved for the unknowns $\rho_1, \dots, \rho_p$. Note that after the first $p$ autocorrelations are found by solving the Yule–Walker equations, then $\rho_k, k > p$ can be iteratively found using the relationship in Equation 3.38.

Also note that for a given set of data assumed to follow an unknown AR(p) model, the model parameters $\phi_1, \dots, \phi_p$ can be estimated by first replacing $\rho_k$

$$\gamma_0-\phi_1\gamma_1-\cdots-\phi_p\gamma_p=\sigma_{\gamma}^2.$$

$$\sigma_{\gamma}^2(1-\phi_1\rho_1-\cdots-\phi_p\rho_p)=\sigma_a^2.$$

Therefore,

$$\sigma_{\gamma}^2=\frac{\sigma_a^2}{1-\phi_1\rho_1-\cdots-\phi_p\rho_p}$$

# 3.2.5 Linear Difference Equations

We have discussed the fact that autocorrelations of an AR(p) model satisfy Equation 3.37 and can be found using Equation 3.39. However, the behavior of these autocorrelations is not immediately apparent. The equation in Equation 3.37 is an example of a linear homogeneous difference equation with constant coefficients, which we will briefly discuss here.
A function, $g_k$ defined on a set of constant integers, $I$, is said to satisfy (or is a solution of) a linear homogeneous difference equation of order $m$ with constant coefficients, if $g_k$ is that

$g_k-b_1g_{k-1}-\cdots-b_mg_{k-m}=0,$

$k \in l$, where $b_1, b_2, b_m$ are constants. Thus, from Equation 3.37, it follows that $\rho_k$ satisfies a $pth$-order linear homogeneous difference equation with constant coefficients for $k > 0$. The general solution to the difference equation in Equation 3.44 is well known (see Brock and Davis, 1991). Specifically, if $g_k$ satisfies Equation 3.44 for $k > 0$,

$g_k = \sum_{i=1}^{v} \sum_{j=0}^{m_i} C_{ij}r_i^{-k}$

where the $r_i$ are the roots of the characteristic equation

$1 - b_1z - b_2z^2 - \dots - b_mz^m = 0,$

$v$ is the number of distinct roots, $m_i$ is the multiplicity of $r_i$ (i.e., if $r_i$ is repeated once, $m_i=2$, and if $r_i$ is not repeated, then $m_i=1$), $\sum_{i=1}^v m_i = m$, and $C_{ij}$ are uniquely determined by the initial conditions

$g_1 = h_1$
$g_2 = h_2$
$\vdots$
$g_m = h_m,$

where the $h_i$ are constants. When there are no repeated roots, Equation 3.37 simplifies to

$g_k = C_1r_1^{-k} + C_2r_2^{-k} + \dots + C_mr_m^{-k}$.

$$\sum_{i=1}^{v} m_i = p,$$
