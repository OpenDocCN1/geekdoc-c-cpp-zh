# 8A.1 Patterns in the Autocorrelations

Consider the autocorrelations of an MA($q$) process which from Equation 3.4 have the form

```
$$\rho_k = 0 \text{ for } k > q \n\neq 0 \text{ for } k = q. \quad (8A.1)$
```

The behavior described in (8A.1) uniquely determines the order $q$ of an MA($q$) process if the true autocorrelations are known. Then, sample autocorrelations that are near zero for $k > q$ while $\hat{ho}_k 
eq 0$ suggest an MA($q$) as a possible model. From Bartlett’s (1946) approximation in Equation 1.22 it follows if $X_i$ is an MA($q$) process then,

$k > q$. Further, since $E[\hat{ho}_k] = 0$ for $k > q$, a rough guide is that

```
$$|\hat{ho}_k| > 2\sqrt{\frac{1+2\sum_{v=1}^{q}\rho_v^2}{n}} \quad (8A.2)$
```

for $k > q$, then this is evidence against an MA($q$) at the $\alpha=0.05$ level of significance. Thus, if an MA($q$) is to be considered the model, then $\hat{ho}_k$ for $k > q$ should essentially remain within the limits specified by Equation 8A.2. However, as the test for white noise, the quoted significance level applies for each $k$ so that it will not be unusual to observe a small percentage of $\hat{ho}_k, k \geq q$, outside the specified limits when the model is an MA($q$). It should be noted that when $X_i$ is white noise, that is, $X_i$ is MA($q$) with $q=0$, then the summation in Equation 8A.2 is taken to be zero, and Equation 8A.2 reduces to 8.1.
