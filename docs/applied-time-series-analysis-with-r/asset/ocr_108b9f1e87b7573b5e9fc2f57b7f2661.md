# EXAMPLE 3.10: AUTOCORRELATION FUNCTION FOR EXAMPLES 3.8 AND 3.9

Based on Equation 3.77, the autocorrelation function for the AR(3) model of Example 3.8 is

```
$$\rho_k = 0.66(0.95)^k + 0.3518(0.95)^k \sin(2\pi f_0 k + 1.31), \quad$ (3.79)$
```

$f_0 = 0.09$. From Equation 3.79, it can be seen that the expression for the autocorrelation function is a mixture of a damped exponential and a damped sinusoidal component which is consistent with our observations concerning Figure 3.16b.

The autocorrelation function for the AR(3) model in Example 3.9, which has a negative real root and the second-order factor as the model in Example 3.8, is

```
$$\rho_k = 0.139(-0.95)^k + 0.862(0.95)^k \sin(2\pi f_0 k + 1.5), \quad$ (3.80)$
```

where $f_0 = 0.09$. Note that the coefficient (0.139) of the oscillating damped exponential term in Equation 3.8 is relatively small causing the damped exponential behavior to not be very visible in a plot of the autocorrelations as was noted in the discussion of Figure 3.17b.
