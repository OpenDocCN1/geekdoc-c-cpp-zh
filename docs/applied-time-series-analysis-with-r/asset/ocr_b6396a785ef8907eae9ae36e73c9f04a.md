which corresponds to Equations 10.6 and 6.9. Properties of the forecasts
are best derived from Equation 10.29. Among these properties is the fact
$\hat{X}_t(\ell)$ is the minimum mean-squared error predictor of $X_{t+\ell}\ given X_t, X_{t-1}, \dots$. Using the general linear form in Equation
10.17 and the forecasts in Equation 10.29, the $\ell$-step ahead of forecasts
errors, $e_t(\ell)$, are given by

```
$$e_t(\ell) = X_{t+\ell} - \hat{X}_t(\ell)$$\n[\ell-1]\
= \sum_{j=0}^{\ell-1} \Psi_j X_{t+\ell-j}$ (10.30)
```

from which it follows that $e_t(\ell)$ has expected value 0 and covariance
matrix, $\Gamma_x(\ell)$, given by

```
$$\Gamma_x(\ell) = E[e_t(\ell)e_t(\ell')]$$\n[\ell-1]\
= \sum_{j=0}^{\ell-1} \Psi_j \Psi_{j'}$ (10.31)
```

In the case of normal errors, forecast limits analogous to Equation 6.33
can be obtained using the diagonal elements of Equation 10.31.

**Using R:** The forecasts in Figure 10.6 were calculated using the true param-
values for illustrative purposes. In practice, you will use the estimated
coefficients to obtain these forecasts. See the "Using R" section at the end of
Example 10.4 for a discussion obtaining forecasts using R.

# 10.3.2 Spectrum of a VAR($p$) Model

In the VAR($p$) case, the multivariate spectrum, $P_x(f)$, defined in Equation
10.7, is the $m \times m$ matrix given, for each $-0.5 \leq f \leq 0.5$, by

```
$P_x(f) = \Phi^{-1}(e^{-2\pi i f}) \Gamma_x \Phi^{-1}(e^{-2\pi i f})$$ (10.32)
```

where for real or complex $z$, the polynomial $\Phi(z) = \mathbf{I} - \Phi z - \dots - \Phi z'$ is the
algebraic equivalent of the operator $\Phi(B)$ defined in Equation 10.16. Note that
Equation 10.32 is the multivariate counterpart to the AR($p$) spectrum given
in Equation 3.53. We mention that the use of the term spectrum and
spectral density is typically used synonymously in the multivariate case to
indicate the Fourier transform of the autocovariance.
