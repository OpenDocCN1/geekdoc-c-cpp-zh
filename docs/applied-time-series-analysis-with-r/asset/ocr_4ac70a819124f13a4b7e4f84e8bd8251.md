# Model Identification

Using R: Use aic.wge to find the best fitting ARMA(p,q) model for specified ranges of p and q the model identification criterion you choose. For example, the command aic.wge(x=0:8,q=0:4,type="aicc") finds the best fitting (based on AIC) ARMA(p,q) model for the data in vector x for models p=0 through 8 and q=0 through 4. You may specify type="aic","bic", or "aic". (default is "aic") Function aic.wge also outputs the ML parameter estimates among other output. The function aic5.wge is similar to aic.wge but finds the top five candidates among the model order ranges using the specified selection criterion.

NOTE: In this book, we use AIC as the model identification criterion. This is not meant as an endorsement of this criterion over the others, but is simply done for consistency of presentation.
