For example, consider the AR(3) model

```
$$(1-\alpha_B B)(1-eta_B B-eta_B^2)X_t = a_t,$$
```

with one real root and one complex conjugate pair of roots (i.e., $m=2$). The model in 3.120 can be written in inverted form

```
$$$X_t = \frac{1}{(1-\alpha_B B)(1-eta_B B-eta_B^2)}a_t,$$
```

Recalling that operators can be inverted using properties of the corresponding algebraic quantities, we use partial fractions to write

```
$$\frac{1}{(1-\alpha_z z)(1-eta_z z-eta_z^2)} = \frac{A}{1-\alpha_z z} + \frac{C_1+C_2 z}{1-eta_z z-eta_z^2 z,$$
```

from which we obtain

```
$$$X_t = \frac{1}{(1-\alpha_B B)(1-eta_B B-eta_B^2)}a_t = \frac{A}{1-\alpha_B B} + \frac{C_1+C_2 B}{1-eta_B B-eta_B^2}a_t,$$
```

for real constants $A, C_1$, and $C_2$. Letting $X^{(1)} = (A/(1-\alpha_B B))a_t$ and $X^{(2)} = (C_1+C_2 B)/(1-eta_B B-eta_B^2)a_t$, it follows that $(1-\alpha_B B)X^{(1)} = Aa_t$, and $(1-eta_B B-eta_B^2)X^{(2)} = (C_1+C_2 B)a_t$. That is, it is a realization from an AR(1) process where the AR factor is the first factor in the factored form of Equation 3.120, and $x^{(2)}$ is the second-order factor in the factored form of Equation 3.120. In Example 10.14, we discuss the use of state-space formulation to actually construct these components. The important point to be made here is that each component corresponds to a row in the factor table. See also West (1997).
