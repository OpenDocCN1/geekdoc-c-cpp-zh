## Definition 10.7

Let $X_t$ be a stationary multivariate process that satisfies

```
$$\mathbf{X}_t - \Phi_1 \mathbf{X}_{t-1} - \dots - \Phi_p \mathbf{X}_{t-p} = \alpha + \mathbf{a}_t - \Theta_1 \mathbf{a}_{t-1} - \dots - \Theta_q \mathbf{a}_{t-q} $$
```

where $\Phi_s$ and $\Theta_s$ are real-valued $m \times m$ matrices, and $\mathbf{a}_t$ is multivariate white noise. Then, $X_t$ is a VARMA$(p,q)$ process.

## 10.3.1 Forecasting Using VAR(p) Models

Given a VAR(p) model, Box-Jenkins style forecasts, $\hat{X}_t$, for $\hat{X}_{t+h}$ “assuming” the infinite past $X_t$, $t=t_0-1, t_0-2, \dots$ can be obtained in a manner analogous to that given in Section 6.2 in the univariate case. Specifically, these forecasts can be expressed in terms of the difference equation,

```
$$\hat{X}_t(\ell) = \sum_{j=1}^p \Phi_j \hat{X}_t(\ell-j) + (\mathbf{I} - \Phi_1 - \dots - \Phi_p)\mu,$$ (10.24)
```

corresponds to Equation 6.21. In Chapter 6, we calculate forecasts based on the assumption that the model is known. Since $\mu$ must be estimated from data, we use the basic formula for calculating from a VAR(p) model as

```
$$\hat{X}_t(\ell) = \sum_{j=1}^p \Phi_j \hat{X}_t(\ell-j) + (\mathbf{I} - \Phi_1 - \dots - \Phi_p)\bar{X}_t,$$ (10.25)
```

corresponds to Equation 6.24 in the univariate case. In practice, the model is estimated from the data, and the $\Phi_s$ in Equation 10.25 are replaced by their estimated values $\hat{\Phi}_s$. Parameter estimation in VAR(p) models will be discussed shortly.

## 10.3.2 Spectrum of a VAR($p$) Model

In the VAR($p$) case, the multivariate spectrum, $P_x(f)$, defined in Equation
10.7, is the $m \times m$ matrix given, for each $-0.5 \leq f \leq 0.5$, by

```
$P_x(f) = \Phi^{-1}(e^{-2\pi i f}) \Gamma_x \Phi^{-1}(e^{-2\pi i f})$ (10.32)
```

where for real or complex $z$, the polynomial $\Phi(z) = \mathbf{I} - \Phi z - \dots - \Phi z'$ is the
algebraic equivalent of the operator $\Phi(B)$ defined in Equation 10.16. Note that
Equation 10.32 is the multivariate counterpart to the AR($p$) spectrum given
in Equation 3.53. We mention that the use of the term spectrum and
spectral density is typically used synonymously in the multivariate case to
indicate the Fourier transform of the autocovariance.
