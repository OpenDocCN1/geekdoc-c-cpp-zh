NOTE: Before proceeding, we point out that some authors and writers of software packages write Equation 3.1 as $X_i-\mu = a_i + 	heta_{i-1} + \dots + 	heta_{i-q}$. Consider the MA(2) model $X_i = a_i - 1.2a_{i-1} + 0.8a_{i-2}$. Using the definition in Equation 3.1, it follows that $	heta_1 = 1$ and $	heta_2 = -0.8$, while the coefficients would be $	heta_1 = -1.2$ and $	heta_2 = 0.8$ using the alternative representation. Before entering coefficients into a time series computer package or comparing formulas involving the $	heta$'s in different textbooks, it is very important to check the MA(q) definition.

Notice that an MA(q) process is a general linear process with a finite number of terms. In particular

```
$$\psi_0=1$$
$$\psi_k=-	heta_k
```

Using the notation in Equation 2.8, note that $\psi(z)=1-\sum_{j=1}^q	heta_jz^j$ where $z$ is real or complex. For an MA(q) process, we denote $\psi(z)$ by $	heta(z)$. An MA(q) process can be shown to be stationary using Theorem 2.3, because there are only a finite number of $\psi$-weights. Since $\sum_{j=1}^q	heta_j^2=1+	heta_1^2+\dots+	heta_q^2$, it follows that

```
$$$\sigma_k^2=\sigma_q^2(1+	heta_1^2+\dots+	heta_q^2)<\infty.$$
```

Also, from Equation 2.7

```
$$$\gamma_k=\sigma_q^2\left{-\theta_{g-k\|+\sum_{j=1}^q\theta_j\theta_{j+k}\right\}, \quad k=1,2,...,q$$
$$$\gamma_k=0, \quad k>q.$$
```

It follows then that

```
$$$\rho_k=\frac{-\sum_{j=1}^q\theta_j\theta_{j+k}}{1+\sum_{j=1}^q\theta_j^2}, \quad k=1,2,...,q$$
$$$\rho_k=0, \quad k>q.$$
```
