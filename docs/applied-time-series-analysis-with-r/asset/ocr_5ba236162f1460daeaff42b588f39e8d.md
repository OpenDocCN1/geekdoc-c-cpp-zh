
Thus, if a given realization is from a white noise, then the sample autocorrelations should be small and approximately uncorrelated at different lags. For a given $k$, it follows that

```
|\tilde{ho}_k|>2\frac{1}{\sqrt{n}},                (8.1)
```

provides evidence against the null hypothesis of white noise at the $\alpha=0.05$ level of significance (where we have rounded $z_{0.975}=1.96 to 2). It should be noted that the significance level $\alpha=0.05$ applies separately for each $k$, and it would not be unusual for 5% of the $\tilde{ho}_k$ to exceed $2(1/\sqrt{n})$ when the data is white noise. As a result, this “test” is actually more of an informal guide for determining whether or not the data should be modeled as white noise. It should be noted, however, that many alternatives of interest, as an MA($q$) model or an AR($p$) model with roots relatively far from the unit circle, have nonzero autocorrelations at low lags followed by zero or near zero autocorrelations at higher lags. Thus, if the “nonzero” $\rho_k^*$ occurs for small $k$, then other models should be considered. This will be discussed in Example 8A.2.
