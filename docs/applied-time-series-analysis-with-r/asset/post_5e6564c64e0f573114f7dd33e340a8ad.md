## 8.2.1 Model Identification Based on AIC and Related Measures

AIC is a general criterion for statistical model identification in multivariate regression and, in our case, identifying $p$ and $q$ in an ARMA($p,q$) model. ML estimation is a common tool that applies to a model or class of distributions with fixed set parameters, $a_t, \dots, a_k$. In this setting, the ML estimators $\hat{a}_1, \dots, \hat{a}_k$ maximize the likelihood function. However, simply maximizing the likelihood is not an appropriate strategy when parameters are being added to an existing model. For example, suppose ML methods are used to choose between a model with $k$ parameters (e.g., AR(k)) and a model from the same class with $k+1$ parameters, for example, an AR(k+1). Consider the strategy of maximizing the likelihood under each scenario and selecting the model with the maximized likelihood. This would always select the AR(k+1) model.

$L_{MAX}(\hat{a}_1, \dots, \hat{a}_k) \leq L_{MAX}(\hat{a}_1, \dots, \hat{a}_{k+1})$,

where $\hat{a}_j$ denotes the ML estimator of $a_j$ for a model with $m$ parameters. To note, when Equation 8.2 is used, there are $k+1$ parameters, for which $\hat{a}_{k+1}=0$. The maximized likelihood on the left-hand side of Equation 8.2 is based on the constraint that $\hat{a}_{k+1}=0$ while the right-hand side is maximized without this constraint. AIC addresses this problem in the ARMA case by imposing a penalty for adding parameters. The method is based on selecting the $p$ and $q$ that minimize the expected Kullback–Leibler distance between the true underlying model of the data and ARMA($p,q$) fit to the data where $0 \leq p \leq P$ and $0 \leq q \leq Q$. Akaike (1976). Essentially, AIC imposes a penalty for adding terms to a model, and the resulting procedure is to select the model that minimizes

$AIC = -2[ln(maximized likelihood)] + 2(\# of free parameters)$.

In the setting of ARMA(p,q) modeling, the AIC criteria becomes

AIC = -2[ln (maximized likelihood)]+2(p+q+1), (8.4)

since there are $p+q+1$ parameters including the constant term. It can be shown that AIC in Equation 8.4 is approximately equal to

AIC = ln($\hat{\sigma}_n^2$)\frac{p+q+1}{n} (8.5)

where $\hat{\sigma}_n^2$ is the estimated white variance associated with the ML fit of an ARMA(p,q) model (see Box et al., 2008; Shumway and Stoffer, 2010). We will subsequently apply AIC by finding the $p$ and $q$ ($0 \leq p \leq P$ and $0 \leq q \leq Q$) that minimize AIC as defined in Equation 8.5.

A problem with the use of AIC is that as the realization length increases, AIC tends to overestimate the model orders (i.e., select models with many parameters). Several authors have considered modifications to AIC to adjust for this problem. Two of the alternatives are AICC (Hurvich and Tsai, 1989) and BIC (sometimes called the Schwarz Information Criterion [SIC]) (Schwarz, 1978). These are given by

AICc = ln($\hat{\sigma}_n^2$)\frac{n+p+q+1}{n-p-q-3}$ (8.6)

and

BIC = ln($\hat{\sigma}_n^2$)+(p+q+1)\frac{\ln(n)}{n} (8.7)

Simulation studies have shown BIC to perform best for large realization lengths, n, while AIC generally performs better for smaller $n$ when the number of parameters is relatively large (see McQuarrie and Tsai, 1998). If computing time related to the use of ML estimation is an issue, the quantities in Equations 8.5 through 8.7 can be approximated using alternative estimation techniques. For example, if the decision has been made to restrict attention to AR models, Equations 8.5 through 8.7 can be calculated using $\hat{\sigma}_n^2$ obtained based on Burg estimates of the model parameters.

Other model identification techniques have been proposed in the literature. For example, Akaike (1969) suggested the use of final prediction error (FPE) for identifying the order of an AR model. Another early technique for identifying the order of an AR model is the criterion AR transfer (CAT) function proposed by Parzen (1974).

# Model Identification

Using R: Use aic.wge to find the best fitting ARMA(p,q) model for specified ranges of p and q the model identification criterion you choose. For example, the command aic.wge(x=0:8,q=0:4,type="aicc") finds the best fitting (based on AIC) ARMA(p,q) model for the data in vector x for models p=0 through 8 and q=0 through 4. You may specify type="aic","bic", or "aic". (default is "aic") Function aic.wge also outputs the ML parameter estimates among other output. The function aic5.wge is similar to aic.wge but finds the top five candidates among the model order ranges using the specified selection criterion.

NOTE: In this book, we use AIC as the model identification criterion. This is not meant as an endorsement of this criterion over the others, but is simply done for consistency of presentation.
