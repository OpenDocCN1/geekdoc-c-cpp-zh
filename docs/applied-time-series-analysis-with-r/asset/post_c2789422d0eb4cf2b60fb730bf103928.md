## 10.1 Additional Multiple Time Series Routines

Except for the Kalman-filtering routines listed above, tswge does not include functions specifically designed for multivariate time series data. We discussed multivariate R functions and CRAN packages in this chapter. These include

- 1. Base R function ccf: As mentioned in Section 10.2, given univariate time series $X_i(x_i)$ and $X_j(x_j)$, the base R function ccf(xi,xj,type='covariance') computes $\gamma_{ij}(k)=E[(X_{i+k}-\mu_i)(X_j-\mu_j)]$, which is not the cross-covariance, $\gamma_{ij}(k)=E[(X_{i+k}-\mu_{i+k})]$ as defined in Equation 10.2. Again, as mentioned in Section 10.2, then you can use the call statement ccf(xi,xj,type='variance'). In order to compute cross-correlations you can specify type='correlation' in each case. The default for ccf is to plot the associated cross-variance and cross-correlation.
- 2. Base R function: this function calculates least squares estimates for VAR models. It also provides for order identification using AIC. The statements needed to perform the analyses in Example 10.4 are given in the “Using R” section at the end of the example.
- 3. CRAN package vars: this package is useful for analyzing VAR models. The vars commands lsfit (finds least squares estimates and performs model identification), serial.test (performs Ljung-Box test following a call to lsfit), and predict calculates forecasts and 95% limits based on the model found using lsfit. The vars commands used in Example 10.4 are given in the “Using R” section at the end of the example.
- 4. CRAN packages and UnitRoots: In Example 10.7 we used the function ca. in CRAN package urca to run the Johansen test for cointegration. In that example we also used the function adTest from CRAN package that was used previously in Example 8.6.
