max.p is the maximum order autoregressive model to be fit (based on AIC) to the residuals.

n.ahead = the number of steps ahead you want to forecast (default = 10)

last = logical variable. If last= FALSE then the forecasts are for x(n+1), x(n+2), ...x+n.ahead where n is the length of the realization. If last= TRUE, then the program forecasts the last n.ahead values in the realization. (default = FALSE)

plot = logical variable. If plot = TRUE then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output.

(default = TRUE)

limits = logical variable. If limits = TRUE then the 95% forecast limits will be plotted along with the forecasts. (default = TRUE)

Example: Suppose a realization of length n=50 is generated from Xt=10+4cos(2t/12)+Z, where (1−B)Zt=at, and σ_t=1 is using the function gen.sigplusnoise.wge described in Appendix 1.B. The following code will generate the realization then calculate and plot forecasts for times 51–70.

```
x = gen.sigplusnoise.wge (n=50,b0=10,b1=0,coef=c(4,0),freq=c(0.0833),psi=c(2,0),phi=.8
```

```
xfore = for.sigplusnoise.wge (x,linear=FALSE,freq=0.0833,n.ahead=20,last=FALSE,FALSE)
```
