# EXAMPLE 10.11: STATE-SPACE FORM OF AN ARMA(p,q) PROCESS

A state-space formulation of the univariate, zero-mean ARMA(p,q) process

```
$Y_t - \phi_1 Y_{t-1} - \dots - \phi_p Y_{t-p} = a_t - \theta_1 a_{t-1} - \dots - \theta_q a_{t-q},$
```

is given by

```
$X_t = \Phi X_{t-1} + V_t \quad \text{(state equation),}\nY_t = (-\	heta_1, -\theta_2, \dots, -\theta_q, 1)X_t \quad \text{(observation equation)},
```

where

$X_t = \begin{pmatrix} U_{t-r+1} \ \vdots \ U_{t+2} \end{pmatrix}, \Phi = \begin{pmatrix} 0 & 1 & 0 & \dots & 0 \ 0 & 0 & 1 & \dots & 0 \ \vdots & \vdots & \vdots & \ddots & \vdots \ 0 & 0 & 0 & \dots & 1 \ \phi_r & \phi_{r-1} & & \dots & \phi_1 \end{pmatrix}, V_t = \begin{pmatrix} 0 \ 0 \ \vdots \ a_t \end{pmatrix}$

where $U_t$, is the AR(p) process given by $\phi(B)U_t = a_t$, $r=\max(p,q+1)$, $\phi_j=0$ for $j>p$, and $	heta_j=0$ for $j>q$. (See Problem 10.9)

# 10.6.3 Goals of State-Space Modeling

Recall that in the case of ARMA and ARIMA modeling, we typically analyze the data in a realization to estimate the model parameters and then use the estimated model for purposes of forecasting/predicting future values, spectral estimation, Given a state-space model

```
$X_t = \Phi X_{t-1} + V_t\nY_t = GX_t + W_t$,
```

the fundamental goal is to estimate the underlying unobserved signal $X_t$, given the observations $Y_r, \dots, Y_t$, for some time $s$. The typical procedure used to accomplish this goal is

+   1. Estimate the parameters $(\mu_v, \Gamma_{\Phi}, \Gamma_F, \Gamma_G$, and \Gamma_W$) of the state-space model.

+   2. Estimate the best linear estimator of $X_t$ (for some time $t$) in the mean-square sense. Specifically, we want to find $E(X_t|Y_r, \dots, Y_t)$. For simplicity, we will use $\hat{X}_t$ to denote $E(X_t|Y_r, \dots, Y_t)$, and we denote the mean-squared error by $\Gamma_t^X = E[(X_t - \hat{X}_t)(X_t - \hat{X}_t)^T]$. This step has three subcategories based on the relationship between time $t$ and the time of the last observed value, $s$.
