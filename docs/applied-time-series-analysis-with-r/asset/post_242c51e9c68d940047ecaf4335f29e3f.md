## 4.2.3 AR Processes with ARCH or GARCH Noise

We briefly consider the effect of ARCH and GARCH noise on AR processes. For the discussion here, we consider the AR(2) process

> $X_t - 1.95X_{t-1} + 0.98X_{t-2} = a_t$.

Figure 4.14a shows a Gaussian noise realization and Figure 4.14b shows a realization from Equation 4.32 where $a_t$ is the noise sequence in Figure 4.14a. While there is no volatility in the noise sequence, the realization in Figure 4.14b shows oscillations in amplitude, which is consistent with realizations from AR(2) models with complex roots near the unit circle. Figure 4.14c shows a realization from an ARCH(1) model with $\alpha_0 = 0.1$ and $a_t$. Figure 4.14d shows a realization from the AR(2) model in Equation 4.32, where $a_t$ is the ARCH(1) noise realization in Figure 4.14c. The ARCH (1) realization shows fairly isolated spikes at about $t=700$ and $t=1150$, which initiate an abrupt increase in amplitude of the corresponding output process in Figure 4.14d, followed by a relatively slow decay. ## 4A.1 Basic computation and plot routines

+   The following functions were discussed previously
i. signplusnoise.wge (Appendix 1B)
ii. gen.arma.plot (Appendix 3B)
b. gen.arch.wge(n,alpha0,alpha,plot,sn) is a function that gen-
erates a length of n from the ARCH(q0) model given in
Equation 4.23.
n is the realization length ($x_t$ $t = 1, \dots , $n$)
alpha0 is the value for $\alpha_0$
alpha is a vector of length q0 containing $\alpha_i$ $i = 1, \dots , $q_0$
plot = TRUE (default) produces a plot of the realization generated
sn determines the seed used in the simulation (see Note (2) below)
(default = 0).

**NOTES:**

+   1. By default the white noise is zero mean, normal noise with variance 1.

+   2. sn = 0 (default) produces results based on a randomly selected seed. If you want to reproduce the same realization on subsequent runs of gen.arch.wge then set sn to the same positive integer value on each run.
Example: The command
x=gen.arch.wge(n=200,alpha0=0.1,alpha=c(.36,.27,.18,.09), plot = TRUE)
generates (using a randomly selected seed) and plots a real-ization from the ARCH(4) model in Equation 4.29.
c. gen.arch.wge(n,alpha0,alpha,beta,plot,sn) is a function that generates a realization of length n from the ARCH(q0) model given in Equation 4.23.
n is the realization of variable (x(t), t=1, ..., n
alpha0 is the value for $q0$
alpha is a vector of length q0 containing $\alpha_i$; i=1, ..., q0
beta is a vector of length p0 containing $\beta_i$; i=1, ..., p0
plot = TRUE (default) produces a plot of the realization generated
sn determines the seed used in the simulation (see Note 2 below) (default=0).

**NOTES:**

+   1. By default the white noise is zero mean, normal noise with variance 1.

+   2. sn = 0 (default) produces results based on a randomly selected seed. If you want to reproduce the same realization on subsequent runs of gen.arch.wge then set sn to the same positive integer value on each run.

Example: The command
x=gen.arch.wge(n=200,alpha0=.1,alpha=.45,beta=.45, plot = TRUE) generates and plots a real-ization from the GARCH(1,1) model in Equation 4.31.
