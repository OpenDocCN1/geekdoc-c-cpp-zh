> $(1-B)(1+B+0.8B^2)X_t = a_t, \quad (7.75)$

spectral densities with infinite spikes, in this case, at $f=0$ and $f=0.25$. In practice, if an ARUMA model such as Equation 7.75 is fit to a set of data, then we recommend plotting the ARUMA spectral density estimates of related near-stationary models. In this case, we can plot the true spectral density associated with

> $(1-0.995B)(1+0.99B^2)(1-B+0.8B^2)X_t = a_t, \quad (7.76)$

Note that the coefficients were selected, so that all three near-stationary roots are equally close to the unit circle. In this case, the roots are 1.005 and $\pm1.005$. Figure 7.4 shows an approximate ARUMA(2,3,0) spectral density estimate with the model fit in Equation 7.75. The sharp peaks at $f=0$ and $f=0.25$ represent the infinite peaks at those frequencies.

## Appendix

Two parameter estimation routines are provided in tswge.ar.wge and est.arma.wge. As the names suggest, these functions are designed to estimate the parameters in the AR and ARMA model respectively. Ar functions mentioned in this chapter also base R functions ar, ar.burg, ar.yw, ar.dle and ar.ols. Also, innovations estimates of MA parameters (shown in Table 7.1 were obtained using itsmr function which is available in CRAN).

- a. est.ar.wge(x, p, factor, type) is a function that obtains parameters of a stationary AR model of order p that is fit to the data in the x

- x is a vector containing the realization to be analyzed
p is the order of the AR model (default = 2)
factor is a logical variable, and if factor = TRUE (default) a factor is printed for the estimated model
type specifies the method used to estimate the parameters: either 'mle' (default), 'burg', or 'yw' (not recommended)

The program outputs:
phi the estimates of the parameters $\phi_1, ..., \phi_p$
res the estimated residuals (using backcasting) based on estimated model
av the estimated white noise variance (based on backcast residuals)
aic the AIC value associated with this model fit
aicc the AICC value associated with this model fit
bic the BIC value associated with this model fit

NOTE: This function calls to the base R functions ar.mle, ar.burg, and ar.yw.

The program outputs:
phi the ML estimates of the parameters $\phi_1,...,$\phi_p$
theta the ML estimates of the parameters $\theta_1,...,$\theta_q$
 the estimated residuals (using backcasting) based on estimated
model
avar the estimated white variance (based on backcast residuals)

aic the AIC value associated with this model fit

aicc the AICC value associated with this model fit

bic the BIC value associated with this model fit

se.phi the standard error(s) of the AR parameter estimates

se.theta the standard error(s) of the MA parameter estimates

## NOTES:

- 1. This function uses a call to the base R function arima.
2. est.arma.wge calculates ML estimates by default. Other options are available in the call to arima if the users desires.
