# Theorem 2.1

If the $h_j=0, 1, \dots$ of a causal linear filter are such that $\sum_{j=0}^{\infty} |h_j| < \infty$, for each $t$, $E[Z_t^2] \leq M$ for some finite $M$, and $\mu$ is a real number, then there is a unique stochastic process, $X_t$, with $E[X_t^2] < \infty$ such that for each $t_i$,

```
$$\lim_{m\to\infty} E[(X_t - \mu - \sum_{j=0}^{m} h_j Z_{t-j})^2] = 0$
```
