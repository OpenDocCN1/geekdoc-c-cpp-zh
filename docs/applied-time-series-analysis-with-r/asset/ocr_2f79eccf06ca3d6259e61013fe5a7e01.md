# Parameter Estimation

From the model in Equation 7.16, we obtain the $n-p$ "regression" equations

```
$X_1 = \phi_1 X_2 + \dots + \phi_p X_{p+1} + \delta_1$\nX_2 = \phi_1 X_3 + \dots + \phi_p X_{p+2} + \delta_2$\n$:
X_{n-p} = \phi_1 X_{n-p+1} + \dots + \phi_p X_n - \delta_{n-p}.$ (7.17)
```

Instead of minimizing the sum of squares $S_n = \sum_{i=p+1}^n a_i^2$, consider estimating the parameters of the model by minimizing the forward and backward sum of squares (FBSS)

```
$FBSS = \sum_{t=p+1}^n a_t^2 + \sum_{t=1}^{n-p} a_t^2.$ (7.18)
```

The Durbin-Levinson algorithm can be used to compute the $\hat{\phi}$, so that the FBSS is minimized and at the same time guarantees that the resulting model is stationary. This result is due to Burg (1975), and the resulting estimates are referred to as the *maximum entropy* or Burg estimates. Explicitly, the Burg algorithm is as follows, where the input data $(x_i$, in the algorithm) have mean corrected,

Initialization:

Let

```
$den^{(0)} = 2 \sum_{j=1}^n x_j^2$\n$f_j^{(0)} = x_j, \quad j=1,\dots,n$\n$b_j^{(0)} = x_j, \quad j=1,\dots,n$\n$a_0^{(0)} = 0$.
```

For $k=1$ through $k=p$, the updating formulas for moving from $k-1$ to $k$ are

```
$num^{(k)} = \sum_{j=k+1}^n f_j^{(k-1)}b_{j-1}^{(k-1)}$$\n$den^{(k)} = [1-(a_{k-1}^{(k-1)})^2]den^{(k-1)} - (f_k^{(k-1)})^2 - (b_k^{(k-1)})^2$
```

```
$a_k^{(k)} = \frac{-2num^{(k)}}{den^{(k)}}$\n$a_j^{(k)} = a_j^{(k-1)} + a_k^{(k)}a_{j-k}^{(k-1)}, \quad j=1,\dots,k-1$\n$f_j^{(k)} = f_j^{(k-1)} + a_k^{(k)}b_{j-k}^{(k-1)}, \quad j=k+1,\dots,n$\n$b_j^{(k)} = b_j^{(k-1)} + a_k^{(k)}f_{j-k}^{(k-1)}, \quad j=k+1,\dots,n$.
```
