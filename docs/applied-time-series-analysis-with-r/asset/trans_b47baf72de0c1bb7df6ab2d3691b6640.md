## 12.3.10 二维小波

尽管这是一本关于时间序列分析的书，我们还是在这一节中对小波分析进行了简要讨论，简要讨论了二维小波。本节简要介绍了 $m \times n$ 图像 $F_{m,n}$ 的小波分析，其中，在一元情况下，我们假设两个维度都是二进的（即 2 的幂）。示例将基于正方形图像，即大小为 $2^l \times 2^l$，其中 $J_n$ 为某个整数。二维 DWT 将 $m \times n$ 图像 $F_{m,n}$ 映射为小波系数。一元 DWT 基于两种类型的小波：父小波测量平滑行为，母小波测量更详细的细节行为。在二维 DWT 的情况下，有四种类型的小波

$\Phi(x, y) = \varphi_0(x) \times \varphi_0(y)$（捕获图像的平滑特征）
$\Psi^x(x, y) = \psi_0(x) \times \varphi_0(y)$（捕获图像的垂直特征）
$\Psi^y(x, y) = \varphi_0(x) \times \psi_0(y)$（捕获图像的水平特征）
$\Psi^{xy}(x, y) = \psi_0(x) \times \psi_0(y)$（捕获图像的对角特征）

下标 $h$ 和 $v$ 分别表示水平和垂直维度，例如，$\varphi_j(y)$ 是通过单独考虑一维 $Y$ 变量得到的父小波。二维等价于方程 1217 由

```
$g(x, y) = \sum_{k,m} s_{j,k,m}^s \Phi_{j,k,m}(x,y) + \sum_{j=1}^k d_{j,k,m}^v \Psi_{j,k,m}^v(x,y) + \sum_{j=1}^k d_{j,k,m}^h \Psi_{j,k,m}^h(x,y) + \sum_{j=1}^k d_{j,k,m}^d \Psi_{j,k,m}^d(x,y), \quad (12.38)$
```

给出，其中方程 1238 中的第一项给出 $g(x,y)$ 的“平滑”近似，即涉及 $j$ 的较高值）。其余求和分别测量水平、垂直和对角细节。$s_{j,k,m},, d_{j,k,m}^v, d_{j,k,m}^h,$ 和 $d_{j,k,m}^d$ 分别称为平滑系数、垂直细节、水平细节和对角细节系数。二维 DWT 由系数 $s_{j,k,m}$ 以及 $d_{j,k,m}^v, d_{j,k,m}^h,$ 和 $d_{j,k,m}^d$ 组成，其中 $j=1,...$。每个系数都表示为 $2^j\times2^j$ 图像中像素上的灰度（或颜色）。特别地，对于 $J=3$，三维小波金字塔算法产生每个 1 级细节的 $n/2\times n/2$ 系数（$d_{1,k,m}^v, d_{1,k,m}^h,$ 和 $d_{1,k,m}^d$）。此外，还有 $n/2\times n/2$ 2 级细节系数和 $n/2^2\times n/2^2$ 3 级平滑系数，类型为 $h, v, d$。另外，保留 $n/2^3\times n/2^3$ 3 级平滑系数。图 12.21 显示了具有 $J=3$ 的二维 DWT 的示意图，其中原始图像包含 $2^J\times2^J$ 像素，其中 $f_0 \geq 3$。
