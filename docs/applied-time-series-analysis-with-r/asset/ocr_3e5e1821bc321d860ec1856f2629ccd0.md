# 3.2.6 Spectral Density of an AR(p) Model

Since $\psi(z) = \phi^{-1}(z)$ for an AR(p) process, it follows from Equation 2.8 that the spectrum is given by

```
$P_X(f) = \sigma_a^2 |\psi(e^{-2\pi f})|^2$
\frac{\sigma_a^2}{|\phi(e^{-2\pi f})|^2}$
$|1 - \phi_1 e^{-2\pi f} - \phi_2 e^{-4\pi f} - \dots - \phi_p e^{-2p\pi f}|^2$.
```

Consequently, the spectral density is

```
$S_X(f) = \frac{\sigma_X^2}{|1 - \phi_1 e^{-2\pi f} - \phi_2 e^{-4\pi f} - \dots - \phi_p e^{-2p\pi f}|^2$.
```

where $\sigma_X^2$ is given in Equation 3.43.

Again remember to be careful about the signs of the coefficients.

# 3.2.7 AR(2) Model

Understanding the features of an AR(1) and AR(2) model is critical to gaining insight into the more general AR(p) model. We have already discussed the AR(1) model, so, in this section, we consider in some detail the AR(2) model

```
$X_t - \phi_1 X_{t-1} - \phi_2 X_{t-2} = a_t$.
```

# 3.2.7.1 Autocorrelations of an AR(2) Model

For $k > 0$, the autocorrelation function of an AR(2) model satisfies the difference equation

```
$ho_k - \phi_1 \rho_{k-1} - \phi_2 \rho_{k-2} = 0$.
```
