3. Spectrum and spectral density for an AR(1): The discussion in Section
3.2.1 regarding inverting the operator allows us to apply Equation 2.8
to obtain the spectrum yielding

```
$P_X(f) = \sigma_\eta^2 |\psi(e^{-2\pi if})|^2
= \sigma_\eta^2 |\phi^{-1}(e^{-2\pi if})|^2
= \frac{\sigma_\eta^2}{|\phi(e^{-2\pi if})|^2}
= \frac{\sigma_\eta^2}{|1-\phi_1 e^{-2\pi if}|^2}$
```

Using Equation 3.35, the spectral density of an AR(1) process is
thus given by

```
$S_X(f) = \frac{\sigma_\eta^2}{\gamma_0} \frac{1}{|1-\phi_1 e^{-2\pi if}|^2}
= \frac{\phi_1^2}{|1-\phi_1 e^{-2\pi if}|^2}$
```
