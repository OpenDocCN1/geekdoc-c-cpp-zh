# 7.2 Preliminary Estimates

In this section, we discuss techniques for obtaining preliminary estimates of the parameters of $AR(p), MA(q)$, and $ARMA(p,q)$ models.

# 7.2.1 Preliminary Estimates for AR(p) Models

We consider the problem of estimating the parameters of the $AR(p)$ models

```
$X_t - \mu - \phi(X_{t-1} - \mu) - \dots - \phi_p(X_{t-p} - \mu) = a_t,$ (7.2)
```

when $p$ is assumed to be known. We focus here on Yule-Walker (YW), least squares, and Burg estimates.

# 7.2.1.1 Yule–Walker Estimates

As the name suggests, the YW estimates are based on the YW equations in Equation 3.41. In particular, recall that the autocorrelation, $ho_u$, of stationary $AR(p)$ process satisfies the difference equation

```
$ho_k = \phi_1ho_{k-1} + \dots + \phi_pho_{k-p},$ (7.3)
```

for $k > 0$. Letting $k=1, 2, \dots, p$ in Equation 7.3 yields the YW estimates

```
$ho_1 = \phi_1 + \phi_2ho_1 + \dots + \phi_pho_{p-1}$
$ho_2 = \phi_1ho_1 + \phi_2 + \dots + \phi_pho_{p-2}$
$\dots$
$ho_p = \phi_1ho_{p-1} + \phi_2ho_{p-2} + \dots + \phi_p.$ (7.4)
```

In Chapter 3, these equations were seen to be useful for finding the $ho_k$ when $\phi_1, \phi_2, \dots, \phi_p$ were known. If the $ho_k$ are known, then the YW equations are $p$ equations in the unknowns $\phi_1, \dots, \phi_p$, that can be solved for the $\phi_u$. YW estimates are found from a realization by replacing $ho_k$, for $k=1, \dots, p$ in Equation 7.4 with the sample autocorrelations, $\hat{ho}_k$, discussed in Chapter 1.
