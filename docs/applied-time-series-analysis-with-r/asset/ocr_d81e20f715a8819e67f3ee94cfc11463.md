# Forecasting

**Using R:** Forecasts from the general seasonal model in Equation 6.47 can be obtained using fore.aruma.gen by specifying s to incorporate the factor $\lambda(B) = (1 - B^s)$. The stationary components of the model are $\phi(B)$ and the stationary factor $\Phi(B)$ for example $(1 - aB^s)$. These factors should be multiplied using mult.wge, and then entered into the vector phi. Nonstationary components of the model can be entered into the model by specifying $d$ for factors such as $(1 - B)^d$, and using the vector lambda to specify other nonstationary components. # EXAMPLE 6.7: FORECASTING MONTHLY HOUSING STAR DATA

In 6.9, we show the new privately owned housing units authorized in the United States from January 1999 to December 2001 (months 1–36). The data set is included in base R under the name housing. The data are monthly and seems to be a clear seasonal trend, for example, small number of permits authorized in January, February, and December with the peak year being at about June. The model

```
$(1 - .0873B - .0802B^2 - .3941B^3)(1 - B^{12})(X - 135.9) = a_t$
```

was fit to the data (see [Chapters 7–9]() for estimation and modeling details), and the forecasts for the next 2 years are shown with the dotted lines. Although visually appears that the forecasts for the next 2 years are copies of the last year observed, this is not the case of the stationary AR(3) component in the model. For example in January 2001 there were 117 permits issued in January 2002 the prediction was that 120 permits would be issued.
