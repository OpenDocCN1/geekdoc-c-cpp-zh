# Stationary Time Series

phi is a vector containing the AR model for the noise process (see Chapter 3). (default = 0) For white noise just use the default values for phi.

vara is the variance of the noise (default = 1).

NOTE: a(t) is a vector of N(0,vara) white noise generated by the function

plot is a logical variable. plot = TRUE (default) produces a plot of the generated realization.

sn determines the seed used in the simulation. (default = 0) (see Note below)

NOTE: sn=0 (default) produces results based on a randomly seed. If you want to reproduce the same realization on subsequent runs of gen.sigplusnoise.wge then set sn to the same positive integer value on each run.

Example: The command

```
x=gen.sigplusnoise.wge(n=100,coef=c(1.5,3.5))
freq=c(.05,.2),psi=c(1.1,2.8),phi=.7,vara=2
calculates
```

```
x(t)=1.5cos(2π(.05)t+1)+3.5cos(2π(.2)t+2.8)+z(t), t=1,2,...,100
```

z(t) is a realization from the AR(1) z(t)=(1-7B)a, where σ²=2. The realization is based on a randomly selected seed, and the resulting signal-plus-noise realization is placed in the vector x.
