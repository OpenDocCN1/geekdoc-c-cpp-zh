# 3.3.4 Autocorrelations of an ARMA(p,q) Model

Multiplying each term in Equation 3.86 (without loss of generality using the zero mean) by X_{t-k} (k ≥ 0) and taking expectations yields

```
\gamma_k - \phi_1\gamma_{k-1} - \cdots - \phi_p\gamma_{k-p} = E[X_{t-k}a_t] - \theta_1E[X_{t-k}a_{t-1}] - \cdots - \theta_qE[X_{t-k}a_{t-q}]\n\= \gamma_X(0) - \theta_1\gamma_X(k-1) - \cdots, \quad (3.96)
```

where

```
\gamma_X(m) = E[X_{t-m}a_t]\n\= E\left( \sum_{j=0}^{\infty} \psi_j a_{t-j}a_t \right). \quad (3.97)
```
