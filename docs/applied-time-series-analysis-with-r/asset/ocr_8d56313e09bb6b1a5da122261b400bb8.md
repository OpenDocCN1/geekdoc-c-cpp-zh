Giraitis and Leipas (1995), Ferrara and Guegan (2001), and Guegan (2008) use the Whittle likelihood to estimate the parameters of a $k$-factor Gegenbauer model. The Whittle likelihood is a frequency-domainbased likelihood based on a class of models parameterized by $\xi$ (possibly vector valued). Letting $P_x(f;\xi)$ denote the spectrum at frequency $f$ under the assumed model with parameter value $\xi$, a useful approximation to -2log-likelihood based on Whittle is 193

```
$$-2 \ln L_W(X;\xi) = \sum \frac{I(f_j)}{P_x(f_j;\xi)}$
```

where $[z]$ is the greatest integer less or equal to $z, f_j = j/n, j=1,2,\dots,[n/2]$, and $I(f)$ is the periodogram defined in Equation 1.8. Model identification can be accomplished using AIC. In the current setting, $P_x(f)$ is defined in Equation 11.21. Kouameé and Heli (2008) proposed minimum distance estimators for the parameters of the $k$-factor GARMA model which are easy to compute and are not based on an assumption that the $a_i$'s are normally distributed.

**Using R:** The tswge package includes the function est.garma.wge to estimate the parameters of the 1-factor GARMA model. The function est.farma.wge is included for use in the special case when a FARMA model is specifically described. Both of these functions use the grid-search procedure recommended by Hosking (1984), Gray et al. (1989, 1994), and Woodward et al. (1998) and include model selection using AIC.
