## 10.5.2 Testing for Cointegration between Nonstationary Time Series

We let $X_{i1}$ and $X_{i2}$ denote the annual incidence of non-perforated appendicitis (appendicitis) and influenza (flu), respectively, in Figure 10.8. The disease incidence data showing a wandering behavior that is indicative of models with unit roots. The question of interest here is whether the two series tend to “tethered together,” that is, to wander together. Engle and Granger (1987) used the term cointegration to describe this “tethering together” idea, which in our setting, implies that each series has a single unit root and there exists some linear combination of the differences $\nabla X_{it}$ and $\nabla X$ is stationary. The cointegration concept has been used extensively in the econometrics literature for analyzing relationships. In an extensive bibliography in this area, see Engle and Granger (1991). Engle and Granger (1987) show that it is useful to use an error correction framework similar to that in Equation 8.23 (see also Problem 8.10) for describing the relationship between $X_n$ and $X_{i2}$. Letting $X_t = (X_{t1}, X_{t2})$, we consider the model

```
$X_t = \alpha + \Phi_1 X_{t-1} + \dots + \Phi_p X_{t-p} + \mathbf{a}_t,$
```

where it is assumed, in this case, that $\Phi(B) = \mathbf{I} - \Phi_1 B - \dots - \Phi_p B^p$ has a factor

```
$$\lambda(B) = \begin{pmatrix} 1-B & 0 \\ 0 & 1-B \end{pmatrix} (10.46)
```

The multivariate error correction model has the form

```
$\nabla X_t = \beta_0 + CX_{t-1} + \beta_1 \nabla X_{t-1} + \dots + \beta_{p-1} \nabla X_{t-p+1} + \mathbf{a}_t, (10.47)$
```

where $\sqrt{V_{t-ij}} = X_{t-i} - X_{t-j}$, $\beta_0 = \mu(I-\Phi_1 - \dots - \Phi_j)$, $C = -(I-\Phi_1 - \dots - \Phi_j)$ and $\beta_j = -(\Phi_j + \dots + \Phi_p)$, for $j=1, \dots, p$. It is assumed that $\Phi(B) = I - \Phi_1 - \dots - \Phi_p$ has rank $\lambda(B)$ in Equation 10.46, then $|I-\Phi_z| \neq 0$ for $z=1$, the matrix $C$ is singular, and in this bivariate case, has rank 0 or 1. Johansen (1988, 1991) and Johansen and Julius (1990) developed tests for cointegration based on the rank of the matrix $C$. Specifically, in the bivariate case, $rank(C)=1$ indicates a cointegrating relationship between $X_i$ and $X_j$; if $rank(C)=0$, the variables are not cointegrated, or they are "tethered together," without unit roots. Letting $\lambda_i \leq \lambda_i$ denote the eigenvalues of the matrix $C$, then the trace statistic (see Johansen, 1988, 1991) for $H_0:rank(C)=0$ (i.e., $\lambda_1=0$) $H_0:rank(C)>0$ is $\lambda_{max}=-n\log(1-\lambda_1)$ while the test statistic for $H_0:rank(C)=1$ is $1$ $H_0:rank(C)>1$ is $\lambda_{max}=-n\log(1-\lambda_2)$. The conclusion of cointegration follows from rejecting $H_0:rank(C)=0$ but failing to reject $H_0:rank(C)=1$ versus $H_0:rank(C)>1$ if $n$ is sufficiently large.

It should be noted that these tests can be applied to find more complicated cointegrating relationships. For example, generalizations of Equation 10.47 have been developed to test whether a trend or constant is included and whether a trend is exogenous or endogenous variables. We only discussed the case $m=2$, and all unit roots are of multiplicity one. The results here can be extended to the case in which unit roots have multiplicities greater than one and in which the multiplicities differ. For further details, see the Johansen tests cited earlier.
