# 11.5 Parameter Estimation and Model Identification

We consider the problem of estimating the parameters of fractional and FARMA models. Geweke and Porter-Hudak (1993) used a semi-parametric periodogram-based regression method to estimate $d$, Hosking (1984) used a likelihood grid-search approach, and Whittle's (1951) frequency-domain approach to ML estimation was implemented by Fox and Taqqu (1986) to the problem of estimating the parameters of a FARMA model. In this section we adapt the grid-search approach by Hosking (1984) to the problem of estimating the parameters of a GARMA model which, as we have seen, includes the fractional and FARMA models as special cases. Other techniques for GARMA models will be briefly referenced. As in Chapter 7, we estimate $\mu$ by $ar{X}$ and the mean corrected data (denoted by $X$) as the realization by. It should be noted that the properties of $X$ as an estimator of $\mu_k$ depend on $|u|$. For example, in the case of a (1-factor) GARMA model, the sample converges at the $(1/\sqrt{n})$ rate whenever $|u| < 1$, while it has a slower convergence rate. See Chung (1996b).

If $X_t$ satisfies the model in Equation 11.20 with $\mu=0$, then $Y_t = \sum_{j=1}^t(1-2u_B+B^2)^k X_j$ satisfies an $ARMA(p,q)$ $\phi(B)Y=\Theta(B)X$. Woodward et al. (1998) recommend the use of a grid-search procedure for finding ML estimates of the parameters of the $k$-factor GARMA model. We assume that $k$ is known. In practice, $k$ will be estimated by identifying peaks in a nonparametric spectral estimator, or by examining factor tables. Based on positions and magnitudes of the peaks in the preliminary spectral estimate, a grid of possible values for $\lambda_i u_i \dots \lambda_k u_k$ is selected to be used in the search. For each set of values $\hat{\lambda}_i u_i \dots, \hat{\lambda}_k u_k$ in the grid search, the data are transformed to obtain

```
$Y_t = \prod_{j=1}^k(1-2u_B+B^2)^k(X_i - \bar{X})$$
$$= \prod_{j=1}^p \sum_{h=0}^{(l+K-1)} C_{-h}(u_j)(X_{t-h}-\bar{X}). \quad (11.27)$
```

In order to make the transformation in Equation 11.27, $X_t, X_{t-2}, \dots, X_{t-k}$ are obtained by backcasting as discussed in Section 7 using a high order AR model.
