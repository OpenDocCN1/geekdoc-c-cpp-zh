# ARMA Time Series Models

```
$\Psi_1 - \phi_1 =-\theta_1$\n$\Psi_2 - \phi_1\Psi_1 - \phi_2 =-\theta_2$\n:\n$\Psi_j - \phi_1\Psi_{j-1} - \phi_2\Psi_{j-2} - \cdots =-\theta_j,\quad (3.116)$
```

where $\psi_0 = 1, \theta_0 = 0$ for $k > q, \phi_k = 0$ for $k > p$. The equations in Equation 3.116 can be rearranged to provide a recursive scheme for calculating the $\psi$-weights. Namely,

```
$\psi_1 = \phi_1 - \theta_1$\n$\psi_2 = \phi_1\psi_1 - \theta_2$\n:\n$\psi_j = \phi_1\psi_{j-1} + \phi_2\psi_{j-2} + \cdots + \theta_j,\quad (3.117)$
```

Notice from Equation 3.117 that for $j > \max(p-1, q)$, $\psi_j$ satisfies the $p$-th order homogeneous difference equation

```
$\psi_j = \phi_1\psi_{j-1} + \phi_2\psi_{j-2} + \cdots + \theta_{j-p},\quad (3.118)$
```

or

```
$\phi(B)\psi_j = 0.$
```

+   Finding $\psi$-weights using division: A very easy way to calculate a few $\psi$-weights is to use division based on the fact that properties of the operators, for example, $\phi(B)$ and $\theta(B)$, can be conveniently found using the algebraic equivalents $\phi(z)$ and $\theta(z)$. For example, we can express $\phi(B)X_t=	heta(B)X_t$, and the coefficients of the operator $\phi^{-1}(B)\theta(B)$ can be found using division based on the algebraic equivalent $\phi^{-1}(z)\theta(z) = \theta(z)/\phi(z)$. As an example, consider the ARMA(2,1) model $(1-1.6B+0.9B^2)X_t$. The $\psi$-weights are given by

```
$1-0.8z = \sum_{k=0}^{\infty} \psi_k z^k,$
```

where $\psi_0 = 1$. Shows that

```
$1-0.8z/1-1.6z+0.9z^2=1+0.8z+0.38z^2-0.112z^3\dots$
```

So, $\psi_1 = 0.8, \psi_2 = 0.38, \psi_3 = -0.112$, etc.
