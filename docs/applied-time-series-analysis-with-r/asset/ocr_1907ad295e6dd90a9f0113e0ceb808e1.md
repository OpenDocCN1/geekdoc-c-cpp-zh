Since $a \neq 0$, it follows that

$E\left[(X_{t_0+\ell}-Z_{t_0})^2ight] < E\left[(X_{t_0+\ell}-Z_{t_0})^2ight]$

and the result follows.

+   a. fore.arma.wge(x,phi,theta,n.ahead,lastn,plot,limits)
This function forecasts n.ahead steps using the Box-Jenkins forecasting approach for stationary ARMA models. The forecasts and limits can optionally be plotted. You can optionally calculate and forecast n.ahead steps the end of the series or you can forecast the last n.ahead data values. Note: The components of phi/or theta may be obtained using mult.wge if the models are given in factor form
x = realization
phi = vector of AR coefficients (default = 0)
theta = vector of MA coefficients (default = 0)
n.ahead = the number of steps you want to forecast (default = 2)
lastn = logical variable. If lastn = FALSE then the forecasts are for x(n+1), x(n+2), ..., x(n+n.ahead) where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization (default = FALSE)
plot = logical variable. If plot = TRUE then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output (default = TRUE)
limits = logical variable. If limits = TRUE then the 95% limits will be plotted with the forecasts (default = TRUE)
