# 5.2 ARIMA(p,d,q) and ARUMA(p,d,q) Processes

The ARIMA(p,d,q) and ARUMA(p,d,q) models defined in Definition 5.1 are useful nonstationary extensions of the ARMA(p,q) model.

# Definition 5.1

+   1. The autoregressive integrated moving average process of orders p, d, and q (ARMA(p,d,q)) is a process, X, whose differences (1 − B)^dX, satisfy an ARMA(p,q) model (that is, a stationary model) where d is a non-negative integer. We use the notation

```
$\phi(B)(1-B)^d X_t = \theta(B)a_t,$$
```

where all the roots of $\phi(z) = 0$ and $\theta(z) = 0$ are outside the unit circle, and $\phi(z)$ and $\theta(z)$ have no common factors.

+   2. The autoregressive root moving average process of orders p, d, and q (ARUMA(p,d,q)) is an extension of the ARIMA(p,d,q) model to include processes, $X_t$, whose $\lambda(B)$ satisfies ARMA(p,q) model where $\lambda(B) = 1 - \lambda_1B - \dots - \lambda_dB^d$ is an operator whose characteristic equation has all its roots (real and/or complex) on the unit circle. We use the notation

```
$\phi(B)\lambda(B)(X_t - \mu) = \theta(B)a_t,$
```

to denote such a process.\It is worth noting that $\phi(1)\lambda(B)\mu = \phi(1)\lambda(1)\mu$, and therefore, we can write Equation 5.8 in the form

```
$\phi(B)\lambda(B)X_t = \phi(1)\lambda(1)\mu + \theta(B)a_t.$
```

The term $\phi(1)\lambda(1)\mu$ is called the *moving average constant*, and if $\lambda(B) = (1 - B)^d$, then $\lambda(1) = 0$ so that $\phi(1)\lambda(1)\mu = 0$. This is not true in general for an ARUMA(p,d,q) model, if $1 - B$ is not a factor of $\lambda(B)$, then $\phi(1)\lambda(1) \neq 0$.
