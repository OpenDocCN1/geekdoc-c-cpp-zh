# 1.4.1 Estimation of $\mu$

Given the realization $[x_t, t = 1, 2, ... , n]$ from a stationary time series, the natural estimate of the common $\mu$ is the sample mean

```
$$\bar{X} = \frac{1}{n} \sum_{t=1}^{n} X_t. \quad (1.4)$
```

It is obvious that the estimator $ar{X}$ is unbiased for $\mu$.

# 1.4.1.1 Ergodicity of $ar{X}$

We will say that $ar{X}$ is ergodic for $\mu$ if $ar{X}$ converges in the mean square sense to $\mu$ as $n$ increases, that is, $\lim_{n\to\infty} E[(ar{X}-\mu)^2] = 0$.

# Theorem 1.2

Suppose $\{X_t; t = 0, \pm1, \pm2, ...\}$ is a stationary time series. Then, $ar{X} = \frac{1}{n} \sum_{t=1}^{n} X_t,$ is ergodic for $\mu$ if and only if

```
$$\lim_{k\to\infty} \frac{1}{k} \sum_{t=0}^{k-1} \gamma_t = 0. \quad (1.5)$
```

See Yaglom (1962) for a proof of Theorem 1.2. We also have the following corollary.
