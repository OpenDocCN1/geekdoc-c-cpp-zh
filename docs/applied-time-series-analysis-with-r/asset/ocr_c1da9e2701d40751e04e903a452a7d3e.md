# ARMA Time Series Models

Case 1—Roots are distinct: As previously mentioned, in this case, $ho_i$ is given by Equation 3.55 with $C_1$ and $C_2$ uniquely determined by Equation 3.56. So it follows that

```
$ho_1 = C_1r_1^{-1} + C_2r_2^{-1} = \frac{\phi_1}{1-\phi_2}}\\n$ho_2 = C_1r_1^{-2} + C_2r_2^{-2} = \frac{\phi_1^2+\phi_2-\phi_2^2}{1-\phi_2}$
```

Denoting $\alpha_1 = r_1^{-1}$ and $\alpha_2 = r_2^{-1}$, and solving these equations

```
$C_1 = \frac{\alpha_1(1-\alpha_2^2)}{(\alpha_1-\alpha_2)(1+\alpha_1\alpha_2)}$
```

and

```
$C_2 = \frac{-\alpha_2(1-\alpha_1^2)}{(\alpha_1-\alpha_2)(1+\alpha_1\alpha_2)}$
```

which yields

```
$ho_k = \frac{(1-\alpha_2^2)\alpha_1^{k+1}-(1-\alpha_1^2)\alpha_2^{k+1}}{(\alpha_1-\alpha_2)(1+\alpha_1\alpha_2)}, \quad k \ge 0. \quad (3.60)$
```

We consider two cases in which the roots are distinct.

+   1. Real roots, that is, $\phi_1^2+4\phi_2>0$: In this case, the characteristic polynomial can be written in factored form

```
$\phi(z) = (1-r_1^{-1}z)(1-r_2^{-1}z)$
```

$r_1$ and $r_2$ are real, and $ho_k$ in Equations 3.55 and 3.60 can be seen as a mixture of damped exponentials or damped oscillations that decay to zero as $k$ increases, since $|\alpha_1|<1$ and $|\alpha_2|<1$.

+   2. Complex roots, that is, $\phi_1^2+4\phi_2<0$: In this case, the second-order characteristic polynomial is irreducible (i.e., $r_1$ and $r_2$ are not real). The roots $r_1$ and $r_2$ are complex conjugates and thus so are $\alpha_1$ and $\alpha_2$.
