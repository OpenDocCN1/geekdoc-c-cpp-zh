## 1.7 时间序列模拟数据

### 1.7.1 模拟数据

在本节中，我们检查从已知时间序列模型模拟出的时间序列实现。将对每个实现值的自相关函数和谱密度进行研究，以便更好地理解它们所传达的信息。用于生成这些实现值的 $p$  AR 模型 $(AR(p))$ 将在[第 3 章](#)中详细检查。对于这些模型，$\rho_1$ 和 $S(f)$ 可以通过[第 3 章](#)中提供的结果获得。

**示例 1.9：两个 AR(1) 模型**

[图 1.18a](#) 和 [1.19a](#) 显示了来自 AR(1) 模型长度为 250 的实现值。

```
$$X_t = 0.9X_{t-1} + a_t; \quad (1.40)$$
```

分别通过

```
$$X_t = -0.9X_{t-1} + a_t; \quad (1.41)$$
```

得到，$a_t$ 是均值为零、单位方差的高斯白噪声。我们注意到图 1.18a 中的序列具有游走行为，没有周期趋势。同样注意，对于较小的 $k$，$_i$ 和 $X_{i+k}$ 之间的相关性似乎更高。另一方面，图 1.19a 中的实现值显示出快速振荡。

模型 (1.40) 和 (1.41) 的真实自相关系数 $\rho_k$ 分别在图 1.18b 和 1.19b 中。在图 1.18b 中，可以看到真实自相关呈指数衰减到零，但对于较小的 $k$，$_i$ 和 $X_{i+k}$ 之间存在较高的正相关，这与我们对数据的观察一致。图 1.19b 显示的自相关函数似乎是衰减指数。在图 1.18c 中，$f=0$ 处的峰值表示相关的实现值表现出或没有周期行为，数据主要是低频的，没有周期趋势。相反，图 1.19c 中的谱图在 $f=0$ 附近接近零，并在 $f=0.5$ 处达到最大值，表明数据具有高度振荡的性质，它们主要是高频的，周期约为 2。

## 示例 1.13：黑子数据

最令人感兴趣的时间序列数据集之一是黑子数据。黑子是太阳表面太阳爆炸或极端大气扰动的区域。黑子之所以在科学界引起了极大兴趣，部分原因是它们似乎对地球产生某种影响。例如，高黑子活动往往会对无线通信产生干扰，并与较高的紫外线强度和正常的光活动有关。其他人还尝试将黑子活动与降水、全球变暖等联系起来，但结果不那么确定。1848 年，瑞士天文学家鲁道夫·沃尔夫（Rudolf Wolf）引入了一种每日黑子活动的方法，从 1749 年起就有使用该方法的月度数据。参见 Waldmeier (1961) 和各种网站。
