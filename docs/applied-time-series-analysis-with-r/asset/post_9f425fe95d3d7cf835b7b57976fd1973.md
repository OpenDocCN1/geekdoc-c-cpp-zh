Examination of Equation 8.6 shows that if $X_t$ is an AR(k) process, then the equations are simply the associated Yule-Walker equations. $\phi_{kk}$ is the solution of the Yule-Walker equations for the $k$th AR process based on “assuming” $X_t$ is AR(k).

The partial autocorrelation function is useful for model identification because of the fact that it has an identifiable pattern when $X_t$ is an AR(p) process. For a stationary AR(p) process, it follows that $\phi_{kk} = \phi_{pp}$ which is nonzero. However, when $k > p$, the last column of the numerator of Equation 8A.7 is a linear combination of the first $p$ columns, and as a result $\phi_{kk} = 0$. This is consistent with the intuition that, if an AR(p+1) is to process a process that is actually an AR(p), then $\phi_{kk}$ should be near zero for $k > p$. In summary, if $X_t$ is AR(p),

```
$$\phi_{kk} = 0 \quad \text{for } k > p \\ \phi_{pp}(\neq 0) = 0 \quad \text{for } k = p, \quad (8A.8)$$
```

is analogous to the property in Equation 8A.1 satisfied by the autocorrelations for an MA(q) process.

Before proceeding note that there is no another definition of the partial autocorrelation from which it derives its name. $\phi_{kk}$ is the correlation between $X_t$ and $X_{t-k}$ in the bivariate distribution of $X_t$ and $X_{t-k}$ conditional on $X_{t+1}, X_{t+2}, \dots, X_{t+k-1}$. For more discussion, see Brockwell and Davis (1991).

In practical situations, identification of $p$ will be based on estimates of $\phi_{kk}$. These estimates can be obtained by any estimation procedures (e.g., Yule-Walker, Burg, and MLE) for estimating the parameters of an AR(k) model. It is common practice to plot autocorrelation estimates based on Yule-Walker estimates which are easily obtained using the Durbin-Levinson recursion in Equation 79. ## 8A.3 Box–Jenkins Procedure for ARMA Model Identification

The classical Box-Jenkins procedure (see Box et al., 2008) for identifying the patterns p and q of an ARMA(p,q) process identifies patterns exhibited by autocorrelations and partial autocorrelations. While these functions provide perfect identification for MA(q) and AR(p) models when true quantities are known, the identification of ARMA(p,q) processes is more problematic. The Box-Jenkins identification patterns are shown in Table 8A.1, and their use recognizing behavior exhibited by solutions to difference equations. For example, the autocorrelations, $\rho_k$, of an ARMA(p,q) process satisfy a linear difference equation with constant coefficients for k>q. The Box-Jenkins procedure is based on the fact that the functional form of the solution is satisfied by $\rho_k$ for k>q-p. Unfortunately these types of patterns do not provide perfect identification even when true quantities are known, and model identification is even more difficult when only the sample autocorrelations and sample partial autocorrelations are available.
