## Appendix 8A: Model Identification Based on Pattern Recognition

In this appendix, we discuss techniques for identifying model orders on the basis of pattern recognition. We have already discussed one example of this technique for white noise checking. Section 8.1, we examined sample autocorrelations with respect to whether they behaved consistently

with the theoretical behavior for a white noise process, that is, $\rho_0 = 0, k \neq 0$. In this appendix, we will discuss the classical Box–Jenkins procedure of looking for patterns in autocorrelations and partial autocorrelations. We then discuss the generalized partial autocorrelation introduced by Woodward and Gray (1981) which is a natural generalization of the Box–Jenkins approach.

### 8A.1 Patterns in the Autocorrelations

Consider the autocorrelations of an MA($q$) process which from Equation 3.4 have the form

```
$$\rho_k = 0 \text{ for } k > q \neq 0 \text{ for } k = q. \quad (8A.1)$$
```

The behavior described in (8A.1) uniquely determines the order $q$ of an MA($q$) process if the true autocorrelations are known. Then, sample autocorrelations that are near zero for $k > q$ while $\hat{\rho}_k \neq 0$ suggest an MA($q$) as a possible model. From Bartlett’s (1946) approximation in Equation 1.22 it follows if $X_i$ is an MA($q$) process then,

$k > q$. Further, since $E[\hat{\rho}_k] = 0$ for $k > q$, a rough guide is that

```
$$|\hat{\rho}_k| > 2\sqrt{\frac{1+2\sum_{v=1}^{q}\rho_v^2}{n}} \quad (8A.2)$$
```

for $k > q$, then this is evidence against an MA($q$) at the $\alpha=0.05$ level of significance. Thus, if an MA($q$) is to be considered the model, then $\hat{\rho}_k$ for $k > q$ should essentially remain within the limits specified by Equation 8A.2. However, as the test for white noise, the quoted significance level applies for each $k$ so that it will not be unusual to observe a small percentage of $\hat{\rho}_k, k \geq q$, outside the specified limits when the model is an MA($q$). It should be noted that when $X_i$ is white noise, that is, $X_i$ is MA($q$) with $q=0$, then the summation in Equation 8A.2 is taken to be zero, and Equation 8A.2 reduces to 8.1.

### 8A.2 Patterns in Partial Autocorrelations

It was shown in Section 3.2 that the autocorrelations of an AR(p) process behave like a mixture of damped exponentials and/or sinusoids depending on the roots of $\phi(z)=0$. As a consequence, examination of the autocorrelations does not provide sufficient information to identify model orders if the true partial autocorrelation function has been widely used as a supplement to the autocorrelations for purposes of identifying the order of AR(p) models.

Suppose $X_t$ is a stationary process with autocorrelations $\rho_j$, $j=0, 1, 2, \dots$, and consider the following system of equations:

```
\rho_1 = \phi_{k1}\rho_0 + \phi_{k2}\rho_1 + \cdots + \phi_{k,k-1}\rho_{k-2} + \phi_{kk}\rho_{k-1}
\rho_2 = \phi_{k1}\rho_1 + \phi_{k2}\rho_2 + \cdots + \phi_{k,k-1}\rho_{k-3} + \phi_{kk}\rho_{k-2}
\vdots
\rho_k = \phi_{k1}\rho_{k-1} + \phi_{k2}\rho_{k-2} + \cdots + \phi_{k,k-1}\rho_1 + \phi_{kk}\rho_0, \quad (8A.6)
```

where $\phi_{ik}$ denotes the $i$th coefficient associated with a $k \times k$ system. The partial autocorrelation function is defined to be $\phi_{kk}$, $k=1, 2, \dots$, and an expression for $\phi_{kk}$ can be obtained by using Cramer’s rule to solve Equation 8A.6. That is,

```
\phi_{11} = \rho_1,
\phi_{22} = \frac{|\begin{smallmatrix} \rho_0 & \rho_1 \ \rho_1 & \rho_2 \end{smallmatrix}|}{|\begin{smallmatrix} \rho_0 \end{smallmatrix}|}
```
