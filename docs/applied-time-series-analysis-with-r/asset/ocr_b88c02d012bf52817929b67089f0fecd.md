# 8.2.1 Model Identification Based on AIC and Related Measures

AIC is a general criterion for statistical model identification in multivariate regression and, in our case, identifying $p$ and $q$ in an ARMA($p,q$) model. ML estimation is a common tool that applies to a model or class of distributions with fixed set parameters, $a_t, \dots, a_k$. In this setting, the ML estimators $\hat{a}_1, \dots, \hat{a}_k$ maximize the likelihood function. However, simply maximizing the likelihood is not an appropriate strategy when parameters are being added to an existing model. For example, suppose ML methods are used to choose between a model with $k$ parameters (e.g., AR(k)) and a model from the same class with $k+1$ parameters, for example, an AR(k+1). Consider the strategy of maximizing the likelihood under each scenario and selecting the model with the maximized likelihood. This would always select the AR(k+1) model.

```
$L_{MAX}(\hat{a}_1, \dots, \hat{a}_k) \leq L_{MAX}(\hat{a}_{k+1}, \dots, \hat{a}_{k+1}),
```

where $\hat{a}_j$ denotes the ML estimator of $a_j$ for a model with $m$ parameters. To note, when Equation 8.2 is used, there are $k+1$ parameters, for which $\hat{a}_{k+1}=0$. The maximized likelihood on the left-hand side of Equation 8.2 is based on the constraint that $\hat{a}_{k+1}=0$ while the right-hand side is maximized without this constraint. AIC addresses this problem in the ARMA case by imposing a penalty for adding parameters. The method is based on selecting the $p$ and $q$ that minimize the expected Kullback–Leibler distance between the true underlying model of the data and ARMA($p,q$) fit to the data where $0 \leq p \leq P$ and $0 \leq q \leq Q$.
