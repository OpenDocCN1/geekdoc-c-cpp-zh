close to -1. We conclude that $(1-B)(1-B^2)$ is appropriate as the non-stationary component of the final ARUMA$(p,d)$ model fit to the data.
The next step is to transform the data by $(1-B)(1-B^2)$ which can be accomplished by differencing the data to obtain $Y_i = X_i - X_{i-1}$ and by applying the transformation $Z_i = Y_i - Y_{i-2}$ to the differenced data. The data set, $Z$, (which is shown in Figure 8.9c), has 144–131 data values and should be modeled as a stationary process. The autocorrelations of $Z$, and are consistent with the autocorrelations of a stationary process. Using AIC with $P=16$ and $Q=4$, an ARMA$(12,1)$ and an AR$(13)$ are the top two models. Using the ARMA$(12,1)$ fit to the transformed data we model

```
$$(1-B)(1-B^2)\phi(B)(X_i-5.54) = \theta(B)_n, \quad (8.29)$
```
