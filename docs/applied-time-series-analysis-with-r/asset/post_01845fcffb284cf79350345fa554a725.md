## Appendix 1B: R Commands

As mentioned in the Preface you should install and load the R command library `tswage`. Some of the commands listed here are simply R commands that do not require the installation of a special library. These will be noted as Base R commands. Commands that perform the computations and plot results associated with topics covered in Chapter 1 fall into two categories:

- 1. Basic computations and plots
- 2. "Combination routines" that provide graphical output of related plots for pedagogical purposes

For example, `plot.sample.wege` plots a realization, sample autocorrelations, periodogram, and smoothed periodogram by the Parzen window. Examination of these four plots is a typical step in understanding the features of a time series realization.

- 1. Basic Computation Routines for Chapter 1
  a. `mean(x)` (base R function): calculates the mean of a time series realization where x is a vector containing the time series realization $x_t, t=1,\dots,n$.
     Example: The basic R command
     `data(ss08); ssm = mean(ss08)`
     calculates the sample mean of the sunspot data in `tswage` data set ss08 and places it in variable ssm. In this case $ssm = 52.24385$.

- acf(x, lag.max, type, plot) (base R function): calculates (and optionally plots) the sample autocorrelations (or sample covariances and sample variance) of the time series realization where x is a vector containing the time series realization, t = 1, ..., n. lag.max is the maximum lag at which to calculate the sample autocorrelations (or covariances) type="correlation" (default) produces the sample autocorrelations, "covariance" specifies the autocovariances, and "partial" indicates the partial autocorrelations (discussed in Chapter 8).
