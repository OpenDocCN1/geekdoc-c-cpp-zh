## 7.7 ARMA Spectral Estimation

In 1.25 and 1.26, we defined the power spectrum and the spectral density of a stationary process, and in Section 1.6, we discussed the periodogram, sample spectrum, and smoothed versions of these quantities as methods for estimating the spectrum and spectral density. In this section, we discuss the method of ARMA spectral estimation, which is based on the spectral density of an ARMA(p,q) process shown in the following (and earlier in Equation 3.92) by

```
$S_X(f) = \frac{\sigma_\epsilon^2 |1 - \theta_1e^{-2\piif} - \dots - \theta_qe^{-2\piif}|^2}{|1 - \phi_1e^{-2\piif} - \dots - \phi_pe^{-2\piif}|^2} \cdot . $
```

The ARMA spectral density estimator based on an ARMA(p,q) fit to a set of data (using any parameter estimation technique) is simply the spectral density

associated with the fitted model. That is, the ARMA spectral density estimator is given by

```
$$\hat{S}_X(f)=\frac{\hat{\sigma}_{\epsilon}^{2}}{2\pi} \left|\frac{1-\hat{\theta}_1e^{-2\pi if}-\hat{\theta}_2e^{-4\pi if}-\dots-\hat{\theta}_qe^{-2q\pi if}}{1-\hat{\phi}_1e^{-2\pi if}-\hat{\phi}_2e^{-4\pi if}-\dots-\hat{\phi}_qe^{-2q\pi if}}\right|^{2} \quad (7.74)$$
```

We will use the generic term ARMA spectral estimator to indicate either the spectrum or spectral density based on the fitted model. Clearly, the ARMA spectral estimator for a set of data will be only as good as the parameter estimates, and thus care must be taken in parameter estimation. Note that ARMA spectral estimators based on AR(p) fits are often called AR spectral estimators.

The ARMA spectral density estimator has an inherent smoothness. Increasing the orders $p$ and $q$ of a model fit, the corresponding spectral density becomes less smooth, similar to the manner in which increasing the truncation point $M$ in the spectral estimates Chapter 1 produces spectral estimators that are less smooth. Thus, choosing orders $p$ and $q$ that are too high may produce estimators that lose important detail, while using orders that are too high and $q$ (to be discussed in Chapter 8) is an important step in the modeling process.

Using R: In tswge function arma.spec.wge you can specify a model and the function outputs a plot of the true (log) spectral density along with frequencies as part of the output. In order obtain ARMA spectral estimates, you can use this function by entering the estimated coefficients as the “true model." Function plots.wge also plots the spectral density values.
