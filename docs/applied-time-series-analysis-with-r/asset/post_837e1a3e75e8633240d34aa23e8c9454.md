## 2. 2-factor GARMA model

A realization of $n = 500$ was generated from the 2-factor GARMA model

$$(1-0.5B)(1-1.6B+B^2)^{0.45}(1+1.6B+B^2)^{0.3}X_i = a_i. (11.31)$$

Thus, $\varphi_0 = 0.5, u_1 = 0.8, \hat{\lambda}_1 = 0.45, u_2 = -0.8, \hat{\lambda}_2 = 0.3,$ and $\mu = 0$. The realization, sample autocorrelations, and Parzen spectral density estimate are shown in Figure 11.13 where it can be seen that the Parzen spectral density has two peaks at approximately 0.1 and 0.4, suggesting $\hat{u}_1 = 0.8$ and $\hat{u}_2 = -0.8$. Based on a grid-search restricting possible values of $\hat{u}_1$ and $\hat{u}_2$ to neighborhoods of 0.8 and $-0.8,$ respectively, $\hat{\lambda}_1$ and $\hat{\lambda}_2$ each range between 0.2 and 0.45, and $p \le 2$ with $q=0$ the model associated with the minimum AIC is

$$(1-0.52B)(1-1.6B+B^2)^{0.35}(1+1.6B+B^2)^{0.3}[X(t)-\bar{X}]=a(t),$$

which is close to the true model.

## EXAMPLE 11.9: FITTING FARMA AND GARMA MODELS TO REAL DATA

In this example we estimate the parameters for flow data over years, to fit the Nile flow data in Figure 11.5a and the log-yx data in Figure 11.5b.

- 1. Since the Nile flow data are traditionally modeled using fractional FARMA, we use function est.farma. we allow $d$ to range from 0 to 0.5 in increments of 0.001, we allow AR orders up to $p=3$ and restrict our attention to FARMA models without MA components, that is, $q=0$. The function est.gamma selects $p=0$ and $d=0.37$. See Appendix 11A for specific statements used to orient the estimates. This estimate is consistent with those using CRAN package fracdiff which fits ML estimates, $d=0.364$.
- 2. Since the log-yx data have a period over 10 years, we focus our search for $u$ in a neighborhood of 0.8. Using est.gamma and letting $u$ range from 0.4 to 1.2 in increments of 0.001, letting $\lambda$ range from 0 to 0.5 in increments of 0.01, letting $j$ range from 0 to 3, and setting $q=0$, we obtain model $(1-0.51B)(1-0.796B+B^2)^{0.4}(X_i-\tilde{X})=a_i,$ $\hat{\sigma}_\gamma^2=0.045$. See Appendix 11A for further details about est.gamma.

## 11.6 Forecasting Based on the k-factor GARMA Model

In this section we consider the problem of forecasting using the $k$-factor GARMA model. While the use of the difference equation provides easy-to-use forecasts the case of the ARMA and ARIMA models using Equations 6.24 and 6.36, respectively, this method is not suitable for GARMA because there is no finite-order difference equation for $\prod_{i=1}^k(1-\mu_i+B^2)$. Brockwell and Davis (1991) use the $\pi$-weights version of the classical Box-Jenkins (see Section 6.4) to forecast the FARMA process $(1-B)^d(X_t-\mu)_t$, and Woodward et al. (1998) use this method for forecasting based on a $k$-factor GARMA model. The $\pi$-weights of the $k$-factor GARMA model can be calculated using the identity

$$\sum_{m=0}^{\infty} \pi_m B^m = \theta^{-1}(B)\phi(B) \prod_{j=1}^{k} (1-2u_jB+B^2)^{\lambda_j}$$
$$\theta^{-1}(B)\phi(B) \prod_{j=1}^{k} \sum_{h=0}^{\infty} C_h^{(c-\lambda_j)}(u_j)B^h.$$

The truncated form (assuming only the data $X_1,...,X_{t_0}$ are available) is given

$$\hat{X}_t(\ell) = \bar{X} - \sum_{j=1}^{k} \pi_j (\hat{X}_{t-j}(\ell-j)-\bar{X}). (11.32)$$

In Section 6.4 we noted that forecasts based on Equation 11.32 the $\pi$ are sufficiently close to zero for $j>t_0-1+\ell$. This will be the case for most ARMA models and for $t_0$ of moderate size. However, for long-memory models, the $\pi$-weights damp very slowly which can cause the truncation in 11.32 to have a substantial effect. Information concerning the relationship between the best linear prediction (based on available data) and forecasts using the truncated $\pi$-weights in the context of fractal and FARMA models and GARMA models, see Miller (1994) and Fu (1995). (See also Ferrara and Gutierrez, 2001.)

Using R: The tseries package contains two functions for producing forecasts from long-memory models: fore.arma.wge and fore.gar.wge. For more details see Appendix 11A.
