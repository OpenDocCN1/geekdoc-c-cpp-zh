introduced a general class of memoryless transformations that have been used on time series data. For a given $\lambda$, such that $0 < \lambda \le 1$, the transformation is specified by

```
$Y = \frac{X_t^2 - 1}{\lambda}$.
```

The logarithmic $\lambda$ transformation applied to the airline data is a limiting case of this class as $\lambda \to 0$, along with the square root (a scaled version of Equation 1.310 when $\lambda=1/2$) are among the more popular transformations of this type. It should be noted that in order to apply the logarithmic, square root, or any other of the Box-Cox transformations, it is necessary that $x_t > 0, t=1, n$.

**Using R:** If $x$ is a vector containing a time series realization (with positive values) then base R functions as $y = \log(x)$, $y = \log10(x)$, or $y = \sqrt(x)$ can be used to perform memoryless transformation on the realization.

# 3.7.2 AR Transformations

A second type of transformation, referred to here as an AR *transformation*, is also useful. Consider the AR(1) model

```
$$(1-0.95B)X_t = a_t,$$
```

and let $Y_t$ be defined by

```
$Y_t = X_t - 0.95X_{t-1}$\
= (1-0.95B)X_t.$
```

It follows that $Y_t$ is white noise

```
$Y_t = (1-0.95B)X_{t-1}$\
= a_t.$
```

Thus, the AR model itself can be viewed as a transformation to white noise or as a “whitening filter”. In fact, this is one of the primary applications of the AR model. Note that application of transformation in Equation 3.311 to a realization of length $n$ produces a “new” realization of length $n-1$ given by

```
$Y_1 = X_2 - 0.95X_1$\
$Y_2 = X_3 - 0.95X_2\
$\vdots$
$Y_{n-1} = X_n - 0.95X_{n-1}.$
```
