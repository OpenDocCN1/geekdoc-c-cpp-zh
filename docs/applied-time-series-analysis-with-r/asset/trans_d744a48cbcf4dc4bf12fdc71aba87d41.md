## 11.8 使用长记忆模型对大气 CO2 数据建模

图 11.15a 显示了从 1958 年 3 月到 1989 年 12 月夏威夷马纳洛亚山顶的 382 个每月大气 CO2 读（Keeling 等，1989）。CO2 数据在这一 31 年 10 个月的时间范围内显示出明显的增长趋势。仔细检查 CO2 水平可以发现，CO2 水平存在年度模式，可能在夏季较高，在冬季较低。图 11.1b 和 c 显示了通过 Parzen 窗口（截断点 $M = 50$）估计的样本自相关和谱密度。显然，样本自相关系数衰减非常缓慢，谱密度中存在三个明显的峰值。作为数据建模的第一步，我们使用了第 3 章中讨论的过拟合程序，并拟合了一个 AR(16) 模型，其相关因子见表 11.3。对其他模型也进行了检验，结果与观测到的结果一致。三组频率为 0.084、0.167 和 0.001 的复共轭根非常接近单位圆。前两个对应于 12 个月和 6 个月的周期 ($1/0.084 \approx 12$，$1/0.167 \approx 6$），而第三对对应于长周期，或者更说是单位根。我们将使用 k 因子 GARMA 来拟合这些具有长记忆或非平稳特征的数据。由于这些是月数据且存在某些年度变化，考虑到上升趋势，建议使用形式为 $1 - B^{12}$ 或 $(1 - B)^2$ 的因子。然而，将表 11.3 中的因子表与表 5.5 中 $1 - B^{12}$ 的因子表对比发现，虽然预期的 $1 - B^{12}$ 相关的因子是可见，但表 11.3 中的前三个因子比其他因子更接近单位圆。这与表 8.5 中对数航空数据的因子表不同，后者显示 $(1 - z)(1 - z^{-2}) = 0$ 的根距离单位圆的距离大致相等。

我们得出结论，“航空公司模型”（即包含因子 $(1 - B - B^2)$ 的模型）不适用于这些数据。

由于表 11.3 中的因子表强烈暗示了存在两个正单位根，我们通过对数据进行二阶差分开始建模。二阶差分数据及相关的自相关系数如图 11.16a 和 b 所示。图 11.16b 显示二阶差分数据的样本自相关系数呈现两个正弦分量缓慢衰减的形式。这表明可以使用一个 2 因子 GARMA 模型，我们将继续使用该模型对数据进行建模。表 11.3 中靠近单位圆的根对应的两个频率为 0.084 和 0.166。对于年度周期，我们使用 $f_1 = 1/12$ 和 $f_2 = 1/6$。得到 $u_1 = \cos(2\pi f_1) = \cos(\pi/6) = 0.866$ 和 $u_2 = 0.5$。然后我们将考虑包含 Gegenbauer 因子 $(1 - 1.732B + B^2)^{k_1}$ 和 $(1 - B + B^2)^{k_2}$ 或非平稳 ARMA 因子 $1 - 1.732B + B^2$ 和 $1 - B + B^2$ 的模型。注意两次差分使用了因子 $(1 - B)^2$ 应用于数据。因此，该数据的 2 因子 GARMA 模型给出：
$$\phi(1-B)^2(1 - 1.732B + B^2)^{k_1}(1 - B + B^2)^{k_2}(X_t - \mu) = \theta(B), \quad (11.3)$$
其中 $\phi(B)$ 和 $\theta(B)$ 的阶分别为 $p$ 和 $q$。Woodward 等（1998）检查了 MLE 估计并使用 $\hat{\lambda}_1 = \hat{\lambda}_2 = 0.49$，这是消除长记忆 12 个月周期的最佳方法。数据通过 $(1-B)^2(1-1.732B+B^2)^{0.49}(1-B+B^2)$ 进行转换，通常识别技术为转换数据选择了 AR(7)。该组的最终 2 因子 GARMA 模型为：
$$(1 - 1.732B + B^2)^{0.49}(1 - B + B^2)^{0.49}\phi(B)(X_t - \bar{X}) = a_t,$$
其中 $\phi(B)$ 代表 Burg 估计值：
$$\hat{\phi}(B)=1+2.32B+3.23B^2+3.52B^3+3.24B^4+3.27B^5+3.25B^6-3.31B^7+3.29B^8+3.09B^9+2.86B^{10}+2.54B^{11}+1.83B^{12}+0.91B^{13}+0.17B^{14}-0.21B^{15}-0.20B^{16}-0.08B^{17},$$
其中 $\bar{X}=2.57$ 且 $\hat{\sigma}_2^2=1.5。基于该模型的最后 60 个月预测值如图 11.15a 中的实际值所示。可以看到预测结果非常好，维持了数据中的周期和上升趋势。

作为 $\text{CO}_2$ 数据的替代模型，我们考虑表 11.3 因子表建议的 ARUMA(11,6,0) 过程。通过六阶非平稳因子 $(1-B)(1-1.732B+B^2)(1-B+B^2)$ 转换的数据建模为 AR(11)，基于 Burg 估计的 $\phi_t(B)$ 给出：
$$\hat{\phi}(B)=1+3.64B+6.99B^2+8.92B^3+7.84B^4+4.07B^5-2.28B^6-2.99B^7-2.14B^9-0.90B^{10}-0.20B^{11}.$$

图 11.17b 显示了图 11.17a 中考虑的 60 个观测值的预测。基于方程 11.34 的预测与数据具有相同的周期行为，但在一个或两个周期后未能遵循上升趋势。Woodward 等（1998）考虑在这种情况下使用 AR(17) 对转换数据进行建模，相应的预测效果优于通过 AR(11) 获得的。Woodward 等（1998）显示，对于该数据集，ARUMA 模型在短期预测中 SME 较小，而基于 2 因子 GARMA 模型的预测在长期表现更好。

## 附录 11A: R 命令

### 11A.1 第11 章的基础计算和绘图程序

- a. `true.farma.aut.wge(d,phi,theta,lag.max,vara,trunc)` 计算与方程 11.5 形式的固定 GARMA 模型相关的真实自相关系数和协方差。
  - d 是分数差分参数方程 11.6
  - phi 是 AR 参数向量（符号与本文一致）
  - theta 是 MA 参数向量（符号与本文一致）
  - lag.max 是计算自相关系数和协方差的最大滞后阶（默认值 25）
  - vara 是白噪声方差（默认值 1）
  - trunc 是 FARMA 协方差无穷级数展开中的截断点（默认值 1000）。参见 Hosking (1981) 中定理 2.4 的证明。
  - plot 是逻辑变量：TRUE（默认） = 绘制自相关系数，FALSE = 不绘制

- 该函数输出：
  - acf（滞后 0 到 lag.max 的真实自相关系数）
  - acv（滞后 0 到 lag.max 的真实协方差）

注意：

- 1. 如果你知道 AR 或 MA 模型的因子而不是系数，可能想使用实用函数 `mult.wge`。
- 2. $\max(p,q+1) \le 25$
