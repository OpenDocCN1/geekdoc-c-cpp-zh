### 3.2.2 Invertibility/Infinite-Order AR Processes

We have seen that under certain conditions, a stationary AR(p) process can be written in the form of a general linear process, that is, an infinite-order MA. A question of interest arises concerning when an MA(q) process can be expressed as an infinite-order AR process. In operator notation, the question is, “When can $X_t=\theta(B)a_t$, be written as $\theta^{-1}(B)X_t=a_t$? If we expand $\theta^{-1}(z)$ in powers of $z$ as

```
$$\theta^{-1}(z) = \sum_{j=0}^{\infty}\pi_j z^j$$
```

and proceed formally to define $\theta^{-1}(B)$ by replacing $z$ by $B$ in Equation 3.82, then application of the operator term by terms yields

```
$$\sum_{j=0}^{\infty}\pi_j X_{t-j} = a_t$$
```

which is a process of infinite AR form.

### Definition 3.4

If an MA(q) process $X_t$, can be expressed in Equation 3.83 with $\sum_{j=0}^{\infty}|\pi_j|<\infty$, then $X_t$, is said to be invertible.

The condition $\sum_{j=0} |\pi_j| < \infty$ assures that $\sum_{j=0} \pi_j X_{t-j}$ is mean square convergent (see Theorem 3.1). The following theorem provides necessary and sufficient conditions for an MA($q$) process to be invertible.

### Theorem 3.3

Let $X_t$ be the MA($q$) process $X_t = \theta(B)a_t$. Then $X_t$ is invertible if and only if the roots of $\theta(z) = 0$ all lie outside the unit circle.

Proof: See Appendix 3B.

In order to determine whether or not a MA($q$) process is invertible, we recommend examining a factor table in which the factors of $\theta(B)$ are given.

**Using R:** Factor tables for MA components can be obtained as in the AR case by using the tswge function factor.wge. See Appendix 3B.

### 3.2.13 Two Reasons for Imposing Invertibility

When using an MA($q$) model to analyze time series data, we restrict our attention to invertible models. There are two main reasons for this restriction.

- 1. Invertibility assures that the present events are associated with the past in a sensible manner: We rewrite the MA(1) model in Equation 3.9 with $\mu=0$ in the form $a_t = X_t + \theta_{t-1}$. Using this form of the model, it follows that $a_{t-1} = X_{t-1} + \theta_{t-1}a_{t-2}$ so that

```
$a_t = X_t + \theta_{t-1}(X_{t-1} + \theta_{t-1}a_{t-2})$
$= X_t + \theta_{t-1}X_{t-1} + \theta_{t-1}^2a_{t-2}$
$= X_t + \theta_{t-1}X_{t-1} + \theta_{t-1}^2X_{t-2} + \theta_{t-1}^3a_{t-3}$.
```

Continuing, we obtain $a_t = X_t + \theta_{t-1}X_{t-1} + \theta_{t-1}^2X_{t-2} + \cdots + \theta_{t-1}^kX_{t-k}$

```
$X_t = -\theta_{t-1}X_{t-1} - \theta_{t-1}^2X_{t-2} - \cdots - \theta_{t-1}^kX_{t-k} + \theta_{t-1}^ka_{t-k} - \theta_{t-1}^{k+1}a_{t-k-1}. \quad (3.84)$
```

If $|\theta_1| > 1$ the process is not invertible and Equation 3.84 shows that in this case, $X_t$ is increasingly dependent on the past. For most problems, this is not a practically acceptable model.

- 2. Imposing invertibility removes model multiplicity: We again consider the MA(1) model in Equation 3.9. From Equation 3.11, the autocorrelation function, $\rho_k$ is zero for $k > 1$ and for $k = 1$ is given by $\rho_1 = -\theta_1/(1 + \theta_1^2)$. Now consider the MA(1) process given by

```
$X_t = \left(1 - \frac{1}{\theta_1}B\right)a_t. \quad (3.85)$
```

For the process in Equation 3.85, it follows that $\rho_k = 0, k > 1$, and $\rho_1$ is given by

```
$\rho_1 = \frac{-1/\theta_1}{1 + 1/\theta_1^2} = \frac{-\theta_1}{1 + \theta_1^2}. \quad (3.85)$
```

Thus, for example, if $\theta_1 = 0.5$, then the two MA(1) processes $X_t = (1-0.5B)a_t$ and $X_t = (1-2B)a_t$ have the same autocorrelations. Notice, that only $X_t = (1-0.5B)a_t$ is invertible. In general, if $\rho_k, k=1, 2, \dots$ are the autocorrelations of an MA(q) process, there are several different MA(q) processes having these autocorrelations, but only one of these is invertible (see Problem 3.8). Thus, by restricting attention to invertible MA(q) processes, a unique model is associated with a given set of MA(q) autocorrelations.

### 3.3 ARMA Processes

In this section, we combine the definitions of MA(q) and AR(p) processes to define the ARMA(p,q) model, that is, the ARMA model of orders $p$ and $q$.

### Definition 3.5

Suppose $[X_t, t=0, \pm1, \pm2, \dots]$ is a causal, stationary, and invertible process satisfying the difference equation

```
$X_t - \mu = \phi_1(X_{t-1}-\mu) - \dots - \phi_p(X_{t-p}-\mu) = a_t - \theta_1 a_{t-1} - \dots - \theta_q a_{t-q}. \quad (3.86)$
```

which in operator notation is $\phi(B)(X_t-\mu) = \theta(B)a_t$, where $\phi(B)$ and $\theta(B)$ have no common factors, $\theta_q \neq 0$ and $\phi_p \neq 0$. Then, $X_t$ will be called an ARMA process of order $p$ and $q$.

As before, without loss of generality, we will let $\mu=0$. It is clear that the ARMA$(p,q)$ models contain MA$(q)$ and AR$(p)$ processes as special cases with $p=0$ and $q=0$, respectively. When $p \neq 0$ and $q \neq 0$, the resulting model is sometimes referred to as a mixed model.

An ARMA$(p,q)$ process can formally be written in the general linear process form, that is, the infinite-order MA

```
$X_t = \phi^{-1}(B)\theta(B)a_t = \psi(B)a_t, \quad (3.87)$
```

and as an infinite-order AR

```
$\theta^{-1}(B)\phi(B)X_t = a_t. \quad (3.88)$
```

Theorem 3.4 will give conditions under which the forms in Equations 3.87 and 3.88 are valid.

The reason for the requirement is that there are no common factors in the definition of an ARMA$(p,q)$ process can be illustrated using the model

```
$(1-0.8B)X_t = (1-0.8B)a_t. \quad (3.89)$
```

The model in Equation 3.89 can be expressed

```
$X_t = (1-0.8B)^{-1}(1-0.8B)a_t = a_t$,
```

so that $X_t$ in Equation 3.89 is white noise. Whenever $\phi(B)$ and $\theta(B)$ share common factors, the model $\phi(B)X_t = \theta(B)a_t$, can be reduced in a similar manner to a lower-order model.

It will be demonstrated in the following material that the AR and MA components, that is, $\phi(B)$ and $\theta(B)$, of an ARMA$(p,q)$ model introduce characteristics into the model of the same type as those in the AR$(p)$ or MA$(q)$ models separately. Some of these characteristics may be apparent in the ARMA$(p,q)$ model. On the other hand, as should be clear from the preceding white noise example, some of the individual characteristics may not be apparent due to near cancellation, etc.
