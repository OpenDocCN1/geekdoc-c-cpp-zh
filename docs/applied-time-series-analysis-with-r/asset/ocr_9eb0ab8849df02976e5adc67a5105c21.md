# 3.3 ARMA Processes

In this section, we combine the definitions of MA(q) and AR(p) processes to define the ARMA(p,q) model, that is, the ARMA model of orders $p$ and $q$.

# Definition 3.5

Suppose $[X_t, t=0, \pm1, \pm2, \dots]$ is a causal, stationary, and invertible process satisfying the difference equation

```
$X_t - \mu = \phi_1(X_{t-1}-\mu) - \dots - \phi_p(X_{t-p}-\mu) = a_t - \theta_1 a_{t-1} - \dots - \theta_q a_{t-q}. \quad (3.86)$
```
