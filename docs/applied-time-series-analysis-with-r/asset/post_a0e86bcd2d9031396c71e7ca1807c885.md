# 13.4 Linear Chirp Processes

Linear chirp processes have applications in fields such as sonar, radar, and optics. Linear chirp processes are named because they behavior changes linearly with time. The data in Figure 12.2a are from a linear chirp process, and the time–frequency plots in Figure 12.4 illustrate the linear change in frequency. In this section, we make use of the fact that linear chirp processes are G-stationary processes with $g(t) = at^2 + bt + c$. Without loss of generality, we take $c=0$. Then we $u=at^2+bt=g(t)$. So, for $at^2+bt-u=0$, it follows

```
t = \frac{-b \pm \sqrt{b^2 + 4au}}{2a}
g = g^{-1}(u),
```

and

```
g^{-1}(g(t) + g(\tau)) = \frac{-b \pm \sqrt{b^2 + 4a(g(t) + g(\tau))}}{2a}\n\frac{-b \pm \sqrt{(2at+b)^2 + 4ag(\tau)}}{2a}
```

This leads to the following definition given by Robertson et al. (2010).

# Definition 13.9

A continuous parameter stochastic process, $X(t)$, is called a generalized linear chirp (GLC) if

+   1. $E[X(t)] = \mu < \infty$,
2. $Var[X(t)] = \sigma^2 < \infty$,
3. $E[X(t) - \mu)(X(g^{-1}(t) + g(t)) - \mu)] = R_x(\tau)$,

where $g(t) = at^2 + bt$, with $a, b \in \mathbb{R}$ and

```
$g^{-1}(t) + g(t) = \frac{-b + \sqrt{(2at+b)^2 + 4ag(t)}}{2a}, t \geq \frac{-b}{2a}\n\frac{-b - \sqrt{(2at+b)^2 + 4ag(t)}}{2a}, t < \frac{-b}{2a}$.
```

# EXAMPLE 13.12: A GLC PROCESS

Let

```
$X(t) = A \cos(2\pi\beta(at^2 + bt) + \psi)
```

where $\psi$ is a uniform $[0, 2\pi]$ random variable. To see that $X(t)$ in Equation 13.21 is a GLC process, let $u = at^2 + bt = g(t)$. Then $Y(u) = A \cos(2\pi u + \psi)$ is a harmonic process as in Example 13.3. See $X(t) = X(g^{-1}(u)) = Y(u)$, it follows that

+   i. $E[X(t)] = E[Y(u)] = 0$
ii. $Var[X(t)] = Var[Y(u)] = \frac{A^2}{2}$
iii. $E[X(t)X(g^{-1}(t) + g(t))] = E[Y(u)Y(u + g(\tau))] = \frac{A^2}{2} \cos(2\pi\beta g(\tau))\n= C_x(g(\tau))\n= R_x(\tau)$

Therefore, $X(t)$ is a GLC process.
Figure 13.14a shows a realization of $X(t)$ with $A=1, \beta=1, a=1, b=1$, and $\psi=0$ over the time interval $[0,4]$, while Figure 13.14b shows the corresponding realization of $Y(u)$.

It should be clear that $X(t)$ in Example 13.12 is easily generalized. That is, it follows that

```
$X(t) = \sum_{k=1} A_k \cos[2\pi\beta_k(at^2 + bt) + \psi_k] + N(t), \quad (13.22)$
```

is a GLC process, where $\psi_k$ are independent uniform $[0, 2\pi]$ random variables, and $N(t)$ is uncorrelated normal noise independent of the $\psi_k$.

# 13.4.1 Models for Generalized Linear Chirps

In this section, we discuss AR-type models for GLC processes that are similar to the Euler(p) and G(p; \lambda) models. To begin the discussion, we define GLC white noise then define the GLC(p) model. As we proceeded formally assuming standard properties of the differential operator, $D$, since our purpose is to motivate the sampling scheme.

# Definition 13.10

Let $z(u)$ be zero mean white noise and let $u=at^2+bt, t > 0$. Then $\epsilon(t)=z(u)$ is defined as GLC white noise.

# Definition 13.11

Consider a process $\{X(t), t < -b/(2a) \text{ or } t > -b/(2a)\}$ defined by

```
$$\prod_{i=1}^{p} \frac{1}{2at+b}D-\alpha_i(X(t)-\mu)=\epsilon(t), \quad (13.24)$
```

where $D$ is a differential operator, $a, b \in (-\infty, \infty)$, $a \neq 0$ and the $\alpha_i$ are real or complex constants with $Re(\alpha_i) < 0, p > 0$, and $\epsilon(t)$ is GLC (zero) mean white noise. $X(t)$ is called a GLC(p) process. Note, if $a=0$ and $t \in (-\infty, \infty)$, then $X(t)$ is an AR(p) process.

The GLC(p) process extends to a GLC(q) process. (See Robertson et al., 2010.) Just as processes in Equations 13.21 through 13.23 are GLC processes, it can be shown that the GLC(p) and GLC(p,q) processes are also GLC processes and consequently are G-stationary as well. See Robertson (2008).

Note that if $u=at^2+bt$, then $du/dt=2at+b$. Consequently,

```
$$\begin{aligned} \frac{1}{2at+b}[D-\alpha]X(t)&=\frac{1}{2at+b}\frac{dX}{dt}-\alpha X(t) \=\frac{dX}{du}-\alpha X. \end{aligned} \quad (13.25)$
```

Proceeding formally one can show

```
$$\prod_{i=1}^{p} \frac{1}{2at+b}D_t-\alpha_i(X(t)-\mu)=\prod_{i=1}^{p}(D_u-\alpha_i)(Y(u)-\mu),$
```
