# **EXAMPLE 3.25: AN AR TRANSFORMATION IN WHICH $\alpha(B)$ IS A FACTOR OF $\phi(B)$**

Consider the AR(4) model previously discussed in Example 3.12. In fact, this model is given by $(1-0.95B)(1+0.8B^2)X_t = a_t$. In Figure $3.33a$ and $b$, we show a realization from this AR(4) model and the theoretical spectral density. These plots were also shown in Figure $3.18a$ and $3.33b$. In the factor table given in Table $3.3$, it can be seen that the factors, in order, are associated with system frequencies $f_0=0, 0.16$, and $0.5$, which is consistent with the spectral density. We now transform to $Y_t = \alpha(B)X_t = (1+0.8B^2)X_t$. In this case, it is seen that $Y_t$ satisfies the model $(1-0.95B)(1+0.8B^2)Y_t = a_t$, that is, the model is an AR (2).
