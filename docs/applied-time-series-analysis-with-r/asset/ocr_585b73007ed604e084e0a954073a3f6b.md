Applied Time Series Analysis with R

AR(2) Case: We begin the proof by showing the complete development for an AR(2) model and then discuss the extension to the general AR(p) case. We consider the AR(2) model

```
$$\phi(B)X_t = (1-\alpha_1B)(1-\alpha_2B)X_t = a_t,$$
```

where $\alpha_1$ and $\alpha_2$ are real or complex, $\alpha_i 
eq \alpha_j$ and $|\alpha_i| < 1, i=1,2$. Using $
abla$ to denote the operator $1-B$,

```
$$\alpha^t\nabla^{-1}X_t \equiv (1-\alpha B)X_t.$$
```

So,

```
$$
abla\left(\frac{\alpha_2}{\alpha_1}\right)^t\nabla^{-2}X_t = (1-\alpha_1B)(1-\alpha_2B)X_t,$$
```

and it follows that

```
$$
abla\left(\frac{\alpha_2}{\alpha_1}\right)^t\nabla^{-2}X_t = \alpha_1^{-t}a_t.$$
```

Then, summing both sides gives

```
$$\sum_{k=-\infty}^t\left(\frac{\alpha_2}{\alpha_1}\right)^k\nabla^{-2}X_k = \sum_{k=-\infty}^t\alpha_1^{-k}a_k,$$
```

so

```
$$
abla\left(\frac{\alpha_2}{\alpha_1}\right)^t\nabla^{-2}X_t - \lim_{k\to-\infty}\left(\frac{\alpha_2}{\alpha_1}\right)^k\nabla^{-2}X_k = \sum_{k=-\infty}^t\alpha_1^{-k}a_k,$$
```

and

```
$$\lim_{k\to-\infty}\left(\frac{\alpha_2}{\alpha_1}\right)^k\nabla^{-2}X_k = 0,$$
```

with probability 1. Thus,

```
$$
abla^{-2}X_t = \sum_{k=-\infty}^t\alpha_1^{-k}a_k,$$
```
