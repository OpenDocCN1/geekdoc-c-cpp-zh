在继续之前，我们注意到两点：

- 1. 对于实时间序列，$P(f)=P(-f)$，同样有 $S(f)=S(-f)$（问题 1.19a）。由于这个原因，真实数据的谱或谱密度图通常只针对 $f\geq 0$，如图 1.14 至图 1.16 所示。
- 2. 在图 1.16b 中，我们实际上在对数尺度上绘制了谱。这样做有两个原因：在这样的图中谱的次峰值更容易识别，且 $10\log_{10}S_X(f)$ 将纵轴单位设为分贝（dB），这是测量声能的标准单位，并在工程中被广泛使用。

# 1.6 估计离散时间序列的功率谱和谱密度

从数据中估计功率谱和谱密度可能是一个具有挑战性的问题，文献中有很多种估计技术。我们在此简要介绍该主题，但在后面的章节中会回来。给定离散参数时间序列的方程 1.29 中的谱，似乎可以通过简单将第 1.4 节讨论的样本自协方差代入方程 1.29 来得到一个自然的谱估计量。所得估计量被称为样本谱，定义在定义 1.14 中。

# 定义 1.14

$X$ 为定义在整数上的离散平稳时间序列。基于该时间序列长度为 $n$ 的实现的样本谱给出：

$$\hat{S}_X(f)=\hat{\sigma}_X^2+2\sum_{k=1}^{n-1}\hat{\rho}_k\cos(2\pi fk)$$

对于 $|f|\leq 0.5$。样本谱密度给出：

$$\hat{S}_X(f)=1+2\sum_{k=1}^{n-1}\hat{\rho}_k\cos(2\pi fk).$$

# 平稳时间序列

求和的极限 $n-1$ 是合理的，因为 $k \geq n$ 的样本自协方差和自相关定义为零。
相关的估计量是周期图，它仅仅是在基频 $f_1 = 1/n$ 的谐波处取值的样本谱。具体而言，谐波 $f_j$ 给出：

$$f_j = \frac{j}{n}, j=1,...,n$$
$$f_j = \frac{n}{2} (\text{若 } n \text{ 为偶数})$$
$$f_j = \frac{j}{n}, j=1,...,m (\text{若 } n \text{ 为奇数且 } n=2m+1).$$
