# Long-Memory Processes

f.fore.farma.wge(x,d,phi,n.ahead,lastn,plot)

This function forecasts n.ahead steps ahead based on FARMA model in Equation 11.6. See Section 11.6. For comparison, forecasts from an AR model fit to the data are also obtained.

x = realization

d = fractional difference

phi = vector of AR coefficients (default = 0)

n.ahead = the number of steps ahead you want to forecast (default = 2)

lastn = logical variable. If lastn = FALSE then the forecasts are for x(n+1), x(n+2), ..., where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization.

plot = logical variable. If plot = TRUE (default) then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output.

The function outputs

```
ar.fore.order (the order of the AR model fit to the data)
farma.fore (a vector containing the FARMA forecasts)
ar.fore (a vector containing the AR forecasts)
```

> NOTE: We assume the $q = 0$, that is, there is no moving average parameters.

Example:

Using the fractional model fit to the Nile data in the example related to est.farma.wge, (1 - B) $(X, -919.35) = a_u$, we obtain forecasts for the next 20 years using the model

```
test.ex = fore.farma.wge(Nile,d = .37,n.ahead = 20,lastn = FALSE,plot = TRUE)
```

It should be noted that fore.farma.wge plots forecasts for the FARMA model specified in the call statement with an AR model fit to the data (using ar.wy with $p \le 20$). In this case, an AR(2) model was selected. The code produces plots of the data along with FARMA and AR forecasts along with the following output:

```
test.ex$ar.fore.order is the order of the AR model fit to the data
test.ex$farma.fore is a vector containing the GARMA forecasts
test.ex$ar.fore is a vector containing the AR forecasts
```
