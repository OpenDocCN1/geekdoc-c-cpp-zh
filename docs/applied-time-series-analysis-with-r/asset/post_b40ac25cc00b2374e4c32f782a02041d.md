```
$\Psi_1 - \phi_1 =-\theta_1$
$\Psi_2 - \phi_1\Psi_1 - \phi_2 =-\theta_2$
:
$\Psi_j - \phi_1\Psi_{j-1} - \phi_2\Psi_{j-2} - \cdots =-\theta_j,\quad (3.116)$
```

where $\psi_0 = 1, \theta_0 = 0$ for $k > q, \phi_k = 0$ for $k > p$. The equations in Equation 3.116 can be rearranged to provide a recursive scheme for calculating the $\psi$-weights. Namely,

```
$\psi_1 = \phi_1 - \theta_1$
$\psi_2 = \phi_1\psi_1 - \theta_2$
:
$\psi_j = \phi_1\psi_{j-1} + \phi_2\psi_{j-2} + \cdots + \theta_j,\quad (3.117)$
```

Notice from Equation 3.117 that for $j > \max(p-1, q)$, $\psi_j$ satisfies the $p$-th order homogeneous difference equation

```
$\psi_j = \phi_1\psi_{j-1} + \phi_2\psi_{j-2} + \cdots + \theta_{j-p},\quad (3.118)$
```

or

```
$\phi(B)\psi_j = 0.$
```

- Finding $\psi$-weights using division: A very easy way to calculate a few $\psi$-weights is to use division based on the fact that properties of the operators, for example, $\phi(B)$ and $\theta(B)$, can be conveniently found using the algebraic equivalents $\phi(z)$ and $\theta(z)$. For example, we can express $\phi(B)X_t = \theta(B)X_t$, and the coefficients of the operator $\phi^{-1}(B)\theta(B)$ can be found using division based on the algebraic equivalent $\phi^{-1}(z)\theta(z) = \theta(z)/\phi(z)$. As an example, consider the ARMA(2,1) model $(1-1.6B+0.9B^2)X_t$. The $\psi$-weights are given by

```
$1-0.8z = \sum_{k=0}^{\infty} \psi_k z^k,$
```

where $\psi_0 = 1$. Shows that

```
$1-0.8z/1-1.6z+0.9z^2=1+0.8z+0.38z^2-0.112z^3\dots$
```

So, $\psi_1 = 0.8, \psi_2 = 0.38, \psi_3 = -0.112$, etc.


## 3.3.6 Approximating ARMA$(p,q)$ Processes Using High-Order AR(p) Models

We have discussed the fact that the stationary and invertible ARMA$(p,q)$ model $\phi(B)X_t = \theta(B)a$, can be written as the infinite-order AR process $\theta^{-1}(B)\phi(B)X_t$. Thus, an ARMA$(p,q)$ model can be well approximated using a high-order AR(p) model. For this reason, time series analysts use the approach of fitting AR models to data since parameter estimation and model identification to be more difficult when MA parameters are included in the model. On the other hand, some analysts prefer the ARMA$(p,q)$ model since it contains fewer parameters (is more parsimonious) than an AR model fit to the data set. In this text, we will cover parameter estimation, forecasting, etc., in the generality provided by the ARMA$(p,q)$ model. In practice, we will often restrict ourselves to AR(p) models.

An example of this trade-off between parsimonious ARMA$(p,q)$ model and a high-order AR(p) model is illustrated in Example 4.1, where theoretical justification is used to show that ARMA$(2,2)$ model is a good approximation for harmonic signal-plus-noise data. However, in that example, we also show that an AR(7) model also works as well as an approximating model.

## 3.4 Visualizing AR Components

Another useful tool for understanding the features of an AR(p) realization is the decomposition of the realization into additive components. Specifically, letting $x_t$ denote a realization from an AR(p) model for which there are no repeated roots of the characteristic equation, then $x_t = x_t^{(1)} + x_t^{(2)} + \dots + x_t^{(m)}$ where $m$, as given in Equation 3.76, is the number

of real roots plus the number of complex conjugate pairs of roots of the characteristic equation. The jth additive component $X_t^{(j)}$

- Corresponds to the jth factor in the factor table
- Is a realization of an AR(1) model for first-order factors
- Is a realization from an ARMA(2,1) model for irreducible second-order factors

For example, consider the AR(3) model

```
$(1-\alpha_B B)(1-\beta_B B-\beta_B^2)X_t = a_t,$
```

with one real root and one complex conjugate pair of roots (i.e., $m=2$). The model in 3.120 can be written in inverted form

```
$X_t = \frac{1}{(1-\alpha_B B)(1-\beta_B B-\beta_B^2)}a_t,$
```

Recalling that operators can be inverted using properties of the corresponding algebraic quantities, we use partial fractions to write

```
$\frac{1}{(1-\alpha_z z)(1-\beta_z z-\beta_z^2 z)} = \frac{A}{1-\alpha_z z} + \frac{C_1+C_2 z}{1-\beta_z z-\beta_z^2 z},$
```

from which we obtain

```
$X_t = \frac{1}{(1-\alpha_B B)(1-\beta_B B-\beta_B^2)}a_t = \frac{A}{1-\alpha_B B} + \frac{C_1+C_2 B}{1-\beta_B B-\beta_B^2}a_t,$
```

for real constants $A, C_1$, and $C_2$. Letting $X^{(1)} = (A/(1-\alpha_B B))a_t$ and $X^{(2)} = (C_1+C_2 B)/(1-\beta_B B-\beta_B^2)a_t$, it follows that $(1-\alpha_B B)X^{(1)} = Aa_t$, and $(1-\beta_B B-\beta_B^2)X^{(2)} = (C_1+C_2 B)a_t$. That is, it is a realization from an AR(1) process where the AR factor is the first factor in the factored form of Equation 3.120, and $x^{(2)}$ is the second-order factor in the factored form of Equation 3.120. In Example 10.14, we discuss the use of state-space formulation to actually construct these components. The important point to be made here is that each component corresponds to a row in the factor table. See also West (1997).
