# 10.5.2 Testing for Cointegration between Nonstationary Time Series

We let $X_{i1}$ and $X_{i2}$ denote the annual incidence of non-perforated appendicitis (appendicitis) and influenza (flu), respectively, in Figure 10.8. The disease incidence data showing a wandering behavior that is indicative of models with unit roots. The question of interest here is whether the two series tend to “tethered together,” that is, to wander together. Engle and Granger (1987) used the term cointegration to describe this “tethering together” idea, which in our setting, implies that each series has a single unit root and there exists some linear combination of the differences $

```
$X_t = \alpha + \Phi_1 X_{t-1} + \dots + \Phi_p X_{t-p} + \mathbf{a}_t,$
```
