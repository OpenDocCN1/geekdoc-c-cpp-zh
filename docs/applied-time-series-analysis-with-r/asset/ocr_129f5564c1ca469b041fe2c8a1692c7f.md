# ARMA Time Series Models

phi is a vector of AR parameters (using signs as in this text).
(default = 0)

theta is a vector of MA parameters (using signs as in this text)
(default = 0)

lag.max is the maximum lag at which the autocorrelations and
autovariances will be calculated (default = 25)

vara is the white noise variance (default = 1)

NOTES:

+   1. You may want to use the utility function .wge if you know
the factors of the model instead of the coefficients.
2. max(p,q+1) ≤ 25.
3. This function uses a call to the base R function arima.sim
which uses the same signs as this text for the AR parameters but
opposite signs for MA parameters. The appropriate adjustments
are made here so that phi and theta should contain parameters
using the signs as in this text. However, if you use arima.sim
(which has options not employed in this implementation-
then you must remember that the MA parameter specifica-
must opposite signs as in this text.

Example: The command

```
test <- plots.true.wge(n=100,phi=c(1.6,-90),
theta= .9,lag.max=25,vara=1)
```

generates a realization and computes the autocorrelations (and
autovariances) from the zero-model X_t-1.6X_{t-1}+0.9X_{t-2}=a_t-0.9a_{t-1}.

NOTE: This is a zero-mean model, and plots.true.wge
always generates a realization from a zero-mean model. In this example,
ple test$data contains the n values of realization, test$out1
d test$acv contain the true autocorrelations and covariances respectively for lags 0, 1, ..., lag.max. The process variance
is given by test$acv[1]. test$spec contains the 251 spectral density
values associated with the frequencies f=0/100, ..., 250/500.
