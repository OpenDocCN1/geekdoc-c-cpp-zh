+   3. factor.comp.wge(x, p, ncomp, report, append) fits an (p) model to a realization x, calculates and prints a factor table associated with an AR(p) model to fit the data using Burg estimates, and plots ncomp additive components where ncomp is less than or equal to the number of factors in the factor table.

x is a vector of n containing the time series realization x, t=1..,n.
p is the order of the AR model to fit to the data
ncomp is the number of additive components to be calculated and plotted

Example: In this example we find additive components for the data in Figure 3.26a (also shown in Figure 3.16a) and contained in tswge dataset fig3.16a. If we use the command,

```
data(fig3.16a); test=factor.comp.wge(fig3.16a,p=3,ncomp=2)
```

+   4. atrans.wge(x,phi,tr,lag.max,plottr) performs an AR transformation yi=phi(B)x, where the coefficients of phi(B) are given in phi.
x=original realization
phi.tr=vector of transforming components
lag.max=maximum lag for calculated sample autocorrelations (original and a transformed data) (default=25)
plottr=logical variable.

If plottr = TRUE (default) then atrans.wge plots the original and transformed realizations and associated sample autocorrelations
Example: In this example, atrans.wge to factor out the second order factor, $1-1.6B + 0.9B^2$, from the data in Figure 3.16a, and plot the data, sample autocorrelations, transformed data, and sample autocorrelations of the transformed data.

```
data(fig316a); test = atrans.wge(fig316a, phi = c(1.6,-0.9), lag.max = 20
```

The vector test contains the $(n-2)$ values of the transformed data.
