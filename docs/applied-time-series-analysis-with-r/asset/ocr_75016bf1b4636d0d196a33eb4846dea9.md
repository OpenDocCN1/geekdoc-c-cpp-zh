zero outside the bounded interval $[2k, 2(k+1)]$. Specifically,

```
$$\Psi_{j,k}(x)=2^{j/2}, \quad 2'k \le x < 2'(k+0.5)\n=-2^{-j/2}, \quad 2'(k+0.5) \le x < 2'(k+1)\n=0. \quad (12.14)$
```
