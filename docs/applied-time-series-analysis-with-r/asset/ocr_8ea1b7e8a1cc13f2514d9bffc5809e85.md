# 108 Applied Time Series Analysis with R

We use the notation $\alpha_1 = a + bi$ and $\alpha_2 = a - bi$. Now, $\alpha_1$ and $\alpha_2$ are given by

```
$a \pm bi = \frac{\phi_1}{2} \pm \frac{\sqrt{-(\phi_1^2 + 4\phi_2)}}{2}} i.$
```

It will be convenient to express $\alpha_1$ and $\alpha_2$ in polar form as $\alpha_1 = R(\cos 2\pi f_0 + i\sin 2\pi f_0) = Re^{2\pi fi_0}$ and $\alpha_2 = Re^{-2\pi fi_0}$, where $	an(2\pi f_0) = b/a$ and $R = \sqrt{a^2 + b^2}$. In our case,

```
$R = |\alpha_1| = \sqrt{-\phi_2}, \quad (3.61)$
```

and $\cos 2\pi f_0 = a/\sqrt{a^2 + b^2} = \phi_1/(\sqrt{-\phi_2})$. Substituting into Equation 3.60, we get

```
$\rho_k = (\sqrt{-\phi_2}) \left\ \frac{\sin((k+1)2\pi f_0 + \phi_2\sin(k-1)2\pi f_0)}{(1-\phi_2)\sin 2\pi f_0} \right\.$
```

Let $\psi$ be such that $	an \psi = (1-\phi_2)/(1+\phi_2)\tan 2\pi f_0$, we can rewrite $\rho_k$ as

```
$\rho_k = (\sqrt{-\phi_2}) \left\ \frac{\sin(2\pi k f_0 + \psi)}{\sin \psi} \right\., \quad (3.62)$
```

where $\cos 2\pi f_0 = \phi_1/(\sqrt{-\phi_2})$. That is, the second factor of Equation 3.62 is periodic with frequency

```
$f_0 = \frac{1}{2\pi} \cos^{-1} \left( \frac{\phi_1}{2\sqrt{-\phi_2}} \right), \quad (3.63)$
```

$\rho_k$ is a damped sinusoidal function, and we call $f_0$ the *natural frequency* or system frequency.
