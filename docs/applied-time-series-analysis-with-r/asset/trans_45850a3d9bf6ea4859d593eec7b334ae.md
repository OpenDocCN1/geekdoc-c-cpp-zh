

fore.garma.wge(x,u,lambda,phi,n.ahead,lastn,plot)

该函数根据方程 11.16 中的 1 因子 GARMA 模型预测 `n.ahead` 步。参见第 11.6 节。作为比较，还获得了与数据拟合的 AR 模型的预测。

x = realization.（观测值）。

u 和 lambda 是方程 11.16 中 Gegenbauer 因子的参数。

phi = 包含你想预测的前几步数的向量。default = 0)

n.ahead = (default = 2)

lastn = 布尔型变量。如果 `lastn = FALSE`（默认），则预测值针对 $x(n+1), x(n+2), \dots x(n.ahead)$，其中 $n$ 是观测值的长度。如果 `lastn = TRUE`，则程序预测观测值中最后 n.ahead 个值。

plot = 布尔型变量。如果 `plot = TRUE`（默认），则预测值将与观测值一起绘制。如果 `plot = FALSE` 则不输出任何图表。

该函数输出：

```
ar.fit.order(与数据拟合的 AR 模型的阶)
garma.fore(一个包含 GARMA 预测值的向量)
ar.fore(一个包含 AR 预测值的向量)
```

注意：我们假设 $q = 0$，即没有移动平均参数。

示例：

为了获得 log-lynx 数据（tswge 中的 lynx）的预测值，我们使用图 11.14(a)，我们使用 `codendata(lynx)`

```
example = fore.garma.wge(lynx,u = .8,lambda = .49,
phi = c(.41,-12,.25),n.ahead = 30,lastn = FALSE,plot = TRUE)
```

使用这段代码可以预测观测值结束之后的 30 步，并绘制预测值和数据。为了获得图 11.14b 中的拟合结果，我们使用以下代码：

```
example = fore.garma.wge (lynx,
u = .8,lambda = .49,phi = c(.41,-12,.25),n.ahead = 30,lastn = FALSE
```

需要注意的是，与图 11.14a 中的图不同，程序还将绘制与数据拟合的 AR 模型相关的预测值（使用 $p \leq 20$ 的 ar.yw）。在这种情况下，选择了 AR(7)。
