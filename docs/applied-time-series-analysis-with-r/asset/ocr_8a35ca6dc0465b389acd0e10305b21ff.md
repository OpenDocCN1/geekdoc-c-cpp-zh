# 3.2.2 Invertibility/Infinite-Order AR Processes

We have seen that under certain conditions, a stationary AR(p) process can be written in the form of a general linear process, that is, an infinite-order MA. A question of interest arises concerning when an MA(q) process can be expressed as an infinite-order AR process. In operator notation, the question is, “When can $X_t=	heta(B)a_t$, be written as $	heta^{-1}(B)X_t=a_t$? If we expand $	heta^{-1}(z)$ in powers of $z$ as

```
$$\theta^{-1}(z) = \sum_{j=0}^{\infty}\pi_j z^j$$
```

and proceed formally to define $	heta^{-1}(B)$ by replacing $z$ by $B$ in Equation 3.82, then application of the operator term by terms yields

```
$$\sum_{j=0}^{\infty}\pi_j X_{t-j} = a_t$$
```

which is a process of infinite AR form.

# Definition 3.4

If an MA(q) process $X_t$, can be expressed in Equation 3.83 with $\sum_{j=0}^{\infty}|pi_j|<<\infty$, then $X_t$, is said to be invertible.
