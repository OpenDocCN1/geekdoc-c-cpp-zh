# 10.3 Multivariate (Vector) ARMA Processes

The AR(p), MA(q), ARMA(p,q), ARUMA(p,d,q), and corresponding seasonal models can be extended to the multivariate case. Our focus will be exclusively on the multivariate AR(p) process. We begin this discussion with Example 10.1.

# EXAMPLE 10.1: A BIVARIATE PROCESS

Consider the bivariate process

```
$X_t = \begin{pmatrix} X_{t1} \ X_{t2} \end{pmatrix}, t=0, \pm1, \pm2, \dots$
```

specified by

```
$X_{t1} = \phi_{11}X_{t-1,1} + \phi_{12}X_{t-1,2} + a_{t1},\nX_{t2} = \phi_{21}X_{t-1,1} + \phi_{22}X_{t-1,2} + a_{t2},$ (10.13)$
```

where $\mathbf{a}_t = (a_{t1}, a_{t2})^Y$ is a bivariate white noise process. The equations in Equation 10.13 can be written in matrix form

```
$X_t = \mathbf{\Phi}X_{t-1} + \mathbf{a}_t,$ (10.14)$
```

where

```
$$\Phi_1 = \begin{pmatrix} \phi_{11} & \phi_{12} \ \phi_{21} & \phi_{22} \end{pmatrix}$.$
```

The bivariate process in Equation 10.13 is an example of a multivariate (or vector) AR(1) process. The vector AR(p) process is defined in Definition 10.6 that follows.
