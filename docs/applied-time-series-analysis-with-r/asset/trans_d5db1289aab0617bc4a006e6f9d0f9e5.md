### 2.4.1 巴特沃斯滤波器

科学家和工程师使用的常用滤波器之一是巴特沃斯滤波器（参见 Butterworth, 1930; Porat, 1997）。这里将简要介绍这种滤波器。虽然巴特沃斯滤波器可以是任何类型（低通、高通等），但我们的讨论将集中在N阶低通巴特沃斯滤波器，其平方频率响应函数为：

```
$|H(e^{-2\pi f})|^2 = \left(\frac{f}{f_c}\right)^{2N}$
```

增加 N 值会使滤波器变陡峭，如图 2.6 所示，我们展示了具有不同 N 值的 $f_c = 0.2$ 的低通巴特沃斯滤波器的平方频率响应。也就是说，对于较大的 N 值，具有截止频率 $f_c$ 的低通巴特沃斯滤波器的平方频率响应函数更地符合理想滤波器：

```
$|H(e^{-2\pi f})|^2 = 1, \ f \le f_c \n=0, \ f > f_c$
```
