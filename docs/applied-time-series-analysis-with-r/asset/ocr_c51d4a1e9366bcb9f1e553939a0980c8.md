# 4.2.1.2 The ARCH($q_0$) Model

The ARCH(1) model can be extended as follows.

$$\alpha_t = \sigma_{t-1}^2 \epsilon_t,$$

where

$$\sigma_{t-1}^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \dots + \alpha_{q_0} a_{t-q_0}^2,$$

and the $\epsilon_t$ are i.i.d., zero mean, unit variance random variables. The process, $[a_t],$ in Equation 4.23 is referred to as an ARCH($q_0$) process. Recall that an ARCH(1) process was suggested as a plausible model to account for the volatility seen in the return of data in Figure 4.7. Economic applications, such as the returns data, originally motivated the introduction of the ARCH model.

The ARCH($q_0$) model in Equation 4.23 can be expressed in a form analog to Equation 4.21. That is, if $a_t$ satisfies the ARCH($q_0$) model in Equation 4.23, then it can be written as

$$a_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \alpha_2 a_{t-2}^2 + \dots + \alpha_{q_0} a_{t-q_0}^2 + w_t,$$
