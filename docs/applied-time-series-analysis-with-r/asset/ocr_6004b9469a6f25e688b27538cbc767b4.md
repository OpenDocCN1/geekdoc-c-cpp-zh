# Parameter Estimation

```
$S_c = \sum_{t=p+1}^{n} \hat{a}_t^2 \nn = \left[ \sum_{t=p+1}^{n} \{X_t - \hat{\mu} - \hat{\phi}_1(X_{t-1} - \hat{\mu}) - \cdots - \hat{\phi}_p(X_{t-p} - \hat{\mu})\}^2 \right].$ (7.13)
```

It should be noted that the problem of finding the least squares solution of the parameters in Equation 7.12 is different from that encountered in the classical regression setting in a number of ways. For example,

+   - $X$, simultaneously plays the role of the response (dependent) and the predictor (independent) variables.
-* $\mu$ is the mean of both the response and predictor variables.
-* The predictor variables are correlated (and possibly).

Also notice that the equations for $t=1, 2, \dots, p$ are not used, since they involve unobservable data, and as a consequence, $X_1, X_2, \dots, X_p$ play a less significant role than does, for example, $X_{p+1}$. Least squares estimates can still be obtained from Equation 7.11, and Mann and Wald (1943) have shown that standard rules about the variances and covariances of regression estimates hold asymptotically as $n\to\infty$ in this setting.
Minimizing $S$, by differentiating with respect to $\mu, \phi_1, \dots, \phi_p$, and setting these derivatives equal to zero produces normal equations that in general lead to solutions that are difficult to solve. As a consequence, least squares solutions obtained by minimizing Equation 7.13 are found numerically.
Approximations have been proposed that allow the least squares estimates to be obtained using a standard multiple regression package. The most common approximation is to take $\hat{\mu}=X$ and minimize the sum of squares

```
$S_c = \sum_{t=p+1}^{n} \{X_t - \hat{\mu} - \hat{\phi}_1(X_{t-1} - \hat{\mu}) - \cdots - \hat{\phi}_p(X_{t-p} - \hat{\mu})\}^2.$ (7.14)
```

These approximate OLS estimates can be obtained directly using multiple regression packages to estimate the coefficients in the model

```
$$\gamma = b_0 + b_1W_1 + \cdots + b_pW_p + e,$
```

where
Y is the response variable
W_1, \dots, W_p$ are the predictor variables
b_0, b_1, \dots, b_p$ are the regression coefficients with $b_0$ being the intercept term
