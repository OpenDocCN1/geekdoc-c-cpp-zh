+   parzen.wge(x, dbcalc, trunc, plot) (tswave R function) calculates and alternatively plots the smoothed periodogram based on the Parzen window.

x is a vector containing the time series relation x, t = 1, ..., n.
dbcalc is a logical variable. dbcalc = "TRUE" (default) calculates the smoothed spectral estimator on the log scale (dB)
truc (integer≥0) specifies the truncation point.
truc = 0 (default) or no value for trunc is specified) indicates that the default truncation point is M=2\sqrt{n}
truc > 0 is a user specified truncation point, i.e. calculations will be on M=trunc

plot is a logical variable. plot = "TRUE" (default) produces a plot of the smoothed spectral estimator (in log or non-log scale depending on).

Example:

```
data(ss08) <- sparz:parzen.wge(ss08)
```

calculates and plots the smoothed spectral estimator (in dB) for the sunspot data using the default truncation point, M=2\sqrt{260}=32. The vectors ssparz$freq and ssparz$pgram contain the frequencies and associated Parzen-based spectral estimates.
