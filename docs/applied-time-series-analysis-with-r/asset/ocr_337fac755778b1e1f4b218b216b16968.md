The underlying signal is then reconstructed using the $\hat{d}_{j,k}$ as the detail coefficients.
A variety of techniques have been used for obtaining the threshold $\lambda$. One popular method is to use a single (universal) threshold, $\lambda_{\mu}$, across all levels of $j$ given by

```
$$\lambda_u = \hat{\sigma}_u \sqrt{2 \log n}, \quad (12.36)$
```

where $\hat{\sigma}_u^2$ is an estimate of the noise variance $\sigma_n^2$. Note that $d_j$ coefficients of the DWT of the noisy signal in Figure 12.8 are almost all due to noise. This is typical for smooth signals, and consequently $\hat{\sigma}_j^2$ is often estimated using only the $d_j$ level coefficients. Donho and Johnstone (1994) set $\hat{\sigma}_j$ to be the median of the absolute deviation (MAD) of the $d_j$ level coefficients. (The MAD of a list of numbers is the median of the absolute differences between the values in the list and the median of the list). Alternatively, separate thresholds can be calculated for each row of detail coefficients, which might be a preferable approach in the case of correlated noise.
