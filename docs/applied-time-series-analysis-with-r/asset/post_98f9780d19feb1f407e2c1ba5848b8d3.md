## 12A.2 Vector Spaces

Let $x = (x_1, x_2, \dots, x_n)$ and $y = (y_1, y_2, \dots, y_n)$ be two $n$-component real vectors.

- 1. The inner product (or dot product) of $x$ and $y$ is given by $\sum_{k=1}^n x_k y_k$.
- 2. The Euclidean norm of $x$, is given by $||x||$, as $(\sum_{k=1}^n x_k^2)^{1/2}$.
- 3. Vectors $x$ and $y$ are orthogonal if their inner product is zero.
- 4. Vectors $x$ and $y$ are orthonormal if they are orthogonal and have norm one.

## 12A.3 Function Spaces of Real-Valued Functions $f: [-\pi, \pi] \to \mathbb{R}$

- 1. The inner product of $f$ and $g$ is given by $\int_{-\pi}^\pi f(x)g(x)dx$.
- 2. The norm of $f$, denoted by $||f||$, is $\int_{-\pi}^\pi |f(x)|^2 dx$.
- 3. The real-valued function $f$ is said to be in $L^2[-\pi, \pi]$ if $\int_{-\pi}^\pi |f(x)|^2 dx < \infty$.
- 4. Functions $f$ and $g$ are orthogonal if their inner product is zero.
- 5. Functions $f$ and $g$ are orthonormal if they are orthogonal and have norm one.

## 12A.4 Systems of Functions

- 1. Let $S = \{f_1, f_2, \dots \}$ where $f_m$ is orthogonal to $f_j$ when $m \neq j$. Then $S$ is said to be an orthogonal system.
- 2. An orthogonal system $S$ is said to be orthonormal if the norm of each function in $S$ is one.
- 3. The functions $S_1 = \{1, \cos kx, \sin kx; k=1, 2, \dots \}$ (or equivalently $S_2 = \{e^{ik}, k=0, \pm1, \dots \}$) are orthogonal systems of functions.
- 4. Fourier series results show that the collections $S_1$ (and $S_2$) are bases for a wide class of functions in $L^2[-\pi, \pi]$.

## 12A.5 Formal Derivation of Wavelet Coefficient

The following is a formal derivation of the fact that

```
$g(x) = \sum_{j=-\infty}^{\infty} \sum_{k=-\infty}^{\infty} d_{j,k}\Psi_{j,k}(x),$
```

then this implies the coefficients $d_g$ are given by

```
$d_{j,k} = \frac{1}{\|\Psi\|^2} \int_{-\infty}^{\infty} g(t)\psi_{j,k}(t)dt$.
```

Formal Derivation: From the equality regarding $g(x)$ given in Equation 12.15, it follows that

```
$g(x) = \sum_{j=-\infty}^{\infty} \sum_{k=-\infty}^{\infty} d_{j,k}\psi_{j,m}(x)\psi_{j,k}(x)$,
```

and

```
$g(t)\psi_{j,m}(t)dt = \sum_{j=-\infty}^{\infty} \sum_{k=-\infty}^{\infty} d_{j,k}\psi_{\ell,m}(t)\psi_{j,k}(t)$.
```

Note that,

```
$\psi_{\ell,m}(t)\psi_{j,k}(t)dt = \begin{cases} 0, & j \neq \ell \text{ or } m \neq k \\ \|\psi\|^2, & j = \ell, m = k \end{cases}$
```

Consequently,

```
$d_{j,k} = \frac{1}{\|\Psi\|^2} \int_{-\infty}^{\infty} g(t)\psi_{j,k}(t)dt$.
```

The following commands are be used in conjunction with dwt and mra functions in the CRAN package waveslim.
b plotts.dwt.wge(x,n.levels,type)

This function calculates the dwt, outputs the wavelet coefficients, plots the DWT in the format of Figure 12.7, and optionally plots the scalogram (time-scale plot)

x is the realization to be analyzed (x must be a vector of length length 2^j₀ for some positive integer j₀ between 2 and 14.
n.levels (default = 4) is the number of levels (n.levels ≤ j₀)
type specifies the type of wavelet used (default = S8), i.e. Symlet(8) wavelet.

Other choices are the Daubelets D4 (shark fin), D6, and D8 and The Haar wavelet (haar)

The program outputs:
d1 through d(n.levels), i.e. the n.level set of wavelet coefficients
s(n.levels), i.e. the scale coefficients associated with n.levels
long information concerning wavelet type (e.g. haar, D4, etc.) along the attributes boundary and class which are by default to dwt and periodic. For more information about these attributes, see the waveslim documentation.

NOTES: plotts.dwt.wge plots a DWT based on the waveslim function dwt (see the waveslim documentation for more details)

Example: To obtain the DWT shown in Figure 12.13a for the bumps256 data set, use the following commands:

```
data(bumps256)
plotts.dwt.wge(bumps256,n.levels = 5,type = 'D6')
```
