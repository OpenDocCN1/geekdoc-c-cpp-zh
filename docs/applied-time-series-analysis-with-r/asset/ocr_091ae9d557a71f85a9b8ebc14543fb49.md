# 13.2.2 Discrete M-Stationary Process

Example 13.1: Motivates the Definition.

# Definition 13.3

Let h > 1 and S = {t_k : t_k = h^k, k = 0, ±1, ±2, ...} and suppose

+   1. E[X(h^k)] = $\mu$
2. Var[X(h^k)] = $\sigma^2 < \infty$
3. E[(X(h^k) - \mu)(X(h^{k-j}) - \mu)] = R_X(h^j)$

for all t_k = h^k ∈ S. Then X(t_k) is a discrete M-stationary process with the discrete dual process Y(t_k) = X(h^{-k}).

C_Y(j) = E[(Y(t_k)-\mu)(Y(t_{k-j})-\mu)]. This can be rewritten C_Y(j) = E[(X(h^k) - \mu)(X(h^{k-j}) - \mu)] = R_X(h^j). Since C_Y(j) = C_{-Y}(j), it follows that R_X(h^j) = R_X(h^{-j}). If t_k = h^k and u = g(t) = t/ln h, then u_k = g(t_k) = g(h^k) = h^k/ln h. Then, t_k = g^{-1}(u_k) = h^k. So

```
$g^{-1}(g(t_k) + g(t_j)) = h^{(g(t_k)+g(t_j))}\n= h^{k+j}\n= h^{k'}$$
```

Thus, a discrete M-stationary process is a discrete G-stationary process with u_k = g(t_k) = t/ln h and S = {t_k : t_k = h^k, k = 0, ±1, ±2, ...}. That is, u_k = k.

# 13.2.3 Discrete Euler(p) Model

Making use of Definition 13.3, Vijverberg and Gray (2009) and Gray et al. (2005) introduced and studied Euler(p) processes. See also Vijverberg and Gray (2009).

# Definition 13.4

Let t_i ∈ S = {t_k = h^k, k = 0, ±1, ±2, ...}, and suppose X(t_i) is the M-stationary solution of

```
$$(X(h^k) - \mu) - \phi_1(X(h^{k-1}) - \mu) - \dots - \phi_p(X(h^{k-p}) - \mu) = a(h^k)$$
```

where a(h^k) is white noise. Then X(t_i) is called a discrete Euler(p) process.
