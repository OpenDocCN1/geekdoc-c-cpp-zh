# Other Stationary Time Series Models

# 4.2.1 ARCH Processes

To address the conditional volatility behavior discussed in connection with the DOW rate of returns data in Figure 4.7, Engle (1982) introduced the ARCH model. We first consider the simplest ARCH process, the ARCH(1) model.

# 4.2.1.1 The ARCH(1) Model

Let $\sigma_{t-1}^2$ be the conditional variance of $a_t$, and suppose

```
$$a_t = \sigma_{t-1} \varepsilon_t,$$
```

where

```
$$\sigma_{t-1}^2 = \alpha_0 + \alpha_1 a_{t-1}^2,$$
```

$0 \le \alpha_1 < 1$, and $\{\varepsilon_t\}$ is a sequence of independent and identically distributed (i.i.d.), zero mean, unit variance random variables that are independent of the $a_{t-k} k=1, 2, \dots$ Then $a_t$ is said to satisfy an ARCH(1) process. Note that the unit of $\varepsilon_t$ is required, so that

```
$$E[(\sigma_{t-1} \varepsilon_t)^2 | a_{t-k}, k=1, 2, \dots] = \sigma_{t-1}^2 E[\varepsilon_t^2 | a_{t-k}, k=1, 2, \dots]$\n$$$ = \sigma_{t-1}^2 E[\varepsilon_t^2] = \sigma_{t-1}^2,$$
```

It is also easily shown (Shumway and Stoffer, 2010) that the $a_t$'s are uncorrelated with a conditional variance that depends on $t$. Note from Equation 4.19 that

```
$$a_t^2 - (\alpha_0 + \alpha_1 a_{t-1}^2) = \sigma_{t-1}^2 (\varepsilon_t^2 - 1,$$
```

and thus that

```
$$a_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + w_t,$$
```

where $w_t = \sigma_{t-1}^2(\varepsilon_t^2 - 1)$ and $E[w_t] = 0$. Thus, $a_t$ satisfies a non-Gaussian AR(1) process with
