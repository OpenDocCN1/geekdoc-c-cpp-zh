# Applied Time Series Analysis with R

For a stationary process, $X_t$, let $\hat{X}_m(1)$ denote the best one-step ahead predictor of $X_{m+1}$ given data $X_l, \dots, X_m$. These predictors can be shown to follow the relationship

```
$$\hat{X}_n(1) = 0, \text{if } n=0$$
$$\$\sum_{j=1}^n \theta_{nj}(\hat{X}_{n-1-j} - \hat{X}_{n-j}(1)), \text{if } n=1, 2, \dots $\quad (7.25)$
```

For some constants $\theta_{ij}=1, 2, \dots, n$. (see Blackwell and Davis, 1992). That is, the one-step ahead predictor is expressed as a linear combination of the prediction errors (innovations) $\hat{a}_{k+1} = X_{k+1} - \hat{X}(1)$. The estimated coefficients $\hat{	heta}_{m1}, \hat{	heta}_{mm}$ and noise variance $\hat{v}_m, m=1, 2, \dots$ are calculated recursively as follows:

```
$$\hat{v}_0 = \hat{\gamma}_0$$
$$\$\hat{	heta}_{mm-k} = \hat{v}_{k-1}^{-1} \left( \sum_{j=0}^{k-1} \hat{	heta}_{m,m-j} \hat{v}_{k-1-j} - \hat{\gamma}_k \right)$
```

for $k=0, 1, \dots, m-1$

```
$$\hat{v}_m = \hat{\gamma}_0 - \sum_{j=0}^{m-1} \hat{	heta}_{m,j}^2 \hat{v}_j$$
```

The innovations algorithm can be used to fit MA models such as

```
$X_t = a_t - \hat{	heta}_{m1}a_{t-1} - \dots - \hat{	heta}_{mm}a_{t-m}$
```

where $m=1, 2, \dots$ This technique is closely related to the use of the Durbin-Levinson algorithm given in Equation 7.9 which produces YW estimates of the AR parameters by recursively solving the YW equations. Unlike the YW estimates, the innovations estimates $\hat{	heta}_1, \dots, \hat{	heta}_q$ are not consistent estimates of $\theta_1, \dots, \theta_q$. In order to obtain consistent estimates, it is necessary to use $\hat{	heta}_{m1}, \dots, \hat{	heta}_{mq}$ where $m$ is substantially larger than $q$. In practice, $m$ is typically increased until $\hat{	heta}_{m1}, \dots, \hat{	heta}_{mq}$ stabilize, they do not change much as $m$ continues to increase. For $100 \le n \le 500$, sufficient stability will often be obtained for $m \le n/4$ (see Blackwell and Davis, 1991).
