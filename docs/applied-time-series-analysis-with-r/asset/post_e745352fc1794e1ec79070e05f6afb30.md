## 3 ARMA Time Series Models

In this chapter we will discuss some of the important models that are used to describe the behavior of a time series. In particular interest will be the AR, MA, and ARMA models. These models were made popular by George Box and Gwilym Jenkins in their classic time series book, the current edition of which is Box et al. (2008). These models have become fundamental to the theory and applications of time series. While several example based on real data are examined in this chapter, we make extensive use of simulated realizations in order the properties and opening an understanding of known models. Also, unless otherwise specified, the autocorrelations and spectral densities illustrated in this chapter are the theoretical quantities for the models being studied. In later chapters, we will use the lessons learned in this chapter as we analyze actual time series.

### 3.1 MA Processes

We begin by defining an MA process of order $q$, which will be denoted $MA(q)$.

Definition 3.1

Let $a_t$ be a white noise process with zero mean and finite variance $\sigma_a^2$, and let the process $X_t, t=0, \pm1, \pm2, ...$ be defined by

```
$X_t - \mu = a_t - \theta_1 a_{t-1} - \dots - \theta_q a_{t-q},$$
```

where $\theta_j, j = 1, ..., q$ are real constants with $\theta_j \neq 0$. The process $X$, defined in Equation 3.1 is called an MA process of order $q$, which is usually shortened to $MA(q)$.

We will often write Equation 3.1 in the form

```
$X_t - \mu = \theta(B)a_t,$$
```

where

```
$\theta(B) = 1 - \theta_1 B - \theta_2 B^2 - \dots - \theta_q B^q.$
```

NOTE: Before proceeding, we point out that some authors and writers of software packages write Equation 3.1 as $X_i-\mu = a_i + \theta_{i-1} + \dots + \theta_{i-q}$. Consider the MA(2) model $X_i = a_i - 1.2a_{i-1} + 0.8a_{i-2}$. Using the definition in Equation 3.1, it follows that $\theta_1 = 1$ and $\theta_2 = -0.8$, while the coefficients would be $\theta_1 = -1.2$ and $\theta_2 = 0.8$ using the alternative representation. Before entering coefficients into a time series computer package or comparing formulas involving the $\theta$'s in different textbooks, it is very important to check the MA(q) definition.

Notice that an MA(q) process is a general linear process with a finite number of terms. In particular

```
$$\psi_0=1$$
$$\psi_k=-\theta_k$$
```

Using the notation in Equation 2.8, note that $\psi(z)=1-\sum_{j=1}^q\theta_jz^j$ where $z$ is real or complex. For an MA(q) process, we denote $\psi(z)$ by $\theta(z)$. An MA(q) process can be shown to be stationary using Theorem 2.3, because there are only a finite number of $\psi$-weights. Since $\sum_{j=1}^q\theta_j^2=1+\theta_1^2+\dots+\theta_q^2$, it follows that

```
$$$\sigma_k^2=\sigma_q^2(1+\theta_1^2+\dots+\theta_q^2)<\infty.$$
```

Also, from Equation 2.7

```
$$$\gamma_k=\sigma_q^2\left{-\theta_{g-k\|+\sum_{j=1}^q\theta_j\theta_{j+k}\right\}, \quad k=1,2,...,q$$
$$$\gamma_k=0, \quad k>q.$$
```

It follows then that

```
$$$\rho_k=\frac{-\sum_{j=1}^q\theta_j\theta_{j+k}}{1+\sum_{j=1}^q\theta_j^2}, \quad k=1,2,...,q$$
$$$\rho_k=0, \quad k>q.$$
```

And here throughout this text, we define the sum $\sum_{j=1}^n f(j)$ to be identically zero if $n<m$. The results in Equations 3.3 and 3.4 show that autocovariances of an MA(q) process trivially satisfy the conditions of Theorem 1.1

### 3.1.1 MA(1) Model

Let $X_i$, be the MA(1) process defined by

```
$X_i - \mu = a_i - \theta_1 a_{i-1}\n= (1 - \theta_1 B)a_i. \quad (3.9)$
```

From Equations 3.2 and 3.3, we obtain

```
$$\gamma_0 = \sigma_a^2[1 + \theta_1^2] = \sigma_X^2\n\gamma_1 = \sigma_a^2[-\theta_1]\n\gamma_j = 0, \quad j > 1. \quad (3.10)$
```

Thus, for an MA(1) process,

```
$$\rho_0 = 1\n\rho_1 = \frac{-\theta_1}{1 + \theta_1^2}\n\rho_j = 0, \quad j > 1. \quad (3.11)$
```

It is easily shown that the function $f(u) = |u|/(1 + u^2)$ has a maximum of 0.5 at $u = \pm1$, from which it follows that for an MA(1) process, $|\rho_1| = 0.5$. In particular, $\rho_1 = 0.5$ when $\theta_1 = -1$ and $\rho_0 = -0.5$ when $\theta_1 = 1$. From Equation 3.66, the spectral density of an MA(1) is given, for $|f| \leq 0.5$, by

```
$S_X(f) = \frac{|1 - \sum_{j=1}^q \theta_j e^{-2j\pi f}|^2}{1 + \sum_{j=1}^q \theta_j^2}\n= \frac{|1 - \theta_1 e^{-2\pi f}|^2}{1 + \theta_1^2}\n= \frac{1}{1 + \theta_1^2}[1 - \theta_1 e^{-2\pi f}][1 - \theta_1 e^{2\pi f}]\n= \frac{1}{1 + \theta_1^2}[1 - 2\theta_1 \cos 2\pi f]\n= 1 - \frac{2\theta_1 \cos 2\pi f}{1 + \theta_1^2}. \quad (3.12)$
```
