We will use the result from multivariate statistics that if $Z_1$ and $Z_2$ are $m_1$ and $m_2$ dimensional random variables, where $Var[Z_1] = \Gamma_{Z_1}$, $Var[Z_2] = \Gamma_{Z_2}$, and $Cov[Z_1, Z_2] = \Gamma_{Z_1Z_2}$, and the vector

![](bbox=[0.4638, 0.1905, 0.5362, 0.2435])

is multivariate normal, then

$E[Z_1 | Z_2] = \mu_{Z_1} + \Gamma_{Z_1Z_2}\Gamma_{Z_2}^{-1}(Z_2 - \mu_{Z_2}), \quad (10A.2)$

and

$Var[Z_1 | Z_2] = \Gamma_{Z_1} - \Gamma_{Z_1Z_2}\Gamma_{Z_2}^{-1}\Gamma_{Z_1}. \quad (10A.3)$

Using Equation 10A.2, it follows

```
$\hat{\mathbf{X}}_t = E[\mathbf{X}_t | Y_{1,\dots t}, Y_{t-1}, Y_t]\n= E[\mathbf{X}_t | (Y_{1,\dots t}, Y_{t-1}), \mathbf{I}_t)]\n= \hat{\mathbf{X}}_t + \mathbf{\Gamma}_t^{-1}\mathbf{G}_t'(\mathbf{G}_t, \mathbf{\G}_t' + \mathbf{\Gamma}_w)^{-1}\mathbf{I}_t.$
```

Let $\mathbf{K}_t = \mathbf{\Gamma}_t^{-1}\mathbf{G}_t'[\mathbf{G}_t, \mathbf{\G}_t' + \mathbf{\Gamma}_w]^{-1}$ and noting that the second equality in Equation 10A.1 shows that $\mathbf{I}_t = \mathbf{Y}_t - \mathbf{G}_t\mathbf{X}_t^{-1}$, then the filtering result in Equation 10.52 follows. Also, from Equation 10A.3 we obtain

```
$\mathbf{\Gamma}_t = Var[\mathbf{X}_t | Y_{1,\dots t}, Y_t]\n= Var[\mathbf{X}_t | (Y_{1,\dots t}, Y_{t-1}), \mathbf{I}_t)]\n= \mathbf{\Gamma}_t^{-1}\mathbf{G}_t'(\mathbf{G}_t, \mathbf{\G}_t' + \mathbf{\Gamma}_w)^{-1}\mathbf{\G}_t'^{-1},.$
```

and the result in Equation 10.53 follows.

# 10A.2 Derivation of the Fact That $x_t^{(i)}$ in Equation 10.65 Is a Realization from an ARMA(2,1)

We want to show that the sequence $x_t^{(i)} = \psi_{it} + \psi'_{it}$ as defined in Equation 10.65 is a realization from an ARMA(2,1) model and is in the additive component component corresponding to the quadratic factor $1 - \alpha_1z - \alpha_2z^2$ of the characteristic polynomial associated with the pair of complex conjugate roots, $r_j$ and $r_{j+1} = r_j^*$. In the following, it is assumed that the component $x_t^{(i)}$ is obtained by adding the $j$th and $(j+1)$st rows of $\mathbf{U}^{-1}$ and multiplying the resulting $p$ real coefficients by $X_t$.
