fore.garma.wge(x,u,lambda,phi,n.ahead,lastn,plot)

This function forecasts n.ahead steps based on a 1-factor GARMA model in Equation 11.16. See Section 11.6. For comparison, forecasts from an AR model fit to the data are also obtained.

x = realization.

u and lambda are the parameters of the Gegenbauer factor in Equation 11.16.

phi = vector the number of steps ahead you want to forecast. default = 0)

n.ahead = (default = 2)

lastn = logical variable. If lastn = FALSE (default) then the forecasts are for x(n+1), x(n+2), ... x(n.ahead) where n is the length of the realization. If lastn = TRUE, then the program forecasts the last n.ahead values in the realization.

plot = logical variable. If plot = TRUE (default) then the forecasts will be plotted along with the realization. If plot = FALSE then no plots are output.

The function outputs

```
ar.fit.order(the order of the AR model fit to the data)
garma.fore(a vector containing the GARMA forecasts)
ar.fore(a vector containing the AR forecasts)
```

NOTE: We assume that q = 0, i.e there are no moving average parameters.

Example:

In order to obtain the forecasts for the log-lynx data (lynx in tswge) we use Figure 11.14(a) we use the codendata(lynx)

```
example = fore.garma.wge(lynx,u = .8,lambda = .49,
phi = c(.41,-12,.25),n.ahead = 30,lastn = FALSE,plot = TRUE)
```

Using this code 30 steps beyond the end of the realization and we plot and the data. To obtain the fit in Figure 11.14b we use the code

```
example = fore.garma.wge (lynx,
u = .8,lambda = .49,phi = c(.41,-12,.25),n.ahead = 30,lastn = FALSE
```

It should be noted that, unlike the plot in Figure 11.14a, the program will also plot the forecasts associated with an AR model fit to the data (using ar.yw with p ≤ 20). In this case AR(7) was selected.
