To find $C_1$ note that from Equation 3.108 $ho_2 = \phi_1ho_1$ and from Equation 3.109 $ho_2 = C\phi_1^2$. So $\phi_1ho_1 = C\phi_1^2$, that is, $C_1 = ho_1\phi_1^{-1}$, and Equation 3.110 becomes

```
$$\rho_k = \rho_1(\phi_1^{-1})^{k-1},$ (3.110)
```

for $k \ge 2$. Now, in order to use Equation 3.107 for $k=0$ and 1 it is necessary to find $\psi_1$. For ARMA(1,1), $\psi_1 = \phi_1-	heta_1$ (see Equation 3.116). So Equation 3.117 becomes

```
$$\gamma_0 = \phi_1\gamma_1 - \sigma_{\epsilon}^2(-1+\theta_1(\phi_1-\theta_1)),$
$\gamma_1 = \phi_1\gamma_0 - \sigma_{	heta}^2\theta_1,$ (3.111)
```

and $\gamma_k = \phi_1\gamma_{k-1}, k > 1$. Solving Equation 3.111 for $\gamma_0$ and $\gamma_1$ yields

```
$$\gamma_0 = \frac{(1-2\theta_1\phi_1+\theta_1^2)}{1-\phi_1^2}\sigma_{\epsilon}^2,$
```

and

```
$$\gamma_1 = \frac{(\phi_1-\thetatheta_1)(1-\\phi_1\theta_1)}{1-\phi_1^2}\sigma_{	heta}^2,$
```

so that

```
$$\rho_1 = \frac{(\phi_1-\thetatheta_1)(1-\\phi_1\theta_1)}{1-2\theta_1\phi_1+\theta_1^2}.$ (3.112)
```
