Based on a fitted model, we calculate the residuals

```
$$\hat{u}_t = X_t - \hat{\phi}_1 X_{t-1} - \cdots - \hat{\phi}_p X_{t-p} - \hat{X}(1-\hat{\phi}_1-\cdots-\hat{\phi}_p)$$
$$+\hat{\phi}_1\hat{u}_{t-1}+\cdots+\hat{\phi}_p\hat{u}_{t-p}. \quad (9.2)$
```

In Section 7.4, we discussed the use of backcasting to compute necessary starting values, so the residuals $\hat{u}_1,\hat{u}_2,...,\hat{u}_t$ can be effectively calculated. A key point of the current section is that if the ARIMA$(p,q)$ model fit to the data is appropriate, then the residuals should be modeled as white noise. If the residuals of the fitted model contain significant autocorrelation, then the model has not sufficiently accounted for the correlation structure in the data. Another assessment that may be of interest is whether the residuals appear to be normally distributed, an assumption of the MLE procedures. We begin by discussing methods for white noise.

#  9.1.1 Check Sample Autocorrelations of Residuals

One method of testing residuals for white noise has already been discussed in Section 8.1. Specifically, for white noise, the autocorrelations satisfy $\rho_k=0, k\neq 0$, and in Equation 8.1 we give $95\%(\pm2/\sqrt{n})$ for testing $H_0:\rho_k=0$. We pointed out that if substantially more than $5\%$ of the sample autocorrelations fall outside these lines, then this is evidence against white noise. See Section 8.1 for a more complete discussion of the use of these limit lines for white noise checking.

#  9.1.2 Ljung-Box Test

The problem with checking the sample autocorrelations against, say, the $95\%$ limit lines, is that the $5\%$ of exceeding these lines applies to the autocorrelations at each lag separately. To provide a single portanteau test that simultaneously tests the autocorrelations at several lags, Box and Pierce (1970) and Ljung and Box (1978) developed tests of the null hypothesis that the data (in our application the residuals) are white noise. The test developed by Ljung and Box (1978) is widely used for this purpose. The Ljung-Box test given by

```
$L=n(n+2)\sum_{k=1}^K\frac{\rho_k^2}{n-k}, \ \quad (9.3)$
```

is used for testing the hypotheses

```
$H_0: \rho_1=\rho_2=\cdots\rho_k=0$$
$$H_a: at least one \rho_k\neq 0 \text{ for } 1\leq k\leq K.\ \quad (9.4)$
```
