Tsay and Tiao (1984) showed that it is not necessary to go through this entire procedure, but that the TT estimates $\hat{\phi}_p^{(0)}$ can be obtained using the recursion

```
$\hat{\phi}_{k+1}^{(m)} = \frac{\hat{\epsilon}_{t-k}^{(m-1)}}{\hat{\epsilon}_{t,k}^{(m-1)}} \hat{\phi}_{kk}^{(m-1)}$
```

where $j=1, \dots, k$ with $k \geq 1$. The recursion is initialized with $\hat{\phi}_p^{(m-1)}=-1$ and with estimates $\hat{\phi}_j^{(0)}$ for the case $q=0$ obtained using a method for estimating parameters of an AR process. Tsay and Tiao (1984) used least squares to initialize this recursion. The TT estimates are asymptotically equivalent to the WY estimates when $X_t$ is stationary, and they are consistent for $\phi_1, \dots, \phi_p$ when the characteristic equation $\phi(z)=0$ has roots on the unit circle. These estimates are not calculated in `tswge`. In the GW-WINKS software, the TT estimates are initialized using Bug estimates due to their stability properties. We refer to these as Bug/TT estimates in the text. GW-WINKS refers to them as Bug/Tiao estimates.

# 7.2.3.3 Estimating the MA Parameters

Consider the ARMA(p,q) model $\phi(B)X_t$. Since $Y_t = \theta(B)a_t$, preliminary estimates of the MA parameters of ARMA(p,q) can be obtained by first estimating the AR parameters (using a procedure such as Bug/TT) and then fitting an MA(q) model to $Y_t = \theta(B)X_t$. This procedure is not currently implemented in `tswge`.
