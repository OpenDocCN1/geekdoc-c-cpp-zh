时间序列分析技术通常分为两大类：时域技术和频域技术。时域技术包括相关性结构分析、建立描述此类数据随时间演变方式的模型，以及对未来行为的预测。频域方法旨在通过从底层周期（或频率）内容的角度检查数据，以建立对时间序列数据的理解。宾夕法尼亚州温度数据包含 12 个月的循环，这就是频域内容检查的一个例子。基本的频域分析工具是功率谱。

## 1.1 时间序列

简单来说，时间序列可以被视为随时间顺序排列的观测集合。我们感兴趣的不是确定性序列，而是按照概率规律运行的序列。在本章，我们将讨论涉及时间序列统计分析的基础知识。开始之前，我们对时间序列的定义必须更加谨慎。实际上，时间序列是随机过程的一个特例。

# 定义 1.1

随机过程 $X(t); t \in T$ 是随机变量的集合，其中 $T$ 是所有随机变量的索引集，$X(t), t \in T$ 定义在相同的样本空间上。当 $T$ 代表时间时，我们称该随机过程为时间序列。

如果 $T$ 取连续值范围（例如 $T = (-\infty, \infty)$ 或 $T = (0, \infty)$），则该过程被称为连续参数过程。相反，如果 $T$ 取离散值集（例如 $T = \{0, 1, 2, \dots\}$ 或 $T = \{0, \pm1, \pm2, \dots\}$），则该过程被称为离散参数过程。实际上，通常将它们分别称为连续过程和离散过程。

当我们处理离散参数过程时，使用符号 $X_t$。然而，当涉及的过程是连续参数或未指定类型时，我们将使用函数符号 $X(t)$。此外，当产生混淆时，我们将使用符号 $X(t)$ 或直接用 $X$ 来表示时间序列。同样，我们通常会将 $\{X_t; t=0, \pm1, \dots\}$ 简写为 $X_t; t=0, \pm1, \dots$ 或简写为 $X$。

记住，随机变量 $Y$ 是定义在样本空间 $\Omega$ 上的函数，其值域是实数。随机变量 $Y$ 的观测值是某个 $\omega \in \Omega$ 的实值 $y(\omega)$。对于时间序列 $X(t)$，对于某个固定的 $\omega \in \Omega$，其“值” $X(t, \omega); t \in T$ 是一个实数集合。这引出了以下定义。

# 定义 1.2

时间序列 $\{X(t); t \in T\}$ 的实现是对于 $\omega \in \Omega$ 的固定值，实值结果集合 $\{X(t, \omega); t \in T\}$。

也就是说，时间序列的实现仅仅是 $\{X(t)\}$ 的一组值，其源于某些观测事件的发生。时间序列 $\{X(t); t \in T\}$ 的实现将表示为 $\{x(t); t \in T\}$。与以前一样在连续参数的情况下，我们有时会使用符号 $\{x(t)\}$ 或直接使用 $x(t)$，在离散参数的情况下使用 $[x_i]$ 或 $x_i$，只要这些是清晰的的。所有可能实现的集合称为*系综*（ensemble），且对于给定的 $t$，随机变量 $X(t)$ 的期望被称为系均平均，并表示为 $E[X(t)] = \mu(t)$。$X(t)$ 的方差由 $Var[X(t)] = E[X(t) - \mu(t)]^2$ 给出，并通常用 $\sigma^2(t)$ 表示，因为它也可以取决于 $t$。

# 示例 1.1：具有两个可能实现的时间序列

考虑对于 $t \in (-\infty, \infty)$ 的随机过程 $Y(t)$，定义为 $Y(t) = \sin(t + \varphi)$，其中 $P(\varphi=0) = 0.5$ 且 $P(\varphi=\pi/2) = 0.5，$P$ 表示概率。该过程有两个可能的实现或样本函数，这些在图 1.2 中所示（对于 $t \in [0,25]$）。当两个可能的曲线的集合构成系综时，个体即为实现。对于这个过程，

```
E[Y(t)] = 0.5sin(t + 0) + 0.5sin(t + \frac{\pi}{2})
```

因此，例如：

```
E[Y(0)] = 0.5sin(0) + 0.5sin(\frac{\pi}{2}) = 0.5,
```

以及

```
E[Y(\frac{\pi}{4})] = \frac{\sqrt{2}}{2}.
```

$E[Y(t)] = \mu(t)$，这意味着期望取决于 $t$。注意，这个期望是取决于系综的“垂直”平均，而不是沿着时间轴的“水平”方向平均。在第 1.4 节中，我们将看到这些不同的平均方法是如何联系的。时间序列分析中特别感兴趣的是 $X(t_1)$ 和 $X(t_2)$ 之间的协方差，$t_1, t_2 \in T$。由于这是同一时间序列内部的协方差，我们将其称为自协方差。

## 平稳时间序列

# 定义 1.3

如果 $X(t); t \in T$ 是时间序列，则对于任意 $t_1, t_2 \in T$，我们定义：

1. 自协方差函数 $\gamma(\cdot)$：
$\gamma(t_1, t_2) = E[[X(t_1) - \mu(t_1)][X(t_2) - \mu(t_2)]]$

2. 自相关函数 $\rho(\cdot)$：
$\rho(t_1, t_2) = \frac{\gamma(t_1, t_2)}{\sigma(t_1)\sigma(t_2)}$

## 1.2 平稳时间序列

在研究时间序列时，通常只有一个实现可用。基于单一实现分析时间序列类似于基于单个观测分析随机变量的。平稳性和遍历性概念对于我们有效地基于单一实现分析时间序列的能力起着重要作用。如果一个过程处于“统计平衡”状态，则认为该它是平稳的。这种时间序列的基本行为不随时间改变。例如，对于这样的过程，$\mu(t)$ 不取决于时间，因此对所有 $t$ 都表示为 $\mu$。似乎每个 $t$ 的 $x(t)$ 提供了关于系均 $\mu$ 的信息，可能基于单一实现估计 $\mu$。遍历过程是指可以从单一实现一致地估计系平均（如 $\mu$）的过程。在本节中，我们将给出平稳性的更正式定义，但我们将对遍历性的讨论进一步推迟到第 1.4 节。
