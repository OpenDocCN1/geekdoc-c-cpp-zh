
The truncated form (assuming only the data $X_1,...,X_{t_0}$ are available) is given

```
$$\hat{X}_t(\ell) = \bar{X} - \sum_{j=1}^{k} \pi_j (\hat{X}_{t-j}(\ell-j)-\bar{X}).$ (11.32)
```

In Section 6.4 we noted that forecasts based on Equation 11.32 the $\pi$ are sufficiently close to zero for $j>t_0-1+\ell$. This will be the case for most ARMA models and for $t_0$ of moderate size. However, for long-memory models, the $\pi$-weights damp very slowly which can cause the truncation in 11.32 to have a substantial effect. Information concerning the relationship between the best linear prediction (based on available data) and forecasts using the truncated $\pi$-weights in the context of fractal and FARMA models and GARMA models, see Miller (1994) and Fu (1995). (See also Ferrara and Guucán, 2001.)
