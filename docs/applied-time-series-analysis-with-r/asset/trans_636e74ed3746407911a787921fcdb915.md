# 第二版序言

我们仍然相信这本书是教授入门时间序列独一无二的著作。我们尽力不提供一个由少数示例补充的模型和方法的汇编。相反，我们投入了大量的精力来提供对模型的见解，我们讨论了来自各种模型的实现的特征，并对基于模型的结果的使用和解释给出了警告。我们已经在我们的项目中成功地将这本书用于博士生以及专业硕士生的教学，并取得了良好的成效。

针对第一版的建议如下：(1) 将计算基础基于 R 语言，以及 (2) 包含更多的真实数据示例。为了解决问题 (1)，我们创建了一个 R 包 *tswge*，该包可在 CRAN 上获取并配合本书。我们在章节内部以及每个章节后的附录中对 *tswge* 函数进行了详细讨论。*tswge* 包包含约 40 个函数，这个数字可能会继续增长。请查看书籍网站 http://www.texas.com/ATSA/index.html 获取更新。我们在整本书中添加了关于 R 使用的指导。特别值得注意的是，第 10 章至第 13 章现在提供了 R 的支持。在第一版中，随附的包 GW-WINKS 仅包含报告这些章节的计算支持。

关于问题 (2)，CRAN 包 *tswge* 包含约 100 个数据文件，其中许多是真实数据集，以及与书中图表和示例相关的大数据集。我们还包含了约 20 个新示例，其中许多与真实数据集的分析有关。

注意：虽然文中不再讨论，但随附第一版的、基于 Windows 的软件包 GW-WINKS 仍然可以在我们的网站 http://www.texas.com/ATSA/index.html 获取，并附有说明。
