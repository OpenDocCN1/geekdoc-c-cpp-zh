Ljung 和 Box (1978) 表，当数据为白噪声时，方程 9.3 中的 $L$ 似近似于自由度为 $K$ 的 $\chi^2$分布。如果测试的数据是拟合 ARMA$(p,q)$ 模型的残差，则该检验在统计上服从自由度为 $K-p-q$ 的 $\chi^2$分布。检查方程 9.3 可以发现，检验统计量衡量了前 $K$ 个样本自相关系数作为一个整体的大小，因此 $L$ 的值表明数据不是白噪声。因此，如果 $L > \chi^2_{1-\alpha}(K-p-q)$，则拒绝白噪声零假设，其中 $\chi^2_{1-\alpha}$ 表示自由度为 $m$ 的 $\chi^2$ 分布的 $(1-\alpha) \times 100\%$ 分位数。我们在示例中使用了 $K=24$ 和 $K=48$ 的 Ljung-Box 检验，这与 Box 等人 (2008) 使用的 $K$ 值一致。对于小样本（$n \le 100$），Box 等人 (2008) 和 Ljung (1986) 建议使用较小的 $K$ 值。

**使用 R：** `tsLboxtest` 执行 Ljung–Box 检验。更多细节请见附录 9A。

## 9.1.3 其他随机性检验

还有许多其他白噪声检验可以使用。白噪声检验本质上是是随机性检验，因此任何此类检验（例如运行检验 runs tests）都可以为此使用。参见 Davis 和 Jones (1968) 关于基于对数周期图的检验。Li (1988) 和 Chan (1994) 开发了比 Ljung–Box 检验对非正态白噪声更稳健的检验。Peña 和 Rodriguez (2002) 开发了一种组合检验，据称在存在正态噪声时是 Ljung-Box 检验更强力的替代方案。

## 9.1.4 残差的正态性检验

关于残差的另一个检查问题是正态性。正态性是 ML 估计的基础。此外，如果不相关的残差是非正态的，存在 ARCH 类型行为的可能性（见 4.2 节）。检查正态性的方法包括使用 Q-Q 图或正式的正态检验，如 Shapiro-Wilk 检验（Shapiro and Wilk, 1965）。其他检验，例如 Anderson-Darling 检验（见 Anderson and Darling, 1952）以及许多其他也可以用于正态检验。在图 9.3 中，我们看到了图 9.2 中标准化残差的 Q-Q 图。航空模型残差的正态性似乎是一个适当的假设，而 PA 温度残差的正态性似乎存疑。无论是 Anderson-Darling 还是 Shapiro-Wilk 检验在 $\alpha=0.05$ 时拒绝正态。

**使用 R：** 有基本函数可以检查正态性。`qnorm(x)` 函数绘制 Q-Q 图，`shapiro.test(x)` 将对数据（向量）执行 Shapiro-Wilk 检验。其他正态检验，包括 Anderson-Darling、Cramer-von Mises 和 Lilliefors (Kolmogorov-Smirnov) 检验，见 Stephens (1974)，可以使用 CRAN 包 `forecast` 中的函数获得。

## 9.2 平稳性与非平稳性

如 8.3 节所述，关于是否在模型中包含非平稳成分（例如 $1-B$、季节性 $1-B$ 等）的决定需要研究人员做出。例如，AIC 不会为你做此类决定。在 8.3 节中提到单位根检验（即模型中的 $1-B$ 因子）。但正如所述，保留单位根是未能拒绝零假设的结果，因此单位根检验通常没有足够的功效来区分接近单位根的和单位根的模型。包含 $1-B$ 因子的最终决定应基于这些考虑，除非有物理理由相信存在均值吸引力。另一个重要问题是，

```
$(1 - \delta B)(X_t - \mu) = a_t,$
```

其中 $\delta$ 接近 1（但不大于 1）可能会显示分段趋势行为。在示例 5.1 中，我们讨论了全球温度数据中的上升趋势由于确定性信号（例如人为）还是简单的随机趋势行为。这在下面的示例中进一步讨论。
