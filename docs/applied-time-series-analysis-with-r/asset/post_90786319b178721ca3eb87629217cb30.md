## 3.2 AR Processes

Let $a_t$, be a white noise process and if $X_t$, $t=0, \pm1,\dots$, $\phi_p$ be real constants with $\phi_p \neq 0$. Then, loosely speaking, is specified by

$X_t-\mu-\phi_1(X_{t-1}-\mu)-\phi_2(X_{t-2}-\mu)-\dots-\phi_p(X_{t-p}-\mu)=a_t, \quad (3.13)$

then $X$, is called an AR process of order $p$, which is usually shortened to AR(p). We will write Equation 3.13 in the operator form

$$\phi(B)(X_t-\mu)=a_t, \quad (3.14)$$

where

the AR(p) model in Equation 3.14 can be rewritten in the form $\phi(B)X_t=\phi(B)\mu+a_t$, by noting that

$$\phi(B)\mu=(1-\phi_1B-\dots-\phi_pB^p)\mu \neq(1-\phi_1-\dots-\phi_p)\mu \neq\phi(1)\mu,$$

can be written as

$\phi(B)X_t = \phi(1)\mu + a_t. \quad (3.15)$

The quantity $\phi(1)\mu$ is referred to as the $MA constant$. The model in Equation 3.13 is often simplified by letting $\tilde{X}_t = X_t - \mu$, which results in

$\tilde{X}_t - \phi_1\tilde{X}_{t-1} - \phi_2\tilde{X}_{t-2} - \cdots - \phi_p\tilde{X}_{t-p} = a_t, \quad (3.16)$

corresponding to Equation 3.13. Henceforth, unless specified differently, we will without loss of generality assume $\mu = 0$ so $\tilde{X}_t = X_t$, and we will specify the AR(p) model as

$X_t - \phi_1X_{t-1} - \phi_2X_{t-2} - \cdots - \phi_pX_{t-p} = a_t, \quad (3.17)$

or

$\phi(B)X_t = a_t. \quad (3.18)$

Likewise, the $MA(q)$ model in Equation 3.1 will usually be written assuming $\mu = 0$.

NOTE: When using the AR(p) or $MA(q)$ to model a given set of stationary time series data, it will be the standard procedure to first estimate $\mu$ by $\bar{X}$, subtract $\tilde{X}$ from each observation, and model the remaining data using the "zero mean" model.

As noted, the $MA(q)$ process is a special case of the general linear process, in which only a finite number of $\psi$-weights are nonzero. Examination of Equation 3.17, however, does not immediately reveal the relationship between the AR(p) process and the general linear process. Actually, the specification of an AR(p) process as given by Equation 3.17 is inadequate since Equation 3.17 has many distinct solutions, and to this point, we have failed to specify which solution we wish to consider. For example, if $X_t$ is a solution of Equation 3.17 and $\phi(B)y_t=0$, then $X_t + cy_t$ is also a solution of Equation 3.17 for any constant $c$. Consequently, Equation 3.17 has an uncountable number of solutions. However, if $c \neq 0$, all of these solutions are nonexistent, and for now our interest is in stationary solutions. This leads us to the following definition:

### 3.2

Suppose $\{X_t; t=0, \pm1, \pm2, \dots\}$ is a causal, stationary process satisfying the difference equation

$$\phi(B)(X_t - \mu) = a_t.$

Then, $X_t$ will be called an AR process of order $p$ and denoted AR(p). Again, we will take $\mu=0$ unless indicated to the contrary.

To clarify Definition 3.2, consider the AR(1) model

$$\phi(B)X_t = (1-\alpha B)X_t = a_t,$$

where $|\alpha| < 1$. Noting that $B\alpha^{-t} = \alpha^{-(t-1)}$, then

$$(1-\alpha B)X_t = \alpha'(1-B)\alpha^{-t}X_t,$$

which can be shown by expanding each side to obtain $X_t - \alpha X_{t-1}$. The two operators $1-\alpha B$ and $\alpha'(1-B)\alpha^{-t}$ are equivalent, that is,

$$1-\alpha B = \alpha'(1-B)\alpha^{-t}.$

Therefore,

$$\alpha'(1-B)\alpha^{-t}X_t = a_t.$

So

$$(1-B)\alpha^{-t}X_t = \alpha^{-t}X_t,$$

and

$$\sum_{k=-\infty}^{t}(1-B)\alpha^{-k}X_k = \sum_{k=-\infty}^{t}\alpha^{-k}a_k,$$

which gives

$$\alpha^{-t}X_t - \lim_{j=-\infty}^{t}\alpha^{-j}X_j = \sum_{k=-\infty}^{t}\alpha^{-k}a_k.$

Since $|\alpha| < 1$, it follows that $\alpha^{-t}X_j = 0$ with probability 1. Consequently,

$$X_t = \sum_{k=-\infty}^{t}\alpha^{t-k}a_k,$$

$= \sum_{h=0}^{t}\alpha^h a_{t-h}.$

## Theorem 3.1

Let X, be causal and cause suppose

```
$\phi(B)X_t = (1-\alpha_1 B)(1-\alpha_2 B)\cdots(1-\alpha_p B)X_t = a_t,$(3.25)
```

where the $\alpha_k$ are real or complex numbers, $\alpha_k \neq \alpha_j, k \neq j$, $|\alpha_k| < 1, k=1, \dots, p$, and $a_t$ is zero mean white noise. Then, X, is an AR(p) process and

```
$X_t = \sum_{\ell=0}^p \psi_{\ell}(p)a_{t-\ell},(3.26)
```

where

- a. $\psi_1(p) = \alpha_1^{p-1}$ for $p=1$
- b. $\psi_k(p) = \frac{\alpha_k^{-p-k}(\alpha_k^{p+1}-\alpha_j^{p+1})}{\alpha_k-\alpha_j} \prod_{h \neq k}^{p-k} (\alpha_{p-k}-\alpha_h)$, for $p \geq 2$.$(3.27)
