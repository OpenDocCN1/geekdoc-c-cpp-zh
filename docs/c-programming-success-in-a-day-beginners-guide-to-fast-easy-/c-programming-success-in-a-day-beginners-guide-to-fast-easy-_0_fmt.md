return 0;
}

## <time.h>

请注意，你必须首先用`time_t`类型声明变量`sec`。该函数引入了一个变量，可以从机器的时间寄存器中提取数据。如果你想显示特定点的时间和日期，在这种情况下仅仅使用`int`将不再有效。
