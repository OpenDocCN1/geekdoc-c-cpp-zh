# DID YOU KNOW?

In 1995, the first completely computer-animated movie, *Toy Story*, arrived in theaters. Created by Pixar, the movie was an instant hit. Since then, Pixar has released more than 15 other movies. Each one has brought new innovations to the world of computer animation.

Some movies are completely computer generated. Companies such as Pixar and DreamWorks create animated movies solely on computers. They use software created especially for the task. Programmers who make this animation software find ways to make things move in realistic ways. They also figure out how to make light and shadows look realistic in a scene. In the world of movies, artists and programmers work together to make beautiful films.
