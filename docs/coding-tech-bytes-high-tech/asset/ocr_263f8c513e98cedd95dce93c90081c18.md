# Coding for Virtual Spaces

Another field that will require creative coding is virtual reality. Virtual reality immerses the user in an entirely different world. A user puts on a headset and is transported to a virtual location. Small screens in front of the eyes create the illusion of being in a three-dimensional environment. Headphones produce noises that sound as if they are coming

from specific directions. And when the user turns his or her head, the screens and headphones work together to match this movement in the virtual world.
