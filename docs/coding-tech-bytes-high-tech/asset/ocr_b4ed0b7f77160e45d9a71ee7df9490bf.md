# # Websites

**Code Academy** (https://www.codecademy.com/) The Code Academy website features free lessons on many different programming languages, including Python, Java, and Ruby.

**Made w/Code** (https://www.madewithcode.com/) The Made w/Code site, run by technology company Google, features many fun and interesting coding projects.

**Hour of Code** (https://code.org/learn) The website for the Hour of Code has links to dozens of coding tutorials. Many of the tutorials feature popular characters, such as those from the Star Wars films and Minecraft.

**Scratch** (https://scratch.mit.edu/) The Massachusetts Institute of Technology (MIT) runs this coding site, which uses an easy-to-learn programming language called Scratch to introduce users to coding concepts.

**Lightbot** (https://lightbot.com/) On the Lightbot website, users can tackle puzzles using basic programming concepts, helping them to think like coders.
