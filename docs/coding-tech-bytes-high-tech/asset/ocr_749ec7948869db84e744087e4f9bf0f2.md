# # Self-Modifying Code

What happens when a program becomes its own programmer? Though human programmers try to make software that can work perfectly, they can't anticipate every issue that may arise. Instead of the programmer having to go back in and rework the code, a self-modifying program could just rewrite its own code. The hope is that such smart software would be able to adapt itself to carry out complex tasks. For example, the US government hopes to make self-learning computers that can assess situations based on huge amounts of complex information. Computers can store vastly more data than human analysts. A smart, adaptable computer with access to all this information may be able to suggest the best decisions in high-stakes situations, such as natural disasters or wars.
