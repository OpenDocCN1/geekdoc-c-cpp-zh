Amazing technological breakthroughs are happening all the time. Scientists and engineers bring new ideas to life, and businesses make them real. Tech Bytes: High Tech explores some of the extraordinary devices and systems that are changing the modern world. Explore the history of these high-tech inventions, what obstacles their inventors encountered along the way, and how these technologies can become a part of society’s culture. Each book contains fast facts, a glossary, an index, and places to go for more information.

# Coding

Coding is the process of giving computers instructions in a language they can understand. It has unlocked the power of modern technology, allowing a computer to complete any task a coder can dream up. Learning to write code is becoming an important skill in our high-tech world.

# DID YOU KNOW?

+   - There are hundreds of different programming languages that coders use.
+   - A single computer program can have millions of lines of code.
+   - Everything that happens on a computer, from video games to spreadsheets to browsing the Internet, has code behind it making it work.
