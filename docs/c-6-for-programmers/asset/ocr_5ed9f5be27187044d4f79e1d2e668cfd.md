As with generic methods, the type-parameter list of a generic class can have one or more type parameters separated by commas. Type parameter T is used throughout the Stack class declaration (Fig. 18.5) to represent the element type. Class Stack declares variable `elements` as an array of type `T` (line 8). This array (created at line 25) will store the Stack's elements. [Note: This example implements a Stack as an array, but they also can be implemented as linked lists.]
