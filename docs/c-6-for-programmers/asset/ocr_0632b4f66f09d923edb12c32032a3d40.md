# *Universal Windows Platform (UWP) for Desktop and Mobile Apps*

The Universal Windows Platform (UWP) is designed to provide a common platform and user experience across all Windows devices, including personal computers, smartphones, tablets, Xbox and even Microsoft’s new HoloLens virtual reality and augmented reality holographic headset—all using nearly identical code.²

*Code Highlighting.* We emphasize key code segments by placing them in gray rectangles.
