assigns to myAccount’s Name property the string entered by the user in line 17. When property Name is invoked by the expression myAccount.Name on the left of an assignment:

+   2. Property Name’s set accessor performs its task—that is, it stores in the myAccount object’s name instance variable the string value that was assigned to property Name in Main (line 18).
+   3. When Name’s set accessor completes execution, program execution returns to where the Name property was accessed (line 18 in Main), then execution continues at line 21.

accesses myAccount’s Name property again, which causes the property’s get accessor to obtain the name instance variable’s new value. As you can see, the last line of the program’s output displays the name input from the user in line 17.
