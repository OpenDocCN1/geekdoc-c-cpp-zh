The outer loop begins by setting the row index to 0 so that row 0's elements can be totaled by the inner loop. The outer loop then increments row to 1 so that row 1's elements can be totaled, then increments row to 2 so that row 2's elements can be totaled. The total can be displayed when the outer for statement terminates. The next example shows how to process a rectangular array in a more concise manner using foreach statements.
