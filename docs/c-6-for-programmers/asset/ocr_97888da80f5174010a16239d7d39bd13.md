# Control Statements: Part 2

# Objectives

In this chapter you'll:

+   - Use counter-controlled iteration.
+   - Use the for and do...while iteration statements.
+   - Use the switch multiple-selection statement.
+   - Use strings in switch expressions and string literals in case labels.
+   - Use the break and continue program-control statements to alter the flow of control.
+   - Use the logical operators to form complex conditional expressions.
+   - Understand short-circuit evaluation of the conditional && and || operators.
+   - Use type decimal to avoid the representational errors associated with using floating-point data types to hold monetary values.
