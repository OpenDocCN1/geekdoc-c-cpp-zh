# ### Overloaded Operators

Lines 24–28 overload the plus operator (+) to add `ComplexNumbers`. Keyword `operator`, followed by an operator symbol (such as `+`), indicates that a method overloads the specified operator. Overloaded operator methods are required to be `public` and `static`.

Methods that overload binary operators must take two arguments—the first is the left operand and the second is the right operand. Class `ComplexNumber`'s overloaded `+` operator takes two `ComplexNumber`s as arguments and returns a `ComplexNumber` that represents the sum of the arguments. The method's body adds the `ComplexNumber`s and returns the result as a new `ComplexNumber`.
