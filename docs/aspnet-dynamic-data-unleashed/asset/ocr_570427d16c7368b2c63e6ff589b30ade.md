Out of the box, Dynamic Data does not allow you to take advantage of custom entity properties. The next section discusses how to overcome this limitation.

# Implementing Support for Custom Properties

The Dynamic Data metadata API discussed in Chapter 7 does support custom properties. In particular, the MetaColumn class has a property called IsCustomProperty, which returns true when the entity property the column represents was not defined in the .EDMX or .DBML file. The trouble, however, is that Dynamic Data does not create MetaColumn objects for custom properties. Figure 13.4 shows a screenshot of the metadata page for the Product entity. Notice that the Country property is missing from the list of columns on the right even though it was already defined in the class.
