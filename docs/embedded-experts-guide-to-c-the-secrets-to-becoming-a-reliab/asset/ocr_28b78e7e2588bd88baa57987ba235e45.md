Fig 7.4 - Conditional compilation should be used in every header file to prevent multiple inclusions of the same file. Conditional compilation is also required for compatibility with C++ compilers.

One of the most common uses of conditional compilation is in header files. It is usual for the entire contents of the file to be wrapped in a #ifndef ... The #ifndef is invariably followed by a definition of the very symbol being checked. This is known as an include guard and prevents the file from being included more than once – after the first inclusion subsequent evaluation of the #ifndef directive will be false and the contents of the file is therefore ignored. It is good practice to use include guards in every header file.
