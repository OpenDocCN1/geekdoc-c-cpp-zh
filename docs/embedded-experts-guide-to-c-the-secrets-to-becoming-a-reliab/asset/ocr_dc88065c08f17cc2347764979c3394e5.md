Fig 5.2a & b - Type punning is used to treat a variable in memory as though it is another type. It can be achieved either by casting a pointer to the first type to a pointer to the second type or by accessing both types through a union. Neither method is well-defined in the C Standard, but both a widely used and supported. Don’t let that make you complacent – the result could be some unexpected and hard to track software defects.
