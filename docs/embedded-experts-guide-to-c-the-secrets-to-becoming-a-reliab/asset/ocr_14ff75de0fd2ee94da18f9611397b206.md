# POSIX

The histories of the C language and the Unix operating system and thoroughly intertwined; they were initially developed almost in parallel and computer scientist Dennis Ritchie was heavily involved in both. As computers became more affordable and widespread, many new variants of Unix and other Unix-like operating systems emerged; this led to efforts to develop a standardised interface for operating systems to maintain compatibility between them and ensure portability of programs from one operating system to another. This resulted in the IEEE publishing the first version of the POSIX (Portable Operating System Interface) standard in 1988. Development has continued and the most recent version of the POSIX standard (at the time of writing) was in 2017.

POSIX was developed with C compatibility in mind and the C Standard Library includes features to provide compatibility with POSIX. Standard methods are provided for creating and managing inter-process messaging, and many other common tasks. A number of additional signals are also introduced by POSIX; although these are not part of the C Standard they are common across all POSIX operating systems so remain relatively portable. Simply, the POSIX allows the C Standard Library to be significantly expanded in a way which is portable, provided the target system runs a POSIX compliant operating system. This makes POSIX compliant operating systems a good choice when deciding which system to use. The unistd.h header file provides much of the POSIX API for the C language.
