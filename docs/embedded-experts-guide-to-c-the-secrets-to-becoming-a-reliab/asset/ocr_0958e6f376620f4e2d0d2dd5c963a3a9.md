Optimising Software

If you are following the rules found in this book, you should find it easier to write code works reliably and efficiently. There are, however, occasions when performance is not quite good enough. When this happens, you need to think about optimisation.

Optimisation is a topic which is discussed a lot but often poorly understood, particularly by less experienced programmers. Discussions often focus on the speed at which software runs, but this only one type of optimisation. Memory usage, power consumption and electromagnetic performance can all be Much of the advice which can be found on this topic is written from the perspective of general-purpose computer programmers; the modern processors found in such computers incorporate many features which are less commonly available and potentially even undesirable in an embedded system. Furthermore, the goal of optimisation on such a system is almost always to reduce the overall time taken for the code to run. While there is certainly some overlap in principles, it is important to remember embedded systems are often constrained in ways general-purpose ones are not.
