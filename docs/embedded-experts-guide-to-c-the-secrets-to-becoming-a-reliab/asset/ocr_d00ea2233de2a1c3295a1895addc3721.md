Indentation may also be used to improve readability of preprocessor blocks. Although it is conventional for the # preceding preprocessor directives to be located at the start of the line, this may be followed by whitespace without changing the meaning of the directives that follow; this can be useful in the same way that indentation of blocks within the code is useful when using conditional macro definitions or other directives within a #if block.

```
/* Indentation of preprocessor directives is
 * allowed - but the ‘#’ may still be placed at
 * the start of the line. */
#if defined(APPLES)
# define PEARS
#endif
```
