Even when a loop cannot be unrolled, there are often other optimisations which can be made. Expressions which do not change from one iteration to the next can be moved outside of the loop so they do not need to be repeatedly evaluated. Even though this may require the declaration of additional, temporary variables (which may well be stored in a register anyway), this can still result in a significant performance boost. Similarly, conditional statements which are evaluated within a loop can be moved outside the loop if the evaluation does not change between iterations.
