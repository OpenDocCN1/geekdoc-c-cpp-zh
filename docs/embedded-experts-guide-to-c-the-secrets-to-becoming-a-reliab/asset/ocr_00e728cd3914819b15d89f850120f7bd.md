```
/* Select the larger of two values. */
#define MAX(VA_, VB_) \
((VA_) > (VB_) ? (VA_) : (VB_))
/* Select the smaller of two values. */
#define MIN(VA_, VB_) \
((VA_) < (VB_) ? (VA_) : (VB_))
```

However, both macros are severely flawed because one of the arguments will always be evaluated twice. It is often difficult or even impossible to implement even seemingly straightforward statements in a way which is guaranteed to be safe using macros; in such cases it is always much safer to use a function instead.
