Other than primitive data types (in C, these are pointers, integer and floating point variables in memory are stored in organised collections of primitive types known as data the C language only supports three types of data structure: arrays, records (which in C are known as structures or structs) and unions. Using the three types a data structures supported by C as building blocks, it is possible to create many other types of data structure, which include queues, stacks, and lists. These compound types are useful, because they allow the programmer to manage memory and to efficiently implement a number of algorithms which cannot be easily performed using only built-in types.

# Arrays

Arrays are the most basic data structure available in C. An array is a collection of variables of the same type which may be identified by their index. Arrays are always allocated as a continuous region in memory; because of this, arrays may also be accessed efficiently using pointers: the (partial) statement array[index] is equivalent to and either form may be used to access any array. This easy and useful relationship between arrays and pointers sometimes results in statements claiming the two types are essentially equivalent – this is untrue despite their compatibility there are a few occasions where the two cannot be used interchangeably (you cannot assign a new address to an array, for instance). There is also an important distinction between them in terms of memory allocation: whereas a pointer definition allocates only the space needed for the pointer variable itself, an array definition allocates all the space required to store the array.
