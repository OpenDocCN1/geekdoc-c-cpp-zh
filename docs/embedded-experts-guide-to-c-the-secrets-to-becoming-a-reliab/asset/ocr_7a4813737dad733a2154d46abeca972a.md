# Endnotes for Chapter 7 - The c processor

1 Translation refers to the process of converting C source code into an executable program or library. This is often referred to as compilation, although compilation is only a single step in the process. The distinction may appear pedantic, but it is an important one if the whole process is to be thoroughly understood.

2 In simple terms, a Turing complete language is one which, at least in theory, can be used to perform any computable function. Finding the smallest prime factor of any natural number is a computable function, but not always a practical one to evaluate; determining whether an arbitrary program will ever terminate (the “halting problem”) is not. The concept of Turing completeness is of mostly academic interest and does not necessarily reveal anything about the usefulness of the “language” as a general-purpose tool. Most modern programming languages are Turing complete. Surprisingly,.so are Microsoft PowerPoint and the game Minesweeper.
