# Fig 11.2 Signals

A minimal example of registering a signal handler. Assuming the initial call to signal() is successful, this program will wait until a SIGINT signal arrives and then execute the signal handler function. Although this is valid C, the C Standard does not specify how or when a signal is sent to an application – or even if the operating system is required to send signals at all.

Other signals may also be available, but their meanings will be implementation defined. If the application wishes to generate a signal of its own, it can do so using the raise function, which results in an indirect call of the relevant signal handler. If and when signals are raised, other than by a call to the raise function, is implementation defined.
