A pool may be either generic or resource specific. A generic pool consists of an array of char arrays, while a resource specific pool consists of an array of whatever the most appropriate type is (which may itself be a collection type, such as an array or structure). The implementation in both cases can be the same. One simple implementation is to use what is known as a free A free list consists of individual pools connected to form a linked list. When a pool is allocated, it is removed from the list. When the pool is freed, it is added back into the list. No overhead needs to be associated with the link pointers in each pool: when the pool is allocated, the pointer can be overwritten with the data the pool is used to store as the list only contains the free pools. Using a union to combine the pointer and the pool data as a single variable is therefore a logical method to use when implementing pools.

```
/* Implement a pool allocator for TOTAL_POOLS
 * pools. Each pool is a block of POOL_SIZE
 * chars. */
/* Create the basic pool type from a union. When
 * allocated, p_next_pool can simply be
 * overwritten. */
typedef union pool_u
{
    union pool_u * p_next_pool;
    char pool_data[POOL_SIZE];
} pool_t;
/* Create an array of pools. */
static pool_t pools[TOTAL_POOLS];
/* Create a pointer to track the next pool to
 * be allocated. */
```
