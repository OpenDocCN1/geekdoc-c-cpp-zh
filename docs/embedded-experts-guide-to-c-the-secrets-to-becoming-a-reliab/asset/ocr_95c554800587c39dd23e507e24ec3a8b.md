This is not a problem for the compiler: in practice, an else statement is always paired with the nearest if Rather, the problem is one of ambiguity in what was intended by the programmer. Without additional information, there is no way of knowing if the observed behaviour is the intended behaviour or not. There is a simple way to remove this ambiguity: always enclose the code controlled by an if or else statement in braces, even if it consists of only a single statement. This not only eliminates the ambiguity associated with the dangling else, it reduces the likelihood of many other common mistakes being made as well. In fact, this advice does not only apply to if statements, it applies to loops as well. Including the braces will not have a negative impact on the performance of your code. It will make it less likely that avoidable errors creep in and less prone to misinterpretation later.
