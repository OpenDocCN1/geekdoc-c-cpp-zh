# Fig 3.3 Stacks

Stacks are an efficient way to store data when it must be read in the opposite order to which it was written, i.e., the most recent element to be written in the first to be read.

Stacks are useful for reading data in the reverse order to which it was written; they can be used to rollback events and return an application to an earlier state – familiar examples are the “undo” and “back” operations in many desktop software packages.
