You can define memory segments using the SECTIONS keyword. There are some standard segments you will come across repeatedly: text, data and BSS. Text is the name given to segments which contain executable code. # Symbols

It is also possible to use a linker script to define symbols. If these symbols are assigned a value as part of a SECTIONS command, then they can be given external linkage and can be referenced in code, although some additional commands may be required to ensure this is the case.
