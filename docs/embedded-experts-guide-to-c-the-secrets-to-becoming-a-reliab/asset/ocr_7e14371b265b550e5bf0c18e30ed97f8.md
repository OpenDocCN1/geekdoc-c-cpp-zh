Structures can be thought of as a means of creating custom, compound types, although, because C does not support operator overloading, there are limits to the ability of the programmer to fully integrate these new types into the language – the assignment operator can be used for the entire structure, rather than individual members, provided the source variable is a compatible structure, but most other operators cannot.

/* Define a custom type using a struct.
 * The new type is “struct fruit_type_s”, not
 * “fruit_type_s”. */
struct fruit_type_s
{
int16_t fruit_id;
char fruit_name[32];
}
/* Give the new type a more straightforward
 * name. We can now declare instances of the
 * type as “fruit_type_t” rather than
 * “struct fruit_type_s”. */
typedef struct fruit_type_s fruit_type_t;
