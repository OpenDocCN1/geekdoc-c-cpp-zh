Wherever possible, alternatives to global variables are to be preferred.
When data must be shared between functions, prefer a pointer to the data
in the function arguments instead. This may not always be possible,
particularly when working with interrupt service routines and callbacks. If
possible, qualify the global variables as static to limit their visibility to the
current module only. It’s also a good idea to qualify them as either volatile
or const as well – the former will prevent the compiler from making
