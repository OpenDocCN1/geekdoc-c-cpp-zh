12 To understand why this is the case, consider the fact a while loop evaluates the terminating condition first, which requires a conditional branch to the code after the loop when the terminating condition is met and an unconditional branch at the end of the loop back to the start; a do ... while loop evaluates the condition at the end of the loop, so requires only a single conditional branch back to the start of the loop. Wrapping the do ... while in an if statement requires an additional conditional branch, but crucially it is only evaluated once rather than on each iteration of the loop.
