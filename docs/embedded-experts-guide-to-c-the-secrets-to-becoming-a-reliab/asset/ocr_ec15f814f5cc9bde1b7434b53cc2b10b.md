The C preprocessor provides directives to allow conditional compilation. These are the #else and #elif (else-if) directives. A preprocessor #if block must be explicitly closed using the #endif directive. Braces are not used to delimit the blocks of code between conditional directives. The #if directive is used to check whether a condition is true at compile time; if the condition evaluates to true, the code which follows will be included in the translation unit until the preprocessor encounters another conditional directive or If the condition evaluates to false, the code will be removed. The code between the directives may be C, preprocessor directives or a combination of both. Conditional compilation is most useful when relatively small amounts of code need to be changed based on conditions which will only be known a compile-time. These conditions can vary significantly – they could be compiler specific; platform specific, such as the processor being used; or even application specific, where you may not wish to include certain features within a particular version of a product. Anything which would normally be allowed within a C file is acceptable within a conditional compilation block. As well as blocks of C, this includes defining macros and including header files. Functions and variables may be declared or defined within conditional compilation blocks but bear in mind any references to these will also need to be conditional. If required, conditional compilation may also be used to abandon compilation if certain prerequisites are not met.
