The final phase of the translation process is called linkage and is performed by a linker. Although the output of Phase 7 is machine code, it is not useful machine code because it cannot be run immediately. The linker has several important tasks to perform:

Firstly, if a program is built from multiple source files, the linker must combine these into a single piece of executable code. At this point, all references to external functions and variables must be resolved.

Secondly, the linker must determine how the machine code should be arranged in the target platform’s address space. This is not simply a case of arranging blocks of code – jump instruction and variable addresses will need to be changed in order to complete this stage.

The linker may need to generate some code. This code will typically create an initial stack for the program to use, may also create a heap and any additional code to determine how the program starts executing. This may be as simple as a jump instruction from the reset vector (the first address accessed by the processor after powering on or a reset) to the main function for software intended to run outside of a hosted environment.
