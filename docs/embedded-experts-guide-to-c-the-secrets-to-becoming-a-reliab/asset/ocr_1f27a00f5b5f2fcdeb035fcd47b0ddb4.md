It is, however, entirely possible to achieve; the Diffie-Hellman key exchange was the first such scheme to be publicly proposed and continues to see widespread use.

Other key exchange algorithms exist. They will not be covered in detail here because, like asymmetric ciphers, there are already a number of libraries for implementing them. There also remains the problem of verifying that the key exchange is taking place with the correct party, which is not a trivial problem to solve. A degree of trust is required for most solutions; for instance, the X.509 certificate standard is a critical part of the TLS protocol used to secure network traffic, but ultimately relies upon a number of trusted certificate authorities to vouch for the authenticity of the certificate; if a certificate authority is compromised in some way (which has been known to then certificates issued by that authority may no longer be relied upon.
