Historically, embedded operating systems have mostly also been real-time operating systems – they are guaranteed to run tasks according to strict time Despite this, there is still relatively little standardisation of how operating systems implement these functions, particularly for simpler operating systems, and software written to work with one system is unlikely to be easily portable to another. Examples of embedded operating systems which behave in a proprietary manner are:

+   Azure RTOS (previously ThreadX).

+   FreeRTOS. (and the related),

+   SAFERTOS and

+   OPENRTOS.

There have been some efforts to standardise operating systems, the most successful of which is POSIX. This is briefly described in the next section, although operating systems which are truly POSIX compliant are relatively rare and somewhat more complex than can be supported by smaller embedded systems.
