One specific benefit of multitasking is it can be used to eliminate many instances of busy waiting from code. Busy waiting (also known as spinning) is a technique used to wait for a resource to become available. It will often take the form of an empty while loop which continuously checks to see if the required resource is available. No other processing can take place while a busy wait is running, which is often considered undesirable, although there are times when no alternative is possible.

```
/* Start a new conversion. */
adc_start_conversion();
/* Wait for sampling to finish. */
while (!adc_finished())
{
/* Stay in the loop until done. */
}
/* Make a copy of the sample and continue. */
new_sample = adc_read();
```

Fig 10.1 - A simple busy wait loop; in this case, the software is waiting for an ADC conversion to complete; the ADC hardware is queried on each loop iteration to determine if the sampling has completed. Depending on the hardware and sample frequency used, this could take some time, during which the CPU could devote cycles to other, useful activities.
