Typical input sources used with GPIOs include components such as switches or jumpers (pins which may either be connected or disconnected as a means of configuring a device). Output loads include components such as LEDs and other indicators. Groups of GPIO connections can often be used to implement more complex interfaces. These simple examples are by no means all that can be achieved with GPIO, although it is often preferable to use dedicated hardware interfaces for many tasks.

Although it is occasionally necessary for an input to generate an interrupt when its state is changed, most inputs can be continuously polled, or sampled, without requiring dedicated interrupts or service routines. Sampled inputs are those which are checked to determine their value; these may be digital inputs or the inputs to dedicated analogue-to-digital converters. Crucially, it is usually possible to read multiple inputs simultaneously which significantly reduces the code complexity associated with them. Sampling is most commonly periodic and driven by a timer interrupt, although alternative methods of triggering a sample are possible.
