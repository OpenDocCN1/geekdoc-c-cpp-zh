# Bootloading

![](bbox=[0.25, 0.33, 0.45, 0.64])

The bootloader is always the first code to run after power is turned on or the processor is reset. The bootloader checks for new software - if there is a new application available, it overwrites the old one (possible using some of the free space). If no new application is available, or if loading has been completed, the bootloader calls the application entry function and the application runs as normal.

Fig 11.1 - A simple bootloader sits alongside the application (sometimes called the “bootloadable”) within program memory. When the system is first activated, the bootloader checks for new software and either overwrites the application or allows it to run. More advanced bootloaders can choose from multiple applications at run-time.
