It is much easier to diagnose a single, clear error than it is to interpret multiple generic compiler messages, or worse, the unexpected runtime behaviour which occurs when a default case is assumed. Some preprocessors also include a means of issuing custom warnings without abandoning compilation.

While this can be useful, warnings are more easily ignored than errors and no method of issuing custom warnings has yet been included as part of the C Standard, so vendors have chosen to implement this in various inconsistent ways.
