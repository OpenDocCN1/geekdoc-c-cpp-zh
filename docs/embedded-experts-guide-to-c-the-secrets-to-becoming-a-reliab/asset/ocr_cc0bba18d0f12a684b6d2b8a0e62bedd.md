Much of the interaction between applications and the operating system can be through wrapper functions provided as part of Application Programming Interface (API) specific to the operating system being used. There are also some features within the C Standard Library which can help, although their behaviour will still vary depending on the compiler and operating system being used.

In very simple cases, the only communication between the operating system and an application will occur when the application's main function is called and when it returns. In a hosted environment, the main function may, dependent on the operating system and compiler, be to able accept arguments and return a value; usually the return value is an int and the arguments are an to communicate the number of arguments being passed, and a char ** which points to an array of strings containing the arguments, but exact details are implementation defined. If such is present, then it allows some configuration of the application to be performed immediately before the program begins to run as well as allowing it to return a value to the operating system when it terminates. Although any value may be returned, the C Standard provides two macros, EXIT_FAILURE and to indicate whether the program ran successfully or not, and any other return value is interpreted in an implementation defined manner.
