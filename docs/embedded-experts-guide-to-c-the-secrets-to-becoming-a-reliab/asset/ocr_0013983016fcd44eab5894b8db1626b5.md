There is far greater choice when considering operating systems which are either compliant but not certified, or mostly compliant. Most versions of Linux and BSD-descended operating systems fall into this category.

There is a great deal more which could be said about multitasking, bootloaders and operating systems – these are advanced topics somewhat beyond the scope of everyday C programming (and, indeed, the C Standard); entire books have been written on each of these topics. However, it is important to have an appreciation of all three subjects, especially as the distinction between embedded and more general-purpose applications becomes increasingly blurred and embedded operating systems grow in both size and complexity – in some cases being comparable to their desktop counterparts.
