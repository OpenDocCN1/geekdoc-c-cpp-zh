Callbacks are also more flexible than using conditional statements since complex selections using such statements can often be simplified to relatively simple pointer arithmetic or array accesses. Perhaps the greatest advantage of callbacks is they provide an additional level of abstraction which allows low-level hardware drivers to be written without needing to modify them for every individual application. This also allows the low-level modules to be hidden from the application programmer, preventing them from inadvertently changing the behaviour from what was intended, or conversely, preventing changes in the low-level modules necessitating a rewrite of the application-level
