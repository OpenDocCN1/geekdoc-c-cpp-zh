Fig 4.3 The previous calculator example may also be implemented using callbacks; each operator is now provided by a separate function, with pointers to those functions stored in an array. The array index for the required operator corresponds with the enumerator value for that operator.

The major disadvantage when using callbacks is they are still pointers and therefore come with all the same problems as other pointers – crucially, it is still the programmer's responsibility to ensure the pointer is valid. In fact, there is an additional risk when using callbacks compared with other pointers – attempting to dereference an invalid pointer to a function will result interpreting whatever happens to be at the pointed-to address as executable instructions, which could have catastrophic consequences (and is most definitely an example of undefined behaviour).

Callbacks are implemented using pointers to functions. This allows a reference to the function to be treated as any other variable would be: the function pointed to can be changed and the reference can be passed to other functions as an argument or it can be stored in an array of similar references as required.
