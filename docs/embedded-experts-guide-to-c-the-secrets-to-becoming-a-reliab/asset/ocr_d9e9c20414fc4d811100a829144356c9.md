Additionally, they have two that cause their outputs to deviate from being statistically (as opposed to truly) random: first, the output sequence will eventually return to its starting value and begin to repeat; second, within a single period of the sequence, no value will appear more than once.

```
/* SEED can be any number other than 0. */
#define SEED 0x12345678UL
/* Generate a 32-bit pseudorandom number using
 * an XOR shift LFSR. */
uint32_t lfsr32(void)
{
    static state = SEED;
    /* The number of bits to shift can change, but
     * should be chosen to give a maximal-length
     * LFSR. */
    state ^= state << 13;
    state ^= state >> 17;
    state ^= state << 5;
    return state;
}
```
