The register keyword is one of the original storage classifiers included in the C It indicates a variable should be stored in a way which allows the fastest possible access to the variable; in most cases, particularly on older systems, this is achieved by storing the variable in a CPU register. The compiler, however, is free to store the variable in main memory if it chooses. However, most modern compilers will store variables in registers wherever possible by default, so the keyword is effectively redundant and unlikely to result in any noticeable improvement to code performance. There is, however, one important side effect of qualifying a variable using since registers are not addressable in the same way as other memory, it is not possible to reference a variable using pointers. This is true whether the compiler ultimately places the variable in a register or in main memory. Given this restriction and the lack of any benefit in most cases, there is little reason to use the register keyword.
