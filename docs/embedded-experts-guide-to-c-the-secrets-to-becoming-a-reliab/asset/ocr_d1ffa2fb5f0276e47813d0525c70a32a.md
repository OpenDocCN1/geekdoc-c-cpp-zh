The symbols to be checked need not be defined in the code itself. Various preprocessor symbols may be defined in the development environment, either as a requirement of the C Standard or as implementation specific additions. There is also usually an option to define custom symbols within the environment without having to edit the files being compiled. For instance, since C95, the C Standard requires the symbol __STDC_VERSION__ to be defined with a value which indicates which version of the standard the compiler is designed to work with. The conditional part of #if and #elif directives is not limited to checking for definitions. Any statement which can be evaluated prior to compilation can be used. This functionality is not used as widely as simply checking for a definition, but is still useful; for instance, if a piece of code requires a compiler to meet a particular version of the C Standard but alternative code can be used for other compilers.

A statement such as #if __STDC_VERSION__ == 199901L can be used in such instances (in this case, the statement will be evaluated as true for a C99 compiler).
