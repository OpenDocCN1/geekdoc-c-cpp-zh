6 Device vendors provide a HAL for their devices, at least modern ones, which certainly aids porting software between devices within the same family, even if it has no benefit in terms of porting that software to a device from another family or another vendor. A well-written operating system should be designed to be portable across many different devices and may therefore add an additional API layer on top of the vendor's HAL to further improve portability. However, relying on the HAL is not without disadvantages, particularly when there are strict timing requirements that must be met. There is much on-going debate around the merits of using a HAL versus so-called bare-metal programming where application software interacts directly with hardware.
