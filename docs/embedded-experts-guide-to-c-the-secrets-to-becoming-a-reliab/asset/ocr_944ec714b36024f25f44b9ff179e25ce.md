The simplest such code involves repeating each bit three times; this allows many transmission errors to be corrected but triples the number of bits that must be sent. Additional repetitions incur greater overheads and repeating only twice provides no benefit compared to no repetition. Slightly more efficient is the Hamming (7,4) code, which encodes four input bits into a seven-bit output – each additional bit is a parity bit for three of the four original data bits – while still allowing all single-bit errors to be corrected. Other Hamming codes exist which can be used to not only correct single errors but to detect double errors as well at the expense of increased overhead.

/* Calculate the parity bit for one byte. */

uint8_t parity (uint8_t byte)
{
    byte ^= byte >> 4;
    byte ^= byte >> 2;
    byte ^= byte >> 1;
    return byte & 1U;
}
