Pointers are variables which store the address of another location in memory. They are often referred to as a reference type and are the only such type available natively in C – many of the reference types found in other programming languages are much more comprehensive than pointers. Because the value of a pointer is an address, the type of object it points to does not affect its size – all pointers occupy the same amount of space in memory. In addition, the address pointed to can be arbitrary, which is the primary reason why pointers are one of the most common sources of serious defects in C programs.

To be useful, pointers must point to something, and although a definition such as uint32_t * const p_cpu_reg = (int *) 0x1000; is valid (and occasionally required), that something is usually another variable, although it can also be a function. Pointers to void are, to some extent, generic pointers – they can point to any type, but cannot be dereferenced without first being cast to a pointer to another type since there is no way of knowing what to do with the data. The C Standard guarantees that a pointer to any type can be cast to a pointer to void and back again without loss of information; however, casting to a pointer to a type other than the original type or char is undefined behaviour.
