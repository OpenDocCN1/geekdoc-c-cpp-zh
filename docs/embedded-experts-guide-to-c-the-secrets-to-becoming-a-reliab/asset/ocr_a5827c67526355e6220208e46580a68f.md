# Type punning

Type punning – changing the type of a variable without changing its representation in memory – is generally frowned upon; however, it is also often unavoidable when writing code to interact with hardware. For instance, if you wish to send 32-bit floating point values using a communications protocol which can only send a single byte at a time, you first need to convert from a float to a type which can be manipulated byte by byte; this typically means it must be treated as an integer type in software. Since type casting changes the representation used, type punning must be used.

A word of warning is necessary here: no method of type punning can be considered compliant with the C Standard. Compilers generally support such methods only because they are widely used and no alternative is defined within the standard.
