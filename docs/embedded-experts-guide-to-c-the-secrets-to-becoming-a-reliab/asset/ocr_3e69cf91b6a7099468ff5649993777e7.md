Newlines in preprocessor statements cause different behaviour: these statements are terminated by a newline rather than a and as a result, where a newline is required in such a statement, it should be immediately preceded by a single backslash Although this is valid at any point in the code, it is most often found in multi-statement macro definitions, where it allows the macro to be written in a similar style to the rest of the code.

It is conventional to use indentation (and in some cases necessary) to demarcate blocks of code in most programming languages. In C, the indentation itself does not change how the code behaves, since blocks are opened and closed using braces. Indentation is purely for the programmer’s benefit – nonetheless, it is a useful visual indicator that allows you to immediately identify related lines of code. This does, of course, assume that the indentation is correct. This is less of a problem than it once was since formatting tools are available that can correctly align the code and most IDEs can determine the appropriate level of indentation as you type.
