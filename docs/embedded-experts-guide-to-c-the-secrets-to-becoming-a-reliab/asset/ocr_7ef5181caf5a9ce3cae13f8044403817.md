Callbacks can be used to extend or alter the functionality of other functions; for example, a generic sorting function may contain code to loop through an array of values; a callback may then be used to determine how to sort them on each iteration, as is the case with the qsort function in the C Standard Note that it does not matter to the calling function what type is stored in the array (although it usually does matter how much memory each instance of the type occupies) – this is only important to the callback. This allows common code to be reused using only a single function while the task-specific code can be contained within callbacks – using the example of the same function can be used to sort arrays of any type and in any way which the programmer desires simply by varying the callback used. The required callback, in these cases, is passed to the other function as a parameter when calling and this is the simplest example of their use. A more complex example would take multiple possible callbacks and determine the correct one to call; this could be as simple as a callback to be used if an operation is successful and another to be used if the operation fails, but any number of callbacks can be used allowing much more complex applications, such as the calculator example from earlier, to be implemented in this way.
