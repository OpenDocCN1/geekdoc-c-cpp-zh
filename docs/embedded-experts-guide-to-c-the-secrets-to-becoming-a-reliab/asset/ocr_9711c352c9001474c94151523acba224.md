# Whitespace

There are three different kinds of whitespace that you will encounter in a C program: new lines, indentations, and single spaces. In most cases, the presence (or absence) of whitespace does not affect tokenisation of the C program. There are a few occasions when this is not the case, but more importantly, even when the tokenisation is well-defined according to the C Standard, it may be difficult to read or even ambiguous from a programmer's perspective. The solution is to use whitespace to make your intentions clear. The additional whitespace is ignored by the compiler and there is a negligible cost associated with it in terms of both storage of the source code and compilation time. Doing so will also successfully prevent problems arising from the instances where whitespace does change the tokenisation of the code.
