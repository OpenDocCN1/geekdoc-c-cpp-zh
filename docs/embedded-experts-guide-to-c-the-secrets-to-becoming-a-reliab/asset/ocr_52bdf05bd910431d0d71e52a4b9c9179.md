Note how, not only is VERSION_NUMBER not defined as VERSION ## REVISION and VERSION_STRING not defined as but an additional, seemingly redundant, macro is required for each operator. Neither of the more intuitive definitions would work and neither would omitting the additional macros – the stringising and token pasting operations take place before macro expansion is performed on the operands and the only workaround is to use an additional macro to expand any operands which require it first.
