# Fixed Addresses

Peripherals, unlike variables, typically reside at a fixed location in memory which needs to be known at compile In principle, it is easy to map a variable to such a peripheral – simply define a pointer and assign the base address of the peripheral to it. Unless it has function scope, such a pointer should be qualified as static to restrict its visibility. The address the variable pointed to) should be const qualified and it may also be a good idea to make the value pointed to This can result in a rather odd-looking definition, perhaps something static uint32_t volatile * const p_hw = (uint32_t *)

If you use those sorts of definitions regularly, you can always make them more readable using a Your compiler may also have a more succinct alternative which will often allow you to avoid the need for tedious and repetitive dereferencing – this may well be preferred from a readability perspective, although it does so by sacrificing portability. Alternatively, similar behaviour can be achieved using a preprocessor definition, such #define HW_REG (*((uint32_t *) 0x1234)).
