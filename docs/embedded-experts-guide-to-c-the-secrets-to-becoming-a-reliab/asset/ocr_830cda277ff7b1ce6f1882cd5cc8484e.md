The names are self-explanatory: input devices include peripherals such as keyboards and analogue to digital converters; displays and relays are examples of output devices and input/output devices include data storage and most communications and networking hardware. In the case of microcontroller based systems or system-on-chip platforms the peripherals are often included in the same device as the CPU. On more complex systems, the peripherals are usually separate hardware. In practice it is usually necessary to have at least some hardware which is not integrated.

Peripherals may be either memory-mapped or port-mapped; memory-mapped peripherals are those which can be accessed using the same bus as the CPU uses for memory accesses whereas port-mapped peripherals require a separate bus and, at the lowest level, special machine code instructions to access. Memory-mapped IO has the advantage of being easily accessed using pointers and without the need for any special instructions, which requires either inline assembly code or a precompiled library. In addition, compiler extensions will often allow the address of a variable to be specified, eliminating the need for pointers, and CPU specific header files will often map peripherals to a meaningful structure type.

This chapter shall cover the methods required to interact with memory-mapped IO. The application-specific nature of

port-mapped IO makes it difficult to cover in any meaningful depth. It is also not possible to consider every type of hardware you may encounter, so while you may find the information here useful, it will still be necessary to adapt it to the applications you work with.
