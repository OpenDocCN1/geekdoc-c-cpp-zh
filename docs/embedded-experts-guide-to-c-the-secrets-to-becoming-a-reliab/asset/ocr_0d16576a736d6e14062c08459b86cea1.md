terminated with a semicolon and still used immediately following an if
Although it is a relatively common practice, if you always use braces with
if statements, you will never need it.

The stringising operator is used when there is a need to treat an argument
as a string. The operator encloses the exact text of the argument within
quotation marks and replaces any special characters which appear with
their escaped equivalents. The token pasting operator is used to create a
new token from two existing tokens. The new token must be valid; you
could use #define ADD_EQ + ##= to define an alternative to the +=
operator (although there is no reason why you would ever need to do this),
but attempting #define ADD_TWO + ##= 2 (which would be equally
unnecessary) will not result in a new token. You may occasionally come
across these operators, although they are relatively rare. Probably their
most common use is in writing macros to aid with debugging. Their use is
often discouraged, first because the way in which they are implemented
can be confusing and is often inconsistent between vendors and secondly
because many people are unfamiliar with their use. If you do use them, be
sure to leave clear comments to explain what they are being used to
achieve.

```
/* Make a string. */
#define STRINGIFY(EXP_) #EXP_
/* An extra macro is required whenever EXP_
* needs to be expanded. */
#define MAKE_STRING(EXP_) STRINGIFY(EXP_)
/* Paste two tokens together. */
#define PASTE(PRE_, SUF_) PRE_ ## SUF_
/* This macro is required for the same reason
* as MAKE_STRING. */
```
