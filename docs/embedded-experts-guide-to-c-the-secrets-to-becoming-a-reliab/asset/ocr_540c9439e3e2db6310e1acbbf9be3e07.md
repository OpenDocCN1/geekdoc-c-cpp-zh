Chapter six, Data Security and Integrity, focusses on the requirements for many modern systems, where protecting communications from eavesdropping is a serious concern.

Chapter seven, The C Preprocessor, deals with the C preprocessor, which is not strictly a part of the language and often neglected, but needs to be properly understood in order to write good software.

Chapter eight, Understanding the Translation Process, gives some in-depth analysis of what happens when a C program is compiled and how the process can be manipulated when required.

Chapter nine, Run! Run! Run! – Optimising Software, provides some useful guidance on how and when to optimise your software as well as helping you to determine which parts of the software to concentrate on.

Chapter ten, Multitasking, introduces the concepts required when writing multitasking software and describes the steps you need to take in order to write a basic task scheduler.

Finally, chapter eleven, Bootloaders and Operating Systems, will help you write software for hosted environments, where you must often sacrifice some control over behaviour in exchange for having many management functions handled for you.

If you have read this far, then this is probably to book for you. All that remains is to wish you the best of luck in developing the skills you need to become an embedded programming expert.
