While there is a degree of compatibility between different versions of the language, it is not guaranteed and certainly should not be relied upon. Features are added with each new edition and some others are deprecated. The behaviour of the language may also be clarified or refined whenever a new version of the standard is published.

The question of which version you should use is not easy to answer. Compilers typically lag by a few years when it comes to implementing the latest version of the standard and many deliberately target earlier versions of the standard as a way of maintaining compatibility. Furthermore, few compilers are truly faithful to the standards anyway; most vendors will include additional features, and many choose not to implement the standard in full. As far as embedded systems are concerned, you are unlikely be using a compiler that implements anything more recent than C99, although there may be many vendor specific extensions included to help with common problems.
