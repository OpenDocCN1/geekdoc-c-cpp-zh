There are two variants of the #include directive: The first contains the
name of the file to be included in quotation marks: #include The second
variant places the name of the file between angled brackets: #include
These two forms are not intended to be completely interchangeable. The
first variant is used, the search path for the file includes the current source
directory. The second variant limits the search path to the standard include
path, which is where the C Standard Library header files can be found.
The distinction is of less importance than it once was; on modern systems
the additional delay involved in searching a greater number of paths is
relatively small. Nonetheless, using the angled bracket form can be a
useful reminder to the programmer the included files may differ from the
originally intended version and the source code itself may not be
available.
