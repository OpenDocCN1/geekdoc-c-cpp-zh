# Endnotes for Chapter 5 - Interacting with Hardware

1 Embedded compilers do often make use of many of the functions found in stdio.h, usually as a means of communicating with a host machine; for instance, the printf function may be used to drive a serial port, which can be connected to a PC for displaying text. Personally I rarely use such features.

2 Global and static variables also reside at a fixed memory address; however, this does not need to be known until run-time. In practice, unless you use dynamic memory allocation, it is determined at link time. Don't worry if this doesn't mean much to you – it's covered later, but it's also not particularly important for most purposes.

3 This definition assumes we wish to address a 32-bit word. The volatile qualifier lets the compiler know the value stored at that location may change unexpectedly, the const qualifier applies to the address itself, which must not be changed. Thus, the definition is for a constant pointer to a volatile 32-bit integer.

4 In this case, the symbol HW_REG is defined as the constant 0x1234 first cast to a pointer to a 32-bit unsigned integer and then dereferenced – i.e. it behaves as a variable residing at a fixed address, determined by the programmer. The symbol may then be treated as a variable throughout the code for most purposes.
