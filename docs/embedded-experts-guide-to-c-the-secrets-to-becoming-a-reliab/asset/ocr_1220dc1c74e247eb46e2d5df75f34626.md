# Queues

In contrast to stacks, queues are First-in, First-out (FIFO) data structures (or First-come, First-served, FCFS, in the context of scheduling algorithms); the most recently written element can only be read from the queue once all previously written elements have been As with a stack, reading an element from a queue also removes it from the queue. Write and read operations are often known as enqueue and dequeue Queues are a commonly used buffer implementation, particularly when data needs to be shared between asynchronous tasks; for instance, an interrupt service routine managing a UART may write data to a queue as it is received, to be read by the main application when it is required rather than handled immediately. Queues are also useful for implementing certain types of task scheduler.

Queues can be efficiently implemented in various ways; doubly linked lists are naturally suited to implementing queues (as well as double ended queues), although probably the simplest implementation is to use a circular buffer and to store read and write indices to keep track of elements. A circular buffer can be implemented using a standard array; causing the elements to wrap-around, so the last element appears adjacent to the first, is achieved by calculating the array index modulo the length of the array (the modulo operator is the % symbol; therefore, the calculation can be expressed as index % If the length of the buffer is a power-of-two, the modulo calculation can be replaced with a single bitwise-and operation, making this implementation even more efficient.
