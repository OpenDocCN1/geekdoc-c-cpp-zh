Like other variables (except arrays), structures are “pass-by-value” by default in C, so when passing structures to or from functions, it is usually preferable to use pointers rather than passing the structures themselves. This avoids the overhead of making a copy of the structure when calling or returning from the function. Furthermore, when passing any pointer or array which you do not intend to modify to a function, remember to qualify it as This allows the compiler to assume the variable pointed to will not change and therefore it does not need to store any copies of the variable currently stored in registers back to main memory only to reload them once the function returns. Any register copies may still be lost, but the compiler at least has the option of trying to avoid the additional work required.

# Caveat Lector: using assembly language for optimisation

It is often claimed efficient code is best written using an assembler. It is certainly true a skilled programmer familiar with both the instruction set and the hardware can improve performance this way, occasionally resulting in speed-ups of 10% or more. However, it is error prone and rarely worth the effort. Furthermore, reaching the necessary level of familiarity with an assembler to consistently write more efficient software than when using a compiler necessarily limits the programmer, since assemblers are always platform specific (which also severely limits portability).
