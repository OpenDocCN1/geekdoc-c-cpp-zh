When accessing peripherals occupying a range of addresses, you have a few options. You could treat the base pointer as an array, preferably replacing fixed-value indices with meaningful names where they appear in the code. This will work and is easy to implement, but it is unusual and may be misunderstood by anybody who happens to review your code in future. It is much more common to use a structure, although it is important to ensure the layout in memory used by the compiler is correct.
