A parallel bus is one which transfers multiple bits simultaneously using separate physical connections for each; conversely, a serial bus transfers a single bit at a time using one physical connection. The bandwidth of parallel buses can be increased simply by increasing the number of connections, thus allowing more bits to transmitted at once.
