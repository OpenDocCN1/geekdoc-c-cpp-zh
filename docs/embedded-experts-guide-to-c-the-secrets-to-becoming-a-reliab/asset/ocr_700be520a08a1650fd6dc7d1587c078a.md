Given a desired hash value, it is practically impossible to find an input to produce that value,

Similarly, it is practically impossible to find an input that produces the same hash value as any other input,

A small change in the input will result in a hash value that appears completely uncorrelated with the original hash value.

These properties make cryptographic hash functions suitable for a wide range of applications where either data integrity, security or both are important. While it is trivial to find an input that produces a particular CRC value, and therefore to alter data in such a way that it appears unchanged, it is infeasible to do the same with a cryptographic hash; providing the expected hash value can be independently verified, this prevents not just unintended corruption, but malicious manipulation of the data as well.
