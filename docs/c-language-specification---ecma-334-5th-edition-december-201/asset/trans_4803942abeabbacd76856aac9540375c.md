
在 `IntToString` 方法中使用 `stackalloc` 初始值设定项在栈上分配一个包含 16 个字符的缓冲区。该方法返回时，此缓冲区将自动丢弃。 [end example]

除了 `stackalloc` 运算符外，C# 不提供用于管理非垃圾回收内存的预定义构造。此类服务通常由支持类库提供，或直接从底层操作系统导入。

**条件性规范性文本结束。**
