Many of the toolbox functions are MATLAB m-files, a series of MATLAB statements that implement specialized image processing algorithms. One can extend the capabilities of the Image Processing Toolbox by writing customized m files, or by using the toolbox in combination with other toolboxes, such as the Signal Processing Toolbox and the Wavelet Toolbox, etc. The toolbox is also supported by a full complement of demo applications.
