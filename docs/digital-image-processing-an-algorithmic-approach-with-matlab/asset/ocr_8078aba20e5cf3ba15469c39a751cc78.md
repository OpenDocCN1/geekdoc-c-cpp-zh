# FIGURE 6.11 Frequency filtering algorithm.

```
h2 = fspecial('gaussian',5,5);
x=imread('sr71.jpg');
x = rgb2gray(x);
figure ; imshow(x)
% Gaussian Noise
xng = imnoise(x,'gaussian',0,0.1);
figure ; imshow(xng)
g1 = imfilter(xng,hl);
figure ; imshow(g1)
g2 = imfilter(xng,h2);
figure ; imshow(g2)
g3 = medfilt2(xng) ;
figure ; imshow(g3)
g4 = convsr(xng) ;
figure ; imshow(g4*0.003)
```
