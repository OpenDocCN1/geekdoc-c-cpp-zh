# 3.3 THEORETICAL TREATMENT

Usually, the following image operators are used as the building blocks for complex processing:

+   1. Image addition
+   2. Image subtraction
+   3. Image multiplication
+   4. Image division
+   5. Image blending

The following sections will discuss these operators theoretically.

# 3.3.1 Pixel Addition

This operator takes as input two images of the same size and produces as output a third image of the same size as the first two, in which each pixel value is the sum of the values of the corresponding pixel from each of the two input images.
