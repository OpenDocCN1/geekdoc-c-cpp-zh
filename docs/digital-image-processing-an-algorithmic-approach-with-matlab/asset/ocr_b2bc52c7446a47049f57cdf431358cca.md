In previous chapters, certain types of image filters designed to remove noise were presented. Figure 15.5 shows the application of a fuzzy inference system (ANFIS) to remove noise from a supervised image. The implication is that a less noisy version of this image is used as a training set to fine-tune the membership functions to allocate new pixel values based on knowledge of the crude version of the image. This approach actually extracted a noise-free image from a highly noisy image.
