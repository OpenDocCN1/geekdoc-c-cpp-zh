# 1.6.1 Basic Steps

Clear the MATLAB workspace of any variables and close open figure windows:

```
Clear all; close all;
```

Although not essential, it is always a good practice to include this step in the beginning of an m-file that is being executed from start and is not dependent on the previous data. To read an image, use the imread command:

```
I = imread('horses.jpg');
```

infers from the file that the graphics file format is JPEG and the name is “horses”, and stores it into the variable I. For the list of supported graphics file formats, see the imread function reference documentation.

The image can then be displayed by using one of the two image display functions: imshow or immview. You can use either one to display an image:

```
imshow(I)
```

Your choice of which display function to use depends on what you want to do. For example, because it displays the image in a MATLAB figure window, imshow provides access to figure annotation and printing capabilities.
