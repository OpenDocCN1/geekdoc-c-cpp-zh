The need for such an operation arises on two occasions: first, if the source image is too dark or too bright, and second, as a result of some processing step, the resulting matrix has values that are very high. A typical example of the second situation is convolution of two images, where products of sums can result in very high values. This is realized in the following:

```
P = imread('coins.png') ;
figure ; imshow(P)
Q = fspecial('unsharp' , 0.5) ;
figure ; mesh(Q)
R = conv2(P,Q) ;
figure ; imshow(R)
figure ; imshow(R*0.005)
```
