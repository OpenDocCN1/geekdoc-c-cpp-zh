## 宗旨与范围

本系列涵盖计算机的传统领域，以及相关技术领域，如软件工程、人工智能、计算机工程、信息系统和信息技术。本系列将收录面向本科生和研究生的教科书，总体遵循专业学会的全球课程标准。编辑希望鼓励新颖和富有想象力的想法和提案，并热衷于帮助和鼓励新作者。编辑欢迎以下提案：为计算机的各个方面提供开创性和富有想象力的视角；在新颖而激动人心的背景下呈现主题；为多媒体、安全和移动系统等新兴领域开辟机遇；捕捉计算机新兴领域的新发展和新应用；以及涉及为计算机提供支持的主题，如数学、统计学、生命科学和物理科学以及商业。
