If an unauthorized user performs (lossy) compression on the image, such as JPEG compression with the aim of reducing the file size, the quality of the image is also reduced. The consequence of this is that information stored in the pixels may also be eroded. This will also change the embedded watermark to the extent that it may not be recognizable.
