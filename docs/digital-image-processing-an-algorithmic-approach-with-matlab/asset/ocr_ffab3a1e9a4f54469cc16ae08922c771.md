# 14.7 SUMMARY

+   - Human face recognition refers to the process of identifying an individual from a known set of people.

+   - Such sets have been very carefully assembled and have been made available as databanks or repositories, mostly without any charge.

+   - The main challenge is the fact that any test image when compared with the images in this database may not have the same orientation, illumination, expressions, or other features as those present in the database.

+   - As such, one-to-one matching is not possible.

+   - Usually, some form of mapping is employed to convert the image into some representative components that are fairly independent of the aforementioned differences.

+   - PCA is one such technique that can decompose a face image into its eigen components, which can be used for classification.

+   - Once such components are known for all the images in the database, any test image's components are compared with the existing components.
