# ## 2.2 IMAGE TYPES AND FILE I/O

Once an image is acquired by the imaging system, it can be read into the computer's memory as a matrix. However, how this image is actually treated in the secondary storage medium varies with type of images and information content. Based on the storage types or file I/O standards, the most commonly used imaging formats in the Windows environment are as follows:

+   1. Bitmap (.bmp)
+   2. Joint Photographic Experts Group (.jpg)
+   3. Graphics Interchange Format (.gif)
+   4. Tagged Image File Format (.tif)
