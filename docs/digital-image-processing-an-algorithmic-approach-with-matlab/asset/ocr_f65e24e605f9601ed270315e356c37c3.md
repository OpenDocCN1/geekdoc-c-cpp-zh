# 15.2 FUZZY LOGIC IN IMAGE PROCESSING

This chapter presents only fuzzy logic and its applications in the image processing domain because it would be impossible to cover all the soft computing constituent technologies in this book. One added advantage of working with fuzzy logic is its simplicity and the ease with which the underlying concepts can be understood. This will be explained in the following sections using two examples related to image classification and image filtering.

Fuzzy set theory is the extension of conventional (crisp) set theory. It handles the concept of partial truth [truth values between 1 (completely true) and 0 (completely false)]. It was introduced by Prof. Lotfi A. Zadeh of the University of California at Berkeley in 1965 as a mean of modeling the vagueness and ambiguity in complex systems. Since then, it has been used in increasingly diversified applications covering almost every discipline in science and technology.
