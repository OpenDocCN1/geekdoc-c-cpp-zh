This H-infinity problem based on the minimization of the magnitude of the estimation error spectrum rather than the average power leads to better filters compared to other solutions. The H-infinity optimization scheme leads to improved performance of the deconvolution process over existing least-squares or H2-based solutions, thus leading to enhanced defect impulse response and thereby improving the defect identification.

Given a linear time-invariant (LTI) system with input f(t), output g(t), and a transfer function H(s), the H-infinity norm is expressed in time domain as

```
\| H \|^2 = \max_{\|g\|_2 \le 1} \left\{ \frac{\| g \|_2}{\| f \|_2} \right\} = \max_{\|f\|_2 \le 1} \left\{ \frac{\sum g^2(k)}{\sum f^2(k)} \right\}. (7.4)
```
