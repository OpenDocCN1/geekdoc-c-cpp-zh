# 12.4.1 Mechanism of Operation

Suppose that each training class is represented by a prototype (or *mean*) vector. This is particularly useful when classifying based on colors because for a selected area, the average color would be a good representation of the neighborhood. Such a mean is given as

```
$$\mu_n = \frac{1}{N_n} \sum_{x \in \omega_n} x \quad \text{for} \quad n=1, 2, ..., M, \quad (12.1)$$
```

where $N_n$ is the number of training pattern vectors from class $\omega_n$. In a color-based classification system, usually an area is first selected for a particular class and all of its enclosed pixels, $x$, are then averaged to get the representative mean. Based on this, we can assign any such given pattern to the class of its closest prototype by determining its proximity to each $\mu_n$. If Euclidean distance is our measure of proximity, then the distance to the prototype is given by

```
$$D_n(x) = \|x - m_n\| \quad \text{for} \quad j=1, 2, ..., M, \quad (12.2)$$
```

which is equivalent to computing

```
$$D_n(x) = x^T m_n - \frac{m_n^T m_n}{2} \quad \text{for} \quad n=1, 2, ..., M, \quad (12.3)$$
```

and assigning $x$ to class $\omega_n$ if $D_n(x)$ yields the smallest value. The *decision boundary* that separates class $\omega_i$ from $\omega_j$ is given by values for $x$ for which

```
$$D_i(x) - D_j(x) = 0. \quad (12.4)$$
```
