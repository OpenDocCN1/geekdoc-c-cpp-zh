# The Formula Editor

A powerful (and often under used) feature of JMP Student Edition is its formula editor. Formulas serve a wide variety of purposes, from assigning simple values to computing complex calculations with parameters and conditional clauses. They are especially useful when transforming data.

A column whose values are computed by a formula is both linked and locked. It is linked to (and dependent on) all other columns that are part of its formula. Its values are automatically recomputed whenever the values in these columns are edited. It is locked so that its data values cannot be edited individually. In the Denim.jmp sample data table, the ordinal variable Thread Wear is computed with a formula that partitions the values of Thread Wear Measured into low, moderate, and severe categories.

To see the formula,

+   - Right-click in the heading of the column Thread Wear.
+   - Select Formula from the menu that appears.
+   - Click Cancel to return to the data table.

The Formula Editor window operates like a pocket calculator with buttons, displays, and an extensive list of easy-to-use features.
