# Tests for Special Causes

The Tests option in the chart type popup menu displays a submenu for test selection. You can select one or more tests for special causes with the options popup menu. Nelson (1984) developed the numbering notation used to identify special tests on control charts.

If a selected test is positive, the last point in the test sequence is labeled with the test number, where the sequence is the moving set of points evaluated for that particular test. When you select several tests for display and more than one test signals at a particular point, the label of the numerically lowest test specified appears beside the point.
