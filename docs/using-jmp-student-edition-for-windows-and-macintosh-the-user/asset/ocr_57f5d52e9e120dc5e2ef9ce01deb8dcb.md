# Examining Results

Now, examine these results. There is a lot of information in this report, and although only a portion is used in this example, all of it is documented in sections that follow. In this initial look at the data, first check if the model as a whole is significant. Then, look at the p values associated with each effect, printed in several places, including just below each leverage plot. Leverage plots are detailed in “Leverage Plots,” p. 91.

The first leverage plot is for the entire model, and its p value indicates that the model is significant. To examine the p values for the individual effects, scroll the window until each effect is visible. Scrolling is accomplished using scroll bars along the edges of the window, or by using the Scroller tool.
