The models are listed in decreasing order of the number of parameters they contain. The model with the highest $R^2$ for each number of parameters is highlighted.

We suggest that no more than about 15 variables be used with this platform. More may be possible, but can strain computer memory (and human patience).

**Note:** Mallow’s $C_p$ statistic is computed, but initially hidden in the table. To make it visible, Right-click (Control-click on the Macintosh) and select **Columns > Cp** from the menu that appears.
