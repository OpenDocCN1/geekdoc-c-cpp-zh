www.murach.com

# The directory that contains the Visual Studio projects

```
C:\Murach\C#
```

# The subdirectories

| Directory | Description |
|---|---|
| Book Applications | The applications presented throughout this book. |
| Exercise Starts | The starting points for the exercises at the end of each chapter. |
| Exercise Solutions | The solutions to the exercises. |
| Database | The database files for the book applications and exercises. |

# How to download and install the files for this book

+   1. Go to www.murach.com and find the page for Murach’s C# (7th Edition).
+   2. If necessary, scroll down to the FREE Downloads tab. Then, click on it.
+   3. Click the DOWNLOAD NOW button for the self-extracting zip file, and respond to the resulting pages and dialog boxes. This should download a file named cse7_allfiles.exe.
+   4. Use File Explorer to find the exe file.
+   5. Double-click this file and respond to the dialog boxes that follow. This should install the files for this book in the directory above.

# How to use a regular zip file instead of a self-extracting zip file

+   1. Follow steps 1-3 above, but download the regular zip file, not the self-extracting zip file.
+   2. Use File Explorer to find the zip file.
+   3. Extract the files stored in this zip file into the C:\Murach directory. If the C:\Murach directory doesn’t already exist, create it.

# The directory that contains a copy of the exercise starts

```
C:\C#
```

# How to make a copy of the exercise starts

+   1. Use File Explorer to find the copy_exercises.bat file in the C:\Murach\C# directory.
+   2. Double-click the copy_exercises.bat file. This should copy all of the subdirectories of the Exercise Starts directory to the C:\C# directory.

# Description

+   - Although we recommend using the self-extracting zip file (an .exe file) to install the downloadable files, some systems don’t allow self-extracting zip files to be downloaded. In that case, you can use a regular zip file.
