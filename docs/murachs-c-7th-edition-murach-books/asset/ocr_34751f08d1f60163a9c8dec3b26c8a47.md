# The Customer Maintenance application

In the topics that follow, you’ll see another version of the Customer Maintenance application that was first presented in chapter 20. Unlike the application shown in that chapter, this version doesn’t use EF. Instead, it uses ADO.NET commands to retrieve, insert, update, and delete rows from the Customers table. This application should give you a thorough understanding of how you can build applications with commands.

# The user interface

Figure 21-10 presents the user interface for the Customer Maintenance application. This user interface consists of two forms and works just like the application presented in chapter 20.

To review, the Customer Maintenance form lets the user add a new customer by clicking the Add button to display the Add Customer form. Or, the user can enter a customer ID into the text box and click the Get Customer button to retrieve the data for an existing customer. Then, the user can modify the data for that customer by clicking the Modify button to display the Modify Customer form. Or, the user can delete that customer by clicking the Delete button.
