# The code for the Customer Maintenance form

Figure 21-14 shows the code for the Customer Maintenance form. It works much like the code for the Customer Maintenance application presented in the previous chapter. However, it uses the database classes presented in the previous two figures to work with the database.

When the user clicks the Get Customer button after entering an integer, the GetCustomer() method of the form is called. In turn, this calls the GetCustomer() method of the CustomerDB class. This retrieves the customer with the specified ID from the database. In addition, the GetCustomer() method of the form calls the GetState() method of the form. This retrieves the state for the customer. These methods are presented on page 2 of this figure.

If the specified customer is found, the DisplayCustomer() method displays the data for the selected customer. Otherwise, the user is notified and the ClearControls() method clears the form controls.

The statement that calls the GetCustomer() method of the CustomerDB class is coded within a try-catch statement. That’s because, if a SQL Server error occurs during the execution of this method, the exception is thrown to the calling method. As a result, the calling method should catch this exception.
