# # The code for the Customer Maintenance form

Figure 20-18 shows the code for the Customer Maintenance form. After the default constructor (not shown here), it declares two class variables. The first stores an instance of the DB context object that’s used by the form, and the second stores the customer that’s currently displayed on the form.

Because this form doesn’t contain a Load event handler, no data is displayed when the form is first loaded. Then, the user can enter a customer ID and click the Get Customer button to retrieve the data for a customer, or the user can click the Add button to add a new customer.

The event handler for the Click event of the Get Customer button starts by calling the IsValidData() method. This method, in turn, calls the IsInt32() method in a class named Validator to check that the user entered an integer for the customer ID. This class contains methods like the ones in the Validator class from chapter 12.

If the customer ID is an integer, it’s used to get the customer with the ID entered by the user from the database. To do that, the code calls the Find() method of the Customers entity collection. This method will return a Customers object if the customer with the specified ID is found. Otherwise, it will return null.

The statement that calls the Find() method is coded within a try-catch statement. That’s because the Find() method will throw an exception if the DB context is no longer available or the database can’t be found. So, this event handler should catch that exception. To handle this exception, the catch block passes the Exception object to the HandleGeneralError() method shown on page 4 of this code listing.

After it executes the Find() method, the event handler checks if the Customers object contains a null value. If it does, a message is displayed indicating that the customer wasn’t found, and a method named ClearControls() is called. This method, which is presented on page 2, clears the data from the controls on the form and moves the focus to the Customer ID text box so the user can enter another ID.

If the Customers object contains a value, the event handler checks whether the States object for that customer has been loaded. That will be the case if the data for another customer in the same state has already been displayed. If it hasn’t been loaded, the Load() method is called to load it.

Finally, the event handler calls the DisplayCustomer() method. This method, which is presented on page 2, displays the data retrieved from the database on the form.
