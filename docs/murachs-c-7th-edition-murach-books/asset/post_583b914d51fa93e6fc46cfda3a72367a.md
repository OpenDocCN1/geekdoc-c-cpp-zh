### The C# language essentials

In section 1, you were introduced to C# programming. In particular, you learned how to use Visual Studio to design a Windows form, to enter the code for that form, and to test that code. However, you didn’t actually learn the details for coding C# statements.

Now, in this section, you’ll learn the C# language essentials. In chapter 4, for example, you’ll learn how to perform arithmetic operations.
