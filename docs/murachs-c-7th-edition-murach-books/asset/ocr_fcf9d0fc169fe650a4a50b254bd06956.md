# What software you need

To develop the Windows Forms applications presented in this book, you must have a computer that’s running on Windows. In other words, even though .NET is cross-platform, you can’t use macOS or Linux to develop Windows Forms applications like the ones shown in this book. And although it’s possible to use Windows 7 SP1 or Windows 8.1, we recommend Windows 10 or later.

On your Windows computer, you need an edition of Visual Studio, and we recommend using Visual Studio Community. This edition can be downloaded from Microsoft’s website for free. However, if you already have another edition of Visual Studio installed on your computer, such as Visual Studio Professional, you can use that if you prefer.

When you install Visual Studio, you can install all of the other components you need to work with this book. This includes the compiler for the C# language, .NET, and SQL Server Express LocalDB, which is an embedded version of the SQL Server database that’s designed to make it easy for developers to test database applications.
