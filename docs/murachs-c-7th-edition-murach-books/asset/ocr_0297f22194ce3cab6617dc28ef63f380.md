# Perspective

Now that you’ve read this chapter, you should have a general idea of how the .NET platform, the Visual Studio IDE, and the C# programming language are related. You should also know how to use Visual Studio to work with the files in projects and solutions. Now, to get more comfortable with Visual Studio, you can step through the exercise that follows.

When you’re done with this exercise, you should be ready for the next chapter. There, you’ll learn more about using Visual Studio as you develop your first C# application.
