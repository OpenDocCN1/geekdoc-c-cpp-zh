
## Perspective

In this chapter, you learned how to display multiple rows from a database table in a DataGridView control. In addition, you learned how to provide for add, update, and delete operations when you use a DataGridView control, you learned how to provide paging for a DataGridView control, and you learned how to use two DataGridView controls to create a Master/Detail form. These are some of the most important skills for working with this control. At this point, you have the background you need to learn more about this control if you ever need to do that.

## Exercise 22-1 Create a Customer Maintenance application that uses a grid

In this exercise, you’ll create a Customer Maintenance application that displays customer data in a DataGridView control. This control will also contain button columns that let the user modify and delete customers, and the form will contain an Add button that lets the user add customers. To make this application easier to develop, the starting point provides the Entity Data Model, the Add/Modify Customer form, the Validator class, and some of the code for the Customer Maintenance form.

## Open the project and create the grid

- 1. Open the application in the C:\C#\Chapter 22\CustomerMaintenance directory.
- 2. Add a DataGridView control to the Customer Maintenance form. When the smart tag menu is displayed, set the options so the user can’t add, edit, or delete data directly in the control.
- 3. Use a LINQ query to get the customer id, name, address, city, state, and zip code for each customer. Sort the customers by name, and store the results in a list. Then, bind the DataGridView control to this list.
- 4. Set the Visible property of the column that contains the customer id so it isn’t displayed. Then, format all the remaining columns so they’re wide enough to display the data they contain. In addition, format the column headers and alternating rows any way you like.
- 5. Adjust the width of the grid so you can see all the columns as well as the vertical scrollbar. In addition, adjust the height of the grid so you can see 10 customers at a time. You may have to run the application and adjust the width and height multiple times before you get this right.

## Add two button columns to the grid

- 6. Declare a constant that contains the index value for the Modify button column that you’ll add to the grid. Then, declare a constant that contains the index value for the Delete button column. Remember, indexes are zero based.
- 7. Add the button columns to the grid. To do that, use the Insert() method of the Columns collection, and pass in the correct constant for the index argument.
- 8. Re-adjust the width of the grid so you can see all the columns as well as the vertical scrollbar. Adjust the position of the buttons and the size of the form so it looks as shown above.
- 9. Generate an event handler for the CellClick event of the DataGridView control. This event handler should start by using the constant values to check if a cell that contains a Modify or Delete button was clicked. If it was, it should get the customer id from the row that was clicked and then get the customer with that id and store it in the selectedCustomer variable. Then, if a Modify button was clicked, it should call the ModifyCustomer() method, and if a Delete button was clicked, it should call the DeleteCustomer() method.
- 10. Test these changes to be sure they work. To test the delete operation, first add a new customer and then delete that customer.

## Exercise 22-3 Create an Invoice Line Item Display application

In this exercise, you’ll create an Invoice Line Item Display application that displays a grid with all of the invoices in the Invoices table. Then, when the user selects an invoice, all of the line items for that invoice are displayed. To make this application easier to develop, the starting point provides the design of the Invoice Line Item Display form.

![](img/844f608d10a44654833ea5efc8a2e7a7_785_0.png)

- 1. Open the application in the C:\C#\Chapter 22\InvoiceLineItemDisplay directory, and display the Invoice Line Items form to see that it contains two DataGridView controls.
- 2. Add code to the DisplayInvoices() method that gets all the columns in all the invoices and then binds the Invoices grid so it displays the invoices.
- 3. Add code to the DisplayLineItems() method that gets the invoice row that was selected and then gets the invoice id from that row. In addition, add a LINQ query that gets the product code, quantity, unit price, and item total for each line item for the invoice, store the line items in a list, and bind the Line Items grid to the list.
- 4. Add code to the Load event handler for the form that calls the DisplayInvoices() method, calls the DisplayLineItems() method to display the line items for the first invoice, and selects the first invoice.
- 5. Generate an event handler for the RowHeaderMouseClick event of the Invoices grid. Then, add code that displays the line items for the invoice that was clicked.
