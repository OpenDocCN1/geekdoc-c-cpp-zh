# # How to view the XML documentation

Once you add XML documentation, Visual Studio will use that documentation when it displays the screen tips that appear in the Visual Studio Code Editor window. This is illustrated by figure 16-5.

In the first example, when I typed the Validator class and a period, the IntelliSense feature displayed a list of the members of the Validator class. Then, I used the arrow keys to select the IsPresent() method. When I did that, Visual Studio displayed a screen tip that included the signature of the IsPresent() method along with the summary that’s provided by the XML documentation that’s shown in the previous figure.

In the second example, I selected the IsPresent() method and typed its opening parenthesis. Then, Visual Studio displayed a screen tip that included the description of the value parameter that’s provided by the XML documentation that’s shown in the previous figure.
