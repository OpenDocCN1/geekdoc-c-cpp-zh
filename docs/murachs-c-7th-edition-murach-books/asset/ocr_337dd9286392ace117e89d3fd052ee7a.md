# Description

+   - The *live code analysis feature* lets you generate code stubs for any undefined class, constructor, property, method, field, enumeration, structure, or interface from the current location in your code.
+   - To generate a code stub for a class, property, method, or field, click in the line that contains the class or member name, click the light bulb icon that appears, and then select the appropriate Generate command from the Quick Actions menu that becomes available.
+   - To generate a code stub for an enumeration, structure, or interface, or to specify additional information for a class, select the Generate New Type... command from the menu and complete the dialog box that’s displayed.
+   - When you enter a class or member that hasn’t been defined, you should use *suggestion mode* for statement completion instead of *completion mode*. With suggestion mode, the name you type is inserted into your code rather than the highlighted entry in the completion list.
+   - To switch to or from suggestion mode, use the Edit→IntelliSense→Toggle Completion Mode command, or press Ctrl+Alt+Spacebar.
