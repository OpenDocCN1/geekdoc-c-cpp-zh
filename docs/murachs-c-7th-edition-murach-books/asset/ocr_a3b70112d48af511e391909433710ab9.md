# ### 4.5.5. mysqltest — MySQL Test Program

This utility, which was previously named mysql_test, is a test program that is used to test the correctness of a MySQL server. It can be used for regression testing of the MySQL server, and for testing the MySQL client/server protocol.

The following table shows the options that the mysqltest program supports:

| Option | Description |
|--------|-------------|
| --help | Display help message and exit |
| --silent | Silent mode, no output except errors |
| --verbose | Verbose mode, print more details |
| --debug | Enable debug output |
| --host=host_name | Connect to MySQL server on given host |
| --port=port_num | TCP/IP port number to use for connection |
| --socket=path | Unix socket file to use for connection |
| --user=user_name | MySQL user name to use when connecting |
| --password[=password] | Password to use when connecting |
| --test-file=file_name | File containing test commands to execute |
| --record | Record results of the test into the test file |
| --result-file=file_name | File to write test results to |
| --silent | Suppress all output except errors |
| --verbose | Print extra information during test execution |

The mysqltest utility reads a test file containing SQL statements and special commands, executes them against the MySQL server, and compares the output with the expected results. Differences are reported to the user.

+   - The test file format is described in the MySQL source tree under the mysql-test directory.
+   - Several built-in commands such as `--echo`, `--sleep`, `--query`, and `--error` are supported.
+   - The program is commonly used with the mysql-test-run.pl harness in MySQL development.

```
```bash
mysqltest --host=localhost --user=root --password --test-file=mytest.test
```
