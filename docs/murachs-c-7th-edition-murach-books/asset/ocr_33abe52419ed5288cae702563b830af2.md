# Description

+   - To start Visual Studio, locate and select Visual Studio from the Start menu or the Apps list.
+   - To make it easier to start Visual Studio, you can create a shortcut for Visual Studio and put it on the desktop or pin it to the start menu.
+   - When Visual Studio starts, it displays a Start window. You can use this window to open a recent solution, open any project or solution, create a new project, and so on.

# Differences between Visual Studio Community and other editions

+   - The screen captures in this book use Visual Studio 2019 Community. If you’re using another edition of Visual Studio, you may notice some minor differences on your system, but Visual Studio should still work similarly.
