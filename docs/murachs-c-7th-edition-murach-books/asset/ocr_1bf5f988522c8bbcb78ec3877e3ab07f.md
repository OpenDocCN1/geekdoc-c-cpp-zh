# How to install the files for this book

This book presents complete applications that illustrate the skills that are presented in each chapter. You can download these applications from our website. Then, you can install them as described in figure A-1. This download also includes the starting points and solutions for the exercises that are at the end of each chapter.

Although we recommend using the self-extracting zip file (an .exe file) to install the downloadable files as described in the first procedure, some systems don’t allow self-extracting zip files to be downloaded. In that case, you can use a regular zip file as described in the second procedure.

Either way, after you’re done downloading the files, you should run the copy_exercises.bat file as described in the third procedure. This copies the subdirectories of the Exercise Starts directory into the C:\C# directory (creating this directory if necessary). That way, you can find the exercise start for chapter 1 in the C:\C#\Chapter 01 directory. In addition, if you make a mistake and want to restore a file to its original state, you can do that by copying it from the Exercise Starts directory.

The Book Applications directory contains all of the Windows Forms applications presented in this book. As a result, you can use Visual Studio to open these applications. Then, you can view the source code for these applications, and you can run them to see how they work.

The Exercise Starts directory contains the starting points for the exercises presented at the end of each chapter. To do that, it contains one subdirectory for each chapter. In addition, it contains two subdirectories named Database and Files. The Database subdirectory contains the files for the MMABooks database that’s used by the exercises in section 5. And the Files subdirectory contains the files used by the exercises for the chapters in sections 3 and 4.

The Exercise Solutions directory contains the source code for the solutions to the exercises. If you have trouble doing an exercise, you can use Visual Studio to open the solution. Then, you can compare the solution to your application to solve any problems that you encountered while attempting to do the exercise.

The Database directory contains another copy of the files for the MMABooks database that’s used in section 5. In addition, it contains a SQL script file that you can use to create the MMABooks database if necessary.
