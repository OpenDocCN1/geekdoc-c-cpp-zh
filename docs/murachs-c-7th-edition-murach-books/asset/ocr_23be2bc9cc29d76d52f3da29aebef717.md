# Description

+   - You can use the *Peek Definition* window that became available with Visual Studio 2015 to display and edit the code for a member in another class from within the class that refers to it.
+   - To display the Peek Definition window, right-click on the member and select Peek Definition from the shortcut menu. The window is displayed below the member you selected but doesn’t overlay any code that follows.
+   - If you edit the code in a Peek Definition window, a tab is opened in the Code Editor for the file that contains that code. Then, the changes you make in the Peek Definition window appear in the window for the file.
+   - You can continue to work with the code outside of the Peek Definition window while that window is open. To close the Peek Definition window, click the Close button in its upper right corner or press the Esc key.
+   - You can use the *Go To Definition* feature that became available with Visual Studio 2017 to display the code for a member in another Code Editor window.
+   - To use the Go To Definition feature, place the cursor inside the member name and press F12, right-click the member name and choose the Go To Definition option, or press the F12 key and click the member whose code you want to display.
