# How to create
and use classes

This chapter presents the basics of creating and using classes in C# applications. Here, you’ll learn how to create classes that include properties, methods, fields, and constructors, as well as classes that contain static members. In addition, you’ll learn how to create structures and records, which are similar to classes.

When you complete this chapter, you’ll start to see how creating your own classes can help simplify the development of an application. As a bonus, you’ll have a better understanding of how the .NET classes work.
