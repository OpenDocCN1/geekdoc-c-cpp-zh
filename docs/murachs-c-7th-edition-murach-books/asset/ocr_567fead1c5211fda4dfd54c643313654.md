# Description

+   - To modify a product, the user clicks the Modify button for the product to display it in the Modify Product form. Then, the user can make the appropriate modifications and click the Accept button to return to the Product Maintenance form.

+   - To delete a product, the user clicks the Delete button for the product. Then, the user responds to the dialog box that’s displayed to confirm the delete operation and return to the Product Maintenance form.

+   - To add a product, the user clicks the Add Product button below the DataGridView control to display a blank Add Product form. Then, the user enters the data for the new product and clicks the Accept button to return to the Product Maintenance form.
