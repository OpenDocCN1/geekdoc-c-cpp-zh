# Exercise 22-3 Create an Invoice Line Item Display application

In this exercise, you’ll create an Invoice Line Item Display application that displays a grid with all of the invoices in the Invoices table. Then, when the user selects an invoice, all of the line items for that invoice are displayed. To make this application easier to develop, the starting point provides the design of the Invoice Line Item Display form.

![](bbox=[0.24, 0.245, 0.73, 0.55])

+   1. Open the application in the C:\C#\Chapter 22\InvoiceLineItemDisplay directory, and display the Invoice Line Items form to see that it contains two DataGridView controls.
+   2. Add code to the DisplayInvoices() method that gets all the columns in all the invoices and then binds the Invoices grid so it displays the invoices.
+   3. Add code to the DisplayLineItems() method that gets the invoice row that was selected and then gets the invoice id from that row. In addition, add a LINQ query that gets the product code, quantity, unit price, and item total for each line item for the invoice, store the line items in a list, and bind the Line Items grid to the list.
+   4. Add code to the Load event handler for the form that calls the DisplayInvoices() method, calls the DisplayLineItems() method to display the line items for the first invoice, and selects the first invoice.
+   5. Generate an event handler for the RowHeaderMouseClick event of the Invoices grid. Then, add code that displays the line items for the invoice that was clicked.
