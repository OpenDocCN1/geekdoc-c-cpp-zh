# The code for the StateDB class

Figure 21-13 shows the code for the StateDB class. This class contains two methods named GetStates() and GetState().

The GetStates() method returns a generic List<> object that contains one State object for each of the rows in the States table, sorted by state name. To get this list, it creates a command with a SELECT statement that retrieves the appropriate data. Then, it executes this command to create a data reader that can be used to read each state. Next, this method uses this reader to read each row in the table, create a State object for each row, and add each State object to the List<> object. Finally, the method returns the list of State objects.

The GetState() method accepts a state code as a parameter and returns a single State object. To get this object, it creates a command with a SELECT statement and a parameter for the state code. Then, it executes this command to create a data reader that can be used to read the selected state. Since this command only retrieves a single row, it adds the SingleRow command behavior to the CloseConnection behavior. Next, it uses the reader to read the single row, create a State object for it, and return that State object.
