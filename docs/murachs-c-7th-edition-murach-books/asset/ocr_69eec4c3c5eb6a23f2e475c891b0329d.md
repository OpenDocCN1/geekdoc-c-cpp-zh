# Perspective

In this chapter, you learned how to use Database First development to create an Entity Data Model from an existing database. You also learned how to use LINQ to Entities to load data into the model, and you learned how to use EF to insert, update, and delete data and check for exceptions. With these skills, you should be able to develop applications that let the user display and maintain data.

Keep in mind, though, that there’s a lot more to learn about EF than what’s presented here. In particular, if the database that an application will work with doesn’t already exist, you’ll need to know how to use Code First development to generate it from the model you create. For more information on how to do that, you can refer to the online documentation or get a separate book on EF.
