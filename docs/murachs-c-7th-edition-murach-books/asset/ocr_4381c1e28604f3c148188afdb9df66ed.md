# Description

+   - To display the debugging options, use the Debug→Options command.
+   - By default, the Edit and Continue feature is on in the Options dialog box. This feature lets you change the code while in break mode and continue running the application.
+   - To display the Exception Settings window, use the Debug→Windows→Exception Settings command.
+   - By default, an application will typically enter break mode only when an exception is thrown and there is no exception-handling code for that exception. However, you can change that by checking or unchecking the box to the left of an exception category or a specific exception.
+   - You can use the toolbar in the Exception Settings window to search for or filter exceptions, add or delete exceptions, or return the settings to their defaults.
+   - Although you should be aware of the options in the Options dialog box and Exception Settings window, you usually won’t need to change any of them.
