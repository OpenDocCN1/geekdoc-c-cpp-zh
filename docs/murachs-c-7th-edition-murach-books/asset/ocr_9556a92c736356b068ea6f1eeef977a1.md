# The syntax for creating a record (C# 9.0 and later)

```
```csharp
public record RecordName
{
    record members...
}
```
```

# A Product record

```
```csharp
public record Product
{
    public Product(string code, string description, decimal price) {...}

    public string Code { get; set; }
    public string Description { get; set; }
    public decimal Price { get; set; }

    public string GetDisplayText(string sep) =>
        Code + sep + Price.ToString("C") + sep + Description;
}
```
```

# Code that creates and compares two record instances

```
```csharp
Product p1 = new Product("C#", "Murach's C#", 57.50m);
Product p2 = new Product("C#", "Murach's C#", 57.50m);
bool isEqual = p1.Equals(p2);              // isEqual is true

p2.Price = 59.50m;
isEqual = p1.Equals(p2);                    // isEqual is false
```
```

# The syntax for creating a record that only contains read-only properties

```
```csharp
public record RecordName(propertyList);
```
```

# A read-only Product record

```
```csharp
public record Product(string Code, string Description, decimal Price);
```
```

# Code that copies an instance of a read-only record and changes a value

```
```csharp
Product product = new Product("C#", "Murach's C#", 57.50m);
```
```

# By passing the values of the original to the constructor of the copy

```
```csharp
Product copy1 = new Product(product.Code, product.Description, 59.50m);
```
```

# By using the with keyword

```
```csharp
Product copy2 = product with { Price = 59.50m };
```
```

# Description

+   - A *record* is a reference type like a class. Unlike a class, a record’s Equals() method compares the values of its properties. This works like a structure.
+   - A record can contain the same types of members as a class, it can be inherited, and you can create an instance of a record with an object initializer.
+   - You can create a record that only contains read-only properties by passing a list of properties to the record, but you can’t use an object initializer with this type of record.
+   - You can use the *with* keyword to copy a record and change one or more property values.
