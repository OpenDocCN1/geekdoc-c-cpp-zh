# The class diagram for the business and database classes

Figure 21-11 presents a class diagram for the Customer Maintenance project. This diagram shows the business and database classes that are used by the Customer Maintenance application. Although you can create class diagrams like this using Visual Studio, class diagrams became an optional feature with Visual Studio 2017. As a result, if you want to use this feature, you need to install the Class Designer component. To do that, you can use the Visual Studio Installer program as described in appendix A.

The Customer and State classes define the business objects that are used by this application. Each of these classes contains auto-implemented properties that can be used to store the values of the columns in the associated table.

The CustomerDB and StateDB classes provide static methods for working with the tables in the MMABooks database. The StateDB class contains a method for getting a list of State objects. The application uses this list to populate the State combo box.

The CustomerDB class contains four methods. The GetCustomer() method returns a Customer object for the customer with a specified ID. And the AddCustomer(), UpdateCustomer(), and DeleteCustomer() methods do just what their names imply.

Finally, the MMABooksDB class contains a static read-only property that returns a connection string for the MMABooks database. This property is used by the methods in the CustomerDB and StateDB classes.
