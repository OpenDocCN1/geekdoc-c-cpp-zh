# How to enable lazy loading

Since EF Core doesn’t provide for lazy loading by default, you need to enable it if you want to use it. To do that, you can follow the instructions presented in figure 20-10.

First, you must install the EF Core Proxies NuGet package shown at the top of this figure. To do that, you can use the procedure presented in figure 20-2.

Second, you must code the OnConfiguring() method in the DB context file as shown in this figure. Here, the code calls the UseLazyLoadingProxies() method of DbContextOptionsBuilder class. This method call is chained to the UseSqlServer() method described in figure 20-7.

Third, your entity classes must be public and unsealed, have a public or protected constructor, and have navigation properties that are virtual. Fortunately, the Scaffold-DbContext command takes care of this for you.
