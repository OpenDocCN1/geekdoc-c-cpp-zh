# Perspective

This chapter has introduced you to the hardware and software components of a multi-user system and described how you use SQL to work with the data in a relational database. With that as background, you're now ready to develop a database application with C#.

# Terms

+   - **Microsoft SQL Server**: composite primary key
+   - **client**: non-primary key
+   - **server**: database server
+   - **database server**: network
+   - **network**: client/server system
+   - **client/server system**: enterprise system
+   - **enterprise system**: local area network (LAN)
+   - **local area network (LAN)**: wide area network (WAN)
+   - **wide area network (WAN)**: network operating system
+   - **network operating system**: database management system (DBMS)
+   - **database management system (DBMS)**: back-end processing
+   - **back-end processing**: application software
+   - **application software**: data source
+   - **data source**: data access API
+   - **data access API**: application programming interface
+   - **application programming interface**: front-end processing
+   - **front-end processing**: SQL query
+   - **SQL query**: query
+   - **query**: Structured Query Language (SQL)
+   - **Structured Query Language (SQL)**: query results
+   - **query results**: relational database
+   - **relational database**: table
+   - **table**: record
+   - **record**: row
+   - **row**: field
+   - **field**: column
+   - **column**: primary key
+   - **primary key**: composite primary key
