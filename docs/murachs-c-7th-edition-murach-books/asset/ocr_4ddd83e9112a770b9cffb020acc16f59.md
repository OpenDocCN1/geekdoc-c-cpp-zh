# Description

+   - The Customer Maintenance project contains the classes that define the business objects used by the Customer Maintenance application and the database classes that are used to work with the MMABooks database.
+   - The business objects are defined by the Customer and State classes. These objects will hold data from the associated tables in the MMABooks database.
+   - The classes that end with DB, including CustomerDB, StateDB, and MMABooksDB, are the database classes. These classes provide static methods and a read-only property for working with the MMABooks database.
+   - The CustomerDB class provides public methods for getting the data for a customer and for adding, updating, and deleting a customer.
+   - The StateDB class provides public methods for getting a list of states or a single state from the States table.
+   - The MMABooksDB class provides a public read-only property for getting a connection string from the App.config file.
