The next assignment operator is **++**. It adds one to a variable. For example, try the following code:

```
```cpp
int c = 5;
c++;
cout << c << "\n";  
```
```

It should print out 6. This is why C++ is called C++. It is the next thing after C. Did I mention that computer programmers like weak jokes?

You can also write ++c to increment the variable c. The difference between c++ and ++c is that c++ takes the value of c before the c was incremented and ++c takes the value of c after c was incremented.

In other words, the code:

```
```cpp
int c = 5;  
int d = c++;  
cout << "c=" << c << "\n";  
cout << "d=" << d << "\n";  
```
```

will give the result that c=6 and d=5. Whereas

```
```cpp
int c = 5;  
int d = ++c;  
cout << "c=" << c << "\n";  
cout << "d=" << d << "\n";  
```
```

will give the result that c=5 and d=6.

> **Danger!**

Using the assignment operators =, +=, ++ etc. as part of more complex expressions is very confusing. Don’t do it.
