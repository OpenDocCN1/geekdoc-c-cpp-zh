# ## 7.7 The architecture of the World Wide Web

The Internet and the World Wide Web are slightly different things. The Internet includes everything on the Internet including Skype, email and Netflix. The World Wide Web is what you can see in a web browser.

So, the World Wide Web is just one particularly popular application that runs on the Internet.

Our “trick” of writing a chart as a text-based file relies on the architecture of the World Wide Web. The World Wide Web is based on sending text files around. Servers receive text data (from users filling in forms and typing URLs). Servers send out text data (HTML files like our chart).

It’s easy to write the server that generates a web page without even understanding HTML. We’ve just done this ourselves. It is also easy to test your server code without even using a web browser.
