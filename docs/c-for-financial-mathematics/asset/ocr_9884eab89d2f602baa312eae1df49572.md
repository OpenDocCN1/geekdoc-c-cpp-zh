The problem with this code is that we're creating a Position that appears to be initialised but then immediately deleting the Instrument it refers to. We're not consciously deleting the instrument, it just happens as part of automatic cleanup when the method exits. This means that the following code which uses the returned position will fail.

    cout << "\n";
}
