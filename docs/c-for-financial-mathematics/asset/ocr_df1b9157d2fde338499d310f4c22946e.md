3.9.4. A commonly occurring function in financial mathematics is the cumulative normal function defined by:

```
$$\mathbf{normcdf}(\mathbf{x}) = N(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{x} \exp(-t^2/2) \mathrm{d}t$$
```

If $x >= 0$ we define:

```
$$k = 1/(1 + 0.2316419x)$$
```

a good approximation for $N(x)$ is given by:

```
$$1 - \frac{1}{\sqrt{2\pi}} \exp(-x^2/2)k(0.319381530 + k(-0.356563782 + k(1.781477937 + k(-1.821255978 + 1.330274429k))))$$.
```

For $x <= 0$ you can use the same formula to evaluate $1 - N(-x)$.

The formula can be derived by choosing the general functional form and then finding the coefficients that give the best fit. For this question, you should just accept the formula on face value.

Write a function called **normcdf** to evaluate the cumulative normal function. Why would N be a bad name for the function?
