Let us not waste any more time understanding arrays in more detail, because we will never use them!

Arrays are not very useful data structures for us because *you cannot change the length of an array*. You can’t insert a new item or add some items at the end. Even worse, the size of an array is fixed at compile time. This means when you write your program, you must choose the size of the array and it can’t grow in response to user input. Also, passing the length around to each function call is annoying.

Arrays are only of interest if you know the size of your arrays when your code is compiled. For example, when working with 3D computer graphics, arrays of length 3 can be useful.

> **Tip: Don’t use arrays**

Vectors do everything you want to do with arrays and much more.
