# ### 17.4 Summary

Templates provide a solution to the Once and Only Once principle that is very useful for writing data structure classes. On the other hand, using templates to write unnecessarily generic code violates the YAGNI principle (You Aren’t Going to Need It).

Templates can be used as an alternative to virtual functions, but virtual functions are normally the better approach.

For financial mathematics problems it is a good idea to take advantage of library classes that are built using templates, but to avoid writing your own template libraries.
