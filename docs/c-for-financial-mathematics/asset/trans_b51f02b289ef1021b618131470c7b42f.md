**宗旨与范围：**
金融数学领域构成了金融行业中不断扩大的一个分支。本丛书旨在捕捉该领域的新发展，并总结整个领域的已知知识。它将涵盖一系列旨在吸引学术界和实务界人士的教科书、参考书和手册。强烈鼓励包含数值代码和具体的实际案例。
