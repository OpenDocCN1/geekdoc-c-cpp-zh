\mathbb{Q}-measure, the discounted expectation of $S_T$ must be $S_0$. We deduce that the discounted expectation of $S_T - K$ is:

$$ S_0 - e^{-rT} K. $$

This is the value of $\mathcal{P}$ at time 0.

The test below confirms that this holds for our Portfoli o class when $r=0$.

One might feel that we should write many more tests for our Portfoli o class to test that it correctly prices more sophisticated portfolios. A central benefit of our design is that writing a large number of tests for the **Portfolio** class is not really necessary. We already have a suite of tests to confirm that various different types of option are priced correctly. The **Portfolio** class has a very simple *price* method and every line of that method is already tested by our test of put call parity. Testing that **Portfolio** works with a portfolio of complex options would add nothing new.
