The **expression** is allowed to be any basic data type. The value `0` is interpreted as **false** and other values are interpreted as **true**.

So, for example, the following code snippet prints out that the test has passed.

```
if (-1.743) {
 cout << "Test passed\n";
}
```

The problem occurs when you use `=` in tests by accident instead of `==`. The following is legal C++:

```
int i = 1;
int j = 3;
if (i = j) {
 cout << "i is equal to j\n";
}
```

In the `if` statement, the code assigns a value of 3 to the variable *i* and then, observing that 3 is non-zero, prints out the false claim that *i* is equal to *j*.

# **Danger!**

Do not use `=` in `if` statements. Use `==` instead. Make the compiler treat warnings as errors to prevent this problem.
