We have separated the employee’s name, address, and contact type into subcategories. Furthermore, we have defined a `struct` dateType. Let us rebuild the employee’s record as follows:

```
```c
struct employeeType
{
    nameType name;
    string empID;
    addressType address;
    dateType hireDate;
    dateType quitDate;
    contactType contact;
    string deptID;
    double salary;
};
```
