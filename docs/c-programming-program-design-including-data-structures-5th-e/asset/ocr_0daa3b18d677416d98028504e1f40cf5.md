# PREORDER TRAVERSAL

In a preorder traversal, the binary tree is traversed as follows:

+   1. Visit the node.
+   2. Traverse the left subtree.
+   3. Traverse the right subtree.

# POSTORDER TRAVERSAL

In a postorder traversal, the binary tree is traversed as follows:

+   1. Traverse the left subtree.
+   2. Traverse the right subtree.
+   3. Visit the node.

Clearly, each of these traversal algorithms is recursive.

The listing of the nodes produced by the inorder traversal of a binary tree is called the **inorder sequence**. The listing of the nodes produced by the preorder traversal is called the **preorder sequence**, and listing of the nodes produced by the postorder traversal is called the **postorder sequence**.
