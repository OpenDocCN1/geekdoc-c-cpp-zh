# **TABLE 17-2**  Inserting a Node in a Linked List Using Two Pointers

| Statement | Effect |
|---|---|
| `p->link = newNode;` | The pointer `p` is linked to `newNode`. |
| `newNode->link = q;` | The pointer `newNode` is linked to `q`. |

