## 迭代器

迭代器类似于指针。一般来说，迭代器指向容器（序列容器或关联容器）的元素。因此，借助迭代器，我们可以依次访问容器的每个元素。

迭代器上最常见的两个操作是 `++`（自增运算符）和 `*`（解引用运算符）。假设 `cntItr` 是容器中的一个迭代器。语句：

```cpp
++cntItr;
```

使 `cntItr` 前进，使其指向容器中的下一个元素。类似地，语句：

```cpp
*cntItr;
```

提供对 `cntItr` 所指向容器元素的访问。

## 迭代器类型

迭代器有五种类型：

- 输入迭代器
- 输出迭代器
- 前向迭代器
- 双向迭代器
- 随机访问迭代器

以下各节描述这些迭代器。
