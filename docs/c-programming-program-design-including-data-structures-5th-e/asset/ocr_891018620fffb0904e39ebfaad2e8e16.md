+   5. The algorithm to determine the minimal spanning tree given in this chapter is of the order \(O(n^3)\). The following is an alternative to Prim’s algorithm that is of the order \(O(n^2)\).

**Input:** A connected weighted graph \(G = (V, E)\) of \(n\) vertices, numbered 0, 1, . . . , \(n - 1\); starting with vertex \(s\), with a weight matrix of \(W\).

**Output:** The minimal spanning tree.

```
Prim2(G, W, n, s)
Let T = (V, E), where E = ϕ.
for (j = 0; j < n; j++)
{
    edgeWeights[j] = W(s,j);
    edges[j] = s;
    visited[s] = false;
}
edgeWeights[s] = 0;
visited[s] = true;
while (not all nodes are visited)
{
    Choose the node that is not visited and has the smallest weight, and call it k.
    visited[k] = true;
    E = E ∪ {(k, edges[k])}
    V = V ∪ {k}
    for each node j that is not visited
        if (W(k,j) < edgeWeights[j])
        {
            edgeWeights[j] = W(k,j);
            edges[j] = k;
        }
}
return T;
```
