## 谓词

谓词是一类特殊的函数对象，返回布尔值。谓词有两种类型：一元谓词和二元谓词。一元谓词检查单个参数的特定属性；二元谓词检查一对参数（即两个参数）的特定属性。谓词通常用于指定搜索或排序条件。在 STL 中，谓词对于相同的值必须始终返回相同的结果。因此，修改其内部状态的函数不能被视为谓词。
