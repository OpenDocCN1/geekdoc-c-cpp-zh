From the definition of the node, it is clear that for each node:

+   1. The data is stored in info.
+   2. A pointer to the left child is stored in lLink.
+   3. A pointer to the right child is stored in rLink.

Furthermore, a pointer to the root node of the binary tree is stored outside of the binary tree in a pointer variable, usually called the root, of type nodeType. Thus, in general, a binary tree looks like the diagram in Figure 20-4.

Before we leave this section, let us define a few terms.

A node in a binary tree is called a **leaf** if it has no left and right children. Let *U* and *V* be two nodes in this binary tree. *T* is called the **parent** of *V* if there is a branch from *U* to *V*. A **path** from a node *X* to a node *Y* in a binary tree is a sequence of nodes *X₀, X₁, …, Xₙ* such that:

+   i.  X = X₀, Xₙ = Y
+   
+   ii.  Xᵢ₋₁ is the parent of Xᵢ for all i = 1, 2, …, n. That is, there is a branch from X₀ to X₁, X₁ to X₂, …, Xᵢ₋₁ to Xᵢ, …, Xₙ₋₁ to Xₙ.

If *X₀, X₁, …, Xₙ* is a path from node *X* to node *Y*, sometimes we denote it by *X* = *X₀ X₁ … Xₙ₋₁ Xₙ* = *Y* or simply *X* → *X₁* → … → *Xₙ₋₁* → *Xₙ* = *Y*.

Because the branches go only from a parent to its children, from the previous discussion it is clear that in a binary tree, there is a unique path from the root to every node in the binary tree.
