As you can see, the function `strcmp` compares its first C-string argument with its second C-string argument character by character.

> **NOTE.** In this chapter, we defined a C-string to be a sequence of zero or more characters. C-strings are enclosed in double quotation marks. Therefore, to store the C-string `"Hello"` in computer memory, you must use a character array of size 6. The length of a C-string is the number of actual characters enclosed in double quotation marks; for example, the length of the C-string `"Hello"` is 5. Because the length of the C-string is the actual number of characters enclosed in double quotation marks, we defined a C-string to be a sequence of zero or more characters. However, you must remember that the null character stored in computer memory at the end of the C-string plays a key role when we compare C-strings, especially C-strings such as `"Bill"` and `"Billy"`.
