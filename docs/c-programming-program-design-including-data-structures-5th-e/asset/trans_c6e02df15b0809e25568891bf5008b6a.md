```cpp
template <class Type>
void doublyLinkedList<Type>::deleteNode(const Type& deleteItem)
{
    nodeType<Type> * current;  //pointer to traverse the list
    nodeType<Type> * trailCurrent;  //pointer just before current

    bool found;

    if (first == NULL)
        cout << "Cannot delete from an empty list." << endl;
    else if (first->info == deleteItem)  //node to be deleted is
                                         //the first node
    {
        current = first;
        first = first->next;

        if (first != NULL)
            first->back = NULL;
        else
            last = NULL;

        count--;
        delete current;
    }
    else
    {
        found = false;
        current = first;

        while (current != NULL && !found)  //search the list
            if (current->info >= deleteItem)
                found = true;
            else
                current = current->next;

        if (current == NULL)
            cout << "The item to be deleted is not in "
                 << "the list." << endl;
        else if (current->info == deleteItem)  //check for
                                              //equality
        {
            trailCurrent = current->back;
            trailCurrent->next = current->next;

            if (current->next != NULL)
                current->next->back = trailCurrent;

            if (current == last)
                last = trailCurrent;

            count--;
            delete current;
        }
        else
            cout << "The item to be deleted is not in list."
                 << endl;
    }//end else
}//end deleteNode
```

## 循环链表

若一个链表中的最后一个节点指向第一个节点，则称该链表为**循环链表**。图 17-45 展示了各种循环链表。

![](img/f97f778697507bb6fdd80c5991210cba_1092_0.png)

**图 17-45** 循环链表

在具有多个节点的循环链表中，如图 17-45(c) 所示，让指针 **first** 指向链表的最后一个节点会很方便。然后，通过使用 **first**，你可以访问链表的第一个节点和最后一个节点。例如，**first** 指向最后一个节点，而 **first->link** 指向第一个节点。

与之前一样，循环链表的常用操作包括：

- 1. 初始化链表（置为空状态）。
- 2. 判断链表是否为空。
- 3. 销毁链表。
- 4. 打印链表。
- 5. 求链表的长度。
- 6. 在链表中查找给定项。
- 7. 在链表中插入一项。
- 8. 从链表中删除一项。
- 9. 复制链表。

## 编程示例：音像店

对家庭或个人来说，周末或假日喜欢去的地方之一是音像店租电影。你所在社区的一家新音像店即将开业。然而，它还没有用于跟踪其影片和客户的程序。店经理希望有人为他们的系统编写一个程序，使音像店能够运作。该程序应能够执行以下操作：

- 1. 借出影片；即办理影片借出手续。
- 2. 归还影片；即办理影片归还手续。
- 3. 创建商店拥有的影片列表。
- 4. 显示特定影片的详细信息。
- 5. 打印商店中所有影片的列表。
- 6. 检查商店中是否有特定影片。

让我们为音像店编写一个程序。这个示例进一步说明了面向对象的设计方法，特别是继承和重载。
