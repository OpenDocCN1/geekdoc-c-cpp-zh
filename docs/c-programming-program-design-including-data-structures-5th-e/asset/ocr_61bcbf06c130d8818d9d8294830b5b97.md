# INSERTION

Consider the linked list shown in Figure 17–7.

**FIGURE 17–7**  Linked list before item insertion

Suppose that p points to the node with info 65, and a new node with info 50 is to be created and inserted after p. Consider the following statements:

```
newNode = new nodeType;   //create newNode
newNode->info = 50;       //store 50 in the new node
newNode->link = p->link;
p->link = newNode;
```

Table 17–1 shows the effect of these statements.

**TABLE 17–1**  Inserting a Node in a Linked List

| Statement | Effect |
|---|---|
| `newNode = new nodeType;` | Creates a new node, initially shown without an info value, while the original list is `head → 45 → 65 → 34 → 76`; `p` points to `65`. |
| `newNode->info = 50;` | Stores `50` in the new node; the original list remains `head → 45 → 65 → 34 → 76`. |
| `newNode->link = p->link;` | Sets the new node's link to the node containing `34`; the new node containing `50` is positioned after `p` and before `34`. |
| `p->link = newNode;` | Completes the insertion: `head → 45 → 65 → 50 → 34 → 76`, with `p` pointing to `65`. |
