首先，我们编写函数 **operator++** 的定义。将时间增加 1 秒的算法如下：

- a. 将秒数加 1。
- b. 如果秒数 > 59，
    - b.1. 将秒数设置为 0。
    - b.2. 将分钟数加 1。
    - b.3. 如果分钟数 > 59，
        - b.3.1. 将分钟数设置为 0。
        - b.3.2. 将小时数加 1。
        - b.3.3. 如果小时数 > 23，
            - b.3.3.1. 将小时数设置为 0。
- c. 返回对象增加后的值。

函数 **operator++** 的定义如下：

```cpp
//Overload the pre-increment operator.
clockType clockType::operator++()
{
    sec++;                    //Step a

    if (sec > 59)             //Step b
    {
        sec = 0;              //Step b.1
        min++;                //Step b.2

        if (min > 59)         //Step b.3
        {
            min = 0;          //Step b.3.1
            hr++;              //Step b.3.2

            if (hr > 23)       //Step b.3.3
                hr = 0;       //Step b.3.3.1
        }
    }

    return *this;              //Step c
}
```

函数 **operator==** 的定义非常简单。如果两个时间的小时、分钟和秒数都相同，则这两个时间相同。因此，函数 **operator==** 的定义如下：

```cpp
//Overload the equality operator.
bool clockType::operator==(const clockType& otherClock) const
{
    return (hr == otherClock.hr && min == otherClock.min
        && sec == otherClock.sec);
}
```

下面给出函数 `operator<=` 的定义。如果满足以下条件之一，则第一个时间小于或等于第二个时间：

- 1. 第一个时间的小时数小于第二个时间的小时数，或者
- 2. 第一个时间和第二个时间的小时数相同，但第一个时间的分钟数小于第二个时间的分钟数，或者
- 3. 第一个时间和第二个时间的小时数、分钟数都相同，但第一个时间的秒数小于或等于第二个时间的秒数。

函数 `operator<=` 的定义如下：

```cpp
//Overload the less than or equal to operator.
bool clockType::operator<=(const clockType& otherClock) const
{
    return ((hr < otherClock.hr) ||
        (hr == otherClock.hr && min < otherClock.min) ||
        (hr == otherClock.hr && min == otherClock.min &&
            sec <= otherClock.sec));
}
```
