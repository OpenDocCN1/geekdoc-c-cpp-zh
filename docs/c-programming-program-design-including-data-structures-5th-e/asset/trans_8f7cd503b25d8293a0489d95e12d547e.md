第 4 步通常按如下方式工作。你将文件流变量与 `>>`、`<<` 或其他输入/输出函数一起使用。将 `>>` 或 `<<` 与文件流变量一起使用的语法，与使用 `cin` 和 `cout` 的语法完全相同。不过，你使用的不是 `cin` 和 `cout`，而是已声明的文件流变量名。例如，语句：
