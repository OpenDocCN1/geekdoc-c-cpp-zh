When we define a vector, we give it an initial size (initial number of elements):

Click here to view image

| vector<int> v1={1, 2, 3, 4}; | size is 4 |
| vector<string> v2; | size is 0 |
| vector<Shape> v3(23); | size is 23; initial value: nullptr |
| vector<double> v4(32,9); | size is 32; initial value: 9.9 |

An explicit size is used in ordinary parentheses, for example, (23), and by default, the elements are initialized to the element type's default value (e.g., nullptr for pointers and 0 for numbers). If you don't want the default value, you can specify it as a second argument (e.g., 9.9 for the 32 elements of v4).

The initial size can be changed. One of the most useful operations on a vector is push_back(), which adds a new element at the end of a vector, increasing its size by one. For example, assuming that we have defined >> for Entry, we can write:

```
void input()
{
    for (Entry& e; cin>>e);
    phone.push_back(e);
}
```

This reads Entries from the standard input into phone_book until the end-of-input (e.g., the end of a file) is reached or the input operation encounters a format error.
