# 1.3 Functions

The main way of getting something done in a C++ program is to call a function to do it. Defining a function is how you specify how an operation is to be done. A function cannot be called unless it has been declared.

A function declaration gives the name of the function, the type of the value returned (if any), and the number and types of the arguments that must be supplied in a call. For example:

Click to view code image

```
Elem* next_elem(); // No argument, return a pointer to Elem (Elem*)
void exit(int); // If no argument, return int
double sqrt(double); // If double argument, return double
```

In a function declaration, the return type comes before the name of the function and the arguments come after in parentheses.

The semantics of argument passing are identical to the semantics of initialization (§3.4.1). That is, argument types are checked and implicit type conversion takes place when necessary (§1.4). For:

Click to view code image

```
double s2 = sqrt("2"); // Call sqrt(2) with the argument type double
double s3 = sqrt("three"); // Error: sqrt() requires an argument of type double
```

The value of compile-time checking and type conversion should not be underestimated.

A function declaration may contain argument names. This can be a help to the reader of a program, but unless the declaration is a function definition, the compiler simply ignores them. For example:

Click to view code image

```
double sqrt(double d); // Return the square root of d
double square(double); // Return the square of the argument
```

The type of a function consists of its return type followed by the sequence of its argument types in parentheses.

