The notation [&int return a<>;] is called lambda expression. It generates a function object similar to Less_than<int>(x). The [&] is a capture list specifying that all names used in the lambda (such as x) will be accessed through references. Had we wanted to "capture" only x, we could have said: [&]. Had we wanted to give the generated copy of x, we could have said: [x]. Capture nothing is [{}], capture all names used by reference is [&], and capture all names used by value is [=].

For a lambda defined within a member function, [this] captures the current object by reference so that we can access members. If we want a copy of the current object, we can use [*this"].

If we want to capture several specific objects, we can list them. The use of [i,this] in the use of expect()($4.5) is an example.

# 7.3.3.1 Lambdas as function arguments
