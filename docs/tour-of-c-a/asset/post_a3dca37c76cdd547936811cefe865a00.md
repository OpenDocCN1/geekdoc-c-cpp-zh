The operations on istams and ostreams are described in §11.2 and §11.3. The operations are type-safe, type-sensitive, and extensible to handle user-defined types (§11.5).

Other forms of user interaction, such as graphical I/O, are handled through built-in libraries that are not part of the ISO standard and therefore described here.

The I/O class has all destructors that free all resources owned (such as buffers and file handles). They are examples of "Resource Acquisition Initialization (RAII); §6.3).

## 11.2 Output

In <iostream>, the I/O stream library defines output for every output of a user-defined type (§11.5). The operator << ("put to") is used as an output operator on objects of type istream; cout is the built-in output stream and cerr is the standard characters for stream reporting errors. By default, values written to cout are converted to a sequence of characters. For example, to output the decimal number 10, we can write:

```
cout << 10;
```

This places the character 1 followed by the character 0 on the standard output stream. Equivalently, we could write:

```
int x (10);
cout << x;
```

Output of different types can be combined in the obvious way:

Click here to view image
```cpp
void h(int i)
{
    cout << "the value of i is " << i;
    cout << "\n";
}
```

For h(10), the output will be the value of i 10. People soon realize that repeating the output stream when outputting several related items. Furthermore, the result of an output expression itself can be used for further output. For example:

Click here to view image
```cpp
void h2(int i)
{
    cout << "the value of i is " << i << "\n";
}
```

This h2() produces the output as h. A character is enclosed in single quotes. Note that a character is output as a character rather than a numerical value.

Click here to view image
```cpp
int b = 'b'; // note: implicitly converted to int
char c = 'c';
cout << b << c;
```

The integer value of the character 'b' is 98 (in ASCII encoding used by C++), this will output.

## 11.3 Input

In <iostream>, the standard library offers istream for input. ostreams deal with character representations of built-in types and can easily be extended to use user-defined types. The operator >> ("get") is used as an input operator; cin is the standard stream. The right-hand operand of >> determines what input is accepted and what is the target of the input operation. For example:

Click here to view image
```cpp
int i;
cin >> i;          // Read an integer into i
double d;
cin >> d;          // Read a double-precision floating-point number into d
```

This reads a number, such as 123, from the standard input into the integer variable i and floating-point number, such as 1.34e5, into the double-precision variable d.

Like output operations, input operations can be chained, so we could have written:

Click here to view image
```cpp
int i;
double d;
cin >> i >> d; // Read into i and d
```

In both cases, the read of the integer is terminated by any character that is not a digit. By default, it skips whitespace, so a suitable input sequence would be:

```
123
1.34e5
```

Often, we want to read a sequence of characters. A convenient way of doing that is to read into a string. For example:

Click here to view image
```cpp
cout << "Please enter your name";
string str;
cin >> str;
cout << "Hello, " << str << "\n";
```

If you type Eric in your response:

Hello, Eric!

By default, a whitespace character, such as a space or a newline, terminates the read, so if you enter Eric Alexander to be the king, the response is still:

Hello, Eric!

You can read a line using the getline() function. For example:

Click here to view image
```cpp
cout << "Please enter your name";
string str;
getline(cin,str);
cout << "Hello, " << str << "\n";
```

With this program, input Eric Alexander yields the desired output:

Hello, Eric Alexander!

The newline that terminated the line is discarded, so cin is ready for the next input line. Using the formatted I/O operations is usually less error-prone, more efficient, and less code manipulating characters by one. In particular, stringstreams take care of memory management and range checking. We can do formatting to and from memory using stringstreams (§11.7.3) or memory streams. The standard strings have the nice property of expanding to fit what you put in them; you don't have to pre-calculate a maximum size. So, if you enter a couple of megabytes of semicolons, hello_line() will echo pages of semicolons back at you.

## 11.4 I/O State

An istream has a state that we can examine to determine whether an operation succeeded. The most common use it is to read a sequence of values:

Click here to view image
```cpp
vector<int> read_ints(istream& is)
{
    vector<int> res;
    for (int i; is >> i; ) {
        res.push_back(i);
    }
    return res;
}
```

This reads from is until that is not an integer is encountered. That something will typically be the end of input. What happening here is that the operation >> returns a reference to is, and testing an istream yields true if the stream is ready for another operation.

In general, the I/O state holds all the information needed to read or write, such as formatting information (§11.6.2), error state (e.g., has-of-file reached?), and what kind of buffering is used. By using a set the user can set to retrieve that an error has occurred (§11.5) and clear the state if an error wasn't serious. For example, we could imagine a version of read_ints() that accepts a terminating string:

Click here to view image
```cpp
vector<int> read_ints(istream& is, const string& terminator)
{
    vector<int> res;
    for (int i; is >> i; ) {
        res.push_back(i);
    }
    if (is.eof()) // If: end of file
        return res;
    if (is.fail()) // If we failed to read an int
        is.clear(); // It reset the state to good
        string s;
        if (s==terminator)
            return res;
        is.setstate(ios_base::failbit); // It add fail() to is's state
    }
    return res;
}
```

## 11.5 I/O of User-Defined Types

In addition to the I/O of built-in types and standard strings, the iostream library allows us to define I/O for our own types. For example, consider a simple type Entry that we might use to represent entries in a telephone book:

```cpp
struct Entry {
string name;
int number;
```

We can define a simple output operator to use a Entry ("name",number) format similar to the one we use for initialization in code:

Click here to view image
```cpp
ostream& operator<<(ostream& os, const Entry& e)
{
    return os << "\"" << e.name << "\" << e.number << "}";
}
```
