# 15.3.4 tuple

Like arrays, the standard-library containers are homogeneous; that is, all elements are of a single type. However we want to treat a sequence of elements of different types as a single object; that we have a heterogeneous container; pair is an example, but not all such heterogeneous sequences have two elements. The standard library provides tuple to generalization of pair with zero or more elements

```
tuple t0 {};
tuple<string,int,double> t1("Shark",123,13.34);
auto t2 = make_tuple("Herring",10,10.23);
tuple t3("Cod",20,9.999);
```

The elements (members) of tuple are initialized; there is no invariant (4.3) maintained among them. If we want an invariant, we must encapsulate the tuple in a class that enforces it.

For a single use, a simple struct is often ideal, but there are many generic uses where the flexibility of tuple saves us from having to define many generic mnemonic names for the members. Members of a tuple are accessed through a get function template.
