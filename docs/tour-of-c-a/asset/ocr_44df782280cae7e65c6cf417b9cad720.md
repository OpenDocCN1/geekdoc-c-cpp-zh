# 14.1 Introduction

The standard-library offers both constrained using concepts (Chapter 8) and unconstrained (for compatibility). versions are <ranges> in namespace ranges. Naturally, I prefer using the concepts. A range is a generalization of the C++98 sequences defined by {begin(), end()} pairs; it specifies what it takes to be a sequence of elements. A range can be defined by

+   - A (begin, end) pair of iterators
- A (begin,n) pair, where begin is an iterator and n is the number of elements
- A (begin,pred) pair, where begin is an iterator and pred is a predicate; if pred(p) is true for the iterator p, we have reached the end of the range. This allows us to have infinite ranges and ranges that are generated “on the fly” (§14.3).
