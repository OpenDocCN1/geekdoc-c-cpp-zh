A string_view gives access to a contiguous sequence of characters. The characters can be stored in many possible ways, including in a string and a C-style string. A string_view is like a pointer or a reference that it does not own the characters it points to. In that, it resembles an STL pair of iterators (§13.3).

Consider a simple function concatenating strings:

```
{
  string res(string_view sv1, string_view sv2);
    // initialize from sv1
    return res += sv2; // append to sv2 and return
}
```

A string_view defines a range, so we can traverse its characters. For example:

Click here to view code image

```
void print_lower(string_view sv1)
{
  for (char c : sv1)
    cout << tolower(c);
}
```

One significant restriction of string_view is that it is a read-only view of its characters. For example, you cannot use a string_view to pass characters to a function that modifies its argument to lowercase. For that, you might consider using a span (§15.2.2).
