We see that sequencer is a coroutine because it used co_yield to suspend itself between calls. This implies that task must be a coroutine handler (see below). This is a deliberately trivial coroutine. All it does is generate a sequence of values and output them. In a simulation simulation, output would directly or indirectly become the input to some other coroutine.
