# 16.6 move() and forward()

The choice between moving and copying is mostly implicit (§3.4). A compiler will prefer to move when an object is about to be destroyed (as in a return) because that's assumed to be the simpler and more efficient operation. However, we must be explicit. For example, a unique_ptr is the sole owner of an object. It cannot be copied, so if you want a unique_ptr elsewhere, you must move it.
