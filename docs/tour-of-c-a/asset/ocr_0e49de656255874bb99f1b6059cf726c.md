# 10.4.2 Regular Expression Notation

The regex library can recognize several variants of the notation for regular expressions. Here, 1 use the default notation, a variant of the ECMA standard used for ECMAScript (more commonly as JavaScript). The syntax of regular expressions is based on special characters:

| Regular Expression Special Characters |
|---||
| \ Any single character (a "wildcard") | Next character has a special meaning |
| \ Begin class | Zero or more (suffix operation)|
| \ End character class | One or more (suffix operation) |
| \ Begin count | Optional (zero or one) (suffix operation) |
| \ End count | Start of line; negation |
| \ Begin grouping | End of line |

For example, we can specify a line starting with zero or more As followed by one or more Bs followed by an optional C like this:

```
^A*B+C?$
```

Examples that match:

```
AAAAAAAAAAAAABBBBBBC
BC
B
```

Examples that do not match:

| AAAA // no B |
| AAABC // initial space |
| AABBCC // too many Cs |

A part of a pattern is considered a subpattern (which can be extracted separately from an smatch) if it is enclosed in parentheses. For example:

```
\d+|d+ // no subpatterns
\d+(-|d+) // one subpattern
(\d+)(|d+) // two subpatterns
```

A pattern can be optional or repeated (the default is exactly once) by adding a suffix:

| Repetition |
|---||
| { n } | Exactly n times |
| {, } n | or more times |
