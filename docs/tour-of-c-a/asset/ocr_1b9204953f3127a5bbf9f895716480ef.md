This a stylized example, but unfortunately not atypical. We need to select among a set of alternatives for initializing a data structure (here v) and we need to do different computations of different alternatives. Such code is often messy, deemed “for efficiency,” and a source of bugs:

+   - The variable could be used before it gets its value.
- The “initialization code” could be mixed with other code, making it harder to comprehend.
- When “initialization code” is mixed with other code, it is easier to get for a case.
- This isn’t initialization, it’s assignment as [I.9.2).
