Basically, the Vector is a "handle" containing pointers to the elements (elem) and the number of elements (sz). The 6 elements in the example can vary from Vector object to Vector, and a Vector can have different numbers of elements at different times ($5.2.3). However, the Vector object itself is always the same size. This is the basic for handling arrays a fixed-size handle to reference varying amounts of data "elsewhere" (e.g., on the free store allocated by new);$5.2.2 How to design and use objects is the main topic of Chapter 5.
