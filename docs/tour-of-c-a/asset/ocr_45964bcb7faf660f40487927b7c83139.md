The point of adding ints in a double will be gracefully a sum much larger than the int. Note how the type of templates argument for sum<Sequence,Value> are deduced from the function arguments. Fortunately, we do not need to explicitly specify those types. This sum is a simplified version of the standard-library accumulate() (§17.3). A function template can be a member function, but not a virtual member. The compiler will not know all instantiations of such a template in a program, or could generate a virtual (§5.4).

# 7.3.2 Function Objects

One particularly useful template is the function object (sometimes called a functor), which is used to define objects that can be called like functions. For example:

class Less {

public:
