The body of sum a fold expression:

Click here to view code image

```
return (v + ... + 0); // add all elements of v with the initial value 0
```

Here, (v..+0) means all the elements of v starting with [v[0]+v[1]+v[2]+v[3]+v[4]]]. That element to be added is the "rightmost" (the one with the highest index); it is starting from the right of the 0. It is called a right fold. Alternatively, we could have used a left fold:

Click here to view code image

```
template<Number... T>
int sum(T... v)
{
    return (0 + ... + v); // add all elements of v to v
}
```

Now, the first element to be added is the "leftmost" (the one with the lowest index):
(((v[0]+v[1])+v[2])+v[3])+v[4]). That is, starting from the left of the 0 is.

> Fold is a powerful abstraction, clearly to the standard-library accumulate(), with a variety of names in different languages and communities. In C++, the expressions are currently restricted to simplify the implementation of variadic templates. A fold does not have to perform numeric computations. Consider a famous example:

Click here to view code image

```
template<Printable ...T>
void print(T&&... args)
{
    (std::cout << ... << args) << '\n'; // print all arguments
}
```

```
print("Hello", "World", 2017); // (((((std::cout << "Hello") << "World") << 2017)) << '\n\');
```

Why 2017? Because fold() was added to C++ 2017 (19.2.3).
