# ## 2.2 Structures

The first step in building a new type is to organize the elements it needs into a data struct:

Click here to view code image

```
struct Vector {
    double* elem; // pointer to elements
    int sz;       // number of elements
}
```

This first version of Vector consists of an int and a double.
A variable of type Vector can be defined like this:

Vector v;

However, by itself is not of much use because v's elem pointer doesn't point to anything. For it to be useful, we must give v some elements to point to. For example:

Click here to view code image

```
void vector_init(Vector& v, int s) // initialize a Vector
{
    v.elem = new double[s]; // allocate an array of s doubles
    v.sz = s;
}
```

That is, v's elem member gets a pointer to the new operator and v's sz member gets the number of elements. The & in Vector identifies that we pass v by non-const reference (1.7); that way, vector_init) modifies the vector passed to.

The new operator allocates memory from the free area (also known as dynamic memory and heap). Objects allocated on the free store are independent of the scope from which they are created and "live" until they are destroyed by the delete (5.2.2).

A simple use of Vector likes like this:

Click here to view code image

```
double read_and_sum(int s) // it reads from cin and return their sum; s is assumed to be positive
{
    Vector v;
    vector_init(v, s); // allocate s elements for v
    for (int i=0; i<s; ++i)
        cin >> v.elem[i]; // read into elements
}
```
