When all we want a sequence of elements, we have a choice between a vector and a list. Unless we have a reason not to use, use a vector. # 12.4 forward_list

The standard library offers a singly-linked list called forward_list:

![](bbox=[0.175, 0.316, 0.802, 0.396])

forward_list: A forward_list differs from a (doubly-linked) list by only allowing forward iteration. The point of that is to save space. There is no need to keep a predecessor pointer in each link and the size of an empty forward_list is just one pointer. A forward_list doesn't even keep its number of elements. If you need the number of elements, count. If you can't afford to count, you probably shouldn't use forward_list.

# 12.5 map

Writing code to look up a name in a list of (name,number) pairs is quite tedious. In addition, a linear search is inefficient for all lists. The standard library offers a balanced binary search tree (usually a red-black tree) called map:

![](bbox=[0.175, 0.653, 0.682, 0.833])

In other contexts, a map is known as an associative array or a dictionary. The standard-library map is a container of pairs of values optimized for lookup and insertion.
