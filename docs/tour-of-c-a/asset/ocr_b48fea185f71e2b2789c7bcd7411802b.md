+   • finally, replace the conte types with template arguments.

Naturally, the repetition of begin() and end() is tedious, so we can simplify the user interface a bit:
Click to view code image

```
template<forward_range R, Arithmetic<value_type_t<R>>> Val
accumulate(const R& r, Val res = 0)
{
    for (auto x : r) {
        res += x;
    }
    return res;
}
```

A range is a standard-library concept representing a sequence with begin() and end() (§13.1). For full generality, we can enhance the += operation also; see §17.3.
Both the pair-of-iterators and the range version of accumulate are useful: the pair-of-iterators for generality, the range version for common uses.

# 8.4 Variadic Templates

A template can be defined to accept any number of arguments of arbitrary types. Such a template is called a variadic template. Consider a simple function to write out values of any type that has a << operator:

Click to view code image

```
void user() {
    print("first": 1, 2, 2, "hello"s"); // first: 1 2 2 hello
    print("insecond": 0, '0.2', 'c', "yuck"s, 0, 1, 2, "in"); // Second: 0.2 c yuck! 0 1 2
}
```

Traditionally, implementing a variadic template has to separate the first argument from the rest and recursively call the variadic template for the tail of the arguments:

Click to view code image

```
template<typename T>
concept Printable = requires(T t) { std::cout << t; } // Just one operation!

void print() {
    // Ill what we do for no arguments: nothing
}

template<Printable T, Printable... Tail>
void print(T head, Tail... tail) {
    cout << head << ' <<'; // first, what we do for the head
    print(tail...); // then, what we do for the tail
}
```

The Printable... indicates that Tail is a sequence of types. The Tail... indicates that tail is a sequence
