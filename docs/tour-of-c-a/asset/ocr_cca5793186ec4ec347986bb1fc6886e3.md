# ## 10.1 Introduction

Text manipulation is a major part of most programs. The C++ standard library offers a string type to save most users from C-style manipulation of arrays of characters pointers.. string_view allows you to manipulate sequences of characters however they may be stored (e.g., in a std::string or char[]). In addition, regular expression matching is offered in a form similar to what is common in most modern languages. Both strings and regex objects can use a variety of character types (e.g., Unicode).
