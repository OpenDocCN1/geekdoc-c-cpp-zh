By putting my code in the namespace My_code, I make sure that my names do not conflict with the standard-library names in namespace std ($3.3). That precaution is wise, because the standard library does not provide support for arithmetic ($5.2.1, $17.4).
The simplest way to access a name in another namespace is to qualify it with the name (e.g., std::cout and My_code::main). The "real main()" is defined in the global namespace, not local to a defined namespace, class, or function.
If qualifying a name becomes tedious or distracting, we can bring the name into a scope with a using-declaration:

A using-directive makes unqualified names from the named namespace accessible from the scope in which we placed the directive.
