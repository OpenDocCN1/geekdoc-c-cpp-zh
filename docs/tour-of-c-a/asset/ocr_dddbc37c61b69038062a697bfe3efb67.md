In a declaration, the unary suffix & "reference to". A reference is similar to a pointer, except that you don't need to use a prefix & to access the value referred by the reference. Also, a reference cannot be made to refer to a different object after its initialization.

# 1.7.1 The Null Pointer

We try to ensure that a pointer always points to an object so that dereferencing is valid.
