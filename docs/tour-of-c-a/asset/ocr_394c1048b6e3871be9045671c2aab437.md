# 17.3 Numerical Algorithms

In <numeric>, we find a set of generalized numerical algorithms, such as accumulate().

| Numerical Algorithms | |
|---|---|
| x=accum(b,e,i) | x is the sum of i and the elements of [b:e) |
| x=accumulate(b,e,i,f) | accumulate using f instead of + |
| x=inner_product(b,e,b2,i2) | x is the inner product of [b:e) and [b2:b2+(e-b)], that is, the sum of (i) and (p1)(p2) for p1 in [b:e) and the corresponding p2 in [b2:b2+(e-b)) |
| x=inner_product(b,e2,b2,i2,f,f2) | inner_product using f and instead of + and * |
| p=partial_sum(b,e,out) | Element i of [out:out) is the sum of elements [b:b+i) |
| p=partial_sum(b,e,out,f) | partial_sum using f instead of + |
| p=adjacent_difference(b,e,out) | Element i of [out:out) is (b+i)-(b-1) for i>0; if e-b>0, then out is 'b |
| p=adjacent_difference(b,e,out,f) | adjacent_difference using f instead of - |
| iota(b,v,n) | For each element in [b:n) assign v and increment++; thus the sequence becomes v, v+1, v+2... |
| x=gcd(n,m) | x is the greatest common denominator of integers n and m |
| x=lcm(n,m) | x is the least common multiple of integers n and m |
| x=midpoint(n,m) | x is the midpoint between n and m |

These algorithms generalize common operations such computing a sum by letting them apply to all kinds of sequences. They also make the operation to elements of these sequences a parameter. For each algorithm, the general version is supplemented by a version using the most common operator for that algorithm. For example:
