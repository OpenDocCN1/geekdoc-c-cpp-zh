# 14.4 Pipelines

For each standard-view ($14.2), the standard library provides a function that produces a filter; that is, an object that can be used as an argument to the filter adaptor. For example, filter() yields a filter_view. This allows to combine filters in a sequence rather than presenting them as a set of nested calls.

Click here to view code image

```
void user(forward_range auto& r)
{
  auto odd = [](int x) { return x % 2; };
  for (int x : r | views::filter(odd) | views::take(3))
    cout << x << "";
}
```

An input range 2 4 6 8 20 produces 1 2 3.
The pipeline style (using Unix pipe adaptor) is widely regarded as more readable than nested calls. The pipeline works left to right; that is fig the result of f is passed to g, so rflg means $g(filter(f(r)))$. The initial r has to be a range or a generator.
These filter functions are in namespace ranges::views:

Click here to view code image

```
void user(forward_range auto& r)
{
  for (int x : r | views::filter([(int x) { return x % 2; }) | views::take(3))
    cout << x << "";
}
```
