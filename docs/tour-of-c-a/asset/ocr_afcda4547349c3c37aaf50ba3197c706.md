of values of types in Tail. A parameter declared with a ... is called a parameter pack. Here, tail is a (function argument) parameter pack where the elements are of the types found in the (template) parameter pack Tail. So, print(t) can take any number of arguments of types.

A call to print(t) expands the arguments into a head (the first) and a tail (the rest). The head is printed and then print() is called for the tail. Eventually, tail will become empty, so we need the no-argument version of print() to deal with it. If we don't want to allow the zero-argument case, we can eliminate that print(t) using a compile-time if.

Click here to view code image

```
template<Printable T, Printable... Tail>
void print(T head, Tail... tail)
{
    cout << head << " ";
    if (constexpr(sizeof(tail) > 0)
        print(tail);
}
```

I used a compile-time if(\$7.4.3), rather than a final call if print(t) from being generated. Given that, the "print"() not need to be defined.
The strength of variadic templates is that they can accept any number of arguments you care to give them. Weaknesses include

+   * The recursive implementations can be tricky to get.
* The type checking of the interface is possibly elaborate template program.
* The type checking is ad hoc, rather than defined in the standard.
* The recursive implementations can be surprisingly expensive in compile time and compiler memory requirements.

Because of their flexibility, variadic templates are widely used in the standard library, and occasionally overused.

# 8.4.1 Fold Expressions

To simplify the implementation of simple variadic templates, C++ offers a limited form of iteration over elements of a parameter pack. For example:

```
template<Number... T>
int sum(T... v)\{
    return (v + ... + 0); // Add all elements of v starting with 0
}
```

This sum can take any number of arguments of types:

