# 10.2.1 string Implementation

Implementing a string class is a popular and useful exercise. However, for general-purpose, your carefully crafted first rarely match the standard string in convenience or performance. These days, string is usually implemented using the short-string optimization. That is, short string values are kept in the string object itself and only longer strings are placed on store.
