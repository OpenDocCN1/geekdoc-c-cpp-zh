# 5.2.2 A Container

A container is an object holding a collection of elements. We call class Vector a container objects of type Vector are containers. As defined in #2.3, Vector isnt an unreasonable container of doubles: it is simple to understand, establishes a useful invariant (#4.3), provides range-checked access (#4.2), and provides size to allow us to iterate over its elements. However, it does have a fatal flaw: it allocates new but never deallocates. That's not a good idea C++ does not offer a garbage collector to manage memory available for new objects. In some environments you can use a collector, or you prefer more control of destruction for logical or performance reasons. We need a mechanism to ensure the memory allocated by the constructor is deallocated; that mechanism is a destructor:

```
class Vector {
public:
    Vector(int s):elem(new double[s]), sz(s) // acquire resources
    {
        for (int i=0; i<s; ++i) // initialize elements
            elem[i]=0;
    }
    ~Vector() { delete elem; } // destructor: release resources
    double& operator[](int i);
    int size();
private:
    double* elem; // elem points to an array of sz doubles
    int sz;
};
```

The name of a destructor is the complement operator, ~, followed by the name of the class; it is the complement of a constructor.
