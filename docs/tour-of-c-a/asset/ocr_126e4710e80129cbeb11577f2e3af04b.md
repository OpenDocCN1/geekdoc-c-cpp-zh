I generalized C++s inheritance mechanisms to support multiple base classes [Stroustrup,1987]. This caused multiple inheritance and was difficult and controversial. Multiple inheritance of abstract classes (often called interfaces) is not universal in languages supporting static type checking and object-oriented programming.

The C++ language evolved hand-in-hand with some of the key libraries. For example, I designed complex [Stroustrup,1984], vector, stack, and (I/O) stream classes [Stroustrup,1985] with the operator overloading mechanisms. The first string and list classes were developed by Jonathan Shirope and me as part of the same effort. Jonathan's string and list classes were the first to see extensive use as part of a library. The string class of standard C++ has its roots in early templates. The library described in [Stroustrup,1987b] was part of the "C++ with Classes" program even in 1980. The development of the template facility was influenced by a variety of vector, map, list, and sort templates developed by Andrew Koenig, Alex Stepanov, and others.

The most important innovation in the 1998 standard library was the STL, a framework of algorithms and containers [Chapter 2, Chapter 13]. It was the work of Alex Stepanov (with Dave Muster, Meng Lee, and others) based on more than decade's work on generic programming. The STL was massively influential within the C++ community and beyond.
