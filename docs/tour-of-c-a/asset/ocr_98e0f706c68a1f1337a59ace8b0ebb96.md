# 7.2 Parameterized Types

We generalize our vector-of-doubles type ($5.2.2) to a vector-of-anything type by making a template and replacing the specific type double with a type parameter. For example:

Click here to view code image

```
template<typename T>
class Vector {
private:
    T* elem; // elem points to an array of sz elements of type T
    int sz;
public:
    explicit Vector(int s); // establish invariant, acquire resources
    ~Vector() { delete elem; } // release resources

    // copy and move operations ...

    T& operator[](int i); // for non-const Vectors
    const T& operator[](int i) const;
    int size() const { return sz; }
};
```

The template<typename T> prefixes a type parameter of the declaration it prefixes. It is C++'s version of the mathematical "for all T," or more precisely "for all types T." If you want the mathematical "for all T, such that P(T)," then use these concepts ($7.2.1, $8.2). Using class to introduce a type parameter is equivalent to using typename, and in old code we often see template<class T> as the prefix.

The member functions can be defined similarly:

Click here to view code image

```
template<typename T>
T& Vector<T>::operator[](int i) {
    if (i < 0 || i >= sz)
        throw out_of_range("Vector::operator[]: negative size");
    return elem[i];
}

template<typename T>
const T& Vector<T>::operator[](int i) const {
    if (i < 0 || i >= sz)
        throw out_of_range("Vector::operator[]: negative size");
    return elem[i];
}
```

Given these definitions, we can define Vectors like this:

Click here to view code image

```
Vector<char> vc(200); // vector of 200 characters
Vector<string> vs(17); // vector of 17 strings
Vector<list<int>> vl(45); // vector of 45 lists of integers
```
