:elem(new double[s]), sz(s)

That is, we initialize elem to s elements of type double obtained from the free store. Then, we initialize sz to s.
Access to elements is provided by a subscript function, called operator[]. It returns a reference to the appropriate element (a double& allowing both reading and writing).
The size(i) function is supplied to give users the number of elements.
Obviously, error handling is missing, but we'll return to that in Chapter 4. Similarly, we did not provide a mechanism to "give back" to the doubles acquired by new; §5.2.2 shows how to destroy a struct to effectively do that.

There is no fundamental difference between a struct and a class; a struct is simply a class with members public. For example, we can define constructors and other member functions for a struct.

# 2. Enumerations

In addition to classes, C++ supports a simple form of user-defined type for which we can enumerate the values:

```
enum Color { red, blue, green };
enum class Traffic { green, yellow, red };
```

```
Color col = Color::red;
Traffic_light = Traffic::light;
```

Note that enumerators, red, are in the scope of their enum class, so that they can be repeated in enum classes without confusion. For example, Color::red is Color's red which is different from Traffic::red.
Enumerations are used to represent small set of integer values. They are used to make code more readable and less error-prone than it would have had the symbolic (and mnemonic) enumerator names not.

The class specifies that an enumeration is strongly typed and that its enumerators are scoped. By separating types, enum classes help prevent accidental mixes of constants. In particular, we cannot mix Traffic_light and Color values.
