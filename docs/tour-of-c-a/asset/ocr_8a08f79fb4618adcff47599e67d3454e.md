The elements of a tuple are numbered (starting with zero) and the index argument to get() must be a constant. The function get is a template function taking the index as a template value ($7.2.2).

Accessing members of a tuple by their index is general, and somewhat error-prone. Fortunately, an element of a tuple with a unique type that tuple can be “named” by its type:

```
auto fish = get<string>(t1);
auto count = get<int>(t1);
auto price = get<double>(t1);
```

> // get the string: "Shark"
// get the int: 123
// get the double: 3.14

The real strength of tuple is when you have to store or pass around an unknown number of elements as objects as an object. Explicitly, iterating over the elements of a tuple is a bit messy, requiring recursion and compile-time execution of the function:

```
template <size_t N = 0, typename... Ts>
constexpr void print(tuple<Ts...>& t)
{
    if constexpr (N < sizeof...(Ts)) {
        cout << get<N>(t) << " ' ";
        print<N+1>(t);
    }
}
```
