When writing templates, we need to classify types.

| Object concepts <concepts> |
| --- | --- |
| destructible<T> | A T can be destroyed and its address taken with unary & |
| constructible_from<T,Args> | A T can be constructed from an argument list of type Args |
| default_initializable<T> | A T can be default constructed |
| move_constructible<T> | A T can be move constructed |
| copy_constructible<T> | A T can be copy copied and move constructed |
| movable<T> | move_constructible<T>, assignable<T&>, and swapable<T> |
| copyable<T> | copy_constructible<T>, movable<T>, and assignable<T, const T&> |
| semiregular<T> | copyable<T> and default_constructible<T> |
| regular<T> | semiregular<T> and equality_comparable<T> |

The ideal for types is regular. A regular type works roughly like an int and simplifies much of our thinking about how to use a type. The lack of default == for classes that most classes start out as semiregular though most could and should be regular.

Whenever we perform an operation as a constrained template template, we need to specify how it can be called, and what else assumptions we make of its semantics.

| Callable concepts <concepts> |
| --- | --- |
| invocable<F,Args> | An F can be invoked with an argument list of type Args |
| regular_invocable<F,Args> | invocable<F,Args> and is equality preserving |
| predicate<F,T> | A regular_invocable<F,Args> returning a bool |
| relation<F,T,U> | A relation<F,T,U> that provides an equivalence relation |
| strict_weak_order<F,T,U> | A relation<F,T,U> that provides strict weak ordering |

A function(f) is equality preserving if x==y implies that f(x)==f(y). An Invocable and a regular_invocable differ only semantically. We can't (currently) only express our intent.

Similarly, a relation and an equivalence_relation differ only semantically. An equivalence relation is reflexive, symmetric, and transitive.

A relation and a strict_weak_order differ only semantically. Strict weak ordering is what the standard library assumes for comparisons, such as <.
