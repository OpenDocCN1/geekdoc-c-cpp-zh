# 10.4.1 Searching

The simplest way of using a pattern is to search for it in a stream:

```
int lineno = 0;
for (string line; getline(cin,line); {
    ++lineno;
    smatch matches;
    if (regex_search(line,matches,pat))
        cout << ":" << matches[0] << "\n";
}
```

The regex_search(line,matches,pat) uses the line for matches that the regex expression stored in pat and if it finds any, it stores in matches. If no match was found, regex_search(line,matches,pat) returns false. The matches are of type match. The "s" stands for "sub" or "string," and an match is a vector of submatches of type string. The first element, matches[0], is the complete match. The result of regex_search() is a collection of matches,

This function reads a file looking for U.S. postal codes, such as TX77845 and DC 20500-0001. An match type is a container of regex results. matches[0] is the whole pattern and matches[1] is the optional-digit subpattern (\d(4)).

The newline character, \ln, can be part of a pattern, so we can search for multiline patterns. Obviously, we shouldn't read one line at a time if we want to.

The regular expression syntax and semantics are designed so regular expressions can be compiled into state machines for efficient execution [Cox,2007]. The regex performs this compilation at run time.
