floating-point-number, such as 12.34e5, into the double-precision floating-point variable d.

Like output operations, input operations can be chained, so I could equivalently have written:

Click here to view code image

```
int i;
double d;
cin >> i >> d; // Read into i and d
```

In both cases, the read of the integer is terminated by any character that is not a digit. By default, it skips whitespace, so a suitable complete input sequence would be

```
1234
12.34e5
```

Often, we want to read a sequence of characters. A convenient way of doing that is to read into a
string. For example:

Click here to view code image

```
cout << "Please enter your name";
string str;
cin >> str;
cout << "Hello, " << str << "\ln";
```

If you type Eric in your response:

Hello, Eric!

By default, a whitespace character, such as a space or a newline, terminates the read, so if you enter Eric Bloodaxeed to be the ill-fated king of York, the response is still:

Hello, Eric!

You can read a line using the getline() function. For example:

Click here to view code image

```
cout << "Please enter your name";
string str;
getline(cin,str);
cout << "Hello, " << str << "\ln";
```

With this program, input Eric Bloodaxe yields the desired output:

Hello, Eric Bloodaxe!

The newline that terminated the line is discarded, so cin is ready for the next input line.

Using the formatted I/O operations is usually less error-prone, more efficient, and less code manipulating characters by one. In particular, stringstreams take care of memory management and range checking. We can do formatting to and from memory using stringstreams (§11.7.3) or memory streams

The standard strings have the nice property of expanding to fit what you put in them; you don't have to pre-calculate a maximum size. So, if you enter a couple of megabytes of semicolons, hello_line() will echo pages of semicolons back at you.
