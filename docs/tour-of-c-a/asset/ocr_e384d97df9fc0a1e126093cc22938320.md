# 6.5.1 Comparisons (Relational Operators)

The meaning of the equality comparisons (== and !=) is closely related to copying. After a copy,
the copies should compare equal:

Click here to view code image

```
X a = something;
X b = a;
assert(a=b); // If a1=b here, something is very odd ($4.5)
```

When defining ==, also define != and make sure that a!=b means !(a==b).

Similarly, if you define <, also define <=, >, >= to make sure that usual equivalences hold:

+   - a<b means (a<b)||(a==b) and !(b<a).
- a>b means b<a.
- a<=b means (a<=b)||(a==b) and !(b<a).

Go identical to treat operands of a binary operator, such as ==, it is best defined as
a free-standing function in the namespace of class. For example:

Click here to view code image

```
namespace NX {
class X {
// ...
};
bool operator===(const X, const X&);
// ...
};
```

The "spaceship operator," <> is a law unto itself, its rules differ from those for all other
operators. In particular, by defining the default <> the other relational operators are implicitly
defined:

Click here to view code image

```
class R {
// ...
auto operator<=>(const R& a) const = default;
};
void user(R r1, R r2) {
bool b1 = (r1<=r2) == 0; // r1==r2
bool b2 = (r1<=r2) < 0; // r1<r2
bool b3 = (r1<=r2) > 0; // r1>r2

bool b4 = (r1==r2);
bool b5 = (r1<r2);
}
```

Like C's strcmp(), <> implements a three-way comparison. A return value means less-
an, zero equal, and a positive value means greater-than.
