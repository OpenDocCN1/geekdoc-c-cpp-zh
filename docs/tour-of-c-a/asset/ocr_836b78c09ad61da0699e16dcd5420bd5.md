C++ provides a conventional set of statements for expressing selection and looping, such as if-statements, switch-statements, while-loops, and for-loops. For example, here is a simple function that prompts the user and returns a Boolean indicating the response:

Click here to view code image

```
bool accept(int)
{
    cout << "Do you want to proceed (y or n)?\";
    char answer = 0;
    cin >> answer;

    if (answer == 'y')
        return true;
    return false;
}
```

To match the << operator ("put to"), the >> operator ("get from") is used for input; use cin in the standard input (Chapter 11). The type of the right-hand operand of >> determines what input is accepted, and its right-hand is the target of the input operation. The \n character at the end of the output string represents a newline (§1.2.1).

The definition of answer appears where it is needed (and not before). A declaration can appear anywhere a statement.
The example could be improved by taking an n (for "no") answer into:

```
bool accept(int)
{
    cout << "Do you want to proceed (y or n)?\";
    char answer = 0;
    cin >> answer;

    switch (answer) {
        case 'y':
            return true;
        case 'n':
            return false;
        default:
            cout << "I'll take that for a.ln\";
            return false;
    }
}
```

A switch-statement tests a value against a set of constants. These constants, called case-labels, must be distinct, and if the value does not match any of them, the default is chosen. If the value doesn't match any case-label and no default is, no action is taken.
We don't have to avoid case by returning from the function that contains its switch-statement. Often, we just want to continue execution with the statement following the switch-statement.
