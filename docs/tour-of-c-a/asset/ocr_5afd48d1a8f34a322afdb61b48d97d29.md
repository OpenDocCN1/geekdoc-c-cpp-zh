The floating-formats are the same as ostream: e for scientific, a for hexfloat, f for fixed, and g for default. For example:

```
cout << format("{0:e}; {0:a}; {0:f}; {0:g}
", 123456); // default, scientific, hexfloat, fixed, default
```

The result was identical to ostream except that the hexadecimal number was not preceded by 0x:

```
123456; 1.2345600e+002; 1.2dd2f2p+6; 123456000; 123456
```

A dot precedes a precision specifier:

```
cout << format("{{0:8} {} {0n}", 1234.56789, 1234.56789, 123456);
cout << format("{{0:precision(4):-4f}", 1234.56789, 1234.56789, 123456);
cout << format("{{0:0n}", 1234.56789);
```

Unlike ostream, formatters are not "sticky": so you can

As with stream formatters, you can also specify the size of the field where a number is to be placed and its alignment in that field.

Like stream formatters, format can also handle time and dates (§ 16.2.2) for example:

Click here to view code image

```
cout << format("{{0:birthday}}", "November/28/2021");
cout << format("{{0:Zp}}", zoned_time(current_time), system_clock::now());
```

The default formatting of values is identical to that of stream formatting. However, format provides a mini-language of about 60 format specifiers allowing very detailed control over formatting of numbers and dates. For example:

Click here to view code image

```
auto ymd = 2021/March/30;
cout << format("{{0:ymd}}: {0:%A}, {0:%B} {0:%d}, {0:%Y}", ymd.month(), ymd.day(), ymd.year()); //
```

This produced:

ymd: Tuesday, March 30, 2021

All time and date format strings start with %.
