# 11.3 Input

In <iostream>, the standard library offers istream for input. ostreams deal with character representations of built-in types and can easily be extended to use user-defined types.

The operator >> "get" is used as an input operator; cin is the standard stream. The type of the right-hand operand of >> determines what input is accepted and what is the target of the input operation. For example:

Click here to view code image

```
int i;
cin >> i;          // Read an integer into i

double d;
cin >> d;          // Read a double-precision floating-point number into d
```
