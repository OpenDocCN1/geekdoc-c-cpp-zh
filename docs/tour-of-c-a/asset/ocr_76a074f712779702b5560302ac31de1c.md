# # 11.9 File System

Most systems have a notion of a file system providing access to permanent information stored as files. Unfortunately, the properties of file systems and the ways of manipulating them vary greatly. To deal with that, the file library in <filesystem> offers a uniform interface to most facilities of file systems. Using <filesystem>, we can partially

+   - express file system paths and navigate through a file system
- examine file types and the permissions associated with this book.

The filesystem library can handle unicode, but explaining how beyond the scope of this book. I recommend using the cppreference [Cppreference] and the Boost filesystem documentation [Boost] for detailed information.
