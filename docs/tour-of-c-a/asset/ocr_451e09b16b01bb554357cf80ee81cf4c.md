# 2.5 Unions

A union struct in which all members are allocated at the same address so that the union occupies only as much space as its largest member. Naturally, a union can hold a value for only one member at a time. For example, consider a symbol table that holds a name and a value. The value can be either a Node or an int:

Click here to view code image

```
enum class Type { ptr, num }; // Il a Type can hold values ptr and num ($2.4)

struct Entry {
  string name; // Il is a standard-library type
  Type t;
  Node* p; // Il use p if t==Type::ptr
  int i; // Il use i if t==Type::num
};

void f(Entry* pe) {
  if (pe->t == Type::num)
    cout << pe->i;
  // ...
};
```

The members p and i are never at the same time, so space is wasted. It can be easily recovered by specifying that both should be members of a union, like this:

```
union Value {
  Node* p;
  int i;
};
```

Now Value::p and Value::i are placed at the same address of memory of each Value object. This kind of space optimization can be important for applications that hold large amounts of memory so that compact representation is critical. The language doesn't keep track of which kind of value is held by a union, so the programmer must do that:

Click here to view code image

```
struct Entry {
  string name;
  Type t;
  Value v; // Il use v.p if t==Type::ptr; use v.i if t==Type::num
};

void f(Entry* pe) {
  if (pe->t == Type::num)
    cout << pe->v.i;
  // ...
};
```
