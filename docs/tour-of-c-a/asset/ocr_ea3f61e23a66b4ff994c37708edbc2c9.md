# Any hexadecimal digit character

In a regular expression, a character class name must be bracketed by [: :]. For example, [:digit:] matches a decimal digit. Furthermore, they must be used with a [] defining a character class.

Several character classes are supported by shorthand notation:

In addition, languages supporting regular expressions often provide:

| | Nonstandard (but Common) Character Class Abbreviations |
|---|---|
| u | A lowercase character | [[:lower:]]
| u | An uppercase character | [[:upper:]]
| l | Not u | ^[:lower:]]
| U | Not u | ^[:upper:]]

For full portability, use the character class names rather than these abbreviations.
As an example, consider writing a pattern that defines C++ identifiers: an underscore or a letter followed by a sequence of letters, digits, or underscores. To illustrate the subtleties involved, I include a false attempt:

```
[alpha:][]* // wrong: characters from the set ":alpha" followed by ...n[[:alpha:]][:alnum:]]* // wrong: doesn't accept underscore (_ is not alpha)
[[:alpha:]][:alnum:]]* // wrong: underscore is not part of alphanum ether

[[:alpha:]]* // OK, but clumsy
[[:alpha:][[:alnum:]]* // OK: include the underscore in the character classes
[[:alpha:]][:alnum:]]*
[[:alpha:]]w* // w is equivalent to [[:alnum:]]
```
