## 13.2 Use of Iterators

For a container, a few iterators referring to can be obtained; begin() and end() are the best. In addition, many algorithms return iterators. For example, the standard algorithm find looks for a value in a sequence and returns an iterator to the element found:


Like standard algorithms, find returns to indicate “not found.” An equivalent, short, definition of has_c is:

Click here to view code image

```cpp
bool has_c(const string& s, char c)
{
  return find(s,c)==s.end();
}
```

A more interesting exercise would be to find the location of all occurrences of a character in a string. We can return the set of occurrences using a vector<char>. Returning a vector is efficient because vector provides semantics (§6.2.1). Assuming that we would like to modify the locations, we pass a non-const string:

Click here to view code image

```cpp
vector<char> find_all(string& s, char c) // find all occurrences of c in s
{
  vector<char> res;
  for (auto p=s.begin(); p!=s.end(); ++p)
    if (*p=='c')
      res.push_back(*p);
  return res;
}
```

We iterate through the string using a conventional loop, moving the iterator p forward one element at a time using ++ and looking at the elements using the dereference operator *. We could test find_all() like this:
