+   - push_back(): Add a new element at the end of (at the back of) the sequence.
These can be declared like this:

Click here to view code image

```
class Vector {
public:
  Vector();                          // default initialize to "empty", that is, no elements
  Vector(std::initializer_list<double> l); // initialize with a list of doubles
  void push_back(double d);          // add element at end, increasing the size by one
  // ...
};
```

The push_back() is useful for input of arbitrary numbers of elements. For example:

Click here to view code image

```
Vector read(istream& is) {
  Vector v;
  for (double d = 0; is >> d; { // read floating-point values into d
    v.push_back(d);               // add d to v
  }
  return v;
}
```

The input loop is terminated by an end-of-file or a formatting unit. Until, happens, each number is added to the end, v's size is the number of elements read. We use a for-statement rather than the more conventional while-statement to limit the scope of d to the loop.

Returning potentially huge amount of data from read could be expensive. The way to guarantee that returning a Vector is cheap to do it with a constructor ($6.2.2):

Click here to view code image

```
Vector v = read(cin); // no copy of Vector elements here
```

The way that std::vector is efficient to make push_back() and other operations that change the vector's size is presented in $12.2.

The std::initializer_list used to define the initializer-list is a standard-library type known to the compiler: when we use a {1,2,3,4}, the compiler will create an object of type initializer_list to give to the program. We can write:

Click here to view code image

```
Vector v = {1, 2, 3, 4, 5};          // v has 5 elements
Vector v2 = {1, 2.3, 3.45, 6.7, 8};      // v2 has 4 elements (truncated)
```

Vector's initializer-list constructor must be defined like this:

Click here to view code image

```
Vector::Vector(std::initializer_list<double> l) // initialize with a list
  :elem(new double[l.size()]), sz(static_cast<int>(l.size())) {
    copy(l.begin(), l.end(), elem); // copy from list into elem ($13.5)
}
```
