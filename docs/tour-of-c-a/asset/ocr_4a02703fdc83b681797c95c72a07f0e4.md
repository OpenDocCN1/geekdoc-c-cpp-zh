The generator return value is what the coroutine stores it between calls. We could, of course, make a function object Fib that worked the same, but then we would have had to maintain its states order. For larger sizes and more complex continuations, saving and restoring state tedious, hard to optimize, and error-prone. In effect, a coroutine is a function that saves its stackframe between calls. The co_yield returns a value and waits for the next. The co_return returns a value and terminates the coroutine.
