The standard library provides a default hash function for strings as well as for other built-in and standard-library types. If necessary, we can provide our own. Possibly, the most common need for a custom hash function comes when we want an unordered container of one of our types. A hash function is often implemented as a function object (§7.3.2). For example:

Click here to view code image

```
struct Record {
    string name;
    int product_code;
    // ...
};

struct Hash {
    // A hash function for Record
    size_t operator()(const Record& r) const {
        return hash<string>(r.name) ^ hash<int>()(r.product_code);
    }
}
```

unordered_set<Record,Hash> my_set; // Il of Records using Hash for lookup

Designing good hash function is an art and requires knowledge of the data to which it is built. Creating a new hash function by combining existing hash functions with exclusive-or (^) is simple and very effective. However, be careful to ensure that every value takes part in the hash to distinguish the values. For example, unless you have several names for the same product code (or several product codes for the same name), combining the two hashes provides no benefits.

We can avoid explicitly mentioning the hash operation by defining it as a specialization of the standard-library hash:

Click here to view code image

```
namespace std {
    // Make a hash function for Record
    template<> struct hash<Record> {
        using argument_type = Record;
        using result_type = size_t;

        result_type operator()(const Record& r) const {
            return hash<string>(r.name) ^ hash<int>()(r.product_code);
        }
    };
};
```
