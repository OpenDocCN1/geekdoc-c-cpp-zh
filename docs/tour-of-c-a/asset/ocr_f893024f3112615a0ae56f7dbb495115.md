# 19.1.2 Early Years

I originally designed and implemented the language because I wanted to distribute the services of a UNIX kernel across multiprocessors and local-area networks (which are now known as multicores and clusters). For that, I needed to precisely specify parts of the system and how they were considered. Simula [Dahl,1970] would have been ideal for that, except for performance considerations. I also needed to deal with hardware and high-performance concurrent programming methods for which C would have been ideal, except for its support for modularity and type checking. The result of adding Simula-style classes to C (§19.3.1). “C with Classes,” was used for major projects in which its features for writing programs that use minimum time and space were severely tested. It lacked operator overloading, references, virtual functions, exceptions, and many details [Stroustrup,1982]. The first use of C++ outside a research organization started in July 1983.

The name C++ (pronounced “see plus”) was created by Rick Massey in the summer of 1983 and chosen as the replacement for “C with Classes” by me. The name signifies the evolutionary nature of the changes from C; “++” is the increment order.
