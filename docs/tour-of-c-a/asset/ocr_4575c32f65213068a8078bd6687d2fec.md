Zero or more, that is, {0}
One or more, that is, {1}
Optional (zero or one), that is (0,1)

For example:

```
A(3)B(2,4)C\*
```

A suffix after any repetition of the notations (?, *, +, and {}) makes the pattern matcher "lazy" or "non-greedy". When that, looking for a pattern, it will look for the shortest match rather the longest. By default, the pattern matcher always looks for the longest match; this is known as the Max match rule. Consider:

```
abab
```

The pattern (ab)+ matches all of ababab. However, (ab)* matches only the first ab.
