Typically, a program produces some output. Here is a program that writes Hello, World!

```
import std;

int main()

  std::cout << "Hello, World!";
}
```

The import std; instructs the compiler to make the declarations of the standard library available. Without these declarations, the expression

Click here to view code image

std::cout << "Hello, World!"
make no sense. The operator ("put") writes its second argument onto its first. In this case, the string literal "Hello, World" is written onto the standard output std::cout. A string is a sequence of characters followed by double quotes. In a string, the backslash character followed by another character denotes a "special character.\ In this case, \n is the newline character, so that characters are written Hello, World! followed by a newline.
The std:: specifies that the name cout is to be found in the standard-library namespace (§3.3). I usually leave out std:: when discussing standard features; §3.3 shows how to make names from a namespace without explicit qualification.
