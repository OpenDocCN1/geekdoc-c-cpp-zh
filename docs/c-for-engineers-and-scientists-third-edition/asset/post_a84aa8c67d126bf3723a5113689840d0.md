
## Chapter 10

As a specific example of a class, take a look at the following definition of a class named Date. This type of class is important in applications where equipment delivery dates and schedules depend on exact dates. To accomplish this task, a number of functions for determining whether a date falls on a weekend or holiday, for example, will still have to be added to this class.

```cpp
// class declaration section
class Date {
private:
    // notice the colon after the word private
    int month;
    // a data member
    int day;
    // a data member
    int year;
    // a data member
public:
    // again, notice the colon here // a member function
    Date(int month = 7, int day = 4, int year = 2005); // the constructor
    void setState(int, int, int); // a member function
    void showDate(); // a member function
}; // this is a declaration - don't forget the semicolon
// class implementation section
Date::Date(int mm, int dd, int yyyy) {
    month = mm;
    day = dd;
    year = yyyy;
}
void Date::setState(int mm, int dd, int yyyy) {
    month = mm; day = dd; year = yyyy;
    return;
}
void Date::showDate() {
    cout << "The date is ";
    cout << setfill('0')
    cout << setw(2) << month << "/";
    cout << setw(2) << day << "/";
    cout << setw(2) << year % 100; // extract the last 2 digits
    return;
}
```

Because this definition might look overwhelming, first notice that it does consist of two sections—a declaration section and an implementation section. The declaration section begins with the keyword class followed by a class name. Following the class name are the class's variable declarations and function prototypes, enclosed in a brace pair terminated with a semicolon. The general structure of this form is as follows:

```cpp
class Name
{
  private:
  a list of variable declarations
  public:
  a list of function prototypes
};
```

Notice that the Date class follows this format. For convenience, it's listed again with no internal comments:

```cpp
// class declaration section
class Date
{
  private:
  int month;
  int day;
  int year;
  public:
  Date(int = 7, int = 4, int = 2005);
  void setState(int, int, int);
  void showDate();
};
```

The name of class is Date. Although the initial uppercase letter isn't required, it's used by convention to designate a class. The body of the declaration section, enclosed in braces, consists of variable and function declarations. In this case, the data members month, day, and year are declared as integers, and setState() and showDate() are declared as prototypes. The private and public access specifiers define which of them—in this case, month, day, and year—can be accessed only by the class functions (or friend functions), as discussed in 10.2. The private designation is meant to ensure data security by requiring access to all private members through the private methods. This type of access restricts a user from seeing how data is actually stored, and is referred to as encapsulation.

In Date class, data is stored using three integers for the month, day, and year. The year is also stored as a four-digit integer. For example, the year 1998 is stored as 1998, not 98. Making sure of all years with their century designation eliminates a multitude of problems that can crop up if only the last two digits are stored. For example, the number between 2006 and 1999 can be calculated as 2006 - 1999 = 7 years, getting the same answer as it is with the year values 06 and 99. Additionally, if for example the year 2006 refers to a two-digit value, such as 06, could either refer to 1906 or 2006.

Following the private class members, the function prototypes in the Date class have been declared as public. This means these functions can be called by any objects and functions not in the class (from the class, other words). In general, all class functions should be public so that they provide capabilities to manipulate class variables outside the class.

- *Other forms are possible. However, this form is commonly used and easy to understand, as it serves as the standard model in this book.*
- *Note that the default membership category in a class is private, which means this can be omitted. In this book, the private designation is used to reinforce the idea of access restrictions in class memberships.*

The Date class provides three functions named Date(), setState(), and showDate(). Notice that one of these functions has the same name, as the class name. This function is referred to as a constructor function, and it has a special purpose: It can be used to initialize class members with values. The default values used for this function are the numbers 7, 4, and 2001, which you can see are the default month, day, and year values. Note that the default value is represented as a four-digit integer for the year designation. Note that the constructor function has no return type, which is a requirement for this special function. The two remaining functions declared in the Date class, setState() and showDate(), have been declared as returning no value (void). (It's in the implementation section that these three member functions are written to permit the initialization, assignment, and display capabilities of their names.)

The implementation section is where the member functions defined in the declaration section are written. This example shows the general form of functions written in the implementation section. This format is correct for all functions except the constructor, which, as stated previously, has no return type:

```cpp
returnType className::functionName(parameter list)
    function body
}
```

As this example, member functions defined in the implementation section have the same format as all user-written C++ functions, with the addition of the class name and scope resolution operator; that identifies the function as a member of a particular class. You can also define these functions in the declaration section by declaring and writing them as inline functions. Section 10.2 includes examples of member functions.

Notice that the first function in this implementation section has the same name as the class, which makes it a constructor function. Therefore, it has no return type. The Date:: at the beginning of the function header identifies this function as a member of the Date class. The rest of the function header

```cpp
Date(int mm, int dd, int yyyy)
```

defines the function as three integer parameters. The body of this function simply assigns the data members month, day, and year with the values of the parameters mm, dd, and yyyy.

The next function header

```cpp
void Date::setState(int mm, int dd, int yyyy)
```

defines setState() as belonging to the Date class (Date::). This function returns no value (void) and expects three integer parameters: mm, dd, and yyyy. In a manner similar to the Date(), the body of this function assigns the data members month, day, and year with the values of the parameters.

Last the function header in the implementation section

```cpp
void Date::showDate()
```

defines a function named showDate(). This function has no parameters, returns no value, and is a member of the Date class. The body of this function, however, needs a little more explanation.

All years have been stored as four-digit values to retain century information, users are accustomed to seeing dates with the year as a value, such as 59. To display the last two digits of the year, the expression % 100 can be used. If the year is 1999, the expression 1999 % 100 yields the value 99, and if the year is 2006, the expression 2006 % 100 yields the value 6.

If you had used the year as a two-digit value, such as 09, you would be altering the stored value of the year to correspond to the last two digits. Because you want to retain the year as a four-digit number, you must carefully manipulate only the displayed value using the expression year % 100 in the count statement. The setfill and setw manipulators are used to make sure the displayed values correspond conventionally accepted. For the date March 9, 2006, should appear as 3/9/06 or 030906. The setw manipulator forces each value to be displayed in a field of 2. This manipulator remains active only for the next insertion, it's before the date value. The setfill remains until the full character is changed, it must be included only once. The setfill manipulator has been used to change the fill character from a blank space to the character 0. This ensures that a date such as December 9, 2006 appears as 12/09/06, not as 12/9.
