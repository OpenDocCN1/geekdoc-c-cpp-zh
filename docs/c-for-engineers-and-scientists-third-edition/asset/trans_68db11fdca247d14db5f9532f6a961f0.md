## 336页 模块化函数

```
void polar(double x, double y, double& r, double& theta)
{
    const double DEGREE = 180.0/3.141593;

    r = sqrt(x * x + y * y);
    theta = atan(y/x) * DEGREE;

    return;
}
```

`polar()` 函数非常直观。函数头声明该函数没有返回值，且它的每个参数都声明为浮点类型。前两个参数用于接收 x 和 y 值，后两个参数是引用参数，用于将转换后的距离和角度传回调用函数。在函数体内，定义了一个常量 `DEGREE` 为 `180.0/3.141593`。接两个赋值语句使用参数 x 和 y 为 r 和 theta 参数赋值。`DEGREE` 常数用于将 `atan()` 函数返回的弧度值转换为度。按照写法，`polar()` 函数可以编译以检查任何编译时错误。为了理解返回值是如何传递的，将引用 `r` 和 `theta` 视为容器（变量），值可以通过它们双向传递。这种情况在图 6.13 中所示，该图说明了引用参数的基本特征：它们仅仅让函数和调用函数能够通过不同的名称访问同一个存储区域。如图 6.13 所示，调用函数可以使用参数名访问在 `polar()` 中赋值给 `r` 和 `theta` 的值 ![](img/e2a849fc7bc04aa2e6669ad865e0c22b_355_0.png)。

## 第6章 337页 案例研究：直角坐标到极坐标转换

### 程序 6.11

```cpp
#include <iostream>
#include <cmath>
using namespace std;

void polar(double, double, double&); //函数原型

int main()
{
    double distance, angle;
    polar(3.0, 4.0, distance, angle);

    cout << "r = " << distance << endl;
    cout << "angle = " << angle << endl;

    return 0;
}

void polar(double x, double y, double& r, double& theta)
{
    const double DEGREE = 180.0/3.141593;

    r = sqrt(x * x + y * y);
    theta = atan(y/x) * DEGREE;

    return;
}
```

注意在 `main()` 中，字面量 3.0 和 4.0 被传递给 `polar()`。该函数接受这些输入作为 x 和 y，并使用这些参数来计算参数 `r` 和 `theta` 的值。在 `main()` 中，最后两个参数被称为 `distance` 和 `angle`，它们的值在调用 `polar()` 之后立即显示。这是程序 6.11 运行时产生的输出：

r = 5
angle = 53.1301

这些结果与你手工计算得到的结果相同。由于函数只执行了两次计算，且测试程序显示的结果与手工计算一致，因此该函数已经过完全测试。剩下的工作是为完整程序所需的另外两个函数分组，以确保每个函数之间交换了正确的参数值。
