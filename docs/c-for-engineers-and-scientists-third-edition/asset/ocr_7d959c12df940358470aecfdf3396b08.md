+   3. (Physics) Typically, most objects that radiate heat do at many different wavelengths (see the Technical Note in Section 3.5 for a description of wavelength). The wavelength at which an object emits its maximum heat energy can be found by using Wein's Law:

$W$ is Wein's constant (2897 microns/$K$).
