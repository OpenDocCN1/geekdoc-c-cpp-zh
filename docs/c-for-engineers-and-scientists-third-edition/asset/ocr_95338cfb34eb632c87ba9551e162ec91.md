C++ provides the decrement operator, --, in prefix and postfix variations. As you might expect, both the expressions variable-- and --variable are equivalent to the expression variable = variable - 1. Here are examples of the decrement operator:

| Expression | Alternative |
| --- | --- |
| i = i - 1 | i-- --i |
| n = n - 1 | n-- --n |
| count = count - 1 | count-- --count |

When the -- operator operates before a variable, it's called a prefix decrement operator. When this operator appears after a variable, the expressions n-- and -- reduce the value of n by one and are equivalent to the longer expression n = n - 1.

As with increment operators, however, the prefix and postfix decrement operators produce different results when used in assignment expressions. For example, the expression k = --n decrements the value of n by one before assigning the value of n to k, and the expression k = n-- first assigns the current value of n to k, and then reduces the value of n by one.
