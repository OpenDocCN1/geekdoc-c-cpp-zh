# 9.3 The String Class

The programs in this book have used the istream class object extensively, but you have not investigated this class in detail or learned how the object is constructed. However, an advantage of object-oriented design is that you can use thoroughly classes without knowing how the class is constructed. You use any class defined by C++s standard library: the string class. You're going to create objects from the class before using them instead of an existing object, such as cout.

A class is a user-created data type. Like built-in data types, a class defines a valid set of data values and a set of operations that can be performed on them. The difference between a user-created data type as an integral part of the compiler, and a class is constructed by a programmer using C++ code is. Other than that and the terminology, the two data types are used in much the same manner. The difference lies in storage that for built-in data types are referred to as variables, whereas storage areas for a class are referred to as objects.

The values class permits are referred to string literals. A string literal is also referred to as a string value, a constant, and more conventionally, a string.
