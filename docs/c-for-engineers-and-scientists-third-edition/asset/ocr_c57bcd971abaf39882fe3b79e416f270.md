# Program 2.10

```
#include <iostream>
using namespace std;

int main()
{
    int num;

    num = 22;
    cout << "The value stored in num is " << num << endl;
    cout << "The address of num = " << &num << endl;

    return 0;
}
```

This is the output of Program 2.10:

The value stored in num is 22
The address of num = 0012FED4

Figure 2.13 illustrates the additional address information provided by Program 2.10's output. The address output by Program 2.10 depends on the computer used to run the program. Every time Program 2.10 runs, however, it displays the address of the first memory location used to store num. As Program 2.10's output shows, the address display is in hexadecimal notation. This display has no effect on how the program uses addresses internally; however a means of displaying addresses is helpful in understanding them. As you'll see in Chapters 6 and 12, using addresses, instead of just displaying them, is an important and powerful programming tool.
