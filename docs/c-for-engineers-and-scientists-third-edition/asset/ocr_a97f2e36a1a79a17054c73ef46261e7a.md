# Internal Array Element Location Algorithm⁵

Internally, each element in an array is obtained by adding an offset to the starting address of the array. Therefore, the memory address of each array element is calculated internally as

Address of element i = starting array address + offset

For one-dimensional arrays, the offset to the element with index i is calculated as

Offset = i * the size of an element

For two-dimensional arrays, the same address calculation is made, except that the offset is determined as

Offset = column index value * the size of an element
row index value * number of bytes in a complete row

where the number of bytes in a complete row is calculated as follows:

number of bytes in a complete row =
maximum column width specification * the size of an element
