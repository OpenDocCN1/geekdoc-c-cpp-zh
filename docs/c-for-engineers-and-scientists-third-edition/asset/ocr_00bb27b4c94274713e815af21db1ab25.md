# 396 Arrays

Notice that the function prototype for findMax() declares that findMax returns an integer and expects an array of five integers as an actual argument. It's also important to know that only one array is created in Program 7.6. In main(), this array is known as nums, and in findMax(), the array is known as vals. As illustrated in Figure 7.8, both names refer to the same array, so vals[3] is the same element as nums[3].

```
int main()
{
    int nums[5];
    .
    findMax(nums);
    return 0;
}
int findMax(int vals[5])
{
    // These reference the same array
}

```

The parameter declaration in the findMax() header actually contains extra information not required by the function. All that findMax() must know is the parameter vals references an array of integers. Because the array has been created in main() and no additional space is needed in findMax(), the declaration for vals can omit the array size. Therefore, the following is an alternative header:

```
int findMax(int vals[])
```

This form of header makes more sense when you realize that only one item is actually passed to findMax() when the function is called: the starting address of the num array, as shown in Figure 7.9.
