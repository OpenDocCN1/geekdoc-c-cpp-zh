As this program is rather simple and each task described by the algorithm is well defined, you can begin coding each task. To show that any task can be coded independently of any other task, you start by coding the function that calculates polar coordinates, or you could start with any function. As an added feature, this function will return the angle θ in degrees rather than the radian measure the atan(y) function returns. Because this function must receive two inputs, the x and y coordinates, and return two outputs, the r and θ coordinates, provide four parameters: two for the inputs and two for the outputs.
