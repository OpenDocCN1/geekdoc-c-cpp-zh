# 5. (Numerical) Many algorithms have been developed for generating pseudorandom numbers. Some use a counting scheme, such as counting beginning at an arbitrary location in a changing memory. Another scheme, which creates pseudorandom numbers by performing a calculation, the method begins with an power reduce method.

The power reduce method begins with an odd $n$-digit integer, referred to as the "seed" number. The seed (the "residue") produces a result (the value $(10^n-3)$). Using the lowest $n$ digits of the result this procedure produces a series of random numbers, with each new number used as the seed for the next number. If the original seed has four or more digits (equal to or greater than 4) and is not divisible by 2 or 5, this procedure yields $5 	imes 10^n$ random numbers before a sequence of numbers repeats itself. For example, starting with a six-digit seed ($n = 6$), such as 654321, a series of $5 	imes 10^4 = 50,000$ random numbers can be generated.

As an algorithm, the steps in generating pseudorandom numbers with a power reduce method consists of the following:

+   * Step 1: Have user enter a six-digit seed that means the number should be an odd number not divisible by 2 or 5—this ends in 5.
* Step 2: Multiply the seed number by 997, which is $10^3-3$.
* Step 3: Extract the lowest six digits of the result produced by Step 2. Use this random number as the next seed.
* Step 4: Repeat Steps 2 and 3 for many random numbers as needed.
