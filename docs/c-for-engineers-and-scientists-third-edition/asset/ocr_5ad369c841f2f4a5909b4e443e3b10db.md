A second line of defense is to use error-processing code in the context of exception handling. This type of code is used to permit the user to correct a problem, such as invalid data entry, by entering a new value. The means of providing this code in C++ is referred to as exception handling.

Using exception handling, you can construct a complete means of ensuring that the user enters an integer instead of an invalid value. The technique involves extending invalidInt() function in Program 9.18 to ensure that not only is an invalid integer value detected, but also the program gives the user the option of reentering values until a valid double-precision number, which is the numerical data type requested-entered data.

Using the invalidInt() from Program 9.18, a more comprehensive function named getInt() is developed that uses exception processing to accept user input continuously until a string corresponding to an integer is detected. After a string is entered, the getInt() function converts the string to an integer and returns the integer value. This technique ensures that the program requesting an integer actually receives an integer and prevents any unwarranted side effects, such as a program crash caused by an invalid data type being entered. The algorithm used to perform this task is as follows:

Set a Boolean variable named notantint to true (while notantint is true)

```
try
  Accept a string value
  If the string value does not correspond to an integer, throw an exception
catch the exception
  Display the error message "Invalid integer - Please reenter:"
  Send control back to the while statement
  Set notantint to false (causes the loop to terminate)
end while
```

Return the integer corresponding to the entered string
