In reviewing Program 6.5, note the items introduced in this section. Second, an assignment is used in main() to store the returned value from the findMax() call in the variable max. In Program 6.5, max is correctly declared as an integer in main()'s variables so that it matches the returned value's data type.

# Inline Functions¹¹

Calling a function places a certain amount of overhead on a computer. This overhead consists of the following steps:

- 1. Placing values in a reserved memory region (the stack) that the function has access to
- 2. Passing control to the function
- 3. Providing a reserved memory location for any returned value (again, using the stack for this purpose)
- 4. Returning to the correct point in the calling program

Paying this overhead is justified when a function is called many times because it can reduce a program's size substantially. Instead of the same code whenever each time it's needed, the code is written once, and called whenever it's needed.
For small functions that aren't called many times, however, the overhead of passing and returning values might not be worth it. By grouping lines of code under a common function name and having the compiler place this code in the program when the function is called, **inline functions** provide this capability.

```cpp
#include <iostream>
using namespace std;

inline double tempvert(double inTemp) // an inline function
{
    return (5.0/9.0) * (inTemp - 32.0);
}

int main() {
    const int CONVERTS = 4; // number of conversions to be made
    int count;
    double fahr;

    for(count = 1; count <= CONVERTS; count++) {
        cout << "*Enter a Fahrenheit temperature: ";
        cin >> fahr;
        cout << "The Celsius equivalent is " << tempvert(fahr) << endl;
    }

    return 0;
}
```
(Note: The OCR text for Program 6.7 contained several errors like `CONST` instead of `const int` and `tempvert(fahrn)` which have been corrected.)

The advantage of using inline functions is execution speed. Because the function is reproduced and included every time it's called, no time is lost. However, the disadvantage is the increase in program size. Inline functions should be used only for small functions that are called extensively.
