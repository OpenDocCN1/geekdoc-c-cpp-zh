This procedure can be extended to 8, 16, 32, and so on to panels. The result is a rather simple generalization of Equation 14.12, and for $n = 2^k$ panels is the following:

```
$S_k = \frac{\Delta x}{3} \left[ f(a) + 4\sum_{odd\, only} f(a + i\Delta x_k) + 2\sum_{even\, only} f(a + i\Delta x_k) + f(b) \right] \quad (Equation\ 14.13)$
```

Equation 14.13, Simpson's rule, is a popular method of evaluating integrals of functions that are smooth, and right so. As you see later in this chapter, Simpson's rule converges nicely in most instances and is easy to use. Also, Equation 14.13 can be adapted to easily handle an odd number of evenly spaced points and is the most common method for estimating the integral of experimentally obtained data.

# Example of Simpson's Rule as an Approximation to an Integral

Again, consider this integral:
$I = \int_1^2 \frac{1}{x} dx$

Using Equation 14.13 first for $k = 1$ yields the following:

+   $k = 1\nn = 2^1 = 2\n\Delta x_z = \frac{b-a}{2^2} = \frac{1}{2}\nS_1 = \frac{\Delta x}{3}[1 + 4(1/1.5) + \frac{1}{2}] = 0.6944444$

+   Repeating for $k = 2$ yields the following results:\n$k = 2\nn = 2^2 = 4\n\Delta x_z = \frac{1}{4}\nS_2 = \frac{\Delta x}{3}[1 + 4(1/1.25 + 1/1.75) + 2(1/1.5) + \frac{1}{2}] = 0.69325397$
