Now see how these operations can be implemented with C++s built-in operators.

A user-defined operation is created as a function that define operations on objects and use C++s built-in operator symbols are referred to as operator functions. Operator functions are defined and implemented in the same manner as member functions, with one exception: the function name connects the operator symbol to the operation defined by. An operator function's name is in the form operator<symbol>, where <symbol> is one of the operators in Table 11.1. For example, operator+ is the name of the addition function, and operator== is the name of the equal-to comparison function.

After the function is selected, the process of writing function simply means having it inputs and produce the correct returned value. For example, to compare Date objects for equality, you select C++s equality operator, and the function name becomes operator== You define comparison operation to accept two Date objects, compare them, and return an integer value indicating result of the comparison: true for equality and for inequality. As a member function, a suitable prototype to include in the class declaration is as follows:

```
bool operator==(Date&);
```

This prototype indicates the function named operator==, it returns a Boolean value, and it accepts a reference to a Date object. Only one Date object is required because the second Date object is the object that calls the function. Now see how to write the function definition to include in the class implementation. For the Date class, the following definition is:

