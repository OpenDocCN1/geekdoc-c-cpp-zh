# Program 5.3

```
#include <iostream>
#include <iomanip>
using namespace std;

int main()
{
    int num;

    cout << "NUMBER SQUARE CUBE\n"
         << "------ ------ ------\n";

    num = 1;
    while (num < 11) {
        cout << setw(3) << num << "    " <<
             << setw(3) << num * num << "    " <<
             << setw(4) << num * num * num << endl;
        num++;            // increment num
    }

    return 0;
}
```

Note that the expression used in Program 5.3 is num < 11. For the integer variable num, this expression is exactly equivalent to the expression num <= 10. The choice of which to use is entirely up to you.

If you want to use Program 5.3 to produce a table of 1000 numbers, all you do to change the expression in the while statement from num < 11 to num < 1001. Changing the 11 to 1001 produces a table of 1000 lines—not bad for a simple five-line while statement.
