void polar(double x, double y, double& r, double& theta) {
{

## 5. (Numerical) Many algorithms have been developed for generating pseudorandom numbers. Some use a counting scheme, such as counting beginning at an arbitrary location in memory. Another scheme, which creates pseudorandom numbers by performing a calculation, begins with a power reduce method. The power reduce method begins with an $n$-digit integer, referred to as the "seed". The seed (the "residue") produces a result $(10^n-3)$. Using the lowest $n$ digits of the result produces a series of random numbers, with each new number used as the seed for the next. If the original seed has four or more digits (equal or greater than 4) and is not divisible by 2 or 5, this procedure yields $5 \times 10^n$ random numbers before a sequence repeats. For example, starting with a six-digit seed ($n=6$), such as 654321, a series of $5 \times 10^4 = 50000$ random numbers can be generated. As an algorithm, the steps in generating pseudorandom numbers with a power reduce method consist of the following:

- Step 1: Have user enter a six-digit seed that means the number should be an odd number not divisible by 2 or 5—this ends in 5.
- Step 2: Multiply the seed number by 997, which is $10^n-3$.
- Step 3: Extract the lowest six digits of the result produced by Step 2. Use this random number as the next seed.
- Step 4: Repeat Steps 2 and 3 for many random numbers as needed.

Therefore, if the user-entered seed number 654321 (Step 1), the first random number is calculated as follows:

- Step 2: $654321 \times 997 = 652358037$
- Step 3: Extract the lower six digits of the number obtained in Step 2, using a standard programming "trick" that involves the following:
- Step 3a: Divide the number by $10^6 = 1000000$, $652358037 / 1000000 = 652.358037$;
- Step 3b: Take the integer part of the result of Step 3a (for example, the integer part of $652.358037 = 652$);
- Step 3c: Multiply the result by $10^6$ (for example, $652 \times 10^6 = 652000000$);
- Step 3d: Subtract this result from the original number (for example, $652358037 - 652000000 = 358037$).

The integer part of a floating-point number can be determined by assigning the floating-point to an integer variable or using a C++ cast (see Section 3.3). In this process, you'll use the cast mechanism. The algorithm for producing a random number can be accomplished with the following code:

```

x = 997.0 * x - 1 * 1e6;
```
