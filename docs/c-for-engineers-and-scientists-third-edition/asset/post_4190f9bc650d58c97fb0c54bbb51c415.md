One of C++'s advantages is that it allows programmers to access the addresses of variables used in a program. This access gives programmers a view into a computer's basic storage structure, resulting in capabilities and programming power that aren't available in other high-level languages. This is accomplished by using a feature called pointers. Although other languages provide pointers, C++ extends this feature by providing pointer arithmetic; that is, pointer values can be added, subtracted, and compared. Fundamentally, pointers are simply variables used to store addresses. This chapter discusses declaring pointers, and then using them in meaningful ways.

### 12.1 Addresses and Pointers

As we saw in Section 5, to display the address of a variable, use the address-of operator, which returns the address of the variable. For example, in the following program, we display the address of num:

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 22;
    cout << "The value of num is " << num << endl;
    cout << "The address of num is " << &num << endl;
    return 0;
}
```

The output of the program above is:

```
The value of num is 22
The address of num is 0x6ffff09ac
```

![](img/e2a849fc7bc04aa2e6669ad865e0c22b_684_0.png)

The address 0x6ffff09ac is shown in hexadecimal format. If you run the program again, the address might be different because the operating system allocates a different memory location for the variable each time the program runs.

A pointer is a variable that stores the memory address of another variable. To declare a pointer, use the asterisk (*) symbol before the data type name. For example, to declare a pointer to an integer, use:

```cpp
int *ptr;
```

In this declaration, `ptr` is the name of the pointer, and its type is `int*`. This means that `ptr` can hold the address of an integer. To assign the address of a variable to a pointer, use the address-of operator:

```cpp
int num = 22;
int *ptr = &num;
```

Now, `ptr` holds the address of `num`. To access the value stored at the address held held by `ptr`, use the dereference operator (*):

```cpp
cout << "The value pointed to by ptr is " << *ptr << endl;
```

The output will be:

```
The value pointed to by ptr is 22
```

### 12.2 Array Names as Pointers

In C++, the name of an array acts as a pointer to its first element. For example, if you have an array:

```cpp
int list[3] = {10, 20, 30};
```

The name `list` is equivalent to the address of `list[0]`. You can use pointer arithmetic to access the array elements:

```cpp
cout << *list << endl;       // Outputs 10
cout << *(list + 1) << endl;  // Outputs 20
cout << *(list + 2) << endl; // Outputs 30
```

When you add an integer to a pointer, the compiler increments the address by the size of the data type the pointer points to. For example, `list + 1` points to the address of the second element, which is 4 bytes (for an `int`) ahead of the first element.

### 12.3 Pointer Arithmetic

Pointer arithmetic allows you to add or subtract integers from pointers. This is particularly useful for iterating through arrays.

```cpp
int arr[5] = {10, 20, 30, 40, 50};
for (int *p = arr; p < arr + 5; ++p) {
    cout << *p << " ";
}
```

You can also subtract one pointer from another to find the number of elements between them.

### 12.4 Passing Addresses

Passing the address of a variable to a function allows the function to modify the original variable. This is known as pass-by-reference.

```cpp
void increment(int *n) {
    *n = (*n) + 1;
}

int main() {
    int x = 10;
    increment(&x);
    cout << x; // Outputs 11
    return 0;
}
```

### 12.5 Common Programming Errors

There are several common errors when working with pointers: 

1. **Uninitialized pointers**: Using a pointer before it has been assigned an address.
2. **Dangling pointers**: Using a pointer that points to a memory location that has been freed.
3. **Memory leaks**: Failing to free memory that has been dynamically allocated.
4. **Double freeing**: Attempting to free the same memory location more than once.

In this chapter, we learned about pointers, variables that store memory addresses. We saw how to declare and initialize pointers, and how to use pointer arithmetic. We also explored how array names act as pointers and how to pass addresses to functions to achieve pass-by-reference. Finally, we discussed common programming errors to avoid.
