# Formatting cout Stream Data

Floating-point data in a cout output stream can be formatted in precise ways. For example, a common format requirement is to display monetary amounts with two digits after the decimal point, such as 123.45. You can do this with the following statement:

```
cout << setflags(ios::fixed)
<< setflags(ios::showpoint)
<< setprecision(2);
```

The first manipulator flag, ios::fixed, forces all floating-point numbers in the cout to be displayed in decimal notation. This flag also prevents scientific notation. The next flag, ios::showpoint, tells the stream to always display two digits after the decimal point. The setprecision manipulator tells the stream to always display two digits after the decimal point. Instead of using manipulators, you can use the cout methods set() and precision(). For example, the previous formatting can also be accomplished with this code:

```
cout.set(ios::fixed)
cout.set(ios::showpoint)
out.precision(2);
```

> Note the name of the object, cout, is separated from the method with a period. This format is the standard way of specifying a method and connecting to a specific object.
Additionally, the flags used in both the setf() method and the setflags() manipulator method can be combined by using the bitwise OR operator, | (explained in Section 15.2) Using this operator, the following two statements are equivalent:

```
cout << setflags(ios::fixed | ios::showpoint)
cout.set(ios::fixed | ios::showpoint);
```

The statement you choose is a matter of personal preference or a predefined imposed standard.
