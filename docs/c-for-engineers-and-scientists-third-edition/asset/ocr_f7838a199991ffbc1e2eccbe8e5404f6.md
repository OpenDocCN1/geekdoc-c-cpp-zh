# Integer Data Types

C++ now built-in integer data types, as shown in Figure 2.6. The essential difference between these integer data types is the amount of storage used for each type, which affects the range of values each type is capable of representing. The three most important and common types used in most applications are int, char, and bool. The other provided to accommodate special situations (such as a small or large range of numbers) and have been retained for historical reasons. They enabled programmers to maximize memory usage by selecting the data type with smallest amount of memory, consistent with an application's requirements. When computer memories were small, and expensive, the amount of memory used was a major concern. Although no longer a concern for most programs, these types still programmers to optimize memory usage when necessary, particularly in special-purpose digital control systems used in home appliances and automobiles.

**The int Type** supported by int data type are numbers, mathematically known as integers. An integer value consists of digits only and optionally be preceded by a plus (+) or minus (-) sign. Therefore, an integer value can be the number 0 or any positive or negative number without a decimal point, as shown in the examples of valid identifiers.

```
0 5 -10 +25 1000 253 -26351 +36
```

As examples illustrate, integers can contain a sign. However, no commas, decimal points, or special symbols, such as the dollar sign, are allowed, in these examples of invalid integers:

```
$255.62 2523 3. 6,243,892 1,492.89 +6.0
```
