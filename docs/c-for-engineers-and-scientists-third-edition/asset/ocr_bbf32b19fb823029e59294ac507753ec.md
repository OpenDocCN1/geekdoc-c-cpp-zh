it's advisable to omit the array size from the function header. For example, the more general form of findMax() can be used to find the maximum value of an integer array size:

```
int findMax(int vals[], int numels) // find the maximum value
{
 int i, max = vals[0];

for (i = 1; i < numels; i++)
  if (max < vals[i])
    max = vals[i];

return max;
}
```

The general form of findMax() declares that the function returns an integer value. The function expects the starting address of an integer array and the number of elements in the array as arguments. Using number elements as the boundary for its search, the function's loop causes each array element to be examined in sequential order to locate the maximum value.
