Having verified that swap() can access main()'s locals firstnum and secnum, you can now expand swap() to exchange the values in these variables. The values in main()'s variables firstnum and secnum can be interchanged from within swap() using the three-step interchange algorithm described in Section 6.3.

+   1. firstnum's value in a temporary location.
2. secnum's value in firstnum.
3. The temporary location's value in secnum.

Using pointers in swap(), this algorithm takes the following form:

+   1. Store the value of the variable that nmlAddr points to in a temporary location by the statement temp = *nmlAddr (see Figure 12.19).
