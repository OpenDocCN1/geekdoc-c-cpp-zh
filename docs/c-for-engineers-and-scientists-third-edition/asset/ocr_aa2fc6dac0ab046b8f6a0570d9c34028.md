# Point of Information

Do You Use a for or while Loop?

Beginning programmers often ask which loop structure should they use—a for or while loop. It's a good question because both loop structures are preprocess loops that, in C++, both can be used to construct fixed-count and variable-count loops.

In most other languages, including Visual Basic and Pascal, the answer is straightforward because the for statement can be used only to construct fixed-count loops. In these languages, then, for statements are used to construct fixed-count loops, and while statements are generally used for variable-count loops.

In C++, this distinction doesn't hold because both statements can be used to create types of loops. The answer is a matter of style. Because a for and while loop are interchangeable in C++, either is appropriate. Some professional programmers always use a for for preset loops and almost never use a while statement; others use a while statement and rarely use a for statement. A third group tends to retain the convention used in other languages—a for loop is generally used to create fixed-count loops, and a while loop is used to create variable-count loops. In C++, it's a matter of style, and you'll encounter all three styles in your programming career.
