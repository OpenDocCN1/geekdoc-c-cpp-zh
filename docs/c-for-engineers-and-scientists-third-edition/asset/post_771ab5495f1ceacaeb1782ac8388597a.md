## File Stream Methods

Each file stream object has access to the methods defined for its ifstream or ofstream class. These methods include connecting a stream object name to an external filename (opening a file), determining whether a successful connection has been made, closing a connection (closing a file), getting the next data into the program from an input stream, putting data from the program onto an output stream, and detecting when the end of a file has been reached.

Opening a file connects a file stream to a specific external filename by using the stream's open() method, which accomplishes two purposes. First, opening a file establishes the physical linking between a program and a file. Details of this link are handled by the computer's OS and are not visible to the program, normally the programmer doesn't need to consider them.

From a coding perspective, the second purpose of opening a file is more relevant. Besides establishing the actual physical connection between a program and a data file, opening a file connects the file's external name to the stream object that the program uses internally. The method that performs this task, open(), is provided by the ifstream and ofstream classes.

#include <cstdlib> // needed for exit()
using namespace std;

int main() {
    ifstream infile;

    infile.open("prices.dat"); // open the file with the
                            // external name prices.dat
    if (infile.fail()) // check for a successful open {
        cout << "\nnThe file was not successfully opened\";
             << "\nnPlease check that the file currently exists.\
        exit(1);
    }

The file has been successfully opened for reading.

A different check is required for output files (that are written to) because if a file exists with the same name as the file to be opened in output mode, the existing file is erased and all its data is lost. To avoid this situation, the file is first opened in input mode to see whether it exists. If it does, the user has the choice of permitting it to be overwritten when it's opened later in output mode. ## Table 8.2 File Status

| Prototype | Description |
| :--- | :--- |
| fail() | Returns a Boolean true if the file hasn't been opened successfully; otherwise, returns a false value. |
| eof() | Returns a Boolean true if a read has been attempted past the end-of-file; otherwise, returns a false value. The value becomes true only when the first character after the valid character is read. |
| good() | Returns a Boolean true value while the file is available for use. Returns a Boolean false value if a read has been attempted past the end-of-file. The value becomes false only when the first character after the valid character is read. |
| bad() | Returns a Boolean true if a read has been attempted past the end-of-file; otherwise, returns a false. The value becomes true only when the first character after the valid character is read.
