AND operations are useful for masking, selecting, bits from an operand because ANDing any bit (1 or 0) with a0 forces the bit to be a 0, and ANDing any bit (1 or 0) with a 1 leaves the original bit unchanged. For example, the variable op1 has the pattern xxxxxxxx, where each x can be 1 or 0, independent of any other x in the number. The result of ANDing this binary with the number 00001111 is as:

```
op1 = x x x x x x x x
op2 = 0 0 0 0 1 1 1 1
```

```
Result = 0 0 0 0 0 0 0 0
```

As you can see in this example, the 0s in op2 mask the bits in op1, and the 1s in op2 filter, the bits in op1 through no change in their values. In this example, the variable op2 is a mask. By choosing the mask appropriately, any bit in an operand can be selected, filtered, out of an operand for inspection. For example, ANDing the variable op1 with 00000010 forces all the bits of the result to be 0, except the third bit. The third bit of the result is a copy of the bit of op1; therefore, if the result of the AND is 0, the third bit of op1 must be 0, and if the result of the AND is a non-zero, the third bit must be 1.

Program 15.2 uses masking to convert lowercase letters into their uppercase, as the letters are stored with the ASCII code. The algorithm for converting letters is based on binary codes for lowercase and uppercase letters ASCII being the same except for bit, which is 1 for lowercase letters and 0 for uppercase letters.

For example, the binary code for the letter A is 01000001 (hex 41). Similarly, the binary code for the letter z is 01111010 (hex 7A), and the binary code for the letter Z is 01011010.
