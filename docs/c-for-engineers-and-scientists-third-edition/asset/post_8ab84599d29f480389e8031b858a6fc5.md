## Default Arguments

C++ provides default arguments in a function call for added flexibility. The primary use of default arguments is to extend the parameter list of existing functions without requiring any change in the calling lists already used in a program.

Default arguments are listed in the function prototype and transmitted automatically to the function call when the corresponding arguments are omitted from the function call. For example, the function prototype

```
void example(int, int = 5, double = 6.78);
```

provides default values for the last two arguments. If any argument is omitted when the function is actually called, the C++ compiler supplies the default values. Therefore, all the following function calls are valid:

```
example(7, 2, 9.3)      // no default arguments
example(7, 2)            // same as example(7, 2, 6.78)
example(7)               // same as example(7, 5, 6.78)
```

Four rules are followed when using default arguments. First, default values are assigned in the function prototype. If any parameter is given a default value in the function prototype, all following it are supplied with default values. If one argument is omitted in an actual function call, all arguments to its right must also be omitted. The second and third rule will allow the C++ compiler to properly correct default values for the missing arguments, with the rightmost argument working toward the left. Fourth, the default value used in the function prototype can be an expression of constants and previously declared variables. If this kind of expression is used, it must pass the compiler's declared variables, even though the expression's actual value is evaluated at runtime.

Default arguments are useful when extending an existing function to include more features without adding new arguments to the right of the existing arguments, and giving each new argument a default value permits all existing function calls to remain as they are. In this way, the effect of the changes can be conveniently isolated from the existing code in the program.

## Reusing Names (Overloading)

C++ provides the capability of using the same function name for more than one function, referred to as function overloading. The only requirement for creating more than one function with the same name is that the compiler must be able to determine which function to use based on the parameters' data types (not the type of return value, if any). For example, take a look at the three following functions, named cdabs():

```cpp
void cdabs(int x) //
    compute and display the absolute value of an integer
{
    if (x < 0)
        x = -x;
    cout << "The absolute value of the integer is " << x << endl;
}
```

```cpp
void cdabs(float x) // compute and display the absolute value of a float {
  if ( x < 0 ) {
    x = -x;
    cout << "The absolute value of the float is " << x << endl;
  }
}
```

```cpp
void cdabs(double x) // compute and display the absolute value of a double {
  if ( x < 0 ) {
    x = -x;
    cout << "The absolute value of the double is " << x << endl;
  }
}
```

Which of the three functions named cdabs() is actually used depends on the argument type supplied at the time of the call. Therefore, the function call cdabs(10); causes the caller to use the function name cdabs(int) that expects an integer argument, and the function call cdabs(6.28f); causes the caller to use the function name cdabs(float) that uses a single-precision argument.

Notice that overloading a function does not mean using the same name for more than one function. Each function that uses the same name must be written and exists as a separate entity. The use of the same function name does not require code in the functions to be similar, although good programming practice dictates that functions with the same name perform essentially the same operations. All that's required to use the same function name is that the compiler can distinguish which function to select based on the data types of the arguments when the function is called. However, if the only difference in the overloaded functions is the argument type, a better programming solution is to create a function template, discussed next. The use of overloaded functions is extremely useful with constructor functions, explained in Section 10.2.

## Function Templates

In most high-level languages, including C++ predecessor, C; each function requires its own unique name. In theory, using unique names makes sense, but in practice, it can lead to a profusion of function names, even for functions that perform essentially the same operations. For example, consider determining and displaying a number's absolute value. If the number passed to the function can be an integer, a single-precision value, or a double-precision value, three distinct functions must be written to handle each case correctly.

Certainly, you could give each function a unique name, such as abs(), fabs(), and dabs(), having the following function prototypes:

```
void abs(int);
void fabs(float);
void dabs(double);
```

Each of these functions performs essentially the same operation on different data types. A much cleaner solution is writing a general function that handles all cases, where the compiler can set parameters, variables, and return type based on the actual function call. You can use templates to achieve this. The advantage of using templates is that you only need to write the code once, and the compiler generates the specific versions for each data type.

A function template is defined using the `template` keyword followed by the template parameters in angle brackets. For example:

```cpp
template <class T>
void showabs(T number) {
    if (number < 0)
        number = -number;
    cout << "The absolute value of the number is " << number << endl;
}
```

In this example, `T` is a placeholder for a data type. When `showabs` is called with a specific type, the compiler replaces `T` with that type and generates the specific version of the function.

## Modularity Using Functions

### Program 6.3

```cpp
#include <iostream>
using namespace std;

template <class T>
void showabs(T number)
{
    if (number < 0)
        number = -number;
    cout << "The absolute value of the number is "
        << number << endl;
    return;
}

int main()
{
    int num1 = -4;
    float num2 = -4.23f;
    double num3 = -4.23456;

    showabs(num1);
    showabs(num2);
    showabs(num3);

    return 0;
}
```
