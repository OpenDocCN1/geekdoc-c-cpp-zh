## 6.2 Returning a Single Value

Using the method of passing data to a function explained in the previous section, the called function receives only copies of the values contained in arguments at the time of the call.(Review Figure 6.3 if it's unclear to you.) When a value is passed to a called function the passed is referred to as **passed by value** and is a distinct advantage of C++.The calling function does not have direct access to the variables used by arguments calling the function, it cannot inadvertently alter the value stored in one of these variables.

The function receiving the passed by value arguments can send the values it wants to in its fashion and return one, and only one, "legitimate" value directly to the calling function (see Figure 6.6). In this section, you will see how this value is returned to the calling function. As you might expect, given C++'s flexibility, there's a way of returning more than a single value, but that's the topic of the next section.

A function can receive many values

As with calling a function, returning a value directly requires handling the interface between the calling and calling functions correctly. From its side of the return transaction, the called function must provide the following items:

- The data type of the returned value
- The actual value being returned

A function returning value must specify, in its header, the data type of the value to be returned. Recall that the function header includes both the function name and a parameter list. For example, the findMax() function written previously determines the maximum value of two numbers passed to it. For convenience, the findMax() code is listed again:

```cpp
void findMax(int x, int y)
    // start of function body
    int maxnum; // variable declaration

    if (x > y)
        // find the maximum number
        maximum = x;
    else
        maximum = y;

    cout << "nThe maximum of the two numbers is "
        << maximum << endl;

    return; // end of function body and end of function
```

In this function header, x and y are the names chosen for the function's parameters:

```cpp
void findMax(int x, int y)
```

If findMax() is to return a value, its function header must be amended to include the data type of the value being returned. For example, if an integer value is to be returned, this is the correct function header:

```cpp
int findMax(int x, int y)
```

Similarly, if the function is to receive two single-precision parameters and return a single-precision value, this is the correct function header:

```cpp
float findMax(float x, float y)
```

If the function is to receive two double-precision parameters and return a double-precision value, the function header would be the following:

```cpp
double findMax(double x, double y)
```

Now see how to modify the findMax() function to return the maximum value of the two numbers passed to it. You must first determine the data type of the value to be returned and include this data type in the function header. Because the maximum value determined by findMax() is stored in the integer variable, the function should return this variable's value. Returning an integer value from findMax() requires the following declaration:

```cpp
int findMax(int x, int y)
```
