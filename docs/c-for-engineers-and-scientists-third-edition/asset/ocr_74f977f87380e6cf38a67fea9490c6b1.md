**Table 9.5** Character Library Functions (Require the Header String or cctype) (continued)

| Function Prototype | Description | Example |
|---|---|--|
| `int ispunct(charExp)` | Returns a true (non-zero integer) if charExp evaluates to a punctuation; otherwise, returns a false (zero integer) | `ispunct('!')` |
| `int isgraph(charExp)` | Returns a true (non-zero integer) if charExp evaluates to a printable character other than white space; otherwise, returns a false (zero integer) | `isgraph(' ')` |
| `int toupper(charExp)` | Returns the uppercase equivalent if charExp evaluates to a lowercase character; otherwise, returns the character code without modification | `toupper('a')` |
| `int tolower(charExp)` | Returns the lowercase equivalent if charExp evaluates to an uppercase character; otherwise, returns the character code without modification | `tolower('A')` |

All the `istype()` functions in Table 9.5 return a non-zero integer (Boolean true value) when the character meets the condition and a zero integer (Boolean false value) when the condition is not met, these functions are typically used in an `if` statement. For example, the following code assumes `ch` is a character variable:

```
if (isdigit(ch))
    cout << "The character just entered is a digit" << endl;
else if (ispunct(ch))
    cout << "The character just entered is a punctuation mark" << endl;
```

In this example, if `ch` contains a digit, the first count statement is executed; if the character is a letter, the second count statement is executed. In both cases, the character to be checked is included as an argument to the function. Program 9.13 illustrates this type of code in a program that counts the number of letters, digits, and other characters in a string. The characters to be checked are obtained using the `string` class's `at()` method. In Program 9.13, this function is used in a `for` loop that cycles through the string from the first character to the last.

```

11 letters

```

As indicated by this output, each of the 33 characters in the string has been categorized correctly as a letter, a digit, or other character.
