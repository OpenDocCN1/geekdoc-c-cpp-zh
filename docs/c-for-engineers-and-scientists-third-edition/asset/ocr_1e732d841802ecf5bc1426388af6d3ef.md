# 1.2 Preliminary Two: Exponential and Scientific Notations

Many engineering and scientific applications require dealing with extremely large and small numbers. For example Avogadro's number, used in chemistry, has the value $602,214,179,000,000,000,000$, the universal gravitational constant used in aerospace and rocket applications has the value $0.000000000667428$. To make entering these numbers in a computer program easier, they can be written in a more compact form as **exponential notation**. Similarly, in performing calculations for certification purposes, an equivalent representation known as **scientific notation** is typically used.

The following examples illustrate how numbers with decimals can be expressed in both exponential and scientific notation:

| Decimal Notation | Exponential Notation | Scientific Notation |
|---|---||
| 1625. | 1.625e3 | $1.625 \times 10^3$ |
| 63421. | 6.3421e4 | $6.3421 \times 10^4$ |
| .00731 | 7.31e-3 | $7.31 \times 10^{-3}$ |
| .00625 | 6.25e-4 | $6.25 \times 10^{-4}$ |
