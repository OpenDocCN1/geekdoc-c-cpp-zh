A static variable isn't created and destroyed each time the function declaring it is called. After they're created, local static variables remain in existence for the program's lifetime. This means the last value stored in the variable when the function finishes executing is available to the function next time it's called.
Because static variables retain their values, they are initialized in a declaration statement in the same way as automatic variables. To understand why, consider the automatic variable declaration num = 0;, which causes the automatic variable to be reset to 0 each time the function is called. This is called a runtime initialization because occurs each time the declaration statement is encountered. This type of initialization would be disastrous for a static variable because resetting the value to 0 each time the function is called destroys the very value you're trying to save.
Initialization of static variables (both local and global) is done only once, when the program is first compiled. At compile time, the variable is created and any initialization value is placed in it.¹⁴ Thereafter, the variable in the variable is kept without further initialization. To see how this works, examine Program 6.18.

# Program 6.18

```
#include <iostream>
using namespace std;

void teststat(); // function prototypeint main()
{
    int count;    // count is a local auto variable
    for(count = 1; count <= 3; count++)
        teststat();

    return 0;
}

void teststat()
{
    static int num = 0;    // num is a local static variable
    cout << "The value of the static variable num is now "
         << num << endl;

    num++;

    return;
}
```

> ¹⁴Some compilers initialize static variables the first time the definition statement is executed rather than when the program is compiled.
