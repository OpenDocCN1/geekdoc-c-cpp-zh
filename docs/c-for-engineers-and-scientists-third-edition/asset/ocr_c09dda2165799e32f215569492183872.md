# 12.1 Addresses and Pointers

As we saw in Section 2.5, to display the address of a variable, you can use C++s address operator, &, which means "the address of." When used in a nondeclaraative statement, the address operator placed in front of a variable's name refers to the address of the variable! For example, in a nondeclaraative statement, &num means the address of num, &miles means address of miles, and &foo means the address of foo. Program 12.1, which is a copy of Program 2.10, uses the address operator to display the address of the num variable.

# Program 12.1

```
#include <iostream>
using namespace std;

int main() {
    int num;

    num = 22;
    cout << "The value stored in num is " << num << endl;
    cout << "The address of num = " << &num << endl;

    return 0;
}
```

The output of Program 12.1 is as follows:

```
The value stored in num is 22
The address of num = 0012FED4
```
