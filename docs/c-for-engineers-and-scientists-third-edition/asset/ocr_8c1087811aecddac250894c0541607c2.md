However, $2\Delta x_2 = \Delta x_1$, you can see that
$f(a + 2\Delta x_2) = f(a + x_1)$

and $f(a+\Delta x_i)$ was already determined in the previous calculation of $T_1$ (Equation 14.8). The point is that by successively doubling the number of panels in each stage, the only new information required to proceed to the next order trapezoidal rule approximation is the evaluation of the function at the midpoints of the current intervals.

To exploit this further, Equations 14.7 and 14.8 can be used to rewrite Equation 14.10 in this form:

```
$T_2 = (\Delta x_2)[f(a) + 2f(a+\Delta x_1) + f(b)] + \Delta x_2[f(a+\Delta x_2) + f(a+3\Delta x_2)]
$= T_1/2 + \Delta x_2[f(a+\Delta x_2) + f(a+3\Delta x_2)]$  (Equation 14.10)
```

This equation can be generalized to

```
$T_k = T_{k-1}/2 + \Delta x_k \sum_{i=1}^{k-1} f(a+i\Delta x_k)$  (Equation 14.11)
```

where

```
Delta x_k = \frac{b-a}{2^k}$
```

The procedure for using Equation 14.11 to approximate an integral by a trapezoidal rule is:

+   1. Compute $T_0$ using Equation 14.6.
2. Repeatedly apply Equation 14.11 for $k=1, 2, \dots$ until sufficient accuracy is obtained.
