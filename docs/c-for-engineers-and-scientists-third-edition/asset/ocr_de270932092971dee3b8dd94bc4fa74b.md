Notice that the Date class follows this format. For convenience, it's listed again with no internal comments:

```
// class declaration section
class Date
{
  private:
  int month;
  int day;
  int year;
  public:
  Date(int = 7, int = 4, int = 2005);
  void setState(int, int, int);
  void showDate();
};
```

The name of class is Date. Although the initial uppercase letter isn't required, it's used by convention to designate a class. The body of the declaration section, enclosed in braces, consists of variable and function declarations. In this case, the data members month, day, and year are declared as integers, and setState() and showDate() are declared as prototypes. The private and public access specifiers define which of them—in this case, month, day, and year—can be accessed only by the class functions (or friend functions), as discussed in 10.2⁴ The private designation is meant to ensure data security by requiring access to all private members through the private methods. This type of access restricts a user from seeing how data is actually stored, and is referred in force until a new category is created.

In Date class, data is stored using three integers for the month, day, and year. The year is also stored as a four-digit integer. For example, the year 1998 is stored as 1998, not 98. Making sure to all years with their century designation eliminates a multitude of problems that can crop up if only the last two digits are stored. For example, the number between 2006 and 1999 can be calculated as 2006 - 1999 = 7 years, getting the same answer as it is with the year values 06 and 99. Additionally, if for example the year 2006 refers to, a two-digit value, such as 06, could either refer to 1906 or 2006.

Following the private class members, the function prototypes in the Date class have been declared as public. This means these functions can be called by any objects
