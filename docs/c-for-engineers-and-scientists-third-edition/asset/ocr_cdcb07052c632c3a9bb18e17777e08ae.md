The parentheses in the expression *(gPtr + 3) are necessary to refer an array element correctly. Omitting the parentheses results in grade[0]*gPtr + 3. Although the pointer in Program 12.5 is created specifically to store the array's starting address, doing so is unnecessary. When an array is created, the compiler creates an internal pointer for it automatically and stores the array's starting address in this pointer. In almost all cases, a pointer constant is identical to a programmer-created variable, but as you'll see, there are some differences.

For each array created, the array name becomes the name of the pointer constant the compiler creates for the array, and the starting address of the first location reserved for the array is stored in this pointer. Therefore, declaring the array in Programs 12.4 and 12.5 actually creates enough storage for five integers, creates an internal pointer named grade, and stores the address of grade[0] in the pointer, as shown in Figure 12.14.
