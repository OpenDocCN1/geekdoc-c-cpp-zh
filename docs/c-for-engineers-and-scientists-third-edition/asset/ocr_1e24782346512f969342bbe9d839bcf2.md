# Floating-Point Types

A floating-point number, more commonly known as a real number, can be the number 0 or positive or negative without a decimal point, as shown in:

+10.625 -6.2 3251.92 0.0 -6.67 +2

Therefore, the numbers 5, 0.0, and +2 are classified as floating-point values, but the same numbers written without a decimal point (5, 0, +2) are integers. With integer values, special symbols such as the decimal sign and comma aren't permitted in real numbers, as shown in these examples of invalid reals:

5,326 24 6,459 $10.29 7.007.645

C++ supports three floating-point types: float, double, and long. The difference between these data types is the amount of storage the compiler uses. Most compilers use the amount of doubles for floats, which allows a double to have approximately twice the precision of a float. For this reason, a float is sometimes referred to as a single-precision number and a double as a double-precision number. The actual storage for each data type, however, depends on the compiler. The ANSI C++ standard requires only that a double have at least the same amount of storage as a float. Currently, most C++ compilers allocate 4 bytes for floats and 8 bytes for doubles and longs, which produces the range of numbers listed in Table 2.6.
