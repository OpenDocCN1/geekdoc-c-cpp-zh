The parentheses around the expression *pt in Figure 13.3 are necessary to access "the structure address is in pt." (*pt) is followed by an identifier to access the structure member. In the absence of parentheses, the structure member operator, takes precedence over the indirection operator, *. the expression *pt.hours is in the pt.hours variable," which would mean "the variable address is in the pt.hours This expression *pt.hours makes no sense because there is no structure named pt and hours does not contain an address.

As shown in Figure 13.3, the starting address of the emp structure is also the address of the first structure member. Using a pointer in this manner is so common that a special notation exists for it. The general expression (*pointer).member can always be replaced with the notation pointer->member. The -> operator is a hyphen followed by a greater-than symbol. For example, the following expressions are equivalent:

+   * (*pt).idNum can be replaced by pt->idNum
* (*pt).payRate can be replaced by pt->payRate
* (*pt).hours can be replaced by pt->hours
