Using Mathematical Library Functions

As used in Program 3.9, the value sqrt function returns is assigned to the variable time. In addition to assigning a function's returned value to a variable, the returned value can be included in a larger expression or even used as an argument to another function. For example, the following expression is:

```
sqrt( sin(theta) )
```

Because parentheses are present, the computation proceeds from the inner to outer pairs of parentheses. The absolute value of theta is computed first and used as argument to the sin() function. The value sin() function returns is then used as an argument to the sqrt() function.
The arguments of all trigonometric functions (sin(), cos(), and so forth) must be in radians. Therefore, to calculate the sine of an angle given in degrees, the angle must be converted to radians first. You can do this by multiplying the angle by the (3.1416/180). For, to obtain the sine of 30 degrees, the expression sin (30 * 3.1416/180).

# Casts

You have already seen the conversion of an operand's data type in mixed-mode arithmetic expressions (Section 2.4) and In addition to implicit data type conversions made automatically in mixed-mode arithmetic and assignment expressions, C++ provides for explicit user-specified type conversions. The operator used to force converting a value to another type is the cast operator. C++ provides compile-time and runtime casts. The compile-time cast is a unary operator with syntax:

```
dataType(expression)
```

The dataType is the data type to which the expression in parentheses is converted. For, the following example

```
int ( a * b)
```

converts the value of the expression a * b to an integer value.
With the introduction of the Late C++ standard, runtime casts are included. In this type of cast, the requested type conversion is checked at runtime and if the conversion results in a valid value. Although four types of runtime casts are available, the most commonly used cast and the one corresponding to the compile-time cast has the following syntax:

```
staticCast<data-type>(expression)
```

For example, the runtime cast staticCast<int>(a * b) is equivalent to the compile-time cast int (a * b).
