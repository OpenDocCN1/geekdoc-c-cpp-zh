# 13.7 Common Programming Errors

Three common errors are made when using structures or unions. The first error occurs because structures and unions, as complete entities, can't be used in relational expressions. For example if TeleType and PhonType are two structures of the same type, the expression TeleType = PhonType is invalid. Members of a structure or union can, be compared if they are of the same data type, using any of C++'s relational operators,

The second common error is actual assignment of a pointer error addresses to structures and unions. When a pointer is used to "point to" either of these data types, or when a pointer is a member of a structure or a union, take care to use the address to access the correct data type. If you're confused about exactly what's being pointed to, remember: "If in doubt, print it out."

# 13.8 Chapter Summary

- 1. A structure allows grouping variables under a common variable name. Each variable in a structure is accessed by its structure variable name, by a period, followed by its variable name. Another term for a data structure is a record. One form for declaring a structure is as follows:

```
struct
  // member declarations
} structureName;
```

- 2. A data type can be created from a structure by using this declaration form:
struct DataType
{
  // member declarations
};
```
Structure variables can then be defined as this DataType. By convention, the first letter of the DataType name is always capitalized.

- 3. Structures are particularly useful as elements of arrays. Used in this manner, each structure becomes one record in a list of records.

- 4. Complete structures can be used as function arguments, in which case the called function receives a copy of each element in the structure. A structure's address can also be passed, as a reference or a pointer, which gives the function direct access to the structure.

- 5. Structure members can be any C++ data type, including other structures, unions, arrays, and pointers. When a pointer is used as a structure member, a linked list can be created. This uses the pointer in one structure to "point to" (contain the address of) the next logical structure in the list.

- 6. Unions are declared in the same manner as structures. The definition of a union creates a memory overlay area, with each union using the same memory storage locations. Wherever, only one member of a union can be active at a time.
