Atomic Data
All the variables declared so far have been used to store atomic data values. An atomic data value is considered a complete entity and cannot be decomposed into a smaller data type supported by the language. For example, an integer can be decomposed into individual digits, C++ doesn't have a numerical digit type. Instead, each integer is regarded as a complete value and, therefore considered atomic data. Because the integer data type supports only atomic data values, it's said to be an atomic data type. As you might expect, doubles, chars, and bools are atomic data types, too.
