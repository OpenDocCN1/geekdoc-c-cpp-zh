# Files

A file is a collection of data stored together under a common name, usually on a disk, magnetic tape, USB drive, or CD/DVD. For example, the C++ programs you store on disk are examples of files. The stored data in a program file is the code that becomes input data to the C++ compiler. In the context of data processing, a C++ program isn't usually considered, and the term "file" or "data file" typically refers to external files containing the data used in a C++ program.

A file is physically stored on an external medium, such each file has a unique filename, referred to as the external name. The external name is how the operating system (OS) knows the file. When you review the contents of a directory or folder (for example, in Windows Explorer), you see files listed by their external names. Each OS has its own specification for the maximum of characters permitted for an external filename. Table 8.1 lists these specifications for commonly used OSs.

| Table 8.1 Maximum Allowable Filenames |
| OS | Maximum Filename Length |
|---|---|
| DOS | 8 characters plus an optional period and 3-character extension |
| Windows 98, 2000, XP, Vista | 255 characters |
| UNIX Early versions | 14 characters |
| Current versions | 255 characters |

To make examples in this book compatible with all the OSs listed in Table 8.1, the more restrictive DOS specification has been adhered to (but not always). If you are one of the other OSs, however, you can take advantage of the increased length specification to create descriptive filenames, but avoiding extremely long filenames because they take more time to type and can result in typing errors. A manageable length for a filename is usually 12 to 14 characters, with a maximum of 25 characters.

Using the DOS, all following are valid filenames:

```
prices.dat    records    info.txt
exper1.dat   scores.dat  math.mem
```

Choose filenames that indicate the type of data in the file and the application for which it is used. Typically, the first eight characters describe the data, and an extension (the characters after the decimal point) describes the application used to create the file.
