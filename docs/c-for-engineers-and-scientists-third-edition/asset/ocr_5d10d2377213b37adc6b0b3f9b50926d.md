# 7.7 A Closer Look: Searching and Sorting

Most programmers encounter the need to sort and search a list of data items at times in their programming careers. For example, you might have to sort a list of names in alphabetical order and search this list to find a particular name. Similarly, you might have to arrange a list of dates in ascending order and search this list to locate a certain date. This section introduces the fundamentals of sorting and searching lists. Note that sorting a list before searching isnt necessary, much faster searches are possible if the list is in sorted order, as you'll see.
