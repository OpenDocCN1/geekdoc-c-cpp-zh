# Using Mathematical Functions

As you have seen, assignment statements can be used to perform arithmetic computations. For example, the following assignment statement multiplies the value in current by resistance and assigns the resulting value to volts:
```cpp
volts = resistance * current;
```

Although subtraction, multiplication, and division are accomplished easily with C++ operators, no operators exist for raising a number to a power, finding the square root, or determining trigonometric values. To perform these calculations, C++ provides standard functions that can be included in a program. Before using C++ mathematical functions, you need to know the following:

- The name of the mathematical function
- What the mathematical function does
- The type the mathematical function requires
- The type of the result the mathematical function returns
- How to include the mathematical library

To illustrate the use of C++ mathematical functions, take look at the mathematical function sqrt(), which calculates a number's square root using this form:
```cpp
sqrt(number)
```

The function's name, in this case, sqrt, is followed by parentheses containing the number for which the square root should be calculated. The purpose of the parentheses after the function name is to provide a funnel through which data can be passed to the function (see Figure 3.9). The items passed to the function through the parentheses are called arguments of the function and constitute its input data. For example, the following expressions are used to compute the square root of the arguments 4., 17.0, 25., 1043.29, and 6.4516:

```cpp
sqrt(4.)
sqrt(17.0)
sqrt(25.)
sqrt(1043.29)
sqrt(6.4516)
```

Notice that the argument to the sqrt() function must be a real value, which is an example of C++s overloading capabilities. Function overloading permits using the same function name for arguments of different data types? There are actually three functions sqrt()—defined for float, double, and long double arguments. The correct sqrt() function is called depending on the type of value passed to the function when the call is made. When one of the functions sqrt() is called (again, the selection is automatic, based on the passed argument), the function determines the square root of its argument and returns the result as a double. The previous expressions return these values:

| Expression | Value Returned |
| --- | --- |
| sqrt(4.) | 2. |
| sqrt(17.0) | 4.12311 |
| sqrt(25.) | 5. |
| sqrt(1043.29) | 32.2 |
| sqrt(6.4516) | 2.54 |

In addition to the sqrt() function, Table 3.5 lists commonly used mathematical functions provided in C++. Access these functions in a program requires including the mathematical header file <cmath>, which contains declarations for mathematical functions. To use this header file, place the following preprocessor statement at the top of any program using a mathematical function:

```cpp
#include <cmath>
```

Although some mathematical functions in Table 3.5 require more than one argument, all by definition, can return at most one value. Additionally, all the functions listed are overloaded, which means the same function name can be used with integer and real arguments.
