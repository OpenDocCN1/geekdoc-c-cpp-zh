# 11.3 Operator Functions

You constructed a single assignment operator in Section 11.1. In this section, you extend this capability and show how to broaden C++ built-in operators to work with class objects. As you'll discover, class operators are also member or friend functions.

The only symbols permitted for user-defined properties are the C++ built-in symbols listed in Table 11.1. These symbols can be adopted for use with no limitation in their meaning by making each operation a function that can be overloaded like any function.The operation of the symbols in Table 11.1 can be redefined as you see fit for your classes, subject to the following restrictions:

+   - Symbols in Table 11.1 cannot be redefined. For example, :, :, , and ? symbols cannot be redefined.
- New operators cannot be created. For example, because % is not an operator in C++, it can be defined as a class operator.
- Therefore neither the precedence of C++ operators can be modified.
- Operators can be redefined for C++ built-in types.
- A unary C++ operator can be changed to a binary operator, and a binary operator can't be changed to a unary operator.
- The operator must be a member of a class or defined to take at least one class member as an operand.
