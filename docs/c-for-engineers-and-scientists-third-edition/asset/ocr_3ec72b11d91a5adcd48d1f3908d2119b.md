```
    getline(cin,record->phoneNumber);

    return;
}

void display(TeleType *contents) // contents is a pointer to a
{
    // structure of type TeleType
    while (contents != NULL) // display until end of linked list
    {
        cout << endl << setflags(ios::left)
        << setw(30) << contents->name
        << setw(20) << contents->phoneNo;
        contents = contents->nextaddr;
    }
    cout << endl;
}
```

The first time new is called in Program 13.11, it's used to create the first structure in the linked list. Therefore, the address returned is stored in the pointer variable list. The address in list is assigned to the pointer variable. This pointer variable is used to point to the current structure. Because the current structure is the first structure created, the address in the pointer list is assigned to the current pointer.

In main() for loop, the name and telephone number members of the newly structure are populated by calling populate() and passing the address of the current structure to the function. At the return, the pointer member of the current structure is assigned the address of the next structure in the list, which is obtained from new. The call to new creates the next structure and returns its address to the pointer member of the current structure. This call completes the population of the current member. The final statement in the for loop resets the address in the current pointer to the address of the next structure in the list.

After the last structure has been created, the final statements in main() populate this structure, assign a NULL address to the pointer member, and call display() to display all structures in the list. The following is a sample run of Program 13.11:
