| What Is Syntax? |
A programming language's syntax is the set of rules for formulating statements that are grammatically correct for the language. In practice, it means a C++ statement with correct syntax has the proper form specified for the compiler. If statements are in the proper form, the compiler accepts them and doesn't generate an error message.
Note, however, a statement or program can be syntactically correct yet logically incorrect. In other words, the statement or program is structured correctly but produces an incorrect result; It is similar to an English statement that grammatically correct but makes no sense, such as "The tree is ragged cat".|

Following the preprocessor #include command is a statement containing the reserved word using. Following this statement, for example, tells the compiler to look to find header files in the absence of an explicit designation:

```
using namespace std;
```

You can think of a namespace as a section of code the compiler uses when it's looking for prewritten classes or functions. Because the iostream header file is contained in a namespace std(the standard library); the compiler automatically uses object cout from this namespace whenever code is referenced by using namespaces, you can create your own classes and functions with the same standard library provides and place them in differently named namespaces. You can tell the program which class or function to use by specifying the namespace where you want the compiler to look for the class or function. In Chapter 9, you learn how to create your own namespaces. For now, use the classes and functions provided by the std namespace.

Because cout is an object of a prewritten class, you don't have to create it; it's available for use just by activating it correctly. Like all C++ objects, cout can perform only certain well-defined actions. For cout, the action is to assemble data for output display. A string of characters is sent to cout, the object makes sure the string is displayed onscreen correctly, as shown in this output from Program 2.1:

Hello world!
