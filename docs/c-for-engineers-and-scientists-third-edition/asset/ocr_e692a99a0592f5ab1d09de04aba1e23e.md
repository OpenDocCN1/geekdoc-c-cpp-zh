# Using fstream Objects

In fstream and ofstream objects, the input or output mode is indicated by the object. Therefore, fstream objects must be used for input, and ofstream objects must be used for output. Another means of creating file streams is to use fstream objects that can be used for input or output, but this method requires explicit mode designation. An fstream object is declared by using the following syntax:

```
fstream objectName;
```

When using fstream class's open() method, two arguments are required: the file's external name and a mode indicator. Here are the permissible mode indicators:

| Indicator | Description |
| --- | --- |
| ios:: | Open a file in input mode |
| ios:: | Open a file in output mode |
| ios::app | Open a file in append mode |
| ios::ate | Go to the end of the opened file |
| ios::binary | Open a binary file in input mode (default is text file) |
| ios::trunc | Delete contents if it exists |
| ios::ncreate | If file doesn't exist, open fails |
| ios::noreplace | If file exists, open fails |

As with ofstream objects, an fstream object in output mode creates a new file and makes the file available for writing. If a file exists with the same name as a file opened for, the old file is erased. For example, the following statement declares file1 as an object of type fstream:

```
fstream file1;
```

The following statement attempts to open the file prices.dat for output:

```
file1.open("prices.dat",ios::out);
```

After this file has been opened, the program accesses the file by the internal name file1, and the computer saves the file under the external name prices.dat.

An fstream object opened in append mode means an fstream is available for data to be added to the end of the file. If the file opened for appending doesn't exist, a new file with the designated name is created and made available to receive output from the program. For example, the following statement declares file1 to be of type fstream and attempts to open a file named prices.dat and make it available for data to be added to the end of the file:

```
file1.open("prices.dat",ios::app);
```
