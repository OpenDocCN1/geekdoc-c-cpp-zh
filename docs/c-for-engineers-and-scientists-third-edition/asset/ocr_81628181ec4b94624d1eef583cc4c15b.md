# Arrays as Arguments

Array elements are passed to a called function in the same manner as scalar variables; they are included as subscribed variables when the function is called. For example, the following function passes the values of the elements volts[2] and volts[6] to the function findMin():

```
findMin(int volts[2], int volts[6]);
```

Passing a complete array of values to a function is, in many respects, easier than passing each element. The called function receives access to the actual array rather than a copy of values in the array. For example, if volts is an array, the function call makes the entire array available to the findMax(). This function is different from passing a single variable to a function.

Recall when a scalar argument is passed to a function (see Section 6.1), the called function receives only a copy of the passed value, which is stored in one of the parameters. If arrays were passed in this manner, a copy of the complete array would have to be created. For large arrays, making copies for each function would waste computer storage and the effort to return multiple-element changes made by the program. (Remember that a function returns at most one direct value.)

To avoid these problems, the called function gets direct access to the array. In this way, any changes the called function makes are made directly to the array. For the arrays, keys, volts, and current are declared as follows:

```
int nums[5];                  // an array of five integers
char keys[256];               // an array of 256 characters
double volts[500], current[500]; // two arrays of 500 doubles
```

> ³The called function has access to the original array because the array's starting address is actually passed as an argument. The formal parameter receiving this address is a pointer. Chapter 12 explains the relationship between array names and pointers.
