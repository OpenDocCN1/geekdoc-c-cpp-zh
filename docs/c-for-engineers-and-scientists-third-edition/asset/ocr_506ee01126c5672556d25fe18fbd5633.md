# 308 Modularity Using Functions

# Program 6.3

```
#include <iostream>
using namespace std;

template <class T>
void showabs(T number)
{
    if (number < 0)
        number = -number;
    cout << "The absolute value of the number is "
        << number << endl;
    return;
}

int main()
{
    int num1 = -4;
    float num2 = -4.23f;
    double num3 = -4.23456;

    showabs(num1);
    showabs(num2);
    showabs(num3);

    return 0;
}
```

Notice the function calls made in the main() function; they call the function showabs() with an integer, float, and double. Now review the function template for showabs() and look at the first line, template <class T>. This line, called a template prefix, is used to inform the compiler that the function immediately following uses a data type named T. The function is created in the same manner as any other data type, such as int, float, and double. When the compiler encounters an actual function call for showabs(), the data type of the argument passed in the call is substituted for T throughout the function. The compiler creates a specific function, using the template, that accepts the argument in the call.

Because Program 6.3 makes three calls to showabs(), each with a different argument type, the compiler creates three showabs() functions. The compiler knows which function to use based on the arguments passed at the time of the call. This is the output displayed when Program 6.3 runs:

The absolute value of the number is 4
The absolute value of the number is 4.23
The absolute value of the number is 4.23456
