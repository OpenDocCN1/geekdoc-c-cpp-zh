A different check is required for output files (that are written to) because if a file exists with the same name as the file to be opened in output mode, the existing file is erased and all its data is lost. To avoid this situation, the file is first opened in input mode to see whether it exists. If it does, the user has the choice of permitting it to be overwritten when it's opened later in output mode.
