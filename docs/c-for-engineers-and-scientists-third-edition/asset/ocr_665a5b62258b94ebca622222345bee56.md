# 5.4 for Loops

In C++, a for loop is constructed by using a for statement. This statement performs the same functions as the while statement but uses a different form. In many situations, especially those with a fixed-count condition, the for statement is easier to use than its while equivalent. This is the syntax of the for:

for (initializing list; altering list) statement:

Although the for statement looks a little complicated, it's really simple if you consider each part separately. In the parentheses of the for statement are three items, separated by semicolons. Each item is optional and can be described separately, but the semicolons must be present, even if you don't use the items.
