The initialization of the names and phone numbers for each structure defined in Program 13.8 is straightforward. Although each structure consists of three members, only the first two of each are initialized. As these members are arrays of characters, they can be initialized with strings. The remaining member of each is a pointer. To create a linked list, each structure pointer must be assigned the address of the next structure in the list.

The few assignments in Statement 13.8 perform the correct assignments. The expression first = t1 stores the address of the first structure in the list for the first variable. The expression t1.nextaddr = &lt;t2 stores the starting address of the t2 structure in the pointer member of the t1. Similarly, the expression t2.nextaddr = &lt;t3 stores the starting address of the t3 structure in the pointer member of the t2 structure. To end, the value of the NULL pointer, which is 0, is stored in the pointer member of the t3 structure.

After values have been assigned to each member and correct addresses have been stored in the appropriate pointers, the addresses in the pointers are used to access each structure’s name member. For example, the expression t1.nextaddr->name refers to the name member of the structure whose address is in the nextaddr member of the t1 structure.
