```cpp
#include <iostream>
#include <fstream>
#include <cstdlib>
#include <string>
using namespace std;

int main() {
    string fname = "list.dat"; // here is the file you are working with
    void inOut(ostream& outFile); // function prototype
    ofstream outFile;

    outFile.open(fname.c_str());

    if (outFile.fail()) // check for a successful open
    {
        cout << "\nThe output file " << fname << " was not successfully opened" << endl;
        exit(1);
    }

    inOut(outFile); // call the function

    return 0;
}

void inOut(ostream& outFile) {
    const int NUMLINES = 5;
    string line;
    int count;

    cout << "Please enter five lines of text:" << endl;
    for (count = 0; count < NUMLINES; count++)
    {
        getline(cin,line);
        outFile << line << endl;
    }

    return;
}
```


470 I/O Streams and Data Files

In main(), the file is an ofstream object named outFile. This object is passed to the inOut() function and accepted as the formal parameter fileOut, which is declared to be a reference to an ofstream object. The inOut() function then uses its reference fileOut as an output file stream in the same manner that main() would use the outFile object. Program 8.8 uses the getOpen() method introduced in Section 8.2 (see Table 8.3).

Program 8.9 expands on Program 8.8 by adding a getOpen() function to perform the operation. Like inOut(), getOpen() accepts a reference argument to an ofstream object. After the getOpen() function finishes, this reference is passed to inOut(), as in Program 8.8. Although you might be to write getOpen() to return a reference to an ofstream, it won't work because it results in an attempt to assign a reference to an existing one.

```cpp
int getOpen(ostream& fileOut)
{
    string name;

    cout << "\nEnter a file name: ";
    getline(cin, name);

    fileOut.open(name.c_str());                   // open the file

    if (fileOut.fail())                        // check for successful
    {
        cout << "Cannot open the file" << endl;
        exit(1);
    }
    else
        return 1;
}
```

```cpp
void inOut(ostream& fileOut)
{
    const int NUMPLIES = 5;                    // number of lines
    int count;
    string line;

    cout << "\nPlease enter five lines of text:" << endl;
    for (count = 0; count < NUMPLIES; ++count)
    {
        getline(cin, line);
        fileOut << line << endl;
    }

    cout << "\nThe file has been successfully written.";

    return;
}
```

Program 8.9 allows the user to enter a filename from the standard input device and then opens the ofstream connection to the external file. If an existing data file's name is entered, the file is destroyed when it's opened for output. A useful trick for preventing this mishap is to open the entered file using an input file stream. If the file exists, the fail() method indicates a successful open (that is, the open doesn't fail), which indicates the file is available for input. This technique can be used to alert the user that the entered name exists in the system and to request confirmation that the data in the file can be destroyed and the file opened for output. Before the file is reopend for output, the input file stream should be closed. Implementing this trick is left for you to try in Exercise 4.

# 8.5 A Case Study: Pollen Count Update

After a file is created, the program is used to update. In this case, the average of the most recent pollen counts is computed.

# Step 1 Analyze the Problem

Pollen counts are taken from August through September. In this time, a new count is added to the file, and the oldest count is then deleted. Additionally, the average of the most recent pollen counts is computed. The input data for this problem consist of 10 numbers. There are required outputs:

- A file of the most recent pollen counts
- The average of the file

>This type of data storage is formatted as first-in/first-out (FIFO) list, also called a "queue". If the file is maintained in last-in/first-out order (LIFO), it's called a "stack".

# Step 2 Develop a Solution

The algorithm for solving this problem is straightforward and is described by the following pseudocode:

```
main() function
  Display a message indicating what the program does.
  Call the input stream function.
  Call the Output stream function.
  Call the Update function.
  Display the 10-week average.
Input stream function
  Request the name of the input data file.
  Open an input file stream and validate a successful connection.
Output stream function
  Request the name of the output data file.
  Open an output file stream and validate a successful connection.
Update function
  Request a new pollen count reading.
  Read the oldest pollen count from the input data file.
  For the remaining input file pollen counts:
    Read an input value.
    Add the value to a total.
    Write the input value to the output stream.
Endfor
  Write the new pollen count to the output stream.
  Add the new pollen count to the total.
  Calculate the average as total / (number of pollen counts).
  Return the 10-week average.
  Close all files.
```

In reviewing this algorithm, notice that the oldest pollen count is "captured" in a total, and never used in any computation. The most recent pollen counts are read and written to the output data file. Finally, the last pollen count is then added to the total and also written to the output data file. Finally, the average of the most recent pollen counts is computed and displayed, and all file streams are closed.
