# 8.5 A Case Study: Poll Count File Update

After a file has been created, application programs are typically written to read and update the file with current data. In this case study, a file is used as a database for storing the 10 most recent poll counts, which are used in the summer as "irritability" measures. With a new reading, it's added to the file, and the oldest record is deleted.

# Step 1 Analyze the Problem

Poll count readings, are taken from August through September in the northeastern United States, measure average of ragged pollen grains in the air. Poll counts in the range of 10 to 200 grains per cubic meter of air are normal during this time of year.
