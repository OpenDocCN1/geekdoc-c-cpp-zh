Similarly, if the function is to receive two single-precision parameters and return a single-precision value, this is the correct function header:

```
float findMax(float x, float y)
```

If the function is to receive two double-precision parameters and return a double-precision value, the function header would be the following:

```
double findMax(double x, double y)
```

Now see how to modify the findMax() function to return the maximum value of the two numbers passed to it. Do must first determine the data type of the value to be returned and include this data type in the function header. Because the maximum value determined by findMax() is stored in the integer variable, the function should return this variable's value. Returning an integer value from findMax() requires the following declaration:

```
int findMax(int x, int y)
```

Observe that it is the same as the original function header for findMax(), with the keyword int substituted for the keyword void.\ Having declared the data type that findMax() will return, all that remains is including a statement in the function to cause the return of the correct value. To return a value, a function must use a return statement, which has this form:

```
return expression;
```

When the return statement is encountered, the expression is evaluated first. The value is automatically converted to the data type declared in the function header before sent back to the calling function. After the value is returned, program control returns to the calling function. Therefore, to return the value stored in maximum, all you need to do is include the statement return maximum; before the closing brace of the findMax() function. The complete code is as follows:

```
int findMax(int x, int y) // function header
{
    int maximum;
    if (x >= y)
        maximum = x;
    else
        maximum = y;
    return maximum; // return statement
}
```

> The return type is related to the parameter data types only as much as the returned value is typically determined by the parameter values. In this case, because the function is used to return the maximum value of its parameters, it would make little sense to return a data type that doesn't match the function's parameter data types.
¹⁰Many programmers prefer the expression in parentheses, as in return (expression); Although either (with or without parentheses) can be used, choose one and stay with it for consistency.
