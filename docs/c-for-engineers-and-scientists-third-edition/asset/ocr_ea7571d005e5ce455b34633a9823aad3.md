Removing a structure from the ordered list is the reverse of adding a record. The actual record is removed from the list by changing the address in the structure preceding it to point to the structure immediately after the deleted record.
Each structure in a linked list has the same format, however, it's clear the last record can't have a valid pointer value that points to another record because there's no other record. C++ provides a special pointer value called NULL that acts as a sentinel or flag to indicate when the record has been processed. The NULL pointer value, like its end-of-string counterpart, has a numerical value of 0.
