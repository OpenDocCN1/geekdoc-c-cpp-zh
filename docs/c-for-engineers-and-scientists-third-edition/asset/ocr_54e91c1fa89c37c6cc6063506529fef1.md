# 310 Modularity Using Functions

# Program 6.4

```
#include <iostream>
using namespace std;

template<class T> // template prefix
T abs(T value)      // header line
{
    T absnum; // variable declaration

    if (value < 0)
        absnum = -value;
    else
        absnum = value;

    return absnum;
}

int main() {
    int num1 = -4;
    float num2 = -4.23f;
    double num3 = -4.23456;

    cout << "The absolute value of " << num1 << endl;
    cout << " is " << abs(num1) << endl;
    cout << "The absolute value of " << num2 << endl;
    cout << " is " << abs(num2) << endl;
    cout << "The absolute value of " << num3 << endl;

    return 0;
}

```

In the first call to abs(0) made within main(), an integer value is passed as an argument. In this case, the compiler substitutes an int data type for the T data type in the function template creates the following function:

```
int abs(int value) // header line
{
    int absnum; // variable declaration
    if (value < 0)
        absnum = -value;
    else
        absnum = value;
    return absnum;
}
```
