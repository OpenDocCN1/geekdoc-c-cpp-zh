## 8.3 Random File Access

The file access refers to the process of retrieving data from a file. There are two types of file access: sequential access and random access. To understand file access types, you first need to understand how data is organized in a file.

The file organization refers to the way data is stored in a file. The files you have used, and will use to come, use a sequential organization, meaning characters in the file are stored in in a sequential manner. In addition, each file has been read in a sequential manner, meaning characters are accessed one after another, which is called access. Although characters are stored sequentially, they don't have to be accessed the same way. In fact, you can skip over characters and read a sequentially filed file in a nonsequential manner.

In random access, any character in the opened file can be read without having sequentially read all ahead of it. To provide random access to files, ifstream creates a file position marker automatically. This is a longer integer representing an offset from the beginning of the file and keeps track of where the next character is to be read or written to. Table 8.4 lists the methods used to access and change the file position marker. The suffixes g and p in these methods denote get and put; get refers to an input (get from file), and put refers to an output (put to file).

Table 8.4 File Position Methods

| Name | Description |
| :--- | :--- |
| seek(offset, mode) | For input files, move to the offset position indicated by the mode. |
| seekp(offset, mode) | For output files, move to the offset position indicated by the mode. |
| tellg(void) | For input files, return the current value of the file position marker. |
| tellp(void) | For output files, return the current value of the file position marker. |

The seek() methods allow the programmer to move to any position in the file. To understand these methods, you must understand how data is referenced in the file using the file position marker.

Each character in a data file is located by its position in the file. The first character in the file is located at position 0, the next at position 1, and so forth. A character's position is referred to as its offset from the start of the file. Therefore, the first character has an 0 offset, the second character has an offset of 1, and so on, for each character in the file.

The seek() methods require two arguments: the offset, as a long integer, in the file and where the offset is to be calculated, determined by the mode. The three alternatives for the mode are ios::beg, ios::cur, and ios::end, which denote the beginning of the file, current position, and end of the file. Therefore, the mode ios::beg means the offset is the true offset from the start of the file. The mode ios::cur means the offset is relative to the current position in the file, and the mode ios::end means the offset is relative to the end of the file. A positive offset means move forward in the file, and a negative offset means move backward.

Examples of seek() method calls are shown in the following code. In these examples, inFile has been opened as an input file and outFile as an output file. The offset passed to seek() and tell() must be a long integer, hence the uppercase L appended to each number in the code.

```cpp
inFile.seekg(4L, ios::beg);   // go to the fifth character in the input file
out.seek(4L, ios::beg);   // go to the fifth character in the output file
inFile.seekg(4L, ios::cur);    // move ahead five characters in the input file
out.seek(4L, ios::cur);    // move ahead five characters in the output file
inFile.seekg(-4L, ios::end); // move back five characters in the input file
out.seek(-4L, ios::end); // move back five characters in the output file
inFile.seekg(0L, ios::beg);   // go to the start of the input file
out.seek(0L, ios::beg);   // go to the start of the output file
inFile.seekg(0L, ios::beg);   // go to the start of the input file
out.seek(0L, ios::beg);   // go to the start of the output file
inFile.seekg(0L, ios::end);   // move to the end of the input file
out.seek(0L, ios::end); // move to the end of the output file
inFile.seekg(-10L, ios::end); // move back ten characters in the input file
out.seek(-10L, ios::end); // move back ten characters in the output file
```
