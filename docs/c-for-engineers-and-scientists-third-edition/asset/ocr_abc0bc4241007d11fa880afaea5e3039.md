# 2.2 Programming Style

C++ programs start at the beginning of the main() function. Because a program can have only one starting point, every C++ program must contain one and only one main() function. As you have seen, all the statements making the main() function are within the braces following the function name. Although the main() function must be present in every C++ program, C++ doesn't require placing the word main, the parentheses, or the braces in any particular form.
