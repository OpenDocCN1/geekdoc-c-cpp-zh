- 15. (数值) a. 欧算法算法使用以下步骤：

第一步：将较大的除以较小的并保留余数。
第二步：将较小的除以余数，再次保留余数。
第三步：继续用上一个余数除以当前余数，直到余数为零，此时最后一个非零余数为 GCD。

例如，如果两个整数是 84 和 49，你得到：

第一步：84/49 的余数为 35。
第二步：49/35 的余数为 14。
第三步：35/14 的余数为 7。
第四步：14/7 的余数为 0。

因此，最后一个非零余数 7 是 84 和 49 的 GCD。
