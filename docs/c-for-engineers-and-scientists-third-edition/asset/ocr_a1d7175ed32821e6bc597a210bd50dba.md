Preliminary Four: Algorithms

To understand how an algorithm works, consider a simple problem: A program must calculate the sum of all numbers from 1 through 100. Figure 1.5 illustrates three methods you could use to find the required sum. Each method constitutes an algorithm.

# Method 1 - Columns: Arrange the numbers from 1 to 100 in a column and add them

+   1
2
3
4
...
98
99
+100
5050

# Method 2 - Groups: Arrange the numbers in groups that sum to 101 and the number of groups by 101

```
1 + 100=101
2 + 99=101
3 + 98=101
4 + 97=101
...\ groups
49 + 52=101
50 + 51=101
```

# Method 3 - Formula: Use the formula

```
n(a + b)
sum=2
where number of terms to be added (100)
a=first number to be added (1)
b=last number to be added (100)
sum=100(1 + 100)/2 = 5050
```
