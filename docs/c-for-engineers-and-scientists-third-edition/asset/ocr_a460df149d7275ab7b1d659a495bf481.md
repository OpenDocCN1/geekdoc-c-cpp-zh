An alternative to this fixed or static allocation of memory storage locations is dynamic allocation of memory. Under a dynamic allocation scheme, the amount of store to be allocated is determined and adjusted at runtime rather than compile time. Dynamic allocation of memory is useful when dealing with lists because it expands the list as new items are added and contracting the list as items are deleted. For example, constructing a fixed array where you don't need to know the exact number of grades. Instead of enlarging and shrinking the array as needed is useful. Table 12.2 describes C++ operators, new and delete, that provide this capability. (These operators require the new header file).

Dynamic storage for scalars variables or arrays are also part of a declaration or an assignment statement. For example, the declaration statement *num = new; reserves an area to hold one integer and places this array's address in the pointer num. This dynamic allocation can also be made by first declaring the pointer with the declaration statement *num; and then assigning the pointer with the assignment statement *num = new; In either case, the allocated storage comes from the computer's free storage area.

Dynamic allocation of arrays is similar but more useful. For example, the declaration int *grades = new int[200];
