Refinements to the Bisection Method

In the figure, the root is to the left of $x_2$, so the interval used for the next iteration is

```
$x_3 = x_2\nf_3 = f_2\nf_2 = f(x_2)$
```

In other words, to use this slightly faster bisection algorithm, the only change that has to be made\nto the previous bisection code is replacing statements of the form

```
$x_2 = (x_1 + x_2) / 2$
```

by a statement of this form:

```
$x_2 = x_1 - (x_2 - x_1) \frac{f_1}{f_1 - f_2}$
```

This method is still guaranteed to obtain a root eventually and almost always converges\nthan the conventional bisection method. However, you pay a small price. The\nvalue of $f_1$ and $f_2$ in using for $x_i$ might be nearly equal, and you could be plagued by\nround-off errors in their difference. In the bisection method, you could predict with\nsome precision the number of iterations required to find the root to a certain accuracy (see\nSection 14.1). This prediction is no longer possible if you use the interpolated values, so the\ncode must include a check for excessive iterations.

This method shows that a change in the algorithm, which is based on more intelligent\nmonitoring of the function, can reap considerable rewards in more rapid convergence. The formal\nname of this method is the **regula falsi method** (the method of false position).
