# 15.3 The Exclusive OR Operator

The exclusive OR operator, performs a bit-by-bit comparison of its operands. The result of the comparison is determined by the following rule: The result of the comparison is 1 if one, and one of the bits being compared is 1; otherwise, the result is 0.
as shown in the following example of an exclusive OR operation, when both bits are compared the same value (both 1 or both 0), the result is 0. When both bits have different values (one 1 and the other 0) the result is 1. Again, each pair or bit comparison is independent of any other bit comparison.

```
0 0 1 1 0 0 1
^ 1 1 0 1 0 1 1
- - - - - - -
0 1 1 0 1 1 0
```

An OR operation can be used to create the opposite value, or complement, of any bit in a variable. The reason is that exclusive OR any bit (1 or 0) with 1 forces the resulting bit to be the opposite value of its original state, and exclusive OR any bit (1 or 0) with 0 leaves the original unchanged. For example, the variable op1 has the pattern x x x x x x x; each can be 1 or 0, independent of any other x in the number. Using the notation that x is the (opposite) value of x, the result of exclusive ORing with the binary number 0 1 0 1 0 1 0 1 is as follows:

```
op1 = x x x x x x x
op2 = 0 1 0 1 0 1 0
```

```
Result = x x x x x x x
```

As you can see in this example, the Is in op2 force the resulting bits to be the complement of their original bit values, and the 0s in op2 filter, the bits in op1 through no change in their values.
