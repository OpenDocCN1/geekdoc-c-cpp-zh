## Point of Information

### When to Use an Array or a Vector
Array is the data structure of first choice when you have a list of primitive data types or objects that don't have to be expanded or contracted. Vector is the data structure of first choice when you have a list of primitive data types or objects that can be grouped as an array but must be expanded or contracted.

Whenever, use STL algorithms to operate on arrays and vectors. STL classes and algorithms provide verified and reliable code that can shorten program time.

Notice that there's both swap algorithm (Table 7.2) and a swap() function (Table 7.1). Because a function is targeted to work specifically with its container type and generally executes faster when a container provides a function with the same name as an algorithm, you should use the class functions.

Finally, the STL provides additional items referred to as iterators, to specify which elements in a container are returned the most useful elements are returned by the STL iterator functions begin() and end(). These general-purpose functions return the position of the first and last elements in a container.

To better understand using any container see how to use the vector container class to a vector holding a list of part numbers. As you'll see, a vector is similar to a C++ array, except it can manually be expanded.

The following statement in Program 7.11 is used to create and initialize the vector partumns:

```cpp
vector<int> partumns(n, n + NUMBELS);
```

The vector partumns is declared as a vector of type int[] and initialized with elements from the n array, starting with the first element n[0] and ending with the last element, located at position n-NUMBELS. Therefore, the size is large enough for four integer values and has been initialized with the integers 136, 122, 109, and 146.

The next set of statements in Program 7.11 displays the initial values in the vector by using standard subscript to notation for accessing array elements. Displaying vector values in this manner requires knowing how many elements each vector contains. As you insert and remove elements, you would like the vector to track the first and last elements' locations. This capability is provided automatically by the two STL iterators functions mentioned previously: begin() and end().

The next major set of statements consists of the following:

```cpp
// modify the element at position 4 (i.e. index = 3) in the vector
partumns[3] = 144;
```

```cpp
// insert an element into the vector at position 2 (i.e. index = 1)
partumns.insert(partumns.begin()+1, 142);
```

These statements are used to modify an existing vector value and insert a new value into the vector. Specifically, the partumns[3] notation uses standard indexing, and the insert() function uses an iterator argument, which is constructed as an offset by using the begin() or end() function. Additionally, you have to specify the value to be inserted at the designated position. Therefore, partnums[3] specifies changing the fourth element in the vector. (Vectors, like arrays, begin at index position 0.) The insert() function is used to insert the integer value 142 in the second position. Because the begin() function returns a value corresponding to the start of the vector, adding 1 to it denominates the vector's second position. At this position, the new value is inserted. All subsequent values are moved up by one position in the vector, and the vector expands automatically to the inserted value. At this point in the program, partnums now contains the following elements:

136 142 122 109

This arrangement of values was obtained by replacing the original value 146 with 144 and inserting the 142 into the second position, which moves all subsequent elements automatically by one and increases the total vector size to five integers.

Next, the statement partnums.push_back(157); is used to append the integer 157 to the end of the vector, which results in the following elements:

136 142 122 109 144 157

Finally, the last section of code in Program 7.11 uses the sort() algorithm to sort elements in the vector. After the algorithm is applied, the vector's values are displayed again. Following is the complete output Program 7.11 produces:
