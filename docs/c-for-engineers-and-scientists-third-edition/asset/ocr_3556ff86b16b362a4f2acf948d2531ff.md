# Inline Functions¹¹

Calling a function places a certain amount of overhead on a computer. This overhead consists of the following steps:

+   1. Placing values in a reserved memory region (the stack) that the function has access to
2. Passing control to the function
3. Providing a reserved memory location for any returned value (again, using the stack for this purpose)
4. Returning to the correct point in the calling program

Paying this overhead is justified when a function is called many times because it can reduce a program's size substantially. Instead of the same code whenever each time it's needed, the code is written once, and called whenever it's needed.
For small functions that aren't called many times, however, the overhead of passing and returning values might not be worth it. By grouping lines of code under a common function name and having the compiler place this code in the program when the function is called, **inline functions** provide this capability.
