Strings in C++ are any combination of letters, numbers, and special characters enclosed in quotation marks ("string in here"). The quotation marks delimit (mark) the beginning and ending of the string and aren't considered part of the string. Therefore, the string of characters making the message sent to cout must be enclosed in quotation marks, as was done in Program 2.1.

# Program 2.2

```
#include <iostream>
using namespace std;

int main()
{
    cout << "Computers, computers everywhere";
    cout << "\n as far as I can C";

    return 0;
}
```

When Program 2.2 is run, the following is displayed:

Computers, computers everywhere
as far as I can C

You might be wondering whether the \n didn't appear in the output. The characters \ and n, when used, are called a newline sequence. They tell cout to send instructions to the display device to the beginning of a new line. Otherwise, the second cout statement would simply append characters to the previous statement's characters; it doesn't start on a new line by itself. In C++, the backslash (\) provides an "escape" from the normal interpretation of the character it alters its meaning—in this case, the n. If the backslash were omitted from the second cout statement in Program 2.2, the n would be printed as the letter "n" and the program would output following:

Computers, computers everywhere as far as I can C
