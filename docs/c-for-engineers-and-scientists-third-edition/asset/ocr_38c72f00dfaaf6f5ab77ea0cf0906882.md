Now assume you want to pass three separate strings—three mice—to PGMD-1’s main() function. Sending arguments to a main() function is easy; simply include the arguments on the command line to begin execution. Because the arguments are typed on the command line, they’re called command-line arguments. To pass the arguments three mice to the main() function of the PGMD-1 program, add them after the program name, as shown:

```
C:\>PGMD-1 three mice
```

When the operating systems command this line, it stores the prompt as a sequence of four strings. (Some systems also store the prompt as part of the first string.) Figure D.2 illustrates the storage of these strings, using each character 1 byte of storage. As shown, each string terminates with the standard C++ null character, \0.

Sending command-line arguments to main() is always this style. Type the arguments on the command line, and the operating system them as a sequence of separate strings. See how to handle the receiving side of the data and let main() know that the arguments are passed to it.

Arguments passed to main(), like all functions, must be declared as part of the function’s definition. To standardize passing arguments to a main(), only two items are allowed: a number and an array. The array is a one-dimensional list, which is named argc (for argument counter), and the array is named argv (for argument values). Figure D.3 illustrates these two arguments.

The integer passed to main() is the total number of items on the command line. In this example, the value of argc passed to main() is 4, which includes the number of the program plus the three command-line arguments.
