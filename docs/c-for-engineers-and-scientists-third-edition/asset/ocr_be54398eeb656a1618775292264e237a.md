When to Use an Array or a Vector
Array is the data structure of first choice when contracted you have a list of primitive data types or objects that don't have to be expanded or contracted. Vector is the data structure of first choice when you have a list of primitive data types or objects that can be grouped as an array but must be expanded or contracted.
Whenever, use STL algorithms to operate on arrays and vectors. STL classes and algorithms provide verified and reliable code that can shorten program time.

Notice that there's both swap algorithm (Table 7.2) and a swap() function (Table 7.1). Finally, the STL provides additional items referred to as iterators, to specify which elements in a container are returned the most useful elements are returned by the STL iterator functions begin() and end(). These general-purpose functions return the position of the first and last elements in a container.
