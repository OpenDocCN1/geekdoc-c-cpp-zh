# Program 6.5

```
#include <iostream>
using namespace std;

int findMax(int, int); // the function prototype

int main() {
    int firstnumber, secnum, max;

    cout << "\nenter a number: ";
    cin >> firstnumber;
    cout << "nGreat! Please enter a second number: ";
    cin >> secnum;

    max = findMax(firstnumber, secnum); // the function is called here

    cout << "\nThe maximum of the two numbers is " << max << endl;
    return 0;
}

int findMax(int x, int y) { // start of function body
    int maxnum; // variable declaration

    if (x >= y) // find the maximum number
        maxnum = x;
    else
        maxnum = y;

    return maxnum; // return statement
}
```

In reviewing Program 6.5, note the items introduced in this section. First, the prototype for findMax() is a statement ending with a semicolon, as all declarations do; it alerts main() and any subsequent functions using findMax() to the data type findMax() returns. Second, an assignment is used in main() to store the returned value from the findMax() call in the variable max. In Program 6.5, max is correctly declared as an integer in main()'s variables so that it matches the returned value's data type.
