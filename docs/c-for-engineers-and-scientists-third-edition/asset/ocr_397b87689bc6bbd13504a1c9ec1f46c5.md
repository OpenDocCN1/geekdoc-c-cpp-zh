# 13.6 Unions

A union is a data type that reserves the same area in memory for two or more variables that can be different types. A variable declared as a union type can be used to hold a character variable, an integer variable, a double-precision variable, or any other valid C++ data type. Each of these types, but only one at a time, can be assigned to the union.

The definition of a union has the same form as a structure definition, with the keyword union used in place of the keyword struct. For example, the following declaration creates a union variable named:

```
union
  char key;
  int num;
  double volts;
};
```

If val were a structure, it would consist of a single member that could be a character variable named key, an integer variable named num, or a double-precision variable named volts. A union reserves enough memory locations to accommodate its largest member's data. This set of locations is then referenced by different names, depending on the data type of the value currently stored in the reserved location. Each value overwrites the previous value, using as many bytes of the memory as necessary.

Union members are referenced by the same notation as structure members. For example, if the union is used to store a character, the correct variable name to access the structure character is val.key. Similarly, if the union is used to store an integer, the value is accessed by the name val.num, and a double-precision value is accessed by the name val.volts. In using union members, it's the programmer's responsibility to make sure the correct member name is used for the data type currently stored in the union.
