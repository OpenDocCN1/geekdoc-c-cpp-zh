The char Data Type The char data type is used to store single characters, including the letters of the alphabet (uppercase and lowercase), the digits 0 through 9, and special symbols, such as + - * . . and ! A character value is any single letter, digit, or special symbol enclosed by quotation marks, as is shown in these examples:

```
'A' '$' 'b' '7' 'y' '!' 'M' 'q'
```

Character values are typically stored in a computer by using ASCII Unicode codes. The ASCII (American Standard Code for Information Interchange, pronounced "as-key") provide codes for the English-language character set plus printer and display control, such as newline and printer page codes. Each character code is contained in a single byte, which provides 256 distinct codes. Table 2.3 shows the ASCII byte codes for uppercase letters.
Additionally, C++ provides for the Unicode code which uses 2 bytes per character and can represent 65,536 characters. This code is used for international purposes because it includes character sets for other languages in addition. As the first 256 Unicode codes have the same numerical value as the 256 ASCII codes (the additional byte is coded with all zeros), you don't need to be concerned with storage code to use with English-language characters.
