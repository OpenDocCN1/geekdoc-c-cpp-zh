The length data member of the Cylinder object isn't used in the assignment because it has no equivalent value in the Circle class. The reverse cast, from base to derived class, isn't simple and requires a constructor to correctly initialize the derived class members that aren't in the base class.

Before leaving Program 11.14, one point should be made. Although the Circle constructor was called explicitly using a base/member initialization list for the Cylinder constructor, an implicit call could have been made. In the absence of an explicit derived class constructor, the compiler automatically calls the default base class constructor first, before the derived class constructor is called. This order of calling works because the derived class contains all the base class members. In a similar fashion, destructor functions are called in the reverse order—first derived class and then base class.

## 11.7 Polymorphism

Overriding a base member function by an overloaded derived member function, as shown with the calcval() function in Program 11.14, is an example of polymorphism. As defined previously, polymorphism permits the same function name to invoke different response in a base class's objects and another response in a derived class's objects. In some situations, however, this method of overriding doesn't work the way you might want. To understand why, take a look at Program 11.15.

## 654 Class Functions and Conversions

```cpp
double One::f1(double num) // a member function
{
    return(num/2);
}
double One::f2(double num) // another member function
{
    return(pow(num,2)); // square the result of f1()
}

// class declaration section for the derived class
class Two : public One {
public:
    virtual double f1(double num); // this overrides class One's f1()
};
// class implementation section for Two
double Two::f1(double num)
{
    return(num/3);
}

int main() {
    One object_1; // object_1 is an object of the base class
Two object_2; // object_2 is an object of the derived class

    // call f2() using a base class object call
    cout << "The computed value using a base class object call is "
         << object_1.f2(12) << endl;

    // call f2() using a derived class object call
    cout << "The computed value using a derived class object call is "
         << object_2.f2(12) << endl;

    return 0;
}
```
