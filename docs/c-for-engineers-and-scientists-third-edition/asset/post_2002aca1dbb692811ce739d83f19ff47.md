The first step in creating a library is to encapsulate all the specialized functions and classes into one or more namespaces and store the complete code (with or without a namespace) into one or more files. For example, you can create one namespace, dataChecks, and save it in the file named dataChecks.cpp. Note that the namespace filename need not be the same as the namespace used in the code.
The syntax for creating a namespace is the following:

```cpp
namespace name
{
    // functions and/or classes in here
} // end of namespace
```

// namespace has been created and stored in a file, it can be included in another
file by supplying a preprocessor directive to inform the compiler where the namespace is
found and by using a using directive that tells the compiler which namespace is in the file
use. For the dataChecks namespace, which is stored in a file named dataChecks.cpp, the following statements perform this task:

```cpp
#include <c:\mylibrary\dataChecks.cpp>
using namespace dataChecks;
```

The first statement provides the full pathname for the source code. Notice that two
backslashes are used to separate items in paths. The double backslashes are required
when providing a relative or full pathname. The only time backslashes aren't required is
when the library code is in the same directory as the program being executed. As indicated,
dataChecks source file is saved in the mylibrary folder. The second statement tells
the compiler to use the dataChecks namespace in the designated file. Program 9.20
includes these two statements in an executable program.
