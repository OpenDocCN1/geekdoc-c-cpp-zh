At the return, the pointer member of the current structure is assigned the address of the next structure in the list, which is obtained from new. The call to new creates the next structure and returns its address to the pointer member of the current structure. This call completes the population of the current member. Just as we create storage dynamically at runtime, the delete operator restores a block of storage to the computer at runtime. The only argument delete requires the starting address of a storage block that was allocated dynamically. Therefore, any address returned can be passed sequentially to delete to restore the reserved memory to the computer. The delete operator does not alter the address passed to it; it simply removes the storage that address references.

# 13.6 Unions

A union is a data type that allows you to store different types of data in the same memory location. The size of the union is the size of its largest member. Only one member can be used at a time. The syntax for defining a union is similar to a structure, but the keyword union is used instead of struct.

```cpp
union {
  char key;
  int num;
  double volts;
};
```

When you define a union, the compiler allocates enough memory to hold the largest member. However, all members share the same memory address. When you assign a value to one member, it will overwrite the values of any other members. This is useful when you have a variable that can hold one of several types, but only one type at any given time.

For example, the following declaration

```cpp
union DateTime {
    int days;
    double time;
};
```

provides a union data type without reserving any storage locations. This data type can be used to define any number of variables. For example, the definition

DateTime first, second, *pt;

creates a union named first, a union named second, and a pointer that can be used to store the address of any union having the DateTime. After a pointer to a union has been declared, the same notation for accessing structure members can be used to access union members. For example, if the assignment pt = &first; is made, pt->days refers to the data member of the union first.

Unions can be members of structures or arrays, and structures, arrays, and pointers can be members of unions. In each case, the notation used to access a member must be consistent with the nesting used. For example, in the structure defined

```cpp
struct {
    char uType;
    union {
        char *text;
        float rate;
    } uTax;
    int flag;
} flag;
```

the variable rate is referenced as

```cpp
flag.uTax.rate
```

Similarly, the first character of the string address is stored in the pointer text is referenced as follows:

```cpp
*flag.uTax.text
```
