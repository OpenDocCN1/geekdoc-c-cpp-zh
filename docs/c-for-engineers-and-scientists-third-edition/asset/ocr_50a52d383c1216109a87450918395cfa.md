Reading and Writing Character-Based Files

# Program 8.6

```
#include <iostream>
#include <fstream>
#include <cstdlib> // needed for exit()
#include <string>
using namespace std;

int main() {
    string filename = "prices.dat"; // put the filename up front
    string line;
    ifstream infile;

    infile.open(filename.c_str());

    if (infile.fail()) // check for successful open
{
        cout << "\nThe file was not successfully opened"
             << "\nn Please check that the file currently exists."
             << endl;
        exit(1);
    }

    // read and display the file's contents
    while (getline(infile, line)) {
        cout << line << endl;
    }

    infile.close();

    return 0;
}
```

# Standard Device Files

The file streams you have seen so far have been logical file objects. A logical file object is a stream that connects to logically related data, such as a data file, to a program. In addition to logical files, C++ supports physical file objects. A physical file object is a stream that connects to a hardware device, such as a keyboard, screen, or printer.

The actual device assigned to the program for data entry is called the standard input file. Usually, it's the keyboard. When a cin method call is encountered in a C++ program, it is a request to the OS to go to this standard input for the expected input. Similarly, when a cout method call is encountered, the output is automatically displayed or "written to" a device that has been assigned as the standard output file. For most systems, it's a computer screen, although it can be a printer.
