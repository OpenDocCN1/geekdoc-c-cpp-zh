```
int *calc()
```

```
double *taxes()
```

In addition to declaring pointers to integers, double-precision numbers, and C++s other data types, you can declare pointers that point to (contain the address of) a function. Pointers to functions are pointers because function names, like array names, are pointer constants. For example, the declaration

```
int (*calc())
```

declares calc to be a pointer to a function that returns an integer. This means calc contains the address of a function, and whose address is the variable calc returns an int. If, for example the function sum() returns an integer, the assignment calc = sum; is valid.
