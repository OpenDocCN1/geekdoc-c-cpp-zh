The mode ios::cur means the offset is relative to the current position in the file, and the mode ios::end means the offset is relative to the end of the file. A positive offset means move forward in the file, and a negative offset means move backward.

Examples of seek() method calls are shown in the following code. In these examples, inFile has been opened as an input file and outFile as an output file. The offset passed to seek() and tell() must be a long integer, hence the uppercase L appended to each number in the code.

```
inFile.seekg(4L, ios::beg);   // go to the fifth character in the input file
out.seek(4L, ios::beg);   // go to the fifth character in the output file
inFile.seek(4L, ios::cur);    // move ahead five characters in the input file
out.seek(4L, ios::cur);    // move ahead five characters in the output file
inFile.seekg(-4L, ios::end); // move back five characters in the input file
out.seek(-4L, ios::end); // move back five characters in the output file
inFile.seekg(0L, ios::beg);   // go to the start of the input file
out.seek(0L, ios::beg);   // go to the start of the output file
inFile.seekg(0L, ios::end);  // go to the end of the input file
out.seek(0L, ios::end);   // go to the end of the output file
inFile.seekg(-10L, ios::end); // go to 10 characters before the input file's end
out.seek(-10L, ios::end); // go to 10 characters before the output file's end
```

As opposed to seek() methods that move the file position, the tell() returns the file position marker value. For example, if 10 characters are read from an input file inFile, the method call returns the long integer 10:

```
inFile.tell();
```

This means the next character to be read is 10 by position from the start of the file and is is the 11th character in the file.
