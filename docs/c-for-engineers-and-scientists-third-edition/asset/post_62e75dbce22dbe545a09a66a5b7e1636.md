# Calling Constructors

As you have seen, constructors are called whenever an object is created. The actual declaration, however, can be made in a variety of ways. For example, the declaration

```
Date c(4,1,2006);
```

used in Program 10.2 could have been written as

```
Date c = Date(4,1,2006);
```

This second form declares c as being of type Date and makes a direct call to the constructor function with the arguments 4, and 2006. This second form can be simplified when only one argument is passed to the constructor. For example, if only the month member of the c object needs to be initialized with the value 8 and the day and year members can use the default values, the object can be created using this declaration:

```
Date c = 8;
```

Because the form using an equal sign represents declarations in C, it's referred to as the C style of initialization. The declaration form in Program 10.2, referred to as the C++ style of initialization, is the form used predominantly in the remainder of this book.

Regardless of how you initialize you, an object should be declared with empty parameters. For example, the declaration Date a(); is not the same as the declaration Date a;. The second declaration uses the default constructor values, and the first results in no object being created.

# Overloaded and Inline Constructors

The primary difference between a constructor and other user-written functions is how the constructor is called: Constructors are called automatically each time an object is created, and other functions must be called explicitly by name. As a function, a constructor must follow all the rules for user-written functions discussed in Chapter 6. Therefore, constructors can have default arguments (as in Program 10.1), can be overloaded, and each can be written as inline functions.

> *This rule is true for all functions except destructors, described later in this section. A destructor function is called automatically each time an object is destroyed.

Recall from Section 6.1 function overloading permits using the same function name with different argument lists. Based on the supplied arguments, the compiler determines which function to use when the call is encountered. To see how overloading is applied to the Date class, take another look at the class declaration repeated here:

```cpp
// class declaration syntax
class Date {
  private:
    int month;
    int day;
    int year;
  public:
    Date(int = 7, int = 4, int = 2005); // constructor
}
```

The constructor prototypes three integer parameters, which are used to initialize the month, day, and year members. Another method of specifying a date is using a long integer in the form year * 10000 + month * 100. With this, the date 12/24/1998 is 19981224, and the date 2/5/2006 is 20060205. A suitable prototype for a constructor that uses dates in this form is shown here:

```cpp
Date(long); // an overloaded constructor
```

The constructor is declared as receiving one long integer. The code for this new Date() function method, of course, convert its single integer into a month, day, and year and is included in the class implementation section. The actual code for this constructor is as follows:

```cpp
Date::Date(long yyyymmdd) // a second constructor
{
  year = int(yyymymdd / 10000.0); // extract the year
  month = int((yyymymdd - year * 10000.0) / 100.0); // extract the day
  day = int(yyymymdd - year * 10000.0 - month * 100.0)
}
```

Don't be overly concerned with the conversion code used in the function body. The important point is that Program 10.3 contains the complete class definition in the context of a working program. The output of Program 10.3 is as follows:

```
The date is 07/04/05
The date is 04/01/98
The date is 05/15/106
```

# Program 10.3

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

// class declaration section
class Date {
  private:
    int month;
    int day;
    int year;
  public:
    Date(int = 7, int day = 4, int year = 2005); // constructor
    Date(long); // another constructor
    void showDate(); // member function to display a date
};

// class implementation section
Date::Date(int mm, int dd, int yyyy) {
  month = mm;
  day = dd;
  year = yyyy;
}
Date::Date(long yyyymmdd) {
  year = int(yyymymmd/10000.0); // extract the year
  month = int(yyymymmd - year * 10000.0)/100.0); // extract the month
  day = int(yyymymmd - year * 10000.0 - month * 100.0); // extract the day
}
void Date::showDate() {
  cout << "The date is ";
  cout << setfill('0')
    << setw(2) << month << '/'
    << setw(2) << day << '/'
    << setw(2) << year << endl;
}
```

# Accessor Functions

An accessor function is any non-constructor member function that accesses private data members. For example, the showDate() function in the Date class is an accessor function. These functions are extremely important because they provide a means of displaying data members.

When you construct a class, make sure to provide a complete set of accessor functions, each function should return data member's exact value, but it should return a useful representation of the value. For example, the date 12/25/2006 is stored as a long integer in the form 20062512. Although an accessor function could display this value, a more useful representation is 12/25/06 or December 25, 2006.

The keyword inline isn't required in this declaration because member functions defined in the class declaration are inline by default. Generally, only inline functions that can be coded on a single line are good candidates for inline functions. This guideline reinforces the convention that inline functions should be small. Therefore, the first constructor is more conventionally written with:

```cpp
Date(int mm = 7, int dd = 4, int yyyy = 2005)
{ month = mm; day = dd; year = yyyy; }
```

The second constructor, which extends over three lines, should be written as an inline function.

# Destructors

The counterpart to constructor functions are destructor functions. Destructors are functions with the same name as constructors but are preceded by a tilde (~). Therefore, for the Date class, the destructor is ~Date(). Like constructors, the C++ compiler provides a default-nothing destructor in the absence of an explicit destructor. Unlike constructors, there can be only one destructor per class because destructors take no parameters and return nothing.

Destructors are called automatically when an object gets out of existence and are meant to 'clean up' any undesirable effects the object might leave. Generally, these effects occur only when an object contains a pointer member.
