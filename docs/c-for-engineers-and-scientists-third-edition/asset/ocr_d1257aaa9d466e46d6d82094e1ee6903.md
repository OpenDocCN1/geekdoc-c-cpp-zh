For simplicity, Program 9.5 attempts to open the input and output files in separate and unset try blocks. More generally, the second file is opened in a nested inner try block, so the attempt to open the second file wouldn't be made if the first file threw an exception (The Point of Information box explains how to nest try blocks.)

In reviewing Program 9.5, pay particular attention to this statement:

```
while(ch = inFile.get())!= EOF
```

This statement reads a value from the input stream continuously until the EOF value is detected. As the returned value does not equal the EOF value, the value is written to the output stream. The parentheses around the expression (ch = inFile.get()) are necessary to make sure a value is read and assigned to the variable ch before the retrieved value is compared to EOF. Without parentheses, the complex expression would be ch = inFile.get() != EOF Given the precedence of operations the relational expression would be executed first. Because it is a Boolean true or false based on the data the get() method retrieves. Attempting to assign this Boolean result to the character variable ch is an invalid conversion across an assignment operator.
