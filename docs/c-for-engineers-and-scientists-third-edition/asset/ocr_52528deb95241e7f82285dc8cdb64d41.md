For a slightly more complicated example of performing a unit analysis for selecting correct conversion factors, consider days to seconds. You can determine the correct form of each conversion factor easily by including the units with each conversion factor, as you change days to hours, then hours to minutes, and finally minutes to seconds, performing each conversion at a time and canceling units as you proceed with each conversion, as

+   1st conversion:
days to hours
(cross out the days)

```
$$days \times \frac{24\text{ hr}}{\text{day}}$$
```

The next conversion changes the units of hours to minutes, using the conversion factor 60 min/hr, as follows:

+   1st conversion:
days to hours
(cross out the days)

+   2nd conversion:
hours to minutes
(cross out the days)

```
$$days \times \frac{24\text{ hr}}{\text{day}} \times \frac{60\text{ min}}{\text{hr}}$$
```
