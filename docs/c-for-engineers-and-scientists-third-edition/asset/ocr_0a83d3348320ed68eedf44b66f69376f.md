range 1 to 30 and the month value to lie in the range 1 to 12. The following function accomplishes these tasks:

```
Date::operator+(int days)
{
    Date temp; // a temporary Date to store the result
temp.day = day + days; // add the days
temp.month = month;
temp.year = year;
    while (temp.day > 30) // now
    {
        temp.month++;
        temp.day = 30;
    }
    while (temp.month > 12) // adjust the years
    {
        temp.year++;
        temp.month -= 12;
    }
    return temp; // the values in temp returned
}
```

The important feature to notice is the use of the temp object. Its purpose is to ensure that none of the function's arguments, which be the operator's operands, are altered. To understand this, consider a statement such as b = a + 284; that this operator function, where a and b are Date objects. This statement should never modify a's value. Rather, the expression a + 284 would yield a value that then assigned to b. The result of the expression is, of course, the temp Date object returned by the operator+().
