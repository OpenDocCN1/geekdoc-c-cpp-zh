# Built-in to Built-in Conversion

Sections 3.1 and 3.3 already explained conversion from one built-in data type to another. We review briefly, this type of conversion is implicit or explicit. An implicit conversion occurs in C++'s operations. For example, when a floating-point value is assigned to an integer variable, only the integer portion of the value is stored. The conversion is implied by the operation and performed automatically when a cast is used. In C++, two cast notations exist. The older C notation has the form `(dataType)expression`, and the newer C++ notation has the function-like `dataType(expression)`. For example, both (int)24.32 and int(24.32) cause the double-precision 24.32 to be truncated to the integer value 24.

An explicit conversion occurs when a cast is used. In C++, two cast notations exist. The older C notation has the form `(dataType)expression`, and the newer C++ notation has the function-like `dataType(expression)`. For example, both (int)24.32 and int(24.32) cause the double-precision 24.32 to be truncated to the integer value 24.

# Built-in to Class Conversion

User-defined casts for converting a built-in type to a class type are created by using constructor functions. A constructor whose first argument is not a member of its class and whose remaining arguments, if any, default is a type constructor. If the first argument of a unary constructor is a built-in data type, the constructor can be used to cast the built-in data type to a class object. Clearly, one restriction of these functions is that, constructors, must be member functions.

Although this type of cast occurs when the constructor is used to initialize an object, it's actually a more general cast than might be evident at first glance. The reason is that a constructor function can be explicitly called after all objects have been declared, whether or not it was called part of an object's declaration. Before exploring this point further, first see how to use a unary constructor. Then you see how to use it as a cast independent of its initialization process.

The cast constructor converts a long integer to a Date class, which consists of dates in the format `monthday/year` and uses the more familiar Date class. The long integer is used to represent dates in the year `10000 * month + 100 + day`. For example, the date 12/31/2000 becomes the long 20001231. Dates represented in this fashion are useful for two reasons: this representation stores a date as a single integer, and dates are in increasing order, which makes starting for example, the date 01/03/2002, which occurs after 12/31/2000, becomes the int 20020103, which is larger than 20001231. Because representing dates can exceed the size of a normal integer, these integers are always long.

A suitable constructor for converting a long integer to a Date stored as a month, day, and year is as follows:

```
// type constructor from long to Date
```
