Typically, a second variable is used to keep track of the current data type stored in the union. For example, the following code could be used to select the appropriate member for display. The value in the uType variable determines the currently stored data type in the val union:

```
switch (uType) {
    case 'c': cout << val.key;
        break;
    case 'i': cout << val.num;
        break;
    case 'd': cout << val.volts;
        break;
    default: cout << "Invalid type in uType : " << uType;
}
```

As in structures, a data type can be associated with a union. For example, the declaration

```
union DateTime {
    int days;
    double time;
};
```

provides a union data type without reserving any storage locations. This data type can be used to define any number of variables. For example, the definition

DateTime first, second, *pt;

creates a union named first, a union named second, and a pointer that can be used to store the address of any union having the form DateTime. After a pointer to a union has been declared, the same notation for accessing structure members can be used to access union members. For example, if the assignment pt = &first; is made, pt->dates refers the data member of the union first.

Unions be members of structures or arrays, and structures, arrays, and pointers can be members of unions. In each case, the notation used to access a member must be consistent with the nesting used. For example, in the structure defined

```
struct {
    char uType;
    union {
        char *text;
        float rate;
    } uTax;
    int flag;
} flag;
```

the variable rate is referenced as

```
flag.uTax.rate
```

Similarly, the first character of the string address is stored in the pointer text is referenced as follows:

```
*flag.uTax.text
```
