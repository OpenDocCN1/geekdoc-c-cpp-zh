
```cpp
class Elevator
{
    // class declaration section
    private:
    int maxFloor;
    int currentFloor;
    // function declaration section
    public:
    Elevator(); // default constructor
    Elevator(int); // overloaded constructor
    void setMaxFloor(int);
    void request(int);
};

// class implementation section
Elevator::Elevator() // default constructor
{
    currentFloor = 1;
    maxFloor = 15;
}

Elevator::Elevator(int cfloor) // overloaded constructor
{
    currentFloor = cfloor;
    maxFloor = 15;
}
void Elevator::setMaxFloor(int maxFloor)
{
    this->maxFloor = maxFloor;
}
void Elevator::request(int newfloor)
{
    if (newfloor < 1 || newfloor > maxFloor || newfloor == currentFloor) {
        // do nothing
    } else if (newfloor > currentFloor) { // move elevator up
        cout << "\nStarting at floor " << currentFloor << endl;
        while (newfloor > currentFloor) {
            currentFloor++; // add one to current floor
            cout << " Going Up - now at floor " << currentFloor << endl;
        }
    }
    cout << "Stopping at floor " << currentFloor << endl;
}
```

```cpp
int main()
{
    Elevator a; // declare 1 object of type Elevator

    a.request(16); // try to go above the highest floor
    a.setMaxFloor(6); // set the highest floor for this elevator
    a.request(7); // try to go above the new maximum floor

    return 0;
}
```

The first statement in Program 11.13's main function creates an object of Elevator that can be accessed with the reference variable a. Because no explicit floor has been given, this elevator begins at floor 1, which is provided by the default constructor. A request is entered and made to move the elevator to floor 16. Because this floor number exceeds the highest floor elevator can travel to, no movement is displayed. This sequence of no movement is repeated by setting the maximum floor value to 6, and requesting that the elevator travel to the 7th floor. The next two statements, however, cause the elevator to move using a request to move to the 6th floor, followed by a request to move to the 3rd floor.

In Program 11.13, notice the control the main() function provides. This sequential control, with subsequent calls made to various class functions and using different argument values, is suitable for testing purposes. However, by inserting calls to request() inside a while loop and using the random number function Math.random() to generate random floor requests, a continuous simulation of the elevator's operation is possible (see Exercise 5).
