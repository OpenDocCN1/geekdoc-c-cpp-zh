# Program 6.2

```
#include <iostream>
using namespace std;

void findMax(int, int); // the function prototype

int main()
{
    int firstname, secnum;

    cout << "\nEnter a number: ";
    cin >> firstname;
    cout << "\Great! Please enter a second number: ";
    cin >> secnum;

    findMax(firstname, secnum); // the function is called here

    return 0;
}

// following is the function findMax()
void findMax(int x, int y)
{
    int maximum; // start of function body
    // variable declaration

    if (x >= y)
        maximum = x;
    else
        maximum = y;

    cout << "\nThe maximum of the two numbers is " *
         << maximum << endl;

} // end of function body and end of function
```

Program 6.2 can be used to select and print the maximum of any two integer numbers the user enters. A sample run of Program 6.2 follows:

Enter a number: 25
Great! Please enter a second number: 5

The maximum of the two numbers is 25
