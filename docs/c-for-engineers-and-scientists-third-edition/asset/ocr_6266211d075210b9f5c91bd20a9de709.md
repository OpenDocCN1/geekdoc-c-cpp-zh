# 412 Arrays

Table 7.1 Summary of Vector Class Functions and Operations (continued)

| Class Functions | Description |
| :--- | :--- |
| insert(pos, elem) | Inserts elem at position pos |
| name.insert(pos, n, elem) | Inserts n copies of elem starting at position pos |
| name.insert(pos, src.begin, src.end) | Inserts elements from src.begin to src.end, starting at position pos |
| name.push_back(elem) | Appends elem at the end of the vector |
| name.erase(pos) | Removes the element at the specified position pos |
| name.erase(begin, end) | Removes elements within the specified range |
| name.resize(value) | Resizes the vector to a larger size, with new elements created by the default constructor |
| name.resize(value, elem) | Resizes the vector to a larger size, with elements created as elem |
| name.clear() | Removes all elements from the vector |
| name.swap(nameB) | Swaps the elements of nameA and nameB; can be performed using the swap algorithm |
| nameA == nameB | Returns a Boolean if nameA elements equal nameB elements; otherwise, returns false |
| nameA != nameB | Returns a Boolean if nameA is equal nameB elements; otherwise, returns true; same as !(nameA == nameB) |
| nameA < nameB | Returns a Boolean if nameA is less than nameB; otherwise, returns false |
| nameA > nameB | Returns a Boolean if nameA is greater than nameB; otherwise, returns false; same as nameB < nameA |
| nameA <= nameB | Returns a Boolean if nameA is less than or equal to nameB |
| nameA >= nameB | Returns a Boolean if nameA is greater than or equal to nameB |
| name.size() | Returns the size of the vector |
| name.empty() | Returns a Boolean if the vector is empty; otherwise, returns false |
| name.max_size() | Returns the maximum possible elements as an integer |
| name.capacity() | Returns the maximum possible elements as an integer without relocating the vector |
