Second, the indirection operator is used in swap() to access the values stored in firstnum and secnum. The swap() function has no knowledge of these variable names, but it does the address of firstnum in nm1Addr and the address of secnum in nm2Addr. The expression *nm1Addr in the first count statement means "the variable whose address is in nm1Addr." It is, of course, the variable firstnum. Similarly, the second count statement obtains the value stored in secnum as "the variable whose address is in nm2Addr."
