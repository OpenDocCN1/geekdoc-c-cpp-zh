# Chapter 6
Function and Parameter Declarations

Certainly, you could give each function a unique name, such as abs(), fabs(), and fabs(), having the following function prototypes:

```
void abs(int);
void fabs(float);
void fabs(double);
```

Each of these functions performs essentially the same operation on different data types. A much cleaner solution is writing a general function that handles all cases, but the compiler can set parameters, variables, and return type based on the actual function call. You can write this type of function in C++ by using templates.
A function template is a single, complete function that serves as a model for a family of functions. The function from the family that is actually created depends on subsequent function calls. To make this concept more concrete, take a look at a function template that computes and displays the absolute value of a passed argument:

```
template <class T>
void showabs(T number)
{
    if (number < 0)
        number = -number;
    cout << "The absolute value of the number " << " is " << number << endl;

    return;
}
```

For the moment, ignore the first line, template <class T>, and look at the second line, which consists of the function header void showabs(T number). Notice that this function header has where the data type is usually placed. For example, if the function header were showabs(int number), you would recognize it as a named function showabs() that expects one integer argument to be passed to it and it returns no value. Similarly, if the function header were showabs(double number), you should recognize it as a function that expects one double-precision argument to be passed to it when the function is called.

The advantage of using T for the function template is that it represents a general data type that can be replaced by int, float, double, and so forth, when the compiler encounters an actual function call. For example, if a function call with an integer argument is encountered, the compiler uses the function template to construct a function that expects an integer parameter. Similarly, if a call is made with a double-precision parameter, the compiler constructs a function that expects a double-precision parameter. As a specific example, take a look at Program 6.3.
