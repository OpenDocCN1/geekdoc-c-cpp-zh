# 700 Pointers

You can go further and replace nums[0] and nums[1] with their pointer notations, using the address of nums. As shown in Figure 12.24, the variable pointed to by nums is nums[0]. That, *nums is nums[0]. Similarly, *(nums + 1) is nums[1]. Using these relationships leads to the following equivalences:

| Pointer Notation | Subscript Notation | Value |
| (*nums) | nums[0] [0] | 16 |
| (*nums + 1) | nums[0] [1] | 18 |
| (*nums + 2) | nums[0] [2] | 20 |
| (*nums + 1) | nums[1] [0] | 25 |
| (*nums + 1) + 1) | nums[1] [1] | 26 |
| (*nums + 1) + 2) | nums[1] [2] | 27 |

The same notation applies when a two-dimensional array is passed to a function. For example, the two-dimensional array is passed to the calc function by using the call calc(nums). As with array passes, an address is passed. A suitable function header for the calc() function is:

```
calc int pt[2][3];
```

As you have seen, the parameter declaration for pt can also be the following:

```
calc int pt[1][3];
```

Using pointer notation, the following is another suitable declaration:

```
calc int (*pt)[3];
```

In this declaration, the inner parentheses are required to create a single pointer to arrays of three integers. Each array is, course, equivalent to a single row of the nums array. By offsetting the pointer, each element in the array can be accessed. Notice that without the parentheses, becomes

```
int pt[3];
```

which creates an array of three pointers, each pointing to a single integer. After the correct declaration for pt is made (any of the three valid declarations can be used), all the following notations in the calc() function are equivalent:

| Pointer Notation | Subscript Notation | Value |
| (*pt) | pt[0] [0] | 16 |
| (*pt+1) | pt[0] [1] | 18 |
| (*pt+2) | pt[0] [2] | 20 |
| (*pt+1)) | pt[1] [0] | 25 |
| (*pt+1)+1) | pt[1] [1] | 26 |
| (*pt+1)+2) | pt[1] [2] | 27 |
