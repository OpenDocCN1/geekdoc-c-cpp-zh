# Structures

```
void display(TeleType *contents) // contents is a pointer to a
{
    while (contents != NULL) // structure of type TeleType
    {
        cout << endl << setflags(ios::left)
            << setw(30) << contents->name
            << setw(20) << contents->phoneNo;
        contents = contents->nextaddr; // get next address
    }
    cout << endl;
    return;
}
```

The output produced by Program 13.9 is as follows:

| Acme, Sam | (555) 898-2392 |
| Dolan, Edith | (555) 682-3104 |
| Lanfrank, John | (555) 718-4581 |

The important concept Program 13.9 shows using the address in one structure to access members of the next in the list. When the display() function is called, the value stored in the variable first. Because first is a pointer variable, the actual value is an address (the address of the t1 structure). The display() function accepts the address in the argument contents. To store the address correctly, contents is declared as a pointer to a structure of the TeleType type. In display(), a while loop is used to cycle through the linked list returning with the structure whose address is in contents. The condition in the while statement ensures that in contents, is not the NULL value. Each name and telephone number of the addressed structure are displayed. The address in contents is updated with the address in the pointer member of the current structure.

The address in contents is retested, and the process continues as long as the address of the structures isn't the NULL value. The display() knows knows how many structures exist. It cycles through the linked list by structure, until it encounters the end-of-list NULL. Because the value of NULL is 0, the tested condition can be replaced by the equivalent expression.

A disadvantage of Program 13.9 is that exactly three structures are defined in main() by name, and storage for them is reserved at compile time. Should a fourth structure be declared and the program recompiled. In Section 13.5, you will see how to have the computer allocate and release storage for structures dynamically at runtime, as storage is required. When a new structure is added to the list, and while the program is running, storage is for the new structure created. Similarly, when a structure is no longer needed and can be deleted from the list, the storage for the deleted record is returned to the computer.
