Notice that the first function in this implementation section has the same name as the class, which makes it a constructor function. Therefore, it has no return type. The Date:: at the beginning of the function header identifies this function as a member of the Date class. rest of the function header

```
Date(int mm, int dd, int yyyy)
```

defines the function as three integer parameters. The body of this function simply assigns the data members month, day, and year with the values of the parameters mm, dd, and yyyy.

The next function header

```
void Date::setDate(int mm, int dd, int yyyy)
```

defines setDate() as belonging to the Date class (Date::). This function returns no value (void) and expects three integer parameters: mm, dd, and yyyy. In a manner similar to the Date(), the body of this function assigns the data members month, day, and year with the values of its parameters.

Last the function header in the implementation section

```
void Date::showDate()
```

defines a function named showDate(). This function has no parameters, returns no value, and is a member of the Date class. The body of this function, however, needs a little more explanation.

All years have been stored as four-digit values to retain century information, users are accustomed to seeing dates with the year as a value, such as 12/59. To display the last two digits of the year, the expression year % 100 can be used. If the year is 1999, the expression 1999 % 100 yields the value 99, and if the year is 2006, the expression 2006 % 100 yields the value 6.

If you had used the year as a two-digit value, such as 09, you would be altering the stored value of the year to correspond to the last two digits of the year. Because you want to retain the year as a four-digit number, you must carefully manipulate only the displayed value using the expression year % 100 in the count statement. Thehfill and setw manipulators are used to make sure the displayed values correspond conventionally accepted. For the date March 9, 2006, should appear as 3/9/06 or 030906. The setter manipulator forces each value to be displayed in a field of 2. This manipulator remains active only for the next insertion, it's before the date value. The setfill remains until the full character is changed, it must be included only once. The setfill manipulator has been used to change the fill character from a blank space to the character 0. This ensures that a date such as December 9, 2006 appears as 12/09/06, not as 12/9.
