Like all expressions, an assignment expression has a value, which is the value assigned to the variable on the left of the assignment operator. For example the a = 5 assigns a value of 5 to the variable a and results in the expression having a value of 5. The expression's value can always be verified by a statement such as the following:

```
cout << "Value of the expression " << (a = 5);
```

This statement displays the value of the expression, not the contents of the variable. Although both the variable's contents and the expression have the same value, it's worth realizing that you're dealing with two distinct entities.

From a programming perspective, the actual assignment of a value to a variable's is important in an assignment expression; the final value of the assignment is of little consequence. However, the fact that assignment expressions have a value has implications that must be considered when you learn about C++ relational operators, which are explained in the next chapter (Section 4.1).

Any expression terminated by a semicolon becomes a C++ statement. The most common example is the assignment expression, which is simply an assignment expression terminated with a semicolon. For example, terminating the assignment expression a = 33 with a semicolon in the assignment statement a = 33;; can be used in a program on a line by itself.

Because the equal is an operator in C++, multiple assignments are possible in the same expression or its equivalent statement. For example, in the expression a = b = c = 25, all the assignment operations have the same precedence. Because the assignment operator has a right-to-left associativity, the final evaluation proceeds in this sequence:

```
c = 25
b = c
a = b
```

This sequence of expressions, which has the effect of assigning the number 25 to each variable, can be represented as:

```
a = (b = (c = 25 ))
```

Appending a semicolon to the original expression results in this multiple assignment statement:

```
a = b = c = 25;
```

This statement assigns the value 25 to the three variables, equivalent to the following:

```
c = 25;
b = 25;
a = 25;
```
