Just as we create storage dynamically at runtime, the delete operator restores a block of storage to the computer at runtime. The only argument delete requires the starting address of a storage block that was allocated dynamically. Therefore, any address returns can be passed sequentially to delete to restore the reserved memory to the computer. The delete operator does not alter the address passed to it; it simply removes the storage that address references.
