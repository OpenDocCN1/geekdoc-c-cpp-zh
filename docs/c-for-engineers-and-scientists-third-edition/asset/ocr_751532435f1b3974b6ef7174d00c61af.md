The term **default constructor** is often used in C++ and refers to any constructor that doesn't require arguments when it's called. The reason it doesnt require arguments is that no arguments are declared, as the compiler-supplied default, or all arguments have been given default values. For example, Date(int mm = 7, int dd = 4, int yyyy = 2005) is a valid prototype for a default constructor. Each argument has been given a default value, and an object can be declared as Type without supplying any further arguments. Using this default constructor, the Date a initializes the object with the default values 7, 4, and 2005.

To verify that a constructor function is called automatically when a new object is created, examine Program 10.2. Note that in the implementation section, the constructor function uses cout to display the message Created a new object with data values. Therefore, whenever the constructor is called, this message is displayed. Because the main() function creates three objects, the constructor is called three times, and the message is displayed three times.

# Program 10.2

```
#include <iostream>
using namespace std;
// class declaration statement
class Date
{
    private:
    int month;
    int day;
    int year;
    public:
    Date(int mm = 7, int dd = 4, int yyyy = 2005); // constructor
};

// class implementation section
Date::Date(int mm, int dd, int yyyy)
{
    month = mm;
    day = dd;
    year = yyyy;
    cout << "Created a new object with data values "
         << month << " , " << day << " , " << year << endl;
}

int main()
{
    Date a; // declare an object
    Date b; // declare an object
    Date c(4,1,2006); // declare an object
    return 0;
}
```
