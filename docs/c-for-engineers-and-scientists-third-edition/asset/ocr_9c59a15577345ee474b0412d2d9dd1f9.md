# Structures

In reviewing Program 13.4, observe that both main() and calcNet() use the same data type to define their structure variables. The structure variable defined in main() and the structure variable defined in calcNet() are different structures. Any changes made to the local variable in calcNet() aren't reflected in the emp variable of main(). In fact, because both structure variables are local to their functions, the same variable name could have been used in both functions with no ambiguity.

When calcNet() is called by main(), copies of emp's structure values are passed to the temp structure, which is then returned to main(). Because calcNet() returns a non-integer, the data type of the returned value must be included in all declarations for calcNet().

An alternative to the pass-by-value call in Program 13.4, in which the function receives a copy of the structure, is a pass by reference that passes a reference to a structure. Doing so permits the function to access and alter values directly in the calling function's structure. For example, referring to Program 13.4, the prototype of calcNet() can be modified to the following:

```
double calcNet(Employee&);
```

If this function prototype is used and the calcNet() function is rewritten to conform to it, the main() function in Program 13.4 can be used as is. Program 13.4a shows changes in the context of a complete program.
