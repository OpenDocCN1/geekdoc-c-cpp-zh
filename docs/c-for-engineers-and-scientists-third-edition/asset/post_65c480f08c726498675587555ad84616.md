Each time a mathematical function is used, it's called into by giving the name of the function and passing it to any data in the parentheses following the function's name (see Figure 3.10).

```
function-name (data passed to the function);
This identifies passes data to
the called the function
```

**Figure 3.10** Using and passing data to a function

The arguments passed to a function need not be constants. Expressions can also be arguments, but the expression can be computed to yield a value of the required data type. For example, the following arguments are valid for the given function:

```
sqrt(4.0 * 5.3 * 4.0)
sqrt(16.0 * 2.0 - 6.7)
sqrt(x * y - z/3.2)
abs(2.3 * 4.6)
sin(theta - phi)
cos(2.0 * omega)
```

The expressions in parentheses are evaluated to yield a specific value. Therefore, values have to be assigned to the variables theta, phi, x, y, z, and omega before they are used in the preceding expressions. After the value of the argument is calculated, it is passed to the function.

Functions can also be included as part of larger expressions, as shown in this example:

```
* sqrt(4.5 * 10.0 - 9.0) - 2.0
= sqrt(36.0) - 2.0
= 4 * 6.0 - 2.0
= 24.0 - 2.0
= 22.0
```

The step-by-step evaluation of an expression such as

3.0 * sqrt(5 * 33 - 13.71) / 5

is as follows:

| Step | Result |
| --- | --- |
| 1. Perform multiplication in the argument. | 3.0 * sqrt(165 - 13.71) / 5 |
| 2. Complete the argument calculation. | 3.0 * sqrt(151.29) / 5 |
| 3. Return a function value. | 3.0 * 12.3 / 5 |
| 4. Perform the multiplication. | 36.9 / 5 |
| 5. Perform the division. | 7.38 |

Program 3.9 illustrates using the sqrt () function to determine the time it takes a ball to hit the ground after it has been dropped from an 800-foot tower. This is the mathematical formula for calculating the time in seconds it takes to fall a given distance in feet:

time = sqrt(2 * distance / g)

where g is the gravitational constant, equal to 32.2 ft/sec.

```

  return 0;
}
```

Using Mathematical Library Functions

As used in Program 3.9, the value sqrt function returns is assigned to the variable time. In addition to assigning a function's returned value to a variable, the returned value can be included in a larger expression or even used as an argument to another function. For example, the following expression is:

```
sqrt( sin(theta) )
```

Because parentheses are present, the computation proceeds from the inner to outer pairs of parentheses. The absolute value of theta is computed first and used as argument to the sin() function. The value sin() function returns is then used as an argument to the sqrt() function.

The arguments of all trigonometric functions (sin(), cos(), and so forth) must be in radians. Therefore, to calculate the sine of an angle given in degrees, the angle must be converted to radians first. You can do this by multiplying the angle by (3.14159/180). For, to obtain the sine of 30 degrees, the expression sin(30 * 3.14159/180).

## Casts

You have already seen the conversion of an operand's data type in mixed-mode arithmetic (Section 2.4). In addition to implicit type conversions made automatically in mixed-mode arithmetic and assignment expressions, C++ provides for user-specified conversions. The operator used to force a value to another type is the cast. The compile-time cast is a unary operator with syntax:

```
dataType(expression)
```

The dataType is the type to which the expression in parentheses is converted. With the introduction of C++ standard, runtime casts are included. In this type of cast, the requested type is checked at runtime and if the conversion results in a valid value. Although four types of runtime casts are available, the most commonly used and the one corresponding to compile-time cast has the following syntax:

```
static_cast<type>(expression)
```

For example, runtime cast static_cast<int>(a * b) is equivalent to compile-time cast (a * b).
