# 6.3 Returning Multiple Values

In a typical function invocation, the called function returns values from its calling function, stores and manipulates the passed values, and directly returns at most one value. When data is passed in this method, it is referred to as **pass by value**.

Calling a function and passing arguments by value is a distinct advantage of C++. It allows functions to be written as independent entities that can use any variable or name without other functions may using the same name. It alleviates any concern that altering a parameter or variable in one function could inadvertently affect a parameter or variable in another. In this approach, parameters are considered initialized variables, or assigned values when the function is executed. At no time, does the called function have direct access to any variable defined in the calling function, even if the variable is used as an argument in the function call.

However, if you need to modify the variables, passing by reference allows the called function direct access to its calling function. This approach allows one function—the calling function—to use and change the value of variables that have been defined in the calling function. This requires passing the variable's address to the called function. After the called function has the variable's address, it "knows where the variable lives," so to speak, and can access and change the value stored there.

Passing addresses is referred to as a **function pass by reference**¹² because the called function can reference, or access, the value whose address has been passed. C++ provides two types of address parameters: references and pointers. This section describes the method that uses reference parameters.

# Passing and Using Reference Parameters

As always, when exchanging data between functions, you must be concerned with both the sending and receiving sides. From the sending side, the calling function and passing an argument as an address that's accepted as a reference parameter is the same as calling and passing a value; the called function is summoned into action by giving its name and a list of arguments. For example, the statement `newval(firstnum, secnum);` calls passes two arguments to it. Whether a value or an address is actually passed depends on the parameter types declared for `newval()`. Now take a look at writing the `newval()` function and prototype so that it receives the addresses rather than the values of the variables `firstnum` and `secnum`, which are assumed to be double-precision variables.
