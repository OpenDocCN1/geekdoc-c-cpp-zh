# 12.2 Array Names as Pointers

Although pointers are, by definition, variables used to store addresses, there's also a direct and intimate relationship between array names and pointers. This section describes this relationship in detail. 12.9 illustrates the storage of a one-dimensional array named grade, which contains five integers. Each integer requires 4 bytes of storage.

| grade[0] (4 bytes) | grade[1] (4 bytes) | grade[2] (4 bytes) | grade[3] (4 bytes) | grade[4] (4 bytes) |

12.9 The grade array in storage

Using subscripts, the fourth element in the grade array is referred to as grade[3]. The use of a subscript, however, conceals the computer's extensive use of addresses. Internally, the computer interprets the subscript to calculate the array element's address based on the array's starting address and the amount of storage each element uses. Calling the fourth element grade[3] forces the compiler to make this address computation:

```
&grade[3] = &grade[0] + (3 * sizeof(int))
```

Remembering that the address operator, &, means "the address of," this statement is read "the address of grade[3] equals the address of grade[0] plus 12." 12.10 illustrates the address computation to locate grade[3].

| grade[0] (4 bytes) | grade[1] (4 bytes) | grade[2] (4 bytes) | grade[3] (4 bytes) | grade[4] (4 bytes) |
