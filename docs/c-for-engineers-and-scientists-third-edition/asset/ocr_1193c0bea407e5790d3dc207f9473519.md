# Program 12.7

```
#include <iostream>
#include <new>
using namespace std;

int main()
{
    int numgrades;

    cout << "Enter the number of grades to be processed: ";
    cin >> numgrades;

    int *grades = new int[numgrades]; // create the array

    for(int i = 0; i < numgrades; i++) {
        cout << "\nEnter a grade: ";
        cin >> grades[i];
    }

    cout << "\nArray was created for " << numgrades << " integers\n";
    cout << "\nThe values stored in the array:\ ";
    for (int i = 0; i < numgrades; i++) {
        cout << "\n" << grades[i];
    }
    cout << endl;

    delete[] grades; // return the storage to the heap

    return 0;
}
```

In Program 12.7 the delete operator is used with braces where the new operator was used previously to create an array. The delete[] statement restores the allocated block back to the free storage area (heap) while the program is running. The only address delete requires the starting address of the dynamically allocated storage block.
