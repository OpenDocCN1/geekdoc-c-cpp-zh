The computer's automatic scaling ensures the expression nPt + i, where i is any positive integer, points to the ith element currently pointed to by nPt. Therefore, if nPt initially contains the address of nums[0], nPt + 4 is the address of nums[4], nPt + 50 is the address of nums[50], and nPt + i is the address of nums[i]. Although addresses are used in Figure 12.5 to illustrate the scaling process, the programmer doesn't need to be concerned with the actual computer uses. Manipulating addresses with pointers doesn't require knowledge of the actual addresses.

Addresses can also be incremented or decremented with prefix and postfix decrement operators. Adding to a pointer allows the pointer to point to the next element of the type being pointed to. Decrementing a pointer allows the pointer to point to the previous element. For example, if the pointer variable p is a pointer to an integer, the expression p++ increments the address in the pointer to point to the next integer, as illustrated in Figure 12.6.

The increment and decrement operators can be applied as both prefix and postfix operators. All the following combinations using pointers are valid:

```
*pNum++ // use the address and increment it
++*pNum // increment the pointer before using it
*pNum-- // use the pointer and decrement it
--*pNum // decrement the pointer before using it
```

Of these four forms, the most commonly used is *ptNum++ because it allows accessing each array element as the address is "marched along" from the array's starting address to the address of the last array element.
