Assignments such as a.operator=(b); can be used to call the overloaded assignment operator and assign b's member values to a. For convenience, the expression a.operator=(b) can be replaced with a = b;

Program 11.2 contains the new assignment operator in the context of a complete program. Except for the addition of the overloaded assignment operator declaration and definition, Program 11.2 is identical to Program 11.1 and produces the same output. It is useful that it illustrates how you can construct your own assignment definitions. Before moving on, two simple modifications to the assignment operator need to be made.
