# 15.4 The Complement Operator

The complement operator, ~, is a unary operator that changes each 1 bit in its operand to 0 and each 0 bit to 1. For example, if the variable op1 contains the binary number 11001010, ~opl replaces this binary number with the number 00110101. The complement operator is used to force any bit in an operand to 0, independent of the actual number of bits used to store the number. For example,

```
opl = op1 & ~07;      // 07 is an octal
umber
```

or its shorter form
sets the three bits of op1 to 0, regardless of how op1 is stored in the computer. Either statement, of course, is replaced by AND the last three bits of op1 with 0s, if the number of bits used to store op1 is known. In a computer that uses 16 bits to store integers, the AND operation is

```
opl = op1 & 0177777;      // in octal
or
```

```
opl = op1 & 0xFFFF;      // in hexadecimal
For a computer that uses 32 bits to store integers, the preceding AND also sets the leftmost or right 16 bits to the left, which is an unintended result. The following is the correct statement for 32 bits:
```

```
opl = op1 & 027777777770;      // in octal
or
```

```
opl = op1 & 0xFFFFFF;      // in hexadecimal
```

Using the complement operator in this situation frees the programmer from having to determine the operand's storage size, and more important, makes the program portable between machines using different integer storage sizes.

# 15.5 Different-Size Data Items

When the operators &, and ^ are used with operands of different sizes, the shorter operand is always increased in bit size to match the larger operand's size. Figure 15.1 illustrates adding a 16-bit unsigned integer to a 32-bit number. As the figure shows, the additional bits are added to the left of the original number and filled with 0s. This is the equivalent of adding leading 0s to the number, which has no effect on the number's value.
