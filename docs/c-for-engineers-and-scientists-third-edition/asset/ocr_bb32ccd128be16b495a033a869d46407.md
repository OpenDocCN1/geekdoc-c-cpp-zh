# Passing a Pointer

Instead of passing a reference, a pointer can be used. Using a pointer, in addition to modifying the function's prototype and header, modifying the call to calcNet() in Program 13.4 is to the following

```
calcNet(&emp);
```

This function clearly indicates that an address is being passed (which isn't the case in Program 13.4a). The disadvantage is the dereferencing notation required inside the function. However, as pointers are widely used in practice, becoming familiar with this notation is worthwhile.

To store the following address correctly, calcNet() must declare its parameter as a pointer. The following function definition for calcNet() is suitable:

```
calcNet(Employee *pt);
```
