# 5.5 A Closer Look: Loop Programming Techniques

This section discusses four common programming techniques associated with pretest (for and while) loops. All techniques are common knowledge to experienced programmers.

# Technique 1: Interactive Input in a Loop

In Section 5.2, you saw the effect of including a cin statement in a while loop. Entering data interactively in a loop is a general technique that is equally applicable to loops. For example, in Program 5.12, a cin statement is used to allow a user to interactively input a set of numbers. As each number is entered, it's added to a total. When the loop is exited, the average is calculated and displayed.

The for statement in Program 5.12 creates a loop that executes four times. The user is prompted to enter a number each time through the loop. After each number is entered, it is added to the total. Notice that total is initialized to 0 before the initializing list of the for statement is executed. The loop in Program 5.12 is executed as long as the value in count is less than 4 and is terminated when count becomes 4. (The increment to 4, in fact is what causes the loop to end.) The output produced by Program 5.12 is essentially the same as Program 5.7.

![](bbox=[0.106, 0.465, 0.355, 0.503])

```
#include <iostream>
using namespace std;
// This program calculates the average of MAXCOUNT user-entered numbers
int main()
{
n    const int MAXCOUNT = 4;
    int count;
    double num, total, average;
    total = 0.0;
    for (count = 0; count < MAXCOUNT; count++)
    {
        cout << "Enter a number: ";
        cin >> num;
        total = total + num;
    }

    average = total / MAXCOUNT;
    cout << "The average of the data entered is "
    << average << endl;

    return 0;
}
```
