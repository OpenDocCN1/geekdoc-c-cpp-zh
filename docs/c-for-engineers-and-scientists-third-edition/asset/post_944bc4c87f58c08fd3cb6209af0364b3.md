## 4.5 Case Study: Solving Quadratic Equations

An important use of C++s statements is to validate data by checking for clearly invalid cases. For example, a date as 53/06 contains an obviously invalid day. Similarly, the division of any number by zero in a program, as 14/0, shouldn't be allowed. Both examples illustrate the need for a technique called defensive programming, in which the program includes code to check for input data before an attempt is made to process it for unreasonable data is referred to as **input validation**.

A second major use of selection statements is to determine the type of calculation to be based on the data. Both uses are shown in this case study, which illustrates a C++ program that determines the roots of a quadratic equation. A quadratic equation has the form $ax^2 + bx + c = 0$ or can be algebraically manipulated into this form. In this equation, $x$ is the unknown variable, and $a, b,$ and $c$ are known constants. Although the constants $b$ and $c$ can be any numbers, the value of the constant $a$ can't be 0. (If $a$ is 0, the equation would become a linear equation in $x$.) Here are examples of quadratic equations:

```
$5x^2 + 6x + 2 = 0$
$x^2 - 7x + 20 = 0$
$3x^2 - 16 = 0$
```

In the first equation, $a = 5, b = 6,$ and $c = 2$; in the second equation, $a = 1, b = -7,$ and $c = 20$; and in the third equation, $a = 3, b = 0,$ and $c = 16$.

## 214 Selection Structures

The real roots of a quadratic equation can be calculated by using these quadratic formulas:

```
x = \frac{-b + \sqrt{b^2 - 4ac}}{2a}
and
x = \frac{-b - \sqrt{b^2 - 4ac}}{2a}
```

Using these formulas, you'll write a C++ program, following the software development procedure, to solve for the roots of a quadratic equation.

## Step 1 Analyze the Problem

The problem requires accepting three inputs—the coefficients $a$, $b$, and $c$ of a quadratic equation. The outputs are the roots of the equation, found by using the formulas.

## Step 2 Develop a Solution

A first attempt at a solution is using the user-entered values of $a$, $b$, and $c$ to calculate a value for each root, as described by the following pseudocode:

- **Display a program purpose message**
- **Accept user-input values for $a$, $b$, and $c$**
- **Calculate the two roots**
- **Display the values of calculated roots**

However, this solution must be refined to account for possible input conditions. For example, if a user enters a value of 0 for both $a$ and $b$, the equation is neither quadratic nor linear and has no solution (referred to a "degenerate case"). Another possibility is that the user enters a zero for $a$ and a non-zero value for $b$. In this case, the equation becomes linear with a single solution. If $b^2 - 4ac$, which is called the **discriminant**, is negative, the square root of a negative number can't be taken, the equation has no real roots (referred as "imaginary roots"). Finally, when the discriminant is 0, both roots are the same (referred as "repeated roots").

## Step 3 Code

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, disc, root1, root2;

    cout << "This program calculates the roots of a quadratic equation of the form" << endl;
    cout << "ax + bx + c = 0" << endl;
    cout << "Please enter values for a, b, and c: ";
    cin >> a >> b >> c;

    if (a == 0 && b == 0) {
        cout << "The equation is degenerate and has no roots." << endl;
    } else if (a == 0) {
        cout << "The equation is linear. The single root is " << -c / b << endl;
    } else {
        disc = pow(b, 2) - 4 * a * c;
        if (disc > 0) {
            root1 = (-b + sqrt(disc)) / (2 * a);
            root2 = (-b - sqrt(disc)) / (2 * a);
            cout << "The two roots are " << root1 << " and " << root2 << endl;
        } else if (disc < 0) {
            cout << "The roots are imaginary." << endl;
        } else {
            root1 = -b / (2 * a);
            cout << "The repeated root is " << root1 << endl;
        }
    }

    return 0;
}
```
