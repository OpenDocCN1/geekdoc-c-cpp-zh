

# 434 数组

```cpp
int vals[3][2] = { (1, 2),
                  (3, 4),
                  (5, 6) };
```

生成了以下三行两列的数组：

```
1 2
3 4
5 6
```

由于 C++ 采用按行顺序初始化的约定，可以省略内部的大括号。因此，以下语句是等效的初始化：
`vals[3][2] = { 1, 2, 3, 4, 5, 6 };`

**5. 数组是通过将数组名作为参数传递给函数的。实际传递的值是数组存储位置的地址。因此，被调用的函数可以直接访问原始数组，而不是数组元素的副本。在被调用的函数中，必须声明一个形式形参数（formal argument）来接收数组元素。形式参数的声明可以省略数组的大小。**
