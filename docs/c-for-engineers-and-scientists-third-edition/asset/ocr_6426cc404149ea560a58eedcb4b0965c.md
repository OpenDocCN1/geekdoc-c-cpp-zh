theta and the function name polar(), the following code performs the required calculation of polar coordinates

```
void polar(double x, double y, double& r, double& theta)
{
    const double DEGREE = 180.0/3.141593;

    r = sqrt(x * x + y * y);
    theta = atan(y/x) * DEGREE;

    return;
```

The polar() function is straightforward. The function header declares that the function returns no value, and each of its parameters is declared as a floating-point data type. The first two parameters are used to accept x and y values, and the last two parameters, which are reference parameters, are used to pass the converted distance and angle values back to the calling function.

In the body, a constant DEGREE is defined as the factor 180.0/3.142593. The next two assignment statements use the parameters x and y to assign values to the r and theta parameters. The DEGREE constant is used to convert the radian value returned by the atan() function into degrees independently. As written, the polar() function can be compiled to check for any compile-time errors.

To understand how the return values are passed, it's helpful to think of the reference r and theta as containers (variables) through which values can be passed in either direction.
