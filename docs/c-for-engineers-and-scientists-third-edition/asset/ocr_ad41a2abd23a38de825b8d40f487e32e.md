# Chapter 11 Class Inheritance

```
int main()
{
    Circle circle_1, circle_2(2); // create two Circle objects
    Cylinder cylinder_1(3,4); // create one Cylinder object

    cout << "The area of circle_1 is " << circle_1.calcalc() << endl;
    cout << "The area of circle_2 is " << circle_2.calcalc() << endl;
    cout << "The volume of cylinder_1 is " << cylinder_1.calcalc() << endl;

    circle_1 = cylinder_1; // assign a Cylinder to a Circle

cout << "\nThe area of circle_1 is now " << circle_1.calcalc() << endl;
    return 0;
}
```

11.14 produces the following output:

The area of circle_1 is 3.14159
The area of circle_2 is 12.5664
The volume of cylinder_1 is 113.097

The area of circle_1 is now 28.2743
The first out lines are straightforward and are produced by the first three statements in the program. As the shows, a call to calcalc() with a Circle object activates the Circle version of this function, and a call to calcalc() with a Cylinder activates the Cylinder version of this function.
The assignment statement circle_1 = cylinder_1; introduces another important relationship between a base and a derived class: A derived class can be assigned to a base class object. This relationship shouldn't be surprising because base and derived classes share a common set of data members. In this type of assignment, only set of data members, which consists of all the base class data members, is assigned. Therefore, as illustrated in Figure 11.9, the Cylinder to Circle assignment results in the following memberwise assignment:

```
circle_1.radius = cylinder_1.radius;
```
