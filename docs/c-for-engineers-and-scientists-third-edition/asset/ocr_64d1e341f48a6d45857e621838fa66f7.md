```
int bubbleSort(int num[], int numel)
{
    int i, j, temp, moves = 0;

    for (i = 0; i < (numel - 1); i++)
    {
        for(j = 1; j < numel; j++)
        {
            if (num[j] < num[j-1])
            {
                temp = num[j];
                num[j] = num[j-1];
                num[j-1] = temp;
                moves++;
            }
        }
    }

    return moves;
}
```

As with selection sort, the number of comparisons in a bubble sort is O(n²), and the number of required moves depends on the initial order of values in the list. In the worst case, when the data is in reverse order, the selection sort performs better than the bubble sort. Both sorts require n²/2 comparisons, but the selection sort needs only n-1 moves, and the bubble sort requires n(n-1)/2 moves. The additional moves the bubble sort result from the intermediate exchanges between adjacent elements to "settle" each element to its final position. In this regard, the selection sort is superior because no moves are necessary. For random data, as that used in Programs 7.14 and 7.15, the selection sort generally performs equal or better than the bubble sort.
