# Table 9.4 The string Class Processing Functions (Require the Header File string) (continued)

| Function/Operation | Description | Example |
| --- | --- | --- |
| void insert(ind, str) | Inserts the string into the complete string, starting at index ind | string.insert(4, "there") |
| void replace(ind, n, str) | Removes n characters in the string object, starting at position ind, and inserts the string at index position ind | string1.replace(2,4, "okay") |
| string substr(ind,n) | Returns a string consisting of n characters extracted from the string, starting at index ind, if n is greater than the remaining number of characters, the rest of the string is used | string2 = string1.substr(0,10) |
| void swap(str) | Swaps characters in str with those in the first string | string1.swap(string2) |
| [ind] | Returns the character at index x, without checking whether ind is a valid index | string1[5] |
| = | Assignment (also) converts a C-string to a string) | string1 = string |
| + | Concatenates two strings | string1 + string2 |
