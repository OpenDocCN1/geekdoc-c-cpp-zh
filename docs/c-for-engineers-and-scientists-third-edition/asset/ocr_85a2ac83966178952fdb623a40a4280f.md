# 12.4 Passing Addresses

You have already seen one method of passing addresses to a function: using references in Section 6.3. Passing a reference to a function is implied the use of an address even though the reference provides the function with the actual, the actual statement statement doesn't reveal what is being passed—it could be a variable or the variable's value. For example, the function call swap(int num1, int &num2); doesn't reveal whether num1 or num2 is an address. By only looking at the declarations for the variables num1 and num2, or by examining the function header for swap() for declarations of the function's parameters, you can determine the data types of num1 and num2. If they have been defined as reference variables, an address is passed; otherwise, the value stored in the variables is passed.
