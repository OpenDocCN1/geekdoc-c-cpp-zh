# 652 Class Functions and Conversions

The length data member of the Cylinder object isn't used in the assignment because it has no equivalent value in the Circle class. The reverse cast, from base to derived class, isn't simple and requires a constructor to correctly initialize the derived class members that aren't in the base class.

Before leaving Program 11.14, one point should be made. Although the Circle constructor was called explicitly using a base/member initialization list for the Cylinder constructor, an implicit call could have been made. In the absence of an explicit derived class constructor, the compiler automatically calls the default base class constructor first, before the derived class constructor is called. This order of calling works because the derived class contains all the base class members. In a similar fashion, destructor functions are called in the reverse order—first derived class and then base class.
