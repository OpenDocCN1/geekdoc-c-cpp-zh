The important concept Program 13.9 shows using the address in one structure to access members of the next in the list. When the display() function is called, the value stored in the variable first. Because first is a pointer variable, the actual value is an address (the address of the t1 structure). The display() function accepts the address in the argument contents. To store the address correctly, contents is declared as a pointer to a structure of the TeleType type. In display(), a while loop is used to cycle through the linked list returning with the structure whose address is in contents. The condition in the while statement ensures that in contents, is not the NULL value. Each name and telephone number of the addressed structure are displayed. The address in contents is updated with the address in the pointer member of the current structure.

The address in contents is retested, and the process continues as long as the address of the structures isn't the NULL value. The display() knows how many structures exist. It cycles through the linked list by structure, until it encounters the end-of-list NULL. Because the value of NULL is 0, the tested condition can be replaced by the equivalent expression.

A disadvantage of Program 13.9 is that exactly three structures are defined in main() by name, and storage for them is reserved at compile time. Should a fourth structure be declared and the program recompiled. In Section 13.5, you will see how to have the computer allocate and release storage for structures dynamically at runtime, as storage is required. When a new structure is added to the list, and while the program is running, storage is for the new structure created. Similarly, when a structure is no longer needed and can be deleted from the list, the storage for the deleted record is returned to the computer.

# 13.5 Dynamic Data Structure Allocation

You have already learned about allocating and deallocating memory space with the new and delete operators (see Section 12.2). For, Table 13.1 repeats the description of these operators.

Table 13.1 Operators for Dynamic Allocation and Deallocation

| Operator Name | Description |
| --- | --- |
| new | Reserves the amount of bytes requested by the requested data type. Returns the address of the first reserved location or NULL if not enough memory is available. |
| delete | Releases a block of bytes previously reserved. The address of the first reserved location is passed as an argument to the operator. |

Dynamic allocation of memory is especially useful when dealing with a list of structures because it permits expanding the list as new records are added and contracting the list as records are deleted. In requesting additional storage space, the user must provide the new operator with an indication of the amount of storage needed for a particular data type. For example, the expression new(int) or new int (the two forms can be used interchangeably) requests enough storage to store an integer number. A request for storage for a data structure is made in the same fashion. For example, using the declaration

```cpp
struct TeleType
{
  string name;
  string phoneNo;
};
```

both the expressions new TeleType and new(TeleType) reserve enough storage for one TeleType data structure.

In allocating storage dynamically, you have no advance indication where the computer will physically reserve the requested number of bytes, and you have no explicit name to access the newly created locations. To access these locations, new returns to address of the first location that has been reserved. This address must, of course, assigned to a pointer. The return of a pointer is especially useful for creating a linked list of data structures. As each new structure is created, the pointer returns to the structure can be assigned to a member of the previous structure in the list. Program 13.10 shows using new to create a structure dynamically in response to a user-input request.

# In reviewing Program 13.10, notice that only two variable declarations are made in main(). The variable key is declared as a character variable, and the variable recPoint is declared as a pointer to a the TeleType. Because the declaration for TeleType is global, TeleType can be used in main() to define recPoint as a pointer.

If a user enters in response to the first prompt in main(), a call to new is made for the required memory to store the. After recPoint has been loaded with the correct address, this address can be used to access the newly created structure.

The populate() function is used to prompt the user-entered data for filling the structure and to store it. The argument passed to populate() in main() is the pointer recPoint. Like all arguments, the value in recPoint is passed to the function. Because the value in recPoint is an address, populate() receives the address of the newly created structure and can access the structure members.

The dispone() function displays the contents of the newly created and populated structure. The address passed to dispone() is the same address that was passed to populate(). Because this passed value is the address of a structure, the argument used to store it is declared as a pointer to the correct structure.

After you understand the mechanism of calling new, you can use it to construct a linked list of structures. Each list must contain at least one member. The address in the pointer member is the starting address of the next structure in the list. Additionally, a pointer must be reserved for the address of the next structure, and the pointer member of the last structure in the list is given a NULL address to indicate that no more members are being pointed to.
