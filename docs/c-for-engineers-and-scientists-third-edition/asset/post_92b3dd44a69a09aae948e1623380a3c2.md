## 2.4 Arithmetic Operations

The previous section presented the data values corresponding to C++'s built-in data types. This section explains the arithmetic operations that can be applied to these values. Integers and real numbers can be added, subtracted, multiplied, and divided. Although it's usually better to mix integers and real numbers when performing arithmetic operations, you can get predictable results when using different data.

The operators used for arithmetic operations are as follows:

| Operation | Operator |
|---|---|
| Addition | + |
| Subtraction | - |
| Multiplication | * |
| Division | / |
| Modulus | % |

These are also called binary operators, which means the operator requires two operands to produce a result. A simple binary expression consists of two literals with an operator connecting them. Examples of simple binary arithmetic expressions are the following:

```
3 + 7
8 - 3
12.6 + 9
12.6 / 2
```

The spaces around arithmetic operators in these examples are inserted for clarity and can be omitted without affecting the value of the expression. However, an expression in C++ must be entered in a straight line, as shown in these examples. For example, the C++ expression equivalent to 12.6 divided by 2 must be entered as 12.6 / 2, not as

12.6
2

You can use cout to display the value of any arithmetic expression onscreen. To do this, the value must be sent to the object. For example, the following statement displays:

```cpp
cout << (6 + 15);
```

Strictly speaking, the parentheses surrounding the expression 6 + 15 are not required to indicate that the value of the expression (21) is being displayed. In addition to displaying a numerical value, cout can display a string, as done in Section 2.1. For example, the following statement sends two pieces of data, a string and a value, to cout:

```cpp
cout << "sum of 6 and 15 is " << (6 + 15);
```

Each set of data to cout must be preceded by its own insertion operator, <<. In the preceding example, the first data sent to display is the string "sum of 6 and 15 is", the second item is the value of the expression 6+15. This statement produces the following:

sum of 6 and 15 is 21

The space between the word "is" and the number 21 is caused by the space in the string sent to cout. As far as cout goes, its input is a set of characters to be displayed in the order they're received. Characters from the input are queued one after the other, and sent to the screen. Placing a space in the input makes the space part of the stream of characters that is displayed. For example, the statement

```cpp
cout << "sum of 12.2 and 15.754 is " << (12.2 + 15.754);
```

yields the following display:

sum of 12.2 and 15.754 is 27.954

When multiple insertions are sent to cout, the code can spread across multiple lines. Only one semicolon must be used, which is placed after the last insertion and terminates the complete statement. Therefore, the display is also produced by the following statement, which spans two lines:

```cpp
cout << "sum of 12.2 and 15.754 is "
     << (12.2 + 15.754);
```

However, when you allow a statement to span multiple lines, two rules must be followed: a string contained in quotation marks cannot be split across lines, and the terminating semicolon should appear only on the last line. You can always place insertion symbols in a line.

The parentheses are not required because the + operator has a higher precedence than the << operator; therefore, the addition is performed before the insertion.

If floating-point numbers have six or fewer decimal digits, they're displayed with enough decimal places to accommodate the fractional part of the number. If the number has more than six decimal digits, the fractional part is rounded to six digits, and if the number has no decimal digits, neither a decimal point nor any decimal digits are displayed. Program 2.6 illustrates cout to display the result of arithmetic expressions in the statements of a complete program.

# Program 2.6

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "15.0 plus 2.0 equals " << (15.0 + 2.0) << endl;
    cout << "15.0 minus 2.0 equals " << (15.0 - 2.0) << endl;
    cout << "15.0 times 2.0 equals " << (15.0 * 2.0) << endl;
    cout << "15.0 divided by 2.0 equals " << (15.0 / 2.0) << endl;

    return 0;
}
```

The output of Program 2.6 is the following:

15.0 plus 2.0 equals 17
15.0 minus 2.0 equals 13
15.0 times 2.0 equals 30
15.0 divided by 2.0 equals 7

## Integer Division

The division of two integer values can produce rather strange results for the unwary. For example, the expression 15/2 yields the integer result 7. Because integers can't contain a fractional part, the fractional part resulting when two integers are divided—the remainder—is dropped (truncated). Therefore, the value of 9/4 is 2 and 20/3 is 6.

Often, you may need to retain the remainder of an integer division. To do this, C++ provides the modulus operator (also referred to as the "remainder operator") which has the % symbol. The operator captures the remainder when an integer is divided by an integer; using a non-integer value with the modulus operator results in a compiler error. The following examples show how the modulus operator is used:

- 9 % 4 is 1 (the remainder when 9 is divided by 4 is 1)
- 17 % 3 is 2 (the remainder when 17 is divided by 3 is 2)
- 15 % 4 is 3 (the remainder when 15 is divided by 4 is 3)
- 14 % 2 is 0 (the remainder when 14 is divided by 2 is 0)

## Expression Types

The result of an arithmetic expression is never a single-precision (float) number. This is because during execution, a C++ program temporarily converts all single-precision numbers to double-precision. The data type of each operation is determined by the following rules:

- If both operands are integers, the result of the operation is an integer.
- If one operand is a real value, the result of the operation is a double-precision.
