In addition to the sqrt() function, Table 3.5 lists commonly used mathematical functions provided in C++. Access these functions in a program requires including the mathematical header file c, which contains declarations for mathematical functions. To use this header file, place the following preprocessor statement at the top of any program using a mathematical function:

```
#include <cmath>
```

Although some mathematical functions in Table 3.5 require more than one argument, all by definition, can return at most one value. Additionally, all the functions listed are overloaded, which means the same function name can be used with integer and real arguments. Table 3.6 shows the value returned by selected functions, using sample arguments.
