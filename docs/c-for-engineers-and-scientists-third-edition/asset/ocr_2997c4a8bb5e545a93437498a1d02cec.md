(Computational) A magic square is a square of numbers with $N$ rows and $N$ columns, in which each integer value from 1 to $(N * N)$ appears exactly once, and the sum of each column, each row, and each diagonal is the same value. For example, Figure 7.17 shows a magic square in which $N=3$, and the sum of the rows, columns, and diagonal is 15. Write a program that constructs and displays a magic square for any odd number $N$. This algorithm is:

```
Insert the value 1 in the middle of the first row (element [0][N%2]).
After a value, $x$, has been placed, move one row up and to the right column.
Place the next, $x+1$, there, unless:
(1) You move off the top (row = -1) in any column. Move to the bottom row and place the next, $x+1$, in the bottom row of that column.
(2) You move off the right end (column = N) of a row. Then place the next number, $x+1$, in the first column of that row which is already filled or out the upper-right corner.
(3) You move to a position that is already filled or it immediately below $x$.
Stop when you have placed as many elements as there are in the array.
```

16. (Computational) Among applications, Pascal's triangle provides a means of determining the number of possible combinations of $n$ takes $r$ at a time. For example, the number of possible combinations of five ($n=5$) taken at a time ($r=2$) is 10.

Each row of the triangle begins and ends with 1. Every other element in a row is the sum of the element directly above it with the element to the left of the one above it. That is, element[n][r] = element[n-1][r] + element[n-1][r-1]

Using this information, write and test a C++ program to create the first 11 rows of a two-dimensional array representing Pascal's triangle. For any given value of $n$ less than 11 and $r$ less than equal to $n$, the program should display the correct element. Use your program to determine how many ways a committee of 8 can be selected from a group of 10 people.
