# Chapter 11

Chapter Summary

+   4. For each class object, a separate set of memory locations is reserved for all data members, except those declared as static. A static data member is shared by all class objects and provides a means of communication between objects. Static data members must be declared in the class declaration and are defined outside the declaration section.

+   5. Static function members apply to the class as rather than to separate objects. Therefore, a static function member can access only static data members and other static function members. Any static function member must be declared in the class declaration and are defined outside the declaration section.

+   6. A nonmember function can access a class's private data members if it's granted friend status by the class. This is done by declaring the function as a friend in the class declaration section. Therefore, the class always determines which non own functions are friends; the class can never forget status on itself.

+   7. User-defined operators can be constructed for classes using operator functions. For example, the function has the form `operatorsymbols`, where `symbols` is one of the following:

```
() [] -> new delete --+ ! * / +
<< >> < <= >= != ! && & | ^ | =
-* = / = &= &= | |= ===
```

For example, the function prototype Date operator+(int); declares that the addition operator is defined to accept an integer and return a Date object.

+   8. User-defined operators can be called in one of two ways—as a conventional function with arguments or as an operator function. For example, for an operator function having the function header

Date::operator+(int)

if dt is an object of type Date, the following two calls produce the same effect:
te.operator+(284)

+   9. Operator functions can also be written as friend functions. The friend version of an operator function always contains an additional class reference that isn't required by the member function.

+   10. There are four categories of data type conversions:
* Built-in types to built-in types
* Built-in types to class types
* Class types to built-in types
* Class types to built-in types

Built-in to built-in type conversions are done by using C++'s implicit conversion rules or its explicit cast operator. Built-in to class type conversions are done by using conversion constructors. From class types to built-in types or from class types to types are done by using conversion operator functions.

+   11. A type conversion constructor is a constructor whose first argument is not a member of its class and remaining arguments, if any, have default values.
