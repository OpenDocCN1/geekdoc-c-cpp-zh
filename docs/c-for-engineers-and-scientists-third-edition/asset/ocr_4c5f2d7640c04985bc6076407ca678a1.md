# Point of Information

| lvalues and rvalues |

The lvalue and rvalue are often used in programming technology. These terms are language independent and are used to designate the following: An lvalue can have a value assigned to it, but an rvalue can't.

In C and C++, an lvalue can appear on both the left and right sides of an assignment operator, but an rvalue can appear only to the right of an assignment operator. The variables you encounter can be an lvalue or rvalue, but a number can only be an rvalue. Not all variables, however, can be lvalues and rvalues. For example, an array type, introduced in Chapter 7, can't be an lvalue or rvalue, but elements in an array can be both.

An example of a coercion occurs when an integer value is assigned to a real variable; this assignment causes the integer to be converted to a real value. Similarly, assigning a real value to an integer variable forces conversion of the real value to an integer, which always results in losing the fractional part of the number by truncation. For example, if temp is an integer variable, the assignment temp = 25.89 converts the value 25 to be stored in the integer variable.

A more complete example of type conversions, which include both mixed-mode and assignment expression, is the evaluation of the expression

```
a = b * d
```

where a and b are integer variables and d is a single-precision variable. When the mixed-mode expression b * d is evaluated, the value of d is converted to a double-precision number for purposes of computation (The value stored in d remains a single-precision number.) Because one of the operands is a double-precision value, the value of the integer b is converted to a double-precision number for computation. (Again, the value stored in b remains an rvalue.) The result of b * d is a double-precision number. Finally, data type conversion after the assignment operator comes into play. Because the left side of the assignment operator is an integer variable, the double-precision value of the expression (b * d) is truncated to an integer value and stored in the variable a.
