# Program 9.2

```
#include <iostream>
using namespace std;

int main() {
    int numerator, denominator;
    bool needDenominator = true;

    cout << "Enter a numerator (whole number only): ";
    cin >> numerator;

    cout << "Enter a denominator (whole number only): ";

    while(needDenominator) {
        cin >> denominator;
        try {
            if (denominator == 0) // integer value is thrown
                throw denominator;
        } catch(int e) {
            cout << "A denominator value of " << e << " is invalid." << endl;
            cout << "Please reenter the denominator (whole number only): ";
            continue; // this sends control back to the while statement
        }
        cout << numerator << " / " << denominator
             << " = " << (double)(numerator) / double(denominator) << endl;
        needDenominator = false;
    }

    return 0;
}
```

In reviewing this code, it's the continue statement in the catch block that returns control to the top of the while statement. (See Section 5.3 for a review of the continue statement.) Following is a sample run of Program 9.2:
