# Program 5.11

```
#include <iostream>
#include <iomanip>
using namespace std;

int main()
{
    const int MAXNUMS = 10;
    int num;

    cout << "NUMBER  SQUARE    CUBE\n";
    cout << "------  ------      ------\n";
    for (num = 1; num <= MAXNUMS; num++)
        cout << setw(6) << num << "    "
             << setw(6) << num << " * " << num << "    "
             << setw(6) << num << " * " << num << " * " << num << endl;
    return 0;
}
```

When Program 5.11 runs, this is the display produced:

| NUMBER | SQUARE | CUBE |
| --- | --- | --- |
| 1 | 1 | 1 |
| 2 | 4 | 8 |
| 3 | 9 | 27 |
| 4 | 16 | 64 |
| 5 | 25 | 125 |
| 6 | 36 | 216 |
| 7 | 49 | 343 |
| 8 | 64 | 512 |
| 9 | 81 | 729 |
| 10 | 100 | 1000 |

Simply changing the 10 in the for statement of Program 5.11 to 1000 creates a loop that executed 1000 times and produces a table of numbers from 1 to 1000. With the while statement, this small change produces an immense increase in the program’s processing and output. Notice also that the expression num++ was used in the altering list in place of the usual num = num + 1.
