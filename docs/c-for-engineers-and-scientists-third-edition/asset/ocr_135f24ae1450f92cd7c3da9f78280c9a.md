# Advanced Pointer Notation

You can also access multidimensional arrays by using pointer notation, although the notation becomes more cryptic as the array dimensions increase. Pointer notation is especially useful with two-dimensional character arrays, and this section discusses pointer notation for two-dimensional arrays. For example, examine this declaration:

```
int nums[0][1] = { {16, 18}, {25, 27} };
```

This declaration creates an array of elements and a set of pointer constants named nums[0], and nums[1]. Figure 12.2 illustrates the relationship between these pointer constants and the elements of the nums array.

| nums | Address of nums[0] | Address of nums[0][0] | nums[0][0] nums[0][1] nums[0][2] |
|---|---|---|---||
| Address of nums[0] | | 16 | 18 |
| Address of nums[1] | | 25 | 26 | 27 |
| nums[1][0] nums[1][1] nums[1][2] | | | |

Figure 12.24 Storage of the nums array and associated pointer constants

The availability of the pointer constants associated with a two-dimensional array allows you to access elements in a variety of ways. One way is to view a two-dimensional array as an array of rows, with each row as an array of three elements. From this viewpoint, the address of the first element in the first row is provided by nums[0], and the address of the first element in the second row is provided by nums[1]. Therefore, the variable pointed to by nums[0] is nums[0][0], and the variable pointed to by nums[1] is nums[1][0]. Each element in the array can be accessed by applying an offset to the correct pointer. Therefore, the following notations are equivalent:

| Pointer Notation | Subscript Notation | Value |
|---|---|--|
| *nums[0] | nums[0] | 16 |
| *(nums[0] + 1) | nums[0][1] | 18 |
| *(nums[0] + 2) | nums[0][2] | 20 |
| *nums[1] | nums[1][0] | 25 |
| *(nums[1] + 1) | nums[1][1] | 26 |
| *(nums[1] + 2) | nums[1][2] | 27 |
