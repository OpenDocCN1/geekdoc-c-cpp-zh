Fluid Mechanies A fluid flow through a pipe can flow in a smooth, constant manner called laminar flow; in a chaotic manner, called turbulent flow; or in an intermediate transitional stage between smooth and turbulent flow. As practical design problem, the Reynolds number can be used to determine the type of flow. For a Reynolds number below 2000, the flow is laminar, and for a Reynolds number above 3000, the flow is turbulent. For a Reynolds number between 2000 and 3000, the flow is from laminar to turbulent. Using this information, write and execute a C++ program that accepts a Reynolds number as input; determines whether the flow is laminar, turbulent, or in transition; and displays a message indicating the type of flow based on the input number.
