# Point of Information

Why the char Data Type Uses Integer Values

In C++, a character is stored as an integer value, the reason is that, in addition to sometimes being confusing to beginners programmers, the need to represent English letters and characters, a program needs special characters that have no printable equivalents: One is the end-of-file character that all computer systems use to designate the end of a data file. The EOF can be transmitted from the keyboard, for example, on UNIX-based systems, it is generated by holding down the Ctrl key and pressing the D; on Windows-based systems, it is generated by holding down Ctrl and Z. On both, the EOF sentinel is stored as the number -1, which has no equivalent character value. (You can check this by displaying the integer value of each character (see Program 9.15) and pressing Ctrl+D or Ctrl+Z, depending on the system you're using.)

By using a 16-bit integer value, more than 64,000 different characters can be represented. This range of characters provides enough storage for multiple character sets, including Arabic, Chinese, Hebrew, Japanese, and Russian, and almost all known symbols. Therefore, storing a character as an integer value has a practical value.

An important consequence of using integer codes for strings is that characters can be compared easily for alphabetical ordering. For example, as long as subsequent letter in an alphabet has a higher value than its preceding letter, the comparison of character values is reduced to the comparison of numeric values. Storing characters in numerical order ensures that adding one to a letter produces the next letter in the alphabet.
