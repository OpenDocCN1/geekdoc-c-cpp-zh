# Class Functions and Conversions

As an example of inheritance, consider three geometric shapes: a circle, a cylinder, and a sphere. All these shapes share a common characteristic—a radius. Therefore, you can make the circle base type for the other two shapes, as illustrated in Figure 11.6. By convention, arrows always point from the derived class to the base class. In this example, the circle is the base class, and the cylinder and sphere are the derived classes.

![](bbox=[0.348, 0.212, 0.651, 0.375])

Figure 11.6 Relating object types

The relationships illustrated in Figure 11.6 are examples of simple inheritance, in which each derived type has only one base type. The complement to simple inheritance is multiple inheritance, in which a derived type has two or more base types. Figure 11.7 illustrates an example of multiple inheritance, but only simple inheritance is discussed in this section.

![](bbox=[0.306, 0.508, 0.693, 0.584])

Figure 11.7 An example of multiple inheritance

The class derivations in 11.6 and 11.7 are formally referred to as class hierarchies because they illustrate the hierarchy, or order, in which one class is derived from another. With this information as background, you can see how to derive one class from another.

A derived class has the same form as any other class: it consists of a declaration and an implementation. The only difference is in the first line of the declaration section. For a derived class, this line is extended to include an access specifier and a base class name in this form:

```
class derivedClassName : classAccess baseClassName
```

For example, if Circle is an existing class, a new class named Cylinder can be derived as:

```
class Cylinder : public Circle
{
    // place any additional data members and
    // member functions in here
}; // end of Cylinder class declaration
```
