## 10.2 Constructors

A constructor function is any function with the same name as its class. Multiple constructors can be defined for each class, as long as they can be distinguished by the number and types of their parameters.

A constructor's intended purpose is to initialize a new object's data members. Depending on the number and types of supplied arguments, one constructor is called each time an object is created. If no constructor function is written, the compiler provides a default constructor. In addition to its initialization role, a constructor function can perform other tasks when it's called and written in a variety of ways. This section explains possible variations of constructor functions and introduces another function, the destructor, which is called automatically whenever an object goes out of existence.

## Constructors

A constructor is any function with the same name as its class. Its main purpose is to initialize an object's member variables when an object is created, so a constructor is called automatically when an object is declared.

A class can have multiple constructors if each constructor has a different formal parameter list.

The term **default constructor** is often used in C++ and refers to any constructor that doesn't require arguments when it's called. The reason it doesnt require arguments is that no arguments are declared, as the compiler-supplied default. For example, Date(int mm = 7, int dd = 4, int yyyy = 2005) is a valid prototype for a default constructor. Each argument has been given a default value, and an object can be declared without supplying any further arguments. Using this default constructor, the Date a initializes the object with the default values 7, 4, and 2005.

Because the main() function creates three objects, the constructor is called three times, and the message is displayed three times.

#include <iostream>
using namespace std;
// class declaration statement
class Date
{
    private:
    int month;
    int day;
    int year;
    public:

    day = dd;
    year = yyyy;

}
