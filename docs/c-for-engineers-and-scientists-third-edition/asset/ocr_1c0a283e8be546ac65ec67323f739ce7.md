First, to preclude any inadvertent alteration to the object on the right-hand side of the assignment, a constant reference argument should be used. For the Date class, it takes this form:

```
void Date::operator=(const Date& newdate)
```

The final modification concerns the operation's return value. As constructed, your simple assignment operator returns no value, which precludes you from using it in multiple assignments, such as a = b = c. The reason is that overloaded operators use the same precedence and associativity as their built-in versions. Therefore, an expression as a = b = c is evaluated as a = (b = c) returns value, making subsequent assignment to an error. To allow multiple assignments, a more complete assignment operator returns a reference to its class. Because implementing this more complete assignment is discussed in Chapter 12. Until then, the simple assignment operator is more than adequate for your needs.
