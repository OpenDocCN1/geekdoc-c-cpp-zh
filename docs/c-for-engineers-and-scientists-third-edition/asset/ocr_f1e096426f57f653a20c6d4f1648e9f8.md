+   - Display a prompt to enter an ion concentration level.
- Read a value for the concentration level.

- Display the calculated value.

To make sure you understand the formula used in the algorithm, do a hand calculation. You can then use the result of this calculation to verify the result program produces. Assuming a hydronium concentration of 0.0001 (although any value would do), the pH level is calculated as -log₁₀⁴. Either by knowing that the logarithm of 10 raised to a power is the power itself or by using a log table, the value of this expression is (-4) = 4.

# Step 3 Code the Solution

Program 3.16 shows using the algorithm in C++. The variable names were chosen to convey the variables' meanings in this application.

![](bbox=[0.107, 0.483, 0.173, 0.523])

```
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double hydron, pHLevel;

    cout << "Enter the hydronium ion concentration: ";
    cin >> hydron;
    pHLevel = -log10(hydron);
    cout << "The pH level is " << pHLevel << endl;

    return 0;
}
```
