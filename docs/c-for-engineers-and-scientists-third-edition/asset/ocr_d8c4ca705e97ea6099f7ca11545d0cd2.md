The process of writing a program, or software, is called programming, and the set of instructions used to construct a program is called a programming language. Programming languages come in a variety of forms and types.

# Machine Language

At their most fundamental level, the only programs that can actually be used to operate a computer are machine-language programs. These programs, also referred to as executable programs (executables, for short), consist of a sequence of instructions composed of binary numbers, as⁴

```
11000000 0000000001 0000000001
11110000 0000000010 0000000011
```

Machine-language instructions consist of two parts: an instruction and an address. The instruction part, referred to as the opcode (short for operation code), is usually the leftmost set of bits and tells the computer to be performed, such as add, subtract, multiply, and so on. The rightmost bits specify the memory addresses of the data to be used. For example, as that the leftmost bits of the first instruction correspond to the opcode, and the next two groups of bits are addresses of the operands to be handled. This instruction would be a command to “add the data in memory location 1 to the data in memory location 2.” Similarly, as the opcode 11110000 means multiply, the next instruction is a command to “multiply the data in memory location 2 by the data in location 3.”

# Assembly Languages

Because each class of computers—such as IBM, Apple, Hewlett-Packard—has its own particular language, writing machine-language programs is tedious and consuming⁵ One of the first advances in programming was substituting word-like symbols, such as ADD, SUB, and MUL, for using decimal numbers and labels for memory addresses. Using these symbols and decimal values for memory addresses, the previous two machine-language instructions can be written as follows:

```
ADD 1, 2
MUL 2, 3
```

Programming languages using this type of symbolic notation are referred to as assembly languages. Because computers can execute only machine-language programs, the instructions in an assembly-language program must be translated into a machine-language program before they can be executed by a computer (see Figure 1.9). Translators perform this function for assembly-language programs are known as assemblers.
