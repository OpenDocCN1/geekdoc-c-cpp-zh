5. (Practice) a. The arbitrary pattern xxxxxxxx, where each x represent 1 or 0, is stored in the integer variable flag. Determine the octal value of a mask that is ANDed with the bit pattern to reproduce the third and fourth bits of flag and set all other bits to 0. The rightmost bit in flag is considered 0.

b. Determine the octal value of a mask that can be used ORed with the bit pattern in flag to reproduce the third and fourth bits of flag and set all other bits to 1. Again, the rightmost bit in flag is considered 0.

c. Determine the octal value of a mask that can be used to complement the values of the third and fourth bits of flag and leave all other bits unchanged. Determine the operation that should be used with the mask value to produce this result.
