# 434 Arrays

```
int vals[3][2] = { (1, 2),
                  (3, 4),
                  (5, 6) };
```

produces the following three-row-by-two-column array:

+   1 2
3 4
5 6

As C++ uses the convention that initialization proceeds in row order, the inner braces can be omitted. Therefore, the following statement is an equivalent initialization:
vals[3][2] = { 1, 2, 3, 4, 5, 6 };

+   5. Arrays are passed to a function by passing the array name as an argument. The value actually passed is the address of the array storage location. Therefore, the called function receives direct access to the original array, not a copy of the array elements. A formal argument must be declared in the called function to receive the array elements. The declaration of the formal argument can omit the array's size.
