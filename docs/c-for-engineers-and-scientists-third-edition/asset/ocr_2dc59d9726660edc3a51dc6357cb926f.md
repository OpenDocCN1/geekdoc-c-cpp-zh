The smallest and most basic data item in a computer is a bit. Physically, a bit is actually a switch that can be open or closed. The convention used in this book is that the open position is represented as a 0, and the closed position is represented as a 1.

A single bit that represent the values 0 and 1 has limited usefulness. All computers, therefore, group a set of bits together for transmission. Grouping 8 bits to form a larger unit, called a byte, is an almost universal counter. A single byte of 8 bits, with each being a 0 or 1, can represent any of 256 different patterns. These patterns range from 00000000 (all switches open) to 11111111 (all switches closed) and all combinations in between. Each pattern is used to represent a letter of the alphabet, a character (such as a dollar sign or comma), a digit, or a number more than one digit. The collection of patterns used to represent letters, digits, and others is called a character code. One character code, called ASCII, is discussed in Section 2.1). The patterns used to store numbers are called number codes, one of which is explained in the next section.

# Two Complement Numbers The most common number code for storing integer values in a computer is the two complement representation. Using this code, the integer equivalent of any pattern, such as 1000101, is easy to determine and can be found for positive or negative integers with no change in the conversion method.
