An important requirement for naming a function is giving it a name that conveys some of what the function does. The names allowed for functions are also used to name other elements of the C++ language and are collectively referred to as identifiers. Identifiers can be made up of any combination of letters, digits, or underscores (_) selected according to the following rules:

+   1. The first character of the name must be a letter or an underscore.
2. Only letters, digits, or underscores can follow the first letter. Also, blank spaces are not allowed to separate words in a function name; either use the underscore to separate words, or capitalize the first letter of every word after the first word.
3. A function name can't be one of the keywords listed in Table 2.1. (A keyword is a word that the language sets aside for special purpose and can be used only in a specified manner.)
4. The maximum number of characters in a function name is 1024.
