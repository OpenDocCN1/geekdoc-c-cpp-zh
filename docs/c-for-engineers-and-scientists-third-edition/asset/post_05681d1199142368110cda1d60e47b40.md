# 2.7 Common Errors

When you start programming, you will encounter many common errors. These include the following:

- Omitting the parentheses after main().
- Omitting the opening brace, {, which signifies the start of a function body.
- Omitting the closing brace, }, which signifies the end of a function.
- Misspelling the name of an object or function, such as typing cot instead of cout.
- Forgetting to enclose a string with quotation marks.
- Omitting a semicolon at the end of each statement.
- Adding a semicolon at the end of #include preprocessor command.
- Incorrectly typing the letter O for 0 or vice versa.
- Incorrectly typing the letter I for 1 or vice versa.
- Forgetting to declare all variables used in a program. The compiler detects this error, and an error message is generated for all undeared variables.
- Storing an array type in declared variable. The compiler detects this error, and the assigned value is converted to the data type of variable.
- Using a variable in an expression before a value has been assigned to it. The value that happens to be the variable when the variable is used is the value memory.
- Dividing integers incorrectly. This error is usually hidden in a larger expression and can be troublesome to detect. For example, the expression

3.425 / 3 + 7.9

yields the same result as the expression

3.425 + 7.9

because the integer division of 2/3 is 0.
- Mixing data types in the same expression without clearly understanding the effect. Because C++ allows expressions with "mixed" data types, understanding the order of evaluation and the data type of all intermediate calculations is important. As a general rule, it's better never to mix data types in expression unless you want a specific effect.
