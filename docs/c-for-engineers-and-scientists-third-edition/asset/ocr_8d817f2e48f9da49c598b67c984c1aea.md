# 11.2 Additional Class Features

This section covers additional features of classes, including defining the scope of a class, creating static class members, and granting access privileges to non own functions. Each of these topics can be read independently of the others.

# Class Scope

You learned about local and global scope in Section 6.5. As you saw, the scope of a variable defines the portion of a program where it can be accessed. For local variables, scope is defined by any block inside a brace pair, {}. This block includes both the function body and any subclasses. Additionally, all parameters of a function are considered local variables.

Global variables can be accessed from their point of declaration throughout the remainder of the file containing them, with three exceptions:

+   - If a local variable has the same name as a global variable, the global variable can be accessed only in the local variable's scope by using the scope resolution operator, ::
- A global variable's scope can be extended into another file by the keyword extern.

In addition to local and global scope, each class defines an associated scope. That is, names of data and function members are local to the scope of their class. Therefore, if a global variable is reused in the same class, the global variable is hidden by the class member in the same way that a local variable hides a global variable of the same name. Similarly, function names are local to the class they're declared and can be used only by objects declared for the class. Additionally, local function variables hide the names of class variables having the same name. Figure 11.2 illustrates the scope of variables and functions for the following declarations:

```
double rate; // global scope
// class declaration section
{
  private:
    double amount, total; // class scope
  public:
    double extend(double, double); // class scope
};
```
