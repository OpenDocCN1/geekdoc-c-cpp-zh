## The Null Statement
All statements must be terminated by a semicolon. A semicolon with nothing preceding it is also a valid statement, the null statement, as shown:

;
It's a do-nothing statement used where a statement is required syntactically, but no action is called for it. Typically, null statements are used with while and for statements. Program 5.10c in Section 5.4 shows an example of a for statement using a null statement.

## 5.4 for Loops

In C++, a for loop is constructed using a for statement. This statement performs the same functions as the while statement but uses a different form. In many situations, especially those with a fixed count, the for statement is easier to use than its while equivalent. This is the syntax of the for:

for (initializing list; condition; altering list)

Although the for statement looks a little complicated, it's really simple if you consider each part separately. In the parentheses of the for statement are three items separated by semicolons. Each item is optional and can be described separately, but the semicolons must be present even if you don't use the items. In the for most common form, the initializing list consists of a single statement used to set the starting (initial) value of a counter, the expression (also called "condition") contains the maximum or minimum value the counter can have and determines when the loop is finished, the altering list provides the value that is added to or subtracted from the counter each time the loop is executed. Here are two examples of simple statements having this form:

```cpp
for (count = 1; count < 10; count = count + 1)
    cout << count;
```

and

```cpp
for (i = 5; i <= 15; i = i + 2)
    cout << i;
```

In the first statement, the counter variable is named count, the initial value assigned to count is 1, the loop continues as long as count is less than 10, and the value of count is incremented by 1 each time through the loop. In the next statement, the counter variable is named i, the initial value assigned to i is 5, the counter continues as long as i's value is less or equal to 15, and the value of i is incremented by 2 each time through the loop. In both examples, a count statement is used to display the value of the counter. Program 5.9 shows another example of a for loop.

## Program 5.9

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main()
{
    const int MAXCOUNT = 5;
    int count;

    cout << "NUMBER      SQUARE ROOT\n";
    cout << "------      -------\n";

    cout << setflags(ios::showpoint);
    for (count = 1; count <= MAXCOUNT; count++)
        cout << setw(4) << count
             << setw(15) << sqrt(double(count)) << endl;

    return 0;
}
```

## 258 Repetition Statements

When Program 5.9 is executed, the following display is produced:

```
NUMBER    SQUARE ROOT
---------------------------
1         1.00000
2         1.41421
3         1.73205
4         2.00000
5         2.23607
```

The first two lines of this output are produced by the count statements placed before the statement. The remaining output is produced by the for loop, which begins with the for statement and is executed as follows: the initial value assigned to the counter variable count is 1. Because the value in count doesn't exceed the final value of 5, the execution of the count statement in the loop produces this display:

```
1         1.00000
```

Control is then transferred back to the for statement, which increments the value in count to 2, and the loop is repeated, producing this display:

```
2         1.41421
```

This process continues until the value in count exceeds the final value of 5, producing the complete output table. For comparison purposes, a while loop equivalent to the for loop in Program 5.9 is as follows:

```cpp
count = 1
while (count <= MAXCOUNT)
{
    cout << setw(4) << count
    << setw(15) << sqrt(count) << endl;
}
```

As you can see in this example, the difference between the for and while loops is the placement of the initialization, condition being tested, and incrementing items. Grouping these items in the for statement is convenient when you must construct fixed-count loops.
