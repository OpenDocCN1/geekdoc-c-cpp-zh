# 11.8 Common Programming Errors

+   1. Using a user-defined assignment operator in a multiple assignment expression when the operator hasn't been defined to return an object.
2. Using the static keyword when defining a static data member or member function. The static keyword should be used only in the class declaration section.
3. Using the friend keyword when defining a friend function. The friend keyword should be used only in the class declaration section.
4. Failing to instantiate static data members before creating class objects that must access these data members.
5. Attempting to redefine an operator meaning as it applies to C++'s built-in types.
6. Redefining an overloaded operator to perform a function not indicated by its conventional meaning. Although this method works, it's an example of bad programming practices.
7. Attempting to make a conversion operator function rather than a member function.
8. Attempting to specify a return type for a conversion operator function.
9. Attempting to override a virtual function without the same type and number of arguments as the original function.
10. Using the virtual in the class implementation section. Functions are declared virtual only in the class declaration section.

# 11.9 Chapter Summary

+   1. An assignment operator can be declared for a class with this function prototype:
void operator=(classNames);
The argument is a reference to the class name. The return type of void precludes this operator in multiple assignment expressions, such as a = b = c.
2. A type of initialization that closely resembles assignment occurs in C++ when one object is initialized by another object of the same class. The class performing this type of initialization is a copy constructor and has this function prototype:
className(const classNames);
It's often replaced with the notation X(X).
3. Each class has an associated class scope, which is defined by the brace pair, {}, containing the class declaration. Data and function members are local to the scope of their class and can be used only by objects declared for the class. If a variable name is reused in a class, the global variable is hidden by the class variable. Within the scope of the class variable, the global variable can be accessed by using the resolution operator, ::.
