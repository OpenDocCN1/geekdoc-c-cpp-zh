## Program 3.1

```cpp
// this program calculates the volume of a cylinder,
// given its radius and height
#include <iostream>
using namespace std;
```

```cpp
int main()
{
    double radius, height, volume;

    radius = 2.5;
    height = 16.0;
    volume = 3.1416 * radius * radius * height;
    cout << "The volume of the cylinder is " << volume << endl;

    return 0;
}
```

When Program 3.1 is compiled and executed, this is the output:

The volume of the cylinder is 314.16

Take a look at the flow of control the computer uses in executing Program 3.1. Program begins with the first statement in the body of the main() function and continues sequentially, by statement, until the closing brace of main() is encountered.

This sequential flow of control is true for all programs. The computer works on one statement at a time, executing that statement with no knowledge of what the next statement will be. This sequential flow explains how all operands used in an expression have values assigned before the expression is evaluated. When the computer executes this statement in Program 3.1,

volume = 3.1416 * radius * radius * height;

it uses whatever value is stored in the variables radius and height at the time the assignment statement is executed. If no values have been specifically assigned to these variables before they're used in the assignment statement, the computer uses whatever values occupy memory when they are referenced. Most C++ compilers initialize all variables to zero automatically. The computer doesn't "look ahead" to see whether you assign values to these later in the program.

In C++, the equal sign, = used in assignment statements is an operator, which differs from how most other high-level languages process this symbol. In C++ (as in C), the = symbol is called the assignment operator, and an expression using this operator, as interest = principal * rate, is an assignment expression. Because the assignment operator has a lower precedence than any arithmetic operator, the value of any expression to the right of the equal sign is evaluated first, before the assignment.

> ²Because C++ doesn't have an exponentiation operator, the square of the radius is obtained by the term radius * radius. Section 3.3 introduces C++'s power function pow(), which allows you to raise a number to a power.

Like all expressions, an assignment expression has a value, which is the value assigned to the variable on the left of the assignment operator. For example, a = 5 assigns a value of 5 to the variable a and results in the expression having a value of 5. The expression's value can always be verified by a statement such as the following:

```cpp
cout << "Value of the expression " << (a = 5);
```

This statement displays the value of the expression, not the contents of the variable. Although both the variable's contents and the expression have the same value, it's worth realizing that you're dealing with two distinct entities.

From a programming perspective, the actual assignment of a value to a variable is important in an assignment expression; the final value of the assignment is of little consequence. However, the fact that assignment expressions have a value has implications that must be considered when you learn about C++ relational operators, which are explained in the next chapter (Section 4.1).

Any expression terminated by a semicolon becomes a C++ statement. The most common example is the assignment expression, which is simply an assignment expression terminated with a semicolon. For example, terminating the assignment expression a = 33 with a semicolon in the assignment statement a = 33; can be used in a program on a line by itself.

Because the equal is an operator in C++, multiple assignments are possible in the same expression or its equivalent statement. For example, in the expression a = b = c = 25, all the assignment operations have the same precedence. Because the assignment operator has a right-to-left associativity, the final evaluation proceeds in this sequence:

```cpp
c = 25
b = c
a = b
```

This sequence of expressions, which has the effect of assigning the number 25 to each variable, can be represented as:

```cpp
a = (b = (c = 25 ))
```

Appending a semicolon to the original expression results in this multiple assignment statement:

```cpp
a = b = c = 25;
```

This statement assigns the value 25 to the three variables, equivalent to the following:

```cpp
c = 25;
b = 25;
a = 25;
```

## Coercion

When working with assignment statements, keep in mind the data type matches both sides of the expression because data type conversions occur across assignment operators. In other words, the value of the expression to the right of the assignment operator is converted to the data type of the variable to the left of the assignment operator. This type of conversion is called coercion if the value assigned to the left side of the assignment operator is forced into the data type of which it is assigned. An example of a coercion occurs when an integer value is assigned to a real variable; this assignment causes the integer to be converted to a real value. Similarly, assigning a real value to an integer variable forces conversion of the real value to an integer, which always results in losing the fractional part of the number by truncation. For example, if temp is an integer variable, the assignment temp = 25.89 converts the value 25 to be stored in the integer variable.

A more complete example of type conversions, which include both mixed-mode and assignment expression, is the evaluation of the expression

```cpp
a = b * d
```

where a and b are integer variables and d is a single-precision variable. When the mixed-mode expression b * d is evaluated, the value of d is converted to a double-precision number for purposes of computation. Because the left side of the assignment operator is an integer variable, the double-precision value of (b * d) is truncated to an integer value and stored in sum.

### Point of Information

| lvalues and rvalues | |

The lvalue and rvalue are often used in programming technology. These terms are language independent and are used to designate the following: An lvalue can have a value assigned to it, but an rvalue can't.

In C and C++, an lvalue can appear on both the left and right sides of an assignment operator, but an rvalue can appear only to the right of an assignment operator. The variables you encounter can be an lvalue or rvalue, but a number can only be an rvalue. Not all variables, however, can be lvalues and rvalues. For example, an array type, introduced in Chapter 7, can't be an lvalue or rvalue, but elements in an array can be both.

## Assignment Variations

Although only one variable is allowed immediately to the left of the sign in an assignment expression, the variable to the left can also be used to the right. For example, the assignment expression sum = sum + 10 is valid. Clearly, as an algebraic equation, sum could never be equal to itself plus 10. In C++, however, sum = sum + 10 is not an equation—it is evaluated in two stages: First, the value of sum + 10 is calculated, second, the computed value is stored in sum.

## Program 3.2

```cpp
#include <iostream>
using namespace std;

int main()
{
    int sum;

    sum = 25;
    cout << "The number stored in sum is " << sum << endl;
    sum = sum + 10;
    cout << "The number now stored in sum is " << sum << endl;

    return 0;
}
```
