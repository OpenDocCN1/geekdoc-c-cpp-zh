In addition to the setw and setprecision manipulators, a field justification manipulator is available. As you have seen, sent to count are normally right-justified in the display field, and strings are left-justified. To alter the default justification for a stream of data, use the setiosflags manipulator. For example, the statement

```
cout << " " << setw(10) << setiosflags(ios::left) << 142 << "|";
```

causes the left-justified display:

```
|142
```

Because set to count can be continued across multiple lines, the previous display is also produced by this statement:

```
cout << " " << setw(10)
<< setiosflags(ios::left)
<< 142 << "|";
```

As always, the field width manipulator is in effect only for the set of data displayed by count. To right-justify a string in a stream, use the setiosflags(ios::right) manipulator. The letters "ios" in the function name and the ios::right argument come from the first letters of the words "input output stream."
