Creating a class requires providing the capability to declare, initialize, assign, manipulate, and display data data members. In Chapter 10, you learned about declaring, initializing, and displaying objects. In this chapter, you continue constructing classes by providing the ability to create operator and conversion capabilities, similar to those inherent in C++s built-in types. With these additions, your user-defined types will all have the functionality of built-in types.

# ## 11.1 Assignment

In Chapter 3, you saw how C++s assignment operator, =, performs assignment between variables. In this section, you see how assignment works when it's applied to objects and how to define your own assignment operator to override the default one for user-defined classes. For a specific assignment example, take a look at the main() function in Program 11.1.
