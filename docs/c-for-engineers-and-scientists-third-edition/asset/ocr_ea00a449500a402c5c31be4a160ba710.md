```
for (count = 1; count < 10; count = count + 1)
    cout << count;
```

and

```
for (i = 5; i <= 15; i = i + 2)
    cout << i;
```

In the first statement, the counter variable is named count, the initial value assigned to count is 1, the loop continues as long as count is less than 10, and the value of count is incremented by 1 each time through the loop.
In the next statement, the counter variable is named i, the initial value assigned to i is 5, the counter continues as long as i's value is less or equal to 15, and the value of i is incremented by 2 each time through the loop. In both examples, a count statement is used to display the value of the counter. Program 5.9 shows another example of a for loop.

# Program 5.9

```
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main()
{
    const int MAXCOUNT = 5;
    int count;

    cout << "NUMBER      SQUARE ROOT\n";
    cout << "------      -------\n";

    cout << setflags(ios::showpoint);
    for (count = 1; count <= MAXCOUNT; count++)
        cout << setw(4) << count
             << setw(15) << sqrt(double(count)) << endl;

    return 0;
}
```
