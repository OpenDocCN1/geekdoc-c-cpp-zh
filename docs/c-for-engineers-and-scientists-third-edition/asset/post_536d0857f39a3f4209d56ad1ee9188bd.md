# Integer Data Types

C++ now has built-in integer data types, as shown in Figure 2.6. The essential difference between these integer data types is the amount of storage used for each type, which affects the range of values each type is capable of representing. The three most important and common types used in most applications are int, char, and bool. The other provided to accommodate special situations (such as a small or large range of numbers) and have been retained for historical reasons. They enabled programmers to maximize memory usage by selecting the data type with smallest amount of memory, consistent with an application's requirements. When computer memories were small, and expensive, the amount of memory used was a major concern. Although no longer a concern for most programs, these types still allow programmers to optimize memory usage when necessary, particularly in special-purpose digital control systems used in home appliances and automobiles.

**The int Type** supported by int data type are numbers, mathematically known as integers. An integer value consists of digits only and can optionally be preceded by a plus (+) or minus (-) sign. Therefore, an integer value can be the number 0 or any positive or negative number without a decimal point, as shown in the examples of valid identifiers.

```
0 5 -10 +25 1000 253 -26351 +36
```

As examples illustrate, integers can contain a sign. However, no commas, decimal points, or special symbols, such as the dollar sign, are allowed, in these examples of invalid integers:


**The char Data Type** The char data type is used to store single characters, including the letters of the alphabet (uppercase and lowercase), the digits 0 through 9, and special symbols, such as + - * . . and !. A character value is any single letter, digit, or special symbol enclosed by quotation marks, as is shown in these examples:

```
'A' '$' 'b' '7' 'y' '!' 'M' 'q'
```

Character values are typically stored in a computer by using ASCII Unicode codes. The ASCII (American Standard Code for Information Interchange, pronounced "as-key") provide codes for the English-language character set plus printer and display control, such as newline and printer page codes. Each character code is contained in a single byte, which provides 256 distinct codes. Table 2.3 shows the ASCII byte codes for uppercase letters.
Additionally, C++ provides for the Unicode code which uses 2 bytes per character and can represent 65,536 characters. This code is used for international purposes because it includes character sets for other languages in addition. As the first 256 Unicode codes have the same numerical value as the 256 ASCII codes (the additional byte is coded with all zeros), you don't need to be concerned with storage code to use with English-language characters.

**The Escape Character** As you've seen in Section 2.1, the backslash (\) has a special meaning in C++. When a backslash is placed in front of a group of characters, it tells the compiler to escape the way these characters are normally interpreted. The combination of backslash and these characters is called an *escape sequence*. Table 2.4 lists C++s most common escape sequences.

**Table 2.4** Escape Sequences

| Escape Sequence | Character Represented | Meaning | ASCII Code |
| :--- | :--- | :--- | :--- |
| \n | Newline | Move to a new line | 00000010 |
| \t | Horizontal tab | Move to the next tab setting | 00000001 |
| \v | Vertical tab | Move to the next tab setting | 00001011 |
| \b | Backspace | Move back one space | 00001000 |
| \r | Carriage return | Move to the start of the current line; used for overprinting | 00101101 |
| \f | Form feed | Issue a form feed | 00001100 |
| \a | Alert | Issue an alert (usually a bell sound) | 00000111 |
| \\ | Backslash | Insert a backslash character (used to place actual backslash character in a string) | 01011010 |
| \? | Question mark | Insert a question mark | 00111111 |
| \' | Single quotation | Insert a single-quote character (used to place inner single quote within a set of outer quotes) | 00100111 |

**Table 2.4** Escape Sequences (continued)

| Escape Sequence | Character Represented | Meaning | ASCII Code |

**Data Type** In C++, the bool data type is used to represent Boolean (logical) data, which is restricted to two values: *true* or *false*. This data type is most useful when a program must examine a condition and take a prescribed course of action, based on whether the condition is true or false. For example, in a sales application, the condition might be "is the total purchase for $100 or more." Only when this condition is true is a discount applied. Because the bool data type uses an integer storage code, it has useful implications that most professional C++ programmers utilize. The practical uses of Boolean conditions are discussed in Chapter 4; the bool data type is discussed in details in that chapter.

# Point of Information

The Character '\n' and the String "\n" The compiler recognizes both '\n' and "\\n" as containing the newline character. The difference is in the data type used. Formally, '\n' is a character literal, and "\n" is a string literal. From a practical standpoint, both cause the same thing to happen: A new line is forced in the output display, encountering the character value '\n'; however, the compiler translates it by using the ASCII code 00000010 (see Table 2.4). In encoding the string value "\n", the compiler translates it by using the correct character code but also adds an end-of-string character, which is '\0'.

Good programming practice requires ending the last output with a newline sequence. This practice ensures that the first line of output from one program doesn't end on the last line displayed by the previously executed program.
