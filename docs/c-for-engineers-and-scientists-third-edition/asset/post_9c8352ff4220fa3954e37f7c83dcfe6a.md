```cpp

#include <fstream>
#include <cstdlib>    // needed for exit())
#include <string>
using namespace std;
```

int main()
{
    string fileOne = "info.txt"; // put the filename up front
    string fileTwo = "info.bak";
    char ch;
    ifstream infile;
    ofstream outfile;

    try // this block tries to open the input file
    {
        // open a basic input stream
        infile.open(fileOne.c_str());
        if (infile.fail()) throw fileOne;
    } // end of outer try block
    catch (string in) // catch for outer try block
    {
        cout << "The input file " << was not successfully opened." << endl
             << " No backup was made." << endl;
        exit(1);
    }

    try // this block tries to open the output file
    {
        // perform all file processing
        outfile.open(fileTwo.c_str());

        if (outfile.fail()) throw fileTwo;

        while ((ch = infile.get()) != EOF)
            outfile.put(ch);

        infile.close();
        outfile.close();
    }
    catch (string out) // catch for inner try block
    {
        cout << "The backup file " << was not not successfully opened." << endl;
        exit(1);
    }

    cout << "A successful backup of " << fileOne
         << " named " << fileTwo << " was successfully made." << endl;

    return 0;
}
```

## 9.3 The String Class

The programs in this book have used the istream object extensively, but you have not investigated this class in detail or learned how the class is constructed. However, an advantage of object-oriented design is that you can use classes thoroughly without knowing how the class is constructed. You use any class defined by C++ standard library: the string class.

A class is a user-created data type. Like built-in data types, a class defines a valid set of data values and a set of operations that can be performed on them. The difference between a user-created data type as an integral part of the compiler, and a class is constructed by a programmer using C++ code is. Other than that and the terminology, the two data types are used in much the same manner. The difference lies in storage that for built-in data types are referred to as variables, whereas storage areas for a class are referred to as objects.

The values class permits are referred to string literals. A string literal is also referred to as a string value, a constant, and more conventionally, a string. Examples of strings are "This is a string", "Hello World", "xyz 123 #&* The quotation marks indicate the beginning and ending points of the string are not stored with the string.
