C++ programmers can make full use of the functions C++ classes provide with- knowing the internal details of how the function is constructed or even how to construct a class. Functions provided as part of a class are generally referred to as class methods (methods, for short). Therefore, a method can be referred to as a function although the term "method" provides more information in telling you the function is part of a class.

Two Parts (Chapters 10 and 11) explains classes and their construction in detail. You will see, a class is constructed from C++ code that includes both data and functions (although the functions are more accurately referred as methods). An object is simply a specific item constructed from a class. For example, a specific car is an object, which is a specific item from the class of all cars, or the book you are reading now is an object, which is a specific item from the class of all three editions of the book C++ For Engineers and Scientists.

Two basic types of files exist: text files, also known as character-based and binary-based files. Binary files store data using a binary code; the difference is in how the codes represent. Briefly, text files store each character, such as a letter, digit, dollar sign, decimal point, and so on, by using a character code (typically ASCII or Unicode). With a character code, a word processing program or text editor can change the files so that you can read them.

Binary-based files use the same code as C++ use for primitive data types. This means numbers appear in their true binary, and strings retain their ASCII or Unicode. The advantage of binary-based files is compactness; storing less space than character values. In general, programmers use text files more often than the file's data can be displayed by word processing programs and simple text editors. The default file type in C++ is always a text file and is the file discussed in this chapter.

# File Stream Objects

A file stream is a one-way transmission used to connect to a file stored on a physical device, such as a disk or CD. Each file stream has its own mode that determines the direction of data on the transmission path--that is, the path between a program from a program to a file. A file stream that receives or reads data from a file is an input file stream. A stream that stores or writes data to a file is an output file stream. The direction, or mode, is defined in relation to the relation, not the file; data going into a program is considered input data, and data sent out of a program is considered output data.
