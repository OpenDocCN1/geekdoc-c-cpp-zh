# Sort Algorithms

Two major categories of sorting techniques, called internal and external sorts, are available for sorting data. Internal sorts are used when the data list isn't too large and the complete list can be stored in the computer's memory, usually in an array. External sorts are used for much larger data sets that are stored in external disk or files and cannot be accommodated in computer's memory as a complete unit. Next, you learn about internal sort algorithms that can be used when sorting lists with fewer than approximately 50 elements. For larger lists, more sophisticated sorting algorithms are typically used.

For example, take a look at the list of numbers shown in Figure 7.15. The first pass through the initial list results in the number 32 being selected and exchanged with the first element in the list. The second pass, made on the reordered list, results in the number 155 selected from the second through fifth elements. This value is then exchanged with the third element in the list and exchanges with the fifth element. Finally, the fourth and last pass through the list selects the remaining minimum value and exchanges it with the fourth element. Although each pass in this example resulted in an exchange, no exchange would have been made in a pass if the smallest value were already in the correct location.
