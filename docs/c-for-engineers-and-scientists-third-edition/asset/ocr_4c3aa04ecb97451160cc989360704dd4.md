# 12.5 Common Programming Errors

In using the material in this chapter, be aware of the following possible errors:

+   1. Attempting to store an address in a variable that hasn't been declared as a pointer.
2. Using a pointer to access nonexistent array elements. For example, if nums is an array of 10 elements, the expression *(nums + 15) points to a location integer beyond the last array element. Because C++ doesn't do bounds checking on array accesses, the compiler cannot catch this type of error. This is the same error, disguised in pointer notation format, that occurs when using a subscript to an out-of-bounds array element.
3. Forgetting the bracket set [],], after the delete operator when dynamically deallocating memory that was allocated with the new [] operator.
4. Incorrectly applying address and direction operators. For example, if pt is a pointer variable, both expressions
pt = &45
pt = &(miles + 10)
is invalid if they attempt to add the address of a value. Notice that the expression pt = &miles + 10, however, is valid. This expression adds 10 to the address of miles. It's the programmer's responsibility to ensure that the final address points to a valid element.
5. Taking addresses of pointer constants. For example, given the declarations
int nums[25];
int *pt;
t assignment
pt = &nums;
