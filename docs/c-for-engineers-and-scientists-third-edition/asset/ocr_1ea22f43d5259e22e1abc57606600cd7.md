# Repetition Statements

All the program examples of the while statement use fixed-count loops because the tested condition is a counter that checks for a fixed number of repetitions. In a variation on the fixed-count loop, the counter is not incremented by each time through the loop but by some other value. For example, suppose you have the task of producing a Celsius-to-Fahrenheit conversion table. Fahrenheit temperatures corresponding to Celsius temperatures from 5 to 50 degrees are to be displayed in increments of 5 degrees, which can be done with this series of statements:

```
celsius = 5;
// starting Celsius value
while (celsius <= 50)
{
    fahrenheit = (9.0/5.0) * celsius + 32.0;
    cout << celsius << " " " << fahrenheit << endl;
    celsius = celsius + 5;
}
```

As before, the while statement consists of everything from the while through the compound statement's closing brace. Before the program enters the while loop, you must make a value assigned to the counter being evaluated, and there's a statement to alter the value of the counter in the loop (in increments of 5 degrees Celsius) to ensure an exit from the while loop.
