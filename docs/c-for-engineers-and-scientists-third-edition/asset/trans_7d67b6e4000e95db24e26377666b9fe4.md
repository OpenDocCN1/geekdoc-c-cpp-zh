## 4.5 案例研究：求解二次方程

C++ 语句的一个重要用途是通过通过检查明显的无效情况来验证数据。例如，日期 `53/06` 包含一个显然无效的日期。同样，程序中任何数字除以零（如 `14/0`）是不应该被允许的。这两个例子说明了这种**防御性编程**技术的必要性，即程序在尝试处理输入数据之前，包含代码来检查输入数据是否不合理，这种技术被称为**输入验证**。

选择语句的第二个主要用途是根据数据确定计算的类型。本案例研究展示了这两种用途，并演示了一个确定二次方程根的 C++ 程序。二次方程的形式为 $ax^2 + bx + c = 0$，或者可以通过代数变形化为这种形式。在方程方程中，$x$ 是未知变量，$a, b$ 和 $c$ 是已知常数。虽然常量 $b$ 和 $c$ 可以是任意数字，但常量 $a$ 的值不能为 0。（如果 $a$ 为 0，则方程将变为 $x$ 的一次方程）。以下是二次方程的示例：

```
$5x^2 + 6x + 2 = 0$
$x^2 - 7x + 20 = 0$
$3x^2 - 16 = 0$
```

在第一个方程中，$a = 5, b = 6,$ 和 $c = 2$；在第二个方程中，$a = 1, b = -7,$ 和 $c = 20$；在第三个方程中，$a = 3, b = 0,$ 和 $c = 16$。

## 214 选择结构

二次方程的实根可以通过以下二次方程公式计算：

```
x = \frac{-b + \sqrt{b^2 - 4ac}}{2a}
和
x = \frac{-b - \sqrt{b^2 - 4ac}}{2a}
```

使用这些公式，你将按照软件开发流程编写一个 C++ 程序来求解二次方程的根。

然而，必须对此解决方案进行改进以考虑可能的输入条件。例如，如果用户对 $a$ 和 $b$ 都输入 0，则方程既不是二次方程也不是一次方程，无解（被称为“退化情况”）。另一种可能性是用户对 $a$ 输入 0，对 $b$ 输入非零值。在这种情况下，方程变为一次方程，只有一个解。如果 $b^2 - 4ac$（称为**判别式**）为负数，则无法对负数开平方根，方程没有实根（被称为“虚根”）。最后，当判别式为 0 时，两个根是相同的（被称为“重复根”）。

## 步骤 3 代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, disc, root1, root2;

    cout << "该程序计算方程为" << endl;
    cout << "ax + bx + c = 0 的二次方程的根" << endl;
    cout << "请输入 a, b, 和 c 的值: ";
    cin >> a >> b >> c;

    if (a == 0 && b == 0) {
        cout << "该方程是退化的且无解。" << endl;
    } else if (a == 0) {
        cout << "这是一个一次方程。单根为 " << -c / b << endl;
    } else {
        disc = pow(b, 2) - 4 * a * c;
        if (disc > 0) {
            root1 = (-b + sqrt(disc)) / (2 * a);
            root2 = (-b - sqrt(disc)) / (2 * a);
            cout << "两个根为 " << root1 << " 和 " << root2 << endl;
        } else if (disc < 0) {
            cout << "根是虚数。" << endl;
        } else {
            root1 = -b / (2 * a);
            cout << "重复根为 " << root1 << endl;
        }
    }

    return 0;
}
```
