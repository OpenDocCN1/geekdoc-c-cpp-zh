Using the formula for pH, you will write a C++ program, using the software development procedure described in Chapter 2, that calculates the pH level of a substance based on a user input value for the concentration of hydronium ions.

# **Step 1 Analyze the Problem**

Although the problem statement provides technical information on the composition of acid rain, from a programming viewpoint, this problem is rather simple. You have only one required output (a pH level) and one input (the concentration of hydronium ions).
