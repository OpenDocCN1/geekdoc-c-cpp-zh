# Class Functions and Conversions

```
int main()
{
    Date(4,1,2007); // declare and initialize one object of type Date
    long b; // declare an object of type long

    b = a; // a conversion takes place here

    cout << "a's date is *";
    a.showDate();
    cout << "\nThis date, as a long integer, is " << b << endl;

    return 0;
}
```

Program 11.10 produces the following output:

a's date is 04/01/07
This date, as a long integer, is 2007041

As this output shows, the change in a's date value to a long is produced by the assignment expression b = a. This assignment, which could also have been written as b = long(a), calls the conversion operator long() to perform the conversion from Date to long. In general, because explicit conversion clearly documents what's happening, it is better to prefer implicit conversion.

Notice that the conversion operator has no explicit argument or return type, which is true of all conversion operators. The implicit argument is always an object of the class being cast from, and return type is implied by the function's name. Additionally, as stated previously, a conversion operator must be a member function.

# Class to Class Conversion

Converting from a class type to a built-in data type is in the same manner as a conversion from a class to a built-in data—by using a conversion operator function. In this case, however, the operator function uses the class name instead of a built-in data name. For example, if you have two classes Date and Intdate, the operator function Intdate() could be placed in the Date class to convert from Date to an Intdate. Similarly, the operator function Date() could be placed in the Intdate class to convert from an Intdate to a Date. Notice that as before, in converting a class type to a built-in data type, the operator function's name determines the result of the conversion; the class containing the operator determines the data type being converted.

Before seeing an example of a class conversion, you should note one additional point. Converting between classes clearly implies two classes: one is defined first, and one is defined second.
