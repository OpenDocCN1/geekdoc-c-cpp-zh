However, $2\Delta x_2 = \Delta x_1$, you can see that
$f(a + 2\Delta x_2) = f(a + x_1)$

and $f(a+\Delta x_i)$ was already determined in the previous calculation of $T_1$ (Equation 14.8). The point is that by successively doubling the number of panels in each stage, the only new information required to proceed to the next order trapezoidal rule approximation is the evaluation of the function at the midpoints of the current intervals.

To exploit this further, Equations 14.7 and 14.8 can be used to rewrite Equation 14.10 in this form:

```
$T_2 = (\Delta x_2)[f(a) + 2f(a+\Delta x_1) + f(b)] + \Delta x_2[f(a+\Delta x_2) + f(a+3\Delta x_2)]$
$= T_1/2 + \Delta x_2[f(a+\Delta x_2) + f(a+3\Delta x_2)]$  (Equation 14.10)
```

This equation can be generalized to

```
$T_k = T_{k-1}/2 + \Delta x_k \sum_{i=1}^{k-1} f(a+i\Delta x_k)$  (Equation 14.11)
```

where

```
Delta x_k = \frac{b-a}{2^k}$
```

The procedure for using Equation 14.11 to approximate an integral by a trapezoidal rule is:

- 1. Compute $T_0$ using Equation 14.6.
- 2. Repeatedly apply Equation 14.11 for $k=1, 2, \dots$ until sufficient accuracy is obtained.

# Example of a Trapezoidal Rule Calculation

To illustrate this section's concepts, the following integral is used:

```
$I = \int_1^2 (1/x) dx$
```

The function $f(x) = 1/x$ can, course, be integrated analytically to give $\ln(x)$, and because $\ln(1) = 0$, the value of the integral is $\ln(2) = 0.6931478$. The trapezoidal approximation to the integral with $a=1$ and $b=2$ begins with Equation 14.6 to obtain $T_0$:

```
$T_0 = \frac{1}{2}\left(1 + \frac{1}{2}\right)(2 - 1) = 0.75$
```

Repeated use of Equation 14.11 yields the following:

```
$k = 1
\Delta x_1 = 1/2$
$T_1 = T_0/2 + \Delta x_1[f(1 + \Delta x_1)] = 0.75/2 + 1/2(1+1/2) = 0.708333$
```

```
$k = 2
\Delta x_2 = 1/4$
$T_2 = T_1/2 + \Delta x_2(1/1.25 + 1/1.75) = 0.6970238$
```

```
$k = 3
\Delta x_3 = 1/8$
$T_3 = T_2/2 + \Delta x_3(1/1.25 + 1/1.375 + 1/1.625 + 1/1.875) = 0.69412185$
```

Continuing the calculation through $k=5$ yields the:

| k | $T_k$ |
| :--- | :--- |
| 0 | 0.75 |
| 1 | 0.708333 |
| 2 | 0.69702 |
| 3 | 0.69412 |
| 4 | 0.69339 |
| 5 | 0.693208 |
| . | . |
| Exact | 0.693147... . |

The convergence of the computed values of the trapezoidal rule isn't particularly fast, the method is quite simple.

# 14.7 Simpson's Rule

The trapezoidal rule is based on approximating the function by straight-line segments. To improve the method's accuracy and convergence rate, an obvious approach is approximating the function by parabolic segments in place of straight lines. This approach results in an approximation for the integral known as **Simpson's rule**; a simple example is shown in Figure 14.11. Specifying a parabola uniquely requires three points, so lowest-order Simpson's rule has two panels.

![](img/e2a849fc7bc04aa2e6669ad865e0c22b_799_0.png)

**Figure 14.11** Area under a parabola drawn through three points. To proceed, we need to know the area under a parabola drawn through three points. Note that the corresponding step in the derivation of the trapezoidal rule was simple: The area under a line through two points is $\Delta x(f(a) + f(b))/2$.

If the curve $f(x)$ drawn in Figure 14.11 is approximated by a parabola drawn through the three points—$f(a), f(b)$, and the value of $f(x)$ at the midpoint of the interval $f_{mid}$—it can be shown with calculus that the area under this parabola, denoted as $S_1$, is

```
$S_1 = \frac{\Delta x}{3} [f(a) + 4f(a+\Delta x) + f(b)]$
```

where

```
$\Delta x = \frac{b-a}{2}$
```

This is the first-order Simpson's rule approximation, where $k=1$ and $n=2^1$ panels. The next level of approximation is to halve the interval width and partition the interval into four panels, as shown in Figure 14.12. The area under the function $f(x)$ is then approximated as the area under two parabolas. Again, using calculus, it can be shown that the area under two parabolas is

```
$S_2 = \frac{\Delta x}{3} [f(a) + 4f(i) + 2f(j) + f(b)]$ (Equation 14.12)
```

where

```
$\Delta x_2 = \frac{b-a}{2^2}$
```

and

```
$i = f(a+\Delta x_2)$
```

![](img/e2a849fc7bc04aa2e6669ad865e0c22b_800_0.png)

Figure 14.12 The second-order Simpson's rule approximation is the area under two parabolas This procedure can be extended to 8, 16, 32, and so on panels. The result is a rather simple generalization of Equation 14.12, and for $n = 2^k$ panels is the following:

```
$S_k = \frac{\Delta x}{3} \left[ f(a) + 4\sum_{odd} f(a+i\Delta x_k) + 2\sum_{even} f(a+i\Delta x_k) + f(b) \right] \quad (Equation 14.13)
```

Equation 14.13, Simpson's rule, is a popular method of evaluating integrals of functions that are smooth, and so. As you see later in this chapter, Simpson's rule converges nicely in most instances and is easy to use. Also, Equation 14.13 can be adapted to easily handle an odd number of evenly spaced points and is the most common method for estimating the integral of experimentally obtained data.

# Example of Simpson's Rule as an Approximation to an Integral

Again, consider this integral:
$I = \int_1^2 \frac{1}{x} dx$

Using Equation 14.13 first for $k = 1$ yields the following:

- $k = 1, n = 2^1 = 2$
$\Delta x_1 = \frac{b-a}{2^2} = \frac{1}{2}$
$S_1 = \frac{\Delta x}{3}[1 + 4(1/1.5) + \frac{1}{2}] = 0.6944444$

- Repeating for $k = 2$ yields the following results:
$k = 2, n = 2^2 = 4$
$\Delta x_2 = \frac{1}{4}$
$S_2 = \frac{\Delta x}{3}[1 + 4(1/1.25 + 1/1.75) + 2(1/1.5) + \frac{1}{2}] = 0.69325397$

Continuing the calculation, you get the values listed in Table 14.2. For comparison, results are also included for the same integral obtained in Section 14.6 when using the trapezoidal rule. Clearly, Simpson's Rule converges much faster than the trapezoidal rule, at least for this example.
