# 624 Class Functions and Conversions

```
{
  temp.month++;
  temp.day = 30;
}
while (temp.month > 12) // adjust the years
{
  temp.year++;
  temp.month -= 12;
}
return temp;
```

The only difference between this version and the member version is the explicit use of a Date argument named op1 (an arity name choice) in the friend version. Therefore, in the friend function's body, the first three assignment statements refer op1's members as op1.day, op1.month, and op1.year, whereas the member function refers to its arguments as day, month, and year.

In determining whether to overload a binary operator as a friend or member operator function, follow this guideline: Friend functions are more appropriate for binary functions that don't modify their operands (such as ==, < and so forth), and member functions are more appropriate for binary functions that modify their operands (such as =, += and -=).
