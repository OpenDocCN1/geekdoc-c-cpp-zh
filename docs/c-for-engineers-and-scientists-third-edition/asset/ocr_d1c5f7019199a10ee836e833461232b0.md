# 6.6 Variable Storage Categories

The scope of a variable defines the location in a program where that can be used. If you draw a box around the section of program code where each variable is valid, the space inside the box would represent the variable's scope. From this viewpoint, a variable's scope can be thought of as the space in the program where the variable is valid.
