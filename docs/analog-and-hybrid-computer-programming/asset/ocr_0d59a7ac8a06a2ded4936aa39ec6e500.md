The LAPLACE delay operator may now be approximated quite simply by the following first-order Padé approximation.⁶⁸

$$P_1(s)=\frac{y_o(s)}{y_i(s)}=\frac{1-\frac{sT}{2}}{1+\frac{sT}{2}}=\frac{2-sT}{2+sT}$$

Cross multiplying the two fractions yields

$$y_o(s)(2+sT)=y_i(s)(2-sT).$$

Treating $s$ as the differentiation operator as before this equation can be interpreted as follows:⁶⁹

$$2y_o+T\dot{y}_o=2y_i-T\dot{y}_i.$$

Rearranging terms yields

$$T(\dot{y}_o+\dot{y}_i)=2(y_i-y_o).$$ \hfill (5.5)

Unfortunately, this differential equation cannot readily be implemented as an analog computer program using the well-known KELVIN-feedback technique. Because there are two derivatives of degree one there is no single highest derivative to solve (5.5) for. Although time-derivatives can be generated on an analog computer,⁷⁰ this is generally not advisable. Instead, integrating over both sides yields

$$T\int_{0}^{t}(\dot{y}_o+\dot{y}_i)\,dt=2\int_{0}^{t}(y_i-y_o)\,dt$$

from which

$$\frac{T}{2}(y_o+y_i)=\int_{0}^{t}(y_i-y_o)\,dt$$

follows.
