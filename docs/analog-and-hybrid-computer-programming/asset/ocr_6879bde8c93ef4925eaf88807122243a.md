$\dot{y}_0 = -a\omega\cos(\tau).$

Since this basic circuit yields $-\cos(\tau)$ as well as $\sin(\tau)$ for $y_0 = 0$ and $\dot{y}_0 = 1$, it is commonly called a *quadrature generator*. It is the basis of many more complex computer setups and is especially useful when figures based on closed loops need to be displayed on an oscilloscope as well as shown in later sections.

Now, what about $0 < \omega < 1$? Wouldn’t a simple solution just require a single coefficient potentiometer after the inverter in the setup shown in figure 4.8? Unfortunately, this is not the case as $\omega$ effectively affects the time-scaling of both integrators! Just using one potentiometer following the inverter, thus preceding the input of the leftmost integrator, would just change its time scale factor to $\omega k_0$ while the second integrator would still run at $k_0$. Therefore, it is typically necessary to change the time scale factor of both integrators at once, as shown in figure 4.9.

Figure 4.10 shows the resulting output signal of the leftmost integrator for $\omega = \frac{1}{2}$. One $x$-division of the screen corresponds to 2 ms as before. So one period of the displayed sine-signal is about 12.55 ms which is a good approximation to $4\pi$ as would be expected for this particular value for $\omega$.
