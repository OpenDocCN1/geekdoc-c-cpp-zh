There is some interplay between the settings of the potentiometers labelled a and a*. As a determines the initial amplitude of the output signal, a* should be set so that the diode bias voltage is of the same size as this initial amplitude. If a > a* the amplitude stabilization circuit will kick in directly after setting the computer to OP-mode. This will result in a quickly decreasing amplitude which is normally undesirable.
