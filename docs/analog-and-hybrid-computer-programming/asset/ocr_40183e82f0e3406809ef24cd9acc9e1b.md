It is assumed that the y component of the cannon's position satisfies y_cannon > 0 while the target's y component is y_target = 0. Using a comparator as shown in figure 7.2, an external halt signal is generated when the shell hits the ground. Its output is not connected to anything as it is only read out by the digital computer after a run to determine the miss distance δ.
