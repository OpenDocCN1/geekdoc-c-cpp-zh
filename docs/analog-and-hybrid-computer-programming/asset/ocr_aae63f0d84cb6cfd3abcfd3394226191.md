# Arch Linux 安装教程

本文将详细介绍如何从零开始安装 Arch Linux，包括分区、安装基础系统、配置网络和引导程序等步骤。

+   * 安装前准备
+   * 磁盘分区
+   * 安装基础系统
+   * 配置系统
+   * 安装引导程序
+   * 完成安装

> > 注意：本教程适用于 UEFI 启动模式。如果你使用 BIOS/MBR，请参考相关文档。

```
```bash
# 验证启动模式
ls /sys/firmware/efi/efivars
```
```

| 分区 | 挂载点 | 大小 |
|------|--------|------|
| /dev/sda1 | /boot/efi | 512M |
| /dev/sda2 | / | 剩余空间 |

分区完成后，使用 mkfs 命令格式化分区，然后挂载到 `/mnt`。接下来使用 `pacstrap` 安装基础系统。
