# B.1.2 Delta function

In many cases, the DIRAC delta function¹⁵⁶ δ(t) is used as input for a dynamic system.¹⁵⁷ It has zero width but satisfies

∫_{-∞}^{∞} δ(t) dt = 1

and is therefore often called the unit impulse. It can be understood as the derivative of the unit step function u(t). Its LAPLACE transform can therefore be derived by integrating by parts as follows:

ℒ{δ(t)} = ∫_{0-}^{∞} (d/dt u(t)) e^{-st} dt = [u(t)e^{-st}]_{0-}^{∞} - ∫_{0-}^{∞} u(t)(-s e^{-st}) dt = 0 + s ∫_{0-}^{∞} e^{-st} dt

Substituting φ = -st as before yields dt = -1/s dφ so that

s ∫_{0-}^{∞} e^{-st} dt = - ∫_{0-}^{∞} e^{φ} dφ = [e^{-st}]_{0-}^{∞} = 1.

Thus, ℒ{δ(t)} = 1.

# B.1.3 Ramp function

Another basic function is the ramp function

f(t) = { 0  t < 0 ; a t  t > 0 }

Its LAPLACE transform can be derived as follows, using integration by parts:

ℒ{f(t)} = a ∫_{0-}^{∞} t e^{-st} dt = a ( [ - t e^{-st} / s ]_{0-}^{∞} - ∫_{0-}^{∞} e^{-st} / s dt ) (B.4)
