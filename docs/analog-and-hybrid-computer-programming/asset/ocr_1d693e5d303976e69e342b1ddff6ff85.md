IO::HyCon requires a configuration file in YAML-format<sup>135</sup> which describes the actual setup of the analog computer, i.e. the addresses of the various computing elements, the serial line parameters, etc. A typical minimum example is shown in the following listing:<sup>136</sup>

```
```yaml
serial:
  port: /dev/cu.usbserial-DN05OL10
  bits: 8
  baud: 115200
  parity: none
  stopbits: 1
  poll_interval: 10
  poll_attempts: 20000
types:
  0: PS
  1: SUM8
  2: INT4
  3: PT8
  4: CU
  5: MLT8
  6: MDS2
  7: CMP4
  8: HC
manual_potentiometers:
elements:
  INT-0: 0x0030
  INT-1: 0x0031
  INT-2: 0x0032
  INT-3: 0x0033
```
```

It consists of the following sections:

**serial:** This section describes the communication setup. port defines the serial device. Its name depends on the operating system and the USB-serial-adapter being used. The remaining parameters are defaults and can be adopted unchanged in most cases.

136 There are more optional sections and settings which will be introduced when required.
