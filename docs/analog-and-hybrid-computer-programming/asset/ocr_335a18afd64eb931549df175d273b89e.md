# MIKUSIŃSKI's operational calculus

This appendix briefly describes an alternative technique to the LAPLACE transformation, which can be used to solve certain differential equations analytically.

# C.1 Introduction

The polish mathematician JAN MIKUSIŃSKI developed an *operational calculus*, the *Calculus of MIKUSIŃSKI*[^162], which will be explored here. His work justified the empirical operator calculus developed and used by OLIVER HEAVISIDE to tackle the problems of signal transmission along undersea cables.[^163]
