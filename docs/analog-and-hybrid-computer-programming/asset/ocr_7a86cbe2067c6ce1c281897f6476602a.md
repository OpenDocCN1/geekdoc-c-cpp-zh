# 6.18 Nosé-Hoover oscillator

Another beautiful chaotic system is the Nosé-Hoover oscillator, which is described in [SPROTT 2010, pp. 95 ff.]. This system is described by the following set of coupled differential equations:

```
\dot{x} = y
\dot{y} = y z - x
\dot{z} = 1 - y^2
```
