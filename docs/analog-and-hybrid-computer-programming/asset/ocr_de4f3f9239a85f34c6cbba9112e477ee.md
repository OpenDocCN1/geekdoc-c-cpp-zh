A two step reaction system such as

\[A \xrightarrow{k_1} B \xrightarrow{k_2} C\]

can be described by the following set of coupled differential equations

\[\begin{aligned}
\dot{a} &= -k_1a \\
\dot{b} &= k_1a-k_2b \text{ and} \\
\dot{c} &= k_2b.
\end{aligned}\]
