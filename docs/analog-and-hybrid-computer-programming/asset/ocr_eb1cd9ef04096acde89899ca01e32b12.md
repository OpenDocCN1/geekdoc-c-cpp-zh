# 4.4.2 Variants

Although this implementation is quite elegant, it comes at a cost as it requires two multipliers, two integrators, and one summer just for the generation of the sine function. In cases like this mathematical pendulum, where the argument of the trigonometric function is restricted (which is the case as long as the pendulum does not flip over), other implementation variants may be advantageous.

A straightforward approach would be to use the TAYLOR series

$$\sin(\varphi) = \sum_{n=0}^{\infty} (-1)^n \frac{\varphi^{2n+1}}{(2n+1)!}$$

to approximate the required harmonic function. Depending on the desired accuracy which in turn depends on the range of the argument φ, it will typically suffice to set

$$\sin(\varphi) \approx \varphi - \frac{\varphi^3}{6}\tag{4.7}$$

for arguments restricted to $-\pi/4 \le \varphi \le \pi/4$.
