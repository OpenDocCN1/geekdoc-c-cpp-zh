
### B.1.2 Delta function
In many cases, the DIRAC delta function¹⁵⁶ δ(t) is used as input for a dynamic system.¹⁵⁷ It has zero width but satisfies

∫_{-∞}^{∞} δ(t) dt = 1

and is therefore often called the unit impulse. It can be understood as the derivative of the unit step function u(t). Its LAPLACE transform can therefore be derived by integrating by parts as follows:

ℒ{δ(t)} = ∫_{0-}^{∞} (d/dt u(t)) e^{-st} dt = [u(t)e^{-st}]_{0-}^{∞} - ∫_{0-}^{∞} u(t)(-s e^{-st}) dt = 0 + s ∫_{0-}^{∞} e^{-st} dt

Substituting φ = -st as before yields dt = -1/s dφ so that

s ∫_{0-}^{∞} e^{-st} dt = - ∫_{0-}^{∞} e^{φ} dφ = [e^{-st}]_{0-}^{∞} = 1.

Thus, ℒ{δ(t)} = 1.

### B.1.3 Ramp function
Another basic function is the ramp function

f(t) = { 0  t < 0 ; a t  t > 0 }

Its LAPLACE transform can be derived as follows, using integration by parts:

ℒ{f(t)} = a ∫_{0-}^{∞} t e^{-st} dt = a ( [ - t e^{-st} / s ]_{0-}^{∞} - ∫_{0-}^{∞} e^{-st} / s dt ) (B.4)

Substituting \(\varphi=-st\) again gives

\[
-\int_{0}^{\infty}\frac{e^{-st}}{s}\,dt=\frac{1}{s^{2}}\int_{0}^{\infty}e^{-\varphi}\,d\varphi=\left[\frac{e^{-st}}{s^{2}}\right]_{0}^{\infty}. \tag{B.5}
\]

Combining (B.4) and (B.5) gives

\[
\mathcal{L}(f(t))=a\left[\frac{te^{-st}}{s}-\frac{e^{-st}}{s^{2}}\right]_{0}^{\infty}-a\left[\frac{(st+1)e^{-st}}{s^{2}}\right]_{0}^{\infty}=\frac{a}{s^{2}}.
\]

### B.1.4 Exponential and trigonometric functions
The Laplace transform of the exponential function has the form

\[
\mathcal{L}(e^{-at})=\int_{0}^{\infty}e^{-at}e^{-st}\,dt=\left[\frac{e^{-(s+a)t}}{-(s+a)}\right]_{0}^{\infty}=\frac{1}{s+a}.
\]

The basic trigonometric functions can also be transformed in a straightforward fashion using the identities

\[
\sin(\varphi)=\frac{e^{i\varphi}-e^{-i\varphi}}{2i}
\] and

\[
\cos(\varphi)=\frac{e^{i\varphi}+e^{-i\varphi}}{2}.
\]

Using (B.6) gives

\[
\begin{aligned}
\mathcal{L}(\sin(\omega t))&=\int_{0}^{\infty}\sin(\omega t)e^{-st}\,dt
=\int_{0}^{\infty}\left(\frac{e^{i\omega t}-e^{-i\omega t}}{2i}\right)e^{-st}\,dt\\
&=\frac{1}{2i}\int_{0}^{\infty}\left(e^{(i\omega-s)t}-e^{-(i\omega+s)t}\right)dt
=\left[\frac{e^{(i\omega-s)t}}{i\omega-s}\right]_{0}^{\infty}-\left[\frac{e^{-(i\omega+s)t}}{-i\omega-s}\right]_{0}^{\infty}\\
&=\frac{1}{2i}\left(\frac{1}{-s+i\omega}-\frac{1}{-s-i\omega}\right)=\frac{\omega}{s^{2}+\omega^{2}}.
\end{aligned}
\]

Using (B.7) the relation

\[
\mathcal{L}(\cos(\omega t))=\frac{s}{s^{2}+\omega^{2}}
\]

can be derived analogously.

## B.2 Laplace transforms of basic operations
Things really get interesting when the LAPLACE transforms of operations instead of simple functions are computed. This is shown below for the time derivative and the time integral of a function. Let

$f(t)=\frac{dx}{dt}$

then integration by parts gives

$\mathcal{L}\{f(t)\}=\int_{0^-}^{\infty}\frac{dx}{dt}e^{-st}\,dt$
$=\left[xe^{-st}\right]_{0^-}^{\infty}-\int_{0^-}^{\infty}-sxe^{-st}\,dt$
$=s\mathcal{L}\{x\}-x(0^-).$

Here $x(0^-)$ denotes the initial value of $x$ at $t=0^-$. The interesting fact is that the time derivative of a function $f(t)$ can be transformed into the much simpler multiplication of the LAPLACE transform of the function with $s$. This can be extended to higher derivatives as well. From

$f(t)=\frac{d^2x}{dt^2}$

follows that

$\mathcal{L}\{f(t)\}=\int_{0^-}^{\infty}\frac{d^2x}{dt^2}e^{-st}\,dt=s^2\mathcal{L}\{f(t)\}-sx(0^-)-\left[\frac{dx}{dt}\right]_{t=0}$

and so forth.

If multiplication with $s$ is the transform of a time derivative, it is tempting to assume that integration will be transformed into a division by $s$. This, indeed, is the case. Let

$f(t)=\int_{0^-}^{t}x\,dt+c$

with $c$ being a constant real value. Its LAPLACE transform is

$\mathcal{L}\{f(t)\}=\int_{0^-}^{\infty}\left(\int_{0^-}^{t}x\,dt\right)e^{-st}\,dt+\frac{c}{s}$

= \left[ -\frac{1}{s} e^{-st} \int_{0-}^{t} x \,dt \right]_{0-}^{\infty} + \frac{1}{s} \int_{0-}^{\infty} x e^{-st} \,dt + \frac{c}{s}

= \frac{1}{s} \mathcal{L}(f(t)) + \frac{c}{s}.

The constant $\frac{c}{s}$ is the initial value of the integral.

## B.3 Further characteristics
Given two functions $f(t)$ and $g(t)$ which can be subjected to a LAPLACE transform yielding $F(s)$ and $G(s)$, the transform has the following useful characteristics:

$\mathcal{L}(\lambda f(t) + g(t)) = \lambda F(s) + G(s)$ \quad\quad (linearity)
$\mathcal{L}(f(\lambda t)) = \frac{1}{\lambda} F\left(\frac{s}{\lambda}\right)$ \quad\quad (scale factor)
$\mathcal{L}(e^{-\beta t} f(t)) = F(s + \beta)$ \quad\quad (exponential damping)
$\mathcal{L}(f(t - T) u(t - T)) = e^{-T s} F(s)$ \quad\quad (time shift)
$\mathcal{L}((f * g)(t)) = F(s) G(s)$ \quad\quad (convolution, see (C.1))

## B.4 Inverse Laplace transform
The inverse LAPLACE transform is defined as

$f(t) = \mathcal{L}^{-1}(F(s)) = \frac{1}{2\pi i} \lim_{T \to \infty} \int_{\gamma - iT}^{\gamma + iT} e^{st} F(s) \, ds$

with $\gamma \in \mathbb{R}$ denoting a vertical line in the complex number plane. $\gamma$ is chosen so that all singularities of $F(s)$ are on its left. This transform is known as the Bromwich integral, after THOMAS JOHN L'ANSON BROMWICH and is typically solved using the residue theorem.$^{160}$

Normally, this process is avoided by using tables of functions and their LAPLACE transforms e.g.:

$\mathcal{L}\{\delta(t)\}=1$
$\mathcal{L}\{\delta(t-T)\}=e^{-Ts}$
$\mathcal{L}\{u(t)\}=\frac{1}{s}$
$\mathcal{L}\{\frac{1}{\sqrt{\pi t}}\}=\frac{1}{\sqrt{s}}$
$\mathcal{L}\{t^n\}=\frac{n!}{s^{n+1}}$
$\mathcal{L}\{t^n e^{-at}\}=\frac{n!}{(s+a)^{n+1}}$
$\mathcal{L}\{\frac{1}{a}(1-(1+at)e^{-at})\}=\frac{1}{s(s+a)^2}$
$\mathcal{L}\{\frac{e^{-at}-e^{-bt}}{b-a}\}=\frac{1}{(s+a)(s+b)}$
$\mathcal{L}\{\sin(\omega t)\}=\frac{\omega}{s^2+\omega^2}$
$\mathcal{L}\{\cos(\omega t)\}=\frac{s}{s^2+\omega^2}$
$\mathcal{L}\{e^{-at}\sin(\omega t)\}=\frac{\omega}{(s+a)^2+\omega^2}$
$\mathcal{L}\{e^{-at}\cos(\omega t)\}=\frac{s+a}{(s+a)^2+\omega^2}$
$\mathcal{L}\{\sinh(\omega t)\}=\frac{\omega}{s^2-\omega^2}$
$\mathcal{L}\{\cosh(\omega t)\}=\frac{s}{s^2-\omega^2}$
$\mathcal{L}\{\frac{\sqrt{a^2+\omega^2}}{\omega}\sin(\omega t+\tan^{-1}(\frac{\omega}{a}))\}=\frac{s+a}{s^2+\omega^2}\quad\text{(B.8)}$
$\mathcal{L}\{\frac{\sin(\omega t)}{t}\}=\arctan\left(\frac{\omega}{s}\right)$

## B.5 Example
Solving a differential equation such as

$\ddot{x}+x=\delta(t)$

using the LAPLACE transform is pretty straightforward. First, the transform is applied to both sides yielding

$s^2\mathcal{L}\{x\}-s x(0-)-[\dot{x}]_{t=0}+\mathcal{L}\{x\}=1.$

Using analog computing elements, simulations of complex systems described by block diagrams and corresponding transfer functions can easily be set up.

Details of this technique, which exceeds the scope of this book, can be found in [SENSICLE 1968], [JOHNSON 1956, pp. 45 ff.], [GILOI et al. 1963, pp. 288 ff.], [CARLSON et al. 1967, pp. 191 ff.], [SYDOW 1964, pp. 128], and other classic text books. Good examples of application are described in [WEEDY et al. 1998] and [GILES 1976].
