Applying this to (4.14) yields the following scaled equation.47

$$\widehat{Q}'' = -3.92 \cdot 10^3 \widehat{Q}' - 1.63 \cdot 10^8 \widehat{Q}$$

The initial condition $Q_0$ must be scaled accordingly yielding (approximately)

$$\widehat{Q}_0 = 0.833.$$

With these scaled amplitudes the remaining step is time scaling. The (un-damped) angular frequency$^{48}$ of the basic RLC-circuit shown in figure 4.25 is

$$\omega = \frac{1}{\sqrt{LC}} \approx 12783\ \text{s}^{-1}$$

resulting in

$$\nu \approx 2\ \text{kHz}$$

since $\nu = \omega/2\pi$. A time-scaling factor of $\beta = 10^4$ is chosen which finally yields

$$\frac{d^2 \widehat{Q}}{d\tau^2} = -0.392 \frac{d\widehat{Q}}{d\tau} - 1.63\widehat{Q}.$$

The coefficients 0.392 and 1.63 can now be readily set as $\mu$ and $\nu$ in the computer setup shown in figure 4.24 with 1.63 represented by $\nu = 0.163$ feeding an integrator input weighted by 10.
