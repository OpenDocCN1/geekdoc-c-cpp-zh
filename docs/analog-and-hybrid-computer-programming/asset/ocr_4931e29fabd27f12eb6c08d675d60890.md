The force exerted on the α-particle is described by COULOMB's law

F = k_e q1 q2 / r^2  (6.26)

where k_e = 8.9875·10^9 Nm^2 C^-2 is COULOMB's constant and q1, q2 are the magnitudes of the charges involved. Since the following simulation will be a qualitative one all of these constants, including masses, can be gathered together in a new variable γ.

The force F acts proportionally to cos(φ) and sin(φ) on x and y with

cos(φ) = x / r and sin(φ) = y / r.

Together with (6.26) and γ this yields the following two coupled differential equations which govern the path of the α-particle:

ẋ = γ x / r^3

ÿ = γ y / r^3

The setup for this problem, which is pretty straightforward, is shown in figure 6.27. It should be noted that there is an explicit additional feedback-path for the summer adding x^2 and y^2, which gives a scaling factor of 1/2. Accordingly, the resulting sum satisfies 0 ≤ r_s ≤ 1, so no overload condition can occur here. As mentioned above, all constants, including this factor 1/2, are gathered into the parameter γ_s. A typical value for this parameter – yielding nice scattering behaviour – is ≈ 0.01.

The only other free parameter is the initial height of the α-particle's trajectory y0. This can be either set manually by means of a free potentiometer connected to +1 and −1 or automatically as shown in figure 6.28 by means of a triangle wave generator consisting of an integrator working in conjunction with two comparators.

To run this program the analog computer is set to repetitive operation with an operation time t_OP = 30 ms. The integrator of the triangle wave generator must be disconnected from the central timing control by patching its ModelC-input to +1 (only the third or fourth integrator of an INT4 module can be used for that purpose), so that it will not be reset between two successive computing runs.
