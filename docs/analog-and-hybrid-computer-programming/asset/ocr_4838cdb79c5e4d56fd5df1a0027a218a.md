It should be noted that $\int_0^t g(t - \tau)f(\tau)d\tau = \int_0^t f(t - \tau)g(\tau)d\tau$ so either the left- or the right-hand function can be interpreted as the weighting function. For the purposes of this discussion it will be assumed that the left-hand function is the weighting function.

To eliminate the somewhat clumsy convolution notation MIKUSIŃSKI introduces the notation $\{f(t)\}$ to denote the function $t \mapsto f(t)$ while $f(t)$ represents the value this function takes at $t$. Using this notation (C.1) reduces to $\{g(t)\}\{f(t)\}$. This looks quite like a multiplication operation and paves the way for the next step.$^{164}$

The special case of $g(t) \equiv 1$ immediately yields $\{1\}\{f(t)\} = \left\{\int_0^t f(\tau)d\tau\right\}$ which suggests the interpretation of $l := \{1\}$ as an integration operator. $l$ can now be used in the following way for example: $l\{\sin(t)\} = \left\{\int_0^t \sin(\tau)d\tau\right\} = -\cos(\tau)\Big|_0^t = 1 - \cos(t)$

Notably, $l$ as an operator allows “calculating” with it as if it were a number or a function. A naturally occurring question concerns the powers of $l$ – what do these look like? $l^2 = l\{1\} = \left\{\int_0^t 1 d\tau\right\} = \{t\}$ $l^3 = l\{t\} = \left\{\int_0^t \tau d\tau\right\} = \left\{\frac{1}{2}t^2\right\}$ $l^4 = l\left\{\frac{1}{2}t^2\right\} = \left\{\frac{1}{2}\int_0^t \tau^2 d\tau\right\} = \left\{\frac{1}{6}t^3\right\}$ etc. This can be generalized to $l^n = \left\{\frac{t^{\,n-1}}{(n-1)!}\right\}$ for $n \in \mathbb{N}.$
