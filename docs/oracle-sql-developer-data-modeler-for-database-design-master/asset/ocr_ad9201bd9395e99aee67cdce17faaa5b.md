# Introducing Design Properties

In addition to properties that help set up your Data Modeler working environment, there are also properties that affect only the particular design you set for. This is a new behavior starting with Data Modeler version 4.0. Since version 4.0.3, either double-click the design name in the Browser pane or right-click and select Properties to open the Design Properties dialog. You can select the Global Design Level Options under Settings. If you Use Global Design Settings, the properties are modified automatically by global design-level settings from the datamodel\datamodel\types\dl_settings.xml. Also, when some of the properties are changed in a design that has Global Design Level Settings, the changes are saved both to the local file and to the global file. For instance, changes to classification types, default fonts and colors, default line widths and colors, naming standard rules, and compare mappings are implemented automatically in the Design Properties dialog.
