5-18 shows an example of a table-per-child solution (described in Chapter 4) and how it is transformed to a relational model. There are two tables (on the right). There are no foreign keys on these tables, and the attributes from the parent entity have been transformed into columns in both table. The attributes in child entities are transformed into columns on the corresponding table. The primary key for both tables is created based on the primary key of the parent table.
