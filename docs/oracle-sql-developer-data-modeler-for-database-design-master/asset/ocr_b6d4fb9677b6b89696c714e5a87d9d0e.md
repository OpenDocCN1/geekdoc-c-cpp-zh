Query Builder, shown in Figure 5-27, you create a query for a view easily. The Query Builder consists of an element filter on the right, output criteria, and three screens for fine-tuning the query on the left: the main canvas, output criteria, and SQL preview. If you do not select Query List from the top of the screen, you will not see this output criteria in the middle. From the filter on the right, you can drag tables to the query canvas (Main) to be included in the query. You can limit the table list to a certain relational model or a subview (Filter Metadata Objects By Diagram). On the canvas you can select the columns you want to be included and deselect the ones you do not want. In the window below Main, the output criteria screen, you can select which columns will be shown in the result of the query and also specify aggregates, aliases, sort types, order, grouping, and criteria for columns to be evaluated on.
