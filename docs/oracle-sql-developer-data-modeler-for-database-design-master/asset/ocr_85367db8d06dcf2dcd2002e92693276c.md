A deprecated element is shown with strikethrough. If the table name has “1” in the end of the name, it means you have created graphical symbols for that table. If you right-click a relational model or a subview canvas, you can decide what details will be on the diagram by selecting View Details, as shown in Figure 5-23.

The main concepts in the relational model are tables, columns, and foreign keys. In a relational model you can share tables officially with other relational models in a same design but in practice with other designs. If you drag a table to another design, the tool shows it is not possible, but it creates a shared table between the two designs. Sharing between designs has some limitations: You cannot have design-level domains and definitions from the data types model because they cannot be used in table definitions.
