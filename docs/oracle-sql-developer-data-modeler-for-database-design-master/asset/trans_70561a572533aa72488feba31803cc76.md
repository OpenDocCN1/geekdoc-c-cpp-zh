要创建一个新的触发器，请转到物理模型的浏览器（Browser）面板，选择你想要添加触发器的表或视图名称，转到“触发器”（Triggers），右键点击并选择“新建”（New）。对于触发器，你可以在四个选项卡上定义属性：常规（General）、触发器体（Trigger Body）、更新列（Update Columns）和注释（Comments）。在常规选项卡上，你定义触发器的名称、架构所有者（用户）以及调用它的触发操作（插入/或更新和/或删除）。你还可以指定触发时间（执行前/执行后）、范围（每行、每条语句）以及状态（启用/禁用）。你还可以定义旧参数名（Ref OLD as）、新参数名（Ref NEW as）、父级参数名（Ref PARENT as）以及条件（Condition）。在触发器体选项卡上，你可以为触发器操作编写实际的 PL/SQL 代码；在更新列选项卡上，如果触发器的操作是更新，你可以选择或删除要更新的列。在注释选项卡上，你可以对触发器进行文档说明。

## 自定义数据类型

你无法在物理模型中创建数据类型，但你早期在数据类型模型中定义的集合类型和结构化类型会自动带到物理模型中。

你可以更改集合类型的名称，并为其定义所有者（Owner）、强制放置（NO/YES）、OID（对象标识符）和注释（Comments）设置。你还可以点击“权限”（Permissions）按钮来定义权限。

你还可以重命名结构化类型，并为其定义所有者（Owner）、强制放置（NO/YES）、全局 ID（Global ID）、调用者权限（空、Current_user、Defined）、映射顺序函数（Map Order Functions）、映射到 Java 类（NO/YES）以及注释（Comments）设置。你还可以点击“权限”（Permissions）按钮来定义权限。

## 其他元素

如果你想在 Data Modeler 中对整个数据库进行设计和文档化，这是可以到的。你可以将一个数据库及其属性添加到物理模型中，以获取其 DDL。在数据库属性（Database Properties）中，你可以在常规（General）、日志（Logging）和表空间（Tablespaces）上定义属性，并编写注释。在定义物理模型的数据库后，你可以在浏览器面板中看到新的分支，用于向数据库添加数据文件、重做日志组和 SYSAUX 文件。

你可以定义目录和磁盘组，并定义上下文（contexts），上下文是一组应用程序定义的属性，用于验证和保护应用程序。你还可以创建簇（clusters）。簇是一个包含一个或多个表数据的架构对象。簇的数据特点是数据被被在一起检索并保存在彼此附近，以实现快速性能。簇中的所有表必须至少有一个共同列。索引簇存储所有共享相同簇键的表行，而哈希簇则将具有相同哈希值的行存储在一起。在物理模型中，你可以创建一个簇，并在“簇属性”对话框的“表/物化视图属性”选项卡上将表或物化视图附加到其中。

## 属性传播

在大多数属性对话框中，你都会看到一个“传播属性”（Propagate Properties）按钮。当你定义了一种类型对象的属性并希望将相同的属性复制到其他相同类型的对象时，此功能非常有用。例如，你可能定义了表的某些属性，如表空间、日志、存储、行依赖、行移动和权限，并且你希望另外 25 张表也具有相同的设置。与其为这 25 张表手动输入所有信息，你可以使用“传播属性”工具。在一个表上设置好所需的属性后，只需点击“传播属性”。打开“属性传播”对话框时，你可以首先选择要传播的属性，然后选择这些属性将传播到哪些对象。这个工具可能是你或你的 DBA 在物理数据库设计中最喜欢的工具。

## 索引

索引是提供快速查询数据库中数据的数据库对象。不同类型的搜索有不同类型的索引。通常，索引的合理性取决于使用情况：数据量、数据的主要使用方式（查询/更新/插入/删除）以及查询的频率。如果数据量很小，可能不需要索引。如果数据主要是插入、更新和删除，那么添加索引可能不是一个好主意，因为索引只会让查询变快，而让其他操作变慢。如果你有一个每年只运行一次的查询，那么在数据库中维护一个支持它 12 个月的索引可能不是一个好主意。索引是为表的某一列或若干列定义的，它仅支持那些在 WHERE 子句中包含这些列的查询。索引并不支持所有查询，它不是性能的万灵药。

## 分区

如果一个表或物化视图很大，可以对其进行分区。Oracle 的分区需要企业版提供的分区选项。分区使得维护变得更容易并提升了性能。在我看来，分区的主要优势是维护，其次是性能提升。例如，分区使得删除变得快速；你只需删除一个分区。如果你决定使用分区，请仔细考虑你的 RDBMS 的功能并仔细设计。

分区操作只影响物理架构。这意味着逻辑模型（和关系模型）保持不变。某些分区可能需要额外的列来获取有效分区键，这时必须更改逻辑模型和程序。

你可以在物理模型的浏览器面板中创建一个新分区；在要创建分区的表下右键点击并选择“新建”。有五个选项卡：常规（General）、子分区顺序（Subpartition Order）、子分区（Subpartitions）、本地索引（Local Index）和注释（Comments）。在常规选项卡上，你可以指定以下设置：名称、列表（自由文本编辑）、表空间（从表空间列表中选择）、日志（null, YES, NO）、存储（从存储模板列表中选择）以及数据压缩（null, YES, NO）。对于属性中的表，你将分区属性设置为 YES，并在“分区”选项卡上选择分区类型，如果需要，还选择子分区类型。在为表选择了子分区类型后，你可以创建一个所选类型的新的子分区（哈希、列表、范围），并指定 DDL 所需的参数。
