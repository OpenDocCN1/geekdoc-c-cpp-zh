mentioned earlier: no design-level domains and no definitions from the data types model. I also suggest selecting the automatic synchronization in this case.

# Tables

Tables have many properties. The ones that also exist for an entity will be transformed from the entity during the engineering process, and that are table specific can be edited in the Table Properties dialog, as shown in Figure 5-25. The first thing to do after the engineering would probably be to run the naming rules for a relational model. can be easily done by clicking the Naming Rules button on the General panel of the Table Properties dialog.
