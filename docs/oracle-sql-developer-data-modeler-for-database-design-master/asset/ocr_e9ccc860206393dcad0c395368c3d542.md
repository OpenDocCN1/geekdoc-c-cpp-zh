# Chapter 7: Generating DDL Scripts for Creating Database Objects 167

PROMPT command is added before each DDL statement in the generated DDL statements. The PROMPT command is used for viewing the progress of a script execution.

+   - If the SQL Developer Formatter preference is selected under SQL Formatting, the SQL formatting follows the SQL Developer defaults; if it is not selected, the formatting follows the traditional Data Modeler defaults.

+   - In Default DDL Files Export Directory, you can specify the directory where the DDL files will be saved by default.

+   - The preference Extended Size For Characters Oracle was introduced in version 4.0.3. It defines whether the MAX_STRING_SIZE = EXTENDED initialization parameter is available when generating the DDL.

+   - A new preference called Include Design And Name DDL Files Path was introduced in 4.0.3. By selecting this preference, you will have the design and model names for the DDL file paths, which makes finding the right DDLs easier. I recommend selecting this preference.

Here is an example of a DDL script for a table called Order with all the preferences earlier selected:

```
PROMPT CREATING TABLE 'Order';
CREATE TABLE "Order"\(
  "OrderNo" NUMBER NOT NULL,
  "Information" VARCHAR2 (100 CHAR) NULL
)
ORGANIZATION HEAP NOCOMPRESS NOCACHE PARALLEL NOROWEDDEPENDENCIES
DISABLE ROW MOVEMENT;
COMMENT ON TABLE "Order"
IS
'This is the table for Orders.';
PROMPT CREATING PRIMARY KEY ON 'Order';
ALTER TABLE "Order" ADD CONSTRAINT "Order_pk" PRIMARY KEY ("OrderNo"
 NOT DEFERABLE VALIDATE;
```

If the Use SQL Developer Formatter preference under SQL Formatting is not selected, the DDL would look like this:

```
PROMPT CREATING TABLE 'Order';
CREATE TABLE "Order"\(
  "OrderNo" NUMBER NOT NULL,
  "Information" VARCHAR2 (100 CHAR) NULL
```
