## 添加业务信息

你可以向 Data Modeler 添加业务信息。在浏览器窗格中进入逻辑模型（Logical Model），双击或右键点击并选择属性（Properties）。在逻辑模型属性中，你可以添加、编辑和删除文档以及负责方。负责方可以包括例如，电子邮件地址、电话号码、统一资源定位符（URL）和位置。所有这些内容都可以先添加到负责方，然后通过双击或选择属性符号（铅笔图标）进行编辑。你可以为设计中的元素添加负责方。

此外，你可以对对象发起请求，并定义例如状态、完整性、请求日期、完成日期和原因。例如，假设你想为实体 Customer 增加一个“新属性，状态”的变更请求。你可以使用搜索功能（有关搜索的更多信息请参见第 11 章）找到所有未完成的变更请求。选择逻辑模型然后选择高级模式（Advanced Mode）。从对象类型列表中选择变更请求逻辑（Change Request Logical）并点击添加属性。选择完成（Complete）并将 False 定义为值。在结果选项卡上，你可以看到逻辑模型中所有未完成的变更请求。搜索后，你可以运行生成 .xls 或 .xlsx 格式的报告并发送给项目经理进行更新。项目经理可能会更新状态、完成日期（注：原文此处重复，已按要求去重）。
