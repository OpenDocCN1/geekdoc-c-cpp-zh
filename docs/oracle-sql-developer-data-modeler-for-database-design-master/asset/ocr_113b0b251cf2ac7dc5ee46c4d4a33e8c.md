# Comparing/Merging Models

This method is for comparing the relational and physical models. The target design must be open in Data Modeler. Choose Tools | Compare/Merge Models. Select the source model you want to compare from the Import Design that will open. Note that you must also have the source design in your working copy directory. If you have several relational models, select the one you want to compare. If you have several physical models in your target design's relational model, select the one you want to. If you do not select any, the relational database management system (RDBMS) that has been defined as the default in Design Properties for the source design is. If you select an RDBMS that does not exist in your physical models of the target design, one will be created for you during the comparison. Click OK.

In the Compare Models dialog, you can see exactly how the two models differ. The source design is always on the left, and the target design is on the right. There are again two ways of seeing the differences: tree view and tabular view. The yellow-triangle shows that there is a difference. If you select element and view details in the screen, you can see what has changed. A red X shows that something has been removed, and a green plus sign shows that something has been added. The default for a deletion is disabled, and for an addition it is selected. Remember to check that you have selected and disabled the elements you want before clicking Merge. If you merge and then realize something was not correct, you can always close the design without saving. When you have selected which changes you would like to make to the target design, you can see the DDLs it would generate by clicking DDL Preview and check if that is what you want and merge the changes to the target design.
