There is also a new column (Customer_TYPE), which is the discriminator column (see Chapter 4) for the table to divide the rows of the table to be either Companies or Persons. Data Modeler creates that automatically as well as the Existence Dependency Constraint shown in Figure 5-16. This constraint is a check constraint that if Customer_TYPE is C, Company_ID cannot be NULL; however, SSN and PersonInfo must be null, and if Customer_TYPE is P, then Company and CompanyInfo must be NULL, and both SSN and PersonInfo cannot be NULL. So, Data Modeler automatically creates the logic for the existence of either a Person or a Company. In Figure 5-17, you can see the check constraint with a list of allowable values created by Data Modeler to check for the discriminator column.
