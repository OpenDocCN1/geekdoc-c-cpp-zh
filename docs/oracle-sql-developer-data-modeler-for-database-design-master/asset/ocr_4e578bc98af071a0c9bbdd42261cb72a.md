Figure 2-4 shows the Preferences dialog, which opens after you choose Tools | Preferences, with Data Modeler selected on the left. Defining the default directories for Data Modeler to use is valuable. It is easier for you to find the directories if you know exactly where they are located. You should define the directories on the Data Modeler tab as all your users because it will make your life much easier, especially with version control and problem solving.

+   - Default Designs Directory is the directory where you will find your designs by default, and if you export or import a Data Modeler design, it will be saved here by default.

+   - Default Import Directory is the default directory for preferences and design-level property imports, among others.
