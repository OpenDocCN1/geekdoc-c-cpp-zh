## Introducing Multidimensional Design

Data Model also supports multidimensional models, which include these elements: cubes, dimensions, levels, and ragged hierarchy links. Multidimensional models can be used if the database supports multidimensional database objects. The two choices are ROLAP or MOLAP. A relational OLAP (ROLAP) is a database extended with OLAP support, and a multidimensional OLAP (MOLAP) is a multidimensional database that stores data in multidimensional arrays.

In multidimensional design, you use a dimensional model (created in ER notation) and map it to multidimensional notation. Typical operations in multidimensional modeling are slicing, dicing, drilling down/up, rolling up, and pivoting. In a slice operation, you select a single value of one of the dimensions and create a new cube with one less dimension than the original. For instance, you could have sales figures for only year 2013, and in a dice operation, you or the end user can select specific values of each dimension on the original cube and create a subcube based on. In a drill down/up operation, the user is able to navigate among levels from the most summarized (up) to the most detailed (down). A roll-up operation summarizes the data along a dimension. The summarization rule might be computing totals through a hierarchy or applying a set of formulas. A pivot operation allows the user to rotate the cube to see different sides of the cube.

## Creating a Multidimensional Model

Multidimensional models are an essential part of designing a data warehouse. A multidimensional model is designed to help users retrieve data in a meaningful way, and is easily to read business queries. Oracle OLAP not only access data stored in relational tables but also includes a special storage structure called an *analytic workspace* (AWM) that allows multidimensional objects with Analytic Workspace Manager (AWM).

In Dataeler you can create a new multidimensional model by right-clicking the multidimensional model in the Browser pane and choosing New Multidimensional Model. On the toolbar you will see icons for the types of elements used designing a multidimensional model. When creating a multidimensional model, you can also define its properties. You can define the name for the model, whether it is visible (Visible), what model will it be based on (logical or relational and which one, such as Bound Model), comments, and notes.
