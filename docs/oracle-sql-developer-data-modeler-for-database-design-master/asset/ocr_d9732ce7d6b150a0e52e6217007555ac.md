# Inheritance

Sometimes you need to model a case on an entity with two or more exclusive child entities. For example, you might want to model a case where the main entity is Customer, but is either a Person or a Company. You can solve it either by using an arc or by using the concepts of supertype and subtype.

An arc is an exclusive relationship group where only one of the relationships can exist for a given instance of an entity. To draw an arc, you must first create all the entities and relationships that you want to include in the arc.
