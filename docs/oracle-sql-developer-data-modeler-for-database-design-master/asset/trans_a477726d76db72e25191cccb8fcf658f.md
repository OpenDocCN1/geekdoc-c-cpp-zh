## 比较两个设计

有两种比较两个设计的方法：你可以选择 文件（File） | 导入（Import） | 数据模型设计（Data Model Designer），或者你可以选择 工具（tools） | 比较/合并模型（Compare/Merge Models）。导入 | 数据模型设计方法用于比较每个层级的设计：逻辑模型、关系模型、物理模型等。比较/合并模型方法仅用于比较关系模型和物理模型。在导入 DDL、从数据字典导入或使用数据库同步时，将使用“比较模型”（Compare Models）对话框。

## 导入数据模型设计

如果你想比较逻辑模型，以及关系模型、物理模型以及其中的更改，你应该使用 文件 | 导入 | 数据模型设计方法。在 Data Modeler 中打开目标设计（target）。然后选择 文件 | 导入 | 数据模型设计。在导入屏幕上选择源设计。如果你想比较逻辑模型，请选择“逻辑模型”设置；如果你想比较关系模型，请选择“关系模型”。对于关系模型，你可以选择将其导入到新的关系模型（新关系模型/New Relational），或者从目标设计的关系模型列表中选择一个现有的关系模型，如图 12-1 所示。你可以使用“新关系模型”在逻辑下创建一个新的关系模型，而不影响现有的关系模型。但如果你想将关系模型与现有关系模型进行比较，请选择该模型。点击“下一步”并“完成”。如图 12-2 所示的 Oracle SQL Developer Data Modeler 设计界面将出现。
