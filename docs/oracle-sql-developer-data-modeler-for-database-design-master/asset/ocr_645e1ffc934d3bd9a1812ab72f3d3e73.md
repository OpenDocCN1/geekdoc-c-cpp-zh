# # Summary

There are several ways of comparing designs to each other and comparing a design to a database. As a result of a comparison, you can also change the design or the database accordingly.

Designs can be compared either with the Import functionality or with Compare/Merge Models. Import compares all the elements a design has, whereas Compare/Merge Models compare only the relational and physical models.

A design and a database can be compared either with synchronization or by importing the DDLs for creating the database or importing them from a data dictionary. The comparisons on the design and database are done with the Compare/Merge Models dialog. During the comparison you can either change the model or get the DDLs to change the database. You can also get ALTER DDLs, for instance, renaming a table or changing a data type of a column. There are several parameters that can be used to get the kind of DDLs you want. Remember to always check the DDLs before running them on your database.
