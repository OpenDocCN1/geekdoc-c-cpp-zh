# A Relationship

A relationship is a logical association between two or more entities. The *degree* of a relationship is the number of entities involved in the relationship. If there are more than two entities in a relationship, it is called a *complex* relationship. “Heli buys an iPad” is a degree 2 (Heli, iPad) relationship (buys).
