# Engineer to Relational Model

In Data Modeler the transformation functionality is called Engineer To Relational Model. You start the transformation either by right-clicking the logical model in the Browser pane and selecting Engineer To Relational Model or by clicking the double arrow pointing right (Figure 5-2). Figure 5-4 shows the Engineer To Relational Model screen is the tree view for what will be transformed. It is also possible to use the tabular view, shown in Figure 5-5.
