The Engineer To property in the Entity Properties dialog is for defining which entity from the hierarchy will be transformed to a table and, if there are several relational models, which relational model. This definition should be for each entity.

There is a new page Subtype in the Entity Properties dialog box since Data Modeler version 4. for implementing subtypes in engineering and setting up a discriminator column, as shown in Figure-40. For entity and subtypes generation, there are two decisions: Subtree Generation and Apply To Model. For Subtree generation there are four choices: Do Not Preset, Single Table, Table Per Child, and For Each Entity. If you want to select decision by setting the Engineer To property to each entity yourself, select Not Preset. I will discuss more about these choices later in this section.
