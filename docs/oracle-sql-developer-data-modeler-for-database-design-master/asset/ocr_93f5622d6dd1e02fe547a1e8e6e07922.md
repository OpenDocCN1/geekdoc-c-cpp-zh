When you continue working with a design you have worked before, always refresh the incoming changes to first see whether there are any changes in Subversion and then click Update Copy to get those changes to your local working copy. Update Working Copy also updates your .svn directory to the same status at the Subversion repository. If you get any errors about mixed versions or something that indicates your local working copy is not on the same level with Subversion, try clicking Update Copy first.

> TIP If you make changes the tool, for instance removing the .svn directory, restart Data Modeler since many things are in cache.

# Exploring Oracle SQL Developer Data Modeler Tools for Subversion

The main tools when working with Subversion are the Versions browser, Pending Changes, and the Team menu. Also, by right-clicking an element in the Browser pane, you can choose Versioning and some operations related to versioning. In the Versions browser, you can see all the definitions for existing Subversion connections. By double-clicking the connection name or right-clicking Properties, you can edit the connection definitions. If right-clicking a design name in the Versions browser, you get the following operations allowed for a directory:

+   - New Remote Directory creates a new directory in Subversion
- The URL will define where the directory will be created. It will be automatically defined as the location in the navigation tree where you have selected New Remote Directory. You only need to fill the Directory Name and Comments fields. Comments can be based on a template.
- The Delete deletes the directory or the file.
- Copy URL copies the URL for the location you are at, and you can paste it where needed.
- Refresh refreshes the Versions browser.
- Show Log starts the Log Browser that shows the revisions of the selected file or directory.
