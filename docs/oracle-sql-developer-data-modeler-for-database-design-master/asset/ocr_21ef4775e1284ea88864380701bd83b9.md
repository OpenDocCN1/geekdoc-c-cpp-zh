> **TIP**
If you want to have the same RDBMS sites for all users, it would be wise to save the file defaultRDBMSSites.xml in version control. Always copy it to your default system types directory when you have added a new site.

You can add a new RDBMS site to a current design by clicking the Add Site button, entering the name for the site, and selecting the RDBMS type from the supported RDBMS types list. Then just click Apply.

> **NOTE**
Changes to the default file are not applied to open designs. You need to close the designs or restart Data Modeler to copy the new sites to the site file of the design.
