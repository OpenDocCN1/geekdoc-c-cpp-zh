# 10 Oracle SQL Data Modeler for Database Design Mastery

This chapter will cover what you need to know about Oracle SQL Data Modeler before start using it. Agreeing on and implementing certain guidelines with your team before start working with the tool will help you streamline your workflow. Specifically, before starting to use Data Modeler in production or in a multiser environment, it is valuable to decide on standardization issues, tweak some settings in the tool, and tune it particularly for your needs. In many cases, it is good to start with a small project when first implementing Data Modeler into your workflow, not because it is a difficult tool to use because there are so many decisions to make in order to use its full potential.

A simple way to standardize your team's workflow and to improve the quality of your database design is to use domains, glossaries, and design rules. A domain defines the possible values for an attribute. Creating domains is easy, but deciding what might encompass is difficult. A glossary is a pre-accepted set of terms, in other words, a vocabulary that can be used in a design. Creating a glossary will probably be more challenging than creating a domain because on what to call concepts is usually difficult. Design rules are a predefined set of rules for the quality of design. Creating domains and glossaries for all the designers to share with it, and implementing domains and glossaries will increase your productivity and the quality of all your designs. In addition, using the design rules before moving to the next phase in the design process will improve the quality of the final database.

Here are some other questions to consider: Which reports do you use? Where will you save them? What kind of data definition language (DDL) files will you have, and will you will save them? How will you use version control, if at all? What kind of relational database management system (RDBMS) will you use? I will touch on these topics throughout this book.

# Downloading and Exploring the Tool

You can download Data Modeler from the Oracle Technical Network (OTN) at www.oracle.com/technwork/developer-tools/datameler/overview/index.html. After downloading the .zip file, unzip it to start using Data Modeler.

There are different versions of Data Modeler depending on your operating system and whether you want the version with or without the Runtime Environment (JRE). You can download the free, stand-alone product of Data Modeler or Oracle SQL Developer, which has Data Modeler integrated into it. You should agree on which version of the product will be used in your organization to avoid conflicts with different versions, especially if you are using version control in a multiser environment.
