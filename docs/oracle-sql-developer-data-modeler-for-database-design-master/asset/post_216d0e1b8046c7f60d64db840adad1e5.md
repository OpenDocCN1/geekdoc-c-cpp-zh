## Comparing Two Designs

There are two ways to compare two designs: You can choose File | Import | Data Model Designer, or you can choose tools | Compare/Merge Models. The Import | Data Model Designer method is for comparing two designs in every level: logical models, relational models, physical models, and so on. The Compare/Merge Models method is only for comparing the relational and physical models. The Compare Models dialog that will be used when importing DDLs, importing from a data dictionary, or using the database synchronization.

## Importing a Data Model Design

If you want to compare the logical models, in addition to the relational and physical models, and also changes from there, you should use the File | Import | Data Model Designer method. Open the target design (target) in Data Modeler. Then choose File | Import | Data Model Designer. Select the source design on the Import screen. Select the Logical Model setting if you want to compare logical models and the relational model if you want to compare that. For the relational model, you can select it to be imported to a new relational model (New Relational), or you can select an existing relational model from the list of relational models in the target design, as shown in Figure 12-1. You can use New Relational to create a new relational model under the logical model without affecting the existing relational model. But if you want to compare the relational model to an existing relational model, select that model. Click Next and Finish. This method is for comparing the relational and physical models. The target design must be open in Data Modeler. Choose Tools | Compare/Merge Models. The Design that will open. Note that you must also have the source design in your working directory. If you have several relational models, select the one you want to compare. If you have several physical models in your target design, select the one you want to. If you do not select any, the database management system (RDBMS) that has been defined as the default in Design Properties for the source design is.
