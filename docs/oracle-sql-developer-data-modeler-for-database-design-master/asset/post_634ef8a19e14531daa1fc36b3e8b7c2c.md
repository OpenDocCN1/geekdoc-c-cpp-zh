Sometimes there are technical columns you would like to add to your tables, but there is no need to have those on your entities. These columns could be, CreatedDate, Creator, ModifiedDate, and Modifier. There is a simple way of adding these columns to every table or a set of tables with Data Modeler during the Engineer To Relational Model transformation. All you need is a table called _template that will include only the columns you want to add to other tables. In this example, that would be table_template (CreatedDate, Creator, ModifiedDate, Modifier). On the Engineer To Relational Model screen, first select all the tables where you want to add those columns and select Use Template Table. Then select the table_template from the Use Template list and click Engineer. You do not need to worry if you have already created the columns because the functionality will add the columns only if they have not been added.

## Examples for Engineering to Relational Model

There are general rules for transforming to the relational model, as discussed earlier in this chapter. During the transformation, also the names of elements are defined. Here are some guidelines about that:

- If you do not interfere with naming while transforming, an entity will become a table with the same Name setting as the entity, with a long name of the entity, and with an abbreviation of short name. A column will be named after the Attribute Name, and the Abbreviation field for the column will be empty by default.
- If you select Apply Translation and Use Preferred Abbreviations during the engineering, the table name and the name for a column will be the Preferred Abbreviation setting of the attribute, and the abbreviation for the column will be empty.
- If you select Apply Translation and have a glossary assigned to the design, the glossary will be followed in the translation as described earlier in this chapter.

You can also define the Attribute property for a table and a column. These abbreviations can be used in templates on the Naming Standards for a relational model, as explained in Chapter 2. You can also exclude transforming properties from the engineering process using the Compare/Copy Options in the Engineer To Relational Model screen, as described earlier in this chapter.
