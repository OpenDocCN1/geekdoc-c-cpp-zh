If you have these scripts (Chapter 5) defined for your tables, you can see them on the Include Table Scripts tab (Figure 7-7). On this tab you can define whether these scripts will be included in the generated DDLs. This does not affect the scripts defined for views; they can be controlled only by Include Into DDL Script on the Scripts tab for View Properties in the relational model. If you disable the script generation for a table in DDL Generation Options, the property Include Into DDL Script for the table on the Scripts tab for table properties in the relational model will automatically be disabled.
