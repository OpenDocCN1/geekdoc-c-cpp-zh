> TIP
Always save your design to see changes you have made in Pending Changes and Outgoing Changes, and always commit your changes to Subversion when you are done. Do not leave the unit until lunch or tomorrow, for instance. Committing right after the change is easier than solving conflicts later. Remember, you have a version control tool, so if you committed something you want to roll back, you can do this easily.
