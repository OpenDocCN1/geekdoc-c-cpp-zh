# Name Abbreviations and Prefix Management

You can use name abbreviations and prefix management to quickly change the naming of objects to meet your needs.

# Name Abbreviation

You can use the Name Abbreviations utility for bulk changing names or abbreviations. You can use it for changing all similar words to the same one; for instance, you could change both C and CUST to CUSTOM. Or you can use it to add abbreviations to tables and columns. The change is based on a comma-separated value (CSV) file. In the file there are pairs of words, and those words are separated by a comma or another separator defined when performing the change. The first word is the name, and the second word is the abbreviation. Name dialog. If you select Name Abbreviation for Direction, the first word will be replaced with the second word. But if you select Abbreviation To Name, the second word in the list will be replaced with the first one. In other words, the Direction setting tells how the list will be read.

You can perform a name abbreviation for names or for abbreviations by selecting All Objects or Abbreviations for the Scope setting.
