- You can refresh the Outgoing Changes list by clicking the Refresh button or the list sign beside it and selecting Refresh Outgoing Changes or Refresh All.

- You can refresh the Unversioned Files list by clicking the Refresh button or the list sign beside it and selecting either Refresh Unversioned Files or Refresh All.
