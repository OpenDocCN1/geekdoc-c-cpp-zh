A new RDBMS site can be added to a file on the Edit External File With Sites tab. Click Select, navigate to the default system types directory, and select defaultRDBMSsites. Click Add Site. # A New Physical Model

Creating a physical model is easy. You just go to the physical model in the Browser, right-click, and select New. Then you will see a list of available RDBMS sites. If you forget to create the site you would like to use, just click Cancel and follow the instructions in the previous section for creating an RDBMS site. If you see one on the list, just click it and then click OK. A physical model with the name of RDBMS site will be created. When you add new elements to your relational model, they will be stored in the physical model automatically. If you wanted some properties for the elements by default, you can do that by setting a preference for a physical model. If you have not set templates in the preferences, you must complete some properties manually, as described in the next section. Some of the properties cannot be filled in automatically and need to be completed.

In the Browser pane, select the physical model name and right-click. You can save a physical model if you select Save, and can delete it by selecting Delete. You can open or close a physical model by selecting Open or Close.

When you open a design, the physical models are not opened automatically. The reason for this is because you might have several physical models in your design with objects. So, when you want to see or edit the physical model, go to the name of the model in the Browser pane, right-click, and select Open.
