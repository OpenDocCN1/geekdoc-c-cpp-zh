You can create your rule set in the Designer Rules dialog on the tab Rule Sets. A rule set is useful when you frequently want to check some rules, not all the rules defined. You can create a new rule set with the green plus button, and can remove an existing one with the red X button. You can add rules to your set by clicking the Rule Set Properties icon (the icon with the pencil) on the Rule Sets tab of the Design dialog and selecting your rules from the list, as shown in Figure 2-20.
