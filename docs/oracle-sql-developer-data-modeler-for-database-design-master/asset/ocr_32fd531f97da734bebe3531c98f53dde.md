# Transforming from a Logical Model to a Relational Model

When the logical model is complete (for now), it is time to transform it to a relational model. Before the transformation, it would be good to check the logical model one more time. Is your model solving all the needs and requirements for business data? Are the modeling and naming standards followed? Are the primary keys correct and defined? Are there entities without a primary key? Do you want Data Modeler to define a surrogate key for them, or do you want to do something yourself? Are all the known attributes defined? Are their data types and compulsories defined correctly? This is a good time to run the design rules for the logical model. See Chapter 2 for more information about design rules.
