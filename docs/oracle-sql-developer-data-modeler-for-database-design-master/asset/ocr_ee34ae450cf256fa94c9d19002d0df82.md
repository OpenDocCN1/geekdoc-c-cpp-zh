On the Entities tab, you can see the Available entities on the left and Selected entities on the right. On this tab you select the entities that the cube will be based on, If you want the list of available entities only to show the fact entities, select List Fact Entities Only.

On the Joins tab, you can see the list of joins for the cube and add or remove joins. If you want to add a new join, click the green plus sign. Now you will be taken to the Join Properties screen. Define the name (Name) for the join object. Define the left entity (Left Entity) and the right entity (Right Entity) in the join operation. By the Relation property, select the relationship from the list that those entities have defined. The Cardinality property is not editable: it shows the cardinality of the selected relationship. If the entity is dominant, select Dominant Role.

On the Attributes tab, you define the attribute pairs that join the left and right entities. You can also define comments and notes.

The Dimensions tab is for viewing, adding, and removing dimensions for the cube; defining the order of the dimensions; and setting Oracle AW Presummarized Levels for a dimension. You can also edit the properties for a dimension. You will learn more about that in this section.

On the Measures tab, you can add and remove measures for the cube. You can also edit the measure (click the Properties icon or double-click the measure name). A measure in a dimensional model is typically a column in a fact table. On the General tab of the Measure Properties dialog, you can edit the name of the measure. If you select the Is Formula property, the formula in the Formula field is used for the measure, and the formula type (No, Base Formula, OLAP Formula, MS Computed) can also be specified. If you do not select the Is Formula property, the Aggregation Function property is used instead. You can also define a fact that it be based on (Based Fact). In both cases you can define the affinity (Fully-Additive, Semi-Additive, Non-Additive) and the WHERE clause limiting the aggregation functions measure aliases. On the Aggregation Functions tab, you can view, add, and remove aggregation functions measure aliases. If you want to set summary levels for a measure alias, select the item from the List and click the Oracle AW Presummarized Levels icon. If you have selected the cube to be an OLAP measure on the General tab in Formula Type, then the Oracle OLAP measure tab you can specify the OLAP properties. On the Names tab, you can specify different names for the measure: Short Name, Long Name, and Plural Name. You can also specify comments, notes, and a description for the measure.

On the Precalculated Slices tab, you can edit, add, and remove slices that are precalculated and stored in the cube. On the Oracle Names tab, you may specify different names for the measure: Short Name, Long Name, and Plural Name.
