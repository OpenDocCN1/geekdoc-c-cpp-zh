In my opinion, the most valuable tab under Naming Standard in the Design Properties dialog is Templates, as shown in Figure 2-10. On the Templates tab you can define how different elements as primary keys, foreign keys, constraints, and indexes will be named. # Sharing the Design-Level Properties

Design-level properties are valid only for the design for which they have been defined. If you want to have the same properties in other designs or used by other users, you can share them with the export/import functionality. From Design Properties, select Settings, as shown in Figure 2-11. By clicking Save, you can save the current settings.
