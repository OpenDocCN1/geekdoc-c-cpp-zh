# Sharing Domains with Other Users

The only domain file Data Modeler uses default.xml located in the directory you set in the Default System Directory preference. There are two possibilities for sharing new domains to other users: You can make changes to the default file and share with other users, or you can make changes to a separate file and share that with all users imported into their local default file. It is useful to have a separate file for your organization's standard set of domains to ensure everyone is using the latest version of the same file. That solution also allows users to define their own domains that will not be shared with other users.

If you decide to use the default domain file and share that, you can copy the file to all computers to the directory specified in Default System Types Directory, and all the users will have the domains available to be used in their designs.

If you decide to have a separate file for company-specific domains, you can share that with users, but you must first import the settings to the local default file before the new domains can be used. Importing can be done with the Import functionality found in the File menu: Choose File | Import | Domains. Select Open Domain File, and select the file wanted.
