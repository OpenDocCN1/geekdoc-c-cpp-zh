# Summary

In physical database design, you design and define physical elements related to the selected RDBMS site and add the physical properties to elements created in the logical design. The outcomes from the physical database design process are the DDL scripts for creating the database. To be able to design the physical model, you need a good understanding of the RDBMS site selected to be able to make the right decisions. During the physical database design you must also design other things, such as backup and recovery strategies.
