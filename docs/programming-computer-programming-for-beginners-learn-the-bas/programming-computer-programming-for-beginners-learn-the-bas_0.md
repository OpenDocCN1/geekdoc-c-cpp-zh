## 第一章：Web 开发简介

网站的创建根据目标受众有不同的目的，有些是为了销售产品，有些则是为了提供信息。Web 开发工具为公司创建网络形象提供了平台。网站让他们接触到更广泛的受众。为了根据需求开发网站，企业聘请开发人员。开发网站可以包括从简单的编程到网络安全、内容添加或 Web 服务器配置的任何内容。

### Web 开发流程

在你开始构建网站之前，首要任务是，你必须理解你正试图向观众或客户传达什么信息或消息。他们在内容方面期待看到什么？你如何让内容变得对用户友好且易于导航？一旦所有前端设计方面都确定了，就必须开始着手网站的后端工作，这包括如何托管、使用什么架构、网站预期的流量负载是多少，以及我们如何搭建基础设施以确保网站的整体构建是稳健的。最后，必须确保网站可以在各种类型的浏览器/设备（如智能手机、平板电脑等）上打开，并且能够通过搜索引擎轻松搜索到。

Web 开发过程中涉及许多步骤，但大致可以分为五个阶段。

1. **需求（Discovery）** - 开发网站的第一步是理解业务需求，包括：创建网站的目的、目标受众以及网站内容。
2. **定义（Definition）** - 必须将第一步收集的信息汇在一起，以定义网站的站点地图或计划。这涉及到创建一个易于导航的系统或用户界面。
3. **设计（Design）** - 这一步涉及构建用户体验。网站的视觉吸引力取决于你选择的模板，并且应该始终考虑到目标受众来完成。例如：针对青少年的网站与针对金融机构的网站会有不同的元素。
4. **开发（Development）** - 在这一步中，实现最终设计以创建一个实际的功能性网站。使用内容管理系统和编程代码来开发网站。
5. **部署（Deployment）** - 对网站的所有功能进行测试，一旦客户对最终产品满意，就会将网站文件上传到客户的服务器上。

### Web 开发的方面

Web 开发可以大致分为两个部分。它们是前端开发和后端开发。为了拥有一个功能齐全的网站，这两个过程需要齐手进行。

#### 前端开发

也称为客户端编码，在这种开发中，你将创建用户在加载 Web 应用时将看到的内容。这包括设计和内容，以及用户将如何与之交互。对于前端开发，你需要使用 `HTML`、`JavaScript` 和 `CSS`。

`HTML` 是用于将文本转换为网页的代码。所有的网页都是用 `HTML` 编写的，这种语言对于所有 Web 应用也至关重要。`CSS` 用于设置样式规则，它决定了网页的外观呈现。`JavaScript` 用于为网页添加功能并使其更具交互性。

#### 后端开发

这也称为服务器端编码。它决定了网页服务器上发生了什么。换句话说，用户看不到这些活动，但它们会影响网站。后端开发中的一项常见活动是为前端生成创建一个数据库。

后端开发使用了多种编码语言和框架。`PHP`、`ASP.NET`、`Ruby on Rails`、`Python`、`Node.js` 和 `Java` 就是其中一些。

### 使用编程语言的优缺点

编程语言用于创建构建网站或 Web 应用的程序。大多数编程语言都很容易学习。它们帮助你为网页添加动态和交互式的活动。复杂的任务可以在相对少的步骤内完成。

编程语言的缺点是编码时产生的 Bug 有时会令人恼且难以解决。Web 开发人员需要像手掌一样熟悉编程语言的语法。因此，大量的努力和良好的记忆是必不可少的。此外，人们需要提高编程速度，否则这是一项非常耗时的活动。

当然，开始学习 Web 开发的最常见原因是成为一名 Web 开发人员。你将能够为人们创建可以在互联网上查看网页和网站。然而，这并不是学习 Web 开发的唯一理由。有很多原因，我们列举了其中几个：

## 第 2 章：学习 HTML5：Web 语言

`HTML` 是 Web 的核心。它是一个被所有人接受的标准。因此，理解它将是开发网页和 Web 应用的关键。

几乎所有读取和写入文件的应用程序都使用一种特殊的文件格式。例如，Windows 上的记事本应用程序可以理解并使用 `.txt` 文件。这些文件包含了打开文档时应显示的所有指令，以及文档的内容和其他数据。`HTML` 以类似的方式运行。这种语言描述 Web 文的内容。

### 什么是 HTML？

`HTML` 是超文本标记语言的缩写。它是创建网页的语言。事实上，`HTML` 是现代互联网的基石。除了网页，它还用于创建 Web 和移动应用的用户界面。

它由一组插入网页中的代码或标记符号组成。代码告诉浏览器如何向用户显示网页上的文字和图像。每一个标记代码被称为元素或标签。浏览器可以读取 `HTML` 文件并将其渲染为可见的网页。它还以语义方式描述网站的结构。

### HTML 的历史

互联网和 `HTML` 的历史完全交织在一起的它们是共同开发的。Tim Berners-Lee 开发了被称为 `HTML` 的语言，用于世界上第一个网站和第一个 Web 服务器。它于 1990 年左右编写，并在 1991 年向公众开放。多年来，`HTML` 经历了多次迭代。2000 年，`HTML` 正式标准化为用于开发 Internet 网页的标记语言。

尽管语言发生了变化，但 `HTML5` 中仍然有一些特征是 HTML 第一版本就存在的。这是 HTML 的最新版本，于 2014 年 10 月发布。当你想要学习 HTML 时，实际上学习的就是 `HTML5`。

所有的 HTML 文档应该以文档类型声明开始，即 `<!DOCTYPE html>`。

HTML 文档仅以 `<html>` 开始并以 `</html>` 结束。

HTML 文档的可视部分位于 `<body>` 和 `</body>` 之间。

### 创建 HTML 网页的元素

为了创建一个简单的网页，你需要了解基本的元素和标签，例如用于定义布局的标签等。这些元素几乎用于所有的网页中，为放置在其上的内容提供结构。以下是你开始创建简单网页时需要了解的知识。

#### 页面标题

所有的 HTML 页面都必须有自己的页面标题。它作为文档的名称。页面标题帮助用户理解他们对该页的预期。此外，当页面被保存到浏览器书签中时，它将作为默认标题。页面标题不会显示在网页的实际内容主体。

页面标题元素的语法如下：

`<Title>…</title>`

标题元素始终放置在 `head` 元素内部。示例：

```html
<!DOCTYPE html>
<html>
<body>
  <h2>标题属性</h2>
  <p title="这些是工具提示"></p>
</body>
</html>
```

#### 段落

页面标题不会影响放置在网页上的实际内容。然而，段落元素（Paragraph element）确实会影响。你可以在 HTML 中分行输入消息。但是，除非你使用段落元素，否则浏览器始终会将它们打印在同一行上。毕竟，HTML 的意义不在于表现形式，而在于含义。该元素的语法如下：

`<p>…</p>`

在这些标签内插入文本时，你可以确保该文本被视为一个独立的文本块。它将显示为一个新的段落。其用法示例如下：

```html
<!DOCTYPE html>
<html>
<head>
<title>动物列表</title>
</head>
<body>
  <p>这是一个动物列表。</p>
  <p>它非常有趣。</p>
</body>
</html>
```

#### 换行

换行标签用于将单行拆分成两行。与其他元素不同，换行没有闭合标签，因为在折断行时并不涉及任何内容。你可能会发现经常使用换行并不容易。但是，你必须避免这样做，特别是当两段文本应该完全独立时。在这种情况下，段落元素会更适合你。换行的标签是 `<br>`，其用法示例如下：

```html
动物列表<br>
和其他动物
```

#### 列表

HTML 允许你将内容组织成列表，使内容在网页上更美观。HTML 中实际上有三种类型的列表：有序列表（ordered list）、无序列表（unordered lists）以及最后是定义列表（definition lists）。在这些，定义列表稍微高级一些。因此，我们在这里只考虑有序列表和无序列表。这两种列表的工作方式相似。然而，当列表项没有顺序时，使用无序列表。它们前面通常有符号。而当项目必须按顺序列出时，使用有序列表。因此，它们前面有递增数字。

无序列表元素可以通过以下语法定义：

```html
<ul>
  <li>...</li>
  <li>...</li>
  <li>...</li>
</ul>
```

有序列表的语法相似。唯一的区别在于使用的标签，如下所示：

```html
<ol>
  <li>...</li>
  <li>...</li>
  <li>...</li>
</ol>
```

`<li>` 标签用于定义放置在相应列表中的每个项目。

为了理解 HTML 中的有序列表和无序列表，你可以看一眼下面的示例。

```html
<!DOCTYPE html>
<html>
<head>
<title>我的第一个网页</title>
</head>
<body>
  <h1>一个简短的动物列表</h1>
  <ul>
    <li>猫。</li>
    <li>狗。</li>
    <li>马。</li>
  </ul>
</body>
</html>
```

你也可以将链接指向同一页面的其他部分。如果你用过维基百科，可能已经见过这种用法了。为了创建这样的链接，你需要在标签上添加 `id` 属性。几乎所有的标签都可以添加此类属性。请查看以下示例以理解它的工作原理。

```html
<p id="bird">The List of Birds</p>
```

```html
<a href="#bird">Check the List of Birds</a>
```

一旦点击链接，页面将滚动到该元素（在此情况下是一个包含相应 `id` 标签的段落）。

#### Hello World 示例

为了帮助你更好地理解 HTML5 中使用的结构和语法，你应该查看以下示例。毕竟，没有比实践更好的学习方法了。以下是一个 `hello world` 示例，这种类型的程序通常在编程中用于介绍语言的基础知识。

```html
<! DOYPE html>
<html Lang="en">
<Head>
<Meta charset="utf-8">
<Title>HTML5: Hello World Example</title>
</head>
<Body>
<h1>Hello World</h1>
</Body>
</html>
```

如你所示，这实际上是一个非常简单的程序。执行此代码后，将打开一个网页并显示“Hello World”文本。由于 HTML5 代码的简单性，你实际上可以理解程序正在发生什么。

首先，定义要在网页上显示的文本语言为英语。然后，通过 `charset` 属性定义 HTML 文档的字符编码。最后，在 `body` 标签内部列出要显示的文本。

#### HTML 文档的结构

HTML 文档是一个包含超文本标记语言的文件。HTML 代码基于标签，标签提供了格式化文档的指令。在任何 HTML 文档中，都会提到文档类型元素，也称为 `doctype`。它的目的是确保浏览器以标准模式渲染 HTML，以便其以正确的方式运行。`doctype` 的使用还允许验证软件知道应该根据哪个版本的 HTML 进行代码验证。

在 `doctype` 之后，使用了 HTML 始标签。它打开 HTML 代码并用结束 HTML 标签关闭。它们作为整个文档的包装器。因此，结束 HTML 标签将始终是任何 HTML 文档中的最后一个内容。

在 HTML 元素之后，插入了 `head` 元素。这个包装器包含了文档的所有信息或元数据。紧随其的是 `title` 元素，它用于定义页面的标题，标题将显示在菜单栏中。

在 `head` 元素之后，使用了 `body` 元素。它包含了将出现在页面上的实际内容。如你所见，Hello World 示例的 `body` 元素中只有一个标题头元素。

#### HTML 的类型

正如我们上面提到的，最新版本是 HTML 5。这个版本可以分为三类。这些类型定义了 HTML 如何使用。

1. **过渡型（Transitional）**：这是最常见的 HTML 类型，具有灵活的语法、拼写和语法组件。这种类型的 HTML 在没有语法限制的情况下使用。浏览器对标签支持尽力而为的方法，如果标签拼写错误，浏览器不会修正错误而是显示内容。
2. **严格型（Strict）**：这种类型要求关闭所有打开的标签。严格 HTML 对手机至关重要，因为它们的处理能力有限。此外，如果代码清洁且无错误，页面加载得更快。

#### HTML 中的元素

在 HTML 中，一个基础元素将在文本块周围有两个标记。一个元素内部也可能包含其他元素。事实上，所有的 HTML 文档都是如此的。毕竟，代码的主要部分总是放在 HTML 元素内部。然而，有少数例外，因为某些元素不能包含任何文本或其他元素。`img` 元素就是其中一个例子。

#### HTML5 中的元素

在 HTML5 中，对元素进行了一些更改。它们现在被分为一系列元素内容类别。在 HTML5 中，元素通过起始标签和结束标签的帮助进行标记。结束标签始终包含一个斜杠，而起始标签则没有。在 HTML5 中，元素名称对大小写不敏感。因此，你可以毫无问题地用大写甚至混合大小写编写它们。然而，使用小写元素名称是一个良好习惯。下面列出了 HTML5 的一些语义和结构元素：

1. `<article>`-定义文章。
2. `<aside>`-定义内容页侧边的内容。
3. `<bdi>`-文本的一部分，其格式可能与其余部分不同。
4. `<details>`-提供用户可能会隐藏的额外细节。
5. `<dialog>`-描述对话框或窗口。
6. `<figcaption>`-为`figure`元素提供说明。
7. `<figure>`-定义插图、照片、图表、代码列表等。

#### HTML5 中的属性

在 HTML 中，元素可以具有属性，用于设置元素的不同属性并改变其行为。某些属性是全局定义的，可以用于任何元素。然而，还有一些属性旨在用于特定的元素。属性应该指定在起始标签中。它们永远不能在结束标签中使用。

与元素一样，HTML 中的属性对大小写不敏感。你可以用任何想要的大小编写它们。然而，你应该练习只使用小写。

大多数属性及其可能的值已在 HTML 规范中定义。因此，你没有权限创建自己的属性。如果你这样做，将使 HTML 无效。毕竟，这可能会误导用户代理，甚至导致网页正确解释出现问题。

播放音频的语法：

3. **时尚表单**：开发者可以使用 HTML5 使用更精美的表单。有不同类型的文本输入和针对不同输入的不同字段。

4. **增强的语义化**：HTML5 语义化得到了提高，这使得识别页脚、页眉、导航等页面部分变得更加容易，因为它们有特定的标签。HTML5 提供了标准代码，从而增加了网页的语义价值。

6. **可访问性**：可以通过 HTML5 元素详细理解网页的结构。

7. **离线缓存**：在使用 HTML5 构建网站时，开发者可以指定由浏览器缓存的文件。这样即使离线状态，您过去访问过的想要再次访问的页面仍然加载。

9. **移动端优化**：HTML5 针对具有完整功能的应用程序和网站进行了优化。移动端用户可以轻松浏览。

### 常见问题（FAQ）

#### HTML5 的目的是什么？

答：HTML5 的设计是为了克服`XHTML`、`HTML4`和`HTML DOM` 2 级的缺点。该语言专注于在不借助额外插件的情况下提供高质量内容。该语言新的结构元素标签为整个网页结构提供了更好的语义支持。错误处理被简化，并且提供了向后兼容性。HTML5 可以在平板电脑、智能手机和 PC 等平台上实现。

#### HTML5 规范可以在所有类型的浏览器上实现吗？

答：目前，尚没有浏览器支持该语言的所有方面。因此，开发者确保其可能使用的特性能够被浏览器支持是至关重要的。

#### HTML 标签和元素不同吗？

答：HTML 中的元素告诉浏览器如何交付文本。当元素被`<>`（尖括号）包围时，它们就变成了标签。

#### 你说的`DOCTYPE`是什么？新格式是什么？

答：这个术语告诉浏览器使用的是哪种 HTML。浏览器使用`<!doctype html>`来确定网页。

#### 描述 HTML5 中 header、section、article 和 footer 的正确用法

答：**Header（头部）**-它用于包含关于页面部分的介绍信息。这些信息可以是作者、日期、标题、目录或任何导航信息。

**Section（区块）**-它是一个灵活的容器，持有内容并共享通用信息。

**Article（文章）**-它持有自包含的内容，可以在不丢失含义的情况下独立重建。例如：博客文章、新闻等。

**Footer（页脚）**-它包含显示在内容末尾的关于该部分信息。例如：版权信息、相关链接等。

#### HTML5 支持哪些媒体元素？

答：它支持`audio`（音频）和`video`（视频）标签。

#### HTML5 中包含任何新元素吗？

答：是的，有两个新元素：`WebGL`和`Canvas`。`Canvas`包含图形，而`WebGL Language`是一种用于在浏览器中生成 3D 图形的跨平台语言。

#### 为什么我们需要数据属性？

答：该属性是该语言的新新增，用于为元素分配自定义数据。该元素非常适合存储私有或敏感数据，并且有匹配的属性。

#### HTML5 带有哪些标准 API？

答：其中一些是：`Text Track`、`Media`、`Application Cache`、`User Interaction`、`Data Transfer`和`History API`。

#### HTML 缓存和 HTML5 缓存有什么区别？

答：HTML5 缓存创建离线版本并存储如图像、HTML 文件、CSS 和 JavaScript，因此与传统的 HTML 缓存增加了网站的速度。总的来说，HTML5 是一种用于创建强大的浏览器应用的兴奋编程语言。它允许你格式化文本、创建链接、添加图形、输入表单等，并将其保存为任何浏览器都可以读取和显示的文本文件。现在你已经了解 HTML5，可以轻松地使用这种编程语言来创建网站。

## 第 3 章：理解 CSS：网页样式

HTML 的功能是创建网页。然而，它无法确保内容的正确呈现。为了让网页美观并改进呈现效果，你需要使用诸如`CSS`的样式表语言。

### 什么是 CSS？

`CSS`代表`Cascading Style Sheets`（级联样式表），是一种设计语言，简化了确保你的网页具有呈现效果的过程。它负责网页的外观。通过它，你可以控制页面的各个方面，如字体样式、文本颜色、列宽、段落间距、布局、背景图像或其他设计。你还可以启用显示变化以适应不同的尺寸和设备。

`CSS`通常用于指定网页的视觉样式，以及用`HTML`或`XHTML`编写界面。然而，你也可以将该语言用于各种 XML 文档类型。

`CSS`的创建允许文档内容与文档呈现（包括颜色、字体和布局）分离。通过分离，可以改进某些内容，例如内容的可访问性。它还增强了呈现各个方面的控制和灵活性。它允许多个 HTML 文件共享相同的格式。

分离还允许以一系列样式交付相同的页面，以适应不同的渲染方法，如打印、屏幕和语音。用户还可以创建一个不同的 CSS 文件来覆盖网页创建者指定的样式。

目前，使用的`CSS`最新版本是`CSS3`。`CSS3`在之前版本的基础上为该语言带了许多新功能。本书将仅关注`CSS3`。

### CSS 的历史

Hakon Wium Lie 在 1994 年 10 月 10 日首次提出了`CSS`。当时还提出了许多其他样式表语言。最后，`CSS1`于 1996 年发布，微软的`Internet Explorer`成为第一个支持`CSS`的浏览器。这种语言专门开发用于持有网络内容，而`HTML`则用于创建文档。

样式表的概念并不新鲜。然而，现有的语言要求样式表来自网络上的不同来源，另一方面，`CSS`通过级联样式的方式影响了文档样式。“级联”一词意味着结合多个 CSS 文件来决定一个页面样式的能力。

让我们来看看 CSS 的一些优点和缺点。

### CSS 提供的优势

使用`CSS`有一些显著的优势。其中一些提到如下：

- **节省时间（Timesaver）**：`CSS`最大的优势之一是它在 Web 开发中节省了大量时间。一个 HTML 页面只需要编写一次`CSS`，然后就可以重复多次用于多个 HTML 页面。可以为 HTML 中的每个元素定义样式，然后应用于各种网页。
- **易于维护（Easy Maintenance）**：`CSS`允许你非常轻松地维护多个页面。你可以通过更改`CSS`中的样式轻松地进行全局更改。所有 HTML 页面中的相应元素将自动更新。
- **页面加载更快（Faster Loading Pages）**：使用`CSS`时，没有必要在 HTML 中多次定义标签属性。只需要为标签编写一条 CSS 规则，即可应用于该特定标签的所有位置。这大大减少了你的代码，缩短了每个页面的下载时间。
- **更好的样式（Better Styles）**：与 HTML 相比，`CSS`提供了范围广得多的属性。这允许你改进 HTML 网页外观的程度比只使用 HTML 属性要得多。
- **缓存（Caching）**：`CSS`允许通过离线缓存存储 Web 应用程序。这允许你离线查看网站。缓存还可以加快页面的加载并提高整个网站的性能。
- **多设备兼容性**：你可以使用样式表来针对一系列设备优化你的内容。
- **全球标准**：事实情况是，`HTML`中可用的属性正在减少。相反，`CSS`被推荐作为替代方案。因此，`CSS`正被用于所有网页，以确保与未来浏览器的兼容性。

### CSS 的缺点

1. **CSS 的不同级别**：这种语言有从`CSS1`到`CSS3`的不同级别，这导致开发者们对于应该使用哪个版本感到了困惑。
2. **碎片化**：在`CSS`中，在某个浏览器中可能有效的代码在另一个浏览器中可能不起作用。因此，Web 开发人员在网站上线之前，必须通过在多个浏览器中运行程序来测试兼容性。



### 缺乏安全性

`CSS` 没有内置的安全系统，因为它是一个开放的基于文本的系统。因此任何对网站具有读写权限的人都可以无论是无意还是刻意地更改 `CSS` 文件、链接或改变格式。

## 开始学习 CSS

要开始学习 `CSS`，需要文本编辑器、一个现代浏览器和一些经验。让我们来看看 `CSS` 是如何工作的：

当文档在浏览器中显示时，它必须将样式信息与文档中的内容结合。文档的处理分为两个阶段：

1. 浏览器将 `CSS` 和标记语言转换为文档对象模型或 `DOM`，它在计算机内存中表示文档。
2. 浏览器显示文档的内容。

在标记语言中，元素被用于定义文档的结构。正如我们在上一节中学到的，元素是使用标签标记的。`CSS` 中的大多数元素都有起始标签和结束标签。标签以“<”符号开头，以“>”结束。

然而，取决于标记语言，少数元素中，“/”出现在元素名称之后，并且它们只有一个单标签或起始标签。每个属性、元素和文本段落都成为 `DOM` 树形结构中的节点。这些节点是根据它们与其他 `DOM` 节点的关系来定义的，即某些元素作为子节点的父节点，而子节点可能有一些兄弟节点。

理解文档对象模型将帮助你调试、设计和维护 `CSS`。让我们来看一个例子来解释这个模型——

在文档中，`<p>` 标签及其结束标签创建了一个容器：

```html
<p>
 <strong>C</strong><strong></strong>ascading
 <strong>S</strong><strong></strong>tyle
 <strong>S</strong><strong></strong>heets
</p>
```

在 `DOM` 中，`P` 节点是父节点，它的子节点是文本节点和 `strong` 节点，其中 `strong` 节点也是文本节点的父节点。

## CSS 中的 Hello World 程序

与其他语言一样，hello world 程序可以作为 `CSS` 的良好介绍。你可以在以下示例看到 CSS 的作用。

```css
<style type="text/css">
h1 {
  Color: DeepSkyBlue;
}
</style>
<h1>Hello, world! </h>
```

你可以看到，这条 `CSS` 规则针对 `HTML` 页面的 `H1` 标签。在这种情况下，我们通过名为 `DeepSkyBlue` 的颜色值更改了 `H1` 文字的颜色。

## 创建并将 CSS 应用到 HTML 文件

在开始为你的 `HTML` 文件创建自己的 `CSS` 之前，你需要知道如何在 `HTML` 中实现 `CSS`。为了实现这一点，你有四种可用方案。它们列如下。

### 1. 内联 (Inline)

在该方法中，样式规则直接放置在 `HTML` 文件中。在需要更改样式的标签中使用 `style` 属性。这里有一个显示内联方法的示例。

```html
<p style="color: blue">…</p>
```

该规则的结果将是该段落的文字变成蓝色。使用这种方法也有缺点，因为它会让 `HTML` 膨肿，并且网站维护变得有些困难。然而，它在某些情况下工作得很好。例如，如果你正在使用一个无法访问 `CSS` 文件的系统，你可以简单地将样式规则添加到元素元素中。

### 2. 内部 (Internal)

如果你想为整个页面实现特定的样式规则，你应该选择内部方法。它也被称为嵌入方法。规则放置在 `head` 元素内部。你可以在下面的示例看到它是如何工作的。

```html
<!DOCTYPE html>
<Html>
<Head>
<Title>CSS Example</title>
<Style>
P {
  Color: green;
}
A {
  Color: blue;
}
</Style>
</head>
</html>
```

当你使用它时，你会发现所有的段落都是绿色的，而所有的链接都显示为蓝色。这种方法的缺点是，每当有人访问网页时，样式都需要下载。这给用户带来了缓慢的浏览体验。然而，这种方法也有自己的优势。整个页面只作为一个文件存在，因为 `CSS` 是 `HTML` 文档的一部分。当你通过电子邮件向某人发送网页或将其用作博客模板时，它是很有用的。嵌入方法的另一个优点是，当使用数据库生成页面内容时，可以同时生成动态样式。标题和其他元素的颜色会被插入到生成的 CSS 规则中。它允许更改颜色。

### 3. 外部 (External)

顾如名，这种方法涉及创建一个完全独立的 `CSS` 文件。这允许将样式应用于整个网站。这就是为什么避免使用内联和内部方法。一个 CSS 文件的基本示例所示：

```css
P {
  Color: green;
}
A {
  Color: blue;
}
```

此文件需要保存在与其样式化的 `HTML` 页面相同的目录下。你可以为 `CSS` 文件选择任何名称，但常见的命名规范建议将其命名为 `style.css` 以便你操作。一旦文件已保存，你就可以将 `HTML` 文件链接到它。下面的代码显示了如何将 `HTML` 文件与相应的 CSS 文件链接。

```html
<!DOCTYPE html>
<Html>
<Head>
<Title>Example</title>
<link rel="stylesheet" href="style.css">
…………….
```

在保存 `HTML` 文件后，它将与相同目录下的名为 `style.css` 的 `CSS` 文件链接。你对 `CSS` 文件的任何更改在打开 `HTML` 文件时都会得到反映。

### 从 CSS 内部导入 CSS 文件

此导入规则允许从 `CSS` 内部挂载新的 `CSS` 文件。要执行此操作，只需执行以下操作——

```css
@import "newstyles.css";
```

在这里，你可以编写你的 `CSS` 文件名以代替 `newstyles` 并确保包含正确的路径。例如，我们有一个拥有 500 页的网站，并想为所有页面添加第二个 `CSS` 文件。因此，我们不需要通过编辑所有 500 个 `HTML` 文件来添加另一个 `CSS` 链接，只需从第一个文件中导入第二个 `CSS` 文件即可，从而节省大量时间。

在 CSS 中，我们本质上并不是在编写程序。毕竟，它是一种样式表语言。相反，我们编写的是规则。一个 CSS 将包含一组样式规则，这些规则会在浏览器将它们应用到 HTML 文档中的关联元素之前进行解释。正如你已经所的，一个样式规则由三部分组成。

- **选择器（Selector）**：这是应用样式的 HTML 标签。
- **属性（Property）**：这是 HTML 标签的一种属性。所有 HTML 属性都会转换为它们对应的 CSS 属性。
- **值（Value）**：每个属性都有一个与之对应的值。

例如：

```css
h1 {color:brown;font-size:12px;}
```

在上面的示例中：

- `h1` 是选择器
- `color` 是属性
- `brown` 是值
- `font-size` 是属性
- `12px` 是值

选择器指向你想要样化的元素。声明块包含多个声明，它们之间用分号隔开，每个声明包含一个 CSS 值和一个属性名，它们之间用冒号隔开。CSS 声明强制以分号结束。声明块被包含在大括号中。

所有 CSS 规则的基本语法如下。

```css
Selector {property: value}
```

CSS 选择器根据元素的名称、类、ID、属性等查找 HTML 元素。CSS 选择器可以通过多种方式定义。事实上，你可以轻松地选择一个你熟悉的用法。这里是几种选择器以及它们的用法。

### 1. 类型选择器（Type Selectors）

你可能已经注意到前面的示例中这种选择器的用法。它允许规则应用于所有相同类型的元素。在接下来的示例中，绿色被应用于页面上的所有一级标题。

```css
h1 {
Color: #36CFFF;
}
```

### 2. 通用选择器（Universal Selectors）

与其选择特定类型的元素，可以使用通用选择器。这允许你将规则应用到任何可以使用给定属性的元素类型。下面的示例说明了通用选择器的用法。其中，文档的整个内容将以黑色显示。

```css
* {
Color: #000000;
}
```

### 3. 后代选择器（Descendant Selectors）

在某些情况下，你可能希望只有当某个元素位于另一个特定元素内部时才对该元素应用样式规则。借助后代选择器的帮助，这完全是可能的。你可以看看下面的示例。其中，只有当 `<em>` 元素出现在 `<ul>` 标签内部时，样式才会应用于该元素。

```css
Ul em {
Color: #000000;
}
```

### 4. 类选择器（Class Selectors）

可以使用类属性来为元素定义样式规则。通过类选择器，具有该类的元素将根据定义的规则进行样式化。看看下方的示例。

```css
.black {
Color: #000000;
}
```

使用此规则后，你会发现文档中所有类属性设置为 `black` 的元素，其内容都将以黑色显示。同时，未来可以细化规则并指定特定的元素。查看下面的示例。

```css
h1.black {
Color: #000000;
}
```

在上面的规则中，内容将样式化为黑色，但仅适用于类属性已设置为 `black` 的 `<h1>` 元素。也可以对特定元素应用多个类选择器。查看下面的示例以了解它是如何工作的。

```html
<p class="center bold">
Text
</p>
```

### 5. ID 选择器（ID Selectors）

在为元素定义样式规则时，你也可以考虑 ID 属性。在这种情况下，所有具有特定 ID 的元素都将根据你定义的规则进行样式化。

```css
#black {
Color: #000000;
}
```

使用此 CSS 规则后，你会发现所有 id 属性为 `black` 的元素，其内容都将以黑色显示。还可以进一步细化此规则并针对特定类型的元素。在接下来的示例中，只有属性为 `black` 的 `h1` 标签会受到规则的影响。

```css
h1#black {
Color: #000000;
}
```

ID 选择器在配合后代选择器使用时非常有用。在接下来的示例中，你会看到，只有当这些二级标题出现在 ID 属性指定为 `black` 的标签内部时，所有的 `<h2>` 标签才会以黑色显示。

```css
#black h2 {
Color: #000000;
}
```

### 6. 子选择器（Child Selectors）

子选择器与后代选择器类似。然而，它们的功能非常不同。下面的示例说明了子选择器的用法。在此 CSS 规则中，只有当段落是 `<body>` 元素的直接子时，才会以黑色显示。如果段落存在任何其他元素（如 `<td>` 或 `<div>`）内部，则不会如此。

```css
Body > p {
Color: #000000;
}
```

### 7. 属性选择器（Attribute Selectors）

通过属性选择器，你可以对具有特定属性的元素应用样式。在这种情况下，`<input type="submit">` 将不受影响。

```css
Input [type="text"] {
Color: #000000;
}
```

属性选择器遵循某些规则：

- `P [Lang]` –在这种情况下，具有 Lang 属性的段落将被选中。
- `P[Lang="en"]` –仅限精确值为 "en" 的。
- `P [Lang~="en"]` –它将选取包含 "en" 的段落。
- `P[lang|="en"]` –属性 属性以 "en-" 开头的。

### 8. 多样式规则（Multiple Style Rules）

在某些情况下，你可能需要为特定元素设置多个样式规则。CSS 允许你组合不同的属性及其值并形成单个代码块。你可以从示例中看到这一点。

```css
h1 {
Color: #000000;
Font-weight: normal;
Letter-spacing: .3em;
Margin-bottom: 2em;
Text-transform: lowercase;
}
```

如示例所示，所有的属性值值对都用分号隔开。如果你愿意，可以将规则保持在一行，而不是使用多行，只要确保它们之间用分号划分即可。

### 9. 选择器组（Selector Groups）

如果你想或需要，也可以将一个样式规则应用于多个选择器。在这种情况下，选择器之间必须用逗号隔开。你可以在给定的示例中看到这种用法。

```css
H1, h2, h3 {
Color: #000000;
Font-weight: normal;
Letter-spacing: .4em;
Margin-bottom: 1em;
Text-transform: lowercase;
}
```

这里定义的样式规则不仅应用于 `<h1>` 元素，还应用于 `<h2>` 和 `<h3>` 元素。列表的顺序不影响规则。

## 在 CSS 中使用颜色

当你对 HTML 文档进行样式化时，颜色无疑将是你实现的内容之一。在 CSS 中，你有能力从 16,777,216 种颜色中选择为你的文本着色。以下是你在样式规则中实现它们的方法。

### 颜色属性的值

在 CSS 中，`color` 属性的值可以使用名称指定。或者，你也可以使用十六代码（hex code）或 RGB 代码。下面列出了将红色作为此属性的值的某些方法。换句话说，当配合 `color` 属性使用以下代码时，你会发现文本将以红色显示。

- red
- `Rib (100%, 0%, and 0%)`
- `rgb(255,0,0)`
- `#f00`
- `#ff0000`

CSS 中预定义了一些颜色名称。它们包括黄色、蓝色、洋红色、石柠绿、绿色、海军蓝、红色、白色、黑色、青色和橄榄色等。CSS 认为认为透明（transparent）也是一个有效值。除了黑色和白色，你会发现颜色名称在 CSS 样式规则中很少使用。由于这些名称具有很高的特异性，它们的灵活性受到了很大限制。

RGB 代码由三个值组成，每个值代表原色。值的范围从 0 到 255，阴影的最低级别由 `0` 表示。`255` 是可能的最高值。以百分比形式表示这些值也是可行的。

十六进制代码使用 16 进制系统。每个十六进制数都以哈希符号开头。在 CSS 中，它们的长度可以是三位或六位。三位版本只是六位版本的简写形式。你会发现，后者版本让你对颜色有更大的控制力。

### 使用 Color 属性

当你想要对文档应用颜色时，可以使用下面两个属性中的一个或两个。

- `Color`：用于给文本应用颜色。
- `Background- color`：用于给背景应用颜色。

在使用这些命令时，请确保你已正确输入了 `color`。浏览器不识别 `color.`。相反，它们可以理解 `color`。这些属性可以应用于几乎所有的 HTML 元素。

文本是另一个常见的样式化项目，用于提高可读性等。CSS 为你提供了许多属性，可以使用它们来更改网页上文本的外观和布局。下面是文本中一些常用的属性。

### font-family 属性

此属性定义文本的字体，例如 `Verdana` 和 `Times New Roman`。当你使用此属性时，你需要确保浏览器能够找到指定为值的字体。这意味着字体必须存在于用户的计算机上。如果你使用稀有或不常用的字体，你的用户可能无法使用该文件，因为他们的计算机上没有该字体。有很多字体在计算机上是始终可用的，例如上面的 `Verdana` 和 `Times New Roman` 以及 `Arial` 和 `Calibri`。

另一方面，你有能力将多个字体指定为此属性的值。你需要借助逗号来分隔值。这允许浏览器在用户的计算机上搜索列表席提到的字体之一。一旦找到正确的字体，该字体将用于显示文本。

请记住，浏览器将按照顺序遵循列表。因此，在你指定为 `Arial`、`Verdana`、`serif` 的列表中，你的用户可能无法使用该文件，因为他们的计算机上没有该字体。

示例：

| 多行输入 | 单行输入 |
| :--- | :--- |

# 第 4 章：学习 JavaScript：让 Web 更具交互性

到目前为止，你已经学习了如何使用`HTML`创建一个基础网页。你还知道如何在`CSS`的帮助下让你的网页看起来很漂亮。然而，对于一个现代网页来说，这远远不够。如今，网站需要具有交互性。为了实现这一点，你需要实现`JavaScript`。

## 什么是 JavaScript？

JavaScript 实际上是一种动态编程语言。当与`HTML`一起使用时，它可以为网页提供动态交互性。然而，`JavaScript`（简称`JS`）主要作为`HTML`文档中的脚本语言使用。这种语言不需要不断下载，就可以轻松运行。它通常用于测验和投票。

### 理解脚本语言

在我们学习所有关于`JavaScript`的之前之前我们需要我们需要什么是脚本。它是一系列语句，为执行某些任务提供指令。通常情况下，脚本语言比结构化语言更容易学习，代码编写也更快。其他脚本语言的示例还有：`Python`、`PHP`、`Tcl`等。这些语言可以根根于`HTML`，通常用于为网页添加功能，如图形显示或不同的菜单样式。脚本语言可以是客户端的，也可以是服务器端的。在客户端脚本语言下，终端用户看到的数据会影响；而在服务器端脚本语言中，数据是在服务器的数据库中进行处理的。

`JavaScript`可用于向用户提供响应，甚至启动幻灯片。通过像`JavaScript`这样的脚本语言，基础网页可以转变为面向用户的活跃平台。

### JavaScript 的历史

`JavaScript`创建于 1995 年，用于 Web 浏览器`Netscape Navigator`。这种语言的原始原初名称是`Mocha`，由`Netscape`的创始人 Marc Andreessen 命名。同年晚些时候，名称被更改为`LiveScript`，在获得商标许可后，命名为`JavaScript`。该语言的第一个商标版本于 1997 年以`ECMAScript`的名称发布。

如今，`JavaScript`已进入了全新的演进阶段。根据现代浏览器的发展，已经有了许多创新、标准化和新开发。

### JavaScript 的特性

1. **浏览器支持** - 大多数浏览器都接受这种脚本语言，因此不需要额外的插件。

### JavaScript 基础

JavaScript 已经成为网上最著名的语言之一。它可以跨平台并在各种浏览器中运行。因此，为了在现实世界中使用这种语言，我们需要首先学习它的基础知识。这将使你对 JavaScript 有基础性的理解。

#### 1. 变量

正如你所知，变量是存储数据的容器。存储在变量中的数据可以是表达式或值。在 JavaScript 语言中，表达式有三种类型。

| 表达式 | 描述 |
| :--- | :--- |
| 逻辑 | 求值为一个布尔值，即 true 或 false |
| 算术 | 求值为一个数字 |
| 字符串 | 求值为一个字符串 |

#### JavaScript 中的变量作用域

变量作用域是指变量定义的程序区域。JavaScript 中的变量可以是两种作用域之一。

**全局变量：** 由于具有全局作用域，这些变量可以在代码的任何地方定义。

**局部变量：** 这些变量仅存在于定义的函数内部。函数参数始终是该特定函数的局部变量。

局部变量可以使用`var`关键字声明，而全局变量应该在不使用`var`关键字的情况下使用。例如：如果在函数内部声明一个局部变量，则它无法在函数外部访问，因此它是该函数的局部变量。如果你在不使用`var`关键字的情况下声明同一个变量，它将对整个脚本可见，而不仅仅是在该函数内部。

在 JavaScript 中，如果存在同名的全局变量，则局部变量在函数体内部具有优先级。通过声明一个与全局变量同名的局部变量，你实际上在函数内部隐藏了该全局变量。

让我们来看一个局部变量的示例

```javascript
var num= 20;
```

如果你想在脚本的其他地方访问`num`变量的值，只需引用变量名即可。`document.write`函数将数据写入网页中。

查看下面的语法：

```javascript
document.write(“The value of num is: “ +num);
```

我们将得到的结果是 “The value of num is: 20”。

为了在变量中存储算术表达式，我们只需要将变量赋值为计算后的值。存储在变量中的不是计算过程，而是计算的结果。因此，我们再次得到结果为 “The value of num is 20”。看下面的示例：

```javascript
var num = (10+10);
document.write( “ The value of num is: “+ num);
```

如果你想更改变量的值，请通过分配给它的名称引用该变量，然后使用等号为其分配一个新值。唯一的区别是不需要使用`var`关键字，因为变量已经声明过了。

```javascript
var num =20
document.write( “ The value of num is: “ +num);
//将 num 的值更新为 30
num=30;
document.write( “ The new value of num is:+ num);
```

所以该脚本的结果将是 “The value of num is 20”，然后是 “The value of num is 30”。

这里有另一个变量的示例以便更好地理解该概念。

```html
<script type="text/javascript">
var money;
var name; 
</script>
```

在上面的示例中，使用了两次`var`关键字来声明两个变量，money 和 name。然而，JavaScript 允许仅用一个`var`关键字声明多个变量。你可以在下面的示例中看到这一点。

```html
<script type="text/javascript">
var money, name;
</script>
```

当值存储在变量中时就会发生变量初始化。在 JavaScript 中，可以在声明变量时进行初始化。或者，你可以在需要该变量时再进行初始化。你可以在下面的示例中看到这种操作。

```html
<script type="text/javascript">
var name = "John";
var money;
money = 12.30;
</script>
```

使用变量时，你需要记住两点。



`var` 关键字必须用于声明或初始化。因此，在单个程序的任何变量的生命周期内，它只会被使用一次。同一个变量不能声明两次，否则可能会导致错误。

由于 JavaScript 是一种弱类型语言，变量可以持有任何值，而不取决于数据类型。换句话说，在声明变量时，不需要指定该变量应该包含什么类型的值。

## 3. 条件语句

与其他编程语言一样，JavaScript 中提供了不同类型的条件语句。它们允许你定义一个条件，其结果决定了将执行的操作。它们允许你的程序根据条件的结果做出决定并执行相关操作。

为了在编程语言中创建任何逻辑，条件语句是它的基础。在 JavaScript 中，条件语句可以用四种方式编写。

| 语句 | 描述 |

| If..else if..else | 如果无限条件中的某一个为真，则执行脚本；如果所有条件都为假，则执行另一个脚本。 |

`if`…`else` 语句的基本语法如下。

```javascript
if (expression) {
    如果表达式为真时执行的语句(s)
}
```

```javascript
    document.write( “num is equal 10”);
```

#### else

```javascript
{
    document.write( “num is equal to 10”);
}
else
{
    document.write( “num is not equal to 10”);
}
```

```javascript
var num=20;
if (num==10)
{
    document.write( “num is equal to 10”);
}
else if (num==20)
{

{
    document.write( “num is something else”);
}
```

```javascript

        document.write( “num is equal to 10”);
        break;

        document.write( “num is equal to 20”);
        break;
    default:
        document.write( “num is something else”);
}
```

## 6. 循环

循环用于迭代数组并在访问值时执行脚本。循环通常包含一个被赋值数值值的变量。该变量随后通过比较运算符与其他值进行比较。之后数值值增加或减少。循环中的比较通常决定变量的初始值是否大于另一个数值值。因此，只要条件为真，循环就会运行，变量的值增加或减少，直到条件变为假。

循环允许你在满足给定条件时重复执行同一个代码块。JavaScript 提供了两种类型的循环：for 循环和 while 循环。

### a) for 循环

for 循环允许在满足特定条件时重复执行同一块代码语句。for 循环的语法如下。

```javascript
for (初始表达式; 条件表达式; 循环表达式) {
    语句
}
```

**示例：**

```javascript
var colors = new array(“red”, “pink”, “green”);

for var (i=0; i<colors.length; i++) {
    Document.write (“The color is: “+ colors[i] +<br/>);
}
```

上面的示例展示了一个`for`循环，它会运行到数值小于数组长度为止。

### b) while 循环

通过`while`循环，可以控制循环执行的次数。换句话说，当你知道循环需要执行多少次时，就会这种循环。因此，你需要确保循环编写得正确，以防止出现无限循环。`while`循环的语法如下。

```
32. While (expression) {
33. Statement(s) to be executed if expression is true
34. }
```

**示例：**

```javascript
var i =0;

while (i<10) {
    document.write(i + “<br/>”);
    i++;
}
```

在上面的示例脚本中，这种类型的循环包含一行代码，它会在`while`循环中的条件为假之前重复该数值。因此，如果没有这一行，将会变成一个死循环。

#### 换行和空白符

JavaScript 会忽略空白符。因此，你可以在脚本中自由使用换行符、制表符和空格。当然，你应该使用它们来格式化你的程序并使其看起来一致且整洁。这使得代码易于阅读和理解。

#### 分号

通常情况下，分号用于标记语句的结束。这在 Java、`C++` 和 `C` 等语言中都是如此。然而，JavaScript 在一种情况下让分号成为可选的。你需要确保每个语句都放在单独的一行。只要你满足了这一条件，就可以避免在代码中插入分号。但是，使用分号是一个良好的习惯，特别是在你学习编程时。

#### 大小写敏感

你需要确保在 JavaScript 中正确使用大小写，因为这种语言是大小写敏感的。因此，所有的关键字、函数名、变量和其他标识符必须以正确的大小写输入。一致性至关重要。在 JavaScript 中，标识符`hi`和`HI`的含义不同。

### 如何将 JavaScript 放入 HTML 文档中？

JavaScript 的优点之一是，你可以灵活地在 HTML 文档的任何地方添加代码。尽管如此，遵循首选方法是一个很好的主意。这可以提高 HTML 文档中 JavaScript 代码的可读性和执行效率。以下是将 JavaScript 包含在 HTML 中的最佳方法。

1. **在 `<head>` 标签内部**

这种选项通常用于你希望在事件发生时运行脚本。例如，你可能希望在用户点击某处时运行脚本。在这些情况下，脚本将放置在`<head>`标签内部，如下例所示。

```html
35. <Html>
36. <Head>
37. <script type="text/javascript">
38. <!--
    Function sayHello () {
        Alert ("Hello World")
    }
//-->
</script>
</head>
<Body>
<input type="button" onclick="sayHello ()" value="Say Hello" />
</body>
</html>
```

2. **在 `<body>` 标签内部**

在某些情况下，你可能需要脚本在页面加载时运行。这样做是为了允许脚本生成页面中的内容。在这种情况下，脚本必须放置在`<body>`标签内部。在这种方法中，你将没有任何用 JavaScript 定义的函数。你可以查看下面关于此类 JavaScript 包含的示例。

```html
39. <Html>
40. <Head>
41. </head>
42. <Body>
43. <script type="text/javascript">
44. <!--
    document.write ("Hello World")
//-->
</script>
<p>Web Page </p>
</body>
</html>
```

3. **在 `<head>` 和 `<body>` 标签内部**

如果你愿意，可以结合两种方法。换句话说，你可以将 JavaScript 代码同时放在`<head>`和`<body>`中。查看示例了解它是如何工作的。

```html
45. <Html>
46. <Head>
47. <script type="text/javascript">
48. <!--
    Function sayHello () {
        Alert ("Hello World")
    }
//-->
</script>
</head>
<Body>
<script type="text/javascript">
<!--
    document.write ("Hello World")
//-->
</script>
<input type="button" onclick="sayHello ()" value="Say Hello" />
</body>
</html>
```



### 在外部文件中

在创建简单的网页时，将 JavaScript 包含在 HTML 文档中是一个好主意。然而，随着你创建复杂的网页，你可能会发现自己在多个地方重复相同的代码。正如你在 CSS 中看到的，你可以创建一个完全独立的文件来存放 JavaScript 代码。该文件应该具有 `.js` 扩展名，并与需要该代码的网页关联。下面的示例说明了如何在 HTML 文档包含外部 JavaScript 文件。在示例中，`filename.js` 是包含 JavaScript 代码的文件。

```html
<html>
<head>
<script type="text/javascript" src="filename.js" ></script>
</head>
<body>
.......
</body>
</html>
```

### JavaScript 中的事件

事件是一种导致 JavaScript 代码执行的操作。事件通常由用户触发。例如，鼠标点击可以是一种事件。根据事件，你可以在 JavaScript 中编写响应。例如，显示消息可以是对事件的响应。这些响应可以被认为是事件处理器，因为它们处理了发生的事件。在 JavaScript 中，可以通过多种方式对事件进行分类。毕竟，事件的数量非常多。

#### onClick 事件

最常见的事件类型是 `onClick` 事件。每当用户左键点击网页时，它就会发生。针对这种事件，你可以做出相应的响应，例如显示消息或进行你的验证。下面的示例说明了如何使用此类事件显示消息。

```html
<html>
<head>
<script type="text/javascript">
<!--
function sayHello () {
Alert ("Hello World")
}
//-->
</script>
</head>
<body>
<p>点击以下按钮查看结果</p>
<form>
<input type="button" onclick="sayHello ()" value="Say Hello" />
</form>
</body>
</html>
```

#### onSubmit 事件类型

这种类型的事件在表单提交时发生。可以将表单验证绑定到此事件上。让我们来看一个示例——

如果下方示例中的 `validate()` 函数返回 `true`，则表单会被提交；否则，表单将不会提交。

```html
<html>
<head>
<script type="text/javascript">
<!--
function validation() {
所有的验证逻辑都放在这里
…….
返回 true 或 false
}
//-->
</script>
</head>
<body>
<form method="post" action="t.cgi" onsubmit="return validate()">
…….
<input type="submit" value="Submit"/>
</form>
</body>
</html>
```

#### onmouseover 和 onmouseout

该事件对图像和文本都能提供很好的效果。当你将鼠标悬停在元素上时，会触发 `onmouseover` 事件；当鼠标移出时，会触发 `onmouseout`。示例：

```html
<html>
<head>
<script type="text/javascript">
<!--
function over () {
document.write ( "鼠标悬停");
}
function out() {
document.write ( "鼠标移出");
}
//-->
</script>
</head>
<body>
<p> 将鼠标移入 div 内部查看结果：</p>
<div onmouseover="over ()" onmouseout="out()">
<h2> 它在 div 内部 </h2>
</div>
</body>
</html>
```

### 关于使用 JavaScript 的提示

1. 确保 JavaScript 能够帮助用户高效、快速地实现目标。如果不能，说明你可能使用不当了。

2. 你为用户提供的 JavaScript 解决方案应该比之前的交互更自然。然而，解决方案不应过于不同，以至于用户无法根据之前的经验联系起来。目标是确保最终用户对解决方案感到满意。

3. 如果你正在处理敏感数据，请不要依赖 JavaScript，因为所有代码都易于读取。此外，用户可能会在浏览器中关闭 JavaScript。

我们可以说，这种简单但丰富的脚本语言有许多可能性。JavaScript 提供了工具，允许最终用户在页面下载后与其交互。在本章中，我们学习了 JavaScript 的基础知识，现在让我们来看看关于这种编程语言的一些常见问题。

### FAQ

#### JavaScript 和 Java 一样吗？

答：不是，它们是不同的编程语言。`Java` 是一种通用编程语言，而 JavaScript 用于让网站具有交互性。

#### 哪些浏览器支持 JavaScript？

答：大多数浏览器都支持 JavaScript。列举如下：

* Microsoft Internet explorer 3.0 及以上版本
* Netscape Navigator 2.0 及以上版本
* Safari

#### 如何在 JavaScript 中添加注释？

答：JavaScript 支持三种不同类型的注释：

a) 多行 C 风格注释，写在 `/*` 和 `*/` 之间的所有内容都是注释。

b) C++ 风格单行注释。此类注释以 `//` 开头，一直持续到下一个换行符。

c) HTML 风格注释以 `<!--` 开头。

#### 当用户无法执行 JavaScript 代码时，可以向用户显示警告吗？

答：可以，可以向不支持 JavaScript 的浏览器用户显示警告。警告文本可以放在 `<NOSCRIPT>` 和 `</NOSCRIPT>` 标签之间。

因此，启用了 JavaScript 的浏览器将忽略这些标签之间的所有内容，而无法执行的浏览器则会在页面上显示你的消息。该消息将显示给禁用了 JavaScript 的用户，以及那些浏览器不支持 JavaScript 的用户。

#### 可以删除 JavaScript（变量）吗？

答：你不能总是删除 JavaScript 变量，这取决于以下条件：

a) 如果 JavaScript 变量第一次是使用关键字 `var x;` 声明的，则无法删除。但作为通变方法，可以将变量设置为 `null` 或 `undefined`。但这并不等同于删除变量。

b) 如果变量 `x` 在脚本中第一次出现时没有任何声明，则可以使用 `delete` 操作符，即 `delete x`。

#### JavaScript 程序不能做什么？

答：使用 JavaScript 代码无法完成以下操作：

a) 无法在客户端局域网或用户系统上使用打印机或其他设备。

b) 无法直接访问用户系统或客户端局域网上的文件。唯一的异常是 cookie 文件。

c) 无法实现多线程或多进程处理。

#### 删除数组元素的方法是什么？

答：在 JavaScript 中有两种删除数组元素的方法，它们是：

a) `myArray.splice(n,1)`。这是一种较慢的方法，但会留下空隙。

b) `delete myArray[n]`。这种方法更快，但也会留下空隙。

#### 有没有方法可以判断用户点击的是右键还是左键？可以使用 onclick 事件处理器吗？

答：左键点击会触发事件。然而，取决于浏览器，右键点击可能不会触发。因此，`onclick` 事件处理器不是实现此功能的可靠方法。相反，我们应该使用 `mousedown` 事件。大多数浏览器都支持 `mouseup` 和 `mousedown` 事件。

#### JavaScript 支持哪些数字格式？

答：数学常量和数字字面量可以用多种方式编写，例如：

a) 指数形式的十进制，例如 `5.57e-11`

b) 常规十进制，例如 `5`、`7`、`137`

c) 八进制，例如 `-055`、`01234`、`0212`

d) 以零开头的正八进制和以零开头的负八进制。

e) 十进制，例如 `0xFF`、`-0xCFFF`

f) 预定义的数学常量，例如 `Math.PI`

#### 如何测试特定变量持有的是字符串还是数字？

答：通过 `typeof` 操作符来测试变量持有字符串还是数字。如果变量持有字符串，`typeof(variable)` 将返回“string”，如果它持有数字，则将返回“number”。

这三种语言是相互交织的，即 HTML 提供了网站的基本结构，并通过 JavaScript 和 CSS 对其进行增强和修改。CSS 告诉 HTML 应该使用什么颜色、字体和其他样式，而 JavaScript 则告诉 HTML 如何执行某些任务，例如弹出窗口等。

在学习 Web 开发时，最需要记住的两个点是：

a) 使用正确的 HTML 标签 – 内容的结构由不同的 HTML 标签来描述，每个标签都有其特定的含义和定义的位置。

b) 保持你的 JavaScript、HTML 和 CSS 代码分离—— 始终将 `JavaScript` 和 `CSS` 放在除 `HTML` 文件之外的独立文件中。这将使你的工作变得简单，并且你能够更好地进行管理。因此，将你所有的样式和功能代码都放在一个地方会让事情变得简单。
