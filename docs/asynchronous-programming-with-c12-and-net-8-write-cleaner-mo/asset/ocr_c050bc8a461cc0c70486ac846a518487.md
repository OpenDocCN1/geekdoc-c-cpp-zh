In some scenarios, multiple asynchronous tasks can be executed concurrently, and their results combined or processed further. `Task.WhenAll` is a useful construct for executing tasks in parallel and awaiting their completion.

# Example: Parallel Execution of Asynchronous Methods

```
```csharp
using System;
using System.Threading.Tasks;

public class Program
{
    public static async Task Main()
    {
        try
        {
            Task<int> task1 = Task1();
            Task<int> task2 = Task2();
            Task<int> task3 = Task3();

            await Task.WhenAll(task1, task2, task3);

            int sum = task1.Result + task2.Result +
            task3.Result;
                Console.WriteLine(\"Sum of results: \" + sum);
        }
        catch (Exception ex)
        {
            Console.WriteLine(\"Error: \" + ex.Message);
        }
    }

    public static async Task<int> Task1()
    {
        await Task.Delay(1000); // Simulate asynchronous
delay
        return 10;
