In this example, `Task2` includes a validation check, and if the input is negative, it throws an `InvalidOperationException`. The `try/catch` block in the `Main` method handles any exceptions thrown by the chained tasks.

# 4. Using Task.WhenAll for Parallel Execution:

Sometimes, chaining tasks sequentially may not be necessary, especially if tasks are independent of each other and can execute concurrently. In such cases, `Task.WhenAll` can be used to await multiple tasks in parallel.

# **Example**: Using Task.WhenAll for Parallel Execution

```
```csharp
using System;
using System.Threading.Tasks;
public class Program
{
    public static async Task Main()
    {
        Task<int> task1 = Task1();
        Task<int> task2 = Task2();
        Task<int> task3 = Task3();
        await Task.WhenAll(task1, task2, task3);
