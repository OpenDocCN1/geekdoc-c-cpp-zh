# 2. Asynchronous Methods:

Asynchronous methods in C# allow developers to define methods that can be executed asynchronously using the `async` and `await` keywords. An asynchronous method returns a `Task` or `Task<T>` representing the result of the asynchronous operation.

# Defining and Calling Asynchronous Methods:

```
```csharp
public async Task<int> GetDataAsync()
{
    // Simulate an asynchronous operation (e.g., fetching data)
    await Task.Delay(2000); // Simulate 2 seconds delay
    return 42; // Simulated data
}
public async Task UseAsyncMethod()
{
    // Calling an asynchronous method using await
    int result = await GetDataAsync();
    Console.WriteLine($"Data received: {result}");
}
```
