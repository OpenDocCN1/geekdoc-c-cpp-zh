Some unit testing frameworks provide async versions of assertion methods, such as `Assert.EqualAsync` in NUnit or `Assert.Equal` with `await` in xUnit, which are useful for comparing async results.

```
```csharp
using Xunit;
using System.Threading.Tasks;

public class MyServiceTests
{
    [Fact]
    public async Task MyAsyncMethod_ShouldReturnExpectedResult()
    {
        // Arrange
        var myService = new MyService();

        // Act
        int result = await myService.MyAsyncMethod();

        // Assert
        await Assert.EqualAsync(42, result); // Async version of assertion
    }
}
```
