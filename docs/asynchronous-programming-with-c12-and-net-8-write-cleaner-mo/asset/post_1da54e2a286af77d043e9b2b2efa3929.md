## 3. Task Continuations for Sequential Operations:

Task continuations allow chaining asynchronous operations sequentially, ensuring one task starts after the completion of another. This is useful for defining a workflow of asynchronous operations.

```csharp
using System;
using System.Threading.Tasks;

public class Program
{
    public static async Task Main()
    {
        Task<int> initialTask = Task.Run(() =>
        {
            return CalculateSum(10, 20);
        });
        Task<string> continuationTask = initialTask.ContinueWith(task =>
        {
            int result = task.Result;
            return $"Sum: {result}";
        });
        string result = await continuationTask;
        Console.WriteLine(result);
    }
    public static int CalculateSum(int a, int b)
    {
        return a + b;
    }
}
```

In this example, `ContinueWith` is used to define a continuation task that processes the result of the initial task (`CalculateSum`) and returns a formatted string.
