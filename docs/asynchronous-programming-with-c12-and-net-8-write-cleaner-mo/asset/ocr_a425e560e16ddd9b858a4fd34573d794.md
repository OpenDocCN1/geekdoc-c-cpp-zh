# 5. Handle Exceptions Appropriately:

Handle exceptions within async methods and propagate them using `throw` if they cannot be handled locally. Consider wrapping exceptions in meaningful custom exceptions for better error handling.

```
```csharp
public async Task<int> DivideAsync(int dividend, int divisor)
{
    try
    {
        await Task.Delay(100); // Simulated async operation
        return dividend / divisor;
    }
    catch (DivideByZeroException ex)
    {
        throw new ArgumentException("Invalid divisor.", ex);
    }
}
```
