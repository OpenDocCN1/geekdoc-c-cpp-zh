
In this example, `Task2` includes a validation check, and if the input is negative, it throws an `InvalidOperationException`. The `try/catch` block in the `Main` method handles any exceptions thrown by the chained tasks.

### 4. Using Task.WhenAll for Parallel Execution:

Sometimes, chaining tasks sequentially may not be necessary, especially if tasks are independent of each other and can execute concurrently. In such cases, `Task.WhenAll` can be used to await multiple tasks in parallel.

## Chapter 5: Utilizing Asynchronous Programming for Network Communication (e.g., HTTP Requests/Responses)

Asynchronous programming plays a vital role in handling network communication tasks efficiently, especially when dealing with HTTP requests/responses in modern applications. Asynchronous operations allow applications to perform non-blocking I/O operations, ensuring responsiveness and scalability. In this exploration, we will delve into utilizing asynchronous programming for network communication, focusing on making HTTP requests and handling responses asynchronously using C# 12 and .NET 8.

### 1. Making Asynchronous HTTP GET Requests:

Making HTTP GET requests asynchronously is a common scenario in applications that communicate with web APIs or fetch data from remote servers. The `HttpClient` class in .NET provides asynchronous methods for making HTTP requests asynchronously.

```csharp
using System;
using System.Net.Http;
using System.Threading.Tasks;

public class Program
{
    private static readonly HttpClient client = new HttpClient();

    public static async Task Main()
    {
        string url = "https://jsonplaceholder.typicode.com/posts/1";
        try
        {
            string response = await GetApiResponseAsync(url);
            Console.WriteLine("Response from API:");
            Console.WriteLine(response);
        }
        catch (Exception ex)
        {
            Console.WriteLine("Error fetching data: " + ex.Message);
        }
    }

    public static async Task<string> GetApiResponseAsync(string url)
    {
        HttpResponseMessage response = await client.GetAsync(url);
        response.EnsureSuccessStatusCode(); // Ensure success status code (2xx)

        return await response.Content.ReadAsStringAsync();
    }
}
```

In this example, `GetApiResponseAsync` method asynchronously makes an HTTP GET request to the specified URL using `HttpClient.GetAsync`. The response content is then read asynchronously using `ReadAsStringAsync`.

### 2. Making Asynchronous HTTP POST Requests:

Similarly, making HTTP POST requests asynchronously is essential for sending data to remote servers or APIs. The `HttpClient` class provides methods for making asynchronous POST requests as well.

```csharp
using System;
using System.Net.Http;
using System.Text;
using System.Threading.Tasks;

public class Program
{
    private static readonly HttpClient client = new HttpClient();

    public static async Task Main()
    {
        string url = "https://jsonplaceholder.typicode.com/posts";
        string postData = "{\"title\": \"New Post\", \"body\": \"This is a new post.\", \"userId\": 1}";

        try
        {
            string response = await PostDataAsync(url, postData);
            Console.WriteLine("Response from API:");
            Console.WriteLine(response);
        }
        catch (Exception ex)
        {
            Console.WriteLine("Error posting data: " + ex.Message);
        }
    }

    public static async Task<string> PostDataAsync(string url, string postData)
    {
        var content = new StringContent(postData, Encoding.UTF8, "application/json");
        HttpResponseMessage response = await client.PostAsync(url, content);
        response.EnsureSuccessStatusCode(); // Ensure success status code (2xx)

        return await response.Content.ReadAsStringAsync();
    }
}
```

In this example, `PostDataAsync` method asynchronously makes an HTTP POST request to the specified URL with the provided JSON data using `HttpClient.PostAsync`. The response content is read asynchronously using `ReadAsStringAsync`.

### 3. Asynchronous Response Handling and Error Management:

Asynchronous programming allows for efficient handling of HTTP responses and error management. `HttpClient` methods return `Task<HttpResponseMessage>` or `Task<HttpResponseMessage>` types, enabling developers to await the response and handle it asynchronously.

```csharp
using System;
using System.Net.Http;
using System.Threading.Tasks;

public class Program
{
    private static readonly HttpClient client = new HttpClient();

    public static async Task Main()
    {
        string url = "https://jsonplaceholder.typicode.com/posts/1000"; // Invalid URL
        try
        {
            HttpResponseMessage response = await client.GetAsync(url);
            if (response.IsSuccessStatusCode)
            {
                string responseData = await response.Content.ReadAsStringAsync();
                Console.WriteLine("Response data:");
                Console.WriteLine(responseData);
            }
            else
            {
                Console.WriteLine("HTTP Error: " + response.StatusCode);
            }
        }
        catch (HttpRequestException ex)
        {
            Console.WriteLine("HTTP Request Error: " + ex.Message);
        }
        catch (Exception ex)
        {
            Console.WriteLine("Error: " + ex.Message);
        }
    }
}
```

In this example, the `Main` method asynchronously makes an HTTP GET request and handles the response and errors asynchronously. It checks if the response is successful (`IsSuccessStatusCode`) and reads the response data if successful. It also handles specific `HttpRequestException` for HTTP request-related errors.

### 4. Managing Multiple Asynchronous Requests:

In scenarios where multiple asynchronous requests need to be made concurrently, `Task.WhenAll` can be used to await the completion of all tasks efficiently.

```csharp
using System;
using System.Net.Http;
using System.Threading.Tasks;

public class Program
{
    private static readonly HttpClient client = new HttpClient();

    public static async Task Main()

        await Task.WhenAll(task1, task2, task3);

        Console.WriteLine("All requests completed:");
        Console.WriteLine("Response 1: " + task1.Result);
        Console.WriteLine("Response 2: " + task2.Result);
        Console.WriteLine("Response 3: " + task3.Result);
    }
}
```
