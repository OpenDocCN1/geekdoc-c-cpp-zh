**Interface Segregation Principle (ISP):** Design interfaces that follow ISP, separating synchronous and asynchronous versions of methods if needed, to provide flexibility and clarity to consumers of the API.

```
```csharp
public interface IDataService
{
    Task<int> GetDataAsync(int id);
}

public class DataService : IDataService
{
    public async Task<int> GetDataAsync(int id)
    {
        // Asynchronous implementation
    }
}
```
```

# 3. Return Task or ValueTask:

Consider returning `Task<T>` or `ValueTask<T>` based on the complexity and performance requirements of the async operation. Use `ValueTask<T>` for simple and frequently executed operations to avoid unnecessary allocations.

```
```csharp
public async Task<int> GetDataAsync(int id)
{
    await Task.Delay(100); // Simulated async operation
    return id * 10;
}
```
