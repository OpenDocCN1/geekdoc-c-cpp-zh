The Task Parallel Library (TPL) in C# is a powerful framework for parallel and asynchronous programming. ## 1. Tasks in the Task Parallel Library:

A `Task` in the TPL represents an asynchronous operation that can run concurrently with other tasks. It encapsulates both the state and the result of an operation, making it easy to work with asynchronous code.

### Creating and Running Tasks:

```csharp
using System;
using System.Threading.Tasks;
public class Program
{
    public static async Task Main()
    {
        // Create and start a new task
        Task<int> task = Task.Run(() =>
        {
            return CalculateSum(10, 20);
        });
        // Wait for the task to complete and get the result
        int result = await task;
        Console.WriteLine("Sum: " + result);
    }
    public static int CalculateSum(int a, int b)
    {
        return a + b;
    }
}
```

In this example, we create and run a task using `Task.Run`, which executes the `CalculateSum` method asynchronously and returns the sum of two numbers.

## 2. Task Continuations:

Task continuations allow you to specify code that should execute after a task completes, either successfully or with an exception. This enables chaining of asynchronous operations and handling of results.

## 3. Cancellation with CancellationToken:

The `CancellationToken` provides a mechanism to cancel tasks asynchronously. It allows for graceful cancellation of operations and cleanup of resources.

### Cancellation Example:

```csharp
using System;

using System.Threading.Tasks;

{
    public static async Task Main()
    {

        CancellationTokenSource cts = new CancellationTokenSource();
        CancellationToken token = cts.Token;

        // Start a task that can be cancelled
        Task longRunningTask = Task.Run(() =>
        {

            {

                Thread.Sleep(1000); // Simulate work
            }

    }
}
```

In this example, we create a cancellation token source (`CancellationTokenSource`) and use it to cancel a long-running task when the user presses Enter.

## 4. Exception Handling with Tasks:

Tasks in the TPL support exception handling to handle errors that occur during asynchronous operations. You can use `try/catch` blocks or `await` with `Task.WhenAll` for handling multiple tasks and exceptions.

### Exception Handling Example:

```csharp
public class Program
{
    public static async Task Main()
    {
        Task<int> task1 = Task.Run(() =>
        {
            throw new Exception("Error in Task 1");
            return 0; // This line won't be reached
        });
        Task<int> task2 = Task.Run(() =>
        {
            throw new Exception("Error in Task 2");
            return 0; // This line won't be reached
        });
        try
        {
            await Task.WhenAll(task1, task2); // Wait for both tasks to complete
        }
        catch (Exception ex)
        {
            Console.WriteLine("Exception caught: " + ex.Message);
        }
    }
}
```

In this example, `Task.WhenAll` is used to wait for both tasks to complete, and any exceptions thrown by the tasks are caught and handled in the `catch` block.
