# Creating and Starting Tasks:

```
```csharp
public void StartTask()
{
    Task task = Task.Run(() =>
    {
        // Code to be executed asynchronously
        Console.WriteLine("Task is running asynchronously.");
    });

    // Continue other work while the task is running
    Console.WriteLine("Continuing with other work...");

    // Wait for the task to complete (optional)
    task.Wait(); // This blocks the main thread, use with
    caution
}
```
```

In this example, `Task.Run` is used to create and start an asynchronous task that prints a message. The `Wait` method is used to block the main thread and wait for the task to complete, but this is optional and should be used carefully to avoid blocking.
