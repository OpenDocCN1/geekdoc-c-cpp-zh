**Example 2.12** Here is another simple proof by induction that illustrates choosing the proper variable for induction. We wish to prove by induction that the sum of the $n$ odd numbers is $n^2$. First we need a way to describe the $n$th number, which is simply $2n-1$. This also allows us to cast the theorem as a summation.

**Theorem 2.3** $\sum_{i=1}^n (2i-1) = n^2$

Proof: The base case of $n=1$ yields $1^2$, which is true. The induction hypothesis is

$$
\sum_{i=1}^{n-1} (2i-1) = (n-1)^2
$$

We use the induction hypothesis to show that the theorem holds for $n$. The sum of the first $n$ odd numbers is simply the sum of the first $n-1$ odd numbers plus the $n$th odd number. In the second line below, we will use the induction hypothesis to replace the partial summation (shown in brackets in the first line) with its closed-form solution. After that, takes care of the result.

$$
\sum_{i=1}^n (2i-1) = \sum_{i=1}^{n-1} (2i-1) + 2n - 1
                               = [(n-1)^2] + 2n - 1
                               = n^2 - 2n + 1 + 2n - 1
                               = n^2
$$

Thus, by mathematical induction, $\sum_{i=1}^n (2i-1) = n^2$.

**Example 2.13** This example shows how we can use induction to prove that a proposed closed-form solution for a recurrence relation is correct.

**Theorem 2.4** The recurrence relation $T(n) = T(n-1); T(1) = 0$ has closed-form solution $T(n) = n-1$.

**Proof:** To prove the base case, we observe that $T(1) = 1-1 = 0$. The induction hypothesis is that $T(n-1)=n-2$. Combining the definition of the recurrence with the induction hypothesis, we see immediately that

$$
T(n) = T(n-1) + 1 = n-2 + 1 = n-1
$$

for $n>1$. Thus, we proved the theorem correct by mathematical induction.

**Example 2.14** This example uses induction without involving summations or others. It also illustrates a more flexible use of cases.

**Theorem 2.5** $2¢$ and $5¢$ stamps can be used to form any value (for values $\ge 4$).

**Proof:** The theorem defines the problem for values $\ge 4$ because it does not hold for the values 1 and 3. Using as the base case, the value of $4¢$ can be made from two $2¢$ stamps. The induction hypothesis is that a value of $n-1$ can be made from some combination of $2¢$ and $5¢$ stamps. We now use the induction hypothesis to show how to get the value of $n$ from $2¢$ and $5¢$ stamps. If the makeup for $n-1$ includes a $5¢$ stamp, it does, then replace a $5¢$ stamp with three $2¢$ stamps. If not, then the makeup must have included at least two $2¢$ stamps (because it is at least size 4 and contains only $2¢$ stamps). In this case, replace two of the $2¢$ stamps with a single $5¢$ stamp. In each case, we have a value of $n$ made up of $2¢$ and $5¢$ stamps. Thus, by mathematical induction, the theorem is correct.

**Example 2.15** Here is an example using strong induction.

**Theorem 2.6** For $n>1$, $n$ is divisible by some prime number.

**Proof:** For the base case, choose $n=2$. 2 is divisible by the prime number 2. The induction hypothesis is that any value $a$, $2 \le a < n$, is divisible by some prime number. There are two cases to consider when proving the theorem for $n$. If $n$ is a prime number, then $n$ is divisible by itself. If $n$ is not a prime number, then $n=a \times b$ for $a$ and $b$, integers less than $n$ but greater than 1. The induction hypothesis tells us that $a$ is divisible by some prime number. That same prime number must also divide $n$. Thus, by mathematical induction, the theorem is correct.

Our next example of mathematical induction proves a theorem by geometry. It also illustrates a standard technique of induction proof where we take $n$ objects and remove some object to use the induction hypothesis.

**Example 2.16** This example shows how we can use induction to prove that a proposed closed-form solution for a recurrence relation is correct.

**Theorem 2.7** The recurrence relation $T(n) = T(n-1); T(1) = 0$ has closed-form solution $T(n) = n-1$.

**Proof:** To prove the base case, we observe that $T(1) = 1-1 = 0$. The induction hypothesis is that $T(n-1)=n-2$. Combining the definition of the recurrence with the induction hypothesis, we see immediately that

$$
T(n) = T(n-1) + 1 = n-2 + 1 = n-1
$$

for $n>1$. Thus, we proved the theorem correct by mathematical induction.
