This form is known as a recurrence with full history. The key to solving such a recurrence is to cancel out the summation terms. The shifting method for summations provides a way to do this. Multiply both sides and subtract the result from the formula for $nT(n+1)$:

```
$nT(n) = cn^2 + 2\sum_{k=1}^{n-1} T(k)$
$(n+1)T(n+1) = c(n+1)^2 + 2\sum_{k=1}^{n} T(k)$
```

Subtracting from both sides yields:

```
$(n+1)T(n+1) - nT(n) = c(n+1)^2 - cn^2 + 2T(n)\n$(n+1)T(n+1) - nT(n) = c(2n+1) + 2T(n)\n$(n+1)T(n+1) = c(2n+1) + (n+2)T(n)\nnT(n+1) = \frac{c(2n+1)}{n+1} + \frac{n+2}{n+1}T(n)$
```

At this point, we have eliminated the summation and can now use our normal methods for solving recurrences to get a closed-form solution. Note that $\frac{c(2n+1)}{n+1} < 2c$, so we can simplify the result. Expanding the recurrence, we get

```
$T(n+1) \le 2c\frac{n+2}{n+1}T(n)\n= 2c\frac{n+2}{n+1}(2c\frac{n+1}{n}T(n-1))\n= 2c\frac{n+2}{n+1}(2c\frac{n+1}{n}(2c\frac{n}{n-1}T(n-2)))\n= 2c(1+\frac{1}{n+1})(2c(1+\frac{1}{n})(2c(1+\frac{1}{n-1})...))\n= 2c(c(n+1))(\mathcal{H}_{n+1}-1)$
```

For $\mathcal{H}_{n+1}$, the Harmonic Series. From Equation 2.10, $\mathcal{H}_{n+1} = \Theta(\log n)$, so the final solution is $\Theta(n \log n)$.
