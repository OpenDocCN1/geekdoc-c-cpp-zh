**Figure 7.20** comparison of sorting algorithms on a 3.4-GHz Intel Pentium 4 running Linux. Shell, Quicksort, Mergesort, and Heapsort are shown with regular and optimized versions. Radix is shown for 4 and 8-bit passes. All times are milliseconds.

Figure 7.20 shows timing results for actual implementations of the sorting algorithms presented in this paper. The algorithms include Insertion Sort, Bubble Sort, Selection Sort, Shell, Quicksort, Mergesort, Heapsort and Radix Sort. Shell shows both the version from Section 7.3 and with increments by division by three. Mergesort shows both the implementation from Section 7.4 and the optimized version (including calls to Insertion Sort for lists of length below). For Quicksort, two versions are shown: the basic implementation and the optimized version that does not partition sublists below length (with Insertion Sort inserted). Heaps' version uses the class definitions from Section 5.5. The second version removes all the class definitions and operates directly on the array using inline code for all functions.

Except for the rightmost columns, the input to each algorithm is a random array of integers. This affects timing for some of the sorting algorithms. For example, Selection is not used to sort because the record size is small, so it does not get the best possible showing. The Radix Sort implementation takes advantage of this range in that it does not look at digits than necessary. On the other hand, it is not optimized to use bit shifting instead of division, even though the bytes used would permit.

The various sorting algorithms are shown for sizes of 10, 100, 1000, 10000, 100000, and 1,000,000. The final two columns of each table show the performance for the algorithms on inputs of size 10,000 where the numbers are in ascending (sorted) and descending (reversed sort) order, respectively. These columns demonstrate best-performance for some algorithms and worst-case performance for others. They also show that for some algorithms, the order of input has little effect.
