Now consider the problem of multiplying polynomials. A vector of $n$ values can uniquely represent a polynomial of degree $n-1$, expressed as

```
$P_a(x) = \sum_{i=0}^{n-1} a_i x^i$
```

Alternatively, a polynomial can be uniquely represented by a list of its values at $n$ distinct points. Finding the value for a polynomial at a given point is **evaluation**. Finding the coefficients for the polynomial given values at $n$ points is **interpolation**.

To multiply $n-1$-degree polynomials $A$ and $B$ normally takes $\Theta(n^2)$ efficient multiplications. However, if we evaluate polynomials (at the same points), we can simply multiply the product of pairs of values to get the correct values for polynomial $AB$.

# **Example 16.5** Polynomial $A$: $x^2 + 1$.

Polynomial B: $2x^2 - x + 1$
Polynomial AB: $2x^4 - x^3 + 3x^2 - x + 1$

When we multiply the evaluations of $A$ and $B$ at points 0, 1, and -1, we get the following results.

```
$AB(-1) = (2)(4) = 8$
$AB(0) = (1)(1) = 1$
$AB(1) = (2)(2) = 4$
```

These are the same as when we evaluate polynomial $AB$ at these points.

Note that evaluating any polynomial at 0 is easy. If we evaluate at 1 and -1, we can share a lot of work between the two evaluations. But we would need five points to nail down polynomial $AB$, since it is a degree-4 polynomial. Fortunately, we can speed processing for any pair of values $c$ and $-c$. This seems to indicate some promising ways to speed up the process of evaluating polynomials.
