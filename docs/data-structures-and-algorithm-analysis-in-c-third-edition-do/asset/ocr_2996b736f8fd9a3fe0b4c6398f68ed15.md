C > B, which means that B is not the largest integer after all. Thus, we have reached a contradiction. The only flaw in our reasoning is the initial assumption that the theorem is false. Thus, we conclude that the theorem is correct.

A reliable technique is proving the contrapositive. We can prove that P ⇒ Q by proving (not Q) ⇒ (not P).

# 2.6.3 Proof by Mathematical Induction

Mathematical induction can be used to prove a wide variety of theorems. Induction also provides a useful way to think about algorithm design, because it encourages you to think about solving a problem by building up from simple subproblems. Induction can help you to prove that a recursive function produces the correct result... Understanding recursion is a big step toward understanding induction, and vice versa, since they work essentially the same process.

Within the context of algorithm analysis, one of the most important uses for mathematical induction is to test a hypothesis. As explained in Section 2.4, seeking a closed-form solution for a summation or recurrence we might first guess or otherwise acquire evidence that a particular formula is the correct solution. If the formula is indeed correct, it is an easy matter to prove that with an induction.

Let Thm be a theorem to prove, and express Thm in terms of positive integer parameter n. Mathematical induction states that Thm is true for any value n (for n ≥ c, where c is some constant) if the following two conditions are true:

+   1. Base Case: Thm holds for n = c, and

+   2. Induction Step: If Thm holds for n − 1, then Thm holds for n.

Proving the base case is usually easy, proving that some small value such as 1 is satisfied for n in the theorem and applying simple algebra or logic as necessary to verify the theorem. The induction step is sometimes easy, and sometimes difficult. An alternative formulation of the induction step is known as strong induction. The induction step for strong induction is:

+   2a. Induction Step: If Thm holds for all k, c ≤ k < n, then Thm holds for n.

Proving either variant of the induction step (in conjunction with verifying the base case) yields a satisfactory proof by mathematical induction.
