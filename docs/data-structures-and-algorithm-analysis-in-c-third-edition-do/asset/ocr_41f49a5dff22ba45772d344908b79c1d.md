**Figure 13.2** Two variations on the alphabet trie representation for a set of ten words. (a) Each node contains sets of links corresponding to single letters, and each letter in the set of words has a corresponding link. “$” is used to indicate the end of a word. Internal nodes direct the search and also spell out the word one letter per link. The word need not be stored explicitly. “$” is needed to recognize the existence of words that are prefixes to other words, such as ‘ant’ in this example. (b) Here the trie extends only enough to discriminate between the words. Leaf nodes of the trie store a complete word; internal nodes merely direct the search.
