# **Example 2.12** Here is another simple proof by induction that illustrates choosing the proper variable for induction. We wish to prove by induction that the sum of the nth odd numbers is n². First we need a way to describe the nth odd number, which is simply 2n-1. This also allows us to cast the theorem as a summation.

# **Theorem 2.3** ∑_{i=1}^n (2i-1) = n²

Proof: The base case of n=1 yields 1², which is true. The induction hypothesis is

```
∑_{i=1}^{n-1} (2i-1) = (n-1)²
```

We use the induction hypothesis to show that the theorem holds for n. The sum of the first n odd numbers is simply the sum of the first n-1 odd numbers plus the nth odd number. In the second line below, we will use the induction hypothesis to replace the partial summation (shown in brackets in the first line) with its closed-form solution. After that, takes care of the result.

```
∑_{i=1}^n (2i-1) = ∑_{i=1}^{n-1} (2i-1) + 2n - 1
                                 = [(n-1)²] + 2n - 1
                                 = n² - 2n + 1 + 2n - 1
                                 = n²
```

Thus, by mathematical induction, ∑_{i=1}^n (2i-1) = n².
