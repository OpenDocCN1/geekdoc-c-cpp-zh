```
// ADT for buffer pools using the message-passing style
BufferPool {
    // Copy "sz" bytes from "space" to position "pos" in the
    buffered storage.
    virtual void insert(void* space, int sz, int pos) = 0;

    // Copy "sz" bytes from position "pos" of the buffered
    storage to "space".
    virtual void getbytes(void* space, int sz, int pos) = 0;
}
```

This simple class provides an interface with two member functions, insert and getbytes. The information is passed between the buffer user and the buffer pool through the space parameter. This storage space, provided by the bufferpool and at least sz bytes, which the buffer pool can take information from (the insert function) or put information into (the getbytes function). Parameter pos indicates where the information will be placed in the buffer pool's logical storage space. Physically, it will actually be copied to the appropriate byte position in some buffer in the pool. This ADT is similar to the read and write methods of the RandomAccessFile class discussed in Section 8.4.
