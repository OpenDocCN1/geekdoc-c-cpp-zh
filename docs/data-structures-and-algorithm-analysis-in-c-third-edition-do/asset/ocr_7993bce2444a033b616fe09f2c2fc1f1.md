The union of P and Q, written P U Q is the set of elements in either P or Q, which is {2, 3, 5, 10}. The intersection of P and Q, written P ∩ Q is the set of elements that appear in both P and Q, which is {5}. The difference of P and Q, written P - Q is the set of elements that occur in P but not Q, which is {2, 3}. Note that P U Q = Q U P and P ∩ Q = Q ∩ P, but in general P - Q ≠ Q - P. In this example, Q - P = {10}. The set {4,3,5} is indistinguishable from P, because of order. Likewise, {4, 3, 4, 5} is also indistinguishable from P, because sets have no concept of duplicate elements.

A collection of elements with no order (like a set), but with duplicated-valued elements is called a bag.¹ To distinguish bags from sets, we use square brackets [] around a bag's elements. For example, bag [3, 4, 5, 4] is distinct from bag [3, 4, 5], while set {3, 4, 5, 4} is indistinguishable from set {3, 4, 5}. However, bag [3, 4, 4, 5, 4] is indistinguishable from bag [3, 4, 4, 5].

> The object referred to as a bag is sometimes called a multiset. But, I reserve the term multiset for a list that may contain sublists (see Section 12.1).
