At this point, our intuition is telling us pretty clearly the relative growth rates of these three functions. But how do we do formally which grows the fastest? And how do we decide the differences are significant in an asymptotic sense, or just constant factor differences?

We can use logarithms to help us get an idea about the relative growth of these functions. Clearly, log $2^n = n$. Equally clearly, log $n^n = n \log n$. We can easily see from this that $2^n$ is $o(n^n)$, that is, $n^n$ grows asymptotically faster than $2^n$.

How does $n!$ fit into this? We can again take advantage of logarithms. Obviously $n! \leq n^n$, so we know that log $n!$ is $O(n \log n)$. But what about a lower bound for the factorial? Consider the following.

```
$n! = n \times (n-1) \times \dots \times \frac{n}{2} \times (\frac{n}{2}-1) \times \dots \times 2 \times 1\n\geq \frac{n}{2} \times \frac{n}{2} \times \dots \times \frac{n}{2} \times 1 \times 1\n= (rac{n}{2})^{n/2}$
```

```
$\log n! \geq \log(\frac{n}{2})^{n/2} = \frac{n}{2} \log\frac{n}{2}$.
```

In other words, log $n!$ is $\Omega(n \log n)$. Thus, log $n!$ is $\Theta(n \log n)$. Note that this does not mean that $n! = \Theta(n^n)$. Because $n^2 = 2 \log n$, it follows that log $n = \Theta(\log n^2)$ but $n \neq \Theta(n^2)$. The function works as a "flattener" when dealing with asymptotics. That is, when $f(n)$ is $O(\log g(n))$ we know that $f(n)$ is in $O(g(n))$. But knowing that log $f(n) = \Theta(\log g(n))$ does not necessarily mean that $f(n) = \Theta(g(n))$.
