In other words, people typically use some knowledge about the expected distribution of key values to “compute” where to look next. This form of “computed” binary search is called a dictionary search or interpolation search. In a dictionary search, we search L at a position $p$ that is appropriate to the value of $K$ as follows:

```
$p = \frac{K - L[1]}{L[n] - L[1]}$
```

This equation is computing the position of $K$ as a fraction of the distance between the smallest and largest key values. This will be translated into that position which is the fraction of the way through, and this position is checked first. With binary search, the value of the key eliminates records either above or below position. The actual value of the key found can be used to compute a new position within the remaining range of the array. The next check is made based on the new computation. This proceeds until the desired result is found, or the array is narrowed until no records are left.

A variation on dictionary search is known as Quadratic Binary Search (QBS), and we will analyze in detail its analysis is easier than the general dictionary search. QBS will first compute $p$ and then examine $L[pm]$. If $K < L[pm]$ then QBS will sequentially probe the left by steps of size $\sqrt{n}$, that is, we step through

```
$L[pm - i\sqrt{n}], i = 1, 2, 3, \dots$
```

until we reach a value less than or equal to $K$. For $K > L[pm]$ we will step the right by $\sqrt{n}$ until we reach a value in $L$ that is greater than $K$. We are well within $\sqrt{n}$ positions of $K$. Assume (for now) that it takes a constant number of comparisons to bracket $K$ within a sublist of size $\sqrt{n}$. We then take this sublist and repeat the process recursively. That is, at the next level we compute an interpolation to start somewhere in the universe. We step to the left or right (as appropriate) by steps of size $\sqrt{n}$.

What is the cost for QBS? Note that $\sqrt{a^2} = a$, and we will be repeatedly taking square roots of the current sublist until we find the element we are looking for. Because $n = 2^{\log n}$ and we can cut $\log n$ in half only $\log \log n$ times, the cost is $\Theta(\log \log n)$ if the number of probes needed is $i$, in which case the cost is $i$ (we have to do $i$ comparisons).
