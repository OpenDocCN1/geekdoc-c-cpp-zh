A further generalization to Binsord yields a bucket sort. Each bin is associated with not just one key, but rather a range of key values. A bucket sort assigns records to bins and relies on other sorting technique to sort the records within each bin. The hope is that the relatively inexpensive processing will keep only a small number of records in each bin, and a "cleanup sort" within the bins will then be relatively cheap.

There is a way to keep the number of bins and the related processing small while allowing the cleanup sort to be based on Binsord. Consider a sequence of keys in the range 0 to 99. If we have ten bins available, we can first assign records... Then, every key will be assigned to the bin matching its rightmost decimal digit. We then take these records from the bins in order and reassign them to the bins on the basis of their leftmost (10's place) digit (define values in range 0 to 9 to have a leftmost digit of 0). In other words, assign the ith record from array A to a bin to have a leftmost digit... using the formula **A[i]/10**. If we know the values from the bins in order, the result is a sorted list.
