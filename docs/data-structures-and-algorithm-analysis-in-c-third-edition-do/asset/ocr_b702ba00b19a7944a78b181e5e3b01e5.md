# 11.3.2 Breadth-First Search

Our graph traversal algorithm is known as a **breadth-first search** (BFS). BFS examines all vertices connected to the start vertex before visiting further away. BFS is implemented similarly to DFS, except that a queue replaces the recursion stack. Note that if the graph is a tree and the vertex is at the root, BFS is equivalent to visiting vertices by level from top to bottom. Figure 11.10 provides an implementation for the BFS algorithm.
