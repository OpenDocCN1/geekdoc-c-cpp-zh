# Sec. 8.1 Primary versus Secondary Storage

In exchange for reduced storage costs, persistence, and portability, secondary storage devices pay a penalty in terms of increased access time. While not all accesses take the same amount of time (more on this later), the typical time required to access a byte from a disk drive in 2011 is around 9 ms (i.e., 9 thousands of a second). This might not seem slow, compared to the time required to access a byte from main memory, this is fantastically slow. Typical access time from standard computer RAM in 2011 is 5-10 nanoseconds (i.e., 5-10 billions of them). Thus, the time to access a byte from a disk drive is about six orders of magnitude greater than that required to access a byte from main memory. While drive and RAM access times are decreased, they have done so at roughly the same rate. The relative speeds have remained the same for several decades, in that the difference in access time between RAM and a disk drive has remained in the range between a factor of 100,000 and 1,000,000.

To gain some intuition for the significance of this speed, consider the time it might take you to look up the entry for disk drives in the index of this book, and then to the appropriate page. Call this "primary memory" access time. If it takes you 20 seconds to perform this access, then an access 500,000 times longer would require months.

It is interesting to note that while processing speeds have increased dramatically, and hardware prices have dropped dramatically, disk and memory access times have improved by less than an order of magnitude over the past 15 years. However, the situation is really much better than that modest speedup would suggest. During the same time, the size of disk and main memory have increased by over three orders of magnitude. Thus, the access times have actually decreased in the face of a massive increase in the density of these storage devices.

# Minimize the number of disk accesses!

There are generally two approaches to minimizing disk accesses. The first is to arrange information so that if you access data from secondary memory, you will get you in as few accesses as possible, and preferably in the first access. File structure is the term used for a data structure that organizes data stored in secondary memory. File structures should be organized so to minimize the required number of disk accesses. The other way to minimize disk accesses is to save information previously retrieved (or retrieve additional data with each access at little additional cost) that can be used to minimize the need for future accesses.
