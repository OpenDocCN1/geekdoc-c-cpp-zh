records of frequent access to. While the benefits might not be as great
as when organized by key value, the cost to organize (at least approximately)
ofrequency of access can be much cheaper, and thus can speed up sequential search
in some situations.

Assume that we know, for each key $k_i$, the probability $p_i$ that the record with
$k_i$ will be requested. Assume also that the list is ordered so that the most
frequently requested record is first, then the next frequently requested record,
and so on. Search in the list will begin sequentially with the first
position. Over the course of many searches, the expected number of comparisons
required for one search is

```
$C_n = 1p_0 + 2p_1 + \dots + np_{n-1}$.$
```

In other words, the cost to access the record in **L[0]** is 1 because each key value
is looked at), and the probability of this occurring is $p_0$. The cost to access the record
in **L[1]** is 2 (because we must look at the first and the second records' key values),
with probability $p_1$. For $n$ records, assuming that all searches are for
records that actually exists, the probabilities $p_0$ through $p_{n-1}$ must sum to one.
Certain probability distributions give computed results.

**Example 9.1** Calculate the expected cost to search a list when each record
has equal chance of being accessed (the classic sequential search through
unsorted list). Setting $p_i = 1/n$ yields

```
$C_n = \sum_{i=1}^n i/n = (n+1)/2$.
```

This matches our expectation that half the records will be accessed on
aver normal sequential search. If the records have equal access
probabilities, ordering records by frequency yields no benefit. We
in Section 9.1 the more general case where we must consider the probability
(labeled $p_n$) that the search key does not match for any record in the
ray. In that, in accordance with our general formula, we get

```
$(1-p_n)\frac{n+1}{2} + p_np_n = \frac{n+1-np_n+2np_n^2}{2} = \frac{n+1+p_n(n-1)}{2}$.
```

Thus, $\frac{n+1}{2} \leq \bar{C}_n \leq n$, depending on the value of $p_0$.

A geometric probability distribution can yield quite different results.
