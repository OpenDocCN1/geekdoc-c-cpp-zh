```cpp
template <typename E, typename Comp>
void bubbleSort(E A[], int n) { // Bubble up i'th largest
    for (int i=0; i<n-1; i++) {
        for (int j=n-1; j>i; j--) {

}
```

### 7.2.3 Selection Sort

Consider the problem of sorting a pile of phone bills for the past year. Another intuitive approach might be to look through the pile until you find the bill for January, and then look the remaining pile until you find the bill for February, and add that before January. Proceed through the ever-shrinking pile of bills to select the next one until you are done. This is the inspiration for our $\Theta(n^2)$ sort, called **Selection Sort**. The $i$th smallest key in the order, placing that into position $i$. In other words, Selection Sort finds the smallest key in an unsorted list, then the second, and so on. Its unique feature is that there are few swaps. To find the next smallest value requires searching through the entire unsorted portion of the array, but only one swap is required to put the result in place. Thus, the number of swaps will be $n-1$ (get the last in place “for free”).

Figure 7.3 illustrates Selection Sort. Below is a C++ implementation.

```cpp
template <typename E, typename Comp>
void selectionsort(E A[], int n) { // Selection Sort
  for (int i=0; i<n; i++) { // Select the ith record
    int lowindex = i; // Remember its index
    for (int j=i+1; j<n; j++) { // Find the least value
      if (Comp::prior(A[j], A[lowindex]))
        lowindex = j;
    }
    swap(A[i], A[lowindex]); // Put it in place
  }
}
```

Selection Sort (as shown here) is similar to Bubble Sort, rather than repeatedly swapping adjacent values to get the next smallest value into place, we instead swap the position of the element to be selected and do one swap at the end. Thus, the number of comparisons is still $\Theta(n^2)$, but the number of swaps is much less than required by bubble sort. Selection Sort is particularly

### 7.3 Shellsort

The next sorting algorithm that we consider called Shellsort, named after its inventor, D.L. Shell. It is also called the **diminishing increment sort**. Unlike Insertion and Selection Sort, there is no real life intuitive way to Shellsort. Unlike exchange sorts, Shellsort makes comparisons and swaps between non-adjacent elements. Shellsort also employs the best-case performance of Insertion Sort. Shellsort's strategy is to make the list "mostly sorted" that a final Insertion Sort can finish the job. When properly implemented, Shellsort will significantly perform better than $\Theta(n^2)$ in the worst case.

Shellsort uses a process that forms the basis for many of the sorts presented in the following sections: Break the list into sublists, sort them, then recombine the sublists. Shellsort breaks the array of elements into "virtual" sublists. Each sublist is sorted using Insertion Sort. Another group of sublists is then chosen and sorted, and so is on.

During each iteration, Shellsort breaks the list into disjoint sublists so that each element in a sublist is a fixed number of positions apart.
