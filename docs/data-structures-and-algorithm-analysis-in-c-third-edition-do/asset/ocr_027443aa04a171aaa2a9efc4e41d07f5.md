**Boolean variables:** A Boolean variable is a variable (of type **bool in C++) that takes one of the two values **true** and **false**. These two values are often associated with the values 1 and 0, respectively, although there is no reason this needs to be the case. It is poor programming practice to rely on the correspondence between 0 and **false**, because these are logically distinct objects of different types.

**Logic Notation:** We will occasionally use the notation of symbolic or Boolean logic. $A \Rightarrow B$ means "A implies B" or "If A then B". $A \Leftrightarrow B$ means "A if and only if B is equivalent to B". $A \lor B$ means "A or B" (useful in the context of symbolic logic or when performing a Boolean operation). $A \wedge B$ means "A and B". $A{\sim}$ and $A$ means "not A" or the definition of N where A is a Boolean variable.

**Floor and ceiling:** The floor of $x$ (written $[x]$) takes real value $x$ and returns the greatest integer $\leq x$. For example, $[3.4] = 3$ as does $[3.0]$, while $[-3.4] = -4$ and $[-3.0] = -3$. The ceiling of $x$ (written $\lceil x\rceil$) takes real value $x$ and returns the least integer $\geq x$. For example, $\lceil3.4\rceil = 4$, as does $[4.0]$, while $\lceil-3.4\rceil = -3$.

**Modulus operator:** The **mod** function returns the remainder of integer division. We often write $n \bmod m$ in mathematical expressions, the syntax for the C++ modulus operator is `% m$. $n \bmod m$ is the integer $r$ such that $n = qm + r$ for an integer, and $|r| < |m|$. Therefore, the result of $n \bmod m$ must be between $0$ and $m-1$ when $n$ and $m$ are positive integers. For example, $5 \bmod 2 = 2$; $25 \bmod 3 = 1$; $5 \bmod 7 = 5$;

There is more than one way to assign values to $q$ and $r$, depending on how integer division is defined. The most common mathematical definition computes the mod function as $n \bmod m = n - m[n/m]$. In this case, $-3 \bmod 5 = 2$. However, Java and C++ compilers typically use the processor’s machine instruction for computing integer arithmetic. This is possible by truncating the fraction result, meaning $n \bmod m = n - m(\text{trunc}(n/m))$. Under this definition, $-3 \bmod 5 = -3$.
