    delete [] listArray; // Reinitialize the list
    listSize = curr = 0; // Remove the array

```cpp
// Insert "it" at current position
void insert(const E it) {
    Assert(listSize < maxSize, "List capacity exceeded");
    for(int i=listSize; i>curr; i--) // Shift elements up
    listArray[i] = listArray[i-1]; // to make room
    listArray[curr] = it;
    listSize++;
}
```

```cpp
// Append "it"
void append(const E it) {
    Assert(listSize < maxSize, "List capacity exceeded");
    listArray[listSize++] = it;
}
```

```cpp
// Remove and return the current element.
E remove() {
    Assert((curr==0) && (curr < listSize), "No element");
    E it = listArray[curr]; // Copy the element
    for(int i=curr; i<listSize-1; i++) // Shift them down
    listArray[i] = listArray[i+1];
    listSize--;
    return it;
}
```

Most of the other member functions for Class AList simply access the current list element or move the current position. Such operations all require $\Theta(1)$ time. Aside from insert and remove, the only other operations that might require more than constant time are the constructor, the destructor, and **clear**. ## 4.1.2 Linked Lists

The second traditional approach to implementing lists makes use of pointers and is usually called a **linked list**. The list uses **dynamic memory allocation**, that it allocates memory for new list elements as needed.

A linked list is made of a series of objects, called the **nodes** of the list. Because a node is a distinct object (as opposed to a cell in an array), it is good practice to create a separate list class. An additional benefit of creating a list class is that it can be reused by the linked implementations for the stack and queue data structures presented in this chapter. Figure 4.4 shows the implementation for list nodes, called the **Link** class. Objects in the **Link** class contain an **element** field to store the value, and a **next** field to store a pointer to the next node on the list. The list built from such nodes is a **singly list**, or a **one-way list**, because each node has a single pointer to the next node on the list.

The **Link** class is quite simple. There are two forms for its constructor, with an initial value and one without. Because the **Link** class is also used by the stack and queue implementations presented later, its data members are made public. While this is tricky regarding encapsulation, the **Link** class should be implemented as a private class of the linked list (or stack or queue) implementation, and thus not visible to the rest of the program.

C++ uses the special symbol NULL for a pointer value that points nowhere, such as for the last list node's **next** field. A NULL pointer is indicated graphically by a diagonal slash through a pointer variable's box.

The list's first node is accessed from a pointer named **head**. To speed access to the end of the list, a pointer named **tail** is also kept to the last link of the list. The position of the current element is indicated by another pointer, named **curr**. Finally, there is no simple way to compute the length of the list simply from these three pointers, the list must be stored explicitly, and updated by every operation that modifies the list. The value *cnt* stores the length of the list.

**LinkedList** also includes helper methods **init** and **removeall**. They are used by **LList**'s constructor, destructor, and **clear** methods.

Note that **LinkedList**'s constructor maintains the optional parameter for minimum list size included for **ArrayList**. This is done simply to keep the calls to the constructor same for both variants. The linked list class does not need to declare a fixed-size array when the list is created, this parameter is unnecessary for linked lists. It is ignored by the implementation.

A key decision for the linked implementation is how to represent the current position. The most reasonable choice appears to be a pointer to the current element. But there is a big advantage to making **curr** pointer to the element preceding the current element.
