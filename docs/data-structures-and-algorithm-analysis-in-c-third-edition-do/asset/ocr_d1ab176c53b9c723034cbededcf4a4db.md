Chap. 9 Searching

Another probe function that eliminates clustering is called quadratic probing. The probe function is some quadratic function

$$\mathbf{p}(K, i) = c_1i^2 + c_2i + c_3$$

for some choice of constants $c_1, c_2$, and $c_3$. The simplest variant is $p(K, i) = i^2$ (i.e., $c_1 = 1, c_2 = 0$, and $c_3 = 0$). The $i$th value in the probe sequence would be $(h(K) + i^2) \mod M$. Under quadratic probing, two keys with different positions will diverge probe sequences.

**Example 9.10** Given a hash table of size $M=101$, assume for keys $k_1$ and $k_2$ that $h(k_1)=30$ and $h(k_2)=29$. The probe sequence for $k_1$ is 30, 31, 34, 39. The probe sequence for $k_2$ is 29, 30, 33, 38. Thus, $k_2$ will probe to $k_1$'s home position as its second choice, the two keys' probe sequences diverge immediately thereafter.

Unfortunate, quadratic probing has the disadvantage that typically not all hash slots will be filled. Using $p(K,i)=i^2$ gives particularly inconsistent results. For many hash table sizes, this probe function will cycle through a relatively small number of slots. If all cycle to full, the record cannot be inserted at all! For example, if our hash table has three slots, then record hashes to slot 0 can only probe slots 0 and 1, and the probe sequence will never visit slot 2 in the table. Thus, if slot 0 and 1 are full, the record cannot be inserted even though the table is not full. A more realistic example is a table with 105 slots. The probe sequence starting from any given slot will only visit 23 slots in the table. If all of these 23 slots happen to be full, even if other slots in the table are empty, the record cannot be inserted because the probe sequence will continually hit only those 24 slots.

Fortunately, it is possible to get good results from quadratic probing at low cost. The right combination of probe function and table size will visit many slots in the particular. If the hash table size is a prime number and the probe function is $p(K,i)=i^2$, then at least half the slots in the table will be visited. Thus, if the table is not half full, we can be certain that a free slot will be found. Alternatively, if the hash table size is a power of two and the probe function is $p(K,i)=(i^2+i)/2$, then every slot in the table will be visited by the probe function.

Both pseudo-random and quadratic probing eliminate primary clustering, which is if two keys hash to the same home position, then they will always follow the same probe sequence for every collision resolution method that we have seen so far. The probe sequences generated by pseudo-random and quadratic probing (for example) are entirely a function of the home position, not the original key value.
