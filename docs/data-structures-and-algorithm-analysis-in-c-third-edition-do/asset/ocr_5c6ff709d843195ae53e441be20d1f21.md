To analyze Quicksort, we first analyze the **findpivot** and **partition** operations operating on a subarray of length *k*. Clearly, **findpivot** takes constant time. Function **partition** contains a *do* loop with two nested **while** loops. The total cost of the partition operation is constrained by how far **l** and **r** can move inwards.
