This section presents spatial data structures for storing point data in two or more dimensions. They are the k-d tree and the PR quadtree. The k-d tree is a natural extension of the BST to multiple dimensions. It is a binary tree whose decisions alternate among the key dimensions. Like the BST, the k-d tree uses object space decomposition. The PR quadtree uses space decomposition and is a form of tree. It is a binary tree with a binary alphabet. For dimensions it has $2^d$ branches. Thus, in two dimensions, the quadtree has four branches (hence the name “quadtree”), splitting into four equal-sized quadrants at each branch. 13.3.3 mentions two variations on these data structures, the bintree and the point quadtree. These structures cover all four combinations of vertex key space decomposition on the one hand, and multi-level binary versus $2^d$-waybranching on the other. 13.3.4 discusses spatial data structures for storing other types of spatial data.

# 13.3.1 The K-d Tree

The k-d tree is a modification to the BST that allows for efficient processing of multidimensional keys. The k-d tree differs from the BST in that level of the k-d tree makes branching decisions based on a particular search key associated with that level, called the discriminator. In principle, the k-d tree could be used to unify searching against any set of keys such as name and zipcode. In practice, it is nearly always to support search for multidimensional coordinates, such as locations in 2D or 3D space. We define the discriminator at level $i$ to be $i \pmod k$ for $k$ dimensions. For example, assume that we store data by $zy$-coordinates. In this case, $k=2$ (there are two coordinates), with the $x$-coordinate field designated 0 and the $y$-coordinate field designated 1. At each level, the discriminator alternates between $x$ and $y$. A node $N$ at level 0 (the root) would have in its left subtree nodes whose $x$ values are less than $N_x$ (because $x$ is binary and $x=0$). The right subtree would contain nodes whose $x$ values are greater than $N_x$. A node $M$ at level 1 would have in its left nodes whose $y$ values are less than $M_y$. There is no restriction on the relative values of $M_x$ and the $M$'s discriminators, because branching decisions are based on the $y$ coordinate. 13.3.11 shows an example of how a collection of two-dimensional points was stored in a k-d tree.
