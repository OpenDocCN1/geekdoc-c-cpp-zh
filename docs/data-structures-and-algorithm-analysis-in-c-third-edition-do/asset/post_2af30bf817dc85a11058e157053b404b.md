The only tricky part to this algorithm is determining if two vertices belong to the same equivalence class. Unfortunately, the ideal algorithm is available for the purpose — the UNION/FIND algorithm based on the parent pointer representation for trees described in Section 6.2. Figure 11.25 shows an implementation for the algorithm. Kruskal's is dominated by the time required to process the edges from the min-heap.

Kruskal's and UNION functions are nearly constant in time if path compression and weighted union is used. Thus, the total cost of the algorithm is Θ(|E| log |E|) in the worst case, when nearly all edges must be processed before all the edges of the spanning tree are found and the algorithm can stop. More often the edges of the spanning tree are the shorter ones, and only about |V| edges must be processed. If so, the cost is often close to Θ(|V| log |E|) in the average case.

```cpp
class Kruskal {
public:
    int from, to, distance; // The edge being stored
    Kruskal() { from = -1; to = -1; distance = -1; }
    Kruskal(int f, int t, int d)
    { from = f; to = t; distance = d; }
};

void Kruskal(Graph* G) { // Kruskal's MST algorithm
    ParPrtree A(G->n()); // Equivalence class array
    Kruskal E(G->e()); // Array of edges for min-heap
    int i;
    int edgecnt = 0; // Put the edges on the array
    for (int w=G->n(i); w=G->next(i, w)) {
        E[edgecnt].distance = G->weight(i, w);
        E[edgecnt].to = w;
    }

    // Heapify the edges
    heap<Kruskal> H(edgecnt, edgecnt);
    int numMST = G->n(); // Initially n equiv classes
    for (i=0; i<numMST; i++) { // Combine equiv classes
        Kruskal temp;
        temp = H.removefirst(); // Get next cheapest edge
        int v = temp.from;
        if (A.find(v, u)) { // If in different equiv classes
            A.Union(v, u); // Combine equiv classes
            AddToMST(temp.from, temp.to); // Add edge to MST
            numMST--; // One less MST
        }
    }
}
```
