**Access Memory (RAM)**, while secondary storage refers to devices such as hard disk drives, solid state drives, removable "USB" drives, CDs, and DVDs. Primary memory also includes registers, cache, and video memories, but we will ignore them for this discussion because their existence does not affect the particular differences between primary and secondary memory.

Along with a faster-CPU, every new model of computer seems to come with more memory. As memory size continues to increase, it is possible that relatively slow disk storage will be unnecessary? Probably not, but the desire to store and process files grows as fast as main memory size. For both main memory and peripheral storage devices have dropped dramatically in recent years, as demonstrated by Figure 8.1. However, the cost per unit of disk drive storage is about two orders of magnitude less than RAM and has for many years.

There is now a wide range of removable media available for transferring or storing data offline in relative safety. These include floppy disks (largely obsolete), writable CDs and DVDs ("flash" drives), and magnetic tape. Optical storage as CDs and DVDs costs roughly the price of hard disk drive space per megabyte, and have become practical for use as backup storage within the past few years. Tape used to be much cheaper than other media, and was the preferred means of backup, but are so popular now as other have decreased in price. "Flash" costs the most per megabyte, but due to their storage capacity and flexibility, which replaced floppy disks as the primary storage device for transferring data between computers when network transfer is not available.

Secondary storage devices have at least two advantages over RAM memory. For most importantly, disk, "flash," and optical media are **persistent**, meaning that they are not erased from the media when the power is turned off. In contrast, RAM used for main memory is usually **volatile** — all information is lost with the power. A second advantage is that CDs and "USB" drives can be easily transferred between computers. This provides a convenient way to take information from one computer to another.
