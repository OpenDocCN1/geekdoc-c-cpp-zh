We use binary insert to place the losers. However, we are free to choose the best ordering for inserting, keeping in mind the fact that binary search has the same cost for $2'$ $2^{2'}-1$ items. For example, binary search requires three comparisons in the worst case for lists of size 4, 5, 6, or 7. So we pick the order of inserts to optimize the binary searches, which means picking an order that avoids a growing subset such that it crosses the boundary on list size to require an additional comparison. This sort is called **merge insert**, and also known as the Ford and Johnson sort.

For ten elements, the poset shown in Figure 15.7 folds in the last four elements (labeled 1 to 4) in the order Element 3, Element 4, Element 1, and finally Element 2. Element 3 will be inserted into a list of size three, costing two comparisons. Depending on where Element 3 ends up in the list, Element 4 will be inserted into a list of size 2 or 3, costing two comparisons in either case. Depending on where Element 3 and 4 are in the list, Element 1 will be inserted into a list of size 5, 6, or 7, all of which require three comparisons to place in right order. Finally Element 2 will be inserted into a list of size 5, 6, or 7.

Merge insert is pretty good, but is it optimal? Recall from Section 7.9 that **information theoretic lower bound** for sorting can be proved to be $\lfloor \log n floor$. That is, we can prove a lower bound of exactly $\lfloor \log n! floor$ comparisons. Merge insert gives us a number of comparisons equal to this information theoretic lower bound for all values up to $n=12$. At $n=12$, merge insert requires 30 comparisons while the information theoretic lower bound is only 29. However, for such a small number of elements, it is possible to do an exhaustive study of every possible arrangement of comparisons. It turns out there is in fact no possible arrangement of comparisons that make the lower bound less than 30 comparisons when $n=12$. Thus, the information theoretic lower bound is an underestimate in this case, because 30 is the best that can be done.
