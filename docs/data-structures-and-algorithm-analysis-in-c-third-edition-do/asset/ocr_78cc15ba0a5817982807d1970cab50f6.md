So we can see that we could multiply two polynomials in less than $\Theta(n^2)$ operations if a fast way could be found to evaluation/interpolation of $2n-1$ points. Before considering how this might be done, first observe the relationship between evaluating a polynomial at values $c$ and $-c$. In general, we can write $P_a(x) = E_a(x) + O_a(x)$ where $E_a$ is the even powers and $O_a$ is the odd powers.
So,

```
$P_a(x) = \sum_{i=0}^{n/2-1} a_{2i}x^{2i} + \sum_{i=0}^{n/2-1} a_{2i+1}x^{2i+1}$
```

The significance is that when evaluating the pair of values $c$ and $-c$, we get

```
$E_a(c) + O_a(c) = E_a(c) - O_a(-c)$
$O_a(c) = -O_a(-c)$
```

Thus, we only need to compute the $E_s$ and $O_s$ instead of twice to get evaluations.

The key fast polynomial multiplication is finding the right points to use for evaluation/interpolation to make the process efficient. In particular, we want to take advantages of symmetries, such as the one we see for evaluating $x$ and $-x$. But we need to find even more symmetries between points if we want to do more than cut the work in half. We have found symmetries not just between pairs of values, but also further symmetries between pairs of pairs, and then pairs of pairs of pairs, and so on.

Recall that a complex number has a real component and an imaginary component. We can consider the position of $z$ on a number line if we use the $y$ dimension for the imaginary component. Now we define a primitive $n$-th root of unity if

$z^0, z^1, \dots, z^{n-1}$ are all the $n$-th roots of unity. For example, when $n=4$, then $z = i$ and $z = -i$. In general, we have the identities $e^{i\pi} = -1$, and $z = e^{2\pi ij/n} = -1^{2j/n}$ (see Figure 16.6). But these points are special in that they will allow us to just do points on a unit circle as we would need the right computation to get the needed symmetries to speed up the overall process of evaluating many points at once.
