**Figure 17.6** The graph generated from Boolean expression $B = (x_1+x_2) \cdot (x_1+x_2+x_3)$. Literals from the first clause are labeled $C1$, and from literals the second clause are labeled $C2$. There is an edge between every pair of vertices except when both vertices represent instances of literals from the same clause, or a negation of the same variable. Thus, the vertices labeled $C1:j_1$ does not connect to the vertex labeled $C1:j_2$ (because they are literals in the same clause) or the vertex labeled $C2:j_1$ (because they are opposite values for the same variable).

where $k_i$ is the number of literals in clause $c_i$. We will transform this to an instance of K-CLIQUE as follows. We build a graph

```
$G = \v[i, j] \mid 1 \le i \le m, 1 \le j \le k_i$;
```

that is, there is a vertex in **G** corresponding to every literal in Boolean **B**. We will draw an edge between each pair of vertices $v[t1, j1]$ and $v[t2, j2]$ unless they are literals within the same clause $(t1=t2)$ or (2) they are opposite values for the same variable (i.e., one is negated and the other is not). Let $k=m$. Figure 17.6 shows an example of this transformation.

**B** is satisfiable if and only if **G** has a clique of size $k$ or greater. **Being** satisfiable implies that there is a truth assignment such that at least one literal $y[i, j]$ is true for each $i$. If so, these $m$ literals must correspond to vertices in a clique of size $k=m$. Conversely, if **G** has a clique of size or greater, the clique must have exactly $k$ (because no two vertices to literals in the same clause can be in the clique) and there is one vertex $v[i, j]$ in the clique for each $i$. There is a truth assignment making each $y[i, j]$ true. That truth assignment satisfies **B**.

We conclude that K-CLIQUE is $\mathcal{NP}$-hard, therefore $\mathcal{NP}$-complete.
