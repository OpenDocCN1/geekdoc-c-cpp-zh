What makes mathematical induction so powerful (and so mystifying most people at first) is that we can take advantage of the *\textit{assumption}* that \textbf{Thrm} holds for all values less than $n$ as a tool to help us prove that \textbf{Thrm} holds for $n$. This is known as the **induction hypothesis**. Having this assumption to work makes the induction step easier than tackling the original theorem itself. Being able to rely on the induction hypothesis provides extra information that we can bring to the problem.

Recursion and induction have many similarities. Both are anchored on one or more cases. A recursive function relies on the ability to call itself to get smaller instances of the problem. Likewise, the truth of the induction proof prove the theorem. The induction hypothesis does not come out of air. It is true if and only if the theorem itself is true, and therefore is reliable within the proof context. Using the induction hypothesis it does work exactly the same as using a recursive call to do.

**Example 2.11** Here is a sample proof by mathematical induction. Call the sum of the first $n$ positive integers $S(n)$.

# **Theorem 2.2** $S(n) = n(n+1)/2$.

**Proof:** The proof is by mathematical induction. For $n=1$, verify that $S(1) = 1(1+1)/2$. $S(1)$ is simply the sum of the first positive number, which is 1. Because $1(1+1)/2 = 1$, the formula is correct for the base.

+   1. **State the induction hypothesis.** The induction hypothesis is

```
$S(n-1) = \sum_{i=1}^{n-1} i = \frac{(n-1)((n-1)+1)}{2} = \frac{(n-1)(n)}{2}$
```

+   2. **Use the assumption from the induction hypothesis for $n-1$ to show that the result is true for $n$.** The induction hypothesis states that $S(n-1) = (n-1)(n)/2$, because $S(n) = S(n-1) + n$, we can substitute for $S(n-1)$ to get

```
$\sum_{i=1}^{n} i = (\sum_{i=1}^{n-1} i + \frac{(n-1)(n)}{2}) + n = \frac{n^2-n+2n}{2} = \frac{n(n+1)}{2}$
```

Thus, by mathematical induction,

```
$S(n) = \sum_{i=1}^{n} i = n(n+1)/2$.
```
