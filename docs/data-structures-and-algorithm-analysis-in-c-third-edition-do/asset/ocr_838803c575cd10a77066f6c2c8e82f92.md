14.22 Recall that two vertices in an undirected graph are component if there is a path connecting. A good algorithm to find the connected components of an undirected graph begins by calling a DFS on the first vertex. All vertices reached by the DFS in the same connected component are marked. We then look through the vertex mark array until an unmarked i is found. After calling the DFS on i, all vertices reachable from i are in a second connected component. We continue working through the mark array until all vertices have been assigned to some component. A sketch of the algorithm is as follows:

```
void recom(Graph G, int v, int component) {
  G->setMark(v, component);
  for (int i=w->first(v); w<G->n(); w = G->next(v, w)) {
    if (G->getMark(w) == 0)
      recom(G, w, component);
  }
```

```
void recom(Graph G) {
  int i;
  component = 1; // Counter for current component
  for (i=0; i<G->n(); i++) // For n vertices in graph
    G->setMark(i, 0); // Vertices start in no component
  for (i=0; i<G->n(); i++)
    if (G->getMark(i) == 0) // Start a new component
      recom(G, i, component++);
}
```

Use the concept of amortized analysis to explain why the total cost of this algorithm is Θ[V + E]. (Note that this will not be a true amortized analysis because this algorithm does not allow an arbitrary series of DFS operations but rather fixed to a single call to DFS from each vertex.)
