# 高级树结构

本章介绍了用于特殊应用的树结构。13.1 节的字典（trie）通常用于存储和检索字符串。它还用于说明键分解的概念。13.2 节的 AVL 树和伸叶树是 BST 的变体。它们是自平衡搜索树的示例，无论插入顺序如何都能保证良好的性能。13.3 节介绍了用于组织点数据的空间数据结构。

每个结构都给出了基本操作描述。本章的一个目的是为课程项目提供机会，因此详细实现留给读者。
