That is, if a decision problem $F$ yields YES on input $I$, then there is a language $L$ containing $I'$ where $I'$ is some suitable transformation of input $I$. Conversely, if $F$ would answer NO for input $I$, then $I$'s transformed version $I'$ is not in the language.

Turing machines are a simple model of computation for writing programs that are language acceptors. There is a "universal" Turing machine that can take as input a description of that machine, and an input string, and run the execution of that machine on that. This Turing machine can be cast as a Boolean expression that the string is satisfiable if and only if the Turing machine accepts for that string. Used Turing machines in his proof because they are simple enough he could develop this transformation of Turing machines to Boolean expressions, but enough to compute any function that a regular computer can compute. The significance of this transformation is that any decision problem performed by the Turing machine is transformable to SAT. Thus, SAT is $\mathcal{N}P$-hard.

As explained above, to show that a decision problem $X$ is $NP$-complete, we prove that $X$ is in $\mathcal{N}P$ (exactly, and normally no by giving a suitable polynomial-time, nondeterministic algorithm) and then prove that $X$ is $\mathcal{N}P$-hard. To prove that $X$ is $\mathcal{N}P$-hard, we choose a known $NP$-complete problem, say $A$. We describe a polynomial-time transformation that takes an *arbitrary* instance $I$ of $A$ to an instance of $X$. We describe a polynomial-time transformation from $SL$ to $SL'$ such that $SL'$ is the solution for $I$. The following example provides a model for how $NP$-completeness is proved.
