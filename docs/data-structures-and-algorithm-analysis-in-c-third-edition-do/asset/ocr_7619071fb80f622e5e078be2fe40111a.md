// Remove element at specified position
remove(pos) {
    Assert(pos >= 0) && (pos < n), "Bad position");
    if (pos == (n-1)) n--; // Last element, no work to do
    else {
        swap(Heap, pos, --n); // Swap with last value
        while (pos != 0) &&
            (Comp:prior Heap[pos], Heap[parent(pos)])) {
                swap(Heap, pos, parent(pos)); // Push up large key
                pos = parent(pos);
            }
        if (n != 0) siftdown(pos); // Push down small key
    }
    return Heap[n];
}

size returns the current size of the heap. H.isLeaf(pos) returns true if pos is a leaf in H, and false otherwise. Members leftchild, rightchild, and parent return the position (actually, the array index) for left left, right, and parent of the position passed, respectively.

One way to build a heap is to insert the elements one at a time. Method insert will insert a new element V into the heap. You might expect the insertion process to be similar to the insert function for a BST, at the root and working down the heap. However, this approach is not likely to work because the heap must maintain the shape of a complete binary tree.
