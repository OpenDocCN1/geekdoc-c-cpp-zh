# Example 14.3 Solve the summation

```
$f(n) = \sum_{i=0}^{n} ar^i = a + ar + ar^2 + \dots + ar^n$.
```

This is a geometric series. Our goal is to find function $g(n)$ such that the difference between $f(n)$ and $g(n)$ from the other leaves leaves us with an easily manipulated equation. Because the difference between consecutive terms of the summation is a factor of $r$, we can shift terms if we multiply the entire expression by $r$:

```
$rf(n) = r \sum_{i=0}^{n} ar^i = ar + ar^2 + ar^3 + \dots + ar^{n+1}$.
```

We can now subtract one equation from the other, as follows:

```
$f(n) - rf(n) = a + ar + ar^2 + \dots + ar^n \n$- (ar + ar^2 + ar^3 + \dots + ar^{n+1})$,
```

The result leaves only the ends:

```
$f(n) - rf(n) = \sum_{i=0}^{n} ar^i - r \sum_{i=0}^{n} ar^i.\n$(1 - r)f(n) = a \frac{a - ar^{n+1}}{1 - r}$.
```

Thus, we get the result

```
$f(n) = \frac{a - ar^{n+1}}{1 - r}$
```

where $r \neq 1$.
