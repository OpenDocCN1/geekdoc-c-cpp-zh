# 11.3 Graph Traversals

Graph traversal algorithms can solve both of these problems by maintaining a mark bit for each vertex on the graph. At the beginning of the algorithm, the mark bit for all vertices is cleared. The mark bit for a vertex is first visited during the traversal. If a marked vertex is encountered during traversal, it is not visited a second time. This keeps the program from going into an infinite loop when it encounters a cycle.

Once the traversal algorithm completes, we can check to see if all vertices have been processed by checking the mark array. If not all vertices are marked, we can continue the traversal from another unmarked vertex. Note that this process works regardless of whether the graph is directed or undirected. To ensure visiting vertices, graphTraverse could be called as follows on a graph G:

```
void graphTraverse(Graph* G) {
  int v;
  for (v=0; v<G->n(); v++) {
    G->setMark(v, UNVISITED); // Initialize mark bits
    for (v=0; v<G->n(); v++) {
      if (G->getMark(v) == UNVISITED)
        depthTraverse(G, v);
    }
  }
}
```

"depthTraverse" might be implemented using one of the graph traversals described in this section.

# 11.3.1 Depth-First Search

The first method of organized graph traversal is called depth-first search DFS. Whenever a vertex V is visited during the search, DFS will recursively visit all of V's unvisited neighbors. Equivalently, DFS will add all edges out of v to a stack. The next vertex to be visited is determined by popping the stack and following that edge. The effect is to follow one branch from the graph to the conclusion, then it will back up and follow another branch, and so. The DFS process can be defined using a depth-first search tree. This tree is composed of the edges that were followed to any new (unvisited) vertex during the traversal, and the edges that leaves out to already visited vertices. DFS can be applied to directed or undirected graphs. Here is an implementation for the DFS algorithm:

```
void DFS(Graph* G, int v) { // Depth first search
  PreVisit(G, v); // Take appropriate action
  G->setMark(v, VISITED);
  for (int w=G->first(v); w<G->n(); w = G->next(v,w)) {
    if (G->getMark(w) == UNVISITED)
      DFS(G, w);
  }
  PostVisit(G, v); // Take appropriate action
}
```
