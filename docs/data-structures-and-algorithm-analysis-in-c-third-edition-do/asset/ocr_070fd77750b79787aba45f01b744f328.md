In this example, the list has four elements. The second element is the sublist $(y1, (a1, a2), y3)$ and the third is the sublist $(z1, z2)$. The sublist $(y1, (a1, a2))$ itself contains a sublist. If a list $L$ has one or more sublists, we call $L$ a **multlist**. Lists with no sublists are often referred to as **linear lists** or **chains**. Note that this definition for multlist fits with our definition of sets from Definition 2.1, where a set's members can be primitive elements or sets.

We can restrict the sublists of a multlist in various ways, depending on whether the multlist should have the form of a tree, a DAG, or a generic graph. A **pure list** is a list whose graph corresponds to a tree, such as in Figure 12.2. In other words, there is exactly one path from the root to any node, which means that no object may appear more than once in the list. In pure list, each pair of angle brackets corresponds to an internal node of the tree. The members of the list correspond to the children for the node. Atoms on the list consist to leaf nodes.

A **reentrant list** is a list whose graph corresponds to a DAG. Nodes might be accessible from the root by more than one path, which is equivalent to saying that objects (including sublists) appear multiple times in the list as long as no cycles are formed. All edges point downward, from the node representing a list or sublist to its elements. Figure 12.2 illustrates a reentrant list. To write out this list in bracket notation, we can duplicate nodes as necessary. Thus, the bracket notation for the list of Figure 12.2 could be written

```
⟨⟨a,b⟩, (⟨a,b),c), (⟨c,d,e), e⟩
```
