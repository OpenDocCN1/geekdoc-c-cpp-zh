**Example 2.14** This example uses induction without involving summations or others. It also illustrates a more flexible use of cases.

**Theorem 2.5** $2e$ and $5e$ stamps can be used to form any value (for values $\ge 4$).

**Proof:** The theorem defines the problem for values $\ge 4$ because it does not hold for the values 1 and 3. Using as the base case, the value of $4e$ can be made from two $2e$ stamps. The induction hypothesis is that a value of $n-1$ can be made from some combination of $2e$ and $5e$ stamps. We now use the induction hypothesis to show how to get the value of $n$ from $2e$ and $5e$ stamps. If the makeup for $n-1$ includes a $5e$ stamp, it does, then replace a $5e$ stamp with three $2e$ stamps. If not, then the makeup must have included at least two $2e$ stamps (because it is at least size 4 and contains only $2e$ stamps). In this case, replace two of the $2e$ stamps with a single $5e$ stamp. In each case, we have a value of $n$ made up of $2e$ and $5e$ stamps. Thus, by mathematical induction, the theorem is correct.

**Example 2.15** Here is an example using strong induction.

**Theorem 2.6** For $n>1$, $n$ is divisible by some prime number.

**Proof:** For the base case, choose $n=2$. 2 is divisible by the prime number 2. The induction hypothesis is that any value $a$, $2 \le a < n$, is divisible by some prime number. There are two cases to consider when proving the theorem for $n$. If $n$ is a prime number, then $n$ is divisible by itself. If $n$ is not a prime number, then $n=a 	imes b$ for $a$ and $b$, integers less than $n$ but greater than 1. The induction hypothesis tells us that $a$ is divisible by some prime number. That same prime number must also divide $n$. Thus, by mathematical induction, the theorem is correct.
