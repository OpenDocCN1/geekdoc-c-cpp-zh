# Example 9.8 Here is a much better hash function for strings.

```
// folding on a string, summed 4 bytes at a time
int sfold(char *key) {
    unsigned int *lkey = (unsigned int *)key;
    int intlength = strlen(key)/4;
    unsigned int sum = 0;
    for (int i=0; i<intlength; i++) {
        sum += lkey[i];
    }
    // Now deat with the extra chars at the end
    int extra = strlen(key) - intlength*4;
    char temp[4];
    lkey = (unsigned int *)temp;
    lkey[0] = 0;
    for (int i=0; i<extra; i++) {
        temp[i] = key[intlength*4+i];
    }
    sum += lkey[0];

    return sum % M;
}
```

This function takes a string as input. It processes the four bytes at a time, and interprets each of the four-byte chunks as a single (unsigned) long value. The integer values for the four-byte chunks are added together. In addition, the resulting sum is converted to the range 0 to $M-1$ using the modulus operator.

If, for example, "aaaabbbb" is passed to sfold, the first four bytes ("aaaa") will be interpreted as the integer value 1,633,771,873 and the next four bytes ("bbbb") will be interpreted as the integer value 1,650,614,682. Their sum is 3,284,386,755 (when viewed as an unsigned integer). If the table size is 101 then the modulus function will cause this for sufficiently long string, the key to hash to 75 in the table. the sum for integer quantities will typically cause a 32-bit integer to overflow (thus losing some of the high-order bits) because the resulting values are so large. This causes no problems when the goal is to compute a hash function.

> 2 Recall from Section 2.2 that the implementation for mod m on many C++ and compilers will yield a negative if n is negative. Implementors for hash functions need to be careful that their hash function does not generate a negative number. This can be avoided by ensuring that n is positive when computing n mod m, or adding m to the result if n mod m is negative. All computation in sfold is done using long values in part to protect against taking the modulus of a negative number.
