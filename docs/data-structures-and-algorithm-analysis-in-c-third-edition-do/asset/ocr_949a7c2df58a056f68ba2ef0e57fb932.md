**Example 13.7** We will find all cities in the k-d tree of Figure 13.4 within 25 units of the point (25, 65). The search begins with the root node, which contains record A. Because (40, 45) is exactly 25 units from the search point, it will be reported. The search procedure determines which branches of the tree to take. The search circle extends to both the left and the right of A's (vertical) dividing line, so both branches of the tree must be searched. The left subtree is processed first. Here, record B has no child, processing of the left subtree is complete. Processing of node storing B found to fall within the search circle. Processing of A's right subtree begins now. The coordinates of record C are checked and not found within the circle. Thus, it should not be reported. However, it is possible that cities within C's subtrees could fall within the search circle if C does not. As C is at level 1, the discriminator is this $y$-coordinate. Because $65 - 25 > 10$, no record in C's subtree (i.e., records above C) could possibly be in the search circle. However, cities in C's right subtree (if it had one) need not be searched. Thus, search proceeds to the node containing record D. Again, D is outside the search circle. $25+25 < 69$, no record in D's right subtree could be within the search circle. This leads to comparing record E's coordinates against the search circle. Record E falls outside the search circle, and processing is complete. So we see that we only search subtrees whose rectangles fall within the search circle.
