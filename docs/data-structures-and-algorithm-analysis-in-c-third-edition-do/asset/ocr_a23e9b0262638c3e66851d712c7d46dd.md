If you truly wish to understand the running time of an algorithm, there are other
factors that are more appropriate to consider than machine speed, programming
language, compiler, and so forth. Ideally we would measure the running time of
the algorithm under standard benchmark conditions. However, we have no way
to calculate the running time reliably than to run an implementation of
tg algorithm on some computer. The only alternative is to use some other measure as
as surrogate for running time.

Of primary consideration when estimating an algorithm’s performance is the
number of basic operations required by the algorithm to process an input of
center size. The terms “basic operations” and “size” are both vague and
depend on the algorithm being analyzed. Size is often the number of inputs pro-\ccessessed. For comparing sorting algorithms, the size of the problem
is typically measured by the number of records to be sorted. A basic operation
must have the property that its time to complete does not depend on the particular
values of its operands. Adding or comparing two integer variables are examples
of basic operations in many programming languages. Summing the contents of an
array n integers is not constant, because the cost depends on the value of n (i.e.,
size of the input).

Example 3.1 Consider a simple algorithm to solve the problem of finding
t largest value in an array of n integers. The algorithm looks at each
integer turn, saving the position of the largest value seen far. This is
called the largest-value sequential search and is illustrated by
the following function:

```
// Return position of largest value in "A" of size "n"
int largest(int A[], int n) {
    int currlage = 0; // Holds largest element position
    for (int i=1; i<n; i++) // For each array element
    if (A[i] < A[currlage]) // if A[i] is larger
        currlage = i; // remember its position
    return currlage; // Return largest position
}
```

Here, the size of the problem is A. length, the number of integers stored
in array A. The basic operation is to compare an integer’s value to that of
t largest value seen so far. It is reasonable to assume that it takes a fixed
amount of time to do one such comparison, regardless of the value of
two integers or their positions in the array.
