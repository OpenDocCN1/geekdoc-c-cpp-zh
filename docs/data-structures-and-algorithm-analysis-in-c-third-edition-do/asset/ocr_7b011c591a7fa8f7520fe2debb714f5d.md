5.5 Implement a priority queue based on the max-heap class implementation of Figure 5.19. The following methods should be supported for manipulating the priority queue:

```
void enqueue(int ObjectID, int priority);
int dequeue();
void changeweight(int ObjectID, int newPriority);
```

Method enqueue inserts a new object into the priority queue with ID ObjectID and priority. Method dequeue removes the object with highest priority from the priority queue and returns its object ID. Method changeweight changes the priority of the object with ID number newPriority. The type for E should be a class that stores the object ID and the priority for that object. You will need a mechanism for finding the position of the desired object within the heap. Use an array, storing the object with ObjectID in position i. (Be sure in your testing to keep the ObjectIDs within the array bounds.) You must also modify the heap implementation to store the object's position in the auxiliary array so that updates to objects in the heap are updated as well in the array.

The Huffman coding tree build manipulates a sorted list. This could result in an O(n²) algorithm, because placing an intermediate Huffman tree on the list could take O(n) time. Revise this algorithm to use a priority queue based on a min-heap instead of a list.
