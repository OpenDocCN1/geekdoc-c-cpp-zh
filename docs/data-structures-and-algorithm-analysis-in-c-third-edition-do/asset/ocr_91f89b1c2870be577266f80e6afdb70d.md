Dividing by $n$ and $f(n-1)$ happen to give us useful patterns to work with. $\frac{f(n)}{n+1}$ and $\frac{f(n)}{n-1}$. Of course, lots of other guesses for function $q$ do not work. For, $f(n)-n=f(n-1)$. Knowing that $f(n)=f(n-1)+n$ is not useful for determining the closed-form solution to this summation. Consider $f(n)-f(n-1)=n$. Again, knowing that $f(n)=f(n-1)+n$ is not useful. Finding the right combination of equations can be like finding a needle in a haystack.

In our first example, we can see directly that the closed-form solution should be. $\frac{f(n)}{n-1}$, obviously $f(n)=n(n+1)/2$.

Dividing $f(n)$ by $f(n-1)$ does not give so obvious a result, but it provides another illustration.

```
$$\begin{aligned}&\frac{f(n)}{f(n-1)} &= \frac{n+1}{n-1}\\&frac{f(n-1)}{f(n-2)} &= (n+1)\frac{f(n-1)}{f(n)}\\n&frac{f(n-1)}{f(n-2)} &= (n+1)(f(n)-n)\\&nf(n)-f(n-1) &= nf(n)+f(n)-n^2\\&2f(n) &= n^2+n=n(n+1)\\&f(n) &= \frac{n(n+1)}{2}\end{aligned}$
```

Again, we still not have a proof that $f(n)=n(n+1)/2$. Why? Because we did not prove that $f(n)/f(n-1)=(n+1)/2$ nor that $f(n)/f(n-1)=(n+1)(n-1)$. We merely hypothesized patterns from looking at a few terms. Fortunately, it is easy to check our hypothesis with induction.
