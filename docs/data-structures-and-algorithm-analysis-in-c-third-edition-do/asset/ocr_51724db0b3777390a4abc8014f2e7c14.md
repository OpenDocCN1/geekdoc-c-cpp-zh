I make a distinction in the text between “C++ implementations” and “pseudocode.” Code labeled as a C++ implementation has actually been compiled and tested on one or more C++ compilers. Pseudocode examples often conform closely to C++ syntax, which typically contain one or more lines of higher-level description. Pseudocode is used when I perceived a greater pedagogical advantage to a simpler, but less precise, description.

**Exercises and Projects:** Proper implementation and analysis of data structures cannot be learned simply by reading a book. You must practice by implementing real programs, constantly comparing techniques to see what works best in a given situation.

One of the most important aspects of a course in data structures is that it is where students learn to program using pointers and dynamic memory allocation, implementing data structures as linked lists and trees. It is where students truly learn recursion. In our curriculum, this is the first course where students do significant design, because it often requires real structures to motivate design exercises. Finally, the fundamental differences between memory-based and disk-based access cannot be appreciated without practical programming experience. For all of these reasons, a structures course cannot succeed without a significant programming component. In our department, the structures course is one of the most difficult programming course in the curriculum.

Students should also work problems to develop their analytical abilities. I provide over 450 exercises and suggestions for programming projects. I urge readers to take advantage of them.
