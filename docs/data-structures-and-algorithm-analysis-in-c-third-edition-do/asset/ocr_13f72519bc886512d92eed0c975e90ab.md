template <typename E> class BinNode {
public:
    virtual ~BinNode() {} // Base destructor

    // Return the node's value
    virtual E& element() = 0;

    // Set the node's value
    virtual void setElement(const E&) = 0;

    // Return the node's left child
    virtual BinNode* left() const = 0;

    // Set the node's left child
    virtual void setLeft(BinNode*) = 0;

    // Return the node's right child
    virtual BinNode* right() const = 0;

    // Set the node's right child
    virtual void setRight(BinNode*) = 0;

    // Return true if the node is a leaf, false otherwise
    virtual bool isLeaf() = 0;
};

Alternatively, we might wish to visit each node only after we its children (and its subtrees). For example, this would be necessary if we wish to return all nodes in the tree to store. We would like to delete the children of a node before deleting the node itself. But to do that requires the children's children be deleted first, and so on. This is called a postorder traversal.
