# 6. Non-Binary Trees

Many organizations are hierarchical in nature, such as the military and most businesses. Consider a company with a president and some number of vice presidents who report to the president. Each vice president has some number of subordinates, and so on. If we wanted to model this company with a data structure, it would be natural to think of the president in the root node of a tree, the vice presidents at level 1, and their subordinates at lower levels as we go down the tree. Because the number of vice presidents is likely to be more than two, the company’s organization cannot easily be represented by a binary tree. We need to use a tree whose nodes have an arbitrary number of children. Unfortunately, when we permit trees to have an arbitrary number of children, they become much harder to implement than binary trees. We consider such trees in this chapter. To distinguish them from binary trees, we use the term general tree.

Section 6.1 presents general tree terminology. Section 6.2 presents a simple solution for solving the problem of processing equivalence classes. Aside general and binary trees, there are also trees for whose internal nodes have a fixed number K where K is something other than two. Such trees are known as $K$-ary trees. Section 6.4 generalizes the properties of binary trees to $K$-ary trees. Sequential representations, useful for applications such as storing trees on disk, are covered in Section 6.5.

## 6.1 General Tree Definitions and Terminology

A tree T is a finite set of one or more nodes such that there is one designated node R, called the root of T.
