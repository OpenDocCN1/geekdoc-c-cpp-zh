# Sec. 11.4 Shortest-Paths Problems

```
// Compute shortest path distances from "s"
// Return these distances in "D"
void Dijkstra(Graph* G, int* D, int s) {
    int i, v, w;
    for (i=0; i<G->n(); i++) { // Process the vertices
        v = minVertex(G, D); return; // Unreachable vertices
        G->setMark(v, VISITED);
        for (w=G->first(v); w<G->n(); w = G->next(v, w)) {
            if (D[w] > D[v] + G->weight(v, w))
                D[w] = D[v] + G->weight(v, w);
        }
    }
}
```

call X. The shortest path from S to X must have its next-to-vertex in S. Thus,

$d(S,X) = min(d(S,U) + w(U,X))\nU/S$

In other words, the shortest path from S to X is the minimum over all paths that go from S to U to X, where U is some vertex in S.

This is solved by Dijkstra's algorithm. It works by maintaining a distance D(X) for all vertices in V. The elements of D are initialized to INFINITE. Vertices are processed in order of distance from S. When a vertex V is processed, D(X) is updated for every neighbor X of V. Figure 11.17 shows an implementation for Dijkstra's algorithm. At the end, array D will contain the distance values.

There are two reasonable solutions to the key issue of finding the unvisited vertex with minimum value during each pass through the loop. The first method is to scan the list of |V| vertices searching for the minimum value, as:

```
int minVertex(Graph* G, int* D) { // Find min vertex
    int i, v = -1;
    // Initialize v to some unvisited vertex
    for (i=0; i<G->n(); i++))
        if (G->getMark(i) == UNVISITED) { v = i; break; }
    for (i++; i<G->n(); i++) // Now find smallest D value
        if (G->getMark(i) == UNVISITED) && (D[i] < D[v])
            v = i;
    return v;
}
```

Because this is done |V| times, and each edge requires a constant-update to D, the total cost for this approach is $\Theta(|V|^2 + |E|) = \Theta(|V|^2)$, because E is in O(|V|^2).

The second method is to store unvisited vertices in a min-heap ordered by distance values. The next-closest vertex can be found in the heap in $\Theta(\log |V|)$
