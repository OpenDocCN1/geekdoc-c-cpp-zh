# 8.8 Projects

8.18 Assume that working memory size is 256KB broken into blocks of 8192 bytes (there is also additional space available for I/O buffers, particular variables). What is the expected size for the largest file that can be merged using replacement selection by two passes of multiway merge? Explain how you got your answer.

8.19 Prove or disprove the following proposition: Given space in memory for heap M records, replacement selection will completely sort a file if no record in the file is preceded by M or more of greater value.

8.20 Imagine a database containing ten million records, with each record being 100 bytes. Provide an estimate of the time it would take (in seconds) to sort the database on a typical desktop or laptop computer.

8.21 Assume that a company has a computer configuration satisfactory for processing its monthly payroll. Assume that the bottleneck in payroll processing is a sorting operation on all of the employee records, and that an external sorting algorithm is used. The company's payroll program is so good that it to hire out its services to payroll processing for other companies. The president has an offer from a second company with 10 times as many employees. She realizes that her computer is not up to the job of sorting 100 times as many records in an acceptable amount of time. Describe what impact of the following modifications to the computing system is likely to have in terms of reducing the time required to process the larger payroll database.

+   (a) A factor of two speedup to the CPU.
(b) A factor of two speedup to disk I/O time.
(c) A factor of two speedup to main memory access time.
(d) A factor of two increase to maintain memory size.

8.22 How can the external sorting algorithm described in this chapter be extended to handle variable-length records?
