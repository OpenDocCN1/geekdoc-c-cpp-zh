(a) The value 19 is inserted to the 2-3 tree of Figure 10.9. This causes the node containing 20 and 21 to split, promoting 20. (b) In turn causes the internal node containing 23 and 30 to split, promoting 23. (c) Finally, the tree root nodes, promoting 23 to become the left record in the new root. The result is that the tree becomes one higher.

The 2-3 tree insert and delete routines do not add new nodes at the bottom of the tree. Instead, they cause leaf nodes to split or merge, causing a ripple effect moving up to the root. If necessary the root will split, causing a new root to be created and making the tree one level deeper. if the last two children of the root merge, the root is removed and the tree will lose a level. In either case, all leaf nodes are always at the same level. When all leaf nodes are at the same level, we say that a tree is **height balanced**. Because the 2-3 tree is height balanced, and every internal node has at least two children, we know that the maximum depth of the tree is $\log n$. Thus, 2-3 tree insert, and delete operations require $\Theta(\log n)$ time.
