**后缀树**（suffix tree）是一种包含给定字符串所有后缀字符串的 PAT，并将每个后缀与完整字符串相关联。后缀树的优势是它允许使用“通配符”进行字符串搜索。例如，查询键 "TH*" 意味着找到所有前两个字符为 "TH" 的字符串。这可以通过普通的 trie 轻松实现。在 trie 中搜索 "*TH" 效率并不高，但在后缀树中效率很高。
