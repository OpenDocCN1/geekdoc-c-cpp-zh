## 2.2 Miscellaneous Notation

Units of measure: I will use the following notation for units of measure. “B” will be used for bytes, “KB” for kilobytes (2¹⁰ = 1024 bytes), “MB” for megabytes (2²⁰ bytes), “GB” for gigabytes (2³⁰ bytes), and “ms” for milliseconds (a millisecond is 1/¹⁰ of a second). Spaces are not placed between the number and the unit abbreviation when power of two is intended. Thus a disk drive of 25 gigabytes (where a gigabyte is identified as 2³⁰ bytes) will be written as “25GB.” Spaces are used when a decimal value is intended. An amount of 2000 bits would be written as “2 Kb” “2Kb” represents 2048 bits. 2000 milliseconds is written as 20 ms. Note that in this large amount storage are nearly measured in powers of two and times in powers of ten.

Functional notation: The functional notation, n! for n an integer greater than 0, is the product of the integers between 1 and n, inclusive. Thus, 5! = 1 · 2 · 3 · 4 · 5 = 120. As a special case, 0! = 1. The functional grows as n becomes larger. Computing the factorial directly is a time-consuming process; it can be useful to use an equation that provides a good approximation. Stirling’s approximation states that n! ≈√π(n/e)ⁿ where e ≈ 2.71828 (e is the base for the system of natural logarithms). Thus we see that n! grows faster than n (because n/e < n), it grows faster than cⁿ for any positive integer c.

Permutations: A permutation of a sequence S is the members of S arranged in some order. For example, a permutation of the integers through n would be those values arranged in some order. If the sequence contains n distinct members, then there are n! permutations for the sequence. This is because there are n choices for the first member in the permutation; for each choice of n-1 choices for the second member, and so on. Sometimes one would like to obtain a random permutation for a sequence, which is, one of n! possible permutations is selected in such that each permutation has equal probability of being selected. A simple C++ function for generating a random mutation is as follows. Here, the n values of the sequence are stored in 0

**Boolean variables:** A Boolean variable is a variable (of type **bool in C++) that takes one of the two values **true** and **false**. These two values are often associated with the values 1 and 0, respectively, although there is no reason this needs to be the case. It is poor programming practice to rely on the correspondence between 0 and **false**, because these are logically distinct objects of different types.

**Logic Notation:** We will occasionally use the notation of symbolic or Boolean logic. $A \Rightarrow B$ means "A implies B" or "If A then B". $A \Leftrightarrow B$ means "A if and only if B is equivalent to B". $A \lor B$ means "A or B" (useful in the context of symbolic logic or when performing a Boolean operation). $A \wedge B$ means "A and B". $A{\sim}$ and $\neg A$ means "not A" or the definition of N where A is a Boolean variable.

**Floor and ceiling:** The floor of $x$ (written $[x]$) takes real value $x$ and returns the greatest integer $\leq x$. For example, $[3.4] = 3$ as does $[3.0]$, while $[-3.4] = -4$ and $[-3.0] = -3$. The ceiling of $x$ (written $\lceil x\rceil$) takes real value $x$ and returns the least integer $\geq x$. For example, $\lceil3.4\rceil = 4$, as does $\lceil4.0]$, while $\lceil-3.4\rceil = -3$.

**Modulus operator:** The **mod** function returns the remainder of integer division. We often write $n \bmod m$ in mathematical expressions, the syntax for the C++ modulus operator is `% m$. $n \bmod m$ is the integer $r$ such that $n = qm + r$ for an integer, and $|r| < |m|$. Therefore, the result of $n \bmod m$ must be between $0$ and $m-1$ when $n$ and $m$ are positive integers. For example, $5 \bmod 2 = 1$; $25 \bmod 3 = 1$; $5 \bmod 7 = 5$;

There is more than one way to assign values to $q$ and $r$, depending on how integer division is defined. The most common mathematical definition computes the mod function as $n \bmod m = n - m[n/m]$. In this case, $-3 \bmod 5 = 2$. However, Java and C++ compilers typically use the processor’s machine instruction for computing integer arithmetic. This is possible by truncating the fraction result, meaning $n \bmod m = n - m(\text{trunc}(n/m))$. Under this definition, $-3 \bmod 5 = -3$.

A logarithm of $y$ is the power to which $b$ is raised, denoted as $b^x = y$. If $b^x = y$, then $x = \log_b y$. This is the logarithm of $y$ with base $b$, written as $\log_b y$. If the base is 10, it is written as $\log y$. If the base is 2, it is written as $\log_2 y$.

Common properties of logarithms:
- $\log_b(xy) = \log_b x + \log_b y$
- $\log_b(x/y) = \log_b x - \log_b y$
- $\log_b(x^k) = k \log_b x$
- $\log_b b = 1$
- $\log_b 1 = 0$

**Example 2.6:** What is the value of $\log_2 8$? Since $2^3 = 8$, $\log_2 8 = 3$.

**Example 2.7:** What is the value of $\log_{10} 100$? Since $10^2 = 100$, $\log_{10} 100 = 2$.

**Example 2.8:** What is the value of $\log_2 100$? Since $2^6 = 64$ and $2^7 = 128$, $\log_2 100$ is between 6 and 7. Using a calculator, $\log_2 100 \approx 6.64$.

**Example 2.9:** The natural logarithm has base $e$, which is approximately 2.71828. It is written as $\ln x$ or $\log x$.

## 2.4 Summations and Recurrences

Most programs construct loops. When analyzing runtime costs for programs with loops, we need to add up the costs for each time the loop is executed. This is an example of a summation. Summations are simply the sum of costs for some function applied to a range of parameter values. Summations are typically written with the symbol $\Sigma$ notation:

$\sum_{i=1}^n f(i)$

This notation indicates that we are summing the value of $f(i)$ over some range of (integer) values. The parameter to the expression and its initial value are indicated below the $\Sigma$ symbol. Here, the notation $i=1$ indicates that the expression is $i$ and it begins with the value 1. At the top of the $\Sigma$ is the maximum value for the parameter $i$. Thus, this means to sum the values of $f(i)$ as $i$ ranges across the integers from 1 through $n$.
