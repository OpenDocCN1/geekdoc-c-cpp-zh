**算法的增长率**是指算法随输入规模增大而增长的速率。图 3.1 显示了六个方程的图表，每个方程都旨在描述特定程序或算法的运行时间。图中展示了典型算法的各种增长率。标记为 10n 和 20n 的两个方程由直线绘制。增长 率为 $cn$（其中 $c$ 为任意正常数）通常被称为**线性**增长或线性运行时间。这意味着对于给定的 $n$，算法的运行时间按相同的比例增长。$n$ 值的翻倍意味着运行时间也大约增加一倍。方程中包含 $n^2$ 因子的高阶项的算法具有**二次**增长。在图 3.1 中，标记为 $2n$ 的线代表二次增长率。标记为 $2^n$ 的线代表**指数级**增长率。标记为 $n$ 的线也是指数级增长的。

正如图 3.1 所示，运行时间为 $T(n) = 10n$ 的算法与 $T(n) = 2n^2$ 的算法之间的差异随 $n$ 的增大而变得极其巨大。当 $n > 5$ 时，运行时间 $T(n) = 2n^2$ 的算法已经慢得多。这是因为其中一个方程的 10 具有更大的常数因子，这只是移动了两条曲线交叉的点。当 $n > 10$ 时，$T(n) = 20n$ 的算法比 $T(n) = 5n$ 的算法慢。$n^2$ 的增长速度虽然比 $T(n) = 10n$ 和 $T(n) = 20n$ 都快，但远没有 $T(n) = 2n^2$ 方程那么快。对于常数 $a, b > 1$，$n^a$ 的增长比 $n^b$ 或 $n^c$ 都快。最后，成本为 $T(n) = cn^2$ 或 $T(n) = n^n$ 的算法即使对于 $n$ 取值适中也是极其昂贵的。注意，对于常数 $a, b \geq 1$，$a^n$ 的增长比 $b^n$ 快。
