Unfortunately, there is no convenient access to the node preceding the one pointed to by curr.

There is an easy solution to this problem. If we set curr to point directly to the preceding element, there is no difficulty in adding a new element after curr. Figure 4.6 shows how the list look when pointer variable curr is set to point to the node preceding the physical current node. See Exercise 4.5 for further discussion of why making curr point directly to the current element fails.

We encounter a number of potential special cases when the list is empty, or when the current position is at an end of list. In particular, when the list is empty we have no element for head, tail, and curr to point to. Implementing special cases for insert and remove increases code complexity, making it harder to understand, thus increases the chance of introducing a programming bug.

These special cases can be eliminated by implementing linked lists with an additional header node as the first node of the list. This header node is a link node like other, but its value is ignored and it is not considered to be an actual element of the list. The header node saves coding effort because we no longer need to consider special cases for empty lists or when the current position is at one end of the list. The cost of this simplification is the space for the header node. However, there are space savings for smaller code size, as statements to handle the special cases are omitted. In practice, this reduction in code typically saves more space than required for the header node, depending on the number of lists created. Implementations for member functions of the **list** class are straightforward. However, **insert** and **remove** should be studied carefully.

Inserting a new node is a three-step process. First, the new node is created and the new node is stored into it. Second, the **next** field of the new list node is assigned to point to the current node (the **after** the node that **curr** points to). Third, the **next** field of node pointed to by **curr** is assigned to the newly inserted node. The following line in the **insert** method of Figure 4.8 does all of these steps.

```
curr->next = new Link<E>(it, curr->next);
```

Operator creates the new link node and calls the **Link** class constructor, which takes two parameters. The first is the element. The second is the value to be placed in the list's **next** field, in this case "curr->next". Figure 4.9 illustrates this three-step process. The new node is added, **tail** is pushed forward if the new element was added to the end of the list. Insertion requires $\Theta(1)$.

Removing a node from the linked list requires only that the appropriate pointer be redirected around the node to be deleted. The following lines from the **remove** method of Figure 4.8 do precisely.

```
Link<E>* lmp = curr->next; // Remember link node
curr->next = curr->next->next; // Remove from list
```

We are careful not to "lose" the memory for the deleted node. So, temporary **lmp** is first assigned to point to the node being removed. A call to **delete** is used to return the old node to free storage. Figure 4.10 illustrates the **remove** method. Assuming that the free **delete** operator takes constant time, removing an element requires $\Theta(1)$.

Method next moves **curr** one position toward the tail of the list, which takes $\Theta(1)$ time. Method **prev** moves **curr** one position toward the head of the list. In a singly linked list, there is no pointer to the previous node. Thus, the only alternative is to march down the list from the beginning until we reach the current node (always sure to remember the node before it, because that is what we really need). This takes $\Theta(n)$ time in the average and worst cases. Implementation of method **moveToPos** is similar in finding the $i$-th position requires matching down $i$ positions from the head of the list, taking $\Theta(i)$.

Implementations for the remaining operations require $\Theta(1)$ time.

```
// Linked list implementation
template <typename E> class LList: public List<E> {
private:
Link<E>* head;      // Pointer to header
Link<E>* tail;      // Pointer to last element
Link<E>* curr;      // Access to current element
int cnt;             // Size of list

void init() {           // Initialization helper method
    curr = head = new Link<E>;
    cnt = 0;
}

void removeall() { // Reset link nodes to free store
    while(head != NULL) {
        curr = head;
        head = head->next;
        delete curr;
    }

public:
    LList(int size=defaultSize) { init(); } // Constructor
    ~LList() { removeall(); } // Destructor
    void print() const;                   // Print list contents
    void clear() { removeall(); init(); } // Clear list

// Insert "it" at current position
void insert(const E& it) {
    curr->next = new Link<E>(it, curr->next);
    if (tail == curr) tail = curr->next; // New tail
    cnt++;
}

void append(const E& it) { // Append "it" to list
    tail->next = new Link<E>(it, NULL);
    cnt++;
}

// Remove and return current element
E remove() {
    Assert(curr != NULL, "No element");
    E it = curr->next->element; 
    Link<E>* lmp = curr->next; // Remember link node
    if (tail == curr) tail = curr->next; // New tail
    curr->next = curr->next->next; // Remove from list
    delete lmp; // Reclaim space
    cnt--; // Decrement the count
    return it;
}
```

```
void moveToStart() // Place curr at start

// Move one step left; no change if at front
void prev() {
  if (curr == head) return; // No previous element
  Link<E>* temp = head;
  // March down until we find the previous element
  while (temp->next!=curr) temp=temp->next;
  curr = temp;
}

// Move one step right; no change if at end
void next() {
  if (curr != tail) curr = curr->next; 
}

int length() const {  int cnt; return cnt; } // Return length

// Return the position of the current element
int currPos() const {
  Link<E>* temp = head;
  int i;
  for(i=0; curr != temp; i++)
    temp = temp->next;
  return i;
}

// Move down to "pos" position
void moveToPos(int pos) {
  Assert((pos>=0) && (pos<cnt), "Position of range");
  curr = head;
  for(int i=0; i<pos; i++) curr = curr->next;
}

const E& getValue() const { // Return current element
  Assert(curr->next != NULL, "No value");
  return curr->next->element;
};
```
