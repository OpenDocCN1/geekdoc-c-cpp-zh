// Find the record that matches a given key value
template <typename key, typename E>
E TTTreeNode<key, E>* root, key k) const {
    if (root == NULL) return NULL; // value not found
    if (k < root->lkey) return root->lval;
    if (k > root->rkey) return root->rval;
    if (k < root->lkey) // Go left
        return findhelp(root->left, k); // EMPTYKEY
    else if (root->center) // 2 child node
        return findhelp(root->center, k); // Go center
    else if (k < root->rkey) // Go center
        return findhelp(root->center, k);
    else return findhelp(root->right, k); // Go right
}

Insertion into a 2-3 tree is similar to insertion into a BST to the extent that the new record is placed in the appropriate leaf node. Unlike BST insertion, a new node is created to hold the record inserted, that is, the 2-3 tree does not grow downward. The first step is to find the leaf node that would contain the record if it were in the tree. If this leaf node contains only one value, then the new record can be added to that node with no modification to the tree, as illustrated in Figure 10.12. In this example, a record with key value 14 is inserted. Searching from the root, we come to the leaf node that stores 15. We add 14 as the left value (pushing the record 15 to the rightmost position).

If we insert the new record into a leaf node L that already contains two records, then more space must be created. Consider the two records of L and the record to be inserted without concern for which two were already in L and which is the new record. The first step is to split L into two nodes.
