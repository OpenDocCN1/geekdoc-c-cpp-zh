```
// Array-based stack implementation
template <typename E> class AStack: public Stack<E> {
private:
    int maxSize;                // Maximum size of stack
    int top;                    // Index for top element
    E *listArray;               // Array holding stack elements

public:
    AStack(int size =defaultSize) // Constructor
        size = size; top = 0; listArray = new E[size]; }
    ~AStack() { delete [] listArray; } // Destructor
    void clear() { top = 0; } // Reinitialize
    void push(const E it) { // Put "it" on stack
        Assert(top != maxSize, "Stack is full");
        listArray[top++] = it;
    }
E pop() { // Return top element
        Assert(top != 0, "Stack is empty");
        return listArray[--top];
    }
const E& top() const { // Return top
        Assert(top != 0, "Stack is empty");
        return listArray[top-1];
    }
    int length() const { return top; } // Return length
}
```

**Figure 4.18** Array-based stack implementation.

The array-based stack implementation is essentially a simplified version of the array-based list. The only important design decision to make is which end of the array should represent the top of the stack. One choice is to make the top be position 0 in the array. In terms of list functions, **insert** and **remove** operations would be the element on position 0. This implementation is inefficient, because every **push** or **pop** operation would shift all elements currently in the stack one position in the array for cost of $\Theta(n)$ if there are $n$ elements. The other choice is to have the top element at position $n-1$ when there are $n$ elements in the stack. In other words, as elements are pushed onto the stack, they are appended to the tail of the list. Method **pop** removes the tail element. In this case, the cost for each **push** or **pop** operation is only $\Theta(1)$.
