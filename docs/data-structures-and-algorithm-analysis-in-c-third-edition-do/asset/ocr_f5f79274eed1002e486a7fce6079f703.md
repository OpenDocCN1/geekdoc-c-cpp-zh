Our final example uses amortized analysis to prove a relationship between
cost of the move-to-front self-organizing list heuristic from Section 9.2 and the cost
for the optimal ordering of the list.

Recall that, for a series of searches, the minimum cost for a static
list results when the list is sorted by frequency of access to its records. This is
t optimal ordering for the records if we never allow the positions of records to
change, because the most-frequently accessed record is first (and thus has least
cost), because the next most frequently accessed record, and so on.
