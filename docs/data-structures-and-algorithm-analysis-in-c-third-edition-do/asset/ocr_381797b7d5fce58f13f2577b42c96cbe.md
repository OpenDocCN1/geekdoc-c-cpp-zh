# 11.4.1 Single-Source Shortest Paths

This section presents an algorithm to solve the **single-source shortest-paths** problem. Given Vertex S in Graph G, find a shortest path from S to every other vertex in **G**. We might want only the shortest path between two vertices, *S* and *T*. However in the worst case, finding the shortest path from *S* to *T*, we might find the shortest paths from *S* to every other vertex as well. So there is no better algorithm (in the worst case) for finding the shortest path to a single vertex to find shortest paths to all vertices. The algorithm described here will only compute the distance to every vertex, rather than recording the actual path. Recording the path requires modifications to the algorithm that the single-source shortest-paths goal is left as an exercise.

Computer networks provide an application for the single-source shortest-paths goal. The goal is to find the cheapest way for one computer to broadcast a message to all other computers on the network. The network can be modeled by a graph with edge weights indicating time or cost to send a message to a neighboring computer.

For un graphs (whenever all edges have the same cost), the single-source paths can be found using a simple breadth-first search. When weights are added, BFS will not give the correct answer.

One approach to solving this problem when the edges having differing weights might be to process the vertices in a fixed order. Label the vertices $v_0$ to $v_{n-1}$, with $S = v_0$. When processing Vertex $v_1$, we take the edge connecting $v_0$ and $v_1$. processing $v_2$, we consider the shortest distance from $v_0$ to $v_2$ and compare that to the shortest distance from $v_1$ to $v_2$. When processing Vertex $v_i$, we consider the shortest path for Vertices $v_i$ through $v_{i-1}$ that have already been processed. Unfortunately, the true shortest path to $v_i$ might go through $v_j$ for $j > i$. Such a path will not be considered by this algorithm. However, the problem would occur if we process the vertices in order of distance from $S$.
