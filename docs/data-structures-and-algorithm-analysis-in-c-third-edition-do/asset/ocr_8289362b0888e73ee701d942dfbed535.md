# Sec. 4.1 Lists

```
// Singly linked node with freelist support
template <typename E> class Link {
private:
    static Link<E>* freelist; // Reference to freelist head
public:
    E element; // Value for this node
    Link* next; // Point to next node in list

    Constructors
    Link(E element, Link* next=NULL)
        { element = element; next = next; }
    Link(Link* next=NULL) { next = next; }

    void* operator new(size_t) { // Overloaded new operator
        if (freelist == NULL) return ::newLink; // Create space
        Link<E>* temp = freelist; // Can take from freelist
        freelist = freelist->next;
        return temp;
    }

    // Overloaded delete operator
    void delete(void* ptr) {
        ((Link<E>*)ptr)->next = freelist; // Put on freelist
        freelist = (Link<E>*)ptr;
    };
```

An alternative is to allocate memory nodes in a single call to the system version of new, anticipating that if the freelist is exhausted, more nodes will be needed. It is faster to make one call to new for 100 link nodes, then load all 100 onto the freelist at once, rather than to make 100 separate calls to new. ptr = ::newLink[100];
