```
// Find the record with the given coordinates
bool findhelp(BinNode<E>* root, int* coord,
E& e, int discrim) const {
// Member "coord" of a node is an integer array storing
// the node's coordinates
if (root == NULL) return false; // Empty tree
int* curcoord = (root->val())->coord();
if (equalCoord(curcoord, coord)) { // Found it
    e = root->val();
    return true;
}
if (curcoord[discrim] < coord[discrim])
    return findhelp(root->left(), coord, e, (discrim+1)%D);
else
    return findhelp(root->right(), coord, e, (discrim+1)%D);
}
```

Inserting a new node in the k-d tree is similar to BST insertion. The k-d search procedure is followed until a NULL pointer is found, indicating the proper place to insert the new node.

Deleting a node from a k-d tree is similar to deleting from a BST, slightly harder. With a BST, the first step is to find the node (call it N) to be deleted. It is then necessary to find a descendant of N which can be used to replace N in the tree. If N has no children, N is replaced with a NULL pointer. Note that if N has one child that has children, we cannot simply assign N's parent to N's child as would be in BST. To do so would change the level of all nodes in the subtree, and the discriminator for a search would change. The result is that the subtree would no longer be a k-d tree because a node's child might violate the BST property for that discriminator.

Similar to BST deletion, the record stored in N should be replaced either by the record in N's right subtree with the least value of N's discriminator, or by the record in N's left subtree with the greatest value for this discriminator. Assume that N is at an odd level and therefore y is the discriminator. N could then be replaced by the record in its right subtree with the y value (call it Ymin). The problem is that Ymin is not necessarily the leftmost node, as it would be in the BST. A modified search procedure to find the y value in the left subtree must be used to find it instead. The implementation for findmin is shown in Figure 13.12. A recursive call to the delete routine then removes Ymin from the tree. Finally, Ymin's record is substituted for the node N.

Note that we can replace the node to be deleted with the least-valued node from the right subtree only if the right subtree exists.
