# Making Plans

When the audience chooses hunger as Arthur’s problem, Tale-Spin generates the conceptual dependency expression “Arthur knows that he is hungry.” This is then asserted. To understand what this means, it is helpful to look at figure 5.1, which illustrates the control structure of Tale-Spin’s simulation.
