## 函数基础

### 函数的组成部分

- **返回值类型**：即`return type`；可以是任何合法的数据类型，例如`int`、`char`、指针……如果函数不返回任何值，则返回值类型为`void`。
- **函数名**：由字母和数字组成的序列中首字符必须是字母（下划线视作字母）。函数名应具有含义。例如`result()`。
- **参数列表**：传递给函数的参数需用逗号分隔，每个参数必须指明其数据类型和名称。

### 3.1、没有参数的 UDF

这种用户自定义函数的返回值为`void`，并且在调用时不传入形参表。
