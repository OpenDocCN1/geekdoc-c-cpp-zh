The letter f is most likely to be misrecognized for the letter k, but only when flanked by other letters. The letter i is likely to be misrecognized for l and j, but only when in isolation. The letter j is more likely to be misrecognized when flanked by other letters, and is misrecognized for f and t as well as for the more surprising g and h. The letter l is more likely to be misrecognized for other ascending letters h and k when flanked by other letters. The letter t is strongly misrecognized for the letter k when flanked by other letters. The fact that narrow letters are often misrecognized as wider letters when flanked is a very interesting finding. It shows that neighboring letters interact with each other and that those interactions need to be considered in more detail.
