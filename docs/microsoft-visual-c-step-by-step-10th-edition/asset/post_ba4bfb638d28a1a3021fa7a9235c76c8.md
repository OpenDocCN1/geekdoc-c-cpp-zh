# Enable an object to notify a binding of a change in a data value

Implement the INotifyPropertyChanged interface in the class that defines the object and raise the PropertyChanged event each time a property value changes. For example:

Click here to view code image

```csharp
class Customer : INotifyPropertyChanged
{
    ...
    public event PropertyChangedEventHandler PropertyChanged;
    protected virtual void OnPropertyChanged(string propertyName)
    {
        if (PropertyChanged is not null)
        {
            PropertyChanged(this, new PropertyChangedEventArgs(propertyName));
        }
    }
}
```

# Retrieving data from a database

So far, the data you’ve used has confined to a simple collection embedded in the ViewModel. In the real world, the data presented by the app is more likely to be stored in a relational database. UWP apps cannot directly access relational database (although some third-party solutions are available). This might sound like a severe restriction, but there are sensible reasons for this. Primarily, it eliminates dependencies that UWP app might have on external resources, making the app a standalone item that can be easily packaged and downloaded from the Windows Store. To address this scenario, you can use a web service.

Web services can implement a variety of functions, but one common scenario is to provide an interface with which an app can connect to a remote source. A web service can be located anywhere—from the computer the app is running on to a web server on a different continent. As long as you can connect to the web service, you can use it to provide access to your information.

Microsoft Visual Studio provides templates and tools with which you can quickly and easily build a web service. The simplest strategy is to base the web service on an entity model generated by using the Entity Framework, as shown in the following diagram. The Entity Framework is a powerful technology with which you can connect to relational database. It can reduce the amount of code needed to add data access capabilities to an app.
