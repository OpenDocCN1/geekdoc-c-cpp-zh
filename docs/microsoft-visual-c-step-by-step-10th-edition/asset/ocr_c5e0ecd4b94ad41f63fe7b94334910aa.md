In this example, the application declares that it needs to:

+   * Receive incoming data from the Internet but cannot act as a server and has no local network access.
* Access GPS information that provides information about the location of the device.
* Read and write files in the user’s Pictures folder.

The user is aware of these requirements and in all cases can disable the settings after installing the app. The application must detect when this has occurred and be prepared to fall back to an alternative solution or disable the functionality that requires these features.
