> // TODO: comments
Developers frequently add // TODO comments as a reminder to revisit a piece of code. These comments often contain a description of the work to be performed, such as // TODO: Implement the doWork method.
Visual Studio recognizes this form of comment, and you can quickly locate them in an application by using the Task List window. To display this window, on the View menu, select Task List. The Task List window opens below the Code and Text Editor window by default. All the TODO comments will be listed. You can then double-click any of these comments to go directly to the corresponding code, which will be displayed in the Code and Text Editor window.
