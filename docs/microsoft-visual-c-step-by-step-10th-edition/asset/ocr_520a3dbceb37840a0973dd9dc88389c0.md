i++; /* incrementing i has no effect on copyi; i now contains 43, but copyi still contains 42 */

The effect of declaring a variable c as a class type, such as Circle, is very different. When you declare c as a Circle, c can refer to a Circle object; the actual value held by c is the address of a Circle object in memory. If you declare an additional named variable ref (also as a Circle object) and assign c to ref, ref will have a copy of the same address as c. In other words, there's only one Circle object, and both ref and c now refer to it.
Here's an example in code:

```
var c = new Circle(42);
Circle refc = c;
```

The following illustration shows both examples. At the sign (@) in the Circle objects represents a reference holding an address in memory.

| int i; |
| i = 42; |
|
| int copyi; |
| copyi = 1; |

| circle c |
| c = new Circle(42); |
|
| circle refc; |
| refc = c; |
| 42 |

This difference is very important. It means that the behavior of method parameters depends on whether they are value types or reference types. You'll explore this difference in the next exercise.
