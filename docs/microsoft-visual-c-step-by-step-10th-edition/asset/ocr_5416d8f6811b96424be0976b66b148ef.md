# # Pattern matching

C# 8.0 includes new pattern-matching capabilities. Patterns extend the decision-making capabilities of many C# statements. They can also make your code concise and readable than was previously possible.

Pattern matching uses the is operator. The easiest way to explain pattern matching for Boolean expressions is through another example. The following statement assigns the value true to the Boolean variable validPercentage if and only if the value of percent variable is greater than or equal to 0 and the value of percent is less than or equal to 100:

Click here to view code image

```
bool validPercentage;
int percent = ...;
validPercentage = (percent >= 0) && (percent <= 100);
```

Pattern matching enables you to simplify the expression to:

Click here to view code image

```
validPercentage = (percent >= 0 and <= 100);
```

The is operator works with the Boolean operator and (known as the conjunctive pattern operator) and the Boolean operator or (the disjunctive pattern operator). You cannot use && or || with is.
