```
static void doWork()
{
    int x = 591;
    for (int i = 2; i <= 10; i++)
    {
        Console.WriteLine($"{x} in base (i) is {x.ConvertToBase(i)}");
    }
}
```

This code creates an int x and sets the value to 591. (You can pick any integer value you want.) The code then uses a loop to print out the value 591 in all bases between 2 and 10.

Notice that ConvertToBase appears as an extension method in IntelliSense when you type the period (.) after the Console.WriteLine statement.
