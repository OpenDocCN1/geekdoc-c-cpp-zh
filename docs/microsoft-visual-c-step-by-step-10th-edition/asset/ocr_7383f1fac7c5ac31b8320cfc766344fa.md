# ManualResetEventSlim

The ManualResetEventSlim class provides functionality by which one or more tasks can wait for an event. A ManualResetEventSlim object can be in one of two states: signaled(true) and unsignaled(false). A task creates a ManualResetEventSlim object and specifies its initial state. Other tasks can wait for the ManualResetEventSlim object to be signaled by calling the Wait method. If the Wait method blocks the tasks, Another task can change the state of the ManualResetEventSlim object to signaled signaled by calling the Set method. This action releases all tasks waiting on the ManualResetEventSlim object, which can then resume. The Reset method changes the state of the ManualResetEventSlim object back to unsignaled.

# SemaphoreSlim

You can use the SemaphoreSlim class to control access to a pool of resources. A SemaphoreSlim object has an initial value (non-negative) and an optional maximum value. Typically, the initial value of a SemaphoreSlim object is the number of resources in the pool. Tasks accessing the resources in the pool first call the Wait method. This method attempts to decrement the value of SemaphoreSlim object. If the result is nonzero, the thread is allowed to continue and can take a resource from the pool. When it has finished, the task should call the Release method on the SemaphoreSlim object. This action increments the value of the SemaphoreSlim.
