+   20. In Solution Explorer, select the appsettings.json file to open it in the Code and Text Editor window.

+   21. Add the connection string shown in the following code in bold to the file. This string contains the parameters needed to connect to the AdventureWorks database. In this string, replace the server name csharpstepbyst2022 with the name of the server you set up when you created the database in Azure. Replace JohnSharp with your username, and YourPassword with your password.

Click here to view code image

```
{
  "ConnectionStrings": {
    "AdventureWorksDB": "Server=tcp:csharpstepbyst2022,database.windows.net,1433;Initial Catalog=AdventureWorks;Persist Security Info=False;User ID=JohnSharp;Password=YourPassword;\nMultipleActiveResultSets=False;Encrypt=True;TrustServerCertificate=False;Timeout=30",
    "Logging": {
      "LogLevel": "Information",
      "Microsoft": "Warning",
      "Microsoft.Hosting.Lifetime": "Information"
    }
  },
  "AllowedHosts": "*"
}
```
