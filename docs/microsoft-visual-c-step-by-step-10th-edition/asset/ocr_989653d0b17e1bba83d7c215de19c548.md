The events that the various GUI controls generate always follow the same pattern. Events are of a delegate whose signature has a void return type and two arguments. The first argument is always the sender (source) of the event, and the second argument is always an EventArgs (or a class derived from EventArgs).

With the sender, you can use a single method for multiple events. The delegated method can examine the sender and respond accordingly. For example, you can use the same method to subscribe to the Click event for two buttons. When you add the same method to two different events.
