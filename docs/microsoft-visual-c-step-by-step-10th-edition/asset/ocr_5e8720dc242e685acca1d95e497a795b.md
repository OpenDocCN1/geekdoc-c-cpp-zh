+   - A params array must be the last parameter. (This means you can have only one params array per method.) Consider this example:


+   - A non-params method always takes priority over a params method. This means you can still create an overloaded version of a method for the common cases, such as in the following example:

```
public static int Min(int leftHandSide, int rightHandSide)
...
public static int Min(params int[] paramList)
```
