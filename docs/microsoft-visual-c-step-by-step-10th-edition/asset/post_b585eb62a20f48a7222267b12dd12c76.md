# Searching for data in the Customers app

The Customers app enables you to browse through records, but sometimes you require a bit more refinement: the ability to find a specific customer or set of customers. To address this, you'll implement Query By Forms (QBF) features. Using QBF, you enter search criteria into the fields on the page. When the user finishes entering the search criteria, the application can call the api/customers/find endpoint to retrieve a list of matching customers you can browse.

Initially, the app is used to browse data; I'll call this browse mode. However, QBF requires you to put the app into another mode, which I'll call search mode. In this mode, the page is cleared, and the user is expected to enter the search criteria. For the example, the user may enter a name into the FirstName field on the page.
