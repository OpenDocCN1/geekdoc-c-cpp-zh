pixelStream.Write(data, 0, data.Length);
...

Unless you've reduced the value of the pixelWidth and pixel fields to save memory, the value of data written to the buffer is just over 570 MB (15,000 * 10,000 * 4 bytes), so this Write operation can take a few seconds. To improve response time, you can perform this operation asynchronously using the WriteAsync method:

```
await pixelStream.WriteAsync(data, 0, data.Length);
```

In summary, when you build applications for Windows, you should seek to exploit asynchronicity wherever possible.
