The ProgressRing controls the rotating ring of activity that you may have seen when an application is busy. This control displays to the user that there is activity—in other words, the application doesn't freeze. The control is only active when the IsBusy property of the ViewModel is true. Setting the Canvas.ZIndex property to 1 ensures that the progress ring appears in front of all other controls on the page when it's active.
