# Quick reference

| To | Do this |
|---| Create an entity model by using the Entity Framework | Add a new class to your project and define properties for each column in the database. Annotate the column with the Table attribute, and identify the column that acts as the primary key with the Key attribute. Create a DbContext class that the app can use to connect the model to a database. |
| Create a REST web service that provides remote access to a database through an entity model | Create an Azure API App using the ASP.NET Core application template. Run the Add Scaffold and select API Controller With Actions, Using Entity Framework. Specify the name of the appropriate entity class from the entity model as the model class, and the data context class for the entity model as the data context class. |
| Deploy a REST web service to the cloud as an Azure app | In Visual Studio, connect to your Azure subscription. Then use the Publish wizard to publish your web service as an Azure App Service. Specify an appropriate service plan that will support the volume of traffic that your web service expects to handle. |
| Consume a REST web service published as Azure API app in a UWP application | Create an HttpClient object in the UWP application. Connect the HttpClient to the URL of the web service. example:
