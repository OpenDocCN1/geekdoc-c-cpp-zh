# Contravariant interfaces

Contravariance follows a similar principle to covariance that it works in the opposite direction. That is, it enables you to use a generic interface to reference an object of type B through a reference to type A as long as type B derives from type A. This sounds complicated, so it's worth looking at an example from the .NET class library.

The System.Collections.Generic namespace in .NET provides an interface called IComparer, which looks like this:

Click here to view code image

```
public interface IComparer<in T>
{
    int Compare(T x, T y);
}
```

A class that implements this interface must define the Compare method, which is used to compare two objects of the type specified by the T parameter. The Compare method is expected to return an integer value: 0 if x and y have the same value, negative if x is less than y, and positive if x is greater than y.
