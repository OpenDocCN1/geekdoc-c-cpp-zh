The Button class automatically raises the Click event when you select the button on the screen. This arrangement makes it easy to create a delegate for a chosen method and attach that delegate to the required event.

The following example shows the code for the UWP form that contains a button named okay, and the code to connect the Click event of the okay button to the okayClick method:
