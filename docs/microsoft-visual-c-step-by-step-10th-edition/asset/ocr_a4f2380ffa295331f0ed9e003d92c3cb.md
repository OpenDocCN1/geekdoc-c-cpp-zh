The REST model relies on the app that accesses the data to send the appropriate HTTP request to the data. For example, the simple request shown previously should send an HTTP GET request to the web service. HTTP supports other verbs as well as POST, PUT, and DELETE, which you can use to create, modify, and remove resources, respectively. Writing the code to generate the appropriate HTTP requests and parsing the responses returned by a REST web service all sounds quite complicated. Fortunately, the ASP.NET Core web API provides libraries that can handle much of this complexity for you.
