Surprisingly, the message that appears still reports the status of each task RanToCompletion, even though the graph appears with holes. This occurs because you sent a cancellation request to each task by using the cancellation token, the methods they were running simply returned. The .NET runtime doesn't know whether the tasks were actually canceled or whether they were allowed to run to completion, and it just ignores the cancellation requests.
