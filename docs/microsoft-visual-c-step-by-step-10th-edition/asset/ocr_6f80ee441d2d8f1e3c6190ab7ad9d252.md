```
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exec</OutputType>
    <TargetFramework>net6.0</TargetFramework>
  </PropertyGroup>
</Project>
```

This is an example of a C# project file. The .NET CLI tools will use this file to compile your code into an executable application. The contents of this file specify the type of executable file to create (an EXE file), and the version of .NET runtime to use to build and run the application (.NET 6.0). You'll see later in this book that you can create other types of executable files, such as dynamic-link libraries (DLLs), which can be shared by many applications.
