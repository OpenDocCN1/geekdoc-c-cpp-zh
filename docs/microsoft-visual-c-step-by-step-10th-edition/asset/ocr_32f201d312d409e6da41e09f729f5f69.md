Be aware that C# is an evolving language:

+   - In 2001, when I wrote the first edition of this book, C# introduced the syntax and semantics necessary to build apps that used Microsoft .NET Framework 1.0.
- Some enhancements were added to Visual Studio and .NET Framework 1.1 in 2003.
- In 2005, C# 2.0 emerged with support for generics and .NET Framework 2.0.
- C# 3.0 added numerous features, such as anonymous types, lambda expressions, and, most significantly, LINQ.
- C# 4.0 extended the language, with support for named arguments, optional parameters, contravariant and covariant interfaces, and integration with dynamic languages.
- C# 5.0 added full support for asynchronous processing through the `async` keyword and the `await` operator.
- C# 6.0 provided further tweaks to the language, such as expression-bodied methods, string interpolation, the `nameof` operator, exception filters, and many others.
- C# 7 and C# 8 included many additional features, such as tuples, local functions in methods, support for expression-bodied members in properties and other scenarios, pattern matching in `switch` statements, the ability to handle and throw exceptions in new ways, enhanced syntax for defining numeric literals, and a general tidying up of the way that you can define and use `out` variables.
- The latest incarnations, C# 9 and C# 10, move the bar upward, adding many syntactic features that you can use to make your code more concise and readable, as well as adding Record types.
