# To run the app using Performance Profiler

+   1. In Visual Studio, on the Debug menu, select Performance Profiler:

![](bbox=[0.163, 0.269, 0.856, 0.646])

+   2. In the Analysis Target window, select Change Target, and select Startup Project.

+   3. In the Available Tools section of the window, select CPU Usage. Then select Start to run the application using Performance Profiler.
