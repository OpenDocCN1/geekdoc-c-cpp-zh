+   - Declare a local int variable i and initialize it to 0.

+   - Write the value of i to the console using Console.WriteLine.

+   - Call Pass.Value, passing i as an argument.

+   - Write the value of i to the console again.

By running Console.WriteLine before and after the call to Pass.Value, you can see that the Pass.Value method actually modifies the value of i. The completed doWork method should look exactly like this:

```
static void doWork() {
    int i = 0;
    Console.WriteLine(i);
    Pass.Value(i);
    Console.WriteLine(i);
}
```
