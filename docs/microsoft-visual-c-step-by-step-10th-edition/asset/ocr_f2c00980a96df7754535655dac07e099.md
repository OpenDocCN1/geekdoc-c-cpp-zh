```
int *pi;
```

Although the variable pi is declared as a pointer, it does not actually point anywhere until you initialize it. For example, to use pi to point to the integer variable i, you can use the following statements and the address-of operator (&), which returns the address of a variable:

```
int *pi;
int i = 99;
...
```

You can access and modify the value held in the variable i through the pointer variable pi like this:

```
*pi = 100;
```

This code updates the value of the variable i to 100 because pi points to the same memory location as the variable i.

One of the main problems that developers learning C and C++ encounter is understanding the syntax used by pointers. The * operator has at least two meanings (in addition to being the arithmetic multiplication operator), and there's often great confusion when to use & rather than *.

The other issue with pointers is that it's easy to point somewhere invalid or forget to point somewhere at all, and then try to reference the data pointed to. The result will be either garbage or a program that fails with an error because the operating system detects an attempt to access an illegal address in memory.

Finally, there are several security flaws in many existing systems resulting from the mismanagement of pointers. Some environments (not Windows) fail to enforce checks that a pointer does not refer to confidential data that belongs to another process, opening up the possibility that data could be compromised.
