13. Select and drag the right side of the window to expand the display so that the text and controls are displayed as they appeared in the Design View window in Visual Studio. This is the optimal size of the form as it was designed.

14. Resize the window displaying the Customers app to its minimum width. In this time, much of the form disappears. Some of the TextBlock content wraps, but the form is clearly not usable in this view.

15. Return to Visual Studio, and on the Debug menu, select Stop Debugging.

That was a lesson in being careful how you lay out an app. Although the app looked fine when it ran it in a window that was the same size as the Design View, as soon as you resized the window to a narrower view, it became useless (or even completely useless). Additionally, the app assumes that the user will be viewing the screen on a device in the landscape orientation. If you temporarily switch the Design View window to the 12" Tablet form factor and select the Portrait orientation button, you can see what the form would look if the user ran the app on a tablet that supports different orientations and rotated the device to switch to portrait mode. (Don't forget to switch back to the 13.3" Desktop form factor afterward.)
