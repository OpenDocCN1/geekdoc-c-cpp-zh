C# pattern matching also provides the not operator for use with is. It is similar to the ! operator works only for patterns. The following code shows another way of determining whether the value in the percent variable lies within the range 0 to 100:

validPercentage = (percent is not < 0 and not > 100);

# Using if statements to make decisions

In a method, when you want to choose between executing two different statements depending on the result of a Boolean expression, you can use an if statement.

# Understanding if statement syntax

The syntax of an if statement is as follows (if and else are C# keywords):

```
if ( booleanExpression )
    statement-1;
else
    statement-2;
```

If booleanExpression evaluates to true, statement-1 runs; otherwise, statement-2 runs. The else keyword and the subsequent statement-2 are optional. If there is no clause and booleanExpression evaluates to false, execution continues with whatever code follows the if statement.

> Note
The Boolean expression must be enclosed in parentheses. Otherwise, the code will not compile.
