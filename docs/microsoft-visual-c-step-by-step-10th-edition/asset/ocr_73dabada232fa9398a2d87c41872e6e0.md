or the other but not. (Two ones yield a zero; this is the “exclusive” part of the operator.) The 8-bit expression 204 ^ 24 is 212 (0b0_11001100 ^ 0b0_00011000 is 0b0_11010100).

You can use these operators together to determine the values of the individual bits in an int. As an example, the following expression uses the left-shift (<<) and bitwise AND (&) operators to determine whether the sixth bit from the right of the byte variable bits is set to 0 or to 1:

```
(bits & (1 << 5)) != 0
```

> Note
The bitwise operators count the positions of bits from right to left, and the bits are numbered starting at 0. So, bit 0 is the rightmost bit, and the bit at position 5 is the six bits places from the right.

Suppose the bits variable contains the decimal value 42. In binary, this is 0b_00101010. The decimal value 1 is 0b_00000001 in binary, and the expression 1 << 5 has the value 0b_00100000; the sixth bit is 1. In binary, the expression bits & (1 << 5) is 0b_00101010 & 0b_00100000, and the value of this expression is 0b_00000000, which is nonzero. If the variable bits contains the value 65, or 0b_01000001, the value of the expression yields the result 0b_00000000, or.

This is a fairly complicated example, but it's trivial in comparison to the following expression, which uses the compound assignment operator &= to set the bit at position 6 to 0:

```
bits &= ~(1 << 5)
```

Similarly, if you want to set the bit at position 6 to 1, you can use the bitwise OR (|) operator. The following complicated expression is based on the compound assignment operator |=:

```
bits |= (1 << 5)
```
