# The SortedList<TKey, TValue> collection class

The SortedList<TKey, TValue> class is very similar to the Dictionary<TKey, TValue> class that you can use to associate keys with values. The primary difference is that the keys array is always sorted. (It's called a SortedList, after all.) In most cases, it takes longer to insert data into a SortedList<TKey, TValue> object than a SortedDictionary<TKey, TValue> object, but data retrieval is often quicker (or at least as quick), and the SortedList<TKey, TValue> uses less memory.
