<ComboBoxItem Content="Mr"/>

The ComboBox elements are displayed in a dropdown list when the app runs, and the user can select one of them.

There’s one important syntactical point to notice in this code: the ComboBox markup has been split into an opening <ComboBox> tag and a closing </ComboBox> tag. You place the ComboBoxItem controls between these opening and closing tags.

A ComboBox control can display simple elements such as a set of ComboBoxItems that display display text, but it can also contain complex elements as buttons, checkboxes, and option buttons. If you’re adding simple ComboBoxItem controls, it’s probably easier to type the XAML markup by hand, but if you’re adding more complex controls, the Object Collection Editor available in the Properties window can prove very useful. However, you should avoid trying to be too clever in a combo box; the best apps are those that provide the most intuitive UIs, and embedding complex controls in a combo box can be confusing to a user.
