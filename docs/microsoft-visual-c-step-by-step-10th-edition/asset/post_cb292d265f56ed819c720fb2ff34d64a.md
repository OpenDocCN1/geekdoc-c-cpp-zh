8. Open the Program.cs file. It should contain the following code:

Click here to view code image

```
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World!");
        }
    }
}
```

This program file is a little more complicated than the one you created, although it does exactly the same. Program.cs defines a class called Program that contains a method. In C#, every method must be defined within a class or struct. The Main method designates the program's entry point. This method should be defined in the Program class as a static method; otherwise, the .NET Framework might not recognize it as the starting point when you run it. You'll learn more about methods in Chapter 3, "Writing methods."

At this point, you're probably thinking, "I didn't create a Program class or a Main method" in the previous exercise. In the latest version of C#, if you have a simple application as shown in the first exercise, the C# compiler will create its own Main method, as its name is actually Main.) You can think of this as a compiler-synthesized Main method, which can save you unnecessary boilerplate in many cases; just compare the code to the program you wrote in the previous exercise to see what I mean. However, the console application template provided with the .NET always creates a Program class and a Main method. Additionally, other types of applications use a different way of marking the entry point for a program. The templates for these types of applications generate the appropriate startup code. You'll see an example later in this section "Creating an application."

As for the using statement and the namespace definition, you'll learn about these items later in this chapter.
