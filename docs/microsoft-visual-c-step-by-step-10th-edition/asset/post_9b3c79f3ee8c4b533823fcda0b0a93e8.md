# Note

The ShowAsync() returns a value, but in this example, you aren't interested in what this value is. You simply want to use the method to display the message. In cases such as this, the syntax = indicates that the value should be discarded. If you omit these two characters, the code will still work, but Visual Studio displays a warning. Visual Studio does this by adding a wavy green line under the statement. If you hover over this line of code, Visual Studio displays a message that states, "Because this call is not awaited, execution of the current method continues before the call is completed. Consider applying the 'await' operator to the result of the call. Expression value is never used." Essentially, this alerts you to the fact that your code has ignored the return value, but you might not be aware of this. In cases such as this, it's always better to be explicit and highlight that you're ignoring ignoring return value.
