In addition to a good number of using directives to bring into scope namespaces that UWP apps use, the files contain the definition of a class called MainPage but not much else. There's a little bit of code for the MainPage class known as a constructor that has a method named InitializeComponent. A constructor is a special method with the same name as the class. It runs when an instance of the class is created and can contain code to initialize the instance. You'll learn about constructors in Chapter 7.
