| Unsubscribe from an event | Create a delegate instance (of the same type as the event), and detach it from the event by using the – operator. For example:

[Click here to view code image](#)
```java
class MyEventHandlerClass {
    private MyClass myClass = new MyClass();
    ...
    public void Stop() {
        myClass.MyEvent -
            new MyClass.MyDelegate(
                (this.eventHandlingMethod);
    }
    ...
}
```
Or:
[Click here to view code image](#)
```java
public void Stop() {
    myClass.MyEvent -
        this.eventHandlingMethod;
}
``` |
