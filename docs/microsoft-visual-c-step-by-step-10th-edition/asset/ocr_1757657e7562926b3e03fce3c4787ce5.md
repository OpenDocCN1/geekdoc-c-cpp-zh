| Subscribe to an event | Create a delegate instance (of the same type as the event) and attach the delegate instance to the event using the += operator. For example:
[Click here to view code image](#)
```csharp
class MyEventHandlingClass {
    private MyClass myClass = new MyClass();
    ...
    public void Start() {
        myClass.MyEvent += new MyClass.MyDelegate(this.eventHandlingMethod);
    }
    private void eventHandlingMethod() {
        ...
    }
}
```
You can also get the compiler to generate the new delegate automatically simply by specifying the subscribing method: 
[Click here to view code image](#)
```csharp
public void Start() {
    myClass.MyEvent += this.eventHandlingMethod;
}
``` |
