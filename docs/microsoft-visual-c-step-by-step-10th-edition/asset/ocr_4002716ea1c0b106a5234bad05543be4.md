The SerialTest method populates an integer array with a set of values (in a long winding way) and then iterates through this list, printing the index of each item in the array together with the value of the corresponding item. The doAdditionalProcessing and doMoreAdditionalProcessing methods simply simulate the performance of long-running operations as part of the processing that might cause the runtime to yield control of the processor.
