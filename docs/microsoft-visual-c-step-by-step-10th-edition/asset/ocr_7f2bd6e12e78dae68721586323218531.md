# Do this

Wait for several tasks to finish

Call the static WaitAll method of the Task class, and specify the tasks to wait for. For example:

Click here to view code image

```
Task task1 = ...;
Task task2 = ...;
Task task3 = ...;
Task task4 = ...;
```

Specify a method to run in a new task when a task has completed

Call the ContinueWith method of the task and specify the method as a continuation. For example:

Click here to view code image

```
Task task = new Task(doWork);
task.ContinueWith(doMoreWork);
TaskContinuationOptions.NotOnFaulted);
```

Perform loop iterations and statement sequences by using parallel tasks

Use the Parallel.For and Parallel.ForEach methods to perform loop iterations by using tasks. For example:

Click here to view code image

```
Parallel.For(0, 100, performLoopProcessing);
...
private void performLoopProcessing(int x)
{
    // Perform loop processing
}
```

Or, use the Parallel.Invoke method to perform concurrent method calls by using separate tasks. For example:

```
Parallel.Invoke(
    doWork,
    doMoreWork,
    doYetMoreWork
);
```
