# Note

Ideally, you should ensure that any background image that you apply to a page or control maintains its aesthetics as the device factor and orientation change. An image that looks cool on a 30-inch monitor might appear distorted and squashed on a tablet. It might be necessary to provide alternative backgrounds for different views and orientations and use the Visual State Manager to modify the Background property of a control to switch between them as the visual state changes.

+   13. Return to AppStyles.xaml in the Code and Text Editor window and add the following FontStyle after the PageStyle style:

Click here to view code image

```
<Style x:Key="PageStyle" TargetType="Page">

</Style>
<Style x:Key="FontStyle" TargetType="TextBlock">
  <Setter Property="FontFamily" Value="Segoe Print"/>
</Style>
```

This style applies to Text elements and changes the font to Segoe Print. This font resembles a handwriting style.

At this stage, it would be possible to reference the FontStyle in every TextBlock control that required this font, but this approach wouldn't provide any advantage over simply setting the FontFamily in the markup for each control. The real power of styles occurs when you combine multiple properties, as you'll see in the next few steps.

```
<Style x:Key="FontStyle" TargetType="TextBlock">
...
</Style>
<Style x:Key="HeaderStyle" TargetType="TextBlock" BasedOn="[StaticResource FontStyle]">

  <Setter Property="TextWrapping" Value="Wrap"/>
</Style>
```
