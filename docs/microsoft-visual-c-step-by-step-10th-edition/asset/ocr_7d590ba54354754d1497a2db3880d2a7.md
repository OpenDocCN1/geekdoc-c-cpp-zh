On the SQL Database page, select **Create**.

On the **Basics** tab of the Create SQL Database page, perform the following tasks:

+   - Leave the **Subscription** box set to the name of your Azure subscription.
- Under the **Resource** group box, select **Create new**, and type **awgroup**.
- In the **Database name** box, type **AdventureWorks**.
- Under the **Server** box, select **Create new**. Then, in the **New Server** pane, type a unique name for your server. Use your company name or even your own name; I used mine (If the name you enter has been used by someone else, you will be alerted, in which case enter another name.) Enter a name and password for the administrator login (make a note of these items); I used **JohnSharp**, but I'm not going to tell you your password), select the location closest to you, and then select **OK** to return to the SQL Database page.
