# Deconstructing an object

You use a constructor to create and initialize an object, typically by populating fields it contains. A deconstructor enables you to examine an object and extract the values of its fields. Taking the Point class from the previous exercise as example, you can implement a deconstructor that retrieves the values of the x and y fields, like this:

Click here to view code image

```
class Point {
    private int x, y;
    ...
    public void Deconstruct(out int x, out int y) {
        x = this.x;
        y = this.y;
    }
}
```

You should note the following points about a deconstructor:

+   - It is always named Deconstruct.

+   - It must be a void method.
