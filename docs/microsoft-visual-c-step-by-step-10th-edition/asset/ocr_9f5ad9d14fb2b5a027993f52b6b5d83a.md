These statements iterate through the params list, adding each item to the tree
using the Insert method. If the value specified by the tree parameter is
ull initially, a new Tree<TItem> is created; this is why the tree parameter is
passed by reference

Click here to view image

```
static void InsertIntoTree<TItem>(ref Tree<TItem> tree, params
TItem[] data)
    where TItem : IComparable<TItem>
{
    foreach (TItem datum in data)
    {
        if (tree is null)
        {
            tree = new Tree<TItem>(datum);
        }
        else
        {
            tree.Insert(datum);
        }
    }
}
```
