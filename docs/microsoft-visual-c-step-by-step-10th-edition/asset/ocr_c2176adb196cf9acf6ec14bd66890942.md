The first step in implementing the Sum method is to check the paramList parameter. This parameter can contain a valid set of integers, can be null, or be an array of zero length. In the latter two cases, it's difficult to calculate the sum, so the best option is to throw an ArgumentException exception. (You could argue that the sum of the integers is 0, but you'll treat this situation as an exception in this example.)
