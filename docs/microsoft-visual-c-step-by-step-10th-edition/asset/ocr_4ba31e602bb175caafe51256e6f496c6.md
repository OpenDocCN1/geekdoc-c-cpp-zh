You define the following simple interface:

Click here to view code image

```
public interface IMyInterface
{
    public void DoSomeWork();
}
```

Later, another developer creates a class that implements this same interface:

Click here to view code image

```
public class myClass : IMyInterface
{
    void IMyInterface.DoSomeWork()
    {
        // Implementation
        ...
    }
}
```

Sometime later, you decide to extend the interface and add another method:

Click here to view code image

```
public interface IMyInterface
{
    public void DoSomeWork();
    public void DoAdditionalWork();
}
```

This change will break all existing apps that use the original interface because they don't implement DoAdditionalWork method.

The traditional way to solve this problem is to create a new interface that extends the existing interface, like this:

Click here to view code image

```
public interface IMyExtendedInterface : IMyInterface
{
    public void DoAdditionalWork();
}
```
