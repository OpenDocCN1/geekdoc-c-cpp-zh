# Propagating exceptions

Adding a try/catch block to the addValues method has made that method other than robust, but you need to apply the same exception handling to the other methods: subtractValues, multiplyValues, divideValues, and remainderValues. The code for each of these exception handlers will likely be very similar, resulting in you writing the code in each method.

Each of these methods is called by the calculateClick method when the user selects the Calculate button. Therefore, to avoid duplication of the exception-handling code, it makes sense to relocate it to the calculateClick method. If FormatException occurs in the subtractValues, multiplyValues, divideValues, or remainderValues method, it will be propagated to the calculateClick method for handling as described in the section "Unhandled exceptions" earlier in this chapter.
