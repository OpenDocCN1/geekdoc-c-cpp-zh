> **Note**nAlthough Segoe Print font is good for labels and titles, it is not recommended as a font for data-entry fields because some of the characters can be difficult to distinguish from one another. For example, the lowercase letter l is very similar to the digit 1, and the uppercase letter o is almost indistinguishable from the digit 0. For this reason, it makes sense to stick with the default font for the TextBox controls.
