The AppStyles.xml file appears in the Code and Text Editor window. A resource dictionary is a XAML file that contains resources that the app can use. The AppStyles.xml file looks like this:

Click here to view code image

```
<ResourceDictionary

xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
</ResourceDictionary>
```

Styles are one example of a resource, you can add other items. In fact, the first resource you will add is not actually a style but an ImageBrush resource that will be used to paint the background of the outermost Grid control on the Customers form.

+   3. In Solution Explorer, right-click the Customers project, point to Add, and then select New Folder. Change the name of the new folder to Images.

+   4. Right-click the Images folder, point to Add, and then select Existing Item.

+   5. In the Adding Item - Customers dialog, browse to the \Microsoft Press\VCSBS\Chapter25Resources folder in your Documents folder, select wood.jpg, and then select Add.

The wood.jpg file is added to the Images folder in the Customers project. This file contains an image of a tasty wooden background that you'll use for the Customers form.

+   6. In the Code and Text Editor window displaying the AppStyles.xml file, add the following XAML markup in bold:

Click here to view code image

```
<ResourceDictionary

xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">

  <Image x:Key="WoodBrush" ImageSource="Images/wood.jpg"/>
</ResourceDictionary>
```

This markup creates an ImageBrush resource called WoodBrush that is based on the wood.jpg file. You can use this image to set the background of a control, and it will display the image in the wood.jpg file.
