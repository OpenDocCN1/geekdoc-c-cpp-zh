You define generic methods by using the same type parameter syntax you use when you create generic classes. (You can also specify constraints.) For example, the Swap<T> method in the class that follows swaps the values in its parameters. Because this functionality is useful regardless of the type of data being swapped, it is helpful to define it as a generic method:

Click here to view code image

```
static void Swap<T>(ref T first, ref T second)
{
  T temp = first;
  first = second;
  second = temp;
}
```

You invoke the method by specifying the appropriate type for its parameter. The following examples show how to invoke the Swap<T> method to swap over two ints and two strings:

Click here to view code image

```
int a = 1, b = 2;
Swap<int>(ref a, ref b);
...
string s1 = "Hello", s2 = "World"
Swap<string>(ref s1, ref s2);
```

> Note

As instantiating a generic class with different type parameters causes the compiler to generate different types, each distinct use of the Swap<T> method allows the compiler to generate a different version of the method. Swap<int> is not the same method as Swap<string>—both methods just happen to have been generated from the generic template, so they exhibit the same behavior, albeit different types.
