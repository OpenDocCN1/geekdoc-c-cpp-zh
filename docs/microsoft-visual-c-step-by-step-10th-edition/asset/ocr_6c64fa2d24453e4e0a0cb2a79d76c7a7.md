18. Find the ConfigureServices method. This method runs when the web service starts running. You use this method to set up the various items that the service needs to run, including creating the DbContext object used to connect to the database.

19. Add the stated statement in the following code to bold to the ConfigureServices method. This statement creates a DbContext to connect to the AdventureWorks database. The connection details will be stored in a configuration file and can be accessed using the key AdventureWorksDB.

Click here to view code image

```
public void ConfigureServices(IServiceCollection services)
{
    services.AddDbContext<CustomerContext>(optionsBuilder =>
        optionsBuilder.UseSqlServer(Configuration.ConnectionString("AdventureWorksDB")));

    services.AddControllers();
    services.AddSwaggerGen(c =>
    {
        c.SwaggerDoc("v1", new OpenApiInfo { Title = "AdventureWorksService", Version = "v1" });
    });
};
```
