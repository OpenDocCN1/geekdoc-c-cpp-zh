> The term gesture refers to the manual touch-oriented operations that a user can perform. For example, a user can tap an item with a finger, and the application will typically respond to this gesture the same way that you would expect it to respond to a mouse click or tap. However, gestures can be far more expressive than the simple operations that can be captured by using a mouse. For example, the rotate gesture involves the user placing two fingers on the screen and tracing the arc of a circle with them; in a typical Windows 11 app, this gesture should cause the UI to rotate the selected object in the direction indicated by the movement of the user’s fingers. Other gestures include unpinching/pinching to zoom in and out on an item to display less or more detail, pressing and holding to reveal additional information about an item (similar to right-clicking the mouse), sliding to select an item and drag it across the screen.

The UWP is intended to run on a wide range of devices with varying screen sizes and resolutions. Therefore, when you implement a UWP app, you need to construct your software so that it adapts to the environment it’s running in—scaling automatically and orientation of the device. This approach opens your software to an increasingly broad market. Additionally, modern devices can detect their orientation and the speed at which the user changes this orientation through the use of built-in sensors and accelerometers. UWP apps can adapt their layout as the user tilts or rotates a device, making it possible for users to work in a mode that’s most comfortable for them.

You should also understand that mobility is a key requirement for many modern apps. With UWP apps, users can roam, and their data can migrate through the cloud to whatever device they have to running your app on a particular moment.
