```
public void AddCardToHand(PlayingCard cardDealt) {
    if (this.playingCardCount >= HandSize) {
        throw ArgumentException("Too many cards");
    }
    this.cards[this.playingCardCount] = cardDealt;
    this.playingCardCount++;
}
```

This code checks to ensure that the hand is not already full. If the hand is full, it throws an ArgumentException (This should never occur, but it's good practice to be safe). Otherwise, the card is added to the cards array at the index specified by the playingCardCount variable, and this variable is incremented.
