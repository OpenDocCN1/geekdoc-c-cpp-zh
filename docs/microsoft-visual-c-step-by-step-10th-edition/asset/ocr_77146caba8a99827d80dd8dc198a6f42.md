12. On the Debug menu, select Start Debugging to build and run the app.

The app starts and displays the form. You can enter data into the form and select a title from the combo box, but you can't do much else yet. However, a much bigger problem is that, depending on the resolution of your screen, the form looks awful. (If the form looks fine, drag the right-hand edge to make it narrower.) The right side of the display has been cut off, much of the text wrapped around, and the Last Name text box has been truncated.
