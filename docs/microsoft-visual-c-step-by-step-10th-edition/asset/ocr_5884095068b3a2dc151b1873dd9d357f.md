# Understanding statement scope

You might have noticed that you can declare a variable in the initialization part of a for statement. Variable is scoped to the body of the for statement and disappears when the for statement finishes. This rule has two important consequences. First, you cannot use that variable after the for statement has ended because it's no longer in scope. Here's an example:

Click here to view code image

```
for (int i = 0; i < 10; i++)
{
    ...
}
Console.WriteLine(i); // compile-time error
```

Second, you can write two or more for statements that reuse the same variable name because each variable is in a different scope, as shown in the following code:

```
for (int i = 0; i < 10; i++) { ... } for (int i = 0; i < 20; i += 2) // okay { ... }
for (int i = 0; i < 10; i++)
{
}
for (int i = 0; i < 20; i += 2) // okay
{
    ...
```
