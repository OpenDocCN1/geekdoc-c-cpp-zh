Duplication in code is a warning sign. If possible, you should refactor code to
avoid duplication and reduce any associated maintenance costs. One way to
aieve this refactoring is to put the common implementation into a new class
created specifically for this purpose. In effect, you can insert a new class into the
class hierarchy, as shown in the following code example:

```
class GrazingMammal : Mammal, IGrazable
{
    ...

    {
        // common code for chewing grass
        Console.WriteLine("Chewing grass ");
    }
}
```
