```
items[2, 3] = 99; // set the element at cell(2,3) to 99
items[2, 4] = items[2,3]; // copy the element in cell(2, 3) to
cell(2, 4)
items[2, 4]++; // increment the integer value at cell(2,
4)
```

There is no limit on the number of dimensions that you can specify for an array. The next example creates and uses an array called cube that contains three dimensions. Notice that you must specify three indexes to access each element in the array.

Click here to view code image

```
int[][] cube = new int[5, 5, 5];
cube[1, 2, 1] = 101;
cube[1, 2, 2] = cube[1, 2, 1] * 3;
```

At this point, it's worth mentioning a word of caution about creating arrays with more than three dimensions. Specifically, arrays consume a lot of memory. The cube array contains 125 elements (5 * 5 * 5). A four-dimensional array for which each dimension has a size of 5 contains 625 elements. If you start to create arrays with three or more dimensions, you can run out of memory. Therefore, you should always be prepared to catch and handle OutOfMemoryException when you use multidimensional arrays.
