# Do this

Create a task and run it

Use the static Run method of the Task class to create and run the task in a single step. For example:

Click here to view code image

```
Task task = Task.Run(() => doWork());
private void doWork()
{
    // The task runs this code when it is started
    ...
}
```

Or, create a new Task object that references a method to run and call the Start method. For example:

```
Task task = new Task(doWork);
task.Start();
```

Wait for a task to finish

Call the Wait method of the Task object. For example:

```
Task task = ...;
...
task.Wait();
```

Or, use the await operator (only in in an async method). For example:

```
await task;
```
