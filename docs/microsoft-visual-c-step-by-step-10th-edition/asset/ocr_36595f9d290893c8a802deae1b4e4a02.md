13. Delete this method and replace it with the definition of a property named Color, as presented here:

```
interface IColor {
    Color Color { set; }
}
```

This is a write-only property, providing a set accessor but no get accessor. You define the property this way because the color isn’t stored in the DrawingShape class and is specified only as each shape is drawn. You can’t actually query a shape to find out which color it is.

> Note
It’s common practice for a property to share the same name as a type (Color in this example).
