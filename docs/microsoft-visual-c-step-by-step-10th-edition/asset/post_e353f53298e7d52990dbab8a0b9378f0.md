- 2. Implement the get accessor as shown in bold in the code that follows:

Click here to view code image

```
sealed class PhoneBook
{
    public Name this [PhoneNumber number]
    {
        get
        {
            int i = Array.IndexOf(this.phoneNumbers, number);
            if (i != -1)
            {
                return this.names[i];
            }
            else
            {
                return new Name();
            }
        }
    }
}
```

The purpose of the accessor is to find the name that matches the specified number. To do this, you need to call the static IndexOf method of the Array class. The IndexOf method searches through an array and returns the index of the first item in the array that matches the specified value. The first argument to IndexOf is the array to search through (phoneNumbers). The second argument to IndexOf is the item for which you are searching. IndexOf finds the integer index of the element if it finds it; otherwise, it returns -1. If the indexer finds the phone number, it should return the corresponding name; otherwise, it should return an empty Name value. (Note that Name is a structure, the default constructor sets its private name field to null).

- 3. Remove the comment // TODO: write 2 indexers here and replace it with a second public read-only indexer for the PhoneBook class that returns a PhoneNumber and accepts a single Name parameter. Implement this indexer in the same way as the first, as shown in bold in the code that follows (Again, note PhoneNumber is a structure and therefore always has a default constructor.) The second indexer should look like this:

Click here to view code image

```
sealed class PhoneBook
{
    public PhoneNumber this [Name name]
    {
        get
        {
            int i = Array.IndexOf(this.names, name);
            if (i != -1)
            {
                return this.phoneNumbers[i];
            }
            else
            {
                return new PhoneNumber();
            }
        }
    }
}
```

Notice that these overloaded indexers can coexist because the values they index are of different types. If the Name and PhoneNumber structures were replaced by simple strings, the overloads would have the same signature, and the class would not compile.

 To call the indexers

- 1. Display the MainPage.xaml.cs file in the Code and Text Editor window and then locate the findByNameClick method. This method is called when the Find Name button is selected. This method is currently empty.
- 2. Replace the // TODO: comment with the code shown in bold in the following example:

Click here to view image

```csharp
private void findByNameClick(object sender, RoutedEventArgs e)
{
    string text = name.Text;
    if (!String.IsNullOrEmptyEmpty(text))
    {
        Name personsName = new Name(text);
        PhoneNumber personsNumber = this.phoneBook[personsName];
        phoneNumber.Text =
            String.IsNullOrEmptyEmpty(personsNumber.Text) ?
            "Not Found" : personsNumber.Text;
    }
}
```

This code performs the following tasks:

- reads the value of the Text property box on the form. This is a string containing the contact name that the user has typed in.
- If the string is not empty, the code searches for the phone number corresponding to that name in the PhoneBook object using the indexer. (Notice that the MainPage class contains a private PhoneBook field named phoneBook.) It constructs a Name object from the string and passes it as the parameter to the PhoneBook.
- If the Text property of the PhoneNumber structure returned by the indexer is not null or empty, the code writes the value of this property to the PhoneNumber box on the form; otherwise, it displays the text Not Found.

Other than the statement that asserts the indexer, there are two further points of interest in this code:

- The static String IsNullOrEmpty is used to determine whether a string is empty or contains a null value. This is the preferred method for testing whether a string contains a value or is an empty string; otherwise, it returns false.
- The ? operator is used by the statement that populates the Text property of the phoneNumber box on the form. Remember that this acts like an inline if...else statement for an expression. In the preceding code, if the expression String.IsNullOrEmptyEmpty(personsNumber.Text) is true, no matching entry was found in the phone book and the text Not Found.
