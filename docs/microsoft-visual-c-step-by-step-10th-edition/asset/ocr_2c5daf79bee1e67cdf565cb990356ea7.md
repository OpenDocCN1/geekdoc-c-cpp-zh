```
columnForRow0[1] = 99;
items[0][1] = 99;
```

You can extend this idea further if you want to create arrays of arrays of arrays rather than rectangular three-dimensional arrays, and so on.

> Note
If you have written code using Java, you should be familiar with this concept. Java does not not have multidimensional arrays; instead, you can create arrays of arrays exactly as just described.
