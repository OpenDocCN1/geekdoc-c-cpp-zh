# Creating symmetric operators

In the preceding section, you saw how to declare a binary + operator to add together two instances of type Hour. The Hour structure also has a constructor that creates an Hour from an int. This means you can add another Hour and an int; you just have to first use the Hour constructor to convert the int to Hour, as in the following example:

```
Hour a = ...;
int b = ...;
Hour later = a + new Hour;
```

This is entirely valid code, but it's not as clear or concise as adding an Hour and an int directly, like this:

```
Hour a = ...;
int b = ...;
Hour later = a + b;
```
