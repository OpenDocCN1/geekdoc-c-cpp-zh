48 and 55 (remember that nextDigit will be between 0 and 7), corresponding to the code for the equivalent octal digit.

```
char digit = Convert.ToChar(digitCode);
```

This statement declares a char variable called digit and initializes it to the result of the Convert.ToChar(digitCode) method call. The Convert.ToChar method takes an integer holding a character and returns the corresponding character. For example, if digitCode has the value 54, Convert.ToChar(digitCode) returns the character '6'.

To summarize, the first four statements in the do loop have determined the character representing the least-significant (rightmost) octal digit corresponding to the number the user entered. The next task is to prepend this digit to the string to be output, like:

```
current = digit + current;
```

The next statement in the do loop is:

```
steps.Text += current + "\n";
```

This statement adds to the Steps box the string containing the digits produced so far for the octal representation of the number. It also appends a newline character so each stage of the conversion appears on a separate line in the box.

Finally, the condition in the while clause at the end of the loop is evaluated:

```
while (amount != 0);
```
