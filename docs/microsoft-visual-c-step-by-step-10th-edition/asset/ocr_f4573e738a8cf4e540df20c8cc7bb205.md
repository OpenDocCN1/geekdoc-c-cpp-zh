The Document Outline window appears, showing the names and types of controls on the form. The Document Outline window provides a simple way to locate and select controls on a complex form. The controls are arranged in a hierarchy, starting with the Page 1, a Universal Windows Platform (UWP) app page contains a Grid control, and the other controls are placed within this Grid. If you expand the Grid node in the Document Outline window, the other controls appear, starting with an outer Grid acts as a frame, and the inner Grid contains the controls that you see on the form. If you expand the inner Grid, you can see each of the controls on the form.
