# 安装代码示例

按照以下步骤在计算机上安装代码示例，以便将其与书中的练习配合使用：

1. 解压缩从书籍网站下载的 `CSharpSBS.zip` 文件，将文件提取到“文档”（Documents）文件夹中。
2. 如果提示，请查看用户许可协议。如果您接受这些条款，请选择“接受”（Accept）选项然后点击“下一步”（Next）。

注意：如果没有出现许可协议，您可以从下载 `CSharpSBS.zip` 文件的同一个网页访问它。
