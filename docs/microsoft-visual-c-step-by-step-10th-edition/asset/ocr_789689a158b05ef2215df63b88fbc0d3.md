# Quick reference

| To | Do this |
| Copy a value variable | Simply make the copy. Because the variable is a value type, you will have two copies of the same value. For example:
```cs
int i = 42;
int copyi = i;
``` |
| Copy a reference variable | Simply make the copy. Because the variable is a reference type, you will have two references to the same object. For example:
```cs
Circle c = new Circle(42);
Circle refc = c;
``` |
| Declare a variable that can hold a value type or the null value | Declare the variable using the ? modifier with the type. For example:
```cs
int? i = null;
``` |
