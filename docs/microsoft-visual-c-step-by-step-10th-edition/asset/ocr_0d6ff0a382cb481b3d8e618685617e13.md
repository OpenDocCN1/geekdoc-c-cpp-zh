# To test the Square and Circle classes

+   1. Display the DrawingPad.xml file in the Design View window.
2. On the form, select the large shaded area.
3. The shaded area of form is the Canvas object. You select this area to set the focus to this object.
   In the Properties window, select the Event Handlers button. (This button has an icon that looks like a bolt of lightning.)
4. In the list of events, locate the Tapped event, and double-click the Tapped box.

Visual Studio creates a method drawingCanvas_Tapped for the DrawingPad class and displays it in the Code and Text Editor window. This is an event handler that runs when the user taps the canvas with a finger or clicks the left mouse on the canvas. You can learn more about event handlers in Chapter 20, "Decoupling application logic and handling events."

At the top of the DrawingPad.xml.cs file, add the following using directive to the list:

```
using Windows.UI;
```

The Windows.UI namespace contains the definition of the Colors class, which you'll use when you set the color of a shape as it is drawn.

6. Add the following code to show in the drawingCanvas_Tapped method:
