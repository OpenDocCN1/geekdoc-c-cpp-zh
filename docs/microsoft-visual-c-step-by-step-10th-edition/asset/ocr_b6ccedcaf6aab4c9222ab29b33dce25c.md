# Note

It's important to tab away from the First Name field before selecting Search. If you don't leave the field, the page doesn't register the text as having been changed, and the query will perform a search for all records instead, returning 840 rows. There are ways around this feature, however. For example, you can capture each keystroke as it occurs in a field by using the TextChanging event. However, this technique is beyond the scope of this chapter.
