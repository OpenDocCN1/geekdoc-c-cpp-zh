```
struct ScreenPosition
{
    private int _x, _y;

    public ScreenPosition(int X, int Y)
{
        this._x = rangeChecked(X);
        this._y = rangeChecked(Y);
    }

    public int X
{
        get { return this._x; }
        set { this._x = rangeChecked(value); }
    }

    public int Y
{
        get { return this._y; }
        set { this._y = rangeChecked(value); }
    }

    private static int rangeChecked(int x) { ... }
    private static int rangeChecked(int y) { ... }
}
```

In this example, a private field directly implements each property, but this is only one way to implement a property. All that’s required for a get accessor to return a value of the specified type. Such a value can easily be calculated dynamically rather than simply retrieved from stored data, in which case there might be no need for a physical field.

> Note
Although the examples in this chapter show how to define properties for a structure, properties are equally applicable to classes; the syntax is the same.
