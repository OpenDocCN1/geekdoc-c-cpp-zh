# Numeric types and infinite values

There are other features of numbers in C# that you should be aware of. For example, the result of dividing any number by zero is infinity, which is outside the range of the int, long, and decimal types; consequently, evaluating an expression as 5/0 results in error. However, the double and float types have a special value that can represent infinity, and the value of the expression 5.0/0.0 is Infinity. The one exception to this rule is the value of the expression 0.0/0.0. Usually, if you divide anything by zero, the result is infinity. The expression 0.0/0.0 results in a paradox; the value must be nan and infinity at the same time. C# has another special value for this situation, called NaN, which stands for not a number. If you evaluate 0.0/0.0, the result is NaN.

NaN and Infinity propagate through expressions. If you evaluate 10 + NaN, the result is NaN, and if you evaluate 10 + Infinity, the result is Infinity. The value of the expression Infinity * 0 is NaN.
