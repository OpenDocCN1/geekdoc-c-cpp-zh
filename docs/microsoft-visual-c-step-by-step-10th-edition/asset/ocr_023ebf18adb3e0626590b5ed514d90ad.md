Parts I and II introduced you to the syntax of the C# language and showed you how to build new types using structures, enumerations, and classes. You also saw how the common runtime (CLR) manages the memory used by variables and objects when a program runs, and you should now understand the lifecycle of C# objects. The chapters in Part III build on this information, showing you how to use C# to create extensible components—highly functional data types that you can use in many applications.

In Part III, you'll learn about more advanced features of C#, such as properties, indexers, generics, and collection classes. You'll see how you can build responsive systems using events and how you can use delegates to invoke the application logic of one class from without closely coupling the classes—a powerful technique that enables you to construct highly extensible systems.
