7. In the Code and Text Editor window, locate the addValues method, which looks like this:

Click here to view code image

```
private int addValues(int leftHandSide, int rightHandSide)
{
    expression.Text = `${leftHandSide} + ${rightHandSide}`;
    return leftHandSide + rightHandSide;
}
```

The addValues method contains two statements.

+   - The first statement displays the calculation being performed in the expression box on the form.

+   - The second statement uses the int version of the + operator to add the values of the leftHandSide and rightHandSide int variables and returns the result of this operation. Remember that adding two int values creates another int value, so the return type of the addValues method is int.

If you look at the subtractValues, multiplyValues, divideValues, and remainder methods, you will see that they follow a similar pattern.
