# Using Boolean operators

A Boolean operator performs a calculation whose result is either true or false. C# has several very useful Boolean operators, represented by the exclamation point (!). The ! operator negates a Boolean value, yielding the opposite of that value. In the preceding example, if the value of the variable areYouReady is true, the value of the expression !areYouReady is false.
