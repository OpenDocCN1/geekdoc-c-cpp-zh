When you bind a command to a control, the control automatically subscribes to this event. This event should be raised by the Command object if the state of the ViewModel is updated and the value returned by the CanExecute method changes. The simplest strategy is to use a timer to raise the CanExecuteChanged event every second or so. The control can invoke CanExecute to determine whether the command can still be executed and take steps to enable or disable depending on the result.
