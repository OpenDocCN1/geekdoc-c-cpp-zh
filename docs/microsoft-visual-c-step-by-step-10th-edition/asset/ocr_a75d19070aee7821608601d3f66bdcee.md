```

```

When you copy a structure variable, each field on the left side is initialized directly using the corresponding field on the right side. This copying is done as a single fast operation that copies the contents of the entire structure, and it never throws an exception. Compare this behavior with the equivalent action if Time were a class, in which case both variables (now and copy) would end up referencing the same object on the heap.

> > Note\If you are a C++ programmer, note that this copy behavior cannot be customized.
