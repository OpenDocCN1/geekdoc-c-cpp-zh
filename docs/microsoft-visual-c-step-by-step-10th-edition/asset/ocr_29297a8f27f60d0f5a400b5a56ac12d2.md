```
<StateManager.VisualStateGroups>
  <VisualStateGroup>
    <VisualState x:Name="TabularLayout">
      <VisualState.StateTriggers>
        <AdaptiveTrigger MinMinWidth="660"/>
      </VisualState.StateTriggers>
      <VisualState.Setters>
        <Setter Target="customersTabularView.Visibility" Value="Visible"/>
        <Setter Target="customersColumnarView.Visibility" Value="Collapsed"/>
      </VisualState.Setters>
    </VisualState>
  </VisualStateGroup>
</StateManager.VisualStateGroups>
```

This code specifies the actions that occur when the trigger is fired. In this example, the actions are defined using Setter elements. A Setter element specifies a property to set and the value that the property should be set. For this view, the customersTabularView Grid changes the values of specified properties: The customersTabularView Grid control is visible, and customersColumnarView Grid control is collapsed (made invisible).
