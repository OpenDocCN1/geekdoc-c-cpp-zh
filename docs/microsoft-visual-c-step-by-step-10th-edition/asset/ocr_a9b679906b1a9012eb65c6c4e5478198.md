# Modifying data by using data binding

In the previous exercise, you saw how easily data in an object can be displayed by data binding. However, data binding is a one-way operation by default, and any changes you make to the displayed data are not copied back to the data source. In the exercise, you saw this when you changed the email address displayed in the narrow view; when you switched to the wide view, the data had not changed.
