This is the parallel equivalent of the original loop. It iterates through the values from 0 to pixelWidth / 2 - 1. Each invocation runs by a task, and each task might run more than one iteration.
Parallel.For method finishes when all the tasks it has created complete their work. Remember: the Parallel.For method expects the final parameter to be a method that takes a single integer parameter. It calls this method passing the current loop index as the parameter. In this example, the calculateData method doesn't match the required signature two parameters: an integer and a byte array. For this reason, the code uses a lambda expression that acts as an adapter that calls the calculateData method with appropriate arguments.
