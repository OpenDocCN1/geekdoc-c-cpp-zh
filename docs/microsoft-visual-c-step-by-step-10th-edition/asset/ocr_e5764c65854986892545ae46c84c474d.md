# Subscribing to an event

Like delegates, events come ready-made with a += operator, and you use this operator to subscribe to an event. In the automated factory example, the software controlling each machine can arrange for the shutdown methods to be called when the MachineOverheating event is raised, like this:

```
class TemperatureMonitor
{
    public delegate void StopMachineryDelegate();
```
