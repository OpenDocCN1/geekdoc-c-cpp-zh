| Create immutable types |

| Define init-only properties. For example:

```
| ```csharp

{
    public int StudentID { get; init; }
    public string Subject { get; init; }
    public char SubjectGrade { get; init; }
}
``` | |
```

| Instantiate an immutable type |

| Use object initialization syntax and specify a value for each init-only property. For example:

```

```
