Although this refactoring seems fairly simple, you should note a few points. Specifically, the signatures of the doSecondLongRunningOperation and doThirdLongRunningOperation methods have changed to accommodate the requirements of continuations. The Task that instigated the continuation is passed as a parameter to a continuation method.) More importantly, you need to ask yourself, “When is the message displayed in the TextBox control?” The issue with this second point is that although the Start method initiates a Task operation, it does not wait for it to complete, the message appears while the processing is being performed rather than when it has finished.
