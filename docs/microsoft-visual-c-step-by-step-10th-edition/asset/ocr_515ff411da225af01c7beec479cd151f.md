# Declaring structure variables

After you’ve defined a structure type, you can use it in the same way you do any other type. For example, if you have defined the Time structure, you can create variables, fields, and parameters of type Time, as shown in this example:

```
struct Time

    ...
}

    public void Method(Time parameter)

        Time localVariable;
        ...
    }
}
```
