# Accessing a series of array elements

C# lets you retrieve a contiguous set of elements from an array using an index of the form $x..y$. The sequence beginning at element $x$ and finishing at $y$—and this is important—not including $y$ are returned. The result is another array containing the elements retrieved. In the following example, the array subset elements 0 and 1 from the names array:

Click here to view code image

```
var names = new[] { { Name = "John", Age = 57 },
new { Name = "Diana", Age = 57 },
new { Name = "James", Age = 30 },
new { Name = "Francesca", Age = 26 } };

var subset = names[0..2];
```

The subset will contain the values for John and Diana (elements 0 and 1). The first number of the range must be less or equal to the second number; otherwise, you will get a System.ArgumentOutOfRangeException. If the first number in the range and second number are the same, the result is a zero-length array.

You can also specify an expression of the form $x^y$ as the starting element. In this case, $y-1$ elements are retrieved counting back from element $x$ (the elements are still retrieved in forward order, though). In the following statement, the array contains the values for Diana, James, and Francesca (starting backward from element 3, or $4-1$ elements):

```
var subset = names[..4];
```
