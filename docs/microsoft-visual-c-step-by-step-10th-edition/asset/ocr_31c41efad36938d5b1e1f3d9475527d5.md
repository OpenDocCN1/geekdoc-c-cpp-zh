# Casting data safely

By using a cast, you can specify that, in your opinion, the data referenced by
an object has a specific type and that it's safe to reference the object by using
type. The key phrase here is “in your opinion.” The C# compiler will not
check that this is the case, but the runtime. If the type of object in memory
does match the cast, the runtime will throw an InvalidCastException, as
described in the preceding section. You should be prepared to catch this
exception and handle it appropriately if it occurs.
