# Write-only properties

Similarly, you can declare a property that contains only a set accessor. In this case, you can use the property in a write context. For example, here's the property of the ScreenPosition structure declared as a write-only property:

Click here to view image

```
struct ScreenPosition
{
    private int _x;
    ...
    public int X
    {
        set => this._x = rangeCheckedX(value);
    }
}
```

The x property doesn't contain a get accessor; therefore, any attempt to use x in a read context will fail, as illustrated here:

Click here to view image

```
Console.WriteLine(origin.X); // compile-time error
origin.X = 200; // compiles OK
origin.X += 10; // compile-time error
```
