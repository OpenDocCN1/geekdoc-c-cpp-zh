# 在接口中定义索引器

使用 `get` 和/或 `set` 关键字定义索引器。例如：

[点击此处查看代码图片](#)

```csharp
interface IRawInt
{
    bool this[int index] { get; set; }
}
```

# 在类或结构体中实现接口索引器

```csharp
struct RawInt : IRawInt
{
    ...
    public bool this[int index]
    {
        get { ... }
        set { ... }
    }
    ...
}
```
