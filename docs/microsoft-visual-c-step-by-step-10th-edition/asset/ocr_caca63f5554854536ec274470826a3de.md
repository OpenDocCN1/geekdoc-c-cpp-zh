# Declaring interface properties

You encountered interfaces in Chapter 13, "Creating interfaces and defining abstract classes." You can use interfaces to define properties as well as methods. To do this, specify the get or set keyword or both, but you replace the body of the get or set accessor with a semicolon, as shown here:

```
interface IScreenPosition {
  int X { get; set; }
  int Y { get; set; }
}
```

Any class or structure that implements this interface must implement the x and y properties with get and set accessor methods (or expression-bodied members).
