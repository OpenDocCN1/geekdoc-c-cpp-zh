# 17.3 .BSS and .DATA sections

Both .bss and .data sections contain values which can change at run-time (variables). Typically, variables initialized to a non-zero value in the source are allocated in the .data section (e.g. 'int a = 10;'); Variables that are not initialized, or initialized with a zero value, can be allocated to the .bss section (e.g. 'int arr[10];'). Because all values of .bss variables are guaranteed to be at the start of the program, there is no need for the linker to allocate space in the binary file. Therefore, bss sections do not take space in the binary file, regardless of their size.

# 17.4 "Static" Local Variables

Local labeled static maintain their value across function calls, and therefore cannot be created on the stack like other local variables. How are static variables created? Let's take a simple example function:

```
void MyFunction(int a)
{
    static int x = 0;
    printf("my number: %d\n", x);
    printf("%d\n", a, x);
}
```
