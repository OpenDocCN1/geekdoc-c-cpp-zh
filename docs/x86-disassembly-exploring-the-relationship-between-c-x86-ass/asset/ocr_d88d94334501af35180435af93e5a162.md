# 5.5.1 MS-DOS header

Open any Win32 binary executable in a hex editor, and note what you see: The first 2 letters are always the letters 'MZ'. To some, the first few bytes in a file determine the type of file are called the 'magic number,' although this book will not use that term, because there is no rule that states the 'magic number' needs to be a single number. Instead, we will use the term 'File ID Tag', or simply File ID. Sometimes this is also known as File Signature.

After the File ID, the hex editor will show several bytes of random-looking symbols, whitespace, the human-readable "This program cannot run in DOS mode".

What is this?

# Hex List of an MS-DOS file header

What you are looking at is the MS-DOS header of the Win32 PE file. To ensure either backwards compatibility, or by graceful decline of new file types, Microsoft has engineered a series of DOS instructions into the head of each PE file. When a 32-bit Windows file runs in a 16-bit environment, the program will terminate immediately with the error message: "This program cannot run in DOS mode".

The DOS header is also known by some the EXE header. Here is the DOS header presented as a C data structure:

```
struct DOS_Header {
  char signature[2] = "MZ";
  short latype;
  short blocks;
  short nreloc;
  short dsize;
  short minalloc;
  short maxalloc;
  void *ea;
  void *sp;
  void *checksum;
  void *id;
  void *cs;
  short relics;
  short overlay;
  short reserved[4];
  short om_id;
  short om_info;
  short reserved2[10];
  long _efanew
}
```
