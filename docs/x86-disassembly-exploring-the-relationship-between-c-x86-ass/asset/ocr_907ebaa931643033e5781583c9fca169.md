# # 26 Debugger Detectors

# ## 26.1 Detecting Debuggers

It may come as a surprise that a running program can actually detect the presence of an attached user-mode debugger. Also, there are methods available to detect kernel-mode debuggers, although the methods used depend in large part on which debugger is trying to be detected.

This subject is peripheral to the narrative of this book, and the section should be considered an optional one for readers.

# ## 26.2 IsDebuggerPresent API

The Win32 API contains a function 'IsDebuggerPresent', which will return a boolean true if the program is being debugged. The following code snippet will detail a general usage of this function:

```
if (IsDebuggerPresent())
{
    TerminateProcess(GetCurrentProcess(), 1);
```

Of course, it is easy to spot uses of the IsDebuggerPresent() function in the disassembledsembled code, and a skilled reverser will simply patch the code to remove this line. For OllyDBG, there are many plugins available which hide the debugger from this and many other APIs.

# ## 26.3 PEB Debugger Check

The Process Environment Block stores the value that IsDebuggerPresent queries to determine its return value. To avoid suspicion, some programmers access the value directly from the PEB instead of calling the API function. The following code snippet shows how to access the value:

```
mov eax, fs:[30h]
mov eax, byte [eax+2]
test eax, eax
je @DebuggerDetected
```
