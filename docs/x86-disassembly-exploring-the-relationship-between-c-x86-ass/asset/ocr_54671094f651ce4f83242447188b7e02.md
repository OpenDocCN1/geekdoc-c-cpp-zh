# Hex Listing of a PE signature, and the pointer to it

The PE header consists only of a File ID signature, with the value 'PE\0\0' where '\0' character is ASCII NULL character. This signature shows that a) this is a legitimate PE file, and b) the byte order of file. Byte order will not be considered in this chapter, and all PE files are assumed to be in 'little endian' format.

The first chunk of information lies in the COFF header, directly after the PE signature.

# 5.5.3 COFF Header

The COFF header is present in both COFF object files (before they are linked) and PE files where it resides. The COFF header has some information that is useful to execute, and some information that is more useful to an object file.

Here is the COFF header, presented as a C structure:

```
struct COFFHeader {
  short Machine;
  short NumberOfSections;
  long Timestamp;
  long PointerToSymbolTable;
  long NumberOfSymbols;
  short SizeOfOptionalHeader;
  short Characteristics;
};
```
