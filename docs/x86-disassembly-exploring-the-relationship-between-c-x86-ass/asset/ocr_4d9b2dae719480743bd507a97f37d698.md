C compiler, compile C and C++ source code directly into machine code. GCC on the other handles C and C++ into assembly language, and an assembler is used to convert into the appropriate machine code. From the standpoint of a disassembler, it notice that it is not possible to exactly reproduce the C or C++ code used originally to create an executable. It is however, possible to create code that compiles identically, or performs the same task.

C language statements do not share a one to one relationship with assembly language. Consider that the following statements will typically compile into the same assembly language code:

```
*arrayA = arrayB[x];
*arrayA = arrayB[x];
arrayA[0] = arrayB[x];

arrayA(0) = arrayB[x];
```

Also, consider how the following loops perform identical tasks, and are likely to produce similar or even assembly language code:

```
for(;;) { ... }
while(i) { ... }
do { ... } while(i);
```

# 1.7.1 Microsoft C Compiler

The Microsoft C compiler is available from Microsoft for free as part of the Windows Server 2003 SDK. It is the same compiler and library as used in MS Visual Studio, but doesn't come with the fancy IDE. The MS C Compiler has a very good optimizing engine. It compiles C and C++, and has the option to compile C++ code into MSIL ( .NET bytecode).

Microsoft's compiler only supports Windows systems, and Intel-compatible 16/32/64 bit architectures.
