# 13.5 Ternary Operator ?:

Again, the best way to learn is by doing. Therefore we will go through a mini example to explain the ternary operator. Consider the following C code:

```
int main(int argc, char **argv)
{
    return (argc > 1)?(5):(0);
}
```

cl.exe produces the following assembly list:

```
_argc = 0              ; size = 4
_argv = 12             ; size = 4
_main
    PROC NEAR
; File C:\documents\settings\andrew\desktop\test2.c
    Line 2
    push                ebp
    mov                 eax, esp
    Line 3
    xor                 eax, eax
    cmp                 DWORD PTR [ebp], 1
    setle              al
    and                 eax, 5
    Line 4
    pop                 ebp
    ret
    ret                 0
_main                ENDP
```

Line 2 sets up a stack frame, and line 4 is a standard exit sequence. There are no local variables. It is Line 3 where we want to look.

The instruction "xor eax, eax" simply sets eax to 0. For more information on that line, see the chapter on intuitive instructions!. The settle function tests the condition of the ternary operator. The cmp instruction is a set of x86 functions that works like a conditional move: it gets the value if argc < 1. Isn't the exact opposite of what we wanted? In this case, it's look at what happens when argc == 0: al gets the value 1. al is decremented (al = eax), and eax is logically anded with 5 . 5 & 0 = 0. When argc == 2 (greater than 1), the settle doesn't do anything, and eax still is zero. eax then decremented, which means eax == -1. What is -1?
