# HexCurve

An ncurses-based hex editor written in C that currently supports hex and decimal address
output, jumping to specified file locations, searching, ASCII and EBCDIC output, bolded
modifications, an undo command, quick keyboard shortcuts, etc.

# VCHE

A hex editor which lets see all 256 characters as found in video ROM, even control and
extended ASCII, it uses the /dev/vcs* devices to edit. It also could edit non-regular files,
hike hard disks, floppies, CDROMs, PIPs, RAM, and almost any device. It comes with
ncurses and a raw version for people who work under X or remotely.

http://www.grigna.com/diego/linux/vche/
