The high-level components of HLA may make programs less efficient, but that cost is often far outweighed by the ease of writing the code. HLA high-level syntax is very similar in many respects to Pascal, which in turn is itself in many respects to C, so many high-level programmers will immediately pick up many of the aspects of HLA.

Here is an example of some HLA code:

```
mov(src, dest);    //C++ comments
pop(ecx);
push(ebp);
for(mov(0,ecx); ecx < 10; inc(ecx)) do
mul(ecx);
endfor;
```

Some assemblers and debuggers can disassemble binary code into HLA-format, although none can faithfully recreate the HLA macros.

# 1.6 Compilers

A compiler is a program that converts instructions from one language into equivalent instructions in another. There is a common misconception that a compiler always converts a high-level language into machine language, but this isn't the case. Many compilers convert code into assembly language, and even a few convert code from high level language into another.
