# 15.3 While Loops

While loops look almost as simple as a Do-While loop, but in reality they aren't as simple at all. Let's examine a generic while-loop:

```
while(x)
{
  // loop body
}
```

What does this loop do? First, the loop checks to make sure that x is true. If x is not true, the loop is skipped. The body is then executed, by another check: if x is still true? If x is true, execution jumps back to the top of the loop, and execution continues. Keep in mind that there needs be a jump to the bottom of the loop (get back up to the top), but it makes no sense to jump back to the top, reset the condition, and then jump to the bottom of the loop if the condition is found to be false. The while-loop then, performs the following steps:

+   1. check the condition; if it is false, go to the end
2. perform the loop body
3. check the condition, if it is true, jump to 2.
4. if the condition is not true, full-through the end of the loop.

Here is a while-loop in C code:

```
while(x <= 10)
{
  x++;
}
```

And then there is that same loop translated into assembly:

```
mov eax, %x
cmp eax, 0xA
jg end
beginning:
inc eax
cmp eax, 0xA
jile beginning
end:
```

If we translate that assembly code back into C, we would get the following code:

```
if(x <= 10) //remember: in If statements, we reverse the condition
from the asm
{
  do
    x++;
  } while(x <= 10)
}
```

See why we covered the Do-While loop first? Because the While-loop becomes a Do-While when it gets assembled.
