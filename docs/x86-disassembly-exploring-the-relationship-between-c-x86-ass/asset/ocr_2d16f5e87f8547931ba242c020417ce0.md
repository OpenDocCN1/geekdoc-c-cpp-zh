# # 2 Disassemblers and Decompilers

# ## 2.1 What is a Disassembler?

w:Disassembler In essence, a **disassembler** is the exact opposite of an assembler. Where an assembler converts code written in an assembly language into binary machine code, a disassembler reverses the process and attempts to recreate the assembly code from the binary machine code.

Since most assembly languages have a one-to-one correspondence with underlying machine instructions, the process of disassembling is relatively straight-forward, and a basic disassembler can often be implemented simply by reading in bytes. Of course, disassembly has its own problems and pitfalls, which are covered later in this chapter.

Many disassemblers have the option to output assembly language instructions in Intel, AT&T, or (occasionally) HLA syntax. Examples in this book will use Intel and AT&T syntax interchangeably. We will typically not use HLA syntax for code examples, but that may change in the future.
