Our first question is this: are the parameters passed on the stack, or on the floating-point register stack, or some place different entirely? To question this, and this function is a knowledge of what fld and fstp do (Floating-Point Load) pushes a floating point value onto the FPU stack, while fstp (Floating-Point Store and Pop) moves a floating point value from ST0 to the specified location, and pops the value from ST0 off the stack. Remember that double values are 8-byte (QWORD), while floats are only stored as 4-byte values (DWORD). It is also important to remember that floating point numbers are not stored in a human-readable format in memory, unless the reader has a basic knowledge of binary. Remember, these aren't integers. Unfortunately, the exact format of floating point numbers is well beyond the scope of this chapter.

x is offset +8, y is offset +16, and z is offset +24 from eb. Therefore, y is pushed first, x is pushed last, and the parameters are passed right-to-left on the regular stack point stack.
