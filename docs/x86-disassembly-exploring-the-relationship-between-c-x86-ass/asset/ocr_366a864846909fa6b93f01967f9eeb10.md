This code looks a little complicated, but don't panic! We will walk through it slowly.
The first two lines of code set up the stack frame:

```
push ebp
mov ebp, esp
```

The next two lines of code compare the value of [ebp+8] (which we know to be the first parameter) to zero. If [ebp+8] is zero, the function jumps to the label 'error'. We will see that the label 'error' sets eax to 0, and returns. We Haven't seen it before, but this looks conspicuously like an if statement. If the parameter is zero, return 'error'.

If, on the other hand, the parameter is not zero, we move the value into eax, and then move the value into [ecax+0], which we know as the first data field in MyClass. We also see, from this code, that this first data field must be 4 bytes long (because we are using eax). After we move eax into [ecax+0], we set eax to 1 and jump to the end of the function.

If we use the MyClass definition as in question 1, above, we can get the following code for our function, `SetValue(int val)`

```
int MyClass::SetValue(int val)
{
  if(val == 0) return 0;
  this->value = val;
  return 1;
}
```

Notice that since we are returning a 0 on failure, and a 1 on success, the function looks like it has a bool return value. However, the return value is 4 bytes wide (eax is used), but the size of a bool is implementation-specific, so we can't be sure. The bool is usually defined to have a size of 1 byte, but it is often stored the same way as an int.
