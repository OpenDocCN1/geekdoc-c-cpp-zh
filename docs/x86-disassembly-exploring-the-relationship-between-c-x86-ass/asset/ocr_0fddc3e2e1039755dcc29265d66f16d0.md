# 23.4 Inline Functions

The C and C++ languages allow the definition of an inline type of function. Inline functions are functions which are treated similarly to macros. During compilation, calls to an inline function are replaced with the body of that function, instead of performing a call instruction. In addition to using the inline keyword to declare an inline function, optimizing compilers may decide to make other functions inline as well.

Function inline works similarly to loop unwinding for increasing code performance. A non-inline function requires a call instruction, several instructions to destroy the stack frame and return from the function. By copying the body of the function instead of making a call, the size of the code increases, but the execution time decreases.

It is not necessarily possible to determine identical portions of code were created originally as macros, inline functions, or were simply copy and pasted. However, when disassembling it can make your work easier to separate these blocks out into separate inline functions, to keep the code straight.
