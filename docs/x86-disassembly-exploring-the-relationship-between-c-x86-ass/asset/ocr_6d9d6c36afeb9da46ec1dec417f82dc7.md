For instance, let's say that in your program you consistently experience crashes after one particular event: immediately after closing a message box. You set breakpoints on all calls to MessageBoxA. You run your program with the breakpoints, and it stops, ready to call MessageBoxA. Executing each line one-by-one thereafter (referred to as *stepping*) through the code, and watching the program stack, you see that a buffer overflow occurs soon after the call.
