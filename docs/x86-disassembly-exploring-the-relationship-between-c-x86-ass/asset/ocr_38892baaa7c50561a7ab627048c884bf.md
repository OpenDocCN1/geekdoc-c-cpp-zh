# 14.2 Example: Identify Branch Structures

How many separate branch structures are in this function? What types are they? Can you give more descriptive names to _Label_1, _Label_2, and _Label_3, based on the structures of these branches?

```
push ebp
mov ebp, esp
mov eax, 0
mov ecx, [ebp + 8]
cmp ecx, 0
je _Label_1
inc eax
jmp _Label_2
:_Label_1
dec eax
:_Label_2
mov ecx, [ebp + 12]
cmp ecx, 0
je _Label_3
inc eax
:_Label_3
mov esp, ebp
pop ebp
ret
```

How many separate branch structures are there in this function? Stripping away the entry and exit sequences, here is the code we left:

```
mov ecx, [ebp + 8]
cmp ecx, 0
je _Label_1
inc eax
jmp _Label_2
:_Label_1
dec eax
:_Label_2
mov ecx, [ebp + 12]
cmp ecx, 0
je _Label_3
inc eax
:_Label_3
```
