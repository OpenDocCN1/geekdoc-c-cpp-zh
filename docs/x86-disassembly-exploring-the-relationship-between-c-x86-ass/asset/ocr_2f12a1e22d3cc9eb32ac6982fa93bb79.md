# 17.5 Signed and Unsigned Variables

Integer formatted variables, such as int, char, short and long may be declared or unsigned variables in the C source code. There are two differences in how variables are treated:

+   - Signed variables use instructions such as add, sub. Unsigned variables use unsigned arithmetic instructions such as addi, subi.
