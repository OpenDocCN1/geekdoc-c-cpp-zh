# Loop Examples

```
mov esi, [ebp + 8]
mov ebx, 0
mov eax, 0
mov ecx, 0
_Label_1:
mov ecx, [esi + ebx + 4]
add eax, ecx
inc ebx
cmp ebx, 100
jns _Label_1
mov esp, ebp
pop ebp
ret 4
```

Notice how the ret cleans its parameter off the stack? That means that this function is a STDCALL function. We know that the function takes, as its only parameter, a pointer to an array of integers. We do not know, however, whether the integers are signed or unsigned, because the je command is used for both types of values. We can assume one or the other, and for simplicity, we can assume unsigned values (unsigned and signed values, in this function, will actually work the same way). We also know that the return value is a 4-byte integer value, of the same type as is found in the parameter array. Since the function doesnt have a name, we can just call it 'MyFunction', and we can call the parameter 'array' because it is an array. From this information, we can determine the following prototype in C:

```
unsigned int STDCALL MyFunction(unsigned int *array);
```
