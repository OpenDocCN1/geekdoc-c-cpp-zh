# Objects and Classes

An example of what an object looks like in memory

**Figure 1:A:** The definition for the class "ABC123." This class has three integers, a, b, and c.
The constructor sets 'a' to equal 1, 'b' to equal 2, and 'c' to equal 3.

**Figure 1.B:** How the object ABC123 might be placed in memory, ordering the variables from the class. Memory address 0x00200000 there is a double integer (32 bits) with a value of 1, representing the 'a'. Memory address 0x00200004 has a double integer with a value of 2, representing the 'b'. And at memory address 0x00200008 there is a double integer with a value of 3, representing the 'c'.

However, the compiler typically needs the variables to be separated into sets that are multiples of a word (2 bytes) namely char arrays; some unused bits might be pad the variables so they meet this size requirement. This is illustrated in **Figure 2**.
