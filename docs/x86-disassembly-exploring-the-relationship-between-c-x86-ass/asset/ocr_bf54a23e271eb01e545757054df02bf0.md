# Further reading

+   • radare, the reverse engineering framework¹² includes open-source tools to disassemble code for many processors including x86, ARM, PowerPC, m68k, etc. several virtual machines including java, msil, etc., and for many platforms including Linux, BSD, OS, Windows, iPhoneOS, etc.

+   • IDA, the Interactive Disassembler¹³ (IDA Pro¹) can disassemble code for a huge number of processors, including ARM Architecture (including Thumb and Thumb-2), ATMEL, AVR, INTEL 8051, INTEL 8086, MOS Technologies 6502, MC6809, MC6811, M68H2C, MSP430, PIC 12XX, PIC 14XX, PIC 16XX, ZilogXX, Zilog Z80, etc.

+   • dmoz: "Disassemblers"⁵ lists a huge number of disassemblers

+   • Program transformation disassembly¹⁶ many highly recommended disassemblers

+   • Wikipedia: objdump¹⁷ of the GNU binutils, can disassemble code for several processors and platforms.

+   • search for "disassemble" at SourceForge¹⁸ shows many disassemblers for a variety of CPUs. Hopper¹⁹ is a disassembler that runs on OS-X and disassembles 32/64-bit OS-X and binaries.
