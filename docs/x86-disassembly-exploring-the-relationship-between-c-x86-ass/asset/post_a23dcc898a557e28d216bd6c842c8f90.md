
## 2.5 Common Decompilers

### Hex-Rays Decompiler

Hex-Rays is a commercial decompiler. It is made as an extension code to popular IDA-Pro dissassembler. It is currently the only commercially available decompiler which produces usable results. It supports both x86 and ARM architecture.

```
http://www.hex-rays.com/products/decompiler/index.html
```

### DCC Decompiler

Dcc is an excellent theoretical look at de-compilation, but it only supports small files.

```
http://www.itee.uq.edu.au/-cristina/dcc.html
```

### Boomerang Decompiler Project

Boomerang Decompiler is an attempt to make a powerful, retargetable decompiler. So far, it only decompiles to C with moderate success.

```
http://boomerang.sourceforge.net/
```

### Reverse Engineering Compiler (REC)

REC is a powerful 'decompiler' that decompiles native assembly code into a C-like code representation. The code is half-way between assembly and C, but it is much more readable than the pure assembly. Unfortunately the program appears to be rather unstable.

```
http://www.backstreet.com/rnc/rec.html
```

### ExeToC

ExeToC decompiler is an interactive decompiler that boasts pretty good results.

```
http://sourceforge.net/projects/exetoc
```

### Decompile-It

Decompile-It is a web-based decompiler for 32-bit Linux x86 executables compiled with -g

```
http://decompile-it.com
```

### 2.6.1 jump tables and other calculated jumps

Subroutines that use this technique adjust the return address to skip over the constant data, then return to an address many bytes after the 'call' instruction. One of the most famous programs that used this technique is the 'Sweet 16' virtual machine.

The technique may make disassembling more difficult.
