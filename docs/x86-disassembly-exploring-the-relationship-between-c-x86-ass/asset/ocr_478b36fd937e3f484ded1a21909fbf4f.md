# 13.4.2 The Compare and Jumps

```
cmp DWORD PTR tv64[ebp], 3
ja SHORT $L810
```

The value of the scratch pad is compared with the value 3, and if the unsigned value is above 3 (4 or more), execution jumps to label $L810. because ja is an unconditional jump. Let's look back at the original C code switch:

```
switch(argc)
  case 1:
    MyFunction(1);
    break;
  case 2:
    MyFunction(2);
    break;
  case 3:
    MyFunction(3);
    break;
  case 4:
    MyFunction(4);
    break;
  default:
    MyFunction(5);
```

Remember, the scratch pad contains the value (argc - 1), which means that this condition is only triggered when argc > 4. What happens when argc is greater than 4? The function goes to the default condition. Now, let's look at the next two lines:

```
mov edx, DWORD PTR tv64[ebp]
jmp DWORD PTR $L810[edx*4]
```

edx gets the value of the scratch pad (argc - 1), and then there is a weird jump that takes place: execution jumps to a location pointed to by value (edx * 4 + $L818). What is it $L818? We will examine that right now.

# 13.4.3 The Switch Table
