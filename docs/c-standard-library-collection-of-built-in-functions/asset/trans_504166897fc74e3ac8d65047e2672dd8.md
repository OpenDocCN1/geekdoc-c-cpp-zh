

```
time_t time(time_t *)
```

## 参数

- **seconds** -- 指向 `time_t` 类型对象的指针，秒值将存储在该对象中。

## 返回值

以 `time_t` 对象表示的当前日历时间。

## 示例

以下示例演示了 `time()` 函数的用法。

```
#include <stdio.h>
#include <time.h>

int main ()
{
    time_t seconds;

    seconds = time(NULL);
    printf("Hours since January 1, 1970 = %ld\n", seconds/3600);

    return(0);
}
```

让我们编译并运行上述程序，将产生以下结果：

```
Hours since January 1, 1970 = 393923
```
