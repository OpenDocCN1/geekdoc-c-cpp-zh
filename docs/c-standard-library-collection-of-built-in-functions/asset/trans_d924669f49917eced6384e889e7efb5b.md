## void clearerr(FILE *stream)

### Description

C 库函数 **void clearerr(FILE *stream)** 清除给定流的末尾文件和错误指示符。

### Declaration

以下是 clearerr() 函数的声明。

```c
void clearerr(FILE *stream)
```

### Parameters

- **stream** -- 这是指向标识流的 FILE 对象的指针。

### Return Value

这不应失败并且不会设置外部变量 *errno*，但如果检测到其参数不是有效的流，则必须返回 -1 并将 *errno* 设置为 EBADF。

### Example

以下示例展示了 clearerr() 函数的用法。

```c
#include <stdio.h>

int main()
{
   FILE *fp;
   char c;

   fp = fopen("file.txt", "w");

   c = fgetc(fp);
   if( ferror(fp) )
   {
      printf("Error in reading from file : file.txt\n");
   }

   clearerr(fp);
   if( ferror(fp) )
   {
      printf("Error in reading from file : file.txt\n");
   }
   fclose(fp);

   return(0);
}
```

## int feof(FILE *stream)

### Description

C 库函数 int feof(FILE *stream) 测试给定流的末尾文件指示符。

### Declaration

以下是 feof() 函数的声明。

```c
int feof(FILE *stream)
```

### Parameters

- stream -- 这是指向标识流的 FILE 对象的指针。

### Return Value

当与流关联的末尾文件指示符被设置时，此函数返回非零值，否则返回零。

### Example

以下示例展示了 feof() 函数的用法。

```c
#include <stdio.h>

int main ()
{
    FILE *fp;
    int c;

    fp = fopen("file.txt","r");
    if(fp == NULL)
    {
        perror("Error in opening file");
        return(-1);
    }
    while(1)
    {
        c = fgetc(fp);
        if( feof(fp) )
        {
            break ;
        }
        printf("%c", c);
    }
    fclose(fp);
    return(0);
}
```

## int fgetpos(FILE *stream, fpos_t *pos)

### Description

C 库函数 int fgetpos(FILE *stream, fpos_t *pos) 获取流的当前文件位置并将其写入 pos。

### Declaration

以下是 fgetpos() 函数的声明。

```c
int fgetpos(FILE *stream, fpos_t *pos)
```

### Parameters

- stream -- 这是指向标识流的 FILE 对象的指针。
- pos -- 这是指向 fpos_t 对象的指针。

### Return Value

此函数在成功时返回零，否则在出错时返回非零值。

### Example

以下示例展示了 fgetpos() 函数的用法。

```c
#include <stdio.h>

int main ()
{
    FILE *fp;
    fpos_t position;

    fp = fopen("file.txt","w+");
    fgetpos(fp, &position);
    fputs("Hello, World!", fp);

    fsetpos(fp, &position);
    fputs("This is going to override previous content", fp);
    fclose(fp);

    return(0);
}
```

## FILE *fopen(const char *filename, const char *mode)

### Declaration

```c

```

### Parameters

- **filename** -- 这是包含要打开的文件名的 C 字符串。
- **mode** -- 这是包含文件访问模式的 C 字符串。它包括：

| "r+" | 打开文件以便同时进行读写。文件必须存在。 |
| "w+" | 创建一个空文件用于读写。 |
| "a+" | 打开文件以便读取和追加。 |
