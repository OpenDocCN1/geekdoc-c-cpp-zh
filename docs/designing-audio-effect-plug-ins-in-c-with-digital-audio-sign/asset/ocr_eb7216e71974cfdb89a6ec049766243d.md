# 13.1 Design a Compressor/Limiter Plug-In

We are going to build a complete dynamics processor with the following features and functions:

+   - Compressor
+   - Limiter
+   - Expander
+   - Gate
+   - Analog or digital time constant
+   - Attack, release controls for detector
+   - Threshold, ratio controls for gain computer
+   - Knee-width control: 0 = hard knee processing
+   - Gain reduction meter to view the reduction

You'll notice a new feature in this plug-in: the ability to monitor a signal and display it on a meter. We will start with the compressor/limiter function and build up from there.
