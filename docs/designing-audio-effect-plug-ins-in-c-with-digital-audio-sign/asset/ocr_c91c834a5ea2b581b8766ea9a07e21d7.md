$H(\omega) = 0.5 + 0.5e^{-j\omega 1}
= 0.5 + 0.5(\cos(\omega) - j\sin(\omega))
= 0.5 + 0.5(\cos(0) - j\sin(0))
= 0.5 + 0.5(1 - j0)
= 1.0 + j0$

Find the magnitude and phase at this frequency:

$|H(\omega)| = \sqrt{(a+jb)(a-jb)}
= \sqrt{(1+j0)(1-j0)}
= 1.0
\text{Arg}(H) = \tan^{-1}(b/a)

# 5.5.2 Nyquist ($\pi$)

$H(\omega) = 0.5 + 0.5e^{-j\omega 1}
= 0.5 + 0.5(\cos(\omega) - j\sin(\omega))
= 0.5 + 0.5(\cos(\pi) - j\sin(\pi))
= 0.5 + 0.5(-1 - j0)
= 0 + j0$

$|H(\omega)| = \sqrt{(a+jb)(a-jb)}
= \sqrt{(0+j0)(0-j0)}
= 0.0
\text{Arg}(H) = \tan^{-1}(b/a)
= \tan^{-1}(0/0)
= 0^*$
