\(\theta_c = 2\pi f_c / f_s\)
\(\alpha = \frac{\tan(\pi Q(f_i) - 1}{\tan(\pi Q(f_i)) + 1}\)
\(\beta = -\cos \theta_c\)
\(a_0 = -\alpha\)
\(a_1 = \beta(1-\alpha)\)
\(a_2 = 1.0\)
\(b_1 = \beta(1-\alpha)\)
\(b_2 = -1.0\)
(12.3)
