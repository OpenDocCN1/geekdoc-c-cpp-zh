For BPF and BSF:

+   - Specify \(\omega_{dL}\) and \(\omega_{dH}\), the lower and upper corner frequencies of the digital filter.
+   - Calculate the two analog corner frequencies with Equation 6.16:

```
\(\omega_{al} = \tan \left[ \frac{\omega_{dl} f_s}{2} \right]\)
\(\omega_{aH} = \tan \left[ \frac{\omega_{dH} f_s}{2} \right]\)
\(\omega_0^2 = \omega_{al} \omega_{aH}\)
\(W = \omega_{aH} - \omega_{al}\)
(6.16)
```

Next, scale the filter with Equation 6.17:

| Filter Type | Scaling Factor |
| :--- | :--- |
| LPF | \(s = \frac{s}{\omega_a}\) |
| HPF | \(s = \frac{\omega_a}{s}\) |
| BPF | \(s = \frac{s^2 + \omega_0^2}{Ws}\) |
| BSF | \(s = \frac{Ws}{s^2 + \omega_0^2}\) |
(6.17)
