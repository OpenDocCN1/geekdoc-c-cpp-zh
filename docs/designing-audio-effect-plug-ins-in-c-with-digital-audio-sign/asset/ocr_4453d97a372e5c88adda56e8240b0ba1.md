First, get the transfer function in a form to use for all the evaluation frequencies (Equation 5.83). Then evaluate at our four frequencies.

```
H(z) = \frac{a_0 + a_1 z^{-1}}{1 + b_1 z^{-1}}
= \frac{1 - 0.92 z^{-1}}{1 - 0.71 z^{-1}}
Let z = e^{j\omega}
H(\omega) = \frac{1 - 0.92 e^{-j\omega}}{1 - 0.71 e^{-j\omega}}
(5.83)
```

Apply Euler's equation:

```
H(\omega) = \frac{1 - 0.92 e^{-j\omega}}{1 - 0.71 e^{-j\omega}}
H(\omega) = \frac{1 - 0.92[\cos(\omega) - j\sin(\omega)]}{1 - 0.71[\cos(\omega) - j\sin(\omega)]}
```
