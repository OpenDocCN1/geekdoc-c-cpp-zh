# processAudioFrame()

The logic for the signal processing of one channel will be as follows:

+   - Read the delayed value x(n – 1) out of the \( z^{-1} \) element.
+   - Implement the difference equation.
+   - Write the current input x(n) into the delay variable; it will be x(n – 1) next time around.
+   - Do this for both channels.
