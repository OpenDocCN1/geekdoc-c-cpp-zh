# 6.6.7 First- and Second-Order APF

Specify:

+   - fc, corner frequency
+   - Q, steepness of phase shift at fc (second-order only)

The design equations are as follows:

| First-Order APF | Second-Order APF |
|---|---|
| \(\alpha = \frac{\tan(\pi f_c / f_s) - 1}{\tan(\pi f_c / f_s) + 1}\) | \(\alpha = \frac{\tan(\pi Q f_c / f_s) - 1}{\tan(\pi Q f_c / f_s) + 1}\) |
| | \(\beta = -\cos \theta_c\) |
| \(a_0 = \alpha\) | \(a_0 = -\alpha\) |
| \(a_1 = 1.0\) | \(a_1 = \beta(1 - \alpha)\) |
| \(a_2 = 0.0\) | \(\alpha_2 = 1.0\) |
| \(b_1 = \alpha\) | \(b_1 = \beta(1 - \alpha)\) |
| \(b_2 = 0.0\) | \(b_2 = -\alpha\) |
