# 5.7 The z Substitution

It’s going to get messy having to write $e^{j\omega}$ so often and we know $e^{j\omega}$ behaves like a polynomial mathematically. So, we can simplify the equations by making a simple substitution of Equation 5.24.

```
$z = e^{j\omega}$ (5.24)
```

This is just a substitution right now and nothing else. Making the substitution in Equation 5.24 and noting the resulting transfer function is now a function of z, not $\omega$, we can write it like Equation 5.25:

```
$H(z) = a_0 + a_1 z^{-1}$ (5.25)
```
