The design equations are as follows:

| LPF | HPF |
| --- | --- |
| \(\theta_c = 2\pi f_c/f_s\) | \(\theta_c = 2\pi f_c/f_s\) |
| \(\gamma = 2 - \cos(\theta_c)\) | \(\gamma = 2 + \cos(\theta_c)\) |
| \(b_1 = \sqrt{\gamma^2 - 1} - \gamma\) | \(b_1 = \gamma - \sqrt{\gamma^2 - 1}\) |
| \(a_0 = 1 + b_1\) | \(a_0 = 1 - b_1\) |
