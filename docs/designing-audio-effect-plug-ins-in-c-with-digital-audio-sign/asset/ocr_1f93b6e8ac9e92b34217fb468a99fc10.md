# 9.6.2 WTOscillator.cpp File

# Constructor

+   • These three new wave tables will be bipolar like the sinusoid table and swing between –1.0 and +1.0, and they will all start with the first sample = 0.0.

```
CMTOscillator::CMTOscillator()
{
    m_PlugInName = "WTOscillator";

    // set our oscillator flag:
    this->m_bOutputOnlyPlugIn = true;

    // slope and y-intercept values for the
    // Triangle Wave
    // rising edge1:
    float mt1 = 1.0/256.0;
    float bt1 = 0.0;

    // rising edge2:
    float mt2 = 1.0/256.0;
    float bt2 = -1.0;

    // falling edge:
    float mtf2 = -2.0/512.0;
    float btf2 = +1.0;

    // Sawtooth
    // rising edge1:
    float ms1 = 1.0/512.0;
    float bs1 = 0.0;

    // rising edge2:
    float ms2 = 1.0/512.0;
    float bs2 = -1.0;
```
