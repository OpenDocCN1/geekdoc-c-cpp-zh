H(ω) = 1 - 1.27[cos(ω) - jsin(ω)] + 0.81[cos(2ω) - jsin(2ω)]
= 1 - 1.27[cos(0) - jsin(0)] + 0.81[cos(2*0) - jsin(2*0)]
= 1 - 1.27[1 - j0] + 0.81[1 - j0]
= 1 - 1.27 + 0.81
= 0.54 + j0
(5.61)

|H(ω)| = √(a² + b²)
= √(0.54² + 0²)
= 0.54
(5.62)

Arg(H) = tan⁻¹(b/a)
= tan⁻¹(0/0.54)
= 0.0°

The exact magnitude is 0.54, which is pretty close to our estimated value of 0.49 using the z-plane graphical method.

# 5.17.2 Nyquist (π)

H(ω) = 1 - 1.27[cos(ω) - jsin(ω)] + 0.81[cos(2ω) - jsin(2ω)]
= 1 - 1.27[cos(π) - jsin(π)] + 0.81[cos(2π) - jsin(2π)]
= 1 - 1.27[-1 - j0] + 0.81[1 - j0]
= 1 + 1.27 + 0.81
= 3.08
(5.63)

|H(ω)| = √(a² + b²)
= √(3.08² + 0²)
= 3.08
(5.64)

Arg(H) = tan⁻¹(b/a)

= 0.0°

The exact magnitude is 3.08, which is pretty close to our estimated value of 3.1 using the z-plane graphical method.
