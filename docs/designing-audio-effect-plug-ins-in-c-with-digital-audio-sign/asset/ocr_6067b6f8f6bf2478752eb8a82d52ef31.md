# 5.5.3 ½ Nyquist (π/2)

```
H(ω) = 0.5 + 0.5e^(-jω1)
   = 0.5 + 0.5(cos(ω) – jsin(ω))
   = 0.5 + 0.5(cos(π/2) – jsin(π/2))
   = 0.5 + 0.5(0 – j1)
   = 0.5 – j0.5			(5.20)
```

```
|H(ω)| = √(a + jb)(a – jb)
   = √(0.5 + j0.5)(0.5 – j0.5)
   = √0.25 + 0.25 = √0.5
   = 0.707				(5.21)
```

```
Arg(H) = tan^(-1)(b/a)
   = tan^(-1)(–0.5/0.5)
   = –45°
```

Compare this to the last chapter's graphical results (Figure 5.14); the magnitude is 0.707 with a phase shift of –45 degrees, and the results agree.
