- Locate each evaluation frequency on the outer rim of the unit circle.

## Step 5: Direct evaluation

Now you can evaluate the filter the same way as before using Euler's equation to separate the real and imaginary components from the transfer function. Evaluate at the following frequencies:

- DC: 0
- Nyquist: \(\pi\)
- ½ Nyquist: \(\pi/2\)
- ¼ Nyquist: \(\pi/4\)

First, get the transfer function in the form of Equation 5.60 to use for all the evaluation frequencies:

```
H(z) = a_0(1 + \alpha_1 z^{-1} + \alpha_2 z^{-2})
Where: \alpha_1 = \frac{a_1}{a_0} \quad \alpha_2 = \frac{a_2}{a_0}
H(z) = 1 - 1.27z^{-1} + 0.81z^{-2}
Let: z = e^{j\omega}
H(\omega) = 1 - 1.27e^{-j1\omega} + 0.81e^{-j2\omega}   (5.60)
```

Apply Euler's Equation:

```
H(\omega) = 1 - 1.27[\cos(\omega) - j\sin(\omega)] + 0.81[\cos(2\omega) - j\sin(2\omega)]
```

Now evaluate for each of our four frequencies in Equations 5.61 through 5.68.

### 5.17.1 DC (0 Hz)

H(ω) = 1 - 1.27[cos(ω) - jsin(ω)] + 0.81[cos(2ω) - jsin(2ω)]
= 1 - 1.27[cos(0) - jsin(0)] + 0.81[cos(2*0) - jsin(2*0)]
= 1 - 1.27[1 - j0] + 0.81[1 - j0]
= 1 - 1.27 + 0.81
= 0.54 + j0
(5.61)

|H(ω)| = √(a² + b²)
= √(0.54² + 0²)
= 0.54
(5.62)

Arg(H) = tan⁻¹(b/a)
= tan⁻¹(0/0.54)
= 0.0°

The exact magnitude is 0.54, which is pretty close to our estimated value of 0.49 using the z-plane graphical method.

### 5.17.2 Nyquist (π)

H(ω) = 1 - 1.27[cos(ω) - jsin(ω)] + 0.81[cos(2ω) - jsin(2ω)]
= 1 - 1.27[cos(π) - jsin(π)] + 0.81[cos(2π) - jsin(2π)]
= 1 - 1.27[-1 - j0] + 0.81[1 - j0]
= 1 + 1.27 + 0.81
= 3.08
(5.63)

|H(ω)| = √(a² + b²)
= √(3.08² + 0²)
= 3.08
(5.64)

Arg(H) = tan⁻¹(b/a)
= tan⁻¹(0/3.08)
= 0.0°

The exact magnitude is 3.08, which is pretty close to our estimated value of 3.1 using the z-plane graphical method.

### 5.17.3 ½ Nyquist (π/2)

H(ω) = 1 - 1.27[cos(ω) - jsin(ω)] + 0.81[cos(2ω) - jsin(2ω)]
= 1 - 1.27[cos(π/2) - jsin(π/2)] + 0.81[cos(2π/2) - jsin(2π/2)]

## Step 6: z transform of impulse response

This second-order feed-forward filter is actually pretty easy to examine for its impulse response. For an impulse stimulus, the impulse response h(n) is h(n) = {1.0, -1.27, 0.81}. Taking the z transform of the impulse response is easy, as shown in Equation 5.69:

```
H(z) = \sum_{n=-\infty}^{+\infty} h(n)z^{-n}
= 1.0z^0 - 1.27z^{-1} + 0.81z^{-2}
= 1 - 1.27z^{-1} + 0.81z^{-2}
```

This is exactly what we expect. This should help you understand two more very important details about pure feed-forward filters.

## 5.18 Second-Order Feed-Back Filter

Analysis of the second-order feed-back filter starts with the block diagram and difference equation. Figure 5.42 shows the topology of a second-order feed-back filter.

The difference equation is as follows:

```
y(n) = a_0x(n) - b_1y(n - 1) - b_2y(n - 2) (5.70)
```

Steps 1 to 3: Take the z transform of the difference equation to get the transfer function, then factor out a_0 as the scalar gain coefficient

We'll continue to combine steps. Once again, the z transform can be taken by inspection using the rules from Section 5.8, and then you need to get it into the form Y(z)/X(z) for the transfer function in Equation 5.71.

```
y(n) = a_0x(n) - b_1y(n - 1) - b_2y(n - 2)
Y(z) = a_0X(z) - b_1Y(z)z^{-1} - b_2Y(z)z^{-2}
```

Separate variables:

$$Y(z) + b_1 Y(z)z^{-1} + b_2 Y(z)z^{-2} = a_0 X(z)$$
$$Y(z)[1 + b_1 z^{-1} + b_2 z^{-2}] = a_0 X(z)$$
(5.71)

Form transfer function:

$$H(z) = \frac{Y(z)}{X(z)} = \frac{a_0}{1 + b_1 z^{-1} + b_2 z^{-2}}$$

Factor out $a_0$:

$$H(z) = a_0 \frac{1}{1 + b_1 z^{-1} + b_2 z^{-2}}$$

![](img/b54974d0a4317ec82d7ae02126d10a6f_146_0.png)

Figure 5.42: Second-order feed-back filter.

### Step 4: Estimate the frequency response

Now you can see why the feed-back filter block diagrams have all the $b$ coefficients negated. It puts the quadratic denominator in the final transfer function in Equation 5.71 in the same polynomial form as the numerator of the feed-forward transfer function. Thus, you can use the same logic to find the poles of the filter; since the coefficients $b_1$ and $b_2$ are real values, the poles must be complex conjugates of each other, as shown in Equation 5.72:

$$H(z) = a_0 \frac{1}{1 + b_1 z^{-1} + b_2 z^{-2}}$$

can be factored as

$$H(z) = a_0 \frac{1}{(1 - P_1 z^{-1})(1 - P_2 z^{-1})}$$

where

$$P_1 = \text{Re}^{j\theta}$$
$$P_2 = \text{Re}^{-j\theta}$$
$$(1 - P_1 z^{-1})(1 - P_2 z^{-1}) = 1 - 2R\cos(\theta)z^{-1} + R^2 z^{-2}$$
(5.72)

therefore

```
H(z) = a_0 \frac{1}{1 + b_1 z^{-1} + b_2 z^{-2}}
= a_0 \frac{1}{(1 - 2R \cos(\theta)z^{-1} + R^2 z^{-2})}
```

and

```
b_1 = -2R \cos(\theta)
b_2 = R^2
```

This results in two poles, \(P_1\) and \(P_2\), located at complex conjugate positions in the \(z\)-plane.

Figure 5.43 shows an arbitrary conjugate pair of poles plotted in the \(z\)-plane. You can see how they are at complementary angles to one another with the same radii.

To estimate we'll need some coefficients to test with. Use the following: \(a_0 = 1.0, b_1 = -1.34, b_2 = 0.902\). Now, calculate the location of the poles from Equation 5.72:

```
R^2 = b_2 = 0.902 \qquad (5.73)
R = \sqrt{0.902} = 0.95
```

then

```
-2R \cos(\theta) = -1.34
2(0.95) \cos(\theta) = 1.34
```
