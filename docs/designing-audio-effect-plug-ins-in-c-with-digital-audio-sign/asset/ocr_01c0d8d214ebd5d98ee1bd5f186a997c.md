Filtering the feedback loop in the frequency domain is done by simply multiplying the LPF transfer function by the feedback term \(g_1 z^{-D}\) in Equation 11.23.

```
H(z) = \frac{z^{-D}}{1 - H_{LP}(z) g_1 z^{-D}}
= \frac{z^{-D}}{1 - g_1 z^{-D} \frac{1}{1 - g_2 z^{-1}}}
= \frac{z^{-D}}{1 - \frac{g_1 z^{-D}}{1 - g_2 z^{-1}}}
\frac{Y(z)}{X(z)} = \frac{z^{-D}}{1 - \frac{g_1 z^{-D}}{1 - g_2 z^{-1}}}
(11.23)
```
