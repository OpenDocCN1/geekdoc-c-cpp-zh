# 8.11 Numerical Method FIR Filters

The last type of FIR filters consists of numerical methods and is not based on IRs or convolution, even though many of them implement a convolution loop. There are books full of numerical methods for performing all kinds of operations, from integration and differentiation to moving averages and interpolation. In this section we will examine a few algorithms and if it interests you, get a book on numerical methods and you will have a plethora of algorithms to try out. Some of these filters can be implemented as FIR topologies while others are better suited for a straight mathematical function call.

# 8.11.1 Moving Average Interpolator

Choose:

N = number of points to interpolate, minimum = 2

Calculate:

$a_k = \frac{1}{N}, \text{where } 0 \le k \le N - 1$ (8.8)

The moving average interpolator (or MA filter) in Figure 8.28 implements a sliding window of N samples wide, over which the input samples are averaged. Each sample gets an equal weight of 1/N.

Example: Design a five-point MA filter.

Solution:

$N = 5, \text{so } a_k = 1/5 = 0.20$
