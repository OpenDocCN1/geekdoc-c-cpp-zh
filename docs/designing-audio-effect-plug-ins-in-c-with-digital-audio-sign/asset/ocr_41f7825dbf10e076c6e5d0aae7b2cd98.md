problem, N-channel mixing circuits incorporate attenuators to reduce the size of the inputs, where the attenuation value is 1/N. When mixing two channels, the attenuators each have a value of ½ while a three-channel mixer would have attenuators with a value of 1/3 on each mixing branch. If all channels happen to have a maximum or minimum value at the same time, their sum or difference will still be limited to ±1.
