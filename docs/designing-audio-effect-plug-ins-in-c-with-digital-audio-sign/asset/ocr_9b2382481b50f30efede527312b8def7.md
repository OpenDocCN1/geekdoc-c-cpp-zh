Y(z) + b_1Y(z)z^{-1} = a_0X(z) + a_1X(z)z^{-1}
Y(z)[1 + b_1z^{-1}] = X(z)[a_0 + a_1z^{-1}]

Form the transfer function:

H(z) = \frac{Y(z)}{X(z)} = \frac{a_0 + a_1z^{-1}}{1 + b_1z^{-1}}

Factor out $a_0$:

H(z) = a_0 \frac{1 + \alpha_1z^{-1}}{1 + b_1z^{-1}}

where

\alpha_1 = \frac{a_1}{a_0}
