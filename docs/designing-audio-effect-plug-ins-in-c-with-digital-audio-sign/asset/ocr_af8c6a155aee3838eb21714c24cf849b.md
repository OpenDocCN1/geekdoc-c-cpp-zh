In the second design, we will modify the current plug-in to include the modulation of the LPF Q value. We will use a second, independent LFO for the Q but will share the same LFO waveform type with the fc LFO. The block diagram is shown in Figure 12.6.

The parameters are as follows:

+   * fc mod rate (0.2 to 10 Hz)
+   * fc mod depth (0 to 100%)
+   * Q mod rate (0.2 to 10 Hz)
+   * Q mod depth (0 to 100%)
+   * LFO type (sine, tri, saw, square)
+   * fc mod range: 100 Hz to = kHz
+   * Q mod range: 0.5 to 10
+   * LPF is fixed as second-order bi-quad
