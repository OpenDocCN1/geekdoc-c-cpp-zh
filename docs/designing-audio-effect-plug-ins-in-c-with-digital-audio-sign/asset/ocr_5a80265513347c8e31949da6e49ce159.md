# 2.3 C and C++ Style DLLs

A DLL written in the C programming language consists of a set of stand-alone functions. There is no main() function. The functions can be defined and implemented in one. c file or can be broken into an interface file (.h) and implementation file (.c)—either way, the DLL performs a set of isolated functions. A problem with using the C programming language to write a DLL is the persistence of data. In C (and C++) the curly brackets {} define the scope of a function.

A fundamental problem is that the data declared inside a function cannot persist from one call to the next. One solution involves using global variables, which is generally frowned upon.
