# Step 5: Direct evaluation

Now you can evaluate the filter the same way as before using Euler's equation to separate the real and imaginary components from the transfer function. Evaluate at the following frequencies:

+   - DC: 0
+   - Nyquist: \(\pi\)
+   - ½ Nyquist: \(\pi/2\)
+   - ¼ Nyquist: \(\pi/4\)

First, get the transfer function in the form of Equation 5.60 to use for all the evaluation frequencies:

```
H(z) = a_0(1 + \alpha_1 z^{-1} + \alpha_2 z^{-2})
Where: \alpha_1 = \frac{a_1}{a_0} \quad \alpha_2 = \frac{a_2}{a_0}
H(z) = 1 - 1.27z^{-1} + 0.81z^{-2}
Let: z = e^{j\omega}
H(\omega) = 1 - 1.27e^{-j1\omega} + 0.81e^{-j2\omega}   (5.60)
```

Apply Euler's Equation:

```
H(\omega) = 1 - 1.27[\cos(\omega) - j\sin(\omega)] + 0.81[\cos(2\omega) - j\sin(2\omega)]
```
