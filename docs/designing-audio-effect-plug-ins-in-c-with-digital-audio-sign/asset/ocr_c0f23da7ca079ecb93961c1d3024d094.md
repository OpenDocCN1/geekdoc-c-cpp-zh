We wish to convert an analog transfer function H(s) into a sampled equivalent H(z). Effectively, this means we need a way to sample the continuous s-plane to produce the sampled z-plane version. In other words, we need to create a sampled analog transfer function H<sub>s</sub>(s) where the subscript s stands for “sampled.” We seek to find a function g(z) such that Equation 6.9 holds true.

```
H(s) \xrightarrow{s=g(z)} H(z) \tag{6.9}
```

Since the sample interval is T, then the term \(e^{j\omega T}\) would correspond to one sample in time. So, if we evaluate H(z) by letting \(z = e^{j\omega T}\) then we will arrive at the sampled analog transfer function H<sub>s</sub>(s) in Equation 6.10:

```
H(s) \xrightarrow{s=g(z)} H(z) \xrightarrow{z=e^{j\omega T}} H_s(s) \tag{6.10}
```

To solve, we note that s = j\(\omega\) (the analog definition of s) and z = \(e^{j\omega T}\) to get Equation 6.11:

```
z = e^{sT} \\
ln(z) = ln(e^{sT}) \\
ln(z) = sT \tag{6.11}
```
