If you know the IR of a system h(n), you can convolve it with the input signal x(n) to produce the output signal y(n). This is the equivalent of multiplying the transfer function H(z) with the input signal X(z) to produce the output Y(z). Thus convolution in the time domain is multiplication in the frequency (z) domain (Equation 8.4).
