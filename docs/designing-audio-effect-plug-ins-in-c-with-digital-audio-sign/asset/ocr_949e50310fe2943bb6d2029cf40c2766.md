# 13.4 Stereo-Linking the Dynamics Processor

You can see from the block diagram and your own code that our stereo dynamics processor shares all of the controls: gains, attack, release, threshold, and ratio. However, the ultimate value of the dynamic gain factor G(n) really depends on the audio content of each channel, which is fed into the independent left and right detectors.
