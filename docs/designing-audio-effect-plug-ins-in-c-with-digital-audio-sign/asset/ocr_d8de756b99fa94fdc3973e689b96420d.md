$K = \tan(\pi f_c/f_s)$
$V_0 = 10^{boost/cut \, dB/20}$
$d_0 = 1 + \frac{1}{Q}K + K^2$ (6.43)
$e_0 = 1 + \frac{1}{V_0 Q}K + K^2$

| $\beta = 2(K^2 - 1)$ | $a_1 = \frac{\beta}{d_0}$ | $a_1 = \frac{\beta}{e_0}$ |

| $\delta = 1 - \frac{1}{Q}K + K^2$ | $b_1 = \frac{\beta}{d_0}$ | $b_1 = \frac{\beta}{e_0}$ |
