+   - Shelving filters
+   - Parametric EQ
+   - Graphic EQ

These all require a slightly modified bi-quad structure. The reason is that these filters require mixing the original, unfiltered input directly with the output in a mix ratio. The ratio is controlled by two more coefficients, c0 and d0.
