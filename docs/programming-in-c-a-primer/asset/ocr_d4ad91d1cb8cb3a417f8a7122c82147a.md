# 19.2

In the C# program given below, a show method is defined for displaying a string in the console window. A thread with the name th is also created in the program using the constructor of the Thread class. Identify the error in the program and specify the reason for the error.

```
using System;
using System.Collections.Generic;
using System.Text;

namespace debugApp2_chap19
{
    class Program
    {
        static void Main(string[] args)
        {
            Thread th = new Thread(new ThreadStart(show));
            th.Start(); // Run Go() on the new thread.
            th.show(); // Simultaneously run Go() in the main thread.
        }
        static void show() {
            Console.WriteLine("This is a thread start program!");
        }
    }
}
```
