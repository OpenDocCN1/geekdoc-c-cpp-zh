# Program 18.4 | USING MULTIPLE CATCH BLOCKS

```
using System;
class Error4
{
	public static void Main()
	{
		int [] a = {5,10};
		int b = 5;
		try
		{
			int x = a[2] / b - a[1];
		}
		catch(ArithmeticException e)
		{
			Console.WriteLine("Division by zero");
		}
		catch(IndexOutOfRangeException e)
		{
			Console.WriteLine("Array index error");
		}
		catch(ArrayTypeMismatchException e)
		{
			Console.WriteLine("Wrong data type");
		}
		int y = a[1] / a[0];
		Console.WriteLine("y = " + y);
	}
}
```

Program 18.4 uses a chain of catch blocks and, when run, produces the following output:

Array index error
y = 2

Note that the array element a[2] does not exist because array a is defined to have only two elements, a[0] and a[1]. Therefore, the index 2 is outside the array boundary thus causing the block catch(IndexOutOfRangeException e) to catch and handle the error. The remaining catch blocks are skipped.
