## 目标

该应用程序为 ASP.NET Web 应用程序创建自定义投票控件。目标是将投票或投票程序的整个功能封装在自定义用户定义控件中，以便可以轻松地在不同的 Web 应用程序中重复使用。创建投票控件应用程序涉及的各个步骤是：

- 1. 创建网站
- 2. 创建 Web 用户控件（.ascx 文件）
- 3. 在 Web.Config 文件中注册控件
- 4. 在 Default.aspx Web 页面中使用自定义控件
- 5. 运行网站
