```
var NAME = EXPR;
var NAME1 = EXPR1, NAME2 = EXPR2;
```

The identifier var is a contextual keyword in the context of local variable declarations. The type of an implicitly typed local variable is inferred from the type of the associated initializer expression.

A discard variable _ may be used as an implicitly declared variable, for example, when you intend to ignore the result of an expression. Discard variables are often used in or in pattern matching. Here’s a trivial example.

```
var _ = 1 + 2;
```
