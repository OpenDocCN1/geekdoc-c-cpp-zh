# 3.3.4. Real literals

Real literals are used to write values of floating point types float and double as well as

```
1_234.567
1000d
10.5e5f
19.99m
```

①
A double literal.

②
A double literal. Can use the suffix, d or

③
A float literal. Uses the suffix, f or

④
A decimal literal. Uses the suffix, m or

Non-consecutive underscores _ can be used in the real literals as well, except for the beginning and ending positions of both integer and fraction parts. Underscores do not affect the values of the real literals.
