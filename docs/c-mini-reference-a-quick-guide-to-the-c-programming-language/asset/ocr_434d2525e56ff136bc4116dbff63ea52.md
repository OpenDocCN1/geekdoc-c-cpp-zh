# 4.1. Namespace Declarations

As of C# 10 and later, a namespace can be declared with or without an explicit block. The scope of the namespace without a block extends to the entire compilation unit/file. The "normal" block-scoped namespace consists of the keyword a namespace name and body, and an optional semicolon For example,

```
namespace War {
    // Any member declarations
}
```

The file-scoped namespace, on the other hand, starts with the keyword a name, and a semicolon The rest of the compilation unit follows the same general structure, e.g., zero or more extern alias directives, using directives (but, not global using directives), followed by any member type declarations, and they all belong to this namespace. For instance,

```
namespace Peace;
// ...
```
