# ### 10.4. Native Integer Types

C# now include two new new contextual keywords, nint and which represent native signed and native unsigned integer types, respectively, which are intended for use in low-level libraries. These [contextual keywords](#) are only treated as keywords when name lookup does not find a viable result at that program location.

The C# types nint and nuint correspond to the underlying .NET types System.IntPtr and respectively, with compiler support for additional conversions and operations for those types as native integer types on a specific platform, or operating system.
