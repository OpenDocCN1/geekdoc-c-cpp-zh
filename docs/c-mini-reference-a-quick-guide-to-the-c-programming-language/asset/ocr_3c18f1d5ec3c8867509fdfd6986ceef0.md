# 11.1. Quoted String Literals

String literals can be written in three different forms in C#, namely, quoted, verbatim, and raw string literals. In addition, there is a special literal syntax for "UTF-8 encoded which is new in C# 11. Quoted string literals start and end with double quotation marks A quoted string literal must escape certain special characters, e.g., \n for a newline and \t for a tab, etc.
