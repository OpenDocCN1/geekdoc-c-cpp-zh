
## 2.2. 顶级语句

自 C# 9 起，程序中的一个源文件可以使用顶级语句，只要该程序不包含任何其他入口点方法。它是一种语法糖，有助于移除一些样板代码。顶级语句会自动包装在隐式定义的启动类的 Main 方法中。

顶级语句可以使用类型为 string[] 的隐式定义变量 args 访问命令行参数。

如果顶级语句返回整数值，该值将成为返回给操作系统/运行时的整数返回代码。

顶级语句可以包含异步表达式。

例如，

```
Console.WriteLine("Hello World");
```

一个包含这一行代码的文件，使用自 C# 10 起可用的隐式全局 using 特性，大致等价于如下内容：

```
namespace Namespace1 {
    class Program {
        static void Main(string[] args) {
            Console.WriteLine("Hello World!");
        }
    }
}
```

自 C# 11 起，存在一些限制：

- 应用程序中只能有一个文件使用顶级语句。
- 该文件中的所有顶级语句都应放在任何其他命名空间成员（例如类型声明）之前。
- 程序不能同时具有顶级语句和显式入口点，例如 Main 方法。

## 2.3. 声明

C# 程序由一系列命名空间组成。命名空间可以包含其他声明，即“成员”。当非命名空间成员声明包含在未显式指定封闭命名空间的程序中时，它们属于“全局命名空间”。

命名空间成员可以是类型声明或其他（嵌套）命名空间声明。类型声明用于定义类、结构体、记录、枚举、接口和委托。类型声明可以包含其他成员。例如，类声明可以包含常量、字段、属性、事件、索引器、运算符、方法、实例构造函数和静态构造函数、终结器以及其他嵌套类型的声明。

## 2.5. 块和作用域

### 2.5.1. 作用域

C# 是一种词法作用域语言。名称的作用域被静态确定为程序文本的特定区域，在该区域内，无需限定名称即可引用由该名称声明的实体。

作用域可以嵌套，内部作用域可以重新声明外部作用域中某个名称的含义。此时，来自外部作用域的名称被称为在内部作用域覆盖的程序文本区域中“隐藏”，并且只有使用限定名才能访问该隐藏名称。

### 2.5.2. 块

块语句允许在只允许单个语句的上下文中编写多个语句。块由写在分隔符 { 和 } 之间的零个、一个或多个语句组成。

例如，

```
{
  STATEMENTS
}
```

STATEMENTS 由零个、一个或多个语句组成。

请注意，块中声明的局部变量或常量的作用域实际上就是该块。

### 3.1. 词法元素

以下 5 个元素构成 C# 程序的词法结构：

- 行终止符，
- 空白，
- 注释，
- 编译器（或预处理）指令，以及
- 诸如关键字和字面量之类的标记。

编译器指令允许对程序文本进行选择性编译，但除此之外它们对其语法结构没有影响。

### 3.1.1. 行终止符

行终止符元素将 C# 编译单元的字符划分为行。行终止符包括：

- 回车
- 换行
- 下一行字符
- 行分隔符，以及
- 段落分隔符

### 3.1.2. 空白

C# 中的空白定义为

- 任何 Unicode 类别为 Zs 的字符，包括 ASCII 空格字符
- 水平制表符
- 垂直制表符，以及
- 换页符

### 3.1.3. 注释

C# 支持两种形式的注释：C 风格的分隔注释和 C++ 风格的单行注释。

分隔注释分别以字符序列 `/*` 和 `*/` 开始和结束。

单行注释以字符序列 `//` 开始，并延伸到同一行的末尾。

```
/* Delimited comment can span
multiple lines */
using /*or, even just a portion of a line */ System;

// A single line comment.
Console.WriteLine("Hello /* Not a comment */ World.");
```

请注意，注释不能包含在 <u>字符串</u> 中。空白和注释充当标记的分隔符。

### 3.2.1. 标识符

C# 标识符由 Unicode 字符组成，标识符的规则通常与其他 C 风格语言中的规则类似。例如，标识符可以以字母或下划线 _ 开头，并且可以包含其他字母和数字等。有几点需要注意：

- 标识符中允许使用 Unicode 转义序列。

- 连续使用多个下划线（例如 __）虽然合法，但不鼓励。

- 标识符可以选择性地以单个 @ 字符开头。

- 逐字标识符通常用于“转义”C# 关键字，否则不鼓励使用。
