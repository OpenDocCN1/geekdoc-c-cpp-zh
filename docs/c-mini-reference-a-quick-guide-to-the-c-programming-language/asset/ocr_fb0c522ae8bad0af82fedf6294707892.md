# 5.1.3. Boxing and Unboxing

Through boxing and unboxing, a value of any type, value type or reference type, can be treated as This provides a unified view of the C# type system. Boxing a value of a value type creates an object on the heap, which can be referenced via a reference variable. Unboxing does the reverse operation. That is, it returns the value contained in the object referenced by the given variable.
