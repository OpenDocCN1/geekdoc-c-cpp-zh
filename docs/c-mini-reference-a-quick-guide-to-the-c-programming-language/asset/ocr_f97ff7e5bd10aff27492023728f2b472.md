# 3.3.3. Integer literals

Integer literals are used to write values of and They have three possible forms: decimal, hexadecimal, and binary.

```
1_234
5678u
-10000000L
10_000_000uL
```

①
An int integer literal.

②
A uint integer literal. Uses the suffix, u or

③
A long integer literal. Uses the suffix, l or

④
A ulong integer literal. Uses a combination of u/U and

Note that (semantically insignificant) underscores _ can be used in the integer literals except for the beginning and ending positions. Underscores cannot be repeated one after another.
