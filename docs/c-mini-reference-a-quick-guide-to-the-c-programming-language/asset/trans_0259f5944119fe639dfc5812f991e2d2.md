
在近期的许多重要变化中，有几项值得注意。

- 首先，接口中的方法现在可以有默认实现，实现类（以及记录和结构体）可以继承这些默认实现。
- 其次，静态方法已成为接口不可或缺的一部分，而不再只是配角（如果你愿意这样理解的话）。
- 第三，从 C# 11 起，静态方法现在甚至可以参与定义接口的“行为”部分。

例如，C# 11 新增的泛型数学支持包括 System.Numerics 命名空间中的 INumber 接口：

```csharp
public interface INumber<TSelf> : IComparable<TSelf>, ... where TSelf : INumber<TSelf> {
    public static virtual int Sign(TSelf value);
    // ...
}
```

例如，所有实现 INumber 的类型都需要实现这个 Sign 虚拟静态方法。这个部分示例也说明了泛型类型的使用。在接口章节中，我们会介绍现代 C# 接口的一些基本要素，包括这些近期变化。

C# 具有统一的类型系统。每个（非接口）类型都继承自 object。这是 C# 1.0 的核心部分，即使经过二十年的语言演进，这一点仍然如此。

可以说，数组是任何编程语言中除基元类型之外最重要的数据结构。C# 的数组是泛型类型，它以类型安全的方式支持所有常见的数组操作，例如索引。数组和其他集合类型现在也支持基于范围的切片语法，使用的是相对较新的 .NET 类型 Index 和 Range。

另一对重要且相对较新的 .NET 类型是 `Span<T>` 和 `Memory<T>`，它们也与 C# 语言紧密集成。这些类型提供了一种安全的方式来访问和操作内存中的对象及其元素或成员，而不必依赖昂贵的内存操作。

设计和实现一个行为良好的类型需要大量工作。在许多像 Java 和 C# 这样以面向对象为主的语言中，有时仅仅为了创建一个简单类型就需要编写大量样板代码。object 类中定义的虚方法就是其中一些例子。原则上（但不一定在实践中），这些方法中的许多都需要被重写，此外还有许多其他方法，这使得创建新类型格外繁琐。

C# 演进中最大的趋势或主题之一，就是让创建自定义类型这项任务变得更容易。例如，委托自 C# 1.0 起就是 C# 的一部分，它只是一种带有一些编译器生成代码的特殊类，因此开发者无需手动实现它们。最近新增的记录和记录结构体，是 C# 中这一趋势的另一个例子。

在 .NET 世界中，元组（或值元组）是最容易创建和使用的复合类型。它们实际上是“轻量级”类，在许多情况下应优先使用它们，而不是创建更正式的类型。枚举类型也允许创建一种基于一组常量值的简单、特殊类型。

尽管有所有这些近期变化，类仍然是 C# 中最重要的构造。C# 编程从根本上说就是定义类型，例如使用类（以及记录和结构体之类的近亲）。在类章节中，我们会介绍 C# 的基本要素。需要注意的是，我们在类上下文中描述的许多内容也适用于记录和记录结构体。

记录用于创建不可变引用类型，主要用于简单的数据存储。C# 提供了简洁的语法来创建和使用记录。特别是，它支持用于创建记录类型的位置参数。例如，现在创建记录类型就像声明一个记录构造函数一样简单。编译器会自动生成整个类以及若干方法。

```csharp
record Book(string Title, string Author);
```

结构体是值类型，基于 System.ValueType 基类，而该基类又继承自 System.Object。结构体类型本身不支持继承。还存在一些特殊种类的结构体，例如只读结构体、ref 结构体和记录结构体。

C# 支持扩展方法，扩展方法是与其他现有类型关联的静态方法。扩展方法可以像目标类型的实例方法一样被调用。

在本书的第一部分，我们主要关注类型。在本书其余部分，我们会介绍 C# 中其余的重要构造，例如表达式和语句。

new 运算符是 C# 表达式最重要的组成部分之一。它用于创建数组，或创建指定类型（例如类或结构体）的新值或新对象。本章中我们还会介绍对象初始值设定项和集合初始值设定项语法。

除了其他编程语言中常见的表达式外，C# 中还有许多不同种类的表达式。本书通篇都会讨论表达式和运算符，但一些更常见的表达式集中在表达式章节中介绍。lambda 表达式是匿名函数。它使用“粗箭头”=> 运算符定义。Lambda 函数可以作为参数传递给其他方法。

C# 的语句与其他 C 风格语言中的语句大体相同，只有一些细微差别。我们在语句章节中快速过一遍 C# 的所有语句，主要是为了完整性。

switch 语句最初基于 C 的 switch-case 语句，它的一项显著变化是现在支持模式匹配，以及 is 和 switch 表达式。模式匹配最初由 Haskell 等函数式编程语言推广，如今已成为许多（函数式或命令式）编程语言不可或缺的一部分，包括 C#。

using 语句和 using 声明用于管理使用后需要清理的资源，例如文件句柄或数据库连接。当实现 IDisposable 接口的对象超出作用域时，会自动调用其 Dispose 方法。

最后，我们通过对 C# 异常和特性的简要描述来结束这本迷你参考手册。异常使用 throw 语句抛出，它们表示程序执行期间的不寻常或异常情况。在 C# 中，异常处理使用 try 语句实现。特性是一种声明性标记，用于向运行时传达有关代码中各种元素（例如类、方法和属性）行为的信息。C# 特性只是继承自 System.Attribute 的常规类。

需要注意的一点是，尽管本书涵盖了广泛的主题，但为了秉承“迷你参考手册”的精神，将篇幅控制在可管理的范围内，我们仍省略了 C# 的一些重要部分。

这些包括 LINQ（语言集成查询）、表达式树、反射、异步编程、迭代器和异步流、泛型数学，以及委托和 .NET Func 与 Action 类型等。我们还省略了许多常用的 .NET 类型，例如 List、Set 和 Dictionary，它们实际上是 C# 的核心部分。鼓励读者就这些主题及更多内容查阅其他资源。此外，本书不讨论不安全代码。

## 2. C# 程序

一个 C# 程序可以由一个或多个源代码文件（称为编译单元）组成，例如位于文件系统中的一个或多个目录中。程序（可执行文件或库）中的所有源文件会一起编译，因此源文件之间没有特定顺序。

每个源代码文件可以包含一组特殊声明和自定义类型定义。类型定义可以包含在零个或多个嵌套命名空间中。C# 中的命名空间是一种逻辑组织单元，主要用于降低名称冲突的可能性。

### 2.1. Main 方法

可执行的 C# 程序（或“应用程序”）应当包含一个具有 Main() 静态方法的类型声明（例如类或接口），或者包含一个带有“顶级语句”的源文件。这是程序的入口点。

Main() 静态方法可以返回 int 类型的值，也可以不返回任何值（由 void 返回类型表示）。它可以接受 string[] 类型的参数，也可以定义为没有任何方法参数。Main() 方法可以是同步的，也可以声明为 async 并返回 Task 或 Task<int>。

因此，Main() 静态方法的有效签名有以下八种组合：

```csharp
static void Main() { /* ... */ }
static int Main() { /* ... */ }
static void Main(string[] args) { /* ... */ }
static int Main(string[] args) { /* ... */ }
static async Task Main() { /* ... */ }
static async Task<int> Main() { /* ... */ }
static async Task Main(string[] args) { /* ... */ }
static async Task<int> Main(string[] args) { /* ... */ }
```
