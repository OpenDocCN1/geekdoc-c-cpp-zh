## 开发系列

本书由该语言架构师 Anders Hejlsberg 及其同事 Mads Torgersen、Scott Wiltamuth 和 Peter Golde 编写，已针对 C# 4.0 全面更新。本书提供了该语言的完整规范，以及十二位知名 C# 专家的描述、参考资料、代码示例和注释。
