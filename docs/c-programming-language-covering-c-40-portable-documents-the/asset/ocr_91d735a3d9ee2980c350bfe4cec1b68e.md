# 6.4.5 User-Defined Explicit Conversions

A user-defined explicit conversion from type S to type T is processed as follows:

+   * Determine the types S₀ and T₀, from which user-defined explicit conversion from type S to type T is processed as follows: If S or T is a nullable type, S₀ and T₀ are their respective underlying types; otherwise, S₀ and T₀ are equal to S and T, respectively.
+   * Find the set of types, D, from which user-defined conversion operators will be considered: This set consists of S₀ (if S₀ is a class or struct), the base classes of S₀ (if S₀ is a class), T₀ (if T₀ is a class or struct), and the base classes of T₀ (if T₀ is a class).
+   * Find the set of applicable user-defined and lifted conversion operators, U. This set consists of the user-defined and lifted implicit or explicit conversion operators declared by the classes or structs in D that convert from a type encompassing or encompassed by S to a type encompassing or encompassed by T. If U is empty, the conversion is undefined and a compile-time error occurs.
+   * Find the most specific source type, Sᵥ, of the operators in U:
+     - If any of the operators in U convert from S, then Sᵥ is S.
+     Otherwise, if any of the operators in U convert from types that encompass S, then Sᵥ is the most encompassed type in the combined set of source types of those operators. If no most encompassed type can be found, then the conversion is ambiguous and a compile-time error occurs.
+     Otherwise, Sᵥ is the most encompassing type in the combined set of source types of the operators in U. If exactly one most encompassing type cannot be found, then the conversion is ambiguous and a compile-time error occurs.
+   * Find the most specific target type, Tᵥ, of the operators in U:
+     - If any of the operators in U convert to T, then Tᵥ is T.
+     Otherwise, if any of the operators in U convert to types that are encompassed by T, then Tᵥ is the most encompassing type in the combined set of target types of those operators. If exactly one most encompassing type cannot be found, then the conversion is ambiguous and a compile-time error occurs.
+     Otherwise, Tᵥ is the most encompassed type in the combined set of target types of the operators in U. If no most encompassed type can be found, then the conversion is ambiguous and a compile-time error occurs.
+   * Find the most specific conversion operator:
+     If U contains exactly one user-defined conversion operator that converts from Sᵥ to Tᵥ, then this is the most specific conversion operator.
+     Otherwise, if U contains exactly one lifted conversion operator that converts from Sᵥ to Tᵥ, then this is the most specific conversion operator.
