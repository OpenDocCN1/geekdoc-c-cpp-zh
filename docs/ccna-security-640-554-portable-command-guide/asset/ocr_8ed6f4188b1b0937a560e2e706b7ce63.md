**NOTE:** You can configure multiple IKE policies. When the IKE negotiation begins, it tries to find a common policy configured on both peers, starting with the highest-priority policies as specified on the remote peer.

**NOTE:** Use the `show crypto isakmp policy` command to verify the IKE settings.

Configurable IKE parameters include the following:

+   - Authentication (default = RSA signatures)
+   - Encryption (default = 56-bit DES)
+   - Hash (default = SHA-1)
+   - DH group (default = 768-bit DH)
+   - IKE SA lifetime (default = 86400 seconds [1 day])
