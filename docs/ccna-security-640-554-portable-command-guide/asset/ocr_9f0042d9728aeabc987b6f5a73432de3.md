Use one of the following commands to identify a protocol or other protocol object groups:

| Command | Description |
|---|---|
| `ciscoasa(config-protocol-object-group)# protocol-object protocol` | Define the protocols in the group. **NOTE:** The `protocol` parameter is the IP protocol numeric identifier (1 through 254) or a keyword identifier (for example, `icmp`, `tcp`, `udp`, or `ip` to include all IP protocols). |
| `ciscoasa(config-protocol-object-group)# group-object group-name` | Assign an object group to the named object. |

Use the following commands to create an ICMP object group:

| Command | Description |
|---|---|
| `ciscoasa(config)# object-group icmp-type group-name` | Create or edit an ICMP object group and enter ICMP type object group configuration mode. |

Use one of the following commands to identify a protocol or other protocol object groups:

| Command | Description |
|---|---|
| `ciscoasa(config-icmp-object-group)# icmp-object icmp-type` | Define the ICMP types in the group. Enter the command for each type. |
| `ciscoasa(config-icmp-object-group)# group-object group-name` | Assign an object group to the named object. |

A service-based object group is used to group TCP, UDP, or TCP and UDP ports into an object. The ASA enables the creation of a service object group that can contain a mix of TCP services; UDP services; ICMP-type services; and any protocol such as Encapsulation Security Protocol (ESP), generic routing encapsulation (GRE), and TCP.

Use the following commands to create a service object group:

| Command | Description |
|---|---|
| `ciscoasa(config)# object-group service group-name` | Create or edit a service group object and enter service object group configuration mode. |

Use one of the following commands to identify a protocol or other protocol object groups:

| Command | Description |
|---|---|
| `ciscoasa(config-service-object-group)# port-object eq service` | Add a port object to a service object group. Specify the decimal number or name of a TCP or UDP port for a service object. |
| `ciscoasa(config-service-object-group)# group-object group-name` | Assign an object group to the named object. |
