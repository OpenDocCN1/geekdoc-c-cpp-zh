| X.509 | • A well-known ITU-T standard that defines basic PKI standard formats for public key certificates and certificate revocation lists (CRL).<br>• X.509 Version 3 (X.509v3) defines the digital certificate format that is used extensively in SSL website authentication, email agents, and IPsec VPNs for initial key exchange. |

# PKI Topologies

| Topology | Description |
|---|---|
| Simple (single-root) PKI | • Issues all the certificates to the end users.<br>• The benefit in such a setup is simplicity.<br>• VPNs that are managed by a single organization often use this topology. |
| Hierarchical CA topology | • Involves multiple hierarchical CAs within an organization.<br>• CAs can issue certificates to end users and to subordinate RAs, which in turn issue their certificates to end users or other CAs.<br>• The main benefits are increased scalability and manageability.<br>• Trust decisions can now be hierarchically distributed to smaller branches. |
| Cross-certified CAs | • Involves multiple flat, single-root CAs that establish trust relationships horizontally by cross-certifying their own CA certificates. |
