# ASA Objects and Object Groups

Objects make it easier to maintain configurations. When an object is modified, the change automatically applies to all rules that use the specified object. Objects are used in Network Address Translation (NAT), access lists, and nested into other object groups.

The ASA supports the following:

| Category | Description |
|---|---|
| **Objects** | ▪ An object identifies an IP address/mask or a protocol (and a port).<br>▪ An object can be reused in several configurations.<br>▪ The ASA supports network objects and service objects.<br>▪ Objects are created using the `object {network \| service} object-name` command. |
| **Object groups** | ▪ Object groups are used to group objects.<br>▪ Objects can be attached or detached from multiple object groups.<br>▪ You can create network, protocol, and Internet Control Message Protocol (ICMP)-type objects groups created using the `object-group {network \| protocol \| icmp-type} group-name` command.<br>▪ You can also create service object groups by using `object-group service group-name [tcp \| udp \| tcp-udp]`. |

# Network and Service Objects

A network object contains a single IP address/mask pair that can be identified using a host, subnet, or range of addresses.

Use the following commands to create or edit a network object:

| Command | Description |
|---|---|
| `ciscoasa(config)# object network` | Create or edit a network object and enter network object configuration mode. |
| `object-name` |  |
| `ciscoasa(config-network-object)# {host ip_addr \| subnet net_addr net_mask \| range ip_addr_1 ip_addr_2}` | Assign the IP address to the named object. You can configure a host address, a subnet, or a range of addresses. |

**NOTE:** Use the `no` form of any of these three commands to remove a network object.

**NOTE:** There can only be one statement in the network object. Entering a second IP address/mask pair will replace the existing configured statement.
