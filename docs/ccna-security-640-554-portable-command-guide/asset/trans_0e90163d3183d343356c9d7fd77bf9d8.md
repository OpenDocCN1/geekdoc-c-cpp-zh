## 命令语法约定

本书中用于呈现命令语法的约定与*IOS命令参考*中使用的约定相同。*命令参考*对这些约定描述如下：

- **粗体**表示按所示原样输入的命令和关键字。在实际配置示例和输出中（不是一般命令语法），粗体表示用户手动输入的命令（例如show命令）。
- *斜体*表示需要你提供实际值的参数。
- 竖线（|）分隔备选且互斥的元素。
- 方括号[ ]表示可选元素。
- 花括号{ }表示必需的选择。
- 方括号内的花括号[ { } ]表示可选元素中的必需选择。
