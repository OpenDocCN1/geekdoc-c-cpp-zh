**Figure 12-5** Basic Firewall Security Configuration Window

| Security Level | Description |
|---|---|
| **High Security** | Option provides the highest level of security and makes the router:

- Drop instant messaging and peer-to-peer traffic
- Inspect HTTP and email traffic and drops noncompliant traffic
- Permits TCP and UDP return traffic initiated by inside users |
| **Medium Security** | Option tracks the use of applications on the network and the router:

- Identifies instant messaging and peer-to-peer traffic
- Inspects HTTP traffic and email traffic for protocol compliance
- Permits TCP and UDP return traffic initiated by inside users |
| **Low Security** | Option provides the lowest level of security and makes the router:

- Permit TCP and UDP return traffic initiated by inside users |
