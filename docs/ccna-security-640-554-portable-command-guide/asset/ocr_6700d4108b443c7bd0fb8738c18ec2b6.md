From this screen, you can modify the access and inspection rules that are displayed. For instance, you can add a new zone policy or add a rule for new traffic or for existing traffic. You can also edit an existing policy or delete it.

**NOTE:** Use the Configure > Security > Firewall > Firewall Components navigation option to add or change zones, zone pairs, and C3PL objects (class maps, policy maps, and policy assignments).

To monitor the firewall status, choose Monitor > Security > Firewall > Firewall Status, as shown in Figure 12-8.

From this screen, you can verify the firewall configuration and view how many connection attempts have been denied and the log entries, including the time and the reason for the log entry.

**NOTE:** For firewall log entries to be collected, logging must be enabled to obtain firewall logging messages with a logging level of debugging (7).
