# VPN Deployment Modes

| VPN deployment mode | Description |
|---|---|
| **Site-to-site VPNs** | • Connects entire networks to each other.<br>• VPN hosts do not require VPN client software.<br>• VPNs send and receive normal TCP/IP traffic through a VPN “gateway” such as a Cisco ISR or an ASA.<br>• The VPN gateway is responsible for encapsulating and encrypting outbound traffic over the Internet to a peer VPN gateway.<br>• Upon receipt, the peer VPN gateway decrypts the content and relays the packet toward the target host inside its private network. |
| **Remote-access VPNs** | • VPN securely connects telecommuters, mobile users, and external consumer-to-business over the Internet.<br>• Hosts may require a preinstalled VPN client (for example, Cisco VPN Client or Cisco AnyConnect) to access the target site using Hypertext Transfer Protocol Secure (HTTPS).<br>• The client encapsulates and encrypts that traffic and sends it over the Internet to the target VPN gateway.<br>• The VPN gateway behaves as it does for site-to-site VPNs. |

**NOTE:** VPNs implement cryptographic protocols to secure the VPN network traffic.
