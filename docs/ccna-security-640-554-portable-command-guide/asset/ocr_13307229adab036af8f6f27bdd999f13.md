+   On all trunk links:
+   * Enable trunking.
+   * Disable DTP.
+   * Use unique native VLAN.

+   On all unused ports:
+   * Disable trunking.
+   * Assign all unused ports to a dedicated VLAN.
+   * Disable the port.

+   On an access port:
+   * Disable trunking.
