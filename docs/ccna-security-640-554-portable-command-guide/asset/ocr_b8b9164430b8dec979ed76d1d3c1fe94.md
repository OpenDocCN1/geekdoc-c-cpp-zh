> **NOTE:** Use the `show port-security` command to view security settings and status and the `show port-security [interface-id] address` command to display all secure MAC addresses configured on all switch interfaces.

When a port violation occurs, such as the maximum number of MAC addresses connected is exceeded, error log messages such as `%P-4-ERR_DISABLE` and `%PORT_SECURITY-2-PSECURE_VIOLATION` are generated and the port status is changed from secure-up to secure-shutdown. When a port is error-disabled, it is effectively shut down, and no traffic is sent or received on the port. The port is error-disabled and must be manually reset by the network administrator using a shutdown and no shutdown sequence. This should be done after the offending host has been removed; otherwise, the violation will be triggered again.

# Fine-Tuning Port Security

If required, you can alter the default maximum number of secure MAC addresses and the port violation action:

| Command | Description |
|---|---|
| `Switch(config-if)#switchport`<br>`port-security maximum value` | Set the maximum number of secure MAC addresses for the interface.<br><br>The default is 1, but the range is 1 to 132.<br><br>**NOTE:** Configure a maximum value of 2 or 3 when connecting an IP phone and host to a switch port. |
| `Switch(config-if)#switchport`<br>`port-security violation`<br>`{protect \| restrict \| shutdown \| shutdown vlan}` | Configure the port action when the number of MAC addresses exceeds the defined maximum. Default is shutdown.<br><br>`shutdown` disables the port and generates syslog and SNMP messages.<br><br>`restrict` drops violating traffic and generates syslog and SNMP messages, while traffic from allowed MAC addresses is permitted to pass normally.<br><br>`protect` drops violating traffic, while traffic from allowed MAC addresses is permitted to pass normally.<br><br>`shutdown vlan` drops violating traffic for the offending VLAN instead of shutting down the entire port. |

**TIP:** Configure shutdown rather than restrict or protect.
