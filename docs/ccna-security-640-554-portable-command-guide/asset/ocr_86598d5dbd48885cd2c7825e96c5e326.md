# Integrated Threat Control Strategy

|  |  |
|---|---|
| Application awareness | Implement application inspection mechanisms, such as the following:<br>• Application Inspection and Control (AIC)<br>• Modular Policy Framework (MPF)<br>• Network-Based Application Recognition (NBAR)<br>• Flexible Packet Matching (FPM) |
| Application-specific gateways | Implement gateways geared toward the inspection and analysis of specific application traffic, including the following:<br>• Cisco IronPort web and email security appliances<br>• ScanSafe web security technologies |
| Integrated threat control and containment | Provide a multidimensional approach to detecting, mitigating, and responding to threats using integrated deployment options, including the following:<br>• Integrated Services Routers (ISRs)<br>• Cisco Adaptive Security Appliances (ASAs)<br>• Intrusion prevention system (IPS) sensors |
| Cisco Security Appliances | Provide a firewalling service available in various form factors, including the following:<br>• Cisco IOS routers<br>• Cisco ASA<br>• Network modules added to the Catalyst 6500 switch |
| Cisco IPS | Provide a threat control mechanism available in various form factors, including the following:<br>• Cisco IOS IPS (limited version)<br>• A dedicated appliance (Cisco 4200)<br>• Cisco ASA 5500 series, ISR G2s, and network modules added to the Catalyst 6500 |
| Security management | Provide a comprehensive approach to event management using security management tools such as the following:<br>• Cisco Configuration Professional (CCP)<br>• Cisco IPS Device Manager (IDM)<br>• Cisco Security Manager (CSM) |
