# Threats Against the Network Infrastructure

Common vulnerabilities and threats against a network infrastructure include the following:

| Category | Items |
|---|---|
| **Vulnerabilities** | Design errors<br>Protocol weaknesses<br>Software vulnerabilities<br>Device misconfiguration |
| **Threats** | Trust exploitation<br>Login, authentication, and password attacks<br>Routing protocol exploits<br>Spoofing<br>Denial of service (DoS)<br>Confidentiality and integrity attacks |
