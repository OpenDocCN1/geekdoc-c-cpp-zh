In this example, Port Address Translation (PAT) is configured. Trusted hosts on the inside zone are translated dynamically, using PAT, to the IP address on the router's untrusted interfaces, in this example Fast Ethernet 0/0.

The first step is to access and run the basic NAT Wizard by navigating to Configure > Router > NAT > Create NAT Configuration.

This opens the Create NAT Configuration screen shown in Figure 12-10.

![](bbox=[0.09, 0.278, 0.93, 0.655])

Figure 12-10   Create NAT Configuration Wizard Screen

You have two NAT Wizard options:

|  |  |
|---|---|
| **Basic NAT** | Choose if you want to connect your network to the Internet (or the outside) and your network has hosts but no servers. |
| **Advanced NAT** | Choose if you want to connect your network to the Internet (or the outside) and your network has hosts and servers and the servers must be accessible to outside hosts (hosts on the Internet). |

Choose Basic NAT and click the Launch the Selected Task button. The wizard displays the NAT Wizard welcome window shown in Figure 12-11.
