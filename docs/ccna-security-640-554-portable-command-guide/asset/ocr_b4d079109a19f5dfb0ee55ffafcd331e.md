Click Enable AAA.

The Enable AAA dialog box appears, as shown in Figure 7-2.

Clicking Yes enables AAA and automatically configures local authentication on the console line. It also configures the vty lines for local authentication, authorization to use the EXEC shell, and accepts the privilege level of the user (if configured).

> **NOTE** Clicking **No** does not enable AAA.
