## Routed and Transparent Firewall Modes

Two firewall modes of operation are available on ASA devices:

| Mode | Description |
|---|---|
| **Routed mode** | • The traditional mode for deploying a firewall.<br>• Two or more interfaces that separate Layer 3 networks.<br>• The ASA is a router hop in the network and can perform Network Address Translation (NAT) between connected networks.<br>• Routed mode supports multiple interfaces, and each interface is on a different subnet and requires an IP address on that subnet. |
| **Transparent mode** | • The ASA functions like a Layer 2 device.<br>• Also referred to as a *bump in the wire* or a *stealth firewall*.<br>• The ASA requires only one management IP address configured in global configuration mode.<br>• Transparent mode does not support dynamic routing protocols, VPNs, quality of service (QoS), or Dynamic Host Configuration Protocol (DHCP) Relay. |

**NOTE:** This section focuses on routed mode.

## ASA Security Levels

The building blocks of ASA security are assigning interfaces to security levels to distinguish between inside (trusted) and outside (untrusted) networks:

- Security levels define the level of trustworthiness of an interface.
- The higher the level, the more trusted the interface.
