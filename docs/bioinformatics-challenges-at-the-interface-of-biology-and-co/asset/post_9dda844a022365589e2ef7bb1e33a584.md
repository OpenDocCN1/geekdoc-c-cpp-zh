Tools built prior to this extension would continue to work seamlessly; the JSON parser would read happily in the new key/value pairs, but it wasn't programmed to do so. ## XML

Extensible Markup Language, XML shares some common goals with JSON, that it allows objects and their properties to be encoded in a well-defined language that can be created and consumed by standard parsers. XML badges itself as a 'language', rather than as a 'notation', and is considerably richer and more complex than JSON. Based on an earlier and much more complex markup language, SGML (Goldfarb, 1990), XML presents a set of highly regular rules for how to encode hierarchically structured data.
