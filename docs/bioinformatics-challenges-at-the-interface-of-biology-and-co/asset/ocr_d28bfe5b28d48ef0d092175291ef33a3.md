# Box 7.8 Useful ontologies and schemes

There are hundreds of science-related ontologies, many of which are accessible via the NCBI's BioPortal, ranging from the very broad (e.g., the Gene Ontology), to the quite specific (e.g., the Fungal Gross Anatomy Ontology). As well as others relate specifically to the life sciences, there are a handful of schemes and ontologies that are useful to know when building bioinformatics applications.

The Dublin Core (DC) scheme is a small set of vocabulary terms that can be used to describe Web resources (video, Images, Web pages, etc.), as well as physical resources, such as CDs, and objects like artworks. The vocabulary includes terms for properties such as Title, Creator, Subject, Description, Rights.

Whereas Dublin Core mostly describes things, the Friend Of A Friend (FOAF) describes people, their activities and their relationships to other people and objects.

The PROV Ontology (PROV-O) can be used to describe provenance to formally record change: who did what, when and why.

CITO, the Citation Type Ontology, allows for the formalisation of citations, both factually and literally, for example linking a database record to capture the fact that it's citing an article that supports or references a particular work.

EDAM is an ontology of common bioinformatics operations, types of data, topics, and data formats, and is useful for classifying bioinformatics tools and services.

The Annotation Ontology (Icarello et al., 2011) is for annotating digital objects with comments, tags, errata, etc.

The Vocabulary of Interlinked Data (VoID) describes datasets represented in RDF. VoID descriptions can be used to help find matches, interpret and integrate data.
