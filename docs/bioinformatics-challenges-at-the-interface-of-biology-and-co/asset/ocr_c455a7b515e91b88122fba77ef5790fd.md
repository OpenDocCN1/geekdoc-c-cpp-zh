# Bioinformatics technologies at the interface of biology and computer science

In Section 4.2.2, we examined the format of the EMBL data library in some detail, largely because its simplicity and ready extensibility led other databases to query and adapt to their own needs. GenBank, however, its database, had grown independently more or in parallel, and used a different framework. We also saw that the databases used a common Feature Table to facilitate interpretation, unfortunately, they are all share. Consider, then, the challenge of locating sequence information from DMRSR-11.

Within the UniProtKB/TrEMBL entry 107, we found an embedded link to ‘BX284605’. Selecting the EMBL view (text option), we found that BX284605 is listed as both the ID and the AC; by contrast, in the GenBank view, it is listed as the entry ‘LOCUS’ and ‘ACCESSIONION’. In EMBL, its description (DE) is ‘Caenorhabditis elegans chromosome V’, and in GenBank its DEFINITION is ‘Caenorhabditis elegans’. In GenBank, the SOURCE and ORGANISM are ‘Caenorhabditis elegans’, whereas in EMBL, this is tagged as OS, the organism species.

Similar issues are encountered when we trace information in the UniProtKB and NCBI Reference (RefSeq) databases: in the former, Q23293-CAEL is the ID and Q232932 the AC, and in the latter, the LOCUS and the ACCESSION. The description (DE) in UniProtKB/TrEMBL is SubName: Full=DromyoSuppression Receptor received, or [Caenorhabditis elegans]¹. At this level, the relationship between the nucleotide and protein sequence databases isn't evident. To help make this connection, the UniProtKB/TrEMBL, gene name (GN) makes reference to ORFNames=CELE_ZC404_11. In RefSeq, this information is held in the coding sequence (CDS) component of the FEATURES table, and tagged as /locus_tag=CELE_ZC404_11’.

Negotiating the ID and nomenclature differences in this single entity requires significant descriptive work; getting computers to perform the same task requires precise translation between the minutiae of each of the different databases and nomenclature systems. But here, we’ve looked at just four coupled primary sequence databases; automatic retrieval from the hundreds of genomic data repositories around the world (or even within a single institute) presents many more challenges – challenges that will ultimately require database and application-specific semantics to be fully documented if we are to help computers to ‘understand’ and complete the tasks we need to perform in future.
