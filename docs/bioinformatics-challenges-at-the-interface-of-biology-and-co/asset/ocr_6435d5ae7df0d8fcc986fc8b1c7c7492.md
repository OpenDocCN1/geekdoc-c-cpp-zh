# Bioinformatics challenges at the interface of biology and computer science

If we take our HBA_HUMAN example once more, a possible simple encoding in XML could look like:

```
<sequence>
  <type>protein</type>
  <identifier>HBA_HUMAN</identifier>
  <description>
    Hemoglobin subunit alpha OS=Homo sapiens=HBA1 PE=1 SV=2
  </description>
  <aminoacids>
    MVSPADKTNVKAAWGKVHGAHAGEAEALERMSSFSPTKTYFPHDLHGSAVKGHG
    KKVLDATNAVHDYMPASALSDLHAKLRVDPNFKHLLCSLLVTAHLAPAEPFT
    AVHLSDDFPLASVTSTKYSR
  </aminoacids>
</sequence>
```

In XML, elements are surrounded by 'tags'; in this example, <sequence> the 'start' tag, </sequence> the corresponding 'end' tag, and other elements such as 'type' and 'identifier', are nested within these. With JSON, XML parsers don't care what the tags are, or as long as they are syntactically valid and correctly nested to form a hierarchy of properties.

If all there were to say about XML, it wouldn't be noteworthy. However, the simplicity of this paradigm allows us to use XML for many tasks. To begin with, we can, for a given XML application, precisely specify the expected structure of the data: e.g., 'a sequence element that holds one of type and identifier elements'. We can use an XML Schema (XSchema) to formalise a schema, somewhat recursively, in XML; this can be used to validate that a given document has the expected structure, or to generate attributes for arbitrary programming languages. We can specify visual styles for when we wish to view the information in an XML document in a formatted way, using the Extensible Stylesheet Language (XSL). We can also translate between different schemas (as the data is transformable) by using an XML Transformation (XSLT), itself an XML document that specifies the mapping of elements and attributes to enable the extraction. For simple queries of XML documents, we can use an XML Path (XPath), a filesystem-like path for identifying and retrieving elements or attributes of: e.g., /sequence/identifier[1]/text() would match the string HBA_HUMAN in example. For greater flexibility, we can use the XML query language (XQuery), which allows to reference external resources, use more advanced logic, and introduce variables to the query process. To link XML documents, allowing us to split data and reduce redundancy, we can use the Xlink protocol.

XML provides a method for assigning namespaces to the names of elements and attributes, by including a number of standard attributes in elements to which we wish namespaces to apply. XML namespaces are actually URIs; which are assigned a prefix (which can be empty, this is the default) that we can use to qualify both element and attribute names directly.
