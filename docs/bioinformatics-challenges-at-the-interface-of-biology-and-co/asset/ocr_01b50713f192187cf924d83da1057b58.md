# Box 7.6 XML: The eXtensible Markup Language

XML is a very simple framework, but one capable of great power and flexibility. It becomes almost trivial to include the type of information we desire in Section 7.4; if we need to keep track of the format we use, we could simply add a version attribute to the root element; if we need to show provenance information, we could add attributes to capture that. An example of these used in a single document is shown below. Line 1 tells us the version of the XML framework we're using (1); lines 3-6 define various namespaces, including a default namespace for the elements that do not include a prefix; lines 8-12 provide provenance information, including the current revision of it; line 16 defines the version of this particular file at the XSchema that defines this format. The rest of the file includes various elements from the different namespaces (section, property, etc.) to annotate a particular region on page 8 of a journal article with a comment relating to the content.

```
<?xml version="1.0" encoding="utf-8"?>
<annotation>
  xmlns:property="http://utopia.es.manchester.ac.uk/kend/property/"
  xmlns:session="http://utopia.es.manchester.ac.uk/kend/session#"
  xmlns:xs="http://www.w3.org/2001/XMLSchema-instance"
  xmlns="http://utopia.es.manchester.ac.uk/kend"
  concept="Usercomment"
  author="http://utopia.es.manchester.ac.uk/users/11282"
  created="2011-01-01T04:06:08"
  updated="2011-01-01T04:06:08"
  revision="1"
  status="published"
  id="http://utopia.es.manchester.ac.uk/annotations/812"
  edit="http://utopia.es.manchester.ac.uk/kend/0/annotations/812"
  context="http://utopia.es.manchester.ac.uk/frameworks/public"
  version="0.7"
  xsi:schemaLocation="http://utopia.es.manchester.ac.uk/kend http://utopia.es.manchester.ac.uk/kend/0.7/xsd/annotation">
<properties>
  <property:comment>
    Does anyone know the PDB code for this figure?
  </property:comment>
  <session:sessionVersion>Kend/0.6</session:sessionVersion>
</properties>
<anchor>
  <document id="http://utopia.es.manchester.ac.uk/documents/819">
    <extent>
      <text>M.ltb CRP; FNR</text>
      <bounds>
        page="8"
        rotation="0"
        left="260.4472"
        top="214.57841559"
        right="279.0992"
        bottom="222.8076535536"
      </bounds>
    </extent>
  </document>
</anchor>
</annotation>
```

An example of XML to encode complex data.
