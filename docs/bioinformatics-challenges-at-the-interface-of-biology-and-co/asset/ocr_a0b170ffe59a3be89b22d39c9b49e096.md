# Chapter 7 Representation and meaning

SKOS: The Simple Knowledge Organisation System
SKOS provides a way to create controlled vocabularies, taxonomies and thesauri. It's designed primarily for indexing- searching applications: e.g., a user searching a database for 'rhopsin' may also be interested in the broader category of GPCRs – it's straightforward to capture such relationships in SKOS.

SKOS is intentionally restrictive (hence the 'simple' in name), providing a small, controlled set of relationships between concepts. The SKOS Primer describes concepts as:

units of thought – ideas, meanings, or (categories of) objects and events...[that]exist in the mind as abstract entities which are defined by the terms used to label them.

Consider the following:

```
ex:Leucine rdf:type skos:Concept;
skos:prefLabel "Leucine"@en;
skos:prefLabel "Leucina"@es;
skos:prefLabel "Leucinium"@ia;
skos:prefLabel "Leucin"@de;
skos:narrower ex:Aliphatic.
```

The first line defines Leucine in the ‘example’ namespace ‘ex’ as having the RDF type of SKOS Concept. Lines 2, 3, and 5 associate a ‘preferred’ label with the concept in English, Spanish, Latin and German, respectively (there can be, at most, one). The final line defines ex:Leucine as being a ‘narrower’ concept than the ex:Aliphatic (i.e., defines it as a subclass of Aliphatic). SKOS allows any synonym of ‘alternative labels’ to be defined using skos:altLabel. For example, we might add:

```
skos:altLabel "4-Methyl-L-norvaline";
skos:altLabel "H Leu OH";
skos:altLabel "L Leucine";
```

to indicate that 4-Methyl-L-norvaline and H-Leu-OH are ‘(human) language independent synonyms for Leucine.

OWL: The Web Ontology
At the other extreme of expressiveness sits the family of knowledge-representation languages OWL (a short acronym of Web Ontology Language). Whereas creating taxonomies and thesauri with SKOS is primarily about capturing concepts and simple relationships, an OWL ontology seeks to emphas objects in a way that makes it to practise which category or class of objects they belong. This defining step – to recognise an object’s class – that’s the main intentional difference. OWL does this using a logic-based language in which statements or axioms have a strict interpretation, such that a computer can draw conclusions from them.
