> Figure 6.14
A simple function for calculating the larger of two numbers. The function is then called with square root expansions as parameters.

For the macro max_a(a,b) of Figure 6.15, the parameters are not evaluated first, but rather substituted into the macro definition before it executes. This leads the macro to execute one more square root than it would have needed to. In cases like this, it is efficient to evaluate the square roots separately, and assign their results to new variables, passing these into the macro, rather than the unevaluated code. This square-root function on systems ensures that expensive operations are executed only once.

Although the square-root function on systems is a relatively quick operation, other heavyweight functions would present greater overheads; and, the previous example of performing an operation in a loop, with overheads can grow startlingly quickly, depending on how such a macro is used. Not many languages macros, but knowing which do, and being aware of their existence, can save us a great deal of frustration, and present considerable speed increases.
