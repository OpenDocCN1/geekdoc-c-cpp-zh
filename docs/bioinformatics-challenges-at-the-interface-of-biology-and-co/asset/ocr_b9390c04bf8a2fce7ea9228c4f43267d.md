# Box 7.5 JSON: The Javascript Simple Object Notation

The JavaScript Simple Object Notation (JSON) is a serialisation format based on how values are represented in the JavaScript language. to character strings, numbers, Boolean values, dictionaries (which make associations between two values), and therefore has no built-in support for names, provenance, or metadata. Everything we need, we must specify ourselves, and must be explicitly encoded in the JSON itself.

At first sight, JSON seems too restrictive to be of use, but it is, and has excellent support in most programming languages. As a result, building systems that consume JSON can be done very quickly; and if the data is simple, without the need for complex metadata, this becomes almost trivial.

The fragment of JSON below shows a simple JSON result returned by querying Europe PubMed Central for UniProtKB entries that the article with ID 2137202 (Dryja et al., 1990) as evidence back up claims in the database record. Items enclosed in square brackets [] are key-value pairs. For example, the top level of the JSON is a dictionary containing five entries with the keys dbCount, dbReferenceList, hitCount, request and version. Depending into the JSON, dbReferenceInfo contains a list, which is one dictionary although the keys used by the dictionary are rather meaningless, and the UniProtKB accession number that we may get aboutmatically (P08100) is simply referred to as "info"; making it very easy for a computer to use this particular data reliably (this is an unfortunate limitation of the way Europe PMC exposes its data, and not a limitation of).

```
{
  "dbCount": {
    "db": 1,
    "dbName": "UniProtKB"
  },
  "dbReferenceList": {
    "dbReferenceInfo": [
      "dbCount": 1,
      "dbReferenceInfo": [
        "info1": "P08100",
        "info2": "Rhodopsin",
        "info3": "Homo sapiens",
        "info4": "UniProtKB"
      ],
      "dbName": "UniProtKB"
    }
  },
  "hitCount": 1,
  "request": {
    "database": "UniProtKB",
    "id": "2137202",
    "page": 1,
    "source": "MED"
  },
  "version": "3.0.1"
}
```

JSON retrieved from Europe PMC listing UniProtKB entries that Dryja et al. (1990).
