# Box 6.2 Regular expressions

It's common in bioinformatics to search for protein or nucleotide sequences for strings, or patterns, of amino acids or nucleotides (perhaps these residues or bases form functional sites). We may be looking for an exact match; at other times, we may want to allow a certain degree of 'fuzziness' that captures the ambiguities and substitutions that occur in the real world of biology. For example, the consensus sequence VRSPZ would allow this fuzziness to be captured in a search. The highly region highlighted in the following:

because V, R, S, and F in the consensus sequence match their characters in the fragment; X matches any (in this case, a F for valine), Z matches glutamic acid or glutamine (here, the E for glutamic). A complete description of the syntax used could be used for search of amino acids in the PROSITE manual. As well as allowing forone substitutions by IUPAC acid and ambiguity codes, consensus sequences can also be used to match more complex patterns. For example, to express name (where, an amino acid, AM) or a repeat (such as A(3), which matches 3 alanines in a row).

Whereas consensus sequences encode a certain amount of biological in their ambiguities (e.g., Z can be one of two specific amino acids), in science, regular expressions provide more flexibility for matching text. These are widely used throughout aspects of biology. Although their syntax and purpose are decidedly simple, regular expressions provide a much richer language for describing general-purpose pattern matching. For example, they allow characters to be optional (by following them with a question mark '?'), repeated one or more times (by following them with a plus sign '+'), an repeated number of times (by following them with a number in brackets '']), or grouped. Regular expressions also use character classes that match other things, unlike only digits (\d), whitespace (\s), or word boundaries (\b); some regular-expression handle much more complicated classes, such as dash characters (\p{Pd}) and currency symbols (\p{Sc}). We can even specify any arbitrary set of characters to match such, that, [AC] might match either A or C.

The following list shows some regular expressions, with explanations of what they match:

+   - ENS[AZFGT]{11} matches the letters ENS followed by zero or more times from A and Z, and would match any one of the letters F, or T or G, followed by exactly 11 digits; for example, this would match Ensembl gene IDs, such as ENSG000001390618

+   - PDOC{5} matches the letters PDOC followed by five digits would match PROSITE document IDs, such as PDOC00049 or PDOC50178;

+   - [ATGC]+ matches one or more of the letters A, T, G, or C; so would match any (non-length) DNA sequence consisting of the letters A, T, G, or C in any order.
