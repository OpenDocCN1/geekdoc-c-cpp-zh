The post-increment operator, a++, first makes a copy of the value as it was before the statement, increments the variable, and returns its previous value via the copy. Figure 6.13 shows the distinction between pre and post-increment in pseudocode. The important point is the copying of information occurs when using the post-increment operator: if we use this operator for the sole purpose of incrementing a value, without the need to use the result – which is often the case when iterating over sequences – we then needlessly cause memory to be allocated and copied. If the value is a simple number, the overhead of head may not be too great; but if increment resides within a loop, that loops many times, this overhead can quickly become significant. Add to this common practice of incrementing numbers but not iterators (fullyfledged and complex objects that keep track of a position in a data structure), and this overhead can quickly dominate a program's execution time.

Knowing and appreciating the difference between pre- and post-increment operators can prevent us from blindly using ++i to increment an iterator, when the increment version +i is, in cases, the most efficient approach.
