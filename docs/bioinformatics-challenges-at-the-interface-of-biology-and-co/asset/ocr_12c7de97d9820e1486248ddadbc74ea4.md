# Box 7.7 Automated Reasoning and the Open World Assumptions

The Open and Closed World Assumptions in the world of formal logic and ontologies there are two ways of looking at systems of knowledge. The Closed World Assumption, anything that isn't known to be true is false; the Open World Assumption, on the other hand, says that anything that isn't known to be true is simply unknown. For example, the assertion 'valine is hydrophobic' if we ask the question 'Is valine hydrophilic?' in a Closed World context, the answer would be 'no'; because we don't have either a statement saying it is true or means by which it can be inferred; in an Open World, the answer would be 'I have no idea'.

In a Closed World, the assumption is that we have all there is about a domain contained within a system; for example, a database of all the students enrolled at a particular university can easily answer the question 'Is this student enrolled?' yet if the person is not recorded in the database as in the world. The Open World Assumption is useful when a system is trying to describe something using incomplete information. A database of sequences is an example of data that could be interpreted under an Open World Assumption. You can ask, 'Is there a human gene with diabetes', the only sensible answers are 'yes' or 'we haven't found one yet'.

The way logic and reasoning in Open and Closed Worlds differs considerably. Imagine that, to build an amino acid ontology from scratch, we make the assertions: 'There are two types of charge: positive and negative', 'Charged amino acids have exactly one type of charge' and 'There is a positive amino acid'. Next, we would also need to assert that there is a negatively charged amino acid. In a Closed World, this would be invalid, as we said a charged amino acid is not only to have one type of charge, and in an Open World, perhaps unnecessary, would not be an error, but would instead result in a new inferred axiom being generated by our reasoning that 'positive' and 'negative' charges must be the same thing, unless we don't say explicitly otherwise!
