Recall the binary examples of Figure 6.4, where each binary digit represents a power of two (1, 2, 4, 8, etc.); similarly, each binary digit represents a fractional power of two (1/2, 1/4, 1/8, 1/16, etc.). Some examples of positive 8-bit fractions are shown in Figure 6.5.

The precise representation in memory is somewhat more complicated than this illustration might suggest (see Box 6.1 for an explanation of the floating-point representation); however, the most important aspect of such fractional systems is their 'coverage'. There are a finite number of values in any finite integer range, allowing sufficiently wide binary representation to encode all its values. However, there are an infinite number of values in any non-trivial real and no representation can encode an infinite number of values in a finite number of bits. This means that there are 'holes' in the real line that a given fractional representation simply cannot encode. In fact, necessarily there are an infinite number of unencodable values.

In practice, unencodable values are rounded up or down to the nearest representable number, otherwise practically no calculation would ever succeed. Unencodable numbers are so common that it is almost impossible to come across them in everyday calculations. As we will see at the start of this section, this is true of even the simplest, most common decimals: the value defined using the standard IEEE 754 single-precision floating-point representation (see Box 6.1). The nearest representable number is the long-wind 0.100000001490116384765625. This represents an error of more than one in a billion. These rounding errors, introduced in the course of everyday computation with floating-point numbers, can cause problems if they're not expected. Even when they are expected, they can be difficult to manage, depending on the application: even minor errors can grow exponentially over the course of a program's lifetime, while each subsequent calculation can multiply that while introducing more error itself, pushing the result further away from the ideal mathematical value.
