(a) Linking databases via AC numbers and IDs; (b) illustration of how changes to the UniProtKB/Swiss-Prot ID and AC number show in broken links in the host database (grey arrows), and invisibility of the UniProtKB/Swiss-Prot entry to access databases that links to its primary AC number or ID (grey box).

Here, the connectivity of the primary database AC requires all databases around the world to echo the change, otherwise that entry effectively becomes invisible to all of those resources, as illustrated in 4.12(b). Another challenge faced by tools like SRS is that databases have grown to a size that many institutes struggle to house and maintain local copies – the larger the database (or sets of databases), the longer the indexing takes to run for online and the other for off-line indexing.

MRS is a query and information-retrieval tool that was developed, at least in part, to address this for speed, for speed and ease-of-use (Hekkelman and Friend, 2005). MRS-files contain both the data and their indices, which remain synchronous, compressing them so that they require less disk space than the raw data. Multiple MRS-files can be integrated, allowing public and private-house data to be merged. MRS offers a fast, robust and freely available alternative to SRS.
