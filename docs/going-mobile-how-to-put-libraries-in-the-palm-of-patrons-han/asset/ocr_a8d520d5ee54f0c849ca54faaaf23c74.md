Patrons increasingly expect access to their libraries anywhere, anytime. This ALA Editions Special Report provides practical guidance for how librarians can put the library in the palms of their patrons’ hands. Using the HTML skills that many librarians already have, combined with flexible development tools, technology expert Scott La Counte shows how creating a customized mobile app doesn’t need to be expensive or require deep expertise. In straightforward, practical terms he

+   - Demonstrates how to establish a presence on the mobile web with mobile websites and phone apps
+   - Details open-source development tools such as PhoneGap that enable the creation of mobile apps that work on a variety of mobile operating systems
+   - Discusses methods for assessing a library’s user base and for getting buy-in from administrators

Following the pointers in this ALA Editions Special Report, libraries can easily go wherever their patrons do!
