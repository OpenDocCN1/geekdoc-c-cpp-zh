# REDIRECTING TO A MOBILE SITE

If you decide to have a mobile version of your site, then you will have to decide how to get phone users to it. There are two ways. First, simply have two addresses that you give out: a computer address and a mobile address. You can tell your patrons to add “m” to the address when accessing the site from a phone (e.g., m.library.com).

The second way is a little more difficult. It requires that you add code into your page that tells the page to search for the user’s browser. If they are using a mobile browser, then they will be redirected to the mobile-friendly site. You need to understand PHP programming to implement such a task. You can also buy the code for $50 (http://detectmobilebrowsers.mobi/).
