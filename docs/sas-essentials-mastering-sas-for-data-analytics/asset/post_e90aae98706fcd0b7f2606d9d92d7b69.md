**ADDITIONAL TECHNIQUES:** Beyond the original six DEFINE statement options (options that appear after *DEFINE var*), there are several other ways you can enhance the output of your report. The next two examples illustrate these additional techniques.

**Reporting Multiple Statistics:** In the COLUMN statement, you can request multiple statistics for a variable by placing a request in parentheses. For example:

```
COLUMN BRAND CITYMPG, (N MEAN STD);
```

The following Hands-on-Example illustrates this technique.

# HANDS-ON EXAMPLE

- 1. Open the program file AREPORT7.SAS.

```
TITLE "PROC REPORT Multiple Statistics Example";
PROC REPORT DATA=MYSASLIB.CARS NOFS;
COLUMN BRAND CITYMPG, (N MEAN STD) HWYMPG ENGINSIZE ;
DEFINE BRAND/GROUP;
DEFINE CITYMPG/ FORMAT=6.1 'City MPG';
DEFINE N / 'N' format=4.;
DEFINE HWYMPG/ ANALYSIS MEAN FORMAT=6.1;
DEFINE ENGINSIZE/ ANALYSIS MEAN FORMAT=6.1;
RUN;
```

(continued) Note the COLUMN statement Multiple where some statistics are listed with parentheses (N MEAN STD). Submit the code and observe the output given (partial) in Table 19.22. Note the N, MEAN, and STD in the CITYMP column.

In particular, note the two DEFINE statements all related to CITYMP. The first statement defined the label and format for CITYMP. The FORMAT=6.1 applies to all of the statistics in the parentheses (N MEAN STD). However, the second DEFINE specifies a separate format for N, so it appears as an integer.

Reporting Totals and Subtotals: As in PROC PRINT, you may want to display totals at the bottom of a column of numbers. To do this in PROC REPORT, use the BREAK and RBREAK statements. The BREAK statement produces a summary at a specified break, and RBREAK specifies a summary at the beginning or end of a report. A simplified BREAK statement syntax is

```
BREAK <BEFORE|AFTER> var/SUMMARIZE <SUPPRESS>;
```

```
RBREAK <BEFORE|AFTER> /SUMMARIZE;
```

# 19.2 Writing Reports in Data Statement

Another way to create reports from a data set is to use the PUT statement within DATA step. Typically this is done using the following technique:

- 1. Specify the name NULL as the data name in DATA step to be able to use the features of the DATA step (Because you are interested in creating a report rather than creating data set.)
- 2. Define a destination (output file) for the report using a FILE statement. The statement FILE prints the report output to the SAS Viewer. When you use FILE "...", the report output is sent to the specified text file.
- 3. Use PUT statements in the DATA step to create lines of output for the report.

# HANDS-ON EXAMPLE

The heart of DATA statement report is the PUT statement. By default, PUT statement displays information for each record in a data set in the SAS Log. For example, open the program file REPORT1.SAS

```
DATA _NULL_; SET MYSASLIB.CARS;
    PUT AGE;
RUN;
```
This simple program lists the values of AGE for each record in the specified data set. In this case, when no FILE option is used, the report output is sent to the SAS Log.

- 1. Run this program and observe the output in the log. Note that there are 5 lines of ages there.
- 2. You typically want to display the results of your report in the Results Viewer or capture the results in a file. To display the output in the Results Viewer, include the statement FILE PRINT in the code:

```
DATA _NULL_; SET MYSASLIB.CARS;
    FILE PRINT;
    PUT AGE;
RUN;
```

Rerun the code and observe the output. This time the values of AGE are displayed in the Results Viewer.

- 3. To make the report more interesting, change the PUT statement to read

- 4. Alternatively, you can specify an output file as the destination for the report. Change the FILE PRINT statement to

```
FILE "C:\SASDATA\OUTPUT.TXT";
```

Run the revised program. Go to Windows and look in the C:\SASDATA folder. Open the file named OUTPUT.TXT to verify that the report was written to that.

There are a number of ways to customize each line of output using the PUT statement. Common options for the PUT statement. Table 19.24 lists small data containing grades for a class. The goal is to create a summary report that includes a listing of grade, each student's grade average, and an average for the class. The data are the following, which are results of three tests.

| Alice, Adams | 88.4 | 91 | 79 |
| Jones, Steve | 99 | 100 | 88.4 |
| Zabar, Fred | 78.6 | 87 | 88.4 |

To make student's grades available for the report, AVE is calculated when the data set GRADES is created using the following code:

```
DATA GRADES;
INPUT NAME $15. G1 G2 G3;
AVE=MEAN(of G1-G3);
DATALINES
Alice, Adams 88.4 91 79
Jones, Steve 99 100 88.4
Zabar, Fred 78.6 87 88.4
;
RUN;
```

Because we also want to include the class average in the report, PROC MEANS is used to calculate that value, using the following code:

```
PROC MEANS DATA=GRADES NOPRINT; OUTPUT=GMEAN;RUN;
```
