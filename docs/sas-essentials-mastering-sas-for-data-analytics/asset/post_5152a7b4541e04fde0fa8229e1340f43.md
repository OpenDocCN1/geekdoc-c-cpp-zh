You can change this default using the statement YEARCUTOFF=19XX in your program. For example, if you specify YEARCUTOFF=1925, a two-digit year that is between 00 and 24 will be interpreted in the twenty-first century (e.g., 21 will be interpreted as 2021), and from 25 to 99 will be interpreted in the twentieth century (e.g., 44 will be interpreted as 1944):

```
DATDIF(date, edate, basis)
```

returns the number of days between two dates. Basis is (default) '30/360', 'ACT/ACT', 'ACT/360', or 'ACT/365'. The BASIS option tells SAS what counting method to use for days (These are some day-count conventions used in investing, accounting, and other disciplines.)

- '30/360' means to use a 30-day month and a 360-day year.
- 'ACT/ACT' means to use the actual number of days.
- 'ACT/360' means to use the actual number of days in each month and 360 days in a year.
- 'ACT/365' means to use the actual number of days in each month and 365 days in a year.

For example,

```
DAYS=DATDIF('07JUL1976d', '01JAN2013d', '30/360');
```

returns the value (number of days) as 13,134, whereas

```
DAYS=DATDIF('07JUL1976d', '01JAN2013d', 'ACT/ACT');
```

returns the value (number of days) as 13,327. These integer values can be displayed in a date-readable manner by applying a date format to the variable as such

```
FORMAT DAYS MDDDY10 ;
```

## HANDS-ON EXAMPLE

1. To calculate the number of days between two dates, use the DATDIF function. For example, if you want to find the number of days between July 7, 1976, and January 1, 2013, using the 30/360 basis:

```
DAYS=DATDIF('07JUL1976d', '01JAN2013d', '30/360');
```

returns the value (number of days) as 13,134, whereas 

```
DAYS=DATDIF('07JUL1976d', '01JAN2013d', 'ACT/ACT');
```

returns the value (number of days) as 13,327. These integer values can be displayed in a date-readable manner by applying a date format to the variable as such

```
FORMAT DAYS MDDDY10 ;
```

2. To calculate minutes and hours between two dates, use the INTCK function. For example, if you want to find the number of weeks between July 7, 1976, and January 1, 2013:

```
WKS=INTCK('WEEK', '07JUL1976'd, '01JAN2013'd);
```

3. To extract the month and day from a date, use the MONTH and DAY functions. For example, if you want to extract the month and day from a date:

```
M=MONTH('07JUL1976d');
D=DAY('07JUL1976d');
```

### B.5 CHARACTER FUNCTIONS

Character functions allow you to manipulate text values. These functions are essential when you must extract information from text values, when you need to create a new text value from several pieces of information, or when you need to “clean up” text values to make them better data analysis.

Table B.6 lists some of the functions used to manipulate character/text variables.

### Table B.6 Character Functions

| Function | Description |
| :--- | :--- |
| CAT(text1, text2, ...) | Concatenates text without removing leading or trailing blanks. CAT removes leading and trailing blanks and CATT removes trailing blanks. For example, |
| CAT(text1, text2, ...) | RESULT=CAT("GEORGE", "WASHINGTON"); Returns the value GEORGE WASHINGTON, and for example, |
| CATT(text1, text2, ...) | RESULT=CATT("GEORGE", "WASHINGTON"); Returns the value GEORGEWASHINGTON |
| CATX(separator, text1, text2, ...) | Removes leading and trailing blanks and inserts a separator between concatenated components. For example, RESULT = CATX(":", "GEORGE", "WASHINGTON"); Returns the value :WASHINGTON |
| COMPBL(text) | Removes multiple blanks between words in a character string |
| COMPRESS(text<characters-to-remove>) | Removes specified characters from a character string |
| FIND(text, text-tofind, <modifiers>, <start>) | Removes quotation from text. Finds an instance of the text within the text. Start is an optional value and modifiers are I ignore case and T for ignore blanks. For example, RESULT=FIND("aBcDef", "DEF", "I"); Returns a value of 4 because DEF begins at the character of ABCDEF (and case is ignored). If no match is found, a value of 0 is returned |
