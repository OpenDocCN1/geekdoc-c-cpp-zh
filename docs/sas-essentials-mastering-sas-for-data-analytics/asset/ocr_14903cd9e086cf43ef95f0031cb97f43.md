# 3.7.2 Importing Data Using the SAS Code

Instead of using the Import Wizard to import CSV (or other data files), you can import data using SAS code. This technique is handy when you are importing a number of similar files. For example, suppose that your CSV data changes over time and you need to re-import it ever changes. When the SAS program is running, it reads the data from the CSV file and creates an SAS data set that you can use in an analysis.

In the Previous Import example, we requested that SAS use the code to import the CARSMP data set. The wizard created PROC IMPORT to perform the import, and because we requested it, "wrote" that code to a file we named IMPORTCAR.SAS. The code created by Wizard is as follows:

```
PROC IMPORT OUT=WORK_MPG_FOR_CARS
    DATAFILE="C:\SASDATA\CARSMP.CSV"
    DBMS=CSV REPLACE;
    GETNAMES=YES;
    DATAROW=2;
```

RUN;

(It may be slightly different on your version of SAS.) If you submit this code from the SAS editor, it performs the exact import performed by the wizard. A simplified syntax for PROC IMPORT is as:

```
PROC IMPORT OUT=dataset
    DATAFILE="filename"
    DBMS=dbmsidentifier <REPLACE>
    <GETNAMES=YES>; *DEFAULT IS YES
<DATAROW=n>; *DEFAULT IS 2;
```
