For the examples in this book, we will create the SAS Library nickname and use it for the following exercises:

+   * The SAS library name: MYASLIB
* The location of the windows folder: C:\SASDATA

Therefore, when the library name MYASLIB is used in a filename, it will refer to a file located in the C:\SASDATA folder. Note that if you've chosen to place the sample files for this a different folder than C:\SASDATA, you need to make appropriate adjustments to the library definition in the Hands-on Examples and chapter exercises.

The following sections describe methods for creating the relationship linking a Windows folder location to an SAS Library name. Two important points to grasp are the following:

+   * Every SAS library has a name such as MYASLIB, RESEARCH, MYDATA, and so on.
* Every SAS library name is a nickname that points to a specific folder such as C:\SASDATA, N:\NETWORK\DRIVE, I:\MYFLASH\DRIVE, and so on.

In the SAS program, every SAS data set has two parts to its name. For example, the SAS data referred to MYASLIB.MAY2000 consists of the following:

+   * the library named MYASLIB;
* the data set named MAY2000.

Even temporary files can be referred to with a (temporary) library name, WORK. There, a file named WORK.LOTSDATA consists of:

+   * the library named WORK (refers to the temporary library);
* the data set named LOTSDATA.
