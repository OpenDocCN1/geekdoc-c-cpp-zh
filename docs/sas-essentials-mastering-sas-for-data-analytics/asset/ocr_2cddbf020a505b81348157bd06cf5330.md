# USING SAS FUNCTIONS

Functions can require one or more arguments. Some require no arguments.
 example, a few mathematical functions in SAS are as follows:

```
S = ABS (X) ;      Absolute value
S = FACT (X) ;     Factorial
S = INT (X) ;       Integer portion of a value
S = LOG (X) ;       Natural log
S = SQRT (X) ;     Square root
```

Some of the other functions available in SAS are SUBSTR, LAG, COS, SIN, ARCS,
LOG10, UNIFORM, NORMAL, SUM, and MEAN. A list of commonly used SAS
and additional examples can be found in Appendix B. These include functions of these
types:

+   - Arithmetic/Mathematical
- Trigonometric
- Date and Time
- Character
- Truncation
- Special Use and Miscellaneous
- Financial
- Access Previous Observations (Lags)

Functions can also be used as a part of a more extensive calculation. For example,

```
C = MEASURE + SQRT(**2 + B**2);
```

would calculate the square of A and then the square of B, then add those numbers, take
the square root of that, then add that number to the value of MEASURE, and assign
the result to the named C.
As mentioned previously, functions may require no argument, one argument, or multiple
a few multi-argument functions in SAS are the following:

```
S = MAX (x1, x2, x3, ... ) ; Maximum value in the list of arguments
S = MIN (x1, x2, x3, ... ) ; Minimum value in the list of arguments
S = SUM (x1, x2, x3, ... ) ; Sum of non-missing values in a list of arguments
S = MEDIAN (x1, x2, x3, ... ) ; Median of a list of non-missing values
S = ROUND (value, round);  Rounds value to nearest round-off unit
```

These functions allow missing values in the list. Thus, the SUM function

```
TOTAL=SUM(TIME1,TIME2,TIME3,TIME4);
```

can create a different answer

```
TOTAL= TIME1+TIME2+TIME3+TIME4;
```
