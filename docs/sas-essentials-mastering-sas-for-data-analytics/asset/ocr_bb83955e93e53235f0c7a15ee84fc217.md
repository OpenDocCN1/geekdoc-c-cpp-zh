# 19.1 Tabulate procedure

Open the program file EX_19.1.SAS. This file contains a program that creates a table showing average CITYMP by BRAND AND SUV.

```
PROC TABULATE DATA=MYASLIB.CARS;
  CLASS BRAND SUV;
  VAR CITYMP;
  TABLE BRAND, SUV*MEAN*CITYMP;
RUN;
```
