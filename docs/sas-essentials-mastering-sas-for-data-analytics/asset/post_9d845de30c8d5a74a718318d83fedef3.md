## 10.4.1 Creating a Contingency Table from Raw Data, the 2 ×2 Case

If your data are stored as individual observations in a SAS data set, you can use the PROCQ procedure to create a table of counts and analyze the results. The following Hands-on Example illustrates this.

### HANDS-ON EXAMPLE

In this example, we consider a data set collected for the purpose of studying the relationship between two floor cleaners and the presence or absence of a rash on the hands. The data for 40 subjects are in a SAS data set named RASH.SAS. A few of the records are shown here coded 1 or 2, and the presence of a rash is coded Y or N.

1. Open the program file FREQ.SAS.

```sas
PROC FREQ DATA=RASH /CHISQ;
TABLE CLEANER*RASH ANALYSIS FOR 2X2 TABLE;
TITLE 'CHI-SQUARE ANALYSIS';

In this case, the chi-square statistic, 8.29, $p=0.004$, indicates an association between CLEANER and RASH (rejects the null hypothesis that the proportion rash for the two cleaners is the same). The continuity adj. chi-square (sometimes called Yates' chi-square) is an adjustment that some statisticians use to improve the chi-square approximation in the case of 2x2 table. Typically, the two-sided p-value Pr ≤ P is the correct value to report except in specialized cases. For this example, the Fisher's p-value is p <0.0095.

## 10.4.2 Tables with Small Counts in Cells

When you summarize counts in tables, and there are small numbers in one or more cells, a typical chi-square statistical analysis may not be valid. For example, suppose you have sampled freshmen and sophomores at a college to see if they advantage of the Learning Enhancement Center (LEC) tutorials and you want to know if the proportion using the center differs. The following example illustrates how this example (with a small sample size) can lead to interpretation problems.

### HANDS-ON EXAMPLE

This example creates a 2x2 table from count data, but the sample size is small enough that there are interpretation problems.

1. Open the program file FREQ.SAS.

```sas
DATA LEARN;
INPUT CLASS $ LEC $ COUNT;
DATALINES;
S Y 4
S N 11
Y 5
N 3
;
PROC FREQ DATA=LEARN;WEIGHT COUNT;
TABLES CLASS*LEC/CHISQ;
TITLE 'Chi Square Analysis of a Contingency Table';
RUN;
```

2. Change the TABLES statement to

```sas
TABLES CLASS*LEC/CHISQ EXPECTED;
```

Resubmit the program and observe the output. The cross-tabulation table is given in Table 10.16. Because this uses the EXPECTED option, it displays expected frequencies in each cell.
