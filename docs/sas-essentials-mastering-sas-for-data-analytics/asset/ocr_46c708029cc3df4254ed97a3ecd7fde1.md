# HANDS-ON EXAMPLE

1. Open the program file AREPORT4 .SAS.

```
PROC REPORT DATA=MYSASLIB.CARS NOFS;
COLUMN BRAND CITYMPG HWMPG;
DEFINE BRAND/GROUP;
DEFINE CITYMPG/ANALYSIS MEAN FORMAT=6.1 'CITYMPG';
RUN;
```

Instead of defining MEAN in the COLUMN statement, the ANALYSIS option allows you to indicate the CITYMPG variable in a DEFINE statement. (The default is SUM.) (You can leave off the ANALYSIS option in the DEFINE statement and it will still work.) Submit this code and observe the output given (partially) in Table 19.19. Note that the mean is reported for CITYMPG, but the SUM is reported for HWMPG.

2. Create a DEFINE statement with (ANALYSIS) that causes the mean HWMPG to be displayed with a 6.1 format and with an appropriate label. Resubmit the code to verify that your changes produced the expected results.
