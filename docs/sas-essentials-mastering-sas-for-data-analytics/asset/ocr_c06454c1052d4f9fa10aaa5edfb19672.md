# ORDER OPTION: THE DEFINE var / ORDER option defines a column variable used to sort the data. You can control the order by adding DESCENDING to reverse the order and an additional ORDER= specify FORMATTED (default), FREQ, INTERNAL, or DATA order. The following Hands-on Example illustrates this option.

# HANDS-ON EXAMPLE

+   1. Open the program file REPORT2 .SAS.

```
TITLE "ORDER OPTION EXAMPLE"
PROC REPORT DATA=MYSASLIB.CARS NOFS;
COLUMN BRAND CITYMPG HWYMPG;
DEFINE BRAND/ORDER 'BRAND=';
DEFINE CITYMPG/DISPLAY FORMAT=6.1 'CITY MPG';
DEFINE HWYMPG/DISPLAY FORMAT=6.1 'HIGHWAY MPG';
RUN;
```

In this example, the BRAND/ORDER option in the DEFINE statement causes the report to be ordered by car brand. The other DEFINE statements are similar to the previous example. Submit this code and observe the (partial) output given in Table 19.17.
