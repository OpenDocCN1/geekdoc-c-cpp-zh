# 5.7 GOING DEEPER: SPLITTING COLUMN TITLES IN PROC PRINT

The statements illustrated for PROC PRINT are the most commonly used, but there are other statements available that can enhance your listing ever.
One handy statement is SPLIT= allows you to specify how labels are split in column titles.

Normally, SAS splits titles when needed to conserve space in a report. For example, the following SAS program (APRINT.SAS) defines labels for a number of variables. The following SAS PROC PRINT options FIRSTOBS=11 and OBS=100 to limit the number of records listed.

```
PROC PRINT DATA="C:\SASDATA\TRAUMA"
(FIRSTOBS=11 OBS=100);
VAR KEY AGE GENDER INJYPE DISSTATUS;
LABEL INC_KEY='Subject Id ' 
AGE='Age in 2014' 
GENDER='Gender ' 
ISS='Injury Severity Score ' 
INJYPE='Injury Type ' 
DISSTATUS='Discharge Status';
RUN;
```

When this is run, it produces the output given in Table 5.12.
Observe how certain labels are split across two lines. SAS does this, so columns are not too wide. This is a good default feature. However, SAS allows you to be more specific. You can tell SAS where you want the labels to be split using the SPLIT= option.
