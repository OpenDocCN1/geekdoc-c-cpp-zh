# TABLE A.2 Common ODS Style Options

| Style Item | What It Sets |
|---|---|n| BACKGROUND= | Sets the color of the cell background. For example, BACKGROUND=YELLOW |
| FLYOVER= | Displays text when the mouse is moved on top of the item. For example, FLYOVER="Summed Value" |
| FONT= | Defines a definition for the font. For example, FONT="SWISS", 10pt |
| FONT_FACE= | Specifies the typeface. For example, FONT_FACE=SCRIPT |
| FONT_SIZE= | Specifies the font size. For example, FONT_SIZE=12 |
| FONT_WEIGHT= | Specifies the weight of font. For example, FONT_WEIGHT=BOLD |
| FOREGROUND= | Specifies the color for text and column labels not otherwise specified. For example, FOREGROUND=LIGHTBLUE |
| JUST= | Specifies cell justification (horizontal, left, right, or center). For example, JUST=LEFT |
