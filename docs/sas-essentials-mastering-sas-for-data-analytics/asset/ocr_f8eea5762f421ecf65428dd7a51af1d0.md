# 7.5 SUMMARY

This chapter provides information on two topics that allow you to write SAS code that can simplify complex procedures: mainly arrays and macros. Arrays can simplify creating and using large data structures that must be manipulated by code. Macro variables allow you to create generalized programs, and macro routines allow you to create code that can be used over and again.
