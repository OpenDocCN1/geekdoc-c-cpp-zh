# 18.6 CREATING BOXPLOTS

Examples in earlier chapters have shown how default SAS output creates boxplots in cases. This section provides information on methods for creating and enhancing boxplots. The abbreviated syntax for this procedure is as follows:

```
PROC BOXPLOT <DATA=dataset>; <options>;nPLOT <devpar=>groupvar(s)</options>
<statements>;
```

The PLOT statement is required. For example, a typical use (group must first be sorted):

```
PROC BOXPLOT DATA = MYDATA;
PLOT HEIGHT*GROUP;
RUN;
```

There are numerous options for PROC BOXPLOT. Some commonly used statements are listed in Table 18.10.
Options for the PLOT statement appear after a slash. For example:

```
PROC BOXPLOT DATA=CARDATA;
PLOT HWYPG*CYLINDERS/CBOXFILL=LIGHTGREEN;
```

Some common options for the PLOT statement associated with PROC BOXPLOT are listed in Table 18.11.
A number of other options are available, many similar to those listed for PROC GPLOT (see SAS documentation for more details).
