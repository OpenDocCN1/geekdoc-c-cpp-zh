## 6.4.5 Correct Date and Time Values

The date and time arrived the clinic are needed to calculate how long it took to serve each patient. However, these values are currently of character type. The following example illustrates how to convert character variables to date and time. For example, to convert the DATEARRIVED:

```
DATEARRIVED=INPUT(TRIM (DATEARRIVED),MMDDYY10.)
```

The new (converted) value must have a new name. In this case DATEARR2 you cannot convert a value to a different type and keep the same name. In this version, the DATEARRIVED value is first trimmed using the TRIM () function. The TIME value is a little trickier because the text value for TIME includes AM or PM, this information needs to be stripped off before it can be converted. To do this, the blank before AM or PM is located using the FIND () function:

```
I= FIND(TIMEARRIVE, " ");
```

However, you want to know if TIME was AM or PM because information is needed to convert TIME to 24-h style (military-type) time. Therefore, perform a second FIND and look for P as will uniquely indicate PM. Use this code:

```
P= FIND(TIMEARRIVE,"p ");
```

If P is greater than 0, then a P is in the statement, and you know that the time represents a value after noon. Otherwise, the time represents a time before noon (AM).
The result of these two FIND () functions is a value for I representing the location of the blank before AM or PM and P representing whether the time is before or after noon. The I is used with a SUBSTR () function to extract a sub-string that contains only the time information:

```
TIMEARRIVE=SUBSTR(TIMEARRIVE,1,I-1);
```

Use an INPUT () function converting the resulting value for TIMEARRIVE to a new DATE-type variable called TIMEARRIVET by applying the time format TIME8.

```
TIMEARRIVET=INPUT(TRIM (TIMEARRIVE),TIME8.)
```
