# CREATING SCATTERPLOTS AND LINE GRAPHS USING GPLOT 399

# HANDS-ON EXAMPLE

This example illustrates how to change the style of a plot’s points and regression line.

+   1. Open the program file AGRAPH2 .SAS.

```
OPTIONS RESET=ALL;
Title "Simple Scatterplot, Change symbol";nPROC GPLOT DATA=MYASLIB.CARS
PLOT HWYMP*CITYMPG
SYMBOL V1=STAR I=RL C=BLUE L=2;
RUN;
QUIT;
```

+   2. Run this program and observe the output shown in Figure 18.2.

+   Note on your screen that the following items are specified for this plot (see Appendix A for more information).

+   * The displayed symbol is a star (V=STAR).
* The displayed symbol is blue (C=BLUE).
* A regression line is displayed (I=RL).
* The displayed line is dotted (L=2).

+   3. Change the C, V, and L options by choosing other values from the definitions listed in Appendix A and rerun the plot to observe how changing these options modifies the plot.
