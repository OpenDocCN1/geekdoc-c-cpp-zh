To turn ODS graphics back on

ODS GRAPHICS ON;

You can also turn off ODS graphics by selecting (in SAS) the menu options Tools → Options → Preferences, and select the Results Tab. The dialog box shown in Figure 8.3 is displayed. Note the option Use ODS Graphics. If you want to turn off ODS graphics, check this box.

Although SAS automatically produces plots for numerous procedures, there may be additional plots you that are not automatically created. In this case, many procedures have added PLOT options that allow you to make these types of requests. As an example, consider the following example:

# HANDS-ON EXAMPLE

PROC FREQ DATA="C:\SASEDATA\SOMEDATA";\TABLES STATUS;
