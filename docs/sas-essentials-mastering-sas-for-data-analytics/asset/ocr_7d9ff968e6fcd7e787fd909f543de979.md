When a variable is defined as a classification variable

Another way to handle categorical variables with three or more categories is to recode
into a series of dichotomous variables (sometimes called indicator or dummy variables). One way to do this is to make ORs easier to interpret. For example, with
the character coding of RACE, you could create 0/1 variables. In the DATA
step, you could define

```
IF RACE="AA" then RACEA=1; ELSE RACEA=0;
IF RACE="H" then RACEH=1; ELSE RACEH=0;
IF RACE="C" then RACEC=1; ELSE RACEC=0;
```

You need less than the number of categories. Therefore, for RACEA, RACEH, and
RACEC are all 0, the race must be OTHER.
