
You're not finished yet! Time is recorded as AM or PM, you may need to adjust the time. If the time is in the afternoon (if P=1), you want to add 12 hours to the recorded time value. Because the time value is in seconds, you calculate the number of seconds in 12 hours is 12×60×60=43200, so the conversion statement is

```
IF P>0 THEN TIMELEFT=TIMELEFT+43200;
```

Finally, the DHS () function is used to combine the date and time values using the code:

```
ARRIVEDT=DHMS(DATEARRIVED2,0,0,TIMEARRIVET)
```

The arguments for the DHS () function are DATE, HOUR, MINUTE, and SECONDS. In this case, we use

- DATEARRIVED2 as the DATE value
- TIMEARRIVET as the SECONDS value
- Because the seconds incorporate hours and minutes, we enter 0 for the HOUR and for MINUTE arguments.

Appropriate formats are also used so that date and time values are displayed appropriately. Unneeded variables are dropped. The following example illustrates how this is done.
