Part 2 of the code creates a data set called BARCHART that includes a new variable named HTMLLINK that is defined for each of the three groups. The third section of the code creates the bar chart using GCHART. In PROC GCHART, the statement option /HTML/ is in the line

```
HBAR GP/ HTML=HTMLLINK;
```

relates the HTML link (HTMLLINK) to each category of GP. Part 3 of the code creates the bar chart.
