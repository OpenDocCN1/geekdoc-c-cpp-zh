+   - However, they are not saved in the output data set.
- And they cannot be renamed, kept, or dropped.

The value of understanding how SAS handles data as it is read from raw data sources is that it provides you with insight in writing code to successfully input the data in the way you want it to be. The brief discussion here is only an introduction to this process. If you want to delve deeper into the inner workings of the DATA step, refer to SAS documentation.
