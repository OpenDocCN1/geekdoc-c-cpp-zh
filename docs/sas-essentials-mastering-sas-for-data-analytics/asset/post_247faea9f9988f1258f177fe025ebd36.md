All of the data manipulation statements discussed in this chapter appear in your program within the DATA step, except for PROC FORMAT. That is, they appear after the DATA statement and before the first RUN. Thus, all of the results performed by these statements become part of the active data set.

## 4.1 LABEL VARIABLES WITH EXPLANATORY NAMES

SAS labels are used to provide descriptive names for variables. Data sets often contain cryptic names such as ID, WT, and on. For people familiar with the data, these make sense. However, if you want to produce output that is readable by others, creating explanatory labels for variables is good practice. In SAS, this can be achieved using the LABEL statement. The LABEL statement uses:

```sas
LABEL VAR1 = 'Label for VAR1'
VAR2 = 'Label for VAR2';
```

You can use single or double quotation marks in the LABEL statement, but they must match type. When SAS prints out VAR1, it also includes the label, making the output more readable. The following program illustrates these labels:

```sas
DATA MYDATA;
INFILE 'C:\SAS\DATA.DAT';
INPUT ID $1-4 DBP $5-7 AGE $9-10 WT $11-13;
LABEL ID = 'Identification Number'
SBP = 'Systolic Pressure'
DBP = 'Diastolic Pressure'
AGE = 'Age on Jan 1, 2000'
WT = 'Weight';
PROC MEANS SBP DBP WT;
RUN;
```

Notice that the LABEL statement is placed within the DATA step. Also, there is only one semicolon at the very end. The output listings in Tables 4.1 and 4.2 show how the LABEL statement adds information to the output. The first set of output shows PROC MEANS without the LABEL statement. Notice that all variable names are listed as they were created from the INPUT statement. The next set of output from PROC MEANS is the same data, and in this case, the LABEL statement, as shown in the aforementioned example, is used. In this case, more informative labels are included in the output. Follow the next Hands-on Example to add label definitions for a data set within the DATA step.

## HANDS-ON EXAMPLE

In this example, you will create labels for variables and learn how to output the labels using PROC LABEL2.SAS.

1. Open the program file LABEL2.SAS.

```sas
DATA MYDATA;
INPUT @1 FNAME $11. @12 LNAME $12. @24 BDATE DATE9;
FORMAT BDATE WORDDATE12;
LABEL FNAME="First Name"; * Complete the labels;
DATALINES;
Bill Smith 08JAN1952
Jane Jones 02FEB1953
Clyde York 23MAR1949
;
PROC PRINT;
RUN;
```

2. Add to create labels for LNAME (Last name) and BDATE (Birth date). For example, the LABEL statement could be as follows:

```sas
LABEL FNAME="First Name"
LNAME="Last Name"
BDATE="Birth Date";
```

Don't forget the semicolon (;) after the last label definition.
