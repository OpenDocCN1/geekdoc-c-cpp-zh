The basic building blocks for PROC TABULATE are the TABLE, CLASS, and VAR statements.

The TABLE Statement: This statement is the most important component in PROC TABULATE. It is used to define what information will be displayed in the table. For example, this simple PROC TABULATE statement defines a class variable (GP) and a table.

```
PROC TABULATE DATA=sasdataset;
CLASS GP;
TABLE GP;
RUN;
```

# Table 19.1 Common Options for PROC TABULATE

| Option | Explanation |
|---|---|
| DATA=datename | Specifies which data set to use |
| OUT=datename | Specifies an output data set |
| STYLE=styletype | Specifies an ODS style format for the table |
| FORMAT= Specifies a default format for each cell, Best 12 is the default |
| ORDER=option | Specifies order that categories are displayed. Options are UNFORMATTED, DATA, FORMATTED, and FREQ |
| MISSING | Specifies that missing values are to be treated as a category |

| CLASS variables; | Specifies categorical variables |
| TABLE specification; | Identifies the dimensions and other components of the table to create |
