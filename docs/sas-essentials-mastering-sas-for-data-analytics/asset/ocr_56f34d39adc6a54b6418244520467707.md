# HANDS-ON EXAMPLE

1. Open the program file AREPORT8.SAS. This program lists cars by BRAND. Each BRAND is summarized by the number of cars by CYLINDERS. BREAK is used to count the number of cars that are automatic or are SUVs and RBREAK creates a grand total. Submit the code and observe the output given (partial) in Table 19.23.

```
PROC REPORT DATA=MYSASLIB.CARS NOFS;
COLUMN BRAND CYLINDERS AUTOMATIC SUV;
DEFINE BRAND/GROUP;
DEFINE CYLINDERS/GROUP;
BREAK AFTER BRAND/SUMMARIZE SUPPRESS;
RBREAK AFTER/ SUMMARIZE;
WHERE CYLINDERS NE -1 ;
RUN;
```
