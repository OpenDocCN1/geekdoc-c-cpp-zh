where PROCLIB is the name of the SAS Library where your formats are located. For example, if you have previously created and stored the FMTMARRIED and $FMTGENDER formats in your MISASLIB.FORMATS, you could use the following code to access those formats with PROC PRINT (any PROC).

```
OPTIONS FMTSEARCH=(MISASLIB.FORMATS);
PROC PRINT DATA="C:\SASDATA\SURVEY";n  VAR SUBJECT MARRIED GENDER;
FORMAT FMTMARRIED. GENDER $FMTGENDER.
RUN;
```

To discover what formats are in a particular format library, you can use the PROC CATALOG procedure as shown here. This code displays all of the formats stored in the MISASLIB.FORMATS library.

```
PROC CATALOG CATALOG = MISASLIB.FORMATS;
  CONTENTS;
RUN;
QUIT;
```

# HANDS-ON EXAMPLE

In this example, you explore creating and using permanent SAS formats.

+   1. Open the program file DFORMAT3.SAS.

```
PROC FORMAT LIBRARY = MISASLIB.CAT1; *CREATE A FORMAT CATA-
LOG;
  VALUE FMTMARRIED 0="No"
  1="Yes"
  VALUE $FMTGENDER "F" = "Female"
  "M" = "Male"
RUN;
```

Submit this code. Examine the SAS Library named MISASLIB and note that it contains a folder named CAT1. This folder contains the two formats you just created.
