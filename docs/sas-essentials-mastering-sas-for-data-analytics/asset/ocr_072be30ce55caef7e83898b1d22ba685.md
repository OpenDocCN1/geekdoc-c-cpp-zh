# HANDS-ON EXAMPLE

This example shows how you can use a macro to calculate multiple comparisons following a KW test.
This example is based on the previous independent four-group comparison earlier in the chapter, with the addition of code to run a macro procedure performing multiple comparisons.

1. Open the program file ANPAR3.SAS.

```
%INCLUDE C:\SASDATA\KW_MC.SAS;
DATA NPAR;
INPUT GROUP WEIGHT @@;
DATALINES;
1 50.8 157.0 144.6 51.7 48.2 51.3 149.0
2 68.7 267.2 66.3 69.8 66.9 65.2 62.0
3 82.6 374.1 80.5 80.3 81.5 78.6 76.1
4 76.9 472.2 73.7 74.2 70.6 75.3 69.8
;


* BEGIN INFORMATION FOR USING THE SAS MACRO KW>MC;
%LET NUMGROUPS=4;
%LET DATANAME=NPAR;
%LET OBSVAR=WEIGHT;
%LET GROUP=GROUP;
%LET ALPHA=0.05;
Title "Kruskal-Wallis Multiple Comparisons"
****************************************************
invoke the KW MC macro
****************************************************
%KW MC (source=&DATANAME, groups=&NUMGROUPS,
obsname=&OBSVAR, gpname=&GROUP, sig=&alpha);
```

> Note the %INCLUDE statement at the top of the program. This statement tells SAS to get additional SAS code that is is stored in a file in the indicated location. Thus, the file C:\SASDATA\KW_MC.SAS must be at the designated location, or you must change the file name to match the one used in the previous KW example.

The data set used in this program is the same as the one used in the previous KW example on weight gains of animals assigned randomly to four treatments.
