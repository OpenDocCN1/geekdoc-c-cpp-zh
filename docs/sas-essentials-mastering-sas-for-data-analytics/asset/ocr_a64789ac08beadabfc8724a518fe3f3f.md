The Era of “Big Data” has arrived. Organizational data sets are growing by leaps and bounds. Institutions, government agencies, and businesses gather information from individual transactions, which can result in hundreds of thousands of data values each day. Whether the data set you are working with millions of records or a few hundred isn't the point of this chapter. The point is that once you read in your data, you will want to store it in a way that makes it easy to retrieve for analysis. That means you may want to store more than raw data values. You'll want your data set to include variable names, labels for variables, manipulations you've done to get it ready for analysis, and other information.
