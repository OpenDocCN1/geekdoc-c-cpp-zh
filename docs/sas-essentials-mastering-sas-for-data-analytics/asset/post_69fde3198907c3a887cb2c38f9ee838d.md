
# 16.2 PERFORMING A LOGISTIC ANALYSIS USING PROC LOGISTIC

PROC LOGISTIC is the SAS procedure that allows you to analyze the data using a binary model. An abbreviated syntax for this statement is as follows:

```
PROC LOGISTIC < options >;
CLASS variables;
MODEL dependentvar < (variable_options) > =
< independentvars > / options ;
```

The PROC LOGISTIC and MODEL statements are required, and only one MODEL statement can be specified. The CLASS statement (if used) must precede the MODEL statement. Note that the dependent variable must be binary. For simplicity, all of the examples in this chapter use a response variable that takes the values 0 or 1.

By default, SAS assumes that the outcome (with p) in the logistic regression equation corresponds to the case in the dependent variable is 0. If, for example, you have a variable such as DISEASE with DISEASE=0 indicating the disease is absent and DISEASE=1 indicating the disease is present, then SAS will return the probability of "disease absent" by default.

The MODEL statement is the heart of the logistic procedure. It specifies the dependent (outcome) variable as well as the independent variables. For

```
MODEL DEPVAR = INDVAR1 INDVAR2/options;
```

As noted earlier, in this chapter the dependent variable will always be binary (dichotomous). This dependent is often coded 0 and 1 (typically 0 means No, and 1 means Yes) but the variable may take any two values such as 1 and 2, A and B, Alive and Dead, and so on.

Because the logistic model is based on predicting an event, case must be taken as to how the DEPVAR is set up. By default, SAS bases its prediction on the smallest value of the dependent variable. Therefore, if your dependent variable is FAIL (where 0 means failed and 1 means failed), by default SAS will model the prediction for FAIL=0 (not failed). To reverse the dependent, use the DESCENDING option. When that option is included in the PROC LOGISTIC statement, FAIL=1 will be modeled instead of FAIL=0. Another way to choose the model value is to explicitly define it in the MODEL statement. For

```
MODEL FAIL(EVENT='1') = independentvars;
```

will cause SAS to use 1 as the value for the model for the dependent variable FAIL. The EVENT= option is designated a "Response option." When the response is binary, EVENT= FIRST or LAST specifies either the first or last-ordered value used as the prediction event. You can indicate a value in quotes (as in the example code above). We recommend that you choose to either the DESCENDING option (see Table 16.1) or the EVENT= option to specify a value of the response variable to predict, if needed.)

The selection options specify how variables will be considered. The BACKWARD method considers all predictors and eliminates the ones that meet. The FORWARD method brings in the most significant variable. STEPWISE is a mixture of the two. A typical model statement utilizing an automated selection technique would be:

```
MODEL Y = X1 X2 ... Xk
/ EXPB
SELECT=STEPWISE
SLENTRY=0.05
SLSTAY=0.1
```

If a model includes independent variables that are categorical, they must be indicated in the CLASS statement. (However, a dichotomous-independent (predictor) variable is coded as 0 and 1, it does not need to be included in the CLASS statement.) For example, the following model is the same, except it includes two variables CAT1 and CAT2. CAT1 and CAT2 must be numeric (i.e., 1, 2, 3) or of character (i.e., A, B, C). Because CAT1 and CAT2 are categorical, they must appear in the CLASS statement.

```
CLASS CAT1 CAT2;
MODEL Y = X1 X2 ... CAT1 CAT2
/ EXPB
SELECTION=STEPWISE
...
