Our first example is a quick overview of how SAS works. You should not be concerned if you don't know much about the information in the SAS program file at this point. The remainder of the book teaches you how to create and run SAS programs.

# HANDS-ON EXAMPLE

In this example, you'll run your first SAS analysis.

+   1. Launch SAS. SAS initially appears as shown in Figure 1.1. (If a tutorial or some other dialog box appears, dismiss it).
2. Open a program file. This example uses a file named FIRST.SAS. To open this file, make sure that your active window is the Editor Window. (Click anywhere in the Editor Window to make it active window). On the menu bar, select File -> Open Program to open the file C:\SASDATA\FIRST.SAS. You may need to navigate to the C:\SASDATA folder to open this file.
3. Examine the opened file, the contents of which appear in the Editor Window. Maximize so you can see more of the program code if necessary. Figure 1.2 shows the Editor Window maximized. We'll learn more in later chapters about these lines of code.

+   4. Run the SAS job. There are three ways to run (sometimes called submit) your SAS code. (1) On the menu bar, select Run -> Submit, (2) click the "running man" icon on the toolbar, or (3) press F8. Perform any of these to run this code.
