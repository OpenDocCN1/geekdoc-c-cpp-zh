# TABLE 9.11 Common OPTIONS for the PROC UNIVARIATE HISTOGRAM Statement

| Option | Meaning |
| --- | --- |
| Density curves such as NORMAL | Overlays a density curve on histogram. Common options would be NORMAL or KERNEL. NORMAL displays a Gaussian (bell-shaped) curve over the histogram. KERNEL displays a smoothed nonparametric density curve. Characteristics of the curve in parentheses. For example,
HISTOGRAM/NORMAL (COLOR=GREEN W=5); specifies a new curve with width 5 (1 is default). Another example,
HISTOGRAM/NORMAL (COLOR=green W=5)
CFILL=YELLOW; fills the curve with the color specified by the CFILL option. You could also use PFILL to indicate a pattern.
Note: Some color options may not work in some versions of SAS unless you turn off DDS graphics using code as
DS GRAPHICS OFF |
| MIDPOINTS | This option allows you to specify the intervals for the histogram bars
MIDPOINTS = min to max units
For example,
MIDPOINTS=0 to 40 by 2 specifies that the horizontal axis will have a minimum of 0, a maximum of 40, and increment of two units. The intervals of the intervals would be 0, 2, 4, ...40 |
| VSCALE | This option specifies the scale of the vertical axis
VSCALE=type scale (count, proportion, or percent)
For example,
VSCALE=COUNT specifies the scale of the vertical axis will be the number of observations per bin (count). You canleqq request the scale to be proportion or percent |
| WAXIS=width | This option specifies the width of the histogram bars
For example,
WAX=3 specifies that the axis width is three units wide (1 is the default) |
| WBARLINE=width | This option specifies the width of the line around the bar
WBARLINE=width-scale (1 is the default)
For example,
WBARLINE=3 specifies that the lines around the histogram bars are three units wide |
| NRWS=n | Specifies the number of rows or columns in a matrix of histograms specified when a CLASS statement is used to produce multiple histograms. For example,|
| NLS=n | PROC UNIVARIATE;
CLASS GENDER;
VAR AGE;
HISTOGRAM AGE/NROWS=2; produces two histograms one over the other (two rows) |
