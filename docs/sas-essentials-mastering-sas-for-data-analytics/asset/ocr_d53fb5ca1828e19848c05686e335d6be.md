```
; PROC FREQ;
WEIGHT WT;
TABLE RATER1*RATER2 / AGREE ; TEST KAPPA;
TITLE 'Kappa EXAMPLE FROM FLEISS';
RUN;
```

This SAS command is similar to that used for a chi-square analysis except with a/AGREE option to request the kappa statistic and a TEST KAPPA statement to request a kappa analysis.

The “Test of Symmetry” table provides a Bowker’s test of marginal homogeneity. A nonsingular result (which is exactly what you want) indicates that there is no evidence that the two raters have differing tendencies to select categories. In this case, the results are marginally nonsingular (p=0.053).
