# 5.7 GOING DEEPER: SPLITTING COLUMN TITLES IN PROC PRINT

The statements illustrated for PROC PRINT are the most commonly used, but there are other statements available that can enhance your listing ever. One handy statement is SPLIT= allows you to specify how labels are split in column titles.

Normally, SAS splits titles when needed to conserve space in a report. For example, the following SAS program (APRINT.SAS) defines labels for a number of variables. The following SAS PROC PRINT options FIRSTOBS=11 and OBS=100 to limit the number of records listed.

```
PROC PRINT DATA="C:\SASDATA\TRAUMA"
(FIRSTOBS=11 OBS=100);
VAR KEY AGE GENDER INJYPE DISSTATUS;
LABEL INC_KEY='Subject Id ' 
AGE='Age in 2014' 
GENDER='Gender ' 
ISS='Injury Severity Score ' 
INJYPE='Injury Type ' 
DISSTATUS='Discharge Status';
RUN;
```

When this is run, it produces the output given in Table 5.12. Observe how certain labels are split across two lines. SAS does this, so columns are not too wide. This is a good default feature. However, SAS allows you to be more specific. You can tell SAS where you want the labels to be split using the SPLIT= option.

Note the changes. The SPLIT="*" statement SAS asterisk (*) is the delimiter that will be used to split labels into two or more lines. The double underline created by repeated equal signs (=) provides a break between the label and the column contents. The statement OBS='Observation*Number=======' tells SAS to report the total number of observations at the bottom of the listing (N) and to use the specified label for the OBS column. The label contains three sections, each section splits by the delimiter *. Thus the label will be three lines long:

```
Observation
Number
==
```

Labels for the variables are similarly defined where the * tells SAS where to split the labels as they are used in the columns for the listing. The label Gender has * * (note the blank between the *) indicating a skip to make the underline for Gender line up with other labels. Compare this with the previous listing in Table 5.12.

Another feature to note is that labels (like the data values) are either right or left justified depending on whether the column represents numeric or text.

# 5.8 GOING DEEPER: COMMON SYSTEM OPTIONS

Although not part of a PROC statement, System Options can be used to customize the way output is displayed or how data in a data set is used. System Options must be placed in the code such that they are operated before needed by any following code. Usually, this is at the top of the code file. We'll use System Options in some examples throughout the text as needed, and they will be described when used. This section introduces some commonly used options. System Options are specified using the OPTIONS statement.

```
OPTIONS option1 option2 ;
```

Any number of options may be included in a single statement. The System Options listed in Table 5.14 are ones that are commonly used. Some of those options will be used in upcoming examples.

| System Options | Meaning |
| --- | --- |
| FIRSTOBS=n and OBS=n; | Specifies the first observation to be used in a data set (FIRSTOBS= and the last observation to be used (OBS).<br>For example<br>OPTIONS FIRSTOBS=2 OBS=21;<br>causes SAS to use data records 2 through 21 in any sequence analysis. When this option is set, it is usually a good idea to reset the values to<br>OPTIONS FIRSTOBS=1; OBS=MAX; |
| YEARCUTOFF=year | Specifies the cutoff year for two digit dates in a 100 year starting with the specified date. For example if YEARCUTOFF=1920 then the data 01/15/19 would be considered 2019 when 01/15/21 would be seen as 1921. The default YEARCUTOFF is 1926. For SAS versions 9 through 9, the cutoff was 1920. |
| PROBSIG=n | Specifies the number of decimals used when reporting p-values. For example PROBSIG=3 would cause p-values to be reported to three decimal places. |
| LINESIZE= n and PAGESIZE= n | Controls characters on an output line (LINESIZE) or number of lines on a page (PAGESIZE) for RTF and PDF output. |
| NONNUMBER | Specifies no numbers will be included in RTF or PDF output. |
| NODATE | Specifies no data will be included in RTF or PDF output. |
| ORIENTATION=option | Specifies paper orientation. Options are PORTRAIT or LANDSCAPE for RTF or PDF output. |
| NOCENTER | Left justifies output (default is centered) |
