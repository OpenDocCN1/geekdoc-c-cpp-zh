
## CHAPTER 8: CONTROLLING OUTPUT USING ODS

## HANDS-ON EXAMPLE

This example illustrates how to capture a specific statistic from the output of a procedure and save that information in a SAS data set.

- 1. Open the program file ODS5.SAS.

```sas
DATA WT;
INPUT WEIGHT @@;
DATALINES;
64 71 53 67 55 58
77 57 56 51 76 68;
ODS TRACE ON;
PROC MEANS DATA=WT;
RUN;
ODS TRACE OFF;RUN;
QUIT;
```

- 2. Run this program. It uses the TRACE option to display the names of the output tables for PROC MEANS in the Log Window, as shown in Figure 8.2. Note that the name of the output table is "Summary."

| Output Added | |
| :--- | :--- |
| Name | Summary |
| Label | Summary statistics |
| Template | base.summary |
| Path | Means.Summary |

Figure 8.2 Trace output from PROC MEANS

- 3. Close the Results Viewer and clear the output and log files. Open the program ODS6.SAS. Note that the SAS code has been modified by the removal of TRACE ON and TRACE OFF and the addition of the following statement before PROC MEANS as shown here:

```sas
ODS OUTPUT SUMMARY=STATS;
PROC MEANS;
```

SUMMARY is the name of the table, and STATS is the name of the output data set you are creating.

- 4. Run the edited program (ODS6.SAS). Look in the Log window and see the following statement which tells you SAS created the requested data set. NOTE: The data set WORK.STATS has 1 observation and 5 variables.

Examine the Results Viewer to see the contents of the new data set as given in Table 8.5. This information can now be used in other calculations as illustrated in the next step.

### 8.5 The SAS Data Set Created Using ODS Output

| Obs | WEIGHT_N | WEIGHT_Mean | WEIGHT_StdDev | WEIGHT_Min | WEIGHT_Max |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 12 | 62.75 | 8.9861378 | 51 | 77 |

The WEIGHT_MEAN and WEIGHT_STDDEV values calculated and stored in the STATS data set can be used to calculate a Z-value for each WEIGHT value in the data set. The following two lines of code can be used to calculate the Z statistic:

```sas
DIFF=WEIGHT-MEAN;
Z=DIFF/WEIGHT_STDDEV;
```

In order to do this calculation, you must merge the WT data set with the statistics in the STAT data set. The next step shows how this is accomplished. Open the program file ODS7. The purpose of this code is to use the information created by PROC MEANS and stored in the STAT data set to calculate the DIFF and Z values in a new data set.

```sas
DATA WTDIFF;
INPUT WEIGHT @@;
DATALINES;
64 71 53 67 55 58
77 57 56 51 76 68;
DATA WTDIFF;
SET STATS;
IF _N_=1 THEN STATS;
DIFF=WEIGHT-MEAN;
Z=DIFF/WEIGHT_STDDEV; /* CREATES STANDARDIZ SCORE (Z-SCORE); */
RUN;
PROC PRINT DATA=WTDIFF;VAR Z;
RUN;
```

This program creates a new data set called WTDIFF that consists of the original data merged with the first (and only row) of the STATS data set. This merge is accomplished with the statement

```sas
IF _N_=1 THEN STATS;
```

- 7. Run this program and observe the output, which contains Z-scores for each record, as given in Table 8.6. Using this technique, you can capture any statistic from a SAS output table, merge it into another data set, and use that information to calculate new variables.

### 8.4.1 Using ODS Graphics from SAS Procedures

ODS graphics refers to graphs that are created from SAS procedures. Although ODS graphics have been around for several SAS versions, the graphics only recently began appearing automatically when you run a SAS PROC (at least in the Windows edition of SAS).

SAS offers ways to customize automatically created graphs using PROC TEM and the Graph Template Language (GTL). However, this feature is not covered in this book. Refer to SAS documentation for more about the GTL programming features. The creation of custom graphics using SAS/GRAPH is covered in Chapter 18.

Sometimes, the automatic creation of ODS graphics is not what you want. You can turn it off by using the command

```sas
ODS GRAPHICS OFF;
```
