The following SAS program (APRINT1.SAS) utilizes several of the PROC PRINT options and the SUM statement:

```
PROC PRINT DATA=MYSASLIB.SOMEDATA\N = 'Number of Subjects is: '
OBS='Subjects';
SUM TIME1 TIME2 TIME3 TIME4;
```

A partial listing of this output is displayed in Table 5.11 showing how the listing has changed by the options included in the PROC PRINT statement

N = 'Number of Subjects is: '

produces the statement at the bottom of the printout reporting the number of subjects. Moreover, the option

OBS='Subjects';

causes the label above the record numbers to be Subjects rather than Obs. Finally, the statement

SUM TIME1 TIME2 TIME3 TIME4;

causes the totals for the four variables to be reported at the bottom of the report.
