# HANDS-ON EXAMPLE

This example calculates the number of days since the first visit.

+   1. Open the program file DRETAIN1.SAS.

```
DATA MYDATA;
INPUT VISIT_DATE ANYDTDTE10;
DATALINES;
01/04/2015
01/29/2015
03/07/2015
04/25/2015
07/06/2015
08/30/2015
;
DATA DAYS;SET MYDATA;
IF _N_=1 THEN FIRST=VISIT_DATE;
RETAIN FIRST;
DAYS=VISIT_DATE-FIRST;
RUN;
PROC PRINT DATA=DAYS;
```

Title ‘These are the contents of the dataset DAYS’;nFORMAT VISIT_DATE FIRST DATE10.
RUN;

+   2. Run this example and observe the output in Table 7.6.
3. Remove the RETAIN statement and rerun the program. Note that the variable FIRST loses its value after the first iteration, and the variable DAYS has a missing value for all records after the first record.
