# 7.3 USING THE RETAIN STATEMENT

The RETAIN statement is used in a DATA step, to retain values of variable across iterations as they are read into the data set. The basic syntax for RETAIN is as follows:

```
RETAIN <var <initial-value(s)> var2 <initial-values(s)> and so on;
```

For example, to instruct SAS to remember the value of the variable SCORE, you would use the statement

```
RETAIN SCORE;
```
