+   * If there are interaction effects, the factor effects should not be interpreted in isolation from each other. It is usually more appropriate to compare effects of the first factor within levels of the second factor, and vice versa. That is, compare cell means rather than the marginal means using posthoc analysis. Because there is no significant interaction in this example, it is appropriate to compare the main effects tests (STATUS AND CONDITION):
* The test for the CONDITION main effect, $p=0.6686$.
* The test for STATUS, $p=0.0056$.

Thus, you can reject the null hypothesis that there is no STATUS effect and conclude that there is evidence to support the hypothesis STATUS (i.e., whether the subject was already trying to lose weight) is a statistically significant factor in real weight loss. Because $p=0.67$ for the CONDITION factor, we conclude that there is no significant CONDITION effect (i.e., the manual seemed to have no effect).
Because there are only two types of STATUS, we do not need to perform multiple comparisons, and the clear conclusion is that STATUS=1 (i.e., those who had previously been trying to lose weight) had significantly more weight loss on average than STATUS=2.

It is helpful to use graphs to help visualize the results of a two-factor analysis. Along with the output shown in Figure 14.5, SAS produces the plot. This plot gives dot plots of the data for the four combinations of STATUS and CONDITION. The solid line lines show the MEAN RESPONSE for subjects in STATUS=1 across CONDITION. The dashed line provides the information for those in STATUS=2.

It can be seen that the lines are approximately parallel, supporting the finding of no significant interaction and indicating that RESPONSE graphs are consistently higher for STATUS=2 across levels of CONDITION. Because RESPONSE is weight loss, the graphical representation supports the finding above that those who had previously been trying to lose weight (STATUS=1) had more success on the weight loss program.
