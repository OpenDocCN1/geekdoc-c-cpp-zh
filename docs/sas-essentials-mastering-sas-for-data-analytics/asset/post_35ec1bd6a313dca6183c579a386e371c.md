For this example, the difference is 20.61, and thus at the $\alpha=0.05$ level (critical value is 3.84) we conclude that AGE should be included in the model. Other criteria that can be used for assessing models are the AIC (Akaike information criterion) or SC (Schwarz criterion) values in the Model Fit Statistics (smaller values indicate a better model in both cases).

Factor analysis is a dimension reduction technique designed to express variables using a smaller number of underlying (latent) variables. In this chapter, we shall discuss exploratory factor analysis, which involves identifying factors, determining the number of factors to extract, and interpreting the results.

## 17.1 FACTOR ANALYSIS BASICS

The typical steps in performing factor analysis are:

- a) Compute a correlation (or covariance) matrix.
- b) Extract the factors (deciding how many to extract).
- c) Rotate the factors to improve interpretation.
- d) Compute factor scores (if needed).

The simplified syntax for this procedure is:

```
PROC FACTOR <options> ;
VAR variables ;
```
