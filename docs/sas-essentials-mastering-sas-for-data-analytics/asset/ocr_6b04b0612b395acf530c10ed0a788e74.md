```
CLASS NAME1 NAME2;
TABLE NAME1, NAME2;
```

Commas separate table dimensions. In the TABLE statement, the code creates a table, commas separate
rows from columns. Therefore, NAME1 defines rows, and NAME2 defines columns. An asterisk (*) crosses two
variables, where categories of the second variable are expanded within the first.
Thus,

```
CLASS NAME1 NAME2 NAME3;
TABLE NAME1, NAME2*NAME3;
```

creates a table where the categories of VAR1 define rows, VAR2 defines columns, and
VAR3 defines columns within the categories of VAR2.
The Var Statement: The VAR statement identifies quantitative (numeric) data. This vari-
able be used to indicate summary statistics in table cells, such as means, sums,
nor medians. For example,

```
CLASS NAME1 NAME2;
VAR OBS;
TABLE NAME1, NAME2*MEAN OBS;
```

The MEAN OBS addition to this code tells the procedure to place the mean of OBS,
bdown by NAME1 and NAME2 variables, in each cell. These building blocksor PROC TABULATE are illustrated in a series of upcoming Hand-on Examples.
