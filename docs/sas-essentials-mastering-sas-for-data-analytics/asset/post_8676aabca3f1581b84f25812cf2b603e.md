
Our first example is a quick overview of how SAS works. You should not be concerned if you don't know much about the information in the SAS program file at this point. The remainder of the book teaches you how to create and run SAS programs.

## HANDS-ON EXAMPLE

In this example, you'll run your first SAS analysis.

- 1. Launch SAS. SAS initially appears as shown in Figure 1.1. (If a tutorial or some other dialog box appears, dismiss it).
- 2. Open a program file. This example uses a file named FIRST.SAS. To open this file, make sure that your active window is the Editor Window. (Click anywhere in the Editor Window to make it active window). On the menu bar, select File -> Open Program to open the file C:\SASDATA\FIRST.SAS. You may need to navigate to the C:\SASDATA folder to open this file.
- 3. Examine the opened file, the contents of which appear in the Editor Window. Maximize so you can see more of the program code if necessary. Figure 1.2 shows the Editor Window maximized. We'll learn more in later chapters about these lines of code.

![](img/6113440fee6085d6edba5f406f541c12_18_0.png)

- 4. Run the SAS job. There are three ways to run (sometimes called submit) your SAS code. (1) On the menu bar, select Run -> Submit, (2) click the "running man" icon on the toolbar, or (3) press F8. Perform any of these to run this code. The SAS instructions in the file are carried out (or, in computer terminology, the commands (continued) are executed. The SAS program creates analysis output that automatically appears in the Results Viewer.

![](img/6113440fee6085d6edba5f406f541c12_19_0.png)

- 5. View the results in Figure 1.3.
- (a) The analysis requested in this SAS program is a task to calculate basic statistics (PROC GENDER) in the data set.
- (b) Note the Results window (as referred to the Results Viewer) on the left of the screen illustrated in Figure 1.3 – it contains a single item called Means: The SAS System (the full name is truncated in the image). As you perform more analyses in SAS, this list will grow. You can quickly display the results of any previous analysis by clicking the item in the list in this Results window.
- 6. Print the output. Make sure the Results Viewer window is active by clicking anywhere in this window. The contents of the window are printed by clicking the printer icon on the toolbar or by selecting File → Print on the menu bar.
- 7. Save the output. To save the results in the Results Viewer, select File → Save on the menu bar and enter an appropriate name for the output file, such as FIRST OUTPUT. The file will be saved as FIRST OUTPUT.MHT. (.MHT extension refers to a single file web page and is automatically added to the file name. If you subsequently open this file, it will open in your default web browser).
- 8. Save the SAS program code (instruction file) that created the output by first going to the Editor Window that contains the FIRST.SAS program code. With the program on the screen, select File → Save As and enter a name such as MYFIRST. Make sure you are saving the code in the C:\SASDATA folder. This saves the file as MYFIRST.SAS. (.SAS extension is automatically added to the file name.)
- 9. Examine the SAS Log. Click on the tab at the bottom of your screen and note that it contains a SAS program code you just ran. It will include statements such as the following:

> NOTE: Writing HTML Body file: sashtml.htm
NOTE: There were 18 observations read from the data set WORK.EMPLOYEES.

This indicates that the output is in an html format (web file format) and that the data set contained 18 records.

- 10. Clear the contents of the Log by right-clicking and selecting Edit → Clear All from the pop-up menu. In the Editor Window, right-click and select Clear All. (We'll learn a shortcut to process this later in this chapter).

The Save command saves the contents of whatever is currently active. Thus, if the Results window is active, it saves the output as .MHT; if the Log is active, it saves the code; and if the Editor Window is active, it saves the file as .SAS.
