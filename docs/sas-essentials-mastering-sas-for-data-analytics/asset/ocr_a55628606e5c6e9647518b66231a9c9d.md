# 2.4 Read an external data file.

The file BPDATA. DAT is a raw (ASCII text) data file that contains data with the following columns:

| Variable Name | Column | Type |
| ID | 1 | Text |
| SBP | 2-4 | Numeric |
| DBP | 5-7 | Numeric |
| GENDER | 8 | Text (M or F) |
| AGE | 9-10 | Numeric |
| WEIGHT | 11-13 | Numeric |
