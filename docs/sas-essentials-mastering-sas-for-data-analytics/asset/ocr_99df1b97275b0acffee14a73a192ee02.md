# HANDS-ON EXAMPLE

This example illustrates how to create a horizontal bar chart.

+   1. Open the program FILE AGRAPH4.SAS.
n```sas
OPTIONS RESET=ALL;
Title "Horizontal Bar Chart";
PROC GART DATA="C:\SASDATA\SOMEDATA";
HBAR STATUS=DISCRETE;
RUN;
QUIT;
```
This code requests a horizontal bar chart on the variable STATUS. The /DISCRETE option tells SAS that the numeric values for the STATUS variable should be treated as discrete values. Otherwise, SAS may assume that the numeric values are range and create a chart using midpoints instead of the actual values.
2. Run the program and observe the output in Figure 18.5.
3. Change HBAR to VBAR and rerun the program and observe the output.
4. Change the statement by adding WIDTH=10,
```sas
VBAR STATUS=DISCRETE WIDTH=10;
```
