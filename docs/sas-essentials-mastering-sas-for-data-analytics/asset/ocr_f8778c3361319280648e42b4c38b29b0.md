# 18.4 Use SGPLOT to create a scatterplot.

Using the skeleton SGPLOT code below, display a scatterplot of X=HWYMPG and Y=CITYMPG and fit a regression line through the scatter with an individual confidence limit (CLI).

```
PROC SGPLOT DATA="C:\SASDATA\CARS";nSCATTER X=CITYMPG Y=;
YAXIS LABEL="City"
YAXIS;
REG X=Y=HWYMPG / CLI;
TITLE "SGPLOT Scatter Plot for Miles Per Gallon"
RUN;
```
