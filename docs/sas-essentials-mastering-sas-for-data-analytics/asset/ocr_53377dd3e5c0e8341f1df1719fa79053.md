the differences are reasonably normally distributed. Thus, even though the sample size is quite small, it seems reasonable to use the paired t-test. The PAIRED option produces several plots that are not shown here.

The paired t-test is actually a one-sample t-test computed on the differenced data. That is, if we computed a new variable DIF=WBEBEFORE-WAFTER and ran a one-sample t-test on the variable DIF testing $H_0:\mu_{DIFF}=0$, we would get identical results. The normality assumption in this case applies to the differenced data.
