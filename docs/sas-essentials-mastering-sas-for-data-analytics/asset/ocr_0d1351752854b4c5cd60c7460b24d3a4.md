# 2.3 RULES FOR SAS VARIABLE NAMES

Each variable (column) in the SAS data set (table) must have a name, and the names must follow certain rules. This differs from Excel, which imposes no restriction on how (or if) name columns of data. However, many of the rules for SAS are similar to those for a data name created in Microsoft Access. Each SAS variable name

+   - must be 1–36 characters long but must not include any blanks;
- must start with the letters A through Z (not case sensitive) or an underscore (_). A name may not include a blank;
- may include numbers (but not as the first character);
- may include upper- and lowercase characters (but variable names are case insensitive);
- should be descriptive of the variable (optional but recommended).

Here are some examples of correct SAS variable names:

```
GENDER
AGE_IN_1999 (notice underscores)
AGEin999
_OUTCOME (notice the leading underscore)
HEIGHT_IN_CM (notice underscores)
WT_IN_LBS (notice underscores)
```

Here are some examples of incorrect SAS variable names:

```
AGE IN 2000
2000MeaslesCount
S S Number
Question 5
WEIGHT IN KG
AGE-In-2000
```

These variable names are incorrect because some include blanks (S S Number, AGE IN 2000, Question 5, WEIGHT IN KG), start with something other than a letter or an underscore (2000MeaslesCount), or contain special characters other than the underscore (AGE-In-2000).
