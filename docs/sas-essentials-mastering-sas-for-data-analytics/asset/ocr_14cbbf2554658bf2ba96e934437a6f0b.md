# CHAPTER 1: GETTING STARTED

The normal opening SAS screen is divided into three visible windows. The top right window is the Log Window, and at the bottom right is the Editor. The third window, which appears as a vertical element on the left, is called the SAS Explorer/Results window. There are other SAS windows that are not visible on the normal opening screen. These include the Graph and Results Viewer windows. To open a SAS window that is not currently visible, click its tab at the bottom of the screen. The Output tab relates to a window that is not often used and we will not discuss it here.) Briefly, here are the purposes of these windows that are used in this text.

**Editor:** Also called the Enhanced Editor or Windows Programming Editor (WPGM), word processor. When you open a previously saved SAS session, its contents appear in this window. SAS code is stored in plain ASCII text, files saved in the ASCII format from any editor or word processor may be easily opened in the editor. You can also copy (or cut) text from another editor or word processor and paste it into the Editor window.

**Log:** When you run a SAS program, perform report detailing (and if the program appears in the Log Window. Typically, when you run a SAS program, you first look at the contents of the Log to see if any errors in the program were reported. The Log highlights errors in red. You should also look for warnings and other notes in the Log Window, which tell you that some of your program may not have run correctly.

**SAS Explorer/Results:** This window appears at the left of the screen and contains two tabs (at bottom of the window): The Results tab displays a tree-like listing of your output, making it easy to quickly scroll to any place in your output. The Explorer window (which you can display by clicking the Explorer tab) displays the available libraries where SAS data files are stored. A SAS library is a nickname for an actual file location on disk, such as C:\SASDATA. This will be described in Detail 3.

**Graph:** If your SAS program creates graphics output, SAS will display a Graph window tab. Click that tab to view graphics results.

**Results Viewer:** Beginning with SAS 9.3, results of an analysis appear in this window. It will appear the first time you run an analysis that creates output.

> Do not close any of the windows that make up the SAS interface. Move from window by clicking the tabs. If you close one of the windows, its tab at the bottom of the SAS screen will disappear and you will need to go to the View pull-down menu and select the appropriate window name to redisplay the element you closed.
