# ### 6.4.2 Fix Case Problems, Allowed Categories, and Delete Unneeded Lines

A second fix to apply to data values is to make sure that is consistent within a variable. For example, if Gender is recorded as F and f, the computer sees that as separate categories and any many gender will not be Correct. Correct case problems, you can use the UPCASE () or LOWERCASE () function to convert data values to all upper or lower case.

```
IF HOW_ARRIVED NOT IN ('CAR', 'BUS', 'WALK') THEN HOW_ARRIVED="";
```
