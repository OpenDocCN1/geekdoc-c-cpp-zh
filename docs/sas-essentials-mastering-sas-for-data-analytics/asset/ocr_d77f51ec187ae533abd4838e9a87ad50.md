# 7.1 USING ARRAYS

A ARRAY statement provides a method for placing a series of observations into a single called array. Often these variables are referenced as part of a DO loop, which is a technique for iterating through a set of data. (DO loops are presented in the following section of this chapter). A simplified syntax for SAS arrays is the following:

```
ARRAY ARRAY-NAME (SUBSCRIPT) <$> ARRAY-VALUES
```
