# 12.2.1 The Simple Linear Regression Model

The regression line that SAS calculates from the data is an estimate of a theoretical line describing the relationship between the independent variable (X) and the dependent variable (Y). The theoretical line is

```
Y = α + etaX + ε
```

where $a$ is the $y$-intercept, $eta$ the slope, and $\epsilon$ an error term that is normally distributed with zero mean and constant variance. It should be noted that $b=0$ indicates that there is no linear relationship between $X$ and $Y$. A simple linear regression analysis is used to develop an equation (a linear regression) for predicting the dependent variable given a value ($x$) of the independent variable. The regression line calculated by SAS is given

```
Y = a + bx
```

where $a$ and $b$ are the least squares estimates of $a$ and $b$.
The null hypothesis states that there is no predictive linear relationship between the two variables. Because $eta=0$ indicates that there is no linear relationship between $X$ and $Y$, the null hypothesis of no linear relationship is tested using

```
H_0: \beta = 0
H_1: \beta \neq 0
```

A low $p$-value for this test (say, <0.05) indicates significant evidence to conclude that the slope of the line is not 0 (zero). That is, the knowledge of $X$ would be useful in predicting $Y$.

+   The t-test for slope is mathematically equivalent to the t-test of $H_0: \rho = 0$ in a correlation analysis.
