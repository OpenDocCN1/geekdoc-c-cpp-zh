
# TABLE 19.24 Options for the PUT Statement

| Option | Meaning |
| --- | --- |
| 'text ' | Information in quotes is output verbatim (unless macro variables are within the quotes). For example, PUT 'Some Text'; |
| Varilename(s) | The value of a variable for each record in the data set is output where a variable name is included, not in quotes. For example, PUT TIME1 TIME2 TIME3; |
| @n, @var, or @expression | Moves to a specified column line. When using @var or @expression, they must be numeric. For example, PUT @5 'Age ' = AGE; |
| +n, +var, or +expression | Moves to a relative line n columns to the right from its current line. When using @var or @expression, they must be numeric. The default is to hold the output on the current output line or move to the next line. |
| var format. | A format specification following a variable causes the variable to be displayed with the specified format. For example, PUT AGE 5.1; displays the value of AGE using a 5.1 format |
| n*char' | Repeats a character n times. For example, PUT 50*'-'; creates a dashed line with 50 characters |

The overall class mean is captured in the output SAS data set GMEAN. The contents of this data set are given in Table 19.25. To display this, go to the SAS Explorer, Work Library, and double-click on the table GMEAN to view this information.

Note that the class mean is 88.667. It appears in the GMEAN data set on the line where _STAT_ is "MEAN." A final step before writing the report is to capture the overall average into a macro variable. This is accomplished with a PUT statement (see Appendix B) as shown:

```sas
DATA _NULL_;
SET GMEAN;
IF _STAT="MEAN" THEN CALL PUT('CLASSMEAN', ROUND(AVE, .2));
RUN;
```

In this case, _NULL_ is used to create the macro variable CLASSMEAN, which is assigned the value AVE from the data set. _NULL_ was used because we did not need to create any data set from the DATA step. The report created using this information is illustrated in the following Hands-on Example:

```sas
TITLE "Grade Report for Course 1234";
DATA _NULL_;
SET GRADES END=EOF;
TABLEHEAD="SUMMARY OF GRADES";

IF _N = 1 then do; * HEADER;
PUT @5=(60-LENGTH(TABLEHEAD))/2 TABLEHEAD; * CENTER;

PUT "NAME" @20 " | TEST 1 " @30 " | TEST 2 " @40 " | TEST 3 " @50 " | AVERAGE";

PUT @5 60*;
PUT @5 "CLASS AVERAGE " @50 " | TRIM(CLASSMEAN) "; * HOLDS LINE FOR NEXT;

```

A breakdown of this code is as follows:

* The report is created within a _NULL_ step using the information from the GRADES data set (The EOF variable is created to mark the last records in the GRADES data set.).
* TABLEHEAD is to be displayed in the report.
* FILE PRINT sends the report to the SAS Viewer.
* Note the three parts of the program within the DATA step:

1. The section beginning with _N_=1 is a header that is only displayed when the first record of the data is read. It centers and puts the title (TABLEHEAD) and puts several lines that make up the header for the report.
