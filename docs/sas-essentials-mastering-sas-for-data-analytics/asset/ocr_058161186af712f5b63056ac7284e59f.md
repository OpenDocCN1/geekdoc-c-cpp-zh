Rows (or columns) represent data from different populations (e.g., treated and not treated), and the other variable represents data observed on the population.
The chi-square test of independence or homogeneity is reported by PROC FREQ (the tests are mathematically equivalent) by the use of the /CHISQ option in the TABLES statement. For example,

```
PROC FREQ; TABLES GENDER*FREQ/CHISQ;
```

will a two-way cross-tabulation table and statistics associated with the table. Also included in the output are the likelihood ratio chi-square, Mantel–Haenszel chi-square, phi, contingency coefficient, and Cramer’s V. For a $2 \times 2$ table, Fisher’s Exact test is also performed.
