# 8.5 Use ODS to select a specific value in a table.

In order to minimize the amount of output for the test, suppose you want to see only the $p$-value for the two-sided Fisher's Exact test. You can do this by capturing specific values from the STATEOUT data set.

+   a. Use the following code to print the $p$-value from the Fisher's Exact test. (This program uses several features that were discussed in previous chapters.)

```
PROC PRINT LABEL DATA=STATOUT;
LABEL CVALUE1='P-VALUE' NAME1='TEST';
WHERE NAME1="XP2_FISH";nVAR NAME1 CVALUE1;
ID TABLE;
RUN;
```

+   b. Why is the LABEL option included in the PROC PRINT statement? (See Chapter 4, the section “Labeling Variables with Explanatory Names.")

+   c. What does the WHERE statement do?

+   d. What does the ID statement do?

Hint: To figure out what each statement does, comment out the statement and rerun the program to see what happens.
