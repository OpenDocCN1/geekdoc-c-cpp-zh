**Saving Your Table in Excel:** Once you create a table using PROC TABULATE, you may save it in an Excel format. In the case of saving it to Word (RTF), you may use an ODS procedure. The process is to open the Excel file using an ODS statement such as

```
ODS TAGSETS.EXCELXP BODY='C:SASDATA\TABLE.XLS';
Your PROC TABULATE code;
RUN;
ODS TAGSETS.EXCELXP CLOSE;
```
