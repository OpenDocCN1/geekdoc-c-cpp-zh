Note the changes. The SPLIT="*" statement SAS the asterisk (*) is the delimiter that will be used to split labels into two or more lines. The double underline created by repeated equal signs (=) provides a break between the label and the column contents. The statement

N OBS = 'Observation*Number*==============';
tells SAS to report the total number of observations at the bottom of the listing (N) and to use the specified label for the OBS column. The label contains three sections, each section splits by the delimiter *. Thus the label will be three lines long:

```
Observation
Number
==
```

Labels for the variables are similarly defined where the * tells SAS where to split the labels as they are used in the columns for the listing. The label Gender has a * * (note the blank between the *) indicating a skip to make the underline for Gender line up with other labels. Compare this with up to the previous listing in Table 5.12.

Another feature to note is that labels (like the data values) are either right or left justified depending on whether the column represents numeric or text.
