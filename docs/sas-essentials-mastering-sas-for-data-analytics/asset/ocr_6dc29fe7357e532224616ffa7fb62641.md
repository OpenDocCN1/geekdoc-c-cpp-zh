ACROSS OPTION: The DEFINE var/ACROSS option allows you to create a column for each unique item for a categorical variable. The following Hands-on Example illustrates the ACROSS OPTION.

# HANDS-ON EXAMPLE

+   1. Open the program file AREPORT6.SAS.

```
PROC FORMAT;
VALUE FMTSUV 0="NOT SUV" 1="SUV";nPROC REPORT DATA=MYSLAS, CARS NOFS;
COLUMN BRAND CITYMP, SUV HWYMP, SUV;
DEFINE BRAND/ORDER;
DEFINE GROUP/GROUP;
DEFINE CITYMP/ANALYSIS MEAN FORMAT=6.1;
DEFINE HWYMP/ANALYSIS MEAN FORMAT=6.1;
DEFINE SUV/ ACROSS BY 'SUV';
FORMAT SUV FMTSUV;
RUN;
```

In this example, the SUV variable has values 0 and 1. To display the MPG variables by SUV or not, the SUV variable is listed with those two variables separated by a comma as CITYMP,SUV. The SUV variable is defined as an ACROSS variable and given a label. For example, a format is created for the SUV variable and applied to that variable within PROC REPORT. The results are given in Table 19.21.

Note how the mean MPG is listed across the table by SUV or NOT SUV for each of the two MPG variables. (Some car brands do not have SUVs or have all SUVs, so there are some missing values in the table.)
