```
DATA PRESSURE;SET MEDDATA;
ARRAY SBP(5) READING1-READING5;
HIGHBP=0;
DO I=1 TO 5;
  IF SBP(I) GT 140 THEN HIGHBP=1;
END;
```

+   - The Array statement sets up an array named sb that contains the values of the variables READING1 through READING5.
- In the DO loop, the variable I iteratively takes the values from 1 to 5, the variable HIGHBP
- Within the DO loop, any of the five readings is greater than (GT) 140, Otherwise, the value of HIGHBP for subject remains at 0.

Once the value of HIGHBP takes the value 1, there is no way for it to be set back to 0 within the same loop. For each record HIGHBP starts at 0 and when changed within the loop, it does not reset to 0 until the next record in the data set is read.
For example, suppose you have a questionnaire in which the variables (answers) are recorded as YES, NO. Missing answers were originally coded in the data as NA. Suppose you want to change these values to the value " " (two quotes together representing a blank, which is typically a missing value for a character value). Using an array and a DO loop, you can quickly perform this task within a DATA step.

```
DATA NEW;SET OLD;
ARRAY ANSWER(1:50) Q1-Q50;
DO I=1 TO 50;
  IF ANSWER(I)="NA" then ANSWER(I)=""
END;
```

+   - The ARRAY statement sets up an array named ANSWER that contains the text values of the variables Q1–Q50.
- The DO statement begins a loop wherein the variable I iteratively takes the values from 1 to 50. The DO loop ends with the END statement.
- Within the DO loop
