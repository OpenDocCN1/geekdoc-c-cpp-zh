# GOING DEEPER: CREATING AN INTERACTIVE BAR UDS 419

The ODS code specifies the HTML file where the output will be saved.

```
ODS HTML BODY="C:\SASDATA\GPA.HTM"
PROC MEANS DATA="C:\SASDATA\SOMOMEDATA" MAXDEC=2 N MEAN STD;
VAR AGE TIME1-TIME4;
WHERE GP="A";nTITLE Summary for GROUP A '
RUN;
```

The PROC MEANS code creates the report we want to save.

IF GP="A" THEN HTMLLLINK=HREF="C:\GPA.HTM";

This statement assigns the 'HREF="C:\GPA.HTM"' to a variable named HTMLLLINK. The HREF statement is a standard HTML statement used in pages on the web to create links to other pages. (Note the HREF is included in single quotation marks and the file name is in double quotation.) In this example, a link is defined when the group (GP) is "A". Once a link variable (HTMLLLINK) is created, it can be applied to a portion of a graph as illustrated in the following Hands-On Example.

# HANDS-ON EXAMPLE

+   1. The program file AGRAPH11.SAS. In Part 1 of the code, note that there are three PROC MEANS procedures that create three files containing reports for Groups A, B, and C. These three PROC MEAN calls are all similar to the code shown in Figure 18.13 and create each HTML report file.

```
*......PART 1: CREATE REPORTS FOR GROUPS A, B, and C;
ODS HTML BODY="C:\SASDATA\GPA.HTM"
PROC MEANS DATA="C:\SASDATA\SOMOMEDATA" MAXDEC=2 N MEAN STD;
VAR AGE TIME1-TIME4;
WHERE GP="A";nTITLE 'Summary for Group A';
RUN;
ODS HTML BODY="C:\SASDATA\GPA.HTM"
PROC MEANS DATA="C:\SASDATA\SOMOMEDATA" MAXDEC=2 N MEAN STD;
VAR AGE TIME1-TIME4;
WHERE GP="B";
```
