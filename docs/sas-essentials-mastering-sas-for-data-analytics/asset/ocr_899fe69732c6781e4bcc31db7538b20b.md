If this occurs, use the following OPTIONS statement (above the code where you refer to the data set) to tell SAS to access the data set, or run the procedure without using the defined formats:

OPTIONS NOFMTTER;

In this case, the output displays the raw values of the variables instead of the assigned format labels.
