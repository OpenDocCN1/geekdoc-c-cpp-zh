Throughout the book, procedures as PROC PRINT and PROC FREQ have been used to produce simple summaries of data. However, these procedures are limited. This chapter introduces two advanced reporting procedures that are designed to help you create professional reports.

# 19.1 USING PROC TABULATE

PROC TABULATE is used to make summary data tables. Unlike PROC FREQ, it can handle multiple levels in rows and columns. You can use PROC TABULATE to create professional reports and publication ready tables. An abbreviated syntax for PROC TABULATE is as follows:

```
PROC TABULATE <options>;nCLASS variables < / options>;nVAR variables < / options>;nTABLE <page> =
```
