# 4.3.3 Using IF-THEN and DO for Program Control

Another use of the IF statement is to control the flow of your SAS program in conjunction with a DO statement. In this case, you can control a group of SAS commands to be conditionally executed by using the following type of code:

```
IF expression then DO;
Code to execute;
END;
```

For example, suppose that you want to calculate BMI (Body Mass Index) for subjects in a data set, but the formula is only relevant for subjects older than 19 years. At the same time, you can assign other values for this group of subjects. You could use the following code:

```
IF AGE GT 19 then DO;
BMI=(WTLBS/HTINCH**)*703;
ISADULT=1;
INCLUDESTUD="Yes";nEND;
```

In this case, when AGE for a subject older than 19, a series of three lines of code is processed. For other subjects in the data set where AGE is younger or equal to 19, BMI, ISADULT, and INCLUDESTUD are not assigned values, and they thus have a missing value. (You might have a second IF-THEN-DO statement to assign other values for this case.)

# 4.3.4 Using @ and IF to Conditionally Read Lines in a Data Set

For big data sets, it is often the case that you don't want to read in all of the data. One method you could use to conditionally read in certain records is to set a test condition and read in the record only if it meets that condition. To do this, you can use the @ it sign in your input statement to read a portion of a record and put the input on hold while you decide whether or not to read in the complete record. This is referred to as a “trailing at.” This is illustrated in the following example:

# HANDS-ON EXAMPLE

This example illustrates the use of a trailing at to conditionally read in data.

INPUT ID $ 1-3 GP $5 AGE 6-9 TIME1 10-14 TIME2 15-19;
