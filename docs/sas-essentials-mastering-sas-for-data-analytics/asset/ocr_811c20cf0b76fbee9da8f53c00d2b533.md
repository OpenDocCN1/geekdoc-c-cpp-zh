# HANDS-ON EXAMPLE

Suppose you have been given a data set in which each line represents a variable and each subject's data are in a single column. This example illustrates how to use PROC TRANSPOSE to restructure this data set. Note that because some of the data are text, you must indicate that with a $ after each variable name in the INPUT statement.

+   1. Open the program file DTRANPOSE1.SAS.

```
DATA SUBJECTS;
INPUT SUB1 $ SUB2 $ SUB3 $ SUB4 $;
DATALINES;
12 21 13 14
13 21 12 14
15 31 23 23
15 33 21 32
M F F M
;

PROC TRANSPOSE DATA=SUBJECTS OUT=TRANSPOSED;
VAR SUB1 SUB2 SUB3 SUB4;
RUN;
PROC PRINT DATA=TRANSPOSED;
RUN;
```

+   2. Run the program. The OUT=TRANSPOSED statement creates a data set named OBS_TRANSPOSED from the procedure. The resulting data set is given in Table 6.2.

TABLE 6.2 Example of Transposed Data

| Obs | _NAME_ | COL1 | COL2 | COL3 | COL4 | COL5 |
|---|---|---|---|---|---||}{
| 1 | SUB1 | 12 | 13 | 15 | | M |
| 2 | SUB2 | 21 | 21 | 31 | 33 | F |
| 3 | SUB3 | 13 | 12 | 23 | 21 | F |
| 4 | SUB4 | 14 | 14 | 23 | 32 | M |

+   3. You can control the names of the columns with a PREFIX statement. Change the PROC TRANSPOSE statement to

```
PROC TRANSPOSE DATA=SUBJECTS OUT=TRANSPOSED PREFIX=INFO;
```

Rerun the program and observe the names of the columns.
