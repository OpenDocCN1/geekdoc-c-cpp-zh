### 6.4 Fix Case, Allowed Categories, and Delete Unneeded Lines

An easy-to-perform check is to delete irrelevant records. In this data set, if a line does not contain a Subject ID, we want to eliminate record. This is done with an IF statement.

```
IF SUBJECT =" THEN DELETE;
```

However, as we use TEMP to make sure that is consistent. For example, if Gender is recorded as f, the computer sees that as separate categories. You can use the UPCASE () or LOWERCASE () to convert data values to upper.

```
IF HOW_ARRIVED NOT IN ('CAR','BUS','WALK') THEN HOW_ARRIVED=""
```
