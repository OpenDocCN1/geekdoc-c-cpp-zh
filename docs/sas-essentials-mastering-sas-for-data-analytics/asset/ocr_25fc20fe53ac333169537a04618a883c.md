# HANDS-ON EXAMPLE

We use the procedure outlined in the previous example to run the factor analysis for the Olympic Athlete Data.

+   1. Open the program file FACTOR2.SAS.

```
PROC FACTOR SIMPLE DATA MYSASLIB.OLYMPIC
METHOD=PRINCIPAL MSA
PRIORS=SMC
ROTATE=VARIMAX
OUTSTAT=FACT_ALL
PLOTS=SCREE;
VAR RUN100 LONGJUMP SHOTPUT HIGHJUMP RUN400
HURDLES DISCUS POLEVAULT JAVEL RUN1500S;
```

RUN;
