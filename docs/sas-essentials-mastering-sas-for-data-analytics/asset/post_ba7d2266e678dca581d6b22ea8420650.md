## 4.4 USING DROP AND KEEP TO SELECT VARIABLES

Sometimes, you may have a data set containing *variables* you do not want to keep. The DROP and KEEP statements in the DATA step allow you to specify which variables to retain in a data set. The general form for these statements is as follows:

```
DROP variables;
KEEP variables;
```

For example,

```
DATA MYDATA;
INPUT A B C D E F G;
DROP E;
DATALINES;
...etc...
```

reads all the data but then drops the variables E and F so that these variables are no longer in the temporary SAS data set MYDATA.

Another way to use DROP and KEEP is as you are reading the data. In this case, the statement is included in the DATA statement as an option specified in parentheses. The format for this use is (DROP= list of variables) or (KEEP= list of variables). For example,

```
DATA MYDATA(DROP=E);
```

The following Hands-Example illustrates this technique.

## 4.5 USING THE SET STATEMENT TO READ AN EXISTING DATA SET

Often, you have a "main" data set that is from some corporate, government, or organization source. If you don't want to change the original data set, you should work with a copy of it. The SET statement is what you need. The SET statement in a DATA step is used to transfer data from an existing SAS data set to a new one. When you use a SET statement, there is no need for an INPUT, INFILE, or DATALINES statement. The SET statement is often used when you want to create one or more SAS data sets by subsetting a larger data set but preserve all data in the original data set.
The general form of the SET statement is as follows:

```
SET SASdataset;
```

For example:

```
DATA NEW; SET OLD;
```

or

```
DATA NEW; SET "C:\SASDATA\OLD";
```

In this example, the SAS data set named OLD already exists. All variables and observations in the existing SAS data set (OLD) are automatically passed through the input buffer to the new SAS data set (NEW) (unless otherwise directed by programming statements). Just as when any new data set is created, additional variables can be created with assignment statements within the SAS data step.

## 4.6 USING PROC SORT

The SORT procedure can be used in the DATA step to rearrange the SAS data set. The sorting information for SORT is shown in Table 4.9. For example,

```
PROC SORT DATA=MYDATA OUT=MYSORT;
```

creates a new sorted data set named MYSORT (and the original MYDATA remain in their order). If you do not include an OUT= statement, SAS sorts the current data set.

## TABLE 4.9 SAS Sorting Sequence

| Type | Sequence |
| :--- | :--- |
| Sorting sequence for character variables | blank!"#$$&©()*+,,-./0-90123456789<=@ABCDEFGHIKJKLMNOPQRSTUVWXYZ^_ghijklmnopqrstuvwxyzxyz~) |
| Sorting sequence for numeric variables | Missing values, first numeric values |
| Default sorting sequence | Ascending (or indicate Descending) |

The BY statement in the PROC SORT paragraph must contain one or more variables and optionally the DESCENDING keyword. The DESCENDING statement tells SORT to arrange the values from highest to lowest instead of the default lowest to highest order. For example:

- * Sorts in ascending/alphabetical order;
- * BY DESCENDING; * Sorts in descending order;
