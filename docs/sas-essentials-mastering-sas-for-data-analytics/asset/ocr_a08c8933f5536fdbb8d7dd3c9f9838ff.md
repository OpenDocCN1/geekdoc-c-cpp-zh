# 1.4.4 Understanding Common File Extensions

Another piece of information you need to be aware of when learning and SAS concerns the type of files used and created by SAS or mentioned in this book. Most Windows files, they have specific file name extensions that indicate what application is associated with them (e.g., the way *.doc or *.docx extension indicates a Microsoft Word file).

SAS Code (filename .sas): This is an ASCII text file and may be edited using the SAS Editor, Notepad, or any text editor that can read an ASCII file.

SAS Log File (filename .log): This ASCII text file contains information such as errors, warnings, and data for a submitted SAS program.

SAS Results File (filename.mht or filename.html): This file contains the web-formatted output as displayed in the Results Viewer. HTML stands for Hyper-Text Markup Language and is the common language of Internet web files. MHT is short for MHTML and for Microsoft (MIME) Hypertext Archive. It is a type of HTML file that contains the entire html-coded information in a single file (where HTML may access external files for some components such as.)

SAS Data File (filename.sas7dat): This file contains a SAS data set that includes variable names, labels, and the results of calculations you may have performed in a DATA step. You cannot open or read this file in SAS or in a few other programs that can read SAS data files.

Raw Data Files (filename.dat or filename.csv): These ASCII (text) files contain raw data that can be imported into SAS or edited in an editor as Notepad.

Excel File (filename.xls or filename.xlsx): Data in a Microsoft Excel file (when properly formatted into a table of columnar data) can be imported into SAS. (We'll discuss file types that can be imported into SAS in Chapter 3.)

# 1.4.5 Getting SAS Help

SAS help is available from the SAS Help pull-down menu (Help -> SAS Help and Documentation). When you select this option, SAS displays a help file as shown in 1.5 (with the SAS Products option). As with other software systems, you can choose to search for keywords (using the Search tab), or scroll through the tree-list to select topics of interest.

In Figure 1.5, note that the Products Sections has been expanded to display links to help with a number of SAS program components. The options Base SAS and SASSTAT refer to the information discussed in this text. Specifically, details about the statistical procedures (PROC) discussed in this book are documented in two sections of the Help file.

SAS is also available on the web in a number of forms. SAS Institute provides many of their reference manuals (as pdf files), there are a number of papers presented at SAS conferences on the web, and a number of independent websites that include SAS examples and, a search for a particular SAS topic (i.e., “SAS ANOVA”) will typically bring up a large number of links.
