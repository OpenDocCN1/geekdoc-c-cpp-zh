# HANDS-ON EXAMPLE

1. Open the program file ATAB3.SAS. Note the new SALES_K statement to define the numeric value, and how it is crossed with the TYPE variable in the TABLE statement. Submit this code and observe the results given in Table 19.9. Note the value for Downstairs, North, Kiosk is 63, meaning that the sum of sales for that cell is $63,000.

```
PROC FORMAT;
VALUE $FMTCOMPASS "N="1.North "S="2.South "E="3.East"
"W="4.West"

RUN;
PROC TABULATE DATA=MYSALIB.REGION ORDER=FORMATTED;
CLASS TYPE SITE;
VAR SALES_K;
TABLE SITE="Store Site"
AREA="Area"*
TYPE="Type Store"*\
SALES_K;
FORMAT AREA $FMTCOMPASS.;
RUN;
```
