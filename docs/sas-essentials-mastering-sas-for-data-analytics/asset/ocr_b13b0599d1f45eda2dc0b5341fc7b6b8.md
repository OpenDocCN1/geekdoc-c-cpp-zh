**2.5.5 Using FORMATs for Output**nAs this chapter discusses how to use informats for reading in data, it makes sense to look at their counterpart, output formats. Output formats, or simply formats, are to tell SAS how to display data when it is listed in a procedure such as PROC PRINT. In this case, we use a SAS statement named FORMAT. For example, the statement (in a DATA step)

```
FORMAT OWE DOLLAR10.2
```
