| TABLE 13.1 Common Options for PROC ANOVA and PROC GLM for Performing a One-Way ANOVA or Simple Repeated Measures |
| Option | Explanation |
| --- | --- |
| DATA = dataname | Specifies which data set to use |
| NOPRINT | Suppresses output. This is used when you want to extract information from ANOVA results but don't want SAS to produce output in the Results Viewer |
| OUTSTAT=datname | Names an output data that saves a number of the results from the ANOVA calculation |
| PLOTS=options | Specifies PLOTS=NONE to suppress plots that are generated by default |

| ALPHA=p | Specifies alpha level for a confidence interval (GLM only) |

Common statements for PROC ANOVA and PROC GLM (for one-way analyses)

+   * CLASS variable list; This statement is required and specifies the grouping variable(s) for the analysis
* MODEL specificaion Specifies the dependent and independent variables for the analysis. More specifically, it takes the form MODEL dependentvariable=independent variable(s); More explanation follows
* FREQ var Specifies a variable that represents the count of values for an observation. Similar to the WEIGHT statement for PROC FREQ
* MEANS vars Calculates means for dependent variables and may include comparisons. This is illustrated in an example below
* LSMEANS vars Calculates least square means for a dependent variable and can be used to request comparisons (GLM only). This is illustrated in an example
* REPEATED vars Used to specify repeated measure variables. This is described in a latter example
* TEST especiation Used to specify a hypothesis test value
* CONTRA specification Allows you to create posthoc comparisons (GLM only)
* BY, FORMAT, LABEL, WHERE These statements are common to most procedures and may be used here
