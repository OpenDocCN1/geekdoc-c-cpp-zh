# 7.4.5 Including SAS Macro Code

You may create a number of SAS macro routines that you want to use again and again.
Instead of including the macro code in the program where you are going to call it, you may
want to include the macro code dynamically in your program. For example, the file that
contains the DISCLAIM macro is DMACROCLAIM.SAS. By placing a %INCLUDE
command, here, at the top of your code, you can make this macro available for use
in a program.

HANDS-ON EXAMPLE

This program illustrates how to include external SAS code in a program.

1. Open the program FIRST.SAS. This was the first SAS program we used. On the
line before the DATA statement entry

%INCLUDE "C:\SASDATA\DMACROCLAIM.SAS";n
And on the line after the last RUN statement entry

%DISCLAIM;
