# E.2 CREATING A PERMANENT SAS LIBRARY

In SUE, to create the permanent SAS library similar to those is mentioned in this book, do this:

+   1. Click on the Libraries Tab at the left of the screen.
2. Click on the leftmost icon (New Library). The dialog box shown in Figure E.6 appears. Enter the information shown in the dialog box to create a library mysaslib. Make sure care for /folders/myfolders/ matches what you created for folder.
3. Make sure you check the box “Re-create this library at start-up.”
4. OK to create the folder.
