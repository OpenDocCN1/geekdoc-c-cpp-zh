# 8.5 GOING DEEPER: USING TRAFFIC LIGHTING TO HIGHLIGHT SELECTED VALUES

There may be an instance when you are creating a report using PROC PRINT that you want to highlight certain values according to some criteria. (This feature only works in PROC PRINT, TABULATE, and REPORT. This example only discusses it in PROC PRINT.) For example, if a value is high or low, you might want to highlight the value with a color. Traffic Lighting is a way to do that. Using Traffic lighting is a two-step procedure:

+   1 Create a format that identifies colors for certain values. For example, suppose you want to highlight high values of ISS, the Injury Severity Score to severity. A format to do that could be created using this code:

```
PROC FORMAT;
FMTSEVERE
LOW-<10="GREEN"
10-<20="BLUE"
20-HIGH="RED";

RUN;
```

+   2 In PROC PRINT, tell SAS which variable to assign this formatting using the VAR statement. For example,

```
VAR ISS/STYLE={FOREGROUND=FMTSEVERE};
```

The following example illustrates Traffic Lighting.
