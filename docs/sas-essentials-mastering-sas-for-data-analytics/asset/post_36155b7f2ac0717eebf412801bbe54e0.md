### 1.1 USING SAS IN A WINDOWS ENVIRONMENT

SAS runs on a number of computer platforms (operating systems) including mainframes and personal computers whose operating systems are UNIX, Mac OS X, Linux, and Windows. This book is based on using SAS in a Windows environment where you have the software installed on your local computer. The vast majority of the content in this book will apply to any SAS computer environment. However, we will include occasional references to differences that might be present in other operating systems. Most of the differences between versions have to do with file references. Moreover, there are many ways to use SAS, notably the programming or Enterprise Guide approaches. This book teaches the programming approach that offers you the most flexibility. Before discussing the SAS program, we will review some of the basic file-handling features of Windows.

#### 1.1.1 Creating a Folder for Storing Your SAS Files

As there are several versions of Windows currently, we present general guidelines that should work in any one of them. To follow our examples, we recommend that you store the data and SAS files in a folder named SASDATA. In fact, we recommend you do this NOW! The examples in this text will assume that all files used in this book are in a folder whose file path is C:\SASDATA. #### 1.1.2 Beginning the SAS Program

Since there are multiple ways to use SAS, launching SAS may differ according to your installation and operating system. For a typical Windows environment, there is a SAS icon (or tile) on your desktop, simply double-click to launch SAS. If the SAS icon is not on your desktop, go to the Start button and select Start → Programs → SAS (English) to launch SAS. Hence, we will refer to this as SAS icon. (We don't recommend that you click on a SAS file to launch SAS because it may not open SAS in the way you want.)

The normal opening screen is divided into three windows. The top right window is the Log, and at bottom right is the Editor. The third window, which appears on the left, is Explorer/Results. There are other SAS windows that are not visible. These include Graph and Results Viewer. To open SAS window that is not visible, click its tab at the bottom. Briefly, here are the purposes of these windows that are used in text:

- **Editor:** Also called the Programming Editor. When you open a previously saved SAS session, its contents appear in this window. You can also copy (or cut) text from another editor or word processor and paste it into the window.
- **Log:** When you run a program, you first look at the Log to see if any errors were reported. The Log highlights errors in red. You should also look for warnings and other notes in the Log, which tell you that some of your program may not have run correctly.
- **Explorer/Results:** This window appears at the left of the screen and contains two tabs: The Results tab displays a tree-like listing of your output, making it easy to quickly scroll to any place in your output. The Explorer window (which you can display by clicking the tab) displays the available libraries where data files are stored. A SAS library is a nickname for an actual file location, such as C:\SASDATA.
- **Graph:** If your SAS program creates graphics output, SAS will display a Graph tab. Click that tab to view graphics results.
- **Results Viewer:** Beginning with SAS 9.3, results of analysis appear in this window. It will appear the first time you run an analysis.

Do not close any of the windows that make up the interface. Move from window by clicking the tabs. If you close one of the windows, its tab at the bottom of the SAS screen will disappear and you will need to go to the View pull-down menu and select the appropriate window name to redisplay the element you closed.
