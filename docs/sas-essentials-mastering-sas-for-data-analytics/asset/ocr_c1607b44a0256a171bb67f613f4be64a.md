```
PROC GPLOT <options>; <PLOT plot-request(s)/ option(s);
```

It is a good idea to include the following command to reset all SAS graphics options before you use PROC GPLOT or other SAS graph procedures:

```
GOPTIONS RESET=ALL;
```

Moreover, it is a good idea to include a QUIT statement after a plot to tell the SAS program that the graph is complete. Otherwise, you may note a “PROC GPLOT Running” warning in the Editor window, indicating that SAS is waiting for more information about the plot. Some of these options are illustrated in this chapter's Hands-on Examples.
Table 18.1 lists some of common options used with PROC GPLOT and Table 18.2 lists some the common statements used with PROC GPLOT.
The PLOT statement is the heart of PROC GPLOT. Using this, you request an X–Y plot from the PROC GPLOT procedure using code such as:

```
PROC GPLOT DATA=sasdatafile;
PLOT yvariable*variable/options;
RUN;
```

# ### TABLE 18.1 Common Options for PROC GPLOT

| Option | Explanation |
| --- | --- |
| DATA = datename | Specifies which data set to use |
| ANNOTATE= | Allows you to change default graphical elements or add new elements to the graph. (This feature is not demonstrated in this chapter.) |
| UNIFORM | Specifies that the same axes are used in all of the graphs produced by the procedure |

# ### TABLE 18.2 Common Statements for PROC GPLOT

| Statement | Explanation |
| --- | --- |
| PLOT (and PLOT2) | Specifies information about vertical and horizontal axes in a scatterline plot, along with statement options that customize the look of the plot. These statements are discussed below. (PLOT2 is not discussed in this chapter.) |
| BUBBLE (and BUBBLE2) | Similar to the PLOT statement but specifies information that creates a bubble plot. An example BUBBLE is given in the SSGRAPH section in this chapter. |
| AXIS, FOOTNOTE, PATTERN, TITLE | These are statements that can be used to enhance graphs. Examples in this chapter illustrate these options |
| BY, FORMAT, LABEL, | These statements are common to most procedures, and may be used here |

Note: At least one PLOT or BUBBLE statement is required.
