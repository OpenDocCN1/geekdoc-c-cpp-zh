# APPENDIX E: USING SAS® UNIVERSITY EDITION WITH SAS ESSENTIALS

Suggestions:

+   - Accept the defaults for installing the Virtual Box.
- We recommend that you download and print the "Start Guide" for specific instructions on the SUE on your computer. Note: You must have a SAS profile (free to set up). You will be prompted to use a profile during the install process if you don't already have one.
- This can take 30 minutes or more depending on your computer and network speed.

Step 2: Add SAS to your VirtualBox (Important): We recommend that you download the sample files used in this book before you set SUE. Go to the http://www.analyticseliot.com/sas website and follow instructions for downloading these sample files. This creates a folder named C:\SASDATA that contains the sample files used for SAS Essentials.

As part of the SUE setup, you are instructed to create a folder (in Windows) named C:\SASUniversityEdition. To set up SAS Essentials, also create a folder named C:\SASUniversityEditionfolders\SASDATA. Copy and paste all of the files from the C:\SASDATA folder into C:\SASUniversityEditionfolders. (Make note of the folder you used since this will become important later.)

From the same SAS web page, locate the Quick Start Guide that links the virtualization program you installed in Step 1. Follow those instructions to add SAS to your virtual machine. (Step 3 uses the instructions "Oracle VirtualBox Quick Start Guide")

Step 3: Begin SAS once you have installed the Visualization Software and SUE, there are typical steps to begin SAS:

+   1. Open the Visualization Software you installed in Step 1. (This example uses Oracle VirtualBox.). The Oracle VirtualBox Manager is shown in Figure E.1.
