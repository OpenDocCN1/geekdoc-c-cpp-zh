The SELECTION options specify how variables will be considered for inclusion in the model. The BACKWARD method considers all predictors and eliminates the ones that do not meet the minimal SLSTAY criterion until only meet the meeting criterion. The FORWARD method brings in the most significant variable until the SELECTION criterion and continues entering variables until none of the remaining variables meet. STEPWISE is a mixture of the two. It begins like the BACKWARD method and uses the SELECTION criterion to enter variables reevaluate variables at each step and may eliminate a variable if it no longer meets the SLSTAY criterion. A typical model statement utilizing an automated selection technique would be follows:

```
MODEL Y = X1 X2 ... Xk
/ EXPB
SELECT=STEPWISE
SLENTRY=0.05
SLSTAY=0.1
```
