# 3.7.3 Exporting Data Using the SAS Code

Exporting data from an SAS data file into another file type (such as a CSV file) is similar to importing. In this case, you use the PROC EX procedure. A simplified syntax for exporting is as follows:

```
PROC EXPORT DATA='filename' or OUTTABLE='tablename'
DBMS=dbmsidentifier
<LABEL><REPLACE>;
```
