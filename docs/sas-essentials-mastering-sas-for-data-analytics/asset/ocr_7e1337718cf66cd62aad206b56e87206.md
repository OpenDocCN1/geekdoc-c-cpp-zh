# 11.3 PERFORMING A PAIRED T-TEST

To perform a paired t-test to compare two repeated measures (such as in a before–after situation), where both observations are taken from the same or matched subjects, PROC TTEST with the PAIRED statement. Suppose your data contains the variables WBEFORE WASTER (before and after weight on a diet) for eight subjects, the hypotheses for this test are follows:

$H_0: \mu_{LOSS} = 0$: The population average weight loss is zero.
$H_a: \mu_{LOSS} \neq 0$: The population average weight loss is not zero.
