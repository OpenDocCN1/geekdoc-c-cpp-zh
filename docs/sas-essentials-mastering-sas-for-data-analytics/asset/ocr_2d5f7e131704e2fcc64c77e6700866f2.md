# CHAPTER 6: SAS® ADVANCED PROGRAMMING TOPICS PART 1

A easy-to-perform check is to delete irrelevant records. In this data set, if a line does not contain a Subject ID, we want to eliminate record. This is done with an IF statement.

```
IF SUBJECT =" THEN DELETE;
```

These fixes are illustrated in the next example.
