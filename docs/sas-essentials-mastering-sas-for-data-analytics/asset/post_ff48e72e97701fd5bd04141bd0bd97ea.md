
The from and to variables are SAS date values. The 'interval' argument can be one of the following lengths of time:

- DAY
- WEEKDAY
- WEEK
- TENDAY
- SEMIMONTH
- MONTH
- QTR
- SEMIY
- YEAR

Thus, the following function counts the number of years between the date variables BEGATE and ENDDATE because the date interval indicated is 'YEAR'.

```
INTCK('YEAR', BEGATE, ENDDATE)
```

The following code counts the number of months between these two dates because the date interval indicated is 'MONTH'.

```
INTCK('MONTH', BEGATE, ENDDATE)
```

Another handy date function is the MDY function. This allows you to convert numbers into a SAS date value. For example:

```
BDATE = MDY(10, 12, 1989);
```

converts the October 12, 1989, into a SAS date value. Dates must be in SAS date format for you to use other SAS date functions or to output dates using SAS format specifications. Or if in a data set you have these values

```
MTH=5; DAY=9; YR=2016;
```

the MDY function

```
VISIDATE = MDY(MTH, DAY, YR);
```

creates a SAS variable named VISIDATE with the value May 9, 2016. For a more comprehensive list of functions, refer to Appendix B in this book.

## HANDS-ON EXAMPLE
This example illustrates a method for calculating the difference between two dates (AGE) using the INTCK function. The procedure uses these steps:

1. Read in BDATE as a SAS date value using the INFORMAT MMYYDD8. specification in the INPUT statement.
2. Convert the target date 08/25/2016 into a variable named TARGET using the MDY function.
3. Use the INTCK function to count the number of years between each date (BDATE) in the data set and the TARGET date and assign this value to the variable AGE.
4. Assign the count of years to the variable named AGE.

Here are the steps:

DATA DATES;

AGE=INTCK('YEAR', BDATE, TARGET); * INTCK function;

To display the dates in a readable manner, a FORMAT statement is included in the PROC PRINT paragraph.

6. For your history buffs: If you include the date

(September 4, 1752) into the list of data values and run the program, it indicates this date fell on a Monday (in the current Gregorian calendar). However, this date did not exist. ## 6.2 USING PROC TRANSPOSE

PROC TRANSPOSE allows you to restructure the values in your data set by transposing (or reorienting) the data. This is typically performed when your data are not in the structure required for analysis. For example, if your data are listed with columns, you can transpose the data so subjects represent rows. The simplified syntax for PROC TRANSPOSE is:

```
PROC TRANSPOSE DATA=input-data OUT=output-data;
PREFIX=prefix
BY=variables
VAR variables;
```

- The input data set is the set to be transposed.
- The output data set is the resulting data set.
- PREFIX specifies a prefix to names of variables created in transposition. The default names are COL1, COL2, and on.
- The BY variable, when specified, causes the transpose to be performed once per group.
- The VAR statement specifies which variables are transposed.

## HANDS-ON EXAMPLE
Suppose you have been given a data set in which each line represents a variable and each subject's data are in a single column. This example illustrates how to use PROC TRANSPOSE to restructure this data. Note that some of the data are text, you must indicate that with $ after each variable name in the INPUT statement.

1. Open the program file DTRANS1.SAS.

```
DATA SUBJECTS;
INPUT SUB1 $ SUB2 $ SUB3 $ SUB4 $;
DATALINES;
12 21 13 14
13 21 12 14
15 31 23 23
15 33 21 32
M F F M
;
PROC TRANSPOSE DATA=SUBJECTS OUT=TRANSPOSED;
VAR SUB1 SUB2 SUB3 SUB4;
RUN;
PROC PRINT DATA=TRANSPOSED;
RUN;
```

2. Run the program. The OUT=TRANSPOSED statement creates a data set named TRANSPOSED. The resulting data set is given in Table 6.2.

| 3 | SUB3 | 13 | 12 | 23 | F | |

4. The solution isn't exactly you want. One way to fix that is to use the RENAME statement to give each column a new name. Note how each variable is renamed, particularly GENDER:
