As in the simple linear regression model, the $R^2$ (R-squared) statistic is used to measure the strength of the relationship between the set of independent variables and the dependent variable. The overall significance of the regression is tested using an analysis of variance approach. This overall test that all $eta_i$ are equal to zero. The $p$-value are reported by SAS. If the $p$-value is low (say, <0.05), the conclusion is that some $eta_i$ are not equal to zero, and thus the equation has some predictive value for $Y$.

When there are several possible independent variables, you may want to determine which subset of them provides the best model. A number of model selection techniques, some manual and some automated (e.g., forward selection, backward elimination) can help you reach a parsimonious set of predictors (i.e., those that provide good prediction with few predictors).
