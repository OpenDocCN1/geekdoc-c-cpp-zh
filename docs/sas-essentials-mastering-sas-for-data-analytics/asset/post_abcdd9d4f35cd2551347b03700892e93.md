## Enhancing Your Table: It is fairly easy to add information to your table. For example, suppose you want to report more than one statistic, say N and MEAN. You can combine statistics by placing them in parentheses such as

(N MEAN)

Or to include the label being put into the table, you could use

```
(N="" MEAN="" )
```

Another enhancement is to put some information in the box that appears at the upper of your table. You can do this by including a /BOX="label" option. For example,

```
TABLE(AREA="" ALL=By Area), (SITE="" ALL=By Site)*TYPE=""
* (N="" MEAN="")*SALES_K=""*F=DOLLAR6.2
/ BOX="Fall Sales;
```

## 19.2 USING PROC REPORT

PROC REPORT is a procedure in SAS that allows you to create professional reports and summaries. It is widely used in companies and organizations that need to produce reports on topics such as income, contributions, sales, and so on. Reports are highly customizable using the many options. Although only a few of these options are illustrated here, these examples will help you learn the basics of PROC REPORT.

The syntax for PROC REPORT is different from most statistical procedures because it has a particular emphasis on defining the columns of the report. Here is a simple syntax for PROC REPORT:

```
PROC REPORT DATA=dataset <options>;
COLUMN variables and specifications;
DEFINE column / attributes;
COMPUTE column;
RUN;
```

COLUMN: The COLUMN statement is used to identify variables of interest reported in columns and to specify headers and groups. Every column you want to display must be indicated in the COLUMN statement. A simple report would

```
PROC REPORT DATA=MYASLIB.CARS NOFS;
COLUMN BRAND CITYMP HWYMP;
RUN;
```

## TABLE 19.14 PROC REPORT DEFINE Options

| Name | Purpose |
|---|---|
| DISPLAY | Displays the indicated variable in the column. This is the default DEFINE/DISPLAY; |
| ORDER | Sorts data and forms groups |
| GROUP | Group (consolidation) observations using the specified variable. For example DEFINE BRAND/GROUP; Displays records by BRAND |
| ANALYSIS | Defines a variable used to calculate a statistic within the cell of a report |
| COMPUTE AND ENDCOMPUTE | Begins and ends a code that calculates a value across page rather than down |

## TABLE 19.15 PROC REPORT DEFINE Option Attributes

| Attributes | Example |
|---|---|
| FORMAT = 'LABEL' | FORMAT=.1 'Model Type' Or 'Model/Type' to split title |
| STATISTIC | Any statistic that is available in PROC MEANS. For example, N, MEAN, SUM, STD (DATA, FORMATTED, FREQ, or INTERNAL) same as PROC FREQ.

DEFINE: The DEFINE statement is used to specify the appearance of the columns. Its syntax is

```
DEFINE report-item / <option(s);
```

DEFINE statements allow you to specify attributes that determine how a variable in a column will be displayed. Options for the DEFINE statement follow a slash (/). These options control the appearance of the information in a column. They can be of several types:

- options that describe how to use a variable;
- options that control column headings;
- options that customize a report item;
- other options for a report item.

The options include DISPLAY, GROUP, ANALYSIS, ORDER, and ACROSS. Table 19.14 includes explanations of each of these options. Some common attributes you can include with the DEFINE options are listed in Table 19.15. These appear after the slash and option named in a DEFINE statement. For example,

```
DEFINE var/DISPLAY statement options;
```

or a more specific example:

DEFINE AGE/DISPLAY 'A Label' FORMAT=6.1;

Just as the split character in a label indicates to go to the next line, so the label Model/Type is displayed on two lines. In the Label example, the default split character is a slash/). However, it can be defined as a different character in the PROC REPORT statement. For example, SPLIT='*' the asterisk the split character. The Following Hands-on Examples illustrate several uses of the DEFINE option.
