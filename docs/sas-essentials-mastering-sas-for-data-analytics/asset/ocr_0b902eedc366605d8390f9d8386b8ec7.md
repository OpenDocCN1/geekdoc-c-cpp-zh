# 3.9 GOING DEEPER: UNDERSTANDING HOW THE DATA STEP READS AND STORES DATA

To understand how SAS works, it can be helpful to “look under the hood” and see what is happening in all bits and bytes as SAS reads and processes data. Knowing how SAS handles data is a bit like knowing how the motor works in your car works. You can drive away okay without knowing anything about pistons, but sometimes, it is good to know what that knocking means.

Having an understanding of the data step can help you create programs that avoid problems (programming errors) and take advantage of the internal workings of the program. For example, consider the following simple program

```
DATA NEW;
INPUT ID $ AGE TEMP;
TEMPF=TEMP*(9/5)+32;
```
