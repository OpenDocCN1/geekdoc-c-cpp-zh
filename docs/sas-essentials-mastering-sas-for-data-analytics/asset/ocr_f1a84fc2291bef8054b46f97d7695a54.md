There are a number of tasks that are made easier when using arrays. One example is searching the contents of an array for a specific number or text value. This is accomplished with an IN statement. For example, the statement

```
IF 3 IN MYARRAY then some expression;
```

performs the expression when there is a 3 somewhere in the array MYARRAY.

### HAND-ON EXAMPLE
