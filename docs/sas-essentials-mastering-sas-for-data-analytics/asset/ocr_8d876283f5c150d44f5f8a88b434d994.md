The key assumption underlying the one-sample t-test is that the population from which the random sample is selected is non-normal. If the data are non-normal, then nonparametric tests such as the sign test and the signed rank test are available (Chapter 15). However, because of the central limit theorem, whenever the sample size is sufficiently large, the distribution of the sample mean is approximately normal even when the population is non-normal. A variety of rules of thumb have been recommended to help you determine whether to go and trust the results of a one-sample t-test when your data are nonnormal. The following are general guidelines (see Moore, McCabe, and Craig, 2014).

+   * Small sample size ($N < 15$): You should not use the one-sample t-test if the data are clearly skewed or have outliers present.
* Moderate sample size ($N > 15$): The one-sample t-test can be safely used except when there are outliers.
* Large sample size ($N > 40$): The one-sample t-test can be safely used without regard to skewness or outliers.

# 11.1.1 Running the One-Sample t-test in SAS

In SAS there are (at least) two ways to perform a one-sample t-test. Using PROC VARIATE, you can specify the value of $\mu_0$ for the test reported in the "Tests for Location" table given in Table 11.1 using the option MU0=value. For example,

```
PROC UNIVARIATE MU0=4;VAR LENGTH; RUN;
```

would request a one-sample t-test of the null hypothesis that $\mu_0 = 4$.
A second method in SAS for performing this one-sample t-test is to use the PROC TTEST procedure, for which the corresponding SAS code is

```
PROC TTEST H0=4;VAR LENGTH; RUN;
```
