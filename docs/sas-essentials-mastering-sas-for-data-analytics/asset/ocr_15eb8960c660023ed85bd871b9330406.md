CALL SYMPUT (macro-var, cval);
CALL SYMPTN (macro-var, nval); where cval is some character value or variable and nval is some numeric value or variable name. For example, to store the value of the character variable MYVAR into the macro variable named LEVEL, CALL SYMPUT ('LEVEL', MYVAR);
You can then reference the variable as &level elsewhere in your SAS code
