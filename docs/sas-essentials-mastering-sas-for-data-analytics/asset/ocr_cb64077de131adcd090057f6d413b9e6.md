# TABLE 9.9 Common Options for PROC UNIVARIATE

| Option | Meaning |
|---|---|
| DATA=datame CIBASIC | Specifies data set to use Requests confidence limits for the mean, standard deviation, and variance based on normally distributed data |
| ALPHA=p MU0=n | Specifies the level for the confidence limits Specifies the value of the location parameter for the one-sample t-test, sign test, and signed rank test (MU stands for the Greek letter $\mu$, which symbolizes the population mean) |
| NORMAL PLOTS | Requests tests for normality Requests stem-and-leaf, box, and probability plots Requests a series of explanatory plots to be created. These include a horizontal histogram, a box plot, and a normal probability plot. |
| NOPRINT | Suppresses the output of descriptive statistics (primarily used in conjunction with the OUTPUT statement) |
| TRIMMED=value | Trims the top and bottom proportion of the data before calculating the mean; this can be used to eliminate outliers from the calculation (e.g., TRIMMED=0.1) |

# TABLE 9.10 Common Statements for PROC UNIVARIATE

| Option | Meaning |
|---|---|
| VAR variable(s); OUTPUT | Identifies one or more variables to analyze Identifies output data set and statistics to include in the data set; the syntax for this statement is OUTPUT=<SAS-data-set> statistic-keyword-l=name(s)> < ...statistic-keyword-l=name()><percentiles-specification>; |
| HISTOGRAM | Produces a histogram of one or more specified variables; the syntax is HISTOGRAM<variable> <option>; A simple program that creates a histogram using the variable AGE in the SOMEDATA data set PROC UNIVARIATE DATA="C:\SASDATA\SOMEDATA"; VAR AGE; HISTOGRAM AGE; RUN; |
| INSET | Sees options for this statement below Puts a box containing summary statistics in a graph associated with CDFPLOT, HISTOGRAM, PPPLOT, PROBLOT, or QQPLOT statements |
| BY, CLASS, WHERE | Statements common to most PROCS |

(Apart from HISTOGRAM, these options also work with CDFPLOT, PPPLOT, PROPLOT, and QQPLOT).
