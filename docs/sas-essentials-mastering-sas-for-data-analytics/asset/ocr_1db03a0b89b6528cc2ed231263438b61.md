# HANDS-ON EXAMPLE

1. Open the program FUNC_DATETIME.SAS. This program reads in a date and time arrived as separate variables and datetime leave as a single variable.

```
DATA TIME;
FORMAT DTARRIVE MMDDDY10. TIMEARRIVE TIME10.
ARRIVETIME DATETIMELEAVE DATETIME19;
INPUT @1 DTARRIVE DATE10.
@12 DATETIMELEAVE DATETIME19;
MERGE DHMS (DTARRIVE, 0, 0, TIMEARRIVE);
SEONDS1=DATETIMELEAVE-ARRIVETIME;
SEONDS2=INTCK('seconds', ARRIVETIME, DATETIMELEAVE);
ALINES;
10NOV2016 1:13 pm 10NOV2016:18:49:19
12DEC2016 9:20 am 12DEC2016:13:23:22
;
```

To calculate the difference between the arrive and leave time, we want to first combine the date arrived with the leave time. Note how this is done using the DHMS function:

```
ARRIVETIME=DHMS(DTARRIVE, 0, 0, TIMEARRIVE);
```

The first parameter is the date, and as we don't have Hours and Minutes, we put DATARRIVE in the Seconds argument. Once we have ARRIVETIME, we can calculate the number of seconds between the two datetimes. This is done by subtraction and with the INTCK function. Run the program and observe the results in Table B.5.

2. Calculate minutes and hours using two methods as follows:

```
MINUTES1=SECONDS1/60;
HOURS2=MINUTES1/60;
MINUTES2=INTCK('MINUTE', ARRIVETIME, DATETIMELEAVE);
HOURS2=INTCK('HOUR', ARRIVETIME, DATETIMELEAVE);
```

Resum the code and observe the output. Note the difference in the results. INTCK gives the integer portion of the results, whereas a straight calculation preserves the fraction.

3. Extract the month and day of the week from DTARRIVE using the MONTH and DAY functions:

```
MONTH=MONTH(DTARRIVE);
DOM=DAY(DTARRIVE);
```

Run the code and observe the results. The month and day of the month are reported as numbers. See the example in the Special Functions for an example of how to display the month and day of the month in words.
