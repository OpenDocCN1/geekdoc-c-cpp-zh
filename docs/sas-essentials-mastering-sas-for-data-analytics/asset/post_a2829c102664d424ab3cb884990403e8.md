## APPENDIX E: USING SAS UNIVERSITY EDITION

SAS University Edition (SUE) is a fully functional version of SAS software that includes these components: SAS Studio, Base SAS, SAS/STAT, and SAS/ACCESS. These modules are sufficient for performing most of the examples in this book. Exceptions are indicated in the following section named "Limitations." Although the interface is different from a locally installed version, the program provides the same analytics. In addition, SUE will run on PC (Windows), Mac, or Linux. The key difference is that in order to run SUE, you must have an active Internet connection. When you submit (run) a SAS program using SUE, the code is sent to a server (via the Internet) and the code is processed there and returned to your workstation. Appendix shows how you can use SUE to run the examples. The main differences are in the user interface and how you access files. This brief tells you how to access files for SAS Essentials.

### E.1 INSTALLING SAS UNIVERSITY EDITION

Follow the instructions provided by SAS to install SUE. It differs according to the type of computer. Here is a summary of the instructions (for installation on Windows).

Step 1: Download Visualization Software To install SUE, go to http://www.sas.com/en_us/university-edition/download-software.html and follow the instructions from SAS on installing a virtualization program (free) for your computer. For this example, we'll use Oracle VirtualBox on a Windows platform. There are several virtual applications to choose from this web page. Choose the one that matches your computer's operating system.

Suggestions:
- Accept the defaults for installing Virtual Box.
- We recommend that you download and print the "Start Guide" for specific instructions on the SUE on your computer. Note: you must have a SAS profile (free to set up). You will be prompted to use a profile during the install process if you don't already one.
- This can take 30 minutes or more depending on your computer and network speed.

Step 2: Add SAS to VirtualBox (Important): We recommend that you download the sample files used in this book before you set SUE. Go to http://www.analyticseliot.com/sas website and follow instructions for downloading these sample files. This creates a folder named C:\SASDATA that contains the sample files used for SAS Essentials.

As part of the SUE setup, you are instructed to create a folder (in Windows) named C:\SASUniversityEdition. To set up SAS Essentials, also create a folder named C:\UniversityEditionfolders\SASDATA. Copy and paste all of the files from the C:\SASDATA folder into C:\UniversityEditionfolders. (Make note of the folder you used since this will become later.)

From the same SAS web page, locate the Quick Start Guide that links the virtualization program you installed in Step 1. Follow those instructions to add SAS to your virtual machine. (Step 3 uses the instructions "Oracle VirtualBox Quick Start Guide")

Step 3: Begin SAS once you have installed the Visualization Software and SUE, there are typical steps to begin SAS:

1. Open the Visualization Software you installed in Step 1. (This example uses Oracle VirtualBox.). The Oracle VirtualBox Manager is shown in Figure E.1.

Step 4: Using UE with SAS Essentials. To test the UE, do these steps:

A. Select FIRST.SAS from the list of SASDATA. Double-click on My Folders (see Figure E.5).
B. Click on the “Running” icon at the top of CODE window. This runs the SAS program, and your results appear in RESULTS tab.
C. Enter the following code:

```sas
PROC MEANS DATA="folders/myfolders/SASDATA";
RUN;
```

After you enter this code, clicking the running man icon and the output in Table E.1 appears. This verifies that you have access to the SAS files in the SASDATA subfolder. (If you get an error, examine the Log and note the errors reported. Click on the CODE tab again, correct any errors in your code, and resubmit.)
