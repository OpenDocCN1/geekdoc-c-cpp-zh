## C.3 RELATIONAL ANALYSES (CORRELATION AND REGRESSION)

Make decision by reading from the left to the right (Table C.3).

### TABLE C.3 Decision Table for Relational Analysis

| What Is the Data Type for the Dependent (Response) Variable? | Procedure to Use/SAS PROC |
|---|---|---|
| You want to analyze the relationship between two variables (if regression, one variable is classified as a predictor variable and the other a predictor variable). | Normal | Pearson correlation, simple linear regression PROC REG (Chapter 12) |
| | At least ordinal | Spearman correlation PROC CORR (Chapter 12) |
| | Categorical | r*c contingency table analysis PROC FREQ (Chapter 10) |
| | Binary | Logistic regression PROC LOGISTIC (Chapter 16) |
| You want to analyze the relationship between a response variable and two more predictor variables. | Normal | Multiple linear regression PROC REG (Chapter 12) |
| | Binary | Logistic regression PROC LOGISTIC (Chapter 16) |

In this table the term "Data type" applies to the dependent variable for regression procedures. For assessment of association (such as correlation or crosstabulation), the data type applies to both variables.

# PROC MEANS – used to calculate statistics for quantitative data (Chapter 9)

```

RUN;
```


# PROC FREQ – frequencies and crosstabulations (Chapter 10)

```
PROC FREQ DATA=dataset; * basic table;

RUN;

RUN;
```

# PROC TTEST – comparing means (Chapter 11)

```
PROC TTEST DATA=dataset H0=3; * Single sample t-test;
VAR varname;
PROC TTEST DATA=dataset; * paired t-test;
CLASS groupvar;
VAR varname;
RUN;
```

# PROC ANOVA, GLM, and MIXED – comparing more than three means (Chapters 13 and 14)

```
PROC ANOVA DATA=dataset; * one-independent group;
CLASS groupvar;
MODEL depvar = groupvar;
MEANS groupvar / TUKEY;
RUN;
PROC GLM; * two-factors;
CLASS factor1var factor2var;
MODEL RESPONSE= factor2var*factor2var;
RUN;
PROC MIXED; * two-factor, one random;
CLASS randomfactor fixedfactor;
MODEL depvar = fixedfactor;
RANDOM randomfactor*fixedfactor;
RUN;
```

# PROC CORR – correlations between pairs of variables (Chapter 12)

```
PROC CORR DATA=dataset Pearson;
VAR AGE TIME1-TIME4;
RUN;
```

# PROC REG – linear regression analysis (Chapter 12)

```
PROC REG DATA=dataset; * simple linear regression;
MODEL dependentvar = independentvar/R; * examine residuals;
RUN;
PROC REG DATA=dataset; * multiple linear regression;
MODEL dependentvar = ind1 ind2 etc/SELECTION=STEPWISE
SLENTRY=0.05;
SLSTAY=0.05;
RUN;
```

# PROC NPARIWAY – nonparametric comparisons (Chapter 15)

```
PROC NPARIWAY DATA=dataset;
CLASS GROUP; * compare independent groups;
VAR SALARY;
RUN;
```

# PROC LOGISTIC – logistic regression (Chapter 16)

```
PROC LOGISTIC DATA=dataset;
CLASS variables;
MODEL dependentvar = independentvar(s)
/ SELECTION=STEPWISE
SLENTRY=0.05
SLSTAY=0.1
RISKLIMITS
CTABLE
OUTROC=ROC1;
RUN;
```
