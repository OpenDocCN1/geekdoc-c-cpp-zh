# B.8 SPECIAL USE FUNCTIONS

The term "special use function" is a catch-all phrase referring to other functions that are useful in SAS. They include functions that provide ways to convert variables from one type to another, create macro variables, create lag values, and determine differences in distance using zip codes. These functions are listed in Table B.11.
