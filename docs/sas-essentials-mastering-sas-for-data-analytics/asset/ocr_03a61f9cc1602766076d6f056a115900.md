# 3.3 Use SAS code to import XLSX data.

+   a. Use the SAS code to import data from the Excel file FAMILY2.XLSX using these criteria:
I. Create an SAS data set named INCOME in the WORK library using the OUT=statement.
II. Use DATAFILE=to specify the location of the original Excel file (XLSX type) on your hard disk.
III. Use DBMS=to specify the data source (see the chart for DBMS options earlier in this chapter for type of file).
IV. Use SHEET=to designate "Dat-a" as the name of the Excel to import.
