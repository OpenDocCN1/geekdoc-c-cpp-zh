$s_p = x_A \sigma_A + x_B \sigma_B$  (i)
$e_p = x_A \mu_A + x_B \mu_B$  (ii)

Since
$x_A + x_B = 1 \quad \text{or} \quad x_A = 1 - x_B$  (iii)

By substituting for $x_A$ in (i), using (iii), one obtains from (i):

$s_p = x_A \sigma_A + x_B \sigma_B,$  using (i)
$= (1 - x_B)\sigma_A + x_B \sigma_B,$  substituting for $x_A$ from (iii)
$= \sigma_A - x_B \sigma_A + x_B \sigma_B$

or

$s_p = \sigma_A + x_B(\sigma_B - \sigma_A)$  (3.56)

Similarly, by substituting for $x_A$ in (ii), using (iii), one obtains from (ii):

$e_p = x_A \mu_A + x_B \mu_B,$  using (ii)
$= (1 - x_B)\mu_A + x_B \mu_B,$  substituting for $x_A$ from (iii)
$= \mu_A - x_B \mu_A + x_B \mu_B$

or

$e_p = \mu_A + x_B(\mu_B - \mu_A)$  (3.57)

## Example 3.13 A Portfolio of Two Perfectly Positively Correlated Risky Assets

If the two returns are perfectly positively correlated, then $\rho_{AB}=1$. Now, for a two-asset portfolio:

σ_p² = x_A² σ_A² + 2 x_A x_B ρ_AB σ_A σ_B + x_B² σ_B²
= x_A² σ_A² + 2 x_A x_B (1) ρ_AB σ_A σ_B + x_B² σ_B², since ρ_AB = 1
= x_A² σ_A² + 2 x_A x_B σ_A σ_B + x_B² σ_B², namely, a binomial perfect square
= (x_A σ_A + x_B σ_B)²   (3.27)

and

σ_p = |x_A σ_A + x_B σ_B|   (3.55)

R_p = x_A R_A + x_B R_B   (3.23)

μ_p = E[R_p] = x_A μ_A + x_B μ_B   (3.24)

### Remarks:
- 1) |x_A, x_B| represents the absolute value of the x expression enclosed.
- 2) If both x_A and x_B are nonnegative, namely, zero or positive, then the expression (x_A σ_A + x_B σ_B) will be nonnegative, since neither σ_A nor σ_B is negative.
- 3) If either x_A or x_B is sufficiently negative, the expression (x_A σ_A + x_B σ_B) may become negative, and the absolute value should apply.
- 4) Risks: From the combinations of long positions in these two assets, namely, x_A ≥ 0, x_B ≥ 0 and in any such combinations: σ_p = x_A σ_A + x_B σ_B from (3.23), σ_p = x_A σ_A + x_B σ_B, from (3.23) = (1 - x_B) σ_A + x_B σ_B = σ_A - x_B σ_A + x_B σ_B namely, σ_p = σ_A + x_B (σ_B - σ_A)   (3.56)
- 5) Similarly, for returns, for such combinations: μ_p = E[R_p] = x_A μ_A + x_B μ_B, from (3.24) = (1 - x_B) μ_A + x_B μ_B = μ_A - x_B μ_A + x_B μ_B namely, μ_p = μ_A - x_B (μ_A - μ_B)   (3.57)
- 6) In Figure 3.20, the σ-μ plot represents the following system: μ_A = 8, σ_A = 5, μ_B = 10, σ_B = 15, and ρ_AB = 1 Both the risk and the return will be proportional to x_p, such portfolio will be on a straight line—connecting the points representing the two assets, namely, point 1: (σ_A =5, μ_A =8), and point 2: (σ_B =15, μ_B =10).

## Example 3.14 The Minimum-Variance Portfolio

The strongest case of diversification occurs when ρ_AB = −1.0.

For this case,

σ_p² = x_A² σ_A² + 2 x_A x_B ρ_AB σ_A σ_B + x_B² σ_B²    (3.27)
= x_A² σ_A² + 2 x_A x_B (−1) σ_A σ_B + x_B² σ_B²    (3.27a)
= x_A² σ_A² − 2 x_A x_B σ_A σ_B + x_B² σ_B²

namely,

σ_p² = (x_A σ_A − x_B σ_B)²

so that

σ_p = |(x_A σ_A − x_B σ_B)|

Thus, for this case, the minimum-variance portfolio will be assigned to the risk-free asset A that may be determined as follows:

From |(x_A σ_A − x_B σ_B)| = 0, it follows that

x_A σ_A − x_B σ_B = 0    (i)

and given that

x_A + x_B = 1    (ii)

or

x_B = 1 − x_A    (iii)

Substituting x_B = 1 − x_A in (i), one obtains

x_A σ_A − (1 − x_A) σ_B = 0

or

x_A (σ_A + σ_B) = σ_B

namely,

$x_A = \sigma_B/(\sigma_A + \sigma_B)$

and

$x_B = 1 - x_A = 1 - \{\sigma_B/(\sigma_A + \sigma_B)\} = \sigma_A/(\sigma_A + \sigma_B)$

When $\sigma_A =5$ and $\sigma_B=15$, 

$x_A = \sigma_B/(\sigma_A + \sigma_B)=15/(5+15)=15/20=3/4=0.75$

and

$x_B = 1 - x_A = 1/4 = 0.25$

so that

$\sigma_p = |(x_A\sigma_A - x_B\sigma_B)| = |(0.75)(5) - (0.25)(15)| = |3.75 - 3.75| = 0$

namely, the two assets are perfectly negatively correlated!

And its Expected Return will be given by

$\mu_p = E[R_p] = x_A\mu_A + x_B\mu_B$

$= (0.75)(8\%) + (0.25)(10\%)$

$= 6.0\% + 2.5\%$

$= 8.5\%$ (3.24)

The above results are graphically presented, in white, in Figure 3.21, which also repeats the results illustrated in Figures 3.10–3.12.

- d) A general formula for the minimum-variance portfolio may be derived as follows:

Starting with a reduced-form equation where the variance var_p of a two-asset portfolio is being expressed as a function of x_B, starting with var_{A-B} = var_A + 2x_B(covar_{A-B} - var_A) + x_B^2(var_A - 2covar_{A-B} + var_B) (3.54) for the two-asset portfolio, assets A and B.

Differentiating both sides of (3.54), with respect to x_B, namely, taking the ∂/∂x_B operation on both sides of (3.54), the result is d(var_{A-B})/dx_B = 0 + 2(covar_{A-B} - var_A) + 2x_B(var_A - 2covar_{A-B} + var_B) (3.55)

To obtain a stationary point, one sets (3.55) to zero, and solve for the value of x_B that will provide the minimum-variance portfolio, namely, solving for x_{B-min}. The result is 2(covar_{A-B} - var_A) + 2x_{B-min}(var_A - 2covar_{A-B} + var_B) = 0 from which x_{B-min} = (var_A - covar_{A-B})/(var_A - 2covar_{A-B} + var_B) (3.56)

This minimum-variance portfolio may have a lower risk than either of the two-component assets, and may also have a higher return!
