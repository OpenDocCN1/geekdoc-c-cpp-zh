"pick" matrix, one obtains the "general" view specification:

Pμ ← ~ N(μ, Ω)  (3.68)

in which Ω is the diagonal matrix diag(σ₁², σ₂², σ₃², …, σₙ²). It may be shown, using Bayes' law, that the posterior distribution of the market mean conditional on these views is

μ̂_q,Ω ~ N(μ_BL, Σ^μ_BL)  (3.69)

where

μ_BL = {(τΣ)⁻¹ + PᵀΩ⁻¹P}⁻¹ {(τΣ)⁻¹π + PᵀΩ⁻¹q}  (3.70)

Σ^μ_BL = {(τΣ)⁻¹ + PᵀΩ⁻¹P}⁻¹  (3.71)

One may then obtain the posterior distribution of the market by taking

A|μ_q,Ω = μ̂_q,Ω + Z  and  Z ~ N(0, Σ)  (3.72)

which is independent of μ.

One may then obtain

E[A] = μ_BL  (3.73)

and

Σ_BL = Σ + Σ^μ_BL  (3.74)

# The Canonical Black-Litt... Reference Model

The remainder of the Black–Litt... model is built on the reference model for returns. It assumes which variables are random, and which are not. It also defines which parameters are modeled, and which are not. Other reference models have been Alternative Reference Model or Beyond Black–Litt...man, which do not have the same theoretical basis as the canonical one that was initially specified in Black and Litt...man (1992).

Starting with normally distributed expected returns,

r ~ N(μ, Σ)  (3.75)

The fundamental objective of the Black–Litt...man model is to model these expected returns, which are assumed to be normally distributed with mean μ and variance Σ. Note that one will need at least these values, the expected returns, and covariance matrix later as inputs into a portfolio selection model.
