With the Lagrangian Multiplier Function L given by (3.39), one has

0 = ∂L/∂x_A = ∂L(x_A, x_B, λ)/∂x_A = ∂{(x_A²σ_A² + x_B²σ_B² + 2x_Ax_Bσ_AB) + λ(x_A + x_B -1)}/∂x_A = (2x_Aσ_A² + 0 + 2x_Bσ_AB) + λ(1 + 0 - 0) = 2x_Aσ_A² + 2x_Bσ_AB + λ (3.41a)

0 = ∂L/∂x_B = ∂L(x_A, x_B, λ)/∂x_B = ∂{(x_A²σ_A² + x_B²σ_B² + 2x_Ax_Bσ_AB) + λ(x_A + x_B -1)}/∂x_B = (0 + 2x_Bσ_B² + 2x_Aσ_AB) + λ(1 + 0 - 0) = 2x_Bσ_B² + 2x_Aσ_AB + λ (3.41b)

0 = ∂L/∂λ = ∂L(x_A, x_B, λ)/∂λ = ∂{(x_A²σ_A² + x_B²σ_B² + 2x_Ax_Bσ_AB) + λ(x_A + x_B -1)}/∂λ = (0 + 0 + 0) + (x_A + x_B -1) = x_A + x_B - 1 (3.41c)

Combining (3.41a) and (3.41b), one obtains 2x_Aσ_A² + 2x_Bσ_AB + λ = 0 = 2x_Bσ_B² + 2x_Aσ_AB + λ namely, 2x_Aσ_A² + 2x_Bσ_AB + λ = 2x_Bσ_B² + 2x_Aσ_AB + λ namely, 2x_Aσ_A² + 2x_Bσ_AB = 2x_Bσ_B² + 2x_Aσ_AB namely, x_Aσ_A² + x_Bσ_AB = x_Bσ_B² + x_Aσ_AB namely, x_Aσ_A² - x_Aσ_AB = x_Bσ_B² - x_Bσ_AB namely, x_A(σ_A² - σ_AB) = x_B(σ_B² - σ_AB) or, x_B = x_A {(σ_A² - σ_AB)/(σ_B² - σ_AB)} (3.42)
