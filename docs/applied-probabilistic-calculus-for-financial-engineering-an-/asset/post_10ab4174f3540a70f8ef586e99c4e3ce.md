
With the Lagrange multiplier function L given by (3.39), one has

0 = ∂L/∂x_A = ∂L(x_A, x_B, λ)/∂x_A = ∂{(x_A²σ_A² + x_B²σ_B² + 2x_Ax_Bσ_AB) + λ(x_A + x_B − 1)}/∂x_A = (2x_Aσ_A² + 0 + 2x_Bσ_AB) + λ(1 + 0 − 0) = 2x_Aσ_A² + 2x_Bσ_AB + λ (3.41a)

0 = ∂L/∂x_B = ∂L(x_A, x_B, λ)/∂x_B = ∂{(x_A²σ_A² + x_B²σ_B² + 2x_Ax_Bσ_AB) + λ(x_A + x_B − 1)}/∂x_B = (0 + 2x_Bσ_B² + 2x_Aσ_AB) + λ(1 + 0 − 0) = 2x_Bσ_B² + 2x_Aσ_AB + λ (3.41b)

0 = ∂L/∂λ = ∂L(x_A, x_B, λ)/∂λ = ∂{(x_A²σ_A² + x_B²σ_B² + 2x_Ax_Bσ_AB) + λ(x_A + x_B − 1)}/∂λ = (0 + 0 + 0) + (x_A + x_B − 1) = x_A + x_B − 1 (3.41c)

Combining (3.41a) and (3.41b), one obtains

2x_Aσ_A² + 2x_Bσ_AB + λ = 0 = 2x_Bσ_B² + 2x_Aσ_AB + λ

namely,

2x_Aσ_A² + 2x_Bσ_AB = 2x_Bσ_B² + 2x_Aσ_AB

namely,

x_Aσ_A² + x_Bσ_AB = x_Bσ_B² + x_Aσ_AB

namely,

x_Aσ_A² − x_Aσ_AB = x_Bσ_B² − x_Bσ_AB

namely,

x_A(σ_A² − σ_AB) = x_B(σ_B² − σ_AB)

or,

x_B = x_A (σ_A² − σ_AB)/(σ_B² − σ_AB) (3.42)

Finally, to obtain the required values (x_A^{min}, x_B^{min}), one may incorporate the third Lagrange multiplier condition (3.41c), namely, combining (3.42) and (3.41c):

From (3.42), x_B^{min} = x_A^{min} (σ_A² − σ_AB)/(σ_B² − σ_AB) (3.43a)

From (3.41c), x_B^{min} = 1 − x_A^{min} (3.43b)

## 3.2.4.2 Effects of Portfolio Variance on Investment Possibilities

For a portfolio of any two assets, A and B, the correlation between A and B may strongly affect the investment possibilities of the portfolio. Thus,

- a) If ρ_AB is close to 1, then the investment set approaches a linear relationship such that the return is close to a straight line connecting the portfolio with all the funds invested in asset B, namely, (x_A, x_B) = (0, 1), to the portfolio with all the funds placed in asset A only, that is, (x_A, x_B) = (1, 0).
- b) In a plot of μ_p (as the ordinate) versus σ_p (as the abscissa) (see Figure 1.2), as ρ_AB approaches 0, the set bows toward the μ_p-axis, and the power of diversification starts to make its presence felt! If ρ_AB = −1, the set will actually tangentially touch the μ_p-axis. This implies that the assets A and B will be perfectly negatively correlated, and there exists a portfolio of A and B that has positively expected return but zero variance!

And to determine the portfolio with σ_p^{min} = 0 when ρ_AB = −1, one may use (3.44a) and (3.44b), and the condition that

σ_AB = ρ_AB σ_A σ_B (3.27)

to give

x_A^{min} = (σ_B² − σ_AB)/(σ_A² + σ_B² − 2σ_AB) (3.44a)

Since ρ_AB = −1,

σ_AB = ρ_AB σ_A σ_B = (−1)σ_A σ_B = −σ_A σ_B (3.45)

Now, from (3.44),

x_A^{min} = (σ_B² − σ_AB)/(σ_A² + σ_B² − 2σ_AB)
= (σ_B² − (−σ_A σ_B))/(σ_A² + σ_B² − 2(−σ_A σ_B)), from (3.45)
= (σ_B² + σ_A σ_B)/(σ_A² + σ_B² + 2σ_A σ_B)
= σ_B(σ_A + σ_B)/(σ_A² + 2σ_A σ_B + σ_B²)
= σ_B(σ_B + σ_A)/(σ_B + σ_A)²
= σ_B/(σ_B + σ_A) (3.44a)

And using (3.44b),

x_B^{min} = 1 − x_A^{min} (3.44b)

## 3.2.4.3 Introduction to Portfolio Optimization

For the efficient set of portfolios as described in Figure 3.6, the critical question will be

> "Which portfolio should an investor choose? And why?"

Of the efficient portfolios, investors will select the one that closely supports their risk preferences. In general, risk-averse investors will prefer a portfolio that has low risk, namely, low volatility, and will prefer a portfolio close to the global minimum-variance portfolio.

On the other hand, risk-tolerant investors will ignore volatility and seek portfolios with high expected returns. These investors will choose portfolios with large amounts of asset A that may involve short-selling asset B.

## 3.2.5 Attractive Portfolios with Risk-Free Assets

In Section 3.1.4, an efficient set of portfolios in the absence of a risk-free asset was constructed. Now consider what happens when a risk-free asset is being introduced.

A risk-free asset is equivalent to a default-free pure discount bond that matures at the end of the assumed investment period. The risk-free rate r_f may be represented by the nominal return on a low-risk bond. For example, if the investment period is 1 month, then the risk-free asset is a 30-day U.S. Treasury bill (T-bill), and the risk-free rate is the nominal rate of return on the T-bill. (The "default-free" assumption of U.S. national debt has been questioned owing to the possible, and probable, inability of the U.S. Congress to address the long-term debt problems of the U.S. government.)

If the portfolio holding of the risk-free asset is positive, then it is equivalent to "lending money" at the risk-free rate. If the portfolio holding of the risk-free asset is negative, then one is borrowing money at the risk-free rate.

## 3.2.5.1 An Attractive Portfolio with a Risk-Free Asset

Consider an arbitrary portfolio with asset B; one may examine the consequences if one should introduce a risk-free asset (say, a T-bill) into this portfolio.

Now the risk-free rate is constant (fixed) over the investment period. The risk-free asset has the following properties:

μ_f = E[r_f] = r_f (3.45a)

var(r_f) = 0 (3.45b)

cov(R_B, r_f) = 0 (3.45c)

Then, within this portfolio,

- let the proportion of the investment in asset B = x_B,
- then the proportion of the investment in T-bills = (1 − x_B)

and hence the return of this portfolio is

R_p = return from asset B + return from the risk-free asset
= x_B R_B + (1 − x_B) r_f
= r_f + (R_B − r_f) x_B (3.46)

The term (R_B − r_f) is the excess return over the T-bill return on asset B.

Hence, the expected return of the portfolio is

μ_p = r_f + (E[R_B] − r_f) x_B
= r_f + (μ_B − r_f) x_B (3.47)

In (3.47), the factor (μ_B − r_f) is the expected excess return or risk premium on asset B.
