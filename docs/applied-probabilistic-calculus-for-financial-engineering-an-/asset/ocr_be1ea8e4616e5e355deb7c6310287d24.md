# Example 3.14 The Minimum-Variance Portfolio

The strongest case of diversification occurs when ρ_AB = −1.0.

For this case,

σ_p² = x_A² σ_A² + 2 x_A x_B ρ_AB σ_A σ_B + x_B² σ_B²    (3.27)
= x_A² σ_A² + 2 x_A x_B (−1) σ_A σ_B + x_B² σ_B²    (3.27a)
= x_A² σ_A² − 2 x_A x_B σ_A σ_B + x_B² σ_B²

namely,

σ_p² = (x_A σ_A − x_B σ_B)²

so that

σ_p = |(x_A σ_A − x_B σ_B)|

Thus, for this case, the minimum-variance portfolio will be assigned to the risk-free asset A that may be determined as follows:

From |(x_A σ_A − x_B σ_B)| = 0, it follows that

x_A σ_A − x_B σ_B = 0    (i)

and given that

x_A + x_B = 1    (ii)

or

x_B = 1 − x_A    (iii)

Substituting x_B = 1 − x_A in (i), one obtains

x_A σ_A − (1 − x_A) σ_B = 0

or

x_A (σ_A + σ_B) = σ_B
