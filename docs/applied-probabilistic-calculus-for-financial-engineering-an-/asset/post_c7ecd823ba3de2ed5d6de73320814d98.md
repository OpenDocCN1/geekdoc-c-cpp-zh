
**Proof:**

Since $C = Ef(S/E)$, from (RE-3.5),

$$\begin{aligned}
\frac{\partial C}{\partial E} &= \frac{\partial}{\partial E}[Ef(S/E)] \\
&= f(S/E) + E\frac{\partial f(S/E)}{\partial E} \\
&= f(S/E)\cdot 1 + E\cdot S\left(-\frac{1}{E^2}\right)\frac{\partial f}{\partial E} \\
&= f(S/E) - (S/E)f'(S/E)
\end{aligned}$$

therefore, upon substituting for $f(S/E)$ from (RE-3.6):

$$\frac{\partial C}{\partial E} = C/E - (S/E)F'(S/E) \tag{RE-3.8}$$

Again, since $C = Ef(S/E)$, from (RE-3.4),

$$\begin{aligned}
\frac{\partial C}{\partial S} &= \frac{\partial}{\partial S}[C] \\
&= \frac{\partial}{\partial S}[Ef(S/E)] \\
&= E\frac{\partial}{\partial S}[f(S/E)] \\
&= E(1/E)\frac{\partial}{\partial S}[f(S/E)] \\
&= (1)f'(S/E) \\
&= f'(S/E)
\end{aligned}$$

Therefore,

$$\frac{\partial C}{\partial S} = f'(S/E) \tag{RE-3.9}$$

or

$$\frac{\partial C}{\partial S} = f'(S/E) = f'$$

Hence,

$$S\frac{\partial C}{\partial S} = Sf'(S/E) = Sf'$$

Again, from (RE-3.5),

$$C = Ef(S/E)$$

Therefore,

$$\begin{aligned}
\frac{\partial C}{\partial S} &= \frac{\partial}{\partial S}[Ef(S/E)] \\
&= (1/E)\frac{\partial}{\partial S}[Ef(S/E)] \\
&= \frac{\partial}{\partial S}[Ef(S/E)] \\
&= f'(S/E)
\end{aligned} \tag{RE-3.10}$$

Therefore,

$$E\frac{\partial}{\partial E}(C) = \frac{\partial}{\partial E}[Ef(S/E)]$$

upon substituting for C from (RE-3.5).

Also, from (RE-3.8),

$$\frac{\partial C}{\partial E} = C/E - (S/E)F(S/E) \tag{RE-3.11}$$

Hence,

$$\frac{\partial C}{\partial E} = \frac{\partial}{\partial E}[Ef(S/E)]$$

$$= f(S/E) \tag{RE-3.12}$$

Now,

$$E\frac{\partial C}{\partial E} = E\left[C/E - (S/E)F(S/E)\right],\text{ from (RE-3.11)}$$ 
$$= C - SF(S/E)$$
$$= C - S\frac{\partial C}{\partial S},\text{ from (RE-3.10)}$$

Hence,

$$S\frac{\partial C}{\partial S} = C = E\frac{\partial C}{\partial E} \tag{RE-3.13}$$

which is an important intermediate result.

Similarly, it may be shown that

$$S^2\frac{\partial^2 C}{\partial S^2} = E^2\frac{\partial^2 C}{\partial E^2} \tag{RE-3.14}$$

which is a final result that may be readily obtained as follows:

Since $S\frac{\partial C}{\partial S} = C - E\frac{\partial C}{\partial E}$, from (RE-3.13)

$$\frac{\partial C}{\partial S} = C/S - (E/S)\frac{\partial C}{\partial E}$$

and

$$\frac{\partial^2 C}{\partial S^2} = \frac{\partial}{\partial S}\left\{C/S - (E/S)\frac{\partial C}{\partial E}\right\}$$
$$= \frac{\partial}{\partial S}\left\{C/S\right\} - \frac{\partial}{\partial S}\left\{(E/S)\left(\frac{\partial C}{\partial E}\right)\right\}$$
$$= -(C/S^2) + (E/S^2)\left(\frac{\partial C}{\partial E}\right)$$

namely,

$$S^2\frac{\partial^2 C}{\partial S^2} = -C + E\left(\frac{\partial C}{\partial E}\right) \tag{RE-3.15}$$

Moreover, since

$$\frac{\partial C}{\partial E} = F(S/E),\text{ from (RE-3.12)}$$ 
$$E\frac{\partial C}{\partial E} = EF(S/E) = C,\text{ from (RE-3.5)}$$

Therefore,

$$\frac{\partial C}{\partial E} = \frac{C}{E} \tag{RE-3.16}$$

and

$$\frac{\partial^2 C}{\partial E^2} = \frac{\partial}{\partial E}\left[\frac{\partial C}{\partial E}\right]$$

by definition

$$= \frac{\partial}{\partial E}\left[\frac{C}{E}\right],\text{ from (RE-3.16)}$$

$$= -\frac{C}{E^2} + \frac{1}{E}\frac{\partial C}{\partial E}$$

by the differentiation of a quotient rule

or

$$E^2\frac{\partial^2 C}{\partial E^2} = -C + E\frac{\partial C}{\partial E} \tag{RE-3.17}$$

Combining (RE-3.15) and (RE-3.17), one finally obtains (RE-3.14), as required.

And now, upon substituting for the terms $S^2\frac{\partial^2 C}{\partial S^2}$ and $S\frac{\partial C}{\partial S}$, from (RE-3.14) and (RE-3.13), respectively, into the Black–Scholes equation (RE-3.1), the result is

$$\frac{\partial C}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 C}{\partial S^2} + r S \frac{\partial C}{\partial S} - r C = 0 \tag{RE-3.1}$$

namely,

$$\frac{\partial C}{\partial t} + \frac{1}{2}\sigma^2 \left(S^2 \frac{\partial^2 C}{\partial S^2}\right) + r\left(S\frac{\partial C}{\partial S}\right) - r C = 0$$

namely,

$$\frac{\partial C}{\partial t} + \frac{1}{2}\sigma^2 \left(E^2 \frac{\partial^2 C}{\partial E^2}\right) + r\left(C - E\frac{\partial C}{\partial E}\right) - r C = 0$$

namely,

$$\frac{\partial C}{\partial t} + \frac{1}{2}\sigma^2 \left(E^2 \frac{\partial^2 C}{\partial E^2}\right) - r E \frac{\partial C}{\partial E} = 0 \tag{RE-3.2}$$

which is (RE-3.7), as required.

### 4.1 Data and Data Processing

*Data* are facts or figures from which conclusions can be drawn. When the data have been recorded, classified, organized, related, or interpreted within a framework so that meaning emerges, they become *information*. There are several steps involved in turning data into information, and these steps are known as *data processing*. This section describes data processing and how computers perform these steps efficiently and effectively.

It will be indicated that many of these processing activities may be undertaken using `R` programming, or performed in an `R` environment with the aid of available `R` packages – where `R` functions and data sets are stored.

##### 4.1.1.1 Coding

The simplified flowchart shows how raw data are transformed into information:

Data → Collection → Processing → Information

Data processing takes place once all of the relevant data have been collected. They are gathered from various sources and entered into a computer where they can be processed to produce information – the output.

Data processing includes the following steps:

- Data coding
- Data capture
- Editing
- Imputation
- Quality control
- Producing results

**Data Coding** First, before raw data can be entered into a computer, they must be coded. To do this, survey responses must be labeled, usually with simple, numerical codes. This may be done by the interviewer in the field or by an office employee. The data coding step is important because it makes data entry and data processing easier.

Surveys have two types of questions – closed questions and open questions. The responses to these questions affect the type of coding performed.

A closed question means that only a fixed number of predetermined survey responses are permitted. These responses will have already been coded.

The following question, in a survey on sporting activities, is an example of a closed question:

To what degree is sport important in providing you with the following benefits?

- 1) Very important
- 2) Somewhat important
- 3) Not important

An open question implies that any response is allowed, making subsequent coding more difficult. In order to code an open question, the processor must sample a number of responses, and then design a code structure that includes all possible answers.

What sports do you participate in?
