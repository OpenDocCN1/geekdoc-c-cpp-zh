For these values of the investment portfolio position, $(x_A^{\min}, x_B^{\min})$, the corresponding values of the expected return $\mu_p$, variance $\text{var}(R_p)$, and standard deviation $\sigma_p$ may be calculated from the following relationships:

$\mu_p = E[R_p] = x_A \mu_A + x_B \mu_B \tag{3.24}$

$\sigma_p^2 = \text{var}(R_p) = x_A^2 \sigma_A^2 + x_B^2 \sigma_B^2 + 2 x_A x_B \sigma_{AB} \tag{3.25}$

$\sigma_p = \text{SD}(R_p) = \sqrt{\text{var}(R_p)} = \sqrt{(x_A^2 \sigma_A^2 + x_B^2 \sigma_B^2 + 2 x_A x_B \sigma_{AB})} \tag{3.26}$

Hence,

$\mu_p = E[R_p] = x_A^{\min} \mu_A + x_B^{\min} \mu_B$
= $(0.2041)(0.2) + (0.7959)(0.04)$
= $0.04082 + 0.03184$
= $0.07266$

$\sigma_p^2 = \text{var}(R_p) = (x_A^{\min})^2 \sigma_A^2 + (x_B^{\min})^2 \sigma_B^2 + 2 (x_A^{\min})(x_B^{\min}) \sigma_{AB}$
= $(0.2041)^2(0.05) + (0.7959)^2(0.01)$
+ $2(0.2041)(0.7959)(-0.0038)$
= $0.00208 + 0.00633 - 0.00123$
= $0.00718$

$\sigma_p = \text{SD}(R_p) = \sqrt{\text{var}(R_p)}$
= $\sqrt{(0.00718)}$
= $0.08473$

# 3.2.4.2 Effects of Portfolio Variance on Investment Possibilities

For a portfolio of any two assets, A and B, the correlation between A and B may strongly affect the investment possibilities of the portfolio. Thus,
