To create good-looking, functional, and successful websites, you have to understand a number of important technologies and languages, including HyperText Markup (HTML), ASP.NET, cascading style sheets (CSS), a server-side programming language as C# or VB, and a client-side language as JavaScript. This and upcoming technologies provide a solid foundation in these technologies, so you should be comfortable with the most important concepts once you have finished this book.

Besides these technologies, you also have to understand the Visual Studio IDE that was introduced in the previous chapter. You need to know how to create sites, add pages, and manage all the toolbars and windows that Visual Studio (VS) offers. In addition, you need to know how to build and design web pages in VS with HTML and server controls.
