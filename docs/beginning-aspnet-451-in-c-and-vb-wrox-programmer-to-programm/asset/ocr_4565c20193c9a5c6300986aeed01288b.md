As you can see in Figure 12-1, each review is assigned to a musical genre such as Pop, Indie Rock, or Techno. But what if you wanted to rename the genre to something like Hardcore Techno? You would need to update all the rows that have this genre assigned. If you had others stored a genre, you would need to visit those tables as well and make the changes manually.

A better solution would be to use a separate table and call it Genre, for example. This table could store the name of a genre and an ID (a sequential number, for example) that uniquely identifies each genre. The Review table then has a relationship to the Genre table and the Genre table also has a SortOrder column, which is used in later examples.

# DIFFERENT KIN OF RELATIONAL DATABASES

You can use many different kinds of databases in your ASP.NET projects, including Microsoft Access, SQL Server, SQLite, Oracle, and MySQL. The most commonly used database in ASP.NET websites is Microsoft SQL Server. This book focuses on using the Microsoft SQL Server 2012 Express LocalDB engine which is free, comes bundled with VS 2012 and has a lot to offer out of the box. Also, because the database format is identical to that of the commercial versions of SQL Server. 2012, it is easy to upgrade to versions at a later stage in the development cycle. This upgrade path is described in detail in Appendix B.

The only problem with LocalDB is you can't use all of the database management tools from Visual Studio. You can create tables and other database objects, but you can't visually new queries and diagrams, two features that you'll use regularly when working with databases in your ASP.NET projects.

To overcome this limitation, you should download and install SQL Server Management Studio (SSMS) Express, the free tools to manage all your SQL Server databases, including LocalDB, and the commercial versions of SQL Server (although in the latter case you probably want to use the more rich version of the tools that ship with the main product).

In the next sections you will see how to acquire and install SQL Server Management Studio Express. The sections that follow show you how to use it to manage your databases and the data they contain.
