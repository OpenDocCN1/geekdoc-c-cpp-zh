# How It Works

Although short, this exercise demonstrates a powerful way to hook into the different events of a control and change the presentation of the underlying control. To see how it works, take a look at the modified SQL code first:

```
SELECT
Genre.Id, Genre.Name, Genre.SortOrder, COUNT(Review.Id) As NumberOfReviews
FROM
Genre LEFT OUTER JOIN
Review ON Genre.Id = Review.GenreId
GROUP BY
Genre.Id, Genre.Name, Genre.SortOrder
```

This modified SQL statement gets all the columns from the Genre table but introduces a new column, NumberReviews, which contains the number of reviews associated with each genre. You do this by executing the SQL COUNT function against the Id column of the Review table. The statement uses GROUP BY group the selected rows into a set of summary rows by collapsing non-unique rows. Because the SQL statement is grouped by all unique columns in the Genre table, you get a unique row including the number of reviews for each genre, whether or not reviews associated, as shown in Figure 15-9, which displays the result of your query in SSMS.
