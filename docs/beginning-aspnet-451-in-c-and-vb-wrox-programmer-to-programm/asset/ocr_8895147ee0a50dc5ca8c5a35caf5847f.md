This placeholder is added for automatically to each new master page you create. You can use it in content pages to add page-specific content between the <head> tags of page, as CSS (both embedded and external style sheets) and JavaScript. You learn more about JavaScript in Chapters 10 and 11. You need to add content to this placeholder in Markup View, because it's not visible in Design View.

The ContentPlaceholder holds cpMainContent in the master page currently does not contain any markup itself. However, it doesn't have to be like this. You can add your own content that will serve as the default in your content pages as long as it is overridden by the content page. For example, you can have the following ContentPlaceholder in a master page:

```
<asp:ContentPlaceholder Id="cpMainContent" runat="server">
This is default text that shows up in content pages that don't
explicitly override it.
</asp:ContentPlaceholder>
```

When you make a new page on this master page, you won't see this default first in Markup View. However, you open the Content control's Tasks panel, shown in Figure 6-6, and choose Default to Master's Content.

When you click Yes when asked you want to default to the master page content, SV removes the entire Content control from the Markup View of the page. However, when you request the page in the browser you will still see the default content from the master page. In Design View, the content is still visible, now presented as a read-only area on the design surface. A master page with default content can be useful if you add a new ContentPlaceholder to the master page at a later stage. Existing pages can simply display the default content, without the need for you to touch all pages. New pages define their own content. If you don't have content in the ContentPlaceholder control in the master page and the content page doesn't have a Content control for the ContentPlaceholder, no output is sent to the browser.

Once you have defaulted to the master page's content, you can create custom content again by opening the Tasks panel and choosing Custom Content. This copies the default contents into a new Content control that you can then modify.
