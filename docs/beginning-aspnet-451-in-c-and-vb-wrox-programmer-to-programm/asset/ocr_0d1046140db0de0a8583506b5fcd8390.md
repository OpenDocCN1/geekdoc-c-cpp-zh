# INTRODUCTION

To put emphasis on a block of code surrounded by other code, I use a bolded font like this:

```
<appSettings>
  &lt;add key="FromAddress" value="planetwrox@example.com"/&gt;
&lt;/appSettings>
```

The surrounding code is used to make it easier to see where the bolded code should be placed.

+   Often when, white space in code is irrelevant, it is mostly the case with ASP.NET markup and HTML. To fit code within the boundaries of this code, I wrap code over multiple lines and indent the part that should have been on the previous line like:

```
Dim result as String =
nWebConfigurationManager.AppSettings.Get("FromAddress")
```

If you're typing this code yourself, you can put it all on one line, or use the same line breaks if you prefer. The sample code comes with this book has the code typically on a single line.

+   Text that appears on-screen often has Each Word With A Capital Letter, even though the original screen text uses a different capitalization. It is done to make the screen stand out from the rest of the text.
