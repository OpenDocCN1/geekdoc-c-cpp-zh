## 面向对象基础

一篇关于 ASP.NET 编写的文章如果没有面向对象（OO）部分就不算完整。面向对象，或面向对象编程，是一种非常流行的编程风格，其中软件被建模为一组相互交互的对象。面向对象是 .NET Framework 的核心。框架内部的 literally 一切都是对象，从简单事物到像 DropDownList、数据库连接或数据驱动控件这样复杂的事物。

由于面向对象是 .NET 的一个重要方面，因此熟悉面向对象编程的一般概念非常重要。与此同时，你不必是 OO 专家也能用 ASP.NET 构建网站。这为你提供了最重要的术语和概念的 10,000 英尺概览。这有助于你在下一章开始构建实用应用程序，而不是在接下来的三周里把鼻子埋在书里。

### 重要的 OO 术语

在面向对象中，一切都围绕对象的概念展开。在 OO 中，一切事实上都是对象。但对象到底是什么？我们又要如何处理类？

### 对象

对象是面向对象编程语言的基本构建块。就像在现实世界中一样，OO 世界中的对象是存储在计算机内存中的事物。它可以是一个保存某人年龄的整数，也可以是一个连接到世界另一端 SQL Server 的开放数据库连接，但它也可以更概念化，比如一个网页。在你的应用程序中，你使用 New（C# 中的 new）关键字创建一个新对象，就像在计算器示例中看到的那样。创建新对象的过程称为实例化，而你创建的对象称为实例。你可以实例化对象或自定义类型，如 Calculator，也可以实例化简单类型，如 Integers 和 Strings：

### VB.NET

Dim myCalculator As Calculator = New Calculator ()

Dim age As Integer = New Integer ()

### C#

```
Calculator myCalculator = new Calculator ();
```

```
int age = new int();
```

由于经常创建 Integer（C# 中的 int）和 String（C# 中的 string）等简单类型的变量，编译器允许你省略 new 关键字和赋值。因此，以下代码在功能上等同于前面的 age 声明：

### VB.NET

Dim age As Integer

### C#

```
int age;
```

本章开头列出的所有数据类型，除了 System.Object，都可以在不使用 New 关键字的情况下创建。

一旦你创建了对象的实例，例如 myCalculator 对象，它就可以使用了。例如，你可以访问其方法和属性来对对象执行有用的操作。但在查看方法和属性之前，你需要先理解类。

### 类

类是对象的蓝图。就像你可以用单一蓝图建造许多相似的房子一样，你可以用单一类创建该类的多个实例。类充当你在应用程序中使用的对象的定义。最基本的形式，类看起来像这样：

### VB.NET

```
Public Class ClassName

End Class
```

### C#

```
public class ClassName
{}
```

由于这段代码只是定义了一个空类，因此它不能做任何有用的事情。为了给类一些行为，你可以为其添加字段、属性、方法、构造函数。此外，你还可以让类继承自现有类，从而在功能和行为方面获得先机。你将在接下来的几个部分中了解这些术语。

### 字段

字段是在类级别声明的简单变量，可以包含数据。它们通常用作属性的 backing 变量（正如你在下一节中看到的那样），但不一定如此。以下是 Person 类中字段的快速示例：

```
VB.NET
Public Class Person
    Private _firstName As String
End Class

C#
public class Person
{
    private string _firstName;
}
```

字段通常标记为 Private（C# 中的 private），这使得它们仅在定义它们的类中可见。如果你需要将字段暴露给其他类，也可以改用属性，下一节将讨论属性。稍后在本章中你将了解更多关于 Private 关键字和其他访问修饰符的信息。

### 属性

对象的属性是对象所具有的特征。考虑一个 Person 对象。Person 有什么属性？很容易想出许多不同的特征，但最常见的是：

- First name
- Last name
- Date of birth

你可以在类中使用 Property 关键字（在 VB.NET 中）或使用类似于方法的属性头（在 C# 中）来定义属性。在两种语言中，你都使用 Get 块（C# 中的 get）和 Set 块（C# 中的 set）来定义所谓的 getter 和 setter。getter 在对象被要求提供特定属性的值时被访问，而 setter 用于为属性分配值。属性只提供对存储在对象中的数据的访问；它们不包含实际数据。为了存储数据，你通常使用所谓的 backing variable。这通常是在类中定义的简单字段，能够为外部属性存储值。在以下示例中，变量 _firstName 是 Firstname 属性的 backing variable：

```
VB.NET
Public Class Person
    Private _firstName As String
    Public Property FirstName()
    Get
        Return _firstName
    End Get
    Set(value As String)
        _firstName = value
    End Set
End Property
End Class

C#
public class Person
{
    private string _firstName;
    public string FirstName
    {
        get { return _firstName; }
        set { _firstName = value; }
    }
}
```

通常，私有 backing variable 以下划线为前缀，后跟第一个单词全部小写，可选后跟首字母大写的单词。因此，FirstName 属性的 backing variable 称为 _firstName，LastName 的称为 _lastName，以此类推。这样，所有适用于整个类的变量都会在 IntelliSense 列表中整齐地排列在一起。只需输入一个下划线，你就会得到所有私有变量的完整列表。注意，在函数或子程序内部定义变量时，通常不使用下划线。

就像你之前看到的关键字一样，Private 也是一个访问修饰符。你将在本章后面了解更多关于访问修饰符的信息。

类中属性的主要原因是封装数据。其思想是属性使你能够控制被分配的数据。这样，你就可以在数据存储到底层 backing variable 之前对其进行验证或操作。假设你的应用程序的一项业务规则规定所有姓名必须以大写字母开头。在非面向对象的语言中，设置姓名的开发者每次用名字填充变量时都必须记住此规则。在 OO 方法中，你可以让 FirstName 属性负责此事，这样其他人就不必担心任何人。你可以在属性的 setter 中执行这种类型的数据操作：

```
VB.NET
Set(value As String)
If Not String.IsNullOrEmpty(value) Then
    _firstName = value.Substring(0, 1).ToUpper() & value.Substring(1)
Else
    _firstName = String.Empty
End If
```

```
C#
set
{
    if (!String.IsNullOrEmpty(value))
    {
        _firstName = value.Substring(0, 1).ToUpper() + value.Substring(1);
    }
}
```
