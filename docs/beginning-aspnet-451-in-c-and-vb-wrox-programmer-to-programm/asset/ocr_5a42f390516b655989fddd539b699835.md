```
<asp:RoleGroup>
<asp:RoleGroup Roles="WebMasters">
  <ContentTemplate>
    <!--Content for WebMasters here--
  </ContentTemplate>
</asp:RoleGroup>
</asp:RoleGroups>
</asp:LoginView>
```

With this, the user Alex only sees the content of the first RoleGroup, even though he is also assigned to the WebMasters role.

# Programmatically Checking Roles

Although it's easy to use the LoginView control to change the content a user is allowed to see at run time, it's not always enough. At times, you need programmatic control over the data you are presenting based on someone's role membership. You can access information about roles for the current user in many ways. First of all, you can access the IsInRole method of the User property from the current page or user control like this:

```
VB.NET
If User.IsInRole("Managers") Then
  ' This code runs for Managers only
End If
```

Alternatively, you can access the Roles class that contains a lot of static methods that you can access directly. The following code is functionally equivalent to the previous example:

```
VB.NET
If Roles.IsInRole("Managers") Then
  ' This code runs for Managers only
End If
```

In addition to the IsInRole method, the Roles class contains a lot of other methods that enable you to work with roles programmatically. For example, you can create and delete roles, assign users to and remove them from roles, and you can get a list of users that are assigned to a certain role.
