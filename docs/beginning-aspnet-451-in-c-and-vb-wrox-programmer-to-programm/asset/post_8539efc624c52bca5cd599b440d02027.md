## TRY IT OUT Installing Visual Studio Express 2013 for Web

This Try It Out Exercise guides you through installing VSEW on your computer. It assumes you're using the web installer, although the process for installing the Express from a DVD is almost identical. The steps you need to perform to install the full version of Visual Studio 2013 are similar as well, although the screens will be somewhat different.

- 1. Start by browsing to www.microsoft.com/express/ and follow the instructions to download VSEW 2013. You can install directly by choosing the Download and then the Install Now link or by downloading an ISO file that you can burn on a DVD or mount on Windows as a virtual drive. Make sure you download Visual Studio 2013 and not one of the other free editions or older versions. This link is ever changed or no longer provides direct access to the VSEW download, search the web for “Install Visual Studio Express 2013 for Web” and you'll be taken to a download page where you can start the installation.
- 2. After the download completes, start the installer. You should see a screen similar to Figure 1-1. Check the checkbox for the license terms and privacy policy. If you're installing the full version of Visual Studio, click the Next button that appeared when you agreed to the license terms. You will see a screen similar to Figure 1-2. Make sure you select at least the Microsoft Web Developer Tools.
- 3. In both cases, click the Install button to start the installation process.
- 4. After a while you will see a message indicating that Visual Studio has been successfully installed. The installer may need to reboot your machine during or after the installation. Once the installer has finished, Visual Studio is ready for use.

The website you created in this Try Out is quite simple, the process that eventually results in the page Default.aspx displayed in your browser is not so simple. By itself, an ASP.NET page (also referred to as an ASPX page of its extension, or a Web Form) can not do much. It needs to be processed and served by a web server before your browser can display it. That is why VS automatically started IIS Express to handle the request for your page.

The resulting HTML causes the browser to display the current date and time. HTML, or HyperText Markup Language, the language that browsers use to display a web page. You learn how HTML looks and how to use it later in this chapter.
