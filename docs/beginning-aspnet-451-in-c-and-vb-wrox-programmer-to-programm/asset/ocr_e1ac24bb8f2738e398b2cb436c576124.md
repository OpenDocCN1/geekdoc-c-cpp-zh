# How It Works

You haven't changed much in the actual process of inserting the Picture into the database. The ListView control collects all the relevant data from the page and calls the InsertMethod, which then inserts the item in the Picture table in the database EF. What is different from the way you set up the templates and the code that inserts the picture. First Inside the ItemTemplate you added an <asp:Image> to place the plain text label. You can see in Figure 14-14, this displays the image, rather than its URL.

To enable a user to upload the images, you replaced the TextBox control in the InsertTemplate with a FileUpload control. Additionally, you added a few validation controls to force the user to enter the required fields. As soon as you click the button, the page posts back and the ListView calls the InsertMethod. Inside this method you added some code that “finds” the upload control in the InsertItem template. Because you can have multiple controls with the same name (for example, a FileUpload control in the InsertTemplate and one in the EditItemTemplate), you cannot access FileUpload directly. Instead, you need to use FindControl on the Insert object to search for the control:

# VB.NET

```
Dim FileUpload1 As FileUpload =
CType(ListView.InsertItem.FindControl("FileUpload1"), FileUpload)
```

# C#

```
FileUpload FileUpload =
(FileUpload)ListView.InsertItem.FindControl("FileUpload1");
```

When you have a reference to the FileUpload control, you can check its HasFile property to see if a file has been uploaded. Additionally you can check FileUpload1.FileName.EndsWith(".jpg") to see if a file has a .jpg extension. To ensure that this test is carried out when the user has uploaded a file, use Or Else in VB and || to short-circuit the logic in the If statement, as explained in Chapter 5.

If the user doesn't upload a file, the code in the If blocks runs. You use FindControl to find the CustomValidator control and set its IsValid property to False (false in C#). This calls the control to display its ErrorMessage property when the page renders. It also adds an error to the ModelState using ErrorDetail. This is needed to tell the ModelBinder that validation failed, which in turn tells the ListView to stay in Insert mode and display the data that the user already added along with the error message

The other validation controls make to sure that a title and description are encoded in the same way as what you saw in Chapter 9.
