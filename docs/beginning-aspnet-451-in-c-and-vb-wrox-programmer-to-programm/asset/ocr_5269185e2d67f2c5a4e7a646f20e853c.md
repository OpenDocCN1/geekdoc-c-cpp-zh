+   6. The next step is to implement the SelectMethod, which is called when the ListView needs to display data. Because the photo album page displays pictures only for the current photo album (identified by the PhotoAlbum query string), you need to find a way to filter the correct pictures from the database using a LINQ query. Fortunately, you can use ASP.NET binding to find and retrieve the ID of the photo album and make it available in the ListView_GetData method. You can use that ID in the Where clause of a LINQ query. To implement this functionality, modify that method as follows. Note that you need to add a/import statement for the namespace System.Web.ModelBinding to bring the QueryString attribute into scope. You can either type this name manually at the top of the code file, or press Ctrl+(Ctrl+dot) in the method definition and pick the name from the list that appears.

# VB.NET

```
Public Function ListListView_GetData(QueryString("PhotoAlbumId")
   photoAlbumId As Integer) As IQueryable
   Dim myEntities As New PlanetWroxEntities()
   Return From p in myEntities
      Where p.PhotoAlbumId = photoAlbumId
      Select p
End Function
```

# C#

```
public IQueryable ListListView_GetData([QueryString("PhotoAlbumId") int photoAlbumId)
{
   var myEntities = new PlanetWroxEntities();
   return p in myEntities.Pictures
      where p.PhotoAlbumId == photoAlbumId
      select p;
}
```

The QueryString attribute applied to the photoAlbumId parameter of the GetData method. attribute signals the ASP.NET run to populate that parameter with the value from the associated PhotoAlbumId query string parameter.
