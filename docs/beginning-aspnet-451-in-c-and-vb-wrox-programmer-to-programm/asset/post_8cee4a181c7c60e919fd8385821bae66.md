## How It Works

In step 4 of this exercise you set the Visible property of the Panel control to False. This means that when the page loads, the control is not visible on the server and thus its HTML never makes it to the browser. When you then check the check box, a postback occurs, which sends the information contained in the form to the server. At server, some code is run that is fired whenever the check box changes its state from checked to unchecked or vice versa. Inside that code block, the following code is executed (shown in C#):

```
Panel.Visible = CheckBox1.Checked;
```

This means that the Panel is only visible when the check box is checked. When it isn't, the Panel is hidden automatically.

As you can see, it's easy to add text and other markup to the Panel control in VS. Right now, you only added some plaintext, but in the next section you see how to add a wizard control and how to use it.

## Magic with the Wizard Control

The wizard control is a great tool for breaking apart large Web Forms and presenting them as bite-sized chunks of information. Instead of confusing your user with one page with many controls on it, you can break the page apart and present each section on a separate page. The wizard control then handles navigation issues by creating Next, Previous, and Finish buttons automatically. In this exercise you use a wizard to create a user for her and favorite programming language. Although the example itself is trivial, and you could have placed both questions on the same page without confusing the user, the example shows how the wizard works and why it's useful. You can easily apply the same techniques to your own, possibly larger, Web Forms.
