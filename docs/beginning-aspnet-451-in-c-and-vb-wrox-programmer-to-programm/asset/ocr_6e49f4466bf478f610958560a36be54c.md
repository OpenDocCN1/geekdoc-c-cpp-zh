# WORKING WITH FILES IN YOUR WEBSITE

An ASP.NET Web Forms consists of at least a single Web Form (a file with .aspx extension), but usually consists of a larger number of files. Many different file types are available in VS, offering a different functionality. In the next section, you will see the most important file types that are used in VS. In addition, you learn a few ways to add these files to your site.
