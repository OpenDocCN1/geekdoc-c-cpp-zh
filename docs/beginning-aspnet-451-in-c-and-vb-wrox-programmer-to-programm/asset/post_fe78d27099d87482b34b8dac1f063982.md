
2. From the Styles folder, move the Styles folder. You can either drag it into the new folder or use Ctrl+X to cut the file, click the Monochrome folder, and press Ctrl+V to paste it again. You can leave the empty Styles folder because it's used again later.

3. To make it clearer when your CSS is coming, rename the file from Styles.css to Monochrome.css. You can rename it by selecting and pressing F2 or by right-clicking it and choosing Rename.

4. Because the main layout is now going to be controlled by the theme, you no longer need the <link> element in the <head> section of the master page over the old CSS, so you can remove it. To this end, open the master page, switch to Markup View, and remove the following highlighted line from the code:

```html
<head runat="server">
<title></title>
<asp:ContentPlaceHolder id="head" runat="server">
</asp:ContentPlaceHolder>
<link href="../Styles.css" rel="stylesheet" type="text/css" />
```

5. The next step is to apply the theme to the web environment. Open the web file from the site and edit directly inside the <system.web>element, create a <pages> element with a theme attribute pointing to the Monochrome theme. There's no support for themes in IntelliSense with the web.config file you need to type the name yourself.

```xml
<system.web>
<pages theme="Monochrome" />
```

6. To test the theme, save all your changes and then request the Default.aspx in your browser. The design of the site should be identical to how.

> **COMMON MISTAKES**: If you get an error about an invalid page title, go back to Visual Studio and change the Title attribute of the @ Default.aspx to "Welcome to Planet Wrox." If your design doesn't look as it should, press Ctrl+F5 or Ctrl+R in the browser. This forces a hard refresh, which means you get the latest version of the files instead of a cached copy of the page.

Instead of linking the CSS file from the master page, the CSS is now included in the page source through the theme set in the Web.config file. To see how this works, open the HTML source of the page in the browser. At the top you will see the following code (I altered the layout for better readability):

```html
<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml">
<head>
<title>Welcome to Planet Wrox</title>
<script src="Scripts/modernizr-2.7.1.js"></script>
<link href="App.Themes/Monochrome/Monochrome.css" type="css" rel="stylesheet" />
</head>
<body>
```

Note that a link to the style sheet from the Monochrome folder is injected in the <head> of the page. ASP.NET run does this for every CSS file it includes in the currently active folder (in alphabetical order), so be sure to keep your theme folder to avoid unnecessary files from being included and downloaded by the browser. Also notice how the <link> is added just right after the <head-tag. This ensures that the file is included after all other files you have added (through the master page, for example). This is in contrast to how the StyleSheet attribute. This type of theme allows its settings to be overridden, it's imported from the top of the file, giving room for other CSS files it follows to change the look and feel of the page.

7. Return to Visual Studio and open the master page in Design View. Notice how all the design is gone and now follows the layout of the page. Unfortunately, VS does not display the theme you've using the theme attribute. However, you can overcome this by setting the StyleSheetTheme attribute. To do this, open the Web.config file, locate the <pages> element you created earlier, and add the following attribute:

```xml
<pages theme="Monochrome" StyleSheetTheme="Monochrome" />
```

8. Save the changes to Web.config, reopen the master page, and switch to Design View. You'll see that VS now applies the correct information to your pages.

9. To add another theme to the site, create a new folder under App_Themes and call it DarkGrey. Now, open the folder where you extracted the downloaded code that comes with this book. If you followed the instructions in this book, your folder is located at C:\ASPNET\Resources. If you don't have these files, they are available at www.wrox.com/go/aspnet-451. Open the chapter 06 and the theme folder, and drag the DarkGrey folder from File Explorer into the DarkGrey theme folder in VS. If dragging doesn't work for you, then use Ctrl+C in File Explorer to copy the file, and then use Ctrl+V in VS to paste the file in your project.
