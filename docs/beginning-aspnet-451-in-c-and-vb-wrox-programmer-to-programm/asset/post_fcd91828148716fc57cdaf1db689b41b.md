# ASP.NET Page Life Cycle and Events in Data Controls

As discussed, the GridView raises RowCreated and RowDataBound events for each row it adds to its output. These events are ideal to peek into the data and then, based on that data, take appropriate action. For example, you can use these events to verify whether a review is displayed authorized. If it's not (meaning it's not in the front-end view), you can change the review's appearance to draw attention to it. Another example of using events would be to hide or disable the controls in the interface when it doesn't make sense for them to be visible or active. You will see how to delete the link in the GridView in the next exercise.

> TRY OUT Hook into RowDataBound

In this Try Out you write an event handler for the RowDataBound event of the Genres page of the Management section. Protected Sub GridView1_RowDataBound(sender As Object, e As GridViewRowEventArgs) Handles GridView1.RowDataBound
```VB.NET
Select Case e.Row.RowType
 Case DataControl.RowType.Data:
 Dim myRow As DataView = CType(e.Row.DataItem, DataView)
 If Convert.ToInt32(myRow("NumberOfReviews")) > 0 Then
 Dim deletelink As LinkButton =
 TryCast(e.Row.FindControl("DeleteLink"), LinkButton)
 If deletelink Is Not Nothing Then
 deletelink.Enabled = False
 End If
 End If
End Select
```

```csharp
protected void GridView1_RowDataBound(object sender, GridViewRowEventArgs e)
{
    case DataControl.RowType.Data:
        DataView myDataView = (DataView)e.Row.DataItem;
        if (Convert.ToInt32(myDataView["NumberOfReviews"]) > 0)
        {
            LinkButton deleteLink = e.Row.FindControl("DeleteLink") as LinkButton;
            if (deleteLink != null)
            {
                deleteLink.Enabled = false;
            }
        }
        break;
}
```
