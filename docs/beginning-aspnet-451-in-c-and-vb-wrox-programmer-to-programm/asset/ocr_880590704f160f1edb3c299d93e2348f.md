# Creating Master Pages

You can add master pages to the site using the Add New Item item dialog box. You can place them in any custom folder in the site, including the root folder, but from an organizational point of view, it's easier to store them in a separate folder. Just like normal ASPX pages, they support the inline code model as well as the Code Behind model. The master pages used in the Planet Wrox project use the Code Behind model exclusively. In the following exercise, you learn how to create a simple master page and add some HTML to it to define the general structure of the pages in your website.
