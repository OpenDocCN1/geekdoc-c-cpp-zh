# TRY OUT Using Basic Selectors

In this exercise, you first add an additional ContentPlaceHolder control to the main master page so it's easier to add client-side jQuery code to your pages. You then write some jQuery to try out the various selectors.

- 1. Open up the Frontend master file from the MasterPages and make it in Markup View.
- 2. Next to the bottom of the page, right before the `</form>` tag, drag a ContentPlaceHolder from the Toolbox. Set its ID to cpClientScript. Your code should end up like this:
```html
<footer>Go Here</footer>
<div>
<asp:ContentPlaceHolder Id="cpClientScript" runat="server">
</asp:ContentPlaceHolder>
</div>
```
- 3. Save and close the master page because you're done with it now.
- 4. Create a new demo page called BasicSelectors.aspx in the demos folder. Once again, base it on your template and give it a meaningful title. Switch to Design View, locate the cpClientScript placeholder at the bottom, open your Smart Tasks, and choose Custom Content. You need to do this in Design View your custom template does not contain this code. If you want to include the code for the cpMainContent in the Markup for new pages based on your custom template, you need to re-create the template by following the steps described in Chapter 6.
- 5. Switch to Markup View and add the following HTML to the cpMainContent placeholder (don't accidentally add it to the placeholder you just added):
```html
<h1>BasicSelectors</h1>
<div class="SampleClass">I am a div.</div>
```
- 6. Add the following jQuery code demonstrating all six basic selectors to the cpClientScript placeholder you created in step 4:
```html
<asp:Content ID="Content" runat="server" ContentPlaceHolderID="cpClientScript">
<script>
$(function () {
  $('*').css('color', 'Green'); // Universal
  $('#sidebar').css('border-bottom', '2px solid red'); // ID
  $('h1').bind('click', function () { alert('Hello World'); }); // Element
  $('.SampleClass').addClass('PleaseWait').hide(5000); // Class
  $('footer, header').slideUp('slow').slideDown('slow'); // Grouped
  $('#sidebar img').fadeTo(5000, 0.1); // Combined
});
</script>
</asp:Content>
```

- 7. Save all files, refresh the request in the page. All text is now green, the sidebar has an extra border, you see the Wait animated icon and text then disappear, the header and footer disappear and then reappear, and finally, during a five-second period, the banner in the sidebar becomes almost transparent. If you click the Basic Selectors heading you get a pop-up saying Hello World.

# How It Works

Pew, lots of animation! I typically recommend adding all these features to your pages at once or you'll be sure away most of your users. However, for this demo it works really well you can see some of the six selectors, but the code that is being executed against their matched sets is probably new to you.

The first selector selects all elements in your page and then applies the css method to turn their color to green. The ID selector then gets a single element and calls the same css method to apply a border. The third example uses the Element selector to find the h1 element and then dynamically binds a click handler so that when you are clicking, the code between the curly braces is executed.

The selector demonstrates the Class selector and shows you how to find elements by their class name. Notice that the class being searched doesn't have to be an existing CSS class defined in your style sheet. Once the elements are found, the addClass method then adds a new class to them, PleaseWait in this example, applies the spinner as the background to the div element. The hide method then hides the elements during a five-second time frame.

The Group selector finds both the footer and the header. The slideUp method then decreases the height of these elements until they have completely disappeared. In doing so, it resets the initial size, so call slideDown again it knows how to restore the elements.

The final example uses Combined selector to find the banner in the right-hand sidebar. Once it has found the image, it dissolves it (in five seconds) by its opacity to 0 percent so it gets almost invisible.

In a later section of this chapter you will see more of the various styling and animation methods that jQuery offers. For now, it's important that you understand the selector syntax to refer to the elements in your page. Quite simply selecting items in your page is not enough. For instance, when you want to select all at once but only odd or even rows, you can apply a "zebra stripe" effect to the table where odd and even rows have different colors. That's where filters come into play.

# Basic Filters

In jQuery you can use filters to filter the result set. opens a lot of possibilities because it enables you to get elements first, last, all even or odd ones, all headings, or a specific location. # How It Works

In this exercise you created a simple Content block that can hold your jQuery code. You then defined a code block that fires as soon as the browser is done loading the DOM. Inside this block you wrote a simple selector that selects the table with an id of DemoTable and used jQuery's css method to change its background color.

In the following table you see a list of jQuery's basic filters. Remember, you can try out each by replacing the // Examples here line with the code examples. Then save the page and load it in your browser to see the code at work.

| FILTER | PURPOSE |
| :--- | :--- |
| :first | Enables you to select the first or last item in a matched set. The following example changes the background color of the first or last row of the table to red:<br> ```css\n$('#DemoTable tr:first').css('background-color', 'red');\n$('#DemoTable tr:last').css('background-color');\n``` The first row is found using #DemoTable. Then all rows are found tr. The first or last row is found using :first and :last filters. |
| :odd | Enables you to select the odd or even items in a matched set. Following example changes the background color of the odd rows to red. Because the numbering is zero-based, you actually see the second and fourth rows change color (because they have an index of 1 and 3, respectively):<br> ```css\n$('#DemoTable tr:odd').css('background-color', 'red');\n``` | |
| :even | | |
| :eq(index) | Matches items by index. :eq (equals) returns a single element by index, and :lt (less than) and :gt (greater) return items smaller or greater than the given index, Examples:<br> ```css\n// Changes the color in the first row (with an index of 0)\n$('#DemoTable tr:eq(0)').css('color', 'green');\n\n// Only the last two rows.\n// with an index of 0, 1 and 2 respectively, are skipped.\n$('#DemoTable tr:gt(2)').css('color', 'green');\n\n// Changes the text color of the first two rows to green.\n$('#DemoTable tr:lt(2)').css('color', 'green');\n``` | |
| :lt(index) | | |
| :gt(index) | | |
| :header | Finds all headers (from h1 to h6) in the page. Example:<br> ```css\n(':header').css('color', 'green');\n``` | |

For a complete list of all basic filters, check out the jQuery documentation at http://api.jquery.com/category/selectors/.
