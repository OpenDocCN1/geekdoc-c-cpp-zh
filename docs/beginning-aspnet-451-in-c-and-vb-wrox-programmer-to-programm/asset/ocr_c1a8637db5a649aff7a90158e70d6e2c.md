# TRY IT OUT Using the Page Inspector to Diagnose your Site

In this exercise, you load a few pages into the Page Inspector and diagnose the underlying HTML. You see how to use the Inspect feature to find the originating source files and how to make changes to the code and refresh the Page Inspector. This should prepare you for cases you need to hunt for a bug in your site.

+   1. If you're in debug mode from the previous exercise, press Shift+F5 to stop debugging. Then close all open files and choose Page Inspector from the Target Browser drop-down on the Standard toolbar, shown in Figure 18-23.
2. Press F5 or click the green arrow to the Target Browser drop-down, in Figure 18-23. If you enabled debugger early, the Page Inspector should start without further messages. If you haven't enabled debugger, follow the on-screen instructions to properly configure your site. After a few seconds, the Page Inspector is loaded in the Document Windows in VS.
