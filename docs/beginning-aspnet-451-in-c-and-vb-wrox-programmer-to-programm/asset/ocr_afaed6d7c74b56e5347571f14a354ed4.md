In addition to View State, controls support the concept of Control State. Controls use a mechanism to keep track of data they absolutely need to operate correctly. You cannot disable Control State but, since only limited amounts of data are stored in Control State, this is not a problem.

# A note about View State and Performance

Because the View State engine adds a considerable amount of information to the page, it's often a good idea to turn off when you don't need it. This way, you can minimize the size of the hidden _VIEWSTATE field, which means the page smaller and loads faster in the browser. Note that when you turn off View State you see the hidden _VIEWSTATE field because Control uses the same field to store its data. Turning off View State is easy, and you can do it at three different places:

+   * At the web level — You can do this in the Web.config file in the root of the site by modifying (or adding) the <pages> element under <system.web>, setting the EnableViewState attribute to:
```xml
<pages enableViewState="false">
</pages>
```

+   * At the page level — At the top of each page you find the page directive, a series of instructions that you can set EnableViewState to False:
```vb
<@ Page Language="VB" AutoEventWire="False" CodeFile="State.aspx.vb"
Inherits="Demos_ State" EnableViewState="False" %>
```

This is useful for pages where you don't need View State all.

+   * At the control level — Each ASP.NET Server Control enables you to set EnableViewState individually, giving you the option to turn it off for controls, leaving it for others.

Once you've turned off View State at a higher level (the page or control level), setting EnableViewState to True at a lower level has no effect. However, using the ModelState property you can accomplish this as follows:

+   * Do not turn off View State in the Web.config file.
* At the page level, set EnableViewState to True and ViewState to Disabled like this:
```vb
<@ Page Language="C#" EnableViewState="True" ViewMode="Disabled" %>
```
This turns off View State for all controls in the page except for those that explicitly enable it by setting the ViewMode to Enabled.
