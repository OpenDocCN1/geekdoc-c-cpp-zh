# CHAPTER 19 DEPLOYING YOUR WEBSITE

However, in the real world when you need to move your site to an external server or host, things are not so easy. Although copying the files that make up your site is usually extremely simple using an FTP program, copying data from your SQL Server database to your host is often a bit trickier. This is because most hosts don't support the free Express or LocalDB instances, you can't just copy the .mdf file from your App_Data folder at home. Instead, these hosts often offer the full version of SQL Server, which you can access with a web-based management tool or with tools such as SQL Server Management Studio.

Getting your database from your local machine to your remote host is typically a two-step process:

+   1. Create a .sql script from your local SQL Server database.
2. Send this script to your host and execute it.

In the next section, you will see how to export your database to a .sql file. I won't show you how to re-create that file at your host because this is different from host to host. Instead, I will give you some general pointers so you know how to look for your host.

# Exporting Your Data to a File

To make it easy to transfer data from your local SQL Server into a SQL Server database of your web host, SQL Server Management Studio comes with a tool to export your database structure and data to a file. This file contains all information required to re-create your database and data at a remote server.

In the following exercise, you will see how to use SSMS to export your database to a file.

# TRY OUT Exporting the Planet Wrox Database

This exercise assumes you've already downloaded and installed SQL Server Management Studio Express. If you haven't already done this, refer to the start of Chapter 12 for more details.
