To show you how to work with complex data at the client, this code example returns two hardcoded Review instances. In later chapters you will see how to work with reviews in a database so you could make this example truly dynamic. For now, it serves the purpose of showing the reviews at the client.

The code sets up a generic collection of Review instances. For now, a Review is a simple class with two properties: an id and a Title. The collection is filled using a collection initializer that adds Review instances, each of them created with an object initializer. Refer back to Chapter 5 for more information on collection and object initializers.

When you call the GetLatestReviews method from client code, you get back a collection of instances that you can loop over. The following code shows the getReviewsCallback method that accomplishes this:

```
function getLatestReviewsCallback(result) {
  var listItems = '';
  for (i i = 0; i < result.length; i++) {
    listItems += '<li>' + result[i].Title + '</li>';
  }
  document.getElementById('Reviews').innerHTML = listItems;
}
```

This code declares a string that will hold the titles of the reviews. It loops over the reviews in the result variable. JavaScript doesn't foresee, but using a string for loop you can easily access all items in the collection. Within the for loop, the review's title is retrieved using result[i].Title, which is then wrapped in a <li> tag and appended to a string variable. In the end, the string is added as the innerHTML of an element called Reviews (which could look like this in: <ul id="Reviews\</ul> so the review titles appear in a bulleted list.

When you type this, you'll notice not that IntelliSense for the result object. VS doesn't know the actual type of the result variable, and as such cannot help you find properties as Id and Title.
