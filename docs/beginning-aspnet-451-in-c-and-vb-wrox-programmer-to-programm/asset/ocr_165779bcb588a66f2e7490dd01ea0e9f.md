Moderniz to your site is very easy using the Package Manager Console that ships with
Visual Studio. To add the library, follow these steps:

+   1. Choose Tools ⧜ Package Manager ⧘ Package Manager Console.

+   2. Type the command and press Enter:

Install-Package Moderniz

+   3. After a delay, your site is expanded with a file packages.config that keeps
track of the installed packages and a Scripts folder that contains the file
moderniz-2.7.1.js. Note: your version could be different if a newer version of
Moderniz has been released by the time you read this. To add this library to your
page, use Default.aspx in Markup View and drag the file from the Solution Explorer
to the head section of the code, directly link to the style sheet. You should end up
with this code:

```
<link href="Styles.css" rel="stylesheet" type="text/css" />
<script src="Scripts/moderniz-2.7.1.js"></script>
</head>
```

You should add Moderniz library to your site if you have a modern browser.
Since you can't control the browsers visiting your site, you want to make sure everyone
se your site as intended. Adding Moderniz fixes the HTML5 compatibility issues for
older browsers hardly causing any overhead. You can learn more about Moderniz
on its website at http://moderniz.com. You'll see a lot more about the Package Manager
Console in Chapter 11.

+   11. Finally, save the changes to all open documents (press Ctrl+Shift+S) and then refresh Default
.aspx in your browser. Your screen should look similar to Figure 3-8, which shows the page in
