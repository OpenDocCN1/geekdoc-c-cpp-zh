5. Double-click the CustomValidator in Design View to have VS an event handler for the ServerValidate event. Add the following code to the handler:

```
VB.NET
Protected Sub CustomValidator1_ServerValidate(source Object,
    args As ServerEventArgs Handles CustomValidator1.ServerValidate)
If Not String.IsNullOrEmpty(PhoneHome.Text) OrElse
    String.IsNullOrEmpty(PhoneBusiness.Text) Then
    args.IsValid = True
Else
    args.IsValid = False
End If
End Sub
```

```
C#nprotected void CustomValidator1_ServerValidate(object source,
    ServerEventArgs args)
{
    if (!string.IsNullOrEmpty(PhoneHome.Text) ||
        !string.IsNullOrEmpty(PhoneBusiness.Text))
    {
        args.IsValid = true;
    } else
    {
        args.IsValid = false;
    }
}
```

```
<script>
function validatePhoneNumbers(source, args)

    var phoneHome = document.getElementById('<%= PhoneHome.ClientID %>');
    var phoneBusiness = document.getElementById('<%= PhoneBusiness.ClientID %>');

        args.IsValid = false;
    }
}
</script>

```
