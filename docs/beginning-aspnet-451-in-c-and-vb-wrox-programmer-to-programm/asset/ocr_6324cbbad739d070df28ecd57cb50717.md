# Exercise 1 Solution

Authentication is all about proving your identity to a system like yours. After you have been authenticated, authorization determines what you can and cannot do in the system.

# Exercise 2 Solution

To expand the access to the Management folder for John and all users in the Editors role, you need to expand the roles attribute to include Editors, and add an additional allow element with its users attribute set to John:

```
<system.web>
<authorization>
    <allow roles="Managers, Editors" />
    <allow users="John" />
    <deny users="*" />
</authorization>
</system.web>
```

The roles attribute allows you to specify multiple roles separated by a comma. To grant the John account access, you need to add an additional allow element and fill in John's name in the users attribute.
