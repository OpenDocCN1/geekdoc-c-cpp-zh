
When a server control is processed, it returns HTML. So, the code for the same button ends up like this rendered in the browser:

```html
 <input type="submit" name="Button1" value="Click Me" id="Button1" />
```

The process of converting the server control to its HTML representation is similar to what you saw earlier that displayed the current date. The server control is processed by the ASP.NET handler. This processing results in HTML, which is sent to the browser, where it's displayed.

You now understand that the basics of an ASP.NET page and the HTML that it generates, it's time to look at VS. Knowing how to use the application and its many tools and windows is an important step in building fun, good-looking, functional websites.

## A TOUR OF THE IDE

Visual Studio is by far the most extensive and feature-rich integrated development environment (IDE) for building ASP.NET pages. The abbreviation IDE refers to all the separate tools you need to build complex applications integrated in a single environment. Instead of writing code in one editor, compiling at the command line, writing HTML and CSS in a separate application, and managing your database in yet another, VS enables you to perform all of these tasks, and more, from the same environment. Besides the efficiency this brings you you don't have to constantly switch tools, this also makes it much easier to learn new areas of VS, because many of the built-in tools work in the same way.

## Choosing Your Development Profile

Because VSE welcomes new people to ASP.NET development as well as seasoned web developers, you can choose from different profiles: Basic Settings, Code Only, and Expert Settings. In Basic Settings, many menu items you frequently use have been hidden or are placed in their own submenu. The Code Only profile is for pure coding sessions where you're not interested in many of the design features of VSE, such as Design View or the Toolbox. Expert Settings give you access to the full functionality of VSEW. You can switch between settings using the Tools Settings menu. This book assumes you are using Expert Settings mode from the beginning. You may not need all the features you see from the start, but you will use most of them by the end of the book. Because the menu items change location depending on the profile you choose, I decided to use Expert Settings right away, to make it easier to refer to a specific menu item or feature. You don't have this option in the commercial versions of Visual Studio — Expert Settings is by default.

## The Main Menu

At the top of the application, right below the Windows title bar, you see the main menu. This menu bar contains items you find in many other Windows applications, like the File, Edit, and Help as well as menus specific to VS, such as the Website and Debug menus. The menu changes dynamically depending on the task you're working on, so you'll see menu items appear and disappear as you work through the application. You can use the Help Set Help Preference to configure online and offline help. Offline help needs to be installed first, and online help requires a connection to the Internet. On the far right you see a Sign In link that lets you sign in with your Microsoft account to enable synchronization of VS settings between different machines.

## The Notification Window

In the application's title bar to the left of the Windows Close, Minimize, and Maximize buttons, you see an icon with a little flag. Clicking the flag icon brings up the Notification window in which Visual Studio provides you with important information. For example, it will show available downloads for new documentation content, expired licenses, product updates, and more. Depending on the importance of the available notifications, the color of the flag in the title bar changes color. The Notifications window is also accessible from the View menu. If you installed the RTM version of Visual Studio, you're likely to see a few updates you can safely install now.

## The Toolbox

On the left of the main screen, the Toolbox folds out, giving you a chance to see what it contains. If you click the tab, the little pin icon in the upper-right corner of the Toolbox (or any of the other panels that has this pin icon), it gets pinned to the IDE so it remains open.

Just as the menu bar and toolbars, the Toolbox automatically updates itself to show content that is relevant to the task you're working on. When you're editing a standard ASP.NET page, the Toolbox shows many controls you can drag and drop onto your page.
