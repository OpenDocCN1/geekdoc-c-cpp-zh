# DEBUGING WITH THE PAGE INSPECTOR

If you want to build a site that is easy to maintain, probably make use of many of the features of ASP.NET and the browser offers. For example, you're probably using a master page for the general layout, you use page-specific content in a content page that uses that page, you may have one or more user controls for content to use across your site (such as the Contact Form in the Planet Wrox website), and you may be using themes and skins to separate the design from the rest of your application.

In the browser, all of this code comes together as a single HTML document in that includes references to external resources as JavaScript and CSS files. Because it's a single file, it is hard to debug code and understand where a certain piece of HTML comes from. In addition, multiple CSS selectors can influence the layout of your page, it may be hard to track down the file in which a certain piece of CSS is defined. Using the Page Inspector, introduced in VS 2012, this now becomes much easier.
