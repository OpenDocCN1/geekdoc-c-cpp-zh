Instead of creating a full page with HTML as you go with standard ASPX pages, you now only get two <asp:Content> placeholders in this VB.NET example:

```
<% Page Title=" Language="VB" MasterFile="/MasterPages/Frontend.master"
AutoEventWire="false" CodeFile="Default.aspx" Inherits="Default" %>
<asp:Content Id="Content1" ContentHolderID="head" runat="Server">
</asp:Content>
<asp:Content Id="Content2" ContentHolderID="cpMainContent" runat="Server">
</asp:Content>
```
