# How It Works

When you define profile properties in Web.config, the ASP.NET run creates a class for you in the background. This class, called ProfileCommon, gives you access to the strongly typed properties such as FirstName, LastName, and FavoriteGenres. The ProfileCommon class inherits from ProfileBase, the base class defined in the .NET Framework that contains the behavior to access the profile in the database by using the configured provider. The ASP.NET Profile Provider in turn takes care of all the hard work of persisting the data in the configured database. For the Membership and Roles provider you saw in the preceding chapter, use `connectionString` attribute of the configured provider.

To define properties, use an `<add>` element with a name attribute and an optional type if the property is of a type other than System.String. For example:
`<add name="FavoriteGenres" type="System.Collections.Generic.List`1[System.Int32]" />`

This property sets up a list that contains Integer values to help the user's favorite music genres. See how to use this property in a later exercise.
