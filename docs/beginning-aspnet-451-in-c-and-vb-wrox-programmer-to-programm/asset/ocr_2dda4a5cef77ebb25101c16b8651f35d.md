# Using the CSS Editor

The CSS editor in VS hosts a number of powerful features, demonstrated in the next Try It Out exercise.

# TRY IT OUT Trying the CSS Editor

In this exercise you modify the styles.css file you created earlier by adding a few new styles. Along the way you're introduced to a number of the CSS editor features listed earlier.

+   1. Open the Styles.css file from the styles folder and locate the section#MainContent selector. Right below its curly brace, add the following CSS selector that targets links (a elements) in the MainContent section:

```
section#MainContent a
{}
```

+   2. Between the opening and closing braces, by a colon (:) and then by a hash symbol (#). As you type the hash symbol, VS presents you with a color picker. If you click the arrow of the color picker, it expands and shows more options, visible in Figure 3-9.

![](bbox=[0.625, 0.335, 0.908, 0.526])

This color picker has few interesting features. Firstly, the top row of colored squares contains a list of colors that are defined in your style sheet. This is a great way to quickly pick a color you've already used for another selector. The list of recognized colors is followed by a vertical bar, which is turned by some default colors that VS adds for you. In Figure 3-9 you can see recognized colors a light and a dark shade of grey. The other colors are all default. Secondly, you can mix your color by dragging the mouse over the large square in the middle as well as over the color vertical bar on the right. Finally, using the tiny color picker icon at the bottom right of the screen, you can quickly select a color from any Windows application or your desktop. This is a great way to retrieve the color from an image you may have opened in some graphics program, for example.

+   3. Complete the style rule for section#MainContent a and add two more style rules as follows:

```
section#MainContent a

  color: #4fff00;
```
