Customizing the IDE

In the next Try It exercise you get the chance to play around with the Visual Studio IDE so you can customize it to your liking.

# TRY IT OUT Customizing the IDE

In this exercise you practice opening and rearranging the windows in the VS IDE. Don't be afraid to mess things up. A little later in this chapter, instructions are given on how to reset the IDE to the way it was when you opened the first time.

+   1. If you closed your website since the previous Try It Out, open it again, or create a new one using the Menu file.

+   2. From the View menu, choose Error List to open the Error List window. If you don't see the Error List item directly, choose Tools 🛠 Settings ⚙️ Expert Settings first. Notice how the Error List gets docked below the Document window by default.

+   3. From the same view, choose Task List. By default, it is docked in the same space as the Error List, with tabs for both next to each other.

+   4. Click the tab of the Task List, and while holding your mouse button, drag the Task List away from its location in the direction of the Document Window. Once you release the window, it appears as a floating window in the IDE. To restore window, drag it back to the center square of the Error List. To change the order in which tabs appear in a tab group, drag tab over the other tabs and release it at the desired location

+   5. If you want, you can repeat the steps for other windows that are visible in the IDE by default or for the ones you find under the View menu. Spend some time familiarizing yourself with all the different windows and how you can arrange them on-screen. Because you'll be working with these windows in the remainder of this book, it's good to be familiar with their locations.

+   6. Next, open the ControlsDemo.aspx (or add a new ASPX if you want to create a new website) from the Solution Explorer by double-clicking. When the page opens, the Toolbox becomes visible automatically. If it doesn't, press Ctrl+Alt+X to show it.

+   7. Right-click the Toolbox and choose Add Tab. Type HTML Fragments as its new name and press Enter. This adds a new entry to the Toolbox that behaves like all the others.

+   8. With the Document window showing your ASPX page in Markup View, type <h1> directly after the opening <div> tag. Note that Visual Studio automatically inserts the closing </h1>. You should end up with code in Markup View looking like this:

```
<div id="form" run="server">
<div>
  <h1></h1>
</div>
```

+   9. Highlight the opening and <h1> tags, and then drag the selection from the Markup View window onto the new Toolbox tab you created in step 7. The selection shows up as Text: <h1></h1>.

+   10. Right-click the Toolbox item you just created, choose Rename Item, and type Heading 1 as the name.
