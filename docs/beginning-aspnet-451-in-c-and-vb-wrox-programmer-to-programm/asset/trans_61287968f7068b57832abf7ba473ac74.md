# Visual Studio 的实用技巧

本书的大多数章节都以一个简短的有用技巧部分结尾。这些技巧要么在正文中找不到合适的位置，要么鼓励你去探索或测试某些功能。有时它们乍一看似乎无关紧要或难以理解，但当你阅读本书并回头查看前几章的技巧时，就会开始变得有意义。不要担心第一次看到某些内容时完全不理解。花点时间思考一下，几天后再回头研究该主题。希望通过让这些想法沉淀下来，事情会自动变得更清晰。这不仅适用于实用技巧部分，也适用于整本书。

- 在进入下一章之前，多玩玩 Visual Studio。向你的站点添加几页，从工具箱中将控件拖放到你的页面上，并在浏览器中查看它们。这样，当你开始下一章时，你会对工具和可用的众多控件有更好的理解。

- 熟悉 Visual Studio IDE 的众多可调整选项。在构建网站时，你大部分时间都在这个 IDE 中度过，因此让它尽可能符合你的喜好是有意义的。不要害怕弄乱它；你随时可以恢复到之前的设置。

- 花点时间浏览 Visual Studio 选项对话框中的设置，该对话框可通过工具 > 选项菜单访问。其中许多设置不言自明，并且确实有助于调整 IDE。

# 使用 Visual Studio 2013 创建网站

上一章为你在 VS 中创建网站提供了快速概述。你只需从文件菜单中选择新建网站，选择语言、标准的 ASP.NET Web 窗体模板，然后单击确定即可。然而，新建网站对话框中包含的内容比你在上一章中看到的要多。你可能已经注意到，你可以在其中选择多种不同的模板来创建不同类型的站点。在查看可用于构建网站的不同模板之前，你需要了解 VS 中可用的不同项目类型。

# 不同项目类型

在 Visual Studio 2013 中，你可以选择两种项目类型来创建 ASP.NET Web 窗体网站：Web 应用程序项目和网站项目。

# Web 应用程序项目

Web 应用程序项目使在团队中工作或需要对站点内容及其编译和部署过程有更多控制的开发人员更容易使用 VS 构建网站。整个网站作为一个项目进行管理，使用单个项目文件跟踪网站的所有内容。

在 VS 中，你可以通过文件 > 新建项目对话框创建新的 Web 应用程序项目。Web 类别包含一个模板——ASP.NET Web 应用程序——可让你创建可包含各种 ASP.NET 相关技术（如 Web 窗体、ASP.NET MVC 和 Web API）的 Web 项目。这是微软“One ASP.NET”计划的一部分，该计划旨在将各种技术在 Visual Studio 中更紧密地结合起来。有关这些技术的更多信息，请访问 www.asp.net 并单击学习菜单项。

> 注  有关 One ASP.NET 的信息以及了解更高级技术，请参阅 Professional ASP.NET 4.5（Wrox：978-1-11-31812-0）。

# 网站项目

网站项目代表 VS 中的网站项目。你可以通过从 Visual Studio 主菜单中选择文件 > 新建网站或文件 > 新建 Web 来创建新的网站项目。
