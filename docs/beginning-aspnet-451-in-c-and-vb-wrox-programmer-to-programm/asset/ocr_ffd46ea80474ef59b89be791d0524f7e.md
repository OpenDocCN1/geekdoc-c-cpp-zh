```
<add name="FavoriteGenres"
type="System.Collections.Generic.List`1[System.Int32]" />
```

The first part of the type attribute looks quite normal. The List class lives in the System .Collections.Generic names makes it sense that you need to specify that here as well. However, right after the class name (List) you see `1`. This is not a type, but the .NET will refer to generic types in- to define it based on a generic type, you need to use the back tick (`) followed by an i. The back tick is usually found to the left of the 1 key on your keyboard. The `1` is then followed by a pair of square brackets that contains the actual type you want to use for the list. The type specified in the FavoriteGenres profile property maps these to VB.NET and C# counterparts:

```
VB.NET
Dim FavoriteGenres As New List(Of Integer)
```

```
C#nList<int> FavoriteGenres = new List<int>();
```

You will see how to use this and other profile properties in the exercises. First, you will learn how to configure profile in web.config the next Try Out. Later exercises show how to work with these properties, and how to use the various methods of the List class.
