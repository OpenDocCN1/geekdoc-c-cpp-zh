The pages you created in the previous chapters took look pretty plain and dull. That's because they lack styling information and therefore default to the standard layout that the browser applies. To spruce your pages, you need a way to change their presentation in the browser. The most common way to do this is by using the cascading sheets (CSS) language. CSS is the de facto language for formatting and designing information on the web, including ASP.NET web pages. With CSS you can quickly change the appearance of your web pages, giving them that great look that your design or create identity dictates.

Solid support for using CSS was initially added in Visual Web Developer (VWD) 2008, one of the predecessors of VS Express 2013 for Web. VS 2012 included a new CSS editor with features similar to other languages, such as C# and VB. The CSS editor has been further enhanced in VS 2013.
