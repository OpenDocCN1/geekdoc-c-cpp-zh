# MAPPING YOUR DATA MODEL TO AN OBJECT MODEL

With EF, you map database items such as tables, columns, and relationships in the database to objects and properties in an object model in your application. VS comes with great tools to make this mapping as easy as possible, as you see in the following exercise.

# TRY OUT A Simple LINQ to Entities Example

In this Try Out, you see how to add an ADO.NET Entity Data Model file to your project, add data bases to the model, and then write a simple LINQ query to access the data in the underlying tables.

+   1. Open the PlanetWrox project that you have been working on so far. Right-click the App_Code folder, choose Add+ New Item, and select your programming language on the left. Click ADO.NET Entity Data model, type PlanetWrox as the name, and Click Add to add it to your project. If you don't see it in the list, check that you right-clicked App_Codes and not another folder like App_Data.
2. In the dialog box that follows, make sure that Generate from Database is selected and click Next.
3. In the Choose Your Data Connection, make sure PlanetWroxConnectionstring1 is selected in the drop-down and check the box to set the settings in web.config is checked. Your dialog now looks like Figure 14-1.
Click Next to go to the Choose Your Version dialog. Choose Entity Framework 6.0 and click Next.
4. On the Choose Your Database Objects and Settings dialog, expand Tables and then debon, and check off the genre and Review tables. If you see a diagram table, leave it unchecked. This is a table used by SQL Server and you don't need it in your Planet Wrox model.
If're using an English version of VS, you get an option to pluralize or singular names in the model automatically, which should leave checked. For other languages you'll need to do this manually, as you see next. Finally, make sure leave the option to include foreign key columns in the model. You see that option is used for later in this chapter. Finish to add the model to your site. If you get a security warning, click Do Not Show Message Again and then click OK. Visual Studio uses what's called T4 template (with a .tt extension) to generate the code for you and by default you need to grant permissions to execute this template.
