DetailsView1.DefaultMode = DetailsViewMode.Edit;

When the control is in edit mode, it knows what to do. It calls the SqlDataSource and requests its data. The SqlDataSource retrieves the ID of the review from the query string, accesses the database, and then returns the correct review, which is displayed on the page. When you subsequently click the Update link, the SqlDataSource fires its UpdateCommand to send the changes to the database.

This exercise provides a nice foundation for the following exercise, where you to extend the DetailsView by implementing custom templates with validation controls and set up any event handlers to respond to the control's events.
