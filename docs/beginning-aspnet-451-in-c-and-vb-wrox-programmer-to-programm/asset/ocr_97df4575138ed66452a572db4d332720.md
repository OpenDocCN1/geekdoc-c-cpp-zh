# MODIFYING THE DOM WITH JQUERY

Once you have a matched set, you want to do something with it. For example, you may want to apply a CSS class or style to the items in it. You may want to append some behavior to them, like adding a class handler that fires code when you get clicked. You've already seen examples of using the css and bind methods, but jQuery has a lot more to offer. In the next two sections, we show how to work with various CSS methods and how to set event handlers.

# CSS Methods

CSS is supported in jQuery a few different ways. First, the css method enables you to retrieve a specific CSS value (like the color of an item), and to set one or more properties on a set of elements. Secondly, methods like addClass, removeClass, toggleClass, and hasClass enable you to alter or inspect the CSS classes that are applied to elements. Furthermore, a couple of methods enable you to work with the dimensions and position of an element. I discuss only the most common ones, but you can look up the entire list at jQuery website. The examples use again the same HTML fragment as before, so it's easy to follow along if you want to try them in your browser.

# css(name, value)

This method enables you to set a CSS property on a matched element. The name argument refers to a CSS property (such as border, color, and so on) and the value defines the style you want to apply. The following example changes the background color of the hi element:

```
$$('hi').css('background-color', 'green');
```
