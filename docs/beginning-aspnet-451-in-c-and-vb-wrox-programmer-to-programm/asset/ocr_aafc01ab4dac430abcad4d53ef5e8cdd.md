| PROPERTY | DESCRIPTION |
| --- | --- |
| CssClass | This enables you to assign a CSS class instead of inline style information. You should give preference to the CssClass property over the individual style properties because they minimize page bloat. You see how to use CssClass in a later exercise. |
| Font | This enables you to set the font for the element through the various subproperties like Font-Names, Font-Size, and Font-Bold. These properties end up as various CSS font properties, such as font-family, font-size, and font-weight. |
| HorizontalAlign These end up as align and valign attributes on the HTML element to which they are applied and enable you to control the alignment of the contents of the element. For example, you use HorizontalAlign to left, or right-align the text of the column headers of GridSearchCV. Note: These properties output attributes that are obsolete in HTML5. Most browsers will still render them as intended, but if HTML5 conformance is important, you shouldn't use these properties, but use your own CSS class assigned with the CssClass property |
| Wrap | This ends up as a white-space: nowrap; CSS declaration when set to False determines whether a piece of text is allowed to wrap to a new line. Height These enable you to control the height and width of the elements to which they are applied and map directly to their CSS height and width counterparts. |

The different data-bound controls have a different set of styles, although they share a few. The following table lists the available styles for the GridSearchCV and describe their purpose. The other data-bound controls have slightly different styles, but from them you should be able to see what they do and determine what they are used for. Another good way to learn more about the different styles that are available is by using Visual Studio's Auto Format, which inserts a number of styles for. You see later how to use and improve the styles that are generated by the Auto Format feature.
