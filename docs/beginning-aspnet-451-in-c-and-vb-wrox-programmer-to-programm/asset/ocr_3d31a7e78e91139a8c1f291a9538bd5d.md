If you now insert or edit a new review, you'll see that the ID of the genre is passed back to the Reviews.aspx page. On that page, you can use ID to preselect the correct item in the DropDownList control, which you can accomplish with the following code in the Page_Load method:

# VB.NET

```
Protected Sub Page_Load(sender As Object, e As EventArgs) Handles Me.Load
    If Not Page.IsPostBack Then
        Dim genreId As String = Request.QueryString.Get("GenreId")
        If Not String.IsNullOrEmpty(genreId) Then
            DropDownList1.DataBind()
            Dim myItem As ListItem = DropList1.Items.FindByValue(genreId)
            If myItem IsNot Nothing Then
                myItem.Selected = True
            End If
        End If
    End If
```

Only when the page is loaded from a new request (and not from a postback) does this code fire. This code tries to find a genreId in the query string. If it can, it tries to find an item with the requested value in the DropDownList. Because the DropDownList hasn't been data bound it doesn't contain any items. Therefore, you need to call DataBind()! This gets the items from the database using EF and puts them in the DropList. Once that and the item is found in the Items collection, it's made the active item by setting its Selected property to True. The SqlDataSource control controls this DropList so when the data source gets reviews, it does so for the correct genre.
