ScriptManagerProxy control. Because you can have only one ScriptManager in a page, you can't add another one in a content page that uses your master page with the ScriptManagerProxy serves as a bridge between the content page and the ScriptManager in the master page, giving you great flexibility as where you register your services.

When you have the ScriptManagerProxy in place, you add the <Services> element to it as you saw with the ScriptManager itself:

```
<asp:ScriptManagerProxy ID="ScriptManagerProxy1" runat="server">
  <Services>
    <asp:ServiceReference Path="-/WebServices/NameService.svc" />
  </Services>
</asp:ScriptManagerProxy>
```

# TRY OUT Calling Web Services from Client-side Code

In this exercise you register a web service in a ScriptManagerProxy control so it becomes available in one page. You write some client-side JavaScript code that accesses the service and then its return value.

+   1. Create a page that uses your service and registers it using a ScriptManagerProxy control. To do this, add a new Web Form in the Demos folder and call it WebServices.aspx. Make sure you base this on your custom template, so it has the correct page set and inherits from the BasePage class, and give it a Title such as Web Demo. Once you've added the page, drag a ScriptManagerProxy control from the AJAX Extensions control of the Toolbox into the markup of the cpMainContent placeholder.

+   2. With the ScriptManagerProxy element, add a <Services> element that in contains a ServiceReference with its Path set to the NameService you created. Note that IntelliSense helps you pick the right file as soon as you type Path" by showing a list with files. Click Pick URL at the bottom of the list and browse to the service file in the WebServices folder. You should end up with this code in the WebServices.aspx page:

```
<asp:Content ID="Content2" ContentHolderID="cpMainContent" runat="server">
  <asp:ScriptManagerProxy ID="ScriptManagerProxy1" runat="server">
  <Services>
    <asp:ServiceReference Path="-/WebServices/NameService.svc" />
  </Services>
</asp:ScriptManagerProxy>
</asp:Content>
```

+   3. Right below closing the tag of the <ScriptManagerProxy>, add an Input (Text) and an Input (Button) by dragging them from the HTML control of the Toolbox. Web elements and ASP.NET Server Controls, you are going to write plain HTML that really executes at the client. Set the id of the text box to YourName and the id of the button to SayHello.
