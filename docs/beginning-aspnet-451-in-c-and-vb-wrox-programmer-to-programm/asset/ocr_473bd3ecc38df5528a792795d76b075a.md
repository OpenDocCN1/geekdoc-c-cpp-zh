Click OK to attach the database to SQL Server. If you get an error, make sure your account (or the Users group you are part of) and the Network Service account have Modify permissions on the c:\Data\SqlServer folder and the .mdf files these folder contains. Also, try running SQL Management Studio as an administrator as explained in step 4.

Your database is now accessible in the Databases node of Management Studio's Object Explorer. If you expand the elements and look into your database, you should see familiar items like tables that you also saw in the Server Explorer in Visual Studio earlier in the book. Figure B-3 shows the attached database and its tables.

At this stage, only administrative accounts (Windows administrators or the built-in SQL Server administrative account SA) have access to the database. To have the Planet Wrox work with your database, you need to configure both SQL Server security and your website. You need to do this next.
