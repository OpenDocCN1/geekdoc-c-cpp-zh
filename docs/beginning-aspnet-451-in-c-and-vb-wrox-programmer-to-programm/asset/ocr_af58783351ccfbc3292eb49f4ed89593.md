WCF services are essentially methods that can be called over a network, like the Internet or your local network. The default using message format for an Ajax-enabled WCF service is JSON. This is a very succinct way to exchange data. For example, the two reviews you saw in earlier example are transferred from the server to the client following this JSON code:

```
{"d":[{"_type":"Review#","Id":1,"Title":"21st Century Breakdown\nby Green Day"},{"_type":"Review#","Id":2,"Title":"nSonic Youth: Daydream Nation live in Roundhouse, London"}]}
```

I split the code over multiple lines to make it readable. In reality, this if you look at the comments about your service code file you see that you can also return XML. However, for most purposes, JSON is an excellent choice.
