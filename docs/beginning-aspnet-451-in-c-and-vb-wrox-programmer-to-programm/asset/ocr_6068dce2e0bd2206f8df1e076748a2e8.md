# How It Works

The website you created in this Try Out is quite simple, the process that eventually results in the page Default.aspx displayed in your browser is not so simple. By itself, an ASP.NET page (also referred to as an ASPX page of its extension, or a Web Form) can not do much. It needs to be processed and served by a web server before your browser can display it. That is why VS automatically started IIS Express to handle the request for the page. When you started up your web browser and directed it to the address of the web server (http://localhost:4985/Default in your Try Out), although the actual port number in the address may change every time you start the web server because it is randomly chosen by You.

It's important to realize that the ASPX page you modified in VS is not the same as the one eventually displayed by the browser.

When you create a page in ASP.NET, you add markup to it. The markup in an ASPX page is a combination of HTML, code for ASP.NET Server Controls (which you learn more about in this chapter and in Chapter 4), code written in Basic.NET or C#, and more.

When you request an ASPX page in your browser, the web server executes, any server-side code it contains in the file, and effectively transforms the ASP.NET markup into HTML that it then sends to the browser, where it is displayed. In the preceding Try Out, the resulting HTML causes the browser to display the current date and time. HTML, or HyperText Markup Language, the language that browsers use to display a web page. You learn how HTML looks and how to use it later in this chapter.
