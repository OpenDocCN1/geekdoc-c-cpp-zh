In addition to the For and the For Each loops, there is one more loop that you need to look at: the While loop.

# The While Loop

As its name implies, the While loop is able to loop while a certain condition is true. Unlike the other two loops, which usually end by themselves, the While loop could loop forever if you're not careful. It could also not execute at all if its condition is never met. The following example shows how to use the While loop:

```
VB.NET
Dim success As Boolean = False
While Not success
    success = SendEmailMessage()
End While
```

```
C#nbool success = false;
{
    success = SendEmailMessage();
}
```

This code tries to send an e-mail using the fictitious SendMessage method and will do so until it succeeds—that is, as long as the success has the value False (false in C#). Note that Not and ! are used to reverse the value of success. The SendEmail method is supposed to return True when it calls SendEmailMessage. If it returns False then it doesn't. If everything works as planned, the code enters the loop and calls SendEmailMessage. The loop condition is no longer met, and the loop ends. However, when SendEmailMessage returns False, for example because the mail server is down, the loop continues and SendEmail is called again.

To avoid endless loops with the While loop, it's a good idea to use a counter that terminates the loop after a certain number of tries. For example, the following code helps to avoid an infinite loop if the mail server is down:

```
VB.NET
Dim success As Boolean = False
Dim loopCount As Integer = 0
While Not success AndAlso loopCount < 3
    success = SendEmailMessage()
    loopCount = loopCount + 1
End While
```

```
C#nbool success = false;
int loopCount = 0;
while (!success && loopCount < 3)
{
    success = SendEmailMessage();
    loopCount = loopCount + 1;
}
```
