# How It Works

To see how it works, you should look at the HTML for the page. The Button control has been transformed into the following HTML:

```
<input type="submit" name="ctl100cpMainContentButton1" value="Button" id="cpMainContent_Button1" class="MyButton" style="background-color:#509EE7;" />
```

Both the Class and the Background attributes in the skin have been added to the HTML. The former ended as a class attribute on the button, and the latter has been transformed into a style attribute. The MyButton class in the CSS file gives the button its white text and inline style determines the background color of the button. If you choose the DarkGrey theme in the drop-down list and then look at the HTML again, you'll notice it has no class and style attributes, giving the button its default look.

As you see, skins are extremely easy to use and enable you to radically change the look of specific controls in your site. But what if you don't want all your buttons to be blue and white at the same time? What if you need one special button that has a red background? You can do this with named skins.

# Named Skins

Named skins are identical to normal skins with one exception: they have a SkinID that enables you to refer to that skin by name. Controls in ASP pages you can use SkinID to apply that specific skin to the control. The next exercise shows how this works.
