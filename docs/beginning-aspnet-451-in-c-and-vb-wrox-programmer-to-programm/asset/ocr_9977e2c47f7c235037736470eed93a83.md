# How It Works

The SiteMap renders as a series of <span>elements that contain either a link or plaintext. Here's a view of the HTML code for the SiteMap from Figure 7-11:

```
<span><a title="Home" href="/">Home</a>&lt;/a&gt;&lt;/span&gt;</span>
<span><a title="Reviews published on this site" href="Reviews/Default.aspx">Reviews</a>&lt;/a&gt;</span>
<span>&lt;span&gt;</span>
<span>All Reviews/</span>
```

The first two items (Home and Reviews) are represented by a link <a> to enable you to navigate to the pages defined in their href properties. The final item — All Reviews is just plaintext. Between the elements you see a <span> with the character set in the PathSeparator property. Because this separator (;) has a special meaning in HTML, its value is encoded to &gt; (greater than) to ensure it ends up as a plaintext in the browser.

If you look at the HTML for the page in your browser, you will also see an <a> element that enables you to skip links. The <a> contains a small image with its left property set to a large negative value, so it is outside of the browser window and you don't see it. This is useful for vision-impaired users with screen readers it enables them to skip the navigation and go directly to the content of the page. The TreeView and Menu controls use an identical approach to prevent a screen reader from reading the entire structure out every time the page is loaded.

The three navigation controls give you a great feature set for a navigation system in your website from the client side. Both the Menu and the Tree controls enable you to quickly display the entire structure of the site so users can easily find their way. SiteMap helps users understand where they are in the site and gives them an easy way to navigate higher up in the site hierarchy.
