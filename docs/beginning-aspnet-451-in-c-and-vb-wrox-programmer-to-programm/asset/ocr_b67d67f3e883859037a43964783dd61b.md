# RangeValidator

The RangeValidator control enables you to check whether a value falls within a certain range. The control is able to check data types like strings, numbers, dates, and currencies. For example, you can use it to make sure a number is between 1 and 10, a character between A and F, or a selected date between today and the next two weeks. The following table lists its important properties.

| PROPERTY | DESCRIPTION |
| --- | --- |
| MinimumValue | This property determines the lowest acceptable value. For example, when checking an integer number between 1 and 10, you set this property to 1. |
| Maximum | This property determines the highest acceptable value. For example, when checking an integer number between 1 and 10, you set this property to 10. |
| Type | This property determines the data type that the validation control checks. This value can be set to String, Integer, Date, or Currency to check the respect data types. |

The following example shows a RangeValidator that ensures the value entered in the Rate box is a number that lies between 1 and 10:

```
<RangeValidator ID="RangeValidator1" runat="server"
ControlValidate="Rate" ErrorMessage="Enter a number between 1 and 10"
MaxValue="10" MinimumValue="1" Type="Integer" />
```

# RegularExpressionValidator

The RegularExpression control enables you to check against a regular expression that you set in the ValidationExpression property of the control. Regular expressions are a complex subject but enable you to search for patterns in text. Regular expressions but visually, Visual Studio has a few built-in expressions that make it easy to validate values like e-mail addresses and ZIP codes. If you want to learn more about regular expressions, pick up a copy of Wirth's Building Regular Expressions by Andrew Watt (ISBN: 978-0-7645-7489-4).

The following example shows a RegularExpressionValidator that ensures that a user enters a value that looks like an e-mail address:

```
<RegularExpressionValidator ID="RegularExpression1" runat="server"
ControlValidate="Email" ErrorMessage="Enter a valid e-mail address"
ValidationExpression="^[\w-\.]+@([\w-]+\.).)+[a-z]{2,4}$" />
```

# CompareValidator

The CompareValidator can be used to compare the value of one control to another. This is often used in sign-up forms where users have to enter a password twice to make sure they type the same password both times. Instead of comparing to another control, you can also compare against a constant value.
