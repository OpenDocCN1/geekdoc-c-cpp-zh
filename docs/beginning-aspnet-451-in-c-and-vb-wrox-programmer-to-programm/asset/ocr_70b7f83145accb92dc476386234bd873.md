# TRY OUT Using the RequiredFieldValidator

In this exercise, you create a user control ContactForm.ascx. You can place it in a web page
visitors to your site can learn some feedback. In later exercises, you extend the control by sending
response by e-mail to your email-account.

+   1. Open the Planet Wrox project and add a new control in the Controls folder. Call the control
ContactForm.ascx. Make sure that it uses your programming language and a Code Behind.
2. Switch to Design View and insert a table by choosing Table ↷ Insert Table. Create a table with
eight rows and three columns.
3. Merge the cells of the first row. To do this, select all cells, right-click the selection, andnn Modify ↷ Merge Cells.
4. In the merged cell, type some text that tells your users they can use the contact form to get
touch with you. You could use an h1 element as a heading above to draw the user's
attention.
5. In the cell of the second row, type the word Name. Into the second cell of the same
row draw a TextBox and set its ID to Name. Into the last cell of the row, draw a
RequiredFieldValidator from the Validation category of the Toolbox. Finally, to the second
cell of the last row, draw a Button. Rename the button to sendButton by setting its ID and set its
