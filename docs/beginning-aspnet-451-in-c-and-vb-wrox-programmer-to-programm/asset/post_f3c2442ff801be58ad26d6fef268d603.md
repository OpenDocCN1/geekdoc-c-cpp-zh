- 11. Switch to Code Behind and complete that method as follows:

# VB.NET

```vb
Public Sub DetailsView1_InsertItem()
    Dim photoAlbum As New PhotoAlbum()
    TryUpdateModel(photoAlbum)
    If ModelState.IsValid Then
        Using myEntities As New PlanetWrixEntities()
            myEntities.PhotoAlbums.Add(photoAlbum)
            myEntities.SaveChanges()
        End Using
        Response.Redirect(String.Format("ManagePhotoAlbum?PhotoId={0}", photoAlbum.Id.ToString()))
    End If
End Sub
```

# C#

```csharp
public void DetailsView1_InsertItem()
{
    PhotoAlbum photoAlbum = new PhotoAlbum();
    TryUpdateModel(photoAlbum);
    if (ModelState.IsValid)
    {
        using (var myEntities = new PlanetWrixEntities())
        {
            myEntities.PhotoAlbums.Add(photoAlbum);
            myEntities.SaveChanges();
            Response.Redirect(Format(
              "ManagePhotoAlbum?PhotoAlbum={0}", photoAlbum.Id.ToString()));
        }
    }
}
```

# How It Works

You started this exercise by adding the Picture and PhotoAlbum tables to both the database and the EF diagram. These tables are used to store data about photo albums and the pictures they contain. Each individual picture belongs to a PhotoAlbum referred to by its PhotoId that points to the Id column of the PhotoAlbum table in the database. The Picture table is designed to hold only data about the picture; the actual file is stored on disk, as you see.

To enable users to create a new photo album, you added a DetailsView control to the page. To make sure the control can be used to insert new photo albums, you set the DefaultMode to Insert. This forces the control to jump into Insert Mode, when the page loads in the browser, the DetailsView renders an interface that enables you to enter a name for the photo album. The controller renders the Insert link because of the CommandField with its ShowInsertButton set to True. By default, the CommandField also has a Cancel link. However, in this case there isn't a sensible cancel action, as the link was hidden by ShowCancelButton to False.

When you enter the name of a photo album in the browser and then click Insert, the page posts back to the server, the DetailsView notices that an Insert command is executed and fires the InsertMethod that you defined in. Inside this method, the data (in this case, only the name of the album) is updated and saved to the database.
