## Adding Your Own Information to the Trace

Adding your own data to the trace is useful if, for example, you want to see the value of a variable, or want to find out a specific events, and when it fires exactly.

You can add information to the trace using the Trace class. This class exposes two useful methods: Write and Warn. Both do pretty much the same thing: they add information to the trace you can optionally put in a category you make up yourself. The only difference between Write and warn is that messages written by Warn appear in red. You could use the Warn method for unexpected situations because the message will draw more attention.

In the following exercise, you see how it is to add your own information to the trace using the Warn and Write methods.

## How It Works

The Write and Warn methods of the Trace class enable you to write additional information to the trace. The ASP.NET runtime keeps track of information and displays it together with the rest of the trace, either directly at the bottom of the page with page-level tracing, or through the special Trace.aspx page you saw earlier.

The Write and Warn methods each have three overloads. The first (shown only with Write in the previous example) accepts a single string that is displayed in the Message column. The second overload also accepts a category name designated with the Warn method. The final overload, not shown in the Try It Out exercise, also accepts an Exception object whose message will be added to the output. This is useful to trace the information of an exception in a Catch block.

## Security

Tracing can be very useful, but leaving information in production can lead to disclosure. Therefore, you should disable tracing when possible.
