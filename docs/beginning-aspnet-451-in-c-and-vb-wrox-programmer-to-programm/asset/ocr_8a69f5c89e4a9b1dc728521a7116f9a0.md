# Exercise 15 Solution

To display only genres that have at least one review, all you need to do is filter out empty genres using Where with a Count method like this:

```
VB.NET
Dim genresWithReviews = From genre in MyEntities.Genres
    Order by genre.Name
    Where genre.Reviews.Count() > 0
    Select New { genre.Name, genre.Reviews }
```

```
C#
var genresWithReviews = from genre in MyEntities.Genres
    orderby genre.Name
    where genre.Reviews.Count() > 0
    select new { genre.Name, genre.Reviews };
```

# Exercise 2 Solution

To preselect the item in the drop-down list after a user has inserted or edited a review, you need to make two modifications. First, you need to change the Redirect statement in the AddEditReviewHandCoded.aspx page so it includes the ID of the genre:

```
VB.NET
Response.Redirect(String.Format("Reviews.aspx?GenreId={0}",
GenreList.SelectedValue));
```

```
C#
Response.Redirect(String.Format("Reviews.aspx?GenreId={0}",
GenreList.SelectedValue));
```

Using String.Format makes this code bit easier to read as opposed to plain string concatenation using the ampersand (&) in VB.NET and the plus (+) in C#.
