# A Closer Look at the Panel Control

In the following exercise, you use a Panel control to create a container for other controls and markup. You only add some text for now, but in a subsequent Try Out exercise you add ASP.NET controls to the panel.

# TRY IT Using the Panel Control

In this exercise you see how to use the Panel control as a container for some simple text. In addition, you use a CheckBox to control the visibility of the Panel at the server.

+   Start by creating a new Web Form with Code Behind called Containers.aspx in the Demos project.

+   Switch the page to Design View and drag a CheckBox and a Panel control from the Toolbox on the design surface under the dashed `<div>` element.

+   Give the CheckBox control a meaningful description by setting its Text property to Show Panel and set its PostBack property to True using the Properties Grid. Rather choosing from the drop-down list for the panel, you can also double-click the PostBack property or its value to toggle between False and True.

+   Set the Visible property of the Panel to False using the Properties Grid. This hides the panel when the page first loads.

+   Inside the Panel control, type some text (for example, I am visible now). Note that the panel behaves like the rest of VS's design surface. You can add text to it, select and format it, and add new controls by dragging them from the Toolbox. The panel should end up like this in Markup:

```
<asp:Panel ID="Panel" runat="server" Visible="False">
I am visible now
</asp:Panel>
```

```
<asp:CheckBox ID="CheckBox" runat="server" PostBack="True" Text="Show Panel" />
<asp:Panel ID="Panel" runat="server">
I am visible now
</asp:Panel>
```

+   In Markup, locate the code for the CheckBox. Position your cursor right before the closing forward slash (/) and press Enter, followed by Ctrl+Space. This brings up IntelliSense, as shown in Figure 4-9.

Select OnChanged by pressing Tab or Enter. Type an equals sign (=), which brings up IntelliSense as shown in Figure 4-10. Note that if you're using C#, you may also see a PostBack item in the list of event handlers.

```
<asp:CheckBox ID="CheckBox" runat="server" PostBack="True" 
Text="Show Panel" OnChanged="#CheckedChanged-" 
<asp:Panel ID="Panel" runat="server" # CreateNewEvent-">
I am visible now
</asp:Panel>
```
