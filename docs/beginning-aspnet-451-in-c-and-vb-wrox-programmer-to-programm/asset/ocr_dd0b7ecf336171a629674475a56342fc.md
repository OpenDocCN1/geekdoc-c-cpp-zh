If you don't see the message with the date and time appear or you get an error on the page in the browser, make sure you saved the changes to all pages. To save all pages at once, press Ctrl+Shift+S or click the Save button in the toolbar (with the moving floppy disk symbols). Additionally, make sure you typed the code for the right language. When you created this page, you chose a programming language that applies to the entire page. You can't mix languages on a single page, if you started with a C# page, make sure you entered the C# code snippet in step 6.

Setting up a page with inline code is very similar. Start by adding a new Web Form to the Demo folder. Click CodeInline.aspx and make sure you check the Place Code in Save File option.
