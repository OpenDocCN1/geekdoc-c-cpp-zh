# WHAT THIS BOOK COVERS

This book teaches you how to create a feature-rich, data-driven, and interactive website called Planet Wrox. Although this is a mouthful, you'll find that with Visual Studio 2013, developing a website that isn't as hard as it seems. You'll see the entire process of building a website, from installing Visual Studio in Chapter 1 all the way to putting up your website on a live server in Chapter 19. The book is divided into 19 chapters, each dealing with a specific subject:

- Chapter 1, "Getting Started with ASP.NET 4.5.1." In this chapter you will see how to obtain and install Visual Studio 2013 for Web, the free version of Visual Studio 2013 to build ASP.NET websites. You are also introduced to HTML5, the latest standard for defining web pages. The chapter closes with an overview of the customization options that Visual Studio gives you.
- Chapter 2, "Building an ASP.NET Website." This chapter shows you how to create a new website and how to add new items to pages. Learning how to create a well-structured site, you also see how to use the numerous tools in Visual Studio to create HTML and ASP.NET pages.
- Chapter 3, "Designing Your Web Pages." Visual Studio comes with a host of tools that enable you to create well-designed and attractive web pages. In this chapter, you will see to make good use of these tools. Additionally, you will learn about CSS, the language that is used to format web pages.
- Chapter 4, "Programming with ASP.NET Server Controls." ASP.NET Server Controls are one of the most important concepts in ASP.NET. They enable you to create complex and feature-rich websites with the large number of server controls that are available, explains what they are used for, and shows you how to use them.
- Chapter 5, "Programming Your ASP.NET Web Pages." Although the built-in CSS tools and the ASP.NET Server Controls can get you a long way in creating web pages, you are likely to use a programming language to enhance your pages. This chapter serves as an introduction to programming with a strong focus on programming web pages. Best of all: the examples you see in this chapter (and the rest of the book) are in Visual Basic and C#, so you can choose the language you like.
- Chapter 6, "Creating Consistent Looking Websites." Consistency is important to give your website an attractive and professional appeal. ASP.NET helps you create consistent-looking pages through the use of master pages, which enable you to define the global look and feel of a page. Skins and themes help you to centralize the looks of controls and other visual elements in your site. You also see how to create a base page that helps to centralize programming code that you need on all your pages.
- Chapter 7, "Navigation." To help users find their way around your site, ASP.NET comes with a number of navigation controls. These controls are used to build the navigation structure of your site. You can be connected to your site's central map that defines the pages in your site. You also learn how to programmatically send from one page to another.
- Chapter 8, "User Controls." User controls are reusable page fragments that can be used in multiple pages. As such, they are great for repeating content like menus, banners, and so on. In this chapter, you learn how to create and use user controls and enhance them with some programmatic intelligence.
- Chapter 9, "Validating Input." A large part of interactivity in your site is defined by the input of your users. This chapter shows how to accept, validate, and process user input.
- Chapter 10, "ASP.NET AJAX." AJAX allows you to create interactive web pages without refreshing the whole page. This chapter shows how to use AJAX to enhance your website. You also learn how to use jQuery.
- Chapter 11, "Query." jQuery is a popular, open-source JavaScript library designed to make it easier to use JavaScript. In this chapter, you learn the basics of jQuery.
- Chapter 12, "Introducing Databases." Understanding how to use databases is critical for building websites. This chapter shows how to use ASP.NET data controls. You also see how to interact with the SQL Server.
- Chapter 13, "Displaying and Updating Data." Building on the knowledge you gained in Chapter 12, this chapter shows how to display and update data using ASP.NET data-bound controls.
- Chapter 14, "LINQ and the ADO.NET Entity Framework." LINQ is Microsoft’s solution for accessing objects, XML, and more. The ADO.NET Entity Framework (EF) is a technology for database access. This chapter shows you how to use EF.
- Chapter 15, "Working with Data — Advanced Topics." Earlier chapters focus mostly on the technical foundations of data, this chapter looks at the same topic from a front-end perspective. You see how to change the visual appearance of data through the use of controls. You also see how to speed up your website by keeping a local copy of frequently accessed data.
- Chapter 16, "Security in Your ASP.NET Website." Although presented late in the book, security is a first-class, important topic. This chapter shows you how to make use of built-in ASP.NET features related to security. You learn about applications that facilitate security. You also learn to let users sign up for an account on your website, how to distinguish between anonymous and logged-on users, and how to manage the users in your system.
- Chapter 17, "Personalizing Websites." Building on the security features introduced in Chapter 16, this chapter shows you how to create personalized pages with content targeted at individual users. You see how to configure and use ASP.NET Profile, which enables you to store personalized data for known and unknown visitors.
- Chapter 18, "Exception Handling, Debugging, and Tracing." You need debugging tools to understand, improve, and fix the code you write for ASP.NET web sites. Visual Studio ships with great debugging support that enables you to diagnose the state of your application at runtime, helping you find and fix problems before your users do. You also get a good look at the Page Inspector and the new Browser Link feature.
- Chapter 19, "Deploying Your Website." By the end of the book, you should have a website that is ready to be shown to the world. But how exactly do you do it? What are the things you need to know and understand to put your website in the wild? This chapter gives the answers and provides you with a good look at configuring different production systems you also see how to implement bundling and minification to improve the performance of your website.
