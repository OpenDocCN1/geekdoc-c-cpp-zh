# Paging Controls

Another useful control is the DataPager, which enables paging on other controls. For the time being, you can only use it to extend the ListView control, but that might change with future versions of the .NET Framework. The ListView and DataPager controls are discussed in Chapter 14.

For the data-bound controls to display something useful, you need to assign them a data source. To bind this data to the controls, two main methods are available: You can assign data to the control's DataSource property, or you can use one of the separate data source controls. In later chapters, you will see how to use the DataSource property; the different data source controls are the topic of the following section.

# Data Source Controls

The Data category of the Toolbox contains six different data source controls that you can use to bind your data to data-bound controls. The XmlDataSource and SiteMapDataSource are used to bind hierarchical, XML-based data to them. You will see MapDataSource when you created the site map in Chapter 7.

The ObjectDataSource control allows you to connect your data-bound controls to separate objects in your application. Instead of tying data directly to a database, you bind data from a separate layer with custom objects to them. Get yourself a copy of W's Professional ASP.NET 4.5 (978-1-118-31821-0) if you want to find out more about the ObjectDataSource control.

The final three data source controls are the SqlDataSource, the EntityDataSource, and LinDataSource. The first is discussed in this chapter. The LinDataSource serves as a data source for LINQ to SQL, a technology similar to the ADO.NET Framework you learned about Chapter 14. Because Microsoft is now promoting the Entity Framework instead of LINQ to SQL, I won't discuss the LinDataSource control in this chapter. The EntityDataSource is used with older versions of the Entity Framework, and hasn't been updated for the latest version of EF. Instead of using this control, Microsoft recommends to use a concept called Model Binding, discussed extensively in the next chapter.

The QueryExtender control acts like an add-on to the LinDataSource and EntityDataSource controls in that it enables you to create a rich filtering interface to search for specific data without writing a lot of code. You can learn more about the QueryExtender in this article: http://bit.ly/92kMPQ.

# Other Data Controls

The final control in the Toolbox is the Chart control. It was initially released as an add-on to VS 2008 but it's designed to render chart graphics from simple bar charts to 3D pie charts and line graphs. You won't discuss this control further, but you can find a series of articles that discuss it in detail here: http://tinyurl.com/nsnbvv.
