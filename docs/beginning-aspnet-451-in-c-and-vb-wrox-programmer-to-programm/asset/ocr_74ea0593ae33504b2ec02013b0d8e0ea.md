# Your First jQuery Page

In this exercise, you add the jQuery library to the master page so it's available to all pages in your site.

+   1. Open the Frontend master file from the MasterPages folder and switch it to Markup View if necessary. Locate the ScriptManager control and add the following bolded markup to it:
```html
<asp:ScriptManager ID="ScriptManager1" runat="server">
<Scripts>
  <asp:ScriptReference Path="~/Scripts/jquery-2.0.3.min.js" />
</Scripts>
</asp:ScriptManager>
```
If ScriptManager didn't have a separate closing tag yet, you should add one now (and remove the slash / from the opening tag) or the code won't be added correctly.
2. Save and close the master page because you're done with it.
3. To try out the jQuery library, create a brand new Web Form in the Demos folder based on your custom template. Call the page .aspx and set its Title to jQuery Demo.
4. With the new page open in Markup View, add the following code to the Content block for cpMainContent:
```javascript
<asp:Content id="Content2" ContentHolderID="cpMainContent" runat="Server">
<input id="Button" type="button" value="button" />
<script>
$(document).ready(function() {
  $('#MainContent\').css('background-color', 'green');

  $('#Button1\').click(function() {
    $(('#MainContent\').css('background-color', 'red')
    .animate({width: '100px', height: '800px'});
  });
});
</script>
</asp:Content>
```

Just like many other programming languages, JavaScript (and thus jQuery) is case sensitive and quite sensitive to missing quotes, brackets, and parentheses, make sure you type this code exactly as shown here. Alternatively, you can copy and paste the code from the full source code that comes with this project.
Note while typing, IntelliSense pops up, helping you complete the code and giving information about various methods and parameters in tooltip. If it doesn't pop up, make sure you added the right <script> element to the master page. Also, try saving and closing all open documents and reopen jquery.aspx.
Save the changes to the page and press Ctrl+F5 to open it in your browser. Notice how the background color of the MainContent element has turned to green. Click the button and notice how the background color changes to red and how the MainContent element changes, ending up with a width of 100 pixels and a height of 800 pixels.
