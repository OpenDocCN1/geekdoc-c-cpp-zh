# How It Works

Most of what you have seen in this exercise should be familiar. You connected a DropDownList to SelectMethod similar to the way you set up the SelectMethod in ManagePhotoAlbum.aspx. Because the DropDownList will only display a read-only list of the photo albums and not paging itself, the return value is an IEnumerable<Picture>. An IEnumerable is the lightest to retrieve data from EF, as it carries no overhead to support operations like alterations of the collection, sorting, and so on. The ListView is also similar to what is discussed earlier in this chapter. However, instead of retrieving the ID of the photo album with a QueryString attribute, the code retrieves the ID from the DropDownList:

VB.NET
```vb
Dim photoAlbumID As Integer = Convert.ToInt32(PhotoAlbumList.SelectedItem)
```

C#
```csharp
int photoAlbumID = Convert.ToInt32(PhotoAlbumList.SelectedItem);
```

Instead of retrieving the ID from directly control, you could also add a parameter to the method and mark it with the Control attribute to automatically retrieve the value from the DropDownList. However, I found that when you apply that, the method for the ListView is called before the method for the DropDownList. In turn means the DropList has no data when the page loads first time. With the current implementation, photoAlbumID will always contain the ID of the selected item in the DropDownList.

The biggest difference from previous examples is the DataPager. As demonstrated in this exercise, paging is handled for you. All you need is to embed a DataPager control somewhere in the LayoutTemplate of the ListView and the rest is taken care of automatically. The GetData method for the ListView returns an IQueryable of Picture, the ListView and DataPager are able to further query the set of pictures. This paging (selecting only the subset of records that are the current page) is done through EF, in turn means that only the rows that are displayed from the database are being query executed effectively and as fast as possible.

If you place the DataPager outside the ListView, don't forget to hook it up to the ListView by the PagedControl ID. If you prefer links or buttons, you can set the Button property of the NextPreviousPageField to Link or Image, respectively. If you use a numeric pager, the NextPreviousPageField element to a NumericPagerField:
```xml
<asp:NumericPagerField PageText="..." PreviousPageText="..." />
```

In this exercise you set PageSize to 3 so it's easier to fill one page and see the page out uses a three-column layout for the Monochrome theme and a two-column layout for the DarkGrey theme, in real-world applications the PageSize is a bit higher, as is 10 or 20. Because the layout, you may want to select a value that is datable by button, such as 18.
