## Adding Existing Files

Not every file you create in your website has to be brand new. In some cases it makes sense to reuse files from other projects. For example, you might want to reuse a logo or a CSS file across sites. You can easily add existing files by right-clicking the website in the Solution Explorer and choosing Existing Item. In the dialog box that appears, you can browse for the files, and optionally select multiple files by holding down the Ctrl key. Finally, when you click Add, the files are added to the website. You can also copy and paste files from a folder on your disk to website in VS. Simply highlight the files in File Explorer, Ctrl+C to copy the files, switch to VS, click the Solution Explorer (or a subfolder of your site), and press Ctrl+V. The files are then copied into your website's folder.

However, there is an even easier way to add files to the site which can be a great time saver when you need to add existing files: drag and drop. The following Try Out shows how this works.

### TRY OUT Adding Existing Files to Your Site

1. In Windows, right-click your desktop and choose New Text Document. If you don't see this option, simply create a new document using Notepad and save it on your desktop.
2. Rename the file from styles.txt to styles.css. Make sure the .txt extension is replaced by .css. If you don't see the .txt extension and the icon of the file doesn't change (by default this is the same icon as a file with a gear symbol on it), Windows is configured to hide extensions for known file types. If that's the case, open Windows Explorer in Windows, click Folder and then Search Options. Switch to the View tab and deselect the option labeled Hide Extensions for File Types.
3. Rearrange VS so you can see part of the desktop with the CSS file as well. When you change the file extension from .txt to .css, Windows may give you warning that the file becomes unusable if you proceed. You can safely answer Yes to this question to continue.
4. Click the CSS file on the desktop and, while holding the mouse button, drag the file into the Solution Explorer and not other parts of VS. For example, when you drag it into the Document Window, VS simply opens the file for you, but doesn't add it.
5. When you release the mouse over your website or an existing file in the Solution Explorer, the CSS file is added to your site.

NOTE: If you are using Windows 7 and VS as an administrator, this might not work because Windows doesn't allow Windows Explorer and VS to communicate. In that case, add existing files using the Existing Item menu or use copy and paste.

## How It Works

Although this seems to be a simple exercise that uses basic skills, it serves to show that VS creates a copy of the file when it adds it to the site. The original styles.css file on the desktop is not affected when you make changes to the copy in VS. This way, it's easy to drag and drop files from existing websites into your new one without affecting the originals. The same applies to files you add using the Item dialog box in VS.

If you have added files to your website's folder outside of VS, they may not show up right away. You can get a fresh copy of the file list by clicking the Refresh button on Solution Explorer's toolbar.

## Organizing Your Site

Because many of the files make up your site, it's often a good idea to group them by function in separate folders. For example, all style files could go in a folder called Styles, .js files containing JavaScript could be in Scripts, user controls could in a Controls folder, and master pages could be stored in a folder called MasterPages. This is a matter of preference, but structured and well-organized sites are easier to manage and understand. The next Try Out explains how you can move files around into new folders to organize your site.

### TRY OUT Organizing Your Website

1. Right-click the Project site in the Solution Explorer and choose Add New Folder.
2. Type styles as the new folder name and press Enter.
3. Create another folder, called Controls. These two folders are used in the remainder of the book.
4. Drag the styles.css file that you added and drop it into the styles folder.

## How It Works

Structure and organization are important to keep your sites manageable. Although you may be tempted to add all of your files to the root of your project, it's better not to do so. With a very small site, you may notice no difference, but as your site begins to grow, you will eventually find it becomes harder to manage when it lacks structure. Placing related files in separate folders is the first step to organizing your site. Storing files of the same type in a single folder is the only way to optimize your site. In later chapters, you see that separate folders are also used to group files with similar functionality. For example, all files that are accessible only by an administrator of the site are grouped in a folder called Management.

The drag-and-drop features of VS make it easy to reorganize your site. Simply pick one file or multiple files and drop them in their new location.
