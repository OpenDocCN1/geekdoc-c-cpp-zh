TryUpdateModel(photoAlbum);
if (ModelState.IsValid)

The first line of code creates a new, empty instance of the PhotoAlbum class. This class has been created by EF when you added the Picture and PhotoAlbum tables to the EF diagram.

The second line is where all the magic happens. When you call UpdateModel(a method that has been added to the Page class), the Model Binder tries to fill the properties of the PhotoAlbum class with values that match the incoming request. It does this by consulting various Value Providers classes dedicated to supplying data from a variety of sources. ASP.NET reports many different value providers, including the FormValueProvider (which gets data from a form that the user submitted), a QueryStringValue(which uses the string of the current request to find values), a CookieValueProvider (retrieves data from cookies), a ProfileValueProvider (which retrieves data from the user's profile), and in this example, the only property that gets updated is the Name property, which is found using the FormValueProvider. ASP.NET can find this property because it has been defined as DataField in the Markup of the DetailsView:

```
<asp:BoundField Field="Name" HeaderText="Name" />
```

The Name value in the DataField attribute is important. This links the control (a TextBox) that the BoundField generates to the Name of the PhotoAlbum so the FormValueProvider can successfully retrieve the value that the user entered after the post.

At this point, the instance of the PhotoAlbum class (held in the photoAlbum variable) has been updated, and its Name property contains the value that you entered in the form.

Once UpdateModel has been called, you can check if the binding succeeded by calling ModelState.IsValid. This property returns false when you try to supply a non-numeric value for a numeric property on your object, for example. In other more advanced scenarios, the model state could also be invalid if the supplied data doesn't match your business rules, such as a required field that is left blank.

If the model state is valid, the code creates and starts a new instance of the PlanetWrixEntities context. It then Add on its PhotoAlbum collection, which adds the album to the internal collection of photo albums. When SaveChanges is called, the Entity Framework sees this is a new photo album and will insert it into the SQL Server database by using an INSERT statement. It retrieves the automatically generated ID of the new album and, if the Id property of the PhotoAlbum instance.
