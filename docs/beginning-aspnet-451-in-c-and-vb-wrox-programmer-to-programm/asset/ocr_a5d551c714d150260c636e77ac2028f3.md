7. In the root of the website, create a new Web Form called SignUp.aspx based on your custom template and give it a Title of Sign Up for a New Account at Planet Wrox.

8. Switch the page to Design View and from the Toolbox, drag a CreateUserWizard control into the main content area for the page. Save and close the page.

9. Open the Web.config file from the root of the site and add an <authentication> element with its attribute set to Forms as a direct child of the <system.web> element:

```
<system.web>
<authentication mode="Forms" />
</system.web>
```

10. Still in the Web.config file, take a look at the <connectionStrings> section. Notice how the NuGet package added a new connection string for you called DefaultConnection. You could leave this connection string there, and everything would work. However, with this connection string, .NET creates a new database and attaches to SQL Server. From a management perspective, it will be easier if your user data is stored in the same database as your reviews, genes, pictures, and photo albums. This is quite easy to accomplish, first, remove the connection string DefaultConnection and replace the value for the connectionString attribute on all four providers (Profile, Membership, Roles, and Session state) with the value of your Planet Wrox connection string (which should be PlanetWroxConnectionString). You should end up with configuration code that looks like the following. Note that I left out a lot of code and only show the code for the Membership provider attribute on all four providers that points to the Planet Wrox connection string:

```
<connectionStrings>
<add name="PlanetWroxConnectionString" connectionString="... />
<add name="PlanetWroxEntries" connectionString="... />
</connectionStrings>

<system.web>
  .. Other code here
  <membership defaultProvider="DefaultMembership">
    <providers>
      <add name="DefaultMembershipProvider"
           Other attributes here
           connectionName="PlanetWroxConnectionString1"
           enablePasswordRetrieval="false" enablePasswordReset="true"
           .. Other attributes here
      />
    </providers>
  </membership>
  .. Other code here
</system.web>
```

11. Save all your changes, go back to Login.aspx, and press Ctrl+F5 to open that page in your browser. You are greeted with a login box, as shown in Figure 1-4.
