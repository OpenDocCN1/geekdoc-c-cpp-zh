# How It Works

Links between pages are likely one of the most important elements in a web page, because they enable you to create a connection between a page in your site and another, whether that page lies on your site or a completely different server on the Internet. Simple links that appear anywhere on the page, the HTML <a> tag with an href attribute is the easiest to set up. When the user clicks a link, the browser requests the page specified in the href's value from the server and displays it. The double dots (..) in the href's value are to refer to the parent directory. The full href attribute means "go up one level in the folder hierarchy and then select the file Default.aspx. You see a lot more about links and how they work in Chapter 7.

You're not limited to linking to pages within your site. If you want to link to external pages instead, replace the href attribute value with the full address of the page, as shown in the following example:

```
<a href="http://www.wrox.com">Go to the Wrox homepage</a>
```

For external links, it's important to include the http:// prefix; otherwise, the browser goes looking for a file or folder called wrox.com on your own website.
