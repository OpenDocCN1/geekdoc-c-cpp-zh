# INTRODUCTION

TO BUILD EFFECTIVE AND ATTRACTIVE DATABASE-DRIVEN WEBSITES, you need two things: a solid and fast framework to run your web pages and a rich and extensive environment to create and program these web pages. With ASP.NET 4.5.1 and Visual Studio 2013 you get both. They together form the platform to create dynamic and interactive websites.

ASP.NET 4.5.1 builds on top of its popular predecessors ASP.NET 2.0, 3.5, 4.0, and 4.5. While maintaining backward compatibility with sites built using these older versions, ASP.NET 4.5.1 and Visual Studio 2013 introduce new, enticing features.

You'll also find many changes — small and large — in both the ASP.NET Framework and Studio. Some of these changes are the inclusion of Entity Framework (discussed in Chapter 14), the introduction of Browser Link in Chapter 18 and the introduction of the Publisher Wizard for Web Sites, discussed in Chapter 19.

If you haven't used Visual Studio 2012 with ASP.NET 4.5 yet, you'll also appreciate the improved CSS and JavaScript editors (discussed in Chapter 3 and Chapter 10, respectively), the inclusion of NuGet (Chapter 11), and the Page Inspector (Chapter 18), all of which were added in VS 2012 VS 13 builds on of.

If you're familiar with earlier versions of ASP.NET, you'll be happy to find many things in the new version of the framework that will make your life as a developer easier. I mention and discuss these features throughout this book where appropriate. For a complete list of all features in ASP.NET, check out the following white paper at the official ASP.NET website:

www.asp.net/visual-studio/overview/2013/release-notes

If this link no longer works by the time you read this book, search www.asp.net for: "What's new in ASP.NET 4.5.1."

Probably the best thing about Visual Studio Express 2013 for Web is its price: it's available for free. This makes Visual Studio and ASP.NET probably the most attractive and compelling web technologies available today.

# WHO THIS IS FOR

This book is for anyone who wants to learn how to build rich and interactive websites that run on the Microsoft platform. With the knowledge you gain from this, you create a great foundation to build any type of website, ranging from simple hobby-related websites to sites that may be created for commercial purposes.
