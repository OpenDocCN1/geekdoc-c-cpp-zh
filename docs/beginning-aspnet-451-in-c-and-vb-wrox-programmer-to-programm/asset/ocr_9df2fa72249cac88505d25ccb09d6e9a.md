7. Save the changes you made to inherit any open page and browse to Login.aspx again. If everything worked out as planned, the error should be gone and you now see the login page.

Remember, though, that all other pages in your site will throw an error when you try to access them. The fix is easy; give them all a valid Title Title attribute in their page directive, you don't need to do this manually. For pages with an empty Title="" attribute, you can quickly do this by searching for Title=" and replacing it with something like Title="Planet Wrox". For pages other than the demo pages you created so far, you're better off giving a unique title, clearly describing the content it contains.

# How It Works

By default, all your pages inherit from the Page class defined in the System.Web.UI namespace. This gives them the behavior required to make them as web pages that can be requested by the browser and processed by the server. Because the inheritance model in .NET enables you to create a chain of classes from each other, you can easily insert your own base page class between a page and the standard Page class. You can do this by changing the Inherits statement (in C#) to your new BasePage:

# VB.NET

```
Partial Class Login
Inherits BasePage
```

# C#

```
public partial class Login : BasePage
```

Inside this new BasePage class you add an event handler that is called when the class fires its PreRender event. As you've learned, this event is raised quite late in the page's life cycle, when the entire page is set up and is rendered to the client:

# VB.NET

```
Private Sub Page_PreRender(sender As Object, e As EventArgs) Handles Me.PreRender
  ' Implementation here
End Sub
```

# C#

```
private void Page_PreRender(object sender, EventArgs e)
{
  // Implementation here
}
```

Note that Visual Basic uses the Handles keyword to tell the compiler that the Page_PreRender method will be used to handle the event. In C#, you need to hook up this handler manually. A good place to do this is in the class's constructor:

```
public BasePage()
{
  this.PreRender += Page_PreRender;
}
```
