6. Click Next and then Final the Configure Data Source wizard.

7. Select the new SqlDataSource (called SqlDataSource2) in Design View and change its ID to the GenreDataSource using the Properties Grid it's easier to recognize in the page.

8. Switch to Markup View, locate the InsertItemTemplate for the Genre of the DetailsView, and remove its contents (the TextBox control). At the place where you removed the TextBox, add a DropList by dragging it into the Markup View. Your code looks like this:

```
<asc:TemplateField HeaderText="Id" SortExpression="Genre">
<EditItemTemplate>
<asc:TextBox Id="TextBox4" runat="server"
Text="{# Bind("Genre")}" /></asc:TextBox>
</EditItemTemplate>
<InsertItemTemplate>
<asc:DropDownList Id="DropDownList1" runat="server">
</asc:DropDownList>
</InsertItemTemplate>
</asc:TemplateField>
```

9. Switch to Design View, right-click the DetailsView, and choose Edit Template Field[4] - Genre, as seen in Figure 13-20. If you do not see this menu item, you may need to click one of the rows with controls first — such as the summary row — to put the focus on the DetailsView correctly.
