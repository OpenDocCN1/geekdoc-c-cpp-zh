

# 查找结果窗口

VS 的查找和替换功能在管理站点内容时是无价的工具。你经常需要在当前文档中甚至整个站点中替换某些文本。查找文件（Ctrl+Shift+F）和替换文件（Ctrl+Shift+H）都会在其结果输出到查找结果窗口中，如图 1-13 所示。

由于同时打开多个信息窗口可能会占用宝贵的屏幕空间，因此最好将它们停靠。这样，一次只有一个窗口可见，同时你仍能快速访问其他窗口。你将在下一部分学习如何自定义 IDE，包括窗口的停靠。

## 自定义 IDE

尽管 Visual Studio 及其工具窗口的标准设置非常实用，但你很可能希望按照自己的喜好自定义 IDE。你可能希望将某些窗口移动到更容易到达的位置，或者你可能希望打开经常使用的额外窗口。Visual Studio 完全可自定义，使你能够调整 IDE 的每一个细节。在下一节中，你将学习如何执行最常见的自定义任务。

### 重新排列窗口

为了让每个窗口都位于应有的位置，你可以在主 IDE 中拖放它们。只需抓住窗口的标题栏或将其拖向新位置即可。一旦开始拖动，你会看到 Visual Studio 会给出提示，显示窗口将结束的位置（见图 1-14）。

如果你拖到中间指示器两侧的四个正方形指示器之一上方，窗口将被停靠在现有窗口旁边。一旦放下，窗口就会弹出到其新位置。如果你将其放在大指示器中间的正方形上，窗口将与该窗口一起停靠，共享相同的屏幕空间。每个窗口都有自己的选项卡，如图 1-14 底部所示的窗口。

除了在 IDE 中将窗口与其他窗口一起停靠外，你还可以拥有浮动窗口。要将停靠的窗口更改为浮动窗口，请将其从当前位置拖出，并在不触及屏幕上的视觉提示的情况下将其放在 IDE 中的某处。你也可以从主菜单中选择 Window -> Float，或右键单击窗口的标题栏并选择 Float。

要将浮动面板恢复到之前的停靠位置，请右键单击其标题栏并选择 Dock，或从菜单中选择 Window -> Dock。确保不要为工具窗口（如 Toolbox 或 Solution Explorer）选择 Dock as Tabbed Document，否则它们会进入主 Document 窗口。这使得在使用打开的文件的同时使用这些工具变得困难，因为这两个窗口共享相同的空间。

### 修改工具箱

你也可以修改工具箱。默认情况下，项目按字母顺序排序，但你可以使用拖放重新排序。要执行此操作，请打开工具箱（按 Ctrl+Alt+X），拖动一个项目（例如标准类别下的 TextBox）到不同位置。你也可以通过右键单击它们并从上下文菜单中选择 Delete 来从工具箱中删除项目。或者，如果项目丢失，你可以通过从同一菜单中选择 Reset Toolbox 来恢复工具箱。

你还可以向工具箱添加自己的项目。最常见的用途是代码片段。只需在 Document 窗口中突出显示一些文本或代码并将其拖到工具箱即可。然后你可以右键单击该项目并选择 Rename Item，为其赋予更具意义的名称，以便轻松识别。

为了避免用自己的代码片段使工具箱变得杂乱，请考虑为它们创建一个单独的类别。你可以通过从工具箱的右键单击菜单中添加 Add Tab 来执行此操作。输入名称并按 Enter 键，你的工具箱选项卡即可使用。

## TRY IT OUT 自定义 IDE

在此练习中，你练习在 VS IDE 中打开和重新排列窗口。不要害怕弄乱东西。本章稍后会给出有关如何将 IDE 重置为首次打开时的状态的说明。

- 1. 如果你自上一个 Try It Out 以来关闭了网站，请再次打开它，或使用文件菜单创建一个新网站。
- 2. 从视图菜单中选择错误列表以打开错误列表窗口。如果看不到错误列表项，请先选择工具 > 选项 > 专家设置。注意错误列表默认停靠在文档窗口下方。
- 3. 从同一视图中选择任务列表。默认情况下，它与错误列表停靠在同一空间中，两者旁边都有选项卡。
- 4. 单击任务列表的选项卡，同时按住鼠标按钮，将任务列表从其位置拖向文档窗口的方向。一旦释放窗口，它将作为浮动窗口出现在 IDE 中。要恢复窗口，请将其拖回错误列表的中心正方形。要更改选项卡组中选项卡出现的顺序，请将选项卡拖到其他选项卡上并在所需位置释放它
- 5. 如果你愿意，可以对 IDE 中默认可见的其他窗口或在视图菜单下找到的窗口重复上述步骤。花一些时间熟悉所有不同的窗口以及如何在屏幕上排列它们。因为你将在本书的其余部分使用这些窗口，所以熟悉它们的位置是很好的。
- 6. 接下来，从解决方案资源管理器中双击打开 ControlsDemo.aspx（或添加新的 ASPX 以创建新网站）。当页面打开时，工具箱会自动显示。如果没有，请按 Ctrl+Alt+X 显示它。
- 7. 右键单击工具箱并选择添加选项卡。键入 HTML Fragments 作为其新名称并按 Enter 键。这会在工具箱中添加一个新条目，其行为与其他条目相同。
- 8. 在文档窗口显示你的 ASPX 页面处于标记视图时，在打开的 <div> 标签后直接键入 <h1>。请注意，Visual Studio 会自动插入关闭的 </h1>。你应该在标记视图中得到如下代码：

```
<div id="form" runat="server">
<div>
  <h1></h1>
</div>
```
- 9. 突出显示打开和 <h1> 标签，然后将选择从标记视图窗口拖到你在步骤 7 中创建的新工具箱选项卡上。选择将显示为 Text: <h1></h1>。
- 10. 右键单击你刚刚创建的工具箱项，选择重命名项，并键入 Heading 1 作为名称。
- 11. 再次将光标放在文档窗口中，然后按 Ctrl+K 紧接着按 Ctrl+D 以格式化文档窗口中的文档。或者，从主菜单中选择编辑 > 格式化文档。这会根据你在文本编辑器对话框中设置规则格式化文档。格式化也适用于许多其他文档类型，包括 C# 和 VB.NET 代码以及 CSS 和 XML 文件。

从现在开始，每当你在标记视图中需要标题时，只需将光标放在文档窗口中你希望标题出现的位置，然后双击工具箱中的相应标题即可。

> 注意 本练习作为向工具箱添加代码的示例。对于 <h1> 元素，你可能更喜欢直接在代码编辑器中键入代码。或者，你也可以使用代码片段。在编辑器中输入 H1 并按 Tab。Visual Studio 会将代码扩展为 <h1> 并将光标定位在两个标签之间，以便你立即开始键入标题。

### 它是如何工作的

Try Out 中的大多数步骤都是不言自明的。通过打开你在构建网站时经常需要的几个窗口。你使用了 IDE 的拖放功能来根据个人喜好重新排列窗口布局。

然后你向工具箱中的控件选项卡添加了一个 HTML 片段。当你将任何标记拖到工具箱时，Visual Studio 会为其创建一个工具箱项，其中包含所选标记。每当你需要在页面中复制该标记时，只需双击该项或将其从工具箱拖到标记视图即可。这对于你经常使用的 HTML 片段来说是节省时间的绝佳方法。你通常将此技术用于较大的代码块；对于 <h1> 这样的元素，Visual Studio 有一个更好的工具，称为 Snippets，你将在本书后面学习。

最后你使用了 Visual Studio 的文档格式化选项来更改文档中代码的布局。这有助于保持代码井井有条，易于阅读。你可以使用通过工具 → 选项访问的选项对话框完全更改代码的格式。展开路径文本编辑器 -> HTML（Web 表单）→ 格式化，然后单击标记选项。

除了布局和工具箱之外，Visual Studio 还允许你在 IDE 中自定义更多内容。以下部分解释了如何自定义另外三个重要的 IDE 功能：文档窗口、工具栏和键盘快捷键。

### 自定义文档窗口

Visual Studio 在文档窗口中文本的显示方式上为你提供了很大的灵活性。你可以更改诸如字体大小、字体颜色，甚至文本的背景颜色等内容。你可以通过选择工具 → 选项，然后选择环境来访问字体和颜色设置。或者，按 Ctrl+Q 将焦点放在 IDE 顶部非常顶部的快速启动文本框上。然后键入 font 并按 Enter 选择突出显示的项目
