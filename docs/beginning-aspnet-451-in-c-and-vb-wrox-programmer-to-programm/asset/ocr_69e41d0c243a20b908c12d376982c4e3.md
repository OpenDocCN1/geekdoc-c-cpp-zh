# ASP.NET Web Forms Site

This template enables you to start a basic ASP.NET web site. It contains a number of files and folders to jump-start the development of your site. The different file types are discussed later in this chapter. The special App_Data folder and the functionality of the pages in the Account folder are discussed later in this book. This template uses an external framework called Bootstrap, a front-end framework that helps you build websites that look great on multiple devices such as desktops, tablets and phones. Unfortunately, a number of the controls that ship with ASP.NET (such as the Menu control you will see in Chapter 7) don't render properly when using Bootstrap. That is why I decided not to use this framework in this book, but instead to focus on all the functionality that ships with ASP.NET. For your projects, you could use this Visual Studio template with Bootstrap, but you'll need to implement alternatives for controls like the Menu. You can learn more about Bootstrap at http://getbootstrap.com.
