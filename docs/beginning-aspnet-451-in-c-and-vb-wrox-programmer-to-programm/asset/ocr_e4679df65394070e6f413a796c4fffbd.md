# WHAT THIS BOOK COVERS

This book teaches you how to create a feature-rich, data-driven, and interactive website called Planet Wrox. Although this is a mouthful, you'll find that with Visual Studio 2013, developing a website that isn't as hard as it seems. You'll see the entire process of building a website, from installing Visual Studio in Chapter 1 all the way to putting up your website on a live server in Chapter 19. The book is divided into 19 chapters, each dealing with a specific subject:

+   Chapter 1, "Getting Started with ASP.NET 4.5.1." In this chapter you will see how to obtain and install Visual Studio 2013 for Web, the free version of Visual Studio 2013 to build ASP.NET websites. You are also introduced to HTML5, the latest standard for defining web pages. The chapter closes with an overview of the customization options that Visual Studio gives you.

+   Chapter 2, "Building an ASP.NET Website." This chapter shows you how to create a new website and how to add new items to pages to. Learning how to create a well-structured site, you also see how to use the numerous tools in Visual Studio to create HTML and ASP.NET pages.

+   Chapter 3, "Designing Your Web Pages." Visual Studio comes with a host of tools that enable you to create well-designed and attractive web pages. In this chapter, you will see to make good use of these tools. Additionally, you will learn about CSS, the language that is used to format web pages.

+   Chapter 4, "Programming with ASP.NET Server Controls." ASP.NET Server Controls are one of the most important concepts in ASP.NET. They enable you to create complex and feature-rich websites with the large number of server controls that are available, explains what they are used for, and shows you how to use them.
