4. Add a RequiredFieldValidator in the EditItemTemplate and the InsertItemTemplate of both the Title and the Summary rows. You can drag and drop it from the Toolbox in Markup View or edit the code manually. Using a code snippet makes this even easier: move your pointer on an entry, new line below the TextBox, type requiredfieldvalidator, and press Tab. VS inserts a RequiredFieldValidator and you automatically assigns the ControlValidate property with the ID of the TextBox.

Make sure you all validators refer to the TextBox controls in the template by setting the ControlValidate property and providing a useful error message. When you're done, the summary field should look like this:
<asp:Template>
  <EditItemTemplate>
    <asp:TextBox Id="TextBox2" TextMode="MultiLine" Width="500" Height="100"
      runat="server" Text='{# Bind (Summary)}'></></asp:TextBox>
    <asp:RequiredFieldValidator ControlValidate="TextBox2" ErrorMessage="Enter a summary" />
  </EditItemTemplate>
  <InsertItemTemplate>
    <asp:TextBox Id="TextBox2" TextMode="MultiLine" Width="500" Height="100"
      runat="server" Text='{# Bind (Summary)}'></></asp:TextBox>
    <asp:RequiredFieldValidator ControlValidate="TextBox2" ErrorMessage="Enter a summary" />
  </InsertItemTemplate>
</asp:Template>

The Title and Body fields should look similar to Summary. The TextBox for the Title field doesn't have the TextMode, Width, and Height properties applied, where the Body field is missing the RequiredFieldValidator. Other than that, the fields should look similar to Summary field.

# VB.NET

```vb
Private Sub EndEditing()
    Response.Redirect("Reviews.aspx")
End Sub

Protected Sub ItemInserted(sender As Object, e As DetailsViewEventArgs)
    If e.Exception Is Nothing Then
        EndEditing()
    End If
End Sub

Protected Sub ItemInserting(sender As Object, e As DetailsInsertEventArgs)
    e.Values("UpdateDateTime") = DateTime.Now
End Sub

Protected Sub ItemUpdated(sender As Object, e As DetailsUpdatedEventArgs)
    If e.Exception Is Nothing Then
        EndEditing()
    End If
End Sub

Protected Sub ItemUpdating(sender As Object, e As DetailsUpdateEventArgs)
    e.Values("UpdateDateTime") = DateTime.Now
End Sub
```

# C#

```csharp
private void EndEditing()
{
    Response.Redirect("Reviews.aspx");
}

protected void ItemInserted(object sender, DetailsViewEventArgs e)
{
    if (e.Exception == null)
    {
        EndEditing();
    }
}

protected void ItemInserting(object sender, DetailsInsertEventArgs e)
{
    e.Values["UpdateDateTime"] = DateTime.Now;
}

protected void ItemUpdated(object sender, DetailsUpdatedEventArgs e)
{
    if (e.Exception == null)
    {
        EndEditing();
    }
}

protected void ItemUpdating(object sender, DetailsUpdateEventArgs e)
{
    e.Values["UpdateDateTime"] = DateTime.Now;
}
```
