To mitigate the problem, you should keep the IDs of your ContentHolder and Content controls as short as possible. To improve readability, this book uses longer names, like cpContent. However, in your sites, you could reduce this to cm or cmc to save some bandwidth on every request.

> NOTE ASP.NET 4 introduced a new feature called ClientID that helps minimize the problems typically associated with changing client-side IDs. You will learn about this feature in Chapter 8.

Master pages enable you to define the general look and feel of your site in a single location, improving the consistency and maintainability of your site. However, there is another way to improve consistency: customize the behavior of the pages in your website. You can do this with a so-called base page, which is discussed next.

# USING A CENTRALIZED BASE PAGE

In Chapter 5 you learned that, by default, all ASPX pages derive from a class System.Web.UI.Page. This means all of your pages have the behavior defined in this class.

In some cases this behavior is not what you want and you need to add some stuff to the mix. For example, you may have the need to add some behavior to each and every page in your site. Instead of adding this behavior to each and every page, you can create a custom base page. All the pages in your site can then inherit from this intermediate page instead of the standard base page class. To have your pages inherit from this base page, you need to do two things:

+   - Create a class that inherits from System.Web.UI.Page in the App_Code folder of your website.
- Make the pages in your site inherit from this base page instead of the standard base page class.

In an upcoming exercise you will create a new base class inside the App_Code folder. For now, the sole purpose of this class is to control the Title of the page at run to stop pages from showing an empty or a meaningless title like "Untitled Page" making it to the browser. Giving your pages a unique and helpful title helps the search engines index them, so it's recommended to always include a title in your web pages. Checking the title programmatically is relatively easy to do, which enables you to focus on the concept of inheritance rather than on the actual code. In the section that discusses themes later in this chapter, you will modify the base page once more, to retrieve the user's preference for a theme.
