When you fill in the form controls and click the Save button, the code in the SaveButtonClick
method fires. If you interact with the database through EF. Then the _id variable does not contain an ID of
anexisting review (see how the ID is retrieved), a new Review is created and added to
the Reviews collection of the entities object. This would be the case when you are creating a brand new
review using the Insert New Review.

# VB.NET

```
myReview = New Review()
myReview.DateTime = DateTime.Now
myReview.UpdateTime = myReview.DateTime
myEntities.Reviews.Add(myReview)
```

# C#

```
myReview = new Review();
myReview.DateTime = DateTime.Now;
myReview.UpdateTime = myReview.DateTime;
myEntities.Reviews.Add(myReview);
```

Because the review creates CreateTime and an UpdateTime, this code sets both. Notice how
the Update is filled with the CreateTime so both contain the same date and time,
indicating the item has not been modified.

myReview = (from r in myEntities.Reviews
