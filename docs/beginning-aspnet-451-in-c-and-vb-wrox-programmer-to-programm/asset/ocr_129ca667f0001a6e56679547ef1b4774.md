# Container Controls

Often it's desirable to group related content and controls. You can do this by putting the controls (or other markup) in one of a container controls, like the Panel, the PlaceHolder, the MultiView, or the Wizard. For example, you can show a number of controls at once. Instead of hiding each control separately, you simply hide the entire container that all the individual controls and markup. Both of these controls have their own advantages and disadvantages. The good thing about the PlaceHolder control is that it has no HTML of its own page, so you can use it as a container without any side effects in the final page. However, it lacks design-support, making it hard to manage the controls inside the PlaceHolder at design time VS. In contrast, the MultiView enables you to enable all controls and other content it contains but renders itself as a <div>. In many cases this isn't a problem, and can even be useful as you that div using CSS at the control, so usually you're best off with the Panel control because of its design-time support.

The MultiView (which can contain one or more <asp:View> elements) and the Wizard are similar in that they enable you to split a long page into multiple areas, making it easy to fill in a long form, for example. The Wizard has built-in support for moving from page to page using Previous, Next, and Finish buttons, while the MultiView must be controlled programmatically.
