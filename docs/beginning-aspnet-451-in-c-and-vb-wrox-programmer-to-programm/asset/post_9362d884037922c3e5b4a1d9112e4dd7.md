Next up is the Code Behind. I'll discuss saving the form for a new review in the database
first. After that, I'll show you how to load an existing review from the database and prepopulate
tform (or rather, the form).

When you fill in the form controls and click the Save button, the code in the SaveButtonClick
method fires. If you interact with the database through EF, then the _id variable does not contain an ID of
an existing review (see how the ID is retrieved), a new Review is created and added to
the Reviews collection of the entities object. This would be the case when you are creating a brand new
review using the Insert New Review.

## VB.NET

```vbnet
myReview = New Review()
myReview.DateTime = DateTime.Now
myReview.UpdateTime = myReview.DateTime
myEntities.Reviews.Add(myReview)
```

## C#

```csharp
myReview = new Review();
myReview.DateTime = DateTime.Now;
myReview.UpdateTime = myReview.DateTime;
myEntities.Reviews.Add(myReview);
```

Because the review creates CreateTime and an UpdateTime, this code sets both. Notice how
the Update is filled with the CreateTime so both contain the same date and time,
indicating the item has not been modified.

If the _id variable contained a review ID (which means an existing review is being edited and saved),
it's queried from the database with a LINQ to Entities query:

## VB.NET

```vbnet
myReview = (From r in myEntities.Reviews
            Where r.Id = _id
            Select r).Single()
myReview.UpdateTime = DateTime.Now
```

## C#

```csharp
myReview = (from r in myEntities.Reviews
            where r.Id == _id
            select r).Single();
myReview.UpdateTime = DateTime.Now;
```

Whether or not an ID was passed to this, at this stage the myReview variable contains a Review
instance. The remaining code then fills the review's properties by retrieving them from the relevant
form controls. For the genre, the code directly assigns the Genre property by querying a complete Genre and assigning it to the Genre property of the Review instance. This works because
the model has support for foreign keys, as you learned in the preceding chapter.

Finally, when the object is fully set up, the code calls SaveChanges on the PlanetWroxEntities object. This eventually sends a SQL INSERT or UPDATE instruction to the database to insert a new or update the existing Review row. With the data source control, calling SaveChanges may incur an error. Chapter 18 digs deep into handling errors that may occur in the code. After SaveChanges has been called, the user is redirected to the Reviews.aspx page using Response.Redirect.

## VB.NET

```vbnet
myEntities.SaveChanges()
Response.Redirect("Reviews.aspx")
```

## C#

```csharp
myEntities.SaveChanges();
Response.Redirect("Reviews.aspx");
```

Once you've saved a review in the database, you can edit it. Once you you click one of the existing reviews in the list at Reviews.aspx, you're taken to the Add/Edit page with the ID of the review in the query string. For example, browsing to http://localhost:1049/Management/AddEdit?Id=6 enables you to edit the Death Magic album by Metallica. The page is able to detect the ID in the query string using the Page_Load:

## VB.NET

```vbnet
If Not String.IsNullOrEmpty(Request.QueryString.Get("Id")) Then
    _id = Convert.ToInt32(Request.QueryString.Get("Id"))
End If
```

## C#

```csharp
if (!String.IsNullOrEmpty(Request.QueryString.Get("Id")))
{
    _id = Convert.ToInt32(Request.QueryString.Get("Id"));
}
```

Because this _id variable is assigned a value in Page_Load, it can be used to load an existing item to display in the form, but also to get the item from the database in the SaveButton.Click event (which you saw earlier).

If there is an ID (_id is a value other than -1) and the page is not posted back, the code sets up a new PlanetWroxEntities instance using a using block and queries the Review instance using the following LINQ to Entities:

## VB.NET

```vbnet
Dim review = (From r in MyEntities.Reviews
              Where r.Id = _id
              Select r).SingleOrDefault()
```

## C#

```csharp
var review = (from r in MyEntities.Reviews
              where r.Id == _id
              select r).SingleOrDefault();
```
