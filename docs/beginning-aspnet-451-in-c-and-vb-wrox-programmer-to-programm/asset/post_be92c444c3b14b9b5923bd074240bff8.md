# How It Works

The different style elements you created in step 5 are converted into their CSS and HTML equivalents. For example, RowStyle and AlternatingRowStyle have their BackColor set to a different background color:

```
<RowStyle BackColor="#FF3FB" />
<AlternatingRowStyle BackColor="White" />
```

When the control renders its HTML, it applies these backgrounds to the table row of the items and alternating items:

```
<tr style="background-color:#FF3FB;"> ... </tr>
<tr style="background-color:White;"> ... </tr>
```

The same principle is applicable to the other styles in the GridView.
If you look at the source of the page, you see a lot of page bloat, because each row has its properties set. This increases the page size, especially with larger results displayed in the GridView. To decrease the page size and improve the performance of the page, you could move the style definitions to a page theme and then use CSS and jQuery instead. You see how to do this.

# TRY OUT Creating Advanced Style Solutions

In this Try Out, you move the style properties for the Genres.aspx page to a separate skin file. You also move the inline style information to a CSS file. Then you use jQuery to separate data and appearance of the page even further.

- 1. On the Solution Explorer, right-click the App_Themes folder, choose Add > New Folder, and type Management as your new name.
- 2. Right-click this new folder and choose Add > Add New Item. Add a skin file called GridView.skin. You should end up with a Solution Explorer looking like Figure 15-5.

- 3. Open the Genres.aspx page in Markup View and delete all the styles you created in the previous exercise except the HeaderStyle, the PagerStyle, the SortedAscendingHeaderStyle, and the SortedDescendingHeaderStyle. From the four remaining styles, remove all attributes and replace them with a single Css named after the style and prefixed with GridView. You should end up with the following styles:

```
<HeaderStyle Css="GridViewHeaderStyle" />
<PagerStyle Css="GridViewPagerStyle" />
<SortedAscendingHeaderStyle Css="GridViewSortedAscendingHeaderStyle" />
<SortedDescendingHeaderStyle Css="GridViewSortedDescendingHeaderStyle" />
```

Don't worry if VS adds error lines under the CSS class names. Because the CSS classes aren't defined, you can find them later, add them to the CSS file, where VS still can't find them.

- 4. Select the styles in the code editor and delete all existing (the comment text you saw earlier), and cut them to the clipboard using Ctrl+X. Open the GridView.skin file, and paste the styles into the skin file.

- 5. Wrap the styles in an <asp:GridView> element with its runat set to server and as CssClass. Don't add an ID attribute, because skin files don't need this. You should end up with this:

```
<asp:GridView runat="server" CssClass="GridView">
    <% styles go here %>
</asp:GridView>
```
