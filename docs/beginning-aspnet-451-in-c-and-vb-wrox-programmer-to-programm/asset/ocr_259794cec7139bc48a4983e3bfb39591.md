6. In the Apply Styles window, right-click Inline Style again, and choose Remove Inline Style from the context menu. This removes the style attribute from the h1 element.

7. From the main menu, choose View Manage Styles. Make sure the window is placed before the Document and not docked in the Document. Under the Current Page item, locate the Instruction selector.

8. Click the ...Introduction selector, and drag it into the area for Styles.css, for dropping it after the h1 selector. Note that VS draws lines between the selectors as you hover over them to indicate the point where the selector will end. Figure 3-26 shows how the ...Introduction is dragged from the current page into Styles ...css, between the h1 and #PageWrapper selectors.

9. Once you drop the selector in the Styles.css section of the Manage Styles window, the associated style is removed from your current page, and then inserted in Styles.css. Because that file is included in your current page using the <link /> element, you see no difference in Design View. You can remove the <style> element from Default.aspx, if it's not needed anymore.

10. If you've already moved the two h1 selectors, open Styles.css and scroll down to the end of the file. Copy the two lines for the padding and margin properties to the clipboard and delete the entire selector. Scroll up in the file and paste the two CSS rules inside the other h1 selector. You should end up with this code:

```
h1
{
  font-size: 20px;
  padding: 0;
  margin: 0 0 10px 0;
}
```

11. Save any changes you may have and then open Default.aspx in your browser by pressing Ctrl+F5. Note that the paragraphs haven't changed and still use the same blue and italic font.

# How It Works

Unfortunately, VS doesn't allow you to move inline styles to external style sheets. However, by creating a copy of the existing style, and deleting the original inline style, you can achieve the same effect. Moving embedded or external style between files is easy. You can simply drag a style from one file to another, and VS will automatically move the code for you. This makes it easy to organize your CSS. Instead of leaving all your embedded CSS in your page because you're afraid to touch it, you can simply drag and drop it into an external file. This makes it easier to reuse those styles in other pages, decreasing page size and page bloat and making your site a lot easier to manage. Obviously, it's important that you are moving the CSS to is attached to the pages you're working with.
