# How It Works

You have two important things to look at in this exercise. First of all, there is the LINQ query that is used to get the genres and reviews from the database. This query uses Include("Reviews") to prevent lazy loading as you earlier create a new object type with two properties: the Name of the Genre as a String and a collection of Review objects called Reviews. The class diagram for the new object type could look like Figure 1-6.

These Name and Reviews are used in the second important part: the Repeater control with the nested bullet list. First, take a look at the Repeater:

```
<Repeater ID="Repeater1" runat="server">
<ItemTemplate>
<asp:Literal ID="Literal" runat="server"
Text="+# Eval("Name") %></asp:Literal><h3></h3>
<!-- BulletedList here -->
<asp:BulletedList
></ItemTemplate>
</Repeater>
```

Although you haven't worked with the Repeater control before, it may look familiar, because it works in a manner similar to the other data controls. Within the <ItemTemplate> you define the property that you want repeated for each item in the data source. Using Eval you can get the value of the Name property and assign it to the Literal, which is wrapped in a pair of <h3>. A similar construct is used for the BulletedList to find a DataSource:

```
<asp:BulletedList ID="BulletedList1" runat="server" DisplayMode="Text"
DataSource="+# Eval("Reviews") %> DataField="Title" />
```
