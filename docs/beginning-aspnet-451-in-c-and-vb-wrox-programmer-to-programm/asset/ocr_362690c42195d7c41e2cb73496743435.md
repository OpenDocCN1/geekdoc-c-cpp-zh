> **COMMON MISTAKES** If your Design doesn't look like this, but looks much closer to the file it ends up in the browser, you may still have the styleSheetTheme set in the Web.config file. Also, you may have more or fewer options selected in the View -> Visual Aids or View -> Formatting Marks, which may affect your display.

+   1. Switch to Markup View and locate the @ Register directive at the top of the file. If the Src attribute starts with two dots, change them to a tilde (~).

```
<@ Register Src="Controls/Banner.ascx" TagName="Banner" TagPrefix="ucl" %>
```

+   2. Save the changes.

+   3. Some browsers automatically draw a border around an image when it's placed within a hyperlink tag. To remove that border, add the following code to both themes' CSS files:

```
img {
  border: 0;
}
```

+   4. Save all changes, right-click Default.aspx in the root of your site in the Solution Explorer, and choose View in Browser.

+   5. The banner is now displayed below the title. Switch to the other theme and you'll see the same banner appear. When you click the banner, a new window is opened that takes you to the site you linked to. If you don't see the banner appear at all, check if you are running ad-blocking software on Windows or in your browser. For example, Firefox has an add-on called Adblock Plus that may block the banner in your web page based on its dimensions.
