Setting the Title and MetaDescription is good for your users and for the ranking of your page in search engines. Title when you bookmark a page, a clear title helps the user find your page again. Search engines like Google and Bing use the title in evaluation of what the page is about. They use the text you set in the MetaDescription (which ends up as a <meta name="description"> /> element in the <head> section of the page's HTML) to present the results to the user. This means the text you enter is your first point of contact with a user who uses a search engine. It's an important piece of information. Rather than using the Summary property for this purpose, you could add an additional column (called SearchEngineDescription, for) the database. You then need to bring this column into the ASP.NET Entity Data Model in the Entity Designer and choosing Update Model from Database. Once you've added this property to the page, don't forget to change the edit pages in the management section (AddEditReview.aspx or AddEditReviewHandCoded.aspx) to support this property as well. Finally, in the ViewDetails.aspx page you can assign its to the MetaDescription property of the Page class.

Besides the MetaDescription, the page class extended with a MetaKeywords property in ASP.NET 4. This property works more or less the same as the MetaDescription and enables you to set the keys for the page. The importance of keywords to influence search engine ranking is heavily debated (many say they are not used by search engines at all, it can't hurt to try them). You could add keywords to the database and by following the same steps as outlined for the SearchEngineDescription property. For more tips on search engine optimization (SEO), consider a guide to Wrox's Professional Search Engine Optimization with ASP.NET: A Developer's Guide to SEO (ISBN: 978-0-470-13147-3).

The ViewDetails.aspx page now performs pretty well! The first time it loads, the item is retrieved from the database and stored in the cache. On subsequent visits to the page, the data is no longer accessed but the item is retrieved from the much faster cache.
