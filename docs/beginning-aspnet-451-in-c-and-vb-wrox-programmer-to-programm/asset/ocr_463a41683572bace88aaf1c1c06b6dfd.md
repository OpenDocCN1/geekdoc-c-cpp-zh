Some of these data types enable you to specify the length. When you define a column of type char, nchar, varchar, or nvarchar you need to specify the length in characters. For example, an nvarchar(10) enables you to store a maximum of 10 characters. For char and nchar, the value you put in a column is padded with spaces if the value is shorter than the maximum length.
