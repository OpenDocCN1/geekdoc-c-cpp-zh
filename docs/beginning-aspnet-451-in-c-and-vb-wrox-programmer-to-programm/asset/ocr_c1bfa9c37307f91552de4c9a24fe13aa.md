Notice how the code uses the read-only FullName property to avoid coding
the logic of concatenating the two names. You can't override any
method you want to. For a method to be overrideable, the parent
class needs to mark the method with the keyword virtual (in C#) or
Override (in VB.NET).

Object inheritance in .NET enables you to create a hierarchy of objects that
enh, or add functionality to, other objects. You can start
with a generic base class (object). Other classes can then inherit from
this class, adding specialized behavior. If you need even more
classes, you can inherit from the class that inherits from Object,
creating a hierarchy of classes that keep more specialized. The
principle works for many classes in the .NET Framework, including the
Page class. You not realize it, but every ASPX page you create in VS
is actually a class that inherits from the System.Web.UI.Page. This
Page class in turn inherits from TemplateControl, which inherits from
Control, The entire hierarchy is shown in
Figure 5-8. At present you see the class myWeb, which could be a
Code Behind of a page such as MyWeb.aspx.

![](bbox=[0.693, 0.185, 0.866, 0.613])

In Figure 5-8 you can see that TemplateControl is an abstract class — a
class that cannot be instantiated; that is, you cannot use New (in C#)
to create an instance of it. It serves as a common base class for
others (like Page) that can inherit from it. The exact classes between
Page and Object are not relevant at this stage, but what's important is
your page inherits all the behavior of the Page class. The fact that
all your ASPX pages inherit from Page is more useful than you might
at first. Because it inherits from Page, you get to use properties and methods defined in this class
for free. For example, the Page class shows a Title property that, when ends up as a <title>
entag. Your page can simply set this property, and the parent Page class handles the
rest for you:

```
C#
Title = "Beginning ASP.NET 4.5.1 in C# and VB from Wrox";
```

You use inheritance in the next chapter when you create a BaseClass that serves as the parent
class for most of the pages you create in the Planet Web website.
