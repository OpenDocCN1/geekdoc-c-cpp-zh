> NOTE When you're using VB.NET, you don't need the OnTick handler on the Timer control because that is taken care of with the Handles keyword in the Code Behind file in that language.

When the timer “ticks” raises its Tick event, which you can handle with the following code:

# VB.NET

```
Protected Sub Timer1_Tick(sender As Object, e As EventArgs) Handles Timer1.Tick
Label1.Text = System.DateTime.Now.ToString()
End Sub
```

# C#

```
protected void Timer1_Tick(object sender, EventArgs e)
{
Label.Text = System.DateTime.Now.ToString();
}
```

When this code is run in the browser, the label will be updated with the current date and time every 5 seconds. If you want to make it faster or slower, you need to adjust its Interval property, which specifies the time in milliseconds. 

This scenario with an auto-updating panel is the ability to refresh with a button click is quite common. The auto-refreshing panel is non-intrusive to feed the user the most up-to-date information from the server. In addition, you could offer your users a button to refresh the data at any moment they choose. From a coding perspective, you wouldn't have to change much; you would call the same code (preferably wrapped in a separate method) for the Timer’s Tick event handler and from the Button's Click event handler.
