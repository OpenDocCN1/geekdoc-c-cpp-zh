| OPERATOR | DESCRIPTION |
| --- | --- |
| AND | Enables to join two expressions. For example, the WHERE clause Id > 20 AND Id < 30 gives you all rows with IDs that fall between 20 and 30 (with 20 and 30 themselves not included). |
| OR | Enables to define multiple criteria of which only one has to match (although more matches are allowed). For example, the WHERE clause GenreId = 5 OR GenreId = 8 gives you all the rows with a GenreId of 5 or 8. |
| BETWEEN | Enables you to specify a range of values that have a lower and upper bound. For example, WHERE Id BETWEEN 10 AND 35 gives you all rows whose IDs are between 10 and 35 (including 10 and 35 themselves) if they exist in the database. |
| LIKE | Used to determine if a value matches a specific pattern. You can use wildcards % to match any string of zero or more characters, and the underscore (_) to match a single character. For example, the WHERE clause Name LIKE 'rock%' returns all genres that have rock in their name, Indie Rock, Hard Rock, and so on. |

If no rows match the clause, you don't get an error, but you simply get zero results back.

After you have defined your filtering requirements with the WHERE clause, you may want to change the order in which the items are returned from the database. You do this with the ORDER BY clause.

# Ordering Data

The ORDER clause comes at the end of the SQL statement and can contain one or more column names or expressions, which can optionally include ASC or DESC to determine if items are sorted in ascending order (with ASC, which is the default if you leave out the keyword) or in descending order (using DESC).

For example, to retrieve all genres from the Genre table and sort them alphabetically by their name in ascending order, you use this SQL statement:

```
SELECT Id, Name FROM Genre ORDER By Name
```

Because ascending is the default order, you don't need to specify the ASC keyword explicitly, although you could if you wanted to. The next example is functionally equivalent to the preceding example:

```
SELECT Id, Name FROM Genre ORDER By Name ASC
```

If you want to return the same rows but sort them in reverse order on their Name column, you use this syntax:

```
SELECT Id, Name FROM Genre ORDER By Name DESC
```
