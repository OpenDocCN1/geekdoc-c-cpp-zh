# How It Works

Pew, lots of animation! I typically recommend adding all these features to your pages at once or you'll be sure to away most of your users. However, for this demo it works really well you can see some of the six selectors, but the code that is being executed against their matched sets is probably new to you.

The first selector selects all elements in your page and then applies the css method to turn their color to green. The ID selector then gets a single element and calls the same css method to apply a border. The third example uses the Element selector to find the h1 element and then dynamically binds a click handler so that when you are the clicking, the code between the curly braces is executed.

Selector demonstrates the Class selector and shows you how to find elements by their class name. Notice that the class being searched doesn't have to be an existing CSS class defined in your style sheet. Once the elements are found, the allClasses method then adds a new class to them, PleaseWait in this example, applies the spinner image as the background to the <div> element. The hide method then hides the elements again during a five-second time frame.

Line number uses the Group selector to find both the footer and the header elements. The slideUp method then slowly decreases the height of these elements until they have completely disappeared. In doing so, it resets the initial size, so you call slideDown again it knows how to size to restore the elements.

The final example uses a Combined selector to find the banner image in the right-hand sidebar. Once it has found the image, it slowly dissolves it (in five seconds) by its opacity to 0.1 (10 percent) so it gets almost invisible.

In a later section in this chapter you will see more of the various styling and animation methods that jQuery offers. For now, it's important that you understand the selector syntax to refer to the elements in your page.
