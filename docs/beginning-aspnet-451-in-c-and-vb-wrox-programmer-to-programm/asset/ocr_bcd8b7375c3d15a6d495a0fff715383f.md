C# also enables you to increase a variable's value by 1 using the ++ operator, like this:

# C#

```
int someNumber = 3;// Results someNumber having the value 4
someNumber++;
```

This construct is used often in loops, as you'll see later in the chapter.

Both languages use arithmetic assignment operators to concatenate string values, as you'll see shortly.

Another common set of operators is the comparison operators, which enable you to compare values.

# Comparison Operators

Just as with the arithmetic operators, VB.NET and C# each have their own set of comparison operators to compare one value to another. A comparison operator always compares two values or expressions and returns a boolean value as the result. The following table lists the most comparison operators.

| VB.NET | C# | USAGE |
| = | == | Checks if two values are equal to each other |
| <> | != | Checks if two values are not equal |
| < | < | Checks if the first value is less than the second |
| > | > | Checks if the first value is greater than the second |
| <= | <= | Checks if the first value is less or equal to the second |
| >= | >= | Checks if the first value is greater or equal to the second |
| Is | is | In VB.NET: Compares two objects; In C#: Checks if a variable is of a certain |

The first thing you'll notice is that C# uses a double symbol (=) for the standard comparison operator. This clearly makes it different from the assignment operator. It's a common mistake in C# to use only a single equals if you intend to compare two values. Consider the following

```
if (result = 4)
{
// Do something here with result
}
```

The intention is here to see if result equals 4. However, because the assignment operator is used instead of a comparison operator, you'll get the compile error that is displayed in Figure 5-2.
