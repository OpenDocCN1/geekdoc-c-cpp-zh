# HTML Attributes

除了 HTML 元素之外，前面的表格中的示例还向你展示了属性。*Attributes* 包含额外的信息，可改变特定元素的行为。例如，用于显示图像的 <img> 标签，其 `src` 属性定义了该图像的来源。同样，<span> 标签包含一个 *style* 属性，可改变文本的颜色。`color: red;` 的值是层叠样式表（CSS）的一部分，将在第 3 章中更详细地讨论。就像 HTML 元素一样，W3C 网站上有一长串适用于它们的属性列表：www.w3.org/TR/html5/index.html。

你不需要记住所有这些元素和属性。其中大多数由 VS 为你生成。在其他需要手工输入的情况下，VS 会提供 IntelliSense 来帮助你找到正确的标签或属性。IntelliSense 将在下一章中讨论。

# HTML Comments

要在 HTML 中添加注释，请将其用注释包裹，如下所示：

```
<!-- This is a comment -->
```

被注释掉的代码不会被浏览器处理（因此不可见）。由于它会被发送到浏览器（因此可见），你应谨慎使用注释。在后面的章节中，我们将注释掉代码以使其不发送到客户端。

# The Rules of HTML5

HTML5 的规则相当简单，而且大多数时候 VS 会帮助你做到正确或显示错误列表以及如何修复它们的建议。与强制执行规则相比，HTML5 比之前的 HTML 版本（称为 XHTML，后者是 HTML 4.0 的重构，采用 XML 规则）更为宽松。

HTML 中的大多数元素必须关闭。因此，当你以 <div> 标签开始时，你必须在页面中的某个位置使用 `</div>`。有一些例外（除 <p> 元素外，如果它直接跟随某些其他元素），但我更喜欢始终一致地关闭我的标签。这也适用于没有自己闭合标签的元素，如 <img> 或 <br>（用于换行）。在 HTML5 中，这些标签可以写成 *self-closing tags*，如 `<img src="Logo.gif">` 或 `<br />`，其中闭合斜杠直接嵌入在标签本身中

# Usage of Attributes

每当你在标签中编写属性时，你可以用双引号、单引号或完全不加引号来编写值。例如，编写 <img> 标签及其 `src` 属性时，可以这样写：

```
<img src="Logo.gif" />
```

你也可以使用单引号来括起属性值，如下所示：

```
<img src='Logo.gif' />
```

两种选项都有效，只要你在值的两端使用相同类型的引号即可。对于不包含空格的值，你也可以省略引号：

```
<input value=yes>
```

有时有必要嵌套单引号和双引号。例如，当某些特殊的 .NET 语法需要使用双引号时，你应使用单引号来包裹属性的值：

```
<asp:Label ID="TitleLabel" runat="server" Text='<% Eval("Title") %>' />
```

你将在本书后面的章节中经常看到这一点。为了保持一致性，本书在所有最终发送到客户端的 HTML 中尽可能使用双引号，因为这是通常接受的标准。

# Nest Your Elements Correctly

嵌套元素时，请确保先关闭最后打开的内部元素，然后再关闭外部元素。考虑以下正确示例，它使用粗体和斜体格式化一段文本：

```
<strong><em>This is some formatted text</em></strong>
```

注意 <em> 标签是在 <strong> 标签之前关闭的。交换闭合标签的顺序会导致无效的 HTML：

```
<strong><em>This is some formatted text</strong></em>
```

# Add a DOCTYPE to Your Page

DOCTYPE 为浏览器提供有关它可以期望的 HTML 类型的信息。默认情况下，VS 会为你的页面添加 HTML5 的 DOCTYPE：

```
<!DOCTYPE html>
```

DOCTYPE 在很大程度上影响了浏览器（如 Internet Explorer）如何渲染页面，如果你在页面上看到异常行为，请检查页面是否具有 DOCTYPE。

你可以在 W3C 查看完整的 HTML5 语法规则：www.w3.org/TR/html-markup/syntax.html。
