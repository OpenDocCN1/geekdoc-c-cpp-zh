
# RETRIEVING AND MANIPULATING DATA WITH SQL

When interacting with databases, you'll spend a good deal of time retrieving and manipulating data. Most of it comes down to four distinct types of operations, grouped under the CRUD acronym: *Create, Read, Update, and Delete.*

Because these data operations are crucial, the next couple of sections show you how to use them in detail.

## Reading Data

To read data from a database, you typically use a few different concepts. First, you need to indicate the columns that you want to retrieve from the table you are querying. You do that with the `SELECT` statement. You need to indicate the table(s) you want to select the data from using the `FROM` keyword. You need a way to filter the data, making sure only the rows you are interested in are returned. You can filter the data using the `WHERE` clause in the SQL statement. Finally, you can order your results using the `ORDER` clause.

## Selecting Data

To read data from one or more database tables, you use the `SELECT` statement. In its most basic form, the statement looks like:

```
SELECT ColumnName [, OtherColumnNames] FROM TableName
```

Here, the parts between the square brackets are considered optional. For example, to retrieve all rows from the *Genre* table and select only their *Id* and *Name* columns, you use this SQL statement:

```
SELECT Id, Name FROM Genre
```

Right after the select statement comes a comma-separated list of column names. You can have only one or many columns as you like here. Instead of specifying columns explicitly, you can also use the asterisk (`*`) character to indicate all columns to be returned. `SELECT *` is usually considered a poor programming practice as you are usually selecting more columns than need, causing unnecessary overhead. It's better to define each column you want to retrieve. If you want to rename a column in the result set, use the `AS` keyword, like this:

```
SELECT Id AS GenreId, Name FROM Genre
```

To limit the number of rows retrieved from a table, you use the `TOP` keyword followed by the maximum number of rows. To get predictable results, you typically use an `ORDER BY` clause. Without that, the order of rows is not guaranteed and `TOP` may return different results each time you call it. Here's a quick example that retrieves the first three genres:

```
SELECT TOP 3 Id, Name FROM Genre ORDER BY Name
```

SSMS by default uses `TOP 200` to limit the number of rows retrieved when you open a table.

Right after the `FROM` keyword, you specify the name of the table from which you want to retrieve data. The previous example showed only one table (the *Genre* table), but you will see later that you can also specify multiple tables using joins.

## Filtering Data

To filter data, you use the WHERE clause, with which you indicate the criteria that you want your data to match. For example, retrieve the ID of the genre you use using the following SQL statement:

```
SELECT Id From Genre WHERE Name = 'Grunge'
```

Note that the word Genre is wrapped in single quotes. This is required for text types and dates when you filter data or send values to an INSERT or UPDATE statement that enables you to create new or change existing rows, as explained later. You can't use them for numeric or boolean types, though, so to get the name of the genre with an ID of 8 would use the following statement:

```
SELECT Name From Genre WHERE Id = 8
```

The preceding two examples show a WHERE clause that uses the equals operator for an exact match. However, you can also use other operators for different criteria. The following table lists a few popular comparison operators you can use in WHERE clauses.

| OPERATOR | DESCRIPTION |
| --- | --- |
| = | The equals operator matches only when the left side and the right side of the comparison are identical. |
| > | The greater than operator matches when the left side of the comparison represents a larger value than the right side. |
| >= | The greater than equal operator matches when the left side of the comparison is equal or larger than the right side. |
| < | The less than operator matches when the left side of the comparison represents a smaller value than the right side. |
| <= | The less than equal operator matches when the left side of the comparison is equal to or smaller than the right side. |
| <> | The not equals performs the reverse of the equals operator and matches when the left side and right side of comparison are different. |

To combine multiple WHERE criteria, SQL supports a number of logical operators such as AND and OR. In addition, it supports other operators to search for text and to specify ranges. The following table lists a few of the operators and describes what they are used for.

| OPERATOR | DESCRIPTION |
| --- | --- |
| AND | Enables to join two expressions. For example, the WHERE clause Id > 20 AND Id < 30 gives you all rows with IDs that fall between 20 and 30 (with IDs included). |
| OR | Enables to define multiple criteria. For example, WHERE Id = 5 OR Id = 8 gives you both. |
| BETWEEN | Enables you to specify a range of values. For example, BETWEEN 10 AND 35. |
| LIKE | Used to determine if a value matches a pattern. You can use wildcards % to match any string, and the underscore (_) to match a single character. |

## Ordering Data

After you have defined your filtering requirements with the WHERE clause, you may want to change the order in which items are returned. You do this with the ORDER clause.

The ORDER clause comes at the end of the SQL statement and can contain one or more column names, which can optionally include ASC or DESC to determine if items are sorted in ascending order (which is the default if you leave out) or descending order (using DESC).

For example, to retrieve all genres from the Genre table and sort them alphabetically by their name in ascending order, you use this statement:

```
SELECT Id, Name FROM Genre
```

Because ascending is the default, you don't need to specify the ASC explicitly. The next example is functionally equivalent to the preceding example:

```
SELECT Id, Name FROM Genre ORDER BY ASC
```

If you want to return the same rows but sort them in reverse order on their Name column, you use this syntax:

```
SELECT Id, Name FROM Genre ORDER BY DESC
```

You can order by columns in the ORDER BY statement that are not part of the SELECT statement as shown in this snippet:

```
SELECT Id, Name FROM Genre ORDER BY SortOrder DESC
```
