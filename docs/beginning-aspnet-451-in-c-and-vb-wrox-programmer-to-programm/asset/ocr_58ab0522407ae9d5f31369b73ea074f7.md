# Introducing the DataPager Control

The DataPager is a separate control that you can use to extend another data-bound control. Currently, .NET Framework lets you use the DataPager only to provide paging capabilities to the ListView control, which the developer community has active implementations for other controls, such as the GridView.

You can hook up the DataPager to the ListView in two ways: You can either define it in the LayoutTemplate of the ListView control or you define it entirely within the ListView. In the first case, the DataPager knows how to provide paging capabilities automatically. In the second case, you need to set the PagedControlID property of the DataPager to the ID of a valid ListView control. You can see how to configure and use the DataPager in conjunction with a ListView next. Useful if you want to place it at a different location on the page, such as in the Per or Sidebar area.

# TRY OUT Paging Data with the ListView and DataPager Controls

In this It Out you create the front-end of the Gig Pics feature. Users of your site can choose one of the available photo albums from a drop-down list and then view all the pictures in a pageable list that is created by a ListView and a DataPager. Figure 14-16 shows the final result of this exercise.

+   1. In the root site, create a new folder named PhotoAlbums. Inside this folder create a new Web Form using your custom page template and call it Default.aspx. Set the Title of the page to Photo Albums.
2. Switch to Design view and drop a DropList control on the page. Using the control's Smart Tags, enable AutoPostBack and, using the Properties Grid, set the control's ID to PhotoAlbumList, DataValueField to Name, and SelectMethod to PhotoAlbumList_GetData, as shown in Figure 14-15.

The TextField will display the name of the photo album in the DropList, while the DataValueField is used as the underlying ID of the photo album. This ID is then used to display the pictures that are of the selected photo album. You will need to manually assign the SelectMethod and add the associated method to the Code Behind, as the control does not support double-click generating the method automatically as the ListView does.
