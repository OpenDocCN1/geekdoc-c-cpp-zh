

# 第 1 章 开始使用 ASP.NET 4.5.1

## 试一试 安装 Visual Studio Express 2013 for Web

本试一试练习指导你如何在计算机上安装 VSEW。它假设你使用的是网络安装程序，虽然从 DVD 安装 Express 的过程几乎相同。你需要执行以安装完整版 Visual Studio 2013 的步骤也类似，只是屏幕会有所不同。

- 1. 首先浏览到 www.microsoft.com/express/ 并按照说明下载 VSEW 2013。你可以直接选择下载然后点击立即安装链接进行安装，或下载一个可以刻录到 DVD 或在 Windows 上作为虚拟驱动器挂载的 ISO 文件。确保你下载的是 Visual Studio 2013 而不是其他免费版本或旧版本。如果此链接 ever 更改或不再提供对 VSEW 下载的直接访问，搜索网络上的“Install Visual Studio Express 2013 for Web” 你将被带到一个下载页面，在那里你可以开始安装。
- 2. 下载完成后，启动安装程序。你应该会看到类似图 1-1 的屏幕。勾选许可条款和隐私政策的复选框。如果你安装的是完整版 Visual Studio，点击同意许可条款后出现的下一步按钮。你将看到类似图 1-2 的屏幕。确保至少选择 Microsoft Web Developer Tools。
- 3. 在两种情况下，点击安装按钮开始安装过程。
- 4. 过了一会儿你会看到一条消息，表明 Visual Studio 已成功安装。安装程序可能需要在安装期间或之后重启你的机器。安装程序完成后，Visual Studio 即可使用。

## 创建你的第一个 ASP.NET 4.5.1 网站

你可能迫不及待地想开始你的第一个 ASP.NET 网站，而不是给你一个关于 VS 中网站的理论概述，下一个试一试练习直接进入行动并展示如何构建你的第一个 Web 项目。然后，在如何工作的解释和后面的部分中，你可以很好地了解在浏览器中查看 .NET 页面时幕后发生了什么。

## 试一试

- 1. 从开始菜单或开始屏幕启动 Visual Studio。对于 VSEW，菜单项称为 VS 2013 for Web。对于 Windows 8.1，你需要点击开始屏幕上的向下箭头以进入所有应用程序的列表。如果你使用的是 Visual Studio 的商业版，只需从开始屏幕启动 Visual Studio 2013；所有 Web 相关组件都从主 VS 程序访问。你将被一个对话框迎接，让你使用 Microsoft 帐户登录 Visual Studio。如果你想在多台机器上同步设置，这很有用。点击登录输入你的凭据或注册新帐户。如果你不想登录，点击现在不，稍后再说。第一次启动 VS 时，可能需要一段时间才能使用，因为它正在自行配置。后续启动应用程序会感觉快得多。
- 2. 如果你使用的是 Visual Studio 的商业版，第一次启动 Visual Studio 时可能会出现一个对话框，让你选择不同的设置集合。你在该框中做的选择会影响窗口、工具箱和快捷方式的布局。选择 Web 开发设置，因为这些设置专门为 .NET 开发人员设计。
- 3. VS 完全配置后，你会看到主屏幕，如图 1-3 所示。你将在下一节中获得所有窗口、工具栏和菜单的完整描述，所以现在，只需专注于创建新网站。点击左上角的文件菜单并选择新建。如果你使用的是 Visual Studio 的商业版，根据你启动 Visual Studio 时选择的设置，你可能必须先打开新建项目，因为它用于创建不同类型的应用程序。

## 创建你的第一个 ASP.NET 网站

新建站点对话框出现，如图 1-4 所示。

![](img/9e033e3b9560597824f8b22941d6d8bb_43_1.png)

- 4. 在对话框中间，模板列表上方，从下拉列表中选择 .NET Framework。然后，在左侧的模板部分，你可以选择用于站点的编程语言。本书在 Visual Basic 和 C# 中都展示示例，因此你可以根据喜好选择一种语言。
- 5. 在中间的模板列表中，点击 ASP.NET Web Site。验证底部 Web 位置下拉列表中是否选择了系统。如果你愿意，可以通过点击浏览按钮并选择计算机硬盘上的新位置来更改网站的存储位置。现在，默认位置在文档下，因此你可以保持原样。

![](img/9e033e3b9560597824f8b22941d6d8bb_44_0.png)
- 6. 点击确定。VS 为你创建一个新的网站，其中包含许多文件和文件夹（见图 1-5）来启动你的网站。
- 7. 通过双击打开文件 Default.aspx 并删除 ID 设置为 BodyContent 的 <asp:Content> 块内的所有代码（它从第 5 行的 <div> 开始并一直到 </div>）。用以下加粗代码替换它：

```
<asp:Content server="server" ID="BodyContent" ContentPlaceholderID="MainContent">
<h2>Hello World</h2>
<p>Welcome to ASP.NET on <% DateTime.Now.ToString() %></p>
</asp:Content>
```
图 1-5

你将在本书中看到很多这种格式的代码。当指示你输入此类代码时，你只需要输入加粗的代码。其他代码应该已经存在于文件中。不要担心带括号 (<) 和百分号的代码；这些称为标签，你稍后会学习它们。虽然这段代码现在可能不熟悉，但你大概可以猜出它的作用：它输出你的日期和时间。
- 8. 按 Ctrl+F5 在 Web 浏览器中打开页面。你将看到类似图 1-6 所示的页面。

![](img/9e033e3b9560597824f8b22941d6d8bb_44_1.png)
图 1-6

如果你已有 Visual Studio 使用经验，你可能习惯按 F5 而不是。如果你使用该选项，站点将在调试模式下打开，你可能会收到一个询问是否要启用调试的对话框（你可以安全地启用）。使用 F5 调试在第 18 章讨论，建议你使用 Ctrl+F5 直到。

如果你在 Internet Explorer 中看到有关内联网设置的警告信息，点击启用内联网设置。

如果你在页面中看不到日期和时间，或出现错误，请再次查看欢迎消息中的代码。它以单个括号 (<) 后跟百分号和冒号开始。以单个括号 (>) 结束。另请确保你完全按照此处所示输入代码，包括大小写。这在使用 C# 时尤其重要，因为该语言区分大小写。

- 注意一个小的图标 IIS Express 已出现在 Windows 托盘中，在图 1-7 中可见。

该图标属于内置 Web 服务器 IIS Express。该服务器已由 VS 自动启动以处理对你的页面的请求。你将在本章后面了解 Web 服务器如何处理你的页面。

![](img/9e033e3b9560597824f8b22941d6d8bb_45_0.png)
图 1-7

如果你在托盘中看不到图标，点击 Windows 托盘附近的箭头并点击自定义选项。然后查看 IIS Express 系统托盘以显示图标和通知。

就是这样，你用 Visual Studio 创建了你的第一个 ASP.NET 网站。

你在本次试一试中创建的网站相当简单，最终导致在浏览器中显示页面 Default.aspx 的过程并不简单。单独的 ASP.NET 页面（也称为 ASPX 页面或其扩展名的 Web 表单）不能做太多。它需要在 Web 服务器处理并提供服务后，浏览器才能显示它。这就是为什么 VS 自动启动 IIS Express 来处理对你的页面的请求的原因。
