In addition to the HTML and other markup you see in the Markup View window, a Web Form can also contain code in either C# or Visual Basic .NET. Where this code is placed depends on the type of Web Form you create. The next section explains the two options you have in more detail.

# Choosing Code Behind and Pages with Inline Code

Web Forms come in two flavors: either as .aspx file with a Code Behind (a file named after the Web Form with an additional .vb or .cs extension) or as .aspx files that have their code embedded, referred to as Web Forms with inline code. Although you won't see much code until Chapter 5, it is important to understand the difference between these types of Web Forms. First, Web Forms with inline code make a little easier to understand. Because the code needed to program your website is of the very same Web Form, you can clearly see how the code relates to the file. However, if your page gets larger and you need more functionality, it's often easier if you have the code in a separate file. That way, it's completely separate from the markup, enabling you to focus on the task at hand.

In the next exercise, you two files demonstrate the difference between Code Behind and inline code.
