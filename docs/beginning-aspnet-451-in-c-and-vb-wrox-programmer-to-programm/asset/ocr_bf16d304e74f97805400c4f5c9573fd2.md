# TRY OUT Customizing Templates of the ListView Control

The templates for the ListView control you added in an earlier exercise are enough only in the most trivial situations. Usually, you need more control. For example, in the ItemTemplate you may want to display an actual image instead of the Label ImageUrl property. Likewise, in the InsertItemTemplate you may want to display a file upload control instead of a text box. In this exercise, you will see how to change these templates so you can incorporate both features. Additionally, you will see how to update the InsertItem to save the uploaded file to disk, and update the database with the URL of the image.

For this example, the account used by the web server (the account you use to log on when you are using IIS Express) reads and writes to the GPics folder that you create in this exercise. The account should already have these permissions on you, if you run into problems with this exercise, refer to the section “Understanding Security in IIS” in Chapter 19.

+   1. Create a new folder in the root of the website called GPics. This folder will contain content pictures uploaded by users.

+   2. Open the ManagePhotoAlbum.aspx page in Markup View and locate the <ItemTemplate> element. The Label that displays the ImageUrl and replace it with an Image control, with its ImageUrl set to the ImageUrl of the picture.

Remove the text ImageUrl that appears above the image.

+   3. To enable to upload images, you need to replace the TextBox for the ImageUrl property with a FileUpload control. You also need to remove the text ImageUrl: again. you do this in the InsertItemTemplate:

Note that you don't need to bind the property to the control here. Because the uploaded image needs special treatment, you will write some code in the Code Behind of the page instead of relying on the built-in data-bindings.

+   4. In Markup, add three validation controls to the InsertItemTemplate: two RequiredValidator controls hooked up to the boxes for the Description and Tooltip, and one CustomValidator with its ErrorMessage to Select a valid .jpg file. Give the RequiredValidator controls an ID as reqDesc and reqTooltip and assign the CustomValidator an ID of csImage, then set the TextMode of the textbox for the Description to Multiline and add a line break ( <br />) for the Insert button.
