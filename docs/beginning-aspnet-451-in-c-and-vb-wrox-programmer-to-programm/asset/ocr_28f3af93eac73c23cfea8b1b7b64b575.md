nYou'll be greeted by a dialog that lets you sign in to Visual Studio with a Microsoft account. It is useful if you want to synchronize your settings across multiple machines. Click Sign In to enter your credentials or sign up for a new account. If you don't want to sign in, Click Not now, maybe later. The first time you start VS, there might be a delay before you can use it because it's busy configuring itself. Subsequent starts of the application will feel much faster.
2. If you're using a commercial version of Visual Studio, you may get a dialog box that lets you choose between different collections of settings the first time you start Visual Studio. The choice you make on that box influences the layout of windows, toolboxes, menus, and shortcuts. Choose the Web Development settings because these settings are designed specifically for .NET developers. You can always choose a different profile by resetting your settings, as explained later in this chapter.
