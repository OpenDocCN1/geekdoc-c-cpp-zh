10. When the control is in template editing mode, you can access the DropListData directly. Open the Smart Tasks panel for the DropListData and choose Data Source. In the Data Source Configuration Wizard, choose GenresDataSource drop-down list and Name and Id from the other two drop-down lists (see Figure 13-21). If Name and Id don't appear in the drop-downs, click the blue Refresh Schema link at the bottom of the screen. If you see the GenreDataSource listed, but use SqlDataSource2 instead, make sure you renamed the control correctly as described in step 7.
