# PRACTICAL TIPS ON JQUERY

To get the most out of jQuery, follow these short tips:

- Experiment and experiment. At first, jQuery is a bit of an odd technique to master, mostly because of all its curly braces and parentheses. However, by practicing it you can become a jQuery master in no time.
- Visit jquery.com website. Besides very good documentation with many examples showing off jQuery's capabilities, you also find a wealth of articles and links on using links to sites that feature video content.
- Invest some time in browsing the jQuery UI and Juice UI websites. You may not need what they offer right now, or you may feel you're not ready to take that next step yet, but it's good to know what these products have to offer when you're building your next website with a rich client interface.

# WHAT IS A DATABASE?

By its simplest definition, a *database* is a collection of data that is arranged so it can be accessed.

The most popular type of database is relational, where data is stored in tables. The term “relational” refers to different ways tables can be related to each other. Each row in the table contains information, and each column contains a property.

# DIFFERENT KIN OF RELATIONAL DATABASES

You can use many different kinds of databases in your ASP.NET projects, including Microsoft Access, SQL Server, SQLite, Oracle, and MySQL. The most commonly used database in ASP.NET websites is Microsoft SQL Server. This book focuses on using the SQL Server 2012 Express LocalDB engine which is free, comes bundled with VS 2012 and has a lot to offer out of the box. Also, because the database format is identical to that of the commercial versions of SQL Server 2012, it is easy to upgrade to versions at a later stage in the development cycle.

The only problem with LocalDB is you can't use all of the database management tools from Visual Studio. You can create tables and other database objects, but you can't visually new queries and diagrams, two features that you'll use regularly when working with databases in your ASP.NET projects.

To overcome this limitation, you should download and install SQL Server Management Studio (SSMS) Express, the free tools to manage all your SQL Server databases, including LocalDB, and the commercial versions of SQL Server (although in the latter case you probably want to use the more rich version of the tools that ship with the main product).

In the next sections you will see how to acquire and install SQL Server Management Studio Express. The sections that follow show you how to use it to manage your databases and the data they contain.
