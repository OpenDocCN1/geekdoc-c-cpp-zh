

# 第 1 章 开始使用 ASP.NET 4.5.1

在图 1-9 中的文档窗口底部，你会看到三个名为 Design、Split 和 Source 的按钮。当你正在处理包含标记的文件，例如 ASPX 页面时，这些按钮会自动出现。它们使你能够打开页面的设计视图（让你了解页面在浏览器中的外观）、其标记视图（HTML 和其他标记），或同时打开。它的工作原理将在第 2 章中更详细地解释，但现在，重要的是要意识到你可以通过点击其中三个在标记、拆分和设计视图之间切换。标记视图也常被称为源视图或代码视图。然而，为了避免与用于编辑代码隐藏文件的代码编辑器混淆，本书专门使用标记视图这一术语。

# 开始页面

每当你启动 VS 时，开始页面就会在文档窗口中加载。通过开始页面，你可以快速创建新的和打开窗口以及其他项目。开始页面提供了许多与网络开发相关的新闻和信息的链接。要将你的项目固定到开始页面，请点击最近项目列表中项目名称左侧的图钉图标。要取消固定项目，右键单击它并选择从列表中删除。要重新打开开始页面，请选择查看开始页面。

为了让你感受如何使用所有这些窗口，以下试用将向你展示如何构建一个包含几个 ASP.NET 服务器控件的简单网页。

# 试用 创建你的第一个 ASP.NET 网页

此试用练习指导你创建一个包含多个 ASP.NET 服务器控件的单个页面的新网站。了解如何使用文档窗口和解决方案资源管理器等窗口，以及如何使用工具箱和属性网格向页面添加 ASP.NET 服务器控件并更改其外观。

- 1. 启动 VS 或 Visual Studio 2013。
- 2. 如果你使用的是 Express 版本，请选择工具 设置 并选择专家设置，以打开提供对 VS 全部功能的访问权限的开发人员配置文件。
- 3. 在文件菜单上创建新网站。根据配置，你可能必须选择文件 新 VS。 这会触发新网站对话框。
- 4. 在此对话框中，确保选择了 ASP.NET 空网站，而不是你在先前练习中使用的 ASP.NET Web 窗体项。确保在 Web 位置下拉列表中选择了文件系统。对于此操作，选择 Visual Basic 还是 C# 都无关紧要。点击确定以创建新站点。
- 5. 接下来，在解决方案资源管理器中右键单击新网站。确保你点击的是网站（标记为 WebSite2），而不是父元素。它是图 1-5 中突出显示的元素。从上下文菜单中，显示如何创建新的添加项。
- 6. 在出现的新的窗口中，点击 Web 窗体并将名称输入为 Control。点击添加按钮时，ASPX 扩展名会自动为你添加。你可以让对话框中的其他设置保持其默认设置。页面应在标记视图中打开，显示默认的 HTML，如 VS 在你创建新页面时为你添加的 <html><head><title> 和 <body> 元素。
- 7. 通过点击文档窗口底部的设计按钮将页面切换到设计视图。
- 8. 如果工具箱未打开，请按 Ctrl+Alt+X 打开或点击工具箱选项卡以显示它，并点击右上角的图钉图标以使工具箱始终可见。从工具箱的标准类别中拖动一个文本框和一个按钮到页面的设计视图中。你应该得到一个看起来像图 1-10 的设计视图。
- 9. 在设计视图中右键单击按钮并选择属性。在属性网格中，点击外观类别下的文本属性（如图 1-11 所示）并将其从 Button 更改为提交信息。 当你按下 Tab 或点击属性网格外部时，页面的设计视图会更新并显示按钮上的新文本。
- 10. 按 Ctrl+F5 在默认浏览器中打开页面。请注意，不一定需要保存对页面的更改（尽管无论如何使用快捷键 Ctrl+S 保存它也是一个好主意）。当你按 Ctrl+F 运行页面时，VS 会自动保存所有打开文档的更改。

# 它是如何工作的

当你在设计视图中从工具箱绘制按钮和文本框时，VS 会在标记视图中为你添加相应的代码。同样，当你在属性网格中更改文本属性时，VS 会自动更新标记视图中控件的标记。除了使用属性网格，你也可以直接在标记视图中在文本属性的引号之间输入文本。

更改文本属性后，你的页面应在标记视图中包含一些代码：

```
<asp:TextBox Id="TextBox" runat="server"/> <asp:Button Id="Button" runat="server" Text="Submit Information" />
```

当你按 Ctrl+F5 在浏览器中查看页面时，Web 服务器接收请求，页面由 ASP.NET 运行处理，并将页面的结果 HTML 发送到浏览器。

在你输入一些文本并点击后，基本相同的过程会重复：Web 服务器接收请求，页面被处理，结果被发送回浏览器。当你点击按钮时，会导致回发发生，其中页面中包含的任何信息——例如你在文本框中输入的文本——都会发送到服务器。ASP.NET 通过重新加载页面来响应回发。但是，这会使用发送到页面的值预先填充控件，例如文本框。
