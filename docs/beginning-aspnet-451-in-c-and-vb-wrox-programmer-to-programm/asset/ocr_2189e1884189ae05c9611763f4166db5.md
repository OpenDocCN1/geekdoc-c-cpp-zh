# Understanding Default Documents

In the context of URLs you should also know about default documents. When you browse to a site like www.domain.com you might magically see a page appear. How does this work? Each web server has so-called default documents, a list of document names that can be served to a browser when no explicit document is supplied. So, when you browse to www.domain.com, the web server scans the directory requested (the root folder in this example) and processes the first file from default lists it finds. In most ASP.NET scenarios, the web server is set up to use Default.aspx as the default document. So, when you browse to www.domain.com on an ASP .NET server, you are actually served the page www.domain.com/Default.aspx.

In the links you create, you should generally leave Default.aspx when it's not needed. It decreases the page size, but more important, it makes it easier for users to type the address.

Now that you have how to use URLs to point to documents and other files, it's time to look at some higher-level controls that make use of these URLs: the ASP.NET navigation controls.
