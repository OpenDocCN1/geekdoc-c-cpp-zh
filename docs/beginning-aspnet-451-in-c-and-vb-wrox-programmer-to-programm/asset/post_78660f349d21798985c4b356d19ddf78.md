
What is the outcome of this? You may think the answer is 48 if you add 2 and 10 together, and then multiply the result by 4. However the right answer is 42; first the multiplication operator is applied on 10 and 4, resulting in 40. Then 2 is added, which leads to 42 as the final result. | \ | Integer division | |
| Mod | Modulus arithmetic | |
| +, - | Addition and subtraction and concatenation using the plus (+) symbol | |
| & | String concatenation | |

This does result in 48 now, because the addition operator is applied before the multiplication operator.

## Comparison Operators

Just as with the arithmetic operators, VB.NET and C# each have their own set of comparison operators to compare one value to another. A comparison operator always compares two values or expressions and returns a boolean value as the result. The following table lists the most comparison operators.

| VB.NET | C# | USAGE |
| = | == | Checks if two values are equal to each other |
| <> | != | Checks if two values are not equal |
| < | < | Checks if the first value is less than the second |
| > | > | Checks if the first value is greater than the second |
| <= | <= | Checks if the first value is less or equal to the second |
| >= | >= | Checks if the first value is greater or equal to the second |
| Is | is | In VB.NET: Compares two objects; In C#: Checks if a variable is of a certain |

The first thing you'll notice is that C# uses a double symbol (=) for the standard comparison operator. This clearly makes it different from the assignment operator. It's a common mistake in C# to use only a single equals if you intend to compare two values. Consider the following

```
if (result = 4)
{
// Do something here with result
}
```

The intention is here to see if result equals 4. However, because the assignment operator is used instead of a comparison operator, you'll get the compile error that is displayed in Figure 5-2.

FIGURE 5-2

At first the error message may look like a strange thing. But if you look at the code closer, it starts to make more sense. First, result gets assigned a value of 4. This value is then used for the if statement. However, if the statement needs a boolean value to determine whether it should run the code inside the block. Because you can't convert an integer to a boolean like this, you get a compile error. The fix is easy, though; just use the proper comparator instead:

```
if (result == 4)
{
    // Do something here with result
}
```

 and result in the value "Hello World"

result = result & secondString
```

```

result &= secondString
```

## C#

```
string firstString = "Hello";
string secondString = "World";
string result;
```

> // The following three blocks are all functionally equivalent

```

In addition to the & and += operators in VB.NET, you could use + and += as well. However, depending on the data types of the expressions you are trying to concatenate, you may not get the result you'd expect. Take a look at this code snippet:

```
Dim firstNumber As String = "4"
Dim secondNumber As Integer = 5
Dim result As String = firstNumber + secondNumber
```

Because result is a String, you may expect the result to be 45, a concatenation of 4 and 5. However, by default, the VB.NET compiler will convert the string "4" into 4, after which addition and not concatenation place, giving a result value of "9", the string representation of it.

To avoid this ambiguity, always use the & and += operators to concatenate strings. Additionally, you can tell VB.NET to stop converting these values for you automatically by adding the following line to the top of your code files:

```
Option Strict On
```

This forces the compiler to generate errors when an implicit conversion is about to occur, as in the previous example.

## Logical Operators

The logical operators are used to combine the results of multiple individual expressions, and to make sure that multiple conditions are true or false, for example. The following table lists the most common operators.

| VB.NET | C# | USAGE |
| --- | --- | --- |
| And | & | Returns True when both expressions result in a True value. |
| Or | | | Returns True if at least one expression results in a True value. |
| Not | ! | Reverses the outcome of an expression. |
| AndAlso | && | Enables to short-circuit your logical And condition checks. |
| OrElse | || | Enables to short-circuit your logical Or condition checks. |

The And, Or, and Not operators (&, |, and ! in C#) are pretty straightforward for their usage, as demonstrated in the following code snippets:

## VB.NET

If Not num1 = 5               // Evaluates to True because num1 is not 5
```

if (!num1 == 5))                // Evaluates to true because num1 is not 5
```
