# 工作原理 (How It Works)

默认情况下，密码以*哈希（hashed）*格式存储在数据库中，这意味着它们无法被检索。哈希处理是一个不可逆的过程，它会为你的数据创建一个唯一的指纹。因为它是不可逆的，所以没有办法重新创建它。
