# How It Works

With the RequiredValidator attached to the TextBox through the ControlValidate property, client-side JavaScript is sent to the browser that validates the control at the client.
TheRequiredValidator control is able to validate another control like a TextBox. It does by comparing the value of the other control with its own InitialValue property and making sure that the other control's value is different. By default, this property is an empty string, which means that anything except is considered a valid value. Whenever you try to submit the form to the server by clicking the Send button, the validation control checks if it is attached to. When the text box is still empty, its property is shown (formatted with the Error CSS class), and the form is not submitted. See how to use and display the control property later in this chapter. When the user enters something in the Name text box, validation succeeds and the page submits to the server successfully.
