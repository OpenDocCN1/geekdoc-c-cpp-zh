At first the error message may look like a strange thing. But if you look at the code closer, it starts to make more sense. First, result gets assigned a value of 4. This value is then used for the if statement. However, if the statement needs a boolean value to determine whether it should run the code inside the block. Because you can't convert an integer to a boolean like this, you get a compile error. The fix is easy, though; just use the proper comparator instead:

```
if (result == 4)
{
    // Do something here with result
}
```

Similar to the simple comparator, you can use the other operators to compare values:

# VB.NET

+   - 4 > 5      ' 4 is not greater than 5; evaluates to False
- 4 <= 5     ' 4 is not equal to 5; evaluates to True
- 5 >= 4      ' 5 is greater than or equal to 4; evaluates to True

# C#

+   - 4 > 5       // 4 is not greater than 5; evaluates to false
- 4 != 5      // 4 is not equal to 5; evaluates to true
- 5 >= 4      // 5 is greater than or equal to 4; evaluates to true

The Is keyword in VB.NET and in C# do completely different. In VB.NET, Is compares two instances of objects, you learn more about in the second half of this chapter. In C#, you use is to find out if a variable is compatible with a certain type. You can accomplish this in VB.NET using the Type operator. The following two examples are functionally equivalent:

# VB.NET

```
Dim myTextBox As TextBox = New TextBox()

If TypeOf myTextBox Is TextBox Then
    // Run some code when myTextBox is a TextBox
End If
```

# C#

```
TextBox myTextBox = new TextBox();

if (myTextBox is TextBox)
{
    // Run some code when myTextBox is a TextBox
}
```
