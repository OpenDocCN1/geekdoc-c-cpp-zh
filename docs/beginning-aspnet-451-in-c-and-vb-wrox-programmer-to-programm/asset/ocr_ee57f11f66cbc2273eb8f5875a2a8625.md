As you can see, it's easy to add text and other markup to the Panel control in VS. Right now, you only added some plaintext, but in the next section you see how to add a wizard control and how to use it.

# Magic with the Wizard Control

The wizard control is a great tool for breaking apart large Web Forms and presenting them as bited chunks of information. Instead of confusing your user with one page with many controls and on it, you can break the page apart and present each section on a separate page. The wizard control then handles navigation issues by creating Next, Previous, and Finish buttons automatically. In this exercise you use a wizard to create a user for her and favorite programming language. Although the example itself is trivial, and you could have placed both questions on the same page without confusing the user, the example shows how the wizard works and why it's useful. You can easily apply the same techniques to your own, possibly larger, Web Forms.
