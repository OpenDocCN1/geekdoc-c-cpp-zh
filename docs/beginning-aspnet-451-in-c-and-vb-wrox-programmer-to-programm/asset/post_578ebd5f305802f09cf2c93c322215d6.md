Using String.Format makes this code easier to read opposed to string concatenation using & in VB.NET and (+) in C#. If you now insert or edit a new review, you'll see that the ID of the genre is passed back to Reviews.aspx. On that page, you can use the ID to preselect the correct item in the DropDownList, which you can accomplish with the following code in the Page_Load method:

```VB.NET
Protected Sub Page_Load(sender As Object, e As EventArgs) Handles Me.Load
    If Not Page.PostBack Then
        Dim genreId As String = Request.QueryString.Get("GenreId")
        If Not String.IsNullOrEmpty(genreId) Then
            DropDownList1.DataBind()
            Dim myItem As ListItem = DropList1.Items.FindByValue(genreId)
            If myItem Is Not Nothing
                myItem.Selected = True
            End If
        End If
    End If
End Sub
```

```C#
protected void Page_Load(object sender, EventArgs e)
{
    if (!Page.PostBack)
    {
        string genreId = Request.QueryString.Get("GenreId");
        if (!string.IsNullOrEmpty(genreId))
        {
            DropDownList1.DataBind();
            ListItem myItem = DropList1.Items.FindByValue(genreId);
            if (myItem != null)
            {
                myItem.Selected = true;
            }
        }
    }
}
```

Only when the page is loaded from a new request (and not from postback) does this code fire. This code tries to find genreId in the query string. If it can, it tries to find an item with the requested value in the DropDownList. Because the DropList hasn't been data bound it doesn't contain any items. Therefore, you need to call DataBind(). This gets the items from the database using EF and puts them in the DropList. Once that the item is found in the Items collection, it's made the active item by setting its property to True. The SqlDataSource control controls this DropList so when the data source gets reviews, it does so for the correct genre.

The various data-bound controls raise exceptions that you can handle in their event handlers. Once you have dealt with the exception appropriately, you need to set the Exceptionled property of the e argument to True. The following code snippet shows how a Label control is updated with an error message. ExceptionHandled is then set to stop the Exception from getting passed to the user interface where it would otherwise result in a “Yellow Screen of Death.”

```VB.NET
Protected Sub SqlDataSource_Deleted(sender As Object, e As SqlDataSourceEventArgs) Handles SqlDataSource.Deleted
    If e.Exception Is Not Nothing
        ErrorMessage.Text = "We're sorry, but something went terribly while " & "deleting your genre."
        e.ExceptionHandled = True
    End If
End Sub
```

```C#
protected void SqlDataSource_Deleted(object sender, SqlDataSourceEventArgs e)
{
    if (e.Exception != null)
    {
        ErrorMessage.Text = @ "We're sorry, but something went terribly while deleting your genre";
        e.ExceptionHandled = true;
    }
}
```

Exercise 2 Solution

To expand the access to the Management folder for John and all users in the Editors role, you need to expand the roles attribute to include Editors, and add an additional allow element with its users attribute set to John:

```xml
<system.web>
<authorization>
    <allow roles="Managers, Editors" />
    <allow users="John" />
    <deny users="*" />
</authorization>
</system.web>
```

The roles attribute allows you to specify multiple roles separated by a comma. To grant the John account access, you need to add an additional allow element and fill in John's name in the users attribute.

From a maintainability perspective, it would be a lot better to add John to the Managers or Editors role if possible. However, you might end up giving John more rights than you want (he could then access anything that is a Manager or an Editor access). Generally, it's best to manage users through roles.
