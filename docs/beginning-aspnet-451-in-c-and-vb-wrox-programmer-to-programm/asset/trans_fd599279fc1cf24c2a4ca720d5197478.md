### How It Works

在每个 Try It Out 之后，你所执行的操作和输入的代码都会被详细解释。

> **NOTE** 像这样方框中的内容包含重要且不容遗忘的信息，与周围文本直接相关。

> **COMMON MISTAKES** 这些是在练习过程中容易犯的错误，以类似方框的形式呈现。当你在练习中遇到困难时，请务必仔细阅读。

至于文本中的样式：

- 新术语和重要词语在首次出现时以*斜体*显示。
- 文本中的代码以如下形式呈现：`Request.Query.Get("Id")`
- 不以 www 开头的 URL 前缀为 http:// 以明确其为 Internet 地址。文本中的 URL 以如下形式呈现：`http://imar.spaanjaars.com.`
- 你会看到许多以 tinyurl.com 或 bit.ly 开头的 URL，它们是方便的在线服务，用于使 URL 更短（更易输入）。在浏览器中输入 tinyurl.com 或 bit.ly 地址会带你到其最终目的地。
- 需要点击多个子菜单的菜单项有一个特殊符号，看起来像这样：File⊞ Folder。
- 与讨论无关的代码或完全省略或被省略号（三个点）和注释替换，如下所示：
```html
<tr
  <td style="white-space:nowrap;">
    Menu items go here; not shown
  </td>
</tr>
```
- 无论示例使用何种语言，都会使用三个点，你会看到它用于 C#、Visual Basic、HTML、CSS 和 JavaScript。当被指示在代码编辑器中输入时，你可以跳过三个点及其所在行后面的内容。
- 首次出现或其它相关代码的格式如下：
```javascript
dim roles As New ArrayList()
roles.Add("Administrators")
roles.Add("ContentManagers")
```

为了强调被其它代码包围的代码块，我使用如下加粗字体：

```
<appSettings>
  &lt;add key="FromAddress" value="planetwrox@example.com"/&gt;
&lt;/appSettings>
```

周围的代码用于更轻松地查看加粗代码应放置的位置。

- 通常当代码中的空白无关紧要时，这在 ASP.NET 标记和 HTML 中很常见。为了使代码适应本代码的边界，我将代码换行到多行并缩进应位于上一行的部分，如：

```
Dim result as String =
nWebConfigurationManager.AppSettings.Get("FromAddress")
```

如果你自己输入此代码，可以将其全部放在一行，或按喜好使用相同的换行。本书附带的示例代码通常将代码放在单行上。

- 屏幕上显示的文本通常为 Each Word With A Capital Letter，即使原始屏幕文本使用不同的大小写。目的是使屏幕内容与其它文本区分开来。
