> NOTE With this feature, the need to switch to Design View and set up the handler by double-clicking a control (as you did in an earlier exercise) or using the Events tab of the Properties Grid (as you see later) has been greatly reduced. It is great for people who prefer hand-coding the Design View and is especially useful in more complex pages where Design View isn't useful anyway.

Note there is a subtle difference between adding the handler using Markup View and Design View if you're using VB.NET. If you use Markup handler, the handler is added to the markup (OnChange="Checkbox1_CheckedChanged") and code is added to the Code Behind. When you use Design View, the code in Markup is not affected, and the code in Behind is annotated with the Handles keyword to indicate which event (for instance, the click on a button, the changed event of a checkbox, and so) the code responds to. At runtime, however, there is no difference.

+   7. Next, add the following line within the handler code that VS added for you:

# VB.NET

```
Protected Sub Checkbox1_CheckedChanged(sender As Object, e As EventArgs)
    Panel.Visible = Checkbox1.Checked
End Sub
```

# C#

```
protected void Checkbox1_CheckedChanged(object sender, EventArgs e)
{
    Panel.Visible = Checkbox1.Checked;
}
```

+   8. Save all your changes and request the page in the browser by pressing Ctrl+F5.

+   9. When the page first loads, you will see the checkbox and the text beside it. When you look at the HTML for the page in the browser (right-click the page and choose View Source or View Page Source depending on your browser), you'll only see the checkbox; there's no code for the Panel control at this stage sent to the browser. When you click the checkbox to place a checkmark in it, the page reloads and shows you the text you entered in step 5.

> WARNING If anything happens, go back to the source of the page in VS and ensure that AutoPostBack is True on the CheckBox control.

If you look at the HTML in the browser, you'll see that the text you typed in step 5 is wrapped in a <div> with an id of Panel1:

```
<div id="Panel1">
    I am visible now
</div>
```
