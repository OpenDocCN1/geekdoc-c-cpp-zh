The Query Designer in SSMS is a very helpful tool for creating new queries against your database.
Instead of hand-coding the entire SQL statement in the SQL pane, you use the Diagram and Criteria
panes to create your queries visually. You can also use the SQL pane to make manual tweaks

contain the text rock. The two criteria are both applied at the same time using the AND keyword,
