# How It Works

When you added the CustomValidator ID="CustomValidator" you set up two event handlers, for the client-side and one for the server-side validation control, both in the following snippet:

```
<asp:CustomValidator ID="CustomValidator" runat="server" ErrorMessage="Enter your
home or phone number ClientValidationFunction="validatePhoneNumbers"
OnServerValidate="CustomValidator_Validate"
Display="Dynamic" /></asp:CustomValidator>
```

If you're using VB.NET, you won't see the OnValidationError attribute that is set up in the Code Behind with the handlers used.

The JavaScript validatePhoneNumbers that you set in the ClientValidationFunction is triggered when you click the button. This function is defined in the markup section of the control and contains references to the text boxes for the phone numbers:

```
var phoneHome = document.getElementById('<PhoneHome.ClientID %>');
var phoneBusiness = document.getElementById('<PhoneBusiness.ClientID %>');
```

Here you can use the server-side ID properties of the controls which have been transformed into their client counters. This is a much better than hard-coding the id attributes of the text boxes in the HTML, which can be changed easily by the ASP.NET runtime. You see how and why this is important in the preceding chapter.

To make the JavaScript you possess in the browser shorter and easier to read, you can use the ClientID property to "fix" the IDs of the phone number controls. Because you will likely have two TextBox controls in a single page, you can assume that you won't end up with two controls with the same name if you fix the control IDs. To do this, you will need to set the ClientID for these two controls to Static, like this:

```
<asp:TextBox ID="Phone" runat="server" ClientID="Static" />
<asp:TextBox ID="Business" runat="server" ClientID="Static" />
```

Because the controls are now fixed, they end up as-is in the final HTML:

```
var phoneHome = document.getElementById('PhoneHome');
var phoneBusiness = document.getElementById('PhoneBusiness');
```

Eventually, the IDs are passed to the JavaScript function getElementById on the document object to get a reference to their respective text in JavaScript. In Chapter 11, which deals with jQuery, I discuss an alternative to using getElementById. If one of them is not an empty string, the validation succeeds.
