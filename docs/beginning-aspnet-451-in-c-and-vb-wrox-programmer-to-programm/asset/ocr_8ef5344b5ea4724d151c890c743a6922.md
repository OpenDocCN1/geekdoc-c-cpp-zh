+   7. Modify the code for the DetailsView to end up like this:

```
<asp:DetailsView AutoGenerateRow="false" Id="DetailsView"
DefaultMode="Insert" run="server">
<Fields>
    <asp:BoundField DataField="Name" HeaderText="Name" />
    <asp:CommandField ShowInsertButton="True" ShowCancelButton="false" />
</Fields>
</asp:DetailsView>
```

+   8. Next, position your cursor before the angled bracket (>) of the opening tag of the DetailsView, type a space, and then type Insert.
