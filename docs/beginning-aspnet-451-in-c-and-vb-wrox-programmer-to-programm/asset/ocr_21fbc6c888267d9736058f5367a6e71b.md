# TRY OUT Seeing the Page and Control Life Cycles at Work

To give an idea of the different events that you can hook into during a page or control's life cycle and the order in which they fire, this Try It Out shows you how to set up a page that displays data from the Genres table using a DataSource. You also add a button to the page that you can use to trigger a postback so influences things. You hook up a number of event handlers to a few interesting events of controls on the page so you can see in what order they are called. You can apply the concepts learned in this exercise to any other page or control that raises events to get a better understanding of how they operate.

+   1. Inside the Demo folder, create a file called Events.aspx. Make sure it's based on your custom page so it inherits from BasePage. Set the page's title to Events Demo.

+   2. Switch to the Design View, drag a GridView into the cpMain placeholder, and then hook it up to a new SqlDataSource using the GridView's Smart Tasks panel. Use PlanetWxConnectionString the connection string and configure the control to retrieve all columns from the Genres table. There's no need to set up, update, or delete behavior, nor do you need to select specific columns or add a clause.

+   3. Back on the GridView's Smart Tasks panel, enable sorting by selecting the second check box. When you're done, your code should look like this:

```
<asp:GridView Id="GridView" runat="server" AutoSorting="True"
AutoGenerateColumns="False" DataKeyNames="Id" DataSourceID="SqlDataSource1"
<Columns>
  <asp:BoundField DataField="Id" HeaderText="Id" ItemVisible="False"
  ReadOnly="True" SortExpression="Id" />
  <asp:BoundField DataField="Name" HeaderText="Name" SortExpression="Name" />
  <asp:BoundField DataField="SortOrder" HeaderText="Sorter"
  SortExpression="SortOrder" />
</Columns>
</asp:GridView>
```

+   4. Make sure you're in Markup View, and directly under the opening Content tag for the cpMain placeholder and before the GridView add the following markup that creates a table with two cells, each with a large heading (h1) and a Label control called NoPostback and Postback, respectively.

```
<table>
<tr>
<td><h1>id:NoPostback</h1><asp:Label Id="NoPostback" runat="server" /></td>
<td><h1>id:Postback</h1><asp:Label Id="Postback" runat="server" /></td>
</tr>
</table>
```

+   5. Switch to Design View, and below the GridView draw a Button control and double-click it in Design View to set up an event handler for its Click event in the Code Behind.

+   6. Switch to Design View and double-click the gray and red area of the page to set up a handler for the control's Load event.
