
# Advanced Filters

Besides the basic filters you just saw, jQuery supports a lot more filters that enable you to get items based on the text they contain, whether or not they are visible, and also on any attributes they may have. Additionally you can find filters to get elements (like buttons, check boxes, radio buttons, and so on) and a number of selectors that enable you to select children, parents, siblings, and descendants. The following table lists the ones you'll use most. The jQuery documentation gives you access to the complete list, with full examples showing how they work.

| FILTER | PURPOSE |
| --- | --- |
| :contains(text) | Matches an element by the text it contains. Example: `$(td:contains('Row 3')).css('color', 'green');` If you leave out the td, the entire table will be green. This is because the table is matched with (one of its children contains the text Row 3) so the color is applied to the table, which in turn changes the text in each cell to green. Note how I am using double quotes for the text string to avoid closing the single quote from the selector. |
| :has(element) | Matches elements that contain at least one of the given elements. Example: `$(header:has("span")).css('color', 'green');` This matches only the h2 because it's a header (:header) and contains a <span>element</span>. |
| [attribute] | Matches an element based on the given attribute. Example: `// Matches the button and the text box as they have a type attribute but would also match other elements with a type attribute` `$('[type]').css('color', 'green');` To select only controls with a type attribute you can use this: `$('input[type]').css('color', 'green');` You need to type some text in the text box to see the green font color. |
| [attribute=value] | Matches an element based on an attribute and that attribute's value. Example: `// Matches just the text box` `$('[type=text]').css('color', 'green');` |

# MODIFYING THE DOM WITH JQUERY

Once you have a matched set, you want to do something with it. For example, you may want to apply a CSS class or style to the items in it. You may want to append some behavior to them, like adding a class handler that fires code when you get clicked. You've already seen examples of using the css and bind methods, but jQuery has a lot more to offer. In the next two sections, we show how to work with various CSS methods and how to set event handlers.

# CSS Methods

CSS is supported in jQuery a few different ways. First, the css method enables you to retrieve a specific CSS value (like the color of an item), and to set one or more properties on a set of elements. Secondly, methods like addClass, removeClass, toggleClass, and hasClass enable you to alter or inspect the CSS classes that are applied to elements. Furthermore, a couple of methods enable you to work with the dimensions and position of an element. I discuss only the most common ones, but you can look up the entire list at jQuery website. The examples use again the same HTML fragment as before, so it's easy to follow along if you want to try them in your browser.

# css(name, value)

This method enables you to set a CSS property on a matched element. The name argument refers to a CSS property (such as border, color, and so on) and the value defines the style you want to apply. The following example changes the background color of the hi element:

```javascript
$('hi').css('background-color', 'green');
```

# css(name)

This method retrieves a specific CSS value based on the property you pass to it. The following example alerts because that's the font-style of the <span>element in the level 2 heading:

```javascript
alert($('#h2 span').css('font-style'));
```

You can use this in your jQuery scripts; for example, you can use it to toggle the font-style between italic and normal or set multiple elements to the same style.

# css(properties)

This is quite a powerful method because it enables you to set properties on the matched elements in one fell swoop. The following example changes the color of all cells in the table to red, changes the font to Verdana and set their padding to 10px. You pass the data to what is called an anonymous object when you wrap the set of properties in a pair of curly braces ({}), each property and value by a colon (:):

```javascript
$('table td').css({'color': 'red', 'font-family': 'Verdana', 'padding': '10px'});
```

# addClass, removeClass, and toggleClass

The addClass, removeClass, and toggleClass methods allow you to add, remove, or toggle CSS classes on elements. For example, addClass adds a new class to the matched set, removeClass removes it, and toggleClass removes the class if it's present or adds it if it's not. This is much more efficient than manipulating styles directly.
