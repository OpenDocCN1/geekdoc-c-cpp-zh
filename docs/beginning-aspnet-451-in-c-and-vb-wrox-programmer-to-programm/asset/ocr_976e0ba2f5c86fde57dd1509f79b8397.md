Another way to convert data types is using the Convert class.

> Note Classes are an important concept in .NET so they are discussed in their section later in this chapter. For now it's important to understand that a class is like a blueprint for objects that are used in .NET. You can create your own classes, but you will also use many of the standard classes that are part of the .NET Framework.

The Convert class contains functionality to convert a number of data types into another type. The following is a simple example of converting a String containing a value that looks like a boolean into a Boolean type:

# VB.NET

```
Dim myBoolean1 As Boolean = Convert.ToBoolean("True")   ' Results in True
Dim myBoolean2 As Boolean = Convert.ToBoolean("False") ' Results in False
```

# C#

```
bool myBoolean1 = Convert.ToBoolean("true");   // Results in true
bool myBoolean2 = Convert.ToBoolean("false"); // Results in false
```

Besides the ToString method, Convert offers you a host of conversion methods, including Int32(for integer types), ToDateTime(for dates), and ToString.

Another way to convert one type into another is using casting. Casting you actually force one type into another, which is different from converting, in which the underlying value of a data is transformed into a new value.

Casting only works for compatible types. You can, for example, cast a DateTime to an Integer. You can, however, cast similar types, like a Double to an Integer or a String to an Object. The reverse of the example isn't always true. Earlier that every data type in the .NET Framework is based on the Object data type, meaning that, for example, a String is an Object.
