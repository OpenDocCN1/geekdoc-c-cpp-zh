# RenderCurrentNodeLink

Determines whether the last element of the path (current page) is rendered as a text link or as plaintext. The default is False, which is usually fine because you are already on the page that element is representing, so there's no need for a link.

# ShowToolTips

Determines whether the control displays tooltips (retrieved from the description attribute of the siteMapNode elements in the Web.itemap file) when the user hovers over the elements in the path. The default is True, which means the tooltips are shown by default.

Depending on your personal preferences, you don't need to define any of the styles of the SiteMap control. In the final page in the browser, the SiteMap consists of many anchor tags <a> and plaintext. If you have set up a selector for anchors in your CSS file, the SiteMap automatically shows in one line with the others of the page.

# TRY OUT Creating a Breadcrumb with the SiteMap Control

A good location for the SiteMapPath is the global map page of the site. That way it becomes visible in all your pages automatically.

+   1. Open the map page in Markup View and locate the MainContent <section> element. Right after its opening, and the <asp:ContentPlaceHolder> tag, press Enter to create some room and draw a SiteMapPath from the Toolbox. Right add two line breaks <br />. You should end up with code like this:
```html
<section id="MainContent">
<asp:SiteMapPath ID="SiteMapPath" runat="server" />:asp:SiteMapPath><br /><br />
<asp:ContentPlaceHolder ID="MainContent" runat="server" />
```
2. Save the changes and then Request Default; in the browser. The page now shows the path from the root of site (identified by the Home item) to the current page. Click a few of the items in the Menu or TreeView control to navigate around the site and you'll see the breadcrumb for each page. Figure 7-11 shows the breadcrumb for the All Reviews in Firefox. The All Reviews is a subset of Reviews, which in falls under the Home root element.
