You opened the page in your browser using the right-click View in Browser option or by pressing Ctrl+F5. With the View in Browser you always open the page by right-click. With the Ctrl+F5 shortcut, you open the page that is currently the active document in the Document Window, or the file that has been set as the Start Page for the website. Additionally, all open files are saved automatically, and the site is checked for errors before the requested page is opened in the browser.

You can assign a page as the Start Page by right-clicking it in the Solution Explorer and choosing Set As Start Page. If you want to control this behavior at a later stage, right-click the Solution in the Solution Explorer and choose Properties Properties. In the Start Options category, you can indicate that you want the currently active page to open, or can assign a specific page, as shown in Figure 2-14.
