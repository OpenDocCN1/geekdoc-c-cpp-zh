# Data Types and Variables

Microsoft .NET supports a large number of different programming languages, including VB.NET, C#, and others. All these languages are able to communicate with each other. For example, you can write some code in C#, using Visual Studio Express 2013 for Windows Desktop to compile it to a dll file (a file with reusable code that can be consumed by other .NET applications), and then use in a web application that uses VB.NET as the primary language. Because of this interoperability, it's necessary to agree on some system that enables all .NET languages to understand each other. This system is called the Common Type System (CTS). It is CTS that defines the data types that are accessible by all CTS-compliant languages. Each language is free to define a set of primitive types, which are essentially shortcuts or aliases for the more complex types in the .NET Framework. Even, if the CTS defines a type called System.Int32, a language like C# is free to alias this type as int and VB is free to alias this as Integer to make it easier for a developer to work with.

The following table lists the most common CTS types in the .NET Framework and their C# and VB.NET aliases. Table also lists the ranges of the variables and what they are used for.

| .NET | C# | VB.NET | DESCRIPTION |
| System.Byte | byte | Byte | Used to store small, positive numbers from 0 to 255. Defaults to 0 when no value is assigned explicitly. |
| System.Int16 | short | Short | Capable of storing numbers between -32,768 and 32,767. Defaults to 0. |
| System.Int32 | int | Integer | Capable of storing numbers between -2,147,483,648 and 2,147,483,647. Defaults to 0. |
| System.Int64 | long | Long | Holds large numbers between -9,223,372,036,854,775,808 and 9,223,372,036,854,775,807. Defaults to 0. |
| System.Single | float | Single | Stores large fractional numbers with decimals between -3.4028235E-38 and 3.4028235E+38. Defaults to 0.0. |
| System.Double | double | Double | Can hold large fractional numbers. It is not as accurate as the Decimal when it comes to the fractional numbers but when extreme accuracy is not a requirement, you should prefer the Double over the Decimal, because the Double is a little faster. Defaults to 0.0. |
| System.Decimal | decimal | Decimal | Stores extremely large fractional numbers with a high accuracy. Defaults to 0. This data type is used to store monetary values. |
| System.Boolean | bool | Boolean | Used to hold a simple boolean value: True or False in VB, and true or false in C#. Defaults to False. |
