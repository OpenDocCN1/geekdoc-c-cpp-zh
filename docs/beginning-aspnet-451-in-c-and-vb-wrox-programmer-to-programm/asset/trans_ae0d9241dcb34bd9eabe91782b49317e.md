## 前言

像 HTML5 和 CSS3 这样的新兴标准的采用率每天都在增长。过去只能在厚客户端应用程序中实现的功能正在网络上成为现实。随着浏览器每天变得更快更好，随着更多常见任务以可重用库的形式出现，以及几乎所有大型 Web 框架的开源，我们的万维网正变得热闹非凡。移动设备的普及和多样化的移动应用程序开发技术使得开发人员进一步考虑将选项和可访问的网络作为其表达媒介。

在此期间，客户端库如 jQuery 和 jQuery Mobile、Angular.js、Knockout.js 以及服务器端技术如 ASP.NET 使得通常困难且繁琐的任务变得易于处理。更不用说，像 Visual Web Developer 这样的免费工具使得开发比以往任何时候都更加容易。现在成为一名 Web 开发人员确实是一种乐趣，很高兴看到这本书出版，让每个人都能轻松上手 Web 开发。

本书作者 Imar Spanjaans 自 2008 年起一直是 ASP.NET 的 Microsoft MVP，这次他还加入了 ASP.NET Insiders 团队，我们在产品进入公开测试版之前就进行想法交流和预发布产品测试。在开发过程中，Imar 一直是团队反馈的源泉，我确信他未来也会继续如此。

在《Beginning ASP.NET 4.5.1: in C# and VB》中，他从基础开始，深入构建概念，并涵盖了 ASP.NET 4.5.1 和 Visual Studio 2013 的最新功能。无论您是刚开始 Web 开发还是升级到 ASP.NET 4.5.1，这本书都绝对值得加入您的工具箱。

认识 Imar 是我的荣幸，我想感谢他对我们社区的贡献。他的见解和想法对 ASP.NET 和 Visual Studio 背后的产品团队来说是无价的。我希望他的见解也能帮助到您。

## 引言

要构建有效且吸引人的数据库驱动网站，您需要两样东西：一个坚固快速的框架来运行您的网页，以及一个丰富全面的环境来创建和编程这些网页。借助 ASP.NET 4.5.1 和 Visual Studio 2013，您可以获得两者。它们共同构成了创建动态和交互式网站的平台。

ASP.NET 4.5.1 建立在其流行的前身 ASP.NET 2.0、3.5、4.0 和 4.5 之上。在保持与使用这些旧版本构建的站点向后兼容的同时，ASP.NET 4.5.1 和 Visual Studio 2013 引入了新颖诱人的功能。

您还会在 ASP.NET 框架和 Studio 中找到许多变化——大大小小的。 其中一些变化包括实体框架的加入（第 14 章讨论），第 18 章中 Browser Link 的引入以及第 19 章中讨论的用于网站的发布向导。

如果您尚未使用 Visual Studio 2012 和 ASP.NET 4.5，您还会欣赏改进的 CSS 和 JavaScript 编辑器（分别在第 3 章和第 10 章讨论），NuGet 的加入（第 11 章），以及在 VS 2012 中添加的页面检查器（第 18 章）。VS 2013 在此基础上进行了构建。

如果您熟悉 ASP.NET 的早期版本，您会很高兴在新版本的框架中找到许多让开发人员生活更轻松的功能。我在本书中适当的地方提及并讨论了这些功能。要获取 ASP.NET 中所有功能的完整列表，请查看官方 ASP.NET 网站上的以下白皮书：

www.asp.net/visual-studio/overview/2013/release-notes

如果到您阅读本书时该链接不再有效，请在 www.asp.net 上搜索：“What's new in ASP.NET 4.5.1.”

Visual Studio Express 2013 for Web 最好的地方可能是它的价格：它可以免费获得。这使得 Visual Studio 和 ASP.NET 成为当今最具吸引力和说服力的 Web 技术。

## 本书适合谁

本书适合任何想要学习如何在 Microsoft 平台上构建丰富且交互式网站的人。通过从中获得的知识，您可以为构建任何类型的网站打下坚实的基础，从简单的爱好相关网站到可能用于商业目的的网站。

任何 Web 编程新手都应该能够跟上，因为不假设有 Web 开发背景，尽管如果您对 HTML 有基本了解会有所帮助。
