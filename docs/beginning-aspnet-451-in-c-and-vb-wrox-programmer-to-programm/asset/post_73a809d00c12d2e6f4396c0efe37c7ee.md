# How It Works

At times, pages with inline code behave the same as pages that use Code Behind. In both cases, the ASP.NET run time uses the Page_Load code and executes any code it finds in it. In the Try It Out, meaning setting the Text of Label1 to a welcome message and today's date and time. The biggest difference between the two options is where the code is stored. In the same disk. When using Code Behind, the VB or C# code you write is stored in a separate file named after the Web Form.

Because pages with Code Behind are easier to manage, I'll use them exclusively for the Planet Wrox website.

In this example, the two code looks very similar to the VB.NET code. The code that sets the Label's text is almost identical. Two languages: VB.NET uses an ampersand (&) to join two pieces of text together, but C# uses the plus (+) character. You can also use the plus character in VB.NET to concatenate strings together, with few caveats, as you'll learn in Chapter 5. The other difference is that C# code must be terminated with a semicolon (;) to indicate the end of a unit, but Visual Basic uses the underscore (_). If you want to split a line over multiple lines in Visual Basic, you use the underscore (_ character). In earlier versions, VB.NET required the underscore in a lot of different places. However, in recent versions of Visual Basic, the designers of the language have greatly reduced the places where you must use underscore.

One place where you need to use the underscore to split over multiple lines is right before the Handles keyword that you saw:

```
Protected Sub Page_Load(sender As Object, e As EventArgs)
    Handles Me.Load
    Label1.Text = "Hello World; the time is now " & DateTime.Now.ToString()
End Sub
```

# Adding Markup to Your Page

You have a number of ways to add HTML and other markup to your pages. First of all, you can simply type it in the Markup View window. However, this isn't always the best option, because it forces you to use a lot of code by hand. To make it easier to insert HTML in the page and apply formatting to it, the Design View offers a number of helpful tools. These tools include the Formatting toolbar and the Format Table menu. For these tools to be active, you need to have the document in Design View. If you're working in Split View mode, you must make sure that the Design View has the focus, or you'll find that most of the tools are not available.

# Inserting and Formatting Text

You can type text in both Design View and in Markup View. Simply place the cursor at the desired location and start typing. When you switch to Design View, the Formatting toolbar becomes available, with the options shown in Figure 2-15.

![](img/9e033e3b9560597824f8b22941d6d8bb_91_0.png)

Many of the buttons on the toolbar function exactly the same as in other editing environments. For example, the B button formats your text with a bold font. Similarly, the I and the U buttons italicize and underline your text, respectively. The drop-down list labeled Block Format enables you to insert HTML elements like <p> for paragraphs, <h1> through <h6> for headings, and <ul>, <ol>, and <li> for lists. You can choose an item from the drop-down list to insert it where it is inserted in your page, or you can select text first and choose the appropriate block element from the list to wrap the selected text.
