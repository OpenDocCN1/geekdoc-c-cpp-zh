
# How It Works

You haven't changed much in the actual process of inserting the Picture into the database. The ListView control collects all the relevant data from the page and calls the InsertMethod, which then inserts the item in the Picture table in the database EF. What is different from the way you set up the templates and the code that inserts the picture. First, inside the ItemTemplate you added an <asp:Image> to place the plain text label. You can see in Figure 14-14, this displays the image, rather than its URL.

To enable a user to upload the images, you replaced the TextBox control in the InsertTemplate with a FileUpload control. Additionally, you added a few validation controls to force the user to enter the required fields. As soon as you click the button, the page posts back and the ListView calls the InsertMethod. Inside this method, you added some code that “finds” the upload control in the InsertItem template. Because you can have multiple controls with the same name (for example, a FileUpload control in the InsertTemplate and one in the EditItemTemplate), you cannot access FileUpload directly. Instead, you need to use FindControl on the Insert object to search for the control:

## VB.NET

```vb
Dim FileUpload1 As FileUpload =
CType(ListView.InsertItem.FindControl("FileUpload1"), FileUpload)
```

## C#

```csharp
FileUpload FileUpload =
(FileUpload)ListView.InsertItem.FindControl("FileUpload1");
```

When you have a reference to the FileUpload control, you can check its HasFile property to see if a file has been uploaded. Additionally, you can check FileUpload1.FileName.EndsWith(".jpg") to see if a file has a .jpg extension. To ensure that this test is carried out when the user has uploaded a file, use Or Else in VB and || to short-circuit the logic in the If statement, as explained in Chapter 5.

If the user doesn't upload a file, the code in the If blocks runs. You use FindControl to find the CustomValidator control and set its IsValid property to False (false in C#). This calls the control to display its ErrorMessage property when the page renders. It also adds an error to the ModelState using ErrorDetail. This is needed to tell the ModelBinder that validation failed, which in turn tells the ListView to stay in Insert mode and display the data that the user already added along with the error message.

The other validation controls make to sure that a title and description are encoded in the same way as what you saw in Chapter 9.

If the user uploads a valid .jpg file, the code continues. It then executes the following code to determine the physical and virtual folder for the file, its name, and its extension:

## VB.NET

```vb
Dim virtualFolder As String = "~/igPics/*"
Dim physicalFolder As String = Server.MapPath(virtualFolder)
Dim fileName As String = Guid.NewGuid().ToString()
Dim extension As String = System.IO.Path.GetExtension(FileUpload1.FileName)
```

## C#

```csharp
string virtualFolder = "~/GigPics/*";
string physicalFolder = Server.MapPath(virtualFolder);
string fileName = Guid.NewGuid().ToString();
string extension = System.IO.GetExtension(FileUpload.FileName);
```

The variable virtualFolder holds the virtual location — starting off the root of the website — of the folder where uploaded images are stored. Using Server.MapPath in its default location of C:\ASP.NET\Site, the physical-Folder variable contains C:\ASP.NET\Site\GigPics.

Next, a random filename is generated using Guid.NewGuid(). The Guid class is able to generate more or less filenames that are guaranteed to be unique across time and space. This code assigns the fileName something like f68de055-2dbe-468a-de045f9462e3, which guarantees a unique filename. Finally, the extension of the file is retrieved using the static GetExtension method of the Path class in the System.IO namespace.

At this stage, you have all the required information to store the file on disk, and then update the data-base. Storing the file on disk is easy using the SaveAs method of the FileUpload control.

## VB.NET

```vb
FileUpload.SaveAs(System.IO.Path.Combine(physicalFolder, fileName + extension))
```

## C#

```csharp
FileUpload.SaveAs(System.IO.Path.Combine(physicalFolder, fileName + extension));
```

This code takes the physical folder, the filename, and passes them to the Combine method of the Path class that builds up the file path. This path is then sent to the SaveAs method, which saves the file at the requested location.

Finally, the picture is updated with the new ImageUrl:

## VB.NET

```vb
picture.ImageUrl = virtualFolder + fileName + extension
```

## C#

```csharp
picture.ImageUrl = virtualFolder + fileName + extension;
```

This assigns something like ~/GigPics/f68de055-2dbe-468a-de045f9462e3.jpg to the ImageUrl property, which is the new virtual location of the uploaded image. Right after you insert the new image, the ListView is updated and shows the new image, using the Image control with its ImageUrl set to the image you just uploaded.

You can imagine if you upload a large number of images for a single photo album, the page becomes more difficult to manage. This is especially true at the front end, where users may be accessing your site over a slow network connection. Instead of presenting all the images in the photo album on a single page, you can split the photo album into multiple pages, enabling users to go from page. You will see how to do this in the next section, which discusses the DataPager.

## Introducing the DataPager Control

The DataPager is a separate control that you can use to extend another data-bound control. Currently, .NET Framework lets you use the DataPager to provide paging capabilities to the ListView control, which the developer community has active implementations for, such as the GridView.

You can hook up the DataPager to the ListView in two ways: You can either define it in the LayoutTemplate of the ListView or you define it entirely within the ListView. In the first case, the DataPager knows how to provide paging capabilities automatically. In the second case, you need to set the PagedControlID property of the DataPager to the ID of a valid ListView. This is useful if you want to place it at a different location on the page, such as in the Sidebar area.
