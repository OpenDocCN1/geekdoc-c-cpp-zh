+   The next step is to add the web server account. Click the Edit button visible in Figure 19-11, and then click the Add button. Type IIS AppPool followed by the name of the application pool. If you followed along with previous exercises, the application pool is called .NET v4.5, which means the account is IIS AppPool\.NET v4.5. Click OK to add the account.

![](bbox=[0.656, 0.423, 0.946, 0.706])

With the account selected you return to the Group or User names list, ensure only the Last Folder Contents and Read are selected. Your dialog box should end up similar to Figure 19-12.

FIG. 19-12

+   Close the dialog box so you return to the Properties dialog box in Figure 19-11.

+   Click the Advanced button to open the Advanced Security settings dialog box. For Windows 7 and Server 2008 R2, click the Change Permissions button and check the Replace Child Objects Permissions box. For Windows 8 and Server 2012, you will find this check box on the Advanced Security settings dialog box. This forces Windows to apply the same security permissions to all subfolders and binders, replacing all existing settings. Click OK and then confirm the changes were made. Finally, close all remaining dialog boxes.

+   Back in File Explorer / Windows Explorer, click App_Data from the Release folder, open its properties box and then its Security tab, and edit the permissions for the web server account you added in step 4 by adding permissions (in this turns some of the other permissions to be selected as well). You need to click the Edit button first to bring the Properties dialog into editable mode. Figure 19-13 shows the completed dialog.

Click OK to close the dialog box.
