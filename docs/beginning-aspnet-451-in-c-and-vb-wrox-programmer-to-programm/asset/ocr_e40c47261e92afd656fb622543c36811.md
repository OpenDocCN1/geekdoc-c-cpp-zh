The second question needs to be answered to apply a certain style in your page is about part of the element must be styled. You do do this with properties.

# Properties

Properties are the part of the element that you want to change with your style sheet. The CSS specification defines a long list of properties (VS' IntelliSense lists more than 100 items), although you don't use all of them in most websites. The following table lists some of the most common CSS properties and where they are used.

| PROPERTY | DESCRIPTION | EXAMPLE |
|---|---|--|
| background-color | Specifies the background color or image of an element. | background-color: White; |
| background-image | | background-image: url(Image.jpg); |
| border | Specifies the border of an element. | border: 3px solid Black; |
| color | Changes the font color. | color: Green; |
| display | Changes the elements as are displayed, enabling you to hide or show them. | display: none; This causes the element to be hidden, and not take up any screen space. |
| float | Enables you to "float" an an element in the page using a left or right float. Other content is then placed on the opposite side. | float: left; This causes other content following a float to be placed at the top-right corner of the element. You see how this works later in the chapter. |
| font-family | Changes the appearance of fonts used on your page. | font-family: Arial; |
| font-size | | font-size: 18px; |
| font-style | | font-style: italic; |
| font-weight | | font-weight: bold; |
| height | Sets the height or width of elements in your page. | height: 100px; |
| width | | width: 200px; |
| margin | Sets the amount of free space inside (padding) and outside (margin) of an element. | padding: 0; margin: 20px; |
