# How It Works

When a page based on a master page is requested in the browser, the server reads in both content page and the master page, merges the two processes, them, and sends the final result to the browser. In step 6 of this exercise you saw that the HTML in the browser for the requested page contained markup from both files.

Master pages will save you a lot of work when it comes to updating or radically changing the layout of your site. Because the entire design and layout of your site is defined in the master page, you only need to touch that single file when you want to make any changes. All content pages will pick up the changes automatically.
