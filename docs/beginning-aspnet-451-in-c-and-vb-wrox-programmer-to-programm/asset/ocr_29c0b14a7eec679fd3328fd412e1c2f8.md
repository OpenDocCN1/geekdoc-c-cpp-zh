# The ListView Control

Up until now, you have seen a few data-bound controls at work. You saw the GridView which is powerful because it supports updates, deletes, sorting, and paging of data, but lacks inserting and generates a lot of HTML markup. You also saw the Repeater control that gives you precise control over the generated HTML, but lacks most features that the other controls have, such as update and delete behavior and sorting and filtering capabilities. Finally, you saw the DetailsView that enables you to insert or update one at a time.

The ListView is a "best of all worlds" control, combining the rich feature set of the GridView with the control over markup that the Repeater gives and adding the insert behavior of the DetailsView. The ListView enables you to display data in a variety of formats, including a grid (rows and columns like the GridView), a bulleted list (similar to how you set up the Repeater earlier in this chapter), and in Flow format, where all the items are placed in the HTML after each other, leaving you to write some CSS to format the data.

The ListView displays and manages data through templates that enables you to control many of the different views that the ListView gives you on its underlying data. The following table describes all the available templates that you can add as direct children of the ListView control in the markup of the page:

| TEMPLATE | DESCRIPTION |
|---|---|
| <LayoutTemplate> | Serves as a container. It enables you to define a location where the individual data items are placed. The data items, presented through the ItemTemplate and AlternatingItemTemplate, are then added as children of this. |
| <ItemTemplate> <AlternatingItemTemplate> | Define the read-only mode for the control. When used together, they enable you to create a "zebra effect," where odd and even rows have a different appearance (usually a different background color). |
