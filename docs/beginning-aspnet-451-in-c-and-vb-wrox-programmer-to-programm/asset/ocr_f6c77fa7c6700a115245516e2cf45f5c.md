AssociatedControlID property. This makes it easy to put focus on the controls in the browser because clicking a Label puts the cursor in the associated TextBox.

When you click the Save Profile button, the values are retrieved from the four TextBox controls and stored in the profile. When the page loads the first time, the reverse of this process takes place: the controls are prefilled with the values from the profile.
