
Now that you've seen the most important jQuery queries, from simple selectors to advanced animation options, you can use this knowledge to make the contact form of the Planet Wrox site a little more attractive.

## ANIMating the Contact Form

In this exercise you apply two animations: one is triggered when the user submits the contact form and slowly slides it until it disappears. The other animation is to show and hide the Message Sent label, attracting more attention until it completely disappears.

- 1. Start by adding an additional text paragraph below the Message Sent label in the ContactForm.ascx control in Markup View. This paragraph will be visible after the form has been submitted, and remains even after the Message Sent text has hidden. Within the paragraph tags add text that thanks the user for their service. Add id and runat="server" attributes to the paragraph (so you can program it in Code Behind) and set its Visible property to False. Finally, set the CssClass attribute of the Label placed before the paragraph to Attention. You should end up with this:
```html
<asp:Label Id="Message" runat="server" CssClass="Attention"
Text="Message Sent" Visible="False" />
<p runat="server" id="MessageSentPara" visible="False">Thank you for your message.
We'll get in touch with you if we need.</p>
```

- 2. Wrap the entire table that holds the controls in a \<div＞ and set its id to TableWrapper. Tables can't be easily resized using slideUp and slideDown, but by wrapping the table in a \<div＞ you can resize the element:
```html
<div id="TableWrapper">
<table class="auto-style" runat="server" id="FormTable">
...
</table>
</div>
```

- 3. In previous versions of VS, you would not see IntelliSense for jQuery and other script libraries in user controls. Because VS doesn't know which pages or master control will be used. Because the script references are added to these pages, the user control doesn't know of existence. You could work around that by adding a reference to the library in the control and hide it in a server-side comment, or remove the reference when you deploy your site. However, VS 2013 has a much cleaner solution. By adding a JavaScript file with the special name of _references to your site, VS gives IntelliSense for all script file references it finds in file. To set this up, first add a JavaScript file called _references.js to the Scripts folder (right-click the folder and add JavaScript file). Then from the Scripts folder in the Solution Explorer, drag jquery-2.0.3.js into the open JavaScript file. VS adds the following code for you:
```javascript
/// <reference path="jquery-2.0.3.js" />
```

Save the code and close and reopen the ContactForm.ascx file. Now on on, you'll see IntelliSense for the jQuery library, no matter where you're adding your jQuery code. Visual Studio looks at the file reference you added to this file and looks for matching files with intellisense.js extension, which it uses to build up IntelliSense the documentation tool tips. You can add other to _references.js as well to light up IntelliSense for JavaScript libraries. I really like this feature because it gives you IntelliSense everywhere without messy hooks or double references. You never have to include a reference to this special file in the pages or controls in your site; it serves purely as a development-time feature.

- 4. Back at the control ContactForm.ascx scroll down to the end of the control's markup, and add a \<script> element and the following jQuery code that fires when the form is about to be submitted.

```javascript
<script>
$function()
{
  $('form').bind('submit', function ()
{
    if (Page_IsValid)
    {
      $('#TableWrapper').slideUp(3000);
    }
  });
  // Code from step 5 goes here
</script>
```

- 5. Right before the closing \</script> tag and after the closing brace, parenthesis, and semicolon of the jQuery document ready handler, add the following bold piece of JavaScript:

```javascript
}};
function pageLoad()
{
  $('.Attention').animate({ width: '600px' }, 3000);
  animate({ width: '100px' }, 3000).fadeOut('slow');
}
</script>
```

The pageLoad method (which is part of the client-side JavaScript made by ASP.NET AJAX) serves the same purpose as jQuery's document ready, with one exception: it fires after a partial page update, which is what takes place after you submit the form because of the UpdatePanel in the user control.

- 6. Switch to Code Behind and add the following line of code to the SendButton_Click method. This code makes the text paragraph visible when the form is submitted and the e-mail message is sent:

```VB.NET
Message.Visible = True
MessagesSentPara.Visible = True
FormTable.Visible = False
```

```c#
Message.Visible = true;
MessagesSentPara.Visible = true;
FormTable.Visible = false;
```

- 7. Save all your changes and close the user control because you're done with it.

- 8. Open the Monochrome.css file from its theme folder and add the following CSS declaration to the bottom of the file:

```css
Attention {
border: 4px solid red;
padding: 10px 0;
width: 100px;
margin: auto;
display: block;
text-align: center;
}
```

- 9. Copy the same declaration to the DarkGrey CSS file.

- 10. Save your changes and then refresh the Planet Wrox site in your browser. Choose the Contact Us item (from About) from the Menu or TreeView control, fill in the form, and click Send.
