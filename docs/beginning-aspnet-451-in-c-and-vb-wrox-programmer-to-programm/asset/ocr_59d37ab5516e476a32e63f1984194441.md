# INTRODUCTION

The site folder contains the site you'll build throughout this book, and the Release folder will contain your final version at the end of this book. Whenever you're stuck with some examples in your book, you can take a peek in the Source folder to see how things should have ended.

If you want to run the site for see how it works, be sure to open the chapter's folder in Visual Studio as a website. You should open a folder such as C:\BegASPNET\Source\Chapter12 rather than opening its parent folder C:\BegASPNET\Source.

If you want to follow along both programming languages, create a second folder C:\BegASPNETV or C:\BegASPNETC to hold the files for the other version. The two sites can coexist without any problems. If you create a folder specifically for the C# language, don't include the hash symbol (# because that's an invalid character in the pathname for a website.

Sticking to this structure ensures a smooth execution of the Try Out exercises in this book. Incorrectly mixing or nesting these folders makes it harder to carry out the exercises and may even lead to unexpected situations and errors. When you run into an issue or error that is not explained in this book, your site structure is still closely related to the one presented here.
