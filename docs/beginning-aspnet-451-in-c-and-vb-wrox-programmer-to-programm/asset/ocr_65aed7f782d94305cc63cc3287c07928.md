# Creating Embedded and Inline Style Sheets

When you're working with a page in Design View, you often need to make minor tweaks to part of the page, like styling a piece of text, aligning an image, or applying a border to an element. At this stage, you need to make a decision about whether to create an inline, embedded, or external style sheet. As you saw earlier, you should opt for external or embedded style sheets if you envision you going to reuse a style later. VS doesn't care much though, it enables you to create styles at all three levels. Even better, it enables you to easily upgrade an embedded style to an external one, or copy inline style information to a different location, giving you great flexibility and the option to change your mind.

In the next exercise, you will see how to create inline and embedded style sheets. You see later how to move those styles to an external style sheet, enabling others to reuse the same styles.
