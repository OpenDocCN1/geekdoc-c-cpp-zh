# TRY IT OUT Implementing NavigateUrl Property

To set the URL that a user is taken programmatically, you need to be able to access the anchor tag that is defined in the control's markup. To do this, you need to give it an id and a runat="server" attribute. To be able to programmatically set the NavigateUrl property you'll need to add the Banner control and ensure that this property survives postbacks, you need to implement a View State property. To show you why you need a View State property, the first three steps of this exercise have you modify the About page so it sets the DisplayDirection of the Banner control programmatically. You'll then cause a postback so you can see that the value for the direction gets lost because it doesn't maintain its state in View State. The second part of the exercise shows you how to implement NavigateUrl property that is able to maintain its state.

+   1. Open the Code Behind of AboutUs.aspx and add the following code to the Page_Load event handler. If the handler isn't there, switch to Design View and double-click somewhere on the gray area of the page.

```
VB.NET
Protected Sub Page_Load(sender As Object, e As EventArgs) Handles Me.Load
    If Page.IsPostBack
        Banner2.DisplayDirection = Direction.Vertical
    End If
End Sub
```

```
C#nprotected void Page_Load(object sender, EventArgs e)
{
    if (Page.IsPostBack)
    {
        Banner2.DisplayDirection = Direction.Vertical;
    }
}
```

Verify that the user control has an ID of Banner2 in the Markup View of the page, or update your code accordingly.

+   2. Switch to Design View and add a Button to the top of the Banner.ascx control by dragging it from the Standard category of controls is placed inside the page (not the one that's defined in the master page). There's no need to write any code for the Button's Click event.
3. Save the page and open it in your browser. Because of the code in Page_Load, the first time the page loads, the banner displays the vertical banner. Now click the button so the page will reload. The page displays the horizontal image. Because the DisplayDirection of the Banner control is set in Page_Load only when Page.PostBack is False, that is what happens when you post postback, causing the banner to revert to its default setting of Horizontal.
