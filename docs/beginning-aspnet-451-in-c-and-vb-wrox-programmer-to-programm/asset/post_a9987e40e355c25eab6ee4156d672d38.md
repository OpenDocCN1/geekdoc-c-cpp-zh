# Introducing NuGet

NuGet is an open source Library Package Manager that comes as a Visual Studio extension and makes it easy to add, remove, and update external libraries in your Visual Studio projects and websites. You've seen it briefly in Chapter 3 (when you added FriendlyUrls), but this chapter dips a little deeper into the core functionality of the package manager.

NuGet was initially developed by Microsoft but has been turned into an Open Source project that accepts contributions from the developer community. Although you use NuGet in the context of VS, NuGet is certainly not for ASP.NET. You can use it for all types of problems you can solve with Visual Studio.

To understand what problems NuGet solves, imagine you want to add an open source library such as jQuery to your ASP.NET website. Although the specifics differ from library to library, you usually need to go through the following steps:

- 1. Find the website of the library.
- 2. Find a link to the download of the latest version of the library and download it.
- 3. Unblock the downloaded file using File Explorer, unzip, and add it to your project, optionally creating a specific folder for it.
- 4. Optionally, add a reference to the library in your project.
- 5. Optionally, configure the library through the web.config file or other files.

Using NuGet, you can greatly minimize the steps needed to add libraries to your project. For example, you can add the jQuery library with just five mouse clicks. In addition to adding packages, NuGet also enables you to update libraries to their latest versions after you've added them to your website, and it enables you to remove packages again without leaving a trace.

Besides the extension for Visual Studio, NuGet also has its own website at http://nuget.org. Here you can browse the catalog of packages, find commands for installing packages (more on that in the next section), read detailed documentation, and more.

To manage libraries with NuGet, you have two options: you can use the NuGet Packages dialog or you can use the Package Manager Console.

# Using the Manage NuGet Packages Dialog Box

The NuGet Packages dialog box enables you to search for packages, as well as many packages you have already installed. Use this dialog box by right-clicking your website in the Solution Explorer and choosing NuGet Packages. Alternatively, choose Tools > Library Package > Manage NuGet Packages for Solution. Figure 11-1 shows the dialog box in action.

![](img/9e033e3b9560597824f8b22941d6d8bb_409_0.png)

FIGURE 11-1

On the left of the dialog box you can choose from three different types of lists with packages:

- **Installed packages** — This item shows a list of packages that have been installed into your website. You can use this option to find out which version of the package you have installed, uninstall packages, or install the same package into another website or project that is part of the same.
- **Online** — This item enables you to search for packages online using the NuGet package source, the official Microsoft source, or any additional features you may have (which you can add using Tools > Options > Package Manager > Package Sources). By default, the list shows the most popular packages (measured by the number of downloads), but you can change the order using the drop-down list at the top. To the left of Sort by drop-down you have the option to display only stable packages, or also include prerelease versions of packages. In the upper-right corner you can search for packages by entering (or of) their name. Once you find the package you want to add to your website, select it, click the Install button and the NuGet Package Manager takes care of the installation process. You see more of this in a later exercise.
- **Updates** This item shows a list of packages for which new versions have been released since you installed the package into your website. Because updates could potentially break an existing website, they are not installed automatically and you need to manually select the packages you want to update.

You can find the documentation on the NuGet dialog box in the documentation section of the NuGet website at http://bit.ly/q2PiuM.

Besides using this dialog box, you can also manage packages using the Package Manager Console.

# Using the Package Manager Console

The Package Manager Console enables you to manage your packages from a command-line interface. It is not user-friendly as the dialog box, but once you get the hang of using NuGet you'll find it can be really useful. Using the console you can access the same features as the dialog box and more. Figure 11-2 shows the Package Manager Console, which you can access from the main menu by choosing Tools > Library Manager Console > Package Manager Console.

> NOTE NuGet is updated quite often (you will be notified by Visual Studio when a new release is available) so your version number may be slightly different. That doesn't matter for the functionality described in this book.

![](img/9e033e3b9560597824f8b22941d6d8bb_410_0.png)

FIGURE 11-2

This command-line window supports a number of commands that help you manage packages. To get a list of the available main commands, type Get-Help NuGet and press Enter. You will see a list of commands appearing that you can execute at the console. The console has IntelliSense as well to help you complete your commands by pressing the Tab key, simply type Get followed by the.

# TRY OUT Using NuGet to Install Packages

In this exercise you see how to find and install the latest jQuery package using the Manage NuGet dialog box. Using the dialog box is the most intuitive and easiest way, so it's a good place to get started with NuGet. In later parts of this book you also use the Console to install packages.

- 1. Start by opening the Manage NuGet Packages dialog box. You can do that by right-clicking in the Solution Explorer and choosing NuGet Packages. Alternatively, you can choose Tools > NuGet Package Manager > Manage NuGet Packages for Solution.
- 2. If it's not already selected, click the Online item in the list on the left.
- 3. Because jquery is so popular, it should appear in the list with packages that are shown by default. If it's not, or if you want to install another package, use the search box in the top-right corner of the dialog box.
- 4. Click the jQuery library package in the list. Make sure you choose the jQuery library, or jQuery Validation package, because these serve a different purpose.
