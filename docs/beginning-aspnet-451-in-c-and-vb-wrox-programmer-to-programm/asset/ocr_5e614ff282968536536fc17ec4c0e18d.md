```
font-size: 20px;
color: Green;

P{
  color: #0000FF
  font-style: italic;
}

.RightAligned {
  text-align: right;
}
/
```

Take great care when typing this code, because CSS is sensitive rather picky about syntax. The first item in the list is an list an h1 tag to style the heading at the first level, just it gets a size of 20 pixels and is displayed in a green font. Notice the colon between font-size and 20px and that the line is closed with a semicolon.

The second item in the list simply contains the letter p and defines the look and feel for all <p> elements in the page. It uses a hexadecimal value (#0000FF) for the color blue.

The last item is prefixed with a prefix (.). followed by the text RightAligned. This item is used to right-align some text in the page. Because CSS is sensitive, it's important to type this exactly as shown here, with a capital R and A, or the CSS code will not line up with the HTML in the next step.

Note that as you type the hash symbol (#) after the color property, a color picker pops up to help you select a color, as in Figure 3-1. For now, close the color picker by pressing Esc and manually complete the code in this chapter. You will see more of this color picker later in this chapter.
