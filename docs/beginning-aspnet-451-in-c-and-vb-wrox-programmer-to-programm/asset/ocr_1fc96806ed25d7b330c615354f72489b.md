5. Still in the Code Behind the master page, you need to add some code that preselects the correct item in the list again when page loads. The best place to do this is in the Page class's Load event. If you're using C#, the Page_Load handler should already be there. If you're using Visual Basic you can add one in two ways: either double-click the page anywhere in Design View (this works in C# as well), or select (Page Events) from the drop-down list above the Document Window in the Code Behind (see Figure 6-21), and then choose Load from the second drop-down. This is a nice way to add handlers for other controls as well, like Button and DropDownList.

Within the handler that VS added for you, add the following code:

# VB.NET

```
Protected Sub Page_Load(sender As Object, e As EventArgs) Handles Me.Load
    If Not Page.IsPostBack Then
        Dim selectedTheme As String = Page.Theme
        Dim preferredTheme As HttpCookie = Request.Cookies.Get("PreferredTheme")
        If preferredTheme IsNot Nothing Then
            selectedTheme = preferredTheme.Value
        End If
        If Not String.IsNullOrEmpty(selectedTheme) Then
            Dim item As ListItem = ThemeList.Items.FindByValue(selectedTheme)
            If item IsNot Nothing Then
                item.Selected = True
        End If
    End If
```

# C#

```
protected void Page_Load(object sender, EventArgs args)
{
    if (!Page.IsPostBack)
    {
        string selectedTheme = Page.Theme;
        HttpCookie preferredTheme = Request.Cookies.Get("PreferredTheme");
        if (preferredTheme != null)
        {
            selectedTheme = preferredTheme.Value;
        }
    }
```
