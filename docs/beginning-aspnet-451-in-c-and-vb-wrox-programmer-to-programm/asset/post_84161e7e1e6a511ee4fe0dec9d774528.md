11. Switch to the Code Behind of the page by pressing F7 and add the following function — which returns the text Yes or No depending on the value that you pass — the top of the class file, right after the Inherits line in VB.NET and after the opening curly brace in C#:

# VB.NET

```
Inherits System.Web.UI.Page
Protected Function GetBooleanText(booleanValue As Object) As String
Dim authorized As Boolean = CType(booleanValue, Boolean)
If authorized Then
    Return "Yes"
Else
    Return "No"
End If
```

# C#

```
public partial class Management_Reviews : System.Web.UI.Page

protected string GetBooleanText(object booleanValue)
{
    bool authorized = (bool)booleanValue;
    if (authorized)
    {
        return "Yes";
    }
    else
    {
        return "No";
    }
}
```

# How It Works

You started by modifying the SelectCommand for the SqlDataSource. Instead of selecting all columns using SELECT *, the SQL statement now contains a subset of the columns, making the page much faster:

```
<SqlDataSource Id="DataSource2" runat="server"
ConnectionString="{ConnectionStrings:PlanetWorkConnectionStringString1}"
SelectCommand="SELECT [ID], [Title], [Authorized], [CreateDateTime]
FROM [Review] WHERE ([GenId] = @GenId)"
</SqlDataSource>
```

<asp:HyperLinkField DataNavigateFields="ID" DataTextField="Title" DataNavigateUrlFormat="AddEditReview.aspx?Id={0}" HeaderText="Title" />
