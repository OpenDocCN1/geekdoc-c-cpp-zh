## How It Works

You didn't have to make a change to make the ListView strongly typed and get access to IntelliSenseense and compile-time checking of your code. All you had to do was add an ItemType property to the ListView and replace the calls to Bind and Eval with Item. With these changes, the control behaves exactly as before. At runtime, the control looks at the value of the assigned properties and displays them in the browser. When you submit data back to the server, the reverse takes place: The values you entered in the controls are retrieved by the Model Binder and assigned to the properties of an instance of the Picture object, which is then saved in the database by the Entity Framework. It is recommended to use the strongly typed binding capabilities whenever you can, because they help you spot errors much sooner and make it easier to type your code.

Right now, users need to type in a URL for an image manually. Obviously, this isn't user friendly. It would be much easier for them if they could pick an image from their local computer and upload it to the server. You will see how to accomplish this in the next exercise.

## TRY OUT Customizing Templates of the ListView Control

The templates for the ListView control you added in an earlier exercise are enough only in the most trivial situations. Usually, you need more control. For example, in the ItemTemplate you may want to display an actual image instead of the Label ImageUrl property. Likewise, in the InsertItemTemplate you may want to display a file upload control instead of a text box. In this exercise, you will see how to change these templates so you can incorporate both features. Additionally, you will see how to update the InsertItem to save the uploaded file to disk, and update the database with the URL of the image.

For this example, the account used by the web server (the account you use to log on when you are using IIS Express) reads and writes to the GPics folder that you create in this exercise. The account should already have these permissions on you, if you run into problems with this exercise, refer to the section “Understanding Security in IIS” in Chapter 19.

- 5. Switch to Code Behind and extend the ListView_ItemInserted with the following code:

### VB.NET

```vb
UpdateModel(picture)
Dim FileUpload As FileUpload =
Dim CType(ListView.InsertedItem.FindControl("FileUpload1"), FileUpload)
If Not FileUpload1.HasFile Or
    Not FileUpload1.FileName.ToLower().EndsWith(".*jpg") Then
    Dim cusImage As CustomValidator =
    CType(ListView.InsertedItem.FindControl("cusImage"), CustomValidator)
    cusImage.IsValid = False
    ModelState.Add("Invalid", cusImage.ErrorMessage)
End If
```
