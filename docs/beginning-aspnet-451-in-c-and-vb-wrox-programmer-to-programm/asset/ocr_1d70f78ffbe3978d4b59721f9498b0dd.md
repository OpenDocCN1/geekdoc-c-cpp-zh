by making the URL unique by adding a query string. For example, ~/Login.aspx and ~/Login.aspx?type=Admin will be seen as two different pages. You see more of the query string later in this chapter.

The title attribute is used in the navigation controls to display the name of the page. You see more about this when you work with the Menu, TreeView, and SiteMap controls. The description attribute is used as a tooltip for the navigation elements. 7-2 shows a tooltip for the By Genre element.

The navigation controls work together with the ASP.NET mechanism. You can automatically hide elements from controls like the Menu that users do not have access to. Security is described in more detail in Chapter 16.

The SiteMap control that displays a breadcrumb (discussed later in this chapter) is able to find the Web.sitemap file. For the other two controls, you need to specify a SiteMapDataSource control (which you can find in the Data category of the Toolbox) explicitly as an intermediate layer to the Web.sitemap file.

To create a Web.sitemap file, you need to add one to your site and manually add the siteMap elements to it. There is no automated way in Visual Studio to create a site map file based on the current site's structure, although third-party solutions exist that help you with this.

# TRY OUT Creating a Web.sitemap File

In this exercise you add a new Web.sitemap file to the site and add a bunch of siteMapNode elements to it. This site map serves as the basis for the navigation controls in the site.

+   1. Right-click the element in the Solution Explorer, choose Add New Item, and click Click SiteMap. Leave the default name set to Web.sitemap and click Add. You will end up with root element containing two nodes in the Web.sitemap file.
2. Modify the siteMap so that it contains this code:

```
<xml version="1.0" encoding="utf-8"?>
<siteMap xmlns="http://schema.microsoft.com/AspNet/SiteMap-File-1.0">
<siteMapNode url="/" title="Home">
<siteMapNode url="/Default.aspx" title="Home">
<siteMapNode url="/Default.aspx" description="Go to the homepage /" />
<siteMapNode url="/Reviews/Default.aspx" title="Reviews"
description="Reviews published on this site />
<siteMapNode url="/Reviews/AllByGenre.aspx" title="By Genre"
description="All Reviews Grouped by Genre" />
<siteMapNode url="/Reviews/All.aspx" title="All Reviews" />
</siteMapNode>
<siteMapNode url="/Default.aspx" title="About"
description="About this Site />
<siteMapNode url="/Contact.aspx" title="Contact Us"
description="Contact Us /"
<siteMapNode url="/AboutUs.aspx" title="About Us"
description="About Us /" />
</siteMapNode>
</siteMap>
```
