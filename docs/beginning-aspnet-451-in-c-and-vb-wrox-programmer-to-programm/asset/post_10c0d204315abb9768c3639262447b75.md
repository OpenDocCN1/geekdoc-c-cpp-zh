
## How It Works

When you visually insert page elements like tables or lists through the available menu, VS inserts the required markup for you in Markup View. When you insert a table, VS adds a <table> element and a number of <tr> and <td> elements to define rows and columns, respectively. It also applies a class attribute to a CSS style that defines the width. It created another for the <td> elements when you dragged the column width to be 200 pixels. Similarly, when you insert a list, VS inserts an <ol> element for numbered or ordered lists and an <ul> element for bulleted or unordered lists. Within these elements, <li> elements are used to define each item in the list.

Besides the HTML tags you have seen so far, there is another important tag you need to look at: the <a> tag, which is used to create links between pages.

## Connecting Pages

An important part of any website is the links that connect the pages in your site. Links enable your visitors to go from one page to another, in the same site or to a completely different site on the Internet. You have a few ways to create links between pages, including:

- The HTML <a> element, explained in this chapter.
- Using the <a href=Hyper:HyperLink> control, discussed in Chapter 7.
- Programmatically through code. This is discussed later in the book.
- The following exercise shows how easy it is to link from one page to another.

## How It Works

Links between pages are likely one of the most important elements in a web page, because they enable you to create a connection between a page in your site and another, whether that page lies on your site or a completely different server on the Internet. Simple links that appear anywhere on the page, the HTML <a> tag with an href attribute is the easiest to set up. When the user clicks a link, the browser requests the page specified in the href's value from the server and displays it. The double dots (..) in the href's value are to refer to the parent directory. The full href attribute means "go up one level in the folder hierarchy and then select the file Default.aspx. You see a lot more about links and how they work in Chapter 7.

You're not limited to linking to pages within your site. If you want to link to external pages instead, replace the href attribute value with the full address of the page, as shown in the following example:

```
<a href="http://www.wrox.com">Go to the Wrox homepage</a>
```

For external links, it's important to include the http:// prefix; otherwise, the browser goes looking for a file or folder called wrox.com on your own website.

## PRACTICAL TIPS ON WORKING WITH WEB FORMS

Here are some tips for working with Web Forms:

- Favor Web Forms with Code Behind over inline code. Although at first you may not notice a big difference in working with them, as your site and pages start to grow, you'll find it's easier to work with a page where the code is separated from the markup.
- Spend some time familiarizing yourself with the different menu items of the Format and Table menus. Most of them generate HTML elements that are inserted into your page. Take a look at the HTML elements and attributes that have been generated for you, and try to change them directly in the code, and through menus and toolbars. This way, you get a good feel for the various tags available and how they behave.
- Experiment with links to connect pages in your site. Notice how VS creates different links depending on the location of the page you are linking to. Chapter 7 deals with linking and the various ways to address pages in your site in much more detail.
