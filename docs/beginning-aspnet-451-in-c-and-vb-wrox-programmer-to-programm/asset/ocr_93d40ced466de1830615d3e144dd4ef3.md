# How It Works

Most of the steps in this Try Out are self-explanatory. By opening a few windows that you frequently need when building websites. You used the drag-and-drop features of the IDE to rearrange the window layout according to your personal preferences.

You then added an HTML fragment to a control tab in the Toolbox. When you drag any markup to the Toolbox, Visual Studio creates a Toolbox item for it that contains the selected markup. Whenever you need a copy of that markup in your page, simply double-click the item or drag it from the Toolbox into Markup View. This is great time saver for HTML fragments that you frequently use. You typically use this technique for larger blocks of code; elements like the &lt;h1&gt;, Visual Studio has a better tool called Snippets, which you will learn about later in this book.

At the end you used Visual Studio's document formatting option to change the layout of the code in the document. This helps to keep the code organized and easy to read. You can fully change how the code is formatted using the Options dialog accessible through Tools → Options. Expand the path Text Editor -> HTML (Web Forms) → Formatting, and click Tag Options.
