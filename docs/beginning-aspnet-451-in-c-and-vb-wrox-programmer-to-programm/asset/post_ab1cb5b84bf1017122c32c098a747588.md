## Using Shorthand

Many of the CSS properties enable you to write a shorthand version as a more expanded version. Take, for example, the border property. In its shortest form, you can set the border property like this:

```
border: 1px solid Black;
```

This border property applies a border to all four sides of an HTML element. The border size is 1px, the style is solid (some of the other options include dashed, dotted, and double), and the border color is set to Black.

This makes it easy to quickly set all four borders of the HTML to the same values. However, if you want to control the individual borders and their properties, you can use the expanded version:

```
border-top-width: 1px;
border-top-style: solid;
border-top-color: Black;
border-right-width: 1px;
border-right-style: solid;
border-right-color: Black;
border-bottom-width: 1px;
border-bottom-style: solid;
border-bottom-color: Black;
border-left-width: 1px;
border-left-style: solid;
border-left-color: Black;
```

This long version creates the exact same style as a solid border on all four sides with a thickness of 1px. In most cases, you should favor shorthand notation over its expanded counterpart, it is much easier to read and maintain. However, if you need absolute control over the border — for example, if you want a 2-pixel dashed border on the top and left, and a green, solid on the right and bottom sides of the HTML element — it's good to know that you can set each border property of all directions individually. You can also mix these options.

```
border: 1px solid Black;
border-left-color: Blue;
```

Other CSS properties that support shorthand include font, background, list-style, margin, and padding. If you're unsure whether a property supports shorthand, the IntelliSense pop-up list appears by pressing Ctrl+Space when you're entering a property in a CSS file or a <style> block.

Although at times it seems you need to use CSS by trial and error, and just hope for the right result, there's a quite accurate model behind CSS that determines how elements should be laid out on the page. This model is called the CSS Box Model.

## CSS Box Model

The CSS Box Model describes the three important CSS properties that are applied to HTML elements: padding, border, and margin. Figure 3-4 shows a graphical representation of the box model.

In the middle there is an HTML element like a <p> or a <div> with a certain height and width. Just outside is **padding**; the whitespace surrounds the element inside the border. Immediately after the padding you can see the border and finally on the outside there is the *margin*, which defines the room between an element (including its padding and border) and its surrounding elements. The three outer properties of an element — padding, border, and margin — add up to the space that an element takes up in the page. To see how this works, consider the following CSS and HTML:

```
.MyDiv {
  width: 200px;
  padding: 10px;
  border: 2px solid Black;
}

<div class="MyDiv">Element</div>
```

This renders a rectangle in the browser with the <div> element surrounded by a border of two pixels, as shown in Figure 3-5.

![](img/9e033e3b9560597824f8b22941d6d8bb_113_0.png)

Before you go on, try answering the question: How wide is the arrow below the <div> element?

If you guessed 224 pixels, you are correct. The width of the arrow is the sum of three values: the width of the element (200 pixels), plus the width of the padding on both sides (two times 10 pixels), plus the width of the border on both sides (two times 2 pixels), resulting in a total width of 224 pixels. So, if you wanted the box to be 200 pixels wide, you'd need to set the width property of the .MyDiv selector to 176px. Outside of the border, margin could further influence the gap between this element and its surrounding elements.

The example shows the effect on the width. Keep this box model in mind when laying out your pages. When elements end up wider than you anticipated, check the width, height, padding, border, and margin properties in the CSS style.
