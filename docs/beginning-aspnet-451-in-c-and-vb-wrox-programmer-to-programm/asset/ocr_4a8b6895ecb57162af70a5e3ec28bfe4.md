4. Next, choose Edit Document from the main menu. Alternatively, press Ctrl+K before Ctrl+D. This shortcut and menu command are available for other types of files, such as HTML, CSS, Visual Basic, and C# files. When executed, they format the document according to the settings for that particular type. In the case of CSS, it formats the closing brace at a certain location, indenting the individual rules. It also performs what's called a hierarchical indent. To understand how this works, take a look at 3-10, which depicts the section#MainContent rule set as the new selectors for the elements you added after formatting the document.

![](bbox=[0.683, 0.355, 0.868, 0.372])

Notice how the section#MainContent rule has been indented between the selectors used by the rule set (section#MainContent a only targets elements within a parent section element with an id of MainContent). Likewise, the section#MainContent a:visited and section#MainContent a:hover rules are indented below the element because they are considered "children" of the element. If you like, you can turn this off by setting Hierarchical Indentation to Off under Tools > Options > Text Editor > Advanced. Alternatively, press Ctrl+Q to focus on the Quick Launch, use CSS Advanced, and press Enter. This opens the Options box. While you there, spend some time browsing the items under the Text Editor to get an idea of how you can change the formatting of the languages you support.

5. The final editor features worth showing how Regions and Comments work. If your CSS becomes unruly, it may help to wrap some parts of the code that belong together in a region. In VS this can be collapsed the code, and expanded when you need to change it. To create it, wrap the code in a region /endregion using CSS comment syntax. For example:

```
/*#region Region Name */
-- Your CSS code here
/*endregion*/
```

```
/*#region Main Content /\nsection#MainContent
{
  width: 664px;
  float: left;
}
```
