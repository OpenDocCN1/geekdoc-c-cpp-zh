Then below the last event (but still within the class definition), add the following method that writes to one of the two labels, depending on whether the current page request is the result of a postback:

# VB.NET

```
Private Sub WriteMessage(<CallerMemberName> Optional handlerName As String = "*")
    If Page.IsPostBack Then
        PostBack.Text &= handlerName & "<br />"
    Else
        NoPostBack.Text &= handlerName & "<br />"
    End If
End Sub
```

# C#

```
private void WriteMessage([CallerMemberName] string handlerName = "*")
    if (Page.IsPostBack)
    {
        PostBack.Text += handlerName + "<br />";
    }
    else
    {
        NoPostBack.Text += handlerName + "<br />";
    }
```
