1. Make sure that Default.aspx is still open and switch to Markup View if necessary.

2. Locate the <h1> element and click it. VS highlights the tag in the Tag Selector at the bottom of the Document Window to indicate it's the active tag.

3. Open the Apply Styles window by choosing View Apply Styles from the main menu. Alternatively, if you have the window docked with other windows, simply click its tab to activate it. Again, make sure the window is not accidentally docked in the Document Window, but either floats or is placed at the side of the Document Window. At the bottom of the Apply Styles window, you'll see an inline style appear (see Figure 3-24).

4. Right-click Inline and create New Style Copy. The New Style dialog box opens, enabling you to create a new style based on the current selection. At the top of the window, choose h1 from the Selector drop-down and Define Inline drop-down choose Existing style sheet. From the URL drop-down choose Styles/Styles.css. If that item isn't available, the Browse button to click and select it. Your dialog box should end up like Figure 3-25.

VS creates a new style set for h1 in the Styles.css file instead of adding the padding and margin info into the existing rule set. If you want to, you can combine the two selectors into one manually.
