Finally, when the object is fully set up, the code calls SaveChanges on the PlanetWroxEntities object. This eventually sends a SQL INSERT or UPDATE instruction to the database to insert a new or update the existing Review row. With the data source control, calling SaveChanges may incur an error. 18 digs deep into handling errors that may occur in the code. After SaveChanges has been called, the user is redirected to the Reviews.aspx page using Response.Redirect.

# VB.NET

```
myEntities.SaveChanges()
Response.Redirect("Reviews.aspx")
```

# C#

```
myEntities.SaveChanges();
Response.Redirect("Reviews.aspx");
```

Once you've saved a review in the database, you can edit it. Once you click one of the existing reviews in the list at Reviews.aspx, you're taken to the Add/Edit page with the ID of the review in the query string. For example, browsing to http://localhost:1049/Management/AddEditReviewId=6 enables you to edit the Death Magic album by Metallica. The page is able to detect the ID in the query string using the Page_Load:

# VB.NET

```
If Not String.IsNullOrEmpty(Request.QueryString.Get("Id")) Then
    _id = Convert.ToInt32(Request.QueryString.Get("Id"))
End If
```

# C#

```
if (!String.IsNullOrEmpty(Request.QueryString.Get("Id")))
{
    _id = Convert.ToInt32(Request.QueryString.Get("Id"));
}
```

Because this _id variable is assigned a value in Page_Load, it can be used to load an existing item to display in the form, but also to get the item from the database in the SaveButton.Click event (which you saw earlier).

If there is an ID (_id is a value other than -1) and the page is not posted back, the code sets up a new PlanetWroxEntities instance using a using block and queries the Review instance using the following LINQ to Entities:

# VB.NET

```
Dim review = (From r in MyEntities.Reviews
Where r.Id = _id
Select r).SingleOrDefault()
```

# C#

```
var review = (from r in MyEntities.Reviews
where r.Id == _id
select r).SingleOrDefault();
```
