# Exchanging Objects with WCF

Although a simple string can be enough as the response from a service, you typically need more information. For example, you may want to load the last two reviews from a service when a user clicks a refresh button. Rather than posting the entire page, you could call a service, retrieve reviews from the database, and then display them in the page somehow. Here is an example of how a service that retrieves reviews could look:

```
VB.NET
<ServiceContract(Namespace="")
[AspNetCoreCompatibilityRequirements(RequirementMode=AspNetCoreCompatibilityRequirementsMode.Allowed)]
Public Class ReviewsService

    <OperationContract>
    Public Function GetLatestReviews() As List(Of Review)
        Dim temp As List(Of Review) From
        {
            New Review() With {.Id = 1,
            .Title = "21st Century Breakdown by Green Day"},
            New Review() With {.Id = 2,
            .Title = "Sonic Youth: Daydream Nation live in Roundhouse, London"}
        }
        Return temp
    End Function
End Class

Public Class Review
    Public Property Id As Integer
    Public Property Title As String
End Class
```

```csharp
[ServiceContract(Namespace = "")
[AspNetCoreCompatibilityRequirements(RequirementMode=AspNetCoreCompatibilityRequirementsMode.Allowed)]
public class ReviewsService
{
    [OperationContract]
    public List<Review> GetLatestReviews()
    {
        List<Review> temp = new List<Review>()
        {
          new Review() {Id = 1,
            Title = "21st Century Breakdown by Green Day"},
          new Review() {Id = 2,
            Title = "Sonic Youth: Daydream Nation live in Roundhouse, London"}
        };
        return temp;
    }
}

public class Review {
  public int Id { get; set; }
  public string Title { get; set; }
}
```

To show you how to work with complex data at the client, this code example returns two hardcoded Review instances. In later chapters you will see how to work with reviews in a database so you could make this example truly dynamic. For now, it serves the purpose of showing the reviews at the client.

The code sets up a generic collection of Review instances. For now, a Review is a simple class with two properties: an id and a Title. The collection is filled using a collection initializer that adds Review instances, each of them created with an object initializer. Refer back to Chapter 5 for more information on collection and object initializers.

When you call the GetLatestReviews method from client code, you get back a collection of instances that you can loop over. The following code shows the getReviewsCallback method that accomplishes this:

```javascript
function getLatestReviewsCallback(result) {
  var listItems = '';
  for (var i = 0; i < result.length; i++) {
    listItems += '<li>' + result[i].Title + '</li>';
  }
  document.getElementById('Reviews').innerHTML = listItems;
}
```

This code declares a string that will hold the titles of the reviews. It loops over the reviews in the result variable. JavaScript doesn't foresee, but using a string for loop you can easily access all items in the collection. Within the for loop, the review's title is retrieved using result[i].Title, which is then wrapped in a <li> tag and appended to a string variable. In the end, the string is added as the innerHTML of an element called Reviews (which could look like this in: <ul id="Reviews"></ul> so the review titles appear in a bulleted list.

When you type this, you'll notice not that IntelliSense for the result object. VS doesn't know the actual type of the result variable, and as such cannot help you find properties as Id and Title.

Note that this code is a bit clunky. Using document.getElementById and innerHTML isn't the best way to write code like this. Therefore, the next chapter introduces you to better alternatives when it discusses jQuery. For now, though, this should suffice, showing the core concept of working with complex objects returned from WCF service.

It's important to realize that the Reviews object you work with in JavaScript is not the exact same one one you use in your service. VB.NET or C# code targets the .NET Framework at the server, whereas your JavaScript runs at the client. To get the object to the client, WCF serializes the collection of reviews into JavaScript Object Notation (JSON) - a string representation of objects that can be used directly in your JavaScript code. You see an example of JSON in a later exercise.

The web services in the Planet Wrox project will only be used to have a client page in the browser talk to the server and exchange data. So, in this site, both the server and the client are in the same web project — one executes at the client (the JavaScript that calls the web server).

# Creating Web Services

Creating WCF services with VS is pretty easy. Just as all the other types, VS comes with a template for the service. You add the service to the site. You then modify the service code to suit your requirements.

# Creating a Web Service

In this exercise you create a simple "Hello World" web service. This service accepts your name as an input parameter and returns a friendly greeting. Greeting's not real world-usage for this exact service, because of the simplicity in the service, it's easy for you to focus on the underlying concepts.

- 1. Create a new folder called services in the root of your site to group all services in a single folder. This is not required, but helps in organizing your site.
- 2. Next, right-click this folder and choose Add New Item. Click the WCF Service (Ajax-enabled) Service item. Because the list of templates can be quite long, you can quickly find the right item by searching for WCF in the search box in the top-right corner of the Add New Item dialog box.
- 3. Click Add to add the service to the site.
- 4. Open the NameService Code Behind file from the App_Code folder, rename the Do method to HelloWorld, and change the code so it accepts a string and returns a personalized greeting. In you need to change the code from a Sub to a Function and have it return String, and in C# from void to a string method, because the service method returns a string.
