# Adding Tables and Other Markup

HTML tables are great if you need to present structured or repeating data, like a list of products in a shopping cart, photos in a photo album, or input controls. There is a lot of debate on the Internet whether you should use tables to lay out your page as well. For example, if your page contains a header, a main content area, and a footer at the bottom, you could use a table with three rows to accomplish this. In general, it's considered bad practice to use tables for purpose because they add a lot of extraneous markup to the page and are often difficult to maintain. Besides, the same result can be accomplished using CSS, which you learn about in the next chapter. Despite the disadvantages tables may be rigid, they are still an invaluable asset in your HTML toolbox when it comes to displaying tabular or otherwise structured information.

# TRY OUT Using the Form and Table Menus

In this exercise, you will learn how to add tables to your page using the Table menu and how to add rows and columns. Additionally, you will learn how to add other elements, such as bulleted lists.

+   1. In the Demo folder, create a new Web Form called TableDemo.aspx. Make sure it uses Code Behind by checking the Place Code in Separate file.
2. Switch to page to Design View, click the dashed rectangle that represents the <div> tag in the page, and choose Table ▾ Insert Table. The Insert Table dialog box appears, as shown in Figure 2-19.
3. Set Rows to 3 and leave Columns to 2. Leave all other settings at their defaults and click OK. The table gets inserted in the page.
4. If you see only a single table, and not the entire table with three rows and two columns, you need to enable Visual Aids. Choose View ▸ Visual Borders from the main menu to turn the borders on. Your Design should now look like Figure 2-20.
