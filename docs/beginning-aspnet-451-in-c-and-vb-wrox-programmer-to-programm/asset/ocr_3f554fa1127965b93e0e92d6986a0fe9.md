# How It Works

At the end of this exercise you end up with code similar to what VS created automatically when you dropped a GridView on the page in an earlier exercise. You have a data-bound control (the DropDownList) that gets its data from a data source (the SqlDataSource). What's different is the way you set things up you a lot more flexibility with regard to the code that is generated. Instead of relying on VS to generate a SQL statement for all the columns in the database, you choose only the two columns you need. Additionally, because the SqlDataSource doesn't require any updates to the data source, you only needed to provide a SelectCommand. You also used the ORDER BY button to control the order in which the items are added to the list.

With the SqlDataSource control set up, displaying the data it returns in a DropDownList is pretty easy. By setting the DropDownList to get the correct data source using the DataSourceId attribute, and then setting up the DataTextField and DataValueField to control what columns you use for the text displayed in the control and the underlying value. By setting AppendDataItems to True, you can preserve the item that you add in code manually. With this setting turned off, the static item a selection would have been cleared as soon as the data-bound items were added.

With the filter control set up, the next step is to create the GridView that displays reviews for the selected genre. You see how to do this in this next exercise.
