and enables you to specify a set of options that determine how long the item is cached, priority it should have compared to other cached items, and what factors trigger the item's removal from the cache.

The Insert method, on the other hand, is much easier. It has a few overloads that enable you to specify the cache and associate it with a specific key. Another overload also enables you to define dependencies that can be used to invalidate a cached item when the original source is changed. This is great for caching files that don't change very often. You can read a file from disk, store it in the cache with a dependency on the original file. When the file is changed, the cached item is automatically invalidated and you can read the original source file again and store it in the cache. The following example shows how to modify the `ContactForm.ascx` control to store and get the item from the cache until changes:

# VB.NET

```
If Page.IsValid Then
Dim mailBody As String = TryCache(Cache("ContactFormBody"), String)
If String.IsNullOrEmpty(mailBody) Then
    Dim fileName As String = Server.MapPath("~/App_Data/ContactForm.txt")
    mailBody = System.IO.ReadAllText(fileName)
    Cache.Insert("ContactFormBody", mailBody, New CacheDependency(fileName))
End If
mailBody = mailBody.Replace("##Name##", Name.Text)
```

End If

# C#

```
if (Page.IsValid)
{
    string mailBody = Cache("ContactFormBody") as string;
    if (String.IsNullOrEmpty(mailBody))
    {
        string fileName = Server.MapPath("~/App_Data/ContactForm.txt")
        mailBody = System.IO.ReadAllText(fileName);
        Cache.Insert("ContactFormBody", mailBody,
            new CacheDependency(fileName));
    }
    mailBody = mailBody.Replace("##Name##", Name.Text);
}
```

Notice how a new CacheDependency which you need to bring the System.Web.Caching namespace into scope with an Imports statement is created and used in the Insert method. This CacheDependency expects the name of the file it depends on. As soon as you change the file on disk (using VS or Notepad, or by overwriting it through FTP), ASP.NET removes the item from the cache so it will be read from the original source file again the next time this code is executed.

You remove items from the cache using the Remove method that accepts the key of the cached item. You define this key when inserting the item, using Add or Insert.
