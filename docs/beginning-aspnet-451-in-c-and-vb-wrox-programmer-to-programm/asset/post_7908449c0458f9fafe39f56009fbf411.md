Two other important methods include parent and prev. These methods are used in DOM traversing, where you can 'walk' up and down the document tree elements that are either below or above an item, or at the same level.
The prev method selects a matched element's direct sibling. To see how this works, take a look at this:

```
alert($('#DemoTable td:contains("Row 1 Cell 2").prev()[0].innerHTML);
```

What do you think if this alerts? If you guessed "Row 1 Cell 1," you're right. The : selector selects the cell in the second column of the row by the text it contains. The prev method returns its first sibling: the cell to the left of it. A matched set is a collection even if it contains only a single item, you still need to use an index like [0] to refer to that item.
The table cell then has an .innerHTML property that returns the content of the cell.

# Common Mistakes When Working with jQuery

Depending on the complexity of the jQuery functionality you're using, writing the code can be quite challenging. You need to take care of the proper capitalization, parentheses, brackets, commas, and more. When you find your jQuery code doesn't run or has unexpected behavior, check to see if your code is suffering from the following problems.

# Your ID Selectors Don't Work

It's likely you forgot to include the # symbol in front of it. $('DemoTable') does not select the table with an id of DemoTable, whereas ($('#DemoTable') selects it. Another situation where your ID selector might not work is when you get the casing wrong. ID selectors are sensitive, so $('#DemoTable') is not the same as ('#DemoTable').

# Your ID Selectors Don't Work, Even with Hash Symbol

In this case, it's likely that the client element doesn't have the id you expect. Maybe the ASP.NET run time changed the client id by prefixing it with the id of its parent? In this case, try setting the ClientID on the relevant control to Static so it ends up more predictable. Also make sure your code executes inside the document ready function because the elements you're targeting may not be available yet.

# None of Your Code Seems to Run

Check your parents, curly braces, and quotes. Each pair needs to be balanced, with an equal number of opening and closing items.

# EFFECTS WITH JQUERY

In an earlier example in this chapter you saw showUp and slideDown to hide you and show elements. But these are only two of the many effect and animation methods that jQuery is available. The following table lists the most common ones you can use. Once, you're advised to try out all examples using the jQueryDemos.aspx page.

| METHOD NAME | PURPOSE |
| :--- | :--- |
| show() | Hides or shows the matched elements by decreasing the height, width, and opacity (making them transparent). Both methods enable you to define a fixed speed (slow, normal, fast) or a number defining the animation in milliseconds. |
| toggle() | The toggle method switches between showing and hiding the matched elements. That is, if they are visible, it hides them, and if they are hidden, it shows them. Example: <br> `$('element').toggle();` |
| slideDown() | Just like hide and show, these methods make matched elements appear or disappear. However, they do this by adjusting the height from its current size to zero or vice versa. Examples: <br> `$('element').slideDown(1000);` |
| slideUp() | The slideToggle method slides down and up elements, which makes it easy to show and hide elements with a single action. Examples: <br> `$('element').slideToggle(1000);` |
| fadeIn() | These methods make the matched elements visible or invisible by changing their opacity. fadeOut sets the opacity to 0, making the item transparent, and then sets the CSS display to none, hiding the item completely. fadeTo lets you specify an opacity (a number between 0 and 1) to determine the transparency level of elements and fadeIn makes the item again and sets the opacity to 1. All three methods enable you to define a fixed speed (slow, normal, fast) or a number defining the duration of the animation in milliseconds. Examples: <br> `$('element').fadeOut(1000);` // dissolve in 1 second <br> `$('element').fadeIn(1000);` // appear in 1 second <br> `$('element').fadeOut(1000, 0.5);` // fade to semi-transparent |
| animate() | Internally, animate is used for many of the animation methods like show and hide. However, it is also externally available to give you great flexibility in animating your elements. With the animate method you can specify a bunch of properties to animate. Consider this example: <br> `$('element').animate({ opacity: 0.4, marginLeft: '50px', fontSize: '50px' }, 1500);` The first argument of the animate method is an object holding one or more properties you want to animate, each one separated by a comma. Notice how you need to use JavaScript’s marginLeft and fontSize, rather than the CSS margin-left and fontSize properties. You can only animate properties that take numeric values. That is, you can use properties like margin, fontSize, opacity, and so on, but not properties like color or fontFamily. |
