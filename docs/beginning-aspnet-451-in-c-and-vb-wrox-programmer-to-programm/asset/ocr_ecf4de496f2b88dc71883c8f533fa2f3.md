# How It Works

To expose a WCF service to the client-side script in your application, you need to register it in the Web.config file. In addition, you need to apply the correct attributes to the service class. Both actions are carried out for when you add an WCF Service (Ajax-enabled) to your project. If you look at the web.config file you see something like this:

![](bbox=[0.483, 0.673, 0.866, 0.783])

```
<system.serviceModel>
<behaviors>
  <endpointBehaviors>
    <behavior name="NameServiceAspNetAjaxBehavior*>
    <enableWebScript />
```
