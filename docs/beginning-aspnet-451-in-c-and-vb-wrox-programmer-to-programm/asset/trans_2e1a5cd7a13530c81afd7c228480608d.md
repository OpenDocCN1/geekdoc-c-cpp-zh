

# 引言

泛指 Web 世界。本书从 Web 开发的起点开始，向你展示如何获取和安装 Visual Studio。后续章节将在你前几章节所得知识的基础上，逐步向你介绍新技术。

你更倾向于使用 Visual Basic 而不是 C#，还是反之呢？或者你认为这两种语言都一样酷？也许你已经下定主意，想同时学习这两种语言？无论情况如何，你都会喜欢这本书，因为所有的代码示例都以这两种语言呈现的！

即使你有以前版本 ASP.NET 的经验，也可能从书中获益匪浅。虽然以前版本的许多概念被引入了 ASP.NET 4.5.1 中，但你会发现书中还有许多新内容，包括强类型数据控件、主代码编辑器、新的调试设施等。

# 本书涵盖内容

本书将教你如何创建一个名为 Planet Wrox 的功能丰富、数据驱动且具有交互性的网站。虽然这个名字听起来很复杂，但你会发现通过 Visual Studio 2013，开发网站并不像想象中那么困难。你将看到构建网站的整个过程，从第 1 章安装 Visual Studio 一直到第 19 章将你的网站部署到活动服务器。本书分为 19 章，每章处理一个特定主题：

- 第 1 章，“入门 ASP.NET 4.5.1”。在本章中，你将看到如何获取和安装 Visual Studio 2013 for Web（用于构建 ASP.NET 网站的 Visual Studio 2013 免费版）。还将介绍 HTML5，这是定义网页的最新标准。章节以 Visual Studio 提供的自定义概述结束。
- 第 2 章，“构建 ASP.NET 网站”。本章向你展示如何创建一个新网站以及如何向页面添加新项目。在学习如何创建一个结构站点的同时，你还将看到如何使用 Visual Studio 中的众多工具来创建 HTML 和 ASP.NET 页面。
- 第 3 章，“设计你的网页”。Visual Studio 配备了许多工具，让你能够创建设计良好且吸引人的网页。在本章中，你将学会如何充分利用这些工具。此外，你将学习 CSS，即用于格式化网页的语言。
- 第 4 章，“使用 ASP.NET 服务器控件编程”。ASP.NET 服务器控件是 ASP.NET 中最重要的概念之一。它们让你利用大量的服务器控件创建复杂且功能丰富的网站，本章将解释它们的用途并展示你如何使用它们。
- 第 5 章，“为你的 ASP.NET 网页编程”。虽然内置的 CSS 工具和 ASP.NET 服务器控件可以让你在创建网页时进步很多，但你可能会使用编程语言来增强你的页面。本章作为编程的介绍，重点关注网页编程。最棒的是：你在本章（以及书的其他部分）看到的示例是用 Visual Basic 和 C# 编写的，因此你可以选择你喜欢的语言。
- 第 6 章，“创建外观一致的网站”。一致性对于赋予你的网站吸引力和专业质感至关重要。ASP.NET 通过通过使用主页（Master Pages）帮助你创建外观一致的页面，这允许你定义页面的全局外观和感受。皮肤和主题帮助你集中网站中控件和其他视觉元素的样式。你还将看到如何创建一个基础页面，帮助你在所有页面上对编程代码进行集中。
- 第 7 章，“导航”。为了帮助用户在你的网站中导航，ASP.NET 提供了许多导航控件。这些控件用于构建网站的导航结构。你可以连接到网站的站点地图，它定义了网站中的页面。你还将学习如何通过程序从一个页面跳转到另一个页面。
- 第 8 章，“用户控件”。用户控件是可重用的页面片段，可以在多个页面中使用。因此，它们非常适合重复菜单、横幅等内容。在本章中，你将学习如何创建和使用用户控件，并用一些程序化智能来增强它们。
- 第 9 章，“输入验证”。你网站中的大部分交互性是由用户的输入定义的。本章展示了如何接受、验证和处理用户输入。
- 第 10 章，“ASP.NET AJAX”。AJAX 允许你在不刷新整个网页的情况下创建交互式网页。本章展示了如何使用 AJAX 增强网站。你还将学习如何使用 jQuery。
- 第 11 章，“查询”。jQuery 是一个流行的开源 JavaScript 库，旨在让 JavaScript 更加容易。在本章中，你将学习 jQuery 的基础。
- 第 12 章，“介绍数据库”。理解如何使用数据库对于构建网站关重要。本章展示了如何使用 ASP.NET 数据控件。你还将看到如何与 SQL Server 交互。
- 第 13 章，“显示和更新数据”。基于第 12 章所学的知识，本章展示了如何使用 ASP.NET 数据绑定控件显示和更新数据。
- 第 14 章，“LINQ 和 ADO.NET Entity Framework”。LINQ 是微软用于访问对象、XML 等的解决方案。ADO.NET Entity Framework (EF) 是一种用于数据库访问的技术。本章向你展示如何使用 EF。
- 第 15 章，“处理数据——高级主题”。前面的章节主要侧重于数据的技术基础，而本章从前端的角度来看相同的主。你将看到如何通过控件更改数据的可视外观。你还将看到如何通过保留频繁访问数据的副本来加速网站。
- 第 16 章，“ASP.NET 网站安全”。虽然在书的最后介绍，但安全性是一个首要的重要课题。本章向你展示如何利用与安全相关的内置 ASP.NET 功能。你学习有助于安全的应用程序。你还将学习让用户在你的网站上注册、如何区分匿名用户和登录用户以及如何管理系统中的用户。
- 第 17 章，“网站个性化”。基于第 16 章介绍的安全功能，本章向你展示如何创建针对个人用户的内容的个性化页面。你将看到如何配置和使用 ASP.NET Profile，它允许为已知和未知访问者存储个性化数据。
- 第 18 章，“异常处理、调试和跟踪”。你需要调试工具来理解、改进和修复为 ASP.NET 网站编写的代码。Visual Studio 提供了强大的调试支持，允许你在运行时诊断应用程序状态，帮助你在用户发现之前发现并修复问题。你还将详细了解页面检查器（Page Inspector）和新的浏览器链接（Browser Link）功能。
- 第 19 章，“部署你的网站”。到书结束时，你应该拥有一个准备好展示给世界的网站。但具体怎么做呢？将网站发布到真实环境需要知道和理解哪些事情？本章提供了答案，并让你详细了解配置不同的生产系统，你还将看到如何实现包处理和压缩（Bundling and Minification）来提高网站的性能。
