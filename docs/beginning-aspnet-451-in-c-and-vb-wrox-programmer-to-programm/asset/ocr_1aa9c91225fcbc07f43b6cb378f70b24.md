# TRY OUT Using Web.conf Transformations

In this exercise, you will edit the file.Web to local disk.config to contain the data that is specific for your production environment. You will then mark it with various xdt: attributes that define how the file should be when you use publish.

+   1. Expand the AppData\PublishProfiles folder and right-click the .pubxml file that VS created in the previous exercise. It should be called local.pubxml if you called your Publish Profile to local disk. Choose Add Config Transform from the menu that appeared. Visual Studio adds a file called Web.to local disk.config to the root of this website.
2. From the root of the Solution Explorer, delete the file Web.debug.config. Sometimes Visual Studio picks this file for the transformation instead of your custom delete. Deleting this file prevents that from happening. You may need to expand the Web.config item.
3. Right-click local disk.config and choose Preview Transform. Visual Studio shows the original file and the generated file by side, as shown in Figure 19-4.

![](bbox=[0.068, 0.425, 0.882, 0.597])

FIGURE 19-4

Notice how the transformed file (on the right) is almost identical to the one on the left, for the absence of the debug attribute. The transformation engine will take all content from the original file and place it in the target file, for those elements and attributes that have explicit been changed with the xdt: attributes.

+   4. Close the Preview window. In Web.to local disk.config add the following bold lines to modify the code and Add addresses for e-mail in the production server:

```
<configuration xmlns="http://schemas.microsoft.com/XML-Document-Transform">
  <appSettings>
    <add key="Address" value=planetwork-production@example.com
         xdt:Transform="SetAttributes" xdt:Locator="Match(key)" />
  </appSettings>
</configuration>
```
