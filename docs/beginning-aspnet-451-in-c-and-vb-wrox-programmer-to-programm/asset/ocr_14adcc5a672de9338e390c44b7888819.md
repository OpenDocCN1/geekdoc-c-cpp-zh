# The Toolbox

On the left of the main screen, the Toolbox folds out, giving you a chance to see what it contains. If you click
the tab, the little pin icon in the upper-right corner of the Toolbox (or any of the other panels that has this pin
icon), it gets pinned to the IDE so it remains open.

Just as the menu bar and toolbars, the Toolbox automatically updates itself to show content
that is relevant to the task you're working on. When you're editing a standard ASPX page, the
Toolbox shows many categories you have available for your use. You can simply drag an item
from the Toolbox and drop it on a location of your page where you want it to appear. These controls
are discussed in detail in Chapter 4. Note that each category also contains a Pointer
icon. This is not a control itself, though for Visual Studio (such as Win Forms)
 icon is used to get out of drawing mode, but it has little use in ASP.NET. The Toolbox
contains multiple categories that you can expand and collapse as you please to make it easier to find the
right tool. You can also reorder the items in the list, add and remove
items from the Toolbox, and even add your tools to it. Customizing the IDE is discussed later
in chapter.

If the Toolbox is not visible on-screen, press Ctrl+Alt+X to open it or choose View ⟢ Toolbox,
have you chosen the Expert Settings in the Tools ⟢ Settings menu.

# The Solution Explorer

At the right of the screen, you see the Solution Explorer. The Solution Explorer is an important
window because it gives you an overview of the files that comprise your website. Instead of placing
all your files in one folder, the Solution Explorer enables you to store files in separate folders,
 a logical and organized structure. You can use the Solution Explorer to add new files to
your site, move existing files using drag and drop or paste, rename files and delete
them from the project, and more. Most of the functionality of the Solution Explorer is hidden
behind its right-click menu, which changes depending on the item you right-click.

At the top of the Solution Explorer, you see a small toolbar that gives you access to
functionality related to your website, including refreshing the Solution Explorer window,
anoption to next related files, and a button that enables you to configure your website. Most of this
functionality is discussed later in the book.

You can access the Solution Explorer by choosing View ⟢ Solution Explorer from the main menu or
or pressing Ctrl+Alt+L.
