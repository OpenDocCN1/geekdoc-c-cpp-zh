# # Defining Controls in Your Pages

As demonstrated in the Try Out, you can simply drag controls from the Toolbox onto the design surface of the page. This makes it easy to add a bunch of controls to a page to get started. However, because of the way the design surface works, it's difficult to find exactly where you want them. For example, it is difficult to drag a control between the opening and closing tags of an HTML element. Fortunately, you can also type the control's markup in Markup View, letting IntelliSense and code snippets help you with the different tags and attributes. You'll also find that the Properties Grid works in Markup View. Simply click the markup, and the Properties Grid is updated to reflect the tag you clicked. This makes it easy to change the properties of the control, while you can see exactly what markup gets generated for you. Visual Studio enables you to bind handlers (as the *Click* event used in the preceding exercise) directly in Markup View without switching to Design View. You will also be able to access the Smart Tasks panel for the controls from code. You see more of these features later in this chapter.

If you look at the Properties Grid for some of the controls in a page, you will notice that many of them have similar properties. In the next section, you see exactly what these properties are and what they are used for.
