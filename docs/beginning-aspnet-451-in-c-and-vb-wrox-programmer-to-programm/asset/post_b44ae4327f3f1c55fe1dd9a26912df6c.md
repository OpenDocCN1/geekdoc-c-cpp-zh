## How It Works

When you create a relationship between two tables, the database will enforce this relationship when you try to insert, update, or delete data. In this example, rows in the Review table have a row in the Genre table that exists in the Review table. When you try to delete a row from the Genre table, the database sees that the genre is used by a row in the Review table and cancels the delete operation. In Chapter 15 you learn how to handle this in your website and present your user with a friendly message.

## SUMMARY

The ability to work with databases is a good addition to your development skills. Most of today's websites use databases, so it's important to understand how to work with them.

To access and manipulate data in a relational database, use a language called Structured Query Language, or SQL for short. Among other elements, define four keywords that enable you to perform CRUD — Create, Read, Update, Delete — operations.

The SELECT statement enables you to retrieve data from one or more tables. To access more than one table, you can use one of the available JOIN types. To limit the number of rows returned by a query, you use a WHERE clause. To order the items in the result set returned by your query, you use the ORDER BY clause. To create new rows in your database use the INSERT statement, and an UPDATE statement to change existing rows. Finally, to delete rows that you longer need, you use the DELETE statement. Like the SELECT and UPDATE statements, DELETE takes an optional WHERE clause that enables you to limit the number of rows deleted.

The second part of this chapter showed you how to use the built-in database tools to create tables with relationships between them. In addition, you saw how a relationship between two tables enables you to protect your data from becoming corrupt or orphaned.

Although this chapter had a strong focus on the SQL that you need to write to access a database, you see in the next chapter that in many cases Visual Studio makes accessing databases generating most of the code for you.
