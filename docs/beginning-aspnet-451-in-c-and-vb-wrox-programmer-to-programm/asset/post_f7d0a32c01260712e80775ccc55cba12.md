9. If you are using IIS on a machine that has SQL Server Express, the first thing you need to do is modify your connection strings. If you don't have SQL Server Express installed, refer to Chapter 12 that shows you how to install SQL Server Expression as well as SQL Server Management Studio Edition. If you are using a different database, or if you only have SQL Server Local DB installed and don't want to install SQL Server Express, look at the section "Moving to a Remote Server" later in this chapter and look Appendix B, which explains how to configure a different SQL Server.

To modify the connection string, open web.config from the Release folder and replace both occurrences with (LocalDB).v11 in the connection strings with .SqlServer. This targets a named instance of SQL Instances= (SQL Server called on the local machine, identified by the dot.). In addition, add UserInstance=True to connection strings to run SQL Server under the same user account as the website. Your connection strings should end like this:

```
<connectionStrings>
<add name="PlanetWroxConnectionString1" connectionString="Data Source=\SqlServer;AttachDb=|DataDirectory|\PlanetWrox.sdf;Integrated Security=True;UserInstance=True"
<providerName="System.Data.SqlClient" />
<add name="PlanetWroxConnectionString2" connectionString="Data Source=\.\/App.Code.PlanetWrox.sdl|\/App.Code.PlanetWrox.mdf;providerName=System.Data.SqlClient;attachDbFilename=|DataDirectory|\PlanetWrox.mdf;integrated security=True;User Instance=True;MultipleActiveResultSets=True;App-EntityFramework&quot"
providerName="System.Data.SqlClient" />
</connectionStrings>
```

You should also add to the transformation file in VS so the connection strings will be updated correctly the time you publish the site.

10. To check if the site works, open a browser and go to http://localhost. You should see the Planet Wrox website appear. By verifying that everything is in order, browse through the site by requesting pages from the menu filling, creating a new account, uploading pictures, and so on. If you get a 404 message for the pages in the site, open Web.config from the Release folder as a direct child node of

```
<configuration>
```

```
<system.webServer>
  <modules runAllManagedModulesForAllRequests="true"></modules>
</system.webServer>
```

This maps requests without an extension (which includes all pages in the side due to the FriendlyUrls package) to .NET, so they are handled correctly. You should add this code to your tformation file in VS as well so the next time it adds to your .config file gets added to you automatically.

If you get other errors, refer to the section "Troubleshooting Web Server Errors."

## How It Works

On a standard system, all folders are protected by NTFS. To ensure proper operation of your website, you need to grant the permissions. In addition, you need to configure the folder. If you get an error, it's the account you need to remove. In the case case, you need to find the solution for it.
