我喜欢自定义文档窗口的一件事是制表符大小，它控制缩进代码时插入的空格数。要更改制表符大小，请选择 Tools > Options，然后在 Text Editor 中选择 All Languages 设置 Tabs。我通常将 Tab 和 Indent Size 设置为 2 个空格，保持 Tab 中的其他设置不变。我喜欢自定义的另一件事是 HTML 元素前后换行的数量。Options 窗口为您提供了完全的控制权：选择 Text Editor HTML (Web Forms) Formatting 然后点击 Tag Specific Options。在列表中您可以选择一个标签，然后通过右侧的设置控制其格式。Preview 框使您能够轻松看到各种设置如何改变格式。请注意，Web Forms 在 Options 对话框中有自己的类别，因为它在内部使用与 Visual Studio 中找到的基于 HTML 的编辑器不同的 HTML 编辑器。

如果您更喜欢在文档窗口的边栏中选择行，请选择 Tools > Options 设置 All Languages 并选中 Lines 复选框。

## 自定义工具栏

您可以以三种方式自定义工具栏：您可以显示或隐藏内置工具栏，您可以向现有工具栏添加和删除按钮，以及您可以创建自己的带有您使用的按钮的工具栏。

## 启用和禁用工具栏

您可以通过右键单击任何现有工具栏或菜单栏然后从列表中选择适当的项目来禁用和启用现有工具栏。一旦工具栏显示出来，您就可以使用其左侧的拖动手柄将其拖到工具栏区域的新位置。

## 编辑工具栏

如果您觉得现有工具栏缺少重要按钮或包含您很少使用的按钮，您可以自定义其上的按钮。为此，右键单击任何工具栏或菜单栏，切换到 Commands 选项卡，并从 Toolbar 下拉菜单中选择要修改的工具栏。右侧的命令按钮，您可以添加新命令和删除现有命令，或更改其顺序。

## 创建自己的工具栏

创建自己的工具栏很有用，如果您想将一些经常使用的功能分组。要创建新工具栏，请打开如前一节所述的 Customize 窗口。点击 New 按钮并为工具栏输入名称。然后切换到 Commands 选项卡并像处理现有工具栏一样修改您的工具栏。

## 自定义键盘快捷键

许多开发人员会更改的另一个设置是键盘快捷键。键盘快捷键是一种节省时间的好方法，因为它们使您能够通过简单的键盘命令执行任务，而无需伸手去拿鼠标并从菜单中选择适当的项目。要更改键盘快捷键，请选择 Tools > Options，展开 Environment，然后点击 Keyboard。或者，按 Ctrl+Q，输入 keyboard 并按回车。在命令列表中查找您想要更改快捷键的命令。由于此列表包含许多项目，您可以通过输入命令的几个字母来过滤列表。例如，在 Commands Finding 过滤器中输入 print 会为您提供所有与打印相关的命令列表。

接下来，在 Press Shortcut Keys 字段中输入新的快捷键并 Assign。Visual Studio 允许您为单个命令输入双重快捷键。例如，您可以将 Close All Documents 绑定到命令 Ctrl+K, Ctrl+O。要执行此命令，您需要在快速连续中按下这两个组合。虽然双重快捷键可能看起来有点过分，但它大大增加了可用快捷键的数量。

## 重置您的更改

如果您在尝试众多自定义选项时搞砸了，也不用担心。您有多种方法可以将 Visual Studio 恢复到之前的状态。

## 重置窗口布局

Window 菜单中可访问的 Reset Window Layout 命令会将所有窗口重置为您首次启动 Visual Studio 时的位置。如果您放置了太多窗口导致 IDE 杂乱无章，此命令非常有用。

## 重置工具箱

如果您不小心从工具箱中删除了项目或删除了整个选项卡，您可以通过右键单击工具箱并选择 Reset Toolbox 将工具箱重置为原始状态。使用此命令前请三思，因为它还会删除您所有的自定义代码片段。

## 重置所有设置

如果您按照之前的 Try It Out 练习进行操作，然后开始尝试自定义可能性，您的 IDE 现在可能处于两种状态之一：它完全按照您想要的方式工作，或者它看起来像一团糟。在后一种情况下，很高兴知道清理混乱很容易。

要将所有 Visual Studio 设置完全恢复到刚安装后的状态，请选择 Tools > Settings > Import and Export Tools > Import and Export Settings，具体取决于您使用的 VS 版本。然后选择 Reset All Settings 选项并点击 Next。如果您愿意，可以创建现有设置的备份；否则，选择 No。会出现另一个屏幕，允许您选择任何设置集合。选择 Expert Settings 或 Web Development，因为这些选项为您提供了跟随本书所需的所有功能。最后，点击 Finish。此操作会将所有设置重置为默认值，包括窗口布局、工具箱和工具箱自定义、快捷键，以及您可能在 Visual Studio Options 对话框中更改的任何内容。因此，仅在您确实确定想要一套全新的 Visual Studio 时才使用此命令。
