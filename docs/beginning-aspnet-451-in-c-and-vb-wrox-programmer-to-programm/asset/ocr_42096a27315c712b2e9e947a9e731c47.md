4. In this screen, you can choose between two Output type options. The first enables you to create a text file with the necessary SQL statements, and the second option enables you to talk to your shared hosting provider over the Internet. If your host supports this, it can give you the necessary information to configure a provider here. For now, choose Save Scripts to Specific Location. Then click the Advanced button and change the setting for Types of Data to Schema and Data. The default value of Schema would only script your database structure, but not the actual records table contains. Set Script Use Database to False. With this setting to True, code will be enabled to create a database at the App_Data folder, which likely won't work on a machine other than yours. Click OK to close the Advanced Scripting Options dialog box.

5. Click Next and the wizard generates the SQL script for your Documents folder as specified in the File Name box shown in Figure 19-15). Open the file in Notepad and look at the SQL statements it contains. Although most of it looks like gibberish to you, it is used as to re-create the database structure and data on a compatible SQL Server database.
