# How It Works

In this exercise you created a simple Content block that can hold your jQuery code. You then defined a code block that fires as soon as the browser is done loading the DOM. Inside this block you wrote a simple selector that selects the table with an id of DemoTable and used jQuery's css method to change its background color.

In the following table you see a list of jQuery's basic filters. Remember, you can try out each by replacing the //Examples you here line with the code examples. Then save the page and load it in your browser to see the code at work.

| FILTER | PURPOSE |
| :--- | :--- |
| :first | Enables you to select the first or last item in a matched set. The following example changes the background color of the first or last row of the table to red:<br> ```css
$('#DemoTable tr:first').css('background-color', 'red');
$('#DemoTable tr:last').css('background-color');
```<, The first row is found using #DemoTable. Then all rows are found tr. The first or last row is found using :first and :last filters. |
| :odd | Enables you to select the odd or even items in a matched set. Following example changes the background color of the odd rows to red. Because the numbering is zero-based, you actually see the second and fourth rows change color (because they have an index of 1 and 3, respectively):<br> ```css
$('#DemoTable tr:odd').css('background-color', 'red');
``` | |
| :even | | |
| :eq(index) | Matches items by index. :eq (equals) returns a single element by index, and :lt (less than) and :gt (greater) return items smaller or greater than the given index, Examples:<br> ```css
// Changes the color in the first row (with an index of 0)
$('#DemoTable tr:eq(0)').css('color', 'green');

// Only the last two rows.
// with an index of 0, 1 and 2 respectively, are skipped.
$('#DemoTable tr:gt(2)').css('color', 'green');

// Changes the text color of the first two rows to green.
$('#DemoTable tr:lt(2)').css('color', 'green');
``` | |
| :lt(index) | | |
| :gt(index) | | |
| :header | Finds all headers (from h1 to h6) in the page. Example:<br> ```css
(':header').css('color', 'green');
``` | |

For a complete list of all basic filters, check out the jQuery documentation at http://api.jquery.com/category/selectors/.
