# CHAPTER 1 GETTING STARTED WITH ASP.NET 4.5.1

At the bottom of the Document Window in Figure 1-9, you see three buttons called Design, Split, and Source. These buttons appear automatically when you're working with a file that contains markup, such as ASPX pages. They enable you to open the Design View of a page (giving you an idea of how the page will look in the browser), its Markup View (the HTML and other markup), or at the same time. How this works is explained in more detail in Chapter 2, but for now, it's important to realize you can switch between Markup, Split, and Design View by clicking one of the three. The Markup View is also often called the Source View or Code View. However, to avoid confusion with the code editor that is used to edit Code Behind files, this book uses the term Markup View exclusively.

# The Start Page

Whenever you start VS, the Start Page is loaded in the Document Window. With the Start Page, you can quickly create new and opening windows and other projects. The Start Page provides a number of links to related news and information about web development. To pin your projects to the Start Page, click the pin icon to the left of the project name in the list with recent projects. To unpin a project, right-click it and choose Remove from List. To reopen the Start Page, choose View Start Page.

To get a feel for how you can use all these windows, the following Try Out shows you how to build a simple web page that contains a few ASP.NET Server Controls.

# TRY OUT Creating Your First ASP.NET Web Page

This Try Out Exercise guides you through creating a new website with a single page that contains a number of ASP.NET Server Controls. See how to use windows like the Document Window and the Solution Explorer, and how to use the Toolbox and the Properties Grid to add ASP.NET Server Controls to the page and change their looks.

+   1. Start VSEW or Visual Studio 2013.
2. If you're using the Express edition, choose Tools Settings and choose Expert Settings to turn on the developer profile that gives you access to the full feature of VSEW.
3. On the File menu create New Web Site. Depending on configuration, you may have to choose File New VSEW instead. This triggers the New VSEW dialog box.
4. In this dialog, make sure ASP.NET Empty Web Site is selected and not the ASP.NET Web Forms item that you used in a previous exercise. Ensure that File System is chosen in the Web Location drop-down list. It doesn't matter if you choose Visual Basic or C# for this. Click OK to create the new site.
5. Next, right-click the new website in the Solution Explorer. Make sure you click the website (labeled WebSite2) and not the parent element. It's the highlighted element in Figure 1-5. From the context menu, appears how to create a new Add Item.
6. In the new window that appears, click Web Form and type Control as the name. The ASPX extension is added for you automatically when you click the Add button. You can leave the other settings in the dialog box at their default settings. The page should open in Markup View, showing you the default HTML, like the <html><head><title>, and <body> elements that VS adds for you when you create a new page.
