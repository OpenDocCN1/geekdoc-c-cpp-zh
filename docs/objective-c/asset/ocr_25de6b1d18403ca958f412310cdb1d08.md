Now, the interesting thing about this program is that we’re doing a fair amount of work here to do this calculation. What if we wanted to change the number we’re calculating the factorial for? Perhaps it would be better if we could isolate that bit of code in a function so that we could reuse it over and over again. Perhaps we could make a function that simply takes an int as a parameter, and then returns the factorial of that int.

Listings 2.23 shows a program where I’ve done exactly that.
