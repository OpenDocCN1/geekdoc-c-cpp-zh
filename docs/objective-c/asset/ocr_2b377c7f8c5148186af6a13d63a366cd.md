It then takes each one of those numbers in turn and calls the method isPrime:. If that method returns true, then it adds that number to the list of primes for our result set. The isPrime: function takes whatever number is given to it, and tries to divide that number by every number below that number. If it divides cleanly, — if there is no remainder — then that number is not a prime. If, however, it gets to the end of all of the numbers less than the number itself, then it is a prime number and it returns true.
