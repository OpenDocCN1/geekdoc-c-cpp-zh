# Making blocks easier to read with typedef

It can sometimes make your code easier to read if you typedef your block definition. This enables you to reuse the definition without having to retype all the arguments and return types of the block. Listing 5.9 shows the class from the last section, but this time, it’s using a typedef for its block arguments. As you can see, this makes the code much clearer and more readable.

Listing 5.9

Same code using a `typedef`

```
typedef void (^BlockWithCharArg)(char *);

@interface Foo : NSObject
{
    BlockWithCharArg myBlock;
}
-(void)doSomethingWithBlock;
-(void)setMyBlock:(BlockWithCharArg)inBlock;
@end

@implementation Foo

-(void)dealloc;
{
    [myBlock release];
    [super dealloc];
}

-(void)setMyBlock:(BlockWithCharArg)inBlock
{
    myBlock = [inBlock copy];
}

-(void)doSomethingWithBlock
{
    myBlock("foo");
    // ....
}
@end
```
