Let us confirm the calculations for Rule [3] from Figure 14.5. This rule has confidence 0.43051. From Figure 14.1, the prior proportion of the consequent (Churn = True) equals 0.14533. Thus,

\( 1 - \frac{\text{Prior proportion of consequent}}{\text{Rule confidence}} = 1 - \frac{0.14533}{0.43051} = 0.66242 \ge 0.40 \)

Allowing for rounding error, the **quot** statistic from Figure 14.7 equals the value we obtained above, 0.66242.

Like Confidence Difference, this method takes uneven distributions into account. It is especially good at finding rules that predict rare events. Of course, like any other data science task using cross-validation, association rule mining needs to be validated. We show how to do this in the exercises.
