To predict the type of wine for each wine in our test data set, we use the **predict()** command

```
ypred <- predict(object = nb01, newdata = wine_test)
```

The object = nb01 specifies that we are using our Naïve Bayes model and newdata = wine_test states the test data set to use. The algorithm classifies each record in the test data set as either a white or red wine and saves the string of classifications as ypred.

Finally, we create the contingency table of actual versus predicted wine types.
