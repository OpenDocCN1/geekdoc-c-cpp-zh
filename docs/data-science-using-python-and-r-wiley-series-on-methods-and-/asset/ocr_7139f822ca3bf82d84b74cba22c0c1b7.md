data = fram_train input specifies where the three variables come from. The size = 1 command states that there is one unit in the hidden layer.

Note that the neural network output is saved as nnet01. Saving the output is required in order to obtain the plot and weights of the neural network.

Next, plot the neural network.

```
plotnet (nnet01)
```

The output from the plotnet() command with the nnet01 input will match Figure 9.7.

nnet01$wts
