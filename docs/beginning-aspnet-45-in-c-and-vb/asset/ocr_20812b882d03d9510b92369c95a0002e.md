This code explicitly checks for the value True / true. However, this is not required and it's quite common to leave it out. The following example is equivalent:

```
```vbnet
If User.IsInRole("Administrators") Then
    DeleteButton.Visible = True
End If
```
```

# C#

```
```csharp
if (!User.IsInRole("Administrators"))
{
    DeleteButton.Visible = true;
}
```
```

I'll use this succinct version of the examples in this chapter. Often you want to perform a different action if the condition is not True. Using the negation operator Not or ! you could simply write another statement:

# VB.NET

```
```vbnet
If User.IsInRole("Administrators") Then
    DeleteButton.Visible = True
End If
If Not User.IsInRole("Administrators") Then
    DeleteButton.Visible = False
End If
```
```

# C#

```
```csharp
if (User.IsInRole("Administrators"))
{
    DeleteButton.Visible = true;
}
if (!User.IsInRole("Administrators"))
{
    DeleteButton.Visible = false;
}
```
```

Clearly, this leads to messy code, because you need to repeat each expression evaluation twice: once for the True case and once for the False case. Fortunately, there is an easier solution: the Else block (else in C#);

# VB.NET

```
```vbnet
If User.IsInRole("Administrators") Then
    DeleteButton.Visible = True
Else
    DeleteButton.Visible = False
End If
```
```

# C#

```
```csharp
if (User.IsInRole("Administrators"))
{
    DeleteButton.Visible = true;
}
else
```
