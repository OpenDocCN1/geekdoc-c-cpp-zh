protected void Page_Load(object sender, EventArgs e)

}

Although this odd syntax may look a little scary at this point, don't worry about it too much now. In most cases, VS adds it for you automatically, as you just saw. In later chapters, you see exactly how this code works, but for now it's important to realize that the code you're going to place between the lines that start with Protected Sub and End Sub in Visual Basic and between the curly braces in C# will be run when the page is requested in the browser.

All code examples you see from now on will include a Visual Basic (VB.NET) and a C# version, so always pick the one that matches your programming language.
