# while Loop

The general form of a while loop follows:

```
while (condition)
statement;
```

| while Statement: The while statement allows a program to repeatedly execute a block of statements while the specified condition is true. |
|---|
| Syntax: |
| `while(condition)` | `while(condition)` |
| `statement;` | `{` |
| | `statement block` |
| | `}` |
| Example: |
| `while(!isspace(ch))` | `while(x > y)` |
| `{` | `{` |
| `cin.get(ch);` | `++c1;` |
| `}` | `--x;` |
| | `}` |

The condition is evaluated before the statements within the loop are executed. If the condition is false, the statement block is skipped, and execution continues with the statement following the while loop. If the condition is true, then the statement block is executed, and the condition is evaluated again.
