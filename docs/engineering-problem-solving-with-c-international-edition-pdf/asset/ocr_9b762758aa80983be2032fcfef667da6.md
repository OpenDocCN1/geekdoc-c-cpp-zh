To insert a value into a linked list, we must traverse the list to find the location for the insert. We begin at the *head* of the list and move from one element to another using the pointer in the current element, until we find the desired location for the insertion. The insertion location can be one of four places: before the first element, between two elements, after the last element, or in an empty list. Figures 9.5 through 9.8 outline each of these cases assuming that we started with the linked list given in Figure 9.4 for each of the first three cases.
