|---|
| Syntax: `for (initialization; condition; modification) statement:` |
| Example: `for (int count=1; count<=10; ++count) sum = sum + count;` `for(int i=counter; i>0; --i) { cin >> degrees; radians = degrees * PI/180 cout << degrees << " " << _radians << endl; }` |

If, for example, we want to execute a loop 10 times, with the value of the variable k going from 1 to 10 in increments of 1, we could use the following for loop structure:
`for (int k=1; k<=10; ++k) { statements; }`
