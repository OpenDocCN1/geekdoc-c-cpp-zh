# 9.2 Pointers to Array Elements

Arrays and array handling were covered in detail in Chapters 7 and 8 using offsets to specify individual array elements. Pointers can also be used to specify individual array elements. Array references using pointers and addresses are almost always faster than references using offsets; thus, pointer references for arrays are generally preferred if speed is a concern. As discussed in this section, pointer references to array values are based on the knowledge that memory assignment of array values is always sequential.
