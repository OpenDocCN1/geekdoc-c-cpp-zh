# The stack class

The C++ STL includes the stack class, which provides an object-based implementation of a stack. The compiler directive #include<stack> must be included to use the stack class.

When a stack is defined, the data type of the objects in the stack must be specified. The following type declaration statement defines an empty stack of integers named astack:

```
stack<int> astack;
```

| Function | Description |
|---|---|
| empty() | returns true if the stack is empty and false otherwise. |
| pop() | removes top element from the stack. Does not return a value. |
| push(value) | adds value to top of stack. |
| size() | returns the number of elements in the stack. |
| top() | returns the value of the first element in the stack. The element is not removed from the stack. |
