# 4.4 break and continue Statements

We used the break statement in the previous chapter with the switch statement. The break statement can also be used with any of the loop structures presented in this chapter to immediately exit from the loop in which it is contained. In contrast, the continue statement is used to skip the remaining statements in the current pass or iteration of the loop and then continue with the next iteration of the loop. Thus, in a while loop or a do/while loop the condition is evaluated after the continue statement is executed to determine if the statements in the loop are to be executed again.
