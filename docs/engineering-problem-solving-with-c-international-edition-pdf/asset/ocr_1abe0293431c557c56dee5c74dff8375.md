# Program Output

Problems 3 and 4 refer to the following statements:

```
int sum, k, i, j;
int x[4][4] = {{3,2,5,7}, {4,6,0,1}, {5,3,7,8}, {2,1,9,3}};
```

3. Give the value in sum after the following statements are executed.

```
sum = x[0][0];
for(int i = 0; k<3; ++k)
   sum += x[k][k];
```

4. Give the value in sum after the following statements are executed.

```
sum = 0;
for(int i=1; i<=3; ++i)
   for(int j=0; j<=3; ++j)
      if(x[i][j] > x[i-1][j])
         sum++;
```

5. Give the value in size after the following statements are executed.

```
vector<vector<double>> power(7, 15);
int size = power.size();
```

6. Give the value of size after the following statements are executed.

```
vector<vector<int>> power(7, 15);
int size = power[0].size();
```
