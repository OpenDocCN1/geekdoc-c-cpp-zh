You can also detect an end-of-file indicator automatically, as illustrated in the following statements:

```
while ( datal >> x )
{
    ++count;

}
```

This while loop uses the value returned by the input request to control execution. The input request will return a value of true if a data value is read from the datal file stream and a value of false if a data value cannot be read from the file stream. In our examples, we will use the eof() function for clarity.
