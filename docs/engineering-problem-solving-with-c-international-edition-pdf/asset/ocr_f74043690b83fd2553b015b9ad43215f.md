Select the directory of your choice from the **Browse...** button, and name the project `ProgramChapter1_1`. Click on the **Finish** button to complete the creation of your NetBeans project.

Recall that every C++ solution requires exactly one function named `main`. To create `main` we must add a new file to our project. To add a new file select **New File...** from the **File** menu. The following **Choose File Type** window will appear:

![](bbox=[0.23, 0.23, 0.74, 0.52])

Select **C++ Files** from the **Categories:** menu and **Main C++ File** from the **File Types:** menu, then click the **Next >** button on the bottom of the screen. A **Name and Location** window will appear, as shown below.

![](bbox=[0.23, 0.64, 0.74, 0.93])
