# bit masks

constants are referenced in various `class` methods and have been assigned the integer values 1, 2, 4, and 7. Recall that the binary value 1, in 8 bits, can be represented as 00000001; binary 2 as 00000010; binary 4 as 00000100; and binary 8 as 00001000. These constants are used as **bit masks** to set and check the state of `overflowFlag`. A bit mask is integer data that is used with bitwise operators to manipulate bits in a single bitwise operation. The implementation of the extended `Pixel` class is provided below:

```
#include "Pixel.h"
/* ----------------------------------------------------------- */
/* Pixel class implementation.                                 */
/* File name: Pixel.cpp                                        */
/* Addition (+) operator.                                      */
Pixel Pixel::operator+(const Pixel& p) const
{
    Pixel temp;
    temp.red = red + p.red;
    temp.green = green + p.green;
    temp.blue = blue + p.blue;
    temp.validate();
    return temp;
}
/* ----------------------------------------------------------- */
/* Multiplication (*) operator.                                */
```
