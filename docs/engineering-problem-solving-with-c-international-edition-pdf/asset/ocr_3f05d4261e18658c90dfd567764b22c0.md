# Program Analysis

Use the following function for problems 11-14:

```
/*--------------------------------------------------------------*/
/* This is a recursive function.                                */
/* The function sum() calls itself                              */
/*--------------------------------------------------------------*/
int sum(int n)
{
   if ( n == 0 )
      return 0;
   Else
   {
      return n + sum( n - 1 );
   }
}
/*--------------------------------------------------------------*/
```
