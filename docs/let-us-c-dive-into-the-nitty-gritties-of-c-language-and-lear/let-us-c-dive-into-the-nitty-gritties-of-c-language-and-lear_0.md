## 第三版序言

自从我写第一版这本书（大约十年前）以来，发生了很多变化。那时 C++ 还是一个新事物。今天，它是程序员社区中成熟、强大且受欢迎的选择。我希望在这个新版中反映这一变化。因此，我针对 Visual Studio 和 `gcc` 等流行的编译器检查了书中的每个程序，当它们无法工作时进行了修改，最后将它们呈现给你们。文本也为了适应变化进行了修改。

## 第一版序言

完成这本书是我做过最困难的事情之一。我花了几乎两年的时间把它变成你现在看到的这种形式。每当我阅读之前的草稿时，几乎都得重写整个部分。有两个原因：首先 C++ 是抽象的，其次是复杂的。大多数 C++ 程序员都是原来的 C 程序员。我也是从 C 迁移到 C++ 的。因此，如果不对任何新的 C++ 特性与 C 中的实现进行对比并告诉读者如何在 C++ 中做得更好，我觉得我失了职责。C++ 斥着大量的术语。我的目标之一是抑制这些术语，而是关注底层概念。在大多数地方，我都尝试展示事物是如何工作的，更重要的是，它们为什么要这样工作。

如果你让我说这本书最重要的特征，我会说无论是代码还是文本，我都努力使其尽可能简单。至于代码，我想展示可以易于编辑、编译和运行的简单示例。我的目标不是通过给这些示例添加修饰来证明我是多么好的程序员。我的目标是证明简单的示例就足够了。

[注：提供的文本包含来自源的大量重复和混乱的 OCR 异常。比其他任何事情都重要的是，我试图为挣扎于新语言的程序员设计这本书。]
