# 第 2 章

## C# 编程语言

你可能会奇怪为什么要使用 C#。这一章涵盖了为什么 C# 是一门非常棒的学习语言的原因，以及它能为你做什么。

C# 是一种后端编程语言。它处理 Web 和桌面应用程序的输入和输出。有很多语言可以选择，所以你可能会奇怪为什么选择 C# 而不是其他编程语言。这一章为你提供了关于 C# 语言的一些背景以及它在编程行业中的用途。

### 为什么要用 C#

没有开发者是绑定在任何语言上的。你可以使用任何基于语言的应用程序来完成开发。当你想要开发纯 Windows 环境的应用程序时，你需要学习 `.NET` 框架的语言之一，包括 `C#` 和 `VB.NET`。当 `.NET` 最初推出时，`VB.NET` 是最流行的语言。这是因为旧版的 Classic VB 很有基础。这一章将为你提供关于 `C#` 语言的一些背景以及它在编程行业中的用途。

### C# 是用来做什么的？

有几个理由你想要使用 `C#`。`C#` 让你处理桌面和 Web 应用程序。为了运行 `C#`，服务器需要 `.NET` 框架。`.NET` 框架只兼容 Windows，所以你需要运行 Windows。

`C#` 常用于 Web 应用程序。具体来说，`C#` 语言用于处理动态代码。例如，当用户通过 Web 表单发送信息时，`C#` 语言进行处理、存储并发送响应。`C# MVC` 仍然处理前端，你使用 `HTML`、`CSS` 和 `JavaScript` 进行前端。`C#` 也用于桌面应用程序，但你可能不再看到桌面应用程序作为主要的软件。编程世界正在转向云应用，这对 `C#` 程序员是有益的。`C#` 程序员可以创建 API 和处理云应用的后端代码。

`C# API` 也称为 `WCF` 应用程序。这些 API 允许开发者集成与内部工作的外部功能。例如，你可以使用 Facebook API 集成到你的应用程序中。`C# API` 也可以这样做。发布 API 的好处是，第三方开发者使用什么语言并不重要。他们可以使用 `PHP`、`Java`、`JavaScript` 和 `Python` 与你的 API 交互。只要应用程序支持 `XML` 或 `JSON` 输入输出，第三方开发者就可以处理你的 `C# API`。

`C#` 还用于数据库应用程序。它与 `SQL Server` 工作，存储并从数据库服务器请求数据。`C#` 可以使用 `Entity Framework` 和 `MSSQL`，这样开发者可以使用 `LINQ` 查询和 `POCO` 类来处理数据。这意味着你不需要在数据库存储过程之间来回切换。相反，开发者可以直接与数据库结构和数据进行工作。

最后，`C#` 用于 Windows 服务。这些是在计算机（通常是服务器）后台运行的程序。它们被用于自动化，以确保某些过程在一天中的特定时间自动发生。

微软提供了 `Visual Studio Express`，这是一个免费版本，它为你提供了创建 `C#` 应用程序所需的所有内容。你也可以使用 `Visual Studio` 创建 `VB.NET` 应用程序。微软将其桌面版和网页版分开了，因此请确保为你的项目下载了正确的版本。例如，如果你想创建一个 Web 应用程序但你使用的是桌面版 `Visual Studio`，那么你将无法创建该程序。在创建应用之前，你需要下载网页版的 `Visual Studio` 应用程序。

要创建具有数据库存储功能的应用程序，你需要 Microsoft `SQL Server`。你不需要完整版或企业版，你只需要 Express 版本来配合你不断增长的应用程序。你可以创建一个功能完整的 `SQL Server` 数据库，它可以与你的应用程序配合，然后你可以将 Express 版本的数据库迁移到功能完整的网站或应用程序版本中。

在安装 `Visual Studio` 时，你可以选择下载与自己的应用程序集成的第三方应用程序。`Visual Studio` 使用 `NuGet`，它允许你下载文件并自动将它们添加到你的项目中。一旦你安装并配置了 `Visual Studio`，就可以下载任何所需的库来开始工作。

如果你决定创建一个 Web 应用程序，需要的最后一个项目是 `IIS`。`IIS`（Internet信息服务）是允许你托管和运行网站的 Web 软件。如果你有一台 Windows 电脑，你已经拥有了 `IIS`。某些版本的 Windows 如果你不升级到专业版，则不允许运行完整版的网站。所有服务器操作系统都运行完整版本的 `IIS`，而桌面版有时需要专业版来运行你的测试网站。如果你不确定，请检查控制面板中的设置，查看你是否有能力在桌面上运行 `IIS`。

#### 一些基础最佳实践

一旦你安装了 `Visual Studio` 并设置好了整个环境，在开始编程之前，有一些最佳实践需要遵循。这些是大多数使用 `C#` 的开发者在工作时遵循的微小标准。如果你决定在行业内工作，你应该了解这些标准，以保持一致性，并在你需要接手另一位编码员的工作时理解其代码。

在构建大型字符串时，使用 `StringBuilder` 代替 `string`。`StringBuilder` 是一个我们将在后续章节中学习的类。它的性能比原始字符串变量更好。你可能会倾向于直接使用原始字符串而不是 `StringBuilder`，但在处理动态字符串时，请务必使用 `StringBuilder`。

使用动词来创建方法。我们将在后续章节中讨论类和方法，但在创建你的类及其方法时，命名方案是非常重要的。方法赋予动词名称，是因为它们执行了存储数据或操作数据的动作。它们还接收用户的输入并为你的用户提供输出。

类属性应该始终是名词。再次，我们将在后续章节中介绍类和属性，但请记住属性应该用名词命名。例如，如果一个属性持有用户的名称，它应该命名为 `m_name`、`m_fullname` 或 `_fullname`。注意，类成员属性应该有某种前缀。它应该是 `m_` 或 `_` 作为前缀。这是命名方案中的标准做法。

经常对你的代码进行注释。记住，必须有人跟在你后面并编辑你的代码。这意味着你需要对代码进行注释，以便他人能够接手你未完成的工作。注释帮助其他编码员理解你的代码应该做什么，它应该期望什么类型的输入，以及编码员是否应该注意系统中的任何异常。

`C#` 是一门非常棒的学习语言。如果你想在 Windows 环境下工作并想在行业内赚钱，`C#` 是学习的完美语言。它是企业中非常流行的语言，薪水也很高。它也是使用 Microsoft `SQL Server` 进行存储的编码员的首选语言。当服务器运行 Windows 操作系统时，它也被用于自动化。事实是，如果你使用 `C#` 和 `Visual Studio`，是不会出错的。它是任何 Web 或桌面开发者都应该学习的流行语言。

# 第 3 章

## 数据类型

**目标：** 数据类型决定了你可以在变量中存储的数据。`C#` 有多种数据类型，本章将帮助你理解它们以及你对这些变量可以做的事情。

当你编写程序时，你需要告诉操作系统它对系统中设置的每个变量可以期待什么。你需要定义变量数据类型的原因是，操作系统根据数据类型分配内存。数据类型告诉操作系统你将在变量中存储什么，并且对于你定义的每个变量都是必不可的。

### 基础数据类型语法

在进入特定的数据类型之前，我们应该看一眼基础语法。以下是定义变量的基本模板。

```
<data type><variable name>;
```

我们将涵盖程序中将使用的几种数据类型，但仅就本节而言，请记住**数据类型指定符**始终是你变量声明语句中的第一个项。

你变量声明语句中的下一个项目是变量名。你可以给变量起任何名称，但通常编码标准定义了你命名变量的方式。例如，大多数开发者要求在变量名中使用“驼峰命名法”`camelCase`。你用小写字母开头，然后变量中的任何后续单词都大写。例如，你将变量命名为 "`camelCase`" 而不是 "`CamelCase`" 或 "`camelcase`"。然而，你可以为变量起任何你喜欢的名称。

注意，`C#` 中不同的大小写代表不同的变量。在 `camelCase` 示例中，`camelCase`、`camelcase` 和 `CamelCase` 都是不同的变量。这遵循了 C 语言的变量命名约定。你会发现 `C#` 遵循了许多标准的 C 风格。

语句的最后一个要求是分号。分号告诉编译器语句已结束。

变量的最后一个规则是，你可以在声明变量的同时为它赋值。让我们看看这种赋值语法。

```
datatype variable name = value;
```

再次，赋值是可选的，但上面的语法是你在声明的同时赋予值的方式。记住，值必须与数据类型匹配。例如，如果你尝试将字符串字符赋值给整数数据类型，编译器将给出错误。

### 字符串数据类型

在任何程序中，你都会处理字符串。字符串是包含单词的变量。这些单词可以是任何字母数字字符，甚至是特殊字符。大多数用户输入都是字符串形式的，但然后你可以将其转换为其他数据类型。例如，你可能会要求用户输入数字，然后将其转换为整数以进行某种计算。

让我们看一个字符串变量的示例。

```
string myName = "John";
```

注意，`string` 数据类型首先用于定义字符串变量。这是一个原始字符串数据类型。数据类型 "`String`" 是一个类，只有当你对变量执行复杂的字符串函数时才使用它。大多数情况下，你在设置变量时使用原始字符串定义。

语句中的下一个项是变量名。我们使用了驼峰命名法，变量名中的第一个字母为小写。接下来的名称使用大写字母。

在这个语句中，我们为定义赋值。我们将 "`John`" 赋值给 `myName`。注意，语句以分号结束。分号告诉编译器语句已结束。如果我们忘记了语句中的分号，下一个语句将导致语法错误。

你也可以声明一个没有值的字符串变量。我们可以使用相同的语句来说明如何定义没有值的变量。

```
string myName;
```

此时，该字符串为空（null）。你也可以使用一个特殊的字符串属性 `Empty` 将字符串初始化为空值。

```cs
string symbolName = string.Empty;
```

上述语句将字符串初始化为空值。这通常用于程序员还不知道字符串的值，且不想将字符串值设置为 `null` 的情况。

### C# 中的数值数据类型

`C#` 提供了多种数据类型，你可以用它们来存储和计算数值。两种主要的数值类型是小数 `decimals` 和整数 `integers`。整数是不带小数点的数值。它们可以是带符号的或无符号的。带符号整数可以是负值，这意味着符号部分是负号，而数字是数值本身。无符号整数是不带加号的正值。它被自动假认为正值。



在 C# 中，小数值有多种数据类型，取决于你想要使用的精度点数量。最小的数值值是 `float` 数据类型。最大的是 `decimal` 数据类型。小数点允许你在变量中存储多达 128 位的数字。

首先，让我们来看一下整数数据类型的声明。

```cs
int myNumber = 22;
```

注意，用于声明整数的声明模板和语法与我们用于字符串变量时是相同的。所有的变量声明都遵循相同的模板语法，因此当你编写代码时，可以预期的每个声明都会遵循这种语法。

我们使用 `int` 数据类型定义了名为 `myNumber` 的变量。它是整数指定器的缩写。整数存储一个 32 位的数字，但你可以使用 `long` 数据类型将整数存储空间扩展到 64 位。让我们来看 `long` 变量声明。

```cs
long myNumber = 222222;
```

我们在上面的语句中使用了了一个较长的整数值，以说明当你使用 `long` 数据类型时可以使用更长的数字。

让我们来看小数变量的声明。首先，让我们来看 `float` 小数声明。

```cs
float myNumber = 22.333;
```

再次，使用了相同的语法模板来定义变量。这次我们使用了一个小数。我们也可以使用 0 作为小数占位符。例如，以下代码也是有效的语法。

```cs
float myFunction = 22.0;
```

如果我们需要更长的小数值，可以使用 `double` 数据类型或 `decimal` 数据类型。`double` 数据类型允许 64 位的小数值。以下代码展示了如何声明一个 `double` 变量。

```cs
double myFunction = 22.2222222222;
```

再次，我们使用了较长的小数值值，说明 `double` 数据类型可以持有多达 32 位的小数值。

接下来，我们有 `decimal` 数据类型。除非你需要高精度（例如科学计算），否则 `decimal` 数据类型很少使用。以下是小数值声明语句的示例。

```cs
decimal myFunction = 33.444444444444444444444444444;
```

你可以使用 `decimal` 数据类型拥有高达 28 的小精度值。除非你有精确数值计算的需求，否则你不需要使用这种类型。

当你确定变量的数据类型时，不要只使用最大的数据类型。使用与你需要的数值匹配的数据类型。在应用程序中使用过多内存被认为是糟糕的代码，并且会损害程序的性能。

### 自定义数据类型

当你使用类（classes）时，你就创建了一个自定义数据类型。你也可以使用结构体（structs）和枚举（enums）创建自定义数据类型。我们将在后续章节中介绍这些数据类型，但在创建程序时，你仍然需要理解如何定义这些变量。

类定义了你自己的属性和方法。就像从 .NET 框架集成的类一样，你也可以创建自己的。我们将讨论如何创建一个带有自己的方法和属性的类，但让我们看看如何使用自己的类来定义变量。假设你有一个名为 `MyClass` 的类。以下代码使用 `MyClass` 数据类型定义了一个变量。

```cs
MyClass myclass = new MyClass();
```

你会发现，使用自定义数据类型定义值与原始数据类型大不相同。你仍然使用数据类型指定，但随后你使用 `new` 指定符配合类的构造函数。我们将在讨论类时介绍构造函数。只需要知道，当你使用带类的类的自定义数据类型时，你需要实例化该类并将其赋值给变量。在这个示例中，我们实例化 `MyClass` 类并将其赋值给 `myclass` 变量。记住 C# 是区分大小写的，所以 `MyClass` 是一个类，而 `myclass` 是一个变量，编译器可以理解其中的区别。

### 常数

你并不总是需要为变量动态赋值。有时你只需要知道 pi 的值始终是 3.14。你不需要动态地分配这个值，因此你可以创建一个常数。常数持有永不改变的静态值。

```cs
const double PI = 3.14;
```

乘法变量的工作原理相同。乘法运算符的语法与我们看过的其他运算符相同。下面的代码是乘法运算符的示例。

```
int myNumber = 3;
addedNumber = myNumber * 4;
```

我们对代码唯一的更改是星号符号 `*`，它用于指定你想将一个变量乘以另一个变量。我们将 `myNumber` 乘以 4，因此结果是 12，存储在 `addedNumber` 变量中。

我们可以使用的最后一个简单运算符是除法运算符。除法运算符的工作方式与其他运算符相同。让我们来看除法运算符的示例。

```
int myNumber = 3;
float addedNumber = myNumber / 4;
```

同样，我们做的更改是除法运算符。我们将 3 除以 4，结果是 .75。请注意，我们需要将 `addedNumber` 改为 `float` 数据类型，因为除法计算的结果是一个小数值。当你进行除法计算时，你通常希望使用 `float` 数据类型以避免代码中的错误，即使你确定每个结果都将整数。

现在我们已经看了简单运算符，可以转向那些较不为人知的运算符了。第一个是取模运算符（模运算）。取模运算符执行除法计算，但它返回的不是减去余数的结果，而是余数。让我们来看一个示例。

```
int myNumber = 4;
float addedNumber = myNumber % 3;
```

在上面的示例中，除法计算是 4 除以 3。结果是 3 进 4 一，余数为 1。因此，`addedNumber` 变量包含值 1。在使用取模运算符时记住这一点，否则你可能会得到不同的结果。

下一个运算符是递增操作。你会经常使用这个运算符，特别是在循环中——我们将在后面的章节中介绍。递增运算符将变量加 1。该运算符是变量加 1 的简写。让我们来看一个示例。

```
int j = 0;
j++;
```

上面的代码与下面的代码相同。

```
int j = 0;
j = j + 1;
```

注意，之前的版本的代码要短得多且更容易阅读。结果只是给变量 `j` 加上了 1。在这个示例中，结果是 `j` 等于 1。

你也可以以相同的方式递减变量。让我们来看递减运算符。

```
int j = 0;
j--;
```

注意，我们只是把加号替换成了减号。结果是变量 `j` 递减了 1。上面的代码与下面的代码相同。

```
int j = 0;
j = j - 1;
```

结果是变量 `j` 包含值 -1。

上面的运算符都是你在整个 C# 代码中将使用的运算符。这些计算在任何 C# 程序中都是常见的。

### 关系运算符

关系运算符用于我们将在后续章节中讨论的循环和条件。关系运算符在两个值（静态或动态变量）之间进行比较。在本节中，我们将介绍不同的运算符。

在许多情况下，你需要确保两个变量彼此相等。关系运算符用于 `if` 条件中，我们将使用 `if` 语法——但请知道，此操作的完整覆盖将在后面的章节中介绍。

让我们先来看相等运算符。

```
int myNumber1 = 1;
 myNumber2 = 2;
if ( myNumber1 == myNumber2)
{
  //如果条件成立，则执行这些操作
}
```

在上面的代码中，我们创建了名为 `myNumber1` 和 `myNumber2` 的两个变量，并将它们初始化为 1 和 2。显然，这两个值不相等，`if` 条件中的关系运算符返回 `false`。由于结果为 `false`，`if` 条件内部的语句不会执行。记住，如果关系运算符的结果为 `false`，则 `if` 语句括号内的任何内容都不会执行，代码执行将跳转到条件下方的任何代码。

就像相等运算符一样，你也可以识别两个变量是否不相等。使用相同的语法，让我们来看示例。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 != myNumber2)
{
//如果条件成立，则执行这些操作
}
```

我们将关系运算符更改为 `!=` 或“不等于”。在这个条件中，计算结果为 `false`，所以这次 `if` 条件内的任何语句都将被执行。

你还需要确定一个值是否大于或小于另一个变量。C# 也有这些关系运算符来为你提供这两个条件。让我们来看大于关系运算符。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 > myNumber2)
{
//如果条件成立，则执行这些操作
}
```

我们使用了相同的语法，只需将关系运算符切换为大于符号即可。在这个示例中，计算结果为 `false`，所以没有任何 `if` 语句被执行。

与大于运算符类似，让我们来看小于语句。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2)
{
//如果条件成立，则执行这些操作
}
```

在上面的语句中，`myNumber1` 确实小于 `myNumber2`，因此计算结果为 `true`。在这个示例中，`if` 语句括号内的语句将执行。

在之前的操作中，变量要么大于要么小于，但如果你想知道该值是否相等呢？你可以将大于和小于运算符与相等运算符结合，以检查两种条件。让我们来看大于等于运算符。

int myNumber1 = 1;

### 逻辑运算符

逻辑运算符允许你在语句中组合条件。你可以通过评估两个条件来控制执行流。有三个逻辑运算符：`&&`（与）、`||`（或）和 `!`（非）。

让我们首先使用上一节中使用的 `if` 条件来看 `&&` 运算符。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2 && myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

在上面的语句中，我们首先评估 `myNumber1` 是否小于 `myNumber2`。在这个示例中，结果为 `true`，但我们添加了 `&&` 逻辑运算符，所以语句在确定执行流之前必须评估第二个条件。第二个条件评估 `myNumber1` 是否等于 2。这个条件的结果为 `false`。因为我们使用了“与”，两个条件都为真时语句才会执行。由于其中之一为 `false`，`if` 语句不执行。

让我们使用相同的值但将逻辑运算符更改为或（`||`）。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 < myNumber2 || myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

最后一个逻辑运算符是非（`!` 操作。非运算符改变条件的逻辑。让我们来看一些代码。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (!myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

在上面的代码中，我们不是在评估条件是否为真，而是识别条件是否为假。因为有非运算符，你知道我们正在评估为 `false`。这个运算符有点让人困惑，但由于表达式计算结果为 `true`，非运算符将条件更改为 `false`。由于条件为 `false`，`if` 语句执行。

### 赋值运算符

你已经见过赋值运算符了。等号是赋值运算符的一个简单示例。

赋值运算符。它将一个值赋予变量。让我们再次查看一遍赋值运算符。

```

```

赋值运算符用于将值 1 赋值给 `myNumber1`。

你也可以对变量进行数学计算，并用一行代码将结果赋值给它。这是将赋值运算符与数学计算结合的一种简写代码形式。你使用我们在第一节中使用相同的数学运算符，并将它们与赋值运算符结合。

让我们来看这个例子。

```
int myNumber1 = 1;
myNumber1 += 2;
```

在这个例子中，`myNumber1` 首先被赋值为值 1。下一条语句在变量上加 2，然后给它赋予新值。第二条语句的结果为 3 并将其赋值给 `myNumber1`。

你可以对任何其他数学操作执行相同的操作。让我们再看另一个使用乘法运算符的例子。

```
int myNumber1 = 1;
myNumber1 *= 2;
```

注意，使用的语法是相同的，只是我们使用了乘法字符。在这个例子中，`myNumber1` 乘以 2，并将该值赋值给 `myNumber1`。结果是 `myNumber1` 现在包含值 2。

运算符是任何编程语言的重要部分，包括 C#。这些运算符存在于每个主要的应用程序中，因此你需要熟悉它们，以便在任何编程语言中工作。

### For 循环

`for` 循环是所有循环结构中最受欢迎的。循环遍历一系列条件，直到满足停止条件。如果停止条件从不被满足，你就会创建一个无限循环，因此你总是需要记住包含停止条件。`for` 循环最受欢迎，是因为很难达到停止条件。

让我们来看你用于 `for` 循环的通用语法模板。

```
for ( init; condition; increment )
{
// 在此处执行
}
```

`for` 循环初始化一个变量，设置停止条件，然后递增初始化的变量。这三条语句用分号隔开。每次迭代时，初始化的变量都会递增，直到满足条件并退出循环。让我们来看一个例子。

```
for ( int j = 0; j < 5; j++)
{
// 在此处执行
}
```

在上面的 `for` 循环中，变量 `j` 被初始化并设为 0。你可以将变量设置为任何值，但标准是将其设置为 0，因为循环通常用于遍历数组，而这些结构从索引 0 开始。下一条语句是条件。只要 `j` 小于 5，循环就会继续。一旦 `j` 等于 5 或大于 5，循环就会执行。递增语句在每次循环后给 `j` 加 1。让我们为循环期间发生的情况增加一些细节。

```
for ( int j = 0; j < 5; j++)
{
    Console.WriteLine(j.ToString());
}
```

上述循环的输出如下。

- 0

- 1

- 2

- 3

- 4

注意值 5 没有打印，因为当 `j` 达到值 5 时，循环退出了。

## If 语句

我们在上一节中对 `if` 语句介绍较少。`if` 语句在编程中非常常见，它是改变代码的一种。

首先，让我们来看 `if` 语句的set模板。

if (expression)

int myNumber1 = 1;

if (myNumber1 == 2)

我们在之前的 `if` 语句使用了相同的代码来提供另一个例子。在这个例子中，我们给了 `if` 语句一些执行的代码。如果 `myNumber1` 等于 2，它会打印“The variable equals the value of 2”。由于 `myNumber1` 初始化为值 1，结果是 `if` 语句不执行括号内的代码。

一直为止，我们只看了带有一个条件的 `if` 语句，但 `if` 语句还允许将条件与 `else` 以及 `if-else` 语句结合。这两者都为你的代码增加了更多控制。让我们来看这种语句的模板。

if(expression)

int myNumber1 = 1;

{
    Console.WriteLine("The variable equals the value of 2");
}
else
{
    Console.WriteLine("The variable does not equal 2");
}
```

我们在之前的 `if` 语句使用了相同的代码，但我们添加了 `else` 语句。与之前的 `if` 语句一样，这个默认为假。而不是直接跳过所有的 `if` 语句，`else` 语句默认执行。这一次，`if` 语句执行的结果是在控制台中显示“The variable does not equal 2”。

}
else
{

}
```

}
```

### Switch 语句

最后一种条件语句是 `switch` 语句。`switch` 语句与 `if` 语句类似，但它是对一个变量进行多个条件的评估。让我们先看看该语句的模板。

```
switch(expression) {
  case constant-expression :
    // 要执行的语句
    break;
  case constant-expression :
    // 要执行的语句
    break;
  default :
    // 要执行的语句
}
```

通过该语句，变量被设置为 `switch` 表达式的值，然后每个 `case` 语句将确定变量是否等于该值。让我们来看 `switch` 语句的运行。

```
int myNumber = 1;
switch (myNumber) {
  case: 1
    Console.WriteLine("Value is 1");
    break;
  case: 2
    Console.WriteLine("Value is 2");
    break;
  default:
    Console.WriteLine("Don’t know the value");
}
```

在上面的代码中，我们评估变量 `myNumber` 的值。我们将其初始化为 1，然后使用 `case` 语句遍历每个可能的值。因为我们知道值是 1，我们可以看到第一个 `case` 语句评估为真，然后在控制台上显示“Value is 1”。

`default` 语句类似于 `if` 块中的 `else` 语句。如果没有任何 `case` 语句的结果为真，则执行 `default` 语句。

`break` 语句用于退出 `case` 语句。如果你不添加 `break` 语句，下一个 `case` 将一直执行，直到代码到达 `default` 语句。只需记住，每个 `case` 语句都需要一个 `break` 来退出 `switch` 块。

我们在本章中学习了几个循环和 `if` 语句。理解代码的执行流非常重要，因为这些语句在包括 C# 在内的任何编程语言中都很常见。这些语句需要通过练习来理解代码的执行方式，因为每个语句都会改变工作流。使用这些语句在你自己的程序中练习代码流。

## 第 6 章：OOP 简介

目标：OOP 是 C# 程序主要的架构代码设计。本章涵盖了使用 OOP 概念进行 C# 编程的基础。

面向对象编程（OOP）与线性开发非常不同。OOP 使用组件的概念进行软件开发。它不是只是逐行编写代码并让每行执行到找到代码末尾，类（classes）的概念使用了按照类定义和调用的顺序来执行的组件。本章将帮助编码人员理解如何与 OOP 及其概念工作。

## 理解 OOP 基础

OOP 使用创建组合在一起以构建整个程序的各个部分的概念。这些部分被称为类（classes）。它们也被称为类对象。类代表了你程序的每个部分。

为了理解为什么类代表了程序的部分，请想象一下汽车。汽车有几个部分组合成一整辆汽车。每个部分单独来说都是没用的，但当它们组合在一起时，它们就创造了一台许多人无法制造的机器。

以汽车为例，你需要（除其他之外）发动机、方向盘和轮胎来组成一台汽车。没有这些组件，汽车就是没用的。类代表了汽车的这些部分。类包含了这些部分的所有属性，以及它们移动或停止汽车所需的任何操作。

在开始编程之前，你需要在编程之前对其进行设计。当你使用第三方绘图程序或你自己的草图和图纸来设计类时，无论你使用什么，布局程序并确定你的类如何表示程序的部分都是关重要的。在编码之前对程序进行设计，可以避免任何由于程序部分缺失而导致的错误。

在设计类时，你还应该确保每个属性和方法都能与类本身良好配合。例如，如果你有一个带有 `Customer`（客户）和 `Product`（产品）类的电子商务应用程序，你不会在 `Customer` 类中放置一个处理产品库存的方法。你会将产品库存放在 `Product` 类中，否则当你发现它在正确的类中不可用时，可能会意外创建两次相同的方法。

## 公共修饰符 (Public Specifier)

一旦你设计了类，就必须决定要让它们对程序的其他部分可用。我们将在下一节讨论如何创建类，但理解围绕它们的基础知识很重要。

`public` 修饰符告诉程序该类可以在程序的任何区域访问。让我们来看一个带有 `public` 修饰符的 `Customer` 类示例。

```
public class Customer {
    public Customer() { }
    public string first_name;
    public string last_name;
    public string phone;
}
```

在上面的 `Customer` 类中，注意类的第一个修饰符是 `public` 关键字。如果我们删除了 `public` 关键字，该类将对程序的其他部分不可用。

## 将类设置为受保护（Protected）

最后一个重要的修饰符是受保护（protected）修饰符。这个并不常用，但偶尔也会使用。受保护类只允许当前类或任何子类使用属性和方法。

我们将介绍如何从父类派生子类，以及如何使用子类来扩展父类。只需记住，在设计程序时，对于受保护的类，只有子类可以使用它的方法和属性。

## 在代码中创建方法

方法是类对程序数据执行的操作。方法本质上是类内部的函数。它们被称为类的“动词”。当对类执行操作时，就会使用方法。它可以是更改电话号码的方法。你可以设置一个方法从库存中减少商品（你会在 `Product` 类中创建一个名为 `DecrementInventory` 方法）。

方法的位置取决于你创建程序时的设计。无论方法名称是什么，注意设计中的重要部分。你总是将方法放在合适的类中。例如，你不会将 `DecrementInventory` 方法放在 `Customer` 类中，因为它与客户无关。糟糕的设计会对你的应用程序架构产生负面影响。

让我们看看类中的方法。我们提到一个允许用户更改电话号码的类方法。在客户类中的示例方法如下：

  {
    this.phone = new_phone;
  }
  public string first_name;
  public string last_name;
  public string phone;
}
```

我们在 `Customer` 类中添加了 `ChangePhone` 方法。如你所见，此方法接收 `new_phone` 变量。该变量获取客户电话号码并赋值给本地属性。再次注意，我们使用 `this` 指定来表示我们要赋值的是本地类变量而不是任何其他变量。当你将局部变量赋值给全局类变量且两者名称相同时，这一点尤为重要，正如我们在上面代码所示。

# 第 8 章
结构与枚举

**目标：** 结构（Structures）和枚举（Enum）是创建自定义数据类型的两种方式。本章将向你展示如何使用这两种数据类型来组织代码并使其更容易读。

我们在上一节中涵盖了类，类允许你创建自己的数据类型。结构和枚举是创建自定义数据类型的另外两种方式，但这些数据类型的工作原理与类不同。在使用结构和枚举时你会受到更严格规则的限制，并且它们用于你在类中看到的不同场景。在本章中，我们将查看这两种结构，并让你了解在 C# 程序中何时会使用它们。

## 为什么使用结构或枚举而不是类？

当你开始使用 C# 编程时，你可能想为一切都创建类。在这一章之前，我们一直推崇每个组件都应该是类的观点，但你可以使用枚举和结构处理程序中较小的组件。

例如，假设你有一个客户类型列表。每个类型在数据库中都有 0 到 3 的值。你可以为客户类型创建一个类，但也可以为这些值创建一个枚举。枚举为这些值提供了一个友好的名称，并存储一个整数来表示每个友好名称的编码值。

结构的作用与枚举类似。结构允许你包含不仅是整数值的内容。枚举用于整数值，而当你需要存储其他数据类型时，结构非常有用。例如，当你需要存储客户 ID 和类型的字符串值时，你可以为客户数据类型创建一个结构。你可能想在结构中存储与客户 ID 匹配的描述。你可以为此类型结构使用类，但有时当你只需要一两个属性来表示自定义数据类型时，类并不是必须的。

在本章中，我们将向你展示何时应该使用这些数据类型而不是构建整个类。在大多数情况下，你将使用类来定义你的应用程序，但在少数示例中，你不需要一个完整的类，而是一个小小的枚举或结构。

## 使用结构

结构与类最相似的东西。它们创建你自己的数据类型，但与类对象的定义略有不同。结构允许你创建一个自定义数据类型，该类型包含代码所需的任何数据类型的值的列表。

结构看起来像具有长属性列表的类，但你使用 `struct` 关键字来定义它们，而不是类定义。

结构括号内是属性。每个属性都应该设置为 `public`，否则你将无法访问它们。在类中，有理由不许可访问属性，但在结构中，你应该将它们设置为 `public`。你可以添加任意数量的结构属性，但当它变得太复杂时，有时选择类比使用结构更好。

## 创建枚举 (Enums)

枚举与结构体略有不同，但它们的设置方式相似。枚举只能存储整数值。当你有一组整数值，且不想在多个变量中静态地设置它们时，枚举就非常有用。例如，假设你想使用一个星期列表，并用从 0 到 6 的整数值表示它们。如果你不使用枚举变量而这样做，你就必须为你调用的每个函数创建变量。与其在每次需要处理星期几时创建七个变量，不如创建一个可以随时调用的枚举。枚举还允许你使用更易于识别的友好名称来表示这些值。

让我们来看创建枚举的模板语法。

```
enum enum_name
{
// 枚举变量的列表
}
```

使用枚举时，你使用 `enum` 关键字来表示你想创建一个枚举数据类型。在指定要创建枚举数据类型后，给你的枚举结构起一个名字。你可以给枚举起任何你喜欢的名字。枚举的命名规则与普通变量相同。

枚举括号内部是定义枚举所需的所有属性。让我们来看一个使用之前描述的“星期”枚举的真实世界示例。

```
enum Days { Sun, Mon, Tue, Wed, Fri, Sat };
```

注意，在枚举中，你不需要定义访问修饰符（specifier），也不需要声明任何数据类型。记住，枚举只持有整数数据类型，所以你不需要定义这些修饰符。它们默认都是公公开的，因此你不需要使用 `public` 修饰符。

当你定义一个枚举变量列表时，编译器会自动为每个变量赋值。除非你另有指定，否则第一个值始终为零。每个额外的变量会被赋予列表中的下一个数字。在这个示例中，第一个变量 `Sunday`，`Monday` 的值为 1，依此类推。

让我们看看你如何在代码中使用它。

```
class EnumProgram {
    enum Days { Sun, Mon, tue, Wed, thu, Fri, Sat };
    static void Main () {
        int monday = (int)Days.Mon;
        int friday = (int)Days.Fri;
        Console.WriteLine("Monday: {0}", monday);
        Console.WriteLine("Friday: {0}", friday);
    }
}
```

在上面的代码中，你可以看到枚举变量是如何返回值的。我们将值分配给两个整数变量。在上面的代码中，输出首先显示 Monday 的整数值，即 1。下一个输出值是 Friday，即 5。

你也可以重新分配枚举中设置的整数值。例如，假设你想让你所有的枚举值都从 1 开始，并分配从 1 到 7 的整数。让我们来看修改枚举值的代码。

`enum Days { Sun = 1, Mon, Tue, Wed, Thu, Fri, Sat };`

在上面的代码中，我们从值 1 开始整数赋值。在这种情况下，最后一个变量 `Sat` 的值不再是 6，而是 7。

你对枚举和结构体的需求可能没有对类那么频繁，但在许多不需要类定义带来的臃肿开销的场景下，它们是非常用的。我们向你展示了几个示例，当你设计程序时，你会发现它们在哪些地方有用。

# 第 9 章
## 继承 (Inheritance)

**目标**：类和面向对象编程（OOP）让你具备从父类派生类的能力。本章将解释类结构中的继承。

OOP 不仅仅是创建类和构建可以调用其他类的程序。你可以从父类派生子类，这样你就不需要为相似的对象重复代码。如果你没有良好的类设计，继承可能会变得复杂，因此本章试图解释继承以及你应该如何设置类结构以获得最佳的可扩展性代码。

## 理解基础继承

继承允许你从父类派生子类。考虑一下动物。如果你有一只狮子和一只鹦鹉，这两种动物都有非常不同的特征，但它们也有相似的特征。它们都是动物，但一种是鸟类，另一种是哺乳动物。如果你不使用继承，你就需要创建两个类从上到下地描述这两种动物。

通过继承，你可以创建一个描述动物基本特征的类，然后从主父类派生子类。例如，鸟类和狮子都有眼睛和脚。它们的眼睛和脚看起来可能不同，但仍然拥有。其他特征不同，但所有的狮子和鸟类都有脚。你可以创建一个定义脚和眼睛的父动物类，然后狮子和鸟类子类可以定义各自动物的特定特征。

继承的目的是为了使代码不再重复。如果没有它，你必须创建一个鸟类和狮子类来定义每种动物的眼睛和脚，这将导致冗余代码。当你创建冗余代码时，管理变得变得困难。当你创建了十个定义动物眼睛的类并需要更改该描述时，你需要修改所有十个类。这在你尝试扩展代码时留下了更多产生错误和问题的空间，而这正是你想要避免的。

并不是每个类都必须是父类或子类。你可以创建不派生自任何其他代码的独立类。你如何设计代码取决于你以及你想要创建程序的需求。

## 继承自父类

在创建子类之前，你需要先创建一个父类。由于我们使用动物作为示例父类，我们首先创建一个动物类，定义所有动物之间最基本的、共享的特征。

让我们来看一个动物类的示例。

```
abstract class Animal
{
    public string eye_color;
    public string number_of_feet;
    public function breath()
    {
        return "Animals breathe air.";
    }
}
```



我们在上面的代码中创建了一个 `Animal` 类。它可以作为父类使用。大多数抽象类不能被实例化，因为抽象类是高层的主类，可以作为许多子对象的父类。上面的代码设置了一些标准特征。两个属性分别获取动物的眼睛颜色和动物的脚的数量。所有动物都会呼吸，所以我们设置了一个方法表示每只动物都会呼吸。

现在是时候派生你的子类了。让我们从主动物类派生一个狮子类。

我们现在有一个继承自父类 `Animal` 的派生子类 `Lion`。我们不需要重新定义狮子的眼睛和脚，因为这些值已经在父类 `Animal` 中存在。

注意，类定义首先命名为 `Lion`，然后添加一个冒号并连接 `Animal` 类。这就是你告诉编译器你想要继承父类的方法。你可以通过添加逗号并添加更多父类名称来派生多个类，以表示你想继承多个父类。子类也可以继承自其他子类。只要不被设置为 `private`，父类的定义就并不重要。一旦你将一个类设置为私有，你就无法派生它或对其进行实例化，因此在选择修饰符时要小心。

我们的 `Lion` 类还拥有属性和方法，它们定义了狮子特有的特征。狮子会咆哮，因此我们有一个 `Roar` 方法来定义狮子说话的方式。我们还有一个 `mane` 属性，来定义狮子的鬃毛。这两个特征是狮子特有的，因此它们属于 `Lion` 类。如果它们对所有动物都是通用的，我们会把它们放在 `Animal` 类中，以便所有其他子类都能使用这些属性和方法。

## 继承与接口

接口是继承的基础。接口允许你定义一个类，该类可以包含链接到接口的每个类的声明，但任何类都可以派生它。它为子类与链接到接口的父类之间提供了一种创建“合约”的方法。

接口与类不同，它们只包含类的声明而不包含类的定义。让我们来看一个示例接口。

```c
public interface IAnimal {
    // interface members
    void breathe();
}
```

由于我们在 `Animal` 类中只有一个方法，因此在接口中也只定义了一个动物方法。注意，接口中没有类定义。你只需要定义接口中使用的函数。这同时也定义了可以在子类中使用的函数。这些接口使得扩展你的类变得更容易，因为你可以在类中创建尚未准备好发布的方法，而在这些方法准备好使用之前，不需要有任何子类来派生它们。

标准的命名方案还包括在命名接口时使用 `I` 前缀。当你在代码中同时处理类和接口时，该前缀可以区分类和接口之间的区别。

一旦你创建了接口，就可以在你的类中继承它。让我们来看看 `Animal` 类派生自 `IAnimal` 接口的情况。

```csharp
public interface IAnimal {
    // interface members
    void breathe();
}

abstract class Animal : IAnimal {
    public string eye_color;
    public string number_of_feet;
    public function breathe() {
        return "Animals breathe air.";
    }
}
```

派生主 `Animal` 接口只需要这些操作。现在，你的其他任何类都可以继承该接口或主 `Animal` 类。对于一个包含接口的程序来说，只允许程序员派生自接口是标准做法，但这取决于你设计代码和布局类的方式。

## 静态类

静态类需要被提到，因为它们与普通的 `public` 类有些不同。静态类不需要实例化，当你想要创建一个包含你想在代码中随机使用的函数的类时，这使得它们是有益的。静态类使用 `static` 关键字定义。

你可能需要一个静态类，因为它包含一个在你在编写代码时可能随手就的函数。例如，C# 中的 `ToString` 方法就是一个静态方法。你可以在不实例化类的情况下随时使用它。只需调用 `ToString` 方法，它就会将你的变量转换为字符串。当你想要将数字转换为字符串值时，就会使用此方法。`ToString` 方法无论其包含什么类型的数据，都会将任何变量转换为字符串。

让我们来看静态类。

```csharp
static class Animal : IAnimal
{
    public string eye_color;
    public string number_of_feet;
    public function breathe()
    {
        return "Animals breathe air.";
    }
}
```

注意，我们将上述 `Animal` 类中的 `abstract` 类型改为 `static`。现在，我们不需要实例化这个类了。由于它不再是抽象定义的类，我们现在可以实例化它。通过 `static` 修饰符，我们可以在不实例化的情况下调用类。让我们看看这在 C# 方法中是什么样的。

```csharp
static class Animal : IAnimal
{
    public string eye_color;
    public string number_of_feet;
    public function breathe()
    {
        return "Animals breathe air.";
    }
}

class StaticTester
{
    static void Main(string[]) args
    {
        Console.WriteLine("This is what happens when you call a static class: {0}", Animal.breathe());
    }
}
```

在上面的代码中，我们定义了静态 `Animal` 类，然后使用类内部的静态方法调用 `breathe` 方法。注意，我们在调用方法之前没有实例化类。当你在代码中使用 `static` 修饰符时，这是有效的语法。

继承是一个复杂的课题，大多数开发者在创建程序时需要一些时间来理解。在设计程序时，你不总是总是继承类，但随着程序的增长和用户的增多，它将大大减少你扩展代码所需的时间。在掌握继承、类和 OOP 面向对象编程 之前，需要一些练习。在练习 OOP 时，多使用一些父子类的继承，以习惯它们在你的设计中的工作方式。

## 数组 Arrays

**目标：** 数组是存储包含多个值的变量。本章将帮助你理解如何处理数组，以及如何从数组中分配和检索值。

数组是几乎任何程序的一部分。它们允许你在一个主变量中存储具有相同数据类型的变量列表。例如，如果你想存储整数列表，可以将它们存储在数组中。数组比其他数据类型稍限一些。你需要预先知道要存储在数组中的数值数量。

### C# 中的数组声明

数组的声明与普通变量略有不同。你仍然必须声明数据类型。当你声明数组时，你必须定义存储在数组中的变量类型。例如，如果你将数组定义为整数数组，你只能存储整数数组。这就是数组与其他数据类型（如类或结构）的区别。

数组存储多个变量，每个变量都有一个索引。索引数字从 0 开始。也就是说，存储在数组中的第一个索引为 0。下一个值的索引为 1，之后的索引为 2。正如你所见，每个值都被赋予下一个索引。这些索引就是你如何向数组赋值以及如何在代码中检索值。

在使用数组之前，你首先需要声明它。让我们先看看模板 `datatype[] arrayName;`

在上面的模板中，第一项 `datatype` 用于确定数组的数据类型。注意，括号 `[]` 表示代码定义中的数组。这是数组代码中指示你想创建一个给定数据类型数组的唯一部分。第二项是数组的名称。你可以为数组命名任何名称来定义数组的值。

让我们来看 C# 代码中定义的数组。
`int[] myNumbers;`

在这个示例中，我们定义了一个整数数组。第二个项是数组的名称。你可以根据自己和你的编程设计为数组起任何有意义的名称。在这个示例中，我们将数组命名为 `myNumbers`。

## 给数组填充值

当你处理数组时，需要向它们中填充值。当你想要为数组填充值时，`for` 循环是最常用的方法。如果你还记得的话，我们之前介绍过 `for` 循环。`for` 循环允许你定义一个变量和一个停止条件，然后使用递增运算符自动遍历数组索引。

由于你通常知道数组的长度以及填充数组所需的数值数量，因此可以使用 `for` 循环。`for` 循环是填充数组数值的首选方法。我们想向 `myNumbers` 数组填充一个数字列表。假设你想向数组填充从 1 到 10 的值。你可以使用数组索引逐个赋值。

逐个使用数组索引比其价值要繁琐得多。填充数组的首选方法是使用 `for` 循环。让我们看看当你想要遍历每个数字并将其赋予数组索引时，`for` 循环是什么样子的。

```cs
for ( int j = 0; j < 10; j++)
{
    myNumbers[ j ] = j;
}
```

在上面的代码中，我们使用了与上一节中相同的数组。我们定义了一个名为 `myNumbers` 的整数数组。从数据类型中知道，`myNumbers` 数组中只能存储整数。

接下来的代码部分是 `for` 循环。我们知道想向数组填充十个数字。因为所有数组都从索引 0 开始，我们知道首先需要将 `j` 的值初始化为 0。`for` 循环会遍历十次数组，从 0 到 9。当变量 `j` 达到 10 时，循环退出，数组中不再存储更多值。

在上面的示例中，0 到 9 的值被存储在数组中。你也可以通过数组索引逐个存储数组值。以下代码是使用数组索引存储数组的示例。

myNumbers[6] = 6;
myNumbers[7] = 7;
myNumbers[8] = 8;
myNumbers[9] = 9;

如你所示，上面的代码比 `for` 循环要繁琐得多。你可以通过在你想要遍历的内容中添加索引值来向数组添加更多数字。显然，使用 `for` 循环比使用静态数字并将它们分配数组而不使用循环要高效得多。

## 第 11 章：泛型

我们已经讨论了类、结构和枚举。所有这些都可以创建一个你可以使用的自定义数据类型。我们还讨论了数组。数组要求在你在使用之前定义数据类型，但你可以使用泛型来回避这一点。在本章中，我们将向你展示如何创建自己的泛型，并使用框架自带的预制 `List`。

## 泛型简介

泛型与数组类似。事实上，当你创建自己的泛型时，你是在代码中创建数组。泛型是你将自定义类型存储为数组的方式。C# 语言为你提供了一种特殊的语法，让你指定想要传递一个泛型数据类型。这种数据类型可以是简单的原始类型（如字符串或整数），你甚至可以将自己的类传递给泛型。

将泛型看作一种与数组相同的方式动态存储值的方法。自定义方法和属性在泛型数据类型上执行类似的任务，但在所有方法的背后都是处理所存储的数组变量的代码。唯一的区别是，数组所包含值的标识符是 `T` 而不是硬编码的原始类型。

在几乎每个程序中，你都会遇到至少一段使用泛型数据类型的代码。这在你处理 Web 应用程序时尤为真实。Web 应用程序使用 `Lists` 和 `集合`，因此你在大多数 Web 应用程序中将需要处理这些泛型列表。

## 创建你自己的泛型类型

.NET 语言有它们自己可以使用的泛型数据类型，但你应该了解如何创建自己的泛型类。当你无法使用通用列表，并想要使用预制 .NET 库中找不到的自定义方法创建自己的类时，创建类是非常重要的。

当你创建一个自己的泛型类型时，你实际上创建了一个自定义类。让我们来看一个接受泛型类型的简单类。

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
}
```

在上面的代码中，我们创建了一个名为 `MyGeneric` 的泛型自定义类。注意 `>` 和 `<` 之间的 `T` 数据类型。这告诉编译器你想传递一个泛型类型。你可以传递自定义类，也可以传递像 `string` 这样的原始数据类型。这就是 `T` 符号在任何类中的意义。它允许你处理任何数据类型，而不会受到定义数组对类所加的限制。

注意该类的其他部分与我们之前创建的其他类相似。构造函数接收我们正在创建的泛型数组的大小，以便代码可以分配正确的内存空间。由于数据类型是泛型的，我们在 `MyGeneric` 数据类型内部创建了一个私有数组。通过 `T[]` 标记，我们可以在数组中存储任何数据类型。

泛型类创建完成后，我们现在需要一种在类内获取和设置项目的方法。由于我们在创建自己的泛型自定义类，我们需要创建这些方法。首先，让我们创建一个向泛型数组添加值的方法。

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
    public void setItem(int index, T value)
    {
        array[index] = value;
    }
}
```



注意我们向 `MyGeneric` 类添加了一个方法。我们保留了相同的属性和构造函数。我们添加了 `setItem` 方法。记住，方法是类的“动词”，所以这个方法向数组添加一个值。它接收数组的索引以标识你想放置值的位置，并使用 `T` 标记告诉编译器可以使用任何泛型数据类型。然后 `setItem` 方法将泛型数据类型分配给数组中的位置。

设置好 `setItem` 方法后，你现在需要从数组中检索值。让我们来看 `MyGeneric` 类中的新方法，它可以允许你从泛型数组中检索值。

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
    public T getItem(int index)
    {
        return array[index];
    }
    public void setItem(int index, T value)
    {
        array[index] = value;
    }
}
```

这是一个可以使用泛型工作的完整类。我们添加了从数组中检索信息的 `getItem` 方法。这就是你可以在程序中创建的泛型类的完成。

## 写入文件

你需要知道的文件操作中最简单且最常用的方法之一是读取其数据。你读取数据出于很多原因，包括导入数据、导入用户偏好、导入表格数据以存储在数据库中，以及其他许多原因。你可以读取预定义的格式化数据，例如逗号分隔的文件或存储其中的纯文本文件。

C# 语言和 .NET 库框架使得将数据存储在文件中比其他语言要简单得多。.NET 语言包含了 `FileStream` 类，它可以帮助你写入文件。它需要几个参数才能运行，但你只需要几行代码就能将数据写入文件。让我们来看看可以实现操作的代码。

```csharp
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.Write);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
        F.Close();
    }
}
```

上面的代码是一个名为 `Program` 的程序的类。`Main` 方法包含了将数据写入文件的代码。这是一个简单的循环，只从 1 循环到 20，并将这些数字写入文件。

第一行代码是 `FileStream` 类，被实例化并赋值给名为 `F` 的变量。第一个参数是你想要存储数据的文件。我们只是简单将数据存储在名为 `test.txt` 的文件中。由于我们没有指定位置，文件将直接存储在程序运行的目录中。

下一个参数是文件模式。`FileMode` 是我们在书中之前见过的一个枚举。该枚举有几种文件模式，可以在创建文件或仅读取文件时使用。在示例中，我们使用了 `OpenOrCreate`。这种文件模式告诉编译器打开文件，但如果文件尚未创建或未找到，则在从其读取之前创建文件。

第三个枚举是 `FileAccess` 枚举。你可以从文件读取、写入文件，或者同时读取和写入文件。因为我们只想写入文件，所以我们需要指定我们只想写入文件。你可以将文件访问设置为读取和写写，但通常的标准是仅根据执行任务时所需的访问权限来设置文件访问。

代码的最后部分将数据写入文件。我们使用 `for` 循环写入从 1 到 20 的数据。注意，我们在将其写入文件之前，显式地将数值值转换为 `byte`。这样做是因为数据是写入文件的，而不是原始数据写入。在将数据写入文件之前，你需要将你的数据转换为 `byte`。在程序中向文件写入自己的数据时，请记住这一点。

我们使用 `WriteByte` 方法将数据写入文件。最后使用的一行代码是 `Close` 方法。如果你不关闭文件，在重启系统之前，你将无法在后续操作中使用它。操作系统会在你打开文件时对文件加锁。你只能以只读模式访问该文件。为了避免这种情况，你需要在代码中每个打开文件的部分都关闭文件。你也无法在任何其他程序中打开它，因此请确保在打开文件的方法的最后始终使用 `Close` 方法。

多线程允许你同时运行多个操作。当你需要处理数据时，多线程可以返回结果。当你有大量数据需要处理时，用户不需要等待。

多线程允许用户在程序完成之前执行任何操作。这是一种创建线程的易用方法。多线程会创建包含代码的线程。

### 在你的 C# 程序中创建线程

一旦你确定程序中需要多线程，你首先需要创建一个包含代码的函数。首先，让我们看看你用于创建线程的代码。

```csharp
class ThreadExample
{
    static void Main(string[] args)
    {
        Thread th = Thread.CurrentThread;
        th.Name = "My Thread";
        Console.WriteLine("这是 {0}", th.Name);
    }
}
```



在上面的代码中，我们创建了一个名为 `My thread` 的新线程。`Thread` 类用于实例化新线程并将其赋值给变量。在创建线程并赋值给 `th` 变量后，我们将线程名称输出到控制台。这只是为了测试我们的代码并确保线程已实际创建。

上面的代码创建了初始线程变量，但我们还没有为线程分配任何值，因此我们还没有真正创建一个多线程应用程序。

让我们看看你可以用于实际创建多线程应用程序的代码，而不仅仅是创建一个线程。

```csharp
class MultithreadedProgram
{
    public static void SecondThread()
    {
        Console.WriteLine("子线程启动");
    }
    static void Main(string[] args)
    {
        ThreadStart childref = new ThreadStart(SecondThread);
        Console.WriteLine("在 Main 方法中：创建子线程");
        Thread childThread = new Thread(childref);
        childThread.Start();
    }
}
```

在上面的代码中，我们创建一个新线程并将其赋值给辅助线程。辅助线程被命名为 `childref`，因此很容易与主线程区分开来。注意 `childThread.Start()` 开始了执行。

```cs
childThread.Start();
childThread.Abort();
}
```

注意，我们添加了一行调用 `Abort` 方法的新代码。一旦完成对该线程的操作，此方法就会销毁该线程。

多线程并不是所有程序都需要的，但当你需要创建创建更好的性能时，它非常有帮助。特别是当你有大量数据需要处理，而不强制用户等待直到进程完成时，它尤为有用。

**目标：** 多态是一种根据用户输入创建不同响应的方法。本章涵盖 C# 中的多态。

多态是程序员创建动态应用程序的强大工具。多态将你的应用程序提升到了新的高度，无论是创建动态应用程序还是提升你的个人代码。多态在 OOP 中也是常见的，当你处理他人的代码时，应该能够识别出多态，因此我们将向你展示如何在自己的程序中使用它。

## 为什么要使用多态？

当程序员初接触 OOP 时，可能很难识别何时该使用多态。我们讨论了 OOP 的一些类方法和属性。我们可以使用相同的 `Animal` 类、`Lion` 类和 `Bird` 类，这些在之前的章节中讨论过。

你可以通过两种方法创建多态类：函数重载 `function overloading` 和运算符重载 `operator overloading`。这是你在创建 C# 项目时看到的最常见方法。

你也可以通过类方法使用多态。再次使用 `animal` 类示例：每种动物都以某种方式说话，但它们说话的方式不同。鸟叫，狮子吼。你可以使用函数重载来指定从不同动物那里听到什么类型的语音。

每当你有一个定义程序的模糊基类时，你可能都需要多态来重写参数和函数，以更好地描述子类的特征。

## 重写函数

当你从主类继承方法时，可以重载这些函数以创建一个动态程序。重写函数是在派生父类的子类中完成的。

回到 `Animal` 类。我们知道每种动物必须以某种方式说话，因此我们在抽象类中创建了一个 `Speak` 方法。由于所有动物说话的方式并不相同，我们需要重写抽象类的 `Speak` 方法，以为我们自己的子类类进行定制。让我们看下代码示例：

在上面的代码中，你可以看到创建了一个 `Animal` 类。记住，抽象类不能实例化，所以你必须派生一个可以实例化的子类，否则抽象类对你的程序将毫无用。我们创建一个抽象 `Animal` 类，其中包含名为 `Speak` 的方法供所有动物使用。我们没有为抽象 `Animal` 类编写构造函数，因为该类无法实例化。构造函数用于实例化，因此在抽象 `Animal` 类中添加构造函数没有意义。

## 重载类

重载 `Overloading` 与重写 `Overriding` 相似，但有明显的区别。重写是在子类中完成的，且方法代码中带有重写关键字。而在重载方法中，你在你自己的类中创建这些方法，因此它的工作方式与重写不同。让我们看看在上一节中创建的 `Lion` 类的一个重载方法：

```cs
abstract class Animal
{
    public abstract void Speak()
    {
        Console.WriteLine("Animals say Hello");
    }
}
```

```csharp
Console.WriteLine("Animals say Hello");
);
class Lion: Animal
{
    public Lion ()
    {
    }
    public override void Speak()
    {
        Console.WriteLine("A lion roars");
    }
    public override void Speak ( string gender)
    {
        if ( gender == "male")
        {
            Console.WriteLine("The female lion purrs.");
        } else {
            Console.WriteLine("The male lion roars.");
        }
    }
}
```

注意我们现在已经在 `Lion` 类中添加了第二个方法。注意此方法的名字与我们的另一个 `Speak` 方法相同，但新方法接收一个 `gender` 参数。这个参数将不带任何参数的主 `Speak` 方法与这个接收 `gender` 参数的新方法区分开。这被称为**方法重载** `overloading`，它是为你的程序创建动态类的一种完全合法的方法。

对于基础编程，你知道你可以为两个方法命名相同的名称，但你唯一需要更改的是参数的数量或参数所接收的数据类型。这产生了编译器可以理解的区分。因此，当编译器尝试编译你的代码时，不会返回错误。

让我们来看调用你新重载方法的代码以及在你调用它们后返回的结果。

```csharp
static void Main(string[] args)
{
    Lion l1 = new Lion();
    l1.Speak();
    l1.Speak("male");
}
```

上述代码的结果产生了如下输出：

Animals say hello.
Male lions roar.

编译器能够理解并区分这种差异，因为每个方法使用的参数数量不同。第一个没有参数，而第二个有一个 `string` 类型参数。

## 错误处理

**目标：** 在部署应用程序之前，你需要修复任何 bug。本章侧重于调试以及你在部署给用户和生产环境之前如何测试你的应用程序。

## 使用 Visual Studio 调试器

如所述，你需要 Visual Studio 代码编辑器来创建和编译 C# 代码。Visual Studio 包含一个调试器，你可以用它来逐行执行代码。与没有良好编程 IDE 的其他语言相比，使用 C# 的优势之一是 C# 允许你逐行执行每一行代码，然后你可以在执行这些行时观察变量的值。

调试器中的变量监视窗口 `Watch List` 对于这一过程非常重要，因为它让你能够实时查看变量的值。如果没有这个工具，你在执行代码时只能猜测变量的值。监视窗口让你在执行代码时查看变量的值。它是识别变量是否被赋予错误值的绝佳方法由于逻辑错误发生在运行时，这对你的调试过程非常有用。

## C# 中的 Try Catch 语句

对于错误处理，任何 .NET 语言 包括 C# 和 VB.NET 的主要组件都是 `try-catch` 语句。该语句允许你捕获错误并执行一个处理用户错误的友好的函数。你不想为用户创建不友好、混乱的错误。在某些情况下，这些错误会给应用程序带来安全问题。处理不当的错误可能会显示信息，在某些情况下，它们可能会显示用于破解你服务器的密码和用户信息——这些是你不想向互联网公开的。解决此问题的方案是捕获错误并显示友好的信息，告诉用户如何处理错误而不会让他们感到沮丧。

让我们先看看创建 `try-catch` 语句的模板。我们为你创建了一个可以遵循的基础模板。

```csharp
try
{
  // 导致异常的语句
}
catch(ExceptionName e1)
{
  // 错误处理代码
}
catch(ExceptionName e2)
{
  // 错误处理代码
}
catch(ExceptionName eN)
{
  // 错误处理代码
}
finally
{
  // 将执行的语句
}
```

在上面的代码中，我们首先声明 `try` 语句。这表示你正在开始 `try-catch` 语句。

`try-catch` 语句中的每个 `catch` 语句捕获不同类型的错误。如果你不知道应该遇到什么类型的错误，语句的语句可能会很难，但你应该创建捕获任何类型错误的 `catch` 语句。当编译器捕获到这些类型的语句时，它们将进入 `catch` 语句块，这就是你创建处理你遇到的错误的自定义代码的地方。

当你编写代码时，请记住，用户发现的错误可能是你浏览代码时可能无法发现的。你需要考虑任何编码错误的可能性，包括任何逻辑错误，因此请确保在你的 `try catch` 结构中捕获 trap 任何可能的错误。

我们展示的最后一个语句是 `finally` 语句。该语句告诉编译器在退出之前执行什么。这是你在程序结束之前运行任何类型语句的最后机会。例如，你的代码中可能有一个打开文件的语句。在语句或程序结束之前，你需要关闭该文件，以避免它被操作系统中的任何其他进程锁定。你可以使用 `finally` 语句在程序和代码结束之前关闭文件，以避免代码出现任何 bug。

为了进一步研究我们的代码，让我们仔细查看代码中的一个真实世界示例。

```csharp
public void division(int num1, int num2)
{
    try
    {
        result = num1 / num2;
    }
```



```
catch (DivideByZeroException e)
{
    Console.WriteLine("Exception caught: {0}", e);
}
finally
{
    Console.WriteLine("Result: {0}", result);
}
}
```

查看上面的代码，了解 `try catch` 语句在实际应用程序中的工作原理。

我们创建了一个除法两个数字的函数。该函数接收两个参数，用于计算两个数字的除法。正如你在数学课上回想的那样，你不能除以零。如果你的代码中没有任何类型的 `try catch` 语句，用户可能会意外发送 0 值作为分母，并导致你的代码出现错误。当你这样做而没有考虑到错误时，你的程序就会崩溃，用户也会对其功能感到沮丧。你可以通过使用 C# 语言中包含的 `try catch` 语句来克服这个问题。

如果用户为分母传递了 0 值，`catch` 代码块会捕获它并以友好的方式处理。当程序出现问题时（即使是因为用户自己的输入），这对你的用户来说是非常重要的。`catch` 语句防止了程序以不友好的方式崩溃，并以你希望在程序中使用的方式来处理错误。

在这个示例中，我们根据程序操作系统的返回的信息向用户显示错误。`catch` 块向用户显示代码中发现了错误，并显示了相关信息。此错误也是从操作系统返回的。这段代码对于调试很有用，但对于真实世界的应用可能并不理想。然而，如何处理你的编码错误取决于你。

你的 `catch` 块的最后一个部分是 `finally` 部分。请记住，当你需要最终处理任何错误并更改代码以确保程序正常关闭且不会导致程序中产生更多额外 bug 时，这就是你想要添加的代码块。

在我们的 `finally` 块中，我们打印出结果，无论是有效的结果值还是我们代码中的错误。

在你的代码中创建错误处理只需要这些。只需记住，你应该创建用户友好的错误，以避免给用户带来困惑。这一章为你提供了一个示例，但你可以使用任何适合你的程序以及你的用户所需的错误处理风格。

编程的知识和理解真的是非常伟大的，因为它是我们最接近魔法力量的东西。你可以字面上地从一个空白记事本从零开始创建一个东西，并让它执行你想做的事。无论是分析和预测股票市场的机器人，还是视频游戏，选择权掌握在你手中。

在本指南中，你学习了 C# 的基础知识。你还没有学习该语言中可以使用的所有方法，但并不是重点。本指南旨在引导你开启一段旅程，发现帮助你所需的对象和方法。
