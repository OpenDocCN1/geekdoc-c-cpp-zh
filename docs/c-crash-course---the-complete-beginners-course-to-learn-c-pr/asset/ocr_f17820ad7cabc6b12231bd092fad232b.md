# Chapter 10
Arrays

**Objective:** Arrays are variables that can contain multiple values. This chapter helps you understand how to work with arrays, and how to assign and retrieve values from them.

Arrays are a part of almost any program. They allow you to store a list of variables with the same data type in one main variable. For instance, if you want to store a list of integer values, you can store them in an array. Arrays are a bit more limited than other data types. You need to know the number of values you want to store in the array ahead of time. This is possible in some program logic, so it makes sense to use an array.

# Declaring an Array in C#

Arrays are declared bit differently than regular variables. You still must declare a data type. When you declare an array, you must define the type of variables that will be stored in the array. For instance, if you define an array as an integer, you can only store an array of integers within the variable. That's the difference between an array and other data types such as classes or structures. Once you define the variable data type, you can use only the same variable data types throughout all of your array.

Arrays store multiple variables, and each variable is given an index. The index numbers start with 0. In other words, the first value stored in the array is the index of 0. The next value has the index of 1, and the one after that has the index of 2. As you can see, each value is given the next number in the index. These index numbers are how you assign values to an array and how retrieve them in your code.
