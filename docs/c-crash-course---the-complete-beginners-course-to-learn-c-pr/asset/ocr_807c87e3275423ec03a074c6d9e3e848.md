Classes

**Objective:** In the last chapter we discussed OOP, and in this chapter we'll put those concepts to work in designing and building classes.

Classes are the main components of OOP. Classes are the objects that come together to create a complete program. They are often called objects or class objects. You can use your class objects within any area of your code provided that the class is public. In this chapter, we'll discuss how to create a class and its methods, properties, and constructors.

# ## Introduction to Classes

As we said earlier, classes define the components for your application. Before you set out to create your classes, you should draw out a design, either through diagramming or wireframes, that explains your program as a visual representation. If you forget a class and need to refactor your code, this is much more frustrating and time-consuming than just classes ahead of time through diagramming software.

Classes are the building blocks of your code structure, so as you're designing your program, you should understand each part that you'll need to create your program. Every piece should be accounted for.

A good way to design your program is to draw out your screens. For each screen, explain what it does. When you understand the way the screen works, then you can better understand the way your classes should be laid out.
