Because we first write to the file and then end it, the position of the file pointer is set to the end of the file. If we attempt to read from it at this point, we'll only get the end of the file and the program will crash. To avoid this, we can reposition the pointer to the beginning of the file. We do this by setting the Position to 0. The next for loop reads the data by byte by byte and displays it on the screen. We see that we use the ReadByte method because we read by byte from the file and display it using the Console static.

Finally, at the end of the program we need to close the file pointer. Again, if we didn't close the file, the operating system would keep a lock on it and we wouldn't be able to use it for any other purpose.

# Appending to a File

In the previous sections, we just created a file, added some content to it, and then read the file data. We just overwrite the data that could already be contained in the file. This is not the best behavior for most programs, because we need to append data to the file instead of overwriting all of it.

You can choose to append data to a file by using the same library that we used in previous sections. We just need to change the file access and modes that we used previously. Let's take a look at the code.

```
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.Append, FileAccess.ReadWrite);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
        F.Position = 0;
    }
}
```
