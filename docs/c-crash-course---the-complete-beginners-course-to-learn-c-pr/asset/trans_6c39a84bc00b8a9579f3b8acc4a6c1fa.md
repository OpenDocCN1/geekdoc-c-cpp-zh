
乘法变量的工作原理相同。乘法运算符的语法与我们看过的其他运算符相同。下面的代码是乘法运算符的示例。

```
int myNumber = 3;
addedNumber = myNumber * 4;
```

我们对代码唯一的更改是星号符号 `*`，它用于指定你想将一个变量乘以另一个变量。我们将 `myNumber` 乘以 4，因此结果是 12，存储在 `addedNumber` 变量中。

我们可以使用的最后一个简单运算符是除法运算符。除法运算符的工作方式与其他运算符相同。让我们来看除法运算符的示例。

```
int myNumber = 3;
float addedNumber = myNumber / 4;
```

同样，我们做的更改是除法运算符。我们将 3 除以 4，结果是 .75。请注意，我们需要将 `addedNumber` 改为 `float` 数据类型，因为除法计算的结果是一个小数值。当你进行除法计算时，你通常希望使用 `float` 数据类型以避免代码中的错误，即使你确定每个结果都将整数。

现在我们已经看了简单运算符，可以转向那些较不为人知的运算符了。第一个是取模运算符（模运算）。取模运算符执行除法计算，但它返回的不是减去余数的结果，而是余数。让我们来看一个示例。

```
int myNumber = 4;
float addedNumber = myNumber % 3;
```

在上面的示例中，除法计算是 4 除以 3。结果是 3 进 4 一，余数为 1。因此，`addedNumber` 变量包含值 1。在使用取模运算符时记住这一点，否则你可能会得到不同的结果。

下一个运算符是递增操作。你会经常使用这个运算符，特别是在循环中——我们将在后面的章节中介绍。递增运算符将变量加 1。该运算符是变量加 1 的简写。让我们来看一个示例。

```
int j = 0;
j++;
```

上面的代码与下面的代码相同。

```
int j = 0;
j = j + 1;
```

注意，之前的版本的代码要短得多且更容易阅读。结果只是给变量 `j` 加上了 1。在这个示例中，结果是 `j` 等于 1。

你也可以以相同的方式递减变量。让我们来看递减运算符。

```
int j = 0;
j--;
```

注意，我们只是把加号替换成了减号。结果是变量 `j` 递减了 1。上面的代码与下面的代码相同。

```
int j = 0;
j = j - 1;
```

结果是变量 `j` 包含值 -1。

上面的运算符都是你在整个 C# 代码中将使用的运算符。这些计算在任何 C# 程序中都是常见的。

# 关系运算符

关系运算符用于我们将在后续章节中讨论的循环和条件。关系运算符在两个值（静态或动态变量）之间进行比较。在本节中，我们将介绍不同的运算符。

在许多情况下，你需要确保两个变量彼此相等。关系运算符用于 `if` 条件中，我们将使用 `if` 语法——但请知道，此操作的完整覆盖将在后面的章节中介绍。

让我们先来看相等运算符。

```
int myNumber1 = 1;
 myNumber2 = 2;
if ( myNumber1 == myNumber2)
{
  //如果条件成立，则执行这些操作
}
```

在上面的代码中，我们创建了名为 `myNumber1` 和 `myNumber2` 的两个变量，并将它们初始化为 1 和 2。显然，这两个值不相等，`if` 条件中的关系运算符返回 `false`。由于结果为 `false`，`if` 条件内部的语句不会执行。记住，如果关系运算符的结果为 `false`，则 `if` 语句括号内的任何内容都不会执行，代码执行将跳转到条件下方的任何代码。

就像相等运算符一样，你也可以识别两个变量是否不相等。使用相同的语法，让我们来看示例。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 != myNumber2)
{
//如果条件成立，则执行这些操作
}
```

我们将关系运算符更改为 `!=` 或“不等于”。在这个条件中，计算结果为 `false`，所以这次 `if` 条件内的任何语句都将被执行。

你还需要确定一个值是否大于或小于另一个变量。C# 也有这些关系运算符来为你提供这两个条件。让我们来看大于关系运算符。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 > myNumber2)
{
//如果条件成立，则执行这些操作
}
```

我们使用了相同的语法，只需将关系运算符切换为大于符号即可。在这个示例中，计算结果为 `false`，所以没有任何 `if` 语句被执行。

与大于运算符类似，让我们来看小于语句。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2)
{
//如果条件成立，则执行这些操作
}
```

在上面的语句中，`myNumber1` 确实小于 `myNumber2`，因此计算结果为 `true`。在这个示例中，`if` 语句括号内的语句将执行。

在之前的操作中，变量要么大于要么小于，但如果你想知道该值是否相等呢？你可以将大于和小于运算符与相等运算符结合，以检查两种条件。让我们来看大于等于运算符。

```
int myNumber1 = 1;
int myNumber2 >= myNumber1
//如果条件成立，则执行这些操作
```

在上面的语句中，没有任何条件是真实的。两个变量不相等，且 `myNumber1` 不大于 `myNumber2`。因此，没有任何 `if` 语句将执行。现在让我们来看小于等于语句。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 <= myNumber2)
{
//如果条件成立，则执行这些操作
```

# 逻辑运算符

逻辑运算符允许你在语句中组合条件。你可以通过评估两个条件来控制执行流。有三个逻辑运算符：`&&`（与）、`||`（或）和 `!`（非）。

让我们首先使用上一节中使用的 `if` 条件来看 `&&` 运算符。

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2 && myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

在上面的语句中，我们首先评估 `myNumber1` 是否小于 `myNumber2`。在这个示例中，结果为 `true`，但我们添加了 `&&` 逻辑运算符，所以语句在确定执行流之前必须评估第二个条件。第二个条件评估 `myNumber1` 是否等于 2。这个条件的结果为 `false`。因为我们使用了“与”，两个条件都为真时语句才会执行。由于其中之一为 `false`，`if` 语句不执行。

让我们使用相同的值但将逻辑运算符更改为或（`||`）。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 < myNumber2 || myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

最后一个逻辑运算符是非（`!` 操作。非运算符改变条件的逻辑。让我们来看一些代码。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (!myNumber1 == 2)
{
//如果条件成立，则执行这些操作
}
```

在上面的代码中，我们不是在评估条件是否为真，而是识别条件是否为假。因为有非运算符，你知道我们正在评估为 `false`。这个运算符有点让人困惑，但由于表达式计算结果为 `true`，非运算符将条件更改为 `false`。由于条件为 `false`，`if` 语句执行。
