# The Numeric Data Types in C#

C# offers several data types that you can use to store and calculate values. The two main numeric values are decimals and integers. Integers are values that have no decimal point value. They can be signed or unsigned. A signed integer is a negative value, which means that the signed part is the negative notation and the number is. An unsigned integer is a positive value that has no plus sign. It's automatically assumed to be a positive value.

Decimal values have several data types in C# depending on the number of precision points you want to use. The smallest decimal value is a float data type. The largest is the decimal data type. A decimal point allows you to store up to a 128-bit number in your variable.

First, let's take a look at an integer data declaration.

```
int myNumber = 22;
```

Notice the declaration to declare an integer is the same template and syntax that we used with a string variable. All variable declarations follow the same template syntax, so you can expect each declaration to follow this syntax when you write your code.

We defined our variable named myNumber with the int data type. It's the shortened version of the integer specifier. An integer stores a 32 bit number, but you can lengthen your integer storage to 64 bit using the long data type. Let's take a look at the long variable declaration.

```
long myNumber = 222222;
```

We used a longer integer value in the above statement to show that you can use longer numbers when you use the long data type.
