The final optional rule for variables is that you can define the variable and give it a value at the same time you declare it. Let's take a look at the syntax template.

```
<datatype><variable name> = value;
```

Again, assigning a value is optional, but the above syntax is how you assign a value at the same time you declare the variable. Remember that the value must match the data type you use. For instance, if you attempt to assign a string character to an integer data type variable, the compiler will give you an error.

# The String Data Type

In any program, you'll work with strings. Strings are the variables that contain words. These words can be any alphanumeric character or even special characters. Most user input data is in the form of a string, but then you can convert that to another data type. For instance, you might ask for a number for user input but then convert the number to an integer to perform some type of calculation using the input.

Let's look at an example at a string variable.

```
string myName = "John";
```

Notice that the string data type is first used to define the string variable. This is a primitive string data type. The data type "String" is a class definition and is only used if you need to perform complex string functions on a variable. For the most part, you will use the primitive string variable definition when you set up your variables.

The next item in the statement is the variable name. We've used camel case, with the first letter in the variable name set in lowercase. The next names use a capital letter.

In this statement, we assign a value to the variable in the definition. We assign the value "John" to the variableName. Notice that the end of the statement terminates with a semicolon. This tells the compiler that the end of the statement has been met. If we forget the semicolon in this statement, the next statement would cause a syntax error.

You can also declare a string variable with no value. We can use the same statement to illustrate how to define variables with no value.

```
string myName;
```
