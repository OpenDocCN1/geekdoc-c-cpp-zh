When you create classes, you'll need at least one property, and you'll probably have at least one method in the class. Classes can be small, with only one line of code, or you can have very large classes that define a large portion of your program. Just remember that classes are scalable, so you should always create a class for each section of your program to ensure that it is scalable when you need more functionality in the future.
