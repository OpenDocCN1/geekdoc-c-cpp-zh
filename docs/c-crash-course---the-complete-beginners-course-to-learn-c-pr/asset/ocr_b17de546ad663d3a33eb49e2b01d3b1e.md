Let's use the same values but change the logical operator to or (||).

int myNumber1 = 1;

if (myNumber1 < myNumber2 || myNumber1 == 2)

Using the or completely changes the way the if statement executes. In the above condition, the first condition calculates to true, but the next condition calculates to false. The or statement says that either the first or the second statement can evaluate to true for the if statement to execute. Since the first statement executes to true, the if will execute.

int myNumber1 = 1;

if (!myNumber1 == 2))

In the above code, instead of evaluating if the condition is true, we identify if the condition is false. You know that we're evaluating to false because of the not operator. This operator is a bit more confusing, but since the expression calculates to true, the not operator changes the condition to false.
