The only change we've made to the code is the asterisk symbol, which is used to specify that you want to multiply one variable by another. We've multiplied myNumber by 4, so the result is 12, stored in the addedNumber variable.

The final simple operator we can use is the division operator. The division operator works in the same way as the others. Let's take a look at an example of the division operator.

Now that we've looked at the simple operators, we can move on to the lesser known ones. The first one is the modulus operator. The modulus operator performs a division calculation, but instead of returning the result minus the remainder, the modulus operator returns the remainder. Let's take a look at an example.

```
int myNumber = 4;
float addedNumber = myNumber % 3;
```

In the above example, the division calculation is 4 divided by 3. The result is that 3 goes into 4 with a remainder of 1. Therefore, the addedNumber variable contains the value of 1. Remember this when you use the modulus operator or you could expect a different result.

The next operator is the increment operation. You'll use this operator often, especially with loops—which we'll cover in future chapters. The increment operator adds 1 to a variable. The operator is shorthand for adding 1 to a variable. Let's take a look at an example.

```
int j = 0;
j++;
```

The above code is the same as the following code.

```
int j = 0;
j = j + 1;
```

Notice that the previous version of the code is much shorter and easier to read. The result is just adding 1 to the j variable. In this example, the result is that j is equal to 1.

You can also decrement a variable in the same way. Let's take a look at the decrement operator.

```
int j = 0;
j--;
```

Notice that we just replaced the plus signs with minus signs. The result is that we decrement the j variable by 1. The above code is the same as the following code.

```
int j = 0;
j = j - 1;
```

The result is that the j variable contains the value -1.

The above operators are all of the ones that you'll use throughout your C# code. These calculations are common to any C# program.

# Logical Operators

Logical operators let you combine conditions in your statements. You can control the flow of execution using logical operators by evaluating two conditions. There are three logical operators: && (and), || (or), and ! (not).

Let's first look at the && operator using the same if conditions we used in the previous section.

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2 && myNumber1 == 2)
{
// if condition equals yes, then do these operations
}
```

In the above statement, we first evaluate if myNumber1 is less than myNumber 2. In this example, the result is equal to true, but we've added the (&&) logical operator, so if the statement must evaluate the second condition before it can determine statement flow. The second condition evaluates if myNumber1 is equal to 2. This condition has a result of false. Because we used the and, both conditions must be true for the statement to execute. Since one of them equals false, the if statement does not execute.

Let's use the same values but change the logical operator to or (||).

```
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 < myNumber2 || myNumber1 == 2)
{
// if condition equals yes, then do these operations
}
```

The final logical operator is the not (!) ) operation. The not operator changes the logic of the condition. Let's take a look at some code.

```
int myNumber1 = 1;
int myNumber2 = 2;
if (!myNumber1 == 2))
{
// if condition equals yes, then do these operations
}
```

In the above code, instead of evaluating if the condition is true, we identify if the condition is false. You know that we're evaluating to false because of the not operator. This operator is a bit more confusing, but since the expression calculates to true, the not operator changes the condition to false. Since the condition calculates to false, the if statement executes.
