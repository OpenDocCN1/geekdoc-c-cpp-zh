# Using Properties

Class methods are the verbs and properties are the nouns. Any attributes that you want to place on your classes are done through properties. Class properties define the “look” of your classes. For instance, a first and last name is a property of the Customer class. It’s an attribute of your customers.

Let’s take a look at our current Customer class properties.

```
public class Customer
{
    public Customer () { {}
    public void ChangePhone (string new_phone)
    {
        this.phone = new_phone;
    }
    public string first_name;
    public string last_name;
    public string phone;
}
```

The above Customer class has three properties. The first name, last name, and phone variables are all properties of the Customer class.

You can add any number of properties to your class. You can add another string property named address to record your customer addresses. Let’s take a look at an example.

```
public class Customer
{
    public Customer () { {}
    public void ChangePhone (string new_phone)
    {
        this.phone = new_phone;
    }
    public string first_name;
    public string last_name;
    public string phone;
    public string address;
}
```

Just remember that all properties are the nouns, or attributes, that describe your class attributes, and methods are the verbs that perform actions on your classes and their data.
