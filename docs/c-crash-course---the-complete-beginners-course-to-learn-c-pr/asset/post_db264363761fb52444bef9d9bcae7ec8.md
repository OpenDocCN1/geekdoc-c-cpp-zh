Let's first take a look at a basic class that describes a customer. Most applications need to include the concept of a customer as one component of the application. Let's take a look at a Customer class that contains the customer's address and last and first name properties.

# Creating Class Constructors

Classes are the building blocks for your programs, and constructors are the scaffolding that hold the classes together. Constructors are what allow you to instantiate the classes throughout the lifetime of your program. You can set specifiers on your constructors, but they must always be the same name as the class, and they should never have a return type.

```csharp
public class Customer
{

        public string last_name;
        public string phone;
    }
```

The constructor is the first line of code in the class definition. Notice that the method name is the same as the class name, because C# is case-sensitive. The constructor is built just like any other method. The constructor has parentheses that can take a parameter if you want to. In this example, we don't have any parameters for the constructor, and no code is executed when the class is instantiated. Let's take a look at a class that takes parameters and then initializes some code.

```csharp
public class Customer
{
    public Customer (string first_name)
    {
        this.first_name = first_name;
    }
    public string first_name;
    public string last_name;
    public string phone;
}
```

In the above snippet, we added more code to the constructor. First, we added a parameter to our constructor. The only way you can instantiate the class now is if you pass something to it. The code within the constructor sets the local property to the value passed to the constructor. In this example, the first name is passed to the constructor and then the value is assigned to the local variable. You know that the local variable is used because of the "this" notation. The "this" specifier means that you want to use a local variable within the class.

You can have multiple constructors within a class. You could give users the option to use a constructor that doesn't require a parameter along with one that requires a first name. The following code illustrates how you can do this:

public class Customer

In the above class code, you now have the option to instantiate with no parameters or with the constructor that automatically assigns the first name to the class property. Using this is a shortcut.

# Creating Methods in Your Code

Methods are the actions that your classes perform on the program's data. Methods are basically functions within your classes. They are also called the "verbs" of your classes. Whenever action is taken against a class, you use a method. It could be a customer changing a phone number (you would then create a ChangePhoneNumber method or removing a product from inventory (this would be a method named "DecrementInventory" in your Product class).

The location of your methods is dependent on your class design that you set up when you create your program architecture. Regardless of your method name, notice the important part of your design is where the method is located. You always place a method in the appropriate class. For instance, you wouldn't put the method DecrementInventory in the Customer class because it's not related to anything that has to do with customers. Poorly designed code can have a negative effect on your application architecture.

Let's take a look at a method within a class. We mentioned a class method that allows a user to change a phone number. Let's take a look at what an example method would look like in a customer class:

```csharp
public class Customer {
  public Customer () { }
  public void ChangePhone(string new_phone) {
    this.phone = new_phone;
  }
  public string first_name;
  public string last_name;
  public string phone;
}
```

We added a ChangePhone method to the Customer class. If you notice, this method takes a new_phone variable. This variable takes the phone number for the customer and assigns it to the local property. Notice again that we use this designation to specify that we want to assign the local class variable and not any other variable. This is especially important when you assign a local variable to a global class variable and both of them have the same name, just as we've illustrated in the above code.

Notice that we added the void specifier as well. You specify what type of value is returned by a method. In this example, nothing is returned, so the specifier is set to void. If we returned, for instance, a string value, we would specify a string return type instead of the void keyword.

Also notice that we set the method to public. This means that any other parts of your code can use the method regardless of whether it's a child class.
