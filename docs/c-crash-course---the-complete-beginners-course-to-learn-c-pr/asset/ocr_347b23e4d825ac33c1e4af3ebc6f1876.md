Sometimes you want to make a thread sleep. The first thread should sleep for a few seconds before the second thread begins to run. You can use the Sleep method to make this happen. The Sleep method pauses one thread for the given amount of time without affecting any of the other threads. Let's take a look at the code.

```
class MultithreadedProgram
{
    public static void SecondThread()
    {
        Console.WriteLine("Child thread starts");
    }

    static void Main(string[] args)
    {
        ThreadStart childref = new ThreadStart(SecondThread);
        Console.WriteLine("In Main: Creating the Child thread");
        Thread childThread = new Thread(childref);
        childThread.Sleep(5000);
        childThread.Start();
    }
}
```

Notice that we added another line of code in this program. We added a Sleep method to the code. We are pausing the thread for 5000 milliseconds. Notice that the time is set in millis. It's important to realize that the time is in milliseconds for most coding programs, so 5000 milliseconds are only 5 seconds. This means that the child thread will wait for 5 seconds while any other threads are running.

You can also pause your thread in the main function that's linked to your thread. Let's take a look at the code.

```
class MultithreadedProgram
{
    public static void SecondaryThread()
    {
        Console.WriteLine("Child thread starts");

        // the thread is paused for 5000 milliseconds
        int sleepfor = 5000;

        Console.WriteLine("Child Thread Paused for {0} seconds", sleepfor / 1000);
    }\}
```
