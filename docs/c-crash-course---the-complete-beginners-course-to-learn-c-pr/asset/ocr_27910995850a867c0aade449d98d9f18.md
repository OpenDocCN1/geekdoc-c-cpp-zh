# Retrieve Values from an Array

Once you assign values to an array, you need to know how to retrieve values from an array as well. In some cases, you fill an array with values that you later need to display to a user. You can use the cumbersome way of retrieving values that we showed in the previous section, or you can use a for loop again. A for loop makes it much easier to retrieve values than it would be by defining the variables you want to retrieve by one.

Let's take a look at what the code looks like with a for loop.

```
int[] myNumbers;
for (int j = 0; j < 10; j++)
{
    myNumbers[ j ] = j;
}
```

```
// now you can display the values
for (int j = 0; j < 10; j++)
{
    Console.WriteLine(myNumbers [j]);
}
```

In the first section of the above code, we defined the array and assigned the array values. In the second for loop, we iterated through each array index and displayed the value of the index values. Notice that again we used the j variable to iterate through each index. Just one line of code is needed as opposed to using the static index variables force you to use several lines of code instead.
