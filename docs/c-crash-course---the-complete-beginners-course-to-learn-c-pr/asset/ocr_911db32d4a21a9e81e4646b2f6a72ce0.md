```
j++;
}
```

Notice using a while loop requires a lot more code. This is one reason they aren’t preferred over a for loop. We first define two variables that we’ll use to control the loop. The while loop is then initiated with its condition. The condition is set to always loop as long as the loop variable is equal to true. Since it's initialized to true, the while loop will iterate at least once.

Within the while loop, we have several statements. The first statement prints out the value of j. The next statement is an if statement that identifies the value of j. If j has reached the value of 5, the if statement flips the loop variable to false, so the evaluation of the stop condition will exit the loop. Finally, the last statement adds 1 to j. Because the while loop doesn’t have an auto-increment variable, you must remember to add your own to the while loop to avoid infinite loops. Infinite loops freeze and crash your program because they never end.

You’ll have to determine which loop is better for your program. You’ll probably use more than one throughout the code, but usually one is better for the execution of your code than the other.
