```
abstract class Animal
{
    public abstract void Speak
(
        Console.WriteLine("Animals say Hello");
    )
}
class Lion: Animal
{
    public Lion ()
    {
    public override void Speak ()
{
        Console.WriteLine("A lion roars");
    }
}
```

Notice that our Lion class has a constructor, because we want to be able to instantiate this class to define a Lion in our program. We then create a Speak method that overrides the Speak method. When the Speak method is called in your program from the Lion class, the overridden method is called. Let’s look at how you call the Lion class and what is printed when you’ve finished.

```
static void Main(string[] args)
{
    Lion l = new Lion();
    l.Speak();
}
```

In the above Main method, we instantiate the Lion class and call the Speak method. Since the Lion class overrides the parent Animal class Speak method, the code returns the phrase “A lion roars” to the user.
