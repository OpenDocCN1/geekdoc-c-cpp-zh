The above code creates the initial thread variable, but we haven't actually assigned any values to the thread, so we still haven't created a multithreaded application.

Let's take a look at the code that you can use to actually create a multithreaded application instead of just creating a thread.

```
class MultithreadedProgram
{
    public static void SecondThread()
    {
        Console.WriteLine("Child thread starts");
    }

    static void Main(string[] args)
    {
        ThreadStart childref = new ThreadStart(SecondThread);
        Console.WriteLine("In Main: Creating the Child thread");
        Thread childThread = new Thread(childref);
        childThread.Start();
    }
}
```

In the code above, we create a new thread and assign it to a secondary thread. The secondary thread is given the name childref, so it's easily distinguishable from the main thread. Notice that we've created a method that contains the code needed to run in the second thread. We named the second thread function SecondThread.

The created thread is done through the library called ThreadStart. ThreadStart is assigned to the Thread class variable named childThread. This assigns the function to another thread. Finally, we start the thread with the Start method. This officially starts the second thread, so you can run it separately from the main thread.
