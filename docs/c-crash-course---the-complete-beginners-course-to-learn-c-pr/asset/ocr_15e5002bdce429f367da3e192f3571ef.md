result of the above statement is that “The variable equals the value of 1” is displayed on the console.

# The Switch Statement

The final conditional statement is the switch statement. The switch statement is similar to the if statement, but it evaluates one variable for multiple conditions. Let’s first a look at the template for this statement.

```
switch(expression) {
  case constant-expression :
    // statement to execute
    break;
  case constant-expression :
    // statement to execute
    break;
  default :
    // statement to execute
}
```

With this statement, the variable is set in the switch expression, and then each case statement determines if the variable equals that value. Let’s take a look at the switch statement in action.

```
int myNumber = 1;
switch (myNumber) {
  case: 1
    Console.WriteLine("Value is 1”);
    break;
  case: 2
    Console.WriteLine("Value is 2”);
    break;
  default:
    Console.WriteLine("Don’t know the value”);
}
```

In the above code, we evaluate the value of the variable myNumber. We initialize it to 1 and then use the case statements to go through each possible value. Because we know the value is 1, we can see that the first case statement evaluates to true, and then “Value is 1” is displayed in the console.

The default statement is similar to the else statement in an if block. If none of the case statements evaluate to true, then the default statement executes.
