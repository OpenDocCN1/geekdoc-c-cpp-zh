```
{
  private Customer() {
    public string first_name;
    public string last_name;
    public string phone;
  }
}
```

With this same class, we changed the public specifier to private. Now, the Customer class is completely hidden to other parts of the program.

Let's try to call the class like we did in the previous section. Take a look at the following code.

```
Customer cust = new Customer();
cust.first_name = "John";
Console.WriteLine(cust.first_name);
```

The above code will give you an error that the class is set to private. When you use a private class, you can only use it within its own compartment. Most classes are not set to private, because they can't be used anywhere else in the program.

# Setting Classes as Protected

The last specifier that's important is the protected specifier. This one isn't used much, but it's still used occasionally. Protected classes only allow the current class or any child classes to use properties and methods.

We'll get into deriving classes from parent classes and using child classes to expand a parent class. Just remember that with a protected class, only the child class can use its methods and properties when you design your program.
