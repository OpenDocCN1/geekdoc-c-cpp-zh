## Chapter 13
Multithreading

**Objective:** Multithreading lets you run multiple processes at the same time within a CPU. This chapter shows you how to set up multiple threads in a C# program.

When you perform an action such as a loop in your program, the operating system waits until this action is completed before it moves to the next process. If you only have such as ten loops to move through, this doesn't take much time at all. However, if you have a thousand or even a million loops to iterate through, it could take several seconds or even minutes before the loop is finished. This means that your user must wait until the process is finished before anything else can be done in your program. This chapter teaches you how to use multithreading to allow processes to run instead of waiting.

## Why to Use Multithreading

Multithreading allows you to run multiple processes at the same time. Think about your program and whether it was created for a large enterprise application. With large applications, you often process large amounts of data. When you need to process large amounts of data, you loop through each record and return the results to your user. When you have large amounts of data, your user could need to wait several minutes before they can do anything with your program. This is not a user-friendly way to create a program.

With multithreading, you can allow the user to perform any actions while still looping through the data. Multithreading creates multiple threads that contain your code. One thread would be for the main user actions and another thread for looping through the data. The user doesn't need to wait until the program is finished to complete the entire functionality of the program.

## Creating Threads in Your C# Program

Once you know that you need multithreading in any of your program, you first need to create a function that contains the code that must be contained within the threading process. First, let's take a look at the code that you use to create a thread.

```csharp
class ThreadExample
{
    static void Main(string[] args)
    {
        Thread th = Thread.CurrentThread;
        th.Name = "My Thread";
        Console.WriteLine("This is {0}", th.Name);
    }
}
```

In the code above, we created a new thread named My thread. The Thread class is what you use to instantiate a new thread and assign it to a Variable. After we create the thread and assign it to the th variable, we then write the thread name to the console. This is just to test our code and ensure that the thread was actually created.

The above code creates the initial thread variable, but we haven't actually assigned any values to the thread, so we still haven't created a multithreaded application.

Let's take a look at the code that you can use to actually create a multithreaded application instead of just creating a thread.

```csharp
class MultithreadedProgram
{
    public static void SecondThread()
    {
        Console.WriteLine("Child thread starts");
    }

    static void Main(string[] args)
    {
        ThreadStart childref = new ThreadStart(SecondThread);
        Console.WriteLine("In Main: Creating the Child thread");
        Thread childThread = new Thread(childref);
        childThread.Start();
    }
}
```

In the code above, we create a new thread and assign it to a secondary thread. The secondary thread is given the name childref, so it's easily distinguishable from the main thread. Notice that the childThread.Start() begins the execution.
