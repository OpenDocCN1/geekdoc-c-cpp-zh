```
List<Customer> myInts = new List<Customer>();

cust.last_name = "Smith";

```

Notice that we still had to initialize the customer and generic list. We added some values to the customer, and then for the loop goes through each value in the myInts generic list and displays the first name. Because we only have one value stored, we have one output value to the console.

Generic lists are a popular way to store large amounts of values regardless of their data type. You'll use generic lists often in your programming, especially if you work with C# MVC web applications.
