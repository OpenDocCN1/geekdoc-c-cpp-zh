
## Chapter 12
File I/O

**Objective:** At some point you will need to write data to files. This chapter focuses on reading and writing file data in C#.

Not all of your programs will use files, but you will run across some sites or console applications that require you to read or write from files. Most Windows applications use some kind of file I/O processes to either read or write to files to store user data or preferences. In this chapter, we'll discuss how you can read and write data to files using C#.NET framework libraries that are included with the system.

## Writing to Files

One of the easiest and most common methods you need to know with files is reading their data. You could read for a number of reasons, including importing data, importing user preferences, importing spreadsheet data to store in a database, and any other number of reasons. You can read predefined formatted data such as a comma delimited file, or a plain text file stored in it.

The C# language and the .NET library framework make storing data in a file much easier than it is with other languages. The .NET language includes the FileStream class that helps you write to a file. It takes a few parameters to get it to work, but you only need a few lines of code to write data to a file. Let's take a look at the code that can make this happen.

```csharp
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.Write);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
        F.Close();
    }
}
```

The above code is a class for a program named Program. The main method contains the code that writes data to a file. It's a simple loop that just loops from 1 to 20 and writes these numbers to the file.

The first line of code is the FileStream class, instantiated and assigned to a variable named F. The first parameter is the file where you want to store the data. We are simply storing data in a file name test.txt. Since we don't specify a location, the file is simply stored in the directory where the program runs.

The next parameter is the file mode. FileMode is an enum that we saw earlier in this book. This enum has several file modes that can be used when creating a file or just reading it. In this example, we use OpenOrCreate. This file mode tells the compiler to open the file, but if the file isn't already created or it's not found, then create the file before reading from it.

The third enum is the FileAccess enum. You can either read from a file, write to a file, or read and write to a file. Because we just want to write to a file, we need to specify that we just want to write to the file. You could set the file access to read and write, but it's generally a standard to only set file access with the access rights you need to perform a task.

The final part of the code writes the data to the file. We use a for loop to write the data from 1 to 20. Notice that we explicitly convert the numeric value to a byte before we write it to the file. This is done because data is written to files instead of raw data. You'll need to convert your data to a byte before you can write data to a file. Just remember this when you write your own data to files in your programs.

We use the WriteByte method to write data to the file. The final line of code used is the Close method. If you don't close the file, you won't be able to use it in future actions until you reboot the system. The operating system puts a lock on the file when you open it. You can only access the file in read only mode. To avoid this situation, you need to close the file in every part of your code where you open it. You won't be able to open it in any other program either, so make sure you always use the Close method at the end of your methods that open your files.

## Deleting a File

You won't only need to create and read and write to a file. There are times you'll need to delete a file as well. Frankly, the .NET framework makes it just as easy to delete a file as it does to create and work with file data.

It's even easier to delete a file than perform the other processes. You use a different class to delete a file. The FileStream library is strictly to read and write to files, but the class is a static class that does short, quick tasks to complete a process. In this case, we want to delete a file, which doesn't need any elaborate code.

Let's take a look at what the code looks like to delete a file from the hard drive.

```csharp
if(File.Exists(@"C:\test.txt"))
{
    File.Delete(@"C:\test.txt");
}
```
