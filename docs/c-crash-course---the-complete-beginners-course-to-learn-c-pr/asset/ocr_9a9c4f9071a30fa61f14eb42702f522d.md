# Constants

You don't always need to dynamically assign a value to a variable. Sometimes know that you know the value of pi is always 3.14. You don’t need to dynamically assign this value, so you can create a constant. A constant holds a static value that never changes. If you attempt to change this variable’s value, the compiler gives you an error.

You define a constant same you define a dynamic variable, except you use the const keyword as the first specifier. Let’s take a look at an example using a pi variable.

```
const decimal pi = 3.14;
```

We used the decimal data type because pi has several precision points that we can use. We won’t be able to change the value in our code, so the pi variable will remain with the value 3.14 throughout the lifetime of the program.

The const data type is used within a class to specify that the variable should have the same value throughout the lifetime of the class. The variable is destroyed when the class is destroyed in memory, but you should know that the variable’s value doesn’t change, regardless of where the variable is used in the code. Because a constant can’t have a dynamic value, you must give it a value when you define it. If you recall, assigning a value to a dynamic variable is optional.

Using data types is something you’ll use in every C# program you create. You’ll need to know how identify data types as you read other coders’ code. You might need to reference the values that can be used with each data type, but you should at least understand which ones store numbers versus strings and other data types.
