When you create a generic type of your own, you create a custom class. Let's take a look at a simple class that takes a generic type.

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
}
```

In the above code, we created a generic custom class named MyGeneric. Notice the T data type between the greater than and less characters. This indicates to the compiler that you want to pass a generic type. You could pass a custom class or pass a primitive data type such as a string. This is the significance of the T notation in any class. It allows you to work with any data type without the limitations put on your classes by defined arrays.

Notice that the other parts of the class are similar to what we've seen with other classes that we've created. The constructor takes the size of the array for the generic that we're creating so the code can allocate the right memory space. Because the data type is generic, we create an array that's private within the MyGeneric data type. With the T[] designation, we can store any data type within the array.

With the generic class created, we now need a way to get and set an item within the class. Because we're creating our own generic custom class, we need to create these methods. First, let's create the method that adds a value to the generic array.

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }

    public void setItem(int index, T value)
    {
        array[index] = value;
    }
}
```

Notice that we added one method to the MyGeneric class. We kept the same property and constructor. We added the setItem method. Remember that methods are the verbs of a class, so this method adds a value to the array. It takes the index of the array to identify where you want to place the value, and uses the T designation to tell the compiler any generic data type can be used. The setItem method then assigns the generic data type to a location in the array.

With the setItem method set, you now need to retrieve a value from the array. Let's take a look at the new method in the MyGeneric class that lets you retrieve a value from the generic array.

```csharp
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }

    public T getItem(int index)
    {
        return array[index];
    }

    public void setItem(int index, T value)
    {
        array[index] = value;
    }
}
```

This is a full class that works with generics. We added the getItem method that retrieves information from the array. This is the completion of the generic class that you can create in your program.

# Using the List Generic Class

You can create your own generic class, or use the premade generic class that is available from the .NET framework. It's much easier to use the premade classes than to create your own. You don't need to create your own unless you have specific needs for your classes that the premade generics don't offer.

There are a few generic classes available, but the most commonly used is the List generic class. The List class contains just about anything you need to do to a list. Let's first a look at how you create a list variable.

```csharp
List<int> myInts = new List<int>();
```

In the code, the primitive data type is set within the greater than and less than signs. Remember that the generic type tells you that you can send any data type, but in this example we use the integer primitive data type.

The int is passed to the generic List class to let it know that you want to store a list of integers within the array.

Since the generic List data type is still a class, you need to use the new keyword and call the base constructor. The list constructor doesn't require a parameter, so we can just use the parentheses with no data passed to the constructor.

With the variable defined and the List instantiated, we can now use its methods and properties. Let's look at the code that adds values to the variable.

```csharp
List<int> myInts = new List<int>();
myInts.Add(1);
myInts.Add(2);
myInts.Add(3);
```

Notice that it's much easier to add a value to the myInts variable. We have the Add method that we can use to add a value to the generic list. We add the numbers one, two, and three to the myInts generic list variable. That's all it takes, instead of using cumbersome code. You can also use a for loop as we used in the array chapter, but this makes it much easier to add values to your code.

Finally, you need a way to retrieve values from the generic list. Let's take a look at the code we can use to loop through each value and print the results to the screen.

```csharp
List<int> myInts = new List<int>();
myInts.Add(1);
myInts.Add(2);
myInts.Add(3);

for (int i = 0; i < myInts.Count; i++)
{
    Console.WriteLine("MyInts: {0}", myInts[i]);
}
```

In the code above, we used the same methods that we used previously, except this time we added an additional for loop to go through each myInts value and display it on the screen. Notice that you can use the for list structure to go through each of the values in a generic list just as you can with an array. In most ways, a generic list and an array work similarly.

# Using the List Class for Custom Class Structures

We used a primitive integer for the above code, but you can also store class structures in a generic list. In other words, your custom classes can be stored in the same way as you store primitive numbers in a list. For instance, if you have a Customer class that contains customer information, you might want to store ten customers, each within its own class. You then add the custom class to a generic list, so you have ten customers stored in an array. You can then loop through each of these Customer values and store them in a database. This makes it easier to add values to your code.

Let's take a look at how you create a list variable.

```csharp
List<Customer> myInts = new List<Customer>();
```

In the code, the primitive data type is set within the greater than and less than signs. Remember that the generic type tells you that you can send any data type, but in this example we use the Customer data type.

The Customer is passed to the generic List class to let it know that you want to store a list of customers within the array.

Since the generic List data type is still a class, you need to use the new keyword and call the base constructor. The list constructor doesn't require a parameter, so we can just use the parentheses with no data passed to the constructor.

With the variable defined and the List instantiated, we can now use its methods and properties. Let's look at the code that adds values to the variable.

List<Customer> myInts = new List<Customer>();
Customer cust = new Customer();
cust.first_name = "John";

myInts.Add(cust);

Notice that it's much easier to add a value to the myInts variable. We have the Add method that we can use to add a value to the generic list. We add the numbers one, two, and three to the myInts generic list variable. That's all it takes, instead of using cumbersome code.
