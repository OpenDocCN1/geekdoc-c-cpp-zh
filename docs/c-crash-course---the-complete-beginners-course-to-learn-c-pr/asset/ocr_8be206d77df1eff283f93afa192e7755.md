```
childThread.Start();
childThread.Abort();
}
```

Notice that we added a new line of code that calls the Abort method. This method destroys the thread once you're finished with it.

Multithreading isn't needed with all programs, but it helps greatly when you need to create better performance for your code. It's especially useful when you have a large amount of data you need to cycle through without forcing your users to wait until the process is finished.
