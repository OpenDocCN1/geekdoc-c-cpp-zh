# Lab Questions

1. What keyword can you use to avoid instantiating a class and using its methods?

+   a. public
b. private
c. void
d. static

Explanation: The static keyword lets you create classes that don’t need to be instantiated before you use their methods.

2. What character is used to identify that you want to inherit a child class from a parent class?

+   a. ;
b. :
c. –
d. ,

Explanation: The colon character is used to define an inherited class.

3. What is the standard prefix used to indicate that you’ve created an interface?

+   a. i
b. I
c. int
d. interface

Explanation: The I prefix is used to distinguish between a regular class and an interface.

4. What is a derived class referred to as when it inherits from a parent class?

+   a. child
b. parent
c. subparent
d. derived

Explanation: A child class inherits from a parent class, so it’s always referred to as a child class or an inherited class.
