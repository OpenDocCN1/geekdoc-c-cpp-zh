# The Numeric Data Types in C#

C# offers several data types that you can use to store and calculate values. The two main numeric values are decimals and integers. Integers are values that have no decimal point value. They can be signed or unsigned. A signed integer is a negative value, which means that the signed part is the negative notation and the number is. An unsigned integer is a positive value that has no plus sign. It's automatically assumed to be a positive value.

Decimal values have several data types in C# depending on the number of precision points you want to use. The smallest decimal value is a float data type. The largest is the decimal data type. A decimal point allows you to store up to a 128-bit number in your variable.

First, let's take a look at an integer data declaration.

```cs
int myNumber = 22;
```

Notice the declaration to declare an integer is the same template and syntax that we used with a string variable. All variable declarations follow the same template syntax, so you can expect each declaration to follow this syntax when you write your code.

We defined our variable named myNumber with the int data type. It's the shortened version of the integer specifier. An integer stores a 32 bit number, but you can lengthen your integer storage to 64 bit using the long data type. Let's take a look at the long variable declaration.

```cs
long myNumber = 222222;
```

We used a longer integer value in the above statement to show that you can use longer numbers when you use the long data type.

Let's take a look at decimal variable declaration. First, let's take a look at a float decimal declaration.

```cs
float myNumber = 22.333;
```

Once again, the same syntax template is used to define a variable. This time we used a decimal number. We could also use zero as a decimal place holder. For instance, the following code would also be valid syntax.

```cs
float myFunction = 22.0;
```

If we needed a longer decimal point value, we could use the double data type or the decimal data type. The double data type allows for a 64-bit decimal value. The following code shows you how to declare a double variable.

```cs
double myFunction = 22.2222222222;
```

Again, we used a longer decimal point value to illustrate that the long data type can hold up to 32-bit decimal values.

Next, we have the decimal data type. Decimal data types are rarely used unless you need significant precision, as in scientific calculations. The following is an example of the decimal value declaration statement.

```cs
decimal myFunction = 33.444444444444444444444444444;
```

You can have to twenty-eight decimal precision values with the decimal data type. You won't need to use this type unless you have a need for precise numeric calculations.

When you determine the data type for your variables, don't just use the largest data type. Use the data type that matches the value you need. Using too much memory for your applications is considered poor coding, and it can harm your program’s performance.

# Constants

You don't always need to dynamically assign a value to a variable. Sometimes know that you know the value of pi is always 3.14. You don’t need to dynamically assign this value, so you can create a constant. A constant holds a static value that never changes. If you attempt to change this variable’s value, the compiler gives you an error.

You define a constant same you define a dynamic variable, except you use the const keyword as the first specifier. Let’s take a look at an example using a pi variable.

```cs
const decimal pi = 3.14;
```

We used the decimal data type because pi has several precision points that we can use. We won’t be able to change the value in our code, so the pi variable will remain with the value 3.14 throughout the lifetime of the program.

The const data type is used within a class to specify that the variable should have the same value throughout the lifetime of the class. The variable is destroyed when the class is destroyed in memory, but you should know that the variable’s value doesn’t change, regardless of where the variable is used in the code. Because a constant can’t have a dynamic value, you must give it a value when you define it. If you recall, assigning a value to a dynamic variable is optional.

You might need to reference the values that can be used with each data type, but you should at least understand which ones store numbers versus strings and other data types.

## Mathematical Operators

Mathematical operators are probably the most common, because you'll need to perform some type of calculation on your numeric variables. Mathematical operators are intuitive, because they follow the same rules that you learned in math class. Mathematical operators include addition, subtraction, division, and multiplication. C# also has a modulus operator for division remainders. With programming in C-style languages, you can also choose to use incremental and decremental operators. We'll cover all of these in this section.

The first operator is the addition operator. As the name suggests, you use this operator to add a value to an existing variable. The following code shows you how to add in C#.

```cs
int myNumber = 3;
int addedNumber = myNumber + 4;
```

In the code above, we first created a variable and then we created a second variable that contained the result of the addition of myNumber to 4. As you can probably guess, the result is 7.

The next operator is subtraction. Just like the addition operator, the subtraction operator is intuitive. It simply subtracts a number from a variable. The following code is an example of the subtraction operator.

```cs
int myNumber = 3;
int addedNumber = myNumber - 4;
```

The code above is the same as that we used in the addition example, except this time we subtracted the number 4 from the myNumber variable. The result is -1, stored in the addedNumber variable.
