The constructor is the first function you see in the class object. Constructors are important parts of the class, because they allow outside methods to instantiate the class and use the properties and methods to manipulate the data. The constructor always has the same name as the class, and it never has a return type. We’ll discuss return types when we discuss how to create methods for your classes.

# Creating Class Constructors

Classes are the building blocks for your programs, and constructors are the scaffolding that hold the classes together. Constructors are what allow you to instantiate the classes you need to use throughout the lifetime of your program. You can set specifiers on your constructors, but they must always be the same name as the class, and they should never have a return type.

Let’s take a look again at the same Customer class we created in the previous section.

```
public class Customer
{
    public Customer () {
        public string first_name;
        public string last_name;
        public string phone;
    }
```

The constructor is the first line of code in the class definition. Notice that the method name is the same as the class name. This includes that because C# is case-sensitive, as you will recall from the first chapter. The constructor is built just like any other method in your classes. The constructor has the trailing parentheses that can take a parameter if you want it to. Then, it has the brackets that contain the executable code, if you want to execute any when when the class is instantiated. In this example, we don’t have any parameters for the constructor, and no code is executed when the code is instantiated.

Let’s take a look at a class that has a constructor that takes parameters and then initializes some code.

```
public class Customer
{
    public Customer (string first_name)
    {
        this.first_name = first_name;
    }
```
