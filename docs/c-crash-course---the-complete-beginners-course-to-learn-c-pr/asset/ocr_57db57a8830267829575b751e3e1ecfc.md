The above code has the structure and a testStructure class for a console application. In the Main function, we define a new variable with the Customer_type data type. We then populate the structure’s properties with values. Notice that the structure code has the same syntax as when you retrieve or set values. This is one reason structures are easy to learn as long as you understand classes.

Once you have the data defined, you can use it anywhere in your code. When you create a variable within a method, the variable is local to the method. You can use it it only within the Main method unless you create the variable global to the class. In our example, we defined the variable within Main, so we can use it anywhere within the Main method.
