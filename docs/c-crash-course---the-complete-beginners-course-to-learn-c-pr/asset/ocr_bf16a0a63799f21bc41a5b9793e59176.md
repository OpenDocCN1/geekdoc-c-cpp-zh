# # Chapter 3
Data Types

**Objective:** Data types determine the data you can store in your variables. C# has several data types, and this chapter helps you understand them and what you can do with these variables.

When you write a program, you need to tell the operating system what it can expect for each variable set up in the system. The reason you need to define variable data types is that the operating system allocates memory based on the data type. The data type tells the operating system what you will store in a variable, and is required for each variable you define.

# **Basic Data Type Syntax

Before we get into specific data types, we should take a look at basic syntax. The following is a basic template for defining a variable.

```
<data type><variable name>;
```

We'll cover several data types that you'll use in your programs, but just for the sake of this section, know that the data type specifier is always the first item in your variable declaration statement.

The next item in your variable declaration statement is the variable name. You can give your variables any name, but usually coding standards define the way you name your variables. For instance, most developers require "camelCase" in variable names. You start the name with a lowercase letter, and then any subsequent words within the variable are capitalized. For you give your variable name "camelCase" instead of "CamelCase" or "camelcase." However, you can name your variables anything you want.

Note that different cases are different variables in C#. In the camelCase example, each variable camelCase, camelcase, and CamelCase are different variables. This follows the C convention of variable naming schemes. You'll notice that C# follows many of the standard C styles, if you've dabbled in the C language.

The final syntax requirement is the semicolon. The semicolon tells the compiler that the end of a statement has been reached and any statements after should start a new statement. If you forget the semicolon, the compiler gives you an error and won't let you compile the code.
