Class properties should always be nouns. Again, we’ll cover classes and properties in future chapters, but remember that properties should be given noun names. For instance, if a property holds a user’s name, it should be named something like m_name, m_fullname, or _fullname. Notice that a class member property should have some kind of prefix. It should be either m_ or _ as a prefix. This is standard among naming schemes.

Comment on your code often. Remember that someone must come after you and edit your code. This means that you need to comment on your code so that others are able to pick up where you left off. Comments help other coders understand what your code is supposed to do, what type of input it should expect, and if the coder should pay attention to any quirks in the system.
