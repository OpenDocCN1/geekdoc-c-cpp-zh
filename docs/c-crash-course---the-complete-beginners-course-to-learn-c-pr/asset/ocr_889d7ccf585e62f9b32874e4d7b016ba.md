In this example, we use the OpenOrCreate file mode again to indicate to the compiler that we want to open the file if it's available. If it's not available, then create the file on the fly. Now let's add the code that writes data to the file, because at this point, the file is empty.

```
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.ReadWrite);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
    }
}
```
