Not all of your programs will use files, but you will run across some sites or console applications that require you to read or write from files. # Writing to Files

One of the easiest and most common methods you need to know with files is reading their data. You could read for a number of reasons, including importing data, importing user preferences, importing spreadsheet data to store in a database, and any other number of reasons. You can read predefined formatted data such as a comma delimited file, or a plain text file stored in it.

The C# language and the .NET library framework make storing data in a file much easier than it is with other languages. The .NET language includes the FileStream class that helps you write to a file. It takes a few parameters to get it to work, but you only need a few lines of code to write data to a file. Let's take a look at the code that can make this happen.

```
class Program
{
    static void Main(string[] args)
    {
        FileStream F = new FileStream("test.txt", FileMode.OpenOrCreate, FileAccess.Write);
        for (int i = 1; i <= 20; i++)
        {
            F.WriteByte((byte)i);
        }
        F.Close();
    }
n
```

The above code is a class for a program named Program. The main method contains the code that writes data to a file. It's a simple loop that just loops from 1 to 20 and writes these numbers to the file.
