## Why Use Polymorphism?

When a programmer is new to OOP, it might be difficult to identify when you would use polymorphism or even why you would want to use it. We discussed OOP and some class methods and properties. We can use our same Animal, Lion, and Bird classes that we discussed in those chapters.

Let's use the same classes we had in other chapters. We discussed having a main, base Animal class. The Animal class contained properties and methods that are common among all animals. We had a property for legs and a method for an animal speaking. We know that all animals can speak in some way, and all animals have legs.

With our Animal class, we had a property that defined the legs for the animal. All animals have legs, but these are not all the same. Different animals have different numbers of legs, and the characteristics of these legs are different between most species. You need a way to describe different animal legs without removing the property from the main Animal class.

You can create polymorphic classes using two methods: function overloading and operator overloading. We'll mostly cover function overloading, because it's the most common method that you'll see when you create your C# coding projects.

You use polymorphism with class methods as well. Using our animal class example again, each animal speaks in some way, but each of them speaks differently. A bird chirps and a lion roars. You can use function overloading to specify about what type of speech you hear from a different animal.

Anytime you have a base class that defines a very vague area of your program, you'll probably need polymorphism to override the parameters and functions to better describe the features in your child classes.

# Overriding Functions

When you inherit methods from main classes, you can overload those functions to create a better dynamic program. Overriding functions is done from the child class that derives its main functions from the parent class.

Let's go back to our Animal class. We know that each animal must speak in some way, and we created a Speak method in the main abstract class. Because all animals don't speak the same, we need to override the main abstract class Speak method to customize it for our own child animal classes. Let's take a look at some code to view an example.

```cs
abstract class Animal
{
    public abstract void Speak()
    {
        Console.WriteLine("Animals say Hello");
    }
}

class Lion: Animal
{
    public Lion ()
    {
    }
    public override void Speak ()
    {
        Console.WriteLine("A lion roars");
    }
}
```

In the above code, you can see that we created an Animal class. Remember that abstract classes cannot be instantiated, so you must derive a child class that actually be instantiated or the abstract class will not be useful to your program. We create an Animal abstract class with a method called Speak that can be used for all animals. We don't have a constructor for the main abstract Animal class, because the class can't be instantiated. Because constructors are for instantiation, there is no point in adding a constructor to the abstract Animal class.

We then create a Lion class. The Lion class derives from the main Animal class, because all Lions are animals. Because the Lion derives from the Animal class, we can use the methods defined within the Animal class. We have only one method Speak, but we can derive this from its parent class. However, Lions have a distinct way of talking to other animals, so we need to override the main Animal Speak method with our own Lion Speak. We do this using the override keyword in C#. Let’s take a look at some code to view an example.

```cs
abstract class Animal
{
    public abstract void Speak()
    {
        Console.WriteLine("Animals say Hello");
    }
}

class Lion: Animal
{
    public Lion ()
    {
    }
    public override void Speak ()
    {
        Console.WriteLine("A lion roars");
    }
}
```

Notice that the Lion class has a constructor, because we want to be able to instantiate this class. When the Speak method is called in your program from the Lion class, the overridden method. Let’s look at how you call the Lion class and what is printed when you’ve finished.

```cs
static void Main(string[] args)
{
    Lion l = new New();
    l.Speak();
}
```

In the above Main method, we instantiate the Lion class and call the Speak method. Since the Lion class overrides the parent Animal Speak method, the code returns the phrase “A lion roars” to the user.

We can also use the Bird class as another example. We know that birds have a different way of speaking than lions, so we can create an override method that creates our own Bird class method that describes the way birds speak in the wild.
