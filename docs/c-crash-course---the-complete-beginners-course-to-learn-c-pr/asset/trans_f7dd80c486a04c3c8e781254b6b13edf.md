
私有的，那么除了本地 Customer 类之外，其他类都无法使用该方法。

# 使用属性

类方法是动词，而属性是名词。你想要放置在类上的任何属性都可以通过属性来实现。类属性定义了类的“外貌”。例如，名和姓是 Customer 类的属性。它们是你的客户的属性。

让我们来看当前的 Customer 类属性。

```
public class Customer
{
    public Customer () { {}
    public void ChangePhone (string new_phone)
    {
        this.phone = new_phone;
    }
    public string first_name;
    public string last_name;
    public string phone;
}
```

上述 Customer 类有三个属性。first_name、last_name 和 phone 变量都是 Customer 类的属性。

你可以为你的类添加任意数量的属性。你可以添加另一个名为 `address` 的字符串属性来记录客户的地址。让我们来看一个示例。

```
public class Customer
{
    public Customer () { {}
    public void ChangePhone (string new_phone)
    {
        this.phone = new_phone;
    }
    public string first_name;
    public string last_name;
    public string phone;
    public string address;
}
```

只需记住，所有属性都是描述类特征的名词（或属性），而方法是在类及其数据上执行操作的动词。。

当你创建类时，你至少需要一个属性，并且类中可能至少有一个方法。类可以很小，只有一行代码；你也可以拥有非常大的类，它们定义了程序的大部分内容。只需记住，类是可扩展的，因此你应该始终为程序的每个部分创建一个类，以确保在将来你需要更多功能时它仍然具有可扩展性。

# 第 8 章
结构与枚举

**目标：** 结构（Structures）和枚举（Enum）是创建自定义数据类型的两种方式。本章将向你展示如何使用这两种数据类型来组织代码并使其更容易读。

我们在上一节中涵盖了类，类允许你创建自己的数据类型。结构和枚举是创建自定义数据类型的另外两种方式，但这些数据类型的工作原理与类不同。在使用结构和枚举时你会受到更严格规则的限制，并且它们用于你在类中看到的不同场景。在本章中，我们将查看这两种结构，并让你了解在 C# 程序中何时会使用它们。

# 为什么使用结构或枚举而不是类？

当你开始使用 C# 编程时，你可能想为一切都创建类。在这一章之前，我们一直推崇每个组件都应该是类的观点，但你可以使用枚举和结构处理程序中较小的组件。

例如，假设你有一个客户类型列表。每个类型在数据库中都有 0 到 3 的值。你可以为客户类型创建一个类，但也可以为这些值创建一个枚举。枚举为这些值提供了一个友好的名称，并存储一个整数来表示每个友好名称的编码值。

结构的作用与枚举类似。结构允许你包含不仅是整数值的内容。枚举用于整数值，而当你需要存储其他数据类型时，结构非常有用。例如，当你需要存储客户 ID 和类型的字符串值时，你可以为客户数据类型创建一个结构。你可能想在结构中存储与客户 ID 匹配的描述。你可以为此类型结构使用类，但有时当你只需要一两个属性来表示自定义数据类型时，类并不是必须的。

在本章中，我们将向你展示何时应该使用这些数据类型而不是构建整个类。在大多数情况下，你将使用类来定义你的应用程序，但在少数示例中，你不需要一个完整的类，而是一个小小的枚举或结构。

# 使用结构

结构与类最相似的东西。它们创建你自己的数据类型，但与类对象的定义略有不同。结构允许你创建一个自定义数据类型，该类型包含代码所需的任何数据类型的值的列表。

结构看起来像具有长属性列表的类，但你使用 `struct` 关键字来定义它们，而不是类定义。

让我们来看用于定义结构的模板。

```
struct structure_name
{
    public data_type name
    // 你需要的任何其他结构属性
}
```

`struct` 关键字表示你想创建一个结构。在 `struct` 关键字之后，你给结构命名。这可以是任何恰当描述该结构应该包含内容的名称。

结构括号内是属性。每个属性都应该设置为 `public`，否则你将无法访问它们。在类中，有理由不许可访问属性，但在结构中，你应该将它们设置为 `public`。你可以添加任意数量的结构属性，但当它变得太复杂时，有时选择类比使用结构更好。

让我们来看一个结构的真实示例。我们将使用之前提到的同一个示例。我们将使用一个客户类型结构。

```
struct customer_type
{
    public int id
    public string description;
    public string type_name;
}
```

在上面的代码中，我们创建了一个名为 `customer_type` 的结构。在结构定义内部，我们创建了三个属性。第一个将代表客户类型的 ID。第二个属性名为 `description`，代表类型的简要描述，然后 `type_name` 属性是客户类型的名称。

定义结构后，你现在可以在代码中使用它了。让我们看看当你想将结构包含在代码中代码看起来是什么样的。

```

```


上述代码包含了一个控制台应用程序的结构和一个 `testStructure` 类。在 `Main` 函数中，我们定义了一个 `Customer_type` 数据类型的新变量。然后我们用值填充结构的属性。注意，结构代码与你检索或设置值时的语法相同。这是结构只要你理解类就易于学习的原因之一。

一旦你定义了数据，你就可以在代码的任何地方使用它。当你在方法内部创建变量时，该变量是方法局部的。你只能在 `Main` 方法内部使用它，除非你创建了类的全局变量。在我们的示例中，我们在 `Main` 内部定义了变量，因此我们可以在 `Main` 方法的任何地方使用它。
