The first line of code is the Filestream class, instantiated and assigned to a variable named F. The first parameter is the file where you want to store the data. We are simply storing data in a file name test.txt. Since we don't specify a location, the file is simply stored in the directory where the program runs.

The next parameter is the file mode. FileMode is an enum that we saw earlier in this book. This enum has several file modes that can be used when creating a file or just reading it. In this example, we use OpenOrCreate. This file mode tells the compiler to open the file, but if the file isn't already created or it's not found, then create the file before reading from it.

The third enum is the FileAccess enum. You can either read from a file, write to a file, or read and write to a file. Because we just want to write to a file, we need to specify that we just want to write to the file. You could set the file access to read and write, but it's generally a standard to only set file access to with the access rights you need to perform a task.

The final part of the code writes the data to the file. We use a for loop to write the data from 1 to 20. Notice that we explicitly convert the numeric value to a byte before we write it to the file. This is done because data is written to files instead of raw data. You'll need to convert your data to a byte before you can write data to a file. Just remember this when you write your own data to files in your programs.

We use the WriteByte method to write data to the file. The final line of code used is the Close method. If you don't close the file, you won't be able to use it in future actions until you reboot the system. The operating system puts a lock on the file when you open it. You can only access the file in read only mode. To avoid this situation, you need to close the file in every part of your code where you open it. You won't be able to open it in any other program either, so make sure you always use the Close method at the end of your methods that open your files.
