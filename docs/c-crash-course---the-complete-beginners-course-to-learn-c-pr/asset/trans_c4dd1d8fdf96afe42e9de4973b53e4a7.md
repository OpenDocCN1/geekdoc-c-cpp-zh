
赋值运算符。它将一个值赋予变量。让我们再次查看一遍赋值运算符。

```
int myNumber1 = 1;
```

赋值运算符用于将值 1 赋值给 `myNumber1`。

你也可以对变量进行数学计算，并用一行代码将结果赋值给它。这是将赋值运算符与数学计算结合的一种简写代码形式。你使用我们在第一节中使用相同的数学运算符，并将它们与赋值运算符结合。

让我们来看这个例子。

```
int myNumber1 = 1;
myNumber1 += 2;
```

在这个例子中，`myNumber1` 首先被赋值为值 1。下一条语句在变量上加 2，然后给它赋予新值。第二条语句的结果为 3 并将其赋值给 `myNumber1`。

你可以对任何其他数学操作执行相同的操作。让我们再看另一个使用乘法运算符的例子。

```
int myNumber1 = 1;
myNumber1 *= 2;
```

注意，使用的语法是相同的，只是我们使用了乘法字符。在这个例子中，`myNumber1` 乘以 2，并将该值赋值给 `myNumber1`。结果是 `myNumber1` 现在包含值 2。

运算符是任何编程语言的重要部分，包括 C#。这些运算符存在于每个主要的应用程序中，因此你需要熟悉它们，以便在任何编程语言中工作。

# 第 5 章
循环和 If 语句

目标：循环和 `if` 语句控制代码的执行方式。我们在上一节中看到了 `if` 语句，现在我们将结合对循环的复习深入探讨它们。

在每个程序中，你都需要根据语句的计算方式来评估语句并执行代码。循环遍历语句直到达到停止条件，而 `if` 语句评估两个条件并根据结果执行语句。在本章中，我们将向你展示如何使用这两种结构来控制代码的执行方式。

# For 循环

`for` 循环是所有循环结构中最受欢迎的。循环遍历一系列条件，直到满足停止条件。如果停止条件从不被满足，你就会创建一个无限循环，因此你总是需要记住包含停止条件。`for` 循环最受欢迎，是因为很难达到停止条件。

让我们来看你用于 `for` 循环的通用语法模板。

```
for ( init; condition; increment )
{
// 在此处执行
}
```

`for` 循环初始化一个变量，设置停止条件，然后递增初始化的变量。这三条语句用分号隔开。每次迭代时，初始化的变量都会递增，直到满足条件并退出循环。让我们来看一个例子。

```
for ( int j = 0; j < 5; j++)
{
// 在此处执行
}
```

在上面的 `for` 循环中，变量 `j` 被初始化并设为 0。你可以将变量设置为任何值，但标准是将其设置为 0，因为循环通常用于遍历数组，而这些结构从索引 0 开始。下一条语句是条件。只要 `j` 小于 5，循环就会继续。一旦 `j` 等于 5 或大于 5，循环就会执行。递增语句在每次循环后给 `j` 加 1。让我们为循环期间发生的情况增加一些细节。

```
for ( int j = 0; j < 5; j++)
{
    Console.WriteLine(j.ToString());
}
```

上述循环的输出如下。

- 0
- 1
- 2
- 3
- 4

注意值 5 没有打印，因为当 `j` 达到值 5 时，循环退出了。

当我们处理数组时，你会再次看到循环。

# While 循环

`while` 循环与 `for` 循环相似，因为它具有相同的停止条件设置。然而，`while` 循环不初始化变量，且在每次迭代后不递增。当你使用 `while` 循环时，你更有可能导致无限循环，因为没有自动递增的值，但当你有一个无法使用数值条件的可用条件时，你需要 `while` 循环。

让我们来看 `while` 循环模板。

```
while (condition)
{
    // 在此处执行
}
```

注意 `while` 循环与 `for` 循环的区别在于它只有一个条件。让我们来看一个例子。

```
while (condition)
{
    // 在此处执行
}
```
bool loop = true;
int j = 0;

while (loop)
{
    Console.WriteLine(j);
    if (j == 5)
    {
        loop = false;
    }
    j++;
}
```
注意使用 `while` 循环需要更多的代码，因为没有自动递增的值，但当你有一个无法使用数值条件的可用条件时，你需要 `while` 循环。

# If 语句

我们在上一节中对 `if` 语句介绍较少。`if` 语句在编程中非常常见，它是改变代码的一种。

首先，让我们来看 `if` 语句的set模板。

```
if (expression)
{
  // 当表达式为真时执行
}
```

我们已经看了一些例子，但让我们来看另一个。

```
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 == 2)
{
  Console.WriteLine("The variable equals the value of 2");
}
```

我们在之前的 `if` 语句使用了相同的代码来提供另一个例子。在这个例子中，我们给了 `if` 语句一些执行的代码。如果 `myNumber1` 等于 2，它会打印“The variable equals the value of 2”。由于 `myNumber1` 初始化为值 1，结果是 `if` 语句不执行括号内的代码。

一直为止，我们只看了带有一个条件的 `if` 语句，但 `if` 语句还允许将条件与 `else` 以及 `if-else` 语句结合。这两者都为你的代码增加了更多控制。让我们来看这种语句的模板。

```
if(expression)
{
// 当表达式为真时执行
}
else
{
// 当表达式不为真时执行
}
```

上述 `if-else` 语句提供了一个在 `if` 语句中的条件为假时执行替代代码的选项。

让我们来看与 `if-else` 结构工作的实际代码。

```csharp
int myNumber1 = 1;
int myNumber2 = 2;
if (myNumber1 == 2)
{
    Console.WriteLine("The variable equals the value of 2");
}
else
{
    Console.WriteLine("The variable does not equal 2");
}
```

我们在之前的 `if` 语句使用了相同的代码，但我们添加了 `else` 语句。与之前的 `if` 语句一样，这个默认为假。而不是直接跳过所有的 `if` 语句，`else` 语句默认执行。这一次，`if` 语句执行的结果是在控制台中显示“The variable does not equal 2”。
