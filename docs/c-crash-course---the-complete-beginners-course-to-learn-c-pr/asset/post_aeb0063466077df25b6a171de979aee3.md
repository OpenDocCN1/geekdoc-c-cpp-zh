## Filling an Array with Values

When you work with arrays, you need to fill them with values. The for loop is what is most common when you want to fill an array with values. If you recall, we covered a for loop. A for loop lets you define a variable and a stop condition, and then automatically iterates through the array indices using the increment operator.

Because you usually know the length of an array and the amount of values you need to use to fill the array, you can use the for loop. The for loop is the preferred way to fill an array with values. We want to fill the `myNumbers` array with a list of numbers. Suppose you want to fill the array with values from one to ten. You could use the array indices to assign the values one by one.

Using array indexes one by one is more cumbersome than it's worth. The preferred way of filling an array is using a for loop. Let's take a look at what a for loop looks when you want to iterate through each number and assign it to the array indices.

```cs
for ( int j = 0; j < 10; j++)
{
    myNumbers[ j ] = j;
}
```

In the above code, we use the same array that we used in the previous section. We defined an integer array named `myNumbers`. We know from the data type that we can only store integers in the `myNumbers` array.

The next section of code is the for loop. We know that we want to fill the array with ten numbers. Because all arrays start with the 0 index, we know that we first need to initialize the value of `j` to 0. The for loop loops through the array ten times, from 0 to 9. When the `j` variable reaches the value of 10, the loop exits and no more values are stored in the array.

In the above example, the values of 0 to 9 are stored in the array. You could also store array values by one using array indexes. The following code is an example of storing an array using the array's indices.

```cs
myNumbers[0] = 0;
myNumbers[1] = 1;
myNumbers[2] = 2;
myNumbers[3] = 3;
myNumbers[4] = 4;
myNumbers[5] = 5;
myNumbers[6] = 6;
myNumbers[7] = 7;
myNumbers[8] = 8;
myNumbers[9] = 9;
```

The above code, as you can see, is much more cumbersome than the for loop. And you can add index values to what you want to iterate through to add more numbers to your array. Obviously, using a for loop is much more efficient than using the static numbers and assigning them to an array without using the loop.

Once you assign values to an array, you need to know how to retrieve values from an array as well. In some cases, you fill an array with values that you later need to display to a user. A for loop makes it much easier to retrieve values than it would be by defining the variables you want to retrieve by one.

## Chapter 11: Generics

Objective: Generic lists are much easier to work with than arrays. This chapter helps you understand how to work with and what you can use them for.

We've discussed classes, structures, and enums. All of these create a custom data type that you can. We've also discussed arrays. Arrays require you to define a data type before you can use them, but you can get around this using generics. In this chapter, we're going to show you how to create your own generics and use the pre-made List that comes with the framework.

### Introduction to Generics

Generics are similar to arrays. As a matter of fact, when you create your own generics you create arrays within the code. Generics are how you can store custom types as an array. The C# language provides you with a special syntax that lets specify that you want to pass a generic data type. This data type can be a simple primitive type such as a string or an integer, or you can even pass your own classes to the generics.

Think of a generic as a way to dynamically store values in the same way as an array. Custom methods and properties perform similar tasks on the generic data type, but behind all of the methods is code that works with the stored array variable. The only difference is that the designation for the array's contained values is T instead of a hard-coded primitive type.

In almost every program, you will run into at least one section of your code that uses a generic data type. This is especially true when you work with web applications. Web applications use Lists and Collections, so you'll need to work with these generic lists in most of your web applications.
