# ## Why Use Polymorphism?

When a programmer is new to OOP, it might be difficult to identify when you would use polymorphism or even why you would want to use it. We discussed OOP and some class methods and properties. We can use our same Animal, Lion, and Bird classes that we discussed in those chapters.

Let's use the same classes we had in other chapters. We discussed having a main, base Animal class. The Animal class contained properties and methods that are common among all animals. We had a property for legs and a method for an animal speaking. We know that all animals can speak in some way, and all animals have legs.

With our Animal class, we had a property that defined the legs for the animal. All animals have legs, but these are not all the same. Different animals have different numbers of legs, and the characteristics of these legs are different between most species species. You need a way to describe different animal legs without removing the property from the main Animal class.

You can create polymorphic classes using two methods: function overloading and operator overloading. We'll mostly cover function overloading, because it's the most common method that you'll see when you create your C# coding projects.

You use polymorphism with class methods as well. Using our animal class example again, each animal speaks in some way, but each of them speaks differently. A bird chirps and a lion roars. You can use function overloading to specify about what type of speech you hear from a different animal.
