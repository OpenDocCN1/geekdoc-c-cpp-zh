## 给数组填充值

当你处理数组时，需要向它们中填充值。当你想要为数组填充值时，`for` 循环是最常用的方法。如果你还记得的话，我们之前介绍过 `for` 循环。`for` 循环允许你定义一个变量和一个停止条件，然后使用递增运算符自动遍历数组索引。

由于你通常知道数组的长度以及填充数组所需的数值数量，因此可以使用 `for` 循环。`for` 循环是填充数组数值的首选方法。我们想向 `myNumbers` 数组填充一个数字列表。假设你想向数组填充从 1 到 10 的值。你可以使用数组索引逐个赋值。

逐个使用数组索引比其价值要繁琐得多。填充数组的首选方法是使用 `for` 循环。让我们看看当你想要遍历每个数字并将其赋予数组索引时，`for` 循环是什么样子的。

```cs
for ( int j = 0; j < 10; j++)
{
    myNumbers[ j ] = j;
}
```

在上面的代码中，我们使用了与上一节中相同的数组。我们定义了一个名为 `myNumbers` 的整数数组。从数据类型中知道，`myNumbers` 数组中只能存储整数。

接下来的代码部分是 `for` 循环。我们知道想向数组填充十个数字。因为所有数组都从索引 0 开始，我们知道首先需要将 `j` 的值初始化为 0。`for` 循环会遍历十次数组，从 0 到 9。当变量 `j` 达到 10 时，循环退出，数组中不再存储更多值。

在上面的示例中，0 到 9 的值被存储在数组中。你也可以通过数组索引逐个存储数组值。以下代码是使用数组索引存储数组的示例。

```cs
myNumbers[0] = 0;
myNumbers[1] = 1;
myNumbers[2] = 2;
myNumbers[3] = 3;
myNumbers[4] = 4;
myNumbers[5] = 5;
myNumbers[6] = 6;
myNumbers[7] = 7;
myNumbers[8] = 8;
myNumbers[9] = 9;
```

如你所示，上面的代码比 `for` 循环要繁琐得多。你可以通过在你想要遍历的内容中添加索引值来向数组添加更多数字。显然，使用 `for` 循环比使用静态数字并将它们分配数组而不使用循环要高效得多。

## 从数组中检索值

一旦你为数组分配了值，你也需要知道如何从数组中检索值。在某些情况下，你会向数组填充之后需要显示给用户的值。你可以使用我们在上一节中展示的繁琐检索值方法，也可以再次使用 `for` 循环。与逐个定义想要检索的变量相比，`for` 循环让检索值变得容易得多。

让我们看看使用 `for` 循环的代码是什么样的。

```cs
int[] myNumbers;
for (int j = 0; j < 10; j++)
{
    myNumbers[ j ] = j;
}
```

```cs
// 现在你可以显示这些值
for (int j = 0; j < 10; j++)
{
    Console.WriteLine(myNumbers [j]);
}
```

在上述代码的第一部分，我们定义了数组并分配了数组值。在第二个 `for` 循环中，我们遍历了每个数组索引并显示了索引的值。注意，我们再次使用变量 `j` 来遍历每个索引。只需要一行代码，而使用静态索引变量会迫使你使用几行代码。

## 第 11 章：泛型

目标：泛型列表比数组更容易处理。本章将帮助你理解如何使用泛型以及你可以用它们做什么。

我们已经讨论了类、结构和枚举。所有这些都可以创建一个你可以使用的自定义数据类型。我们还讨论了数组。数组要求在你在使用之前定义数据类型，但你可以使用泛型来回避这一点。在本章中，我们将向你展示如何创建自己的泛型，并使用框架自带的预制 `List`。

### 泛型简介

泛型与数组类似。事实上，当你创建自己的泛型时，你是在代码中创建数组。泛型是你将自定义类型存储为数组的方式。C# 语言为你提供了一种特殊的语法，让你指定想要传递一个泛型数据类型。这种数据类型可以是简单的原始类型（如字符串或整数），你甚至可以将自己的类传递给泛型。

将泛型看作一种与数组相同的方式动态存储值的方法。自定义方法和属性在泛型数据类型上执行类似的任务，但在所有方法的背后都是处理所存储的数组变量的代码。唯一的区别是，数组所包含值的标识符是 `T` 而不是硬编码的原始类型。

在几乎每个程序中，你都会遇到至少一段使用泛型数据类型的代码。这在你处理 Web 应用程序时尤为真实。Web 应用程序使用 `Lists` 和 `集合（集合），因此你在大多数 Web 应用程序中将需要处理这些泛型列表。
