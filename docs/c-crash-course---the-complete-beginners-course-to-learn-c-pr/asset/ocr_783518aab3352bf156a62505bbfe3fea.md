# Lab Questions

+   1. What is the .NET class library that helps you read and write to files in your code?

+   a. FileMode
b. FileAccess
c. FileStream
d. File

Explanation: The FileStream class has methods that let you read and write to files without writing your own code.

+   2. What is the enum you use when you open a file that specifies how you want to open the file?

+   a. FileMode
b. FileAccess
c. FileStream
d. File

Explanation: The FileMode enum specifies if you want to open and create a file if it does not exist.

+   3. What enum determines the type of access you want to give the program when it opens the file?

+   a. FileMode
b. FileAccess
c. FileStream
d. File

Explanation: The FileAccess enum tells the compiler if you're going to read, write, or read and write to the file.
