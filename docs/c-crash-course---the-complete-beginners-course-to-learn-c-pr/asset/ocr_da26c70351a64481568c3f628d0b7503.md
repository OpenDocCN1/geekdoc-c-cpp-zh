```
static class Animal : IAnimal
{
    public string eye_color;
    public string number_of_feet;
    public function breathe()
    {
        return "Animals breathe air.";
    }
}
```

Notice that we changed the abstract type in the above Animal class to static. Now, we don't need to instantiate this class. We can instantiate the class now that it's not an abstract defined class. With the static specifier, we can call the class with no instantiation. Let's take a look at what this looks like in a C# method.

```
static class Animal : IAnimal
{
    public string eye_color;
    public string number_of_feet;
    public function breathe()
    {
        return "Animals breathe air.";
    }
}
```

```
class StaticTester
{
    static void Main(string[]) args
    {
        Console.WriteLine("This is what happens when you call a static class: {0}", Animal.breathe());
    }
}
```

In the above code, we define our static Animal class and then we call the breathe method using the static method contained within the class. Notice that we didn't instantiate the class before we called the method. This is valid syntax when you use the static specifier in your code.
