# Chapter 11
Generics

Objective: Generic lists are much easier to work with than arrays. This chapter helps you understand how to work with generic lists and what you can use them for.

We've discussed classes, structures, and enums. All of these create a custom data type that you can use throughout your C# program. We've also discussed arrays. Arrays require you to define a data type before you can use them, but you can get around this restriction by using generics. Generics allow you to create arrays that can hold generic types that you can't use with a regular array. In this chapter, we're going to show you how to create your own generics and use the pre-made List generic that comes with the .NET framework.

# Introduction to Generics

Generics are similar to arrays. As a matter of fact, when you create your own custom generics you create arrays within the generic code. Generics are how you can store custom data types as an array. You can create a generic class to store any data type you want. The C# language provides you with a special syntax that lets specify that you want to pass a generic data type. This data type can be a simple primitive type such as a string or an integer, or you can even pass your own classes to the generics class.

Generics use the special T syntax to indicate that you want to pass a generic data type to the class methods. Think of a generic as a way to dynamically store values in the same way as an array. Custom methods and properties perform similar tasks on the generic data type, but behind all of the methods is code that works with the stored array variable. The only difference is that the designation for the array's contained values is T instead of a hard-coded primitive type structure.

In almost every program, you will run into at least one section of your code that uses a generic data type. This is especially true when you work with web applications. Web applications use Lists and Collections, so you'll need to work with these generic lists in most of your web applications. For instance, when you send information from a form to your C# controllers, the form is sent in a form collection generic data type that you can use to retrieve your values.
