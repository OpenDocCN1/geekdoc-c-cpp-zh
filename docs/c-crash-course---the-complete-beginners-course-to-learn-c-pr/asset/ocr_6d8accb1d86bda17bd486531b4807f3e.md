Notice that we used the same relative code that we had previously. This time, we decided to put the Sleep method call in the secondary thread method to call it from there. This code does the same thing that the previous section did. There are two threads, and one is set in the child thread which we instantiate and create. The 5000 milliseconds pauses the secondary thread for 5 seconds (when you convert milliseconds to seconds).

We write the output to the console so you can identify what is going on as your program runs. The secondary thread pauses, but the main thread still keeps running regardless of what the secondary thread is doing. This is the advantage of using multithreaded processes.

# Deleting a Thread

At some point, you'll need to delete or destroy threads after you're finished with them. This frees up the memory that was allocated for that thread.

Take a look at the code you can use to destroy a thread.

```
class MultithreadedProgram
{
    public static void SecondThread()
    {
        Console.WriteLine("Child thread starts");
    }

    static void Main(string[] args)
    {
        ThreadStart childref= new ThreadStart(SecondaryThread);
        Console.WriteLine("In Main: Creating the Child thread");
        Thread childThread = new Thread(childref);
        childThread.Sleep(5000);
    }
}
```
