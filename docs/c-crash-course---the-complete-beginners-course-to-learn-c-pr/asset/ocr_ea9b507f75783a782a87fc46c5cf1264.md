You can also add an if statement to your else statement. This lets you create several conditions in one if statement block. Let's take a look at the template.

```
if (expression)
{
  // statements that execute when the expression equals true
}
else if (expression)
{
  // statements that execute when the expression doesn’t equal true
}
else
{
  // statements that execute when the expression doesn’t equal true
}
```

Notice that we still kept the else statement with the two conditions. The else statement is optional for any statement. For instance, you could have just the two if statements from the template above and leave out the else statement.

Now, let’s take a look at some actual code that uses the template. We’ll use the same variables from previous examples.

```
int myNumber1= 1;
int myNumber2 = 2;
if ( myNumber1 = 2)
{
  Console.WriteLine("The variable equals the value of 2");
}
else if ( myNumber1= 1)
{
  Console.WriteLine("The variable equals the value of 1");
}
else
{
  Console.WriteLine("The variable does not equal 2 or 1");
}
```

In this statement, we use the same condition in the first block and the else block. If you notice, the first block evaluates to false. This time, we now have an else if statement.
