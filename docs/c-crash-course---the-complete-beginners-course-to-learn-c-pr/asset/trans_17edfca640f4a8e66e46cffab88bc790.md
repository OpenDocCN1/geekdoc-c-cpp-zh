# C# 中的数值数据类型

C# 提供了多种数据类型，你可以用它们来存储和计算数值。两种主要的数值类型是小数（decimals）和整数（integers）。整数是不带小数点的数值。它们可以是带符号的或无符号的。带符号整数可以是负值，这意味着符号部分是负号，而数字是数值本身。无符号整数是不带加号的正值。它被自动假认为正值。

在 C# 中，小数值有多种数据类型，取决于你想要使用的精度点数量。最小的数值值是 `float` 数据类型。最大的是 `decimal` 数据类型。小数点允许你在变量中存储多达 128 位的数字。

首先，让我们来看一下整数数据类型的声明。

```cs
int myNumber = 22;
```

注意，用于声明整数的声明模板和语法与我们用于字符串变量时是相同的。所有的变量声明都遵循相同的模板语法，因此当你编写代码时，可以预期的每个声明都会遵循这种语法。

我们使用 `int` 数据类型定义了名为 `myNumber` 的变量。它是整数指定器的缩写。整数存储一个 32 位的数字，但你可以使用 `long` 数据类型将整数存储空间扩展到 64 位。让我们来看 `long` 变量声明。

```cs
long myNumber = 222222;
```

我们在上面的语句中使用了了一个较长的整数值，以说明当你使用 `long` 数据类型时可以使用更长的数字。

让我们来看小数变量的声明。首先，让我们来看 `float` 小数声明。

```cs
float myNumber = 22.333;
```

再次，使用了相同的语法模板来定义变量。这次我们使用了一个小数。我们也可以使用 0 作为小数占位符。例如，以下代码也是有效的语法。

```cs
float myFunction = 22.0;
```

如果我们需要更长的小数值，可以使用 `double` 数据类型或 `decimal` 数据类型。`double` 数据类型允许 64 位的小数值。以下代码展示了如何声明一个 `double` 变量。

```cs
double myFunction = 22.2222222222;
```

再次，我们使用了较长的小数值值，说明 `double` 数据类型可以持有多达 32 位的小数值。

接下来，我们有 `decimal` 数据类型。除非你需要高精度（例如科学计算），否则 `decimal` 数据类型很少使用。以下是小数值声明语句的示例。

```cs
decimal myFunction = 33.444444444444444444444444444;
```

你可以使用 `decimal` 数据类型拥有高达 28 的小精度值。除非你有精确数值计算的需求，否则你不需要使用这种类型。

当你确定变量的数据类型时，不要只使用最大的数据类型。使用与你需要的数值匹配的数据类型。在应用程序中使用过多内存被认为是糟糕的代码，并且会损害程序的性能。

# 自定义数据类型

当你使用类（classes）时，你就创建了一个自定义数据类型。你也可以使用结构体（structs）和枚举（enums）创建自定义数据类型。我们将在后续章节中介绍这些数据类型，但在创建程序时，你仍然需要理解如何定义这些变量。

类定义了你自己的属性和方法。就像从 .NET 框架集成的类一样，你也可以创建自己的。我们将讨论如何创建一个带有自己的方法和属性的类，但让我们看看如何使用自己的类来定义变量。假设你有一个名为 `MyClass` 的类。以下代码使用 `MyClass` 数据类型定义了一个变量。

```cs
MyClass myclass = new MyClass();
```

你会发现，使用自定义数据类型定义值与原始数据类型大不相同。你仍然使用数据类型指定，但随后你使用 `new` 指定符配合类的构造函数。我们将在讨论类时介绍构造函数。只需要知道，当你使用带类的类的自定义数据类型时，你需要实例化该类并将其赋值给变量。在这个示例中，我们实例化 `MyClass` 类并将其赋值给 `myclass` 变量。记住 C# 是区分大小写的，所以 `MyClass` 是一个类，而 `myclass` 是一个变量，编译器可以理解其中的区别。

# 常数

你并不总是需要为变量动态赋值。有时你只需要知道 pi 的值始终是 3.14。你不需要动态地分配这个值，因此你可以创建一个常数。常数持有永不改变的静态值。

```cs
const double PI = 3.14;
```
