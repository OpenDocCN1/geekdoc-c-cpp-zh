The above code is the same as the following code.

```
int j = 0;
j = j + 1;
```

Notice that the previous version of the code is much shorter and easier to read. The result is just adding 1 to the j variable. In this example, the result is that j is equal to 1.

You can also decrement a variable in the same way. Let's take a look at the decrement operator.

```
int j = 0;
j--;
```

Notice that we just replaced the plus signs with minus signs. The result is that we decrement the j variable by 1. The above code is the same as the following code.

```
int j = 0;
j = j - 1;
```

The result is that the j variable contains the value -1.

The above operators are all of the ones that you'll use throughout your C# code. These calculations are common to any C# program.
