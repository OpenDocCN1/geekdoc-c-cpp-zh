```
array[index] = value;
}
```

Notice that we added one method to the MyGeneric class. We kept the same property and constructor. We added the setItem method. Remember that methods are the verbs of a class, so this method adds a value to the array. It takes the index of the array to identify where you want to place the value, and uses the T designation to tell the compiler any generic data type can be used. The setItem method then assigns the generic data type to a location in the array.

With the setItem method set, you now need to retrieve a value from the array. Let's take a look at the new method in the MyGeneric class that lets you retrieve a value from the generic array.

```
public class MyGeneric<T>
{
    private T[] array;
    public MyGeneric(int size)
    {
        array = new T[size + 1];
    }
```

```
public T getItem(int index)
{
    return array[index];
}
```

```
public void setItem(int index, T value)
{
    array[index] = value;
}
```

This is a full class that works with generics. We added the getItem method that retrieves information from the array. This is the completion of the generic class that you can create in your program.

# Using the List Generic Class

You can create your own generic class, or use the premade generic class that is available from the .NET framework. It's much easier to use the premade classes than to create your own. You don't need to create your own unless you have specific needs for your classes that the premade generics don't offer.
