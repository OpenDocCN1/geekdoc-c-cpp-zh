In the above code, we created two variables named myNumber1 and my2 initialized both of them with the values of 1 and 2. Obviously, these two values are not equal, the relational operator in the if condition returns false. Since the result is false, the statements within the if condition are not executed. Remember that if the result of a relational operator is false, nothing within the if statement brackets is executed and code execution will jump to whatever code is under the condition.

Just like the equality operator, you can also identify if two variables are not equal. Using the same syntax, let's take a look at an example.

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 != myNumber2)
{
//if condition equals yes, then do we these operations
}
```

We changed the relational operator to != or "not equal to.". In this condition, the result of the calculation is false, so any statements within the if condition are executed this time.

You'll also need to determine if a value is greater than or less than another variable. C# also has these relational operators to provide you with these two conditions. Let's take a look at the greater than relational operator.

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 > myNumber2)
{
//if condition equals yes, then do we these operations
}
```

We used the same syntax and just switched the relational operator to the greater than symbol. In this example, the result of the calculation is false, so none of the if statements are executed.

Similar to the greater than operator, let's take a look at the less than statement.

```
int myNumber1 = 1;
int myNumber2 = 2;
if ( myNumber1 < myNumber2)
{
//if condition equals yes, then do we these operations
}
```
