# Using the List Class for Custom Class Structures

We used a primitive integer for the above code, but you can also store class structures in a generic list. In other words, your custom classes can be stored in the same way as you store primitive numbers in a list. For instance, if you have a Customer class that contains customer information, you might want to store ten customers, each within its own class. You then add the custom class to a generic list, so you have ten customers stored in an array. You can then loop through each of these Customer values and store them in a database. This makes it much easier to store custom values and avoids having to write extra code.

Let's take a look at the code. Let's first initialize a variable for the Customer class.

```
List<Customer> myInts = new List<Customer>();
```

In the code above, notice that the syntax is the same as we saw in the previous section, but we used the Customer data type instead of the int data type. This allows us to store a Customer data value in an array instead of primitive data types.

Now let's add a value to the generic variable.

```
List<Customer> myInts = new List<Customer>();
Customer cust = new Customer();
cust.first_name = "John";
cust.last_name = "Smith";
myInts.Add(cust);
```

In the code above, we instantiated the list variable and then created a customer data type variable. We filled the customer class variable with some data and then stored the entire class in the myInts generic list. This is very useful when you want to store numerous customers in your database. Instead of iterating through every variable value that's needed in the database, you can just use one class storage structure and store each one in the custom List generic class.
