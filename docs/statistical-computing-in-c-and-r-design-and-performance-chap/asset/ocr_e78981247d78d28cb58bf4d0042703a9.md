First, Listing B.1 creates multiple figure using the graphics mfrow = c(2, 2) that states we have a 2 x 2 array of figures and that the rows of the array are to be filled in first as new columns. A similar parameter mfrow fills the columns. List of the R parameters can be obtained by using par() on the command line. By using par in way the mfrow parameter is set globally and will remain that unless it is explicitly changed. In particular, parmfrow = c(1, 1) has the effect of changing mfrow back to its original value.

In general global parameter changes may be made in creating a figure. A simple way to return to the original settings is to save the current parameters (e.g., par=par0d) and then restore them using the function par (e.g., par(par0d)) after a plotting has been completed. That is what was done in Listing B.1.

The data that is used in Figure B.2 is created by generating a response vector y from a regression model with slope and zero intercept. The random error of the data is generated from a normal distribution with mean zero and standard deviation .25. The independent variable (or x) values are uniformly spaced over the unit interval. The left-hand plot in Figure is a histogram of the y values that was created using the function hist. The second plot on the first row is a boxplot for the same data created using the function boxplot. Appropriate titles and axis labels have been added to both figures using the main, xlab and ylab arguments.

The first one on the second row is a scatter plot of the x and y vectors where the selected symbol (pch = 4) is x rather than the open circle. The lines has been used to overlay a dashed line with the default width to indicate the true mean for the responses. A legend has been placed on the plot using the legend function with its first arguments specifying the location of the upper-hand corner of the legend.
