To illustrate the construction of a nested iterator class we will again work with a singly linked list class. In addition, we give the class some real utility, it will be implemented as a template.

The first step is to give the Node class structure. This is accomplished in the listing below.

```
template <class Key, class Data>
struct Node {
    Data dataValue;
    Key keyValue;
    Node* Next;

    Node()
    Node(Data data, Key key, Node* next = 0)
        : dataValue(data), keyValue(key), Next(next) {};
```

This is very similar to the definition of the Node struct from Section 9.2.2. The only change is that the int data types for the key and data components have been replaced by the generic template parameters Key and Data
