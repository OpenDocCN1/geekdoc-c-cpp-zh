Let us turn to the case of S4 generics. To see the currently available generic functions use getGeneric() on the R command line. New methods for the functions whose names appear in the resulting list may be created using the setMethod function. For functions that are not currently present, a new generic function must be created by first using setGeneric and then invoking setMethod. Simplified prototypes for setGeneric and setMethod are

```
setGeneric(name, signature)
```

and

```
setMethod(name, signature, definition)
```

with a character string that represents the name of the function, definition a function specification and signature a character array that defines data types for the non-ellipsis arguments of the generic function specified in name.

To illustrate the use of setGeneric and setMethod we will initially focus on a simple "toy" example that will demonstrate the ideas with a minimum of technical detail. suppose that a new two-argument function func is to be introduced into our R session. This is accomplished with the command

```
> setGeneric("func", function(object1, object2, ...)
+ standardGeneric("func"))
```

This establishes for a generic function having three arguments: object1, object2 and the ellipse. The presence of standardGeneric in the body of the function indicates that the incarnation of func will serve as the function for methods dispatch. In it represents a hub or "traffic control center" that directs calls to the appropriate method function. It performs this operation based on the non-ellipse arguments or object1 and object2 in this instance. To remove a generic function from the workspace use removeGeneric: e.g.,

```
> removeGeneric("func")
[1] TRUE
```

This will remove func as well as any method functions it might have. If only a particular method function should be removed, removeMethod can be used.

To see how method dispatch considers the introduction of two new methods from func via

```
> setMethod("func", signature("numeric", "numeric")
+ function(object1, object2) object1*object2)
+ object2 = c("numeric", function(object1, object2))
+ print(paste(object1, object2)))
[1] "func"
```

The signature arguments for the two method functions have been specified using two different but equally valid ways: the first case employs the signature function that returns a list of classes that will be matched in order to the arguments of the hub function while the second just specifies the argument array directly.
