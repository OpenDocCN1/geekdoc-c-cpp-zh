3.40. A simple pairwise swapping algorithm for sorting a one-dimensional array is provided by bubblesort. The primary for loop for this algorithm is given in Algorithm 3.1.

# Algorithm 3.1 Bubblesort algorithm: Sort the array $a = (a_1, \dots, a_n)$

```
for i = 1 to n - 1 do
  for j = 1 to n - i do
    if a_j > a_{j+1} then
      temp = a_{j+1}
      a_{j+1} = a_j
      a_j = temp
  end
end
```
