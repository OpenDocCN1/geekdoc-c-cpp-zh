The previous example illustrates the way to use Newton's method for functions with multiple local minima: try a lot of starting values. A simple way to implement this is to proceed along the lines of Listing 8.9 and generate starting points randomly over the search interval. A program that accomplishes this is given in the list below.

```cpp
double ranNewton(Function& f, double a, double b,
    int nSearch, unsigned long seed, int* nFail) const {
    double start, minTemp, minTemp = b;
    int ier = 0;
    *nFail = 0;
    // instantiate ranGen object
    ranGen RNG;
    RNG.setSeed(seed);
    // pointer for random uniforms
    double* pu = new double;

    // random search begins
    for(int i = 0; i < nSearch; i++){
        // generate a uniform for the starting value
        ranGen.unif(1, pu);
        start = a + (b - a)*(pu);
        minTemp = newton(f, a, b, start, &ier);

        // compare local to global minimizer
        if(f(minTemp, 0) < f(minTemp, 0) && ier == 0)
            minTemp = minTemp;
    } else if(ier != 0)
        ++nFail;
    }

    delete pu;
    return minTemp;
}
```

The premise that ranNewton method is essentially the same as that a to b that are used as starting values for Newton iterations. Random numbers are generated in the method requires a function object and the limits of the search interval if it passes on to our first version of the new method that terminates the recursion when it occurs. It requires a seed to start the random number generator that is obtained through a ranGen object in Listing 8.9. The use of break statements in the Newton method pays dividends by allowing us to simply return to ranNewton when a starting value causes problems for Newton rather than the entire program. A record is maintained through the variable nFail that tells us how many of the searches were ended before they were completed.

There are (at least) two functions that carry out Newton optimization in R: optim and nlm. Both of these functions perform minimization over quasi-Newton type algorithms that use fine difference approximations for the first and second derivatives that appear in the Newton setting. The optim function provides access to several other minimization techniques including simulated annealing that can be found in Section 8.6. It also allows for constraints while nlm does not have that option. As a result, our focus will be on the use of optim.

A simplified version of the prototype for optim is

```cpp
optim(par, fn, method = "L-BFGS-B", lower, upper)
```

The par argument is the starting value to initiate the recursion, fn is the function to be minimized and lower and upper are the bounds to define the entire real line in the univariate case. The method L-BFGS-B is a limited memory, quasi-Newton algorithm that employs the BroydenGS scheme for second derivative approximations and allows for constraints in form of bounds (see, e.g., Byrd et al. 1995 and Zhu et al. 1997). The limited memory aspect is not particularly relevant for our one dimensional setting. In general, the optim function can be used for optimization in higher dimensions where such issues become important.

# 8.5 Maximum likelihood

The technique of maximum likelihood estimation leads to an optimization problem that is unique to statistics. First, let $X_1, \dots, X_n$ be a collection of random variables with joint density (or probability mass function) $g(\theta^*)$ for $\theta^*$ fixed, unknown member of a set $\Theta$ that is a subset of the real line. Suppose now that $X_i$ have been observed in the sense that we have $X_1 = x_1, \dots, X_n = x_n$ with the subscript observed values that are now fixed rather than random. The question is how to "best" extract the information about the parameter $\theta$ from the observed data.

The sample likelihood is defined to be

$$L(\theta) = g(x_1, \dots, x_n).$$$$

It is a function of $\theta$ because $x_1, \dots, x_n$ are now fixed. The maximum likelihood estimator, or mle, of $\theta$ is given by

$$\hat{\theta} = \argmax_{\theta \in \Theta} L(\theta).$$

The motivation for using mle as an estimator is as possible for the case where the components of $X$ are discrete. In that instance of

$$L(\theta) = Prob(X_1 = x_1, \dots, X_n = x_n).$$$$

i.e., $L(\theta)$ is the probability of seeing the observed values $x_1, \dots, x_n$ for a given value of $\theta$. This gives the interpretation of the choice for $\theta$ that assigns the highest probability for the data that was actually collected.

Our treatment of maximum likelihood will detail the special case where $X_1, \dots, X_n$ represent a random sample in the sense of Definition 4.1. Let $f(\theta)$ be the common (univariate) density or probability mass function for some value of $\theta$ in which $g(x_1, \dots, x_n) = \prod_{i=1}^n f(x_i;\theta)$ makes it easier to work with the negative logarithm of the likelihood

$$\ell(\theta) = -\sum_{i=1}^n \ln f(x_i;\theta).$$$$

The value of epsilon can be specified as an argument to optim and defaults to $10^{-7}$ otherwise. The derivative of the objective function can also be supplied to optim as its argument.
