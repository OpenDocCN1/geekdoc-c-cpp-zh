The modification of Algorithm 9.1 is that resize is called when the array becomes full to accommodate another stored entry. The other is the way the start the elements of the array are shifted. The first value of Size is augmented. This allows us to start at the slot with index Size - 1 and work our backward while shifting each entry by one array. An advantage of this approach is that it avoids the temporary storage.

The other side of insertion is deletion. It may be of interest to remove elements from a dArray object and, if Size becomes sufficiently small after a number of deletions, resizing may be of value as a means of conserving memory. Implementation of these operations is the subject of Exercises 9.3-9.4.

```
    int* pa;

    v.insert(1, 9);
    std::cout << v.getSize() << " " << v.getContainerSize() << "";
    std::cout << std::endl;
    for(int i = 0; i < v.getSize(); i++) {
        std::cout << v[i] << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

A dArray object is initialized with a pointer to int that corresponds to two integer objects. Thus the initial Size value should be 2 and the initial value of containerSize should be 4. An additional pair of integers are appended to the array and the values of Size and containerSize are checked. An int is inserted to force a call to the resize method, after which Size and containerSize are checked again and the contents of the dArray object are printed to standard output. It is necessary to sort the elements in a numeric method to obtain, e.g., statistics of interest. We have seen examples of a sorting method in the bubblesort Algorithm 3.1 and the selection sort method of Section 6.4. These sorting schemes are slow and require an order of n^2 operations on average to sort an n-element array. A better option is the quicksort algorithm that requires an average of O(n log n) operations to order the elements.
