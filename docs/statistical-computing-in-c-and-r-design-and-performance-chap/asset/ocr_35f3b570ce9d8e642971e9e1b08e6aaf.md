There are a number of subtle aspects about this program that merit concern. First note that for an object or variable to be referenced in the private clause it must first been declared or initialized. The reason is that Opt, myRank, myMin, myLow and myUp were declared in the serial section of Listing 11.2 before the parallel construct. Once a parallel block is encountered each thread receives its own versions of all the private variables and objects. In case of objects, thread-specific variables are created using the default class constructor. As a result, an object must come from a class having a default constructor for it to be used in a private clause. On the other hand, the default destructor is called at the end of a parallel block and do not persist throughout the program or carry over to other regions.

The pmin pointer in Listing 11.2 provides access to many locations in shared memory as there are the threads then perform their optimization tasks and write the outcomes into distinct locations by their thread number. The scope of pmin is all of main which continues to exist after the end of the parallel block allowing minimum element to be declared as a global minimizer.

For minimization purposes each thread should have its own Opt and Functor class and object must be initialized with the same values. However, arise if we try to assign a pre-initialized object as private than one that has merely declared. The objects for threads other than the master (or thread number 0) are created using the default constructor which means they will be initialized correctly. On the other hand, if an object of type Optim and Functor were simply declared prior to the parallel region there would be no way to initialize inside the region. The firstprivate clause that was used here provides the solution to such difficulties. In general, a statement of the

```
#pragma omp firstprivate(variableName)
```

will cause each thread to receive their own copy of the variable varName with the value that it had prior to the beginning of the parallel block. For Listing 11.2 of the firstprivate clause with the Opt class object ensures every thread receives an independent object with the number of iterations it nEvents for each thread (cf. Listing 8.7).
