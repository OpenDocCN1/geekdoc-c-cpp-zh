# 6.3 Generic methods

As compared to the C++ setting, functions are linked to a particular class and ac-cess only through a class object, functions in R may extend across multiple classes. This
allows us to write a function that operates on objects from a given class and subsequently
extend function to work on and produce different types of output for some
other class. In this generic or "template" functions are created with the same name that
ake arguments from different classes. This section presents details on how functions
are created in the R language. Since R comes with a number of predefined generic func-tions, there are basically problems that must be addressed: how to extend one of the
defined generics to a new class and how to define a new generic function.

As noted at the beginning of the chapter there are two ways to create generic functions
in R: the S3 and S4 systems. The syntax for creating and extending functions under the
systems is quite different. Then, the first step in extending an existing function is to
ascertain whether it is of the S3 or S4 variety. One way to make a determination is through
use of the isS4 or isGeneric functions that returns TRUE when applied to the names of
4 generic functions. In the case of the functions show and coefficients discussed in
Appendix B this produces

ells us that show is S4 and coefficients is S3. An alternative and more informative
strategy is to look at a function's "listing" that is returned by entering the names of
command line. In the case of show and coefficients this generates the output

```
> isGeneric("show")
[1] TRUE
> isGeneric("coefficients")
[1] FALSE
> show
```
