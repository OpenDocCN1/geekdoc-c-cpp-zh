
# SOLVING LINEAR EQUATIONS

When a diagonal of a square, upper-triangular matrix is zero, this means that the matrix is singular. In that case, there is no unique solution to the linear system. The calling Matrix object as well as the right-hand side Vector object should not be altered by backward substitution. To account for this, I have made a constant member function and the method's argument is passed as in *constant* reference.

Lower-triangular systems can be solved similarly to the upper-triangular case. Specifically, suppose the system is $Lb = c$ with $L$ lower-triangular matrix having $l_{ij} = 0, j > i$. Then, $b_1 = c_1/l_{11}, b_2 = (c_2 - l_{21}b_1)/l_{22}$

```
$b_t = (c_t - \sum_{j=1}^{t-1} l_{tj}b_j)/l_{tt}
```

for $t = 2, \dots, n$. The member function **forward** for class *Matrix* that implements this is given in Appendix D. In general the process of solving (7.1) can be formulated as constructing LU decomposition of $A$ where $A = LU$ for $L$ and $U$ lower and upper-triangular matrices, respectively. Given such a decomposition for $A$, $b$ can be computed using forward and backward substitution. Specifically, $Lz = c$ is first solved by forward substitution and $b$ is calculated from $Ub = z$ via backward recursion.

## 7.2 Gaussian elimination

The results in the last section provide the means for solving any upper-triangular system. More generally, this ensures that a solution can be obtained for any linear system that can be transformed to upper-triangular through a series of row operations: i.e., by left multiplication of $A$ and $c$. This can be accomplished with iterated Gauss transformations. Let $x = (x_1, \dots, x_n)^T$ be a vector with $x_k \neq 0$ and the Gaussian matrix

$$\begin{bmatrix} 1 & \dots & 0 & 0 \\ \vdots & \ddots & \vdots & \vdots \\ 0 & \dots & 1 & 0 \\ 0 & \dots & -x_k & 1 \end{bmatrix}$$

Then, one may check that $T_k(x) = (x_1, \dots, x_k, 0, \dots, 0)^T$. With this mind, the system (7.1) can be transformed to upper-triangular via the process described in Algorithm 7.1. The algorithm begins by initializing a work $G$ as the matrix $A$ for the linear system. Similarly, a right-hand side vector $h$ is initialized to $c$. Gauss transforms are then sequentially applied to the vector and work matrix until the system is upper-triangular. At that point the solution is available by backsolving. The LU decomposition of a matrix $A$ exists provided that all the principal minors of $A$ are nonzero. A more general factorization of $A$ as $LUP$ with $L$ lower, $U$ upper triangular and $P$ a permutation matrix always exists. An algorithm for computing LUP decomposition can be found in Chapter 2 of Cohen et al. (2001).

# NUMERICAL ALGEBRA

### Algorithm 7.1 Gauss sweep
```
G = A, h = c
for k = 1:(n-1) do
  h = T_k(G)
  G = T_k(G)
end
return b
```
An R function that was created to produce a Gauss transform for a given vector of input has the designation

```
gTran <- function(x, k) {
  n <- length(x)
  T <- diag(1, n)
  e <- vector(mode = "numeric", length = n)
  temp <- vector(mode = "numeric", length = n)
  temp[(k+1):n] <- -x[(k+1):n]/x[k]
  T <- T + temp*%t(e)
}
```
This function creates the transform $T_k(x)$ using the fact that $T_k(x) = I + v_k e_k^T$, where $e$ is an $n \times 1$ vector of all zeros except for a 1 at its kth component. The R function `diag(a, n)` is used to create a square matrix with all diagonal entries equal to $a$. To illustrate Algorithm 7.1, first, a matrix $A$ and right-hand side $c$ are generated by

The R language comes equipped with three basic functions for solving linear systems: `backsolve`, `forward`, and `solve`. For a general, nonsingular square matrix $A$, `solve(A, c)` returns the solution of $Ab = c$. The computations are carried out using a routine from the LAPACK numerical package that performs Gaussian elimination. If `solve` is now applied to the original matrix $A$ and right-hand side vector $c$ from our example, we obtain a result that agrees with the result from the Gauss transform. In addition to solving systems when no right-hand side is specified, `solve(A)` returns the inverse of the matrix. The example serves to illustrate a case where the Gauss transform works well.
