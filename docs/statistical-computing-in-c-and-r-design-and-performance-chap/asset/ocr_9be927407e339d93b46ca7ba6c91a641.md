There are instances where the defaults that new supplies for a given class (or the way they propagate into classes that are constructed from user-defined classes) may not be satisfactory. In the case of C++ a cure for such default arguments to a constructor which is in R as well. But, R provides another means to accomplish this using prototype function when the class is first created via the setClass function. For example, in our regr the X matrix could be specified by defaulting to a 1 x 1 "matrix" with a single element, the y and b slots could be set as 0 and the intercept could be set to 1, 1. This latter will make the inclusion of a constant term the default fitting behavior. This can be accomplished with

```
setClass("regr", representation(X = "matrix", y = "numeric",n+ b = "numeric", intercept = "logical", prototype(X) =
+ matrix = (0, 1, 1, y = 0, b = 0, intercept = TRUE))
```
