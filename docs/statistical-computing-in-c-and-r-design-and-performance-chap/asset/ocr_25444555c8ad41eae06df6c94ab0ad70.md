The fitting of linear smoothing splines has been implemented as a C++ class. The header file for class Lin appears in Listing 7.1.

# Listing 7.1 linss.h

```
//linss.h
#ifndef LINSS_H
#define LINSS_H

#include "vector.h"
#include "matrix.h"

class Linss{
    int n;
    Vector x, y;
    Matrix lhsMat(double lam) const;
npublic:
    Linss(const Vector& X, const Vector& Y);
    Vector smooth(double lam, double* GCV) const;
};
#endif
```

The members are two Vector objects that contain the values for the response and independent variable and an integer that represents the number of observations. The method smooth will return the linear smoothing fitted values as a Vector object for a specified value of the smoothing parameter. The GCV criterion is also evaluated and returned in a pointer that passes in from the GCV class. As the Linss class requires the Vector and Matrix class by value, the header files for both classes must be included in the Linss class header.
The method definitions for class Linss take the form

# Listing 7.2 linss.cpp

```
//linss.cpp
#include "linss.h"

Linss::Linss(const Vector& X, const Vector& Y){
    x = Vector(X);
    y = Vector(Y);
    n = x.rows();
}

Vector Linss::smooth(double lam, double* GCV) const {
    Matrix G(n, n, 0);
    Matrix H = lhsMat(lam);
    Vector fit = H.bandChol(y, G, 1);
}
```
