```
> set.seed(123)
> hT <- new.env(hash) = TRUE, parent = emptyenv(), size = 3
> env.profile(hT)
$size
[1] 3

$nchains
[1] 0

$counts
[1] 0 0 0

> assign("x", 1, envir = hT)
> assign("mat", matrix(rnorm(16), 4, envir = hT)
> assign("expr", expression(1 + pi), envir = hT)
> assign("intSeq", 1:5, envir = hT)
> env.profile(hT)
$size
[1] 3

$nchains
[1] 2

$counts
[1] 2 2 0

> eval("expr", envir = hT)
[1] 4.141593
> hT["intSeq"]
[1] 1 2 3 4 5
> hT$intSeq
[1] 1 2 3 4 5
> rm("intSeq", envir = hT)
> exists("intSeq", envir = hT)
[1] FALSE
```

First, an empty hashing table hT is created and examined using the env.profile function. The output from env.profile tells us that hT has three buckets (i.e., size is 3) with no chains (or linked lists) and no elements in any of the buckets as indicated by the values of counts. Next, four objects are inserted into hT using assign and its profile is examined. The hash table now has two chains or linked lists with two elements in each bucket and a third bucket that empty. The indexing operator [] and extraction operator $ provide alternatives for accessing elements in an environment as illustrated by retrieving the expression and sequence objects from hT. Note that the "index" used with [] must be the object's name. Finally, the sequence object is deleted from hT using rm and exists to check that the deletion has been successful.
