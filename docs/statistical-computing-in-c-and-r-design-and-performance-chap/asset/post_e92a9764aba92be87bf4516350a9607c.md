
# COMPUTER REPRESENTATION OF NUMBERS

Since transistors have only two states it is not surprising that the choice of base for computer arithmetic is binary or 2. The base version of (2.1) is the **binary expansion**

```
$k = \sum_{j=0}^{m} b_j(2)^j \quad (2.2)$
```

with $m$ non-negative integer for $b_m \neq 0$. The $b_j$'s coefficients can take on only the values 0 or 1. Returning to our example, it can be seen that 

```
$193 = 1*(2)^7 + 1*(2)^6 + 1*(2)^0.$
```

This corresponds to (2.2) with $m=7, b_7=b_0=1$ and $b_5=\dots=b_1=0$.nThe fact that the coefficients of a binary number are zeros and ones means that it can be represented as a sequence of zeros and the ones with the ones corresponding to the $b_j$ in (2.2) and their location in the sequence identifying the associated power of two. The slots hold the coefficients in the sequence are called *bits* with a sequence of eight bits being termed a *byte*. For the number 193 this translates into representation such as

| $2^7$ | $2^6$ | $2^5$ | $2^4$ | $2^3$ | $2^2$ | $2^1$ | $2^0$ |
|---|---|---|---|---|---|---|---|
| 1 | 1 | 0 | 0 | 0 | 0 | 0 | 1 |

That is, in binary 193 can be represented exactly in one byte by the value 11000001.\nThe connection between machine memory and binary arithmetic becomes complete once bits and bytes are identified with individual transistors and blocks of transistors. Represent a number in its binary representation is physically created by allocating a block of memory (e.g., a group of contiguous transistors), identifying the transistors in the block with a power of 2 from its binary representation and turning on those transistors that correspond to powers of 2 have unit coefficients. To elaborate the point a bit, the first, seventh and eighth transistor would be turned on and the other five would be turned off. Note that it would take eight bits/transistors to store 193 and any fewer would not be capable of doing the job.\nJust as 193 cannot be stored in anything less than eight bits there is a limit to the number of bits. For example, the largest number that can be stored in one byte is

```
$$\sum_{j=0}^{7}(2)^j=2\sum_{j=0}^{7}2^{-j}=2^7\frac{1-(1/2)^8}{1-(1/2)}=255. \quad (2.3)$$
```

More generally the largest number that can be stored in $m$ bits is $2^m - 1$ (Exercise 2.1).

## 2.2 Storage in C++

Let us consider the ideas about number representation from the previous section are implemented in C++. While investigating this issue we will also introduce some of the language features that will allow us to write, compile and execute C++ programs.\nThe amount of storage that is allocated to different data types can be determined using the *sizeof* operator that C++ inherits from C. Listing 2.1 below demonstrates the use of this operator to determine information about storage space, in bytes, for some of the primitive data types discussed in the previous section.

# STORAGE IN C++

Listing 2.1 storageSize.cpp

```cpp
//storageSize.cpp
#include <iostream>

using namespace std;

int main() {
    cout << "The storage allocated for a char is " << sizeof(char) << " bytes" << endl;
    cout << "The storage allocated for an unsigned short is " << sizeof(unsigned short) << " bytes" << endl;
    cout << "The storage allocated for an integer is " << sizeof(int) << " bytes" << endl;
    cout << "The storage allocated for a long integer is " << sizeof(long) << " bytes" << endl;
    cout << "The storage allocated for an unsigned long integer is " << sizeof(unsigned long) << " bytes" << endl;
    cout << "The storage allocated for a float is " << sizeof(float) << " bytes" << endl;
    cout << "The storage allocated for a double is " << sizeof(double) << " bytes" << endl;
    return 0;
}
```

Now this is a very simple program, but it illustrates some of the syntax that will be seen again. At the outset there is a comment (signed by //) that uses the name of the program, a practice we will adhere to the book. The use of two dashes causes the compiler to ignore the succeeding text on a line. Had we wanted a comment that ran more than one line it have been accomplished using /* at the start of each line or by commenting multiple lines by */.\nThe comment in Listing 2.1 is followed by the statement #include <iostream> which is a directive to the preprocessor to include the input/output classes in the C++ Standard Library. The actual code for this has already been compiled and will automatically be linked with our during the compilation process. There are many other tools available from this library just for input and output. But, as one example, the use of #include <cmath> provides access to many mathematical functions such as the log, trigonometric functions, etc.\nThe next statement in the code, using namespace std; ensures that there will be no ambiguity in referring to functions and classes that have any of the specific names that have been given to those in the C++ Standard Library. Specifically, Listing 2.1 will use the cout and the output manipulator endl that are declared in the iostream header file. The names of these operators are made globally available with using std; omission of this line would have caused the compiler to generate an error such as

```
storageSize.cpp: In function 'main()'
storageSize.cpp:6: error: 'cout' was not declared in this scope
storageSize.cpp:7: error: 'endl' was not declared in this scope
```

Basically, a namespace is a collection of definitions of variables, functions and other components associated with a library or program that have been gathered together for various reasons. Among other things namespaces provide a mechanism for reusing desirable names for functions and classes other context. It is possible to bypass the directive using use of the scope operator :: as discussed in Section 3.8. For now we will travel the simpler path of stating up front that all references are to the Standard Library. We come now to the start of the program signaled by the appearance of the word main. Every C++ program must have one and only one **main function**. It serves the purpose of directing the flow of activity within a program. While there may be many functions and objects whose actions are intricately laced throughout a program, wherever takes place must have been initiated by directions main. The body of main (as well as of any function) is enclosed by the matching braces { }.

In terms of content, main in Listing 2.1 is a clear of explanatory text to be printed with values that are returned by the *sizeof* operator. An application of *sizeof* to a particular data type (supplied as an argument) returns the number of bytes that are used for its storage.

The symbols << and >> are the output and insertion operators that work with the standard input and output objects cin and cout, respectively, that relay information to and from (typically) a. The output manipulator endl provides the facility to chain together input/output operations. The output manipulator endl that appears at the end of each output line produces a carriage return (or starts a new line) and flushes (or clears) the output buffer. You will see the effect of this when we look at our program. Note that each line of code in main is ended with a semicolon.

The final line of the program is return 0; In general the return statement has that one might effect; it returns to a calling function. In the case of how it is used here in main, it transfers control to the operating system. An exit integer with a value of 0 is returned upon completion of the program. The fact that 0 is viewed as an integer is a consequence of the *int* designation that immediately precedes main. Is true more generally in that a function must return a value of the same type that appears in its definition with the exception of main functions and functions with return void. The return statement could also have been omitted from Listing 2.1 without compilation errors. The void return type will be discussed.

The "storage size" source code was saved as storage.cpp. The cpp file extension is one of the permissible options for the compiler that is available in Unix environments. The others are .cc, .cxx and .C. To run it, we first compile

```
$ g++ -Wall storageSize
```

The compilation begins with g++ that invokes the GNU compiler. This has the effect of transforming the input fileSize.cpp into machine language. In this, there were two compiler options that were used: -Wall on all of the most commonly used warnings while -o allows us to specify the name of the executable, as storageSize in this instance. Without the -o option the executable would be a.out by default; the a.out is an abbreviation of "assembly output"

To run and load the program name of the executable (i.e., storageSize) is entered on the command line preceded by the ./ modifier that informs the shell where to look for the executable. In this particular instance, the result is
