The value of iA is set on line 17 of Section 7.6 where B constructor employs an initializer list that prefers the constructor with a colon and a base class constructor. We discussed initializer lists in Section 3.8.3 in the context of const members. In the inheritance setting initializer lists serve the purpose of forcing the members of the inherited base class prior to the construction of any that are unique to the derived class. This is essentially the only way derived objects can be initialized.
