The vectors of sample means, variances and sample sizes are extracted exactly as in Listing 5.3. The difference in the columns that would be used in comparisons are provided by all pairs of values from the first two arguments to outer. Since both of these are integer arrays 1:ncol(A), all possible pairwise comparisons will be conducted. This is wasteful in terms of computational effort and also returns an array that contains redundant entries. The latter problem is easily solved using the upper.tri function that takes a matrix argument and returns an array of the same dimension with above diagonal entries set to TRUE and all other entries set to FALSE. The lower.tri function performs a similar operation where only the below diagonal entries set to TRUE. The output from upper.tri is given as an argument to the subsetting operator applied to a matrix of the same dimension, the outcome will be an array consisting of just the upper diagonal elements of matrix.

The function Vectorize provides a way of creating a new function that will behave as
if were being used. It has somewhat simplest that we use form

```r
Vectorize(FUN, vectorizeArg)
```

where FUN is the function to be vectorized and vectorizeArg is a character
vector the names of the arguments that will be vectorized. The default value for vectorizeArg is all the arguments of FUN. To conclude this section, we will use this
approach to create a function that performs means comparisons using R's t.test function.


For two-sample problems both the x and y numeric vector arguments can be supplied

to TRUE, the statistic will be the value of a pooled t-test statistic such
as the ones we have been using in this and the previous section.
