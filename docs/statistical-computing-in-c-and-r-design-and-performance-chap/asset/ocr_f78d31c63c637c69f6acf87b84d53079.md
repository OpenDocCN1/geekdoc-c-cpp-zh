In general, for a vector object v the statement

```
v.resize(k);
```

will change its number of elements from v.size() to k. If the container has more k
objects, the first k elements are retained and the others are deleted. If, as is the case in
Listing 10.2, k (i.e., 3) is larger than the current value of v.size() (i.e., 0), the contents
of v are expanded by an additional k - v.size() objects created with their default class
constructor while the existing content of v remains unchanged. Thus, for our case where v
contains vector objects, the command

```
v.resize(nrows);
```

will expand the vector object v to have nrows slots holding vector objects that have all
default length of 0. A similar method is obtained from

```
v[i].resize(ncols);
```

```
v[0][0] = 1 v[0][1] = 2

v[2][0] = 3 v[2][1] = 6
```

Finally, let us discuss copying of one vector object into another. If v is a vector<>
object for some class T, the simplest way to create a new vector<> object that
contains the content of v is with the class constructor using syntax like

```
vector<> v1(v);
```

This produces an independent copy of v in the vector<> object v1. Alternatively, to copy
vector object or, more generally, some portion of one into another, existing
vector object the assign method for the vector class can be used. For example, the
result was obtained with the copy constructor is produced by

```
vector<> v1;
v1.assign(v.begin(), v.end());
```

Our choice of the range of v.begin() to v.end() is arbitrary and a subset of the elements
of v can be copied by replacing its iterators that point to one other location in
vector that is being copied.
