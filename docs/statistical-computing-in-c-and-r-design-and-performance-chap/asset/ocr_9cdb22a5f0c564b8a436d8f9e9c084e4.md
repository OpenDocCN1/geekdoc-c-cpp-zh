The code in range is relatively straightforward apart from some bookkeeping that is needed to deal with production of numbers rather than singleton. An indicator or flag iAccept is set to 0 or 1 depending on whether or not there is still one of the pair of numbers available to avoid using the uniform PRNG than necessary. The decision variable in the loop nFill will be augmented to make sure that it is incremented when a new pair of numbers is generated and as a remaining value from a previous pair is added to the sample.

The WHBM class was used with seeds 123, 456 and 789 to produce 500 standard normal random deviates. These values were imported into R as a numeric vector named nData The histogram shown in Figure 4. The histogram exhibits some of the bell shape that would be expected from normal data.

Kernel estimators provide alternatives to histograms that show estimates of the parent distribution for a set of data. If $X_1, ..., X_n$ are observed sample values, such estimators have the form

> $f_n(x) = \frac{1}{nh} \sum_{i=1}^{n} K(\frac{x-x_i}{h})$

where $K$ is a density function and $h > 0$ is the bandwidth that controls the amount of averaging or smoothing that is performed on the data. For kernel estimators the bandwidth must be chosen with care and there are a number of bandwidth selection methods that can be used for this purpose.

Figure 4.4 also shows a kernel density estimator to fit the data using the R `density(nData, kernel = "gaussian")`

This estimator employs a "rule-of-thumb" bandwidth nrd0 for the normal distribution discussed, for example, in Silverman (1986). There are a number of other bandwidth choices that can be perused by the help file for bw.norm
