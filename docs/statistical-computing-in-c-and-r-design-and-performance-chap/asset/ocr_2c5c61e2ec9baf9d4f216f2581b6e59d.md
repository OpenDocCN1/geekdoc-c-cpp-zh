# R FOR STATISTICAL ANALYSIS

```
sample(x, size, replace = FALSE, prob = NULL)
```

The x argument is the array to be sampled while size is the number of elements to select. If replace is set to TRUE, sampling will be done with replacement and is carried out without replacement otherwise. The prob argument can be a vector of probabilities for selecting the elements of the null or empty object. If no value is specified for prob the selection is made with uniform probability. To demonstrate this idea

```
> set.seed(123)
> sample(letters, 4)
> "h" "e" "j" "u"
> sample(LETTERS, 10, replace = TRUE)
[1] "Y" "B" "N" "X" "L" "Y" "L" "R" "O"\1 3 3 1 1 3 3 2 3
> sample(c(1, 2, 3), 10, replace = TRUE, prob = c(.1, .3, .6))
[1] 2 2 3 3 3 1 2 2
```

This example used the built-in R arrays letters and LETTERS that contain the lower- and upper-case letters of the alphabet.
