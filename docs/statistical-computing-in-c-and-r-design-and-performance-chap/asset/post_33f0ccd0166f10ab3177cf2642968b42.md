A simple alternative to the golden section method is to partition the search interval into smaller subintervals (or some other minimization algorithm) to each of the subinterval. Of course, the success of this approach will depend on the partition and could fail if some of the subintervals contain more than one local minimum. Another similar, but distinctly different, $u1, u2$ are generated from the uniform distribution over the search interval $[a, b]$ and a golden section search is conducted over the interval $[min(u1, u2), max(u1, u2)]$. The process is repeated until some stopping criterion is met. This is the approach that we considered here.

//compare local to global minimizer
if(newMinTemp < f(minTemp)){
 minTemp = newMinTemp;
}

}

delete[] pu;
return minTemp;
}

Linss::gcv(double lLam) const {
