The presence of standardGeneric in the description of show designates as an S4 function
whileMethod signifies that coefficients are S3. The additional information obtained
from the listings is that show has a single argument object which coefficients have arguments
object the catchall ellipsis. Functions that are written to extend show and
coefficients to reg objects have matching arguments. Functions that provide
such extensions are called method functions.

To extend an existing S3 function func to a new class one need only create a
named func myClass. For example, consider the S3 coefficients function that
currently has the method function

```
> methods(coefficients)
[1] coef.Arima* coef.aov coef.default* coef.listof* coef.nls*
Non-visible functions are asterisk
Warning message:
In methods(coefficients):
 generic function 'coefficients' dispatches methods for generic 'coef'
```

The warning message tells us that coefficients will be dispatched on calls to
functions that work for coef. In the beginning of their names. Thus, a version of coefficients
that will work for reg objects is simple

```
coef.regr <- function(object)
object@
```

which now serves as an accessor function for the vector of regression coefficients. With
coef.regr in an application of methods now produces

```
> methods(coefficients)
[1] coef.Arima* coef.aov* coef.default* coef.listof* coef.nls*
[6] coef.regr
Non-visible functions are asterisk
Warning message:
In methods(coefficients):
 generic function 'coefficients' dispatches methods for generic 'coef'
```

revealing that our new function has been successfully installed in the family of method
functions for coefficients. An application of coef to the regr object regCar from the previous section gives the expected result: viz,
