The final line of code illustrates how to unload a library that has been linked to an R session. We noticed that R has an API that allows functions from the R math library to be used in our C++ code. Our X class used the R function dnorm for the normal cdf to illustrate this feature.

The R API becomes available by including the Rmath header file that contains the prototypes for the available functions. A technique for deciphering the meaning of these prototypes was described in Section 4.9. Briefly, one matches the arguments in the prototype to the ones for function in its corresponding R help page. In the case of the dnorm function this approach revealed

+   a) the first and third arguments are the evaluation point for the cdf,
b) the second and arguments are mean and standard deviation, respectively,
c) choosing 1 and 0 for the fourth and fifth arguments will return values that are lower tail probabilities.

To use a random number generator from the R API there are additional functions that must be used: GetRstate and PutRNGstate. They retrieve the current value of the seed from R and return the new value after the generator has been used. As result, GetRstate must be called before invoking the generator and PutRNGstate is called once the generator is no longer required. The idea is illustrated by

The rngFunc calls the R function for generating pseudo-random numbers from a normal distribution. The arguments for the mean and standard deviation are passed in pointers to double and a pointer to double, x, is provided to store the numbers that are generated. Note that the memory for x must be allocated in R and failure to do so or a failure to allocate memory will produce unpredictable results. The actual random numbers are generated in a loop that is sandwiched between the requisite calls to GetRstate and PutRNGstate.
