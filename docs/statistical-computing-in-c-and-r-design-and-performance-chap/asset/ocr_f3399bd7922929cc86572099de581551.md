The updating feature is realized by, e.g., making a change to powerClassDriver.cpp. This will produce

```
$ make -f powerClass.mk
g++ -c -Wall powerClassDriver.cpp powerClass.o -o powerClass
g++ -Wall powerClassDriver.o powerClass
```

Make only copies the one object file needed to be changed as the result of the editing. Making one change that if, instead, powerClass had been changed, then all the object files would have been recreated because both powerClassDriver.cpp and powerClass.cpp have been designated as depending on powerClass.h in powerClass.mk. More detail on the utility can be obtained from Stallman, et al. (2004).

# 3.8 Miscellaneous topics

In this section a few unrelated concepts will be examined that will arise in subsequent developments. Let us begin with the discussion of a slightly simplified version of the class that derives from the C++ implementation of the C struct type.

# 3.8.1 Structs

As mentioned at the beginning of Section 3.7, in C it is possible to construct data types called structs that are similar to classes in the sense that they have data members. Unlike classes the C version of a struct has no methods (or member functions) and the data members are public. For compatibility reasons, in C++ a struct is a class where all data members and methods are public (rather than private).

The code below illustrates the construction and use of a struct.

```
//structEx.cpp
#include <iostream>

using namespace std;

struct X{
  int K;
};

int main(){
  X x;
  x.K = 1;
	cout << x.K << endl;
	return 0;
}
```

If we run this code, it simply writes the integer 1 to the shell. What this demonstrates that the member K of the X object can be accessed directly from a calling program (or in this class). One should check that this will no longer be the case if struct X is replaced by class X in this listing.
