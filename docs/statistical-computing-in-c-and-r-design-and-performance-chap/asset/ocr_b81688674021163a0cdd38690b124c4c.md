4.36. Consider the problem of computing the integral

```
$W = \int_{B} f(u_1, \dots, u_d) du_1 \dots du_d$
```

of square integrable function of d variables over a subset B of the unit d-cube $[0,1]^d$. Let $U_1, \dots, U_n$ be a random sample of size n from the uniform distribution over $[0, 1]^d$. Then, a Monte Carlo estimator of W is

```
$$\widetilde{W} = n^{-1} \sum_{i=1}^{n} f(U_i)I_B(U_i)$
```

with $I_B$ the indicator function for set B: i.e., $I_B(u)$ is 1 or 0 depending on whether or not $u \in B$.

+   a) Show that $E[\widetilde{W}] = W$ and that $Var(\widetilde{W}) = ||\widetilde{W}||^2/n$

```
$||\widetilde{W}||^2/n = \int_{B} (f(u_1, \dots, u_d) - W)^2 du_1 \dots du_d$.
```

+   b) A stratified sampling approach to estimation of $W$ partitions into $k$ contiguous, nonoverlapping subsets $B_1, \dots, B_k$ with $U_{i,j} \in B_j$. Random samples $U_{i,j}, j=1,\dots,k$ are taken from uniform distributions over each set in the partition that produce the integral estimator

```
$$\widetilde{W}_S = \sum_{j=1}^{k} n_j^{-1} \sum_{i=1}^{n_j} f(U_{ij})I_{B_j}(U_{ij})$.
```

Show that $E[\widetilde{W}] = W$ and that $Var(\widetilde{W}) \leq Var(W)$.
