
## B.1 R as a calculator

R is typically used in an interactive mode through command line input. When employed in this manner it is possible to realize an effect much like an advanced scientific calculator through creation and execution of expressions involving the operators and functions that are available in the language. In this section we will examine R from "calculator" perspective.

First, R can process algebraic command line input involving the operators

- - for binary minus,
- + for binary plus,
- * for binary multiplication,
- / for binary division,
- ^ for exponentiation,
- %% for modulus,
- %/% for binary integer division,
- abs for absolute value,
- floor for the next smallest integer and
- ceiling for the next largest integer.

Expressions can also employ standard mathematical function such as

- sqrt for the square root function,
- cos for the cosine function,
- sin for the sine function,
- tan for the tangent function,
- exp for the exponential function,
- log, log10 and log2 for the logarithm for base e, base 10 and base 2
- gamma for the gamma function.

This makes it easy to perform insightful calculations such as

```
> a <- 2*pi
> (log(exp(cos(a))) + sin(log10(10^pi)))/cos(0))
[1]
```

Most of the mathematical operations and functions have been vectorized in the sense of working with matrix and vector arguments. In such cases, the function is applied to an array on element-wise basis. The code snippet demonstrates this by creating a vector of four integers and computing their values 7.

```
> x <- vector(mode = "integer", length = 4)
> x[1] <- 17
> x[2] <- -43
> x[3] <- 11
> x[4] <- 107
> x%%7
```

The example illustrates one of the most powerful features of R: its facility for subscribing arrays and lists. Subscribing is accomplished with [] for both arrays and [][] with lists. The difference between the two in this latter instance is that [] returns a sublist while [[]] returns the actual object held in the list. As seen from the example, when used with a one-dimensional array an integer argument to [] returns the array's element whose index agrees with the argument.

A vector in R is converted to a matrix (or, more generally, a multi-dimensional array) by specifying its dim attribute. In the case of our previous integer vector this produces

```
> dim(x) <- c(2, 2)
> x*x

[,1] [,2]
[1,] 289 121
[2,] 18449 11449
> (x*x)[1, 1]%7
[1] 2
> (x*x)[2, 2]%7
[1] 2
```

First, the vector is converted to a 2 ×2 matrix by setting both the row and column arguments for dim(x) to two. The vectorization feature of multiplication operator * is illustrated with this matrix. Next, subsetting operations are used on the matrix in conjunction with the modulus and multiplication operators. In general, [] takes two comma separated arguments for a matrix that correspond to a row and column index, respectively. The x*x[1, 1] syntax, for example, gives us the left-hand element of the case all or row entries. Either the column or row arguments for [] may be left unspecified in which the subscript is specified. The last expression using (x*x)[, 2] illustrated this feature.

Subsetting operations are not restricted to positive integers for arguments. Negative integers can be used to delete rows or columns whose logical values can be used to pick out elements that meet some specified criteria. To demonstrate this feature we employ the matrix

```
> x
[,1] [,2]
[1,] 17 11
[2,] -43 107
```

to produce the results

```
> x[-1,]
[1] -43 107
> (x > 0)
[,1] [,2]
[1,] TRUE TRUE
[2,] FALSE FALSE
> x[(x > 0)]
[1,] 17 11
> x(x[,1] > 0)
[1] 11
```

The use of [] indicates that the row with index 1 is to be deleted. The result is a “matrix” consisting only of the second row of x. The next command reveals that a logical expression applied to a matrix returns a matrix of the same dimension with entries that are either TRUE or FALSE depending on or not they satisfy the condition. In this particular case, the condition is that an element be positive and the resulting matrix of logical values has FALSE for the (2,1) element with the value -43. The utility of this is realized when we use the logical array as an index for the original matrix to produce a subset of the matrix elements corresponding to those entries that evaluate to TRUE. Similar operations can be performed with specific rows or columns of a matrix. In example, 1] evaluates TRUE for the first column with the consequence that the first row is selected. Selection of 2 for the column index returns the (1, 2) matrix element. A discussion of R subscribing is provided by Spector (2008).

When applied to an array max and min functions will return the largest and smallest element. In the case of our matrices this produces

```
> max(A); max(B)
[1] 0.9568333
[1] 0.942698
> min(A); min(B)
[1] 0.0455565
[1] 0.0420593
```

Note the use of semicolon to allow more than one element to be entered from a single prompt. Both the seq and c functions can be used to specify array or column indices. As demonstrated above with the > operator, logical operators can also be used in this capacity. R logical operators include

- ! for not,
- < and >= for logical less than,
- == for logical binary equal,
- & for logical binary AND,
- | for logical binary OR.

Like any good scientific, R has a sum for adding up a group of numbers. But, it is more powerful than its hand-held relative that it can carry out calculations like

```
> sum(seq(-pi, pi, by = .5))
[1] -1.840704
> sum(A)
[1] 8.545771
```

When used in the apply function sum can produce marginal row or column sums for an array. In general the apply function has the form

```
apply(X, MARGIN, FUN)
```

where X is an array, FUN is the function to be applied to the rows or columns of the array. Using this idea with our previous matrices produces results like

```
> apply(A, 1, sum)
[1] 2.832886 4.150658 1.562227
> apply(B, 2, sum)
[1] 1.187972 2.217194 2.327580 1.908302 1.030415
```

There is nothing special about sum in this example that other choices for the FUN argument not work equally well. For example,

```
> apply(A, 1, min)
[1] 0.2875775 0.5726334 0.0455565
> apply(B, 2, max)
[1] 0.8989250 0.9545036 0.9942698 0.7085305 0.5941420
```

Other calculator-like features of R are the choose factorial functions that calculate the binomial coefficients and factorials. The choose function has two arguments for the number of trials and number of successes in a binomial experiment where factorial takes one integer argument. An illustration of a typical calculation is

```
> choose(10,3); factorial(5)
[1] 120
[1] 120
```
