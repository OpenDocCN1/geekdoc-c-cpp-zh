# NUMERICAL LINEAR ALGEBRA

This program uses the one-dimensional pointer based constructors to create both a and two-dimensional array. In accessing the file information that will fill the arrays it is assumed that the storage format progresses across the n columns then the rows with the elements of the one-dimensional array residing in the last column. The pointers that provide access to the data are used to create the Array2D object and Array1D object that are printed using overloaded output insertion operators.

Listing 7.9 illustrates the use of an overloaded + operator for matrix addition. There are also overloaded versions of =, -, +, *, /, and /. The *, /, and / carry out their respective computations on an element-wise basis. In particular, this means that does not produce matrix multiplication. This is instead of the mattmult function illustrated in the program. It should be noted that the Array1D and Array2D constructors create shallow copies that are essentially just an alias for the original; that altering the changes the original. To obtain an independent copy it is necessary to use the copy method for the class. For example.

```
Array2D B = A.copy();
```

produces an Array2D object whose memory is independent of object A.
