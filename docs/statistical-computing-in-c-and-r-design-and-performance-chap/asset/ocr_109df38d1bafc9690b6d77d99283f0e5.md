# Algorithm 5.1 n-step bisection algorithm

```
a = 0, b = 1
for j := 1 to n
  m := (a + b)/2
  if f(a)f(m) <= 0
    a := a, b := m
  else
    a := m, b := b
  end if
return (a + b)/2
```
