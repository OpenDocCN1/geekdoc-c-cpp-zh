The TNT can be augmented with the JAMA package to provide the facility for solving linear systems and carrying out eigenvalue and singular-value decompositions. JAMA contains the template classes. Eigenvalue, QR and SVD for carrying out Cholesky and QR factorizations and eigenvalue or singular value decompositions. The classes have constructors that take Array2 objects as arguments and return objects that can access methods that correspond to various numerical routines. The Cholesky and QR classes solve methods that take Array1 objects as right-hand side for a linear system and return an Array1 object. The Eigenvalue class has methods getV and getEigenvalues that return the eigenvectors and eigenvalues of a real symmetric matrix in Array2 and Array1 that are provided as arguments. The analogous functions for the SVD class are getU, getSingularValues that return the left and right vectors in Array2 and values in Array1 object with all objects being passed into the functions by reference.

A program that uses the JAMA package is given in the next listing. The idea is that arrays will be read from text files. The first array is comprised of a square × n array with an n-vector right-hand side as the last column in the file. This first array and eigenvector will be used to demonstrate the solution of a linear system and an eigenvalue decomposition using the JAMA Cholesky and Eigenvalue classes. A second, array will be imported and used to exemplify using the SVD class.
