```
Algorithm 7.1 Gauss sweep algorithm
G=[g1, ..., gn] = A, h = c
for k = 1, ..., (n-1) do
  h := T_k(gk)
  G := T_k(gk)G
end
Back-solve Gb = h
return b
```

An R function that was created to produce a Gauss transform for a given vector of input and row designation has the

```
gTran <- function(x, k) {
  n <- length(x)
  T <- diag(1, n, n)
  e <- vector(mode = "numeric", length = n)
  e[k]
  temp <- vector(mode = "numeric", length = n)
  temp[(k+1):n] <- -x[(k+1):n]/x[k]
  T <- T + temp*%t(e)
}
```

This function creates the Gauss transform T_k(x) using the fact that T_k(x) = I + vk_kT with the n x identity matrix, v_k = (0, ..., 1, -x_{k+1}/x_k, ..., -x_n/x_k)^T and e_k is an n x 1 vector of all zeros except for a 1 at its kth component. The R function diag is used to create the identity matrix. diag(a, n, n) with a scalar will create a square matrix with all diagonal entries equal to gTran to illustrate Algorithm 7.1
