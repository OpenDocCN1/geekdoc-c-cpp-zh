Now let us explore some of the details behind the use of exceptions in Listing 3.20. Here flags indicate input and output stream objects that provide information about the stream's state. These are one-bit variables with names ebit, failbit and badbit. The value of ebit is set to 1 if the end of a file is reached and is 0 otherwise. Units for failbit indicate problems when reading or writing operations encounter an unexpected value while badbit is set to 1 in the case of corruption of an input or output stream. It might be hoped that an exception would be thrown if any of the three bits equals to 1. This is not true by default, but it can be made by using the exceptions class method with one or more of the bits. The bits are combined using the bit-wise OR operator | evaluates to 1 if any of the bits are 1. The first write operation in Listing 3.20 illustrates that an ofstream object is created and then used to set up the conditions for throwing an exception. The argument std::ofstream::failbit | std::badbit will evaluate to 1 if either failbit or badbit is set. The exception class that corresponds to stream objects will be thrown. The actual call to the open method is made inside a try block. If a failure is thrown, it is retrieved by the catch block and the information from its what method is output.
