Listing 5.1 sumFunc.r

```
#sumFunc.r
sumFunc <- function(x){
  n <- length(x)
  x <- as.integer(x)
  sum <- 0
  for (i in 1:n){
    if(!x%%3){
      sum <- sum + x[i]
    else sum <- sum + 3*x[i]
    if(sum > 300){
      print(paste("Your sum of", sum, "exceeds 300"))
      break
    }
  }
  return(sum)
}
```

The function in Listing 5.1 takes a vector as input and then performs meaningless calculations that return a value that has the property of, being an integer multiple of 3. The first step in the process is to determine the length of the input vector and convert all its elements to integers. The program steps through all the elements of the transformed vector adding to a running sum if they are modulo 0 (i.e., they are divisible by 3 without remainder) and adding three times their value otherwise. If the sum exceeds 300 execution is terminated by a break statement. Output from sumFunc is

+   > sumFunc(10 + :20)
[1] 270
> sumFunc((30 + :):50)
[1] "Your sum of 387 exceeds 300"
[1] 387

It takes as input a matrix (or data frame) whose columns correspond to samples from different. The program employs the R mean and var functions discussed in Appendix B to compute the means and variances that correspond to the columns of the input array. Setting the local parameter na.rm to TRUE causes the mean and var functions to ignore (or remove) missing values. The is.na is applied to each column of the input matrix to count the number of missing observations in each argument. The entries in the vectors evaluate to TRUE for every NA that is encountered and are FALSE. The function treats the Boolean variables as numeric value with 0 for FALSE and 1 for TRUE with the result that summing a vector produces the number of TRUE values. In this particular case the number TRUE is the number of missing values.
