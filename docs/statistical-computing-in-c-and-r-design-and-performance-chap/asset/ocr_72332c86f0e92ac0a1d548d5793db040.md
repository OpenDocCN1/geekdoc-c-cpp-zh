A "class full view" on the type of outcome would be to conclude that all methods are capable of producing solutions that are in the neighborhood of the global optimizer. Further experience with this particular example suggests that simulated annealing is the most sensitive to the choice of its tuning parameters, and in respect, the other methods are more reliable. Part of this is undetected due to the details of our particular implementation. However, in a general sense, it should be pointed out that simulated annealing is really more relevant for high-dimensional solutions with possibly nonsmooth objective functions. In contrast, blind search is not a viable option and the golden section becomes intractable. Although Newton's method readily extends to the case of more than one, the objective function needs to be differentiable.

In Section 8.4 the R function has simulated simulated annealing that comes available through the method of "SANN". The cooling schedule is used by optim is Tk = inf/(k-1) mod tmax+ e; where temp is the starting temperature for the cooling schedule (which defaults to 10) and max is the number of function evaluations that are allowed at each temperature (and also defaults to 10). The values of temp and max are set by the control argument for optim that must be given as a list that lists the parameter values by name. Another parameter for optim is maxit that sets the maximum number of iterations. It is also set using the control argument and defaults to 100 for the derivative-based methods and 10,000 for SANN.
