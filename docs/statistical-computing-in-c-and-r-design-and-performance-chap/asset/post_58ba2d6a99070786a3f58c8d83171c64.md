The save_image function was discussed in Appendix B as a mean to save an R workspace for later use. Actually, this is a special case of the more general R function save that writes a representation of an R object to a file it can later be accessed using the load function. The following group of commands demonstrates how this works with a simple target of integers.

```r
> A <- 1:5
> B <- 6:10
> save(A, B, file = "AB.RData")
> rm(A, B)
> temp <- load("AB.RData")
> temp
[1] "A" "B"
> A
[1] 1 2 3 4 5
> B
[1] 6 7 8 9 10
```

After creating the arrays A and B, an R decipherable representation for the vectors are stored in the file AB.RData and the original arrays are destroyed using the remove function rm. The information that A and B is successfully recovered from the file using the load function. The return value from load is an array whose elements are character giving the name of the objects that were loaded.

The output from an R session or program can be collected in a file using the sink function. A disconnected prototype for this function is

```r
sink(file, append, split)
```

The file argument variables that the name of the file that will hold the output append and split are logical that default to FALSE. A specification of TRUE means the output will be appended to any that already exists in the output file of TRUE means that output will be sent to standard output as well as the designated file. The use of sink is illustrated in the next example.

```r
> sink("temp.txt")
> cat(0)
> sink("temp.txt", append = TRUE, split = TRUE)
```

The read.table and write.table functions actually open connections to the file provided as arguments after their assigned reading or writing task. More generally, a connection can be given rather than a file name for the file argument for these functions as well as scan and cat. # 5.3 Classes, methods and namespaces

R comes with a large number of pre classes and associated methods. The command class(objectName) can be used to determine the class of an object objectName. To obtain a list of all classes that are available in the R use the command classes(). Every R object has two attributes: namely length and mode. The meaning of length is self-explanatory for classes that include storage numeric, logical, function, expression and list. To determine the length or mode of an object A length(A) and mode(A).

As in C++, R are created using R supplied constructors. The language has a new command with, e.g.,

```r
> A <- new("matrix")
0 matrix
```

having the effect of creating a new matrix object A of the default 0 x 0 size. The new will be explored in the next chapter. For now the focus will be on using the class constructors that are already available for pre-existing classes. The class constructors are expected to have the same name as the class although that is not strictly necessary. The arguments that are needed for a constructor, or any other function, can be determined by the args function with the name of the function as its interest as: e.g:

```r
> args(matrix)
function (data = NA, nrow = 1, ncol = 1, byrow = FALSE, dimnames = NULL)
```

More generally, in most cases the function list is showing if only its name is entered on the command line. Notably exceptions include arithmetic operators. The get function can provide useful information as

```r
> get("%%")
function (e1, e2) .Primitive("%%")
```

The output indicates that %% is a binary function (in view of the two arguments e1 and e2). The presence of the .Primitive function indicates that %% is implemented within the internal code C on which R is built. This is related to internal function will be seen in occasion in R functions. Both functions are the province of R developers, and such, fall outside the realm of this text. The previous output from args tells us that the matrix class constructor has five arguments: data, nrow, ncol, byrow whose default values are NA, 1, 1, FALSE and NULL. We have already discussed the NA constant. The reserved words TRUE and FALSE are the R Boolean constants. As in C++, TRUE and FALSE have numerical values of 1 and 0.

The default choice NULL for the dimnames argument corresponds to another reserved word. A value of NULL is often used to initialize a matrix. The byrow argument tells us which elements of the data are used to fill in the matrix by rows (when byrow = TRUE) or by columns (when byrow = FALSE). Finally, dimnames is an argument for rows and columns which can be discussed in more detail. As an example, the command input

```r
> A <- matrix(0, 3, 3)
```

produces a 3x3 matrix. The same effect is obtained from

```r
> A <- matrix(0, ncol = 3)
```

which shows that explicit use of names is not necessary unless they are entered in the same order. The matrix constructor tells us the matrix class has five arguments: data, nrow, ncol, byrow, whose default values are NA, 1, 1, FALSE and NULL.
