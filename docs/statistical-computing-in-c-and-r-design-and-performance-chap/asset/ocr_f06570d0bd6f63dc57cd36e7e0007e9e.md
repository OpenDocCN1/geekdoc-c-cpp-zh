# COMPUTER REPRESENTATION OF NUMBERS

Since transistors have only two states it is not surprising that the choice of base for computer arithmetic is binary or 2. The base version of (2.1) is the **binary expansion**

```
$k = \sum_{j=0}^{m} b_j(2)^j \quad (2.2)$
```

with $m$ non-negative integer for $b_m \neq 0$. The $b_j$'s coefficients can take on only the values 0 or 1. Returning to our example, it can be seen that

```
$193 = 1*(2)^7 + 1*(2)^6 + 1*(2)^0.$
```

This corresponds to (2.2) with $m=7, b_7=b_0=1$ and $b_5=\dots=b_1=0$.\nThe fact that the coefficients of a binary number are zeros and ones means that it can be represented as a sequence of zeros and the ones with the ones corresponding to the $b_j$ in (2.2) and their location in the sequence identifying the associated power of two. The slots hold the coefficients in the sequence are called *bits* with a sequence of eight bits being termed a *byte*. For the number 193 this translates into representation such as

| $2^7$ | $2^6$ | $2^5$ | $2^4$ | $2^3$ | $2^2$ | $2^1$ | $2^0$ |
|---|---|---|---|---|---|---|--|
| 1 | 1 | 0 | 0 | 0 | 0 | 0 | 1 |

That is, in binary 193 can be represented exactly in one byte by the value 11000001.\nThe connection between machine memory and binary arithmetic becomes complete once bits and bytes are identified with individual transistors and blocks of transistors. Represent a number in its binary representation is physically created by allocating a block of memory (e.g., a group of contiguous transistors), identifying the transistors in the block with a power of 2 from its binary representation and turning on those transistors that correspond to powers of 2 have unit coefficients. To elaborate the point a bit, the first, seventh and eighth transistor would be turned on and the other five would be turned off. Note that it would take eight bits/transistors to store 193 and any fewer would not be capable of doing the job.\nJust as 193 cannot be stored in anything less than eight bits there is a limit to the number of bits. For example, the largest number that can be stored in one byte is

```
$$\sum_{j=0}^{7}(2)^j=2\sum_{j=0}^{7}2^{-j}=2^7\frac{1-(1/2)^8}{1-(1/2)}=255. \quad (2.3)$
```

More generally the largest number that can be stored in $m$ bits is $2^m - 1$ (Exercise 2.1).
