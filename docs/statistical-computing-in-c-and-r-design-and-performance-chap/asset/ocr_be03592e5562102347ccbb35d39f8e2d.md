Once the processor reads the data in it uses a for loop to pass out the samples by sending each processor element of pdata that is determined by the receiving processors' rank. All the processors, including the master, then analyze their respective samples using an object with a class Summary. This class is structured along the lines of Exercise 3.34. In particular, it contains an implementation (the method called worst)2.3 for computing a sample mean and variance. These two statistics are stored in locations accessed through pointers that are sent back to the master processor once each processor's work is completed. Finally, the master processor combines the results(also via Algorithm 2.3) from the other processors to obtain the F-statistic for testing the hypothesis that all n populations have the same mean.
