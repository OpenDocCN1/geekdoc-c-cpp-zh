The dimnames function provides a model for how to write replacement functions. The
requirements are that

+   a) the function name (in quotes) must end with <-,
b) the final argument of the replacement function must be named value and
c) the replacement function must return the object that modifies.

The succeeding code uses this to create a function that replaces a vector by
trimmed version where only values from a middle percentage of the data are
tained.

```
trim <- function(x, value){
 x <- x[quantile(x, value) <= x & x <= quantile(x, 1 - value)]
}
```

The R function quantile is used to compute the 100(value) and 100(1 - value) percentiles from the input data vector x. Then, the subset of values that fall between these two percentiles is extracted by using the subsetting operator with a logical argument.
An example of trim is given below:

```
> set.seed(123)
x <- rnorm(10)
mean(x, trim = .1)
trim(x) < .1
[0.03703159
[-0.05604756 -0.2301747 1.5588031 0.07505839 0.12982774 0.46091621
[-0.66885285 -0.4456191
> mean(x)
0.03703159
```

A pseudo-random sample of 10 normals is generated and the 100 trimmed mean is computed using the R function with trim argument equal to .1. Our replacement function is used to trim 10% of the values from each data set; i.e., into only the middle 80% of the data are retained. An application of the mean function now produces the same value for the 10% trimmed version of mean.
R language allows a function system.time that can be employed for run-time calculations like using to the clock function in C++. One calls system.time by providing it with the expression to be evaluated as argument. The output is an object of proc_time whose elapsed members are total CPU time, system CPU time of the current process and elapsed time since the process started. In terms of our meanComp function from List 5.2 we can produce such as

```
> set.seed(123)
A <- matrix(rnorm(5*10^-5), 10, 5)
> system.time(meanComp(A))
user elapsed
0.132 0.018 0.150
```

The mean function was applied to samples of 100,000 observations from a standard normal distribution and the analysis was performed in .15 seconds.
