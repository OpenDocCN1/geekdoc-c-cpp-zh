# 5.3 Classes, methods and namespaces

R comes with a large number of precompiled classes and associated methods. The command class(objectName) can be used to determine the class of an object objectName. To obtain a list of all classes that are available in the R use the command getClasses().

Every R object has two attributes: namely length and mode. The meaning of the length character is self-explanatory for classes that include storage numeric, logical, function, expression and list. To determine the length or mode of an object A length(A) and mode(A).

As in C++, R are created using R supplied constructors. The language does a new command with, e.g.,

```
> A <- new("matrix")
A < 0 matrix
```

having the effect of creating a new matrix object A of the default 0 x 0 size. The new will be explored in the next chapter. For now the focus will be on using the class constructors that are already available for pre-existing classes.

The class constructors are expected to have the same name as the class although that is not strictly necessary. The arguments that are needed for a constructor, or any other function, can be determined by the args function with the name of the function as its interest as: e.g:

```
> args(matrix)
function (data = NA, nrow = 1, ncol = 1, byrow = FALSE, dimnames = NULL)
NULL
```

More generally, in most cases the function list is showing if only its name is entered on the command line. Notably exceptions include arithmetic operators. The get function can provide useful information as

```
> get("%%")
function (e1, e2) .Primitive("%%")
```

The output indicates that %% is a binary function (in view of the two arguments e1 and e2). The presence of the .Primitive function indicates that %% is implemented within the internal code C on which R is built. This is related to. Internal function will be seen in occasion in R functions. Both functions are the province of R developers, and such, fall outside the realm of this text.

The previous output from args tells us that the matrix class constructor has five arguments: data, nrow, ncol, byrow whose default values are NA, 1, 1, FALSE and NULL.
