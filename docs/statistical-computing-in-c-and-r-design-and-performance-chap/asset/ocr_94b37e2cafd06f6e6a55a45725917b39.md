for(int i = 0; i < 2; i++){

pD[i] = new double[3];
for(int j = 0; j < 3; j++) {

```
fileOut<int> outFile(argv[1], 0);
outFile.write(2, 3, pI);
```

```
// Now append to argv[2]
fileOut<> outDouble(argv[2], 1);
outDouble.write(2, 3, pD);
return 0;
```

Use a fileOut object with integer data, the template parameter must be given explicitly as int. The second write operation uses data of type double in which case the default value becomes useless. The brackets <> are still required in this instance; but an explicit of T is unnecessary. Output from this program looks

Note that the outDriver.cpp file was compiled here because fileOut.h contains the source code for class rather than declarations/prototypes. In essence, the compiler works with one large file that begins with the class declaration and the method definitions before concluding with the main function. The first use of the outDriver executable produces the expected results. The file permission is changed for out.txt, both write and append operations to file produce error messages.

To conclude this session, let us discuss creating a file input of our fileOut class. In many ways the same concepts apply that we want to create a template class to allow for general forms of input data. In fact, if the dimensions of the input array are presumed to be known, then an input class can be obtained through a simple modification of the fileOut formulation.
