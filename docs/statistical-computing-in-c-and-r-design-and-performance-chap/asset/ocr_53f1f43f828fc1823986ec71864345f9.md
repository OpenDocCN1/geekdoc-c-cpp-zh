The goal of + is to create a new matrix object that is the sum of it and the calling Matrix object: i.e., A + translates to operator+(B). We do not want B to be altered by this operation which is why it is passed as a const reference. The same protection is provided for the calling Matrix object and this is provided by making + a const method. Similar considerations apply for * and the tran method.

To understand the return types for the overloaded addition one must consider how these functions work in practice. With the goal to create a new Matrix object (hence, the matrix return type) is the sum of (corresponding to the hidden pointer that will appear on the left-hand side of + and the matrix object B that appears as the argument to the function. In contrast to the += operator must overwrite the contents of the matrix on the left-hand side of the calling object and object B is listed as the argument of the function. No new memory needs to be allocated and the contents of the Matrix object (corresponding to the pointer) is overwritten using the scalar value of += on an element-by-element basis. The Matrix being overwritten (i.e., the one on the left-hand side of +=) is presumed to exist, a reference is returned to its location in memory rather than a new Matrix object. The explicit use of this->p[i][j] in the + operator accumulation loop is unnecessary but helps to distinguish between the three pointers that are active in the loop.

There are three overloaded versions of the * operator that have been specified for multiplication: for ordinary matrix multiplication and two for scalar multiplication. The following code gives the definitions for these operators.

Matrix::operator*(const Matrix& B) const {
if(nCols != B.nRows){
    cout << " Bad and column dimensions in *!" << endl;
    exit(1);
}
Matrix C(nRows, B.nCols);//matrix of all zeros
for(int i = 0; i < nRows; i++){
    for(int j = 0; j < B.nCols; j++)
        for(int k = 0; k < B.nCols; k++)
            C.p[i][j] += B.p[i][k]*B.p[k][j];
}
return C;
}
