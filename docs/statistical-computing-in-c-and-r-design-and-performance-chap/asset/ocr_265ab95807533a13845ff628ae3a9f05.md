A reference also has the property of a pointer in that if an object is passed under its reference “name” to a function can actually alter the object being referenced. A reference can be viewed as similar to a pointer that can only point to one location in memory: the one that was used when it was initialized. Then, dereferencing is accomplished by simply using the name of the referenced variable.
The code below illustrates some of the features of references.

```
//refEx.cpp
#include<iostream>
using namespace std;
void f(int& j) {
    j++;
    cout << j << endl;
}
int main() {
    int i = 2;
    cout << &i << endl;
    f(i);
    cout << i << endl;
    int& j = i;
    int k = j;
    cout << i << " " << j << " " << k << endl;
    cout << &i << " " << j << " " << &k << endl;
    return 0;
}
```

The two addresses and the lone integer 3 appear in the first lines of the output provided by j demonstrate that both variable i from main and the reference to i by j in the function f share the same address in memory and that altering j in f will also alter i. We create a variable j in main that is a reference to i and initialize it to i. A new integer k is then assigned the value of j. But, k is be located in a different memory. This is a consequence of how the assignment operator behaves when used with primitive data types: i.e., a new memory is created for the variable on the left-hand side of = and the value of the right-hand side is written into this location. Thus, the effect of assigning the reference j to k is the same as obtained if a pointer pi was created that point to i (because j is a reference to i) and then the assignment k = *pi was executed.
