The Date class in R allows for operations addition, subtraction and certain logical relation operators (e.g., <, >, ==) that make it possible to manipulate dates in useful ways. Our initial use of the Date class is to determine the date of the week for the input value drawDate. For this purpose, the character drawDate is first coerced to a Date object using the asDate function. then, the weekdays function is applied to the output as drawDate corresponds to a Monday or Thursday. If the starting day is Thursday, then the next day will not occur for four days as to a three-day interval for a starting date that falls on a Monday. An if/else block is employed to deal with the two different possibilities.

Once the day of the week has been determined, the overloaded + operator for the Date class is used to augment the value of drawDate for the other drawings that will be included in the data set. The effect of adding an integer to a Date object is to produce a new Date object that is advanced by the same number of days as the value of. R vectorized addition applies here as well; adding a vector of integers to a Date object will produce a vector of Date objects that have been moved forward by the number of days in the vector.

For our particular case, the number of days that will pass between draws is either three or four and this must accumulate over the course of the drawing process. So, in the case of, e.g., a Monday start date, we add 0 to ensure that the date is the same as that specified in drawDate. the object as Date(drawDate) is advanced according to the vector

```
cumsum(rep(c, 4), ceiling((n - 1)/2), length.out = n - 1))
```

There are several steps involved in explaining this code segment and we will go them one-by-one. First, the rep function discussed in 5.1 is applied to produce the output (3, 4). The number of replicas is taken to be the smallest integer that is at least half of the sample size n-1. If the sample size is odd this gives the desired result. For sample sizes, only one of the two elements from the last replicas of (2, 3) is needed. Appropriately truncate the output from rep in this case an additional length.out for rep has been set to n-1. As a result, the vector returned from rep will no longer than n-1 elements. The idea is illustrated below where rep was used in this context and without specifying the length.out for n = 5 and n = 6.

```
> rep(c, 4), ceiling(4/2), length.out = 4
[1] 3 4 3 4
> rep(c, 4), ceiling(5/2)
[1] 3 4 3 4 3
> rep(c, 4), ceiling(5/2), length.out = 5
[1] 3 4 3 4 3 4
```

From the previous example, rep will return a vector consisting of the alternating integers 3 and 4. This tells us how many days will pass between each draw. To translate into actual dates, the increments must taken cumulatively; i.e., if a drawing occurs on a Monday 3 days before the Thursday date, 3+4 days pass before the next Monday, 10 days before the subsequent Thursday date. As suggested by this progression, the way to augment the initial value of as.Date(drawDate) is to add on the cumulative (partial) sums of days between the n draws that will make up the data. The cumsum function produces such sums; using numeric cumsum(v) is a vector of the same length as v with its entry equal to the sum of the first i elements of v.
