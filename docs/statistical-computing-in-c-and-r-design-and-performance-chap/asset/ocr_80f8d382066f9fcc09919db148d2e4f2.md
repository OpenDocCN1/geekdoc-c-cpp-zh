# NUMERICAL LINEAR ALGEBRA

To check the accuracy of the Cholesky factor we can compare it to answers produced with the R chol function that performs a Cholesky factorization: namely,

```
> chol (A)
  [1]         [2]         [3]         [4]         [5]
[1] 1.678801 -1.873512 -0.124054 -2.497715 -0.6449736
[2] 0.000000  1.383693  1.227898  0.600928 -0.7682812
[3] 0.000000  0.000000  0.767374  1.135502 -0.8695156
[4] 0.000000  0.000000  0.000000  0.367215 -1.0253122
[5] 0.000000  0.000000  0.000000  0.000000  0.5906208
```

The two Cholesky factors agree apart from the fact that the R chol function returns the upper-rather triangular factor. Thus, to solve a system in R with the Cholesky factorization uses forward-solving with the transpose of the upper-triangular factor and back-solving with the factor returned from chol. In terms of this translates to

```
> U <- chol(A)
  h <- forwardsolve(t(U), cVector)
  backsolve(U, h)
[1] -30.89287 -99.34466 153.15147 -128.24258 -33.69657
```

A second option is to use the inverse matrix A⁻¹ computed via the Cholesky method. This is accomplished with the chol2inv function which takes the Cholesky factor obtained from chol as input. Again, for example this produces

```
> chol2inv(chol(A))%%%cVector
  [1]
[1] -30.89287
[2] -99.34466
[3] 153.15147
[4] -128.24258
[5] -33.69657
```

# 7.2.4 Banded matrices

Of interest is that the matrix A = {aij} is said to be band-limited structure with bandwidth q if aij = 0 whenever |i - j| > q. For example, the matrix below is 6 × 6 and two-banded

| a11 | a12 | a13 | 0 | 0 | 0 |
| a21 | a22 | a23 | a24 | 0 | 0 |
| a31 | a32 | a33 | a34 | a35 | 0 |
| 0 | a42 | a43 | a44 | a45 | a46 |
| 0 | 0 | a53 | a54 | a55 | a56 |
| 0 | 0 | 0 | a64 | a65 | a66 |

In the case of a positive-definite matrix A, it is easy to see that the matrix L in the Cholesky factorization has the same lower bandwidth as A (Exercise 7.6). Thus, the order of computation can be substantially reduced by restricting attention to the nonzero matrix elements.
