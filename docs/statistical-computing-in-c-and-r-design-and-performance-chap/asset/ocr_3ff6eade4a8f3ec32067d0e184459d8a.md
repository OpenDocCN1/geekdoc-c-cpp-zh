# Generation of pseudo-random numbers

# 4.1 Introduction

The random sample concept represents a cornerstone in the theory and application of statistics. The usual definition for this term would be

**Definition 4.1.** A collection of random variables $X_1, \dots, X_n$ is a random sample if they are all independent and have the same probability distribution.

The idea seems simple enough. But, the physical creation of collections of numbers that behave like realized values turns out to be a problem that anything but simple. The solution that will be studied in this chapter is the pseudo-random number generator (PRNG). This approach has a long history withviews provided, for example, in Devoye (1986), Lueur (2001), Monahan (Chapter 11) and Gentle (2003). The artificial data obtained from PRNGs have a myriad of uses that span the scientific disciplines. In particular, they represent the primary role that statisticians use for testing new methodology. Thus, it is important to have some understanding of (i) how PRNGs work, ii) the properties a “good” PRNG should possess, iii) the types of PRNGs that exist and iv) how high-quality PRNG implementations can be used in practice. These are among those that will be addressed in the present chapter.

At the outset, we should explain the reason for the “pseudo” of the PRNG term. PRNGs typically rely on varying seeds or seeds to initiate the recursion that produces the desired random sample. If they are produced by random process, then the numbers produced by the generator will be random. But, given any values for the seeds, the outcomes produced by a generator are deterministic or exactly reproducible; each time the random generator is using the same sequence of values is returned. This is a good property in the sense that allows the user to repeat portions of experiments that may have been lost due to errors, accidentally erased, by invalidating coding errors, It also allows the results of an experiment to be reproduced to alternate or enhance output and summary statistics. On the other hand, deterministic sequences of numbers can hardly be considered “random”. For this reason, the modifying phrase “pseudo” is usually replaced to “random” when discussing algorithmic methods for generating random numbers. While tells us what a PRNG is not, it leaves the meaning of the PRNG terminology in state of limbo. Here we will use the definition for a PRNG employed, e.g., by Robert and Casella (2004).

**Definition 4.2.** A PRNG is an algorithm that, starting from an initial seed (or seeds), produces a sequence of numbers that behaves as if it were a random sample from a probability distribution when analyzed statistical goodness-of-fit tests.
