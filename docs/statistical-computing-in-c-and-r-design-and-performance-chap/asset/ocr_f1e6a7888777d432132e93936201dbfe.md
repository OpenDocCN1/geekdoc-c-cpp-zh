The chainHash class itself is relatively simple. There are three members: the number of buckets, tableSize, the number of objects in the table, Size, and the vector object that holds the lists containing the pair objects that populate the table. There are basic insert and lookup methods to find objects in the table as well as accessor functions to retrieve the values of the Size and tableSize class members. None of these new ideas involve at this point. Accordingly, most of the subsequent discussion will be directed towards the more novel aspect of fles the internal iterator class that provides the means to navigate inside a chainHash object.
