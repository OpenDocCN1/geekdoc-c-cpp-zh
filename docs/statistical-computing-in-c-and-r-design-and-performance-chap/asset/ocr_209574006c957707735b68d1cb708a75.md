The aim was to generate three random numbers and, as a result, memory was allocated in R for a three-component, vector object x. The seed was set and rngFunc called using the .C interface. The output was stored in the list object whose fourth entry was the array that was passed as the first argument to .C. The rngFunc function was called again producing two random numbers. The seed was then reset to its initial value and the resulting output from rngFunc is to agree with our first set of numbers.

The C interface can be used to import any of the C++ code that has been developed far into R. For example, let us consider how this could be accomplished using our Moore random number generator from Chapter 4. First, the FM.cpp and FM.h files from Chapter 4 must be renamed as FM.cc and FM.hh, respectively. Next, an interface program must be created. For this particular case something like

```
//fmR.cc
#include "R.h"
#include "FM.hh"

extern "C" {

void rngFM(int* N, int* SEED) {
    int n = *N;
    unsigned long seed = (unsigned long)*SEED;
    FM* pM = new FM();
    double* pu = new double[n];
    pM->ranGen(seed, n, pu);
    printf("Your random numbers are\n");
    for(int i = 0; i < n; i++)
        printf("%f \\n", pu[i]);

    delete pM;
    delete pu[];
}
}
```

will suffice. Then, the interface file fmR.cc and the FM.cc are compiled and linked into a shared library fmR.so as

$ CMD SHLIB fmR.cc FM.cc
