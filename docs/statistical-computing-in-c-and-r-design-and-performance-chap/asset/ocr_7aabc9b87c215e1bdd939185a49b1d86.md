# A SKETCH OF C++

We have already seen that C++ allows function overloading. The same is true for the basic arithmetic operators as +, -, /, *, the shortcut operators +=, -, /=, *= and many others. To create an overloaded operator use the syntax

```
returnType operatorName(arguments)
```

As a case in point, overloaded versions of the multiplication operator have been defined for the X struct in Listing 3.9: one is designated as const and one is not. Both operators perform a type of scale multiplication wherein their int multiplies an X object's int data members.

Both of the multiplication operators in the X struct work for expressions of the form X*a with an X object and an integer. It expressions like a* that are problematic; this would only make sense if integers were themselves a case, and as an overloaded operation for dealing with X objects. Such is not the case. However, the two-argument version of * directly as a binary function with int and X object arguments. Once inside the function, the int and X objects are reversed and the multiplication methods from the X class can used. The overloaded version of * is not an X class method, and as a result, the X argument should be passed in a const reference to make certain that the const version of the * operator in the X class can be used to carry out the computation.

The code in Listing 3.9 was compiled and executed to produce

```
2
const version of *
const version of *
2
```

The output shows that, as expected, the non-const version of * was used for right-hand multiplication of the X object while the const version was used to carry left multiplication. Actually, the presence of two multiplication operators is redundant here in that the const version can be used exclusively without loss of functionality for the class.

# 3.8.4 Forward references

As programs grow, more complex relationships can develop between different classes. It is commonly the case that objects of one class will produce and operate on objects of another. A simple example of this is provided by the next listing.

Listing 3.10 circular

```
//circular.cpp
struct Y;//forward declaration
struct X {
Y* A;
X() {}
X(Y* a){A = a;}
Y& funcX(Y& y){return y;}
};

struct Y {
X B;
Y() {}
YY(X b){B = b;}
X funcY(X x){return x;}
}
```
