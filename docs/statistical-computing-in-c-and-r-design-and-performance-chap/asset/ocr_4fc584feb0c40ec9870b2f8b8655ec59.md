# 3.10 Input, output and templates

Up to now all the input and output to our programs has been directed through the shell interface. This is unlikely to be sufficient in any general sense and certainly not for the purposes of statistical analysis where input and output to files is essential. Thus, in this section we will address the issue of reading from and writing to files. The solutions that we obtain will be satisfactory for many applications but are nonetheless constrained to handling file structures that have very specific formats. A more flexible framework is postponed until Chapter 10.

The problems that will be considered are the input and output of arrays that contain values of the C/C++ primitive data types. Of the two, the output problem is usually the most straightforward in one can expect to have the array to be written to a file during the course of computation and therefore have knowledge of its structure.
