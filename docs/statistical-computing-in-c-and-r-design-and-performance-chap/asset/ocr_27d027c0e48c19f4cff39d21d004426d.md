In addition to estimating the number of times a certain key value has been seen, count-sketch can be used to provide other statistics of interest for an input sequence. The data include range queries (approximately counting all keys in a given range), quantiles of the key distribution and heavy hitters (most frequent keys). We see, e.g., Cormode and Muthukrishnan (2005) for further discussion of how this can be accomplished.

The 7700 words and their frequencies were read into R and stored in the arrays words and freq. The (word) frequencies were then converted to "raw" using the R replication function rep. In terms of what it is used here, rep takes two vectors and repeats the first according to the frequencies specified in the second. For example, the first component of the vector words is the "the" that occurred 61,847 times as first element of the vector freq. The newword array will therefore contain 61,847 instances of "the".
