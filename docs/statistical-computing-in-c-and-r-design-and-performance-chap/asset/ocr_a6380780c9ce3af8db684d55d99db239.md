The anonymous namespace in the RngStream.cpp file holds the matrices in (11.1)-(11.2) in the 3 x 3 AdvanceSeed A1p127 and A2p127 the moduli $2^{32}-209$ and $2^{32}-22853$ are stored in the unsigned long integers m1 and m2. It also includes the matVecModM prototype

```
void MatVecModM(const double A[3], const double s[3], double v[3],
                double m)
```

This function perform multiplication of a 3 x 3 array three-element arrays s modulo and return the result in the three-element array v, by taking A to be A1p127 or A2p127 and m to be m1 or m2, a given seed can be advanced $2^{127}$ states to obtain a seed for the next random number stream.
```
void RngStream::AdvanceSeed(unsigned long seedIn[6],
                unsigned long seedOut[6]) {
    double tempIn[6]; double tempOut[6];
    for(int i = 0; i < 6; i++)
        tempIn[i] = seedIn[i];
    MatVecModM(A1p127, tempIn, tempOut, m1);
    MatVecModM(A2p127, &tempIn[3], &tempOut[3], m2);
    for(int i = 0; i < 6; i++)
        seedOut[i] = tempOut[i];
}
```

to the RngStream.cpp file. By declaring AdvanceSeed as static it can be used directly without an RngStream object which is precisely what is needed for the application that we have in mind.
