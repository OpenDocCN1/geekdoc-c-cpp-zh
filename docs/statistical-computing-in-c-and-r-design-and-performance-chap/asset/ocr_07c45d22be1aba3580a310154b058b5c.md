For the g5 setting, our choice for the binary functor is

```
struct sumFreq : public std::binary_function<int*, g5, int*> {
umFreq();

int* operator()(int freq, const g5& g) {
for (int i = 0; i < 40; i++)
freq[i] += getFreq(i);
return freq;
}
};
```

For any g5 object, the sumFreq functor will access the frequency of occurrence for the 40 balls using the g5 class accessor getFreq and add them to the appropriate elements of the array represented by its first pointer to int argument. The recursion is begun by giving the initial value of a pointer whose locations have all set to 0. The range is specified by the begin() and end() iterators from the g5Array class which results in the collection of frequencies for every object in the container.

For a bit variety, the actual chi-square statistic was evaluated using the transform and inner_product algorithms with the latter coming from the numeric library. The requisite calculations can be broken into three steps: i) subtract the frequency from observed frequency, ii) divide this difference by the square root of the expected frequency and iii) sum the results from steps i and ii. The algorithm is used to carry out the first two steps. This simply transforms every element in a specified range (given as its first argument) using a user-supplied functor (given as its third argument).
