# 10.2 A C++ STL hash table

Currently the C++ STL does not include a hash table implementation.‡ Hash tables are a part of the draft standard in the C++ TR1 document that is already least partially implemented in several compilers, not necessarily gcc, is largely safe and portable. The next standard will include these features and many others, of which are are discussed in Appendix C.

Despite the absence of a specific hash container, the STL provides all that is necessary to create effective hash tables as we demonstrated in this section. The development here is motivated by Section 12.4 of Ford and Topp (2002).

Conceptually, we know from Section 9.2.4 that a chaining hash table consists of three components:

+   - an array that represents the buckets for the table,
- linked lists that hold the elements in each bucket and
- elements that are a composed of key and data modules.

Thus, the appropriate containers from the STL can be used in combination to create a composite structure that has these required features. In that, the pair container from Section 9.2.4.2 has already been used as the third component and there is no reason to deviate from this scheme. The vector container can provide the buckets; this comes with the added benefit of providing a built-in resizing mechanism for the table.
