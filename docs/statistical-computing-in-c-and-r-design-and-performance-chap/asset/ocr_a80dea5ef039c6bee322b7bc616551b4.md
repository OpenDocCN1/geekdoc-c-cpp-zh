# CREATING CLASSES AND METHODS IN R

```
g5 <- function(a){
  drawdate <- as.Date(a[1])
  mname <- a[2]
  sno <- as.integer(a[3])
  day <- a[4]
  A <- matrix(as.integer(a[5:50]), 10, 5, byrow = TRUE)
  g50bj <- new("g5", drawDate = drawdate, mName = mname, sno = sno,
  day = day, data = A)
}
```

The first four elements of the input array are used to set the values that will be used to fill the drawDate, mName, and Slot for the g5 object. Then the next 50 elements are converted from character to integer using the as.integer function and reshaped into a 10 x 5 matrix. This information is used in the constructor function to create a new object.
