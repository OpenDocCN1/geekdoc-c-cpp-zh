## 8.3 Golden section

In this section we develop our first optimization method. To begin, let us deal with a simple case where a convex function $f$ is defined on the integers $N_m = \{1, \dots, m\}$. The objective is to find the fastest algorithm in the sense that it finds the fewest evaluations $\nu_n$ of $f$ on $N_m$ to find its minimum. Our discussion of this problem stems from developments in Kiefer (1953) and Monahan (2001).

One may check that an arbitrary choice is allowed for $f$, then $\nu_2 = 2$ and $\nu_3 = 3$. For $m=4$ and $N_4 = \{1, 2, 3, 4\}$, the minimizer can be found in $\nu_4 = 3$ evaluations if $f$ is first evaluated at 2 and 3. If $f(2) < f(3)$ it is only necessary to evaluate $f(1)$ to decide between 2 and 1 for the minimizer. Similarly, if $f(3) < f(2)$ only $f(4)$ need to be evaluated.

For $m = 7$ evaluation at 3 and 5 will eliminate $\{5, 6, 7\}$ or $\{1, 2, 3\}$, reduce the problem to the situation with $m = 4$ and thereby allow for minimization in $\nu_{\gamma} = 4$ evaluations.

Finally, for $m = 12$ evaluation at 5 and 8 eliminates five points (i.e., $8, 9, 10, 11, 12$), or $\{1, 2, 3, 4, 5\}$ and puts the remaining evaluation in the ideal location for the best point search.

The pattern can now be seen to look like this: The Fibonacci numbers $F_0 = 1$ and $F_1 = 1$:

```
$F_j = F_{j-1} + F_{j-2}, \ j = 2, \dots$
```

Then, for $m = F_{k-1}$, evaluate $f$ at $F_{k-1}$ and $F_{k-2}$ eliminating $F_{k-2}$ points and reducing the problem to one that is evident having $m = F_{k-1} - 1$. The total number of evaluations is $\nu_{k-1} = k-1$.

Of situations involving minimizing a function over a grid whose size is determined by a Fibonacci number are rare. However, the results for this setting can be applied to deal with a case that is actually of interest.

Suppose that $f(\theta)$ is a continuous function with argument $\theta$ taking values in the interval $[0, 1]$. Let us now consider doing a grid search over the m-point set:

```
$\left\{ 0, \frac{1}{m-1}, \dots, \frac{m-2}{m-1} \right\}$
```

We want to see what as the grid grows over $[0, 1]$. So, it suffices to take $m = F_{k-1}$ and let $k \to \infty$. The search is defined by the first two points which are $\frac{F_{k-2}}{F_{k-1}}$ and $\frac{F_{k-3}}{F_{k-1}}$. Thus, $r = \lim_{k \to \infty} \frac{F_{k-2}}{F_{k-1}} = \frac{-1+\sqrt{5}}{2} \approx 0.618$.

Consequently, the two evaluation points are then $r$ and $1-r$. If $f(1-r) < f(r)$, the minimizer must lie in the interval $[0, r]$ and it suffices to search for the minimizer of $f$ over $[0, r]$. On the other hand, if $f(1-r) > f(r)$, the minimizer must lie in the interval $[1-r, 1]$. To describe the general case, suppose that $f$ is defined on an interval $[a, b]$, in which case our scheme tells us to evaluate it at $a+r(b-a)$ and $a+(1-r)(b-a)$.

In the next iteration, our current search procedure would, in theory, continue indefinitely unless safeguards which eventually terminate the search. A typical stopping rule would conclude the search if a preset maximum of iterations is exceeded:

```
$|minTemp^{(k+1)} - minTemp^{(k)}| < \delta minTemp^{(k)}$
```

with $minTemp^{(k)}$ our approximation to the minimizer of the $k$th iteration and $\delta$ a small constant. From Section 2.5 we know that for single and double precision cannot detect differences smaller than $10^{-7}$ or $10^{-16}$ which would seem to make them obvious choices for $\delta$. However, these options are much too general for purposes and perhaps $10^{-7}$ and $10^{-8}$ represent more attainable choices as will be explained below.

The search procedure we have described is the golden section algorithm. Formal pseudo-code of the method is provided in Algorithm 8.1 for user-specified values of $\delta$ and the maximum number of iterations $itMax$.

## Algorithm 8.1 Golden section algorithm

```
niter = 0, r = (1+\sqrt{5})/2, minTemp = b, change = \infty
low = a, up = b, f_{low} = f(a+(1-r)(b-a)), f_{up} = f(a+r(b-a))
while $\delta > |minTempLast|$ and niter < itMax
  minTempLast = minTemp
  minTemp = (low + up)/2
  if $f_{low} < f_{up}
    up = low + r(up-low), f_{up} = f_{low}
    f_{low} = f(low+(1-r)(up-low))
  else
    low = low + (1-r)(up-low), f_{low} = f_{up}
    f_{up} = f(low+r(up-low))
  end
  change = minTemp - minTempLast
  niter = niter + 1
end while
```
