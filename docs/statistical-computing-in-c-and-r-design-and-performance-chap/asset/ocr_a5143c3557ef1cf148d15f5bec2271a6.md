# PROGRAMMING IN R

The code below creates two lists and gives names to their elements.

```
> <- list("a", "b")
ames(a) <- c("a1", "a2")
b <- list(b1 = "c", b2 = "d", b3 = "e")
names(b)
[1] class("b1", "b2", "b3")
[1] list(a[1])
[1] class(a[[[1]]
[1] "character"
[1] class(a[[1]])
[1] "character"
```

The names for the list objects have been assigned in two ways: using the names function and directly in the list constructor. As seen from this example, list elements may be accessed via the dereferencing operator [] (which is always possible) or by their names using $ if names have been assigned. Dereferencing returns the actual object that was stored in the list. Note that using the [] operator with a list, instead of [], will return a sublist that corresponds to the specified indices. In this particular case, a[] is a one-element list while a[[1]] is the character object that provides the sole component of a[1].

Let us return to the discussion of dimnames for the matrix class. This is a list that contains names for the rows and columns of the matrix. The list can be supplied as an argument on creation of a matrix or specified after the fact via the dimnames function and assigned using both approaches. This is illustrated by the next example where a 2x3 matrix is created and assigned using both approaches.

```
> dimA <- list("R1", "R2", c("C1", "C2", "C3")
A <- matrix(1:6, 2, 3, dimnames = dimA)
names(dimA)
[[1]]
[1] "R1" "R2"
[[2]]
[1] "C1" "C2" "C3"
```

```
> names(dimA) <- list("C1", "C2", c("R1", "R2", "R3")
A <- t(A)
```

```
C1 C2
R1 1 2
R2 3 4
R3 5 6
A["R2", "C1"]
[1] 3
```

Notice in this example that the dimnames function without an argument returns the current value of dimnames for the object supplied as. The values for dimnames appear to appear in the display of the matrix A that was created in the example and were used to access the elements of the matrix by supplying them as arguments to the subscripting operator []. It is also seen that R really corresponds to the names of dimensions through the way they adjust automatically to the replacement of the matrix A with its transpose t(A).
