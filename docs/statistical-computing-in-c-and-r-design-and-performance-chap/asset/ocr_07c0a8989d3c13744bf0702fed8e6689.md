To create an ofstream object with name outFile corresponding to an existing file whose
name is stored in the C-string variable fileName, use out either

```
std::ofstream outFile;
outFile.open(fileName);
```

or

```
std::ofstream outFile(fileName);
```

Note that the "name" of the file must include a path specification if it is not in the same
directory as the program. The scope resolution operator has also been used to specify that
ofstream refers to the definition in the std namespace.

To actually write to the file the insertion operator << is used in the same
m as for writing to standard output. The only syntactic difference is that cout
be replaced with the name of the ofstream object or outFile in this particular case. Upon
conclusion of writing to a file may be closed, thereby freeing it for other uses (e.g., reading
or appending),

```
outFile.close();
```

The basic ideas behind C++ file output are illustrated in the following program.

![](bbox=[0.385, 0.483, 0.615, 0.498])

```
//simpleOut.cpp
#include <iostream>
#include <fstream>
int main(int argc, char** argv) {
    std::ofstream outFile;
    outFile.open(argv[1]);
    for(int i = 0; i < atoi(argv[2]); i++){
        for(int j = 0; j < atoi(argv[3]); j++)
            outFile << (i + 1)*(j + 1) << " ";
        outFile << std::endl;
    }
    outFile.close();
    outFile.open(argv[1], std::ios_base::app);
    outFile << "End of file" << std::endl;
    outFile.close();
    return 0;
}
```

Listing 3.18 opens an output stream to a name that is input from the command line
in argv[1]. If a file with the name does not exist it will be created and if it does
its content will be overwritten. An array is written to argv[1] with row column
dimens determined by the command line arguments argv[2] and argv[3], respectively.
The connection is closed after which a second connection is made to argv[1] using outFile.
In doing this second argument std::ios_base::app has been passed to the open method
