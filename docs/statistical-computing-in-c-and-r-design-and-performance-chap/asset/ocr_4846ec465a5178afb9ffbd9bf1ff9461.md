```
unsigned long CMS::FreqEst(string key){
    unsigned long minSoFar = numeric_limits<unsigned long>(),max();
    unsigned long nCount = 0;
    for(int i = 0; i < D; i++) {
        thisCount = B[i][fnHash(i, key)];
        if(thisCount < minSoFar) minSoFar = thisCount;
    }
    return minSoFar;
```

The for loop can initialize the search for (10.1). The only problem is obtaining a value for the estimator that is provided by the numeric_limits template class parameter unsigned long max returns the largest unsigned long int that can be represented on the machine.

```
void CMS::readData(istream& file){
    string key; int theCount = 0, totalCount = 0;
    while(!file.eof()) {
        getline(file, key);
        if(key == "the") nCount++;
        insertKey(key);
        totalCount++;
        if(totalCount%100000 == 0)
            cout << key << " " << getFreqEst("the") << endl;
    }
}
```

This method takes an istream object as its argument which corresponds to an input file; for our specific application of interest will be words.txt that was created previously in R from the British National corpus data. The file will be read until the end of the file is enclosed: i.e., file.eof() evaluates to true. Each word is read using the getline function from Section 3.8.5. The resulting key is then "inserted" into the B array with the insertKey method. To emulate what might happen while reading from an actual stream, could also be included to monitor the frequency of the word "the" and report on its estimated and actual frequency every 100,000 words are read from the "stream".
