Each element of $L$ can be computed in order $q$ flops, and hence, all the elements of $L$ can be obtained in a total of order $nq^2$ flops. Finally, the forward and backward substitution steps are also of order $nq$ which verifies the claim.

The C++ code below implements the banded Cholesky algorithm for a given matrix with
s specified bandwidth. The companion methods bandBack and bandFor for backward and
forward of banded systems are given in Appendix D.

```cpp
Vector Matrix::bandChol(const Vector& RHS, Matrix& G,
    int bwidth) const {
    double temp = 0;
    int low, up;

    for(int j = 0; j < nCols; j++){
        if(pa[j][j] == 0){
            cout << "Singular system!" << endl;
            exit(1);
        }
        temp = pa[j][j];
    }
    low = std::max(0, j - bwidth);

    for(int k = low; k < j; k++)
        temp -= G[j][k]*G[j];

    G.pa[j][j] = sqrt(temp);

    up = std::min(j + bwidth, nRows);

    for(int i = j + 1; i <= up; i++){
        temp = pa[i][i];
        for(int k = low; k < j; k++)
            temp -= G[j][k]*G[i][k];
        G.pa[i][j] = temp/G[j][j];
    }
    Vector h = G.bandFor(RHS, bwidth);
    Vector b = G.trans().bandBack(h, bwidth);
    return b;
}
```

## 7.2.5 An application: linear smoothing splines

One application of banded Cholesky methods is in the computation of linear smoothing splines. The problem involves bivariate $(x_i, y_i), i=1, ..., n$, with $0 \leq x_1 < ... < x_n \leq 1$. A linear smoothing fit $f$ to this data is obtained through minimization of criterion

$$\sum_{i=1}^{n} (y_i - f(x_i))^2 + \lambda \int_{0}^{1} (f'(x))^2 dx, \lambda = 0$$

over continuous functions $f$ with square-integrable derivatives. The smoothing parameter $\lambda$ in (7.8) governs the smoothness or goodness of the fit to the data. As $\lambda$ grows large $f$ tends to the average of $y_i$ as $\lambda \to 0$ the fitted function interpolates the $y_i$; that is, $\lim_{\lambda \to 0} f_{\lambda}(x_i) = y_i, i=1, ..., n$. It is known (e.g., Wahba 1990) that $f_{\lambda}(x)$ is a piecewise linear function whose derivative jumps continuously and vanishes outside of $[x_i, x_{i+1}]$.
