## 3.11 Function templates

Class templates provide a way of producing generic functions in the sense that class methods can be made applicable to any data type (either primitive or user defined) that is used in the creation of the class object. However once a template object has been created with a specific data type, its methods become data type specific. For example, objects from the fileOut class will have all an associated method write. But a fileOut object created for working with type int will fail if an attempt is made to write out data of type double.

Function templates are a way to obtain more flexibility than what is available from class template methods. They are standalone functions that are not tied to class objects and can be applied to different data types within the same program. The syntax for creating a function looks like

```cpp
template<T>
returnType functionName(T t, additional arguments)
{
    // body of function
}
```

Here both the function's return type returnType as well as the additional arguments can be any data type as well as an object of the generic class T. Unlike classes, default values cannot currently be given for the template parameters in a template function.
The succeeding function performs the same operations as the write method for our fileOut template class in the previous section using a template function.

```cpp
//fileTemp.cpp
#include <iostream>
#include <fstream>
template<class T>
void write(const T* p, int nrows, int ncols, char* fName, bool app){
  if(app) {
    std::ofstream fileOut(fName, std::ios::app);
    for(int i = 0; i < nrows; i++){
      for(int j = 0; j < ncols; j++) {
        fileOut << p[i][j] << " ";
      }
      fileOut << std::endl;
    }
    fileOut.close();
  } else {
  std::ofstream fileOut(fName);
  for(int i = 0; i < nrows; i++){
    for(int j = 0; j < ncols; j++) {
      fileOut << p[i][j] << " ";
    }
    fileOut << std::endl;
    }
    fileOut.close();
  }
}
```

## EXERCISES

```cpp
int main(int argc, char** argv) {
  int** pi = new int*[2];
  for(int i = 0; i < 2; i++)
    pi[i] = new int[2];
  for(int j = 0; j < 2; j++)
    pi[i][j] = (i + 1)*(j + 1);

  write((int**)pi, 2, 2, argv[1], 0);

  double** pd = new double*[2];
  for(int i = 0; i < 2; i++)
    pd[i] = new double[3];
  for(int j = 0; j < 3; j++)
    pd[i][j] = (double)((i + 1)*(j + 1))/6;

  write((double**)pd, 2, 2, argv[1], 1);

  for(int i = 0; i < 2; i++)
    delete[] pd[i]; 
  delete[] pd;
  return 0;
}
```

The syntax is a bit subtle. The function is implicitly working on two dimensional arrays. The first argument suggests only one dimensional array is being passed into the function. The trick is that T is itself a pointer to some other generic class T0 which gives us a pointer to objects; using absent notation, but the relation can be expressed as T*=T0*. The template function contains additional arguments that specify the number of rows and columns (i.e., ncols) of the array, the name for the file that is used for writing and a logical variable that determines whether or not append the output to an existing file. The main function in the listing takes an output file name from a command line argument and writes a two-dimensional array of integers to the file using specialized data of type int. The output file is then reopened in append mode and is written to output data of type double. Some results obtained by running this program

```

$ cat outFile.txt

0.333333 0.666667
```
