Under conditions detailed in L'Ecuyer and Tezuka (1991) and L'Ecuyer (1996) the period length for the generator can be as large as the product of the periods for the individual generators. Tables containing good parameter choices for generators of this nature are given in L'Ecuyer (1999).

An example of combined generator is proposed by Wichmann and Hill (1982) that will be referred to as the WH generator in the sequel. The algorithm uses the linear congruential (and, hence, multiple recursive with $k=1$) generators

```
$x_i = 17Lx_i \mod 30269$
$y_i = 172y_{i-1} \mod 30307$
$z_i = 170z_{i-1} \mod 30323$
```

with the resulting uniform random deviate obtained from

```
$u_i =(\frac{x_i}{30269} + \frac{y_i}{30307} + \frac{z_i}{30323}) \mod 1$
```

The period of this generator exceeds $2.8 \times 10^{13}$. Our implementation of a C++ WH class for the WH generator has the header file

Here $a1, a2, a3, m2 and m3$ represent the multipliers and moduli for the three generators. Although they have been specified explicitly in the constructor definition to produce the WH generator, other choices could be obtained as input to another constructor to produce a more general implementation. The operative class method takes the seed, sample size and a pointer to double. The memory locations near the pointer are filled with random deviates by the generator.

The WH generator provides an appreciable increase in period length beyond of the Fisher-Moore generator of Section 4.4. Even so, its period is too short for many applications that require very long streams as random number in parallel computing environments. One source for generators can be used such as the Rngstreams of L'Ecuyer, et al. (2001, 2002). The source code for the package in C, C++, C# and Java can be downloaded from

In particular, the C++ implementation of Rngstreams furnishes an OOP framework where objects are created that have an associated method Rand301 to produce uniform deviates.

the "backbone" for Rngstreams is Merg32k3a. It is a combination of the two multiple recursive generators that produce the

```
$x_{1,n} = (1403580 \times x_{1,n-2} - 810728 \times x_{1,n-3}) \pmod{2^{32} - 209}, \quad (4.11)$
$x_{2,n} = (527612 \times x_{2,n-1} - 1370589 \times x_{2,n-3}) \pmod{2^{32} - 22853}, \quad (4.12)$
```

at the nth step of recursion initial $\tilde{x}_i = (x_{i,0}, x_{i,1}, ..., x_{i,2})^T$, for $i=1,2$. The two states are combined to produce the uniform random $u_n$ via

```
$z_n = (x_{1,n} \pmod{2^{32} - 209}), \quad \text{if } z_n > 0,$
$u_n = z_n / (2^{32} - 209), \quad \text{if } z_n = 0.$
```

In (4.10) this corresponds to $K=2, 3$, $m_1 = 2^{32}-209, a_1=1403580, a_2=-810728, m_2=2^{32}-22853, a_3=527612, a_4=-1370589$. The period for this generator is approximately $2^{61}$ provided that $x_{1,0}, x_{1,1}, x_{1,2}$ are not 0 and are all less than $(2^{32}-209)$ and $x_{2,0}, x_{2,1}, x_{2,2}$ are less than $(2^{32}-22853)$ and not all zero. # 4.6 Nonuniform generation

As noted in the introduction, the generation of uniform random numbers is the key to producing pseudo-random samples from nonuniform distributions. The most direct approach is to use the probability integral transform of Theorem 4.1 as implemented in Algorithm 4.1. A case where this can be done in closed form is the exponential distribution with probability density function

$$f(x) = \begin{cases} \lambda exp\{-\lambda x\}, & x>0; 0, & \text{otherwise}. \end{cases}$$

The distribution function corresponding to $f$ is $F(x)=1-\exp\{-\lambda x\}$ for $x>0$ for which inverse or quantile function is $F^{-1}(u)=-\ln(1-u)/\lambda$ with $u \in (0,1)$. The driver program below uses this function to produce a pseudo-random sample from the exponential distribution using the WH generator as Algorithms 4.4-5.
