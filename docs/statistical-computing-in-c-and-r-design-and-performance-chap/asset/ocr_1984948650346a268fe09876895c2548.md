# AVOIDING LOOPS IN R

raply(object, f)

The object is a list of lists and f is the function to be applied. The use of rapply is demonstrated below.

```
# A < list(1:10, 20, 30), list(list(40:50, 60:70), 80:90)
+ 100:110)
> rapply(A, f = sum)
[1] 55 275 495 715 935 1155
```

Note that the action of rapply on a non-list object is just to apply f (or sum in this case) to the object while it continues to recursively work over any list of lists it encounters its argument.

The mean comparison example of the previous section is one instance where apply and apply can be used to produce more efficient code than a loop implementation. With this in mind we write a function to carry out pairwise mean comparisons.

Listing 5.3 meanComp.r

```
meanComp <- function() {
indexList <- list()

# fill indexList with all the index pairs
count <- 0
for(i in 1:ncol(A)) {
  for(j in (i+1):ncol(A)) {
    indexList[[count + j - i]] <- c(i, j)
    count <- count + ncol(A) - i
  }
}
n
# compute the statistics for the columns
meanVec <- apply(A, MARGIN = 2, FUN = mean, na.rm = TRUE)
varVec <- apply(A, MARGIN = 2, FUN = var, na.rm = TRUE)
nVec <- apply(A, MARGIN = 2, FUN = 
  function(e) length(e) - sum(is.na(e)))

# compute the t statistics
apply(indexList, FUN = function(e) {
n1 <- nVec[e[1]]
n2 <- nVec[e[2]]
Diff <- meanVec[e[1]] - meanVec[e[2]]
n <- n1 + n2 - 2
sFactor <- sqrt((n1{-1} + n2{-1})
spooled <- sqrt((n1-1)*varVec[e[1]] + (n2-1)*varVec[e[2]])/n)
mDiff/(sPooled*sdFactor)
})
```
