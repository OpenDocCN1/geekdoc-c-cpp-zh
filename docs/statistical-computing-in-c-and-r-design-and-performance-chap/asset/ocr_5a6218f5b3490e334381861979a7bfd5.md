Note that the pointer in simplePointer.cpp was initialized with 0 which has the effect of producing a null pointer: namely, a pointer that points to no location in memory and as a result, cannot be dereferenced. An alternative, equivalent, is to initialize the pointer with the "NULL" in C++ which is an alias for 0. We will use the 0 option throughout this text and view explicit initialization of pointers with as a good programming practice. It makes it clear to users and others that the pointer does not point to a valid memory location and cannot be dereferenced until that has changed.

Null pointers are quite useful Although they cannot be dereferenced, they can be compared using == and != to others. No valid pointer (i.e., one that points to a valid memory) will compare as equal to the null pointer and this can be used in conditional statements to determine if a memory allocation has occurred, if a function has executed successfully, etc. Null pointers play an essential role in many of the basic operations that are performed with the abstract data structures of Chapter 9.

Pointers are key to dynamic memory allocation for vectors and arrays and for passing variables in a manner that will allow their values to be altered. To address the first point that in C++ there are three memory storage: automatic storage (or "stack"), static storage and the free-store or the heap. The free-store is a large block of memory used for allocation of memory at run-time. What would be used if there is any uncertainty about how much memory will be needed when you run your program. This, of course, is a common occurrence in many statistical applications where code could be adapt to data sets of general sizes that may be determined until run time. Even in the context of our random number generation programs the size of the random numbers need to be determined at run-time and could be arbitrarily depending depending on needs of the user.

The operator new used to allocate memory on the free-store. The syntax looks like

```
dataType* p = new dataType[size];
```

In this instance the operator returns a pointer to dataType whose value is the binding of size contiguous blocks of memory with each block being large enough to hold a dataType object.

double* p = 0;
p = new double[1];
