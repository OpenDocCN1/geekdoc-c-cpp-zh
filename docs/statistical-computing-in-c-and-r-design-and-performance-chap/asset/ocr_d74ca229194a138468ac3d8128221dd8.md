There are a few features that merit discussion in this listing. First, at the beginning of the listing three constants are defined: π,√2π and the optimal constant for use with the Cauchy instrument. This allows them with global scope as discussed in Section 3.2. That is, by defining pi, sqrt outside the scope of function in the program they become available to all functions that may need them removing the need to compute more than. The algorithm works through a while loop that terminates when nFill, the number of samples that have been accepted, coincides with the desired sample size. A variable that counts the number of rejected samples has also been included to assess the efficiency of using the Cauchy distribution for generation of samples from the normal distribution.
