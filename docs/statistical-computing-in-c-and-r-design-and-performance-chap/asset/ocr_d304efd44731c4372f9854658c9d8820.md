Suppose there are three arrays, x1, x2 of equal length and the formula log(y) ~ x1 + x1^2 + x1*x2 - 1 is used in the lm function. This specifies that a linear model was be fitted with data in x providing the independent variables in the form of the natural logarithm of its elements. The model is then to be fitted with terms involving x1 as well as its square and product with the values in the x2 array. The formula of a -1 in the formula results in no intercept. Otherwise, an intercept would be included by default.

The lm function returns object of class lm that member elements that include coefficients, residuals and fitted. These can be accessed using the $ operator. in this case the mtcars example produces

```
> mtl <- lm(A[, 1]) ^ A[, 2] + A[, "wt"]
> mtlm$Coefficients
(Intercept) A[, 2] A[, "wt"]
34.9605404 -0.01772474 -3.35082533
```

Note that both a column index and column name have been used to access a specific column of the array A that contains data. An application of the summary function to our lm object returns an analysis of variable table as well as other relevant information.

```
> summary(mtlm)
```
