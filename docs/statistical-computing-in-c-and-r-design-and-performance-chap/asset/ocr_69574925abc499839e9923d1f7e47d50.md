# ALGORITHM BASICS

Again, the function will inherit from the STL binary_function class with its first template parameter being type g5, a second parameter of type string and a bool return type. The problem is that function is a binary function and a unary function which find_if requires.

The STL provides the function adapter bind2nd that sets the second argument for a binary function at specified value thereby converting a binary function into a unary function. There is also a bind1 adapter that serves the same purpose for the first argument of a binary function. In terms of the way it is used in the lookup method, bind2nd will call the overloaded (()) operator for the g5Equal with its second argument set at value of the string argument supplied to lookup.

```
std::transform(&freq[0], &freq[40], &temp[0], std::bind2nd(std::minus<double>(), e));
std::transform(&temp[0], &temp[40], &freq[0], std::bind2nd(std::divides<double>(), sqrt(e)));

```

All that is computed is the "global" chi-square statistic for the entire data set. The creation of a more selective method that allows targeting of particular machine/ball combinations is left as an exercise (Exercise 10.11).

The first step in the chiSquare method is to calculate the frequency of occurrence of the different balls. This is accomplished by first creating an int that will be used to collect the data from the Pfreq objects that are members of the g5 objects in the container. The actual accumulation of frequencies will employ the accumulate algorithm from the STL library.

The basic idea for accumulate derives from the now (hopefully) familiar summing recursion

```
double sum = b;
for(int i = 0; i < n; i++)
sum += a[i];
```

That will sum the elements of an n-element array given a starting sum of b. The algorithm provides a way to create an abstract recursion of this.
A prototype for accumulate is

```
accumulate(iterator begin, iterator end, dataType initialValue,
binaryFunction f)
```
