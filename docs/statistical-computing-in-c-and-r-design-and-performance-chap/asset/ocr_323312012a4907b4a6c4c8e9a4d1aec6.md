# Algorithm 4.5 Poisson random number generation

```
sum = 0
X = 1
while sum < 1
    Generate Y from an exponential density with parameter 1/λ
    sum = sum + Y
    X = X + 1
end while
return X - 1
```

Show that this algorithm works in the sense that the returned value of $X$ will behave as a pseudo-random Poisson deviate with parameter $\lambda$.
