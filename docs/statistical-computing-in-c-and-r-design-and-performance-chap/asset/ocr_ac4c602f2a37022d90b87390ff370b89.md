This class Functor uses is probably the most direct approach and overloads the () operator with two arguments. The first corresponds to the optimization variable, as, while the second is an integer that is combined with if statements to determine which of the functions f' or f'' will be evaluated. Our previous one-argument version of () can live in harmony with the two-argument version and suffices for access to the function itself. An overloaded constructor that takes one function pointer has been provided to handle cases where no derivative information is available. The fact that the one-argument version of () can be interchangeably with object created from either class makes the Listing 8.11 function useful for derivative and derivative based methods without changing our previous code that was created for the latter methods.

The prototype for the Newton method now takes the form

```
double newton(double& f, double a, double b, double start,
int* i const);
```

The arguments for newton are a Newton object, the lower and upper terminals (a and b) of the interval that should contain the minimizer and a value to be used as an initial "guess" for the minimizer's location. For a convex function, specification of a and b would be extraneous to the algorithm. But, when dealing with functions that have multiple minima the inclusion of a and b provides means to check that the Newton method does not take you beyond the region of interest. In general, there is no risk that the Newton step f'(k) should produce a new value (k+1) in the region of interest and that this derivative f''(k) can also produce a floating-point 0. Both of these problems are met taking into account and that is the purpose of the i pointer argument for newton. This variable will return an error code that indicates either of the two problems has been encountered.
