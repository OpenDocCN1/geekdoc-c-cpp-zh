The Like class will be used to obtain the mla for the exponential distribution with density

```
f(x) = { theta exp(-theta x), x > 0,
        0, otherwise,}
```

for theta > 0. This is a trivial case in the sense that the mla has a closed form and is found to be the reciprocal of the sample mean sum_{n=1}^n xi/n. Its utility lies in the fact that it gives a test case where the answer is known.
