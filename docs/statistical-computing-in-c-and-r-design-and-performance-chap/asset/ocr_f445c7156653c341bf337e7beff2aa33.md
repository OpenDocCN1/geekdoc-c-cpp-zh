The argument list for the matrix constructor tells us the information that can be specified to create a default matrix object. The purpose of the first arguments is to provide clear data representing a collection of one or more real numbers that are to provide the entries in the matrix, nrow being the number of rows and ncol the number of columns. Thus,

```
> A <- matrix(data = 0, nrow = 3, ncol = 3)
```

produces a 3 ×3 matrix of all zero entries. The same effect is obtained from

```
> A <- matrix(0, 0, 3)
```

which shows that explicit use of the argument names is not necessary unless they are entered in the same order they appear in the function definition.

The byrow argument for the matrix class constructor is used to specify which elements of the data argument are used to fill in the matrix object by rows (when byrow = TRUE) or by columns (when byrow = FALSE). Finally, dimnames is an argument names for rows and columns of the matrix which can be discussed in more detail later. As an example, the command line input

```
> A <- scan("file", ncol = 3, byrow = TRUE)
```

would read a three-column data set with an arbitrary number of rows from the file myfile in the current directory and place it in the matrix object A. Note that the scan function treated the data as a one-dimensional array of length 3×n. The array was then reshaped by the matrix class constructor.
