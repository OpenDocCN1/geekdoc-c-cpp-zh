The (simulated) values for the "stock index" variable were generated with R’s arma.sim function This is capable of producing data from autoregressive and moving average models. Here we have used it for a first order autoregressive model of the form

```
$X_t = \phi X_{t-1} + \epsilon_t, t=1, \dots, 100,$
```

with $\phi=6$ and the $\epsilon_i$ zero mean, uncorrelated normal errors with standard deviation 5. The output from arma.sim was shifted by adding a factor of 2500 and then combined with the day vector using the paste function to create a 100 component character array indexData. This data is shown in Figure 10.1 that was created with the R ts.plot function for plotting univariate and multivariate time series.

We will use "stock index" data to illustrate various features of the STL list class. In particular, we will use it to demonstrate insertion of a new node into a list. To make this (somewhat) more meaningful, a particular date 1952-05-29 was omitted when the data from R was written to a file. This date corresponds to slot 96 of the indexData array and, hence indexData[-96] is the same array as the entry in 96. For future reference the last six lines of the complete data set were printed during our R session before writing the data to its files.
