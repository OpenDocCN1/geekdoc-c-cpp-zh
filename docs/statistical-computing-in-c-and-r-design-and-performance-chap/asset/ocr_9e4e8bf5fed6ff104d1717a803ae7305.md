This dereferencing works generally in that regardless of the type that is stored in the vector container, like v[i] will always return the object that is stored in its ith slot.

Of particular interest for data analysis purposes is the case

```
vector<double> > v;
```

that produces a container v[i] now corresponds to an “ordinary” array of doubles in its own right. So, for all practical purposes, v is a matrix with row v[i] and its (i, j) entry is accessed with v[i][j]. Note that the space after the first > in the declaration for v is necessary.

The advantage of using vector<double> v in lieu of vector v[] or double** is, in the infrastructure of the STL. For example, when using pointers or arrays, a programmer must, at some point, make a commitment in terms of size of the structure. This is tedious and error-prone. In contrast, class vector provides built-in methods that allow the user to add elements to the structure: either one-by-one or by inserting multiple elements at time.

The specific methods for the vector class that will be of most immediate utility for us are capacity, size, pop, push_back, insert and assign. The function size returns an integer that represents the number of objects that are currently being held in a vector. The capacity method gives the number of slots in a vector. The difference between the value returned by capacity and size is the number of objects that can be added to a vector before more memory must be allocated.

The push_back function adds an additional element to the end of the vector. The code snippet

```
vector<int> v;
int a = 1;
v.push_back(a);
```

creates a new vector object to hold variables of type int and creates a new slot at the end of v that is filled with the value in the variable (a or 1, in this case). To remove the last component from a vector we proceed similarly using the function pop_back.

```
v.pop_back();
```

would undo what we had previously accomplished with push_back.

Insertion of an obj into a vector requires us to use the iterator class that is an internal (ie., nested) feature of class vector. In general, iterators are obtained via the syntax

```
vector<className>::iterator iterator;
```

Then, as in Section 10.2, the insert method for class vector takes the form

```
v.insert(iter, obj);
```

where obj is the object to be inserted into the container. The effect of this command is to be inserted the object in the slot immediately prior to that specified by iter and an iterator that points to the inserted object. Thus, for example:

vector<className>::iterator iter = v.insert(v.begin() + 2, obj);
(*iter).methodName();
