# GENERATION OF PSEUDO-RANDOM NUMBERS

# 4.3 Lehmer type congruential number generators in C++

There are many linear congruential number generators that have been studied in great detail in the literature. In this section out will be focused on a particular variety of multiplicative generator deriving from a proposal in Lehmer (1949) that was later implemented by Payne, et al. (1969). The idea behind generators is to choose m as a large Mersenne prime and then take a to satisfy the conditions of Theorem 4.3 and to ensure that the maximum period is attained.

Let us now on the particular case of m = 2^31 - 1. One finds that

```
m - 1 = 2^31 - 2 = 2 * 3^2 * 7 * 11 * 31 * 151 * 331
```

All the numbers in this period are prime and the fundamental theorem of arithmetic (cf. Andrews 1971) entails that this factorization is: i.e., there are no other prime numbers that divide m. The second condition of Theorem 4.3 can now be checked to see if any particular a is a multiplier that will produce a full period. This approach allows us to verify the generator specified by

```
x_i = 630360016*x_{i-1} mod (2^31 - 1)
```

will have the full 2^31-2 period. The choice of a=630360016 was specified by Payne, et al. (1969). It appears as generator II in the Fishman and Moore (1982) comparison study and, for that, will hereafter be referred to as FM2.

An implementation of the FM2 generator is provided in the code below.

> Listing 4.1 basicFM2.cpp

```
//basicFM2.cpp
#include <iostream>

using std::cout; using std::endl;

unsigned long power(int i, int k){
    unsigned long long = (unsigned long)i;
    if(k > 1)
        nout = iout*power(nout, k - 1);
    return iout;
}

int main(int argc, char* argv[]) {
    unsigned long a = 630360016;///seed
    unsigned long seed = 123;///seed
    unsigned long m = power(2, 31); //modulus
    cout << "Your random number is "
    seed = (a%seed)%m;
    double u = ((double)seed)/((double)m);
    cout << u << endl;
    return 0;
}
```

