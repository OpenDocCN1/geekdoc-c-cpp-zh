# 40 A SKETCH OF C++

```
for(initializingExpression; testExpression; increment){
    statements and expressions
}
```

The loop begins with the initializing statement initializingExpression that will give the starting value for an index variable. After the first; a condition represented by testExpression is evaluated as either true or false. The execution of the related code (i.e., the statements between the two curly braces) or body of the loop continues until testExpression evaluates to false. Each time the body of the loop is executed, a control expression (usually the value of an index variable) is updated or incremented and testExpression is evaluated again.

A while loop appears like

```
while(testExpression{
    statements and expressions
}
```

Unlike the for loop, the while loop will continue to force execution of its associated code of as long as testExpression evaluates to true. Thus, the code

```
while(i){
    cout << "I'm in a loop" << endl;
}
```

will print "I'm in a loop" to standard output indefinitely until execution is forcibly terminated (Section 4 of Appendix A).
Actually, the for loops are equivalent in the sense that

```
for(; testExpression{
    statements and expressions
}
```

will emulate a while loop. Similarly,

```
initializingExpression;
while(testExpression{
    statements and expressions
    increment;
}
```

emulates a for loop using a while construct. The version of a for loop used here illustrates the arguments for a for loop are optional the semicolons are mandatory. In particular,

```
for(;);
    cout << "I'm in a loop!" << endl;
```

will produce the same effect as the previous while loop that printed the "I'm in a loop! message and must also be manually terminated by the user.
