# 3.8.8 Timing a program

To conclude this section we will touch on a topic that arises when evaluating numerical computation time. The idea is that one has written a program and wants to determine how long it takes to execute. The tools for accomplishing this are accessed through inclusion of the time header file. This makes the available function clock returns an object of type clock whose values represent processor time relative to some arbitrary point that excludes any time waiting for input, output or other processes that may be running. The constant CLOCKS_PER_SEC tells the number of ticks that occur per second and can be used to translate an interval of clock time into seconds. To avoid truncation from integer arithmetic the values of clock_t types should be cast to double (see Section 2.4) when using them to evaluate run-time for a program.
The listing below uses the clock function to calculate the time required to carry out computations in a loop.

```
//clockEx.cpp
#include <iostream>
#include <ctime>

using std::cout; using std::endl;

int main(){
    double x, sec;
    clock_t b = clock();
    while(x < 1000)
        x += 0.0001;
    sec = (double)(clock() - b)/(double)CLOCKS_PER_SEC;
    cout << "The while loop took " << sec << " seconds to compute x = "
        << x << endl;
    return 0;
}
```

Upon execution this output code produced for the particular machine where it was employed

The while loop took 0.346182 seconds to compute x = 1000

Thus about a third of a second was needed to compute a sum of 1000 when it is accumulated in increments of $10^{-5}$.
