As was true for the power class in Chapter 3, the FM2.h file essentially consists of just the class prototype that appeared at the beginning of FM2Class.cpp. The only real difference is the presence of the long guard preprocessor discussed in Section 3.7.

The header file for a class contains all the information that the class and does not need to know any of the details about the class methods, e.g., new computational methodology, in order to be able to use an object of the class. In fact, the code of the method definitions can be changed without affecting the class interface. This is an important feature in fact that altering the internal aspects of a method (in response to, new methodology) will not propagate into other programs that use the class. In addition, casual users of a class need not and, in general, should not alter method definitions. This latter fact is a particularly compelling reason why, the actual details of the class will be implemented in a separate source file.

As a case in point, the method definitions for the FM2 class will be placed in a file FM2.cpp that has the contents

```
//FM2.cpp

unsigned long iout = (unsigned long)i;
if(k > 0) {
out = iout*power(i, k - 1);

}
FM2::FM2() : a = 60360016, expFor2 = 31;

void FM2ragen(unsigned long seed, int n, double* pU) const {
unsigned long m = power(2, expFor2) - 1;
for(int i = 0; i < n; i++){
seed = (a*seed)%m;
```
