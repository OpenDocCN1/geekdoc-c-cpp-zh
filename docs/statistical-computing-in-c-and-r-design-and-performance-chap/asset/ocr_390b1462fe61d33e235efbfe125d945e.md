# 6.2 Creating a new class

Suppose that we wish to construct a new class named regr for dealing with a linear regression situation where an n x1 response vector y is to be related to p independent variables values are contained in the columns of an n x p matrix X. The analysis will produce, a vector b of least-squares coefficients. Of course R already provides the facility for this linear models (i.e., lm class) and this would be the superior option in cases of practical interest. The goal of the present exercise is not to produce a class that can compete with the lm class or something of much practical. Instead, the objective is to implement the steps involved in class creation in a relatively simple setting. A more detailed and useful illustration of the construction of classes and methods is the subject of Section 6.4.

To create a class in R one uses thesetClass and representation functions. For our regr class might take this form

```
> setClass("regr", representation(X = "matrix", y = "numeric", b = "numeric", intercept = "logical")
```

This command creates a class with four members, X, y, and intercept that are objects from the existing R classes (for the X matrix), numeric (for the response vector y and estimated coefficient b) and logical. By using the numeric class for y and b we have stated that they will be represented in R double precision objects. The Boolean variable intercept will be used to specify whether or not an intercept term is to be included in the linear regression fit to the data.

The getClass command provides a way to check that a class has been created correctly. For example, an application of getClass to our regr class returns

| Name X y b intercept |
| Class matrix numeric numeric logical |

This output tells that the class regr has four member elements (X, y, b and intercept) which R refers to as slots. The names of the elements (X, y, b and intercept) and their respective classes (matrix, numeric and logical) are also listed.

The command removeClass("className") will remove an existing class className from the current R session demonstrated in the next list.

```
> isClass("regr")
[1] TRUE
> removeClass("regr")
[1] TRUE
> isClass("regr")
[1] FALSE
```

Removal of the class was preceded and followed with an application of the isClass command that checks if its argument is a formally defined class. The FALSE return from its second application tells us the regr class is no longer defined.

An object from a class can be created with the new operator. In particular, using new with the regr class means

```
> regrObj <- new("regr")
> regrObj
```
