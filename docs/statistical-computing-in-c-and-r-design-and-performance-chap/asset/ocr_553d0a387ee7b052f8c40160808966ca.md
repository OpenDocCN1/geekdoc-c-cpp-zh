Only the name of the file was supplied read.table. This works because the target file group1.txt is in the current, viewed by R, working directory. If had not been the case, it would have been necessary to provide the path to the file.

Notice from the example that the default action is to use the letter V with column names for the variables and integers for the rows. There are various ways this behavior can be customized. For example, assign specific names to the rows and columns of the group1.txt, one might

```
> read.table("group1.txt", col.names = paste("Sample", 1:4,
+ sep = " "), row.names = paste("row", 1:6, sep = "")
Sample1 Sample2 Sample3 Sample4
rowrow1 25 26 30 38
rowrow2 25 24 29 25
rowrow3 31 24 28 39
rowrow4 27 20 25 29
rowrow5 31 22 28 34
rowrow6 35 29 20 40
```

There are two aspects of this operation that merit some additional comment. First, and foremost, this example illustrates how names are given to the rows and columns by supplying values for the col.names and row.names for read.table. Both arguments can be assigned an array of character values of the same length as the number of columns or rows. The other interesting feature is the specific character vectors were constructed in this case as will be explained.

The paste function provides a very convenient tool for creating characters from a mix of numeric and character values. It performs a character conversion and concatenation operation where all the elements supplied as arguments are converted to character mode and then concatenated with white-space separation into a single object. Thus, for example,

> > paste("Sample", 1)
[1] "Sample 1"

is a way to combine the string "Sample" and the integer 1 to create the string "Sample 1". The problem with this particular choice for, e.g., a column name for group1.txt data is the presence of an embedded space. R syntactically names can only use letters, digits, or underscores that do not start with a letter or are not followed by a blank space. Names which need this requirement in the case can be obtained by avoiding blank spaces. This is readily accomplished by setting the sep argument for paste as " ". For we could construct

```
> v <- c(paste("Sample", 1, sep = " "), paste("Sample", 2, sep = " "))
+ paste("Sample", 3, sep = " "), paste("Sample", 4, sep = " "))
v
[1] "Sample1" "Sample2" "Sample3" "Sample4"
```

and then use v as value for col.names in read.table to produce the results. Our practical approach uses an additional shortcut that exploits the way paste handles vectors: i.e., vector arguments are concatenated term-by-term to return a character vector. Consequently,

```
> paste("Sample", 1:4, sep = " ")
[1] "Sample1" "Sample2" "Sample3" "Sample4"
```

creates the desired character vector in one command by concatenating "Sample" with the vector
