# ABSTRACT DATA STRUCTURES

The functions dbInsert, dbFetch (or the indexing operator []) and dbDelete perform the hash table insertion, look-up and deletion operation dbExists can be used to check for the existence of a specified key. For example, the list below involves the same types of computations that were carried out using environments.

```
> set.seed(123)
> dbInsert(hT, "a", 1)
> dbInsert(hT, "b", matrix(rnorm(16), 4, 4))
> dbInsert(hT, "c", expression(1 + pi))
> dbInsert(hT, "d", 1:5)
> eval([["c"])
[1] 4.141593
> dbExists(hT, "d")
[1] TRUE
> dbDelete(hT, "d")
> dbExists(hT, "d")
[1] FALSE
```

As before, four objects are inserted into the hash table and the third expression object is evaluated using the index operator to perform the table look-up. The existence of the fourth object is tested using the dbExists function, it is removed from the table with dbDelete and success of removal is checked using dbExists.

The databases created using the filehash persist and can be accessed in future R sessions using the dbInit function. To illustrate this we created a “large” data file and ended the R session with

```
> dbDelete("bigfile")
[1] TRUE
> hT <- dbInit("bigfile")
> set.seed(123)
> invisible(apply(1:4, FUN = function(i) {
+ dbInsert(hT, paste("a", i, sep = ""),
+ rnorm(10^7, .05*i)))
})
> q()
```

A new session was started in the directory and a new filehash object was linked to the file with

```
> library(filehash)
filehash: Simple key-value database (2.1-1 2010-10-04)
> hT <- dbInit("bigfile")
> lapply(hT["a1", "a2", "a3", "a4"], FUN = mean)
```
