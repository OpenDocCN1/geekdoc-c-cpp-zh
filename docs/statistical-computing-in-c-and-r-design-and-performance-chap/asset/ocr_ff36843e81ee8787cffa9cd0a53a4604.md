The set of natural linear splines with knots at $x_1, \dots, x_n$ is a linear space with dimension $n$. As a result, it follows that $f_\lambda = \sum_{j=1}^n b_j B_j$ with $B_1, \dots, B_n$ some suitable set of linear basis functions. Substituting this representation into the estimation criterion produces the normal equations

Figure 7.1 *Linear smoothing splines with different choices for $\lambda$*

```
$(B^T B + \lambda\Omega)b = B^Ty$
```

for $b = (b_1, \dots, b_n)^T$ with

```
$B = \begin{cases} \{B_j(x_i)\}_{i,j=1,n}, \ \ \Omega = \begin{cases} \int_0^1 B'_i(x)B'_j(x)dx \ i,j=1,n \end{cases} \end{cases}$
```

and $y = (y_1, \dots, y_n)^T$ the response vector. The resulting vector of fitted values then has the form

```
$f_\lambda = (f_\lambda(x_1), \dots, f_\lambda(x_n))^T = H(\lambda)y$
```

for

```
$H(\lambda) = B(B^T B + \lambda\Omega)^{-1}B^T$.
```
