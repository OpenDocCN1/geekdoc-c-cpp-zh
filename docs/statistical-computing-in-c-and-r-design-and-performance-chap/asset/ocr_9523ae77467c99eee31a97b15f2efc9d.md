The effect of round-off error on minimization is seen in our examples which holds generally. To see this observe in Press, and for $\theta$ near the minimizer $\theta_{min}$ of a slightly different objective, function $f$

```
$f(\theta) \doteq f(\theta_{min}) + \frac{1}{2}(\theta_{min} - \theta)^2$
```

or

```
$|\theta_{min} - \theta| \doteq = \frac{2|f(\theta) - f(\theta_{min})|}{|f'(\theta_{min})|}$
```

with $f'$ the second derivative of $f$. Thus, if the function $f(\theta) - f(\theta_{min})$ can be evaluated to an accuracy of no more than $10^{-k}$, the minimizer can be expected to be approximated within an order of $10^{-k/2}$. As a result, $10^{-7/2}$ and $10^{-8}$ rather represent relative error bounds for single and double precision calculations, respectively. In terms of the effective iterations in double precision for the golden section method on $[0,1]$ this translates to an upper bound of about $-8/log_{10}(r) \approx 38$.

The function optimizer in R conducts a search for a minimizer (maximizer) using Brent's method (e.g., Press et al. 2005). This algorithm is a modification of the golden section that attempts to enhance its performance by mixing parabolic extrapolation (Exercise 8.5) with the golden section partitioning. A simplified version of the prototype for optimize is

```
optimize(func, lower = a, upper = b, maximum = FALSE)
```

Here is a function that has been defined in R and a and b are the lower and upper bounds for the interval to be searched. The logical parameter maximum False as its default value and need not to be specified for minimization. By setting maximum = TRUE the search will be conducted for a maximizer of func. The optimize function returns a two-component containing the approximate minimizer and the value of the objective function at the minimizer.

An application of optimize to $f(\theta) = -\theta(1 - \theta)$

```
> func <- function(theta){-theta*(1 - theta)}
> optimize(func, lower = 0, upper = 1)
$minimum
[1] -0.25
```

The objective function is quadratic which that parabolic extrapolation is exact here and the minimizer can be produced in a single step without the need for sectioning (Exercise 8.5).

The golden section algorithm is one of several optimization methods that do not require the existence (or knowledge) of the objective function's derivative. Other options include the bisection (Exercise 8.20), regula falsi and secant methods discussed in, e.g., Conte and Deor (1972), Press, et al. (2005) and Flowers (2006).
