To get samples from the chi-square distribution with an integer degrees-of-freedom $
u$ we could use the fact that such a random variable has the same distribution as sum of $\nu$ squared normal random variables. So one could generate independent standard normal random variables $Z_1, \dots, Z_{\nu}$ and then $X = \sum_{i=1}^{\nu} Z_i^2$ could be taken as the desired value. This is not the most computationally approach and a superior alternative is provided by Kinderman and Monahan (1977) (see also Section 11.2C of Monahan 2001) and Cheng and Feast (1979). The idea is a consequence of our next theorem.

**Theorem 4.5.** *Let $f$ be a density on the real line and suppose that the random variables $U_1, U_2$ have a joint distribution that is uniform over*

```
A = \{(u_1, u_2) : 0 \le u_1 \le \sqrt{f(u_2/u_1)}\quad (4.15)
```

$U_2/U_1$ is a random variable with density $f$.

*Proof.* To evaluate the area of the region A To do, make the change of variable $u_1$ and $u_2$ to $x_1 = u_2/u_1$ and $x_2 = u_1$. The Jacobian for this transformation is $x_2$ so that

```
\int_{-\infty}^{\infty} \sqrt{f(x_1)} x_2 dx_2 dx_1 = \frac{1}{2} \int_{-\infty}^{\infty} f(x_1) dx_1 = \frac{1}{2}.
```

The joint density for $X_1 = U_2/U_1$ and $X_2 = U_1$ is therefore

```
h(x_1, x_2) = \begin{cases} 2x_2, & 0 \le x_2 \le \sqrt{f(x_1)},\n0, & \text{otherwise.} \end{cases}
```

The marginal density for $X_1$ is now to be $f$ which establishes the theorem.

To use Theorem 4.5 in practice we need to be able to bound the region A where $U_1$ and $U_2$ reside. Then, until variables are uniformly distributed over the region laid by the bounds. Now, at least $U_1 \le \max_x x\sqrt{f(x)}$ and $U_2 = U_2/U_1$, it is also true that $\min_x x\sqrt{f(x)} \le U_2 \le \max_x x\sqrt{f(x)}$. Thus, random variables $U_1$ and $U_2$ can be generated with uniformly distributed over $[0, \max_x x\sqrt{f(x)}]$ and $[\min_x x\sqrt{f(x)}, \max_x x\sqrt{f(x)}]$, respectively. If $U_2^2 \le f(U_1)$ is accepted as a sample from the distribution corresponding to $f$ and otherwise the process is repeated.

As Chen and Feast (1979), we will apply this to the case of a gamma random variable with the density

```
f(x) = \begin{cases} \frac{1}{\Gamma(\alpha)}x^{\alpha-1}\exp\{-x\}, & x \ge 0,\nn0, & \text{otherwise.} \end{cases}
```

This will allow us to simulate chi-square random variables as a random variable $X$ with a gamma distribution can be transformed to a chi-square random variable $Y$ with $\nu = 2\alpha$ degrees-of-freedom by taking $Y=2X$.

If $\alpha > 1$, we should assume that the case, $x^{\alpha-1}\exp\{-x\}$ and $x^{\alpha+1}\exp\{-x\}$ are maximized at $x = \alpha-1$ and $x = \alpha+1$. Thus, in our previous formulation $\max_x x\sqrt{f(x)} \le [(\alpha-1)/e]^{(\alpha-1)/2}/\Gamma(\alpha)$ and $0 = \min_x x\sqrt{f(x)} \le [((\alpha+1)/e]^{(\alpha+1)/2}/\Gamma(\alpha)$. Gamma random deviates can therefore be generated using Algorithm 4.3 (Exercise 4.23).
