The following illustrates how scan can be used to read the data from our group1.txt file.

```
> A <- scan("group1.txt", what = integer(0))
Read 24 items
> storage.mode(A)
[1] "integer"
> A
[1] 25 26 30 35 38 24 29 31 24 28 39 27 20 25 29 31 22 28 34 34 35 29 20 40
```

By setting equal to integer(0) the data has been imported as type integer rather than double. Unfortunately

```
> A <- cbind(A[seq(1, 20, by = 4)], A[seq(2, 20, by = 4)],
+ A[seq(3, 20, by = 4]), A[seq(4, 20, by = 4)]
```

that also uses the scan and cbind functions discussed in Appendix B. A more direct route to preserve the structure in an input file is available through the list of types that corresponds to the different columns in the input file. For our example, this might take the form

```
> A <- scan("group1.txt", what = rep(list(integer(0)),4)
Read 6 records
> A
[[1]]
[1] 25 25 31 27 31 35

[[2]]
[1] 26 34 24 20 22 29

[[3]]
[1] 30 29 28 25 28

[[4]]
[1] 38 25 29 39 34 40
```

In specifying the value for what we used the R replication function rep. The prototype for this function works an R object and times the number of times the object is replicated. The rep returns an object of the same type as x argument times copies of x. For our case, using rep(list(integer(0)),4) is equivalent to

```
> scan("group1.txt", what = list(integer(0), integer(0), integer(0),
+ integer(0))
```

Also, note that the returned by scan in this instance is a list which entails its component vector accessed using the [] operator. The matrix form for the data could be recovered with, e.g.,

```
> A <- cbind(A[[1]], A[[2]], A[[3]], A[[4]])
```

While scan reads one value at a time from a file, the readLines function will read the file in one line at a time. An application of readLines to the group1.txt produced

```
> A <- readLines("group1.txt", n = 2)
> A
[1] "25 26 30 38" "25 34 29 25"
```
