In our current search procedure would, in theory, continue indefinitely, unless safeguards which will eventually terminate the search. A typical stopping rule would conclude the search if preset maximum of iterations is exceeded

```
$|minTemp^{(k+1)} - minTemp^{(k)}| < \delta minTemp^{(k)}$
```

with $minTemp^{(k)}$ our approximation to the minimizer of the $k$th iteration and $\delta$ a small constant. From Section 2.5 we know that for single and double precision cannot detect differences smaller than $10^{-7}$ or $10^{-16}$ which would seem to make them obvious choices for $\delta$. However, these options are much too general for purposes and perhaps $10^{-7}$ and $10^{-8}$ represent more attainable choices as will be explained below.

The search procedure we have described is the golden section algorithm. Formal pseudo-code of the method is provided in Algorithm 8.1 for user-specified values of $\delta$ and the maximum number of iterations itMax.

# Algorithm 8.1 Golden section algorithm

```
niter = 0, r = (1+\sqrt{5})/2, minTemp = b, change = \infty
low = a, up = b, f_{low} = f(a+(1-r)(b-a)), f_{up} = f(a+r(b-a))
while $\delta > |minTempLast|$ and niter < itMax
  minTempLast = minTemp
  minTemp = (low + up)/2
  if $f_{low} < f_{up}$
    up = low + r(up-low), f_{up} = f_{low}
    f_{low} = f(low+(1-r)(up-low))
  else
    low = low + (1-r)(up-low), f_{low} = f_{up}
    f_{up} = f(low+r(up-low))
  end
  change = minTemp - minTempLast
  niter = niter + 1
end while
```

A measure of the efficiency of an optimization procedure such as Algorithm 8.1 is its convergence rate. If $\theta_{min}$ is the value of $\theta$ that minimizes $f$ and $\theta^{(k)}$ is the approximation of $\theta_{min}$ on the $k$th step of the search, the convergence rate for the algorithm is (relative) rate at $|\varepsilon_{k+1}| \leq C|\varepsilon_k|$ for some constant $C$ when $k$ is large. The golden section search provides one example of an algorithm that exhibits linear convergence.
