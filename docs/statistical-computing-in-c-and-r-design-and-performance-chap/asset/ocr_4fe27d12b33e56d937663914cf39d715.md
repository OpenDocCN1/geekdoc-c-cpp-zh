# 7.2.5 An application: linear smoothing splines

One application of banded Cholesky methods is in the computation of linear smoothing splines that are used for nonparametric regression and scatter plot smoothing. The problem involves bivariate $(x_i, y_i), i=1, ..., n$, with $0 \leq x_1 < ... < x_n \leq 1$. A linear smoothing fit $f$ to this data is obtained through minimization of criterion

> $$\sum_{i=1}^{n} (y_i - f(x_i))^2 + \lambda \int_{0}^{1} (f'(x))^2 dx, \lambda = 0$$

over continuous functions $f$ with square-integrable derivatives. It is known (e.g., Wahba 1990) that $f_{\lambda}(x)$ is a piecewise linear function whose derivative jumps continuously and vanishes outside of $[x_i, x_{i+1}]$. The smoothing parameter $\lambda$ in (7.8) governs the smoothness or goodness of the fit to the data. As $\lambda$ grows large $f$ tends to the average of $y_i$ as $\lambda \to 0$ the fitted function interpolates the $y_i$; that is, $\lim_{\lambda \to 0} f_{\lambda}(x_i) = y_i, i=1, ..., n$.
