It will be useful to recall some of the details concerning the fictional Guess game that was introduced in Section 5.6. The game consists of five balls being selected from a set of 40 balls without replacement. The drawings occur on Monday and Thursday using one of the two machines, A or B and of the ten balls, numbered 1 to 10. A series of ten draws are conducted prior to each draw producing a total of 10 selections of five balls every Monday and Thursday.

A set of data corresponding to 10 Guess draws was created in Section 5.6 and stored in the file guess.txt.
