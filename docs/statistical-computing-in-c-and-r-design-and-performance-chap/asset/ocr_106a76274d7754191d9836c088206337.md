The class now contains a method for computing the transpose of the matrix as well as overloaded operators for addition, multiplication and element access. In particular, the subscript operator [] is defined inline. Although it may not be entirely obvious, this gives access to the matrices. From this, suppose that A is a Matrix object. Then, from the operator's definition, A[i] = p[i] for a given index i. But, that means A[i][j] = p[i][j] which verifies our claim. The const modifier before the double* return type in Listing 3.15 is to ensure that the elements of the matrix cannot be modified; that is, with const double* the statement such as A[i][j] = b for indices i and j and some constant b will produce an error message.

Implementations of the two methods for matrix addition whose prototypes appear in the class Matrix header are listed in the following list:

```
Matrix::operator+(const Matrix& B) const {
if(nRows != B.nRows || nCols != B.nCols) {
	cout << "Bad row and/column dimensions in !" << endl;
	exexit(1);
}
Matrix temp(nRows, nCols);
for(int i = 0; i < nRows; i++) {
	for(int j = 0; j < nCols; j++) {
		temp.pA[i][j] = this->pA[i][j] + B.pA[i][j];
	}
}
```

```
Matrix::operator+=(const Matrix& B) {
if(nRows != B.nRows || nCols != B.nCols) {
	cout << "Bad row and/column dimensions in !" << endl;
	exit(1);
}
for(int i = 0; i < nRows; i++) {
	for(int j = 0; j < nCols; j++) {
		pA[i][j] += B.pA[i][j];
	}
}
return *this;}
```

Both additions first check that the row and column dimensions of the two matrices agree so addition is possible. The + operator uses the diagonal Matrix constructor to create a temp of all zeros that is of right size to hold the matrix sum.
