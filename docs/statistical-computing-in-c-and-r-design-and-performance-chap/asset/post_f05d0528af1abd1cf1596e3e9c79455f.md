```cpp
int main(int argc, char* argv[]){
  int start = atoi(argv[1]);
  int bound = atoi(argv[2]);
//compute the sum with a for loop
int sum = 0;
for(int i = start; i <= bound; i++)
  sum += i;
  cout << "The sum from the for loop is " << sum << endl;
//compute the sum with a while loop
sum = 0;
int i = start;
while (sum <= bound){
  sum += i;
}
  cout << "The sum from the while loop is " << sum << endl;

}
```

Values for the bound and the starting point for the summation are passed into the program as the second and third character strings that are entered on the command line after the ./ prefixed name of the executable. They are converted from character values using the atoi function that used previously in 2.3. The sum is then initialized to 0 and incremented iteratively in each of the two loop structures. Results from the program might appear like

```

```

There are two other conditional statements in C++ that can provide alternatives to if/else blocks: switch and the conditional operator ?. The switch statement allows selection among different sections of a set of code depending on the value of an integral expression. As such, it can provide a convenient alternative to if/else blocks when dealing with logical conditions that produce multiple branches. The syntax for the conditional operator is

```
testExpression ? expression1 : expression2
```

Here testExpression is a logical construct. When it evaluates to true, expression1 is executed and expression2 is enacted. Detailed treatments of switch and the conditional operator can be found, for example, in Chapter 6 of Prata (2005).

It is sometimes necessary to terminate a loop when some unusual condition arises. A break statement will terminate the execution of the most interior enclosing loop or conditional statement in which it appears. For example,

```cpp
//breakEx.cpp
#include <iostream>

using namespace std;

int main(){
  for(int i = 0; i < 3; i++)
    for(int j = 0; j < 10; j++)
      if(j == 2) break;
      cout << j << "";
}
```

# 3.5 Using arrays and pointers

To this point we have primarily dealt with primitive data types. These include arrays and classes which are the building blocks for compound data types that are either primitive or defined. Arrays will be treated in this section while pointers are the topic of Section 3.7.

An important part of most programming languages is the use of arrays for data storage and manipulation. A one-dimensional array is a vector that, in C++, may contain objects of any one data type, either.

Arrays are declared in C++ code using square brackets []. There is nothing special about the one-dimensional case. The declaration is

```cpp
int nRows[nCols];
```

will reserve the memory space for a two-dimensional integer array or matrix with nRows rows and nCols columns. The (i, j)th array is accessed using x[i][j]. Note that in C/C++ 0-offset indexing, which means the first element of a one-dimensional array is x[0] rather than x[1]. Similarly, the first component of a two-dimensional array is x[0].

```cpp
double a[3] = {1, 2, 3};
int a[7] = {1, 2};
float a[2][3] = {{1, 3, 5}, {2, 4, 6}};
```

The first statement initializes a three-element array of doubles with a[0] = 1, a[1] = 2 and a[2] = 3. The second statement initializes only the two elements in the integer array a[0] and a[1]. The uninitialized elements are set to 0 by default; Finally, a is a 2x3 array with row a[0][0] = 1, a[0][1] = 3, a[0][2] = 5 and second row a[1][1] = 4, a[1][2] = 6.

Another way to work with arrays is through the use of pointers. The value of an object type pointer is a memory location. Pointers may have indices beyond their connection to arrays that make an essential ingredient of any C++ programmer's repertoire.

Whenever we execute a program it is loaded into the computer's memory. One may think of memory being sequentially arranged, one-byte blocks that are numbered from zero and going up to an integer that represents the total amount of available memory, although this may not be strictly in reality. Each part of the program occupies one or more of these memory blocks. The address of a program component can be accessed in C/C++ using the address operator &. An illustration of this is the following simple program.

# USING ARRAYS AND POINTERS

```cpp
//addresses.cpp

#include <iostream>

using namespace std;

int main() {
    double v[4] = {1., 2., 3., 4.};
    cout << "Address of v[0] = " << v[0] << endl;
    cout << "Address of v[3] = " << v[3] << endl;
    return 0;
}
```

produces the (machine-dependent) output
```
$ g++ -Wall addresses -o addresses
Address of v[0] = 0xbffff9d0
Address of v[3] = 0xbffff9e8
```

The addresses returned from the program are in hexadecimal format with the letters a, b, c, d and e corresponding to 10-15. The output shows, that it will always be true for arrays in C++, the storage for v has been allocated in contiguous blocks of bytes of memory. To see this, first recall that a double is allocated eight bytes of storage. Then, note that the memory allocated to the first component of v at 0xbffff9d0 is 24 (i.e., 3 × 8) bytes (counting in hexadecimal) from the memory where its last component begins at 0xbffff9e8.

Pointers are variables that allow us to work with addresses. A pointer takes a memory location address as its value and provides the facility to access (i.e., read or write) to that location. A pointer p to an object dataType is declared via the syntax

```cpp
dataType* p;
```

So, example,

```cpp
int* p;
```

declares a pointer p that can be used to hold the address of a variable of type int. This can hit a bit further, if we write

```cpp
int* p;
int i = 1;
p = &i;
```

the result is p "points" to the address of i in memory. To access the number that is stored in this location, the pointer is dereferenced using the syntax *p. This is illustrated by the code example below.

```cpp
//simplePointer.cpp
#include <iostream>

using namespace std;

int main() {
    int* p = 0;
    int i = 1;
    p = &i;
    cout << "Address of i = " << &i << endl;
    cout << "Address of p = " << &p << endl;
    cout << "Value of p = " << p << endl;
    cout << "Value of i through p = " << *p << endl;
    return 0;
}
```
