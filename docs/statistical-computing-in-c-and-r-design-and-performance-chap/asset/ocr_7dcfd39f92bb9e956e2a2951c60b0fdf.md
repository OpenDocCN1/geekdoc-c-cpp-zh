# AN FM2 CLASS

Recall from Chapter 3 the C/C++ compiler requires us to provide a sketch prototype information about classes before they can be used. Accordingly, statements 8-9 of Listing 4.2 tell the compiler that FM2 has two data members: name, and an exponent that is to be used in the modulus exp2. The members are declared to have types unsigned long and int, respectively. Statement 10 then gives the prototype for the named recursive function. This function is only used internally in the method range and is therefore designated as private.

The next group of statements (i., 13–14) give two special functions: the class constructor FM2 and the destructor FM2 that are used to create and destroy objects from the class. Finally, a prototype is provided for the actual random number generation function that has been called range. The arguments for this function will be the seed, the sample size n and a pointer to "array" of n double precision locations. The class prototype ends with delimiter;

The functions or methods that appear in the class (with the exception of the class destructor) are defined in detail next. The compiler is informed that these functions belong to the class FM2 through use of the scope resolution operator ::. The (default) class constructor, the function FM2 sets the value for the constant and the exponent for the modulus in a way that produces the FM2 generator defined as in (4.4). The FM2 class could, be structured to provide much more freedom in the creation of a generator by making different choices for a and exp2. This could be incorporated into the class by including an additional constructor that would take its values as arguments (Exercise 4.11), or if the FM2 generator is all we need to use the value of m = 2³−1 be defined as a global constant to avoid having to (repeatedly) compute it.

The purpose of the destructor is, among other things, to release any memory that has been dynamically allocated in constructing an instance of the class or an object. There is no such commodity that arises in this implementation which means FM2() is just the trivial function with empty body the curly braces. The effect will be that the memory will be deleted on an element-wise basis whenever an FM2 object goes out of scope. This is actually the behavior for the destructor that is automatically called when none has been freed. Consequently, our explicit specification of destructor on line 14 of Listing 4.2 was unnecessary in this instance.

To use an object of type FM2 a pointer to a class FM2 is created on line 45 of main. In this instance, the new object calls the class constructor and allocates this memory which is sufficient to hold all the aspects of the resulting FM2. Once this object is available, the range method can be accessed via the - operator. Lines 46–49 and 51–54 are carried out to show that the requested memory allocation was successful. If the pointer returned from the version of new will be null which equates to the Boolean value false. In case, an error message will be output and the C++ system function exit (available via the cstdlib header) from Section 3.8 will be used to immediately terminate the execution of the program.

One possible variation on the design of this class involves allocation of the design that holds the actual random numbers produced by the program. The tactic taken here has been to allocate the memory in main thereby making the process more obvious. One could as easily as have made the vector of random numbers a (private) member class of FM2. If that destructor would actually need to perform the memory release and it would be necessary to add another (const) class method that would provide access to the values of random numbers.
