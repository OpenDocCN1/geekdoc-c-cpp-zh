The errors incurred from floating-point division can be bounded similarly to the case of multiplication (Exercise 2.5). However, this is not true for floating-point addition and subtraction. In fact, as noted by Wilkinson (1963, page 17), it is not possible to obtain a bound for the relative errors associated with such calculations as the floating-point sum can be zero when the sum is zero.

An indication of how problems can arise from subtraction is provided by taking $x$ and $y$ to floating-point numbers with $m$ significands $x=1.0\dots^v$ and $y=b_0b_1\dots b_{m-1}.^v$ with $b_0=\dots=b_{m-1}=1$. In this instance the difference between $x$ and $y$ is $2^{v-m}$. This difference is amplified by $2^m$ for chopping and rounding to the closest value. The absolute error for approximating $x-y$ is one in either case because $(2^{-(v-m)})/2^{v-m}=1$ and $(0-2^{-(v-m)})/2^{v-m}=-1$. This implies that the absolute error in subtracting $x$ from $y$ using floating-point calculations can be as large as the quantity $x-y$. Put, there may be no digits of accuracy in the output unless taken to provide additional accuracy in the calculation.

# 2.6 Computing a sample variance

One of the earliest calculations carried out in an elementary methods course is computing a sample mean and standard deviation from a set of data values. The sample deviation is defined to be

```
$S=\sqrt{RSS/(n-1)}$
```

with RSS is the residual sum-of-squares

```
$RSS=\sum_{j=1}^{n}(x_{j}-\bar{x})^{2}$
```

with $\bar{x}=n^{-1}\sum_{j=1}^{n}x_{j}$ the sample mean.
