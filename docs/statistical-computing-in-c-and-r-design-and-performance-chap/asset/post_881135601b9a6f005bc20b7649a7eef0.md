The C interface can be used to import any of the C++ code that has been developed far into R. For example, let us consider how this could be accomplished using our Moore random number generator from Chapter 4. First, the FM.cpp and FM.h files from Chapter 4 must be renamed as FM.cc and FM.hh, respectively. Next, an interface program must be created. For this particular case something like

```cpp
//fmR.cc
#include "R.h"
#include "FM.hh"

extern "C" {

void rngFM(int* N, int* SEED) {
    int n = *N;
    unsigned long seed = (unsigned long)*SEED;
    FM* pM = new FM();
    double* pu = new double[n];
    pM->ranGen(seed, n, pu);
    printf("Your random numbers are\n");
    for(int i = 0; i < n; i++)
        printf("%f \n", pu[i]);

    delete pM;
    delete pu[];
}
}
```

will suffice. Then, the interface file fmR.cc and the FM.cc are compiled and linked into a shared library fmR.so as

$ CMD SHLIB fmR.cc FM.cc

The final step is to import the fmR.so library into the R environment using the dyn.load function in the manner

# 192 PROGRAMMING IN R

> dyn.load("fmR.so")

The random number generator program can now be executed using the .C function. It is a bit less cumbersome to "wrap" rngFM in an R function that takes care of actually calling and passing the arguments to C. A function that serves this purpose is

```r
rngFM <- function(N, seed) {
  C("rngFM", as.integer(N), as.integer(seed))
}
```

```
a = 0, b = 1
for j := 1 to n
  m := (a + b)/2
  if f(a)f(m) <= 0
    a := a, b := m
  else
    a := m, b := b
  end if
return (a + b)/2
```
