We come now to the start of the program signaled by the appearance of the word main. Every C++ program must have one and only one **main function**. It serves the purpose of directing the flow of activity within a program. While there may be many functions and objects whose actions are intricately laced throughout a program, wherever takes place must have been initiated by directions main. The body of main (as well as that of any function) is enclosed by the matching braces { }.

In terms of content, main in Listing 2.1 is a clear of explanatory text to be printed with values that are returned by the *sizeof* operator. An application of *sizeof* to a particular data type (supplied as an argument) returns the number of bytes that are used for its storage.

The symbols << and >> are the output and insertion operators that work with the standard input and output objects cin and cout, respectively, that relay information to and from (typically) a. The output manipulator endl provides the facility to chain together input/output operations. The output manipulator endl that appears at the end of each output line produces a carriage return (or starts a new line) and flushes (or clears) the output buffer. You will see the effect of this when we look at our program. Note that each line of code in main is ended with a semicolon.

The final line of the program is return 0; In general the return statement has that one might effect; it returns to a calling function. In the case of how it is used here in main, it transfers control to the operating system. An exit integer with a value of 0 is returned upon completion of the program. The fact that 0 is viewed as an integer is a consequence of the *int* designation that immediately precedes main. Is true more generally in that a function must return a value of the same type that appears in its definition with the exception of main functions and functions with return void. The "storage size" source code was saved as storage.cpp. The cpp file extension is one of the permissible options for the compiler that is available in Unix environments. The others are .cc, .cxx and .C. To run it, we first compile

```
$ g++ -Wall storageSize
```

The compilation begins with g++ that invokes the GNU compiler. This has the effect of transforming the input fileSize.cpp into machine language. In this, there were two compiler options that were used: -Wall on all of the most commonly used warnings while -o allows us to specify the name of the executable, as storageSize in this instance. Without the -o option the executable would be a.out by default; the a.out is an abbreviation of "assembly output"
