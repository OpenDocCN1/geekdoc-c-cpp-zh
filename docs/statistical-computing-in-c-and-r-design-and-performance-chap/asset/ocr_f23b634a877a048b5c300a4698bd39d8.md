Algorithm 9.14 shows how to extract a node from a heap. One swaps the highest-indexed element, reduces the size by one, down-heapifies the root and then returns the former root as output. The idea is illustrated in Figures 9.6-9.8 for the heap in Figure 9.1. The first step is to swap the elements in the first and thirteenth (or last) positions producing Figure 9.6. Next, the new node is swapped with the second node in Figure 9.7 since this is its smallest child. Next, the new node is swapped with its smallest child in Figure 9.8 and the heap priority is restored.

Algorithm 9.14 extractMin(): Extract the minimum from a heap in an array A
Swap A[1] and A[size]
size := size - 1
downify(1)
return A[size + 1]

This process used for removing the minimum can be used to sort objects that are stored in a heap. All that is necessary to make size consecutive elements in heap is to call extractMin as given in Algorithm 9.15.
