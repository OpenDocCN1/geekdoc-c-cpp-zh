The file methods getVRows getV return the number of observations and the elements of the vector<string > object that holds the data. The question remains how to effectively extract the information from the index from this object. To illustrate the problem, consider the first line of index.txt file that looks like

1952-01-17 997.9762176724

The first object returned by getV(0, 0) in this case will be 1952-01-17. We need to extract the value for Day (i, 17), Month (i, 1) and Year (1952) from this string and use them to create a Date object. There are various ways to deal with the individuals in a string object. Array type indexing can be done and will work here (with the + operator for concatenation) if it can be assured that the month and day values will be recorded as two-digit integers, with leading zeros. We have opted for a slightly more robust alternative adapted from the tokenizer of Section 10.3.2. An application of the class class find_first to the string 1952-01-17 with its argument will return the location to the right of the Year value 1952. A similar use of find_last_of will give us the location that immediately precedes the Day value 17. All this is enough; it does not address the issue of how to actually obtain the value for Day, Month and Year. The substr method gives us an option that will work regardless of how many days are used when recording the dates. Its mnemonic moniker suggests, this function creates a copy of a subset of the elements in a string object. It takes two arguments: the first is the location where the copying begins and the second is the number of consecutive elements that are be copied starting at that location. If the second argument is not supplied, the end of the string object is used by default.

By using string methods, the problem of extracting the Date in the IndexError constructor reduces to simple bookkeeping. First, we pinpoint the locations of the two dashes and store them in the variables idx1 and idx2. Then, these are used to define the number of elements for substr. The substr method returns a string object which requires an application of the c_str method to convert its output into a C-style string. After obtaining the date information, it can be used directly to construct a Date object.

Once the date has been processed, the observed value for the response or "index" variable will be the next object in the vector<vector<string>> container member of the FileIndex. This can be converted to type by combining the c_str method and atof. Then, the result will be used with the corresponding Date object to create an IndexError object for insertion into the list member of the IndexError class using the push_front method. This process continues until getVRows() observation in the data have been exhausted.

The list class has an insert and a push_back method that perform interior insertions and add to the tail of a list object, respectively. For this particular setting it is somewhat convenient to combine these into a single method of the

```
list<IndexData>::iterator insert(const IndexData& d{
list<IndexData>::iterator iter = L.begin();
while(iter->T >= d.T && iter != L.end())
iter++;
if(iter == L.end())
L.push_back(d);
else
L.insert(iter, d);
return iter;
}
```
