Once the draws have been created in List 5.5, the next step is to generate the vectors of machine and ball selections. Again, not having to artificially mimic the drawing process leaves us to generate these two arrays using the sample function Section 3 of Appendix B with the populations considering the characters “A” and “B” and the integers from 1 to 10.

The day for each draw is given by the date and can be extracted using the weekdays. Rather than store the entire name for a day, the characters “M” and “T” are extracted off from the string that holds the day's name with the substr function. The start and stop arguments for this function define the position of the beginning and ending character to be used in creating the substr. Thus, setting both start and stop as 1 will return the first character in the string.

The vectors drawDate, Machine and Set are combined into an n-row array using the cbind function. The rows of this array must then be paired with the actual drawing data. The later aspect of the simulation is accomplished by a combination of the replicate and sample functions; namely:

```
A <- replicate(n=10, sample.int(40, 5))
```

The replicate function is a member of the apply-family family that can be used for repeated evaluation of an expression. Its prototype has the form

```
replicate(n, expr)
```

where expr is to be evaluated and n is the requested number of evaluations. For our application, n is 10 times the total number of drawings: 9 test draws and 1 game occur every time the game is played. The actual numbers for the balls that are drawn are produced using the function sample.int. This is a specialization of the sample function that has the basic form

```
sample.int(n, size, replace)
```

This version assumes that the population being sampled is the integers from 1 to its first n. The replace argument defaults to FALSE as required for our case.
