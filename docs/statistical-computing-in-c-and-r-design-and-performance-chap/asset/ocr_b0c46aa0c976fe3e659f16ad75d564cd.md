An examination of the coefficients from our running mcmat example suggests that the blot of regrCar can be simplified to (20,0,-5,1). Thus, we might need to perform the operation

```
>regrCar <- c(20, 0, -5, 1)
Error in bHat(regrCar) <- c(20, 0, -5, 1) :
  could not find function "bHat-"
```

This error message is a bit confusing as we just wrote and successfully used our bHat accessor function. The problem is that we are not using bHat here, instead, attempting to use its replacement version bHat<- (Section 5.4) that has not been defined for the regr class. This oversight is easy to correct

```
> setGeneric("bHat-", function(x, value) standardGeneric("bHat-")
[1] "bHat-"
```

We then replace the name of the method using function

```
> replaceMethod("bHat", "regr", function(x, value)
+ {x0 b <- value;}
[1] "bHat-"
```

Then, the alternative version of the coefficient vector can be installed with

```
> bHat(regrCar) <- c(20, 0, -5, 1)
> bHat(regrCar)
[1] 20 0 -5 1
```
