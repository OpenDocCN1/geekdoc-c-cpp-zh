The process can be continued and, in general, movement from the kth to the (k + 1)st update is accomplished via

```
\theta^{(k+1)} = \theta^{(k)} - \frac{f'(\theta^{(k)})}{f''(\theta^{(k)})}$
```

Algorithm 8.2 summarizes the form of Newton recursions for user-specified values of the tolerance parameter $\delta$ for the minimum relative difference between successive approximations to the minimum, the maximum number of iterations $itMax$ and an initial starting point $\theta^{(0)}$.

```
Algorithm 8.2 Newton-Raphson algorithm
niter = 1, minTemp = \theta^{(0)}, minTempLast = b
while |minTempLast - minTemp| > \delta|minTempLast| and niter < itMax do
  minTemp = minTempLast
  minTemp = minTempLast - f'(minTempLast)/f''(minTempLast)
  niter = niter + 1
end
return minTemp
```

Not only does the Newton approach work but it actually produces quadratic rates of convergence near mean compared to the linear rate achieved by the golden section method. To see this define

```
\varepsilon_k = \theta_{min} - \theta^{(k)}.$
```

Now that if $f$ has a third derivative $f'''$ the condition $f''(\theta_{min}) = 0$ implies that

```
$f'(\theta^{(k)}) + f''(\theta^{(k)})(\theta_{min} - \theta^{(k)}) + \frac{f'''(\theta^{(k)})}{2}(\theta_{min} - \theta^{(k)})^2 = 0$
```

or, equivalently that,

```
\theta_{min} - [\theta^{(k)} - \frac{f'(\theta^{(k)})}{f''(\theta^{(k)})}] = \frac{f'''(\theta^{(k)})}{2f''(\theta^{(k)})}(\theta_{min} - \theta^{(k)})^2$
```

with $\theta^*$ a point between $\theta_{min}$ and $\theta^{(k)}$. Thus,

```
\varepsilon_{k+1} = \varepsilon_k^2 \frac{f'''(\theta^*)}{2f''(\theta^{(k)})}$
```

and our claim has been verified.
