The sorting process uses recursion (cf. Exercise 3.7); i.e., each time the minimum element is removed from the list sortList calls itself. This process continues until the list is of size one. At that point the last two lines of the function are realized for the first time after the minimum elements from the previous iterations are sequentially collected in the new y.

There is another way to create an S4 generic function: add a method to any existing function. A simple example that demonstrates the basic idea

```
> func <- function(x, y) x*y
> setMethod("func", signature(y = "integer"), function(x, y) y)
Creating a generic signature from function "func"
[1] "func"
> func(3, 3); func(3, as.integer(3));
[1] 9
[1] 3
```

We can use this approach to create an S4 generic function from the existing S3 function sort. It has arguments

+   - args(sort)
function(x, decreasing = FALSE, ...)
NULL

A new S4 generic function that adheres to this format can be created with

```
> setMethod("sort", signature("g5List"), function(x,
+ decreasing = FALSE, ...) {writeObject <- new("g5List",
+ objList = sort(objList), nData = nData(x),
+ nSet = nSet(x), nMach = nMach(x)
+ newObject})
Creating a new generic function for "sort" in ".GlobalEnv"
[1] "sort"
```

The list below gives some illustrations of using the new sort method.

```
> as.Date(g5List@objList, function(e) = as.Date(e@drawDate),
+ + origin = "1970-01-01"[1:5]
[1] "1952-01-17" "1952-01-21" "1952-01-24" "1952-01-28" "1952-01-31"
> as.Date(g5List@objList, function(e)
+ as.Date(e@drawDate), origin = "1970-01-01"[1:5]
[1] "1952-12-29" "1952-12-25" "1952-12-22" "1952-12-18" "1952-12-15"
> set.seed(123)
> g5List <- new("g5List", g5List@objList,
+ nData = nData(g5List), nSet = nSet(g5List),
+ nMach = nMach(g5List))
> as.Date(g5List@objList, function(e)
+ as.Date(e@drawDate), origin = "1970-01-01"[1:5]
[1] "1952-12-29" "1952-12-25" "1952-12-22" "1952-12-18" "1952-12-15"
```

The original g5List object g5List holds g objects in chronologically ascending order. Our sort method successfully reverses this order. It is also applied to a g5List obtained from g5List by randomly shuffling its contents with similar results.
