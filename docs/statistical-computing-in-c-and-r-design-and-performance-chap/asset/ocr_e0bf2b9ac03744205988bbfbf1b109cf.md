```
const Node* Tree::lookUp(const int& key) const {
    const Node* temp = Root;
    while(temp != 0 && temp->first != key) {
        if (key < temp->first)
            temp = temp->Left;
        else
            temp = temp->Right;
    }
    return temp;
}
```

In the case of lookup, a pair that points to the location of the node the specified key value is returned. For the insert method, a new Node object must be created using the pair that has been passed into the function. The search begins with the Root pointer and inserts the new node if the tree is empty. Otherwise, the descent method as lookup is to find the location where the node can be added. By doing this pointer to Node, previous is to keep track of the previous node that was encountered at each step of the way down. This process necessarily ends with a node that has at most one child allowing a new node to be appended. The only question is whether should be appended as a left or right child. The trailing pointer previous contains this information. After insertion the Size member is incremented by one.
