```
gcSearch <- function(x, y, low, up, nEvents){
  gcVals <- seq(low, up, length = nEvents)
  cbind(gcVals, apply(gcVals, function(lLam)
  linss(x, y, 10~lLam[[2]]]))
}
```

The GCV function takes input the data vectors x and y along with lower and upper bounds (low and up, respectively) for the search size of grid (nEvents). The grid is constructed using the R seq function. A slight twist shows that the search is carried out on a scale with the grid representing a partition of powers of 10. The logarithmic scale is appropriate because it is known that the GCV criterion tends to behave like the power of the smoothing parameter near its minimum. The supply function is used in conjunction with its wrapper function to evaluate the GCV criterion across the specified grid.

This search carried out a 100 point grid for values of λ that are evenly spaced in log10 scale between -2 and 0. A plot of the result is shown in Figure 7.2. This suggests that the minimizer lies in the interval [10⁻¹,10⁻¹/2]. We will return to this observation in Section 8.3.

# 7.2.6 Banded matrices via inheritance

So banded matrices have been treated as if were matrices (i.e., no pattern of zero elements) in terms of how they are stored, multiplied, transposed, with efficient solution of linear systems being the only use that has been made of the band structure. This is wasteful from a storage perspective. After all, if the matrix is symmetric with bandwidth q, there are q+1 unique, nonzero entries per row. This means that if the matrix has nRows, all nonzero entries can be held in, e.g., nRows*(q+1) memory locations rather than would be required. The special structure of banded matrices could be built directly into class Matrix by adding new constructors and methods to the C++ inheritance mechanism. Another value will be explored in this section is to make use of the C++ inheritance mechanism.

Inheritance is a means of forming an "is a" relationship between two classes; class A B every object of class B has all the qualities (i.e., members and methods) of class A object. This object B can be viewed as an A object in the sense that it will have all the functionality by the A class. The relationship is established syntactically in the class declaration

# class B : public

which indicates that class B is a derived from the base class. Derived classes automatically copy the elements and methods of the base class. The degree of access that is allowed to the base class components is determined by the type of inheritance that is specified in the derived class declaration. The most common one is public and that the only one that will be considered here.
