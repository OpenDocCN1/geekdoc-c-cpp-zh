## 4.3 Lehmer type congruential number generators in C++

There are many linear congruential number generators that have been studied in great detail in the literature. In this section out the focus will be focused on a particular variety of multiplicative generator deriving from a proposal in Lehmer (1949) that was later implemented by Payne, et al. (1969). The idea behind generators is to choose $m$ as a large Mersenne prime and then take $a$ to satisfy the conditions of Theorem 4.3 and to ensure that the maximum period is attained.

Let us now on the particular case of $m = 2^{31} - 1$. One finds that

```
m - 1 = 2^{31} - 2 = 2 * 3^2 * 7 * 11 * 31 * 151 * 331
```

All the numbers in this period are prime and the fundamental theorem of arithmetic (cf. Andrews 1971) entails that this factorization is: i.e., there are no other prime numbers that divide $m$. The second condition of Theorem 4.3 can now be checked to see if any particular $a$ is a multiplier that will produce a full period. This approach allows us to verify the generator specified by

```
x_i = 630360016*x_{i-1} mod (2^{31} - 1)
```

will have the full $2^{31}-2$ period. The choice of $a=630360016$ was specified by Payne, et al. (1969). It appears as generator II in the Fishman and Moore (1982) comparison study and, for that, will hereafter be referred to as FM2.

An implementation of the FM2 generator is provided in the code below.

> Listing 4.1 basicFM2.cpp

```cpp
//basicFM2.cpp
#include <iostream>

using std::cout; using std::endl;

unsigned long power(int i, int k){
    unsigned long long iout = (unsigned long)i;
    if(k > 1)
        iout = iout*power(iout, k - 1);
    return iout;
}

int main(int argc, char* argv[]) {
    unsigned long a = 630360016;///seed
    unsigned long seed = 123;///seed
    unsigned long m = power(2, 31); //modulus
    cout << "Your random number is ";
    seed = (a%seed)%m;
    double u = ((double)seed)/((double)m);
    cout << u << endl;
    return 0;
}
```

This code can be compiled and executed using

```
$ g++ -Wall basicFM2.cpp -o basicFM2
./basicFM2
```

# LEHMER TYPE GENERATORS in C++

Listing 4.1 contains a simple utility function that computes the value of an integer raised to a specified power. This function gives an illustration of using the C++ recursion capability that allows a function to call itself (Exercises 3.7-3.10). Notice that the function returns unsigned long and, accordingly, must return an unsigned long via a return statement at (or before) the end of the function's scope; it must return a value in the range of statements that appear between the two braces containing the body of the function. The unsigned long int type will give eight bytes of size which is needed (exactly) all the integer values used in the generator. One may check that the four bytes available with the int type are not enough and the resulting code could produce unusable output.

As PRNG implementations go, one leaves a lot to be desired. First, only one returns one number, and as from the results of running the program, it gives the same "random" every time. These shortcomings are easily fixed by allowing for user input. This can be done either by using line arguments or by cin from the iostream library. A possible implementation that allows for input of both the seed and the value for a sample size might appear in Listing 4.1 with the alternative main program section below.

```cpp
int main(int argc, char* argv[]) {
unsigned long a = 63063006;
unsigned long seed = 0;
int n = 0;

cout << "Choose a value for the sample size:" << endl;
std::cin >> n;
cout << "Choose a value for the seed:" << endl;
std::cin >> seed;
unsigned long m = power(2, 31) - 1;

cout << "Your random numbers are " << endl;
for(int i = 0; i < n; i++) {
seed = (a*seed)%m;
double u = ((double)seed)/(double)m;
cout << u << " ";
}
cout << endl;
return 0;
}
```
