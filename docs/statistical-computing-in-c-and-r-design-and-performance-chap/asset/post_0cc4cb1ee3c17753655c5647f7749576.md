```cpp
void Heap::downHeapify(int i, int size){
    int temp = i, newTemp;
    bool done = 0;
    while (temp + 1 <= size && !done){//still a remaining node
        if(2*temp + 1 == size)//no right child: bottom of the heap
            if (A.pa[temp] > A.pa[2*temp + 1]) {
                swap(temp, 2*temp + 1);
                done = 1;
            }
        else if (A.pa[2*temp + 1] < A.pa[2*temp + 2] && !done){
            if (A.pa[temp] > A.pa[2*temp + 1]) {
                swap(temp, 2*temp + 1);
                newTemp = 2*temp + 1;
            }
        else if (A.pa[2*temp + 1] >= A.pa[2*temp + 2] && !done){
            if (A.pa[temp] > A.pa[2*temp + 2]) {
                swap(temp, 2*temp + 2);
                newTemp = 2*temp + 2;
            }
        else
            done = 1;
            temp = newTemp;
        }
    }
}
```

As indicated by Algorithm 9.12 there are several cases that must be considered. If we are at the bottom of the heap and there is no right child, simply swap the two elements if the parent is smaller. Otherwise, there will be two children and the parent is swapped with the child having the smallest key provided it is the smaller of the two. The whole process is managed by a while loop that will terminate the downward movement of the i-indexed node at the level determined by the size. The other option is that none of the if or else statements evaluate to true, which means that the heap property has been restored. An alternative to using a break statement when it evaluates to true is to use a temporary variable `newTemp` used to store the value of the index while the while loop progresses. This allows the value to be reset in the first else block without altering the `temp` loop variable until the end of an iteration.

The append method from the `dArray` includes the new object as the last node in the heap. Then, `upHeapify` does the rest and moves the node up to its proper position. If the heap has only one element, then that is returned to the calling program. Otherwise, the top (or 0 index) node is swapped with the bottom (A.Size - 1 index) node and the new node is down-heapified. Note that the "minimum" node is not actually extracted but allowed to remain in the darray A. The Size parameter for A is decremented meaning that the slot that is now occupied by the "minimum" is viewed as free space by A. Its content will be overwritten by the next item that is inserted into the heap.

Finally, let us consider the `heapSort` method in the next listing.

```cpp
void Heap::heapSort(){
  for(int i = A.Size - 1; i > 0; i--){
    swap(0, i);
    downHeapify(0, i);
  }

  for(int i = 0; i <= (A.Size - 1)/2; i++){
    swap(1, A.Size - i);
  }
}
```

This method sequentially removes objects from the top of the heap and inserts them into the bottom where they accumulate in decreasing order. The re-arranging is done using progressively subtrees with one subtree being formed on each step by excluding the current bottom node. So, for example, the first iteration the bottom node that represents the object with the smallest key value will be "excluded" to give a subtree of A.Size - 2 slot of A and the next subtree will consist of all the last two (non-null) elements of A, etc. At the end of the sorting process the objects will be arranged in a darray with the `heapSort` method reverses the order from left to right so that the object with the minimum key is the first entry in the array.
