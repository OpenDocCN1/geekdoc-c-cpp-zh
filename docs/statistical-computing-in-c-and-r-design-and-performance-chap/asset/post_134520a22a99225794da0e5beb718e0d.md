## A.4 Things that are running and how to stop them

At any time on your system there may be several jobs or tasks that are managed by your shell. A list of the processes that are running is returned by the ps command. Results from using ps might appear like

```
$ ps
PID TTY         TIME CMD
29837 tty000    0:00:08 -bash
29891 tty000    0:00:07 emacs
29895 tty000    0:06:69 ./ack
```

This says there are currently three processes that are active: the shell (bash), emacs and an executable with the name. The first column of the process ID (a unique number that shell has assigned to each of the processes), the next column is the "name" of the controlling terminal, the third column is the CPU time that has been used by each process and the final column is the name of the command. More information about activity can be obtained from jobs. For this example, jobs produced

```
$ jobs
[1]- Stopped       emacs
[2]+ Stopped       ./ack
```

The emacs and ack programs have been given job numbers 1 and 2, respectively, and both have been stopped or suspended. This suspension was accomplished by the Ctrl+z command. A suspended can be restarted using fg (for foreground) prior to its number.

To kill a job that is running in the foreground use Ctrl+c. This is, unfortunately, quite unexpected results due to coding or other errors. Such programs can be suspended with Ctrl+z and then killed using kill processID or kill %jobNumber with processID and jobNumber representing the process ID and job number, respectively, for the job to be terminated. In our example, kill 29895 or kill %2 will terminate the ack job after ps produces

```
$ ps
PID TTY         TIME CMD
29837 tty000      0:00.10 -bash
29891 tty000      0:00.20 emacs
```

verifying that ack is no longer being managed by the shell. To terminate the shell itself either exit or Ctrl d can be used.
