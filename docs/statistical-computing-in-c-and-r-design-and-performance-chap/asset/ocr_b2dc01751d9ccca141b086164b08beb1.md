The other eigenvalues can also be computed using the power method as demonstrated in the previous section.

The R function svd computes the SVD of a matrix provided as its argument can be used to assess the accuracy of our power methods. The output from svd is returned as a list; the first component of the list (named d) holds the singular values while the second and third components (v and u) contain the right and left singular vectors. An application of svd to the matrix used in our example produces

```
> svd(A)
$d

```
