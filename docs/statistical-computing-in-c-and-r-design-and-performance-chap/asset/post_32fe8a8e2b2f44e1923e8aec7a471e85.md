In more complicated situations, the try/catch approach has many features that may make it worth considering. For example, a function can throw an exception. This allows the error to be passed up the call stack to a function that knows how to handle it. This is more flexible than simply terminating the program. Furthermore, exceptions can carry information about the error, allowing for more detailed reporting. For example, an exception object could include an error code or a message string.

In C++, the standard exception class is defined in the <stdexcept> header. It provides a virtual method what() which returns a C-style string describing the error. You can derive from this class to create your own exception types. The following example shows how to define and use a custom exception.

```cpp
//tryCatchEx.cpp
#include <iostream>
#include <string>
#include <stdexcept>

using namespace std;

// Custom exception class
class MyException : public exception {
private:
    string message;
public:
    MyException(const string& msg) : message(msg) {}
    virtual const char* what() const throw {
        return message.c_str();
    }
};

int main() {
    string s = "Hi ya'll!";
    int n;
    try {
        cout << "Enter an integer < 5 " << endl;
        cin >> n;
        if (n >= 5) {
            throw MyException("Integer is greater than 5");
        }
        s.insert(n, " there ");
    } catch (const MyException& e) {
        cout << "Caught exception: " << e.what() << endl;
    } catch (const exception& e) {
        cout << "Caught standard exception: " << e.what() << endl;
    }
    cout << s << endl;
    return 0;
}
```

## 75 MEMORY MANAGEMENT

In C++, memory can be managed in two ways: the stack and the heap. The stack is managed automatically by the compiler. When a variable is declared, its memory is allocated on the stack. When the function ends, the memory is deallocated. The heap is managed manually by the programmer. You use the new operator to allocate memory on the heap and the delete operator to free it.

```cpp
// memory.cpp
#include <iostream>

int main() {
    int* p = new int; // Allocate an integer on the heap
    *p = 42;
    std::cout << "Value: " << *p << std::endl;
    delete p; // Free the memory on the heap
    return 0;
}
```

It is crucial to delete any memory that you allocate with new. Failure to do so results in memory leaks, which can cause the program to consume all available memory. A safer way to manage memory is to use smart pointers, which automatically deallocate memory when they are no longer in scope.

```cpp
// smart_ptr.cpp
#include <iostream>
#include <memory>

int main() {
    std::unique_ptr<int> p1 = std::make_unique<int>(42);
    std::cout << "Value: " << *p1 << std::endl;
    // Memory is automatically freed when p1 goes out of scope
    return 0;
}
```
