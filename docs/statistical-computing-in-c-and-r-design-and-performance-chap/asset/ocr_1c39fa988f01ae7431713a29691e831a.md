For convenience of access to the elements of a g5List object we should extend the list
setting operator [[] to work with the g5List class. The natural way to accomplish this
by having g5ListObj[[i]] correspond to g5ListObj[[i]] for a g5 object
g5ListObj. The [[ operator is an S4 function type of the corresponding R
page helps the page after

```
x[[i, j, ... exact = TRUE]
```

The R page helps show that the methods may only be dispatched on internal code which is built into
t R interpreter with the x argument. So by x = "g5list" an indexing method can be introduced with

```
> setMethod("[[[", signature(x = "g5List", function(x, i, j, ...
+ exact = TRUE) obj@List([[i]])
[1] "[[-"
```

It seems natural to define a replacement of [[ at that point which is readily
accomplished with

```
> ReplaceMethod("[[[", signature(x = "g5List",
+ function(x, i, j, ..., exact, value) {x@g5List[[i]] <= value; x})
[1] "[[-"
```

The effect is to replace a component of the list with a specified index with the g5 object
the right side of the - symbol.
The listing operator is probably the most natural way to access the individual g5
objects in a g5List object. This alone is not sufficient in that it does not provide us with
access to the other g5 class members ndvars, nMach and nSet. of these, can be
obtained using the @ operator. But a more aesthetically pleasing approach is provided by
accessor functions created with the code

```
> setGeneric("ndvars", function(object) standardGeneric("ndvars")
[1] "ndvars"
> setMethod("ndvars", signature = "g5List", function(object)
+ object@ndvars
[1] "ndvars"
> setGeneric("nMach", function(object) standardGeneric("nMach")
[1] "nMach"
> setMethod("nMach", signature = "g5List", function(object)
+ object@nMach
```
