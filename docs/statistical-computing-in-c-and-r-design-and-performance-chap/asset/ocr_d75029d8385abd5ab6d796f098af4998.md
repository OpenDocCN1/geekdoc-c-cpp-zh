The save_image function was discussed in Appendix B as a mean to save an R workspace
for later use. Actually, this is a special case of the more general R function save that writes
a representation of an R object to a file it can later be accessed using the load
function. The following group of commands demonstrates how this works with a simple
target of integers.

+   - A 1:5
>- B 6:10
>- save(A, B, file = "AB.RData")n> rm(A, B)
> temp <- load("AB.RData")
> temp
[1] "A" "B"
> A
[1] 1 2 3 4 5
> B
[1] 6 7 8 9 10

After creating the arrays A and B, an R decipherable representation for the vectors are
stored in the file AB.RData and the original arrays are destroyed using the remove function
rB. The information that A and B is successfully recovered from the file using the load
function. The return value from load is an array whose elements are character
 giving the name of the objects that were loaded.
In some instances it is useful to output code or functions that have been written inside
of R, e.g., for defining a command as

```
> dump("functionName", "pathToFile/fileName")
```

can be used to accomplish this. (Note that the quotes around functionName into the
here.) this will write a text representation for the functionName into the
fileName (if it does not already exist) in the directory pathToFile.
to recover or read such a file the command is source. In this instance
> source("pathToFile/fileName")

brings contents of fileName into the current R workspace. This feature is designed to
work with R and the input file's content will also be parsed to check for syntax errors.
The output from an R session or program can be collected in a file using the sink
function. A disconnected prototype for this function is

```
sink(file, append, split)
```

The file argument variables that the name of the file that will hold the output append and
split are logical that default to FALSE. A specification of TRUE meansmeans the output will be appended to any that already exists in the output file
of TRUE for split means that output will be sent to standard output as well as the
designated file. The use of sink is illustrated in the next example.

```
> sink("temp.txt")
> acos(0)
> sink())
> sink("temp.txt", append = TRUE, split = TRUE)
> cos(acos(0))
```
