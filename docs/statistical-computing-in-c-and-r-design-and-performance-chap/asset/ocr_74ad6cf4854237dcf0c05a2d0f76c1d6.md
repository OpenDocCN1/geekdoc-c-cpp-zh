The functions, 1lp and lpp calculate the negative log-likelihood and its derivatives at a given theta for the parameter. For this purpose they use the Functor which was supplied to the class constructor to sum the observed sample values and directly evaluate f and f'. These functions were designated as private in the class header because they are internal for this particular instance.
The form of the mle method in Listing 8.15 is perhaps somewhat deceptive in its seeming simplicity. The idea is straightforward: a function object encapsulates the 1lp and lpp methods (i.e., a Functor object from Listing 8.16) is constructed and then passed out to an optimization object to find the mle. However, similar to the smoothing spline example of Section 8.3.1, the fact that the mle template class parameter must be set as const like. Also, the functions 1, 1lp and lpp must all be const member functions in order to be invoked by this pointer that is passed to the Optim object.
