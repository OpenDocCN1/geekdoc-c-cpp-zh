# ADT DICTIONARY

Both stack and queue ADTs are easily implemented using either dynamic arrays or linked lists. The creation of C++ code for this purpose is the subject of Exercises 9.38-9.40. The R file package provides implementations of stack and queue ADTs. The queue databases are created on disk using the functions createS and createQ. The databases are linked to R with initS and initQ. For example, the list below corresponds to an R session where both stack and queue databases were created.

The system function is used to check the contents of the current working directory with the Unix is command. We see that "empty" database files with myQueue and myStack have been created on disk. Linking to the databases in R (with initQ and initS) the result is that two new types of object of stack and queue are present in the R workspace that can be used to read and write from their respective databases in the current working directory.

Both stack and queue objects obtained through filehash support the operations push, pop, top and isEmpty. The push and pop functions return the enqueue and dequeue operations for queue objects while top is the analog of preview. The isEmpty function returns TRUE applied to empty objects and FALSE otherwise.

Some experimentation with the stack object myStack produced

```
> isEmpty(ms)
[1] TRUE
> push(ms, 1)
> isEmpty(ms)
[1] FALSE
> push(ms, matrix(rnorm(16), 4, 4))
> push(ms, expression(1 + pi))
> push(ms, 1:5)
> print(pop(ms))
[1] 1 2 3 4 5
> top(ms)
```
