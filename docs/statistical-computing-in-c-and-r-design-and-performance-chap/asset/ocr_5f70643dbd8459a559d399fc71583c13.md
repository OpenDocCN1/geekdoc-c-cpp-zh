The most effective way to proceed is via creation of a shared library using, e.g., the
interface program

```
//Driver.cc
#include "R.h"
#include "vector.hh"
#include "linss.hh"

extern "C" {
    void linss(int* n, double* lam, double* px, double* py,
               double* pfit, double* GCV) {

    Vector y(*n, py);
    Vector x(*n, px);

    Linss S(x, y);
    Vector fit = S.smooth(GCV, lam);
    for(int i = 0; i < *n; i++)
        fit[i] = fit[i];

    printf("The value of GCV at lambdaOpt = %f %f\n", *lam,
           *GCV);
n}
```

This is a slightly modified version of Listing 7.4. The first difference is in function rather than
form. By Listing 7.4 the lam pointer provided information being passed into the program
now it is a memory location that will be filled in with the GCV optimal smoothing
parameter that is returned from the smooth method. The second difference is the use of the
Rprintf function that was discussed in Section 5.7.

A shared library using the CMD SHLIB linssDriver.cc matrix.cc is compiled with

$ R CMD SHLIB linssDriver.cc matrix.cc vector.cc
OncelinDriver.so is brought into R with the dyn.load function, it will be accessible
through the name linss of the function that manages the transfer of information from and
to R Session. In Section 7.25 a wrapper function along the lines of Listing 7.5 can
be created to facilitate its use. One possibility is

```
#GCV.r
linss <- function(x, y) {
    fit <- .C("linss", as.integer(length(x)), 0., as.double(x),
             as.double(y), vector("numeric", length(x)), 0.0)
    list(fit[5], fit[6])
}
```
