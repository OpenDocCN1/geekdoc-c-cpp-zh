One of the simplest schemes is called dictionary two tables, T1 and T2, of size m and two hash functions, h1 and h2, each with range {0,...,m-1}. Each key of the dictionary is stored in exactly one of the tables. To check, if x is in the dictionary, we need to check if a is found at location h1(a) of T1 or at location h2(a) of T2. To insert a, first try T1[h1(a)]. If this entry is empty, insertion is done. Otherwise, a is inserted and the current occupant is moved to T2 using the same process with hash function h2. Should that spot be occupied, the replacement is leaving a new homeless object at which point the T1 and T2 are reversed.

9.35. Another simple data structure that is equivalent to a skip list (Pugh, 1990). The idea here is to begin with an ordered list containing a subset of the elements. To implement this in practice, we use randomization. To insert a node a, start in the top list and walk until two elements are found. Then, descend to the next below and continue the process. Once a location for a is found in the lowest list, it may be inserted there. Then, for each level above, flip an unbiased coin to decide whether to add it to the higher level. This ensures that every list is half the size of the one below and with high probability there are about log2 n lists.
