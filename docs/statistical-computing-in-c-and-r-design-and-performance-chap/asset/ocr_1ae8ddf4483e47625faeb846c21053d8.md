For insert the new pair is added to the list object using its push_front method and the number of elements in the table is also incremented. In contrast, Lookup does not alter the table but searches for the pair object with the designated key has found. This is presumed to exist and no mechanism has been provided to handle a misspecified key value.

The main function shown below is from a program that was written to try out the chainHash class.

```
int main() {
    chainHash<double, int> CH(3);
    cout << "The table size is " << CH.getTableSize() << endl;

    for(int i = 0; i < 10; i++) {
        CH.insert(pair<double, int>(sqrt(i), i*i));
        cout << "The number of objects in the container is " <<
             CH.getSize() << endl;
    }

    chainHash<double, int>::iterator iter = CH.lookup(5);
    cout << iter.Index << " " << iter->first << " " <<
         iter->second << " " << endl;

    iter++;
    cout << iter.Index << " " << iter->first << " " <<
         iter->second << " " << endl;

    for(iter = CH.begin(); iter != CH.end(); iter++) {
        cout << iter.Index << " " << iter->first << " " << endl;
    }

    return 0;
}
```

A table with three buckets is created and then filled with 10 pair objects that have Key components of type double and int data members. An iterator object is defined to point to the pair object with key value √. The increment operator is applied to this iterator object and it is used in a for loop to explore the chainHash object.

To make this a specific choice is needed for a hash function that can be used with non-integer keys. The one selected for this purpose is

```
template<class Key, class Data> int
chainHash<Key, Data>::hash(Key key a) const {
    return ((int)floor(a)) % tableSize;
}
```

The C++ floor function (along with a cast) is used to transform double precision keys into integers. Although effective, this is not the best solution to the problem; a generic class should not need adjustments to allow for different types. A more satisfactory solution is to overload the modulus operator for the Key class in a way that gives the desired result in the form of a generic hash function in the chainHash class.
