Function overloading happens when there are multiple functions with the same name that take different arguments. In C++ we can use this facility to create methods for multiplication, scalar multiplication of a matrix, matrix-vector multiplication, etc., that are invoked by the * operator normally used for scalar multiplication.

The word "template" represents a structured format that can be created for use in recurring, similar applications. For example, a template form for a job application would easily work to present information about an applicant's qualities, contact addresses, etc., that would be pertinent for all possible recipients. Other information such as the salutation and address of the recipients would be left blank if the document could be adapted to specific cases. Class and function templates in object-oriented programming behave analogously to the template idea. The role of "blank spaces" is played by parameters that specify data types. For example, using such an input/output operation to be directly and appropriately for the type of integers, floating-point values, characters or strings of characters. In this sense a template provides a family of classes or functions whose elements are indexed by the possible values for their parameters.

Inheritance is a feature of object-oriented languages that allows new classes to be constructed from base classes. The new or derived classes inherit the public members and methods of the base class and modify them if necessary to produce a polymorphic behavior. For example, a banded matrix is a matrix whose special structure can be exploited to realize savings in both storage and space of matrix operations inversion. Thus we generate a general class from which a banded matrix is derived. While some of the methods from the base class work well with banded matrices, such as matrix-vector multiplication should be specialized to lower use of the bounded limit structure. The approach is to create another version of the * operator, except that in this instance the solution lies in a * virtual method; also to coexist as a method in both the base and derived class behave differently depending on whether a full or banded matrix uses the operator. This is not the same as function overloading where the arguments determine its behavior.

## 1.3 What lies ahead

The next chapter begins with a discussion of how computers represent numbers. The fact that computers have only finite memory poses problems dealing with irrational numbers. Exact storage would require infinite memory locations which is necessary to compromise and settle for an approximate representation. This leads to the discussion of round-off error and other consequences of working with floating-point arithmetic. Some theory of this topic is obligatory in a book on numerical methods. This is more likely due to the importance of the subject than to maintenance of a convention.

A bit of advice on round-off error is "use double precision and don't worry about it". The bad part of this recommendation is not the use of "double precision", which is certainly a good practice in most settings. Instead the problem is in believing that increasing the precision solves all numerical problems and allows one to take a cavalier view of the whole round-off issue.

The data in Figure 1.1 represents values of a computer system performance variable that were taken at one-second intervals for a total of 810 seconds. The data will be analyzed using an autoregressive model of order 2; that is, the observed responses $x_1\dotsx_{810}$ will be treated as realizations from

> $$X_t = \beta_0 + \beta_1x_{t-1} + \beta_2x_{t-2} + e_t, t=3,\dots,810,$$

with the $e_t$ being uncorrelated random errors with zero means and common variance. The goal is to obtain estimators of $\beta_0, \beta_1$ and $\beta_2$. One approach to estimation is through a conditional least squares criterion we minimize

$$\sum_{t=3}^{810}(x_t - b_0 - b_1x_{t-1} - b_2x_{t-2})^2 \quad (1.1)$$

as a function of $b_0, b_1, b_2$ conditional on the first two observations which are used to initialize the recursion (e.g., Shumway and Stoffer 2010).

One can obtain the minimizers of (1.1) directly. However, if observations are arriving in real time it may be of interest to compute the estimators at each time point and update them when a new observation arrives. The first step in this updating algorithm is to compute efficient estimators corresponding to a fit of the response based on the first four observations.
