Conditional execution statements have the usual form in R: e.g., either

```
if(testExpression){
  statements and expressions
}
```

or

```
if(testExpression){
  statements and expressions
} else {
  statements and expressions
}
```

There is also R Analog of the C/C++ switch statement that was mentioned in Section 3.4. It is discussed in Section 2.6 of Venables and Ripley (2000) and the corresponding R help page. The ifelse function in R is a vectorized return of the C/C++ conditional operator (if Section 3.4). It has the syntax

```
ifelse(testExpression , yes, no)
```

with yes and no vectors providing that will be returned when the elements of the vector testExpression of Boolean variables are TRUE or FALSE, respectively. The values in yes and no will be recycled if either loop is too short.

As in C++ the curly braces in a loop or conditional expression are not needed if the corresponding code is a single line: e.g.,

```
x <- 3
for(i in 1:3)
  if(x < 5) x <- x + 1
```

will run without error. Of whatever importance is the syntax involving else in an/ifelse block. The else term must be on the same line as the closing brace for the preceding phrase in an interactive session. For example, consider

+   x <- 5
if(x < 5){
  + x <- x + 3
} else {
  + x <- sqrt(x)
}
