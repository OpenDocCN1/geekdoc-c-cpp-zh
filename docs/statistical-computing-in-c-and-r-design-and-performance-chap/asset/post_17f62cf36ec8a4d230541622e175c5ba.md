The development of an analogous version of Listing 8.1 in C++ is a more formidable task as C++ is missing the key ingredient from R that allows functions with object status. The solution is to simply correct this “deficiency” and devise a way to create objects in C++. Of course, this is not as easy as it might sound and the formulation of a satisfactory solution will lead us through some interesting language territory.

In C++ objects are often referred to as functors. In a broad sense this can mean objects that are created from a class with an overloaded version of (). A specific example of a functor is provided by the next listing.

# Listing 8.2 functorEx.cpp

```cpp
//functorEx.cpp
#include <iostream>
#include <cmath>

using std::cout; using std::endl;

struct Functor{
  int nCalls;
  Functor() : nCalls(0) {}

  int operator()(double x){
    nCalls++;
    cout << "Calling from " << endl;
    return floor(x);
  }
};

int main(){
  Functor f;
  cout << f(2.5) << endl;
  cout << f.nCalls << endl;
  return 0;
}
```

# FUNCTION OBJECTS

The struct functor in Listing 8.2 is similar to the C r func in Listing 8.1 in its purpose is to provide a constructor that can hold the C++ floor function. The mechanism for accomplishing this is an overloaded () operator that takes a double argument and returns an int. The body of the operator evaluates floor at the operator's argument and returns the result.

Listing 8.2 reveals another property of functors that differentiates from the functions they encapsulate: As functors are classes/structs, they may also have member elements or data components. This allows them to, e.g., “remember” when they were called or their last output. In terms of Listing 8.2 the functor f in main will retain a record of how many times it was used through the member nCalls. The default constructor for the struct initializes nCalls to 0. So, the program's output

Calling from ()
2

demonstrates that the initial state of f has been updated.

One criticism can be directed at a functor as the one in Listing 8.2 is that it can encapsulate only one function. For example, a new functor would have to be created to containing the function ceil that returns the greatest integer that is not smaller than its argument. These two functions are of very similar nature in the sense that they both take a double argument and return an integer.” It would be nice to have a single class/struct that could hold either of these functions, or more generally, any function that takes a double argument and returns an int. One avenue for creating this type of functor is provided by function pointers.

The syntax for creating an ordinary function pointer is

```
returnType (*pFunc)(arguments)
```

This produces a pFunc that can point to any function with returnType as its type and an argument list of the same length with data types that match, in order listed for pFunc. Similarly, the pointer pFunc can be passed to a function which has a function pointer as an argument with returnType as its return type and an argument list with length and data types matching the pFunc. The pFunc pointer can be used as if it were ordinary function; writing pFunc(argumentValues) with argumentValues has the effect of dereferencing the pointer.

To create a member function for a class/struct X one uses syntax such as

```
returnType (X::*pFunc)(arguments)
```

The code below provides an alternative spin on executing the tasks performed by the previous listings in this section. In this case Z has two member functions.

```cpp
//pointToFunc.cpp
#include <iostream>
#include <cmath>

using std::cout; using std::endl;

struct Z{
public:
  int func(double x){
    cout << "Calling from func" << endl;
    return ceil(x);
  }
  int floorFunc(double x){
    cout << "Calling from floor" << endl;
    return floor(x);
  }
};

struct Functor {
public:
    int (Z::*pf)(double);
    Z* pT;
    Functor(Z* pT, int (Z::*pf)(double)) : pT(pT), pf(pf) {}
    int operator()(double u) const {
        return (pT->*pf)(u);
    }
};

int main(){
    Z z;
    Functor f1(&z, &Z::func);
    cout << f1(2.5) << endl;
    Functor f2(&z, &Z::floorFunc);
    cout << f2(2.5) << endl;
    return 0;
}
```
