The only issue that remains is dealing with the boundaries. After initializing the first row of $L$ exactly for the nonbanded case, we can make certain that the boundaries are handled correctly by computing all in (7.4)-(7.5) from the bound $\max(1, i+t-q)$ and restricting $t$ to the range from 0 to $\min(q, n-1)$.

To maintain computational efficiency, both the forward and backward substitution steps must explicitly use the band structure. This means that, by solving $Lz = c$ with $z_1 = c_1/l_{11}$

```
$z_j = (c_j - \sum_{k=\max(1,j-q)}^{j-1} l_{jk}z_k) / l_{jj}, j = 2, \dots, n, \quad (7.6)$
```

and then back-solving $L^Tb = z$ via $b_n = z_n/l_{nn}$

```
$b_j = (z_j - \sum_{k=j+1}^{\min(n,j+q)} l_{jk}b_k) / l_{jj}, j = n-1, \dots, 1. \quad (7.7)$
```

The claim now is that all of this is accomplished in only $O(nq)$ flops. To see that this is true, there are only $O(nq)$ nonzero elements in $A$ and $L$. Each element of $L$ can be computed in order $q$ flops, and hence, all the elements of $L$ can be obtained in a total of order $nq^2$ flops. Finally, the forward and backward substitution steps are also of order $nq$ which verifies the claim.

The development thus far implies in general, $n^2$ memory locations will be needed to hold this matrix in the linear system. In the case of band structure, this can be reduced to $n(2q+1)$.
