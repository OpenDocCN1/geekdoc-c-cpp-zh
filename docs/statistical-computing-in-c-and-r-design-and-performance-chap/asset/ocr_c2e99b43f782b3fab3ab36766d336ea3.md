Then, all divisions are defined, the system $Ub = c$ can be solved via $b_n = c_n/u_{nn}$, $b_{n-1} = (c_{n-1} - u_{n-1,n}b_n)/u_{n-1,n-1}$, etc., with the general step being

```
$b_t = \frac{c_t - \sum_{j=t+1}^{n} u_{tj}b_j}{u_{tt}}$
```

for $t = n-1, \dots, 1$. This is a back-solving algorithm.
The computational effort involved in back-solving is on the order of $n^2$ floating-point operations or flops. Floating-point operations include addition, subtraction, multiplication and division. This is how we arrive at the $n^2$ figure observe solving for $b_n$ requires one division while solving for $b_i$ involves $n-t$ multiplications, $n-t$ subtractions and one division for $t = n-1, \dots, 1$. Thus, this effort is

```
$1 + \sum_{t=1}^{n} \{2(n-t) + 1\} = n^2$.
```

This type of operation cost is often referred as the *complexity* of the algorithm and that term is frequently employed with $O$ notation to describe the order of an algorithm's computational effort. Thus, in case the back-solving algorithm has complexity $O(n^2)$.
Back-solving is easily implemented in an iterative form that is amenable for use with a computer as by the following new member function for our class Matrix from Chapter 3.

```
Vector Matrix::operator=(const Vector& RHS) const {
double temp;//temporary storage

Vector b(nRows, 0.0); //solution vector

//initialize the recursion
if(pA[nRows - 1][nRows] != 0)
  b.pA[nRows - 1] = RHS.pA[nRows - 1]/pA[nRows - 1][nRows];
else{
  cout << "Singular system!" << endl;
  exit(1);
}

//now work through the remaining rows
for(int i = (nRows - 2); i >= 0; i--){
if(pA[i][i] != 0) {
  temp = b.pA[i];
  for(int k = (i + 1); k < nRows; k++){
    temp -= b.pA[k]*pA[i][k];
    b.pA[i][i] = temp/pA[i][i];
  }
}else{
  cout << "Singular system!" << endl;
  exit(1);
}
}
return b;
}
```
