
# Chapter 3 A sketch of C++

## 3.1 Introduction

This chapter presents some of the essential ingredients that will be needed for code development in C++. We will begin with a few basics that allow us to get started writing programs and then proceed quickly to incorporate tools that will allow for effective access to the power of the language. The treatment is uneven at best. More detailed and exhaustive coverage can be obtained from Stroustrup (1997), Eckel (2000) and Prata (2005) as well as many other language references that are available online.

As seen in the previous chapter, schematically a C++ program will look like

```
include declarations and definitions
int main(int argc, char* argv[]){
    body of program
}
```

Each include statement must be preceded by `#` and the body of the main has to be enclosed with curly braces; and the same is true for declarations and some definitions that describe variables and functions will be explained in detail shortly. The argv and argc arguments to main are optional but useful for specification of additional parameters from the command line as seen in Listing 2.3 of 2.5.

The body of the program will consist of variable definitions, arithmetic expressions, loops, conditional execution statements, etc. These will be discussed in the forthcoming sections. Perhaps the first thing to think about is the fact was mentioned in Section 2.3: every variable's type must be declared explicitly when it is introduced into the code. As an example, the code snippet

```
int x;
x = 0;
```

begins with a declaration that informs the compiler that a variable x will be used that is of type int. The next line of code is an assignment where x is given the value 0. This could all have been accomplished in one step

```
int x = 0;
```

where the type of x is declared in the same statement where it is assigned a value. Both of these ways of introducing x into a program are syntactically correct. But, an attempt to compile

```cpp
//typeName.cpp
int main(){
    x = 3;
    return 0;
}
```

will the compiler to lodge a complaint of the form

```
typeError.cpp: In function int main() :
typeError.cpp:4: error: 'x' was not declared in this scope
```

Note that this is the typical form of an error message returned by the Gnu C++ compiler tells us the name of the file where the error occurred (i.e., typeError.cpp), the name of the function in the file which contains the error (i.e., main) and gives the line number in program (specifically, line 4 in the file typeError.cpp) where the error was detected.

In C there is a distinction between a declaration and a statement with the former having purpose of informing storage requirements while the latter executes an (or actions) on a variable (or variables), performs writing operations, etc. Under the C standards, declarations and statements cannot be mixed. There is more flexibility in C++ that declarations are also viewed as statements which allows them to be mixed executable statements. For example, the snippet

```cpp
int main() {
int x, y;
x = 0; y = 0;
int z = x + y;
return 0;
}
```

is legal in C++. However, the fourth line of code int z = x + y; is illegal in some versions of C*. The ability to mix declarations and code will feature prominently in C++ for loops as seen in Section 3.4.
