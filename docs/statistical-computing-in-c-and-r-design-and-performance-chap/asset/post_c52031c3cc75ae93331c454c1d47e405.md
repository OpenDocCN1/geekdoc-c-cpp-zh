An example, let us use random number generators from the R Standalone Library. First note that the uniform random number generator that uses the R library is a multi-with-carry developed by Marsaglia (e.g., Marsaglia 2003) that has passed in excess of $2^{109}$¹ This generator requires two seeds that are set with the function set_seed with unsigned integer arguments that are passed by value. The ending values can be retrieved by the function get_seed with arguments of type unsigned integer* that allows the function to write back into memory maintained by the calling program.

List 4.11 illustrates the use of the R library for generating normal deviates. Here a sample size and the two seeds are requested as input at which point the seeds for the generator are initialized with set_seed. The sample is then generated and the ending values are retrieved and printed to standard output. The seeds are reset to their starting values and the process is repeated to illustrate that identical values will be produced.

//RmathEx2.cpp
#define MATHLIB_STANDALONE
#include <iostream>
#include "Rmath.h"

using std::cin; using std::cout; using std::endl;

int main() {
    unsigned int seed1, seed2, n, df;
    cout << "enter a value for the sample size:" << endl;
    cin >> n;
    cout << "Enter a value for the first seed:" << endl;
    cin >> seed1;
    cout << "Enter a value for the second seed:" << endl;
    cin >> seed2;
    cout << "Enter a value for degrees-of-freedom:" << endl;
    cin >> df;
    set_seed(seed1,seed2);
    cout << "Here is a sample of standard normals:" << endl;
    for(int i = 0; i < n; i++) {
        cout << rnorm(0, 1) << " ";
    }
    cout << endl;
    cout << "Here is a sample of chi-squares with " << df << endl;
}
```
