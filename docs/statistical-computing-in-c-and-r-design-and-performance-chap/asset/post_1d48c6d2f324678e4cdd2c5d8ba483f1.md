which gives the number of times that other keys have hashed to the same value k for the jth hash. By definition of the data structure, $B[j,h_j(k)] = n_k + X_{k,j}$ which implies $B[j,h_j(k)] \geq n_k$.

To establish the upper bound, observe that $E[X_{k,j}] \leq N/w \leq \epsilon/e$. By Markov's inequality and the randomness of the d hashes count

```
$Prob(\tilde{n}_k - n_k \leq \epsilon) = Prob(\min B[j,h_j(k)] - n_k \leq \epsilon)$
= Prob(B[j,h_j(k)] - n_k \leq \epsilon \text{ for some } j = 1, \dots, m)$
= 1 - \Pi_{j=1}^m Prob(B[j,h_j(k)] - n_k > \epsilon)$
= 1 - \Pi_{j=1}^m Prob(X_{k,j} > \epsilon)$
\leq 1 - e^{-\delta} = 1 - \delta.$
```

In addition to estimating the number of times a certain key value has been seen, count-sketch can be used to provide other statistics of interest for an input sequence. The data include range queries (approximately counting all keys in a given range), quantiles of the key distribution and heavy hitters (most frequent keys). We see, e.g., Cormode and Muthukrishnan (2005) for further discussion of how this can be accomplished.

```cpp
class CMS
{
    int W;
    int D;
    unsigned long Seed;
    vector<vector<int>> B;
    vector<int> a;
    vector<int> b;

    void insertKey(string key);
    int fnvHash(int i, string key);

public:
    CMS(int w, int d, unsigned long seed);
    CMS();
    void readData(ifstream& inFile);
    unsigned long getFreqEst(string key);
};
```

The class has six private members including the number of hash functions D, the number of hashed values W and the vector<vector<int>> B that will hold the frequencies of hashed values. The universal hash family produces the values in B will be created along the lines of Example 9.4 of Section 9.2.4.1. This requires a random number generator provided by the randGen class from Appendix E corresponds to the Seed data member. The coefficients produced by the generator will be stored in the vector<int> class members a and b. There are three public methods: a class constructor, a method to read data from a stream and the function getFreqEst that computes the estimated frequencies from the B array. The private fnvHash and insertKey evaluate the hash functions at a given key value and update the B array.
