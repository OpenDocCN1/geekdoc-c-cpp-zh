The names for the list objects have been assigned in two ways: using the names function and directly in the list constructor. As seen from this example, list elements may be accessed via the dereferencing operator [] (which is always possible) or by their names using $ if names have been assigned. Dereferencing returns the actual object that was stored in the list. Note that using the [] operator with a list, instead of [[]], will return a sublist that corresponds to the specified indices. In this particular case, a[] is a one-element list while a[[1]] is the character object that provides the sole component of a[1].

# WRITING R FUNCTIONS

In a certain sense, there is no direct analog of the C++ member functions or methods for an R class. That is, functions are not segregated as belonging to only a single class. Instead, a function is an object with an independent existence that is free of restrictive ties. This allows for the creation of something generic functions where the R language interpreter determines which function is appropriate by examining the types of the arguments in the function call. There are two systems that produce generic functions in R: S3 and S4. Both of these will be discussed in Chapter 6.

For similar reasons to those for C++, R has a namespace system that is used by some packages. Generally, any R package includes variables with names that can mask those from other packages being used in a current session. The way to resolve name clashes with the R scope/namespace resolution operator :: provides access to exported variables from a package via syntax of the form

```
packageName::name
```

with the name of a variable or function and the name of the package where name resides. The term exported variables refers to variables/functions that a package creator has made for package users.

# 5.4 Writing R Functions

We now have enough background to begin to write our own R functions. An R function definition will have the basic form

``` evenfunctionName <- function(arguments){
  statements and expressions
}
```

A value can be explicitly returned from any point within a function (thereby terminating computation) by using a return statement similar to what transpires in C++. Otherwise, the return value is whatever is produced by the last line of the function definition. As an illustration, the function below takes a matrix A and returns a list containing the product of A with its transpose t(A) and the number of rows

```
myFunc <- function(A){
  list(A*%t(A))
}
```

To apply this to a matrix B we generally use myFunc(B). The body of a function will generally consist of expressions using basic R operators and objects in conjunction with various execution control created by for and while loops and if/else statements. The for loop in R looks like

```
for(varName in sequence){
  statements and expressions
}
```

with sequence representing a vector of values that varName can assume. In contrast, the while loop has the form

```
while(testExpression){
  statements and expressions
}
```

with testExpression an expression that evaluates to TRUE or FALSE. Additional control over loop iteration can be obtained using break and next statements. When break is encountered the entire loop will terminate while next moves to the next iteration step. The repeat construct provides a simple loop structure that involves no logical conditions. must be terminated with a break statement. Conditional execution statements have the usual form in R: e.g., either

```
if(testExpression){
  statements and expressions
}
```

or

```
if(testExpression){
  statements and expressions
} else {
  statements and expressions
}
```

There is also R Analog of the C/C switch statement that was mentioned in Section 3.4. It is discussed in Section 2.6 of the help page. The ifelse function in R is a vectorized return of the if conditional operator. It has the syntax

```
ifelse(testExpression, yes, no)
```

with yes and no vectors providing that will be returned when the elements of the vector testExpression are TRUE or FALSE, respectively. The values in yes and no will be recycled if either loop is too short. As in C++ the curly braces in a loop or conditional expression are not needed if the code is a single line: e.g.,

```
x <- 3
for(i in 1:3)
  if(x < 5) x <- x + 1
```

will run without error. Of whatever importance is the syntax involving else in ifelse block. The else term must be on the same line as the closing brace for the preceding phrase in an interactive session. For example, consider

+   x <- 5
if(x < 5){
  + <- x + 3
} else {
  + <- sqrt(x)
}
[1] 2

that will replace the value of a variable x with the square root of x + 3 depending on whether or not its value is less 5. If we forget to place the else term on the same line as the last curly brace the outcome is

+   x <- 5
if(x < 5){
  + <- x + 3
}
  > x
[1]

Entering a new line after the brace produces a syntactically complete expression and the interpreter has no way of knowing that there is more to come. So, it simply executes the expression that it has to that point and returns the command prompt indicating that it is done.

Listing 5.1 sumFunc.r

```
#sumFunc.r
sumFunc <- function(x){
  n <- length(x)
  x <- as.integer(x)
  sum <- 0
  for (i in 1:n){
    if(!x%%3){
      sum <- sum + x[i]
    } else sum <- sum + 3*x[i]
    if(sum > 300){
      print(paste("Your sum of", sum, "exceeds 300"))
      break
    }
  }
  return(sum)
}
```

The function in Listing 5.1 takes a vector as input and then performs calculations that return a value that has the property of an integer multiple of 3. The first step in the process is to determine the length of the input vector and convert all its elements to integers. The program steps through all the elements of the transformed vector adding to a running sum if they are modulo 0 (i.e., they are divisible by 3 without remainder) and adding three times their value otherwise. If the sum exceeds 300 execution is terminated by a break statement. Output from sumFunc is

+ > sumFunc(10:20)
[1] 270
> sumFunc(30:50)
[1] "Your sum of 387 exceeds 300"
[1] 387
