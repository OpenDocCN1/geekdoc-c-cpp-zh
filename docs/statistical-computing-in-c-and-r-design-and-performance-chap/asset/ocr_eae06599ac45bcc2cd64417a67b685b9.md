First note of the two constants at the beginning of the file that correspond to r and 1-r. Seeing that they are specified outside the body of any method they have global scope which makes them importance for future applications of the method that they will not need to be recomputed each time the golden method is called. The const designation also makes sure that their values cannot be inadvertently altered. The code for the golden method proceeds as in Algorithm 8.1. A question arises how to implement the initialization step of change = ∞. This is accomplished by the C++ numeric_limits template that allows us to set the change variable at the machine representation for positive infinity (cf. the eigen method for Matrix in Section 7.3).
