A vector in R is converted to a matrix (or, more generally, a multi-dimensional array) by specifying its dim attribute. In the case of our previous integer vector this produces

```
> dim(x) <- c(2, 2)
> x*x

[,1] [,2]
[1,] 289 121
[2,] 18449 11449
> (x*x)[1, 1]%7
[1] 2
> (x*x)[2, 2]%7
[1] 2
```

First, the vector is converted to a 2 ×2 matrix by setting both the row and column arguments for dim(x) to two. The vectorization feature of multiplication operator * is illustrated with this matrix. Next, subsetting operations are used on the matrix in conjunction with the modulus and multiplication operators. In general, [] two comma separated arguments for a matrix that correspond to a row and column index, respectively. The x*x[1, 1] syntax, for example, gives us the left-hand element of the case all or row entries. Either the column or row arguments for [] may be left unspecified in which the subscript is specified. The last expression using (x*x)[, 2] illustrated this feature.

Subsetting operations are not restricted to positive integers for arguments. Negative integers can be used to delete rows or columns whose logical values can be used to pick out elements that meet some specified criteria. To demonstrate this feature we employ the matrix

```
> x
[,1] [,2]
[1,] 17 11
[2,] -43 107
```

to produce the results

```
> x[-1,]
[1] -43 107
> (x > 0)
[,1] [,2]
[1,] TRUE TRUE
[2,] FALSE FALSE
> x[(x > 0)]
[1,] 17 11
> x(x[,1] > 0)
[1] 11
```

The use of [] indicates that the row with index 1 is to be deleted. The result is a “matrix” consisting only of the second row of x. The next command reveals that a logical expression applied to a matrix returns a matrix of the same dimension with entries that are either TRUE or FALSE depending on or not they satisfy the condition. In this particular case, the condition is that an element be positive and the resulting matrix of logical values has FALSE for the (2,1) element with the value -43. The utility of this is realized when we use the logical array as an index for the original matrix to produce a subset of the matrix elements corresponding to those entries that evaluate to TRUE.
