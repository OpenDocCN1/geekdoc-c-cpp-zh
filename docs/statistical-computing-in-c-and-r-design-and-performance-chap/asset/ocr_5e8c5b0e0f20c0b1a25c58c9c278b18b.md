# THE C++ LIST CONTAINER

Here a vector container is created and filled with three integers. Then, the begin() and end() iterators for the vector object are used in the assign function to fill a new list L. The contents of L are examined and removed with the front and pop methods using a loop (see class list begin() and end()). A check is made to see if the list is empty (see Exercise 1.3 for discussion of the boolalpha flag) after it is filled using another constructor. This latter constructor takes two arguments: size (3 in example) and an object (2 in this instance) that will be copied, repeatedly, to fill the nodes. The elements of the list object are examined again and the clear and empty methods are called.

The output from our list example program is

```
12 2 1
Empty? true
12 12 12
Empty? true
```

The list was filled as expected using the contents of the vector object and then with three copies of the integer 12. It was then successfully emptied by both the loop and pop.front method and the clear method.
