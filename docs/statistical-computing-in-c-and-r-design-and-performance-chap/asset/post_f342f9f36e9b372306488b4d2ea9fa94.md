We will develop a framework for using Guess5 data that allows us to look at subsets of the drawing data corresponding to different machines, balls, etc., in the next chapter. For present, let us focus on the somewhat more direct problem of analyzing the data we have stored in guess5.txt in its entirety. From the standpoint of the players Guess5 game choice of interest is whether the (40) = 658008 possible combination of five balls means that every one of the 40 without replacement has the same chance of occurrence on any given draw. With this hypothesis, using a chi-square statistic would require a history of millions of draws to be valid thereby proving that from practical consideration (Exercise 5.12). Instead, it is possible to carry out tests of hypotheses against various distributions whose rejection would imply rejection of the overall uniform selection hypothesis (Joe 1993). The simplest of these concerns the individual ball selection probabilities should be 5/40 per draw. A chi-square test can be used for this purpose and that the approach will be implemented.

The first step in analysis of data that has been collected from Guess5 draws is to import it into R in a form that is suited for the planned analysis. If the aim is to calculate a chi-square statistic using all the draws, only the drawing results are needed; however, the information about drawing equipment and dates is extraneous.

For this example let us now adopt the perspective that guess5.txt represents collected data with the focus of analysis. As the equipment/date information is not needed, one can import guess5.txt to simply read all the draws into a long vector filtering out information about date, set machine and day of the week. This can be accomplished with a for loop that uses the skip argument for the scan function.

It remains only to compute the chi-square statistic.

> $$\frac{\sum (Obs[i] - E[i])^2}{E[i]}$ $

where Obs[i] are the observed frequencies of the K population elements or categories and E[i] are the expected frequencies for each category under the null hypothesis. The focus is on largely categories; i.e., given any draw from the population, the chance an object will be from any of the categories is 1/K. Our formula for the chi-square statistic is appropriate for drawing with replacement but must be alerted for situations where draws are conducted without replacement. Specifically, if n independent draws are conducted where k elements are selected without replacement, Joe (1993) shows that

> $$\chi^2 = \frac{K-1}{K-k} \frac{(Obs[i]-n/K)^2}{n/K}$
