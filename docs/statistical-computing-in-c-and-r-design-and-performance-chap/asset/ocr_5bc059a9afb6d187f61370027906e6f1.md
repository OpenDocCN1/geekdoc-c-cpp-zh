The class has six private members including the number of hash functions D, the number of hashed values W and the vector<vector<int>> B that will hold the frequencies of hashed values. The universal hash family produces the values in B will be created along the lines of Example 9.4 of Section 9.2.4.1 This requires a random number generator provided by the randGen class from Appendix E corresponds to the Seed data member. The coefficients produced by the generator will be stored in the vector<int> class members a and b. There are three public methods: a class constructor, a method to read data from a stream and the function getFreqEst that computes the estimated frequencies from the B array. The private fnvHash and insertKey evaluate the hash functions at a given key value and update the B array.

CMS::CMS(int w, int d, unsigned long seed) : W(w), D(d), Seed(seed){
    a = vector<int>(D);
    b = vector<int>(D);
    B = vector<vector<int>>(W, vector<int>(D, 0));
    double* andb = new double[2*D];
    srand(Seed);
    rand.randUn(2*D, andb);
    for(int i = 0; i < D; i++) {
        a[i] = floor(andb[2*i]);
        b[i] = floor(andb[2*i+1]);
    }
}

The values for class members D and Seed are specified as arguments to the constructor and set in an initializer list. The two vector<int> objects that will hold the coefficients for the hash functions are initialized following initialization of the frequency B array. In this case another, vector class constructor is called: the first argument is an integer that determines how many times the second argument is replicated in the container. Thus, vector<int>(D, 0) creates a D-element array of all zero entries and the second call to this constructor produces a W vector object with this array in every slot.
