Define the relative error from floating-point approximation to

```
$E = \frac{\tilde{x}-x}{x} \quad (2.13)$
```

with $\tilde{x}$ as the approximation to $x$ obtained from either one of the rounding schemes. The relative error satisfies

```
$$\tilde{x} = x+\tilde{x}-x\n\tilde{x} = x(1+\frac{\tilde{x}-x}{x})\n\tilde{x} = x(1+E) \quad (2.14)$
```

which gives it a simple interpretation in terms of how it measures the disparity between $x$ and $\tilde{x}$. The value of $|E|$ pertains only to the significant and in respects the number of significant digits of accuracy for the approximation. From (2.12), $|E| \leq 2^{-(m+1)}$ under rounding to the nearest value and $|E| \leq 2^{-m}$ in the case of chopping.
