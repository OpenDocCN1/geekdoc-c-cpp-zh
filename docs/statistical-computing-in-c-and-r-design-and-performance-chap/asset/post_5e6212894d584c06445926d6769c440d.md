
## SOLVING LINEAR EQUATIONS

This class has the usual pointer-to-pointer and diagonal matrix (default) constructors, a
copy constructor, an explicit destructor to release the memory in the private member pA
 overloaded assignment and indexing operators. Accessors are provided to give
access to the private members nRows and nCols.

The principal difference between the Matrix class in Listing 7.7 and previous incarnations is how we handle the solution of linear equations. The gauss method has been wrapped in
a virtual function solve. The intention is to use a band-limited formulation for solve in
pdBand class that will be derived from class Matrix.

The header file for the pdBand class is given in the following list:

## Listing 7.8 pdBand.h

```cpp
//pdBand.h
#ifndef PDBAND_H
#define PDBAND_H
#include <iostream>
#include "simpleMatrix.h"
#include "vector.h"

class pdBand : public Matrix{
    int q = bandwidth;
    Vector bandBack(const Vector& RHS) const;
    Vector bandForward(const Vector& RHS) const;
    Vector bandchol(const Vector& RHS) const;

public:
    pdBand(int nRows, int q = -1, double a = 0.);
    pdBand(int nRows, int q, const pdBand* const* pa);
    pdBand(const pdBand& A);

    ~pdBand();

    Vector solve(const Vector& RHS) const {
        std::cout << "Solution via banded Cholesky from class PdBand"
                  << std::endl;
        return bandChol(RHS);
    }

    Matrix bandToFull() const;
};
#endif
```

The class declaration for pdBand begins on line 8 of Listing 7.8. It takes the usual format except
that has been augmented by : Matrix to indicate that pdBand is a derived class
that inherits the public members and member functions from its parent class Matrix. It
entails that a pdBand object can use getRows, getCols, the indexing operator, etc., using an object from class Matrix without having to include it in the class declaration.
Addition to the members that pdBand inherits from class Matrix it has its own
q that will hold the bandwidth of the matrix. In this mind, it is highly
useful at this point to detail the plan for storing the matrix elements in a pdBand object.
If A is an n x n symmetric banded matrix with bandwidth q and elements $a_{ij}, i,j =1,...,n$, it is only necessary to store its diagonal and above diagonals. This means that A's contents can be placed in $n \times (q+1)$ matrix of form

| $a_{11}$ | $a_{12}$ | $a_{13}$ | ... | $a_{1q}$ | $a_{1(q+1)}$ |
|---|---|---|---|---|---|
| $a_{22}$ | $a_{23}$ | $a_{24}$ | ... | $a_{2(q+1)}$ | $a_{3(q+1)}$ |
| ... | ... | ... | ... | ... | ... |
| $a_{(n-q)}$ | $a_{(n-q+1)}$ | $a_{(n-q+2)}$ | ... | $a_{(n-1)}$ | $a_{(n)}$ |
| $a_{(n-q+1)}$ | $a_{(n-q+2)}$ | ... | $a_{(n)}$ | $a_{(n)}$ | 0 |
| $a_{(n-q+2)}$ | ... | $a_{(n)}$ | $a_{(n)}$ | 0 | 0 |
| ... | ... | ... | ... | ... | ... |
| $a_{nn}$ | | | | | 0 |

There is a useful relationship between the elements of $A$ and those of $\tilde{A}$ in that
$a_{ij} = \tilde{a}_{(i,j-1)}, \quad j \le \min(i+q, n)$, with the $(i,j)$ element of $\tilde{A}$ (page 220 of Björck 1996). Relation (7.17) will be exploited to translate matrices from Section 7.2.4 to work with matrices that are in this compressed storage mode. As a specific example of a matrix $A$ in band storage mode we use the banded matrix $A$ that was produced in Section 7.2.4. This matrix is converted to our band mode with

```
> A <- matrix(0, 6, 3)
> for(i in 1:4)
> A[1,] <- A[i, i:(1 + 2)]
> A[5, 1:2] <- A[5, 5:6]
> A[6, 1] <- A[6, 6]
```

with the result

| | 1 | 2 | 3 |
|---|---|---|---|
| 1 | 0.0671146 | 0.03285631 | -0.02547667 |
| 2 | 2.2845905 | 0.24176066 | 0.73343776 |
| 3 | 3.5142686 | 0.20403810 | 0.27406444 |
| 4 | 2.2404457 | 1.13430207 | -0.82495484 |
| 5 | 2.8809309 | -0.01716435 | 0.0000000 |
| 6 | 1.1492209 | 0.0000000 | 0.0000000 |

As mentioned above, it is necessary to define constructors (including a copy constructor), a destructor and the assignment operator in a derived class. The definitions for the three constructors for class pdBand take the form

```cpp
pdBand::pdBand(int nrows, int q, double a) {
  Matrix(nrows, q+1, a);
  q = q;
}
```

```cpp
pdBand::pdBand(int nrows, int q, const double* pa, const double* pb) {
  Matrix(nrows, q+1, pa);
  q = q;
}
```

```cpp
pdBand::pdBand(int nrows, const pdBand& A) {
  Matrix(A);
  q = A.q;
}
```

The approach is the same in all three cases: initializer list calls the appropriate class Matrix constructor and the body of the constructor sets the width of the parameter that is the pdBand constructor. The utility of the diagonal matrix constructor for the pdBand is limited to its default route. In this regard, it uses a default value of -1 for q. Since the number of columns is q + 1, this has the effect of producing an inherited Matrix object with nRows and nCols as zero and, hence, a null pointer for pointer-to-member.

The destructor in class Matrix was designated as virtual. Declaring the virtual is generally a good practice when developing an inheritance relationship. Even though destructors are not inherited, the base class destructor will be called when the object goes out of scope. One aim of this inheritance exercise is to create a generic method that will adapt to the form of the calling Matrix object; i.e., a method that will adapt to objects from derived matrices. The method that was used for solve in class Matrix was Gauss elimination. For a positive-definite banded matrix much more efficient approach is to use a banded Cholesky recursion and that the way solve has been formulated in the pdBand class.

To use a banded Cholesky it is necessary to methods for forward and backward substitution by employed band structure as bandBack and bandFor in Appendix D. There is a little more to do in this case as the Cholesky recursion will produce factors that are in a compressed storage format. In this regard, a method for solving that will work with an upper-triangular matrix in band storage is

```cpp
Matrix pdBand::bandToFull() const {
  int nrows = this->getRows();
  double** pTemp = new double*[nrows];
  for(int i = 0; i < nrows; i++) {
    pTemp[i] = new double[q+1];
    for(int j = 0; j < q+1; j++) {
        if(j <= std::min(i+q, n))
            pTemp[i][j] = (*this)[i+j-i];
        else
            pTemp[i][j] = 0;
    }
  }
  Matrix A(nrows, pTemp);
  for(int i = 0; i < nrows; i++)
    delete[] pTemp[i];
  delete[] pTemp;
  return A;
}
```
