The random number generator program can now be executed using the .C function. It is a bit less cumbersome to "wrap" rngFM in an R function that takes care of actually calling and passing the arguments to .C. A function that serves this purpose is

```
rngFM <- function(N, seed) {
  C("rngFM", as.integer(N), as.integer(seed))
}
```

An example of output from rngFM is

```
> rngFM(5, 123)
Your random numbers are
0.104714
0.723072
0.156521
0.328550
0.635906
[[1]]
5

[[2]]
[1] 123
```
