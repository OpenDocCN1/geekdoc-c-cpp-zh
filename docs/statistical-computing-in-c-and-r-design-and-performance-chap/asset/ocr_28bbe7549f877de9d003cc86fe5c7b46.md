# EIGENVALUES AND EIGENVECTORS

The first step in the power iteration is

```
> v1 <- v1
> v1 <- A%*v1
> v1 <- v1/sqrt(drop(t(v1)%*%v1))
```

It turns out that t(v1)%*%v1 is the R class matrix and must be “demoted” to numeric using the drop function discussed in Section 6.2. The approximation to the first eigenvalue of A that results from this

```
> drop(t(v1)%*%A*%v1)
[1] 8.327123
```

Certainly this is not very satisfactory. So, another iteration appears to be needed which produces

```
> v1 <- A%*v1
> v1 <- v1/sqrt(drop(t(v1)%*%v1))
> drop(t(v1)%*%A*%v1)
[1] 13.82744
```

The next iteration gives

```
> v1 <- A%*v1
> v1 <- v1/sqrt(drop(t(v1)%*%v1))
> drop(t(v1)%*%A*%v1)
[1] 15.05940
```

The fourth, fifth and sixth iterations provide further improvements which

```
> v1 <- A%*v1
> v1 <- v1/sqrt(drop(t(v1)%*%v1))
> drop(t(v1)%*%A*%v1)
[1] 15.18656
```

```
> v1 <- A%*v1
> v1 <- v1/sqrt(drop(t(v1)%*%v1))
> drop(t(v1)%*%A*%v1)
[1] 15.19824
```

and

```
> v1 <- A%*v1
> v1 <- v1/sqrt(drop(t(v1)%*%v1))
> drop(t(v1)%*%A*%v1)
[1] 15.19933
```

We might be tempted to stop iteration at this point. However, the vector v1 produced in the last iteration is

```
> v1
[1,]
[1,] -0.38658660
[2,] 0.56064349
[3,] 0.19034451
[4,] 0.70707149
[5,] 0.00696751
```
