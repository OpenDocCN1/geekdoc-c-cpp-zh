```
$A = \sum_{j=1}^{r} \lambda_j v_j v_j^T \quad (7.20)$
```

for positive eigenvalues $\lambda_1, \dots, \lambda_r$ and associated eigenvectors $v_1, \dots, v_r$. For simplicity it will be assumed that the $\lambda_j$ are distinct in which case they can be arranged so that $\lambda_1 > \lambda_2 > \dots > \lambda_r$.

The Euclidean norm of a $p$-vector $v=(v_1, \dots, v_p)^T$ is

```
$||v||=\{\sum_{i=1}^p v_i^2}^{1/2}$
```

and the inner product of two $p$-vectors $v$ and $x=(x_1, \dots, x_p)^T$ is

```
$$\langle v, x\rangle=\sum_{i=1}^p v_i x_i$
```

The eigenvalue-eigenvector pairs $(\lambda_i, v_i)$, $i=1, \dots, r$, for $A$ then satisfy

```
$Av_i = \lambda_i v_i \quad (7.21)$
```

subject to

```
$$\langle v_i, v_j\rangle=\delta_{ij}$ \quad (7.22)$
```

with $\delta_{ij}$ equal to 1 when $i=j$ and 0 otherwise. The combination of $(7.21)-(7.22)$ gives $v^T Av_i = \langle v, Av_i\rangle = \lambda_i v^T$, for $i=1, \dots, r$.

The approach that will be described for computing eigenvalues is generally called the power method. The idea behind it is quite simple. The eigenvectors $v_1, \dots, v_r$ are known to form an orthonormal basis for an $r$-dimensional subspace of $\mathbb{R}^p$. As a result, an additional $p-r$ vectors $v_{r+1}, \dots, v_p$ can be found so that $v$ provide an orthonormal basis for all of $\mathbb{R}^p$. Using this basis $p$-vector $v$ can be written as

```
$$\v=\sum_{i=1}^r \lambda_i v_i$ \quad (7.23)$
```

with $a_i = \langle v, v_i\rangle$. Thus,

```
$Av=\sum_{i=1}^r \lambda_i Av_i, \ A(Av)=A^2v=\sum_{i=1}^r \lambda_i^2 Av_i, \dots, A^kv=\sum_{i=1}^r \lambda_i^k Av_i,$
```

But, if $a_1 \neq 0$,

```
$$\sum_{i=1}^r a_i^k Av_i = \lambda_1^k [a_1 v_1 + \sum_{i=2}^r (\lambda_i/\lambda_1)^k a_i v_i]$
```

and

```
$||\sum_{i=2}^r a_i^k v_i|| \leq ||v|| ||\sum_{i=2}^r (\lambda_i/\lambda_1)^{2k}|| \leq \sqrt{r-1}||v||(\lambda_2/\lambda_1)^k$
```

since $\sum_{j=2}^r a_j^2 \leq ||v||^2$. The fact that $\lambda_2/\lambda_1 < 1$ has the consequence that the remainder converges to 0 as $k$ increases.
