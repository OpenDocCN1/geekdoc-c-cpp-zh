The functions f, fp and fpp are the logarithm of the exponential density and its two derivatives that are used to create the FunctorIn object. The sample size, file name (for the data) and a starting value for the recursion are obtained from command line arguments. However, for the exponential distribution the parameter space is the real line. Thus, a lower limit of a=0 is specified while the upper limit is set to the machine definition of infinity using the numeric_limits template. The R stats package includes the function mle that can be used for univariate and multivariate likelihood problems. This function appears to be a wrapper for the optim function that allows some arguments to be fixed in the likelihood function. This provides us with an ability to fix the data aspect of the likelihood and only optimize with respect to the parameter(s).

The prototype for mle looks like

```
mle(minlog, start = list(), method = "BFGS", fixed = list(), ...)
```

The minlog argument is the negative of the logarithm of the likelihood function that is to minimized. The start parameter is a list of starting values for the minlog arguments specified by the parameter name. The fixed parameter is a similar list designates arguments that are to be held while assigning them specific values. The default optimization is the quasi-Newton BFGS algorithm. But, any of the methods available for optim can be used as with their arguments specified via the ellipsis.
