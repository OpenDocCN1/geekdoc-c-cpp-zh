11.5. The opposite effect of Bcast can be obtained from the MPI function Gather. It collects information from all the processors into a single processor that is usually taken to be processor 0. This is then gathered into recvbuf which needs to be defined on processor 0.

```
void MPI::COMM_Gather(void* sendbuf, int count,
MPI_Datatype datatype, void* recvbuf, int count,
MPI_Datatype datatype, int count);
```

The quantity sendbuf is a pointer to count memory locations that is sent from each processor to 0. This is then gathered into recvbuf which needs to be defined on processor 0 and have size equal to the product of count and the number of processors (including processor 0). As was the case with Bcast, the function Gather must be called by all processors. Use Bcast and Gather to provide an alternative version of Listing 11.3 that does not require/receive loops.
