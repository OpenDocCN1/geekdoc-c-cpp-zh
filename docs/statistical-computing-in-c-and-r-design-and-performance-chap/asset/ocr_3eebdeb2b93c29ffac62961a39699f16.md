The algorithm returns the node that has the desired value or NULL if no node exists with that key. Note that potentially every node in the list must be examined to find the one with the targeted key value. Thus, this operation can require order n operations in an n-element list.

To insert a node to the right of (i.e., immediately after) a node with given key value, we first look up the key to find where the new node should be placed. This also allows us to check if an element with the same key is already present which should trigger an error report. The idea is implemented in Algorithm 9.5.

As true for dynamic arrays, it is also of interest to be able to sort the elements in a list. The method of choice in this case is called mergesort. Like quicksort, it uses a divide-and-conquer strategy although mergesort handles the details in how that is accomplished.

To illustrate the mergesort, let us again consider sorting the integer array

+   15 1 18 28 27 19 38 6 2 40

that was used in Section 9.2.1. To divide, this array into the subarrays (15, 1, 18, 28, 27) and (19, 49, 38, 6, 40). Let us focus on the second array which we split into two more component arrays (19, 49, 38) and (6, 2, 40). Again, working with the second subarray, we arrive at a singleton 6 and (2, 40) the latter which is already sorted. The next step is to merge these two "arrays". To accomplish this the larger array. The pair (6, 2) is sorted and appended to 40 to give (2, 6, 40). By the same process (19, 49, 38) is ordered as (19, 38, 49) and the basic idea remains the first; the largest value from the two arrays, 49, is returned to the new array and the problem reduces to merging (2, 6, 40) and (19, 38). For this purpose we retain 40 and then must merge (2, 6) and (19, 38). 38 is retained and (2, 6) is merged with 19. Working our way backward, (2, 6, 19) becomes (2, 6, 19, 38, 40) and finally, to (2, 6, 19, 38, 40, 49). The algorithmic scheme is now fully clear and should be apparent that taking this process to logical conclusion will return a fully ordered array.
