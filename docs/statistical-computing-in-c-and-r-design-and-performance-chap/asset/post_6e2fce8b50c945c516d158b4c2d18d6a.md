5.32. An alternative to the experiment-wise error rate is to control the false discovery rate (FDR). The FDR is the expected number of rejections when the null hypothesis is true. A procedure for controlling the FDR has been developed by Benjamini and Hochberg (1995) and Benjamini and Yekutieli (2001). Suppose $m$ hypothesis tests have been conducted and produced p-values $p_1, \dots, p_m$. Then, the Benjamini/Hochberg/Yekieli bounds the FDR by a specified value $\alpha \in (0,1)$. The calculations proceed according to Algorithm 5.2.

# Algorithm 5.2 Benjamini-Hochberg-Yekieli FDR control method

```
Arrange $p_1, \dots, p_m$ in numerically ordering as $p_{(1)} \le \dots \le p_{(m)}$
q = \alpha / \sum_{j=1}^k 1
k = \max \{1 \le i \le m : p_{(i)} \le q (i/m)\}$
if $k$ exists
  Reject the null hypotheses corresponding to $p_{(1)}, \dots, p_{(k)}$
else
  Reject nothing
end if
```
