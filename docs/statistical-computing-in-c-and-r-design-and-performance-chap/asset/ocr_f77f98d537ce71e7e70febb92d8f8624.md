Listing 3.6 brings with a prototype description of the class similar in nature to what we did for the function square in Listing 3.5. This is also called the class interface if it provides sufficient information for a programmer to use the class and its methods without having to see the actual details of the class implementation. Detailed definitions of the member functions are provided outside of this prototype by using the class name with the scope operator ::. Thus, for line 21 of the listing states that xToK is a function or method that returns a double value while taking a double precision argument. In this simple setting, the definitions of member functions for the class could have been included in the class declaration or prototype. But, in the present approach leads more directly towards readable object-oriented code.

The class Power has only one data member: the integer k that represents the power we want to use for computations. A function whose name is the same as the name of the class is called a *constructor*. Because C++ allows for function name overloading, there can be more than one constructor provided that their arguments differ. The purpose of a constructor is to produce a class object; ie: a specific instance of class. As seen from line 33 of Listing 3.6, the constructor can be called using the new operator to produce a pointer to an object of the class. If no constructor is included in a class the compiler will automatically supply one; this for our Power class default constructor is a function with an empty body and no arguments. It would have the (implicit) form

Power() {
