The R language has an exception or condition mechanism that bears some similarity to the C++ version discussed in Section 3.8.7. The R help page on this subject provides source of information while the text by Gentleman (2009) gives an accessible introduction to the topic.

The simplest entry to the exception management facility is the tryCatch function. Exceptions/conditions in R come in the form of message, warning and error objects. These are instances of classes that provide information about a condition that occurred in the execution of a program. In its simplest form, the tryCatch function is comprised of an expression to be evaluated and one or more handler functions that define the action or actions to be taken when a particular condition occurs. If there are no conditions generated by evaluating the expression, the results of the evaluation are returned. Otherwise, a search is made to find a handler that matches the condition.

Both a warning and error object are generated by our spelling error. The TryCatch function can be used to reduce this by "catching" either of the two conditions and instituting an appropriate fix. A function that does this is given below:

```r
readFile <- function(fileName) {
  out <- tryCatch(suppressWarnings(fileName),
    error = function(e) {
      print(e)
      print("Please enter a file name followed by a return")
      newName <- scan("", what = character(0), quiet = TRUE)
      readFile(newName)))
}
```

Here the use of scan is encapsulated inside tryCatch. The suppressWarnings function has been used so that only error (and not warning) objects will be generated when problems are encountered.
