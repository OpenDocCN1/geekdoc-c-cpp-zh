The const varies in three classes: const class members, static class members and const member functions. The use of const for a class member means once a object has been created, the value of member cannot be changed. Initialization of const members requires a special type of syntax involving constructor initializer list and a colon before the opening curly brace precedes the constructor's body.

An initializer list is a comma separated list of argument and value pairs that occurs after the constructor's argument and a colon For a constructor for a class className with two arguments that memberName1 and memberName2 the syntax might look like this

```
className(argument1, argument2) : memberName1(argument1),
memberName2(argument2){
body of method
}
```

In general values for only subset (including none) of the member variables can be set using an initializer list. On the other hand, the values for all member variables can be initialized in this manner in which the body of the constructor may be empty. If that is the case, the curly braces must be present.
