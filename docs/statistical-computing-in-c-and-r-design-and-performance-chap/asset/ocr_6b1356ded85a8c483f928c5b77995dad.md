An array is just a const pointer. That is, once an array in a program it cannot be resized nor the memory it occupies utilized for any other purpose until it goes out of scope. In this mind we can think of a statement that dimensions n-element array like

```
double z1[];
```

as being similar to

```
double* z2 = new double[n];
```

in that require block allocation of the memory that is necessary to store n doubles. However, in the first case the z1 is allocated automatically on the stack and released automatically whenever z1 goes out of scope. Because we have no control over this memory, z1 cannot be reallocated. In the second case the memory for z2 is obtained dynamically on the free-store. It must then be freed explicitly

```
delete[] z2;
```

But, once the memory is freed, a block of memory, of different size (although still for doubles), can be pointed to by the z2 pointer.

So far we have only dealt with vectors (one-dimensional arrays) using pointers. This is not sufficient and it is also necessary to have an analogous way of working with two-dimensional arrays or matrices. This can be accomplished through the use of a vector or one-dimensional arrays of pointers. The memory for the rows of the matrix is allocated to each of the pointers in the array. Of course, the way to get a vector of pointers is to use a pointer. To create an array with nRows and nCols we first create a pointer that points to a block of memory containing nRows pointers, corresponding to each row of the array. Then, each of these memory locations contains the address of the block of memory that is located to the corresponding row of the matrix.
