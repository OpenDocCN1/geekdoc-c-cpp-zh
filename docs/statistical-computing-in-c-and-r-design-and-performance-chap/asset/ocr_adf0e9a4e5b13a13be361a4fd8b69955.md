Suppose that $f(	heta)$ is a continuous function with argument $	heta$ taking values in the interval
$[0, 1]$. Let us now consider doing a grid search over the m-point set

```
$\left\{ 0, \frac{1}{m-1}, \dots, \frac{m-2}{m-1} \right\\}$
```

We want to see what as the grid grows over $[0, 1]$. So, it suffices to take
$m = F_k - 1$ and let $k \to \infty$.

The search is defined by the first two evaluation points which are $\frac{F_{k-2}}{F_{k-1}}$ and $\frac{F_{k-1}}{F_{k-2}}$. Thus,
el $r = \lim_{k \to \infty} \frac{F_{k-1}}{F_{k-2}}$, we see that

```
$\lim_{k \to \infty} \frac{F_{k-2}}{F_{k-1}} = \lim_{k \to \infty} \frac{F_{k-2}}{F_{k-2}+F_{k-1}} = \frac{r}{r+1}$
```

and

```
$\lim_{k \to \infty} \frac{F_{k-1}}{F_k} = \lim_{k \to \infty} \frac{F_{k-1}}{F_{k-2}+F_{k-1}} = \frac{1}{1+r}$
```

are the limiting points for evaluation of $f$. It only remains to determine $r$. This derives from
the fact that

```
$r = \lim_{k \to \infty} \frac{F_{k-1}}{F_k} = \frac{1}{1+r}$
```

thus, $r$ is the positive root of the quadratic equation $r^2+r-1=0$; i.e.,

```
$\frac{-1+\sqrt{5}}{2}=.618.$
```

Consequently, the two evaluation points are then to be $r^2=1-r$ and $r$. At the begin-
ning $(1-r)$ is compared to $r$. If $f(1-r) < f(r)$, the minimizer must lie in the interval
$[0,r]$ and it suffices to search for the minimizer of $f(ru)$ with $u \in [0,1]$. This ensures
evaluations at $u=1-r$ and $u=r$ are found, or equivalently, $f(r(1-r))$ is compared to
f(r^2)=f(r)$ with the latter value already available from the previous comparison.

On the other hand, if $f(1-r) > f(r)$, the minimizer must lie in the interval $[1-r,1]$
and search proceeds by looking for the minimizer of $f(1-r+ru)$ over $u \in [0,1]$. In this
instance $f(1-r+r(1-r))=f(1-r)$ has been computed.
