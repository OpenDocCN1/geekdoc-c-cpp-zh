7.32. Let $x_1, \dots, x_p$ be linearly independent $n$-vectors for $n \ge p$. A numerically stable modification of the Gram-Schmidt process is given in Algorithm 7.7 below.

```
Algorithm 7.7 Modified Gram-Schmidt algorithm
q_1 = x_1
r_{11} = ||q_1||
q_1 = q_1/r_{11}, r_{1j} = q_1^T x_j, j = 2, \dots, p
x_j^{(1)} = x_j - r_{1j}q_1, j = 2, \dots, p
for i = 2, \dots, p-1
  q_i = x_i^{(i)}
  r_{ii} = ||q_i||
  q_i = q_i/r_{ii}, r_{ij} = q_i^T x_j, j = i+1, \dots, p
x_j^{(i)} = x_j - r_{ij}q_i
end
q_p = x_p^{(p-1)}, r_{pp} = ||q_p||
q_p = q_p/||q_p||
```
