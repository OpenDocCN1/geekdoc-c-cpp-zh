
# THE C++ LIST CONTAINER

```cpp
struct Date {
    Date(int year, int month, int day);
    bool operator<<(const Date& date) const;
    bool operator>=(const Date& date) const {
        return !(*this < date);
    }
    bool operator=(const Date& date) const;
    bool operator!=(const Date& date) const {
        return !(*this == date);
    }
};
```

The struct has three members that hold the (Day), Month (Month) and year (Year) for when the observation occurred. The default constructor merely sets the member's values using an initializer list. To facilitate printing Date objects, the output insertion operator was overloaded in Exercise 3.19:

```cpp
ostream& operator<<(ostream& out, const Date& date) {
    out << date.Month << "-" << date.Day << "-" << date.Year;
    return out;
}
```

Elements will be inserted into our list container for the "stock index" data in order of their temporal arrival. The Date objects will therefore provide the natural sorting and searching information that will be used for look-up and other purposes. Operations depend on the comparison operators with the two keys being the ones for < and ==. Other operators can be obtained by composition of these two.
The < and == operators for Date objects are defined by:

```cpp
bool Date::operator<(const Date& date) const {
    if (Year < date.Year)
        return true;
    if (Year == date.Year && Month < date.Month)
        return true;
    if (Year == date.Year && Month == date.Month
        && Day < date.Day) {
        return true;
    }
    return false;
}
```

```cpp
bool Date::operator==(const Date& date) const {
    if (Year == date.Year && Month == date.Month
        && Day == date.Day) {
        return true;
    }
    return false;
}
```

Observations with smaller Year members occur earlier while observations within the same year occur earlier if they have smaller Month members, etc. The definition of == is similarly straightforward.

The data that is recorded each day will be held in the members of the struct IndexData that has the declaration/definition:

```cpp
struct IndexData {
    Date T;
    double Value;
    IndexData() {}
    IndexData(Date t, double value) : T(t), Value(value) {}
};
```

This is a container for an object of type Date and a double and the same utility could be realized using a pair struct, e.g., Section 9.2.4.12. An overloaded insertion operator was also created for this struct to take the form:

```cpp
std::ostream& operator<<(ostream& out, const IndexData& d) {
    out << d.T << " " << d.Value;
    return out;
}
```

We are now ready to formulate the IndexList class that will be used to manage an accumulated collection of "index" data such as the data created from R in the index.txt file. The perspective is similar to that of the Guess5 from Chapters 5-6 and Section 10.3.3; the data resides on disk and must be read into our program to instantiate a list object. The reading will be carried out using the fileIn from Sections 10.3.2–10.3.3. The specific version of fileIn from Section 10.3.3 that imported all as string objects will be used here, and methods from the string class will be used to reformat the data in a way that makes it suitable for analysis.

The declaration for IndexList is given in the next line:

```cpp
struct IndexList {
    list<IndexData> L;

    IndexList(fileIn fin);

    IndexData pop_front();
    list<IndexData>::iterator lookUp(const Date& date);
    list<IndexData>::iterator insert(const IndexData& d);
};
```

The struct has a single list member. There is also the standard and default constructor that takes a fileIn as its only argument. There are also lookUp, insert and pop_front methods that will require a list class of explanation. Before proceeding in direction it should be noted that this struct is a wrapper for a list class that also adds on a few additional features that are useful for this particular application.

The nondefault constructor for the IndexList struct is:

```cpp
IndexList::IndexList(fileIn fin) {
    Date temp;
    IndexData tempI;
    int idx1, idx2;
    for(int i = 0; i < fin.getVNRows(); i++){
        idx1 = fin.get(i, 0).find_first_of("-");
        idx2 = fin.get(i, 0).find_last_of("-");
        temp.Year = atoi(fin.get(i, 0).substr(idx1, 1).c_str());
        temp.Month = atoi(fin.get(i, 0).substr(idx1 + 1, idx2 - idx1 - 1).c_str());
        temp.Day = atoi(fin.get(i, 0).substr(idx2 + 1, 1).c_str());
        tempI.T = temp;
        tempI.Value = atof(fin.get(i, 1).c_str());
        L.push_back(tempI);
    }
}
```
