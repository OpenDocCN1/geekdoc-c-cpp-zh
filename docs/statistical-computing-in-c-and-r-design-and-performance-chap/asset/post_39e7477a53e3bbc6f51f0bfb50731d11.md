3.19. A very useful operator for overloading is the output insertion operator. A prototype for << is

```
ostream& operator<<(ostream& out, const dataType& object)
```

The first argument is a reference to an ostream object and the second is a reference to the output.

The simple program illustrates how the output insertion operator can be overloaded to provide a print utility for a class.

```cpp
#include <iostream>

using std::ostream; using std::cout; using std::endl;

class X{
    int I;

public:
    X(int i) : I(i) {}
    friend ostream& operator<<(ostream& out, const X& x);
};

ostream& operator<<(ostream& out, const X& x) {
    out << x;
    return out;
}

int main() {
    X x(7);
    cout << x << endl;
    return 0;
}
```

First, is a friend function of the X class. This serves the same purpose as making a class friend: namely, it allows the function to have access to the private members of the class. Our definition for << produces a binary operator that is not owned by (i.e., a member of) either the X or ostream class. Thus, in particular, it will be defined outside the X class. By giving it friend status we have made it possible to access the I member of the X for printing purposes.

Replace the printMatrix utility in Matrix with an overloaded output insertion operator.
