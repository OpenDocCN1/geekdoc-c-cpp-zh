The idea is that p + i is a pointer to the memory location i blocks from p and *(p + i) dereferences this pointer. In contrast to the array dereferencing, this makes a pointer look more like an index variable and we use that perspective to generalize the pointer concept.

The simple program below illustrates the use of pointer arithmetic.

```
int main() {
    int* p = new int[5];
    for(int i = 0; i < 5; i++)
        *(p + i) = 3*i;

    for(int i = 0; i < 5; i++)
        cout << *(p++) << " ";
    cout << endl;
    
    return 0;
}
```

Both the addition and postfix increment operators are used here to traverse the memory that has been allocated to a pointer to int. The output from the program is

0 3 6 9 12

A somewhat different spin on the previous code uses the pointer directly in the indexing process.

```
int main() {
    int* begin = new int[5];
    int* end = begin + 5;
    int i = 0;
    for(int* iter = begin; iter != end; iter++)
        *iter = 3*i;
        cout << *iter << " ";
    i++;
    cout << endl;

    return 0;
}
```

Here the role of the integer allocated and the pointer to int are reversed. The pointer now travels across the memory locations allocated to the pointer begin with its value restricted to lie between begin and another pointer. The end pointer refers to the one-pass-end memory location discussed in Section 3.5 that always exists and can be pointed to without dereferenced. An equivalent formulation of the previous listing that uses a while loop is

```
int main() {
    int* begin = new int[5];
    int* end = begin + 5;
    int* iter = begin;
    int i = 0;
    while(iter != end){
        *iter = 3*i;
        cout << *iter << " ";
    iter++;
}
```
