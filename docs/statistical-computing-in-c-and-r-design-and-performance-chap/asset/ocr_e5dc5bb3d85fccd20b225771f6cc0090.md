# ALGORITHM BASICS

```
struct g5Less : std::binary_function<g5, g5, bool> {
  bool operator()(const g5& g1, const g5& g2) const {
    std::string temp1, temp2;
    temp1 = g1.getDate() % g2.getDate();
    if (atoi(temp1.substr(0, 3).c_str()) < atoi(temp2.substr(0, 3).c_str()))
      return true;
    if (atoi(temp1.substr(0, 3).c_str()) == atoi(temp2.substr(0, 3).c_str()))
      && atoi(temp1.substr(5, 6).c_str()) < atoi(temp2.substr(5, 6).c_str()))
        return true;
    if (atoi(temp1.substr(0, 3).c_str()) == atoi(temp2.substr(0, 3).c_str()))
      && atoi(temp1.substr(5, 6).c_str()) == atoi(temp2.substr(5, 6).c_str()))
      && atoi(temp1.substr(8, 9).c_str()) < atoi(temp2.substr(8, 9).c_str()))
        return true;
    return false;
};
```

The sorting is to be drawn by date and accordingly, we need to supply a function that provides an order of < them. Thus, it should be a binary function that returns true when the date of one g5 is earlier than that of others. The dates that are used to make the comparisons are extracted from the Date members of the g5 class arguments using string class methods in a similar manner to the developments in Section 10.4.1. The three template parameters represent the type of the first and second function argument and the return type, in that order. Thus, the parameters are specified as g5 for both function arguments and bool. It now suffices to apply the algorithm sort with the vector object's `begin()` and `end()` iterators.

The main function of a program that will apply our sort to the data in guess5.txt is shown in the next listing.

```
int main() {
  g5Array g5A("guess5.txt");
  std::vector<g5> vSort = g5A.g5Sort();
  std::cout << "Sorting results" << std::endl;
  for (int i = 0; i < 3; i++)
    vSort[i].printG5();
  std::cout << std::endl;

  return 0;
}
```
