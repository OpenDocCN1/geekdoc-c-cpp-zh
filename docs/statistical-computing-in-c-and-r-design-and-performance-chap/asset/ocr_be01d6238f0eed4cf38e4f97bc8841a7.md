# ## 8.1 Introduction

Statistical estimation methods generally require maximizing or minimizing some sort of performance criterion. For example, in the case of nonlinear regression one may estimate the parameters $	heta$ in a regression function $g(\cdot;	heta)$ via least-squares; i.e., by minimizing

```
$f(\theta) = \sum_{i=1}^{n} (y_i - g(x_i;	heta))^2$$
```

with respect to $	heta$, where $y_i, i=1, \dots, n$, are the responses that were observed at $x_1, \dots, x_n$ of a vector of variables. As another instance, maximum likelihood estimation of a parameter vector $	heta$ involves maximizing the likelihood function $L(	heta)$ which is the joint probability density or mass function for the data evaluated at the observed sample values. In general, this is accomplished by equivalently minimizing $l(	heta) = -\ln L(	heta)$. As illustrated by the likelihood setting, all minimization problems can be made into minimization problems. Thus, it suffices to concentrate on numerical minimization.

The task of finding a global minimizer of an objective function is complicated by the possibility that there may be multiple local minima. On the other hand, any continuous, nonconstant function will be either convex or concave (i.e., bowl shaped) in an area around a local minima. So, in that sense, focus can be directed towards the simpler problem of finding the minimum of a convex function. The minimization methods that will be considered in this chapter are designed for purpose. The remaining task is then one of locating all the local minima. Techniques for accomplishing that goal will be discussed.

Minimization of the GCV criterion for the linear smoothing spline in Section 7.25 represents a prototypical illustration of the type of optimization problems that will be of most interest for our study. The basic framework is that there is a class (i.e., **Lines**) of method and the aim is to find a minimizing or arguments of that method for a particular object from the class. The first step in this process is to give a minimization routine to the object's member function. This means that the function to be minimized will originate outside the minimization class and some way of passing the function into the class will be needed. Consequently, this is the first topic that will be explored.
