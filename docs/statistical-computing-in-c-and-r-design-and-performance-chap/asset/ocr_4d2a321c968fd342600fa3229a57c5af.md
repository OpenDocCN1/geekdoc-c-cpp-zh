# BASIC MPI COMMANDS FOR C++

The dest and source arguments in Send and Recv represent the rank of the node for which the message is intended and the rank of the node from which a message is to be received, respectively. The remaining tag argument is a parameter that provides some sorting facility for incoming and outgoing messages. It comes handy if one is sending, for example, two doubles to another processor. Using a different tag for each will make certain they are identified correctly and then stored in a suitable variable by the receiving processor.

With the above preliminaries we are now ready to write our second MPI program. It uses inter-node communication to create the “Hello world!” application.

```
//mpiEx2.cpp
#include <iostream>
#include <mpi.h>

int main({
    MPI::Init();
    int myRank = MPI::COMM_WORLD.Get_rank();
    int np = MPI::COMM_WORLD.Get_size();

    char msg[20];
    if(myRank == 0) {
        strcpy(msg, "Hello ya'll");
        for(int i = 1; i < np; i++)
            MPI::COMM_WORLD.Send(msg, 20, MPI_CHAR, i, 0);
    }
    else{
        MPI::COMM_WORLD.Recv(msg, 20, MPI_CHAR, 0, 0);
        std::cout << msg << " from processor " << myRank << std::endl;
    }

    MPI::Finalize();
    return 0;
}
```

The idea behind mpiEx2.cpp is that a portion of our greeting message will now be relayed from the "master" or rank 0 to the other processors using the Send and Recv functions. This illustrates how branching statements can be used to determine the action of each of the processors; in this case, the processor 0 is told to tell all the others are to receive via use of an if/else block.

The message segment "Hello ya'll" will be stored in the char array msg which has been chosen to length 20. The choice of 20 is arbitrary. It can be any value large enough to provide storage for the portion of the greeting it meets. To place in msg the rank 0 processor uses the strcpy function whose purpose is to copy strings into characters. An array of (at most) 20 elements of type MPI_CHAR is sent and received. Processor 0 sends the array to each of the other processors using the Send function in a loop with the dest argument being the receiving processor’s rank and the value of tag arbitrarily to 0. The other processors receive the message by using 0 as the source argument for the Recv function. In this lancer the value of tag must agree with the value used in the Send function. The results obtained from running the program with several processors

```
$ mpiEx2.cpp -o mpiEx2
$ mpiexec -np 7 mpiEx2
Hello ya'll from processor 4
```
