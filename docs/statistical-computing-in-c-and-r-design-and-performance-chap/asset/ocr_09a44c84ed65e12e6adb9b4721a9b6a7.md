The struct has two data members: a pointer to the Head Node object and the integer Size that represents the number of nodes in the list. A constructor and copy constructor have been given; the constructor creates an "empty" linkedList with a null pointer for its head node. There are three methods that correspond to the push,lookUp and insert Algorithms 9.3-9.5. There are four other methods that, in combination, will merge the nodes in a list via mergesort. The sort method is a wrapper function for mergesort with merge and merge corresponding to Algorithms 9.7 and 9.6, respectively.
The copy constructor was encoded as

```
linkedList::linkedList(const linkedList& L){

if(L.Size == 0){
Head = 0;
Size = 0;
}
else{
Size = L.Size;
Node* temp = 0;
for(Node* iter = L.Head; iter!=0; iter = iter->Next){
if(temp == 0)//empty list
Head = new Node(iter->dataValue, iter->keyValue);
temp = Head;
else
temp->Next = new Node(iter->dataValue, iter->keyValue);
temp = temp->Next;
}
temp->Next = 0;//null pointer as Next for tail node
}
```

The case of copying an empty list is dealt with initially. To copy a nonempty list, the size is initially set. Then, one uses a pointer to Node to move over the existing list while appending nodes to the new linkedList object. The appending is done using a pointer to Node, that sequentially copies the new nodes to each other. After the head node is initialized using the head node of the list that is copied, temp is used to define the Next member of the Node object at its current location. It moves to the node it created and repeats the process.
