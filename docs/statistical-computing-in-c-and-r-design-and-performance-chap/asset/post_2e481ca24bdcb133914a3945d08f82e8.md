A simple class with one public member K and two methods are created. One class method (getThis) returns the value of this pointer while the other (getThisRef) returns a reference to an object constructed from class X. The way references are returned the syntax for the reference method a bit subtle. The fact that this is a pointer to the object address means that the dereferenced pointer *this is the object itself. So, to return a reference to the object, we dereference this *this and the function return type (i.e., &X) dictates that the address of the reference is that of *this: namely, the value of this.

The main function in Listing 3.8 instantiates an X object named w and creates other objects using w. The first object x is a pointer to data type X we create using this pointer for w. The second object y is a reference variable for X objects that is initialized with a reference to*this, or equivalently, a reference to w. The final object z is of type X but is created by dereferencing this pointer for w. Specifically, a new memory location is set aside for z and then the value of K for the object *w.getThis() is copied in this location.
