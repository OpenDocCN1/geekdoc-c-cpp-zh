The class has six members: string variables Date, Machine and Day for the drawing date, name of the machine that was used and day of the week for the drawing, an int variable that will hold the set number used in the drawing, a pointer-to-pointer short integer "array" that will hold the actual drawing information and a pointer to int that hold the frequencies of occurrence for the 40 balls for a g5 object. The numbers drawn all between 1 and 40 and the four bytes of it storage would be wasted; the two short int type work just as well. A default constructor sets the two pointer variables to null. This is needed, for example, to create an empty vector container of a specified size for g5 objects. There is also a constructor that takes input values for five of the member variables. Accessor methods are given for two of the class members and a utility method has been provided. Dynamic memory allocation is involved and, accordingly, a copy constructor, overloaded assignment operator and explicit destructor are provided. An overloaded = operator has been included for work that will arise in Section 10.7. Correction of the code for these methods is addressed in Exercise 10.9.
