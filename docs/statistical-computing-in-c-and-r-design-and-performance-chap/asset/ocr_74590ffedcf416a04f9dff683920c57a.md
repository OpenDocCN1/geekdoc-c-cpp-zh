The zeros and ones in the array indicate which variable subsets should be in the fitted model: 0 signifies that the variable should be excluded and 1 means it should be included in the fit. The first row consists of all zeros. It has the effect of producing a fit with only the constant term: ie, fit is the average of the response values.

The leafy function is used to create which components are composed of- sensitive blocks of 256 rows from the subsets data frame. These are then distributed to the processors via a for loop. The processors then to call mpi.recv.Robj to receive their data using the mpi.bcast.cmd function. This latter function is a version of mpi.remote.exec which produces no output.

The function that will be used to create the fi subsets

```
myRegTask <- function(mySubsets) {
  n <- length(y)
  aicVec <- apply(mySubsets, MARGIN = 1, function(a){
    ind <- as.vector(a, mode = "logical")
    if(sum(a) == 0)
      k <- log(n)
    else
      extractAIC(lm(y ~ X, ind), k = log(n))
    location <- which.min(aicVec[, 2])
    list(mySubsets[location, aicVec, location])
}
```

The argument mySubsets will contain a subset of the subsets data frame held by the master processor. There is a minor problem of determining how to translate the rows of this object into what can be used with the indexing operator when it is applied to the X matrix to the variable subset that will be used in the regression. The solution is to translate each row into a logical vector using the vector class constructor with argument set to logical. An if statement is also needed to make certain that the case of fitting the constant is handled correctly; the sum of the ind vector will evaluate to 0 when all the predictors are excluded from the fit and is to determine if it is the case. The second component of the vector returned from extractAIC is the value of the criterion function. The best fit for a given processor will be the one whose index corresponds to the column of aicVec contains the smallest BIC. This index is found by using the which.min function* to the second row of aicVec. The processor then returns its optimal subset along with the corresponding value of BIC to the master processor.

Finally, the data and the myRegTask function are sent to the processors which are ordered to carry out their calculations

```
> mpi.bcast.Robj2slave(y)
> mpi.bcast.Robj2slave(X)
> mpi.bcast.Robj2slave(myRegTask)
> mpi.remote.exec(myRegTask(mySubsets))
```
