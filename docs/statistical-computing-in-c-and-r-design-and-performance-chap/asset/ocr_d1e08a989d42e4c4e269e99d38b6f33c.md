# 8.5 Maximum likelihood

The technique of maximum likelihood estimation leads to an optimization problem that is unique to statistics. First, let $X_1, \dots, X_n$ be a collection of random variables with joint density (or probability mass function) $g(:\theta^*)$ for $	heta^*$ fixed, unknown member of a set $\Theta$ that is a subset of the real line. Suppose now that $X_i$ have been observed in the sense that we have $X_1 = x_{1O}, \dots, X_n = x_{nO}$ with the O subscript observed values that are now fixed rather than random. The question is how to "best" extract the information about the parameter $\theta$ from the observed data.
The sample likelihood is defined to be

$$L(\theta) = g(x_{1O}, \dots, x_{nO}).$$

It is a function of $\theta$ because $x_{1O}, \dots, x_{nO}$ are now fixed. The maximum likelihood estimator, or mle, of $\theta$ is given by

$$\hat{\theta} = \argmax_{\theta \in \Theta} L(\theta).$$$$

The motivation for using mle as an estimator is as possible for the case where the components of $X$ are discrete. In that instance of

$$L(\theta) = Prob(X_1 = x_{1O}, \dots, X_n = x_{nO}).$$

i.e., $L(\theta)$ is the probability of seeing the observed values $x_{1O}, \dots, x_{nO}$ for a given value of $	heta$. This gives the interpretation of the choice for $\theta$ that assigns the highest probability for the data that was actually collected.
Our treatment of maximum likelihood will detail the special case where $X_1, \dots, X_n$ represent a random sample in the sense of Definition 4.1. Let $f(:\theta)$ be the common (univariate) density or probability mass function for some value of $\theta$ in which $g(x_{1O}, \dots, x_{nO}) = \prod_{i=1}^n f(x_i;\theta)$ makes it easier to work with the negative logarithm of the likelihood

$$\ell(\theta) = -\sum_{i=1}^n \ln f(x_i;\theta).$$$$

for optimization purposes. Minimizing $\ell(\theta)$ is equivalent to maximizing $L(\theta)$ and this shows us that the likelihood function (and its derivatives if they are needed needed to use Newton's method) must first be constructed from the observed data and packaged in a form that is amenable for use with a version of our Optim class. The C++ way to approach this is through creation of a likelihood class.
The design that will be used for our likelihood class is similar in spirit to the approach that was used for Linss in Section 8.3.2. Access to the data will be provided by the calling program. A function object will be created that will be passed to an optimization class. The end result will be the mie that will be returned as output.
