# USING ARRAYS AND POINTERS

```
//addresses.cpp

#include <iostream>

using namespace std;

int main() {
    double v[4] = {1., 2., 3., 4.};
    cout << "Address of v[0] = " << v[0] << endl;
    cout << "Address of v[3] = " << v[3] << endl;
    return 0;
}
```

produces the (machine-dependent) output
$ g++ -Wall addresses. -o addresses
Address of v[0] = 0xbffff9d0
Address of v[3] = 0xbffff9e8

The addresses returned from the program are in hexadecimal format with the letters a, b, c, d and e corresponding to 10-15. The output shows, that it will always be true for arrays in C++, the storage for v has been allocated in contiguous blocks of bytes of memory. To see this, first recall that a double is allocated eight bytes of storage. Then, note that the memory allocated to the first component of v at 0xbffff9d0 is 24 (i.e., 3 × 8) bytes (counting in hexadecimal) from the memory where its last component begins at 0xbffff9e8.

Pointers are variables that allow us to work with addresses. A pointer takes a memory location address as its value and provides the facility to access (i.e., read or write) to that location. A pointer p to an object dataType is declared via the syntax

```
dataType* p;
```

So, example,

```
int* p;
```

declares a pointer p that can be used to hold the address of a variable of type int. This can hit a bit further, if we write

```
int* p;
int i = 1;
p = &i;
```

the result is p "points" to the address of i in memory. To access the number that is stored in this location, the pointer is dereferenced using the syntax *p. This is illustrated by the code example below.

```
//simplePointer.cpp
#include <iostream>

using namespace std;

int main() {
    int* p = 0;
    int i = 1;
    p = &i;
    cout << "Address of i = " << &i << endl;
    cout << "Address of p = " << &p << endl;
```
