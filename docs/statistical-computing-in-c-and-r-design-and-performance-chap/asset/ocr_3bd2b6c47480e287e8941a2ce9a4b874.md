# 7.6 The Template Numerical Toolkit

Our particular implementation of the classes Matrix and Vector should be viewed as merely a first step in the creation of classes that can be employed in statistical computing applications. In particular, the algorithms for solving linear systems, finding eigenvectors, etc., need further refinement before they can be considered for day-day usage. In this regard, a thorough development would require a detour from our current path to a detailed study of numerical methods along the lines of Golub and Van Loan (1996). In lieu of tuning the Matrix and Vector classes another option is to employ existing software packages that provide features for numerical/vector manipulation with better supporting routines for numerical methods. There are several alternatives that can be used for this purpose including the matlab, Lapack++ and the Template Numerical Toolkit (TNT) in conjunction with JAMA/C++ that provides C++ translations of libraries in Lapack that can be downloaded from http://math.nist.gov/tnt. We conclude this chapter by giving a brief introduction to TNT.

The TNT and JAMA libraries can be downloaded from http://math.nist.gov/tnt. The download will produce all the necessary header files. The fact that the classes are templates also means that the actual source code is contained in the headers. Consequently, there are no libraries to compile and everything that is needed for compilation is accomplished with include directives. In particular, by including the file tnt.h obtains access to all the matrix and vector functions that include indexing and elementary numerical operations such as addition and multiplication.

The matrix and vector classes are named Array2D and Array1D, respectively. The variety of constructors that include specifications such as

```
Array2D();
Array2D(int m, int n, T* a);
Array2D(int m, int n, const T& a);
```

for two-dimensional arrays or matrices and

```
Array1D();
Array1D(int n, T* a);
Array1D(int n, const T& a);
```

for one-dimensional arrays or vectors. The default constructors create all others. The others employ the template format in Section 3.11 with T being a generic placeholder for a specific data type whose designation can be postponed until the array object is actually constructed.
