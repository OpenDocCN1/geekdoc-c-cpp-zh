```

The desired result has been obtained by specifying the split argument for strsplit as a white space. The output from strsplit has been returned in a list structure. To convert the lists of variables to integer values requires an application of the unlist function and coercion/coercing of the integer to you require e.g.,

```
> as.integer(unlist(A[1], split = " "))
+ as.integer(unlist(A[2], split = " "))
[1] 25 26 30 38

The previous examples mark our first exposure to the ubiquitous (in R) function that performs the R analog of the C++ casting operations. The term for this is coercion. The as.integer function is one example that we use to have character strings, numeric (i.e., double precision) values, as viewed as integer values.
