Initially, the output is written to the target file temp.txt after the connection
to the file is closed by invoking sink with no arguments. Output is then appended to the
temp.txt file by echoing to the command line.

It is also possible to open a connection to that file that allows for reading, writing or ap-
pending of input and this approach is treated in depth in Chapter 10 of Chambers
(1998) and Section 4.3 of Gentleman (2009). Using a connection is more efficient, e.g., when
data is being read from or written to a file. The read.table and write.table
functions actually open connections to the file provided as arguments are after
conclusion of their assigned reading or writing task. More generally, a connection can be
given, rather than a file name, for the file argument for these functions as well as for
scan and cat.

The file command opens a connection that remains open for reading, writing or both
until it is explicitly closed. In its simplest form an application of file might appear like

```
Name <- file("pathToFile/fileName", open = "r")
```

This would open a connection to fileName in the directory pathToFile as a result as a
r specification of the open argument. To write or append to fileName, open can be
specific as v or a. A connection is closed with

```
close(connectionName)
```

where connectionName is the name has assigned to the connection being closed.
