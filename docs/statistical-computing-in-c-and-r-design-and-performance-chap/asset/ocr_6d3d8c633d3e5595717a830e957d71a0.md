Linking objects to compile multiple source files can become tiresome if
many source files and/or the process has to be repeated. A program that
allows us to efficiently automate the compilation of each code in a project is the
make utility. Other features, this program checks to see if any files in the project
have changed since the last compilation and recompiles only the ones that have been
altered. To use it is necessary to have a myfile in the directory that contains the
code to be compiled. An illustration of such a file, named powerClass.mk in this case, that
was written to compile our power class example is shown below.

Listing 3.7 powerClass.mk

```
powerClass : powerClassDriver.o powerClass.o
g++ -Wall powerClass
powerClass.o : powerClass.cpp powerClass.h
g++ -Wall powerClass.cpp
pClassDriver.o : powerClassDriver.cpp powerClass.h
g++ -Wall powerClassDriver.cpp
```

This is a very simple myfile, but it illustrates the basic idea. The first item on line 1 of the
makefile is for a target. After the colon, the dependencies are listed and
the second line gives the gcc command line that should be used. The ensuing blocks
of the myfile recursively describe how to produce each of the dependencies. Thus,
4-5 of Listing 3.7 give instructions for generating the object file powerClass.o, etc. The new
feature is that there is now additional information provided about the dependence of each
our cpp files on other files is what makes useful to determine when recompilation
is necessary. An important requisite for a myfile is that the lines of code after each set
