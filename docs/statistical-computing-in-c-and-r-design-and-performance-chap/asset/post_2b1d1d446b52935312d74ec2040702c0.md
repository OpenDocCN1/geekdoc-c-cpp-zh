## 7.6 The Template Numerical Toolkit

Our particular implementation of the classes Matrix and Vector should be viewed as merely a first step in the creation of classes that can be employed in statistical computing applications. In particular, the algorithms for solving linear systems, finding eigenvectors, etc., need further refinement before they can be considered for day-day usage. In this regard, a thorough development would require a detour from our current path to a detailed study of numerical methods along the lines of Golub and Van Loan (1996). In lieu of tuning the Matrix and Vector classes another option is to employ existing software packages that provide features for numerical/vector manipulation with better supporting routines for numerical methods. There are several alternatives that can be used for this purpose including the matlab, Lapack++ and the Template Numerical Toolkit (TNT) in conjunction with JAMA/C++ that provides C++ translations of libraries in Lapack that can be downloaded from http://math.nist.gov/tnt. We conclude this chapter by giving a brief introduction to TNT.

The TNT and JAMA libraries can be downloaded from http://math.nist.gov/tnt. The download will produce all the necessary header files. The fact that the classes are templates also means that the actual source code is contained in the headers. Consequently, there are no libraries to compile and everything that is needed for compilation is accomplished with include directives. In particular, by including the file tnt.h obtains access to all the matrix and vector functions that include indexing and elementary numerical operations such as addition and multiplication.

The matrix and vector classes are named Array2D and Array1D, respectively. The variety of constructors that include specifications such as

```
Array2D();
Array2D(int m, int n, T* a);
Array2D(int m, int n, const T& a);
```

for two-dimensional arrays or matrices and

```
Array1D();
Array1D(int n, T* a);
Array1D(int n, const T& a);
```

for one-dimensional arrays or vectors. The default constructors create all others. The others employ the template format in Section 3.11 with T being a generic placeholder for a specific data type whose designation can be postponed until the array object is actually constructed. The integers m and n are the row and column dimensions of the two-dimensional arrays while n designates the rows for the one-dimensional case. The constructors with T& a arguments return arrays with every entry set to the value a. As true for our Matrix and Vector these constructors are used for creation of arrays with all zero entries. The one-dimensional array constructor with the pointer argument acts like the constructor that was used for class Vector in Section 3.9 in that it creates the Array1D object using a pointer (or array). The two-dimensional case involving a pointer is much more involved. A one-dimensional array of dimension m*n must be given to the constructor with the contents of the underlying array arranged in row major form.

In Listing 7.9 below of the contents of a matrix are read from a file and subject to various manipulations using tools from the TNT package. The scope resolution operator is employed to specify references to names in the TNT namespace.

Listing 7.9 tntEx1.cpp

```
//tntEx1.cpp
#include <iostream>
#include <fstream>
#include "tnt.h"
using std::cout; using std::endl;
int main(int argc, char** argv){
    int m = atoi(argv[2]); int n = atoi(argv[3]);
    double* pc = new double[n];
    double* pA = new double[m*n];
    std::ifstream fin;
    fin.open(argv[1]);
    for(int i = 0; i < m; i++){
        for(int j = 0; j < n; j++)
            fin >> pA[i*n + j];//row major form
        fin >> pc[i];
    }
    TNT::Array1D<double> c(n, pc);
    cout << "The vector c" << endl;
    cout << c << endl;
    TNT::Array2D<double> A(m, n, pA);
    cout << "The matrix A" << endl;
    cout << A << endl;
    TNT::Array2D<double> B(m, n);
    for(int i = 0; i < m; i++){
        for(int j = 0; j < n; j++)
            B[i][j] = (double)(i + 1)*(j + 1);
    }
    cout << "The matrix B" << endl;
    cout << B << endl;
    cout << "The sum of A and B" << endl;
    cout << A + B << endl;
    cout << "The product of A and B" << endl;
    cout << matmul(A, B) << endl;
    return 0;
}
```

This program uses the one-dimensional pointer based constructors to create both a and two-dimensional array. In accessing the file information that will fill the arrays it is assumed that the storage format progresses across the n columns then the rows with the elements of the one-dimensional array residing in the last column. The pointers that provide access to the data are used to create the Array2D object and Array1D object that are printed using overloaded output insertion operators.

Listing 7.9 illustrates the use of an overloaded + operator for matrix addition. There are also overloaded versions of =, -, +, *, /, and /. The *, /, and / carry out their respective computations on an element-wise basis. In particular, this means that * does not produce matrix multiplication. This is instead of the mattmult function illustrated in the program. It should be noted that the Array1D and Array2D create shallow copies that are essentially just an alias for the original; altering changes the original. Array2D B = A.copy();

The TNT can be augmented with the JAMA package to provide the facility for solving linear systems and carrying out eigenvalue and singular-value decompositions. JAMA contains the template classes. Eigenvalue, QR and SVD for carrying out Cholesky and QR factorizations and eigenvalue or singular decompositions. The classes have constructors that take Array2 objects as arguments and return objects that can access methods that correspond to various numerical routines. The Cholesky and QR classes solve methods that take Array1 objects as right-hand side for a linear system and return an Array1 object. The Eigenvalue class has methods getV and getEigenvalues that return the eigenvectors and eigenvalues of a real symmetric matrix in Array2 and Array1 that are provided as arguments. The analogous functions for the SVD class are getU, getSingularValues that return the left and right vectors in Array2 and values in Array1 object with all objects passed into the functions by reference.

A program that uses the JAMA package is given in the next listing. The idea is that arrays will be read from text files. The first array is comprised of a square × n array with an n-vector right-hand side as the last column in the file. This first array and eigenvector will be used to demonstrate the solution of a linear system and an eigenvalue decomposition using the JAMA Cholesky and Eigenvalue classes. A second, array will be imported and used to exemplify the SVD class.
