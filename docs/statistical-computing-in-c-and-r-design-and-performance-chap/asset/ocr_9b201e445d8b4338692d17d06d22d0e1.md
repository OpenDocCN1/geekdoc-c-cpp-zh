# AN EXAMPLE

A validity check function should be installed to ensure that the constructor has produced a valid g5 object. A function that will work for that purpose is

```
validG5 <- function(object){
  if(object@mName != "A" & object@mName != "B")
    return(paste("Incorrect machine for date", object@Date))
  if(object@sNo < 1 | object@sNo > 10)
    return(paste("Incorrect set number for date", object@date))
  if(object@Day != "M" & object@Day != "T")
    return(paste("Incorrect day for date", object@date))
  if(any(object@data < 1 | object@data > 40))
    return(paste("Incorrect ball number for date", object@data))
  return(TRUE)
}
```

This can be set as the function to check for incorrect g5 input data through the command

```
setValidity("g5", validG5)
```

The effect will not be rejection unless the ball set, machine or day entries do not coincide with that are appropriate for the game. Similarly a check is performed to see that all the ball numbers are between 1 and 40. The calculations in this latter case are carried out using any function that takes a logical array as its argument and returns TRUE if any of elements evaluate as TRUE. If there are any number values that fall outside the 1 to 40 range, will return TRUE and the date of the draw where error has been found will be printed to help locating the problem and correcting it in the text file containing the data.

Now that we have created the g5 class the R generic functions can be extended to work with g5 objects. One of interest is the S3 function summary. We could use the S3 system discussed in the previous section to define a version of summary that would be applicable to the g5 class. There is another option: make summary an S4 generic function with

+   > setGeneric("summary")
[1] "summary"
> summary
standardGeneric("summary" defined from package "base"

```
function(object, ...)
standardGeneric("summary")
<environment: 0x12839c40>
Methods may be defined for arguments: object
UseMethods("summary") for currently available ones.
```

The last part of the output confirms that summary is now an S4 function with the same arguments, object and the elipsis, as its S3 progenitor. A method that would serve our purpose is installed with

```
setMethod("summary", "g5", function(object){
  cat(paste("Drawings for", object@drawDate, "used Machine",
    object@mName, "Ball Set", object@sNo, "\n"))
  cat("Drawing results with presets", "\n"))
  print(object@data)
}
```
