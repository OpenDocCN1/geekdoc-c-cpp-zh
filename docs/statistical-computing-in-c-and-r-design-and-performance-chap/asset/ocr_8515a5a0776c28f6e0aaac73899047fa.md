# 2.4 Floating-point representation

Storage types with fixed positional representation work for integers. This basic idea could be used to represent rational numbers or fractions as $k/m$ with $k$ and $m$ integers. However, the utility of the fixed point framework leaves the unresolved problem of storing and working with irrational numbers, which comprise the bulk of the number system.

At this point we must realize that a general number cannot be stored in its entirety and, as a result the stored value remains only an approximation to the truth. Errors are created in computer arithmetic with real numbers due to the rounding of the numbers for storage as well as further manipulations. These issues will be discussed in the next section. The present suffices it to recognize that there is a limit to the precision that can be achieved from any computer representation that might be employed for irrational numbers. We will express the precision by the number of significant digits of agreement between the true value of a number and its floating-point representation. A good storage system is one that attempts to minimize losses in precision subject to the constraints that have been imposed by the allowed amount of storage.

Roughly speaking, significant digits are obtained by removing leading and trailing zeros from a number would take place for scientific notation. For example, this is an act that for the developments in this and the next section. To effectively scale irrational numbers on a computer the decimal point must be allowed. By we mean that the decimal is placed after the first significant digit. To recover the actual value of a number this decimal relocation is accompanied by multiplication by the base (e.g., 2 or 10) to an appropriate power. This is an adaptive representation for numbers that allow considerable storage flexibility to the integer case.

To be more specific, let us return to the base 10 scenario where the floating decimal concept is already familiar in the form of E-notation. For example, under this format the values 21.237 and .01237 would be retained as 2.1237E+1 and 2.1237E-2. The use of "E" in this context stands for the exponent of 10 and what is really being stated is that $21.237 = 2.1237 \times 10^1$ and $.021237 = 2.1237 \times 10^{-2}$.
