```cpp
struct g5Less : std::binary_function<g5, g5, bool> {
  bool operator()(const g5& g1, const g5& g2) const {
    std::string temp1, temp2;
    temp1 = g1.getDate() % g2.getDate();
    if (atoi(temp1.substr(0, 3).c_str()) < atoi(temp2.substr(0, 3).c_str()))
      return true;
    if (atoi(temp1.substr(0, 3).c_str()) == atoi(temp2.substr(0, 3).c_str()))
      && atoi(temp1.substr(5, 6).c_str()) < atoi(temp2.substr(5, 6).c_str()))
        return true;
    if (atoi(temp1.substr(0, 3).c_str()) == atoi(temp2.substr(0, 3).c_str()))
      && atoi(temp1.substr(5, 6).c_str()) == atoi(temp2.substr(5, 6).c_str()))
      && atoi(temp1.substr(8, 9).c_str()) < atoi(temp2.substr(8, 9).c_str()))
        return true;
    return false;
};
```

The sorting is to be drawn by date and accordingly, we need to supply a function that provides an order of < them. Thus, it should be a binary function that returns true when the date of one g5 is earlier than that of others. The dates that are used to make the comparisons are extracted from the Date members of the g5 class arguments using string class methods in a similar manner to the developments in Section 10.4.1. The three template parameters represent the type of the first and second function argument and the return type, in that order. Thus, the parameters are specified as g5 for both function arguments and bool. It now suffices to apply the algorithm sort with the vector object's `begin()` and `end()` iterators.

Next is the method for looking up a g5 object that corresponds to a specified date. The code for this purpose looks like

cpp
g5Array::const_iterator g5Array::lookup(const std::string& s) const {
  g5Equal f;
  const_iterator iter = std::find_if(begin(), end(), f, s);
  return iter;
}
```

It returns an iterator that points to the location of the target object in the g5Array container. The find_if function from the algorithm library is used to carry out the search in lookup. The functor supplied to find_if needs to be a unary operator that plays the role of ==. In this case we want comparisons to be carried out in terms of dates such as

```cpp
struct g5Equal : std::binary_function<g5, std::string, bool> {
  g5Equal() {}
  bool operator()(const g5& g, const std::string& s) const {
    if (g.getDate() == s)
      return true;
    return false;
  }
};
```

Again, the function will inherit from the binary_function class with its first parameter being type g5, a second parameter of type string and a bool return type. The problem is function is a binary function which find_if requires. The STL provides the bind adapter that sets the second argument at specified value. There is also a bind adapter that serves the same purpose for the first argument. In terms of the way it is used in the lookup method, bind2 will call the overloaded operator() for g5Equal with its second argument.

Finally, the g5Array chiSquare method is given by

```cpp
double g5Array::chiSquare() const {
  int* freq = new int[40];
  for (int i = 0; i < 40; i++)
    freq[i] = 0;

  sumFreq freq;
  std::accumulate(begin(), end(), freq);

  double e = n / 50.0;
  double* temp = new double[40];
  std::transform(freq[0], freq[40], temp[0], std::bind2(std::minus<double>(), e));
  std::transform(freq[0], freq[40], temp[0], std::bind2(std::divides<double>(), sqrt(e)));
  double chiStat = inner_product(temp[0], temp[40], freq[0], 0);

  return (39.0 / 50.0) * chiStat;
}
```

All that is computed is the "global" chi-square statistic for the entire data set. The creation of a more selective method that allows targeting particular machine/ball combinations is left as an exercise (Exercise 10.11). The first step in the chiSquare method is to calculate the frequency of occurrence of the different balls. This is accomplished by first creating an int that will be used to collect the data from the freq objects that are members of the g5 objects in the container. The actual accumulation of frequencies will employ the accumulate algorithm from the STL library.

The basic idea for accumulate derives from the now (hopefully) familiar summing recursion

```cpp
double sum = b;
for(int i = 0; i < n; i++)
  sum += a[i];
```

That will sum the elements of an n-element array given a starting sum of b. The algorithm provides a way to create an abstract recursion of this. A prototype for accumulate is

```cpp
accumulate(iterator begin, iterator end, dataType initialValue, f)
```

Here begin and end iterators are for a container object that point to the begin and end of a region where the “accumulation” is performed. The initialValue object is an instance of the class dataType whose objects are to be accumulated. It plays a role to b in our simple sum recursion. In that sense, it can be viewed as a starting value for the recursive process that will be directed by accumulate. The function f is a binary object that defines the operations that will be used to perform the “accumulation”: e.g., abstract versions of -, * or any other procedure that is amenable to an accumulation process.

For the g5 setting, our choice for the binary functor is

```cpp
struct sumFreq : std::binary_function<int*, g5, int*> {
  sumFreq() {}
  int* operator()(int freq, const g5& g) {
    for (int i = 0; i < 40; i++)
      freq[i] += g.getFreq(i);
    return freq;
  }
};
```

For any g5 object, the sumFreq functor will access the frequency of occurrence for the 40 balls using the g5 class accessor getFreq and add them to the appropriate elements of the array represented by its first pointer to int argument. The recursion is begun by giving the initial value of a pointer whose locations have all set to 0. The range is specified by the begin() and end() iterators from the g5Array class which results in the collection of frequencies for every object in the container.
