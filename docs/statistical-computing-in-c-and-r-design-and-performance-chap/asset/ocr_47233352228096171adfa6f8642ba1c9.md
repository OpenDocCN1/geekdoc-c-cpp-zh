As with Node struct, the changes required to adapt the LTC class from linked template parameters to allow for indexing and storing objects of general types.

Let us begin the discussion of 9.7 by examining the internal iterator struct for the LTC. As the phrase "nested", suggests, the entry declaration for class iterator is contained within the LTC declaration.
The operative aspect of the iterator in 9.7 is its current member. There are two constructors: a default constructor that creates a pointer to Node with current initialized as the null pointer and a constructor that takes an LTC object as its argument and initializes current as the Head of the object. Class methods are provided for dereferencing or access object (i.e., == and !=), assignment, comparison of iterator objects, prefix and postfix increment operators that move current with the latter being obtained by application of the former. Note the presence of a dummy argument that allows the postfix operator to be overloaded.
