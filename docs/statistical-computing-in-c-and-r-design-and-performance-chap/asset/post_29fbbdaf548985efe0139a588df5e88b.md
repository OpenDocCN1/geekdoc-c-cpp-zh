## B.3 R for statistical analysis

As the previous two sections have fully demonstrated, R is much more than just a statistics software package. Of course, it does come equipped with a number of functions for carrying out many of the standard statistical calculations that arise in the analysis of data. Many are more available through packages that can be downloaded from the CRAN website.

The data set mtcars in this example contains information on several variables related to 32 cars that was reported in a 1974 issue of Motor Trend magazine. We have elected to work with three variables: miles per gallon (mpg), displacement (disp) and weight (wt) and coerced them into the form of a matrix with the as.matrix function. An application of the summary function to the resulting array produces typical summary statistics corresponding to each column in the array. The standard deviations and inter-quantile ranges were also computed for each column using the sd and IQR functions in combination with the apply function. The variances could have been obtained similarly by var instead of sd.

The values for mean, median, and quartiles can be obtained directly using the mean, median and quantiles as illustrated by

```
> mean(A, 1)
> [1] 20.0906
> median(A[, 1])
> [1] 19.2
> quantile(A[, 1], prob = c(.25, .75))
  25%     75%
15.425 22.800
> min(A[, 1]); max(A[, 1])
> [1] 10.4
> [1] 33.9
```

The probs argument for quantile designates the percentile or percentiles that are to be computed. The choice of probs = c(.25, .75) indicates that the 25th and 75th percentiles, or equivalently, the quartiles are to be calculated. The max and min functions were also used to obtain the smallest and largest values of the mpg variable.

It is uncommon for data to have missing values which appears in R as the constant NA. The default behavior of R data functions when they encounter an NA is to return NA as output, perform an error or omit the missing value and perform the requested analysis. This default behavior can be overridden by specifying a value for a function argument with name such as na.rm or na.action. In particular, the na.rm (for "NA remove") is what appears in the mean function as illustrated by the code snippet

```
> dat <- c(pi, NA, exp(pi), 1:5)
> mean(dat)
> [1] NA
> mean(dat, na.rm = TRUE)
> [1] 5.897469
```

By setting na.rm to TRUE, a mean for the non-NA values is returned by the mean function. The order() function can be used for sorting elements in an array. This function takes a vector and returns a vector of integers representing the ranks of the input vector. More precisely, the 1st component of the returned vector from order() is the rank of x[1] among the values in x. Conversely, order(x) is the x with elements rearranged numerically. In this case, the same effect could be accomplished with R's sort function. The order function works more generally; produces a matrix with rows rearranged so that the elements in its ith column are ordered.

R contains functions for performing linear models. The primary argument for lm that was used in the previous section is a formula object that defines a relationship between dependent and independent variables. The dependent variables on the left-hand side and the independent variables on the right-hand side separated by +. Suppose there are three arrays, x1, x2 of equal length and the formula log(y) ~ x1 + x1^2 + x1*x2 is used in lm this specifies that a linear model was fitted with data providing the natural logarithm of its elements. The model is then fitted with terms involving x1 as well as its square and product with x2. The formula results in no intercept. Otherwise, an intercept would be included by default. The lm function returns object of class lm that include coefficients, residuals and fitted. These can be accessed using the $ operator. Note that both a column index and column name have been used to access a specific column of the array.

```
> mtl <- lm(A[, 1]) ~ A[, 2] + A[, "wt"]
> mtl$Coefficients
(Intercept) A[, 2] A[, "wt"]
34.96054 0.00919 -3.35082
```

Finally, it is good to know that R comes with a function that can be used for drawing random samples from an array that is specified as its first argument. The prototype for sample appears as

```
sample(x, size, replace = FALSE, prob = NULL)
```

The x argument is the array to be sampled while size is the number of elements to select. If replace is set to TRUE, sampling will be done with replacement and is carried out without replacement otherwise. The prob argument can be a vector of probabilities for selecting the elements of the null or empty object. If no value is specified for prob the selection is made with uniform probability. To demonstrate this idea

```
> set.seed(123)
> sample(letters, 4)
> "h" "e" "j" "u"
> sample(LETTERS, 10, replace = TRUE)
[1] "Y" "B" "N" "X" "L" "Y" "L" "R" "O"
3 3 1 1 3 3 2 3
> sample(c(1, 2, 3), 10, replace = TRUE, prob = c(.1, .3, .6))
[1] 2 2 3 3 3 1 2 2
```

This example used the built-in R arrays letters and LETTERS that contain the lower- and upper-case letters of the alphabet.
