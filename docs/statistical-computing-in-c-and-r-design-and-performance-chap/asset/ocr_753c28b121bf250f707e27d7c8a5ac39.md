There is a bit more to the ~ operator that has been mentioned here. It is part of a generic class Arith that includes arithmetic operators as +, -, *, *. Group generics are collections of functions that perform related operations and have comparable mathematical structure in terms of, e.g., the number of arguments. With generic functions it is possible to simultaneously extend all operators in the group to work with objects of a given class. We will illustrate this in the next section using the Compare generic.

The @ and slot function provide us with a means of accessing the slots of an object. However, as for the C++ setting, it is generally preferable to use accessor functions that are simple and named. For example, we might create an accessor function for the coefficient of an regr object with

```
> setGeneric("bHat", function(object) standardGeneric("bHat")
[1] "bHat"
> setMethod("bHat", signature = "regr", function(object) object@b)
[1] "bHat"
```
