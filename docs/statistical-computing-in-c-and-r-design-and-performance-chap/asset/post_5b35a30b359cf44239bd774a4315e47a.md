
## 430 DATA STRUCTURES IN C++

The remainder of this section will be focused on illustrating the priority_queue container in the context of a discrete event simulation wherein the activity in some physical system is modeled through a sequence of events that occur, sequentially, over a specified period of time. The setting we will use is that of M/M/n queue i.e., a queue with n servers where there are Poisson customers arriving with rate parameter λ and independent exponential service times with mean λ. The servers and customers are also assumed to operate independently. A similar development using the queue class will be explored in Exercise 10.15.

The basic elements of the model are the customers and servers, and, each will need to be developed in the form of a class. The customer class will be treated first. The declaration is

```cpp
struct Customer{
    int Arrive;
     bool Gold;
    Customer(int t = 0, bool gold = 0) : Arrive(t), Gold(gold) {}

    bool operator<(const Customer& x) const;
};
```

There are two members: the customer's arrival Arrival and a Boolean variable Gold. The Arrival class is the member that the Customer object enters the simulation. To simplify matters, time will evolve in discrete (i.e., one minute) intervals and, Arrival will take only on integer values. The Gold class represents the presence or absence of "gold" in the sense associated with car rentals, airlines, etc., where frequent passage can lead to a customer receiving a preferential "gold" level of service. The way that Gold is used is in the definition of a < operator which takes the

```cpp
bool Customer::operator<(const Customer& x) const {
    if (Gold == 0 && x.Gold == 0 ||
        Gold == 1 && x.Gold == 1)
        if (Arrive < x.Arrive)); // earlier arrival higher priority
            return false;
    else
        return true;

    if (Gold == 0 && x.Gold == 1)
        return true;
    if (Gold == 1 && x.Gold == 0)
        return false;
}
```

The STL queue is a max queue i.e., elements are partially sorted in descending order determined by the < operator. All things being equal, our overloaded version of this operator has the effect that earlier arrivals get higher priority and, conversely, later arrivals leads to lower priority. On the other hand, a customer with a Gold value is always preferred (i.e., >=) to a customer with Gold equal to false.

Output allows us to track the progress of the simulation is created with an overloaded insertion operator amenable for Customer objects. It takes the form

```cpp
std::ostream& operator<<(const std::ostream& out, const Customer& x){
    out << "Arrival time = " << x.Arrive << " Gold = " <<
        std::boolalpha << x.Gold << std::endl;
    return out;
}
```

## QUEUES

Our definition for the Server class is

```cpp
struct Server{
    bool Busy;
    int serviceTime;
    Server(){
        Busy = 0; serviceTime = 0;
    }
};
```

A particular Server object may be "busy" with a Customer object in which case its Boolean Busy member will evaluate to true. Otherwise, the Server object will be available for assignment to the next object from the queue. The other member of the Server struct is serviceTime. With arrival time, this will be measured in discrete intervals.

With the Customer and Server classes at our disposal, the simulation class can now be defined in Listing 10.6.

Listing 10.6 MMNQueue.h

```cpp
class MMNQueue{
    std::priority_queue<Customer> Q;
    Server* pS; // array of servers
    ranRng Rng; // random number generator
    void update(int t);
    int rPoisson();
    double Exp(double lambda);
    bool isGold();
    void updateServers();
    int freeServer();

    // simulation parameters
    int runTime, nServers;
    double lambdaC, lambdaT, goldProb;
    unsigned long Seed;

    // statistics
    int totalTime, numberCustomers;
public:
    MMNQueue(int runtime, int nServers, double lambac,
        double lambdat, double goldProb, unsigned long seed) :
        runTime(runtime), nServers(nServers), lambdaC(lambac),
        lambdaT(lambdat), goldProb(goldProb), Seed(seed){
        totalTime = 0; numberCustomers = 0;
        pS = new Server[nServers];
        Rng = ranRng();
        Rng.setSeed(Seed);
    }
    ~MMNQueue(){
        delete[] pS;
    }
    double runSimulation();
};
```

The parameters for the simulation are:

- runTime: the length of time the simulation will be allowed to run.
- nServers: the number of servers for the system.
- lambdaC: the means for the Poisson customer arrival distribution and the exponential service time distribution.
- goldProb: the presence or absence of Gold "status" for a Customer object is modeled as a Bernoulli random variable with goldProb evaluating the probability of Gold evaluating as true.
- Seed: the generation of random numbers from the Poisson, exponential and Bernoulli distributions requires a random number generator of some sort. The one that will be used is the ranUn method from the randGen class in Appendix E. The value of Seed provides the seed that will initialize the generator.

The class constructor defines these parameters through an initializer list. The constructor also creates an array of servers and initializes the system.

This function serves as the simulation's "clock" in it moves the process forward at one unit intervals from the beginning time at 0 to its end time. During this period its only function is to call the update method that handles initialization of new Customer objects, manages the service times for the Server objects, etc. When the simulation ends, the runSimulation will empty the priority_queue container while adding the waiting time for its Customer elements (that waited and were not served) onto the process waiting totalTime. Its last action is to return the average waiting time over the entire simulation.

```cpp
double MMNQueue::runSimulation(){
for(int t = 0; t < runTime; t++){
    cout << "time = " << t << endl;
    update(t);
    cout << "queue size " << Q.size() << endl;
}
while(!Q.empty()){ // some people still in the queue
    totalTime += runTime - Q.top().Arrive;
    Q.pop(); // remove customer
}
return ((double)totalTime/numberCustomers);
}

void MMNQueue::update(int t) {
    updateServers();
    int serverIndex = 0;
    // number of new customers that arrived in last minute
    int numberNew = rPoisson();
    cout << "number of new customers " << numberNew << endl;
    // serve as many as possible right away
    while(freeServer() != -1 && Q.empty() && numberNew > 0){
        serverIndex = freeServer();
        pS[serverIndex].Busy = 1;
        pS[serverIndex].serviceTime = ceil(rExp(lambdaT));
        numberNew--;
    }
    Customer temp;
    if(numberNew > 0){//add to the queue
        for(int i = 0; i < numberNew; i++){
            temp = Customer(t,isGold());
            cout << "Waiting customer has " << temp;
            Q.push(temp);
        }
        numberCustomers += numberNew;
    }
    while(freeServer() != -1 && !Q.empty()){
        serverIndex = freeServer();
        pS[serverIndex].Busy = 1;
        pS[serverIndex].serviceTime = ceil(rExp(lambdaT)); 
        totalTime += t - Q.top().Arrive;
        cout << "Customer being served has " << Q.top();
        Q.pop();
    }
}

void MMNQueue::updateServers() {
    for(int i = 0; i < nServers; i++){
        if(pS[i].serviceTime > 0)
            pS[i].serviceTime--;
        else
            pS[i].Busy = 0;
    }
