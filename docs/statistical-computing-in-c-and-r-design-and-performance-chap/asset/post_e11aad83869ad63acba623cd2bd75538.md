# 7.4 Singular value decomposition

An extension of the eigenvector decomposition for a symmetric matrix leads to singular value decomposition, or merely SVD, that applies to matrices that are neither symmetric nor square. The SVD appears in multivariate analysis in the context of correlation analysis, and also has applications in the solution of general least-squares problems. Let A be a real $p \times m$ matrix of rank $r$. Then $AA^T$ is a symmetric-semidefinite matrix that can be written as

```math
AA^T = \sum_{j=1}^{r} \lambda_j^2 u_j u_j^T
```

for eigenvalues $\lambda_1^2 \geq \lambda_2^2 \geq \dots \geq \lambda_r^2 \geq 0$ and associated eigenvectors $u_1, \dots, u_r$. Now, define

```math
v_j = \frac{1}{\lambda_j} A^T u_j \quad (7.24)
```

for $j=1, \dots, r$ and observe that $v_j$ is an eigenvector for $A^T$ because

```math
A^T A v_j = \frac{1}{\lambda_j^2} A^T A^T u_j = \lambda_j^2 v_j
```

Thus, $AA^T$ and $A^TA$ have the same nonzero eigenvalues and their eigenvectors are related by (7.24). Additionally,

```math
u_i^T A v_j = (A u_i)^T v_j = \lambda_j \delta_{ij} \quad (7.25)
```

with $\delta_{ij}$ either 0 or 1 depending on whether $i$ is equal to $j$. The (left) singular vectors $u_1, \dots, u_r$ can be augmented by an additional $p-r$ orthonormal vectors $U=[u_1, \dots, u_p]$. Similarly, an additional $m-r$ orthonormal vectors $v_{r+1}, \dots, v_m$ can be constructed to create the orthonormal matrix $V=[v_1, \dots, v_m]$ of right singular vectors. The vectors $u_{r+1}, \dots, u_p$ necessarily correspond to 0 eigenvalues of $AA^T$ and $A^TA$, respectively. As a result, (7.25) can be rewritten in the standard SVD form

```math
U^T AV = \begin{bmatrix} \Lambda & 0_{r \times (m-r)} \\ 0 & O_{(p-r) \times (m-r)} \end{bmatrix} \quad (7.26)
```

or, equivalently, as

```math
A = U \begin{bmatrix} \Lambda & 0_{r \times (m-r)} \\ O_{(p-r) \times r} & O_{(p-r) \times (m-r)} \end{bmatrix} V^T \quad (7.27)
```

for

```math
A = \text{diag}(\lambda_1, \dots, \lambda_r). \quad (7.28)
```

In combination these develops our next theorem.

**Theorem 7.2.** Let $A$ be a $p \times m$ matrix of rank $r \le \min(p, m)$. Then,

```math
A = \sum_{j=1}^r \lambda_j u_j v_j^T. \quad (7.29)
```

where $\lambda_j^2$ are the nonzero eigenvalues of $AA^T$ and $A^TA$ and $u_j, v_j = \lambda_j^{-1} A^T u_j, j = 1, \dots, r$ are the corresponding eigenvectors. As a result of Theorem 7.2, a SVD can be produced using the computational scheme described in Algorithm 7.4.

# Algorithm 7.4 SVD algorithm

```python
if number of rows for $A \le$ number of columns then
  compute eigenvalues $\lambda_j^2$ and eigenvectors $u_j, j=1, \dots, r$ of $AA^T$
  $v_j = \lambda_j^2 A^T u_j, j=1, \dots, r$
else
  compute eigenvalues $\lambda_j^2$ and eigenvectors $v_j, j=1, \dots, r$ of $A^TA$
  $u_j = \lambda_j^{-1} A v_j, j=1, \dots, r$
end if
  return $\lambda_j, u_j, v_j, j=1, \dots, r$
```
