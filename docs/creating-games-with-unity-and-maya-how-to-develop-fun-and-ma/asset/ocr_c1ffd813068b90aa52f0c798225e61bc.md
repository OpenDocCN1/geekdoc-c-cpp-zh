# ### Why?

That's a long line of code, so let's look at what's happening there. iTween.RotateTo is calling up the custom class RotateTo that iTween provides. Then, `hit.collider.gameObject` is the object being rotated (in this case it's the power switch that the ray is casting upon). Then the Hashtable Args. The format for these is `argumentToChange : value`, so in order these arguments are saying “rotate to X = 0 ("x": 0); do it over 1 second ("time":1), when done look back to the object the script is attached to, not the object you were rotating ("completeTarget":gameObject), and when you're done, fire the TurnOnLights function ("oncomplete": "TurnOnLights").” Cool power in one line of code.
