# Why?

We carefully scaled Aegis in Maya to allow for this quick setting of Scale Factor of 1. The Animations area is where we get to define the multiple animations that may be attached to any one asset. This can really have any amount of animations. The key here is defining the animations with a good name that we can call up later. The default animation this asset will run (in the absence of other instructions) is the first one—Idle. But, with script we could call up any of the others (more on this later).
