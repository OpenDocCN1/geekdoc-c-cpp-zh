# ### Warnings and Pitfalls

Be very sure that the joints are not built in a straight line (as in the knee joint directly beneath the hip joint). We are going to animate the character's legs using something called IK (Inverse Kinematics) and the calculations are made much easier if the joints that are to be bent already have a bend to them (so Maya knows which direction to bend them).

Also, note that the hip, knee, and ankle joints are in the middle of the leg (where these joints really exist in a person's anatomy), but the ball and toe joints are on the ground, which represents the axis that the polygons assigned to these joints should rotate around.
