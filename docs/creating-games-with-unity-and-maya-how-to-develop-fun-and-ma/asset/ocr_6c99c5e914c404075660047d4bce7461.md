# ## Why?

Why are we suddenly building a bunch of materials in the Hypershade, when in the past we have built them as we went? Well, creating a material as we assign it works great for situations when one material is all that will be on a given object. However, when assigning multiple materials to one object, it works best if the materials are already constructed.
