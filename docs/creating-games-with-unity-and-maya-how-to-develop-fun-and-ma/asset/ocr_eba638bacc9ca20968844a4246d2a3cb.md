# Tips and Tricks

As the number of shells increase, the number of functions will increase, which means the number of nodes increases and the file gets heavier and heavier with history. As I was working toward the previous steps, Maya began to get really sluggish as it tried to work through all that history for every step. A quick Edit>Delete All by Type>History cleans up the history and Maya is snappy again.
