# Why?

“Mirror across” is asking which plane to use as the mirror plane. If the character is facing forward (looking toward positive Z), YZ is the appropriate plane. The Replacement Names For Duplicated Joints just goes through all the joints and looks for L_ and replaces it with R_. This means that the left versions (designated by L_) are all renamed to right versions (called R_); this includes the associated IK handles. Cool, no?
