# Tips and Tricks

Using the Liquefy tool is a lot of fun. The trick is to be sure to use varying sizes of brushes to avoid really noticeable smearing, and use Show Backdrop (bottom-right corner) to dial in the UV guides to make sure you are liquefying into the proper place.
