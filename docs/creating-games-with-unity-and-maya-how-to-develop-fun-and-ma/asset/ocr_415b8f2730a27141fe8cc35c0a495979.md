# Warnings and Pitfalls

GameObject.Find is a very handy tool to have. However, it can quickly be abused. For instance, if GameObject.Find is contained within a function Update, this means that Unity is being asked to go find an object on every single frame. Very many of these and suddenly Unity is more busy looking for objects than it is running the game. Generally, use GameObject.Find when it can fire once (like in function Awake situations or within another function that is called at a very specific time).

# Why?

A private variable is a variable that can be defined, but it isn't defined in the Unity Editor via dragging items as we did before. Although those could remain public, since they are going to be defined in the script, it keeps another developer from trying (or feeling like they need) to populate variables.
