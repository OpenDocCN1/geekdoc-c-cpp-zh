# Why?

Several why's here. First, the Root joint is going to be the one joint to rule them all. This joint is going to be the parent-most joint of all the joints in the skeleton. It will be important that it is sitting in the middle of Aegis because this will be the mirror point. By placing the joint from the side-view panel, we know that the X Position value of the joint is 0.
