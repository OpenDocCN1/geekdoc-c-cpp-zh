# Tutorial 15.2: Setting Up the Armed Arms

+   **Step 1:** Check to see if there is a file in the Character Assets folder called AegisChung_Arms_Prefab, which should have come through processes in Chapter 10. However, if you skipped Chapter 10 for some reason, or if the AegisChung_Arms_Prefab is not there, be sure to import the AegisArms unity package (Assets>Import Package>Custom Package and then find where you've downloaded the package to).
+   
+   **Step 2:** In the Hierarchy, select First Person Controller and make sure its Rotation XYZ are all set to 0. Move the mouse over the Scene view and press F to frame the First Person Controller.

> **Why?**
> 
> Again, the idea here is that when the arms are placed as children of the Main Camera, that everything is lined up.

+   **Step 3:** Expand the First Person Controller group so that Main Camera is visible.
+   
+   **Step 4:** Place AegisChung_Arms in the scene as a child of Main Camera. The quickest way to do this is to drag AegisChung_Arms from the Project panel directly on to Main Camera (Figure 15.12).

> **Why?**
> 
> This will look weird for a minute. The arms will be embedded in the white capsule and will be difficult to see. Similarly, all the weapons may be visible. Not to worry, we'll fix that in a minute.

We're making the arms a child of the camera so that wherever the camera moves, the arms move—which means the guns will always be pointed at where we're looking.
