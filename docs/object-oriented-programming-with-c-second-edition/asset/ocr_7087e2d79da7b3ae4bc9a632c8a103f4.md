First, let us have a look at the modified definition of the structure Distance. Two new keywords, private and public have been introduced in the definition of the structure. Their presence in the foregoing example tells the compiler that iFeet and fInches are private members of variables of the structure Distance and the member functions are public. Those of iFeet and fInches of each variable of the structure Distance can be accessed/modified only through member functions of the structure and by any non-member function in the program (note that it is the iFeet and fInches of the invoking object that are accessed/modified by the member functions). Any attempt to violate this restriction is prevented by the compiler because is how the C++ compiler recognizes the private keyword. Since the member functions are public, they can be invoked from any part of the program.

As we can observe from Listing 2.3, the compiler refuses to compile the line in which a private member of a structure variable is accessed from a non-member function (the main() function in Listing 2.3).

The keywords private and public are also known as access modifiers or access specifiers because they control the access to the members of structures.
