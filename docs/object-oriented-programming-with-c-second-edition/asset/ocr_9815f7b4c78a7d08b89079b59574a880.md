The loop has been defined to execute as long as the call to the next() function through the pointer does not return NULL. But, we can see from Figure 9.23 that this function will return NULL right now because the next pointer of the node at which iter is pointing NULL. Thus, the re-initialization expression of the for loop will not execute, the loop will terminate, and the iter pointer will continue to point at the first node of the linked list. The next statement to execute is:

```
iter->setNext(temp);
```

This will copy the value of the temp pointer to the next pointer of the node at which iter points. As a result, the linked list will look like Figure 9.24.

![](bbox=[0.238, 0.279, 0.81, 0.576])

The rest of the process remains the same as the previous one. Since temp and iter are local variables, they go out of scope and what we are left with is a linked list that looks like Figure 9.25.
