现在让我们研究 delEnd() 函数。正如名称所示，该函数删除列表的最后一个节点。与 delBeg() 函数相比，这个函数稍微复杂。

```cpp
/*
 删除最后一个节点的函数。
 */ void SingleLinkedList::delEnd() {
    /* 如果列表为空 */
    if(head == NULL) {
        /* 删除头 */
        head = NULL;
    } else {
        /* 声明一个临时指针 */
        ListNode* iter;
        /* 遍历列表指向最后一个节点 */
        for(iter = head; iter->getNext() != NULL; iter = iter->getNext());
        /* 删除最后一个节点 */
        delete iter->getNext();
        /* 将 next 指针置空 */
        iter->setNext(NULL);
    }
```
