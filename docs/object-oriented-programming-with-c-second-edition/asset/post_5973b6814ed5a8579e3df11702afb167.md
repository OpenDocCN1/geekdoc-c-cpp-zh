## 2.1.9 Arrow Operator

Member functions can be called with respect to an object through a pointer pointing at the object. The arrow operator (->) does this. An illustrative example is shown in Listing 2.13.

## Listing 2.13 Accessing members through pointers

```cpp
/*Beginning of PointerMember.cpp*/
#include<iostream.h>
#include"Distance.h"

void main() {
    Distance d1;           //object
    Distance * dPtr;      //pointer
    dPtr=&d1;               //pointer initialized
    /*Same as d1.setFeet(1.1) and d1.getInches(1.1)*
    dPtr->setFeet(1);      //calling member functions
    dPtr->setFeet(1.1);    //through pointers
    /*Same as d1.getInches() << d1.getInches()*
    cout<<dPtr->getInches()<<" "<<dPtr->getInches()endl;
}
/*End of PointerToMember.cpp*/
```

# Output
11.1

It is interesting to note that the dot (. ) operator, the definition of the arrow (->) operator has also been extended in C++. It takes not only data members on its right in C, but also member functions as its right-hand side operand. If the operand on right is a data member, then the arrow behaves as it does in C language. However, if it is a member function of a class where the same type is its left-hand side operand, then the compiler simply passes the value of the pointer as an implicit leading parameter to the function call. Thus, the statement

```
dPtr->setFeet(1);
```

after conversion becomes

```cpp
setFeet(dPtr,1);
```

Now, the value of dPtr is copied into this pointer. Therefore, this pointer also points at the same object at which dPtr points.

## 2.1.10 Calling One Member Function from Another

One member function can be called from another. An illustrative example is shown in Listing 2.14.

| Listing 2.14 | Calling member function from another |

class A
{
    int x;
public:
    void setindirect(int q);
    void setx(int p);

{
    x=q;

void A::setx(int p)
{
    setindirect(p);
}

    A A1;

    A1.setx(2);

/*end of NestedCall.cpp*/
