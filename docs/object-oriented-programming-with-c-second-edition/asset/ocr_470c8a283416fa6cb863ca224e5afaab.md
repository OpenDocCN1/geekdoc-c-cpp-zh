# Object-Oriented Programming with C++

+   - **Purpose of the class construct**: Like C++, Java also provides the class construct. The purpose and functionality of this construct is approximately the same in both languages. Like classes that are defined in C++, there are member functions and member data in the classes that are defined in Java. there are differences between the ways this construct has been implemented in the two languages. The section on ‘Differences between C++ and Java’ explains these differences.
- **The static keyword**: The purpose of this keyword is the same in both languages.
- **Constructor**: Constructors in Java are defined exactly the same way as they are defined in C++ and also serve the same purpose. Constructors in C++ and Java are similar to each other in the following ways: The compiler defines the constructor if we do not define one. If we define the zero-argument constructor or a parameterized constructor for a class, the compiler does not define the default constructor for the class. An access specifier can be specified to a constructor.\ **Inheritance**: Like C++, Java also supports inheritance. However, Java does not support multiple inheritance. This is explained in the section ‘Differences between C++ and Java’.
- **Static polymorphism**: Like C++, Java supports static polymorphism. Two functions with different signatures can have the same name.
- **Dynamic polymorphism**: Dynamic polymorphism is supported in both C++ and Java. If a member function of the base class has been overridden in the derived class and it is called for a base reference that refers to a derived class object, then the member function of the derived class gets called.
- **Overriding member functions of base in derived classes**: Base class functions can be overridden in the derived class except when the base function has been specified as final. This exceptional case has been explained in the section ‘Differences between C++ and Java’.

# C.2 Differences between C++ and Java

+   The following are some of the features that C++ and Java differ:
- **Structures and unions**: There are no structures and unions in Java. Java supports only classes.
- **The main() function**: The main() function in C++, the main() function in Java is not a global function. It is instead a public static function of a class. The class that has such a main() function is executed by clients or command line.
Unlike the main() function in C++, which takes an array of character pointers as parameter, the main() function in Java takes an array of objects of the String class.
- **Header files versus packages**: Instead of header files, we have packages in Java. Packages in Java serve a similar purpose as header files in C++. Packages are included in Java source codes by using the import directive as:
```\import java.util.Date; //importing a package
```nThis statement imports the Date class, which is defined in the ‘util’ package, which is in turn included in the ‘Java’ package.
