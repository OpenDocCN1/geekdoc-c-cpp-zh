As before, the test expression inside the if statement will be tested. However, this time, the test will fail. Therefore, the first block will be bypassed. The test expression in the next statement will get tested. This will return true because the value in the node at nodePtr is 20 is greater than the value of pValue, which is 10.

Now comes the tricky part. The second if will execute. The insert() function will be called recursively and the second generation of the function will start executing. Looking closely at the value that is passed to the recursive call to the insert() function. It is as follows:

```
nodePtr -> getLeft()
```

We know that this function will call a reference to the left pointer of the node at nodePtr points currently (and we know nodePtr currently points at the first node). Thus, when the second generation of the function gets called, nodePtr, which is one of the formal arguments, ends up a reference to the left pointer of the first node. The address of the first node is 6221, the address of its left pointer will be 6225 (we already know why). The address of nodePtr will also be 6225. Its value will also be NULL because the value of the left pointer of the first node is NULL.

The other argument, pValue, gets created as a local variable in the second generation. Let us assume that its address is 6720. Figure 9.76 explains what is happening.

A new node will get created and its address will get copied to nodePtr. Since nodePtr is a reference to the left pointer of the first node, the value of the left pointer of the first node will also become equal to the address of the newly created node.
