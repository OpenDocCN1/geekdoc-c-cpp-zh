# Output

Inside the catch block of test_hmean()
Inside the catch block of main()

Let us follow the execution of the main() function. The main() function calls the test_hmean() function from inside the try block. The test_hmean() function in turn calls the hmean() function from inside the try block. The hmean function throws an error because the values passed to it are opposite to each other (10 and -10). The type of exception is hexception. The test_hmean() has a catch block that handles exceptions of this type. Therefore, the catch block of the test_hmean() executes. The first statement of the catch block displays "Inside the catch block of test_hmean()". The second statement of the catch block throws the same exception. Thus, the exception is not consumed by the test_hmean() function. Inside, it gets upwards to the calling function, which is main().

main() in turn has a catch block that handles exceptions of the thrown type. Therefore, the catch block of the main() function executes. The single statement in this displays the error "Inside the catch block of main()".

Naturally, if the throw statement is removed from the catch block of the test_hmean() function, then the catch handler of the main() function would not receive any exception for it to handle. execute(the test_hmean() function would not be throwing anything). Let us remove the throw statement and see whether the output changes or not. See Listing 11.14.
