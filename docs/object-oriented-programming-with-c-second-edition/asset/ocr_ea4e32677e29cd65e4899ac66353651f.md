The code in Listing 8.26 works if the right-hand side operand of the greater-than object is an object class Distance. However, if it is a float-type value, the expression will not compile.

d1>4.5

This is because the compiler will interpret this expression as follows:

d1.operator>('4.5')

The float type '4.5' will be passed as a parameter to the operator-overloading function. Since the formal argument of the operator-overloading function is a Distance type object, the compiler will throw an error. In the case of the addition operator, introducing a suitable constructor that converts from float to Distance solves the problem (Listing 8.21). Nevertheless, one condition still needs to be tackled. What will happen if the left-hand side operand is of float type?

4.75 > d1

The solution is the same as in the case of the addition operator. We replace the function given in Listing 8.26 with a friend function, as shown in Listing 8.27.
