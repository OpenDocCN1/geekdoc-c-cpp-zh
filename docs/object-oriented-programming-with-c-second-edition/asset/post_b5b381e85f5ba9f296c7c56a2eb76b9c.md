Each object of the above class will be a node in the BST. Each node will have three data members—val, left, and right. The data of each node will be stored in the first member, val. This is an integer-type variable, which means the nodes will contain integer values. The remaining data members are left and right. Each of these is a pointer to another node. As we know, each node of a BST has either a left child or a right child or neither. If a node has a left child node, then the left data member will point at that node. Otherwise, it will be NULL. The same holds true for the right data member.

Since temp is a reference to the left pointer, its address will be the same as that of the left pointer, which is 2176. And, from our knowledge of reference, we know that any change to the value of temp will cause the same change to the value of the left pointer (because they are essentially two names for the same memory block). Thus, if the following statement executes now, it will change the value of the left pointer.
The next statement in the program is:

```cpp

The above statement will create a new object of the BSTNode class and assign its address to the temp pointer. Consequently, the value of the left pointer in the node1 will also become equal to the address of the newly created object, as shown in Figure 9.67.

temp -> setVal(10);
```

This will assign 10 to the node, as shown in Figure 9.68.
