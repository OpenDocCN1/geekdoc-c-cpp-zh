
Had the class B in the preceding code contained at least one virtual function, the last statement would have printed class B as desired. Given that class A has a virtual function, what would the following tests evaluate to?

```cpp
typeid(APtr) == typeid("A") //comparing pointers
typeid(*APtr) == typeid(A) //comparing objects pointed at
```

The first of these expressions would return true while the second one would return false. In the first case, the types of, and not the types of the objects being pointed at, are compared. Since '*APtr' is of type 'A*', the first statement returns true. In the second case, the types of the objects being pointed at and not the types of the pointers, are compared. Since '*APtr' is of type B, the second statement returns false.

# Summary

In C++, the library programmer can provide operators with additional capabilities to operate on objects of his/her class. This is known as operator overloading.
Operators can be overloaded by functions whose names composed of the keyword and the symbol of the operator being overloaded. These functions may be member functions or friends. Friend functions are used when the objects of the class for which the operator is overloaded invariably appear on the right-hand side of the operator.
Operators are overloaded to:

- Neutralize the effects of the functions that are generated by default (the 'assignment' operator).
- To make the operation of the operators more efficient (the new and delete operators).
- To provide capabilities to the class so that its objects can be used in predefined templates.

The rules for operator overloading are as follows:
* New operators cannot be created.
* Meaning of existing operators cannot be changed.
* The following operators cannot be overloaded:
  - :: (scope resolution)
  - . (member selection)
  - * (member selection through pointer to member)
  - ?: (conditional operator)
  - sizeof (finding the size of values and types)
  - typeid (finding the type of object pointed at)
* The following operators can be overloaded member functions alone:
  - = (Assignment operator)
  - () (Function operator)
  - [] (Subscripting operator)
  - -> (Pointer-to-member access operator)
* Number of arguments that an existing operator takes cannot be changed.
* basic type to class type (using a constructor),
* class type to basic type (using a type conversion operator), and
* class type to class type (using either a constructor or a type conversion)
* The C++ language provides a new set of operators for typecasting. These operators be be instead of the highly error-prone method of typecasting provided by the C language.

The dynamic_cast operator is used to determine whether a base class pointer points to an object of the base class or one of the derived classes at run time. It is also used to determine whether a base class reference refers to an object of the base class or an object of the derived classes at run.

The static_cast operator serves the same purpose as the typeid operator for implementing typeid (typeid is a keyword in C++). The typeid operator returns the type_information.

In general, if a derived class type and the value to be converted is the dynamic_cast operator returns a pointer to the object. Else, it returns NULL. For the dynamic_cast operator to operate, the base class must be polymorphic in nature, it should have at least one virtual function.

Apart from dynamic_cast operator, C++ provides the typeid operator for implementing typeid (typeid is a keyword in C++). The typeid operator returns the type of the passed value as a reference to an object of class type_info. The class type_info is defined in the header file typeinfo.h.
