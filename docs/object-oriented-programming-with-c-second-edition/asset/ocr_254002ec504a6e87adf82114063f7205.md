# 8.2.1 Overloading Increment and Decrement Operators (Prefix and Postfix)

Let us recollect the class Distance. We can overload the increment operator for objects of
the class. What would we like such a function to do? If ‘d1’ and ‘d2’ are objects of the class
Distance, then the following statement

```
d2 = ++d1;
```

is interpreted by the compiler

```
d2 = d1.operator ++ ();
```
