**Private Class Members** members of a class that have been declared under the private section of a class. private members can be accessed by member functions of the same class.

**static_cast Operator** The difference between the static cast and the dynamic cast operator is that while dynamic cast performs a run-time check to ensure a valid conversion, static cast carries out no such check.

**Procedure-Oriented Programming** In this system, code is divided into procedures. Data and procedures that work upon the data are not bound together.

**Static Binding** (see early binding)

**Protected Class Members** members of a class that have been declared under the protected section of a class. Protected members can be accessed by member functions of the same class and those of the derived class.

**Static Data Member** static data hold global data that is common to all objects of the class. Static data are members of the class and not of any object of the class, they are not contained inside any object.

**Static Function Member** static member functions are not called with an existing object. This function's purpose is to access and/or modify data members of the class.

**Public Class Members** function and data members of a class that have been declared under the public section of a class. Public members can be accessed by not only the member of the class and those of the derived class. They can be accessed by global non-member functions.

**Memory Allocation** In this method of memory allocation, the amount of memory to be allocated and the time at which it would get allocated run-time are both decided during compile itself.

**Pure Virtual Functions** A special type of virtual function whose declaration is specified “=0”. Presence of a pure virtual function makes the class abstract. A derived class must not override the virtual functions of the base becomes an abstract base class. (see abstract class, virtual functions)

**Memory Deallocation** In this method of memory allocation, to be deallocated and the time at which it would get deallocated during run-time are both decided during compile itself.

**Static Polymorphism** (see early binding)

**Queues** are very similar to linked lists. However, in a queue, we can add a node to the end. Moreover, in a queue, we can delete a node from the beginning.

Structure A C language that enables the programmer to put together data that influence others' values and should be put pointer. C++ does not allow the programmer to define member functions inside structures. This lacks of data security.

**Reference Variables** A reference is a reference to another variable. It does not occupy its own memory. It shares the memory copied by the variable of which it is a reference.

**reinterpret_cast** A new operator that allows the conversion of one type to another.

**Subclass** (see child class, derived class, inheritance)

**SuperClass** (see parent class, base class, inheritance)

this pointer A constant pointer that points to each member function as a leading formal argument. It points at the object for which the function is called.

**Scope Resolution Operator** An operator that enables the C++ programmer to define a member function outside the class.

**throw** A keyword in C++ that allows the library programmer to throw an exception whenever an invalid condition is encountered that the library code itself. *(see also exception handling, try, throw)

**Trees**, unlike lists, stacks, and queues, do not have a linear structure. In a tree, each of the nodes may be connected to more than one node.

**try** A keyword in C++ that allows a client to place calls to functions that are likely to throw exceptions. *(see also exception handling, try, throw)

**typedef Operator** An operator that enables us to determine the type of object at which a pointer points.

**Virtual Base** A base class that is derived by using the virtual keyword while declaring the derived class. If a class derives from two classes that in turn inherit from a virtual base class, the final derived class gets only one copy of the features of the virtual base class.

**Virtual Function** A class member function can be declared as a virtual function by prefixing it with the virtual keyword. Virtual functions enable dynamic polymorphism.
