The first conversion by the static_cast operator in Listing 8.70 is correct. 'BPtr' (of type 'Btr') points at 'B1' (of type B).

However, the second conversion by the static_cast operator is incorrect. 'BPtr' (of type 'Btr') points at 'C1' (of type C). Since 'BPtr' is of type 'B*', the member functions of class B alone be called with respect to it.

It is interesting to note what happens when 'BPtr' points at 'C1' and the B::setx(x) function is called for it. The statement

x=2;
