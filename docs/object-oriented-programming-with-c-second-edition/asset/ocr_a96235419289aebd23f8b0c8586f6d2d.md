# Object-Oriented Programming with C++

Programs having inline functions to run faster than equivalent programs with non-inline functions. A function is declared inline either by defining it inside a class or by declaring it outside with the keyword inline. This feature should be used sparingly. Otherwise, the increased size of the executable can slow it down.

Only one copy of a static data member exists for the entire class. This is in contrast to non-static members that exist in *each* object. Static data members are used to keep data that relates to the entire set of objects that exist at any given point during the program's execution. A data member declared as a static member of a class by prefixing its declaration with the keyword static.

Required member functions be declared as const functions to prevent an inadvertent change in the data members. A function can be declared as a constant by specifying its prototype in the header of the function by the keyword const.

Static member functions can access static data members only. Without declaring any objects. A member function declared as a static member of a class by prefixing its declaration in the class by the keyword static.

A mutable data member is never constant. It is modified inline const functions. A friend function is non-member function that has right to access private data members of the class of which it is. This does not really negate the philosophy of OOP. A friend function still needs to be declared inside the class of which it is a friend. The advantage of a friend function is that it is not called with respect to object.

Objects can appear as locals variables inside functions. They can also be passed by value or by reference to functions. Finally, they can be returned by value or by reference from functions.

Arrays of objects can be created. Arrays created inside classes also. One class can be defined inside another class. Such a class is known as a nested class. The class that contains the nested class is known as the enclosing class. Nested classes can be defined in the private, protected or public portions of the enclosing class.

A global non-function can be declared as a friend to a class. Member function of one class can be declared as a friend of another too. A class or a function is declared to a desired class by prototyping it in the class and prefixing the prototype with the keyword friend.

Namespaces enable the C++ programmer to prevent pollution of the global namespace. They help prevent names.
