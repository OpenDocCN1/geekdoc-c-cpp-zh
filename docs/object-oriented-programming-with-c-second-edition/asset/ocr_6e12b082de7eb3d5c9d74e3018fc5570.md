# 7.13 Manipulators

Manipulators are used to format the output. C++ provides some pre-defined manipulators. The programmer can create his own application-specific manipulators. Manipulators can be inserted in an output stream just like values are inserted for output.

```
out << manipulator1 << manipulator2 << value1 << manipulator3 << value2;
```

In this example, out is an object of the class ostream or any of its derived classes. cout can also be used in place of out to format the output to the monitor.

# 7.13.1 Pre-defined Manipulators

C++ provides a number of manipulators that are pre-defined in the header file iomanip.h. Therefore, programs that use these manipulators must include header file. Some of the most commonly used manipulators are listed in Table 7.2.

Table 7.2 Pre-defined Manipulators

| Manipulator | Use |
| --- | --- |
| setw(int w) | Set the field width to w |
| setprecision(int d) | Set the floating point precision to d |
| setfill(int c) | Set the fill character to c |
| setiosflags(long f) | Set the format flag to f |
| resetiosflags(long f) | Clear the flag specified by f |

> The setw() manipulator

The setw() manipulator takes an integer-type variable as its only parameter. This parameter specifies the width of the column within which the next output will be output. If the value that is output is passed in the insertion stream occupies less than bytes than the specified parameter, extra space will be created in the column that will contain the output. It is passed as a parameter to the setfill()平衡 function.
An example snippet follows:

```
cout << 123 << endl;
cout << setw(3) << 10;
```
