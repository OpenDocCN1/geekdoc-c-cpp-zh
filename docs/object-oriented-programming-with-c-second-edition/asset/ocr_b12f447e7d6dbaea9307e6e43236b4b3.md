The foregoing output makes one thing very clear. All non-static member functions in Java are virtual functions. The abstract qualifier is used in the declaration of a member function of the base class only to force its override in the derived class. An overridden member function of the base class can be called from the member function of the derived class by using the keyword super as illustrated in Listing C.9.
