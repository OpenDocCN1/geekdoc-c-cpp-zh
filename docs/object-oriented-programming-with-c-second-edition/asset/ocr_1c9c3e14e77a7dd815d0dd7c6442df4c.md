# Object-Oriented Programming with C++

x=add(10,20,30);
t values of 'a', 'b', and 'c' are 10, 20, and 30, respectively. But, in the second function call
y=add(40,50);

the values of 'a', 'b', and 'c' are 10, 20, and 0, respectively. The default value—zero—for
the third parameter 'c' is taken. This explains the output of the above listing.
Default values can be assigned to more than one argument. Listing 1.26 illustrates this.

# Listing 1.26 Default values for more than one argument

```
/*Beginning of multDefaultArg.cpp*/
#include<iostream.h>
int add(int a,int b=0,int c=0);          //second and third arguments
                                     //have default values
void main() {
    int x,y,z;
    x=add(10,20,30);                    //all default values ignored
    y=add(40,50);                       //default value taken for the
                                        //third argument
                                        //default value taken for
    z=add(60);                          //the second and the third
                                        //arguments
    cout<<x<<endl<<y<<endl<<z<<endl;
}
int add(int a,int b,int c) {
    return(a+b);
}
/*End of multDefaultArg.cpp*/
```

# Output

```
60
90
60
```

There is no need to provide names to the arguments taking default values in the function prototypes.

```
int add(int,int=0,int=0);
```

can be written instead of
int add(int,int b=0,c=0);

Default values must be supplied from the rightmost argument. Before supplying default value to an argument, all arguments to its right must be given default values. Suppose you write
int add(int,int=0,int=0);

you are attempting to give a default value to the second argument from the right without specifying a default value for the argument on its right. The compiler will report an error that (for the third argument).
