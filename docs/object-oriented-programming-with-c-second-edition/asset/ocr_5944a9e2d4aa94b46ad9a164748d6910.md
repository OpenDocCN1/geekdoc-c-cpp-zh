# ## 9.1 Introduction

As mentioned in the overview, data structures are special ways in which pieces of data are arranged and related to each other during run-time. These pieces of data can be integers, character strings, strings, etc. Each piece of data is embedded in a node that contains the piece of data along with one or more pointers that point either at other similar nodes or have null values.

We will soon learn to create such nodes ourselves. Let us first look at the following figure that clearly illustrates two nodes. Each node contains an integer and a pointer. The value of the integer in the first node is 10, and the value of the integer in the second node is 20. The pointer in the first node points to the second node. Let us assume that the address of the second node is 1296. Therefore, the value of the pointer in the first node will be 1296. The pointer in the second node is NULL value. This means that the pointer in the second node is not pointing to any other node. This also means that the second node is the last node in the list (Figure 9.1).
