# 1.7 Reference Variables in C++

First, let us understand the basics. How does the operating system (OS) display the value of variables? How are assignment operations such as 'x=y' executed during run? A detailed answer to these questions is beyond the scope of this book. A brief study is, nevertheless, possible and necessary for a good understanding of reference variables. What follows is a simplified and tailored explanation.

The OS maintains the addresses of each variable as it allocates memory for them during runtime. In order to access the value of a variable, the OS first finds the address of the variable and then transfers to the byte whose address matches that of the variable.

Suppose the following statement is executed ('x' and 'y' are integer type variables).

```cpp
x=y;
```

The following steps are:

- 1. The OS finds the address of 'y'.
- 2. The OS transfers control to the byte whose address matches this address.
- 3. The OS reads the value from the block of four bytes that starts with this byte (most C++ compilers use integer-type variables to occupy four bytes during runtime and will accept this value for our purpose).
- 4. The OS pushes the read value into a temporary stack.
- 5. The OS finds the address of 'x'.
- 6. The OS transfers control to the byte whose address matches this address.
- 7. The OS copies the value from the stack, where it had put earlier, into the block of four bytes that starts with the byte whose address it has found (above 'x').

Notice that addresses of the variables on the left as well as on the right of assignment are determined. However, the value of the right-hand operand is also determined. The expression on the right must be capable of being evaluated to a value. This is an important point and must be borne in mind. It will enable us to understand a number of concepts later.

# Introduction to C++

Especially, you must remember that the expression on the left of the assignment operator must be a valid lvalue. An lvalue is an expression that refers to a memory location, and its value can be assigned to it.

Now, let us study reference variables. A reference variable is nothing but an alias for an existing variable. This means that the reference variable and the original variable share the same memory location. Any change made through the reference variable will also change the original variable. The syntax for declaring a reference variable is as follows:

```cpp
type &reference = variable;
```

For example, if 'x' is an integer-type variable and we want to create a reference to it:

```cpp
int x = 10;
int &ref = x;
ref = 20;
```

In this case, the value of x will be 20 because 'ref' is just another name for 'x'. Reference variables are often used to pass arguments to functions, which avoids the overhead of making copies of large objects.
