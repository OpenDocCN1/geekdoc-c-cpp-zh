# Listing 3.3 Creating an array dynamically when its size is specified during run time

```
/*Beginning of DynArray.cpp*/
#include<iostream.h>
void main()
{
    int * iPtr;
    unsigned int iSize;
    cout<<"Enter the size of the array : ";
    cin>>iSize;
    iPtr = new int[iSize];
    for(int i=0;i<iSize;i++)
        cout<<"Enter the value for element "<<i+1<<" : ";
        cin>>iPtr[i];
    for(int j=0;j<iSize;j++)
        cout<<iPtr[j]<<endl;
    
}
/*End of DynArray2.cpp*/
```

We note that the new operator has enabled us to allocate memory dynamically. In
Listing 3.3, memory is getting allocated during run time (just like in static memory allocation).
However, the amount of memory to be allocated is being decided during run time itself.
Same methodology can be applied for dynamically creating arrays of the other predefined
fundamental data types. Arrays of class objects can also be created dynamically in the same
way. Listing 3.4 is a case in point.
