An object that will store the value of the right-hand side operand of the arithmetic operator will appear in the list of formal arguments. The left-hand side operand will be passed implicitly to the function which the operator-overloading function will be called with respect to it. The statement

```
Obj3 = Obj1 <arithith_op_symbol> Obj2;
```

will be interpreted as

```
Obj3 = Obj1.operator <arithith_op_symbol> (Obj2);
```

If instead a friend function overloads the arithmetic operator, the syntax will be as in Listing 8.18.

+   Listing 8.18 Syntax for overloading the arithmetic operators through friend functions

```
class <class_name>
{
  public:
    //prototype
    friend <return_type>operator<arithith_op_symbol>(<param_list>);
    //definition
    <return_type> operator<arithith_op_symbol>(<param_list>)
    //function body
}
```

Objects that store the values of the left-hand side and the right-hand side operands of the arithmetic operator will appear in the list of formal arguments. The statement

```
Obj3 = Obj1 <arithith_op_symbol> Obj2;
```

will be interpreted as

```
Obj3 = Obj1.operator <arithith_op_symbol> (Obj2);
```

Since, the arithmetic operator has been overloaded by a friend function, the final interpretation will be

```
Obj3 = operator <arithith_op_symbol> (Obj1,Obj2);
```
