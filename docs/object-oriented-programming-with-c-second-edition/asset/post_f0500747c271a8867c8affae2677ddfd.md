# 8.2 Overloading Operators

## 8.2.1 Overloading Increment and Decrement Operators (Prefix and Postfix)

Let us recollect the class Distance. We can overload the increment operator for objects of the class. What would we like such a function to do? If ‘d1’ and ‘d2’ are objects of the class Distance, then the following statement

```cpp
d2 = ++d1;
```

is interpreted by the compiler

```cpp
d2 = d1.operator ++ ();
```

Let us envisage that this operator-overloading function should first increment ‘iFeet’ portion of ‘d1’. It would leave the finches of ‘d1’ unaltered. Then it would return the result object. With these guidelines in mind, the prototype and definition of the operator-overloading function will be as shown in Listing 8.12.

# Listing 8.12 Declaring member function to overload the increment operator

```cpp
/*Beginning of Distance.h*/
class Distance
{
    public:
    /*
    rest of the class Distance
    */
    Distance operator ++ ();
};
/*End of Distance.h*/
/*Beginning of Distance.cpp*/
#include "Distance.h"
Distance Distance :: operator ++ ()
{
    return Distance(+iFeet, fInches);
}
/* definitions of the rest of the functions of class
Distance
*/
/*End of Distance.cpp*/
```

The operator-overloading function should be public because it will mostly be called from functions that are not members of the class Distance. It should not be a constant member function because it would verily modify the value of at least one of the data members (iFeet) of the calling object. Although the definition of the operator-overloading function appears cryptic, it is in fact very simple (and economical). First, the increment operator works (it is in prefix notation). Thus, the iFeet data member of the calling object gets incremented. Second, the explicit call to the constructor creates a nameless object of the class Distance by passing the incremented value of iFeet and the unaltered value of fInches as parameters. Third, the operator-overloading function returns the nameless object constructed. If the call to the operator-overloading function is on the right-hand side of the assignment operator, the value of the returned object will expectedly be copied to the object on the left. Thus, our purpose is served.

However, we would like a different effect to be produced if we write the statement

```cpp
d2 = d++;
```

In this case, the operator-overloading function should return the original value of 'd' before incrementing it. To do this, we must first create a copy of the object, then increment the original object, and finally return the copy. The implementation would look like this:

```cpp
Distance operator ++ (int)
{
    Distance temp = *this;
    iFeet++;
    return temp;
}
```

The `int` parameter is a dummy parameter used to distinguish the postfix operator from the prefix operator. Similarly, the decrement operator would be implemented as:

```cpp
Distance operator -- ()
{
    iFeet--;
    return *this;
}

Distance operator -- (int)
{
    Distance temp = *this;
    iFeet--;
    return temp;
}
```
