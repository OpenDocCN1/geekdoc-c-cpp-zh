# 11.3.4 Accessing the Thrown Object in the Catch Block

If we declare an object of the exception class in the catch handler, then the thrown object gets copied into it. This can be accessed and used for further processing. Listing 11.10 illustrates this.

Listing 11.10 Accessing thrown objects

```
#include<iostream>
#include<math.h>
#include<string.h>

double hmean(double,double);
double gmean(double,double);

class hmeanexp {
    char cError[30];
public:
    hmeanexp(char * s) {
        strcpy(cError,s);
    }
    char * getError() {
        return cError;
    }
}
class gmeanexp {
    char cError[30];
public:
    gmeanexp(char * s) {
        strcpy(cError,s);
    }
    const char * getError() {
        return cError;
    }
}

void main() {
    double x,y,z1,z2;
    char choice='y';
    while(choice=='y') {
        cout<<Enter a number: ";
        cin>>x;
        cout<<Enter another number: ";
        cin>>y;
        try {
            z1=hmean(x,y);
            z2=gmean(x,y);
```
