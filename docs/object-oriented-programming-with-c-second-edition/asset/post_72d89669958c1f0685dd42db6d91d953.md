This function assigns the value of the parameter that is passed to it the next data member. While studying the linked list class, you will realize that the value passed to this function of the node class will be the address of the next node in the list. This should also be obvious from the definition of the parameter pNext. Let us understand these effects with the help of an actual program (Listing 9.6) and figures that illustrate the effects of its statements.

We can see from its definition that the setNext function assigns the value of its parameter to the next data member of the object for which it has called. In the above case, the function has been called for the object at which temp points. The value passed to it as parameter is the value of temp1, which is 320. As result, the value of the next pointer of the object at which temp points is set to 320 and it now points at the freshly created node. Now for the getNext() function.
