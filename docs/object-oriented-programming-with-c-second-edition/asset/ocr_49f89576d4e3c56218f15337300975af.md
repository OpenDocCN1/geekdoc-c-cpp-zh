Another object endl allows us to insert a new line into the output stream. Listing 1.8 illustrates this.

# Listing 1.8 Inserting new line by 'endl'

```
/*Beginning of endl.cpp*/
#include<iostream>
void main() {
    int x,y;
    x=10;
    y=20;
    cout<<x;
    cout<<endl; //inserting a new line by endl
    cout<<y;
}
/*End of endl.cpp*/
```

Output
10
20

A striking feature of the insertion operator is that it works equally well with values of all fundamental types as its right-hand operand. It does not need the format specifiers that are needed in the printf() family of functions. Listing 1.9 exemplifies this.

# Listing 1.9 Outputting data with the insertion operator

```
/*Beginning of cout.cpp*/
#include<iostream>
void main() {
    int iVar;
    char cVar;
    float fVar;
    double dVar;
    char * cPtr;
    iVar=10;
    cVar='x';
    fVar=2.3;
    dVar=3.14159;
    cPtr="Hello World";
    cout<<iVar;
    cout<<endl;
    cout<<cVar;
    cout<<endl;
    cout<<fVar;
    cout<<endl;
    cout<<dVar;
    cout<<endl;
    cout<<cPtr;
    cout<<endl;
}
/*End of cout.cpp*/
```
