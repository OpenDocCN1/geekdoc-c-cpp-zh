The copy constructor has been explicitly defined for the class String so that no two objects of the class String end up sharing the same resource, that is, end up with their contained pointers pointing at the same block of dynamically allocated memory. In this case, two such blocks may contain two copies of the same data as a result of the copy constructor, which is perfectly acceptable. However, there are situations where no two objects should share even copies of the same data.

no objects should share even copies of the same data. If A is a class for whose objects this restriction needs to be applied, then we should ensure that a statement like the second below should not compile.

```

A A2 = A1;
```
