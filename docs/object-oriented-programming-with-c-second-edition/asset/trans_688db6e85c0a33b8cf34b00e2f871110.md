## 4.1.2 参数化构造函数

构造函数接受参数，因此可以进行重载。假设对于 `Distance` 类，库程序员决定在创建对象时，应用程序程序员能够为对象中包含的数据成员传递一些初始值。为了实现这一点，他/她可以创建一个如代码列表 4.5 所示的参数化构造函数。

代码列表 4.5 用户定义的参数化构造函数——通过在栈上创建对象来调用

```cpp
/*Distance.h 的开头*/
class Distance {
    public:
        Distance();      //库程序员提供的原型
        Distance(int, float); //参数化构造函数的原型
    /*
        Distance 类的其余部分
    */
}
```
