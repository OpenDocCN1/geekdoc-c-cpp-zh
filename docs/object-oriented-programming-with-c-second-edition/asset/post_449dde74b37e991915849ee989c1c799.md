# The detailed explanation

Let us go to the while loop. The loop reads the characters from the file one by one. If the first character is neither a punctuation mark nor the new line, we simply add it the string representing a word (second line of the while loop).

```cpp
word=word+cVar;
```

When a punctuation mark or the end of line is encountered,

```cpp
if(cVar==' ' || cVar==',' || cVar==';' || cVar=='\n')
```

we reckon that we have finished a word. We populate an object 'loc' with the line number and word of the word.

```cpp
loc.first=iLineNum;
loc.second=iWordNum;
```

We also increment 'iWordNum' because the position of the next word would be greater than the previous one. For the time being, ignore the test

```cpp
if(flag==0)
```

Since our word map (Step 1) should keep a vector of all positions of each word, we must find whether the word already exists in our word map or not.

```cpp
iter=wordmap.find(word);
```

This statement returns an iterator. If the word is found in any of the first members of the word map, it points to that element first member is the word itself. The word is not found in any of the first members of the word map, the iterator passes its end. If the word is found in any of the first members of the word map,

```cpp
if(iter!=wordmap.end())
```

we append the object 'loc', which we have already populated, to the location vector, which is the second member of the element pointed by the iterator.

```cpp
(iter->second).push_back(loc);
```

If the word is not found in any of the first members of the word map, we populate a temporary vector of locations with only one element—the location object 'loc'.

```cpp
temp.push_back(loc);
```

Next, we insert the word and its location vector into the word map.

```cpp
wordmap[word]=temp;
```

We ensure that the temporary vector of locations remains vacant by writing the following line of code.

```cpp
temp.erase(temp.begin(),temp.end());
```

Next, we decide the contents of the string that is holding the just read word so that the next word can be loaded from the file.

```cpp
word.erase();
```
