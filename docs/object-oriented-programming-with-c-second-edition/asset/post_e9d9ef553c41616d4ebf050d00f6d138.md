## Glossary

Abstract Base Class A class that has at least one pure virtual function. Abstract base classes cannot be instantiated. They only serve as base classes for other classes to derive from (see also virtual functions)

Class Template A template for a class definition. Data type of data members is undefined.

Arrow Operator (->) An operator to access data members of an object or call member functions through a pointer that points at the object.

Clone Functions A function that creates an object of the same type at which a base pointer points and returns its address.

Base Class A class from which another class inherits. (see also inheritance)

Command Line Arguments Command line arguments are values that are passed to executables when they run from the command line.

Binary Search Tree A binary tree is a special form of binary tree. In a binary search tree, any value contained in its left child is less than the value in the node and the value contained in the node is less than the value contained in its right.

const_cast Operator This operator is used to cast the constancy of a variable.

Binary Tree A binary tree in which each node is linked to a maximum of 2 nodes.

Constant Member Functions A member function that can only read the value of data members but not modify them.

Call by Reference The formal argument of the called function is of reference type. (see also reference variables)

Constructor A member function that is called automatically with respect to each object at the time of its creation. It is used to guarantee the initialization of data members of the object. (see also Initialization of Data)

Call by Value The formal argument of the called function is of non-reference type. (see also reference variables)

Copy Constructor A constructor that is called whenever an object is created and simultaneously equated to another object. It is called with respect to the object that is getting while the existing object is passed as a parameter to it.

catch The keyword used to catch an exception. (see also exception handling, try, throw)

Data Member A member variable that would contain the values of class objects. Each object of the class has its own copy of the data member.

Child Class A class that inherits from another class. (see also inheritance)

Data Security An object-oriented feature that refers to preventing unauthorized functions from accessing data.

Class A language construct provided by C++ that enables the implementation of object-oriented concepts like data security, guaranteed initialization of data, data abstraction, hiding, etc. A class has member functions and member data.

Default Constructor The constructor that is defined by default by the compiler if we do not take parameters. (see also Zero-argument Constructor)

Default Values for Function Arguments Default values can be assigned to function arguments. These values are assigned to the arguments if no values are passed when the function is called.

delete An operator that allows us to return a dynamically allocated block of memory to the operating system. (see also dynamic deallocation)

Derived Class (see child class) Destructor A function that gets called automatically for each object at the time of its destruction. It is used to release resources held by objects.

Dot Operator An operator that allows us to access data members of an object or class members with respect to an object.

dynamic_cast A operator used for downcasting a pointer of derived class. If the class pointer typically points as an object of the target, the dynamic cast returns the address of the object pointed at, it returns NULL. The dynamic cast is used instead of pointers, it returns the reference to the target or throws an exception of the type bad_cast.

Dynamic Binding In dynamic binding, if an overridden function of the base class is called with respect to a pointer or a reference of the base class type, then which of the functions (base class function or one of the derived classes) will be called, based on the type of the object pointed or referred to at runtime. The same function has more than one (in the base class and the derived classes). This can lead to the execution of a particular version depending upon circumstances arising during runtime.

Dynamic Memory Allocation In this type of memory allocation, more memory is allocated in response to requirements arising during runtime.

Dynamic Memory Deallocation Once it is not required, memory allocated dynamically can be returned to the operating system. This is dynamic memory deallocation.

Dynamic Polymorphism (see dynamic binding) Early Binding In early binding version of a called function that has multiple forms will be called at compile time instead of runtime.

Enclosing Class A class that contains the definition of another class is known as an enclosing class. (see nested class)

Exception Handling Exception handling is a library to notify error conditions, which is incapable of handling, to the calling client. The client can catch the exception and decide upon a suitable error-handling strategy. Alternatively, the client may choose to re-throw exceptions. (see also catch, try)

Explicit Constructor Explicit constructors do not allow implicit conversion when an object is instantiated. Constructors are declared by explicitly prefixing their declarations with the explicit keyword. We need to mention the explicit keyword in the declaration of the constructor only. It is not necessary to prefix the definition with the explicit keyword. Explicit constructors prove to be useful for the programmer if/she is creating a class for which an implicit conversion by the constructor is undesirable.

Friend Function A non-member function that has been granted rights to access private data members of the class of which it has been declared friend.

Friend Class A class whose entire set of members has been granted special rights to access private data members of the class of which it has been declared friend.

Function Member A function that is a member of a class. It is declared within the class. It has the right to access the private members of all objects of the class.

Function Overloading A facility that enables the programmer to create two functions with the same name.

Function Template A template for a function definition. The type of arguments is undefined. An actual definition of the function gets generated only when the function is called.

Guaranteed Initialization of Data The members of a variable may attain invalid values at its time of creation. C++ enables guaranteed initialization of data by defining constructors. (see also constructor)

new Operator An operator that enables us to capture memory in response to conditions arising during runtime (see also dynamic memory allocation)

Inheritance A feature provided by object-oriented languages that allows a class to inherit the data and members of an existing class. (see also base class, parent class, super class, derived class, subclass)

New Styles C++ provides the following new cast operators to replace the old error-prone and difficult-to-detect class styles:

- dynamic_cast
- static_cast
- reinterpret_cast
- const_cast

Inline Function A function that is expanded in its call by the compiler.

Late Binding (see dynamic binding)

Linked Lists List consists of nodes that are linked to each other in a linear fashion. Each node in a linked list is an object that is made of two parts. The first part is the data carried by the node. The second part of each node is a pointer that carries the address of the next node in the list. This is a description of a single linked list. Alternatively, each node may have an additional pointer for double linked lists.

Object An instance of a class is known as an object.

Object-Oriented Programming System A system that enables programmers to model real-world objects. Data and procedures work together in a single class instance.

Manipulators are operators that enable the C++ programmer to format the output from their programs.

Operator Overloading A feature of object-oriented languages allows programmers to provide definitions to operators so they can take class objects as operands.

Multiple Inheritance A type of inheritance where a class inherits the features of more than one base class.
