接下来是 `setNext()` 函数。

```cpp
/*
该函数设置下一个指针（next）的值。
*/
void SingleLinkedListNode::setNext(SingleLinkedListNode * pNext)
{
    /*
    将下一个指针的值设置为传入
    参数的值。
    */
    next = pNext;
}
```

该函数将传递的参数值赋值给它的 `next` 数据成员变量。在学习链表类时，你会发现传递给节点类该函数的数值将是列表中下一个节点的地址。从参数 `pNext` 的定义中也可以显而易见地看出这一点。让我们通过实际程序（列表 9.6）和说明其语句效果的图表来理解这些影响。
