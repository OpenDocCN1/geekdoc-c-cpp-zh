In the introduction of this chapter, we had realized that an ideal solution to the problem of handling runtime-errors should allow the library to sense and dispatch errors, and the application to trap the dispatched error and take appropriate action. The exception-handling mechanism of C++ meets this requirement perfectly.

In order to appreciate the superiority of exception handling over the C-style solutions, we should follow the following things in mind:

+   * It is necessary to catch an exception if it is thrown.
* When an exception is thrown, the stack is unwound.
