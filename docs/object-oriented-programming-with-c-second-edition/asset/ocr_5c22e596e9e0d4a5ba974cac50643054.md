# Summary

C++ allows a class to be defined in such a way that it automatically includes member data and member functions of an existing class. As usual, it allows additional member data and member functions to be defined in the new class also. This is called inheritance.

The existing class whose features are being inherited is known as the base class or parent or super class. The new class that is defined by inheriting from the base class is known as the derived class or child or subclass.

Objects of the derived class contain data members of the derived class as the base class. Objects of the base class can call member functions of the derived class as those of the base class.

By only allowing the common data and common member functions in the base class, inheritance enables reuse and code maintenance. Inheritance implements an 'is-a' relationship whereas containmentship implements a 'has-a' relationship. Friendship is not inherited.

A base class pointer can point at an object of the derived class. A derived class pointer cannot point at an object of the base class.

Member functions of the base class can be overridden in the derived class. Defining a member function in the derived class in such a manner that its name and signature match those of a base function is known as overriding.

Base class members can be initialized to values that are passed to the constructor of the derived class. These values can be passed to the base class constructor.

Protected members are inaccessible to member functions. But they are accessible to the member functions of their own class and to member functions of the derived classes.

Classes are derived by the public, protected, and private keywords. Deriving by the public access

specifier retains the access level of base classes. Deriving from the protected access specifier reduces the access level of public base class members to protected while the access level of protected and private base members remains unchanged. Deriving by the private access specifier reduces the access level of public and protected base class members to private while access level of base class members remains unchanged. The default access specifier for inheritance is 'private'.

In inheritance, a class derives from more than one class. Multiple inheritance leads to a number of ambiguities. Ambiguity arises if or more of the base classes have a member of the same name. Ambiguity can also arise if two or more classes inherit from a common base class. This is known as diamond-shaped inheritance. These ambiguities are resolved by the following:

+   - Using the scope resolution operator and passing the name of the actual class to call the function in the intermediate base class
- Overriding the function of the ultimate base class
- Deriving the intermediate base classes using the virtual keyword

When a class inherits from a derived class, it is known as multi-inheritance. In hierarchical inheritance, a single class serves as a base for multiple derived(s). Hybrid inheritance is a mixture of the above kinds of inheritance.

Constructors are invoked in the following order:

+   - Virtual base class constructors in the order of inheritance
- Normal base class constructors in the order of inheritance
- Member objects' constructors in the order of declaration
- Derived class constructor

Destructors are invoked in the reverse order.

# Key Terms

+   - base class, parent class, super class

- function members of base class and objects of the derived class
