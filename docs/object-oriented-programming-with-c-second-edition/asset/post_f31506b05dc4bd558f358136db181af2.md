# 9 Data Structures

## OVERVIEW
These data structures are very useful in the world of programming. They are nothing-special ways in which various pieces of data are arranged and related to each other during run time. We are already familiar with one data structure—arrays. However, arrays have various limitations.

You can create data structures like lists, trees, etc. Lists are a superior substitute for arrays. Data structures are used to solve a number of programming problems. They can be created using various programming languages, including C++. This chapter explains the most important data structures—linked lists and trees. It also includes full fledged programs that can be used to create data structures.

## 9.1 Introduction

As mentioned in the overview, data structures are special ways in which pieces of data are arranged and related to each other during run-time. These pieces of data can be integers, character strings, strings, etc. Each piece of data is embedded in a node that contains the piece of data along with one or more pointers that point either at other similar nodes or have null values.

We will soon learn to create such nodes ourselves. Let us first look at the following figure that clearly illustrates two nodes. Each node contains an integer and a pointer. The value of the integer in the first node is 10, and the value of the integer in the second node is 20. The pointer in the first node points to the second node. Let us assume that the address of the second node is 1296. Therefore, the value of the pointer in the first node will be 1296. The pointer in the second node is NULL value. This means that the pointer in the second node is not pointing to any other node. This also means that the second node is the last node in the list (Figure 9.1).

We are already familiar with one data structure—arrays. However, arrays have the limitation that their size cannot be modified during run time. Whatever the programmer specifies for the size of the array, the user of the program may find that the size is fixed during run time. Conversely, the user may find that the size of the array is not enough to hold the number of elements that he/she needs to create. Also, we cannot easily insert a new element at the beginning or in the middle of the array. Linked lists (a type of data structure) are a good substitute for arrays. They do not have the above limitations of arrays. One element of the array is followed by only one element. But Trees (another type of data structure) enable us to link one element to more. Again, just like linked lists, data structures can be used to solve a number of programming problems like database engineering. They can be created using C++, utilizing classes, functions, pointers, and delete operators.

## 9.2 Linked Lists

Linked lists are data structures. They consist of nodes that are linked to each other in a linear fashion. Each node in a list is an object that is made up of two parts. The first part is data carried by the node. The second part of node is a pointer that carries the address of the next node in the list. This is how a node is linked to the node. Each node in a list is linked to exactly one node (Note that we are talking about linked lists. We also have double linked lists where one node is connected to two nodes–the next node in the list and the previous node in the list). 9.2 illustrates a sample structure of a single list.

This figure shows that each of the four nodes represents a node and the address of each node has been mentioned above. The address of the first node is 6327, that of the second node is 9243, that of the third node is 743, and that of the last node is 8138. Let us ignore the node labelled head for the time being. In this specific case, each node carries data as the data. But we can embed any type of data. The data carried by the first node is 4527, that by the second node is 55, that by the third node is 3281, and by the last node is 21629. As we know, the second part of each node is a pointer that carries the address of the next node in the list. the address stored inside the first node is 9243 (which is the address of the second node), the address stored inside the second node is 743 (which is the address of the third node), and the address stored inside the third node is 8138 (which is the address of the fourth node). The address stored inside the fourth node is NULL (which indicates that it is not connected to any other node and is therefore the last node). We also need to store the address of the first node. This is where the head pointer comes into play. It stores the address of the first node (6327 in this case).
