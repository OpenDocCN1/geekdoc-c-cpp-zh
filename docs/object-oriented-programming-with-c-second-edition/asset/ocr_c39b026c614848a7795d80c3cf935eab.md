# Listing 1.14 Cascading the extraction operator

```
/*Beginning of cinCascade.cpp*/
#include<iostream.h>
void main ()
{
int x,y;
cout<<"Enter two numbers\n";
cin>>x>>y; //cascade the extraction operator
cout<<"You entered: "<<x<<" "<<y;
}
/*End of cinCascade.cpp*/
```

# Output

Enter two numbers
10<enter>
20<enter>
You entered 10 and 20

It was mentioned in the beginning of this section that cin is an object that is associated with the console. Hence, if it is the left-hand side operand of the extraction operator, on the right gets its value from the keyboard. You will learn in the chapter on stream handling that it is possible to pass objects of some other classes that are similarly associated with disk files as the left-hand side operand to the extraction operator. In such cases, the variable on the right gets its value from the associated files.
