# Object-Oriented Programming with C++

Default Values for Function Arguments Default values can be assigned to function arguments. These values are assigned to the arguments if no values are passed when the function is called.

delete An operator that allows us to return a dynamically allocated block of memory to the operating system. (see also dynamic deallocation)

Derived Class (see child class) Destructor A function that gets called automatically for each object at the time of its destruction. It is used to release resources held objects.

Dot Operator An operator that allows us to access data members of an object or class members with respect to an object. dynamic_cast A operator used for downcasting a pointer of derived class. If the class pointer typically points as an object of the target, the dynamic cast returns the address of the object pointed at, it returns NULL. The dynamic cast is used instead of pointers, it returns the reference to the target or throws an exception of the type Bad cast.

Dynamic Binding In dynamic binding, if an overridden function of the base class is called with respect to a pointer or a reference of the base class type, then which of the functions (base class function or one of the derived classes) will be called, based on the type of the object pointed or referred to runtime. The same function has more than one (in the base class and the derived classes). This can lead to the execution of a particular version depending upon circumstances arising during runtime.

Dynamic Memory Allocation In this type of memory allocation, more memory is allocated in response to requirements arising during run

Dynamic Memory Deallocation Once it is not required, memory allocated dynamically can be retuned to the operating system. This is dynamic memory deallocation.

Dynamic Polymorphism (see dynamic binding) Early Binding In early binding version of a called function that has multiple forms will be called at runtime during compile time.

Enclosing Class A class that contains the definition of another class is known as an enclosing class. (see nested class)

Exception Handling Exception handling is a library to notify error conditions, which is incapable of handling, to the calling client. The client can catch the exception and decide upon a suitable error-handling strategy. Alternatively, the client may choose to re-throw exceptions. (see also catch, try)

Explicit Constructor Explicit constructors do not allow implicit conversion when an object is instantiated. Constructors are declared by explicitly prefix their declarations with the explicit keyword. We to mention the explicit keyword in the declaration of the constructor only. It is not necessary to prefix the definition with the explicit keyword. Explicit constructors prove be useful for the programmer if/she is creating a class for which an implicit conversion by the constructor is undesirable.

Friend Function A non-member function that has been granted rights to access private data members of the class of which it has been declared friend.

Friend Class A class whose entire set of members has been granted special rights to access private data members of the class of which it has been declared friend.

Function Member A function that is a member of a class. It is declared within the class. It has the right to access the private members of all objects of the class.

Function Overloading A facility that enables the programmer to create two functions with the same name.
