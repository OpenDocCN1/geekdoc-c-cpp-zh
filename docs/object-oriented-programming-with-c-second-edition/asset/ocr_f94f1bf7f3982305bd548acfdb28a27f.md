# ### 5.7.4 Hierarchical Inheritance

In hierarchical inheritance, a single class serves as a base class for more than one derived class. Figure 5.9 illustrates this.

In Figure 5.9, class A is the common base for classes B and C. This is demonstrated in Listing 5.32.

#include<iostream>

    public:
