The delEnd() function has been called after the second call to the prependNode() function. We already know that the test expression in the outer if block inside the delEnd() function will return true. However, the test expression in the inner block, which calls the getNext() via the head pointer, will return false. This is because the next pointer of the node at which the head pointer points is NULL. Its value is 7912. It points to the second node. Therefore, the else block will execute.

The first statement in the else block declares a temporary pointer iter. The second statement calls a for loop that does not have a body (there is a semicolon at the end of the statement). The initialization statement of the for loop copies the value of the head pointer to iter (Figure 9.54).

![](bbox=[0.29, 0.526, 0.77, 0.706])

**Figure 9.54** A temporary iterator pointing at the first node

Now, look carefully at the test expression of the for loop. The iter -> getNext() returns a pointer to the second node. The chained call to the getNext() function returns the value of the second node's next pointer. As be seen from Figure 9.54, this value is NULL. The test expression returns false and the loop breaks.

The next statement calls the getNext() function via iter. It passes the value returned by this call, as a parameter to the delete operator. However, this call to the getNext() function returns a pointer to the second node. Therefore, the delete operator gets called on the second node. This causes the memory occupied by the second node to get returned to the operating system.
