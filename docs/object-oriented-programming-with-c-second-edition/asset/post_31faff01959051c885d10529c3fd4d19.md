Class objects are always references. Listing C.2 illustrates this.

Listing C.2 Class objects are passed by reference

```java
class A {
    public int x; //public member
}
class first {
    public static void main(String args[]) {
        A A1 = new A(); //necessary to initialize since A1
                        //is only a reference // now A1 is
                        //a reference to a memory location
        A1.x=100;
        A A2;
        A2=A1; //A2 is also a reference to the
               //memory location to which A1 is a
               //reference
        //outputting to the console
        System.out.println("Before changing:");
        System.out.println("A1.x=" + A1.x + ",A2.x=" + A2.x);
        A1.x=200; //A1 changed, A2.x changed
        System.out.println("After changing:");
        System.out.println("A1.x=" + A1.x + ",A2.x=" + A2.x);
    }
}
```

Output
Before changing:
A1=100,A2.x=100
After changing:
A1=200,A2.x=200

- **Garbage collection**: Unlike C++, where dynamically acquired memory must be explicitly returned to the OS, garbage collection is automatic in Java. During the execution of a Java program, an automatic garbage collector runs in the background. If it finds any locked memory that is no longer being referenced, it returns it to the OS.
- **Destructor**: There is no delete keyword in Java. Therefore, there are no destructors in Java.

In Java, the programmer can simply create an object by using the new operator. There is no need to worry about reclaiming the memory, that is the garbage collector's responsibility.

The `finalize()` method in Java approximates the destructor's behaviour. However, there is a difference. The garbage collector will definitely execute this method for an object that it is destroying. The exact instance at which the garbage collector would destroy is not specified.

- **Terminating class definitions, access specifiers, defining member functions**: Class definitions are defined by semicolon in C++. In Java, class definitions are not terminated by a semicolon.

In C++, access specifiers are specified for a group of class members. In Java, access specifiers are specified for each individual class member separately.

Class member functions may be defined outside the class in C++. In Java, class member functions are defined inside the class.

Unlike C++, access specifiers can be specified for classes in Java. A class prefixed with the keyword public is visible to classes outside the package in which it was created. Otherwise, it is visible to classes of the same package.

Consider the class given in Listing C.3 in C++.

## Listing C.3 Access specifiers provided to individual members in Java

```cpp
class A
{
    private:
        int x;
    public:
        void setx(int);
        int getx();
}

public class A
{
    private int x;
    public void setx(int p)
    {
        x=p;
    }
    public int getx()
    {
        return x;
    }
}
```

Apart from private, protected, and public access specifiers, which are also provided by C++, Java provides the package access specifier makes a member or a class to which it is applied visible to other classes of the same package only. It is the default access specifier. The functionality of this specifier is similar to that of namespaces in C++.

- **Enumerations**: Java does not support enum keyword, an enumerated type can be created in Java as a class that has only final data (Listing C.4).

## Listing C.4 Specifying and using enumerated types in Java

```java
//creating an enumerated type
public class Color
{
    static final int red=1;
    static final int blue=2;
    static final int green=3;
    static final int yellow=4;
    static final int brown=5;
}
```

In C and C++, while using values of enumerated types, we need not qualify them by the name of the enumerated type. This drawback does not exist in Java as the value of enumerated type is qualified by the name of the enumerated type itself.

- **The keyword**: This provides provides same functionality in Java as it does in C++ with the difference that in C++ it is pointer whereas in Java it is reference. Therefore this need not be dereferenced in Java (Listing C.5).

## Listing C.5 this is a reference in Java

```java
class A
{
    private int x;
    void setx(int x) { this.x=x; }
}
```

In the above example, this was used to resolve name ambiguity. The name of the member variable of class A is the same as that of the formal argument of setx(). Using this keyword resolves this ambiguity and the value of the member variable gets that of the formal argument.

- **The syntax of inheritance**: Java provides extends keyword for declaring a derived class. This can be used as follows:

```java
//class B inherits from A
class B extends A {}
```

- **The default base class in Java**: If you do not specify a base class for a class you are defining, the Java compiler assigns a class called Object as its base class. Therefore all classes in Java inherit from the class Object.
- **Overriding member functions of a base class**: Using final keyword in the declaration of the member function of a class prevents the derived class from overriding it. The compiler throws an error if a member function of the derived class overrides a final method of the base class.
- **Interfaces and abstract base classes**: An interface in Java is similar to the abstract class in C++ with the following differences:
    - Member functions of an interface can only be declared. They cannot be defined.
    - Member data of an interface are considered final.

An interface is declared in Java as follows:

```java
public interface A {
    void abc();           //declaration only - no definition
    void def();          //declaration only - no definition
}
```

Like the abstract classes of C++, interfaces in Java cannot be instantiated. A a = new A();

A class that implements an interface can be instantiated provided it defines all member functions of the interface. See Listing C.6.

## Listing C.6 Declaring and implementing an interface in Java

```java
public class B implements A      //syntax for implementing the interface
    public void abc() {
        /*
        definition of the function
        */
}
```

If not all member functions of the interface are defined in the class that implements them, the class becomes an abstract base class and cannot be instantiated.

Multiple inheritance is not supported in Java. However, Java provides interfaces. A class in Java can inherit from only one class but implement an unlimited number of interfaces. In the following definition, class X inherits from class P but implements the interfaces A and B.

```java
//implementing more than one interface
public class X extends P implements A, B {
    /*
    definition of class X
    */
}
```

# 434 Object-Oriented Programming with C++

An abstract class is declared in C++ by declaring at least one of its member functions as a pure virtual function. An abstract class is declared in Java by the abstract keyword in its declaration. As in C++, an abstract class cannot be instantiated. See Listing C.7.

## Listing C.7 An abstract class in Java

```java
public abstract class A
//an abstract class
{
    public abstract void abc();
    //an abstract method
    //an abstract class
    public void def(){
    //an non-abstract method
    //of an abstract class
    /*
    definition of the function
    */
}
```

As seen, some functions of an abstract class can be declared abstract by using the abstract keyword in their declaration while the others can be declared as non-abstract by not using the abstract keyword in their declaration. In contrast to interfaces, member functions of an abstract class can be defined. If not all members of an abstract class are defined in the class that extends it, the latter class also becomes an abstract base class and cannot be instantiated.

Abstract and non-abstract member functions of the abstract base class can be overridden in the derived class. See Listing C.8.

## Listing C.8 Overriding base class functions in the derived class

```java
abstract class A
{
    public abstract void abc();
    public void def()
    {
        System.out.println("def() function of class A");
    }
}
public class B extends A
{
    public void abc()
        //overriding abstract function of
        //base class
    {
        System.out.println("abc() function of class B");
    }
    public void def()
        //overriding non-abstract function
        //of base class
    {
        System.out.println("def() function of class B");
    }
    public static void main(String args[])
    {
        A A1 = new B();
        A1.abc();
    }
}
```
