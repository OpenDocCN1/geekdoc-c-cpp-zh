# Stream and File Handling

File pointers can be explicitly manipulated by the use of some functions that have been provided as members of the stream handling classes. An explanation of these functions follows.

# 7.9.1 seekp() Function

This function is used to explicitly make the put pointer at a desired position in the open file. It is important to note that by default the put pointers are at the beginning of the file if it is newly opened for writing. In case an existing file is opened for appending, the put pointer points to its end by default. Also, every write operation pushes the put pointer by the number of bytes written.

The seekp() function has been defined in the class stream. It has two versions:

```
ostream & ostream :: seekp(streampos pos);
ostream & ostream :: seekp(streamoff off,
                               ios::seek_dir dir);
```

In the first version, the seekp() function takes only one parameter—the absolute position with respect to the beginning of the file. The type streams is defined with long as the source data type. We must remember that the numbering of the position starts from zero. In this example, the put pointer is made to point at the second byte of the file:

```
ofile.seekp(1); //ofile is an object of class ostream
```

In the first version, the new position of the put pointer can be specified with respect to the beginning of the file only. But in the second version, the seekp() function takes two parameters—the first parameter is the offset and the second parameter is the position in the open file with respect to which the offset being specified. The type streamoff is defined with long as the source data type. The type ios::seek_dir is an enumerated type with the following values:

```
ios::off—offset will be calculated from the beginning of the file
ios::cur—offset will be calculated from the current position in the file
ios::end—offset will be calculated from the end of the file
```

In the following example, the put pointer is made to point at the last byte of the file. We must remember that the EOF character is the last byte of the file. Thus, in the following example, the put pointer will end pointing at the last byte that was written into the file that is one by the last of EOF character.

```
ofile.seekp(-1,ios::end); //ofile is an object of class
//fstream
```

Some more examples follow:

```
ofile.seekp(0,ios::beg); //take the put pointer to the
//beginning of the file
of.seekp(2,ios::beg); //take the put pointer to the
//third byte from the beginning
//of the file
of.seekp(-2,ios::cur); //take the put pointer two
//bytes to the left from its it
//current position in the file
of.seekp(2,ios::cur); //take the put pointer bytes
```
