When the new operator is used, the OS blocks a block of memory of the requested size. The OS never allocates this block of memory in response to subsequent requests for memory blocks as long as this block of memory is not deallocated. When the delete operator is used on the pointer that points to this block of memory, the memory gets deallocated, that is, free and made available for the OS. In other words, the OS, in subsequent requests for memory blocks, may allocate this free block of memory.

A dynamically allocated block of memory remaining locked is quite a blessing. The fact that the block of memory locked by the code in a function persists even after the function terminates is fairly desirable. A called function may allocate a memory block and a pointer to the calling function can be made to point at it.
