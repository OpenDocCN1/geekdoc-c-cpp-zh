# Summary

Constructors can be used to guarantee a proper initialization of data members of a class. Domain constraints on values of data members can be implemented via constructors.

If destructors can be used to guarantee a proper clean up when an object goes out of scope. Destructors are member functions and have the same name as that of the class but with the tilde prefix. The compiler creates a destructor if we do not define one. Destructors do not take parameters and cannot be overloaded. do not return anything (not void). The compiler implicitly embeds a call to the destructor for each object going out of scope (for being destroyed). An explicit call to the destructor for an existing object is forbidden.

Constructors are member functions and have the same name as that of the class. The compiler creates a zero-argument constructor and a copy constructor if we do not define. Constructors take parameters and, therefore, can be overloaded. do not return anything (not void). The compiler implicitly embeds a call to the constructor for each object that is being created. An explicit call to the constructor for an existing object is forbidden.
