# Object-Oriented Programming with C++

# Summary

Streams are nothing but a flow of data to from program variables. Input stream is the flow of data from a file on the permanent storage medium to program variables. The keyboard is also treated as source of input stream. Output stream is the flow of data to a file on the permanent storage medium from program variables. The monitor is also treated as target for output streams.

C++ provides us with a hierarchy of classes to implement various aspects of stream handling. The class ios is the base class in this hierarchy.

The class ostream is derived from the class and handles the general output. The operator (<<) is derived and overloaded in the class stream to handle output streams from program variables to output.

The class ostream_withassign is derived from the class ostream. cout is an object of the class ostream which stands for console output. As mentioned earlier, C++ treats all peripheral devices as streams. It treats nothing but a file (for input) streams. The object cout monitors the screen.

The class istream is derived from the class ios and handles the general input streams. The extraction operator (>>) is defined and overloaded in the class stream to handle input streams from files to program variables.

The class istream_withassign is derived from the class cin. cin is an object of the class istream_withassign. cin stands for console input. C++ treats all peripheral devices as. It treats the keyboard also as a file (for input). The object cin represents the keyboard.

The class ios is derived by multiple inheritance from the classes istream and ostream. It has the functionality to handle both input and output streams. The class ofstream is derived from the class stream. It has the functionality to handle output streams to disks. The class fstream is derived from the class istream. It has the functionality to handle both input and output streams from files to disks.

In text mode, numeric data that exists in base 2 format in the memory variables, is first converted to base 10 before being output. In binary mode, no such conversion exists.

In text mode input, numeric data that is being input into a memory variable is reckoned to be in base 10 format. Therefore, it is first converted into base 2 format and then stored in the target variable.

The insertion operator is used to output in text mode. The put() function is used to output a single character at a time. The get() function is used to use in data to input a single character at a time.

The write() function is used to output in binary mode. The read() function is used to input data in binary.

Apart from the constructors of the library classes, the open() function can also be used to open files. The first parameter of the constructor and the open() function is the name of the file. The second parameter specifies the mode. Destructors of stream classes close the files associated with any. The close() function can be used to explicitly close files.

Files can be moved by the seek() and seek() functions. Their current positions are determined by the tell(). An intermediate record can be directly accessed by the seeking() or seek() function to make the file pointer jump to a specific byte in the file. It is necessary for member functions for outputting and inputting data of complex cases.

Every object of the istream, or of a class that is derived from either of these classes, contains three flags that indicate the state of the next file. These flags are:

+   - eof becomes true if the file is end of input (the ebit flag).

+   - fail becomes true if the read/write operation fails. The fail() function returns the state of the failbit flag.

+   - bad becomes true if the file is being corrupt during recovery (the bad()) function returns the state of the badbit flag).

The clear() function is used to clear the bits described. C++ provides several pre-defined manipulators. The programmer can create his own application-specific manipulators.
