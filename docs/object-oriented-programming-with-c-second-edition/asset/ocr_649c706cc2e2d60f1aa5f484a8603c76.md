# 8.4 New Style Casts and the typeid Operator

C++ provides a new set of operators for typecasting. These operators can be used instead of the highly error-prone method of typecasting provided by the C language. An example of the traditional method of typecasting was mentioned in the section ‘Explicit address manipulation’ in Chapter 2.

New style casts are safe to use and can be easily located in source codes by using the search facility of the editor where the source code has been opened. The latter benefit is especially useful in large source codes.

Ideally, a program should not need casts at all. However, there are various programming patterns where they are necessary. In order to meet this new, new style casts should be used instead of the old style.

There are four new style casts:

+   * dynamic_cast
* static_cast
* reinterpret_cast
* const_cast

Each of these operators converts the object, which is passed to it as an operand, in a pre-defined way and returns the converted object. The general syntax of these operators is:

> operator <type>(value whose type is to be converted)

The typeid operator is similar to the dynamic_cast operator.

# 8.4.1 dynamic_cast Operator

Run time type information (RTTI) enables us to find the type of a value and to compare the two types of values. C++ provides dynamic_cast operator and the typeid operator for implementing RTTI.

The dynamic_cast operator is used to determine whether a particular class pointer points at an object of the base class or one of the derived classes at time. It is also used to determine whether a base class reference to an object of the base class or an object of one of the derived classes at run time.

We know from Chapter 5 that a base class pointer can point at an object of the derived class while a base class pointer cannot point at an object of the base class.

Let A be a base class and B be its derived class.

```
A A1, * Aptr;
B B1, * Bptr;
Aptr=&B1; // line 1: OK: Can convert from B* to A*
Bptr=&A1; // line 2: ERROR: Cannot convert from A* to B*
// line 3: ERROR: Cannot convert from A* to B*
```
