# Listing 8.13 Overloading the increment operator in both the prefix and the postfix notation

```

class Distance {
```

The explanation for the definition of the function to overload the increment operator in postfix notation is as follows. The constructor gets called before the increment operator executes because the increment operator has been purposely placed in postfix notation. Thus, a nameless object with the initial values of the calling object is created. Thereafter, the increment operator returns the value of iFeet data and the values of the calling object is returned.
