One possible way of using this function is by using a loop to obtain a string from the user, which can be of any length. While writing the program, the application programmer need not predict the length of the string user will enter. The following code can be used for adding a character to a stretchable string in the object-oriented way.

```
while(1) //potentially infinite loop
{
    getch(); //if user finishes entering the string
    if(ch=='\n') //break the loop
        break; //else append the character to it
    s1.addChar(ch);
}
```
