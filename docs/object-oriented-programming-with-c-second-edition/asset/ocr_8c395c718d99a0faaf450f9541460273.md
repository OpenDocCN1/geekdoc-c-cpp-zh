Functions with no formal arguments

In C, it is reckoned that a function that has no formal arguments accepts an unspecified number
of parameters. Therefore, it is legal to pass parameters to it.

In C++, it is reckoned that a function that has no formal arguments does not accept
parameters. Therefore, it is illegal to pass parameters to it.
