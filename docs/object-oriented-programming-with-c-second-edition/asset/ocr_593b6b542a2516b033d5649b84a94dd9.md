The class stream is derived from the class ios and handles the general input streams. The extraction operator (>>) is defined and overloaded in the class istream to handle inputs from input to program variables.

The class istream_withassign is derived from the class cin. cin is an object of the class istream_withassign stands for console input. C++ treats all peripheral devices as files. It treats the keyboard also as a file (for input stream). The object cin represents the keyboard.
The statement translates as:
cin>>;

“Extract the stream from the file (which is nothing but the keyboard) and place it in the program variable 'x'.
The class iostream is derived by multiple inheritance from the classes istream and ostream. It has the functionality to handle both input and output streams.
The class ofstream is derived from the class ostream. It has the functionality to handle output streams to disks. Objects of the class ofstream represent output files on the disk. Thus, the following piece of code opens a disk file for output (note that the name of the file to be opened is passed as a string to the constructor of the class):
ofstream file("first.dat");

The file first.dat is opened for output in the directory where the executable will run. The entire path of file to be opened can be prefixed to the name of the file. Since the insertion operator is defined in the base class of the class ofstream, the object ofile is passed as the left-hand side operand instead of cout.
