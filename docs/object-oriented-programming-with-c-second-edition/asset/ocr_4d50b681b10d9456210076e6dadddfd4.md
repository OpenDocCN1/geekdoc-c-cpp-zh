# *Recursive Nature of Binary Trees*

If you look closely, you will observe that binary trees have recursive structures. The entire tree has a root, a left sub-tree, and a right sub-tree. Both of the sub-trees are themselves. Both of them have roots and sub-trees.

While programming functions that model operations on trees, we can exploit recursive nature of trees and make them recursive too. This will make the functions shorter and reduce our programming effort. You will understand while studying these functions.
