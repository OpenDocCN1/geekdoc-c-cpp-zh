Contrast objects of the class StrPtr with ordinary pointers that point at objects of the class String. In case of ordinary pointers, there is no guarantee that the pointer being is pointing at a valid block of memory.

```
void f1(String * p)
{
    p->setString("abc"); //No way to check the validity of p
}
```

On the other hand, an attempt to partially initialize an object of the class StrPtr results in a compile-time error.

```
StrPtr p;
//ERROR: no zero-argument constructor
```

Therefore, in case of smart pointers, there is a guarantee that the pointer being used is pointing at a valid block of memory.

```
void f1(StrPtr p)
{
    p->setString("abc"); //p is definitely valid
}
```
