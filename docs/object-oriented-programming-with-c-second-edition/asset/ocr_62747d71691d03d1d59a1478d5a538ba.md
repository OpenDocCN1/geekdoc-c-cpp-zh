It can be observed that an error is produced when a direct access is made to a member of the enclosing class through a function of the nested class. This is as it should. After all, creation of an object of the nested class does not cause an object of the enclosing class to be created. The classes are nested merely to control the visibility. `A::B::BTest()` function will be called with respect to object of class B, a direct access to a member of the enclosing class can be made through an object of that class.

By default, the enclosing class and the nested class do not have access rights to each other’s private data members. They can do so if they are friends to each other.

# Summary

Classes have both member data and member functions. Member functions can have exclusive rights to access data members. Member functions and member data can be private, protected, or public. The struct keyword has been redefined in C++. Apart from member data, structures in C++ can have member functions also. In a class, members are public by default.

The scope resolution operator is used to separate the class definition from the definitions of the member functions. The class definition can be placed in a header file. Member functions, with the use of scope resolution operator, can be placed in a source implementation file.

The `this` pointer is inserted by the compiler, as a formal argument, in the prototype and in the definition of each member function of each class. When a member function is called with respect to an object, the compiler inserts the address of the object as a parameter to the function call. Consequently, this `this` pointer, which exists as the implicit leading formal in all member functions, always points to the object with respect to which member function has been called.

Access to member data and member functions from within member functions is resolved by the `this` pointer. The `this` pointer is a constant pointer in non-constant member functions and a constant pointer to a constant in case of constant member functions.

If the operator on its right is a data member, the object-to-member access operator (`->`) behaves as it does in C language. However, if it is a function of a class whose object of the same class is its left-hand side operand, then the compiler simplifies the `address of the object` as an implicit parameter to the function call.

Similarly, if the operator on its right is a data member, the pointer-to-member access operator (`->`) behaves just as it does in C language. However, if it is a member of a class whose pointer to an object of the same class is its left-hand side operand, then the compiler passes the value of the `pointer` as an implicit parameter to the function call. Member functions can call each other. Calls are resolved through this `this` pointer. Member functions can be overloaded. Default values are given to the formal arguments of member functions.
