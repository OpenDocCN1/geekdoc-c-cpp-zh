
## Stream and File Handling

File pointers can be explicitly manipulated by the use of some functions that have been provided as members of the stream handling classes. An explanation of these functions follows.

### 7.9.1 seekp() Function

This function is used to explicitly make the put pointer at a desired position in the open file. It is important to note that by default the put pointers are at the beginning of the file if it is newly opened for writing. In case an existing file is opened for appending, the put pointer points to its end by default. Also, every write operation pushes the put pointer by the number of bytes written.

The seekp() function has been defined in the class stream. It has two versions:

```cpp
ostream & ostream :: seekp(streampos pos);
ostream & ostream :: seekp(streamoff off,
                               ios::seek_dir dir);
```

In the first version, the seekp() function takes only one parameter—the absolute position with respect to the beginning of the file. The type streampos is defined with long as the source data type. We must remember that the numbering of the position starts from zero. In this example, the put pointer is made to point at the second byte of the file:

```cpp
ofile.seekp(1); //ofile is an object of class ostream
```

In the first version, the new position of the put pointer can be specified with respect to the beginning of the file only. But in the second version, the seekp() function takes two parameters—the first parameter is the offset and the second parameter is the position in the open file with respect to which the offset being specified. The type streamoff is defined with long as the source data type. The type ios::seek_dir is an enumerated type with the following values:

```cpp
ios::beg—offset will be calculated from the beginning of the file
ios::cur—offset will be calculated from the current position in the file
ios::end—offset will be calculated from the end of the file
```

In the following example, the put pointer is made to point at the last byte of the file. We must remember that the EOF character is the last byte of the file. Thus, in the following example, the put pointer will end pointing at the last byte that was written into the file that is one by the last of EOF character.

```cpp
ofile.seekp(-1,ios::end); //ofile is an object of class
//fstream
```

Some more examples follow:

```cpp
ofile.seekp(0,ios::beg); //take the put pointer to the
//beginning of the file
of.seekp(2,ios::beg); //take the put pointer to the
//third byte from the beginning
//of the file
of.seekp(-2,ios::cur); //take the put pointer two
//bytes to the left from its it
//current position in the file
of.seekp(2,ios::cur); //take the put pointer bytes
```

```cpp
//to the right from its it
//current position in the file
//take the put pointer to the end
//of the file (past the
//last byte)
ofile.seekp(0,ios::end);
```

```cpp
ofile.seekp(-1,ios::end);
//take the put pointer to the last
//byte of the file
```

Let now understand the difference between ios::app and ios::ate flags. Both of these opens the file for appending and making the put pointer point at the end of the file by default (past the last existing byte). Neither of the two overflows an existing file. The difference between the two is that while the file ios::ate allows you to rewind the put pointer and modify the existing contents of the file, the file ios::app does not allow. In other words, if the file is using ios::app flag, an attempt to use the seekp() function for rewinding the put pointer will fail. The put pointer would continue to point at the end of the file. As bytes are appended to the file, the put pointer, as already mentioned, moves forward. Therefore, it cannot be rewound if the file is using the ios::app flag. In case of ios::ate, the put pointer can be rewound.

### 7.9.2 tellp() Function

The tellp() returns the current position of the put pointer. It has been defined in the class ostream

```cpp
ostream::tellp();
```

In the following example, the current position of the put pointer is determined and stored in a program variable.

```cpp
long pos = ofile.tellp(); //ofile is an object of the
//class ostream
```

### 7.9.3 seekg() Function

This function is used to explicitly make the get pointer point at a desired position in the open file. It is important to note that by default the get pointer points at the beginning of the file that is for reading. Every read operation pushes forward the get pointer by the number of bytes.
The seekg() function has been defined in the class istream. It has two versions.

```cpp
istream & istream :: seekg(streampos pos);
istream & istream :: seekg(streamoff off,
ios::seek_dir dir);
```

The explanation for these two versions of the seekg() function is similar to the one provided for the corresponding versions of seekp() function.

### 7.9.4 tellg() Function

The tellg() function, like the tellp() function, returns the current position of the get pointer. It has been defined in the class istream.

```cpp
istream::tellg();
```

In the following example, the current position of the get pointer is determined and stored in a program variable.

```cpp
long pos = ifile.tellg();      //ifile is an object of the
                               //class istream
```

### 7.10 Random Access to Files

In random access, an intermediate record of a file is accessed directly without sequentially iterating through its neighbouring records. We have already studied the tools necessary for accessing a record in a disk file at random, the seek() and seek() functions.
Suppose we output integer-type values into a file and we want to directly access the nth integer. We can do this sequentially by using a loop that starts from the first record. This loop increments a counter after every read and stops when the counter indicates the (n-1)th record has been read. At this point, pointers point to the nth record.
A more direct approach is to use either the seekp() function or the seek() function, as we need may be, as:

```cpp
ofile.seekg((n-1)*sizeof(int), ios::beg); //ofile is an
                                              class
fstream
```

This statement causes the pointers to point at the nth record. At this point, if the operation is conducted, the nth record would be modified. Note that the technique works only if the size of all records is equal.

### 7.12 Object/Output Member Functions

We have realized that classes have pointers that externally help show output and input. Client programs should not be burdened with the responsibility of knowing how data stored in classes is organized.

Let us provide the String class, which has been our example so far, with the functionality to write data and read from disk. See Listing 7.27.

#### Listing 7.27 Input/output of objects through member functions

```cpp
#include<iostream>
class String
{
  explicit String(const char * p = NULL);
  const char * getString();
  void diskOut(ostream&);
  void diskIn(istream&);
};
```

```cpp
/*
 of the class String*/
String::String(const char * p)
{
  if(p==NULL) //if default value passed...
    cStr=NULL; //nullify
    len=0;
  } else //otherwise...
    len=strlen(p);
    cStr=new char[len+1]; //dynamically allocate a //separate memory block //and copy into it
    strcpy(cStr,p);
  }
const char * String::getString()
{
  return cStr;
}
void String::diskOut(ostream& fout)
{
  fout.write((char*)&len, sizeof(int));
  for(int i = 0;i<len;i++)
    fout.put(cStr[i]);
}
void String::diskIn(istream& fin)
{
  String temp;
  fin.read((char*)&temp.len, sizeof(int));
  temp.cStr= new char[temp.len+1];
  int i;
  for(i=0;i<temp.len;i++)
    fin.get(temp.cStr[i]);
  temp.cStr[i]='\0';
  *this = temp;
}
```
