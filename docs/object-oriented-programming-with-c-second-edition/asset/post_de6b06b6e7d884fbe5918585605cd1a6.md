Let us now study the delEnd() function. As the name suggests, this function deletes the last node from the list. Compared to the delBeg() function, this is a slightly complicated function.

```cpp
/*
 Function to delete the last node.
 */
 void SingleLinkedList::delEnd() {
    /* if the list is empty */
    if(head == NULL) {
        /* delete head */
        head = NULL;
    } else {
        /* declare a temporary pointer */
        ListNode* iter;
        /* iterate the list to point at the last node */
        for(iter = head; iter->getNext() != NULL; iter = iter->getNext());
        /* delete the last node */
        delete iter->getNext();
        /* nullify the next pointer */
        iter->setNext(NULL);
    }
}
```
