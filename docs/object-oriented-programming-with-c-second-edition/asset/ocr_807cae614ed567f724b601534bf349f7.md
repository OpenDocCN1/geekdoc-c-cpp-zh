# Output
No nodes in list

When the list is empty, we expect the function to display a message that says that the list is empty. Let us see whether this happens or not.

Note that the value of the head pointer inside the list1 object will get set to NULL at the time of creation because of the constructor. Hence, it will be NULL at the time the display() function gets called.

Now, when the function begins executing, the if block compares the value of the head pointer with NULL. Since the value of the head pointer is NULL, the test expression in the if statement returns NULL. Therefore, the if block executes. This causes the string 'No nodes in list' to get displayed on the monitor. Naturally, the else block does not execute and the function comes to an end. And this is what we are expecting.
