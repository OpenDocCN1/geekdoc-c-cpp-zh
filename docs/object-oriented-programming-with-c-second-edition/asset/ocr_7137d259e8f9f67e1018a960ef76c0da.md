We can specify our own handler function also! We can specify that the new operator, upon encountering an out-of-memory condition, calls a function of your choice. We can do this by calling the set_new_handler() function and passing the name of the desired function as a parameter to it. The prototype of the set_new_handler() function clarifies this. The prototype is in the new.h header file.

```
new_handler set_new_handler(new_handler);
```

Obviously, new_handler is a data type. It is a function pointer. The first argument of the set_new_handler() is a function pointer. If we pass the name of our desired function as a parameter to the set_new_handler() function, all subsequent out-of-memory conditions cause the new operator to call it. Our desired function becomes the new handler. Moreover, when the set_new_handler() function is called, it returns a pointer to the previous new function.

An illustrative example follows in Listing 3.10.

# Listing 3.10 Specifying a new handler function

```
/*Beginning of newHandler.cpp*/
#define BIG_NUMBER 9999999
#include<new.h> //for set_new_handler() function
void myHandler()
{
/*
    code to handle out-of-memory condition
*/
}
void main()
{
    new_handler oldHandler;
//set the function myFunctionHandler as the new handler
oldHandler = set_new_handler(myNewHandler);
int * p = new int[BIG_NUMBER]; //probably cause out-of-
//memory condition
}
/*End of handler.cpp*/
```

If the OS is unable to allocate the requested amount of memory, which is quite likely in Listing 3.10, the new operator fails. The new handler function gets called. The call to the set_new_handler() function, just prior to the call to the operator, has already set the myHandler as the new handler. Therefore, the function myHandler gets called.

An important characteristic of the new operator is that when its request for memory fails, it calls the new handler repeatedly until its request is satisfied. This helps in meaningfully defining the new handler function (Listing 3.11).

We can make the new handler function log an error message and then call the abort() function.

# Listing 3.11 Defining the new handler function

```
void myNewHandler()
{
    //statement to log a suitable error message
abort();
}
```
