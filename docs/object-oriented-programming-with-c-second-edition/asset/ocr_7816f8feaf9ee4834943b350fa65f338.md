# 9.4 Queues

Queues are data structures too. They are very similar to stacks. The only difference between the two is in their push operations. In a stack, the push operation causes the new node to get added to the beginning. But, in a queue, the push operation causes the new node to get added to the end.

Thus, queues are said to have a FIFO (first-in-first-out) operation. The first node to get is the first to get out.
