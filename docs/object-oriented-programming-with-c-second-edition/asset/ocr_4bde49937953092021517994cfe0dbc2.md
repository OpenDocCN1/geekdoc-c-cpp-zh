# Exercises

+   1. What is inheritance? How does it enable code reusability?
2. How does inheritance influence the size and functionality of derived classes?
3. How does inheritance compare with containment?
4. How does inheritance compare with nesting?
5. Create a global non-member function that has a base class pointer as its argument. Call the member functions of the base class through the pointer within this function. Now can you function by passing addresses of the derived classes?
6. Override one of the base class functions that have been called from the function you have defined above, the derived class. Pass the address of an object of the derived class to the function. Which function calls—the overridden function of the base class or the overriding function of the derived class?
Make a derived class pointer at an object of the base class by typecasting. Now access a member of the derived class that does not exist in the base class. What happens?
8. Why is it necessary for the derived class constructor to pass values explicitly to the base class constructor?
9. A base class has data members. However, a class that is derived from it does. Does the derived class need a constructor? Why?
10. What is the effect of using the access specifier on the visibility of a base class member?
11. Will a function of the derived class be able to access a public of the base class if no access specifier was used to derive the derived class? Why?
12. What are the ambiguities that arise in multiple diamond-shaped inheritance? How can they be removed?
13. In which order are the constructors and destructors called when an object of the derived class is created?

+   14. State true or false
(a) A base class object is usually smaller than an object of its derived class.

(d) Inheritance implements a 'has-a' relationship.
(e) Public of the base class can be called with respect to an object of the derived class if the protected specifier was used to derive the derived class.
