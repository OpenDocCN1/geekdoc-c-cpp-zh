The abort() function simply terminates the program. We can also throw an exception
from the new handler function. The chapter on exception handling explains the syntax
of throwing exceptions and its superiority over calling the abort() function.

Another course of action is to replace the new handler function by another one.
For this, we can call the set_new_handler() function from the existing new handler
function and the name of the new handler as a parameter to it. Of course, a call
should be preceded by the code that attempts to resolve the out-of-memory condition first.
The new handler should be replaced only if this attempt fails. See Listing 3.12.

# Listing 3.12 Replacing the new handler function

```
#include<new.h>
void myNewHandler() {
    //make attempt to resolve the out-of-memory
    //condition
    if(above_attempt_fails)
        set_new_handler(myAnotherHandler);
}
```

# Summary

Memory is allocated for program variables during run only. In static memory allocation, the amount of memory to be decided during compile time itself. The instance at which statically allocated variable would get created during the program's execution is also decided during the program's compilation.

On the other hand, the amount of memory to be decided during run time in dynamic memory allocation. Moreover, memory can be allocated in response to conditions that arise run time.

C++ provides the new operator for allocating memory dynamically. The syntax of the new operator for allocating memory for a single block

```
<pointer> = new <data_type>;
```

The new operator allocates enough memory in the heap area to accommodate one variable of the data type that is passed as its right-hand-side operand. Further, it returns the address of the first byte of this allocated block of memory that can be stored in the pointer on the left-hand-side of the assignment operator as shown in the above statement.

Memory for an array can be allocated by using the new operator. The syntax in is as follows:

```
<pointer> = new <data_type>[number_of_elements];
```

Again, dynamically allocated memory can be dynamically allocated in response to conditions that arise run time. Dynamically allocated memory must be deleted, and returned to the Operating System. Otherwise, memory leak would occur.

C++ provides the delete operator for deallocating memory dynamically. The syntax of the delete operator for deallocating memory earlier allocated for a single block

```
delete <pointer>;
```

The delete operator deallocates the memory in the heap area that the pointer is passed as its right-hand-side operand points at.

Memory for an array can also be deallocated using the delete operator. The syntax is as:

```
delete []<pointer>;
```
