## 8.1.3 一元运算符和二元运算符重载概述

重载一元运算符的成员函数不接受操作数。这是因为除了调用对象外，没有其他参数传递给运算符，且调用对象作为隐式参数传递给该对象的。重载一元运算符的友元函数自然接受一个参数，因为调用对象将作为显式参数传递给它。

同样，重载二元运算符的成员函数接受一个参数。这是因为除了调用对象外，另一个值将作为操作数传递给运算符（二元运算符接受两个操作数）。调用对象本身将作为隐式参数传递给函数。同样，重载二元运算符的友元函数会多接受一个参数，即两个操作数。我们可以很好地解释这一点。

## 8.1.5 运算符重载规则

在重载运算符时必须遵循以下规则：

- 1. 不能创建新运算符：不能创建新运算符（例如 `**`）。例如，列表 8.6 所示的代码段将产生编译错误。

列表 8.6 尝试创建新运算符的非法尝试

```cpp
class A
{
    public:
    void operator ** ();
};
```

- 2. 现有运算符的意义不能更改：任何运算符重载函数（成员函数或友元函数）都至少应接受一个其所属或为其友元的类的操作数。因此，无法更改现有运算符在基本类型（char, int, float, double）操作数上的工作方式。在成员函数的情况下，此条件是自动强制的，因为对象的地址被隐式作为参数传递给它。然而，在友元函数的情况下，库程序员需要额外小心。例如，下面的代码段（列表 8.7）将无法编译。

列表 8.7 尝试修改内建类型运算符行为的非法尝试

```cpp
class A
{
    public:
    friend int operator + (int, int); //错误：无法
//编译
};
```

- 3. 某些现有运算符不能重载：以下运算符不能重载：
- ::（作用域解析）
- .（成员选择）
- .*（通过成员指针进行成员选择）
- ?:（条件运算符）
- sizeof（查找值和类型的大小）
- typeid（查找所指向对象的类型）
