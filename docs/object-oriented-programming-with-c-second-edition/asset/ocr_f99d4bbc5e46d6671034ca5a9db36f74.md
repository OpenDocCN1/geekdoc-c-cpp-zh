# Listing 9.32 Testing the BSTNode class

```

Beginning of BSTNodeTest2.cpp

void f1(BSTNode *temp, int pVal)
{
  temp = new BSTNode();
  temp->setVal(pVal);
}
void main()
{
  BSTNode node1;
  node1.setVal(20);
  f1(node1.getLeft(), 10);
  cout << node1.getLeft() -> getVal() << endl;
}
/*End of BSTNodeTest2.cpp
*/
```

Output
10

Listing 9.32 is similar to the previous one. The difference is that temp is a formal argument in a called function instead of being a local variable in the caller. When the f1() function is called, a reference to the left pointer gets passed as a parameter to it. The corresponding formal argument in the f1() function, temp, is also a reference-type variable. Consequently, temp ends being a reference for the left pointer of node1 object. The consequence of the statements inside the f1() function has already been explained.
As you can see in Listing 9.32, a left child again got added to an existing node, but this time via the called function. This technique will be used later while defining the insert() function of the BST class, function that enables us to insert nodes in the BST. It is therefore important to understand this explanation.
