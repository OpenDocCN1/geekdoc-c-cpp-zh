Let us look at the rest of the statements.

```
/*
Reset temp1 so that it points at the first node.
*/
temp1 = temp;
```

The above statement will copy the value of temp to temp1. This will cause temp1 to point at the same node as temp, which is the first node (Figure 9.14).

After this, we have

```
/*
Display the value in the node that temp1 points at.
*/
cout << temp1->getVal() << endl;
```

This time, the temp1->getVal() will return 10. The above statement will therefore display this value on the screen.
