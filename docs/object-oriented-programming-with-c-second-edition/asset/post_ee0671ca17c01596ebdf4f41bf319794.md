When the new and delete operators are called by passing the derived class type as parameter, it is seen that the operator functions of the base class are called. How can this be a problem?

The problem this inheritance causes is due to the fact that when the new operator is called, the head pointer points to the wrong place. Let us suppose the new operator is overloaded for class A in Listing 8.5. After the new operator executes for the first time, the head pointer points four bytes away from the first byte of the pool even the derived class type is passed as parameter to the new operator. Thus, when the new operator is called for the second time, the address of the fifth byte is returned and not the ninth. The address of the ninth is desired because an object of class B will occupy eight bytes—four for 'x' and four for 'y'. The problem that arises because this can be clearly understood from Listing 8.5.

**Listing 8.52 Undesirable effect of operator new and delete functions inherited**

```cpp
/*Beginning of Main.cpp*/
#include"B.h"
#include<iostream>
void main() {
    B* Bptr01 = new B;
    B* Bptr02 = new B;
    Bptr02->set(20);
    cout<<Bptr02->get()<<endl;
    Bptr01->set(10);
    cout<<Bptr02->get()<<endl;
}
/*End of Main.cpp*/
```

# Output
2
10

After the first two statements in Listing 8.5, 'Bptr01' will point at the first byte of the memory pool and 'Bptr02' will point at the fifth. The third statement writes 20 into the block of bytes from the fifth byte to the eighth byte. However, the fifth statement writes '10' into the same memory block!

In order to neutralize this effect of inheritance, the size of memory block targeted for allocation or deallocation should be compared with the size of the class for which the operator is overloaded. If these two do not match, the global new or the global delete operator should be called (see Listing 8.5).

**Listing 8.5 Preventing the ill effects of the new and delete operators inherited**

```cpp
void* A::operator new(const size_t size) {
    if(size != sizeof(class A)) // true if derived class type is passed as parameter
        return ::operator new(size);
    //rest of the code
}

void A::operator delete(void* p, const size_t size) {
    if(size != sizeof(class A)) // true if derived class type is passed as parameter
        ::operator delete(p);
        return;
    //rest of the code
}
```
