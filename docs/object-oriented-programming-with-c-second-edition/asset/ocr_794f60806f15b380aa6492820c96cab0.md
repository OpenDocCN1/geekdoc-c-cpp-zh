The process implemented in Listing 8.68 for safely casting a pointer of base class type to a pointer of derived class type is known as downcasting. This process enables us to access those features of the derived class that are not present in the base class.
If the dynamic_cast operator is used with references, it throws an exception of type Bad_cast where it would otherwise returned NULL, pointers been used. Understanding this requires preliminary knowledge of exception handling. Therefore, Listing 8.69 can be read after reading Chapter 11 on exception handling.
