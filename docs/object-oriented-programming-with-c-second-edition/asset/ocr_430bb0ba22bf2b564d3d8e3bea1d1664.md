Now, let us start the study of a class that will allow us to abstract characters and overcome many of the drawbacks that exist within. Our purpose is to ultimately define a class that can be used instead of character arrays.

Let us call the class String. It has two data members. Both of these data members will be private. The first data member will be a character. It will point to a dynamically allocated block of memory that contains the actual character array. The other data member will be a long unsigned integer that will contain the length of this character array.
