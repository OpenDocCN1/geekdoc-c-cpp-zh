Figure 9.12 Effect of setName() function

We can see from its definition that the setName() function assigns the value of its parameter to the next data member of the object for which it has called. In the above case, the function has been called for the object at which temp points. The value passed to it as parameter is the value of temp1, which is 320. As result, the value of the next pointer of the object at which temp points is set to 320 and it now points at the freshly created node.
