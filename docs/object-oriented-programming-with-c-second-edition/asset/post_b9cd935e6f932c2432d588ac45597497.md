# Summary

Classes have both member data and member functions. Member functions can have exclusive rights to access data members. Member functions and member data can be private, protected, or public. The struct keyword has been redefined in C++. Apart from member data, structures in C++ can have member functions. In a class, members are public by default.

The scope resolution operator is used to separate the class definition from the definitions of the member functions. The class definition can be placed in a header file. Member functions, with the use of scope resolution operator, can be placed in a source file.

The `this` pointer is inserted by the compiler as a formal argument in the prototype and in the definition of each member function. When a member function is called with respect to an object, the compiler inserts the address of the object as a parameter to the function call. Consequently, this `this` pointer, which exists as an implicit leading in all member functions, always points to the object with respect to which member function has been called.

Access to member data and member functions from within member functions is resolved by the `this` pointer. The `this` pointer is a constant pointer in non-constant member functions and a constant pointer in case of constant member functions.

If the operator on its right is a data member, the object-to-member access operator (`->`) behaves as it does in C language. However, if it is a function of a class whose object of the same class is its left-side operand, then the compiler simplifies the address of the object as an implicit parameter to the function call.

Similarly, if the operator on its right is a data member, the pointer-to-member access operator (`->`) behaves just as it does in C language. However, if it is a member of a class whose pointer to an object of the same class is its left-side operand, then the compiler passes the value of the pointer as an implicit parameter to the function call. Member functions can call each other. Calls are resolved through the `this` pointer. Member functions can be overloaded. Default values are given to the formal arguments of member functions.

# Object-Oriented Programming with C++

Programs having inline functions run faster than equivalent programs with non-inline functions. A function is declared inline either by defining it inside a class or by declaring it outside with the keyword inline. This feature should be used sparingly. Otherwise, the increased size of the executable can slow it down.

Only one copy of a static data member exists for the entire class. This is in contrast to non-static members that exist in *each* object. Static data members are used to keep data that relates to the entire set of objects that exist at any given point during the program's execution. A data member declared as a static member of a class by prefixing its declaration with the keyword static.

Required member functions be declared as const functions to prevent an inadvertent change in the data members. A function can be declared as a constant by specifying its prototype in the header of the function by the keyword const.

Static member functions can access static data members only without declaring any objects. A member function declared as a static member of a class by prefixing its declaration in the class by the keyword static.

A mutable data member is never constant. It is modified inline const functions. A friend function is a non-member function that has right to access private data members of the class of which it is. This does not really negate the philosophy of OOP. A friend function still needs to be declared inside the class of which it is a friend. The advantage of a friend function is that it is not called with respect to object.

Objects can appear as locals variables inside functions. They can also be passed by value or by reference to functions. Finally, they can be returned by value or by reference from functions.

Arrays of objects can be created. Arrays created inside classes also. One class can be defined inside another class. Such a class is known as a nested class. The class that contains the nested class is known as the enclosing class. Nested classes can be defined in the private, protected or public portions of the enclosing class.

A global non-function can be declared as a friend to a class. Member function of one class can be declared as a friend of another too. A class or a function is declared to a desired class by prototyping it in the class and prefixing the prototype with the keyword friend.

Namespaces enable the C++ programmer to prevent pollution of the global namespace. They help prevent names.
