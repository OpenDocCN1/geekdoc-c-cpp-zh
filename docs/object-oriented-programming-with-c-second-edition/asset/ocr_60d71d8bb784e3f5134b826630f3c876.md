Now, there are separate functions to overload the subscript operator for constant and non-constant objects. However, the function given in Listing 8.56 is still imperfect. Let us consider the following piece of code.

```
const String s("abcd"); //unacceptable, but the compiler doesn't
s[1]='x'; //complain!
```

The second statement in the code calls the constant function with respect to the constant object. The function returns the selected element by reference and the value of the selected element set to 'x'. Although the compiler will compile, our perception of a constant tells us the second statement should not compile. In order to ensure this, we must make the constant String::operator[] function return the value as a constant reference and not as a non-constant reference. See Listing 8.57.
