```
class B : public A
{
    public:
    void abc();
};
void B::abc()
{
    A::abc();

}
```

The ability to provide implementation to virtual methods allows data types to provide core functionality while requiring derived classes to provide a specialized implementation. Note that the class remains abstract even if we provide an implementation for its pure virtual function.
As requirements, a member function can be non-virtual, or pure virtual.

# 6.5 Virtual Destructors and Virtual Constructors

We will now study the creation and use of virtual constructors and destructors. We will first study virtual destructors. This will be followed by a study of virtual destructors.

# 6.5.1 Virtual Destructors

Destructors can be defined as virtual. If necessary, destructors must be defined as virtual. Why? Let us consider Listing 6.21 (A is a base class and B is a class derived from A).

> Listing 6.21 Destroying a derived class object through a base pointer

```
* A APtr;
APtr = new B;
...
...
delete APtr;
```

Let us consider the last line of Listing 6.21 that APtr deletes the memory occupied by the object of class B at which ‘APtr’ points. Because ‘APtr’ is of base type, only the base class destructor is called with respect to the object before the entire memory occupied by the object is returned to the OS. This can lead to memory leaks from other problems. Suppose objects of the derived class B have a pointer. It is possible that this pointer, which is in the object at which ‘APtr’ points, is assigned a dynamically allocated block during the lifetime of the object. Although the destructor of class B destroys memory block a memory leak will still occur because the destructor of class B is not called.

On the other hand, if the destructor of class A is virtual, then against the last line of Listing 6.21, the first destructor of class B will be called, the destructor of class A will be called. Finally, the entire memory block occupied by the object will be returned to the OS.

The conclusion is that if we expect the use of the delete operator on a base class and the presence of pointers in the derived classes, we must declare the destructor of the base class as virtual.
