In the case of C++, the dot operator's definition has been extended. It not only takes data members as C but also member functions as its right-hand side operand. If the operand on its right is a data member, the dot operator behaves just like it does in C language. However, if the operand on its right is a member function, the dot operator causes the address of the object on its left to be passed as an implicit parameter to the function call.

Clearly, members of the invoking object are referred when they are accessed by any qualifiers in member functions. It should also be obvious that multiple copies of member data exist (inside each object) but only one copy exists for each member function.

It is evident that this pointer should continue to point at the same object—the object with respect which the member function has been called—throughout its lifetime. For reason, the compiler interprets it as a constant pointer.

The accessibility of the implicit call is the same as that of the objects passed as parameters and the local objects inside that function. Listing 2.9 illustrates this. A new function—add()—has been added to the existing definition of the Distance class.
