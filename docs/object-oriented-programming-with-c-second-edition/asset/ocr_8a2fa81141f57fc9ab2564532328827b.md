# Appendix E: Glossary 451

Function Prototype A function declaration that tells the compiler the return type of the function and the number of its formal arguments.

functions can modify their values. (see also constant functions)

Function Template A template for a function definition. The type of its formal arguments is undefined. An actual definition of the function gets generated only when the function is called. The types of the corresponding parameters replace the undefined data types of formal arguments.

Namespace A language in C++ allows us to divide the source code into logical parts. This helps in preventing clashes of names. Two classes with the same name can be defined if they belong to different namespace.

Nested Class A class that is defined within another class is known as a nested class. (see also enclosing class)

New Handler Function A function that gets called whenever an out-of-memory condition is encountered. We can define our new handler function.

Guaranteed Initialization of Data The members of a variable in C language may attain invalid values at its time of creation. C++ enables guarantee initialization of data objects by defining constructors. (see also constructor)

new Operator An operator that enables us to capture memory in response to conditions arising during run time (see also dynamic memory allocation)

Inheritance A feature provided by object-oriented languages that allows a class to inherit the data and members of an existing class. (see also base class, parent class, super class, derived class, sub class)

New Styles C++ provides the following new cast operators to replace the old error-prone and difficult-to-detect class styles:

+   * dynamic cast
* static cast
* reinterpret cast
* const cast

Inline Function A function that is expanded in its call by the compiler.

Late Binding (see dynamic binding)

Linked Lists List consists of nodes that are linked to each other in a linear fashion. Each node in a linked list is an object that is made of two parts. The first part is the data carried by the node. The second part of each node is a pointer that carries the address of the next node in the list. This is a description of a single linked list. Alternatively, each node may have an additional pointer, to double linked lists.

Object An instance of a class is known as an object.

Object-Oriented Programming System A system that enables programmers to model real-world objects. Data and procedures work together in a single class instance.

Manipulators are operators that enable the C++ programmer to format the output from their programs.

Operator Overloading A feature of object-oriented languages allows programmers to provide definitions to operators so they can take class objects as operands.

Multiple Inheritance A type of inheritance where a class inherits the features of more than one base class.

Parameterized Class (see Class Template)

Parameterized Constructor A constructor that takes parameters.

Parent Class (see Base Class)

Mutable Data Members Data members that are never constant. Even constant member

Polymorphism A feature of object-oriented languages allows programmers to create two functions with identical names. Polymorphism
