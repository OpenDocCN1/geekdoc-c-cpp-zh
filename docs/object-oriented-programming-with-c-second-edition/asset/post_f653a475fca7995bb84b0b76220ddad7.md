## 8.2.3 Overloading Arithmetic Operators

Arithmetic operators are binary operators. Therefore, the syntax for overloading them through member functions is illustrated in Listing 8.17.

Listing 8.17 Syntax for overloading the arithmetic operators through member functions

```cpp
class <class_name>
{
    public:
        //prototype
        <return_type> operator<arith_op_symbol>(<param_list>);
};
//definition
<return_type> <class_name>::operator<arith_op_symbol>(<param_list>
{
  //function body
}
```

* Note

# Object-Oriented Programming with C++

An object that will store the value of the right-hand side operand of the arithmetic operator will appear in the list of formal arguments. The left-hand side operand will be passed implicitly to the function which the operator-overloading function will be called with respect to it. The statement

```cpp
Obj3 = Obj1 <arith_op_symbol> Obj2;
```

will be interpreted as

```cpp
Obj3 = Obj1.operator <arith_op_symbol> (Obj2);
```

If instead a friend function overloads the arithmetic operator, the syntax will be as in Listing 8.18.

+ Listing 8.18 Syntax for overloading the arithmetic operators through friend functions

```cpp
class <class_name>
{
  public:
    //prototype
    friend <return_type>operator<arith_op_symbol>(<param_list>);
    //definition
    <return_type> operator<arith_op_symbol>(<param_list>)
    //function body
}
```

Objects that store the values of the left-hand side and the right-hand side operands of the arithmetic operator will appear in the list of formal arguments. The statement

```cpp
Obj3 = Obj1 <arith_op_symbol> Obj2;
```

will be interpreted as

```cpp
Obj3 = Obj1.operator <arith_op_symbol> (Obj2);
```

Since, the arithmetic operator has been overloaded by a friend function, the final interpretation will be

```cpp
Obj3 = Obj1.operator <arith_op_symbol> (Obj2);
```

Listing 8.20 Overloading the arithmetic operator through member functions

```cpp
/*Beginning of Distance.h*/
class Distance
{
    int ifet;
    float inches;
    public:
        Distance(int = 0);
        Distance operator+(const Distance&);
        int getFeet() const;
        float getInches() const;
};
/*End of Distance.h*/
```

```cpp
/*Beginning of Distance.cpp*/
#include "Distance.h"
Distance::Distance(int p)
{
    ifet = p;
    inches = 0;
}
Distance Distance::operator+(const Distance& obj)
{
    return Distance(ifet+obj.ifet, inches+obj.inches);
}
int Distance::getFeet() const
{
    return ifet;
}
float Distance::getInches() const
{
    return inches;
}
/*End of Distance.cpp*/
```

However, one condition remains to be tackled. What if the left-hand side is a float type? The solution is to provide a constructor that converts from float to Distance.

+ Listing 8.22 Overloading the arithmetic operator through a constructor

```cpp
/*Beginning of Distance.h*/
class Distance
{
    int ifet;
    float inches;
    public:
        Distance(int = 0);
        Distance(float);
        friend Distance operator+(const Distance&);
        int getFeet() const;
        float getInches() const;
};
/*End of Distance.h*/
```

```cpp
/*Beginning of Distance.cpp*/
#include "Distance.h"
Distance::Distance(int p)
{
    ifet = p;
    inches = 0;
}
Distance::Distance(float p)
{
    ifet = (int)p;
    inches = 0;
}
friend Distance operator+(const Distance& obj)
{
    return Distance(ifet+obj.ifet, inches+obj.inches);
}
int Distance::getFeet() const
{
    return ifet;
}
float Distance::getInches() const
{
    return inches;
}
/*End of Distance.cpp*/
```
