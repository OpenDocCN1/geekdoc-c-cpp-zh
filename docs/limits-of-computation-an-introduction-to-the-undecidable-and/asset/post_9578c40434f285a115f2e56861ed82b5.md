If P exists, it must take any program S with input I and announce "yes, halts" or "no, never halts." It might do this announcement by writing one of the two phrases to the screen. This is shown in Figure 6.9.

We can easily change P to P_Rev (read as "P revised") with the following three changes.

1. Use self as input: Instead of inputs S and I, now P_Rev takes only one input S and will decide what S does on S.
2. Turn "yes" into a loop: If P would write "yes, halts," then P_Rev goes into an infinite loop.
3. Turn "no" into "yes": If P would write "no, never will halt," then P_Rev writes "yes, halts" and stops.

Imagine how to do this: a pattern search through P. Any statement of the form

```
writeln ("yes, halts")
```

is replaced by

```
while true do x := 1
```

And any line of the form

```
writeln ("no, never will halt")
```

is replaced by

```
writeln ("yes, halts"); exit (0);
```

This revised program P_Rev works on all possible input programs, since P does. In particular, one can ask what P_Rev does when fed its own code.

This is a version of the halting problem—answering the question whether a Turing machine, or a given program running on some computer, will ever halt. And, as the above discussion shows, this is undecidable.

Recall that the set of natural numbers N has cardinality ℵ, and that the set of infinite sequences over [0, 1] has the much larger cardinality ℔. Let Σ be any alphabet. By letting the strings in standard lexicographical order (v < w if v is shorter than w; if v, w have the same length, v < w if it precedes it in the dictionary), we have an easy-to-one correspondence between the strings over Σ and the natural numbers. We have seen this before; we know that |Σ|* = ℵ.

> {0,1}* = {ε, 0, 1, 00, 01, 10, 11, 000, ...}

Take any language L over {0, 1}. It has a characteristic vector that is 0 in the i-th position if the i-th string is not in L, and 1 in the i-th position if the i-th string is in L. See Figure 6.11 for the characteristic vectors of some languages.

These characteristic vectors make a one-to-one correspondence between the set of languages over Σ* (the subsets of Σ*) and infinite sequences over {0, 1}. But we know that there are ℔ infinite sequences over {0, 1}, and uncountably many languages. This means that there are ℔ uncountably many languages, for any alphabet Σ.

Not natural numbers correspond to encodings of Turing machines. For example, the substring 11111 never appears in any encoding using the scheme from 1, so numbers as 11111, 11111011, and 1111101111 do not correspond to any Turing machine. This is not really a problem—it would only mean that there are more integers than there are Turing machines. Another simple solution is to say that each number does correspond to some Turing machine, but if it cannot be decoded into a Turing machine then we say that it corresponds to a Turing machine with no moves at all (Turing machine that rejects all inputs). Thus, 11111, 11111011, and 1111101111—and all the other Turing machine strings—correspond to this no-move TM.
