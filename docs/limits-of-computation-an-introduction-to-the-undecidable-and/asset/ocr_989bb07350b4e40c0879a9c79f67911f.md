# 28 ■ Limits of Computation

One can also form such sets (or languages) from $L_1$ as

Prefix ($L_1$) = {$w | w$ is the prefix of some x in $L_1$}

Suffix ($L_1$) = {$w | w$ is the suffix of x in $L_1$}

The prefixes of the string $x = \sigma_1\sigma_2 ... \sigma_n$ are $\epsilon, \sigma_1, \sigma_1\sigma_2, ..., \sigma_1\sigma_2 ...$ $\sigma_n$. Similarly, the suffixes are $\sigma_1\sigma_2 ...$ $\sigma_n, ..., \sigma_{n-1}\sigma_n, \epsilon$. Note that a string of length $n$ has $n+1$ prefixes and $n+1$ suffixes.

# Example

Consider the following language over $\{0, 1\}$:

$L_1 = \{10, 110\}$

Now:

Prefix ($L_1$) = {$\epsilon, 1, 10, 11, 100\}$

Suffix ($L_1$) = {$\epsilon, 0, 10, 110\}$

One can also form left and right quotients of two languages:

$L_1/L_2 = \{y \in \Sigma^* | yx \in L_1 	ext{ for some } x \in L_2\}$ (right quotient)

$L_1/L_2 = \{y \in \Sigma^* | 	ext{for some } x \in L_1, xy \in L_2\}$ (left quotient)

This can be stated as: $L_1/L_2$ contains strings such that it is possible to find a string in $L_2$ to add this string and obtain a string in $L_1$. In other words, to see if $w$ is in $L_1/L_2$ you have to see there is any string you can find from $L_2$ that, when added after $w$, puts the combined string in $L_1$ and remove a string from $L_2$ from the **right**.

$L_1\setminus L_2$, however has those strings such that it is possible to find a string from $L_2$ that when added in the front (left) gives a string in $L_2$. Or again, think that the $L_2$ is on the top (numerator), and think of $L_1\setminus L_2$ as the strings obtained by beginning with a string from $L_2$ and removing a string from $L_1$ from the **left**.
