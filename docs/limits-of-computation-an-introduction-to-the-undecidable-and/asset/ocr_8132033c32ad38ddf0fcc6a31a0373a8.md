# Turing Machines

# 4.1 OVERVIEW

Theoretical computer science needs a model of a computer—a perfect machine, not dependent on electricity, chip design, or anything that might have a flaw. This model could run programs in a high-level language such as C++, Java, or Python—but usually be much simpler than that. What is needed is a simple machine such that if a problem can be solved on this machine, then it can be solved on a PC, a supercomputer, or whatever—and vice versa. Moreover, one would also want that a solution “in reasonable time” on a standard computer would be possible if and only if (iff) it could be done in reasonable time on the model machine.

There have been several different models proposed—some very related, some that do not look like machines at all, but rather are similar to an abstract branch of mathematics. The most useful and widely used model is the one proposed by the English mathematician and code breaker Alan Turing.

The purpose of this chapter is the exploration of this model (in several different flavors), and to explore the idea that some problems are not solvable all on any variety of computer.

# 4.2 THE TURING MACHINE MODEL

Informally, a Turing machine is a device with a very, very large memory (so large that no problem can ever exhaust it) and a means to read and write to that memory—that is, to act on its storage locations in some very precisely defined manner.
