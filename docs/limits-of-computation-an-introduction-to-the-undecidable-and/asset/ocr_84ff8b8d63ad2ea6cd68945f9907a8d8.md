# NO GOES TO NO (OR, EQUIVALENTLY, YES COMES FROM YES)

As is often the case, it will be easier to prove the contrapositive; that is, a yes instance of the transformed clauses must come from a yes instance of the original clause. (Remember this, as it will occur often).

So, suppose that each of the clauses on the right is satisfiable with some assignment of true values to the $y_{i_1}, ..., y_{i_k}$ and the $y_j, ..., y_l$. For clauses of length up to three, the new clause is nearly identical to the old: if one is true, so is the other. For the clauses containing the $y_i, ..., y_p$, the key is that the set of clauses cannot be made just by choosing true values for the $y_l$ because of the may variables and their negations are threaded through the new clauses.

This can be proved on a case-by-case basis. Try to make all the clauses true, starting from left ($y_i$, true), right ($y_j$, false), or middle (either $y_m$ true or $y_{m+1}$ false). Wherever you start, propagate left or right (or both), attempting to make all the clauses true using only the $y_i, ..., y_p$. This can-not be.

# 2.2.3 Component Design

Sometimes there is no way to take the local properties of one decision problem and make changes to each of them to arrive at a valid transformation so that $X \le_p Y$.

If this cannot be done, the whole structure of X must be considered. The problem Y may be constructed out many parts of X, with changes, reorganizations, additions, or deletions. This often takes considerable ingenuity, and leads to long, complex, hard-to-read proofs. One proof by component design may look nothing like another proof; knowing how to do one reduction may be no help in doing others.

We actually seen a component design transformation in the Cook-Levin theorem. Here, moves and paths in a nondeterministic Turing machine (NDTM) were transformed into Boolean expressions. States, moves, configurations, and the accepting condition become expressed in a large set of nontrivial Boolean clauses. Other examples of component design will be somewhat shorter. No other proof will require an entire chapter, although some of them can be complicated.
