So:

$w^* = \{\epsilon, aaa, aaaaa, aaaaaaaa, ...\}$

$x^* = \{\epsilon, b, bb, bbb, bbbb, bbbbb, ...\}$

$y^* = \{\epsilon, aba, abaaba, abaabaaba, ...\}$

$z^* = \{\epsilon\}$

The **homomorphic image of a language** L under some mapping $h$ from $\Sigma_1$ to $\Sigma_2^*$ is the homomorphic mapping of all of the strings in L.

# Examples

+   I. Let $\Sigma_1 = \{0, 1\}, \Sigma_2 = \{a, b, c\}, h: 0 \rightarrow abc, 1 \rightarrow b$.

$L_1 =$ strings that contain the substring 00

$L_2 = 0^n1^m$

$h(L_1) =$ combinations of abc and b that contain the substring abcabc

$h(L_2) = (abc)^n(abc)^m$

+   II. Let $\Sigma_1 = \{0, 1\}, \Sigma_2 = \{a, b, c\}, h: 0 \rightarrow aa, 1 \rightarrow \epsilon$.

$L_1 =$ strings that contain the substring 00

$L_2 = 0^n1^m$

$h(L_1) = (aa)^{k+2} = \{a^4, a^6, ...\}, k \geq 0$

$h(L_2) = (aa)^k = a^{2k}, k \geq 0$

+   III. Let $\Sigma_1 = \{0, 1\}, \Sigma_2 = \{a, b\}, h: 0 \rightarrow a, 1 \rightarrow b$.

Then $h(L)$ is simply L with 0 becoming a, 1 becoming b, for any L.
