How many of these variables do we need? In each case, only a number that is polynomial in p(n), since:

Time from 0 to p(n): $0 \leq t \leq p(n)$

State from 0 to $|Q| - 1$: $0 \leq s \leq |Q|$

Square identifier from $-p(n) + 1$ to $p(n)$ and $+1$: $-p(n) + 1 \leq i \leq p(n)$

Symbol number in the alphabet: $0 \leq j \leq |\Gamma| - 1$

+   1. The machine starts correctly, so at time $t = 0$:

+      a. In start state: $Q[0, 0]$

+      b. Head on square 1: $H[0, 1]$

+      c. Input $w = \sigma_1 \dots \sigma_n$, where the $k_i^{th}$ symbol of $\Sigma \subseteq \Gamma$: (For example, if $\Gamma = \{B, a, b, c\}$ then $w = ccba$, then $k_1 = k_2 = 4, k_3 = 3, k_4 = 2$).

$S[0, 1, k_1]$

$S[0, 2, k_2]$

...

$S[0, n, k_n]$

+   d. The other possibly reachable squares contain blanks (assume $B$ is encoded as $0$, the first symbol of $\Gamma$).

$S[0, j, 0]$ for $-p(n) + 1 \leq j \leq 0$ and $n < j \leq p(n)$

+   2. The machine accepts the state (1) at some time before $p(n)$. Here, we should take the convention that the $\delta$ transition function is defined for all states and all times up to $p(n)$; if $q$ is $q_{accept}$ or $q_{reject}$, $\delta(q, \sigma) = (q, \sigma, stay)$ for all $\sigma$—this essentially extends the transition function to remain in accepting or rejecting states once.

$Q[1, 1] \vee Q[2, 1] \vee Q[3, 1] \dots \vee Q[p(n), 1]$
