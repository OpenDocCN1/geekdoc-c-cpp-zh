10. At each step t, 0 ≤ t ≤ p(n) - 1, the machine moves to a legiti-mate choose from its δ function. We can start writing this as follows: suppose that in state s, reading symbol k, there are j possible moves m, in the δ relation.

That is, in time t, if the machine is in state s and the current symbol is k (so the head must be on square h that contains the symbol k), then at time (t + 1) the configuration must change to one of the j choices:

```
Q[t, s] ∧ H[t, h] ∧ S[t, k] ⇒ m1 ∨ m2 ... ∨ mj
```

We will be of the form Q[t + 1, s'] ∧ H[t + 1, h'] ∧ S[t + 1, k'], with h' = h ± 1, and s' and k' the new state and symbol from δ.

With some effort and applications of Boolean logic, these become clauses:

```
(¬Q[t, s] ∨ ¬H[t, h] ∨ ¬S[t, k] ∨ Q[t, s'])
```

```
(¬Q[t, s] ∨ ¬H[t, h] ∨ ¬S[t, k] ∨ H[t + 1, h'])
```

```
(¬Q[t, s] ∨ ¬H[t, h] ∨ ¬S[t, k] ∨ S[t, h, k'])
```

(We can drop the ∧’s and make these three separate clauses.)

# 8.8.2 Proof Part II: Construction in Polynomial Time and Correctness

+   1. Polynomial time: Each group of clauses consists of a polynomial number of polynomial clauses. Thus, putting these together with ∧ to make a Boolean clause in conjunctive normal form, we get a long—but still polynomially bounded—clause.

+   2. Yes goes to yes: If the Turing machine accepts the string, then there is a path—a sequence of configurations—from the start state to accept it. That sequence will guide how to set the Boolean variables—at each step t, set them to match the configuration and the moves used. Now, the clause will be satisfied.

+   3. Yes comes from yes (no goes to no): Suppose that the Boolean clause is satisfiable. Then the first set of clauses says that the Turing machine began as it should, and the clause that says that it has reached q_accept by time p(n) says that it accepted its input.
