## 9.9 SUBSET SUM

The last decision problem that answer is Subset Sum. Here, we are given a multiset (which have repeated elements) of $n$ integers, $S = \{I_1, \dots, I_n\}$ and a target $T$. The question is, can one choose subset of the integers $S' = \{I_1, \dots, I_j\}$, $j \le n$, so that the sum of the integers in $S'$ is $T$?
For example, if $S = \{32, 47, 74, 22, 9, 50, 15, 18, 9\}$ and $T=100$, then there is a yes instance since the sum of the underlined integers is 100.
