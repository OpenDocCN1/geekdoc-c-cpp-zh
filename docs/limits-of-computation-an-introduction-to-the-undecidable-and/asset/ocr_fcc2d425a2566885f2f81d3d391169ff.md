In modified English:

+   1. If the string is empty, reject.

+   2. Check if the string is length 1 (move right one square; if blank, length was 1).

If length was 1, move back to the single character and accept if it is 1.

+   3. If length > 1, move to left end and blank one character; move to right end and blank out another.

+   4. Repeat steps 1–3 until accept or reject.
