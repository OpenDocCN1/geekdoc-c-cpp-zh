Theorem: If $L_1 \le L_2$ and $L_2$ is decidable, then so is $L_1$.

Theorem: If $L_1 \le L_2$ and $L_1$ is undecidable, then so is $L_2$.

Theorem: If $L_1 \le L_2$, then $\overline{L_1} \le \overline{L_2}$.
