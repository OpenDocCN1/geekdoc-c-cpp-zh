Given a Turing machine, it is undecidable whether the Turing machine accepts any string at all (whether its language is nonempty).

# Theorem 7.9

Given a Turing machine, it is undecidable whether the Turing machine accepts all strings (whether its language is Σ*).

# Proof

Once more, exactly the same construction of M’ from M will work.

+   M accepts w ⇒ L(M') = Σ* ⇒ M’ accepts all strings.
M does not accept w ⇒ L(M') = ∅ ⇒ M’ does not accept all strings.
