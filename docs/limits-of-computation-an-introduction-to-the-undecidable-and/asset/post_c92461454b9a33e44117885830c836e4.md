## Definition 5.5

A two-tape Turing machine $M = (\Sigma, \Gamma, Q, q_{accept}, q_{reject}, q_{start}, \delta)$ differs from the definition of an ordinary Turing machine only in the delta function, which maps a state, a symbol from tape 1, and a symbol from tape 2; writes new symbols to two tapes; and moves the two heads left or right (unless it also has a stay option).

```
\delta: Q - \{q_{accept}, q_{reject}\} \times \Gamma \times \Gamma \rightarrow Q \times \Gamma \times \Gamma \times \{Left, Right\} \times \{Left, Right\}
```

The convention is that the machine begins with the input written on the first tape in the usual way, and the second tape begins blank.

**Note:** For many uses of multitape Turing machines, the stay option is very convenient—so that one head can remain in place while another head moves. Thus, we will generally assume a delta function of the form

```
\delta: Q - \{q_{accept}, q_{reject}\} \times \Gamma \times \Gamma \rightarrow Q \times \Gamma \times \Gamma \times \{Left, Right, Stay\} \times \{Left, Right, Stay\}
```

To see how this is, think of a simple example as $L = \{strings\ of 0's\ and 1's\}$ that the number of zeros is equal to the number of ones. This can be done on one tape by moving back and forth, crossing out a zero and a one on each, and finding if all characters are crossed out on the same pass. With three tapes, (1) move across the input once, copying each zero to tape 2 and each one to tape 3. Then (2) pass back across these two tapes, checking that heads on tape 2 and tape 3 hit the blank at the same time, so that the count of 0s must have equaled the count of 1s. Or, to accept the language of palindromes, $\{w | w = w^R\}$, simply copy the input to tape 2 and run two heads, one forward across the string and the other backward, checking that the symbols match (Figure 5.3).

## Theorem 5.6

Any $k$-tape Turing machine $M$ has an equivalent one-tape Turing machine $M'$. $t$ steps of $M$ can be emulated in $Kt$ steps of $M'$, where $K$ is a constant. Thus, if an algorithm is bounded by $t(n)$ steps on an input of size $n$ on a $k$-tape machine, it is bounded by $Kt(n)$ steps on a one-tape machine.

## Proof

As in emulating a two-way infinite tape on a semi-infinite tape, there are many choices for building $M'$. All the information from the $k$-tapes must be put onto one tape. Each tape can have a finite string on it, and each tape has its own head position.

A standard trick for encoding head positions is to double the alphabet—for each symbol $\sigma$ in $\Sigma$, add another symbol $\sigma'$. Thus, when tape $i$ is put onto the single-tape machine, the presence of the head on a cell will be encoded as that symbol with its prime.
