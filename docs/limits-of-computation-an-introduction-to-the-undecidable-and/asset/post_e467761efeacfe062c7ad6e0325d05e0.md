## 8.9 CONCLUSION

The above transformation takes any nondeterministic TM that can reach an accept state and transforms it into a set of Boolean clauses that can be satisfied, and vice versa. This shows that any problem in NP can be polynomially transformed to CNF-SAT.

Thus, the collection of NP-complete problems now has its first known member.

This is critical, for now other members of NP can be added to the set of NP-complete problems just by producing a polynomial transformation from a known NP-complete problem. There is only one known NP-complete problem now use, but there is now a starting place. Each problem that is added to the set of NP-complete problems will yield one more language to use as a starting point.

## 9.1 ADDING OTHER PROBLEMS TO THE LIST OF KNOWN NP-COMPLETE PROBLEMS

The next order of business will be adding members to the collection of NP-complete problems. No other proof will be that of Cook-Levin, beginning with arbitrary members of NP and depending on the definition of NP-completeness. Instead, all these proofs use polynomial reducibility.
