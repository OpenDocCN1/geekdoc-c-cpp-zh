# 10.5.1 Linear Programming

Until 1979, when Linear Programming was shown to be in P, it was considered a possible candidate for NP-intermediate.

Given m integer vectors (V1 ... Vm) of length n, vectors D of length m (d1 ... dm), and C of length n (c1 ... cn), and integer target T, there is a vector X, X = (x1 ... xn) such that

```
V · X ≤ d, for all i, 1 ≤ i ≤ m
C · X ≥ T
```

The operator is the dot product of two vectors, = (x1 ... xn).(y1 ... yn) = x1y1 + x2y2 + ... + xnyn.

In NP: The certificate is the vector X.
In P: The polynomial algorithm is found (Khachian, 1979).
