# 7.3 REDUCIBILITY AND LANGUAGE PROPERTIES

If you know something about one language L$_1$ and know how it is related
to another language L$_2$ by reducibility, then some properties follow easily.
These include:

# Theorem 7.3

If L$_1$ $\le$ L$_2$ and L$_2$ is decidable, then so is L$_1$.

# Theorem 7.4

If L$_1$ $\le$ L$_2$ and L$_1$ is undecidable, then so is L$_2$.

# Theorem 7.5

If L$_1$ $\le$ L$_2$, then $\overline{L_1}$ $\le$ $\overline{L_2}$ .

# Theorem 7.6

If L$_1$ $\le$ L$_2$ and L$_2$ $\le$ L$_3$, then L$_1$ $\le$ L$_3$.
