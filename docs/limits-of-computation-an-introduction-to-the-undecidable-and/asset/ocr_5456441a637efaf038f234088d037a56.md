# Example

is vertex w reachable from vertex v in a graph G? (That is, is there a
path from v to w?) There are polynomial algorithms for finding
t shortest path from v to w, and for finding—in polynomial time—nt length of the shortest paths between any two vertices in G.

```
Algorithm: input the graph G = V,E; vertices v and w
Let Reachable(v) = {v}
Repeat
  for each vertex vi in Reachable(v)
  for each vertex vj in the adjacency list of
    vi
    if vj is not in Reachable(v), add it to the
    set until the set Reachable is unchanged
through an iteration of the loop.
```

Analysis: constant time to initialize all conditions
for each vertex vi in Reachable(v)//this set has max size |V|
