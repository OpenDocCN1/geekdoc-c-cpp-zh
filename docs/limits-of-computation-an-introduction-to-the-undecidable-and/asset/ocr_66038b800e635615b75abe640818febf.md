# Theorem 10.6

If P $
eq$ NP, then there exist languages in NP that are not NP-complete also not in P.

# Proof

This is a diagonalization argument (Ladner, 1975), but is a complicated one. In previous diagonalizations, there has only been one diagonal. In this case, we must diagonals against both the members of P and the members of NP-complete. This is done by diagonalizing with the polynomial reductions from SAT; every member of NP-complete has one of these. Thus, we enumerate all the polynomially bounded Turing machines—and construct a language not decided by one of these, and so not in P. We also enumerate all the polynomial reductions from SAT—and construct a language not reduced by one of these, and so not in NP-complete.

$M_{SAT}$ be a TM that decides SAT. An easy exponential algorithm exists to construct the whole truth table; it is not known if a polynomial time algorithm exists.

To enumerate the polynomially bounded deciding Turing machines (TMs): $M_{p_1}$, $M_{p_2}$, ..., $M_{p_i}$, ..., do the following:

+   Enumerate the TMs: $M_1$, $M_2$, ..., $M_i$, ...
Enumerate the polynomials: $n$, $n^2$, ..., $n^k$, ...
Enumerate the pairs ($M_i, n'$); We can make this pair into a polynomially bounded TM (by running $M_i$, until time $n=n$; if it has not yet accepted, stop and reject).

This is now an enumeration of the polynomial-bounded TMs since (1) and (2) every polynomially bounded TM will appear in the enumeration (why?).
