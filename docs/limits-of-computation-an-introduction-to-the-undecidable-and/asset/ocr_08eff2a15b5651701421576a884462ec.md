# Theorem 9.18

3DM is NP-complete.

+   1. 3DM is in NP. Left to the reader (see the Exercises).
2. 3SATₖ 3DM.

Beginning with an instance of 3SAT with variables xᵢ ... xₙ and clauses cᵢ ... cₙ we need to construct three sets X, Y, Z as well as P, the set of triples.
We start with the set X of 2 elements xᵢ,ⱼ and ¬xᵢ,ⱼ, 1 ≤ i ≤ n, 1 ≤ j ≤ m. Essentially, choosing xᵢ,ⱼ will correspond to “xᵢ,ⱼ is true in clause j” and ¬xᵢ,ⱼ will mean “xᵢ, is false in clause j.” Of course, something else must be done to ensure that:

+   a. Each xᵢ, is either true or false.
b. If true in one clause, it is true in all other clauses (and likewise false).

We begin Y and Z by putting m elements fᵢ, 1 ≤ i ≤ m into Y and gⱼ, 1 ≤ j ≤ m into Z. We begin the set of triples P by adding “satisfying” triples. The number of these triples will vary depending on the structure of the clauses. Each clause has length 3, but may contain a repeated literal (so will contain between one and three distinct literals). Thus, there will be triples between one and m such triples.

```
(xᵢ,ⱼ, fᵢ, gⱼ) for 1 ≤ j ≤ m if the variable xᵢ, occurs in clause j.
(¬xᵢ,ⱼ, fᵢ, gⱼ) for 1 ≤ j ≤ m if the variable ¬xᵢ,ⱼ occurs in clause j.
```

The f and g will appear in no other triples, to put them into a matching for each, either (xᵢ,ⱼ, fᵢ) or (¬xᵢ,ⱼ, fᵢ, gⱼ) must be chosen, as shown in Figure 9.17.
