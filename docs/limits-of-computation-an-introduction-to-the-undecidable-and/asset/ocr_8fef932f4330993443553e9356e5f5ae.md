# 58 ■ Limits of Computation

10. Give an algorithm that determines whether a given undirected graph G = (V, E) contains a cycle. (A cycle is a path from a vertex back to itself.) What is the order of your algorithm? Can you find an O(|V|) algorithm, that is, linear in the number of vertices and independent of the number of edges?

11. Give the O relationships between:

+   a. f(n) = log n and g(n) = log n
b. f(n) = log₂ n and k(n) = log₁ n
c. f(n) = log n and g(n) = log (n²)
d. g(n) = log n and h(n) = (log n)²
e. f(n) = 2^n and g(n) = n!

12.

+   a. Write an algorithm in pseudocode to find the average of n integers.
b. What is the order of this algorithm if the integers are bounded in size?
c. What is the order if the integers can be arbitrarily large?

13. Consider two algorithms for division of integers, n divided by m: (a) repeated subtraction and (b) the one you learned for long division in elementary school. Write out both algorithms in pseudocode (using numbers in base 10 or base 2, whichever you prefer) and analyze their orders.

14. Write (pseudocode) algorithms for each of the following, and give their order:

+   a. Add an element to the beginning of a linked list of length l.
b. Add an element to the end of a linked list of length l.
c. Add an element to the correct location of a sorted linked list of length l.
d. Multiply two n × n matrices.
e. Find the first occurrence of the substring aa in a string of length n.
