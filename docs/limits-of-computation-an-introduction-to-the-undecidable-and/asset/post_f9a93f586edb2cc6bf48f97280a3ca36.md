## 9.8 THREE-DIMENSIONAL MATCHING (3DM)

The three-dimensional matching problem is best understood by considering a simpler example, the two-dimensional matching (2DM) problem, which is often stated as the marriage problem. There is a relatively simple polynomial algorithm for solving 2DM, so 2DM is highly unlikely to be NP-complete.

Suppose you have two sets X and Y (perhaps women and men), of the same size, $|X| = |Y|$. Now you have a third set P consisting of ordered pairs from X and Y, so that $P \subseteq X \times Y$. One can find that $(x, y)$ in $P$ means that $x$ is willing to marry $y$, and vice versa. The idea is to find a suitable set of marriages that everyone is paired with someone they are willing to marry. Thus, $|P|$ must be at least $|X|$ for a pairing to occur. So, if

X = \{Ann, Betty, Carol\}$

Y = \{David, Ed, Frank\}$

P = \{(Ann, Frank), (Ann, Ed), (Betty, Ed), (Carol, David), (Carol, Ed)\}

then a matching is

\{{(Ann, Frank), (Betty, Ed), (Carol, David)\}

The three-dimensional matching problem has three sets X, Y, Z and $P \subseteq X \times Y \times Z$. Perhaps we are on some planet where there are three generations, or perhaps X is the women, Y is the men, and Z is the pets, so that $(Ann, David, Fido)$ in $P$ means that Ann, David, and Fido are willing to live together.

The proof that 3DM is NP-complete is one of the more complicated component design proofs. The proof is due to Richard Karp (1972).

Many sets can be proven NP-complete by reducing 3DM to the set problem in question. Often, you just need to drop the order so that triples are viewed as sets). An example is exact by three sets (X3C), where one is given a set X (whose size is a multiple of 3) and a collection C of three-element subsets of X, and asked if some subcollection of C covers X exactly (each element of X is in one, and only one, member of C).
