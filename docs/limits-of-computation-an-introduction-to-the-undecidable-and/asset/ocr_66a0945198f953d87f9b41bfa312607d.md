Now:

M accepts w $\Rightarrow$ L(M') = L(M$_i$) $\Rightarrow$ L(M') is yes instance.
M does not accept w $\Rightarrow$ L(M')=$\varnothing$ $\Rightarrow$ L(M') is no instance.

Thus, if we can answer whether M' has the property or not, we can answer whether M accepts w. This last question is undecidable.

In other words, all nontrivial questions about the language accepted by Turing machines are undecidable. There are not any interesting trivial questions—that would be a contradiction. “Is composed of strings” is a trivial question. On the other hand, other questions (“Is the language finite?” “Does it contain some string of length 5?” “Does it contain all strings with prime length?”) are nontrivial questions.

Questions about the Turing machine itself are often—but always—undecidable. For example, consider the following questions about a Turing machine:

Decidable: “Does the machine have a state $q_{271}$?”
“Does enter $q_{271}$ on the empty string in less than 57293 steps”

Questions are decidable if they can be answered by inspection of the transition function, or if they ask about a limited operation of the Turing machine.

Undecidable: “enters $q_{271}$ on the empty string”

“enters $q_{271}$ on any string whatsoever”

Questions are undecidable if they relate to what strings the machine accepts. The questions above would be more obviously undecidable if $q_{271}$ were replaced by $q_{accept}$.

Undecidable does not mean “never has an answer”. For some machines, one could look at the transition function and perhaps note that $q_{271}$ never appears on the right-hand side of any move. It would never be possible to enter that state. What undecidable means that there is no way of answering the question for all possible legal inputs. More about this in the next section.
