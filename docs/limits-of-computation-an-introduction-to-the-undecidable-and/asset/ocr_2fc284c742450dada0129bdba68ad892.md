```
Algorithm for UTM
Find current (state 2) and current symbol (next 0's after head on tape 3) on tape 1
In this case, state = 000; finds 11010010001000010011
Update tape 2 to new state
Update tape 3 to new symbol (add or erase 0's)
Move head to next group of 0's, left or right
If state = 00 or state = 000 (accept or reject)
Else repeat
```
