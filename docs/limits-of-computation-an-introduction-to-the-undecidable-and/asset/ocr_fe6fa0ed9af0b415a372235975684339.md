# 10.8 NPSPACE = PSPSPACE

There is a surprising relationship between nondeterministic space bounds and deterministic space. Recall that a major recurring theme has been the fact that it is unknown whether P = NP. However, for space, the answer to the analogous question is known.

We could define NPSPACE as the set of problems that can be accepted by a nondeterministic Turing machine in polynomial space; that is, those that have at least one path to q_{accept} that requires no more than a polynomial amount of space (strings in the language).

# Theorem 10.9 (Savitch, 1969)

If a decision problem X can be recognized by a nondeterministic Turing machine in space bounded by s(n), where n is the length of the input, X can be recognized by an equivalent deterministic Turing machine in space bounded by s^2(n).
