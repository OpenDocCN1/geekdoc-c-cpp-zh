Limits of Computation

FIGURE 6.9 Action of infinite loop Detector P.

If P exists, it must take any program S with input I and announce "yes, halts" or "no, never halts." It might do this announcement by writing one of the two phrases to the screen. This is shown in Figure 6.9.

We can easily change P to P_Rev (read as "P revised") with the following three changes.

+   1. Use self as input: Instead of inputs S and I, now P_Rev takes only one input S and will decide what S does on S.
2. Turn "yes" into a loop: If P would write "yes, halts," then P_Rev goes into an infinite loop.
3. Turn "no" into "yes": If P would write "no, never will halt," then P_Rev writes "yes, halts" and stops.

Imagine how to do this: a pattern search through P. Any statement of the form

```
writeln ("yes, halts")
```

is replaced by

```
while true do x := 1
```

And any line of the form

```
writeln ("no, never will halt")
```

is replaced by

```
writeln ("yes, halts"); exit (0);
```

This revised program P_Rev works on all possible input programs, since P does. In particular, one can ask what P_Rev does when fed its own code.
