If one is working on what would have been the right side of the two-way
infinite tape, a move on the right is done by moving two “new"
cells; likewise a move left is a move by two.

For example, if the usual Turing machine has the δ(q₂,₆, 1) = 1,

semi-infinite tape machine will need to (1) write 1, (2) move one cell,
and (3) write the next symbol (for any σ in Σ), move again,
and go to q₅₃,right.
