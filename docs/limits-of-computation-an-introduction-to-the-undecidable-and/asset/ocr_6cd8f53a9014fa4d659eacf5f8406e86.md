# 6.2 Writing "to Hello World."

(2) the input to program (if the program takes input). Determine either: (a) yes, this program on this input will sometime write "Hello World," or (b) no, this program on this input will never write "Hello World."

You cannot solve this task by running the code on it input—that might work, but the only time you have a guaranteed answer is when you see the "Hello World" appear. And, to be a correct program or algorithm, it must work correctly for all inputs. If it executes the program and sees the words "Hello World" as output, and if no output appears—after a minute, an hour, a day, a week, whatever—it could not say that the code never writes "Hello World." The test program might be just getting to the point where it will write the phrase.
