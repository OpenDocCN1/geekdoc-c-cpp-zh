# 3.6.3 Size of the Input

Counting the size of the input string $x$ deserves a moment of discussion. This size of the input will be important, and will get further discussion later in the text. In these examples, the input consists of two integers, with two digits. As input, one cannot write them together (where does one stop 6018?), so the length of the input is the number of digits in the first number + the number of digits in the second number + 1 for a separating character. Thus, if the input $x$ is the pair of numbers 60 and 18, it can be written as $x = 60\#18$, and $|x| =5$. For the pair of numbers 600,132,157 and 18,924, the size of the input would be 18 (or 15 if we drop the three commas).
