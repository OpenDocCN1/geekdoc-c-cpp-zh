# Theorem 1.18 (Cantor)

There is no one-to-one correspondence between the set of all natural numbers and the set of reals R[0,1).

The proof is not difficult. First, let's represent all numbers in binary. Second, to make the representation for a binary fraction unique, we need to disallow any infinite sequence of 1's. For example, these two numbers denote exactly the same number:

```
0.001111111... = 0.010000...
```

so we use the second representation for the number 1/4.
(You may ask why the two numbers above are the same. Two numbers are only different if there is some distance between them, or, when you subtract one from the other, you do not get zero. Try the above subtraction.)
