# Undecidability and Reducibility ■ 149

For each symbol $\sigma$ in $\Gamma$, add

$\sigma_{q_{accept}}, \quad q_{accept}\sigma$ (top length 2, bottom length 1)\n$q_{accept} \quad q_{accept}$

These moves containing $q_{accept}$ are the only string pairs with a top longer than the bottom.

# Example

Consider a very simple TM that accepts strings over {0, 1} with the second symbol equal to 1. One TM for this language (though perhaps not the simplest machine, note that this is not a deciding machine) is shown in Figure 7.2. It is not a deciding machine.

This accepts 0101 by the following sequence of configurations (written with the head position by embedding the state in the string)

```
$q_0010 \rightarrow 0q_1 \rightarrow 01q_{accept} 0$
```

The start domino, or pair, for MPCP is

```
##\n##q_0010##
```

The first move is $q_0, \rightarrow q_1, 0, R$, so we use the tile that corresponds to this move, and extend the string by

```
$q_00\n0q_1$
```
