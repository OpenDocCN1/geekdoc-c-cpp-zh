A leftmost derivation is a chain of rules, beginning with the start symbol and ending with a string over Σ*, such that at each step, the leftmost variable is replaced by one of its right-hand sides.

# Example

In C, a block statement begins with { and ends with \}. Inside the braces, there can be any number of statements. Each statement is followed by a ;.
For this example, let s, standing for statement, be a terminal:

```
Σ = {s, '{', ';', '}', '}'} $\quad$ V = {S, SL}
```

```
S → {SL}
SL → s; SL
SL → ε
```

When two or more rules have the same left-hand side, they can be written together with | (for or). For example, SL → s; SL | ε.
Leftmost derivation for {s; s; s}:

```
S → {SL} → {s; s; SL} → {s; s; s; SL} → {s; s; s; s}
```

# Definition 7.19

A grammar is ambiguous if some string that it generates can be generated in more than one way (has more than one leftmost derivation).

# Example

Simple grammar for arithmetic expressions over the variables a, b, c:

```
Σ = {a, b, c, +, *, /, (, )}} $\quad$ V = {E}
```

```
E → E + E | E - E | E * E | E/E | (E)
→ a | b | c
```
