# 7.2 REDUCIBILITY

Definition 7.1

Suppose $P_1$ and $P_2$ are decision problems. Then $P_1$ is **reducible** to $P_2$, written $P_1 \leq P_2$, if there is a mapping $f$ from all possible instances (yes or no) of $P_1$ to possible instances of $P_2$ such that:

+   1. $f$ is computable (that is, some Turing machine—or transducer—can compute).
2. If $X$ is a yes instance of $P_1$, then $f(X)$ is a yes instance of $P_2$.
3. If $X$ is a no instance of $P_1$, then $f(X)$ is a no instance of $P_2$.

Note that 3 can be rewritten equivalently as:

3'. If $f(X)$ is a yes instance of $P_2$, then $X$ is a yes instance of $P_1$

since 3' is the contrapositive of 3. That is, “no goes to no” is equivalent to “yes comes from yes.” This second form is often easier to use in proofs.

This mapping can be visualized; see Figure 7.1

Conditions 2 and 3 say that answering $P_2$ will also answer $P_1$. That is, if one looks at $f(X)$ and answers it is a yes (or no) instance of $P_2$, then it immediately follows that $X$ was a yes (or no) instance of $P_1$.
