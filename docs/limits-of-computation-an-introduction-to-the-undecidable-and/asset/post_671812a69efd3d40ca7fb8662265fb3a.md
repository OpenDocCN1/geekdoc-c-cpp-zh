## DOES MY PROBLEM HAVE A SOLUTION? GOOD SOLUTION?

The computer scientist should be aware—of questions like these, and if told to write code to solve problem X, it would be nice to know that X has a solution and that this solution will not require centuries or millenia to execute.

Questions to consider before beginning: Is there a known algorithm for this problem? Or, are algorithms that work, but take too long? A problem that used to be difficult, but now has become easier, is the forecasting of weather. Weather (like many physical systems) obeys a complicated set of differential equations, and it can be forecast by getting initial data points—the current weather—and solving these equations. However, if it takes longer to solve the equations than for weather to happen, these forecasts are not useful. It does not do much to have the forecast for Tuesday on the following Wednesday. Problems like this one generated research in methods for solving differential equations, and considerable progress has been made.

But what problems are like this—solvable with good methods? Are there any problems that are difficult and not that we can expect ever to have good solutions?

Of course, if one needs a solution to a problem that has no solution—or no reasonable solution—then here too, some knowledge is useful. It is not necessary to give up and say, “Can’t be done.” Knowing the difficulties (and the options around them) is the first step.

## 1.1 SETS—BASIC TERMS

A set is a collection of objects.

A member or element is an object in a set. A set is said to contain its elements. Elements in a set are listed in braces.

A well-ordered set is a set in which there is a natural ordering of the elements such that for any distinct elements $e_1$ and $e_2$ in the set, either $e_1 < e_2$ or $e_2 < e_1$.

## Definition 1.1

The set A is a subset of set B, denoted $A \subseteq B$, if and only if (iff) every member of A is also a member of B.

## Definition 1.2

The empty set, denoted $\varnothing$, is the set {}. It contains no elements.

## Definition 1.3

The set A is a proper subset of set B iff every member of A is also a member of B and $A \neq B$, denoted $A \subset B$.

## Definition 1.4

The standard set operations are union, intersection, difference, and complement. They are defined as:

- The **union** of two sets A and B, denoted $A \cup B$, is the set $\{x \mid x \in A \text{ or } x \in B\}$.
- The **intersection** of two sets A and B, denoted $A \cap B$, is the set $\{x \mid x \in A \text{ and } x \in B\}$.
- The **difference** of two sets A and B, denoted $A - B$, is the set $\{x \mid x \in A \text{ and } x \notin B\}$.
- The **complement** of a set A, denoted $A^c$, is the set $\{x \mid x \notin A \text{ and } x \in U\}$.

## Definition 1.5

A **multiset** is a set in which the repetition of elements is important. Order is still irrelevant in a multiset.

## Definition 1.6

The power set of A, denoted $P(A)$, is the set of all subsets of A.

The Cartesian product or cross-product of two sets A and B, denoted $A \times B$, is the set $\{(x, y) : x \in A \text{ and } y \in B\}$.

## 1.2 FUNCTIONS

A **function** or mapping from set A to set B (written $f: A \to B$) is a subset of $A \times B$ such that each $x \in A$ is associated with a unique $y \in B$.

For $f: A \to B$:

- A is called the **domain** of $f$.
- B is called the **codomain** of $f$.
- If $f(x) = y$:
- $y$ is called the **image** of $x$ under $f$
- $x$ is the **preimage** of $y$ under $f$.
