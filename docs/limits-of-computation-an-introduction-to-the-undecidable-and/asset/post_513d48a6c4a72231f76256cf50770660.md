Single dominos can be repeated—have duplicates. That is, there are $n$ different dominos, but each domino has an unlimited number of copies. Think of the problem as having a finite number of patterns, but an infinite number of copies of each pattern. Note also that once there is a solution, then any concentrated repetition of this solution is also a solution. Thus, there is a shortest solution, but no longest solution, since the supply of dominos never runs out.

# Definition 7.13

**Post Correspondence Problem (PCP):** Given $\Sigma$, and $n$ pairs $(a_i, b_i)$, $i = 1, \dots, n$, with $a_i$ and $b_i$ strings from $\Sigma^*$ (no string be empty), is there a sequence $i_1, i_2, \dots, i_k$ of integers, not necessarily distinct, $1 \leq i, j \leq n$, so that

$a_{i_1}a_{i_2}\dots a_{i_k} = b_{i_1}b_{i_2}\dots b_{i_k}$

Note that here we are writing the top and bottom of the tile as the pair $(a_i, b_i)$. That is, $(a_i, b_i)$ is another way of writing

$\frac{a_i}{b_i}$

This problem will turn out to be undecidable—there is no algorithm to solve it. If one bounds the problem—adds a number $K$ that $k \leq K$, then the problem is solvable in exponential time (try all subsequences), and is **NP**-complete (see Chapters 8 and 9).

# **MODIFIED PCP (MPCP)**

To prove PCP, we begin with a modified version. The idea is to simplify the proof. In this modified version, there are two special dominos, or four special strings—a starting pair $a_{start}, b_{start}$, and a final pair $a_{last}, b_{last}$, plus a set of $(a_i, b_i)$, $i=1, n$.

Then the question becomes, does there exist a sequence so that

$a_{start}a_{i1}a_{i2} \dots a_{ik}a_{last} = b_{start}b_{i1}b_{i2} \dots b_{ik}b_{last}$

Example:

$$\frac{a_{start}}{b_{start}} = \frac{1}{10}, \frac{a_1}{b_1} = \frac{0100}{10}, \frac{a_2}{b_2} = \frac{0110}{0}, \frac{a_3}{b_3} = \frac{1}{011}, \frac{a_{last}}{b_{last}} = \frac{1}{01}$$

Then we can make the string $1$ $0100$ $1$ $01100$ $1 = a_{start}a_1a_2a_3a_{last} = b_{start}b_1b_2b_3b_{last}$.

$10$ $011$ $011$ $001$ $001$

Note that one of the starting strings must be a prefix of the other; similarly, one of the last strings must be a suffix of the other. For these reasons, even without the restrictions of MPCP, $a_i$ could not start or end the matching.
