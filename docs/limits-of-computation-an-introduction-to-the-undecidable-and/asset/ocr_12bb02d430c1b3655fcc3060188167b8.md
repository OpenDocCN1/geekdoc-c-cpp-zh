If one encodes a Turing machine followed by its encoded input string, note that one can find the end of the machine and the beginning of the string at the point where four 1's appear.
Thus any TM, with input, can be encoded as a string of 0's and 1s. Does any string of 0's and 1s correspond to the encoding of a TM? Not unless we take the convention that it does. Note that no string that we get as the encoding of a Turing machine has more than four consecutive 1's (and never has three in a row). And, the pattern of pairs on 1's is constrained at the start and end of moves. The transitions be a function (never more than one move from a given state, symbol pair) makes more constraints on what can be a legal TM encoding.
