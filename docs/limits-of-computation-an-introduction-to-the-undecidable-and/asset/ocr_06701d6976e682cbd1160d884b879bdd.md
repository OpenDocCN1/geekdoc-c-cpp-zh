And since any number of new unreachable states could be added, there is an infinite number of Turing machines that accept the same language. They appear superficially, though actually act on a string in the same way.\ Nortrivially, there are often multiple ways to approach a problem. For example, another way of accepting strings whose last symbol is 1 is to use the state to remember the last symbol read, and accept if the machine hits a blank when the last symbol read was 1.
