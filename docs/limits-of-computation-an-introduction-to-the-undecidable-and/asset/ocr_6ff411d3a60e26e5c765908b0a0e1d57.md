Languages 25

$L_2L_4 = \{w \mid w \text{ contains any number of 0's followed by any number of 1's}\}$

$L_2L_5 = L_2$

$L_4L_6 = L_6$

The concatenation of a language L with itself multiple times can also be written with the **repetition** operator.

# Examples

Consider the following languages over {0, 1\}:

$L_1 = \{0, 11\}$

$L_2 = \{w \mid \text{the length } |w| = 2\}$

$L_3 = \{\varepsilon\}$

$L_4 = \varnothing$

Now:

$L_1^2 = \{00, 011, 110, 1111\}$

$L_1^3 = \{000, 0011, 0110, 1100, 01111, 11011, 11110, 111111\}$

$L_2^2 = \{w \mid \text{the length } |w| = 4\}$

$L_2^k = \{w \mid \text{the length } |w| = 2k\}$

$L_3^k = L_3$

$L_4^k = L_4 \text{ for } k > 0$

The **Kleene star** (or **Kleene closure**) of a language is $L^* = L^0 \cup L^1 \cup L^2 \cup L^3 \cup \dots$ Note that $\varepsilon$ is always in $L^*$ for any language L.
