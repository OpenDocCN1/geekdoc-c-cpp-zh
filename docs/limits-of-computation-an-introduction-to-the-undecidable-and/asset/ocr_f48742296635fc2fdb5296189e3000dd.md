# 7.4 REDUCIBILITY TO SHOW UNDECIDABILITY

So far, it has been proved that the problem ACCEPT$_{TM}$ ={<M,w>} M and w are encoded Turing machines and strings, and M accepts w is undecidable. For a different problem, we will be able to show P is undecidable by finding a mapping from ACCEPT$_{TM}$ to P.

There is fairly standard procedure for building this mapping from ACCEPT$_{TM}$ to P.

+   1. Build a yes/no instance L' = L(M') of P. M' will be a Turing machine with input x' over some alphabet Σ'.

How do we build this and what Σ' is vary. One thing that almost never varies is that M' has M and w built into it—that is, M' depends on M and w, or M' has M and w hard-coded into it. You can think of M as built into the state information of M', or as written on two internal tapes of M', or simply as part of M'. How one actually would build M and into M' is not important. It would take a lot of time and effort to actually do this, but it is not hard to see that it can be done.


+   2. The trick is to build M' so that the language it accepts is one of two different languages, one that is a yes instance of P and one that is no instance.

Whether it is a yes or no instance should depend on whether M accepts w or not.

There are times M' must look at its input and possibly accept before it runs on w. However, that is not the usual case.

+   3. Usual to build M':

First, run M on w. In doing this, three things could happen: (a) M accepts w, (b) M rejects w, or (c) M is looping on w, and has not—and will not—ever accept or reject.
