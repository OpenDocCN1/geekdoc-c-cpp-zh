
## Theorem 9.14

HC is NP-complete.
The proof of is in four parts:

- 1. HC is in NP
- 2. VC $\le$p HC (construct transformation, show it is a polynomial)
- 3. VC $\le$p HC (yes goes to yes)
- 4. VC $\le$p HC (comes from yes)

### 1. HC is in NP.
The certificate $c$ is obviously the circuit. Without loss of generality, we can assume that any circuit starts and ends at the first vertex $v_i$, so there is no need to include $v_i$ in the certificate. Now, what do we need to check?

HAMILTONIAN-CIRCUIT-VERIFY(G, c) =

- Check that each element of $c$ is a vertex in $G$.
- Check that each element of $c$ is distinct.
- Check that $|c| = n - 1$.
- Check that $v_i$ is not in the certificate.
- Check that $\{v_{n-1}, v_i\}$ is an edge in $V$.
- Check for each $c_i, c_{i+1}$ in $c$, $1 \le i \le n - 2$.
- Check that $\{c_i, c_{i+1}\}$ is an edge in $V$.

Clearly, each of the steps needed to verify the certificate is polynomially bounded.

### 2. VC $\le$p HC. An instance of VC has a graph $G = (V, E)$ and an integer $m$. We will use a (fairly complex) version of local replacement to build a new graph $G' = (V', E')$ so that $G'$ has a Hamiltonian circuit if and only if $G$ has a vertex cover of size $m$.

- a. The integer $m$ in VC becomes $m$ vertices $a_1, \dots, a_m$. There are no edges from any $a_i$, to any $a_j$ for $i \neq j$.
- b. Each edge $\{v_i, v_j\}$ in $G$ becomes a gadget, which is a set of 12 vertices (in two rows of 6, one row labeled $v_{i,j,i,1}$ to $v_{i,j,i,6}$, the other labeled $v_{i,j,j,1}$ to $v_{i,j,j,6}$ and 12 edges (down sides, four edges on each side, with four edges making two $X$ shapes, as shown in Figure 9.10 for the edge $\{v_i, v_j\}$).

Note: The first subscript $i, j$ is only necessary to differentiate the vertices-v from edge $\{i, j\}$ from the six very similar vertices that come from edge $\{i, k\}$. We will drop that pair of subscripts in most of our diagrams. See the simpler figure on the right side of Figure 9.10.

We will call these complicated subgraphs "flags" since they have some resemblance to maritime signal flags.

The flags will be connected to other parts of the graph only at the four corners. This means that any path visiting the nodes in the flag enters at one corner, exits at another corner, and there are only two ways to visit all the nodes in the flag visit half of the vertices on this pass—come at one corner, go straight up or down—and to visit the other side on a different pass (left side of Figure 9.11). Another path might be to come in a corner (for example, upper left), go down, over and up, back across, and out the corner on the same side as the corner one came in on. Of course, this has a similar path coming in upper right. These options are the second and third shown in Figure 9.11.

Order the edges out of $v_i$ in any order (one way is to start with any one first, then order clockwise). Connect the $v_i$ sides in this order (last of the first to first of the next; last of one to first of the next, etc).   i. This example of component design is a polynomial transformation.
  ii. A instance of VC goes to a yes instance of HC.
  iii. A yes instance of HC comes from a yes instance of VC (note that this is the same as a no instance of VC goes to a no instance of HC).

## Decision TSP is NP-complete. Given a weighted graph G with $v_1 \dots v_n$ and edges $e_{ij}$ with positive weight $w_{ij}$ between pair of $v_i, v_j$, and a bound $K$, does G have a path that starts at $v_1$, visits every vertex of G, and returns to $v_1$ such that the length is less than $K$?

## Traveling Salesman Problem (TSP) is NP-hard. Given a weighted graph $G$ with vertices $v_1 \dots v_n$ and edges $e_{ij}$ with positive weight $w_{ij}$, what is the length of the shortest path that starts at $v_1$, visits every vertex of $G$, and returns to $v_1$?

Note: Since this problem is not a decision problem, it is not a candidate for the class of NP-complete, but if one could solve this, one would have a solution to the K-decision TSP.

## 9.7 Eulerian Circuits (AN INTERESTING PROBLEM IN P)

An interesting note is the problem of Eulerian circuits An Eulerian circuit is a path through the graph from $v_i$ back to $v_i$ such that every edge is included in the path. Eulerian circuits are not required to be simple paths; they can visit a vertex more than once.

The famous Bridges of the Königsberg puzzle can be transformed into an Eulerian circuit problem. One could take a Sunday stroll in the city of Königsberg that would cross each bridge exactly once? The transformation is made making vertices out of islands and mainlands, and connecting land masses if there is a bridge from one to the other. Figure 9.16 shows a map of 1700s Königsberg with the associated multigraph (a multigraph has more than one edge between some pairs of vertices).

It is easy to prove that an Eulerian circuit exists if and only if every vertex has an even degree. This test can easily be done in polynomial time.
