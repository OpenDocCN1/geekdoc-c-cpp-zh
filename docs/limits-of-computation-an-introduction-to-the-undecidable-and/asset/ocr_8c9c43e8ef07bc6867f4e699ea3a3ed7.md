# 230 Limits of Computation

Subset Sum (almost certainly) not strongly NP-complete, since if T is bounded by a polynomial in the length of the input, nT then we have an algorithm bounded by nT, and nT is polynomial in the length of the input. It can only remain NP-complete with bounded T if P = NP.

For the NP-complete problems that do not have numbers (e.g., SAT), there is no difference between polynomial and pseudo-polynomial. They cannot have polynomial or pseudo-polynomial algorithms unless P = NP.

There are other problems that have numbers, but the numbers are small numbers compared to the size of the input. For instance, VC has a number K, the size of the vertex cover. K must be smaller than |V|. Any pseudo-polynomial algorithm in K would be a polynomial in |V|. Such problems cannot have pseudo-polynomial algorithms unless P = NP.

The decision version of the Traveling Salesman Problem (TSP) is a number problem, since the weights on the edges can be arbitrarily large. However, even if the weights are bounded by a small integer (even 1 or 2), it can be shown to remain NP-complete (see the Exercises). Thus, it is an example of a number problem that is strongly NP-complete.

Multiprocessor Scheduling (defined in the Exercises) is another number problem, and is also strongly NP-complete.

# 10.3 COMPLEMENT CLASSES

A natural operation on sets is to consider the complement; a natural operation on decision problems is to consider the instances. For example, a yes instance of CNF-SAT is a Boolean expression in conjunctive normal form that is true for any assignment of truth and false to its variables. A no instance is a Boolean expression, again in conjunctive normal form, that is never for any assignment of truth values to its variables. In other words, it is an expression whose truth table has a final column that is FALSE.
