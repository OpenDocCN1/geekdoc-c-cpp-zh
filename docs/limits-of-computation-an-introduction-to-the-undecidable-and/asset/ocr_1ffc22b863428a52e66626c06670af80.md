# EXERCISES

+   1. Prove each of the following is undecidable. Do not use Rice's theorem.
    a. The writing problem: Given a symbol $\sigma$, does the Turing machine ever write $\sigma$ during its computation on any string whatsoever?
    b. The halt-on-something problem: Given a Turing machine and a string, does the machine halt (enter either) on any string in $\^*$?
    c. The emptiness problem: Given a Turing machine, does the machine accept any string at all (is its language nonempty)?
    d. The reject anything problem: Given a Turing machine, does the machine reject any string at all (is its language non-\Sigma^*$)?

+   2. For each of the following questions, show whether the question is decidable or undecidable. Explain each answer.
    a. Given a Turing machine M, does it have a state $q_7$?
    b. Given a Turing machine M, does it have any transition into state $q_7$?
    c. Given a Turing machine M and a string w, does it ever enter state $q_7$ while processing w?
    d. Given a Turing machine M, does it ever enter state $q_7$ on any string whatsoever?

+   3. Given two languages $L_1$ and $L_2$, and the language $L = L_1,L_2$ (the concatenation of the first languages), prove:
    a. If $L_1$ and $L_2$ are Turing decidable, so is L.
    b. If $L_1$ and $L_2$ are Turing acceptable, so is L.

+   4. Are the following decidable or not? Justify your answers.
    a. Given a Turing machine M with input w, does M ever move its head to the left during its computation on w?
    b. Given a Turing machine M with input w, does M ever write any symbol on its tape?
