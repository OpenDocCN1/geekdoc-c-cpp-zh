# 9.3 GRAPH PROBLEMS

So far, we have discussed only problems involving Boolean expressions. These form a large group of important decision problems, but there are many other kinds of problems. Some of the most interesting problems come from graph theory, for example, the classic traveling salesman (or woman!) wants to visit n cities, wanting the least distance possible, while making the circuit. However, as noted before, as the Traveling Salesman Problem (TSP) is not a decision problem—but it has a closely related version that is a decision problem.

The first graph problem is not as intuitive or as easy to state as TSP—like other NP-complete graph problems—will require some definitions that you probably have not met before, but which are not difficult.

Graphs can be undirected or directed, as shown in Figure 9.1.

In this book, unless otherwise specified, a graph denotes an undirected graph. Graphs consist of nodes or vertices v₁, ..., vₙ and edges {v₁, vj} or, for directed graphs, directed edges or “arrows” (v₁, vj). We will write G = (V, E); that is, G is composed of a set V of vertices v₁, ..., vₙ, |V|=n, and a set of edges E, |E|≤². We write directed graphs as G = (V, A) with arrows instead of edges.

Graphs may also be weighted, in which case there is some positive number (weight) associated with each edge. Weighted graphs are often undirected complete graphs. A graph G is complete if there are edges between all pairs of vertices.
