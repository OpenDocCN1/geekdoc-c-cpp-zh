# Example

Question 1: Given a quadrilateral, is it a square (all sides and
angles equal)?

Question 2: Given a polygon with n \ge 3 sides, are all the sides
same length—is it equilateral and equiangular?

Clearly, if you had an answer to question 2, it would also answer
question 1.

# Example

Suppose there is a person, Professor Jones, who carries an umbrella
exactly when it is raining (so rain $ightarrow$ umbrella; no rain (even if storms
forecast) $ightarrow$ no umbrella).

Question 1: Is it raining?
Question 2: Is Professor Jones carrying an umbrella?

In this (idealized) case, if you are sitting in a room with no win-
dows and Professor Jones walks in, you can tell whether it is raining
outside by noting whether Professor Jones came in with an umbrella
or not.

Decision problem 1: At time t, is it raining?
Decision problem 2: At time t, is person X carrying an umbrella?

It is certainly debatable whether this situation can be called real
life; there are very few people as this. Professor Smith, who carries an
umbrella when it is raining (or if he thinks it will rain), would not be
acceptable in place of Professor Jones.
