# 26 Limits of Computation

$L^* = \{w | w = x_1x_2 \dots x_n, \text{ where } n \geq 0 \text{ and } x_i \in L\}$$
$={\varepsilon\} \cup L \cup LL \cup LLL \dots$
$={\varepsilon\} \cup L \cup L^2 \cup L^3 \dots \cup L^k \dots$

# Example

Consider the following languages over {a, b, c}:

$L_1 = \{a, b\}$$
$L_2 = \{aaa\}$$
$L_3 = {{\varepsilon\}$$
$L_4 = \varnothing$

Then:

$L_1^* = \{w | w \text{ does not contain c}\}$$
$L_2^* = \{w | w \text{ contains only a and } |w| = 3k\}$$
$L_3^* = L_3$
$L_4^* = {{\varepsilon\}    \text{ (since } \varepsilon \in L' \text{ for all languages)}$

When we take the * operator on a string, we are considering the string w as the language {w}; thus $w^*$ is language consisting of all strings that can be formed through any number (zero or more) of repetitions of w.
