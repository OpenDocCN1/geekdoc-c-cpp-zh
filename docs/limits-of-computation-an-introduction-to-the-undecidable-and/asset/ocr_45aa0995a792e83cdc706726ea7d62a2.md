# Trial Definition IV

An algorithm is a well-defined finite sequence of steps, guaranteed to terminate.

Definition IV is a reasonable working definition for most programmers. The phrase “well-defined” can be interpreted as “expressible in some programming language”—after we have the definition of a Turing machine, that will be the preferred definition. “Termination” is the absence of any infinite loop. An algorithm to find an entry in a database will return that entry or announce that it is not there; an algorithm to sort a file will end with the file in proper order.

Some definitions for the word algorithm omit the restriction that it must terminate—and are certainly computer programs, such as the one managing a monitoring system in a hospital, that should never terminate. An almost algorithm, that may or does not terminate, will here be called a computation or computational method.

# 3.5 HISTORY

Although the word algorithm only began appearing in dictionaries, it has a long history. Algorithm/algorithm is derived from the name of Abu Abdullah Muhammad al-Khwarizmi, a Persian mathematician (from native of Khwarizm; so the word actually derives from a place name), who, 810 C.E., wrote an influential treatise on procedures for solving problems in algebra—also a word from the Arabic, al-jabr. The confusion between the word algorithm, which morphed into the word algorithm, is likely linked to similar words in English (such as arithmetic and logarithm).
