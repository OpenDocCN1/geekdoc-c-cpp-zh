## 10.7 REACHABLE CONFIGURATIONS

In a graph, vertex $v_i$ is reachable from vertex $v_j$ if there is a path between the vertices. There is a simple polynomial algorithm to check this (see Chapter 4).

This has a nice application to Turing machines. We consider a graph that has nodes for every possible configuration of the Turing machine operating on a string $w$ using no than K cells on the tape, with edges between nodes for moves of the transition function $\delta$. There are a lot of these configurations, but only a finite number (see Exercises). There is, of course, one starting configuration $(q_0w_1w_2...w_k)$. Many accepting configurations. Any configuration with state $q_{accept}$—as there is no concern as to what is on the tape—is an accepting configuration.

The question about whether a Turing machine accepts string $w$ can be transformed to the graph question: Is there a path from the starting configuration to any of the accepting configurations?

What is the size of this graph, where every configuration is a node? A Turing machine with Q states, tape alphabet $\Gamma$ using S tape cells, the number of configurations is bounded by

```
|G| = |Q| \times |\Gamma|^S \times S
```

Since the Turing machine is one of $|Q|$ possible states, each of the cells contains one of $|\Gamma|$ symbols, and the head is on one of the S cells.

Thus, for a space-bounded problem, one can find whether the machine reaches an accept state by using the standard algorithm for reachable on this graph.

## 10.8 NPSPACE = PSPACE

There is a surprising relationship between nondeterministic space bounds and deterministic space. Recall that a major recurring theme has been the fact that it is unknown whether P = NP. However, for space, the answer to the analogous question is known.

We could define NPSPACE as the set of problems that can be accepted by a nondeterministic Turing machine in polynomial space; that is, those that have at least one path to q_{accept} that requires no more than a polynomial amount of space (strings in the language).

## Theorem 10.9 (Savitch, 1969)

If a decision problem X can be recognized by a nondeterministic Turing machine in space bounded by s(n), where n is the length of the input, X can be recognized by an equivalent deterministic Turing machine in space bounded by s^2(n).

## Proof

This is an application of reachability. For configurations on the Turing machine (the vertices in the graph of all configurations) let:

REACHABLE (c_i, c_j, k) = true if configuration c_i is reachable from c_j in k steps

Note the following:

REACHABLE (c_i, c_j, 0) = true if configuration c_i equals c_j
REACHABLE (c_i, c_j, 1) = true if $\delta(c_i)$ includes c_j as one of the possibilities

As we have noted, the total number of configurations is finite, and for some K,

2^K > total number of configurations

If c_j is reachable from c_i in any number of steps, it can reached in 2^K (or fewer) steps.

REACHABLE (c_i, c_j, k) for any k $\Leftrightarrow$ REACHABLE (c_i, c_j, 2^K)

For a Turing machine that uses s(n) cells, the total number of configurations is

```
|Q| \times |\Gamma|^s(n) \times s(n) = constant \times 2^(log |Q| + log s(n) + s(n) log |\Gamma|)
= constant \times 2^{constant x s(n)}
```

That is, K = K's(n).
For each of the accepting configurations c_accept, we will determine REACHABLE (c_0, c_accept, 2^K). This will be true if, for some configuration c_m:

REACHABLE (c_0, c_m, 2^(K-1)) and REACHABLE (c_m, c_accept, 2^(K-1))

Thus, our algorithm for REACHABLE (c_i, c_j, 2^K) will be:

```
REACHABLE (c_i, c_j, 2^K) =
for all configurations c
  if REACHABLE (c_i, c_j, 2^(K-1))
    if REACHABLE (c, c_j, 2^(K-1))
      return true
  return false
```

This is a recursive algorithm. There are no more than K = K's(n) calls to REACHABLE at once. For each call, we store the configuration of the caller and K. Each configuration uses O(s(n)) space to store—essentially, the tape (bounded by s(n), with the head position encoded) and the state number, ≤|Q|.

Thus, the total space used is K's(n)s(n) = O(s^2(n)).

## 10.9 A PSPACE COMPLETE PROBLEM

What kinds of problems are in PSPACE? Of course, any problem in P or NP is in PSPACE. Any problem in co-NP is in PSPACE.
But all of these problems are (probably) too easy to catch the full of what can be computed in polynomial space, PSPACE. We should look for one of the hardest problems in this category.

## Definition 10.11

A problem is PSPACE-complete if:

- 1. Y is in the class PSPACE.
- 2. For any problem X in PSPACE, X ≤_p Y.

## Definition 10.12

A problem Y is PSPACE-hard if for any problem X in PSPACE, X ≤_p Y.

The reduction used is still polynomial time, though it is applied to problems in polynomial space.
To find a good example, it is only necessary to return to Boolean expressions. A Boolean expression can contain the quantifiers ∀ (for all) and ∃ (there exists, for some) in addition to the connectors.
For example, in the universe of cats,

```
∃ x ∃ y same_color (x, y)
```

means for cats x and y (not necessarily distinct), x and y are the same color. This statement is obviously true. Any one cat from the universe will demonstrate its truth, since it is the same color as itself.

∀x ∃y same_color (x, y)

means for any cat x, there is a cat same color as x. This is also true, since letting y = x, x is the same color as x.

∀x ∃y same_color (x, y) ∧ (x, y)

means for any cat x, there is a different cat that is the same color as x. This is probably not true; the existence of any uniquely colored cat would make it false.

∀x ∀y same_color (x, y)

is patently false, since this says that all cats are the same color.
If x, y are Boolean variables, their universe is much smaller than the universe of all cats—the only possible values for x and y are false and true, 0 and 1.

∀x∃y (x ∧ y) ∨ (¬x ∧ y)

This expression can be read as “For any x, either true or false, there is a truth value for y which will make the expression true.” So we would need to check it for x = true and x = false.

- True: when x = 0, y = 1 makes the expression true
- when x = 1, y = 0 makes it true

∀x∀y (x ∧ y) ∨ (x ∧ ¬y)

This expression says that for both true and false, and for both y and y false, the expression is true. That is not correct.

- False: if x = 0, expression is false when y = 0
- if x = 1, expression is false when y = 0

The above expressions are in prenex form—that is, all the quantifiers are at the head. That is not necessary. However, any quantified expression can be rewritten in prenex form.

A variable is bound if it occurs within the scope of a quantifier; otherwise it is free. All variables are bound in the above expressions.

## Example

$x_1, x_2, x_3$ are bound in the formula below; $x_4$ and $x_5$ are free:

```
$\forall x_3 \exists x_2 \forall x_3 \quad x_1 \wedge \neg x_2 \wedge x_5 \Rightarrow \neg x_4 \vee x_2 \vee x_3$
```

## 10.9.1 Quantified Boolean Formulas (QBFs)

A quantified Boolean formula (QBF) is a Boolean expression in prenex form with no free variables. Thus, it has the form

```
$Q_{x_1} Q_{x_2} \dots Q_{x_n} E$
```

where E is a Boolean expression in $x_1, ..., x_n$, and each $Q_i$ is either the quantifier $\forall$ or $\exists$.

The decision problem is whether this formula is true or not.
To prove QBF is PSPACE-complete, we need to know two things: (1) the problem is in PSPACE, and (2) that every problem in PSPACE is polynomially reducible to QBF. Neither of these properties is immediately obvious.

## Theorem 10.13

QBF is in PSPACE.

Proof

This is another application of recursion, similar to REACHABILITY. We will use recursion to remove the quantifiers, one at a time. The recursive algorithm requires only polynomial space.
Let E be a Boolean expression in prenex form, possibly with quantifiers:

- 1. If E contains no quantifiers, then it contains no variables and consists of the Boolean constants 0 and 1 with connectors; simply evaluate it.
