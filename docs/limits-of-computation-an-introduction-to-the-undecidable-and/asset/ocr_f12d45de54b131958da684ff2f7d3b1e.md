# 6.1.1.2 Problem 2: Greling's Paradox

An adjective is said to be autological if the property denoted by the adjective is possessed by the adjective itself, and heterological if the property denoted by the adjective is not possessed by the adjective itself. For example, polysyllabic is autological since it has five syllables, and monosyllabic is heterological since it does not have one syllable. The word black written in standard black font is autological; the word green is heterological unless we print it in a green font. Question: Is the word heterological heterological?

# 6.1.1.3 Problem 3: Russell's Paradox

Bertrand Russell was deeply involved in formalizing set theory. One concerns sets that are described by some property.

```
S = {x some universe | x has property P}
```

Some sets—most sets—are elements of themselves. The set C = {x | x is a prime integer} is a set, not prime integer, C ≠ C. However, A = {x | x is an infinite set} is an infinite set, so A ∈ A.
Now consider Z = {X | X is a set and X ≠ X}. If Z ∈ Z, then Z ≠ Z, and if Z ≠ Z, then Z ∈ Z. (Why?) Neither of these can be true. Discovery and resolution of paradox made significant changes to set theory, including modifications of how sets can be constructed.
