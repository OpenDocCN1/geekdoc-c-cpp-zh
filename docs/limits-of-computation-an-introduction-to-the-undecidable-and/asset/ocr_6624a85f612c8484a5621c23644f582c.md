# 4.3.7 Transition Function

The transition function (or delta function) δ controls the operation of the Turing machine. At each step of its execution, a Turing machine examines both the symbol under its read/write head and its current state. It consults its delta function in order to determine how to proceed. The machine replaces the symbol beneath its read/write head with a new symbol, changes its state to a new state, and moves the read/write head either to the left or to the right one cell, as directed by its transition function.

Since δ is a function, it must be defined for all possible state and symbol pairs—except out of course, the two states where moves are not allowed. Since the Turing machine stops execution once it has entered either q_{accept} or q_{reject} it need not—in fact, must not—make a move from either of these states. The transition function therefore takes as its domain Q={q_{accept}, q_{reject}} × Γ. Its range is quite naturally Q × Γ × [left, right], where left and right are the directions to move the read/write head either left or right, respectively.

Several things should be noted here:

+   - A Turing machine must write a symbol to its tape at every step. However, it can always replace the current symbol under the read/write head with exactly the same symbol that there was there.
- A Turing machine must go to a new state on each move, but that state can be the same that it was in previously.
- A Turing machine must move its read/write head either to the left or to the right at every step. It cannot stay positioned over the same symbol, although it can certainly move in one direction and then move again in the opposite order to regain its original position.
