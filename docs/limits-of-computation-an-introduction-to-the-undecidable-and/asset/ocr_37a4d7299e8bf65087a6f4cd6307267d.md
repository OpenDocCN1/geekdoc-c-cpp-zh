# Corollary 1.19

There is no one-to-one correspondence between the natural numbers and the set of infinite sequences $\{0, 1\}$.

# Proof

Exactly the same, only (1) take $r_i$ as infinite sequences of $\{0, 1\}$ instead of real numbers, and (2) there is no need to disallow the sequence $(1, 1, 1, \dots).$

Cantor gave these two cardinalities the name $\aleph_0$ (the cardinality of the natural numbers, often called countable) and $\aleph_1$ (the cardinality of $\mathbb{R}[0,1)$, which is also the cardinality of all real numbers, and the cardinality of all infinite sequences over $\{0, 1\}$, and termed uncountable). Or, we can say that $\aleph_0 = |\mathbb{N}|$ and $\aleph_1 = |\mathbb{R}|$.

Note that in the $\aleph_1$ sequence $x = x_1 x_2 x_3 \dots$, there are two choices of each of $x_i$ (0 and 1). Thus, we can say, in some sense, that

```
$2*2*2*\dots*2=2^{\aleph_0}=\aleph_1$
```

with $\aleph_0$ the number of 2s.
