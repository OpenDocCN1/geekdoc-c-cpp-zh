We will show that given a satisfying assignment of true values, one can get a three-dimensional satisfying assignment, as there will be one or more literals in each clause. If we have such assignment, with $x_1$ true, $x_2$ true, and $x_3$ false, these triples are bold and italicized. Arbitrarily, choose one italicized triple from each clause. The chosen triple is underlined.

```
$(x_{1,1}, f_1, g_1), (x_{3,1}, f_1, g_1) \leftarrow (x_{1,1}, f_1, g_1)$
$(x_{1,2}, f_2, g_2), (x_{2,2}, f_2, g_2) \leftarrow (x_{1,2}, f_2, g_2)$
$(
eg x_{1,3}, f_3, g_3), (
```
