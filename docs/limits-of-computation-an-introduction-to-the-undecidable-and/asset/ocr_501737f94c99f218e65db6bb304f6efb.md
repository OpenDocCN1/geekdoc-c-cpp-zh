# 3.8 DEFINITIONS

There are many ways to compare the sizes of two functions or two algorithms. We will use only O (capital letter omicron from the Greek alphabet, pronounced “big oh”). This is the way you probably first in data structures or algorithms analysis class. The main reason for using here is that it is an upper bound—which in this course is what we care about, rather than an exact measure—and it is usually convenient to calculate.

# Definition 3.5

For functions f and g defined on the integers, f is O(g) if there exist positive integers C and N such that |f(n)| ≤ |g(n)| for all n ≥ N.
