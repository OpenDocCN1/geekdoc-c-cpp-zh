# Definition 3.5 Restated

For positive functions f and g defined on the positive integers, f is O(g) if there exists a positive integer C such that f(n) ≤ C g(n) for all positive integers n.

Sometimes it is convenient to consider O(g) to be a set, and then we say f ∈ O(g), instead of f is O(g). Some authors will say O(f) = g, but this is best avoided.
The distinction between f ∈ O(g) and f is O(g) is rarely a problem.

# 3.9 USEFUL THEOREMS

The following two theorems are often useful for proving that one function is f O of another. Direct limits are often not useful, since any function that describes the order of an algorithm will be increasing, positive, and tend to infinity.

This is a standard case where applying l'Hospital's rule works well.

$$\lim_{x\to\infty} \frac{f(x)}{g(x)} = C$
