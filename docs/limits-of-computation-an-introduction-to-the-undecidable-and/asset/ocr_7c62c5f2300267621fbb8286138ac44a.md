# Examples

Consider the following languages over {a, b, c}:

$L_1 = \{a, b, aabc, bbaabcc\}$

$L_2 = \{\varepsilon, aa, cba\}$

$L_3 = \{w \mid w = w^R\}$

$L_4 = \{w \mid w \text{ contains exactly one b}\}$

$L_5 = \{w \mid w \text{ starts with a}\}$

$L_6 = \varnothing$

# Union (all strings that are in either of the languages):

$L_1 \cup L_2 = \{\varepsilon, a, b, aa, aabc, cba, bbaabcc\}$

$L_3 \cup L_4 = \{w \mid w = w^R \text{ or w contains exactly one b}\}$

$L_5 \cup L_6 = L_5$

# Intersection (strings that are in both of the languages):

$L_1 \cap L_4 = \{b, aabc\}$

$L_2 \cap L_5 = \{aa\}$

$L_3 \cap L_6 = L_6$

# Difference (a string that is a member of the first language but not a member of the second):

$L_2 - L_3 = \{cba\}$

$L_1 - L_5 = \{b, bbaabcc\}$

$L_4 - L_6 = L_4$
