# Fact

An expression in conjunctive normal form (CNF) is true if and only of each of its clauses is true. Thus, some texts do not speak of an expression in conjunctive normal form; instead, they speak of a set of clauses that all have to be satisfied.

Decision problem: CNF satisfiability (abbreviated CNF-SAT).
Instance: A Boolean expression E over variables $x_1, ..., x_n$ in conjunctive normal form.
Question: Is there an assignment of true values to the variables $x_1, ..., x_n$, such that E is true (that E is satisfied)?

This is our basis problem, the first NP-complete problem. The theorem is: easily stated; the main part of the proof is the next section of the text, but the proof begins below.

# Theorem 8.19

(Cook-Levin) CNF-SAT in NP-complete.

Clearly, CNF-SAT is a decision problem. It is trivial to find yes and no instances—one can do so with n = 1 and the single Boolean variable $x_1$. (Yes instances: $x_1, x_1 \vee \neg x_1, x_1 \vee x_1$; no instance: Exercise 14a).

Claim: CNF-SAT is in NP.

A certificate for CNF-SAT is the assignment of true and false to the variables that satisfy the expression—make the expression true, or equivalently, make every clause true. We do not have to find the certificate—we guess it (omnipotently, omnisciently) or that it is simply handed to us.
