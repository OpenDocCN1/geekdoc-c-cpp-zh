# 8.8 COOK–LEVIN THEOREM: PROOF

The basis for the rest of the proof will be the theorem that shows CNF-SAT is NP-hard (since CNF-SAT is in NP, it is therefore NP-complete).

We know absolutely nothing about X except that it is in NP. It might be a graph problem, a Boolean expression problem, a problem with numbers, or something altogether different. We must find a way to transform X into CNF so that: (1) the reduction can be done in polynomial time, (2) a yes instance of X becomes a satisfiable expression in CNF-SAT, and (3) a no instance of X becomes cannot be satisfied by any assignment of truth values to the variables.

All we know about X is that it is in NP; that is, it has a nondeterministic Turing machine M_ₓ that has a short (polynomially bounded) path to qₐ for yes instances, but no path ever to qₐ for no instances. The proof, due to Steven Cook (1971, a paper based on his PhD thesis) and proven independently by Levin (1974), using another method, is ingenious. Cook received the prestigious ACM Turing Award in 1982 for his work. His Turing Award lecture (1983) is worth reading. Hartmanis and Hopcroft (1971) present an overview of the early work in complex theory.

The idea will be to take the Turing machine Mₓ and to write a set of Boolean clauses that effectively and completely describe its operation and the path to the accepting state.

The Boolean expression to be satisfied is then the conjunction of all the clauses. The clauses should be ∨'s of variables and their negations. These clauses must specify:

+   - The Turing machine starts in the proper configuration.

+   - Each configuration is legal for the Turing machine. This will mean that the TM tape head is on one and only one cell, its tape cells contain one and only one symbol, and the machine is in one and only one state at each step.

+   - Each move follows one of the legal moves in its transition function.

+   - The Turing machine reaches its accept state.
