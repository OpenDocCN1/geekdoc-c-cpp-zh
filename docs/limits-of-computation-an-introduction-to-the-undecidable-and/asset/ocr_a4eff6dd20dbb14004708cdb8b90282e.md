We need one more function f: N → N and the Turing machine Mf that computes it; it is defined below.
Using M_{SAT} and Mf define M, a TM that takes a Boolean expression in conjunctive normal form. Its language L(M) will be (1) not in P, (2) in NP, but (3) NP-complete.
For input w, M_{SAT} on w:

If M_{SAT} rejects w, so does M (L(M) ⊆ SAT).
If M_{SAT} accepts, compute M on |w| to compute f(|w|).
If f(|w|) is an even integer, accept; reject.
L(M) = {w | w is in SAT and f(|w|) is even} (where f and Mf are defined below).

The easy part (once f is defined) is that L(M) is in NP—all that is required is a certificate that the string is in SAT, and f(|w|) is even. This last part will be true f(|w|) will only take O(|w|) steps to compute.
