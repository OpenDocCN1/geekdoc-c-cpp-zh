# Theorem 5.6

Any k-tape Turing machine M has an equivalent one-tape Turing machine M'. t steps of M can be emulated in Kt steps of M', Moreover, where K is a constant. Thus, if an algorithm is bounded by t(n) steps on an input of size n on a k-tape machine, it is bounded by Kt(n) steps on a one-tape machine.

# Proof

As in emulating a two-way infinite tape on a semi-infinite tape, there are many choices for building M'.
All the information from the k-tapes must be put onto one tape. Each tape can have a finite string on it, and each tape has its own head position.

A standard trick for encoding head positions is to double the alphabet—for each symbol σ in Σ, add another symbol σ'. Thus, when tape i is put onto the single-tape machine, the presence of the head on a cell will be encoded as that symbol with its prime.
