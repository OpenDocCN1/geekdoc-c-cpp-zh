# 1.3 CARDINALITIES

Before we can discuss cardinality, we must review what we mean when we say that two sets are the "same size." For example, consider the two sets below:

{A, B, C} {cow, dog, cat}

The "wrong" answer is that the two sets both have three elements—or perhaps more correctly, counting elements to three is all right, but does not go back to first principles. Why do they have three elements? What does it mean to have three elements? The "right" answer, the one that goes back to the foundations of arithmetic, is that there is a one-to-one correspondence between them—for example, A ↔ cat, B ↔ cow, and C ↔ dog. The reason they have three elements is that each is in one-to-one correspondence with some set that exhibits the basics of "threeness."

# Definition 1.17

A set S is countable iff there is a surjective function f: N → S. A set S is infinite iff there is a surjective function f: S → N.

Georg Cantor (German mathematician, 1845–1918) proved that there are different sizes of infinities. For example, there are obviously an infinite number of natural numbers, since the mapping f(i) = i is a surjective function f: N → N.

# Theorem 1.18 (Cantor)

There is no one-to-one correspondence between the set of all natural numbers and the set of reals R[0,1).

The proof is not difficult. First, let's represent all numbers in binary. Second, to make the representation for a binary fraction unique, we need to disallow any infinite sequence of 1's. For example, these two numbers denote exactly the same number:

```
0.001111111... = 0.010000...
```

so we use the second representation for the number 1/4.
(You may ask why the two numbers above are the same. Two numbers are only different if there is some distance between them, or, when you subtract one from the other, you do not get zero. Try the above subtraction.)

Now, to prove something does not exist, assume that it does and arrive at a contradiction. Thus, assume that there is a one-to-one correspondence between the natural numbers and R[0, 1).

```
r₁ = 0.01010110 ... ↔ 1
r₂ = 0.010101011 ... ↔ 10
r₃ = 0.0111001 ... ↔ 11
r₄ = 0.10101010 ... ↔ 100 Diagonal = .0110110 ...
r₅ = 0.01011100 ... ↔ 101
r₆ = 0.01011111 ... ↔ 110
r₇ = 0.01001010 ... ↔ 111
```

To be a one-to-one correspondence, every real number must appear once, and every natural number must appear once. However, we can construct a real that does not correspond to any natural number, that is, it is not rₖ for any k.
