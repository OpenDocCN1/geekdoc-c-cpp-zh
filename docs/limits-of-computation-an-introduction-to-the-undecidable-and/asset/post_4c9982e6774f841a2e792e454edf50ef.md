- Bar: Choose TRUE.
- Triangle: Omit one TRUE vertex.

Now, this is a vertex cover. Each bar has an end (the true end) in $V'$. At least one of the vertices in each triangle is connected to the true end of a bar in order to satisfy the clause. As depicted in Figure 9.7, each triangle also has two vertices in $V'$, and any two vertices in a triangle cover the remaining edges in the triangle.

And, because a TRUE vertex was omitted from each triangle, the edge from this vertex to a bar is covered by the TRUE end of the bar. The other two edges from the triangle to the bars are covered by the two vertices in the triangle.

- 3. To finish the proof, we need to show that if the graph—constructed has a vertex cover, then the Boolean expression is satisfied (that is, yes comes from yes). This proof relies on the constraints on how the vertex cover can be chosen. While there are many ways to choose $m = n + 2|C|$ from $G$, the only possible way to be a vertex cover is to have a $V'$ that includes one vertex from each bar, and two vertices from each triangle (there is simply no other way to have a cover of a triangle!). If you can have a successful vertex cover, then the lines interconnecting the bars and triangles must have one end in the vertex cover. Two of the interconnecting lines are covered by the two vertices chosen from each triangle, but the third must be covered by the vertex chosen from the bar—and that means setting that vertex to be TRUE will guarantee at least one true variable in each clause.

# 9.5 OTHER GRAPH PROBLEMS

The following graph definitions are used in many NP-complete problems.

# Definition 9.8

An independent set of size $m$ in $G$ is a set of vertices such that no two vertices are adjacent.

# Problem

Given $G$ and $m$, does $G$ contain an independent set (IS)?

# Definition 9.9

A feedback vertex set of size $m$ in a directed graph is a set of vertices $V'$ such that every cycle in the graph is broken.

# Problem

Given a directed graph and $m$, does it contain a feedback vertex set (FVS)?

# Definition 9.10

A $k$-clique in a graph $G$ is a complete subgraph on $k$ vertices.

# Problem

Given a graph $G$ and $k$, does $G$ contain a $k$-clique?

# Definition 9.11

A dominating set of size $m$ in a graph $G$ is a set of vertices $V'$ such that every vertex of $G$ is connected to some vertex in $V'$.

# Aside: How is this different from a vertex cover? In a graph, what is the smallest dominating set?

# Problem

Given a graph $G$ and $m$, does $G$ contain a dominating set?

# Definition 9.12

A graph $G = (V, E)$ can be colored with $m$ colors $c_1, c_2, ..., c_m$ ($1 \le m \le |V|$) if there is a way to assign the colors $c_j$ to the vertices $v_j$ such that no adjacent vertices have the same color. Such an assignment of $m$ colors to $V$ is called an $m$-coloring.

# More NP-Complete Problems ■ 201

# Problem

- Given a graph $G$, does $G$ have a three-coloring?
- Given a graph $G$ and integer $k$, does $G$ have a $k$-coloring?

# Definition 9.13

The degree of a vertex $v$ in $V$ is the number of edges connected to $v$. (See the Exercises at the end of the chapter for some problems using vertex degree.)

The proofs that these problems are NP-complete vary from easy to difficult. Also interesting is that some similar problems are not NP-complete. For example, there is a simple polynomial algorithm to determine whether a graph $G$ has a two-coloring.

# 9.6 HAMILTONIAN CIRCUIT (HC)

Hamiltonian circuits (and the related traveling salesman problems) are old and interesting graph problems. Recall that HC asks if one can start at some vertex, visit all the other vertices in the graph, and return to the starting place? For many graphs, the answer is clearly no. There can be no Hamiltonian circuit if there are isolated vertices, or if there are any vertices with only one edge, for example. For small graphs, it is easy to check by inspection whether or is not there a Hamiltonian circuit. For example, in Figure 9.9, the graph on the left is an instance; the graph on the right is no instance.

The HC problem is the decision problem: Given a graph $G = (V, E)$, does $G$ have a Hamiltonian circuit?
