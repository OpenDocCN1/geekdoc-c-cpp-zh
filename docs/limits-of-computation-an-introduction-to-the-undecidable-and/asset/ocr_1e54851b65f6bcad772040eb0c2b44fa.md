Now the two possible outputs from HWD are yes and no. Suppose that we change each occurrence of the string yes in an output statement to no, and every occurrence of no to "Hello World." Call this new program HWD Revised or HWDRev for short. It is shown in Figure 6.6.

This is (as in all these cases) a problem of self-reference. What would happen if we run HWDRev on itself? We do that by sending HWDRev to HWD (see Figure 6.7). And what would the original HWD say about HWDRev? If HWD were to say yes, then HWDRev should print "Hello World." But, the way it is written, the yes was changed into a no.

And, if HWDRev writes "Hello World" if and only if it does not write "Hello World." This cannot happen! So HWDRev cannot exist—and neither HWDIn or HWD. All this is summarized in Figure 6.8.
