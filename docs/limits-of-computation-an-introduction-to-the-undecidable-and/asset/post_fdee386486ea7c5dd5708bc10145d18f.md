# Definition 2.6

**The shuffle** of strings $v$ and $w$ is a set of strings of the form $v_{i_1}w_{j_1}v_{i_2}w_{j_2} \dots v_{i_n}w_{j_n}$, where $n \geq 1$ and $v = v_1, \dots, v_n$ and $w = w_1, \dots, w_n$. The $v_i$ and $w_j$ are substrings of $v$ and $w$.

Because some of the substrings are $\varepsilon$, this does not mean the two strings are the same length or that characters alternate. It does mean the symbols of $v$ and $w$ both appear in order in any string in their shuffle.

For example, if $v = 000$ and $w = 11111, 011010110$ is in the shuffle of strings $v$ and $w$. And if $v = 01$ and $w = 110$, then $10110$ is in the shuffle of $v$ and $w$. (Exercise: List other strings in the shuffle.) Note that for $v=01$ and $w = 110$, all strings in the shuffle of $v$ and $w$ have two $0$'s and three $1$'s—but not strings with two $0$'s and three $1$'s are in shuffle$(v,w)$; for $00111$ is not (why?).

Shuffles are not the only interesting operations on strings and languages. One can take halves (or last halves, or thirds) of strings, cycle the characters in a string, and more. However, none of these operations have much general use. And if you think that shuffle is weird and of not much general use, you may be correct—generally, operations such as concatenation and reversal are of much more use (and simpler to understand).

# 2.3 OPERATIONS ON LANGUAGES

Languages are sets, so course all the usual set operations are available on two languages $L_1$ and $L_2$: **union** $(L_1 \cup L_2)$, **intersection** $(L_1 \cap L_2)$, **difference** $(L_1 - L_2)$, and **complement** $(L_1 \cup L_1^*)$.

# Examples

Consider the following languages over {a, b, c}:

$L_1 = \{a, b, aabc, bbaabcc\}$

$L_2 = \{\varepsilon, aa, cba\}$

$L_3 = \{w \mid w = w^R\}$

$L_4 = \{w \mid w \text{ contains exactly one b}\}$

$L_5 = \{w \mid w \text{ starts with a}\}$

$L_6 = \varnothing$

# Union (all strings that are in either of the languages):

$L_1 \cup L_2 = \{\varepsilon, a, b, aa, aabc, cba, bbaabcc\}$

$L_3 \cup L_4 = \{w \mid w = w^R \text{ or w contains exactly one b}\}$

$L_5 \cup L_6 = L_5$

# Intersection (strings that are in both of the languages):

$L_1 \cap L_4 = \{b, aabc\}$

$L_2 \cap L_5 = \{aa\}$

$L_3 \cap L_6 = L_6$

# Difference (a string that is a member of the first language but not a member of the second):

$L_2 - L_3 = \{cba\}$

$L_1 - L_5 = \{b, bbaabcc\}$

$L_4 - L_6 = L_4$

# Complement (strings not in the language):

$L_2 = \{w \mid w \neq \varepsilon \text{ and } w \neq aa \text{ and } w \neq cba\}$

$L_4 = \{w \mid w \text{ does not contain exactly one b}\}$

$L_6 = \Sigma^*$

But, because the elements of a language are strings, there are also other operations available.

# Definition 2.7

The concatenation of two languages $L_1$ and $L_2$ is the set of all strings that can be formed by concatenating a string from $L_1$, with a string from $L_2$.

$L_1L_2 = \{w \mid w = xy, x \in L_1 \text{ and } y \in L_2\}$

# Examples

Consider the following languages over $\{0, 1\}$:

- $L_1 = \{\varepsilon, 1, 00\}$
- $L_2 = \{1, 11, 111\}$
- $L_3 = \{w \mid w \text{ contains any number of } 0's \text{ (no } 1's); \text{ that is, } w = 0^k \text{ for some } k\}$
- $L_4 = \{w \mid w \text{ contains any number of } 1's; \text{ i.e., } w = 1^j \text{ for some } j\}$
- $L_5 = \{\varepsilon\}$
- $L_6 = \varnothing$

Then:

- $L_1L_2 = \{1, 11, 001, 0011, 1111, 001111\}$

$L_2L_4 = \{w \mid w \text{ contains any number of 0's followed by any number of 1's}\}$

$L_2L_5 = L_2$

$L_4L_6 = L_6$

The concatenation of a language L with itself multiple times can be written with the **repetition** operator.

# Examples

Consider the following languages over $\{0, 1\}$:

- $L_1 = \{0, 11\}$
- $L_2 = \{w \mid \text{length } = 2\}$
- $L_3 = \{\varepsilon\}$
- $L_4 = \varnothing$

Now:

$L_1^2 = \{00, 011, 110, 1111\}$

$L_1^3 = \{000, 0011, 0110, 1100, 01111, 11011, 11111\}$

$L_2^2 = \{w \mid \text{length } = 4\}$

$L_2^k = \{w \mid |w| = 2k\}$

$L_3^k = L_3$

$L_4^k = L_4$ for $k > 0$

The **Kleene star** (or **Kleene closure**) of a language is $L^* = L^0 \cup L^1 \cup L^2 \cup \dots$ Note that $\varepsilon$ is always in $L^*$ for any language L.

# Example

Consider the following languages over {a, b, c}:

- $L_1 = \{a, b\}$
- $L_2 = \{aaa\}$
- $L_3 = \{\varepsilon\}$
- $L_4 = \varnothing$

Then:

$L_1^* = \{w \mid w \text{ does not contain c}\}$

$L_2^* = \{w \mid w \text{ contains only a and } |w| = 3k\}$

$L_3^* = L_3$

$L_4^* = \{\varepsilon\}$

When we take the * operator on a string, we are considering the string as the language {w}; thus $w^*$ is language consisting of all strings that can be formed through any number (zero or more) of repetitions of w.

# Examples

Consider following strings over $\Sigma = \{a, b\}$:

- $w = aaa$
- $x = b$
- $y = aba$

So:

$w^* = \{\varepsilon, aaa, aaaaa, aaaaaaaa, \dots\}$

$x^* = \{\varepsilon, b, bb, bbb, bbbbb, \dots\}$

$y^* = \{\varepsilon, aba, abaaba, abaabaaba, \dots\}$

$z^* = \{\varepsilon\}$

The **homomorphic image of a language** L under some mapping $h$ from $\Sigma_1$ to $\Sigma_2^*$ is the homomorphic mapping of all strings in L.

# Examples

- I. Let $\Sigma_1 = \{0, 1\}, \Sigma_2 = \{a, b, c\}, h: 0 \rightarrow abc, 1 \rightarrow b$.
  $L_1 =$ strings that contain 00
  $L_2 = 0^n1^m$
  $h(L_1) =$ combinations of abc and b that contain the substring abc
  h(L_2) = (abc)^n(b)^m$

- II. Let $\Sigma_1 = \{0, 1\}, \Sigma_2 = \{a, b, c\}, h: 0 \rightarrow aa, 1 \rightarrow \varepsilon$.
  $L_1 =$ strings that contain 00
  $L_2 = 0^n1^m$
  $h(L_1) = (aa)^{k+2} = \{a^4, a^6, \dots\}, k \geq 0$
  $h(L_2) = (aa)^k, k \geq 0$

- III. Let $\Sigma_1 = \{0, 1\}, \Sigma_2 = \{a, b\}, h: 0 \rightarrow a, 1 \rightarrow b$.
  Then $h(L)$ is simply L with 0 becoming a, 1 becoming b, for any L.
