# 10.9 A PSPACE COMPLETE PROBLEM

What kinds of problems are in PSPACE? Of course, any problem in P in NP is in PSPACE. Any problem in co-NP is in PSPACE.
But all of these problems are (probably) too easy to catch the full of what can be computed in polynomial space, PSPACE. We should look for one of the hardest problems in this category.

# Definition 10.11

A problem is PSPACE-complete if:

+   1. Y is in the class PSPACE.
2. For any problem X in PSPACE, X ≤_p Y.

# Definition 10.12

A problem Y is PSPACE-hard if for any problem X in PSPACE, X ≤_p Y.

The reduction used is still polynomial time, though it is applied to problems in polynomial space.
To find a good example, it is only necessary to return to Boolean expressions. A Boolean expression can contain the quantifiers ∀ (for all) and ∃ (there exists, for some) in addition to the connectors.
For example, in the universe of cats,

```
∃ x ∃ y same_color (x, y)
```

means for cats x and y (not necessarily distinct), x and y are the same color. This statement is obviously true. Any one cat from the universe will demonstrate its truth, since it is the same color as itself.
