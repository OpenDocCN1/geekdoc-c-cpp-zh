# Definition 4.3

A Turing machine M **accepts** an input string $w \in \Sigma^*$ iff it enters $q_{\text{accept}}$

# Definition 4.4

A Turing machine M **rejects** an input string $w \in \Sigma^*$ iff it enters $q_{\text{reject}}$

# Definition 4.5

A Turing machine M **halts** an input string $w \in \Sigma^*$ iff it enters either $q_{\text{accept}}$ or $q_{\text{reject}}$

# Definition 4.6

A Turing machine M **loops** an input string $w$ iff it **never** enters either $q_{\text{accept}}$ or $q_{\text{reject}}$

We also need some terminology to describe the behavior of Turing machines on entire languages.

# Definition 4.7

A Turing machine M **decides** language $L$ over $\Sigma$ iff for any string $w$ in $\Sigma^*$, $M$ enters $q_{\text{accept}}$ if $w$ is in $L$, and enters $q_{\text{reject}}$ if $w$ is not in $L$. The language $L$ is **decidable** or **recursive**.

# Definition 4.8

A Turing machine M **accepts** (or **recognizes**) language $L$ over $\Sigma$ if for any string $w$ in $\Sigma^*$, $M$ enters $q_{\text{accept}}$ if and only if $w$ is in $L$. The language $L$ is **recursively enumerable** (RE) or **semidecidable** or acceptable.
