
# Limits of Computation

There is no particular reason that a symbol has to be a connected line—consider the symbol j, or the symbol x. There is also no particular reason that a symbol has to have a well-defined name, except that then we would be reduced to making names for each one (squiggle-1, squiggle-2, etc.). Exotic, artistic alphabets are hard to name, and thus to discuss and to write. The standard alphabets in formal language theory consist of some set of standard characters, perhaps with embellishments such as x or x' . In most class and text examples, alphabets are small. The alphabets {0, 1} or {a, b, c} are used in many examples.

A string over the alphabet Σ is a finite sequence of symbols from Σ.

Letters near the end of the alphabet are often used as names of strings (u, v, w, etc.). To stand for the symbols in the string, σ (or sometimes τ) will be used.

## Definition 2.3

The length of a string w, denoted |w|, is the number of nonunique characters w contains. As strings are finite, every string has a defined lengths.

## Examples

- w = abb = σ₁σ₂σ₃ over Σ = {a, b, c}, σ₁ = a, σ₂ = σ₃ = b, |w| = |abb| = 3
- u = bbbb over Σ = {a, b, c}, |u| = |bbbb| = 4
- v = 1001111 over Σ = {0, 1}, |v| = 7

Note: Sequences have different notations—often the notation used depends on whether the sequence is used in a course in mathematics, for formal languages, or algorithms analysis.

```
w = ababa (formal languages)
w = (a, b, a, b, a) (algorithms analysis)
```

The shortest string over any alphabet is the empty string—a string with no characters at all. We denote the empty string as $\varepsilon$—the Greek letter epsilon—although some authors use $\varepsilon$ or $\lambda$ instead. Its length is zero, $|\varepsilon| = 0$.

There is no longest string over an alphabet. A string may be of any length, so long as it is finite.

## Examples

Consider the two alphabets $\Sigma_1 = \{a, b, c\}$ and $\Sigma_2 = \{b, c, d\}$. The following- strings over both $\Sigma_1$ and $\Sigma_2$:

```
$\varepsilon$
bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
bbcbcb
```

The following are not strings over $\Sigma_1$ and $\Sigma_2$:

```
abacabad $(d \notin \Sigma_1, a \notin \Sigma_2)$nb b c (")”—that is, blank—$\Sigma_1$ or $\Sigma_2$)
```

An exponent can be used to note the **repetition** or number of times a character is repeated within a string.

## Example

```
$a^4b^5a^2 = aaaabbbbbaa
b^{28} = bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
0^5 = 00000
a^0 = \varepsilon
1^3 = 111$ (This is a string operation, not arithmetic!)
```

## Definition 2.4

A language over $\Sigma$ is a set of strings over $\Sigma$.

## Examples

The following are languages over the alphabet Σ = {0, 1}:

$L_1 = \{0, 01, 001, 0001, 00001, 000001\}$

$L_2 = \{\varepsilon, 111111, 0000000000\}$

$L_3 = \{\varepsilon\}$

$L_4 = \{\}$

An infinite language consists of an unbounded number of strings. It would be impossible in this case to list all of the elements of the language, so we instead describe its contents using Peano's notation.

## Examples

The following are languages over the alphabet Σ = {a, b, c}—all $L_5$ are infinite.

- $L_1 = \{w \mid w \text{ begins with } b\}$
- $L_2 = \{w \mid w \text{ begins or ends with } c\}$
- $L_3 = \{w \mid w \text{ contains an even number of } a's\}$
- $L_4 = \{w \mid w \text{ does not contain } c\}$
- $L_5 = \{w \mid w \text{ is a word in the Scrabble* dictionary}\} = \{a, aa, aba, ba, baa, baba, bacca, cab \dotsdots\}$

In addition to the above notation, we can also use ellipses when a pattern can be clearly established.

## Example

The following are languages over the alphabet Σ = {0, 1}:

$L_1 = \{1, 01, 001, 0001, 00001, \dots\}$

$L_2 = \{1, 010, 00100, 000100, \dots\}$

$L_1 = \{\varepsilon, 00, 0000, 000000,, \dots\}$

We can also use either of the above notations for finite languages if we wish to stress the structure of their component strings.

The smallest language over any alphabet $\Sigma$ is $L_{\emptyset} = \{\\}$\}$, with no strings whatsoever (the language has zero strings, or $|L_{\emptyset}| = 0$). This is distinct from any small language, $L_{\varepsilon} = \{\varepsilon\}$, a language with exactly one string in the language ($|L_{\varepsilon}| = 1$). Remember this distinction! The string $\varepsilon$ is not "nothing"; it is indeed a real string, just one with no symbols in it.

# 2. OPERATIONS ON STRINGS

There are many operations that can be done on strings—simple one, others more complicated.

The **reversal** of a string $w = \sigma_1\sigma_2 \dots \sigma_n$ (written $w^R$) is obtained by placing its characters in the opposite order, $w^R = \sigma_n\sigma_{n-1} \dots \sigma_1$. Note that the lengths are the same, $|w| = |w^R|$.

## Examples

$(abc)^R = cbba$

$(00111)^R = 11100$

$(abba)^R = abba$

$\varepsilon^R = \varepsilon$

The **concatenation** of two strings $u = \sigma_1\sigma_2 \dots \sigma_n$ and $v = \tau_1\tau_2 \dots \tau_m$ (write $uv$, $u v$, or sometimes as $u \times v$) is the string obtained by appending $v$ onto the end of $u$, as $\sigma_1\sigma_2 \dots \sigma_n\tau_1\tau_2 \dots \tau_m$.

The length $|uv| = |u| + |v|$.

## Examples

Consider the following strings over $\Sigma = \{0, 1\}$:

$w = 000$
$x = 1$
$y = 01010$
$z = \varepsilon$

Then:

$wx = 0001$
$xy = 101010$
$yz = 01010$
$zw = 000$

Note that $zw = w$ for any string $w$. So in particular, $\varepsilon = w$ for any string.

One can take multiples of a string, also denoted by $w^n$, as well. The repetition of a string, $w^n$, is the concatenation of a string with itself.

## Examples

Consider the following strings over $\Sigma = \{a, b, c\}$:

$w = ababa$ (formal languages)
$w = (a, b, a, b, a)$ (algorithms analysis)

$a^4b^5a^2 = aaaabbbbbaa$
$b^{28} = bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
$0^5 = 00000$
$a^0 = \varepsilon$
$1^3 = 111$ (This is a string operation, not arithmetic!)

## Definition 2.5

The lexicographical order, on strings $\Sigma$, is defined so that $v < w$ if:

1. $|v| < |w|$
2. $|v| = |w|$, $v = \sigma_1\sigma_2 \dots \sigma_n, w = \tau_1\tau_2 \dots \tau_n$ for some $i > 0$ such that $\sigma_j = \tau_j$ for $j = 1, 2, \dots, i - 1$, and $\sigma_i < \tau_i$ in the ordering of symbols of $\Sigma$.

And, as usual, $v \le w$ if $v < w$ or $v = w$. Note that the empty string $\varepsilon$ is less than nonempty string $w$.

The homomorphic image of a string is the string with substitutions made for each character. If there are two alphabets $\Sigma_1$ and $\Sigma_2$, and a mapping $h$ takes each character in $\Sigma_1$, to some string of $\Sigma_2$, then this is easily extended to strings over $\Sigma_1$, by replacing each character in the string by its image. (The name homomorphism comes from mathematics; it is a function in which $f(xy) = f(x)(y)$—here, you are given what to do with each symbol; you extend naturally to strings.)

# Example

Let $\Sigma_1 = \{0, 1\}$, $\Sigma_2 = \{a, b, c\}$ with $0 \to abc, 1 \to b$ (mapping defined on the two elements of $\Sigma_2$). That is, $h(0) = abc, h(1) = b$. Or, informally, what do you do with 0? Replace it with abc. What do you do with 1? Replace it with just b. Now you know what to do with the only two symbols in the alphabet, so you should know what to do with every string over {0, 1}.

```
001 → abcabc h(001) = abcabc
110 → bbabc h(110) = bbabc
0 → abc h(0) = abc
ε → ε h(ε) = ε
```
