# 2.1 ALPHABETS AND STRINGS

The study of computation can be made more formal by the use of alphabets, strings, and languages. The basic goal of this text is to get the student of computer science to understand what it means to “solve a problem,” and similarly, what it means that “a problem has no solution.” Thus, this chapter is devoted to presenting the terms and definitions that will be needed to discuss solving problems in precise terms.

# Definition 2.1

An alphabet is a finite set of symbols (or characters). (The Greek letter Σ is often used to denote an alphabet; occasionally, the letter Γ is used.)

# Examples

```
Σ = {a, b, c}
```

```
Σ = {0, 1}
```

```
Σ = { , , }
```

```
Σ = {a, b, c, d, ..., z, A, B, C, D, E, ..., Z}
```
