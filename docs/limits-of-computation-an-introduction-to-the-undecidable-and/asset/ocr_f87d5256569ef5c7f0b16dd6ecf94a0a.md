Repetition has a higher precedence than concatenation; thus:

$ab^4 = abbbbb$

$(ab)^4 = abababab$

The string $x$ is a **substring** of the string $y$ if for some strings $u$ and $v$, $y = uxv$.

We will use $w_i$ to denote a substring of the string $w$. For instance, if $w = abb$, then $w = w_1w_2$ with $w_1 = ab$ and $w_2 = b$ (as one of several possible ways to divide $abb$ into two substrings).
