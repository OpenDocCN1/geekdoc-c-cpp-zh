# 242 ■ Limits of Computation

2^K > total number of configurations

If c_j is reachable from c_i in any number of steps, it can reached in 2^K (or fewer) steps.

REACHABLE (c_i, c_j, k) for any k ⇔ REACHABLE (c_i, c_j, 2^K)

For a Turing machine that uses s(n) cells, the total number of configurations is

```
|Q| × |Γ|^s(n) × s(n) = constant × 2^(log |Q| + log s(n) + s(n) log |Γ|)
= constant × 2^constant x(n)
```

That is, K = K's(n).
For each of the accepting configurations c_accept, we will determine REACHABLE (c_0, c_accept, 2^K). This will be true if, for some configuration c_m:

REACHABLE (c_0, c_m, 2^(K-1)) and REACHABLE (c_m, c_accept, 2^(K-1))

Thus, our algorithm for REACHABLE (c_i, c_j, 2^K) will be:

```
REACHABLE (c_i, c_j, 2^K) =
for all configurations c
  if REACHABLE (c_i, c_j, 2^(K-1))
    if REACHABLE (c, c_j, 2^(K-1))
      return true
  return false
```

This is a recursive algorithm. There are no more than K = K's(n) calls to REACHABLE at once. For each call, we store the configuration of the caller and K. Each configuration uses O(s(n)) space to store—essentially, the tape (bounded by s(n), with the head position encoded) and the state number, ≤|Q|.

Thus, the total space used is K's(n)s(n) = O(s^2(n)).
