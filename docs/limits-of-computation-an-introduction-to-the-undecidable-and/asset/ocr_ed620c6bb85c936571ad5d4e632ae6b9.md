What does a problem in co-NP look like? The easiest to construct an example is simply to take the complement of a problem in NP. For example, take CNF-SAT = {Boolean expressions with no assignment of truth values to make the expression true. There is a straightforward exponential algorithm to show that an expression in: CNF-SAT—construct the truth table and show that all rows evaluate to false. There is no obvious way to make a shorter shortcut. Unlike showing that one row is true, there seems to be a good short way to show that all rows are false without actually constructing the rows.

Thus, by definition, CNF-SAT is in co-NP. But it seems not to be in NP. Notice, proving that problem is not in NP is nontrivial. One would have to prove that no polynomial certificate exists, and nondeterministic proofs are often difficult (usually assuming existence and getting a contradiction).

Or, consider the complement of the Hamiltonian circuit, HC = {G | there is no way to make a Hamiltonian circuit through G}. One way to check that a graph is in HC would be to try all possible circuits; no easier way is readily apparent. HC is also in co-NP, but almost certainly is not in NP.
