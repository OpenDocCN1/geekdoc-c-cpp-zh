# 1.3 CARDINALITIES

Before we can discuss cardinality, we must review what we mean when we say that two sets are the "same size." For example, consider the two sets below:

{A, B, C} {cow, dog, cat}

The "wrong" answer is that the two sets both have three elements—or perhaps more correctly, counting elements to three is all right, but does not go back to first principles. Why do they have three elements? What does it mean to have three elements? The "right" answer, the one that goes back to the foundations of arithmetic, is that there is a one-to-one correspondence between them—for example, A ↔ cat, B ↔ cow, and C ↔ dog. The reason they have three elements is that each is in one-to-one correspondence with some set that exhibits the basics of "threeness."

# Definition 1.16

Let N_k be the first k natural numbers {0, 1, 2, ..., k−1}. A set S is finite if a bijection exists f: S → N_k for some natural number k.
