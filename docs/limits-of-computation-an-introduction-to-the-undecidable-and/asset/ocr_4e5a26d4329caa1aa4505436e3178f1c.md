Single dominos can be repeated—have duplicates. That is, there are n different dominos, but each domino has an unlimited number of copies. Think of the problem as having a finite number of patterns, but an infinite number of copies of each pattern. Thus, you are not limited to a string of length n or less, but can have arbitrarily long strings.

Note that if any domino has the same string on both the top and the bottom, there is a trivial solution. For example, if a domino is

```
aabc
aaabc
```

then that domino by itself satisfies the criteria.

Note also that once there is a solution, then any concentrated repetition of this solution is also a solution. Thus, there is a shortest solution, but no longest solution, since the supply of dominos never runs out.
