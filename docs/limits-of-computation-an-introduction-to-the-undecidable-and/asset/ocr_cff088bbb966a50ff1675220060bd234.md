And, as usual, v ≤ w if v < w or v = w.
Note that the empty string ε is less than nonempty string w.
This definition can be restated as: if one string is shorter than another, if two strings have the same length, the one that would appear first in a dictionary is smaller.

The homomorphic image of a string is the string with substitutions made for each character. If there are two alphabets Σ₁ and Σ₂, and a mapping h takes each character in Σ₁, to some string of symbols from Σ₂, then this is easily extended to strings over Σ₁, by replacing each character in the string by its image. (The name homomorphism comes from mathematics; it is a function in which f(xy) = f(x)(y)—here, you are given what to do with each symbol; you extend naturally to strings.)

# Example

Let Σ₁ = {0, 1}, Σ₂ = {a, b, c} with 0 → abc, 1 → b (mapping defined on the two elements of Σ₂). That is, h(0) = abc, h(1) = b. Or, informally, what do you do with 0? Replace it with abc. What do you do with 1? Replace it with just b. Now you know what to do with the only two symbols in the alphabet, so you should know what to do with every string over {0, 1}.

```
001 → abcabc h(001) = abcabc
110 → bbabc h(110) = bbabc
0 → abc h(0) = abc
ε → ε h(ε) = ε
```
