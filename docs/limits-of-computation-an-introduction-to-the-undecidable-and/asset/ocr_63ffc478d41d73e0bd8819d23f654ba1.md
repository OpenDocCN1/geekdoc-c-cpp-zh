The 13 unique substrings are therefore:

ε, a, b, c, ac, ba, bba, bbb, bbac, bbba, bbbac

Note from the above examples that a string w of length n has 1 + (n(n + 
1)/2) possible substrings as follows:

+   One substring of length n
Two substrings of length (n - 1)—can remove first or last symbol
Three substrings of length (n - 2)—remove first two, last two, or
one from each end
Four substrings of length (n - 3)
...
n substrings of length 1
One substring of length 0

# Definition 2.5

The length-first lexicographical ordering L(w, w), or simply the lexico-
graphical order, on strings over an alphabet Σ is defined so that v < w if:

+   1. |v| < |w|
2. |v| = |w|, w = σ₁σ₂ ... σn, w = τ₁τ₂ ... τn for some i > 0 such that σᵢ =
tᵢ for j = 1, 2, ..., i - 1, and σᵢ < τᵢ in the ordering of symbols of the
alphabet Σ.
