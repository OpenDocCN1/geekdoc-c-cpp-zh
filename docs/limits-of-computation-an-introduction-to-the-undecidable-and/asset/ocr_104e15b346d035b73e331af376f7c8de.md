# 7.6 UNDECIDABILITY: WHAT DOES IT MEAN?

A question is undecidable if there is no Turing machine that can answer the question and halts on all inputs. Or, equivalently, a question is undecidable if it has no algorithm.

Again, undecidable does not mean that the question can never be answered. Answers can be found in some, maybe even many, cases.

What it means is that there is absolutely no way to write a program that will answer the question in all possible cases. Solving the question is not a matter of being clever or smart enough—it is simply impossible.

For example, take the very first question of ACCEPT; does M accept? One that will answer the question is to feed M and w to the universal Turing machine (UTM), and run the UTM for a fixed time or a number of steps (it would be easy to encode the UTM in a standard programming language, and let this program run for, say, 30 min).

It is possible—even likely—that the universal Turing machine will have found M on w enters of q_accept or q_reject. In the first case, one can say yes, M accepts w in the second, that M does not accept w.

However, if the universal Turing machine has not yet announced that M has accepted or rejected w, one is out of luck. There is nothing to say. Running the machine for another fixed amount of time—but might answer the question.

# 7.7 POST CORRESPONDENCE PROBLEM (OPTIONAL)

One of the most accessible problems from language theory: is it ambiguous? That is, is there some string that has two (or more) different parse trees? This sometimes has an answer—for example, if one can find a string with two parse trees, or one can prove the grammar meets requirements of compiler theory (it is LL(1) or LR(1), etc.). But there is no algorithm that will answer the question for all grammars; that is, the problem is undecidable.

Unfortunately, there is no easily accessible proof of this important fact. To be able to prove that the question is undecidable, the first step will be to consider the Post Correspondence Problem (PCP), which is easy to state, fairly easy to understand, and is important because of its applications to problems like the ambiguity of a grammar.
