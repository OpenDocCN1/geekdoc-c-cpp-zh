PATH = {G = (V, E) with vertices v, w, and there is a path from v to w in G}.

Certificate: Listing of the vertices in the path.

Verifier: Check that the path is legal.

The class of problems that we are next interested in are those that have short certificates, but no known short solutions (“short,” as usual, means bounded by a polynomial in the length of the input). Informally, these are problems where it is hard to find a solution, but easy to check a solution works if you are given one.

The class of problems with short certificates, NP, is called the class of nondeterministic polynomial (decision) problems. Of course, P ⊆ NP, so the problems that are interesting are those in NP-P.

# Definition 8.2

A decision problem is in NP if there is a nondeterministic Turing machine (TM) M that for any instance X_y, M reaches qaccept in time bounded by a polynomial in the size of the input to the machine, |X_y|.

That is, if X is a yes or no instance of the problem, and the length (size) of the encoding of X is n (|X|=n), then there is a nondeterministic Turing (NDTM) M_N and a polynomial p such that:

If X is a yes instance, M_N has a path of length ≤ p(n) to the accept state.

If X is a no instance, M_N has no path to the accept state.

# Definition 8.3

A decision problem is in NP if and only if it has a polynomial verifier.

That is, if X is a yes instance of the problem, then X has a certificate C, and there is a (deterministic) Turing machine M_D that can check (verify) C—that it is valid—and this check is done in a number of steps bounded by a polynomial in the length of the problem.
