# Set Theory ■ 9

Z⁺ = positive integers 1, 2, 3, ...
Z⁺ = Z⁺ × Z⁺ × Z⁺ = {(x, y, z) | x, y, z ∈ Z⁺}

Correspondence: List the triples in some order, for example, start with n = 3.

+   List all that add to n (n initialized to 3) (1, 1, 1) ↔ 1
Increment n, list all that add to n: n = 4 (1, 1, 2) ↔ 2
(1, 2, 1) ↔ 3
(2, 1, 1) ↔ 4
n = 5 (1, 1, 3) ↔ 5
(1, 2, 2) ↔ 6
(1, 3, 1) ↔ 7
(2, 1, 2) ↔ 8
(2, 2, 1) ↔ 9
(3, 1, 1) ↔ 10
n = 6 (1, 1, 4) ↔ 11

etc.
Note the well-defined order. All numbers that add to n (n + 1) are listed before those that add to 1 in the first position are listed before those that begin with 2, and so on; likewise the second position. Thus, with sum n = 12, the first triples are (1, 1, 10), (1, 2, 9) ... (10, 10), (2, 1, 9) ... (10, 1, 1).

Any well-defined order will work, such as the one above—where every triple (r, s, t) will be enumerated at some point when enumerating the triples that sum to u = r + s + t. So the mapping is onto. No two triples match the same integer, so it is also one-to-one and a bijection.

Set 1 = R(0, 1) = reals from 0 to 1, not including 0 or 1.

Correspondence: Any bijective function, for example, f(x) = tan π(x - ½) or g(x) = (x - 1/2)/x(x - 1).
