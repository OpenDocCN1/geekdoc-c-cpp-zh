For decision problems, the only question is yes/no, whether or not a certain string is in a language or not. The job of the Turing machine is simply to take an input string and determine whether the answer is yes or no.

It does this by following a scheme where it looks at memory locations, one at a time, possibly changing the contents, and moving to the next location either or back (right or left). Its set of instructions tells it what to do when reading a certain symbol on its tape.

We think of a Turing machine, then, as an infinitely long tape containing symbols, with a read/write head sitting over one of these symbols. This read/write head is connected to the Turing machine control, which keeps track of which state it is in and gives instructions to the read/write head. # 4.3 FORMAL DEFINITION OF TURING MACHINE

Definition 4.1

A Turing machine M = (Σ, Γ, Q, q_accept, q_reject, q_start, δ) in which:

+   * Σ is the input alphabet with blank B ∉ Σ.
* Γ is the tape alphabet with B ∈ Γ and Σ ⊂ Γ.
* Q is a set of finite states.
* q_accept ∈ Q is the unique accept state.
