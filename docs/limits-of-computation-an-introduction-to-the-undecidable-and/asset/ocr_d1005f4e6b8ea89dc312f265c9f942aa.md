# 9.5 OTHER GRAPH PROBLEMS

The following graph definitions are used in many NP-complete problems. Some such problems are listed with their definitions.

# Definition 9.8

An independent set of size m in G is a set of vertices V', |V'| = m, such that no two vertices of V' are connected by an edge.

# Problem

Given G and m, does G contain an independent set (IS) of size m?

# Definition 9.9

A feedback vertex set of size m in a directed graph G is a set of vertices V such that every circuit in G contains a vertex of V'.
