Consider this reduction from three-coloring of a graph G = (V, E) to CNF-SAT.

For each vertex i = 1, |V|, v[i, 1] \vee v[i, 2] \vee v[i, 3].

For all i, 1 \leq i \leq |V| and all pairs j, k, with 1 \leq j < k \leq 3, v[i, j] \Rightarrow \neg v[i, k].

For each edge ij in E, and for 1 \leq k \leq 3, v[i, k] \Rightarrow \neg v[j, k].

Is this a valid reduction? If yes, show; if not, correct.

Is it polynomial? If yes, show; if not, correct.

Assuming that you now have a valid polynomial reduction, and if it is known that CNF-SAT is NP-complete, what can you say about three-coloring?
