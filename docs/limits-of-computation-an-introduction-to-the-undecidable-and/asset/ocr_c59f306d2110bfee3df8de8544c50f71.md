# 244 ■ Limits of Computation

∀x ∃y same_color (x, y)

means for any cat x, there is a cat same color as x. This is also true, since letting y = x, x is the same color as x.

∀x ∃y same_color (x, y) ∧ (x, y)

means for any cat x, there is a different cat that is the same color as x. This is probably not true; the existence of any uniquely colored cat would make it false.

∀x ∀y same_color (x, y)

is patently false, since this says that all cats are the same color.
If x, y are Boolean variables, their universe is much smaller than the universe of all cats—the only possible values for x and y are false and true, 0 and 1.

∀x∃y (x ∧ y) ∨ (¬x ∧ y)

This expression can be read as “For any x, either true or false, there is a truth value for y which will make the expression true.” So we would need to check it for x = true and x = false.

+   - True: when x = 0, y = 1 makes the expression true
- when x = 1, y = 0 makes it true

∀x∀y (x ∧ y) ∨ (x ∧ ¬y)

This expression says that for both true and false, and for both y and y false, the expression is true. That is not correct.

+   - False: if x = 0, expression is false when y = 0
- if x = 1, expression is false when y = 0

The above expressions are in prenex form—that is, all the quantifiers are at the head of the expression. That is not necessary. However, any quantified Boolean expression can be rewritten in prenex form.
