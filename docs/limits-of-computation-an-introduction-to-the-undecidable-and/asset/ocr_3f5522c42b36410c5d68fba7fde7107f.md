# Definition 5.8

A nondeterministic Turing machine N = (Σ, Γ, Q, q_{accept}, q_{reject}, q_{start}, \delta) in which:

+   - Σ is the **input alphabet** with B ∉ Σ.
- Γ is the **tape alphabet** with B \in Γ and Σ ⊆ Γ.
- Q is a finite **state set**.
- q_{accept} \in Q is the unique **accept state**.
- q_{reject} \in Q is the unique **reject state**.
- q_{start} \in Q is the designated start state.
- \delta: Q - {q_{accept}, q_{reject}] \times Γ \to \mathscr{P}(Q \times {Left, Right}) is the **transition relation**.

Here, \mathscr{P} is the power set, so each element is mapped to—possibly—a set of combinations.

The only difference between this definition and that of its deterministic counterpart occurs in its \delta component. Examine this carefully: it maps into the power set! Thus, the value of \delta(q, \sigma) is a set of zero or more triples, and \delta is a relation and not a function. Thus, it is possible from a certain position (in state q, reading \sigma) that there is no possible move (as in an ordinary TM), or many possible moves.
