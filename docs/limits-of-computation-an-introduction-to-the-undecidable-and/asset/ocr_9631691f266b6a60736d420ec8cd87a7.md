# Limits of Computation

Each of these is a finite sequence of steps that provides a solution to every instance of the computational problem, that is, it is a mapping from the set of all inputs to the set of correct solutions (outputs).

The above definition is quite helpful: it tells us what an algorithm is in functional terms. It does not, however, tell how we arrive at this mapping between input and output. As programmers, we realize that there are many issues surrounding the design, implementation, and execution of a computer algorithm. What logic do we use? What data structures do we need? How do we show that our algorithm is working correctly? There is clearly more attached to the notion of algorithm than this abstract statement.

The word algorithm itself is fairly recent in the English language; older dictionaries do not contain it, though they do contain related word algorithm.

# Trial Definition II (Merriam-Webster’s Collegiate Dictionary, 11th edition)

An algorithm is a “procedure” for solving a mathematical problem (as of finding the greatest common divisor) in a finite number of steps that frequently involves repetition of an operation; broadly, a step-by-step procedure for solving a problem or accomplishing some end, esp. by a computer.

Donald Knuth may have had the most influence on the use of the word, and other computer science terms, with his three-volume book on algorithms, The Art of Computer Programming, which he began in 1962 (when he was a graduate student); it is most recently available in a third edition (1997).

# Trial Definition III (after Knuth, 1968, p. 4)

An algorithm is a finite set of rules that gives a sequence of operations for solving a specific type of problem, with five important features:

+   - Finite: It must always terminate after a finite number of steps.
- Definite: Each step is precisely defined; actions to be carried out must be rigorously and unambiguously specified for each case.
