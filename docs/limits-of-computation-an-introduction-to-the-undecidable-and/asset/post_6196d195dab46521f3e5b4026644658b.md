## Theorem 7.21

The following questions about CFGs $G_1$ and $G_2$ are undecidable:

- 1. $L(G_1) \cap L(G_2) = \varnothing$
- 2. $L(G_1) = L(G_2)$
- 3. $L(G_1) \subseteq L(G_2)$
- 4. $L(G_1) = \Sigma^*$

## Proof

All reductions from PCP to either the question or its complement. Recall that either (yes goes to yes and no to no) OR (yes goes to no and no goes to yes) from an undecidable problem will show that this problem is undecidable.

**Comment:** There are some questions about context-free languages that have algorithms—whether a string $w$ in $L(G)$ is empty, or whether $L(G)$ is infinite. Thus, unlike questions about Turing machines (no nontrivial question about the language accepted is decidable), there are questions about grammars that have algorithms. These algorithms are often nontrivial; for more on, see any standard text on formal language theory. Unfortunately, as the previous two theorems show, there are many questions that have no algorithms.

Thus in an automata course, one finds that: (1) almost every question about deterministic finite automata is decidable, (2) some questions about context-free grammars are decidable, and (3) nontrivial question about the language accepted by Turing machines is decidable. Thus, the power of the machine increases, the number of decidable questions decreases.

# Classes NP and NP-Complete

## 8.1 THE CLASS NP (NONDETERMINISTIC POLYNOMIAL)

Most of the problems met in the field of computer science are in the class P—those decision problems that are easy to solve. In contrast, **NP** will consist of problems that are not easy to solve (though no one has been able to prove this!), but have solutions that are easy to check.

## 8.2 DEFINITION OF P AND NP

## Definition 8.1

The class **P** is the set of all decision problems that have polynomial solutions (that is, they are in $O(p(n))$ for some polynomial $p$ of the input).

In contrast, **NP** will consist of problems that are not easy to solve (though no one has been able to prove this!), but have solutions that are easy to check.

There are two standard ways to define the class **NP**. Nothing mathematical should have two definitions, but these two definitions are equivalent. So, we will give both, and immediately show that they are equivalent. Sometimes it will be easier to use one definition than the other, so it will be useful to have both available.

Note that a instance of a decision problem can have a **certificate**. A certificate is showing how the decision problem is satisfied, that is, what proves that it is a yes instance. For example, it is always possible to think of some kind of certificate for a problem. An actual solution is always a certificate. And, for many problems, there are short certificates—certificates that are shorter than the actual solutions.

- COMPOSITE = {n | n is a positive integer and n is not prime}.
    - Certificate: A pair of numbers $1 < x,y < n$ such that $xy = n$.
    - Verifier: Multiply $x \cdot y$, check that the product is $n$.

- PRIME = {n | n is positive integer} has no obvious short certificate.
    - Certificate: Listing of all primes $p$ from 2 to $n/2$, with their nonzero remainders (mod $p \neq 0$).
    - Verifier: Check these approximately $n/4$ divisions (or see Pratt, 1975) for a polynomial certificate and verifier.

- TAUTOLOGY = {Boolean expressions that are true for all truth assignments}.
    - Certificate: No known short certificate, but certainly the complete truth table would work as a certificate; verify that each row evaluates to.
    - Verifier: Calculate truth table, check that each row evaluates to.
