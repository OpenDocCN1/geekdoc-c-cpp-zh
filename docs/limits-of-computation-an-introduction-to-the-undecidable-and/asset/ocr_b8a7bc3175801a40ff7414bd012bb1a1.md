4.7.2 Given a Turing Machine, Trace Its Operation on a Given String This should be easy. In the start state reading the first symbol of the input string (reading a blank B if the input string is empty). Trace the sequence of configurations of the Turing Machine. At each step, show the (1) state it is in, (2) position of the head, and (3) entire nonblank contents of the tape. You can draw a picture of each configuration, or use the convention of the state followed by the string (position of head underlined), or the other convention with the state embedded in the string.

4.7.3 Given a Turing Machine, Describe the Language It Accepts This can be easy or hard or essentially impossible—a lot depends on the complexity of the Turing machine. The tape alphabet should be obvious (just look at the labels on the arrows). Try a few sample strings, running them through the machine. then, see if you can figure out the logic behind the states and arrows.

4.7.4 Given a Language, Write a Turing Machine That Decides on (or Accepts) This Language

The authors believe that each student should write out a Turing machine or two or three or four—in order to understand their basic operation. This is often tedious, because the operations are very limited.

We recommend beginning with an English description of how the Turing machine will operate—keep this with your final machine. Think of it as comments that allow the reader to understand some very hard-to-read code (i.e., the Turing machine). Then write the Turing machine diagram. Finally, run some strings through the Turing machine to be sure it is operating in the way you expect (that is, test your Turing machine).

For example, writing a machine to accept strings of odd length over {0,1} whose center character is a 1. In English: (1) find the center character (if no center character, string is even length and reject), and (2) accept if this center character is 1.
