**Important Note:** These two theorems prove that a polynomial algo-
rith on a k-tape Turing machine will remain polynomial when trans-
formed to a one-tape machine. That means that if we want to prove that an
algorithm has a polynomial order, but we do not care what the order of the
polynomial is, we can use any number of tapes that we like.

On the other hand, we cannot use a nondeterministic polynomial algo-
rith to show that a problem has a polynomial algorithm. In moving from
nondeterministic to deterministic machines, an algorithm may become
exponential.

# 5.1.5 Other Extensions and Limitations of Turing Machines

There are many other extensions that can be applied to the basic Turing
machine model that are Turing-complete:

+   * Allow multiple heads on one tape.
* Use a two-dimensional infinite tape.
* Replace tape with two stacks of unlimited depth.

The following changes, however, are not Turing-complete:

+   * Replace tape with one stack of unlimited depth (pushdown automa-
or or PDA).
* Allow only use of the input section of the tape (linear bounded
atonom or LBA).

(logspace machine).
