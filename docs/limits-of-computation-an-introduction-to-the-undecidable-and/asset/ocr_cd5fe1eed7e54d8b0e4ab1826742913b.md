# Proof

+   1. SUBSET-SUM is in NP.

SUBSET-SUM-VERIFY(S, T, c) =

Check each element of c corresponds to one distinct element of S. Check that the elements of c add to the target T.

The above verifier is quite simple. Note that the addition of two numbers is proportional to the length of the longer integer, so adding the |S'| elements of the certificate is bounded polynomially.
