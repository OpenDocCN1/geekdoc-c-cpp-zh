There are, however, an infinite number of both instances and solutions to the sorting problem. This distinction is important. Although each instance and each solution to every computational problem must be finite, there may be infinitely many instances.

Consider another familiar problem from introductory computer science—searching.

# Example: Searching Problem

Input: $(k, i_1, i_2, \dots, i_n)$
Output: $(o)$, where $o = TRUE$ if $\exists j [i_j = k]$; $o = FALSE$ otherwise
Alternate output: $(n)$, where $n = j$ if $\exists j [i_j = k 	ext{ and } m < j, i_m 
eq k]$; $n = -1$ otherwise

The input to this computational problem might seem a bit confusing at first. In the first case, the input sequence contains a key $k$ followed by a list of elements $i_1, i_2, \dots, i_n$. The output of the searching problem is $TRUE$ if it exists in this list, or $FALSE$ if it does not.

Just as the sorting problem, there is no upper limit to the number of elements $i$ that might appear in the input sequence—just as long as this number is finite. The empty sequence (), however, is not a valid instance of the searching problem, as a key $k$ must always be the first element of every input sequence.

Note that even though there are only two possible solutions to the searching problem, there are still an infinite number of instances, and therefore an infinite number of question–answer pairings.

# Example: Integer Addition Problem

Input: $(d_1 d_2 \dots d_n, c_1 c_2 \dots c_m)$, where $d_i$ and $c_i$ are digits with base 10
Output: $(b_1 b_2 \dots b_r)$, where this is the proper sum of the two integers

One valid input instance would be (10,341, 79,855); its solution would be (90,196).

The problem of real addition is not a computational problem—there is no way to specify a pair of arbitrary real numbers (or even a single number) as a finite sequence.
