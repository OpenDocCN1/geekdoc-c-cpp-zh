# 3.6.1 Why Polynomial?

It is not truly reasonable to say that all polynomials are small enough to say that an action that takes many steps should be efficient. For example, an algorithm that would take 10,000n¹⁰⁰ steps to do something to an array of size n would not be generally useful. However, this is the standard definition of tractable/reasonable/efficient for mathematical (and other) justifications that we will go into later.

The main reason for the definition is that problems not bounded by a polynomial, whose growth is faster than any polynomial, grow so fast that they are absolutely not efficient. These “superpolynomial” algorithms are exponential, although other functions (such as factorials and functions like n!ᵇⁿ) are superpolynomial.

The definitions of efficient and tractable for algorithms will be revised later chapters, with further justifications. For the moment, it will be enough to see that any superpolynomial algorithm is not efficient. Consider how long it would take a computer with a 1-nanosecond instruction cycle to compute the number of instructions by the first column in Table 3.1.
