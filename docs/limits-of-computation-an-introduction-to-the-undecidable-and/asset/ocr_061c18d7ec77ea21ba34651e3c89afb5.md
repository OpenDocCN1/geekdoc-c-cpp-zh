This is not quite true. No real computer has infinite memory—and a Turing machine does. However, if one is smart enough and rich enough, one can use network storage, multiple disks, and external storage so that in practice, memory is essentially unlimited.

One might think that if one were a good programmer, one could write the program P. However, that is impossible—program P cannot exist.

Note that P must work without running S on I. It could try doing that—run S on I—but if S halts within some reasonable time (say 10 minutes), P can answer “yes, halts.” After 10 minutes, if S is still running, P cannot know whether it will stop soon not. Similarly, after 100 minutes or 100 millennia, the only thing known is that P has not yet terminated.
