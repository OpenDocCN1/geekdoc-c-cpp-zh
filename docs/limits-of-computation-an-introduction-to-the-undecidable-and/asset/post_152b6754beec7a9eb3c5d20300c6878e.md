## Turing Machines

## 4.1 OVERVIEW

Theoretical computer science needs a model of a computer—a perfect machine, not dependent on electricity, chip design, or anything that might have a flaw. This model could run programs in a high-level language such as C++, Java, or Python—but usually be much simpler than that. What is needed is a simple machine such that if a problem can be solved on this machine, then it can be solved on a PC, a supercomputer, or whatever—and vice versa. Moreover, one would also want that a solution “in reasonable time” on a standard computer would be possible if and only if (iff) it could be done in reasonable time on the model machine.

## 4.3 FORMAL DEFINITION OF TURING MACHINE

 4.1 A Turing machine $M = (\Sigma, \Gamma, Q, q_{accept}, q_{reject}, q_{start}, \delta)$ in which:

- $\Sigma$ is the input alphabet.
- $\Gamma$ is the tape alphabet with $B \in \Gamma$.
- $Q$ is a set of finite states.
- $q_{accept} \in Q$ is the unique accept state.
- $q_{reject} \in Q$ is the unique reject state.
- $q_{start} \in Q$ is the specially start state.
- $\delta: Q \setminus \{q_{accept}, q_{reject}\} \times \Gamma \to Q \times \Gamma \times \{left, right\}$ is the transition function.

### 4.3.1 Input Alphabet

The input $\Sigma$ contains all the symbols that can be used as input to a particular Turing machine. As each decision problem specifies its input differently, this alphabet changes depending upon the purpose of the machine. A machine to decide PRIME (given an integer, would need an alphabet to represent the symbols of its input, whereas one to decide the shortest path would need an alphabet to represent a weighted graph (nodes, edges, etc.).

The Turing machine begins with its input written as a string over $\Sigma$ onto an otherwise empty tape (and the head on the first symbol of the string, if there is one). The unused portion of the tape contains blanks (denoted by the marker B). For various reasons (such as finding left and right ends of the string), we restrict the input by requiring that it not contain this B marker. (Side note: if you want something that naturally contains blanks—such as the text of a story—then first replace every blank in the input with something else, such as underscore or # or $\sim$ or whatever).

### 4.3.2 Tape Alphabet

The tape alphabet $\Gamma$ contains all the symbols that could be written onto its tape. As with $\Sigma$, this alphabet varies depending upon the nature of the problem.
