# Definition 5.7

A nondeterministic Turing machine (NDTM) **accepts** a string w if *(or any)* sequence of legal moves from the start state on w reaches $q_{accept}$■

It does not matter if it reaches this 1% of the time, and ended in $q_{reject}$ the other 99%. It still accepts.
In words, for a nondeterministic machine, a string is accepted if there is any possible way to accept it. You can think of this as follows: it is accepted if an omniscipotent being were running the machine, telling it which move to pick. Only if there is absolutely no sequence of moves leading to an accepting state will the machine not accept.

A simple, but perhaps instructive, example would be the design of TM to accept strings that contain the substring 11. Of course, this is easy to do with a standard deterministic TM. But a nondeterministic TM could just guess how many steps to move right. It moves right many times, and then checks that the current symbol and next symbol are both 1. What if they are not? In a string of length 1000 with only one occurrence of 11 (such as $0^{98}11^{50}$), the chances of landing on that first are very small! And if it moves so far that it is off the string? It does not matter. As long as the string contains 11, then there is some way of moving to right and accepting, so it does.
