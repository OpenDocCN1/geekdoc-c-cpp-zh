Figure 6.4 Action of HWDIn.

To show why the Hello World Writing Detector program cannot be written, we will assume that it can. Then, by using self-reference, we arrive at a contradiction, and we will have proved that the program can not exist.

Thus, assuming we can write the Writes Hello World Detector for Programs That Take Input program (call HWDIn for short), we have the machine shown in Figure 6.4.

If we could HWDIn, it would also work on programs without input. For example, the first and third programs above take no input. The second takes input, but one could hold hard values for its input into the program without changing how it runs (except for the inconvenience of rewriting and recompiling for new input values).

Assuming that HWDIn can be written, so so can this Hello World Detector (named simply, HWD), which works on programs with no input. HWD is HWDIn, but any input has been hard coded into HWD. It is shown in Figure 6.5.
