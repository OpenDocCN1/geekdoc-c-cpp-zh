# 10.7 REACHABLE CONFIGURATIONS

In a graph, vertex $v_i$ is reachable from vertex $v_j$ if there is a path between the vertices. There is a simple polynomial algorithm to check this (see Chapter 4).

This has a nice application to Turing machines. We consider a graph that has nodes for every possible configuration of the Turing machine operating on a string $w$ using no than K cells on the tape, with edges between nodes for moves of the transition function $\delta$. There are a lot of these configurations, but only a finite number (see Exercises). There is, of course, one starting configuration $(q_0w_1w_2...w_k)$. Many accepting configurations. Any configuration with state $q_{accept}$—as there is no concern as to what is on the tape—is an accepting configuration.

The question about whether a Turing machine accepts string $w$ can be transformed to the graph question: Is there a path from the starting configuration to any of the accepting configurations?

What is the size of this graph, where every configuration is a node? A Turing machine with Q states, tape alphabet $\Gamma$ using S tape cells, the number of configurations is bounded by

```
$|G| = |Q| \times |\Gamma|^S \times S$
```

Since the Turing machine is one of $|Q|$ possible states, each of the cells contains one of $|\Gamma|$ symbols, and the head is on one of the S cells.
