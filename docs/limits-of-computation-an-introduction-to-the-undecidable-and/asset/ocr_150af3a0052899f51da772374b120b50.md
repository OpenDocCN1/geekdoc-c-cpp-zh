last characters. They cannot be first since the Σ string begins with # and the bottom with a character from Σ; similarly, they cannot be last since the bottom string ends with # and the top with a symbol from the alphabet. Here, it is important to note that the strings are not allowed to be empty.

Thus, suppose the PCP problem has a solution. Then the modified $a_{start}$ is indeed first, and the modified $a_{last}$ is indeed last.

2. The modified

```
$x_0 \quad and \quad x_{n+1}\ny_0 \quad \ y_{n+1}$
```

could appear in the middle of the PCP solution, but only as a pair

```
$$\frac{x_{n+1}}{y_{n+1}}, \frac{x_0}{y_0}$
```

if $x_0/y_0$ were to appear in the middle with some string before it, the bottom string would contain #[, and there is no way to get that substring on the top half. Thus, the match from

```
$$\frac{x_0}{y_0}$
```

to the first occurrence of

```
$$\frac{x_{n+1}}{y_{n+1}}$
```

would also be a match. This is the MPCP solution.

# Theorem 7.16

$ACCEPT_{TM} \leq MPCP$

(where $ACCEPT_{TM} = \{M, w: M \text{ and } w \text{ are encodings of TM } M \text{ and string } w, M \text{ accepts } w\}$).
