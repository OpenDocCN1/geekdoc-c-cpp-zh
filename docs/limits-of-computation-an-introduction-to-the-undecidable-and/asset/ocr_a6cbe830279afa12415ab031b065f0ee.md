# 8.4 PROPERTIES

There are several theorems on polynomial reducibility that are similar to those on the reducibility discussed in Section 7.3.

# Theorem 8.6

If L1 ≤_p L2 and L2 is in P, then so is L1.

# Theorem 8.7

If L1 ≤_p L2 and L1 is not in P, then L2 is not in P.

# Theorem 8.8

If L1 ≤_p L2 and L2 is in NP, then so is L1.
