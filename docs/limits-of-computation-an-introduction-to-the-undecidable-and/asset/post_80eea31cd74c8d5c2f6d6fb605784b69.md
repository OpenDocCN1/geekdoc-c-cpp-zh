## Theorem 7.7

Given a Turing machine, it is undecidable whether the Turing machine accepts the empty string $\epsilon$.

### Proof

This follows the classic pattern. Start with a Turing machine $M$ and its input $w$. We want to build a new $M'$ so that

- $M$ accepts $w \Rightarrow M'$ accepts $\epsilon$ (and maybe other strings too).
- $M$ does not accept $w \Rightarrow M'$ does not accept $\epsilon$.

To do this, we build an $M'$ that has $M$ built into it.
Action of $M'$ on its input $x$:

- Ignore $x$ while $M'$ runs $M$ on $w$.
If $M$ accepts, $M'$ enters its own accept state $q_{M'-accept}$ (so accepts $x$).
If $M$ rejects, $M'$ rejects its input, entering its reject state.

(Should $M$ be looping on $w$, we do not have to state what to do. $M'$ will wait for $M$ to finish on $w$, and that will never occur. So $M'$ is simply waiting, waiting, waiting...).

Now the language of $M'$ depends on what $M$ does on $w$:

- $M$ accepts $w \Rightarrow L(M') = \Sigma^* \Rightarrow M'$ accepts $\epsilon$.
- $M$ does not accept $w \Rightarrow L(M') = \emptyset \Rightarrow M'$ does not accept $\epsilon$.

## Theorem 7.8

Given a Turing machine, it is undecidable whether the Turing machine accepts any string at all (whether its language is nonempty).

### Proof

Exactly the same construction of $M'$ from $M$ will work.

- $M$ accepts $w \Rightarrow L(M') = \Sigma^* \Rightarrow L(M') \neq \emptyset$
- $M$ does not accept $w \Rightarrow L(M') = \emptyset$

## Theorem 7.9

Given a Turing machine, it is undecidable whether the Turing machine accepts all strings (whether its language is $\Sigma^*$).

### Proof

Once more, exactly the same construction of $M'$ from $M$ will work.

- $M$ accepts $w \Rightarrow L(M') = \Sigma^* \Rightarrow M'$ accepts all strings.
- $M$ does not accept $w \Rightarrow L(M') = \emptyset \Rightarrow M'$ does not accept all strings.

## Theorem 7.10

Given a Turing machine and tape symbol $\tau$, it is undecidable whether the Turing machine ever writes $\tau$ during computation on input string $z$.

### Proof

A similar construction will work. We will build $M'$ with input $x$; it will write $\tau$ if and only if $M$ accepts $w$.

First step of $M'$: Run $M$ on $w$.

If $M$ accepts, $M'$ looks at its input. If $x = z$, then $M'$ writes $\tau$ on its tape.
(If $x$ is not $z$, $M'$ can do whatever it wants: it can simply halt and reject or whatever.)
If $M$ does not accept $w$, $M'$ goes to the reject state without writing anything on the tape.
If $M$ is looping on $w$, so is $M'$, simply waiting or looping until $M$ finishes.
$M$ accepts $w \Rightarrow M'$ on $z$ writes $\tau$.
$M$ does not accept $w \Rightarrow M'$ never writes $\tau$ on $z$ (or any other string).

## Theorem 7.11

Given a Turing Machine $M$ and a string $w$, it is undecidable whether $M$ halts on $w$.

**Note:** This is the Halting problem, and the well-known language $HALT_{TM}$ can be defined as

$HALT_{TM} = \{M, w: M \text{ halts on } w\}$

We say that $M$ halts on $w$ if it enters either of the states $q_{accept}$ or $q_{reject}$. These are the only two states without moves out of the state; every other configuration has a next configuration. If $M$ does not accept $w$, we do not say that it loops, although there are many ways in which it can loop (cycle back and forth between adjacent tape squares, move right forward, etc.).

### Proof

We want to show $ACCEPT_{TM} \leq HALT_{TM}$. In this case, we will do slightly differently, but again, we build a machine $M'$ so that $M'$ halts on $w$ and only if $M$ accepts $w$. But here, we do it by letting $M'$ change its state $q_{reject}$ into a new state $q_{new}$. This is a simple cut-and-paste; every occurrence of $q_{reject}$ in the delta function is replaced by $q_{new}$. In $q_{new}$ we add moves so that on every symbol, $M'$ writes a blank and moves. (Technically, we require that $M'$ has its own state $q_{reject}$ so we can add that, but no transitions to it, so it is unreachable).

Now, if $M$ accepts $w$, $M'$ halts on $w$. And if $M$ does not accept $w$, it must either loop on $w$ or reject it—and in either case, $M'$ does not halt on $w$. Thus, goes to yes, goes to no, and answering whether $M'$ halts on $w$ also answers whether $M$ accepts $w$.
