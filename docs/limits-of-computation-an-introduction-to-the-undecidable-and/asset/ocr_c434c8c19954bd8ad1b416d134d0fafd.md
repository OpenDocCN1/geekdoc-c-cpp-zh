# 7.5 RICE’S THEOREM (A SUPER-THEOREM)

In one sense, one theorem—Rice’s theorem—makes all the above theorems unnecessary. What it says, in brief, is that essentially every question about what a Turing machine accepts, what states it enters, or what symbols it writes—these are all undecidable. Thus, we could simply have begun with Rice’s theorem. Then, all of the above theorems would follow immediately.

# Theorem 7.12 (Rice’s Theorem)

A question about Turing machine languages is said to be nontrivial if it is true for some, but not all, Turing machine languages. Any nontrivial question about languages accepted by a Turing machine is undecidable.

> Note: It is actually hard to think of trivial Turing machine questions. Anything interesting (“is finite,” “has at least five strings,” “contains the empty string”) is nontrivial—some languages are yes instances, some are no instances. Only questions such as “is over alphabet,” “contains zero or more strings,” “is a subset of itself” are trivial—the answer is yes (or no) for all languages.

# Proof

We need two languages, one that is a yes instance of this question and one that is no instance. Since the property is nontrivial, there must be both yes and no examples.

Consider the empty language ∅. Suppose it does not have the property (if it does, we need to repeat this proof with modification; see Exercises). Let L be a language that has the property. L is a Turing machine (TM) language, so it is accepted by a TM_L.

Now we need to build M’, again with a given M and w built into it. M’ works as follows on its input x:

```
Run M on w.
If M accepts w, run M_L on x and accept M_L does.
If M rejects w, go to the reject state.
```
