# Theorem 9.14

HC is NP-complete.
The proof of is in four parts:

+   1. HC is in NP
2. VC ≤_p HC (construct transformation, show it is a polynomial)
3. VC ≤_p HC (yes goes to yes)
4. VC ≤_p HC (comes from yes)

1. HC is in NP.
The certificate c is obviously the circuit. Without loss of generality, we can assume that any circuit starts and ends at the first vertex v_i, so there is no need to include v_i in the certificate. Now, what do we need to check?

HAMILTONIAN-CIRCUIT-VERIFY(G, c) =

Check that each element of c is a vertex in G.
Check that each element of c is distinct.
Check that |c| = n - 1.
Check that v_i is not in the certificate.
Check that {v_{n-1}, v_i} is an edge in V.
Check for each c_i, c_{i+1} in c, 1 ≤ i ≤ n - 2.
Check that {c_i, c_{i+1}} is an edge in V.
Clearly, each of the steps needed to verify the certificate is polynomially bounded.

+   2. VC ≤p HC. An instance of VC has a graph G = (V, E) and an integer m. We will use a (fairly complex) version of local replacement to build a new graph G' = (V', E') so that G' has a Hamiltonian circuit if and only if G has a vertex cover of size m.

+   a. The integer m in VC becomes m vertices a_1, ..., a_m. There are no edges from any a_i, to any a_j for i ≠ j.
b. Each edge {v_i, v_j} in G becomes a gadget, which is a set of 12 vertices (in two rows of 6, one row labeled v_{i,j,i,1} to v_{i,j,i,6}, the other labeled v_{i,j,j,1} to v_{i,j,j,6} and 12 edges (down sides, four edges)
