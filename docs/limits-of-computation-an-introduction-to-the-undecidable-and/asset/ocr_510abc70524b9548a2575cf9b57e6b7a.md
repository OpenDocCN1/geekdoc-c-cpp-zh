number of state-character combinations. The maximum degree of non-determinism for all (state, symbol) combinations will be called D. Thus, there are at most D moves from any configuration.

D = maximum number of choices in the delta function

Note that

D ≤ 2 |Q| |Γ|

and that D = 1 when the machine is deterministic.
Consider the integers base (D + 1) generated in lexicographical order:

+   - 1; 2; ... D; all single moves from q_start
- 11; 12; ... DD; all sequences of two moves from q_start
- 111; 112; ... DDD; all sequences of moves of length 3

...

Now a sequence such as 233D2 would mean:

+   - From the start, take the second possible move.
- Now, take the third possible move.
- And again, take the third.
- Now take the Dth possible move.
- Finally, take the second possible move.
- If this accepts, fine.

Else try the next sequence, which will be 233D3.

Note: By using integers D, there is no need to be concerned about numbers with more than one digit. It would be possible to use base 10 (or any other base). However, if D > 9, we will need an extra separator symbol so that one can determine if 233 means (2nd move, 3rd move, 3rd move) or (23rd move, 3rd move) or (233rd move) or ....
