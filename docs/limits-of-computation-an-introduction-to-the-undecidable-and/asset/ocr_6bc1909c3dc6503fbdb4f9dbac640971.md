# Definition 7.13

**Post Correspondence Problem (PCP):** Given $\Sigma$, and $n$ pairs $(a_i, b_i)$, $i = 1$, $\dots, n$, with $a_i$ and $b_i$ strings from $\Sigma^*$ (no string be empty), is there a sequence $i_1, i_2, \dots, i_k$ of integers, not necessarily distinct, $1 \leq i, j \leq n$, so that

$a_{i_1}a_{i_2}\dots a_{i_k} = b_{i_1}b_{i_2}\dots b_{i_k}$

Note that here we are writing the top and bottom of the tile as the pair $(a_i, b_i)$. That is, $(a_i, b_i)$ is another way of writing

$\frac{a_i}{b_i}$

This problem will turn out to be undecidable—there is no algorithm to solve it. If one bounds the problem—adds a number $K$ that $k \leq K$, then the problem is solvable in exponential time (try all subsequences), and is **NP**-complete (see Chapters 8 and 9).

# Theorem 7.14

PCP is undecidable.

# Proof

Nontrivial. First, we will prove that (1) the problem modified PCP (MPCP) $\leq PCP$, and then (2) MPCP is undecidable.
