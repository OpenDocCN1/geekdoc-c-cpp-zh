**Note:** Of course, a deterministic Turing machine is also a nondeterministic machine where the number of choices at each step is exactly one. So the theorem says that a language has an ordinary TM if and only (iff) it has a NDTM.

# Proof (of Theorem 5.9)

The idea is simple: the deterministic Turing machine must try all possible sequences of moves that the nondeterministic machine could make, and accept if it ever finds an accepting sequence of moves. The only complication is how to systematically try all sequences of moves. It can not take a sequence and follow until it reaches a resolution, as it might never do so. And, it does not have to be efficient, so it can restart at the very beginning time.

Thus, it should try:

+   - All sequences of moves of length 1 (all possible configurations that it can reach in one move)
- All sequences of moves of length 2
- All sequences of moves of length 3
