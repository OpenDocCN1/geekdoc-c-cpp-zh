# Limits of Computation

# Definition 1.17

A set S is countable iff there is a surjective function f: N $	o$ S. A set S is infinite iff there is a surjective function f: S $	o$ N.

Georg Cantor (German mathematician, 1845–1918) proved that there are different sizes of infinities. For example, there are obviously an infinite number of natural numbers, since the mapping f(i) = i is a surjective function f: N $	o$ N.

0, 1, 2, 3, 4, 5, ... (base 10)

0, 1, 10, 100, ... (base 2)

There are also an infinite number of real numbers. Even in the half-open interval over the real numbers, R[0, 1) = {x : 0 $\le$ x < 1}, there are an infinite number of numbers (you should be able to find a surjective function from f: R[0, 1) $	o$ N).

Recall that each real number in (or any) interval has a decimal expansion as 0.1210...

These expansions are infinite. Like the decimal for 1/5 or the binary expansion of 1/4, are all zeros after a certain point. Some, like 1/7, have a repeating pattern, and some, like $\pi$/10, have no pattern at all.

But, what kind of infinities are these? More on that shortly.

# 1.4 COUNTING ARGUMENTS AND DIAGONALIZATION

Many sets have the same cardinality; there are one-to-one correspondences between the two. Three simple examples would be:

+   $Z^+$ = positive integers = 1, 2, 3, ...

+   $Z_{2n\ge10}$ = positive integers starting at 10 = 10, 11, 12...

+   Correspondence: f(n) = n + 9

+   $Z^+$ = positive integers = 1, 2, 3, ...

+   $Z_{even}$ = even positive integers = 2, 4, 6, 8, ...

+   Correspondence: f(n) = 2n
