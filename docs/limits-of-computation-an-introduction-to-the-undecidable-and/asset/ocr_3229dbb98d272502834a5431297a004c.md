It is also obvious that any machine can spend limitless time on very limited space. But, what is less obvious is that if space is limited, time can be limited—there is a time bound so that once this is reached, a Turing machine that has not halted will never halt (and thus never accept). If it was here before, in the same state of the same place, with the same tape contents, and since this is a deterministic Turing machine, well then, it must be headed off the same thing it did before, and it will be returning to this configuration again and again.

Thus, there is a limit to the amount of space a Turing machine can use, and if we keep track of all possible Turing machine configurations—there may be a very large number, finite—then if we see any configuration repeated, we will be in an infinite loop. Furthermore, if this number of configurations is K and the Turing machine runs for K+1 steps, then we know (by the pigeonhole principle') that it must have repeated some configuration and be in an infinite loop. Thus, there is no reason to let this Turing machine run for arbitrarily long time periods. After (K+1) steps, it has either accepted or will never accept.
