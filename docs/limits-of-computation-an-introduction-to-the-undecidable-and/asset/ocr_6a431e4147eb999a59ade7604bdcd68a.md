# # Undecidability and Reducibility

# ## 7.1 UNDECIDABLE PROBLEMS: OTHER EXAMPLES

Once we have the first undecidable problem (whether the Turing machine accepts the string w), it is generally not necessary to use contradiction or the property of being self-referential again. Because this language is the basis for so much of what follows, we have given it a special name (ACCEPTTM) and will often be referring back to it. Other texts have also given it special names; Sipser (2006) calls it ATM for acceptance-by-Turingmachine; Cohen (1996) calls it ATM in honor of Alan Mathewson Turing.

ACCEPTTM = {M, w: M is a Turing machine that accepts w}

(by M, we might more properly say “encoding of M, encoding of w”).
This is something that occurs several times in theoretical computer science—the first problem is difficult to prove, and after that, one can use the first problem and the idea of reducibility to prove other problems are in the same category.

The basic idea of reducibility is simple: if one has two questions, and if one knows the answer to question 1 by the answer to question 2, you do not need both answers. Answering question 2 will answer both of them. In some sense, question 2 must be harder (or at least as hard) as question 1, since an answer to it answers both.
