# Algorithms ■ 51

Another better solution uses two stacks. There is a standard algorithm for evaluating binary (and unary) operations with precedence. Note that → is right associative (the other operators are left associative).

Maintain two stacks, one for operators and one for operands. Push left parenthesis and ^, v, ¬ onto the operator stack; push operands (0 or 1) onto one. If the current operator is lower precedence than the one on top of the stack (same precedence and left associative operation), pop the operands, do operation, and push result.

On a right parenthesis, do all operations back to the matching left parenthesis; pop the “left parenthesis.\ This algorithm will produce the value of the expression after pass through the input.
