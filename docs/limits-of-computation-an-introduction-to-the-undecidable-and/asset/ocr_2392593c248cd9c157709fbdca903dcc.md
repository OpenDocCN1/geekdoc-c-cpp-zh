# Definition 8.13

A problem Y is NP-complete if:

+   1. Y is in the class NP.
2. For any problem X in NP, X ≤_p Y.

# Definition 8.14

A problem Y is NP-hard if for any problem X in NP, X ≤_p Y.

There are two requirements for a decision problem to be NP-complete. One must show that it satisfies both 1 and 2. Showing 1 is often easy, and both texts and students tend to neglect it—either forget to mention it or say something such as “obviously in NP,” but one must not simply ignore this constraint.

The class of NP-complete problems is important. These are the hardest problems in NP.

# 8.6 INTRACTABLE AND TRACTABLE—ONCE AGAIN

# Definition 8.15

A problem is intractable if it is NP-hard. A problem is tractable if it is in P, the class of problems with polynomial solutions.

Why these definitions? First, why consider any problem in P to be manageable or tractable or easy? Problems with high-order polynomial solutions, such as an n¹⁰ algorithm or worse, are surely not easy to solve!
