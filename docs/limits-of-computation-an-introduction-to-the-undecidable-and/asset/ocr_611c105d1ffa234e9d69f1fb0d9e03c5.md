# Undecidability and Reducibility ■ 131

Question (or decision problem) 1: Is the temperature too high?
Question (or decision problem) 2: Is the warning light on?

# Example

Sam sees some movies; Ann is a movie critic and sees every movie that comes out. Moreover, her taste exactly agrees with Sam's. If Sam likes a movie, so does Ann; if Sam does not like a movie, Ann does not like it either.

Question 1: We are told that Sam saw movie X. Did he like it (yes/no)?
Question 2: What did Ann think of movie X (Does she like it? yes/no)?

When is a problem harder (or more precisely, as hard or harder) than some other problem? We would surely say that Y is harder than X if knowing the solution to Y would give us the answer (yes or no) to X.

For example, in mathematics, you might want to know if a particular third degree polynomial has an integer root. Your book has an algorithm that works for all polynomials of degree up to 4. So this algorithm would also work for your third degree polynomial. That is, obviously, the prob "integer root of polynomial of degree up to 4" is harder than the same problem with degree to 3.

And clearly, an answer to a question about all polygons would answer a question about quadrilaterals.

The key here is that there is a mapping from one problem to another, and that yes answers of the first to yes answers of the second, while no's of the first becomes no's of the second. Instead of asking the question about the original problem, we only need to ask it for the second. Yes of the second means yes of the first, no means of the first. Answering the second question gives you a two-for-one bonus; you get answers to both problems.

Note that an answer to the first problem gives no bonus; you cannot (necessarily) get all the answers to problem 2 from problem 1. You can get some answers to problem—2 of problem 2, so by following the mapping, you get an answer for that instance of problem 2. If the mapping were onto, that is, if every instance of problem 2 were an image of something from problem 1, and the mapping $P_1$ to $P_2$ had an inverse mapping, then the problems would be equivalent (and answering either would answer both).
