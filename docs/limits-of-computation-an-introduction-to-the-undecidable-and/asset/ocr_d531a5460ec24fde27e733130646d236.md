# Turing-Completeness ■ 105

There is one restriction on tape alphabets Γ. Any alphabet must include the character blank B, so it is natural to encode the blank as 0.

One option would simply be to list the characters of the alphabet in some order, and assign them encodings in that order, starting with 00 (since 0 is the encoding of the blank B).

# Examples

Σ₁ = {a, b, c} would be encoded as:

a = 00

b = 000

c = 0000

Σ₂ = {モ,玄,才} would be encoded as

モ = 00

玄 = 0000

才 = 0000

One problem here is the two different languages,

L₁ = aⁿᵇⁿc²ⁿ

L₂ = モⁿ玄ⁿ才²ⁿ

would have exactly the same strings once they were encoded. However, the two languages, though different, are in some sense the same (they are mathematically isomorphic), so this need not be particularly worrisome. This is the approach that we will use in this book (but like many other conventions, other authors will make choices).
