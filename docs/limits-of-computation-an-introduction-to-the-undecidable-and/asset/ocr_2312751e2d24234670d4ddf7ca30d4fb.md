# Examples of Problems in LOGSPACE

{A, max | a ≤ max for all a in array A} is decidable in space log max.
{w | w is a palindrome over [0.1]*} is decidable in space log [w].
{G | G is a graph with no isolated nodes} is in LOGSPACE.

# 10.13 APPROACHES TO HARD PROBLEMS IN PRACTICE

So, what do you do if you need a solution to a problem that is NP-complete, or worse, PSPACE-complete? Even worse, undecidable?
The bottom line is wary, but

the situation is not hopeless. For one thing, if the problem is NP-hard, it may only be exponential in the worst case. In these hard cases may almost never arise. One approach is to use an exponential algorithm, with the expectation (hope?) that its running time for the usual sort of problem encountered will be reasonable.

In some cases, there may be an algorithm for identifying the worse (exponential) cases. You can then run that algorithm first, and your solution second.

If an approximation to the best solution is good enough (as it may well for Traveling Salesman), many NP-complete problems are known to have polynomial approximation algorithms. There are also probabilistic algorithms, which make random choices in their executions (which is different from nondeterminism). Some decision problems have good probabilistic algorithms, which will answer: “Yes, with probability 0.X.” If this probability is close enough to 1.0, that may be good enough.

Even an undecidable problem may have a solution for the cases you are interested in. Do your research, find what is known, and write a program to solve the problem most of the time.
