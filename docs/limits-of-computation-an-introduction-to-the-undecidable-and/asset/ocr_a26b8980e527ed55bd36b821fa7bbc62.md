+   4. If the original graph G has a vertex cover of size m, then the constructed graph G' has a Hamiltonian circuit. Consider the simple graph G2' in Figure 9.14, which has a vertex cover V' = {v2, v4} of size m = 2, shown with the graph G2' built using the component design transformation described.
Note there are four gadgets, one for each of the edges in the original graph G2, and two external vertices for m = 2, a yes instance of VC for G2.
G2' has a Hamiltonian circuit as shown in Figure 9.15. As there are only two vertices a1 and a2, the circuit is done in two loops, one pass from a1 to a2 and another from a2 to a1. As v2 and v4 in the VC G2 are both adjacent to v1, it is possible to make two passes through the gadget corresponding to either edge {v1, v2} or {v1, v4}, whereas only a path from v4 can reach v3.
