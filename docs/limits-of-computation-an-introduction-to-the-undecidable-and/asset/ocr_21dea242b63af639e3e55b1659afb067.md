# 10.5.2 PRIME

Given a positive integer N, is N prime?

In NP: The certificate is certainly not obvious—the certificate for COMPOSITE is any pair of factors. However, there is also a certificate for PRIME.

In P: The polynomial algorithm is found (Agrawal et al., 2020), so this cannot be our NP-intermediate problem.

# 10.5.3 Graph Isomorphism

Given two graphs G₁ = (V, E) and G₂ = (V, E₂), is there a way to match the vertices of G₁ to those of G₂ so there is an edge between the two vertices of G₂? (Note that we assume that the two graphs have the same number of vertices, v₁, ..., vₙ, otherwise there would be no hope of an isomorphism.)

In NP: The certificate is the vertex correspondence between the two graphs.

It is still unknown whether in P or NP-complete: Open question. It has been proven in P for some special cases of graphs.

# 10.5.4 Other Examples?

Here, are very few examples of possible problems to be in NP, but not NP-complete. Almost any problem that a polynomial certificate has turned out to be in either P or NP-complete. Again, if P = NP, there are no NP-intermediate problems.
