# Classes NP and NP-Complete ■ 173

We do have to show that we can verify that this assignment of truth values makes the whole expression true, and the verification is bounded by time polynomial in the length of the input.

If we want to be very precise, we will have to spend a lot of detail encoding the input and measuring its length. Suppose

```
E = C1 ∧ C2 ∧ C3  ... Cm, each Ci a clause containing some of x1, ..., xn
```

We can imagine a Turing machine with input alphabet Σ = {x, 0, 1, ..., 9, ∧, ∨, (, }. (Aside: All of symbols are not necessarily. We can eliminate the x and some of the logical symbols, and the parentheses (). How? Can we rewrite decimal in binary, to eliminate 2, ..., 9).

The Turing machine would begin with the certificate (a string of length n of 0's and 1's for the values, false or true, for the x1, ..., x50), followed by the expression itself. One could encode x59 ∨ x67 as x59 ¬x67, or just as 59 ∨ ¬67 for the expression (x1 ∧ x3 ∧ x5) ∧ (¬x2 ∨ x4 ∨ x1) ∧ ¬(x1 ∨ x4 ∧ x3) with x1, x2 and x3, true, and x4 and x5 false, might encoded as:

```
11001(x1 ∨ x3 ∨ x5) ∧ (¬x2 ∨ x4 ∨ x1) ∧ (¬x1 ∨ x4 ∧ ¬(x1))
```

which has 45 characters, but it could be encoded in other ways with fewer characters.

It might be easiest to begin by copying the certificate to a second tape. One approach would be to make n passes across the expression. At the ith pass, the machine would look at the value (true or false) and mark any true clause containing, x (if true) and ¬x (if false). After n passes, the expression is true if all clauses are marked true. Getting the true assignment for x would take less than n steps; making a pass over the expression would take less than |E| steps, and is done n times, so the entire procedure would take less than n|E| steps.

The quantities, n, m, and |E| are related. For interesting cases, n is much less than |E|, although it would be possible to have an expression over many variables where only a few of them appeared at all. It is left as an exercise to explore in more detail the relationship between n and |E|. The important number for us is the length of the input, |E|. The bound of n|E| is polynomial in |E|.
