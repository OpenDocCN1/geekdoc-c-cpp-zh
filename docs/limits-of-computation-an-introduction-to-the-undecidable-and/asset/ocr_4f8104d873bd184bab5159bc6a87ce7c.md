The head of this new machine would have to scan the entire tape, remembering (in its states) what should be written for each primed symbol, and where each head should go. It would rescan the tape, making the replacements and changing the symbols left or right to primed symbols.

One complication is that new space may have been created within the string—for example, if all the heads were to move left, the new string would become (if all heads write the same symbol they read) a'bal-B'caal-B'cc, shown in Figure 5.7.

To create space within the string, some part of the string will be shifted right (or left, all shifts are to the right).

Now count what it takes to carry out each of these steps. If the length of the input, on the first tape, started as $|I|$, the length of the nonblank portion of the first tape is at most $t+|I|$, and each of the other $(k-1)$ tapes is at most $t$. There are $(k-1)$ turnstile symbols. Thus, storing all k-tapes on one tape takes at most $|I|+kt+(k-1)$ cells. Note that k is fixed, and for any given input, so is $|I|$, but $t$ increases, so after enough time elapses, $t > k$ and $t > |I|$.

Thus, the length of the nonblank portion (and the time it takes to scan this much of the tape) is

```
$|I|+kt+(k-1) < t+kt+(k-1) < t+kt+t=(k+2)t
when t > |I|$ and $t > k$.
```

Suppose one wants to shift a string of length $L$ to the right. One simple way to do that is:

+   1. Move to right end of string (L steps); move to last symbol (one step).
2. Read this symbol and move right (one step), copy symbol, and move left (one step).
