# 4 Limits of Computation

The **union** of two sets A and B, denoted A ∪ B, is the set {x | x ∈ A or x ∈ B}.
The **intersection** of two sets A and B, denoted A ∩ B, is the set {x | x ∈ A and x ∈ B}.
The **difference** of two sets A and B, denoted A – B, is the set {x | x ∈ A and x ∉ B}.

# Definition 1.7

A **multiset** is a set in which the repetition of elements is important. Order is still irrelevant in a multiset.

# Example

{4, 1, 2, 4, 1} ≠ {4, 1, 2} (for multisets)
{4, 1, 2, 4, 1} = {4, 1, 2} (for sets)
{4, 1, 2, 4, 1} = {1, 1, 2, 4, 4} (for multisets and sets)

# Definition 1.8

A **well-ordered set** is a set in which there is a natural ordering of the elements such that for any distinct elements e₁ and e₂ in the set, either e₁ < e₂ or e₁ > e₂. For example, the English language alphabet {a, b, c, ..., x, y, z} is a well-ordered set. We rely on this fact when we alphabetize.

# Definition 1.9

A **sequence** is a list of objects in an order. Elements in a sequence are listed in parentheses.

# Example

(a, b, r, a, c, a, d, a, b, r, a)
(3, 1, 4, 1, 5, 9, 2)
