# Example: Does a List Contain a Certain Element, the Key?

Algorithm to solve: Find an element key in a list of n elements, if present.

```
Algorithm: (1) read(key)
(2) element = first element
(3) while (element != key) && (element
    <= last)
    (4) element := next element
```

Analysis: initialization: 2 steps, one read, one assignment moving through the list: 2 tests and 1 move, one...n times

> O = 2+3n = O(n)

Note the common simplifications:

All operations assumed to take one step or 1 unit of time.
Worst case counted (best case would be first, average case in center, or ..).

# Example: Is d the Greatest Common Divisor of n, m Positive Integers?

Algorithm: Find GCD using Euclid's algorithm for GCD (n, m), n, m positive integers.

```
(1) while m != 0 do {
  (2) r := n mod m
  (3) n := m
  (4) m := r
} // at end of loop, n is the GCD
(5) if (n==d) return true else return false
```

For the length of the input, we need the number of digits required to express an integer n in base 10. This is calculated by letting x = log10(n + 1), and then taking the ceiling of that number (the next integer above x, or if x is an integer (so, ceiling 5.21 = 6, ceiling 7.00 = 7).
