The first tape will hold the input and never change, to make it easy to
start over with a new sequence of moves.

The second tape holds the working tape in base (D + 1) as above.
The third tape is the working tape—each cycle by copying the
input tape to the working tape. The sequence as read tape 2 is carried
out this working tape. If the machine does not enter q_{accept} the working
tape is erased before the next cycle.

One needs some convention for the action to carry out the move
number called for not exist. For example, what should one do if one
isupposed to make the fourth move from (q_{23} a), and there is only one
move available from (state, symbol) combination? One can either skip
sequence (just erase it and move to the next sequence), or one can
use the convention that the highest k is used for all moves k, k + 1,
... D.

This algorithm is written in pseudocode (see Figure 5.11).
How many steps does this take? The nondeterministic machine
accepts after t steps, the deterministic will have tried all the paths
oflength 1, 2, 3, and so on, up to (t - 1), and some of the paths of length t.

```
n = 1; tape 3 = {1} // try first move out of start
Repeat for all strings on tape 3 of length n
  Copy input tape (tape 1) to working tape (tape 2).
  Repeat until
    (1) no symbol remains on Tape 3 or
    (2) the symbol on Tape 3 is not a valid move or
    (3) a rejecting configuration is found
      Use Tape 2 to simulate one branch of
      nondeterministic computation. Consult Tape 3 at
      every step to determine which choice to make from
      transition function. If an accepting configuration
      found, Accept.
    Erase tape 2
  Change string on Tape 3 to lexicographic next.
Let n = n+1
```
