# Corollary 9.17

The Traveling Salesman Problem (TSP) is NP-hard. [Given a weighted graph G with vertices $v_1 \dots v_n$ and edge $e_{ij}$ with positive integer weight between pair of $v_i,v_j$, what is the length of the shortest path that starts at $v_1$, visits every vertex of G, and returns to $v_1$]?

Note: Since this problem is not a decision problem, it is not a candidate for the class of NP-complete problems, but if one could solve this, one would have a solution to the K-decision TSP.

# 9.7 EUERIAN CIRCUITS (AN INTERESTING PROBLEM IN P)

An interesting note is the problem of Eulerian circuits An Eulerian circuit is a path through the graph from $v_i$ back to $v_i$ such that every edge is included in the path. Eulerian circuits are not required to be simple paths; they can visit a vertex more than once.

The famous Bridges of the Königsberg puzzle can be transformed into an Eulerian circuit problem. One could take a Sunday stroll in the city of Königsberg that would cross each bridge exactly once? The transformation is made making vertices out of islands and mainlands, and connecting land masses if there is a bridge from one to the other. Figure 9.16 shows a map of 1700's Königsberg with the associated multigraph (a multigraph has more than one edge between some pairs of vertices).

It is easy to prove that an Eulerian circuit exists if and only if every vertex has an even degree. This test can easily be done in polynomial time.
