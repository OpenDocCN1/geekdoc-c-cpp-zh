Computer programming is a subtle art. A successful programmer needs more than knowledge of a programming language’s syntax. Getting the most out of any programming language requires a deep understanding of its mechanics (how the syntax elements fit together) and its semantics (how those elements define and control the resulting program’s behavior).

Semantics can be low level, such as the effects of copy-by-value behavior on equality comparisons between objects, or more conceptual, such as the application of different kinds of polymorphism. Semantics also plays a part in application design: carefully designed objects can express different concepts in a system, giving the code structure and meaning.
