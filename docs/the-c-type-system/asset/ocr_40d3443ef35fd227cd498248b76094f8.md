+     - “Primitive Obsession” wiki page, https://wiki.c2.com/?PrimitiveObsession
+     - Refactoring Guru website, https://refactoring.guru/smells/primitive-obsession
+     - Fit wiki page, http://fit.c2.com/wiki.cgi?WholeValue
+     - “The CHECKS Pattern Language of Information Integrity,” by Ward Cunningham, http://c2.com/ppr/checks.html
+   - The Quantity pattern is described in Martin Fowler’s *Analysis Patterns: Reusable Object Models* (Addison-Wesley Professional, 1996). The Primitive Obsession code smell is identified in his book *Refactoring: Improving the Design of Existing Code* (Addison-Wesley Professional, 2018).
