# TABLE 7-2

| PROPERTY | PURPOSE |
|---|---|
| Text | Gets or sets the control's text without any formatting. |
| Rtf | Gets or sets the control's Rich Text Format (RTF) contents. This includes the text plus RTF formatting codes that define how the text should be displayed. |
| SelectedText | Gets or sets the selection's text. |
| SelectedRtf | Gets or sets the selection's text and RTF codes. |

# GIVING THE USER CONTROL

Allowing the user to change text settings is easy. When the user selects text in the control, the RichTextBox sets its SelectionStart and SelectionLength properties accordingly. All you need to do is set the appropriate property (for example, SelectionColor) and the selected text is updated.
