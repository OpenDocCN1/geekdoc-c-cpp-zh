# FIGURE 37-4

Enter your server name in the indicated textbox. If you're running SQL Server Express Edition, follow the server's name with \SQLEXPRESS, as shown in the figure. For example, my computer is named QuarkBeast and I'm running SQL Server Express Edition so I entered QUARKBEAST\SQLEXPRESS in Figure 37-4.

Enter the name of the database on the server (I entered CustomerDatabase in Figure 37-4) and click OK.

> NOTE In the dialog shown in Figure 37-4, if you enter the name of a database that doesn't exist on the server, Visual Studio tells you that the database doesn't exist and asks if you want to create it. If you click Yes, you can use the Server Explorer to build the database. The Server Explorer doesn't provide as many features as a database management tool such as SQL Server Management Studio, but it's handy if you don't have easy access to those tools.
