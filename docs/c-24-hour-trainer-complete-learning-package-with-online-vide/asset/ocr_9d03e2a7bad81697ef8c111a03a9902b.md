# DriveInfo

The `DriveInfo` class provides information about the system's drives. Its static `GetDrives` function returns an array of `DriveInfo` objects describing all of the system's drives. Table 29-1 summarizes the `DriveInfo` class's most useful properties.

TABLE 29-1

| PROPERTY | PURPOSE |
|---|---|
| AvailableFreeSpace | The total number of bytes available. |
| DriveFormat | The drive format, as in NTFS or FAT32. |
| DriveType | The drive type, as in Fixed or CDRom. |
| IsReady | Returns true if the drive is ready. A drive must be ready before you can use the AvailableFreeSpace, DriveFormat, TotalSize, or VolumeLabel properties. |
| Name | The drive's name, as in C:\. |
| RootDirectory | A DirectoryInfo object representing the drive's root directory. |
| TotalFreeSpace | The number of bytes available, taking quotas into account. |
| TotalSize | The drive's total size in bytes. |
| VolumeLabel | The drive's label. |
