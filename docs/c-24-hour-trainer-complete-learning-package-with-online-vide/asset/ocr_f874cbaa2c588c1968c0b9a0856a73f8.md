When the window resizes, the TextBoxes and LinkLabel stretch horizontally, and the PictureBox stretches vertically. Notice in Figure 3-8 that the cover image is rather tall and thin. When the PictureBox grows taller, it can display a larger version of the cover image. The control displays the image as large as possible without distorting it.
