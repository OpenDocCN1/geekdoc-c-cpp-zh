# UNDERSTANDING CLASSES AND INSTANCES

When you add a new form to the project, you're really adding a new type of form, not a new instance of that type. If you add the MakeUserForm type to a project and then run the program, you will still only see the original startup form (with the catchy name Form1) and MakeUserForm is nowhere to be seen.
