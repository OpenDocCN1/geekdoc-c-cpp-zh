# ## Corollary 11.3.

\(r(A+B) \geq |r(A) - r(B)|\).

# ## Proof.

Clearly, \(r(A) = r(A+B-B) \leq r(A+B) + r(-B) = r(A+B) + r(B)\), and hence \(r(A+B) \geq r(A) - r(B)\). Similarly, we have \(r(A+B) \geq r(B) - r(A)\). \(\blacksquare\)

Now recall that for a given matrix \(A \in C^{m \times n}\) the null space \(\mathcal{N}(A) \subseteq C^n\) is a vector space. The dimension of \(\mathcal{N}(A)\) is called the _nullity_ of \(A\) and is denoted by \(n(A)\).

# ## Theorem 11.4.

If \(A \in C^{m \times n}\), then \(r(A) + n(A) = n\).

# ## Proof.

Let \(B\) be a row reduced echelon form of the matrix \(A\). Since the rank of the matrix \(A\) is \(r(A)\), first \(r(A)\) rows of \(B\) will be nonzero, i.e., \(B\) will have \(r(A)\) pivot elements. Thus the linear homogeneous system (5.3) in its equivalent form \(Bx = 0\) will have \(r(A)\) basic variables, and \(n - r(A)\) free variables. Hence, the system (5.3) has a set of \(n - r(A)\) linearly independent solutions, i.e., \(n(A) = n - r(A)\). \(\blacksquare\)

# ## Corollary 11.4.

\(r(A) + n(A^t) = m\).

# ## Corollary 11.5.

If \(r(A) = n \leq m\), then \(n\) columns of \(A\) are linearly independent, and \(x = 0\) is the only solution of the homogeneous linear system (5.3).

# ## Example 11.1.

The row and column echelon form of the matrix

\(A = \left( \begin{array}{ c c c c }
1 & 2 & 1 & 5 \\
1 & 2 & -1 & 1 \\
2 & 4 & -3 & 0
\end{array} \right)\)

are

\(\left( \begin{array}{ c c c c }
1 & 2 & 1 & 5 \\
0 & 0 & 1 & 2 \\
0 & 0 & 0 & 0
\end{array} \right) \text{ and } \left( \begin{array}{ c c c c }
1 & 0 & 0 & 0 \\
1 & 2 & 0 & 0 \\
2 & 5 & 0 & 0
\end{array} \right).\)

Thus, \(r(A) = 2\), the set \(\{(1,2,1,5), (0,0,1,2)\}\) generates \(R(A)\), and the set \(\{(1,1,2)^t, (0,2,5)^t\}\) generates \(C(R)\). From the row echelon form it also follows that the set \(\{(-2,1,0,0)^t, (-3,0,-2,1)^t\}\) generates \(\mathcal{N}(A)\), and \(n(A) = 2\).
