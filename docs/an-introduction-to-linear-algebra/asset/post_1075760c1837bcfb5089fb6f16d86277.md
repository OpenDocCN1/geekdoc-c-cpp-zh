# Chapter 25

# Special Matrices

In this last chapter we shall briefly discuss irreducible, nonnegative, diagonally dominant, monotone, and Toeplitz matrices. These matrices frequently occur in numerical solutions of differential and integral equations, spline functions, problems and methods in physics, statistics, signal processing, discrete Fourier transform, and the study of cyclic codes for error correction.

An \(n \times n\) matrix \(A=(a_{ij})\) is said to be *reducible* if the set of indices \(N=\{1,2,\ldots,n\}\) can be divided into two nonempty disjoint sets \(S\) and \(T\) with \(N=S\cup T\) such that \(a_{ij}=0\) for all \(i\in S\) and \(j\in T\). A square matrix is called *irreducible* if it is not reducible.

**Example 25.1.** The following matrices are reducible

$$
A=\begin{pmatrix}5&3&0\\6&4&0\\0&6&9\end{pmatrix},\qquad
B=\begin{pmatrix}3&2&5\\0&7&1\\0&4&3\end{pmatrix}.
$$

Clearly, for the matrix \(A\), if we take \(S=\{1,2\}\), \(T=\{3\}\) then \(a_{13}=a_{23}=0\), whereas for the matrix \(B\) if \(S=\{2,3\}\), \(T=\{1\}\) then \(a_{21}=a_{31}=0\). The following matrices are irreducible

$$
C=\begin{pmatrix}5&3&1\\6&4&0\\0&6&9\end{pmatrix},\qquad
D=\begin{pmatrix}3&2&5\\0&7&1\\1&4&3\end{pmatrix}.
$$

For this, we need to consider all six possible partitions of the set \(\{1,2,3\}\), i.e.,

\(P_1:S=\{1\},T=\{2,3\};\ P_2:S=\{2\},T=\{1,3\};\ P_3:S=\{3\},T=\{1,2\};\)

\(P_4:S=\{1,2\},T=\{3\};\ P_5:S=\{2,3\},T=\{1\};\) and \(P_6:S=\{1,3\},T=\{2\}\). For the matrix \(C\) in each of these partitions, we have \(a_{12}=3\), \(a_{21}=6\), \(a_{32}=6\), \(a_{13}=1\), \(a_{21}=6\), \(a_{12}=3\). Similarly, for the matrix \(D\), we have \(a_{12}=2\), \(a_{23}=1\), \(a_{32}=4\), \(a_{13}=5\), \(a_{31}=1\), \(a_{12}=2\).

The following result provides necessary and sufficient conditions for an \(n\times n\) matrix to be reducible.

**Theorem 25.1.** An \(n\times n\) matrix \(A\) is reducible if and only if there exists a permutation matrix \(P\) such that

$$
P^tAP=\begin{pmatrix}A_{11}&0\\A_{21}&A_{22}\end{pmatrix}.
$$

**Corollary 25.1.** An \(n\times n\) tridiagonal matrix \(A=(a_{ij})\) is irreducible if and only if \(a_{i,i+1}\ne 0\), \(i=1,\cdots,n-1\) and \(a_{i,i-1}\ne 0\), \(i=2,\cdots,n\).

Matrices in (4.2) and (4.16) are irreducible.

An \(m\times n\) matrix \(A=(a_{ij})\) is said to be *nonnegative* (*positive*) if \(a_{ij}\ge (> )0\), \(1\le i\le m,1\le j\le n\). Eigenvalues and eigenvectors of nonnegative irreducible \(n\times n\) matrices are described by the following result.

# Theorem 25.3 (Perron–Frobenius).

If \(A\) is an \(n\times n\), nonnegative irreducible matrix, then the following hold:

- (i) one of its eigenvalues, say, \(\lambda^*\) is positive, and if \(\lambda\) is any other eigenvalue, then \(|\lambda|\le\lambda^*\)
- (ii) there is a positive eigenvector \(v^*\) corresponding to the eigenvalue \(\lambda^*\)
- (iii) the eigenvalues of modulus \(\lambda^*\) are simple
- (iv) all eigenvalues of modulus \(\lambda^*\) are of the form

$$\lambda_k=\lambda^*\exp\left(\frac{2\pi k\sqrt{-1}}{m}\right),\qquad k=0,1,\cdots,m-1.$$

**Example 25.4.** For the matrix \(C\) in *Example 25.1*, \(\lambda^*\simeq 10.740084\), \(v^*\simeq (1,0.890197,3.064995)^t\), and for the matrix \(D\), \(\lambda^*\simeq 8.074555\), \(v^*=(1,0.688283,0.739598)^t\).

An \(n\times n\) matrix \(A=(a_{ij})\) is said to be *diagonally dominant* if for every row of the matrix, the magnitude of the diagonal entry in a row is larger than or equal to the sum of the magnitudes of all the other (non-diagonal) entries in that row, i.e.,

$$|a_{ii}|\ge\sum_{j=1,j\ne i}^{n}|a_{ij}|\quad\text{for all }1\le i\le n.\tag{25.2}$$

If in (25.2) a strict inequality holds, then \(A\) is called *strictly diagonally dominant*.
