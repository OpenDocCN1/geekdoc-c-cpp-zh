# **Theorem 25.9.**

Let the $n\times n$ matrix $A$ be written as $A=I-B$, where $B=(b_{ij})\geq 0$ and (in any norm) $\|B\|<1$. Then, the matrix $A$ is monotone.

# **Example 25.11.**

Consider the following matrix and its inverse

$$A=\begin{pmatrix}1&-\frac{1}{2}&-\frac{1}{4}\\-\frac{1}{4}&\frac{1}{2}&-\frac{1}{6}\\-\frac{1}{6}&-\frac{1}{3}&1\end{pmatrix},\qquad A^{-1}=\begin{pmatrix}\frac{32}{19}&\frac{42}{19}&\frac{15}{19}\\\frac{20}{19}&\frac{19}{19}&\frac{33}{38}\\\frac{12}{19}&\frac{30}{19}&\frac{27}{19}\end{pmatrix}.$$

From [Theorem 26.6](#) it follows that the matrix $A$ is monotone. Since

$$A=I-B=\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}-\begin{pmatrix}0&\frac{1}{2}&\frac{1}{4}\\\frac{1}{4}&\frac{1}{2}&\frac{1}{6}\\\frac{1}{6}&\frac{1}{3}&0\end{pmatrix},$$

the matrix $B$ satisfies all conditions of [Theorem 25.9](#), and hence matrix $A$ is monotone.

# **Theorem 25.10.**

Let the $n\times n$ matrix $A$ be symmetric, positive definite, and written as $A=I-B$, where $B=(b_{ij})\geq 0$. Then, the matrix $A$ is monotone.
