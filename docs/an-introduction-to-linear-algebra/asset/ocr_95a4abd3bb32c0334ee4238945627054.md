S7. The matrix \(V=(v^1,\cdots,v^r|v^{r+1},\cdots,v^n)\) orthogonally diagonalizes
\(A^tA\); we use Remark 14.2 to extend the set \(\{u^1,\cdots,u^r\}\) to \(\{u^1,\cdots,u^r|u^{r+1},\cdots,u^m\}\), which forms an orthonormal basis for \(R^m\), and construct the matrix
\(U=(u^1,\cdots,u^r|u^{r+1},\cdots,u^m)\); we define the matrix \(\Sigma\) as follows

\(\Sigma=\left(\begin{array}{ c c c }
D_{rr} & \vdots & 0_{r,n-r} \\
\cdots\cdots\cdots & \vdots & \cdots\cdots\cdots \\
0_{m-r,r} & \vdots & 0_{m-r,n-r}
\end{array}\right);\)

here, \(D_{rr}\) is the diagonal matrix

\(D_{rr}=\left(\begin{array}{ c c c c }
\sigma_1 & 0 & \cdots & 0 \\
0 & \sigma_2 & \cdots & 0 \\
\vdots & \vdots & \ddots & \cdots \\
0 & 0 & \cdots & \sigma_r
\end{array}\right)\)

and \(0_{k\ell}\) is the \(k\times\ell\) zero matrix.

S8. We claim that \(U\Sigma=AV\). Indeed, we have

\(U\Sigma=(\sigma_1u^1,\cdots,\sigma_ru^r|0,\cdots,0)\)
\(=(Av^1,\cdots,Av^r|Av^{r+1},\cdots,Av^n)=AV.\)

S9. Using the orthogonality of \(V\), it follows that

\(A=U\Sigma V^t.\) (19.1)

# Theorem 19.1. Every \(m\times n\) matrix \(A\) with rank \(r\) has a singular value
decomposition, i.e, (19.1) holds.

# Proof. The steps S1–S9 provide the constructive proof of (19.1). \(\blacksquare\)

It is clear that for a symmetric matrix, singular value decomposition is the
same as orthogonal diagonalization, provided the eigenvalues are arranged in
a decreasing order.

# Example 19.1. We shall find singular value decomposition of the matrix

\(A=\left(\begin{array}{ c c c c }
2 & 2 & 1 & 0 \\
1 & -1 & 0 & 1
\end{array}\right).\)

For this, we note that

\(A^tA=\left(\begin{array}{ c c c c }
5 & 3 & 2 & 1 \\
3 & 5 & 2 & -1 \\
2 & 2 & 1 & 0 \\
1 & -1 & 0 & 1
\end{array}\right).\)
