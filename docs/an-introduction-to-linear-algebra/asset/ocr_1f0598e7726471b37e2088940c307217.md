where
\(w_1(k+1)=\lambda_1w_1(k),\quad w_1(0)=1w_j(k+1)=\lambda_jw_j(k)+w_{j-1}(k),\quad w_j(0)=0,\quad j=2,\cdots,n.\) (20.21)

**Proof.** Differentiating (20.11) \(k\) times and substituting \(x=0\) gives (20.20),
where \(w_j(k)=r_j^{(k)}(0),\ 1\le j\le n\). \(\blacksquare\)

**Remark 20.2.** The solution of the system (20.21) is
\(w_1(k)=\lambda_1^kw_j(k)=\sum_{\ell=0}^{k-1}\lambda_j^{k-1-\ell}w_{j-1}(\ell),\quad j=2,\cdots,n.\)

**Example 20.7.** For a \(3\times 3\) matrix \(A\) having all the three eigenvalues
equal to \(\lambda_1\) it follows from (20.14) that
\(A^k=\lambda_1^kI+k\lambda_1^{k-1}(A-\lambda_1I)+\frac{1}{2}k(k-1)\lambda_1^{k-2}(A-\lambda_1I)^2.\) (20.22)

In particular, for the matrix \(A\) in Example 20.3, we have
\(A^k=\frac{1}{2}(-1)^k\left(\begin{array}{ c c c }
2-3k-3k^2 & -2k & k+k^2 \\
6k & 2 & -2k \\
-9k-9k^2 & -6k & 2+3k+3k^2
\end{array}\right).\)

**Example 20.8.** For a \(3\times 3\) matrix \(A\) with eigenvalues \(\lambda_1,\lambda_1,\lambda_2\) it follows
from (20.15) that
\(A^k=\lambda_1^kI+k\lambda_1^{k-1}(A-\lambda_1I)+\left\{\frac{k\lambda_1^{k-1}}{(\lambda_1-\lambda_2)}+\frac{\lambda_2^k-\lambda_1^k}{(\lambda_1-\lambda_2)^2}\right\}(A-\lambda_1I)^2.\) (20.23)

In particular, for the matrix \(A\) in Example 20.4, we have
\(A^k=\left(\begin{array}{ c c c }
(-1)^k & 0 & 2(1-(-1)^k) \\
0 & (-1)^k & (1-(-1)^k) \\
0 & 0 & 1
\end{array}\right).\)
