where \(c\) is an arbitrary column vector. From (20.18) it immediately follows
that the unique solution of (20.16), (20.17) is \(\phi(k)=A^ku^0\), \(k \in \mathbb{N}\). Now when
\(A\) is diagonalizable we can state the following result whose proof is similar to
that of Theorem 20.1.

# **Theorem 20.3.** Let the notations and hypotheses of Theorem 20.1 be
satisfied. Then, the set

\(\phi^1(k)=u^1\lambda_1^k,\cdots,\phi^n(k)=u^n\lambda_n^k,k \in \mathbb{N}\)

is a fundamental set of solutions of (20.16).

Further, we note that like (20.1) the general solution of (20.16) can be
written as

\(\phi(k)=A^kc=\sum_{i=1}^nc_i\lambda_i^ku^i=PD(k)P^{-1}c,\) (20.19)

where again \(P=(u^1,\cdots,u^n)\) is the nonsingular matrix, \(c=(c_1,\cdots,c_n)^t\) is
the constant vector, and \(D(k)\) is the diagonal matrix

\(D(k)=\left(\begin{array}{ c c c c }
\lambda_1^k & 0 & \cdots & 0 \\
0 & \lambda_2^k & \cdots & 0 \\
\vdots & \vdots & \ddots & \vdots \\
0 & 0 & \cdots & \lambda_n^k
\end{array}\right).\)

From (20.19) it follows that \(A^k=PD(k)P^{-1}\) provided the matrix \(A\) is diag-
onalizable (see Chapter 18).
