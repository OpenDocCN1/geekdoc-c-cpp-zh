**4.3.** $P^{-1}=\begin{pmatrix}1&-\frac{1}{2}&0\\\frac{\sqrt3}{2}&\frac{1}{2}&0\\0&0&1\end{pmatrix}$, so $P^{-1}AP=\begin{pmatrix}1&0&0\\0&-1&0\\0&0&0\end{pmatrix}$.

**4.4.** If $A$ is upper triangular, then $a_{ij}=0$, $i>j$, and hence $\alpha_{ij}=0$, $j>i$. Now use (4.1).

**4.5.** $(B(A+B)^{-1}A)^{-1}=A^{-1}(A+B)B^{-1}=A^{-1}(AB^{-1}+I)=B^{-1}+A^{-1}$.

**4.6.** $(A+B)^{-1}(A-B)=(A-B)(A+B)^{-1}=\operatorname{tr}(B^{-1}A)=\operatorname{tr}(AB^{-1})$.

**4.7.** $(A^H)^H=(A^{-1})^H=(A^H)^{-1}$. Now $A^{-1}$ is unitary, as follows from $A^H=A^{-1}$. Finally, since $A^H=A^{-1}$ and $B^H=B^{-1}$, we have $(AB)(AB)^H=ABB^HA^H=ABB^{-1}A^{-1}=I$. Thus, $(AB)^H=(AB)^{-1}$, and so $AB$ is unitary.

**4.9.** Since $(I+A)(I-A)=(I-A)(I+A)$, we have $(I-A)=(I+A)^{-1}(I-A)(I+A)$, therefore $(I-A)(I+A)^{-1}=(I+A)^{-1}(I-A)$. Clearly, $(I-A)^t=(I-A^t)$ and $(I+A)^t=(I+A^t)$, thus $B^t=((I+A)(I-A)^{-1})^t=((I-A^t)^{-1}(I+A^t))=(I-A^t)^{-1}(I+A^t)=(I+A^t)^{-1}(I-A^t)=B^{-1}$.
