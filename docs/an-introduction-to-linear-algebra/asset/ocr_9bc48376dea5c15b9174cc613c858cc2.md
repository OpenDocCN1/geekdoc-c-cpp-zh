for example, the matrix

$$A=\begin{pmatrix}1&0&7&3&4\\3&5&7&1&0\\0&4&3&2&7\\6&3&9&0&2\end{pmatrix}$$

can be partitioned as

$$\begin{pmatrix}1&0&7&3&4\\3&5&7&1&0\\0&4&3&2&7\\6&3&9&0&2\end{pmatrix}=\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix},$$

or

$$\begin{pmatrix}1&0&7&3&4\\3&5&7&1&0\\0&4&3&2&7\\6&3&9&0&2\end{pmatrix}=\begin{pmatrix}A_{11}&A_{12}&A_{13}\\A_{21}&A_{22}&A_{23}\\A_{31}&A_{32}&A_{33}\end{pmatrix}.$$

If $A=(A_{ij})_{r\times s}$, $B=(B_{ij})_{s\times t}$ and the blocks $A_{ij},B_{ij}$ are conformable, then $AB=(C_{ij})_{r\times t}$, where

$$C_{ij}=\sum_{k=1}^{s}A_{ik}B_{kj}.$$

In partitioned matrices the blocks can be treated as numbers so that the basic operations between matrices (with blocks of correct orders) can be performed.
