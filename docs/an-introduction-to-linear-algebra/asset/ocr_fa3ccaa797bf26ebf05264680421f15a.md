# Theorem 15.5 (Riesz representation theorem). Let V be a finite dimensional vector space over the field F (F = R, C) on which (., .) is an inner product. Let f : V → F be a linear functional on V. Then, there exists a vector u ∈ V such that f(v) = (v, u) for all v ∈ V.
