## 12.4.3 例 3：药物置换问题

让我们考虑 Maurer 和 Weigand [12] 以及 Bojkov 和 Luus [1] 考虑的时间最优药物置换问题，其中需要在最短时间内使患者血液中两种药物华法林和苯丁酸氮芥达到期望水平。表示这两种药物在患者血液中浓度变化的方程为

$$\frac{dx_1}{dt} = g_1[g_4(0.02 - x_1) + 46.4x_1(u - 2x_2)]$$ (12.30)
