Thus we write the final state constraints as

$|x_i(t_f)| \le \epsilon_i, \qquad i = 1, 2, \cdots, n,$
(12.62)

where we could have a different tolerance for each state variable. Here, for simplicity, we take all the tolerances to be the same, namely $\epsilon_1 = \epsilon_2 = \cdots = \epsilon_n = \epsilon$.

By trying different structures for the augmented performance index, Bojkov and Luus [2] found that the following structure was useful in solving a 20-plate gas absorber time optimal control problem:

$J = \sigma \sum_{i=1}^{n} x_i^2(t_f) + \mu \sum_{i=1}^{n} (|x_i(t_f)| - \epsilon)^2 + \theta t_f,$
(12.63)

where

$\sigma = \begin{cases} 0 & \text{if all } |x_i(t_f)| \le \epsilon \\ 1 & \text{if any } |x_i(t_f)| > \epsilon \end{cases}$
(12.64)

$\mu = \begin{cases} 0 & \text{if all } |x_i(t_f)| \le \epsilon \\ 1 & \text{if any } |x_i(t_f)| > \epsilon \end{cases}$
(12.65)

$\theta = \begin{cases} \epsilon^2/(nQ) & \text{if all } |x_i(t_f)| \le \epsilon \\ 0 & \text{if any } |x_i(t_f)| > \epsilon, \end{cases}$
(12.66)
