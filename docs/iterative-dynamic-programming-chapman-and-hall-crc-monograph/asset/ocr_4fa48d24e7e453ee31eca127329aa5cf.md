# 4.6 Iterations with systematic reduction in region size

The optimal trajectory from the first iteration provides the centre point for the x-grid at each stage, and the optimal control policy from the first iteration gives the central value for the allowable values for control at each stage. The corresponding regions s_i and r_j are contracted by a small amount to provide a finer resolution, and the procedure is continued for a number of iterations. When this procedure is carried out for a sufficiently large number of iterations, it is expected that convergence to the optimal control policy is obtained with sufficient accuracy.
