# Table 2.1: Diet problem with 5 foods

| Food | Utility | Cost dollars | Calories | Protein gm | Iron mg | Maximum allowed |
|---|---|---|---|---|---|---|
| Beer, 12-oz bottle | 100 | 1.25 | 150 | 1.0 | 0.0 | 2 |
| Pizza, sector | 50 | 0.90 | 185 | 7.0 | 0.7 | 3 |
| Hamburger | 25 | 0.99 | 245 | 21.0 | 2.7 | 2 |
| Hot dog | 20 | 1.10 | 270 | 8.6 | 1.3 | 1 |
| Grapefruit | 35 | 0.79 | 90 | 2.0 | 1.0 | 1 |
| **Constraints** |  | 4.00 | 800 | 25 | 3.50 |  |

is

$$I = 100x_1 + 50x_2 + 25x_3 + 20x_4 + 35x_5 \tag{2.19}$$

subject to the constraints

$$1.25x_1 + 0.9x_2 + 0.99x_3 + 1.1x_4 + 0.79x_5 \le 4 \quad (\text{cost}) \tag{2.20}$$

$$150x_1 + 185x_2 + 245x_3 + 270x_4 + 90x_5 \le 800 \quad (\text{calories}) \tag{2.21}$$

$$x_1 + 7x_2 + 21x_3 + 8.6x_4 + 2x_5 \ge 25 \quad (\text{protein}) \tag{2.22}$$

$$0.7x_2 + 2.7x_3 + 1.3x_4 + x_5 \ge 3.5 \quad (\text{iron}) \tag{2.23}$$

with $x_i \ge 0$. We also have upper bounds on each of the foods. Therefore, there are the additional inequality constraints as determined from the last column of Table 2.1:

$$x_1 \le 2 \tag{2.24}$$

$$x_2 \le 3 \tag{2.25}$$

$$x_3 \le 2 \tag{2.26}$$

$$x_4 \le 1 \tag{2.27}$$

$$x_5 \le 1. \tag{2.28}$$

To put this problem into standard form, we start with the inequalities (2.22) and (2.23) and convert them into equalities by subtracting positive semi-definite surplus variables $x_6$ and $x_7$ from the left hand sides to yield

$$x_1 + 7x_2 + 21x_3 + 8.6x_4 + 2x_5 - x_6 = 25 \tag{2.29}$$

$$0.7x_2 + 2.7x_3 + 1.3x_4 + x_5 - x_7 = 3.5. \tag{2.30}$$
