# 11.3 State inequality constraints

# 11.3.1 Problem formulation

Let us consider the system described by the differential equation

```
dx/dt = f(x, u) (11.117)
```

where the initial state x(0) is given. The state vector is x is an (n × 1) vector and u is an (m × 1) control vector bounded by

```
α_j ≤ u_j ≤ β_j,   j = 1, 2, ⋯, m. (11.118)
```

Inside the given time interval there are k state constraints of the form

```
ψ_i(x) ≤ 0,   i = 1, 2, ⋯, k. (11.119)
```

The optimal control problem is to find the control policy u(t) in the time interval 0 ≤ t < t_f that minimizes the performance index

```
I = Φ(x(t_f)) (11.120)
```

where the final time t_f is specified.
