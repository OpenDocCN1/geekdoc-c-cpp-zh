## 13. （Richardson 外推）

二项式方法是一阶精确的，并且可以将二项式价格表示为关于时间步数 n 的渐近展开式如下：

Xₙ = BS + A/n + O(n⁻²)
X₂ₙ₊₁ = BS + A/(2n+1) + O(n⁻²)

其中：

+   Xₙ = n 步的二项式价格
+   A = 与 n 无关的常数
+   BS = 精确的 Black–Scholes 价格（与 n 无关）
+   O(n⁻²) = 如第 17 章所讨论的大 O 记号。

我们希望去除上述渐近展开式中的一阶项，经过简单的代数运算后得到以下形式的新二阶近似：

(1 - n/(2n + 1))⁻¹ (X₂ₙ₊₁ - n/(2n + 1) Xₙ) BS + O(n⁻²). (11.7)
