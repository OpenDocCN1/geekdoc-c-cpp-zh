and

$$\frac{f(x)}{cg(x)}=x^2.$$

Then the algorithm is:

+   1. Generate $U_1$, $U_2$ from $U(0,1)$.
+   2. If $U_2\le U_1^2$ accept $U_1$ as the random variable from $f$. Else, go to step 1.

This is not a very efficient algorithm as approximating quadratic functions by constants is not very accurate. Exercise 4 discusses a more accurate approach.

The second alternative to the inverse transform method is the *composition method*. We use this method when a distribution function $F$ can be expressed as a linear combination of other distribution functions $F_1$, $F_2$, … such that:

$$F(x)=\sum_{j=1}^{\infty}p_jF_j(x),\qquad p_j\ge 0,\qquad \sum_{j=1}^{\infty}p_j=1. \tag{26.14}$$

This method is useful when it is easier to sample from the component distributions than from the distribution $F$ itself. The general steps to sample from $F$ are:

+   1. Generate an index $I$ such that $\operatorname{Prob}(I=i)=p_i$, $i=1,2,\ldots$
+   2. Generate a random variate $x$ with distribution function $F_I$.

We take a simple example:

$$f_X(x)=\frac{5}{12}[1+(x-1)^4],\qquad 0\le x\le 2$$

that we can write as a weighted average:

$$f_X(x)=\frac{5}{6}f_1(x)+\frac{1}{6}f_2(x),\quad 0\le x\le 2$$

where:

$$f_1(x)=1=2,\quad f_2(x)=\frac{5}{2}(x-1)^4,\quad 0\le x\le 2.$$

Some simple algebra shows that:

$$x=\begin{cases}2U, & \text{if } U<5/6\\1+\sqrt[5]{2U}, & \text{if } U\ge 5/6.\end{cases}$$
