# 10.11.1 Conjugate Gradient Method

This method is used for solving a system of simultaneous linear algebraic equations:

AU = F

where A is a given n × n matrix, U is an n × 1 vector of unknowns and F is a known n × 1 vector. In this section we first discuss the CGM algorithm and corresponding C++ code when A is a symmetric matrix and we then discuss the steps of the algorithm when A is a general (not necessarily symmetric) matrix. The algorithm in the case of a symmetric matrix is given by:

r₀ = F − AU₀
p₀ = r₀

for j = 1, ..., n compute:

aⱼ = ||rⱼ||₂² / pⱼᵀ A pⱼ
Uⱼ₊₁ = Uⱼ + aⱼ pⱼ
rⱼ₊₁ = rⱼ − aⱼ A pⱼ
bⱼ = ||rⱼ₊₁||₂² / ||rⱼ||₂²
pⱼ₊₁ = rⱼ₊₁ + bⱼ pⱼ

where rⱼ and pⱼ are vectors of length n for j ≥ 0.
