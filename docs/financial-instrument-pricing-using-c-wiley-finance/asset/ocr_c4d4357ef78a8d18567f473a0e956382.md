# 18.3.2 Inner Products

The concept of the inner (or dot) product of vectors is well known in mathematics. For example, let (a₀, ..., a_J) and (b₀, ..., b_J) be two containers. Then the following properties (and more!) are supported:

```
⎧ ∏_{j=0}^J (a_j ± b_j),  ∏_{j=0}^J a_j * b_j
⎨
⎩ ∑_{j=0}^J (a_j ± b_j),  ∑_{j=0}^J a_j * b_j.   (18.1)
```

```
init Val op1(a₀ op2 b₀) ... op1(a_J op2 b_J).   (18.2)
```
