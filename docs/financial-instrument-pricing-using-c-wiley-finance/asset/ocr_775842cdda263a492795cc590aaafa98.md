bounded domain Ω in n-dimensional space (for more information, see Fichera, 1956, Oleinik and Radkevic, 1973). We depict this domain, its boundary Σ and inward unit normal ν in Figure 20.1. Let us examine the elliptic equation defined by:

Lu ≡ Σ_{i,j=1}^n a_{ij} ∂²u/∂x_i∂x_j + Σ_{i=1}^n b_i ∂u/∂x_i + c u = f in Ω (20.31)

where:

Σ_{i,j=1}^n a_{ij} ξ_i ξ_j ≥ 0 in Ω ∪ Σ ∀ ξ = (ξ₁, ..., ξ_n) ∈ ℝⁿ. (20.32)

The characteristic form (20.32) is strictly positive in most cases but we are interested in where it is zero, and in particular in finding the subsets of the boundary Σ where it is zero. To this end, we define:

Σ₃ = { x ∈ Σ : Σ_{i,j=1}^n a_{ij} ν_i ν_j > 0 }. (20.33)

Only on the boundary where the characteristic form is zero (the characteristic boundary, that is, Σ − Σ₃) do we define the Fichera function:

b ≡ Σ_{i=1}^n ( b_i − Σ_{k=1}^n ∂a_{ik}/∂x_k ) ν_i (20.34)
