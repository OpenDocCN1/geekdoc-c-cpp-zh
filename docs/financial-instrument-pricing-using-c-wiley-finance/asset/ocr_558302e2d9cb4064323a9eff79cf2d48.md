We now show that $L(b,n) \in \Omega(n\log_b n)$. Let $x$ be a variable and let $\lfloor x \rfloor$ be the largest integer not greater than $x$. Let $m = \lfloor n/2 \rfloor$. Then:

$L(b,n) = \sum_{j=1}^{m} \log_b(j) + \sum_{j=m+1}^{n} \log_b(j) \ge \sum_{j=m+1}^{n} \log_b(j) \ge (n - m)\log_b(m + 1)$
$\ge (n/2)\log_b(n/2) = (n/2)(\log_b n - \log_b 2) \ge \left(\frac{n}{2}\right)\left(\log_b n - \frac{1}{2}\log_b n\right)$ for all $n \ge n_0$.

Hence, $L(b,n) \ge \frac{1}{4} n \log_b n$ for all $n \ge n_0$ and we thus conclude that $L(b,n) \in \Omega(n\log_b n)$. Hence, relationship (17.7) has been proved.
