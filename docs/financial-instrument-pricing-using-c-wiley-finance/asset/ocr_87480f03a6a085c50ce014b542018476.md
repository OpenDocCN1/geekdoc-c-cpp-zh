Having decided on the transformation (20.24) we can now rewrite the PDE (20.13) in the new coordinates (y, t). To this end, we perform some algebra. First, the inverse transformation is given by:

x = αy / (1 − y)

and furthermore:

∂y/∂x = (1 − y)² / α, ∂²y/∂x² = −2/α (1 − y)³
∂u/∂x = α⁻¹(1 − y)² ∂u/∂y
∂²u/∂x² = α⁻²(1 − y)² ∂/∂y { (1 − y)² ∂u/∂y }.

In general, we model convection–diffusion–reaction PDEs of the form:

∂u/∂t = a(x, t) ∂²u/∂x² + b(x, t) ∂u/∂x + c(x, t)u + f(x, t),   0 < x < ∞.   (20.26)

When applying the transformation (20.24) we can transform the PDE (20.26) into one involving the variable y with new (modified) drift and diffusion terms:

∂u/∂t = A(x, t) ∂²u/∂y² + B(x, t) ∂u/∂y + C(y, t)u + F(y, t),   0 < x < ∞.   (20.27)

In computational finance the drift and diffusion terms tend to be low-order monomials in x and when transformed they will be products of low-order polynomials, for example in the case when α = 1:

x^β ∂²u/∂x² = (y/(1 − y))^β (1 − y)² ∂/∂y { (1 − y)² ∂u/∂y } = y^β (1 − y)^{2−β} ∂/∂y { (1 − y)² ∂u/∂y }

and

x^β ∂²u/∂x = y^β (1 − y)^{2−β} ∂u/∂y, for β ∈ ℝ.

We now examine the Black–Scholes PDE:

∂V/∂t = ½ σ² S² ∂²u/∂S² + r S ∂V/∂S − r V,   0 < S < ∞, 0 < t < T.   (20.28)
