the quadratic form X^T Σ^{-1} X where X = (X1, X2, X3, X4)^T in equation (16.12), which we have not done. We leave this to the assiduous reader.

For more background on continuous multivariate distributions, see Johnson and Kotz (1972) and Kotz, Balakrishnan and Johnson (2000).

# 16.10 CHOOSER OPTIONS

A chooser option is an option where the holder has the right to choose whether it is a call or a put at some point in its life. The value of a chooser option at the point t1 where the choice is made is given by:

```
w(S, Xc, Xp, t, Tc, Tp) = max[CBSM(S, Xc, Tc), PBSM(S, Xp, Tp)]    (16.18)
```

where CBSM(S, X, T) and PBSM(S, X, T) are the values of the call and put underlying the option, respectively. These types of options can be priced using lattice methods, as discussed in Mun (2002) using the binomial method. A complex chooser option is one that is based on two expiries Tc, Tp and two strikes Kc, Kp. The price of the complex chooser option is then:

```
w = S e^{(b-r)Tc} M(d1, y1; ρ1)
    - Xc e^{-rTc} M(d2, y1 - σ√Tc; ρ1) - S e^{(b-r)Tp} M(-d1, -y2; ρ2)
    + Xp e^{-rTp} M(-d2, -y2 + σ√Tp; ρ2)    (16.19)
```

where:

```
d1 = [log(S/I) + (b + σ²/2)t] / [σ√t],   d2 = d1 - σ√t

y1 = [log(S/Xc) + (b + σ²/2)Tc] / [σ√Tc],   y2 = [log(S/Xp) + (b + σ²/2)Tp] / [σ√Tp]

ρ1 = √(t/Tc),   ρ2 = √(t/Tp)
```

and the value I is the solution of the nonlinear equation:

```
I e^{(b-r)(Tc - t)} N(z1) - Xc e^{-r(Tc - t)} N(z1 - σ√(Tc - t))
    + I e^{(b-r)(Tp - t)} N(-z2) - Xp e^{-r(Tp - t)} N(-z2 + σ√(Tp - t)) = 0    (16.20)

z1 = [log(I/Xc) + (b + σ²/2)(Tc - t)] / [σ√(Tc - t)],   z2 = [log(I/Xp) + (b + σ²/2)(Tp - t)] / [σ√(Tp - t)].
```
