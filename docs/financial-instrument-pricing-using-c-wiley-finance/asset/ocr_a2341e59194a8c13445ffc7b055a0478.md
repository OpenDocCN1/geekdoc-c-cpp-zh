And it uses the following member functions:

```
const u::vector<double>& result() const
{ // Updated value

    return XkP1;
}
```

```
double operator () (double x) const
{ // Function call operator (needed for Brent)

    return func(Xk + (x * gXk));
}
```

    {
        std::cout << "(" << n++ << "," << error << ")";
    }
