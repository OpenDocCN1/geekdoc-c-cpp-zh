
(13.39). 于是我们有 \(f^{(p)}(x)-S^{(p)}(x)=o(\|\Delta_k\|^{3-p})\) （\(p=0, 1, 2, 3\)）（其中 \(f^{(p)}(x)\) 是 \(f\) 对 \(x\) 的 \(p\) 阶导数）。

```
\begin{cases}
a_j U_{j-1} + b_j U_j + c_j U_{j+1} = f_j, \quad 1 \le j \le J-1 \\
U_0 = \alpha U_1 + \varphi \\

\end{cases}

\end{cases}
```
