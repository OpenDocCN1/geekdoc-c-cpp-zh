In the case of ‘AS 26.3.3’ (equation (16.8)) we get the quadrature scheme:

M(a, b, ρ) ≅ ∫_{AL}^{a} Z(x) N(w(x)) dx ≅ ((a - AL)/2) ∑_{j=1}^{n} w_j Z(\tilde{x}_j) N(w(\tilde{x}_j))    (16.11)

where \tilde{x}_j = (a-AL)/2 x_j + (a+AL)/2 , j = 1, ..., n and AL = truncation point.
