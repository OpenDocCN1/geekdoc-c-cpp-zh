Infinity: inf
Epsilon: 1e-99
Return quite NaN: nan
Max rounding error: 0.5

Floating-point types cannot store all real values (those in the set ℝ) exactly. For example, 0.5 can be stored exactly in a binary floating point but not 0.1. What is stored is the nearest representable real value. Fixed-point types (usually decimal) are also defined as exact, in that they only store a fixed precision. The results of computations are rounded up or down.
