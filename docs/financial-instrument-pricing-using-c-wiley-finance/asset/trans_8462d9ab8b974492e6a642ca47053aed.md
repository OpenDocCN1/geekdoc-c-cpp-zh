    {

        {

            {

            }
            return false;
        }

        if (std::abs(b - a) < tol*m)

            return true;
        }
        return false;
    }
};

1. （凸函数和凹函数）
我们现在讨论凸函数和凹函数。定义在区间 [a,b] 上的实函数 f，其中 −∞ < a < b < ∞，如果满足：

f((1 − λ)x + λy) ≤ (1 − λ)f(x) + λf(y) for x,y ∈ (a,b) and 0 ≤ λ ≤ 1.

则称为凸函数。函数 f 被称为凹函数，如果函数 F = −f 是凸的，即：

f((1 − λ)x + λy) ≥ (1 − λ)f(x) + λf(y).

任何凸函数的局部最小值也是全局最小值。
