# Controlling Variable Input

| Input SAS data set | Raw data file |
|---|---|
| DROP= and KEEP= in an input data set | Affects contents of PDV |
| PDV | DROP and KEEP statements DROP= and KEEP= in an output data set Output SAS data set |

The DROP= and KEEP= data set options can be used to exclude variables from processing in
a PROC step.

```
proc print data=orion.employee_addresses
(keep=Employee Name City State Country);
run;
```

However, the DROP= and KEEP= data set options do not affect the order in which the variables are
processed.
