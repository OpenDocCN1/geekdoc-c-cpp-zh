# First. and Last. for Multiple BY Variables

When you use more than one variable in the BY statement, Last.BY-variable=1 for the primary variable forces Last.BY-variable=1 for the secondary variable(s).

| Proj | Dept | First. Proj | Last. Proj | First. Dept | Last.Dept |

| A | ADMIN | 1 | 0 | 1 | 0 |
| A | ADMIN | 0 | 0 | 0 | 0 |
| B | ADMIN | 0 | 1 | 0 | 1 |
| B | ADMIN | 1 | 0 | 1 | 1 |
| B | ENGINR | 0 | 0 | 1 | 0 |

# Multiple BY Variables

Here is the complete DATA step.

```sas
data pdsals(keep=Proj Dept DeptSal NumEmps);
  set proj;
  by Proj Dept;
  if First.Dept then do;
    DeptSal=0;
    NumEmps=0;
  end;
  DeptSal+Salary;
  NumEmps+1;
  if Last.Dept;
```
