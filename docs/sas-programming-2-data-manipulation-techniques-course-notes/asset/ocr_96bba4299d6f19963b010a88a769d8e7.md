# Multiple Data Sets without a Common Variable

You can use the DATA step to merge three or more SAS data sets that lack a common variable.

![](bbox=[0.115, 0.566, 0.513, 0.668])

The BY statement variables must exist on all of the data sets. If the data sets lack a common variable, more than one DATA step is required.
