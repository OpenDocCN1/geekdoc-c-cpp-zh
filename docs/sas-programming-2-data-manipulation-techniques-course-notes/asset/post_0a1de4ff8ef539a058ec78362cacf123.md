## 2.01 Multiple Choice Poll – Correct Answer

Which of the following occurs at the end of a DATA step iteration?

- a. reinitialize the PDV
- b. implicit OUTPUT and implicit RETURN
- c. read the next observation

```sas
data forecast;
set orion.growth;
total_employees *= (1+increase);
run;
implicit OUTPUT;
implicit RETURN;
```

By default, every DATA step performs an implicit OUTPUT and implicit RETURN at the end of each iteration.

## 2.02 Multiple Answer Poll – Correct Answers

Which variable or variables are reinitialized?

Variables created by INPUT and assignment statements are reinitialized. Variables read with a SET statement are not.

## 2.06 Short Answer Poll – Correct Answer

The set orion.employee_addresses contains nine variables. How many variables are in the usa, australia, and other data sets? 4, 6, 9

```sas
data usa (Keep=Employee_Name City State Country)
      australia (drop=Street_ID State Country)
      other;
      set orion.employee_addresses;
      if Country='US' then output usa;
      else if Country='AU' then output australia;
      else output other;
      run;
```

Four variables are kept in usa, three are dropped from australia, and there is no DROP or KEEP for other.

## 2.07 Short Answer Poll – Correct Answer

Country is dropped on input, and therefore it is not available for processing. Every observation is written to other.

      else if Country='AU' then output australia;

## Creating an Accumulating Variable

By default, variables created with an assignment statement are initialized to missing at the top of each iteration of the DATA step.
