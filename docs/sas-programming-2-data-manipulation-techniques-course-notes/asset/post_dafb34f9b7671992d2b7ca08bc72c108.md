# Automatic Character-to-Numeric Conversion

SAS automatically converts a character value to numeric value when the character value is used in a numeric context, such as:
- assignment to a numeric variable
- an arithmetic operation
- logical comparison with a numeric value
- a function that takes numeric arguments

The WHERE statement and the WHERE= option do not perform any automatic conversion.

# Automatic Character-to-Numeric Conversion

The automatic conversion uses informat produces a numeric missing value from a character value that does not conform to standard notation.

# INPUT Function

The INPUT function returns the value produced when the source is read with a specified informat.

```
data conversions;
CV1='32000';
CV2='32000';
CV3='032008';
CV4='030508';
Var1=input(CV1,5.);
Var2=input(CV2,comma.);
Var3=input(CV3,date.);
Var4=input(CV4,ddmm.);
run;
```

If you use the INPUT function to create a variable not previously defined, the type and length of the variable is defined by the informat.

# Explicit Character-to-Numeric Conversion

Continue with the business scenario by creating the variables EmpID, Bonus, and HireDate. Use the INPUT function to explicitly convert values to numeric.

```
data hrdata;
  keep EmpID GrossPay Bonus HireDate;
  set orion.convert;
  EmpID=input(ID,5.)+10000;
  Bonus=input(GrossPay,comma.)*10;
  HireDate=input(Hired,mmddyy10);
run;
```

proc print data=hrdata noobs;
