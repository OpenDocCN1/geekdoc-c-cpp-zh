## BY

BY 语句允许数据分组。

```sas
proc sort data=orion;
  by Dept;
run;

data ssort;
  set orion;
  by Dept;
  sum DeptSal;
  if first(Dept) DeptSal = 0;
  if last(Dept) output;
run;
```

BY 语句用于输出指定的观测值。

SAS 会提前查看下一个观测值来确定 Last.Dept 的值。
