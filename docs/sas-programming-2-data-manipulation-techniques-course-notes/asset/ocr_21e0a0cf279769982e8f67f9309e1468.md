# Substitution within a SAS Literal

There is no SYMBOLGEN message for the secondnreference to site because it is not resolved.

```
68 options symbolgen;
69 let site=Melbourne;
70 proc print data=orion.employee_addresses;
71 where City="&site";
      SYMBOLGEN: Macro variable SITE resolves to Melbourne
72 var Employee_ID Employee_Name;
73 title "Employees from &site";
74 run;
```

# Using Macro Variables within a SAS Literal

If the code requires quotation marks, the macro variable
reference should be enclosed in double quotation marks.

```
%let site=Melbourne;
proc print data=orion.employee_addresses;
where City="&site";nvar Employee_ID Employee_Name;
title "Employees from &site";nrun;
```
