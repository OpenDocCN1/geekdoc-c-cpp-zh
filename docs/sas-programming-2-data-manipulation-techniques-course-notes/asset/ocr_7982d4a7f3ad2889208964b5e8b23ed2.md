# Using a Control Data Set to Create a Format

p210d01

This demonstration illustrates how to create a permanent format from a SAS data set, and start values.

+   1. Submit step 1 to create a SAS data set that contains the format name, labels, and start values.

+   a. The DATA step creates the control data set country.

+   b. Use PROC PRINT to view the new data set.

```
/* Step 1 */
/* Make a CNTLIN data set containing */
/* the variables FMTNAME, START, and */
/* LABEL. */

data country;
  keep Start Label FmtName;
  retain Fmtname '$country'
  set orion.(rename=(Country=Start
  Country_Name=Label));

run;

proc print data=country noobs;
  title 'Country';
run;
```

+   2. Submit Step 2 to use a SAS data set to create the permanent format.

+   a. The first PROC FORMAT creates the format Scountry.

+   b. Use PROC CATALOG to view the contents of the catalog orion.formats.

+   c. The second PROC FORMAT AUGMENTS Scountry by creating a label for missing values.

+   d. Use PROC FORMAT with the FMTLIB option to document Scountry and Sextra.

```
/* Step 2 */
/* Use the data set COUNTRY TO */
/* make the format $country. */

proc format library=orion.MyFmts cntlin=country;
  run;

proc catalog cat=orion.MyFmts;
  contents;
run;
```
