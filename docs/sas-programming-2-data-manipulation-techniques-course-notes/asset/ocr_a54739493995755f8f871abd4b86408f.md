# SAS Variable Lists

| Name prefix | REV: | |
| --- | --- | --- |
| | Specifies all variables that begin with REV, such as REVJAN, REVFEB, and REVMAR. |
| | _ALL_ | Specifies all variables that are already defined in the current DATA step. |
| Special SAS name lists | NUMERIC_ | Specifies all numeric variables that are already defined in the current DATA step. |
| | _CHARACTER_ | Specifies all character variables that are already defined in the current DATA step. |
