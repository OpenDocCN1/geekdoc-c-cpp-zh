
## 4.2 Controlling when a Record Loads

### Placement of the Subsetting IF Statement

Generally, the most efficient place to put the subsetting statement is as soon as all the variables that are needed to evaluate the condition are assigned values.

```sas
data EuropeQ;
infile "path\sales.dat";
input @6 Location $3. @;
if Location = 'EUR';
input @1 SaleID $4.
@10 SaleDate date9.
@20 Amount commax7;
run;
```

![](img/d3bde6e6ab06b1fc622215d982111742_164_0.png)

SAS releases a record held by a trailing @ when the next iteration of the DATA step begins.

### Subsetting Mixed Record Types: Output

```sas
proc print data=EuropeQ1 noobs;
var SaleID Location SaleDate Amount;
run;
```
