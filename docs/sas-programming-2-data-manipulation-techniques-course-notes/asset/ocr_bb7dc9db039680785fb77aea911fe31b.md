The SCAN function returns the nth word of a character value.

The SCAN function is used to extract words from a character value when the relative order of words is known, but their starting positions are not.

The default delimiters are as follows:

```
ASCII (PC, UNIX) blank.<(++|&!$*);-,,%^
EBCDIC (zOS) blank.<(++|&!$*);-,,%|&
```
