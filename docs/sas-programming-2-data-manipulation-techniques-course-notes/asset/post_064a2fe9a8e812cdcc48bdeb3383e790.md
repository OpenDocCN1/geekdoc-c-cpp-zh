data change;
  set orion.employee_donations;

  array Diff{3};
  do i=1 to 3;

  end;
run;

# Assigning Initial Values to an Array

When the initial value list is specified, all elements behave as if they were named in a RETA statement. This is often used to create a lookup table, that is, a list of values to refer to during DATA step.

```sas
array Target{5} (50,100,125,150,200);
```

| Target1 | Target2 | Target3 | Target4 | Target5 |
|---|---|---|---|---|
| 50 | 100 | 125 | 150 | 200 |

(initial-value-list) lists the initial values for the corresponding array elements. The values can be numbers or character strings. Character strings must be enclosed in quotation. Elements are matched by position. If there are more array elements than values, the remaining array elements are assigned missing values and SAS issues a warning.

# 7.4 Using SAS Arrays

# Creating a Temporary Lookup Table

You can use the keyword _TEMPORARY_ in an ARRAY statement to indicate that the elements are not needed in the output data set.

```sas
data compare(drop=i);
 set orion.employee_donations;
 array Contrib{4} Qtr1-Qtr4;
 array Diff{4};
 array Goal{4} temporary (10,20,20,15);
 do i=1 to 4;
 Diff{i}=Contrib{i}-Goal{i};
;
run;
```

p20d17

You can save memory if you do not need to access the individual array element variables by name, the only way you can access the array elements is by subscribing. Arrays of temporary elements are useful when the only purpose for creating an array is to perform a calculation. To preserve the result of the calculation, assign it to a variable.
