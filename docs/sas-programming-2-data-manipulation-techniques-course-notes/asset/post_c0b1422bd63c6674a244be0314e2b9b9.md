### Repetitive Coding

What if the employee wants to determine annual and quarterly interest for a period of 20 years (80 quarters)?

```sas
data compound;
Amount=50000;
Rate=.045;
do i=1 to 20;
    Yearly+Amount*Rate;
end;
do i=1 to 80;
    Quarterly+Amount*Rate/4;
end;
run;
```

### DO Loop Processing

Use DO loops to perform the repetitive calculations.

```sas
data compound (drop=i);
Amount=50000;
Rate=.045;
do i=1 to 20;
  Yearly+Amount*Rate;
end;
do i=1 to 80;
  Quarterly+Amount*Rate/4;
end;
run;
```

### Iterative DO Statement

The values of start, stop, and increment
- must be numbers or expressions that yield numbers
- are established before executing the loop
- if omitted, increment defaults to 1.

Details of index-variable:
- The index-variable is written to the output data set by default.
- At the termination of the loop, the value of index-variable is one increment beyond the stop value.

start specifies the initial value of the index variable.
stop specifies the ending value of the index variable.
increment specifies a positive or negative number to control the incrementing of index-variable.
Changes to the values of stop or increment made within the DO loop do not affect the number of iterations.

### Sample DO Loops with Item Lists

- The DO loop is executed once for each item in the list.
- The list must be comma separated.

```sas
do Month='JAN', 'FEB', 'MAR';
end;
do odd=1,3,5,7,9;
end;
do i=Var1,Var2,Var3;
end;
do index-variable=item-1...item-n;
```
