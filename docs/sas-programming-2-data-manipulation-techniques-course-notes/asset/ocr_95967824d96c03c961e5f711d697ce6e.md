# Data Cleanup: Step 2

```
data correct;
  clean up;
  set option;
  if find(Product,'Mittens','I') > 0 then do;
    substr(Product ID, 9,1)='5';
    Product=Tranwrd(Product, 'Luci', 'Lucky');
end;
```
