# Truncation Functions

Compare the values from the CEIL, FLOOR, and INT functions with a negative argument.

```
data truncate;
Var1=-6.478;
CeilVar1=ceil(Var1);
FloorVar1=floor(Var1);
IntVar1=int(Var1);
```

| Var | CeilVar1 | FloorVar1 | IntVar1 |
| -6.478 | -6 | -7 | -6 |

For values greater than or equal to 0, the FLOOR and INT functions return the same value. For values less than 0, the CEIL and INT functions return the same value.
