# SAS Variable Lists: Examples

Numbered Range List

| Qtr1 | Qtr2 | Var1 | Qtr3 | Qtr4 |

```
Total=sum(of Qtr1-Qtr4)
```

Var1 not included

Name Range List

| Qtr1 | Second | Q3 | Fourth | Var2 |

```
Total=sum(of Qtr1--Fourth)
```

Var2 not included

# SAS Variable Lists: Examples

Name Prefix List

| TotJan | Qtr2 | TotFeb | TotMar |

```
Total=sum(of Tot:)
```

QTR2 not included

Special Name Lists

| Qtr1 | Name | Q3 | Fourth |
| N | $ | N | N |

```
Total=sum(of Numeric_)
```

Name not included

# SAS Variable Lists

| Numbered range lists | x1-xn | Specifies all variables from x1 to xn inclusive. You can begin with any number and end with any number as long as you do not violate the rules for usersupplied variable names and the numbers are consecutive. |

| Name range lists | x--a | Specifies all variables ordered as they are in the program data vector, from x to a |

| | x-numeric-a | Specifies all numeric variables from x to inclusive. |

| | x-character-a | Specifies all character variables from x to inclusive. |
