# 4.1 Reading Data Files with Formatted Input

| Informat | Definition |
|---|---|
| PERCENT | Operates like COMMA.d but divides the number by 100 if it is followed by a percent sign (%). |

If the *d* is not specified, it defaults to 0. This means that COMMA. and COMMA7.0 are equivalent.

If the data contains decimal points, SAS ignores the *d* value and reads the number of decimal places that are actually in the input data. If the data does not contain decimal places, *d* specifies the number of decimal places to imply.

DOLLAR.d is an alias for COMMA.d, and DOLLARX.d is an alias for COMMAX.d.

More information about EUROX.d is available through SAS Help and Documentation.

# SAS Date Informat Examples
Examples of data informats showing the nonstandard raw data values and the converted SAS numeric values:

| Informat | Raw Data Value | SAS Date Value |
|---|---|---|
| MDYY6 | 010160 | 0 |
| MMDDYY8 | 01/01/60 | 0 |
| MMDDYY10 | 01/01/1960 | 0 |
| DDMMYY6 | 311260 | 365 |
| DDMMYY8 | 31/12/60 | 365 |
| DDMMYY10 | 31/12/1960 | 365 |
| DATE7 | 31DEC59 | -1 |
| DATE9 | 31DEC1959 | -1 |

The ANYDTDTEW informat can be used to read data that has a variety of date forms. More information about ANYDTDTEW. is available in SAS Help and Documentation.
