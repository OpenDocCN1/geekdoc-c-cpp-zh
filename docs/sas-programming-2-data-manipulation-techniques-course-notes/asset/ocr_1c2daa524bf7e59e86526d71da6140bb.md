# INT Function

The INT function returns the integer portion of the argument.

```
NewVar=INT(argument);
z=int(3.9);
```

![](bbox=[0.105, 0.246, 0.603, 0.303])

The value of argument is numeric.

# Setup for the Poll

In this program, the values returned from the FLOOR and INT functions are the same.

```
data truncate;
Var=6.478;
CeilVar=ceil(Var);
FloorVar=floor(Var);
IntVar=int(Var);
run;
```
