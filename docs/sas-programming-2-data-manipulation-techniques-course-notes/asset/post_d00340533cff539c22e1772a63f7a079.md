## 7.4 Using SAS Arrays

### Using an Array as a Function
The program below passes an array to the SUM function.

```sas
data test;
  set orion.employee_donations;
  array val{4} Qtr1-Qtr4;
  Tot1=sum(of val*);
  Tot2=sum(of val*);
run;
proc print data=test;
  var Employee_ID Tot1 Tot2;
run;
```

### DIM Function
The DIM function returns the number of elements in an array. This value is often used as the stop value in a DO loop.

```sas
data charity;
  set orion.employee_donations;
  keep Employee_ID Qtr1-Qtr4;
  array Contrib{*} qtr;
  do i=1 to dim(Contrib);
    Contrib{i}=Contrib{i}*1.25;
  end;
run;
```
> DIM(array_name)

![](img/d3bde6eab06b1fc622215d982111742_322_1.png)

The HBOUND function returns the upper bound of an array. The LBOUND function returns the lower bound of an array. The following DO loop processes every element in an array:

```sas
do i=lbound(items) to hbound(items);
  *process items{i};
end;
```

In most arrays, subscripts range from 1 to n, where n is the number of elements in the array. The value 1 is a convenient lower bound. You do not need to specify the lower bound. specifying both bounds is useful when the array dimensions have a beginning point other than 1. For example, the following ARRAY defines an array of 10 elements, with subscripts range from 5 to 14:

```sas
array items{5:14} n5-n14;
```

### Using an Array to Create Numeric Variables
An ARRAY statement can be used to create new variables in the program data vector.

```sas
array Pct{4} Pct1-Pct4;
```

If Pct1 and Pct4 do not exist in the PDV, they are created. This statement produces the same results:

```sas
array Pct{4};
```
