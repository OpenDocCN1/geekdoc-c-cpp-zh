# Using User-Defined Macro Variables

A developer manually changes the year values each time that the following program is submitted. Use user-defined macro variables to simplify program maintenance.

```sas
proc print data=orion.order_fact;
where year (order_date)=2007;
title "Orders for 2007";
run;
proc means data=orion.order_fact mean;
```

# Creating and Using a Macro Variable

Use a %LET statement to create a user-defined macro variable, year, and a macro variable reference, &year, to obtain the value of the macro variable.

```sas
%LET year=2007;
proc print data=orion.order_fact;
where year (order_date)=&year;
title "Orders for &year";
run;
proc means data=orion.order_fact mean;
where year (order_date)=&year;
class order_type;
var total_retail_price;
title "Average Retail Prices for &year";
title2 "by Order Type";
run;
```

# Resulting Code: After Symbolic Substitution

The macro variable references are resolved prior to compilation. The references are replaced with the corresponding text value. The resulting code is sent to the compiler.

```sas
proc print data=orion.order_fact;
  where year (order date) = 2007;
  title "Orders for 2007";
run;
proc means data=orion.order_fact;
  where year (order date) = 2007;
  class order_type;
  var total_retail_price;
  title "Average Retail Prices for 2007";
  title2 "by Order_Type";
run;
```

# Examples of the %LET Statement

- Macro variable values have the following characteristics:
- Minimum length is 0 characters (null value).
- Maximum length is 65,534 characters (64K).
- Numbers are stored as text strings.
- Mathematical expressions are not evaluated.
- Case is preserved.
- Leading and trailing blanks are removed.
- Quotation marks, if any are stored as part of the value.

```sas
%let year=2007;
%let city=Dallas, TX;
```

| Name | Value |
|---|---|
| year | 2007 |
| city | Dallas, TX |

# Displaying Macro Variable Values in the Log

Enable the SYMBOLGEN system option to write a message to the SAS log each time a macro variable is resolved.

```sas
options symbolgen;
let year=2007;
proc means data=orion.order_fact mean;
where year(order_date)=&year;
class order_type;
var total_retail_price;
title "Average Retail Prices for &year";
title2 "by Order_Type";
run;
```

# Substitution within SAS Literal

Double quotation marks enable macro variable resolution and single quotation marks prevent variable resolution.

```sas
%let site=Melbourne;
proc print data=orion.employee_addresses;
where City="&site"
var Employee_ID Employee_Name;
title "Employees from &site";
run;
```

# Using %PUT to Display Macro Variables

To display the names and values of all user-defined macro variables, use this form of the %PUT statement:

Partial SAS Log

```sas
%put user_;
```

```sas
%put user_;
GLOBAL SITE Melbourne
GLOBAL YEAR 2007
```

To display both user-defined and automatic macro variables, use this form of the %PUT statement:

Partial SAS Log

```sas
%put all_;
```

```sas
%put all_;
GLOBAL SITE Melbourne
GLOBAL YEAR 2007
AUTOMATIC AFDSID 0
AUTOMATIC AFDSNAME
AUTOMATIC AFLIB1
```
