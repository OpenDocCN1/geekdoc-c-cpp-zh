# Using PROC SQL to Join Tables

The Employee_ID column appears in both tables,
so it must be qualified to identify which variable is
selected.

# Using PROC SQL to Join Tables

To qualify the column, use the table name as a prefix
when the column is referenced.

```
proc sql number;
select sales_mgmt.Employee_ID,
Employee_Name,
Job Title,
Salary
from orion.sales_mgmt,
orion.employee_addresses;
quit;
```
