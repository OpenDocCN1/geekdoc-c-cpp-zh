
## 2.3 Selecting Variables and Observations

### Using OBS= and FIRSTSTOBS= in a PROC Step

The FIRSTSTOBS and OBS= data set options can also be used in SAS procedures. The PROC PRINT step below begins processing at observation 10 and ends after observation 15.

```sas
proc print data=orion.employee_addresses
   (firststobs=10 obs=15);
   var Employee Name City State Country;
run;
```

### Adding a WHERE Statement

When the FIRSTOBS= or OBS= option and the WHERE statement are used together, the following occurs:

- The subsetting WHERE is applied first.
- The FIRSTOBS= and OBS= options are applied to the resulting observations.

The following step includes a WHERE statement and an OBS= option:

```sas
proc data=orion.employee_addresses
  (obs=10);
  where Country='AU';
  var Employee Name City Country;
run;
```

## 2.4 Solutions

Solutions to Exercises

- 1. Writing Observations Explicitly

```sas
data work.sales;
set orion.employee_organization;
where Department='Sales';
keep Employee_ID Job_Title Manager_ID;
run;

data work.exec;
set orion.employee_organization;
where Department='Executives';
keep Employee_ID Job_Title;
run;
```

- 2. Print only the first six observations from work.sales.

```sas
proc print data=work.sales (obs=6);
   title "Sales Employees";
run;
```

- 3. Print selected observations from work.exec.

```sas
proc print data=work.exec (firstobs=2 lastobs=3)
   title "Executives";
run;
```

- 4. Creating Variables

```sas
data work.instore;
set orion.orders;
where Order_Type=1;
ShipDays = date(Delivery) - date(Order);
if ShipDays=0 then output;

data work.delivery;
set orion.orders;
where Order_Type=1;
ShipDays = date(Delivery) - date(Order);
if ShipDays>0 then output;
```

- 5. Modify the program to read all order.orders.

```sas
data work.delivery;
set orion.orders;
ShipDays = date(Delivery) - date(Order);
if ShipDays>0 then output;
```

- 6. Use PROC FREQ.

```sas
proc freq data=work.instore;
   table Order_Date,year.;
   title "In-stock Store Purchases, By Year";
run;
```
