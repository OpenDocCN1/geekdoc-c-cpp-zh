# 4.1 Reading Raw Data Files with Formatted Input

| Statement | Description |
| --- | --- |
| INFILE 'raw-data-file-name': | The INFILE statement identifies the physical name of the raw data file to read with an INPUT statement.

*raw-data-file-name'* is the physical name that the operating environment uses to access the file of raw data.

Examples:
| Windows | infile 's:\workshop\offers.dat'; |
| UNIX | infile '/users/userid/offers.dat'; |
| z/OS (OS/390) | infile 'useridid.workshop.rawdata(offers)'; |

The PAD and LRECL= options can be useful for reading variable-length records typically found in Windows and UNIX environments. See SAS Help and Documentation for more information about the PAD and LRECL= options.

INPUT specifications; The INPUT statement describes the arrangement of values in the raw data file and assigns input values to the corresponding SAS variables.
