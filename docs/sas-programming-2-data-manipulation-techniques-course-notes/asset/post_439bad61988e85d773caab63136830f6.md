# Advantages of PROC SQL and the DATA Step

With the SQL procedure, you can do the following:

- Join tables and produce a report in one step without creating a SAS data set
- Join tables without presorting the data
- Use complex matching criteria

With the DATA step, you can do the following:

- Create multiple data sets
- Direct output to data sets based on data set contributors
- Use First. and Last. processing
- Use DO loops and arrays
- Perform complex data manipulation

The SELECT statement syntax shows the clauses allowed and the order in which they must be written.

```sql
SELECT <DISTINCT> object-item < ...object-item>
INTO macro-variable-specification<, macro-variable-specification>
FROM from-list
<WHERE sql-expression>
<GROUP BY group-by-item, ... group-by-item>
<HAVING sql-expression>
<ORDER BY order-by-item<, order-by-item>>;
```

# Purpose of the Macro Facility

The *macro facility* is a text-processing facility that supports symbolic substitution within SAS code.

![](img/d3bde6e6ab06b1fc622215d982111742_452_0.png)

# Types of Macro Variables

There are two types of macro variables.

# System-Defined Automatic Macro Variables

Automatic macro variables are set at SAS invocation and are always available. These include the following:

| Name | Description |
| --- | --- |
| SYSDATE | Date of SAS invocation (DATE7.) |
| SYSDATE | Date of SAS invocation (DATE9.) |
| SYSDAY | Day of the week of SAS invocation |
| SYSTEM | Time of SAS invocation |
| SYSSCP | Abbreviation for the operating system: OS, WIN, HP 64, and so on |
| SYSVER | Release of SAS software being used |

To refer to a macro variable, use &macro-variable-name.

# Using Automatic Macro Variables

Automatic macro variables can be used to avoid hardcoding values.

```sas
proc print data=orion.customer_type noobobs:
title "Listing of Customer_Type Data Set";
footnot "Created &atime &sysday, &sysdate";
footnote2 "on the &syscap System Using Release &sysver";
run;
```

Prior to compilation, the macro references are replaced with the values of the corresponding macro variables.

```sas
proc print data=orion.customer_type noobobs:
title "Listing of Customer_Type Data Set";
footnot "Created 12:22 Tuesday, 14FEB2012";
footnote2 "on the WIN System Using Release 9.3";
run;
```
