# CEIL Function

The CEIL function returns the smallest integer greater than or equal to the argument.

```
NewVar=CEIL(argument); x=ceil(4.4);
```

![](bbox=[0.11815, 0.24633000000000002, 0.62485, 0.31633])

The value of argument is numeric.

# FLOOR Function

The FLOOR function returns the greatest integer less than or equal to the argument.

```
NewVar=FLOOR(argument); y=floor(3.6);
```

![](bbox=[0.11815, 0.62433, 0.62485, 0.69433])

The value of argument is numeric.
