# 5.5 Converting Variable Type 5-77

An analyst at Orion Star has written a SAS program to calculate the total price of the items shipped and create a comment that includes the ship date. Unfortunately, the SAS program is giving unexpected results.

a. Open and submit the program p205e10.sas.

b. View the unexpected results.

|---|---|---|---|---|--|
| 24080200021 | 05JAN2011 | 2 | $42.45 | Shipped on 18632 | . |
| 24080200035 | 04JAN2011 | 6 | $12.15 | Shipped on 18631 | . |
| 24020100225 | 04JAN2011 | 2 | $77.85 | Shipped on 18631 | . |
| 21020500002 | 09JAN2011 | 3 | $5.70 | Shipped on 18638 | . |

c. Modify the program to get the expected results.

Partial PROC PRINT Output

| Product_ID | Ship_Date | Quantity | Price | Comment | Total |
|---|---|---|---|---|--|
| 24080200021 | 05JAN2011 | 2 | $42.45 | Shipped on 01/05/2011 | $84.90 |
| 24080200035 | 04JAN2011 | 6 | $12.15 | Shipped on 01/04/2011 | $72.90 |
| 24020100225 | 04JAN2011 | 2 | $77.85 | Shipped on 01/04/2011 | $155.70 |
| 21020500002 | 09JAN2011 | 3 | $5.70 | Shipped on 01/09/2011 | $17.10 |

- Look about the PROC CONTENTS output for orion.ship.
- Notice that Ship_Date is numeric with a permanently assigned DATE9. format. It needs to be converted into a character value using the MMDYY10 format.
- Notice that Price is character. It needs to be converted into a numeric value using the COMMA7. or DOLLAR*.
- Use functions to convert the values of Ship_Date and Price to get the desired results.
