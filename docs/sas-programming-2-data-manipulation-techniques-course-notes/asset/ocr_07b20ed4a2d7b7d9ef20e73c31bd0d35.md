# SUM Function

A RETA statement along with a SUM function in an assignment statement can be used to create Mth2Dte.

```
data mnthtot;
set orion.aprsales;
retain Mth2Dte 0;
Mth2Dte=sum(Mth2Dte, SaleAmt);
run;
```

+   - The SUM function ignores missing values.
