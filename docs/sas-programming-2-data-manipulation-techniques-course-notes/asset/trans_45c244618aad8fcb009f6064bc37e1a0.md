SCAN 函数返回字符值的第 n 个单词。当位置未知时，使用 SCAN 函数从字符串中提取单词。

默认分隔符如下：
```
ASCII (空格)
EBCDIC (逗号)
```

## SCAN 函数详情

当你使用 SCAN 时：

- 如果单词少于 n，则返回缺失值。
- 如果 n 为负数，SCAN 函数从字符串末尾选择单词。
- 两个或多个连续分隔符被视为单个分隔符。
