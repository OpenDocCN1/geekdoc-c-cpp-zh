# Compilation: What Variables Are Created?

```
data compare(drop=i Goall1-Goal4);
  set orion.employee donations;
  array Contrib{4} Qtr1-Qtr4;
  array Diff{4};
  array Goal{4} (10,20,20,15);
  do i=1 to 4;
    Diff(i)=Contrib{i}-Goal{i};
  end;
run;
```
