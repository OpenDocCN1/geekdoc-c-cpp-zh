# SQL Procedure: Syntax Overview

PROC SQL statement signals the start of an SQL procedure.

The QUIT statement ends an SQL procedure. A RUN statement is not needed because the query is executed when the semicolon is reached.

```
options ls=80; PROC SQL;
proc sql;
select *
from orion.sales_mgmt;
quit;
QUIT;
```

The QUIT statement is omitted, the SQL procedure remains in memory to process subsequent queries. A QUIT statement or the start of another step terminates the SQL procedure and removes it from memory.
