

# SUM 函数忽略缺失值

SUM 函数会忽略缺失值。它可以用于计算季度贡献额与相应目标之间的差值。

```sas
data compare(drop=i);
  set orion.employee_donations;
  array Contrib{4} Qtr1-Qtr4;
  array Diff{4};
  array Goal{4}_temporary (10,20,20,15);
  do i=1 to 4;
    Diff{i}=sum(Contrib{i},-Goal{i});
  end;
run;
```

# 输出：查找表应用

```sas
proc print data=compare noobs;
  var employee_id diff1-diff4;
run;
```

部分 PROC PRINT 输出（共 124 条观测值）

|---|---|---|---|---|
| 120265 | -10 | -20 | -20 | 10 |
| 120267 | 5 | -5 | -5 | 0 |
| 120269 | 10 | 0 | 0 | 5 |
| 120270 | 10 | -10 | -15 | -15 |
| 120271 | 10 | 0 | 0 | 5 |

缺失值的处理方式相当于该季度没有产生贡献。

## 7.5 答案

1. 使用 DO 循环计算

```sas
data future_expenses;
  drop start stop;
  Wages=1287400;
  Retire=1765000;
  Medical=649000;
  start=year(today())+1;
  stop=start;
  do Year=start to stop;
    wages = wages * 1.06;
    retire=retire*0.014;
    medical=medical*1.095;
    Total_Cost=sum(wages,retire,medical);
    output;
  end;
```

data future_expenses;

  do Year=year(today())+1 to year(today())+10;

# 使用条件 DO 循环计算

```sas
data income_expenses;
  Wages=1287400;
  Retire=1765000;
  Medical=649000;
  Income=5000000;
  start=year(today())+1;
  do until (Total_Cost > Income);
    wages = wages * 1.06;
    retire=retire*0.014;
    medical=medical*1.095;
    Total_Cost=sum(wages,retire,medical);
    output;
    year+1;
  end;
run;
```

# 使用带有语句的迭代 DO 循环

```sas
data expenses;
  Income=5000000;
  Expenses = 3875000;
  do Year=1 to 30;
    income+(income * .01);
    expenses+(expenses * .02);
  end;
run

proc print data=expenses;
  format income expenses dollar$15.2;
run;
```
