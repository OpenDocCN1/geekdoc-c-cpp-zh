# INPUT Function

The INPUT function returns the value produced when the source is read with a specified informatat.

```
data conversions; NumVar=INPUT(source,informat);
CVar1='32000';
CV2='32.000';
CV3='03may2008';
CV4='030508';
Var1=input(CVar1,5.);
Var2=input(CVar2,commax6.);
Var3=input(CV3,date9.);
Var4=input(CVar4,ddmmy6.);
run;
```

If you use the INPUT function to create a variable not previously defined, the type and length of the variable is defined by the informat.
