# CATX Function: Step 2

Combine FName and LName to create FullName The CATX function removes leading and trailing blanks, inserts delimiters, and returns a concatenated character string.

```
NewVar=CATX(separator, string-1, ...string-n)
```

```
FullName=catx(' ', FName, LName);
```

| FName | LName | FullName |
| $ 15 | $ 15 | $ 200 |
| Sue | Farr | Sue Farr |

# Other CAT Functions

There are three other CAT functions that concatenate character strings.

| Function | Details |
| --- | --- |
| CAT(string-1, ...string-n) | Does not remove leading or trailing blanks from the arguments before concatenating them |
| CAT(string-1, ...string-n) | Removes leading trailing blanks from the arguments |
| CATT(string-1, ...string-n) | Removes trailing blanks from the arguments |
| CATQ(modifiers,<delimiter>, string-1, ...string-n) | Concatenates character or numeric values by using a delimiter to separate items and by adding quotation marks to strings that contain the delimiter. |

# Example of CAT Functions

```
data test_cat;
/* Each value has a leading and trailing blank */
a = ' a - ';
b = ' b - ';
c = ' c - ';

cat_example=cat(a, b, c);
catt_example=catt(a, b, c);
cats_example=cats(a, b, c);
catq_example=catq('D','a,b,c);
```
