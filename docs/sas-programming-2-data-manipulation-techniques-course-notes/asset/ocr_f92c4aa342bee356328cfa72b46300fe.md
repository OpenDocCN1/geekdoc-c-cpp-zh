Solutions to Exercises

+   1. Rotating a Data Set

```
data set=sixmonths;
set orion.orders midyear;
keep customer id month sales;
array months{6} month1-month6;
do Month=1 to 6;
  if months{Month} ne then do;
    Sales=months{Month};
    output;
  end;
end;
run;
```

```
proc print data=sixmonths;
run;
```

+   2. Rotating a Data Set and Using a Lookup Table

```
data travel;
set orion.travel expense;
keep employee id trip_id Expense_Type amount;
array exp{5} expl-exp5;
array descr{5} $ 14 temporary ('Airfare', 'Hotel', 'Meals',
'Transportation', 'Miscellaneous');
do i=1 to 5;
  if exp{i} ne then do;
    Expense_Type=descr{i};
    Amount=exp{i};
    output;
  end;
end;
run;
```

```
proc print data=travel;
format Amount dollar8.2;
run;
```
