# 4-8 Chapter 4 Reading Raw Data Files

To move the pointer $n$ positions backward, use $+(-n)$.

SAS informats have the following form:

```
$informatat<w>.<d>
```

where

$ indicates a character informat.

informat names the SAS informat or user-defined informat.

w specifies the number of columns to read in the input data.

. is a required delimiter.

![](bbox=[0.118, 0.335, 0.593, 0.633])

The following table gives a brief definition for some of the informats. Complete information can be found in SAS OnlineDoc.

| Informat | Definition |
|---|---|n| Sw. | Reads standard character data. |
| w.d | Reads standard numeric data. |
| COMMAw.d DOLLARw.d | Reads nonstandard numeric data and removes embedded commas, blanks, dollar signs, percent signs, and hyphens. |
| COMMAw.d DOLLARw.d | Operates like $COMMA.d$ and $DOLLARw.d$, but reverses the role of the decimal point and comma. This convention is common in many European countries. |
| EUROXw.d | Reads nonstandard numeric data and removes embedded characters in European currency. |
