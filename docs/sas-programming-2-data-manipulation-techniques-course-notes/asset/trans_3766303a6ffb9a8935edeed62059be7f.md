# 7.02 答

如何为每年生成单独的观测值？

```sas
data invest;
do Year=2008 to 2010;
  Capital=5000;
  Capital+(Capital*.045);
output;
run;
proc print data=invest;
```

# 使用 DO 循环减少冗余代码

```sas
data forecast;
  set orion.growth;
  do Year=1 to 6;
    Total_Employees=Total_Employees*(1+Increase);
    output;
  end;
run;

proc print data=forecast noobs;

```
