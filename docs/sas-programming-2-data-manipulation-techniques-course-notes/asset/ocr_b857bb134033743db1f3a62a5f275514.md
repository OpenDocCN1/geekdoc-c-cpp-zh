# Using %PUT to Display Macro Variables

Remember, you can use the %PUT statement to display the names and values of all automatic macro variables.

```
1 %put automatic_;
AUTOMATIC AFDSID 0
AUTOMATIC AFDSNAME
AUTOMATIC AFLIB1
AUTOMATIC AFSTR1
AUTOMATIC AFSTR2
```

# Using %PUT to Display Macro Variables

To display the names and values of all user-defined macro variables, use this form of the %PUT statement:

Partial SAS Log

```
%put user_;
```

```
136 %put user_;
GLOBAL SITE Melbourne
GLOBAL YEAR 2007
```

To display both user-defined and automatic macro variables, use this form of the %PUT statement:

Partial SAS Log

```
%put all_;
```

```
136 %put all_;
GLOBAL SITE Melbourne
GLOBAL YEAR 2007
AUTOMATIC AFDSID 0
AUTOMATIC AFDSNAME
AUTOMATIC AFLIB1
```
