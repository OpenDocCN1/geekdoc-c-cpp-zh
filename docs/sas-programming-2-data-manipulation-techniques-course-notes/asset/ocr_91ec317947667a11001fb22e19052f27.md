# Converting a Variable: Compilation

```
data hrdata (drop=CharGross);
set orion.convert(rename=(GrossPay=
CharGross));
GrossPay=input (CharGross,comma6.);
run;
```

Partial PDV

| ID | CharGross | Hired | GrossPay |
|---|---|---|--|
| $5 | $ 6 | $7 | N 8 |
