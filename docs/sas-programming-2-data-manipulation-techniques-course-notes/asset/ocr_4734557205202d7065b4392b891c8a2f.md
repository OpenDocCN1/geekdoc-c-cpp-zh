# 11.07 Short Answer Poll – Correct Answer

Examine the program below. What change (or changes) must be made to generate reports for 2008? Change the value assigned in the %LET statement.

```
%let year=2008;
proc print data=orion.order fact;
where year (order date) = &year;
title "Orders for &year";
run;
proc means data=orion.order fact mean;
where year (order date) = &year;
class order_type;
var total retail price;
title "Average Retail Prices for &year";
run;
title2 "by Order Type";
```
