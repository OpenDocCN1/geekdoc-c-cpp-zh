## ROUND Function

The ROUND function returns a value rounded to the nearest multiple of rounding unit.

```sas
data truncate;
NewVar1=round(12.12);
NewVar2=round(42.65,.1);
NewVar3=round(-6.478);
NewVar4=round(96.47,10);
run;

NewVar=ROUND(argument,rounding-unit);
```

| NewVar1 | NewVar2 | NewVar3 | NewVar4 |
|---|---|---|---|
| N 8 | N 8 | N 8 | N 8 |
| 12 | 42.7 | -6 | 100 |

## CEIL Function

The CEIL function returns the smallest integer greater than or equal to the argument.

```sas

```

## Truncation Functions

Compare the values from the CEIL, FLOOR, and INT functions with a negative argument.

```sas
data truncate;
Var1=-6.478;
CeilVar1=ceil(Var1);
FloorVar1=floor(Var1);
IntVar1=int(Var1);
```

| Var | CeilVar1 | FloorVar1 | IntVar1 |
|---|---|---|---|
| -6.478 | -6 | -7 | -6 |

For values greater than or equal to 0, the FLOOR and INT functions return the same value. For values less than 0, the CEIL and INT functions return the same value.

## Descriptive Statistics Functions

Descriptive statistic functions are used to calculate the values needed for donation_stats.

| Function | Returns |
|---|---|
| SUM | Sum of arguments |
| MEAN | Average of arguments |
| MIN | Smallest value from arguments |
| MAX | Largest value from arguments |
| N | Count of nonmissing arguments |
| NMISS | Count of missing numeric arguments |
| CMISS | Count of missing numeric or character arguments |

The CMISS function is new in SAS 9.2.

## Descriptive Statistics Functions

data descript;
Var1=12;

## Completed Business Scenario

Use the SUM, MEAN, and N functions to calculate donation statistics.

```sas
data donation_stats;
  set orion.employee;
  keep Employee_ID Total AvgQt NumQt;
  Total=sum(of Qtr1-Qtr4);
  AvgQt=round(mean(of Qtr1-Qtr4));
  NumQt=n(of Qtr1-Qtr4);
run;
proc print data=donation_stats noobs;
  var Employee_ID Total AvgQt NumQt;
run;
```
