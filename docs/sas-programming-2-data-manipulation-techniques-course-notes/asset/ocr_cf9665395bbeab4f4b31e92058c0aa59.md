+   • Create three new variables FCode1, FCode2, and LCode. As described above, variables should contain the following:

| Variable Name | Value | Length |
|---|---|--|
| FCode1 | First letter of First_Name | $1 |
| FCode2 | Final letter of First_Name | $1 |
| LCode | First four letters of Last_Name | $4 |

Remember to make these new values lowercase too.

There are several ways to approach getting the final letter of First_Name. For one of those ways, you need to know that the length of First_Name is 12 characters.
