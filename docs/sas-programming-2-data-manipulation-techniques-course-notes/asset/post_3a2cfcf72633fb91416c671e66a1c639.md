
# Creating an Accumulating Variable

Retain the values of Mth2Dte and set an initial value.

```sas
data mnthtot;
  set orion.aprsales;
  retain Mth2Dte 0;
  Mth2Dte=Mth2Dte+SaleAmt;
run;
```
RETAIN variable-name <initial-value>...

If you do not supply an initial value, all the values of Mth2Dte will be missing.

# RETAIN Statement: Details

The RETAIN statement

- retains the value of the variable in the PDV across iterations of the DATA step
- initializes the retained variable to missing or a specified variable before the first iteration of the DATA step
- is a compile-time-only statement.

> The RETAIN statement has no effect on variables read with SET, MERGE, or UPDATE statements. Variables read from SAS data sets are retained automatically.

# SUM Function

A RETAIN statement along with a SUM function in an assignment statement can create Mth2Dte.

```sas
data mnthtot;
set orion.aprsales;
retain Mth2Dte 0;
Mth2Dte=sum(Mth2Dte, SaleAmt);
run;
```
> The SUM function ignores values.

# Sum Statement

Use the sum statement to create Mth2Dte.

```sas
data mnthtot2;
set orion.aprsales;
Mth2D+=SaleAmt;
run;
```
> The sum statement initializes to zero and automatically increases by the value of SaleAmt for each observation.
