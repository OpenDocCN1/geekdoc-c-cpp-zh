# 2.3 Selecting Variables and Observations

# Using OBS= and FIRSTSTOBS= in a PROC Step

The FIRSTSTOBS and OBS= data set options can also be used in SAS procedures. The PROC PRINT step below begins processing at observation 10 and ends after observation 15.

```
proc print data=orion.employee_addresses
   (firststobs=10 obs=15);
   var Employee Name City State Country;
run;
```
