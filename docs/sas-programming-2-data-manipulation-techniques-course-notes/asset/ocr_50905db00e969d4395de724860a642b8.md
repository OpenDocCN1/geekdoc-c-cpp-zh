# # ROUND Function

The ROUND function returns a value rounded to the nearest multiple of rounding unit.

```
data truncate;
NewVar1=round(12.12);
NewVar2=round(42.65,.1);
NewVar3=round(-6.478);
NewVar4=round(96.47,10);
run;

NewVar=ROUND(argument,rounding-unit);
```
