
## 9.1 Using Data Manipulation Techniques with Match-Merging

### Objectives
- Review match-merging of SAS data sets.
- Show examples of data manipulation techniques with match-merging.
- Show techniques to perform a match-merge for these special cases:
  - three or more SAS data sets that lack a single common variable
  - variable names that need to be altered to obtain the correct merge results.

### Match-Merging (Review)
Match-merging combines observations from one or more SAS data sets into a single observation in a new data set, based on the values of one or more common variables.

### Match-Merging (Review)

This program writes observations for matches only. The IN= data set option creates a variable that can be used to identify matches and non-matches.

```
data CustOrd;
  merge orion.customer(in=cust)
         work.order_fact(in=order);
  by Customer_ID;
  if cust=1 and order=1;
run;
```

### Business Scenario

### Business Scenario

The manager would like you to create the following SAS data sets:
- **noorders** – containing the name and birthdate of customers who have not placed an order
- **orders** – detailing orders placed including customer name, ID of the product ordered, quantity, and price
- **summary** – containing a count of orders placed by each customer

### Data Manipulation Techniques

These techniques are added one at a time to show how the final solution can be built and tested in small steps.

![](img/d3bde6e6ab06b1fc622215d982111742_380_0.png)

### OUTPUT Statement

In this program, the OUTPUT statement is used to direct customers with matching orders to one data set and customers with no orders to another data set.

```
data orders noorders;
  merge orion.customer
  work.order_fact(in=order);
  by Customer_ID;
  if order=1 then output orders;
  else output noorders;
run;
```

### DROP= and KEEP= Options

You can use the DROP= and KEEP= data set options to determine which variables are written to each output set.

```
data orders (keep=(Customer_Name ID Total_Retail_Price))
  noorders (keep=(Customer_Name Birth_Date));
  merge orion.customer
  work.order_fact(in=order);
  by Customer_ID;
  if order=1 then output orders;
  else output noorders;
run;
```

NOTE: The data set WORK.NOORDERS has 35 observations and 2 variables.

### First, and Last. Variables and Sum Statement

The First. and Last. variables along with the sum statement can be used to create the values for the summary data set.

```
data orders (keep=(Customer_Name ID Total_Retail_Price))
noorders (keep=(Customer_Name Birth_Date))
summary (keep=(Customer_Name NumOrders));
merge orion.customer
work.order_fact(in=order);
  by Customer_ID;
  if order=1 then do
    output orders;
    if first.Customer_ID then NumOrders=0;
    NumOrders+1;
    if last.Customer_ID then output summary;
  end
  else output noorders;
run;
```

### Multiple Data Sets without a Common Variable

You can use the DATA step to merge three or more SAS data sets that lack a common variable.

![](img/d3bde6e6ab06b1fc622215d982111742_384_0.png)

The BY statement variables must exist on all of the data sets. If the data sets lack a common variable, more than one DATA step is required.
