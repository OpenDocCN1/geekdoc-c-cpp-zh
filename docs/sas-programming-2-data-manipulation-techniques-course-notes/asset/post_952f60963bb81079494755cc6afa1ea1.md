
## 4.1 Reading Raw Data Files with Formatted Input

| Statement | Description |
| --- | --- |
| INFILE 'raw-data-file-name': | The INFILE statement identifies the physical name of the raw data file to read with an INPUT statement. |

*raw-data-file-name'* is the physical name that the operating environment uses to access the file of raw data. |

Examples:
| Windows | infile 's:\workshop\offers.dat'; |
| UNIX | infile '/users/userid/offers.dat'; |
| z/OS (OS/390) | infile 'useridid.workshop.rawdata(offers)'; |

The PAD and LRECL= options can be useful for reading variable-length records typically found in Windows and UNIX environments. See SAS Help and Documentation for more information about the PAD and LRECL= options.

INPUT specifications; The INPUT statement describes the arrangement of values in the raw data file and assigns input values to the corresponding SAS variables.

## 4-8 Chapter 4 Reading Raw Data Files

To move the pointer $n$ positions backward, use $+(-n)$.

SAS informats have the following form:

```
$informatat<w>.<d>
```

where

$ indicates a character informat.

informat names the SAS informat or user-defined informat.

w specifies the number of columns to read in the input data.

. is a required delimiter.

![](img/d3bde6e6ab06b1fc622215d982111742_131_0.png)

The following table gives a brief definition for some of the informats. Complete information can be found in SAS OnlineDoc.

| Informat | Definition |
|---|---|
| $|n| Sw. | Reads standard character data. |
| w.d | Reads standard numeric data. |
| COMMAw.d DOLLARw.d | Reads nonstandard numeric data and removes embedded commas, blanks, dollar signs, percent signs, and hyphens. |
| COMMAw.d DOLLARw.d | Operates like $COMMA.d$ and $DOLLARw.d$, but reverses the role of the decimal point and comma. This convention is common in many European countries. |
| EUROXw.d | Reads nonstandard numeric data and removes embedded characters in European currency. |

## 4.1 Reading Data Files with Formatted Input

| Informat | Definition |
|---|---|
| PERCENT | Operates like COMMA.d but divides the number by 100 if it is followed by a percent sign (%). |

If the *d* is not specified, it defaults to 0. This means that COMMA. and COMMA7.0 are equivalent.

If the data contains decimal points, SAS ignores the *d* value and reads the number of decimal places that are actually in the input data. If the data does not contain decimal places, *d* specifies the number of decimal places to imply.

DOLLAR.d is an alias for COMMA.d, and DOLLARX.d is an alias for COMMAX.d.

More information about EUROX.d is available through SAS Help and Documentation.

The ANYDTDTEW informat can be used to read data that has a variety of date forms. More information about ANYDTDTEW. is available in SAS Help and Documentation.
