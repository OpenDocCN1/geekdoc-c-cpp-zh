# 4.3 Solutions

Solutions to Exercises

+   1. Using Formatted Input

```
data sales_staff;
ininfile "&path\sales1.dat";
input @Employee ID 6.
@21 Last Name $18.
@43 Job Title $20.
@64 Salary Dollar8.
@87 Hire Date mmddyy10;

run;

title 'Australian and US Sales Staff';
proc print data=sales_staff noobs;
run;
ntitle;
```

+   2. Using Formatted Input and the Subsetting IF Statement

```
data AU_trainees US_trainees;
drop Country;
infile "&path\sales1.dat";
input @Employee ID 6.
@21 Last Name $18.
@43 Job Title $20.
@64 Salary Dollar8.
@73 Country $2.
@87 Hire Date mmddyy10;
if Job Title = 'Sales Rep. I';
if Country = 'AU' then output AU_trainees;
else if Country='US' then output US_trainees;
run;

title 'Australian Trainees';
proc print data=AU_trainees noobs;
run;

title 'US Trainees';
proc print data=US_trainees noobs;
run;
title;
```
