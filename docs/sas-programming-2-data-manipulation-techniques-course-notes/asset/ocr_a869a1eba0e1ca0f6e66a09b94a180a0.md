# Creating Variables with Arrays

```
data change;
  set orion.employee_donations;
  drop i;
  array Contrib{4} Qtr1-Qtr4;
  array Diff{3};
  do i=1 to 3;
    Diff{i}=Contrib{i+1}-Contrib{i};
```

```
when I=3
Diff{3}=Contrib{4}-Contrib{3};
Diff3=Qtr4-Qtr3;
```
