# Fourth Iteration of the DO Loop

```
data charity;
set orion.employee donations;
keep Employee ID Qtr1-Qtr4;
array Contrib{4} Qtr1-Qtr4;
doi i=1 to 4;
  Contrib(i)=Contrib{i}*1.25;
end;
```

```
when i=4
Contrib{4}=Contrib{4}*1.25;
Qtr4=Qtr4*1.25;
```
