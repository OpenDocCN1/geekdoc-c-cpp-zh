

# 在 SELECT 组中使用 DO-END

使用 DO 和 END 语句在表达式为真时执行多条语句。

```sas
data usa other;
  set orion.employee addresses;
  select (uppercase(country));
    when ('US') do;
      Benefits=1;
      output usa;
    end;
    when ('AU') do;
      Benefits=2;
      output australia;
    end;
    otherwise do;
      Benefits=0;
      output other;
    end;
run;
```

# 省略 Select 表达式

当前示例的此版本省略了 SELECT 表达式。

```sas
data usa australia other;
  set orion.employee addresses;
  select;
    when (country='US') output usa;
    when (country='AU') output australia;
    otherwise output other;
  end;
```

```sas
SELECT;
  WHEN (expression-1)
    statement;
  ..<WHEN (expression-n)
    statement;
  <OVERWISE statement>
END;
```

有关使用 SELECT 组的更多信息，请参考 SAS 文档。
