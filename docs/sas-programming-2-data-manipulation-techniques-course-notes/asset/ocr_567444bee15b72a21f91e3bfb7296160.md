# Using PROC SQL to Join Tables

To join two or more SAS tables, list them in the / FROM clause separated by commas.

```
proc sql number;
select sales mgmt.Employee_ID,
  Employee_Name,
  Job Title,
  Salary
from orion.sales mgmt,
  orion.employee_addresses;
quit;
```
