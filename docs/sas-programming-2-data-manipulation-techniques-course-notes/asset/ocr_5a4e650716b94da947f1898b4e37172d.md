# Execution: Performing Repetitive Calculations

```
data invest;
do Year=2008 to 2010;
  Capital+5000;
  Capital+(Capital*.045);
end;
run;
```

![](bbox=[0.335, 0.237, 0.497, 0.258])

| Year | Capital | N |
|---|---|---||
| | 0 | 1 |

**Capital** is used in a sum statement, so it is initialized to zero automatically and retained.
