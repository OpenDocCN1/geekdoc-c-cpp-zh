# 旋转 SAS 数据集

下面的 DATA 步骤旋转输入数据集，并且如果某个季度有捐款，则输出一个观测值。

```sas
data rotate (keep=Employee_Id Period Amount);
set orion.employee_donations
  (drop=recipients paid_by);
  array contrib(4) qtr1-qtr4;
  do i=1 to 4;
  if contrib(i) != . then do;
    Period=cats("Qtr",i);
    Amount=contrib(i);
    output;
  end;
run;
```
