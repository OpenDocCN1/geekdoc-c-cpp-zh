# Displaying Multiple SAS Data Sets

The PRINT procedure can print only one data set.
a separate PROC PRINT step is required for each data set.

```
title 'Employees in the United States';\proc print data=usa;
run;
title 'Employees in Australia';\proc print data=australia;
run;
title 'Non US and AU Employees';\proc print data=other;
run;
title;
```
