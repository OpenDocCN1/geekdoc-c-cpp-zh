# Logic Errors

A logic error occurs when the program statements follow the rules and execute but the results are not correct.
No notes are written to the log, so logic errors are often difficult to detect.

![](bbox=[0.273, 0.212, 0.483, 0.273])

This section focuses on identifying logic errors.
