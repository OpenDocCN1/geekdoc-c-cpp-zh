# 4.2 Controlling when a Record Loads

```
data sales01;
infile &path\sales.dat";ninput SaleID $4. @6 Location $3. @
if Location='USA' then
input @10 Datemmddy10
@20 Amount 7;
else if Location='EUR' then
input @10 Datedate9.
@20 Amount commax7;
run;
```
