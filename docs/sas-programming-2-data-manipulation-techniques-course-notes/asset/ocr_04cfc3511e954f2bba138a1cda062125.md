# SUBSTR Function (Right Side)

Extract the fourth character from the value in the Acct_Code variable and store it in Org_Code.

```
NewVar=SUBSTR(string,start,<length>);
```

```
Org_Code=substr(Acct_Code, 4, 1);
```

PDV

| Acct_Code | Org_Code |
|---|---|
| $6 | $6 |
| AQ2 | 2 |

![](bbox=[0.273, 0.313, 0.473, 0.363])

| NewVar | If NewVar is a new variable it will be created with the same length as string. To set a different length for NewVar, use a LENGTH statement prior to the assignment statement. |

| string | String can be a character constant, variable, or expression. |

| start | Start specifies the starting position. |

| length | Length specifies the number of characters to extract. If omitted, the substring consists of the remainder of string. |

The SUBSTR function on the left side of an assignment statement is used to replace characters.
