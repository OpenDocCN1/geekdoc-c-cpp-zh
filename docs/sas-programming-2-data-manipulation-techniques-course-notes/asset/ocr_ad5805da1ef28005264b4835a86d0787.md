# 7.4 Using SAS Arrays

# Creating a Temporary Lookup Table

You can use the keyword _TEMPORARY_ in an ARRAY statement to indicate that the elements are not needed in the output data set.

```
data compare(drop=i);
 set orion.employee_donations;
 array Contrib{4} Qtr1-Qtr4;
 array Diff{4};
 array Goal{4} temporary (10,20,20,15);
 do i=1 to 4;
 Diff{i}=Contrib{i}-Goal{i};
;
run;
```

You can save memory if you do not need to access the individual array element variables by name, the only way you can access the array elements is by array subscribing. Arrays of temporary elements are useful when the only purpose for creating an array is to perform a calculation. To preserve the result of the calculation, assign it to a variable.
