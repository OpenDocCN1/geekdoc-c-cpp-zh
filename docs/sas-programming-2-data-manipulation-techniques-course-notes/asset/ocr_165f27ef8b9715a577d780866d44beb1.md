# Explicit Numeric-to-Character Conversion

The PUT function writes values with a specific format.

```
data hrdata;
  keep Phone Code Mobile;
  set orion.convert;
  Phone='(' !! put(Code,3.) !! ' ')'
  !! Mobile;
run;
```

# Explicit Numeric-to-Character Conversion

```
proc print data=hrdata noobs;
run;
```
