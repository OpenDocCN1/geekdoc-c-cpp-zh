# Line Pinter Controls

```
data contacts;
infile "&path\address.dat";
input FullName $30. /* /
Address2 $25. /* /
Phone $8.;
```

Load fourth line of raw data

8 6 9 -7 0 0 8

The forward slash is known as a *relative* line pointer control that moves the pointer relative to the line on which it currently positioned. There is also an *absolute* line pointer control that moves the pointer to a specific line in a group of lines. Here is an example.

```
data contacts;
infile ""&path\address.dat";
input #1 FullName $30.
#3 Address2 $25.
#4 Phone $8.;
```

SAS Help and Documentation for more information about absolute line pointer controls.
