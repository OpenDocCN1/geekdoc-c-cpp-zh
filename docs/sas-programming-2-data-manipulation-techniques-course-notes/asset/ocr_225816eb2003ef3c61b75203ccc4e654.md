# 4. Cleaning Text Data

```
data names;
length New Name $50
Fnames $30
Last $30;
set orion.customers_ex5;
Fnames = scan(Name,2,',');
Last = propcase(scan(Name,1,','),('Ms.'),FNames,Last);
if Gender='F' then New Name=CATX(' ','Ms.',FNames,Last);
else if Gender='M' then New Name=CATX(' ','Mr.',FNames,Last);
```
