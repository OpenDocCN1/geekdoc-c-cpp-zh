- 1. Performing a Match-Merge on Two Data Sets
```sas
data revenue
NotSold(keep=Price Product_ID Product_Name)
InvalidCode(keep=Product_ID Quantity Customer);
merge orion.web_products(in=InProduct)
      orion.web_orders(in=InOrders)
  by Product_ID;
  if InProduct and InOrders then do;
    Revenue=Quantity * Price;
    output revenue;
end;
  else if InProduct and not InOrders then output notold;
  else if not InProduct and InOrders then output invalidcode;
run;
```

## 10-4 Creating a Formats

### Creating a Format (Review)

Use PROC FORMAT to create the format.

```sas
proc format;
$country 'AU' = 'Australia'
            'CA' = 'Canada'
            'DE' = 'Germany'
            'IL' = 'Israel'
            'TR' = 'Turkey'
            'US' = 'United States'
            'ZA' = 'South Africa';
run;
```

### Using a Control Data Set to Create a Format

Instead of entering all of the values in PROC FORMAT, you can create a format from a data set that contains the code and value.

## Using a Control Data Set to Create a Format

| Country | Country_Name | Population | Country_ID | Continent_ID | FormerName |
|---|---|---|---|---|---|
| AU | Australia | 20,000,000 | 160 | | |

```sas
ndata country;
keep Start Label FmtName;
retain FmtName '$country';
set orion.country (rename=(Country=Start Country_Name=Label));
run;
```
CNTLIN=data set has the following features:

- assumes that the ending value of the format range is equal to the value of Start if no End is found
- can be used to create new formats, as well as re-create existing formats
- must be grouped by FmtName

### FmtName

- can be up to 32 characters in length
- for character formats, must begin with a dollar sign ($), followed by a letter or underscore
- for numeric formats, must begin with a letter or underscore
- cannot end in a number
- cannot be the name of a SAS format.

## Using a Control Data Set to Create a Format

Use the CNTLIN= option to read the data and create the format.

```sas
proc format cntlin=country;
run;
CNTLIN=SAS-data-set;
```

The variables FmtName, Start, and Label are required in order to create a format from a CNTLIN data set.

## Setup for the Poll
