# OTHERWISE Statement

The OTHERWISE statement is optional, but omitting it results in an error all WHEN conditions are false.

```
data usa australia;
set orion.employee addresses;
select (Country);
when ('US') output usa;
when ('AU') output australia;
otherwise;
end;
run;
```
