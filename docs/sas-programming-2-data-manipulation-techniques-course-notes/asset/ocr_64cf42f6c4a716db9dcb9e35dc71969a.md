# Display Messages and Variable Values in the Log

```
PUTLOG 'text';
PUTLOG variable-name=;
PUTLOG variable-format-name=;
PUTLOG ALL;
```

# Permanent Formats and Control Data Sets

```
PROC FORMAT LIBRARY=output-sas-catalog
FMTLIB CNTLININ=input-sas-data-set
CNLOUT=input-sas-data-set;
```

```
RUN;
```

# PROC TRANSPOSE

```
PROC TRANSPOSE DATA=input-data-set
<OUT=output-data-set>
<NAME=variable-name>;
<BY <DESCENDING> variable-1
<DESCENDING> var-n
<NORTSORTED>;
<VAR variable(s);
<ID variable>;
```

```
END;
```

```
RUN;
```

```

```
END;
