# 7.05 Short Answer Poll

How can you generate one observation for each quarterly amount?

```
data invest (drop=Quarter);
  do Year=1 to 5;
    Capital+5000;
  do Quarter=1 to 4;
    Capital+(Capital*(.045/4));
  end;
  output;
end;
run;

proc print data=invest noobs;
run;
```
