# FROM Clause

Columns listed in the SELECT statement are separated by commas. There is no comma following the last column in the list.

```
SELECT object-item< ...object-item>
proc sql;
select job_title, salary
from orion.sales_mgmt;
quit;
FROM from-list ...
```

The FROM clause identifies the SAS table or tables from which to read.
