# Multiple INPUT Statements

By default, SAS loads a new record into the input buffer when it encounters an INPUT statement. You can have multiple INPUT statements in one DATA step.

```sas
data contacts;
infile "&path\address.dat";
input FullName $30;
input;\input Address2 $25;
input Phone $8;
run;
```

Load first line of raw data
Partial Input Buffer 1 2
1 2 3 4 5 6 7 8 9 0
Ms. | Sue | Farr

By default, SAS begins reading each new line of raw data at position 1 of the input buffer, so having @1 in the INPUT statement is not necessary.

# Multiple INPUT Statements

```sas
data contacts;
infile "&path\address.dat";
input FullName $30;
```
