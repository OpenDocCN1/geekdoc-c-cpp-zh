# About This Class

This class focuses on manipulating data with the
DATA step, including

+   - creating multiple SAS data sets
- accumulating totals and summarizing data
- reading fixed column raw data files
- manipulating variable values with functions
- performing DO loop and SAS array processing
- rotating data sets
- merging data sets
