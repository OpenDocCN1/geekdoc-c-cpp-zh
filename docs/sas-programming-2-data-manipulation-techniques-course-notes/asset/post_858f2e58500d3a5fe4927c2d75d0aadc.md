# SQL Procedure: Syntax Overview

PROC SQL statement signals the start of an SQL procedure.

The QUIT statement ends an SQL procedure. A RUN statement is not needed because the query is executed when the semicolon is reached.

```sas
options ls=80; PROC SQL;
proc sql;
select *
from orion.sales_mgmt;
quit;
QUIT;
```

The QUIT statement is omitted, the SQL procedure remains in memory to process subsequent queries. A QUIT statement or the start of another step terminates the SQL procedure and removes it from memory.

# SQL Procedure: Syntax Overview

An SQL SELECT statement (also called a *query*) is submitted to SAS tables. A query contains smaller building blocks named *clauses*.

```sas
SELECT *
options ls=80;
proc sql;
select *
from orion.sales_mgmt;
quit;
```

The SELECT clause identifies columns to include in the query result. To select all columns, use an asterisk in place of the column names.

# FROM Clause

Columns listed in the SELECT statement are separated by commas. There is no comma following the last column in the list.

```sas
SELECT object-item <object-item>
proc sql;
select job_title, salary
from orion.sales_mgmt;
quit;
FROM from-list ...
```

The FROM clause identifies the SAS table or tables from which to read.

# Using PROC SQL to Join Tables

To qualify the column, use the table name as a prefix when the column is referenced.

```sas
proc sql number;
select sales_mgmt.Employee_ID,
  Employee_Name,
  Job Title,
  Salary
from orion.sales_mgmt,
  orion.employee_addresses;
quit;
```

# Using PROC SQL to Join Tables

To join two or more SAS tables, list them in the FROM clause separated by commas.

```sas
proc sql number;
select sales_mgmt.Employee_ID,
  Employee_Name,
  Job Title,
  Salary
from orion.sales_mgmt,
  orion.employee_addresses;
quit;
```

# Cartesian Product

Each row in orion.sales_mgmt is combined with every row in orion.employee_addresses.

Conceptually, when two tables are specified in a join, each row of the first table is matched with every row of the second table to produce a Cartesian product, which is stored in an internal or intermediate table. The number of rows in the intermediate table is equal to the product of the number of rows in each of the source tables. The intermediate table becomes the input to the rest of the query, although some of its rows might be eliminated by the WHERE clause.
