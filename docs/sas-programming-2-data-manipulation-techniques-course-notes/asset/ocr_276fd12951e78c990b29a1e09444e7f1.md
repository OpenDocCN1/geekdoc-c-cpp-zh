10-4 Chapter 10 Creating and Maintaining Permanent Formats

# Creating a Format (Review)

Use PROC FORMAT to create the format.

```
proc format;
$country 'AU' = 'Australia'
            'CA' = 'Canada'
            'DE' = 'Germany'
            'IL' = 'Israel'
            'TR' = 'Turkey'
            'US' = 'United States'
            'ZA' = 'South Africa';

run;
```

# Using a Control Data Set to Create a Format
