# Execution: Rotating a SAS Data Set

```
data rotate (keep=Employee_Id Period Amount);
set orion.employee_donations
(drop=recipients paid_by);
array contrib(4) qtri-qtr4;
doi i=1 to 4;
  if contrib(i)ne . then do
    Period=cats("Qtr",i);
    Amount=contrib(i);
    output;
  end;
end;
run;
```
