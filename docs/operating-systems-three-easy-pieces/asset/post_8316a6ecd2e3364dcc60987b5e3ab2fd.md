## 27.1 Thread Creation

The first thing you have to be able to do to write a multi-threaded program is to create new threads, and some kind of thread interface must exist. In POSIX, it is easy:

```c
#include <pthread.h>
int
pthread_create(pthread_t *thread,
                const pthread_attr_t *attr,
                void *(*start_routine)(void*),
                void *arg);
```

This declaration might look a little complex (particularly if you haven't used functions in C), but actually it's not too bad. There are four arguments: thread, attr, start.routine, and arg. The first, thread, is a pointer to a structure of type pthread_t; we'll use this structure to interact with.

The second argument, attr, is used to specify any attributes thread might have. Some examples include stack size or priority.

The third argument, start.routine, is the most complex, but actually it's not too bad. There are four arguments: thread, attr, start.routine, and arg. The first, thread, is a pointer to a structure of type pthread_t; we'll use this structure to interact with.

The fourth argument, arg, is exactly what we pass to the thread. Because the routine can return anything, it is defined to return a pointer to void; because the pthread_join() routine changes the value of the argument, we return value.

## 27.2 Thread Completion

The example shows how to create a thread. However, what happens if you need to wait for completion? You need to do something special; in particular, you must call pthread_join().

```c
int pthread_join(pthread_t thread, void **value);
```
