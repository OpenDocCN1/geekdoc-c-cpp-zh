In the first row (0,0,1,1), there are two 1s (C2, C3), and thus XOR of all of those values will be 0 (P); similarly, in the second row there is only one one (C1), and thus XOR will be 1 (P). You can remember this in a simple way: the number of 1s in any row, including the parity, must be an even (not odd) number; that is the invariant and the RAID must maintain in order for parity to be correct.

From the example above, you might also be able to guess how parity information can be used to recover from a failure. Imagine the column C2 is lost. To figure out what values must have in the column, we simply have to read the XOR parity bit and reconstruct the right answer. Specifically, assume the first row's value in column C2 is lost (it is a 1); by reading the other values in that row (0 from C0, 1 from C1, from C3 and 0 from the parity column P), we get the values 0, 1, and 0 because we know that XOR gives the number of 1s in each row and we know what the missing data must be: a 1. And how reconstruction works in a RAID-based scheme! Note also how we computed the reconstructed value: we just XOR the data bits and parity bits together, in the same way that we calculated the parity in the first place.

Now you might be wondering: we are talking about XORing all of these, and yet from above we know that the RAID places 4KB (or larger) blocks on each disk; how do we XOR a block of disks to compute the parity? Simply perform a bitwise XOR across each bit of the data blocks; puts the result of bitwise XOR corresponds to the parity slot in the block. # RAID-4 Analysis

Let us analyze RAID-4. For a capacity standpoint, RAID-4 uses 1 disk for parity information for every group of disks it is protecting. Thus, our useful capacity for a RAID group is $(N-1) \cdot B$.

Reliability is also quite easy to understand: RAID-4 tolerates 1 disk failure and no more. If more one disk is lost, there is simply no way to reconstruct the last disk.

Finally, there is performance. This let us start by analyzing steadystate throughput. Sequential read performance can utilize all of the disks except the parity disk, and thus deliver a peak effective bandwidth of $(N-1) \cdot S$ MB/s (an easy case).
