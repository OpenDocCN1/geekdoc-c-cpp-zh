# MECHANISM: LIMITED DIRECT EXECUTION

# References

[A79] "Alto User's Handbook" by Xerox. Xerox Palo Alto Research Center, September 1979. Available: http://history-computer.com/Library/AltoHandbook.pdf. An amazing system, way ahead of its time. It became famous Steve Jobs visited, took notes, and built Lisa and eventually Mac.

[C04] "Microbook - A Technique for Reality" by G. Candea, S. Kawamoto, Y. Fuji, G. Friedman, A. Fox OS'04, San Francisco, CA, December 2004. An excellent paper pointing out how one can go with rebuild in making robust systems.

[I11] "64 and IA-32 Architecture Software Developer's Manual" by Volume 3A and 3B: System Guide. Intel Corporation, January 2011. This is just a boring manual, but some of those are useful.

[K66] "One-Level Storage Technique" by T. Kilburn, D.B.G. Edwards, M. Lanjigan, F.H. Summer. IRE Transactions on Electronic Computers, April 1962. Atlas pioneered much of what you see in modern systems. However, this is not the best one to read. If you were to read only one, might be the historical perspective before 1970.

[L78] "The Machine Interface and A Historical Perspective" by S. H. Lavington. Communications of the ACM, 21, 1978. A history of the early development of computers and the pioneering efforts of Atlas.

[M63] "A Time-Sharing Debugging System for a Small Computer" by J. McCarthy, S. Boilen, E. Fry, and C. R. Lacker. AFIPS '63 (Spring), 1963, New York, USA. An early paper about time-sharing that refers to using a timer interrupt; which it discusses: "The basic task of the 17 channel is to decide whether to remove the current user from discourse and so to decide which program to swap in as he goes out.

[M96] "Portable tools for performance analysis" by Larry McVoy and Carl Steinlein. USENIX Annual Conference, January 1996. A fun paper about how to measure a number of differences about OS performance. Download imbench and give it a try.

[M11] "Mac OS 9" by Apple Computer, January 2011. http://en.wikipedia.org/wiki/Mac_OS.9. You can easily find an OS 9 emulator if you want to; check it out, it's a little Mac!

[O90] "The Single Unix Specification, Version 3" by The Open Group, May 2010. Available: http://www.unix.org/version3/. This is hard and painful to read, so avoid it if you can. Unless someone is paying you to read it. Or, if you're curious about it

[S07] "The Genesis of Innofect Flesh on the Return: into-libc with Function Calls (on the 80s)" by Howard Shannon. CS 07, October 2007. One of those mind-blowing ideas you'll see in research time to time. The author shows that if you can jump into code arbitrarily, you can essentially stitch together any code sequence (given a large code base); for the details.
