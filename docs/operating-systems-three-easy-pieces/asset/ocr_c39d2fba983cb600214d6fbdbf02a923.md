We should note that inodes are typically not that big, for example
128 or 256 bytes. Using 256 bytes per inode, a 4KB block can hold 16
inodes, and our file system built on a 64-block partition contains 80 inodes. In our on-
file system, built on a tiny 64-block partition, this represents the
maximum number of files we can have in our file system; however,
that the same file system, built on a larger disk, could simply allocate
a larger inode table and accommodate more files.
