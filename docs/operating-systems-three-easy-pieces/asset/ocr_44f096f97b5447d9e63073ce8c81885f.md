The second case (Figure 31.8) occurs when the child runs to complete before the parent gets a chance to call `sem_wait()`. In this case, the child will first call `sem_post()`, increasing the value of the semaphore from 0 to 1. When the parent gets a chance to run, it will call `sem_wait()` and find the value of the semaphore to be 1; the parent will decrement the value (to 0) and return from `sem_wait()` without waiting, also achieving the desired effect.
