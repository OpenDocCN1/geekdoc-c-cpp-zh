# # References

[AD14] "Operating Systems: Three Easy Pieces" (Chapter: Flash-based Solid State Drives) by Remzi. Arpacci-Dousseau and Andrea Arpacci-Dousseau. Arpacci-Dousseau Books, 2014. A bit gauche to refer you to another chapter in this very book, but who are we to judge?

[B07] "ZFS: The Last Word in Files" by Johnwick and Bill Moore. Copy Available: http://www.ostep.org/citations/zfs_last.pdf. Slides on ZFSs; there is no free ZFS paper? (Maybe you will write one, so can we cite it here?)

[H17] "The Unwritten Contract of Solid State Drives" by Jun He, Sudan Khanna, Andrea C. Arpacci-Dousseau, Remzi H. Arpacci-Dousseau, EuroSys 17, 2017. When writers make no effort to extract performance from SSDs, both scale (or parallel requests) and latency matter most. The more things change—

[HLM94] "File System for NFS File Server" by Dave Hines, James Lu, Michael Mahmood. USENIX 94. WAFL takes many ideas from LFS and RAID and puts it into a high-speed NFS for the multi-billion dollar company NetApp.

[L77] "Physical Integrity in a Large Segmented Database" by R. Lorie. ACM Transactions on Databases, Volume 2, 1 (1977). The original idea of paging is presented here.

[M94] "A File System for UNIX" by Robert K. McKusick, William N. Joy, Sam J. Lee, Robert S. Fabry, ACM TOCS, Volume 3, August 1994. The free LFS paper: see on CFS for more details.

[MR97] "Improving the Performance of Log-Structured File Systems with Adaptive Methods" by Jeanna Neefe Mathews, Remzi Dousseau, Adam M. Castro, Randolph Y. Wang, Thomas E. Anderson, SOSP '1997, pages 228–235, Saint Mayo, Montreal. A more recent paper presents-better cleaning policies for lfs.

[P98] "Hardware Trends and Database Opportunities" by David D. Patterson. SIGMOD '98, Keynote, May 4. Slides available at: http://www.berkeley.edu/patterns/keynote.html. A great set of slides on trends in computer systems. Hopefully, Patterson will create another of these soon.

[R91] "Design and Implementation of the Log-Structured File System" by Mendel Rosenblum and John Ousterhout. SOSP '91, Pacific Grove, CA, October 1991. The original SOSP paper about lfs, has been cited by hundreds of other papers and inspired many modern systems.

[R92] "Design and Implementation of the Log-Structured File System" by Mendel Rosenblum. http://www.berkeley.edu/Pubs/TechIPS/TechIPS-92-068.pdf. The award-winning paper of lfs.

[SS95] "File system using clustering: a performance comparison" by Marco Selger, Keith A. Smith, Hari Balakrishnan, June Chang, Sara Menschae, Venkatesan Podabaman. USENIX 1995, New Orleans, Louisiana, 1995. A paper that showed the LFS performance suffers most, particularly for many calls to fsync() (such as database workloads). The paper is still widely cited.

[S90] "Write-Disk Caching" by James A. Sun, Susan Cyr, Cyril. Orji. SIGMOD '90, New York, May 1990. An early study of software buffering and its benefits. However, buffering for too long can be harmful: see [M94] for details.

[Z12] "De-direction for Flash-based SSDs with Nameless Writes" by Yiyang Zhang, Prash Prath Arul, Andrea C. Arpacci-Dousseau, Remzi H. Arpacci-Dousseau. FAST 13, San Jose, California, February 2013. A paper on a new way to build flash-based storage devices, to avoid redundant mapping in the file system and FTL.
