# ## Scheduling Metrics

Beyond making workload assumptions, we also need one more thing to enable us to compare different scheduling policies: a scheduling met-ric metric is something that we use to measuring, and there are a number of different metrics that make sense in scheduling.

For now, let us simplify by simply having a sin-gle metric: turnaround time. The turnaround of a job is defined as the time at which the job completes minus the time at which the job arrived in the system. More formally, the turnaround time $T_{turnaround}$ is:

```
$T_{turnaround} = T_{completion} - T_{arrival} \quad (7.1)$
```

Because we have assumed that all jobs arrive at the same time, for now $T_{turnaround} = 0$ and hence $T_{turnaround} = T_{completion}$. This fact will change as we relax the aforementioned assumptions.

You should note that turnaround time is a performance metric, which will be our primary focus of this chapter. Another metric of interest is fair-ness, as performance and fairness are often at odds in scheduling; a scheduler, for example, by Jain's Fairness Index [91]. Per-ample may optimize performance but at the cost of preventing a few jobs from running, decreasing fairness. This conundrum shows that life isn't always perfect.
