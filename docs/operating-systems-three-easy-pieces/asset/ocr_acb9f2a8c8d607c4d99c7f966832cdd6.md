To understand the performance of sequential writes, we must first understand how they are done. When writing a big chunk of data to disk, RAID-4 can perform a simple optimization like a full-stripe write. For example, the case where the blocks 0, 1, 2, and 3 have been sent to the RAID as part of a write request (Figure 38.5).

In this case, the RAID can simply calculate the new value of P0 by performing an XOR across the blocks 0, 1, 2, and then write all of the blocks (including the parity block) to the five disks in parallel (highlighted in gray in the figure). Full-stripe writes are the most efficient way for RAID-4 to write to disk.

Once we understand this, calculating the performance of sequential writes in RAID-4 is easy: the effective bandwidth is also (N-1) MB/s. Even though the parity disk is constant in use during operation, the client does not gain performance advantage from it.

Now let us analyze the performance of random reads. As you can see from the example, a set of 1-block random reads will be spread across the disks of the system but not the parity disk. Thus, the effective performance is: (N-1) MB/s.

Random writes, which we have saved for last, present the most interesting case for RAID-4. Imagine we overwrite block 1 in the example above. We would leave us with a problem: the parity block P0 would no longer accurately reflect the correct value of the stripe; in this example, P0 must also be updated. How can we update both correctly and efficiently?

It turns there are two methods. The first, known as additive parity, requires us to do the following. To compute the value of the new parity block, read in all of the other disks in the stripe in parallel (in the example, 0, 2, and 3) and XOR those with the new block (1). The result is your new parity. To complete the write, you can then write the new data and parity to their respective disks, also in parallel.

The problem with this technique is that it scales with the number of disks, and thus in large RAIDs requires a high number of reads to compute parity. The, subtractive parity method.
