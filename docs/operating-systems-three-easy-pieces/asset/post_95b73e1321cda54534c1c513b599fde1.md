# **Better, But Still Broken: While, Not If**

Fortunately, this fix is easy (Figure 30.10): change the if to a **while**. Think about how this works: now T1 wakes up and (with the lock held) re-checks the state of the shared variable (c2). If the buffer is empty at that point, the consumer simply goes back to sleep (c3). The corollary (c1) is also changed in a producer (p2).

Thanks to Mesa semantics, a simple rule to remember with condition variables is to **always use loops**. Sometimes you don't have to check the condition, but it is always safe to do so; just do it and be happy.
