# TIP: THE PRINCIPLE OF ISOLATION

Isolation is a key principle in building reliable systems. If two entities are properly isolated from one another, this implies that one can fail without affecting the other. Operating systems strive to isolate processes from each other and in this prevent one harming the other. By using memory isolation, the OS ensures that running programs cannot affect the operation of the underlying OS. Some modern OS's take isolation even further, by walling off pieces of the OS from other pieces of the OS. Such microkernels [BH70, R89, S03] may provide greater reliability than that monolithic kernel designs.

# 13.5 Summary

We have seen the introduction of a major OS subsystem: virtual memory. The VM system is responsible for providing the illusion of a large, sparse, private address space to programs, which OS, with some serious hardware help, will take each of these virtual memory references, and turn them into physical addresses, to fetch the desired information. The OS will do this for many processes at once, making sure to protect programs from one another, as well as protect the OS. The entire approach requires a great deal of mechanism (low-level machinery) as well as some critical processes to work; we'll start from the bottom up, describing the critical mechanisms first.
