# # References

+   - [B+08] "An Analysis of Data Corruption in the Storage Stack" by Lakshmi N. Bairavasanaram, Garrett R. Goodson, Bianca Schroeder, Andrea C. Apaci-Dusseau, Remzi H. Apaci-Dusseau. FAST '08, San Jose, CA, February 2008. Our own work analyzing how disks actually corrupt your data, not out of something! And something a reliable storage system must consider.

+   - [B+88] "Disk Shaving" by D. Morton and J. Gray. VLDB 1988. One of the first to discuss mirroring, therein "called shaving".

+   - [CU95] "Stripping in a RAID level 5 disk array" by Peter. Chen and Edward K. Lee. SIGMETRICS, A brief analysis of some of the parameters in a RAID-5 disk array.

+   - [C+04] "Rocky Parity for Disk Failure Correction" by P. Corbett, B. English, A. Go, T. Trancan, S. Kleiman, J. Long, S. Sarkar. FAST '04, February 2004. Though not the first pair of RAID system with two disks, it is currently and highly-understand version of said idea. We read it to learn more.

+   - [DAA05] "Fault-journaled Resynchronization for Software RAID" by Timothy D. Doreny, A. Apaci-Dusseau, R. Apaci-Dusseau. FAST 2005. Our own work on the consistent-update problem. Here we solve for Software RAID by integrating the journaling methodology of the file system with the software RAID benefit.

+   - [HLM94] "File System for an NFS File Server Application" by Dave Hunt, James Lee, Michael Lucken. USENIX Winter 1994, San Francisco, California, 1994. The sparse file-introducing product in storage, the flexible-any file layout or WAFL file system that underlies the NetApp file server.

+   - [BK86] "Synchronized Disk Interleaving"- The Emerging Approach to High Performance" by F. Kurzweil. IEEE Transactions on Computers, Volume Presentation at SIGCOMP '88, March 1988, San Francisco, California. Another earliest work on RAID is found here.

+   - [P+88] "Redundant Arrays of Inexpensive Disks" by D. Patterson, G. Gibson, and R. Katz. SIGMOD1988. This is considered the RAID paper, written by authors Patterson, Gibson, and Katz. The paper has many test-time-of awards and ushered in the RAID era, including the RAID named it!

+   - [Pr86] "Maintaining Fault Tolerance in Parallel Storage Systems" by A. Park, K. Balasubramanian. Department of Computer Science, Princeton, CS-TR-05-57, November 1986. Another early work on RAID.

+   - [SG86] "Disk Striping" by K. Salem, H. Garcia-M. IEEE International Conference on Engineering, 1986. And yes, there are a lot of these, which kind of came out of the woodwork when the RAID system was published in SIGMOD.

+   - [S84] "Byzantine Generals in Action: Implementing Fail-Stop Processors" by F.B. Schneider. ACM Transactions on Computer Systems, 2(2):145154, May 1984. Finally, a paper that is not about RAID! This paper is actually about how systems fail, and how to make something behave in a fail-stop manner.
