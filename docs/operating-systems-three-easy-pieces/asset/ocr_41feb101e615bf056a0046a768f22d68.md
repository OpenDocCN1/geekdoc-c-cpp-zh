# Homework (Measurement)

In this homework, you are to measure the size and cost of accessing a TLB. The idea is based on work by Saavedra-Barrera [SB92], who developed a simple but beautiful method to measure numerous aspects of cache hierarchies, with a very simple user-level program. Read his work for more details.

The basic idea is to access some number of pages in a large data structure (e.g., an array) and to time those accesses. For example, let's say the TLB size of 4 (which would be very small, but useful for the purposes of this discussion). If you write a program that touches 4 or fewer pages, repeatedly in a loop, each access should be a TLB hit, and relatively fast. However, once you touch 5 pages or more, repeatedly in cost, to that of a TLB miss.

In this loop, one page of the array is updated, up to the number of pages specified by NUMPAGES. By timing such a loop repeatedly (say, a few hundred times in order to run around once, or however many loops needed for a few seconds), you can time how long each access takes (on average). By looking for jumps in cost as NUMPAGES increases, you can roughly determine whether a second-level TLB exists (and how big it is if it does), and in general get a good sense of how TLB hits and misses affect performance.
