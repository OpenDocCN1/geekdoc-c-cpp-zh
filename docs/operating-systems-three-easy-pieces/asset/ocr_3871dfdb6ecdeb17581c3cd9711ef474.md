AFS makes an exception to this simple model between processes on the same machine. In this case, writes to a file are not immediately visible to other local processes (i.e., a process does not have to wait until a file is closed to see its latest updates), making using a single machine behave exactly as you would expect, as this behavior is expected upon typical UNIX systems. Only when switching to a different machine would you be able to detect the more general ARFS consistency mechanism.

There is one interesting cross-machine case that is worthy of further discussion. In the rare case that processes on different machines are modifying a file at the same time, AFS naturally employs what is known as a *last writer wins* approach (which perhaps should be called *last closer wins*).
