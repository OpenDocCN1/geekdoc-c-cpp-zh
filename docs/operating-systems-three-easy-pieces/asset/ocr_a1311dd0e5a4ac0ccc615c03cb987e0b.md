# SUN'S NETWORK FILE SYSTEM (NFS)

# References

[AKW98] "The AWK Programming Language" by Alfred A. Weiner, Brian W. Kernighan, Peter J. Weinerberger, 1998 (last edition). A concise, wonderful book about awk. Once we had the pleasure of meeting Peter Weinerberger when he introduced himself, he said "I'm Peter Weinerberger, you 'w' in awk? As huge awk fans, this was a moment to savor. One of us (Renzi) then said, "I love awk! I particularly like the book, which makes everything so wonderfully clearly." Weinerberg (crestfallen), and Oh, Kernighan wrote it.

[C00] "NFS Illustrated" by Brent Gallager. Addison-Wesley Publishing Computing Systems, 2000. NFS meaningful throughput and detail per the protocol itself.

[ES03] NFS Tools: Techniques for System Analysis by Daniel Ellard and Marco Saltzer. UCS, San Diego, California. An intricate analysis of NFS done via passive tracing. The authors show how to derive a vast amount of file system understanding.

[HM94] "File System Design for NFS Server Appliance" by Dave Hits, James Law, Michael Shell, Sun Microsystems, San Francisco, California, 1994. Hits were greatly influenced by work-on long-structured file systems.

[K86] "Vnodes: Architecture for Multiple File Systems in Sun Unix" by Steve R. Staubach, Carl Leve, USENIX Summer '86, Atlanta, Georgia. This paper shows how to build a file system architecture into operating system, enabling multiple file system elements to be used within a single operating system on some form.

[NT90] "Kerberos: Authentication Service for Computer Networks" by B. Clifford Needham, Theodore S. IIE, IEEE Communications, 32(9):33-38, September 1994. Kerberos is an early and highly influential authentication service. We probably should write a book about it some time...

[OI91] "The Role of Distributed State" by John K. Outsterter. Available at this site: http://ftp.cs.berkeley.edu/papers/papers.state. A referenced referenced of distributed state; a broader perspective on the problems and challenges.

[P94] "NFS Version 3: Design and Implementation" by Brian Pawlowski, Czech Juszczak, Peter Staubach, Carl Smith, Dave Leeds, Hits USENIX Summer 1994, pages 137-152. The small modifications that underlie NFS version 3

[P01] "NFS version 4" by Brian Pawlowski, David Daveck, David Robin, Robert Thorbert. 2002. International System Administration and Networking Conference (SANE 2000). Undoubtedly the most popular paper on NFS ever written.

[R91] "The Design and Implementation of the Log-structured File System" by Mendel Rosen-Blum, John Outsterter. Symposium on Operating Systems Principles (SOSP), 1991. LFS again. On your new ever get LFS.

[S86] "The Sun Network File System: Design, Implementation and Experience" by Russell Sandberg. USENIX Summer 1986. The original NFS paper, a bit of challenging to read, is worth to see the source of these useful ideas.

[Sun89] "NFS: Network File System Specification" by Sun Microsystems, Inc. Request for Comments: 1094, March 1989. Available: http://www.iet.org/rfc/rfc1094.txt. The detailed specification; read if you must, if you are getting paid to do it. Hopefully, paid a lot.
