TIP: MAKE THE SYSTEM USABLE

Probably the most basic lesson from FPS is that not only did it introduce the conceptually good idea of disk-aware layout, but it added a number of features that simply made the system more usable. Long file names, symbolic links, and a rename operation that worked atomically improved the utility of the system; while hard to write a research paper about (imagine trying to read a 14-page about “The Symbolic Link: Hard Link’s Lost Cost”), such small features made FPS more powerful and thus likely increased its chances for adoption. Making a system usable is often as more important than it does deep technical innovations.

Other usability improvements were added as well. FPS was one of the first systems to allow for long file names, enabling more expressive names in the file system instead of the traditional fixed-size approach (e.g., 8 characters). Further, a new concept was called a symbolic link. As discussed in a previous chapter [AD14b], hard links are limited in that they could not point to directories (for fear of introducing loops in the file system hierarchy) and that they can only point to files or directory within the same volume (the node number must still be meaningful). Symbolic links allow the user to create an “alias” to any other file or directory on a system and are much more flexible. FPS also introduced an atomic rename() operation for renaming files. Usability improvements, beyond the basic technology, also likely gained FPS a stronger user base.

# 41.8 Summary

The introduction of FPS was a watershed moment in file system history, as it made clear that the problem of file management was one of the most interesting issues within an operating system, and showed how one might begin to deal with that most important of devices, the hard disk. Since that time, hundreds of new file systems have developed, but still today many file systems take cues from FPS (e.g., Linux ext2 and ext3) are obvious intellectual descendants. Certainly all modern systems account for the main lesson of FPS: treat the disk like it’s a disk.
