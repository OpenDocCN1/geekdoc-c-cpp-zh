+   7. One interesting aspect of caching multiprocessors is the opportunity for better-than-expected speed of jobs using multiple CPUs (and caches) compared to running jobs on a single processor. Specifically, when you run on N CPUs, a situation sometimes super-linear speed. To experiment with this, use the job description (-L a:100,b:100,c:100:50,c:100:50) with a small cache (-M 50) to create three jobs. Run this on systems with 1, 2, and 3 CPUs (-n 1,-n 2,-n 3). Now do the same, but with a larger per-CPU cache of size 100. What do you notice about performance as the number of CPUs scales? Use -c to confirm your guesses, and other tracing flags to dive even deeper.
