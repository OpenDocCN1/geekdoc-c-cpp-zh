Like those other systems, upon a context switch, the user portion of the address space changes; the kernel portion is the same across processes. Like those other systems, a program running in user mode cannot access kernel virtual pages; only by trapping into the kernel and transitioning to privileged mode can such memory be accessed.

In classic 32-bit Linux (i.e., Linux with a 32-bit virtual address space), the split between user and kernel portions of the address space takes place at address 0xC0000000, and three-quarters of the way through the address space. Thus, virtual addresses 0 through 0xFFFFFFFF are user virtual addresses; the remaining virtual addresses (0xC0000000 through 0xFFFFFF) are in the kernel's virtual address space. 64-bit Linux has a similar split but at significantly different points. One slightly interesting aspect of Linux is that it contains two types of kernel virtual addresses. The first are known as kernel logical addresses [O6]. This is what you would consider the normal virtual address space of Linux; to get more memory of this type, kernel code merely needs to call kmalloc.
