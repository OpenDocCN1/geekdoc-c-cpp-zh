Block 0 is now ready to be programmed. Most SSDs will write pages
in order (i.e., low to high), reducing reliability problems related to pro-
gram disturbance. The SSD then directs the write of logical block 100
into physical page 0:

| Block: | 0 | 1 | 2 |
| Page: | 00 01 02 03 04 05 06 07 08 09 10 11 |
| Content: | a1 | | | | | | | | | | |
| State: | V E E | | | | | | | | | | |

But if the client wants to read logical block 100? How can it find
where it is? The SSD must transform a read issued to logical block 100
into a read of physical page. To accommodate functionality, when
the FTL writes logical block 100 to physical page 0, it records this fact
in an in-memory mapping table. We will track the state of this mapping
table in the diagrams as:

| Table: | 100 → 0 | Memory |

| Block: | 0 | 1 | 2 |
| Page: | 00 01 02 03 04 05 06 07 08 09 10 11 |
| Content: | a1 | | | | | | | | | | | |
| State: | V E E | | | | | | | | | | | |

Now you see what happens when the client writes to the SSD.
The SSD finds a location for the write, usually picking the next free
page; it then programs page with the block's contents, and records
the logical-to-physical mapping in its mapping table. Subsequent results
use the table to translate the logical block address presented by
the client into the physical page needed to read the data.
Let's examine the rest of the writes in our example write stream:
101, 2000, and 2001. After writing these blocks, the state of the device is:

| Table: | 100 → 0 | 101 → 1 | 2000→ 2 | 2001→ 3 | Memory |

| Block: | 0 | 1 | 2 |
| Page: | 00 01 02 03 04 05 06 07 08 09 10 11 |
| Content: | a1 a2 b1 b2 | | | | | | | | | |
| State: | V V V | | | | | | | | | | |

The log-based approach by its nature improves performance (erases
only required in a while, and the costly read-modify-write of
the direct-mapped approach avoided altogether), and greatly enhances
reliability. The FTL can spread writes across all pages, performing
what is called wear leveling and increasing the lifetime of the device;
'll discuss wear leveling further below.
