# Cost

As we have, the performance of SSDs generally outweighs modern hard drives, even when performing sequential I/O. So why haven’t SSDs replaced hard drives? The answer is simple: cost or more specifically, cost per unit of capacity. Currently [AI15], an SSD costs something about $150 for a 250-GB drive; while an SSD costs 60 cents per GB. A typical hard drive costs roughly $50 for 1-TB of storage, which means it 5 cents per GB. There is still more a 10× difference in cost between these two storage media.
These performance and cost differences dictate large-scale storage systems. If performance is the main concern, SSDs are a terrific choice, particularly if random performance is important. If, on the other hand, you are assembling a large data center and wish to store massive amounts of information, the cost difference will drive you towards hard drives. Of course, a hybrid approach can make sense – some storage systems are being assembled with both SSDs and hard drives, using a smaller number of SSDs for more popular “hot” data and delivering high performance, while storing the rest of the “colder” (less used) data on hard drives to save cost. As long as the price gap exists, hard drives are here to stay.
