# References

+   [B+13] "Efficient Virtual Memory for Big Memory Servers" by A. Basu, J. Gandhi, J. Chang, M. D. Hill, M. M. Swift. ISCA 15, 13 June 2013, Tel-Aviv, Israel. A recent work showing that TLBs matter, consuming 10% of cycles for large-memory workloads. The solution: one massive segment to hold data sets. We go back, so that we can recover

+   [BB72] TENEX, A Paged Time Sharing System for PDP-10" by D. Dobson, J. D. Burch, F. L. Murphy, R. S. Thomson. ACM, Volume 15, 1972. An early time-sharing OS where a number of good ideas came. On-write was just one of these; also an inspiration for modern operating systems, virtual memory management, and file systems.

+   [C81] "Converting a Segment-Based to a Paged Architecture Locking Page-Reference Bits" by B. Oaabaga, W. N. Noy. IOS '81, Pacific Grove, California, December 1981. A good read for exploit protection mechanism to emulate reference bits, by a group at Berkeley working on their version of UNIX: Berkeley Systems Distribution (BSD). The group was influential in the development of virtual memory.

+   [C05] "Understanding Linux" by W. Love, and M. Ceseti. O'Reilly Media, November 2005. One of the many books you can find on Linux, which are date, but still worthwhile.

+   [C03] "The Innov's Dilemma" by Clayton Christensen. Harper Publishers, 2003. A fantastic book about the disk-drive industry and how new innovations disrupt existing ones. A good read for business managers and computer scientists. Provides insights on how large and successful companies completely fail.

+   [C93] "Windows NT" by H. C. Suter. Microsoft Press, 1993. The book about Windows NT that explains the system to top, more detail than you might like. A pretty good book.

+   [C04] "Understanding Virtual Memory Management" by M. Gorman. Prentice Hall, 2004. An in-depth look at Linux VM, but also a bit of other.

+   [G17] "Live KASLR" by D. Grus, M. Milch, M. Schwarz, R. Petit, C. Santiago, S. Mangard. Engineering Security Systems and Systems, 2017. Available: https://grus.fi/files/kaslr.pdf Essential info on KASLR, KPTI, and beyond.

+   [Q94] "A Low Overhead Performance Buffer Management Replacement Algorithm" by T. Johnson, D. Shasta. VLDB '94, 1994 Santiago, Chile. A simple but effective approach to building page replacement.

+   [L82] "Virtual Memory in the VAX/VMS Operating System" by H. Levy, P. Lipman. IEEE Computer, Volume 15/3, 1982. The original source of this article. Particularly important if you want to go graduate school, where all the do you read, read some more papers, work more, effectively write a paper and then some more.

+   [RI16] "Virtual Memory and Linux" by A. Ott. IEEE Linux Conference, 2016. https://events.linuxfoundation.org/sites/events/files/slides/0216_mem.pdf. A useful set of slides which gives an overview of the Linux VM.

+   [S07] "The Geometry of Return-on-Intellect without Functions (on the x86)" by H. Shacham, CCS '07, October 2007. A generalization of return-to-lib. Dr. Beth Garner in Basic Instinct, "It's crazy!" This is what we say about ROB.

+   [S04] "On the Effectiveness of Address-space Randomization" by H. Shacham, M. Page, B. Pfaff, E. J. Geb, N. M. Modaddu, D. Boneh. CCS '04, October 2004. A description of the return-to-lib attack and its limits. Start reading, but because: the rabbit hole of systems security is deep...
