# 39.17 Making And Mounting A File System

We've toured the basic interfaces to access files, directories, and
certain types of special types links. But there is one more topic we
should discuss: how to assemble a full directory tree from many under-\lying file systems. This task is accomplished by first making file systems,
and mounting them to make their contents accessible.

To make a file system provide a tool, usually re-
ferred to as mkfs (pronounced “make fs”), that performs exactly this task.
The idea is as follows: give the tool, as input, a device (such as a disk part-\ition, e.g., /dev/sda) and a file system type (root.g., ext3), and it simply
writes a file system starting with a root directory, onto that partiton.

However, once such a file system is created, it needs to be made ac-\cessible within the uniform file system tree. This task is achieved via the
mount program (which makes the underlying system call () to
the real work). What mount does, simply is to attach an existing direc-
tory as a mount point and essentially paste a new file system onto
the directory at that point.
