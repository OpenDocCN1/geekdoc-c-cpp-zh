# Homework (Simulation)

The program, `malloc.py`, lets you explore the behavior of a simple free-space allocator as described in the chapter. See the README for details of its basic operation.

# Questions

+   1. First run with the flags -n 10 -H 0 -p BEST -s 0 to generate a few random allocations and frees. Can you predict what alloc()/free() will return? Can you guess the state of the free list after each request? What do you notice about the free list over time?
2. How are the results different using a WORST fit policy to search for the free list (-p WORST)? What changes?
3. What about when using FIRST (-p FIRST)? What speeds up when you first fit?
4. For the above questions, how is the list kept order affect the time it takes to find a free location for some of the policies. Use the different free list orderings (-1 ADSORT, -1 SIZERT+) to see how policies and the list ordering interact.
5. Coalescing of a free list can be quite important. Increase the number of random allocations (say to -n 1000). What happens to larger allocation requests over time? Run with and without coalescing (i.e., with the -c flag). What differences in outcome do you see? Does the ordering of the list matter in this case?
6. What happens when you change the percent allocated fraction -P to higher than 50? What happens to allocations as it nears 100? What about the percent nears 0?
7. What kind of specific requests can you make to generate a highly-fragmented free space? Use the -A flag to create fragmented free lists, and see how different policies and options change the organization of the free list.
