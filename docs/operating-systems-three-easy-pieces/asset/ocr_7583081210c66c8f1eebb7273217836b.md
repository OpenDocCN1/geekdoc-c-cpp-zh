One last point about this address space relates to protection. Clearly,
The OS does not want user access to reading or writing Os data or
code. The hardware must support different protection levels for
pages to enable this. The VAX did so by specifying, in protection levels
the page table, which privilege level the CPU must be in order to
access a particular page. Thus, system data and code are set to a higher
level of protection than user data and code; an attempted access to
information from user code would generate a trap into the OS, and (you
gued it) the likely termination of the offending process.
