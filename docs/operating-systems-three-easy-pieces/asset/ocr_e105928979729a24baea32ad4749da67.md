# 338 LOCKS

```
typedef struct __lock_t {
    int flag;
} lock_t;

void init(lock_t *lock) {
    // 0: lock is available, 1: lock is held
    lock->flag = 0;
}

void lock(lock_t *lock) {
    while (TestAndSet(&lock->flag, 1) == 1) {
        // spin-wait (do nothing)
    }
}

void unlock(lock_t *lock) {
    lock->flag = 0;
}
```

Figure 28.3: A Simple Spin Lock Using Test-and-set

The test-and-set instruction does as follows: it returns the value pointed to by the old_ptr, and simultaneously updates said value to new. The key, is that this sequence of operations is performed atomically. The reason it is called "test and set" is that it enables us to "test" the old value (which is returned) while simultaneously "setting" the memory to a new value: as turns out, this more powerful instruction is enough to build a simple spin lock, as we now examine in 28.3. Or better yet: figure it out yourself!

Let's make sure understand why this lock works. Imagine the case where a thread calls lock() and no other thread currently holds the lock; when TestAndSet(flag, 1), the routine will return the old value of flag, which is 0; thus, the calling thread, which is testing the value of flag, will not get spinning in the while loop and will acquire the lock. The thread will also set the value to 1, indicating that the lock is now held. When the thread is finished with its critical section, it calls unlock() to set the lock back to zero.
The second case we can imagine when one thread already has the lock held (i.e., flag is 1). In this case, thread will call lock() and then call TestAndSet(flag, 1) as well. This time, TestAndSet() will return the old value at flag, which is 1 (because the lock is held), while simultaneously setting it to 1. As long as the lock is held by another thread, TestAndSet() will repeatedly return 1, and thus thread will spin and spin until the lock is finally released. When the flag is finally set to 0 by some other thread, this thread will call TestAndSet() again, which will now return 0 while atomically setting the value to 1 and acquire the lock and enter the critical section.
