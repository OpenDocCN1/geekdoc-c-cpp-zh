# Splitting and Coalescing

A free list contains a set of elements that describe the free space remaining in the heap. Thus, assume the following 30-byte heap:

| free | used | free |
|---|---|---|
| | 10 | 20 | 30 |

The free list for this heap would have two entries on it. One entry describes the first 10-byte free segment (bytes 0-9), and one entry describes the other free segment (bytes 20-29):

```
head addr:0 len:10 -> addr:20 len:10 -> NULL
```

As described above, a request for anything greater than 10 bytes could fail (returning NULL); there isn't a single contiguous chunk of memory of that size available. A request for exactly that size (10 bytes) could be satisfied either of the free chunks. But what happens if the request is for smaller than 10 bytes?
