# INTERLUDE: Thread API

The second argument, attr, is used to specify any attributes this thread might have. Some examples include setting the stack size or perhaps information about the scheduling priority of the thread. An attribute is initialized with a separate call to pthread_attr_init(); see the manual page for details. However, in most cases, the defaults will be fine; in this case, we will simply pass the NULL in.

The third argument is the most complex, but really just asking: which function should this thread start running? In C, this is a function (start.routine), and this one tells us the following: a expected function name (as passed a single argument of type void * in the parentheses after start.routine), and returns a value of type void (a void pointer).

If this routine required an integer instead of a void pointer, the declaration would look like this:

```
int pthread_create(.., // first two args are the same
                    void (*start_routine)(int),
                    int arg);
```

If the routine took a void pointer as an argument, but returned an integer, it would look like this:

```
int pthread_create(.., // first two args are the same
                    int (*start_routine)(void *),
                    void *arg);
```

Finally, the fourth argument, arg, is exactly the argument to be passed to the function where the thread begins execution. You might ask: why do we need thread pointers? Well, the answer is simple: using a void pointer as an argument to the function start_routine allows us to pass in any type of argument; having it allows the thread to return any type of result.

Let's look at an example in Figure 27.1. Here we create a thread that passes two arguments, packed into a single type we define ourselves (myarg.t). The thread, created, can simply cast its argument to the type it expects and unpack the arguments as desired.

And there is it! Once you create a thread, you really have another live executing entity, complete with its own stack, running within the same address space as all the currently threads in the program. The fun begins!

# 27.2 Thread Completion

The example shows how to create a thread. However, what happens if you need to wait for a thread to complete? You need to do something special in order to wait for completion; in particular, you must call the routine pthread_join().

```
int pthread_join(pthread_t thread, void **value_ptr);
```
