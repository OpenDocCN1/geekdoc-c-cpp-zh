# The Single Buffer Producer/Consumer Solution

The solution here is again a small: use two condition variables, instead of one, to properly which type of thread should wake up when the state of the system changes. Figure 30.12 shows the resulting code.

In the code, producer waits on condition empty and signals fill. Conversely, consumer waits on fill and signal empty. By doing so, the second problem above is avoided by design: a consumer can never accidentally wake a consumer, and a producer can never accidentally wake a producer.
