Figure 29.6: Scaling Approximate Counters

Figure 29.6 shows the importance of the threshold value S, with four threads incrementing the counter one million times on four CPUs. If S is low, performance is poor (the global count is quite accurate); if S is high, performance is excellent, but the global count lags (by most the number of CPUs multiplied by S). This accuracy/performance trade-off is what approximate counters enable.
