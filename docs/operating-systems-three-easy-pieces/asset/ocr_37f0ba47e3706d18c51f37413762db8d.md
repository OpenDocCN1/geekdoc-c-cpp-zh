Third, we should note that one has to be extremely careful with how values are returned from a thread. Specifically, returning a pointer which refers to something allocated on the thread's call stack. If you do, what do you think will happen? (think about it!) Here is an example of a dangerous piece of code, modified from the example in Figure 27.2.

```
void *mythread(void *arg) {
    myret_t *args = (myret_t *) arg;
    printf("%d %da\n", args->a, args->b);
    myret_t oops; // ALLOCATED ON STACK: BAD
    oops.x = 1;
    oops.y = 2;
    return (void *) &oops;
```

In this case, the variable oops is allocated on the stack of mythread. However, when it returns, the value is automatically deallocated (that's why the stack is so easy to use, after all!), and passing back a pointer
