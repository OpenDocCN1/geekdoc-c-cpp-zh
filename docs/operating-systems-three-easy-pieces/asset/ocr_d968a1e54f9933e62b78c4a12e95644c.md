# Homework (Code)

This homework lets you explore some real code that deadlocks (or avoids deadlock). The different versions of code correspond to different approaches to avoiding deadlock in simplified vector_add() runtime. See the README for details on these programs and their common substrate.

# Questions

2. Add the -d flag, and change the number of loops from 1 to higher numbers. What happens? Does the code (always) deadlock?
