# 39.16 Permission Bits And Access Control Lists

The abstraction of a process showed two central virtualizations: of
the CPU and memory. Each of these gave the illusion to a process that
it had its own CPU and its own private memory; in reality, the OS
underneath used various techniques to share limited physical resources
among competing entities in a safe and secure manner.

The file system presents a visual view of a disk, transforming it
 a bunch of raw blocks into more user-friendly files and di-rectories, described within this chapter. However, the abstraction is
notably different from that of the CPU and memory, in that files are com-mon among different users and processes and are not (always)
private. Thus, a more comprehensive set of mechanisms for enabling var-ious degrees of sharing are usually present within file systems.

The first form of such mechanisms is the classic permission bits.
to see permissions for a file foo.txt, just type:

```
prompt ls -l foo.txt
-rw-r-- 1 remzi wheel 0 Aug 24 16:29 foo.txt
```

We'll pay attention to the first part of this output, namely the
-rw-r--. The first character here shows the type of the file: - for
a regular file (which foo.txt is), d for directory, for a symbolic link,
and so forth; this is (mostly) not related to permissions, so we'll ignore it
 now.

We are interested in the permission bits, which are represented by the
next characters (rw-r--r--). These bits determine, for each regular
file, directory, and others, exactly who can access it and how.

The permissions consist of three groups: what the owner of the file
can do to it, what someone in a group can do the file, and what
(sometimes referred to as other) can. The abilities the owner,
group member, or others have the ability to read the file, write,
or, execute it.

In example above the first three characters of the output of ls
show that the file is both readable and writable by the group (rw-),
only readable by members of the group wheel and also by anyone else
in the system (r--- followed by r--).

The owner of the file can readily change these permissions, for exam-\ple by using the chmod command (to change the file mode). To remove
t ability for anyone except the owner to access the file, you could type:

```
prompt chmod 600 foo.txt
```
