LOG-STRUCTURED FILE SYSTEMS

# # Homework (Simulation)

This section introduces lfs.py, a simple LFS simulator you can use to understand better how LFS-based file system works. Read the README for details on how to run the simulator.

# # Questions

+   1. ./lfs.py -n 3, perhaps varying the seed (-s). Can you figure out which commands were run to generate the final file system contents? Can you tell the liveness of each block in the final file system state? Use -o to show which commands were run, and -c to show the liveness of the final file system state. How much harder does the task become for you as you increase the number of commands issued (i.e., -n 3 to -n 5)?

+   2. If you know the painful, can you help yourself a little bit by showing the set of updates caused by each specific command. To do so, run ./lfs.py -n 3 -l. Now see if it is easier to understand what each command must have been. Change the random seed to get different commands to interpret (e.g., -s 1, -s 2, -s 3, etc.).

+   3. To test your ability to figure out what updates are made by each command, run the following: ./lfs.py -o -F -100 (and perhaps a other random seeds). This shows a set of commands and does NOT show the final state of the file system. Can you reason about what the final state of the file system must be?

+   4. Now see if you can determine if files and directories are live after a number of file operations. Run tt ./lfs.py -n 20 -s 1 and then examine the final file system state. Figure out which pathnames are valid? Run tt ./lfs.py -n 20 -s 1 -c -v to see the results. Run with -o to see if your answers match the series of random commands. Use different randomseed to get more problems.

+   5. Now let's issue some specific commands. First, create a file and write to it. To do so, use the -L flag, which lets you specify specific commands to execute. Create the file "foo" and write it four times:
-L c,foo:w,0,1w:/foo,1,1w:/foo,2,1w:/foo,3,1w -o
o. See if you can determine the liveness of the file system state; use -c to check your answers.

+   6. Now, let's do the same thing, but with a single write operation instead of foo. Run ./lfs.py -o L c,foo:w,0 to create file "foo" and write 4 blocks with a single write operation.
