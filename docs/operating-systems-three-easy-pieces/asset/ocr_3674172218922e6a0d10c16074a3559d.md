# References

[A07] "A Five-Year Study of File-System Metadata" by Nitin Agrawal, William J. Boloski, John R. Dourcer, Jacob R. Lorch. FAT '07, San Jose, California, February 2007. An excellent review of file-system analyses are actually used. Use the bibliography to follow the trail of file-analysis papers back to the early 1980s.

[B07] "ZFS: The Last Word in File Systems" by Ben Bonwick and Bill Moore. Available from: http://www.ostep.org/Citations/zfs_last.pdf. One of the most important file systems, full of features and advancements. We should have a chapter on it, and perhaps soon better.

[B02] "The FAT File System" by Andrews Brouwer. September, 2002. Available online: http://www.fune.net/tui/linux/fs/fat.html. A nice description of the FAT file system, not the kind canon. You have to admit, but fat probably tastes better.

[C94] "The Windows File System" by Helen Custer. Microsoft Press, 1994. A short book about NTFS: there are provided you with more technical details elsewhere.

[H-88] "Scale and Performance in a Distributed File System" by John H. Howard, Michael L. Kazi, Sherri G. Menees, David A. Nichols, S. Subramanian, Robert N. Sidbotham, Michael J. West. ACM TOCS, Volume 6, February 1988. A classic distributed file system; we'll be learning more about it later, don't worry.

[P09] "The Unix Time-Sharing System: Internal Layout" by Dave Portier. Available: http://www.nongu.org/ext2/ext2.html. Some details on ext2, a very simple linux file system for FS. We'll be reading about it in the next chapter.

[RT74] "The Unix: An Unified I/O and Memory Subsystem" by M. Ritchie, K. Thompson. CACM Volume 17,7, 1974. The original paper about UNIX. Read it to see the underpinnings of modern operating systems

[S00] "UBC: An Unified Buffer Cache" by Chuck Silver, T TREND, 2000. A nice paper about NetBSD's integration of file-system buffer caching and the virtual-memory page cache. Many other systems do the same type of

[S96] "Scalability in the XFS File System" by Adam Sweeney, Doug Courville, Wei Hu, Curtis Anderson, Mike Nishimoto, Geoff Peck. USENIX '96, January 1996, San Diego, California. The first attempt to make scalability of operations, including things like having millions of files in a directory, a central focus. A great example of pushing an idea to the extreme. The key idea behind this file system: everything is everything. We should have a chapter on this file system too.
