+   * **(+): This is known as the Add AND operator.**

It will add the values from both operands and then assign the total of these to the operand on the left side.

+   * **(*=): This is the Multiply AND operator.**

It will multiply both operands and then pass the results to the operand on the left side.

+   * **(-=):** This is the operator that subtracts the value of your operand on the right from the one on the left and then returns the difference to the left operand.

+   * **(/=): This is the divide and operator**

It will divide the value on the left side by the value on the right side and then assign this amount to the left side.

One of the things we need to look at here is how the assignment operators will appear in many of the C++ programs that we wish to employ. Some will be used on a frequent basis, such as the equal sign when dealing with variables and giving a value to them.

Then there will be some of the above choices that are not very popular, and you are unlikely to utilize them until you have advanced quite a bit in your coding.

Most of the time, though, the assignment operator that you will use is the equal sign. This allows us to assign the correct value to the variable we want to work with, but there may be instances when we want to use some of the other assignment operators to assist move our code ahead.

+   * **(>):** this operator will compare the values of your operands.
