The comments are the first aspect of the syntax that we will examine in the C++ language. These will be useful to learn about since they will allow us to put a little message or a note in the code that we are creating without altering how the code will function.

These comments will assist us, and others who look at the code, in understanding what you want to do with it. As a newbie, you will notice that many scripts will contain this kind of comments to help you understand what is going on.

The comments will serve to guide you with what you are wanting to accomplish in the code, and we are theoretically allowed to include as many of these as we like in our programs. The rule of thumb here is to restrict the comments to just those that are required so that the scripts do not get jumbled.

**To create comments in this language, use the (//) sign before the comment.**

This will notify the compiler that you are creating one of these comments, and it should just skip over this section and not include it in the execution that you deal with here.

You may put them in any area of the code you choose, and the compiler will understand what is going on. Even in this language, we may make a remark that is longer than one line or takes up more than one line. This is something that is difficult to do in other languages but is unique to the C++ programming language.

When you want to continue through and have a code that takes on more than one line, add the /* symbol to the beginning of the comment, and then use the */ symbol wherever it ends. When the compiler encounters this, it will know that it should continue through the code without reading any of this.
