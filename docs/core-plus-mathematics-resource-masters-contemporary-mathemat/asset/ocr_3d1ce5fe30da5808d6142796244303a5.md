# Form B

Suggested Solutions

+   1. **a.** Any equation that satisfies $6=a(0-h)^2+k$ where $a>0$ is correct. One example is $y=(x-1)^2+5$.
+   
+      **b.** Any equation of the form $y=a(x+3)^2+8$ where $a<0$ will have a maximum point at $(-3,8)$.
+   
+      **c.** If the $x$-intercepts are $(2,0)$ and $(8,0)$, then a function rule must be of the form $y=a(x-2)(x-8)$. Students can then rewrite this rule in vertex form. If $a=1$, $y=x^2-10x+16$. In vertex form, this is $y=(x-5)^2-9$.

+   2. If $b^2-4ac>0$, the graph will have 2 $x$-intercepts.
+   
+      If $b^2-4ac=0$, the graph will have 1 $x$-intercept.
+   
+      If $b^2-4ac<0$, the graph will not intersect the $x$-axis.

+   3. **a.** $(x+8)^2-4$
+   
+      **b.** $(x-3)^2+1$

+   4. **a.** $x=-4\pm\sqrt{5}$
+   
+      **b.** $x=-\frac{1}{3}$ and $x=1$
+   
+      **c.** $x=\frac{-3\pm\sqrt{57}}{6}$
+   
+      **d.** $x=2\pm5i$
