## Transformation Graphing Application

The Transformation Graphing App® is a dynamic application that allows you to input a general equation for a function based on parameters, then view changes in its graph as the parameters are changed.

| Calculator Commands | Expected Display |
|---|---|
| **Begin the application:**<br>`APPS`, highlight **Transfrm**, `ENTER` | Calculator applications menu with **Transfrm** highlighted. |
| **Enter general equation:**<br>`Y=`, then enter, for example, **AX^2+BX+C**. (Note that variable coefficients do not need to be separated from **X** by a multiplication sign.) | The general equation is entered in the calculator's function editor. |
| **Set the initial parameter values:**<br>`WINDOW`, adjust the window settings, enter `.5`, `ENTER`, `1.5`, `ENTER`, `-5`, `ENTER`, `.5` | Window settings showing the initial parameter values. |
| **Display the graph, then dynamically change parameters:**<br>`GRAPH`, use the arrow keys to select a parameter; use the left and right arrow keys to change the selected parameter by the step value, or enter values using the keypad. | The graph is displayed with the parameter values shown. |
| **Return to normal calculator functionality:**<br>`APPS`, highlight **Transfrm**, `ENTER`, `ENTER` | Transformation Graphing menu with **1: Uninstall** and **2: Continue**. |

### Form A

- 1. Consider the graph of the polynomial function shown below.

  ![](img/524030daad8f78e8d291a7f96ed9b8cb_15_0.png)

  - a. What is the smallest possible degree for this polynomial function? Explain your reasoning.
  - b. Estimate the coordinates of all local maximum points.
  - c. Estimate the coordinates of all local minimum points.
  - d. Estimate the zeroes of this polynomial function.

- 2. Consider the function $f(x)=(x^2-x)(x+5)$.

  - a. What are the zeroes of $f(x)$?
  - b. Write $f(x)$ in standard polynomial form.

- 3. Consider the polynomial function $f(x)=7x^3+x^2-4x+10$.

  - a. Write a polynomial function rule for $g(x)$ so that the degree of $f(x)+g(x)$ is 4. Explain your reasoning.
  - b. Write a polynomial function rule for $h(x)$ so that the degree of $f(x)-h(x)$ is 2. Explain your reasoning.
  - c. Write a polynomial function rule for $p(x)$ so that the degree of $f(x)\cdot p(x)$ is 6. Explain your reasoning.

- 4. Write a rule for a cubic function that has zeroes only at $(3, 0)$ and $(-2, 0)$. Explain your reasoning.

- 5. The daily revenue of the Lensic movie theater depends on the ticket cost $x$ according to the function $R(x)=x(250-5x)$. The daily expenses of the theater are related to the ticket price according to the rule $E(x)=1{,}250-30x$.

  - a. Find a rule in standard polynomial form for the daily profit.
  - b. If the ticket price is \$8, what is the daily profit?

### Suggested Solutions

- 1.
  - a. The polynomial must be at least degree 4 since it has three local maxima or minima and four $x$-intercepts.
  - b. The local maximum points are $(-3.9, 8.1)$ and $(2.9, 8.1)$. Student estimates should be close to these.
  - c. The local minimum point is $(-0.5, -4.6)$.
  - d. The zeroes of the function are $x=-5$, $x=-2$, $x=1$, and $x=4$.

- 2.
  - a. The zeroes of $f(x)$ are $x=0$, $x=1$, and $x=-5$.
  - b. $f(x)=x^3+4x^2-5x$.

- 3.
  - a. Any polynomial of degree 4 is correct.
  - b. Any polynomial of degree 3 with $7x^3$ as the leading term is correct.
  - c. Any polynomial of degree 3 is correct.

- 4. The possible rules are of two forms:
  - $f(x)=a(x-3)^2(x+2)$, where $a$ is any real number, and
  - $f(x)=a(x-3)(x+2)^2$, where $a$ is any real number.

- 5.
  - a. $P(x)=x(250-5x)-(1{,}250-30x)=-5x^2+280x-1{,}250$.
  - b. The daily profit is \$670, since $P(8)=670$.
