### Form A — Suggested Solutions

- **1.**
  - **a.** The girth of the box is 4x. Thus, the greatest length must be 108 − 4x. The area of one end of the box is x². Since the volume is the area of the end times the length, the volume is x²(108 − 4x).
  - **b.** V(x) = −4x³ + 108x²
  - **c.** 3
  - **d.** The zeroes are 0 and 27.
  - **e.** The maximum volume of the box is 11,664 in³. The dimensions of this box are 18 in. × 18 in. × 36 in.
- **2.**
  - **a.** IV

  - **e.** II

    f(x) = (x + 3)² − 13

  - **c.** x = [−6 ± √(6² − 4(1)(−4))] / [2(1)] = −6/2 ± √52/2 = −3 ± √13

  - **a.** x⁴ + 5x³ + 6
  - **b.** −8x³ + 4x + 7
- **5.**
  - **a.** (3x − 15)/(x − 5) = 3(x − 5)/(x − 5) = 3
  - **b.** (3x² + 6x)/(x + 3)

- **7.**
  - **a.** It looks like a line because the simplified form of f(x) = (x² + 7x + 6)/(x + 1) is f(x) = x + 6, which is a rule for a linear function.
  - **b.** The graph is not really a line because the original function is undefined when x = −1. But the domain of a linear function is all real numbers.
