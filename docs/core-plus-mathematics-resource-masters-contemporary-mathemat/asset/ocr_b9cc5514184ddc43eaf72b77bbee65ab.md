# # Transformation Graphing Application

The Transformation Graphing App® is a dynamic application that allows you to input a general equation for a function based on parameters, then view changes in its graph as the parameters are changed.

| Calculator Commands | Expected Display |
|---|---|
| **Begin the application:**<br>`APPS`, highlight **Transfrm**, `ENTER` | Calculator applications menu with **Transfrm** highlighted. |
| **Enter general equation:**<br>`Y=`, then enter, for example, **AX^2+BX+C**. (Note that variable coefficients do not need to be separated from **X** by a multiplication sign.) | The general equation is entered in the calculator's function editor. |
| **Set the initial parameter values:**<br>`WINDOW`, adjust the window settings, enter `.5`, `ENTER`, `1.5`, `ENTER`, `-5`, `ENTER`, `.5` | Window settings showing the initial parameter values. |
| **Display the graph, then dynamically change parameters:**<br>`GRAPH`, use the arrow keys to select a parameter; use the left and right arrow keys to change the selected parameter by the step value, or enter values using the keypad. | The graph is displayed with the parameter values shown. |
| **Return to normal calculator functionality:**<br>`APPS`, highlight **Transfrm**, `ENTER`, `ENTER` | Transformation Graphing menu with **1: Uninstall** and **2: Continue**. |
