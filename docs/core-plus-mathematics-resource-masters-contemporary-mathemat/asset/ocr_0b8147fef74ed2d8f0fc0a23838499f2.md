# Suggested Solutions
Chromatic Polynomials

Students can work alone or in pairs on this project. You may wish to spend some time introducing or reviewing the Multiplication Principle of Counting before students begin work on this project. Every polynomial has a related *chromatic polynomial*. Using the Multiplication Principle of Counting, these polynomials are fairly easy to find for graphs with up to 4 vertices. However, it is easy to create a graph with 5 vertices for which the chromatic polynomial is complicated and difficult to justify. A recursive algorithm exists for computing the chromatic polynomial for any graph G. The algorithm shows that every graph has a chromatic polynomial. However, which polynomial have corresponding graphs is still an unanswered question in mathematics. Students who are ready for a challenge should be encouraged to investigate the recursive algorithm for computing the chromatic polynomial that is described in some graph theory textbooks: $C_G(k)=C_{G-e}(k)-C_{G/e}(k)$, where $G-e$ is the graph with the edge $e$ removed and $G/e$ is the graph where the vertices of $e$ are identified together (made one).

# Solutions

+   1. There are 6 different 3-colorings of the given graph. Start at any vertex; there are 3 choices for coloring that vertex. Then there are 2 possible colors for the next vertex that is chosen, and the last vertex must be colored using the remaining color. This gives 6 possible 3-colorings. Some students might choose to show all 6 possibilities. In this case, be sure they can justify that they have all possible 3-colorings.

+   2. **a.** Since each vertex can be assigned any of the $k$ colors, there are $k^4$ possible assignments. Thus, the chromatic polynomial on a null graph (a graph with no edges) of 4 vertices is $C_G(k)=k^4$.
+   
+   **b.** Start with any vertex; choose one of $k$ colors. Choose a second vertex. Since it is adjacent to the first vertex, it can be colored with $(k-1)$ colors. Choose one of these colors. The third vertex can be colored with $(k-2)$ colors and the fourth vertex with $(k-3)$ colors. Thus, the chromatic polynomial for a complete graph on 4 vertices is $C_G(k)=k(k-1)(k-2)(k-3)$. The zeroes for this polynomial are 0, 1, 2, and 3, which indicates that there are no colorings if only 0, 1, 2, or 3 colors are used.
+   
+   **c.** Graph on $p$ vertices with no edges: $C_G(k)=k^p$
+   
+   Complete graph on $p$ vertices: $C_G(k)=k(k-1)(k-2)\cdots(k-p+1)$
