+   2. a.  $f(x)=(x-5)^2-22$

+   b.  The minimum point has coordinates $(5,-22)$.

+   3. a.  Any value of $c$ such that $b^2-4ac$ is positive and not a perfect square will give an equation with two irrational solutions. Since $b^2-4ac>0$, $7^2-4(2c)>0$ implies that $c<\frac{49}{8}$.
+   
+   b.  In order for the solution to be rational, $b^2-4ac$ must be a perfect square. Some possible choices for $c$ are $c=-4$, $c=3$, and $c=5.21375$.
+   
+   &nbsp;&nbsp;&nbsp;&nbsp;If $c=-4$, $b^2-4ac=49-4(2)(-4)=81$.
+   
+   &nbsp;&nbsp;&nbsp;&nbsp;If $c=3$, $b^2-4ac=49-4(2)(3)=25$.
+   
+   &nbsp;&nbsp;&nbsp;&nbsp;If $c=5.21375$, $b^2-4ac=49-4(2)(5.21375)=7.29$.
+   
+   c.  Any value of $c$ such that $49-4(2)c<0$, or $c>\frac{49}{8}$, will give an equation with two complex solutions.
