# ### Form B
### Suggested Solutions

+   1. a. The domain of f(x) is all real numbers except 8 and 0.
+      b. The only x-intercept of the graph is (−1, 0). The x-coordinate of the x-intercept is a zero of the numerator of the function but not a zero of the denominator of the function.
+      c. There is only one vertical asymptote at x = 0. Zero is the only value that is a zero of the denominator and not a zero of the numerator.

+   2. a. (x − 5) / 10
+      b. No. They are not equivalent for x = −5. The original expression is undefined for x = −5, but the simplified expression equals −1 when x = −5.

+   3. Responses will vary. Students should provide a rational function of the form f(x) = p(x) / ((x − a)(x − b)) such that neither (x − a) nor (x − b) are factors of p(x). In this case, x = a and x = b are vertical asymptotes.

+   4. a. x + 4
+      b. x + 15
+      c. C(x) = (x + 4) / (x + 15)
+      d. The horizontal asymptote is C(x) = 1 which represents 100% ammonia. As more and more ammonia is added to the solution, that is, as x grows large (|x| → ∞), the concentration of ammonia approaches 100%.

+   5. a. (8x − 16) / (6x − 2) = (4x − 8) / (4x − 1)
+      b. (4x + 4) / (x + 1) = (4(x + 1)) / (x + 1) = 4
+      c. x(x + 5) / (x(x − 2)) + ((x − 2)(3x + 1)) / (x(x − 2)) = (x² + 5x + 3x² − 5x − 2) / (x(x − 2)) = (4x² − 2) / (x² − 2x)
+      d. 5 / (4(x + 5)) = 5 / (4x + 20)
+      e. 1/2
+      f. 5(x + 5) / (2x) = (5x + 25) / (2x)
