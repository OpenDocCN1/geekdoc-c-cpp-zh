# Robot in the Lab!

Rudy the Robot is loose in the science lab. Help Rudy make a big mess.

To copy our starter code, go to https://scratch.mit.edu/projects/319254293.

This project has five sprites. The lab bench and group of beakers are decorative sprites. We will use layers to keep the sprites in the right order.

# Pro Tip!

Scratch lets you see other people’s projects. You can even copy the code to make them your own. Our code contains the sprites and sounds we will use in this book.
