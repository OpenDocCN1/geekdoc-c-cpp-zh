form, the diffusion equation reads

```
u_t - (P u_x)_x - (Q u_y)_y + K u = F,
```

where P, Q, K, and F are given functions of t, x, and y and u ≡ u(t, x, y) is the unknown solution. It is assumed that this equation holds in a given time interval [0, T] and a given domain Ω in the Cartesian (x, y)-plane. It is also assumed that initial conditions that specify u at the initial time t = 0 are given and that boundary conditions that specify u or u_n (the directional derivative of u in the direction that is normal to the boundary and points toward the outside of the domain) are also given at the boundary ∂Ω.

In many realistic applications, the time-dependent process represented by u(t, x, y) converges as t → ∞ to a stable equilibrium state or stagnation state or steady state. Clearly, in the steady state, u_t ≡ 0, because u no longer changes in time. Thus, u is actually a function of the spatial variables x and y only: u ≡ u(x, y). In this case, the given functions P, Q, K, and F take their limit values as t → ∞ (if these limits indeed exist), so they are also functions of x and y only. Thus, the diffusion equation takes the form

```
−(P u_x)_x − (Q u_y)_y + K u = F,   (x, y) ∈ Ω.
```

where P, Q, K, F, and the unknown u are functions in Ω. This PDE is accompanied by the boundary conditions

```
u = G,    (x, y) ∈ Γ₀,
α u + P u_x n₁ + Q u_y n₂ = G,    (x, y) ∈ Γ.
```

Here,

+   Γ₀ is the subset of the boundary ∂Ω where Dirichlet boundary conditions are imposed:

+   Γ = ∂Ω \ Γ₀ is the remainder of the boundary ∂Ω, where mixed boundary conditions are imposed;

+   G is a given function on ∂Ω;

+   α is a given function on Γ; and

+   (n₁, n₂) is the outer normal vector to Ω; that is, it is a unit vector (n₁² + n₂² = 1), is normal to Γ (makes a right angle with the tangent to Γ), and points toward the outside of Ω.

We refer to this problem as the diffusion problem in Ω. In fact, this problem arises not only in the steady state of time-dependent problems but also in implicit and semi-implicit time-marching schemes for the numerical solution of time-dependent problems.

# 11.2 The Weak Formulation

In the convection-diffusion equation in Chapter 7, Section 13, the diffusion coefficient is the constant ε, so the finite-difference scheme is suitable. For problems with variable coefficients, on the other hand, this scheme may no longer be accurate. In particular, when the coefficients are discontinuous, the solution u(x, y) may have no continuous derivatives.
