Consider, for example, a complex organic molecule, which may be of particular interest in organic chemistry or microbiology [80]. The complete structure of the molecule can be written in terms of parameters that define it uniquely, such as the Cartesian location of the atoms in it or the distances between every two atoms in it.

Discovering these parameters can again be formulated in terms of an inverse problem. Indeed, each arbitrary choice of values of parameters determines the domain in a different way. For each such domain, the nonlinear Helmholtz or Maxwell equation can be solved numerically, and the numerical data can be compared to some observed data available in advance. The correct choice for the parameters, or the correct structure of molecule, is the one for which the numerical data agree with the observed data with minimal errors.

The Gauss–Newton iterative method in [37] to solve such an inverse problem requires again the numerical solution of the PDE in each iteration. In [37], however, multigrid is used for diffusion problems only, not for more complicated problems such as the Maxwell system. Fortunately, here one can use the present adaptive-refinement and multigrid algorithms not only for diffusion problems but also for (nonlinear) Helmholtz and Maxwell equations, to come up with an efficient (object-oriented) implementation of the numerical microscope.

# 30.7 Oil and Mining Exploration

The present approach can be used to discover not only potentially harmful substances such as the pollution in a cloud in the atmosphere but also potentially valuable substances such as oil, natural gas, and other mining in deep soil or sea. Rather than only one parameter that is optimized above, here a few different parameters can be used to stand for the concentration of substances at a few different locations of particular interest. Discovering these concentrations can indeed be formulated as an inverse problem.

The Gauss–Newton iterative method in [37] can be used to solve this inverse problem. In each iteration, the current approximate parameters are used to form the Maxwell system, which is then solved numerically. By comparing the numerical results to some preliminary observed data, one then decides how to improve the current approximate parameters and use them to form a yet more realistic Maxwell system in the next iteration, and so on. The values of parameters obtained at the last iteration are then accepted as the true values, and are then used to estimate the amount of valuable substance in the ground or ocean.
