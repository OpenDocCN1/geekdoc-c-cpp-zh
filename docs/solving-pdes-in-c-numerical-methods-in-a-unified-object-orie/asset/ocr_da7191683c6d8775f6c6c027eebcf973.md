# 27.2 The Stiffness Matrix

Let M be a mesh of tetrahedra that approximates the original domain Ω. Here we define the stiffness matrix A^(s) obtained from the linear finite-element discretization over M.

It is easy to see that the volume of the reference tetrahedron T is 1/6. (See exercises at the end of Chapter 24.) Define the following polynomials of three variables:

P_{k,t}(x,y,z) = 1 − x − y − z
P_{l,t}(x,y,z) = x
P_{m,t}(x,y,z) = y
P_{n,t}(x,y,z) = z.

Furthermore, define the constant three-dimensional vectors (the gradients of these polynomials) by

g_{k,t} = ∇P_{k,t} = ⎛ −1 ⎞
                     ⎜ −1 ⎟
                     ⎝ −1 ⎠
g_{l,t} = ∇P_{l,t} = ⎛ 1 ⎞
                     ⎜ 0 ⎟
                     ⎝ 0 ⎠
g_{m,t} = ∇P_{m,t} = ⎛ 0 ⎞
                     ⎜ 1 ⎟
                     ⎝ 0 ⎠
g_{n,t} = ∇P_{n,t} = ⎛ 0 ⎞
                     ⎜ 0 ⎟
                     ⎝ 1 ⎠.

The (i⃗, j⃗)th matrix element in A^(s) that couples the nodes i⃗ and j⃗ to each other is defined by

A_{i⃗,j⃗}^{(s)} ≡ Σ_{t∈M, i⃗,j⃗∈t} |det(S_t)| g_{j,t}^T S_t^{-1} S_t^{-T} g_{i,t} ∫∫∫_T dx dy dz
= 1/6 Σ_{t∈M, i⃗,j⃗∈t} |det(S_t)| g_{j,t}^T S_t^{-1} S_t^{-T} g_{i,t},

where g_{j,t}^T is the row vector that is the transpose of the column vector g_{j,t}, and S_t^{-T} is the transpose of the inverse of the 3 × 3 matrix S_t. To complete the definition of the stiffness matrix, we still need to add the contributions from the boundary conditions.
