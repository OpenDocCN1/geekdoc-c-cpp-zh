A color is a maximal subset of unknowns that are decoupled from each other in the coefficient matrix A. In other words, the unknowns i and j can both belong to the same color only if A_{i,j} = A_{j,i} = 0. Furthermore, the color is maximal in the sense that no extra unknown can be added to it without violating the above condition. In other words, an unknown k doesn’t belong to the color only if there exists at least one unknown l that already belongs to the color and for which A_{k,l} ≠ 0 or A_{l,k} ≠ 0.

Finding a coloring with the minimal possible number of colors is a too difficult task: in fact, it is an NP-complete problem. Still, a rather good coloring algorithm with a fairly small number of colors is implemented in Section 20.15 in [69].

In each color, the unknowns can be relaxed simultaneously in parallel. Thus, the reordered Gauss–Seidel relaxation in which the relaxation is made color by color is fairly parallelizable.

Still, the multigrid V-cycle in Figure 17.1 is inherently sequential in terms of levels: a level cannot be relaxed until the previous level has been relaxed. This is true in the first leg on the left, in which a level cannot be relaxed until the finer levels have been relaxed, as well as in the second leg on the right, in which a level cannot be relaxed until the coarser levels have been relaxed. The situation is a little better in a V(0,1)-cycle, in which the first leg is missing. Still, the right leg requires an inherently sequential loop from the coarsest level to the finest level.

To fix this problem, it is suggested in [48] to replace the standard V-cycle by the so-called AFACx cycle. In this cycle, all the levels are relaxed simultaneously, and not before a correction term is added to each of them from the next coarser level. These correction terms, however, are independent of each other, and hence can also be calculated simultaneously in parallel. In fact, on each such coarse level, the residual equation restricted from the next finer level is not solved for but merely relaxed upon, requiring no data from any coarser level.

It turns out that, although this correction term fails to approximate the solution to the original problem, it still does approximate well its fine features, and hence supplies a sufficiently good correction term for the previous finer level. Once this correction term is prolonged back to this finer level, the fine-level relaxation can be carried out independently of any other level. The detailed AFACx cycle is described in Section 13.3 in [68].

The AFACx cycle requires somewhat more computation work than the standard V-cycle, because the coarse-level relaxation is used only to supply the correction term for the previous finer level, and is dropped soon after. Furthermore, it requires about twice as many iterations to converge (at least when no outer acceleration is used). Still, this may be worthwhile when parallel implementation is considered. Indeed, because all the levels are relaxed independently of each other, an efficient load-balancing algorithm [48] can be used to provide an efficient parallel C++ implementation.
