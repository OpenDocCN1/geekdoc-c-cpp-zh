The following function uses the above "lastOne()" function and the constructor that takes a "number" argument to drop meaningless leading zeroes from the "number" object 'n' that is passed to it by reference:

The above "add()" function is now used to implement the standard algorithm to multiply two numbers:

```
const number
operator*(const number& n, const number&k){
    number nk(n.length()+k.length(),0);
    for(int i=0; i<k.length(); i++)
        if(k[i])
            add(nk,n,i,i+n.length());
    return dropLeadingZeroes(nk);
} // n times k
```

Note that meaningless leading zeroes are dropped from the product "nk" before it is returned. Alternatively, the multiplication of two long natural numbers could also be implemented using the fast Fourier transform (FFT) and convolution. This might reduce the time complexity from O(log² n) to O((log n)log(log n)).

Similarly, the above "subtract()" function is used to implement the standard algorithm to divide 'n' by 'k':

```
const number
operator/(number n, const number&k){
    int len = n.length()-k.length();
    if(geq(n,k,len,n.length()))
        len++;
    number result(len,0);
    for(int i=len-1; i>=0; i--){
        if(geq(n,k,i,i+k.length())){
            result(i) = 1;
            subtract(n,k,i,i+k.length());
        }
        else
            result(i) = 0;
    }
    return dropLeadingZeroes(result);
} // divide n by k
```

Note that, since 'n' is passed by value rather than by reference, changes that are made to it throughout the function are not saved.

The same algorithm is also used in the "%=" operator below to calculate 'n' modulus 'k' and store the result in 'n'. The only change is that here the result of the division of 'n' by 'k' is not needed, so it is not calculated:

Let us now define some logical operators. The above "equal()" function is used in the following "==" operator to check whether two given numbers are equal to each other or not:

```
bool operator==(const number& n,const number& k) {
    return n.length() >= k.length() ?
        equal(n,k,0,k.length())
        :
            equal(k,n,0,n.length());
} // check if n is equal to k
```

Similarly, the above "geq()" function is used in the following ">=" operator to check whether the first argument is indeed greater than or equal to the second number or not:

```
bool operator>=(const number& n,const number& k) {
    return n.length() >= k.length() ?
        geq(n,k,0,k.length())
        :
            (n==k) | !geq(k,n,0,n.length());
} // check if n is greater than or equal to k
```

Moreover, the above "==" operator can also be used to check whether two given numbers are different from each other or not:

```
bool operator!=(const number& n,const number& k) {
    return !(n==k);
} // check if n is not equal to k
```
