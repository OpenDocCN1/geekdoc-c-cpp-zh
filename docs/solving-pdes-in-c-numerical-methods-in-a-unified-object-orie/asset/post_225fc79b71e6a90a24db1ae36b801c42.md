
Consider, for example, a complex organic molecule, which may be of particular interest in organic chemistry or microbiology [80]. The complete structure of the molecule can be written in terms of parameters that define it uniquely, such as the Cartesian location of the atoms in it or the distances between every two atoms in it.

Discovering these parameters can again be formulated in terms of an inverse problem. Indeed, each arbitrary choice of values of parameters determines the domain in a different way. For each such domain, the nonlinear Helmholtz or Maxwell equation can be solved numerically, and the numerical data can be compared to some observed data available in advance. The correct choice for the parameters, or the correct structure of molecule, is the one for which the numerical data agree with the observed data with minimal errors.

The Gauss–Newton iterative method in [37] to solve such an inverse problem requires again the numerical solution of the PDE in each iteration. In [37], however, multigrid is used for diffusion problems only, not for more complicated problems such as the Maxwell system. Fortunately, here one can use the present adaptive-refinement and multigrid algorithms not only for diffusion problems but also for (nonlinear) Helmholtz and Maxwell equations, to come up with an efficient (object-oriented) implementation of the numerical microscope.

## 30.7 Oil and Mining Exploration

The present approach can be used to discover not only potentially harmful substances such as the pollution in a cloud in the atmosphere but also potentially valuable substances such as oil, natural gas, and other mining in deep soil or sea. Rather than only one parameter that is optimized above, here a few different parameters can be used to stand for the concentration of substances at a few different locations of particular interest. Discovering these concentrations can indeed be formulated as an inverse problem.

The Gauss–Newton iterative method in [37] can be used to solve this inverse problem. In each iteration, the current approximate parameters are used to form the Maxwell system, which is then solved numerically. By comparing the numerical results to some preliminary observed data, one then decides how to improve the current approximate parameters and use them to form a yet more realistic Maxwell system in the next iteration, and so on. The values of parameters obtained at the last iteration are then accepted as the true values, and are then used to estimate the amount of valuable substance in the ground or ocean.

## 30.8 The Mathematical Formulation

Let us consider a more general mathematical formulation of the inverse problem. Assume that the stiffness matrix

```
A ≡ (a_{i,j})_{1 ≤ i,j ≤ N}
```

is a smooth function of an unknown scalar e, so that both the first derivative

```
A' ≡ A'_e(e) ≡ (a'_{i,j})_{1 ≤ i,j ≤ N}
```

and the second derivative

```
A'' ≡ A''_e(e) ≡ (a''_{i,j})_{1 ≤ i,j ≤ N}
```

For example, the tensor product of the N × N matrices A and A′ produces the tensor

(A ⊗ A′)i,j,k,l ≡ ai,j a′k,l.

Furthermore, the tensor-matrix product is the analogue of the matrix-vector product. More precisely, just as the matrix-vector product produces a vector, the tensor-matrix product produces a matrix. For example,

(SA′)i,j ≡ Σk,l=1N Si,j,k,l a′k,l.

If, however, the original tensor is of six indices, then the tensor-matrix product produces a four-index tensor. For example,

(RA′)i,j,k,l ≡ Σm,n=1N Ri,j,k,l,m,n a′m,n.

There are a few possible ways to define the transpose of a tensor. In this discussion we use the following nonstandard definitions:

Ri,j,k,l,m,n^t ≡ Ri,j,m,n,k,l

and

Si,j,k,l^t ≡ Sj,i,k,l.

Note that, with the above definition, we have

S^t A′ = (SA′)^t.

We are now ready to reformulate the inverse problem in a concrete mathematical setting.

## 30.10 The Minimization Problem

The inverse problem is thus to minimize b, or to find a scalar e for which

b′(e) = 0.

To make this formula more explicit, let us use the chain rule (Sections 10.11, 12.5, and 28.5). In fact, the chain rule is used twice: the first time, to derive b:

b′ = ∇c w′ = w′ w′;

and the second time, to derive w:

w′ = ((∂A⁻¹/∂A) A′)(∂w(A⁻¹)/∂A⁻¹) = ((∂A⁻¹/∂A) A′) f.

where

(∂A⁻¹/∂A)i,j,k,l ≡ ∂Ai,j⁻¹/∂ak,l

is the Jacobian tensor that linearizes the inverse operator A⁻¹(A).

To have a more explicit formulation of this Jacobian, let us use Cramer’s rule and the definition of minor in Section 3.15. Recall that the minor A^{[i,j]} is obtained from the original matrix A by dropping the jth row and the ith column. Furthermore, let

|A| = det(A)

denote the determinant of the matrix A. From Cramer’s rule, the partial derivative of |A| with respect to a_{k,l} (or the (k,l)th component in the gradient of |A|) is

(∂|A|/∂A)_{k,l} ≡ ∂|A|/∂a_{k,l} = (-1)^{k+l} |A^{[k,l]}| = |A| A^{-1}_{l,k}.

This can be written more compactly as

∂|A|/∂A = |A| A^{-T}.

Using the chain rule once again, we have

∂|A|^{-1}/∂A = d|A|^{-1}/d|A| · ∂|A|/∂A = -|A|^{-2}|A| A^{-T} = -|A|^{-1} A^{-T}.

This formula will be particularly helpful below.

To form the required Jacobian, we also need to define the tensor S as follows. If k = j or l = i, then

S_{i,j,k,l} = 0.

If, on the other hand, k ≠ j and l ≠ i, then S_{i,j,k,l} is defined from a minor of a minor of A, obtained by dropping both the jth and kth rows and both the ith and lth columns from the original matrix A. More precisely, it is assumed that S is skew-symmetric under the index permutation j ↔ k or i ↔ l:

S_{i,j,k,l} = -S_{i,k,j,l} = -S_{l,j,k,i} = S_{l,k,j,i}.

Therefore, without loss of generality, we may assume that

j > k and i > l.

In this case, S_{i,j,k,l} is defined by

S_{i,j,k,l} ≡ |A|^{-1} (-1)^{i+j+k+l} |(A^{[j,i]})^{[k,l]}| = (-1)^{i+j}|A|^{-1}|A^{[j,i]}| (-1)^{k+l}|A^{[j,i]}|^{-1}|(A^{[j,i]})^{[k,l]}| = A^{-1}_{i,j} (A^{[j,i]})^{-1}_{l,k}.

If, on the other hand, k > j, then one can still modify the above definition and revise its right-hand sides by replacing k by k − 1 to account for the row indexing in A^{[i,j]} that is

different from the original row indexing in A due to the missing jth row. Alternatively, one could use the skew-symmetry discussed above to define

S_{i,k,j,l} ≡ −S_{i,j,k,l}.

Similarly, if l > i, then one can still modify the above definition and revise its right-hand sides by replacing l by l − 1 to account for the original ith column in A that is missing in A^{[j,i]}. Alternatively, one could use the skew-symmetry to define

S_{i,j,k,i} ≡ −S_{i,j,k,l}.

We are now ready to calculate a particular element in the required Jacobian of the inverse operator A^{−1}(A):

∂A_{i,j}^{−1}/∂a_{k,l} = (−1)^{i+j} ∂(|A^{[j,i]}|/|A|)/∂a_{k,l}
= (−1)^{i+j}|A|^{−1} ∂|A^{[j,i]}|/∂a_{k,l} + (−1)^{i+j}|A^{[j,i]}| ∂|A|^{−1}/∂a_{k,l}
= S_{i,j,k,l} − A_{i,j}^{−1} A_{k,l}^{−1}.

This can be written more compactly as

∂A^{−1}/∂A = S − A^{−1} ⊗ A^{−t}.

## 30.11 Newton’s Iteration

To use Newton’s iteration (Section 9.12) to solve the nonlinear equation b′(e)=0 for e, we need the second derivative b″(e) as well. To calculate this derivative, we first define the tensor R of six indices as follows. If k = j or m = j or m = k or l = i or n = i or n = l, then

R_{i,j,k,l,m,n}=0.

Otherwise, the corresponding element in R is defined as follows. Assume that R is skew-symmetric under index permutations such as j ↔ k, k ↔ m, i ↔ l, or l ↔ n:

R_{i,j,k,l,m,n}=−R_{i,k,j,l,m,n}=−R_{i,j,m,l,k,n}=−R_{l,j,k,i,m,n}=−R_{i,j,k,n,m,l}.

Clearly, this implies that R is skew-symmetric under index permutations of the form j ↔ m or i ↔ n as well:

R_{i,j,k,l,m,n}=−R_{i,m,k,l,j,n}=−R_{n,j,k,l,m,i}=R_{n,m,k,l,j,i}.

Thus, without loss of generality, we may assume that

j > k > m and i > l > n.

In this case, R_{i,j,k,l,m,n} is defined from a minor of a minor of a minor of A, obtained by dropping the jth, kth, and mth rows and the ith, lth, and nth columns from the original matrix A:
