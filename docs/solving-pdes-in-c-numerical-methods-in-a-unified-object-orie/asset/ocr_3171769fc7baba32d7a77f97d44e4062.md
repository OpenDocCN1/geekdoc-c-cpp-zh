```
const number&
operator%=(number& n, const number&k) {
    int len = n.length() - k.length();
    if (geq(n,k,len,n.length()))
        len++;
    for(int i=len-1; i>=0; i--)
        if(geq(n,k,i,i+k.length()))
            subtract(n,k,i,i+k.length());
    return dropLeadingZeroes(n);
} // mod k
```

The above "%=" operator can also be used in the following "%" operator that doesn’t change its arguments:

```
const number
operator%(const number& n, const number&k) {
    number a(n);
    return a %= k;
} // n mod k
```

Let us now define some logical operators. The above "equal()" function is used in the following "==" operator to check whether two given numbers are equal to each other or not:

```
bool operator==(const number& n,const number& k) {
    return n.length() >= k.length() ?
        equal(n,k,0,k.length())
        :
            equal(k,n,0,n.length());
} // check if n is equal to k
```

Similarly, the above "geq()" function is used in the following ">=" operator to check whether the first argument is indeed greater than or equal to the second number or not:

```
bool operator>=(const number& n,const number& k) {
    return n.length() >= k.length() ?
        geq(n,k,0,k.length())
        :
            (n==k) | !geq(k,n,0,n.length());
} // check if n is greater than or equal to k
```

Moreover, the above "==" operator can also be used to check whether two given numbers are different from each other or not:

```
bool operator!=(const number& n,const number& k) {
    return !(n==k);
} // check if n is not equal to k
```
