# 27.9 Exercises

+   1. Show that the stiffness matrix $A^{(s)}$ defined in Section 27.2 above is symmetric in the sense that
+      $$A^{(s)}_{i,j}=A^{(s)}_{j,i}.$$

+   2. Show that the row sums in $A^{(s)}$ vanish:
+      $$\sum_i A^{(s)}_{i,j}=0.$$

+   3. Conclude that the column sums in $A^{(s)}$ vanish as well:
+      $$\sum_j A^{(s)}_{i,j}=0.$$

+   4. Let $w$ be the constant grid function:
+      $$w_i \equiv C,\quad i\in N,$$
+      for some constant number $C$. Show that
+      $$A^{(s)}w=0.$$

+   5. Conclude that $A^{(s)}$ is singular.

+   6. Conclude that
+      $$\det(A^{(s)})=0.$$

+   7. Show that all the elements in the boundary matrix $A^{(b)}$ are nonnegative.

+   8. Show that the boundary matrix $A^{(b)}$ is symmetric as well.

+   9. Show that the mass matrix $A^{(m)}$ is symmetric as well.

+   10. Show that all the elements in $A^{(m)}$ are nonnegative.

+   11. Show that the matrix $A^{(n)}(v)$ that is the Jacobian of $f$ at $v$ is symmetric as well.

+   12. Write the constructor that takes the three-dimensional mesh $M$ as an argument and produces the sum of stiffness, boundary, and mass matrices
+      $$A^{(s)}+A^{(b)}+A^{(m)}.$$
