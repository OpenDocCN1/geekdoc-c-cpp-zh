# 30.12 Direct Calculation

Fortunately, the four-index tensor S is used in Sections 30.10 and 30.11 above only to calculate the tensor-matrix products SA′ and SA′′. This gives one the opportunity to avoid the explicit calculation of S.

Let us show how SA′ can indeed be calculated without the explicit calculation of S itself. Let A(k) be the matrix whose rows are the same as in the original matrix A, except of the k th row, which is the same as in A′:

```
A^{(k)}_{p,q} ≡ { a'_{p,q} if p = k, a_{p,q} if p ≠ k. }
```

The determinant of A(k) can then be written as

```
|A^{(k)}| = Σ_{l=1}^{N} (-1)^{k+l} a'_{k,l} |A^{[k,l]}|.
```

Similarly, once the j th row and the i th column are dropped from A(k), we have

```
|(A^{(k)})^{[j,i]}| = Σ_{1≤l≤N, l≠i} (-1)^{k+l} a'_{k,l} |(A^{[j,i]})^{[k,l]}|.
```

Note that this is true if j > k. If, on the other hand, k > j, then k in the above right-hand side should be replaced by k − 1:

```
|(A^{(k)})^{[j,i]}| = Σ_{1≤l≤N, l≠i} (-1)^{k-1+l} a'_{k,l} |(A^{[j,i]})^{[k-1,l]}| = - Σ_{1≤l≤N, l≠i} (-1)^{k+l} a'_{k,l} |(A^{[k,l]})^{[j,i]}|.
```

Still, this makes no difference in the discussion below. For this reason, we keep assuming without loss of generality that j > k.

Using Cramer's rule and the original definition of S in Section 30.10, we therefore have

```
|A^{(k)}| (A^{(k)})^{-1}_{i,j} = (-1)^{i-j} |(A^{(k)})^{[j,i]}| = Σ_{1≤l≤N, l≠i} (-1)^{i+j+k+l} a'_{k,l} |(A^{[j,i]})^{[k,l]}| = |A| Σ_{l=1}^{N} S_{i,j,k,l} a'_{k,l}.
```

This gives an efficient way to calculate the inner sum in the required tensor-matrix product

```
(SA')_{i,j} = Σ_{k=1}^{N} Σ_{l=1}^{N} S_{i,j,k,l} a'_{k,l}.
```
