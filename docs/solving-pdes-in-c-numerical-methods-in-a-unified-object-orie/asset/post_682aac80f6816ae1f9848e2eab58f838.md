
## 5.36 The Fast Fourier Transform

To define FFT, let us first make a few observations.

Assume that $n$ is even. In this case, we have

$$w_n^{n/2} = \exp((2\pi\sqrt{-1} / n)(n/2)) = \exp(\pi\sqrt{-1}) = -1.$$

For this reason, the $i$-th row in the Fourier matrix $W_n$ (for some $0 \le i < n/2$) is related to the row that lies $n/2$ rows ahead by

$$w_n^{(i+n/2)j} = w_n^{ij} w_n^{(n/2)j} = (-1)^j w_n^{ij}.$$

More compactly, the $j$-th column in $W_n$ (for some $0 \le j < n$) can be split into two subvectors that may differ from each other by sign only:

$$
\begin{pmatrix} 
1 \\ 
w_n^j \\ 
w_n^{2j} \\ 
\vdots \\ 
w_n^{(n-1)j} 
\end{pmatrix} 
= 
\begin{pmatrix} 
\begin{pmatrix} 
1 \\ 
w_n^j \\ 
w_n^{2j} \\ 
\vdots \\ 
w_n^{(n/2-1)j} 
\end{pmatrix} \\ 
(-1)^j \begin{pmatrix} 
w_n^j \\ 
w_n^{2j} \\ 
\vdots \\ 
w_n^{(n/2-1)j} 
\end{pmatrix} 
\end{pmatrix}
$$

Let us now see how the Fourier matrix of order $n/2$ is related to the original Fourier matrix of order $n$. For this purpose, note that

$$w_{n/2} = \exp(2\pi\sqrt{-1} / (n/2)) = \exp(4\pi\sqrt{-1} / n) = w_n^2.$$

With this observation, the previous formula takes the form:

If $j$ is even:
$$
\begin{pmatrix} 
1 \\ 
w_n^j \\ 
w_n^{2j} \\ 
\vdots \\ 
w_n^{(n-1)j} 
\end{pmatrix} 
= 
\begin{pmatrix} 
\begin{pmatrix} 
1 \\ 
w_{n/2}^j \\ 
w_{n/2}^{2j} \\ 
\vdots \\ 
w_{n/2}^{(n/2-1)j} 
\end{pmatrix} \\ 
\begin{pmatrix} 
w_{n/2}^j \\ 
w_{n/2}^{2j} \\ 
\vdots \\ 
w_{n/2}^{(n/2-1)j} 
\end{pmatrix} 
\end{pmatrix}
$$

If $j$ is odd:
$$
\begin{pmatrix} 
1 \\ 
w_n^j \\ 
w_n^{2j} \\ 
\vdots \\ 
w_n^{(n-1)j} 
\end{pmatrix} 
= 
\begin{pmatrix} 
\begin{pmatrix} 
1 \\ 
w_{n/2}^{(j-1)/2} \\ 
w_{n/2}^{j-1} \\ 
\vdots 
\end{pmatrix} \\ 
-w_{n/2}^{(j-1)/2} \begin{pmatrix} 
w_{n/2}^{(j-1)/2} \\ 
w_{n/2}^{j-1} \\ 
\vdots 
\end{pmatrix} 
\end{pmatrix}
$$

This allows us to write the Fourier transform of the original order $n$ in terms of the Fourier transform of the reduced order $n/2$. For this purpose, let us split the original vector $f$ into two subvectors of order $n/2$ each: the subvector

$$f^{(e)} \equiv (f_0, f_2, f_4, \dots, f_{n-2})^T$$

that contains the even-numbered components in $f$, and the subvector

$$f^{(o)} \equiv (f_1, f_3, f_5, \dots, f_{n-1})^T$$

that contains the odd-numbered components in $f$. With this splitting, the Fourier transform of $f$ can be written as

$$W_n f = \begin{pmatrix} W_{n/2} f^{(e)} + \mathrm{diag}(1, w_n, w_n^2, \dots, w_n^{n/2-1}) W_{n/2} f^{(o)} \\ W_{n/2} f^{(e)} - \mathrm{diag}(1, w_n, w_n^2, \dots, w_n^{n/2-1}) W_{n/2} f^{(o)} \end{pmatrix}.$$

Assume further that $n$ is a power of 2. In this case, both $W_{n/2} f^{(e)}$ and $W_{n/2} f^{(o)}$ can be computed recursively by suitable applications of $W_{n/4}$, and so on.

This is indeed FFT. It is easy to prove by mathematical induction that the total cost of FFT is $n \log_2 n$ complex multiplications and $n \log_2 n$ complex additions, which for large $n$ is far less than in the original naive algorithm.

We are now ready to implement FFT. The "FFT()" function defined below takes a vector 'f' with components of type 'T' and returns a vector with components of type 'S', where the template parameters 'T' and 'S' are not yet specified. In the actual call to the function, 'S' is usually specified as "complex". Still, we'd like to give the user some more freedom to specify 'T' and 'S' in other ways as well.

How are these template parameters specified? Well, upon being called, the function notices that the vector argument 'f' has components of a certain type. From this time on, the function interprets 'T' to be this type. Furthermore, the function also takes yet another argument, named "type", which is of a certain type that may well be different from 'T'. Upon reading "type", the function interprets 'S' to be the same as the type of "type".

The function "FFT()" also takes an integer argument "inverse" to indicate whether the transform that is applied is the original Fourier transform or its inverse. If "inverse" vanishes, then the original Fourier transform is applied. If, on the other hand, "inverse" = 1, then the inverse transform is applied.

Finally, the function also takes the integer argument "first" to indicate whether this is an outer call or not. If "first" = 1, then a division by $n$ is required in the inverse transform. If, on the other hand, "first" = 0, then this means that this is an inner recursive call that requires no such division. The default value of "first" is 1, so it can be dropped by users of "FFT()":

```cpp
template<class T, class S>
const dynamicVector<S>
FFT(int inverse, const dynamicVector<T>&f,
const S&type, int first=1){
```

If 'f' is a trivial vector with one component only, then this must be the innermost call to "FFT". In this case, the returned vector is the same as 'f', except that its component is converted to type 'S':

```cpp
if(f.dim()==1)

```

Otherwise, f is split into its even and odd subvectors: $f^{(e)}$ is stored in the local vector "even", and $f^{(o)}$ is stored in the local vector "odd":

```cpp
dynamicVector<T> even(f.dim()/2,0.);
dynamicVector<T> odd(f.dim()/2,0.);
for(int i=0; i<f.dim(); i+=2){
    even(i/2) = f[i];
    odd(i/2) = f[i+1];
}
```

The local complex variable 'w' contains $w_n$ (if the original Fourier transform is applied) or $\bar{w}_n$ (if the inverse transform is applied):

```cpp
double angle = 8. * atan(1.) / f.dim();
const complex w(cos(angle),(2*inverse-1) * sin(angle));
```

Recursion is now used to calculate $W_{n/2}f^{(e)}$ (stored in the local vector "Feven") and $W_{n/2}f^{(o)}$ (stored in the local vector "Fodd"):

```cpp
complex wi = 1.;
const dynamicVector<S>
    Feven = FFT(inverse,even,type, 0);
dynamicVector<S>
    Fodd = FFT(inverse,odd,type, 0);
```

Furthermore, "Fodd" is now multiplied from the left by a diagonal matrix that contains the powers of 'w' on its main diagonal:

```cpp
for(int i=0; i<f.dim()/2; i++){
    Fodd(i) *= wi;
    wi *= w;
}
```

Finally, if this is the outer call in the inverse transform, then the returned vector is also divided by $n$:

```cpp
return inverse&&first ?
        (1./f.dim()) * dynamicVector<S>(
        Feven + Fodd,Feven - Fodd)
    :
        dynamicVector<S>(
        Feven + Fodd,Feven - Fodd);
} // FFT
```

## 5.38 Convolution

Let

$$u \equiv (u_0, u_1, u_2, \dots, u_{l-1})^t$$

be an $l$-dimensional vector and

$$v \equiv (v_0, v_1, v_2, \dots, v_{m-1})^t$$

be an $m$-dimensional vector. The convolution of $u$ and $v$ is the $(l + m - 1)$-dimensional vector defined by

$$(u * v)_k \equiv \sum_{0 \le i < l, 0 \le j < m, i + j = k} u_i v_j$$

($0 \le k < l + m - 1$).

Clearly, if $u$ contains the coefficients of the polynomial

$$u(z) \equiv \sum_{i=0}^{l-1} u_i z^i$$

and $v$ contains the coefficients of the polynomial

$$v(z) \equiv \sum_{j=0}^{m-1} v_j z^j$$

then the convolution vector defined above contains the coefficients of the product polynomial $u(z)v(z)$.

Let us now use FFT to calculate the convolution efficiently. To this end, let us first define a simple operator that multiplies two vectors of the same dimension component by component:

```cpp
template<class T>
const dynamicVector<T>
operator|(const dynamicVector<T>&u,
    const dynamicVector<T>&v) {
    dynamicVector<T> uv(u.dim(),0.);
    for(int i=0; i<u.dim(); i++)
        uv(i) = u[i] * v[i];
    return uv;
} // multiply component by component
```

With this operator, one can simply write "u|v" to return the vector whose $i$-th component is the product of the $i$-th component in `u` by the $i$-th component in `v`. This operator is indeed useful in the convolution operator defined next:
