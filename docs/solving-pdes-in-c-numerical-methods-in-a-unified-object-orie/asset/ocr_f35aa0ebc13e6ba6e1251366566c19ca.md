# A.32 Assembling the (Nonlinear) Electricity Equations

The following constructor assembles the coefficient matrix for the electricity equations reduced from the original Maxwell equations in Section 29.12. It is assumed that two external parameters are available: "HELM" is the coefficient of the linear mass term (K in Chapter 25), and "HELMNonlin" is the coefficient of the nonlinear mass term (K₁ in Chapter 25).

The code can be considered as an extension of the code in Section A.28 above.
