The next constructor constructs the binary representation of the integer argument "decimal" that is passed to it by value. For this purpose, the required number of binary digits is calculated in the following loop and stored in the "dimension" field inherited from the base "dynamicVector" class. Indeed, the local integer variable "dec" used in the loop is initialized to "decimal" and then divided iteratively by 2 until the result of this division vanishes:
