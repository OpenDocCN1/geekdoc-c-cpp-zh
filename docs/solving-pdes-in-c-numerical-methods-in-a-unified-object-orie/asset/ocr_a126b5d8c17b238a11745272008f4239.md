This special case is particularly relevant to the second partial derivatives of a composite function defined in t. Indeed, for any function v(x, y, z) with continuous second partial derivatives, ∇∇^T v is a 3 × 3 symmetric matrix. Therefore, ∇∇^T v can also be represented uniquely as the six-dimensional row vector

(v_xx, v_xy, v_yy, v_xz, v_yz, v_zz).
