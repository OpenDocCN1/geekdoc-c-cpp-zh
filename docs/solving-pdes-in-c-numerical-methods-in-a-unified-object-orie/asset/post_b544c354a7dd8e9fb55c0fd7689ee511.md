
(0 ≤ i < 40). Indeed, after this substitution, the functions R_{i,t} (0 ≤ i < 40) have vanishing degrees of freedom at all the edge and side midpoints in t, as required. Furthermore, this substitution makes no change to the original degrees of freedom at the corners, which remain appropriate. Thus, the functions R_{i,t} (0 ≤ i < 40) can now be rightly called corner basis functions.

## 28.12 Degrees of Freedom in the Mesh

So far, we have only indexed the 56 degrees of freedom in a particular tetrahedron t in the mesh. Here we index the degrees of freedom in the entire mesh M. This indexing scheme will be used later to form the stiffness matrix.

Let n_n be the total number of nodes in the mesh M, n_e the total number of edges, and n_s the total number of sides. We are interested here in piecewise polynomial functions in M, that is, functions that are defined in M and whose restriction to each individual tetrahedron t in M is a polynomial of degree five. These polynomials are not necessarily the same: in each individual tetrahedron, the definition of the polynomial might be different, according to the 56 degrees of freedom in this particular tetrahedron. Still, the definitions in the different tetrahedra must match at the common nodes, edges, and sides of adjacent tetrahedra. Therefore, there is no absolute freedom to define the polynomial in a particular tetrahedron completely independently of the definitions in the other tetrahedra: the definition does depend on the definitions in the adjacent tetrahedra. Thus, the total number of degrees of freedom in defining the piecewise polynomial function in the entire mesh is

N ≡ 10n_n + 2n_e + n_s.

N, the total number of degrees of freedom in the entire mesh, will later serve as the order of the stiffness matrix. To assemble this matrix, however, we’ll also need to order the degrees of freedom in the entire mesh in some well-defined order. In other words, we must have an indexing of all the degrees of freedom in the entire mesh. Naturally, this indexing scheme is induced by the indexing schemes of the nodes, edges, and sides in the mesh, which are assumed to be defined arbitrarily in advance.

## 28.13 The Indexing Scheme

For every node i̅ in M, let 0 ≤ |i̅| < n_n denote its index in the list of nodes in the mesh. The 10n_n first degrees of freedom in the mesh are ordered ten by ten as in the list of nodes, with each ten being associated with a particular node.

Furthermore, let 0 ≤ |(i̅, j̅)| < n_e denote the index of the edge leading from i̅ to j̅ in the list of edges in the entire mesh. The next 2n_e degrees of freedom in the mesh are ordered two by two as in the list of edges, with each 2 being associated with a particular edge midpoint.

Moreover, let 0 ≤ |(i̅, j̅, k̅)| < n_s be the index of the side vertexed at i̅, j̅, and k̅ in the list of sides in the entire mesh. The final n_s degrees of freedom in the mesh are ordered as in the order of the sides with which they are associated. This completes the indexing of the N degrees of freedom in the mesh.

For every tetrahedron t ∈ M, let us write

t = (\vec{k}, \vec{l}, \vec{m}, \vec{n}),

where \vec{k}, \vec{l}, \vec{m}, and \vec{n} are the corners of t in some arbitrary order that is determined in advance.

Let us now redefine the indices of the corner basis functions R_{i,t} (0 ≤ i < 40) defined in t to agree with the above indexing scheme in the entire mesh. More precisely, let us introduce new corner basis functions of the form h_{n,t} that differ from the original R_{i,t} ’s only in their index:

We are now ready to define the required basis functions in the mesh, namely, piecewise polynomial functions for which the degrees of freedom in the mesh vanish, except for only one degree of freedom, whose value is 1. Indeed, for each fixed 0 ≤ i ≤ N, the basis function φ_i is defined in M in such a way that its only nonzero degree of freedom in the mesh is the i th one:

φ_i ≡ { h_{i,t} if i ~ t,
0 if i ∤ t
(for every t ∈ M).

Thus, every function f that (a) is continuous in M, (b) is a polynomial of degree five in each individual tetrahedron t ∈ M, (c) has a continuous gradient across the edges and side midpoints in M, and (d) has a continuous Hessian at the nodes in M can be written uniquely as a linear combination of the basis functions in the mesh:

f = \sum_{i=0}^{N-1} f^{(i)} φ_i ,

where f^{(i)} is the i th degree of freedom of f (the value of the corresponding partial derivative of f at the corresponding node, edge midpoint, or side midpoint) in the mesh. Indeed, in each particular tetrahedron t ∈ M, both the left-hand side and the right-hand side of the above equation have the same 56 degrees of freedom, so they must be identical to each other in t. Since this is true for every t ∈ M, they must be identical throughout the entire mesh M as well.

Below we use the basis functions φ_i (0 ≤ i < N) to assemble the N × N stiffness matrix.

## 28.15 The Stiffness Matrix

For 0 ≤ i, j < N, the (i, j)th element in the stiffness matrix A^{(s)} is now defined by

A_{i,j}^{(s)} ≡ ∭_M ∇^t φ_j ∇ φ_i dx dy dz = Σ_{t∈M} ∭_t ∇^t φ_j ∇ φ_i dx dy dz = Σ_{t∈M, i,j∼t} ∭_t ∇^t h_{j,t} ∇ h_{i,t} dx dy dz = Σ_{t∈M, i,j∼t} |det(S_t)| ∭_T ∇^t (h_{j,t} ∘ D_t) S_t^{-1} S_t^{-T} ∇ (h_{i,t} ∘ D_t) dx dy dz.

Note that the functions of the form h_{i,t} ∘ D_t used in the above integral are easily available. Indeed, since h_{i,t} is equal to R_{n,t} for some 0 ≤ n < 56, h_{i,t} ∘ D_t is the same as R_{n,t} ∘ D_t. Furthermore, just as R_{n,t} has been produced from the r_{k,t}'s (0 ≤ k < 56), R_{n,t} ∘ D_t can be calculated directly from the r_{k,t} ∘ D_t's, which are nothing but the original basis functions p_k defined in the reference tetrahedron T in Section 28.2. Thus, all the calculations can be carried out in T only: the original calculation of R_{n,t} ∘ D_t as a linear combination of the r_{k,t} ∘ D_t's, the substitution to make it a proper basis function (using the chain rule to calculate the required degrees of freedom of the form R_{n,t}^{(m,t)} in T only), the re-indexation to form h_{i,t} ∘ D_t, and the derivation and integration of the latter to calculate the contribution from t to the stiffness matrix.

This completes the definition of the stiffness matrix A^{(s)}. The boundary term A^{(b)}, the mass matrix A^{(m)}, and the 2N × 2N matrix A^{(n)}(f) (where f is a 2N-dimensional vector grid function) used in the Newton iteration to solve the nonlinear Helmholtz equation can be defined in a similar way. This is left to the exercises.

## 28.16 The Refinement Step in a Nonlinear Equation

In order to produce the finer mesh on which the PDE can be approximated with a yet greater accuracy, the PDE must first be solved on the current (coarse) mesh, to indicate over which edges the discrete (coarse) solution has a large variation (jump). These edges are then refined or divided to produce the next finer mesh. This is the refinement step.

In order to solve the discrete problem on the coarse mesh, an inner Newton iteration should be used. To start this iteration, however, one must have a proper initial guess. Naturally, this initial guess can be prolonged from the discrete solution computed before on the previous coarser mesh.

This prolongation, however, is not trivial. If the multigrid version in Section 17.15 or 17.16 is used, then one may use the prolongation operator available within the multigrid V-cycle. Still, this is a "local" prolongation that gives the prolonged value at a particular fine-grid point in terms of its neighbor coarse-grid points only. The resulting initial guess on the current mesh thus may not be sufficiently close to the required solution, so the inner Newton iteration may fail to converge to it.
