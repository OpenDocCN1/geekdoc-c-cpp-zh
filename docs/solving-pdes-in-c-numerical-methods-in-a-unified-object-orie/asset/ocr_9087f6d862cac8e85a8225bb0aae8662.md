# 29.2 Dirichlet Boundary Condition as a Constraint

The Dirichlet boundary conditions that are imposed on the original PDE can be viewed as an external constraint imposed on the minimization problem in Figure 29.1. If, for example, the Dirichlet boundary condition is imposed at the point a in the domain in which the function v is defined, then it takes the form of the linear constraint equation

```
L(v) ≡ v(a) = specified value.
```

Thanks to the linearity of the functional L, every level set of the form

```
{v | L(v) = const.}
```
