# Figure 25.2. The case in which the vector p contains two Fourier modes: the nearly singular mode c^{(l)}, whose eigenvalue λ_l is minimal in magnitude, and the mode c^{(l+2)}, whose eigenvalue λ_{l+2} is bounded from below in magnitude by the size of the horizontal line in the picture.

![](bbox=[0.32, 0.42, 0.68, 0.55])

Thus, the above sum must contain at least two different modes to cancel the first and last components in Ap. In fact, to have a minimal ||Ap||, p must be of the form

```
p = α_l c^{(l)} − α_l c^{(l±2)}.
```

Here, the expression l ± 2 is interpreted as l + 2 if l < 2 or if |λ_{l+2}| ≤ |λ_{l-2}|, and as l − 2 otherwise. (Note that l ± 1 cannot be used instead of l ± 2, because (Ap)_{N-1} must be small as well.) In either case, we have (see Figures 25.1 and 25.2)

```
|λ_{l±2}| ≥ π² |(l ± 2)² − [(l ± 1)² + l²]/2|.
```

Now, the right-hand side is equal to π²|7/2 ± 3l| (where the minus sign can be used only for l ≥ 2), which is minimal at l = 2, so we have

```
|λ_{l±2}| ≥ π² |(l ± 2)² − [(l ± 1)² + l²]/2| ≥ π² 5/2.
```

Furthermore, when l ≥ 2, one can use the inequality

```
π² l² ≥ −ℜ K / 2
```
