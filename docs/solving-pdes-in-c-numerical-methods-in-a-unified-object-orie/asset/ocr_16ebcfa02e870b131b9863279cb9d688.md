# 5.12 Derivatives of a Product

In this section, we show why it is particularly important to have the opportunity to store the list of derivatives as an object. For this purpose, we present a function that takes list arguments and combines all the items in them in the calculation. This function will be particularly useful in the long-memory process in Chapter 6, Section 14.

Assume that the derivatives of the functions f(x) and g(x) at a given point x up to and including order n are available. Compute the nth derivative of the product fg at x, denoted by

```
(fg)^(n)(x).
```

Note that this quantity has the same algebraic structure as Newton’s binomial:

```
(f + g)^n = Σ_{i=0}^n (n choose i) f^i g^{n-i}.
```

The only difference is that here the sum is replaced by a product, and the power is replaced by a derivative. Therefore, we have the formula

```
(fg)^(n) = Σ_{i=0}^n (n choose i) f^{(i)} g^{(n-i)}
```

at the given point x.
