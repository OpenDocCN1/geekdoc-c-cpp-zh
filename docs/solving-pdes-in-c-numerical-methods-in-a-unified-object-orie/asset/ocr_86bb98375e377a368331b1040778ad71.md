There is, however, one more subtle difference between the present problem and standard denoising: the noise is assumed to be normal to the surface [41]. Therefore, the correction term in each Newton iteration must be projected onto the vector normal to the surface before being added to the previous approximation. If, for example, $j^{(i)}$ denotes the approximation to node $j$ in the $i$th mesh produced at the $i$th Newton iteration, then the vector normal to the surface at $j^{(i)}$ can be approximated by

$\vec{n}_j^{(i)} \equiv \sum_{k^{(i)} \text{ and } l^{(i)} \text{ are connected to } j^{(i)} \text{ in the } i\text{th mesh}} \left(k^{(i)} - j^{(i)}\right) \times \left(l^{(i)} - j^{(i)}\right)$

or

$\vec{n}_j^{(i)} \equiv \sum_{k^{(i)} \text{ and } l^{(i)} \text{ are connected to } j^{(i)} \text{ in the } i\text{th mesh}} \frac{\left(k^{(i)} - j^{(i)}\right) \times \left(l^{(i)} - j^{(i)}\right)}{\left\|\left(k^{(i)} - j^{(i)}\right) \times \left(l^{(i)} - j^{(i)}\right)\right\|_2}$

where ‘×’ stands for the vector product in three dimensions (see Sections 9.25 and 28.10 in [69]). Furthermore, $\vec{n}_j^{(i)}$ can be normalized to be a unit vector:

$\vec{n}_j^{(i)} \leftarrow \vec{n}_j^{(i)} / \|\vec{n}_j^{(i)}\|_2.$

Now, once the $(i+1)$st Newton iteration is computed as in Section 10.7, it is modified by

$j^{(i+1)} \leftarrow j^{(i)} + \left(\left(j^{(i+1)} - j^{(i)}\right)^T \vec{n}_j^{(i)}\right) \vec{n}_j^{(i)}$,

so the correction term has no component that is tangent to the surface. Once this is done for every node $j^{(i)}$ in the $i$th mesh, the $(i+1)$st mesh is complete, and the process is ready to proceed to the next iteration. This procedure is repeated until a sufficiently good approximation is obtained for every node $j$ and indeed for the entire mesh that lies on the required surface.

Since one is only interested in denoising the normal component, a more efficient algorithm could actually be used. This algorithm avoids denoising the vector function $j$, and denoises its normal component only. For this, it applies the Newton iteration to a scalar nonlinear diffusion equation as in Section 10.3 above. More precisely, at the $i$th Newton iteration, one solves for the scalar unknown function

$u \equiv u(j^{(i)}) \equiv \left(j^{(i+1)} - j^{(i)}\right)^T \vec{n}_j^{(i)}$

in the $i$th mesh. As before, the $x$- and $y$-partial derivatives in the scalar diffusion equation in Section 10.3 are interpreted as the directional derivatives in the directions tangent to the relevant triangle in the $i$th mesh. At the end of the $i$th iteration, the improved approximation to node $j$ is defined by

$j^{(i+1)} \equiv j^{(i)} + u(j^{(i)}) \vec{n}_j^{(i)}$,

to form the entire $(i+1)$st mesh and proceed to the $(i+1)$st iteration. This algorithm is more in the spirit of the algorithm introduced in [41].

In either of these algorithms, the diffusion operator must be rediscretized in each iteration on the unstructured mesh associated with it. As we’ll see in the next part of the book, object-oriented C++ programming is particularly suitable for this kind of discretization.
