Furthermore, let e ≥ 5 be a small coprime of φ (see Section 5.21). Now, let m be a message, that is, an integer number smaller than p that should be sent secretly to the decoder. Since both n and e are available publicly, the "powerMod" function in Section 5.22 can be used by the sender to calculate the coded message

c = m^e mod n.

To decode the coded message c, the decoder must also have another secret number d, the inverse of e modulus φ:

d ≡ e⁻¹ mod φ.

Thanks to the fact that e and φ are coprime, d indeed exists uniquely and can be calculated using the "invertMod" function in Section 5.22. Fortunately, this can be done by the decoder only, who has φ available.

From Fermat’s little theorem introduced below, it follows that

m^φ = (m^{p-1})^{q-1} = 1 + J q
m^φ = (m^{q-1})^{p-1} = 1 + L p

for some nonnegative integers J and L satisfying J q = L p. Since both p and q are prime, p must divide J as well, implying that J q = J' p q = J' n for some nonnegative integer J'. This means that

m^φ ≡ 1 mod n

as well.

Thus, the decoder is the only one who can use d in the "powerMod" function in Section 5.22 to recover the original message m as follows:

c^d mod n = (m^e)^d mod n = m^{ed} mod n = m m^{K φ} mod n = m.

where K is some nonnegative integer. This completes the definition of the RSA algorithm.

The following program implements the RSA algorithm. This implementation uses variables of type "long int", which may contain integer numbers of order 10^9. In particular, p, q, and m (as well as the external variable N) must be of order 10^4 to make sure that n, φ, d, and the coded message c (including the local temporary variables used in the recursive calls in the "powerMod" function that produces it) do not exceed 10^9.

```
int main(){
    long int p,q,n,phi,e,d,m,c;
    printf("q=%d\n",q = findPrime(N-1));
    printf("p=%d\n",p = findPrime(q-1));
    printf("n=%d\n",n = p * q);
    printf("phi=%d\n",phi = (p - 1) * (q - 1));
    printf("e=%d\n",e = coprime(phi));
    printf("d=%d\n",d = invertMod(e,phi));
    printf("ed mod phi=%d\n",e * d % phi);
    m = p-1;
    printf("m=%d\n",m);
```
