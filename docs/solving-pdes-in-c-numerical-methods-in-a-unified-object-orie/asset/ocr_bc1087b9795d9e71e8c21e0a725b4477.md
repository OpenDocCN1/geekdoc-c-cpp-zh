Traditional education approaches focus on giving bottom-line information and implementing practical tools. Such approaches, however, may lead to a too disciplined way of thinking, and block any natural curiosity or creativity.

More modern education approaches, on the other hand, attempt to stimulate the pupil’s imagination in the context of general human culture and the process in which it has developed. In these approaches, education should be based not only on well-prepared information but also on raw material to allow the pupil some room for playing, experimenting, exploring, and developing his/her own way around. This way, the pupil is likely to develop his/her own free language that may lead him/her to new discoveries or any original work.

Thus, the key to developing skills for productive work is not necessarily technical information or background but rather high language. The high level of abstraction used in high language may give one the tools required to enrich his/her vocabulary further and to develop new ideas and theories.

# 4.24 Language and Education—Rousseau’s Theory

This is why education mustn’t be too strict: it must leave sufficient room for free personal development. Still, the pupil must receive at least the minimal information required to improve his/her own language. This can be obtained by a lot of free, well-balanced reading.

Jean-Jacques Rousseau, the prophet of education, was opposed even to this kind of reading. In fact, Rousseau said that the child should only talk to his/her mentor to learn about real freedom and liberty, and read nothing until he/she is 15 years old. Only at this age is the child ready to read his/her first book—Robinson Crusoe by Daniel Defoe—to obtain the sense of a man who lives completely alone and is therefore completely free from any external influence or any law imposed by society.

The ideal form of education proposed by Rousseau is probably too strict. In fact, free, well-balanced reading of all kinds of prose, poetry, fiction, and nonfiction may enrich the child’s language to allow development of the abstract part of his/her mind.

As discussed below, this is true not only in natural human languages but also in formal mathematical languages. The key factor in object-oriented programming, in particular, is to allow the programmer to constantly enrich his/her own programming language with more and more abstract objects so as to be able to implement advanced mathematical objects and algorithms.

# 4.25 Object-Oriented Programming Language

C may be considered as a process-oriented programming language. Indeed, the basic element in C is the process or function (with one or more input arguments), which calculates and produces the required output. In fact, every command in C is actually a function, which also returns a value.

The input data used in processes in C are not considered an integral part of the process. In fact, the process can be defined before the data have been specified. For example, functions can be defined with dummy arguments, to be given concrete values only when the function is actually called. In fact, when the function is compiled, a finite state machine (automaton) is created, and each dummy argument is represented by an input line, to be filled by a concrete argument later on when the function is actually called.
