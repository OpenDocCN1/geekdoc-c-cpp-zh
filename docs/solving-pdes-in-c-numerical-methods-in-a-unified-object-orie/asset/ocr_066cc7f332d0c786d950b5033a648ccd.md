Clearly, the linear (partial) differential operator $f'(u^{(i)})$ has to be recalculated (and rediscretized) in each iteration. Fortunately, it doesn’t have to be inverted explicitly but only implicitly. For this purpose, however, one must assume that it is nonsingular (invertible). In other words, the PDE that uses it in the left-hand side must be well posed in the sense that it has a unique solution. Fortunately, this is indeed the case in most relevant problems, as discussed in Sections 11.3–11.6, 20.5, 21.4, and 29.1.
