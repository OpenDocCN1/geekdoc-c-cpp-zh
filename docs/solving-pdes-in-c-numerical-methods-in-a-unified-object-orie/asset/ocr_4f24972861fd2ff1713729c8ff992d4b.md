the aim is to discover the correct depth of the slit. As we’ve seen above, a sufficiently accurate approximation to the true depth of slit can be obtained iteratively. Indeed, the golden-ratio iteration can be used to minimize the error function defined as the absolute value of the difference between the numerical solution and the observed solution at some boundary point away from the slit. The depth of slit for which this error is minimized is then accepted as the true depth of slit.

The same approach can also be used to discover the true values of other parameters that are important in practical applications. In Section 6.15, for example, an inverse problem as in Section 30.1 is solved to find the parameter a0, which is just one of the initial conditions for the ODE considered there. In this application, no observed datum is needed: the optimal a0 is the derivative at the initial time r = 0 for which the solution remains bounded for as long as possible.

Another parameter of practical interest that can be found by solving an inverse problem is the concentration of pollution in a cloud in the atmosphere. Unlike in Section 30.2 above, this inverse problem is aimed not at discovering the domain, which is this time completely available in advance in terms of the shape of the cloud, but rather at measuring the pollution only. Indeed, since the pollution affects the (nonlinear Helmholtz) PDE, finding it may be formulated in terms of an inverse problem as well.

Thus, the golden-ratio iteration in Section 1.20 can be used in this case as well. In the first iteration, an initial guess is used to approximate the concentration of pollution poorly. This poor guess is used to formulate the nonlinear Helmholtz equation in the cloud in the initial iteration only. It is assumed that a laser beam is sent towards the cloud from a satellite that lies just above the cloud. This beam is returned to the satellite to be measured and supply the required observed data.

The error function is then defined as the absolute value of the difference between this measurement of the true returned beam and the numerical value of the numerical returned beam obtained from the numerical solution of the nonlinear Helmholtz equation with the current (rather poor) approximation of the concentration of pollution. In each iteration, this approximation is improved, yielding a more accurate nonlinear Helmholtz equation to be solved in the next iteration, and so on. The resulting golden-ratio iteration converges to a sufficiently accurate concentration of pollution, for which the numerical returned beam calculated from the numerical solution of the PDE agrees with the true returned beam with a sufficiently small error. This final approximation to the concentration of pollution is then accepted as the true concentration of pollution.

Clearly, in each iteration, a nonlinear Helmholtz equation should be solved in the cloud. Fortunately, this can be done rather efficiently using the present adaptive-refinement and multigrid algorithms, implemented in the present object-oriented framework.

# 30.6 Numerical Microscope

As we’ve seen above, the problem of measuring the depth of a slit in Section 22.7 can be formulated as an inverse problem. The iterative method to solve this problem may actually be viewed as a numerical microscope. Indeed, since the slit is narrower than the wavelength of any visible light, including the wavelength of any laser beam, the depth of the slit cannot be measured directly but only numerically as the solution of the inverse problem.

This approach can be extended further to form a numerical microscope to “see” not only the depth of a slit in a tiny object but also the complete structure of a nanoscale object.
