# 21.5 Continuation Process

A possible cure to the above problem is to use a continuation process in the refinement algorithm. This means that the stiffness matrix at the coarsest mesh is assembled using v = 0.9, and the subsequent stiffness matrices at finer and finer meshes are assembled using larger and larger v, until v = 0.99 is used at the finest mesh. Automatic boundary refinement is also used, as in Chapter 14, Section 8. In this process, the convergence factor of the modified multigrid preconditioner is on average 0.95; that is, the energy norm of the preconditioned residual is reduced by 5% on average in each call to the modified multigrid algorithm in the PCG iteration. Although this is not considered rapid convergence, it is still acceptable for such a difficult problem. (See Figure 21.2 for the distribution of nodes in this numerical experiment.)
