The first argument in the function, ‘p’, stands for the array of pointers-to-coefficients in the polynomial p of degree ‘n’. Therefore, "p+1" is nothing but the array of pointers-to-coefficients of the polynomial p₁ of degree "n−1", used in the recursion:

```
return n ==0 ?
    *p[0]
    :
    *p[0] + x * HornerArray(p+1,n-1,x);
} // recursive Horner code
```

Thanks to the fact that the "item" field is declared as protected (rather than private) in the base "list" class, it can be accessed from the derived "polynomial" class as well. The "operator()" function defined below uses this property to apply the above "HornerArray" function to the array "item" to produce the required value of the current polynomial at the argument ‘x’:

```
template<class T>
template<class S>
const T
polynomial<T>::operator()(const S&x) const{
    return HornerArray(item,degree(),x);
} // Horner algorithm to calculate a polynomial
```

With this operator, the user can write "p(x)" to have the value of the well-defined polynomial ‘p’ at a given argument ‘x’.

# 24.7 Polynomials of Two Variables

To implement a polynomial of two variables, one only needs to specify ‘T’ to be a polynomial in its own right. Here we use this implementation to calculate the value of a polynomial of two variables

p(x,y) ≡ Σᵢ aᵢ(x) yⁱ

at some given arguments x and y:

```
template<class T>
template<class S>
const S
polynomial<T>::operator()(const S&x,
    const S&y) const{
    return (*this)(y)(x);
} // compute p(x,y)
```

This function calls the original "operator()" of Section 24.6 twice. In the first call, the argument y is used to obtain the polynomial of one variable p(·,y), where y is a fixed number. In the second call, the argument x is used to compute the required number p(x,y).
