$t_1 \equiv (\vec{j}, \vec{k}, \vec{n}, \vec{m}),$
$t_2 \equiv (\vec{j}, \vec{l}, \vec{n}, \vec{m})$

by introducing a new fine node $\vec{n}$ in between $\vec{k}$ and $\vec{l}$ (Figure 31.2). To define the prolongation operator $P$, let $w$ be a three-dimensional vector function defined on the corners of $t$. The fine-grid function $P w$ is then defined naturally by

$(P w)(\vec{j}) \equiv w(\vec{j})$
$(P w)(\vec{k}) \equiv w(\vec{k})$
$(P w)(\vec{l}) \equiv w(\vec{l})$
$(P w)(\vec{m}) \equiv w(\vec{m})$
$(P w)(\vec{n}) \equiv \frac{w(\vec{k}) + w(\vec{l})}{2}.$

Furthermore, let $q$ be a constant scalar function that has the constant value $q(t)$ in the entire coarse tetrahedron $t$. Define $P q$ as a scalar function that is constant in $t_1$ and also constant in $t_2$:

$(P q)(t_1) \equiv q(t),$
$(P q)(t_2) \equiv q(t).$

This completes the definition of the fine velocity-type vector function $P w$ and the fine pressure-type scalar function $P q$. Thus, the prolongation operator $P$ is well defined.

As in Section 17.13, the restriction operator is then defined by $R \equiv P^t$, and the coarse-grid matrix used in the recursion in the multigrid V-cycle is defined by $Q \equiv R A P$. Alternatively, because the stiffness matrix $A$ may be highly nonsymmetric, $R$, $P$, and $Q$ can be defined as in Section 17.12. Fortunately, in either case, $Q$ has the same stencil as the original stiffness matrix that has been assembled in the coarse mesh in the original adaptive-refinement process, so the rest of the multigrid hierarchy can be defined recursively as well.

Clearly, this is just a prototype multigrid version. The prolongation operator designed in Section 21.10 (with each subdomain being, e.g., a coarse tetrahedron) uses much more insight about the original PDE, and thus has a much better chance to produce a good multigrid preconditioner.

Once the Newton iteration is complete and a sufficiently good approximate solution has been found on the current mesh, the next finer prolongation operator can also be used to prolong it to the next finer mesh to serve as an initial guess for the Newton iteration that is about to start there. (See also Section 21.9 above.)
