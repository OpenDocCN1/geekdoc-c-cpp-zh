# Application in Nonlinear Optics: The Nonlinear Helmholtz Equation in Three Spatial Dimensions

In this chapter, we introduce the finite-element discretization method for the nonlinear Helmholtz equation in three dimensions. The objects implemented above are then used to implement the Newton iteration to solve the equation on the adaptive finite-element mesh.

The Newton iteration, however, requires the separation of the real and the imaginary parts in each complex number, to guarantee differentiability of the nonlinear coefficient in the original PDE. For this purpose, object-oriented programming (OOP) proves to be most useful. Indeed, each element in the sparse matrices is implemented no longer as a mere scalar but rather as a "matrix2" object to store a 2 × 2 block submatrix. This submatrix represents a complex number with real and imaginary parts that are indeed separated from each other, as required.

# 27.1 The Reference Tetrahedron

The elements in the coefficient matrix define the connection between adjacent nodes in the mesh, or nodes that belong to the same tetrahedron in the mesh. In fact, each matrix element may be written as the sum of the contributions from those tetrahedra that contain both nodes. This contribution is obtained from integration over this tetrahedron. The easiest way to calculate this integral is to map the tetrahedron onto the reference tetrahedron T (Figure 27.1).
