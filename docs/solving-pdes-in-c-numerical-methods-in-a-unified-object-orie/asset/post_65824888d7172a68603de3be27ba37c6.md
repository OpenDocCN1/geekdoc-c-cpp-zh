
# A.28 Stiffness and Mass Matrices in Three Dimensions

Here we implement the constructor that takes a three-dimensional mesh as an argument and produces the sum of stiffness, boundary, and mass matrices defined in Sections 27.2 to 27.4. It is assumed that the mesh M covers the unit cube (as in Section A.27 above), and that b (the subset of the boundary on which mixed boundary conditions are imposed) contains two sides of this cube only:

b = {(x,y,z) | x(1 − x) = 0}.

```
template<class T>
sparseMatrix<T>::sparseMatrix(
    mesh<tetrahedron>&m) {
    item = new row<T>*[number = m.indexing()];
```

Because the "sparseMatrix" class is derived from a list of rows, it inherits the field "item", which is an array of pointers to "row" objects. In the above code line, this array is set to contain as many pointers to rows as the number of nodes in the mesh, which is returned from the "indexing" function applied to the "mesh" argument 'm'.

Next, we define a vector of integers to indicate whether a particular node in the mesh is a boundary node in b or not:

```
dynamicVector<int> xBoundary(number,0);
```

This vector (or grid function) is initialized to zero. Later on, it will take the value 1 at indices i corresponding to boundary nodes i ∈ b.

```
for(int i=0; i<number; i++)
    item[i] = 0;
point3 gradient[4];
gradient[0] = point3(-1,-1,-1);
gradient[1] = point3(1,0,0);
gradient[2] = point3(0,1,0);
gradient[3] = point3(0,0,1);
for(const mesh<tetrahedron>* runner = &m;
    runner;
    runner =
        (const mesh<tetrahedron>*)runner->readNext()) {
```

We have just entered the loop over the tetrahedra of the form t ∈ M. The pointer "runner", which points to the "tail" of the underlying linked list of tetrahedra, is converted explicitly from a mere pointer to a linked list of tetrahedra to a pointer to a concrete mesh of tetrahedra. This way, one can refer not only to the first tetrahedron in the "tail" of the linked list by writing "(*runner)()" [invoking the "operator()" of the underlying linked-list object] but also to member functions of the derived "mesh" class as well.

Next, the 3 × 3 matrix S_t is defined:

```
matrix3
    S(((*runner)()[1]() - (*runner)()[0](),
       (*runner)()[2]() - (*runner)()[0](),
(*runner)()[3]() - (*runner)()[0]());
 matrix3 Sinverse = inverse(S);
 matrix3 weight =
 fabs(det(S)/6.) *
 Sinverse * transpose(Sinverse);
```

We are now ready to enter the inner loop, which scans the corners i of the tetrahedron t pointed at by "runner". For each corner i encountered in this inner loop, the integer 'I' denotes its index in the list of nodes in the entire mesh. Then, it is checked whether i is a boundary node in b or not. If it is, then the 'I'th component in the vector "xBoundary" increases from 0 to 1 or 2, to store the valuable information that i is indeed a boundary node in b:

```
for(int i=0; i<4; i++){
 int I = (*runner())[i].getIndex();
 if(((*runner())[i]()[0] <= 1.e-6)
 xBoundary(I) = 1;
 if(((*runner())[i]()[0] >= 1. - 1.e-6)
 xBoundary(I) = 2;
 }
```

We are now ready to calculate the contribution from t to the matrix element a_{i,j} in the constructed matrix. where i and j are just any two corners of t. This is done by a yet inner loop over the corners j of t, indexed by 'J' in the list of nodes in the entire mesh:

```
for(int i=0; i<4; i++){
 int I = (*runner())[i].getIndex();
 for(int j=0; j<4; j++){
 int J = (*runner())[j].getIndex();
 }
 }
```

To add the contribution from t to a_{i,j}, we distinguish between two cases: if the 'I'th row in the constructed matrix already exists, then this contribution is added to it in a row operation:

```
T mass = fabs(det(S))/120.;
 if(i==j)mass *= 2.;
 if(item[I]){
 row<T> r(mass*gradient[j]*weight*gradient[i],J);
 *item[I] += r;
 }
```

If, on the other hand, the 'I'th row does not yet exist, then it must be constructed using the "new" command:

```
else
 item[I] = new row<T>(mass*gradient[j]*weight*gradient[i],J);
```

Next, we also add to the matrix element a_{i,j} the contribution from t associated with the mixed boundary conditions on b. This is done by a yet inner loop on the corners k~ of t, which, together with the original corners i~ and j~ scanned in the outer loops, form the triangle Δ(i~,j~,k~) in b:

```
for(int k=0; k<4; k++){
    int K = (*runner())[k].getIndex();
    if((i!=j)&&(j!=k)&&(k!=i)
    &&((xBoundary[I] * xBoundary[J]
    * xBoundary[K]==1) ||
    (xBoundary[I] * xBoundary[J]
    * xBoundary[K]==8)) {
```

This "if" question makes sure that Δ(i~,j~,k~) is indeed a boundary triangle in b. The contribution from this triangle to a_{i,j} is now calculated, using the fact that the area of the triangle is

1/2 || (j~ - i~) × (k~ - i~) ||_2 .

where ‘×’ stands for the vector product in three dimensions:

```
point3 jMinusi =
    (*runner())[j]() - (*runner())[i]();
point3 kMinusi =
    (*runner())[k]() - (*runner())[i]();
T boundaryTerm =
    l2norm(jMinusi&kMinusi) / 24.;
row<T> boundaryTermJ(boundaryTerm,J);
*item[I] += boundaryTermJ;
```

(See exercises at the end of Chapter 24 above.) Furthermore, the same contribution must also go to the main-diagonal element a_{i,i}:

```
row<T> boundaryTermI(boundaryTerm,I);
*item[I] += boundaryTermI;
}
}
}
}
} // sum of stiffness, boundary, and mass matrices
```

This completes the construction of the sum of the stiffness, boundary, and mass matrices

A^{(s)} + A^{(b)} + A^{(m)}.

# A.29 High-Order Basis Functions in Three Dimensions

Here we define the constructor that produces the 56 × 56 matrix B in Section 28.2. For this purpose, we use the function "C()" defined at the end of Section 1.17.

If B is to be inverted by a direct method as in Section 3.20, then it would make sense to store it in a dense dynamic matrix as in Section 3.14. Here, however, we prefer to implement it as a sparse matrix to benefit from the present iterative methods.

Since the constructor must be a member function, it should first be declared in the block of the "sparseMatrix" class as follows:

```
sparseMatrix(char*);
```

Note that the constructor takes a dummy string argument to distinguish it from the default constructor. Here is the complete definition:

```
template<class T>
sparseMatrix<T>::sparseMatrix(char*){
    item = new row<T>*[number = 56];
    for(int i=0; i<number; i++)
        item[i] = 0;
}
```

Once the 56 rows have been initialized to be the zero (null) pointers, the matrix elements can be set in nested loops. The outer loop is over the 56 columns in the matrix. In fact, this loop is by itself a triple loop that scans all the triplets in T^(5) (see Section 28.2). The index ĵ_{i,j,k} that orders the triplets (i,j,k) ∈ T^(5) in the lexicographical order is stored in the integer variable 'J':

```
int J = -1;
for(int i=0; i<=5; i++)
    for(int j=0; j<=5-i; j++)
        for(int k=0; k<=5-i-j; k++) {
            J++;
```

Now, in order to loop over the rows in the matrix, the first 40 rows are divided into four subsets of ten rows each, associated with partial derivatives evaluated at the four corners of the reference tetrahedron T. Each inner loop that scans a subset of 10 rows is itself implemented as a triple loop to scan the triplets (l,m,n) ∈ T^(2):

```
if((i==l)&&(j==m)&&(k==n)){
    T coef = factorial(i) * factorial(j) *
        factorial(k);
    if(item[I])
        item[I]->append(coef,J);
    else
        item[I] = new row<T>(coef,J);
}
```

Furthermore, the next 10 rows are associated with partial derivatives evaluated at the corner (1,0,0). Clearly, at this corner, the (n,m,l)th partial derivative is nonzero only for monomials that their y-power is exactly m, their z-power is exactly l, and their x-power is at least n:

```
if((i==l)&&(j==m)&&(k>=n)){
    T coef = factorial(i) *
        factorial(j) * C(k,n);
    if(item[10+I])
        item[10+I]->append(coef,J);
    else
        item[10+I] = new row<T>(coef,J);
}
```

Similarly, the next 10 rows are associated with partial derivatives evaluated at the corner (0,1,0). Clearly, at this corner, the (n,m,l)th partial derivative is nonzero only for monomials that their x-power is exactly n, their z-power is exactly l, and their y-power is at least m:

```
if((i>=l)&&(j>=m)&&(k==n)){
    T coef = factorial(i) *
        C(j,m) * factorial(k);
    if(item[20+I])
        item[20+I]->append(coef,J);
    else
        item[20+I] = new row<T>(coef,J);
}
```

Similarly, the next 10 rows are associated with partial derivatives evaluated at the corner (0,0,1). Clearly, at this corner, the (n,m,l)th partial derivative is nonzero only for monomials that their x-power is exactly n, their y-power is exactly m, and their z-power is at least l:

```
if((i>=l)&&(j==m)&&(k==n)){
    T coef = C(i,l) * factorial(j) *
        factorial(k);
    if(item[30+I])
        item[30+I]->append(coef,J);
    else
        item[30+I] = new row<T>(coef,J);
}
```

This completes the first 40 rows in the matrix.
