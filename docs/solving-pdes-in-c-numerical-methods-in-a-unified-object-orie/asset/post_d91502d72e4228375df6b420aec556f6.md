
in the mesh, and therefore can be easily calculated to form the coefficient matrix required in each Newton iteration.

There is, however, one more subtle difference between the present problem and standard denoising: the noise is assumed to be normal to the surface [41]. Therefore, the correction term in each Newton iteration must be projected onto the vector normal to the surface before being added to the previous approximation. If, for example, $j^{(i)}$ denotes the approximation to node $j$ in the $i$th mesh produced at the $i$th Newton iteration, then the vector normal to the surface at $j^{(i)}$ can be approximated by

$\vec{n}_j^{(i)} \equiv \sum_{k^{(i)} \text{ and } l^{(i)} \text{ are connected to } j^{(i)} \text{ in the } i\text{th mesh}} \left(k^{(i)} - j^{(i)}\right) \times \left(l^{(i)} - j^{(i)}\right)$

or

$\vec{n}_j^{(i)} \equiv \sum_{k^{(i)} \text{ and } l^{(i)} \text{ are connected to } j^{(i)} \text{ in the } i\text{th mesh}} \frac{\left(k^{(i)} - j^{(i)}\right) \times \left(l^{(i)} - j^{(i)}\right)}{\left\|\left(k^{(i)} - j^{(i)}\right) \times \left(l^{(i)} - j^{(i)}\right)\right\|_2}$

where ‘×’ stands for the vector product in three dimensions (see Sections 9.25 and 28.10 in [69]). Furthermore, $\vec{n}_j^{(i)}$ can be normalized to be a unit vector:

$\vec{n}_j^{(i)} \leftarrow \vec{n}_j^{(i)} / \|\vec{n}_j^{(i)}\|_2.$

Now, once the $(i+1)$st Newton iteration is computed as in Section 10.7, it is modified by

$j^{(i+1)} \leftarrow j^{(i)} + \left(\left(j^{(i+1)} - j^{(i)}\right)^T \vec{n}_j^{(i)}\right) \vec{n}_j^{(i)}$,

so the correction term has no component that is tangent to the surface. Once this is done for every node $j^{(i)}$ in the $i$th mesh, the $(i+1)$st mesh is complete, and the process is ready to proceed to the next iteration. This procedure is repeated until a sufficiently good approximation is obtained for every node $j$ and indeed for the entire mesh that lies on the required surface.

Since one is only interested in denoising the normal component, a more efficient algorithm could actually be used. This algorithm avoids denoising the vector function $j$, and denoises its normal component only. For this, it applies the Newton iteration to a scalar nonlinear diffusion equation as in Section 10.3 above. More precisely, at the $i$th Newton iteration, one solves for the scalar unknown function

$u \equiv u(j^{(i)}) \equiv \left(j^{(i+1)} - j^{(i)}\right)^T \vec{n}_j^{(i)}$

in the $i$th mesh. As before, the $x$- and $y$-partial derivatives in the scalar diffusion equation in Section 10.3 are interpreted as the directional derivatives in the directions tangent to the relevant triangle in the $i$th mesh. At the end of the $i$th iteration, the improved approximation to node $j$ is defined by

$j^{(i+1)} \equiv j^{(i)} + u(j^{(i)}) \vec{n}_j^{(i)}$,

to form the entire $(i+1)$st mesh and proceed to the $(i+1)$st iteration. This algorithm is more in the spirit of the algorithm introduced in [41].

In either of these algorithms, the diffusion operator must be rediscretized in each iteration on the unstructured mesh associated with it. As we’ll see in the next part of the book, object-oriented C++ programming is particularly suitable for this kind of discretization.

## 10.11 Multidimensional Scaling

In the previous section, we assumed that the exact surface is unknown, so we have to find the unknown three-dimensional vectors $\vec{j}$ that contain the geometric location of the $j$th node on this surface. Here, on the other hand, the unknown $\vec{j}$ is an $n$-dimensional column vector (for some integer $n \ge 2$) that represents the $j$th node only formally in terms of its distance from the other nodes. The problem of finding such optimal vectors $\vec{j}$ is referred to as multidimensional scaling.

Because the geometric location of the $j$th node is available, the distance between the $j$th and $k$th nodes is known as well, and is denoted by $\delta_{j,k}$. For example, $\delta_{j,k}$ could stand for the geodesic distance on the surface or just the Cartesian distance in the three-dimensional space in which the surface is embedded.

Furthermore, let $\Phi$ be some differentiable mapping from the $n$-dimensional Cartesian space to the $l$-dimensional Cartesian space (for some integer $l \ge 2$). ($\Phi$ can be used to deform the $n$-dimensional space and enhance certain parts of it to make distances calculated there more pronounced, if necessary.) Moreover, let $\Phi'$ denote the Jacobian of $\Phi$, namely, the $l \times n$ matrix whose rows are the gradients of the individual components of $\Phi$ (as in Section 9.14). For example, in the trivial case in which $l=n$ and $\Phi$ is just the identity mapping that changes nothing, $\Phi'=I$ is just the identity matrix of order $l=n$.

Finally, let $\Phi''$ be the $l$-dimensional column vector whose components are not just scalars but rather $n \times n$ matrices (as in Section 9.14). More precisely, each individual component in $\Phi''$ is the Hessian (the matrix of second partial derivatives; see Section 28.7) of the corresponding component of $\Phi$.

Now, let $m$ be the collection of the unknown $n$-dimensional vectors of the form $\vec{j}$. The problem is to find an $m$ that minimizes the function

$$g(m) \equiv \sum_{\substack{j,k\in m,\ j\ne k}} \left(\left\|\Phi(\vec{j})-\Phi(\vec{k})\right\|_2^2-\delta_{j,k}^2\right)^2.$$

Clearly, $g$ is minimized at such an $m$ for which the gradient of $g$ (the vector of partial derivatives of $g$ with respect to each coordinate of each $\vec{j}\in m$) vanishes:

$$f(m)\equiv\nabla g(m)=0.$$

To solve this system of equations for $m$, let us first write $f$ more explicitly, using the chain rule. (See Sections 12.5, 28.5, and 30.10; also see Section 12.33 in [69].)

Let $f_j(m)$ denote the $n$-dimensional subvector of $f(m)$ that contains the $n$ components of $f(m)$ that correspond to $\vec{j}\in m$. Note that, in the double sum in the definition of $g(m)$ above, $\vec{j}$ may appear either in the former or in the latter term in the inner squared $l_2$-norm, which contributes an extra factor 2 to the partial derivative of $g(m)$ with respect to $\vec{j}$:

vectors $\vec{j},\vec{k} \in m$. Let us denote this Hessian matrix by $A(m)$. The $n \times n$ block submatrix that couples $\vec{j} \in m$ with $\vec{k} \in m$ ($\vec{k} \neq \vec{j}$) is calculated by the chain rule (see Section 28.7 below and Section 12.35 in [69]):

```
$A_{j,k}(m) = -8\left(\|\Phi(\vec{j}) - \Phi(\vec{k})\|_2^2 - \delta_{j,k}^2\right)\Phi''(\vec{j})\Phi'(\vec{k})$  
$- 16\Phi''(\vec{j})\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)^t \Phi'(\vec{k}).$
```

Furthermore, the $n \times n$ main-diagonal blocks in $A(m)$ are given by

```
$A_{j,j}(m) = 8\Phi''(\vec{j})\Phi'(\vec{j}) \sum_{\vec{k}\in m,\,\vec{k}\neq\vec{j}} \left(\|\Phi(\vec{j}) - \Phi(\vec{k})\|_2^2 - \delta_{j,k}^2\right)$  
$+ 8\Phi''(\vec{j}) \sum_{\vec{k}\in m,\,\vec{k}\neq\vec{j}} \left(\|\Phi(\vec{j}) - \Phi(\vec{k})\|_2^2 - \delta_{j,k}^2\right)\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)$  
$+ 16\Phi''(\vec{j})\left(\sum_{\vec{k}\in m,\,\vec{k}\neq\vec{j}} \left(\Phi(\vec{j}) - \Phi(\vec{k})\right)\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)^t\right)\Phi'(\vec{j}).$
```

The Newton iteration (Section 9.14) is now defined as follows. Pick some $m$ as an initial guess. In each iteration, improve $m$ by the substitution

```
$m \leftarrow m - x,$
```

where $x$ is the solution of the linear system

```
$A(m)x = f(m).$
```

More specifically, each $\vec{j} \in m$ is improved by the substitution

```
$\vec{j} \leftarrow \vec{j} - x_j.$
```

where $x_j$ is the $j$th $n$-dimensional subvector in $x$. Since $f$ might be nonconvex, it might be advisable to use relaxation as in Section 9.15, to make sure that divergence as in Figure 9.11 never happens.
