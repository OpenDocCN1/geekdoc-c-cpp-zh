vectors $\vec{j},\vec{k} \in m$. Let us denote this Hessian matrix by $A(m)$. The $n \times n$ block submatrix that couples $\vec{j} \in m$ with $\vec{k} \in m$ ($\vec{k} \neq \vec{j}$) is calculated by the chain rule (see Section 28.7 below and Section 12.35 in [69]):

```
$A_{j,k}(m) = -8\left(\|\Phi(\vec{j}) - \Phi(\vec{k})\|_2^2 - \delta_{j,k}^2\right)\Phi''(\vec{j})\Phi'(\vec{k})$  
$- 16\Phi''(\vec{j})\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)^t \Phi'(\vec{k}).$
```

Furthermore, the $n \times n$ main-diagonal blocks in $A(m)$ are given by

```
$A_{j,j}(m) = 8\Phi''(\vec{j})\Phi'(\vec{j}) \sum_{\vec{k}\in m,\,\vec{k}\neq\vec{j}} \left(\|\Phi(\vec{j}) - \Phi(\vec{k})\|_2^2 - \delta_{j,k}^2\right)$  
$+ 8\Phi''(\vec{j}) \sum_{\vec{k}\in m,\,\vec{k}\neq\vec{j}} \left(\|\Phi(\vec{j}) - \Phi(\vec{k})\|_2^2 - \delta_{j,k}^2\right)\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)$  
$+ 16\Phi''(\vec{j})\left(\sum_{\vec{k}\in m,\,\vec{k}\neq\vec{j}} \left(\Phi(\vec{j}) - \Phi(\vec{k})\right)\left(\Phi(\vec{j}) - \Phi(\vec{k})\right)^t\right)\Phi'(\vec{j}).$
```

The Newton iteration (Section 9.14) is now defined as follows. Pick some $m$ as an initial guess. In each iteration, improve $m$ by the substitution

```
$m \leftarrow m - x,$
```

where $x$ is the solution of the linear system

```
$A(m)x = f(m).$
```

More specifically, each $\vec{j} \in m$ is improved by the substitution

```
$\vec{j} \leftarrow \vec{j} - x_j.$
```

where $x_j$ is the $j$th $n$-dimensional subvector in $x$. Since $f$ might be nonconvex, it might be advisable to use relaxation as in Section 9.15, to make sure that divergence as in Figure 9.11 never happens.
