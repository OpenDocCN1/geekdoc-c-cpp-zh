
R_{i,j,k,l,m,n} \equiv |A|^{-1} (-1)^{i+j+k+l+m+n} \left| \left( \left( A^{[j,i]} \right)^{[k,l]} \right)^{[m,n]} \right| 
= (-1)^{i+j} |A|^{-1} |A^{[j,i]}| (-1)^{k+l} |A^{[j,i]}|^{-1} \left| \left( A^{[j,i]} \right)^{[k,l]} \right| 
\cdot (-1)^{m+n} \left| \left( A^{[j,i]} \right)^{[k,l]} \right|^{-1} \left| \left( \left( A^{[j,i]} \right)^{[k,l]} \right)^{[m,n]} \right| 
= A_{i,j}^{-1} \left( A^{[j,i]} \right)_{l,k}^{-1} \left( \left( A^{[j,i]} \right)^{[k,l]} \right)_{n,m}^{-1} 
= S_{i,j,k,l} \left( \left( \left( A^{[j,i]} \right)^{[k,l]} \right)^{-1} \right)_{n,m}

If, on the other hand, k > j > m, then one can still modify the above definition and revise its right-hand sides by replacing k by k − 1 to account for the row indexing in A^{[j,i]} that is different from the original row indexing in A due to the missing jth row. Alternatively, one could use the skew-symmetry discussed above to define

R_{i,k,j,l,m,n} \equiv - R_{i,j,k,l,m,n}.

The other possible orders of the triplets j, k, and m and i, l, and n are handled in the same spirit.

This tensor provides the Jacobian of S with respect to A:

\frac{\partial S}{\partial A} = \frac{\partial (|A| S / |A|)}{\partial A} 
= |A|^{-1} \frac{\partial (|A| S)}{\partial A} + |A| S \otimes \frac{\partial |A|^{-1}}{\partial A} 
= |A|^{-1} |A| R - |A| S \otimes |A|^{-1} A \,' 
= R - S \otimes A^t .

As a result, we have the following tensor of six indices:

\frac{\partial^2 A^{-1}}{\partial A^2} = \frac{\partial (S - A^{-1} \otimes A^{-t})}{\partial A} 
= R - S \otimes A^{-t} - \left( \left( \frac{\partial A^{-1}}{\partial A} \otimes A^{-t} \right)^t - A^{-1} \otimes \left( \frac{\partial A^{-1}}{\partial A} \right)^t \right).

We are now ready to calculate b''(e):

b'' = (w' w')' 
= w'' w' + w' w'' 
= ||w'||^2 + w' w'' 
= \left\| \left( \left( \frac{\partial A^{-1}}{\partial A} \right) A' \right)^t f \right\|^2 + w'^t \left( \left( \left( \frac{\partial^2 A^{-1}}{\partial A^2} \right) A' \right) A' \right) f + w'^t \left( \left( \frac{\partial A^{-1}}{\partial A} \right) A'' \right) f .

## 30.12 Direct Calculation

Fortunately, the four-index tensor S is used in Sections 30.10 and 30.11 above only to calculate the tensor-matrix products SA′ and SA′′. This gives one the opportunity to avoid the explicit calculation of S.

Let us show how SA′ can indeed be calculated without the explicit calculation of S itself. Let A(k) be the matrix whose rows are the same as in the original matrix A, except of the k th row, which is the same as in A′:

```
A^{(k)}_{p,q} ≡ { a'_{p,q} if p = k, a_{p,q} if p ≠ k. }
```

The determinant of A(k) can then be written as

```
|A^{(k)}| = Σ_{l=1}^{N} (-1)^{k+l} a'_{k,l} |A^{[k,l]}|.
```

Similarly, once the j th row and the i th column are dropped from A(k), we have

```
|(A^{(k)})^{[j,i]}| = Σ_{1≤l≤N, l≠i} (-1)^{k+l} a'_{k,l} |(A^{[j,i]})^{[k,l]}|.
```

Note that this is true if j > k. If, on the other hand, k > j, then k in the above right-hand side should be replaced by k − 1:

```
|(A^{(k)})^{[j,i]}| = Σ_{1≤l≤N, l≠i} (-1)^{k-1+l} a'_{k,l} |(A^{[j,i]})^{[k-1,l]}| = - Σ_{1≤l≤N, l≠i} (-1)^{k+l} a'_{k,l} |(A^{[k,l]})^{[j,i]}|.
```

Still, this makes no difference in the discussion below. For this reason, we keep assuming without loss of generality that j > k.

Using Cramer's rule and the original definition of S in Section 30.10, we therefore have

```
|A^{(k)}| (A^{(k)})^{-1}_{i,j} = (-1)^{i-j} |(A^{(k)})^{[j,i]}| = Σ_{1≤l≤N, l≠i} (-1)^{i+j+k+l} a'_{k,l} |(A^{[j,i]})^{[k,l]}| = |A| Σ_{l=1}^{N} S_{i,j,k,l} a'_{k,l}.
```

This gives an efficient way to calculate the inner sum in the required tensor-matrix product

```
(SA')_{i,j} = Σ_{k=1}^{N} Σ_{l=1}^{N} S_{i,j,k,l} a'_{k,l}.
```

This gives an efficient way to calculate the inner sum in the required triple product $(RA')A'$, provided that $A^{(k,m)}$ is indeed available with its LUP-factorization as in Sections 3.18 and 3.19 above.

The total number of distinct matrices of the form $A^{(k,m)}$ $(1 \le m < k \le N)$ is

$$\binom{N}{2} = \frac{N(N-1)}{2}.$$

Fortunately, these matrices can be factorized concurrently in parallel. Furthermore, if there are only a few nonzero rows in $A'$ as discussed above, then there are only a few such matrices to factorize.

To reduce the amount of fill-in in the LUP-factorization, the rows in $A$ must be ordered cleverly in advance to minimize the bandwidth of $A$. For example, if $A$ is the stiffness matrix for the Maxwell equations in some finite-element mesh, then the rows should be ordered triplet by triplet, where each triplet contains the three rows corresponding to the three unknown functions at some particular node in the mesh.

Unfortunately, the amount of fill-in may still be prohibitively large in terms of time or storage. To avoid fill-in at all, we consider below a more explicit approach, which avoids any LUP-factorization.

## 30.13 Iterative Calculation

When $A$ is a large sparse matrix, its LUP-factorization may be prohibitively expensive to calculate due to time or storage limit. In this case, one might want to consider calculating the tensors $S$ and $R$ explicitly, using iterative rather than direct linear-system solvers.

Let us start with the calculation of the four-index tensor $S$ defined in Section 30.10. For this purpose, let us recall our original assumptions that $j > k$ and $i > l$. With these assumptions, the original definition in Section 30.10 can be rewritten in a slightly different way:

$S_{i,j,k,l} \equiv |A|^{-1}(-1)^{i+j+k+l} \left|\left(A^{[j,i]}\right)^{[k,l]}\right|$

$= |A|^{-1}(-1)^{i+j+k+l} \left|\left(A^{[k,l]}\right)^{[j-1,i-1]}\right|$

$= (-1)^{k+l}|A|^{-1}|A^{[k,l]}|(-1)^{i+j}|A^{[k,l]}|^{-1}\left|\left(A^{[k,l]}\right)^{[i-1,j-1]}\right|$

$= A_{l,k}^{-1}\left(A^{[k,l]}\right)_{i-1,j-1}^{-1}.$

Thus, to calculate the elements in $S$, one must solve linear systems of the form

$$A^{[k,l]}x = I^{(j-1)},$$

where $1 \le l \le N$, $1 \le k < j \le N$, $I^{(j-1)}$ is the $(j-1)$st column in the identity matrix of order $N-1$, and $x$ is the $(N-1)$-dimensional vector of unknowns. In fact, the solutions $x$ make it possible to calculate sufficiently many elements in $S$, whereas the rest of the elements are defined by the skew-symmetry discussed in Section 30.10.

The total number of linear systems is

```
N \left( \binom{N}{2} \right) = \frac{N^{2}(N-1)}{2} = O(N^{3}).
```

Fortunately, these linear systems are completely independent of each other, so they can be solved concurrently in parallel. Furthermore, each linear system can be solved iteratively, to benefit from its sparsity.

Moreover, the total number of linear systems that actually need to be solved may be far less than in the above estimate. In fact, the above linear system should be solved only if

```
a'_{k,l} \neq 0 \ or \ a''_{j,l} \neq 0.
```

Indeed, the four-index tensor S is used in Sections 30.10 and 30.11 only to calculate the tensor-matrix product SA', defined by

```
(SA')_{i,j} = \sum_{k,l=1}^{N} S_{i,j,k,l} a'_{k,l},
```

or SA'', defined by

```
(SA'')_{i,j} = \sum_{k,l=1}^{N} S_{i,j,k,l} a''_{k,l}.
```

Now, since A is sparse, A' is sparse as well. Furthermore, if a'_{k,l} = a''_{j,l} = 0, then a''_{k,l} = a''_{j,l} = 0 as well. so x contributes nothing to the above sums, and is not needed. The result is that the total number of linear systems that need to be solved decreases to O(N²) only.

Let us now consider the six-index tensor R, defined in Section 30.11 above. Recall our original assumptions that j > k > m and i > l > n. In view of these assumptions, the original definition of the elements in this tensor can be rewritten in a slightly different way:

```
R_{i,j,k,l,m,n} \equiv |A|^{-1}(-1)^{i+j+k+l+m+n} \left| \left( (A^{[k,l]})^{[m,n]} \right) \right|_{[j-2,i-2]} = (-1)^{k+l}|A|^{-1}|A^{[k,l]}|^{-1}|A^{[m+n]}| \left| (A^{[k,l]})^{[m,n]} \right|_{[j-2,i-2]} = A_{l,k}^{-1}(A^{[k,l]})^{-1}_{n,m} \left( (A^{[k,l]})^{[m,n]} \right)^{-1}_{i-2,j-2} = S_{n+1,m+1,k,l} \left( (A^{[k,l]})^{[m,n]} \right)^{-1}_{i-2,j-2}.
```
