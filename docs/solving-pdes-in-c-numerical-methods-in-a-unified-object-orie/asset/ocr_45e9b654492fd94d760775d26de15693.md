```
if(next)
    ((mesh<tetrahedron>*)next)->
        refineNeighbors(nI,nJ,nIJ);
```

(Because the "next" field is a mere pointer to a linked list of tetrahedra, it must be converted explicitly to a pointer-to-mesh before the recursive call can be made.) This recursive call searches the "tail" of the underlying linked list (which contains all the tetrahedra but the first one) for potential neighbor tetrahedra that share the edge leading from "nI" to "nJ". This recursive call uses a yet inner recursive call to search the yet shorter tail that contains all the tetrahedra but the first and second ones, and so on. As a result, the final recursive call at the top of the stack of recursive calls is executed first, and checks only whether the last tetrahedron in the underlying linked list is a neighbor tetrahedron or not. If it is, then it is refined as well, as required. Then, the previous recursive call is executed, to check the previous tetrahedron and refine it if necessary, and so on, until the first tetrahedron is checked and refined if necessary:

```
int ni = nI < item;
int nj = nJ < item;
```

This is how the first tetrahedron, "item", is checked to see whether or not it is a neighbor that shares the edge leading from "nI" to "nJ": first, the "<" operator of Section 13.3 is invoked to check whether "nI" and "nJ" are indeed nodes in "item". If they are, then this operator also returns their indices in the list of nodes in "item" plus 1. This extra 1 can now be subtracted to give the indices "ni" and "nj" of "nI" and "nJ" in the list of nodes in "item":

```
if(ni&&nj){
    ni--;
    nj--;
```

Furthermore, the two other nodes in "item" also have some indices "nk" and "nl" (that are different from "ni" and "nj") in its list of nodes in "item". These indices can be found in simple loops:

```
int nk = 0;
while((nk==ni) || (nk==nj))
    nk++;
int nl = 0;
while((nl==ni) || (nl==nj) || (nl==nk))
    nl++;
```
