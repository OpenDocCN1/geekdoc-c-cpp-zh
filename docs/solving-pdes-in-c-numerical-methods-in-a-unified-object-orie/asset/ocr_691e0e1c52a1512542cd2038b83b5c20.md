# Chapter 27. Application in Nonlinear Optics

Let us use this notation to define the operator f more specifically in the context of the finite-element scheme for the nonlinear Helmholtz equation: for every node i ∈ M.

f(v)_i
≡ ∑_{i∈M, ĩ∈I} |det(S_i)| ∬_T |P_i(v)|^2 P_i(v) P_{ĩ,d} dx dy dz
= ∑_{i∈M, ĩ∈I} |det(S_i)| ∬_T (ℜ² P_i(v) + ℑ² P_i(v)) ℜ P_i(v) P_{ĩ,d} dx dy dz
+ √-1 ∑_{i∈M, ĩ∈I} |det(S_i)| ∬_T (ℜ² P_i(v) + ℑ² P_i(v)) ℑ P_i(v) P_{ĩ,d} dx dy dz.

This way, f is written in terms of its real and imaginary parts, as before.

In the Newton iteration to solve the nonlinear Helmholtz equation, we also need yet another mass matrix. A^{(n)}(v), obtained from the linearization of the nonlinear term. More precisely, A^{(n)}(v) is the Jacobian of f (interpreted as an operator on vector grid functions) at the vector grid function v. Thus, the elements of this matrix are no longer scalars but rather 2 × 2 block submatrices. More specifically, the (ĩ, j̃)th 2 × 2 block submatrix in A^{(n)}(v) is defined as follows. The upper left element in it is defined by partial derivation (under the integral sign as in Section 31.4 below) of ℜ f(v)_ĩ with respect to ℜ v_j̃ :

(A^{(n)}(v)_{ĩ,j̃})_{1,1}
≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T (3ℜ² P_i(v) + ℑ² P_i(v)) P_{ĩ,j̃} dx dy dz .

Furthermore, its upper right element is defined by partial derivation (under the integral sign) of f(v)_ĩ with respect to ℑ v_j̃ :

(A^{(n)}(v)_{ĩ,j̃})_{1,2} ≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T 2ℜ P_i(v) ℑ P_i(v) P_{ĩ,j̃} dx dy dz .

Similarly, its lower left element is defined by partial derivation (under the integral sign) of ℑ f(v)_ĩ with respect to ℜ v_j̃ :

(A^{(n)}(v)_{ĩ,j̃})_{2,1} ≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T 2ℜ P_i(v) ℑ P_i(v) P_{ĩ,j̃} dx dy dz
= (A^{(n)}(v)_{ĩ,j̃})_{1,2} .

Finally, its lower right element is defined by partial derivation (under the integral sign) of ℑ f(v)_ĩ with respect to ℑ v_j̃ :

(A^{(n)}(v)_{ĩ,j̃})_{2,2}
≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T (ℜ² P_i(v) + 3ℑ² P_i(v)) P_{ĩ,j̃} dx dy dz .

This completes the definition of A^{(n)}(v) at the given vector grid function v.
