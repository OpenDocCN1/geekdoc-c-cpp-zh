# 30.13. Iterative Calculation

The total number of linear systems is

```
N \left( \binom{N}{2} \right) = \frac{N^{2}(N-1)}{2} = O(N^{3}).
```

Fortunately, these linear systems are completely independent of each other, so they can be solved concurrently in parallel. Furthermore, each linear system can be solved iteratively, to benefit from its sparsity.

Moreover, the total number of linear systems that actually need to be solved may be far less than in the above estimate. In fact, the above linear system should be solved only if

```
a'_{k,l} \neq 0 \ or \ a''_{j,l} \neq 0.
```

Indeed, the four-index tensor S is used in Sections 30.10 and 30.11 only to calculate the tensor-matrix product SA', defined by

```
(SA')_{i,j} = \sum_{k,l=1}^{N} S_{i,j,k,l} a'_{k,l},
```

or SA'', defined by

```
(SA'')_{i,j} = \sum_{k,l=1}^{N} S_{i,j,k,l} a''_{k,l}.
```

Now, since A is sparse, A' is sparse as well. Furthermore, if a'_{k,l} = a''_{j,l} = 0, then a''_{k,l} = a''_{j,l} = 0 as well. so x contributes nothing to the above sums, and is not needed. The result is that the total number of linear systems that need to be solved decreases to O(N²) only.

Let us now consider the six-index tensor R, defined in Section 30.11 above. Recall our original assumptions that j > k > m and i > l > n. In view of these assumptions, the original definition of the elements in this tensor can be rewritten in a slightly different way:

```
R_{i,j,k,l,m,n} \equiv |A|^{-1}(-1)^{i+j+k+l+m+n} \left| \left( (A^{[k,l]})^{[m,n]} \right) \right|_{[j-2,i-2]} = (-1)^{k+l}|A|^{-1}|A^{[k,l]}|^{-1}|A^{[m+n]}| \left| (A^{[k,l]})^{[m,n]} \right|_{[j-2,i-2]} = A_{l,k}^{-1}(A^{[k,l]})^{-1}_{n,m} \left( (A^{[k,l]})^{[m,n]} \right)^{-1}_{i-2,j-2} = S_{n+1,m+1,k,l} \left( (A^{[k,l]})^{[m,n]} \right)^{-1}_{i-2,j-2}.
```
