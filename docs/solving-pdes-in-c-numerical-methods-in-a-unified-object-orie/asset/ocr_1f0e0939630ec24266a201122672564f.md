With these functions, we can now define (outside the block of the "multigrid" class) a new binary operator that takes a vector f and returns A⁻¹ f, using the multigrid iteration in Chapter 17, Section 17.10, accelerated by PCG as in Section 17.11 in Chapter 17 and Section A.19 in the Appendix:

```
template<class T>
const dynamicVector<T>
operator/(const dynamicVector<T>&f,const multigrid<T>&mg){
    dynamicVector<T> x(f.dim(), 0.);
    PCG(mg,mg.getA(),f,x);
    return x;
} // compute A^{-1}f by multigrid and PCG
```

With this operator, one can simply write "f/MG" to have A⁻¹f, where 'f' is a given vector and A is the coefficient matrix in the given "multigrid" object "MG".

The following binary operator multiplies all the items in a list by a constant object of any type:

```
template<class S, class T>
const list<T>
operator*(const S&R, const list<T>&l){
    list<T> R1(l.size(), R * l[0]);
    for(int i=1; i<l.size(); i++)
        R1(i) = R * l[i];
    return R1;
} // matrix times list
```

In the above loop, the items in the local list "R1" are accessed by the nonconstant "operator()" in Chapter 3, Section 3.4, and are defined as 'R' times the corresponding items in the original list 'l'. The above operator can indeed be used in the multigrid fusion algorithm to restrict the original list of right-hand-side vectors to the coarse grid by multiplying them (from the left) by the restriction matrix R.
