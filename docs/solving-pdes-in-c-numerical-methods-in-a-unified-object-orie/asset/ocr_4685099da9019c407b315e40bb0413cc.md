    runner; runner = runner->readNext()){

        return 0;
    if((*runner]() * (*runner]() >= n)
        return 1;
}

} // is prime ?

Note that this function is implemented as a template function. This gives the user the freedom to call it with 'T' being either "int" or "long int" or even a new class of arbitrarily long integer numbers as in Section 5.24 below. As a matter of fact, 'T' is specified by the arguments with which the function is called. If they are of type "int", then 'T' is interpreted as "int": if, on the other hand, they are of type "long int" (an integer that can be as large as 10^9), then 'T' is interpreted as "long int", and so on.
