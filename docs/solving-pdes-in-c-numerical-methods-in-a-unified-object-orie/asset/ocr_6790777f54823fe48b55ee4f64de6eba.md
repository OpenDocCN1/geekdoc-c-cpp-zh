```
if(f.dim()==1)
    return dynamicVector<S>(1,S(1.) * f[0]);
```

Otherwise, f is split into its even and odd subvectors: f^(e) is stored in the local vector "even", and f^(o) is stored in the local vector "odd":

```
dynamicVector<T> even(f.dim()/2,0.);
dynamicVector<T> odd(f.dim()/2,0.);
for(int i=0; i<f.dim(); i+=2){
    even(i/2) = f[i];
    odd(i/2) = f[i+1];
}
```

The local complex variable 'w' contains w_n (if the original Fourier transform is applied) or \bar{w}_n (if the inverse transform is applied):

```
double angle = 8. * atan(1.) / f.dim();
const complex w(cos(angle),(2*inverse-1) * sin(angle));
```

Recursion is now used to calculate W_{n/2}f^{(e)} (stored in the local vector "Feven") and W_{n/2}f^{(o)} (stored in the local vector "Fodd"):

```
complex wi = 1.;
const dynamicVector<S>
    Feven = FFT(inverse,even,type, 0);
dynamicVector<S>
    Fodd = FFT(inverse,odd,type, 0);
```

Furthermore, "Fodd" is now multiplied from the left by a diagonal matrix that contains the powers of 'w' on its main diagonal:

```
for(int i=0; i<f.dim()/2; i++){
    Fodd(i) *= wi;
    wi *= w;
}
```

Finally, if this is the outer call in the inverse transform, then the returned vector is also divided by n:

```
return inverse&&first ?
        (1./f.dim()) * dynamicVector<S>(
        Feven + Fodd,Feven - Fodd)
    :
        dynamicVector<S>(
        Feven + Fodd,Feven - Fodd);
} // FFT
```

This completes the implementation of FFT.
