In our example, we use

```
g(t,x,y) = { 1000 P(x,y),  t ≤ 20Δt,
                0,          t > 20Δt. }
```

In other words, g is proportional to the diffusion coefficient P in the first 20 time steps, to get the contour to shrink and approach the object in the image. At further time steps, on the other hand, it is assumed that the contour has already shrunk sufficiently: in order to get it to approximate the object in the image with a yet greater accuracy, g must vanish. In the present example, we use 30 more time steps with vanishing g.

The linear system obtained in each time step in the implicit time marching is solved approximately by three multigrid iterations (in the first 20 time steps) or by one multigrid iteration (in the next 30 time steps). The solution at the final time step is then interpolated smoothly into a yet finer grid of pixels (see Chapter 27 in [69]), and the final contour is the set of points at which this solution vanishes. For example, the final contour displayed in Figure 10.6 gives a rather good segmentation to the face, hair, and hat of the well-known model Lena.

# 10.10 Denoising in a Curved Surface

Denoising is relevant not only in digital images but also in noisy curved surfaces obtained, e.g., from laser scanning. In this case, the task is to find the accurate surface from noisy data about it. More precisely, one has to find the exact location of the nodes in the discrete mesh that approximates the surface well, using their rough estimates only. More specifically, one has only a noisy datum of the form j̄ for each node j that lies on the unknown surface in the three-dimensional Cartesian space. Thus, the accurate location of the node j is unknown; all one can hope for is to have a better approximation for it by denoising the noisy datum j̄.

Thus, in this case, j can be thought of as the unknown vector function that needs to be discovered from the original noisy data j̄. To be consistent with the notations in Section 10.7 above, let us denote

```
j ≡ (r_j, g_j, b_j),
```

where r_j is the x-coordinate of j, g_j is the y-coordinate, and b_j is the z-coordinate. To solve for j and have the mesh that approximates the surface well, one must solve a nonlinear diffusion system as in Section 10.7. Here, however, instead of a fixed rectangular grid of pixels, one solves in an unstructured mesh of triangles (or a triangulation) that may move in each iteration until it converges to the required surface.
