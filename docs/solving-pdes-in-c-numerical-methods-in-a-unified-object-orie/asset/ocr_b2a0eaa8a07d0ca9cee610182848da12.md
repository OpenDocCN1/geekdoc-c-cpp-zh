# 5.36 The Fast Fourier Transform

To define FFT, let us first make a few observations.

Assume that n is even. In this case, we have

w_n^{n/2} = exp((2π√-1 / n)(n/2)) = exp(π√-1) = -1.

For this reason, the i th row in the Fourier matrix W_n (for some 0 ≤ i < n/2) is related to the row that lies n/2 rows ahead by

w_n^{(i+n/2)j} = w_n^{ij} w_n^{(n/2)j} = (-1)^j w_n^{ij}.

More compactly, the j th column in W_n (for some 0 ≤ j < n) can be split into two subvectors that may differ from each other by sign only:

⎛ 1 ⎞   ⎛ ⎛ 1 ⎞ ⎞
⎜ w_n^j ⎟ = ⎜ ⎜ w_n^j ⎟ ⎟
⎜ w_n^{2j} ⎟   ⎜ ⎜ w_n^{2j} ⎟ ⎟
⎜  :  ⎟   ⎜ ⎜  :  ⎟ ⎟
⎝ w_n^{(n-1)j} ⎠   ⎝ ⎝ w_n^{(n/2-1)j} ⎠ ⎠
                ⎛ ⎛ 1 ⎞ ⎞
                ⎜ (-1)^j ⎜ w_n^j ⎟ ⎟
                ⎜ ⎜ w_n^{2j} ⎟ ⎟
                ⎜ ⎜  :  ⎟ ⎟
                ⎝ ⎝ w_n^{(n/2-1)j} ⎠ ⎠

Let us now see how the Fourier matrix of order n/2 is related to the original Fourier matrix of order n. For this purpose, note that

w_{n/2} = exp(2π√-1 / (n/2)) = exp(4π√-1 / n) = w_n^2.

With this observation, the previous formula takes the form

⎛ 1 ⎞   ⎛ ⎛ 1 ⎞ ⎞
⎜ w_n^j ⎟ = ⎜ ⎜ w_{n/2}^j ⎟ ⎟
⎜ w_n^{2j} ⎟   ⎜ ⎜ w_{n/2}^{2j} ⎟ ⎟
⎜  :  ⎟   ⎜ ⎜  :  ⎟ ⎟
⎝ w_n^{(n-1)j} ⎠   ⎝ ⎝ w_{n/2}^{(n/2-1)j} ⎠ ⎠
                ⎛ ⎛ 1 ⎞ ⎞
                ⎜ ⎜ w_{n/2}^j ⎟ ⎟
                ⎜ ⎜ w_{n/2}^{2j} ⎟ ⎟
                ⎜ ⎜  :  ⎟ ⎟
                ⎝ ⎝ w_{n/2}^{(n/2-1)j} ⎠ ⎠
