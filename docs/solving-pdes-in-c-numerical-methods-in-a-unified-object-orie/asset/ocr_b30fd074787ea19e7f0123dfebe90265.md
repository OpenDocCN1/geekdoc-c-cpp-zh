# A.34  Assembling the Divergence Equation in the Electricity System

To solve the three final exercises at the very end of Chapter 29, we extend here the matrix assembled in Section A.32 above by placing the rectangular matrix $Z$ below it and its transpose $Z^t$ to the right of it, where each row in $Z$ is obtained by integrating the divergence equation against some function that is 1 in one tetrahedron only and 0 elsewhere (or, in other words, by integrating the divergence equation in some tetrahedron $t$ in the mesh). For this purpose, recall that the unit (or reference) tetrahedron $T$ is mapped onto $t$ by the affine mapping $D_t$, whose Jacobian is $S_t$ (Section 27.1). Thus, a nodal basis function in $t$ (a linear function with the value 1 at one corner of $t$ and the value 0 at the three other corners) can be written as the composite function obtained by applying $D_t^{-1}$ and then applying the corresponding nodal basis function in $T$. From the chain rule (Sections 10.11, 12.5, 28.5, and 30.10), we have that the gradient of the original nodal basis function in $t$ is equal to $S_t^{-1}$ times the gradient of the corresponding nodal basis function in $T$. Fortunately, the latter gradient has a very simple form: it is either $(-1,-1,-1)^t$ or $(1,0,0)^t$ or $(0,1,0)^t$ or $(0,0,1)^t$, which are already stored in the "point3" object’s "gradient[0]", "gradient[1]", "gradient[2]", and "gradient[3]", respectively (Section A.32).

Furthermore, the above composite form is also useful to integrate a nodal basis function in $t$. In fact, one could just integrate over the reference tetrahedron $T$ and multiply the result by the absolute value of the determinant of $S_t$. Since the volume of the unit tetrahedron is $1/6$, the integral over $t$ of the constant function 1 is $|\det(S_t)|/6$.

The order of the coefficient matrix (or the number of unknowns in the discrete system) is the sum of the order of the matrix assembled in Section A.32 and the number of rows in the rectangular matrix $Z$. Fortunately, the number of rows in $Z$ is also available: it is the same as the number of tetrahedra in the mesh, which can be obtained from the function "length()" inherited from the base "linkedList" class.
