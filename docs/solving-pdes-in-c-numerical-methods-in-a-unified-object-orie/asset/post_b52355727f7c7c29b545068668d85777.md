## 26.8 The Adaptive Algorithm

As we have seen above, the finite-element scheme that uses a mesh of tetrahedra is much more suitable for adaptive refinement than standard finite differences. In the initial (coarse) mesh, the domain is approximated by the union of only a few disjoint tetrahedra. In each refinement step, some edges in the previous coarser mesh are divided to form the next finer mesh in the next finer level (see Section 26.6). More precisely, only those edges over which the "jump" in the current discrete solution is relatively large are divided. More specifically, if $e = (e^{(1)}, e^{(2)})$ is an edge in the mesh with the endpoints $e^{(1)}$ and $e^{(2)}$, then the jump over this edge is defined by

$$j(e, v) \equiv ||v(e^{(1)}) - v(e^{(2)})||,$$

where $v$ is the discrete solution in the current (coarse) mesh. Now, the maximal jump in a mesh $m$ is defined by

$$j_0(m, v) \equiv \max_{e \in t, t \in m} j(e, v).$$

Furthermore, the average jump is defined by

$$j_1(m, v) \equiv \frac{\sum_{t \in m} \sum_{e \in t} j(e, v)}{6 \sum_{t \in m} 1}.$$

In the refinement step, only those edges $e$ for which

$$j(e, v) \ge \max(j_0(m, v)/2, j_1(m, v))$$

(where $m$ is the mesh of tetrahedra in the current level and $v$ is the discrete solution on it) are divided. (The tetrahedra that share these edges are divided as well to preserve conformity.)

The rest of the edges, on the other hand, remain undivided in the next finer mesh as well. This completes the definition of the next finer mesh in the next finer level. It is also possible to replace $j_1(m, v)$ by a more standard average:

$$j_2(m, v) \equiv \frac{\sum_{e \in m} j(e, v)}{\sum_{e \in m} 1}$$

This, however, would require us to index the edges in the entire mesh. (See Section A.30 in the Appendix.) Once the edges are indexed, it is also possible to form the list of edges in the entire mesh and order it in increasing-jump order: edges with a small jump at the beginning of the list, and edges with a larger jump at the end. With this list, one could divide only those edges with the largest jumps in the current mesh (say, only the edges in the last fifth of the list), leaving the remaining edges (which have a smaller jump) undivided in the next finer mesh as well.

In the present applications, however, we prefer to avoid this extra programming, and stick to the original $j_0$ and $j_1$ to decide which edges to divide in the adaptive algorithm.

# Application in Nonlinear Optics: The Nonlinear Helmholtz Equation in Three Spatial Dimensions

In this chapter, we introduce the finite-element discretization method for the nonlinear Helmholtz equation in three dimensions. The objects implemented above are then used to implement the Newton iteration to solve the equation on the adaptive finite-element mesh.

The Newton iteration, however, requires the separation of the real and the imaginary parts in each complex number, to guarantee differentiability of the nonlinear coefficient in the original PDE. For this purpose, object-oriented programming (OOP) proves to be most useful. Indeed, each element in the sparse matrices is implemented no longer as a mere scalar but rather as a "matrix2" object to store a 2 × 2 block submatrix. This submatrix represents a complex number with real and imaginary parts that are indeed separated from each other, as required.

## 27.1 The Reference Tetrahedron

The elements in the coefficient matrix define the connection between adjacent nodes in the mesh, or nodes that belong to the same tetrahedron in the mesh. In fact, each matrix element may be written as the sum of the contributions from those tetrahedra that contain both nodes. This contribution is obtained from integration over this tetrahedron. The easiest way to calculate this integral is to map the tetrahedron onto the reference tetrahedron $T$ (Figure 27.1).

![Figure 27.1. The unit tetrahedron.](img/1f293b0ceb2de964310ea7f941a1b580_624_0.png)

Consider a general tetrahedron $t$ in the three-dimensional Cartesian space, with vertices (or corners) denoted by $\vec{k}$, $\vec{l}$, $\vec{m}$, and $\vec{n}$:

$$t = (\vec{k}, \vec{l}, \vec{m}, \vec{n}).$$

where the order of vertices in this notation is determined arbitrarily in advance. With this notation, the reference tetrahedron is presented as

$$T = ((0,0,0),(1,0,0),(0,1,0),(0,0,1)).$$

Let $S_t$ be the $3 \times 3$ matrix whose columns are the three-dimensional vectors leading from $\vec{k}$ to the three other corners of $t$:

$$S_t \equiv (\vec{l} - \vec{k} \mid \vec{m} - \vec{k} \mid \vec{n} - \vec{k}).$$

With this notation,

$$S_T = I$$

is the $3 \times 3$ identity matrix.

Let us use the matrix $S_t$ to define a mapping from $T$ onto $t$:

$$D_t \left( \begin{pmatrix} x \\ y \\ z \end{pmatrix} \right) \equiv \vec{k} + S_t \left( \begin{pmatrix} x \\ y \\ z \end{pmatrix} \right).$$

Indeed, the corners of the reference tetrahedron $T$ are mapped onto the corresponding corners of $t$:

$$D_t \left( \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix} \right) = \vec{k}$$

$$D_t \left( \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \right) = \vec{l}$$

$$D_t \left( \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} \right) = \vec{m}$$

$$D_t \left( \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} \right) = \vec{n}.$$

Clearly, the inverse mapping maps $t$ back onto $T$:

$$D_t^{-1} \left( \begin{pmatrix} x \\ y \\ z \end{pmatrix} \right) = S_t^{-1} \left( \begin{pmatrix} x \\ y \\ z \end{pmatrix} - \vec{k} \right).$$

Below we use this mapping to define the coefficient matrix for the finite-element scheme.

## 27.2 The Stiffness Matrix

Let $M$ be a mesh of tetrahedra that approximates the original domain $\Omega$. Here we define the stiffness matrix $A^{(s)}$ obtained from the linear finite-element discretization over $M$.

It is easy to see that the volume of the reference tetrahedron $T$ is $1/6$. (See exercises at the end of Chapter 24.) Define the following polynomials of three variables:

$$P_{k,t}(x,y,z) = 1 - x - y - z$$
$$P_{l,t}(x,y,z) = x$$
$$P_{m,t}(x,y,z) = y$$
$$P_{n,t}(x,y,z) = z.$$

Furthermore, define the constant three-dimensional vectors (the gradients of these polynomials) by

$$g_{k,t} = \nabla P_{k,t} = \begin{pmatrix} -1 \\ -1 \\ -1 \end{pmatrix}, \quad g_{l,t} = \nabla P_{l,t} = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \quad g_{m,t} = \nabla P_{m,t} = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \quad g_{n,t} = \nabla P_{n,t} = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}.$$

The $(\vec{i}, \vec{j})$th matrix element in $A^{(s)}$ that couples the nodes $\vec{i}$ and $\vec{j}$ to each other is defined by

$$A_{\vec{i},\vec{j}}^{(s)} \equiv \sum_{t \in M, \vec{i},\vec{j} \in t} |\det(S_t)| g_{j,t}^T S_t^{-1} S_t^{-T} g_{i,t} \int\int\int_T dx dy dz$$
$$= \frac{1}{6} \sum_{t \in M, \vec{i},\vec{j} \in t} |\det(S_t)| g_{j,t}^T S_t^{-1} S_t^{-T} g_{i,t},$$

where $g_{j,t}^T$ is the row vector that is the transpose of the column vector $g_{j,t}$, and $S_t^{-T}$ is the transpose of the inverse of the $3 \times 3$ matrix $S_t$. To complete the definition of the stiffness matrix, we still need to add the contributions from the boundary conditions.
