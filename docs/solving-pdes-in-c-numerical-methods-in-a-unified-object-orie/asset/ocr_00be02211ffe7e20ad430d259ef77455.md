16. Modify the above inner GMRES iteration to use the Kaczmarz iteration (Sections 17.6 and A.16) as a preconditioner. In the normal equations in Section 17.6, make sure to use the Hermitian adjoint A* = A̅ᵀ rather than the mere transpose Aᵀ. For this purpose, the "transpose()" function for sparse matrices must call the "transpose()" function to calculate the complex conjugate of its elements, which are implemented as 2 × 2 matrices. To have an efficient Kaczmarz preconditioner, make sure that A*, A*A, and A*f are calculated only once. The solution can be found on the Web page of the book at http://www.siam.org/books/cs09.

17. Run the above code and conclude that, unfortunately, the Kaczmarz preconditioner contributes nothing to the convergence rate, so using no preconditioner at all is preferable.
