Gauss–Seidel (Chapter 17, Section 5), ILU (Chapter 17, Section 7), multigrid (Chapter 17, Section 10), and approximate inverse (Section 17.20).

ILU is implemented with two possible thresholds: ILU(0.01) uses a threshold as small as 0.01, which yields a rapid convergence, yet cannot be used in most practical applications due to loss of sparsity, leading to too large set-up time and storage requirement. ILU(0.05), on the other hand, which uses the larger threshold of 0.05 to produce sparser incomplete factors L and U, results in a slow convergence, as can be seen in Table 19.1.

The approximate-inverse preconditioner is implemented as in Section 17.20 with a threshold as large as δ = 0.5, in an attempt to reduce the set-up time. Unfortunately, it turns out that even with such a large threshold the set-up time is so large that this preconditioner is quite impractical for this application.

The multigrid preconditioners are implemented in a V-cycle with one prerelaxation, one post-relaxation, and one relaxation to solve approximately the coarsest-grid system ("Nu1", "Nu2", and "NuCoarse" in Chapter 17, Section 10, are set to 1). The relaxation method used in this V-cycle is Gauss–Seidel ("useILU" in Chapter 17, Section 10, is set to 0).
