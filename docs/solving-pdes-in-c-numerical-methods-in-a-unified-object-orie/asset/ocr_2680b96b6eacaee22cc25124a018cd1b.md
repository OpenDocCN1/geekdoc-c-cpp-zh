already exists, then the "append()" function is called. If, on the other hand, this row does not yet exist, then the "new" command is used to allocate memory for it in the first place.

```
for(int i = 0; i < M; i++)
    for(int j = 0; j < N; j++) {
        if(j<N-1)
            if(this->item[i*N+j])
                this->item[i*N+j]->append(
                    -gradushiftx(i,j,"read"), i*N+j+1);
            else
                this->item[i*N+j] = new row<double>(
                    -gradushiftx(i,j,"read"), i*N+j+1);
        if(i<M-1)
            if(this->item[i*N+j])
                this->item[i*N+j]->append(
                    -gradushifty(i,j,"read"), i*N+j+N);
            else
                this->item[i*N+j] = new row<double>(
                    -gradushifty(i,j,"read"), i*N+j+N);
    }
```

We are now ready to add the strictly lower triangular part as well:

```
*this += transpose(*this);
```

We are now ready to add the main diagonal as well. For this, we use the constructor that produces the diagonal row-sum matrix:

```
*this -= sparseMatrix<T>(*this,"rowsum");
```

Finally, we also add a small positive number to the main diagonal to avoid singularity:

```
*this += sparseMatrix<T>(rowNumber(), .1);
} // constructing fusion matrix
```

This completes the construction of the sparse matrix in Chapter 10, Section 10.4. In particular, when the argument 'u' is the trivial uniform image 'u ≡ 1, this constructor produces the discrete Laplacian, required in the multigrid fusion algorithm.
