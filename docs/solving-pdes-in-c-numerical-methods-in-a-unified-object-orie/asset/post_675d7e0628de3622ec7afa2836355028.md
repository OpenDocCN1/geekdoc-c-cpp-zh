
# Chapter 23

# Multigrid for Nonlinear Equations and for the Fusion Problem in Image Processing

In Chapter 17, Sections 17.8–17.16, multigrid is introduced as an iterative method for solving large sparse linear systems of algebraic equations arising from PDE discretization. Here, on the other hand, multigrid is used not merely as a linear-system solver but also as an algorithm for fusing digital images.

To this end, the original multigrid algorithm is first extended to nonlinear systems as well. The defect correction introduced for this purpose is particularly useful in the multigrid fusion algorithm as well.

Thanks to the present object-oriented framework, the implementation of the multigrid fusion algorithm is particularly short and straightforward. In fact, the entire algorithm is complete in one command line in the fusion function. This shows once again how valuable object-oriented programming can be to implement all sorts of advanced mathematical algorithms.

## 23.1 Nonlinear Systems

So far, we’ve mainly considered linear systems of the form

Ax = f,

where f is a given N-dimensional vector, x is the N-dimensional vector of unknowns, and A is the given nonsingular N × N coefficient matrix. Here we extend this problem to the nonlinear system

A(x) = f,

in which A is an invertible mapping from the N-dimensional space to itself. To discuss solvers for this system, let us rewrite it in a slightly different form:

A(x) − A(x̃) = f − A(x̃).

What is the advantage of this form? Suppose that we already have an approximate solution x̃ for the original system. Then, all we need to do is to find the error

e ≡ x − x̃.

Fortunately, the above multigrid iteration provides the answer to this problem. Indeed, it solves efficiently for the unknown vector x, at least whenever the original differential operator has no discontinuous coefficients. Indeed, whenever the original differential operator has rather smooth coefficients, the coarse-grid operator Q can be obtained by a straightforward rediscretization of the original differential operator on the coarse grid. This way, Q indeed approximates A well, as required, so the multigrid iteration should indeed converge rapidly to the required solution x.

In the fusion problem [82], on the other hand, the situation is completely different. It is assumed that A⁻¹ is indeed available in the sense that there exists an efficient algorithm (e.g., the above multigrid iteration) to solve A(x) = f. However, the problem here is that f is inaccurate: it only approximates the true right-hand side.

For example, assume that there are multiple digital images

u⁽¹⁾, u⁽²⁾, ..., u⁽ᵐ⁾

of the same object, person, or landscape. Some of these images may be better focused than the others. The problem is to develop an automatic algorithm to fuse these images into one well-focused image.

To do this, note that each digital image u⁽ʲ⁾ (1 ≤ j ≤ m) introduces the right-hand side

f⁽ʲ⁾ = A(u⁽ʲ⁾).

The idea is thus to fuse these multiple right-hand sides into a single vector f, which is then used in a sophisticated multigrid fusion algorithm to produce the required well-focused image.

## 23.7 The Laplacian

In the fusion problem, the original differential operator could be just the linear Laplacian operator:

−Δ = −∇·∇ = −∂²/∂x² − ∂²/∂y².

The original matrix A could then discretize the Laplacian on the original fine grid by finite differences, volumes, or elements. (In the present implementation we use finite differences, as in Chapter 10.) Similarly, the coarse-grid matrix Q could just rediscretize the Laplacian by the same numerical method on the coarse grid.

As in Chapter 10, the boundary conditions are of the Neumann type. These boundary conditions should be incorporated in A and Q as well. This way, both A and Q have zero row-sum. In other words, both A and Q map every constant vector to the zero vector.

On one hand, this is a good sign. Indeed, it indicates that Q agrees with A at least on the eigenvector of the smallest possible eigenvalue. This is indeed the most important eigenvector: it represents the lowest frequency in the Fourier decomposition of the solution x, or the longest wave in x, or the global nature of x.

In other words, Q indeed approximates A well in terms of spectrum. Therefore, the coarse-grid problem is indeed likely to produce a solution of the same nature as that of the original fine-grid problem.

Still, on the other hand, the above also means that both A and Q are singular matrices, so the original system Ax = f may have no solution at all. To avoid singularity, we therefore add a small positive number to the main diagonal, as in Chapter 10.

So far, we’ve assumed that Q is defined geometrically by rediscretizing the Laplacian on the coarse grid. Alternatively, Q could also be defined algebraically by the triple product

Q ≡ RAP,

as in Chapter 17, Section 17.8. This way, as shown in Chapter 10 in [68], Q approximates A well not only for positive-semidefinite or SPD problems but also for indefinite problems. This approach is indeed used in the present implementation.

## 23.8 Multiple Right-Hand Sides

One way to produce a sharp image is to distinguish between different pixels. At each particular pixel, it makes sense to use an image u^(i) that has little blur at this pixel, or has a rather large source or sink at this pixel. For this purpose, we need to pick the correct right-hand side f^(i) that has a rather large absolute value at that pixel. This f^(i) is the only one that should contribute to f at that pixel.

Recall that, in the fusion problem, A has been applied to the original images

u^(1), u^(2), ..., u^(m)

to produce the multiple right-hand sides

f^(1) = A u^(1), f^(2) = A u^(2), ..., f^(m) = A u^(m).

Each right-hand side discretizes the divergence of the gradient of the corresponding image, so it contains the sources and sinks in this image.

## 23.9 The Right-Hand Side

The multiple right-hand sides

f^(1), f^(2), ..., f^(j), ..., f^(m)

should thus be incorporated into a new right-hand side f with sources and sinks with maximal absolute value. For this purpose, let us first define the "max()" function that takes two N-dimensional vectors u and v to produce the new N-dimensional vector max(u, v) by picking the larger value (in magnitude) at each component (or pixel):

(max(u, v))_i ≡ { u_i if |u_i| ≥ |v_i|, v_i if |u_i| < |v_i| }

(1 ≤ i ≤ N). This function is then used in the inductive definition of f:

f ≡ max(f^(1), f^(2), ..., f^(m)) ≡ max(max(f^(1), f^(2), ..., f^(m-1)), f^(m)).

This way, each component (or pixel) in f is indeed the maximal component (in magnitude) in the f^(i)'s. This is why f is indeed used in the multigrid fusion algorithm below.

## 23.10 Alternative Right-Hand Side

Alternatively, the right-hand side $f$ could also be defined as follows. For $1 \le i \le N$, let $e^{(i)}$ be the $i$th standard unit vector, or the $i$th column of the identity matrix of order $N$. Furthermore, let $j(i)$ be an integer number between $1$ and $m$ for which $f^{(j(i))}$ is maximal (in modulus) at component (or pixel) $i$:

$|f_i^{(j(i))}| \ge |f_i^{(1)}|$  
$|f_i^{(j(i))}| \ge |f_i^{(2)}|$  
$\vdots$  
$|f_i^{(j(i))}| \ge |f_i^{(m)}|.$

Initially, let $f$ be the zero $N$-dimensional vector. Now, for $i = 1,2,\ldots,N$, update $f$ by the following substitution:

$f \leftarrow f + u_i^{(j(i))} A e^{(i)}$,

where

$u^{(1)} = A^{-1} f^{(1)}$  
$u^{(2)} = A^{-1} f^{(2)}$  
$\vdots$  
$u^{(m)} = A^{-1} f^{(m)}.$

Fortunately, the $u^{(j)}$'s are already available on the original fine level, so no inversion of $A$ is required. Furthermore, on the coarse level, it is assumed that $Q$ is easily invertible.

Moreover, the above loop contains no expensive vector operation. Indeed, $A e^{(i)}$ is already available as the $i$th column in the sparse matrix $A$, or the $i$th row in the symmetric sparse matrix $A$. Thus, each update of $f$ in the above loop requires only a few scalar operations.

In the example in Section 23.14 below, however, it turns out that the original definition of $f$ in Section 23.9 above gives a better result.

## 23.11 Global Features

Unfortunately, the combined right-hand side $f$ calculated above is still not good enough. Indeed, it may contain only local sources and sinks that are well-observed on the fine grid, but not necessarily more global coarse-grid features. To have these features as well, it is not enough to calculate the algebraic solution $x$ associated with $f$. Indeed, the naive algebraic solution

$x = A^{-1} f$

may lack any coarse-grid sharpness. A more sophisticated multigrid fusion algorithm is required not only to solve algebraically the original system with the inaccurate right-hand side $f$ but also to take into account coarse-grid contributions to the true image as well.
