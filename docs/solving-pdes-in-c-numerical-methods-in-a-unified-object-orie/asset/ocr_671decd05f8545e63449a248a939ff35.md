Finally, we define an ordinary operator to calculate the real inner product of two dynamic vectors:

```
template<class T>
const T operator&&(const dynamicVector<T>&u,
    const dynamicVector<T>&v){
    T sum = 0;
    for(int i = 0; i < u.dim(); i++)
        sum += u[i] * v[i];
    return sum;
} // real inner product
```
