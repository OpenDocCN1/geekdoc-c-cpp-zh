# 27.8 Numerical Results

It turns out that the adaptive-refinement algorithm in Section 26.8 is particularly efficient. Indeed, each level uses only a couple of thousands of degrees of freedom (nodes), even in the finest mesh.

In each level, linear finite elements are used to assemble the stiffness and mass matrices and form the coefficient matrix used in the Newton iteration in Section 27.7. Furthermore, in each level, 100 GMRES iterations (with the multigrid preconditioner) are used to provide the discrete solution u on the current mesh. It turns out that the convergence factor of the multigrid preconditioner is about 0.85 on average; that is, the average factor by which the l₂-norm of the preconditioned residual is multiplied in each GMRES iteration is 0.85 or so.

We start with a few levels of adaptive refinement to form a fine mesh on which the linear problem (K = −40, K₁ = 0) is well approximated. Indeed, thanks to the fact that the solution is available in a closed form, the error is available as well. This error (in each level) is shown in Table 27.1.

In the next couple of levels, we turn to the nonlinear case. Indeed, |K₁| increases from level to level (see Table 27.2). Furthermore, in this nonlinear case, we also replace the homogeneous Neumann boundary conditions at y = 0, y = 1, z = 0, and z = 1 by mixed complex boundary conditions, as advised in [32]:

$$\begin{aligned}
u_y + \sqrt{K}\,u &= 0 &&\text{if } y=1,\\
-u_y + \sqrt{K}\,u &= 0 &&\text{if } y=0,\\
u_z + \sqrt{K}\,u &= 0 &&\text{if } z=1,\\
-u_z + \sqrt{K}\,u &= 0 &&\text{if } z=0.
\end{aligned}$$

In each of these levels, a few outer Newton iterations (Section 27.7) are performed. In each Newton iteration, 100 inner GMRES iterations (with the multigrid preconditioner) are used to reduce the l₂-norm of the preconditioned residual by at least six orders of magnitude.

As can be seen in Table 27.2, a couple of outer Newton iterations is sufficient to reduce the (outer) residual considerably. Similar results are also obtained in the more difficult case K = −80 in Tables 27.3 and 27.4.
