# 5.31 Implementation of the Rabin–Miller Test

To implement the Rabin–Miller test, we must first write a function that takes the nonconstant argument "n1" and filters out every power of 2 from it. In other words, the function writes "n1" in the form

"n1" = 2^r s,

where s is odd. In the process, "n1" is gradually changed into s, and r is returned by the function:

```
template<class T>
int factor2(T& n1){
    int r = 0;
    while(n1%2==0){
        n1 /= 2;
        r++;
    }
    return r;
} // factorize powers of 2
```

When the function is actually called, the template parameter 'T' can be set to the class "number" defined above, to stand for an arbitrarily long integer number. Furthermore, the input argument "n1" may take the value n − 1, where n is the tested number. This way, the function indeed produces the required factorization

n − 1 = 2^r s,
