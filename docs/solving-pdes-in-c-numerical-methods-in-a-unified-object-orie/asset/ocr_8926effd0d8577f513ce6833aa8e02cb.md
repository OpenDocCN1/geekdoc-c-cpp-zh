# A.1 Representation of Integers in Any Base

The following code is a more elegant and general version of the code in Section 1.12 in Chapter 1. In fact, it can be used to represent an integer number in any base. In particular, when the chosen base is 2, the code is equivalent to that in Section 1.12 in Chapter 1.

```
int reverse(int n, int base){
    int reversed = n%base;
    while(n /= base)
        reversed = reversed * 10 + n%base;
    return reversed;
} /* reverse an integer number */

int changeBase(int n, int base){
    int even = n%base ? 0 : 1;
    return reverse(reverse(n+even,base),10)-even;
} /* change base from 10 to "base" */
```
