[Usually, only half of this term is integrated by parts, to account for a nonlinear boundary term of the form $(\u00b7\u00b7n)u/2$ that may be used in the mixed boundary condition. Fortunately, both terms in the above right-hand side are only algebraic (rather than differential) in the unknown vector function $u$, so they can be discretized and linearized as in Sections 27.5\u201327.7 below.] The detailed formulation is given in [44].

The original Navier\u2013Stokes system can be perturbed by replacing the zero element in the upper-left corner of the matrix of differential operators by $-\lambda^{-1}$ for some fixed (large) parameter $\lambda$. The stiffness matrix $A^{(\lambda)}$ produced from the linearized perturbed system can then serve as preconditioner for the corresponding linear problem in each Newton iteration (in much the same way as in Section 21.7 above).

# 21.10 Towards Domain Decomposition and Multigrid

In the boundary conditions in the Stokes equations, the pressure function $p$ is used only in the mixed conditions in $\Gamma_N$, but not in the Dirichlet conditions in $\Gamma_D$. Therefore, if no mixed boundary conditions are used, that is, $\Gamma_N=\varnothing$, then $p$ is determined up to an additive constant only. To define $p$ properly, one must also use an integral condition of the form

$$\int_{\Omega} p\,dx\,dy = \text{given constant}.$$

In the following, this condition is used to design a domain-decomposition/multigrid algorithm for the Stokes equations.
