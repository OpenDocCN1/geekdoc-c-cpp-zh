# 5.32 FFT and Its Use in Cryptography

The discrete Fourier transform is used often in applied science and engineering. An efficient way to calculate this transform is by the recursive Fast Fourier Transform (FFT), introduced by Cooley and Tukey.

Below we use recursion and dynamic vectors to come up with a particularly straightforward implementation of FFT. Furthermore, we study the performance of FFT and show that it is indeed better than that of the naive algorithm. Still, we also discuss and estimate the storage overhead in FFT.

FFT is particularly useful in multiplying arbitrarily large natural numbers efficiently. As we’ve seen above, this operation is often required in practical algorithms in cryptography.

As discussed above, natural numbers used in cryptography should be so large that they can never be stored in any standard "int" or even "long int" variable. Fortunately, the object-oriented approach comes to our aid once again: after all, we can define our own "number" class (as in Section 5.24) by derivation from an arbitrarily long array of bits. This way, any mathematical algorithm can preserve its original implementation: all that one needs to do is to use "number" rather than "int" in the original template functions. This way, the original algorithm can use huge natural numbers to produce practically unbreakable coding-decoding methods.
