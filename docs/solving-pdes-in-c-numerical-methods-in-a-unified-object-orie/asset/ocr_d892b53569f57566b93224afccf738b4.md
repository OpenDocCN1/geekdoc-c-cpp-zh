# 24.5 Composition of Polynomials

Here we compute the composition p o q of the given polynomials p and q, defined by

(p o q)(x) ≡ p(q(x)).

For this purpose, we use a Horner-like algorithm, in which p is applied to a polynomial rather than to a mere scalar:

```
template<class T>
const polynomial<T>
operator&(const polynomial<T>&p,
    const polynomial<T>&q) {
```

The local polynomial "result" is initialized to be the constant polynomial, whose constant value is the same as the coefficient of the largest x-power in 'p':

```
polynomial<T> result(1,p[p.degree()]);
```

Then, "result" is updated again and again in a loop, as in Horner's algorithm (Section 5.8):

```
for(int i=p.degree(); i>0; i--){ 
    result *= q; 
    result += polynomial<T>(1,p[i-1]); 
} 
return result; 
} // Horner algorithm to compose p and q
```

# 24.6 Recursive Horner Code

p(x) = a₀ + x p₁(x),
