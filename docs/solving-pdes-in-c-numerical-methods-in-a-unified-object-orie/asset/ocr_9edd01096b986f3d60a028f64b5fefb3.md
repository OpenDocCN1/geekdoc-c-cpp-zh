where φ_j = φ_{j+N/2} (0 ≤ j < N/2) is the nodal basis function that has the value 1 at the jth node and vanishes at all the other nodes, and x_j (0 ≤ j < N) is the unknown coefficient of φ_j in the expansion.

In order to obtain the ith equation in the discrete system, 0 ≤ i < N/2, we pick s = φ_i and t ≡ 0. Similarly, the ith equation (N/2 ≤ i < N) is obtained by picking s ≡ 0 and t = φ_{i−N/2}. The discrete stiffness system is, thus,

A x = f,

where A is the stiffness matrix of order N defined below, x is the N-dimensional vector of unknowns, and f is the given N-dimensional vector defined by

f_i = { −∫_Ω F φ_i dx dy   if 0 ≤ i < N/2, −∫_Ω G φ_{i−N/2} dx dy   if N/2 ≤ i < N, }

plus a contribution from the boundary conditions.

# 20.7 The Stiffness Matrix

The stiffness matrix A in the above discrete system can be split into four blocks of order N/2:

A = ( A^{(0,0)}  A^{(0,1)} ; A^{(1,0)}  A^{(1,1)} ).

The four blocks can be calculated as in Chapter 12, Section 5. The only change is that the diagonal matrix diag(P, Q) used there should be replaced here by

( 1  0 ; 0  (1−ν)/2 )

to calculate A^{(0,0)},

( (1−ν)/2  0 ; 0  1 )

to calculate A^{(1,1)},

( 0  (1−ν)/2 ; ν  0 )

to calculate A^{(0,1)}, or

( 0  ν ; (1−ν)/2  0 )

to calculate A^{(1,0)}. This completes the definition of the stiffness matrix.
