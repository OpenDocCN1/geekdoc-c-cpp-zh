# 4.15 Formal Languages

Unlike natural languages, formal languages (such as programming languages or mathematics) are completely objective and have no room for any personal interpretation. Indeed, formal objects are defined uniquely in mathematical terms, possibly using preliminary axioms or lower-level objects that have already been defined earlier. This inductive definition method is discussed below in some more detail.

Although a formal object can be interpreted intuitively from a few different points of view, they must all coincide mathematically and give mathematically equivalent properties and functions. Indeed, the object may be implemented on the computer in several different ways, some more efficient than others. Still, all these potential implementations must be mathematically equivalent to each other and satisfy the original mathematical axioms and properties that make the object what it is.

Thus, to think about a formal object means to realize its mathematical nature: the properties and functions that make it what it is. The best way to do this is to implement the object on the computer. Indeed, this way one may realize the formal structure of the object, including the data it requires and the relations and interactions among them. Choosing a suitable data structure may be particularly helpful to interpret the nature of the object correctly. Furthermore, the properties of the object are best understood once implemented in efficient computer functions, which form an integral part of the implementation of the object.

In summary, thanks to their objective mathematical nature, formal languages are much more stable than natural human languages. Still, even formal languages may require some “atom” objects that are defined only implicitly in terms of elementary axioms. An arbitrarily large hierarchy of more and more complex objects can then be defined recursively, as discussed below.

Below we introduce a mathematical model for learning and interpreting a language. This model is relevant not only to formal languages but also to human languages that are learned in adulthood rather than in childhood. Indeed, such languages are learned by the rational (rather than the intuitive) part of one’s mind.

# 4.16 Inductive Definition and Interpretation

In both natural languages and formal languages, arbitrarily complex objects can be defined and interpreted using lower-level objects that have already been defined earlier or will be defined shortly. This process actually uses mathematical induction. Indeed, to define a highly complex object, one assumes that all less-complex objects have already been defined properly. This way, the definition of the present object may well use any lower-level object.

The above approach is actually the basis for every language, may it be formal or natural. Indeed, the dictionary definition of any word uses words that are assumed to be already well defined and understood by the reader.

The above assumption can actually be viewed as an induction hypothesis. Indeed, assuming that lower-level objects are well understood, they can indeed be used to produce a rather clear and sensible interpretation of the higher-level object that is currently defined.

Thanks to the above assumption or hypothesis, the definition takes a rather transparent and elegant form. Indeed, there is no need to bother with the detailed definitions of the lower-level objects. After all, they are assumed to be well understood. Therefore, they can be used as complete (diamond) objects, allowing full attention to be given to the features of the currently defined object.
