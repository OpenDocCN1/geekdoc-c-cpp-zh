
## 21.9 The Navier–Stokes Equations

Here, we present the Navier–Stokes equations that govern the dynamics of fluids. We assume that the equations are stationary: that is, the process has already converged to a steady state, so no time derivative or time variable is present. The functions depend only on the spatial variables x, y, and z.

The unknown and right-hand-side functions have the same form as in the Stokes equations above. In fact, the only difference between the Stokes and Navier–Stokes systems is in the lower-right block in the coefficient matrix that contains the differential operators. In the following, we describe this difference in detail.

Let Re be a (large) positive parameter that characterizes the problem (the Reynolds number). Define

ε ≡ 1/Re.

The stationary Navier–Stokes equations are given by

⎛ 0   −∇· ⎞ ⎛ p ⎞   ⎛ g ⎞
⎜ ∇  −εΔ+(∇v)ᵀ⎟ ⎜ v ⎟ = ⎜ f ⎟

where Δ stands for the vector Laplacian (the 3 × 3 diagonal matrix with scalar Laplacians on its main diagonal).

Note that the lower-right block in the coefficient matrix that contains the differential operators depends on the yet unknown vector v. Thus, the equations are no longer linear, like the Stokes equations, but rather quasi-linear, as in Chapter 9. In fact, the lower-right block is the three-dimensional analogue of the singularly perturbed conservation law in Chapter 9, Section 11. Thus, the solution may exhibit all sorts of irregular behavior, such as shock and rarefaction waves.

Because the problem is nonlinear, it is natural to use Newton’s iteration (Section 9.16), in which the original system is linearized successively around better and better approximate solutions. The iteration must start from an initial guess that already incorporates the above nonlinear waves. A possible initial guess is the numerical solution produced by the alternating-direction Godunov scheme in Chapter 9, Section 11.

Another possible initial guess can be obtained from the adaptive-refinement algorithm. In this approach, the numerical solution v at a particular mesh is used not only to refine the mesh but also as the initial guess in Newton’s iteration on the next, finer, mesh. In other words, v is used to linearize the system of PDEs around it, refine the current mesh, and initialize the Newton iteration for the corresponding stiffness system on the next, finer, mesh [44].

The stiffness system is recalculated at each level, with piecewise-constant approximation to p as in Section 21.7 above. In the integration by parts used to define the weak formulation, one should bear in mind that the nonlinear term contributes two terms to the bilinear form:

∫Ω v·(∇v)·w dΩ = −∫Ω v·(∇w)·v dΩ −∫Ω (∇·v)v·w dΩ +∫ΓN (v·w)(v·n̄) dΓN
= −∫Ω v·(∇w)·v dΩ +∫Ω g v·w dΩ +∫ΓN (v·w)(v·n̄) dΓN.

[Usually, only half of this term is integrated by parts, to account for a nonlinear boundary term of the form (· · n)u/2 that may be used in the mixed boundary condition. Fortunately, both terms in the above right-hand side are only algebraic (rather than differential) in the unknown vector function u, so they can be discretized and linearized as in Sections 27.5–27.7 below.] The detailed formulation is given in [44].

The original Navier–Stokes system can be perturbed by replacing the zero element in the upper-left corner of the matrix of differential operators by −λ⁻¹ for some fixed (large) parameter λ. The stiffness matrix A^(λ) produced from the linearized perturbed system can then serve as preconditioner for the corresponding linear problem in each Newton iteration (in much the same way as in Section 21.7 above).

## 21.10 Towards Domain Decomposition and Multigrid

In the boundary conditions in the Stokes equations, the pressure function p is used only in the mixed conditions in Γ_N, but not in the Dirichlet conditions in Γ_D. Therefore, if no mixed boundary conditions are used, that is, Γ_N=∅, then p is determined up to an additive constant only. To define p properly, one must also use an integral condition of the form

$$\int_{\Omega} p\,dx\,dy = \text{given constant}.$$

In the following, this condition is used to design a domain-decomposition/multigrid algorithm for the Stokes equations.

To define the multigrid algorithm, it is sufficient to design a prolongation operator P to prolong a coarse-grid function to the entire fine grid. In Figure 21.3 such a coarse-grid function is introduced: its u-values are specified at the corners of the subdomains [where

**Figure 21.3.** *The coarse-grid function to be prolonged.* The values of u=(u^{(1)},u^{(2)}) are available at the corners. The values of p are constant in each subdomain [p^{(t)} at the top subdomain and p^{(b)} at the bottom subdomain.]

![](img/1f293b0ceb2de964310ea7f941a1b580_547_0.png)

**Figure 21.4.** *The first prolongation step, to determine the prolonged u values in each edge by solving a Dirichlet–Neumann subproblem in a thin strip containing it, using the available u-values at the corners as Dirichlet data and the constant p-values at the top and bottom subdomains as Neumann data.*

u = (u^{(1)}, u^{(2)}) is a vector function and its p-values are specified to be constant in each subdomain.

The prolongation operator consists of two steps. In the first step (Figure 21.4), prolonged u-values are defined in each edge of each subdomain. This is done by solving a homogeneous Dirichlet–Neumann Stokes subproblem in a thin strip containing the edge, with Dirichlet data at the left and right edges of the strip taken from the original u-values available there, and Neumann data at the top and bottom edges of the strip. The p-values required in these Neumann boundary conditions also use the original p-values available at the top and bottom edges of the strip (p^{(t)} and p^{(b)}, respectively). For example, at the bottom edge of the strip, the boundary conditions are

-p\vec{n}+\mu((\nabla u)^t+\nabla u)\vec{n}=-p^{(b)}\vec{n}.

Note that it is assumed that u satisfies homogeneous Neumann boundary conditions of the form ∇u = 0 in the top and bottom edges of the strip. This is why no ∇u term appears in the right-hand side of the above formula.

Once u has been prolonged to every edge in every subdomain, we are ready for the second prolongation step to prolong both u and p to the interiors of the subdomains as well (Figure 21.5). For this, we solve in each subdomain a homogeneous Dirichlet Stokes subproblem. The Dirichlet data for each subproblem are taken from the u-values available from the first prolongation step. Furthermore, the additive constant required to determine p in the subdomain uniquely is determined in such a way that it agrees with the original constant p-value available from the coarse-grid function in this subdomain. For example, in Figure 21.5 we use the extra condition

\[\int p\,dx\,dy=\int p^{(b)}\,dx\,dy\]

to determine p uniquely, as required.

This completes the definition of the prolongation operator P, as now both u and p are well-defined in the entire fine grid. The restriction operator is then defined as usual by R = P^t. Finally, the coarse-grid matrix is then defined by Q = RAP. This completes the definition of the multigrid algorithm for the Stokes equations.

The above algorithm can also be extended to other systems of PDEs, such as the Maxwell equations considered below, provided that the coarse grid is sufficiently fine to capture the important oscillations and variations in the solution of the PDE. Unfortunately,
