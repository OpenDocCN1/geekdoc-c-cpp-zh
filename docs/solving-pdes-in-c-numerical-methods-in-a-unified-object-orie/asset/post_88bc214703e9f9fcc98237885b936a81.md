
The complex variable 'I' will be used below in the "FFT()" function to set the template parameter 'S' used there to be "complex". This way, "FFT()" will return a complex vector, as required.

First, we define the local vector "uv" to store the resulting convolution vector:

```cpp
dynamicVector<complex> uv(u.dim()+v.dim()-1,0.);
```

Next, we extend the original vectors 'u' and 'v' into the local vectors 'U' and 'V' (respectively), whose dimension is a power of 2:

```cpp
int power2 = 1;
for(; power2 < uv.dim(); power2 *= 2)

dynamicVector<T> U(power2,0.);
dynamicVector<T> V(power2,0.);
for(int i=0; i<u.dim(); i++)
    U(i) = u[i];
for(int i=0; i<v.dim(); i++)
    V(i) = v[i];
```

We now use FFT and its inverse to calculate the convolution of 'U' and 'V' efficiently and store it in the local vector "UV", whose dimension is a power of 2 as well:

```cpp
dynamicVector<complex> UV = FFT(1,FFT(0,U,I) | FFT(0,V,I),I);
```

The extended vector "UV" is now copied back to the shorter vector "uv", which is then returned as the required output:

```cpp
for(int i = 0; i < uv.dim(); i++)
    uv(i) = UV[i];
return uv;
} // convolution
```

This completes the efficient implementation of the convolution operator using FFT.

## 5.39 FFT in Cryptography

Recall that the class "number" that implements arbitrarily long natural numbers is derived in Section 5.24 above from the base "dynamicVector" class. Still, to benefit from this inheritance, one must be careful to change the type of the scalar argument in "operator*" and "operator/" in the base "dynamicVector" class from 'T' to "double", to avoid ambiguity with the new "operator*" and "operator/" in the derived "number" class. With this correction, the above convolution operator can now be used to multiply two arbitrarily long natural numbers more efficiently:

```cpp
const number operator*(const number& n,
    const number&k){
dynamicVector<complex> NK = n||k;
```

The local complex vector "NK" that contains the convolution of the input numbers 'n' and 'k' is not yet ready to be returned. It must first be converted to an integer vector:

```cpp
dynamicVector<int> nk(NK.dim(),0);
for(int i=0; i<nk.dim(); i++)
    nk(i) = int(NK[i].re() + .1);
```

The integer vector "nk" produced from "NK" is not yet ready to be returned. After all, it must first be converted to a vector of Boolean digits (0 or 1). To have this form, the components in "nk" that are greater than 1 must be shifted ahead to subsequent components that represent coefficients of higher powers of 2:

```cpp
for(int i=0; i<nk.dim()-1; i++){
    nk(i+1) += nk[i] / 2;
    nk(i) %= 2;
}
```

The last component in "nk" may still contain a digit that is greater than 1. In order to shift this digit ahead as well, "nk" must first be extended to a yet longer vector, named "result":

```cpp
int moreBits = 0;
for(int finalDigit = nk[nk.dim()-1];
    finalDigit > 1; finalDigit /= 2)
    moreBits++;
dynamicVector<int> result(nk.dim()+moreBits,0);
for(int i=0; i<nk.dim(); i++)
    result(i) = nk[i];
```

In the extended vector "result", this digit can be shifted ahead as well, as required:

```cpp
for(int i=nk.dim()-1; i<result.dim()-1; i++){
    result(i+1) = result[i] / 2;
    result(i) %= 2;
}
```

Finally, "result" must be converted into a "number" object before being returned:

```cpp
number resultNumber(result.dim(),0);
for(int i=0; i<result.dim(); i++)
    resultNumber(i) = result[i];
return resultNumber;
} // n times k using convolution
```
