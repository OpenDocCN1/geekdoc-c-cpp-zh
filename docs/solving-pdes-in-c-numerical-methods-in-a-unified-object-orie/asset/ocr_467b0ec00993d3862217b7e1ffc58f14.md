```
row<T> radiationI(
    radiationMatrix,I+iblock*nodes);
row<T> radiationJ(
    radiationMatrix,J+iblock*nodes);
*item[I+iblock*nodes] += radiationI;
*item[I+iblock*nodes] += radiationJ;
```

Furthermore, the above boundary terms also contribute to the relevant components in the right-hand side ‘f’:

```
f(I+iblock*nodes) +=
    radiationMatrix
  * x[I+iblock*nodes];
f(I+iblock*nodes) +=
    radiationMatrix
  * x[J+iblock*nodes];
```

Moreover, at mesh points that lie in the left side of the unit box (the side at which x = 0), it is assumed that the right-hand side f̂ in the original system also contains a nonhomogeneous boundary term. Because the right-hand side in the current Newton iteration is f̂ = A(x') − f̂, this term must be subtracted from the corresponding components in ‘f’:

```
if (xBoundary[I]
  * xBoundary[J]
  * xBoundary[K]==1)
  f(I+iblock*nodes) -=
      point(0.,4. * radiation);
}
```

Finally, the Jacobian of the nonlinear term also contributes to the relevant matrix element (Sections 27.5 and 27.6):

```
point J1(integral(threeX2pY2 * Pij),
    integral(twoXY * Pij));
point J2(J1[1],
    integral(X2pThreeY2 * Pij));
matrix2 Jacobian(J1,J2);
row<T> JacobianJ(
    helmholtzNonlin * Jacobian,J+iblock*nodes);
*item[I+iblock*nodes] += JacobianJ;
}
```
