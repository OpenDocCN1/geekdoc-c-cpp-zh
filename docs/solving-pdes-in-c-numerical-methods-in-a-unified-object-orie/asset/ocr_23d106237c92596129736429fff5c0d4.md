In addition, for each edge midpoint, the normal derivative is also considered as an extra degree of freedom. This makes a total of 21 different polynomials of degree five, each of which takes the value 1 for a particular partial derivative (or degree of freedom) and 0 for all the others. Thanks to the fact that there are exactly 21 monomials in each such polynomial, it is indeed possible to compute these polynomials. (See Chapter 28 below.)

A basis function in the mesh is piecewise polynomial: in each triangle, it is defined as the particular polynomial that takes the value 1 for one particular degree of freedom only. For example, the basis function that takes the value 1 only for the xy-partial derivative at a particular node is defined in each triangle that uses this node as a vertex as the suitable polynomial in this triangle that indeed takes the value 1 for the xy-partial derivative at this node only. (See Section 28.14 below.) In particular, the combined basis function vanishes throughout all the triangles that don’t use this node as a vertex.

The same can be done at the edge midpoints: a basis function can be defined from a combination of the two different polynomials defined in the two adjacent triangles that share this edge. As a result, the basis function takes the value 1 for the normal derivative at this edge midpoint, and 0 for all the other degrees of freedom in the entire mesh. (See Section 28.14 below.) Again, the combined basis function vanishes throughout all the triangles that don’t share this edge.

The basis functions described above have an important advantage: they are not only continuous in the entire mesh as in linear, quadratic, and cubic finite elements (Section 12.41 in [69]), but also have continuous gradients in the entire mesh (Section 12.42 in [69]). This makes them better candidates to approximate well the solution to the original PDE. Still, in diffusion problems with discontinuous coefficients P and Q, not the gradient ∇u but rather the flux P u_x + Q u_y should be continuous, so the previous kinds of finite elements may be preferable.
