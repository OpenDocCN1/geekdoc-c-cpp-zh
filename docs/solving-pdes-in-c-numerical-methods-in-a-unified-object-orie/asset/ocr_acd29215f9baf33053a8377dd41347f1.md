# 9.7  Singular Perturbation

Here, we consider the singular perturbation of the Riemann problem, in which a small diffusion term is added to the PDE:

$$-\varepsilon u_{xx}(t,x)+u_t(t,x)+u(t,x)u_x(t,x)=0,\qquad -1<x<1,\ 0<t<\infty.$$

The initial and boundary conditions are as before.

The original Godunov scheme should be modified slightly to apply to this problem. In fact, here the integration along the vertical edges ∂s₂ and ∂s₄ of the square s in Figure 9.4 is also done on the term −εuₓₓ(t,x), so more terms must be added in the calculation of the (i + 1)th time step in Section 9.4. These terms can be added in an explicit, implicit, or semi-implicit way. For simplicity, we consider here only the explicit way, in which the Godunov scheme takes the modified form

```
$$u_{i+1,j}=u_{i,j}-\frac{(\Delta t)\varepsilon}{h^2}\left(2u_{i,j}-u_{i,j-1}-u_{i,j+1}\right)$$
$$\qquad-\frac{\Delta t}{h}\left(f(u_{i+1/2,j+1/2})-f(u_{i+1/2,j-1/2})\right).$$
```

(The half time step is computed as before.) We refer to this scheme as the explicit Godunov scheme.

We have applied this scheme to the singular perturbation of the N-wave problem defined above. In order to maintain stability, we have used ε = h/4. (For larger values of ε, smaller values of Δt or the implicit or semi-implicit scheme must be used.) The results are displayed in Figure 9.8.

It can be seen that the solution has a symmetric and straight N-shape as before. It is only slightly smoothed at the middle point x = 0 due to the extra diffusion term, but the N-shape is still as clear as before.
