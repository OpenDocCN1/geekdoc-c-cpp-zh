### 15.5 Polynomials of Degree Five

Here we consider finite elements that use polynomials of a yet higher order: five. In these finite elements, the basis functions are defined as polynomials of degree five in each finite element (or triangle). Thus, the approximate solution to the original PDE is a polynomial of degree five in each finite element as well.

In a polynomial of degree five, there are 21 different monomials. (See the exercises at the end of Chapter 28.) Therefore, in each finite element (or triangle), there are 21 different polynomials, each of which takes the value 1 for a particular partial derivative at some vertex of the triangle (or some edge midpoint) and 0 for all the other partial derivatives. (See Chapter 28 below.)

At each vertex, partial derivatives of order up to 2 are considered: the zeroth derivative (the original polynomial itself), the first partial derivatives (the x- and y-partial derivatives), and the second partial derivatives (the xx-, xy-, and yy-partial derivatives). This makes a total of six different partial derivatives for each vertex, for a total of 18 different polynomials (see Figure 15.3).

![](img/1f293b0ceb2de964310ea7f941a1b580_429_0.png)

**Figure 15.3.** The 21 degrees of freedom in a triangle: six partial derivatives at each vertex (the zeroth derivative denoted by the bullet, the first partial derivatives denoted by the inner circle, and the second partial derivatives denoted by the outer circle) and the normal derivative (denoted by a small line segment) at the edge midpoints.

In addition, for each edge midpoint, the normal derivative is also considered as an extra degree of freedom. This makes a total of 21 different polynomials of degree five, each of which takes the value 1 for a particular partial derivative (or degree of freedom) and 0 for all the others. Thanks to the fact that there are exactly 21 monomials in each such polynomial, it is indeed possible to compute these polynomials. (See Chapter 28 below.)

A basis function in the mesh is piecewise polynomial: in each triangle, it is defined as the particular polynomial that takes the value 1 for one particular degree of freedom only. For example, the basis function that takes the value 1 only for the xy-partial derivative at a particular node is defined in each triangle that uses this node as a vertex as the suitable polynomial in this triangle that indeed takes the value 1 for the xy-partial derivative at this node only. (See Section 28.14 below.) In particular, the combined basis function vanishes throughout all the triangles that don’t use this node as a vertex.

The same can be done at the edge midpoints: a basis function can be defined from a combination of the two different polynomials defined in the two adjacent triangles that share this edge. As a result, the basis function takes the value 1 for the normal derivative at this edge midpoint, and 0 for all the other degrees of freedom in the entire mesh. (See Section 28.14 below.) Again, the combined basis function vanishes throughout all the triangles that don’t share this edge.

The basis functions described above have an important advantage: they are not only continuous in the entire mesh as in linear, quadratic, and cubic finite elements (Section 12.41 in [69]), but also have continuous gradients in the entire mesh (Section 12.42 in [69]). This makes them better candidates to approximate well the solution to the original PDE. Still, in diffusion problems with discontinuous coefficients P and Q, not the gradient ∇u but rather the flux P u_x + Q u_y should be continuous, so the previous kinds of finite elements may be preferable.

## Part V: The Numerical Solution of Large Sparse Linear Systems of Algebraic Equations

The finite-element discretization method produces a large system of algebraic equations called the stiffness system. The number of equations in this system, N, is as large as the number of nodes in the mesh. Actually, the system can be written algebraically as

Ax = f, where A is the coefficient (stiffness) matrix of order N, f is the given N-dimensional right-hand-side vector, and x is the N-dimensional vector of unknowns. The matrix A is sparse in the sense that most of the elements in it are zero. Once this system is solved numerically, the i-th component in x, x_i, is the value of the numerical solution of the partial differential equation (PDE) at the node of index i in the list of nodes in the mesh. The approximate solution at points that are not in the grid can also be obtained by some interpolation.

The numerical solution of a linear system of the form Ax = f is, thus, an essential part of the numerical solution of PDEs. In the past, before computers became available, this task had to be done manually using Gaussian elimination (Chapter 2, Section 21). Of course, this approach is impractical unless the order of the system is very small.

Fortunately, the digital computer freed the human mind from the exhausting work of such calculations. All that is left for us humans to do is to write a correct and efficient computer program (code) and feed it to the computer.

Since the machine is much more powerful than the human mind in terms of memory and computational ability, it can solve a system with a much higher order. The number of unknowns (or grid points) can be much larger than before and the numerical model much more accurate and realistic. Thus, the digital computer has started a new era in experimental and applied science and engineering.

The opportunity to solve realistic numerical models increased the appetite of scientists and engineers to make further progress and solve even more advanced and complicated applications. Unfortunately, it turns out that the power of the digital computer is not unlimited. When the order of a system is too large, traditional Gaussian elimination is impractical because it requires prohibitively large time and memory resources. In fact, in some cases the computer can work for hours, days, and even weeks before it completes the calculations.

It is therefore essential to use the computational power offered by the computer wisely and develop more efficient algorithms to solve large sparse linear systems of equations. These algorithms must be much more efficient than traditional Gaussian elimination in terms of both time and storage. They must preserve the sparsity of the coefficient matrix A and avoid extensive fill-in. The implementation must take advantage of this sparsity, store only nonzero matrix elements, and disregard zero ones. This is the subject of this part.

This part contains three chapters. In the first one (Chapter 16), the present object-oriented approach is used to implement sparse matrices efficiently along with useful functions such as arithmetic operations. In the second one (Chapter 17), efficient iterative methods for solving large sparse linear systems are presented and implemented. In the third one (Chapter 18), parallel implementation is discussed.
