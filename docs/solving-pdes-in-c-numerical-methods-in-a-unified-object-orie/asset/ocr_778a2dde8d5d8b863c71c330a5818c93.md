The domain Ω in which the original PDE is defined may have a rather complicated and curved boundary ∂Ω. In fact, ∂Ω may be available only implicitly as the zero level set of some given function F:

∂Ω ≡ {(x,y,z) | F(x,y,z) = 0}.

For example, if ∂Ω is to be the sphere that confines the unit cube [0,1]³, then F should be defined by

F(x,y,z) ≡ 3/4 − (x−1/2)² − (y−1/2)² − (z−1/2)² .

In practice, however, F is often given as a computational function rather than as an analytic function. This means that, although it has no closed form, F can still be computed for every given independent variables x, y, and z.

Finding a boundary point on ∂Ω means finding a triplet x, y, and z for which

F(x,y,z) = 0.

When the derivatives of F are available, Newton's iteration can be used for this purpose. In the more general case in which F may be available as a computational function only, the golden-ratio algorithm implemented in Section 1.20 above can still be used to maximize the function −F² to find a boundary point.
