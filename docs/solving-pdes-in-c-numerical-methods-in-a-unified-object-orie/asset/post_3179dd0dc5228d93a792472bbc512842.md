## 29.2 Dirichlet Boundary Condition as a Constraint

The Dirichlet boundary conditions that are imposed on the original PDE can be viewed as an external constraint imposed on the minimization problem in Figure 29.1. If, for example, the Dirichlet boundary condition is imposed at the point a in the domain in which the function v is defined, then it takes the form of the linear constraint equation

```
L(v) ≡ v(a) = specified value.
```

Thanks to the linearity of the functional L, every level set of the form

```
{v | L(v) = const.}
```

L(v) ≡ v(a) ≡ x = −2.5

is illustrated.

The solution u of the constrained minimization problem minimizes g among those functions v ∼ (x, y) that satisfy the constraint, or lie on the constraint line. This is why u can no longer lie at the center as in Figure 29.1: it must lie on the constraint line, which is away from the center.

From the viewpoint of a viewer who “lives” inside the constraint line and whose world is limited to the constraint line only, the constrained problem takes the same form as an unconstrained problem defined within the constraint line. This is why the solution u of the constrained problem must lie at the “center” of the constraint line. More precisely, it must lie at the unique point at which the constraint line is tangent to a circle in Figure 29.2. At this point, the gradient of g (the outer normal to the circle in Figure 29.2) must have the same direction as the gradient of the constraint functional L, which is perpendicular to the constraint line. In other words, there must be a scalar λ for which

∇g(u) = −λ∇L.

## 29.3 The Gradient as a Linearization

When the domain in which u is defined is finite, ∇g(u) has a geometrical meaning: it is the outer normal to the level set of g at u, defined by

{v | g(v) = g(u)}

(the circle in Figure 29.2). Similarly, ∇L is the vector perpendicular to the level set of L:

{v | L(v) = L(u)}

(the vertical line in Figure 29.2). In fact, the value of L can be obtained in terms of an inner product with the gradient:

L(v) = (∇L, v).

Thus, the linear functional L can actually be identified with its gradient ∇L.

In more general cases, in which the domain in which v is defined may be infinite, ∇g(u) is the linear functional that approximates g best in a small neighborhood of u:

g(u + v) = g(u) + ∇g(u)(v) + O(|v|²).

For linear functionals like L, in particular, we have

L(u + v) = L(u) + L(v),

so the gradient is independent of u:

∇L = L.

Thus, the equation at the end of Section 29.2 above simplifies to read

∇g(u) = −λL.

## 29.4 Lagrange Multiplier

As discussed above, both sides of the above equation can be interpreted as linear functionals that can be applied to just any function v:

a(u,v) - f(v) = -λL(v).

This form is useful in finding the solution u. This setting is useful not only in our simple case but also in more general cases. Indeed, from the Hahn–Banach theorem, it follows that the constrained minimization problem indeed has a unique solution u. To find it, one can now solve the extended equation
a(u,·) - f = -λL,
where the extra unknown λ is called the Lagrange multiplier [22].

## 29.5 The Algebraic System: An Example

Returning to our simple case, in which

L(v) ≡ v(a) ≡ x,

we have

∇L = \left( \begin{array}{c} 1 \\ 0 \end{array} \right).

Therefore, in this case, the above equation takes the simpler form

a(u,v)-f(v)=-λ \left( \begin{array}{c} 1 \\ 0 \end{array}, \begin{array}{c} x \\ y \end{array} \right) = -λx = 2.5λ

for every v ~ (x,y). This gives two independent equations: one with v ~ (1,0) and the other with v ~ (0,1). Together with the original constraint

L(u) ≡ u(a) = -2.5,

we have a system of three equations in the three unknowns u(a), u(b), and λ. The solution of this 3×3 linear system gives us the unique solution u illustrated geometrically in Figure 29.2. The Lagrange multiplier λ (which is also calculated when this system is solved) is then dropped and never used again.
