# A.33 Setting Dirichlet Boundary Conditions

Here we show how Dirichlet boundary conditions can be imposed on the Dirichlet boundary Γ_D ⊂ ∂Ω. For this purpose, we assume that there is a vector "DirichletBoundary", with the value 0 at components that correspond to mesh points in Γ_D and 1 at all the other components. To eliminate the components with the value 0 from the list of unknowns, the corresponding rows in the original coefficient matrix should be masked by the "DirichletBoundary" vector.

To mask a given row by a given vector named "mask", we need to declare two more member functions in the block of the "row" class in Section 16.3 above:

