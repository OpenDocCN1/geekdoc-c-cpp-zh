# 12.2  The Discrete Weak Formulation

The triangulation of the domain Ω, denoted by T, induces a subspace of piecewise-linear continuous functions on which the original weak formulation is approximated. This subspace, denoted by V, contains the functions that are continuous in T and linear in each particular triangle in it.

With the notation in Chapter 11, Section 2, the discrete form of the weak formulation is as follows: find a function **ũ** in V that agrees with G at every node in Γ₀ and also satisfies

$$a(\tilde{u},v)=f(v)$$

for every function v in V that vanishes at every node in Γ₀. We refer to the above problem as the discrete weak formulation or discrete problem.

In fact, the discrete problem can be viewed as the restriction of the original weak formulation to V. As we'll see below, the number of degrees of freedom (or unknowns) in the discrete problem is the same as the number of nodes in T. Thus, it can be solved numerically on a digital computer.

# 12.3  The Stiffness System

Let us now rewrite the discrete weak formulation in an algebraic form that can be implemented on a computer. For every node j in the triangulation T, let φⱼ be the function in V that has the value 1 at j and 0 at all the other nodes in T. In other words, φⱼ vanishes on every triangle in T except those triangles that use j as a vertex, where φⱼ decreases linearly from j toward the edge that lies across from it, where it vanishes. The function φⱼ is also called the nodal basis function corresponding to j.

In what follows, ũ denotes the solution to the discrete weak formulation. In fact, ũ can be written as a sum over all the nodes in T:

$$\tilde{u}=\sum_{j\in T}x_j\phi_j,$$

where the unknown scalars xⱼ are the same as ũ(j) (the value of ũ at node j). Clearly, because ũ agrees with G at nodes in Γ₀, we have xⱼ = ũ(j) = G(j) for j ∈ Γ₀, so these xⱼ's are already known; the rest of the xⱼ's, which correspond to j's that don't lie on Γ₀, are yet to be solved for.
