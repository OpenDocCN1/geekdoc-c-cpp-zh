Such an approach may make sense for a general mesh that has been generated by some unknown process, but not in the present context, in which this process is well known. One might want to take advantage of the original adaptive-refinement process and let the coarse mesh in the multigrid hierarchy be the same as the original coarse mesh from which the current fine mesh has been formed in the first place. (See Chapter 12 in [68].)

The prolongation operator that transforms a function \(w\) defined on the nodes in the coarse mesh into a fine-grid function \(Pw\) defined on the fine nodes as well can then be designed in a domain-decomposition approach as in Section 17.13 or 21.10, with the sub-domains being, e.g., just coarse finite elements in the coarse mesh. This approach may work not only for the Stokes system but also for the Navier–Stokes and Maxwell systems. Here, however, we introduce a yet more straightforward prolongation operator, which is also suitable for these three systems of PDEs.
