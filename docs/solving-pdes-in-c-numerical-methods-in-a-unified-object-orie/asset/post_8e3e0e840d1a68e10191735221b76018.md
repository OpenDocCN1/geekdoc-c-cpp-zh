This completes the function that also refines the neighbor tetrahedra that share the edge leading from "nI" to "nJ". This function is used in the refinement step below.

The following function implements the entire refinement step: it scans the tetrahedra in the coarse mesh and refines them by dividing one of their edges. In practice, only those edges over which the discrete solution varies sharply should be divided. Here, however, we assume for simplicity that all the coarse edges are divided.

In this nested loop, the integers 'i' and 'j' represent distinct indices of nodes in the first tetrahedron, "item". More precisely, we must find a way to refer to these corners by finding their indices 'k' and 'l' in the list of corners in "item":

while((l==i) || (l==j) || (l==k))

## 26.7 Nonrecursive Refinement in a Complicated Domain

Recursive functions may be prohibitively expensive, especially in terms of storage. After all, the arguments used in each recursive call must be stored in a rather large stack. This is why we implement the refinement step in a nonrecursive version as well. Furthermore, this version is suitable for a general domain Ω with a complicated boundary ∂Ω as well. (It is assumed here that Ω is convex; otherwise, the approach in Figure 14.12 should also be considered.)

The domain Ω in which the original PDE is defined may have a rather complicated and curved boundary ∂Ω. In fact, ∂Ω may be available only implicitly as the zero level set of some given function F:

∂Ω ≡ {(x,y,z) | F(x,y,z) = 0}.

For example, if ∂Ω is to be the sphere that confines the unit cube [0,1]³, then F should be defined by

F(x,y,z) ≡ 3/4 − (x−1/2)² − (y−1/2)² − (z−1/2)² .

In practice, however, F is often given as a computational function rather than as an analytic function. This means that, although it has no closed form, F can still be computed for every given independent variables x, y, and z.

Finding a boundary point on ∂Ω means finding a triplet x, y, and z for which

F(x,y,z) = 0.

When the derivatives of F are available, Newton's iteration can be used for this purpose. In the more general case in which F may be available as a computational function only, the golden-ratio algorithm implemented in Section 1.20 above can still be used to maximize the function −F² to find a boundary point.
