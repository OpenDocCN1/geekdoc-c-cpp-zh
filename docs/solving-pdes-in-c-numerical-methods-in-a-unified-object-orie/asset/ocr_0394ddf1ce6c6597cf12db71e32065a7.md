# 5.35  The Naive Implementation

Let us first implement the Fourier transform and its inverse in the naive way. It is assumed that the original vector **f** has components of type ‘T’, which may be the “complex” type, the “double” type, the “int” type, etc. The returned vector, on the other hand, has components of type ‘S’, which may be different from ‘T’. Usually, ‘S’ is the “complex” type. Still, ‘S’ is not yet specified; this way, it may be a more complicated type in more advanced applications.

The argument "type" is used to specify ‘S’. In the applications below, "type" is going to be a “complex” object, thereby setting ‘S’ to be “complex” as well, as required.

The integer argument "inverse" determines which transform is applied. If it vanishes, then the original Fourier transform is applied. If, on the other hand, "inverse" == 1, then the inverse transform is applied:

```
template<class T, class S>
const dynamicVector<S>
FT(int inverse, const dynamicVector<T>&f,
   const S&type)
   dynamicVector<S> result(f.dim(),0.);
   double angle = 8. * atan(1.) / f.dim();
   const complex
      w(cos(angle),(2*inverse-1) * sin(angle));
```

The local complex variable ‘w’ contains wₙ (if "inverse" = 0) or w̄ₙ (if "inverse" = 1). Next, the polynomial f() is formed and stored in the local "polynomial" object "ff":

```
complex wi=1.;
polynomial<T> ff(f.dim());
for(int i=0; i<f.dim(); i++)
   ff(i) = f[i];
```

Horner’s algorithm is then used to sample "ff" at the powers of ‘w’ and place the results in the returned vector "result":

```
for(int i=0; i<f.dim(); i++){
   result(i) = HornerPolynomial(ff,wi);
   wi *= w;
}
return inverse ?
             result / result.dim()
           : result;
}  // naive Fourier transform
```

This completes the naive implementation of the Fourier transform and its inverse.

This naive implementation requires the evaluation of the polynomial f() at 1, wₙ, wₙ², ..., wₙⁿ⁻¹. Because each such evaluation requires O(n) arithmetic operations, the total number of arithmetic operations is O(n²). This amount may be prohibitively large for large n.
