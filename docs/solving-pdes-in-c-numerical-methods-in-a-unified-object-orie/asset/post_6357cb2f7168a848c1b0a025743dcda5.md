
## 23.12 The Multigrid Fusion Algorithm

To define the multigrid fusion algorithm, let us return to the formula that is the basis for the defect-correction formula:

$$A_1(\tilde{x}+\tilde{e}) - A_1(\tilde{x}) = f - A(\tilde{x}).$$

Here, however, $f$ is inaccurate, so we are more interested in the approximation

$$A_1(\tilde{x}+\tilde{e}) - A_1(\tilde{x}) \doteq f - A(\tilde{x}),$$

where ‘$\doteq$’ stands for approximation.

Fortunately, it is assumed here that $A$ is easily invertible. Therefore, it makes sense to choose

$$\tilde{x} \equiv A^{-1}(f).$$

Furthermore, the coarse-grid operator $A_1$ is defined by

$$A_1 \equiv A P Q^{-1} R A.$$

Moreover, the coarse-grid correction term $\tilde{e}$ is defined implicitly in such a way that

$$A_1(\tilde{x}+\tilde{e}) = A(P U),$$

where $U$ is obtained by applying the multigrid fusion algorithm recursively to the coarse grid rather than to the fine grid. The coarse-grid right-hand-side vector $F$ used in this recursive application is assumed to be more accurate than the naive choice $R f$. For example, $F$ could be produced from $R f^{(1)}, R f^{(2)}, \dots, R f^{(m)}$ by applying the above max() function:

$$F \equiv \max(R f^{(1)}, R f^{(2)}, \dots, R f^{(m)}).$$

This way, $F$ indeed contains the sources and sinks associated with the coarse grid. Still, $F$ may fail to contain the sources and sinks associated with further coarser grids in the multigrid hierarchy. This is why the coarse-grid problem is again a mere approximation that uses ‘$\doteq$’ rather than an equation that uses ‘$=$’.

Thus, $U$ is assumed inductively to be the optimally fused image in terms of sources and sinks not only at the coarse grid (like the naive solution $Q^{-1}(F)$) but also at further coarser grids as well. Only if there are no coarser grids (the two-level case, in which the coarse grid is also the coarsest grid), $U$ is defined simply by

$$U \equiv Q^{-1} F.$$

In the three-level (or multilevel) case, on the other hand, $U$ is defined only implicitly as the result of the multigrid fusion algorithm applied recursively to the coarse (rather than fine) grid.

As a result, we have the formula

$$A(P U) - A(P Q^{-1}(R f)) + A(A^{-1}(f)) \doteq f.$$

If $A$ is indeed linear as in the discrete Laplacian, then this simplifies to read

$$A\left(P U - P Q^{-1} R f + A^{-1} f\right) \doteq f.$$

Thus, the multigrid fusion algorithm advises us to accept the fine-grid image

$$P U - P Q^{-1} R f + A^{-1} f,$$

where $U$ is obtained by applying the same multigrid fusion algorithm recursively on the coarse grid [82].

The term

$$A^{-1}f - P Q^{-1} R f = (A^{-1} - P Q^{-1} R)f$$

in the above formula can be viewed as a defect correction that is added to the naive fine-grid approximation $PU$ obtained from the naive prolongation of the best available coarse-grid approximation $U$.

The following binary operator multiplies all the items in a list by a constant object of any type:

```cpp
template<class S, class T>
const list<T>
operator*(const S&R, const list<T>&l){
    list<T> R1(l.size(), R * l[0]);
    for(int i=1; i<l.size(); i++)
        R1(i) = R * l[i];
    return R1;
} // matrix times list
```

In the above loop, the items in the local list "R1" are accessed by the nonconstant "operator()" in Chapter 3, Section 3.4, and are defined as 'R' times the corresponding items in the original list 'l'. The above operator can indeed be used in the multigrid fusion algorithm to restrict the original list of right-hand-side vectors to the coarse grid by multiplying them (from the left) by the restriction matrix R.
