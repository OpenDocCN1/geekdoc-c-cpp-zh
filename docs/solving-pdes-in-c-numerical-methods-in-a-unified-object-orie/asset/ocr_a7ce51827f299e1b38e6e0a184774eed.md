# Chapter 31

# Application in the
Navier–Stokes Equations

In this chapter, we use the present object-oriented framework to form a numerical solver for the Navier–Stokes system of nonlinear PDEs in an adaptive mesh of tetrahedra. Linear finite elements are used to discretize the velocity functions, and constant finite elements are used to discretize the pressure function. Newton’s iteration is then used to linearize the nonlinear term. An inner GMRES iteration is used to solve the linear system in each Newton iteration. Unfortunately, a point Gauss–Seidel or Jacobi preconditioner cannot be used within GMRES due to the zero main-diagonal elements in the lower-right block in the coefficient matrix. Instead, we use the Kacmarz preconditioner or a multigrid preconditioner that uses Kacmarz relaxation.

# 31.1 The Strong Formulation

The Navier–Stokes system of nonlinear PDEs has already been discussed briefly in Section 21.9 above in the context of two-dimensional problems. In a three-dimensional domain of the form

Ω ⊂ (−∞,∞)³

the system still has the same strong formulation:

v ≡ (v₁(x, y, z), v₂(x, y, z), v₃(x, y, z))ᵗ
