```
const number&
operator+=(number&n, const number&k) {
    add(n,k,0,k.length());
    return n;
}  //  add a number
```

This "+ =" operator is in turn used in the following ‘+’ operator that doesn’t change its arguments:

```
const number
operator+(const number& n, const number&k) {
    if(n.length()>=k.length()) {
        number a(n);
        return a += k;
    }
    else{
        number a(k);
        return a += n;
    }
}  //  n plus k
```

Furthermore, the "+ =" operator is also used (in conjunction with the constructor that converts a standard integer into a "number" object) to increment ‘n’ by 1 and return the result:

```
const number& operator++(number&n) {
    return n += number(1);
}  //  add 1
```

As a matter of fact, here one could equally well write "n+ 1" and let the above constructor invoke implicitly to convert the standard integer ‘1’ into the "number" object "number(1)".

Similarly, the above "subtract()" function is used to define the following "- =" operator:

```
const number&
operator-=(number&n, const number&k) {
    subtract(n,k,0,k.length());
    return n;
}  //  subtract a number
```

This "- =" operator is in turn used in the following ‘-’ operator that doesn’t change its arguments:

```
const number
operator-(const number& n, const number&k) {
    number a(n);
    return a -= k;
}  //  n minus k
```
