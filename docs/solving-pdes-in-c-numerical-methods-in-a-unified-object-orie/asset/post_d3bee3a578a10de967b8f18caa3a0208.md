
This way, ‘X’ contains the real part of the current numerical approximation to the "iblock"th component of the electricity field in the current tetrahedron (mapped onto the unit tetrahedron), and ‘Y’ contains the imaginary part. More precisely, with the notation in Section 27.5.

```
`X' + sqrt(-1) Y' = P_t('x'),`
```

where t is the current tetrahedron in the loop. The polynomials ‘X’ and ‘Y’ will be useful to discretize the nonlinear term later on. Furthermore, we’ll also need some linear combinations of the squares of these polynomials:

```
polynomial<polynomial<polynomial<double> > >
    X2 = X * X;
polynomial<polynomial<polynomial<double> > >
    Y2 = Y * Y;
X2pY2 = X2 + Y2;
threeX2pY2 = 3. * X2 + Y2;
X2pThreeY2 = X2 + 3. * Y2;
twoXY = 2. * X * Y;
```

The local scalar variable "helmNonlin" is the product of the (external) coefficient of the nonlinear mass term and the determinant of the 3 × 3 matrix ‘S’ that maps the current tetrahedron onto the unit tetrahedron:

```
double helmNonlin=HELMNonlin*fabs(det(S));
```

In the following nested loop over the four corners of the current tetrahedron, the nonlinear mass term first contributes to the right-hand side ‘f’ in the current Newton iteration (at components that correspond to the "iblock"th component of the electricity field):

```
for(int i=0; i<4; i++){
    int I = (*runner())[i].getIndex();
    f(I+iblock*nodes) += helmNonlin *
        pointIntegral(X2pY2 * X * P[i]),
        integral(X2pY2 * Y * P[i]);
    for(int j=0; j<4; j++){
        int J = (*runner())[j].getIndex();
        polynomial<polynomial<polynomial<double> > >
            Pij = P[i] * P[j];
```

Furthermore, in the inner loop over the corners, the exercises at the end of Chapter 24 are used to calculate the contribution to the corresponding matrix element:

```
for(int jblock=0;jblock<3;jblock++) {
    double helmBlock =
        (iblock == jblock) ? helm : 0.;
    matrix3 derive =
        (iblock == jblock) ? I3 : Z3;
    derive(iblock,jblock,"write") -= 1.;
```

Here, the elements of the 3 × 3 matrix "derive" are set using the proper "operator()" in Section 2.23 above. This way, "derive" distinguishes properly between different blocks in the matrix and can be used to calculate the correct contribution "addIJ" to the relevant matrix element:

```
matrix3 weight=
    fabs(det(S)/6.) * Sinverse *
    derive * transpose(Sinverse);
T addIJ = helmBlock +
    gradient[j]*weight*gradient[i];
if(item[I+iblock*nodes]){
    row<T> r(addIJ,J+jblock*nodes);
    *item[I+iblock*nodes] += r;
}
else
    item[I+iblock*nodes] =
        new row<T>(addIJ,J+jblock*nodes);
```

Moreover, the corresponding component in ‘f’ is updated as well:

```
f(I+iblock*nodes) +=
    addIJ * x[J+jblock*nodes];
}
```

This completes the loop over the block columns in the matrix. Still, as in Section A.28, we also need to assemble the contributions from the boundary term:

```
for(int k=0; k<4; k++){
    int K = (*runner)()[k].getIndex();
    if((i!=j)&&(j!=k)&&(k!=i)
        &&((xBoundary[I] * xBoundary[J] *
        xBoundary[K]==1)||(xBoundary[I] *
        xBoundary[J] * xBoundary[K]==8))){

            - (*runner)()[i]();

            - (*runner)()[i]();

            * l2norm(jMinusi&kMinusi) / 24.;
        T radiationMatrix(
            point(0.,radiation),
            point(-radiation,0.));
```

```
row<T> radiationI(
    radiationMatrix,I+iblock*nodes);
row<T> radiationJ(
    radiationMatrix,J+iblock*nodes);
*item[I+iblock*nodes] += radiationI;
*item[I+iblock*nodes] += radiationJ;
```

Furthermore, the above boundary terms also contribute to the relevant components in the right-hand side ‘f’:

```
f(I+iblock*nodes) +=
    radiationMatrix
  * x[I+iblock*nodes];
f(I+iblock*nodes) +=
    radiationMatrix
  * x[J+iblock*nodes];
```

Moreover, at mesh points that lie in the left side of the unit box (the side at which x = 0), it is assumed that the right-hand side f̂ in the original system also contains a nonhomogeneous boundary term. Because the right-hand side in the current Newton iteration is f̂ = A(x') − f̂, this term must be subtracted from the corresponding components in ‘f’:

```

  * xBoundary[J]
  * xBoundary[K]==1)
  f(I+iblock*nodes) -=
      point(0.,4. * radiation);

```

Finally, the Jacobian of the nonlinear term also contributes to the relevant matrix element (Sections 27.5 and 27.6):

```

    integral(twoXY * Pij));
point J2(J1[1],
    integral(X2pThreeY2 * Pij));

    helmholtzNonlin * Jacobian,J+iblock*nodes);

## A.33 Setting Dirichlet Boundary Conditions

Here we show how Dirichlet boundary conditions can be imposed on the Dirichlet boundary Γ_D ⊂ ∂Ω. For this purpose, we assume that there is a vector "DirichletBoundary", with the value 0 at components that correspond to mesh points in Γ_D and 1 at all the other components. To eliminate the components with the value 0 from the list of unknowns, the corresponding rows in the original coefficient matrix should be masked by the "DirichletBoundary" vector.

To mask a given row by a given vector named "mask", we need to declare two more member functions in the block of the "row" class in Section 16.3 above:

```
template<class S>
const S maskTail(const dynamicVector<int>&,
    const dynamicVector<S>&);
template<class S>
const S maskAll(const dynamicVector<int>&,
    const dynamicVector<S>&);
```

The "maskTail" function works in the same way as the recursive "truncateTail" function in Section 3.6 above:

```
template<class T>
template<class S>
const S row<T>::maskTail(
    const dynamicVector<int>& mask,
    const dynamicVector<S>& f) {
S sum=0.;
```

There are only two changes: first, the criterion for dropping a row element is no longer its small magnitude but rather the fact that the corresponding component in the vector argument "mask" vanishes:

```

    if(!mask[(*next)().getColumn()] ) {
```

The second change is that the function not only drops the elements masked by "mask", but also computes recursively the sum of the dropped elements, each multiplied by the corresponding component in the vector argument 'f':

```
sum = (*next)().getValue() *
    f[(*next)().getColumn()];
    dropNextItem();
    sum += maskTail(mask, f);

else
    sum = (*(row<T>*)next).maskTail(mask, f);

```

Similarly, just as the function "truncateItems" at the end of Section 3.6 calls the "truncateTail" function, the function "maskAll" below calls the above "maskTail" function:

```

    const dynamicVector<int>& mask,
    const dynamicVector<S>&f) {

Here, however, there is also a returned value: the sum of the dropped elements, each multiplied by the corresponding component in the vector argument ‘f’:

```

    sum += getValue() * f[getColumn()];
    dropFirstItem();
}
return sum;
}  // mask a row
```

```

First, equations in the original system

that correspond to mesh points in Γ_D are replaced by trivial equations of the form

\tilde{x}_i = \tilde{f}_i :

```

    if(!DirichletBoundary[i])
    *item[i] = row<T>(1.,i);

In view of this, one must make sure well in advance that these components of "tildeF" corresponding to mesh points in Γ_D indeed agree with the Dirichlet boundary data. Furthermore, the corresponding component of the right-hand-side vector ‘f’ in the current Newton iteration must vanish:

This must be implemented in the constructor in the previous section.
