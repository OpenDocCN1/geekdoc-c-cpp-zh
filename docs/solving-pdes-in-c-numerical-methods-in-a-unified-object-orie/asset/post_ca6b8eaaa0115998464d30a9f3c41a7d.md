## Chapter 30
## Towards Inverse Problems

In the PDEs discussed so far in this book, the domain is known in advance. In an inverse problem, on the other hand, the domain may not be fully known. In fact, there may be infinitely many potential domains to choose from. The required domain is the one for which the solution of the PDEs best meet some observed data that are available in advance.

To find a sufficiently accurate approximation to the correct domain, an iterative method is used. In the initial iteration, some initial guess is used to approximate the unknown domain. This approximate domain is then improved iteratively as follows. In each iteration, the PDE is solved numerically on the current approximate domain, and the numerical solution is compared to the original observed data and used to improve the approximate domain further. The improved approximate domain is then used in the next iteration to solve the PDE numerically once again, and so on.

Clearly, the above method requires the numerical solution of the PDE in each iteration, on the approximate domain available in this iteration. Fortunately, the present adaptive-refinement and multigrid algorithms can be used for this purpose for many kinds of PDEs, including the (nonlinear) Helmholtz and Maxwell equations.

### 30.1 Missing Data

Well-posed PDEs are defined in a given domain, with given boundary conditions on its boundary. The required solution is a function that not only satisfies the PDE in the interior of the domain but also meets the given conditions on its boundary. For elliptic problems, a unique solution exists. In other words, the boundary conditions can indeed be interpolated to form the function that indeed satisfies the PDE throughout the entire domain.

In time-dependent parabolic and hyperbolic problems, on the other hand, initial conditions must also be specified in advance in the entire domain in the initial time. The solution is then a time-dependent function that not only satisfies the PDE in the interior of the domain at any time but also meets the boundary conditions at any time and the initial conditions at the initial time.

In inverse problems, on the other hand, some datum is missing. For example, a boundary or initial condition may be missing from the original setting of the PDE. The problem is then not only to solve a PDE but first of all to set this missing parameter to its optimal value.

### 30.2 Unspecified Domain

Assume that an elliptic PDE is given in a domain Ω, with, say, mixed boundary conditions on its boundary ∂Ω. However, Ω is not specified uniquely: it depends on a yet unknown parameter, such as the depth of the slit in Figure 22.3. The problem is then not only to solve the original boundary-value problem in Ω, but first of all to specify this parameter in an optimal way.

### 30.3 Extra Observed Data

To compensate for the missing parameter, we assume that we have an extra piece of information available in advance. For example, we assume that the value u^(o)(z_0) of the solution at some boundary point z_0 ∈ ∂Ω is known in advance by, say, some preliminary observation. In the model in Figure 22.4, for example, z_0 could lie on the right edge of the nearly rectangular domain. In the model in Figure 22.5, on the other hand, z_0 could lie on the circular part of the boundary.

### 30.4 Minimizing the Error

For each particular choice of the missing parameter, the domain Ω has a slightly different shape. For each such domain, one could solve the well-posed PDE numerically and come up with the numerical approximation u^(n)(z_0) for the solution at z_0 ∈ ∂Ω.

Clearly, the optimal value for the parameter is the one for which the error

|u^(n)(z_0)-u^(o)(z_0)|

is minimal. In fact, this error is a scalar function of the parameter. Thus, the golden-ratio algorithm implemented in Section 1.20 can be used to find an optimal parameter that minimizes (locally) this error function.

Furthermore, if observed data are available not only at z_0 but also at the boundary points z_1,z_2,…,z_k ∈ ∂Ω (for some k ≥ 1), then the above error can be replaced by the squared average error

∑_{i=0}^{k}|u^(n)(z_i)-u^(o)(z_i)|^2.

The golden-ratio algorithm can then be used to find the optimal value of the parameter that minimizes (locally) this error function. This value has a better chance to meet the true value of the unknown parameter, as it projects a rather accurate solution not only at z_0 but also at the boundary points z_1,z_2,…,z_k.

### 30.5 Polluted Cloud

In the above, the inverse problem is to discover an unknown parameter that is important to define the domain properly. In the measuring problem in Section 22.7, for example, the aim is to discover the correct depth of the slit. As we’ve seen above, a sufficiently accurate approximation to the true depth of slit can be obtained iteratively. Indeed, the golden-ratio iteration can be used to minimize the error function defined as the absolute value of the difference between the numerical solution and the observed solution at some boundary point away from the slit. The depth of slit for which this error is minimized is then accepted as the true depth of slit.

The same approach can also be used to discover the true values of other parameters that are important in practical applications. In Section 6.15, for example, an inverse problem as in Section 30.1 is solved to find the parameter a0, which is just one of the initial conditions for the ODE considered there. In this application, no observed datum is needed: the optimal a0 is the derivative at the initial time r = 0 for which the solution remains bounded for as long as possible.

Another parameter of practical interest that can be found by solving an inverse problem is the concentration of pollution in a cloud in the atmosphere. Unlike in Section 30.2 above, this inverse problem is aimed not at discovering the domain, which is this time completely available in advance in terms of the shape of the cloud, but rather at measuring the pollution only. Indeed, since the pollution affects the (nonlinear Helmholtz) PDE, finding it may be formulated in terms of an inverse problem as well.

Thus, the golden-ratio iteration in Section 1.20 can be used in this case as well. In the first iteration, an initial guess is used to approximate the concentration of pollution poorly. This poor guess is used to formulate the nonlinear Helmholtz equation in the cloud in the initial iteration only. It is assumed that a laser beam is sent towards the cloud from a satellite that lies just above the cloud. This beam is returned to the satellite to be measured and supply the required observed data.

The error function is then defined as the absolute value of the difference between this measurement of the true returned beam and the numerical value of the numerical returned beam obtained from the numerical solution of the nonlinear Helmholtz equation with the current (rather poor) approximation of the concentration of pollution. In each iteration, this approximation is improved, yielding a more accurate nonlinear Helmholtz equation to be solved in the next iteration, and so on. The resulting golden-ratio iteration converges to a sufficiently accurate concentration of pollution, for which the numerical returned beam calculated from the numerical solution of the PDE agrees with the true returned beam with a sufficiently small error. This final approximation to the concentration of pollution is then accepted as the true concentration of pollution.

Clearly, in each iteration, a nonlinear Helmholtz equation should be solved in the cloud. Fortunately, this can be done rather efficiently using the present adaptive-refinement and multigrid algorithms, implemented in the present object-oriented framework.

### 30.6 Numerical Microscope

As we’ve seen above, the problem of measuring the depth of a slit in Section 22.7 can be formulated as an inverse problem. The iterative method to solve this problem may actually be viewed as a numerical microscope. Indeed, since the slit is narrower than the wavelength of any visible light, including the wavelength of any laser beam, the depth of the slit cannot be measured directly but only numerically as the solution of the inverse problem.

This approach can be extended further to form a numerical microscope to “see” not only the depth of a slit in a tiny object but also the complete structure of a nanoscale object.
