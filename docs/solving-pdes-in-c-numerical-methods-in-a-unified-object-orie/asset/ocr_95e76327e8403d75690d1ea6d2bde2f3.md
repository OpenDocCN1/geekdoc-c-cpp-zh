# 19.2 The Finite-Element Mesh

The finite-element mesh is constructed by the adaptive-refinement algorithm with automatic boundary refinement (Chapter 14, Section 8). The initial mesh contains 11 nodes and 9 triangles only, providing a rather poor approximation of the domain and its boundary (Figure 19.2). Still, this mesh will improve gradually during the refinement process and eventually have sufficient resolution both in the interior of the domain and at the boundary. Clearly, one could use some extra triangles at the circular part of the boundary to start from a better initial mesh.

Global refinement can be used by setting the threshold in Chapter 14, Section 3, to 0. This approach, however, is not very practical. Indeed, the number of nodes grows so rapidly that it becomes as large as 427,000 already in the 9th level. Adaptive local refinement is clearly necessary.

In Figure 19.3, one can see how the mesh refines in the first 14 levels of refinement. Thanks to the adaptive refinement and the automatic boundary refinement, the mesh refines not only in the interior of the domain but also near the circular boundary. The nodes are particularly clustered around the irregular part of the boundary (at which Dirichlet boundary conditions are given).

The threshold used in the adaptive refinement may change dynamically from level to level, as in Section 26.8 below. This approach seems to provide a rather good accuracy in the model problem tested there, and allows using a quite large number of levels. Of course, one could use a yet smaller threshold to add more nodes in each level of refinement.
