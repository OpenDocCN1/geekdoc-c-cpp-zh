The (i + 1)th time step is then produced from the (i + 1/2)th time step in the same way that the (i + 1/2)th time step was produced from the ith time step. Note that the random number θ may assume different values at different time steps. This completes the definition of the random-choice scheme.

# 9.6 The N-Wave

The N-wave is the solution u(T, x) (at a sufficiently large time T) of the following version of the Riemann problem:

```
u_t(t,x) + u(t,x) u_x(t,x) = 0,    -1 ≤ x ≤ 1, 0 < t < ∞
```

with sinusoidal initial conditions of the form

```
u(0,x) = - sin(π x)
```

and periodic boundary conditions of the form

```
u(t, -1) = u(t, 1),    0 ≤ t < ∞
```

The reason for this name is that the solution has the shape of the letter N in English. Here, we solve for the N-wave numerically and indeed observe this shape.

We use the Godunov scheme with Δt = h/2 on a 200 × 200 time-space grid and obtain the results in Figure 9.6. The solution at the 200th time step indeed has a symmetric and straight N-shape, as required.
