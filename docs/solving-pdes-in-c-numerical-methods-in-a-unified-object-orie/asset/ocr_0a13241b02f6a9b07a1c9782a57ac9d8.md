# A.26 Computing Partial Derivatives

The following code constructs the (partial) derivatives of polynomials of one, two, or three variables. implemented in Chapter 24. First, we define the function that computes and returns the kth derivative of a polynomial of one variable. For this purpose, we use the function "C()" defined at the end of Section 1.17.

```
template<class T>
const polynomial<T>
d(const polynomial<T>&p, int k){
    if(k>p.degree())
        return polynomial<T>(1,0.);

```

If k is larger than the degree of the polynomial, then its kth derivative is just the zero polynomial. If, on the other hand, k is smaller than or equal to the degree of the polynomial, then the kth derivative is returned in the local polynomial object "dp" defined below:

```
polynomial<T> dp(p.degree()+1-k,0.);
for(int n=0; n<=dp.degree(); n++)
    dp(n) = C(n+k,k) * p[n+k];
return dp;
} // kth derivative
```

The above function is now used to compute the (j,k)th partial derivative of a polynomial of two variables:

```
template<class T>
const polynomial<polynomial<T> >
d(const polynomial<polynomial<T> >&p, int j, int k){
    polynomial<T> zero(1,0.);
    if(k>p.degree())
        return polynomial<polynomial<T> >(1,zero);
```

Note that here "p.degree()" is the largest y-power in 'p'. Therefore, if 'k' is larger than "p.degree()", then the zero polynomial is returned, and the function terminates. Otherwise, the function uses the previous version of "d()" to compute the 'j'th derivative of the coefficients in 'p', which are polynomials of one variable:

```
print(integral(P[0]*P[1]*P[2]));
printf("\n");
print(integral(P[1]*P[2]*P[3]));
printf("\n");
print(integral(P[2]*P[3]*P[0]));
printf("\n");
print(integral(P[3]*P[0]*P[1]));

return 0;
}
```
