# 26.3 Adaptive Mesh Refinement

Usually, the initial mesh is too coarse to approximate well the curved three-dimensional domain Ω, in which the original PDE is given. At least one refinement step is therefore necessary to improve on the initial coarse mesh and produce a yet finer and more accurate mesh.

In the refinement step, some of the tetrahedra in the coarse mesh are divided into two subtetrahedra. In fact, only those edges in the coarse mesh over which the discrete solution varies sharply are divided, whereas the other edges remain undivided in the fine mesh as well. This procedure is called adaptive mesh refinement.

# 26.4 Preserving Conformity in the Finer Mesh

It is assumed that the initial coarse mesh is conformal in the sense that two adjacent finer mesh must share an entire edge on each side with each other. To make sure that the finer mesh is conformal as well, one must be careful to divide not only the discrete solution jumps but also all the coarse tetrahedra that share it. This way, the midpoint of this edge serves as the joint corner of all the subtetrahedra resulting from dividing the coarse tetrahedron that share it. With this approach, the finer mesh resulting from the refinement step is conformal as well, as required. This procedure is implemented below, using the present object-oriented approach.
