# ## 29.4 Lagrange Multiplier

As discussed above, both sides of the above equation can be interpreted as linear functionals that can be applied to just any function v:

a(u,v) - f(v) = -λL(v).

This form is useful in finding the solution u. This setting is useful not only in our simple case but also in more general cases. Indeed, from the Hahn–Banach theorem, it follows that the constrained minimization problem indeed has a unique solution u. To find it, one can now solve the extended equation
a(u,·) - f = -λL,
where the extra unknown λ is called the Lagrange multiplier [22].

# ## 29.5 The Algebraic System: An Example

Returning to our simple case, in which

L(v) ≡ v(a) ≡ x,

we have

∇L = \left( \begin{array}{c} 1 \\ 0 \end{array} \right).

Therefore, in this case, the above equation takes the simpler form

a(u,v)-f(v)=-λ \left( \begin{array}{c} 1 \\ 0 \end{array}, \begin{array}{c} x \\ y \end{array} \right) = -λx = 2.5λ

for every v ~ (x,y). This gives two independent equations: one with v ~ (1,0) and the other with v ~ (0,1). Together with the original constraint

L(u) ≡ u(a) = -2.5,

we have a system of three equations in the three unknowns u(a), u(b), and λ. The solution of this 3×3 linear system gives us the unique solution u illustrated geometrically in Figure 29.2. The Lagrange multiplier λ (which is also calculated when this system is solved) is then dropped and never used again.
