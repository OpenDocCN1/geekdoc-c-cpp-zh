This completes the refinement step that improves the original coarse mesh and produces the finer mesh of tetrahedra.

# 26.7 Nonrecursive Refinement in a Complicated Domain

Recursive functions may be prohibitively expensive, especially in terms of storage. After all, the arguments used in each recursive call must be stored in a rather large stack. This is why we implement the refinement step in a nonrecursive version as well. Furthermore, this version is suitable for a general domain Ω with a complicated boundary ∂Ω as well. (It is assumed here that Ω is convex; otherwise, the approach in Figure 14.12 should also be considered.)

First, let us introduce the nonrecursive version of the "refineNeighbors" member function, which divides the edge leading from the node "nI" to the node "nJ" at its midpoint "nIJ". In the process, all the tetrahedra that share this edge are divided as well. Note that the code below contains the prefix "template<>" before the function. This way, the code compiles well not only with old compilers but also with GNU Version 3.2 and higher.
