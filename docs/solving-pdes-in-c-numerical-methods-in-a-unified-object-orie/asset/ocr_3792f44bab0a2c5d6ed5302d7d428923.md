# ## 24.12 Integral on the Unit Tetrahedron

Consider now a polynomial of three variables $p(x,y,z)$. Assume that both $x$ and $y$ are fixed numbers, so $p(x,y,z)$ is actually a polynomial of one variable only. Let $P$ be the indefinite integral of this polynomial (Section 24.9). Thus, $P \equiv P(x,y,z)$, where $x$ and $y$ are fixed parameters, and $z$ is the only variable.

Let us now use $P$ to calculate the integral of $p$ over the unit tetrahedron in Figure 27.1:

$$\int_0^1\int_0^{1-x}\int_0^{1-x-y} p(x,y,z)\,dz\,dy\,dx = \int_0^1\int_0^{1-x} P(x,y,1-x-y)\,dy\,dx.$$

To form the polynomial of two variables $1-x-y$, we write it as

$$1-x-y=(1-x)y^0+(-1)y^1.$$

Thus, to form $1-x-y$, we have to use the constructor that takes two polynomial arguments: the polynomial of one variable $1-x$ and the constant polynomial $-1$. To form the constant polynomial $-1$, we call the constructor that takes the integer argument $1$ (to indicate that this is a polynomial of degree $0$) and the “double” argument $-1$ (to specify the coefficient):

```
```cpp
polynomial<T> minus1(1,-1.);
```
```

To form the polynomial $1-x$, on the other hand, we call the constructor that takes two “double” arguments to specify the two coefficients:

```
```cpp
polynomial<T> oneMinusx(1.,-1.);
```
```

Finally, to form the required polynomial of two variables $1-x-y$, we call the constructor that takes two polynomials of one variable, $1-x$ and $-1$:

```
```cpp
polynomial<polynomial<T> >
oneMinusxMinusy(oneMinusx,minus1);
```
```

The “indefiniteIntegral” function is now applied to the original polynomial $p(x,y,z)$ to produce its indefinite integral with respect to $z$ (denoted by $P(x,y,z)$ in the above formula). The original “operator()” of Section 24.6 (with both ‘S’ and ‘T’ being polynomials of two variables) is then applied to it, to calculate it at the fixed argument $z=1-x-y$ and to produce the polynomial of two variables $P(x,y,1-x-y)$. Finally, this polynomial is integrated over the unit triangle, using the “integral()” version of the previous section:

```
```cpp
