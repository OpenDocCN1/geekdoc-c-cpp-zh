To illustrate how the values $u_{i+1/2,j+1/2}$ at the half time step are calculated, let us return to our case, in which

$f(u(t,x)) = \frac{1}{2}u^2(t,x).$

In this case, we have

$u_{i+1/2,j+1/2} \equiv \begin{cases} u_{i,j} & \text{if } u_{i,j} > u_{i,j+1} \text{and } (u_{i,j}+u_{i,j+1})/2 \ge 0 \\ \text{(local shock wave traveling to the right),} \\ u_{i,j+1} & \text{if } u_{i,j} > u_{i,j+1} \text{and } (u_{i,j}+u_{i,j+1})/2 < 0 \\ \text{(local shock wave traveling to the left),} \\ u_{i,j} & \text{if } 0 \le u_{i,j} \le u_{i,j+1} \\ \text{(local rarefaction wave traveling to the right),} \\ u_{i,j+1} & \text{if } u_{i,j} \le u_{i,j+1} \le 0 \\ \text{(local rarefaction wave traveling to the left),} \\ 0 & \text{if } u_{i,j} < 0 < u_{i,j+1} \\ \text{(local rarefaction wave).} \end{cases}$

In order to use the half time step, we also need to define the values $u_{i+1/2,1/2}$ and $u_{i+1/2,N+1/2}$ at the endpoints. Using the periodic boundary conditions, this can be done either as before or by

$u_{i+1/2,1/2} \equiv u_{i+1/2,N-1/2} \quad \text{and} \quad u_{i+1/2,N+1/2} \equiv u_{i+1/2,3/2}.$

This completes the definition of the Godunov scheme.

# 9.5 The Random-Choice Scheme

Here, we describe the random-choice scheme [72] for the solution of the Riemann problem

$u_t(t,x) + u(t,x)u_x(t,x) = 0, \quad -1 \le x \le 1, \ 0 < t < \infty,$

with general initial conditions

$u(0,x) = u_0(x)$

and periodic boundary conditions. In this scheme, the half time step is also calculated by solving small local Riemann problems as in Figure 9.5. This, however, is done in a slightly different way: a random number $-1 < \theta < 1$ is picked at each half time step, and $u_{i+1/2,j+1/2}$ takes the value of the solution to the local Riemann problem in Figure 9.5 at the point $(j+1/2+\theta/2)h$. More precisely, the random-choice scheme is defined by

$u_{i+1/2,j+1/2} \equiv \begin{cases} u_{i,j} & \text{if } u_{i,j} > u_{i,j+1} \text{and } \theta h/\Delta t \le (u_{i,j}+u_{i,j+1})/2 \\ \text{(local shock wave),} \\ u_{i,j+1} & \text{if } u_{i,j} > u_{i,j+1} \text{and } \theta h/\Delta t \ge (u_{i,j}+u_{i,j+1})/2 \\ \text{(local shock wave),} \\ u_{i,j} & \text{if } \theta h/\Delta t \le u_{i,j} \le u_{i,j+1} \\ \text{(local rarefaction wave),} \\ u_{i,j+1} & \text{if } u_{i,j} \le u_{i,j+1} \le \theta h/\Delta t \\ \text{(local rarefaction wave),} \\ \theta h/\Delta t & \text{if } u_{i,j} < \theta h/\Delta t < u_{i,j+1} \\ \text{(local rarefaction wave).} \end{cases}$
