For any polynomial of three variables p(x, y, z) defined in t, let p^(i,t) denote its degree of freedom at the midpoint of D_t(s), or its directional derivative (in the direction specified by the three-dimensional column vector S_t N_s Y_{t,s}) at the midpoint of D_t(s). With our default choice, in particular, we have

```
p^(i,t) = p_x (D_t (midpoint of s)).
```

Let us verify that, for the side-midpoint basis function defined above, this degree of freedom is indeed as required:

```
R_{i,t}^{(i,t)} = 1.
```

Indeed,

```
∇^t R_{i,t} S_t N_s Y_{t,s} = Ŷ_{t,s}^{-1} ∇^t r_{i,t} S_t N_s Y_{t,s}
= Ŷ_{t,s}^{-1} ((∇^t p_i) ∘ D_t^{-1}) S_t^1 S_t N_s Y_{t,s}
= Ŷ_{t,s}^{-1} (((∇^t p_i) ∘ D_t^{-1}) N_s) Y_{t,s}.
```

From the discussion at the beginning of this section, it follows that, when evaluated at the midpoint of D_t(s), the middle term in this triple product reduces to the three-dimensional row vector (1,0,0), so the entire triple product takes the value 1, as required.

This completes the definition of the side-midpoint basis functions in t. Below we use these functions to define edge-midpoint basis functions as well.

# 28.10 Edge-Midpoint Basis Functions

As discussed above, the edge-midpoint functions R_{i,t} (40 ≤ i < 52) are not really basis functions, because they may still have nonzero degrees of freedom. More precisely, they may have a nonzero directional derivative at the midpoints of the adjacent sides. Fortunately, this problem can now be fixed by subtracting suitable multiples of the corresponding side-midpoint basis functions. This is done by the substitution

```
R_{i,t} ← R_{i,t} − Σ_{j=52}^{55} R_{i,t}^{(j,t)} R_{j,t}
```

(40 ≤ i < 52). Indeed, after this substitution, the directional derivative of the edge-midpoint function R_{i,t} vanishes at all the side midpoints in t, as required. Furthermore, this substitution makes no change to the other degrees of freedom, which remain correct. As a result, the functions R_{i,t} (40 ≤ i < 52) can now be rightly called edge-midpoint basis functions.

# 28.11 Corner Basis Functions

Similarly, both the edge-midpoint and side-midpoint basis functions can now be used to fix the corner functions R_{i,t} (0 ≤ i < 40) and modify them to be proper basis functions:

