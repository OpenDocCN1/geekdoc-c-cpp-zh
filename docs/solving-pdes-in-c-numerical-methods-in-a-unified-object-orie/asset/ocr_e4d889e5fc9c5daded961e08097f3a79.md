# 25.2 The One-Dimensional Case

In one dimension, the nonlinear Helmholtz equation is actually an ODE:

−u′′(x)+Ku(x)+K1|u(x)|2u(x)=0

in the unit interval

x∈(0,1),

where K and K1 are given complex parameters with nonnegative real parts. (Note that the parameter K used here plays the role of the coefficient −4π2K2 used in Chapter 22, Section 22.2.) To make the problem well posed, mixed complex boundary conditions are imposed at the endpoints x=0 and x=1:

−u′(0)+√Ku(0)=2√K and u′(1)+√Ku(1)=0.

Note that, when K is real and negative, √K=i√|K|.

The above boundary-value problem in the finite interval [0,1] is obtained in [4] from a problem defined in the semi-infinite interval [0,∞) by truncating it at 1 and imposing artificial boundary conditions at 1 to allow a periodic solution. In the original problem in [0,∞), the boundary condition at ∞ is that u remains bounded. However, this problem can also be viewed as an initial-value problem in the timelike variable x≥0. This way, one can use the method of Section 6.15 above to find a suitable second initial condition about the initial derivative u′(0) with which u remains bounded for as long as possible and is therefore either asymptotic in the sense that it converges (to 0) as x→∞ or at least periodic as x→∞.

Still, here we stick to a boundary-value problem in a finite interval as in [4], which can be extended to a PDE in a finite two-dimensional (and indeed three-dimensional) domain as in [3] and in subsequent chapters in this book.

The linear case K1=0 in the above boundary-value problem in the interval [0,1] has the unique solution

u(x)=exp(−√Kx).

In the nonlinear case K1≠0, on the other hand, as well as for problems with non-homogeneous boundary conditions or right-hand side, no closed-form solution is available. In such cases, a discretization scheme must be used to solve the equation numerically rather than analytically. The original ODE is then approximated in the form of the algebraic system

A(v)=b,

where N is the number of points in the discrete grid, b is a given N-dimensional (possibly complex-valued) vector, v is the N-dimensional (possibly complex-valued) vector of unknowns, and A is a given operator. For example, in the linear case K1=0, A is an N×N (possibly complex-valued) matrix.

# 25.3 The Error and the Truncation Error

Let w be the N-dimensional vector obtained by sampling u(x) at the grid points. The error is then defined as the N-dimensional vector that is the difference between w and v:

error=w−v.
