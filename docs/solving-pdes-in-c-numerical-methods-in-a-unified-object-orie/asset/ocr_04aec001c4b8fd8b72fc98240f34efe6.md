uniquely as a linear combination of the basis functions:

```
p(x, y, z) = Σ_{i=0}^{55} p^{(i)} p_i(x, y, z)
```

or

```
p ≡ Σ_{i=0}^{55} p^{(i)} p_i
```

where the scalar p^{(i)} is the i th degree of freedom of p. In particular, the i th basis function, p_i, has only one nonzero degree of freedom, p_i^{(i)} = 1:

```
p_i^{(j)} = { 1 if j = i, 0 if j ≠ i }
```

(0 ≤ j < 56).

# 28.2 Basis Functions in the Reference Tetrahedron

The triplets of the form (i, j, k) used to index the coefficients a_{i, j, k} of a polynomial of degree 5, p(x, y, z), form the discrete tetrahedron

```
T^{(5)} ≡ {(i, j, k) | 0 ≤ i, j, k, i + j + k ≤ 5}.
```

Let us order these triplets in the lexicographic order; that is, (i, j, k) is prior to (l, m, n) if either (a) i < l or (b) i = l and j < m or (c) i = l and j = m and k < n. Let us use the index 0 ≤ î_{i, j, k} < 56 to index these triplets in this order. Using this index, we can form the 56-dimensional vector of coefficients x̄:

```
x̄_{î_{i, j, k}} ≡ a_{i, j, k},    (i, j, k) ∈ T^{(5)}.
```

The same approach can be used to order the triplets in the smaller discrete tetrahedron

```
T^{(2)} ≡ {(l, m, n) | 0 ≤ l, m, n, l + m + n ≤ 2}.
```

In this case, once the triplets of the form (l, m, n) are ordered in the lexicographic order, the index 0 ≤ î_{l, m, n} < 10 is used to index them in this order.

To represent a basis function p_q for some integer 0 ≤ q < 56, we need to specify its coefficients a_{i, j, k}, or the components of x̄. Unfortunately, these coefficients are rarely available explicitly. In order to find them, we must use every piece of information we may have about p_q, including its available degrees of freedom. More precisely, we must solve a linear system of algebraic equations, in which x̄ is the vector of unknowns:

```
B x̄ = I^{(q)}
```

where I^{(q)} is the q th column of the identity matrix of order 56, and B is the 56 × 56 matrix defined by the relations

```
p_q^{(i)} = Σ_{j=0}^{55} B_{i, j} x̄_j = { 1 if i = q, 0 if i ≠ q }
```

0 ≤ i, q < 56.
