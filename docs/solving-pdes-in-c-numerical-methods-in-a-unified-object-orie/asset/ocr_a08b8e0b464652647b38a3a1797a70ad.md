Furthermore, the "- =" operator is also used in the following "--" operator, which decrements its argument by 1:

```
const number& operator--(number&n) {
    return n -= number(1);
}  // subtract 1
```

This completes the implementation of the arithmetic operators with "number" objects.

Finally, here is a function that takes a moderate "number" object (of order 10^5) and converts it into a standard integer:

```
const int in(const number&n){
    int result = n[n.length()-1];
    for(int i=n.length()-2; i>=0; i--){
        result *= 2;
        result += n[i];
    }
    return result;
}  // conversion to int
```

It is not recommended to implement this function as an "operator int" member function within the block of the "number" class, because then it would be used by the compiler to convert "number" objects to standard integers not only explicitly but also implicitly (with no notice whatsoever), which might not be what the programmer intended.

# 5.25 The RSA Algorithm with Long Numbers

Here is how the above "number" class can be used to implement the RSA algorithm in Section 5.23 with arbitrarily long numbers. It is assumed here that 'N' is a large external "number" object.

```
int main(){
    number q = findPrime(N-1);
    number p = findPrime(q-1);
    number n = p * q;
    number phi = (p-1) * (q-1);
    number e = coprime(phi);
    number d = invertMod(e,phi);
    number m = 999999;
    printf("m=%d\n",in(m));
    number c = powerMod(m,e,n);
    printf("recovered message=%d\n",in(powerMod(c,d,n)));
    return 0;
}
```
