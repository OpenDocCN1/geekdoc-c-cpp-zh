```
const sparsePolynomial
operator*(const monomial&a,const sparsePolynomial&p){
return sparsePolynomial(p) *= a;
} // monomial times sparse polynomial
```

Furthermore, the "+ =" operator inherited from the base "linkedList" class in Chapter 3, Section 3.5, can be used to add a sparse polynomial to the current sparse polynomial. When the monomials in these polynomials are well-ordered according to increasing power, the sum of polynomials is well-ordered also. This "+ =" operator is now used further to multiply two sparse polynomials:

```
const sparsePolynomial
operator*(const sparsePolynomial&p,
const sparsePolynomial&q){
sparsePolynomial result = q * p;
if(q.readNext()){
sparsePolynomial rest = 
*(const sparsePolynomial*)q.readNext() * p;
result += rest;
}
return result;
} // sparse polynomial times sparse polynomial
```

It is straightforward to extend the above also to polynomials of N independent variables, where N is a fixed integer that may be greater than 1 (see Chapter 25 in [69]). First, monomials of N variables are implemented as a pair whose first field is of type 'T' and second field is of type "vector<int,N>". This way, the "monomial" class is a template class with two unspecified parameters: 'T', the type of coefficient, and 'N', the number of independent variables.

The second field in the above pair contains the indices used in the monomial. For example, when N = 2, the monomial a_i x^i y^j is implemented in the pair (a_i, (i, j)). The sparse polynomial is then implemented as a linked list of monomials, ordered lexicographically: (i1, j1) < (i2, j2) if and only if i1 < i2 or i1 == i2 and j1 < j2. Once the corresponding "operator<" is implemented in the class "vector<int,N>", the "+ =" operator inherited from the base "linkedList" class in Chapter 3, Section 3.5, can be used to add two sparse polynomials while preserving order. The above "operator*" can then be used to multiply two sparse polynomials of N independent variables.
