
```cpp
template<class T>
const polynomial<T>
operator+(const polynomial<T>& p,
    const polynomial<T>&q) {
    polynomial<T> keep = p;
    return keep += q;
} // add two polynomials
```

## 24.3 Multiplication by a Scalar

The next operator multiplies a polynomial by an object of type ‘S’, to be specified later by the user. (Usually, ‘S’ is a mere scalar, still, below we’ll see that it can also be a more complicated object.) More precisely, the first argument, the nonconstant polynomial ‘p’, is multiplied by the second argument, ‘a’, which is an object of type ‘S’:

```cpp
template<class T, class S>
const polynomial<T>&
operator*=(polynomial<T>& p, const S&a){
    for(int i=0; i<=p.degree(); i++)
        p(i) *= a;
    return p;
} // multiplication by a scalar
```

In the above loop, the "operator()" is used to access the coefficients of ‘p’ and multiply them by ‘a’ by the "*=" operator that is relevant to the ‘T’ class. With the above function, users can write "p *= d" to multiply the well-defined polynomial ‘p’ by a scalar ‘d’ of any type.

The above function is now used to define scalar-times-polynomial and polynomial-times-scalar multiplications:

```cpp
template<class T, class S>
const polynomial<T>
operator*(const S&a, const polynomial<T>&p){
    polynomial<T> keep = p;
    return keep *= a;
} // scalar times polynomial
```

```cpp
template<class T, class S>
const polynomial<T>
operator*(const polynomial<T>&p, const S&a){
    polynomial<T> keep = p;
    return keep *= a;
} // polynomial times scalar
```

With these functions, the user can write "p * d" or "d * p" to have the product of the well-defined polynomial ‘p’ and a scalar ‘d’ of any type.

## 24.5 Composition of Polynomials

Here we compute the composition p ∘ q of the given polynomials p and q, defined by

(p ∘ q)(x) ≡ p(q(x)).

For this purpose, we use a Horner-like algorithm, in which p is applied to a polynomial rather than to a mere scalar:

```cpp
template<class T>
const polynomial<T>
operator&(const polynomial<T>&p,
    const polynomial<T>&q) {
```

The local polynomial "result" is initialized to be the constant polynomial, whose constant value is the same as the coefficient of the largest x-power in 'p':

```cpp
polynomial<T> result(1,p[p.degree()]);
```

Then, "result" is updated again and again in a loop, as in Horner's algorithm (Section 5.8):

```cpp
for(int i=p.degree(); i>0; i--){ 
    result *= q; 
    result += polynomial<T>(1,p[i-1]); 
} 
return result; 
} // Horner algorithm to compose p and q
```

## 24.6 Recursive Horner Code

Next, we calculate the value p(x) of a given polynomial p of degree n at a given argument x. For this purpose, we use the recursive formula

p(x) = a₀ + x p₁(x),

where p₁ is a polynomial of degree n − 1. In fact, this formula is nothing but the Horner algorithm in a recursive setting. To implement it efficiently, the trick is to avoid constructing or storing p₁ explicitly.

The function "HornerArray" that implements the above idea has already been declared as a member function of the "polynomial" class to allow other member functions to call it, which will prove useful below. Furthermore, the type of the third argument 'x' has been declared as the template class 'S', to be specified later by the user. This provides extra flexibility, since 'S' may be different from 'T':

```cpp
template<class T>
template<class S>
const T
polynomial<T>::HornerArray(T** const&p,
    int n, const S&x) const{
```

The first argument in the function, ‘p’, stands for the array of pointers-to-coefficients in the polynomial p of degree ‘n’. Therefore, "p+1" is nothing but the array of pointers-to-coefficients of the polynomial p₁ of degree "n−1", used in the recursion:

```cpp
return n ==0 ?
    *p[0]
    :
    *p[0] + x * HornerArray(p+1,n-1,x);
} // recursive Horner code
```

Thanks to the fact that the "item" field is declared as protected (rather than private) in the base "list" class, it can be accessed from the derived "polynomial" class as well. The "operator()" function defined below uses this property to apply the above "HornerArray" function to the array "item" to produce the required value of the current polynomial at the argument ‘x’:

```cpp
template<class T>
template<class S>
const T
polynomial<T>::operator()(const S&x) const{
    return HornerArray(item,degree(),x);
} // Horner algorithm to calculate a polynomial
```

With this operator, the user can write "p(x)" to have the value of the well-defined polynomial ‘p’ at a given argument ‘x’.

## 24.7 Polynomials of Two Variables

To implement a polynomial of two variables, one only needs to specify ‘T’ to be a polynomial in its own right. Here we use this implementation to calculate the value of a polynomial of two variables

p(x,y) ≡ Σᵢ aᵢ(x) yⁱ

at some given arguments x and y:

```cpp
template<class T>
template<class S>
const S
polynomial<T>::operator()(const S&x,
    const S&y) const{
    return (*this)(y)(x);
} // compute p(x,y)
```

This function calls the original "operator()" of Section 24.6 twice. In the first call, the argument y is used to obtain the polynomial of one variable p(·,y), where y is a fixed number. In the second call, the argument x is used to compute the required number p(x,y).

## 24.10 Integral on the Unit Interval

The above function is now used to integrate a polynomial of one variable over the unit interval [0,1], using the formula

$$\int_{0}^{1} p(x)dx = P(1) - P(0) = P(1),$$

where P is the indefinite integral defined in the previous section:

```cpp
template<class T>
const T
integral(const polynomial<T>&p) {
  return indefiniteIntegral(p)(1.);
} // integral on the unit interval
```

Indeed, after "indefiniteIntegral" is called to compute P, "operator()" is invoked to calculate the required number P(1).

## 24.11 Integral on the Unit Triangle

Consider now a polynomial of two variables p(x,y). Assume that x is a fixed number, so p(x,·) is actually a polynomial of one variable only. Let P be the indefinite integral of this polynomial (Section 24.9). Thus, P ≡ P(x,y), where x is a fixed parameter, and y is the only variable.

Let us now use P to calculate the integral of p over the unit triangle in Figure 5.5:

$$\int_{0}^{1}\int_{0}^{1-x} p(x,y)dy dx = \int_{0}^{1} P(x,1-x)dx.$$

This formula is indeed implemented below:

```cpp
template<class T>
const T
integral(const polynomial<polynomial<T> >&p) {
```

First, we use the constructor that takes two "double" arguments to form the polynomial 1−x: This polynomial is then stored in a local polynomial object named "oneMinusx":

```cpp
polynomial<T> oneMinusx(1., -1.);
```

Next, the "indefiniteIntegral" function is applied to the original polynomial `p` to form the indefinite integral with respect to y (denoted by P in the above formula). Then, "operator()" of Section 24.6 is applied to P(x,y) (with the polynomial argument 1−x) to substitute 1−x for y and produce P(x,1−x). Indeed, the argument of "operator()" can be not only a mere scalar but also a polynomial of one variable, so the template class `S` in Section 24.6 is interpreted as a polynomial of one variable as well. Finally, the original version of "integral()" is applied to P(x,1−x) to integrate over the unit interval:

```cpp
return
  integral(indefiniteIntegral(p)(oneMinusx));
} // integral on the unit triangle
```

## 24.12 Integral on the Unit Tetrahedron

Consider now a polynomial of three variables $p(x,y,z)$. Assume that both $x$ and $y$ are fixed numbers, so $p(x,y,z)$ is actually a polynomial of one variable only. Let $P$ be the indefinite integral of this polynomial (Section 24.9). Thus, $P \equiv P(x,y,z)$, where $x$ and $y$ are fixed parameters, and $z$ is the only variable.

Let us now use $P$ to calculate the integral of $p$ over the unit tetrahedron in Figure 27.1:

$$\int_0^1\int_0^{1-x}\int_0^{1-x-y} p(x,y,z)\,dz\,dy\,dx = \int_0^1\int_0^{1-x} P(x,y,1-x-y)\,dy\,dx.$$

This formula is indeed implemented below:

```cpp
template<class T>
const T
integral(const
    polynomial<polynomial<polynomial<T> > >&p){
```

To form the polynomial of two variables $1-x-y$, we write it as

$$1-x-y=(1-x)y^0+(-1)y^1.$$

Thus, to form $1-x-y$, we have to use the constructor that takes two polynomial arguments: the polynomial of one variable $1-x$ and the constant polynomial $-1$. To form the constant polynomial $-1$, we call the constructor that takes the integer argument $1$ (to indicate that this is a polynomial of degree $0$) and the “double” argument $-1$ (to specify the coefficient):

```cpp
polynomial<T> minus1(1,-1.);
```

To form the polynomial $1-x$, on the other hand, we call the constructor that takes two “double” arguments to specify the two coefficients:

```cpp
polynomial<T> oneMinusx(1.,-1.);
```

Finally, to form the required polynomial of two variables $1-x-y$, we call the constructor that takes two polynomials of one variable, $1-x$ and $-1$:

```cpp
polynomial<polynomial<T> >
oneMinusxMinusy(oneMinusx,minus1);
```

The “indefiniteIntegral” function is now applied to the original polynomial $p(x,y,z)$ to produce its indefinite integral with respect to $z$ (denoted by $P(x,y,z)$ in the above formula). The original “operator()” of Section 24.6 (with both ‘S’ and ‘T’ being polynomials of two variables) is then applied to it, to calculate it at the fixed argument $z=1-x-y$ and to produce the polynomial of two variables $P(x,y,1-x-y)$. Finally, this polynomial is integrated over the unit triangle, using the “integral()” version of the previous section:

```cpp
return
    integral(indefiniteIntegral(p)(oneMinusxMinusy));
}   // integral on the unit tetrahedron
```
