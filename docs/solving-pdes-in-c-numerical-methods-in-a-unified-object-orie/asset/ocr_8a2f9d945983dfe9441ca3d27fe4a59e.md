Third, let us assemble the linearized term in Section 31.4. For this purpose, we need to store the vector function v (the approximate solution in the current Newton iteration) and the gradient ∇v_{iblock+1}. Fortunately, this gradient is constant in the current tetrahedron, and is therefore independent of the corner 'i' or 'j'.
