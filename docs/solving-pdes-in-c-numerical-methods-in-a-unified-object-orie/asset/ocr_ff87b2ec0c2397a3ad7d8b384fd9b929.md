To have a more explicit formulation of this Jacobian, let us use Cramer’s rule and the definition of minor in Section 3.15. Recall that the minor A^{[i,j]} is obtained from the original matrix A by dropping the jth row and the ith column. Furthermore, let

|A| = det(A)

denote the determinant of the matrix A. From Cramer’s rule, the partial derivative of |A| with respect to a_{k,l} (or the (k,l)th component in the gradient of |A|) is

(∂|A|/∂A)_{k,l} ≡ ∂|A|/∂a_{k,l} = (-1)^{k+l} |A^{[k,l]}| = |A| A^{-1}_{l,k}.

This can be written more compactly as

∂|A|/∂A = |A| A^{-T}.

Using the chain rule once again, we have

∂|A|^{-1}/∂A = d|A|^{-1}/d|A| · ∂|A|/∂A = -|A|^{-2}|A| A^{-T} = -|A|^{-1} A^{-T}.

This formula will be particularly helpful below.

To form the required Jacobian, we also need to define the tensor S as follows. If k = j or l = i, then

S_{i,j,k,l} = 0.

If, on the other hand, k ≠ j and l ≠ i, then S_{i,j,k,l} is defined from a minor of a minor of A, obtained by dropping both the jth and kth rows and both the ith and lth columns from the original matrix A. More precisely, it is assumed that S is skew-symmetric under the index permutation j ↔ k or i ↔ l:

S_{i,j,k,l} = -S_{i,k,j,l} = -S_{l,j,k,i} = S_{l,k,j,i}.

Therefore, without loss of generality, we may assume that

j > k and i > l.

In this case, S_{i,j,k,l} is defined by

S_{i,j,k,l} ≡ |A|^{-1} (-1)^{i+j+k+l} |(A^{[j,i]})^{[k,l]}| = (-1)^{i+j}|A|^{-1}|A^{[j,i]}| (-1)^{k+l}|A^{[j,i]}|^{-1}|(A^{[j,i]})^{[k,l]}| = A^{-1}_{i,j} (A^{[j,i]})^{-1}_{l,k}.
