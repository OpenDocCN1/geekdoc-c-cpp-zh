
Let $b \subset \partial M$ be the part of the boundary on which mixed boundary conditions are imposed. Let us denote the triangle $s \in b$ by

$s \equiv \Delta(\vec{k}, \vec{l}, \vec{m}),$

where $\vec{k}, \vec{l},$ and $\vec{m}$ are those nodes in $M$ that serve as vertices in $s$, ordered in some arbitrary order that is determined in advance.

Furthermore, define the polynomials of two variables

$q_{\vec{k},s}(x,y) = 1 - x - y,$

$q_{\vec{l},s}(x,y) = x,$

$q_{\vec{m},s}(x,y) = y.$

We are now ready to define $A^{(b)}$, the matrix that contains the contributions from the mixed boundary conditions. This matrix has the same order as $A^{(s)}$. Most of its elements vanish, except for the ones specified below.

For every two distinct nodes $\vec{i}$ and $\vec{j}$ in $b$, the corresponding off-diagonal element in $A^{(b)}$ is defined by

$$A^{(b)}_{i,j} \equiv \sum_{s=\Delta(\vec{i},\vec{j},\vec{k})\in b} \|\vec{j} - \vec{i} \times (\vec{k} - \vec{i})\|_2 \int_T q_{\vec{i},s} q_{\vec{j},s} dx dy$$

$$= \frac{1}{24} \sum_{s=\Delta(\vec{i},\vec{j},\vec{k})\in b} \|\vec{j} - \vec{i} \times (\vec{k} - \vec{i})\|_2,$$

where '$\times$' stands for the vector product in three dimensions (see Sections 9.25 and 28.10 in [69]).

These nonzero matrix elements are now used to also define the nonzero main-diagonal elements in $A^{(b)}$. Indeed, for every node $\vec{i}$ in $b$, define the main-diagonal element corresponding to it by

$$A^{(b)}_{i,i} \equiv \sum_{j \neq i} A^{(b)}_{i,j}.$$

This completes the definition of the boundary matrix $A^{(b)}$, which will be used later to add the boundary term to the original stiffness matrix $A^{(s)}$.

Below we also define the mass matrix that discretizes $A^{(s)}$ the Helmholtz term in the original equation.

Here we define the mass matrix $A^{(m)}$ obtained from the finite-element discretization of the Helmholtz term in the original equation. For any two nodes $\vec{i}$ and $\vec{j}$ in the mesh $M$, the $(\vec{i},\vec{j})$th matrix element is defined by

$$A^{(m)}_{i,j} = \sum_{t \in M, \vec{i},\vec{j} \in t} |\det(S_t)| \iint_T P_{i,t} P_{j,t} dx dy dz .$$

$$= \begin{cases} \frac{1}{120} \sum_{t \in M, \vec{i},\vec{j} \in t} |\det(S_t)| & \text{if } \vec{i} \neq \vec{j}, \\ \frac{1}{60} \sum_{t \in M, \vec{i},\vec{j} \in t} |\det(S_t)| & \text{if } \vec{i} = \vec{j}. \end{cases}$$

## 27.5 The Nonlinear Term

The coefficient $|u|^2$ in the nonlinear term $K_1|u|^2u$ in the Helmholtz equation is nondifferentiable so long as it is considered as a standard complex-valued function. To make it differentiable (and, hence, ready for the Newton iteration of Section 9.14), its real part must be separated from its imaginary part.

Consider a complex-valued grid function $v$, defined on the nodes in the mesh $M$. Note that $v$ may be viewed as a vector, whose $i$-th component, $v_i$, is the same as the returned value $v(i)$. Furthermore, $v$ can be written in terms of its real and imaginary parts:

```
v_i = Re v_i + sqrt(-1) Im v_i.
```

(Such a separation is used in [4] to apply a finite-difference scheme to the one-dimensional nonlinear Helmholtz equation.) Furthermore, the complex number $v_i$ can be interpreted as a point in the two-dimensional Cartesian plane:

```
v_i = ( Re v_i \ Im v_i ) .
```

In this interpretation, $v$ can be viewed as a function from the nodes in $M$ to the Cartesian plane. This is why the function $v$ is also called below a vector grid function.

Consider now an operator $f$ that transforms the complex-valued grid function $v$ into another complex-valued grid function $f(v)$. In fact, $f(v)$ can also be written in terms of its real and imaginary parts:

```
f(v)_i = Re f(v)_i + sqrt(-1) Im f(v)_i,   i ∈ M.
```

Furthermore, $f(v)_i$ can also be interpreted as a point in the two-dimensional Cartesian plane:

```
f(v)_i = ( Re f(v)_i \ Im f(v)_i ) .
```

This way, $f(v)$ is interpreted as a vector grid function as well, and $f$ is actually interpreted as an operator on the set of vector grid functions.

To define the operator $f$ more specifically, let us first introduce a helpful notation. For every tetrahedron

```
t = (k, l, m, n) ∈ M,
```

let us denote the polynomial of three variables

```
P_t(v) ≡ v_k P_{k,t} + v_l P_{l,t} + v_m P_{m,t} + v_n P_{n,t}.
```

As above, this polynomial can also be written in terms of its real and imaginary parts:

```
P_t(v) = Re P_t(v) + sqrt(-1) Im P_t(v)
= Re v_k P_{k,t} + Re v_l P_{l,t} + Re v_m P_{m,t} + Re v_n P_{n,t}
+ sqrt(-1) ( Im v_k P_{k,t} + Im v_l P_{l,t} + Im v_m P_{m,t} + Im v_n P_{n,t} ).
```

## Chapter 27. Application in Nonlinear Optics

Let us use this notation to define the operator $f$ more specifically in the context of the finite-element scheme for the nonlinear Helmholtz equation: for every node $i ∈ M$.

$f(v)_i$
≡ ∑_{i∈M, ĩ∈I} |det(S_i)| ∬_T |P_i(v)|^2 P_i(v) P_{ĩ,d} dx dy dz
= ∑_{i∈M, ĩ∈I} |det(S_i)| ∬_T (ℜ² P_i(v) + ℑ² P_i(v)) ℜ P_i(v) P_{ĩ,d} dx dy dz
+ √-1 ∑_{i∈M, ĩ∈I} |det(S_i)| ∬_T (ℜ² P_i(v) + ℑ² P_i(v)) ℑ P_i(v) P_{ĩ,d} dx dy dz.

This way, $f$ is written in terms of its real and imaginary parts, as before.

In the Newton iteration to solve the nonlinear Helmholtz equation, we also need yet another mass matrix. $A^{(n)}(v)$, obtained from the linearization of the nonlinear term. More precisely, $A^{(n)}(v)$ is the Jacobian of $f$ (interpreted as an operator on vector grid functions) at the vector grid function $v$. Thus, the elements of this matrix are no longer scalars but rather $2 × 2$ block submatrices. More specifically, the $(ĩ, j̃)$th $2 × 2$ block submatrix in $A^{(n)}(v)$ is defined as follows. The upper left element in it is defined by partial derivation (under the integral sign as in Section 31.4 below) of ℜ $f(v)_{ĩ}$ with respect to ℜ $v_{j̃}$ :

$(A^{(n)}(v)_{ĩ,j̃})_{1,1}$
≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T (3ℜ² P_i(v) + ℑ² P_i(v)) P_{ĩ,j̃} dx dy dz .

Furthermore, its upper right element is defined by partial derivation (under the integral sign) of $f(v)_{ĩ}$ with respect to ℑ $v_{j̃}$ :

$(A^{(n)}(v)_{ĩ,j̃})_{1,2} ≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T 2ℜ P_i(v) ℑ P_i(v) P_{ĩ,j̃} dx dy dz .$

Similarly, its lower left element is defined by partial derivation (under the integral sign) of ℑ $f(v)_{ĩ}$ with respect to ℜ $v_{j̃}$ :

$(A^{(n)}(v)_{ĩ,j̃})_{2,1} ≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T 2ℜ P_i(v) ℑ P_i(v) P_{ĩ,j̃} dx dy dz$
= $(A^{(n)}(v)_{ĩ,j̃})_{1,2}$ .

Finally, its lower right element is defined by partial derivation (under the integral sign) of ℑ $f(v)_{ĩ}$ with respect to ℑ $v_{j̃}$ :

$(A^{(n)}(v)_{ĩ,j̃})_{2,2}$
≡ ∑_{i∈M, j̃∈I} |det(S_i)| ∬_T (ℜ² P_i(v) + 3ℑ² P_i(v)) P_{ĩ,j̃} dx dy dz .

This completes the definition of $A^{(n)}(v)$ at the given vector grid function $v$.

## 27.6 The Advantage of the Object-Oriented Framework

The power of OOP is apparent in the implementation of the matrix $A^{(n)}(v)$. Indeed, it can be implemented in a sparse-matrix object, with “T” being a "matrix2" object rather than a mere scalar. For consistency, the elements in the stiffness matrix $A^{(s)}$ are implemented as "matrix2" objects as well, using the equivalence

$$c \sim \begin{pmatrix} \Re c & -\Im c \\ \Im c & \Re c \end{pmatrix}$$

for any complex number $c$. This allows arithmetic operations with such matrices, including multiplication by a complex number (implemented as a "matrix2" object) and addition. Furthermore, vectors are implemented with components that are "point" objects rather than mere scalars, using the equivalence

$$c \sim \begin{pmatrix} \Re c \\ \Im c \end{pmatrix}$$

for any complex number $c$. This allows arithmetic operations with such vectors, including multiplication (from the left) by a complex number (implemented as a "matrix2" object) and addition. Furthermore, it allows the matrix-times-vector multiplication. With these operations, the Newton iteration of Section 9.14 can be easily implemented.

## 27.7 The Newton Iteration

Consider the nonlinear operator $F$ defined on the set of the vector grid functions by

$$F(v)=\left(A^{(s)}+\sqrt{K}\,A^{(b)}+K\,A^{(m)}\right)v+K_1f(v)$$

(where $v$ is any vector grid function, and the nonlinear operator $f$ is as in Section 27.5). Clearly, the Jacobian of the nonlinear operator $F$ at $v$ is the matrix

$$A(v)=A^{(s)}+\sqrt{K}\,A^{(b)}+K\,A^{(m)}+K_1A^{(n)}(v).$$

This Jacobian will be useful in the Newton iteration below. (See Section 9.14.)

Consider now the following problem: find a vector grid function $u$ for which

$$F(u)=\vec{0}$$

(where $\vec{0}$ is the zero vector grid function). The Newton iteration that converges to the required solution $u$ is defined as follows:

- 1. Let the vector grid function $u^{(0)}$ be a suitable initial guess.
- 2. For $i=0,1,2,\ldots$,
  - (a) Solve the linear system
    $$A(u^{(i)})x=F(u^{(i)})$$
    for the unknown vector grid function $x$.
  - (b) Define
    $$u^{(i+1)}\equiv u^{(i)}-x.$$
