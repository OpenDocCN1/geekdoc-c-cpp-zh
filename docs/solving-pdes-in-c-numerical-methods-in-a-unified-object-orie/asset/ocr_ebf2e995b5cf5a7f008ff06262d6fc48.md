Figure 17.9, one must solve a Dirichlet subproblem in the union of finite elements that share this node as their joint vertex.

The Dirichlet boundary conditions for this subproblem are the original values of $u$ at the center node and at the other bullets on the edges across from it. This way, the original value of $u$ at the center node is indeed prolonged implicitly to the rest of the degrees of freedom in Figure 17.9 as well.

Once the above subproblem has been solved, the prolonged values $Pu$ for all the degrees of freedom at the center node in Figure 17.9 are indeed well defined. The definitions of the prolonged values $Pu$ for the degrees of freedom at the edge midpoints in Figure 17.9, on the other hand, are not yet complete: besides the contribution from the center node, there are more contributions from the original $u$ values at the other coarse-grid nodes (the corners in Figure 17.8), which must be added as well to form the final prolonged value $Pu$ at each edge midpoint in Figure 17.9.

In fact, the prolongation procedure at these edge midpoints is in the spirit of the approach used before in the case of linear finite elements. Indeed, if a particular edge midpoint is indexed by $i$ and is assumed to be the only fine point that needs to be prolonged to (a nonrealistic assumption made for the sake of the discussion only), and if the edge endpoints are indexed by $j$ and $k$, then the new prolonged value would be the weighted average

$$(Pu)_i=\frac{A_{i,j}u_j+A_{i,k}u_k}{A_{i,j}+A_{i,k}}.$$

as in algebraic multigrid.

Furthermore, the same applies to the "fine" degrees of freedom at the center in Figure 17.9 as well. Indeed, if such a degree of freedom is indexed by $i$ and is assumed to be the only one that needs to be prolonged to, and if the original $u$-value at the center is indexed by $k$, then the new prolonged value would be obtained by the formula

$$(Pu)_i=\frac{A_{i,k}u_k}{A_{i,k}}=u_k,$$

as in prototype algebraic multigrid.

Thus, we have seen that the present multigrid version for high-order finite elements can be viewed as a geometrically motivated version of algebraic multigrid. In other words, algebraic multigrid can be viewed as a simplified automatic version of prototype multigrid versions not only in linear finite elements but also in high-order finite elements.

# 17.16  Multigrid for Adaptive Meshes

The multigrid method implemented in Section 17.10 assumes nothing about the origin of the linear system of algebraic equations. Indeed, it can be applied equally well to linear systems arising from all sorts of discretization methods, including finite differences, finite volumes, and finite elements. In fact, it provides a "black-box" linear-system solver that takes the coefficient matrix and the right-hand side as inputs and produces the required solution as an output.
