## A.31 Indexing the Sides in the 3-D Mesh

A similar function, named "sideIndexing", is used to index the sides in the entire mesh. First, the function is declared in the block of the "mesh" class:

```cpp
int sideIndexing(int, int);
```

For each tetrahedron encountered in this loop, the four vertices in it can again be denoted by 0, 1, 2, and 3. With this notation, the four sides in the tetrahedron are then scanned in the following order:

$(0,1,2),\ (0,1,3),\ (0,2,3),\ (1,2,3).$

This is indeed done in the following triple loop, in which the sides are denoted by $(i,j,k)$ (where $0 \leq i < j < k \leq 3$), and the integer variable 'I' counts them:

```cpp
int I = -1;
for(int i=0; i<=1; i++)
    for(int j=i+1; j<=2; j++)
        for(int k=j+1; k<=3; k++){
            I++;
        }
```

As before, a yet inner loop is used to check whether $(i,j,k)$ also serves as a side of the form $(n_i,n_j,n_k)$ in a yet previous tetrahedron in the mesh:

```cpp
for(mesh<T>* previous = this;
    previous&&(previous != runner)
    &&(runner->item.readMeshIndex(40+2*6+I) < 0);
    previous=(mesh<T>*)previous->next){
    int ni = runner->item[i] < previous->item;
    int nj = runner->item[j] < previous->item;
    int nk = runner->item[k] < previous->item;
```

If it does, then the (local) index of the extra vertex (the vertex that lies across from $(n_i,n_j,n_k)$) in the list of four vertices in that previous tetrahedron is identified and placed in the variable "nl":

```cpp
if(ni&&nj&&nk){
    ni--;
    nj--;
    nk--;
    int nl = 0;
    while((nl==ni) || (nl==nj) || (nl==nk))
        nl++;
```

This fourth vertex, "nl", is now used to define the (local) index 'J' of $(n_i,n_j,n_k)$ in the list of four sides in that previous tetrahedron:

```cpp
int J = 3 - nl;
```

The (local) index 'J' is now used to assign the (global) index of $(n_i,n_j,n_k)$ in the list of sides in the entire mesh to $(i,j,k)$ as well:

```cpp
runner->item.meshIndex(40+2*6+I)
    = previous->item.readMeshIndex(40+2*6+J);
}
}
```

If, however, no previous tetrahedron that shares the side $(i, j, k)$ has been found, then $(i, j, k)$ must be assigned a new index in the list of sides in the entire mesh, and the side counter "sides" must be incremented by 1:

```cpp
if (runner->item.readMeshIndex(40+2*6+I) < 0)
    runner->item.meshIndex(40+2*6+I) =
        10 * nodes + 2 * edges + sides++;
}
}
```

Finally, the function also returns the total number of sides in the mesh:

```cpp
return sides;
} // indexing the sides in the mesh
```

This completes the indexing of the sides in the entire mesh.

## A.32 Assembling the (Nonlinear) Electricity Equations

The following constructor assembles the coefficient matrix for the electricity equations reduced from the original Maxwell equations in Section 29.12. It is assumed that two external parameters are available: "HELM" is the coefficient of the linear mass term ($K$ in Chapter 25), and "HELMNonlin" is the coefficient of the nonlinear mass term ($K_1$ in Chapter 25).

The code can be considered as an extension of the code in Section A.28 above. Indeed, here the matrix elements are no longer mere scalars but rather 'T' objects, to be specified later by the user as "matrix2" objects ($2 \times 2$ matrices). As discussed in Sections 27.5 and 27.6, this gives us the opportunity to construct the coefficient matrix in the Newton iteration to solve a nonlinear problem of the form

$A(\dot{x}) = \tilde{f}$.

This is also why the vector arguments 'x' (the current approximation to $\dot{x}$ in the current Newton iteration) and 'f' (the current right-hand side $A('x') - \tilde{f}$ in the current Newton iteration) have components of type "point" (two-dimensional subvectors) rather than mere scalars.

The code in Section A.28 assembles a scalar PDE. This is why the order of the matrix constructed in it is "nodes", that is, the number of nodes in the mesh. The present code, on the other hand, assembles a system of three PDEs, so the coefficient matrix must contain $3 \times 3$ block submatrices, each of which is of order 2 times "nodes".
