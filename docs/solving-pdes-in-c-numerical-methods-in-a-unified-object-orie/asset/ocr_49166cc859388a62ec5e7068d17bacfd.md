As we'll see below, the discrete Fourier transform of the original vector f is obtained by sampling the polynomial f(Z) at n distinct complex points z. Because any polynomial of degree n − 1 is determined uniquely by its value at n distinct points, the Fourier transform is indeed invertible.

More precisely, the inverse Fourier transform can be used to calculate the coefficients of a polynomial from its values at n equidistant points of the form z0, z1, ..., zn−1 on the unit circle in the complex plane. This may be quite practical: for example, to calculate the coefficients of the product of two given polynomials f() and g(). one only needs to sample them at z0, z1, ..., zn−1 and then apply the inverse Fourier transform to the n products f(z0)g(z0), f(z1)g(z1), ..., f(zn−1)g(zn−1).

Let us now define the Fourier transform in some more detail. Let wn be the nth complex root of the unity in the complex plane:

```
wn ≡ exp(−2π√−1/n).
```

Define the Fourier matrix of order n by

```
Wn = (wij)0≤i,j<n .
```

The Fourier transform transforms the original vector f into the vector Wn f obtained by evaluating the polynomial f() at the powers of w:

```
Wn f = (f(1), f(wn), f(wn2), ..., f(wn^{n−1}))^t .
```

# 5.34 The Inverse Transformation

Let us now discuss a few properties of the Fourier transform and its inverse. First, the columns of Wn are orthogonal to each other. Indeed, the inner product of the jth and kth columns (for some distinct 0 ≤ j,k < n) is

```
∑_{i=0}^{n−1} (w^j)^i (w^k)^i = ∑_{i=0}^{n−1} (w^{j−k})^i = (1 − (w^{j−k})^n ) / (1 − w^{j−k}) = (1 − 1) / (1 − w^{j−k}) = 0.
```

Furthermore, the squared l2-norm of the jth column of Wn (for some 0 ≤ j < n) is

```
∑_{i=0}^{n−1} (w^j)^i (w^j)^i = ∑_{i=0}^{n−1} (w^j)^i = ∑_{i=0}^{n−1} 1 = n.
```

Thus, the inverse Fourier matrix is

```
Wn^{−1} = 1/n Wn^* = 1/n ar Wn = 1/n ( (w_n^{-1})^{ij} )_{0≤i,j<n} .
```

The inverse Fourier transform can thus be applied simply by applying the original Fourier transform with ar w_n = w_n^{-1}, rather than the original w_n, and then dividing by n.
