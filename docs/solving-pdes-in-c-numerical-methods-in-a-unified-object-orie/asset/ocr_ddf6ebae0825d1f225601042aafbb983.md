Let us use our original assumption to bound the blocks in Q in the following sense:
‖J_{i+1} Q_i B_i^{-1} J_i^{-1}‖ = ‖J_{i+1} J_i^{-1} (I − Δt Λ_i /2)(I + Δt Λ_i /2)^{-1}‖
≤ ‖J_{i+1} J_i^{-1}‖ · ‖(I − Δt Λ_i /2)(I + Δt Λ_i /2)^{-1}‖
≤ 1.

(When the eigenvalues of Δt A_i lie well away from the origin, this bound can actually be improved to a constant smaller than 1.)

As a result, we have
‖J Q J^{-1}‖ ≤ 1.

Let M denote the number of time steps. Using the above results and the formula
(I − Q)^{-1} = Σ_{k=0}^{M-1} Q^k,
we have
‖J(I − Q)^{-1} J^{-1}‖ = ‖ Σ_{k=0}^{M-1} (J Q J^{-1})^k ‖
≤ Σ_{k=0}^{M-1} ‖J Q J^{-1}‖^k
≤ M.

(When the eigenvalues of Δt A_i lie well away from the origin, this upper bound can actually be improved to a constant independent of M.)

Thus, the application of (I − Q)^{-1} to a vector also produces no instability. This guarantees stability in the time-marching process. In fact, we have
‖J A^{-1} J^{-1}‖ = ‖J B^{-1} J^{-1} J(I − Q)^{-1} J^{-1}‖
≤ ‖J B^{-1} J^{-1}‖ · ‖J(I − Q)^{-1} J^{-1}‖
≤ Δt · M = T

(where T is the maximal time). This guarantees that small errors in ℱ indeed produce only small errors in the numerical solution u.

# 8.4 Accuracy and Adequacy

Here, we use the above stability result to show that the numerical schemes are accurate and adequate in the sense described below.

Let ũ be the numerical solution and u be the vector obtained from the solution u(t,x) of the original PDE when confined to the discrete time-space grid. The discretization error
ũ − u
is the difference between the numerical solution ũ = A^{-1} ℱ and the true values in u.
