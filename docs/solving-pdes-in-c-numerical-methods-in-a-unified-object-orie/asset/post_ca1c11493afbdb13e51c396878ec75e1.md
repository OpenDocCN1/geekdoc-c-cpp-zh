
## 29.7 Boundary Conditions as a Linear Operator

Assume that Γ₀ in Chapter 11 contains one point only:

Γ₀ = {a}.

In this case, the weak formulation in Section 11.2 can be written as above: either find a scalar λ and a function u (with square-integrable partial derivatives in Ω) that satisfy

a(u, v) + λ v(a) = f(v),
    u(a) = G(a)

(where G is a given function on Γ₀) for every function v with square-integrable partial derivatives in Ω, or find a function u that satisfies

a(u, v) = f(v),
    u(a) = G(a)

for every function v that satisfies the homogeneous boundary condition v(a) = 0. Clearly, this latter form is simpler, and is therefore used in the finite-element scheme.

Assume now that Γ₀ contains two points:

Γ₀ = {a₁, a₂}.

From the discussion in the previous section, the weak formulation in Section 11.2 can be written as follows: either find scalars λ₁ and λ₂ and a function u that satisfy

a(u, v) + λ₁ v(a₁) + λ₂ v(a₂) = f(v),
    u(a₁) = G(a₁),
    u(a₂) = G(a₂)

for every function v, or find a function u that satisfies

a(u, v) = f(v),
    u(a₁) = G(a₁),
    u(a₂) = G(a₂)

for every function v with square-integrable partial derivatives in Ω and every function p that is square-integrable in Γ₀, or find a function u that satisfies

a(u, v) = f(v),
    u = G  weakly in Γ₀

for every function v that vanishes (weakly) in Γ₀. By “weakly” we mean here that the equation does not necessarily hold pointwise, but only in terms of integration: both sides of the equation produce the same result once integrated against a function p in Γ₀. (This is as in the second equation in the previous system.)

The second equation in the above systems, the constraint equation, can be written in terms of the linear operator L that restricts a function defined in Ω to its values in Γ₀ only. In this context, the constraint equation can be written as

L(u) = G

(weakly). In the sequel, we consider not only L associated with Dirichlet boundary conditions as above, but also other kinds of linear operators. In this context, the subset of functions v for which L(v) = 0 (weakly) is not always available, so the original form that uses Lagrange multipliers may be more useful.

## 29.8 The Divergence Equation as a Constraint

The original Maxwell equations introduced in Section 22.11 above for the unknown electric field

E ≡ (E₁, E₂, E₃)

and the unknown magnetic field

B ≡ (B₁, B₂, B₃)

can be written more compactly as

1/c Eₜ − ∇ × B = − 4π/c J,
∇ × E + 1/c Bₜ = 0,
∇ · B = 0,
∇ · E = 4π ρ.

In Section 22.11, it is pointed out that there are here more equations than unknown functions. To fix this, the homogeneous equations in the above system (the second and third equations) have been used there most strongly to introduce vector and scalar potential functions.

This strong interpretation of the second and third equations means that they must hold pointwise throughout the domain Ω. This strong assumption is rather undesirable: can it be avoided?

Fortunately, it indeed can. This is done by treating the two former equations in the system (the curl equations) as the main equations in the system, and the two latter equations

(the divergence equations) as mere constraints. This way, there are two main (vector) equations in the two (vector) unknowns E and B, as required. Furthermore, both the main equations and the constraint equations can be interpreted only weakly in Ω, as required. Moreover, as we’ll see next, the boundary conditions can be interpreted weakly as well in ∂Ω.

Let Ω be a domain in the three-dimensional Cartesian space. Assume that the boundary ∂Ω can be written as the union of three disjoint subsets:

∂Ω = Γ₁ ∪ Γ₂ ∪ Γ₃.

Γ₁ is called the electric wall, Γ₂ is called the magnetic wall, and Γ₃ is called the no-flux no-current wall [8]. Furthermore, define also

Γ₄ ≡ Γ₃

and

Γ₅ = Γ₆ ≡ Ω.

For every boundary point (x, y, z) ∈ ∂Ω, let n⃗ = n⃗(x, y, z) be the outer normal vector (the unit vector that is perpendicular to the plane that is tangent to ∂Ω at (x, y, z) and points from (x, y, z) towards outside Ω). Define also the following linear operators Lₖ that take the two vector functions Ẽ and B̃ (that are defined in Ω) as their arguments and produce a vector or scalar function defined in Γₖ (1 ≤ k ≤ 6):

L₁(Ẽ, B̃) = n⃗ × Ẽ
L₂(Ẽ, B̃) = n⃗ × B̃
L₃(Ẽ, B̃) = n⃗ · (∇ × Ẽ)
L₄(Ẽ, B̃) = n⃗ · (∇ × B̃)
L₅(Ẽ, B̃) = ∇ · B̃
L₆(Ẽ, B̃) = ∇ · Ẽ.

Let us now impose the following (natural) boundary conditions on the original Maxwell system:

Lₖ(E, B) = 0 weakly in Γₖ, 1 ≤ k ≤ 4.

Below we use the linear operators L₅ and L₆ in a similar way. In this approach, the original divergence equations are interpreted as mere constraints rather than as standard equations. This way, the number of equations doesn’t exceed the number of unknown functions, as required.

## 29.9 The Weak Form

In what follows, we use the following notation for the inner product of two fields:

E · B ≡ E₁ B̄₁ + E₂ B̄₂ + E₃ B̄₃.

With the above natural boundary conditions, and with the divergence equations interpreted as constraints, the original (strong) Maxwell system takes the following weak form: find

vector functions E and B (with square-integrable curl and divergence in Ω) so that

1/c ∫_Ω E_t · Ē dΩ − ∫_Ω (∇ × B) · Ē dΩ = −4π/c ∫_Ω J · Ē dΩ
∫_Ω (∇ × E) · B̄ dΩ + 1/c ∫_Ω B_t · B̄ dΩ = 0
∫_{Γ_k} L_k(E,B) p_k dΓ_k = 0   (1 ≤ k ≤ 5)
∫_Ω (∇ · E) p_6 dΩ = 4π ∫_Ω ρ p_6 dΩ

for all vector functions Ē and B̃ that satisfy the homogeneous constraints L_k(Ē, B̃) = 0 weakly in Γ_k (1 ≤ k ≤ 6) and all scalar functions p_k that are square-integrable in Γ_k (1 ≤ k ≤ 6). (In the setting in [21], p_5 and p_6 are no longer arbitrary, but rather dependent on B̃ and Ē: p_5 is chosen to be the complex conjugate of ∇ · B̃, and p_6 is chosen to be the complex conjugate of ∇ · Ē.)

Note that the first two equations in this system (the time-dependent curl equations) can be added to each other, yielding an equivalent system that holds for every pair of the form (Ē, B̃) rather than all individual fields Ē and B̃. Indeed, the original curl equations can be obtained from their sum by considering pairs of the form (Ē,0) and (0, B̃). The sum form, however, is particularly useful, because its left-hand side defines the bilinear form a((E,B),(Ē,B̃)), used in the finite-element discretization below. (In the setting in [21] mentioned above, in which p_5 ≡ ∇ · B̃ and p_6 ≡ ∇ · Ē, the two final constraint equations are added to this sum as well, so the bilinear form a contains integrals of ∇ · B ∇ · B̃ and ∇ · E ∇ · Ē as well.)

Because it is rather difficult to design fields Ē and B̃ that satisfy the homogeneous constraints, it makes sense to resort to the original Lagrange-multiplier form introduced in Sections 29.2–29.4 above, in which no homogeneous constraints are used. This approach is indeed used in the discretization below.

## 29.10 The Finite-Element Discretization

Assume now that the three-dimensional domain Ω is approximated by a mesh of tetrahedra M as in Chapter 26. Then the unknown electric field E can be approximated by three scalar functions that are continuous in the mesh and linear in each particular tetrahedron. The number of degrees of freedom in each such function is the same as the number of nodes in the mesh. In fact, each degree of freedom is associated with a piecewise linear nodal basis function with the value 1 at a particular node and 0 at all the other nodes. Thus, each of the three unknown functions in E is approximated by a linear combination of these nodal basis functions, with scalar coefficients that serve as unknowns in the discrete system of algebraic equations.

The fields B, Ē, and B̃ can be approximated in the same way. The scalar functions p_5 and p_6, on the other hand, can be approximated by functions that are constant in each individual tetrahedron in the mesh.
