# 28.14 Basis Functions in the Mesh

For every tetrahedron t ∈ M, let us write

t = (\vec{k}, \vec{l}, \vec{m}, \vec{n}),

where \vec{k}, \vec{l}, \vec{m}, and \vec{n} are the corners of t in some arbitrary order that is determined in advance.

Let us now redefine the indices of the corner basis functions R_{i,t} (0 ≤ i < 40) defined in t to agree with the above indexing scheme in the entire mesh. More precisely, let us introduce new corner basis functions of the form h_{n,t} that differ from the original R_{i,t} ’s only in their index:

h_{10|\vec{k}| + q , t} = R_{q,t}

h_{10|\vec{l}| + q , t} = R_{10+q ,t}

h_{10|\vec{m}| + q , t} = R_{20+q ,t}

h_{10|\vec{n}| + q , t} = R_{30+q ,t}

where q is any integer between 0 and 9.

Similarly, let us redefine the indices of the edge-midpoint basis functions R_{i,t} (40 ≤ i < 52). More precisely, let us introduce new edge-midpoint basis functions of the form h_{n,t} that differ from the original R_{i,t} ’s only in their index:

h_{10n +2 +2(\vec{k},\vec{l}) +q ,t} = R_{40+q ,t}

h_{10n +2 +2(\vec{k},\vec{m}) +q ,t} = R_{42+q ,t}

h_{10n +2 +2(\vec{k},\vec{n}) +q ,t} = R_{44+q ,t}

h_{10n +2 +2(\vec{l},\vec{m}) +q ,t} = R_{46+q ,t}

h_{10n +2 +2(\vec{l},\vec{n}) +q ,t} = R_{48+q ,t}

h_{10n +2 +2(\vec{m},\vec{n}) +q ,t} = R_{50+q ,t}

where q is either 0 or 1.

Finally, let us redefine the indices of the side-midpoint basis functions R_{i,t} (52 ≤ i < 56). More precisely, let us introduce new side-midpoint basis functions of the form h_{n,t} that differ from the original R_{i,t} ’s only in their index:

h_{10n +2n_e + |(\vec{k},\vec{l},\vec{m})| ,t} = R_{52,t}

h_{10n +2n_e + |(\vec{k},\vec{l},\vec{n})| ,t} = R_{53,t}

h_{10n +2n_e + |(\vec{k},\vec{m},\vec{n})| ,t} = R_{54,t}

h_{10n +2n_e + |(\vec{l},\vec{m},\vec{n})| ,t} = R_{55,t}

We say that the indices used in the left-hand sides above are associated with t, because they index degrees of freedom associated with a corner, edge midpoint, or side midpoint in t. This property is denoted by

10|\vec{k}| + q ~ t

10|\vec{l}| + q ~ t

10|\vec{m}| + q ~ t

10|\vec{n}| + q ~ t
