
## 4.17 Recursive Definition and Interpretation

Of course, the practical interpretation is done recursively rather than inductively. Indeed, to use the lower-level objects, one must recall their original definitions as well. These definitions invoke in turn yet more elementary definitions of yet lower-level objects, and so on, until the atom objects at the lowest level are reached.

Thus, the practical interpretation is done upwards rather than downwards. Indeed, the atom objects at the very bottom of the recursion are interpreted first, to be used in the definitions of higher-level objects, to be used in the definitions of yet higher-level objects, and so on, until the current object at the highest level is reached and defined.

Fortunately, the complicated recursive process can be left to the computer. When we humans define or interpret an object, we use the more elegant (downward) inductive approach. This way, we can assume that lower-level objects are already well interpreted and focus on the features of the high-level object that is currently under consideration.

The above model is relevant not only to formal languages but also to human languages, provided that they are learned at adulthood by the rational part of one’s mind. The first language used by a baby, on the other hand, is learned by a much more intuitive (Wittgenstein-type) mechanism.

## 4.18 Intuitive Interpretation—Chomsky’s Theory

As discussed above, the dictionary definition of a word is inductive in its nature: it uses lower-level words that are assumed to be well understood. This point of view is relevant not only to formal but also to second natural languages that are studied by adults.

In fact, this inductive mechanism may produce an arbitrarily large hierarchy of more and more complex objects, to make one’s vocabulary richer and richer. In fact, it makes the original vocabulary grow further and further by introducing new objects and concepts, using previous definitions.

Still, as in Chomsky’s theory, the baby learns a first natural language not from a dictionary but rather intuitively, directly from practical experience. This way, the new word is well embedded in his/her mind as a new atom word, independent of any other word: it is well connected to the memories associated with it, which lie in the background of the baby’s mind. These memories are then invoked each time the word is used later on.

We are now ready to use the present ideas to introduce the concept of object-oriented programming.

## 4.19 Objects in Language

Each sentence in a natural (human) language contains a subject that operates upon an object. Thus, an object can be interpreted as something upon which the subject operates. Better yet, an object can be interpreted independently of any subject as a noun upon which operations can be carried out.

The above is true not only in natural languages but also in formal languages such as mathematical languages and programming languages. For example, algebraic objects such as numbers, vectors, and matrices can undergo arithmetic operations such as addition, subtraction, and multiplication. In object-oriented programming, each object is implemented in a class, along with the functions and operators that act upon it.

## 4.21 Lacan: Mind Is Language

Lacan’s theory proposes that the mind of a human being is actually identical to the language that he/she uses. Indeed, in order to think about an object, one must first give it a name. Conversely, in order to give an object a name, one must first have some idea about it. Thus, the terminology used to refer to the object actually makes it present in one’s mind. For example, to be able to think about a general chair (rather than a concrete chair), one must introduce the word “chair.” Conversely, to understand the word “chair,” one must be familiar with the general concept of chair. This is why an animal, which lacks language, can think only of a concrete chair rather than the general concept of chair.

The above makes sense not only in natural languages but also in formal languages such as mathematics. Here, however, the name that is given to the object must also have a mathematical meaning to characterize the object in terms of relations or axioms. For example, the term “vector” means that arithmetic operations can be carried out with commutative and distributive laws.

In Lacan’s theory, one can think about an abstract concept only once he/she has a word for it. For example, one can think about freedom only once he/she has the word “freedom” in his/her vocabulary. Similarly, the mathematician can think about a vector thanks to his/her familiarity with the term “vector,” or with the mathematical properties that characterize it uniquely and make it what it is: an object that can undergo linear arithmetic operations. The object-oriented implementation may also contribute to a better understanding of the mathematical object by giving the properties and axioms that characterize it a more concrete form in terms of a data structure and computer functions.

## 4.22 Language and Mind

In Wittgenstein’s theory, language only contains subjective pointers or references to the ideas and concepts in one’s mind. Furthermore, language may refer only to the rational and abstract part in consciousness. The rest of the human mind, including the subconsciousness, can be referred to only by symbolic views as in dreams rather than by words.

In this respect, a word in a natural human language can be compared to a piece of classical music or modern (rather than realistic) art. Indeed, just as a piece of modern art may introduce a new insight or uncover a hidden emotion, a word can also invoke a memory that is well-embedded in deep consciousness or even subconsciousness. For example, even a prosaic word like “table” that refers to the abstract notion of the general table must highlight the subjective memory of some concrete table from early childhood.

In Lacan’s theory, on the other hand, language is mind. More precisely, language is the rational and abstract part of consciousness. In fact, an abstract notion in one’s consciousness not only can, but also must, be represented by some word to enable one to think about it or to relate it to other concepts as well.

## 4.23 Language and Creativity

The input information that one receives throughout life, including written, verbal, or sensory information, defines and develops one’s personality and consciousness. At the same time, this information also develops one’s language to make it possible not only to refer to but also to think about abstract concepts or to draw relations between concepts. Indeed, without language, a human could only think about concrete objects using sensory information about them, much like an animal.

Traditional education approaches focus on giving bottom-line information and implementing practical tools. Such approaches, however, may lead to a too disciplined way of thinking, and block any natural curiosity or creativity.

More modern education approaches, on the other hand, attempt to stimulate the pupil’s imagination in the context of general human culture and the process in which it has developed. In these approaches, education should be based not only on well-prepared information but also on raw material to allow the pupil some room for playing, experimenting, exploring, and developing his/her own way around. This way, the pupil is likely to develop his/her own free language that may lead him/her to new discoveries or any original work.

Thus, the key to developing skills for productive work is not necessarily technical information or background but rather high language. The high level of abstraction used in high language may give one the tools required to enrich his/her vocabulary further and to develop new ideas and theories.

## 4.24 Language and Education—Rousseau’s Theory

This is why education mustn’t be too strict: it must leave sufficient room for free personal development. Still, the pupil must receive at least the minimal information required to improve his/her own language. This can be obtained by a lot of free, well-balanced reading.

Jean-Jacques Rousseau, the prophet of education, was opposed even to this kind of reading. In fact, Rousseau said that the child should only talk to his/her mentor to learn about real freedom and liberty, and read nothing until he/she is 15 years old. Only at this age is the child ready to read his/her first book—Robinson Crusoe by Daniel Defoe—to obtain the sense of a man who lives completely alone and is therefore completely free from any external influence or any law imposed by society.

The ideal form of education proposed by Rousseau is probably too strict. In fact, free, well-balanced reading of all kinds of prose, poetry, fiction, and nonfiction may enrich the child’s language to allow development of the abstract part of his/her mind.

As discussed below, this is true not only in natural human languages but also in formal mathematical languages. The key factor in object-oriented programming, in particular, is to allow the programmer to constantly enrich his/her own programming language with more and more abstract objects so as to be able to implement advanced mathematical objects and algorithms.

## 4.25 Object-Oriented Programming Language

C may be considered as a process-oriented programming language. Indeed, the basic element in C is the process or function (with one or more input arguments), which calculates and produces the required output. In fact, every command in C is actually a function, which also returns a value.

The input data used in processes in C are not considered an integral part of the process. In fact, the process can be defined before the data have been specified. For example, functions can be defined with dummy arguments, to be given concrete values only when the function is actually called. In fact, when the function is compiled, a finite state machine (automaton) is created, and each dummy argument is represented by an input line, to be filled by a concrete argument later on when the function is actually called.
