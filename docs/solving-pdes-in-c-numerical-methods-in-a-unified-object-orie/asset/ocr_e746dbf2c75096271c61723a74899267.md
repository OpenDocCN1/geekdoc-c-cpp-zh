As a result,

On the other hand, the matrix element A_{i,j} that couples the adjacent nodes i and j doesn't vanish. Indeed, since the only triangle that contributes to it is △(i,j,k), it follows from Section 12.7 that

```
A_{i,j} = -\frac{\cot(\angle(j,k,i))}{2} = -\frac{\cot(\pi/N)}{2}
```
