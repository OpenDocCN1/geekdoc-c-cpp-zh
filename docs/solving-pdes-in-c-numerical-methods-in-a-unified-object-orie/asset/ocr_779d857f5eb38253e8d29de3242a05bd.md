nonzero coefficients are stored. More precisely, the sparse polynomial is implemented as a linked list of monomials of the form a_i x^i, where a monomial is actually a pair of numbers: a scalar number to store the nonzero coefficient a_i, and an integer number to store the power i.

Later on, we’ll indicate how this object is implemented in the general case. First, however, we implement it in the simple case of a real polynomial of a single variable. In this case, the "monomial" object is already available in Chapter 16, Section 16.2:

```
typedef rowElement<double> monomial;
```

This way, the "monomial" object indeed contains two fields: a "double" field to contain the coefficient a_i, and an integer field to contain the power i. For greater transparency, we also define the member function "power()" that reads this integer field. This function is first declared as a member of the "monomial" class by writing in the body of the "rowElement" class

```
int power() const;
```

Then, it is defined by writing

```
int monomial::power() const{
    return getColumn();
} // power of the monomial
```

Using the code in Chapter 16, Section 16.3, the sparse polynomial is now implemented as a linked list of monomials:

```
typedef row<double> sparsePolynomial;
```

We are now ready to define the operator that multiplies the current sparse polynomial by a monomial. This operator is first declared as a member of the "sparsePolynomial" class by writing in the body of the "row" class

```
const row& operator*=(const rowElement<T>&);
```

Then, it is defined by writing

```
const sparsePolynomial&
sparsePolynomial::operator*=(const monomial&a){
    item = monomial(item.getValue() * a.getValue(),
        item.power() + a.power());
    if(next) *(sparsePolynomial*)next *= a;
    return *this;
} // current sparse polynomial times monomial
```
