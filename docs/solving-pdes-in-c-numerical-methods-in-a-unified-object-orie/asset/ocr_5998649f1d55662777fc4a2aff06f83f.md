# 22. The polynomial of two variables

The polynomial of two variables

```
p(x,y) = \sum_{i,j} a_{i,j} x^i y^j
```

can be written in the form

```
p(x,y) = \sum_i a_i x^i ,
```

where the coefficients a_i are actually polynomials in y:

```
a_i \equiv a_i(y) = \sum_j a_{i,j} y^j .
```

Use this formula to implement p(x,y) as a polynomial of polynomials.
