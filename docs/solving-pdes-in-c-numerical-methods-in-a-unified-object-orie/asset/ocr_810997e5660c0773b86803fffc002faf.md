# 30.11 Newton’s Iteration

To use Newton’s iteration (Section 9.12) to solve the nonlinear equation b′(e)=0 for e, we need the second derivative b″(e) as well. To calculate this derivative, we first define the tensor R of six indices as follows. If k = j or m = j or m = k or l = i or n = i or n = l, then

R_{i,j,k,l,m,n}=0.

Otherwise, the corresponding element in R is defined as follows. Assume that R is skew-symmetric under index permutations such as j ↔ k, k ↔ m, i ↔ l, or l ↔ n:

R_{i,j,k,l,m,n}=−R_{i,k,j,l,m,n}=−R_{i,j,m,l,k,n}=−R_{l,j,k,i,m,n}=−R_{i,j,k,n,m,l}.

Clearly, this implies that R is skew-symmetric under index permutations of the form j ↔ m or i ↔ n as well:

R_{i,j,k,l,m,n}=−R_{i,m,k,l,j,n}=−R_{n,j,k,l,m,i}=R_{n,m,k,l,j,i}.

j > k > m and i > l > n.
