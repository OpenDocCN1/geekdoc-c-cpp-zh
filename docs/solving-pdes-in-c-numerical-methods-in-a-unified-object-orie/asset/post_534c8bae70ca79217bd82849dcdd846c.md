
## 25.5 Error Estimate

Using standard Taylor expansions, the truncation error can then be estimated by

$$\|\text{truncation error}\| = \frac{1}{12}\left(\max_{0<x<1} |u''''(x)|\right)h^2 + \left(\max_{0<x<1} |u''''''(x)|\right) O(h^4)$$

as $h \to 0^+$ (with $K$ being kept fixed), where $\|\cdot\|$ stands for the square root of the sum of squares, divided by $\sqrt{N}$. As a result, the error can be estimated by

$$\|\text{error}\| \le \frac{1}{12}\|A^{-1}\|\left(\max_{0<x<1} |u''''(x)|\right)h^2 + O\left(\|A^{-1}\|\max_{0<x<1} (|u''''''(x)|)h^4\right),$$

where $\|A^{-1}\|$ is the maximal ratio between $\|A^{-1}p\|$ and $\|p\|$ for any nonzero $N$-dimensional vector $p$:

$$\|A^{-1}\| \equiv \max_{p} \frac{\|A^{-1}p\|}{\|p\|}.$$

In particular, when $u(x)$ is available in a closed form as in the above model case, we have

$$|u''''(x)| = |K|^2 \text{ and } |u''''''(x)| = |K|^3,$$

so the above estimate takes the form

$$\|\text{error}\| \le \frac{1}{12}\|A^{-1}\||K|^2 h^2 + O\left(\|A^{-1}\||K|^3 h^4\right).$$

## 25.6 Upper Bound for the Inverse of A

To simplify the above estimate further, let us show that

$$\|A^{-1}\| \le \left(\left(\pi^2/\sqrt{3}\right)\max\left(\pi^{-1}\sqrt{-\Im K/2.5/2}\right)\right)^{-1}.$$

Indeed, recall that

$$\|A^{-1}\| \equiv \max_{p} \frac{\|A^{-1}p\|}{\|p\|} = \max_{p} \frac{\|A^{-1}Ap\|}{\|Ap\|} = \max_{p} \frac{\|p\|}{\|Ap\|} = \left(\min_{p} \frac{\|Ap\|}{\|p\|}\right)^{-1}.$$

Thus, we must find a nonzero vector $p$ for which $\|Ap\|$ is relatively as small as possible. To do this, we must expand $p$ in terms of Fourier modes.

For $0 \le k < N$, define the $k$th Fourier cosine vector (or mode) by

$$c^{(k)} \equiv (\cos(k\pi/(2N)), \cos(3k\pi/(2N)), \cos(5k\pi/(2N)), \dots, \cos((2N-1)k\pi/(2N))).$$

In other words, the $j$th component in the vector $c^{(k)}$ is given by

$$c^{(k)}_j = \cos((j+1/2)k\pi/N), \quad 0 \le j < N.$$

Clearly, $c^{(k)}$ is the eigenvector of the so-called "Neumann part" of $A$, defined by

$$\tilde{A} \equiv h^{-2} \begin{pmatrix} 1+Kh^{2} & -1 & & & \\ -1 & 2+Kh^{2} & -1 & & \\ & -1 & 2+Kh^{2} & -1 & \\ & & \ddots & \ddots & \ddots \\ & & & -1 & 2+Kh^{2} & -1 \\ & & & & -1 & 1+Kh^{2} \end{pmatrix}$$

with the corresponding eigenvalue

$$\lambda_k = 4h^{-2}\sin^{2}(k\pi/(2N)) + K.$$

In particular, for $k \ll N$, we can use the formula

$$\displaystyle \lim_{x\to 0} \frac{\sin(x)}{x}=1$$

to have

$$\lambda_k \sim k^{2}\pi^{2}+K.$$

Note that, thanks to the fact that $\tilde{A}$ is symmetric, the $c^{(k)}$'s are orthogonal to each other. Furthermore, their norm is also known:

$$\|c^{(0)}\| = 1,$$

and, for $0 < k < N$,

$$\|c^{(k)}\| = 1/\sqrt{2}$$

(see the exercises at the end of this chapter).

Let $l$ be the integer for which $|\lambda_l|$ is minimal. We then say that $c^{(l)}$ is nearly singular.

Let us now write the vector $p$ as a linear combination of the $c^{(k)}$'s:

$$p = \sum_{k=0}^{N-1} \alpha_k c^{(k)}.$$

Without loss of generality, assume also that

$$\|p\| = 1.$$

Since we are looking for a $p$ with minimal $\|Ap\|/\|p\|$, the above sum must contain only "smooth" modes with $k \ll N$. Furthermore, the sum must also contain at least two different modes. Indeed, if it contained one mode only, then the first and last components in $Ap$ would be too large:

$$(Ap)_0 \ge O(h^{-1}) \le (Ap)_{N-1}$$

(due to the term $h^{-2}h\sqrt{K}$ in the first and last rows in $A$), resulting in

$$\|Ap\| \ge |(Ap)_0|/\sqrt{N} \ge O\left(h^{-1/2}\right).$$

Thus, the above sum must contain at least two different modes to cancel the first and last components in Ap. In fact, to have a minimal $\|Ap\|$, $p$ must be of the form

$$p = \alpha_l c^{(l)} - \alpha_l c^{(l\pm2)}.$$

Here, the expression $l \pm 2$ is interpreted as $l + 2$ if $l < 2$ or if $|\lambda_{l+2}| \le |\lambda_{l-2}|$, and as $l - 2$ otherwise. (Note that $l \pm 1$ cannot be used instead of $l \pm 2$, because $(Ap)_{N-1}$ must be small as well.) In either case, we have (see Figures 25.1 and 25.2)

$$|\lambda_{l\pm2}| \ge \pi^2 |(l \pm 2)^2 - [(l \pm 1)^2 + l^2]/2|.$$

Now, the right-hand side is equal to $\pi^2|7/2 \pm 3l|$ (where the minus sign can be used only for $l \ge 2$), which is minimal at $l = 2$, so we have

$$|\lambda_{l\pm2}| \ge \pi^2 |(l \pm 2)^2 - [(l \pm 1)^2 + l^2]/2| \ge \pi^2 5/2.$$

Furthermore, when $l \ge 2$, one can use the inequality

$$\pi^2 l^2 \ge -\Re K / 2$$

to have the yet stronger lower estimate:

$$|\lambda_{l\pm2}| \ge \pi^2 |(l \pm 2)^2 - ((l \pm 1)^2 + l^2)/2| \ge \pi^2 (3l - 7/2) \ge \pi^2 l \ge \pi^2 \pi^{-1} \sqrt{-\Re K / 2}.$$

Clearly, even for the case $l = 0$ for which $\|c^{(l)}\|$ is maximal, we still have

$$\frac{\|p\|}{\|\alpha_l c^{(l\pm2)}\|} = \frac{|\alpha_l| \|c^{(l)} - c^{(l\pm2)}\|}{\|\alpha_l c^{(l\pm2)}\|} = \frac{\|c^{(l)} - c^{(l\pm2)}\|}{\|c^{(l\pm2)}\|} = \frac{\sqrt{\|c^{(l)}\|^2 + \|c^{(l\pm2)}\|^2}}{\|c^{(l\pm2)}\|} \le \sqrt{3}.$$

Therefore,

$$\|A p\| \ge |\lambda_{l\pm2}| \cdot |\alpha_l| \|c^{(l\pm2)}\| \ge |\lambda_{l\pm2}| \|p\| / \sqrt{3},$$

or

$$\|A p\| / \|p\| \ge |\lambda_{l\pm2}| / \sqrt{3}.$$

By combining this inequality with the lower bound developed before for $|\lambda_{l\pm2}|$, we have the required lower bound for $\|A p\| / \|p\|$ as well. The inverse of this lower bound provides the required upper bound for $\|A^{-1}\|$.

As a result, the above error estimate simplifies to read

$$\|\text{error}\| \le \frac{\sqrt{3}}{30\pi^2} |K|^2 h^2 + O(|K|^3 h^4).$$

Furthermore, if

$$-\Re K > (5\pi)^2 / 2,$$

then the error estimate can improve to read

$$\|\text{error}\| \le \frac{\sqrt{6}}{12\pi} |\Re K|^{-1/2} |K|^2 h^2 + O(|\Re K|^{-1/2} |K|^3 h^4).$$

## 25.7 Adequacy

The above analysis still holds even in the more practical case in which $|K| \to \infty$ as $h \to 0$, provided that

$$K \ll h^{-2}.$$

Thus, the above error estimates are still valid, which means that the finite-difference scheme is adequate in the sense of [67].

The solution of the above example aligns with the Cartesian directions and indeed with the cubic grid used in the finite-difference scheme. This is why it is no surprise that the finite-difference scheme seems suitable for this example, perhaps even more than standard finite-element schemes that use a mesh that doesn't necessarily align with the Cartesian directions. Still, when used with adaptive refinement, the finite-element scheme can become superior to the finite-difference scheme not only in this special example, but also in more general cases in which the solution doesn't necessarily align with the cubic grid. This is indeed shown in the numerical results below.

What is the best mesh-refinement strategy for this problem? In the above model case in which the solution aligns with the Cartesian coordinates, the answer can be given in advance. Indeed, because the solution depends on $x$ only, one would like to refine in the $x$-direction only, leaving the other spatial directions undefined. This approach would reduce the total number of grid points considerably, resulting in a very efficient scheme.

Still, this scheme would be accurate for this particular example only. In more general cases, with more complicated boundary conditions or right-hand side or with a nontrivial nonlinear term, a more automatic mesh-refinement process is required. Such a process is introduced below.
