# Hexadecimal to binary

To transform the base 16 to base two is sufficient to remember that each hexadecimal digit results in four binary digits, and then transform each one in four orders.

Example: Turning 0xBC5 in binary number.

B(16)=11  11|2  5|2  2|2  1|2  B(16)=1011(2)
  1 5  1 2  0 1  1 0

C(16)=12  12|2  6|2  3|2  1|2  C(16)=1100(2)
  0 6  0 3  1 1  1 0

5(16)=5  5|2  2|2  1|2  5(16)=0101(2)
  1 2  0 1  1 0

We have: BC5(16)=101111000101(2).

Remark: The octal base is also important, but not as much as the binary and hexadecimal ones. The handling is similar to that of the latter.
