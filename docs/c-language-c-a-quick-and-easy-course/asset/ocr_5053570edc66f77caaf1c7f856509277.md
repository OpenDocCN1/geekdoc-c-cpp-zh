# Arithmetical operators

In decreasing order of precedence, the arithmetical operators in C are as follows:

| Operator | Role |
|---|---|
| - | unary (signal) |
| + | unary (signal) |
| ++ | unary (increment) |
| -- | unary (decrement) |
| * | multiplicative (multiplication) |
| / | multiplicative (division) |
| % | multiplicative (remainder of the division) |
| + | additive (sum) |
| - | additive (subtraction) |

Remark: The powering operation will be obtained by the pow() function, of the header file math.h.

# Boolean operators

The following are the logical, or Boolean, operators in C:

| Operator | Role |
|---|---|
| ! | unary (not) |
| && | binary (and) |
| || | binary (or) |
