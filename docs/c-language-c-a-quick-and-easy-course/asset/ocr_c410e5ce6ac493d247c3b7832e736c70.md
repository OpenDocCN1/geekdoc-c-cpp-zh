# CHAPTER 11

# HANDLING OF FILES - the fopen() function

For Input/Output (or I/O) of data in discs or terminal devices, ports and printers, C language has two forms of handling: the standard input/output, or high level, defined by ANSI, and the system-level input/output, which has been adopted by the UNIX operating system, but has not been included in the ANSI standard.

The streams of I/O are called stdout (standard output), stdin (standard input, keyboard), stderr (error output), stdaux (auxiliary device) and stdprn (printer).

The high level I/O is also called bufferized I/O, because the flow (‘stream’) of bytes is stored in a buffer, before being passed to its final destination.

The stdio.h header functions for handling files in I/O standard are:

| clearerr() | fputc() | getchar() | scanf() |
|---|---|---|---|
| Fclose() | fputs() | gets() | setbuf() |
| feof() | fread() | perror() | setvbuf() |
| ferror() | freopen() | printf() | sprintf() |
| Fflush() | fscanf() | putc() | sscanf() |
| fgetc() | fseek() | putchar() | tmpfile() |
| Fgetpos() | fsetpos() | puts() | tmpnam() |
| fgets() | ftell() | remove() | ungetc() |
| fopen() | fwrite() | rename() | vfprintf() |
| fprintf() | getc() | rewind() | vprintf() |
|  |  |  | vsprintf() |

In addition to the above functions in the stdio.h header file, there are also constants as EOF, NULL and SEEK_SET.
