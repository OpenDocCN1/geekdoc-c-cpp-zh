Another way to the swap technique is to use a somewhat surprising feature. You assign to x the sum of two variables, x + y. Then you assign to y the difference x-y, which now means the sum minus y, i.e., x + y - y. At this point, y has the value that was in the original x. And as the new x is storing the initial sum, simply deduct the new y, which is the old x, making x =x-y. For example, if we have x = 7 and y = 5, we do x = 7+5, which gives x = 12; then we do y =x-y, that now means 12-5, and then we have y = 7; now, x = x-y, which is 12-7, getting x = 5.
