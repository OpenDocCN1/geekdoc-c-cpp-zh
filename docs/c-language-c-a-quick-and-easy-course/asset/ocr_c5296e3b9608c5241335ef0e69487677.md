# Selective sorting

For comparison, and cultural enrichment, the next example-program shows a more rudimentary algorithm, slower and more intuitive for ordination. There are several other similar processes, but it is sufficient, for our purposes here, to know the selective sorting algorithm

# Example-program #12C

```
/* Program “Selecor.cpp” */
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#define TOTAL 60
int mat[TOTAL];
void Selectsort() /* Selectsort Algorithm */
{
 int i,j,k;
 for(i=0;i<TOTAL;i++)
 {
  k=i;
  for(j=i+1;j<TOTAL;j++) if(mat[j]<mat[k]) {
   int h=mat[k]; mat[k]=mat[j];mat[j]=h;
  }
 }
}
main() /* Array to sort */
{
 int i; srand(time(NULL));
 for(i=0;i<TOTAL;i++) mat[i]=rand();
 puts("n Original array:");
 for(i=0;i<TOTAL;i++) printf("%8d",mat[i]);
 puts("n Sorted array:");
}
```
