## 27.6.3 Class template istream_bufiter

The class template istream_bufiter defines an input iterator (27.2.3) that reads characters from the streambuf for which access to the current character is provided. When each iterator is evaluated, the iterator advances to the next input. If the end of stream is reached (ambuf_type::getc() traits::eof()), the iterator becomes the end-of-stream iterator value. The default constructor istream_bufiter() and the constructor istream_bufiter(0) construct an end-of-stream iterator suitable for use as an end-of-range. All specializations of istream_bufiter shall have a trivial copy constructor, and a constexpr default constructor, and a trivial destructor.

+ 2. The result of operator*() on an end-of-stream iterator is undefined. For any other iterator value a char_type value is returned. It is impossible to assign a character via an input iterator.
