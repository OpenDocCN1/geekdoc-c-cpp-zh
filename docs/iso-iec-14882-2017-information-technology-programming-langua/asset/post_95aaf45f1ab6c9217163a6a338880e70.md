## 23.17.3 Clock requirements [time.clock.req]

- 1 A clock is a bundle consisting of duration, a time_point, and a function to get the current time_point. The origin of the clock time_point is referred to as the clock's epoch. A clock shall meet the requirements in Table 52.
- 2 In Table 52 C1 and C2 denote clock types. t1 and t2 are returned by Ci::now() where the call returning t1 happens before (4.7) the call returning t2 and both of these occur before Ci::time_point::max(). [Note: This means Ci did not wrap around between t1 and t2. — end note]

Table 52 — Clock requirements

| Expression | Return type | Operational semantics |
|---|---|---|
| C1::rep | An arithmetic type or a class emulating an arithmetic type | The representation type of C1::duration. |
| C1::period | a specialization of ratio | The tick period of the clock in seconds. |
| C1::duration | chrono:duration<C1::rep, C1::period> | The duration type of the clock. |
| C1::time_point | chrono:time_point<C1> or chrono:time_point<C2, C1::duration> | The time_point of the clock. C1 and C2 shall refer to the same epoch. |
| C1::is_steady | const bool | true if <= C2 is always true and the time between clock ticks is constant, otherwise false. |
| C1::now() | C1::time_point | Returns a time_point representing the current point in time. |

- 3 [Note: The relative difference in these durations is reported by a clock and the SI definition is a measure of the quality of implementation. — end note]

  (4.1) TC satisfies the clock requirements (23.17.3),
  (4.2) the types TC::rep: duration, and TC::time_point satisfy the requirements of EqualityComparable (Table 20), HashComparable (Table 21), DefaultConstructible (Table 22), CopyConstructible (Table 24), Copyable (Table 26), Desturable (Table 27), and the requirements of numeric types (29.3).   (4.4) the function TC::now() does not throw exceptions, and
  (4.5) the type TC::time_point::clock meets TrivialClock, recursively.

## 23.17.4 Time-related traits [time.traits]

### 23.17.4.1 treat_as_floating_point [time.traits.is_fp]

```cpp
template <class Rep> struct treat_as_floating_point
: is_floating_point<Rep> {};
```

1 The duration uses the treat_as_floating_point trait to determine if a duration object can be converted to another duration with a different tick period. If treat_as_floating_point<Rep> is true, implicit conversions are allowed among durations. Otherwise, the implicit convertibility depends on the tick periods of the durations. [Note: The intention of this trait is to indicate whether a class behaves like a floating-point type, and thus division of one value by another with acceptable loss of precision. If treat_as_floating_point<Rep> is false, it is rejected if it behaved like an integral type for the purpose of these conversions. — end note]

## 23.17.5 Class duration [time.duration]

1 A duration measures between two points in time (time_points). A duration has a count of ticks and a tick period. The tick period is the amount of time which occurs from one to the next, in units of seconds. It is expressed as a rational constant using the ratio.
