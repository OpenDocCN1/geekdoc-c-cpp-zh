
# ISO/IEC 14882:2017(E)

## 30.10.15.22 Is regular file

[fs.op.is_regular_file]

```
bool is_regular_file(file_status s) noexcept;
  Returns: s.type() == file_type::regular;
bool is_regular_file(const path& p);
  Returns: is_regular_file(status(p));
Throws: filesystem_error if status(p) would throw filesystem_error.
bool is_regular_file(const path& p, error_code& ec) noexcept;
  Effects: Set ec as if status(p, ec). [Note: file_type::none, file_type::not_found and file_type::unknown sets ec to error values. To distinguish between cases, call the status function.]
  is_regular_file(status(p, ec)). Returns false if an error occurs.
```

# 30.10.15.25 Last write time

[fs.op.last_write_time]

```
file_time last_write_time(const path& p);
file_time last_write_time(const path& p, error_code& ec) noexcept;
  Returns: The time of last modification of p. as determined as if by the POSIX stat
  structure st_mtime assigned as by POSIX stat(0). The signature with argument ec
  returns file_time::min() if an error occurs.
  Throws: As specified in 30.10.7.
void last_write_time(const path& p, file_time_type new_time);
void last_write_time(const path& p, error_code& ec) noexcept;
  Effects: Set the time of last modification of the file resolved to p to new_time, as if by POSIX
  futimes().
```

Throws: As specified in 30.10.7.

[Note: A postponement of last_write_time(p) == new_time is not specified since it might not hold for file systems with coarse granularity. — end note]

# 30.10.15.26 Permissions [fs.op.permissions]

```
void permissions(const path p, perms prms, perm_options opts=perm_options::replace);
void permissions(const path p, perms prms, error_code ec) noexcept;
void permissions(const path p, perms prms, perm_options opts, error_code ec);
```

- 1 Requires Exactly one of the perm_options replace, add, or remove is present in opts.
- 2 Remarks: The signature behaves as if it had an additional parameter perm_options opts with an argument of opts::replace.
- 3 Effects: The action applied by opts to the file p resolves, or to p itself if p is a symbolic link and perm_options::nofollow is set as by POSIX fchmod(at).
- 4 [Note: Contextual permissions are viewed as bits, but the actual implementation may use some other mechanism. — end note]
- 5 Throws: As specified in 30.10.7.

# 30.10.15.30 Remove

```
bool remove(const path& p);
bool remove(const path& p, error_code ec) noexcept;
```

Effects: If exists(symlink_status(p, ec)), the file p is removed as if POSIX remove(). [ Note: A symbolic link is itself removed, rather than the file it resolves to. — end note]

- 2 Postconditions: exists(symlink_status(p)) is false.
- 3 Returns: if p did not exist, otherwise true. The signature with argument ec returns false if an error occurs.
- 4 Throws: As specified in 30.10.7.

# 30.10.15.31 All

```
uintmax_t remove_all(const path& p);
uintmax_t remove_all(const path& p, error_code ec) noexcept;
```

Effects: Recursively deletes the contents of p if it exists, deletes p itself, as by POSIX remove(). [ Note: A symbolic link is itself removed, rather than the file it resolves to. — end note]

- 2 Postconditions: exists(symlink_status(p)) is false.
- 3 Returns: The number of files removed. The signature with argument returns static_cast<uintmax_t>(-1) if an error occurs.
- 4 Throws: As specified in 30.10.7.

# 30.10.15.32 Rename

```
void rename(const path& old_p, const path& new_p);
void rename(const path& old_p, const path& new_p, error_code ec) noexcept;
```

- 1 Effects: Moves old_p to new_p as if by POSIX rename(). [ Note:
(1.1) If old_p and new_p resolve to the same existing file, no action is taken.
(1.2) Otherwise, the rename may include the following effects:
(1.2.1) — if new_p resolves to an existing non-directory file, new_p is removed, otherwise;
— if new_p resolves to an existing directory, new_p is removed if empty on POSIX compliant operating systems but may be on other operating systems.
A symbolic link is itself renamed, rather than the file it resolves to. — end note]
2 Throws: As specified in 30.10.7.

# 30.10.15.34 Space

```
space_info(const path& p);
space_info(const path& p, error_code ec) noexcept;
```

Returns: An object of type space_info. The value of the space_info is determined as if by using POSIX statfs to obtain a POSIX struct statfs, and then multiplying its f_blocks, f_bfree, and f_available members respectively by its f_size, and assigning to the capacity, free, and available members set to static_cast<uintmax_t>(-1). For the signature with argument ec, all members will be set to static_cast<uintmax_t>(-1) if an error occurs.

- Throws: As specified in 30.10.7.
Achieves: The value of space_info::available is operating system dependent. [Note: available may be less than free. — end note]

# 30.10.15.35 status

```
file_status(const path& p);
```

- Effects: If
error_code ec;
file_status result = status(p, ec);
if (result.type() == file_type::none)
throw filesystem_error(implementation-supplied-message, p, ec);
return result;

- Returns: See below.
Throws: Result values of file_status(file_type::not_found) and file_status(file_type::unknown) are not considered failures and do not cause an exception to be thrown. — end note

```
file_status(const path& p, error_code ec) noexcept;
Effects: If, determines the attributes of the path p resolves to, as by using POSIX stat(). If, during determination, the underlying system API reports an error, ec to indicate the specified error. Otherwise, ec.clear(). [Note: This allows users to specify the details of API errors even when the value returned by status() is not file_status(file_type::none). — end note
```

Let perms the result of (m & per::mask), where m is determined as by converting the st_mode of the observed struct stat to the type per.

- Returns:
If ec != error_code():
If the specific error indicates that p cannot be resolved because some element of the path does not exist, returns file_status(file_type::not_found).
