An entity is captured if it is captured explicitly or implicitly. An entity captured by a lambda-expression, its expression is odr-reduced (6.2) in the scope containing it. If *this is not defined or captured by the enclosing function shall be a non-static member function. If a lambda-expression or an instantiation of the generic lambda template of a generic lambda odr-uses (6.2) this or a variable with automatic storage duration from its scope, this entity shall be captured by the lambda-expression an entity that is not defined or captured in the immediately enclosing lambda expression or, the program is ill-formed.     int s = i;
