5 Remarks: If [first, last1) contains m elements that are equivalent to each other and [first2, last2) contains n elements that are equivalent to them, then all m elements from the first range shall be copied to the output range, and then max(n - m, 0) elements from the second range shall be copied to the output range, in order.

+   1 Requires: The resulting range shall not overlap with either of the original ranges.

+   2 Effects: Constructs a sorted intersection of the elements from the two ranges; that is, the set of elements that are present in both of the ranges.

+   3 Returns: The end of the constructed range.

+   4 Complexity: At most 2 * (last1 - first1) + (last2 - first2) - 1 comparisons.

+   5 Remarks: If [first, last1) contains m elements that are equivalent to each other and [first2, last2) contains n elements that are equivalent to them, then min(m,n) elements shall be copied from the first range to the output range, in order.
