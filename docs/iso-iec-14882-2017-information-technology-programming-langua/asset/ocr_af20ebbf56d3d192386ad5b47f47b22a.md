The instantiation context of an expression that depends on the template arguments is the set of declarations

one-definition rule (6.2), the program is ill-formed, no diagnostic is required.

# 17.6.4 Candidate functions [temp.dep.candidate]

+   For a call where the proper-expression is a name, the candidate functions are found using
the usual lookup rules (6.4.1, 6.4.2) except:

+   For the part of the lookup unqualified name lookup (6.4.1), only function declarations from the
template definition are found

+   For the part of the lookup in associated namespaces (6.4.2), only function declarations are found
inther the template definition context or the template instantiation context are found.

If the call would be ill-formed or would find a better match the lookup within the associated
namespaces considered all function declarations found in those namespaces in all translation
units, not just those declarations found in the template definition and template instantiation
contexts, then the program has undefined behavior.

# 17.6.5 Friend names declared within a class template [temp.inject]

Friend classes or functions can be declared within a class template. When a template is instantiated,
the names of its friends are treated as if the specialization had been explicitly declared at its point of instantiation.

With non-template classes, the names of namespace-scope friends of a class template specialization
are not visible during an ordinary lookup unless explicitly declared at namespace scope.
may be found under the rules for associated classes (6.4.2).^{140} (14.3) Example:

```
template<typename T> struct number {
number(int);
 friend gcd(number x, number y) { return 0 };
};

void gcd() {
  number<double> a(3), b(4);
  a = gcd(a,b); // finds gcd because number<double> is an associated class,
  b = gcd(3,4); // making gcd visible in its namespace (global scope)
} // ill-formed: gcd is not visible
```

140) Friend declarations do not introduce new names into any scope, either when the template is declared or when it is
stantiated.
