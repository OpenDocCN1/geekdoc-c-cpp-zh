# 30.2.2 Assign and swap

```
basic_stringbuf operator=(basic_stringbuf& rhs)
```

Effects: After the move assignment *this has the observable state it would have had if it had been moved from rhs (see 30.8.2.1).

Returns: *this.

```
void swap(basic_stringbuf& rhs);
```

Effects: Exchanges the state of *this and rhs.

```
template <class charT, Traits, Allocator>
void swap(basic_stringbuf<charT, Traits, Allocator>& x,
     basic_stringbuf<charT, Traits, Allocator>& y);
```

Effects: as if x.swap(y).

# 30.2.3 Member functions

```
basic_stringbuf<charT, Traits, Allocator> const();
```

Returns: A basic object whose content is equal to the basic_string underlying character sequence. If the basic_string was created in only input mode, the resultant basic_string contains the character sequence in the range [eback(), eptr()). If the basic_string was created with && ios_base::out being nonzero the resultant basic_string contains the character sequence in the range [pbase(), mark), where high_mark represents the position of the last character initialized by writing to the stream, by constructing the basic_stringbuf with a basic_string, or by calling the str(string) member function. In the case of the call of str(string) member function, all characters initialized are now considered uninitialized (except for those characters re-initialized by the new basic_string). Otherwise the basic_stringbuf has been created in neither input mode and a zero length basic_string is returned.
