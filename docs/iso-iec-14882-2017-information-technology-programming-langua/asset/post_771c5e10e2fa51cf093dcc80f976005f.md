## 21.6.2.4 Data races

- For purposes of determining the existence of data races, the library versions of operator new, replacement versions of global operator new, the C standard library functions aligned_alloc, calloc, and malloc; the library versions of operator delete, replacement versions of operator delete, the C standard library free and the C standard library alloc shall not introduce a data race (20.5.9). All calls to allocate and deallocate particular of storage occur in a single total order, and each deallocation shall happen before (4.7) the next allocation (if any) in this order.

## 21.6.3 Storage allocation errors

### 21.6.3.1 Class bad_alloc

```cpp
namespace std {
    class bad_alloc : public exception {
    public:
        bad_alloc() noexcept;
        bad_alloc(const bad_alloc&) noexcept;
        bad_alloc& operator=(const bad_alloc&) noexcept;
        virtual const char* what() const noexcept override;
    };
};
```

- The class bad_alloc defines the types of objects thrown as exceptions by the implementation to report a failure to allocate storage.

```cpp
bad_alloc() noexcept;
```

Effects: Constructs an object of class bad_alloc.

```cpp
bad_alloc(const bad_alloc&) noexcept;
bad_alloc& operator=(const bad_alloc&) noexcept;
```

Effects: Copies an object of class bad_alloc.

```cpp
const char* what() const noexcept override;
```

Returns: An implementation-defined NTBS.

Remarks: The message may be a multibyte string (20.4.2.15.2), suitable for conversion and display as a wstring (24.3, 25.4.1.4).

### 21.6.3.2 Class bad_array_new_length

```cpp
namespace std {
    class bad_array_new_length : public bad_alloc {
    public:
        bad_array_new_length() noexcept;
        virtual const char* what() const noexcept override;
    };
};
```

The class bad_array_new_length defines the type of objects thrown as exceptions by the implementation to report an allocation of an array size less than or greater than an implementation-defined limit (8.3.4).

```cpp
bad_array_new_length() : noexcept;
```

Effects: constructs an object of class bad_array_new_length.

```cpp
const char* what() const noexcept override;
```

Returns: An implementation-defined NTBS.

Remarks: The message may be a non-multibyte string (20.4.2.1.5.2), suitable for conversion and display as a wide string (24.3, 25.4.1.4).

### 21.6.3.3 Type new-handler [new.handler]

```cpp
using new_handler = void (*)();
```

- The type of a handler function to be called by operator new() or operator new[] (21.6.2) when they cannot satisfy a request for additional storage.

- Required Behavior: a new-handler shall perform one of the following:
  (2.1) make sure storage is available for allocation and then return;
  (2.2) throw an exception of type bad_alloc or a class derived from bad_alloc;
  (2.3) terminate the execution of the program without returning to the caller.

### 21.6.3.4 set new-handler [new.handler]

```cpp
new_handler set_new_handler(new_handler new_p) noexcept;
```

Effects: establishes the function designated by new_p as the current new-handler.

Returns: The previous new-handler.

Remarks: The initial new-handler is a null pointer.

### 21.6.3.5 get_new-handler [new.handler]

```cpp
new_handler get_new_handler() noexcept;
```

Returns: The current new-handler. [Note: This may be a null value.]

## 21.6.4 Pointer optimization barrier [ptr.launder]

```cpp
template <class T> T* launder(T* p) noexcept;
```

- Requires: p represents the address A of a byte in memory. An object X that is within its lifetime (6.8) whose type is similar (7.5) to T is located at address A. All stores of type that are reachable through the result are reachable (see below).

- Returns: A value of type T* pointing to X.

- Remarks: An invocation of this function may be used in a constant expression whenever the value of its argument is used in a constant expression. A store of type that is reachable through a pointer that points to an object Y if it is within the storage occupied by X, or a pointer-interconvertible with Y, or the immediately-enclosing array object if Y is an array element. The program is ill-formed if T is a array or void.

Note: If a new object is created in storage occupied by an existing object of the same type, a pointer to the original object can be used to refer to the object unless the type contains const or reference members; in the latter cases, this function can be used to obtain a pointer to the new object. See 6.8.

Example:

```cpp
struct X { const int n; };
X *p = new X(3);
const int a = p->n; // p does not point to object (6.8) because X::n is const
const int b = p->n; // undefined behavior
const int c = std::launder(p)->n; // OK
```

## 21.6.5 Hardware interference size

```cpp
inline size_t hardware_interference_size;
```

This number is the minimum size between concurrently accessed objects to avoid performance degradation due to contention. It should be at least alignof(max_t).

## 21.7 Type identification

### 21.7.1 Header <typeinfo> synopsis

```cpp
namespace std {
    class type_info;
    class bad_cast;
}
```

### 21.7.2 Class type_info [type.info]

```cpp
namespace std {
    class type_info {
    public:
        virtual ~type_info() noexcept;
        bool operator==(const type_info& rhs) const noexcept;
        bool operator!(const type_info& rhs) const noexcept;
        bool before(const type_info& rhs) const noexcept;
        size_t hash_code() const noexcept;
        virtual const char* name() const noexcept;
    };
}
```

- The class type_info describes type information generated by the implementation (8.2). Objects of this class store a pointer to a name, and an encoded value for comparing types. The names, encoding, and calling sequence for types are all unspecified and may differ by programs.

- bool operator==(const type_info& rhs) const noexcept;
  Effects: Compares the current object with rhs.
  Returns: true if the two values describe the same type.

- operator!(const type_info& rhs) const noexcept;
  Returns: (*this == rhs).

- bool before(const type_info& rhs) const noexcept;
  Effects: Compares the current object with rhs.
  Returns: true if *this precedes rhs in the implementation's collation order.

- size_t hash_code() const noexcept;
  Returns: An unspecified value, except that within a single execution of the program, it shall return the same value for any two type_info objects which compare equal.
  Remarks: An implementation may return different values for two type_info objects which do not compare equal.

- const char* name() const noexcept;
  Returns: An implementation-defined NTBS.
  Remarks: The message may be a null-terminated multibyte string (20.4.2.1.5.2), suitable for conversion and display as (24.3, 25.4.1.4).

- type_info(const type_info& rhs) = delete;
- type_info& operator=(const type_info& rhs) = delete;
