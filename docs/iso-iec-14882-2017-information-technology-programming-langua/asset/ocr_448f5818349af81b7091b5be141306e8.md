If a base class is accessible, one can implicitly convert a pointer to a derived class to a pointer to that X*
class (7.11, 7.12). [Note: It follows that members and friends of a class X can implicitly convert X* to a
pointer to a private or protected member class of X. The access to a member is affected
by the class in which the member is named. This class is the member which the member is looked up. [Note: This class can be explicit, e.g., when a qualified-id is used, or implicit, e.g.,
when a class member access operator (8.2.5) is used (including cases where an implicit "this->" is added).
If both a class member access operator and a qualified-id are used to name the member (as in p->T), then the
class naming the member is defined by the nested-name-specifier of the qualified-id (that is, T).\end note] A member is accessible at the point R when named in class H
