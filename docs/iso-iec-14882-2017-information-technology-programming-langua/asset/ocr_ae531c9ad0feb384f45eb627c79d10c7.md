# 30.5.3.3 ios_base functions [ios.base.locales]

```
locale imbue(const locale& loc);
```

1 Effects: Each registered callback (fn, index) (30.5.3.6) as (*fn) (imbue_event, *this, index) at a time that a call to ios_base::getloc() from within fn returns the new locale loc.

2 Returns: The previous value of getloc().

3 Postconditions: loc == getloc().

4 Returns: If no locale has been imbued, copy of the global C++ locale, locale(loc), in effect at the time of construction. Otherwise, returns the imbued locale, to be perform locale-dependent input and output operations.

# 30.5.3.4 ios_base static members [ios.members.static]

```
bool sync_with_stdio(bool sync = true);
```

1 Returns: If the previous state of the iostream objects (30.4) was synchronized and otherwise returns false. The first time it is, the function returns true.

2 Effects: If any input or output operation has occurred the standard streams prior to the call, the implementation is implementation-defined. Otherwise, with a false argument, it allows the standard streams to operate independently of the standard C streams.

3 When a standard i object str is synchronized with a standard std stream f, the effect of inserting a character c by

```
fputc(f, c);
```

is the same as the effect of
str.rdbuf()->put(c);
for any sequences of characters; the effect of extracting a character c
c = fgetc(f);
