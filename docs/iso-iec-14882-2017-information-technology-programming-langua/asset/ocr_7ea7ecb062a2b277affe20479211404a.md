# 23.11.2.20 get_deleter [util.smartptr.deleter]

```
template<class D, class T>
get_deleter(const D& d) returns address_of(d) noexcept;
```

+   1 Returns: If p returns a pointer to d, of uninvalided d, returns address_of(d); otherwise returns nullptr. The pointer remains valid as long as there exists a shared_ptr instance that owns d. [Note: It is unspecified whether the pointer remains longer than that. This can happen if the implementation doesn't destroy the deleter until all shared_ptr instances share ownership with p have been destroyed. — end note ]

# 23.11.2.23 Class template weak_ptr [util.smartptr.weak]

1 The weak_ptr class stores a reference to an object that is already managed by a shared_ptr. To access the object, a weak_ptr can be converted to a shared_ptr using the following method constructor:

```
namespace std {
  template<class T> class weak_ptr {
  public:
    using element_type = T;
```

```
// 23.11.2.3.1, constructors
constexpr weak_ptr() noexcept;
template<class T> weak_ptr(const shared_ptr<T>& r) noexcept;
template<class T> weak_ptr(const weak_ptr<T>& r) noexcept;
weak_ptr(weak_ptr<T> r) noexcept;
template<class T> weak_ptr(weak_ptr<T>&& r) noexcept;
```

```
// 23.11.2.3.2, destructor
~weak_ptr();
```

```
// 23.11.2.3.3, assignment
weak_ptr& operator=(const weak_ptr<T>& r) noexcept;
template<class Y> weak_ptr& operator=(const shared_ptr<Y>& r) noexcept;
template<class Y> weak_ptr& operator=(const shared_ptr<Y, Deleter>& r) noexcept;
weak_ptr& operator=(const shared_ptr<Y, Deleter>&& r) noexcept;
```
