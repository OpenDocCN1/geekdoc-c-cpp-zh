piecewise_linear_distribution();

Effects: Constructs a piecewise_linear_distribution with n = 1, ρ₀ = ρ₁, b₀ = 0, and b₁ = 1.

```
template<class InputIteratorB, class InputIteratorW>
piecewise_linear_distribution(InputIteratorB first, InputIteratorB last, InputIteratorW fw = InputIterator())
```

Requires: InputIteratorB and InputIteratorW each satisfy the requirements of an input iterator (Table 95). Moreover, iterator_traits<InputIteratorB>::value_type and iterator_traits<InputIteratorW>::value_type must be convertible to double. If firstB == +firstW == last, then n = 1, ρ₀ = ρ₁, b₀ = 0, and b₁ = 1. Otherwise, [firstB, lastB) shall form a sequence of length n + 1, and the length of the sequence starting from firstW shall be at least n+1, and any $w_k$ for $k \ge n+1$ shall be ignored by the distribution.

Effects: Constructs a piecewise_linear_distribution with parameters as specified above.

```
template<class UnaryOperation>
piecewise_linear_distribution(initial_value, list<RealType>, UnaryOperation fw)
```

Requires: Each instance of UnaryOperation shall be a function object (23.14) whose return type shall be convertible to double. Moreover, if $b1.size() < 2$, then n = 1, ρ₀ = ρ₁, b₀ = 0, and b₁ = 1. Otherwise, let $[b1.begin(), b1.end())$ form a sequence $b_0, \dots, b_n$, and $w_k = fw(b_k)$ for $k = 0, \dots, n$.

Complexity: The number of invocations of fw shall not exceed n + 1.

```
template<class UnaryOperation>
piecewise_linear_distribution(size_t nw, RealType, RealType, UnaryOperation fw)
```

Requires: Each instance of UnaryOperation shall be a function object (23.14) whose return type shall be convertible to double. Moreover, if $nw = 0$, then $n = 1$, otherwise $n = nw$. The relation $0 < \delta = (xmax - xmin)/n$ should hold.

Effects: Constructs a piecewise_linear_distribution with parameters taken or calculated from the following values: $bk = xmin + k\delta$ for $k = 0, \dots, n$, and $w_k = fw(b_k)$ for $k = 0, \dots, n$.

Complexity: The number of invocations of fw shall not exceed n+1.

```
vector<result_type> intervals() const;
```

Returns: A vector<result_type> returns n + 1 and operator[] returns member $b_k$ when invoked with argument $k=0, \dots, n$.
