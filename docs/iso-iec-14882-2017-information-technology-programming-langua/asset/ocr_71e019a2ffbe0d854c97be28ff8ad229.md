# ISO/IEC 14882:2017(E)

```
template <class InputIterator>
set(InputIterator first, InputIterator last,
 const Compare& comp = Compare(), const Allocator& alloc = Allocator());
```

+   Effects: Creates an empty set using the specified comparison object and allocator, and inserts elements from the range [first, last).

+   Complexity: Linear in N if the range [first, last] is already sorted using comp and otherwise log N, where N is last - first.

# 26.4.6.3 set specialized algorithms [set.special]

```
template <class Key, class Compare, class Allocator>
void swap(set<Key, Compare, Allocator>& x, set<Key, Compare, Allocator>& y)
 noexcept(noexcept(x.swap(y)));
```

Effects: As by if x.swap(y).

# 26.4.7 Class template multiset [multiset.overload]

# 26.4.7.1 Class multiset iterator

+   A multiset is an associative container that supports keys (possibly contains multiple copies of the same value) and provides retrieval of the elements. The multiset supports bidirectional iterators.

+   A multiset satisfies all the requirements of a reversible container (26.2), of an associative container (26.6), and of an allocator-container (Table 86). multiset also provides most operations in 26.6 for duplicate keys. This means that a multiset supports the a_eq operations in 26.6 but not the uq_operations. For a multiset<Key> the key_type and value_type are Key. Descriptions are provided only for operations on multiset that are not described in one of these tables and for which there is semantic difference.
