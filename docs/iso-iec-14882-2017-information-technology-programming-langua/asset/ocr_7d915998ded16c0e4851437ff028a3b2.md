5 The resulting substituted and adjusted function type is used as the type of the function template for argument deduction. If a template argument has not deduced and its corresponding template argument has a default argument, the template argument is determined by substituting the template arguments for determining template parameters into the default argument. If the substitution results in an invalid type, described type deduction fails. [Example:

```
template <class T, U = double>
void f(T t = 0, U u = 0);

void g() {
    f(1, 'c');          // <int,char>(1,0)
    f(1);               // <int,double>(1,0)
    f();               // error: T cannot be deduced
    f<int>>();           // <int,double>(0,0)
    f<int,char>();      // <int,char>(0,0)
}
-- end example
```

When all template arguments are deduced or obtained from default template arguments, all of template parameters in the template parameter list and the function type are used with the corresponding deduced or default argument values. If the substitution results in an invalid type, type deduction fails.

6 At certain points in the template argument deduction process it is necessary to take a type that makes use of template parameters and replace those with the corresponding template arguments. This is done at the beginning of template argument deduction when any explicitly specified arguments are substituted into the function type, and at the end of template argument deduction when any template arguments are deduced or obtained from default argument declarations.

7 The substitution occurs in all types and expressions that are used in the function type and template argument expressions include not only constant expressions as those that appear in array bounds or nontemplate arguments (i.e., non-constant expressions) inside sizeof, declype, and others that allow non-constant expressions. The substitution proceeds in order and stops when substitution fails to deduce anything.
