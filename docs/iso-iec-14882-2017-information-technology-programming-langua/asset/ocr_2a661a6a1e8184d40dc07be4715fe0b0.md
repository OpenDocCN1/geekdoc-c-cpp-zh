# ISO/IEC 14882:2017(E)

```
// 23.17.6.2. observer
constexpr duration time_since_epoch() const;
```

```
// 23.17.6.3. arithmetic
constexpr time_point& operator+=(const duration& d);
constexpr time_point& operator-=(const duration& d);
```

```
// 23.17.6.4. special values
static constexpr time_point min();

;
```

+   1 Clock shall meet the Clock requirements (23.17.3).

+   2 If Duration is not an instance of duration, the program is ill-formed.

# 23.17.6.1 time_point constructors [time.point.cons]

```
constexpr time_point();
```

+   1 Effects: Constructs an object of type time_point, initializing d_ with duration::zero(). Such a time_point object represents the epoch.

```
constexpr explicit time_point(const duration& d);
```

+   2 Effects: Constructs an object of type time_point, initializing d_ with d. Such a time_point object represents the d+.

```
template <class Duration2>
constexpr time_point(const time_point<clock, Duration2>& t);
```

+   3 Remarks: This constructor shall not participate in overload resolution unless Duration2 is implicitly convertible to duration.

+   4 Effects: Constructs an object of type time_point, initializing d_ with t.time_since_epoch().

# 23.17.6.2 time_point observer [time.point.observer]

```
constexpr duration time_since_epoch() const;
```

+   1 Returns: d_.

# 23.17.6.3 time_point arithmetic [time.point.arithmetic]

```
constexpr time_point& operator+=(const duration& d);
```

+   1 Effects: As if: d_ += d;

+   2 Returns: *this.

```
constexpr time_point& operator-=(const duration& d);
```

+   3 Effects: As if: d_ -= d;

+   4 Returns: *this.
