# 7.6 Integral promotions [conv.promotion]

+ 1 A prvalue of an integer type other than bool, char16_t, char32_t or wchar integer type if int can be converted to rank (7.15) is less than the rank of type (9.2) of unsigned int; unsigned int, long, unsigned long int can represent all values of its underlying type; otherwise, the source can be converted to a prvalue of unsigned int.

+ 2 A prvalue of type char16_t, char32_t, or wchar_t (6.9.1) can be converted to a prvalue of the first of following types that can represent all values of its underlying type: unsigned int, long int, unsigned long int long long int, unsigned long long int. If none of the types in that list can represent all values of its underlying type, a prvalue of char16_t, char32_t, or wchar_t can be converted to a prvalue of its underlying type.

+ 3 A prvalue of an unscoped enumeration type whose type is not fixed (10.2) can be converted to a value of the first of the following types that can represent all values of the enumeration (the values of the base-type, from min to max) are (9.2): unsigned int, long int, unsigned long int, long int, unsigned long long int. If none of the types in that list can represent all values of the enumeration, a prvalue of unscoped enumeration type can be converted to a prvalue of the integer with lower conversion rank (7.15) greater than the rank of long in which all the values of the enumeration are represented. If there are two such types, the one signed is chosen.

+ 4 A prvalue of an unscoped enumeration type whose type is fixed (10.2) can be converted to a prvalue of its underlying type. Moreover, if integral promotion can be applied to its type, a value of an unscoped enumeration type whose type is fixed can also be converted to a prvalue of the promoted type.

+ 5 A prvalue of an integral field (12.2.4) can be converted to a prvalue of int if int can represent the values of the bit-field; otherwise, it can be converted to unsigned int if unsigned int can represent all values of the bit-field. If the bit-field is larger, no integral promotion applies to it. If the bit-field has an enumerated type, it is treated as any other value of type for promotion purposes.

+ 6 A prvalue of bool can be converted to a prvalue of int, with false becoming zero and true becoming one.

7 These conversions are called integral promotions.

# 7.8 Integral conversions [conv.integral]

+ 1 A prvalue of an integer type can be converted to a prvalue of another integer type. A prvalue of an unscoped enumeration type can be converted to a prvalue of an integer type.

+ 2 If the destination type is unsigned, the resulting value is the least unsigned integer congruent to the integer (modulo 2^n where n is the number of bits used to represent the result). [Note: In a two’s complement representation, this conversion is conceptual and there is no change in the bit pattern (if there is no truncation). — end note]

+ 3 If the destination type is signed, the value is unchanged if it can be represented in the destination type; otherwise, the value is implementation-defined.

+ 4 If the destination type is bool, 7.14. If the source type is bool, the value is converted to zero and the true is converted to one.

+ 5 The conversions allowed as integral promotions are excluded from the set of integral conversions.

# 7.9 Floating-point conversions [conv.double]

+ 1 A value of floating-point type can be converted to a prvalue of another floating-point type. If the source value can be exactly represented in the destination type, the result of the conversion is exact. If the source is between two destination values, the result of the conversion is an implementation-defined choice of either. Otherwise, the behavior is undefined.

+ 2 The conversions allowed as floating-point promotions are excluded from the set of floating-point conversions.

# 7.10 Floating-integral conversions [conv.int]

+ 1 A value of floating-point type can be converted to a prvalue of an integer type, the fractional part is discarded. The behavior is undefined if the truncated value cannot be represented in the destination type. [Note: If the destination type is bool, 7.14. — end note]

+ 2 A value of integer or unsigned type can be converted to a prvalue of a floating-point type. The result is exact. If the value is within the range of values that can be represented but the truncated value cannot be represented, the conversion is an implementation-defined choice. [Note: Loss of precision occurs if the integral value cannot be represented exactly as a value of the floating-point type — end note] If the value is outside the range of values that can be represented, the behavior is undefined. If the source type is bool, the value is converted to zero and the true is converted to one.

# 7.11 Pointer conversions

+ 1 A null pointer constant is an integer literal (5.3.2) or a prvalue of type std::nullptr_t. A null pointer constant can be converted to a pointer type; the result is the null pointer value of that type and is distinguishable from every other value of pointer or function type. Such a conversion is called a null conversion. Two null pointer values of the same type should compare equal. The conversion of an integral type to a pointer-qualified type is a single conversion, and not the sequence of a pointer conversion followed by a qualification (7.5). [Note: The result of a pointer to type std::nullptr_t is not a null pointer value. — end note]

+ 2 A value of "pointer to cv T", where T is an integer type, can be converted to a prvalue of "pointer to void".

A type of "pointer to cv D", where D is a class type, can be converted to a prvalue of "pointer to cv B", where B is a base (Class 13) of D. If B is an inaccessible (Class 4 or 13.2) base class of D, a program that necessitates this conversion is ill-formed. The result of the conversion is the null pointer converted to the null pointer value of the destination type.

# 7.12 Pointer to member conversions [conv.mem]

+ 1 A null pointer constant (7.11) can be converted to a pointer to member type; the result is the null pointer value of that type and is distinguishable from any pointer to member not created from a null pointer constant. Such a conversion is called a null member pointer conversion. Two null member pointer values of the same type should compare equal. The conversion of a null pointer constant to a pointer to member of cv-qualified type is a single conversion, and not the sequence of the pointer to member conversion followed by a qualification conversion (7.5).

A prvalue of "pointer to member of B of type T", where B is a class type, can be converted to a prvalue of "pointer to member of D of type T", where D is a derived class (Clause 13) of B. If B is an inaccessible (Clause 14), ambiguous (13.2), or virtual (13.1) base class of D, or a base class of a virtual base class of D, a program that necessitates this conversion is ill-formed. The result of conversion refers to the same member as the pointer before the conversion takes, but it refers to the base class as if it were the derived class. The result refers to the member in D's instance of B. Since the result has type "pointer to member of B of type T", induction with an object is valid; the result is the same as if indirecting the pointer to member of B with the subclass of D. The member pointer value is converted to the member pointer value of the destination type.

# 7.13 Function pointer conversions [conv.fptr]

A prvalue of "pointer to noexcept function" can be converted to a prvalue of "pointer to noexcept function". The result is a pointer to the function. A prvalue of "pointer to member of type noexcept function" can be converted to a function of type "pointer to member of noexcept function". The result points to the member

Example:

```
void (*p)();
void (**p)(); // error: cannot convert pointer to noexcept function
struct S { typedef void (*p)(); operator p(); };
void (*q) noexcept(); // error: cannot convert pointer to noexcept function
```
- end example

# 7.14 Boolean conversions [conv.bool]

An arithmetic value, unspecified enumeration, pointer, or pointer type can be converted to a prvalue of type bool. A zero value, null pointer or member pointer value is converted to false; any other value is converted to true. For de-initialization (11.6), a prvalue of type std::nullptr_t can be converted to a prvalue of type bool; the resulting value is false.

# 7.15 Integer conversion rank [conv.rank]

Every integer type has an integer conversion rank defined as:

+ No signed integer types other than char and signed char (if char is signed) have the same rank, even if they have the same representation.

+ The rank of long int type shall be greater than the rank of long int, which is greater than the rank of int, which shall be greater than the rank of short int, which shall be greater than the rank of signed char.

+ The rank of any unsigned integer type equal the rank of the corresponding unsigned integer type.

+ The rank of any standard integer type shall be greater than the rank of any extended integer type with the same size.
