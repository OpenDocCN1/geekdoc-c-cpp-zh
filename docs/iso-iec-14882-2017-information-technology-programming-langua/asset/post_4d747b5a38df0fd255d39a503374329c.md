## 30.6.3.4.4 Putback

```cpp
int_type putback(int_type c = traits::eof());
```

1 Remarks: The public functions of basic_backbuf call this function only when gptr() is null, gptr() == eback(), or traits::eq(traits::to_char_type(c), gptr()[-1]) returns false. Other calls must also satisfy that constraint.

The pending sequence is defined as for underflow():

- (1.1) If traits::eq_int_type(c, traits::eof()) returns true, then the input sequence is backed up one character before the pending sequence is determined.
- (1.2) If traits::eq_int_type(c, traits::eof()) returns false, then c is prepended. Whether the input sequence is backed or modified in any way is specified.

2 Postconditions: On the return of gptr(), eback(), and pptr() are the same as for underflow().

3 Returns: traits::eof() to indicate failure. Failure may occur because the input sequence could not be backed up, or if some other reason the pointers could not be consistent with the constraints.

## 30.6.3.4.5 Put area

```cpp
streamize xsput(const char* s, streamize n);
```

1 Effects: Writes n characters to the output sequence if repeated calls to sput(c) fail when either n characters have been written or a call to sput(c) would return traits::eof().

2 Returns: The number of characters written.

```cpp
int_type overflow(int_type c = traits::eof());
```

3 Effects: Consumes some initial subsequence of the pending sequence. The pending sequence is defined as the concatenation of:
- (3.1) the empty sequence if gptr() is null, otherwise the characters in [gptr(), egptr()), followed by
- (3.2) some (possibly empty) sequence of characters read from the input sequence.

4 Let r be the number of characters consumed from the pending sequence. If r is not considered in base pbase() and pptr() call so that: pptr() - pbase() == r and the characters starting at pbase() are the associated output. If r is zero (all characters of the pending sequence have been consumed) then pbase() is set to null, or pbase() and pptr() are set to the same null value.

5 The function may fail if either adding some character to the associated output fails or if it is unable to establish pbase() and pptr() according to the rules.

6 Returns: traits::eof() or throws an exception if the function fails.

Typically, overflow returns c to indicate success, except when traits::eq_int_type(c, traits::eof()) returns true, in which case it returns traits::not_eof(c).
