+   1 The syntax_option_type is an implementation-defined bitmask type (20.4.2.1). Setting its elements has the effects listed in Table 130. A valid value of syntax_option_type shall have at one of the grammar elements ECMAScript, basic, extended, awk, grep, egrep. set no grammar element is set, the default grammar is ECMAScript.

Table 130 — syntax_option_type effects

| Element | Effect(s) if set |
| | | |
| icase | Specifies that matching of regular expressions against a character sequence shall be performed without regard to case. |
| nosub | Specifies that no sub-expressions shall be considered to be marked, so that when a regular expression is matched against a character sequence, no sub-expression matches shall be in the supplied match_results structure |
| optimize | Specifies that the regular expression engine should pay more attention to the speed with which regular expressions are matched, and less to the speed with which regular expression objects are constructed. Otherwise it has no detectable effect on the program output |
| collate | Specifies that characters of the form "a-b" shall be locale sensitive. |
| ECMAScript | Specifies that the grammar recognized by the regular expression engine shall be used by ECMAScript in ECMAS-262, as modified in 31.13 |
| basic | Specifies that the grammar recognized by the regular expression engine shall be used by basic expressions in POSIX, Base Definitions and Sections, Regular Expressions. |
| extended | Specifies that the grammar recognized by the regular expression engine shall be used by extended expressions in POSIX, Base Definitions and Sections, Regular Expressions. Specifies that the grammar recognized by the regular expression engine shall be used by the utility awk in POSIX. |
| grep | Specifies that the grammar recognized by the regular expression engine shall be used by the utility grep in POSIX. |
| egrep | Specifies that the grammar recognized by the regular expression engine shall be used by the utility egrep given the -E option in POSIX. |
| multiline | Specifies that "^" shall match the beginning of a line and shall match the end of a line, if the ECMAScript engine is selected. |
