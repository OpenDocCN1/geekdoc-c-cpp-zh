# ISO/IEC 14882:2017(E)

# 8.1.5.2 Captures

lambda-capture:
  capture-default
  capture-list
  capture-default , capture-list
capture-default:
  =
ncapture-list:
  capture ... opt
  capture-list , ... opt
capture:
  simple-capture
  init-capture
simple-capture:
  identifier
  & identifier
  this
  * this
init-capture:
  identifier initializer
  & identifier initializer

[expr.prim.lambda.capture]

+   1. The body of a lambda-expression may refer to variables with automatic storage duration and the *this object (if any) of enclosing block scopes by capturing these entities, as described.
2. If a lambda-capture includes a capture-default that is =, a simple-capture of that lambda-capture shall be preceded by &. A lambda-capture includes a capture-default that is =, each simple-capture of that lambda-capture shall be of the form "&identifier" or "*this". [Note: The form [&,] is redundant but accepted for compatibility with ISO C++ 2014.] Ignoring appearances in initializers of init-capture, an identifier shall not appear more than once in a lambda-capture. |Example:

```
struct S2 { void f(int i); };
void f(int i) {
[i]; // OK
[&](); // error: i preceded by & when & is the default
[*this](); // OK
[*this](); // error: when = is the default
[i](); // error: i repeated
[this, i](); // error: this appears twice
}
```

+   - example
3. The identifier whose smallest enclosing scope is a block scope (6.3.3) is a local lambda expression; any other lambda-expression shall not have a capture-default or simple-capture in its lambda-introducer. The reaching scope of a local lambda expression is the set of enclosing scopes up to the innermost function and its parameters. [Note: This reaching scope includes any intervening lambda-expressions.

The identifier in a simple-capture is looked up the usual rules for unqualified name lookup (6.4.1) where such lookup shall find an entity. An entity designated by a simple-capture is said to be explicitly captured, and shall be *this (when the simple-capture is "this" or "*this") or a variable with automatic storage duration declared in the reaching scope of the local lambda expression.
