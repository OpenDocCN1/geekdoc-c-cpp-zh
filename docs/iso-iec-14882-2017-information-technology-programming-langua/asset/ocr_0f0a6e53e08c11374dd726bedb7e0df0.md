# 11.4.3 Deleted definitions

+   A function definition of the form:
attribute-specifier-seq_opt decl-specifier-seq_opt virt-specifier-seq_opt = delete; is called a deleted definition. A function with a deleted definition is also a called function.

+   A program that refers to a deleted function implicitly or explicitly, other than to declare it, is ill-formed. [ Note: This includes calling the function implicitly or explicitly in expressions that are not potentially-evaluated. If a function or a pointer-to-member of a virtual, it is referenced only if the function is selected by overload resolution. The implicit optdr (6.2) of a virtual function does not, by itself, constitute a reference. — end note ]
