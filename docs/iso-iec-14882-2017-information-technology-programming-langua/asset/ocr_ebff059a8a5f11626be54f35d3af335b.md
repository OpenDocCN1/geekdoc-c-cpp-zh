7 A non-type-template-parameter shall not be declared to have floating-point, class, or void type. [Example:
template<double d> class X; // error
template<double* pd> class Y; // OK

8 A non-type-template-parameter is a template-argument type array of "T" or of type T is adjusted to be of type "pointer" to T. [Example:
template<int a> struct R { /* ... */ };
template<int b[5]> struct S { /* ... */ };
int p;
R<* p; // OK
S* q; // OK due to parameter adjustment
int v[5]; // OK due to implicit argument conversion
Rv w; // OK due to both adjustment and conversion
-- end example|

9 A default-template-argument is a template-argument (17.3) specified after = a template-parameter. A default-template-argument may be specified for any kind of template-parameter (non-type, type) that is not a template parameter pack (17.5.3). A default-template-argument may be specified in a template declaration. A default-template-argument shall not be specified in the template-parameter-lists of the definition of a member function template. If a function template declaration specifies a default-template-argument, then that declaration shall be a definition and shall be the only declaration of the function template in the translation unit.

10 The set of default-arguments available for use is obtained by merging the default arguments from all prior declarations of the template in the same way default function arguments are (11.3.6). [Example:
template<class T1, class T2 = int> class A;
template<class T1 = int, class T2 = int> class A;

is equivalent to
template<class T1 = int, class T2 = int> class A;
-- end example|

11 If a template-parameter of a class template, variable template, or alias template has a default-template-argument, each subsequent shall be a template parameter pack. If a template-parameter is a primary class template, primary variable template, or alias template is also a template parameter pack, it shall be the last template-argument. A template-parameter pack in a function template shall be followed by another template parameter unless that template parameter can be deduced from the parameter-type-list (11.3.5) of the function template or has a default argument (17.8.2). A template parameter of a deduction guide template (17.9) that does not have a default argument shall be deduced from the parameter-type-list of the deduction guide template. [Example:
template<class T1 = int, class T2 = class> class B; // error
