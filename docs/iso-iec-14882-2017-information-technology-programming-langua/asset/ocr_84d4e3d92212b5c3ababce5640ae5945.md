# 29.6.8.6.2 Class piecewise_constant_distribution [rand.dist.samp.comp]

1 A piecewise_constant_distribution random number generator produces numbers x, b0 ≤ x < bn, uniformly distributed each subinterval [bi, bi+1) according to the probability density function

> p(x | b0, b1, ..., bn-1) = wi, for bi ≤ x < bi+1.

2 The n+1 parameters bi, also known as this distribution's interval boundaries, shall satisfy the relation bi < bi+1 for i = 0, ..., n-1. Unless specified, the remaining n parameters wi are calculated as:

> wk = wk / (S - (bk - bk)) for k = 0, ..., n-1,

in which the values wk, commonly known as the weights, shall be non-negative, non-NaN, and infinity. Moreover, the following relation shall hold: 0 < S = w0 + ... + wn-1.
