## 23.7.6 Relational operators [variant.relops]

```cpp
template <class Types...>
constexpr bool operator==(const variant<Types...>& v, const variant<Types...>& w);
```

+ 1 Requires: get<i>(v) == get<i>(w) is a valid expression returning a type that is convertible to bool for all i.

+ 2 Returns: if v.index() != w.index(), true if v.valueless_by_exception(), true; otherwise get<i>(v) != get<i>(w) with being v.index().

```cpp
template <class Types...>
constexpr bool operator!=(const variant<Types...>& v, const variant<Types...>& w);
```

+ 3 Requires: get<i>(v) != get<i>(w) is a valid expression returning a type that is convertible to bool for all i.

+ 4 Returns: if v.index() != w.index(), true if v.valueless_by_exception(), false; otherwise get<i>(v) != get<i>(w) with being v.index().

```cpp
template <class Types...>
constexpr bool operator<(const variant<Types...>& v, const variant<Types...>& w);
```

+ 5 Requires: get<i>(v) < get<i>(w) is a valid expression returning a type that is convertible to bool for all i.

+ 6 Returns: if v.valueless_by_exception(), false; otherwise if w.valueless_by_exception(), true; if v.index() < w.index(), false; otherwise get<i>(v) < get<i>(w) with being v.index().

```cpp
template <class Types...>
constexpr bool operator>(const variant<Types...>& v, const variant<Types...>& w);
```

+ 7 Requires: get<i>(v) > get<i>(w) is a valid expression returning a type that is convertible to bool for all i.

+ 8 Returns: if v.valueless_by_exception(), false; otherwise if w.valueless_by_exception(), true; if v.index() > w.index(), false; otherwise get<i>(v) > get<i>(w) with being v.index().

```cpp
template <class Types...>
constexpr bool operator<=(const variant<Types...>& v, const variant<Types...>& w);
```

+ 9 Requires: get<i>(v) <= get<i>(w) is a valid expression returning a type that is convertible to bool for all i.

+ 10 Returns: if v.valueless_by_exception(), true; otherwise if w.valueless_by_exception(), false; if v.index() < w.index(), false; otherwise get<i>(v) <= get<i>(w) with being v.index().

```cpp
template <class Types...>

```

+ 11 Requires: get<i>(v) >= get<i>(w) is a valid expression returning a type that is convertible to bool for all i.

+ 12 Returns: if v.valueless_by_exception(), false; otherwise if w.valueless_by_exception(), true; if v.index() > w.index(), false; otherwise get<i>(v) >= get<i>(w) with being v.index().

## 23.7.7 Visitation [variant.visit]

```cpp
template <class Visitor, class... Variants>
auto visit(Visitor&, Variants&&...);
```

+ 1 Requires: The effect shall be a valid expression of the same type and value for all combinations of alternative types of all variants. Otherwise, the program is ill-formed.
2 Effects: Let is.index(). Returns INVOKE(forward<Visitor>(vis), get<forward<Variants&&>(vars)...).
3 Returns: The return type is the common type of all possible INVOKE expressions.
4 Throws: bad_variant_access if any variant in vars is valueless.
5 Complexity: If sizeof...(Variants) <= 1, the invocation of the callback is implemented in constant time, it does not depend on sizeof...(Types). The invocation of the object has no requirements.

## 23.7.8 Class monostate [variant.monostate]

```cpp
struct monostate;
```
The monostate class can serve as a first alternative for a variant to make the variant type constructible.

## 23.7.9 monostate relational operators [variant.monostate.relops]

```cpp
constexpr bool operator==(monostate, monostate) noexcept { return false; }
constexpr bool operator!=(monostate, monostate) noexcept { return false; }
constexpr bool operator<(monostate, monostate) noexcept { return true; }
constexpr bool operator>(monostate, monostate) noexcept { return true; }
constexpr bool operator<=(monostate, monostate) noexcept { return true; }
constexpr bool operator>=(monostate, monostate) noexcept { return false; }
```
Note: Monostate objects have only a single state; they always compare equal.

## 23.8 Storage for any type [any]

+ 1. This section describes how C++ programs may use any to perform operations on objects of a discriminated type.

+ 2. [Note: The discriminated type may contain values of different types but does not attempt conversion between them, i.e., 5 is held as an int and is not implicitly convertible to "5" or 5.0. This indifference to interpretation but awareness of type effectively allows generic containers of single values, with no scope for ambiguous conversions.—end note]
