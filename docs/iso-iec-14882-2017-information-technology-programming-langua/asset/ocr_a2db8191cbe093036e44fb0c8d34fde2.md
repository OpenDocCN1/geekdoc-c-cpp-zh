# ISO/IEC 14882:2017(E)

# 26.5.5.2 unordered_multimap constructors [unordered.multimap.cnstr]

```
unordered_multimap() : unordered_multimap(size_type(see below)) {}
explicit unordered_multimap(size_type n,
    const hasher& hf = hasher(),
    const key_equal& eql = key_equal(),
    const allocator_type& alloc = allocator_type());
```

+   1 Effects: Constructs an unordered_multimap using the specified hash function, key equality predicate, and allocator, and using at least n buckets. For the default constructor, the number of buckets is implementation-defined. max_load_factor() returns 1.0.

+   2 Complexity: Constant.

```
template <class Iterator>
unordered_multimap(Iterator f, Iterator l,
    size_type n = see below,
    const hasher& hf = hasher(),
    const key_equal& eql = key_equal(),
    const allocator_type& alloc = allocator_type());
unordered_multimap(initializer_list<value_type> il,
    size_type n = see below,
    const hasher& hf = hasher(),
    const key_equal& eql = key_equal(),
    const allocator_type& alloc = allocator_type());
```

+   3 Effects: Constructs an unordered_multimap using the specified hash function, key equality predicate, and allocator, and using at least n buckets. If n is not provided, the number of buckets is implementation-defined. Inserts elements from the range [f, l) for the first form, or the range [il.begin(), il.end()) for the second form. max_load_factor() returns 1.0.

+   4 Complexity: Average linear, worst case quadratic.

# 26.5.5.3 unordered_multimap modifiers [unordered.multimap.modifiers]

```
template <class P>
iterator insert(const P& obj);
```

+   1 Effects: Equivalent to return replace(std::forward<P>(obj));

+   2 Remarks: This signature shall not participate in overload resolution unless is_constructible<value_type, P> is true.

```
template <class P>
iterator insert(const iterator_hint hint, const P& obj);
```

+   3 Effects: Equivalent to return place_hint(hint, std::forward<P>(obj));

+   4 Remarks: This signature shall not participate in overload resolution unless is_constructible<value_type, P> is true.

# 26.5.5.4 unordered_multimap swap [unordered.multimap.swap]

```
template <class Key, class T, class Hash, class Pred, class Alloc>
void swap(unordered_multimap<Key, T, Hash, Pred, Alloc>& x,
    unordered_multimap<Key, T, Hash, Pred, Alloc>& y)
    except(noexcept(x.swap(y)));
```

+   1 Effects: As if by x.swap(y).
