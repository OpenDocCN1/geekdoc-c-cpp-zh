```

    const polymorphic_allocator<T2>& b) noexcept
```

# 23.1.2.4 Access to program-wide memory_resource objects [mem.res.global]

memory_resource* new_delete_resource() noexcept;

+   1 Returns: A pointer to a static-duration object of a type derived from memory_resource that can
serve as a resource for allocating memory using ::operator new and ::operator delete. The last r.
value is returned every time this function is called. For a return value p and a memory resource
p->is_equal(r) returns true && r == p.
