# 9.8 Ambiguity resolution [stmt.ambig]

1 There is an ambiguity in the grammar involving expression-statements and declarations: expression-statement with a function-style explicit type conversion (8.2.3) as its leftmost expression is indistinguishable from a declaration where the declaration starts with a c. In cases the statement is a declaration

> [Note: If the statement syntactically be a declaration, there is no ambiguity, this rule does not apply. The statement might need to be examined to determine whether this is the case. This resolves the meaning of many examples. [Example: Assuming T is a simple-type-specifier (10.1.7)].

```
T(a)= 7;               // expression-statement
T(a)++;                  // expression-statement
T(a,5);                // expression-statement
T(d(int);            // declaration
T(e) = {1, 2, 3};     // declaration
T(f) =                // declaration
T(g)(double);          // declaration
```

In the last example above, which is a pointer to T, is initialized to double(3). This is of course ill-formed for semantic reasons, which does not affect the syntactic analysis. — end example]

The remaining cases are declarations. [Example:

```
class T {
//
public:
T();
T(int);
T(int, int);
//
T();

T(b)=1;              // declaration
T(c)=7;               // declaration
T(d),e,f=3;          // declaration
extern int h;
T(g,h);             // declaration
//
— end note]
```

3 The disambiguation is purely syntactic that is, the meaning of the names occurring in such a statement, whether they are instantiated as type-names or not, is not used or changed by the disambiguation. Class templates are to determine if a qualified name is a type-name. Disambiguation precedes, and a statement disambiguated as a declaration may be an ill-formed declaration. If during parsing, a name in a template parameter is bound differently than it would be bound during a trial parse, the program is ill-formed. No diagnostic is required. [Note: This can occur only when the name is declared earlier in the declaration. — end note] [Example:

```
struct T1 {
T1 operator()(int x) { return T1(); }
int operator=(int x) { return x; }
T1(int x) {
};
```
