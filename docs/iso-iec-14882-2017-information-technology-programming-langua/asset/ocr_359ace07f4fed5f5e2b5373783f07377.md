# 23.15.3 Helper classes [meta::help]

```
namespace std {
template <class T, T v>
struct integral_constant {
    static constexpr T value = v;
    using value_type = T;
    using integral_type = T;
    constexpr value_type operator() const noexcept { return value; }
    constexpr value_type operator() const noexcept { return value; }
};
```

1 The class template integral_constant, alias template bool_constant, and its associated typedef-names true_type and false_type are used as base classes to define the interface for various traits.

# 23.15.4 Unary traits [meta::unary]

1 This subclass contains templates that may be used to query the properties of a type at compile time.

2 Each of these templates shall be a UnTypeTrait(23.15.1) with a base characteristic of true_type if the corresponding condition is true, otherwise false_type.

# 23.15.1 Primary type categories [meta::cat]

1 The primary type categories correspond to the descriptions given in section 6.9 of the C++ standard.

2 For any given type T, the result of applying any of these templates to T and ev T shall yield the same result.

3 [Note: For any given type, exactly one of the primary categories has a value member that evaluates to true. — end note]
