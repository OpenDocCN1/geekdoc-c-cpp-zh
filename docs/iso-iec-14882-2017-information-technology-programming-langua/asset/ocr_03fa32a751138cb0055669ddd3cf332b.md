# ISO/IEC 14882:2017(E)

# 23.15.7.3 Sign modifications

[meta.trans.sign]

Table 47 — Sign modifications

| Template | Comments |
| --- | --- |
| template `<class T> struct make_signed; | If T names a (possibly cv-qualified) signed integer type (6.9.1) then the member typedef **type names** T; otherwise, if T names a (possibly cv-qualified) unsigned integer type then **names** the corresponding signed integer type, with the same cv-qualifiers as T; otherwise, type names the integer with smallest cv-qualifiers as T (7.15) for which sizeof(T) == sizeof(type), with the same qualifiers as T. Requires: T shall be a (possibly cv-qualified) integral type or enumeration but not a bool type. |
| template `<class T> struct make_unsigned; | If T names a (possibly cv-qualified) unsigned integer type (6.9.1) then the member typedef **type names** T; otherwise, if T names a (possibly cv-qualified) signed integer type then **names** the corresponding unsigned integer type, with the same cv-qualifiers as T; otherwise, type names the unsigned integer with smallest cv-qualifiers as T (7.15) for which sizeof(T) == sizeof(type), with the same qualifiers as T. Requires: T shall be a (possibly cv-qualified) integral type or enumeration but not a bool type. |

# 23.15.7.4 Array modifications

[meta.trans.arr]

Table 48 — Array modifications

| Template | Comments |
| --- | --- |
| template `<class T> struct remove_extent; | If T names a "array of U", the member typedef type be U, otherwise T. *Note: For multidimensional arrays, only the first array dimension is removed. For a "array of const U", the resulting type is const U. — note.* |
| template `<class T> struct remove_all_extents; | If T is a "multi-dimensional array of U", the resulting member typedef is U, otherwise T. |

+   1 | Example:
// the following assertions hold:
assert(is_same_v<remove_extent_t<int[]>, int*>);
assert(is_same_v<remove_extent_t<int[2]>, int[2]*>);
assert(is_same_v<remove_extent_t<int[3]>, int[3]*>);
assert(is_same_v<remove_extent_t<int[][][3]>, int[][3]*>);
— example

+   2 | Example:
// the following assertions hold:
assert(is_same_v<remove_all_extents_t<int[]>, int>);
assert(is_same_v<remove_all_extents_t<int[2]>, int[2]>);
assert(is_same_v<remove_all_extents_t<int[3]>, int[3]>);
assert(is_same_v<remove_all_extents_t<int[][][3]>, int[][3]>);
