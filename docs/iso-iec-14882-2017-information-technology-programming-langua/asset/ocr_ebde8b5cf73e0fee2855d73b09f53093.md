# ISO/IEC 14882:2017(E)

27.5.1.3.5 operator->

```
constptr operator->() const;
Returns: addressof(operator*);
```

27.5.1.3.6 operator++

```
constptr reverse_iterator operator++();
Effects: As if by: --current;
Returns: *this;
constptr reverse_iterator operator++(int);
```

```
Effects: As if by:
reverse_iterator tmp = *this;
--current;
return tmp;
```

27.5.1.3.7 operator--

```
constptr reverse_iterator operator--();
Effects: As if by: --current;
Returns: *this;
constptr reverse_iterator operator--(int);
```

```
Effects: As if by:
reverse_iterator tmp = *this;
++current;
return tmp;
```

27.5.1.3.8 operator+=

```
constptr reverse_iterator operator+(difference_type n) const;
Returns: reverse_iterator(current-n).
```

27.5.1.3.9 operator+=

```
constptr reverse_iterator operator+=(difference_type n);
Effects: As if by: --current = n;
Returns: *this;
```

27.5.1.3.10 operator-=

```
constptr reverse_iterator operator-(difference_type n) const;
Returns: reverse_iterator(current+n).
```

27.5.1.3.11 operator=-

```
constptr reverse_iterator operator-=(difference_type n);
Effects: As if by: current += n;
Returns: *this;
```
