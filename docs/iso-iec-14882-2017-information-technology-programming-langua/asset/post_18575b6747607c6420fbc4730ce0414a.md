# ISO/IEC 14882:2017(E)

# 17.7.3 Explicit specialization

+ An explicit specialization of any of the following:
- function template
- class template
- variable template
- member function of a class template
- static data member of a class template
- member class of a class template
- member enumeration of a class template
- member class of a class template
- member function of a class or class template

can be declared by a declaration introduced by template<>; that is:
`explicit-specialization:
template <> declaration`

[Example:

```cpp
template<T> class stream<char> { /* ... */ };

template<T> class Array<char> { /* ... */ };
template<T> void sort(Array<T>& v) { /* ... */ };

template<> void sort(Array<char>*);
```

Given these declarations, `sort<char>` will be used as the definition of streams; other streams will be handled by class template instantiations from the class template. Similarly, `sort<char>` will be used as the sort for arguments of type `Array<char>`; other `Array` types will be sorted by functions generated from the template. — [10.3.1, 12.2, 17.5.2].

+ An explicit specialization can be declared in any scope in which the corresponding primary template may be defined ([10.3.1, 12.2, 17.5.2]).

+ A declaration of a function template, class template, or variable template being explicitly specialized shall precede the declaration of the explicit specialization. [Note: A declaration, but not a definition of the template is required. — end note.] The declaration of a class or class template shall precede the declaration of an explicit specialization for a member template of the class or class template. [Example]:

```cpp
template<> class X<int> { /* ... */ };
// error: X is not a template
template<> class X;
```

```cpp
template<> class X<char> { /* ... */ };
// OK: X is a template
— end example.
```

A function template, a member function, a member template, a member enumeration, a member class template, a static data member, or a static data member template of a class template may be explicitly specialized for a class specialization that is implicitly instantiated; in this case, the definition of the class template shall precede the explicit specialization for the member of the class template. If such an explicit specialization also names an implicitly-declared special member function (Clause 15), the program is ill-formed.

6 A member of an explicitly specialized class is not implicitly instantiated from the member declaration of the class template; instead, the member of the class template specialization itself be explicitly defined if its definition is required. In this case, the definition of the class template specialization shall be in scope at the point at the member is defined. The definition of an explicitly specialized class is unrelated to the definition of a generated specialization. That is, members need not have the same names, types, etc. as the members of a generated specialization. Members of an explicitly specialized class are defined in the same manner as members of normal classes, and not using the template<> syntax. The same is true when defining a member of an explicitly specialized member class.
