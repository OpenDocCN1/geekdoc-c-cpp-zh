# 17.5.6 Function templates

+   A function template defines an unbounded set of related functions. [Example: A family of sort functions might be declared like this

template<class T> class Array {};
template<class T> void sort(Array<T>&);

— example

A function template can be overloaded with other function templates and non-template functions (11.3.5).
A non-template function is not related to a function template (i.e., unless it has the same name and type as a potentially generated function template specialization).^{139}

# 17.5.6.1 Function template ordering

+   It is possible to overload function templates so that different function template specializations have the same type. [Example:
// translation unit 1:
template<class T>
void f(T*);
void f(int* p);
f(p); // calls f<int*>(int*)

— example
// translation unit 2:
template<class T>
void f(T*);
void f(int* p) {
f(p); // calls f<int*>(int*)
}

Such specializations are distinct functions and do not violate the one-definition rule (6.2).

+   The signature of a function template is defined in Clause 3. The names of the template parameters are significant only for establishing the relationship between the template parameters and the rest of the signature.
[Note: Two distinct function templates may have identical return types and function parameter lists, even if overload resolution cannot distinguish them.

template<class T> void f(); // OK: overloads the first template
template<int> void f(); // distinguishable with an explicit template argument list

— end

When an expression references a function template used in the function parameter list or the type in the declaration of a function template, the expression references the template parameter is part of the signature of the function template. It is necessary to declare a function template in one translation unit to be linked with another declaration of the function template in another translation

If such a non-template function is odr-used (6.2) in a program, it must be defined; it will not be implicitly instantiated by the function template definition.
