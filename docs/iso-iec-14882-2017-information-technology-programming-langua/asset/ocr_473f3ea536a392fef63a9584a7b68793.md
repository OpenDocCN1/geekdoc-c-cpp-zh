23.1.2.5 Class enable_shared_from_this [util.smartptr.enab]

+   1 A class inherits from enable_shared_from_this<T> to inherit the shared_from_this member functions that obtain a shared_ptr instance to *this.

+   2 [Example:
int main() {
    shared_ptr<X> p(new X);
    shared_ptr<X> q = p->shared_from_this();
    assert(p == q);
    assert(p.owner_before(q) && !q.owner_before(p)); // p and q share ownership
}
end example]
