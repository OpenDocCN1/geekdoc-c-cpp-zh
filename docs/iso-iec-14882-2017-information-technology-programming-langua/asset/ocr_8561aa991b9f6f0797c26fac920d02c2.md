# 30.4.4 Wide stream objects [wide.stream.objects]

wistream wcin;

+   1 The object wcin controls input from a stream buffer associated with the object stdin, declared in
<stdio> (30.11.1).

+   2 After the object wcin is initialized, wcin.tie() returns &wcout. Its state is otherwise the same as the
required for basic_ios<wchar_t>::init (30.5.5.2).

wstream wcout;

+   3 The object wcout controls output to a stream buffer associated with the object stdout, declared in
<stdio> (30.11.1).

+   4 The object wcerr controls output to a stream buffer associated with the object stderr, declared in
<stdio> (30.11.1).

+   5 After the object wcerr is initialized, wcerr.flags() & unitbuf is returns
&wcout. Its state is otherwise the same as required for basic_ios<wchar_t>::init (30.5.5.2).

wstream wcg;

+   6 The object wcg controls output to a stream buffer associated with the object stderr, declared in
<stdio> (30.11.1).
