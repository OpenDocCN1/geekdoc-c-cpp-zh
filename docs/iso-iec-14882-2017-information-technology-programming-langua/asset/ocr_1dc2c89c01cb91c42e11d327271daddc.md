# ISO/IEC 14882:2017(E)

```
struct S {
    std::initializer_list<double>; // #1
    std::initializer_list<int>; // #2
    S(); // #3
    // ...
};

S s1 = { 1.0, 2.0, 3.0 }; // invoke #1
S s2 = { 1, 2, 3 }; // invoke #2
S s3 = { }; // invoke #3
// end example]
```
