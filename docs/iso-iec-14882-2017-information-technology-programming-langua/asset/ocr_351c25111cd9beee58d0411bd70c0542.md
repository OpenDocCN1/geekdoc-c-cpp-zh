# 8.3.6 Alignof [expr.alignof]

An alignof expression yields the alignment requirement of its operand. The operand should be a type-id representing a complete object type, or an array reference, or one of those types.

The result is an integral constant of type std::size_t.

When alignof is applied to a reference, the result is the alignment of the referenced type. When alignof is applied to an array, the result is the alignment of the element type.

# 8.3.7 noexcept operator [expr.unary.noexcept]

The noexcept operator determines whether the evaluation of its operand, which is an unevaluated operand (Clause 8), can throw an exception (18.1).

```
noexcept-expression:
noexcept ( expression )
```

The result of the noexcept operator is a constant of type bool and is a.

The result of the noexcept operator is true unless the expression is potentially-throwing (18.4).

# 8.4 Explicit type conversion (cast) [expr.cast]

The result of (T) cast-expression is of type T. The result is an lvalue if T is an reference or a reference to function and xvalue if T is a reference to object type; otherwise the result is a prvalue.[Note: If T is not a non-class type, the cv-qualifiers are discarded when determining the type of the resulting value; Clause 8. —end note]

An explicit type conversion can be expressed using functional notation (dynamic_cast, static_cast, reinterpret_cast, const_cast), or explicitly defined by the cast notation.

```

unary-expression
( type-id ) cast-expression
```
