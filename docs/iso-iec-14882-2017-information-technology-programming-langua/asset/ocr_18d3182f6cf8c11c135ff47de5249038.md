# ISO/IEC 14882:2017(E)

```
struct T2 { T2(int){ } };

int a, (*(b)(T2))(int), c, d;

void f() {
    // disambiguation requires this to be parsed as a declaration:
T1(a) = 3,                                // T2 will be declared as a variable of type T1, but this will not
T2(4),                                    // allow the last part of the declaration to parse properly,
    (*+b)(T2(c))(int(d));                     // since it depends on T2 being a type-name
}
-- end example]
```
