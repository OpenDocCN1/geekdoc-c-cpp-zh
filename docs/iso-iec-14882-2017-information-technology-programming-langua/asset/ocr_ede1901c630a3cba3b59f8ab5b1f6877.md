# ISO/IEC 14882:2017(E)

Returns: *this.
basic_ostream<char, traits>& operator<<(nullptr_t
);

Effects: Equivalent to:
return this << s;
where s is an implementation-defined NTCTS (20.3.16).

# 30.7.5.2.4 Character inserter function templates

```
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, char c);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, char c);
// specialization
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, char c);
// signed and unsigned
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, signed char c);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, unsigned char c);
```

Effects: Behaves as a formatted output function (30.7.5.2.1). Constructs a character sequence seq if c is type char and the type of stream is not char, then seq consists of out.iden(c); otherwise seq consists of c. Determines padding for seq as described in 30.7.5.2.1. Inserts seq into out. Calls width(0).

Returns: *this

```
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, const char* s);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, const char* s);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, const char* s);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out, signed char* s);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out);
template<class char, traits>
basic_ostream<char, traits>& operator<<(basic_ostream<char, traits>& out,
    const unsigned char* s);
```

Requires: s shall not be a null pointer.

Effects: Behaves like inserted (as described in 30.7.5.2.1). Creates a character sequence seq of n characters starting at, each widened by out.iden(w) (30.7.5.5.3), where n is the number that would be computed by:

+   traits::length(s) for the overload where the first argument is of type basic_ostream<char, traits>& and the second is of type char*, and also for the overload where the first argument is of type basic_ostream<char, traits>& and the second is of type const char*nchar_traits<char>::length(s) for the overload where the first argument is of type basic_ostream<char, traits>& and the second is of type const char* (reinterpret_cast<const char*>(s)) for the other two overloads.

Determining padding for seq as described in 30.7.5.2.1. Inserts seq into out. Calls width(0).

Returns: *out
