void f(ios_base& str, int base) {
    // set basefield
    str.setf(base == 8 ? ios_base::oct :

The expression out << setbase(base) shall have type basic_ostream<charT, traits>& and value out. The expression >> setbase(base) shall have type basic_istream<charT, traits>& and value out.

unspecified setfill(char type);
Returns: An object of unspecified type such that if out is an object of type basic_ostream<charT, traits> and c has type charT then the expression out << setfill(c) behaves as if called f(out), where the function f is defined

```
template<class charT, class traits>
void f(ios<charT, traits>& str, charT c) {
    // set character
    str.fill(c);
}
```

The expression out << setfill(c) shall have type basic_ostream<charT, traits>& and value out.

unspecified setprecision(int n);
Returns: An object of unspecified type such that if out is an object of type basic_ostream<charT, traits> then the expression out << setprecision(n) behaves as if called f(out, n), or if in is an object of type basic_istream<charT, traits> then the expression >> setprecision(n) behaves as if called f(in, n), where the function f is defined

```
void f(ios_base& str, int n) {
    // set precision
    str.precision(n);
}
```

The expression out << setprecision(n) shall have type basic_ostream<charT, traits>& and value out. The expression >> setprecision(n) shall have type basic_istream<charT, traits>& and value in.

unspecified setw(int n);
Returns: An object of unspecified type such that if out is an instance of basic_ostream<charT, traits> then the expression out << setw(n) behaves as if called f(out, n), or if in is an object of type basic_istream<charT, traits> then the expression >> setw(n) behaves as if called f(in, n), where the function f is defined

```
void f(ios_base& str, int n) {
    // set width
    str.width(n);
}
```

The expression out << setw(n) shall have type basic_ostream<charT, traits>& and value out. The expression >> setw(n) shall have type basic_istream<charT, traits>& and value out.
