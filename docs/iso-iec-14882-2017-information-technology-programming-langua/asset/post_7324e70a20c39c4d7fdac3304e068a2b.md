
# ISO/IEC 14882:2017(E)

## 31.12 Regular expression iterators

## 31.12.1 Class template regex_iterator

The class regex_iterator is an iterator adaptor. It represents a new view of existing iterator sequence, by enumerating all occurrences of a regular expression within that sequence. A regex_iterator uses regex_search to find successive regex matches within the sequence from which it was constructed. The iterator is constructed, and stores a value of match_results<BidirectionalIterator>. If the end of the sequence is reached (regex_search returns false), the iterator becomes equal to the end-of-sequence iterator value. The default constructor constructs an end-of-sequence iterator (not defined), which is the only iterator permitted to be used for the end. The result of regex_iterator on an end-of-sequence iterator is not defined. For other iterator values a const match_results<BidirectionalIterator>& is returned. The result of operator* on match_results<BidirectionalIterator> is returned. It is possible to store things into regex_iterators. Two non-end-sequence iterators are equal. An end-sequence iterator is not equal when they are constructed from the same arguments.

```cpp
namespace std {
    template <BidirectionalIterator>
    typename iterator_traits<BidirectionalIterator>::value_type;
    class traits : regex_traits<BidirectionalIterator>;
    class regex_iterator {
    public:
        regex_iterator() = basic_regex<charT, traits>
        using forward_iterator;
        using iterator_category = match_results<BidirectionalIterator>;
        using value_type = pdiff_t;
        using pointer = const value_type*;
        using reference = const value_type&;

        regex_iterator()
        _iterator();
        regex_iterator(const BidirectionalIterator a, BidirectionalIterator b,
                       const regex_type* re,
                       const regex_constants::match_type m = regex_constants::match_default);
        regex_iterator(const BidirectionalIterator a, BidirectionalIterator,
                       const regex_constants::match_type flags = regex_constants::match_default) = delete;
                       const regex_type* re);
        regex_iterator(const regex_iterator& iter);
        regex_iterator& operator=(const regex_iterator& iter) = default;
        bool operator==(const regex_iterator& other) const;
        bool operator!=(const regex_iterator& other) const;
        const value_type& operator*() const;
        const value_type* operator->() const;
        regex_iterator& operator++();
        regex_iterator operator++(int);

    private:
        BidirectionalIterator begin; // exception only
        BidirectionalIterator end; // exception only
        const regex_type* prege; // exception only
        const regex_constants::match_type flags; // exception only
        match_results<BidirectionalIterator> match; // exception only
};
```

An object of type regex_iterator that is not an end-of-sequence iterator holds a zero-length match if match[0], matched == true and match[0].first == match[0].second. [Note: For example, this can occur when the pattern of the regular expression matched consists only of an assertion (such as '^', '\D', '\b', '\B') — end note]

## 31.12.1.1 regex_iterator constructors [re.regiter.cnstr]

```cpp
regex_iterator();
```

- 1 Effects: Constructs an end-of-sequence iterator. `regex_iterator(BidirectionalIterator a, BidirectionalIterator b, const regex_type &regex, const constants::match_type m = *regex, constants::match_default);`
- 2 Initializes: begin and end to a and b, specifically sets regex to &, flags to m, then calls regex_search(begin, end, match, *flags). If this false returns *this to the end-of-sequence iterator.

## 31.12.1.2 regex_iterator comparisons [re.regiter.comp]

```cpp
bool operator!=(const regex_iterator& right) const;
```

- 1 Returns: true if *this and right are both end-of-sequence iterators or if the following conditions all hold:
(1.1) begin == right.begin,
(1.2) end == right.end,
(1.3) prex == right.prex,
(1.4) flags == right.flags, and
(1.5) match[0] == right.match[0];
otherwise false.
- 2 Returns: (*this == right).

*(Note: The OCR text had `bool operator=(const regex_iterator& right) const;` which is likely a typo for `operator!=` based on the logic and the subsequent `operator==` context.)*

## 31.12.1.3 regex_iterator indirection [re.regiter.deref]

```cpp
const value_type& operator*() const;
```

- 1 Returns: match.

```cpp
const value_type* operator->() const;
```

- 2 Returns: &match.

## 31.12.1.4 regex_iterator increment [re.regiter.incr]

```cpp
regex_iterator& operator++();
```

- 1 Effects: Constructs a local variable of type BidirectionalIterator and initializes it with the value of match[0].second.
- 2 If the iterator holds a zero-length match and start == end the operator sets *this to the end-of-sequence iterator and returns *this.
- 3 Otherwise, if the iterator holds a zero-length match, the operator calls: `regex_search(start, end, match, *prex);`.
- 4 In all cases where the call to regex_search returns true, match.prefix().first should be equal to the previous value of match[0], and for each index in the half-open range [0, match.size()) for match[i]. It is unspecified how the implementation makes these adjustments.

```cpp
regex_iterator operator++(int);
```

- Effects as by: `++(*this); return *this;`

## 31.12.2 Class regex_token_iterator [re.tokiter]

The class regex_token_iterator is an iterator adaptor represents a new view of existing sequence, by enumerating all occurrences of a regular expression within that sequence, and presenting one or more sub-expressions for each match. Positioned by the iterator is a sub_match class instance that enumerates one sub-expression for each section of the character sequence splitting: that is to say it enumerates one sub-expression for each section of the character sequence within the regular expression. When regex_token_iterator is used to enumerate a single sub-expression with index -1, the iterator performs splitting; if the character sequence does not match the regular expression, the iterator becomes equal to the end-of-sequence iterator. After it is constructed, the iterator stores a value N to sequence. It also maintains a list of sub-expressions which will be enumerated. Every operator++ uses count is incremented; if N exceeds or equals sub.size(), the iterator increments position and sets N to zero. If the end of sequence is reached the iterator becomes equal to the end-of-sequence iterator, the sub-expression which has been enumerated has index -1, in which case the iterator evaluates last sub-expression to the end of the input sequence being generated, provided that the last regular match would not an empty sequence. The default constructor constructs an end-of-sequence iterator object, which is the only iterator to be used for the end. an end-of-sequence iterator is not defined. For any other iterator a const sub_match<BidirectionalIterator>& is returned. The result of operator-> on an end-of-sequence iterator is not defined. For any other iterator a const sub_match<BidirectionalIterator>* is returned.

It is impossible to store things into regex_token_iterators. Two end-of-sequence iterators are always equal. An end-of-sequence iterator is not equal to a non-end-of-sequence iterator. Two non-end-sequence iterators are equal when they are constructed from the same arguments.

```cpp
namespace std {
    template <class BidirectionalIterator,
        class charT = typename iterator_traits<BidirectionalIterator>::value_type,
        class traits = regex_traits<charT>>
    class regex_token_iterator {
    public:
        using reg_type = regex<charT, traits>;
        using iterator_category = forward_iterator_tag;
        using value_type = sub_match<BidirectionalIterator>;
        using difference = ptrdiff_t;
        using pointer = const value_type*;
        using reference = const value_type&;

        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            int match = 0,
            regex_constants::match_flag_type m =
            regex_constants::match_default);
        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            const vector<int>& submatches,
            regex_constants::match_flag_type m =
            regex_constants::match_default);
        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            initializer_list<int> submatches,
            regex_constants::match_flag_type m =
            regex_constants::match_default);

        template <size_t N>
        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            const int (&submatches)[N],
            regex_constants::match_flag_type m =
            regex_constants::match_default);
        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            int match = 0,
            regex_constants::match_flag_type m =
            regex_constants::match_default = delete);
        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            const vector<int>& submatches,
            regex_constants::match_flag_type m =
            regex_constants::match_default = delete);
        regex_token_iterator(BidirectionalIterator a, BidirectionalIterator b,
            const regex& re,
            initializer_list<int> submatches,
            regex_constants::match_flag_type m =
            regex_constants::match_default = delete);
```
