## 8.2.4 Pseudo destructor

The use of a pseudo-destructor-name by a . , or arrow -> represents the destructor for the non-class type denoted by dot or detype-specifier. The result shall only be used as operand for the function call operator ~, and the result of such a call has a type. The only effect is the evaluation of the *postfix-expression* before the dot or arrow.

The left-hand side of the dot operator is of scalar type. The left-hand side of the arrow operator is of pointer to scalar. This scalar type is the object type. The re-unqualified version of the object and the type denoted by the *pseudo-destructor-name* is the same type. Furthermore, the two types in a *nested-specifier_qt type-name :: type-name* shall share the same scope (ignoring cv qualification).

## 8.2.7 Dynamic cast

1 The result of the expression dynamic_cast<T>(v) is the result of converting the v to type T. T shall be a prvalue or pointer to complete class type, or a pointer to void. The dynamic_cast operator shall not cost anything (8.11).

2 If T is a pointer type, v shall be prvalue of complete class type, and the result is prvalue of T. If T is an rvalue reference, v shall be lvalue of a complete class type, and the result is lvalue of the type referred by T. If T is an rvalue reference referred by T, v shall be lvalue having a complete class type; the result is lvalue of the type referred by T.

3 If the type of v is the same as T, or if it is the same as the object type in T or more cv-qualified the result is (converted if necessary).

4 If v is a null pointer, the result is the null pointer of type T.

5 If T is a "pointer to cv B" and v is "pointer to cv D", where D is a base class of D, the result is a pointer to the D object pointed to by v. Similarly, if T is "reference to cv B" and v has cv D that is a base class of D, the result is the unique subobject of the D object referred by v.
