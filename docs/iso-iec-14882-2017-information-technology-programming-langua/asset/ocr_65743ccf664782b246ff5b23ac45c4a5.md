# 31.5.3 Implementation-defined_error_type [re.err]

```
namespace std::regex_constants {
  using error_type = 73;
  inline constexpr error_type_collate = unspecified;
  inline constexpr error_type_ctype = unspecified;
  inline constexpr error_type_escape = unspecified;
  inline constexpr error_type_backref = unspecified;
  inline constexpr error_type_paren = unspecified;
  inline constexpr error_type_brace = unspecified;
  inline constexpr error_type_badbrace = unspecified;
  inline constexpr error_type_range = unspecified;
  inline constexpr error_type_space = unspecified;
  inline constexpr error_type_badrepeat = unspecified;
  inline constexpr error_type_complexity = unspecified;
  inline constexpr error_type_stack = unspecified;
}
```

+   1. The error_type is an implementation-defined enumerated type (20.4.2.1.3). Values of error_type represent the conditions described in Table 132.

Table 132 — error_type values in the C locale

| Value | Error condition |
| --- | --- |
| error_collate | The expression contains an invalid element name. |
| error_ctype | The expression contains an invalid character class name. |
| error_escape | The expression contains an invalid escaped character, or a trailing escape. |
| error_backref | The expression contains an invalid back reference. |
| error_paren | The expression contains mismatched ( and ). |
| error_brace | The expression contains mismatched { and }. |
| error_badbrace | The expression contains an invalid range in a { } expression. or The expression contains an invalid character range, such as [b-a] in most encodings. |
| error_space | There was insufficient memory to convert the expression into a finite state machine. |
| error_badrepeat | One of + was not preceded by a regular expression. |
| error_complexity | The complexity of an attempted match exceeded a pre-set level. |
| error_stack | There was insufficient memory to determine whether the regular expression could match the specified sequence. |

# 31.6 Class regex_error [re.badexp]

```
class regex_error : public runtime_error {
public:
  explicit regex_error(regex_constants::error_type code);
  regex_constants::error_type code() const;
};
```

+   1. The regex_error defines the types of objects thrown as exceptions to report errors from the regular expression library.
