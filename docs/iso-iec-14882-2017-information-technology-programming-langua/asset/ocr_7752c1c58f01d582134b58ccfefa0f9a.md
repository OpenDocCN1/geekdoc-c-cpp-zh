# ISO/IEC 14882:2017(E)

# 21.9.2 Initializer list constructors

constexpr initializer_list() noexcept;

Effects: Constructs an empty initializer_list object.

Postconditions: size() == 0.

# 21.9.3 Initializer list access

constexpr E begin() const noexcept;

Returns: A pointer to the beginning of the array. If size() == 0 the values of begin() and end() are unspecified but they must be defined.

constexpr E end() const noexcept;

Returns: begin() + size();

constexpr size_t size() const noexcept;

Returns: The number of elements in the array.

Complexity: Constant time.

# 21.9.4 Initializer list range access

template<Class> constexpr E begin(initializer_list<E> il) noexcept;

Returns: il.begin().

template<Class> constexpr E end(initializer_list<E> il) noexcept;

Returns: il.end().

# 21.10 Other runtime support

Headers <cset> (nonlocal jumps), <csignal> (signal handling), <carg> (variable arguments), and <cstddef> (runtime environment, system), provide for compatibility with C code.

Calls to the function getenv (21.2.2) shall not introduce a data race (20.5.5.9) provided that nothing modifies the environment. [Note: Calls to the POSIX functions setenv and putenv modify the environment.]

+   A call to the setlocale (25.5) may introduce a data race with other calls to the setlocale function or with functions that are affected by the current C locale. The implementation shall behave as if no library other than <locale>: global calls the setlocale function.
