## 29.7.2.8 vararray member functions [vararray.members]

```
void swap(vararray v) noexcept;
```

- Effects: *this obtains the value of v. obtains the element of *this.
- Complexity: Constant.

```
size_t size const;
```

- Returns: The number of elements in the array.
- Complexity: Constant time.

```
T sum() const;
```

- Requires: size() > 0. This function may only be instantiated for a type T to which operator+= be applied.
- Returns: The sum of all elements of the array. If the array has length 1, returns the value of 0. Otherwise, the returned value is calculated by applying operator+= to a copy of an element of the array and all other elements of the array in an unspecified order.

```
T min() const;
```

- Requires: size() > 0.
- Returns: The minimum value contained in *this. For an array of length 1, the value of 0 is returned. For all other array lengths, the determination is made using operator<.

```
T max() const;
```

- Requires: size() > 0.
- Returns: The maximum value contained in *this. For an array of length 1, the value of 0 is returned. For all array lengths, the determination is using operator<.

```
valarray shift(int n) const;
```

- Returns: A varray of length size(), each of elements I is (*this)[I + n] if I + n is non-negative and less than size(), otherwise T(). [Note: If element is taken the leftmost element, a value of n shifts the elements left, with zero fill. — end note]
- [Example: If the array has value -2, the first two elements of the result will be value-initialized(11.6); the third element of the result will be assigned the value of the first element of the argument, etc. — end example]

```
valarray shift(int n) const;
```

- Returns: A varray of length size() that is a circular shift of *this. If element is taken as the leftmost element, a non-negative value of n shifts the elements left n and a negative value of n shifts the elements right -n places.

```
valarray apply(T func(T)) const;
valarray apply(T func(const T&)) const;
```

```
void resize(size_t sz, const T& c);
```

Effects: The changes of the array to sz and then assigns each value of the second argument. Resizing invalidates all pointers and references to elements in the array.
