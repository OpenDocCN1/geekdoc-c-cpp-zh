+   - For a signed integer value, the function strtol.
- For an unsigned integer value, the function strtoul.
- For a float value, the function strtof.
- For a double value, the function strtod.
- For a long double value, the function strtold.

The numeric value to be stored can be one of:

+   - zero, if the conversion does not convert the entire value.

- the most representable value, if the field be converted to an unsigned integer type represents a value that cannot be represented in val.
