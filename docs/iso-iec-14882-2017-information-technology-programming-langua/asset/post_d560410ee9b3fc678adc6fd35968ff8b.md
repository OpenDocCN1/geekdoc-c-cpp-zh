## 23.15.7 Transformations between types [meta.trans]

1 This subclause contains templates that may be used to transform one type to another following defined rule.

2 Each of the templates in this subclause shall be a *TransformationTrait* (23.15.1).

## 23.15.7.1 Const-volatile modifications [meta.trans.cv]

Table 45 — Const-volatile modifications
| Template | Comments |
|---|---|
| template <class T> | The member typedef type names the same type as T except that any top-level const-qualifier has been removed. [*Example: struct remove_const_; remove_const_t<const volatile int> evaluates to volatile int, whereas remove_const_t<const int*> evaluates to const int.—end example*] |
| template <class T> struct remove_volatile; | The member typedef type names the same type as T except that any top-level volatile-qualifier has been removed. [Example: remove_volatile_t<const int> evaluates to const int, whereas remove_volatile_t<volatile int> evaluates to volatile int — end example] |
| template <class T> struct remove_cv; | The member typedef type names the same type as T except that top-cv-qualifier has been removed. [Example: remove_cv_t<const int> evaluates to int, whereas remove_cv_t<volatile int> evaluates to const volatile int — end example] |
| template <class T> struct add_const; | If T is a reference, function, or top-level const-qualified type, then T1; otherwise, type names T. |
| template <class T> struct add_volatile; | If T is a reference, function, or top-level volatile-qualified type, then type names the same type as T, otherwise T volatile. |
| template <class T> struct add_cv; | The member typedef type names the same type as add_const_t<add_volatile_t<T>> |

## 23.15.7.2 Reference modifications [meta.trans.ref]

Table 46 — Reference modifications
| Template | Comments |
|---|---|
| template <class T> struct remove_reference; | If T names a "reference to T1" then the member typedef type names T1; otherwise, type names T. |
| template <class T> struct add_lvalue_reference; | If T names a referable type (20.3.18) then the member typedef type names T&; otherwise, type T. [Note: This rule reflects the semantics of reference collapsing (11.3.2). — end note] |
| template <class T> struct add_rvalue_reference; | If T names a referable type then the member typedef type names T&&; otherwise, type T. [Note: This rule reflects the semantics of reference collapsing (11.3.2). For example, when a T names an add_rvalue_reference<T> is not an rvalue reference. — end note ] |

## 23.15.7.3 Sign modifications [meta.trans.sign]

Table 47 — Sign modifications
| Template | Comments |
|---|---|
| template <class T> struct make_signed; | If T names a (possibly cv-qualified) signed integer type (6.9.1) then the member typedef names T; otherwise, if T names a (possibly cv-qualified) unsigned integer type then names the signed integer type, with the same qualifiers as T; otherwise, type names the integer with smallest qualifiers as T (7.15) for which sizeof(T) == sizeof(type), with the same qualifiers as T. Requires: T shall be a (possibly cv-qualified) integral type or not a bool type. |
| template <class T> struct make_unsigned; | If T names a (possibly cv-qualified) unsigned integer type (6.9.1) then the member typedef names T; otherwise, if T names a (possibly cv-qualified) signed integer type then names the unsigned integer type, with the same qualifiers as T; otherwise, type names the integer with smallest qualifiers as T (7.15) for which sizeof(T) == sizeof(type), with the same qualifiers as T. Requires: T shall be a (possibly cv-qualified) integral type or not a bool type. |

## 23.15.7.4 Array modifications [meta.trans.arr]

Table 48 — Array modifications
| Template | Comments |
|---|---|
| template <class T> struct remove_extent; | If T names a "array of U", the member typedef type is U, otherwise T. *Note: For multidimensional arrays, only the first array dimension is removed. For "array of const U", the resulting type is const U.* |
| template <class T> struct remove_all_extents; | If T is a "multi-dimensional array of U", the resulting member typedef is U, otherwise T. |
| 1 | Example:
// the following assertions hold:
assert(is_same_v<remove_extent_t<int[]>, int*>);
assert(is_same_v<remove_extent_t<int[2]>, int[2>);
assert(is_same_v<remove_extent_t<int[3]>, int[3>);
assert(is_same_v<remove_extent_t<int[][][3]>, int[][][3>); |
| 2 | Example:
// the following assertions hold:
assert(is_same_v<remove_all_extents_t<int[]>, int>);
assert(is_same_v<remove_all_extents_t<int[2]>, int[2>);
assert(is_same_v<remove_all_extents_t<int[3]>, int[3>);
assert(is_same_v<remove_all_extents_t<int[][][3]>, int[][][3>); |

## 23.17.5 Pointer modifications [meta.trans.ptr]

Table 49 — Pointer modifications
| Template | Comments |
|---|---|
| template <class T> struct remove_pointer; | If T has type ("possibly cv-qualified") pointer to T1 then the typedef type names T1; otherwise, it names T. |
| template <class T> struct add_pointer; | If T has a referable type (20.3.18) or a cv void type then the member typedef type names the same type as remove_reference<T>; otherwise, type names T. |
