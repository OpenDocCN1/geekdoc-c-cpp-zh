
# ISO/IEC 14882:2017(E)

```cpp
template<class ExecutionPolicy, class ForwardIterator1, class ForwardIterator2>
bool equal(ExecutionPolicy&& exec,
ForwardIterator1 first1, ForwardIterator1 last1,
ForwardIterator2 first2, ForwardIterator2 last2);

template<class InputIterator1, class InputIterator2,
class BinaryPredicate>
bool equal(InputIterator1 first1, InputIterator1 last1,
InputIterator2 first2, InputIterator2 last2,
BinaryPredicate pred);

template<class ExecutionPolicy, class ForwardIterator1, class ForwardIterator2>
bool equal(ExecutionPolicy&& exec,
ForwardIterator1 first1, ForwardIterator1 last1,
ForwardIterator2 first2, ForwardIterator2 last2,
BinaryPredicate pred);
```

- 1. If last2 was not given in the argument list, it denotes first2 + (last1 - first1) below.
- 2. Returns: If last1 == last2 return false. Otherwise true if every iterator i in the range [first, last1), the following conditions hold: *i == *(first2 + (i - first1)), pred(i, *(first2 + (i - first1))) == false. Otherwise, returns false.
- 3. Complexity:
    - (3.1) For the overloads with ExecutionPolicy.
    if InputIterator1 and InputIterator2 meet the requirements of random access iterators (27.2) and last1 - first1 == last2, then no applications of the corresponding predicate;
    - (3.2) at least min(last1 - first1, last2 - first2) applications of the corresponding predicate.
    - (3.2.1) For the overloads with ExecutionPolicy.
    if ForwardIterator1 and ForwardIterator2 meet the requirements of random access iterators and last1 - first1 == last2, then no applications of the corresponding predicate;
    - (3.2.2) min(last1 - first1, last2 - first2) applications of the corresponding predicate.

# 28.5.12 Is permutation [alg.is_permutation]

```cpp
template<class ForwardIterator1, class ForwardIterator2>
bool is_permutation(ForwardIterator1 first1, ForwardIterator1 last1,
ForwardIterator2 first2, ForwardIterator2 last2);

template<class ForwardIterator1, class ForwardIterator2, class BinaryPredicate>
bool is_permutation(ForwardIterator1 first1, ForwardIterator1 last1,
ForwardIterator2 first2, ForwardIterator2 last2, BinaryPredicate pred);
```

- 1. Requires: ForwardIterator1 and ForwardIterator2 should have the same value type. The comparison function should be an equivalence relation.
- 2. Remarks: If last2 was not given in the argument list, it denotes first2 + (last1 - first1) below.
- Returns: If last1 - first1 = last2 - first2, return false. Otherwise true if there exists a permutation of the elements in the range [first2, first2 + (last1 - first1)), beginning with ForwardIterator2 begin, such that equal(first1, last1, pred) or equal(first1, last2, pred) returns true; otherwise, false.
- Complexity: The order of applying the predicate if ForwardIterator1 and ForwardIterator2 meet the requirements of random access iterators and last1 - last2 = first2. Otherwise, last1 - first1 applies applications of the corresponding predicate if equal(first1, last2, pred) would return true if pred was given in the list or equal(first1, last2, pred) would return true if pred was given in the argument list; otherwise, O(N), where N has a value like first1.

# 28.5.13 Search

```cpp
template<class ForwardIterator1, class ForwardIterator2>
search(ForwardIterator1 first1, ForwardIterator1 last1,
      ForwardIterator2 first2, ForwardIterator2 last2);

template<class ExecutionPolicy, class ForwardIterator1, class ForwardIterator2>
search(ExecutionPolicy&& exec, pred,
      ForwardIterator1 first1, ForwardIterator1 last1,
      ForwardIterator2 first2, ForwardIterator2 last2);

template<class ForwardIterator1, class ForwardIterator2,
      class BinaryPredicate>
search(ForwardIterator1 first1, ForwardIterator1 last1,
      ForwardIterator2 first2, ForwardIterator2 last2,
      BinaryPredicate pred);

template<class ExecutionPolicy, class ForwardIterator1, class ForwardIterator2,
      class BinaryPredicate>
search(ExecutionPolicy&& exec, pred,
      ForwardIterator1 first1, ForwardIterator1 last1,
      ForwardIterator2 first2, ForwardIterator2 last2,
      BinaryPredicate pred);
```

- Effects: Finds a subsequence of equal values in a sequence.
- Returns: The iterator returns i in the range [first1, last1 - (last2-first2)) such that for every non-negative integer n not less than last2 the following conditions hold: *(i + n) == *(first2 + n), and pred*(i + n) != false. Returns true if [first1, last2] is empty, otherwise last1 if no iterator found.
- Complexity: At most (last1 - first1) * (last2 - first2) applications of the corresponding predicate.

```cpp
template<class ForwardIterator, class Size, class T>
search(ForwardIterator first, ForwardIterator last, Size count,
      const T& value);

template<class ForwardIterator, class Size, class T,
      class BinaryPredicate>
search(ForwardIterator first, ForwardIterator last, Size count,
      const T& value, BinaryPredicate pred);
```

- 4. Requires: Size must be integrable.
- 5. Effects: Finds a subsequence of equals in a sequence.
- 6. Returns: The iterator i in the range [first, last-count) such that for every non-negative integer n less than count the conditions hold: (i + n) == value, pred*(i + n) != false. Returns last if no such iterator found.
- 7. Complexity: At most first applications of the predicate.

```cpp
template<class ForwardIterator, class Searcher>
search(ForwardIterator first, ForwardIterator last,
      const Searcher& searcher);
```

- 8. Effects: Equivalent to search(first, last).
- 9. Remarks: Searcher meet Copyible requirements.

# 28.6 Copy [alg.copy]

```cpp
template<class InputIterator, class OutputIterator>
copy(InputIterator first, InputIterator last,
      OutputIterator result);
```

- 1. Requires: result shall not be in the range [first, last).
- 2. Effects: Copies elements in the range [first, last) into the range [result, result + (last - first)] from first and proceeding to last. For each non-integer n < (last - first), performs *(result + n) = *(first + n).
- 3. Returns: result + (last - first).
- 4. Complexity: At most first assignments.

```cpp
template<class ExecutionPolicy, class ForwardIterator, class OutputIterator>
copy(ExecutionPolicy&& exec,
      ForwardIterator first, ForwardIterator last,
      OutputIterator result);
```

- 5. Requires: The range [first, last] and [result, result + (last - first)] shall not overlap.
- 6. Effects: Copies elements in the range [first, last] into the range [result, result + (last - first)). For each non-integer n < (last - first), performs *(result + n) = *(first + n). 
- 7. Returns: result + (last - first).
- 8. Complexity: Exactly last – first assignments.

```cpp
template<class InputIterator, class Size, class OutputIterator>
copy_n(InputIterator first, Size n,
      OutputIterator result);

template<class ExecutionPolicy, class ForwardIterator, class Size, class OutputIterator>
copy_n(ExecutionPolicy&& exec,
      ForwardIterator first, Size n,
      OutputIterator result);
```

- Effects: For each non-integer i < n, performs *(result + i) = *(first + i).
- Returns: result + n.
- Complexity: Exactly n assignments.

```cpp
template<class InputIterator, class OutputIterator, class BinaryPredicate>
copy_if(InputIterator first, InputIterator last,
      OutputIterator result, BinaryPredicate pred);

template<class ExecutionPolicy, class ForwardIterator, class OutputIterator, class BinaryPredicate>
copy_if(ExecutionPolicy&& exec,
      ForwardIterator first, ForwardIterator last,
      OutputIterator result, BinaryPredicate pred);
```

- 12. Requires: The range [first, last] and [result, result + (last - first)] should not overlap.
- Note: For the overlap with an ExecutionPolicy, there may be a performance cost if iterator_traits<ForwardIterator>::value_type is not Constructible.
- 13. Effects: All of the elements referred to by i in the range [first, last) for which pred(i) is true.
- 14. Returns: The end of the resulting range.
- 15. Complexity: Exactly last – first applications of the corresponding predicate.
- 16. Remarks: Stable (20.5.5.7).

```cpp
template<class BidirectionalIterator, class BidirectionalIterator2>
backward(BidirectionalIterator first, BidirectionalIterator last,
      BidirectionalIterator2 result);
```

- 17. Requires: result should not be in the range [first, last) or in the range [result – (last-first), first), starting from last – 1 and preceding to last.
- 18. For each positive integer n <= (last – first), performs *(result – n) = *(last – n).
- 19. Returns: result – (last –first).
- 20. Complexity: Exactly last – first assignments.

# 28.6.2 Move [alg.move]

```cpp
template<class InputIterator, class OutputIterator>
move(InputIterator first, InputIterator last, OutputIterator result);
```

- 1. Requires: result should not be in the range [first, last] into the range [result, result + (last – first)].
- 2. Effects: Moves elements in the range [first, last) into the range [result, result + (last – first)).
- 3. copy_backward should be used instead of copy when last is in the range [result – (last – first), result).
