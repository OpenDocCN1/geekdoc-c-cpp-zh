# 23.11.2.2 Class shared_ptr [util.smart.shared]

The shared_ptr class stores a pointer, usually obtained via new. shared_ptr implements semantics
of ownership; the last remaining owner of the pointer is responsible for destroying the object, or
otherwise releasing the resources associated with the stored pointer. A shared_ptr is said to be empty if it
ds not own a pointer.
