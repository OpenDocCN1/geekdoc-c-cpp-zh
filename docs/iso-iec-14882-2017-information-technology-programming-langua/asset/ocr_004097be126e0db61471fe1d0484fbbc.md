# ISO/IEC 14882:2017(E)

# # Annex B [impliments]
Implementation quantities

1 Because computers are finite, C++ implementations are inevitably limited by the size of the programs they can successfully process. Every implementation shall document these limitations where known. This documentation may cite fixed limits where they exist, how to compute variable limits by a function of available resources, or say fixed limits do not exist or are unknown.

2 The limits may constrain quantities that include those described below or others. The bracketed number following each quantity is recommended as the minimum for that quantity. However, these quantities are only guidelines and not determine compliance.
