+   (1.3) For all overloads, in the ranges [first, [last] and [result, result + (last - binary_op)], may neither modify elements invalidate iterators or subranges.285

Effects for overloads with no ExecutionPolicy and a non-empty range, the function creates an accumulator value whose type is InputIterator's value, initializes it with *first, and assigns to *result. For every iterator in [first + 1, last), in order, creates an object value whose type is InputIterator's value type, initializes it with *i, computes acc + binary_op(op, acc), assigns to *result(i - first), and moves forward from acc.

For the overloads with no ExecutionPolicy and a non-empty range, the function creates an object whose type is ForwardIterator's value type, initializes it with *first, and assigns to *result. For every d in [1, last - 1), creates an object value whose type is ForwardIterator's value type, initializes it with *(first + d) - *(first + d - 1) or binary_op(*(first + d), *(first + d - 1)), and assigns to the *(result + d).

+   Returns: result + (last - first).

+   Complexity: Exactly [last] of the binary operation.

+   Remarks: for the overloads with no ExecutionPolicy, result may be equal to first. For the overloads with ExecutionPolicy, the ranges [first, [last] and [result, result + (last - first)] should not overlap.

# 29.8.12 Iota [numeric.iota]

```
template <class ForwardIterator, class T>
void iota(ForwardIterator first, ForwardIterator last, T value);
```

+   Requires: T must be convertible to ForwardIterator's value type. The expression ++val, where val has type, must be well formed.

+   Effects: For each element i in the range [first, last), assigns *i = value and increments i by ++value.

+   Complexity: Exactly [last - first] increments and assignments.

# 29.8.13 Greatest common divisor [numeric.gcd]

```
template <class M, class N>
constexpr common_type_t<M, N> gcd(M m, N n);
```

+   Requires: |m| and |n| should be representable as a value of common_type_t<M, N>. [Note: These *are* valid if gcd(m, m) = |m| is representable as a value of type M. — end note]

+   Remarks: If either M or N is not an integer, or if either is a bool, the program is ill-formed.

+   Returns: Zero when m and n are both zero. Otherwise, returns the greatest common divisor of |m| and |n|

+   Throws: Nothing.

# 29.8.14 Least common multiple [numeric.lcm]

```
template <class M, class N>
constexpr common_type_t<M, N> lcm(M m, N n);
```

+   Requires: |m| and |n| should be representable as a value of common_type_t<M, N>. The least common multiple of |m| and |n| should be representable as a value of type common_type_t<M, N>.

> 285) The use of fully closed ranges is intentional.
