+   10 Note: When virtual base classes are used, a hidden declaration can be reached along a path through the subject matrix that does not pass through the hiding declaration. This is not an ambiguity. The identical use with non-virtual base classes is an ambiguity; in case there is no unique instance of the name that hides others. — end note] [Example:

```
struct V { int f0(); int x; };
struct W { int g0(); int y; };
struct B : virtual V, W {
    int f0(); int x;
    int g0(); int y;
};
struct C : virtual V, W { };
struct D : B, C { void glorp(); };
```

Figure 6 — Name lookup

The names declared in V and the left-hand instance of W are hidden by those in B, but the names declared in the right-hand instance of W are not hidden at all.

```
void D::glorp() {
    x++;               // OK: B::x hides V::x
f0();               // OK: B::f hides V::f()
    y++;               // error: B::y and C's W::y
g0();               // error: B::g0() and C's W::g0()
}
```
