# ISO/IEC 14882:2017(E)

# 20.5.3 Requirements on types and expressions [utility.requirements]

+   20.5.3.1 describes requirements on types and expressions used to instantiate templates defined in the C++ standard library. 20.5.3.2 describes on swappable types and swappable expressions. 20.5.3.3 describes the requirements on pointer-like types that support null values. 20.5.3.4 describes the requirements on hash function objects. 20.5.3.5 describes the requirements on storage allocators.

+   20.5.3.1 Template argument requirements [utility.arg.requirements]
The templates in the C++ standard library refer to various names whose details are set out in Tables 20–27. In these cases, T is an object or reference type to be supplied by a C++ program instantiating a template; a, b, and c are values of type (possibly) T; s and t are modifiable of type; t denotes an identifier; rv is an value of T; and v is an value of type (possibly) T or an value of type T.

+   In general, a default constructor is not required. Certain class member function signatures T() shall be a well-defined argument (11.6) if one of signatures is called using the default argument (11.3.6).
