Effects: If is a null pointer, it allocates an array of long unspecified size and stores a pointer to its first element in iarray. The function then extends the array pointed by iarray as necessary to include the element iarray[idx]. Newly allocated element of the array is initialized to zero. The reference returned is invalid after any operations on the object.293 However, if the function fails294 and this is a base subclass of a basic_io object or object, the effect is equivalent to calling basic_ios::setstate(badbit) on the derived object (which may throw failure).

```
void* pword(int idx);
```

Effects: If a null pointer, it allocates an array of pointers to void of unspecified size and stores a pointer to its first element in array. The function then extends the array pointed by array as necessary to include the element array[idx]. Newly allocated element of the array is initialized to zero, the value with the same index yields another reference to the same value. If the function fails295 and this is a base subclass of a basic_io object or object, the effect is equivalent to calling basic_ios::setstate(badbit) on the derived object (which may throw failure). The reference of the storage referred to is retained, so until the next call to copyfmt, pword with the same index yields another reference to the same value.295

+   Returns: On success array[idx]. A valid void* initialized to 0.

+   Remarks: After a subsequent call to pword(int) for the same object, the earlier return value may no longer be valid.
