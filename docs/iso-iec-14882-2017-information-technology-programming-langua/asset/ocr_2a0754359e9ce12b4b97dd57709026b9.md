# C.1 C++ and ISO C

This subclause lists the differences between C++ and ISO C, by the chapters of this document.

# C.1.1 Clause 5: lexical conventions

# 5.11 New Keywords

New keywords are added to C++;

Rationale: These keywords were added in order to implement the new semantics of C++.

Effect on original feature: Change to semantics of well-defined feature. Any ISO C programs that used any of these keywords as identifiers are not valid C++ programs.

Difficulty of converting: Converting one specific program is easy. Converting a large collection of related programs takes work.

How widely used: Common.

# 5.13.3

Change: Type of character literal is changed from int to char.

Rationale: This is needed for improved function argument type matching. For example:

```
int function(int i );

function(char c );
```

```
function('x ');
```

it is possible that this call will make the second version of function return than the first.
Effect on original feature: Change to semantics of well-defined feature. ISO C programs which depend upon nsizeof('x') = sizeof(int) are probably rare.

will not work the same as C++ programs.

Difficulty of converting: Simple.

How widely used: Simple.

# Subclause 5.13.5:

Change: String literal is changed from "array of char" to "array of const char". The type of a string literal is changed from "array of some-integer-type" to "array of const char16_t". The type of a char* string literal is changed from "array of some-integer-type" to "array of const char32_t". The type of a string literal is changed from "array of wchar_t" to "array of const wchar_t".

Rationale: This avoids calling an inappropriate overloaded function, which might expect to be able to modify its argument.

Effect on original feature: Change to semantics of well-defined feature.
Difficulty of converting: Syntactic transformation. The fix is to add:

```
char* p = "abc"; // valid in C, invalid in C++
void f(char c) {
    char* p = (char*)"abc"; // OK: cast added
    f(p);
    f((char*)"def"); // OK: cast added
}
```
