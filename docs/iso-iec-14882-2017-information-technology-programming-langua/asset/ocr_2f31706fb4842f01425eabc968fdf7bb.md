# 19.5 Error directive [cpp.error]

+   1 A preprocessing directive of the form

# error pp-tokens_opt new-line
caus the implementation to produce a diagnostic message that the specified sequence of preprocessing tokens, and renders the program ill-formed.

# 19.6 Pragma directive [cpp.pragma]

+   1 A preprocessing directive of the form

# pragma pp-tokens_opt new-line
c the implementation to behave in an implementation-defined manner. The behavior might translation to fail or cause the translator or the resulting program to behave in a non-conforming manner. Any pragma that is not recognized by the implementation is ignored.

# 19.7 Null directive [cpp.null]

+   1 A preprocessing directive of the form

has no effect.
