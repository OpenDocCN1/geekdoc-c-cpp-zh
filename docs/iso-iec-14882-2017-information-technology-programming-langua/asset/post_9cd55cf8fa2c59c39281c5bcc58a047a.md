# 26.5.5 Class template unordered_multimap

# 26.5.5.1 Class template unordered_multimap overview

An unordered_multimap is an associative container that supports elements (instances of unordered_multimap may contain multiple copies of each key value) and associates values of another mapped type with keys. The unordered_multimap supports forward iterators.

An unordered_multimap satisfies all the requirements of a container, of an associative container, and an allocator-aware container (Table 86). It provides the operations described in the preceding requirements for equal elements, as unordered_multimap supports the a_eq operations in table, not the uniq_operations. For an unordered_multimap<Key, T>, the key type is Key, the mapped type is T, and the value type is pair<const Key, T>.

This section only describes operations on unordered_multimap that are not described in one of the requirement tables, or for which there is additional semantic

```cpp
namespace std {
    template <class Key,
        class T,
        class Hash = hash<Key>,
        class Pred = equal_to<Key>,
        class Allocator = allocator<pair<const Key, T>>>
    class unordered_map{
    public:
        using key_type = Key;
        using mapped_type = T;
        using value_type = pair<const Key, T>;
        using hasher = Hash;
        using equal_to = Pred;
        using allocator_type = Allocator;
        using pointer = typename Allocator_traits<Allocator>::pointer;
        using const_pointer = typename Allocator_traits<Allocator>::const_pointer;
        using reference = value_type&;
        using const_reference = const value_type&;
        using size_type = implementation_defined; // 26.2
        using difference_type = implementation_defined; // 26.2

        using iterator = implementation_defined; // 26.2
        using const_iterator = implementation_defined; // 26.2
        using local_iterator = implementation_defined; // 26.2
        using const_local_iterator = implementation_defined; // 26.2
        using node_type = unspecified;

        // 26.5.2 construct/copy/destroy
        unordered_map(size_type n);
        explicit unordered_map(size_type n,
            const Hash& h = hasher(),
            const Key_eq& eql = key_equal(),
            const allocator_type& alloc = allocator_type());
        template <class InputIterator>
        unordered_map(InputIterator f, InputIterator l,
            const Hash& h = hasher(),
            const Key_eq& eql = key_equal(),
            const allocator_type& alloc = allocator_type());
        unordered_map(const unordered_map& other);
        explicit unordered_map(const unordered_map& other);
        unordered_map(const unordered_map& other, const allocator_type& alloc);
        unordered_map(initializer_list<value_type> il,
            size_type n = il.size(),
            const Hash& h = hasher(),
            const Key_eq& eql = key_equal(),
            const allocator_type& alloc = allocator_type());
    };
```
