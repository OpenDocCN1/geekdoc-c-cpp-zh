# 23.11.2.3.1 weak_ptr constructors [util.smartptr.weak.const]

```
constexpr weak_ptr() noexcept;
```

+   1 Effects: Constructs an empty weak_ptr object
Postconditions: use_count() == 0.

```
weak_ptr(const weak_ptr<Y>& r) noexcept;
template<class Y> weak_ptr(const shared_ptr<Y>& r) noexcept;
```

+   3 Remarks: The first and second constructors will not participate in overload resolution unless Y is compatible with T.

+   4 Effects: If r is empty, constructs an empty weak_ptr object; otherwise, a weak_ptr object that shares ownership with r and stores a copy of the pointer stored in r.

+   5 Postconditions: use_count() == r.use_count().

```
weak_ptr(weak_ptr<Y>&& r) noexcept;
template<class Y> weak_ptr(weak_ptr<Y>&& r) noexcept;
```

+   6 Remarks: The second constructor will not participate in overload resolution unless Y is compatible with T.

+   7 Effects: Move a weak_ptr instance from r.

+   8 Postconditions: *this shall contain the old value of r. if r is empty, r.use_count() == 0.

# 23.11.2.3.2 weak_ptr destructor [util.smartptr.weak.dest]

```
~weak_ptr();
```

+   1 Effects: Destroys the weak_ptr object which has no effect on the object it stored pointer to.
