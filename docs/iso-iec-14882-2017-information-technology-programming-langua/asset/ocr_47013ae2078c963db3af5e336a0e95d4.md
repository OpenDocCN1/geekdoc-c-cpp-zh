# 21.2.4 Alignments, offsets

The offset(type, member-designator) has the same semantics as the corresponding macro in the C standard library header <stddef.h>, but accepts a restricted set of arguments in this document. The use of offset on a type other than a standard-class (Clause 2) is conditional—The expression offset(type, member-designator) is never type-dependent—(17.6.2) and it is value-dependent—(17.6.3) and only if type is dependent. The result of applying the offset macro to a static data member or function is undefined. No operation by the offset macro can throw an exception and offset(type, member-designator)) shall be true.

The type size_t is an implementation-defined unsigned integer type that is large enough to contain the size of bytes in any object (8.3.3).

> [Note: It is recommended that implementations that use ptrdiff_t and size_t integer conversions are no greater than that of signed int unless a larger size is necessary to contain all the possible values. — end note]

The type max_align_t is a POD type whose alignment requirement is at least as large as every scalar type, and whose alignment requirement is supported in every context (6.11).
