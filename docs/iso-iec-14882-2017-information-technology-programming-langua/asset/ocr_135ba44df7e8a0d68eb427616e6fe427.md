```
static constexpr T denom_min() noexcept;
```

Minimum subnormal value.208

Meaningful for floating-point types.

In specializations for which has_denom == false, returns the minimum normalized value.

```
static constexpr bool is_iec559;
```

true if only the type adheres to ISO/IEC/IEEE 60559.209

Meaningful for floating-point types.

```
static constexpr bool is_bounded;
```

true if the set of values representable by the type is finite.210 [Note: All fundamental types (6.9.1) are bounded. This member is false for arbitrary precision types. — end note

Meaningful for all specializations.

```
static constexpr bool is_module;
```

true if the type is modulo.211 A type is modulo if, for any operation +, -, * on values of that type result would fall outside the range [min(), max()], the returned value differs from the true value by an integer multiple of max() - min() + 1.

> Example: is_modulo for signed integer types (6.9.1) unless an implementation, an extension to this document, defines integer overflow to wrap. — end example

Meaningful for all specializations.

```
static constexpr bool trap;
```

true if, at program startup, there exists a value of the type that would cause an arithmetic operation using to trap.212
