# 21.7.2 Class type_info [type.info]

```
type_info(const type_info& rhs) = delete;
type_info& operator=(const type_info& rhs) = delete;
};
```

+   1 The class type_info describes type information generated by the implementation (8.2.8). Objects of this class store a pointer to a name, and an encoded value for comparing two types for equality or order. The names, encoding, rule, and calling sequence for types are all unspecified and may differ by programs.
2 bool operator=(const type_info& rhs) const noexcept;
3 Effects: Compares the current object with rhs.
4 Returns: true if the two values describe the same type.
5 operator!(const type_info& rhs) const noexcept;
6 Returns: (*this == rhs).
7 before(const type_info& rhs) const noexcept;
8 Effects: Compares the current object with rhs.
9 Returns: true if *this precedes rhs in the implementation's collation order.
10 size_t hash_code() const noexcept;
11 Returns: An unspecified value, except that within a single execution of the program, it shall return the same value for any two type_info objects which compare equal.
12 Remarks: An implementation may return different values for two type_info objects which do not compare equal.
13 const char* name() const noexcept;
14 Returns: An implementation-defined NTBS.
15 Remarks: The message may be a null-terminated multibyte string (20.4.2.1.5.2), suitable for conversion and display as (24.3, 25.4.1.4).
