# 8.2.1 Supervising [expr.sub]

+   A postfix expression followed by expression in square brackets is a postfix expression. One of the expressions shall be a glance of array of T or a pointer to T and the other shall be a value of unescaped enumeration or integral type. The result is of type "T". The type "T" shall be a completely-defined object type.56 The expression E1[E2] is identical (by definition) to *(E1)(E2) [Note: see 8.3 and 8.7 for details of * and + 11.3.4 for details.]. — end note], except that in the case of an array operand, the result is an inline if operand is an xvalue. The expression E1 shall be followed before the expression E2.
A braced-list should not be used with the built-in subscript.

# 8.2.2 Function call [expr.call]

+   A function call is a postfix expression followed by parentheses containing possibly empty, comma-separated initializer-list constructs the arguments to the function. The postfix expression shall have function type or function pointer type. For a call to a non-member function or to a static member, the postfix expression shall be either an lvalue that refers to a function (in which the function-to-pointer standard conversion (7.3) is suppressed on the postfix expression), or it shall have function pointer type.
