## 27.8 Container access

In addition to being available via inclusion of the <iterator> header, the function templates in 27.8 are available when any of the following headers are included: <regex>, <set>, <string>, <unordered_map>, <unordered_set>, <list>, <map>, <deque>, <forward_list>, and <vector>.

```cpp
template <class C> constexpr auto size(const C& c) -> decltype(c.size());
Returns: c.size().
```

```cpp
template <class T, size_t N> constexpr auto size(const T (&array)[N]) noexcept
Returns: N.
```

```cpp
template <class C> constexpr auto empty(const C& c) -> decltype(c.empty());
Returns: false.
```

```cpp
template <class T, size_t N> constexpr bool empty(const T (&array)[N]) noexcept
Returns: false.
```

```cpp
template <class E> constexpr bool empty(initializer_list<E> il) noexcept;
Returns: il.size() == 0.
```

```cpp
template <class C> constexpr auto data(const C& c) -> decltype(c.data());
Returns: c.data().
```

```cpp
template <class T, size_t N> constexpr T* data(const T (&array)[N]) noexcept
Returns: array.
```

```cpp
template <class E> constexpr E* data(initializer_list<E> il) noexcept;
Returns: il.begin().
```

## 28 Algorithms library [algorithms]

### 28.1 General [algorithms.general]

  + 1 This Clause describes components that C++ programs may use to perform arithmetic operations on containers (Clause 26) and other sequences.
  2 The following subclauses describe components for non-modifying sequence operations, modifying sequence operations, sorting and related operations, and algorithms from the ISO C library, as summarized in Table 100.
