# ISO/IEC 14882:2017(E)

{EzExample}:

```
class B { };
namespace M {
namespace N {
    class X : public B {
        void f();
    }
}
void M::N::X::f() {
    int i = 16;
}
```

```
// The following scopes are searched for a declaration of i:
// 1) outermost block of M::N::X; before the use of i
// 2) scope of M::N::X
// 3) scope of M::N::X's base class B
// 4) scope of namespace M
// 5) scope of namespace
// 6) scope, before the definition of M::N::X::f;
```

[Example] 12.2.1 and 12.2.3 describe the restrictions on the use of names in member function definitions. 12.2.5 further describes the restrictions on the names in nested classes. 12.4 describes the restrictions on the use of names in local definitions. — end note]

+   9 Name lookup for a name used in the definition of a friend function describes the restrictions on the names in the scope of nested friendship shall be defined in the class granting friendship, name lookup in the friend function definition shall proceed as described for lookup in member function definitions.

+   10 In a friend declaration defining a member function, a name used in the function declarator and not part of a template-argument in the declarator-id is first looked up in the scope of the function class (13.2). If it is not found, or if the name is part of a template-argument in the declarator-id, the look up is described for unique names in the definitions of the class granting friendship. [Example]:

```
struct A {
    typedef int AT;
    void f1();
    void f2(float);
    template <class T> void f3();
};
struct B {
    typedef char CT;
    typedef float BT;
    friend A::f1(AT); // parameter type is A::AT
    friend A::f2(BT); // parameter type is B::BT
    friend A::f3(AT()); // template argument is A::AT
};
```

— end note]

+   11 During the lookup for a name used as a default argument (11.3.6) in a parameter-declaration-clause or used in the expression of a mem-initializer for a constructor (15.6.2), the function parameter names are visible and hides the names of entities declared in the block, class or namespace scopes containing the declaration. [Note: 11.3.6 further describes the restrictions on the use of names in default arguments. 15.6.2 further describes the restrictions on the use of names in a c-initializer. — end note]
