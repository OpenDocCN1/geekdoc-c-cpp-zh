10 Effects: Reads a character from the input sequence, if possible, without moving the stream position past it, as follows:

+   (10.1) If the input sequence has a read position available, the function signals success by returning (unsigned char)gnext.

+   (10.2) Otherwise, the current write pointer pnext is not a null pointer and is greater than the current end pointer gend, make a read position available by assigning to gend greater than gnext and greater than pnext.

Returns (unsigned char)gnext.

11 Returns EFSF to indicate failure.

12 Remarks: The function can alter the number of read positions available as a result of any call.

13 Effects: Alters the stream position within one of the controlled sequences, if possible, as indicated in Table 145.

| Conditions | Result |
| --- | --- |
| (which & ios::in) == 0 | positions the input sequence |
| (& & ios::out) != 0 | positions the output sequence |
| (which & (ios::in | ios::out)) == (ios::in | ios::out)) | positions both the input and the output sequences |
| and way == either ios::beg or ios::end | |
| Otherwise | the positioning operation fails. |

14 For a sequence to be positioned, if its next pointer is a null pointer, the positioning operation fails. Otherwise, the function returns newoff as indicated in Table 146.

| Condition | newoff Value |
| --- | --- |
| way == ios::beg | 0 the next pointer minus the beginning pointer (xnext - xbeg) |
| way == ios::end | seekhigh the beginning pointer (seekhigh - xbeg) |

16 If (newoff + off) < (seeklow - xbeg) or (seekhigh - xbeg) < (newoff + off), the positioning operation fails. The function adds xbeg + newoff to the next pointer xnext.
