6 A mem-initializer can delegate to another of the constructor's class using any class-or-decltype that denotes the constructor's class itself. If a mem-initializer designates the constructor's class, it shall be the only mem-initializer; the constructor is a delegating constructor, and the constructor selected by the mem-initializer is the target constructor. The target body of the delegating constructor is executed. If a constructor delegates to itself directly or indirectly, the program is ill-formed, no diagnostic required. Example:

```
struct C {
    C() {} //: non-delegating constructor
    C(int) : C(42) //: delegates to #1
    C(char c) : C(C(42)) //: ill-formed due to recursion with #4
    C(double d) : C('a') //: ill-formed due to recursion with #3
};
```

7 The initialization-list or braced-init-list is used to initialize the designated subobject (or, in the case of a delegating constructor, the complete object) according to the initialization rules of 11.6 for direct-initialization. Example:

```
struct B {
    B(int) : /* ... */ {};
    B(int) : /* ... */ {};
};
struct D {
    B b1, b2;
    D(int);
    B b1;
    const int c;
};
D(int a) : b2(a), b1(a+2), c(a+3), b(a+4) { /* ... */ }
D(10);
```

> > Note: The initialization by each mem-initializer constitutes a full-expression (1.6). Any expression in a mem-initializer is evaluated as part of the full-expression that performs the initialization.
- note A mem-initializer where the mem-initializer denotes a virtual base class is ignored during execution of a constructor of any class that is not the most derived class.

8 A temporary expression bound to a reference in a mem-initializer is ill-formed. Example:

```
struct A {
    A() : v(42) // error
    const int v;
};
```

9 In a non-delegating constructor, if a potentially constructed subobject is not designated by a mem-initializer (including the case where there is no mem-initializer-list because the constructor has no constructor-initializer), then

+   — if the entity is a non-static data member that has a default member initializer (12.2) and either
    — the constructor's class is a union (12.3), and no other variant member of that union is designated by a mem-initializer-or-decl
    — the constructor's class is not a union, and if the entity is a member of an anonymous union, no other member of that union is designated by a mem-initializer-id,
— the entity is initialized from its default member initializer as specified in 11.6;

+   otherwise, if the entity is an anonymous union or a variant member (12.3.1), no initialization is performed;
