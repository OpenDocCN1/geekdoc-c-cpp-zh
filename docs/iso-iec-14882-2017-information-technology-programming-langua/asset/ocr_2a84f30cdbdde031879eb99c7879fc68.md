# ISO/IEC 14882:2017(E)

void this_thread::yield(O) noexcept;

Effects: Offers the implementation opportunity to reschedule.

Synchronization: None.

```
template <class Clock, class Duration>
void sleep_until(const chronos::time_point<Clock, Duration>& abs_time);
```

Effects: Blocking the calling for the absolute timeout (3.2.4) specified by abs_time.

Synchronization: None.

Throws: Timeout-related exceptions (3.2.4).

```
template <class Rep, class Period>
void sleep_for(const chron::duration<Rep, Period>& rel_time);
```

Effects: Blocking the calling for the relative timeout (3.2.4) specified by rel_time.

Synchronization: None.

Throws: Timeout-related exceptions (3.2.4).

# 33.4 Mutual exclusion

This section provides mechanisms for mutual exclusion: mutexes, and lock once. These mechanisms ensure the production of race-free programs (4.7).
