## 30.5.2 Types

using streamoff = implementation-defined;

- 1 The streamoff is a synonym for one of the signed integral types of sufficient size to represent the maximum possible file size for the operating system.
- 2 using streamsize = implementation-defined; type streamsize is a synonym for one of the signed integral types. It is used to represent the number of characters transferred in an I/O operation, or the size of I/O buffers.

> 290) Typically long. streamsize is used in most places where ISO C would use size_t, except for the strebuf constructors, use streamsize, which carries negative values. It should probably be the signed type corresponding to size_t (which is what Posix2 calls size_t).

## 30.5.3.1 Types [ios::types]

### 30.5.3.1.1 Class ios_base::failure [ios::failure]

```cpp
namespace std {
    class ios_base::failure : public system_error {
    public:
        explicit failure(const string& m, error_code ec = io_errc::stream);
        explicit failure(const char* m, const error_code ec = io_errc::stream);
    };
}
```

An implementation is permitted to define ios_base::failure as a synonym for a class with equivalent functionality to ios_base::failure shown in this subclass. [Note: When ios_base::failure is the injected class name] The failure defines the base class for all types that might provide a nested type, failure to emulate the injected class name as exceptions, by functions in the ostreams library, to report errors detected during buffer operations.

When ios_base::failure exceptions occur, implementations should follow values of ec that identify the specific reason for the failure. [Note: Errors arising from the operating system would typically be reported as system_category() with an error value of the error reported by the operating system. Errors arising from the stream library would typically be reported as error_code(io_errc::stream, iostream_category()).]
