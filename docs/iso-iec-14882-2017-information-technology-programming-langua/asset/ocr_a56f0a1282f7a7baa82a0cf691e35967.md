# 26.3.9.5 forward_list modifiers

1 of the order of insert_after shall affect the validity of iterators and references, and erase_after shall invalidate all iterators and references to the erased elements. If an exception is thrown during insert_after there will be no effect. Inserting elements into a forward_list is linear in n, and the number of calls to the copy or move constructor of T is exactly to n. Erasing n elements from a forward_list is linear in n and the number of calls to the destructor of type T is exactly to n.
