For a call to a non-static member function, the postfix expression shall be an implicit (12.2.2, 12.2.3) or explicit class member access (8.2.5) whose id-expression is a function name, or a pointer-to-member (8.5) selecting a function member; the call is as a member of the class referred to by the expression. In the case of an implicit class member access, the object is the one pointed to by this expression. [Note: A member function call of the class is interpreted as (*) (12.2.2) or explicit call — end note] If a function name is used, it may be converted (Clause 10), in which case the appropriate function shall be selected according to the rules in 10.3. If the non-static member function in the expression is qualified, then it is called. Such a call is referred to as a virtual call. [Note: The type is the type of the object referred to the current value of the object expression. 15.7 describes the behavior of virtual functions when called. — end note]

> [Note: If a function member name is used, and name lookup (6.4) does not find a declaration of that name the program is ill-formed. No function is implied by such a call. — end note]

If the postfix expression designates a destructor (15.4), the type of the function call is void; otherwise, the type of the function call is the return type of the statically chosen function (i.e., ignoring the keyword), even if the type of function is actually defined. This return type shall be an object, reference or void.

When a function is called, each parameter (11.3.5) shall be initialized (11.6, 8.5, 15.1) with its corresponding argument type. If the function is a non-static member, this parameter of the function (12.2.1) shall be initialized with a pointer to the object called, converted as by an explicit call (8.4). [Note: There is no access or checking on this conversion: the exception checking and dispatching are as of the possible (implicit) class member access operations (13.1, 14.2, and 15.1) [Note: This allows a parameter to be a pointer to an incomplete class type. However, it allows a passed-value parameter to have an incomplete class type. — end note] Example: The access of the constructor, conversion functions or destructor is checked at the point of the call in the calling function. If the function or the constructor throws an exception, the search for a handler in the scope of the calling function continues; in particular, if the function has called a function-block (Clause 18) with a handler that could handle the exception, this handler is not considered. — end example]

The postfix expression is sequenced before each expression in the expression-list and any default argument. The initialization of a parameter, including every associated value computation and side effect, is sequenced with respect to that of any other parameter.
