# 19.2 Source file inclusion [cpp.include]

+   1 A include directive identifies a header or source file that can be processed by the implementation.

+   2 A preprocessing directive of the form

```
# include <h-char-sequence> new-line
```

searches a sequence of implementation-defined places for a header identified uniquely by the specified sequence between the < and > delimiters, and causes the replacement of directive by the entire contents of the header. How the places are specified or the header identified is implementation-defined.
