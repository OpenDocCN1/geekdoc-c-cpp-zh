# 17.6.2 Dependent names

Inside a template, some constructs have semantics that may differ from instantiation to another. Such a construct depends on the template parameters. In particular, expressions may depend on the type and/or value of template parameters (as determined by the template arguments) and this determines the context for name lookup for certain names. Expressions may be type-dependent (that, is, may depend on a template parameter) or value-dependent (that, is, when evaluated as a constant expression (8.20) may depend on a template parameter) as described in this section. In an expression of the form:

```
postfix-expression ( expression-list )
```

where the postfix-expression is unqualified, the unqualified-id denotes a dependent name if
ay of the expressions in the expression-list is a pack expansion (17.5.3),
any of the expressions or braced-init-lists in the expression-list is type-dependent (17.6.2.2), or
or the unqualified-id is a template-id in which any of the template arguments depends on a template parameter.

If an operand of an operator is a type-dependent expression, the operator also denotes a dependent name. Such names are unbound and are looked up at the point of the template instantiation (17.6.4.1) in the context of the template definition and the context of the point of instantiation. [Example:

```

        p->j++;

```
