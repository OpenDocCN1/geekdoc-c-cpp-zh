# ISO/IEC 14882:2017(E)

11. If a function template f is called in a way that requires a default argument be used, the dependent names are looked up, the semantics constraints are checked, and the instantiation of any template in the default argument is as if the default argument had been an initializer in a function template specialization with the same scope, the template parameters and the same access as that of the function f used at that point, except the scope in which a closure is declared (8.1.5.1) – and therefore its associated namespaces remain remained from the context of the definition for the default argument. This analysis is called default instantiation. The instantiated default is used as the argument of f.

12. Each default is instantiated independently. [Example]:

```
templateClass T void f(T x, T y = zdef(T), T = zdef(T));

class A {
Adef(A);

void g(A a, A b, A c) {
f(a, b, c); // no default argument instantiation
f(a, b); // default argument x = zdef(T) instantiated
} // ill-formed; ydr is not declared
}
```

end example

13. The noexcept-specifier of a template specialization is not instantiated when needed (18.4); if so, if such a noexcept-specifier is present but has not yet been instantiated, the dependent names are looked up, the semantics constraints are checked, and the instantiation of any template used in the noexcept-specifier is done as if it were being done as part of instantiating the declaration at that point.

# 17.7.2 Explicit instantiation [temp.explicit]

1. A class, function, or member template can be explicitly instantiated from its template. A member function, member class or static data of a class template can be explicitly instantiated from the member associated with its class template. An explicit instantiation of a function template or member function of a class template shall not use the inline or constexpr specifiers.

2. The syntax for explicit instantiation is:

```
explicit-instantiation:
extern_template declaration
```

There are two types of explicit instantiation: an explicit instantiation definition and an explicit instantiation declaration. An explicit instantiation declaration begins with the extern keyword.
