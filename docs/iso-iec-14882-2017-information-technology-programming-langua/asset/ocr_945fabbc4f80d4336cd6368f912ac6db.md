# ISO/IEC 14882:2017(E)

```
struct D : B {
    virtual void f(long) override; // error: wrong signature overriding B::f
    virtual void f(int) override;  // OK
};

// end example
```

Even though destructors are not inherited, a destructor in a derived class overrides a base class destructor declared: 15.4 and 15.5.

The return type of an overriding function can be either identical to the return type of the overridden function or covariant with the classes of the functions. If a function D::f overrides B::f, the return types of the functions are covariant if they satisfy the following criteria:

+   (7.1) both are pointers to classes, or references to classes, or value references to classes

+   (7.2) the class in the return type of B::f is the same as the class in the return type of D::f, or is an unambiguous direct base class of the class in the return type of D::f

+   (7.3) both pointers or references have the same class-qualification and the class type in the return type of D::f has the same class-qualification as the class in the return type of B::f

If the class in the covariant type of D::f differs from that of B::f; the return type of D::f will be complete at the point of declaration of D::f or be the class type D. When the overriding function is called as the final overrider of the overridden function, its result is converted to the type returned by the (statistically chosen) overridden function. Example:
