# 24.3 String classes [string.classes]

1 The header <string> defines the basic_string template for manipulating varying-length sequences of char-like objects and type de-names, ustring, u32string, and wstring that name the specializations basic_string<char>, basic_string<char16_t>, basic_string<char32_t>, and basic_string<char>, respectively.
