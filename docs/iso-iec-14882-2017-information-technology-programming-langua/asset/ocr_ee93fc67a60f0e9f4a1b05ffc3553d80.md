# ISO/IEC 14882:2017(E)

# 30.5.3.6 ios_base_callback callbacks [ios.base.callback]

```
void register_callback(event_callback fn, int index);
```

+   1 Effects: Registers the pair (fn, index) that during calls are imbue() (30.5.3.3), copyfmt(), or -ios_base() (30.5.3.7), the function fn is called with argument index. Functions registered are called when an event occurs, in opposite order of registration. Functions registered while a callback function is active until the next event.

+   2 Requires: The function fn shall not throw exceptions.

+   3 Remarks: Identical pairs are not merged. A function registered twice will be called twice.

# 30.5.3.7 ios_base_constructors/destructor [ios.base.cons]

```
ios_base();
```

+   1 Effects: Each ios_base member has an indeterminate value after construction. The object's members shall be initialized by calling basic_init before the first use or before it is destroyed, whichever comes first; otherwise the behavior is undefined.

```
-ios_base();
```

+   2 Effects: Destroys an object of class ios_base. Each registered callback pair (fn, index) (30.5.3.6) as (*erase_event, *this, index) at such time any ios_base member function called from within has well-defined results.

# 30.5.4 Class template fpos [fpos]

```
namespace std {
template <class state> class fpos {
public:
// 30.5.4.1, members
state state() const;
void state(stateT);
private:
state st; // exposition only
};
```

# 30.5.4.1 fpos members [fpos.members]

```
void state(stateT);
```

```
state state() const;
```

+   2 Returns: Current value of st.

# 30.5.4.2 fpos requirements [fpos.operations]

+   1 Operations specified in Table 112 are permitted. In that,

+   (1.1) P refers to an instance of fpos.

+   (1.2) p and q refer to values of type P,

+   (1.3) O refers to a value of type streamoff,

+   (1.4) o refers to a value of type streamoff,

+   (1.5) sz refers to a value of type streamsize and

+   (1.6) i refers to a value of type int.
