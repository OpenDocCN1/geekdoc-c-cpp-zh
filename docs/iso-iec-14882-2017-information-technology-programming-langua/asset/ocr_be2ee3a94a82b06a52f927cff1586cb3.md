# ISO/IEC 14882:2017(E)

# 25.4.2.2.2 num_put virtual functions

```
iter_type_do(put_type out, iosbase str, char_type fill, long val) const;
iter_type_do(put_type out, iosbase str, char_type fill, long val) const;
iter_type_do(put_type out, iosbase str, char_type fill, unsigned long val) const;
iter_type_do(put_type out, iosbase str, char_type fill, unsigned long val) const;
iter_type_do(put_type out, iosbase str, char_type fill, double val) const;
iter_type_do(put_type out, iosbase str, char_type fill, void* val) const;
```

Effects: Writes characters to the character output, formatting val as described. In the following, a local variable initialized with:

```
local isc str=2;
```

The details of this operation occur in stages:

+   - Stage 1: Determine a conversion specifier spec and determine the characters that would be printed by printf(30.11) given this specifier for
  printf(spec, val)
  assuming that the current locale is "C" locale
- Stage 2: Adjust the representation by converting char determined by stage 1 to a charT and returns values returned using of use_facet<numpct<charT>>(str.getloc())
- Stage 3: Determine where padding is required.
- Stage 4: Insert the sequence into the output.

Detailed descriptions of each stage.

Returns: out.

Stage 1: The first stage of stage 1 is to determine a conversion specifier. The tables describe this determination use the following local variables

```
ffflags flags = (flags & (iosbase::basefield));
ffflags basefield = (flags & (iosbase::basefield));
ffflags uppercase = (flags & (iosbase::uppercase));
ffflags floatfield = (flags & (iosbase::floatfield));
ffflags showbase = (flags & (iosbase::showbase));
ffflags showbase = (flags & (iosbase::showbase));
ffflags showpoint = (flags & (iosbase::showpoint));
```

All tables used in describing stage are ordered. That is, the first line given is the one that applies. A line without a condition is the default behavior when none of the earlier lines applies.
For conversion from an integral type other than a character type, the function determines the integral conversion specifier as Table 75.

Table 75

| State | stdio equivalent |
|---| --- |
| basefield == iosbase::oct | % |
| (basefield == iosbase::hex) && uppercase | %x |
| (basefield == iosbase::hex) | %X |
| for a signed integral type | %d |
| for an unsigned integral type | %u |
