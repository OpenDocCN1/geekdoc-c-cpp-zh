# 16.5 Overloaded operators [over.oper]

1 A function declaring one of the following operator-ids as its name declares an operator function. A function template declaration having one of the following operator-ids as its name declares an operator function template. A specialization of an operator template is also an operator function. An operator function is said to implement the operator named in its operator-id.

operator function-id:
    operator operator
