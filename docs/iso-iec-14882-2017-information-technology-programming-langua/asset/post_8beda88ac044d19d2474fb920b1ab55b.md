## 25.4.1.1.2 virtual functions [locale.ctype.virtuals]

```
bool do_is(mask, charT c) const;
const charT* do_is(const charT* low, const charT* high, mask* vec) const;
```

Effects: Converts a character or sequence of characters. For each argument, identifies a value M of ctype_base:mask; the second form identifies a value M of ctype_base:mask for *p (where low <= p && p < high), and into vec[p - low].

2 Returns: The first form returns the result of the expression (M & m) != 0; true if the character has the characteristics. The second form returns high.

```
const charT* do_scan_is(mask m, const charT* low, const charT* high) const;
```

3 Effects: Locates a character in a buffer that conforms to a classification m.

7 Effects: Converts a character or characters to upper case. The second form replaces each character *p in the range [low, high] for which a corresponding upper-case character exists, with that character.

8 Returns: The first form returns the upper-case character if it is known to exist, or its argument if not. The second form returns high.

```
charT tolower(charT) const;

```

Effects: Converts a character or characters to case. The second form replaces *p in the range [low, high] and for which a corresponding lower-case character exists, with that character.

Returns: The first form returns the corresponding lower-case character if it is known to exist, or argument if not. The second form returns high.

```
char do_widen(char c) const;
const* do_widen(const char* low, const char* high) const;
```

Effects: The simplest transformation from a char value or sequence of chars to the corresponding value. The only characters for which unique transformations are required in the basic source character set (5.3).

For any named type with a type<char> facet fct and valid type_base::mask M, itcs(c, M) || !(M, do_widen(c)) is true.

The second form returns character *p in the range [low, high], placing the result in [p-low].

Returns: The first form returns the transformed value. The second form returns high.

```
char do_narrow(char c, char default) const;
const* do_narrow(const char* low, const char* high, char default, const char*) const;
```

Effects: The simplest transformable from a char value or sequence of char values to the corresponding char value or values.

For any c in the basic source character set (5.3) the transformation is that do_widen(do_narrow(c, o)) == c

For any named type with a type<char> facet fct however, and type_base::mask M, is(c, M) || !is(M, do_narrow(c, default)) is true (unless no_narrow returns default). In addition, for any digit c, the expression (do_narrow(c, '0')) evaluates to the digit value of the character. The second form transforms *p in the range [low, high], placing the result (or default if no transformation is readily available) in default[p.

Returns: The first form returns the transformed value; or default if no mapping is readily available. The second form returns high.

## 25.4.1.2 Class template type_typename [locale.ctype.typename]

```cpp
namespace std {
  template<class char>
  class type_typename : public type<char> {
  public:
    using mask = typename type<char>:::mask;
    explicit type_typename(const char*, size_t refs = 0);
    explicit type_typename(const string&, size_t refs = 0);

  protected:
    ~type_typename();
  };
}
```

namespace std {
template <>
    class ctype<char> : public locale::facet, public ctype_base {

    const* is(const char* low, const char* high, mask* vec) const;

    const* scan(const char* not, mask m, const char* low, const char* high) const;

    const* toupper(const char* low, const char* high) const;
    char tolower(char c) const;
    const* tolower(const char* low, const char* high) const;

    char widen(char c) const;
    const* widen(const char* low, const char* high, char* to) const;
    char narrow(char c, char default) const;
    const* narrow(const char* low, const char* high, char default, char* to) const;

    const mask* table() const;
};
