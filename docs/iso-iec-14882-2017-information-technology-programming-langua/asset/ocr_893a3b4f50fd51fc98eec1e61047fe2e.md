# ISO/IEC 14882:2017(E)

In this document, the notation *cv* (or *cv1*, *cv2*, etc.), used in the description of types, represents an arbitrary set of cv-qualifiers, i.e., of {const}, {volatile}, {const, volatile}, or the empty set. For a type cv T, the *top-level* cv-qualifiers of that type are denoted by *cv*: [Example: The type corresponding to the *type-id* const int has no top-level cv-qualifiers. The type corresponding to the *type-id* volatile int * has the top-level cv-qualifier. For a class T, the type corresponding to the *type-id* volatile (C::volatile)(int) has the top-level cv-qualifier volatile. — end example]

CV-qualifiers applied to an array type attach to the notation "cv T", where T is an array type, refers to an array type whose elements are so-qualified. An array type whose elements are considered to have the same cv-qualifications as its elements. [Example:
```

type;
const arr1[] = {0};
const arr2[] = {0};
```

The type of both *arr1* and *arr2* is "array of 5 const char", and the array type is const-qualified. — end example
