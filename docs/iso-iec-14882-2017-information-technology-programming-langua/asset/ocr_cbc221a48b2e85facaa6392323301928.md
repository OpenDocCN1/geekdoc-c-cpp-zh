# 26.3.7.1 Class array overview

+   The header <array> defines a class for storing fixed-size sequences of objects. An array is a contiguous container (26.2.1). An instance of array<T, N> stores N elements of T, so that size() == N is an invariant.

+   An array is an aggregate (11.6.1) that can be list-initialized with up to N elements that are convertible to T.
