# ISO/IEC 14882:2017(E)

+ 1. Effects: The allocation functions (6.7.4.1) called by a new-expression (8.3.4) allocate bytes of storage. The second form is called for a type with new-alignment, and allocates storage with the specified alignment. The first form is called otherwise, and allocates storage aligned to any object of that type object's size does not have extended alignment.

+ 2. Replaceable: A C++ program may define functions with either of these function signatures, and thereby displace the default versions defined by the C++ standard library.

+ 3. Required behavior: Return a non-pointer to suitably aligned storage (6.7.4.1), or throw a bad_alloc exception. This requirement is binding on any replacement versions of these functions.

+ 4. Default behavior:

+ (4.1) Executes a loop: Within the loop, the function first attempts to allocate the requested storage. Whether an attempt invokes a call to the C standard library malloc or aligned_alloc is unspecified.

+ (4.2) Returns a pointer to the allocated storage if the attempt is successful. Otherwise, if the new_handler (21.6.3.5) is a null pointer, returns bad_alloc.

+ (4.3) Otherwise, the function calls the new_handler function (21.6.3). If the function returns, it loops again.

+ (4.4) The loop terminates when an attempt to allocate the requested storage is successful or when a new_handler does not return.

```cpp
void* operator new(size_t size, std::nothrow&) noexcept;
void* operator new(size_t size, std::align_val_t alignment) noexcept;
```

+ 5. Effects: As above, these are called by a placement version of a new-expression when a C++ program may return a null result, instead of a bad_alloc exception.

+ 6. Replaceable: A C++ program may define functions with either of these function signatures, and thereby displace the default versions defined by the C++ standard library.

+ 7. Required behavior: Return a non-pointer to suitably aligned storage (6.7.4.1), or return a null pointer. Each of these versions of operator new returns a pointer as acquired from the (possibly) non-placement function. This requirement is binding on any replacement versions of these functions.

+ 8. Default behavior: Calls operator new(size), or operator new(size, alignment), respectively. If the call returns normal, returns the result of that call. Otherwise, returns a pointer.

+ 9. Example:
