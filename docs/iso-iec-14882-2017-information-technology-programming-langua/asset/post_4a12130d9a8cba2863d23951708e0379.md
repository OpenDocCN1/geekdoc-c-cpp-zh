## 26.6.5.4 priority_queue specialized algorithms

```cpp
template <class T, class queueT, class Container, class Compare>
void swap(priority_queue<T, queueT, Container, Compare>& y) noexcept(noexcept(x.swap(y))))
{
  x.swap(y);
```

Remarks: This function shall not participate in order resolution unless is_swappable_v<Container> is true and is_swappable_v<Compare> is true.

Effects: As if x.swap(y).

## 26.6.6 Class template stack

+ 1 Any sequence supporting operations back(), push_back() and pop_back() can be used to instantiate stack. In particular, vector (26.3.11), list (26.3.10) and deque (26.3.8) can be used.

### 26.6.6.2 stack constructors

[stack.cons]

```cpp
explicit stack(const Container& cont);
```

+ 1. Effects: Initializes c with cont.

```cpp
explicit stack(Container&& cont) : cont(std::move(cont)) {}
```

+ 2. Effects: Initializes c with std::move(cont).

### 26.6.6.3 stack constructors with allocators

[stack.cons.alloc]

1. If use_allocator<v, container_type, Allocator> is false the constructors in this clause shall not participate in overload resolution.

```cpp
template<class Alloc> explicit stack(const container_type& cont, const Alloc& a);
```

+ 2. Effects: Initializes c with a.

```cpp
template<class Alloc> stack(const container_type& cont, const Alloc& a);
```

+ 3. Effects: Initializes c with the first argument as a and as the second argument.

```cpp
template<class Alloc> stack(container_type&& cont, const Alloc& a);
```

+ 4. Effects: Initializes c with std::move(cont) as the first argument and as the second argument.

```cpp
template<class Alloc> stack(stack&& s, const Alloc& a);
```

+ 5. Effects: Initializes c with s.c as the first argument and as the second argument.

```cpp
template<class Alloc> stack(const Alloc& s, const Alloc& a);
```

Effects: Initializes c with std::move(s.c) as the first argument and as the second argument.

## 26.6.6.4 stack operators [stack.ops]

