The class strambuf associates the input sequence, and possibly the output sequence, with an object of some character type, whose elements store array values. The object has several attributes.

[Note: For the sake of offset, these are represented as elements of bitmask type (indicated here as T1) called strstate. The elements are:

+   (2.1) allocated, when a dynamic array object has been allocated, and hence should be freed by the destructor for the strambuf object;

+   (2.2) constant, when the array object has const elements, so the output sequence cannot be written;

+   (2.3) dynamic, when the array object is allocated (or reallocated) as necessary to hold a character sequence that can change in length;
