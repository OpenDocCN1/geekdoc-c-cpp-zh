# 23.8.3.2 Assignment [any.assign]

```
any& operator=(const any&& rhs);
```

+   1 Effects: As if any(rhs).swap(*this). No effects if an exception is thrown.

+   2 Returns: *this.

+   3 Throws: Any exception arising from the copy constructor of the contained value.

```
any& operator=(any&& rhs) noexcept;
```

+   4 Effects: As if any(std::move(rhs)).swap(*this).

+   5 Returns: *this.

+   6 Postconditions: The state of *this is equal to the state of rhs and rhs is left in a valid but otherwise unspecified state.

```
template<class T>
any& operator=(T&& rhs);
```

7 Let VT be decay<T>.

8 Requires: VT shall satisfy the CopyConstruct requirements.

9 Effects: Constructs an object of type any that contains an object of VT direct-initialized with std::forward<T>(args), and tmp.swap(*this). No effects if an exception is thrown.

10 Returns: *this.

11 Remarks: This operator shall not participate in overload resolution unless VT is not the same type as any and is_copy_constructible_v<VT> is true.

12 Throws: Any exception thrown by the selected constructor of VT.
