# 31.10 Class template match_results

+   Class template match_results denotes a sequence of character sequences representing the result of a regular expression. Storage for the container is allocated and as necessary by the member functions of class match_results.

+   The class template match_results satisfies the requirements of an allocator-container and of a sequence container (26.2.1, 26.2.3) except that only operations performed for const-qualified sequence containers are supported and that the semantics of comparison functions are different from those required for a container.
