## 23.6.8 Comparison with T [optional.comp_with_t]

```cpp
template <class T, class U> constexpr operator==(const optional<T>& x, const U& v);
```

The expression x == v will be well-formed and its result will be convertible to bool.
[Note: T need not be EqualityComparable. — end note]

Effects: Equivalent to: return bool(x) ? x == v : false;

```cpp
template <class T, class U> constexpr operator!=(const U v, const optional<T>& x);
```

The expression x != v will be well-formed and its result will be convertible to bool.

Effects: Equivalent to: return bool(x) ? x != v : false;

```cpp
template <class T, class U> constexpr operator<(const U v, const optional<T>& x);
```

The expression x < v will be well-formed and its result will be convertible to bool.

Effects: Equivalent to: return bool(x) ? x < v : true;

```cpp
template <class T, class U> constexpr operator<=(const U v, const optional<T>& x);
```

The expression x <= v will be well-formed and its result will be convertible to bool.

```cpp

```

The expression x > v will be well-formed and its result will be convertible to bool.

## 23.6.9 Specialized algorithms [optional.specalg]

```cpp
template <class T> void swap(optional<T>& x, optional<T>& y) noexcept(noexcept(x.swap(y)));
```

Calls: x.swap(y);

Remarks: This shall not participate in overload resolution unless is_move_constructible_<T> is true or is_swappable<T> is true.

```cpp
template <class T> constexpr optional<decay_t<T>> make_optional(T&& v);
```

Returns: optional<decay_t<T>>(std::forward<T>(v));

```cpp
template <class T, class... Args>
constexpr optional<T> make_optional(Args&&... args);
```

Effects: Equivalent to return optional<T>(in_place, std::forward<Args>(args)...);

```cpp
template <class T, class U, class... Args>
constexpr optional<T> make_optional(initializer_list<U> il, Args&& args);
```

Effects: Equivalent to return optional<T>(in_place, std::forward<Args>(args)...);

## 23.6.10 Hash [optional.hash]

```cpp
template <class T> struct optional<T>;
```

The specialization `optional<T>` is enabled if and only if `remove_const_t<T>` is enabled. For an object of type `optional<T>`, if `bool(o) == true`, then `hash<optional<T>>()(o)` will evaluate to the same value as `hash<remove_const_t<T>>`; otherwise it evaluates to an unspecified value. The member functions are guaranteed to be noexcept.

## 23.7 Variants [variant]

A variant object manages the lifetime of a variant. If a variant holds a value, that variant's type has been one of the types given by variant arguments. These are alternatives.

### general [variant.general]

```cpp
namespace std {
  template <... Types>
  class variant {
    template <T> struct variant_size; // not defined
    template <T> struct variant_size<const T>;
    template <T> struct variant_size<volatile T>;
    template <T>
    inline constexpr size_t variant_v = variant_size<T>::value;

    template <... Types>
    struct variant_size<Types...>;

    template <size_t I, class T> struct variant_alternative; // not defined
    template <size_t I, class T> struct variant_alternative<I, const T>;
    template <size_t I, class T> struct variant_alternative<I, volatile T>;
    template <size_t I, class T> struct variant_alternative<I, const T>;
    template <size_t I, class T>
    using variant_alternative_t = typename variant_alternative<I, T>::type;

    template <size_t I, class... Types>
    struct variant_alternative<Types...>;

    inline constexpr size_t variant_npos = -1;

    ### 7.5 value access [variant.7.5, value]
    template <... Types>
    class variant {
    bool holds_alternative(const variant<Types>&...) noexcept;

    template <size_t I, class... Types>
    constexpr variant_alternative_t<I, Types...>& get(const variant<Types>&...) const noexcept;
    template <size_t I, class... Types>
    constexpr variant_alternative_t<I, Types...>& get(const variant<Types>&...) const noexcept;
    template <size_t I, class... Types>
    constexpr variant_alternative_t<I, Types...>& get(const variant<Types>&...) const noexcept;
    };
```
