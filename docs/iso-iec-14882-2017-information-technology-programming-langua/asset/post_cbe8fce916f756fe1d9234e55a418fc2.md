## 6.4.3 Qualified lookup [basic:lookup.qual]

4 When considering associated namespace, the lookup is the same as the lookup performed when the associated namespace is used as a qualifier (6.4.3.2) except that:

- 4.1 Any-directives in the associated namespace are ignored.
- 4.2 Any-namespace-scope friend or function templates declared in associated classes are visible within their respective namespaces even if they are not visible during an ordinary lookup (14.3).
- 4.3 All names except of (possibly overloaded) functions and function templates are ignored.

1 The name of a class or namespace member or enumerator is referred to as the :: scope resolution operator (8.1) applied to a nested-name-specifier that denotes its class, namespace, or enumeration. If a :: scope resolution operator performed in a nested-name-specifier is not preceded by a declype-specifier, lookup of the name preceding that :: considers only namespaces, types, and templates whose specializations are types. If the name does not designate a namespace or a class, enumeration, or dependent type, the program is ill-formed. Example:

```
class A {
public:
    static int n;
int main() {
    int A;
    A::n = 42;
    B::n; // OK
// ill-formed: A does not name a type
} // example
```

2 [Note: Multiply qualified names, such as R1::N2::N3::, can be used to refer to members of classes (12.2.5) or members of namespaces. -- note]

3 In a declaration where the declarator-id is a qualified-id, names used before the qualified-id declared are looked up in the defined namespace; names following the qualified-id are looked up in the scope of the member's class or namespace. ::Example:

```
class X {
class C {
static const int number = 50;
};
X::arr[number]; // ill-formed: to ::X::arr[number]
// and not to: X::C::arr[number];
```

4 A name prefixed by :: is looked up in the scope of the member's class or namespace. Example:

```cpp
class X {
class C {
static const int number = 50;
};
X::arr[number]; // ill-formed: to ::X::arr[number]
// and not to: X::C::arr[number];
```

5 A name prefixed by :: is looked up in the global scope. Example:

```cpp
struct A {
    ~A();
};
    typedef AB;
int main() {
    A* p;
    p->AB(); // explicitly calls the destructor
}
```

6 If a nested-name-specifier is not used, the program is ill-formed. Example:

```cpp
class A {
public:
    static int n;
int main() {
    int A;
    A::n = 42;
    B::n; // OK
// ill-formed: A does not name a type
} // example
```

## 6.4.3.1 Class members

1 If the nested-name-specifier nominates a class, the name specified by the nested-name-specifier is looked up in the scope of the class (13), except for the cases listed below.
