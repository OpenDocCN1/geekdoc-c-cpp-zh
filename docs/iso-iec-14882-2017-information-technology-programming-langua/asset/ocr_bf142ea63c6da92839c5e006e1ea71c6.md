# 7.1 Value-to-prvalue conversion

1 A value (6.10) of a non-function, non-array type T can be converted to a prvalue.57 If T is an incomplete type, a program that necessitates this conversion is ill-formed. If T is a non-class type, the type of the prvalue is the cv-unqualified version of T. Otherwise, the type of the prvalue is T.59

2 When an value-to-prvalue conversion is applied to an expression e, and other

+   (2.1) e is not potentially value,

+   (2.2) the evaluation of e results in the evaluation of a member ex of the set of potential results of e, and ex variable x that is not used by ex (6.2).

the value contained in the referenced object is not accessed. [Example]:

```
struct S {
  int n;
}
auto f() {
  S x;
  constexpr y { 
    return [](bool b) { return b ? y : x.n; };
}
auto g = f();
int m = g(false);
// undefined behavior due to access of x.n outside its lifetime
int n = g(true);
// Ok, does not access y.n
// end example
```

3 The result of the conversion is determined by the following rules:

+   (3.1) If T is std::ptr_t, the result is a null pointer conversion (7.11). [Note: Since no value is fetched from ptr, there is no side effect for a value access (4.6), and an inactive member of a union (12.3) may be accessed. — end note

+   (3.2) Otherwise, if T has a class type, the conversion copy-initializes the result object from the glvalue.

+   (3.3) Otherwise, the object to which the glvalue refers to an invalid pointer value (6.7.4.2, 6.7.4.3), the behavior is implementation-defined.

+   (3.4) Otherwise, the value contained in the object by the glvalue is the prvalue.

[4] Note: see 6.10. — end note

# 7.2 Array-to-pointer conversion

1 An array of type "array of T" or "array of unknown size T" can be converted to a prvalue of type "pointer to T". The temporary materialization conversion (7.4) is applied. The result is a pointer to the first element of the array.

57 For historical reasons, this conversion is called the "value-to-prvalue" conversion, even though that name does not accurately reflect the taxonomy of expressions described in 6.10.

58) In C++ class and array types can have cv-qualified types. This differs from ISO C, in which non-values never have cv-qualified types.
