# ISO/IEC 14882:2017(E)

# 32 Atomic operations library [atom]

# 32.1 General [atomic.general]

+   1 This Clause describes components for fine-grained atomic access. This access is provided via operations on atomic objects.

+   2 The following subclasses describe atomic requirements and components for types and operations, as summarized below.
