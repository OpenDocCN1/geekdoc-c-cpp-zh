# 17.3.2 Template non-type arguments

+   If the type of a non-template-parameter contains a placeholder type by template deduction (10.1.7.4, 17.1), the deduced parameter is determined from the type of the template-argument by template deduction (10.1.7.4.1). If a deduced parameter type is not permitted for a template-parameter declaration (17.1), it is ill-formed.

+   A template-argument for a non-type template-parameter shall be a converted constant expression (8.2) of the value of the template-parameter. For a non-type template-parameter of reference or pointer type, the value of the constant expression shall not refer to the address of:

+   a subject (4.5),

+   a temporary object (15.2),

+   a string literal (5.13.5),

+   the result of a type expression (8.2.8), or

+   a prenamed __func__ variable (11.4.1).

> [Note: If the template-argument represents a set of overloaded functions (or a pointer or pointer member to such), the matching function is selected from the set (16.4). -- end note]

+   [Example:

```
template<const int*> ptr> struct X { /* ... */ };
int ai[];
X(ai); // array to pointer and qualification conversions

struct Y {
template<const Y&> struct Z { /* ... */ };
Y y;
// no conversion, but extra cv-qualification
Z(y);

template<int <span>> struct W { /* ... */ };
int b[5];
W(b); // no conversion

void f(char);
void f(int);

template<void (*)(int)> struct A { /* ... */ };
A&f(int) a; // selects f(int)

template<auto n> struct B { /* ... */ };
B<1 = b1; // OK: template parameter type is int
B<'a'> = b2; // OK: template parameter type is char
B<2.5> = b3; // error: template parameter type cannot be double
```
