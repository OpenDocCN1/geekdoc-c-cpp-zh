# 26.4.5.2 multimap constructors

> [multimap.com]

explicit multimap(const Compare& comp, const Allocator& alloc = Allocator());

- 1 Effects: Constructs an empty multimap using the specified comparison object and allocator.
- 2 Complexity: Constant.

```cpp
template<class InputIterator>
multimap(InputIterator first, InputIterator last,
  const Compare& comp = Compare(),
  const Allocator& alloc = Allocator());
```

- 3 Effects: Constructs an empty multimap using the specified comparison object and allocator, and inserts
elements from the range [first, last).
- 4 Complexity: Linear in N if the range [first, last) is already sorted by comp and otherwise
N log N, where N is last - first.

# 26.4.5.3 multimap modifiers [multimap.modifiers]

```cpp
template <class P> iterator insert(P& x);
template <class P> iterator insert(const_iterator position, P<P> (x));
```

> Effects: The first form is equivalent to return emplace(std::forward<P>(x)); The second form is equivalent to return emplace_hint(position, std::forward<P>(x)).

> Remarks: This signature shall not participate in overload resolution unless is_constructible_<value_type, P&> is.

# 26.4.6 Class template [set]

# 26.4.6.1 Class template set overview [set.overview]

- A is an associative container that supports unique keys (at most one of each key value) and provides fast retrieval of the keys. The set class supports bidirectional iterators.
- B satisfies all of the requirements of a bidirectional container (26.2), an associative container (26.6), and an allocator-aware container (26.8). A set also provides operations described in 26.6 for unique keys. A set that supports unique operations in 26.6 but not the equality operations. For a set<Key> the key and value_type are Key. Descriptions are provided only for operations not described in these and for operations there is additional semantic information.
