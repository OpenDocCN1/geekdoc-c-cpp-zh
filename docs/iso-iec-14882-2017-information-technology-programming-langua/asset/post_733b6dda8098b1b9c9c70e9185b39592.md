13 In a non-delegating constructor, initialization proceeds in the following order:

§ 15.6.2

+ (13.1) First, and only for the constructor of the derived class (4.5), virtual base classes are initialized the order they appear on a depth-first left-to-right traversal of the directed acyclic graph of base classes, where "left-to-right" is the order of appearance of the base classes in the derived class base-specifier-list.

+ (13.2) Then, base classes are initialized in order as they appear in the base-specifier-list (regardless of the order of the mem-initializers).

+ (13.3) Then, non-static data members are initialized in the order they were declared in the class definition (again regardless of the order of the mem-initializers).

+ (13.4) Finally, the compound-statement of the constructor body is executed.

```
 15.6.3 Initialization by inherited constructor

When a constructor for type B is invoked to initialize an object of a different type D (that is, when the constructor was initialized (10.3.3)), initialization proceeds as if a default constructor was used to initialize the D object and base class from which the constructor was inherited, except that the B object is initialized by the invocation of the inherited constructor. The complete initialization is considered to be a single function call; in particular, the initialization of the inherited constructor's parameters is sequenced before the initialization of any part of the object. [Example:

```
struct B1 {
  B1(int, ...) {}
};

struct B2 {
  B2(double) {}
};

int get();

struct D1 : B1 {
  using B1::int;
  int x;
  int y = get();
};

void test() {
  D1(2, 3, 4);
  // OK: // d.x is default-initialized (no initialization is performed),
  // d.y is initialized by calling get()
  // error: D has a deleted default constructor
}

D1 e;
struct D2 : B2 {
  using B2::int;
  B1 b;
  // error: B1 has a deleted default constructor
}

D2 f(1.0);
struct W { W(int); };
struct X { virtual W::W; X(X&) = delete; };
struct Y : X { using X::X; };
struct Z : Y { virtual Y; using Y::Y; };
X(0); // OK: initialization of Y does not invoke constructor of X

```
template<class T> class Log : class T {
  using T::T;
  ~Log() { std::cout << "Destroying wrapper" << std::endl; }
};
```

Class Log wraps any class and for all of its constructors, writing a message to the standard log whenever an object of class Log is destroyed. — end example

If the constructor was inherited from multiple base class subobjects of type B, the program is ill-formed. [Example:

```
struct A { A(int); };
```

```
struct B : A { using A::A; };

struct C1 : B { using B::B; };
struct C2 : B { using B::B; };

struct D1 : C1, C2 {
    using C1::C1;
    using C2::C2;
};

struct V1 : virtual B { using B::B; };
struct V2 : virtual B { using B::B; };

struct D2 : V1, V2 {
    using V1::V1;
    using V2::V2;
};

D D1(0());
D D2(0());
// ill-formed: ambiguous
// OK: initializes virtual B base class, which initializes the A base class
// then initializes the V1 and V2 base classes as if by a default constructor

struct M { M(int); };
struct N : M { using M::M; };
struct O : M {};
struct P : N, O { using N::N; using O::O; };

// use M(O) to initialize O's base class
```
