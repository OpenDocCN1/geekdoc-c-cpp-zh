## 2 Effects: These functions have the semantics specified in the C standard.

## 3 Remarks: These functions do not attempt to allocate storage by calling ::operator new(21.6) on allocation, which can be to be declared reachable upon deallocation, and need not to be declared reachable as the result of an undeclared_reachable() call. [Note: This allows C libraries to remain unaffected by restrictions on pointers at the expense of providing fewer garbage collection detection options.] It also allows malloc() to be implemented with a separate allocation arena, bypassing the normal declare_reachable() implementation, above functions should never intentionally be used as a replacement for declare_reachable(), and newly written code is strongly encouraged to treat memory allocated with these functions as though it were allocated with operator new.

# 23.11 Smart pointers

## 23.11.1 Class template unique_ptr

1 A unique_ptr is an object that owns and manages that other object through a pointer. More precisely, a unique pointer is an object u that stores a pointer to a second object p and will dispose of p when u is itself destroyed (e.g., when leaving block scope (9.7)). In this context, u is said to own p.

2 The mechanism by which u disposes of p is known as p's associated deleter, a function object whose correct invocation results in p's appropriate disposition (typically delete).

3 Let the notation u.p denote the pointer stored by u, and u.d denote the associated deleter. Upon request, u can reset (replace) u.p and u.d with another pointer and deleter, and properly disposes of its owned object via the associated deleter after replacement is considered completed.

4 Additionally, u can, upon request, transfer ownership to another pointer u2. Upon completion of such a transfer, the following postconditions hold:

```
(4.1) u.p is equal to the transfer-u.p,
(4.2) u.p is equal to nullptr;
```

```
(4.3) if the transfer-u.d maintained state, the pre-transfer associated ownership has been transferred to u.d.
```

As in the case of a result, u2 properly disposes of its pre-transfer ownership via the pre-associated deleter before the transfer is considered complete. [Note: A deleter's state is never copied, only moved or swapped as ownership is transferred.] -- end note

5 Each object of a type instantiated from the unique_ptr template in this subclass has the strict ownership semantics, specified above, unique pointer. In partial satisfaction of these semantics, u is MoveConstructible and Moveable, but is not CopyAssignable. The template parameter T unique_ptr may be an incomplete type.

6 [Note: The uses of unique_ptr include exception safety for dynamically allocated memory, passing ownership of dynamically allocated memory from a function and returning dynamically allocated memory from -- end note

# 23.11.1 Default deleters [unique_ptr.dltr]

## 23.11.1.1 In general [unique_ptr.dltr.general]

1 The class template default_delete serves as the default deleter (destruction policy) for the class template unique_ptr.

2 The template parameter T of default_delete may be an incomplete type.

    template <class T, class D = default_delete<T>> class unique_ptr {
public:
    using pointer = see below;
    using element_type = T;
    using deleter = D;

    // // 23.11.2.1 constructors
    constexpr unique_ptr() noexcept;
    explicit unique_ptr(pointer p) noexcept;
    unique_ptr(pointer p, see below d1) noexcept;
    unique_ptr(pointer p, see below d2) noexcept;
    unique_ptr(const unique_ptr& u) noexcept;
    constexpr unique_ptr(const unique_ptr& u) noexcept;
    template <class U, class E> unique_ptr(unique_ptr<U, E>&& u) noexcept;

    // // 23.11.2.2 destructor
    ~unique_ptr();

    // // 23.11.2.3 assignment
    unique_ptr& operator=(const unique_ptr& u) noexcept;
    template <class U, class E> unique_ptr& operator=(unique_ptr<U, E>&& u) noexcept;
    unique_ptr& operator=(nullptr_t) noexcept;

    // // 23.11.2.4 observers
    add_value_reference<T_> operator*() const noexcept;
    pointer operator->() const noexcept;
    pointer get() const noexcept;
    deleter_type get_deleter() const noexcept;
    const deleter_type get_deleter() const noexcept;
    explicit operator bool() const noexcept;

    // // 23.11.2.5 modifiers
    void release() noexcept;
    void reset(pointer p = nullptr) noexcept;
