# 8.3.5 Delete

The delete-expression destroys a most object (4.5) or array created by a new-expression.

```
delete-expression:
delete cast-expression
::delete [ cast-expression ]
```

The first alternative is for non-array objects, and the second for arrays. The delete keyword is immediately followed by empty square brackets, it shall be interpreted as the second alternative.81 The operand shall be a pointer to object type or type of class. If class type, the operand is implicitly converted (Clause 7) to a pointer to object type.92 The delete-expression has result void.
2 If the operand has a deallocation function, the value of the operator of delete may be a null pointer or a (4.5) alternative (delete array), the value of the operator of delete alternative (array array new-expression) may be a null pointer or a pointer to a non-array object created by a previous new-expression.83 If not, the behavior is undefined. In the second alternative the value of the operator delete may be a null pointer or a pointer value that resulted from a previous array new-expression. If not, the behavior is undefined. [Note: The syntax of the delete-expression must match the type of the object allocated by new, not the syntax of the new-expression. A pointer to const type can be the type of a delete-expression; if it matches (8.2.11) of the pointer expression before it is used as the operand of the delete-expression. — end note]

3 In the first alternative (delete), if the type of the object to be deleted is different from its dynamic type, the static type shall be a base class of the dynamic type of the object to be deleted and the static must have a virtual destructor or the behavior is undefined. In the second alternative (delete array) if the dynamic type of the object to be deleted differs from its static type, the behavior is undefined.

4 The cast-expression in a delete-expression shall be evaluated exactly once.

+   1) A lambda expression with a lambda-introducer consists of empty square brackets can follow the delete keyword if the lambda expression is enclosed in parentheses.

+   2) It is forbidden that an object is deleted using a pointer of type void* because void is not an object type.

+   3) For non-zero arrays, this is the same as a pointer to the first element of the array created by new-expression. Zero-length arrays do not have a first element.
