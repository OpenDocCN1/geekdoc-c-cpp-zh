# ISO/IEC 14882:2017(E)

1 The logic_error defines the type of objects thrown as exceptions to report errors presumably detectable before the program executes, as violations of logical preconditions or class invariants.

```
logic_error(const string& what_arg);
2 Effects: Constructs an object of class logic_error.
3 Postconditions: strcmp(what(), what_arg.c_str()) == 0.
logic_error(const char* what_arg);
4 Effects: Constructs an object of class logic_error.
5 Postconditions: strcmp(what(), what_arg) == 0.
```

# 22.2.3 Class domain_error [domain-error]

```

class domain_error : public logic_error {

}
```

```
3 Postconditions: strcmp(what(), what_arg.c_str()) == 0.
```
