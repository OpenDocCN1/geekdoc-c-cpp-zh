# 21.6.3.3 Type new-handler [new.handler]

```
using new_handler = void (*)();
```

+   The type of a handler function to be called by operator new() or operator new[] (21.6.2) when they cannot satisfy a request for additional storage.

+   Required Behavior: A new-handler shall perform one of the following:
(2.1) make sure storage is available for allocation and then return;
(2.2) throw an exception of type bad_alloc or a class derived from bad_alloc;
terminate the execution of the program without returning to the caller.

# 21.6.3.4 set new-handler [new.handler]

```
new_handler set_new_handler(new_handler new_p) noexcept;
```

Effects: establishes the function designated by new_p as the current new-handler.

Returns: The previous new-handler.

Remarks: The initial new-handler is a null pointer.

# 21.6.3.5 get_new-handler [new.handler]

```
new_handler get_new_handler() noexcept;
```

Returns: The current new-handler. [Note: This may be a null value. — end note]

# 21.6.4 Pointer optimization barrier [ptr.launder]

```
template <class T> T launder(T* p) noexcept;
```

+   Requires: p represents the address A of byte in memory. An object X that is within its lifetime (6.8) whose type is similar (7.5) to T is located at address A. All stores of type that are reachable through the result are reachable (see below).

+   Returns: A value of type T* points to X.

+   Remarks: An invocation of this function may be used in a constant expression whenever the value of its argument is used in a constant expression. A store of type that is reachable through a pointer that points to an object Y if it is within the storage occupied by X, or a pointer-interconvertible with Y, or the immediately-enclosing array object if Y is an array element. The program is ill-formed if T is a type cur or void.
