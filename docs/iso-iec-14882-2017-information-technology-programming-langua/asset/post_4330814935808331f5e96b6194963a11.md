# 6.5 Program and linkage

1 A program consists of one or more translation units (Clause 5) linked together. A translation unit consists of a sequence of declarations.
translation-unit:

2 A name is said to have linkage when it denotes the same object, reference, function, type, template, namespace or value a name introduced by a declaration in another scope:

- When a name has external linkage, the entity it denotes can be referred to by names from scopes of other translation units or from other scopes of the same translation unit.
- When a name has internal linkage, the entity it denotes can be referred to by names from other scopes in the same translation unit.
- When a name has no linkage, the entity it cannot be referred to by names from other scopes.

The name of a declaration in block scope and the name of a variable by a block scope extern declaration have the same name and linkage. If there is a visible declaration of an entity with linkage having the same name and type, ignoring entities outside the innermost enclosing namespace, the block scope declaration declares that entity and receives the linkage of the previous declaration. ## 6.6 Start and termination

### 6.6.1 main function

A program shall have a function called main. Executing a program starts a thread of execution (4.7.33) in which main is invoked, and in which variables of static storage might be initialized (6.6.2) and destroyed (6.6.4). It is implementation-defined whether a program in a freestanding environment is required to define a start-up and termination is implementation-defined: execution of constructors for objects with static storage; termination the execution of destructors for objects with static storage end note

An implementation shall define the main function. This function shall not be overloaded. It shall have C++ linkage and it shall declare a return type of int, but otherwise its type is implementation-defined. An implementation shall allow

(2.1) a function of (int, pointer to char) returning int

(2.2) as the type of main (11.3.5). In the latter form, for purposes of exposition, the first function parameter is passed from the program in which the program runs is argv[0] through argv[argc-1] as pointers to the initial characters of null-terminated strings (NTMSs) (20.4.1.1.2) and argv[0] shall be the pointer to the initial character of a NTMS that represents the name used by the program or *. The value of argc shall be non-negative. The value of argv[argc] shall be 0. [Note: It is recommended that any optional (parameters) may be passed after argv; — end note

The main function shall be defined within a program. The linkage (6.5) of main is implementation-defined. A program that defines main to be inline, static, or constexpr is ill-formed. The main function shall not be declared with a linkage-specification (10.5). A program that declares a main at global scope or declares the name with C language linkage (in any namespace) is ill-formed. The main name is not otherwise reserved. [Example: Member functions, classes, and enumerations can be called main, as in other namespaces — end example]
