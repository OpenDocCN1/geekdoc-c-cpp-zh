- 4 Effects: Moves content from the rvalue rhs. Its implementation-defined whether the sequence pointers in *this(eback(), gptr(), egptr(), rhs_pbase(), pptr(), eptr()) obtain the values which rhs had. ## 30.2.2 Assign and swap

```cpp
basic_stringbuf& operator=(basic_stringbuf& rhs)
```

Effects: After the move assignment *this has the observable state it would have had if it had been moved from rhs (see 30.8.2.1).

Returns: *this.

```cpp
void swap(basic_stringbuf& rhs);
```

Effects: Exchanges the state of *this and rhs.

```cpp
template <class charT, Traits, Allocator>
void swap(basic_stringbuf<charT, Traits, Allocator>& x,
     basic_stringbuf<charT, Traits, Allocator>& y);
```

Effects: as x.swap(y).

## 30.2.3 Member functions

```cpp
basic_stringbuf<charT, Traits, Allocator> const();
```

Returns: A basic object whose content is equal to the basic_string underlying sequence. If the basic_string was created in only input mode, the resultant basic_string contains the character sequence in range [eback(), egptr()). If the basic_string was created with ios_base::out being nonzero, the resultant basic_string contains the character sequence in range [pbase(), eptr()), where mark represents the position of the last character initialized by writing to the stream, by constructing the basic_string, or by calling str() member function. In the case all initialized are now considered uninitialized (except for those re-initialized by the basic_stringbuf has created in neither input mode and a zero length basic_string is returned.

```cpp
void str(const basic_string<char, Allocator>& s);
```

Effects: Copies s into the stringbuf underlying character sequence and initializes the input and output sequences according to mode.

Postconditions: If mode & ios_base::out is nonzero, pptr() points to the underlying character and eptr() == pptr() + s.size(); if mode & ios_base::in is nonzero, pptr() == pptr() + s.size(). If mode & ios_base::in is nonzero, eback() points to the underlying character, and both gptr() == eback() and egptr() == eback() + s.size() holds.

## 30.8.2.4 Overridden functions

```cpp

```

```cpp
int_type putback(int_type c = traits::eof()) override;
```

Effects: Puts the character designated by c to the output sequence, if possible, in one of three:

- If traits::int_type(c, traits::eof()) returns false and if the input sequence has putback available, and if traits::to_char_type(c), gptr()[-1]) returns true, assigns gptr() - 1 to gptr().
  Returns: c.
- If traits::int_type(c, traits::eof()) returns false and if the input sequence has putback available, and if mode & ios_base::out is nonzero, to gptr().
  Returns: c.
- If traits::int_type(c, traits::eof()) returns true and if the input sequence has putback available, assigns gptr() - 1 to gptr().
  Returns: not_eof(c).

Returns: As specified above, or traits::eof() to indicate failure.

Remarks: If the function can succeed in more than one of these, it is unspecified which is chosen.

```cpp
int_type overflow(int_type c = traits::eof()) override;
```

Effects: Appends the character designated by c to the output sequence, if possible, in one of two:

- If traits::int_type(c, traits::eof()) returns false and if either the output sequence has a write position available or the function can make a write position available (as described below), the function sput(c).
Signals by returning
- If traits::int_type(c, traits::eof()) returns true, there is no character to append.
Signals by returning

Remarks: The function can alter the number of write positions available as a result of any call.

Returns: As specified above, or traits::eof() to indicate failure.

The function can make a write position available only if (mode & ios_base::out) != 0. To make a write position available, the function reallocates (or initially allocates) an object with sufficient number of elements to hold the current array (if any), plus at least one additional write position.

If (mode & ios_base::in) != 0, the function alters the read pointer egptr() to just past the new write position.

```cpp
pos_type seekoff(off_type off, ios_base::seekdir dir,
    ios_base::openmode mode = ios_base::in | ios_base::out) override;
```

Effects: Alters the stream position within one of the controlled sequences, if possible, as indicated in Table 115.

| Conditions | Result |
|---|---|
| (which & ios_base::in) == ios_base::in | positions the input sequence |
| (which & ios_base::out) == ios_base::out | positions the output sequence |
| (which & ios_base::in | ios_base::out) == (ios_base::in | ios_base::out) and way == ios_base::beg \| ios_base::end | positions both the input and output sequences |
| Otherwise | the positioning operation fails |

For a sequence to be positioned, its next pointer (either egptr() or pptr()) is a null pointer the positioning operation fails. Otherwise, the function determines newoff as indicated in Table 116.

| Condition | newoff Value |
|---|---|
| way == ios_base::beg | 0 | the next pointer minus the beginning pointer (xnext xbeg). |
| way == ios_base::cur | |
| way == ios_base::end | the high mark pointer minus the beginning pointer (high_mark - xbeg). |

If (newoff + off) < 0, or if newoff + off refers to an undefined character (30.8.2.3), the positioning operation fails. Otherwise, the function xbeg + newoff + off refers to the next pointer next.

Returns: pos_type(newoff), constructed from the result offset newoff (of off_type), that stores the stream position. If the positioning operation fails, or if the constructed object cannot return the stream position, the return value is pos_type(off_type(-1)).
