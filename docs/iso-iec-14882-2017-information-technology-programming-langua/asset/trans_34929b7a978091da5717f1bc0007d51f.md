## 23.2. 运算符 [operators]

- 1 为了避免 `operator!=` 之外 `operator>`、 `<=` 以及 `operator<` 的冗余定义，库提供了以下内容：

```cpp
template <class T> bool operator!(const T& x, const T& y);
```
- 2 要求：类型 `T` 是可比较的（表 20）。
- 3 返回：!(x == y)。

```cpp
template <class T> bool operator<(const T& x, const T& y);
```

- 4 要求：类型 `T` 是可比较的（表 21）。
- 5 返回：(y < x)。

```cpp
template <class T> bool operator<=(const T& x, const T& y);
```

- 6 要求：类型 `T` 是小于可比较（表 21）。
- 7 返回：!(x <= y)。

```cpp
template <class T> bool operator>=(const T& x, const T& y);
```

- 8 要求：类型 `T` 是大于可比较（表 21）。
- 9 返回：!(x >= y)。
