# ISO/IEC 14882:2017(E)

```
true: "a" and false: "abb", the input sequence "a" yields == true and err == str.eof;
the input sequence "abc" yields == str.failbit, with ending at the 'c' element. For targets
the sequence "1" and false: "0", the input sequence "1" yields == true and err == str.goodbit.
empty targets ('*'), any input sequence err == str.failbit. // example
```

Returns: in
