# ISO/IEC 14882:2017(E)

```
template<class T> void f(T);
template<class T> void f(T*);
template<class T> void f(const T*);
```

```
template<class T> void g(T);
template<class T> void g(T&);
```

```
template<class T> void h(T&);
template<class T> void h(A<T>&);
```

```
void m() {
    const int p;
    f(p);                // f(const T*) is more specialized than f(T) or f(T*)
    float x;
    g(x);                // ambiguous: g(T) or g(T&)
    int* z;
    h(z);                // overload resolution selects h(A<T>&)
    const A<int> z2;
    h(z2);               // h(T&) is called; h(A<T>&) is not callable
}
```

+   - end example

Note: Since partial ordering in a class considers only parameters for which there are explicit call arguments, some parameters are ignored (namely, function parameters with default arguments, and ellipsis parameters). [Example]:

```
template<class T> void f(T);\          // #1
template<class T> void f(T*, int=1);     // #2
template<class T> void g(T);\           // #3
template<class T> void g(T*, ...);      // #4
```

```
int main() {
    int* ip;
    f(ip);                  // calls #2
    g(ip);                  // calls #4
}
```

+   - end example] [Example:

```
template<class T, class U> struct A { };
```

```
template<class T, class U> void f(U, A<U, T> p = 0);   // #1
template<class T, class U> void f(U, A<U, T> p = 0);   // #2
template<class T, class U> void g(T, T = T(0));          // #3
template<class T, class U> void g(T, U ...);           // #4
```

```
void h() {
    f<int>(42, A<int>(42));               // calls #2
    f<int>(42);                         // error: ambiguous
    g(42);                               // error: ambiguous
}
```

+   - end example] [Example:

```
template<class T, class...> U void f(T, U...); // #1
template<class T> void T;                            // #2
template<class T, class...> U void g(T*, U...);     // #3
```
