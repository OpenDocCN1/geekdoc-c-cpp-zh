```

1   Effects: Calls str.setf(ios_base::dec, ios_base::basefield);
2   Returns: str.
ios_base& hex(ios_base& str);
3   Effects: Calls str.setf(ios_base::hex, ios_base::basefield);
4   Returns: str.
ios_base& oct(ios_base& str);
5   Effects: Calls str.setf(ios_base::oct, ios_base::basefield);
6   Returns: str.
```

> 298) The function signature dec(ios_base&) can be called by the function signature basic_ostream stream::operator<<{(ios_base*) (ios_base)} to permit expressions of the form << dec to change the format flags stored in cout.
