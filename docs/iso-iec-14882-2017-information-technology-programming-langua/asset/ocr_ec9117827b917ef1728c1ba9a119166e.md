# 14.5 Access to virtual functions [class.access.virt]

The access rules (Clause 14) for a virtual function are determined by its declaration and are not affected by the rules for a function that later overrides it. [Example:

```
class B {
public:
    virtual int f();
};
class D : public B {
private:
    int f();
};
nvoid f() {
    D d;
    B* pb = &d;
    D* pd = &d;

pb->f();               // OK: B::f() is public, D::f() is invoked
pd->f();               // error: D::f() is private
}
-- end example]
```

Access is checked at the call point when the type of expression used to denote the object for which the member function is called (B* in the example above). The access of the member function in the class in which it was defined (D in the example above) is in general known.

# 14.6 Multiple access [class.paths]

If a name can be reached by several paths through a multiple inheritance graph, the access is that of the path that gives most access. [Example:

```
class W {
public: void f();
};
class A : private virtual W {};
class B : public virtual W { };
class C : public A, public B {
    void f();
};
// OK
```

Since W::f() is available to C::f() along the public path through B, access is allowed. -- end example]

# 14.7 Nested classes [class.access.nest]

A nested class is a member and has such the same access rights as any other member. The members of an enclosing class have no special access to members of a nested class; the usual access rules (Clause 1a) shall be obeyed. [Example:

```
class E {
    int x;
    class B { };
}
```
