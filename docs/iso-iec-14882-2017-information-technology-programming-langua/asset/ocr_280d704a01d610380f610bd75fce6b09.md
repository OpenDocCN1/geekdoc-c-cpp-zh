# 23.6.6 Relational operators [optional.relops]

```
template <class T, class constexpr bool operator==(const optional<T>& x, const optional<D>& y);
```

+   1 Requires: The expression x == *y shall be well-formed and its result shall be convertible to bool.
[Note: T need EqualityComparable. — end note]

+   2 Returns: If bool(x) != y, false; otherwise if bool(y) == false, otherwise x != *y.

+   3 Remarks: Specializations of this function for which *y is a constant expression shall be constexpr functions.

```
template <class T, class constexpr bool operator!const optional<T>& x, const optional<D>& y);
```

+   4 Requires: The expression x != *y shall be well-formed and its result shall be convertible to bool.

+   5 Returns: If bool(x) != y, false; otherwise if bool(y) == false, otherwise x != *y.

+   6 Remarks: Specializations of this function for which *y != is a constant expression shall be constexpr functions.

```
template <class T, class constexpr bool operator<(const optional<T>& x, const optional<D>& y);
```

+   7 Requires: The expression x < *y shall be well-formed and its result shall be convertible to bool.

+   8 Returns: If !y, false; otherwise !x, otherwise x < *y.

+   9 Remarks: Specializations of this function for which *x < y is a constant expression shall be constexpr functions.

```
template <class T, class constexpr bool operator<=(const optional<T>& x, const optional<D>& y);
```

+   10 Requires: The expression x <= *y shall be well-formed and its result shall be convertible to bool.

+   11 Returns: If !x, false; otherwise !y, true; otherwise x <= *y.

+   12 Remarks: Specializations of this function for which *x <= y is a constant expression shall be constexpr functions.

```
template <class T, class constexpr bool operator>=(const optional<T>& x, const optional<D>& y);
```

+   13 Requires: The expression x >= *y shall be well-formed and its result shall be convertible to bool.

+   14 Returns: If !x, true; otherwise !y, false; otherwise x >= *y.

+   15 Remarks: Specializations of this function for which *x >= y is a constant expression shall be constexpr functions.

```
template <class T, class constexpr bool operator==(const optional<T>& x, nullopt_t) noexcept;
```

+   16 Requires: The expression x == *y shall be well-formed and its result shall be convertible to bool.

+   17 Returns: If !y, true; otherwise !x, false; otherwise x == *y.

+   18 Remarks: Specializations of this function for which *x == y is a constant expression shall be constexpr functions.

# 23.6.7 Comparison with nullopt [optional.nullops]

```
template <class T> constexpr bool operator==(const optional<T>& x, nullopt_t) noexcept;
```

```
template <class T> constexpr bool operator==(nullopt_t, const optional<T>& x) noexcept;
```

+   1 Returns: !x.
