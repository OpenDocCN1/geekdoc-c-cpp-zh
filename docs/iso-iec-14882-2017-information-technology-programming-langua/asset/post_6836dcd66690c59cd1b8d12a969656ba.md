# 26.6 In Container adapters

```cpp
[container.adaptors]
```

The headers queue and stack contain the container adapters queue, priority_queue, and stack.

The container adapters take a Container template parameter, and each constructor takes a Container reference argument. This argument is copied into the Container member of each adapter. If the container takes an allocator, then a compatible allocator may be passed in the adapter's constructor. Otherwise, normal type or no construction is used for the container argument. The first template parameter T of the container adapters shall be the type as Container::value_type.

For container adapters, no swap function throws an exception unless that exception is thrown by the swap of the adapter's Container or Object (if any).

A deduction guide for a container adapter does not participate in overload resolution if any of the following are true:

- (4.1) It has an InputIterator parameter and a type that does not qualify as iterator is deduced for that parameter.
- (4.2) It has a Compare template parameter and a type that qualifies as allocator is deduced for that parameter.
- (4.3) It has a Container template parameter and a type that qualifies as allocator is deduced for that parameter.
- (4.4) It has an Allocator template parameter and a type that does not qualify as allocator is deduced for that parameter.
- (4.5) It has both Container and Allocator template parameters, and uses_allocator_v<Container, Allocator> is false.

# 26.6.4 Class template queue

# 26.6.4.1

Any sequence container operations front(), back(), push_back() and pop_front() can be used to instantiate queue. In particular, list (26.3.10) and deque (26.3.8) can be used.

```cpp
namespace std {
template<class T, class Container = deque<T>>
class queue {
public:
    using value_type = typename Container::value_type;
    using reference = typename Container::reference;
    using const_reference = typename Container::const_reference;
    using size_type = typename Container::size_type;
    using container_ = Container;

protected:
    Container c;

public:
    explicit queue(const Container& c);
    explicit queue(const Alloc& alloc) : Alloc();
    template<class Alloc> queue(const Alloc& alloc);
    template<class Alloc> queue(const Container& c, const Alloc& alloc);
    template<class Alloc> queue(Container&& __x, const Alloc& alloc);
    template<class Alloc> queue(Container&& __x, const Alloc& alloc);

    bool empty() { return c.empty(); }
    size_type size() { return c.size(); }
    reference front() { return c.front(); }
    const_reference front() { return c.front(); }
    reference back() { return c.back(); }
    const_reference back() { return c.back(); }
    void push(const T& x) { c.push_back(x); }
    void push(T&& x) { c.push_back(std::move(x)); }
    template<typename... Args>
    void emplace(Args&&... args) { c.emplace_back(std::forward<Args>(args)...); }
    void pop() { c.pop_front(); }
    void swap(queue& q) noexcept(is_swappable_v<Container>) {
        using std::swap; swap(c, q.c);
    }
};

template<class T>
queue<T>::queue() -> typename Container::value_type, const Container&;

template<class T>
queue<T>::operator=(const Container& c) -> typename Container::value_type, const Container&;
```
