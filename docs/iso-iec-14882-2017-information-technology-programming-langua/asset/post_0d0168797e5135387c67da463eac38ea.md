## 23.11.2.2 Class shared_ptr [util.smart.shared]

The shared_ptr class stores a pointer, usually obtained via new. shared_ptr implements semantics of ownership; the last remaining owner of the pointer is responsible for destroying the object, or otherwise releasing the resources associated with the stored pointer. A shared_ptr is said to be empty if it does not own a pointer.

Effects: Constructs an empty shared_ptr object.

Postconditions: use_count() == 0 && get() == nullptr.

```cpp
template<class T> explicit shared_ptr(T* p);
```

Requires: p shall be a pointer. The expression delete[] when T is an array type, delete p when T is not an array type, shall have well-defined behavior, and shall not throw.

Effects: When T is not an array type, it constructs a shared_ptr that owns the object p. If an exception is thrown, delete[] is called. 

Postconditions: use_count() == 1 && get() == p.

Throws: bad_alloc, or an implementation-defined exception when resource could not be obtained.

Remarks: When T is an array type, this constructor shall not participate in overload resolution unless the expression delete is well-formed and either T is U[N] or Y(*) is convertible to T*.

```cpp
template<class T, class D> shared_ptr(T* p, D);
template<class T, class D, class A> shared_ptr(T* p, D, A& a);
template<class T, class D, class A> shared_ptr(nullptr_t, D d, A& a);
```

Requires: construction of d with std::move(d) shall not throw. A shall be an allocator.
Effects: Constructs a shared_ptr that owns the object p and the deleter d. When T is not an array type, the first and second constructors shall use a copy of a for internal use. If an exception is thrown, delete(p) is called.

```cpp
template<class T> shared_ptr(const shared_ptr<T>& r, element_type* p) noexcept;
```

Effects: Constructs a shared_ptr that stores p and shares ownership with r.

Postconditions: get() == p && r.use_count() == r.use_count().

[Note: To avoid the possibility of a dangling pointer, this constructor should ensure that p remains valid until least the ownership group of r is destroyed.—end note].
