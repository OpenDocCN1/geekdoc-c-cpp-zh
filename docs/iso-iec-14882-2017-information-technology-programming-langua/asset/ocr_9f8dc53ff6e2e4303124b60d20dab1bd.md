# ISO/IEC 14882:2017(E)

# 26.4.5.3 multimap modifiers [multimap.modifiers]

```
template <class P> iterator insert(P& x);
template <class P> iterator insert(const_iterator position, P<P>(x);
```

> Effects: The first form is equivalent to return emplacement(std::forward<P>(x)); The second form is equivalent to return emplacement_hint(position, std::forward<P>(x)).

> Remarks: This signature shall not participate in overload resolution unless is_constructible_<value_type, P&> is.

# 26.4.5.4 multimap specialized algorithms [multimap.special]

```
template <class Key, class T, class Compare, class Allocator>
void swap(multimap<Key, T, Compare, Allocator>& x,
multimap<Key, T, Compare, Allocator>& y)
noexcept(x.swap(y));
```

> Effects: As if x.swap(y).

# 26.4.6 Class template [set]

# 26.4.6.1 Class template set overview [set.overview]

+   A is an associative container that supports unique keys (at most one of each key value) and provides fast retrieval of the keys. The set class supports bidirectional iterators.
B satisfies all of the requirements of, a reversible container (26.2), of an associative container (26.6), and of an allocator-aware container (Table 86). A set also provides operations described in 26.2.6 for unique keys. A set that supports the a_uniq operations in 26.2.6 but not the a_eq operations. For a set<Key> the key and value_type are Key. Descriptions are provided only for operations that are not described in these and for operations where there is additional semantic information.

```
template <class Key, class Compare = less<Key,
                               Allocator = allocator<Key>>
class set {
public:
  // types:
  using key_type = Key;
  using key_compare = Compare;
  using value_type = Key;
  using allocator = Allocator;
  using pointer = typename allocator_traits<Allocator>::pointer;
  using const_pointer = typename allocator_traits<Allocator>::const_pointer;
  using reference = value_type&;
  using const_reference = const value_type&;
  using size_type = implementation_defined; // see 26.2
  using difference_type = implementation_defined; // see 26.2
  using iterator = implementation_defined; // see 26.2
  using const_iterator = implementation_defined; // see 26.2
  using reverse_iterator = std::reverse_iterator<iterator>;
  using const_reverse_iterator = std::reverse_iterator<const_iterator>;
  using node_type = unspecified;
  using insert_return_type = INSERT_RET_TYPE, node_type>;
```
