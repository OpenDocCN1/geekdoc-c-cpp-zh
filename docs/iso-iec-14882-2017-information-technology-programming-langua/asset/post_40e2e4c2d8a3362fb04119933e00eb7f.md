- 1 Requires: The source and [first, last] sequences are UTF-8 encoded. The value type of Source and Iterator is char.
- (2.1) If value_type is char and the current narrow encoding (30.10.4) is UTF-8, return path(source) or path(first); otherwise;
- (2.2) If value_type is wchar and the native wide encoding is UTF-16, or if value_type is char6_t or char32_t, convert source from [first, last) to a temporary, tmp. of type string_type and return path(tmp);
- (2.3) convert source from [first, last) to a temporary, tmp, of type u32string and return path(tmp).

Remarks: Argument format (30.10.8.2) applies to the arguments for these functions. Unicode encoding conversions are unspecified.

Example: A string to be read from a database that is encoded in UTF-8, and to create a directory using the native encoding for filenames:
```cpp
namespace fs = std::filesystem;
std::string utf8_string = read_utf8_data();
fs::create_directory(fs::u8path(utf8_string));
```

For POSIX-based operating systems with the native narrow encoding set to UTF-8, no encoding or type conversion occurs.
For POSIX-based operating systems with the native narrow encoding not set to UTF-8, a conversion to UTF-32 occurs, followed by a conversion to the current narrow encoding. Some Unicode characters have no native character representation.
For Windows-based operating systems a conversion from UTF-8 to UTF-16 occurs. — end example]
