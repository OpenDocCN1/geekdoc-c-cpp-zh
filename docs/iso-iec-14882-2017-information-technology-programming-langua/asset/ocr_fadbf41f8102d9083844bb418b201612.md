# 11.6.2 Character arrays

An array of char type (6.9.1), char16_t array, char32_t array, or wchar_t array can be initialized by a string literal, char16_t string literal, char32_t string literal, or wide string literal, respectively, or by an appropriately-typed string literal enclosed in braces (5.1.3). Successive characters of the string literal initialize the elements of the array. [Example:

```
char msg[] = "Syntax error on line \n";
```

show how array members are initialized with a string-literal. Note that '\n' is a single character and a trailing '\0' is appended, sizeof(msg) is 25. — end example
