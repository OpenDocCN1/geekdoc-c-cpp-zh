- 11 Each enum-name and each enumerator is declared in the scope that immediately contains the enum-specifier. The scope rules define all names in 6.3 and 6.4. Example:

```cpp
enum direction {left='l', right='r'};
void g() {
    direction d; // OK
    d = left; // OK
    d = direction::right; // OK
}
```

```cpp
void h(altitude='h', low='l') {
    altitude a;
    a = high; // error: high not in scope
    a = altitude::low; // OK
}
```

An enumerator declared in the scope can be referred to using the class member operators (::, (dot) and (arrow)), see 8.2.5. Example:

```cpp
struct X {
    enum direction {left='l', right='r'};
    int f(int i) return i=left ? 0 : i=right ? 2;
};
```

```cpp
void g(X* p) {
    direction d; // error: direction not in scope
    int i;
    i = p->left(left); // error: left not in scope
    i = p->X(right); // OK
    i = p->f(p->left); // ...
}
```

## 10.3 Namespaces [basic.namespace]

- 1 A namespace is an optionally-named declaration region. The name of a namespace can be used to access entities declared in that namespace; that is, the members of the namespace. Unlike other declarative regions, the definition of a namespace can be split over several parts of one or more translation units.

- 2 The outermost declarative region of a translation unit is a namespace; see 6.6.6.

### 10.3.1 Namespace definition [namespace.def]

```cpp
namespace-name:
identifier
namespace-alias
namespace-definition:
  named-namespace-definition
  unnamed-namespace-definition
unnamed-namespace-definition:
  named-namespace-definition:
    inline_opt namespace attribute-spec_opt identifier { namespace-body }
  unnamed-namespace-definition:
    inline_opt namespace attribute-spec_opt { namespace-body }
  nested-namespace-definition:
    namespace-enclosing-namespace-specification :: identifier { namespace-body }
enclosing-namespace-specification:
  identifier
namespace-body:
  declaration-seq_opt
```

- 1 Every namespace-definition shall appear in the global scope or in a namespace scope (6.3.6). The identifier is the name of the namespace. If the identifier, when looked up (6.4.1), refers to a namespace-name (but not a namespace-alias) that was introduced in a member of a namespace set of that namespace, the namespace-definition extends the previously-declared namespace. Otherwise, the identifier is introduced as a namespace-name into the declarative region in which the named-namespace-definition appears.

- 3 Because a namespace-definition contains declarations in its namespace-body and a namespace-definition is itself a declaration, it follows that namespace-definitions can be nested. Example:

```cpp
namespace Outer {
    int i;
    namespace Inner {
        void i() { i++; } // Outer::i
        int i;
        void i() { i++; } // Inner::i
    }
}
```
