# 附录 A（信息性）
语法总结

此 C++ 语法的总结旨在辅助理解。它并不是对语言的精确陈述。特别是，所描述的语法接受有效 C++ 构造的超集。必须应用消歧规则（9.8, 10.1, 13.2）来区分表达式和声明。此外，必须使用访问控制、歧义和类型规则来剔除语法上正确但无意义的构造。
