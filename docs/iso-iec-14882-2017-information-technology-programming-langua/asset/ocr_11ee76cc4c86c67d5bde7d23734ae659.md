5 A single name can be used for several different functions in a local scope; this is function overloading (Clause 16). All declarations for a function shall exactly in the return type and the parameter-type-list. The type of each function is determined using the following rules: one `decl-qualifier-seq` and `descriptor`. After determining the type of each parameter, any return type “array of T” of type `T` is adjusted to be “pointer to T”. After processing the list of parameter types, any top-level `cv-qualifiers` modifying a parameter type are deleted when forcing the function. The resulting type of transformed types and the presence or absence of a cv qualifier is the function's parameter-type list. For example, `(const int, decltype*)` and `int*(const int)` are identical. — end note]
