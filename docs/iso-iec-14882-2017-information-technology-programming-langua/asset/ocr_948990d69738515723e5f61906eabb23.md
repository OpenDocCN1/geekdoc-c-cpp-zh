# ISO/IEC 14882:2017(E)

# 17.8.2 Template argument deduction [temp,deduct]

1 When a function template specialization is referenced, all of the template arguments shall have values. 
The values can be explicitly specified, or in some cases, they be deduced from the use or obtained from default template-arguments. Example:

```
void f(Array<complex<>> cv, Array<int>& ci) { // calls sort(Array<complex<>>&)
	sort(cv);
	sort(ci); // calls sort(Array<int>&)
}

void g(double d) {
	int i = convert<int>(d); // calls convert<int,double>(double)
	char c = convert<char>(d); // calls convert<char,double>(double)
}
// end example
```

2 When an explicit template argument is listed, if the template arguments are not compatible with the template parameter list or do not result in a value type as described below, type deduction fails. Specifically, the following steps are performed when evaluating an explicitly specified template argument list with respect to a given function:
(2.1) If the specified template arguments do not match the template parameters in kind (i.e., type, non-type, template), or if there are more arguments than parameters and no argument for each non-pack parameter, type deduction fails.
(2.2) If any non-type argument does not match the type of the corresponding non-type parameter, and is not convertible to the type of the corresponding non-type parameter as specified in 17.3.2, deduction fails.
(2.3) The specified template argument values are substituted for the corresponding template parameters as specified below.

3 After this substitution is performed, the function type adjustments described in 11.3.5 are performed. [Example: A parameter type of “void (const int, int[5])” becomes “void(*)(int,int*)”] — [Note: A top-level qualifier in a function parameter declaration does not affect the function type but affects the type of the function parameter variable within the function. — end note] | Example:

```
template <class T> void f(T T);
template <class X> void g(const X X);
template <class Z> void h(Z, Z);
```

```
int main() {
// // 1: function type is f(int), t is const
f<int>(1);

// // 2: function type is f(int), t is const
const int(1);

// // 3: function type is g(int), x is const
g<int>(1);

h<const int>(1,0);
```
