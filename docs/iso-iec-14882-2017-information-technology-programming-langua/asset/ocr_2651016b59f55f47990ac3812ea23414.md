9 Each init-declarator in the init-declarator-list contains exactly one declarator-id, which is the name declared by that init-declarator and one of the names declared by the declaration. 10 If the decl-spec-seq contains the typedef-spec, the declaration is declared to be a typedef-name, and the name of each init-declarator is synonymous with its associated type (10.1.3).
