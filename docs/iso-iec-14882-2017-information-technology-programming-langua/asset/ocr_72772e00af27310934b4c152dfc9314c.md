# ISO/IEC 14882:2017(E)

```
template <class charT, class traits>
    void swap(basic_fstream<charT, traits>& x,
             basic_fstream<charT, traits>& y);

```

1 The template `basic_fstream<charT, traits>` supports reading and writing from files. It uses a `basic_filebuf<charT, traits>` object to control the associated sequences. For the sake of exposition, the maintained data is presented here:

+   (1.1) — `sb`, `basic_filebuf` object.

# 30.9.5.1 basic_fstream constructors [fstream.assign]

```
basic_fstream(
    const char& s,
    ios_base::openmode mode = ios_base::in | ios_base::out);
nexplicit basic_fstream(
    const filesystem::path& value_type s,
    ios_base::openmode mode = ios_base::in | ios_base::out);

```

2 Effects: Constructs an object of base class `basic_fstream<charT, traits>`, initializing the base class with `basic_istream<charT, traits>(&ksb)` (30.7.4.6.1) and initializing `sb` with `basic_filebuf<charT, traits>()`.

```
explicit basic_fstream(
    const string& s,
    ios_base::openmode mode = ios_base::in | ios_base::out);
explicit basic_fstream(
    const filesystem::path& p,
    ios_base::openmode mode = ios_base::in | ios_base::out);

```

2 Effects: The same as `basic_fstream(s.c_str(), mode)`. If it returns a null pointer, calls `setstate(failbit)`.

3 Effects: The same as `basic_fstream(&rhs)`.

4 Effects: Moves from the rvalue `rhs`. This is accomplished by moving the base class, and the contained `basic_filebuf`. Next `basic_istream<charT, traits>::setdbuf(&rhs)` is called to install the contained `basic_filebuf`.

# 30.9.5.2 Assign and swap [fstream.assign]

```
basic_fstream& operator=(basic_fstream&& rhs);
```

1 Effects: Assigns the base and members of `*this` from the base and corresponding members of `rhs`.

2 Returns: `*this`.

```
void swap(basic_fstream&& rhs);
```

3 Effects: Exchanges the state of `*this` and `rhs` by calling `basic_istream<charT, traits>::swap(rhs)` and `sb.swap(rhs.sb).
