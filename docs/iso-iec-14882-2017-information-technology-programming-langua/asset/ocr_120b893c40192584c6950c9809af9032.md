runtime_error(const string& what_arg);

+   Effects: Constructs an object of class runtime_error.

+   Postconditions: strcmp(what(), what_arg.c_str()) == 0.

+   Effects: Constructs an object of class runtime_error.

+   Postconditions: strcmp(what(), what_arg) == 0.
