## 29.6.4.3 Class template independent_bits_engine [rand.adapt.libits]

1 An independent_bits_engine random engine adaptor copies random numbers that are produced by some engine e, to produce random numbers with a specific number of bits w. The state x, of an independent_bits_engine adapter object copies of the state e, of its base engine e; the size of the state is the size of e's.

2 The transition and generation algorithms are described in terms of the following integral integral constants:
a) R=max(e) - e.min(e)
b) With w as determined below, let w0=[w/n], n0=n - w mod n, y0=2^w[R/2^w], and y1=2^w[R/2^w]+1
c) Let m=[w/|y|] if and only if the relation R <=|y| holds as a result. Otherwise let n=1+[w/m].

> Note: The relation w=w0*n+(n mod w0) always holds. — end note.

3 The transition algorithm is called by invoking (e) as needed to obtain n0 values less than y0+e.min(e) and n-values less than y1+e.min(e).
4 The generation algorithm uses the values produced while advancing the state as described to yield a quantity S as obtained by the following algorithm:

```cpp
S=0;
for (k=0; k!=n0; k++) {
  tu=e()-e.min(u); while (u >= y0);
  sS=2^w+u mod 2^w;
}
for (k=n0; k!=n; k++) {
  tu=e()-e.min(u); while (u >= y1);
  sS=2^{w+1}+u mod 2^{w+1};
}
```

## 29.6.4.4 Class template shuffle_order_engine

1 A shuffle_order_engine random number engine adapter produces the random numbers that are produced by some base engine, but delivers them in a different sequence. The state x, of a shuffle-order-engine object x consists of state e, of its base engine, and an additional value Y of the delivered by e, and an additional sequence V of k values of the delivered by e. The size of the state is of e's state k+1.

2 The transition algorithm performs the values produced by e. The state transition is performed as:

a) Calculate an integer j = $\frac{i-1}{\text{size\_of\_e}+1}$

b) Set Y to V_j and set V_i to e.

3 The generation algorithm yields the value Y produced while advancing e's state as described.

## 29.6.6 Class random_device [rand.device]

1 A random_device uniform random generator produces nondeterministic random numbers.

2 If implementation limits prevent generating nondeterministic random numbers, the implementation may employ a random number.

```cpp
class random_device {
public:
  // types

  // constructors
  explicit random_device(const string& token = implementation-defined);

  // generating functions
  result_type operator()();

  // property functions
  double entropy() const noexcept;

  // no copy functions
  random_device(const random_device&) = delete;
  void& operator=(const random_device&) = delete;
};
```

3 Effects: Constructs a random_device nondeterministic uniform random generator. The semantics and default value of the token are implementation-defined.
