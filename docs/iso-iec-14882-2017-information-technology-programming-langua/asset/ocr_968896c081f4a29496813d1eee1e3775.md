> Effects: Characters are converted to the format specified by a moneyput<charT, Intl> facet
reference and the character mapping by a type<char> facet reference obtained from
t locale retrieved by get_facet(str).flags(). The argument is transformed into a
sequence of characters if it has
ct.widen(bufi, bufi + sprint(buf, buf2)
for character buffers if the first character in digits or buf2 is equal to ct.widen('-').
then the pattern used is the result of mp.neg_format(); otherwise the pattern is
of mp.pos_format(); Digit characters are written, with thousands separators and
decimal point specified by the format. They appear (after the optional leading sign)
digits or buf2. In digits, the optional leading sign (including digits
a non-digit character) is added last.

> Remarks: The currency symbol is generated if and only if (str.flags() & str.showbase) is nonzero.
If the number of characters generated for the specified format is less than the value returned by
str.width() on the entry, then copies of fill are necessary to pad the speci-
width. For the value equal to (str.flags() & str.adjustfield), if (af == str.integral)
true, the fill characters are placed where none or space appears in the formatting pattern; otherwise
if (af == str.left) is true they are placed after the other characters; they are placed
before the other characters. [Note: It is possible, with some combinations of format pattern and flag
values, to produce output that is not parsed using money_get<>:: end note]
