# ISO/IEC 14882:2017(E)

Alters the stream position within one of the controlled sequences, if possible, to correspond to the stream position stored in sp (as described below).

+   - If (which & ios::in) != 0, positions the input sequence.

+   - If (which & ios::out) != 0, positions the output sequence.

+   - If the function positions neither sequence, the positioning operation fails.

For a sequence to be positioned, if its next is a null pointer, the positioning operation fails. Otherwise, the function determines newpos from sp.offset():

+   - If newoff adds an invalid stream, has a negative value, or a value greater than (seekhigh - seeklow), the positioning operation fails

+   - Otherwise, the function adds to the positioning pointer xbeg and stores the result in the next pointer nnext.

Returns pos_type(newoff), constructed from the resultant off newoff (of type off_type), that stores the stream position, if possible. If the positioning operation fails, or if the object cannot represent the stream position, the function returns pos_type(off_type(-1)).

```
streambuf<char>(char* s, size_t n) override;
```

Implementation defined, except thatA(0), has no effect.

# D.6.2 Class istream

```
namespace std {
class istream : public basic_istream<char> {
public:
    explicit istream(const char* s);
    explicit istream(char* s);
    istream(const char* s, size_t n);
    istream(char* s, size_t n);
    virtual streambuf* rdbuf() const;
    char* str();
    char* str();
private:
    streambuf sb; // exposition only
};
```

The class istream supports the reading of objects class streambuf. It supplies a streambuf object to control the associated array object. For the sake of exposition, the maintained data is presented here:

+   - sb, the streambuf object.
