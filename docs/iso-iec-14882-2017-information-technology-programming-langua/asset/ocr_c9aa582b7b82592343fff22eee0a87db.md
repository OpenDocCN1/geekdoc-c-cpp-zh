# ISO/IEC 14882:2017(E)

# 23.19.5 Parallel execution policy [exececpol.par]

```
class execution::parallel_policy { unspecified };
```

+   1 The class execution::parallel_policy is an execution policy type used as a unique type to disambiguate parallel algorithm overloading and indicate that a parallel algorithm's execution may be parallelized and vectorized.

+   2 During the execution of a parallel algorithm with the execution::parallel_policy policy, if the invocation of an element access function exists via an uncaught exception, terminate() shall be called.
