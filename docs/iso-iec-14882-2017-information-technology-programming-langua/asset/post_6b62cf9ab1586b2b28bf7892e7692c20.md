# 29.6.3.2 Class mersenne_twister_engine [rand.eng,mers]

1 A *mersenne_twister_engine* random number engine $w$ produces unsigned integer numbers in the closed interval $[0, 2^w-1]$. The state $x$ of a *mersenne_twister_engine* is of size $n$ and consists of a sequence $X$ of $n$ values of the type given by: all subscribers to $X$ are to be taken $m$.

2 The transition algorithm employs a twisted feedback shift register defined by shift values $n$ and $m$, a twist value $r$, and a conditional mask $a$. To improve the uniformity of the result, the shift register is additionally temporarily (i.e., scrambled) according to a bit matrix defined by values $u, d, a, b, c,$ and $t$.

The transition performs the upper $w-r$ bits of $x_i$ with the lower $r$ bits of $x_{i+1}$ to obtain an unsigned integer value $Y$.

a Concatenate $w \cdot (Y \oplus a)$, set $x_{i+1}$ to $x_i \oplus (Y \ll r) \oplus \alpha$. The sequence $X$ is initialized with the help of an initialization multiplier $f$.

3 The algorithm determines the unsigned integer values $z_1, z_2, z_3, z_4$ as follows, delivers $z_4$ as its result:

a $z_1 = x_1 \xor (x_1 \ll u) \text{ and } b$.
b $z_2 = z_1 \xor (z_1 \ll w) \text{ and } b$.
c $z_3 = z_2 \xor (z_2 \ll s) \text{ and } c$.
b $d_4 = z_3 \xor (z_3 \ll r) \text{ and } f$.

# 29.6.3.3 Class subtract_with_engine [rand.eng.sub]

1 A subtract_with_engine random engine produces numbers using integer numbers. The state of a subtract_with_engine object $x$ is size $O(n)$, and consists of a sequence $X$ of $r$ integers $0 \le x < 2^w$; all subscriptions to $X$ are modulo $r$. The state also consists of an additional integer $c$ (the carry) whose value is 0 or 1.

2 The transition is performed as:

a) Let $Y_i = X_{i-1} - c$.
b) Set $X_i = Y_i \pmod m$. Set $c$ to 1 if $Y_i < 0$, otherwise set $c$ to 0.

Note: This algorithm corresponds to linear congruential generator of the form $TA(x) = (a \cdot x) \pmod b$, where $b$ is of form $m \cdot 2^a$ and $a = (b-1)/m$.

3 The algorithm is given by $GA(x) = y$, where $y$ is the value produced as result of advancing the engine's state as described above.
