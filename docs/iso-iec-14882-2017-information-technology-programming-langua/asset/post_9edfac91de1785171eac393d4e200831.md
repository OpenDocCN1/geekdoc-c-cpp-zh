## 26.3.9.2 forward_list constructors, copy, assignment [forward_list.cons]

```cpp
explicit forward_list(const Allocator& alloc);
```

- Effects: Creates an empty forward_list object using the specified allocator.
- Complexity: Constant.

```cpp
explicit forward_list(size_type n, const Allocator& = Allocator());
```
- Effects: Constructs a forward_list object with n default-inserted elements using the specified allocator.
- Requires: T shall be DefaultInsertable into *this.
- Complexity: Linear in n.

```cpp
forward_list(size_type n, const T& value, const Allocator& = Allocator());
```
- Effects: Constructs a forward_list object with n copies of value using the specified allocator.
- Requires: T shall be Copyable into *this.
- Complexity: Linear in n.

```cpp
template<class InputIterator>
forward_list(InputIterator first, InputIterator last, const Allocator& = Allocator());
```
- Effects: Constructs a forward_list object equal to the range [first, last].
- Complexity: Linear in distance(first, last).

## 26.3.9 forward_list iterators

```cpp
iterator forward_begin() noexcept;
const_iterator forward_begin() noexcept;
const_iterator before_begin() noexcept;
```

- Returns: A non-dereferencable iterator that, when incremented, is equal to the iterator returned by begin().
- Effects: cbefore_begin() is equivalent to const_cast<forward_list<const T>&>(this).before_begin().
- Returns: before_begin() == end() shall evaluate false.

## 26.3.9.5 forward_list modifiers

The order of insert_after shall affect the validity of iterators and references, and erase_after shall invalidate all iterators and references to the erased elements. If an exception is thrown during insert_after there will be no effect. Inserting elements into a forward_list is linear in n, and the number of calls to the copy or move constructor of T is exactly to n. Erasing n elements from a forward_list is linear in n and the number of calls to the destructor of type T is exactly to n.

```cpp

```
- Requires: position is before_begin or a dereferencable iterator in the range [begin(), end()).

- Returns: An iterator pointing to the x.


- Returns: An iterator pointing to the last inserted element or position.
