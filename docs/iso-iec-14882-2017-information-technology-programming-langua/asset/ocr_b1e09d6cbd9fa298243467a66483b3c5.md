6 To zero-initialize an object or reference of type T means:

```
(6.1) if T is a scalar type (6.9), the object is initialized to the value obtained by converting the literal
(0) to type of T;
```

```
(6.2) if T is a (possibly cv-qualified) non-class type, each non-static data member, each non-virtual
base subclass, and if the object is not a base class subclass, each virtual base class subclass
zero-initialized and padding is initialized to zero bits;
```

```
(6.3) if T is a (possibly cv-qualified) type, the object’s first-static named data member is zero-
initialized and padding is initialized to zero bits;
```

```
(6.4) if T is an array type, each element is zero-initialized;
```

```
(6.5) if T is a reference type, no initialization is performed.
```

7 To default-initialize an object of type T means:

```
(7.1) if T is a (possibly cv-qualified) class type (Clause 12), constructors are considered. The applicable
constructors are enumerated (16.3.1,3), and the first for the initializer () is chosen through overload
resolution (16.3). This constructor then is called, with an empty argument list, to initialize the
object;
```

```
(7.2) if T is an array type, each element is default-initialized.
```

```
(7.3) otherwise, no initialization is performed.
```

A class T is const-constructible if default-initialization of T would invoke a user-provided
constructor of T (not inherited from a base class) or if

```
(7.4) each non-static data member of T has a default member initializer, or if M is of
class type X (or array), then T is const-constructible;
```

```
(7.5) if T is a union with at least one non-static data member, each variant member has a default
initializer;
```

```
(7.6) if T is not, for each anonymous union member with at least one non-static data member (if
ay), each potentially constructed base class of T is const-default-constructible.
```

If a program calls for the default-initialization of an object of a const-qualified type T, T shall be a const-
default-constructible class type or array.

8 To value-initialize an object of type T means:

```
(8.1) if T is a (possibly cv-qualified) class type (Clause 12) with no default constructor (15.1) or
default constructor is deleted, then the object is value-initialized;
```

```
(8.2) if T is a (possibly cv-qualified) class type without a user-provided or deleted constructor, then
the object is zero-initialized and the semantic constraints for default-initialization are checked, and if T
h a non-trivial default constructor, the object is value-initialized;
```

```
(8.3) if T is an array type, each element is value-initialized;
```

```
(8.4) otherwise, the object is zero-initialized.
```
