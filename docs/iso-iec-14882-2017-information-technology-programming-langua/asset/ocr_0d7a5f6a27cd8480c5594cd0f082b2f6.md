# ISO/IEC 14882:2017(E)

# 30.2 iostreams requirements [iostream.requirements]

# 30.2.1 Imbue imhabitations [iostream.limits.imbue]

1 No function declared in Clause 30 except for ios_base::imbue and basic_filebuf::pubimbue causes any instance of basic_ios::imbue or basic_streambuf:: to be called. If any user function from a class declared in Clause 30 or as other defined virtual function calls any class 30 imbue, the behavior is undefined.

# 30.2.2 Positioning type limitations [iostream.limits.pos]

+   1 The Classes of Clause 30 with template charT and traits behave as described if traits:pos_ and type:off_type are streream and stream respectively. Except as noted explicitly, their behavior when traits:pos and type:off are other types is implementation-defined.
2 In the Classes of Clause 30, a template parameter with name charT represents a member of the set of types containing char, wchar_t, and any other implementation-defined character types that satisfies the requirements for a character on which the stream components can be instantiated.

# 30.2.3 Thread safety [iostream.threadsafety]

+   1 Concurrent access to a stream object (30.8, 30.9), stream buffer (30.6) or C Library stream (30.11) by multiple threads results in a data race (4.7) unless otherwise specified (30.4). [Note: Data race result in undefined behavior (4.7)-- end note
2 If one thread makes a call to a stream that writes a value to a stream, and as another thread results in the value from the stream through a library call b to sync that this does not result in a data race, then a's write synchronizes with b's.
