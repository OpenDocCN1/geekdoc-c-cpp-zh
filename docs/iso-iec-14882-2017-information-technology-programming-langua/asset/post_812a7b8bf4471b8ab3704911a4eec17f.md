
# ISO/IEC 14882:2017(E)

## 30.7.4.5 Rvalue stream extraction [iostream.rvalue]

```cpp
template <class charT, traits, class T>
basic_istream<charT, traits>& operator>>=(basic_istream<charT, traits>& is, T&& x);
```

Effects: Equivalent to:

```
is >> std::forward<T>(x);
return is;
```

Remarks: This function shall not participate in overload resolution unless the expression `is >> std::forward<T>(x)` is well-formed.

## 30.7.4.6 Class template basic_iostream [iostream.class]

```cpp
namespace std {
template <class charT, traits = char_traits<charT>>
class basic_iostream<charT, traits>
: public basic_istream<charT, traits>
    , public basic_ostream<charT, traits> {
public:
    using char_type = charT;
    using int_type = typename traits::int_type;
    using pos_type = typename traits::pos_type;
    using off_type = typename traits::off_type;
    using traits_type = traits;
```

```cpp

```

```cpp

```

```cpp

// 30.7.4.6.3. copy

```

```cpp

basic_iostream& operator=(basic_iostream&& rhs);
void swap(basic_iostream& rhs);
};
```

The class template basic_iostream inherits a number of functions that allow reading input and output to sequences generated by a stream buffer.

### 30.7.4.6.1. basic_iostream constructors [iostream.const]

```cpp
explicit basic_iostream(basic_streambuf<charT, traits>* sb);
```

Effects: Constructs an object of class basic_iostream, initializing the base class subclasses with basic_istream<charT, traits>(sb) (30.7.4.1) and basic_ostream<charT, traits>(sb) (30.7.5.1).

Postconditions: rdbuf() == sb and count() == 0.

```cpp
basic_iostream(basic_iostream&& rhs);
```

Effects: Move objects from the rvalue rhs by constructing the basic_istream base class with move(rhs).

## 30.7.4.6.2 basic_iostream destructor

```cpp
virtual ~basic_iostream();
```

Effects: Destroys an object of class basic_iostream.
Remarks: Does not perform any operations on rdbuf.

## 30.7.4.6.3 basic_iostream assign and swap

```cpp
basic_iostream& operator=(basic_iostream&& rhs);
```

Effects: As if swap(rhs).

```cpp
void swap(basic_iostream& lhs, traits& rhs);
```

Effects: Calls basic_iostream<charT, traits>::swap(rhs).

# ISO/IEC 14882:2017(E)

1 The class template basic_ostream defines a number of function signatures that assist in formatting and writing output to a stream buffer.

2 Two groups of function signatures share common properties: the formatted output functions (inserters) and unformatted output functions. Both groups generate (or insert) characters by calling rdbuf(). They may use other public members of basic_ostream except that rdbuf()->overflow(), xsputn(), and sync().

3 If one of these called functions throws an exception, unless explicitly noted the output function sets badbit in error state. If badbit is in exceptions(), the output function catches without completing its actions, which does not throw and returns an error.

## 30.7.5.1 basic_ostream constructors

```cpp
explicit basic_ostream(basic_streambuf<charT, traits>* sb = nullptr);
```

Effects: Constructs an object of basic_ostream, initializing the base class object with basic_ios<charT, traits>::init(bitset) (30.5.5.2).
Postconditions: rdbuf() == sb.

```cpp
basic_ostream(basic_ostream& rhs);
```

Effects: Moves from the rhs. This is achieved by default-construction the base class and calling basic_ios<charT, traits>::move(rhs).

```cpp
virtual ~basic_ostream();
```

Effects: Destroys an object of class basic_ostream.
Remarks: Does not perform any operations on rdbuf.

## 30.7.5.2 basic_ostream assign and swap

```cpp
basic_ostream& operator=(basic_ostream& rhs);
```

Effects: As if swap(rhs).
Returns: *this.

```cpp
void swap(basic_ostream& rhs);
```

Effects: Calls basic_ios<charT, traits>::swap(rhs).
