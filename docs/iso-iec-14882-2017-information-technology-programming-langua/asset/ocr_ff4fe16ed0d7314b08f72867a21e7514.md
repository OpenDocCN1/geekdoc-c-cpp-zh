# ISO/IEC 14882:2017(E)

1 The template bitset<N> describes a sequence consisting of a fixed number of bits, N.

2 Each bit represents either value zero (reset) or one (set). To toggle a bit is to change the value zero to one, or one to zero. Each bit has a non-negative position. When converting an object of class bitset and a value of some integral, bit position pos corresponds to the bit value 1 << pos. The integral value corresponding to two or more bits is the sum of their bits.

3 The functions described in this subclass can report three kinds of errors, each associated with a distinct exception:

+   (3.1) an invalid-argument error is associated with exceptions of type invalid_argument (22.2:4);

+   (3.2) an out-of-range error is associated with exceptions of type out_of_range (22.2:6);

+   (3.3) an overflow error is associated with exceptions of type overflow_error (22.2:9).

# 23.9.2.1 bitset constructors [bitset.cons]

```
const bitset bitset();
```

1 Effects: Constructs an object of class bitset, initializing all bits to zero.

```
const bitset(unsigned long long val);
```

2 Effects: Constructs an object of class bitset, initializing the first M bits to the corresponding bit values in val. M is the smaller of N and the number of bits in the value representation (6.9) of unsigned long long. If M < N, the remaining bits are initialized to zero.

```
template <charT, class traits, class Allocator>
explicit bitset(
const basic_string<charT, traits, Allocator>& str,
ntypename basic_string<charT, traits, Allocator>::size_type pos = 0,
= basic_string<charT, traits, Allocator>::npos,
char zero = charT('0'),
char one = charT('1'));
```

3 Throws: out_of_range if pos > str.size() or invalid_argument if an invalid character is found (see below).

4 Effects: Determines the effective length rlen of the initializing string as the smaller of n and str.size() - pos if pos is other than zero.
The function then invalid_argument if any rlen characters in str beginning at position pos is other than zero. The function uses traits::eq() to compare the characters.

Otherwise, the constructed object has class bitset if the character in str, beginning at position pos, is zero. Otherwise, the element has the value one. Character position pos + M - 1 corresponds to bit position. Subsequent decreasing positions correspond to increasing bit positions.

5 If M < N, remaining bits are initialized to zero.

explicit bitset(
const basic_string<charT>& str,
typename basic_string<charT>::size_type n = basic_string<charT>::npos,
char zero = charT('0'));
