```

path extension() const;

- + Returns: a path whose pathname in generic format is the suffix of filename() not included in stem.

```
[Example]:
path("foo/bar.txt").extension(); // yields "txt" and stem() is "bar"
path("foo/bar.tar").extension(); // yields "tar" and stem() is "bar"

# 30.10.8 iterators [fs.path.iter]

- 1 Iterators iterate over the pathname in the generic format (30.10.8.1).
- 2 path::iterator satisfies all the requirements of a bidirectional iterator (27.2.6) except, for dereferenceable iterators and b of type path::iterator ==, there is no requirement that a and b are bound to the same object. Its value_type is path.
- 3 Calling any non-const member of path object invalidates all iterators referring to elements of that object.
- 4 For the elements of pathname in the generic format, the forward traversal order is as follows:
    - The root-name element, if present.
    - The root-directory element, if present. [Note: The generic format is required to ensure lexicographical comparison works. — end note]
    - Each successive filename, if present.
    - An empty element, if a trailing non-root directory-separator is present.
- 5 The backward traversal order is the reverse of forward traversal.

```
iterator begin() const;
Returns: An iterator for the first element in the traversal above. If no elements are present, the end iterator.
iterator end() const;
Returns: The iterator.
```

> Note: Path equality and path value have different semantics.

- (8.1) Equality is determined by the path non-operator==, which considers the path's lexical representations. [Example: path"foo" = "bar" is never true. — example]

- (8.2) Equivalence is determined by the equivalent() non-member function, which determines if two paths resolve to the same file. [Example: equivalent("foo", "bar") will be true if both paths resolve to the same file. — example]

Programmers wishing to determine if two paths are the "same" must decide if "the same" means the "same representation" or "resolve to the same file", and choose the appropriate function accordingly.
