# ISO/IEC 14882:2017(E)

8 If a substitution results in an invalid type or expression, type deduction fails. An invalid type or expression is one that will be ill-formed, with a diagnostic required, if using the substituted arguments. [Note: If no diagnostic is required, the program is ill-formed. Access checking is part of the substitution process.—end note] Only invalid types and expressions in the immediate context of the function and its template parameters can result in a deduction failure. [Note: The substitution into types and expressions can result in effects such as the instantiation of class template specializations and/or function template specializations, the generation of implicitly-defined functions, etc. Such effects are not in the immediate context” and can result in the program being ill-formed.—end note]

[Example:

```
struct X { };
struct {
    X(int)
};

template <class T> auto f(T t1, T t2) -> decltype(t1 + t2); // #1
X(Y, Y); // #2

X x1, x2;
X3 = f(x1, x2); // deduction fails on #1 (cannot add X*X), calls #2
—end example]
```

[Note: Type deduction may fail for the following reasons:

+   (8.1) Attempting to instantiate a pack expansion containing multiple parameter packs of different lengths.
(8.2) Attempting to create an array with an element that is void, a function type, a reference type, or an abstract class type, or attempting to create an array with a size that is zero or negative. [Example:
template <T> int f(T*);
 i = f<int>(0);
int j = f<void>(0); // invalid array
—end example]

+   (8.3) Attempting to use a type that is not a class or enumeration in a qualified name. a qualified name. [Example:
template <class T> int f(typename T::B*);
int i = f<int>(0);
—end example]

+   (8.4) Attempting to use a type in a nested-name-specifier of a qualified-id when that type does not contain the specified member, or

+   (8.4.1) the specified member is not a type where a type is required,
(8.4.2) the specified member is not a template where a template is required,
(8.4.3) the specified member is not a non-type where a non-type is required.

[Example:

```
template <int> struct X {};
template <class T> class Z { };
template <class T> void f(typename T::*)();
template <class T> void g(XCT::N*)();
template <class T> void h(ZCT::TT*)();
struct A {};
struct B { int Y; };
struct C {};
```
