# ISO/IEC 14882:2017(E)

```
std::cout << << path("foo/bar.txt").stem(); // outputs "bar"
path p = "foo.bar.tar";
for ( : ; !p.extension().empty(); p = p.stem()) {
    std::cout << p.extension() << '\n';
    // .tar
    // .bar
}
// end example [ ]
```

path extension() const;

+   Returns: a path whose pathname in generic format is the suffix of filename() not included in stem.

```
[Example]:
path("foo/bar.txt").extension(); // yields "txt" and stem() is "bar"
path("foo/bar.tar").extension(); // yields "tar" and stem() is "bar"
path("foo/profile").extension(); // yields \.profile" and stem() is "profile"
path(".bar").extension(); // yields "bar" and stem() is ""
path("").extension(); // yields ""
 end example
```

> Note: The period is included in the return value so that it is possible to distinguish between no extension and an extension. — end note

> Note: On non-POSIX operating systems, for a path p, it may not be the case that p.stem() + p.extension() == p.filename(), even though the generic format paths are the same. — end note

# 30.10.8.4.10 path query

```
[fs.path.query]
bool empty() const noexcept {
    Returns: true if the pathname in generic format is empty, else false.
}
bool root_path() const {
    Returns: .root_path().empty();
}
bool root_name() const {
    Returns: .root_name().empty();
}
bool root_directory() const {
    Returns: .root_directory().empty();
}
bool has_relative_path() const {
    Returns: .relative_path().empty();
}
bool has_parent_path() const {
    Returns: .parent_path().empty();
}
bool has_filename() const {
    Returns: .filename().empty();
}
bool has_stem() const {
    Returns: !stem().empty();
}
```
