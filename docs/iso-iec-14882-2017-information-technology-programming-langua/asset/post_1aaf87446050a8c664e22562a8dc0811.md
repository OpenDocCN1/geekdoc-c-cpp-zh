# 23.17.6 Class template time_time_point [time.point]

```cpp
template <class Clock, class Duration = typename Clock::duration>
class time_point {
public:
    using Clock = Clock;
    using duration = Duration;
    using rep = typename duration::rep;
    using period = typename duration::period;
private:
    duration d; // exposition only

public:
    // 23.17.6.1.
    constexpr time_point(); // has value epoch
    constexpr explicit time_point(const duration& d); // same as time_point() + d
    template <class Duration2>
    constexpr time_point(const time_point<Clock, Duration2>& t);
```

# 23.17.6.1 time_point constructors [time.point.cons]

```cpp
constexpr time_point();
```

- 1 Effects: Constructs an object of type time_point, initializing d with duration::zero(). Such a time_point object represents the epoch.

```cpp
constexpr explicit time_point(const duration& d);
```

- 2 Effects: Constructs an object of type time_point, initializing d with d. Such a time_point object represents the d+.

```cpp
template <class Duration2>
constexpr time_point(const time_point<Clock, Duration2>& t);
```

- 3 Remarks: This constructor shall not participate in overload resolution unless Duration2 is implicitly convertible to duration.
- 4 Effects: Constructs an object of type time_point, initializing d with t.time_since_epoch().

# 23.17.7 Clock

The types defined in this subclass shall satisfy the TrivialClock requirements (23.17.3).

# 23.17.7.1 Class system_clock

Objects of class system_clock represent wall time from the system-realtime clock.

```cpp
class system_clock {
public:
  using rep = ratio<specified, unspecified>;
  using period = ratio<specified, unspecified>;
  using duration = chrono::duration<rep, period>;
  using time_point = chrono::time_point<system_clock>;
  static constexpr bool is_steady = unspecified;

  static time_point now() noexcept;

  // Map to C API
  static time_t to_time_t (const time_point& tp) noexcept;
  static time_point from_time_t(time_t t) noexcept;
};
```
