## 27.5.1.2 reverse_iterator requirements [reverse.iter.requirements]

- 1 The template Iterator shall meet all the requirements of a Bidirectional iterator (27.2.6).
- 2 Additionally, if any of the members operators operator++(27.5.3.8), operator--(27.5.3.10), operator+=(27.5.3.14), operator-=(27.5.3.9), operator=(27.5.3.11), operator[](27.5.3.12), or the non-member operator++(27.5.3.18), operator--(27.5.3.17), operator+=(27.5.3.14), operator-=(27.5.3.10), operator< (27.5.3.13), operator> (27.5.3.17), operator- (27.5.3.19) or operator+=(27.5.3.20) are referenced in a way that requires instantiation (17.7.1).

### 27.5.1.3.21 Non-function member iterators

## 27.5.2 Insert iterators

To make possible with insertion in the same way as inserting into an array, a special kind of iterator adaptors, insert iterators, are provided in the library. With regular iterator classes,

```cpp
while (first != last) *result = *first;
```
causes a range (first, last) to be copied into a range starting with result. The same code with result being an insert iterator will insert elements into the container. This allows all of the copying algorithms to work in the insert mode instead of the regular mode.

An insert iterator is constructed from a container and possibly one of its pointers pointing to where insertion takes place, if it is at the beginning or of the container. Insert iterators satisfy the requirements of output iterators. operator returns the insert iterator itself. The assignment operator=(const T&) is defined on insert iterators to allow writing into them, it inserts right where the insert iterator is pointing. In other words, an insert iterator is like a cursor pointing into the container where the insertion takes place, back_insert_iterator inserts elements at the end of a container, front_insert_iterator inserts elements at the beginning of a container, and insert_iterator inserts elements where the iterator points to a container. back_insert_iterator, front_insert_iterator, and inserter

### 27.5.2.1 Class template back_insert_iterator

```cpp
namespace std {
    template<class Container>
    class back_insert_iterator {
    protected:
        Container* container;
    public:
        using iterator_category = output_iterator_tag;
        using value_type = void;
        using difference_type = void;
        using pointer = void;
        using reference = void;
        using container_type = Container;

        explicit back_insert_iterator operator=(const Container& x);
        back_insert_iterator& operator=(const typename Container::value_type& value);
        back_insert_iterator& operator=(const typename Container::value_type&& value);
        back_insert_iterator& operator++();
        back_insert_iterator operator++(int);
        // ... (rest of class omitted for brevity but follows logic)
    };
```
