A using-declaration (10.3.3) brings from a base class an assignment operator with a parameter type that does not match that of a copy/move assignment operator is not considered an explicit declaration of such an operator and does not support the implicit declaration of the derived operator, the operator introduced by the using-declaration is hidden by the implicitly-declared copy/move assignment operator of the derived class.
