# 16.6 Built-in operators

The candidate functions that operate on the built-in operators defined in Clause 8 are specified in this subclause. These candidate functions participate in operator overload resolution process in 16.3.2 and are for no other purpose. [Note: Built-in operators operate only with non-class type, and operator overload resolution occurs only when an expression is a built-in operator only when an operand has a class type or a class type that has a conversion to a non-class type appropriate for the operator, or when an operand has an enumeration type that can be converted to a type appropriate for the operator. Also note that some of the candidate functions in this subclause are more permissive than the built-in operators and are selected when the expression is the built-in operator given in Clause 8, and to satisfy any additional semantic constraints given. If there is a user-defined function with the same name and parameter types as a built-in operator function, the built-in function is hidden and not included in the set of candidate functions. — end note]

- In this subclause, the promoted integral type is used to refer to those types which are preserved by integral promotion (7.6) including int and long excluding exc. char). Similarly, the promoted arithmetic type refers to floating types plus integral types. [Note: In all cases where a promoted integral type or promoted arithmetic type is required, an operand of enumeration type will be acceptable by way of the integral promotions. — end note]

In the remainder of this section, v represents either volatile or no cv-qualifier.

- For every pair (T, T), where T is an arithmetic type other than bool, there exist candidate operator functions of the form

```cpp

```

- For every pair (T, vg), where T is an arithmetic type other than bool, there exist candidate operator functions of the form


# 17 Templates

A template defines a family of classes, functions, or variables, or an alias for a family of types.
template-declaration:
template < template-parameter-list > declaration
template-parameter-list:
template-parameter
template-parameter-list , template-parameter
[Note: The > following consecutive template-parameter-list of a template-declaration may be the product of replacing >> by two consecutive tokens (17.2) — end note]
declaration in a template-declaration shall

- (1.1) declare or define function, a class, or a variable
- (1.2) define a function, a class member, an enumeration, or a static data member of a class template or a class nested within a class template,
- (1.3) define a template of a class or class template, or
- (1.4) define a deduction-guide, or
- (1.5) define an alias-declaration.

A template-declaration is a declaration. A template-declaration is also a definition if it defines a function, a class, or a static data member. A declaration introduced by template declaration of a variable is a variable template. A variable template at class is a static data template member.

```cpp
template<class T>
constexpr pi = T(3.141592653859732385);
template<class T>
T circular_area(T r) {
    return pi * r * r;
}
struct matrix_constants {
template<class T>
using Pauli = hermitian_Matrix<T, 2>;
template<class T>
constexpr T sigma1 = { 0, 0, 1 }, { 1, 0, 0 };
template<class T>
constexpr T sigma2 = { 0, -1 }, { 1, 0, 0 };
template<class T>
constexpr T sigma3 = { 1, 0, 0 }, { 0, -1 };
};
```
