# 29.6.8.5.5 Class fisher_f_distribution [rand.dist.norm.f]

A fisher_f_distribution random number distribution produces random numbers x ≥ 0 distributed according to the probability density function

> $p(x|m,n) = \frac{\Gamma((m+n)/2)}{\Gamma(m/2)\Gamma(n/2)} \left(n\right)^{m/2} x^{(m/2)-1} \left(1 + \frac{m}{n}\right)^{-(m+n)/2}$$
