
# ISO/IEC 14882:2017(E)

```cpp
template <class money> unspecified get_money(moneyT& mon, bool intl = false);
```

Requires: The type money shall be either long double or a specialization of the basic_string template (Clause 24).

Effects: The expression in >> get_money(mon, intl) described below behaves as a formatted function (30.7.2.1).

Returns: An object of unspecified type if that is an object of type basic_istream<charT, traits>, then the expression in >> get_money(mon, intl) behaves as if called f(in, mon, intl); where the function f is defined:

```cpp
template <class charT, class traits, class money>
void f(basic_ios<charT, traits>& in, moneyT& mon, bool intl) {
    using Iter = istreambuf_iterator<char>;
    using Money = get_money<charT, Iter>;

    ios_base::istate err = ios_base::goodbit;
    const Money getMon = use<Money>(in.getloc());

    getMon.get(Iter(in.rdbuf()), Iter(), intl, str, err);

    if (Iter(in.rdbuf()) != err || err != fail) {
        in.setstate(err);
    }
}
```

The expression in >> get_money(mon, intl) shall have type basic_istream<charT, traits>& and return value in.

```cpp
template <class money> unspecified put_money(const moneyT& mon, bool intl = false);
```

Requires: The type money shall be either long double or a specialization of the basic_string template (Clause 24).

Returns: An object of unspecified type if that is an object of type basic_ostream<charT, traits> then the expression << put_money(mon, intl) behaves as a formatted function (30.7.5.2.1) that calls f(out, mon, intl), where the function f is defined:

```cpp
template <class charT, class traits, class money>
void f(basic_ostream<charT, traits>& out, const moneyT& mon, bool intl) {
    using Iter = ostreambuf_iterator<char>;
    using Money = put_money<charT, Iter>;

    const Money mPut = use<Money>(out.getloc());
    Iter end = mPut.put(Iter(out.rdbuf()), intl, str.fill(), mon);

    if (end.failed()) {
        out.setstate(ios_base::badbit);
    }
}
```

The expression << put_money(mon, intl) shall have type basic_ostream<charT, traits>& and return value.

```cpp
template <class charT> unspecified get_time(struct tm& tmb, const charT* fmt);
```

Requires: The tm mb shall be a valid pointer to an array of objects of type charT with char_traits<charT>::length(fmt) elements.

Returns: An object of unspecified type if that is an object of type basic_istream<charT, traits> then the expression in >> get_time(tmb, fmt) behaves as if f(in, tmb, fmt), where the function f is defined as:

```cpp
template <class charT, class traits>
void f(basic_ios<charT, traits>& in, istream_iterator<charT> it,
    using TimeGet = get_time<charT, traits>;
    ios_base::istate err = use_facet<TimeGet>(in.getloc());
    TimeGet::get(Iter(in.rdbuf()), Iter(), str, err, tmb,
    fmt, traits::length(fmt));

    if (err != ios_base::goodbit) {
        in.setstate(err);
    }
}
```

The expression in >> get_time(tmb, fmt) shall have type basic_istream<charT, traits>& and return value in.

```cpp
template <class charT> unspecified put_time(const struct tm* tmb, const charT* fmt);
```

Requires: The argument tmb shall be a valid pointer to an object of type tm and the argument fmt shall be a valid pointer to an array of objects of type charT with char_traits<charT>::length(fmt) elements.

Returns: An object such that if out is an object of type basic_ostream<charT, traits> then the expression << put_time(tmb, fmt) behaves as if it called f(out, tmb, fmt), where the function f is defined:

```cpp
template <class charT, class traits>
void f(basic_ostream<charT, traits>& out, const struct tm* tmb, const charT* fmt) {
    using Iter = oambuf_iterator<charT, traits>;
    using TimePut = put_time<charT, traits>;

    const TimePut tp = use_facet<TimePut>(out.getloc());
    const Iter end = tp.put(Iter(out.rdbuf()), tmb, fmt,
    fmt, fmt += traits::length(fmt));

    if (end.failed()) {
        out.setstate(ios_base::badbit);
    }
}
```

The expression << put_time(tmb, fmt) shall have type basic_ostream<charT, traits>& and return value out.

## 30.7.8 Quoted manipulators

Quoted manipulators provide string insertion and extraction of quoted strings (for example, XML and CSV formats). Quoted manipulators are useful for ensuring that the content of a string with spaces remains unchanged if inserted and then extracted via I/O.

```cpp
template <class charT> unspecified quoted(charT& s, charT delim = '\"', charT escape = '\\');
```

```cpp
template <class charT, class traits, class Allocator> unspecified quoted(const basic_string<charT, traits, Allocator>& s, charT delim = '\"', charT escape = '\\');
```

```cpp
template <class charT, class traits> unspecified quoted(basic_string_view<charT, traits> s, charT delim = '\"', charT escape = '\\');
```

Returns: An object of unspecified type such that it is an instance of basic_ostream with member type char_type the same as charT and member type traits is the same as traits, then the expression << quoted(s, delim) behaves as a formatted output of the character sequence, initially consisting of the following elements:

- (2.1) delim.
- (2.2) Each character in s. If the character is equal to escape or delim, as determined by traits::eq, first output escape.
- (2.3) delim.

Let x be the number of elements in seq. Then padding for delim as described in 30.7.5.1 is determined as if calling out.rdbuf()->putn(n), where n is the larger of out.width() and x, and out() is called. The expression << quoted(s, delim) behaves as basic_ostream<charT, traits>& and return value out.

Returns: An object of unspecified type such that (3.1) If in is an instance of basic_istream with member type char_type same as charT and member type traits is the same as traits, then the expression >> quoted(s, delim) behaves as it extracts the following characters using operator>>(basic_istream<charT, traits>&) which may throw ios_base::failure:

- (3.1.1) Skip the first character equal to delim, as determined by traits_type::eq; then
- (3.1.2) Otherwise, in >> s.
- (3.1.3) Until an unescaped delim character is reached or in, extract characters from in and append them to s, except that an escape is reached, ignore it and append the next character to s.
- (3.1.4) Discard the final character.
- (3.1.5) Restore the flags to its original value.
- (3.2) If out is an instance of basic_ostream with member type char_type same as charT and member type traits is the same as traits, then the expression << quoted(s, delim) behaves as the const basic_string<charT, traits, Allocator<charT>>& overload of the quoted function.

The expression >> quoted(s, delim) shall have type basic_istream<charT, traits>& and return value in. The expression << quoted(s, delim) shall have type basic_ostream<charT, traits>& and return value out.

## 30.8 String-based streams

### 30.8.1 Header <sstream> synopsis

```cpp
namespace std {
    template <class charT, class traits = char_traits<charT>,
    class Allocator = allocator<charT>>
    class basic_stringbuf{
        using stringbuf = basic_stringbuf<char>;
        using wstringbuf = basic_stringbuf<wchar>;

    template <class charT, class traits = char_traits<charT>,
    class Allocator = allocator<charT>>
    class basic_istream{
        using istream = basic_istream<charT>;
        using wistream = basic_istream<wchar>;
    
    template <class charT, class traits = char_traits<charT>,
    class Allocator = allocator<charT>>
    class basic_ostream{
        using ostream = basic_ostream<charT>;
        using wostream = basic_ostream<wchar>;
    }
}
```

The <sstream> defines four class templates and eight types that associate stream buffers with class string, as described in 24.3.

## 30.8.2 Class template-basic_stringbuf

```cpp
namespace std {
    template <class charT, class traits = char_traits<charT>,
    class Allocator = allocator<charT>>
    class basic_stringbuf : public basic_stringbuf<charT, traits> {
    public:
        using char_type = charT;
        using int_type = typename traits::int_type;
        using pos_type = typename traits::pos_type;
        using off_type = typename traits::off_type;
        using traits_type = traits;
        using Allocator = Allocator;

        // 30.8.2.1. constructors
        explicit basic_stringbuf(openmode mode = ios_base::in | ios_base::out);
        explicit basic_stringbuf(const charT&, traits, const Allocator& str,
        ios_base::openmode mode = ios_base::in | ios_base::out);
        basic_stringbuf(const basic_stringbuf& rhs) = delete;
        basic_stringbuf(const basic_stringbuf& rhs) = delete;
```
