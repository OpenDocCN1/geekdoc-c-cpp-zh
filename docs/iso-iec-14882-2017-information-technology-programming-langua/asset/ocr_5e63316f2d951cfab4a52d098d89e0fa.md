# ISO/IEC 14882:2017(E)

The lvalue-to-rvalue conversion (7.1) is applied if and only if the expression is a glvalue of volatile-qualified type and it is one of the following:

+   - ( expression ), where expression is one of these:
- id-expression (8.1.4),
- subscripting (8.2.1),
- class member access (8.2.5),
- indirection (8.3.1),
- pointer-to-member expression (8.5),
- conditional expression (8.16) where both the second and third operands are one of these,
- comma expression (8.19) where the right operand is one of these.

> [Note: Using an overloaded operator causes a function call; the above covers operators with meaning. — end note] If the expression is a prvalue after this optional conversion, the temporary materialization conversion (7.4) is applied. [Note: If the expression is an lvalue, it must have a volatile copy constructor to initialize the temporary or the result of the lvalue-to-rvalue conversion. — end note] The glvalue is evaluated and its value discarded.

The values of the floating operands and the results of floating expressions may be represented in greater precision than that required by the type: these are not changed thereby.⁶⁴

The cv-type of types T1 and T2 is a type T3 similar to T1 whose cv-qualification signature (7.5)

+   - for every i > 0, cv* is the union of cv1 and cv2;
- if the result is reference-related to cv1 or cv2, then const is applied to cv2 for 0 < k < i.

> [Note: Given composite pointer type T1 and T2, this construction ensures that at least one is a pointer or pointer to member type: :nullptr_t; — end note]

The composite pointer type of two operands p1 and p2 having types T1 and T2, respectively, where at least one is a pointer or pointer to member type or std::nullptr_t;

+   - if either p1 or p2 is "pointer to cv void" and the other type is "pointer to cv T", where T is an object type
- if T1 or T2 is "pointer to cv T1" and the other type is "pointer to cv T2", respectively;
- if T1 is "pointer to cv C1" and T2 is "pointer to cv C2", where C1 is reference-related to C2 or C2 is reference-related to C1 (11.6.3), the cv-composite type of T1 and the cv-composite type of T2 and T1, respectively;
- if T1 is "pointer to member of type cv U1" and T2 is "pointer to member of type cv U2", where C1 is reference-related to C2 or C2 is reference-related to C1 (11.6.3), the cv-composite type of T1 and the cv-composite type of T2 and T1 and T2, respectively;
- if T1 and T2 are similar types (7.5), the cv-composite type of T1 and T2;
- otherwise, a program that necessitates the determination of a composite pointer type is ill-formed.

⁶⁴) The cast and assignment operators must perform their specific conversions as described in 8.4, 8.2.9 and 8.18.
