(2.1) If one pointer represents the address of a complete object, another pointer represents the address one the last element of a different complete object,the result of the comparison is unspecified.

(2.3) Otherwise, the operands compare unequal.

3 If at least one of the operands is a pointer to member, member conversions (7.12) and qualification conversions (7.5) are performed on both operands to bring them to their composite pointer type (Clause 8). Comparing pointers to members is defined as follows:

(3.1) If two members are both null pointer value, they compare equal.

(3.2) If only one of two members is null pointer value, they compare unequal.

(3.3) If either is a pointer to a virtual member function, the result is unspecified.

(3.4) If one refers to a member of class C1 and the other refers to a member of a different class C2, neither is a base class of other, the result is unspecified. [Example:
