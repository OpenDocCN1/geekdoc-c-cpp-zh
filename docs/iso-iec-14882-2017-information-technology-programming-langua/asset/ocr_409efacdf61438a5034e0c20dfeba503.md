# 23.7.3.6 Swap [variant.swap]

```
void swap(variant& lhs, variant& rhs) noexcept(see below);
```

+   - Requires: Lvalues of type T, shall be swappable (20.5.3.2) and is_move_constructible_v<T> shall be true for all i.

Effects:

+   - if valueless_by_exception() && rhs.valueless_by_exception() no effect. Otherwise,

+   - if index() == rhs.index(), swap(get<*(this)>, get<*(rhs>>) where i is index(i). Otherwise,

+   - exchanges values of rhs and this.

Remarks: If an exception occurs during the call to swap(get<*(this)>, get<*(rhs)), the states of the contained of *this and rhs are determined by the exception safety guarantee of values of T for i, where i is index(i). If an exception occurs, the values of *this and rhs are determined by the exception safety guarantee of variant's move constructor. The exception inside noexcept is equivalent to the logical AND of is_move_constructible_v<T> && is_not_swappable_v<T> for all i.

# 23.7.4 variant helper classes [variant.helper]

```
template <class T> struct variant_size;
```

Remarks: All specializations of variant_size shall meet the UnaryTypeTrait requirements (23.15.1) with a base characteristic of integral_constant<size_t, N> for some N.

```
template <class T> class variant_size<volatile T>;
```

Let VS denote variant_size<T> of the un-qualified type T. Then each of the three templates shall meet the UnaryTypeTrait requirements (23.15.1) with a base characteristic of integral_constant<size_t, VS::value>;

```
template <class Types...>
			struct variant_size<variant<Types...>> : integral_constant<size_t, sizeof...(Types)>> {};

			template <size_t I, class T> class variant_size<alternative<I>, const T>;
			template <size_t I, class T> class variant_size<alternative<I>, volatile T>;
			template <size_t I, class T> class variant_size<alternative<I>, volatile T>;
```

Let VA denote alternative<I, T> of the un-qualified type T. Then each of the three templates shall meet the TransformationTrait requirements (23.15.1) with a member typedef that names the following type:

+   - for the first specialization, add_const_T<VA>::type;
			- for the second specialization, add_volatile_T<VA>::type;
			- for the third specialization, add_cv_t<VA>::type.
