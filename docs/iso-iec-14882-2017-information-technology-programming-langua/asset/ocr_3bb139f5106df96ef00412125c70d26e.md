# 10.6.3 \ dependency [dcl.attr.dep]

+   1 The attribute-carries-dependency specifies propagation into and out of functions. It may appear at most once in each attribute-list and no attribute-argument-clause shall be present. The attribute may be applied to the declarator-id of parameter-declaration in a function declaration or lambda, in which case it specifies the initialization of the parameter carries a dependency to (4.7) each value-to-value conversion (7.1) of that object. The attribute may also be applied to the declarator-id of a function declaration, in which case it specifies the return value, if any, carries a dependency to the evaluation of the function expression.

+   2 The first declaration of a function specifies the carries-dependency attribute for its declarator-id if any declaration of the function specifies the carries-dependency attribute. Furthermore, the first declaration of a function specifies the carries-dependency attribute for a parameter if any declaration of function specifies the carries-dependency attribute in its first declaration in one translation unit and one of its parameters is declared with the carries-dependency attribute in its first declaration in the same function or one of its parameters is declared without the carries-dependency attribute in its first declaration in another translation unit, the program is ill-formed, no diagnostic required.

+   3 [Note: The carries_dependency attribute does not change the meaning of the program, but may result in generation of more efficient code. — end note]

+   4 [Example:
