
# ISO/IEC 14882:2017(E)

## 23.14.11.1 Class template is_bind_expression [func.bind.isbind]

```cpp
namespace std {
  template<class T> struct is_bind_expression; // see below
}
```

1 The class template `is_bind_expression` can be used to detect function objects generated by `bind`. The function template uses `is_bind_expression` to detect subexpressions.

2 Instantiations of `is_bind_expression` shall meet the requirements. The implementation shall provide a definition that has a characteristic of `true_type` if `T` is a type returned from `bind`, otherwise it shall have a characteristic of `false_type`. A program may specialize this template for a user-defined `T` to have a characteristic of `true_type` to indicate that `T` should be treated as a subexpression associated with `U`.

## 23.14.11.2 Class template is_placeholder [func.bind.isplaceholder]

```cpp
namespace std {
  template<class T> struct is_placeholder; // see below
}
```

1 The class template `is_placeholder` can be used to detect placeholders, and so on. The function template uses `is_placeholder` to detect placeholders.

2 Instantiations of `is_placeholder` shall meet the requirements. The implementation shall provide a definition that has a characteristic of `integral_constant<int, J>` if `T` is the type of placeholders; otherwise it shall have a characteristic of `integral_constant<int, 0>`. A program may specialize this template for a user-defined `T` to have a characteristic of `integral_constant<int, N>` with `N > 0` to indicate that `T` should be treated as a placeholder type.

## 23.14.11.3 Function template bind [func.bind.bind]

In the following
- (1) `FD` is the type decay of `F` constructed from `std::forward<F>(f)`,
- (2) `fd` is an value of type `FD` constructed from `std::forward<F>(f)`,
- (3) `Ti` is the $i$-th argument in the parameter pack `BoundArgs`,
- (4) `TD` is the type decay`<T>`,
- (5) `ti` is the $i$-th argument in the function parameter pack `args`,
- (6) `td` is an value of type `U` constructed from `std::forward<U>(u)`,
- (7) `U` is the deduced type of `BoundArgs...` parameter of the forwarding wrapper, and
- (8) `uj` is the $j$-th argument associated with `U`,

```cpp
template<class F, class... Args>
bind(F&& f, Args&&... args);
```

Requires: `is_constructible<F, Args>` shall be true. For each `T` in `BoundArgs`, `is_constructible<T, U>` shall be true. `INVOKE(f, v1, ..., vn)` shall be a valid expression for values `v1, v2, ..., vn` which has the value `(BoundArgs)`. The cv of the call wrapper, as specified below, shall be neither `volatile` nor `const`.

Returns: A forwarding wrapper `INVOKE(f, std::forward<V>(v1), v2: std::forward<VN>(v2), ..., vn: std::forward<VN>(vn))` where the values and types of the arguments `v1, v2, ..., vn` are determined as specified below. The copy constructor and move constructor of the forwarding wrapper shall throw an exception if only the constructor of `FD` or if any of the types `TD` throws.

Throws: Nothing unless the constructor of `fd` or if any of the values `td` throws an exception.

Remarks: The return type shall satisfy the requirements of `MoveConstructible`. If all of `FD` and `TD` satisfy the requirements of `CopyConstructible`, then the return type shall satisfy the requirements of `CopyConstructible`. [Note: This implies that all `FD` and `TD` are `MoveConstructible`. — end note]

```cpp
template<class R, class F, class... BoundArgs>
function(F&& f, BoundArgs&&... args);
```

Requires: `is_constructible_v<FD, TD>` shall be true. For each `T` in `BoundArgs`, `is_constructible_v<T, v>` shall be true. `INVOKE(v1, w2, ..., wN)` shall be a valid expression for values `w1, w2, ..., wN` which have the same size. The cv-wrappers of the call wrapper `g`, as specified below, shall not be `volatile const`.

Returns: A call wrapper `g` (23.14.3). The effect of `g(u1, ..., uM)` shall be `INVOKE(std::forward<U1>(u1), ..., std::forward<UM>(uM))` where the values and types of the arguments `v1, v2, ..., vM` are determined as specified before. The copy constructor and move constructor of the call wrapper shall throw an exception if and only if the constructor of `FD` or if any of the types `TD` throws.

Throws: Nothing unless the constructor of `fd` or if any of the values `td` throws an exception.

Remarks: The return type shall satisfy the requirements of `MoveConstructible`. If all of `FD` and `TD` satisfy the return type shall satisfy the requirements of `CopyConstructible`. [Note: This implies that all `FD` and `TD` are `MoveConstructible`. — end note]

The values of arguments `v1, v2, ..., vN` and their corresponding types `V1, V2, ..., VN` depend on the types `TD`, derived from the call `bind` and the cv-wrappers of the call wrapper `g` shall be as follows:

- (10.1) if `(is_bind_expression_v<TD>)` is true, the argument is `td`, `(std::forward<U>(uj) ...)`;
- (10.2) if the value `j` of `is_placeholder_v<TD>` is not zero, the argument is `td`, `(std::forward<U>(uj) ...)` and its type `V` is `U&&`;
- (10.3) otherwise, the value is `td`, and its type `V` is `TD`;

## 23.14.11.4 Placeholders

```cpp
namespace std::placeholders {
  // M is the implementation-defined number of placeholders
  see i1;
  see i2;
}
```

All placeholder types shall be `DefaultConstructible` and `CopyConstructible`, and their default constructors and copy/move constructors shall not throw exceptions. It is implementation-defined whether placeholder types are `CopyAssignable`. Copy assignment operators shall not throw exceptions.

## 23.14.11.4 Placeholders should be defined as:
```cpp
inline constexpr t();
```
If they are not, they shall be declared as:
```cpp
extern t1;
```
