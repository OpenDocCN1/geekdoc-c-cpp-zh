9 A simple-template-id that names a class template explicit specialization has been declared but not defined can be used exactly like the names of other incompletely-defined classes (6.9). Example:

```
template<Class> class X;
template<int> class X<int>;

<int>* p;
<int>* x;

// end example
```

> // X is a class template
// OK: pointer to declared class X<int>
// error: object of incomplete class X<int>

10 A trailing template-argument can be left unspecified in the template-id naming an explicit template specialization it can be deduced from the function argument. Example:

```
template<T> class Array { /* ... */ };
template<T> void sort(Array<T&>);

// explicit specialization for sort(Array<int>&)
// with deduced template-argument of type int;
// end example
```

11 A function with the same name as a class and a type that exactly matches of a template specialization is not an explicit specialization (17.5.6).

12 An explicit specialization of a class or variable template is inline if it is declared with the inline specified or deduced, and independently of whether its function or variable template is inline. Example:

```
template<T> void f(T) { /* ... */ };
template<T> inline g(T) { /* ... */ };

template<int> void f(int) { /* ... */ };
template<int> int g(int) { /* ... */ };

// end example
```

> // OK: inline
// OK: not inline

13 An explicit specialization of a static data member of a class template or an explicit specialization of a static data member template is a definition if the declaration includes an initializer; otherwise, it is a declaration. [Note: The definition of a static data member of a template that requires default-initialization must use a braced-init-list.

```
template<X> Q<int>::x;
template<X> Q<int>::x = :;
template<X> Q<int>::x = {};

// end example
```

> // declaration
// error: declares a function
// definition

14 A member or member template of a class template may be explicitly specialized for a given implicit instantiation of the class template, even if the member or template is defined in the class template definition. An explicit specialization of a member or member template is specified using the syntax for: Example:

```
template<class T> struct A {
void f(T);
template<class X1> void g1(T, X1);
template<class X2> void g2(T, X2);
hoid h(T) {}
};

// specialization
```
