# ISO/IEC 14882:2017(E)

# 24.3.2.7.9 basic_string::compare [string::compare]

```
int compare(basic_string_view<charT, traits sv> const noexcept;
```

+   1. Effects: Determines the effective length len of the strings to compare as the smaller of size() and sv.size(). The function compares the two strings by calling traits::compare(data(), sv.data(), len).
2. Returns: The nonzero result if the comparison is nonzero. Otherwise, returns a value indicated in Table 63.

Table 63 — compare results
| Condition | Return Value |
|--- |--- |
| size() < sv.size() | < 0 |
| size() == sv.size() | 0 |
| size() > sv.size() | > 0 |

```
int compare(size_pos pos1, size_type n1, basic_string_view<charT, traits sv> const const;
```

+   3. Effects: Equivalent to:

```
return basic_string_view<charT, traits>(data(), size()).substr(pos1, n1).compare(sv);
template<class T>
int compare(size_pos pos1, size_type n1, const T&, size_pos pos2, size_type n2 = npos) const;
```

+   4. Effects: Equivalent to:

```
basic_string_view<charT, traits> sv = t;
return basic_string_view<charT, traits>(data(), size()).substr(pos1, n1).compare(sv.substr(pos2, n2));
```

+   5. Remarks: This function shall not participate in overload unless is_convertible_v<const T, basic_string_view<charT, traits>> is true and is_convertible_v<const T, const char*> is false.

```
int compare(const basic_string& str const noexcept;
```

+   6. Effects: Equivalent to: return compare(basic_string_view<charT, traits>(str));

```
int compare(size_pos pos1, size_type n1, const basic_string& str) const;
```

+   7. Effects: Equivalent to: return compare(pos1, n1, basic_string_view<charT, traits>(str));

```
int compare(size_pos pos1, size_type n1, const basic_string& str, size_pos pos2, size_type n2 = npos) const;
```

+   8. Effects: Equivalent to:

```
return compare(pos1, n1, basic_string_view<charT, traits>(str), pos2, n2);
```

```
int compare(const char* s) const;
```

+   9. Returns: compare(basic_string(s));

```
int compare(size_pos pos1, size_type n1, const char* s) const;
return basic_string(*this, pos, n1).compare(basic_string(s));
```
