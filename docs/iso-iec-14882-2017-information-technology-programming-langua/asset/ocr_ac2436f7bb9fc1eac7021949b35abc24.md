> Note: Path equality and path value have different semantics.

+   (8.1) Equality is determined by the path non-operator==, which considers the path's lexical representations. [Example: path"foo" = "bar" is never true. — example]

+   (8.2) Equivalence is determined by the equivalent() non-member function, which determines if two paths resolve to the same file system. [Example: equivalent("foo", "bar") will be true if both paths resolve to the same file. — example]

Programmers wishing to determine if two paths are the "same" must decide if "the same" means the "same representation" or "resolve to the same actual file", and choose the appropriate function accordingly.
