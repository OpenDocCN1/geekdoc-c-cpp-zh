# 15.3.2 Conversion functions [class.conv.f]

+   1 A member of a class X having parameters with a name of the form
```
conversion-id:
operator-type-id
type-specifier-seq conversion-declarator,opt
conversion-declarator:
ptr-operator conversion-declarator,opt
```

specifies conversion to X by the conversion-type-id. Such functions are called conversion functions. A decl-specifier-seq of a conversion function (if any) shall be a defining type-specifier not static. The type of the conversion function (11.3.5) is “function taking no parameters returning ‘conversion-type’.” A conversion function is never used to convert a (possibly cv-qualified) object to a (possibly cv-qualified) same object type (or a reference to it), to a (possibly cv-qualified) base class of that type (or a reference to it),¹¹¹⁷ [Example:

```
struct X {
  operator int();
  operator auto() -> short;
};
nvoid f(X a) {
  int i = int(a);
  i = a;
}
```

In all cases the value assigned will be converted by X::operator int(). — end example
