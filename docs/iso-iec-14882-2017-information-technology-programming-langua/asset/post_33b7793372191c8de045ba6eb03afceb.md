The class template basic_streambuf serves as an abstract class for deriving stream buffers whose objects control two characters: a character input sequence and a character output sequence.

## 30.6.3.1 basic_streambuf constructors

basic_streambuf();

- 1 Effects: Constructs an object of class basic_streambuf<charT, traits>, and initializes.
- (1.1) all its pointer members to null pointers, the getloc() a member to the global locale(), and at the time of construction.
- 2 Remarks: Constructs a copy of rhs. 

Effects: The getloc() member is initialized, results of calling member functions, and members of facets can be safely cached until the next time the member imbue is called.

basic_streambuf(const basic_streambuf& rhs);

- 3 Effects: Constructs a copy of rhs.

Postconditions:

```
(4.1) eback() == rhs.eback()
(4.2) gptr() == rhs.gptr()
(4.3) egptr() == rhs.egptr()
(4.4) pbase() == rhs.pbase()
(4.5) pptr() == rhs.pptr()
(4.6) eptr() == rhs.eptr()
(4.7) getloc() == rhs.getloc()
```

```cpp
-basic_streambuf();
```

- 5 Effects: None.

> 299 The default constructor is protected for class basic_streambuf to assure that only objects for classes derived from this class may be constructed.

## 30.6.3.2 basic_streambuf public member functions

### 30.6.3.2.1 Locales [streambuf.locales]

void imbue(const locale& loc);

- 1 Postconditions: loc == getloc().
- 2 Effects: Calls imbue().
- 3 Returns: Previous value of getloc().

locale getloc() const;
- 4 Returns: If imbue() has ever called, the last value of loc supplied, otherwise the current global locale(), at the time of construction. If after imbue() has been called before imbue() has returned, it returns the previous value.

### 30.6.3.2.3 Get avail [streambuf.get]

streamsize avail();
- 1 Returns: If a read position is available, returns egptr() - gptr(). Otherwise returns showmany().

int_type nextc();
- 2 Effects: Calls uget().
- 3 Returns: If function returns traits::eof(), returns traits::eof(). Otherwise, returns sgetc().

int_type imbue();
- 4 Returns: If the input sequence read is not available, returns underflow(). Otherwise, returns traits::to_type(*gptr()) and increments the next pointer for the input sequence.

int_type sgetc();
- 5 Returns: If the input sequence position is not available, returns underflow(). Otherwise, returns traits::to_type(*gptr()).

streamsize sgetn(char_type* s, streamize n);
- Returns xsgetn(s, n).

### 30.6.3.2.4 Putback [streambuf.putback]

int_type sputback(char_type c);

- If the input sequence position is not avail, or if traits::eq(c, gptr()) is false, returns pbackfail(traits::to_type(c)). Otherwise, increments the next pointer for the input sequence and returns traits::to_type(*gptr()).

int_type sungetc();
- If the input sequence position is not avail, returns pbackfail(). Otherwise, increments the next pointer for the input sequence and returns traits::to_type(*gptr());

### 30.6.3.2.5 Put area [streambuf.put.area]

int_type sput(char_type c);

- If the output sequence write position is not avail, returns overflow(traits::to_type(c)). Otherwise, shifts c at the next pointer for the output sequence, increments the pointer, and streamize sputn(char_type* s, streamize n);
- Returns xsputn(s, n).
