
# ISO/IEC 14882:2017(E)

function(null_ptr_t f) noexcept;

Postconditions: !*f;

function(const function& f);

Postconditions: !*this if !*f; otherwise,*this targets a copy of f.target().

Throws: shall not throw exceptions if f's target is a specialization of reference_wrapper or a function pointer. otherwise throw bad_alloc or any exception thrown by the copy constructor of the stored object. [Note: Implementations should avoid the use of dynamically allocated memory for small called objects, for example, where f's target is an object holding only a pointer or reference to an object and a member function pointer. — end note]

function(function&& f);

Postconditions: !*this if ,*f has no target; otherwise this is equivalent to the target of f before construction, and f is in a valid state with an unspecified value.

Throws: shall not throw if f's target is a specialization of reference_wrapper or a function pointer. otherwise throw bad_alloc or any exception thrown by the copy or move constructor of the stored object. [Note: Implementations should avoid the use of dynamically allocated memory for small called objects, where f's target is an object holding only a pointer or reference to an object and a member function pointer. — end note]

```cpp
template<class F> function(F f);
```

Requires: F is Constructable.

Remarks: This constructor shall not participate in order resolution unless F is Lvalue-Callable ([24.13.13.2]) for argument Types... and return type R.

Postconditions: !*this if any of the following:

- f is a null pointer value.
- f is a member pointer value.
- F is an instance of the function class, initialized with std::move(f). [Note: Implementations should avoid the use of dynamically allocated memory for small called objects, where f is an object holding only a pointer or reference to an object and a member function pointer. — end note]

Otherwise,*this throws exceptions when f is a function pointer or a reference_wrapper<T> for some T. Otherwise, may throw bad_alloc or any exception thrown by f's copy or move constructor.

```cpp
template<class F> function(F&&) -> function<F>
```

Remarks: This deduction guidance participates in order resolution unless F&:operator() is well-known when treated as an unvaluated reference. In that case, if decaytype(F)::operator() is of the form R(G::*)(A...) cv const& for a class G, the deduced type is function<R(A..>).

```cpp
Example:
void f() {
  int i(5);
  g = [&](double) { return 1; }; // deduces functionint(double)
}
— end example
```

## 23.14.14 Searchers

This subclause provides object types (23.14.3) for operations that search for a sequence [pat_first, pat_last] in which an object is provided to the object's call operator. The operator searches the first sequence (the part to be searched for) is provided to the object's constructor, and the second (the sequence to be searched) is provided to the function call operator.

Each specification of a class template specified 23.14.14 shall meet the CopyConstructible and CopyAssignable requirements. Template parameters named

- ForwardIterator
- ForwardIterator1,
- ForwardIterator2,
- RandomAccessIterator1,
- RandomAccessIterator2,
- BinaryPredicate

of templates specified in this subclause 23.14.14 shall meet the requirements. The Boyer-Moore search implements the Boyer-Moorepool algorithm. The Boyer-Moorepool search implements the Boyer-Moore algorithm. In general, the Boyer-Moore search will use more memory and get better runtime than Boyer-Moorepool.

### 23.14.4.1 Class template default_searcher

```cpp
template <class ForwardIterator1, class BinaryPredicate = equal_to<>>
class default_searcher {
public:
    default_searcher(ForwardIterator1 pat_first, ForwardIterator1 pat_last,
    BinaryPredicate pred = BinaryPredicate());

    template <class ForwardIterator2>
    pair<ForwardIterator2, ForwardIterator2> const
    operator()(ForwardIterator2 first, ForwardIterator2 last) const;

private:
    ForwardIterator1 pat_first_;      // exposition only
    ForwardIterator1 pat_last_;       // exposition only
    BinaryPredicate pred_;            // exposition only
};
```

```cpp
default_searcher(ForwardIterator1 pat_first, ForwardIterator1 pat_last,
    BinaryPredicate pred = BinaryPredicate());
```

- 1. Effects: Constructs a default_searcher object, initializing pat_first_ with pat_first, pat_last_ with pat_last, and with pred.
- 2. Throws: Any exception thrown by the copy constructor of BinaryPredicate or ForwardIterator.

```cpp
template <class ForwardIterator2>
    pair<ForwardIterator2, ForwardIterator2> const
    operator()(ForwardIterator2 first, ForwardIterator2 last) const;
```

- 3. Returns: A pair of iterators i and j such that (3.1) i == search(first, last, pat_first_, pat_last_, pred_) and (3.2) if i == last, then j == next(i, distance(pat_first_, pat_last)).
