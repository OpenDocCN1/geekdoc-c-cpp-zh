## 17.7.2 Explicit instantiation [temp.explicit]

1. A class, function, or member template can be explicitly instantiated from its template. A member function, member class or static data of a class template can be explicitly instantiated from the member associated with its class template. An explicit instantiation of a function template or member function of a class template shall not use the inline or constexpr specifiers.

2. The syntax for explicit instantiation is:

```cpp
explicit-instantiation:
extern_template declaration
```

There are two types of explicit instantiation: an explicit instantiation definition and an explicit instantiation declaration. An explicit instantiation declaration begins with the extern keyword.

3. If the explicit instantiation is for a class or class member, the elaborated-type-specific in the declaration shall include a simple-template-id. If the explicit instantiation is for a function or member function, the unqualified-id in the declaration should be either a template-id, where all arguments can be deduced, a template-name or operator-function-id. [Note: The declaration may declare a qualified-id, in which case the unqualified-id of the qualified-id must be a template-id. end note] If the explicit instantiation is for a member function, class or static data member of a class template specialization, the name of the class template specialization for the qualified name shall be a simple-template-id. If the explicit instantiation is for a member function of a template, the declaration shall appear in an enclosing namespace of its template. An explicit instantiation shall appear in the namespace where the name declared in the explicit instantiation is declared, or if namespace is inline (10.3.1), any namespace from its enclosing namespace set. [Note: Regarding qualified names in declarators, 11.3. end note] [Example:

```cpp
template<class T> class Array { void mO(); };
template<class T> class Array { Array(int*); };
template<class T> void sort(Array<T>&) { /* ... */ }
void sort(Array<char>&); // argument
```

```cpp
namespace N {
template<class T> void fT(T&);
} // end example
```

4. A declaration of a function template, a variable template, member function or static data member of a class template, a member function of a class or class template shall precede an explicit instantiation of that entity unless the explicit instantiation names a class of class template, a class member of a class template, or a class member of a class or class template is preceded by an explicit specialization of the same template arguments. If the declaration of the explicit instantiation names a member function (Clause 15), the program is ill-formed.

5. For a set of template arguments, if an explicit instantiation of a template appears after a declaration of an explicit specialization for that template, it has no effect. Otherwise, for an explicit instantiation definition of a function template, a variable template, a member function template, or a member or static data member of a class template shall be present in every translation unit in which it is instantiated.

6. An explicit instantiation of a class, function, or variable template specialization is placed in the namespace in which the template is defined. An explicit instantiation for a member of a class template is placed in the namespace where the enclosing class is defined. An explicit instantiation for a member template is placed in the namespace where the enclosing class or class template is defined. [Example:

```cpp
namespace N {
template<class T> class Y { void mO(); }; };
template class Y<int>; // error: class template Y not visible in the global namespace
using N::Y;
template class Y<int>; // error: explicit instantiation outside of the namespace of the template
template class N::Y<char*>; // OK: explicit instantiation in namespace N
```
