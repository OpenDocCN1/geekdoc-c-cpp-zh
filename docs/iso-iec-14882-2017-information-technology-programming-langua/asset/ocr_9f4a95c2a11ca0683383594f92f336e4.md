| Expression | Return type | Assertion/note pre-/post-condition |
|---|---|---|
| v.translate_nocase(c) | X::char_type | For all characters C that are to be considered equivalent to c when comparisons are performed without regard to case, then `v.translate_nocase(c) == v.translate_nocase(C).` |
| v.transform(F1, F2) | X::string_type | Returns a sort for the character sequence designated by the iterator [F1, F2] such that the character sequence [G1, G2] sorts before the character sequence [H1, H2] then `v.transform(F1, G2) < v.transform(H1, H2).` |
| v.transform_primary(F1, F2) | X::string_type | Returns a sort for the character sequence designated by the iterator [F1, F2] such that the character sequence [G1, G2] sorts before the character sequence [H1, H2] when character case is not considered then `v.transform_primary(G1, G2) < v.transform_primary(H1, H2).` |
| v.lookup_collatname(F1, F2) | X::string_type | Returns a sequence of characters representing the collating element of the character sequence designated by the iterator range [F1, F2]. Returns an empty string if the sequence is not a valid collating element. |
| v.lookup_classname(F1, F2, b) | X::char_class_type | Converts the character sequence designated by the iterator range [F1, F2] into a value of type that can subsequently be passed to `lookup_classname`. Values returned together; the resulting value represents membership in either of the corresponding character classes. If it is true, the returned bitmask is suitable for matching characters without regard to their case. If the character sequence is not the name of a class recognized by X, the returned shall be independent of the case of the characters in the sequence. |
| v.isctype(c, cl) | bool | Returns `true` if c is a member of one of the character classes designated by `cl`; `false` otherwise. |
| v.value(c, I) | int | Returns the value represented by the digit c in base I if the character c is a valid digit in base I; otherwise returns -1. [Note: The value of I will only be 8, 10, or 16. — end note]
