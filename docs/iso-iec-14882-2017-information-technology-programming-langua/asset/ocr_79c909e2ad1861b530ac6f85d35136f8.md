# ISO/IEC 14882:2017(E)

# 29.7.7.2 glslice_array_assignment

```
void operator=(const valarray<T>&) const;
const glslice_array& operator=(const glslice_array&) const;
```

These assignments have reference semantics, assigning the values of the argument elements to selected elements of the valarray<T> object which the glslice_array refers.

# 29.7.7.3 glslice_array_compound assignment

```
void operator*=(const valarray<T>&) const;
void operator/=(const valarray<T>&) const;
void operator+=(const valarray<T>&) const;
void operator-=(const valarray<T>&) const;
void operator=(const valarray<T>&) const;

void operator*=(const valarray<T>&) const;
void operator<<=(const valarray<T>&) const;
void operator>>=(const valarray<T>&) const;
```

These compounds have reference semantics, applying the indicated operation to the elements of the argument and selected elements of the valarray<T> object which the glslice_array object refers.

# 29.7.7.4 glslice_array_fill_function

```
void operator=(const T&) const;
```

This function has reference semantics, assigning the value of its argument to the elements of the valarray<T> object to which the glslice_array object refers.
