# ISO/IEC 14882:2017(E)

Effects: Erases all the first element from every consecutive group of elements referred to by the iterator i in the range [first + 1, last) for which *i == *(i-1) (for the version of unique with no arguments) and pred(*i, (i - i)) (for the version of unique with a predicate argument) holds. Invalidates only iterators and references to the erased elements.

Throws: Nothing else is thrown by *i == *(i-1) and pred(*i, (i - 1))

Complexity: If the range [first, last) is not empty, except (last - first) - 1 applications of the corresponding predicate, otherwise applications of the predicate.

```
void merge(list& x);
void merge(list& x);
template <class Compare> void merge(list& x, Compare comp);
template <class Compare> void merge(list& x, Compare comp);
```

Requires: comp shall define a strict order (28.7), and both the list and the argument list shall be sorted according to this.

Effects: If (kx != this) does nothing; otherwise merges the two sorted ranges [x.begin(), x.end()) and [kx, end). The result is a range in which the elements will be sorted in non-decreasing order by the order defined by comp; for every iterator i, in the range other than the first, the condition comp(*i, (i - 1)) will be false. Pointers and references to the moved elements of x now become valid. The elements continue to refer to them, but they now behave as iterators into this, not into x.

Stable: (20.5.5.7). If (kx != this) the range [x.begin(), x.end()) is empty then no merges are copied by this operation. The behavior is undefined if get_allocator() =

```
x.get_allocator();
```

Complexity: At most size() * size() - 1 applications of comp if (kx != this); otherwise, no
ap of comp are performed. If an exception is thrown other than a comparison there are no
effect.

```
void reverse() noexcept;
```

Effects: Reverses the order of the elements in the list. Does not affect the validity of iterators and references.

Complexity: Linear time.

```
void sort();
template <class Compare> void sort(Compare comp);
```

Requires: operator< (for the first version) or comp (for the second version) shall define a strict weak\ordering (28.7).

Effects: Sorts the list according to the operator< or a Compare function. If an exception is
thrown, the order of the elements in *this is unspecified. Does not affect the validity of iterators and
references.

Stable: (20.5.5.7).

Complexity: Approximately N log N, where N == size().
