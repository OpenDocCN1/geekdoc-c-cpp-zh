# 23.15.5 Type property queries [meta.unary.prop.query]

1 This clause contains constraints that may be used to query properties of type at compile time.

| Template | Value |
| :--- | :--- |
| template <class T> | alignof(T) |
| struct alignment_of; | Requires: alignof(T) shall be a valid expression (8.3.6) |
| template <class T> struct_size; | If T is an array type, an integer value representing the number of dimensions of T; otherwise, 0. |
| template <class T, unsigned I = 0; | If T is not an array type, or if its rank less than or equal to I, or if I is 0 and T has type "array of unknown bound U", then 0; otherwise, the bound (11.3) of the Ith dimension of T, where index of I is zero-based |

2 Each of these templates shall be a ~Trait (23.15.1) with a base characteristic of integral_size_t, Value.
