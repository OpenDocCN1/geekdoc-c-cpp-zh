# 15.8 Copying and moving class objects

A class object can be copied or moved in two ways: by initialization (15.1, 11.6), including for function argument passing (8.2.2) and for function return (9.6.3) and by assignment (8.18). Conceptually, these two operations are implemented by a copy/move constructor (15.1) and copy/move assignment operator (16.5.3).

A program is ill-formed if the copy/move constructor or the copy/move assignment operator for an object is implicitly-derived and the special member function is not accessible (Clause 14); Note: Copying/moving one object into another using the copy/move constructor or the copy/move assignment operator does not change the layout or size of such element.— end

# 15.8.1 Copy/move constructors

A non-template constructor for class X is a copy constructor if its first parameter is of type X&, const X&, volatile X& and either there are no other parameters or else all other parameters have default arguments (11.3.6). Example: X(const X&) and X(const X&, int=1) are copy constructors.

```
struct X {
X();
X(const X&, int = 1);

X(a);
X(b, 0);
X(c = b);
// calls X(const X&);
// calls X(const X&, int);
// calls X(const X&, int);\ end example
```

A non-template constructor for class X is a move constructor if its first parameter is of type X&&, const X&&, volatile X&& or volatile X&& and either there are no other parameters or else all other parameters have default arguments (11.3.6). Example: Y::Y(Y&&) is a move constructor.

```
struct Y {
Y(Y&);
Y(Y&&);

extern Y f(int);
Y d(Y&&);
Y e = d;
// calls Y(Y&&);
// calls Y(const Y);\ end example
```

Note: All forms of copy/move constructor may be declared for a class. [Example:

```
struct X {
X(const X&);
X(X&&);
X(const X&);
X(const X&&);
};
// OK
// OK, but possibly not sensible; end note
```

Note: If a class X has only a copy constructor with a parameter of type X&, an initializer of type const X or volatile X cannot initialize an object of type (possibly cv-qualified) X. [Example:

```
struct X {
X();
X(X&&);
// default constructor
// copy constructor with a non-const parameter
```
