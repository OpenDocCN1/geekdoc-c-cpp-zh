# ISO/IEC 14882:2017(E)

Table 91 — Unordered associative container requirements (in additi-on to container) (continued)

| Expression | Return type | Assertion/note pre-/post-condition | Complexity |
| :--- | :--- | :--- | :--- |
| a.merge(a2) | void | *Requires: a.get_allocator() == a.get_allocator().* Attempts to extract each element in a2 and insert it into a using the hash function and key equality predicate of a. In containers with unique keys, if there is an element with a key equivalent to the key of an from a2, then that element is not extracted from a2. *Postconditions:* Pointers and references to the transferred elements of a2 refer to those same elements as members of a. Iterators referring to the transferred elements and all iterators referring to elements remaining in a2 will remain valid. *Throws:* Nothing unless the function or key equality predicate throws. | Average case O(N), where N is a2.size(). Worst case O(N*a.size())+N). |
| a.erase(k) | size_type | Erases all elements with key equivalent to k. Returns the number of erased elements. | Average case O(a.count(k)). Worst case O(a.size()). |
| a.erase(q) | iterator | Erases the element pointed to by q. Returns the iterator immediately q prior to the erasure. | Average case O(1), worst case O(a.size()). |
| a.erase(r) | iterator | Erases the element pointed to by r. Returns the iterator immediately r prior to the erasure. | Average case O(1), worst case O(a.size()). |
| a.erase(q1, q2) | iterator | Erases elements in the range [q1, q2]. Returns the iterator immediately following the erased elements prior to the erasure. | Average case linear in distance(q1, q2), worst case O(a.size()). |
| a.clear() | void | Erases all elements in the container. *Postconditions:* a.empty() returns true | Linear in O(a.size()). |
