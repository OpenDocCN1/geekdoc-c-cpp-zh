# 7.9 Floating-point conversions [conv.double]

1 A value of floating-point type can be converted to a prvalue of another floating-point type. If the source value can be exactly represented in the destination type, the result of the conversion is exactly representation. If the source is between two adjacent destination values, the result of the conversion is an implementation-defined choice of either those. Otherwise, the behavior is undefined.

2 The conversions allowed as floating-point promotions are excluded from the set of floating-point conversions.

# 7.11 Pointer conversions

1 A null pointer constant is an integer literal (5.3.2) or a prvalue of type std::nullptr_t. A null pointer constant can be converted to a pointer type; the result is the null pointer value of that type and is distinguishable from every other value of pointer or function type. Such a conversion is called a null conversion. Two null pointer values of the same type should compare equal. The conversion of an integral type can be converted to a pointer to cv qualified-type is a single conversion, and not the sequence of a pointer conversion followed by a qualification (7.5). [Note: The result of a pointer to type std::nullptr_t is not a null pointer value. — end note]

2 A value of "pointer to cv T", where T is an integer type, can be converted to a prvalue of "pointer to void".

A type of "pointer to cv D", where D is a class type, can be converted to a prvalue of "pointer to cv B", where B is a base (Class 13) of D. If B is an inaccessible (Class 4 or 13.2) base class of D, a program that necessitates this conversion is ill-formed. The result of the conversion is the null pointer converted to the null pointer value of the destination type.
