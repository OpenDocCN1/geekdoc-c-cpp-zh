# 30.10.15.4 Copy file

```
bool copy_file(const path& from, const path& to, error_code& ec) noexcept;
bool copy_file(const path& from, const path& to, error_code& ec) none;
```

**Returns:** copy_file(from, to, copy_options=none) if

**Throws:** As specified in 30.10.7.

```
bool copy_file(const path& from, const path& to, copy_options options);
 copy_file(const path& from, const path& to, copy_options options,
error_code& ec) noexcept;
```

**Requires:** At least one element from each option group (30.10.13) is set in options.

Effects: As follows:

+   (4.1) Report a file already exists as specified in 30.10.7

+   (4.1.1) is_regular_file(from) is false, or

+   (4.1.2) exists(to) is true and is_regular_file(to) is false, or

+   (4.1.3) exists(to) is true and equivalent(from, to) is true, or

+   (4.1.4) exists(to) is true and

```
(options & copy_options::skip_existing |
copy_options::overwrite_existing |) == copy_options::none
```

Otherwise, copy the contents and attributes of the file from resolves, to the file it resolves, if:

+   (4.2.1) exists(to) is false, or

+   (4.2.2) (options & copy_options::overwrite_existing) != copy_options::none, or

+   (4.2.3) (options & copy_options::update_existing) != copy_options::none and from is\more recent than to, determined as if by use of the last_write_time function (30.10.15.25).

+   (4.3) Otherwise, no effects.

**Returns:** true if the file was copied, otherwise false. The signature with argument ec returns
false if an error occurs.
