## 16.3.1.1 Call to named function

- 1 Of interest in 16.3.1.1 are only function calls in which the *postfix-expression* ultimately contains a name that denotes one or more functions that may be called. A *postfix-expression*, perhaps nested deeply in parenthese, has one of the following:

  * postfix-expression:
    * postfix-expression -> id-expression
    * postfix-expression -> id-expression
    * primary-expression

These represent syntactic types of function calls: qualified function calls and unqualified function calls where the name is preceded by an -> operator. Since the construct *A->B* is generally called (*A).B, the reference of Clause 16 augments, without loss of order, all member calls can be normalized to the form that use an object and the -> operator. Furthermore, Clause 16 assumes that the *postfix-expression* is the left operand of the -> operator, which has type *cv T'* where T denotes a class T²⁵. Under this assumption, the id-expression in the call is looked up as a member function of T following the rules for looking up names. The argument list is the id-expression in the call augmented by the left operand of the -> operator in the normalized manner, called the member object.

In unqualified function calls, the name is not qualified by an -> operator and has the member function of primary-expression. The name is looked up in the function call following the rules for name lookup (6.4). The function declarations constitute the set of candidate functions each candidate consists of same class T. In (1), the argument list is the same as expression-list in the call. In (2), the argument list is the expression-list augmented by qualified function name. If this keyword (16.2.1) is in scope and refers to class T, or derived class of T, the implicit object is augmented by derived object *(this). If this keyword is not in scope or refers to another class, then the derived object is replaced by the implicit object and overload resolution selects one of the non-static member functions of T, which is ill-formed.
