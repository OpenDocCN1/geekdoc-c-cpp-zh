# 24.3.2.1 basic_string general requirements [string::require]

- 1 If any operation calls size() to exceed max_size(), that operation shall throw an exception object of length_error.
- 2 If any function or operator of basic_string throws an exception, that function or operator shall have no effect.
- 3 In every specialization basic_string<charT, Allocator>, the type allocator_traits<Allocator>::value_type must have the same name as the charT. Every object of basic_string<charT, traits> shall use an object of type Allocator to allocate and free storage for the contained charT objects. The Allocator used shall be obtained as defined in 26.2.1. In every specialization basic_string<charT, Allocator>, the type shall satisfy requirements (24.2), and the traits::char_type must have the same name as the charT.

References, pointers, and iterators to the elements of a basic_string sequence may be invalidated by the uses of basic_string:

- (4.1) as an argument to any standard library function taking a reference to non-const basic_string as an argument.
- (4.2) Calling non-const member functions, except [], at data, front, back, begin, rbegin, and rend.
