# ISO/IEC 14882:2017(E)

(2.2) If *T* is a class type (including unions), its associated classes are the class itself, the class of which it is a member, if any; and its direct and indirect base classes. Its associated namespaces are the innermost namespaces of its associated classes. Furthermore, if *T* is a template specialization, its associated namespaces and classes also include: the namespaces and classes associated with the types of the arguments provided for template parameters (excluding template parameters); the classes of which any template arguments are members; and the classes of which member templates used as template arguments are. *Note: Non-type template arguments do not contribute to the set of associated namespaces.* — *end note*

(2.3) If *T* is an enumeration type, its associated namespace is the innermost namespace of its declaration. If it is a class, its associated class is the member's class; if it has no associated class.

(2.4) If *T* is a pointer or array of *U*, its associated namespaces and classes are those associated with *U*.

(2.5) If *T* is a function type, its associated namespaces and classes are those associated with the function return type and those associated with the return.

(2.6) If *T* is a member function of class *X*, its associated namespaces and classes are those associated with the function return type and return, together with those with *X*.

(2.7) If *T* is a data member of class *X*, its associated namespaces and classes are those associated with the member type together with those with *X*.

If an associated namespace is an inline namespace, its enclosing namespace is also included in the set. If an associated namespace directly contains inline namespaces, those inline namespaces are also included in the set. In addition, the associated namespaces and classes are the union of those associated with each of the members i.e., the classes and namespaces associated with its parameter types and return type. Additionally, if the associated function is named a *template-id*, its associated classes and namespaces also include its *template-arguments* and its *template-namespaces.

*X* be the lookup set produced by unqualified lookup (6.4.1) and *Y* be the lookup set produced by argument lookup (defined below). If *X* contains

+   (3.1) — a declaration of a class member,
(3.2) — *Y* empty is neither a function declaration that is not using a *declaration*, or,
(3.3) — a declaration that is not a function for template

then *Y* is empty. Otherwise *Y* is the set of declarations found in the namespaces associated with the argument types as described below. The set of declarations found by the lookup of name is the union of *X* and *Y*. *Note: The namespaces and classes associated with the argument types can include namespaces and classes already considered by the ordinary lookup.* — *end note* [Example:

```
namespace NS {
class T {
    void f();
    void g(int);
};
NS::T param;
void g(NS::T, float);
int main() {
    f(param);
    extern void g(NS::T, float);
    g(param, 1);
} // OK: calls NS::f; OK: calls g(NS::T, float)
```
