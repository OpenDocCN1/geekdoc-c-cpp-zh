5 In addition, a member function, static data member, a named class or enumeration of class scope; or an unnamed class or enumeration defined in a class-scope declaration that the class or enumeration has the type name for linkage purposes (10.1.3), has the same linkage, if as the name of the class or enumeration, is its member.

The name of a declaration in block scope and the name of a variable by a block scope extern declaration have the same name and linkage. If there is a visible declaration of an entity with linkage having the same name and type, ignoring entities outside the innermost enclosing namespace, the block scope declaration declares that entity and receives the linkage of the previous declaration. Otherwise, if no matching entity is found, the block scope declaration declares that entity and receives the linkage of external linkage. If, within a translation unit, the same entity is declared with both internal and external linkage, the program is ill-formed. [Example:

```
static void f();
static int i = 0; // #1
void g() {
    extern void f(); // internal linkage
    int i; // #2: has no linkage
    extern void f(); // internal linkage
    extern int i; // #3: external linkage, ill-formed
}
```

Without the declaration at #2, the declaration #3 would link with the declaration at #1. Because the declaration with internal linkage is hidden, #3 is given external linkage, making the program ill-formed. — end example]
