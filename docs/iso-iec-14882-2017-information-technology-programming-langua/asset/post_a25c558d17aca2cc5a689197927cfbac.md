
# ISO/IEC 14882:2017(E)

## 29.9.5.11 Incomplete elliptic integral of the first kind [sf.cmath.ellint_1]

```cpp
double ell_1(double k, double phi);
float ell_1(float k, float phi);
long double ell_1(long double k, double phi);
```

Effects: These functions compute the incomplete elliptic integral of the first kind of their respective arguments k and phi (measured in radians).

Returns:

```
$F(k, \phi) = \int_{0}^{\phi} \frac{d\theta}{\sqrt{1-k^2\sin^2\theta}} \quad |k| \le 1$
```

where k is k and $\phi$ is phi.

## 29.9.5.12 Incomplete elliptic integral of the second kind [sf.cmath.ellint_2]

```cpp
double ell_2(double k, double phi);
float ell_2(float k, float phi);
long double ell_2(long double k, double phi);
```

Effects: These functions compute the incomplete elliptic integral of the second kind of their respective arguments k and phi (measured in radians).

Returns:

```
$E(k, \phi) = \int_{0}^{\phi} \sqrt{1-k^2\sin^2\theta} d\theta, \quad |k| \le 1$
```

where k is k and $\phi$ is phi.

## 29.9.5.13 Incomplete elliptic integral of the third kind [sf.cmath.ellint_3]

```cpp
double ell_3(double k, double phi);
float ell_3(float k, float phi);
long double ell_3(long double k, long double nu, double phi);
```

Effects: These functions compute the incomplete elliptic integral of the third kind of their respective arguments k, nu, and phi (measured in radians).

Returns:

```
$$\Pi(\nu, k, \phi) = \int_{0}^{\phi} \frac{d\theta}{(1-\nu^2\sin^2\theta)\sqrt{1-k^2\sin^2\theta}}, \quad |k| \le 1$$
```

where $\nu$ is nu, k is k, and $\phi$ is phi.

## 29.9.5.14 Exponential integral [sf.cmath.expint]

```cpp
double expint(double x);
float expint(float x);
long double expint(long double x);
```

Effects: These functions compute the exponential integral of their respective arguments x.

Returns:

```
$Ei(x) = \int_{-\infty}^{x} \frac{e^{-t}}{t} dt$
```

where $x$ is x.

## 29.9.5.15 Hermite polynomials [sf.cmath.hermite]

```cpp
double hermite(unsigned n, double x);
float hermite(unsigned n, float x);
long double hermite(unsigned n, long x);
```

- Effects: These functions compute the Hermite polynomials of their respective arguments n and x.
- Returns:

$H_n(x) = (-1)^n e^{x^2} \frac{d^n}{dx^n} e^{-x^2}$

where n is n and x is x.
- Remarks: The calling of each of these functions is implementation-defined if n >= 128.

## 29.9.5.16 Laguerre polynomials [sf.cmath.laguerre]

```cpp
double laguerre(unsigned n, double x);
float laguerre(unsigned n, float x);
long double laguerre(unsigned n, long x);
```

- Effects: These functions compute the Laguerre polynomials of their respective arguments n and x.
- Returns:

$L_n(x) = \frac{e^x}{n!} \frac{d^n}{dx^n} (x^n e^{-x})$, for $x \ge 0$

where n is n and x is x.
- Remarks: The calling of each of these functions is implementation-defined if n >= 128.

## 29.9.5.17 Legendre polynomials [sf.cmath.legendre]

```cpp
double legendre(unsigned n, double x);
float legendre(unsigned n, float x);
long double legendre(unsigned n, long x);
```

- Effects: These functions compute the Legendre polynomials of their respective arguments l and x.
- Returns:

$P_l(x) = \frac{1}{2^l!} \frac{d^l}{dx^l}(x^2-1)^l$, for $|x| \le 1$

where l is l and x is x.
- Remarks: The calling of each of these functions is implementation-defined if l >= 128.

## 29.9.5.18 Riemann zeta function [sf.cmath.emann_zeta]

```cpp
double riemann_zeta(double x);
float riemann_zeta(float x);
long double riemann_zeta(long x);
```

- Effects: These functions compute the Riemann zeta function of their respective arguments x.
- Returns:

$$\zeta(x) = \sum_{k=1}^{\infty} k^{-x}, \text{ for } x > 1$$
$$\sum_{k=1}^{\infty} (-1)^{k-1} k^{-x}, \text{ for } 0 < x \le 1$$
$$\zeta(x) = 2^{x-1}\pi^{x-1}\sin\left(\frac{\pi x}{2}\right)\Gamma(1-x)\zeta(1-x), \text{ for } x < 0$$

where $x$ is x.

## 29.9.5.19 Spherical Bessel functions of the first kind

```cpp
double spb_bessel(unsigned n, double x);
float spb_bessel(unsigned n, float x);
long double spb_bessel(unsigned n, long x);
```

- Effects: These functions compute the spherical Bessel functions of the first kind of their respective arguments n and x.
- Returns:

$j_n(x) = (\frac{\pi}{2x})^{1/2}J_{n+1/2}(x)$, for $x \ge 0$

where $n$ is n and $x$ is x.
- Remarks: The effect of calling each of these functions is implementation-defined if n >= 128.

## 29.9.5.20 Spherical associated Legendre functions

```cpp
double spb_legendre(unsigned l, unsigned m, double theta);
float spb_legendre(unsigned l, unsigned m, float theta);
long double spb_legendre(unsigned l, unsigned m, long theta);
```

- Effects: These functions compute the spherical associated Legendre functions of their respective arguments l, m, and theta (measured in radians).
- Returns:

$Y_l^m(\theta)$

where $Y_l^m(\theta) = (-1)^m \sqrt{\frac{(2l+1)}{4\pi(l-m)!}} P_l^m(\cos\theta)e^{im\phi}$, for $|m| \le l$

where $l$ and $m$ are m and $\theta$ is theta.
- Remarks: The effect of calling each of these functions is implementation-defined if l >= 128.

## 29.9.5.21 Spherical Neumann functions

```cpp
double spb_neumann(unsigned n, double x);
float spb_neumann(unsigned n, float x);
long double spb_neumann(unsigned n, long x);
```

- Effects: These functions compute the spherical Neumann functions, also known as the Bessel functions of the second kind, and respect arguments n and x.
- Returns:

$n_n(x) = (\frac{\pi}{2x})^{1/2}N_{n+1/2}(x)$, for $x > 0$

where $n$ is n and $x$ is x.
- Remarks: The effect of calling each of these functions is implementation-defined if n >= 128.

## 30.2 iostreams requirements [iostream.requirements]

### 30.2.1 Imbue itations [iostream.limits.imbue]

1 No function declared in Clause 30 except for ios_base::imbue and basic_streambuf::imbue causes any instance of basic_streambuf to be called. If any user function calls basic_ios, the behavior is undefined.

### 30.2.2 Positioning type limitations [iostream.limits.pos]

1 The Classes of 30 with traits:pos and type:off are stream and respectively.
2 In Classes of 30, a template parameter charT represents a member of the set of types containing char, wchar_t, and any implementation-defined character types on which the stream can be instantiated.

### 30.2.3 Thread safety [iostream.threadsafety]

1 Concurrent access to a stream object (30.8, 30.9), stream buffer (30.6) or C Library stream (30.11) by multiple threads results in a data race (4.7) unless otherwise specified (30.4). [Note: Data race result in undefined behavior (4.7)]
2 If one thread makes a call to a stream that writes a value to a stream, and as another thread results in the value from the stream through a library call sync that this does not result in a data race, then a's write synchronizes with b's.
