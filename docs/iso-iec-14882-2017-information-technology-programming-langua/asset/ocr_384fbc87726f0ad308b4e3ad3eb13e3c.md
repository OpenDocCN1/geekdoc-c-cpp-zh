(1.2) The controlled output sequence can be not writable.

(1.3) The controlled sequences can be associated with the contents of other representations for character sequences, such as external files.

(1.5) The controlled sequences can impose limitations on how the program can read characters from a sequence, write characters to a sequence, put characters into an input sequence, or alter the stream position.

2 Each sequence is characterized by three pointers, if non-null, all point to the same `char` array. The array represents, at any moment, a (sub)sequence of characters from the sequence. Operations performed on a sequence alter the values stored in that sequence, perform reads and writes to or from associated sequences, alter the "stream position" and conversion state as needed to maintain this subsequence relationship. The three pointers are:

+   (2.2) the next pointer, or element address that is a candidate for reading or writing (called `xnext` here);

+   (2.3) the end pointer, or first element address the end of the array (called `zend` here).

3 The following semantic constraints shall apply for any set of three pointers for a sequence, using the pointers given names above:

+   (3.1) If `xnext` is not a null pointer, then `xbeg` and `xbeg` shall also be non-null pointers into the `char` array, as described above; otherwise, `xbeg` and `zend` shall also be null.

+   (3.2) If `xnext` is not a null pointer and `xnext < xbeg` for an output sequence, then a *write* position is available. In this case, `xnext` shall be assigned as the element to write (to put, or to store a character value, into the sequence);

+   (3.3) If `xnext` is not a null pointer and `zend < xnext` for an input sequence, then a *pushback* position is available. In this case, `xnext[-1]` shall have a defined value and is the next (preceding) element to store a character that is put into the input sequence.

+   (3.4) If `xnext` is not a null pointer and `xbeg < z` for an input sequence, then a *read* position is available. In this case, `xnext` shall have a defined value and is the next element to read (to get, or obtain a character value, from the sequence);
