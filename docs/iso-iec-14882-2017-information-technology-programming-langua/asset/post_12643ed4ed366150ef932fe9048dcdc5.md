- Effects: Constructs an object of complex number.
- Postconditions: real() && imag() == im.

## 29.5.5 complex member operators [complex.member.ops]

```cpp
complex<T> operator=(const T& rhs);
- Effects: Assigns the value rhs to the real part of the complex value *this and stores the result in real part of *this, leaving the imaginary part unchanged.

complex<T> operator-(const T& rhs);
- Effects: Subtracts the value rhs from the real part of the complex value *this and stores the result in real part of *this, leaving the imaginary part unchanged.

complex<T> operator*(const T& rhs);
- Effects: Multiplies the value rhs by the complex value *this and stores the result in *this.

complex<T> operator/(const T& rhs);
- Effects: Divides the value rhs into the complex value *this and stores the result in *this.

template<class X> complex<T>& operator+=(const complex<X>& rhs);
- Effects: Adds the value rhs to the complex value *this and stores the sum in *this.
- Returns: *this.

template<class X> complex<T>& operator-=(const complex<X>& rhs);
- Effects: Subtracts the value rhs from the complex value *this and stores the difference in *this.
- Returns: *this.

template<class X> complex<T>& operator*=(const complex<X>& rhs);
- Effects: Multiplies the value rhs by the complex value *this and stores the product in *this.
- Returns: *this.

template<class X> complex<T>& operator/=(const complex<X>& rhs);
- Effects: Divides the value rhs into the complex value *this and stores the quotient in *this.
- Returns: *this.
```
