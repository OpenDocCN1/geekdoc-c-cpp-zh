These — end note.]

+   2 [Note: This Clause does not cover concepts that affect only a non-static data type. Language concepts are introduced in the relevant Clauses. — end note]

+   3 An entity is a value, object, reference, function, enumerator, type, class member, bit-field, template, namespace, or parameter pack.

+   4 A name is a use of an entity introduced by an identifier(5.10.2), operator-function(16.5), literal-operator(16.5.8), conversion-function(15.3.2), or template-id(17.2) that denotes an entity or label(9.6.4, 9.1).

+   5 Every name that denotes an entity is introduced by a non-static data member or Every label is introduced by a goto statement(9.6.4) or a labeled-statement(9.1).

+   6 A variable is introduced by the declaration of a reference or any non-static data member or an object. The variable's name is called name lookup(6.4).

+   7 Some names denote types or templates. In general, whenever a name is encountered it is necessary to determine whether name denotes one of these entities before continuing to process the program that it contains. The process that determines this is called name lookup(6.4).

+   8 Two names are the same

+   (8.1) they are identifiers composed of a single part of the character sequence,
(8.2) they are operator-function-ids formed with the same operator, or
(8.3) they are conversion-function-ids formed with the same type, or
(8.4) they are names of literal operators that refer to the same class, function, or variable(17.4), or
(8.5) they are the names of literal operators(16.5.8) formed with the same literal identifier.

+   9 A name used in more than one translation unit can potentially refer to the same entity in these translation units upon the linkage(6.5) of the name specified in each translation unit.
