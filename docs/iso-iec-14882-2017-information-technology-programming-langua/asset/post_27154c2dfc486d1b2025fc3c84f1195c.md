## 24.3.3.2 operator==
```cpp

bool operator==(const basic_string<charT, traits, Allocator>& lhs,
               const basic_string<charT, traits, Allocator>& rhs) noexcept;
```

Returns: `rhs == lhs`.

```cpp
template<class charT, class traits, class Allocator>
bool operator==(const charT* lhs, const basic_string<charT, traits, Allocator>& rhs);
```

Returns: `rhs == lhs`.

```cpp
template<class charT, class traits, class Allocator>
bool operator==(const basic_string<charT, traits, Allocator>& lhs, const charT* rhs);
```

Requires: ptr to an array of at least `traits::length(rhs) + 1` elements of charT.

Returns: `lhs.compare(rhs) == 0`.

## 24.3.3.9 Inserters and extractors
```cpp
template<class charT, class traits, class Allocator>
basic_istream<charT, traits>&
operator>>(basic_istream<charT, traits>&& is, basic_string<charT, traits, Allocator>&& str);
```

Effects as a formatted input function (3.4.2.1). After constructing a sentry object, if the sentry converts to true, calls sentry.erase() and extracts characters from is and appends to them as if calling sentry.append(i). If is.width() is greater than zero, the maximum number n of characters is appended until str.max_size(). Characters are extracted and appended until one of the following occurs:

- n characters are stored;
- end-of-file occurs on the input sequence;
- isspace(c, is.geteof()) is true for the next available input character c.

After the last character (if) is extracted, is.width() is zero and the sentry object is destroyed.

If the function extracts no characters, it calls is.setstate(ios::failbit), which may throw ios_failure(30.5.5.4).

Returns: is.
