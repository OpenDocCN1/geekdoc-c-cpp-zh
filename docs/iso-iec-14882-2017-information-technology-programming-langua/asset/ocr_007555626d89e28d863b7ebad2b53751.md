# ISO/IEC 14882:2017(E)

```
constexpr const T& value() const;
constexpr T& value() &;
```

Effects: Equivalent to:

```
return (*this) ? *val : throw bad_optional_access();
```

```
constexpr T& value() &&;
constexpr const T& value() const;
```

Effects: Equivalent to:

```
return (*this) ? std::move(*val) : throw bad_optional_access();
```

```
template <class U> constexpr T value_or(U&& v) const;
```

Effects: Equivalent to:

```
return (*this) ? *this : static_cast<T>(std::optional<U>(v));
```

Remarks: If is_copy_constructible && is_convertible<U&, T> is false, the program is ill-formed.

```
template <class U> constexpr T value_or(U&& v) const;
```

Effects: Equivalent to:

```
return (*this) ? std::move(*this) : static_cast<T>(std::optional<U>(v));
```

Remarks: If is_move_constructible && is_convertible<U&, T> is false, the program is ill-formed.

# 23.6.3.6 Modifiers

```
void reset() noexcept;
```

+   1 Effects: If *this contains a value, calls-T::-() to destroy the contained value; otherwise no effect.

+   2 Postconditions: If *this does not contain a value.

# 23.6.4 No-value indicator

```
struct nullptr_t {see below};
inline constexpr nullptr_t nullptr(unspecified_t);
```

+   1 struct nullptr_t is an empty structure used as a unique type to indicate the state of not containing a optional value. In particular, optional<T> has a constructor with nullptr_t as a single argument; this indicates that an optional object not containing a value shall be constructed.

+   2 nullptr_t does not have a default constructor or an initializer-list constructor, and shall not be an aggregate.

# 23.6.5 Bad_optional_access

```
class bad_optional_access : public exception {
public:
bad_optional_access();
};
```

+   1 The bad_optional_access defines the type of objects thrown as exceptions to report the situation when an attempt is made to access the value of an optional object that does not contain a value.

```
bad_optional_access();
```

Effects: Constructs an object of class bad_optional_access.
