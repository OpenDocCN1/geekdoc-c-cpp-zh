# ISO/IEC 14882:2017(E)

2 list provides three splice operations that destructively move elements from one to another. The behavior of splice operations is undefined if get_allocator() != x.get_allocator().

```
void splice(const_iterator position, list& x);
void splice(const_iterator position, list&& x);
```

3 Requires: x != this.

4 Effects: Inserts the contents of x by position and x becomes empty. Pointers and references to the moved elements of x now refer to the same elements as members of *this. Iterators referring to the moved elements will continue to refer to their elements, but they behave as Iterators into *this, not into x.

5 Throws: Nothing.

6 Complexity: Constant time.

```
void splice(const_iterator position, list& x, const_iterator i);
void splice(const_iterator position, list&& x, const_iterator i);
```

7 Requires: i is a dereferable iterator.

8 Effects: Inserts an element pointed to i by list x and removes the element from x. The result is unchanged if i == position or i == *1. Pointers and references to *i continue to refer to this same element as member of *this. Iterators referring to *i (including itself) continue to refer to the same element, but behave as Iterators into *this, not into x.

9 Throws: Nothing.

10 Complexity: Constant time.

```
void splice(const_iterator position, list& x, const_iterator first, const_iterator last);
void splice(const_iterator position, list&& x, const_iterator first, const_iterator last);
```

11 Requires: [first, last) is a valid range. The program has undefined behavior if position is an iterator in the range [first, last).

12 Effects: Inserts elements in the range [first, last) before position and removes the elements from x. Pointers and references to the moved elements of x now refer to those same elements as members of *this. Iterators referring to the moved elements will continue to refer to their elements, but they behave as Iterators into *this, not into x.

13 Throws: Nothing if fx != this; otherwise, linear time.

```
void remove<class Predicate> void remove_if(Predicate pred);
```

15 Effects: Erases all the elements in the list referred by iterator i for which the following conditions hold: *i == value, pred(*i) != false. Invalidates the iterators and refers to the erased elements.

16 Throws: Unless an exception is thrown by *i == value or pred(*i) != false.

17 Remarks: Stable (20.5.5.7).

18 Complexity: Exactly size() of the corresponding predicate.
