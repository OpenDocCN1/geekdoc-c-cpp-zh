# 11.6.4 List-initialization [dcl.init.list]

+ 1 List-initialization is initialization of an object or reference from a braced-list. Such an initializer is called an initializer list, and the comma-separated initializer-clauses of the list are called the elements of the initializer list. The initializer may be empty. List-initialization can occur in direct-initialization or copy-initialization contexts; list-initialization in a direct-initialization context is called direct-list-initialization and list-initialization in a copy-initialization context is called copy-list-initialization. [Note: List-initialization can be used

3 List-initialization of an object or reference of type T is defined as:

- (3.1) If T is a character array and the initializer list has a single element of type U, where U is T or a class derived from T, the object is initialized from that element (by copy-initialization for copy-list-initialization, or by direct-initialization for direct-list-initialization).
- (3.2) Otherwise, if T is a character array and the initializer list has a single element that is an appropriately-typed literal (11.6.2), initialization is performed in that section.
- (3.3) Otherwise, if T is aggregate, aggregate initialization is performed (11.6.1).

```cpp
double a[] = { 1, 2 }; // OK
int a[] = { 1, 2 }; // narrowing
struct S2 {
  int m1;
  double m2, m3;
};
s2 = { 1, 2, 3 }; // OK
s2 = { 1.0, 3 }; // narrowing
s2 = {}; // OK: default-initialized
```
- (3.4) Otherwise, if the initializer list has no elements and T is a class type with a default constructor, the object is value-initialized.
- (3.5) Otherwise, if T is a specialization of std::initializer_list<E>, the object is described below.
- (3.6) Otherwise, if T is a class type, constructors are considered. The applicable constructors are enumerated and the best one is chosen through overload resolution (16.3,16.3.1). If a narrowing conversion (see below) is required to convert any of the arguments, the program is ill-formed.

```cpp

S s2 = { 1, 2, 3 }; // invoke #2
S s3 = { }; // invoke #3
```
end example
