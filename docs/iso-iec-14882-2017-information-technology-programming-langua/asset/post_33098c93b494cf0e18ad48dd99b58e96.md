# 17.8.3 Overload resolution

1 A function can be overloaded by (non-template) functions of its name or by (other) function templates of the same name. When a call to name is written (explicitly, or using the operator notation) argument deduction (17.8.2) and checking of any explicit template argument (17.3) are performed for each function template to find the argument values (if any) can be deduced with that function to instantiate a template specialization that can be invoked with the calls. For each call, if argument deduction and checking succeeds, the template-arguments (deduced and or explicit) are used to synthesize a single function template specialization which is added to the candidate functions to be used in overload resolution. If, for a given function template, no specialization can be deduced, then no candidate functions exist for that template. The complete set of candidate functions includes all the synthesized declarations and all of the non-template overloaded functions of the same name. The remainder of overload resolution, the synthesized declarations are treated like any other functions

# 17.9 Deduction guides [temp.deduct.guide]

Deductions are made when a template-name appears as a type for a deduced class template argument (10.1.7.5). Deductions are not found by lookup. When performing class template argument deduction (16.3.1.8), deduction guides for the class template are considered.

```cpp
deduction-guide:
explicit-type template-name (parameter-declaration-clause) -> simple-template-id;
```

+ 2 [Example:

```cpp

struct S {

template<class U>
S(U) -> S<typename U::type>;
