
## 31 Regular expressions library

### 31.1 General

+ 1 This Clause describes components that C++ programs may use to perform operations involving regular expression matching and searching.

+ 2 The following subclasses describe a basic regular expression class template and its traits that can handle char-like (24.1) template elements, two specializations of this class template that handle sequences of char and wchar_t, a class template that handles the result of a regular expression match, a series of algorithms that allow a character sequence to be operated upon by a regular expression, and two iterators for enumerating regular expression matches, as described in Table 128.

## 31.2 Definitions

+ 1 The following definitions shall apply to this Clause:

### 31.2.1 collating element

a sequence of one or more characters within the current locale as if they were a single character.

### 31.2.2 finite state machine

an unspecified data structure that is used to represent a regular expression, and which permits matches against the regular expression to be obtained.

### 31.2.3 format specifier

a sequence of one or more characters that is to be replaced with some part of a regular expression match.

### 31.2.4 matched

a sequence of zero or more characters is matched by a regular expression when the characters in the sequence correspond to a sequence of characters defined by the pattern.

### 31.2.5 [defns.regex.primary.equivalence]

primary equivalence class
a set of one or more characters that share the same primary sort key: that is the sort weighting that depends only upon character shape, and not accents, case, or locale specific tailorings.

### 31.2.6 [defns.regex.regular.expression]

regular expression
a pattern that selects strings from a set of character strings.

### 31.2.7 [defns.regex.subexpression]

sub-expression
a subset of a regular expression that has been marked by parenthesis.

## 31.3 Requirements [re.req]

+ 1 This subclass defines requirements on classes representing regular expression. [Note: The class template traits, defined in Clause 31.7, satisfies these requirements. — end note]

2 The class template basic_regex, defined in Clause 31.8, defines a set of related traits and functions to complete the definition of its semantics. These types and functions are provided as a set of member typenames and functions in the template parameters traits used by the basic_regex class template. This subclass defines the semantics of these.

3 To specialize class template basic_regex for a container CharT and its related expression traits, use basic_regex<CharT>.
