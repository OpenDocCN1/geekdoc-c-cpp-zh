# ISO/IEC 14882:2017(E)

```
bp->vf1();                          // calls Derived::vf1()
bp->vf2();                          // calls Base::vf2()
bp->f();                           // calls Base::f() (not virtual)
B* p = bp->vf4();                   // calls Derived::pf() and converts the
                                               result to B*

Derived* dp = &d;                                // calls Derived::pf() and does not
D* q = dp->vf4();                    // convert the result to B*

dp->vf2();                         // ill-formed: argument mismatch
}
```

[Note: The interpretation of a virtual function depends on the type of the object for which it is called (the dynamic type), whereas the interpretation of a non-virtual member function depends only on the type of the pointer or reference denoting that (the static type) (8.2.2). — end note]

[Note: The virtual specifies membership, so a virtual function cannot be a non-member (10.1.2) function. No virtual function can be a static member, since a virtual function calls on a specific object for determining which to invoke. A virtual function declared in one class can be declared a friend in another class. — end note]

A virtual function declared in a class shall be declared, or declared pure (13.4) in that class, or both; no diagnostic is required (6.2).

Example: Here are some of virtual functions with multiple base classes:

```
struct A {
    virtual void f0();
};

struct B1 : A {\                   // non-virtual derivation
    void f0();
};

struct B2 : A {
    void f0();
};

struct D : B1, B2 {\               // D has two separate A subobjects
};

void foo() {
    D d;
    // A* b = &d; // would be ill-formed: ambiguous
    B1* bp = &d;
    A* ap = bp;
    D* dp = &d;

    ap->f();                         // calls D::B1::f
    dp->f();                         // ill-formed: ambiguous
}

In class D above there are two occurrences of class A and hence two occurrences of the virtual member
function A::f. The final overrider of B1::A::f is B1:::f and the final overrider of B2::A::f is B2:::f. — end
example]
```
