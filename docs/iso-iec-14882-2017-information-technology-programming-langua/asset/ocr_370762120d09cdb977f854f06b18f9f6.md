# ISO/IEC 14882:2017(E)

# 30 Input/output library

# 30.1 General

1 This Clause describes components that C++ programs may use to perform input/output operations.

2 The following subclauses describe requirements for stream parameters, and components for forward declarations of iostream, predefined iostream objects, base classes, buffering, stream formatting and manipulators, string streams, and file streams, as summarized in Table 106.

| Subclass | Header(s) |
|---|---|
| 30.2 | Requirements | <iosfwd> |
| 30.3 | Forward declarations | <iostream> |
| 30.4 | Standard iostream objects | <iostream> |
| 30.5 | iostream base classes | <ios> |
| 30.6 | Stream buffers | <strebuf> |
| 30.7 | Formatting and manipulators | <iostream>, <iomanip> |
| 30.8 | String streams | <iostream> |
| 30.9 | File streams | <fstream> |
| 30.10 | File systems | <filesystem> |
| 30.11 | C files | <cctype>, <cint> |
