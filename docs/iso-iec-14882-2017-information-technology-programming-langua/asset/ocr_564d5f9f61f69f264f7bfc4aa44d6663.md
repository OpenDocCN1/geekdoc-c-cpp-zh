7 The replacement of explicit declarations for class templates, class templates, variable templates, member functions of class templates, static data members of class templates, member classes of class templates, member enumerations of class templates, static member templates of class templates, member functions of templates of class templates, member members of templates of class templates, member functions of non-template classes, static data members of non-template classes, member functions of non-template templates, etc., and the placement of partial specialization declarations of class templates, variable templates, member classes of non-template templates, member functions of non-template templates, templates of class templates, etc., can affect whether a program is well-formed according to the relative positioning of the explicit declarations and their points of instantiation in the translation unit it will compile. When writing a specialization, be careful about its location; or to make it compile as its kind to itself instantiation.

8 A template explicit specialization is in the namespace in which the template was defined. [Example:

```
namespace N {
template<T> class X { /* ... */ };
template<T> class Y { /* ... */ };
template<T> class X<int> { /* ... */ }; // OK: specialization in same namespace
template<T> class Y<double>; // forward-declare intent to specialize for double
}

template<T> class N::Y<double> { /* ... */ }; // OK: specialization in enclosing namespace
template<T> class N::Y<short> { /* ... */ }; // OK: specialization in enclosing namespace
end example]
```
