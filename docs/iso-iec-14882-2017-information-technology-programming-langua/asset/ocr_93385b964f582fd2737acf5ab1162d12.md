14 Reading an object by a volatile givalue (6.10), calling a library I/O function, or a function that does any of these operations are all side effects, which are changes in the state of the execution. Evaluation of an expression (or a subexpression) in general includes both value computation (determining the identity of an object for evaluation and fetching a value previously assigned to it for object evaluation) and initialization of side effects. When a call to a library I/O function returns access to a volatile givalue the side effect is considered complete, even though some effects implied by the call (such as the I/O itself) or the volatile access may not have completed.

15 Sequenced is an asymmetric, pair-wise relation between evaluations caused by a single thread (4.7), which induces a order among evaluations. Given any two evaluations A and B, if A is sequenced before B (or, equivalently, B is sequenced before A), then the evaluation of A shall precede the evaluation of B. If A is not sequenced before B, then A and B are indeterminately sequenced. The evaluation of subexpressions can overlap; if A and B are indeterminately sequenced either A is sequenced before B or B is sequenced before A, but it is specified.—end note. An expression X is to be sequenced before an expression Y if every value computation and side effect associated with the expression X is sequenced before every value computation and side effect associated with the expression Y.

16 Every value computation and side effect associated with a full-expression is evaluated before every value computation and side effect associated with the next full-expression to be evaluated.
