# ISO/IEC 14882:2017(E)

+   10 Effects: Inserts elements into the range (first, last) and removes the elements from x. Pointers and references to the moved elements of x now refer to those same elements as members of *this. Iterators referring to the moved elements will continue to their elements, but they behave as iterators into *this, not in x.

+   11 Complexity: O(distance(first, last))

```
void remove(const T& value);
template <class Predicate> void remove_if(Predicate pred);
```

+   12 Effects: Erases all the elements in the list referred to by list i for which the following conditions hold: *i == value (remove(i)), pred(*i) is true (for remove_if(i)). Invalidates the iterators and references to the erased elements.

+   13 Throws: Nothing unless an exception is thrown by the equality comparison or the predicate.

+   14 Remarks: Stable (20.5.5.7).

+   15 Complexity: Exactly(distance(begin(), end())) applications of the corresponding predicate.

```
void unique();
template <class BinaryPredicate> void unique(BinaryPredicate pred);
```

+   16 Effects: Erases all but the first from every consecutive group of elements referred to by the iterator in the range [first, last) for which i == (i-1) (for the version with no arguments) or pred(*i, i-1) (for the version with a predicate holds). Invalidates the iterators and references to the erased elements.

+   17 Throws: Nothing unless an exception is thrown by the equality comparison or the predicate.

+   18 Complexity: If the range [first, last) is not empty, (last - first) - 1 applications of the corresponding predicate, otherwise no of the predicate.

```
void merge(forward_list& x, forward_list& y);
template <class Comp> void merge(forward_list& x, Comp comp);
template <class Comp> void merge(forward_list& x, Comp comp);
```

+   19 Requires: The merged sorted ranges [begin(), end()) and [x.begin(), x.end()) of *this and x are both sorted according to ordering. get_allocator() = x.get_allocator().

+   20 Effects: The merged sorted ranges [begin(), end()) have no effects. If an exception is thrown other than by a comparison then no pointers and references to the moved elements of x now refer to those same elements as *this. Iterators referring to the moved elements will continue to their elements, but they behave as iterators into *this, not in x.

+   21 Remarks: Stable (20.5.5.7), The behavior is undefined if get_allocator() != x.get_allocator().

+   22 Complexity: At most distance(begin(), end()) + distance(x.begin(), x.end()) - 1-isons.

```
void sort();
template <class Comp> void sort(Comp comp);
```

+   24 Effects: Sorts the list according to the operator or the comp function. If an exception is thrown, the order of elements in *this is unspecified. Does not affect the validity of iterators and references.
