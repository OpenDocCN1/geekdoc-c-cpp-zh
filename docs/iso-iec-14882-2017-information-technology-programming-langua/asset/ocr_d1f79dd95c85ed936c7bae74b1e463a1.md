+   Note: Conversions of expression of array type are discussed in 7.2. Objects of array types cannot be
modified, see 6.10. — end note.

+   Note: Except where E1[E2] is identical to *(E1+(E2)) (8.2.1), the subscript operator [] is interpreted
a way that if E1 is an array and E2 an integer, then E1[E2] refers to the E2th member of E1. Therefore, its
asymmetric aspect, assignment is a commutative operation. — end note

+   Note: A consistent rule is followed for multidimensional arrays. If E is an n-dimensional array of rank
i j×...×k, then E appearing in an expression that is subject to the array-to-pointer conversion (7.2)
is converted to a pointer to an (n−1)-dimensional array with rank j×...×k. If the * operator,
explicitly or implicitly as an array is applied, the result is the pointed-to
(n−1) dimensional array, which is immediately converted to a pointer. Example:
int x3d[3];

Here x is a 3×5 array of integers. When x appears in an expression, it is converted to a pointer to the first
of its three-dimensional array of integers. In the expression x[i] which is equivalent to *(x+i), x is first
converted to a pointer as described; then x+i is converted to the type of x, which involves multiplying i by
the length of the pointer. The results are added and indirection applied to yield an array of (five integers), which in turn is converted to a pointer to the first
of integers. If there is another subscript the same argument applies again; this time the result is an integer.
