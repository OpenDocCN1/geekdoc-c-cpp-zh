# 8.6 Multiplicative operators

+   1. The multiplicative operators *, /, and % group left-to-right.
```
plicative-expression:
  multiplicative-expression
  multiplicative-expression * multiplicative-expression
  multiplicative-expression / multiplicative-expression
  multiplicative-expression % multiplicative-expression
```

+   2. The operands of * and / shall have arithmetic or unscoped enumeration type; the operands of % shall have integral or unscoped enumeration type. The usual arithmetic operations are performed on the operands and determine the type of the result.

+   3. The binary * operator indicates multiplication.

+   4. The / operator yields the quotient, and the binary % operator yields the remainder from the division of the first expression. If the second operand of / % is zero the behavior is undefined. If integral operands / operator yields the algebraic quotient with functional part discarded; if the quotient (a/b)*b + a%b is equal to a; the behavior of both a/b and a%b is undefined.

# 8.7 Additive operators

+   1. The additive operators + and group left-to-right. The usual arithmetic operations are performed for operands of arithmetic or enumeration type.
```
additive-expression:
  multiplicative-expression
  additive-expression + multiplicative-expression
  additive-expression - multiplicative-expression
```
