# 25.4.1.1.2 virtual functions [locale.ctype.virtuals]

```
bool do_is(mask, charT c) const;
const charT* do_is(const charT* low, const charT* high, mask* vec) const;
```

Effects: Converts a character or sequence of characters. For each argument, identifies a value M of ctype_base:mask; the second form identifies a value M of ctype_base:mask for *p (where low <= p && p < high), and into vec[p - low].

2 Returns: The first form returns the result of the expression (M & m) != 0; true if the character has the characteristics. The second form returns high.

```
const charT* do_scan_is(mask m, const charT* low, const charT* high) const;
```
