# ISO/IEC 14882:2017(E)

# 17.7 Template instantiation and specialization

The act of instantiating a function, a class, a class template or a member template is referred to as template instantiation.

A function instantiated from a template function is called an instantiated function. A class instantiated from a class template is called an instantiated class. A member function, a member class, a member enumeration, or a static data member of a class template instantiated the member definition of the class template is called, respectively, an instantiated function, member class, member enumeration, or static member. A member instantiated from a member function is called an instantiated member function. A class instantiated from a member template is called an instantiated member class.

An explicit specialization may be declared for a function, a class template, a member of a class template or a member template. An explicit specialization is declared using `template<>`. In an explicit specialization declaration for a class template, a class template or a member template the name of the class that explicitly specialized shall be a simple-template-id. In the explicit specialization declaration for a template function or a member function the name of the function template explicitly specialized may be a-template-id. Example:

```
template<class T> struct A {
    static int x;
};

template<class U> void g() {

template<> struct A<double> {}; // specialization for T = double
template<> struct A<int> {}; // specialization for T = int
template<> void g(char) { // specialization for U = char
    U; // U is deduced from the parameter type
}
template<class T> void gint(int t) {
template<> int A<char>*x = int; // specialization for T = char

template<class T> struct B {
    static int x;
};
template<class T> int B<T>::x = 1;
// end example-
```

An instantiated template can either be explicitly instantiated (17.7.2) for a given argument list or be explicitly instantiated. A specialization is a class, function or member that is either instantiated or explicitly specialized (17.7.3).

For a given class and a given set of template-arguments,

+   an explicit instantiation definition shall appear at most once in a program,

+   an explicit specialization shall be defined at most once in a program (according to 6.2), and

+   both an explicit instantiation and a declaration of an explicit specialization shall not appear in a program unless the explicit instantiation follows a declaration of the explicit specialization.

An implementation is not required to diagnose a violation of this rule.

Each template specialization instantiated from a template has its own copy of static members. Example:

```
template<class T> class X {
    static T s;
};
template<class T> T X<T>::s = 0;
X<int> aa;
```
