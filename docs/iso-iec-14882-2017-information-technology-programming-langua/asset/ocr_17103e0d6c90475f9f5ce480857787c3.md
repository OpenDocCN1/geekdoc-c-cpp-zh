# 15.3 Conversions [class.conv]

+   Type conversions of class objects can be defined by constructors and conversion functions. These conversions are user-defined conversions and are used for implicit type conversions (Clause 7), for explicit access control rules (Clause 14). Access control obeys the access control rules (8.4, 8.2.9).

+   User-defined conversions are applied only when they are unambiguous (13.2, 15.3.2). Conversions obey the order of after ambiguity resolution (6.4).

> [Note: See 16.3 for the use of conversions in function calls as well as examples below. — note

+   At most one user-defined (constructor or conversion function) is implicitly applied to a single value. — Example:
```cpp
struct X {
  operator int();
};
struct Y {
  operator X();
};
Y a;
int b = a;
int c = X(a);
// error, a.operatorX().operator int() not tried
// OK: a.operatorX().operator int()
```
