# ISO/IEC 14882:2017(E)

# 4.2 Structure of this document

+   1 5 through 19 describe the C++ programming language. That description includes detailed specifications in a form described in 4.3. For convenience, Annex A repeats all syntactic specifications.

+   2 21 through 33 and Annex D (the library clauses) describe the C++ standard language. That description includes detailed descriptions of the entities and macros that construct the library, in a form described in Clause 20.

+   3 Annex B recommends lower bounds for the conforming of implementations.

+   4 C summarizes the evolution of C++ since its first published description, and explains in detail the differences between C++ and C. Certain features exist for compatibility purposes; Annex D describes these features.

+   5 Throughout this document, each is introduced by “Example:” and terminated by “— end example”. Each note is introduced by “Note:” and terminated by “— end note”. Examples and notes may be nested.

# 4.3 Syntax notation

+   1 In the syntax used in this document, syntactic categories are indicated by *italic* type, and literal words and characters in **constant** type. Alternates are listed on separate lines except in a few cases where a line of alternates is marked by the phrase “one of”. If the text of an alternative is too long to fit on a line, the text is continued on subsequent lines indented from the first line. An optional or non-terminal symbol is indicated by the subscript *opt*, so

```
*expression_opt*
```

indicates an optional enclosed in brackets.

+   2 Names for syntactic categories are generally chosen to indicate their meaning (e.g., *class-name, typedef-id*).

+   (2.1) X—name is one of an identifier in a context that describes its meaning (e.g., *class-name, typedef-id*).

+   (2.2) X—id is one or more X’s with context-dependent delimiter (e.g., *qualified-id*).

+   (2.3) X—seq is one or more X’s with intervening delimiters (e.g., *declaration-seq* is a sequence of declarations separated by commas).

+   (2.4) X—list is one or more X’s separated by intervening commas (e.g., *identifier-list* is a sequence of identifiers separated by commas).

# 4.4 The C++ memory model

# [intro.memory]

+   1 The fundamental storage unit in the C++ memory model is the byte. A byte is at least large enough to contain any of the basic character set (5.3) and the eight-bit units of the UTF-8 encoding form is composed of a contiguous sequence of bits; the least bit is called the *low-order bit*, the most significant is called the *high-order bit*. Every byte is accessible to a C++ program as one or more sequences of bytes. Every byte has a unique address.
