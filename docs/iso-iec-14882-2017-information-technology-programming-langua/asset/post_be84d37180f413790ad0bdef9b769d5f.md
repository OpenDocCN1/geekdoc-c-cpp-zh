# 16.4 Address of overloaded function

An overloaded function name without arguments is resolved in contexts to a function, a pointer to a function or member function from the overload set. A function with template member is designed as overloaded. A function with FT is selected for the function type required in the context if F (after applying function conversion (7.13)) is identical to FT [Note: That is, the class of the function is a member matching a pointer-to-member.— end note] The target can be

- (1.1) an object or being initialized (11.6, 11.6.3, 11.6.4),
- (1.2) the left side of an argument (8.2.2),
- (1.3) the return value of a function (8.2.2),
- (1.4) a parameter of a user-defined operator (16.5),
- (1.5) an explicit type of function, operator, or conversion (9.6.3),
- (1.6) an explicit type name (8.2.3, 8.2.9, 8.4),
- (1.7) a pointer-to-template name (17.3.2).

The overloaded function name must be preceded by &. An overloaded function name shall not have arguments in contexts other than those listed. [Note: Any redundant parentheses surrounding the overloaded function name is ignored (8.1.— end note]

2 If the name is a function name, template argument deduction is used to generate a single template specialization, which is added to the set of overloaded candidates.
