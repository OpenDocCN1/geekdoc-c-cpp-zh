- For given inline function defined in different translation units, the accumulated sets of default arguments in a declaration of the translation units will be the same; 62. If a friend relation specifies a default argument expression, that declaration shall be a definition and be the only declaration of the function or template in the translation unit

The default argument has the same constraints as the initializer of a variable of the same type, using copy-initialization semantics [6.6]. The names in the default argument are bound, and the semantic constraints are checked at the point where the default argument is used. Lookup and checking of semantic constraints for default arguments in function templates and member functions of class templates are performed as described in [6.4.1]. In the following code, g will be called with the value f(2);

```
int a;
int f(int);
int g = f(a);
// default argument: f(::a)
void h() {
    int a = 2;
    int a = 3;
    g(); // gf(f(::a))
}
```

Except for member functions of class templates, the default arguments in a member function that appears outside of the class definition are provided by the member function declaration in the class definition; the program is ill-formed if a default constructor [15.1], copy or move constructor, copy or move assignment operator [15.8] is declared. Default arguments for a member function of a class template shall be specified on the initial declaration of the member function within the class template. [Example]:

```
class C {
    void f(int i = 3);
    void g(int i, int j = 99);
}
```

void C::g(int i = 88, int j) {} // in this translation unit, C::g can be called with no argument
