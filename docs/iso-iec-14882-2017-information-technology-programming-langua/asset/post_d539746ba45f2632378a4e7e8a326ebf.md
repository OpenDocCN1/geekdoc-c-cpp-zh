
# ISO/IEC 14882:2017(E)

```cpp
void resize(size_type n);
```

```cpp
size_type capacity() const noexcept;
```

Returns: The size of the allocated storage in the string.

```cpp
void reserve(size_type res_arg = 0);
```

The member function reserve() is a non-binding directive that informs a basic_string object of a planned change in size, that it may manage the storage allocation accordingly.

Effects: After reserve(), capacity() is greater or equal to the size of reserve. [Note: Calling reserve(), but may reduce capacity() if size is less than capacity() is in a non-binding shrink-to-fit request. — end note]

Throws length_error if res_arg > max_size().

```cpp
void shrink_to_fit();
```

Effects: shrink_to_fit() is a non-binding request to reduce capacity() to size(). [Note: The request is non-binding to allow implementation-specific-optimizations. It does not increase capacity(), but may reduce capacity() by causing reallocation. — end note]

Complexity: Linear in the size of the sequence.

Remarks: Reallocations invalidate all the references, pointers, and iterators to the elements in the sequence as well as the post-end-iterator. If no reallocation happens, they remain valid.

void clear() noexcept;

```cpp

```

## 24.3.2 basic_string element access

```cpp
const_reference operator[](size_type pos) const;
operator[](size_type pos);
```

Returns: *(begin() + pos) if pos < size(). Otherwise, returns a reference to an object of type charT with value charT(), modifying the object to any value other than charT() leads to undefined behavior.

Throws: Nothing.

Complexity: Constant time.

```cpp
const_reference at(size_type pos) const;
at(size_type pos);
```

Throws: out_of_range if pos >= size().

```cpp

```
