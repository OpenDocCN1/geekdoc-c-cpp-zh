memory_resource* upstream_resource() const;

Returns: The value of allocate(size_t bytes, size_t alignment) override;

void do_allocate(size_t bytes, size_t alignment) override;
Returns: A pointer to allocated storage (6.7.4.2) with a size of at least bytes. The size and alignment of the allocated memory shall meet the requirements for a class derived from memory_resource (23.12).

Effects: If the unused space in current_buffer can fit a block with the specified bytes, and alignment, then allocate the block from current_buffer; otherwise set current_buffer to upstream_rsrc->allocate(n, m), where n is not less than max(bytes, next_buffer) and m is not less than alignment, and increase next_buffer by an implementation-defined growth factor (which need not be integral), then allocate the block from the newly-allocated current_buffer.

Throws: Nothing unless upstream_rsrc->allocate() throws.

void do_allocate(void* p, size_t bytes, size_t alignment) override;

Effects:

Throws: Nothing.

Remarks: The memory used by this resource increases monotonically until its destruction.

The class template scoped_allocator_adaptor is an allocator that specifies the memory resource (the outer allocator) to be used by any other allocator and also specifies an inner resource. This is instantiated with one outer and two inner allocators. This allows the resource to be passed to the constructor of every element within the container. If instantiated with only one allocator type, the outer becomes the scoped_allocator_adaptor itself, using the same allocator for the container and every element within the contain, and if the elements have more than one allocator, the first allocator is the outer for use by the container; the second allocator is passed to the constructors of the container's elements, and if the elements are removed or destroyed, the total number of allocated elements is updated and checked. If containers are destroyed in the-allocator case, the number of allocators is used repeatedly, as in the single-allocator case, for any remaining instances. [Note: The scoped_allocator_adaptor is derived from the outer allocator type so it can be substituted in most expressions. ]
