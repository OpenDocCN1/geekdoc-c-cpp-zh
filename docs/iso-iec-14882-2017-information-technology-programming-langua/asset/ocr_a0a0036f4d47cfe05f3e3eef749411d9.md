# 28.5.5 Find

  const T& value);

```

```

```

  Predicate pred);
template<class ExecutionPolicy, class ForwardIterator, class Predicate>
ForwardIterator find_if_not(ExecutionPolicy&& exec, ForwardIterator first, ForwardIterator last,
  Predicate pred);
```

+   1 Returns The first i in the range [first, last) for which the corresponding conditions hold: *i == value, pred(*i) != false. Returns last if no such Iterator is found.

+   2 Complexity: At most first applications of the corresponding predicate.
