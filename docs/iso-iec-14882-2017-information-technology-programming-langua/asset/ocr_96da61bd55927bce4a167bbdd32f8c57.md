# 26.6.4.2 queue constructors

```
[queue.cons]
```

explicit queue(const Container& cont);

+   1 Effects: Initializes c with cont.

explicit queue(const Container& cont = Container());

+   2 Effects: Initializes c with std::move(cont).

# 26.6.4.3 queue constructors with allocators

```
[queue.cons]
```

+   1 If uses_allocator_v<queue_type, Alloc> is false the constructors in this subclause do not participate in overload resolution.

```
template <class Alloc> explicit queue(const Alloc a);
```

+   2 Effects: Initializes c with a.

```
template <class Alloc> queue(const Container_type& cont, const Alloc a);
```

+   3 Effects: Initializes c with const as the first argument and as the second argument.

```
template <class Alloc> queue(const Container_type&& cont, const Alloc a);
```

+   4 Effects: Initializes c with std::move(cont) as the first argument and as the second argument.

```
template <class Alloc> queue(const queue_type& q, const Alloc a);
```

+   5 Effects: Initializes c with q.c as the first argument and as the second argument.

```
template <class Alloc> queue(queue&& q, const Alloc a);
```

+   6 Effects: Initializes c with std::move(q.c) as the first argument and as the second argument.

# 26.6.4.4 queue operators

```
[queue.ops]
```

```
template <class T, class Container>
bool operator==(const queue<T, Container>& x, const queue<T, Container>& y);
```

+   1 Returns: x.c == y.

```
template <class T, class Container>
bool operator!=(const queue<T, Container>& x, const queue<T, Container>& y);
```

+   2 Returns: x.c != y.

```
template <class T, class Container>
bool operator<(const queue<T, Container>& x, const queue<T, Container>& y);
```

+   3 Returns: x.c < y.
