# ISO/IEC 14882:2017(E)

# 17.6.1 Locally declared names

Like normal (non-template) classes, class templates have an injected-class-name (Clause 12). The injected-class-name can be used as a template-name or a type-name. When it is used with a template-argument-list, as a template-argument for a template-parameter, or as the final identifier in the injected-type-specifier of a class friend declaration, it refers to the class template itself. Otherwise, it is equivalent to the template-name followed by the template-parameters of the class template enclosed in <.

Within the scope of a class template specialization or partial specialization, when the injected-class-name is used as a type-name, it is equivalent to the template-name followed by the template-arguments of the class template specialization or partial specialization enclosed in <. Example:

```
template<class> class A {\ntemplate<class> class Y {
    Y* p; // meaning Y<int>
    char* q; // meaning Y<char>
    A* b; // meaning A<:Y>
    template<class> friend class Y;
};
// end example
```

The injected-class-name of a class template or class template specialization can be used either as a template-name or a type-name wherever it is. Example:

```
template <T> struct Base {
    Base* p;
};
template <T> struct Derived : public Base<T> {
    typename Base::Base* p; // meaning Base<T>
};
template<T, template<class> class U = T::template Base struct Third {
    ThirdBase<int> t; // OK: default argument was injected-class-name as a template
};
// end example
```

A lookup that finds an injected-class-name (13.2) can result in an ambiguity in certain cases (for example, if it found in more than one class). If all of the injected-class-names that refer to specializations of the same class, and the name is used as a template-name, the reference refers to the class template and not a specialization thereof, and is not ambiguous. Example:

```
template <T> struct Base {
template <T> struct Base : Base<char> {
    typename Base::Base b; // error: ambiguous
    typename Base::Base<double> b; // OK
};
// end example
```

When the normal name of the template (i.e., the name from the enclosing scope, not the injected-class-name) is used, it always refers to the class template itself and not a specialization of the template. Example:

```
template <class> class X {
    X* p; // meaning X<T>
    X<T>* p2;
    X<int>* p3;
```
