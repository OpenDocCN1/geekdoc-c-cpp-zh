# 12.4 Local class declarations [class.local]

+   1 A class can be declared within a function definition; such a class is called a local class. The name of a local class is local to its enclosing scope. The local class is in the scope of the enclosing scope, and has the same access to non-static variables as the enclosing function does. Declarations in a local class shall not od-use (6.2) a variable with automatic storage from an enclosing scope. — Example:

```
int x;
void f() {
static int s;
int x;
const int N = 5;
extern q();

struct local {
int g() { return x; } // od-use of automatic variable x
int h() { return s; } // OK
int k() { return q(); } // OK
int l() { return q(); } // OK
int m() { return N; } // OK: not od-use
int* o() { return N; } // od-use of automatic variable N
}

local* p = 0; // local: not in scope
 — end example
```

+   2 An enclosing function has no access to members of the local class; it obeys the access rules (Clause 14). Member functions of a local class shall be defined within their definition, if they are defined at all.

+   3 If X is a local nested class Y may be declared in class X and later defined in the definition of class X or later defined in the same scope as the definition of class X. A class nested within a local class is a local class.

+   4 A local class shall not have static data members.
