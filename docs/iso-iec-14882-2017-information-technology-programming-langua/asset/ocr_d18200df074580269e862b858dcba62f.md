# ISO/IEC 14882:2017(E)

If one of the called functions throws an exception, unless explicitly noted otherwise, the input function sets badbit in error. If badbit is not in exceptions(), the input function throws the exception without completing its actions, or it does not throw anything and proceeds as if the function had returned a failure indication.

# 30.7.4.1.1 basic_stream constructors [stream.cons]

explicit basic_stream(basic_streambuf<charT,traits>* sb);

+   1 Effects: Constructs an object of class basic_stream, initializing the base subject with basic_ios::init(sb) (30.5.5,2).
2 Postconditions: gcount() == 0.
basic_stream(const basic_stream& rhs);
3 Effects: Moves constructs from the rhs value. This is accomplished by default constructing the class, copying the gcount() from rhs, calling basic_ios<charT,traits>::move(rhs) to initialize the base class, and setting the gcount() for rhs to 0.
virtual ~basic_stream();
4 Effects: Destroys an object of class basic_stream.
5 Remarks: Does not perform any operations on rdbuf().

# 30.7.4.2 Class basic_stream:: assign and swap [stream.assign]

2 Returns: *this.

void swap(basic_stream& rhs);

# 30.7.4.1.3 Class basic_stream::sentry [stream.sentry]

```
namespace std {
template <class charT, class traits = char_traits<charT>>
class basic_stream<charT,traits>::sentry {
  using traits = traits;
  bool ok; // exception only
```

```
public:
  explicit sentry(basic_stream<charT,traits>& is, bool noskipw = false);
  -sentry();
  sentry(const sentry&) = delete;
  sentry& operator=(const sentry&) = delete;
  explicit operator bool() const { return ok; }
};
```

1 The sentry defines a class that is responsible for doing exception safe prefix and suffix operations.
