## 23.2.5 Forward/move_helpers

- 1 The library provides templated helper functions to simplify moving semantics to an value and simplify the implementation of forwarding functions. All functions specified in this clause are failsafe(21.10.4).

```cpp
template <class T> constexpr T&& forward(reference_t<T>&& t) noexcept;
template <class T> constexpr T&& forward(reference_t<T>&& t) noexcept;
```

- 2 Returns: static_cast<T&>(t).
- 3 Remarks: If the second is instantiated with an lvalue reference, the program is ill-formed.

```cpp
Example:
template <class T, class A1, class A2>
shared_ptr<T> factory(A1&& a1, A2&& a2) {
    return shared_ptr<T>(new(std::forward<A1>(a1), std::forward<A2>(a2)));
}

struct A {
    int;
    const double;
};

void g() {
    shared_ptr<A> sp1 = factory<A>(2, 1.414); // error: 2 will not bind to int&
    int i = 2;
    shared_ptr<A> sp2 = factory<A>(i, 1.414); // OK
```

In the first call, A1 is deduced as int, so 2 is forwarded to A's constructor as rvalue.
The second call, A2 is deduced as int, so 1 is forwarded to A's constructor as lvalue.
In both cases, A2 is deduced as double, so 1.414 is forwarded to A's constructor as rvalue. — end[example];

```cpp
template <class T> constexpr T&& remove_reference_t<T>&& move(T&& t) noexcept;
```

- 5 Returns: static_cast<remove_reference_t<T>&>(t).
- 6 Example:

```cpp
template <class T, class A1>
shared_ptr<T> factory(A1&& a1) {
    return shared_ptr<T>(new(std::forward<A1>(a1)));
}
```

```cpp
struct A {
    A();
    A(const A&);      // copies from values
    A(A&&);           // moves from rvalues
};

void g() {
    A a;
    shared_ptr<A> spl = factory(a);      // "a" binds to A(const A&)
    shared_ptr<A> spl = factory(std::move(a)); // "a" binds to A(A&&)
};
```

In the first call, A1 is deduced as A&&, so it is forwarded as a non-const reference. This binds to the constructor A(const A&), which copies the value from a. In the second call to factory, because of the call std::move(a); A1 is deduced as A&&, so it moves to the constructor A(A&&), which moves the value. end example

## 23.2.7 Function template decltype

The library provides the function decltype to simplify the definition of expressions which occur as unvaluated expressions (Clause 8).

```cpp
template <class T> T_reference<T>& declval() noexcept; // unvaluated
```

- 2 Remarks: If this is instantiated with an lvalue reference, the program is ill-formed.
- 3 Remarks: The template parameter T of decltype may be an incomplete type.

Example:
template <class T, class From> decltype(static_cast<T>(declval<From>()))(From&&)
declares a function T which only participates in overloading if the type From is converted to T. end example

## 23.2.8 Primitive output conversion

- 1 All functions convert value to string by filling range [first, last], where first, last is required to be a value.
- 2 The functions that taking floating-point value have no precision argument ensure that the string representation consists of the smallest number of characters such that there is at least one digit before the radix (if present) and parsing the corresponding from_chars function. Note: This guarantee applies only if to_chars and from_chars are executed on the same implementation.
- 3 The functions taking a chars_format parameter determine the conversion specifier for printf as follows:
The conversion specifier is f if fmt is chars_format::fixed, e if fmt is chars_format::scientific, x (without leading "0") in the result if fmt is chars_format::hex, and if fmt is chars_format::general.
- 4 Requires: base value between 2 and 36 (inclusive).
- 5 Effects: The value of value is converted to a string of digits in the given base (no redundant zeros). Digits in the range 10-35 (inclusive) are represented as lowercase a..z. if value is less than zero, representation starts with a minus sign.
- 6 Threads: None.
- 7 Remarks: The implementation shall provide overloads for all signed and unsigned integer types as the type of the parameter value.

```cpp
to_chars_result to_chars(char* first, char* last, float value);
to_chars_result to_chars(char* first, char* last, double value);
to_chars_result to_chars(char* first, char* last, long double value);
```

- 8 Effects: value is converted to a string in the style of printf in the "C" locale. The conversion specifier is f or chosen according to the requirement for a shortest representation (see above); a is tied to f.
- 9 Threads: None.

```cpp
to_chars_result to_chars(char* first, char* last, float value, chars_format fmt);
to_chars_result to_chars(char* first, char* last, double value, chars_format fmt);
to_chars_result to_chars(char* first, char* last, long double value, chars_format fmt);
```

- 10 Requires: fmt has the value of one of the enumerators of chars_format.
- 11 Effects: value is converted to a string in the style of printf in the "C" locale.
- 12 Threads: None.

```cpp
to_chars_result to_chars(char* first, char* last, float value, chars_format fmt, int precision);
to_chars_result to_chars(char* first, char* last, double value, chars_format fmt, int precision);
to_chars_result to_chars(char* first, char* last, long double value, chars_format fmt, int precision);
```

- 13 Requires: fmt has the value of one of the enumerators of chars_format.
- 14 Effects: value is converted to a string in the style of printf in the "C" locale with the given precision.
- 15 Threads: None.

SEE ALSO: ISO C 7.21.1

## 23.2.9 Primitive numeric input conversion [utility.from.chars]

All functions member from_chars analyze the string [first, last) for a pattern, where [first, last) is be a valid range. If characters match the pattern, value is unmodified, the member ptr of return value is first and the member ec is errc::invalid_argument. Otherwise, the characters matching the pattern are interpreted as a representation of a type of value. The member ptr of return value points the first character that does not match the pattern, or the value last if all characters match. If the parsed value is not in the range, the member ptr has the value errc::too_large, and the contents of range [first, last] are unspecified.

## 23.3.1 In general

The library provides a class template that can represent an integer sequence. When used as a function template the parameter packing can be deduced and used in a pack expansion.
[Note: The index_sequence alias is provided for the common case of an integer sequence of size_t; see also 23.3.5.5. — end note]

  using value_type = T;
