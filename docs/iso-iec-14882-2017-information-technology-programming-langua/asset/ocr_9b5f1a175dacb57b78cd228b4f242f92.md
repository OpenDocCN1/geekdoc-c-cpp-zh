# 20.5.4.2.2 Namespace posix [namespace.posix]

1 The behavior of a C++ program is undefined if it adds declarations or definitions to namespace posix unless otherwise specified. The namespace posix is reserved for use by ISO/IEC 9945 and other POSIX standards.

# 20.5.4.2.3 Names for future standardization [namespace.future]

1 Top level namespaces with a name starting with std followed by a non-empty sequence of digits are reserved for future standardization. The behavior of a C++ program is undefined if it adds declarations or definitions to such a namespace. Example: The top level namespace std2 is reserved for use revisions of this International Standard.—end example

# 20.5.4.3 Reserved names [reserved.names]

1 The C++ standard library reserves the following kinds of names:

+   - macros
- global names
- names with external linkage

2 If a program declares or defines a name in a context where it is used, other than as explicitly allowed by this Clause, its behavior is undefined.
