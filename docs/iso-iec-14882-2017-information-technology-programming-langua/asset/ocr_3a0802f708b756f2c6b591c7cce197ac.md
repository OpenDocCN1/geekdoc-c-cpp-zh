# ISO/IEC 14882:2017(E)

**Required**: A call to an operator delete[] with a size parameter may be changed to the corresponding operator delete[] without a size parameter, without affecting memory allocation.
Note: A conforming implementation is for operator delete(void* ptr, std::size_t size) to simply call operator delete(ptr). — end note

**Default**: Functions that have a size parameter forward their other parameters to the corresponding function without a size parameter. The functions that do not have a size parameter forward to their corresponding operator delete() (single-object) function.

```
operator delete(void* ptr, std::size_t t) noexcept;
operator delete(void* ptr, std::size_t alignment, const std::align_val t) noexcept;
```

**Effects**: The deallocation functions (6.7.4) may be changed by the implementation to return the ptr invalid when the constructor invoked from a placement version of the new-expression throws an exception.

**Replaceable**: A C++ program may define functions with these function signatures, and thereby displace the functions defined by the C++ standard library.

**Required**: If ptr is not null it shall return the address of a block of memory allocated by a caller to a (possibly replaced) operator new[](std::size_t) or operator new[](std::size_t alignment, std::align_val t) that has not been invalidated by an intervening call to operator delete[

**Required**: If an implementation has strict pointer safety (6.7.4.3) then ptr shall be a safely-delivered pointer.

**Required**: If the alignment is not present, ptr shall have been returned by an allocation function without an alignment parameter. If present, the alignment argument shall equal the alignment passed to the allocation function that returned ptr.

**Default**: Calls operator delete[](ptr), or operator delete(ptr), respectively.
