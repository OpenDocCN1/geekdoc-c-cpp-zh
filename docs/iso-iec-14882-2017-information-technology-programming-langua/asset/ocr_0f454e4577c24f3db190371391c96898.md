# ISO/IEC 14882:2017(E)

[Note: Because using a using-declarator designates a base class member (and not a member subobject or a member function of a base class subobject), a using-declarator cannot be used to resolve inherited member ambiguities.
[Example:

```
struct A { int x(); };
struct B : A { };
struct C : A {
    using A::;
    int x(int);
};
struct D : B, C {
    using C::;
    int x(double);
    int f(D* d) {
        return d->x(); // overload resolution selects A::x, but A is an ambiguous class
    }
-- example -- end note;
```

19 A synonym created by a using-declarator has the usual accessibility for a member-declaration. A using-declarator that names a constructor does not create a synonym; instead, the additional constructors are accessible if they would be used when constructing an object of the base class, and the accessibility of the using-declaration is ignored. [Example:

```
class A {
private:
    void f(char);
public:
    void f(int);
protected:
    void g();
};
class B : public A {
public:
    using A::g; // error: f(char) is inaccessible
// B::g is a public synonym for A::g
};
```

If a using-declarator uses the keyword typename and specifies a dependent (17.6.2), the name introduced by the using-declarator is treated as a typedef-name [10.1.3].

# 10.3.4 Using directive [namespace::udir]

```
using-directive:
    attribute-specifier-using namespace nested-name-specifier,namespace-name;
```

+   1 A using-directive does-not appear in class scope, but may appear in namespace scope or in block scope.
[Note: When using a namespace-name in a namespace, only names are considered, see 6.4.6. -- end ] The optional attribute-specifier applies to the using-directive.

+   2 A using-directive specifies that the names in the nominated namespace are accessible after the using-directive appears. During unqualified name lookup (6.4.1), the names appear as if they were declared in the nearest enclosing namespace which contains both the using-directive and the nominated namespace. [Note: In this context, "contains" means "contains directly or indirectly". -- end
