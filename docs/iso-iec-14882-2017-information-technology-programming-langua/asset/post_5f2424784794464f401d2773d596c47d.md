## 23.10.4 Pointer safety

A complete object is declared reachable while the number of calls to undeclare_reachable with an argument referencing the object exceeds the number of calls to undeclare_reachable with the object.

```cpp
void declare_reachable();
```

```cpp
template <class T> declare_reachable(T* p);
```

```cpp
void declare_no_pointers(char* p, size_t n);
```

- Requires: The pointers in the specified range are currently registered with declare_no_pointers(). If the specified range is in an allocated object, then it shall be within a single allocated object. The object shall live until the corresponding undeclare_no_pointers() call. In a garbage-collection implementation, the fact that a region in an object is registered with undeclare_no_pointers() should not prevent the object from being collected.
- Effects: The n starting at p no longer contains traceable pointer locations, independent of their type. Hence induction through a pointer located there is undefined if it points to was created by global operator new and not previously declared reachable. [Note: This may be used to inform a garbage collector or leak detector that this memory may not be traced.]
- Throws: Nothing.
- Note: Under some conditions implementations may need to allocate memory. However, the request can be ignored if memory allocation fails.

```cpp
13 void undeclare_no_pointers(char* p, size_t n);
```

14 Requires: The same range previously have been passed to declare_no_pointers(). It shall be called before the lifetime of the object ends.

15 Throws: Nothing.

```cpp

17 Returns: pointer_safety::strict if the implementation has strict pointer safety (6.7.4.3). It is implementation-defined whether get_pointer_safety returns pointer_safety::relaxed or pointer_safety::preferred if the implementation has relaxed pointer safety.
```

## 23.10.5 Align [ptr.align]

```cpp
1 void* align(size_t size, size_t alignment, void*& ptr, size_t space);
2 Effects: If it is to fix bytes of size aligned by alignment into the buffer pointed to by ptr with length, the function updates ptr to represent the first possible address of storage decreases space by the number of bytes used for alignment. Otherwise, the function does nothing.
```

3 Requires:

- (2.1) alignment be a power of two
- (2.2) ptr shall represent the address of contiguous storage of at least space bytes

4 Returns: A null if the requested aligned buffer would not fit into the available space, otherwise adjust the value of ptr.

> [Note: The function updates ptr and space arguments so that it can be called repeatedly with different alignment and uses space for the same buffer.]

## 23.10.7 uses_allocator [allocator.uses]

### 23.10.7.1 uses_allocator [allocator.uses.trait]

```cpp
template <class T, class Alloc> struct T has a nested allocator_type that is convertible to Alloc.
```

Remarks: Automatically detects whether T is convertible from Alloc. meets the BaseTypeRequires (23.15.1). The implementation shall provide a definition that is derived from true_type if the qualified-id T::allocator_type is valid and denotes a type (17.8.2) and is_convertible_v<T, T::allocator_type> != false, otherwise it shall be derived from false_type. A program may specialize this template to derive from true_type for a user-defined T that does not have a nested allocator_type but nonetheless be constructed with an allocator wherever.

> pointer_safety::preferred might be returned to indicate that a leak detector is running so that the program can avoid spurious leak reports.

- (1.1) the first argument of a constructor has type allocator_arg_t and the second argument has type Alloc or
- (1.2) the last argument of a constructor has type Alloc.

## 23.10.7 Allocator-uses construction [allocator.uses_construction]

Uses-allocator construction with Alloc refers to the construction of an object obj of type T, using constructor arguments v1, v2, ... of types V1, V2, ..., respectively, and an allocator of type Alloc, according to the following rules:

- (1.1) if uses_allocator<V, Alloc> is true and is_constructible_v<T, V1, V2, ...> is true, then obj is initialized as obj(v1, v2, ...);
- (1.2) if uses_allocator<V, Alloc> is true and is_constructible_v<T, allocator_arg_t, Alloc, V1, V2, ...> is true, then obj is initialized as obj(allocator_arg, Alloc, V1, V2, ...);
- (1.3) if uses_allocator<V, Alloc> is true and is_constructible_v<T, V1, V2, ..., Alloc> is false, then obj is initialized as Alloc();
- (1.4) otherwise, the request for uses_allocator-construction is ill-formed. [Note: An error will result if uses_allocator<V, Alloc> is true but the specific class does not.]

## 23.10.8 Allocator traits [allocator.traits]

The allocator_traits supplies an interface to all allocator. [Note: Thus, it is possible to create an allocator.]

```cpp
namespace std {
template <class Alloc> struct allocator_traits {
  using value_type = typename Alloc::value_type;
  using pointer = typename Alloc::pointer;
  using const_pointer = typename Alloc::const_pointer;
  using reference = typename Alloc::reference;
  using const_reference = typename Alloc::const_reference;
  using difference_type = typename Alloc::difference_type;
  using size_type = typename Alloc::size_type;
  using allocator_type = typename Alloc::allocator_type;
  using rebind = struct rebind<Alloc, value_type>;
  using other = typename rebind::allocator_type;

  static pointer allocate(size_type n);
  static void deallocate(pointer p, size_type n);
};

template <class Alloc, class U>
struct rebind {
  using other_type = Alloc<U>;
};

template <class Alloc>
struct allocator_traits<Alloc> {
  using value_type = typename Alloc::value_type;
  using pointer = typename Alloc::pointer;
  using const_pointer = typename Alloc::const_pointer;
  using reference = typename Alloc::reference;
  using const_reference = typename Alloc::const_reference;
  using difference_type = typename Alloc::difference_type;
  using size_type = typename Alloc::size_type;
  using allocator_type = typename Alloc::allocator_type;
  using rebind = struct rebind<Alloc, value_type>;
  using other = typename rebind::allocator_type;

  static pointer allocate(size_type n);
  static void deallocate(pointer p, size_type n);
};
```
