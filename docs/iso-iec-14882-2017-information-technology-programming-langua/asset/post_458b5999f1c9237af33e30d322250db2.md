ISO/IEC 14882:2017(E)

An object of class stores any instance of type that satisfies the constructor requirements or no value, and this is referred to as the state of the class. The stored instance is the contained value. Two states are equivalent if they have no value, or both have a value. The any_cast functions provide type-safe access to the contained value. Example: the object constructed is holding an int. Such small-object optimization should only be applied to types for which move_constructible_v<T> is true.

### 23.8.3.1 Construction and destruction [any::cons]

constexpr any() noexcept;
Postconditions: has_value() is false.

any(const any& other);
Effects: If has_value() is false, constructs an object that has no value. Otherwise, equivalent to any(in_place_tag<T>, Args&&...)) where T is the type of the contained value.

any(any&& other) noexcept;
Effects: If has_value() is false, constructs an object that has no value. Otherwise, constructs an object of any that contains the contained value of other, or an object of the same type constructed from value as a value.
Postconditions: other is in a valid but unspecified state.

template<class T>
any(T&& value);
Let: VT shall decay<T>.
Requirements: VT shall satisfy the CopyConstructible requirements.
Effects: Constructs an object of any that contains an object of type VT direct-initialized with std::forward<T>(value), and move_constructible_v<VT> is true.

template<class T, class... Args>
explicit any(in_place_tag<T>, Args&&...);
Let: VT be decay<T>.
Requirements: VT shall satisfy the CopyConstructible requirements.
Effects: Initializes the contained value as direct-initializing an object of type VT with the arguments std::forward<Args>(args).
Postconditions: *this contains a value of type VT.
Throws: Any exception thrown by the selected constructor of VT.
Remarks: This constructor shall not participate in overload resolution unless copy_constructible_v<VT> is true and is_constructible_v<VT, Args...> is true.

template <class T, class U, class Args>
explicit any(in_place_tag<T>, std::initializer_list<U> il, Args&&... args);
Let: VT be decay<T>.
Requirements: VT shall satisfy the CopyConstruct requirements.
Effects: Initializes the contained value if direct-list-initializing an object of VT with the arguments il.
Postconditions: *this contains a value.
Throws: Any exception thrown by the selected constructor of VT.
Remarks: This constructor shall not participate in overload resolution unless copy_constructible_v<VT> is true and is_constructible_v<VT, initializer_list<U>, Args...> is true.

any() noexcept;
Effects: As if reset().

### 23.8.3.2 Assignment [any.assign]

any& operator=(const any&& rhs);
Effects: As if any(rhs).swap(*this). No effects if an exception is thrown.
Returns: *this.
Throws: Any exception arising from the copy constructor of the contained value.

any& operator=(any&& rhs) noexcept;
Effects: As if any(std::move(rhs)).swap(*this).
Returns: *this.
Postconditions: The state of *this is equal to the state of rhs and rhs is left in a valid but unspecified state.

template<class T>
any& operator=(T&& rhs);
Let: VT be decay<T>.
Requirements: VT shall satisfy the CopyConstruct requirements.
Effects: Constructs an object of any that contains an object of VT direct-initialized with std::forward<T>(rhs), and tmp.swap(*this). No effects if an exception is thrown.
Returns: *this.
Remarks: This operator shall not participate in overload resolution unless VT is not the same type as any and copy_constructible_v<VT> is true.
Throws: Any exception thrown by the selected constructor of VT.

### 23.8.3.3 Modifiers [any.modifiers]

template<class T, class... Args>
decay<T>&& emplace(Args&& rhs);
Let: VT be decay<T>.
Requirements: VT shall satisfy the CopyConstruct requirements.
Effects: Initializes the contained value if direct-list-initializing an object of VT with the arguments std::forward<Args>(args).
Postconditions: *this contains a value.
Throws: Any exception thrown by the selected constructor of VT.
Remarks: This constructor shall not participate in overload resolution unless copy_constructible_v<VT> is true and is_constructible_v<VT, initializer_list<U>, Args...> is true.

reset() noexcept;
Effects: As if reset().

swap(any&& rhs) noexcept;
