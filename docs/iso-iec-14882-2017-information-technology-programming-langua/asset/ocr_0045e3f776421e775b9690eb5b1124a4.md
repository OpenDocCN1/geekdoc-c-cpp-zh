# 9.4.1 The if statement [stmt.if]

+   If the condition (9.4) yields true the first subacement is executed. If the else part of the statement is present and the condition yields false, the second subacement is executed. If the first subacement is reached via a label, the condition is not evaluated and the second subacement is not executed. In the second form of it (the one containing else), if the first subacement is also if statement then that inner statement shall contain an else part.⁹⁰

+   If the statement is of the form constexpr if the value of the condition shall be a contextually converted expression of type bool (8.20); this form is called a constexpr if statement. If the value of the converted condition is false, the second subacement, otherwise the second templated entity violated, is a discarded statement. (Clause 17), if the condition is not value-dependent after its instantiation, the discarded subacement (if any) is not discarded. [Note: Labels do not require an entity to be defined.] A label declared in a subacement of a statement shall be associated with a switch-statement (9.4.2) within the same statement. A case or default label appearing within such an if statement shall be referred to by a statement (9.6.4) declared in a subacement of a constexpr statement. Example:

```
template<typename T, typename Rest = sizeof(T) > 0> void g(T&& p, Rest&&... rs) {
    g(rs...);
} // no definition of an empty argument list

extern int x;

int f() {
    if constexpr (true) {
        return 0;
    } else if (x) {
        return x;
    } else {
        return -x;
    }
} // end example
```

An if statement of the form is equivalent to

```
if constexpr_opt ( init-statement condition ) statement
{
    init-statement
    if constexpr_opt ( condition ) statement
}
```

In other cases, the else is associated with the nearest-unnested if.
