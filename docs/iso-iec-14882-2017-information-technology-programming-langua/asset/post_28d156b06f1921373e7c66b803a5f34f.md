## 23.12.2 Class memory_resource [mem.res.class]

The memory_resource is an abstract interface to an unbounded set of classes encapsulating memory resources.

```cpp
class memory_resource {
    static constexpr size_t max_align = alignof(max_align_t); // extension only
public:
    virtual ~memory_resource();

    void allocate(size_t bytes, size_t alignment = max_align);
    void deallocate(void* p, size_t bytes, size_t alignment = max_align);

    bool is_equal(const memory_resource& other) const noexcept;
private:
    virtual void do_allocate(size_t bytes, size_t alignment) = 0;
    virtual void do_deallocate(void* p, size_t bytes, size_t alignment) = 0;
    virtual bool do_is_equal(const memory_resource& other) const noexcept = 0;
};
```

### 23.12.2.1 memory_resource member functions [mem.res.public]

- memory_resource();

1. Effects: Destroys this memory_resource.
2. allocate(size_t bytes, size_t alignment = max_align);
   Effects: Equivalent to return: do_allocate(bytes, alignment);
3. deallocate(void* p, size_t bytes, size_t alignment = max_align);
   Effects: Equivalent to return: do_deallocate(p, bytes, alignment);
4. is_equal(const memory_resource& other) const noexcept;
   Effects: Equivalent to return: do_is_equal(other);

### 23.12.2.2 memory_resource private virtual member functions [mem.res.private]

```cpp
virtual void do_allocate(size_t bytes, size_t alignment) = 0;
```

1. Requirements: Alignment shall be a power of two.
2. Returns: A derived class shall implement this function to return a pointer to allocated storage (6.7.4) with a size of at least bytes. The storage is aligned to the specified alignment, if such is supported (6.11); otherwise it is aligned to max_align.
3. Throws: A derived class shall throw an appropriate exception if it is unable to allocate memory with the requested size and alignment.

```cpp
virtual void do_deallocate(void* p, size_t bytes, size_t alignment) = 0;
```

4. Requires: p shall have been returned from a call to allocate(bytes, alignment) on a memory resource to *this, and the storage at p shall not have been deallocated.
5. Effects: A derived class shall implement this function to dispose of allocated storage.
6. Throws: Nothing.

```cpp
virtual bool do_is_equal(const memory_resource& other) const noexcept = 0;
```

7. Returns: A derived class shall implement this function to return memory allocated from this can be deallocated from other, otherwise false. (Note: The most-derived type of other might not match the type of this. For a derived class D, a particular implementation of this might return false if dynamic_cast<D*>(other) == nullptr.)

## 23.12.2. memory_resource equality [mem.req]

```cpp
bool operator==(const memory_resource& a, const memory_resource& b) noexcept;
```
Returns: a == b || a.is_equal(b).

```cpp
bool operator!=(const memory_resource& a, const memory_resource& b) noexcept;
```
Returns: !(a == b).

## 23.12.3. Class polymorphic_allocator [mem.polymorphic_allocator.class]

A specialization of class pmr::polymorphic_allocator conforms to the Allocator requirements (20.5.3). Constructed with different memory resources, different instances of the same specialization of pmr::polymorphic_allocator allows objects to behave as if they used allocator at runtime even though they use the same allocator type.

```cpp
template <class T>
class polymorphic_allocator {
    memory_resource* m_resource;

public:
    using value_type = T;

    // 23.12.3.1. constructors
    polymorphic_allocator() noexcept;
    polymorphic_allocator(memory_resource* r);
    polymorphic_allocator(const polymorphic_allocator& other) = default;

    template <class U>
    polymorphic_allocator(const polymorphic_allocator<U>& other) noexcept;

    polymorphic_allocator& operator=(const polymorphic_allocator& rhs) = delete;

    // 23.12.3.2. member functions
    T* allocate(size_t n);
    void deallocate(T* p, size_t n);

    template <class T, class... Args>
    void construct(T* p, Args&&... args);
};
```

### 23.12.3 polymorphic_allocator constructors

```cpp
polymorphic_allocator() noexcept;
```
1. Effects: Sets m_resource to get_default_resource().

```cpp
polymorphic_allocator(memory_resource* r);
```
2. Requires: r is non-null.
3. Effects: Sets m_resource to r.
4. Throws: Nothing.
5. [Note: This constructor provides an implicit conversion from memory_resource.]

```cpp
template <class U>
polymorphic_allocator(const polymorphic_allocator<U>& other) noexcept;
```
6. Effects: Sets m_resource to other.resource().

### 23.12.3 polymorphic_allocator member functions

```cpp
T* allocate(size_t n);
```
1. Equivalent to:
   return static_cast<T*>(m_resource->allocate(n * sizeof(T), alignof(T)));

```cpp
void deallocate(T* p, size_t n);
```
2. Requires: p was allocated from a memory resource x, equal to *m_resource, x.allocate(n * sizeof(T), alignof(T)).
3. Equivalent to: m_resource->deallocate(p, n * sizeof(T), alignof(T)).
4. Throws: Nothing.

```cpp
template <class T, class Args...
void construct(T* p, Args&&... args);
```
5. Requires: Uses-allocator constructor of T with allocator resource() (see 23.10.7.2) and constructor args std::forward<Args>(args...) is well-formed. [Note: Uses-allocator construction is always well-formed for types that do not use allocators.]
Effects: Construct a T object in the storage whose address is represented by p by uses-allocator construction with allocator resource() and constructor arguments std::forward<Args>(args...).
Throws: Not if the constructor of T throws.

