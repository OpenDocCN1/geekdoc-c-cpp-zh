# [class.mfct.non-static]

# 12.2.2 Non-static member functions

A non-static member function may be called for an object of its class type, or for an object of a derived class (Clause 13) from its class type, using the class member access syntax (8.2.5, 16.3.1.1). A non-static member function may also be called directly using the call syntax (8.2.2, 16.3.1.1) from within the body of a member function of its class or of a class derived from it.

If a non-static member function of a class X is called for an object that is not of type X, or of a class from X, the behavior is undefined.

When an id-expression (8.1) is not part of a class member access syntax (8.2.5) and not used to form a pointer to a member (8.3.1) is used in a class member of class X in a context where this can be used (8.1.2), if lookup (6.4) resolves the name in the id-expression to a non-static member function of some class C, and if the id-expression is evaluated as C or a base of X, the id-expression is transformed into a class member access expression (8.2.2) using (this) (12.2.2.1) as the postfix-expression. [Note: If C is not a base class of X, the expression is ill-formed. — end example.] A member function that resolves to a static member, an enumer or an unqualified-id (8.1) used in the definition of a member of type X or a base class of X, the unqualified-id is transformed into a qualified-id (8.1) or a nested-member-specifier names of the member. These transformations do not apply in the template definition (17.6.2). [Example]:

```
struct tnode {
    char word[20];
    int count;
    tnode* left;
    tnode* right;
};

void set(const char* w, tnode* n, tnode* r) {
    count = sizeof(tword)<count
    if (sizeof(tword)>count)
        perror("tnode string too long");
    strcpy(tnode->word,w);
    left = 1;
    right = r;
}
```

```
void f(tnode n1, tnode n2) {
n1.set("abc",n2,0);
n2.set("def",0,0);
}
```

In the body of the member function tnode::set, the member word, count, left, and right refer to the object for which the function is called. Thus, in the n1.set("abc",n2,0), this refers to n1, and to n2. The functions strlen, and strcpy are not members of the class tnode and should be declared elsewhere.¹110 — end example]

A non-static member function may be declared const, volatile, or const volatile. These cv-qualifiers affect the type of this pointer (12.2.2.1). They also affect the function type (11.3.5) of the member function; a member function declared const is a const member function, a member function declared volatile is a volatile member function and a member function declared const volatile is a const volatile member function.
