# 30.7.5.2 Formatted output functions

## 30.7.5.2.1 Common requirements

+ 1 Each member function begins execution by constructing an object of class sentry. If this object returns true when converted to a value of type, the function generates the requested output. If any generation fails, the formatted output function does setstate(ios_base::failbit), which throws an exception. If an exception is thrown during output, badbit is set in this error state. If exceptions() != 0 then the exception is rethrown. Whether or not an exception is thrown, the sentry object is destroyed leaving the formatted output function. If no exception is thrown, the result of the formatted output function is *this.

+ 2 The descriptions of the individual formatted functions describe how they perform output and do not mention the sentry object.

318 The os.tie()->flush() does not necessarily occur if the function can determine that no synchronization is needed.

319 The sentry constructor and destructor can also perform implementation-dependent operations.
320 without causing an ios::failure to be thrown.

3 If a formatted output function of a stream determines padding, it does so as follows. Given a charT character sequence where charT is the character type of the stream, if the length of seq is less than os.width(), enough copies of os.fill() are added to this sequence as necessary to pad to a width of os.width() characters. If os.flags() & ios_base::justfield() == ios_base::left, the characters are placed after the character sequence; otherwise, they are placed before the character sequence.
