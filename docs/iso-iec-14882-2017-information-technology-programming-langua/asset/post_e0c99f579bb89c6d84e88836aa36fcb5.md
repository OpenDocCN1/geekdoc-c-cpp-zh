# 17.3.2 Template non-type arguments

- If the type of a non-template-parameter contains a placeholder type by template deduction (10.1.7.4, 17.1), the deduced parameter is determined from the type of the template-argument by template deduction (10.1.7.4.1). If a deduced parameter type is not permitted for a template-parameter declaration (17.1), it is ill-formed.

- A template-argument for a non-type template-parameter shall be a converted constant expression (8.2) of the value of the template-parameter. For a non-type template-parameter of reference or pointer type, the value of the constant expression shall not refer to the address of:

  - a subject (4.5),
  - a temporary object (15.2),
  - a string literal (5.13.5),
  - the result of a type expression (8.2.8), or
  - a prenamed __func__ variable (11.4.1).

# 17.3.3 Template arguments

A template-argument for a template-parameter should be the name of a class template or alias template, expressed as id-expression. When the template-argument names a class template, only primary classes are considered when matching the template with the corresponding parameter; specializations are not considered if their parameter lists match that of the template. Any specializations associated with the primary class or variable are considered when a specialization based on the template-parameter is instantiated. If a specialization is not visible at the point of instantiation, and it would have been selected, a diagnostic is required. [Example:
```cpp
template<class T> class A {
int x;
};
template<class T> class A<T*> { // partial specialization
long x;
};
```

A template-parameter P is at least specialized as a template-argument A, if the following rewrite to two function templates, the function corresponding to P is at least specialized as the function template corresponding to A according the partial ordering rules for function templates (17.5.6.2). Given an instance class X with the template list of A (including default arguments):

- (4.1) Each of the two functions has the same template parameters, respectively, as P or A.
- (4.2) Each function template has a single function parameter whose is a specialization of X with arguments corresponding to the respective function template where, for each template parameter PP in the template list of the function, a corresponding template AA is formed. If (17.5.3); otherwise, AA is the id-expression PP.

If the rewrite produces an invalid type, P is not at least specialized as A.

# 17.4 Type equivalence [temp.type]

- 1 Two template-ids refer to the same class, function, or literal if
  - (1.1) their template-names, operator-function-ids, or literal-oper refer to the same template
  - (1.2) their corresponding type-arguments are the same type
  - (1.3) their corresponding non-type template-arguments of integral or enumeration have identical values
  - (1.4) their corresponding non-type template-arguments of pointer type refer to the same object or function or are both the null value
  - (1.5) their corresponding non-type template-arguments of pointer-to-member type refer to the same class member or are both the null member value
  - (1.6) their corresponding non-type template-arguments of reference type refer to the same object or function and
  - (1.7) their corresponding template-arguments refer to the same template.
