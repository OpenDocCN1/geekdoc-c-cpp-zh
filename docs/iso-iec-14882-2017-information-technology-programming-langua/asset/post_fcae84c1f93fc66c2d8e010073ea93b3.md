A member of a class template may be declared a friend of a non-template class. In this case, the corresponding member of every specialization of the primary class and class template partial specializations is a friend of the class granting friendship. For explicit specializations and specializations of partial specializations, the corresponding member is the member (if any) that has the same name, kind (type, function, class template, or function template), template parameters, and signature as the member of the class template instantiation that would otherwise have been generated. [Example:

```cpp
template<typename T> struct A {
struct B {
void f();
struct D {
void g();
};
};
template<> struct A<int> {
struct B {
int f();
struct D {
void g();
};
};
```

```cpp
class C {
template<class T> friend struct A<T>::B; // grants friendship to A<int>::B even though
template<class T> friend void A<T>::f(); // it is not a specialization of A<T>::B
template<class T> friend void A<T>::D::g(); // because its return type does not match
template<class T> friend void A<T>::D::g(); // does not grant friendship to A<int>::g())
// because A<int>::D is not a specialization of A<T>::D
};
// end example
```

[Note: A friend declaration may declare a member of an namespace scope (17.6.5). — end note]

A friend template shall not be declared in a local class.

Friend declarations shall not declare partial specializations. [Example:

```cpp
template<class T> class A {
class X {
template<class T> friend class A<T*>; // error
};
// end example
```

When a friend declaration refers to a specialization of a function template, the function parameter declaration shall not include default arguments, shall not be used in such a declaration.

# ISO/IEC 14882:2017(E)

## 17.5.5 Class template specializations

A primary template declaration is one in which the class template name is an identifier. A template declaration in which the class template name is a `simple-template-id` is a partial specialization of the class named named `simple-template-id`. A partial specialization of a class template provides an alternative definition of the template that is used instead of the primary definition when the arguments in the specialization match those in the partial specialization. The primary template shall be declared before any specializations of that template. A partial specialization shall be declared before the first use of a class template specialization that would make use of the partial specialization as the result of an explicit or implicit instantiation in every translation unit where no diagnostic occurs;

- Each class partial specialization is a distinct template and definitions shall be provided for the members of that template partial specialization (17.5.5.3).

[Example]

```cpp
template< T1, T2 > class A {
};
template< T1, T2 > class A<class T*, I> {
};
template< T1, T2 > class A<int*, T2, I> {
};
template< T1, T2 > class A<int, T2, S> {
};
```

The first declaration declares the (unspecified) template. The second and subsequent declarations declare specializations of the primary template.

The parameters are specified in the bracketed list that immediately follows the template name. For partial specializations, the argument list is explicitly written immediately following the class template name. Specifically, the order of the template arguments is the sequence in which they appear in the template argument list. Specifically, [Example: The argument list for the primary template in the example above is `<T1, T2, I>`.] [Note: The template argument list shall not be specified in the primary template. For example:

```cpp
template<class T1, T2, I>
class A<T1, T2, I> {}; // error
```

- A class partial specialization may be declared in any scope in which the primary template may be declared (10.3.1, 12.2, 17.5.2). [Example:

```cpp
template<class T> struct A {
struct C {
    template<class T2> struct B {};
    template<class T2> struct B<T2> {}; // partial specialization #1
};
// partial specialization
template<class T> template<class T2>
struct A<T>::C<T2> {}; // #2
A<int>::C<int> b; // uses #2
```

Partial declarations are not found by lookup. Rather, when the primary template name is used, any previously-declared specializations of the primary template are considered. One consequence is that a `using-declaration` which refers to a class template does not restrict the set of specializations which may be found through the `using-declaration`. [Example:

```cpp
namespace N {
    template<class T1, class T2> class A {}; // primary template
}
using N::A; // refers to the primary template
namespace N {
    template<class T> class A<T, T> {}; // partial specialization
}
A<int, int> a; // uses the partial specialization, which refers to the primary template
    // end example]
```

- 7 A non-type argument is non-specialized if it is the name of a non-type argument. All other non-type arguments are specialized.

- 8 Within the argument list of class template specialization, the following restrictions apply:
(8.1) The type of template corresponding to a non-type argument should not be dependent on a parameter of the specialization. [Example:

```cpp
    template<class T, T> struct C {};
    template<class T> struct C<T> {}; // error

    template<int X, int (*array)[X]> class A {
    int array[5];
    template<int X> class A<X>; // error
    // end example
```
(8.2) The specialization should be more specialized than the primary template (17.5.5.2).
(8.3) The template parameter list of specialization should not contain default values of the argument list.
(8.4) An argument should not contain an expanded pack. If an argument is an expansion (17.5.3), it should be the last argument in the template argument list.

## 17.5.5.1 Matching of class template specializations

When a class template is used in a context that requires an instantiation of the class, it is necessary to determine whether the instantiation is to be generated using the primary template or one of the partial specializations. This is done by matching the template arguments of the class template specialization with the template argument list of the partial specializations.

- (1.1) If exactly one matching specialization is found, the instantiation is generated from that specialization.
- (1.2) If more than one matching specialization is found, the partial order (17.5.5.2) are used to determine whether one of the specializations is more specialized than the others. If none of the specializations is more specialized than all of the other specializations, then the use of the class template is ambiguous and compilation is ill-formed.
- (1.3) If no matches are, the instantiation is generated from the primary template.

- 2 A partial specialization matches a class template if the template arguments of the partial specialization can be deduced from the actual template argument list (17.8.2). [Example:

```cpp
template<class T1, class T2, int I> class A {}; // #1
template<class T1, int I> class A<T1, T*, I> {}; // #2
template<class T1, class T2, int I> class A<T1*, T2, I> {}; // #3
```

There is no way in which they could be used.

```cpp
template<class T> class A<int, T*, 5> { }; // #4
template<class T1, T2, int> class A<T1, T2, I> { }; // #5
A<int, I> a1; // uses #1
A<int, int*> a2; // uses #2, T is int, I is 1
A<int, char*, 5> a3; // uses #4, T is char
A<int, char*, I> a4; // uses #5, T1 is char, T2 is I is 1
A<int*, int*, 2> a5; // ambiguous: matches #3 and #5
// end example
```

- 3 If the arguments of a partial specialization are deduced because of the structure of the template-id, the program is ill-formed. [Example:

```cpp
template<int, I> struct A {};
template<int> struct A<I2> {}; // error
template<int> struct A<CI> {}; // OK
template<int, int> struct B {};
template<int> struct B<CI, I2> {}; // OK
// end example]

- 4 In a type that refers to a class specialization (e.g., class template, int, I) the template parameter list of the primary template. The template arguments of a specialization are deduced from the arguments of the primary template.

## 17.5.5.2 Ordering of class template specializations

- 1 For class partial specializations, the first is more specialized than the second, if the following return two functions, the first template is more specialized than the second according to the ordering rules for function templates (17.5.6.2):
(1.1) Each of the two functions has the same parameters as the corresponding partial specialization.
(1.2) Each function has a single function whose type is a class template specialization where the template arguments are the corresponding template parameters from the function template for each template argument in the template-argument-list of the simple-template-id of the partial specialization.

- 2 [Example:

```cpp
template<int, int, class T> class X {};
template<int, int> class X<XI, int> {}; // #1
template<int> class X<CI, I> {}; // #2
template<int, IO> void f(X<IO, IO, int>); // /A
template<int, IO> void f(X<IO, IO, int>); // /B
template<class T> class Y {};
template<class* p> class Y<class* p>; // #3
template<class** pp> class Y<class** pp>; // #4
template<class* p0> void g(Y<class* p0>); // /C
template<class** pp0> void g(Y<class** pp0>); // /D
```

According to the ordering rules for function templates, the function B is more specialized than the function template A and the function template D is more specialized than the function template C.
