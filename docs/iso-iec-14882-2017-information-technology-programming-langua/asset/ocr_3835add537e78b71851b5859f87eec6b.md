# 30.5.3.1.1 Class ios_base::failure [ios::failure]

```
namespace std {
    class ios_base::failure : public system_error {
    public:
        explicit failure(const string& m, const error_code ec = io_errc::stream);
        explicit failure(const char* m, const error_code ec = io_errc::stream);
    };
}
```

An implementation is permitted to define ios_base::failure as a synonym for a class with equivalent functionality to ios_base::failure shown in this subclass. [Note: When ios_base::failure is the injected class name—end note] The failure defines the base class for all types that might provide a nested type, failure to emulate the injected class name as exceptions, by functions in the ostreams library, to report errors detected during buffer operations.

When ios_base::failure exceptions occur, implementations should follow values of ec that identify the specific reason for the failure. [Note: Errors arising from the operating system would typically be reported as system_category() with an error value of the error reported by the operating system. Errors arising from the stream library would typically be reported as error_code(io_errc::stream, iostream_category()).

```
explicit failure(const string& m, const error_code ec = io_errc::stream);
```

Effects: Construct an object of class failure by constructing the base class with msg and ec.
