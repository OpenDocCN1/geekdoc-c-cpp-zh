# 23.8 Storage for any type [any]

+   1. This section describes how C++ programs may use any to perform operations on objects of a discriminated type.

+   2. [Note: The discriminated type may contain values of different types but does not attempt conversion between them, i.e. 5 is held as an int and is not implicitly convertible to "5" or 5.0. This indifference to interpretation but awareness of type effectively allows generic containers of single values, with no scope for ambiguous conversions.—end note]
