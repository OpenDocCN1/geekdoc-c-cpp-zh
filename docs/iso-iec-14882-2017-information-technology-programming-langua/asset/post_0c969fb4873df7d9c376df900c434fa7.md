## 23.3.3 Alias template make_integer_sequence

```cpp
template<T, N>
using make_integer_sequence = integer_sequence<T, see below>;
```

> If N is negative the program is ill-formed. The alias template make_integer_sequence denotes a specialization of integer_sequence with N non-type arguments. The type make_integer_sequence<T, N> denotes the type integer_sequence<T, 0, 1, ..., N-1>. [Note: make_integer_sequence<int> denotes the type integer_sequence<int> — end note]

## 23.4 Pairs

### 23.4.1 General

1 The library provides a template for heterogeneous values of pairs. The library also providing a function template to simplify their construction and several templates that provide access to pair objects if they were tuple objects (see 25.3.6 and 25.3.7).

### 23.4.2 Class pair

```cpp
namespace std {
  template<class T1, class T2>
  struct pair {
    using first_type = T1;
    using second_type = T2;

    T1 first;
    T2 second;

    pair(const pair&) = default;
    pair(pair&&) = default;
    explicit pair();
    explicit constexpr pair(const T1& x, const T2& y);
    template<class U1, U2> explicit constexpr pair(U1&& x, U2&& y);
    template<class U1, U2> explicit constexpr pair(const U1&, U2& y);
    template<class U1, U2> explicit constexpr pair(U1&&, const U2&&);
    template<class... Args>
    pair(const tuple<Args...>& args) -> pair<first_args, tuple<Args...> second_args>;

    pair* operator=(const pair& p);
    template<class U1, U2> pair& operator=(const pair<U1, U2>& p);
    template<class U1, U2> pair& operator=(pair<U1, U2>&& p);

    void swap(pair& p, pair&& p) noexcept(see below);
  };

  (see below);

  template<class T1, class T2>
  pair(T1, T2) -> pair<T1, T2>;
}
```

1 Constructors and member functions of pair shall not throw exceptions unless one of the elementwise operations specified to be called for that operation throws an exception.

2 The default move and copy constructor, respectively, of pair shall be a constexpr function if and only if all required element-wise initializations for copy and move, satisfy the requirements for a constexpr function. The destructor of pair shall be a trivial destructor if (is_trivially_destructible_v<T1> && is_trivially_destructible_v<T2>) is true.

```cpp
constexpr pair();
```

3 Effects: Value-initializes first and second.
4 Remarks: This constructor shall not participate in overloads resolution unless is_default_constructible_v<second_type> is true. [Note: this behavior can be implemented by a constructor template argument. — The constructor is explicit if and only if either first_type or second_type is not implicitly default-constructible. [Note: this behavior can be implemented with a trait that checks whether a first_type or second_type can be initialized with {}. — end note]

```cpp
constexpr pair(const T1& x, const T2& y);
```

5 Effects: Initializes first and second with y.
6 Remarks: This constructor shall not participate in overloads resolution unless is_copy_constructible_v<first_type> is true and is_constructible_v<second_type> is true. The constructor is explicit if and only if is_convertible_v<second_type, first_type> is false or is_convertible_v<second_type, second_type> is false.

```cpp
template<class U1, class U2> constexpr pair(forward<U1> x, forward<U2> y);
```

7 Effects: Initializes first and second with x.
8 Remarks: This constructor shall not participate in overloads resolution unless is_constructible_v<first_type> is true and is_constructible_v<second_type, U2&> is true. The constructor is explicit if and only if is_convertible_v<U1, first_type> is false or is_convertible_v<U2&, second_type> is false.

```cpp
template<class U1, class U2> constexpr pair(const U1& p, const U2& q);
```

9 Effects: Initializes from the corresponding members of the argument.
10 Remarks: This constructor shall not participate in overloads resolution unless is_constructible_v<first_type> is true and is_constructible_v<second_type, U2&> is true. The constructor is explicit if and only if is_convertible_v<U1, first_type> is false or is_convertible_v<U2&, second_type> is false.

```cpp
template<class U1, class U2> constexpr pair(pair<U1, U2>&& p);
```

11 Effects: Initializes first with forward<U1>(p.first) and second with forward<U2>(p.second).
12 Remarks: This constructor shall not participate in overloads resolution unless is_constructible_v<first_type> is true and is_constructible_v<second_type, U2&> is true. The constructor is explicit if and only if is_convertible_v<U1, first_type> is false or is_convertible_v<U2&, second_type> is false.

```cpp
template<class... Args> pair(piecewise_construct, Args&&...);
```

13 Requires: is_constructible_v<first_type, Args&&...> is true and is_constructible_v<second_type, Args&&...> is true.
14 Effects: Initializes first with arguments of types Args... obtained by forwarding the elements of second and initializes second with arguments of type Args... whereby constructor first and second are each provided in a tuple, called piecewise construction.

```cpp
pair& operator=(const pair& p);
```

Effects: Assigns p.first to first and p.second to second.
Remarks: This operator shall be defined if is_copy_assignable_v<first_type> is true and is_copy_assignable_v<second_type> is true.
Returns: *this.

```cpp
template<class U1, class U2> U2& operator=(const U1& u, const U2& p);
```

Effects: Assigns p.first to first and p.second to second.
Remarks: This operator shall not participate in overload resolution unless is_assignable_v<first_type, U1&> is true and is_assignable_v<second_type, U2&> is true.
Returns: *this.

```cpp
pair& operator=(pair&& p) noexcept(see below);
```

Effects: Assigns forward<U1>(p.first) to first and forward<U2>(p.second) to second.
Remarks: This operator shall be defined if is_move_assignable_v<first_type> is true and is_move_assignable_v<second_type> is true.
The expression is equivalent to: is_not_move_assignable_v<first_type> && is_not_move_assignable_v<second_type>.

```cpp
template<class U1, class U2> U2& operator=(pair<U1, U2>&& p);
```

Effects: Assigns forward<U1>(p.first) to first and forward<U2>(p.second) to second.
Remarks: This operator shall not participate in overload resolution unless is_assignable_v<first_type, U1&&> is true and is_assignable_v<second_type, U2&&> is true.
Returns: *this.

```cpp
void swap(pair&& p) noexcept(see below);
```

Requires: first shall be swappable with p.first and second shall be swappable with p.second.
Effects: Swap first with p.first and second with p.second.
The expression is equivalent to: is_not_swappable_v<first_type> && is_not_swappable_v<second_type>.

## 23.4.3 Specialized algorithms

[pairs.spec]

```cpp
template<class T1, class T2> constexpr bool operator=(const T1& x, const T2& y, const T1& x, const T2& y);
```

Returns: *x.first == y.first && x.second == y.second.

```cpp
template <class T1, class T2>
constexpr bool operator<(const pair<T1, T2>& x, const pair<T1, T2>& y);
```

2 RETURNS: x.first < y.first || !(y.first < x.first && x.second < y.second).

```cpp
template <class T1, class T2>
constexpr bool operator!=(const pair<T1, T2>& x, const pair<T1, T2>& y);
```

3 RETURNS: !(x == y).

```cpp
template <class T1, class T2>
constexpr bool operator>(const pair<T1, T2>& x, const pair<T1, T2>& y);
```

4 RETURNS: y < x.

```cpp
template <class T1, class T2>
constexpr bool operator<=(const pair<T1, T2>& x, const pair<T1, T2>& y);
```

5 RETURNS: !(x < y).

```cpp
template<class T1, class T2>
void swap(pair<T1, T2>& x, pair<T1, T2>& y);
```

6 noexcept(except(x.swap(y)));

7 Effects: As if x.swap(y).

8 Remarks: This function shall not participate in overload resolution unless is_swappable_v<T1> is true and is_swappable_v<T2> is true.

```cpp
template <class T1, class T2>
constexpr pair<V1, V2> make_pair(T1&& x, T2&& y);
```

9 RETURNS: pair<V1, V2>(std::forward<T1>(x), std::forward<T2>(y)), where V1 and V2 are determined as follows: Let Ui be decay_t<Ti> for each Ti. If Ui is a specialization of reference_wrapper, then Vi is Ui::element_type; otherwise Vi is Ui.

10 [Example: In place of:

```cpp
return pair<int, double>(5, 3.141526); // explicit types
a C++ program may have:
return make_pair(5, 3.141526); // types are deduced
// end example ]
