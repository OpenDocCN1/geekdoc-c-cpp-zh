# 21.8.3 Class bad_exception [bad.exception]

```
namespace std {
    class bad_exception : public exception {
    public:
        bad_exception() noexcept;
        bad_exception(const bad_exception&) noexcept;
        bad_exception& operator=(const bad_exception&) noexcept;
        const char* wat() const noexcept override;
    };
}
```

The bad_exception defines the type of the object referenced by the exception_ptr returned from a current exception (21.8.6) when the active exception object fails to copy.

bad_exception() noexcept;

Effects: Constructs an object of bad_exception.

bad_exception(const bad_exception&) noexcept;
bad_exception& operator=(const bad_exception&) noexcept;

Effects: Copies an object of class bad_exception.

const char* wat() const noexcept override;

# 21.8.4 Abnormal termination [exception.terminate]

# 21.8.4.1 Type terminate_handler [terminate.handler]

```
using terminate_handler = void (*)();
```

The type of a handler function to be called by: :terminate() when terminating exception processing.

Required behavior: A terminate_handler shall terminate execution of the program without returning to the caller.

Default behavior: The implementation's default terminate_handler calls abort().

# 21.8.4.2 set_terminate [set.terminate]

terminate_handler set_terminate(terminate_handler f) noexcept;

Effects: Establishes the function designated by f as the current handler function for terminating exception processing.

Remarks: It is unspecified whether a null pointer designates the default terminate_handler.

Returns: The previous terminate_handler.
