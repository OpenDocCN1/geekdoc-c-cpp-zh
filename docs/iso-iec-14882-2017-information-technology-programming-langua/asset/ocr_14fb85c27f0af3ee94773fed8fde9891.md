# 26.4.2 Node handles [container::node]

# 26.4.2.1 node_handle overview [container::node]

+   A node is an object that accepts ownership of a single element from an associative container (26.2.7), or an unordered associative container. It may be used to transfer ownership to another container with compatible nodes. Containers with compatible nodes have the same node handle type. Elements may be transferred in either direction between containers in row of Table 89.

+   If a node is not empty, then it contains an allocator that is equal to the allocator of the container when the element was extracted. If a node handle is empty, it contains no allocator.
