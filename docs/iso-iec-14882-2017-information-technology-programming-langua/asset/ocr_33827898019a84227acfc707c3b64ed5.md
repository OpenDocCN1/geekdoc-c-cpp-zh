# 30.6.3.4  basic_streambuf virtual functions [streambuf.virtual]

# 30.6.3.4.1  Locales [streambuf.virt.locales]

```
void imbue(const locale&);
```

Effects: Change any translations by locale.

Remarks: Allows the derived class to be informed of changes in locale at the time they occur. Between invocations of this class a derived class from streambuf can safely cache results of calls to locale functions and to members of facts so obtained.

Default behavior: Does nothing.

# 30.6.3.4.2  Buffer management and notification [streambuf.buffer]

```
streambuf* setbuf(char_type* s, streamize n);
```

Effects: Influences buffering in a way that is defined separately for each class derived from streambuf in this Clause (30.9.2.1, 30.9.2.4).

Default behavior: Does nothing. Returns this.
