# ISO/IEC 14882:2017(E)

```
system_error(error_code ec, const char* what_arg);
```

+   3 Effects: Constructs an object of class system_error.

+   4 Postconditions: code() == ec and string(what()).find(what_arg) != string::npos.

```
system_error(error_code ec);
```

+   5 Effects: Constructs an object of class system_error.

+   6 Postconditions: code() == ec.

```
system_error(int ev, const error_category& ec, const string& what_arg);
```

+   7 Effects: Constructs an object of class system_error.

+   8 Postconditions: code() == error_code(ev, ec) and string(what()).find(what_arg) != string::npos.

```
system_error(int ev, const error_category& ec, const char* what_arg);
```

+   9 Effects: Constructs an object of class system_error.

+   10 Postconditions: code() == error_code(ev, ec) and string(what()).find(what_arg) != string::npos.

```
system_error(int ev, const error_category& ec);
```

+   11 Effects: Constructs an object of class system_error.

+   12 Postconditions: code() == error_code(ev, ec).

```
const error_code& code() constexcept;
```

+   13 Returns: ec or error_code(ev, ec), from the constructor, as appropriate.

```
const char* what() const noexcept;
```

+   14 Returns: An NTBS incorporating the arguments supplied in the constructor.

> [Note: The returned NTBS might be the contents of what_arg + " " + code.message(). — end note]
