# ISO/IEC 14882:2017(E)

If could leaves a registered function by exit because the function does not provide a handler for a thrown exception, std::terminate() shall be called (18.5.1).

(9.2) Next, all open C streams (as mediated by the function signatures declared in <cstdio>) with unwritten buffer data are flushed, all open C streams are closed, and all files created by calling tmpfile() are removed

(9.3) Finally, control returns to the host environment. If status is zero or EXIT_SUCCESS, an implementation-definition of the status successful termination is returned. If status is EXIT_FAILURE, an implementation-definition of the status unsuccessful termination is returned. Otherwise the status is returned implementation-defined.¹⁷
