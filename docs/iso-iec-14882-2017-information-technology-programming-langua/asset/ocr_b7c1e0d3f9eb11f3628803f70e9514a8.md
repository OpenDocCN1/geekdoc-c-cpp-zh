# ISO/IEC 14882:2017(E)

> Note: A container allocates allocator_traits<A>::construct(m, p, args) to construct an element at p using args with m == get_allocator(). The default construct in allocator will call ::new(void*)T(args), but specialized allocators may choose a different definition. — end note
