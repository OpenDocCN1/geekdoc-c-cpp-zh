# ISO/IEC 14882:2017(E)

```
union Y { int x; int k; };
void g() {
    Y y = { 1, 2 };
    int n = y.x.a;                    // OK, y.x is active union member (12.2)
    y.k = 4;                          // OK: ends lifetime of y.x, y.k is active member of union
                                // undefined behavior: y.x.b modified outside its lifetime,
    y.x.b = n;                        // S(y.x) is empty because X's default constructor is deleted,
                                // so union member y.x's lifetime does not imply static
}
```

[Note: In example, one must use explicit destructor and placement *new-expression* to change the active member of a union. — end note]|Example: An object of type U having non-static members m of type M and n of type N. If M has a non-trivial destructor and N has a non-trivial constructor for n to use, if they declare or inherit the destructor and placement *new-expression* as follows:

```
u.~M();
new (&u.n) N;
```

# 12.3.1 Anonymous unions

[class.union.anon]

+   1 A union of the form

```
union { int a; const char* p; };
```

is called an anonymous union; it defines an unnamed type and an unnamed object of that type called an anonymous union. Each member-declaration in the member-specification of an anonymous union shall either define non-static data member or be a static *assert-declaration*. [Note: Nested types, anonymous functions cannot be declared within an anonymous union. — end note] The names of members of an anonymous union shall be distinct from the names of any other entity in the scope in which the anonymous union is declared. For the purpose of name lookup, after the anonymous union definition, the members of the union are considered to have been defined in the scope in which the anonymous union is declared. [Example:

```
void f() {
    union { int a; const char* p; };
    a = 1;
    p = "*";
}
```

Here a and p are used like ordinary (non-member) variables, but since they are members they have the same address. — end example

+   2 Anonymous unions declared in a named namespace or in the global namespace shall be static. Anonymous unions declared at block scope shall be declared with any storage class for a block-scope variable, or with no storage. A storage class is not allowed in a declaration of an anonymous union in a block scope. An anonymous union shall not have private or protected members (Clause 14). An anonymous union should not have member functions.

+   3 A union for which objects, pointers, or references are declared is not an anonymous union. [Example:

```
void f() {
    union { int a; char* p; } *ptr = &obj;
    a = 1;                        // error
    ptr->a = 1;                                  // OK
}
```
