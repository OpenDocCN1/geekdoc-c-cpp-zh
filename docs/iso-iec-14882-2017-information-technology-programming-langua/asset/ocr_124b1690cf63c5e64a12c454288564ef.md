# ISO/IEC 14882:2017(E)

template <class InputIterator>
multiset(InputIterator first, InputIterator last,
const Compare& comp = Compare(), const Allocator& alloc = Allocator());

+   3 Effects: Creates an empty multiset using the specified comparison object and inserts elements from the range [first, last).

+   4 Complexity: Linear in N if range [first, last] is already sorted using comp and otherwise O log N, where N is last - first.

# 26.4.7 multiset sorted algorithms [multiset.special]

```
template <class Key, class Compare, class Allocator>
void swap(multiset<Key, Compare, Allocator>& x,
multiset<Key, Compare, Allocator>& y)
noexcept(noexcept(x.swap(y)));
```

+   1 Effects: As if x.swap(y).

# 26.5 Unordered associative containers [unordered.general]

# 26.5.1 In general

+   1 The header <unordered_map> defines the classes unordered_map and unordered_map; the header <unordered_set> defines the classes unordered_set and unordered_multiset.

+   2 The exposition-only aliases template iter_key_t, iter_val_t, and iter_alloc_t defined in 26.4.1 may appear in deduction guides for unordered containers.

# 26.5.2 Header <unordered_map> synopsis [unordered.map.syn]

```
#include <initializer_list>
namespace std {
// 26.5.1. class template unordered_map
template <class Key>
class T,
class Hash = hash<Key>,
class Pred = equal_to<Key>,
class Alloc = allocator<pair<const Key, T>>

```

```
// 26.5.5. class template unordered_multimap
```
