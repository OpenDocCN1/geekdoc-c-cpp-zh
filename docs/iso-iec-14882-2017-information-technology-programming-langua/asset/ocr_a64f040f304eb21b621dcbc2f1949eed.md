# ISO/IEC 14882:2017(E)

```
void str(const basic_string<char, Allocator>& s);
```

Effects: Copies s into the stringbuf underlying character sequence and initializes the input and output sequences according to mode.

Postconditions: If mode & ios_base::out is nonzero, phase() points to the underlying character and eptr() == phase() + s.size() holds; if mode & ios_base::at is nonzero, pptr() == phase() + s.size() holds, else pptr() == phase is true. If mode & ios_base::in is nonzero, eback() points to the underlying character, and both gptr() == eback() and egptr() == eback() + s.size() holds.

```
int_type putback(int_type c = traits::eof()) override;
```

Effects: Puts the character designated by c to the output sequence, if possible, in one of three:

+   - If traits::eq_int_type(c, traits::eof()) returns false and if the input sequence has putback position available, and if traits::eq(to_char_type(c), gptr()[-1]) returns true, assigns gptr() - 1 to gptr().

Returns: c.

+   - If traits::eq_int_type(c, traits::eof()) returns false and if the input sequence has putback position available, and if mode & ios_base::out is nonzero, s to--gptr().

Returns: c.

+   - If traits::eq_int_type(c, traits::eof()) returns true and if the input sequence has putback position available, assigns gptr() - 1 to gptr().

Returns: not_eof(c).

Returns: As specified above, or traits::eof() to indicate failure.

Remarks: If the function can succeed in more than one of these, it is unspecified which is chosen.

```
int_type overflow(int_type c = traits::eof()) override;
```

Effects: Appends the character designated by c to the output sequence, if possible, in one of two:

+   - If traits::eq_int_type(c, traits::eof()) returns false and if either the output sequence has a write position available or the function can make a write position available (as described below), the function sput(c).

Signals by returning

+   - If traits::eq_int_type(c, traits::eof()) returns true, there is no character to append.

Signals by returning

Remarks: The function can alter the number of write positions available as a result of any call.

Returns: As specified above, or traits::eof() to indicate failure.

The function can make a write position available only if (mode & ios_base::out) != 0. To make a write position available, the function reallocates (or initially allocates) an object with sufficient number of elements to hold the current array (if any), plus at least one additional write position.
