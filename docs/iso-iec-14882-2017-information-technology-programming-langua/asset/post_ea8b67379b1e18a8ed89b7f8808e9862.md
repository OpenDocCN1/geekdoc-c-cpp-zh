## 23.17.5-8 Suffixes for duration literals [time::duration::ms,]

- 1 This section describes literal suffixes for constructing duration literals. The suffixes h, min, s, us, ns duration value of the constructing hours, minutes, seconds, milliseconds, microseconds, and nanoseconds are preserved if they are applied to integral literals.
- 2 If any of these suffixes are applied to a floating-point literal the result is a chrono::literal with unspecified floating-point representation.
- 3 If any of these suffixes are applied to an integer literal and the resulting chrono::duration value cannot be represented in the result type because of overflow, the program is ill-formed.
- 4 The following example shows some duration literals.
using namespace std::chrono_literals;
auto constexpr aday=24h;
auto constexpr lesson=45min;
auto constexpr halfhour=0.5h;
-- end example --
