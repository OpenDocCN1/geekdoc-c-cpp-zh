# ISO/IEC 14882:2017(E)

3 If a formatted output function of a stream determines padding, it does so as follows. Given a charT character sequence where charT is the character type of the stream, if the length of seq is less than os.width(), enough copies of os.fill() are added to this sequence as necessary to pad to a width of os.width() characters. If os.flags() & ios_base::justfield() == ios_base::left, the characters are placed after the character sequence; otherwise, they are placed before the character sequence.

4 Effects: The classes num_get<> and num_put<> handle locale-dependent numeric formatting and parsing. These inserters use the imbued locale to perform numeric formatting. When val is of type bool, long, unsigned long, unsigned int, unsigned long, double, or const void*, formatting conversion occurs as it performed the following code fragment:

```
bool failed = use_facet(
num_put<charT, ostreambuf_iterator<charT, traits>>(
(getloc())).put(*this, *this, fill(val), failed));

```

When val is of type short the formatting conversion occurs as it performed the following code fragment:

```
ios_base::flags baseflags = flags() & ios_base::basefield;
bool failed = use_facet(
num_put<charT, ostreambuf_iterator<charT, traits>>(
(getloc())).put(*this, *this, fill(
baseflags == ios_base::oct || baseflags == static_cast<unsigned short>(val)
? static_cast<static_cast<unsigned int>>(val)
: static_cast<long>(val)).failed));

```

When val is of type int the formatting conversion occurs as it performed the following code fragment:

```
ios_base::flags baseflags = flags() & ios_base::basefield;
bool failed = use_facet(
num_put<charT, ostreambuf_iterator<charT, traits>>(
(getloc())).put(*this, *this, oct(
baseflags == ios_base::oct || baseflags == static_cast<unsigned int>(val)
? static_cast<long>(val)).failed));

```
