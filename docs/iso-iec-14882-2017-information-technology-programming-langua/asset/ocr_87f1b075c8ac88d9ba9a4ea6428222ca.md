# ISO/IEC 14882:2017(E)

# 23.5.3.6 Tuple helper classes [tuple_helper]

```
template <class T> struct tuple_size;
```

Remarks: All specializations of tuple_size shall meet the UnaryTrait requirements (23.15.1) with a basic characteristic of integral_constant<size_t, N> for some N.

```
template <class Types...>
class tuple_size<Types...> : public integral_constant<size_t, sizeof...(Types)> {};
```

```
template <size_t I, class Types...>
class tuple_element<I, tuple<Types...>> {
public:
```

```
using type = TI;
```

Requires: I < sizeof...(Types). The program is ill formed if I is out of bounds.

Note: TI is the type of the I element of Types, indexing is zero-based.

```
template <size_t I, class T> class tuple_element<I, const T>
template <size_t I, class T> class tuple_element<I, volatile T>
template <size_t I, class T> class tuple_element<I, T>;
```

Let TE denote tuple_size of the ce-unqualified type T. If the expression TS::value is wellformed when treated as an operand, then each of the three templates shall meet the UnaryTrait requirements (23.15.1) with a basic characteristic of

```
integral_constant<size_t, TS>;
```

Otherwise, they have no member value.

Access is permitted if in a context unrelated to TS and only the value of the immediate expression is considered. [Note: The compilation of the expression can result in effects such as the instantiation of template specializations and function template specializations, the generation of implicitly-defined functions, and so on. Such effects are not in the "immediate context" and can result in the program being ill-formed.

> end note |

In addition available via inclusion of the <tuple> header, the three templates are available when either of the headers <array> or <utility> are included.

```
template <size_t I, class T> class tuple_element<I, const T>
template <size_t I, class T> class tuple_element<I, volatile T>
template <size_t I, class T> class tuple_element<I, T>;
```

Let TE denote tuple_size of the ce-unqualified type T. Each of the three templates shall meet the TransformationTrait requirements (23.15.1) with a member typedef name that has the following type:

+   - for the first specialization, add_const<T<TE>>,
- for the second specialization, add_volatile<T<TE>>,
- for the third specialization, add_cv<T<TE>>.

In addition available via inclusion of the <tuple> header, the three templates are available when either of the headers <array> or <utility> are included.
