# 26.5.5 Class template unordered_multimap

# 26.5.5.1 Class template unordered_multimap overview

An unordered_multimap is an associative container that supports elements (instances of unordered_multimap may contain multiple copies of each key value) and associates values of another mapped type with keys. The unordered_multimap supports forward iterators.

An unordered_multimap satisfies all the requirements of a container, of an associative container, and an allocator-aware container (Table 86). It provides the operations described in the preceding requirements for equal elements, as unordered_multimap supports the a_eq operations in table, not the uniq_operations. For an unordered_multimap<Key, T>, the key type is Key, the mapped type is T, and the value type is pair<const Key, T>.
