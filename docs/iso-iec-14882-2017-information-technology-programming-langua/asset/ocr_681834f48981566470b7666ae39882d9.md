# ISO/IEC 14882:2017(E)

# 13 Derived classes [class.derived]

+   1 A list of base classes can be specified in a class definition using the notation:
base-class:
  - base-specifier-list
base-specifier-list:
  base-specifier ...opt
  base-specifier-list, base-specifier ...opt
base-specifier:
  attribute-specifier-seq_opt class-or-detype
  attribute-specifier-seq_opt virtual access-specifier_opt class-or-detype
  attribute-specifier-seq_opt virtual access-specifier class-or-detype
class-or-detype:
  nested-specifier_opt class-name
  nested-specifier_opt template simple-template-id
  detype-specifier:
access-specifier:
  private
  public

2 The optional attribute shall denote a class type that is not an incompletely defined class (Clause 12). The class denoted by the class-detype of a base-specifier is said to be a direct base class for the class being defined. If the name is not found during the lookup for a base class of D a non-type names are ignored (6.3.10). If B is a base class of D if it is a direct base class of D or a direct base class of D is said to be (directly or indirectly) derived from its (direct or indirect) base classes. A class is an indirect base class of another if it is a base class but not a direct base class. [Note: See Clause 14 for the meaning of access-specifier.] Undeclared in the derived class, members of base classes are also considered members of the derived class. Members of a base class other than constructors are to be inherited by the derived class. Construction of a class can also be inherited in 10.3.3. If members are referred to in expressions the same name as members of the derived class, their names are hidden or ambiguous (13.2). [Note: The scope resolution operator :: (8.1) can be used to refer to a direct or indirect base class membership. This allows access to a name that has been redeclared in the derived class. A derived class can itself serve as a base class subject to access control; see 14.2. A pointer to a derived class can be implicitly converted to a reference to an unambiguous base class (11.6). — end note]

+   3 The base-specifier-list specifies the type of the base class subobjects contained in an object of the derived type. [Example:

```
struct Base {
  int a, b, c;
};

struct Derived : Base {
  int b;
};
```
