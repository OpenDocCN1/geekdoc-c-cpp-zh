# ISO/IEC 14882:2017(E)

to the same (4.7).

```
constexpr shared_ptr() noexcept
```

Effects: Constructs an empty shared_ptr object.

Postconditions: use_count() == 0 && get() == nullptr.

```
template<class T> explicit shared_ptr(T* p);
```

Requires: p shall be a pointer. The expression delete[] when T is an array type, delete p when T is not an array type, shall have well-defined behavior, and shall not throw exceptions.
Effects: When T is not an array type, it constructs a shared_ptr that owns the object of an unspecified type p. Otherwise, a shared_ptr that owns p and a deleter of an unspecified type calls delete[] when p. If T is not an array type, delete p is called. If an exception is thrown, delete p is called when T is not an array type, delete[] is otherwise.

Postconditions: use_count() == 1 && get() == p.

Throws: bad_alloc, or an implementation-defined exception when resource could not be obtained.
Remarks: When T is an array type, this constructor shall not participate in overload resolution unless the expression delete is well-formed and either T is U[N] and Y[*] is convertible to T*, or T is U() and Y[] is convertible to T*. When T is not an array type, this constructor shall not participate in overload resolution unless expression delete p is well-formed and Y* is convertible to T.

```
template<class T, class D> shared_ptr(T* p, D d);
template<class T, class D, class A> shared_ptr(T* p, D d, A& a);
template<class T, class D, class A> shared_ptr(nullptr_t, D d, D d, A& a);
```

Requires: construction of d and deleter of D initialized with std::move(d) shall not throw. The expression delete(p) shall have well-defined behavior and shall not throw exceptions. A shall be an allocator.
Effects: Constructs a shared_ptr that owns the object p and the deleter d. When T is not an array type, the first and second constructors shall use a copy of a for internal use. If an exception is thrown, d(p) is called.

Postconditions: use_count() == 1 && get() == p.

Throws: bad_alloc, or an implementation-defined exception when resource could not be obtained.

Remarks: When T is an array type, this constructor shall not participate in overload resolution unless is_move_constructible<T, U> is true, the expression d(p) is well-formed, and either T is U[N] or Y(*) is convertible to T*. When T is not an array type, this constructor shall not participate in overload resolution unless is_move_constructible<vD> is true, the expression d(p) is well-formed, and Y* is convertible to T.

```
template<class T> shared_ptr(const shared_ptr<T>& r, element_type* p) noexcept;
```

Effects: Constructs a shared_ptr that stores p and shares ownership with r.

Postconditions: get() == p && r.use_count() == r.use_count().

[Note: To avoid the possibility of a dangling pointer, this constructor should ensure that p remains valid until least the ownership group of r is destroyed.—end note].
