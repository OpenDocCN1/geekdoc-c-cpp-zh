contains the two characters '\xA' and 'B' after concatenation, and not the single hexadecimal character '\xAB'. — end example

After any concatenation, in translation phase 7 (5.2), '\00' is appended to string literal so that programs can find its end character.

Escape sequences and universal-character-names in raw-string literals have the same meaning as in character literals (5.13.3), except that the single quote '\'' is representable either by '\'' or the escape sequence \\' preceded by a \, and except that a universal-character-name may contain more than one element due to multiple encoding. The size of a char32_t for each character requiring sequences, universal-character-names, and other characters, plus one for the size of a char16_t for the number of code-character-names shall be within the range 0x000 to 0xFFFFFF. The size of a raw string literal is the total number of escape sequences and other characters, plus at least one for the multibyte encoding of each universal-character-name, plus one for the terminating '\0'.

Evaluating a string-literal result in a string object with static storage duration, initialized from the given characters as specified. Whether all string literals are distinct (that is, in nonoverlapping objects) and whether successive evaluations of a string-literal yield the same or a different object is unspecified. [Note: The effect of modifying a string literal is undefined.] — end note

# 5.13.6 Boolean literals

The Boolean literals are the keywords false and true. Such literals are values and have type bool.
