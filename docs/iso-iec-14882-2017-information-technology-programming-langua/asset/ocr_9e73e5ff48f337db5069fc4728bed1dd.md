Effects: The simplest transformation from a char value or sequence of chars to the corresponding value.234 The only characters for which unique transformations are required in the basic source character set (5.3).

# 25.4.1.2 Class template type_typename

[locale.ctype.typename]

  class type_typename : public type<char> {
