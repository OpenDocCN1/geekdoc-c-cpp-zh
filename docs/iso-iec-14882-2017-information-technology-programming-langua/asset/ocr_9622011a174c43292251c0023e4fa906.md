# 23.7.3.2 Destructor [variant.dtor]

```
-variant();
```

> Effects: If valueless_by_exception is false, destroys the contained value.

> Remarks: If is_trivially_destructible<v,T> == true for all T, then this destructor shall be a trivial.

# 23.7.3.3 Assignment [variant.assign]

```
variant& operator=(const variant& rhs);
```

+   Let j be rhs.index().

> Effects: If neither rhs holds a value, there is no effect. Otherwise,

+   * if this holds a value but rhs does not, destroys the value contained in *this and sets *this to not hold a value. Otherwise.

+   if index() == j, assigns the value contained in rhs to the value contained in *this. Otherwise,

+   if is_nothrow_move_constructible<v,T> or is_no_move_constructible<v,T> is true, equivalent to emplace<j>(get<j>(rhs)). Otherwise,

```
=this.
```

Returns: *this.

Postconditions: index() == rhs.index().

> Remarks: This function shall not participate in overload resolution unless is_copy_constructible<v,T> && is_copy_assignable<v,T> is true for all i.

```
variant& operator=(variant&& rhs) noexcept(see below);
```

+   Let j be rhs.index().

> Effects: If neither rhs holds a value, there is no effect. Otherwise,

+   * if this holds a value but rhs does not, destroys the value contained in *this and sets *this to not hold a value. Otherwise.

+   if index() == j, assigns get<j>(rhs) to the value contained in *this. Otherwise,

+   equivalent to emplace<j>(get<j>(std::move(rhs))).

Returns: *this.
