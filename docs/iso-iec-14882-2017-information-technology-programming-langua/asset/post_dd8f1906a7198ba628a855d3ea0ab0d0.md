## 30.9.3 Class template basic_ifream

```cpp
namespace std {
    template <class charT, class traits = traits<charT>>
    class basic_ifream : public basic_ifream<charT, traits> {
    public:
        using char_type = charT;
        using int_type = typename traits::int_type;
        using pos_type = typename traits::pos_type;
        using off_type = typename traits::off_type;
        using traits_type = charT;

        // 30.9.3.1, constructors
        basic_ifream();
        explicit basic_ifream(const char* s,
                              ios_base::openmode mode = ios_base::in);
        explicit basic_ifream(const filesystem::path::value_type* s,
                             ios_base::openmode mode = ios_base::in);
        explicit basic_ifream(const string& s,
                              ios_base::openmode mode = ios_base::in);
        explicit basic_ifream(const filesystem::path& s,
                              ios_base::openmode mode = ios_base::in);
        basic_ifream(const basic_ifream& rhs) = delete;
        basic_ifream(basic_ifream&& rhs) = delete;

        // 30.9.3.2, assign and swap
        basic_ifream& operator=(const basic_ifream& rhs) = delete;
        basic_ifream& operator=(basic_ifream&& rhs) = delete;
        void swap(basic_ifream& rhs);

        // 30.9.3.3, members
        basic_filebuf<charT, traits>* rdbuf() const;
        bool is_open();
        void open(const char* s, ios_base::openmode mode = ios_base::in);
        void open(const filesystem::path::value_type* s,
                  ios_base::openmode mode = ios_base::in); // wide systems only; see 30.9.1
        void open(const string& s, ios_base::openmode mode = ios_base::in);
        void open(const filesystem::path& s, ios_base::openmode mode = ios_base::in);
        void close();
    private:
        basic_filebuf<charT, traits> sb;

    template <class charT, class traits>
    void swap(basic_ifstream<charT, traits>& x,
             basic_ifstream<charT, traits>& y);
};
```

- 1 The class basic_ifstream<charT, traits> supports reading from named files. It uses a basic_filebuf<charT, traits> object to control the associated sequence. For the sake of exposition, the maintained data is presented here:
- (1.1) sb, the filebuf object.

## 30.9.3.1 basic_ifstream constructors

```cpp

```

- 1 Effects: Constructs an object of class basic_ifstream<charT, traits>, initializing the base class with basic_ifstream<charT, traits>&(kb) (30.7.4.1) and initializing sb with basic_filebuf<charT, traits>()(30.9.2.1).

```cpp
explicit basic_ifstream(const char* s,
                             ios_base::openmode mode = ios_base::in);
explicit basic_ifstream(const filesystem::path::value_type* s,
                        ios_base::openmode mode = ios_base::in); // wide systems only; see 30.9.1
```

- 2 Effects: Constructs an object of class basic_ifstream<charT, traits>, initializing the base class with basic_ifstream<charT, traits>&(kb) (30.7.4.1) and calls rdbuf()->open(s, mode | ios_base::in). If that function returns a null pointer, it calls setfail(failbit).

```cpp
explicit basic_ifstream(const string& s,
                             ios_base::openmode mode = ios_base::in);
explicit basic_ifstream(const filesystem::path& s,
                        ios_base::openmode mode = ios_base::in);
```

- 3 Effects: The same as basic_ifstream(s.c_str(), mode).
- 4 Effects: Moves from the rvalue rhs. This is implemented by moving the base class, and the contained filebuf. Next basic_ifstream<charT, traits>::rdbuf(&kb) is called to install the contained filebuf.
