auto x4 = (i); // decltype(x4a) is int
decltype(auto) x4d = i; // decltype(x4d) is int&
auto x5 = f(); // decltype(x5a) is int

auto x6 = {1, 2}; // decltype(x6a) is int::initializer_list<int>
decltype(auto) x6d = {1, 2}; // error: is not an expression

decltype(auto) x7d = &i; // error: type is not plain decltype(auto)

# 10.1.7 Deduced class specialization types

+   1 A placeholder for a deduced class type is a decl-specifier in the decl-class-seq of an initializing declaration [11.6] of a variable, the placeholder is replaced by the return type of the function by overload resolution for class template deduction [16.3.1.8]. If the decl-class-seq is followed by an init-declator-list or member-declator-list containing more than one declarator, the type that replaces the placeholder shall be the same in each deduction.
2 A placeholder for a deduced class type can also be used in the new-type-id or type-id of a new-expression [8.3.4], or as the simple-type-specifier in an explicit type conversion (functional notation) [8.2.3]. A placeholder for a deduced class type shall not appear in any other context.
3 Example:

```
template<T> struct container {
    container(T) {}
    template<class Iter>
    container(Iter beg, Iter end);
};
template<class Iter> container(Iter b, Iter e) : container<typename std::iterator_traits<Iter>::value_type>{
std::vector<double> v = { /* ... */ };
};

container c(); // OK, deduces int for T
auto d = container(v.begin(), v.end()); // error, int is not an iterator
container e(5, 6);
//-- end example
```

# 10.2 Enumeration declarations

+   1 An enumeration is a distinct type [6.9.2] with named constants. Its name becomes an enum-name within its scope.

enum-name:
    identifier

enum-specifier:
    enum-head { enumerator-list-opt }
    enum-head { enumerator-list , }

enum-head:
    enum-key attribute-specifier-seqopt enum-name-opt enum-base-opt
nenum-head-name:
    named-name-specifier-seqopt identifier

opaque-enum-declaration:
    enum-key attribute-specifier-seqopt named-name-specifier-seqopt identifier enum-base-opt;
