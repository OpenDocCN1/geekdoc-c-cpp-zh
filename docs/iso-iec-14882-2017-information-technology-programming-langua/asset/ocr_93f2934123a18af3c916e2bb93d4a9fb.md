This form of construction, whereby constructor arguments first and second are each provided in a tuple object, is called piecewise_construction.

```
pair& operator=(const pair& p);
```

Effects: Assigns p.first to first and p.to second.

Remarks: This operator shall be defined as undefined if is_copy_assignable_v<first_type> is true and is_copy_assignable_v<second_type> is true.

Returns: *this.

```
template<class U1, class U2> U2& operator=(const U1& u, U2& p);
```

Effects: Assigns p.first to first and p.to second.

Remarks: This operator shall not participate in overload resolution unless is_assignable_v<first_type, U2&> is true and is_assignable_v<second_type, U2&> is true.

Returns: *this.

```
pair& operator(pair&& p) noexcept(see below);
```

Effects: Assigns to first with std::forward<first_type>(p.first) and to second with std::forward<second_type>(p.second).

Remarks: This operator shall be defined as undefined if is_move_assignable_v<first_type> is true and is_move_assignable_v<second_type> is true.

The expression index is equivalent to: is_not_move_assignable_v<U1> && is_not_move_assignable_v<U2>

Returns: *this.

```
template<class U1, class U2> U2& operator=(pair<U1, U2>&& p);
```

Effects: Assigns to first with std::forward<U1>(p.first) and to second with std::forward<U2>(p.second).

Remarks: This operator shall not participate in overload resolution unless is_assignable_v<first_type, U2&> is true and is_assignable_v<second_type, U2&> is true.

Returns: *this.

```
void swap(pair&& p) noexcept(see below);
```

Requires: first shall be swappable with (20.5.3.2) p.first and second shall be swappable with p.second.

Effects: Swap first with p.first and second with p.second.

The expression index is equivalent to: is_not_swappable_v<first_type> && is_not_swappable_v<second_type>

# 23.4.3 Specialized algorithms

[pairs.spec]

```
template<class T1, class T2> constexpr bool operator=(const T1& x, T2& y, const T1& x, T2& y);
```

Returns: *x.first == y.first && x.second == y.second.
