# 30.6.3.3.1 Assignment

basic_streambuf operator=(const basic_streambuf& rhs);

Postconditions:

Effects: Assigns the members of rhs to *this.

+   - eback() == rhs.eback()
- gptr() == rhs.gptr()
- egptr() == rhs.egptr()
- pbase() == rhs.pbase()
- ptr() == rhs.ptr()
- epptr() == rhs.epptr()
- getloc() == rhs.getloc()

Returns: *this.

void swap(basic_streambuf& rhs);

Effects: Swaps the members of rhs and *this.
