+   3 [Note: For input iterators, a == b does not imply a != b (Equality does not guarantee the substitution property or referential transparency). These algorithms can be used with istreams as the source of the input data through the istreamiterator class (2.7.2) — end note ]

# 27.2.4 Output iterators [output.iterators]

+   1 A class or operator type X satisfies the requirements of an output iterator if X satisfies the Iterator requirements (2.7.2) and the expressions in Table 96 are the indicated semantics.

Table 96 — Output iterator requirements (in addition to Iterator)

| Expression | Return type | Operational semantics | Assertion/note pre/post-condition |
| --- | --- | --- | --- |
| *r = o | result is not used | | Remarks: After this operation r is not required to be dereferable. Postconditions: r is incremental. |
| ++r | T& | | r == ++r. Remarks: After this operation r is not required to be dereferable. Postconditions: r is incremental. |
| r++ | convertible to const T& | { T tmp = *r; ++r; return tmp; } | Remarks: After this operation r is not required to be dereferable. Postconditions: r is incremental.
