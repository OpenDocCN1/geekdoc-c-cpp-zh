# ISO/IEC 14882:2017(E)

```
template <class queue<InputIterator>
prior_queue<InputIterator first, InputIterator last,
const Compare& x = Compare(), Container&& y = Container());
```

Requires shall define a strict weak ordering (28.7).

Effects Initializes with x and c with y (copy constructing or moving as appropriate);
calls.insert(c.end(), first, last); and finally calls make_heap(c.begin(), c.end(), comp).

# 26.6.5.2 priority_queue constructors with allocators [piqueue.cons.alloc]

If uses_allocator_y<Container, Alloc> is false false the constructors in this clause shall not participate in overload resolution.

```
template <class Alloc> Alloc(const Alloc& a);
```

Effects Initializes with c and value-initializes comp.

```
template <class Alloc> priority_queue(const Compare& compare, const Alloc& a);
```

Effects Initializes with c and initializes comp with compare.

```
template <class Alloc> priority_queue(const Compare& compare, const Container&& cont, const Alloc& a);
```

Effects Initializes with c as the first argument and a the second argument, and initializes comp with compare; calls make_heap(c.begin(), c.end(), comp).

```
template <class Alloc> priority_queue(const Compare& compare, Container&& cont, const Alloc& a);
```

Effects Initializes with c as the first argument and a the second argument, and initializes comp with compare; calls make_heap(c.begin(), c.end(), comp).

```
template <class Alloc> priority_queue(priority_queue&& q, const Alloc& a);
```

Effects Initializes with q.c as the first argument and a the second, and initializes comp with q.comp.

```
template <class Alloc> priority_queue(priority_queue&& q, const Alloc& a);
```

Effects Initializes with std::move(q.c) as the first argument and a the second argument, and initializes comp with std::move(q.comp).

# 26.6.5.3 priority_queue members [piqueue.members]

```
void push(const value_type x);
```

Effects: As by:

+   - c.push_back(x)
- push_heap(c.begin(), c.end(), comp);

```
void push(value_type& x);
```

Effects: As by:

+   - c.push_back(std::move(x));
- push_heap(c.begin(), c.end(), comp);

```
template <class... Args> void emplace(Args&&... args);
```

Effects: As by:

+   - c.emplace_back(std::forward<Args>(args)...);
