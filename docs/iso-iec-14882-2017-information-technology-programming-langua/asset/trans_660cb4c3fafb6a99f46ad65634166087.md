1 C++ 标准库中的任何函数都可以通过抛出其类型的异常来报告失败；或者抛出一个会被处理器捕获的异常。

2 C++ 标准库函数在调用抛出异常的程序指定函数时不抛出异常。

3 标准库中的析构操作不应抛出异常。C++ 标准库中的每个析构都应具有非抛异常规范。

4 C++ 库中没有段但具有可能抛异常规范的函数可能会抛出实现定义的异常。

5 实现可以通过添加非抛异常规范来加强非虚函数的异常规范。
