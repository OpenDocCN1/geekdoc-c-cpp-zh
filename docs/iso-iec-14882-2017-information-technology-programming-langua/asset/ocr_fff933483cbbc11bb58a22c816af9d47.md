# 27.5.2 Insert iterators

> [insert.iterators]

To make possible with deal insertion in the same way as inserting into an array, a special kind of iterator adaptors, insert iterators, are provided in the library. With regular iterator classes,

```
while (first != last) *result = *first;
```

causes a range (first, last) to be copied into a range starting with result. The same code with result being an insert iterator will insert corresponding elements into the container. This allows all of the copying algorithms to work in the insert mode instead of the regular override mode.

An insert iterator is constructed from a container and possibly one of its pointers pointing to where insertion takes place, if it is at the beginning or not of the container. Insert iterators satisfy the requirements of output iterators. operator returns the insert iterator itself. The assignment operator=(const T&) is defined on insert iterators to allow writing into them, it inserts right where the insert iterator is pointing.
