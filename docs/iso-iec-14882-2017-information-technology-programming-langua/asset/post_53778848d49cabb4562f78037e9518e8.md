## 16.3.3.1 Implicit conversion sequences [over.best.ics]

An implicit conversion sequence is a sequence of conversions to convert an argument in a function call to the type of the parameter being called. The sequence of conversions is an implicit conversion as defined in Clause 7, which is governed by the rules for initialization of an object or reference by a single expression (16.6, 11.63).

2. Implicit conversion sequences are considered only with the type, cv-qualification, and value category of the argument and how these are converted to match the corresponding properties of the parameter. Other properties, such as life time, storage class, accessibility of the argument, whether the argument is a bit-field, and when a function is deleted (11.4.3), are ignored. So, although an implicit conversion sequence can be defined for a given argument-parameter, the conversion from the argument to the parameter might still be ill-formed in the final analysis.

3. A well-formed implicit conversion sequence is one of the following forms:

- (3.1) a standard conversion sequence (16.3.3.1),
- (3.2) a user-defined conversion sequence (16.3.3.1.2), or
- (3.3) an ellipsis conversion sequence (16.3.3.1.3).

4. However, if the target is

- (4.1) the first parameter of a constructor or
- (4.2) the implicit object parameter of a user-defined conversion function

and the constructor or user-defined conversion function is a candidate by

- (4.3) 16.3.1.3, when the argument is the temporary in the second step of a class copy-initialization,
- (4.4) 16.3.1.4, 16.3.1.5, (in all cases),
- (4.5) the second step of 16.3.1.7 when the initializer has exactly one element that is itself an initializer list, and the target is the first parameter of a constructor of class X, and the conversion is to X or reference to cv X.

user-defined conversion sequences are not considered. [Note: These rules prevent more than one user-defined conversion from being applied during overload resolution, avoiding infinite recursion. — end note]

## 16.3.3.1.2 User-defined conversion sequences [over.ics.user]

A user-defined conversion sequence consists of initial standard conversion sequence followed by a user-defined conversion (15.3) followed by a second standard conversion sequence. If the user-defined is specified by a constructor (15.3.1), the initial standard conversion sequence converts the source type to the type required by the argument of the constructor. If the user-defined is specified by a conversion function (15.3.2), the initial standard conversion sequence converts the source type to the implicit object parameter of the conversion function.
