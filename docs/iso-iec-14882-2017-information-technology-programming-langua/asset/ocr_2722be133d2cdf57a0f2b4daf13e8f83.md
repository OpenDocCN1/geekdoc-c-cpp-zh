# ISO/IEC 14882:2017(E)

```
template<class T> complex<T> sin(const complex<T>&);
```

Returns: The complex sine of x.

```
template<class T> complex<T> sinh(const complex<T>&);
```

Returns: The complex hyperbolic of x.

```
template<class T> complex<T> sqrt(const complex<T>&);
```

Returns: The complex square root of x, in the range of the right half-plane. If the argument is a negative number, the value returned lies on the positive imaginary axis.

```
template<class T> complex<T> tan(const complex<T>&);
```

Returns: The complex tangent of x.

```
template<class T> complex<T> tanh(const complex<T>&);
```

Returns: The complex hyperbolic tangent of x.

# 29.5.9 Additional overloads [cmplx.over]

+   1 The following function templates shall have additional overloads:

```
arg          norm
conj         proj
imag         real
```

+   2 The additional overloads shall be sufficient to ensure:
    1. If the argument has type double, then it is effectively cast to complex<double>.
    2. Otherwise, if the argument has type double or an integer type, then it is effectively cast to complex<double>.
    3. Otherwise, if the argument has type float, then it is effectively cast to complex<float>.

+   3 Function pow shall have additional overloads to ensure, for a call with at least one argument of type complex<T>:
    1. If either argument has complex<double> or long double, then both arguments are effectively cast to complex<double>.
    2. Otherwise, if either argument has type complex<double>, double, or an integer, then both arguments are effectively cast to complex<double>.
    3. Otherwise, if either argument has type complex<float> or float, then both arguments are effectively cast to complex<float>.

# 29.5.10 Suffices for complex number literals [complexx.literals]

+   1 This section describes constructing complex numbers. The suffixes i, il, and if create numbers of the types complex<double>, complex<long double>, and complex<float> respectively, with their imaginary part denoted by the literal number and the real part being zero.
