Effects: Finds a subsequence of equal values in a sequence.
Returns: The iterator returns i in the range [first1, last1 - (last2-first2)) such that for every non-negative integer n not less than last2 the following conditions hold: *(i + n) == *(first2 + n), and pred*(i + n) != false. Returns true if [first1, last2] is empty, otherwise last1 if no iterator is found.

Complexity: At most (last1 - first1) * (last2 - first2) applications of the corresponding predicate.
