
# ISO/IEC 14882:2017(E)

## 23.6 Optional objects [optional]

### 23.6.1 In general [optional.general]

This subclass describes class template that represents optional objects. An optional object is an object that contains the storage for another object manages the lifetime of this contained object, if any. The contained object may be initialized after the optional object has been initialized, and may be destroyed before the optional object has destroyed. The initialization state of the contained object is tracked by the optional object.

### 23.6.3 Class template optional [optional|optional]

```cpp
template <class T>
class optional {
public:
    using value_type = T;

    // 23.6.3.1, constructor
    constexpr optional() noexcept;
    constexpr optional(null_t) noexcept;
    constexpr optional(const optional<T>&);
    constexpr optional(optional<T>&&) noexcept(see below);
    template <class... class Args...>
    constexpr explicit optional(in_place_t, Args&&...);
    template <class U, class Args...>
    constexpr explicit optional(in_place_t, initializer_list<U>&&, Args&&...);
    constexpr optional(const U&);
    template <class U>
    optional optional(const U&);
    template<class U>
    optional(U&&&&);

    // 23.6.3.2, destructor
    ~optional();

    // 23.6.3.3, assignment
    optional& operator=(null_t) noexcept;
    optional& operator=(const optional<T>&);
    optional& operator=(optional&&) noexcept(see below);
    template<class U = T>
    const optional& operator=(const U&&&);
    template<class U = T>
    const optional& operator=(U&&&&);
    template<class... Args>
    T& operator(Args&&...);
    template<class... Args>
    T& operator(initializer_list<Args>, Args&&...);

    // 23.6.3.4. swap
    void swap(optional&&) noexcept(see below);

    // 23.6.3.5. observers
    const T* operator() const;
    const T* operator() const;
    const T& operator() const;
    const T& operator() const;
    explicit bool operator(bool) const noexcept;
    bool has_value() const;
    const T value() const;
    const T value() const;
    const T& value() const&;
    template<class U>
    const T& value_or(U&&) const&;
    template<class U>
    const T& value_or(U&&) const&&;

    // 23.6.3.6. modifiers
    void reset() noexcept;

private:
    T* val; // exposition only
}
template<class T> optional operator() -> T;

Any instance of optional<T> at any given time contains a value or does not contain a value. When an instance of optional<T> contains a value, it means that an object of type T, referred to as the optional's contained value, is stored within the dynamic memory, to allocate its contained value. Implementations are not permitted to use additional storage, such as dynamic memory. The contained value shall be allocated in the region of the optional<T> storage suitably aligned for the T. When an object of type optional<T> is converted to bool, the conversion returns true if the object contains a value; otherwise the conversion returns false. Member val is provided for exposition only. When an optional<T> object contains a value, val points to the contained value. T shall be an object and must satisfy the requirements of Destructible.

### 23.6.3.1 Constructors
constexpr optional() noexcept;
constexpr optional(null_t) noexcept;
- Postconditions: *this does not contain a value.
- Remarks: No contained value is initialized. For every object type T constructors shall be constexpr (10.1.5).

constexpr optional(const optional& rhs);
- Effects: If rhs contains a expression, initializes the contained value as direct-non-initializing an object of type T with the expression *rhs.
- Postconditions: bool(rhs) == bool(rhs);
- Throws: Any exception thrown by the selected constructor of T.
- Remarks: This constructor shall be defined as deleted if is_copy_constructible_v<T> is false; is_trivially_copy_constructible_v<T> is true, this shall be a constexpr constructor.

constexpr optional(optional&& rhs) noexcept(see below);
- Effects: If rhs contains a value, initializes the contained value as direct-non-initializing an object of type T with the expression move(rhs); rhs is unchanged.
- Postconditions: bool(rhs) == bool(*rhs);
- Throws: Any exception thrown by the selected constructor of T.
- Remarks: This constructor shall not participate in overload resolution unless is_throw_move_constructible_v<T> is true. If is_trivially_move_constructible_v<T> is true, this shall be a constexpr constructor.

template <class... Args> constexpr explicit optional(in_place_t, Args&&... args);
- Effects: Initializes the contained value as if direct-non-initializing an object of type T with the arguments std::forward<Args>(args)....
- Postconditions: *this contains a value.
- Throws: Any exception thrown by the selected constructor of T.
- Remarks: If T selected for the initialization is a constexpr constructor, this constructor shall be a constexpr constructor. This constructor shall not participate in overload resolution unless is_constructible_v<T, initializer_list<U>, Args&&...> is true.

template <class U> constexpr explicit optional(in_place_t, initializer_list<U> il, Args&&... args);
- Effects: Initializes the contained value as if direct-non-initializing an object of type T with the expression std::forward<U>(il).
- Postconditions: *this contains a value.
- Throws: Any exception thrown by the selected constructor of T.
- Remarks: This constructor shall not participate in overload resolution unless is_constructible_v<T, Args&&...> is true. If T's constructor selected for the initialization is a constexpr constructor, this shall be a constexpr constructor.

template <class U> constexpr optional(U&& u);
- Effects: Initializes the contained value as if direct-non-initializing an object of type T with the expression std::forward<U>(u).
- Postconditions: *this contains a value.
- Throws: Any exception thrown by the selected constructor of T.
- Remarks: If T's selected constructor is a constexpr constructor, this constructor shall be a constexpr constructor.
