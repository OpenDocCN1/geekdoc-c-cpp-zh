# 28.7 Minimum and maximum

```
template<class T> const T min(const T& a, const T& b);
template<class T> const T min(const T& a, const T& b, const Compare comp);
```

+   * Requires: For the first type, type T shall be LessThanComparable (Table 21).
* Returns: The smaller value.
* Remarks: Returns the first argument when the arguments are equivalent.
* Complexity: Exactly one comparison.

```
template<class T>
const T min(initializer_list<T> t);
template<class T> const T min(initializer_list<T> t, const Compare comp);
```

+   * Requires: T shall be CopyConstructible and t.size() > 0. For the first type, T shall be LessThanComparable.
* Returns: The smallest value in the iterator_list.
* Remarks: Returns the leftmost argument when several arguments are equivalent to the smallest.
* Complexity: Exactly t.size() - 1 comparisons.

```
template<class T> const T max(const T& a, const T& b);
template<class T> const T max(const T& a, const T& b, const Compare comp);
```

+   * Requires: For the first type, type T shall be LessThanComparable (Table 21).
* Returns: The larger value.
