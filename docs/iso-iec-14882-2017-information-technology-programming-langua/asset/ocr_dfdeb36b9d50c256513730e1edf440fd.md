Requires:

+   - If is provided, T shall MoveConstructible (Table 23); otherwise, ForwardIterator1’s value type must be MoveConstructible.

+   - If is provided, all of

+   - binary_op(init, init);

+   - binary_op(init, unary_op*(first)), and

+   - binary_op(unary_op*(first), unary_op*(first))
