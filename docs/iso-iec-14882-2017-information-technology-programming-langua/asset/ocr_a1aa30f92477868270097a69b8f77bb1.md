# 7.6 Integral promotions [conv.promotion]

+   1 A prvalue of an integer type other than bool, char16_t, char32_t or wchar integer type if int can be converted to
rank (7.15) is less than the rank of type (9.2) of unsigned int; unsigned int, long, unsigned long int
can represent all values of its underlying type; otherwise, the source can be converted to a prvalue of unsigned int.

+   2 A prvalue of type char16_t, char32_t, or wchar_t (6.9.1) can be converted to a prvalue of the first
of following types that can represent all values of its underlying type: unsigned int, long int,
unsigned long int long long int, unsigned long long int. If none of the types in that list can
represent all values of its underlying type, a prvalue of char16_t, char32_t, or wchar_t can be
converted to a prvalue of its underlying type.

+   3 A prvalue of an unscoped enumeration type whose type is not fixed (10.2) can be converted to a
value of the first of the following types that can represent all values of the enumeration (the values
of the base-type, from min to max) are (9.2): unsigned int, long int, unsigned long int, long
int, unsigned long long int. If none of the types in that list can represent all values of the
enumeration, a prvalue of unscoped enumeration type can be converted to a prvalue of the
integer with lower conversion rank (7.15) greater than the rank of long in which all the
values of the enumeration are represented. If there are two such types, the one signed is chosen.

+   4 A prvalue of an unscoped enumeration type whose type is fixed (10.2) can be converted to
a prvalue of its underlying type. Moreover, if integral promotion can be applied to its type, a
value of an unscoped enumeration type whose type is fixed can also be converted to a prvalue
of the promoted type.

+   5 A prvalue of an integral field (12.2.4) can be converted to a prvalue of int if int can represent
the values of the bit-field; otherwise, it can be converted to unsigned int if unsigned int can represent
all values of the bit-field. If the bit-field is larger, no integral promotion applies to it. If the bit-field has
en enumerated type, it is treated as any other value of type for promotion purposes.

+   6 A prvalue of bool can be converted to a prvalue of int, with false becoming zero and true
becoming one.

7 These conversions are called integral promotions.

# 7.7 Floating-point promotion [conv.fpprom]

+   1 A prvalue of float can be converted to a prvalue of double. The value is unchanged.

+   2 This conversion is called floating-point promotion.

# 7.8 Integral conversions [conv.integral]

+   1 A prvalue of an integer type can be converted to a prvalue of another integer type. A prvalue of an unscoped
enation type can be converted to a prvalue of an integer type.

+   2 If the destination type is unsigned, the resulting value is the least unsigned integer congruent to the
integer (modulo 2^n where n is the number of bits used to represent the result). [Note: In a two’s
complement representation, this conversion is conceptual and there is no change in the bit pattern (if there is
no truncation). — end note]
