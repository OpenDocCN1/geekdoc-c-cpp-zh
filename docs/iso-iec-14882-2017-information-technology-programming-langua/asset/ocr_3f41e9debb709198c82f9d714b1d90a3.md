# 30.9.3.1 basic_ifstream constructors


basic_ifstream();

+   1 Effects: Constructs an object of class basic_ifstream<charT, traits>, initializing the base class with basic_ifstream<charT, traits>&(kb) (30.7.4.1) and initializing sb with basic_filebuf<charT, traits>()(30.9.2.1).

```

                             ios_base::opmode mode = ios_base::in);
explicit basic_ifstream(const filesystem::path::value_type* s,
                        ios_base::opmode mode = ios_base::in); // wide systems only; see 30.9.1
```

+   2 Effects: Constructs an object of class basic_ifstream<charT, traits>, initializing the base class with basic_ifstream<charT, traits>&(kb) (30.7.4.1) and calls rdbuf()->open(s, mode | ios_base::in). If that function returns a null pointer, it calls setfail(bit).

```
explicit basic_ifstream(const string& s,
                             ios_base::opmode mode = ios_base::in);
explicit basic_ifstream(const filesystem::path& s,
                        ios_base::opmode mode = ios_base::in);
```

+   3 Effects: The same as basic_ifstream(s.c_str(), mode).


basic_ifstream(basic_ifstream& rhs);

+   4 Effects: Moves from the rvalue rhs. This is implemented by moving the base class, and the contained basic_filebuf. Next basic_ifstream<charT, traits>::set_rdbuf(&kb) is called to install the contained basic_filebuf.
