# 23.14.9 Bitwise operations [bitwise.operations]

+   1 The library provides basic function object classes for all of the bitwise operators in the language (8.11, 8.13, 8.12, 8.31).

```
    template<class T, class U> constexpr operator()(T& t, U& u) const

    -> decltype(std::forward<T>(t) & std::forward<U>(u));

```
