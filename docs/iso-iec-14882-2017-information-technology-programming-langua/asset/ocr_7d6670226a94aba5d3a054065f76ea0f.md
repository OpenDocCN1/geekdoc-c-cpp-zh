> Any instance of optional<T> at any given time contains a value or does not contain a value. When an instance of optional<T> contains a value, it means that an object of type T, referred to as the optional object's contained value, is stored within the dynamic memory, to allocate its contained value. Implementations are not permitted to use additional storage, such as dynamic memory. The contained value shall be allocated in the region of the optional<T> storage suitably aligned for the T. When an object of type optional<T> is converted to bool, the conversion returns true if the object contains a value; otherwise the conversion returns false.

> Member val is provided for exposition only. When an optional<T> object contains a value, val points to the contained value.

> T shall be an object and must satisfy the requirements of Destructible (Table 27).
