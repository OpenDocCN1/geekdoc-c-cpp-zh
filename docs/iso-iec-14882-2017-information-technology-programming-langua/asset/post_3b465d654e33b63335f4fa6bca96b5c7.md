## 26.3.10 Class template list [List]

## 26.3.10.1 Class template list overview [List.overview]

A list is a container that supports bidirectional iterators and allows constant insert and erase operations when needed, with storage management handled automatically. Unlike vectors (26.3.11) and deques (26.3.8), fast access to elements is not supported, but many algorithms only require sequential access.

A list satisfies all the requirements of a reversible container (given in two tables in 26.2), of a sequence container (including all of the optional requirements (26.2.3)), and of an allocator container (Table 86). The exceptions are the operator[] and member functions, which are not provided.258 Descriptions are provided here for operations on list that are not described in one of these tables or for operations where there is additional information.
