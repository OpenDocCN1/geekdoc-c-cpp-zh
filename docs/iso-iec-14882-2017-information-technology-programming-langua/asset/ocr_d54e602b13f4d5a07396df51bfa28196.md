# ISO/IEC 14882:2017(E)

 (8.3.4) in storage associated with another object e of type "array of N
unsigned char" or of type "array of N std::byte" (21.2.1), that array provides storage for the
object if:

+   3.1 — the lifetime of e has begun and not ended, and
3.2 — the storage for the new object fits entirely within e,
3.3 — there is no smaller array object that satisfies these constraints.

> [Note: If that array previously provided storage for another object, the lifetime of that objectnends its storage was used (6.8). — end note]:

```
template<typename T>
struct AlignedUnion {
  align(T..) unsigned char data[max(sizeof(T)...)];
  int f() {
    AlignedUnion::char* au;
    int *p = new (au.data); // OK, au.data provides storage
    char *c = new (au.data)()); // OK, lifetime of *p
    char *d = new (au.data + 1) char();
    return *c + *d;
  }
}
```

```
struct A { unsigned char a[32]; };
struct B { unsigned char b[16]; };
A;
B *b = new (a.a + B); // a.a provides storage for *b
int *p = new (b->b) + 4); // b->b provides storage for *p
// a does not provide storage for *p (directly),
// *p is nested within a (see below)
```

+   4 An object a is nested within another object b:
4.1 — a is a subobject of b, or
4.2 — b provides storage for a, or
4.3 — there exists object c where a is nested within c, and c is nested within b.

5 For object x, there is some object the complete object of x, which is itself., determined as follows:

+   5.1 — If x is a complete object, the complete object of x
5.2 Otherwise, the object of x is the complete object of the (unique) object that contains x.

6 If a complex object, a bit-field(12.2.2), or an array element of class type, is considered the
most derived, from the class of its base class subobject; an object of the most
derived class or a non-class type is called a most derived.

7 Unless it is a bit-field(12.2.4), a most derived must have a nonzero size and occupy one
bytes of storage. Base class subobjects have zero size. An object of trivially copyable or standard-layout
type (6.9) occupy contiguous bytes of storage.

8 Unless an object is a bit-field or a base class subobject of zero size, the address of that is
the first byte it occupies. Two objects a and b with overlapping lifetimes are not bit-fields may have
the same address if not nested within the other, or if at least one is a base class subobject of zero size
