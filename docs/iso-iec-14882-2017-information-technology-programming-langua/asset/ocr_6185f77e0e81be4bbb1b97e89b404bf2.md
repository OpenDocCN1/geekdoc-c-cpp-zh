# 31.13 Modified ECMAScript regular expression grammar

+   1. The regular expression recognized by basic_regex objects constructed with the ECMAScript flag that is specified by ECMA-262, as specified as below.

+   2. Objects of type specialization of basic_regex within themselves a default-constructed instance of their traits template parameter, hereafter referred to as traits_inst. This traits_inst object is used to support type localization of the regular expression: basic_regex member functions shall not call any dependent C or C++ API, including the formatted string input functions. They shall call the appropriate traits member to achieve the required effect.

+   3. The following productions within the ECMAScript grammar are modified as follows:
```
ClassAtom ::
ClassAtomDash
ClassAtomExClass
ClassAtomCollatingElement
ClassAtomEquivalence

IdentityEscape ::
SourceCharacter not c
```

+   4. The following new productions are added:
```
ClassAtomExClass ::
  [: ClassName ]

ClassAtomCollatingElement ::
  [: ClassName ]

ClassAtomEquivalence ::
  [: ClassName =]

ClassName ::
ClassNameCharacter
ClassNameCharacter ClassName

ClassNameCharacter ::
SourceCharacter not one of ", \"
```"

+   5. The productions ClassAtomExClass, ClassAtomCollatingElement provide functionality equivalent to that of the same features in regular expressions in POSIX.

+   6. The regular expression may be modified by any regex_constants::syntax_option_type flags when constructing an object of type specialization of basic_regex according to the rules in Table 130.

+   7. A Class production, when used in ClassAtomExClass, is not valid if traits_inst.lookup_classname returns zero for that name. The names recognized as valid ClassNames are determined by the type of the traits class, but at least the following names shall be recognized: alpha, alpha, blank, cntrl, digit, graph, lower, print, punct, space, upper, xdigit, d. s. w. In addition the following expressions shall be equivalent:
\d and [[:digit:]]
