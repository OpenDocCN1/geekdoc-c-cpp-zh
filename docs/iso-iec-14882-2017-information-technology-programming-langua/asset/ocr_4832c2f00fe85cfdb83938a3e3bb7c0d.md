# ISO/IEC 14882:2017(E)

# 20.3.6

constant subexpression
expression evaluation as subexpression of a *conditional-expression* CE (8.16) would not prevent CE from being a core expression (8.20)

# 20.3.7

deadlock
situation where one or more threads are unable to continue execution because each is blocked waiting for one or more of the others to satisfy some condition

# 20.3.8

default behavior
(implementation) specific behavior provided by the implementation, within the scope of the required behavior

# 20.3.9

default behavior
(specification) description of *replacement function* and *handler function*

# 20.3.10

direct-not-list-initialization
direct-initialization (11.6) that is not list-initialization (11.6.4)

# 20.3.11

handler function
non-reserved function which may be provided by a C++ program

> Note 1 entry: A C++ program may designate a handler function at various points in its execution by supplying a pointer to the function when calling any of the library functions install handler (Clause 2) — end note

# 20.3.12

iostream class templates
templates, defined in Clause 30, that take two template arguments

> Note 1 entry: The arguments are named *char* and *traits*. The argument *char* is a character container class, and the argument *traits* is a class which defines additional characteristics and functions of the character type represented by *char* necessary to implement the iostream class templates — end note

# 20.3.13

modifier function
class member (12.2.1) other than a constructor, assignment operator, or destructor that alters the state of the class

# 20.3.14

move assignment
assignment of an rvalue of some object type to a modifiable lvalue of the same type

# 20.3.15

move construction
direct-initialization of an object of some type with an rvalue of the same type

# 20.3.16

NTCS
sequence of values that have character type that precede the terminating null character value char()
