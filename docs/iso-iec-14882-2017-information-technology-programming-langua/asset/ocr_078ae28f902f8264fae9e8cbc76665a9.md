# ISO/14882:2017(E)

template <Tuples...> constrpr<CTypes...> tuple_cat(Tuples...> tpls);

In the following paragraphs, let $T$ be the type in Tuples, $U_i$ be $remove\_reference\_t<T>$, and $tp_i$ be the $i^{th}$ parameter in the function parameter $tpls...$, where all indexing is zero-based.

Requirements: For all $U_i$, the type must be $cu\tuple<Args...>, where $cu$ is the (possibly) $i^{th}$ cv-qualifier-seq and $Args$ is the parameter list representing the elements in $U_i$. Let $A_i$ be the $i^{th}$ type in $Args$. For all $A_i$ the following requirements shall be satisfied:

+   If T is not an lvalue reference, then $is\constructible<U_i, cu::A_i> == true$, otherwise

+   $is\constructible<V<A_i>

Remarks: In the types CTypes all shall be equal to the ordered sequence of the elements $Args...$, $Args...$, Args_{1...n}$, where $n$ is sizeof...(Tuples). Let $e_i$ be the $i^{th}$ ordered sequence of tuple elements of the resulting object corresponding to the tuple sequence,

Returns a tuple object initialized by initializing the $k_i^{th}$ type element $e_i$ in $e...$, with $get<k_i>(std::forward(t));$ for each $k_i$ and each $e$, in order.

> [Note: Implementation may support additional types in the parameter pack Tuples that support the tuple-like protocol, such as pair and array. — end note]

# 23.5.3 Calling a function with a tuple

```
template <class F, class Tuple> [tuple::apply]
constrpr decltype(auto)(F&& f, Tuple&& t);
```

Effects: Given the exposition-only function:

```
template <class F, class Tuple, size_t... I>
constrpr decltype(auto)
    apply_impl(F&& f, Tuple&& t, index_sequence<I...>) { // exposition only
    return INVOKE(std::forward<F>(f), std::forward<Tuple>(t)...:get<I>(std::forward<Tuple>(t))...); // see 23.14.3
}
```

Equivalent to:

```
return apply_impl(std::forward<Tuple>(t),
    make_index_sequence<tuple_size_v<decay_t<Tuple>>>());
```

```
template <class T, class Tuple>
constrpr T make_from_tuple(Tuple&& t);
```

Effects: Given the exposition-only function:

```
template <class T, class Tuple, size_t... I>
constrpr T make_from_tuple(Tuple&& t, index_sequence<I...>) { // exposition only
    return T(get<I>(std::forward<Tuple>(t))...);
}
```

Equivalent to:

```
return make_from_tuple<T>(t,
    make_index_sequence<tuple_size_v<decay_t<Tuple>>>>());
```

> [Note: The type of T must be specified as an explicit template parameter, as it cannot be deduced from the argument list. — end note]
