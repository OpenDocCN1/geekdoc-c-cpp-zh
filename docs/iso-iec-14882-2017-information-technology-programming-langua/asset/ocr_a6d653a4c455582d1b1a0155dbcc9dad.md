# ISO/IEC 14882:2017(E)

# 29.9.5.8 Cylindrical Bessel functions of the first kind

double cyl_bessel_j(double nu, double x);
float cyl_bessel_j(float nu, float x);
long double cyl_bessel_j(long double nu, long double x);

> Effects: These functions compute the cylindrical Bessel functions of the first kind of their respective nu arguments and x.

+   2 Returns:

```
$J_{\nu}(x) = \sum_{k=0}^{\infty} \frac{(-1)^k(x/2)^{\nu+2k}}{k!\Gamma(\nu+k+1)} \quad x \ge 0$
```

where $\nu$ is nu and x is.

Remarks: The effect of calling each of these functions is implementation-defined if nu >= 128.

# 29.9.5.9 Irregular modified cylindrical Bessel functions

double cyl_bessel_x(double nu, double x);
float cyl_bessel_xf(float nu, float x);
long double cyl_bessel_xl(long double nu, long double x);

> Effects: These functions compute the irregular modified cylindrical Bessel functions of their respective nu arguments and x.

+   2 Returns:

```
$K_{\nu}(x) = (\pi/2)^{\nu+1}(J_{\nu}(x) + I_{\nu}(x)) \quad \frac{\pi}{2}\frac{L_{\nu}(x)-I_{\nu}(x)}{\sin\nu\pi}} \quad x \ge 0 \text{ and non-integral } \nu$;n\frac{\pi}{2\mu}\frac{L_{\mu}(x)-I_{\mu}(x)}{\sin\mu\pi} \quad x \ge 0 \text{ and integral } \nu$
```

where $\nu$ is nu and x is.

Remarks: The effect of calling each of these functions is implementation-defined if nu >= 128.

+   4 See 29.9.5.7, 29.9.5.8, 29.9.5.9.

# 29.9.5.10 Cylindrical Neumann functions

double cyl_neumann(double nu, double x);
float cyl_neumann(float nu, float x);
long double cyl_neumann(long double nu, long double x);

> Effects: These functions compute the cylindrical Neumann functions, also as the cylindrical Bessel functions of the second kind, of their respective nu and x.

+   2 Returns:

```
$N_{\nu}(x) = \frac{J_{\nu}(x)\cos\nu\pi-Y_{\nu}(x)}{\sin\nu\pi} \quad x \ge 0 \text{ and non-integral } \nu$;
\frac{\pi}{2\mu}\frac{J_{\mu}(x)\cos\mu\pi-J_{\mu}(x)}{\sin\mu\pi} \quad x \ge 0 \text{ and integral } \nu$
```

where $\nu$ is nu and x is.

Remarks: The effect of calling each of these functions is implementation-defined if nu >= 128.

+   4 See 29.9.5.8.
