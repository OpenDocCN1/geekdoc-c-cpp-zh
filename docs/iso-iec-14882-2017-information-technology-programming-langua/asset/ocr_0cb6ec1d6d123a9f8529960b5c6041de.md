# ISO/IEC 14882:2017(E)

11 If D is an reference type A, then the signatures are:

```
unique_ptr(pointer p, const A& d) noexcept;
unique_ptr(pointer p, const A& d) = delete;
```

12 Effects: Constructs a unique_ptr object which owns p, initializing the pointer with p and initializing the deleter from std::decltype(d)(d).

13 Remarks: Constructors shall not participate in order resolution unless is_constructible_v<D, decltype(d)> is true.

14 Postconditions: get_deleter() returns a reference to the stored deleter. If D is a reference type then get_deleter() returns a reference to the value.

15 Remarks: If class type argument deduction (16.3.1.8) would cause function template construction to either of these constructors, the program is ill-formed.

+   [Example]:

```
D;
unique_ptr<int, D1>(new int()); // D must be MoveConstructible
unique_ptr<int, D2>(new int()); // D must be CopyConstructible
unique_ptr<int, D3>(new int()); // D3 holds a reference to d
unique_ptr<int, const D4>(new int()); // error: value object combined
 with reference type
```

+   - example

unique_ptr<U&> u noexcept;

17 If E is not a reference type, D shall satisfy the requirements of MoveConstructible (Table 23). The construction of the deleter from value D shall not throw an exception.

18 Effects: Constructs a unique_ptr by transferring ownership from u to this. If D is a reference type, get_deleter() returns the deleter that was constructed from u; otherwise, this deleter is constructed from u.get_deleter(). The deleter is constructed with std::forward<E>. --- end note

19 Postconditions: get() yields the value u.get() yielded before the construction, get_deleter() returns a reference to the stored deleter. If D is a reference type then get() and get_deleter() return the same value deReference.

```
template <class U, class E> E u;
```

20 If E is not a reference type, construction of the deleter from value of E shall be well formed and not throw an exception. Otherwise, if E is a reference type and construction of the deleter from value of E shall be well formed and not throw an exception.

21 Remarks: constructor unique_ptr shall not participate in order resolution unless:

+   (21.1) unique_ptr<U, E&>:pointer is implicitly convertible to pointer,

+   (21.2) U is not an array type, and

+   either D is a reference type and E is the same type as D, or D is not a reference type and E is implicitly convertible to D

22 Effects: Constructs a unique_ptr by transferring ownership from u to this. If E is a reference type, this deleter is copy constructed from u's deleter; otherwise, this deleter is moved from u.deleter. [Note: The deleter is constructed with std::forward<E>. --- end note

Postconditions: get() yields the value u.get() yielded before the construction, get_deleter() returns a reference to the stored deleter that was constructed from u.get_deleter().
