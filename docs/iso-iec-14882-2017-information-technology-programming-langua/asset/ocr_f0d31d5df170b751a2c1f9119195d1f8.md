# 12.2.3.1 Static member functions [class.static.mft]

[Note: The rules described in 12.2.1 apply to static member functions. — end note]

[Note: A static member function does not have this pointer (12.2.1). — end note] A static function shall not be virtual. There shall be no static and a non-static member function with the same name and the same parameter types (16.1). A member function shall not be declared const, volatile, or volatile.

# 12.2.3.2 Static data members [class.static.data]

A static member is not part of the subjects of a class. If a static member is declared *thread_local* there is one copy of the member per thread. If a static member is not declared *thread_local* there is one copy of the data member that is shared by all the objects of the class.

The declaration of an inline static data member in class definition is not a definition and may be of an incomplete type other than void. The definition for a static data member that is not defined inline in the class definition shall appear in a namespace scope enclosing the member's class definition. The definition at namespace scope, the name of the static data member shall be qualified by its class name using the :: operator.
