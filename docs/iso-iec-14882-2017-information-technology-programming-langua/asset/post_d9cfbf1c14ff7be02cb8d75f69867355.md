# 15.8 Copying and moving

A object can be copied or moved in two ways: by initialization (15.1), for function passing (15.2), for function return (15.3) and by assignment (15.4).

## 15.8.1 Copy constructors

A declaration of a constructor for a class X is ill-formed if its first parameter is of (optionally cv-qualified) X and there are no other parameters or else other parameters have default arguments. A member template is never instantiated to produce such a constructor. [Example:

```
struct S {
    template<typename T> S(T);
    S();
};

g g;
void h() {
    S a(g); // does not instantiate the member template to produce S<S>(S);
// uses the implicitly declared copy constructor
}
// end example
```
