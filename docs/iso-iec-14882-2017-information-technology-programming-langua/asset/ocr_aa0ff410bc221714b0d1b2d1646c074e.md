# ISO/IEC 14882:2017(E)

```
template<class T> class A<int, T*, 5> { }; // #4
template<class T1, T2, int> class A<T1, T2, I> { }; // #5
nA<int, I> a1; // uses #1
A<int, int*> a2; // uses #2, T is int, I is 1
A<int, char*, 5> a3; // uses #4, T is char
A<int, char*, I> a4; // uses #5, T1 is char, T2 is I is 1
A<int*, int*, 2> a5; // ambiguous: matches #3 and #5
-- end example
```

+   3 If the arguments of a partial specialization are deduced because of the structure of the template-list and the template-id, the program is ill-formed. [Example:
template<int, I> struct A {};
template<int> struct A<I1, I2> {}; // error
template<int> struct A<CI, I> {}; // OK

+   4 In a type that refers to a class specialization, (e.g., class template, int, I>) the template parameter list of the primary template. The template arguments of a specialization are deduced from the arguments of the primary template.

# 17.5.5.2 Ordering of class template specializations [temp.class.order]

+   1 For class partial specializations, the first is more specialized than the second, if the following return two functions, the first template is more specialized than the second according to the ordering rules for function templates (17.5.6.2):
(1.1) Each of the two functions has the same parameters as the corresponding partial specialization.
(1.2) Each function has a single function whose type is a class template specialization where the template arguments are the corresponding template parameters from the function template for each template argument in the template-argument-list of the simple-template-id of the partial specialization.

+   2 [Example:
template<int, int, class T> class X {};
template<int, int> class X<XI, int> {}; // #1
template<int> class X<CI, I> {}; // #2
template<int, IO> void f(X<IO, IO, int>); // /A
template<int, IO> void f(X<IO, IO, int>); // /B
template<class T> class Y {};
template<class* p> class Y<class* p>; // #3
template<class** pp> class Y<class** pp>; // #4
template<class* p0> void g(Y<class* p0>); // /C
template<class** pp0> void g(Y<class** pp0>); // /D
According to the ordering rules for function templates, the function B is more specialized than the function template A and the function template D is more specialized than the function template C.
