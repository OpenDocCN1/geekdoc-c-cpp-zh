## 14.4 Protected member access

An access check beyond those described earlier in Clause 14 is applied when a non-static member or non-static function is a member of its naming class (14.2).¹¹⁵ As described earlier, access to a protected member is granted because the reference occurs in a friend or member of some class C. If the access is to form a pointer to member (8.3.1), the nested-name-specifier shall denote C or a class derived from C. All other accesses allow a (possibly implicit) object expression (8.2.5). In this case, the class of the object shall be C or a class derived from C. Example:

```cpp
class B {
protected:
int i;
static int j;
};
class D1 : public B {
friend void fr(B*, D1*);
};
class D2 : public B {
friend void fr(B*, D1*, D2*);
void mem(B*);
};
void fr(B* pb, int* p1, D2* p2) {
pb->i = 1; // ill-formed
p1->i = 2; // OK (access through a D2)
p2->i = 4; // OK (access through a D2, even though naming class is B)
int B::pmi_B = &B::i; // OK
int B::pmi_B2 = &D2::i; // OK (type of D2::i is int B::)
B::j = 5; // ill-formed (not a friend of naming class B)
D2::j = 6; // OK (refers to static member)
}
g(B* pb, int p1, int p2) {
pb->i = 1; // ill-formed
p1->i = 2;               // ill-formed
p2->i = 3;               // ill-formed
}
// -- end example
```

¹¹⁵ This additional check does not apply to other members, e.g., static data members or enumerator member constants.

## 14.5 Access to virtual functions [class.access.virt]

The access rules (Clause 14) for a virtual function are determined by its declaration and are not affected by the rules for a function that later overrides it. Example:

```cpp
class B {
public:
    virtual int f();
};
class D : public B {
private:
    int f();
};
void f() {
    D d;
    B* pb = &d;
    D* pd = &d;

pb->f();               // OK: B::f() is public, D::f() is invoked
pd->f();               // error: D::f() is private
}
// -- end example
```

Access is checked at the call point when the type of expression used to denote the object for which the member function is called (B* in the example above). The access of the member function in the class in which it was defined (D in the example above) is in general known.

## 14.6 Multiple access [class.paths]

If a name can be reached by several paths through a multiple inheritance graph, the access is that of the path that gives most access. Example:

```cpp
class W {
public: void f();
};
class A : private virtual W {};
class B : public virtual W { };
class C : public A, public B {
    void f();
};
// OK
```

Since W::f() is available to C::f() along the public path through B, access is allowed. -- end example]

## 14.7 Nested classes [class.access.nest]

A nested class is a member and has such the same access rights as any other member. The members of an enclosing class have no special access to members of a nested class; the usual access rules (Clause 1a) shall be obeyed. Example:

```cpp
class E {
    int x;
    class B { };
}

class I {
    B b;
    int y;
    void f(E* p, int i) {
        p->x = i; // OK: E::I can access E::x
    }
}

int g(I* p) {
    return p->y; // error: I::y is private
}
};
// — end example]

## Special member functions [special]

The default constructor (15.1), copy constructor and copy assignment operator (15.8), move constructor and move assignment operator (15.8), and destructor (15.4) are special member functions. Note: The implementation will implicitly declare these member functions for some class types when the program does not explicitly declare them. The implementation will implicitly define them if they are odr-declared (6.2). See 15.1.

An implicitly-declared special function is not user-provided. Example:

```cpp
struct A {
    B();
};
struct B {
    B& operator=(const B&);
    B(const B& s) {
        this;
    }
};
```

## 15.1 Constructors [class.ctor]

A default constructor is a constructor that can be called with no arguments, or a constructor whose all arguments have default arguments. If no constructor for a class X is provided, a default constructor is implicitly defined. If there is no user-declared constructor, a default having no parameters is implicitly declared as defaulted.

A deleted default constructor is defined as follows:

- (1) X is a union that has a variant member with a non-trivial default constructor and no variant member of X has a default member
- (2) X is a union that has a variant member with a non-trivial default constructor and no variant member of the anonymous union has a default initializer
- (3) any non-static data member of class-qualified is of reference type
- (4) any non-static data member of class-qualified type (or array) with no brace-or-initializer is not a user-provided default constructor
- (5) X is a union and all of its variant members are of const-qualified type (or array)
- (6) X is a union and all of its anonymous member are of const-qualified type (or array)
- (7) any potentially deleted subobject has a destructor that is deleted or inaccessible from the default constructor.

A default constructor is trivial if it is not user-provided and if:

- (1) its class has no virtual functions (13.3) and no virtual base classes (13.1)
- (2) no non-static data member of its class has a default member initializer (12.2)
- (3) all the direct base members of its class have trivial default constructors
- (4) for all the non-static data members of its class are of class type (or array), each such class has a trivial default constructor.

Otherwise, the default constructor is non-trivial.
