# 31.8.5 basic_regex locale [re.regex.locale]

local_type imbue(locale_type loc);

1&nbsp;&nbsp;Effects: Returns the result of traits\_inst.imbue(loc) where traits\_inst is a (default-initialized)
instance of the template argument traits stored within the object. After a call to imbue the
basic\_regex object does not match any character sequence.

local_type getloc() const;

2&nbsp;&nbsp;Effects: Returns the result of traits\_inst.getloc() where traits\_inst is a (default-initialized)
instance of the template parameter traits stored within the object.

# 31.8.6 basic_regex swap [re.regex.swap]

void swap(basic_regex &);

1&nbsp;&nbsp;Effects: Swaps the contents of the two regular expressions.
2&nbsp;&nbsp;Postconditions:*this contains the regular expression that contains the regular expression
that was in *this.
3&nbsp;&nbsp;Complexity: Constant time.

# 31.9 Class template_match [re.submatch]

1 Class template sub_match denotes the sequence of characters matched by a particular marked sub-expression.

```
namespace std {
  template <BidirectionalIterator>
  class sub_match : public BidirectionalIterator {
  public:
    typename iterator_traits<BidirectionalIterator>::value_type = typename iterator_traits<BidirectionalIterator>::value_type;
    using difference_type = typename iterator_traits<BidirectionalIterator>::difference_type;
    using iterator = BidirectionalIterator;
    using string_type = basic_string<value_type>;

bool matched;

    constexpr sub_match match();

    difference_type length() const;
    operator string_type() const;
    string_type str() const;

    int compare(const sub_match& s) const;
    int compare(const string_type& s) const;
    int compare(const value_type* s) const;
  };
} //
```
