## 30.9 File-streams

## 30.9.1 Header <fstream> synopsis

```cpp
namespace std {
template <class charT, class traits = char_traits<charT>>
class_filebuf {
  using filebuf = basic_filebuf<charT>;
  using wfilebuf = basic_filebuf<wchar_t>;
template <class charT, class traits = char_traits<charT>>
class_ifstream {
  using istream = basic_ifstream<char>;
  using wistream = basic_ifstream<wchar_t>;
template <class charT, class traits = char_traits<charT>>
class_ofstream {
  using ofstream = basic_ofstream<char>;
  using wstream = basic_ofstream<wchar_t>;
template <class charT, class traits = char_traits<charT>>
class_fstream {
  using fstream = basic_fstream<char>;
  using wstream = basic_fstream<wchar_t>;
}
```

The header <fstream> defines four classes and eight types that associate stream buffers with files as source or sink of bytes. In an environment that uses a large character set, the file typically holds multibyte character sequences and the basic_filebuf object converts those multibyte sequences into wide character sequences.

> Note: The class basic_filebuf treats a file as a source or sink of bytes. In this clause, member functions taking arguments of const filesystem::path::value_type are only provided on systems where filesystem::path::value_type (30.10.8) is not char. [Note: These functions enable path support for systems with a wide path type, such as wchar_t.]

## 30.9.2. basic_filebuf constructors

```cpp
basic_filebuf();
```

- 1 Effects: Constructs an object of basic_filebuf<charT, traits>, initializing the base class with basic_iostream<charT, traits>(30.7.4.1).
- 2 Postconditions: is_open() == false.

```cpp
basic_filebuf<charT, traits>& rhs;
```

- 3 Effects: Moves from the rvalue rhs. It is implementation-defined whether the sequence pointers in *this (eback, gptr, egptr, pbase, ptr, epptr) obtain the value that rhs had. They do or not. Additionally *this refers to the file which rhs before the construction, and rhs reference is buffered (if any after the construction, no file left after the destructor). The source, locale and any other state of rhs is copied.
- Postconditions: Let rhs p refer to the state of rhs just prior to this construction and rhs_a refer to the state of rhs after this construction.
- (4.1) is_open() == rhs_p.is_open()
- (4.2) rhs_a.is_open() == false
- (4.3) gptr() == rhs_p.gptr() - rhs_p.eback()
- (4.4) egptr() - eback() == rhs_p.egptr() - rhs_p.eback()
- (4.5) pptr() - pbase() == rhs_p.pptr() - rhs_p.pbase()
- (4.6) epptr() == rhs_p.epptr() - rhs_p.pbase()
- (4.7) if (eback()) eback() == rhs_a.eback()
- (4.8) if (gptr()) gptr() != rhs_a.gptr()
- (4.9) if (egptr()) egptr() != rhs_a.egptr()
