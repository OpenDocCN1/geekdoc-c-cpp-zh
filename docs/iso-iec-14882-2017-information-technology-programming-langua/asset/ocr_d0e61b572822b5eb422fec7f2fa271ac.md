# ISO/IEC 14882:2017(E)

# 2.4.3 char_traits specializations

```
namespace std {
  template<> struct char_traits<char>;n  template<> struct char_traits<char16_t>;n  template<> struct char_traits<char32_t>;n  template<> struct char_traits<wchar_t>;
}
```

+   1 The header <string> defines four specializations of the class template: char_traits<char>, char_traits<char16_t>, char_traits<char32_t>, and char_traits<wchar_t>.

+   2 The requirements for the members of these specializations are given in Clause 24.2.1.

# 2.4.3.1 struct char_traits<char>

```
namespace std {
  template<> struct char_traits<char> {
    using char_type = char;
    using int_type = int;
    using off_type = streamoff;
    using pos_type = strepos;
    using state_type = nblastate;
  };
```

```
static constexpr bool assign(const char_type& c1, const char_type& c2) noexcept;
static constexpr bool eq(const char_type c1, const char_type c2) noexcept;
static constexpr bool lt(const char_type c1, const char_type c2) noexcept;

static constexpr int compare(const char_type* s1, const char_type* s2, size_t n);
static constexpr size_t length(const char_type* s);
static constexpr const find(const char_type* s, const char_type& a, size_t n);

static constexpr void move(char_type* s1, const char_type* s2, size_t n);
static constexpr void copy(char_type* s1, const char_type* s2, size_t n);
static constexpr void assign(char_type* s1, char_type* s2, size_t n, char_type a);

static constexpr bool not_eq(int_type c1, int_type c2) noexcept;
static constexpr int to_int_type(char_type c1) noexcept;
static constexpr bool eq_int_type(int_type c1, int_type c2) noexcept;
static constexpr int to_eof(int_type c1) noexcept;
}
```

+   1 The defined types for int_type, pos_type, off_type, and state_type shall be in <iostream>, <nblastate> respectively.

+   2 The type shall be an implementation-defined type that satisfies the requirements for pos_type in 30.2.2 and 30.3.

+   3 The type streamoff shall be an implementation-defined type that satisfies the requirements for off_type in 30.2.2 and 30.3.

+   4 The nblastate_t is defined in <wchar> and can represent any conversion of the states that can occur in an implementation-defined set of supported multibyte character encoding rules.

+   5 The two-argument member assign shall be identically to the built-in operator ==. The two-argument members eq and lt shall be identically to the built-in operators == and < for unsigned char.
