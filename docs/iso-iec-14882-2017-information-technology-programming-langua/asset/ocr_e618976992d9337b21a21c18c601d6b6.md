# ISO/IEC 14882:2017(E)

# 31.2.5 [defns.regex.primary.equivalence]

primary equivalence class
a set of one or more characters that share the same primary sort key: that is the sort weighting that depends only upon character shape, and not accents, case, or locale specific tailorings.

# 31.2.6 [defns.regex.regular.expression]

regular expression
a pattern that selects strings from a set of character strings.

# 31.2.7 [defns.regex.subexpression]

sub-expression
a subset of a regular expression that has been marked by parenthesis.
