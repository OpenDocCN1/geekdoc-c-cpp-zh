# 10.6.2 Alignment specification

1 Alignment-specifier may be applied to a variable or to a class member, but it should not be applied to a bit-field, a function parameter, or an exception-declaration (18.3). An alignment-specifier may also be applied to the declaration or definition of a class (in an elaborated-type-specifier (10.1.7.3) or class-head (Claus 12), respectively) to the declaration or definition of an entity (in an opaque-declaration or enum-declaration, 10.2)). An alignment-specifier with an ellipsis is a pack expansion (17.5.3).

2 When the alignment-specifier is of the form aligns(constant-expression) :

+   (2.1) the constant-expression evaluates

+   (2.2) if the expression does not evaluate to an alignment value (6.11), or if it extends an alignment and the implementation does not support that alignment in the context of the declaration, the program is ill-formed.

3 An alignment-specifier of an entity of the form aligns(type-id) has the same effect as aligns(alignof(type-id)) (8.3.6).

4 The requirement of alignment of an entity is strictly the nonzero alignment specified by its alignment-specifiers, if any; otherwise, the alignment-specifiers have no effect.

5 The combined effect of all alignment-specifiers in a declaration shall not specify an alignment that is less strict than the alignment that would be required for the entity being declared if all alignment-specifiers appearing to that entity were omitted. [Example:

```
struct aligns(1) U {
struct aligns(16) {
 S;
};
// error: U aligns an alignment that is less strict than if the aligns(1) was omitted.

```

6 If the definition of an entity has an alignment-specifier, any non-defining declaration of entity shall either specify equivalent alignment or no alignment-specifier. Conversely, if any declaration of an entity has an alignment-specifier, every declaration of that entity shall have an equivalent alignment. A diagnostic is required if an entity has different alignment-specifiers in different translation units. [Example:

```
// Translation unit #1:
struct S { int x; } s, *p = &s;

// Translation unit #2:
struct aligns(16) S;
extern S p;
// error: definition of S lacks a definition, no diagnostic required

```

alignas(T) aligns(A) T[N]; ensures that the final requested alignment will not be weaker than alignof(T), and
