# 16.3.3.2 Ranking implicit conversion sequences

1 This subdefines the basic forms of implicit conversion sequences based on the relationships better conversion sequence and better conversion. If implicit conversion sequence S1 is defined by these rules to be a better sequence than S2, then it is also the case that S2 is a worse conversion sequence than S1. If conversion sequence S1 is neither better nor worse than conversion sequence S2, then S1 and S2 are considered to be *indistinguishable* conversion sequences.

2 When comparing the basic forms of implicit conversion sequences (as defined in 16.3.3.1)

+   (2.1) a standard conversion sequence (16.3.3.1) is a better conversion than a user-defined conversion sequence or an ellipsis conversion sequence,

+   (2.2) a user-defined conversion sequence (16.3.3.2) is a better conversion than an ellipsis conversion sequence.
