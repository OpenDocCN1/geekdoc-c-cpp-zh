# ISO/IEC 14882:2017(E)

```
float strtof(const string&, size_t* idx = nullptr);
double stod(const string&, size_t* idx = nullptr);
long double stod(const string&, size_t* idx = nullptr);
```

4 Effects: These functions call strtof(str.c_str(), ptr), strtod(str.c_str(), ptr), and strtol(str.c_str(), ptr), respectively. Each function returns the converted value, if any. The argument designates a pointer to an object internal to the function to determine what to store at *idx. If the function does not throw an exception and idx != 0, the function stores in *idx the index of the first unconverted element of str.

5 Returns: The converted value.

6 Throws: invalid argument if strtof, strtod, or strtol detects no conversion can be performed. Throws out_of_range if strtof, strtod, or strtol sets errno to ERANGE or if the converted value is outside the range of representable values for the type.

```
string to_string(unsigned val);
string to_string(long val);
string to_string(unsigned long val);
string to_string(long long val);
string to_string(unsigned long long);
string to_string(float val);
string to_string(double val);
string to_string(long double val);
```

7 Returns: Each function returns a string object holding the character representation of the value as would have been generated by calling sprintf(buf, fst, ptr) with a format specifier of "%d", "%u", "%ld", "%lu", "%ll", "%f", or "%Lf", respectively, where buf designates an internal buffer of sufficient size.

```
stoll(const string& str, size_t* idx = nullptr, base = 10);
stoull(const unsigned long& str, size_t* idx = nullptr, base = 10);
long long strtol(const string& str, size_t* idx = nullptr, base = 10);
unsigned long strtou(const unsigned long& str, size_t* idx = nullptr, base = 10);
```

8 Effects: The first two functions call wcstol(str.c_str(), ptr, base), and the last three functions call wcstoul(str.c_str(), ptr, base), wctoll(str.c_str(), ptr, base), and wcstoul(str.c_str(), ptr, base), respectively. Each function returns the converted value, if any. The argument designates a pointer to an object internal to the function to determine what to store at *idx. If the function does not throw an exception and idx != 0, the function stores in *idx the index of the first unconverted element of str.

9 Returns: The converted value.

10 Throws: invalid argument if wcstol, wctoll, or wcstoul detects no conversion could be performed. Throws out_of_range if the converted value is outside the range of representable values for the type.
